# Σχετικά

Οι ακολουθίες στη Factor υπάρχουν σε δύο μορφές όταν χρειάζεται να τις *τροποποιήσεις*:

- **Πίνακες** (`{ … }`) έχουν σταθερό μήκος. Μπορείς να αλλάξεις τι βρίσκεται *σε* κάθε θέση με `set-nth` / `change-nth`, αλλά δεν μπορείς να τους μεγαλώσεις ή να τους μικρύνεις.
- **Διανύσματα** (`V{ … }`) έχουν μεταβλητό μήκος. Το `push` προσθέτει στο τέλος, το `pop` αφαιρεί και επιστρέφει το τελευταίο στοιχείο.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| λέξη            | αποτέλεσμα                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`, πίνακας από `n` αντίγραφα του `elt` |
| `<vector>`      | `( n -- vector )`, κενό διάνυσμα με χωρητικότητα `n` |
| `V{ }`          | κενό literal διανύσματος                           |
| `set-nth`       | `( elt n seq -- )`, εκχωρεί στοιχείο στη θέση `n` |
| `change-nth`    | `( i seq quot -- )`, εφαρμόζει το `quot` στο στοιχείο στη θέση `i` |
| `push`          | `( elt seq -- )`, προσθέτει στο τέλος ενός διανύσματος |
| `suffix!`       | `( seq elt -- seq )`, προσθέτει στο τέλος επιτόπου, επιστρέφει το διάνυσμα |
| `pop`           | `( seq -- elt )`, αφαιρεί και επιστρέφει το τελευταίο |
| `pop*`          | `( seq -- )`, αφαιρεί το τελευταίο, το απορρίπτει |
| `clone`         | `( obj -- copy )`, νέο ανεξάρτητο αντίγραφο     |
| `new-sequence`  | `( n exemplar -- newseq )`, νέα ακολουθία ίδιας κλάσης με το `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`, νέα παραλλαγή με δυνατότητα αλλαγής μεγέθους |

Όταν μεταβάλλεις μια ακολουθία που πέρασε ο καλών, η αλλαγή είναι ορατή στον καλούντα, γιατί κρατάει το ίδιο αντικείμενο. Αν δεν είναι αυτό που θέλεις, κάνε πρώτα `clone` για να πάρεις ένα ανεξάρτητο αντίγραφο.
