# Εισαγωγή

## Δυνατότητα null

Στη Java, το literal `null` χρησιμοποιείται για να δηλώσει την απουσία τιμής.

Οι πρωτόγονοι τύποι δεδομένων στη Java έχουν όλοι μια προεπιλεγμένη τιμή και επομένως δεν μπορούν ποτέ να είναι `null`.
Κατά σύμβαση, ξεκινούν με πεζό γράμμα, π.χ. `int`.

Οι τύποι αναφοράς περιέχουν τη διεύθυνση μνήμης ενός αντικειμένου και μπορούν να έχουν τιμή `null`.
Γενικά ξεκινούν με κεφαλαίο γράμμα, π.χ. `String`.

Αν προσπαθήσεις να αντιστοιχίσεις μια τιμή `null` σε μια πρωτόγονη μεταβλητή, θα προκύψει σφάλμα κατά τη μεταγλώττιση, καθώς η μεταβλητή περιέχει πάντα μια πρωτόγονη τιμή του τύπου που της έχει αντιστοιχιστεί.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Η αντιστοίχιση μιας τιμής `null` σε μια μεταβλητή αναφοράς δεν θα προκαλέσει σφάλμα κατά τη μεταγλώττιση, καθώς οι μεταβλητές αναφοράς μπορούν να είναι `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
