# Εισαγωγή

## Λίστες

Μια λίστα στη Gleam είναι μια αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές. Όλες οι τιμές σε μια λίστα πρέπει να έχουν τον ίδιο τύπο. Επειδή οι λίστες είναι αμετάβλητες, μόλις κατασκευαστεί μια λίστα, η τιμή της δεν μπορεί ποτέ να αλλάξει. Οποιεσδήποτε συναρτήσεις ή τελεστές φαίνεται να τροποποιούν μια λίστα (όπως η προσθήκη ενός στοιχείου), στην πραγματικότητα επιστρέφουν μια νέα λίστα.

Οι λίστες μπορούν να οριστούν ως εξής:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Ο πιο συνηθισμένος τρόπος για να προσθέσεις ένα στοιχείο σε μια λίστα είναι μέσω της σύνταξης επέκτασης:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Το module [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) της βασικής βιβλιοθήκης του Gleam περιέχει πολλές χρήσιμες συναρτήσεις για να δουλεύεις με λίστες. Αυτό το module χρησιμοποιείται πολύ συχνά στον κώδικα Gleam, οπότε είναι καλό να εξοικειωθείς μαζί του.

Τα μοτίβα λιστών μπορούν να χρησιμοποιηθούν σε εκφράσεις case για να αντιστοιχίσεις λίστες και να εκχωρήσεις τις τιμές που περιέχουν σε μεταβλητές:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Εκτός από την αντιστοίχιση λιστών με ακριβές μήκος, η σύνταξη επέκτασης μπορεί να χρησιμοποιηθεί για να αντιστοιχίσεις λίστες που έχουν τουλάχιστον ένα συγκεκριμένο μήκος:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Η σύνταξη επέκτασης μπορεί επίσης να χρησιμοποιηθεί για να εκχωρήσεις το υπόλοιπο της λίστας σε μια μεταβλητή:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Οι εκφράσεις case πρέπει να έχουν ένα μοτίβο για κάθε πιθανή τιμή του τύπου πάνω στον οποίο γίνεται η αντιστοίχιση, οπότε συχνά χρησιμοποιείται ένα τελικό μοτίβο απόρριψης (`_`) για να καλύπτει τις υπόλοιπες τιμές.
