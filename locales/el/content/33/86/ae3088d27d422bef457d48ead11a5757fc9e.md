# Εισαγωγή

Υπάρχουν φορές που μια συνάρτηση υψηλότερης τάξης δέχεται μια άλλη συνάρτηση ως παράμετρο και τη χρησιμοποιεί με τέτοιον τρόπο, ώστε η συνάρτηση που περνάς να καλείται _αφού_ τερματίσει η συνάρτηση υψηλότερης τάξης. Αυτό ονομάζεται διαφυγή από τη συνάρτηση υψηλότερης τάξης, και η συνάρτηση που περνάς αναφέρεται ως _συνάρτηση διαφυγής_.

Αυτό συμβαίνει συνήθως σε ασύγχρονο κώδικα, αλλά μπορεί να προκύψει και σε συναρτήσεις υψηλότερης τάξης, όπου η συνάρτηση που περνάς (ή μια συνάρτηση που την καλεί) επιστρέφεται από τη συνάρτηση υψηλότερης τάξης. Για παράδειγμα:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Εδώ, η συνάρτηση `prepare` δέχεται μια συνάρτηση για την παράμετρο `kitchen` και στη συνέχεια κατασκευάζει μια νέα συνάρτηση, τη `newKitchen`, η οποία μπορεί να καλέσει τη `kitchen`. Αυτή η συνάρτηση `newKitchen` επιστρέφεται μετά σε αυτόν που την κάλεσε. Η προσπάθεια να γράψεις αυτή τη συνάρτηση σε Swift οδηγεί στο σφάλμα: _Escaping local function captures non-escaping parameter 'kitchen'_

Η Swift εγείρει σφάλμα σε αυτή την περίπτωση, γιατί υπάρχουν καταστάσεις όπου η εμφωλευμένη συνάρτηση ή η συνάρτηση που περνάς μπορεί να συλλάβει μια τιμή που μπορεί να οδηγήσει σε διαρροές μνήμης. Το πώς συμβαίνει αυτό και το πώς αποτρέπονται αυτές οι διαρροές ξεπερνούν το εύρος αυτής της άσκησης. Ωστόσο, αυτό το σφάλμα μπορεί να αντιμετωπιστεί τοποθετώντας το χαρακτηριστικό `@escaping` πριν από την υπογραφή τύπου της συνάρτησης που περνάς.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Αυτό το χαρακτηριστικό δηλώνει στον μεταγλωττιστή της Swift ότι ο συγγραφέας γνωρίζει πως ενδέχεται να προκληθούν διαρροές μνήμης, επιτρέποντας σε αυτή τη συνάρτηση να διαφύγει.
