# Μετατροπή μεταβλητής σε const

Σκέψου να μετατρέψεις τη μεταβλητή `%{name}` σε `const`, καθώς η τιμή της προορίζεται να μην αλλάζει ποτέ. Συνήθως, οι τιμές `const` ορίζονται στο επίπεδο της κλάσης, αφού χρησιμοποιούνται συχνά σε πολλές μεθόδους. Σε αυτή την περίπτωση, η τιμή `const` μπορεί να οριστεί μέσα στην ίδια τη μέθοδο, που σημαίνει ότι οι άλλες μέθοδοι δεν μπορούν να χρησιμοποιήσουν την τιμή της.
