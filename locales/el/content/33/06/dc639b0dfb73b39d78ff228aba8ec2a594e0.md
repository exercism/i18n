# Σχετικά

Μια [`list`][lists] στη F# είναι μια αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές. Οι τιμές σε μια λίστα πρέπει όλες να έχουν τον ίδιο τύπο. Επειδή οι λίστες είναι αμετάβλητες, μόλις δημιουργηθεί μια λίστα, η τιμή της δε μπορεί ποτέ να αλλάξει. Η λίστα της F# έχει μια _κεφαλή_ (το πρώτο στοιχείο) και μια _ουρά_ (όλα όσα έρχονται μετά το πρώτο στοιχείο). Η ουρά μιας λίστας είναι η ίδια μια λίστα.

Οι λίστες μπορούν να οριστούν ως εξής:

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

Ο πιο συνηθισμένος τρόπος να προσθέσεις ένα στοιχείο σε μια λίστα είναι μέσω του τελεστή `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Μπορείς να προσαρτήσεις λίστες με τον τελεστή `@` ή με τη `List.append`:

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

Τις λίστες τις χειρίζεσαι με συναρτήσεις και τελεστές που ορίζονται στο [άρθρωμα `List`][list-module]. Κάποιες από αυτές τις συναρτήσεις είναι επίσης διαθέσιμες ως [ιδιότητες][list-properties] ενός στιγμιοτύπου `list`:

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

Δεν υπάρχει σωστή ή λανθασμένη επιλογή εδώ. Γενικά, οι συναρτήσεις του αρθρώματος `List` τα πάνε καλύτερα με την εξαγωγή τύπων, ενώ οι ιδιότητες επιτρέπουν πιο συνοπτικό κώδικα.

Όποιες συναρτήσεις ή τελεστές φαίνεται να τροποποιούν μια λίστα (όπως η προσθήκη ενός στοιχείου), στην πραγματικότητα επιστρέφουν μια νέα λίστα. Η απόδοση συνήθως δεν είναι πρόβλημα, καθώς η υλοποίηση των λιστών αποτρέπει τις περιττές δεσμεύσεις μνήμης και αντιγραφές.

Επειδή οι λίστες είναι υλοποιημένες ως απλά συνδεδεμένες λίστες, η προσθήκη στοιχείου στην αρχή (με τον τελεστή `::`) είναι πολύ γρήγορη, ενώ η πρόσβαση σε ένα στοιχείο με τη θέση του είναι δυνητικά σχετικά αργή.

Μπορείς επίσης να επεξεργαστείς λίστες με αντιστοίχιση μοτίβων, μέσω των μοτίβων [_λίστα_][list-pattern] και [_cons_][cons-pattern]:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Μπορείς επίσης να _απορρίψεις_ μια τιμή κατά την αντιστοίχιση μοτίβων. Όταν δε σε ενδιαφέρει μια τιμή σε μια συγκεκριμένη περίπτωση (δηλαδή δεν πρόκειται να _χρησιμοποιήσεις_ μια τιμή), μπορείς να χρησιμοποιήσεις μια κάτω παύλα (`'_'`) για να το δηλώσεις αυτό:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Το μονό `'_'` πρέπει να έρχεται πάντα _τελευταίο_ στην αντιστοίχιση μοτίβων. Κάθε τιμή που _δεν_ ταιριάζει με καμία από τις άλλες περιπτώσεις θα αντιμετωπίζεται από αυτή την περίπτωση.
