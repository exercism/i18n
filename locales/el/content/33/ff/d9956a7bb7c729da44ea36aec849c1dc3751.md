# Τεστ

Για να κατεβάσεις μια άσκηση, για παράδειγμα τη `hello-world`, άνοιξε ένα τερματικό και τρέξε:

```bash
exercism download --track roc --exercise hello-world
```

Στη συνέχεια, πήγαινε στον φάκελο της άσκησης και επεξεργάσου τον κώδικα για να λύσεις την άσκηση. Για παράδειγμα:

```bash
cd {your Exercism folder}/roc/hello-world
edit HelloWorld.roc
```

Κάθε άσκηση συνοδεύεται από μια σουίτα τεστ. Μπορείς να τρέξεις τα τεστ με την εντολή `roc test`, για παράδειγμα:

```
roc test hello-world-test.roc
```

Αν έχεις λύσει την άσκηση, θα πρέπει να δεις 0 αποτυχημένα τεστ, για παράδειγμα:

```
All (5) tests passed in 123.4 ms.
```

Ωστόσο, αν ο κώδικάς σου έχει σφάλματα, θα μοιάζουν κάπως έτσι:

```
── EXPECT FAILED in hello-world-test.roc ───────────────────────────────────────

This expectation failed:

6│  expect hello == "Hello, World!"
    ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^


1 failed and 0 passed in 123.4 ms.
```

Αυτό θα σε βοηθήσει να διορθώσεις τον κώδικά σου. Μόλις ο κώδικάς σου δουλέψει, μπορείς να τον υποβάλεις με την εντολή `exercism submit` (δες το `HELP.md` στον φάκελο της άσκησης για περισσότερες λεπτομέρειες).
