# Import

Η [ειδική μορφή `import`][import] σου επιτρέπει να χρησιμοποιείς συναρτήσεις και μακροεντολές από ένα εξωτερικό άρθρωμα χωρίς να χρησιμοποιείς το όνομα του αρθρώματος.

Η εισαγωγή ενός ολόκληρου εξωτερικού αρθρώματος μπορεί να δημιουργήσει συγκρούσεις με υπάρχουσες τοπικές συναρτήσεις. Για να το αποφύγεις αυτό, υπάρχουν δύο επιλογές: `:except` και `:only`. Και οι δύο περιμένουν μια λίστα λέξεων-κλειδιών, όπου το κλειδί είναι το όνομα της συνάρτησης και η τιμή το πλήθος των ορισμάτων της.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Συνήθως τα imports προστίθενται στην αρχή του ορισμού του αρθρώματος, αλλά μπορούν να προστεθούν οπουδήποτε. Έχουν λεκτική εμβέλεια, που σημαίνει ότι ένα import που προστίθεται μέσα στον ορισμό μιας συνάρτησης δεν θα είναι διαθέσιμο σε άλλη συνάρτηση.

Τα αχρησιμοποίητα imports προκαλούν προειδοποιήσεις του μεταγλωττιστή.
