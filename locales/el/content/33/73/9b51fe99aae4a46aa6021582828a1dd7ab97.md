# Οδηγίες

Η φίλη του Lucian γυρίζει σπίτι, και εκείνος δεν έχει μαγειρέψει ακόμα το επετειακό τους δείπνο!

Σε αυτή την άσκηση, θα γράψεις κώδικα για να βοηθήσεις τον Lucian να μαγειρέψει τα εξαίσια λαζάνια από το αγαπημένο του βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες που σχετίζονται με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο σε λεπτά

Όρισε τη σταθερά `expected_minutes_in_oven` που αντιπροσωπεύει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο σε λεπτά είναι `40`.

## 2. Υπολόγισε τον χρόνο που απομένει στο φούρνο σε λεπτά

Υλοποίησε τη μέθοδο `remaining_minutes_in_oven` που παίρνει ως _παράμετρο_ τα πραγματικά λεπτά που βρίσκονται τα λαζάνια στον φούρνο και _επιστρέφει_ πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στον φούρνο, με βάση τον **αναμενόμενο χρόνο στο φούρνο σε λεπτά** από την προηγούμενη εργασία.

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη μέθοδο `preparation_time_in_minutes` που παίρνει ως _παράμετρο_ τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και _επιστρέφει_ πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υλοποίησε τη μέθοδο `total_time_in_minutes` που παίρνει _δύο παραμέτρους_: η παράμετρος `numbernumber_of_layers` είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια, και η παράμετρος `actual_minutes_in_oven` είναι ο αριθμός των λεπτών που βρίσκονται τα λαζάνια στον φούρνο. Η μέθοδος πρέπει να _επιστρέφει_ πόσα λεπτά έχεις δουλέψει συνολικά για το μαγείρεμα των λαζάνια, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στον φούρνο τη στιγμή αυτή.

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
