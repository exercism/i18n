# Οδηγίες

Είναι ο τελικός της σεζόν στο τοπικό κλαμπ. Κρατάς τον πίνακα κατάταξης στη γραμμή τερματισμού: οι δρομείς περνούν με τη σειρά, οι διάδρομοι χρειάζονται ετικέτες και το επίσημο κατάστιχο πρέπει να σχολιαστεί πριν από την επόμενη κούρσα.

Τα ονόματα των δρομέων φτάνουν ως πίνακας, με σειρά τερματισμού: το όνομα στη θέση 0 είναι ο νικητής, αυτό στη θέση 1 είναι ο δεύτερος, και ούτω καθεξής.

## 1. Ανάθεσε αριθμούς συμμετοχής

Όρισε τη συνάρτηση `assign-bibs` να δέχεται έναν πίνακα με ονόματα δρομέων και να επιστρέφει έναν πίνακα από ζεύγη `{ position name }`, πρώτα τη θέση.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Ετικέτες διαδρόμου

Όρισε τη συνάρτηση `lane-labels` να δέχεται έναν πίνακα με ονόματα δρομέων και να επιστρέφει συμβολοσειρές σαν την `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Σήμανε τους δρομείς

Όρισε τη συνάρτηση `tag-racers` να δέχεται έναν πίνακα με ονόματα δρομέων *και* μια συμβολοσειρά σήμανσης, και να επιστρέφει ετικέτες της μορφής `"<tag>/<index>: <name>"`. Το ίδιο σήμα μπαίνει μέσα σε κάθε ετικέτα.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Κατέγραψε τους τερματισμούς

Όρισε τη συνάρτηση `record-finishes` να δέχεται έναν πίνακα με ονόματα δρομέων και ένα κατάστιχο (ένα vector). Για κάθε δρομέα, πρόσθεσε επιτόπου στο κατάστιχο μια συμβολοσειρά της μορφής `"<index>: <name>"`. Δεν επιστρέφει τίποτα.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Κουδούνια γύρου

Όρισε τη συνάρτηση `lap-bells` να δέχεται έναν αριθμό `laps` και να επιστρέφει μια συμβολοσειρά που αποτελείται από το `"ding "` επαναλαμβανόμενο `laps` φορές.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
