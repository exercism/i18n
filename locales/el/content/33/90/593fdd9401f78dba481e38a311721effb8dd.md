# Παράρτημα οδηγιών

## Υλοποίηση

Σε αυτή την άσκηση θα υλοποιήσεις μια διαδικασία που προορίζεται να δεσμεύει τη συμβολοσειρά που επιστρέφει. Η αποδέσμευση της συμβολοσειράς είναι ευθύνη αυτού που καλεί τη διαδικασία.

```odin
// The procedure will be called like that:
formatted := format("Gianna", 4)
// ...
// and eventually the caller will delete the string
delete(formatted)
```
