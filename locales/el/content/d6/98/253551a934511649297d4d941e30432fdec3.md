# Εισαγωγή

Μια [`function`][function] είναι ένας τρόπος να χωρίζεις τον κώδικα σε τμήματα, ώστε να μπορείς να τον καλείς με το όνομά του από ένα ή περισσότερα σημεία του προγράμματος.
Οι συναρτήσεις χρησιμοποιούνται για την εκτέλεση συγκεκριμένων και επαναλαμβανόμενων εργασιών.

Πιο τυπικά: συνάρτηση είναι οποιοδήποτε αντικείμενο της Python στο οποίο μπορεί να εφαρμοστεί η πράξη `function call`.
Μια συνάρτηση μπορεί να χρησιμοποιηθεί για να κάνει `return` μία ή περισσότερες τιμές ως αποτέλεσμα κάποιων πράξεων, ή μπορεί να χρησιμοποιηθεί για μία ή περισσότερες `side effects`.
Αν μια συνάρτηση δεν ορίζει τιμή επιστροφής, θα επιστρέψει και πάλι `None`.

Ακολουθεί ένα παράδειγμα συνάρτησης με παρενέργεια:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

Στο παραπάνω παράδειγμα, η λέξη-κλειδί `def` χρησιμοποιείται για να σηματοδοτήσει την αρχή του ορισμού της συνάρτησης.
Το `hello` είναι το όνομα της συνάρτησης.
Οι κενές παρενθέσεις δηλώνουν ότι δεν περνιέται καμία τιμή στη συνάρτηση.
Το σώμα της συνάρτησης είναι η μοναδική εντολή `print("Hello")`.
Η `print` είναι επίσης μια συνάρτηση.
Το `"Hello"` μέσα στις παρενθέσεις της συνάρτησης `print` είναι γνωστό ως `argument`.
Το όρισμα χρησιμοποιείται από τη συνάρτηση `print` για να ξέρει τι θα εκτυπώσει.
Πρόσεξε ότι το σώμα της συνάρτησης έχει εσοχή.
Η εσοχή είναι σημαντική, γιατί η Python βασίζεται σε αυτήν για να ξέρει πού τελειώνει αυτό το μπλοκ κώδικα.
Το σώμα της συνάρτησης τελειώνει είτε στο τέλος του προγράμματος είτε ακριβώς πριν από την επόμενη γραμμή κώδικα που _δεν_ έχει εσοχή.
Επειδή το `hello()` δεν ορίζει τιμή `return`, εκτελεί την παρενέργειά του, δηλαδή την κλήση της `print()`, και μετά επιστρέφει `None`.
Τέλος, καλούμε τη συνάρτηση χρησιμοποιώντας το όνομά της και τις παρενθέσεις, που σηματοδοτούν στον διερμηνευτή της Python ότι αυτό είναι ένα όνομα που μπορεί να _κληθεί_.

Ακολουθεί ένα παράδειγμα συνάρτησης με τιμή επιστροφής:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

Το σώμα αυτής της συνάρτησης άλλαξε: από το να _καλεί_ τη `print`, τώρα _επιστρέφει_ τη `string` "Hello".
Στο τέλος, ο κώδικας εξακολουθεί να εκτυπώνει το `"Hello"`, αλλά η παρενέργεια συμβαίνει στον _κώδικα που καλεί_ και όχι στη συνάρτηση `hello`.
Αν ξεχάσεις τις παρενθέσεις όταν καλείς τη συνάρτηση `hello` (π.χ. `print(hello)`), τότε η `print` θα εμφανίσει κάτι σαν

```
<function hello at 0x0000026E18E93E20>
```

Είναι σημαντικό ότι, ακόμα κι αν μια συνάρτηση δεν δέχεται ορίσματα (_δηλαδή δεν έχει παραμέτρους_), πρέπει να χρησιμοποιείς τις κενές παρενθέσεις για να την _καλέσεις_ σωστά.
Αυτό είναι διαφορετικό από μια γλώσσα όπως η Ruby, που δεν απαιτεί κενές παρενθέσεις για να καλέσεις μια συνάρτηση χωρίς ορίσματα.

Μια συνάρτηση μπορεί να ορίσει μηδέν ή περισσότερες `parameters`. Μια παράμετρος ορίζει ποια ορίσματα δέχεται η συνάρτηση.

Ακολουθεί ένα παράδειγμα συνάρτησης που δέχεται ένα όρισμα:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

Η παράμετρος ορίζεται ως `name`.
Το `"Bob"` είναι το όρισμα που περνάει το πρόγραμμα στη συνάρτηση `hello`.
Η συνάρτηση _επιστρέφει_ τη `string` "Hello, Bob".

Τι γίνεται αν κάποιος καλέσει τη `hello` χωρίς να περάσει όρισμα;
Το πρόγραμμα πετάει ένα σφάλμα:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Αν δεν θέλουμε το πρόγραμμα να πετάει σφάλμα όταν δεν υπάρχει όρισμα (_αλλά θέλουμε να επιτρέψουμε στον κώδικα που καλεί να μην το δίνει_), μπορούμε να ορίσουμε ένα [προεπιλεγμένο όρισμα][default arguments].
Ένα προεπιλεγμένο όρισμα ορίζει ποια τιμή θα χρησιμοποιηθεί αν το όρισμα λείπει όταν καλείται η συνάρτηση.

Ακολουθεί ένα παράδειγμα συνάρτησης με προεπιλεγμένο όρισμα:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Στην παράμετρο `name` δίνεται το προεπιλεγμένο όρισμα `"you"`, οπότε το πρόγραμμα εμφανίζει `Hello, you`, αν δεν του περάσεις όρισμα `name`.

Για περισσότερα σχετικά με τα ορίσματα συναρτήσεων, δες την έννοια [ορίσματα συναρτήσεων][function arguments].
