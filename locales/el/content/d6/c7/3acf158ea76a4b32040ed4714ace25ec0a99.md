# Προσθήκη οδηγιών

## Λέξεις

Όρισε ένα tuple `linked-list-node`.

Όρισε ένα tuple `linked-list` και δώσε μια μέθοδο `M: linked-list length`
(από το `sequences`), ώστε τα τεστ να μπορούν να καλέσουν το `length` απευθείας
στη λίστα σου.

- `<linked-list> ( -- linked-list )`: δημιουργεί μια κενή λίστα.
- `>linked-list ( seq -- linked-list )`: προσθέτει κάθε στοιχείο του
  `seq` σε μια νέα λίστα, με τη σειρά.
- `linked-list>array ( linked-list -- array )`: επιστρέφει τις
  τιμές, με την κορυφή της λίστας πρώτη.
- `list-push ( linked-list value -- linked-list )`: προσθέτει μια τιμή
  στην κορυφή.
- `list-pop ( linked-list -- linked-list value )`: αφαιρεί και
  επιστρέφει την τιμή στην κορυφή.
- `list-peek ( linked-list -- value )`: επιστρέφει την τιμή στην κορυφή
  χωρίς να την αφαιρέσει.
- `list-reverse ( linked-list -- linked-list )`: επιστρέφει μια λίστα
  με τα στοιχεία σε αντίστροφη σειρά.

Πέτα μια κλάση σφάλματος `list-empty` από το `list-pop` και το `list-peek`
όταν η λίστα είναι κενή.
