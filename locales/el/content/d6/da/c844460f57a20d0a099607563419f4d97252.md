# Εισαγωγή

Μια *παράθεση*, δηλαδή κώδικας μέσα σε `[ ]` αγκύλες, είναι η ίδια μια τιμή στη Factor, ακριβώς όπως ένας αριθμός ή μια συμβολοσειρά. Μπορείς να την αποθηκεύσεις σε μια μεταβλητή, να τη βάλεις σε έναν πίνακα, να τη δώσεις σε μια άλλη λέξη και να την *καλέσεις* αργότερα.

## `call`

Το `call` (στο [`kernel`][kernel]) εκτελεί μια παράθεση:

```factor
3 4 [ + ] call .
! => 7
```

Όταν καλείς μια παράθεση με `call` σε ένα περιβάλλον όπου η Factor δεν μπορεί να συμπεράνει την επίδραση στη στοίβα της, πρέπει να δηλώσεις την επίδραση ρητά:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

Αυτό μεταγλωττίζει έναν έλεγχο κατά την εκτέλεση ότι η παράθεση έχει πραγματικά την επίδραση που δηλώθηκε.

## Οι παραθέσεις μέσα σε ακολουθίες

Επειδή οι παραθέσεις είναι τιμές, ένας πίνακας μπορεί να περιέχει ένα μείγμα από αριθμούς και παραθέσεις:

```factor
{ 3 4 [ + ] }
```

Έτσι, το "ένα πρόγραμμα" γίνεται μια συνηθισμένη ακολουθία, και το `each` γίνεται ένας φυσικός τρόπος να την εκτελέσεις:

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## Κόβοντας το τέλος μιας ακολουθίας

Το `head*` επιστρέφει τα πάντα εκτός από τα τελευταία `n` στοιχεία· το `last2` επιστρέφει τα δύο τελευταία:

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

Μαζί με το `suffix`, αυτά είναι όλα όσα χρειάζεσαι για να γράψεις μια πράξη στη στοίβα που "καταναλώνει τα δύο πάνω στοιχεία και σπρώχνει ένα αποτέλεσμα".
