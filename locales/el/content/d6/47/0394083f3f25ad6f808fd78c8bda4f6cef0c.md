# Σχετικά με τις Ανώνυμες Συναρτήσεις και τα Κλεισίματα

Η PHP επιτρέπει να δηλώνεις συναρτήσεις μέσα σε άλλες συναρτήσεις. Αυτές οι συναρτήσεις δε χρειάζεται να έχουν όνομα, αλλά μπορείς να τις εκχωρήσεις σε μεταβλητές ή ακόμη και να τις περάσεις απευθείας σε μια άλλη συνάρτηση που απαιτεί μια παράμετρο συνάρτησης.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

Η συνάρτηση που ορίζεις και περνάς στο `array_filter` παραπάνω είναι μια ανώνυμη συνάρτηση. Η συνάρτηση `array_filter` τη χρησιμοποιεί για να προσδιορίσει αν μια δεδομένη τιμή ενός πίνακα θα επιστραφεί στο αποτέλεσμα του `array_filter`. Αν η συνάρτηση επιστρέψει `true` για μια τιμή, τότε αυτή θα συμπεριληφθεί στον πίνακα αποτελεσμάτων.

Μπορείς επίσης να χρησιμοποιήσεις ανώνυμες συναρτήσεις για να αναφέρεσαι, μέσα από τη συνάρτηση, σε μεταβλητές που βρίσκονται στην εμβέλεια εκτός της συνάρτησης. Αυτό είναι γνωστό ως το ότι η εμβέλεια της συνάρτησης "κλείνει" πάνω από τη μεταβλητή που χρησιμοποιείται στη συνάρτηση, εξ ου και το όνομα "κλείσιμο". Σε ορισμένες γλώσσες, όλες οι μεταβλητές που βρίσκονται στην εμβέλεια επιτρέπεται αυτόματα να χρησιμοποιούνται μέσα στο κλείσιμο. Στην PHP, το `$this`, που αναφέρεται στο τρέχον αντικείμενο, επιτρέπεται αυτόματα μέσα στο κλείσιμο. Όλες οι άλλες μεταβλητές πρέπει να αναφέρονται ρητά χρησιμοποιώντας τη λέξη-κλειδί `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

Στη συνάρτηση `makeAdderFunction` παραπάνω, η τιμή `$number` που περνιέται "κλείνει" μέσα στην εσωτερικά ορισμένη ανώνυμη συνάρτηση, η οποία μετά επιστρέφεται. Έπειτα, κάθε φορά που εκτελείται αυτή η συνάρτηση, γνωρίζει την τιμή του `$number` που είχε περαστεί. Αν καλέσεις ξανά αυτή τη συνάρτηση με έναν άλλο αριθμό, θα επιστραφεί μια εντελώς διαφορετική συνάρτηση. Δε θα αλλάξει τις τιμές ή τη λειτουργικότητα που επέστρεψε η πρώτη κλήση της συνάρτησης.
Αν χρειάζεται να κλείσεις πάνω από περισσότερες από μία μεταβλητές, μπορούν να προστεθούν στη λέξη-κλειδί `use`, χωρισμένες με κόμμα.

Η PHP έχει επίσης μια συντομότερη σύνταξη συναρτήσεων που ονομάζεται `arrow functions`. Απαιτείται να είναι αρκετά απλές. Η βασική τους μορφή είναι:

```php
fn(arguments) => expression
```

Σε αυτό το στυλ συνάρτησης, δε χρειάζεται να χρησιμοποιήσεις το `use`. Κλείνει και συλλαμβάνει αυτόματα οποιεσδήποτε τιμές στη γονική εμβέλεια. Η παράσταση σε αυτές τις `arrow functions` επιστρέφεται αυτόματα, χωρίς να χρειάζεται να χρησιμοποιήσεις τη λέξη-κλειδί `return`. Αυτό σου επιτρέπει να ξαναγράψεις τη συνάρτηση `onlyOdds` παραπάνω ως εξής:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

Η `makeAdderFunction` παραπάνω θα μπορούσε να ξαναγραφτεί ως εξής:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Σημείωση:** Αν η συνάρτηση δε μπορεί να γραφτεί ως παράσταση, τότε δε μπορεί να χρησιμοποιηθεί η συντομότερη σύνταξη `arrow functions`.

Οι μεταβλητές περνιούνται και χρησιμοποιούνται μέσα στις ανώνυμες συναρτήσεις και στα κλεισίματα κατά τιμή. Αυτό σημαίνει ότι αν αλλάξεις την τιμή της μεταβλητής μέσα στη συνάρτηση, δε θα επηρεαστεί η τιμή της μεταβλητής έξω από τη συνάρτηση. Αν χρειάζεται να τροποποιηθεί η τιμή, μπορείς να τη μεταβιβάσεις κατ' αναφορά.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

Στο παραπάνω παράδειγμα, το `array_walk` διατρέχει κάθε στοιχείο του πίνακα, στέλνοντας κάθε τιμή στη συνάρτηση που δηλώνεται στην κλήση. Διατηρεί ένα τρέχον άθροισμα στο `$total`, όπου κάθε τιμή που προστίθεται είναι η απόλυτη τιμή του αριθμού. Παρακολουθεί επίσης πόσοι αριθμοί υπήρχαν. Και οι δύο τιμές χρησιμοποιούνται στο κλείσιμο κατ' αναφορά, όπως υποδεικνύεται από το `&` μπροστά από κάθε μεταβλητή στο τμήμα `use`. Αυτό σημαίνει ότι οι αλλαγές που συμβαίνουν στις μεταβλητές θα εξακολουθούν να ισχύουν όταν ολοκληρωθεί το `array_walk`, ώστε η συνάρτηση να μπορεί να επιστρέψει τον μέσο όρο των απόλυτων τιμών των αριθμών του πίνακα.

Οι ανώνυμες συναρτήσεις και τα κλεισίματα μπορούν να προσφέρουν έναν βολικό τρόπο για να ορίσεις μια συνάρτηση που μπορεί να χρειαστεί μόνο μέσα σε ένα συγκεκριμένο πλαίσιο, ή για να ορίσεις μια συνάρτηση που επιστρέφει μια δυναμική συνάρτηση με βάση ένα σύνολο παραμέτρων που είναι γνωστές σε διαφορετική χρονική στιγμή από εκείνη κατά την οποία χρησιμοποιείται πραγματικά η συνάρτηση.
