# Λογικές τιμές

Η Crystal έχει έναν τύπο γνωστό ως [`Bool`][bools].
Αντιπροσωπεύει τις τιμές `true` και `false`.

## Λογικοί τελεστές

Η Crystal έχει τρεις λογικούς τελεστές (`!`, `||`, `&&`), που συνδυάζουν λογικές τιμές και φτιάχνουν εκφράσεις που παράγουν διαφορετικές τιμές.

### And(`&&`)

Ο [τελεστής _and_][and] στη Crystal αντιπροσωπεύεται από το `&&` και επιστρέφει `true` αν και οι δύο τιμές είναι `true`. Αλλιώς, επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _and_, μία λογική τιμή τοποθετείται στα δεξιά του `&&` και μία άλλη στα αριστερά.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

Ο [τελεστής _or_][or] στη Crystal αντιπροσωπεύεται από το `||` και επιστρέφει `true` αν **τουλάχιστον μία** από τις τιμές που δίνονται είναι `true`. 
Αν και οι δύο τιμές είναι `false`, τότε επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _or_, μία λογική τιμή πρέπει να τοποθετείται στα δεξιά του `||` και μία άλλη στα αριστερά.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

Ο τελεστής _not_ στη Crystal αντιπροσωπεύεται από το `!` και επιστρέφει `true` αν η δεδομένη λογική τιμή είναι `false` και επιστρέφει `false` αν δοθεί `true`.
Όταν χρησιμοποιείς τον τελεστή _not_, μία λογική τιμή πρέπει να τοποθετείται μετά τον τελεστή (`!`).

```crystal
!true
# => false

!false
# => true
```

## Χρήση παρενθέσεων(`()`)

Όταν δουλεύεις με λογικές τιμές, μπορείς να χρησιμοποιήσεις παρενθέσεις για να αποφασίσεις ποιες λογικές τιμές θα αξιολογηθούν πρώτες.
Το αποτέλεσμα μπορεί να διαφέρει ανάλογα με το πώς χρησιμοποιούνται οι παρενθέσεις.
Στη Crystal, ό,τι βρίσκεται μέσα στις παρενθέσεις αξιολογείται πρώτα.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Εφόσον ό,τι βρίσκεται μέσα στις παρενθέσεις αξιολογείται πρώτα, ο τελεστής _not_ θα εφαρμοστεί στην έκφραση μέσα στις παρενθέσεις στο παρακάτω παράδειγμα.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Να χρησιμοποιείς παρενθέσεις μόνο όταν επηρεάζουν το αποτέλεσμα. Αλλιώς, πρέπει να παραλείπονται.
~~~~
