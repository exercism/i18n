# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις κώδικα για να βοηθήσεις έναν ελεύθερο επαγγελματία να επικοινωνεί με έναν project manager.
Ο στόχος σου είναι να παρέχεις μερικά βοηθητικά εργαλεία για να υπολογίζεις γρήγορα την ημερήσια και τη μηνιαία χρέωση, προαιρετικά με μια δεδομένη έκπτωση.

Πρώτα, ορίζουμε μερικούς κανόνες ανάμεσα στον ελεύθερο επαγγελματία και τον project manager:

- Η ημερήσια χρέωση είναι 8 φορές η ωριαία χρέωση.
- Ο μήνας έχει 22 χρεώσιμες ημέρες.

Μερικές φορές, ο ελεύθερος επαγγελματίας προσφέρεται να εφαρμόσει μια έκπτωση στην ημερήσια χρέωσή του (για παράδειγμα, για τους πιο πιστούς πελάτες του ή για πελάτες μη κερδοσκοπικών οργανώσεων).

Οι εκπτώσεις αναπαρίστανται ως δεκαδικοί αριθμοί που εκφράζουν ποσοστά, για παράδειγμα, `25.0` (25%).

## 1. Υπολόγισε την ημερήσια χρέωση δεδομένης της ωριαίας χρέωσης

Υλοποίησε μια συνάρτηση με το όνομα `daily_rate` που να υπολογίζει την ημερήσια χρέωση, παίρνοντας ως παράμετρο μια ωριαία χρέωση.
Το συμβόλαιο ορίζει ότι μια μέρα έχει 8 χρεώσιμες ώρες.

```cpp
daily_rate(60)
// => 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι τύπου `double`.

## 2. Υπολόγισε μια τιμή με έκπτωση

Υλοποίησε μια συνάρτηση `apply_discount` που να υπολογίζει την τιμή μετά από μια έκπτωση.
Θα πρέπει να δέχεται δύο παραμέτρους: την αρχική τιμή και το ποσοστό έκπτωσης.

```cpp
apply_discount(150, 10)
// => 135.0
```

Η τιμή που επιστρέφεται πρέπει να είναι πάντα τύπου `double`, χωρίς καμία στρογγυλοποίηση.

## 3. Υπολόγισε τη μηνιαία χρέωση δεδομένων μιας ωριαίας χρέωσης και μιας έκπτωσης

Υλοποίησε μια συνάρτηση `monthly_rate` που να υπολογίζει τη μηνιαία χρέωση με έκπτωση.
Θα πρέπει να έχει δύο παραμέτρους, μια ωριαία χρέωση και την έκπτωση σε ποσοστό.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

Η μηνιαία χρέωση που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα πάνω (δηλαδή με οροφή) στον πλησιέστερο ακέραιο.

## 4. Υπολόγισε τον αριθμό των πλήρων εργάσιμων ημερών δεδομένων ενός προϋπολογισμού, μιας ωριαίας χρέωσης και μιας έκπτωσης

Υλοποίησε μια συνάρτηση `days_in_budget` που παίρνει έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση, και υπολογίζει πόσες πλήρεις μέρες εργασίας καλύπτει.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

Ο αριθμός των ημερών που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα κάτω (δηλαδή με δάπεδο) στον αμέσως μικρότερο ακέραιο.
