# Σχετικά

Ο πρωτόγονος τύπος `char` της Java είναι μια αναπαράσταση 16 bit ενός μεμονωμένου χαρακτήρα Unicode.

~~~~exercism/note
Ο τύπος `char` βασίζεται στην [αρχική προδιαγραφή Unicode][unicode-specification], η οποία χρησιμοποιούσε 16 bit για την αναπαράσταση των χαρακτήρων.
Αυτό αρκεί για να καλύψει τα περισσότερα από τα κοινά γράμματα και καλύπτει χαρακτήρες στο εύρος από 0x0000 έως 0xFFFF.
Η προδιαγραφή έχει έκτοτε επεκτείνει το εύρος των δυνατών χαρακτήρων μέχρι το 0x01FFFF.

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

Πολλά `char` μπορούν να σχηματίσουν μια συμβολοσειρά, όπως `"word"`, ή τα `char` μπορούν να υποστούν επεξεργασία ανεξάρτητα.
Ένα λεκτικό `char` περικλείεται από μονά εισαγωγικά (π.χ. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Πώς παίρνεις τα `char` μιας `String`

Η μέθοδος `String.toCharArray` επιστρέφει τα char μιας String ως πίνακα.
Όπως αναφέρθηκε στους [πίνακες][concept-arrays], μπορείς να χρησιμοποιήσεις έναν `for` βρόχο για να διατρέξεις τον πίνακα.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Η κλάση [Character][docs-character]

Υπάρχουν πολλές ενσωματωμένες μέθοδοι της βιβλιοθήκης για να εξετάζεις και να χειρίζεσαι `char`.
Αυτές βρίσκονται ως στατικές μέθοδοι της κλάσης [`java.lang.Character`][docs-character].
Ορίστε μερικά παραδείγματα:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Κάποιες μέθοδοι της κλάσης Character έχουν υπερφόρτωση, ώστε να δέχονται είτε `char` είτε `int`.
Για παράδειγμα, η `isDigit` έχει μία που δέχεται ένα [`char`][is-digit-char] και μία άλλη ένα [`int`][is-digit-int].
Όπως αναφέρθηκε προηγουμένως, ο τύπος `char` μπορεί να αναπαραστήσει μόνο τους χαρακτήρες στο εύρος από 0x0000 έως 0xFFFF.
Ο `int`, ωστόσο, μπορεί να αναπαραστήσει όλους τους χαρακτήρες, εξ ου και οι υπερφορτώσεις με `int`.

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## Πώς προσθέτεις ένα `char` σε μια `String`

Ο τελεστής `+` μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα `char` σε μια `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Πρόσεχε να _μην_ χρησιμοποιήσεις το `+` για να ενώσεις δύο `char` σε μια `String`!
Η πρόσθεση δύο `char` με αυτόν τον τρόπο δίνει ένα `int`, _όχι_ μια `String`!
Για παράδειγμα:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Αυτό συμβαίνει επειδή η Java προάγει το `char` σε `int` (δείτε το [4.2 Πρωτόγονοι Τύποι και Τιμές][jls-primitives] της [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Ωστόσο, όταν υπάρχουν πολλοί χαρακτήρες που πρέπει να προστεθούν, μπορεί να είναι πιο αποδοτικό να χρησιμοποιήσεις ένα [`StringBuilder`][docs-stringBuilder]:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
