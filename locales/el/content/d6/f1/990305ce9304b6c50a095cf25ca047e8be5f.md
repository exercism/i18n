# Προσθήκη στις οδηγίες

## Πρόσθετες οδηγίες

Θα σου δοθεί ένας πίνακας με το όνομα "isogram".
Η πρώτη στήλη, "phrase", περιέχει κάποιο κείμενο.
Πρέπει να προσδιορίσεις αν η φράση είναι ισόγραμμα.
Ενημέρωσε τη δεύτερη στήλη, "is_isogram", με μια ακέραια τιμή:

* 1 αν η φράση είναι ισόγραμμα,
* 0 αν δεν είναι.

~~~~exercism/note
Οι πράξεις σύγκρισης της SQLite επιστρέφουν τιμές Boolean ως αριθμούς 0/1

```sh
$ sqlite3
sqlite> .mode table
sqlite> SELECT 1 < 2 AS "true", 1 > 2 AS "false";
+------+-------+
| true | false |
+------+-------+
| 1    | 0     |
+------+-------+
```
