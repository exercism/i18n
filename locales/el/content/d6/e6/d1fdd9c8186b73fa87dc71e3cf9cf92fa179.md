# Οδηγίες

Γράφεις τον ψηφιακό πυρήνα μιας μικρής κονσόλας μίξης σε ένα στούντιο ηχογράφησης.

Ο ήχος φτάνει ως ροή δειγμάτων.
Κάθε δείγμα είναι ένας αριθμός που περιγράφει τη θέση του κώνου ενός μεγαφώνου τη δεδομένη στιγμή.
Η κονσόλα επεξεργάζεται ένα ολόκληρο μπλοκ δειγμάτων ταυτόχρονα, εφαρμόζοντας την ίδια πράξη σε κάθε ένα.

Έχεις πέντε εργασίες, καθεμία από τις οποίες επεξεργάζεται ένα μπλοκ δειγμάτων που βρίσκεται στη μνήμη.
Λαμβάνεις τους τελεστέους μέσω διευθύνσεων μνήμης και γράφεις την απάντησή σου μέσω μιας διεύθυνσης αποτελέσματος.

~~~~exercism/note
Οι υπολογισμοί σε αυτή την άσκηση πρέπει να γίνονται με εντολές SIMD, όχι με βαθμωτές πράξεις.
~~~~

## 1. Ανάμιξε δύο κομμάτια

Το στούντιο μερικές φορές ηχογραφεί όργανα σε διαφορετικά κομμάτια.
Για να τα ακούσεις από τα ίδια ηχεία, αθροίζεις τα δύο κομμάτια σε ένα.

Υλοποίησε τη συνάρτηση `mix_tracks`, η οποία προσθέτει δύο κομμάτια μεταξύ τους, δείγμα προς δείγμα.
Κάθε κομμάτι είναι ένα μπλοκ από 8 προσημασμένα δείγματα 16 bit.
Ένα άθροισμα που υπερχειλίζει το εύρος των προσημασμένων 16 bit πρέπει να περιορίζεται αντί να αναδιπλώνεται.

Αυτή η συνάρτηση παίρνει ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte για ένα buffer όπου γράφονται τα 8 αναμεμειγμένα δείγματα.
- `track_a`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του πρώτου κομματιού, με 8 προσημασμένα δείγματα 16 bit.
- `track_b`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του δεύτερου κομματιού, με 8 προσημασμένα δείγματα 16 bit.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 2. Αφαίρεσε τη διαρροή

Όταν δύο μικρόφωνα ηχογραφούν ταυτόχρονα, το καθένα πιάνει ένα αμυδρό αντίγραφο της πηγής του άλλου.
Αυτό το ανεπιθύμητο αντίγραφο ονομάζεται _διαρροή_.
Μόλις μετρηθεί αυτή η διαρροή, πρέπει να αφαιρεθεί και πάλι για να καθαρίσει το κομμάτι.

Υλοποίησε τη συνάρτηση `remove_bleed`, η οποία αφαιρεί το μπλοκ της διαρροής από το μπλοκ του κομματιού, δείγμα προς δείγμα.
Κάθε μπλοκ είναι 8 προσημασμένα δείγματα 16 bit και η αφαίρεση πρέπει να γίνεται με κορεσμό.

Αυτή η συνάρτηση παίρνει ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης όπου γράφονται τα 8 καθαρισμένα δείγματα (η ευθυγράμμιση δεν είναι εγγυημένη).
- `track`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του ηχογραφημένου κομματιού, 8 προσημασμένα δείγματα 16 bit.
- `bleed`: διεύθυνση μνήμης της διαρροής προς αφαίρεση, 8 προσημασμένα δείγματα 16 bit (η ευθυγράμμιση δεν είναι εγγυημένη).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 3. Συνδύασε τους μετρητές

Πάνω από κάθε κανάλι βρίσκεται ένας μετρητής στάθμης, μια μικρή ράβδος της οποίας η φωτεινότητα δείχνει πόσο δυνατό είναι αυτό το κανάλι.
Το μπροστινό πάνελ έχει έναν κεντρικό μετρητή που πρέπει να λάμπει τόσο φωτεινά όσο τα δύο κανάλια μαζί.
Αθροίζεις τα δύο μπλοκ του μετρητή για να τον οδηγήσεις.

Σημείωσε ότι ένας φωτεινός μετρητής μένει στη μέγιστη φωτεινότητα αντί να γυρίζει πίσω στο σκοτάδι, οπότε το άθροισμα γίνεται με κορεσμό.

Υλοποίησε τη συνάρτηση `combine_meters`, η οποία προσθέτει δύο μπλοκ του μετρητή δείγμα προς δείγμα.
Αυτή η συνάρτηση παίρνει ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte όπου γράφονται οι 16 συνδυασμένες τιμές.
- `meter_a`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του μπλοκ του μετρητή του πρώτου καναλιού, με 16 συσκευασμένες ανυπόγραφες τιμές 8 bit.
- `meter_b`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του μπλοκ του μετρητή του δεύτερου καναλιού, με 16 συσκευασμένες ανυπόγραφες τιμές 8 bit.

Κάθε μπλοκ είναι 16 ανυπόγραφες τιμές 8 bit.
Πρέπει να προστεθούν μεταξύ τους, με κορεσμό στο ανυπόγραφο εύρος.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 4. Εφάρμοσε ένα σβήσιμο

Το τραγούδι δεν πρέπει να σταματά απότομα, αλλά να σβήνει σταδιακά στο τέλος.
Έχεις ένα μπλοκ από _συντελεστές ενίσχυσης_, έναν για κάθε δείγμα, που μειώνουν σταδιακά την ένταση, από πιο σιγά σε ακόμη πιο σιγά.

Κάθε συντελεστής είναι ένα κλάσμα εκφρασμένο πάνω στο `65536`.
Για παράδειγμα, αν ένα δείγμα έχει τιμή `16384`, στην πραγματικότητα εκφράζει το `16384 / 65536`, που είναι `1 / 4`.
Η μεγαλύτερη χρησιμοποιήσιμη τιμή, το `32767`, είναι λίγο κάτω από το ένα δεύτερο.

Εφόσον το `65536` είναι `2^16`, πολλαπλασιάζοντας ένα δείγμα με τον συντελεστή του και κρατώντας το _υψηλό μισό_ του γινομένου προκύπτει `sample * gain / 65536`.

Υλοποίησε τη συνάρτηση `apply_fade`, η οποία κλιμακώνει κάθε δείγμα με τον συντελεστή του.
Αυτή η συνάρτηση παίρνει ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte όπου γράφονται όλα τα κλιμακωμένα δείγματα.
- `track`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte του κομματιού, με `n` προσημασμένα δείγματα 16 bit.
- `gains`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte των συντελεστών ενίσχυσης, με `n` προσημασμένες τιμές 16 bit, καθεμία στο εύρος `0` έως `32767`.
- `n`: ο αριθμός των δειγμάτων, που δεν είναι ποτέ μηδέν και είναι πάντα πολλαπλάσιο του `8`, ως ανυπόγραφος ακέραιος 64 bit.

Σημείωσε ότι το κομμάτι είναι ένας πίνακας που περιέχει `n` προσημασμένα δείγματα 16 bit, όπου το `n` δεν είναι ποτέ μηδέν και είναι πάντα πολλαπλάσιο του `8`.
Για κάθε δείγμα, το κλιμακωμένο αποτέλεσμα είναι τα _υψηλά_ 16 bit του προσημασμένου γινομένου: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Το να κρατάς το υψηλό μισό στρογγυλοποιεί προς το αρνητικό άπειρο.
Γι' αυτό το `20000 * 32767` κλιμακώνεται σε `9999`, ενώ το `-20000 * 32767` κλιμακώνεται σε `-10000` αντί για `-9999`.
~~~~

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 5. Εξασθένησε ένα κομμάτι

Ο ντράμερ ηχογραφήθηκε πολύ πιο δυνατά απ' ό,τι έπρεπε.
Για να χαμηλώσεις όλο το κομμάτι, διαιρείς κάθε δείγμα με μια σταθερά.

Υλοποίησε τη συνάρτηση `attenuate_track`.
Αυτή η συνάρτηση παίρνει ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte όπου γράφονται τα αποτελέσματα, ως προσημασμένοι ακέραιοι 32 bit.
- `samples`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte των δειγμάτων, `n` προσημασμένες τιμές 16 bit.
- `divisor`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte με 4 πανομοιότυπα αντίγραφα του διαιρέτη, ως ακέραιοι 32 bit.
- `n` είναι ο αριθμός των δειγμάτων, που δεν είναι ποτέ μηδέν και είναι πάντα πολλαπλάσιο του `4`, ως ανυπόγραφος ακέραιος 64 bit.

Σημείωσε ότι το `samples` είναι ένας πίνακας που περιέχει `n` προσημασμένα δείγματα 16 bit, όπου το `n` δεν είναι ποτέ μηδέν και είναι πάντα πολλαπλάσιο του `4`.

Ο διαιρέτης παρέχεται ως `4` αντίγραφα του ίδιου ακέραιου 32 bit, ήδη αντιγραμμένα ώστε να γεμίζουν και τις τέσσερις λωρίδες ταυτόχρονα.

Το ακέραιο SIMD δεν έχει συσκευασμένη διαίρεση, οπότε η δουλειά γίνεται σε συσκευασμένη κινητή υποδιαστολή και μετά μετατρέπεται πίσω σε συσκευασμένους ακέραιους 32 bit για να αποθηκευτεί στο `result`.
Μετέτρεψε πίσω με αποκοπή προς το μηδέν, ώστε ένα πηλίκο `2.3` να γίνει `2` και το `-2.3` να γίνει `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.
