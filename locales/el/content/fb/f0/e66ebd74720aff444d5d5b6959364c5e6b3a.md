# Προσθήκη στις οδηγίες

## Υποδείξεις

Αυτή η άσκηση δουλεύει με δεδομένα κειμένου. Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με τον `[Char]`, μια λίστα από χαρακτήρες. Για πιο αποδοτικό χειρισμό δεδομένων κειμένου, μπορεί να χρησιμοποιηθεί ο τύπος `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να

- Διαβάσεις για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στην Haskell.
- Προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- Κάνεις εισαγωγή του `Data.Text` με [τον παρακάτω τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

        import qualified Data.Text as T
        import           Data.Text (Text)

- Μπορείς τώρα να γράψεις π.χ. `transform :: Map Int Text -> Map Char Int` και να αναφερθείς στους συνδυαστές του `Data.Text` ως π.χ. `T.toLower`.
- Να ψάξεις την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Αυτό το μέρος είναι εντελώς προαιρετικό.
