# Σχετικά

Το φιλτράρισμα είναι η διαδικασία δημιουργίας μιας ακολουθίας από μια άλλη ακολουθία, αντιγράφοντας όλα τα στοιχεία της αρχικής εκτός από ορισμένα.
Η επιλογή τού ποια στοιχεία θα συμπεριληφθούν στη νέα ακολουθία μπορεί να γίνει με μια συνάρτηση κατηγόρημα (μια συνάρτηση που αξιολογείται σε μια τιμή boolean) ή με έλεγχο ισότητας με ένα συγκεκριμένο αντικείμενο.

## Αφαίρεση με κατηγόρημα

Η `remove-if` είναι μια συνάρτηση που δέχεται ως ορίσματα μια συνάρτηση κατηγόρημα και μια ακολουθία και επιστρέφει μια ακολουθία με μόνο εκείνα τα στοιχεία για τα οποία το κατηγόρημα αξιολογήθηκε σε ψευδή τιμή.
Με άλλα λόγια, "αφαιρεί" όλα τα στοιχεία της ακολουθίας για τα οποία το κατηγόρημα αξιολογείται σε αληθή τιμή. Ωστόσο, πρόσεξε ότι αυτή η συνάρτηση δεν τροποποιεί την αρχική ακολουθία!
Αντ' αυτού, επιστρέφει μια νέα ακολουθία χωρίς τα αντίστοιχα στοιχεία. Αν το κατηγόρημα ήταν αληθές για όλες τις τιμές, τότε επιστρέφεται μια κενή ακολουθία.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Διατήρηση στοιχείων με κατηγόρημα

Υπάρχει μια συνάρτηση, η `remove-if-not`, που είναι ακριβώς σαν την `remove-if`, μόνο που *διατηρεί* το στοιχείο για το οποίο το κατηγόρημα αξιολογείται σε αληθή τιμή.

Εναλλακτικά, μπορείς να χρησιμοποιήσεις τη `complement` για να μετατρέψεις ένα κατηγόρημα στο "αντίθετό" του.

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## Αφαίρεση συγκεκριμένου στοιχείου

Αν θέλεις να αφαιρέσεις ένα συγκεκριμένο στοιχείο από μια ακολουθία, μπορείς να χρησιμοποιήσεις τη `remove`, η οποία δέχεται το στοιχείο προς αφαίρεση και μια ακολουθία.
Επιστρέφονται όλες οι τιμές της ακολουθίας που δεν είναι ίσες με το στοιχείο προς αφαίρεση.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

Η συνάρτηση που θα χρησιμοποιηθεί για τον έλεγχο ισότητας μπορεί να οριστεί με την [παράμετρο λέξη-κλειδί][concept-keyword-parameters] `:test`.

Πρόσεξε ότι η `remove` θα μπορούσε να υλοποιηθεί με τη `remove-if`, γράφοντας ένα κατηγόρημα που ελέγχει την ισότητας ενός αντικειμένου με ένα συγκεκριμένο στοιχείο.

## Πολλές επιλογές

Κάθε μία από αυτές τις συναρτήσεις δέχεται επίσης πολλές άλλες [παραμέτρους λέξεις-κλειδιά][concept-keyword-parameters], που της επιτρέπουν να λειτουργεί μόνο σε υποακολουθίες, να εφαρμόζεται μόνο έναν ορισμένο αριθμό φορών και άλλα. Δες την [τεκμηρίωση του Hyperspec][hyperspec-remove] για όλες τις λεπτομέρειες.


## Καταστροφικές επιλογές

Εκτός από τις `remove`, `remove-if` και `remove-if-not`, υπάρχουν οι `delete`, `delete-if` και `delete-if-not`, που έχουν το ίδιο αποτέλεσμα, μόνο που μπορεί να τροποποιήσουν την ακολουθία που τους περνάς.
