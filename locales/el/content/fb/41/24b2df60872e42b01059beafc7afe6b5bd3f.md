# Εισαγωγή

Όπως ακριβώς μπορείς να δημιουργήσεις έναν δείκτη προς ένα `int` ή προς οποιονδήποτε άλλο βασικό τύπο δεδομένων, μπορείς να δημιουργήσεις και έναν δείκτη προς μια συνάρτηση.
Ένας δείκτης σε συνάρτηση μπορεί να χρησιμοποιηθεί για να περάσεις μια συνάρτηση σε μια άλλη συνάρτηση.
Μια συνάρτηση που περνιέται ως τιμή παραμέτρου σε μια άλλη συνάρτηση ονομάζεται συνάρτηση πρώτης τάξης.
Μια συνάρτηση που δέχεται μία ή περισσότερες συναρτήσεις ως παράμετρο, ή που επιστρέφει μια συνάρτηση, ονομάζεται συνάρτηση ανώτερης τάξης.

Στο παρακάτω παράδειγμα, οι `is_even` και `is_odd` είναι συναρτήσεις πρώτης τάξης.
Η συνάρτηση ανώτερης τάξης είναι η `test_number`.

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
Η υπογραφή της συνάρτησης `bool (*func) (int)` για το πρώτο όρισμα της `test_number` ταιριάζει με την υπογραφή των συναρτήσεων που περνιούνται.
Τόσο η `is_even` όσο και η `is_odd` δέχονται μια παράμετρο `int` και επιστρέφουν `bool`.
Στο `(*func)`, το `func` αντιπροσωπεύει το όνομα της συνάρτησης που θα χρησιμοποιηθεί.
Αν χρησιμοποιούνταν το `(*fn)`, τότε θα καλούνταν ως εξής: `printf(text, number, fn(number)? "true": "false");`.
Για να ικανοποιήσουμε την παράμετρο του δείκτη σε συνάρτηση, όταν καλούμε την `test_number` περνάμε το όνομα μιας συνάρτησης που έχει την αναμενόμενη υπογραφή.
Έτσι, βλέπουμε ότι το όνομα μιας συνάρτησης δείχνει στη διεύθυνση αυτής της συνάρτησης.
