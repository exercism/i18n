# περιττές συνθήκες

Οι [συνθήκες][conditionals] χρησιμοποιούνται περιττά σε αυτή τη λύση.
Η χρήση ενός [προεπιλεγμένου ορίσματος][default argument] σε συνδυασμό είτε με [str.format][str.format] είτε με [f-strings][f-strings] (_γνωστά και ως "συμβολοσειρές με μορφοποίηση" ή "συμβολοσειρές με παρεμβολή"_) μπορεί να κάνει τον κώδικα πιο καθαρό και λιγότερο φλύαρο.

Για περισσότερες λεπτομέρειες, δες αυτή τη δημοσίευση για [προεπιλεγμένα ορίσματα στην Python][python default arguments].
Η ανάρτηση ιστολογίου [μορφοποίηση συμβολοσειρών στην Python][string formatting in python] μπορεί επίσης να αποτελέσει ένα καλό σημείο εκκίνησης για να μάθεις τις επιλογές μορφοποίησης συμβολοσειρών της Python.
