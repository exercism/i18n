# Σχετικά

Η εντολή `guard` στη Swift χρησιμοποιείται για πρώιμες επιστροφές από συναρτήσεις της Swift, όταν δεν πληρούται μια απαραίτητη συνθήκη, η οποία πρέπει να ικανοποιείται για να συνεχιστεί η επεξεργασία, π.χ.:

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

Εδώ, το `guard` ελέγχει αν η έκφραση Boolean που ακολουθεί τη λέξη-κλειδί `guard` αξιολογείται ως αληθής. Αν ναι, τότε η επεξεργασία συνεχίζεται με τον κώδικα που ακολουθεί την εντολή `guard` (εδώ `let root = myValue.squareRoot()`. Διαφορετικά, θα εκτελεστεί ο κώδικας της ρήτρας else. Σε αντίθεση με μια εντολή `if`, μια εντολή `guard` _πρέπει_ να έχει ρήτρα else, και σε αντίθεση με τη ρήτρα else μιας if-else, η ρήτρα else ενός guard _πρέπει_ να εξέρχεται από το πεδίο εμβέλειας της εντολής guard. Δηλαδή πρέπει να χρησιμοποιεί μια εντολή μεταφοράς ελέγχου, όπως `return`, `continue` ή `break`, ή πρέπει να πετάει ένα σφάλμα ή να τερματίζει το πρόγραμμα.

Ένα παράδειγμα χρήσης του είναι η συνάρτηση sinc, η οποία ισούται με sin(x)/x, με το sinc(0) να ορίζεται ως 1, αποφεύγοντας έτσι τα προβλήματα της διαίρεσης με το μηδέν. Αυτή η συνάρτηση μπορεί να γραφτεί σε Swift, χρησιμοποιώντας ένα `guard` ως εξής:

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
