# Οδηγίες

Έχεις ξαφνικά μια λιγούρα για τηγανίτες.
Ως σύγχρονος άνθρωπος με τεχνικές κλίσεις, γράφεις μια λίστα αγορών για τα υλικά των τηγανιτών σε μορφή JSON.
Η δομή της λίστας είναι:

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

Ένα υλικό αναπαρίσταται ως αντικείμενο JSON, όπως:

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

Ένα υλικό έχει μια προαιρετική ιδιότητα με όνομα `"substitute"` που περιέχει μια
συμβολοσειρά με ένα άλλο υλικό που μπορεί να χρησιμοποιηθεί στη θέση του.

Ας δούμε πώς μπορούμε να εξετάσουμε τη λίστα αγορών με το `jq`

## 1. Εξήγαγε το όνομα της λίστας αγορών

Γράψε μια έκφραση που να βγάζει το στοιχείο "name" της λίστας αγορών.

## 2. Μέτρησε πόσα υλικά χρειάζονται

Μέτρησε μόνο τα υποχρεωτικά υλικά. Μη συμπεριλάβεις τα προαιρετικά υλικά.

## 3. Πόση ζάχαρη;

Γράψε μια έκφραση που να βγάζει την ποσότητα ζάχαρης.
Θέλουμε μόνο το αριθμητικό μέρος.

## 4. Αντιστοίχισε τα υλικά που μπορούν να αντικατασταθούν

Μερικά από τα υλικά μπορούν να αντικατασταθούν (αν δεν έχεις το υλικό X, μπορείς να χρησιμοποιήσεις το Y).
Βγάλε ένα αντικείμενο JSON που αντιστοιχίζει το συνιστώμενο υλικό με το υποκατάστατό του.
Συμπεριλάβε τα προαιρετικά υλικά στην αντιστοίχιση.
