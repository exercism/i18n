# Σχετικά

Η Kotlin σχεδιάστηκε και αναπτύχθηκε από την JetBrains, την εταιρεία πίσω από το IntelliJ.
Είναι μια γλώσσα που εκτελείται στη JVM και μπορεί να στοχεύσει εκδόσεις 6+ (συμπεριλαμβανομένης της [πλατφόρμας Android](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)).
Η JetBrains ήθελε να χρησιμοποιήσει μια γλώσσα με στατική τυποποίηση που να μπορεί να αφαιρεί τον επαναλαμβανόμενο κώδικα της Java, να προσφέρει σύγχρονα συναρτησιακά παραδείγματα και να έχει απρόσκοπτη αμφίδρομη διαλειτουργικότητα με τη Java και την υπάρχουσα βάση κώδικα της.
Η JVM είχε ήδη εναλλακτικές γλώσσες όπως η Groovy και η Scala, αλλά καμία δεν ανταποκρινόταν στα κριτήρια που ήθελαν, οπότε έφτιαξαν την Kotlin.

Η σύνταξη της Kotlin είναι παρόμοια με της Scala και της Swift, αλλά αντλεί τα κορυφαία χαρακτηριστικά από άλλες γλώσσες, όπως η C# και η Groovy.
Η Kotlin υιοθέτησε μια πραγματιστική προσέγγιση ως προς τα χαρακτηριστικά που συμπεριέλαβε στη γλώσσα, παρέχοντας μόνο λειτουργικότητα που έχει αποδειχθεί χρήσιμη για τους προγραμματιστές.
Με αυτή την απόφαση υλοποίησαν ένα υποσύνολο χαρακτηριστικών της Scala, με την πρόθεση να παρέχει πιο συντηρήσιμο κώδικα και ευκολότερη καμπύλη μάθησης για προγραμματιστές που αναζητούν μια "καλύτερη Java".

Η JetBrains έχει μια αφοσιωμένη ομάδα προγραμματιστών που εργάζεται στην Kotlin, με τη βάση κώδικα διαθέσιμη στο [Github](https://github.com/JetBrains/kotlin).
