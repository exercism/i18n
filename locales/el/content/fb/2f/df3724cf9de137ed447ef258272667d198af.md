Η δημόσια διεπαφή μιας βάσης κώδικα χρειάζεται προσεκτικό σχεδιασμό, καθώς κάθε δημόσια συνάρτηση αυξάνει το μακροπρόθεσμο κόστος συντήρησης και κάνει την αναδιαμόρφωση πιο δύσκολη.

Σε κάθε άσκηση του Exercism, η δημόσια διεπαφή ορίζεται από το σύνολο των δοκιμών.
Αν μια συνάρτηση ελέγχεται από τις δοκιμές, πρέπει να είναι δημόσια.
Όλες οι άλλες συναρτήσεις πρέπει να είναι ιδιωτικές, συμπεριλαμβανομένων των συναρτήσεων με το ίδιο όνομα αλλά διαφορετικό αριθμό ορισμάτων.

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
Σημείωσε ότι τα προεπιλεγμένα ορίσματα αλλάζουν τον αριθμό ορισμάτων μιας συνάρτησης.

Όταν γράφεις μια βιβλιοθήκη, συχνά χρειάζεται να κάνεις συναρτήσεις δημόσιες για χρήση ανάμεσα σε module.
Για να κρύψουν τέτοιες συναρτήσεις από την τεκμηρίωση, οι δημιουργοί βιβλιοθηκών προσθέτουν `@doc false` πριν από τους ορισμούς των συναρτήσεων ή `@moduledoc false` για να κρύψουν ολόκληρο το module.
