# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που περνάει η λαζάνια στο μαγείρεμα.

## 1. Όρισε τον αναμενόμενο χρόνο στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `expected_minutes_in_oven` που δε δέχεται κανένα όρισμα και επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στον φούρνο σε λεπτά είναι 40:

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. Υπολόγισε τον χρόνο που απομένει στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `remaining_minutes_in_oven` που δέχεται ως όρισμα τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο σε λεπτά της προηγούμενης εργασίας.

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparation_time_in_minutes` που δέχεται ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη συνάρτηση `total_time_in_minutes` που δέχεται δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει συνολικά για το μαγείρεμα της λαζάνιας, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου που έχει περάσει η λαζάνια στον φούρνο μέχρι στιγμής.

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

Όρισε τη συνάρτηση `alarm` που δε δέχεται κανένα όρισμα και επιστρέφει ένα μήνυμα που δηλώνει ότι η λαζάνια είναι έτοιμη να τη φας.

```gleam
alarm()
// -> "Ding!"
```
