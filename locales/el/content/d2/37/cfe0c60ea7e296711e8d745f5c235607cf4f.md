# Αγνόησε

## Οδηγίες ειδικά για τη jq

Υπάρχει μια ενσωματωμένη συνάρτηση [`flatten`][flatten] που λύνει σε μεγάλο βαθμό αυτή την άσκηση.
Δοκίμασε να τη λύσεις μόνος σου χωρίς να χρησιμοποιήσεις την ενσωματωμένη συνάρτηση `flatten`, για να πάρεις το μέγιστο από αυτή την άσκηση.

<details><summary>Κάνε κλικ εδώ για υποδείξεις:</summary>

- Μια αναδρομική συνάρτηση μπορεί να φανεί χρήσιμη.
  Μάθε περισσότερα για την αναδρομή στην [ενότητα Αναδρομή][recur].
- Η συνάρτηση [`type`][type] μπορεί να βοηθήσει.
</details>

[flatten]: https://jqlang.org/manual/#flatten
[type]: https://jqlang.org/manual/#type
[recur]: https://exercism.org/tracks/jq/concepts/recursion
