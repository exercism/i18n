# Εισαγωγή

## Ενότητες

Ο κώδικας Gleam οργανώνεται σε ενότητες, και κάθε αρχείο είναι μία ενότητα Gleam.

Μέχρι τώρα έχουμε γράψει συναρτήσεις με τη σύνταξη `pub fn`, η οποία ορίζει μια συνάρτηση που είναι δημόσια διαθέσιμη σε άλλες ενότητες. Οι συναρτήσεις που ορίζονται με `fn` είναι ιδιωτικές για την ενότητα στην οποία ορίζονται και δεν μπορούν να χρησιμοποιηθούν από άλλες ενότητες.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Οι ενότητες Gleam έχουν ονόματα, και το όνομα βασίζεται στη διαδρομή του αρχείου μέσα στον κατάλογο `src` ή `test`.

Για παράδειγμα, μια ενότητα που ορίζεται στο `src\geometry\rectangle.gleam` (στα Windows) ή στο `src/geometry/rectangle.gleam` (σε λειτουργικά συστήματα τύπου UNIX) θα ονομαζόταν `geometry/rectangle`.

## Εισαγωγή συναρτήσεων από άλλες ενότητες

Η πρόσβαση σε συναρτήσεις που ορίζονται σε άλλες ενότητες γίνεται μέσω εισαγωγών.
Όλες οι συναρτήσεις μέσα σε αυτή την ενότητα που εκτίθενται από αυτή γίνονται προσβάσιμες όταν εισάγεις αυτή την ενότητα.
Αλλά το πώς προσπελαύνονται ποικίλλει ανάλογα με το πώς εισάγεται η ενότητα.

Οι εισαγωγές με πρόθεμα είναι οι προεπιλεγμένες, και η πρόσβαση σε μια συνάρτηση μέσα σε μια τέτοια ενότητα (για παράδειγμα τη συνάρτηση `map` στην ενότητα `gleam/list`) γίνεται βάζοντας ως πρόθεμα το όνομα της ενότητας (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Από προεπιλογή, το όνομα που χρησιμοποιείται για να αναφέρεσαι στην ενότητα είναι το τελευταίο μέρος του ονόματος της ενότητας, στην περίπτωση αυτή `int`, αλλά αυτό μπορεί να αλλάξει χρησιμοποιώντας τη λέξη-κλειδί `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Οι εισαγωγές χωρίς πρόθεμα επιτρέπουν άμεση πρόσβαση στις εκτεθειμένες συναρτήσεις μέσα σε αυτή την ενότητα, χωρίς πρόθεμα.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Οι εισαγωγές με πρόθεμα προτιμώνται καθώς κάνουν πιο σαφές στον αναγνώστη από πού προέρχεται μια συνάρτηση, και για την αποφυγή συγκρούσεων ονομάτων.


## Πρότυπη βιβλιοθήκη

Η Gleam έχει μια πλούσια και καλά τεκμηριωμένη πρότυπη βιβλιοθήκη. Η τεκμηρίωση είναι διαθέσιμη στο διαδίκτυο στη διεύθυνση [hexdocs.pm/gleam_stdlib][docs]. Αποθήκευσε αυτόν τον σύνδεσμο κάπου, θα τον χρησιμοποιήσεις πολύ!

Οι περισσότεροι ενσωματωμένοι τύποι δεδομένων έχουν μια αντίστοιχη ενότητα που προσφέρει συναρτήσεις για εργασία με αυτόν τον τύπο δεδομένων, π.χ. υπάρχει η ενότητα `gleam/int` για ακέραιους, η ενότητα `gleam/string` για συμβολοσειρές, η ενότητα `gleam/list` για λίστες και ούτω καθεξής.

[docs]: https://hexdocs.pm/gleam_stdlib/
