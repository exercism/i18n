# Τριαδικός τελεστής

Ο τριαδικός τελεστής προσφέρει μια εναλλακτική σύνταξη για να εκτελέσεις μια σύγκριση `if..else..` και να επιστρέψεις μια τιμή.

## Σύνταξη

Η PHP διαθέτει μια εντολή `if`, όπου μια ενέργεια μπορεί να προσδιοριστεί με βάση την "αληθότητα" μιας συνθήκης.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Εναλλακτικά, ο τριαδικός τελεστής μπορεί να αναπαραστήσει την ίδια λειτουργία:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Η σύνταξη της σύγκρισης είναι σύντομη και παριστάνεται ως `(condition) ? (evaluate if true) : (evaluate if false);`.

## Πλεονεκτήματα

Το προφανές πλεονέκτημα του τριαδικού τελεστή είναι η συντομία: η έκφραση με συνθήκη γράφεται πιο σύντομα από μια εντολή `if..else..`. Υπάρχουν όμως και αρκετά άλλα:

- Είναι μια έκφραση που μπορεί να χρησιμοποιηθεί μέσα σε μια άλλη έκφραση.
- Διευκολύνει την τεμπέλη αξιολόγηση κάθε κλάδου.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  Σε αυτό το παράδειγμα, αν δεν απαιτείται η ακριβής απάντηση, ο δαπανηρός υπολογισμός δεν καλείται.

## Μειονεκτήματα

Οι τριαδικοί τελεστές έχουν αρκετά μειονεκτήματα, γι' αυτό αξίζει να σκεφτείς προσεκτικά τη χρήση τους:

- Ένας τριαδικός τελεστής μπορεί να είναι πιο δύσκολος στην ανάγνωση, αφού βασίζεται στην ερμηνεία συμβόλων και όχι στη χρήση λέξεων-κλειδιών.
- Ένας τριαδικός τελεστής μπορεί άθελά σου να οδηγήσει σε bugs, επειδή ο τριαδικός τελεστής στην PHP είναι αριστερά προσεταιριστικός, σε αντίθεση με τις περισσότερες σύγχρονες γλώσσες (π.χ. C, Java, JavaScript).
- Η έκφραση που αξιολογείται στους δύο κλάδους, τον αληθή και τον ψευδή, πρέπει να επιστρέφει μια τιμή.

## Ακόμα πιο σύντομη

Η σύνταξη του τριαδικού τελεστή μπορεί να συντομευτεί ακόμα περισσότερο σε `(condition) ?: (evaluate if falsey)`.
Μια τέτοια χρήση είναι, για παράδειγμα, να δίνεις μια εφεδρική τιμή μέσα σε μια έκφραση:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Αυτό είναι γνωστό και ως _τελεστής Elvis_ (`?:`)
