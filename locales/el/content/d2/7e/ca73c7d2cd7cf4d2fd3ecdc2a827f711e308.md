# Υπολογιστής Κουζίνας

## Ιστορία

Η ιστορία διευκολύνει την εξερεύνηση των [πλειάδων][type-tuple] σε μια γλώσσα.

Η βασική υπόθεση είναι ότι συχνά τα υλικά της κουζίνας μετριούνται με ασαφείς τρόπους και απαιτούν διαφορετική μετατροπή ανάλογα με τις ποσότητες ή τα διαθέσιμα εργαλεία. Οι πλειάδες χρησιμοποιούνται για να παρέχουν [duck typing][concept-duck-typing] στο αριθμητικό μέρος της μέτρησης.

Έτσι, εξερευνάται η βασική μετατροπή τιμών με χρήση αριθμών κινητής υποδιαστολής.

### Μετατροπές

| Από                    | Προς    |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 φλιτζάνι         | 240mL   |
| 1 ουγγιά υγρού (ΗΠΑ) | 29.57mL |
| 1 κουταλάκι του γλυκού | 5 mL  |
| 1 κουταλιά της σούπας | 15 mL  |

## Εργασίες

Αυτό θα πρέπει να καθοδηγεί τους μαθητές στο πώς να χρησιμοποιούν:

- Πλειάδες
- Πλειάδες ως ομαδοποιημένες πληροφορίες
- Λήψη τιμών από μια πλειάδα με χρήση της θέσης του στοιχείου
- Λήψη τιμών από μια πλειάδα με αντιστοίχιση προτύπων
- Δημιουργία νέων πλειάδων
