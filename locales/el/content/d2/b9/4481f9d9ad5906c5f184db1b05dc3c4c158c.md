# Εισαγωγή

Η γιαγιά σου έχει αρχίσει πρόσφατα να ενδιαφέρεται έντονα για τη λύση δυαδικών παζλ.
Αν και γίνεται ολοένα και καλύτερη, κολλάει αρκετά συχνά.
Όντας το εξυπηρετικό εγγόνι που είσαι, αποφασίζεις να φτιάξεις μια μικρή εφαρμογή που μπορεί να λύσει οποιοδήποτε δυαδικό παζλ.
Έτσι θα μπορείς να δίνεις στη γιαγιά σου υποδείξεις για την επόμενη κίνησή της.
