# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Τα κυριολεκτικά [συμβολοσειράς][string] είναι μια ακολουθία χαρακτήρων που περικλείεται σε διπλά εισαγωγικά.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς ορίσματα.
- Πρέπει να επιστρέψεις έναν [ακέραιο][integers].

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με ένα όρισμα.
- Πρέπει να επιστρέψεις μια τιμή από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή αφαίρεσης][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με ένα όρισμα.
- Πρέπει να επιστρέψεις μια τιμή από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή πολλαπλασιασμού][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο ορίσματα.
- Πρέπει να επιστρέψεις έναν ακέραιο από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να καλέσεις μια από τις άλλες συναρτήσεις που όρισες προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή πρόσθεσης][operators] για να προσθέσεις τιμές.

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς ορίσματα.
- Πρέπει να επιστρέψεις μια [συμβολοσειρά][string].
