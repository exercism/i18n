# Υποδείξεις

## Γενικά

- Η σύνταξη για τον ορισμό ενός closure είναι `{ (parameter list) -> ReturnType in bodyOfClosure }`

## 1. Γράψε ένα closure για να αντιστρέψεις δύο καλώδια

- Μπορείς να χρησιμοποιήσεις την αποδόμηση πλειάδας για να ονομάσεις τα επιμέρους στοιχεία μιας πλειάδας

## 2. Γράψε ένα closure για να περιστρέψεις τα καλώδια

- Μπορείς να χρησιμοποιήσεις την αποδόμηση πλειάδας για να ονομάσεις τα επιμέρους στοιχεία μιας πλειάδας
