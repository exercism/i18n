# Σχετικά

Στη Gleam οι συναρτήσεις είναι πρώτης τάξης, που σημαίνει ότι οι συναρτήσεις είναι κανονικές τιμές που μπορούν να ανατεθούν σε μεταβλητές, να περαστούν ως ορίσματα και να επιστραφούν από άλλες συναρτήσεις.

Μια επώνυμη συνάρτηση που ορίζεται σε ένα άρθρωμα μπορεί να αναφερθεί με το όνομά της.

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Η Gleam έχει επίσης ανώνυμες συναρτήσεις, οι οποίες ορίζονται μέσα σε άλλες συναρτήσεις.

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

Ο τύπος μιας συνάρτησης γράφεται με σύνταξη παρόμοια με αυτή των ανώνυμων συναρτήσεων. Ο τύπος μιας συνάρτησης που παίρνει ένα `Int` και ένα `Float` και επιστρέφει ένα `Int` γράφεται ως εξής:

```gleam
fn(Int, Float) -> Int
```

Οι ανώνυμες συναρτήσεις μπορούν να αναφέρονται σε μεταβλητές που βρίσκονταν στο πεδίο εμβέλειας όταν ορίστηκαν, κάτι που τις κάνει _closures_.

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

Η σύνταξη _σύλληψης συνάρτησης_ προσφέρει έναν βολικό συντομευμένο τρόπο για τη δημιουργία ανώνυμων συναρτήσεων που περνούν ένα μόνο όρισμα σε μια συνάρτηση. Αυτές οι δύο εκφράσεις είναι ισοδύναμες:

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
