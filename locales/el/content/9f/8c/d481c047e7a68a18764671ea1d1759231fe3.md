# Οδηγίες

Συνεχίζοντας τη δουλειά σου στο λούνα παρκ, καλείσαι να γράψεις μερικές βοηθητικές μεθόδους που θα διευκολύνουν τον έλεγχο του κατά πόσο ένας επισκέπτης μπορεί να χρησιμοποιήσει ένα παιχνίδι.

## 1. Έλεγξε αν ένας επισκέπτης έχει πάσο παιχνιδιών

Υλοποίησε τη μέθοδο `Attendee#has_pass?` ώστε να επιστρέφει μια τιμή boolean (`true`/`false`) με βάση την ύπαρξη πάσου παιχνιδιών.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Έλεγξε αν ένας επισκέπτης χωράει σε ένα παιχνίδι

Υλοποίησε τη μέθοδο `Attendee#fits_ride?` για να δεις αν ένας επισκέπτης χωράει σε ένα παιχνίδι με βάση το ύψος του.
Το ελάχιστο απαιτούμενο ύψος του παιχνιδιού δίνεται ως όρισμα.
Ένας επισκέπτης πρέπει να έχει ύψος μεγαλύτερο ή ίσο με το ελάχιστο απαιτούμενο ύψος του παιχνιδιού.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Έλεγξε αν ένας επισκέπτης επιτρέπεται να ανέβει σε ένα παιχνίδι

Υλοποίησε τη μέθοδο `Attendee#allowed_to_ride?` για να δεις αν ένας επισκέπτης επιτρέπεται να ανέβει σε ένα παιχνίδι. Το ελάχιστο απαιτούμενο ύψος του παιχνιδιού δίνεται ως όρισμα. Ένας επισκέπτης πρέπει να έχει πάσο παιχνιδιών και να χωράει στο παιχνίδι.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
