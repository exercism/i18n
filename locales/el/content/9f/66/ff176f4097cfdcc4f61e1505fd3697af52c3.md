# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες, καθεμία από τις οποίες θα παίρνει μια γραμμή καταγραφής και θα σου ζητάει να κάνεις κάτι με αυτήν.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLevels.message()` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Τυχόν κενά στην αρχή ή στο τέλος πρέπει να αφαιρούνται:

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLevels.logLevel()` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο πρέπει να επιστρέφεται με πεζά γράμματα:

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Αναμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLevels.reformat()` που αναμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής μέσα σε παρενθέσεις:

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
