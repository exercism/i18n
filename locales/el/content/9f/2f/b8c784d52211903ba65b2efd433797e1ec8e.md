# Εισαγωγή

Το I/O στη Factor είναι χτισμένο πάνω σε *ροές*: αντικείμενα από τα οποία
διαβάζεις byte ή χαρακτήρες, ή στα οποία τους γράφεις. Το λεξιλόγιο
[`io`][io] σου δίνει δύο όψεις του ίδιου [πρωτοκόλλου][stream-protocol].

## Οι δύο όψεις

Οι λέξεις **ρητής ροής** παίρνουν τη ροή ως όρισμα. Όλες αρχίζουν με
`stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Οι λέξεις **περιβάλλουσας ροής** διαβάζουν από όποια ροή είναι *δεσμευμένη
αυτή τη στιγμή* ή γράφουν σε αυτήν, δηλαδή τη δυναμική μεταβλητή
`input-stream` ή `output-stream` που ισχύει σε όλο το πρόγραμμα. Έχουν
σύντομα ονόματα:

```
read1 read readln write write1 print flush
```

Την περιβάλλουσα μορφή χρησιμοποιεί ο περισσότερος καθημερινός κώδικας.
Στη ρητή μορφή καταφεύγεις όταν έχεις στα χέρια σου μια συγκεκριμένη ροή
και δεν θέλεις να αλλάξεις την περιβάλλουσα.

## Ροές στη μνήμη

Στην άσκηση θα δουλέψεις με ροές που στηρίζονται σε συμβολοσειρές, από το
[`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Ένα `<string-reader>` διαβάζει από μια κυριολεκτική συμβολοσειρά σαν να
ήταν αρχείο, ενώ ένα `<string-writer>` συγκεντρώνει ό,τι γράφεται σε αυτό,
ώστε να μπορείς να το διαβάσεις ξανά αργότερα. Και τα δύο υλοποιούν το
ίδιο πρωτόκολλο με τις ροές αρχείων, οπότε όσα μαθαίνεις εδώ ισχύουν
απευθείας και για τα `<file-reader>` / `<file-writer>`.

## Εμβέλεια με `with-…`

Για να δεσμεύσεις μια ρητή ροή ως την περιβάλλουσα για ένα quotation και
να την αποδεσμεύσεις μετά, χρησιμοποίησε ένα combinator `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

Το [`with-string-writer`][with-string-writer] είναι η βολική μορφή για το
"μάζεψε ό,τι τυπώνει αυτό το quotation": φτιάχνει τον writer, εκτελεί το
quotation με αυτόν τον writer ως περιβάλλουσα έξοδο και επιστρέφει τη
συμβολοσειρά που συνέλεξε:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Όλοι οι combinators `with-…` είναι destructor combinators (η ίδια
οικογένεια με τα `with-disposal` και `with-destructors` του
[`boatswains-bilge`][boatswains-bilge]): η ροή αποδεσμεύεται στην έξοδο
ακόμα κι αν το quotation πετάξει ένα σφάλμα.
