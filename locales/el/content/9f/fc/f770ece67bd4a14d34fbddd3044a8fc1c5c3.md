# Σχετικά με τους χαρακτήρες

Αυτό είναι δυνητικά ένα _μεγάλο_ θέμα!
Μπορεί κανείς να γράψει ένα ολόκληρο βιβλίο γι' αυτό, και αρκετοί το έχουν κάνει (ψάξε στο Amazon για "unicode book" για να δεις μερικά παραδείγματα).

## Μια πολύ σύντομη ιστορία

Ο χειρισμός χαρακτήρων στους υπολογιστές ήταν πολύ πιο απλός τις προηγούμενες δεκαετίες, όταν οι προγραμματιστές θεωρούσαν ότι τα αγγλικά ήταν η μόνη σημαντική γλώσσα.
Δηλαδή: 26 γράμματα, κεφαλαία και πεζά, 10 ψηφία, μερικά σημεία στίξης, συν έναν κωδικό (0x07) για να χτυπάει ένα κουδουνάκι, και όλα χωρούσαν σε 7 bits: το σύνολο χαρακτήρων [ASCII][wiki-ascii].

Φυσικά, οι άνθρωποι άρχισαν να ρωτούν τι γίνεται με τα à, ä και Ł, μετά άλλοι άρχισαν να ρωτούν για τα ऄ, ஹ και ญ, και οι νέοι ήθελαν emojis 😱.
Τι να κάνουμε;

Για να μην τα πολυλογούμε, πολλοί έξυπνοι και υπομονετικοί άνθρωποι χρειάστηκε να συμμετάσχουν σε επιτροπές για χρόνια, δουλεύοντας τις λεπτομέρειες του συνόλου χαρακτήρων [Unicode][web-unicode] και κωδικοποιήσεων όπως το [UTF-8][wiki-utf-8], και πολλά προγράμματα χρειάστηκαν μια _πολύ_ περίπλοκη επανεγγραφή.
Επίσης, εισήχθησαν πολλά νέα bugs.

Για να μην καταρρεύσουν _τα πάντα_, ο σχεδιασμός των Unicode/UTF-8 διασφαλίζει ότι οι πρώτοι 127 κωδικοί είναι ίδιοι με το ASCII _(ακόμα και το κουδουνάκι)_.

## Χαρακτήρες στην Kotlin

Οι γλώσσες που σχεδιάστηκαν μετά το 2005 περίπου έχουν το τεράστιο πλεονέκτημα ότι υπήρχε ήδη ένα σχετικά σταθερό πρότυπο Unicode.

Η Kotlin (κυκλοφόρησε για πρώτη φορά το 2011) μπόρεσε να υποθέσει ότι οι χρήστες θα χρησιμοποιούν διάφορες (ανθρώπινες) γλώσσες και θα χρειάζονταν το Unicode για να τις εκφράσουν.

~~~~exercism/advanced
Οι [χαρακτήρες][ref-char] στην Kotlin είναι [`codepoints`][wiki-codepoint] 16 bit (UTF-16), ίδιοι με το `char` της JVM.
Αυτό αρκεί για να εκφραστούν τα περισσότερα γραπτά αλφάβητα, αλλά όχι ολόκληρο το φάσμα των emojis.

Το πλήρες πρότυπο Unicode χρησιμοποιεί έως έξι bytes (48 bits) ανά χαρακτήρα (που ονομάζεται [`grapheme`][wiki-grapheme]).

Οι `Strings` της Kotlin υποστηρίζουν αυτό το πλήρες πρότυπο χρησιμοποιώντας πολλαπλά codepoints ανά χαρακτήρα, όταν είναι απαραίτητο.
Για παράδειγμα, το 😱 θα ήταν `\uD83D` και `\uDE31`.

Δυστυχώς, η Java δεν έχει ενσωματωμένη υποστήριξη grapheme, και για λόγους συμβατότητας ούτε η Kotlin.

[wiki-codepoint]: https://en.wikipedia.org/wiki/Code_point
[wiki-grapheme]: https://en.wikipedia.org/wiki/Grapheme
[ref-char]: https://kotlinlang.org/docs/characters.html
~~~~


Τα κυριολεκτικά χαρακτήρων γράφονται με μονά εισαγωγικά και διαφέρουν από τις συμβολοσειρές που γράφονται με διπλά εισαγωγικά.
Αυτό είναι μάλλον προφανές για όσους προέρχονται από τον κόσμο της C/C++, αλλά μπορεί να μπερδέψει τους προγραμματιστές Python και JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code // => 65535 (64k, the largest code point allowed)

val not_char = 'abc' // => Too many characters in a character literal.
```

Η μετατροπή μεταξύ `Char` και `Int` είναι απλή:

```kotlin
a.code  // => 97
Char(97) // => 'a'
```

Ο μεταγλωττιστής επιτρέπει _μερικές_ μορφές ακέραιης αριθμητικής σε `Char`:

```kotlin
'a' + 5     // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Μερικές συναρτήσεις για `Char`

Όπως πάντα, υπάρχουν πάρα [πολλές συναρτήσεις][ref-char-lib] για να τις συζητήσουμε εδώ, οπότε αυτή είναι απλώς μια επιλογή.

- Για τα κατάλληλα αλφάβητα, άλλαξε πεζά/κεφαλαία με τις [`uppercase()`][ref-uppercase] και [`lowercase()`][ref-lowercase].
- Έλεγξε τα πεζά/κεφαλαία με τις [`isUpperCase()`][ref-isuppercase] και [`isLowerCase()`][ref-islowercase].
- Έλεγξε τον τύπο του χαρακτήρα με:
  - [`isLetter()`][ref-isletter], καλύπτει πολλά αλφάβητα (τις κατηγορίες Lu, Ll, Lt, Lm και Lo στο unicode)
  - [`isDigit()`][ref-isdigit], στο εύρος 0..9 (την κατηγορία Nd στο unicode)
  - `isLetterOrDigit()`, συνδυάζει τις δύο προηγούμενες
  - [`isWhitespace()`][ref-iswhitespace], οποιονδήποτε χαρακτήρα κενού (τις κατηγορίες Cc, Zp, Zl και Zs στο unicode)

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

Επίσης, οι [κανονικές εκφράσεις][ref-regex] (που θα είναι το αντικείμενο μιας επόμενης έννοιας) επιτρέπουν ισχυρή αναζήτηση και χειρισμό.

## Μετατροπές μεταξύ λίστας `Char` και `String`

Για να μετατρέψεις ένα `String` σε `List` από `Char`, μπορείς να χρησιμοποιήσεις το `toList()`.

Για να μετατρέψεις μια `List` από `Char` σε `String`, υπάρχει η συνάρτηση [`joinToString()`][ref-jointostring], που παίρνει ως όρισμα έναν διαχωριστικό (συχνά την κενή συμβολοσειρά).

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Σημείωσε ότι το `joinToString()` λειτουργεί σε List ή Array.
Για να _μετατρέψεις_ έναν μεμονωμένο `Char` σε συμβολοσειρά ενός χαρακτήρα, χρησιμοποίησε το `toString()`.

```kotlin
'a'.toString() // => "a"
```

Για να ελέγξεις αν ένας χαρακτήρας υπάρχει σε ένα `String`, ή σε μια λίστα ή πίνακα `Char`, έχουμε το `in`, που αντιστοιχεί στη συνάρτηση [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
