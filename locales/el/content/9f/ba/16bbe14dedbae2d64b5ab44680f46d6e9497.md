# Σχετικά

Η βιβλιοθήκη ακολουθιών της Factor βασίζεται σε μεγάλο βαθμό στα *quotations*, δηλαδή κώδικα μέσα σε `[ ]`, για να παραμετροποιεί την επανάληψη. Το σχήμα είναι πάντα το ίδιο: δίνεις μια ακολουθία και ένα quotation, και η λέξη ανώτερης τάξης εκτελεί το quotation σε κάθε στοιχείο.

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

Ο πλήρης κατάλογος των πιο συνηθισμένων:

| λέξη         | σχήμα                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

Όταν η *δική σου* λέξη προωθεί ένα quotation χρόνου εκτέλεσης σε έναν από αυτούς τους συνδυαστές, δήλωσε τη λέξη σου με `; inline`, ώστε η εξαγωγή εφέ του συνδυαστή να μπορεί να δει το σχήμα του quotation στο σημείο κλήσης. Οι λέξεις που φτιάχνονται μόνο από quotations που υπάρχουν αυτούσια στον κώδικα δεν το χρειάζονται.

Πέρα από τις βασικές λειτουργίες των ακολουθιών:

| λεξιλόγιο          | παρέχει                                       |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`, `sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`, `cum-product`, `cum-min`, `cum-max` |
| [`grouping`][grouping]         | `group`, `clump`, `monotonic-split`           |
| [`sets`][sets]             | `members`, `all-unique?`                      |

Τα ζεύγη (`bi`, `tri`) και οι συνδυαστές "n-ary" (`2map`, `2each`, `zip`) επεκτείνουν το ίδιο μοτίβο όταν το quotation χρειάζεται περισσότερες από μία εισόδους.
