# Δομές

Οι δομές είναι προσαρμοσμένοι τύποι δεδομένων που σου επιτρέπουν να ονομάσεις και να συσκευάσεις μαζί πολλαπλές σχετιζόμενες τιμές.
Μοιάζουν με τις πλειάδες, αλλά είναι πιο ευέλικτες και σου επιτρέπουν να ονομάσεις κάθε κομμάτι δεδομένων, κάνοντάς τον κώδικά σου πιο ξεκάθαρο.
Οι δομές στην Cairo έχουν αυτές τις ιδιότητες:

- Κάθε τύπος δομής έχει ένα συγκεκριμένο όνομα.
- Κάθε μέλος μιας δομής ονομάζεται **πεδίο**.
- Κάθε πεδίο μιας δομής έχει ένα συγκεκριμένο όνομα.
- Η ορατότητα παρακολουθείται σε επίπεδο πεδίου: κάθε πεδίο μπορεί να είναι ανεξάρτητα δημόσιο ή ιδιωτικό.

## Ορισμός και δημιουργία στιγμιοτύπων δομών

Για να ορίσεις μια δομή, χρησιμοποίησε τη λέξη-κλειδί `struct` ακολουθούμενη από ένα όνομα και άγκιστρα που περιέχουν τα πεδία με τα ονόματα και τους τύπους τους:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Για να δημιουργήσεις ένα στιγμιότυπο ενός `struct`, προσδιόρισε το όνομα του `struct` και χρησιμοποίησε άγκιστρα με ζεύγη κλειδιού-τιμής για τα πεδία.
Σημείωσε ότι μπορείς να παραθέσεις τα πεδία με οποιαδήποτε σειρά όταν δημιουργείς ένα στιγμιότυπο:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Αλληλεπίδραση με ένα στιγμιότυπο δομής

Χρησιμοποίησε τη σημειογραφία με τελεία για να προσπελάσεις ή να τροποποιήσεις τα πεδία ενός στιγμιότυπου `struct`.
Σημείωσε ότι για να τροποποιήσεις ένα πεδίο, το στιγμιότυπο πρέπει να είναι μεταβλητό:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Όπως με κάθε έκφραση, μπορούμε να κατασκευάσουμε ένα νέο στιγμιότυπο του `struct` ως την τελευταία έκφραση στο σώμα της συνάρτησης για να επιστρέψουμε σιωπηρά αυτό το νέο στιγμιότυπο:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Συντομογραφία αρχικοποίησης πεδίων

Στο τελευταίο παράδειγμα είχε νόημα να ονομάσεις τις παραμέτρους `email` και `username` της συνάρτησης με τα ίδια ονόματα όπως τα πεδία στο `struct`, αλλά το να πρέπει να τις επαναλαμβάνεις όταν τις αναθέτεις σε πεδία δομής είναι λίγο κουραστικό.
Ευτυχώς, υπάρχει μια βολική συντομογραφία για την αρχικοποίηση πεδίων δομής από μεταβλητές με τα ίδια ονόματα:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Δημιουργία στιγμιοτύπων από άλλα στιγμιότυπα με σύνταξη ενημέρωσης δομής

Χρησιμοποίησε τη σύνταξη ενημέρωσης δομής για να δημιουργήσεις ένα νέο στιγμιότυπο από ένα υπάρχον, αλλάζοντας μερικά από τα πεδία και κρατώντας τα υπόλοιπα ίδια.
Αυτό επιτυγχάνεται χρησιμοποιώντας τον τελεστή `..`.

Χωρίς σύνταξη ενημέρωσης:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Με σύνταξη ενημέρωσης:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

Η σύνταξη `..user1` αντιγράφει τα υπόλοιπα πεδία από το `user1` στο `user2`.
Σημείωσε ότι αυτό μετακινεί τα δεδομένα από το `user1` στο `user2`, οπότε το `user1` δεν μπορεί να χρησιμοποιηθεί στη συνέχεια αν περιέχει τύπους που δεν μπορούν να αντιγραφούν.
