# Σχετικά

Η κλάση Lambda είναι μια συλλογή συναρτησιακών μεθόδων, ώστε να μπορείς να χρησιμοποιείς προγραμματισμό συναρτησιακού στυλ στη Haxe. Σου επιτρέπει να δουλεύεις με ένα ολόκληρο Iterable ταυτόχρονα. Αυτό είναι συχνά προτιμότερο από ρουτίνες επανάληψης, αφού είναι λιγότερο επιρρεπές σε σφάλματα και πιο ευανάγνωστο. Για ευκολία, οι κλάσεις Array και List περιέχουν μερικές από τις πιο συχνά χρησιμοποιούμενες μεθόδους της κλάσης Lambda.

Μερικές από τις συναρτήσεις της κλάσης `Lambda` είναι:

- `Lambda.array`, `Lambda.list` Μετατρέπουν ένα Iterable σε Array ή List. Επιστρέφουν πάντα ένα νέο στιγμιότυπο.
- `Lambda.count` Μετράει τον αριθμό των στοιχείων. Αν το Iterable είναι Array ή List, είναι πιο γρήγορο να χρησιμοποιήσεις την ιδιότητα length.
- `Lambda.has` Ελέγχει αν το συγκεκριμένο στοιχείο υπάρχει στο Iterable.
- `Lambda.indexOf` Βρίσκει τη θέση του συγκεκριμένου στοιχείου.
- `Lambda.find` Βρίσκει το πρώτο στοιχείο που ταιριάζει με τη συνάρτηση αναζήτησης που δίνεις.
- `Lambda.concat` Συνενώνει δύο Iterable και επιστρέφει μια νέα List.
- `Lambda.filter` Βρίσκει τα στοιχεία που ικανοποιούν ένα κριτήριο και επιστρέφει μια νέα List.

Ένα παράδειγμα που δείχνει μερικές από τις συναρτήσεις:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
