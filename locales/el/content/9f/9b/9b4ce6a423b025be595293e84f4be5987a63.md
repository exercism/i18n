# Εισαγωγή

Οι ευρετηριαστές επιτρέπουν την ανάγνωση ή τον ορισμό των τιμών ενός αντικειμένου μέσω του τελεστή ευρετηριασμού: `[]`. Ένας ευρετηριαστής δέχεται ένα μόνο όρισμα και μπορεί να έχει και τμήμα `get` ή/και `set`. Το τμήμα `set` ενός ευρετηριαστή έχει μια ειδική τιμή, τη `value`, η οποία είναι η τιμή που περνάει στον ευρετηριαστή.

```csharp
class LapTimes
{
    private int[] times = new[] { 2, 4, 3, 8 };

    public int this[int lap]
    {
        get { return times[lap]; }
        set { times[lap] = value; }
    }
}

var lapTimes = new LapTimes();

// Use the getter
Console.WriteLine(lapTimes[1]); // => 4

// Use the setter
lapTimes[2] = 5;
Console.WriteLine(lapTimes[2]); // => 5
```
