# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις πάνω σε μια εφαρμογή προγραμματισμού ραντεβού για ένα ινστιτούτο αισθητικής που άνοιξε στις 15 Σεπτεμβρίου του 2012.

Έχεις πέντε εργασίες, οι οποίες όλες θα έχουν να κάνουν με ημερομηνίες ραντεβού.

## 1. Ανάλυση της ημερομηνίας του ραντεβού

Υλοποίησε τη συνάρτηση `Schedule` ώστε να αναλύει μια κειμενική αναπαράσταση της ημερομηνίας ενός ραντεβού και να τη μετατρέπει στην αντίστοιχη μορφή `time.Time`:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Έλεγχος αν το ραντεβού έχει ήδη περάσει

Υλοποίησε τη συνάρτηση `HasPassed` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού ήταν κάπου στο παρελθόν:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Έλεγχος αν το ραντεβού είναι το απόγευμα

Υλοποίησε τη συνάρτηση `IsAfternoonAppointment` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού είναι το απόγευμα (>= 12:00 και < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Περιγραφή της ώρας και της ημερομηνίας του ραντεβού

Υλοποίησε τη συνάρτηση `Description` που παίρνει μια ημερομηνία ραντεβού και επιστρέφει μια περιγραφή αυτής της ημερομηνίας και ώρας:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Επιστροφή της ημερομηνίας επετείου των εγκαινίων του ινστιτούτου

Υλοποίησε τη συνάρτηση `AnniversaryDate` που επιστρέφει την ημερομηνία επετείου των εγκαινίων του ινστιτούτου για το τρέχον έτος σε UTC.

Υποθέτοντας ότι το τρέχον έτος είναι το 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Σημείωση:** η τιμή επιστροφής είναι `time.Time` και η ώρα της ημέρας δεν έχει σημασία.
