# Υποδείξεις

## Γενικά

- Πρόσεξε τους απαριθμητές που θα συναντήσεις.
- Τα tests μπορούν να τρέξουν μόνο αφού έχεις υλοποιήσει κάθε εργασία.
  Για να δεις τα αποτελέσματα των tests, χρειάζεσαι μόνο έναν πρόχειρο σκελετό των συναρτήσεων και των κλάσεων.
- Κάθε συνάρτηση, κλάση και απαρίθμηση που χρησιμοποιείται από τα tests πρέπει να δηλώνεται στο αρχείο κεφαλίδας.

## 1. Προσπάθησε να αποσπάσεις μερικά πρώτα στοιχεία

- Η κλάση και το enum βρίσκονται σε διαφορετικά namespaces.
- Χρησιμοποίησε ένα `class enum` για το `System`
- Μπορείς είτε να έχεις δύο κατασκευαστές, είτε έναν κατασκευαστή με προεπιλεγμένο όρισμα.

## 2. Βρες περισσότερες λεπτομέρειες

- Η πρώτη γραμμή `REQUIRE` ελέγχει το προεπιλεγμένο `System`.
- Το `generation` φαίνεται να αυξάνεται κατά ένα σε ένα κλωνοποιημένο σκάφος.
- Το `System` φαίνεται να μένει ανέπαφο από τη διαδικασία κλωνοποίησης.

## 3. Ρίξε μια ματιά στα εσωτερικά της λειτουργίας

- Η συνάρτηση-μέλος `shoot_buster` φαίνεται να εξαρτάται από έναν εσωτερικό μετρητή.
