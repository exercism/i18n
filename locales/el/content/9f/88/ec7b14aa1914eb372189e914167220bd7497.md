# Προσαρμοσμένοι Επαναλήπτες

Χρησιμοποιείς επαναλήπτες ήδη από το `bird-survey`. Τώρα γράφεις τον δικό σου.

## yield

Ένας επαναλήπτης μοιάζει με μια ρουτίνα, με δύο διαφορές: το όνομά του τελειώνει σε `!`, και παραδίδει τιμές με `yield` αντί για `return`.

```sather
   markers!(count : INT) : INT is
      loop
         yield 100 * 1.upto!(count);
      end;
   end;
```

Το `yield` δίνει μια τιμή στον βρόχο που κάλεσε τον επαναλήπτη και μετά
**περιμένει**. Όταν αυτός ο βρόχος ξαναγυρίσει, ο επαναλήπτης συνεχίζει από
αμέσως μετά το `yield`, με τα πάντα ακριβώς όπως τα άφησε: τις μεταβλητές
του, τον δικό του βρόχο, τη θέση του.

Αυτό είναι ένας επαναλήπτης: μια ρουτίνα που μπορεί να κάνει παύση στη μέση
και μετά να συνεχίσει.

```sather
   loop
      #OUT + TRAIL::markers!(3) + " ";      -- 100 200 300
   end;
```

## Τερματισμός

Ένας επαναλήπτης τελειώνει με έναν από δύο τρόπους.

**Εξάντληση.** Όταν ο βρόχος του ίδιου του επαναλήπτη τελειώσει, ή η ρουτίνα
φτάσει στο τέλος της, τελείωσε, και ο βρόχος που τον κάλεσε τερματίζεται
αμέσως.

**quit.** Το `quit` τον τερματίζει επιτόπου, χωρίς να κάνει `yield`.

```sather
   named!(names : ARRAY{STR}) : STR is
      loop
         name ::= names.elt!;
         if name = "" then quit; end;
         yield name;
      end;
   end;
```

Αυτό παραδίδει ονόματα μέχρι να συναντήσει ένα κενό, και σταματά. Το `quit`
είναι για έναν επαναλήπτη ό,τι το `return` για μια ρουτίνα, με τη διαφορά
ότι δεν κουβαλά καμία τιμή: δεν έχει μείνει τίποτα να παραδώσει.

## once

Ένα όρισμα με τη σήμανση `once` υπολογίζεται μία μόνο φορά, όταν ξεκινά ο
βρόχος, αντί σε κάθε γύρο:

```sather
   markers!(once count : INT) : INT is
```

Χρησιμοποίησέ το για ό,τι δεν αλλάζει από γύρο σε γύρο, δηλαδή για τα
περισσότερα ορίσματα. Οι επαναλήπτες της ίδιας της βιβλιοθήκης το κάνουν:
`upto!(once i : SAME)`.

## Επαναλήπτες Χωρίς Τιμή

Ένας επαναλήπτης δε χρειάζεται να παραδώσει κάποια τιμή. Ένα παράδειγμα
είναι ο `times!`:

```sather
   steps!(once count : INT) is
      loop
         ignored ::= 1.upto!(count);
         yield;
      end;
   end;
```

Ένα σκέτο `yield` δεν παραδίδει τίποτα και αφήνει απλώς τον βρόχο να
συνεχίσει.

## Πού Βρίσκεται η Θέση

Κάθε *σημείο του προγράμματος* που καλεί έναν επαναλήπτη κρατά τη δική του
θέση, γι' αυτό, όταν καλείς τον ίδιο επαναλήπτη δύο φορές μέσα στο σώμα ενός
βρόχου, τον διατρέχεις δύο φορές. Τώρα μπορείς να δεις το γιατί: οι δύο
κλήσεις είναι δύο ξεχωριστές ρουτίνες σε παύση.
