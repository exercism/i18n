# Υποδείξεις

## 1. Πάρε όλα τα κρασιά συγκεκριμένου χρώματος

- Τα ορίσματα με λέξεις-κλειδιά καθορίζονται γράφοντας ένα όνομα πριν από το όνομα του ορίσματος, με ένα κενό ανάμεσά τους.
- Η συνάρτηση [`list.filter`][list-filter] μπορεί να χρησιμοποιηθεί για να επιλέξεις στοιχεία από μια λίστα που ικανοποιούν ένα δεδομένο κατηγόρημα.

## 2. Πάρε όλα τα κρασιά συγκεκριμένου χρώματος που εμφιαλώθηκαν ένα συγκεκριμένο έτος

- Τα ορίσματα με λέξεις-κλειδιά καθορίζονται γράφοντας ένα όνομα πριν από το όνομα του ορίσματος, με ένα κενό ανάμεσά τους.
- Η συνάρτηση [`list.filter`][list-filter] μπορεί να χρησιμοποιηθεί για να επιλέξεις στοιχεία από μια λίστα που ικανοποιούν ένα δεδομένο κατηγόρημα.

## 3. Πάρε όλα τα κρασιά συγκεκριμένου χρώματος που εμφιαλώθηκαν σε συγκεκριμένη χώρα

- Αυτή η συνάρτηση μπορεί να υλοποιηθεί καλώντας τη `wines_from_country` και μετά τη `wines_of_color` στο αποτέλεσμα.

[list-filter]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#filter
