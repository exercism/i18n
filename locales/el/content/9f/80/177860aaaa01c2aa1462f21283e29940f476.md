# Οδηγίες

Βοηθάς έναν φίλο να δημιουργήσει μια αναφορά από μετρήσεις που έχει πάρει σε διάφορες γωνιές του κήπου του.
Δυστυχώς, ο φίλος σου έχει αποθηκεύσει τα δεδομένα σε μια περίεργη μορφή.
Κάθε μέτρηση είναι ένα σύνολο πεδίων χωρισμένων με κόμμα.
Ωστόσο, έχει αποθηκεύσει διψήφιους αριθμούς σε δύο στήλες.

| αριθμός πεδίου | σημασία |
| --- | --- |
| 1 | αριθμός αναγνώρισης |
| 2 | τοποθεσία |
| 3 | πρώτη μέτρηση, ψηφίο δεκάδων |
| 4 | πρώτη μέτρηση, ψηφίο μονάδων |
| 5 | δεύτερη μέτρηση, ψηφίο δεκάδων |
| 6 | δεύτερη μέτρηση, ψηφίο μονάδων |

Για μια γραμμή εισόδου όπως η `101,house,4,2,5,4`
- η πρώτη μέτρηση είναι `42`,
- η δεύτερη μέτρηση είναι `54`.

## Εργασία 1: Δημιούργησε την αναφορά

Η εργασία σου είναι να βρεις τον μέσο όρο των δύο μετρήσεων και να εμφανίσεις τα αποτελέσματα κάθε γραμμής στην ακόλουθη μορφή

```none
#<id>, <label> = <average>
```

Εφόσον ο μέσος όρος του 42 και του 54 είναι 48, η έξοδος για τη γραμμή του παραδείγματος θα πρέπει να είναι:

```none
#101, house = 48
```
