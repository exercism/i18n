# Εισαγωγή

Η συνάρτηση είναι ένα μπλοκ οργανωμένου, επαναχρησιμοποιήσιμου κώδικα που χρησιμοποιείται για να εκτελέσει κάποια ενέργεια.
Υπάρχουν πολλοί τρόποι να ορίσεις συναρτήσεις στη JavaScript.
Εδώ θα δούμε τις _δηλώσεις συνάρτησης_ και τις _εκφράσεις συνάρτησης_.
Άλλες δυνατότητες, όπως οι [συναρτήσεις βέλους][concept-arrow-functions], θα καλυφθούν σε άλλα concept.

## Δήλωση συνάρτησης

Ο τυπικός τρόπος να ορίσεις μια συνάρτηση στη JavaScript είναι η _δήλωση συνάρτησης_, που ονομάζεται επίσης _ορισμός συνάρτησης_ ή _εντολή συνάρτησης_.

Αποτελείται από τη λέξη-κλειδί `function`, το όνομα της συνάρτησης και μια λίστα παραμέτρων χωρισμένων με κόμμα μέσα σε παρενθέσεις.
Ακολουθεί το σώμα της συνάρτησης (σύνολο εντολών που ορίζει τι κάνει η συνάρτηση) μέσα σε άγκιστρα.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

Στη JavaScript, καλείς μια συνάρτηση γράφοντας το όνομα της συνάρτησης και μετά παρενθέσεις που περιέχουν τα ορίσματα.

```javascript
someName(arg1, arg2, arg3);
```

## Παράμετροι

Όταν δουλεύεις με παραμέτρους μέσα στο σώμα της συνάρτησης, πρόσεξε τις πιθανές παρενέργειες.

- Οι τιμές των [πρωτογενών τύπων δεδομένων][mdn-primitives] είναι _αμετάβλητες_.
  Η αρχική τιμή δεν επηρεάζεται ποτέ από το τι συμβαίνει στο όρισμα μέσα στο σώμα της συνάρτησης.
- Για όλες τις άλλες τιμές (αντικείμενα, πίνακες, συναρτήσεις), μια εκ νέου ανάθεση δεν επηρεάζει την αρχική τιμή.
  Ωστόσο, αν τροποποιήσεις ένα τέτοιο όρισμα (π.χ. προσθέσεις ένα κλειδί σε ένα αντικείμενο), τροποποιείς και την αρχική τιμή που πέρασε.

Από προεπιλογή, όλες οι παράμετροι που ορίζονται στη δήλωση συνάρτησης είναι προαιρετικές στη JavaScript.
Αν δώσεις λιγότερα ορίσματα από όσες είναι οι παράμετροι, τα ορίσματα που λείπουν θα είναι `undefined` μέσα στη συνάρτηση, δες [Null και Undefined][concept-null-undefined].
Σε πολλές περιπτώσεις, έχει νόημα να ορίσεις μια πιο κατάλληλη προεπιλεγμένη τιμή από το `undefined`.
Αυτό μπορεί να γίνει ορίζοντας προεπιλεγμένες παραμέτρους απευθείας στον ορισμό της συνάρτησης.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Εντολή `return`

Μια εντολή `return` τερματίζει την εκτέλεση της συνάρτησης και καθορίζει μια τιμή που θα επιστραφεί σε αυτόν που κάλεσε τη συνάρτηση. Μια συνάρτηση μπορεί να έχει πολλές εντολές `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Η τιμή επιστροφής μιας συνάρτησης μπορεί να αποθηκευτεί σε μια μεταβλητή.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

Το αποτέλεσμα μιας συνάρτησης που δεν επιστρέφει καμία τιμή με `return` ή δεν έχει εντολή `return` είναι `undefined`.
Δεν υπάρχουν έμμεσα `return` στη JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

Στη JavaScript, μπορείς να επιστρέψεις μόνο μία ακριβώς τιμή.
Αν θέλεις να περάσεις περισσότερες πληροφορίες, πρέπει πρώτα να τις συνδυάσεις σε μία οντότητα, συνήθως σε ένα [αντικείμενο][concept-objects] ή σε έναν [πίνακα][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Έκφραση συνάρτησης

Η δήλωση συνάρτησης είναι μια αυτόνομη εντολή.
Αλλά μερικές φορές είναι χρήσιμο να ορίσεις μια συνάρτηση ως μέρος μιας άλλης έκφρασης, π.χ. σε μια ανάθεση, ως παράμετρο συνάρτησης ([callback][concept-callbacks]) ή ως τιμή σε ένα [αντικείμενο][concept-objects].
Αυτό μπορεί να γίνει με μια έκφραση συνάρτησης.
Έχει την ίδια σύνταξη με μια δήλωση συνάρτησης, μόνο που το όνομα της συνάρτησης μπορεί να παραλειφθεί για να δημιουργηθεί μια _ανώνυμη συνάρτηση_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
