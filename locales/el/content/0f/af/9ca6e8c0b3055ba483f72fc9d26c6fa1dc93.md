# Συμβουλές

## 1. Εκτύπωσε μια κονκάρδα για έναν υπάλληλο

- Η [παρεμβολή συμβολοσειρών][string-interpolation] μπορεί να χρησιμοποιηθεί για να δημιουργήσεις συμβολοσειρές περιγραφής.
- Υπάρχει μια [ενσωματωμένη μέθοδος για να μετατρέψεις μια συμβολοσειρά σε κεφαλαία][to-upper-case].

## 2. Εκτύπωσε μια κονκάρδα για έναν νέο υπάλληλο

- Πρέπει να ελέγξεις αν το ID είναι `null` πριν το χρησιμοποιήσεις.
- Μπορείς να χρησιμοποιήσεις τους [τελεστές ισότητας][equality-operators] για να συγκρίνεις την τιμή με το `null`

## 3. Εκτύπωσε μια κονκάρδα για τον ιδιοκτήτη

- Πρέπει να ελέγξεις αν το τμήμα είναι `null` πριν το χρησιμοποιήσεις.
- Μπορείς να χρησιμοποιήσεις τους [τελεστές ισότητας][equality-operators] για να συγκρίνεις την τιμή με το `null`
