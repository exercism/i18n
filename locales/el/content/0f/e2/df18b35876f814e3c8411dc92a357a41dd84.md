# Εισαγωγή

Υπάρχουν δύο διαφορετικοί τύποι αριθμών στη Java:

- Ακέραιοι: αριθμοί χωρίς ψηφία μετά το δεκαδικό διαχωριστικό (ακέραιοι αριθμοί).
  Παραδείγματα είναι `-6`, `0`, `1`, `25`, `976` και `-500000`.
- Αριθμοί κινητής υποδιαστολής: αριθμοί με μηδέν ή περισσότερα ψηφία μετά το δεκαδικό διαχωριστικό.
  Παραδείγματα είναι `-20.4`, `0.1`, `2.72`, `16.984025` και `1024.0`.

Οι δύο πιο συνηθισμένοι αριθμητικοί τύποι στη Java είναι το `int` και το `double`.
Το `int` είναι ένας ακέραιος 32 bit και το `double` είναι ένας αριθμός κινητής υποδιαστολής 64 bit.

Οι αριθμητικές πράξεις γίνονται με τους τυπικούς αριθμητικούς τελεστές.
Οι αριθμοί μπορούν να συγκριθούν χρησιμοποιώντας τους τυπικούς τελεστές σύγκρισης αριθμών (π.χ. `5 > 4` και `4 <= 5`) και τους τελεστές ισότητας (`==`) και ανισότητας (`!=`).

Η Java έχει δύο τύπους αριθμητικών μετατροπών:

1. Έμμεσες μετατροπές: δε χάνονται δεδομένα και δεν απαιτείται πρόσθετη σύνταξη.
2. Ρητές μετατροπές: μπορεί να χαθούν δεδομένα και απαιτείται πρόσθετη σύνταξη με τη μορφή ενός _cast_.

Καθώς το `int` έχει μικρότερη ακρίβεια από το `double`, η μετατροπή από `int` σε `double` είναι ασφαλής και επομένως αποτελεί έμμεση μετατροπή.
Ωστόσο, η μετατροπή από `double` σε `int` μπορεί να σημαίνει απώλεια δεδομένων, οπότε απαιτεί ρητή μετατροπή.
