# Εισαγωγή

Θυμήσου ότι ένα πρόγραμμα `jq` είναι ένα _pipeline από εκφράσεις_.
**Η ανάθεση μεταβλητής** ακολουθεί αυτόν τον κανόνα: μια _ανάθεση μεταβλητής_ είναι μια έκφραση που έχει τη μορφή:

```jq
... | expr as $varname | ...
```

## Το φίλτρο έχει ως έξοδο την είσοδο

Όπως η _έκφραση ταυτότητας_ `.`, έτσι και η έξοδος της _ανάθεσης μεταβλητής_ είναι ίδια με την είσοδό της.
Ο καθορισμός της τιμής της μεταβλητής είναι μια παρενέργεια.

Παράδειγμα που δείχνει ότι το `.` μετά την ανάθεση είναι το ίδιο με την αρχική είσοδο:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Εμβέλεια μεταβλητής

Η εμβέλεια της μεταβλητής είναι "λεξιλογική": η μεταβλητή θα βρίσκεται στην εμβέλεια για το υπόλοιπο pipeline.
Οι μεταβλητές που ορίζονται μέσα σε συναρτήσεις (θα δούμε τις συναρτήσεις πιο μετά) είναι "τοπικές" στη συνάρτηση.

## Ονόματα μεταβλητών

Η μεταβλητή πρέπει να ξεκινά με `$`.
Το υπόλοιπο του ονόματος της μεταβλητής είναι ένα **αναγνωριστικό**: ξεκινά με ένα γράμμα ή κάτω παύλα και ακολουθούν γράμματα, αριθμοί ή κάτω παύλες.

## Ανάθεση με αποδόμηση

Από το εγχειρίδιο:

> Μπορείς να δηλώσεις πολλές μεταβλητές με μία μόνο έκφραση `as`, δίνοντας ένα μοτίβο που _ταιριάζει με τη δομή της εισόδου_ (αυτό είναι γνωστό ως "αποδόμηση").

Παραδείγματα:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Το ταίριασμα του ονόματος της μεταβλητής με το _κλειδί του αντικειμένου_ προσφέρει μια συντόμευση:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Σταθερές

Όπως φαίνεται στο παραπάνω παράδειγμα, οι μεταβλητές είναι βολικές για την αποθήκευση σταθερών.
Είναι καλύτερα να δίνεις ένα όνομα στις σταθερές αντί να εμφανίζονται "μαγικοί αριθμοί" μέσα στον κώδικα.

## Συχνά οι μεταβλητές δεν χρειάζονται

Συχνά είναι πιο ευανάγνωστο να παραλείπεις τις μεταβλητές.

Σκέψου να υπολογίσεις τον μέσο όρο μιας λίστας αριθμών

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

σε σύγκριση με

```jq
[2, 4, 8, 7] | add / length
```

Αυτό αναδεικνύει μία από τις πιο ισχυρές πτυχές του `jq`: η είσοδος σε ένα φίλτρο παρέχεται σε _κάθε_ υποέκφραση:

- ο πίνακας εισόδου `[2,4,8,7]` περνά στο `add` (το οποίο αθροίζει τους αριθμούς εφαρμόζοντας τον τελεστή `+` σε όλα τα στοιχεία)
- _παράλληλα_, το `[2,4,8,7]` περνά και στο `length`
- όταν ολοκληρωθούν αυτές οι υποεκφράσεις, τα αποτελέσματά τους διαιρούνται μεταξύ τους και προκύπτει ο μέσος όρος των αριθμών του πίνακα εισόδου.
