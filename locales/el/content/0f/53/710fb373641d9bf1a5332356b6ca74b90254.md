# Οδηγίες

Θα γράψεις κώδικα που θα σε βοηθήσει να μαγειρέψεις μια λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Υπάρχουν πέντε εργασίες, όλες σχετικές με τη διαδικασία μαγειρέματος της συνταγής σου.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε μια σταθερά `ExpectedBakeTime` που επιστρέφει πόσα λεπτά πρέπει να ψηθεί η λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής σου, η λαζάνια πρέπει να μείνει στον φούρνο για 40 λεπτά:

```powershell
> $ExpectedBakeTime
> 40
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Υλοποίησε τη συνάρτηση `RemainingTime` που παίρνει ως όρισμα τα πραγματικά λεπτά που η λαζάνια βρίσκεται στον φούρνο και επιστρέφει πόσα λεπτά χρειάζεται ακόμη να ψηθεί, με βάση τη σταθερά `ExpectedBakeTime`.

```powershell
> RemainingTime -Minutes 30
> 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη συνάρτηση `PreparationTime` που παίρνει ως όρισμα τον αριθμό των στρώσεων που θέλεις να προσθέσεις στη λαζάνια και επιστρέφει πόσα λεπτά θα χρειαστείς για να τις φτιάξεις.
Υπόθεσε ότι κάθε στρώση θέλει 2 λεπτά για να ετοιμαστεί.

```powershell
> PreparationTime -Layers 2
> 4
```

## 4. Υπολόγισε τον συνολικό χρόνο μαγειρέματος (προετοιμασία + ψήσιμο) σε λεπτά

Υλοποίησε τη συνάρτηση `ElapsedTime` που έχει δύο παραμέτρους: `Layers` (_ο αριθμός των στρώσεων που προστέθηκαν στη λαζάνια_) και `Minutes` (_ο αριθμός των λεπτών που η λαζάνια ψήνεται στον φούρνο_).
Αυτή η συνάρτηση πρέπει να επιστρέφει τον συνολικό αριθμό λεπτών που μαγειρεύεις, ή το άθροισμα του χρόνου προετοιμασίας σου και του χρόνου που η λαζάνια έχει ήδη περάσει ψηνόμενη στον φούρνο.

```powershell
> ElapsedTime -Layers 3 -Minutes 20
> 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

Όρισε τη συνάρτηση `Notification` που δεν παίρνει κανένα όρισμα και επιστρέφει ένα μήνυμα που δηλώνει ότι η λαζάνια είναι έτοιμη να φαγωθεί.

```powershell
> Notification
> "Lasagna's ready!"
```
