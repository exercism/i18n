# Προσθήκη οδηγιών

## Μορφή εισόδου

Η παράμετρος `board`, που αντιπροσωπεύει το ταμπλό του παιχνιδιού, έχει τη μορφή πίνακα συμβολοσειρών.

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

Κάθε χαρακτήρας μιας συμβολοσειράς αντιπροσωπεύει ένα κελί.
Οι έγκυρες τιμές για ένα κελί είναι:

- ` ` ένα κενό διάστημα που αντιστοιχεί σε ένα άδειο κελί
- `B` ένα κελί που ανήκει στον μαύρο παίκτη
- `W` ένα κελί που ανήκει στον λευκό παίκτη

## Μορφές εξόδου

Η συνάρτηση `getTerritory` αναμένεται να επιστρέψει ένα αντικείμενο με 2 ιδιότητες:

- `owner` Ο ιδιοκτήτης της περιοχής (`NONE`, `BLACK` ή `WHITE`)
- `territory` Ένας πίνακας συντεταγμένων που αντιπροσωπεύει κάθε κελί στην περιοχή.

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

Η συνάρτηση `getTerritories` αναμένεται να επιστρέψει ένα αντικείμενο με 3 ιδιότητες:

- `territoryBlack` Ένας πίνακας συντεταγμένων που αντιπροσωπεύει τις περιοχές που ανήκουν στον παίκτη `BLACK`
- `territoryWhite` Ένας πίνακας συντεταγμένων που αντιπροσωπεύει τις περιοχές που ανήκουν στον παίκτη `WHITE`
- `territoryNone` Ένας πίνακας συντεταγμένων που αντιπροσωπεύει τις περιοχές που δεν ανήκουν σε κανέναν από τους δύο παίκτες

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
