# Υποδείξεις

 ## 1. Καθόρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Καθόρισε μια [σταθερά][constants] που θα περιέχει την τιμή [`number`][numbers] που δίνεται στη συνταγή.

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- [Επίστρεψε έναν αριθμό][return] από τη μέθοδο, ορίζοντας την τιμή της.
- Χρησιμοποίησε τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- [Επίστρεψε έναν αριθμό][return] από τη μέθοδο, ορίζοντας την τιμή της.
- Χρησιμοποίησε τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.
- Χρησιμοποίησε τη σταθερά που δίνει τον επιπλέον χρόνο σε λεπτά ανά στρώση.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- [Επίστρεψε έναν αριθμό][return] από τη μέθοδο, ορίζοντας την τιμή της.
- [Κάλεσε][invocation] μία από τις άλλες μεθόδους που υλοποίησες προηγουμένως.
- Χρησιμοποίησε τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.
