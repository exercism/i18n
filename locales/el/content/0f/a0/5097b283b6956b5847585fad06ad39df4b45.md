# Μαθαίνοντας τη Crystal

- [Επίσημη τεκμηρίωση Crystal][offical-doc]: Αυτή είναι αυτή τη στιγμή η βασική πηγή μάθησης για τη Crystal. Και είναι πολύ αναλυτική, από τα βασικά literals και τις μεταβλητές μέχρι προχωρημένα πράγματα όπως τα macros. Έχει επίσης μια ωραία [τεκμηρίωση για τις συμβάσεις προγραμματισμού][coding conventions].

- [Crystal for Rubyists][rubyists guide]: Μια πρακτική εισαγωγή στη γλώσσα Crystal.

- Crystal Playground - Αν και η Crystal δεν έχει ενσωματωμένο REPL (όπως η Ruby, η Python ή η Node), έχει έναν τρόπο να πειραματιστείς σχετικά εύκολα με κώδικα. Απλώς τρέξε `crystal play` και θα έχεις έναν χώρο για να παίξεις με τη Crystal στον browser σου, στο localhost:8080.

- [Διαδικτυακός επεξεργαστής][online editor] - Ένα REPL για τη Crystal μέσα στον browser, είναι καλό μέρος για να πάρεις μια πρώτη γεύση της γλώσσας. 
  Χωρίς να χρειάζεται να εγκαταστήσεις τίποτα.

[rubyists guide]: http://www.crystalforrubyists.com/
[offical-doc]: https://crystal-lang.org/reference/
[coding conventions]: https://crystal-lang.org/reference/conventions/coding_style.html
[online editor]: https://replit.com/languages/crystal
