# Αντιστροφή του `if` για happy path στα αριστερά

Για να το απλοποιήσεις, αντιστρέψε τη συνθήκη του `if` που χειρίζεται την περίπτωση σφάλματος,
και μετά ξεφορτώσου τον κλάδο `else` επιστρέφοντας μέσα στο `if`.
Μια παροιμία της Go λέει "[Το happy path είναι ευθυγραμμισμένο στα αριστερά](https://medium.com/@matryer/line-of-sight-in-code-186dd7cdea88)",
που σημαίνει ότι η κανονική ροή ελέγχου ακολουθεί το αριστερό περιθώριο,
και μόνο οι εξαιρετικές περιπτώσεις ή οι περιπτώσεις σφάλματος έχουν εσοχή.
