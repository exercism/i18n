# Υποδείξεις

## Γενικά

- [Ιδιότητες][docs.microsoft.com-properties]
- [Χρήση ιδιοτήτων][docs.microsoft.com-using-properties]

## 1. Επίτρεψε στη ζυγαριά να έχει ακρίβεια

- Πρέπει να προσθέσεις μια [ιδιότητα μόνο `get`][stackoverflow.com-get-only-properties] στην οποία θα αποθηκεύεται η ακρίβεια.
- Μπορείς να αρχικοποιήσεις την ιδιότητα μόνο `get` από τον κατασκευαστή (και μόνο από τον κατασκευαστή).

## 2. Επίτρεψε να ορίζεται το βάρος στη ζυγαριά

- Πρέπει να προσθέσεις μια ιδιότητα με ένα ιδιωτικό [πεδίο υποστήριξης][docs.microsoft.com-properties-with-backing-fields].

## 3. Βεβαιώσου ότι απορρίπτεται ένα αρνητικό βάρος εισόδου

- Η λέξη-κλειδί `value` χρησιμοποιείται για να δηλώσει την τιμή που θέλει αυτός που καλεί να έχει η ιδιότητα.
- Πρόσθεσε [έλεγχο εγκυρότητας][stackoverflow.com-validating-properties] στον προσπελαστή `set` της ιδιότητας `Weight`, ώστε να πετάει μια εξαίρεση όταν η τιμή δεν είναι έγκυρη.

## 4. Επίτρεψε να εφαρμόζεται στη ζυγαριά μια ρύθμιση απόβαρου

- Πρέπει να προσθέσεις μια [αυτόματα υλοποιημένη ιδιότητα][docs.microsoft.com-auto-implemented-properties] για τη ρύθμιση του απόβαρου.

## 5. Βεβαιώσου ότι η ζυγαριά έχει προεπιλεγμένη ρύθμιση απόβαρου

- Μπορείς να αρχικοποιήσεις μια [αυτόματα υλοποιημένη ιδιότητα][docs.microsoft.com-auto-implemented-properties] όπως ακριβώς μπορείς να αρχικοποιήσεις ένα πεδίο.

## 6. Επίτρεψε την ανάκτηση του βάρους

- Πρέπει να προσθέσεις μια ιδιότητα μόνο `get`, στην οποία να υπολογίζεται το σωστό βάρος εμφάνισης.

## 7. Εμφάνισε σωστά τη συμβολοσειρά του βάρους εμφάνισης

- Πρέπει να κάνεις κατάλληλη [μορφοποίηση της συμβολοσειράς][stackoverflow.com-format-string].
