# Προσθήκη στις οδηγίες

## Σημειώσεις

Αυτή η άσκηση απαιτεί να δημιουργήσεις μια δομή δεδομένων συνδεδεμένης λίστας στην οποία μπορείς να κάνεις επανάληψη.

1. Υλοποίησε την ιδιότητα `Count`. Δεν θα πρέπει να είναι δυνατό να αλλάξει η τιμή της από έξω
2. Υλοποίησε τη μέθοδο `Push(T value)` που προσθέτει μια τιμή στη λίστα, στην κεφαλή της.
3. Υλοποίησε τη μέθοδο `Pop()` που αφαιρεί και επιστρέφει μια τιμή από την κεφαλή.
4. Πρόσθεσε έναν κατασκευαστή που να επιτρέπει την αρχικοποίηση με μία μόνο τιμή ή με ένα iterable
5. Υλοποίησε τη διεπαφή `IEnumerable<T>`. Για περισσότερες πληροφορίες, δες [αυτή τη σελίδα](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1).
6. Βεβαιώσου ότι η μέθοδος `Reverse()` είναι διαθέσιμη.
