## Απομαγνητοφώνηση

### Η ιστορία του Exercism

Το Exercism υπάρχει εδώ και αρκετό καιρό. Δημιουργήθηκε για πρώτη φορά το 2013 από την Katrina Owen ως εργαλείο για τους μαθητές της. Στη v1, ήταν απλώς μια συλλογή από ενδιαφέροντα Practice Exercises. Στη v2, έγινε μια πλατφόρμα για δωρεάν mentoring στον κώδικα.

### Τα προβλήματα της v2

Υπάρχουν τρία βασικά προβλήματα που αντιμετωπίζει η v3.

Πρώτο: η δύσκολη αρχική εγκατάσταση, δεύτερο: εξάσκηση στον κώδικα χωρίς μάθηση, τρίτο: ο μεγάλος χρόνος απόκρισης των mentors.

#### Πρόβλημα 1. Δύσκολη αρχική εγκατάσταση

Πρόβλημα νούμερο ένα: η δύσκολη αρχική εγκατάσταση. Για να ξεκινήσεις με το Exercism, πρέπει να εγκαταστήσεις το Exercism CLI, τη γλώσσα προγραμματισμού που θέλεις να δοκιμάσεις και να νιώθεις άνετα στο τερματικό. Πρέπει να ρυθμίσεις τον editor σου ώστε να κάνει χρωματισμό σύνταξης για τη νέα γλώσσα, και ούτω καθεξής. Για έμπειρους προγραμματιστές, όλη αυτή η προετοιμασία είναι μια ενοχλητική σπατάλη χρόνου. Για αρχάριους όμως, μπορεί να είναι ένα εμπόδιο αδύνατο να ξεπεραστεί.

Η λύση: να μπορούν οι άνθρωποι να γράφουν κώδικα στον browser. Χωρίς καμία αρχική εγκατάσταση.

Για να γίνει αυτό εφικτό, το Exercism έχει τώρα έναν web editor, και κάθε γλώσσα προγραμματισμού έχει τον δικό της Test Runner, αφιερωμένο στην εκτέλεση των tests για τις ασκήσεις του Exercism.

##### Web editor

Αυτός είναι ο web editor [[screenshot που εμφανίζεται στο 2:25](https://youtu.be/ijQof_ASicw?t=145)]. Έχει δύο πάνελ, τον πηγαίο κώδικα στα αριστερά και τις οδηγίες και το σύνολο των tests στα δεξιά.

Δεν έχει περίτεχνα χαρακτηριστικά, γιατί ο σκοπός του δεν είναι να αντικαταστήσει τα αγαπημένα σου εργαλεία. Ο σκοπός του είναι να σου επιτρέψει να αναβάλεις την εγκατάσταση όλων των απαραίτητων εργαλείων και εξαρτήσεων μέχρι να νιώσεις πιο άνετα με τη νέα γλώσσα προγραμματισμού και να ξέρεις ότι θέλεις να συνεχίσεις να δουλεύεις μαζί της.

Ο web editor είναι εντελώς προαιρετικός. Μπορείς να συνεχίσεις να χρησιμοποιείς το CLI και να δουλεύεις με τα αγαπημένα σου εργαλεία στον υπολογιστή σου.

##### Test Runners

Για να είναι ο web editor αξιοποιήσιμος, χρειάζεται ένας τρόπος να εκτελούνται τα tests πάνω στη λύση που γράφεις στον browser. Αυτή είναι η δουλειά του Test Runner.

Κάθε γλώσσα στο Exercism έχει τον δικό της Test Runner. Ο Test Runner είναι υπεύθυνος για την αναφορά των αποτελεσμάτων των tests, αλλά δεν είναι μόνο αυτό. Πρέπει επίσης να εξάγει το σώμα του test ώστε να ξέρεις ποιος κώδικας εκτελείται και να μπορείς να ερμηνεύσεις το μήνυμα αποτυχίας, αλλά και να καταγράφει την έξοδο του test ώστε να μπορείς να κάνεις debug
τον κώδικά σου στον browser χρησιμοποιώντας `puts`, `print`, `console.log` ή όποια συνάρτηση εκτύπωσης προσφέρει η γλώσσα σου.

Οι Test Runners είναι κρίσιμοι για την επίλυση ασκήσεων στον browser, αλλά θα χρησιμοποιούνται και για λύσεις που υποβάλλονται μέσω του CLI. Όταν περιηγείσαι στις community solutions για μια δεδομένη άσκηση ή όταν κάνεις mentoring σε έναν μαθητή, μπορείς να δεις αν η λύση περνάει τα tests χωρίς να χρειάζεται να την κατεβάσεις και να την εκτελέσεις τοπικά.

#### Πρόβλημα 2. Εξάσκηση στον κώδικα χωρίς μάθηση

Πρόβλημα νούμερο δύο: το Exercism είναι μια πλατφόρμα για εξάσκηση στον κώδικα, αλλά δεν πρόσφερε κανένα υλικό για να μάθεις μια συγκεκριμένη γλώσσα από το μηδέν. Έπρεπε να το κάνεις αυτό κάπου αλλού πρώτα.

Οι ασκήσεις στο Exercism ήταν σχεδιασμένες να είναι ενδιαφέρουσες και απαιτητικές, αλλά μερικές φορές ακόμα και οι πιο εύκολες είναι πολύ δύσκολες για να αποτελέσουν σημείο εισόδου σε μια νέα γλώσσα προγραμματισμού. Αυτό ισχύει ειδικά όταν προσπαθείς να μάθεις μια γλώσσα με εντελώς διαφορετική σύνταξη ή ακόμα και όταν χρησιμοποιεί διαφορετικό προγραμματιστικό παράδειγμα.

Η λύση: να προσφέρεται μάθηση παράλληλα με την εξάσκηση.

Με την προσθήκη του Syllabus και των Learning Exercises, το Exercism έχει γίνει πλέον ένα εξαιρετικό εργαλείο για να βουτήξεις κατευθείαν σε μια νέα γλώσσα προγραμματισμού.

##### Syllabus

Τι είναι το Syllabus; Το Syllabus είναι ένα δέντρο από Concepts που συγκροτούν κάθε γλώσσα προγραμματισμού. Το Syllabus είναι μοναδικό για κάθε track στο Exercism, γιατί κάθε γλώσσα προγραμματισμού είναι διαφορετική και έχει διαφορετικά Concepts.

Τα Concepts εξαρτώνται το ένα από το άλλο, σχηματίζοντας διάφορους κλάδους του δέντρου. Πρέπει να μάθεις το προηγούμενο concept στον κλάδο για να ξεκλειδώσεις το επόμενο concept.

Για παράδειγμα, αυτή είναι η αρχή του Syllabus του Elixir [[screenshot που εμφανίζεται στο 5:10](https://youtu.be/ijQof_ASicw?t=310)]. Ξεκινά με ένα concept που λέγεται "basics", το οποίο καλύπτει: πώς ορίζεις ένα module, πώς ορίζεις μια συνάρτηση με όνομα και πού βρίσκεις την τεκμηρίωση για την πρότυπη βιβλιοθήκη. Αυτή η γνώση είναι απαραίτητη για κάθε άσκηση του Exercism. Πρέπει να μάθεις το basics για να ξεκλειδώσεις οποιοδήποτε άλλο concept. Μπορείς να μάθεις για παράδειγμα τα booleans, και μόλις μάθεις τα booleans, μπορείς να μάθεις για την έκφραση cond, και ούτω καθεξής.

Για να πάρεις μια ιδέα, αυτό είναι το πλήρες Syllabus του Elixir [[screenshot που εμφανίζεται στο 6:16](https://youtu.be/ijQof_ASicw?t=376)]. Αυτή τη στιγμή περιέχει πάνω από 50 Concepts, αλλά χρειάζεται ακόμα να επεκταθεί.

Στην κορυφή θα βρεις Concepts όπως: συμβολοσειρές, λίστες, maps και tuples. Στη μέση υπάρχουν: το module `Enum`, οι κανονικές εκφράσεις, τα structs και η συγγραφή typespecs. Και στο τέλος: protocols, processes και tasks.

##### Learning exercises

Μαθαίνεις τα Concepts του Syllabus λύνοντας Learning Exercises. Τα Learning Exercises είναι διαφορετικά από τα Practice Exercises. Σχεδιάστηκαν για να διδάσκουν έννοιες προγραμματισμού σε μαθητές που δεν ξέρουν καθόλου τη συγκεκριμένη γλώσσα προγραμματισμού, αλλά ξέρουν τουλάχιστον μία άλλη γλώσσα και βασικές έννοιες προγραμματισμού.

###### Εισαγωγή

Κάθε Learning Exercise ξεκινά με μια εισαγωγή. Η εισαγωγή περιγράφει βασικές πληροφορίες για τα Concepts που διδάσκει αυτή η άσκηση. Τα περισσότερα Learning Exercises διδάσκουν ένα μόνο concept, αλλά υπάρχουν εξαιρέσεις.

Αυτό το παράδειγμα δείχνει μια εισαγωγή για τα maps του Elixir [[screenshot που εμφανίζεται στο 7:12](https://youtu.be/ijQof_ASicw?t=432)]. Εξηγεί τι είναι τα maps, πώς ορίζεις ένα map, πώς προσπελαύνεις μια τιμή σε ένα map και ούτω καθεξής. Περιέχει μερικά παραδείγματα κώδικα για να δείξει τη νέα σύνταξη, αλλά όχι πάρα πολλά, ώστε να μην μπορείς απλώς να αντιγράψεις και να επικολλήσεις την εισαγωγή για να λύσεις την άσκηση.

###### Οδηγίες

Έπειτα υπάρχουν οι οδηγίες. Οι οδηγίες των Learning Exercises χωρίζονται σε μικρές εργασίες. Οι εργασίες είναι σχεδιασμένες να ωθούν τον μαθητή να χρησιμοποιεί τα πιο κρίσιμα μέρη κάθε concept.

Για παράδειγμα, το Learning Exercise που διδάσκει τα maps θα βάλει τον μαθητή να δημιουργήσει ένα map, μετά να διαβάσει μια τιμή από ένα map, μετά να ενημερώσει μια τιμή σε ένα map, μετά να πάρει όλα τα κλειδιά ενός map και ούτω καθεξής.

Κάθε Learning Exercise έχει μια ιστορία, αλλά η ιστορία δεν είναι τόσο σημαντική. Υπάρχει για να μη χρειάζεται να χρησιμοποιείς άσκοπες τιμές όπως "foo bar" και "1 2 3", αλλά δεν παίζει μεγάλο ρόλο στην άσκηση, όπως συμβαίνει στα Practice Exercises.

###### Υποδείξεις

Κάθε εργασία συνοδεύεται από μια μικρή λίστα με υποδείξεις, σε περίπτωση που ο μαθητής κολλήσει. Οι υποδείξεις συχνά αποκαλύπτουν ποια συγκεκριμένη συνάρτηση να χρησιμοποιήσεις σε ποια εργασία και σε οδηγούν στην τεκμηρίωση αυτής της συνάρτησης.

##### Εξάσκηση στα concepts

Αλλά η επίλυση ενός μόνο Learning Exercise δεν αρκεί για να κατακτήσεις πραγματικά το concept. Πρέπει να το εξασκήσεις κι αυτό. Γι' αυτό εξετάσαμε όλα τα Practice Exercises που υπήρχαν ήδη στη v2 και διαλέξαμε μερικά που μπορούν να χρησιμοποιηθούν για την εξάσκηση κάθε concept.

Έτσι φαίνεται ένα μεμονωμένο concept στο δέντρο [[screenshot που εμφανίζεται στο 9:01](https://youtu.be/ijQof_ASicw?t=541)]. Οι κουκκίδες αντιπροσωπεύουν ασκήσεις. Η πρώτη κουκκίδα με το εικονίδιο της λάμπας είναι ένα Learning Exercise, και οι άλλες κουκκίδες είναι Practice Exercises.

Έτσι φαίνεται ένα concept αφού λύσεις μερικές ασκήσεις [[screenshot που εμφανίζεται στο 9:37](https://youtu.be/ijQof_ASicw?t=577)]. Πρόσεξε πώς μερικά από τα Practice Exercises αυτού του concept είναι ακόμα κλειδωμένα, παρόλο που το Learning Exercise έχει ολοκληρωθεί. Αυτό συμβαίνει γιατί τα Practice Exercises δεν περιορίζονται στην εξάσκηση ενός μόνο concept. Μπορεί να χρειαστεί να μάθεις περισσότερα Concepts από ό,τι μόνο τα atoms [concept που φαίνεται στο screenshot] πριν ξεκλειδωθούν αυτές οι ασκήσεις.

Τα Learning Exercises υποτίθεται ότι είναι τετριμμένα για ανθρώπους που γνωρίζουν ήδη καλά μια δεδομένη γλώσσα. Αλλά μην ανησυχείς, είναι εντελώς προαιρετικά. Μπορείς να περάσεις από το learning mode στο practice mode, που θα σου δώσει άμεση πρόσβαση σε όλα τα ενδιαφέροντα Practice Exercises χωρίς να χρειάζεται να περάσεις πρώτα από το Syllabus.

##### Syllabus = τεράστιος κόπος

Μια σημαντική λεπτομέρεια που πρέπει να αναφέρω, για να κρατήσεις τις προσδοκίες σου σε λογικά πλαίσια, είναι ότι η ανάπτυξη του Syllabus είναι ΤΕΡΑΣΤΙΑ προσπάθεια. Δεν έχει κάθε track αρκετούς ενεργούς maintainers ώστε να έχει το Syllabus έτοιμο αυτή τη στιγμή.

Τη στιγμή που γράφω αυτό το βίντεο [4 Σεπτεμβρίου 2021], τα Learning Exercises είναι διαθέσιμα μόνο σε: Common Lisp, C#, Elm, Elixir, F#, Go, Java, JavaScript, Python, Ruby, Rust και Swift. Το track Julia θα λανσάρει σύντομα το Syllabus του.

#### Πρόβλημα 3. Ο μεγάλος χρόνος απόκρισης των mentors

Πρόβλημα νούμερο τρία: ο μεγάλος χρόνος απόκρισης των mentors. Δεν έχουν όλα τα tracks αρκετούς mentors. Κάποια tracks έχουν τόσο λίγους mentors που ο χρόνος αναμονής για mentoring μπορεί να φτάσει και έναν μήνα. Αυτό ήταν πάντα εξαιρετικά αποθαρρυντικό για τους μαθητές. Είναι τόσο κεντρικό ζήτημα για το Exercism, που αντιμετωπίζεται από 3 διαφορετικές οπτικές γωνίες.

##### Αυτοματοποιημένο feedback

Η λύση νούμερο 1 είναι να παρέχεται αυτοματοποιημένο feedback. Μεγάλο μέρος του feedback που γράφουν οι mentors στους μαθητές είναι επαναλαμβανόμενο. Το να μπορείς να εντοπίζεις αυτόματα συνηθισμένα λάθη και να τα αναφέρεις απευθείας στον μαθητή αλλάζει τα δεδομένα.

Το να λαμβάνει ο μαθητής αυτοματοποιημένο feedback για συνηθισμένα λάθη θα του επιτρέπει να βελτιώσει τη λύση του ακόμα και πριν ζητήσει mentoring, κάτι που θα κάνει ευκολότερη και τη δουλειά του mentor. Θα γλιτώνει τους mentors από το να αναφέρουν κουραστικές λεπτομέρειες όπως snake_case εναντίον camelCase, και θα τους αφήνει να εστιάζουν στην ουσία της λύσης. Σε κάποιες περιπτώσεις, το αυτοματοποιημένο feedback θα αρκεί για να ικανοποιήσει τον μαθητή και δεν θα ζητήσει καν mentoring.

Στη v3 υπάρχουν δύο είδη εργαλείων για αυτοματοποιημένο feedback: οι Analyzers και οι Representers.

###### Analyzers

Ο Analyzer είναι ένα εργαλείο που ψάχνει για συγκεκριμένα χαρακτηριστικά σε μια λύση και επιστρέφει στον μαθητή μια λίστα με προκαθορισμένα σχόλια για όσα βρίσκει. Ποια χαρακτηριστικά, εξαρτάται απολύτως από τη γλώσσα και τη συγκεκριμένη άσκηση.

Για παράδειγμα, η Elixir έχει έναν πολύ συγκεκριμένο κανόνα ονοματοδοσίας για συναρτήσεις και μεταβλητές. Ένας από τους ελέγχους που κάνει ο Analyzer της Elixir για κάθε άσκηση είναι ο έλεγχος όλων των ονομάτων μεταβλητών και συναρτήσεων. Αν βρει ένα όνομα που δεν είναι γραμμένο σε snake_case, θα υπενθυμίσει στον μαθητή τον κανόνα ονοματοδοσίας.

Ένας άλλος έλεγχος που μπορεί να κάνει ο Analyzer της Elixir είναι ο εντοπισμός της χρήσης ενός συγκεκριμένου module. Για παράδειγμα, αυτός ο έλεγχος [[screenshot που εμφανίζεται στο 13:20](https://youtu.be/ijQof_ASicw?t=800)] για τη μη χρήση του module Enum είναι ειδικός για το Learning Exercise της αναδρομής. Η χρήση του module Enum ακυρώνει τον σκοπό του Learning Exercise, οπότε ο Analyzer θα υπενθυμίσει στον μαθητή να μην το κάνει αυτό και να χρησιμοποιήσει αναδρομή αντ' αυτού.

###### Representers

Το δεύτερο εργαλείο που θα μας βοηθήσει να παρέχουμε αυτοματοποιημένο feedback στο Exercism είναι ο Representer. Ο Representer παίρνει τη λύση και αφαιρεί τα μη ουσιώδη μέρη. Κανονικοποιεί τη μορφοποίηση, αφαιρεί σχόλια και τεκμηρίωση, και αντικαθιστά ονόματα συναρτήσεων και μεταβλητών με placeholders.

Η έξοδος του Representer ονομάζεται representation. Κάθε λύση που υποβάλλεται στο Exercism θα περνά από τον Representer και το representation της θα αποθηκεύεται στην πλατφόρμα μαζί με τη λύση.

Οι mentors θα έχουν τότε πρόσβαση σε μια διεπαφή όπου μπορούν να περιηγηθούν στα representations των λύσεων που έχουν υποβληθεί. Για κάθε μοναδικό representation, ένας mentor μπορεί να αφήσει feedback πάνω σε αυτό το representation. Έπειτα, αυτό το feedback θα παρουσιάζεται σε κάθε μαθητή που υποβάλλει μια παρόμοια λύση με το ίδιο representation. Ο mentor χρειάζεται να γράψει το feedback μόνο μία φορά και το feedback μπορεί να φτάσει σε όλους όσους το χρειάζονται.

Οι ίδιοι οι Representers έχουν ήδη υλοποιηθεί και έχουν κάνει deploy σε κάποιες γλώσσες, αλλά τη στιγμή που γράφω αυτό το βίντεο [4 Σεπτεμβρίου 2021], η διεπαφή για τους mentors λείπει ακόμα από την πλατφόρμα, οπότε πρέπει να περιμένουμε λίγο μέχρι να είναι πλήρως διαθέσιμη αυτή η λειτουργία.

##### Αποφεύγοντας ανεπιθύμητες συνεδρίες mentoring

Μια άλλη λύση για τις μεγάλες ουρές mentoring είναι να αποφεύγουμε τις ανεπιθύμητες συνεδρίες mentoring. Στη v2, το mentoring ήταν υποχρεωτικό για τα core exercises. Η υποβολή ενός core exercise σήμαινε ότι ζητούσες αυτόματα mentoring, και δεν μπορούσες να προχωρήσεις στο επόμενο core exercise χωρίς την έγκριση του mentor. Πολλοί μαθητές μάθαιναν τη γλώσσα δουλεύοντας τα core exercises, οπότε χρειάζονταν το mentoring για να τους καθοδηγήσει στη διαδικασία της μάθησης.

Αυτό δεν ισχύει πια. Ο διδακτικός ρόλος των core exercises και η έγκριση του mentor έχουν περάσει στα Learning Exercises και στους Analyzers. Στη v3, το mentoring είναι πάντα προαιρετικό και πρέπει να το ζητήσεις ρητά.

###### Αίτημα mentoring

Για να ζητήσεις mentoring, πρέπει να απαντήσεις σε 2 ερωτήσεις: Τι ελπίζεις να μάθεις από αυτό το track; και: Πώς μπορεί ένας mentor να σε βοηθήσει με τη λύση σου; Γνωρίζοντας εκ των προτέρων ποιες είναι οι προσδοκίες του μαθητή από τη συνεδρία mentoring, ο mentor μπορεί να επιλέξει τα αιτήματα mentoring που ταιριάζουν καλύτερα στις γνώσεις και στο στυλ mentoring του, κάτι που κάνει πιθανότερο να μείνουν και οι δύο πλευρές ικανοποιημένες από τη συνεδρία.

###### Ουρά mentoring & αγαπημένα

Στη νέα ουρά mentoring οι mentors μπορούν να δουν στατιστικά για το ιστορικό mentoring του μαθητή. Μπορούν να δουν ποιος μαθητής δεν έχει περάσει ποτέ από mentoring και μπορεί να χρειάζεται πιο προσεκτική εξέταση, και ποιος μαθητής έχει περάσει πολλές φορές από mentoring και καταλαβαίνει πώς λειτουργεί.

Οι mentors μπορούν επίσης επιτέλους να βρουν μαθητές που είχαν κάνει mentoring στο παρελθόν και να αναπτύξουν σχέσεις μαζί τους. Οι mentors μπορούν ακόμα και να προσθέσουν μαθητές στα αγαπημένα και να το χρησιμοποιήσουν για να βάζουν προτεραιότητα σε μαθητές με τους οποίους είχαν στο παρελθόν καλή εμπειρία.

###### Λίστες αποκλεισμού

Μετά από κάθε συνεδρία mentoring, τόσο ο μαθητής όσο και ο mentor έχουν τη δυνατότητα να αποκλείσουν τον άλλον. Υπάρχουν δύο λίστες αποκλεισμού, οι αποκλεισμένοι μαθητές και οι αποκλεισμένοι mentors. Αν εγώ, ως mentor, σε αποκλείσω ως μαθητή, μπορεί αργότερα να μου κάνεις εσύ mentoring. Το άλλο άτομο φυσικά δεν θα έχει ιδέα ότι αποκλείστηκε, οπότε δεν μπορεί να αντεπιτεθεί εναντίον σου.

Μπορείς να επιλέξεις να αποκλείσεις κάποιον για οποιονδήποτε λόγο, αλλά αν παραβιάζει τον Κώδικα Δεοντολογίας, φρόντισε να τον αναφέρεις και ρητά, για να προστατεύσεις τους άλλους χρήστες.

##### Περιορισμός των αρνητικών συνεπειών της μεγάλης αναμονής

Τέλος, το τελευταίο βήμα για την αντιμετώπιση του προβλήματος της μεγάλης αναμονής είναι να διασφαλίσουμε ότι, ακόμα κι αν χρειάζεται μερικές φορές να περιμένεις, οι αρνητικές συνέπειες της αναμονής είναι ελάχιστες. Στη v3, το να περιμένεις mentoring δεν σε εμποδίζει να λύνεις άλλες ασκήσεις. Μπορείς ακόμα να προχωράς στο track.

Μια συνεδρία mentoring μπορεί να τερματιστεί από οποιαδήποτε πλευρά. Αν είσαι μαθητής και δεν σου αρέσει η προσέγγιση που ακολουθεί ένας συγκεκριμένος mentor μαζί σου, μπορείς πάντα να ζητήσεις διαφορετική προσέγγιση ή να επιλέξεις να φύγεις από τη συνεδρία. Ανεξάρτητα από το πώς τελειώνει η συνεδρία mentoring, ο μαθητής μπορεί να ζητήσει νέα συνεδρία mentoring με άλλον mentor για την ίδια λύση.

###### Θέσεις mentoring

Για κάθε track, μπορείς να έχεις από 1 έως 4 θέσεις mentoring. Το να έχεις πολλαπλές θέσεις mentoring μπορεί να σε βοηθήσει όταν θέλεις να ζητήσεις mentoring για μια δύσκολη άσκηση που δεν είναι πιθανό να πάρει γρήγορα mentoring, και ταυτόχρονα να μπορείς να παίρνεις mentoring και για άλλες ασκήσεις.

Οι θέσεις mentoring ξεκλειδώνονται κερδίζοντας reputation. Το reputation δίνεται όταν δημοσιεύεις τις λύσεις σου για να τις βλέπουν όλοι, όταν κάνεις mentoring σε μαθητές και όταν συνεισφέρεις σε οποιοδήποτε από τα repositories του Exercism. Αυτό σημαίνει ότι οι μαθητές που συνεισφέρουν περισσότερο στην πλατφόρμα μπορούν να παίρνουν περισσότερο mentoring.
