# Εισαγωγή

Μια συνάρτηση στην Cairo σου επιτρέπει να ομαδοποιείς κώδικα σε μια επαναχρησιμοποιήσιμη μονάδα, κάνοντας τα προγράμματά σου πιο αρθρωτά και πιο εύκολα στην κατανόηση.
Οι συναρτήσεις στην Cairo αποτελούνται από τη λέξη-κλειδί `fn`, ακολουθούμενη από το όνομα της συνάρτησης, μια λίστα παραμέτρων μέσα σε παρενθέσεις και ένα μπλοκ κώδικα που ορίζει τι κάνει η συνάρτηση.

## Παράμετροι Συναρτήσεων

Στην Cairo, όλες οι παράμετροι των συναρτήσεων πρέπει να έχουν ρητά δηλωμένο τύπο.
Σε αντίθεση με κάποιες γλώσσες, η Cairo δεν συμπεραίνει τύπους και δεν υπάρχουν προεπιλεγμένες τιμές παραμέτρων, οπότε όλες οι παράμετροι είναι υποχρεωτικές.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Παράμετροι εναντίον Ορισμάτων

Είναι σημαντικό να ξεχωρίζεις μεταξύ `parameters` και `arguments`:

- Οι **παράμετροι** είναι τα ονόματα μεταβλητών που χρησιμοποιούνται στον ορισμό της συνάρτησης, όπως τα `greeting` και `name` στη συνάρτηση `print_greeting_name`.
- Τα **ορίσματα** είναι οι πραγματικές τιμές που περνιούνται στη συνάρτηση όταν αυτή καλείται.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Εντολές και Εκφράσεις

Τα σώματα των συναρτήσεων αποτελούνται από μια σειρά εντολών που προαιρετικά καταλήγουν σε μια έκφραση.

- Οι εντολές είναι οδηγίες που εκτελούν κάποια ενέργεια και δεν επιστρέφουν τιμή.
- Οι εκφράσεις αποτιμώνται σε μια τιμή αποτελέσματος.

Η δημιουργία μιας μεταβλητής και η ανάθεση τιμής σε αυτήν με τη λέξη-κλειδί `let` (έστω) είναι μια εντολή.

```rust
let y = 6;
```

Αλλά το `6` στην παραπάνω εντολή είναι μια έκφραση που αποτιμάται στην τιμή `6`.

Η κλήση μιας συνάρτησης είναι μια έκφραση, αφού αποτιμάται πάντα σε μια τιμή: τη ρητή τιμή επιστροφής της συνάρτησης, αν έχει οριστεί, ή αλλιώς τον τύπο "unit" `()`.

## Τιμές Επιστροφής

Οι συναρτήσεις στην Cairo μπορούν να επιστρέφουν τιμές στον κώδικα που τις καλεί.
Οι τιμές επιστροφής αναγράφονται μετά τις παραμέτρους, χωρισμένες με ένα βέλος `->`.
Στην Cairo, η τιμή επιστροφής της συνάρτησης ταυτίζεται με την τιμή της τελευταίας έκφρασης στο μπλοκ του σώματος της συνάρτησης.
Μπορείς να επιστρέψεις νωρίς από μια συνάρτηση χρησιμοποιώντας τη λέξη-κλειδί `return` και καθορίζοντας μια τιμή.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Κλήση Συναρτήσεων

Για να καλέσεις μια συνάρτηση στην Cairo, χρησιμοποιείς απλώς το όνομα της συνάρτησης ακολουθούμενο από ορίσματα μέσα σε παρενθέσεις.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
