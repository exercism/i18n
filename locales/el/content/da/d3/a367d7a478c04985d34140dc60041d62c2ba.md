# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο ακόμα κώδικα σχετικό με την προετοιμασία και το μαγείρεμα της καταπληκτικής λαζάνιας σου από το αγαπημένο σου βιβλίο συνταγών.

Έχεις τέσσερις εργασίες.
Η πρώτη σχετίζεται με το μαγείρεμα αυτό καθαυτό, ενώ οι άλλες τρεις αφορούν την τέλεια προετοιμασία.

## 1. Υπολόγισε τον χρόνο προετοιμασίας

Για την επόμενη λαζάνια που θα ετοιμάσεις, θέλεις να βεβαιωθείς ότι έχεις κρατήσει αρκετό χρόνο ώστε να απολαύσεις το μαγείρεμα.
Έχεις ήδη σχεδιάσει ποιες στρώσεις θα έχει η λαζάνια σου.
Τώρα θέλεις να υπολογίσεις πόσο χρόνο θα πάρει η προετοιμασία με βάση αυτό.

Υλοποίησε μια συνάρτηση `PreparationTime` που δέχεται ένα slice από στρώσεις ως `[]string` και τον μέσο χρόνο προετοιμασίας ανά στρώση σε λεπτά ως `int`.
Η συνάρτηση θα πρέπει να επιστρέφει την εκτίμηση για τον συνολικό χρόνο προετοιμασίας με βάση τον αριθμό των στρώσεων ως `int`.
Η Go δεν έχει προεπιλεγμένες τιμές για τις συναρτήσεις.
Αν ο μέσος χρόνος προετοιμασίας περαστεί ως `0` (η προεπιλεγμένη αρχική τιμή για ένα `int`), τότε θα πρέπει να χρησιμοποιηθεί η προεπιλεγμένη τιμή `2`.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Υπολόγισε τις ποσότητες νουντλς και σάλτσας που χρειάζεσαι

Εκτός από το να κρατήσεις τον χρόνο, θέλεις επίσης να βεβαιωθείς ότι έχεις αρκετή σάλτσα και νουντλς για να μαγειρέψεις τη λαζάνια των ονείρων σου.
Για κάθε στρώση νουντλς στη λαζάνια σου, θα χρειαστείς 50 γραμμάρια νουντλς.
Για κάθε στρώση σάλτσας στη λαζάνια σου, θα χρειαστείς 0,2 λίτρα σάλτσας.

Όρισε τη συνάρτηση `Quantities` που παίρνει ως παράμετρο ένα slice από στρώσεις ως `[]string`.
Η συνάρτηση θα προσδιορίσει τότε την ποσότητα νουντλς και σάλτσας που χρειάζεται για να φτιάξεις το γεύμα σου.
Το αποτέλεσμα θα πρέπει να επιστραφεί ως δύο τιμές: το `noodles` ως `int` και το `sauce` ως `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Πρόσθεσε το μυστικό συστατικό

Πριν λίγο καιρό επισκέφτηκες έναν φίλο και έφαγες λαζάνια εκεί.
Ήταν καταπληκτική και είχε κάτι το ξεχωριστό.
Ο φίλος σου έστειλε τη λίστα με τα συστατικά και σου είπε ότι το τελευταίο στοιχείο της λίστας είναι το "μυστικό συστατικό" που έκανε το γεύμα τόσο ξεχωριστό.
Τώρα θέλεις να προσθέσεις κι εσύ αυτό το μυστικό συστατικό στη συνταγή σου.

Γράψε μια συνάρτηση `AddSecretIngredient` που δέχεται ως παραμέτρους δύο slices με συστατικά τύπου `[]string`.
Η πρώτη παράμετρος είναι η λίστα που σου έστειλε ο φίλος σου, η δεύτερη είναι η λίστα συστατικών της δικής σου συνταγής.
Το τελευταίο στοιχείο στη λίστα συστατικών σου είναι πάντα `"?"`.
Η συνάρτηση θα πρέπει να το αντικαταστήσει με το τελευταίο στοιχείο από τη λίστα του φίλου σου.
**Σημείωση:** Η `AddSecretIngredient` δεν επιστρέφει τίποτα, θα πρέπει να τροποποιήσεις απευθείας τη λίστα με τα συστατικά σου.
Η λίστα με τα συστατικά του φίλου σου **δεν** θα πρέπει να τροποποιηθεί.
Επίσης, καθώς το `slice` περνιέται σε μια συνάρτηση ως δείκτης, οι αλλαγές στα δύο ορίσματα `[]string` που περνιούνται στην `AddSecretIngredient` τροποποιούνται άμεσα.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Κλιμάκωσε τη συνταγή

Οι ποσότητες που αναγράφονται στο βιβλίο συνταγών σου αρκούν μόνο για δύο μερίδες λαζάνια.
Επειδή θέλεις να μαγειρέψεις για περισσότερα άτομα την επόμενη φορά, θέλεις να υπολογίσεις τις ποσότητες για διαφορετικό αριθμό μερίδων.

Υλοποίησε μια συνάρτηση `ScaleRecipe` που παίρνει δύο παραμέτρους.

- Ένα slice με ποσότητες `float64` που χρειάζονται για 2 μερίδες.
- Τον αριθμό των μερίδων για τις οποίες θέλεις να μαγειρέψεις.

Η συνάρτηση θα πρέπει να επιστρέφει ένα slice από `float64` με τις ποσότητες που χρειάζονται για τον επιθυμητό αριθμό μερίδων.
Θέλεις όμως να κρατήσεις την αρχική συνταγή.
Αυτό σημαίνει ότι το όρισμα `quantities` δεν θα πρέπει να τροποποιηθεί σε αυτή τη συνάρτηση.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
