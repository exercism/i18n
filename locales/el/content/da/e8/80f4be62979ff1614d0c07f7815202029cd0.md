# Εισαγωγή

Οι σταθερές είναι τιμές που ορίζονται σε χρόνο μεταγλώττισης και δεν μπορεί να τους εκχωρηθεί νέα τιμή.
Χρησιμοποίησε τη λέξη-κλειδί `const` για να δηλώσεις μία μεμονωμένη σταθερά:

```go
const greeting = "hello"
```

Μπορείς να δηλώσεις πολλές σταθερές σε ένα μπλοκ.
Μέσα σε ένα μπλοκ, μια σταθερά χωρίς ρητά ορισμένη τιμή επαναλαμβάνει την προηγούμενη έκφραση:

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

Οι σταθερές δηλώνονται συνήθως σε επίπεδο πακέτου, αν και μπορούν να δηλωθούν και μέσα σε μια συνάρτηση.

## Σταθερές με τύπο και χωρίς τύπο

Όταν δηλώνεις μια σταθερά χωρίς να προσδιορίσεις τύπο, αυτή μένει χωρίς τύπο.
Μια σταθερά χωρίς τύπο δεν έχει καθορισμένο τύπο· η τιμή της καθορίζει με ποιους τύπους είναι συμβατή.
Όσο η υποκείμενη τιμή είναι συμβατή, ο μεταγλωττιστής θα τη μετατρέψει στον απαιτούμενο τύπο σε κάθε χρήση:

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

Μια σταθερά με τύπο καθορίζει τον τύπο της από τη δήλωση:

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## Τι μπορεί να είναι σταθερά

Οι σταθερές μπορούν να περιέχουν μόνο Boolean, αριθμούς, συμβολοσειρές και runes.
Επειδή οι τιμές ορίζονται σε χρόνο μεταγλώττισης, το αποτέλεσμα μιας κλήσης συνάρτησης δεν μπορεί να χρησιμοποιηθεί για σταθερά.

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## Iota

Μέσα σε ένα μπλοκ σταθερών, το `iota` αντιπροσωπεύει τη θέση της σταθεράς μέσα στο μπλοκ:

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

Κάθε σταθερά μετά την πρώτη κληρονομεί την ίδια έκφραση, με το `iota` να αυξάνεται κατά ένα.

Το `iota` λειτουργεί και σε εκφράσεις.

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
