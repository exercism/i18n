Πέρυσι ξαναφτιάξαμε το [Exercism](https://exercism.io) με νέα έμφαση σε πιο επίσημη καθοδήγηση. Στο πλαίσιο αυτής της αλλαγής, απενεργοποιήσαμε τη δυνατότητα της ευρύτερης κοινότητας να σχολιάζει τις λύσεις των άλλων. Το σκεπτικό πίσω από αυτό ήταν η επιθυμία να κρατήσουμε τη μαθησιακή εμπειρία σε πιο ιδιωτικούς και ασφαλείς χώρους, και να αποφύγουμε τυχαία ανεπιθύμητα σχόλια από αγνώστους.

Τώρα με χαρά ανακοινώνω ότι επαναφέραμε τα σχόλια της κοινότητας στις λύσεις. Το σκεπτικό μας είναι ότι οι λύσεις των άλλων αποτελούν μια πολύτιμη ευκαιρία μάθησης, και θέλουμε να δώσουμε στους ανθρώπους τη δυνατότητα να κάνουν ερωτήσεις για ιδέες ή τεχνικές που βλέπουν σε λύσεις. Δεν θέλουμε σε καμία περίπτωση αυτό να γίνει ένα δεύτερο στάδιο δημόσιας καθοδήγησης, και γι' αυτό προσθέσαμε μια ειδοποίηση που υπενθυμίζει στους σχολιαστές τον σκοπό του πλαισίου:

![Προειδοποίηση για σχόλια](https://assets.exercism.io/blog/introducing-community-comments-warning.png)

Ξέρουμε επίσης ότι πολλοί χρήστες **δεν** θέλουν να μπορούν οι άλλοι να σχολιάζουν τις λύσεις τους. Μπορεί να θέλουν ακόμα να τις κάνουν δημόσιες, αλλά δεν θέλουν τις επιπλέον αλληλεπιδράσεις, ή την "ακαταστασία" τού να έχουν άλλοι τις σκέψεις τους πάνω στη δουλειά που εκθέτουν. Γι' αυτό προσθέσαμε μια επιλογή για να ενεργοποιείς ή να απενεργοποιείς τα σχόλια ανά λύση, στην οποία έχεις πρόσβαση μέσω της επιλογής "Διαχείριση δημόσιων λύσεων" στο προφίλ σου. Για να γίνει αυτό πιο γρήγορο, προσθέσαμε μια γενική επιλογή για να ορίζεις μια προεπιλογή για τις νέες λύσεις. Την επόμενη φορά που θα συνδεθείς, θα δεις ένα αναδυόμενο παράθυρο που θα σε ρωτάει τι θα ήθελες να ορίσεις ως προεπιλογή:

![Γενική επιλογή σχολιασμού](https://assets.exercism.io/blog/introducing-community-comments-option.png)

Παράλληλα, αντικαταστήσαμε τις "αντιδράσεις" που λανσάραμε πέρυσι με ένα πιο απλοποιημένο σύστημα αστεριών. Αν δεις μια λύση που σου αρέσει, μπορείς να της βάλεις γρήγορα ένα αστέρι (πάνω δεξιά της σελίδας) και τότε θα εμφανιστεί στη σελίδα "Λύσεις με αστέρι", στην οποία έχεις πρόσβαση από το κύριο μενού, κάτω από το άβατάρ σου. Αρχικά είχαμε παρουσιάσει αυτή τη δυνατότητα ως έναν ενδιαφέροντα τρόπο να ομαδοποιούνται οι λύσεις με βάση τις αντιδράσεις διαφορετικών ανθρώπων, αλλά τώρα έχουμε πιο εκτεταμένα σχέδια για να ομαδοποιούμε τις λύσεις χρησιμοποιώντας στατική ανάλυση του κώδικα, και έτσι αποφασίσαμε να αποσύρουμε αυτή τη δυνατότητα και να απλοποιήσουμε την εμπειρία του χρήστη.

Μπορείς να βρεις τις λύσεις των άλλων μέσω του συνδέσμου "Προβολή λύσεων κοινότητας" αφού ολοκληρώσεις την καθοδήγηση σε μια Βασική Άσκηση, ή αφού υποβάλεις μια Δευτερεύουσα Άσκηση. Πρόσεξε κάτι σαν αυτό:

![Σύνδεσμος προς τις λύσεις της κοινότητας](https://assets.exercism.io/blog/introducing-community-comments-link.png)

Ελπίζουμε να απολαύσεις πολύ τις λύσεις της κοινότητας και να ωφεληθείς μαθαίνοντας από τη δουλειά των άλλων. Αν αντιμετωπίσεις οποιοδήποτε πρόβλημα, άνοιξε ένα ζήτημα στη [σελίδα ζητημάτων μας στο GitHub](https://github.com/exercism/exercism). Ευχαριστούμε για την ανάγνωση!
