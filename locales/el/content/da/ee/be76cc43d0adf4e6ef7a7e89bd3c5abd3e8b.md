# Οδηγίες

Η σεζόν του netball τελείωσε και η κατάταξη αποφασίζει ποιοι παίζουν στους τελικούς.

Το υπόδειγμα σού δίνει μια κλάση `TEAM`. Γράψε το `FINALS_LADDER` κάτω από αυτή.

## 1. Ποιος είναι πάνω από ποιον;

Το `higher` παίρνει δύο ομάδες και απαντά αν η πρώτη πρέπει να μπει πάνω από τη
δεύτερη. Πρώτη μπαίνει η ομάδα με τους περισσότερους βαθμούς. Οι ομάδες που
ισοβαθμούν χωρίζονται με βάση τη διαφορά τερμάτων, με τη μεγαλύτερη πρώτη.

```sather
FINALS_LADDER::higher(#TEAM("Vixens", 24, 40), #TEAM("Magpies", 20, 90))
-- => true
```

## 2. Η κατάταξη

Το `ladder` παίρνει τις ομάδες με οποιαδήποτε σειρά και τις απαντά
ταξινομημένες. Ο πίνακας που δίνεται πρέπει να μείνει όπως ήταν.

```sather
FINALS_LADDER::ladder(teams)
-- => the same teams, best first
```

## 3. Διάβασε την κατάταξη

Το `names` παίρνει έναν πίνακα με ομάδες και απαντά τα ονόματά τους ενωμένα
με `", "`.

```sather
FINALS_LADDER::names(FINALS_LADDER::ladder(teams))
-- => "Vixens, Magpies, Swifts"
```

## 4. Οι πρωταθλητές

Το `premiers` παίρνει τις ομάδες με οποιαδήποτε σειρά και απαντά το όνομα της
ομάδας στην κορυφή. Όταν δεν υπάρχει καμία ομάδα, η απάντηση είναι `""`.

```sather
FINALS_LADDER::premiers(teams)
-- => "Vixens"
```

## 5. Μια εντελώς διαφορετική σειρά

Το `shortest_first` παίρνει έναν πίνακα από συμβολοσειρές και τις απαντά
ταξινομημένες κατά μήκος, με τη μικρότερη πρώτη. Οι συμβολοσειρές με το ίδιο
μήκος μπαίνουν σε αλφαβητική σειρά.

```sather
FINALS_LADDER::shortest_first(|"Magpies", "Vixens", "Swifts"|)
-- => "Swifts", "Vixens", "Magpies"
```

Το κριτήριο ισοπαλίας δεν είναι διακοσμητικό. Η ταξινόμηση δεν είναι σταθερή,
οπότε χωρίς αυτό δύο ονόματα με το ίδιο μήκος θα μπορούσαν να βγουν με
οποιαδήποτε σειρά.

Αυτή είναι η ίδια ρουτίνα ταξινόμησης όπως στην εργασία 2, με διαφορετικό
κανόνα να της δίνεται. Αυτό είναι το νόημα της άσκησης.
