# Σχετικά

Το `<iota>` της Factor παράγει μια *εικονική* ακολουθία από τους ακέραιους
`0, 1, …, n-1`. Αν τη διατρέξεις με το `map`, παίρνεις μια πινακοποιημένη
ακολουθία όπου κάθε στοιχείο είναι συνάρτηση της θέσης του:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Δύο κομμάτια σου επιτρέπουν να μετατρέψεις μια ακολουθία ακέραιων κωδικών σε
συμβολοσειρά:

| λέξη      | ρόλος                                                   |
|-----------|---------------------------------------------------------|
| `CHAR:`   | literal κατά τον χρόνο ανάλυσης που βάζει στη στοίβα το σημείο κώδικα ενός χαρακτήρα |
| `>string` | μετατρέπει μια ακολουθία σημείων κώδικα σε συμβολοσειρά  |

Συνδυασμένα, σχηματίζουν το καθιερωμένο ιδίωμα για να χτίζεις μια σειρά
χαρακτήρων με βάση τη θέση:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Η επιλογή του χαρακτήρα με `if` (ή `?`) μέσα στο quotation κρατά την απόφαση
για κάθε θέση κοντά στη θέση από την οποία εξαρτάται.
