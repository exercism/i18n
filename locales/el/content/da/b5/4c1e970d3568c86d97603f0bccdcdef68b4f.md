# Break, Continue

Όταν χρησιμοποιείς μια δομή ελέγχου με βρόχο ή επανάληψη, οι λέξεις-κλειδιά `break` και `continue` μπορούν να σε βοηθήσουν να ελέγξεις τη ροή ενός προγράμματος.
Η λέξη-κλειδί `break` βγαίνει από το πλαίσιο του βρόχου στην εξωτερική εμβέλεια, τερματίζοντας έτσι τον βρόχο.
Η λέξη-κλειδί `continue` παραλείπει το υπόλοιπο της τρέχουσας επανάληψης και ξεκινά ξανά το πλαίσιο του βρόχου από την αρχή της επόμενης επανάληψης.
Αν και σπάνιο, μπορεί να δοθεί ένας αριθμός μαζί με τη λέξη-κλειδί, για να ορίσεις από πόσα πλαίσια θα βγεις ή σε ποιο επίπεδο θα μεταβείς στην επόμενη επανάληψη.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Στο προηγούμενο παράδειγμα, το `continue` εκτελείται πέντε (5) φορές, αλλά στην έκτη (6) επανάληψη εκτελείται το `break`, με αποτέλεσμα ο κώδικας να βγει από τον βρόχο.
