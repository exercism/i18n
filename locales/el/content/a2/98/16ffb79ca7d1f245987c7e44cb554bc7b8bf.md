# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

* Πρέπει να προσθέσεις μια νέα καταχώριση στον πίνακα `lasagna` με κλειδί `oven_time` και τον αναμενόμενο χρόνο ψησίματος σε λεπτά.
* Η τιμή πρέπει να είναι αριθμός.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

* Πρέπει να γράψεις το σώμα της συνάρτησης `remaining_oven_time`.
* Πρέπει να επιστρέψεις έναν αριθμό.
* Μπορείς να χρησιμοποιήσεις τον [αριθμητικό τελεστή](https://www.lua.org/manual/5.4/manual.html#3.4.1) για αφαίρεση.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

* Πρέπει να γράψεις το σώμα της συνάρτησης `preparation_time`.
* Πρέπει να επιστρέψεις έναν αριθμό.
* Μπορείς να χρησιμοποιήσεις τον [αριθμητικό τελεστή](https://www.lua.org/manual/5.4/manual.html#3.4.1) για πολλαπλασιασμό.

## 4. Υπολόγισε τον χρόνο εργασίας που έχει περάσει σε λεπτά

* Πρέπει να γράψεις το σώμα της συνάρτησης `elapsed_time`.
* Πρέπει να επιστρέψεις έναν αριθμό.
* Μπορείς να [καλέσεις](https://www.lua.org/manual/5.4/manual.html#3.4.10) μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
* Μπορείς να χρησιμοποιήσεις τον [αριθμητικό τελεστή](https://www.lua.org/manual/5.4/manual.html#3.4.1) για πρόσθεση.
