# Οδηγίες

Θα γράψεις κώδικα για να σε βοηθήσει να μαγειρέψεις μια λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με το μαγείρεμα της συνταγής σου.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη μεταβλητή `$Lasagna::ExpectedMinutesInOven` με τον αριθμό των λεπτών που πρέπει να μείνει η λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```perl
$Lasagna::ExpectedMinutesInOven
# => 40
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Τροποποίησε την υπορουτίνα `Lasagna::remaining_minutes_in_oven`, η οποία παίρνει ως όρισμα τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο, ώστε να επιστρέφει πόσα λεπτά πρέπει να παραμείνει ακόμα η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```perl
Lasagna::remaining_minutes_in_oven(30)
# => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Τροποποίησε την υπορουτίνα `Lasagna::preparation_time_in_minutes`, η οποία παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια, ώστε να επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```perl
Lasagna::preparation_time_in_minutes(2)
# => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Τροποποίησε την υπορουτίνα `Lasagna::total_time_in_minutes` που παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο.
Η υπορουτίνα πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο τη δεδομένη στιγμή.

```perl
Lasagna::total_time_in_minutes(3, 20)
# => 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

Τροποποίησε την υπορουτίνα `Lasagna::oven_alarm`, η οποία δεν παίρνει κανένα όρισμα, ώστε να επιστρέφει ένα μήνυμα που να δείχνει ότι η λαζάνια είναι έτοιμη για φάγωμα.

```perl
Lasagna::oven_alarm()
# => "Ding!"
```
