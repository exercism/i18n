# Εκτέλεση των tests

## Κατέβασε μια άσκηση

Χρησιμοποίησε το [Exercism CLI][cli] για να κατεβάσεις την άσκηση με την οποία θέλεις να ασχοληθείς.

```sh
exercism download --track=dart --exercise=hello-world
```

Έπειτα, πήγαινε στον κατάλογο της άσκησης.

```sh
cd /path/to/exercism/dart/hello-world
```

## Εγκατέστησε τις εξαρτήσεις

Πριν τρέξεις τα tests, κατέβασε τις εξαρτήσεις της άσκησης.

```sh
dart pub get
```

## Τρέξε τα tests

```sh
dart test
```

## Κατανόηση των αποτελεσμάτων των tests

Το `dart test` χρησιμοποιεί από προεπιλογή τον compact reporter, εμφανίζοντας σε μία γραμμή ένα συνεχώς ενημερωμένο πλήθος από tests που πέρασαν, παραλείφθηκαν και απέτυχαν.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect

To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
```

## Δουλεύοντας με τα tests

Οι περισσότερες ασκήσεις έχουν πολλά tests, και όλα εκτός από το πρώτο παραλείπονται από προεπιλογή.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Για να δουλέψεις τα tests ένα-ένα, άλλαξε το `skip: true` σε `skip: false` σε κάθε test καθώς προχωράς. Εναλλακτικά, τρέξε όλα τα tests ταυτόχρονα χωρίς να επεξεργαστείς το αρχείο.

```sh
dart test --run-skipped
```

Όλα τα tests εκτελούνται από τον διαδικτυακό test runner κατά την υποβολή, συμπεριλαμβανομένων και των παραλειπόμενων.
