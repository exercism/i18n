# Δοκιμές

Μπορείς να τρέξεις τις δοκιμές εκτελώντας την παρακάτω εντολή στον κατάλογο της άσκησης:

```bash
dub test
```

## Περνώντας τις Δοκιμές

Κάνε την πρώτη δοκιμή να μεταγλωττιστεί, να συνδεθεί και να περάσει ακολουθώντας τους [τρεις κανόνες της ανάπτυξης καθοδηγούμενης από δοκιμές](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd).
Δημιούργησε την ελάχιστη απαραίτητη δομή δηλώνοντας χώρους ονομάτων, συναρτήσεις, κλάσεις κ.λπ., ώστε να εξαλείψεις τυχόν σφάλματα μεταγλώττισης και να κάνεις τη δοκιμή να αποτύχει. Στη συνέχεια, γράψε τον ελάχιστο απαραίτητο κώδικα για να περάσει η δοκιμή. Αφού το κάνεις αυτό, αφαίρεσε το σχόλιο από την επόμενη δοκιμή μετακινώντας την παρακάτω γραμμή μετά την επόμενη δοκιμή.

```D
static if (all_tests_enabled)
```

Αυτό μπορεί να προκαλέσει σφάλματα μεταγλώττισης, καθώς μπορεί να χρησιμοποιηθούν νέες δομές που δεν έχεις ακόμη δηλώσει ή ορίσει. Και πάλι, διόρθωσε τα σφάλματα μεταγλώττισης στο ελάχιστο για να έχεις μια αποτυχημένη δοκιμή, μετά άλλαξε τον κώδικα στο ελάχιστο για να περάσει η δοκιμή, αναδιαμόρφωσε την υλοποίησή σου για αναγνωσιμότητα και εκφραστικότητα και μετά προχώρησε στην επόμενη δοκιμή.

Προσπάθησε να χρησιμοποιείς τις τυπικές δυνατότητες της D αντί να γράφεις με το χέρι τους δικούς σου αλγορίθμους ή βοηθητικά μέσα χαμηλού επιπέδου.
