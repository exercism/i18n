# Σχετικά

Το `Enum` είναι μια πολύ χρήσιμη μονάδα που προσφέρει ένα σύνολο αλγορίθμων για την εργασία με enumerables. Προσφέρει:

- ταξινόμηση ([`sort/2`][enum-sort/2], [`sort_by/2`][enum-sort_by/2]),
- φιλτράρισμα ([`filter/2`][enum-filter/2]),
- ομαδοποίηση ([`group_by/3`][enum-group_by/3]),
- καταμέτρηση ([`count/2`][enum-count/2])
- αναζήτηση ([`find/3`][enum-find/3]),
- εύρεση ελάχιστης/μέγιστης τιμής ([`min/3`][enum-min/3], [`max/3`][enum-max/3]),
- αναγωγή ([`reduce/3`][enum-reduce/3], [`reduce_while/3`][enum-reduce_while/3]),

Και πολλά άλλα! Ανατρέξε στην [τεκμηρίωση της μονάδας `Enum`][enum-functions] για την πλήρη λίστα.

## Enumerable

Γενικά, ένα _enumerable_ είναι κάθε δεδομένο πάνω στο οποίο μπορούμε να κάνουμε επανάληψη, δηλαδή μια συλλογή. Στην Elixir, ένα enumerable είναι κάθε τύπος δεδομένων που υλοποιεί το πρωτόκολλο `Enumerable` [protocol][exercism-protocols]. Αυτοί είναι:

- [`List`][list]
- [`Map`][map]
- [`Range`][range]
- [`Stream`][stream]
- [`MapSet`][mapset]
- [`Function`][function]
- [`Date.Range`][date-range]
- [`IO.Stream`][io-stream]
- [`File.Stream`][file-stream]

Μην ανησυχείς αν δεν τα ξέρεις όλα ακόμα.

Ο καθένας μπορεί να υλοποιήσει το πρωτόκολλο `Enumerable` για τη δική του προσαρμοσμένη δομή δεδομένων.

## Reduce

Το `Enum.reduce/2` σου επιτρέπει να _ανάγεις_ ολόκληρο το enumerable σε μία μόνο τιμή. Για να το πετύχεις αυτό, χρησιμοποιείται μια ειδική μεταβλητή που ονομάζεται _συσσωρευτής_. Ο συσσωρευτής μεταφέρει την ενδιάμεση κατάσταση της αναγωγής ανάμεσα στις επαναλήψεις. Αυτό το κάνει μία από τις πιο ισχυρές συναρτήσεις για τα enumerables. Πολλές άλλες εξειδικευμένες συναρτήσεις θα μπορούσαν να αντικατασταθούν από τη γενικότερη `reduce`. Για παράδειγμα...

Εύρεση της μέγιστης τιμής:

```elixir
Enum.max([4, 20, 31, 9, 2])
# => 31

Enum.reduce([4, 20, 31, 9, 2], nil, fn x, acc ->
  cond do
    acc == nil -> x
    x > acc -> x
    x <= acc -> acc
  end
end)

# => 31
```

Ακόμα και αντιστοίχιση (αλλά χρειάζεται να αντιστρέψεις το αποτέλεσμα μετά):

```elixir
Enum.map([1, 2, 3, 4, 5], fn x -> x + 10 end)
# => [11, 12, 13, 14, 15]

Enum.reduce([1, 2, 3, 4, 5], [], fn x, acc -> [x + 10 | acc] end)
# => [15, 14, 13, 12, 11]
```

## Αντιστοίχιση map

- Με [`Map.new/2`][map-new]:
  ```elixir
  %{a: 1, b: 2}
  |> Map.new(fn {key, value} -> {key, value * 10} end)
  ```

- Με [`Enum.into/3`][enum-into]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.into(%{}, fn {key, value} -> {key, value * 10} end)
  ```

- Με [`Enum.map/2`][enum-map]:
  ```elixir
  %{a: 1, b: 2}
  |> Enum.map(fn {key, value} -> {key, value * 10} end)
  |> Enum.into(%{})
  ```
