# Σχετικά

Το PowerShell είναι μια δυναμική και έμμεσα τυποποιημένη (_υποστηρίζει όμως και [ισχυρά τυποποιημένες][strong typed] μεταβλητές_) γλώσσα σεναρίων από τη Microsoft, με κύρια έμφαση στην αυτοματοποίηση εργασιών και τη διαχείριση ρυθμίσεων.

Το PowerShell υποστηρίζει προστακτικό, συναρτησιακό, αντικειμενοστρεφή, ακόμη και προγραμματισμό σε στυλ pipeline.

Το PowerShell χτίστηκε πάνω στην πλατφόρμα .NET και κυκλοφόρησε για πρώτη φορά το 2006.
Περιλαμβάνεται από προεπιλογή σε όλα τα σύγχρονα λειτουργικά συστήματα Windows και μπορεί επίσης να εγκατασταθεί σε Mac και Linux.


## Μεταβλητές

Υπάρχουν δύο συνηθισμένοι τρόποι για να ορίσεις μια μεταβλητή στο PowerShell.

Τα ονόματα μεταβλητών στο PowerShell πρέπει να ξεκινούν με `$` και χρησιμοποιούν τον τελεστή ανάθεσης `=` για να συνδέσουν το όνομα της μεταβλητής με μια τιμή.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Μπορείς επίσης να ορίσεις ρητά τον τύπο μιας μεταβλητής, αν θέλεις να επιβάλεις/απαιτήσεις η τιμή να είναι συγκεκριμένου τύπου.
Το PowerShell θα κάνει ό,τι καλύτερο μπορεί για να μετατρέψει την τιμή από τον έναν τύπο στον άλλο, αν αυτό είναι δυνατό.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Σταθερές

Οι σταθερές στο PowerShell είναι μεταβλητές που δεν μπορούν να **αλλάξουν** ούτε να **αφαιρεθούν** μετά τον ορισμό τους.
Αυτό μας οδηγεί στον δεύτερο τρόπο ορισμού μεταβλητών: χρησιμοποιώντας το cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Συναρτήσεις

Οι συναρτήσεις στο PowerShell ορίζονται με τη λέξη-κλειδί `function`.
Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες τυπικές παραμέτρους μέσα σε παρενθέσεις `()`, και ακολουθεί το σώμα της συνάρτησης, που ξεκινά με `{` και τελειώνει με `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Οι συναρτήσεις στο PowerShell μπορούν να επιστρέφουν τιμές ρητά μέσω της λέξης-κλειδιού `return`, αφού κληθούν με τη σύνταξη `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Σχόλια

Τα σχόλια μιας γραμμής στο PowerShell ξεκινούν με `#` και τελειώνουν στο τέλος της γραμμής.
Τα μπλοκ σχολίων στο PowerShell ξεκινούν με `<#` και τελειώνουν με `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
