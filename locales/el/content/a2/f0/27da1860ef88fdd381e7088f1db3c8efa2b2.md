# Μάθηση

## Μαθαίνοντας C από το μηδέν

Γενικά, το Exercism υποθέτει ότι γνωρίζεις ήδη τη σύνταξη και τους μηχανισμούς μιας γλώσσας σε μια συγκεκριμένη διαδρομή.
Ωστόσο, η γνώση της σύνταξης μιας γλώσσας είναι μόνο το πρώτο βήμα για να αποκτήσεις εξειδίκευση σε αυτή.
Το Exercism σου επιτρέπει να εξασκηθείς στη λύση προβλημάτων και να ανταλλάξεις απόψεις με άλλους προγραμματιστές που έχουν λύσει το ίδιο πρόβλημα.
Μέσα από αυτή την κοινή συζήτηση αποκτάμε εμπειρία και διορατικότητα για να γίνουμε καλύτεροι προγραμματιστές.

Αν μόλις τώρα ξεκινάς με τη γλώσσα C, καλό είναι να αφιερώσεις πρώτα χρόνο για να μάθεις τα βασικά της.
Ορίστε μερικοί πόροι που μπορούν να σε βοηθήσουν να ξεκινήσεις:

* [Learn C][]
* [CS50x][]

Το [CodeChef][] είναι μια απλή φόρμα στο web για έναν μεταγλωττιστή C, που σου επιτρέπει να δοκιμάσεις μικρά προγράμματα.
Μερικές φορές αυτός μπορεί να είναι ένας ευκολότερος τρόπος για ένα γρήγορο πείραμα από το να στήσεις κάτι τοπικά σε ένα ολοκληρωμένο περιβάλλον ανάπτυξης.

## Ανάπτυξη καθοδηγούμενη από τεστ στη C

Το Exercism υποθέτει ότι είσαι εξοικειωμένος με την έννοια της ανάπτυξης καθοδηγούμενης από τεστ.
Κάθε άσκηση συνοδεύεται από μια σειρά τεστ που είναι ήδη γραμμένα για σένα.
Προχωράς στην άσκηση ένα τεστ τη φορά, γράφοντας σταδιακά μια υλοποίηση που να ικανοποιεί τα τεστ.

Αν είσαι νέος στην ανάπτυξη καθοδηγούμενη από τεστ, συνιστάται να δουλέψεις πρώτα πάνω σε μια [γρήγορη επισκόπηση κάποιων πλαισίων εργασίας για τεστ στη C][test-frameworks] ή να διαβάσεις το βιβλίο [Test-Driven Development for Embedded C][tdd] του James Grenning.
Αυτοί οι πόροι καλύπτουν το [Unity][] και το [CppUTest][]; αυτή η διαδρομή χρησιμοποιεί το Unity.
