# ΕΚΜΑΘΗΣΗ

Το Vim έρχεται ήδη με εξαιρετική τεκμηρίωση ενσωματωμένη. Η πρόσβαση στην
τεκμηρίωση γίνεται με την εντολή `:help`.

Για μια εισαγωγή, δες το `:h user-manual`.

Σχεδόν όλες οι εγκαταστάσεις του Vim περιλαμβάνουν επίσης ένα διαδραστικό φροντιστήριο:

```
$ vimtutor
```

Το Vim μετράει δεκαετίες και παραμένει δημοφιλές. Θα βρεις πολλούς πόρους γι' αυτό
στο διαδίκτυο, άλλους καλύτερους από άλλους. Οι καλοί αναφέρονται
[εδώ](https://exercism.org/docs/tracks/vimscript/resources).
