# Προσαρμοσμένοι επαναλήπτες

```sather
   markers!(once spacing : INT, once count : INT) : INT is
      loop
         yield spacing * 1.upto!(count);
      end;
   end;
```

| | ρουτίνα | επαναλήπτης |
| --- | --- | --- |
| όνομα | `foo` | `foo!` |
| επιστρέφει μια τιμή | `return` | `yield` |
| ολοκληρώνεται | `return`, ή το τέλος | `quit`, ή όταν εξαντληθεί |
| μπορεί να κληθεί | οπουδήποτε | μόνο μέσα σε έναν `loop` |
| κρατά τη θέση του | όχι | ναι |

## yield

Το `yield` παραδίδει μια τιμή και αναστέλλεται. Τα πάντα αποκαθίστανται στην επόμενη επανάληψη: οι τοπικές μεταβλητές, η θέση μέσα στους βρόχους του ίδιου του επαναλήπτη και οι θέσεις οποιωνδήποτε επαναληπτών καλεί ο ίδιος.

Ένα `yield` μέσα σε εμφωλευμένους βρόχους συνεχίζει από τον πιο εσωτερικό, και αυτό είναι που κάνει απλή τη συγγραφή μιας διάσχισης πάνω σε κάτι εμφωλευμένο:

```sather
   all_cells!(grid : ARRAY{ARRAY{INT}}) : INT is
      loop
         row ::= grid.elt!;
         loop
            yield row.elt!;
         end;
      end;
   end;
```

## quit

Τερματίζει τον επαναλήπτη, άρα και τον βρόχο που τον καλεί. Δεν μεταφέρει καμία τιμή: ένα `quit` δεν είναι ένα τελευταίο αποτέλεσμα, είναι η αναγγελία ότι δεν υπάρχουν άλλα.

Ένας επαναλήπτης με τύπο επιστροφής πρέπει να αποδίδει μια τιμή σε κάθε `yield`· το `quit` είναι ο τρόπος με τον οποίο αρνείται να το κάνει.

## once

```sather
   markers!(once count : INT) : INT is
```

Ένα όρισμα `once` αξιολογείται όταν αρχίζει ο βρόχος και διατηρείται. Ένα απλό όρισμα επαναξιολογείται σε κάθε επανάληψη, κάτι που έχει σημασία όταν η έκφραση που περνιέται περιέχει κλήση άλλου επαναλήπτη:

```sather
   loop
      #OUT + TRAIL::markers!(sizes.elt!);     -- a new count every turn
   end;
```

Σημείωσε τα ορίσματα ως `once`, εκτός αν θέλεις συγκεκριμένα το αντίθετο. Όλη η βιβλιοθήκη το κάνει.

## self και επαναλήπτες

Ένας επαναλήπτης μπορεί να κληθεί πάνω σε ένα αντικείμενο, και τότε το `self` είναι αυτό το αντικείμενο. Η κατάσταση παύσης του ανήκει στο σημείο κλήσης, όχι στο αντικείμενο, οπότε δύο βρόχοι που διασχίζουν το ίδιο αντικείμενο δεν παρεμβαίνουν ο ένας στον άλλο.

## Πότε να γράψεις έναν

Γράψε έναν επαναλήπτη όταν η απάντηση είναι μια ακολουθία και ο καλών πρέπει να αποφασίσει πόσο από αυτήν θα πάρει. Το να σταματήσεις νωρίς δεν κοστίζει τίποτα, και δεν χτίζεται τίποτα που δεν χρησιμοποιείται, ενώ μια ρουτίνα που επιστρέφει έναν `ARRAY` πρέπει πρώτα να χτίσει ολόκληρο το σύνολό του.
