# Εισαγωγή

Η Haxe υποστηρίζει ανάκλαση τύπων και πεδίων κατά τον χρόνο εκτέλεσης. Για να χρησιμοποιήσεις σωστά την ανάκλαση, πρέπει να καταλάβεις ποιες λειτουργίες υποστηρίζονται και ποιες όχι. Δεδομένης της δυναμικής φύσης της ανάκλασης, αυτό δε μπορεί να προσδιοριστεί πάντα κατά τον χρόνο μεταγλώττισης.

Το API της ανάκλασης αποτελείται από δύο κλάσεις:

- `Reflect`: Ένα ελαφρύ API που λειτουργεί καλύτερα με ανώνυμες δομές, με περιορισμένη υποστήριξη για κλάσεις.
- `Type`: Ένα πιο ισχυρό API για εργασία με κλάσεις και απαριθμήσεις.

Για το παρακάτω παράδειγμα, χρησιμοποιούμε τον στόχο JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
