# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που παρακολουθείς πόσα πουλιά έχουν επισκεφτεί τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις πέντε εργασίες, όλες σχετικές με τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Για λόγους σύγκρισης, κρατάς πάντα δίπλα σου ένα αντίγραφο από τις μετρήσεις της προηγούμενης εβδομάδας, οι οποίες ήταν: 0, 2, 5, 3, 7, 8 και 4. Υλοποίησε τη μέθοδο `BirdCount.last_week` που επιστρέφει τις μετρήσεις της προηγούμενης εβδομάδας:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν χθες

Υλοποίησε τη μέθοδο `BirdCount#yesterday` ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου χθες. Οι μετρήσεις των πουλιών είναι ταξινομημένες ανά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο να είναι η σημερινή μέτρηση.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Υπολόγισε τον συνολικό αριθμό των πουλιών που σε επισκέφτηκαν

Υλοποίησε τη μέθοδο `BirdCount#total` ώστε να επιστρέφει τον συνολικό αριθμό των πουλιών που έχουν επισκεφτεί τον κήπο σου:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Κάποιες ημέρες είναι πιο πολυάσχολες από άλλες. Μια πολυάσχολη ημέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.
Υλοποίησε τη μέθοδο `BirdCount#busy_days` ώστε να επιστρέφει τον αριθμό των πολυάσχολων ημερών:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Έλεγξε αν υπήρξε κάποια ημέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη μέθοδο `BirdCount#day_without_birds?` που επιστρέφει `true` αν υπήρξε κάποια ημέρα κατά την οποία μηδέν πουλιά επισκέφτηκαν τον κήπο. Διαφορετικά, επιστρέφει `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
