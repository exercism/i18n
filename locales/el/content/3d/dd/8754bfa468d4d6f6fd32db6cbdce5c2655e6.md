# Οδηγίες

Το σημειωματάριο ενός ντετέκτιβ γεμίζει όσο προχωράει μια υπόθεση και αδειάζει ξανά
καθώς οι γραμμές έρευνας αποκλείονται.

Και οι πέντε εργασίες μπαίνουν στην κλάση `CASE_NOTES`.

## 1. Άνοιξε μια υπόθεση

Επίστρεψε ένα νέο, άδειο σημειωματάριο.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Γράψε ένα στοιχείο

Πρόσθεσε ένα στοιχείο στο τέλος του σημειωματάριου. Αυτό δεν επιστρέφει τίποτα:
αλλάζει το σημειωματάριο που του δίνεται.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. Πόσα στοιχεία;

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Απέκλεισε ένα

Βγάλε το στοιχείο σε μια θέση από το σημειωματάριο. Ό,τι ακολουθεί μετακινείται
προς τα πάνω. Αυτό επίσης δεν επιστρέφει τίποτα.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Διάβασε ξανά την υπόθεση

Επίστρεψε όλα τα στοιχεία που υπάρχουν στο σημειωματάριο, ενωμένα με `"; "`. Ένα
άδειο σημειωματάριο διαβάζεται ως κενή συμβολοσειρά.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
