# Οδηγίες

Ένα ρομπότ πάρτι κρεμάει γιρλάντες για τη μεγάλη γιορτή. Κάθε σειρά γιρλάντας είναι μια οριζόντια σειρά από `n` μικρές σημαιούλες, και ο χαρακτήρας κάθε σημαιούλας καθορίζεται από τη θέση της στη σειρά, μετρώντας από αριστερά ξεκινώντας από το `0`. Βοήθησε το ρομπότ να συναρμολογήσει τα παρακάτω μοτίβα.

## 1. Αλφαβητική γιρλάντα

Όρισε την `alphabet-bunting` ώστε να παίρνει έναν μη αρνητικό ακέραιο `n` από τη στοίβα και να επιστρέφει μια συμβολοσειρά με τα πρώτα `n` πεζά γράμματα του αλφαβήτου.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Μπορείς να υποθέσεις ότι το `n` είναι το πολύ `26`.

## 2. Γιρλάντα μέτρησης

Όρισε την `counting-bunting` ώστε να παίρνει το `n` και να επιστρέφει μια συμβολοσειρά από `n` ψηφία, όπου η σημαιούλα στη θέση `i` δείχνει το `i mod 10`.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Γιρλάντα με ρίγες

Όρισε τη `stripe-bunting` ώστε να εναλλάσσει δύο χαρακτήρες: οι ζυγές θέσεις παίρνουν `*` και οι μονές θέσεις παίρνουν `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Γιρλάντα με σημάδια

Κάθε πέμπτη σημαιούλα είναι ένα ειδικό σημάδι. Όρισε τη `marker-bunting` ώστε οι θέσεις `0`, `5`, `10`, … να παίρνουν `|` και οι υπόλοιπες να παίρνουν `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Γιρλάντα κοιλάδας

Το ρομπότ κρεμάει μια γιρλάντα σταθερού μεγέθους με 10 σημαιούλες που στερεώνεται σε έναν γάντζο στο κέντρο. Μετρώντας από την αριστερότερη σημαιούλα στη θέση `-5` μέχρι (αλλά χωρίς να συμπεριλαμβάνεται) το `5`, ο χαρακτήρας κάθε σημαιούλας είναι η απόσταση από το κέντρο, γραμμένη ως ψηφίο.

Όρισε τη `valley-bunting` (χωρίς ορίσματα) ώστε να επιστρέφει αυτή τη σταθερή συμβολοσειρά.

```factor
valley-bunting .
! => "5432101234"
```
