# Οδηγίες ειδικά για SQLite

- Η στήλη **matrix** περιέχει την είσοδο, έναν πίνακα από πίνακες ακεραίων κωδικοποιημένο σε JSON.
- Οι στήλες **result** θα πρέπει να περιέχουν την έξοδο, τη λίστα με τα σημεία σέλας.
  Η έξοδος θα πρέπει να είναι ένας πίνακας αντικειμένων κωδικοποιημένος σε JSON. Κάθε αντικείμενο έχει δύο κλειδιά: row και column.
  Για παράδειγμα, `[{"row": 2, "column": 1}]`.
