# χρησιμοποίησε μία εντολή `return`

Αυτή η λύση χρησιμοποιεί πολλαπλές εντολές `return`, αλλά μπορείς να τη γράψεις με μία μόνο `return`.
Σκέψου να χρησιμοποιήσεις έναν [τριμερή τελεστή](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/op2.html) για να χειριστείς την περίπτωση που η είσοδος είναι `null`.
