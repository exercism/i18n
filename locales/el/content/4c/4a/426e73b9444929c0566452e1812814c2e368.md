# μην χρησιμοποιείς εμφωλευμένη εντολή if

Δοκίμασε να ξαναγράψεις τις εντολές if ώστε να αποφύγεις τη βαθιά εμφώλευση, καθώς μπορεί να οδηγήσει σε κώδικα που είναι πιο δύσκολο να ακολουθήσεις. Δες τα παρακάτω δύο κομμάτια κώδικα:

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

Σύγκρινέ το με τον παρακάτω κώδικα:

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

Το δεύτερο παράδειγμα έχει μια πολύ συγκεκριμένη δομή: όλες οι διαδρομές που έχουν να κάνουν με σφάλματα αντιμετωπίζονται μέσα σε μπλοκ με εσοχή, ενώ η "ομαλή διαδρομή" είναι πάντα ευθυγραμμισμένη τέρμα αριστερά. Έτσι, ο κώδικας διαβάζεται πολύ εύκολα, αφού βλέπεις γρήγορα ποια είναι η πιο συνηθισμένη διαδρομή μέσα στον κώδικα, χωρίς σφάλματα.
