# Σχετικά

[Τα cons][hyper-conses] είναι ένας βασικός τύπος δεδομένων στην Common Lisp. Αποτελούνται από ένα κεφάλι και μια ουρά (που για [ιστορικούς λόγους][history] ονομάζονται `car` και `cdr`).
Δεν υπάρχει περιορισμός στους τύπους δεδομένων του κεφαλιού και της ουράς ενός cons.

Τα cons δημιουργούνται με τη συνάρτηση [`cons`][hyper-cons], η οποία παίρνει δύο αντικείμενα και αξιολογείται σε ένα cons (κάποιες φορές αποκαλείται και "cons cell").

Στα μέρη ενός cons μπορείς να έχεις πρόσβαση με τις συναρτήσεις [`car`][hyper-car] και [`cdr`][hyper-cdr].

## Αναφορά

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
