# Εισαγωγή

Πολλά προγράμματα χρειάζονται (ψευδο)τυχαίες τιμές για να προσομοιώσουν γεγονότα του πραγματικού κόσμου.

Συνηθισμένα, οικεία παραδείγματα περιλαμβάνουν:

- Ρίψη νομίσματος: μια τυχαία τιμή από το ('H', 'T').
- Ρίψη ζαριού: ένας τυχαίος ακέραιος από το 1 έως το 6.
- Ανακάτεμα μιας τράπουλας: μια τυχαία διάταξη μιας λίστας καρτών.
- Η δημιουργία δέντρων και θάμνων σε μια προσομοίωση τρισδιάστατων γραφικών.

Το να παράγεις πραγματικά τυχαίες τιμές με έναν υπολογιστή είναι μια [εκπληκτικά δύσκολη τεχνική πρόκληση][why-randomness-is-hard], γι' αυτό υπάρχουν και οι "ψευδοτυχαίοι" γεννήτορες.

## Παραγωγή τυχαίων αριθμών

Στη Javascript, μπορείς να παράγεις ψευδοτυχαίους αριθμούς χρησιμοποιώντας τη συνάρτηση [`Math.random()`][Math.random].
Θα επιστρέψει έναν ψευδοτυχαίο αριθμό κινητής υποδιαστολής μεταξύ του 0 (συμπεριλαμβανομένου) και του 1 (μη συμπεριλαμβανομένου).

Για να πάρεις έναν τυχαίο αριθμό μεταξύ του _min_ (συμπεριλαμβανομένου) και του _max_ (μη συμπεριλαμβανομένου), μπορείς να χρησιμοποιήσεις μια συνάρτηση σαν κι αυτή:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## Παραγωγή τυχαίων ακεραίων

Για να παράγεις έναν τυχαίο ακέραιο, μπορείς να χρησιμοποιήσεις τη `Math.floor()` ή τη `Math.ceil()` για να μετατρέψεις έναν τυχαία παραγόμενο αριθμό σε ακέραιο.
