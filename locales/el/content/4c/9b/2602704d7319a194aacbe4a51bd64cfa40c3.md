# Υποδείξεις

## Γενικά

* Τι θα μπορούσε να κάνει ένας απλούστερος zipper πάνω σε μια (μη κενή) δομή δεδομένων λίστας; Το να αφαιρέσεις έναν βαθμό κίνησης στον zipper μπορεί να βοηθήσει αν κολλήσεις. Ένας zipper πάνω σε μια λίστα θα χρειαζόταν να ασχολείται μόνο με τη μετακίνηση αριστερά, τη μετακίνηση δεξιά και τη λήψη και τον ορισμό ενός στοιχείου στην εστίαση.
* Το `t` στο `Zipper t a` αντιπροσωπεύει τη δομή δεδομένων δυαδικού δέντρου για τις ανάγκες αυτής της άσκησης. Αυτό δίνει στον zipper τη δυνατότητα να κάνει "zip" γύρω από δυνητικά περισσότερες από μία δομές δεδομένων!
