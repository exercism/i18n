# Οδηγίες

Μόλις ξεκίνησες να δουλεύεις στη ρεσεψιόν ενός αναρριχητικού γυμναστηρίου.
Τα μέλη αγοράζουν συνδρομές για έναν ορισμένο αριθμό μηνών και δηλώνουν την είσοδο και την έξοδό τους κάθε φορά που επισκέπτονται το γυμναστήριο.
Ο διευθυντής σού ζήτησε να γράψεις ένα βοηθητικό εργαλείο που απαντά στις ερωτήσεις που κάνουν πιο συχνά τα μέλη.

## 1. Υπολόγισε πότε τελειώνει μια συνδρομή

Μια συνδρομή που ξεκινά σε μια δεδομένη ημερομηνία τελειώνει την ίδια ημέρα του μήνα, τον δεδομένο αριθμό μηνών αργότερα.
Όταν αυτή η ημέρα δεν υπάρχει στον μήνα λήξης, η συνδρομή τελειώνει την τελευταία ημέρα εκείνου του μήνα.

Υλοποίησε τη μέθοδο `FrontDesk.membershipEnd()` που παίρνει την ημερομηνία έναρξης μιας συνδρομής και τον αριθμό των μηνών της, και επιστρέφει την ημερομηνία κατά την οποία τελειώνει:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Δείξε πόσο διαρκεί μια συνδρομή

Στην κάρτα μέλους, το γυμναστήριο εκτυπώνει πόσο διαρκεί η συνδρομή σε χρόνια, μήνες και ημέρες.

Υλοποίησε τη μέθοδο `FrontDesk.membershipLength()` που παίρνει την ημερομηνία έναρξης και την ημερομηνία λήξης μιας συνδρομής, και επιστρέφει τη διάρκεια της συνδρομής ως `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Μέτρησε τις ημέρες που απομένουν σε μια συνδρομή

Τα μέλη ρωτούν συχνά πόσες ημέρες τους απομένουν πριν τελειώσει η συνδρομή τους.

Υλοποίησε τη μέθοδο `FrontDesk.daysLeft()` που παίρνει τη σημερινή ημερομηνία και την ημερομηνία λήξης μιας συνδρομής, και επιστρέφει τον συνολικό αριθμό ημερών από σήμερα μέχρι την ημερομηνία λήξης.
Όταν η ημερομηνία λήξης είναι σήμερα ή έχει ήδη περάσει, δεν απομένει καμία ημέρα, οπότε η μέθοδος επιστρέφει `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Μέτρησε τη διάρκεια μιας επίσκεψης

Το γυμναστήριο είναι ανοιχτό όλο το εικοσιτετράωρο, και ο τουρνικέ καταγράφει την ημερομηνία και την ώρα εισόδου και εξόδου κάθε μέλους.

Υλοποίησε τη μέθοδο `FrontDesk.visitDuration()` που παίρνει την ημερομηνία και ώρα εισόδου και εξόδου μιας επίσκεψης, και επιστρέφει τη διάρκεια της επίσκεψης ως `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Εκτύπωσε μια επίσκεψη στην απόδειξη

Η απόδειξη δείχνει τη διάρκεια μιας επίσκεψης σε ώρες και λεπτά, όπως `1h 35m`.
Τα λεπτά γράφονται πάντα με δύο ψηφία, τυχόν δευτερόλεπτα παραλείπονται, και οι ώρες δεν περιορίζονται σε μία ημέρα.

Υλοποίησε τη μέθοδο `FrontDesk.formatVisit()` που παίρνει τη διάρκεια μιας επίσκεψης και την επιστρέφει σε αυτή τη μορφή:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
