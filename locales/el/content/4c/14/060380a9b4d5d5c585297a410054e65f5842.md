# Εισαγωγή

Μερικές φορές, όταν διατρέχεις μια ακολουθία, χρειάζεσαι τη *θέση* του στοιχείου μαζί με το ίδιο το στοιχείο. Η οικογένεια `*-index` στις [`sequences`][sequences] παραδίδει και τα δύο στην παράθεση για κάθε στοιχείο. Το `times` είναι ο στενός ξάδελφος για απλή επανάληψη με μέτρημα, χρήσιμο όταν χρειάζεσαι μόνο μια καταμέτρηση, όχι μια ακολουθία.

## `each-index` και `map-index`: θέση στην παράθεση

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

Η παράθεση λαμβάνει το στοιχείο κάτω από τη θέση, ενώ το `index` είναι στην **κορυφή** της στοίβας:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

Το `each-index` εκτελεί την παράθεση για την παρενέργειά της και δεν επιστρέφει τίποτα. Το `map-index` συλλέγει τα αποτελέσματα για κάθε στοιχείο σε μια νέα ακολουθία ίδιου τύπου με την είσοδο.

## `times`: επανάληψη με μέτρημα

Το `times` (στο [`math`][math]) εκτελεί την παράθεσή του `n` φορές.

```
times ( n quot: ( -- ) -- )
```

Το δημοσιευμένο σχήμα `( -- )` είναι το *ελάχιστο*, γιατί το `times` είναι `inline`, μια παράθεση με ισορροπημένο αποτέλεσμα όπως `( str -- str )` λειτουργεί μια χαρά, και η στοίβα περνάει από τη μια επανάληψη στην άλλη. Αυτό σου δίνει έναν συσσωρευτή με μέτρημα χωρίς καμία μεταβλητή κατάσταση:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

Το σώμα κάθε επανάληψης βλέπει την τρέχουσα συμβολοσειρά, προσθέτει σε αυτήν και αφήνει τη νέα συμβολοσειρά στη στοίβα για την επόμενη επανάληψη. Το ίδιο κόλπο δουλεύει για το `each-index` και το `map-index` όταν θέλεις να περάσεις έναν συσσωρευτή μέσα από αυτά.
