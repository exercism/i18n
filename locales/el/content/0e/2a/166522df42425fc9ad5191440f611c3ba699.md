# Προσάρτημα οδηγιών

## Δεσμευμένες διευθύνσεις

Ο buffer για την πρώτη συμβολοσειρά χρησιμοποιεί τα byte 1024-2047 της γραμμικής μνήμης.
Ο buffer για τη δεύτερη συμβολοσειρά χρησιμοποιεί τα byte 2048-3071 της γραμμικής μνήμης.

Δεν θα χρειαστεί να τροποποιήσεις αυτούς τους buffer ή να δεσμεύσεις επιπλέον μνήμη.
