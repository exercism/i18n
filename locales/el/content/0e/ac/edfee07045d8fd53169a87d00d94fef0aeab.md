# Εισαγωγή

Η κλάση `str` προσφέρει [πολλές χρήσιμες μεθόδους][str methods] για την εργασία με συμβολοσειρές και τη σύνθεσή τους.
Αυτές περιλαμβάνουν αναζήτηση, καθαρισμό, διαχωρισμό, μετασχηματισμό, μετάφραση και πολλές άλλες τεχνικές.

Οι συμβολοσειρές είναι [ακολουθίες][text sequence] από [σημεία κώδικα Unicode][unicode code points]. Μεμονωμένοι "χαρακτήρες" ή σημεία κώδικα (_συμβολοσειρές μήκους 1_) μπορούν να αναφερθούν με αριθμό `0-based index` από τα αριστερά, ή με αριθμό `-1-based index` από τα δεξιά.
Οι συμβολοσειρές υλοποιούν όλες τις [συνήθεις πράξεις ακολουθίας][common sequence operations].

Μπορείς να τις διατρέξεις χρησιμοποιώντας τη σύνταξη `for item in <str>` ή `for index, item in enumerate(<str>)`.
Μπορείς επίσης να τις συνενώσεις χρησιμοποιώντας `<str> + <other str>` ή `<str>.join(<iterable>)`.

Οι συμβολοσειρές είναι _αμετάβλητες_, που σημαίνει ότι η τιμή ενός αντικειμένου `str` στη μνήμη δεν μπορεί να αλλάξει.
Οι συναρτήσεις ή οι μέθοδοι που επενεργούν σε μια `str` (_όπως αυτές που μαθαίνουμε εδώ_) επιστρέφουν ένα νέο `instance` αυτού του αντικειμένου `str` αντί να τροποποιήσουν την αρχική `str`.

Παρακάτω ακολουθεί μια μικρή επιλογή από μεθόδους συμβολοσειρών της Python.
Για τον πλήρη κατάλογο, δες την [κλάση str][str methods] στην τεκμηρίωση της Python.


[`<str>.title()`][str-title] αναλύει μια συμβολοσειρά και γράφει με κεφαλαίο τον πρώτο "χαρακτήρα" κάθε "λέξης" που βρίσκει.
Στην Python, αυτό εξαρτάται σε μεγάλο βαθμό από τον [κωδικοποιητή γλώσσας][codecs] που χρησιμοποιείται και από το πώς η συγκεκριμένη γλώσσα αναπαριστά λέξεις και χαρακτήρες.
Μπορεί επίσης να ισχύουν κανόνες [τοπικών ρυθμίσεων][locale] για μια γλώσσα ή ένα σύνολο χαρακτήρων.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] επιστρέφει `True` αν η συμβολοσειρά τελειώνει με `<suffix>`, αλλιώς `False`.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] επιστρέφει ένα αντίγραφο της `str` με τα αρχικά και τα τελικά `<chars>` αφαιρεμένα.
Τα σημεία κώδικα που καθορίζονται στο `<chars>` δεν είναι πρόθεμα ή επίθεμα: **όλοι οι συνδυασμοί** των σημείων κώδικα θα αφαιρεθούν ξεκινώντας από **τα δύο άκρα** της συμβολοσειράς.
 Αν δεν καθοριστεί τίποτα για το `<chars>`, θα αφαιρεθούν όλοι οι συνδυασμοί σημείων κώδικα κενού διαστήματος.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] επιστρέφει ένα αντίγραφο της συμβολοσειράς με όλες τις εμφανίσεις του `<substring>` αντικατεστημένες από το `<replacement substring>`.

Το απόσπασμα που χρησιμοποιείται παρακάτω είναι από το [The Hunting of the Snark][The Hunting of the Snark] του [Lewis Carroll][Lewis Carroll]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
