# Introduction

Ένας `Map` χρησιμοποιείται για την αποθήκευση ζευγών **κλειδιού** και **τιμής**. Οι `Maps` αρχικοποιούνται όπως ακριβώς ένας πίνακας, αλλά χρησιμοποιούν τον τελεστή `=>` για τα map literals. Μπορούν επίσης να έχουν τους τύπους κλειδιού-τιμής τους ορισμένους ρητά, ή οι τύποι μπορούν να συναχθούν. Τα κλειδιά πρέπει να είναι μοναδικά, αλλιώς πετιέται ένα σφάλμα.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Μπορείς να διατρέξεις έναν `Map` χρησιμοποιώντας έναν `for` βρόχο. Μπορείς να διατρέξεις είτε τις τιμές είτε τα κλειδιά:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
