# Υποδείξεις

Η χρήση μιγαδικών αριθμών για στροφές σε 2D μπορεί να κάνει τα πράγματα πολύ πιο καθαρά και αριθμητικά πιο ακριβή.

## 1. Κατασκεύασε έναν μιγαδικό αριθμό από καρτεσιανές συντεταγμένες

- Η ενσωματωμένη μέθοδος [`complex(x, y)`][complex] είναι πιο αποδοτική από την ανάθεση `x + im*y`.
- Δες την εισαγωγή για μια ανασκόπηση.

## 2. Κατασκεύασε έναν μιγαδικό αριθμό από πολικές συντεταγμένες

- Υπάρχουν μερικοί ισοδύναμοι τρόποι να το κάνεις αυτό (π.χ. `exp`, `cis`, `cispi`).
- Δες την εισαγωγή και τις οδηγίες για περισσότερη ανασκόπηση.

## 3. Εκτέλεσε μια περιστροφή διανύσματος σε 2D

- Ο [τύπος του Euler][euler] είναι ο φίλος σου εδώ και θα μπορούσες να χρησιμοποιήσεις τη συνάρτησή σου `euler`.
- Υπάρχουν μέθοδοι για να ανακτήσεις το [πραγματικό][real] μέρος και το [φανταστικό][imaginary] μέρος ενός μιγαδικού αριθμού, ή και τα δύο!

## 4. Εκτέλεσε μια ακτινική μετατόπιση

- Η συνάρτησή σου `euler` μπορεί να φανεί χρήσιμη, ή και όχι...
- Η ενσωματωμένη μέθοδος [`angle`][angle] μπορεί να χρησιμοποιηθεί για να βρεις γρήγορα ένα όρισμα από έναν μιγαδικό αριθμό.
- Η μέθοδος [`abs`][abs] μπορεί να χρησιμοποιηθεί για να βρεις το μέτρο ενός μιγαδικού αριθμού.

## 5. Βρες το τραγούδι που θέλεις

- Αυτή είναι μια καλή ευκαιρία να συνθέσεις τις συναρτήσεις σου `rotate` και `rdisplace`.
