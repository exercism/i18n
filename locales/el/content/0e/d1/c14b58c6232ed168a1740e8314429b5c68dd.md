# Τζογκλάρισμα τύπων

Το τζογκλάρισμα τύπων μπορεί επίσης να αναφέρεται και ως εξαναγκασμός τύπων.
Τζογκλάρισμα τύπων έχουμε όταν δύο τιμές διαφορετικών τύπων εξαναγκάζονται στον ίδιο τύπο για να εκτελεστεί μια πράξη.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Αυτό μπορεί να γίνει έμμεσα (δες το παραπάνω παράδειγμα) ή ρητά, με μετατροπή τύπων στο στυλ της `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Οι τύποι που επιτρέπονται για χειροκίνητη μετατροπή τύπων είναι: `bool`, `int`, `float`, `string`, `array`, `object`.
Τις περισσότερες φορές, η μετατροπή τύπων χρησιμοποιείται για να μετατρέψει έναν ακέραιο (`int`) σε αριθμό κινητής υποδιαστολής (`float`) ή το αντίστροφο.
