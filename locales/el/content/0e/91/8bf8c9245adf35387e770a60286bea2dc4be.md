# Σχετικά

Ένας αριθμός κινητής υποδιαστολής είναι ένας αριθμός με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή.
Παραδείγματα είναι τα `4.0`, `0.1`, `3.14`, `-6.4` `16.984025` και `1024.0`.
Στη Ruby, οι αριθμοί κινητής υποδιαστολής υλοποιούνται μέσω της κλάσης [Float][Float].

Μπορείς να βρεις μια σύντομη εισαγωγή στους αριθμούς κινητής υποδιαστολής στο [0.30000000000000004.com][0.30000000000000004.com].

Η [σελίδα Float Toy][evanw.github.io-float-toy] έχει μια ωραία, γραφική εξήγηση του πώς τα bits ενός αριθμού κινητής υποδιαστολής μετατρέπονται σε μια πραγματική τιμή κινητής υποδιαστολής.

Για να εκτελείς κάποια λογική επανειλημμένα, μπορείς να χρησιμοποιήσεις βρόχους.
Σε αυτό το παράδειγμα ο `while` βρόχος είναι χρήσιμος επειδή συνεχίζει να επαναλαμβάνεται _όσο_ μια συνθήκη αποτιμάται σε κάποια τιμή truthy (δηλαδή όχι `false` ή `nil`).
Η Ruby υλοποιεί έναν βρόχο παρόμοιο με τον `while` βρόχο.
Ονομάζεται `until` βρόχος και μάλλον έχεις ήδη μαντέψει τι κάνει.
Συνεχίζει να επαναλαμβάνεται _μέχρι_ να αποτιμηθεί μια boolean συνθήκη σε `true`.
Σε κάποιες γλώσσες, για να εκτελεστεί ένα κομμάτι κώδικα απεριόριστες φορές, χρησιμοποιούνται κατασκευές όπως `while true`.
Στη Ruby, γι' αυτόν τον σκοπό υπάρχει ο `loop` βρόχος.
Αν και ο `loop` βρόχος δεν εξαρτάται από μία μόνο συνθήκη, μπορεί να τερματιστεί χρησιμοποιώντας τη λέξη-κλειδί `return` ή `break`.

Η μέθοδος `#years_before_desired_balance` από την προηγούμενη άσκηση θα μπορούσε να είχε γραφτεί χρησιμοποιώντας οποιονδήποτε από τους τρεις βρόχους που αναφέραμε:

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

Όπως θα έχεις ήδη προσέξει, η Ruby δεν έχει τελεστή αύξησης (`i++`) όπως κάποιες άλλες γλώσσες.
Αντ' αυτού, μπορούν να χρησιμοποιηθούν κατασκευές όπως το `i += 1` (που είναι ίσο με το `i = i + 1`).
