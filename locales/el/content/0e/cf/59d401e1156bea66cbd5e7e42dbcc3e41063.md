# Εισαγωγή

Μπορείς να προσπελάσεις μεμονωμένους χαρακτήρες σε ένα `String` χρησιμοποιώντας τη μέθοδο δείκτη που χρησιμοποιείται και στους πίνακες.
Ωστόσο, οι [θέσεις][string-indices] που χρησιμοποιούνται για συμβολοσειρές _δεν_ είναι ακέραιοι αριθμοί και δεν μπορείς να δουλέψεις απευθείας με αυτές.
Αντ' αυτού, πρέπει να υπολογιστούν με βάση κάποια άλλη γνωστή θέση, όπως η `startIndex`, η οποία δείχνει το σημείο όπου βρίσκεται ο πρώτος χαρακτήρας σε μια μη κενή συμβολοσειρά, χρησιμοποιώντας τις μεθόδους που υπάρχουν στις βιβλιοθήκες [`String`][string-docs] και [`NSString`][nsstring-docs] (όταν εισάγεται το module `Foundation`, οι συμβολοσειρές στη Swift έχουν πρόσβαση σε όλες τις ιδιότητες και τις μεθόδους του NSString).

Για παράδειγμα, δεδομένης της παρακάτω συμβολοσειράς:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Δεν μπορείς να γράψεις `csv[21]` για να πάρεις το "g" από το "orange", αλλά πρέπει να υπολογίσεις μια τιμή τύπου `String.Index` και να δώσεις αυτή τη θέση.
Σημείωσε ότι αυτές οι θέσεις δεν προορίζονται να είναι καταναλώσιμες από τον άνθρωπο από μόνες τους.
Είναι αυτό που ονομάζεται _αδιαφανείς θέσεις_, καθώς ο άνθρωπος δεν χρειάζεται να ξέρει τι περιέχουν.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Πρόσεξε, ωστόσο, ότι αν η μετατόπιση δεν είναι έγκυρη θέση, δηλαδή αν θα επέστρεφε τη θέση πριν από το `startIndex` ή μετά το `endIndex`, η πράξη θα πετάξει ένα σφάλμα και θα κρασάρει το πρόγραμμα.
Για να αποφύγεις αυτό το πρόβλημα, μπορείς να ορίσεις μια θέση περιορισμού.
Αυτό επιστρέφει μια προαιρετική θέση και θα επιστρέψει nil για θέσεις που θα ήταν άκυρες.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Επιπλέον, οι θέσεις δεν μπορούν να μοιράζονται μεταξύ συμβολοσειρών.
Για παράδειγμα, αν χρησιμοποιήσεις το `index` του "g" στο "orange" που υπολόγισες παραπάνω για να προσπελάσεις τη συμβολοσειρά `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, δηλαδή `fam[index]`, το πρόγραμμά σου θα κρασάρει.

Υπάρχουν πολλοί λόγοι για όλα αυτά, αλλά όλοι βασικά συνοψίζονται στο ότι "το Unicode είναι μπερδεμένο".

Γενικά, αν χρειάζεσαι τυχαία πρόσβαση σε μεμονωμένους χαρακτήρες, μάλλον θέλεις να χρησιμοποιήσεις κάποια άλλη δομή δεδομένων, όπως τον `Array<Character>`.

## Κάποιες χρήσιμες μέθοδοι

Η Swift έχει τις μεθόδους `first` και `last` για να πάρεις τον πρώτο και τον τελευταίο χαρακτήρα μιας συμβολοσειράς.
Αυτές οι μέθοδοι επιστρέφουν έναν προαιρετικό χαρακτήρα, οπότε αν η συμβολοσειρά είναι κενή, θα επιστρέψουν nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Μπορείς επίσης να χρησιμοποιήσεις τις μεθόδους `prefix` και `suffix` για να πάρεις ένα τμήμα μιας συμβολοσειράς.
Αυτές οι μέθοδοι παίρνουν έναν ακέραιο ως όρισμα και επιστρέφουν μια υποσυμβολοσειρά που περιέχει τους πρώτους ή τους τελευταίους n χαρακτήρες της συμβολοσειράς.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
