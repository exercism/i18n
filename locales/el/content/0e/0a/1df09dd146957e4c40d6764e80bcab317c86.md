# Εισαγωγή

Ένα *tuple* συγκεντρώνει αρκετές ονομασμένες τιμές σε ένα αντικείμενο, αυτό που άλλες γλώσσες το λένε καταγραφή, struct ή κλάση. Κάθε κλάση tuple έχει ένα σταθερό σύνολο από ονομασμένα slots και ο Factor δημιουργεί αυτόματα getters και setters γι' αυτά.

## Ορισμός ενός tuple

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Κάθε slot δηλώνεται `{ name initial: default-value }`. Χωρίς ρήτρα `initial:`, η προεπιλεγμένη τιμή είναι `f`.

## Κατασκευή ενός tuple

Ο πιο απλός κατασκευαστής είναι το `new`:

```factor
point new .
! => T{ point }
```

Το `boa` ("by order of arguments") γεμίζει τα slots με τη σειρά δήλωσης από τη στοίβα δεδομένων:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

Η κυριολεκτική σύνταξη `T{ class { slot value } … }` σου επιτρέπει να κατασκευάσεις ένα tuple με ένα υποσύνολο από τα slots του ορισμένα, και εκτυπώνεται με τον ίδιο τρόπο:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Όταν η τιμή ενός slot ταιριάζει με την προεπιλεγμένη τιμή του, ο εκτυπωτής το παραλείπει.

## Ανάγνωση ενός slot

Ο Factor δημιουργεί έναν getter `slot>>` για κάθε slot. Οι getters βρίσκονται στο [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Ενημέρωση ενός slot

Οι setters γράφονται `>>slot` και *μεταλλάσσουν* το tuple επί τόπου:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Για να αφήσεις το αρχικό ανέπαφο, κάνε πρώτα `clone`:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

Το `change-slot` παίρνει ένα quotation που αντιστοιχίζει την τρέχουσα τιμή στη νέα:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

Το `change-x` μεταλλάσσει κι αυτό, οπότε κάνε `clone` πριν το καλέσεις αν θέλεις να διατηρήσεις το αρχικό.
