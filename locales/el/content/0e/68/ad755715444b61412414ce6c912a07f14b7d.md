# Εισαγωγή

Οι τριαδικοί τελεστές επιτρέπουν να ορίζονται συνθήκες if μέσα σε εκφράσεις αντί για μπλοκ εντολών. Αυτό θυμίζει προσεγγίσεις του συναρτησιακού προγραμματισμού και συχνά μπορεί να κάνει τον κώδικα πιο εκφραστικό και λιγότερο επιρρεπή σε σφάλματα.

Ο τριαδικός τελεστής συνδυάζει 3 εκφράσεις: μια συνθήκη που ακολουθείται από μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι αληθής (το μέρος `if`, που εισάγεται με `?`), και μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι ψευδής (το μέρος `else`, που εισάγεται με `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```
