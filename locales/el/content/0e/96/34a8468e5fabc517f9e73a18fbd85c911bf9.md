# Σχετικά

Ο βρόχος [`for`][for-statement] σου επιτρέπει να εκτελείς κώδικα επανειλημμένα μέσα σε έναν βρόχο, μέχρι να ικανοποιηθεί μια συνθήκη.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Ένας βρόχος `for` αποτελείται από τέσσερα μέρη:

1. Τον αρχικοποιητή: εκτελείται μία φορά πριν από την είσοδο στον βρόχο. Συνήθως χρησιμοποιείται για να ορίσεις τις μεταβλητές που χρησιμοποιούνται μέσα στον βρόχο.
2. Τη συνθήκη: εκτελείται πριν από κάθε επανάληψη του βρόχου. Ο βρόχος συνεχίζει να εκτελείται όσο αυτή αξιολογείται ως `true`.
3. Τον επαναλήπτη: εκτελείται μετά από κάθε επανάληψη του βρόχου. Συνήθως χρησιμοποιείται για να τροποποιήσεις (συχνά: να αυξήσεις ή να μειώσεις) τη μεταβλητή ή τις μεταβλητές του βρόχου.
4. Το σώμα: τον κώδικα που εκτελείται σε κάθε επανάληψη του βρόχου.

## Βρόχοι `for` εναντίον βρόχων `foreach`

Γενικά, οι [concept:csharp/foreach-loops]() προτιμώνται έναντι των βρόχων `for` για τους παρακάτω λόγους:

- Ένας βρόχος `foreach` εγγυάται ότι θα περάσει από _όλες_ τις τιμές. Με έναν βρόχο `for`, είναι εύκολο να παραλείψεις στοιχεία, για παράδειγμα εξαιτίας ενός σφάλματος κατά ένα.
- Ένας βρόχος `foreach` είναι πιο _δηλωτικός_: ο κώδικάς σου δηλώνει _τι_ θέλεις να κάνει, σε αντίθεση με έναν βρόχο `for` που δηλώνει _πώς_ θέλεις να το κάνεις.
- Ένας βρόχος `foreach` είναι αλάνθαστος, ενώ με τους βρόχους `for` είναι εύκολο να κάνεις ένα σφάλμα κατά ένα.
- Ένας βρόχος `foreach` λειτουργεί με όλους τους τύπους συλλογών, συμπεριλαμβανομένων εκείνων που δεν υποστηρίζουν τη χρήση ευρετηριαστή για την πρόσβαση σε στοιχεία.

Για να εγγυηθεί ότι ένας βρόχος `foreach` θα περάσει από _όλες_ τις τιμές, ο μεταγλωττιστής δεν επιτρέπει την τροποποίηση μιας συλλογής μέσα σε έναν βρόχο `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Ο βρόχος `for` έχει πάντως κάποια πλεονεκτήματα σε σχέση με έναν βρόχο `foreach`:

- Μπορείς να ξεκινήσεις ή να σταματήσεις στη θέση που θέλεις.
- Μπορείς να χρησιμοποιήσεις όποια συνθήκη τερματισμού θέλεις (Boolean).
- Μπορείς να παραλείψεις στοιχεία προσαρμόζοντας την αύξηση της μεταβλητής του βρόχου.
- Μπορείς να επεξεργαστείς συλλογές από το τέλος προς την αρχή, μετρώντας αντίστροφα.
- Μπορείς να χρησιμοποιήσεις βρόχους `for` σε σενάρια που δεν αφορούν συλλογές.
