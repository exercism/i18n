# Τεστ

## Εκτέλεση των τεστ

Για να εκτελέσεις τα τεστ, τρέξε την παρακάτω εντολή στον κατάλογο της άσκησης:

```shell
make
```

Αυτή συναρμολογεί τη λύση σου, μεταγλωττίζει τα τεστ, τα συνδέει σε ένα πρόγραμμα RISC-V και το εκτελεί με το `qemu-riscv32`.
Το πρόγραμμα τυπώνει μια γραμμή για κάθε τεστ, δείχνοντας αν πέρασε, απέτυχε ή αγνοήθηκε, και στο τέλος μια σύνοψη.

## Επίλυση της άσκησης

Το να λύσεις μια άσκηση σημαίνει να περάσεις όλα τα τεστ της.
Από προεπιλογή, όταν τρέχεις τα τεστ εκτελείται μόνο ένα τεστ (το πρώτο).
Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει αυτό το ένα τεστ.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ αφαιρώντας τη γραμμή `TEST_IGNORE();`.
Όταν ενεργοποιήσεις όλα τα τεστ και η υλοποίησή σου τα περνάει όλα, θα έχεις λύσει την άσκηση!
