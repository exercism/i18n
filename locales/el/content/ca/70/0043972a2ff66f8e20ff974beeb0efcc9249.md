# Προσθήκη στις οδηγίες

## Εργασία με ημερομηνίες στην Prolog

Η ενσωματωμένη υποστήριξη της Prolog για ημερομηνίες είναι [αρκετά στοιχειώδης][built-in-dates-support].
Ενώ μπορείς να λύσεις αυτή την άσκηση με ό,τι είναι ενσωματωμένο στην Prolog, ένας πολύ πιο βολικός τρόπος για να δουλέψεις με ημερομηνίες είναι μέσω του [πακέτου date_time][date-time-package].

### Εγκατάσταση του πακέτου date_time

Αν η εγκατεστημένη έκδοση του Swipl είναι αρκετά ενημερωμένη, μπορείς να εγκαταστήσεις το πακέτο τρέχοντας:

```bash
swipl pack install date_time
```

Αν αυτό δεν δουλέψει, μπορείς να τρέξεις:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Αν χρησιμοποιείς τον διαδικτυακό επεξεργαστή κώδικα, δεν χρειάζεται να εγκαταστήσεις τίποτα χειροκίνητα.
~~~~

### Χρήση του πακέτου date_time

Πρόσθεσε τον παρακάτω κώδικα στην αρχή του αρχείου της λύσης σου για να χρησιμοποιήσεις το πακέτο `date_time`:

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
Συμβουλή: η [πηγή του πακέτου date_time][date-time-package-source] είναι καλά τεκμηριωμένη και μπορεί να σου φανεί πολύ χρήσιμη!

[date-time-package-source]: https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src
~~~~
