# Οδηγίες

Δουλεύεις σε ένα λούνα παρκ και σου έχει δοθεί μια προδιαγραφή για να σχεδιάσεις ένα σύστημα που θα διαχειρίζεται την προσέλευση και τα παιχνίδια. Σου έχει ανατεθεί να μοντελοποιήσεις τον Attendee (το άτομο που επισκέπτεται το πάρκο).

## 1. Δημιούργησε νέους επισκέπτες

Υλοποίησε τη μέθοδο `Attendee#initialize` της κλάσης `Attendee`. Θα πρέπει να δέχεται ένα ύψος (σε εκατοστά) και να το αποθηκεύει σε μια μεταβλητή στιγμιοτύπου

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. Πόσο ψηλός είναι ο επισκέπτης

Υλοποίησε τον getter `Attendee#height` της κλάσης `Attendee`. Θα πρέπει να επιστρέφει το ύψος του στιγμιοτύπου

```ruby
Attendee.new(106).height
# => 106
```

## 3. Ποιο είναι το αναγνωριστικό της κάρτας παιχνιδιών

Δεν έχουν αγοράσει όλοι οι επισκέπτες κάρτα παιχνιδιών, αλλά πρέπει να ξέρουμε αν έχουν κάρτα ή όχι. Υλοποίησε τον getter `Attendee#pass_id` για την κλάση `Attendee`. Θα πρέπει να επιστρέφει το pass_id του στιγμιοτύπου ή `nil` αν ο επισκέπτης δεν έχει κάρτα.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Επίτρεψε στους επισκέπτες να αγοράσουν κάρτα

Υλοποίησε τη μέθοδο `Attendee#issue_pass!` ώστε να αλλάζει την κατάσταση του στιγμιοτύπου και να θέτει τη μεταβλητή στιγμιοτύπου pass id στο όρισμα. Θα πρέπει να επιστρέφει το pass id.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Ανακάλεσε την κάρτα

Μερικοί επισκέπτες παραβιάζουν τους κανόνες με επικίνδυνη συμπεριφορά, οπότε το πάρκο θέλει να μπορεί να ανακαλεί κάρτες. Υλοποίησε τη μέθοδο `Attendee#revoke_pass!` ώστε να αλλάζει την κατάσταση του στιγμιοτύπου και να θέτει το pass id σε `nil`

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
