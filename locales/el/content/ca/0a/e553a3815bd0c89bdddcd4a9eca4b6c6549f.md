# Εισαγωγή

Οι συναρτήσεις και οι μέθοδοι της Go μπορούν να επιστρέψουν πολλαπλές τιμές:

```go
func GetCard() (Card, error) { ... }
```

Κάθε τιμή επιστροφής πρέπει να ανατίθεται με τη σειρά της και να χωρίζεται με κόμμα:

```go
card, err := GetCard()
```

Κάθε θέση στην ανάθεση δηλώνει μια μεταβλητή.
Η Go δεν θα μεταγλωττίσει τον κώδικα αν κάποια δηλωμένη μεταβλητή δεν χρησιμοποιείται πουθενά.
Ο κενός αναγνωριστής `_` παίρνει τη θέση ενός ονόματος μεταβλητής για να παραλείψει αυτή την τιμή επιστροφής:

```go
card, _ := GetCard()
```

Η `error` είναι μια ενσωματωμένη διεπαφή.
Ένα `nil` error σημαίνει ότι δεν προέκυψε σφάλμα· οποιαδήποτε τιμή που δεν είναι `nil` σημαίνει ότι κάτι πήγε στραβά.
Κατά σύμβαση, οι συναρτήσεις που μπορούν να αποτύχουν θα πρέπει να επιστρέφουν ένα `error` ως τελευταία τιμή.
Ο καλών πρέπει να το ελέγξει πριν χρησιμοποιήσει οποιαδήποτε άλλη τιμή επιστροφής:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
