# Υποδείξεις

- Η είσοδος για τη `shared_birthday` μπορεί να είναι τύπου `String ` ή `Date `.
- Η έξοδος για τη `random_birthdays` είναι `Vector{Date}`
- Ο αριθμός των δοκιμών στη `estimate_probability_of_shared_birthday` πρέπει να είναι τουλάχιστον 10.000, ώστε να πάρεις μια αρκετά ακριβή εκτίμηση της πιθανότητας.
- Λειτουργίες που μπορεί να σου φανούν χρήσιμες περιλαμβάνουν τις [isleapyear][isleapyear] και [monthday][monthday],
- Η Διαδρομή Μάθησης έχει τεκμηρίωση εννοιών που μπορεί να αποτελέσει χρήσιμη εισαγωγή:
  - [Ημερομηνίες και ώρες][dates-times]
  - [Τυχαιότητα][randomness]
  - [Σύνθεση συναρτήσεων][function-composition]
  - [Συναρτήσεις ανώτερης τάξης][hof]
