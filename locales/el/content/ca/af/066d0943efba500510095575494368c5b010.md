# Σχετικά

Οι εκφράσεις υπό συνθήκη χρησιμοποιούνται για να εκτελεστεί κώδικας ανάλογα με το **αν** μια συνθήκη είναι **αληθής** ή **ψευδής**. Αυτές οι εκφράσεις γράφονται ως εξής:

```haxe
if (condition) {
  expressions
};
```

Το αποτέλεσμα της συνθήκης είναι τύπου `Bool`, οπότε όταν το αποτέλεσμα είναι `true` εκτελούνται οι εκφράσεις.

Μερικές φορές, όταν η συνθήκη είναι στην πραγματικότητα `false`, θέλουμε να εκτελεστεί ένα άλλο κομμάτι κώδικα. Εδώ μπαίνει στο παιχνίδι η έκφραση `else`, η οποία εκτελεί τις εκφράσεις όταν η αρχική συνθήκη είναι `false`. Αλλά τι γίνεται αν θέλουμε να ελέγξουμε τη συνθήκη για πολλαπλές περιπτώσεις; Τότε χρησιμοποιούμε το `else if (condition)`. Να ένα πλήρες παράδειγμα:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
