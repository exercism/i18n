# μετατροπή rune σε byte με απώλεια

Η μετατροπή από `rune` σε `byte` είναι ασφαλής εδώ, γιατί η συμβολοσειρά εισόδου περιέχει μόνο χαρακτήρες ASCII.
Ωστόσο, τα `runes` της Go μπορούν να αποτελούνται από πολλά `bytes`, κάτι που μπορεί να δημιουργήσει προβλήματα όταν έχεις να κάνεις με χαρακτήρες εκτός ASCII.

Για περισσότερα πάνω σε αυτό, διάβασε το [Strings, bytes, runes and characters in Go](https://blog.golang.org/strings) στο ιστολόγιο της Go.

Για να το δεις στην πράξη, πρόσθεσε ένα test που περιέχει χαρακτήρες εκτός ASCII.
