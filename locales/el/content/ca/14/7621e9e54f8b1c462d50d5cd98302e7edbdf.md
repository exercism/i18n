# Εισαγωγή

## Boolean

Το Elixir αναπαριστά τις τιμές αληθής και ψευδής με τον τύπο Boolean (λογική τιμή). Υπάρχουν μόνο δύο τιμές: `true` και `false`. Αυτές οι τιμές μπορούν να δεσμευτούν σε μια μεταβλητή:

```elixir
true_variable = true
false_variable = false
```

Μπορούμε να αξιολογήσουμε αυστηρές εκφράσεις Boolean χρησιμοποιώντας τους τελεστές `and/2`, `or/2` και `not/1`.

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Όταν γράφεις μια συνάρτηση που επιστρέφει μια τιμή Boolean, είναι ιδιωματικό να τελειώνεις το όνομα της συνάρτησης με `?`. Την ίδια σύμβαση μπορείς να τη χρησιμοποιήσεις και για μεταβλητές που αποθηκεύουν τιμές Boolean.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
