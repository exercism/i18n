# Εκτέλεση των tests

Το SWI Prolog μπορεί να τρέξει είτε διαδραστικά είτε εκτελώντας το απευθείας από τη γραμμή εντολών.

## Γραμμή εντολών

Μπορείς να χρησιμοποιήσεις την παρακάτω εντολή για να τρέξεις τα tests από τη γραμμή εντολών:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Αντικατέστησε το `<exercise>` με το όνομα της άσκησης που υλοποιείς.

## Διαδραστικά

Για να τρέξεις το Prolog διαδραστικά, πρώτα τρέξε:

```bash
swipl
```

Αφού ξεκινήσει η κονσόλα του Prolog, φόρτωσε την υλοποίησή σου και τρέξε τα tests με:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Αντικατέστησε το `<exercise>` με το όνομα της άσκησης που υλοποιείς.

### Επαναφόρτωση αλλαγών

Αφού φορτωθούν τα παραπάνω αρχεία, μπορείς να εφαρμόσεις όποιες αλλαγές έχεις κάνει τρέχοντας:

```
?- make.
```

## Tests που παραλείπονται

Όταν ξεκινάς πρώτη φορά μια άσκηση, θα τρέξει μόνο το πρώτο test. Τα υπόλοιπα έχουν παραλειφθεί με την προσθήκη `condition(pending)` στον στόχο `test`.
Μόλις περάσει το πρώτο test, ενεργοποίησε το επόμενο test αλλάζοντας το `pending` στο `condition(pending)` σε `true`.
Επανάλαβε για κάθε test μέχρι να τρέχουν και να περνούν όλα.

### Γραμμή εντολών

Πρόσθεσε το όρισμα `-- --all` στο τέλος της εντολής για να τρέξεις και τα tests που εκκρεμούν:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
