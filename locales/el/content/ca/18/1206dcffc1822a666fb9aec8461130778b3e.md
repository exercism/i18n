# Σχετικά

Η Haxe έχει ενσωματωμένη υποστήριξη για κανονικές εκφράσεις. Μπορούν να χρησιμοποιηθούν για να επαληθεύσεις τη μορφή μιας συμβολοσειράς, να μετασχηματίσεις μια συμβολοσειρά ή να εξαγάγεις δεδομένα που ακολουθούν κάποιο μοτίβο από ένα δεδομένο κείμενο.

Για να δημιουργήσεις μια κανονική έκφραση, γράψε ανάμεσα στο `~/` και στο `/`:

```haxe
var r = ~/haxe/i;
```

Ένας διαφορετικός τρόπος για να το κάνεις αυτό είναι να χρησιμοποιήσεις το στιγμιότυπο `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Εδώ το `i` είναι μια σημαία που κάνει το μοτίβο να μην κάνει διάκριση μεταξύ πεζών και κεφαλαίων. Υπάρχουν και άλλες σημαίες, όπως:

- `g`: καθολική αντικατάσταση.
- `m`: αντιστοίχιση σε πολλαπλές γραμμές.

Ανάμεσα στο `~/` και στο `/`, γράφεις τα μοτίβα της κανονικής έκφρασης. Για παράδειγμα, θέλεις να ψάξεις για μια συμβολοσειρά που περιέχει γράμματα από το A έως το Z. Εδώ μπορούμε να χρησιμοποιήσουμε το μοτίβο εύρους `[A-Z]`. Υπάρχουν πολλά μοτίβα, όπως:

- `.`: οποιοσδήποτε χαρακτήρας
- `*`: επανάληψη μηδέν ή περισσότερες φορές
- `+`: επανάληψη μία ή περισσότερες φορές
- `[A-Z0-9]`: εύρη χαρακτήρων
