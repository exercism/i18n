# Εισαγωγή

## Συμβολοσειρές

Οι συμβολοσειρές στην Elixir οριοθετούνται από διπλά εισαγωγικά και είναι κωδικοποιημένες σε UTF-8:

```elixir
"Hi!"
```

Οι συμβολοσειρές μπορούν να συνενωθούν χρησιμοποιώντας τον τελεστή `<>/2`:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Οι συμβολοσειρές στην Elixir υποστηρίζουν παρεμβολή χρησιμοποιώντας τη σύνταξη `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Για να βάλεις έναν χαρακτήρα νέας γραμμής σε μια συμβολοσειρά, χρησιμοποίησε τον κωδικό διαφυγής `\n`:

```elixir
"1\n2\n3\n"
```

Για να δουλέψεις άνετα με κείμενα που έχουν πολλές νέες γραμμές, χρησιμοποίησε αντ' αυτού τη σύνταξη heredoc με τρία διπλά εισαγωγικά:

```elixir
"""
1
2
3
"""
```

Η Elixir παρέχει πολλές συναρτήσεις για εργασία με συμβολοσειρές στο module `String`.

## Τελεστής pipe

Ο τελεστής `|>` ονομάζεται τελεστής pipe. Μπορεί να χρησιμοποιηθεί για να αλυσιδώσει κλήσεις συναρτήσεων με τέτοιο τρόπο ώστε η τιμή επιστροφής της προηγούμενης κλήσης συνάρτησης να περνά ως πρώτο όρισμα στην επόμενη κλήση συνάρτησης.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
