# Συναρτήσεις

Στη JavaScript, οι συναρτήσεις είναι _αντικείμενα πρώτης κατηγορίας_, που σημαίνει ότι μπορούν να ανατεθούν σε μεταβλητές και ιδιότητες, να περαστούν σε άλλες συναρτήσεις και να επιστραφούν από συναρτήσεις. Μπορούν να έχουν ιδιότητες και μεθόδους, ακριβώς όπως οποιοδήποτε άλλο _αντικείμενο_.

## Είσοδος: πέρασμα ορισμάτων

Οι συναρτήσεις της JavaScript σου επιτρέπουν να περάσεις ορίσματα όταν καλούνται. Τα ορίσματα [περνιούνται πάντα κατ' αξία](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Με άλλα λόγια, αν μια συνάρτηση αναθέσει ξανά τιμή σε μια παράμετρο μέσα στη συνάρτηση, η τιμή δεν θα αλλάξει έξω από τη συνάρτηση. Αυτό δεν σημαίνει ότι τα αντικείμενα που περνιούνται δεν μπορούν να τροποποιηθούν.

> [!TIP]
> Όταν περνιέται ένα αντικείμενο, η αναφορά σε αυτό το αντικείμενο περνιέται κατ' αξία. Αυτό κάνει να _φαίνεται_ πως τα αντικείμενα που περνιούνται αντιμετωπίζονται διαφορετικά, αλλά δεν ισχύει κάτι τέτοιο.

Ένα παράδειγμα συνάρτησης που δέχεται δύο ορίσματα και τα πολλαπλασιάζει είναι:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Έξοδος: τιμή επιστροφής

Η JavaScript μπορεί να επιστρέψει μία μόνο τιμή από μια συνάρτηση χρησιμοποιώντας τη λέξη-κλειδί `return`, ακολουθούμενη από μια έκφραση. Όταν δεν επιστρέφεται τίποτα από μια συνάρτηση, η τιμή που επιστρέφεται είναι `undefined`.

Ένα παράδειγμα συνάρτησης που επιστρέφει μια τιμή είναι:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Ορισμός συναρτήσεων

Υπάρχουν τέσσερα είδη συναρτήσεων στη JavaScript:

1. Κανονικές συναρτήσεις που μπορούν να επιστρέψουν οτιδήποτε και εκτελούνται πάντα μέχρι το τέλος·
2. Ασύγχρονες συναρτήσεις που επιστρέφουν πάντα ένα `Promise` και μπορούν να τεθούν σε παύση και να συνεχιστούν με τον τελεστή `await`·
3. Συναρτήσεις γεννήτριες: που επιστρέφουν πάντα ένα αντικείμενο `Generator` και μπορούν να τεθούν σε παύση και να συνεχιστούν με τον τελεστή `yield`·
4. Ασύγχρονες συναρτήσεις γεννήτριες: που επιστρέφουν πάντα ένα αντικείμενο `AsyncGenerator` και μπορούν να τεθούν σε παύση και να συνεχιστούν με _αμφότερους_ τους τελεστές `yield` και `await`.

Για καθένα από αυτά τα τέσσερα είδη, υπάρχουν τρεις τρόποι για να τα ορίσεις:

1. χρησιμοποιώντας μια δήλωση
2. χρησιμοποιώντας μια έκφραση
3. χρησιμοποιώντας τον κατασκευαστή

Τέλος, υπάρχει ειδική σύνταξη για τον ορισμό _συναρτήσεων βέλους και μεθόδων_.
