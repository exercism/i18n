# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου τις τελευταίες επτά μέρες.

Έχεις έξι εργασίες, όλες σχετικές με τους αριθμούς των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Για λόγους σύγκρισης, κρατάς πάντα κοντά σου ένα αντίγραφο των μετρήσεων της προηγούμενης εβδομάδας, που ήταν: 0, 2, 5, 3, 7, 8 και 4. Δημιούργησε ένα διάνυσμα που να περιέχει τις μετρήσεις της προηγούμενης εβδομάδας:

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν τον κήπο σήμερα

Υλοποίησε τη συνάρτηση `today` ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου σήμερα. Οι μετρήσεις των πουλιών είναι ταξινομημένες ανά μέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης μέρας και το τελευταίο στοιχείο να είναι η σημερινή μέτρηση.

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. Αύξησε τη σημερινή μέτρηση

Υλοποίησε τη συνάρτηση `inc-bird` ώστε να αυξάνει τη σημερινή μέτρηση:

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη συνάρτηση κατηγορήματος `day-without-birds?` που επιστρέφει `true` αν υπήρξε μέρα κατά την οποία μηδέν πουλιά επισκέφτηκαν τον κήπο, αλλιώς να επιστρέφει `false`:

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο για έναν ορισμένο αριθμό πρώτων ημερών

Υλοποίησε τη συνάρτηση `n-days-count` που επιστρέφει τον αριθμό των πουλιών που έχουν επισκεφτεί τον κήπο σου από την αρχή της εβδομάδας, αλλά περιορίζοντας τη μέτρηση στον καθορισμένο αριθμό ημερών από την αρχή της εβδομάδας.

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Μερικές μέρες είναι πιο πολυάσχολες από άλλες. Πολυάσχολη μέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.
Υλοποίησε τη συνάρτηση `busy-days` ώστε να επιστρέφει τον αριθμό των πολυάσχολων ημερών:

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. Έλεγξε για παράξενη εβδομάδα

Τον τελευταίο χρόνο, διαπίστωσες ότι κάποιες εβδομάδες ακολουθούν το ίδιο, παράξενο πρότυπο, όπου οι μετρήσεις εναλλάσσονται μεταξύ ενός και μηδέν πουλιών που επισκέπτονται τον κήπο. Υλοποίησε τη συνάρτηση `odd-week?` που επιστρέφει `true` αν το πρότυπο των μετρήσεων των πουλιών αυτής της εβδομάδας ταιριάζει με το παράξενο πρότυπο:

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
