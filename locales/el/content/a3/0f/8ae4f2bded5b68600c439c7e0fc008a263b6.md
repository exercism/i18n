# Εισαγωγή

## Τύποι struct

Έχουμε ήδη δει τύπους struct. Για υπενθύμιση, ένα `struct` είναι μια ακολουθία από ονομασμένα στοιχεία που ονομάζονται _πεδία_, όπου κάθε πεδίο έχει ένα όνομα και έναν τύπο.
Το όνομα ενός πεδίου πρέπει να είναι μοναδικό μέσα στο struct.
Τα struct μπορούν να συγκριθούν με την _κλάση_ στο παράδειγμα του αντικειμενοστρεφούς προγραμματισμού.

Δημιουργείς ένα νέο struct χρησιμοποιώντας τις λέξεις-κλειδιά `type` και `struct` και μετά ορίζεις ρητά το όνομα και τον τύπο των πεδίων, όπως φαίνεται στο παρακάτω παράδειγμα.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Τύποι που δεν είναι struct

Μπορείς επίσης να ορίσεις τύπους που δεν είναι struct, τους οποίους μπορείς να χρησιμοποιήσεις ως ψευδώνυμο για δηλώσεις ενσωματωμένων τύπων.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

Μπορείς επίσης να ορίσεις τύπους που δεν είναι struct και αποτελούνται από πίνακες και map.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
