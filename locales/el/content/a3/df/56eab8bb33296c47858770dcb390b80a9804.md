# Σχετικά

Οι [συμβολοσειρές][getting-started-strings] στην Elixir ορίζονται με διπλά εισαγωγικά και είναι κωδικοποιημένες σε UTF-8:

```elixir
"Hi!"
```

Οι συμβολοσειρές μπορούν να συνενωθούν με τον τελεστή [`<>/2`][kernel-concat]:

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Οι συμβολοσειρές στην Elixir υποστηρίζουν [παρεμβολή][string-interpolation] με τη σύνταξη `#{}`:

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

Οποιαδήποτε έκφραση της Elixir είναι έγκυρη μέσα στην παρεμβολή. Αν δοθεί μια συμβολοσειρά, η συμβολοσειρά παρεμβάλλεται ως έχει. Αν δοθεί οποιαδήποτε άλλη τιμή, η Elixir θα επιχειρήσει να τη μετατρέψει σε συμβολοσειρά.

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Η Elixir παρέχει πολλές συναρτήσεις για την εργασία με συμβολοσειρές στο module `String`. Αν δεν είσαι σίγουρος πώς να επεξεργαστείς μια συμβολοσειρά με τον τρόπο που χρειάζεσαι, ρίξε μια ματιά στις [συναρτήσεις που διατίθενται στο module `String`][string-module-functions] και πολύ πιθανόν θα βρεις αυτό που χρειάζεσαι.

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

Χρησιμοποιώντας μερικές από αυτές τις συναρτήσεις, θυμήσου ότι ο πρώτος χαρακτήρας σε μια συμβολοσειρά έχει τη θέση `0`.

Ορισμένοι χαρακτήρες χρειάζεται να [διαφύγουν][escape-characters] για να μπουν σε μια συμβολοσειρά, π.χ. οι αλλαγές γραμμής, τα διπλά εισαγωγικά ή ο χαρακτήρας `#`:

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

Για να δουλέψεις άνετα με κείμενα που έχουν πολλές αλλαγές γραμμής, χρησιμοποίησε τη [σύνταξη heredoc με τριπλά διπλά εισαγωγικά][heredoc-syntax]:

```elixir
"""
1
2
3
"""
```

Πολύ συχνά θα δεις αυτή τη σύνταξη να χρησιμοποιείται για την τεκμηρίωση κώδικα:

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
