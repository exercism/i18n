# Εισαγωγή

Ένας `for` βρόχος σου επιτρέπει να διατρέξεις έναν πίνακα και να επαναλάβεις τον κώδικα για κάθε στοιχείο:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Στο παραπάνω παράδειγμα, το `fruit` είναι η μεταβλητή που κρατά την τιμή ενός μεμονωμένου στοιχείου του πίνακα `fruitList`. Ο μεταγλωττιστής διασφαλίζει ότι μπορεί να γίνει επανάληψη πάνω στον `fruitList`, αλλιώς σταματά την εκτέλεση.

Μπορείς να κάνεις επανάληψη πάνω σε αριθμούς χρησιμοποιώντας τον τελεστή εύρους. Ο τελεστής παίρνει δύο τελεστέους `Int` και γράφεται ως `min...max`:

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
