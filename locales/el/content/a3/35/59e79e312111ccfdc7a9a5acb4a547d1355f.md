# Οδηγίες

Σε αυτή την άσκηση, θα υλοποιήσεις μηχανισμούς ενός παιχνιδιού ρόλων.
Ο χαρακτήρας ενός παίκτη αναπαρίσταται από τον παρακάτω τύπο:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Οι παίκτες σε αυτό το παιχνίδι πρέπει να φτάσουν στο επίπεδο 10 για να ξεκλειδώσουν μια δεξαμενή μάνα, ώστε να μπορούν να αρχίσουν να ρίχνουν ξόρκια.
Θα δουλέψεις πάνω σε δύο κομμάτια λειτουργικότητας αυτού του παιχνιδιού: τον μηχανισμό ανάστασης και τον μηχανισμό ρίψης ξόρκιων.

## 1. Συστήσου

Γράψε το περιεχόμενο της συνάρτησης `introduce`.
Σημείωσε ότι το πεδίο `Name` της καταγραφής `Player` είναι `Option`.
Οι παίκτες που παίζουν στα κρυφά μπορεί να θέλουν να κρύψουν το όνομά τους αφήνοντάς το ορισμένο σε `None`. Τέτοιοι παίκτες θα συστηθούν ως `"Mighty Magician"`.
Διαφορετικά, χρησιμοποίησε απλώς το όνομά σου για να συστηθείς.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Υλοποίησε τον μηχανισμό ανάστασης

Η συνάρτηση `revive` θα πρέπει να ελέγχει ότι ο χαρακτήρας του παίκτη είναι όντως νεκρός (η υγεία του έχει φτάσει στο 0).
Αν είναι, θα πρέπει να επιστρέφει ένα νέο στιγμιότυπο `Player` με 100 υγεία.
Διαφορετικά, αν ο χαρακτήρας του παίκτη δεν είναι νεκρός, η συνάρτηση `revive` επιστρέφει `None`.

Αν το επίπεδο του παίκτη είναι 10 ή παραπάνω, θα πρέπει να αναστηθεί και με 100 μάνα.
Αν το επίπεδο του παίκτη είναι κάτω από 10, το μάνα του θα πρέπει να είναι `None`.
Η συνάρτηση `revive` θα πρέπει να διατηρεί το επίπεδο του παίκτη.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Αν κληθεί η μέθοδος `revive` σε έναν παίκτη του οποίου η υγεία είναι 1 ή παραπάνω, τότε η συνάρτηση θα πρέπει να επιστρέφει `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Υλοποίησε τον μηχανισμό ρίψης ξόρκιων

Η συνάρτηση `castSpell` παίρνει ως ορίσματα ένα `int` που δείχνει πόσο μάνα κοστίζει το ξόρκι, καθώς και έναν `Player`.
Επιστρέφει τον ενημερωμένο παίκτη, καθώς και το πόση ζημιά προκαλεί το ξόρκι που ρίχτηκε.
Μια επιτυχημένη ρίψη ξόρκιου προκαλεί ζημιά ίση με το διπλάσιο του κόστους μάνα του ξόρκιου.
Ωστόσο, αν ο παίκτης δεν έχει αρκετό μάνα, δεν συμβαίνει τίποτα, ο παίκτης μένει αμετάβλητος και δεν προκαλείται ζημιά.
Αν ο παίκτης δεν έχει καν δεξαμενή μάνα, η προσπάθεια να ρίξει το ξόρκι πρέπει να μειώσει την υγεία του κατά το κόστος μάνα του ξόρκιου και δεν προκαλεί ζημιά.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
