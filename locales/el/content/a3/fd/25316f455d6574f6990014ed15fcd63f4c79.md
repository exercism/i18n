# Εισαγωγή

Ο κώδικας της Elixir εκτελείται στην εικονική μηχανή BEAM. Το BEAM αποτελεί μέρος του Συστήματος Χρόνου Εκτέλεσης της Erlang. Έχοντας εμπνευστεί από την Erlang και μοιραζόμενη το περιβάλλον εκτέλεσής της, η Elixir προσφέρει εξαιρετική διαλειτουργικότητα με τις βιβλιοθήκες της Erlang. Αυτό σημαίνει ότι οι προγραμματιστές Elixir μπορούν να χρησιμοποιούν βιβλιοθήκες της Erlang μέσα από τον κώδικα Elixir τους. Μάλιστα, η κοινότητα της Elixir αποθαρρύνει τη συγγραφή βιβλιοθηκών Elixir για λειτουργικότητα που παρέχεται ήδη από τις βιβλιοθήκες της Erlang.

Ως αποτέλεσμα, κάποιες λειτουργίες, όπως οι μαθηματικές πράξεις ή οι συναρτήσεις χρονομέτρησης, είναι διαθέσιμες στην Elixir μόνο μέσω της Erlang.

Η τυπική βιβλιοθήκη της Erlang είναι διαθέσιμη για χρήση στον κώδικα Elixir μας χωρίς να χρειάζεται κανένα επιπλέον βήμα.

Οι συναρτήσεις της Erlang μπορούν να κληθούν με τον ίδιο τρόπο που καλούμε τις συναρτήσεις της Elixir, με μία μικρή διαφορά. Τα ονόματα των ενοτήτων της Erlang είναι άτομα `snake_case`. Για παράδειγμα, για να καλέσεις τη συνάρτηση `pi/0` της Erlang από την ενότητα `math`, θα έγραφες:

```elixir
:math.pi()
# => 3.141592653589793
```

Οι πιο συχνά χρησιμοποιούμενες συναρτήσεις της Erlang που δεν έχουν αντίστοιχη στην Elixir είναι:

- Η `:timer.sleep/1`, που αναστέλλει μια διεργασία για τον δεδομένο αριθμό χιλιοστών του δευτερολέπτου.
- Η `:rand.uniform/0`, που παράγει έναν τυχαίο δεκαδικό αριθμό `x`, όπου `0.0 <= x < 1.0`.
- Η `:io_lib.format/2`, που παρέχει μορφοποίηση συμβολοσειρών σε στυλ C (με ακολουθίες ελέγχου). Χρησιμοποιώντας αυτή τη συνάρτηση, θα μπορούσαμε για παράδειγμα να εκτυπώσουμε έναν ακέραιο σε οποιαδήποτε βάση από το 2 έως το 36 ή να μορφοποιήσουμε έναν δεκαδικό αριθμό με την ακρίβεια που θέλουμε. Σημείωσε ότι αυτή η συνάρτηση, όπως πολλές συναρτήσεις της Erlang, επιστρέφει μια λίστα χαρακτήρων.
- Η ενότητα `math`, που παρέχει μαθηματικές συναρτήσεις όπως `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` και άλλες.

Για να ανακαλύψεις την τυπική βιβλιοθήκη της Erlang, ρίξε μια ματιά στο [Εγχειρίδιο Αναφοράς STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
