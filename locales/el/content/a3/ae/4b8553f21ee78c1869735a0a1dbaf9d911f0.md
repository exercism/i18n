# Παράρτημα οδηγιών

## Ειδικές οδηγίες για το track

Αυτή η άσκηση εστιάζει στην προσθήκη μεθόδων στη δομή `Int` στη Swift.
Ο ευκολότερος τρόπος είναι να χρησιμοποιήσεις [επεκτάσεις][extensions].

```swift
extension Int {
  // 
}
```

Μπορείς να βρεις την τεκμηρίωση του `Int` [εδώ][int].

[int]: https://developer.apple.com/documentation/swift/int
[extensions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/extensions/
