# Σχετικά

Κάθε πρόγραμμα που έχεις τρέξει ποτέ, είτε είναι παιχνίδι, πρόγραμμα περιήγησης ή εφαρμογή για κινητό, καταλήγει σε μια μεγάλη λίστα μικροσκοπικών εντολών που ο επεξεργαστής εκτελεί μία προς μία.
Η γλώσσα assembly είναι ο τρόπος με τον οποίο γράφεις ο ίδιος αυτές τις εντολές.
Αντί για μεταβλητές, λίστες και βρόχους `for`, δουλεύεις με τα βασικά δομικά στοιχεία του ίδιου του επεξεργαστή: ένα μικρό σύνολο καταχωρητών, διευθύνσεις μνήμης και άλματα από τη μια εντολή στην άλλη.

Το RISC-V (προφέρεται "risk five") είναι ένας σχεδιασμός για επεξεργαστές που ξεκίνησε στο Πανεπιστήμιο της Καλιφόρνιας, στο Μπέρκλεϊ, το 2010.
Σε αντίθεση με τους περισσότερους σχεδιασμούς επεξεργαστών, είναι ένα ανοιχτό πρότυπο: κανείς δε χρειάζεται να πληρώσει ή να ζητήσει άδεια για να κατασκευάσει ένα τσιπ RISC-V, και η προδιαγραφή είναι ελεύθερη για να τη διαβάσει οποιοσδήποτε.
Τσιπ RISC-V βρίσκονται σε μικροελεγκτές, υπολογιστές μονής πλακέτας, συσκευές αποθήκευσης και πολλά άλλα.

Το RISC-V είναι μια καλή πρώτη γλώσσα assembly, επειδή σχεδιάστηκε για να είναι απλό.
Οι εντολές του ακολουθούν έναν μικρό αριθμό κανονικών μοτίβων, και οι 32 καταχωρητές του έχουν σαφείς και συνεπείς ρόλους, οπότε υπάρχουν πολύ λιγότερα πράγματα να απομνημονεύσεις απ' ό,τι με τους επεξεργαστές των περισσότερων φορητών υπολογιστών.
Αυτή η απλότητα είναι και ο λόγος που πολλά πανεπιστήμια χρησιμοποιούν τώρα το RISC-V για να διδάξουν πώς λειτουργούν οι υπολογιστές.

Να μια μικρή γεύση: μια συνάρτηση που προσθέτει δύο αριθμούς:

```riscv
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

Σε αυτό το track γράφεις assembly RISC-V 32-bit.
Δε χρειάζεσαι υλικό RISC-V: τα προγράμματά σου δοκιμάζονται σε έναν εξομοιωτή, ο οποίος υποδύεται έναν επεξεργαστή RISC-V.
Μπορείς να λύνεις ασκήσεις στον online editor ή στον δικό σου υπολογιστή χρησιμοποιώντας δωρεάν εργαλεία.

Το να μάθεις assembly απαιτεί υπομονή, αλλά αξίζει τον κόπο.
Μόλις δεις πώς μοιάζει ένας βρόχος ή μια κλήση συνάρτησης από την πλευρά του επεξεργαστή, κάθε άλλη γλώσσα προγραμματισμού βγάζει λίγο περισσότερο νόημα.
