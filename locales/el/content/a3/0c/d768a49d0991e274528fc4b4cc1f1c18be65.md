# χρήση γυμνών επιστροφών

Η κοινότητα της Go συνιστά να αποφεύγεις τις *γυμνές επιστροφές* (ή *σκέτες επιστροφές*) υπό κανονικές συνθήκες,
καθώς συνήθως κάνουν τον κώδικα πιο δυσανάγνωστο.
Δες τον [επίσημο οδηγό αναθεώρησης κώδικα της Go](https://github.com/golang/go/wiki/CodeReviewComments#naked-returns) για λεπτομέρειες.
Υπάρχει μια [πρόταση](https://github.com/golang/go/issues/21291) να αφαιρεθούν εντελώς οι σκέτες επιστροφές στη Go 2.
