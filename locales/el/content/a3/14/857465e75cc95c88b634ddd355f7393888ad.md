# Εισαγωγή

Ένα φορτίο με εφόδια έκτακτης ανάγκης έχει φτάσει, αλλά υπάρχει ένα πρόβλημα.
Για να προστατευτούν από ζημιές, τα είδη, φακοί, κιτ πρώτων βοηθειών, κουβέρτες, είναι συσκευασμένα μέσα σε κουτιά, και μερικά από αυτά τα κουτιά είναι εμφωλευμένα πολλά στρώματα βαθιά μέσα σε άλλα κουτιά!

Για να είσαι έτοιμος για μια έκτακτη ανάγκη, τα πάντα πρέπει να είναι εύκολα προσβάσιμα σε ένα κουτί.
Μπορείς να ξεπακετάρεις όλα τα εφόδια και να τα βάλεις σε ένα μόνο κουτί, ώστε να είναι έτοιμα όταν τα χρειαστείς περισσότερο;
