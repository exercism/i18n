# Σχετικά

Τα λεξικά, όπως οι αντίστοιχες δομές σε άλλες γλώσσες, π.χ. οι χάρτες ή οι συσχετιστικοί πίνακες, αποθηκεύουν ζεύγη κλειδιού/τιμής, έτσι ώστε μια τιμή να μπορεί να ανακτηθεί ή να αλλάξει απευθείας περνώντας το κλειδί στην ιδιότητα ευρετηριασμού του λεξικού.

Επιπλέον, ζεύγη κλειδιού/τιμής μπορούν να προστεθούν και να αφαιρεθούν από το λεξικό. Κλειδιά, τιμές και ζεύγη κλειδιού/τιμής μπορούν να απαριθμηθούν.

Οι τιμές μπορούν να είναι αντικείμενα οποιουδήποτε τύπου της C#, κάτι που περιλαμβάνει πρωτογενείς τύπους, struct _και_ κλάσεις.

Το αντικείμενο Dictionary επιτρέπει στα κλειδιά να είναι αντικείμενα οποιουδήποτε τύπου. Ωστόσο, για να διασφαλιστεί η σωστή συμπεριφορά κατά την εκτέλεση, τα κλειδιά πρέπει να έχουν ένα κατάλληλο hashcode, όπως αυτό που επιστρέφει η [GetHashCode][gethashcode].

Ένα στιγμιότυπο λεξικού δεν μπορεί να προσπελαστεί με ασφάλεια από περισσότερα από ένα νήματα (δεν είναι thread-safe). Το [ConcurrentDictionary][concurrent-dictionary] είναι διαθέσιμο για καταστάσεις πολυνηματικότητας.

Δες επίσης [HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary], [SortedDictionary][sorted-dictionary].

Αν και δεν υπάρχει μη-γενική έκδοση του Dictionary, αρκετές κλάσεις παραμένουν στη βιβλιοθήκη για να υποστηρίζουν έναν μη-γενικό χάρτη. Πρέπει να γνωρίζεις τη μη-γενική IDictionary και τη Hashtable, κυρίως για να τις αναγνωρίζεις όταν τις βλέπεις. Είναι απίθανο να χρειαστεί να τις χρησιμοποιήσεις, εκτός από τη συντήρηση παλιού κώδικα.

Συχνά θα θέλεις να εκθέτεις και να προσπελαύνεις το λεξικό μέσω της διεπαφής του [`IDictionary<TKey, TValue>`][idictionary].

Σημείωσε ότι, λόγω της φύσης των [ιδιοτήτων ευρετηριασμού][indexer-properties], οι πρωτογενείς τιμές μπορούν να τροποποιηθούν επιτόπου, όπως:

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
