# Δυαδικό, Οκταδικό και Δεκαεξαδικό

Το δυαδικό, το οκταδικό και το δεκαεξαδικό (_γνωστό και ως hex_) είναι διαφορετικά [συστήματα αρίθμησης][numeral-systems] με διαφορετικές βάσεις.
Το δυαδικό έχει βάση το 2, το οκταδικό έχει βάση το 8 και το δεκαεξαδικό έχει βάση το 16.
Οι συνηθισμένοι ακέραιοι στο Crystal είναι βάσης 10.
Το δυαδικό, το οκταδικό και το δεκαεξαδικό είναι όλα αναπαραστάσεις ακεραίων.
Αυτό σημαίνει ότι αναπαριστούν θετικούς και αρνητικούς αριθμούς (_συμπεριλαμβανομένου του μηδενός_) χωρίς κλάσματα ή δεκαδικά ψηφία και υποστηρίζουν όλες τις πράξεις που μπορούμε να κάνουμε με ακεραίους.

## Δυαδικό

Το [δυαδικό][binary] είναι ένα σύστημα αρίθμησης βάσης 2, που χρησιμοποιεί μόνο τα ψηφία 0 και 1.
Συνήθως αναπαριστά τις καταστάσεις 0 ("off") και 1 ("on") της ροής του ηλεκτρισμού μέσα από τρανζίστορ και διακόπτες στους υπολογιστές, καθώς και τα θετικά και αρνητικά φορτία στα μαγνητικά μέσα αποθήκευσης.
Το δυαδικό μπορεί να αναπαραστήσει όλους τους ακεραίους που χρησιμοποιούνται στη βάση 10.

Ένα απόσπασμα από το σύστημα βάσης 2 μοιάζει κάπως έτσι, αν και συνεχίζεται άπειρα και δεν σταματά στο 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Έτσι, αν θέλουμε να αναπαραστήσουμε τον αριθμό 6, στο δυαδικό θα ήταν: 110

| Αξία θέσης    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Δυαδικός αριθμός | 1   | 1   | 0   |

Και η πράξη θα ήταν: `4 + 2 + 0 = 6`

Άλλο ένα παράδειγμα: 19

| Αξία θέσης    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Δυαδικός αριθμός | 1   | 0   | 0   | 1   | 1   |

Ο δυαδικός αριθμός θα ήταν: 10011
Και η πράξη θα ήταν: `16 + 0 + 0 + 2 + 1 = 19`

## Το δυαδικό στο Crystal

Στο Crystal, μπορούμε να αναπαραστήσουμε δυαδικά literals χρησιμοποιώντας το πρόθεμα `0b`.
Αν γράψεις `0b10011`, το Crystal θα το ερμηνεύσει ως δυαδικό αριθμό και θα το μετατρέψει σε βάση 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Αν γράψεις έναν αριθμό με πρόθεμα `0b` που δεν είναι στο δυαδικό σύστημα, θα πετάξει ένα σφάλμα μεταγλώττισης.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Πράξεις με δυαδικούς αριθμούς

Εφόσον οι δυαδικοί αριθμοί είναι ακέραιοι, μπορούμε να κάνουμε πάνω τους όλες τις πράξεις που μπορούμε και με τους ακεραίους.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Μετατροπή από και προς τη δυαδική αναπαράσταση

Το Crystal θα μετατρέψει αυτόματα ένα δυαδικό literal σε `Int32`.
Για να μετατρέψεις ένα `Int32` σε δυαδική αναπαράσταση, χρησιμοποίησε τη μέθοδο [`<int>.to_s(base)`][to_s] με το όρισμα της βάσης ορισμένο σε 2.
Η μέθοδος θα επιστρέψει μια αναπαράσταση συμβολοσειράς του δυαδικού αριθμού:

```crystal
19.to_s(2)
# => "10011"
```

Για να μετατρέψεις μια αναπαράσταση συμβολοσειράς ενός δυαδικού σε ακέραιο, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_i], περνώντας τη βάση (2) ως όρισμα:

```crystal
"10011".to_i(2)
# => 19
```

Το να δώσεις λάθος βάση (_ή μια μη έγκυρη δυαδική αναπαράσταση_) θα πετάξει ένα `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Δυαδικές μέθοδοι

Υπάρχουν ορισμένες μέθοδοι που μπορούν να χρησιμοποιηθούν σε ακεραίους για να πάρουμε πληροφορίες για τη δυαδική αναπαράσταση του αριθμού.

Το [`<int>.bit_length`][bit_length] θα επιστρέψει τον αριθμό των bits που χρειάζονται για να αναπαραστήσουν τον αριθμό:

```crystal
19.bit_length
# => 5
```

Το [`<int>.bit(index)`][bit] θα επιστρέψει το bit στη δεδομένη θέση, ξεκινώντας από τα δεξιά (_το λιγότερο σημαντικό bit_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Οκταδικό

Το [οκταδικό][octal] είναι ένα σύστημα αρίθμησης βάσης 8.
Χρησιμοποιεί τα ψηφία 0, 1, 2, 3, 4, 5, 6 και 7.

Στο Crystal, μπορούμε να αναπαραστήσουμε οκταδικούς αριθμούς χρησιμοποιώντας το πρόθεμα `0o`.
Όπως με το δυαδικό, το Crystal μετατρέπει αυτόματα μια οκταδική αναπαράσταση σε `Int32`.

```crystal
0o123
# => 83
```

Το να βάλεις πρόθεμα `0o` σε έναν αριθμό που δεν είναι στο οκταδικό σύστημα θα πετάξει ένα σφάλμα μεταγλώττισης.

### Μετατροπή από και προς την οκταδική αναπαράσταση 

Όπως με το δυαδικό, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_s(base)`][to_s] για να μετατρέψουμε ένα `Int32` σε οκταδική αναπαράσταση.
Και μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_s] για να μετατρέψουμε μια οκταδική αναπαράσταση σε `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Όπως με το δυαδικό, το να δώσεις λάθος βάση θα πετάξει ένα `ArgumentError`.

## Δεκαεξαδικό

Το [δεκαεξαδικό][hexadecimal] είναι ένα σύστημα αρίθμησης βάσης 16.
Χρησιμοποιεί τα ψηφία 0 - 9 και τα γράμματα A, B, C, D, E και F.
Το A είναι 10, το B είναι 11, το C είναι 12, το D είναι 13, το E είναι 14 και το F είναι 15.

Μπορούμε να αναπαραστήσουμε δεκαεξαδικούς αριθμούς στο Crystal χρησιμοποιώντας το πρόθεμα `0x`.
Όπως με το δυαδικό και το οκταδικό, το Crystal θα μετατρέψει αυτόματα τα δεκαεξαδικά literals σε `Int32`.

```crystal
#=> 0x123
291
```
 
Το να βάλεις πρόθεμα `0x` σε έναν μη δεκαεξαδικό αριθμό θα πετάξει ένα σφάλμα μεταγλώττισης.

###  Μετατροπή από και προς τη δεκαεξαδική αναπαράσταση

Όπως με το δυαδικό, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_s(base)`][to_i] για να μετατρέψουμε ένα `Int32` σε δεκαεξαδική αναπαράσταση.
Και μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_s] για να μετατρέψουμε μια δεκαεξαδική αναπαράσταση σε `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Όπως με το δυαδικό και το οκταδικό, το να δώσεις λάθος βάση θα πετάξει ένα `ArgumentError`.

## Ακρίβεια

Όταν μετατρέπουμε έναν αριθμό σε αναπαράσταση συμβολοσειράς, μπορούμε να ορίσουμε την ακρίβειά του.
Δηλαδή τον **ελάχιστο** αριθμό ψηφίων που χρησιμοποιούνται για να αναπαρασταθεί ο αριθμός.
Αν ο αριθμός έχει λιγότερα ψηφία από την ακρίβεια, θα προστεθούν μηδενικά μπροστά στην αναπαράσταση συμβολοσειράς.
Αυτό γίνεται περνώντας το όρισμα `precision` στη μέθοδο [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```
