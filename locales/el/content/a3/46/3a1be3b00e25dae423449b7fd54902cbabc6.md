# Υποδείξεις

## Γενικά

- [Οδηγός για την εργασία με enum][java-tutorial-enum-types].

## 1. Ανάλυση του επιπέδου καταγραφής

- Υπάρχει μια [μέθοδος για να πάρεις ένα μέρος μιας συμβολοσειράς][java-docs-substring].
- Μπορείς να χρησιμοποιήσεις μια [εντολή `switch`][java-tutorial-switch-statement] για να χειριστείς κομψά τα διάφορα επίπεδα καταγραφής.

## 2. Υποστήριξη άγνωστου επιπέδου καταγραφής

- Υπάρχει μια ειδική περίπτωση στο `switch`, η `default`, που μπορεί να χρησιμοποιηθεί για να καλύπτει περιπτώσεις που δεν έχουν προσδιοριστεί.

## 3. Μετατροπή της γραμμής καταγραφής σε σύντομη μορφή

- Μπορείς να προσθέσεις πεδία και μεθόδους σε έναν τύπο enum, δες τον [οδηγό για την εργασία με enum][java-tutorial-enum-types].
