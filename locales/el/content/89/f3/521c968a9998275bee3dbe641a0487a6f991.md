# Σχετικά με τις συνθήκες

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][operators] μοιάζουν με αυτούς πολλών άλλων γλωσσών, με μερικές επεκτάσεις.

Για την ισότητα, οι τελεστές είναι `==` (ίσο) και `!=` (διάφορο).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Επιπλέον, οι τελεστές `===` και `!==` ελέγχουν την ["αναφορική ισότητα"][referential-equality]:
`a === b` αν και μόνο αν τα `a` και `b` δείχνουν στο ίδιο αντικείμενο.
Αυτό θα βγάλει περισσότερο νόημα αργότερα στη διδακτέα ύλη.

Οι τελεστές μεγαλύτερο/μικρότερο είναι επίσης συμβατικοί.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Διακλάδωση με `if`

Αυτή είναι η πλήρης μορφή μιας [έκφρασης `if`][if-else]:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Οι παρενθέσεις `()` γύρω από κάθε συνθήκη είναι υποχρεωτικές.
- Μια συνθήκη πρέπει να αξιολογείται σε Boolean (λογική τιμή) `true` ή `false`.
  Η Kotlin δεν έχει την έννοια του "truthy" και του "falsy" όπως τη συναντάμε σε κάποιες γλώσσες.
- Τα άγκιστρα `{}` είναι προαιρετικά, αν υπάρχει μόνο μία έκφραση.
- Τόσο το `else if` όσο και το `else` είναι προαιρετικά, και μπορούν να υπάρχουν πολλά μπλοκ `else if`.

Η έκφραση `if` μπορεί επίσης να χρησιμοποιηθεί για να "επιλέξει" μια τιμή:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Εναλλακτικές;

Από σκόπιμη επιλογή, η Kotlin _δεν_ έχει τον τριαδικό τελεστή `? :` που συναντάμε στη Java.
Προτιμάται μια συνοπτική μορφή του `if ... else`:

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

Σε αντίθεση με τη Ruby, η συνοπτική μορφή `if ... else` χρειάζεται *πάντα* ένα `else` και έτσι δεν μπορεί να χρησιμοποιηθεί ως εντολή φύλαξης:

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

Σημείωσε ότι στην Kotlin, το `if` είναι μια [_έκφραση_][expression] που επιστρέφει μια τιμή.
Δεν είναι μια [_εντολή_][statement] όπως στη Java.

Θα δούμε σε μια επόμενη έννοια ότι η Kotlin έχει μια ισχυρή δομή [`when`][when], που προορίζεται να αντικαταστήσει τις μεγάλες αλυσίδες από ρήτρες `else if` με αντιστοίχιση προτύπων.
