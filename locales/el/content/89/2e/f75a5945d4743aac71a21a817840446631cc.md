# Σχετικά

Στη C#, μια πλειάδα είναι μια δομή δεδομένων που οργανώνει δεδομένα, καθώς περιέχει δύο ή περισσότερα πεδία οποιουδήποτε τύπου.

Μια πλειάδα δημιουργείται συνήθως τοποθετώντας δύο ή περισσότερες παραστάσεις χωρισμένες με κόμμα μέσα σε ένα ζεύγος παρενθέσεων.

```csharp
string boast = "All you need to know";
bool success = !string.IsNullOrWhiteSpace(boast);
(bool, int, string) tripple = (success, 42, boast);
```

Ως παράσταση όπως οποιαδήποτε άλλη, μια πλειάδα μπορεί να χρησιμοποιηθεί με πολλούς τρόπους: σε [εκχωρήσεις][tuple-assignment], για την αρχικοποίηση ενός πεδίου ή μιας μεταβλητής, ως [τιμή επιστροφής][tuple-return-values] από μια μέθοδο ή ως παράμετρος. Μπορούν να ελεγχθούν ως προς την [ισότητα][tuple-equality]. Η ισότητα των πλειάδων παρουσιάζεται πλήρως στην άσκηση `pattern-matching-tuples`, αλλά για λόγους πληρότητας δίνεται ένα παράδειγμα στον παρακάτω κώδικα.

Τα πεδία εξάγονται με τη σύνταξη της τελείας. Από προεπιλογή, το πρώτο πεδίο είναι το `Item1`, το δεύτερο το `Item2` κ.ο.κ. Τα μη προεπιλεγμένα ονόματα συζητούνται παρακάτω στην ενότητα _Ονοματοδοσία_.

Μια πλειάδα μπορεί να χρησιμοποιηθεί ως γενική παράμετρος, π.χ. `IList<(bool, string)>`

Επιπλέον, οι πλειάδες υποστηρίζουν την "αποδόμηση", που συζητείται παρακάτω, και μπορούν να χρησιμοποιηθούν στην αντιστοίχιση προτύπων, η οποία καλύπτεται σε μεταγενέστερη άσκηση.

```csharp
// initialization
(int, int, int) vertices = (90, 45, 45);

// assignment
vertices = (60, 60, 60);

//  return value
(bool, int) GetSameOrBigger(int num1, int num2)
{
    return (num1 == num2, num1 > num2 ? num1 : num2);
}

// method argument
int Add((int, int) operands)
{
    return operands.Item1 + operands.Item2;
}

// equality testing
var estimateA = (42, 1729);
var estimateB = (2*3*7, 7*13*19);
bool result = estimateA == estimateB;
// => result == true
```

Αυτή η [εισαγωγή][tuples] δείχνει πώς να ορίσεις και να χρησιμοποιήσεις πλειάδες.

## Ονοματοδοσία

Τα ονόματα πεδίων όπως το `Item1` δεν κάνουν τον κώδικα ευανάγνωστο. Υπάρχουν 3 τρόποι για να δώσεις ονόματα στα πεδία: α) στη δήλωση του τύπου, β) στην παράσταση που τη δημιουργεί, γ) μέσω [αρχικοποιητών προβολής πλειάδας][tuple-projection-initializers] (δεν παρουσιάζονται εδώ).

```csharp
// name items in declaration
(bool success, string message) results = (true, "well done!");
bool mySuccess = results.success;
string myMessaage = results.message;

// name items in creating expression
var results2 = (success: true, message: "well done!");
bool mySuccess2 = results2.success;
string myMessaage2 = results2.message;
```

Μην προσπαθήσεις να γίνεις πολύ έξυπνος με τον μηχανισμό ονοματοδοσίας. Στην πραγματικότητα είναι απλώς συντακτική ζάχαρη. Για παράδειγμα, δεν μπορείς να αλλάξεις τα ονόματα μιας πλειάδας όταν της εκχωρείς τιμές από μια άλλη πλειάδα.

## Αποδόμηση

Μερικές φορές είναι βολικό να πάρεις μια πλειάδα και να εκχωρήσεις τα πεδία της σε πολλές μεταβλητές, αρχικοποιώντας τις αν χρειάζεται. Ο μηχανισμός αυτός ονομάζεται [αποδόμηση][tuple-deconstruction]. (Μπορεί επίσης να εφαρμοστεί στα δικά σου αντικείμενα. Δες [εδώ][udt-deconstruction]).

```csharp
var goodNumbers = (42, 3.142, 1729);
(int ultimateQuestion, var π, var ramanujan) = goodNumbers;
return ultimateQuestion;
// => 42
```

## Εκχώρηση πεδίων

Στα πεδία των πλειάδων μπορεί να γίνει εκχώρηση μεμονωμένα. Ωστόσο, δεδομένης της τάσης της C# προς την αμεταβλητότητα, αυτού του είδους η χρήση δεν είναι διαδεδομένη. Οι πλειάδες χρησιμοποιούνται συχνά σαν να ήταν αμετάβλητες, κάτι που φυσικά δεν ισχύει.

```csharp
(int, string) tpl;
tpl.Item1 = 1;
tpl.Item2 = "bad";
tpl.Item2 = "even worse";
// => (1, "even worse";
```

## Ιστορικό

Οι πλειάδες που συζητάμε δεν πρέπει να συγχέονται με το [`System.Tuple`][system-tuple], το οποίο πιθανότατα θα συναντήσεις μόνο σε βάσεις κώδικα παλαιότερης τεχνολογίας.

Η κατάσταση είναι ελαφρώς πιο μπερδεμένη όταν πρόκειται για το `System.ValueTuple`. Η [τεκμηρίωση][system-value-tuple] για την τελευταία υπερφόρτωση του [`System.ValueTuple`][system-value-tuple] αναφέρει ότι "Οι τύποι πλειάδας τιμών παρέχουν την υλοποίηση χρόνου εκτέλεσης που υποστηρίζει τις πλειάδες στη C#". Με τον όρο "τύποι πλειάδας τιμών" εδώ εννοούν τις γενικές υπερφορτώσεις του `System.ValueTuple`. Με τον όρο "πλειάδες" εννοούν αυτά που μας απασχόλησαν σε αυτή την άσκηση. Στην ουσία λένε ότι το `System.ValueTuple` είναι λεπτομέρεια υλοποίησης των πλειάδων. Αυτό είναι απίθανο να ενδιαφέρει πολύ τους περισσότερους ανθρώπους, τις περισσότερες φορές. Δυστυχώς, μεγάλο μέρος της τεκμηρίωσης για τις "πλειάδες", ακόμη και της ίδιας της Microsoft, είναι γεμάτο με αναφορές στο `System.ValueTuple`. Πιθανότατα είναι ασφαλές να τις προσπεράσεις.

## Άλλες χρήσεις και περιορισμοί

Η αντιστοίχιση προτύπων είναι μια ιδιαίτερα παραγωγική χρήση των πλειάδων. Καλύπτεται σε μεταγενέστερη άσκηση.

Οι πλειάδες επιτρέπουν και κάποιες άλλες μικρές στυλιστικές πινελιές:

- Πολλαπλή εκχώρηση (ιδιαίτερα σε κατασκευαστές), π.χ. `(this.field1, this.field2) = (arg1, arg2);`
- Ανταλλαγή ή ανακύκλωση τιμών, π.χ. `(a, b) = (b, a);`
- Χρήση αντί για `struct` σε μια λίστα
- Χρήση ως κλειδί λεξικού ή ως περιεχόμενο ενός συνόλου.
- Χρήση στο LINQ. (Το LINQ καλύπτεται σε μεταγενέστερες ασκήσεις).

Η τεκμηρίωση περιγράφει τις πλειάδες ως έναν ελαφρύ μηχανισμό και αυτό είναι το κλειδί για την επιτυχημένη χρήση τους. Η χρήση μιας πλειάδας αντί για μια κλάση ή ένα `struct` μπορεί να οδηγήσει σε κουραστική επανάληψη των τύπων πεδίων της και πιθανώς των ονομάτων τους. Αυτό ισχύει ιδιαίτερα για τη χρήση της ως όρισμα μεθόδου ή ως γενικό όρισμα σε συλλογές.

Το καλύτερο είναι να χρησιμοποιείς κόλπους όπως η πολλαπλή εκχώρηση και η ανταλλαγή με σύνεση.

Δεν υποστηρίζονται σχεσιακές πράξεις εκτός από την ισότητα και την ανισότητα.

Σημείωσε ότι οι πλειάδες εισήχθησαν στη γλώσσα σχετικά πρόσφατα (C# 7), οπότε αν θέλεις να τις χρησιμοποιήσεις, φρόντισε η βάση κώδικα σου να χρησιμοποιεί την [έκδοση][language-version] 7 ή μεταγενέστερη της γλώσσας.
