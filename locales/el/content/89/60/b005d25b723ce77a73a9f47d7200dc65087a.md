# Εισαγωγή

## Αρθρώματα

Μέχρι τώρα, όλες οι ασκήσεις που έχεις δει χρησιμοποιούν κλάσεις.
Μερικές φορές δεν χρειαζόμαστε την επιβάρυνση της δημιουργίας ενός αντικειμένου με κατάσταση, οπότε αντί γι' αυτό χρησιμοποιούμε `module`.

Ένα άρθρωμα μοιάζει πολύ με μια κλάση (στην πραγματικότητα, το `Module` είναι ο γονέας του `Class` στην ιεραρχία των αντικειμένων) και η κύρια διαφορά είναι ότι αντί να χρησιμοποιούμε μεθόδους στιγμιοτύπων, χρησιμοποιούμε μεθόδους κλάσης.
Οι μέθοδοι κλάσης ξεκινούν με `self.` και καλούνται απευθείας πάνω σε ένα άρθρωμα.

Για παράδειγμα:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Βρόχοι

Υπάρχουν αρκετοί τρόποι να γράψεις βρόχους στη Ruby, αλλά καθώς γενικά τείνουμε να χρησιμοποιούμε απαρίθμηση αντί για βρόχους, ο βρόχος που συναντάς πιο συχνά είναι ίσως ο `while` βρόχος:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

Μπορείς επίσης να χρησιμοποιήσεις τον αδερφό του, `until`

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
