# Σχετικά

[Οι κλειστές][closures] στη Swift είναι αυτοτελή μπλοκ κώδικα στα οποία μπορούν να περαστούν παράμετροι για να ενεργοποιήσουν τον υπολογισμό τους και να επιστρέψουν τιμές.
Οι κλειστές επίσης συλλαμβάνουν τιμές από το περιβάλλον τους και τις χρησιμοποιούν στους υπολογισμούς τους.
Καθώς είναι αυτοτελείς, μπορούν να μεταβιβάζονται σε ένα πρόγραμμα όπως άλλες τιμές ή να ανατίθενται σε σταθερές και μεταβλητές.

Οι κλειστές μπορεί να μοιάζουν πολύ με τις συναρτήσεις της Swift· και πράγματι μοιάζουν, για καλό λόγο.
Οι συναρτήσεις στη Swift είναι ειδικές περιπτώσεις κλειστών που απαιτείται να έχουν όνομα και ορίζονται χρησιμοποιώντας μια ελαφρώς διαφορετική σύνταξη.

Ενώ οι συναρτήσεις στη Swift είναι τεχνικά κλειστές, όταν οι άνθρωποι αναφέρονται σε "κλειστές" στη Swift, εννοούν τις [κλειστές εκφράσεις][closure-expressions].
Οι κλειστές εκφράσεις γράφονται ως μια λίστα παραμέτρων ακολουθούμενη από έναν τύπο επιστροφής και τη λέξη-κλειδί `in` ακολουθούμενη από το σώμα της κλειστής, όλα μέσα σε ένα ζεύγος αγκίστρων:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Αυτό ορίζει μια κλειστή έκφραση τύπου `(Double, Double) -> Double`, και μπορεί να εκτελεστεί με παρόμοιο τρόπο όπως μια συνάρτηση αυτού του τύπου, εφαρμόζοντάς την σε παραμέτρους του κατάλληλου τύπου:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Καθώς δεν είναι πολύ βολικό να γράφεις ολόκληρη την κλειστή έκφραση κάθε φορά που θέλεις να την εκτελέσεις, οι κλειστές μπορούν να ανατεθούν σε ονόματα, όπως οποιαδήποτε άλλη τιμή στη Swift.
Στη συνέχεια μπορούν να κληθούν εφαρμόζοντας το όνομα στις παραμέτρους:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Όπως φαίνεται παραπάνω, οι κλειστές, όπως οι κανονικές συναρτήσεις, μπορούν να παραλείψουν τη λέξη-κλειδί `return` εάν το σώμα της κλειστής είναι μία μόνο έκφραση.

Τις περισσότερες φορές, οι κλειστές χρησιμοποιούνται με συναρτήσεις υψηλότερης τάξης, είτε περνώντας τις ως παραμέτρους είτε επιστρέφοντάς τις ως αποτελέσματα:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
