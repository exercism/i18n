# Εισαγωγή

Στη Swift, τα closures και οι συναρτήσεις μπορούν να έχουν πρόσβαση σε σταθερές και μεταβλητές από την εμβέλεια που τα περιβάλλει.
Μπορούν επίσης να διατηρούν την πρόσβαση σε αυτές τις τιμές ακόμα και αφού η εμβέλεια που τα περιβάλλει ολοκληρώσει την εκτέλεσή της.
Αυτή η συμπεριφορά ονομάζεται [_σύλληψη τιμών_][capturing-values].

```swift
func makeAdder(base: Int) -> (Int) -> Int {
    func adder(_ i: Int) -> Int {
        base + i
    }
    return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15

func makeLogger(logLevel: String) -> (String) -> Void {
    let logHeader = "[\(logLevel)]: "
    return { msg in print(logHeader, msg) }
}
// makeLogger: (String) -> (String) -> Void

let infoLogger = makeLogger(logLevel: "info")
// infoLogger: (String) -> Void

infoLogger("This is a log message")
// prints "[info]: This is a log message"
```

Στα παραπάνω παραδείγματα, τόσο η `makeAdder(base:)` όσο και η `makeLogger(logLevel:)` επιστρέφουν συναρτήσεις ή closures που συλλαμβάνουν τιμές από την εμβέλεια στην οποία περικλείονται.
Οι συναρτήσεις που επιστρέφονται συνεχίζουν να αναφέρονται σε `base` και `logHeader` ακόμα και αφού οι `makeAdder(base:)` και `makeLogger(logLevel:)` έχουν επιστρέψει.

[capturing-values]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID103
