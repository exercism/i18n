# Προσθήκη οδηγιών

## Η εντολή `apply` της Tcl

Οι περιπτώσεις δοκιμών μπορεί να φαίνονται μπερδεμένες.
Αναμένεται να υλοποιήσεις το εξής:

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

Γιατί αυτό το τελευταίο όρισμα έχει τόσα άγκιστρα;

Θυμήσου ότι η εντολή `proc` ορίζεται ως:

```tcl
proc procName argList body
```

Η Tcl έχει μια εντολή `apply`:

```tcl
apply func ?arg1 arg2 ...?
```

Αυτό το "func" είναι μια λίστα δύο στοιχείων `{argList body}` που είναι ουσιαστικά μια ανώνυμη proc (ή "λάμδα").
Η εντολή `apply` καλεί αυτή την ανώνυμη proc, περνώντας τα ορίσματα που χρειάζεται.

Για παράδειγμα, αυτά είναι ισοδύναμα:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Η χρήση του `apply` κάνει απλούστερη τη μεταβίβαση μπλοκ κώδικα.

Αναφορά: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
