# Υποδείξεις

## Γενικά

- Οι φακοί δεν χρησιμοποιούνται πολύ στη Roc, επειδή η σύνταξη ενημέρωσης καταγραφών καλύπτει ωραία τις περισσότερες περιπτώσεις.
  Για παράδειγμα, δες αυτή την εμφωλευμένη καταγραφή:

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  Τώρα ας κουρέψουμε τον Bob:

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  Δεν χρειάζονται φακοί!

- Παρ' όλα αυτά, αν και οι φακοί είναι σπάνιοι στη Roc, είναι συνηθισμένοι σε άλλες γλώσσες όπως η Haskell και η Scala, οπότε μπορεί να θέλεις να δεις πώς θα μπορούσε κανείς να τους υλοποιήσει στη Roc.
  Είναι επίσης ένας καλός τρόπος να εξασκηθείς σε κάποιες προχωρημένες δυνατότητες της Roc, όπως οι παραμετροποιημένοι τύποι και οι καταγραφές που περιέχουν συναρτήσεις.
  Πράγματι, ορίστε ένας τρόπος να αναπαραστήσεις έναν φακό στη Roc:

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  Αυτός είναι ένας παραμετροποιημένος τύπος: το `whole` και το `part` θα μπορούσαν να είναι οποιοιδήποτε τύποι.
  Το `whole` είναι συνήθως μια καταγραφή, ενώ το `part` μπορεί να είναι οποιουδήποτε τύπου πεδίο.
  Το πεδίο `get` περιέχει μια συνάρτηση που επιστρέφει ένα συγκεκριμένο `part` από το δεδομένο `whole`, ενώ το πεδίο `set` περιέχει μια συνάρτηση που επιστρέφει ένα αντίγραφο του δεδομένου `whole`, με ένα συγκεκριμένο `part` αντικατεστημένο από το δεδομένο `part`.

  Για παράδειγμα, ορίστε ένας φακός για να παίρνεις ή να θέτεις τα μαλλιά ενός ατόμου:

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  Μπορούμε να χρησιμοποιήσουμε αυτόν τον φακό για να εστιάσουμε στα μαλλιά του Bob, έτσι:

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  Και μπορούμε να αλλάξουμε τα μαλλιά του έτσι:

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- Σημείωση: οι παρενθέσεις γύρω από το `hair_lens.set` είναι απαραίτητες: χωρίς αυτές, η Roc θα έψαχνε για μια συνάρτηση με όνομα `set` στον τύπο του `hair_lens`.

- Οι φακοί γίνονται ιδιαίτερα χρήσιμοι όταν αρχίζεις να τους συνθέτεις, αφού σου επιτρέπουν να παίρνεις και να θέτεις βαθιά εμφωλευμένα μέρη.
  Αυτό μπορεί να γίνει υλοποιώντας μια συνάρτηση σαν αυτή:

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  Μόλις υλοποιηθεί αυτή η συνάρτηση, μπορείς να τη χρησιμοποιήσεις για να δημιουργήσεις έναν φακό μήκους μαλλιών έτσι:

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  Τώρα μπορείς να κουρέψεις ξανά τον Bob:

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- Ίσως θελήσεις επίσης να υλοποιήσεις μια συνάρτηση που σου επιτρέπει να εφαρμόζεις οποιονδήποτε μετασχηματισμό σε ένα εμφωλευμένο μέρος:

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  Μόλις την υλοποιήσεις, μπορείς να χρησιμοποιήσεις το `over` έτσι:

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- Σου προτείνουμε πρώτα να περάσεις τα τεστ χρησιμοποιώντας τη σύνταξη ενημέρωσης καταγραφών της Roc και μετά να δοκιμάσεις να χρησιμοποιήσεις φακούς.
