# Οδηγίες

Ως επίδοξη μάγισσα, η Elyse χρειάζεται να εξασκηθεί σε μερικά βασικά.
Έχει μια στοίβα κάρτες που θέλει να χειριστεί.

Για να τα κάνει λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10, ώστε η στοίβα με τις κάρτες της να μπορεί να αναπαρασταθεί με ένα διάνυσμα αριθμών.
Η θέση μιας συγκεκριμένης κάρτας αντιστοιχεί στη θέση της μέσα στο διάνυσμα.

## 1. Πάρε μια κάρτα από τη στοίβα

Για να διαλέξεις μια κάρτα, επέστρεψε την κάρτα στη θέση `position` από τη στοίβα που σου δίνεται.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. Αντάλλαξε μια κάρτα στη στοίβα

Κάνε ένα ταχυδακτυλουργικό κόλπο και αντάλλαξε την κάρτα στη θέση `position` με την κάρτα αντικατάστασης που σου δίνεται.
Επέστρεψε τη στοίβα με τις αλλαγές.

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. Βάλε μια κάρτα στην κορυφή της στοίβας

Κάνε μια κάρτα να εμφανιστεί βάζοντας μια νέα κάρτα στην κορυφή της στοίβας.
Επέστρεψε τη στοίβα με τις αλλαγές.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. Αφαίρεσε μια κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας την κάρτα στη θέση `position` από τη στοίβα.
Επέστρεψε τη στοίβα με τις αλλαγές.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. Αφαίρεσε την πάνω κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας την κάρτα στην κορυφή της στοίβας.
Επέστρεψε τη στοίβα με τις αλλαγές.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. Βάλε μια κάρτα στο κάτω μέρος της στοίβας

Κάνε μια κάρτα να εμφανιστεί βάζοντας μια νέα κάρτα στο κάτω μέρος της στοίβας.

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. Αφαίρεσε μια κάρτα από το κάτω μέρος της στοίβας

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας την κάρτα στο κάτω μέρος της στοίβας.
Επέστρεψε τη στοίβα με τις αλλαγές.

## 8. Έλεγξε το μέγεθος της στοίβας

Έλεγξε αν το μέγεθος της στοίβας είναι ίσο με `stack_size` ή όχι.

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
