# Κονκάρδες ονόματος

## Ιστορία

Σε αυτή την άσκηση θα γράφεις κώδικα για να τυπώνεις κονκάρδες ονόματος για τους εργαζόμενους ενός εργοστασίου. Οι εργαζόμενοι έχουν ένα ID, ένα όνομα και το όνομα του τμήματός τους. Οι ετικέτες των κονκάρδων των εργαζομένων έχουν την εξής μορφή: `"[id] - [name] - [DEPARTMENT]"`.

Εξαιτίας μιας ιδιοτροπίας του υπολογιστικού συστήματος, οι νέοι εργαζόμενοι μερικές φορές δεν έχουν ακόμη ID όταν ξεκινούν να δουλεύουν στο εργοστάσιο. Επειδή οι κονκάρδες είναι υποχρεωτικές, θα πάρουν μια προσωρινή κονκάρδα χωρίς το πρόθεμα ID.

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει κονκάρδα διαρκώς. Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα. Σε αυτή την περίπτωση, η ετικέτα θα πρέπει να τυπώνει `"OWNER"` αντί για το όνομα του τμήματος.

## Εργασίες

Αυτές είναι παραδείγματα εργασιών που ταιριάζουν στην άσκηση με τις κονκάρδες των εργαζομένων:

- Εκτύπωσε μια κονκάρδα για έναν εργαζόμενο
- Εκτύπωσε μια κονκάρδα για έναν νέο εργαζόμενο
- Εκτύπωσε μια κονκάρδα για τον ιδιοκτήτη
