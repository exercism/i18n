# ΡΥΘΜΙΣΗ

Αυτή η διαδρομή χρησιμοποιεί δύο εργαλεία για να τρέχει το σύνολο δοκιμών και να εξασφαλίζει τις βέλτιστες πρακτικές:

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## Εκτέλεση δοκιμών

1. Εγκατέστησε το [vader.vim](https://github.com/junegunn/vader.vim/#installation).
1. Άνοιξε τη λύση σου:
    ```
    $ vim exercise.vim
    ```
1. Κάνε source το τρέχον αρχείο ώστε οι καθολικές συναρτήσεις του να είναι διαθέσιμες στο Vim:
    ```
    :source %
    ```
1. Τρέξε τις δοκιμές:
    ```
    :Vader exercise.vader
    ```

Οι διαδρομές μπορεί να διαφέρουν.

Αν θέλεις έναν βολικό συντομευτικό τρόπο για τα παραπάνω βήματα, βάλε αυτό στο vimrc σου:

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

Έπειτα, άνοιξε οποιοδήποτε αρχείο `.vim` ή `.vader` από έναν κατάλογο άσκησης και τρέξε την εντολή `:Test`.

## Έλεγχος αρχείων Vim

1. Εγκατέστησε το [vint](https://github.com/Kuniwak/vint#quick-start).
1. Έλεγξε αναδρομικά όλα τα αρχεία Vim:
    ```
    $ vint .
    ```

Για πιο αναλυτικές πληροφορίες σχετικά με τη διαδρομή Vim script, δες τη [σελίδα βοήθειας](https://exercism.org/languages/vimscript).
