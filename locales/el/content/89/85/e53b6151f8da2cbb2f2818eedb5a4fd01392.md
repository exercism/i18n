# Εισαγωγή

Στη JavaScript, ένας πίνακας είναι μια δομή που μοιάζει με λίστα, χωρίς σταθερό μήκος, η οποία μπορεί να περιέχει οποιονδήποτε τύπο πρωτογενών τιμών ή αντικειμένων, ακόμη και μεικτούς τύπους.

Για να δημιουργήσεις έναν πίνακα, πρόσθεσε στοιχεία ανάμεσα σε αγκύλες `[]`.
Για να διαβάσεις από τον πίνακα, βάλε τη θέση μέσα σε αγκύλες `[]` μετά το αναγνωριστικό.
Οι θέσεις ενός πίνακα ξεκινούν από το μηδέν.

Για παράδειγμα:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Για να βρεις πόσα στοιχεία έχει ένας πίνακας, χρησιμοποίησε την ιδιότητα `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Για να αλλάξεις ένα στοιχείο του πίνακα, εκχωρείς μια τιμή στη θέση του:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Μέθοδοι

Κάποιες από τις [μεθόδους][array_methods] που είναι διαθέσιμες σε κάθε αντικείμενο Array μπορούν να χρησιμοποιηθούν για να προσθέσεις ή να αφαιρέσεις στοιχεία από τον πίνακα.

### push

> Η μέθοδος `push()` προσθέτει ένα ή περισσότερα στοιχεία στο τέλος ενός πίνακα και επιστρέφει το νέο μήκος του πίνακα.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> Η μέθοδος `pop()` αφαιρεί το τελευταίο στοιχείο από έναν πίνακα και επιστρέφει αυτό το στοιχείο.
> Αυτή η μέθοδος αλλάζει το μήκος του πίνακα.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> Η μέθοδος `shift()` αφαιρεί το πρώτο στοιχείο από έναν πίνακα και επιστρέφει αυτό το στοιχείο που αφαιρέθηκε.
> Αυτή η μέθοδος αλλάζει το μήκος του πίνακα.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> Η μέθοδος unshift() προσθέτει ένα ή περισσότερα στοιχεία στην αρχή ενός πίνακα και επιστρέφει το νέο μήκος του πίνακα.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> Η μέθοδος splice() αλλάζει τα περιεχόμενα ενός πίνακα αφαιρώντας ή αντικαθιστώντας υπάρχοντα στοιχεία ή/και προσθέτοντας νέα στοιχεία επί τόπου. Αυτή η μέθοδος επιστρέφει έναν πίνακα που περιέχει τα στοιχεία που διαγράφηκαν.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
