# Σχετικά

Ένα *ξένο σύνολο* (μια δομή union-find) κρατά μια συλλογή τιμών χωρισμένη σε ομάδες που δεν επικαλύπτονται και απαντά γρήγορα σε μία ερώτηση: βρίσκονται αυτές οι δύο τιμές στην ίδια ομάδα; Ζει στο λεξιλόγιο [`disjoint-sets`][disjoint-sets].

Το `<disjoint-set>` δημιουργεί μια κενή δομή. Οι τιμές, δηλαδή τα *άτομα*, προστίθενται με το `add-atom` ή μαζικά με το `add-atoms`· καθένα ξεκινά σε μια ομάδα μόνο του:

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

Το `equate` ενώνει τις ομάδες που περιέχουν δύο άτομα. Η ένωση είναι μεταβατική: μόλις το `a` εξισωθεί με το `b` και το `b` με το `c`, και τα τρία μοιράζονται μία ομάδα.

```
equate ( atom1 atom2 disjoint-set -- )
```

Κάθε ομάδα προσδιορίζεται από ένα μόνο κανονικό μέλος, τον *αντιπρόσωπό* της. Το `representative` τον επιστρέφει, και δύο άτομα ανήκουν στην ίδια ομάδα αν και μόνο αν οι αντιπρόσωποί τους είναι ίσοι. Το `equiv?` κάνει αυτόν τον έλεγχο απευθείας:

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

Ποιο άτομο επιλέγεται ως αντιπρόσωπος μιας ομάδας είναι εσωτερική λεπτομέρεια: μπορεί να είναι οποιοδήποτε μέλος της ομάδας και μπορεί να αλλάξει καθώς οι ομάδες συγχωνεύονται. Μη βασίζεσαι ποτέ στο ότι ένα συγκεκριμένο άτομο είναι ο αντιπρόσωπος· μόνο στο ότι δύο άτομα στην ίδια ομάδα συμφωνούν.

Το `disjoint-set-members` επιστρέφει κάθε άτομο που έχει προστεθεί.

Η δομή είναι *μεταλλάξιμη*: το `equate` και το `add-atom` αλλάζουν το ξένο σύνολο επιτόπου αντί να επιστρέφουν ένα νέο. Η υλοποίηση χρησιμοποιεί ένωση κατά τάξη με συμπίεση μονοπατιού, οπότε μια μεγάλη σειρά κλήσεων σε `equate` και `representative` έχει ουσιαστικά σταθερό χρόνο η καθεμία.
