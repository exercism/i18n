# Σχετικά

Μια τιμή Boolean αντιπροσωπεύει το αν μια συνθήκη είναι `true` ή `false`.
Στη Go, ο τύπος `bool` μπορεί να πάρει μόνο μία από αυτές τις δύο τιμές.

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## Λογικοί τελεστές

Οι λογικοί τελεστές δρουν σε μία ή δύο τιμές Boolean και παράγουν ένα αποτέλεσμα Boolean.

| Τελεστής | Όνομα | Συμπεριφορά                                       |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | Επιστρέφει το αντίθετο μιας μεμονωμένης τιμής Boolean |
| `&&`     | AND  | Επιστρέφει `true` μόνο όταν και οι δύο πλευρές είναι `true` |
| `\|\|`   | OR   | Επιστρέφει `true` αν οποιαδήποτε πλευρά είναι `true`           |

Χρησιμοποίησε το `!` (NOT) όταν χρειάζεσαι το αντίθετο μιας τιμής Boolean:

```go
!isDoorLocked // false
```

Χρησιμοποίησε το `&&` (AND) όταν και οι δύο συνθήκες πρέπει να είναι `true`:

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

Χρησιμοποίησε το `||` (OR) όταν τουλάχιστον μία συνθήκη πρέπει να είναι `true`:

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

Η σειρά αξιολόγησης των λογικών τελεστών είναι η εξής: πρώτα το `!`, μετά το `&&` και τέλος το `||`.
Χρησιμοποίησε παρενθέσεις για να ομαδοποιήσεις τον κώδικα και να ελέγξεις ποιες πράξεις γίνονται πρώτες:

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
