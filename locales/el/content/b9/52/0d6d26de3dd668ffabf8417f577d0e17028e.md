## Γενικά

Μην υλοποιήσεις το struct `SimpleLinkedList` ως περιτύλιγμα γύρω από ένα `Vec`. Αντ' αυτού, δέσμευσε κόμβους στον σωρό.

Αυτό μπορεί να υλοποιηθεί ως:

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

Το πεδίο `head` δείχνει στο πρώτο στοιχείο (Node) αυτής της συνδεδεμένης λίστας.

Αυτή η υλοποίηση απαιτεί επίσης ένα struct `Node` με τα εξής πεδία:

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

Το `data` περιέχει τα αποθηκευμένα δεδομένα, και το `next` δείχνει στον επόμενο κόμβο (αν υπάρχει) ή None.

## Γιατί `Option<Box<Node<T>>>` και όχι απλώς `Option<Node<T>>`;

Δοκίμασέ το μόνος σου. Θα πάρεις το παρακάτω σφάλμα.

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

Το πρόβλημα είναι ότι κατά τη μεταγλώττιση το μέγεθος του next πρέπει να είναι γνωστό.
Καθώς το `next` είναι αναδρομικό ("ένας κόμβος έχει έναν κόμβο που έχει έναν κόμβο..."), ο μεταγλωττιστής δεν ξέρει πόση μνήμη πρέπει να δεσμευτεί.
Αντίθετα, το [Box](https://doc.rust-lang.org/std/boxed/) είναι ένας δείκτης στον σωρό με καθορισμένο μέγεθος.
