# Εισαγωγή

Τα σχόλια σου επιτρέπουν να αφήνεις σημειώσεις στον κώδικα χωρίς να επηρεάζουν την εκτέλεσή του.
Τα σχόλια μίας γραμμής ξεκινούν με `//`, και τα σχόλια πολλαπλών γραμμών περικλείονται σε `/*` και `*/`:

```go
// This is a single-line comment.

/*
This is a
multiline comment.
*/
```

Τα σχόλια εξυπηρετούν διαφορετικούς σκοπούς ανάλογα με το πού εμφανίζονται.

## Σχόλια κώδικα

Τα σχόλια κώδικα εξηγούν γιατί γίνεται κάτι, όχι τι.
Χρησιμοποίησέ τα όταν ο λόγος πίσω από μια απόφαση δεν είναι προφανής από τον κώδικα:

```go
results = results[1:] // skipping the header row
```

## Σχόλια τεκμηρίωσης

Τα σχόλια τεκμηρίωσης βρίσκονται ακριβώς πριν από μια δήλωση, χωρίς να μεσολαβεί κενή γραμμή ανάμεσα στο σχόλιο και τη δήλωση.
[`godoc`][godoc] τα αναλύει για να δημιουργήσει τεκμηρίωση πακέτου.
Ένα σχόλιο τεκμηρίωσης πρέπει να είναι μια πλήρης πρόταση που ξεκινά με το όνομα του αναγνωριστικού και τελειώνει με τελεία.

Τα σχόλια πακέτου ξεκινούν με το όνομα του πακέτου:

```go
// Package kelvin provides tools to convert temperatures to and from Kelvin.
package kelvin
```

Τα σχόλια συνάρτησης ξεκινούν με το όνομα της συνάρτησης:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```

[godoc]: https://go.dev/blog/godoc
