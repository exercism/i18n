# Συμβολοσειρές

Το `STR` περιέχει κείμενο. Μια συμβολοσειρά γράφεται μέσα σε διπλά εισαγωγικά.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Ένα `STR` δεν αλλάζει ποτέ από τη στιγμή που θα δημιουργηθεί. Όλα όσα ακολουθούν απαντούν με μια *νέα* συμβολοσειρά, αντί να τροποποιούν εκείνη για την οποία ρωτήθηκαν.

## Ένωση

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

Το `+` ενώνει επίσης έναν αριθμό με μια συμβολοσειρά, κι έτσι ένας αριθμός μπαίνει μέσα σε μια πρόταση:

```sather
"Opus " + 27           -- "Opus 27"
```

## Μήκος

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

Το `.size` μετρά χαρακτήρες και η απάντηση είναι ένα `INT`.

## Κομμάτια

| Κλήση | Απάντηση |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Όταν ζητάς περισσότερα από όσα υπάρχουν, παίρνεις πίσω αυτά που υπάρχουν, αντί να αποτύχει.

## Σύγκριση

Το `=` ρωτά αν δύο συμβολοσειρές είναι το ίδιο κείμενο και το `/=` αν διαφέρουν.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Τα πεζά και τα κεφαλαία έχουν σημασία. Τα `.upper` και `.lower` δίνουν ένα αντίγραφο σε πεζά ή σε κεφαλαία, που είναι ο συνηθισμένος τρόπος να συγκρίνεις χωρίς να δίνεις σημασία:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Δύο λόγια για το μέγεθος

Ένα `STR` είναι μια σειρά από bytes και το `.size` μετρά bytes. Για αγγλικό κείμενο αυτό ταυτίζεται με το μέτρημα των γραμμάτων. Για κείμενο με τόνους ή άλλα αλφάβητα δεν ταυτίζεται, γιατί αυτά τα γράμματα πιάνουν περισσότερο από ένα byte το καθένα.
