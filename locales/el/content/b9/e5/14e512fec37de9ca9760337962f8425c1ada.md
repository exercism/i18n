Τα πράγματα όμως είναι λίγο ακατάστατα: οι συντεταγμένες της Azara φαίνεται να έχουν διαφορετική μορφή και σειρά από του Rui, και πρέπει να κοιτάζουν συνεχώς από τη μία λίστα στην άλλη για να καταλάβουν ποιοι θησαυροί πάνε με ποιες τοποθεσίες.
Καθώς είναι νέοι pythonistas, ήρθαν σε σένα για βοήθεια, ώστε να γράψουν ένα μικρό πρόγραμμα (ουσιαστικά, ένα σύνολο συναρτήσεων) που θα οργανώσει καλύτερα τις πληροφορίες του κυνηγιού τους.


## 1. Εξαγωγή συντεταγμένων

Υλοποίησε τη συνάρτηση `get_coordinate()`, που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και επιστρέφει μόνο τη συντεταγμένη του χάρτη που έχει εξαχθεί.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Μορφοποίηση συντεταγμένων

Υλοποίησε τη συνάρτηση `convert_coordinate()`, που παίρνει μια συντεταγμένη με τη μορφή "2A" και επιστρέφει μια πλειάδα με τη μορφή `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Αντιστοίχιση συντεταγμένων

Υλοποίησε τη συνάρτηση `compare_records()`, που παίρνει ένα ζεύγος `(treasure, coordinate)` και μια καταγραφή `(location, coordinate, quadrant)` και συγκρίνει τις συντεταγμένες της καθεμιάς.
Επίστρεψε **`True`** αν οι συντεταγμένες "ταιριάζουν", και **`False`** αν δεν ταιριάζουν.
Μορφοποίησε ξανά τις συντεταγμένες όπως χρειάζεται για σωστή σύγκριση.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Συνδυασμός των ταιριασμένων καταγραφών

Υλοποίησε τη συνάρτηση `create_record()`, που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και μια καταγραφή `(location, coordinate, quadrant)` από τη λίστα του Rui και επιστρέφει `(treasure, coordinate, location, coordinate, quadrant)` **αν οι συντεταγμένες ταιριάζουν**.
Αν οι συντεταγμένες _δεν_ ταιριάζουν, επίστρεψε τη συμβολοσειρά **"not a match"**.
Μορφοποίησε ξανά τη συντεταγμένη όπως χρειάζεται για σωστή σύγκριση.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
