# Εισαγωγή

Η Common Lisp χρησιμοποιεί τους συνήθεις αριθμητικούς τελεστές για τις περισσότερες πράξεις, αλλά είναι κάπως ξεχωριστή στο ότι χρησιμοποιεί "προθεματικό συμβολισμό" αντί για τον πιο οικείο "ενθεματικό συμβολισμό".

Πιο παραστατικά:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Ο προθεματικός συμβολισμός μετατρέπει κάποιες πράξεις, όπως το `2 + 2`, στην κάπως μη οικεία μορφή `(+ 2 2)`, αλλά κάνει πολύ πιο εύκολη τη δουλειά με περισσότερους από έναν αριθμούς ταυτόχρονα.

## Βασικά μαθηματικά

Η Common Lisp έχει όλες τις τυπικές συναρτήσεις: `+`, `-`, `*`, `/` για πρόσθεση, αφαίρεση, πολλαπλασιασμό και διαίρεση.

Όταν εξετάζεις τη διαίρεση, μπορεί να θέλεις να μάθεις το υπόλοιπό της. Αυτό γίνεται με τη συνάρτηση `mod` (για modulo), η οποία παίρνει έναν αριθμό και έναν διαιρέτη ως ορίσματα:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Σύγκριση αριθμών

Τέλος, μπορεί να σου φανεί χρήσιμο να συγκρίνεις διαφορετικούς αριθμούς χρησιμοποιώντας συναρτήσεις όπως `=` (ίσο), `/=` (όχι ίσο) και `>=` (μεγαλύτερο ή ίσο).
Όταν αυτές οι συγκρίσεις είναι αληθείς (όπως στην `(= 1 1)`), επιστρέφουν `T`, και όταν δεν είναι (όπως στην `(> 0 1)`), επιστρέφουν `NIL`.
