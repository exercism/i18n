# Τεστ

## Εκτέλεση των τεστ

Όταν βρίσκεσαι στον φάκελο μιας άσκησης, θα πρέπει να βλέπεις δύο υποφακέλους:

* Ο `src` περιέχει τη λύση σου στην άσκηση
* Ο `spec` περιέχει τα τεστ που θα τρέξεις για την άσκηση

Αν βρίσκεσαι στον σωστό φάκελο (δηλαδή σε αυτόν που περιέχει τα `src` και `spec`), μπορείς να τρέξεις τα τεστ αυτής της άσκησης εκτελώντας `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Αυτό θα τρέξει όλα τα αρχεία τεστ στον φάκελο `spec`.

Σε κάθε αρχείο τεστ, όλα τα τεστ εκτός από το πρώτο έχουν παραλειφθεί.

Μόλις καταφέρεις να περάσει ένα τεστ, μπορείς να ενεργοποιήσεις το επόμενο αλλάζοντας το `pending` σε `it`.

## Μορφοποίηση Crystal

Πριν υποβάλεις τη λύση σου, συνιστάται να τρέξεις το `crystal tool format` πάνω της.

Μπορείς να μορφοποιήσεις τα πάντα στον τρέχοντα φάκελό σου με:

```bash
$ crystal tool format ./
```

Ή μπορείς να μορφοποιήσεις επιλεκτικά αρχεία με:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Υποβολή της λύσης σου

Φρόντισε να υποβάλεις το αρχείο πηγαίου κώδικα στον φάκελο `src` όταν υποβάλλεις τη λύση σου:

```bash
$ exercism submit src/<exercise>.cr
```
