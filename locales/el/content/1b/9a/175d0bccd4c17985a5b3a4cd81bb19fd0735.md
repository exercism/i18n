# Οδηγίες

Υλοποίησε ένα βασικό αντιδραστικό σύστημα.

Ο αντιδραστικός προγραμματισμός είναι ένα προγραμματιστικό παράδειγμα που εστιάζει στον τρόπο με τον οποίο υπολογίζονται οι τιμές η μία σε σχέση με την άλλη, ώστε μια αλλαγή σε μία τιμή να διαδίδεται αυτόματα και στις υπόλοιπες, όπως συμβαίνει σε ένα υπολογιστικό φύλλο.

Υλοποίησε ένα βασικό αντιδραστικό σύστημα με κελιά που έχουν τιμές που μπορούν να οριστούν ("κελιά εισόδου") και κελιά που έχουν τιμές υπολογισμένες με βάση άλλα κελιά ("κελιά υπολογισμού"). Υλοποίησε τις ενημερώσεις έτσι ώστε, όταν αλλάζει μια τιμή εισόδου, οι τιμές να διαδίδονται μέχρι το σύστημα να φτάσει σε μια νέα σταθερή κατάσταση.

Επιπλέον, τα κελιά υπολογισμού θα πρέπει να επιτρέπουν την καταχώριση συναρτήσεων επανάκλησης για ειδοποίηση αλλαγών. Κάλεσε τις συναρτήσεις επανάκλησης ενός κελιού όταν η τιμή του σε μια νέα σταθερή κατάσταση έχει αλλάξει σε σχέση με την προηγούμενη σταθερή κατάσταση.
