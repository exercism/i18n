# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις ένα πρόγραμμα που θα σε βοηθήσει να προετοιμαστείς για την αγορά ενός οχήματος.

Έχεις δύο εργασίες: να καθορίσεις αν θα χρειαστείς άδεια οδήγησης και να εκτιμήσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Καθόρισε αν θα χρειαστείς άδεια οδήγησης

Κάποια είδη οχημάτων απαιτούν άδεια οδήγησης για να τα χειριστείς.
Υπόθεσε ότι μόνο τα οχήματα που περιέχουν `car` ή `truck` απαιτούν άδεια. Όλα τα υπόλοιπα μπορούν να χειριστούν χωρίς άδεια.

Υλοποίησε ένα ζεύγος `pattern {action}` που να ταιριάζει όταν το πρώτο πεδίο είναι `needs_license`.
Θα πρέπει να παίρνει το είδος του οχήματος από το δεύτερο πεδίο και να εκτυπώνει "true" αν χρειάζεσαι άδεια για αυτό το είδος οχήματος.
Αν δεν χρειάζεσαι άδεια, δεν χρειάζεται να εκτυπώσεις τίποτα.

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες την απόφασή σου, θέλεις να βεβαιωθείς ότι θα πάρεις μια δίκαιη τιμή στην αντιπροσωπεία.
Επειδή ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια πρόχειρη εκτίμηση, υπόθεσε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν καινούργιο.
Αν είναι πάνω από 10 ετών, κοστίζει το 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά όχι μεγαλύτερο από 10 ετών, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε ένα ζεύγος `pattern {action}` που να ταιριάζει όταν το πρώτο πεδίο είναι `resell_price`.
Θα πρέπει να παίρνει την αρχική τιμή του οχήματος από το δεύτερο πεδίο και την ηλικία από το τρίτο πεδίο.
Η ενέργεια θα πρέπει να εκτυπώνει την εκτιμώμενη τιμή.

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
