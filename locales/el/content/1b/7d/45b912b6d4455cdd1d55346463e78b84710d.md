* [ετικέτα `awk` στο Stack Overflow][so].
* δες την ενότητα Πόροι στη [σελίδα πληροφοριών της ετικέτας `awk` στο Stack Overflow][so-info].
* άνοιξε ένα issue στο αποθετήριο Github [exercism/awk][github].
* IRC: `irc://irc.liberachat.net/#awk`, `irc://irc.liberachat.net/#exercism`
    * δες το [Libera.chat][libera] αν δεν είσαι εξοικειωμένος με το IRC.
