# Τεστ

Διάλεξε το λειτουργικό σύστημα που χρησιμοποιείς:

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# Εκτέλεση των τεστ

## Windows

1. Άνοιξε ένα Command Prompt.

2. Κατέβασε την πρώτη άσκηση:

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. Πήγαινε στον φάκελο της άσκησης:

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. Εκτέλεσε τα τεστ:

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *(Μην ανησυχείς αν τα τεστ αποτύχουν την πρώτη φορά που θα τα τρέξεις, έτσι ξεκινάς κάθε άσκηση.)*

5. Λύσε την άσκηση. 
    Διάβασε το `instructions.md` και δες πώς να λύσεις την άσκηση ([δες στο GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Καλή τύχη, καλή διασκέδαση και καλώς ήρθες στο track COBOL!

## macOS

1. Άνοιξε ένα παράθυρο Terminal.

2. Κατέβασε την πρώτη άσκηση:

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. Πήγαινε στον φάκελο της άσκησης:

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. Εκτέλεσε τα τεστ:

    ```
     $ bash test.sh
    ```
    *(Μην ανησυχείς αν τα τεστ αποτύχουν την πρώτη φορά που θα τα τρέξεις, έτσι ξεκινάς κάθε άσκηση.)*

    Υπόδειξη: Αν λάβεις μήνυμα ότι λείπει το `basename`, μπορείς να χρησιμοποιήσεις το [brew](https://brew.sh/) για να εγκαταστήσεις το coreutils. (`brew install coreutils`)

5. Λύσε την άσκηση. 

    Διάβασε το `instructions.md` και δες πώς να λύσεις την άσκηση ([δες στο GitHub](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)).


Καλή τύχη, καλή διασκέδαση και καλώς ήρθες στο track COBOL!
