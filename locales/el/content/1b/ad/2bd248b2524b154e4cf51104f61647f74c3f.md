# Θέση συμπλήρωσης

## Συναρτήσεις χρόνου

Αυτή η άσκηση απαιτεί τη χρήση των [Συναρτήσεων χρόνου][time-func] του GNU awk.

Για τις συναρτήσεις ανάλυσης και μορφοποίησης ημερομηνίας και ώρας, φρόντισε να **ορίσεις τη σημαία UTC**.
Για να το δείξουμε:

```sh
export TZ=Asia/Kolkata
gawk 'BEGIN {
    time = 1234567890
    print strftime("%Y-%m-%d %T", time)     # format for local timezone
    print strftime("%Y-%m-%d %T", time, 1)  # format for UTC
}'
```

εμφανίζει:

```none
2009-02-14 05:01:30
2009-02-13 23:31:30
```

[time-func]: https://www.gnu.org/software/gawk/manual/html_node/Time-Functions.html
