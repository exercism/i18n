# Συνθήκες

Η Crystal έχει αυτό που ονομάζουμε εκφράσεις ελέγχου· αυτές χρησιμοποιούνται για να ελέγχουν τον τρόπο με τον οποίο θα τρέξει το πρόγραμμα και παίρνουν μια τιμή truthy ή falsey.
Υπάρχουν τελεστές που μπορούν να χρησιμοποιηθούν για να δημιουργήσουν τιμές truthy ή falsey, και είναι γνωστοί ως [τελεστές ισότητας και σύγκρισης][equality-and-comparison].

Υπάρχουν δύο κύριες εκφράσεις ελέγχου που χρησιμοποιούνται για να καθορίσουν ποιος κώδικας θα εκτελεστεί και ποιος όχι.
Δηλαδή, ποιος κλάδος θα εκτελεστεί κάθε φορά.

Αυτές οι δύο είναι: η `if` και η `unless`.

## Τελεστές σύγκρισης

Οι τελεστές σύγκρισης χρησιμοποιούνται για να συγκρίνουν τιμές και επιστρέφουν μια τιμή `true` ή `false`.
Αυτοί οι τελεστές απαιτούν δύο τιμές του ίδιου τύπου για να συγκριθούν.
Αν οι τιμές δεν είναι του ίδιου τύπου, τότε ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Εδώ είναι μια λίστα με τους τελεστές σύγκρισης και ένα παράδειγμα για το πότε δίνουν μια τιμή `true`:

| Μέθοδος | Περιγραφή           | Παράδειγμα |
| ------ | --------------------- | ------- |
| <      | μικρότερο από             | 4 < 5   |
| <=     | μικρότερο ή ίσο με    | 4 <= 4  |
| >      | μεγαλύτερο από          | 3 > 1   |
| >=     | μεγαλύτερο ή ίσο με | 2 >= 2  |

## Τελεστές ισότητας

Οι τελεστές ισότητας είναι παρόμοιοι με τους τελεστές σύγκρισης, αλλά χρησιμοποιούνται για να ελέγξουν αν δύο τιμές είναι ίσες ή όχι.

Ο τελεστής `==` ελέγχει αν δύο τιμές είναι ίσες, συμπεριλαμβανομένου του τύπου της τιμής.
Αν οι τιμές είναι ίδιες, τότε θα επιστρέψει `true`, αλλιώς θα επιστρέψει `false`.
Ο τελεστής `==` μπορεί να συγκρίνει οποιονδήποτε τύπο τιμής με οποιονδήποτε άλλο τύπο τιμής.
Ο `!=` λειτουργεί με τον ίδιο τρόπο, αλλά θα επιστρέψει `true` αν οι τιμές δεν είναι ίσες και `false` αν είναι ίσες.

## Ο τελεστής spaceship

Ο τελεστής spaceship είναι ένας ξεχωριστός τελεστής σύγκρισης και το όνομά του προέρχεται από την όψη του.
Είναι ξεχωριστός με την έννοια ότι δεν επιστρέφει μια τιμή truthy ή falsey, αλλά έναν αριθμό.
Γράφεται ως `<=>` και χρησιμοποιείται για να συγκρίνει δύο τιμές.
Θα επιστρέψει `1` αν η αριστερή τιμή είναι μεγαλύτερη από τη δεξιά, `-1` αν η αριστερή τιμή είναι μικρότερη από τη δεξιά, και `0` αν οι τιμές είναι ίσες.

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## Η εντολή `if`

Η εντολή [`if`][if] χρησιμοποιείται για να ελέγξει αν μια δεδομένη συνθήκη είναι truthy ή falsey.
Αν η συνθήκη είναι truthy, τότε ο κώδικας μέσα στην εντολή `if` θα εκτελεστεί.
Μια εντολή `if` τελειώνει με τη λέξη-κλειδί `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Η εντολή `unless`

Η εντολή [`unless`][unless] λειτουργεί πολύ παρόμοια με την εντολή `if`, αλλά θα εκτελέσει τον κώδικα μέσα στην εντολή `unless` αν η συνθήκη είναι falsey.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Η εντολή `else`

Η εντολή `else` μπορεί να χρησιμοποιηθεί μαζί με τις εντολές `if` και `unless`.
Η εντολή `else` θα εκτελεστεί αν ο κλάδος `if` ή ο κλάδος `unless` δεν εκτελεστεί.

~~~~exercism/warning
Ακόμα κι αν ένας κλάδος `else` μπορεί να χρησιμοποιηθεί μαζί με το `unless,` κάτι τέτοιο αποθαρρύνεται, γιατί βλάπτει την αναγνωσιμότητα.
Αντ' αυτού, συνιστάται η χρήση του `if !condition` με έναν κλάδο else.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## Εντολές "cascading-if"

Η εντολή `elsif` μπορεί να χρησιμοποιηθεί μαζί με την εντολή `if`.
Η εντολή `elsif` θα εκτελεστεί αν ο κλάδος `if` δεν εκτελεστεί και η συνθήκη της εντολής `elsif` είναι truthy.
Οι εντολές `elsif` μπορούν να συνδεθούν σε αλυσίδα και η πρώτη συνθήκη που είναι truthy θα εκτελεστεί.
Μπορεί επίσης να υπάρχει μια εντολή else στο τέλος της εντολής if, η οποία θα εκτελεστεί αν καμία από τις προηγούμενες εντολές δεν ήταν αληθής.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Ο τριαδικός τελεστής

Η Crystal έχει έναν τριαδικό τελεστή, μια εντολή if-else σε μία γραμμή: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## Τα if και unless ως επίθημα

Οι εντολές if και unless μπορούν επίσης να χρησιμοποιηθούν ως [επίθημα][if-as-suffix]· αυτό είναι χρήσιμο όταν θέλεις να εκτελέσεις μία μόνο γραμμή κώδικα αν μια συνθήκη είναι αληθής.
Γίνεται βάζοντας την εντολή if ή unless μετά τον κώδικα που θέλεις να εκτελέσεις.

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## Τύποι με συνθήκες

Όταν η μεταβλητή ανατίθεται σε διαφορετικούς τύπους, θα φέρει και τους δύο τύπους.
Αυτό συμβαίνει επειδή ο μεταγλωττιστής δεν γνωρίζει ποιος κλάδος θα εκτελεστεί.
Αυτή η πολλαπλή ανάθεση, γνωστή και ως ένωση, θα εξηγηθεί σε επόμενες έννοιες.
Αυτό φαίνεται στο παρακάτω παράδειγμα:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
