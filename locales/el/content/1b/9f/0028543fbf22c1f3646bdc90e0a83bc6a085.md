# Εισαγωγή

Οι κανονικές εκφράσεις στην Elixir ακολουθούν την προδιαγραφή **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), όπως και άλλες δημοφιλείς γλώσσες, όπως η Java, η JavaScript ή η Ruby.

Η μονάδα `Regex` προσφέρει συναρτήσεις για να δουλεύεις με κανονικές εκφράσεις. Κάποιες από τις συναρτήσεις της μονάδας `String` δέχονται επίσης κανονικές εκφράσεις ως ορίσματα.

~~~~exercism/note
Αυτή η άσκηση υποθέτει ότι γνωρίζεις ήδη τη σύνταξη των κανονικών εκφράσεων, συμπεριλαμβανομένων των κλάσεων χαρακτήρων, των ποσοδεικτών, των ομάδων και των συλλήψεων.

Αν χρειάζεται να φρεσκάρεις τις γνώσεις σου στις κανονικές εκφράσεις, ρίξε μια ματιά σε μία από αυτές τις πηγές: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

## Σίγιλ

Ο πιο συνηθισμένος τρόπος για να δημιουργήσεις κανονικές εκφράσεις είναι με το σίγιλ `~r`.

```elixir
~r/test/
```

Σημείωσε ότι όλα τα σίγιλ της Elixir υποστηρίζουν [διαφορετικά είδη οριοθετών][sigils], όχι μόνο το `/`.

## Αντιστοίχιση

Ο τελεστής `=~/2` μπορεί να χρησιμοποιηθεί για να εκτελέσεις μια αντιστοίχιση κανονικής έκφρασης που επιστρέφει αποτέλεσμα `boolean`. Εναλλακτικά, υπάρχουν και οι συναρτήσεις `match?/2` τόσο στη μονάδα `Regex` όσο και στη μονάδα `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## Σύλληψη

Αν ένας απλός έλεγχος boolean (λογική τιμή) δεν αρκεί, χρησιμοποίησε τη συνάρτηση `Regex.run/3` για να πάρεις μια λίστα με όλες τις συλλήψεις (ή `nil` αν δεν υπήρξε αντιστοίχιση). Το πρώτο στοιχείο της λίστας που επιστρέφεται είναι πάντα μια αντιστοίχιση για ολόκληρη την κανονική έκφραση, και τα επόμενα στοιχεία είναι οι ομάδες που αντιστοιχίστηκαν.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## Τροποποιητές

Η συμπεριφορά μιας κανονικής έκφρασης μπορεί να τροποποιηθεί προσθέτοντας ειδικές σημαίες. Όταν χρησιμοποιείς ένα σίγιλ για να δημιουργήσεις μια κανονική έκφραση, πρόσθεσε τους τροποποιητές μετά τον δεύτερο οριοθέτη.

Συνηθισμένοι τροποποιητές είναι:
- `i` - η αντιστοίχιση δεν κάνει διάκριση πεζών-κεφαλαίων.
- `u` - ενεργοποιεί μοτίβα ειδικά για το Unicode, όπως το `\p`, και κάνει κλάσεις χαρακτήρων όπως τα `\w`, `\s` κ.λπ. να αντιστοιχίζουν και χαρακτήρες Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
