# Προσθήκη στις οδηγίες

## Σχετικά με το Enum

Η εντολή `enum` σου επιτρέπει να δημιουργήσεις ένα ισχυρά τυποποιημένο σύνολο ετικετών.
Μπορείς να χρησιμοποιείς αυτή την απαρίθμηση στον κώδικα χωρίς να χρειάζεται να κάνεις ανάλυση ή να ελέγχεις για ορθογραφικά λάθη.

Οι απαριθμήσεις αναπαρίστανται εσωτερικά ως ακέραιοι με αρχική τιμή το μηδέν.
Από προεπιλογή, το PowerShell αναθέτει στην πρώτη ετικέτα της λίστας την τιμή μηδέν και στις υπόλοιπες ετικέτες διαδοχικούς ακεραίους.

Παράδειγμα:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Για να μάθεις περισσότερα για το Enum στο PowerShell, δες την [ενότητα Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
