# χωρίς ακέραιο λεκτικό

Η Elixir έχει μια [ειδική σύνταξη](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) για να γράφεις ακέραιους που αντιστοιχούν σε [Σημεία Κώδικα Unicode](https://en.wikipedia.org/wiki/Code_point): μπορείς να βάλεις ένα `?` μπροστά από το λεκτικό του χαρακτήρα για να αποκαλύψεις το σημείο κώδικα του.

Για παράδειγμα,

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

Όταν επεξεργάζεσαι σημεία κώδικα, αυτή η σημειογραφία είναι πολύ πιο ευανάγνωστη από τους αριθμούς και είναι πάντα προτιμότερη.
