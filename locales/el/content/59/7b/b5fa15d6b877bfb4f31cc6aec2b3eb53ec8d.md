# Εισαγωγή

Εργάζεσαι για μια κρατική υπηρεσία που έχει υποκλέψει μια σειρά από κρυπτογραφημένα σήματα επικοινωνίας από μια ομάδα ληστών τραπεζών.
Τα σήματα περιέχουν μια μεγάλη ακολουθία ψηφίων.
Η ομάδα σου πρέπει να χρησιμοποιήσει διάφορες τεχνικές ψηφιακής επεξεργασίας σήματος για να αναλύσει τα σήματα και να εντοπίσει τυχόν μοτίβα που μπορεί να υποδεικνύουν τον σχεδιασμό μιας ληστείας.
