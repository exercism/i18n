# Σχετικά

Τα νήματα του Factor είναι *συνεργατικές συνρουτίνες* σε ένα μόνο νήμα του λειτουργικού συστήματος.
Ένα νήμα τρέχει μέχρι να παραχωρήσει ρητά τον έλεγχο ή να εκτελέσει κάποια λειτουργία I/O που μπλοκάρει,
οπότε ο χρονοδρομολογητής επιλέγει ένα άλλο εκτελέσιμο νήμα. Από αυτό
προκύπτουν δύο πράγματα:

- Ό,τι συμβαίνει ανάμεσα σε δύο σημεία παραχώρησης του ελέγχου είναι στην πράξη ατομικό.
- Ο πραγματικός παραλληλισμός σε πολλούς πυρήνες απαιτεί να βγεις έξω από το τυπικό
  vocab `threads` (για παράδειγμα, το `concurrency.distributed` για σχεδιασμούς με
  πολλαπλές διεργασίες).

Τα τυπικά στοιχεία ταυτοχρονισμού είναι οργανωμένα σε επίπεδα:

| Vocab                       | Παρέχει                               |
|-----------------------------|----------------------------------------|
| [`threads`][threads]                   | `spawn`, `yield`, ταυτότητα νήματος      |
| [`concurrency.promises`][concurrency.promises]      | `<promise>`, `fulfill`, `?promise`     |
| [`concurrency.locks`][concurrency.locks]         | `<lock>`, `with-lock`                  |
| [`concurrency.combinators`][concurrency.combinators]   | `parallel-map`, `parallel-each`        |
| [`concurrency.semaphores`][concurrency.semaphores]    | `<semaphore>`, `acquire`, `release`    |
| [`concurrency.mailboxes`][concurrency.mailboxes]     | γραμματοκιβώτια ανά νήμα, `send`, `receive`  |
| [`concurrency.channels`][concurrency.channels]      | λαβές συνάντησης, `to`, `from`       |

```factor
USING: concurrency.combinators concurrency.locks
concurrency.promises kernel sequences threads ;

! parallel-map: fork-join, in order
{ "alpha" "beta" "gamma" } [ length ] parallel-map .
! => { 5 4 5 }

! spawn + promise: hand-rolled fork-join
<promise> [
    [ "hello, world" swap fulfill ] curry "greeter" spawn drop
] keep ?promise .   ! => "hello, world"

! <lock> + with-lock: protect a shared mutable slot
<lock> :> guard
guard [ "do thing under lock" drop ] with-lock
```

Το `parallel-map` είναι το API υψηλού επιπέδου και αυτό στο οποίο καταφεύγει πρώτα ο
ιδιωματικός Factor. Η τριάδα `spawn` / `<promise>` / `?promise` είναι το υλικό από το
οποίο έχει χτιστεί το `parallel-map`, και είναι βολική όταν το σχήμα της επανάληψης δεν
ταιριάζει με το map (για παράδειγμα, όταν ξεκινάς νήματα εργάτες που σου απαντούν μέσα από
άλλα κανάλια).

Τα κλειδώματα προστατεύουν την *κοινόχρηστη μεταβλητή κατάσταση*, συνήθως μια θέση
πλειάδας ή έναν πίνακα κατακερματισμού που τον διαβάζουν ή τον γράφουν περισσότερα από ένα
νήματα. Αντιμετώπισε και τις αναγνώσεις και τις εγγραφές σαν να χρειάζονται το κλείδωμα,
αν υπάρχει έστω και μία μη ατομική σύνθετη ενημέρωση. Το να ξεχάσεις το κλείδωμα από τη
μία ή την άλλη πλευρά είναι η κλασική συνταγή για μια κομματιασμένη ανάγνωση.
