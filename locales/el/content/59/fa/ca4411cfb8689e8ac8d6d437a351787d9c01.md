# Βρόχοι

```sather
   loop
      ...
   end;
```

Η Sather έχει ακριβώς μία εντολή βρόχου. Δεν υπάρχει `while` ούτε `for`· και τα δύο χτίζονται από το `loop` και από κάτι που το τερματίζει.

## Μεταβλητές

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

Το `::=` δηλώνει και παίρνει τον τύπο από την τιμή που δίνεται. Όταν μια μεταβλητή πρέπει να υπάρχει πριν υπάρξει τιμή γι' αυτήν, δήλωσέ την με τύπο:

```sather
   total : INT;
   total := 0;
```

Μια μεταβλητή που δηλώνεται χωρίς τιμή ξεκινά ως μηδέν για το `INT`, ως `false` για το `BOOL` και ως void για μια συμβολοσειρά ή ένα αντικείμενο.

## Τερματισμός ενός βρόχου

| Τι γράφεις | Τερματίζει τον βρόχο |
| --- | --- |
| `until!(q)` | όταν το `q` είναι αληθές |
| `while!(q)` | όταν το `q` είναι ψευδές |
| `break!` | αμέσως |

Και τα τρία μπορούν να εμφανιστούν οπουδήποτε στο σώμα, και ένας βρόχος μπορεί να χρησιμοποιήσει περισσότερα από ένα.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## Το θαυμαστικό

Τα `until!`, `while!` και `break!` τελειώνουν σε `!` επειδή είναι **επαναλήπτες**, δηλαδή πράγματα που μπορούν να εμφανιστούν μόνο μέσα σε έναν βρόχο και που μπορούν να τον τερματίσουν. Το να γράψεις έναν από αυτούς έξω από έναν βρόχο είναι σφάλμα και όχι προειδοποίηση. Οι επόμενες ασκήσεις χρησιμοποιούν τους άλλους επαναλήπτες της βιβλιοθήκης και, τελικά, γράφεις καινούριους.

## Βρόχοι για πάντα

Ένας βρόχος που δεν έχει τίποτα να τον τερματίσει τρέχει για πάντα. Καμιά φορά αυτό είναι όντως το επιθυμητό, αλλά πολύ πιο συχνά σημαίνει ότι η τιμή για την οποία ρωτά η συνθήκη δεν αλλάζει ποτέ. Αν ένα πρόγραμμα κολλήσει, το πρώτο πράγμα που πρέπει να ελέγξεις είναι αν κάτι μέσα στον βρόχο το κινεί προς τον τερματισμό.
