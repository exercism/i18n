# Υποδείξεις

## 1. Διπλασίασε κάθε φύλλο

- Υπάρχει μια ενσωματωμένη μέθοδος που είναι ιδανική για [απλούς μετασχηματισμούς][map_method_docs] σαν αυτόν.

## 2. Δημιούργησε πολλαπλά αντίγραφα για κάθε 3 που βρίσκεται στην τράπουλα

- Υπάρχει μια ενσωματωμένη μέθοδος ιδανική για προσαρμοσμένους μετασχηματισμούς ή [συσσωρεύσεις][reduce_method_docs] (όπως το άθροισμα ενός πίνακα, κ.λπ.)

## 3. Βρες δύο φύλλα από το ακριβές κέντρο της τράπουλας

- Υπάρχει μια ενσωματωμένη μέθοδος για [κοπή και τεμαχισμό][slice_method_docs] πινάκων σε μικρότερα τμήματα.

## 4. Τα δύο εξωτερικά φύλλα θα εμφανιστούν ξανά στη μέση της τράπουλας

- Υπάρχει μια ενσωματωμένη μέθοδος για την [εισαγωγή ή αφαίρεση][splice_method_docs] στοιχείων από τη μέση ενός πίνακα.
- Ο πίνακας έχει επίσης ενσωματωμένες μεθόδους για την αφαίρεση του πρώτου και του τελευταίου στοιχείου, δες την [τεκμηρίωση του Array στο MDN][array_docs].

## 5. Κάθε φύλλο που δεν είναι 2 εξαφανίζεται

- Υπάρχει μια ενσωματωμένη μέθοδος για το [φιλτράρισμα][filter_method_docs] ή τον αποκλεισμό στοιχείων σε έναν πίνακα.

## 6. Μετέτρεψε μια ανακατεμένη τράπουλα σε μια τέλεια ταξινομημένη τράπουλα

- Υπάρχει μια ενσωματωμένη μέθοδος για [ταξινόμηση][sort_method_docs].

## 7. Αναδιάταξε την τράπουλα

- Υπάρχει μια ενσωματωμένη μέθοδος για την [αντιστροφή][reverse_method_docs] ενός πίνακα.
