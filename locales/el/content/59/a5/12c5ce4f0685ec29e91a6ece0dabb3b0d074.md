# Εισαγωγή

Μια [εντολή `switch`][switch] συγκρίνει μια τιμή με πολλαπλά πιθανά μοτίβα αντιστοίχισης.
Προσφέρει μια πιο καθαρή και πιο ευανάγνωστη εναλλακτική αντί να αλυσιδώνεις πολλαπλές εντολές `if-else`.

Μια εντολή `switch` ξεκινά με τη λέξη-κλειδί `switch` ακολουθούμενη από την τιμή που θα ελεγχθεί.
Κάθε πιθανή αντιστοίχιση εισάγεται με τη λέξη-κλειδί `case`.
Η λέξη-κλειδί `default` ορίζει μια εφεδρική περίπτωση που εκτελείται αν καμία από τις ρητές περιπτώσεις δεν ταιριάζει.
Όπως και οι αλυσίδες `if-else`, μια εντολή `switch` εκτελεί μόνο το μπλοκ κώδικα που σχετίζεται με την πρώτη περίπτωση που ταιριάζει.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Δες την παρακάτω αλυσίδα `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Αυτό μπορεί να γραφτεί πιο καθαρά με μια εντολή `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
