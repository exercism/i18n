# Οδηγίες

Ανέφερε στατιστικά I/O δικτύου.

Γράφεις ένα [PaaS][paas] και χρειάζεσαι έναν τρόπο να χρεώνεις τους πελάτες με βάση τη χρήση δικτύου και συστήματος αρχείων.

Δημιούργησε ένα περιτύλιγμα για συνδέσεις δικτύου και αρχεία που μπορεί να αναφέρει στατιστικά I/O.
Το περιτύλιγμα πρέπει να αναφέρει:

- Τον συνολικό αριθμό των bytes που διαβάστηκαν/γράφτηκαν.
- Τον συνολικό αριθμό των λειτουργιών ανάγνωσης/εγγραφής.

[paas]: https://en.wikipedia.org/wiki/Platform_as_a_service
