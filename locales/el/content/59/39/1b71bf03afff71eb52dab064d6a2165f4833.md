# Σχετικά

Το [Nil][nil-dictionary] είναι μια αγγλική λέξη που σημαίνει "τίποτα" ή "μηδέν".
Στη Ruby, το `nil` είναι ένα αντικείμενο που χρησιμοποιείται για να εκφράσει την _απουσία_ μιας τιμής.
Σε άλλες γλώσσες προγραμματισμού, τιμές όπως `null` ή `none` μπορεί να παίζουν παρόμοιο ρόλο.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Η Ruby δίνει σε κάθε μεταβλητή στιγμιοτύπου την προεπιλεγμένη τιμή `nil` όταν τη συναντήσει για πρώτη φορά, μέχρι να οριστεί κάτι διαφορετικό.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
