# Συμβουλές

## Γενικά

- Τα αντικείμενα μιας δομής δημιουργούνται δηλώνοντας το όνομα της δομής και μετά τις τιμές των πεδίων μέσα σε άγκιστρα.
- Ο `@T` μπορεί να χρησιμοποιηθεί για να δηλώσεις στιγμιότυπα κάποιου τύπου `T`, π.χ. το `let i: @u32 = @1;` δηλώνει μια μεταβλητή `i` που είναι στιγμιότυπο της τιμής `1` του `u32`.
- Μπορείς να εξάγεις μια τιμή από ένα στιγμιότυπο χρησιμοποιώντας τον τελεστή `*` (desnap), π.χ. το `let int = *an_int_snapshot;`.
- Μπορείς να κάνεις μια τιμή μεταβλητή χρησιμοποιώντας τη λέξη-κλειδί `mut`, όπως στο `let mut i = 1;`.

## 1. Δημιούργησε έναν μετρητή ψήφων

- Πρέπει να δημιουργήσεις έναν δείκτη σε μια δομή `VoteCounter`, με άλλα λόγια, ένα `@VoteCounter`.
- Μπορείς να αντιστοιχίσεις απευθείας την παράμετρο `value` όταν δημιουργείς ένα αντικείμενο δομής.

## 2. Πάρε τον αριθμό των ψήφων από έναν μετρητή

- Μπορείς να χρησιμοποιήσεις τον τελεστή `*` σε ένα στιγμιότυπο για να το κάνεις desnap και να πάρεις την τιμή του, π.χ. `*my_snapshot`

## 3. Αύξησε τις ψήφους ενός μετρητή

- Αντί να τροποποιήσεις το στιγμιότυπο `@VoteCounter`, πρέπει να επιστρέψεις ένα νέο αντικείμενο `VoteCounter` με τις ψήφους αυξημένες.
- Μπορείς να κάνεις desnap την υποκείμενη τιμή του μετρητή ψήφων χρησιμοποιώντας τον τελεστή `*`, ή να καλέσεις τη συνάρτηση που έφτιαξες στην προηγούμενη εργασία.

## 4. Δημιούργησε τα αποτελέσματα των εκλογών

- Δημιούργησε μια νέα δομή ή μεταβλητή `ElectionResult` με τα πεδία `name` και `vote_counter` να παίρνουν τις τιμές των ορισμάτων της συνάρτησης.
- Μπορείς να δημιουργήσεις ένα στιγμιότυπο `VoteCounter` χρησιμοποιώντας τον τελεστή `@` πριν από το όνομα της μεταβλητής ή τη δήλωση της δομής, ή να καλέσεις τη συνάρτηση `new_vote_counter` που έφτιαξες σε κάποια από τις προηγούμενες εργασίες.

## 5. Ανακοίνωσε τα αποτελέσματα

- Αν και λαμβάνεις ένα στιγμιότυπο ενός `ElectionResult`, μπορείς να προσπελάσεις τα πεδία του με τη σημειογραφία της τελείας `.`, σαν να μην ήταν στιγμιότυπο!
- Φτιάξε το μήνυμα προσπελάσσοντας τα πεδία `name` και `vote_counter` της δομής.
- Όταν κάνεις desnap ένα εμφωλευμένο στιγμιότυπο, πρέπει να εφαρμόσεις τόσους τελεστές `*` όσα είναι τα στιγμιότυπα που θέλεις να κάνεις desnap:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Επανακαταμέτρηση ψήφων

- Εξαιτίας του [τρόπου με τον οποίο υλοποιούνται τα λεξικά][dictionaries underneath], απαιτείται να είναι μεταβλητά για να μπορείς και να τα τροποποιείς και να διαβάζεις από αυτά, που σημαίνει ότι οι αλλαγές που κάνεις στο λεξικό μέσα στη συνάρτηση θα είναι ορατές και έξω από τη συνάρτηση.
- Για να αυξήσεις την τιμή ενός κλειδιού σε ένα `let mut m: Felt252Dict<u32>`, θα πρέπει να συνδυάσεις τις συναρτήσεις `get` και `insert`: `m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
