# Οδηγίες

Σε αυτή την άσκηση παίζεις ένα παιχνίδι ρόλων με το όνομα "Wizard and Warriors", στο οποίο μπορείς να παίξεις είτε ως Wizard είτε ως Warrior.

Υπάρχουν διαφορετικοί κανόνες για τους Warriors και τους Wizards που καθορίζουν πόσους πόντους ζημιάς προκαλούν.

Για έναν Warrior, οι κανόνες είναι οι εξής:

- Προκαλεί 6 πόντους ζημιάς αν ο χαρακτήρας που επιτίθεται δεν είναι ευάλωτος
- Προκαλεί 10 πόντους ζημιάς αν ο χαρακτήρας που επιτίθεται είναι ευάλωτος

Για έναν Wizard, οι κανόνες είναι οι εξής:

- Προκαλεί 12 πόντους ζημιάς αν ο Wizard έχει προετοιμάσει ένα ξόρκι εκ των προτέρων
- Προκαλεί 3 πόντους ζημιάς αν ο Wizard δεν έχει προετοιμάσει ένα ξόρκι εκ των προτέρων

Γενικά, οι χαρακτήρες δεν είναι ποτέ ευάλωτοι. Ωστόσο, οι Wizards _είναι_ ευάλωτοι αν δεν έχουν προετοιμάσει ένα ξόρκι.

Έχεις έξι εργασίες που δουλεύουν με χαρακτήρες Warrior και Wizard.

## 1. Περιγράψε έναν χαρακτήρα

Κάνε override τη μέθοδο `ToString()` της κλάσης `Character` ώστε να επιστρέφει μια περιγραφή του χαρακτήρα, με τη μορφή `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Κάνε τους χαρακτήρες μη ευάλωτους από προεπιλογή

Βεβαιώσου ότι η μέθοδος `Character.Vulnerable()` επιστρέφει πάντα `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Επίτρεψε στους Wizards να προετοιμάζουν ένα ξόρκι

Υλοποίησε τη μέθοδο `Wizard.PrepareSpell()` ώστε να επιτρέπει σε έναν Wizard να προετοιμάσει ένα ξόρκι εκ των προτέρων.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Κάνε τους Wizards ευάλωτους όταν δεν έχουν προετοιμάσει ένα ξόρκι

Βεβαιώσου ότι η μέθοδος `Vulnerable()` επιστρέφει `true` αν ο wizard δεν έχει προετοιμάσει ένα ξόρκι, αλλιώς επιστρέφει `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Υπολόγισε τους πόντους ζημιάς για έναν Wizard

Υλοποίησε τη μέθοδο `Wizard.DamagePoints()` ώστε να επιστρέφει τους πόντους ζημιάς που προκαλούνται: 12 πόντους ζημιάς όταν έχει προετοιμαστεί ένα ξόρκι, 3 πόντους ζημιάς όταν όχι.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Υπολόγισε τους πόντους ζημιάς για έναν Warrior

Υλοποίησε τη μέθοδο `Warrior.DamagePoints()` ώστε να επιστρέφει τους πόντους ζημιάς που προκαλούνται: 10 πόντους ζημιάς όταν ο στόχος είναι ευάλωτος, 6 πόντους ζημιάς όταν όχι.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
