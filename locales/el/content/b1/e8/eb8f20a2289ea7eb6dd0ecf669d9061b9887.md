# Μέθοδοι Λεξικού στην Python

Η κλάση `dict` στην Python παρέχει πολλές χρήσιμες [μεθόδους][dict-methods], μερικές από τις οποίες παρουσιάζονται στην άσκηση έννοιας για τα λεξικά.

Αυτή η έννοια καλύπτει μερικές ακόμη:

- Η `<dict>.setdefault()` προσθέτει αυτόματα κλειδιά χωρίς να πετάει ένα KeyError.
- Η `<dict>.fromkeys(<iterable>, <default value>)` δημιουργεί ένα νέο `dict` από οποιονδήποτε αριθμό iterables.
- Οι `<dict>.keys()`, `<dict>.values()` και `<dict>.items()` παρέχουν βολικούς iterators.
- Η `sorted(<dict>.items())` μπορεί εύκολα να αναδιατάξει τις καταγραφές σε ένα `dict`.
- Η `<dict_one>.update(<dict_two>)` ενημερώνει ένα `dict` με τις τιμές που επικαλύπτονται από ένα άλλο `dict`.
- Οι `<dict> | <other_dict>` και `<dict> |= <other_dict>` συγχωνεύουν ή ενημερώνουν δύο `dict` μέσω τελεστών.
- Οι `reversed(<dict>.keys())`, `reversed(<dict>.values())` ή `reversed(<dict>.items())` παράγουν _ανεστραμμένες_ προβολές.
- Η `<dict>.popitem()` αφαιρεί και επιστρέφει ένα ζεύγος `key`, `value`.

[dict-methods]: https://docs.python.org/3/library/stdtypes.html#dict
