# Σχετικά

Η τυπική βιβλιοθήκη Gleam υλοποιεί έναν τύπο `Queue` στο module `gleam/queue`. Είναι παρόμοιος με τον τύπο `List`, αλλά με μερικές βασικές διαφορές:

- Ο τύπος `Queue` δεν έχει κυριολεκτική σύνταξη που να μπορεί να χρησιμοποιηθεί για την κατασκευή ουρών ή για αντιστοίχιση μοτίβων πάνω τους.
- Στον τύπο `Queue`, τα στοιχεία μπορούν να προστεθούν και να αφαιρεθούν αποδοτικά τόσο από το μπροστινό όσο και από το πίσω άκρο, ενώ ο τύπος `List` μπορεί να προσθέτει και να αφαιρεί στοιχεία αποδοτικά μόνο από το μπροστινό άκρο.

Τις περισσότερες φορές θα θέλεις να χρησιμοποιήσεις τον τύπο `List`, αλλά όταν χρειάζεται να μπορείς να προσθέτεις και να αφαιρείς από το τέλος μιας συλλογής, ο τύπος `Queue` είναι καλή επιλογή.

Οι ουρές μπορούν να δημιουργηθούν χρησιμοποιώντας τις συναρτήσεις `queue.new` και `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Τα στοιχεία μπορούν να προστεθούν στην ουρά χρησιμοποιώντας τις συναρτήσεις `queue.push_front` και `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Τα στοιχεία μπορούν να αφαιρεθούν από την ουρά χρησιμοποιώντας τις συναρτήσεις `queue.pop_front` και `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Μια ουρά μπορεί να μετατραπεί σε λίστα χρησιμοποιώντας τη συνάρτηση `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Ισότητα ουρών

Λόγω του τρόπου με τον οποίο υλοποιούνται οι ουρές, δύο ουρές με τα ίδια στοιχεία στην ίδια σειρά μπορεί να μην είναι ίσες σύμφωνα με τον τελεστή `==`, ο οποίος συγκρίνει τιμές δομικά. Για παράδειγμα:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Αν χρειάζεται να συγκρίνεις δύο ουρές για ισότητα, μπορείς να χρησιμοποιήσεις τη συνάρτηση `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
