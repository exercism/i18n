# Συνένωση συμβολοσειρών

Η συνένωση συμβολοσειρών είναι απολύτως έγκυρη στη Crystal, αλλά ένας πιο συνηθισμένος τρόπος για να συνθέσεις μια συμβολοσειρά είναι η [παρεμβολή συμβολοσειράς][interpolation].
Για παράδειγμα:

```crystal
# Rather than:
"One for " + name_variable + ", one for me"

# Consider:
"One for #{name_variable}, one for me."
```

[interpolation]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/string.html#interpolation
