# Οδηγίες

Η Alizé έχει ένα online κατάστημα μόδας. Η μεγάλη ετήσια έκπτωση πλησιάζει, οπότε θέλει να φτιάξει κάποια λειτουργικότητα που θα τη βοηθήσει να κάνει απογραφή του αποθέματος.

Κάθε μεμονωμένο είδος στο απόθεμα αναπαρίσταται με έναν προσαρμοσμένο τύπο.

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. Επίστρεψε μια λίστα με τα ονόματα των ειδών

Υλοποίησε τη συνάρτηση `item_names`, η οποία παίρνει έναν iterator από είδη και επιστρέφει έναν iterator με τα ονόματά τους στην ίδια σειρά.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. Επίστρεψε τα είδη που είναι φθηνά

Υλοποίησε τη συνάρτηση `cheap`, η οποία παίρνει έναν iterator από είδη και επιστρέφει έναν iterator με τα είδη που κοστίζουν λιγότερο από 30.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. Επίστρεψε τα είδη που έχουν εξαντληθεί

Υλοποίησε τη συνάρτηση `out_of_stock`, η οποία επιστρέφει τα είδη που δεν έχουν απόθεμα.

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. Επίστρεψε το συνολικό απόθεμα

Υλοποίησε τη συνάρτηση `total_stock`, η οποία υπολογίζει τη συνολική ποσότητα των ειδών στην αποθήκη σου:

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
