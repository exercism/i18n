# Προσθήκη οδηγιών

## Λέξεις

- `tick ( matrix cols -- matrix' )`: προωθεί το πλέγμα κατά μία γενιά και επιστρέφει το νέο πλέγμα.

Κάθε γραμμή του πλέγματος αναπαρίσταται ως ακέραιος 64-bit· το `cols` είναι ο αριθμός των στηλών (το πολύ 64). Για παράδειγμα,

```
    0 1 0
    1 0 0
    1 1 0
```

αναπαρίσταται ως

```
0b010
0b100
0b110
```
