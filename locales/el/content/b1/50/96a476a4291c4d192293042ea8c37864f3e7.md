# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις μια γραμμή συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων.

## 1. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά ώρα

Υλοποίησε μια συνάρτηση που δέχεται τον αριθμό των αυτοκινήτων που παράγονται ανά ώρα και το ποσοστό επιτυχίας και υπολογίζει τον αριθμό των επιτυχημένων αυτοκινήτων που φτιάχνονται ανά ώρα. Το ποσοστό επιτυχίας δίνεται ως ποσοστό, από `0` έως `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι αριθμός κινητής υποδιαστολής.

## 2. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά λεπτό

Υλοποίησε μια συνάρτηση που δέχεται τον αριθμό των αυτοκινήτων που παράγονται ανά ώρα και το ποσοστό επιτυχίας και υπολογίζει πόσα αυτοκίνητα παράγονται με επιτυχία κάθε λεπτό:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι ακέραιος αριθμός.

## 3. Υπολόγισε το κόστος παραγωγής 

Κάθε αυτοκίνητο κοστίζει κανονικά $10.000 για να παραχθεί μεμονωμένα, ανεξάρτητα από το αν είναι επιτυχημένο ή όχι. Αλλά με λίγο σχεδιασμό, 10 αυτοκίνητα μπορούν να παραχθούν μαζί για $95.000. Για παράδειγμα, 37 αυτοκίνητα μπορούν να παραχθούν με τον εξής τρόπο:
37 = 3 x ομάδες των δέκα + 7 μεμονωμένα αυτοκίνητα

Έτσι, το κόστος για 37 αυτοκίνητα είναι:
3 \* 95,.000 + 7 \* 10.000 = 355.000

Υλοποίησε μια συνάρτηση που υπολογίζει το κόστος παραγωγής ενός αριθμού αυτοκινήτων, ανεξάρτητα από το αν είναι επιτυχημένα:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι ακέραιος αριθμός.
