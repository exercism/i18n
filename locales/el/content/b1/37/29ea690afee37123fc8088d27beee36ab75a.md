# Γενικές Κλάσεις

Έχεις χρησιμοποιήσει τα `ARRAY{STR}`, `FMAP{STR,INT}` και `FSET{STR}` από νωρίς. Τα άγκιστρα πάντα περιείχαν έναν τύπο. Τώρα γράφεις μια κλάση με δικά της άγκιστρα.

## Το πρόβλημα

Το γραφείο απολεσθέντων χρειάζεται ένα κουτί που χωράει ένα πράγμα και θυμάται ποιος το παρέδωσε. Ένα κουτί για ένα πουλόβερ:

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

και μετά την ίδια κλάση ξανά για ένα μπουκάλι νερό, και ξανά για ένα τηλέφωνο. Τρία αντίγραφα που διαφέρουν σε μία λέξη.

## Η παράμετρος τύπου

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

Το `{T}` μετά το όνομα της κλάσης είναι μια **παράμετρος τύπου**. Το `T` δεν είναι τύπος, είναι ένα υποκατάστατο για όποιον τύπο δοθεί όταν χρησιμοποιηθεί η κλάση. Μέσα στην κλάση, το `T` χρησιμοποιείται ακριβώς όπως θα χρησιμοποιούνταν οποιοδήποτε όνομα τύπου.

## Χρήση

Δώσε τον τύπο μέσα σε άγκιστρα:

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

Τα `LOST_BOX{STR}` και `LOST_BOX{INT}` είναι δύο διαφορετικοί τύποι. Το να βάλεις τον έναν εκεί που χρειάζεται ο άλλος είναι ένα λάθος που το πιάνει ο μεταγλωττιστής, ακριβώς σαν να είχες γράψει τις δύο κλάσεις στο χέρι, που στην ουσία είναι κι αυτό που συμβαίνει: ο Sather φτιάχνει μια ξεχωριστή κλάση από το πρότυπο για κάθε τύπο που χρησιμοποιείται πραγματικά.

Έτσι, δεν υπάρχει κανένα κόστος σε χρόνο εκτέλεσης, ούτε απώλεια πληροφορίας τύπου: το `jumper.item` είναι πραγματικά `STR`, όχι κάτι που πρέπει να ελεγχθεί ή να μετατραπεί.

## Περισσότερες από μία

Μια κλάση μπορεί να πάρει πολλές παραμέτρους, χωρισμένες με κόμματα. Το `FMAP{K,T}` είναι το παράδειγμα που ήδη ξέρεις.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## Ονοματοδοσία

Κατά σύμβαση, ένα μόνο κεφαλαίο γράμμα: `T` για ένα πράγμα, `K` για ένα κλειδί, `E` για ένα στοιχείο. Η βιβλιοθήκη τα χρησιμοποιεί παντού.
