# Introduction

## Ακέραιοι

Στη Gleam υπάρχουν δύο διαφορετικά είδη αριθμών: οι ακέραιοι και οι αριθμοί κινητής υποδιαστολής.

Οι ακέραιοι είναι αριθμοί χωρίς δεκαδικό μέρος.

```gleam
let integer = 3
// -> 3
```

Η Gleam έχει αρκετούς τελεστές που δουλεύουν με ακέραιους.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## Αριθμοί κινητής υποδιαστολής

Οι αριθμοί κινητής υποδιαστολής είναι αριθμοί με ένα ή περισσότερα ψηφία μετά την υποδιαστολή.

```gleam
let float = 3.45
// -> 3.45
```

Οι αριθμοί κινητής υποδιαστολής έχουν επίσης το δικό τους σύνολο τελεστών.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## Ενότητες

### Ενότητες

Ο κώδικας Gleam οργανώνεται σε ενότητες, και κάθε αρχείο είναι μία ενότητα Gleam.

Μέχρι τώρα γράφαμε συναρτήσεις με τη σύνταξη `pub fn`, η οποία ορίζει μια συνάρτηση που είναι δημόσια διαθέσιμη σε άλλες ενότητες. Οι συναρτήσεις που ορίζονται με `fn` είναι ιδιωτικές για την ενότητα στην οποία ορίζονται και δε μπορούν να χρησιμοποιηθούν από άλλες ενότητες.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Οι ενότητες Gleam έχουν ονόματα, και το όνομα βασίζεται στη διαδρομή του αρχείου τους μέσα στον κατάλογο `src` ή `test`.

Για παράδειγμα, μια ενότητα που ορίζεται στο `src\geometry\rectangle.gleam` (στα Windows) ή στο `src/geometry/rectangle.gleam` (σε λειτουργικά συστήματα τύπου UNIX) θα ονομαζόταν `geometry/rectangle`.

### Εισαγωγή συναρτήσεων από άλλες ενότητες

Η πρόσβαση σε συναρτήσεις που ορίζονται σε άλλες ενότητες γίνεται μέσω εισαγωγών.
Όλες οι συναρτήσεις μέσα σε μια ενότητα που εκείνη εκθέτει γίνονται προσβάσιμες όταν εισάγεις αυτή την ενότητα.
Αλλά το πώς έχεις πρόσβαση σε αυτές διαφέρει ανάλογα με τον τρόπο που εισάγεται η ενότητα.

Οι εισαγωγές με πρόθεμα είναι η προεπιλογή, και η πρόσβαση σε μια συνάρτηση μέσα σε μια τέτοια ενότητα (για παράδειγμα στη συνάρτηση `map` της ενότητας `gleam/list`) γίνεται βάζοντας πρόθεμα το όνομα της ενότητας (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Από προεπιλογή, το όνομα που χρησιμοποιείς για να αναφέρεσαι στην ενότητα είναι το τελευταίο μέρος του ονόματος της ενότητας, στην περίπτωση αυτή `int`, αλλά αυτό μπορεί να αλλάξει χρησιμοποιώντας τη λέξη-κλειδί `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Οι εισαγωγές χωρίς πρόθεμα δίνουν άμεση πρόσβαση στις εκτεθειμένες συναρτήσεις αυτής της ενότητας, χωρίς να χρειάζεται πρόθεμα.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Οι εισαγωγές με πρόθεμα προτιμώνται, γιατί κάνουν πιο σαφές στον αναγνώστη από πού προέρχεται μια συνάρτηση και βοηθούν να αποφεύγονται οι συγκρούσεις ονομάτων.


### Τυπική βιβλιοθήκη

Η Gleam έχει μια πλούσια και καλά τεκμηριωμένη τυπική βιβλιοθήκη. Η τεκμηρίωση είναι διαθέσιμη στο διαδίκτυο στη διεύθυνση [hexdocs.pm/gleam_stdlib][docs]. Αποθήκευσε κάπου αυτόν τον σύνδεσμο, θα τον χρησιμοποιήσεις πολύ!

Οι περισσότεροι ενσωματωμένοι τύποι δεδομένων έχουν μια αντίστοιχη ενότητα που προσφέρει συναρτήσεις για εργασία με αυτόν τον τύπο δεδομένων, π.χ. υπάρχει η ενότητα `gleam/int` για ακέραιους, η ενότητα `gleam/string` για συμβολοσειρές, η ενότητα `gleam/list` για λίστες και ούτω καθεξής.

[docs]: https://hexdocs.pm/gleam_stdlib/
