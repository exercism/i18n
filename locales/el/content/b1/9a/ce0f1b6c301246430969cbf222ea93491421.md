# Σχετικά

[Οι συμβολοσειρές][strings] στη Haxe είναι αμετάβλητα αντικείμενα που αναπαριστούν κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.). Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσουν ένα στιγμιότυπο `string`:

```haxe
var fruit:String = "Apple";
```

Ο χειρισμός μιας συμβολοσειράς μπορεί να γίνει καλώντας μία από τις [μεθόδους ή ιδιότητες][string-api] της. Καθώς οι τιμές συμβολοσειράς δεν μπορούν να αλλάξουν ποτέ αφού οριστούν, όλες οι μέθοδοι χειρισμού συμβολοσειρών επιστρέφουν μια νέα συμβολοσειρά.

Μια συμβολοσειρά οριοθετείται από χαρακτήρες διπλών εισαγωγικών (`"`). Κάποιοι ειδικοί χαρακτήρες χρειάζονται [διαφυγή][escaping] χρησιμοποιώντας τον χαρακτήρα ανάστροφης καθέτου (`\`). Επιπλέον, οι συμβολοσειρές στη Haxe είναι πολλαπλών γραμμών και επιτρέπουν την εύκολη κατασκευή μεγάλων κυριολεκτικών συμβολοσειρών:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

Ο απλούστερος τρόπος για να συνενώσεις συμβολοσειρές είναι να χρησιμοποιήσεις τον [τελεστή `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Για πιο σύνθετη μορφοποίηση συμβολοσειρών, προτιμάται η [παρεμβολή συμβολοσειρών][interpolation]. Αυτό γίνεται περικλείονοντας τη συμβολοσειρά σε χαρακτήρες μονών εισαγωγικών (`'`) και χρησιμοποιώντας το σύμβολο του δολαρίου (`$`) για να ενεργοποιήσεις την παρεμβολή μεταβλητών. Είναι επίσης δυνατό να αξιολογήσεις ολόκληρες εκφράσεις χρησιμοποιώντας `${expr}`, όπου `expr` είναι οποιαδήποτε έγκυρη έκφραση στη Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
