# Εισαγωγή

Αυτή η άσκηση χτίζει πάνω σε αυτά που είδες στο [Παρατηρητής Πουλιών στην Αυλή][backyard-birdwatcher], παρουσιάζοντας τις λέξεις υψηλότερης τάξης που παίρνουν ένα *quotation*, δηλαδή ένα κομμάτι κώδικα μέσα σε `[ ]` αγκύλες, για να κατευθύνουν τη λειτουργία.

## Τα quotations ως τιμές

Ένα quotation είναι απλώς ένα κομμάτι κώδικα αυτούσιο. Μπορείς να το περάσεις ως δεδομένα σε μια άλλη λέξη:

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

Εδώ το `[ 2 > ]` είναι ένα quotation που παίρνει έναν αριθμό και αφήνει ένα Boolean. Το `count` το εκτελεί σε κάθε στοιχείο και μετράει πόσα αποτελέσματα είναι αληθή.

## Φιλτράρισμα και απόρριψη

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

Το `without` αντιμετωπίζει το δεύτερο όρισμά του ως σύνολο: κάθε στοιχείο του `seq` που είναι `=` με *οποιοδήποτε* στοιχείο του `exclude` απορρίπτεται. Το `sift` είναι η ειδική περίπτωση του `reject` χωρίς quotation: κρατάει κάθε στοιχείο εκτός από το `f`, βολικό για να καθαρίσεις τα κενά που άφησε ένα προηγούμενο `map`.

### Κρατώντας το αποτέλεσμα του ελέγχου

Το `find` σου επιστρέφει το *στοιχείο* που ταιριάζει. Όταν ο έλεγχος *υπολογίζει* ήδη την τιμή που θέλεις πραγματικά, το `map-find` σου γλιτώνει ένα δεύτερο πέρασμα: εκτελεί το quotation σε κάθε στοιχείο και επιστρέφει το πρώτο αποτέλεσμα που δεν είναι `f` **και** το στοιχείο που το παρήγαγε.

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

Το quotation επιστρέφει `f` για τα στοιχεία που δεν πληρούν τη συνθήκη και το αποτέλεσμα που θέλεις να κρατήσεις για εκείνο που την πληροί. Αν κανένα δεν πληροί τη συνθήκη, το `map-find` αφήνει `f f`, ακριβώς όπως το `find`.

### Φιλτράρισμα καταγραφών με βάση ένα πεδίο

Όταν τα στοιχεία είναι *tuples*, το κατηγόρημα συνήθως προβάλλει ένα πεδίο μέσω του αυτόματα παραγόμενου reader `slot>>` και ελέγχει με βάση αυτό:

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## Περνώντας μια σταθερή τιμή με το `with`

Μερικές φορές το κατηγόρημα χρειάζεται μια τιμή που είναι ίδια σε κάθε κλήση: ένα κατώφλι, έναν διαιρέτη, μια συμβολοσειρά-στόχο. Το `with` (στο [`kernel`][kernel]) ενσωματώνει αυτή τη σταθερή τιμή μέσα στο quotation, μετατρέποντας ένα quotation δύο ορισμάτων `( value elt -- ? )` στο quotation ενός ορίσματος που περιμένουν τα `filter`, `count`, `map` και `each`:

```
with ( value seq quot -- seq curry )
```

Κάθε κλήση ανά στοιχείο βλέπει `( value elt )` στη στοίβα: πρώτα η σταθερή τιμή, μετά το τρέχον στοιχείο:

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## Αντιστοίχιση και επανάληψη

Το `map` (στο [`sequences`][sequences]) εφαρμόζει ένα quotation σε κάθε στοιχείο και επιστρέφει τον πίνακα με τα αποτελέσματα. Το `each` κάνει την ίδια διαδρομή αλλά πετάει τα αποτελέσματα, κάτι χρήσιμο όταν το quotation εκτελείται μόνο για τις παρενέργειές του. Το `2map` διατρέχει *δύο* ακολουθίες παράλληλα και συνδυάζει τα αντίστοιχα στοιχεία. Τα `2each` και `2reduce` είναι τα ξαδέρφια του για σκέτες παρενέργειες και για αναδίπλωση αντίστοιχα. Το `zip` είναι η συντόμευση για το "ταίριαξέ τα χωρίς να τα συνδυάσεις":

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

Το `2reduce` περνάει έναν συσσωρευτή μέσα από τις δύο ακολουθίες ταυτόχρονα: το quotation του παίρνει `( accumulator elt1 elt2 -- accumulator' )`. Εδώ συσσωρεύει ένα εσωτερικό γινόμενο: κάθε ζεύγος πολλαπλασιάζεται και τα γινόμενα αθροίζονται (`1*10 + 2*20 + 3*30`):

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

Το `map-as` είναι το ξαδέρφι του `map` που επιβάλλει τον τύπο της ακολουθίας εξόδου: πέρασε ένα κενό `{ }` ή `V{ }` ως exemplar για να παρακάμψεις την προεπιλογή που βασίζεται στον τύπο εισόδου (αλλιώς, η αντιστοίχιση μιας συμβολοσειράς σε μη-χαρακτήρες βγάζει σφάλμα όταν ο Factor προσπαθεί να συσκευάσει τα αποτελέσματα πίσω σε συμβολοσειρά).

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

Και οι δύο μορφές με δύο ακολουθίες σταματούν στο μήκος της μικρότερης εισόδου. Το `zip` είναι το ίδιο με το `[ 2array ] 2map`: κρατάει τα ζεύγη αντί να τα συμπτύσσει.

## Ταξινόμηση

Το `sort` επιστρέφει ένα ταξινομημένο αντίγραφο σε φυσική σειρά. Το `sort-by` (στο [`sorting`][sorting]) ταξινομεί με βάση ένα κλειδί που εξάγεται από κάθε στοιχείο:

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## Συνάθροιση

Το `map-sum` (στο [`sequences`][sequences]) εφαρμόζει ένα quotation σε όλη την ακολουθία και αθροίζει τα αποτελέσματα σε ένα πέρασμα:

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## Ελάχιστο και μέγιστο

Τα `minimum` και `maximum` επιστρέφουν κατευθείαν το μικρότερο ή το μεγαλύτερο στοιχείο μιας ακολουθίας. Τα `minimum-by` και `maximum-by` (όλα στο [`sequences`][sequences]) επιστρέφουν το στοιχείο του οποίου το εξαγόμενο κλειδί είναι το μικρότερο ή το μεγαλύτερο:

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## Γράφοντας τη δική σου λέξη υψηλότερης τάξης

Όταν η *δική σου* λέξη παίρνει ένα quotation ως όρισμα κατά την εκτέλεση και το προωθεί στα `map`, `filter`, `each` κ.λπ., δήλωσε τη λέξη σου με `; inline`. Αυτό λέει στον μεταγλωττιστή να κάνει inline τη λέξη σου σε κάθε σημείο κλήσης, όπου το quotation είναι γνωστό literal. Χωρίς αυτό, ο μεταγλωττιστής δεν έχει τρόπο να γνωρίζει το stack effect του quotation.

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

Οι λέξεις που χτίζονται μόνο από literal quotations δε χρειάζονται `inline`, παρά μόνο εκείνες που προωθούν ένα *εισερχόμενο* quotation.

Αν μια τέτοια λέξη `inline` καλέσει ποτέ *τον εαυτό της*, δηλαδή έναν αναδρομικό συνδυαστή, δήλωσέ την με `; inline recursive`. Χωρίς την επιπλέον λέξη ο μεταγλωττιστής σταματά με το *"The inline recursive word ... must be declared recursive"*, που σου λέει ακριβώς τι να προσθέσεις.

## Παίρνοντας το δεύτερο στοιχείο

Για έναν πίνακα 2 στοιχείων, το `second` επιστρέφει το δεύτερο στοιχείο του. Το `first` επιστρέφει το πρώτο. Και τα δύο είναι στο [`sequences`][sequences].

## Από αριθμούς σε συμβολοσειρές

Το `number>string ( n -- str )` (στο [`math.parser`][math.parser]) μετατρέπει έναν αριθμό στη δεκαδική συμβολοσειρά του:

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
