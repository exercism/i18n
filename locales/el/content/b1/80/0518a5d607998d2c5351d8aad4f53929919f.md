# Οδηγίες

Η Lilly, η εξωγήινη της Lisp, έχει φτιάξει σίγουρα πολλά λαζάνια με τη βοήθειά σου. Θέλει να σε ευχαριστήσει δίνοντάς σου μερικά υπολείμματα. Πρώτα όμως έχει κάποια σχόλια για μία από τις συναρτήσεις με τις οποίες τη βοήθησες.

Σε αυτή την άσκηση θα γράψεις μερικές ακόμα συναρτήσεις για να βοηθήσεις τη Lilly στο μαγείρεμα των λαζάνια, αλλά και για να τη βοηθήσεις να μοιραστείτε τα υπολείμματα.

Έχεις έξι εργασίες: τρεις για τη βελτίωση των υπαρχουσών συναρτήσεων μαγειρέματος των λαζάνια και τρεις για τη μοιρασιά των υπολειμμάτων.

## 1. Κάνε την `preparation-time-in-minutes` πιο εύκολη στη χρήση

Η Lilly λέει ότι βρήκε λίγο άβολη τη χρήση της `preparation-time-in-minutes`, αφού έπρεπε να μετρήσει όλες τις στρώσεις πριν χρησιμοποιήσει τις συναρτήσεις. Η Lilly αναρωτιέται αν θα μπορούσες να φτιάξεις μια εκδοχή της συνάρτησης που να παίρνει τις στρώσεις (όσες κι αν είναι) ως ορίσματα και μετά να υπολογίζει τον χρόνο προετοιμασίας με βάση το πόσες στρώσεις υπήρχαν. Υπενθύμιση: χρειάζονται 19 λεπτά για να προετοιμαστεί μία μόνο στρώση.

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. Επίτρεψε την αλλαγή του αναμενόμενου χρόνου ψησίματος

Ενώ οι γονικές μονάδες της Lilly έψηναν πάντα τα λαζάνια τους για 337 λεπτά, η Lilly παραδέχεται ότι άλλοι εξωγήινοι της Lisp προτιμούν να ψήνουν τα λαζάνια τους για μεγαλύτερα ή μικρότερα χρονικά διαστήματα.

Θα ήταν λοιπόν καλό η `remaining-minutes-in-oven` να μη χρησιμοποιεί την `expected-minutes-in-oven`, αλλά να μπορεί να παίρνει μια _προαιρετική_ παράμετρο που να ορίζει αν ο χρόνος πρέπει να είναι "longer", "very long", "shorter" ή "very short". Το "longer" ή το "shorter" σημαίνει πρόσθεσε ή αφαίρεσε 100 από τον προεπιλεγμένο χρόνο των 337. Το "very long" ή το "very short" σημαίνει πρόσθεσε ή αφαίρεσε 200. Αν δεν δοθεί καμία παράμετρος, ή το όρισμα είναι "normal", τότε θα πρέπει να επιστρέφεται η προεπιλεγμένη τιμή 337.

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. Η Lilly θυμάται άλλον έναν προτιμώμενο τρόπο ψησίματος

Μόλις τελείωσες αυτή την αλλαγή, η Lilly θυμήθηκε ότι υπάρχουν μερικοί εξωγήινοι της Lisp που θέλουν _πραγματικά σύντομους_ χρόνους ψησίματος. Στην ουσία το θέλουν ωμό. Έτσι τώρα η συνάρτηση θα πρέπει να επιστρέφει 0 αν το όρισμα ήταν `NIL`, καθώς και τις ίδιες τιμές όπως στην προηγούμενη εργασία.

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. Μοιρασιά των υπολειμμάτων

Τώρα που βοήθησες να βελτιωθούν οι συναρτήσεις μαγειρέματος των λαζάνια, υπάρχουν _πάρα πολλά λαζάνια_! Η Lilly θέλει να σε ανταμείψει για όλη τη βοήθειά σου μοιράζοντας τα υπολείμματα μαζί σου. Θα χρειαστεί να γράψεις μια συνάρτηση που παίρνει τρεις παραμέτρους: τη συνολική ποσότητα των υπολειμμάτων, τον αριθμό των δοχείων για υπολείμματα που βρήκε η Lilly στα ντουλάπια της και τον ίδιο αριθμό για σένα. Επειδή η αναζήτηση δοχείων για υπολείμματα μπορεί να πάρει διαφορετικό χρόνο, και η ακριβής ποσότητα των υπολειμμάτων μπορεί να καθοριστεί όσο εσύ και η Lilly ψάχνετε στα ντουλάπια σας, συμφωνείτε και οι δύο ότι η συνάρτηση θα πρέπει να δέχεται τα ορίσματα με οποιαδήποτε σειρά, ώστε να μπορείς να σημειώνεις τον κάθε αριθμό μόλις τον καθορίζεις. Όταν έχεις και τους τρεις αριθμούς, μπορείς απλώς να κλείσεις την παρένθεση στην κλήση της συνάρτησης και να την αξιολογήσεις.

Η συνάρτηση θα πρέπει να επιστρέφει την ποσότητα των υπολειμμάτων που περισσεύουν, δηλαδή τη διαφορά ανάμεσα στο βάρος των υπολειμμάτων και στον συνολικό αριθμό των δοχείων που βρήκατε εσύ και η Lilly.

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. Κάνοντας υποθέσεις

Ύστερα από μερικές διαδρομές πήγαινε-έλα στα αντίστοιχα ντουλάπια σας, συμφωνείτε και οι δύο ότι θα ήταν υπέροχο αν η συνάρτηση μπορούσε απλώς να _υποθέσει_ ότι εσύ ή η Lilly είχατε... ας πούμε 10 δοχεία, αν δεν είχε διευκρινιστεί.

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. Προεπιλεγμένη ποσότητα υπολειμμάτων

Ακόμα καλύτερα, η συνάρτηση θα μπορούσε να _υποθέσει_ ότι υπάρχουν αρκετά υπολείμματα για να γεμίσουν τα δοχεία. Έτσι, αν δεν δοθεί το βάρος, η συνάρτηση θα πρέπει να επιστρέφει `:just-split-it`. _Ωστόσο_, αν δοθεί το βάρος και είναι `nil`, τότε θα πρέπει να επιστρέφει `:looks-like-someone-was-hungry`.

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
