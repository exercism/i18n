# Εισαγωγή

Ας υποθέσουμε ότι θέλεις όλους τους μη αρνητικούς ακέραιους μέχρι το 1000.
Θα ήταν γελοίο αν έπρεπε να τους πληκτρολογήσεις σε έναν πίνακα.

Για αυτό έχουμε τον τύπο `range`:

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

Τα εύρη είναι πολύ συνηθισμένα: όχι μόνο για να σου γλιτώσουν πληκτρολόγηση, αλλά και ως τύποι επιστροφής από συναρτήσεις.

Σημείωσε ότι τα εύρη _δεν_ είναι διανύσματα.
Είναι απλώς ένα σύνολο από οδηγίες για τη δημιουργία μιας ακολουθίας ("οκνηρή" αξιολόγηση, ή ένας "επαναλήπτης").

Αν χρειάζεσαι ένα εύρος ως διάνυσμα, χρησιμοποίησε τη συνάρτηση `collect()` για μετατροπή:

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

Το βήμα μπορεί να οριστεί, στην περίπτωση αυτή 0.3:

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

Άρα η σύνταξη είναι `start:stepsize:stop`.
Και τα δύο ακραία όρια _περιλαμβάνονται_, όπως φαίνεται στο παράδειγμα με τους ακέραιους.
Αν το βήμα δεν διαιρεί ακριβώς το `stop - start`, το τελευταίο στοιχείο θα αποφύγει να ξεπεράσει το `stop`.

## Εύρη χαρακτήρων

Μη αριθμητικές ακολουθίες μπορούν επίσης να χρησιμοποιηθούν σε εύρη.
Το πιο απλό παράδειγμα είναι τα γράμματα ASCII:

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

Ο τύπος `Char` θα καλυφθεί με περισσότερες λεπτομέρειες σε άλλη έννοια.
Για την ώρα, αντιμετώπισέ τα απλώς ως μεμονωμένους χαρακτήρες σε μονά εισαγωγικά.

## Συναρτήσεις και τελεστές για εύρη

Έλεγξε τα όρια ενός εύρους με τις `first()` και `last()`.

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## Περισσότερα για την ευρετηρίαση διανυσμάτων

Εύρη ακεραίων και διανύσματα μπορούν να χρησιμοποιηθούν στην ευρετηρίαση διανυσμάτων:

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
