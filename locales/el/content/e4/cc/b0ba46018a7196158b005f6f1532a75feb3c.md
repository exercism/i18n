# Οδηγίες

Σε αυτή την άσκηση θα γράφεις κώδικα για να βοηθήσεις μια εταιρεία πινακίδων να δημιουργεί προσαρμοσμένα μηνύματα για τις πινακίδες της.

## 1. Φτιάξε μια πινακίδα περίστασης

Υλοποίησε τη συνάρτηση `buildSign(occasion, name)` που δέχεται μια συμβολοσειρά ως παράμετρο `occasion` και μια συμβολοσειρά που περιέχει το όνομα κάποιου ως παράμετρο `name`.
Οι δύο παράμετροι θα ενσωματωθούν σε ένα template string για να παραχθεί το μήνυμα της πινακίδας.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Φτιάξε μια πινακίδα γενεθλίων

Υλοποίησε τη συνάρτηση `buildBirthdaySign(age)` που δέχεται μια ηλικία και, με βάση την ηλικία, θα καθορίσει μέρος του μηνύματος της πινακίδας.
Αν η ηλικία είναι 50 ή μεγαλύτερη, η πινακίδα θα αναφέρεται στον χρήστη ως _mature_, αλλιώς θα αναφέρεται σε αυτόν ως _young_.
Το ακριβές αναμενόμενο αποτέλεσμα φαίνεται παρακάτω:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Φτιάξε μια πινακίδα αποφοίτησης

Υλοποίησε τη συνάρτηση `graduationFor(name, year)` που παίρνει ένα όνομα ως παράμετρο συμβολοσειράς και ένα έτος ως αριθμητική παράμετρο και χρησιμοποιεί παρεμβολή συμβολοσειρών για να δημιουργήσει μια φράση για μια πινακίδα που χρησιμοποιεί μια αλλαγή γραμμής για να χωρίσει τις δύο γραμμές του μηνύματος.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Υπολόγισε το κόστος μιας πινακίδας

Υλοποίησε τη συνάρτηση `costOf(sign, currency)` που παίρνει μια συμβολοσειρά που περιέχει το περιεχόμενο της πινακίδας και μια συμβολοσειρά που αντιπροσωπεύει το νόμισμα.
Η πινακίδα έχει βασική τιμή 20 στο νόμισμα που δίνεται. Επιπλέον, κάθε γράμμα κοστίζει 2. (Τα κενά περιλαμβάνονται στον υπολογισμό.)
Η φράση που επιστρέφεται περιλαμβάνει το κόστος κατασκευής της πινακίδας, γραμμένο με δύο ψηφία μετά την υποδιαστολή, ακολουθούμενο από τη συμβολοσειρά του νομίσματος.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
