# Εισαγωγή

Οι πίνακες είναι οι ακολουθίες σταθερού μήκους της Factor: μπορείς να αλλάξεις τα στοιχεία, αλλά όχι το μήκος. Ξέρεις ήδη πώς να γράφεις έναν literal πίνακα, `{ … }`, και πώς να κόβεις και να συναθροίζεις έναν. Αυτή η άσκηση καλύπτει τα λίγα εργαλεία που χρειάζεσαι όταν φτιάχνεις πίνακες από τιμές στη στοίβα και μετά αναζητάς ή αναδιατάσσεις τα περιεχόμενά τους.

## Κατασκευή από τη στοίβα

Τα `1array`, `2array`, `3array` και `4array` (στο [`arrays`][arrays]) παίρνουν 1, 2, 3 ή 4 τιμές από την κορυφή της στοίβας και τις ομαδοποιούν:

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## Συνένωση

Το `concat` (στο [`sequences`][sequences]) παίρνει μια ακολουθία της οποίας τα στοιχεία είναι και τα ίδια ακολουθίες και τα ισοπεδώνει κατά ένα επίπεδο. Το `join` κάνει το ίδιο, με έναν διαχωριστή ανάμεσα σε κάθε ζευγάρι:

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## Αντιστροφή

Το `reverse` επιστρέφει μια νέα ακολουθία με τα στοιχεία σε αντίστροφη σειρά:

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## Είναι πίνακας;

Το `array?` (στο [`arrays`][arrays]) είναι το κατηγόρημα τύπου. Είναι αληθές για κάθε τιμή που φτιάχνεται από το `<array>`, τα `1array`/`2array`/..., ή έναν literal πίνακα `{ … }`, και ψευδές για όλα τα υπόλοιπα (συμπεριλαμβανομένων των διανυσμάτων, των συμβολοσειρών και άλλων ακολουθιών):

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## Αναζήτηση

Το `index` επιστρέφει τη θέση του πρώτου στοιχείου που είναι ίσο με την τιμή εισόδου, ή `f` αν αυτή δεν υπάρχει. Το `member?` επιστρέφει απλώς ένα Boolean (λογική τιμή). Και τα δύο παίρνουν **πρώτα το στοιχείο** και **μετά την ακολουθία**. Το `members` (στο [`sets`][sets]) επιστρέφει τα *μοναδικά* στοιχεία μιας ακολουθίας, δηλαδή την πράξη της αφαίρεσης των διπλότυπων, και το `all-unique?` (επίσης στο `sets`) ελέγχει αν η ακολουθία δεν έχει ήδη διπλότυπα:

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
