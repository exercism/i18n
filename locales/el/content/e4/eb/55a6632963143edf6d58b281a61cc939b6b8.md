# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Μια καθολική, επώνυμη συνάρτηση ορίζεται με
  [`defun`][cookbook-functions].
- Μια συνάρτηση "επιστρέφει" (_π.χ._ αξιολογείται σε) την τιμή της
  τελευταίας έκφρασης στο σώμα της.
- Ο ορισμός μιας συνάρτησης μπορεί να περιλαμβάνει μια προαιρετική
  συμβολοσειρά τεκμηρίωσης μετά τη λίστα παραμέτρων.

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Θα χρειαστεί να γράψεις μια [συνάρτηση][cookbook-functions] με μία
  παράμετρο.
- Μπορείς να χρησιμοποιήσεις το [`-`][hyper-subtract] για να αφαιρέσεις αριθμούς.

* Μπορείς να καλέσεις μια άλλη συνάρτηση βάζοντας το όνομα της
  συνάρτησης ως πρώτο στοιχείο μιας έκφρασης (_π.χ._ `(func)`).

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][cookbook-functions] με μία
  παράμετρο
- Μπορείς να χρησιμοποιήσεις το [`*`][hyper-multiply] για να πολλαπλασιάσεις αριθμούς.

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][cookbook-functions] με δύο
  παραμέτρους.
- Μπορείς να χρησιμοποιήσεις το [`+`][hyper-plus] για να προσθέσεις αριθμούς.
