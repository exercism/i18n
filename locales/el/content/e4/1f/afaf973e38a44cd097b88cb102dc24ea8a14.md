# `for` βρόχοι

Η επανάληψη είναι μια θεμελιώδης έννοια στον προγραμματισμό που σου επιτρέπει να εκτελέσεις ένα μπλοκ κώδικα πολλές φορές.
Στη Swift, υπάρχουν δύο τύποι βρόχων: οι [βρόχοι `for-in`][for-loops] και οι `while` βρόχοι.
Σε αυτό το κεφάλαιο, θα μάθεις για τους βρόχους `for-in`.

Οι `for` βρόχοι σου επιτρέπουν να διατρέξεις μια ακολουθία τιμών, παίρνοντας ένα ένα τα στοιχεία με τη σειρά και δεσμεύοντας το καθένα σε μια μεταβλητή της επιλογής σου.
Η Swift σου επιτρέπει να διατρέξεις ποικίλες ακολουθίες, όπως διαστήματα, πίνακες και συμβολοσειρές (και άλλους τύπους που θα καλυφθούν αργότερα).
Όταν έχει διατρεχθεί κάθε στοιχείο της ακολουθίας, ο βρόχος τερματίζεται.

Οι `for` βρόχοι δηλώνονται με τη λέξη-κλειδί `for`, ακολουθούμενη από ένα όνομα μεταβλητής, τη λέξη-κλειδί `in` και μια ακολουθία τιμών πάνω στην οποία θα κάνεις επανάληψη.
Η μεταβλητή που δίνεις στον βρόχο `for-in` είναι αμετάβλητη, που σημαίνει ότι δε μπορείς να αλλάξεις την τιμή της μέσα στον βρόχο.
Ας δούμε ένα παράδειγμα ενός βρόχου `for-in` που διατρέχει έναν πίνακα αριθμών:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Η μεταβλητή `number` δηλώνεται μέσα στον βρόχο `for-in` και είναι διαθέσιμη μόνο μέσα στο πεδίο εμβέλειας του βρόχου.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Επανάληψη πάνω σε ένα διάστημα

Μπορείς επίσης να διατρέξεις ένα διάστημα αριθμών χρησιμοποιώντας έναν βρόχο `for-in`.
Αυτό σου επιτρέπει να εκτελέσεις ένα μπλοκ κώδικα έναν συγκεκριμένο αριθμό φορών. Για παράδειγμα, το διάστημα `1...5` θα διατρέξει τους αριθμούς 1, 2, 3, 4 και 5, οπότε ο βρόχος θα εκτελεστεί 5 φορές.
Μερικές φορές μπορεί να θέλεις να διατρέξεις θέσεις σε μια δομή δεδομένων όπως ένας πίνακας, και τότε μπορείς να χρησιμοποιήσεις ένα διάστημα `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Επανάληψη πάνω σε μια συμβολοσειρά

Μπορείς επίσης να διατρέξεις μια συμβολοσειρά χρησιμοποιώντας έναν βρόχο `for-in`.
Αυτό σου επιτρέπει να διατρέξεις κάθε χαρακτήρα της συμβολοσειράς, και πρόσεξε ιδιαίτερα ότι ο τύπος που δίνεται στον βρόχο είναι `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Η Swift παρέχει επίσης μια συνάρτηση `stride` που σου επιτρέπει να δημιουργήσεις μια ακολουθία πάνω σε ένα διάστημα με συγκεκριμένο βήμα.
Την οποία μπορείς στη συνέχεια να διατρέξεις με έναν βρόχο `for-in`.
Η `stride` ορίζεται ως [`stride(from:to:by:)`][stride-to] ή [`stride(from:through:by:)`][stride-through]· η πρώτη είναι αποκλειστική και η δεύτερη συμπεριληπτική.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Πρόσεξε ότι η παράμετρος `to` είναι αποκλειστική, οπότε ο βρόχος θα επαναλαμβάνεται μέχρι τον αριθμό πριν από την παράμετρο `to`, ενώ η παράμετρος `through` είναι συμπεριληπτική, οπότε σε αυτή την περίπτωση θα συμπεριλάβει και το `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
