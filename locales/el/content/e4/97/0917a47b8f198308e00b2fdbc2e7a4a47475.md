# Σχετικά

Η Haxe έχει δύο τύπους αριθμών, τους ακέραιους και τους δεκαδικούς:

- `Int`: Αντιπροσωπεύει έναν ακέραιο αριθμό.
- `Float`: Αντιπροσωπεύει έναν δεκαδικό αριθμό κινητής υποδιαστολής διπλής ακρίβειας 64 bit.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Ενώ κάθε `Int` μπορεί να χρησιμοποιηθεί όπου αναμένεται ένα `Float` (δηλαδή, το `Int` **είναι εκχωρήσιμο σε** ή **ενοποιείται με** το `Float`), το αντίστροφο δεν ισχύει: η ανάθεση ενός `Float` σε ένα `Int` μπορεί να προκαλέσει απώλεια ακρίβειας και γι' αυτό δεν επιτρέπεται σιωπηρά.

## Σύγκριση

Οι αριθμοί είναι ίσοι αν έχουν την ίδια τιμή.

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

Για την τελευταία περίπτωση, δες το [0.30000000000000004.com][0.30000000000000004.com] για μια σύντομη εξήγηση.
