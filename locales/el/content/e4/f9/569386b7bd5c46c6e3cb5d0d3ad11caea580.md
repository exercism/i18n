# Σχετικά

Το `case` είναι ο διακόπτης πολλαπλών επιλογών του Factor με βάση την ισότητα. Είναι το κατάλληλο εργαλείο όταν η επιλογή εξαρτάται από το αν μία μόνο τιμή είναι ίση με μία από αρκετές εναλλακτικές, όχι όταν κάθε κλάδος χρειάζεται διαφορετικό έλεγχο (γι' αυτό χρησιμοποίησε το `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Μερικά πράγματα που αξίζει να μην μπερδέψεις:

- Η ισότητα είναι το `=`. Ό,τι συγκρίνεται με `=` μπορεί να χρησιμοποιηθεί ως κλειδί: αριθμοί, συμβολοσειρές, χαρακτήρες, σύμβολα, ακόμα και πλειάδες.
- Οι *ταιριασμένοι* κλάδοι βλέπουν τη στοίβα *χωρίς* την τιμή εισόδου. Οι *προεπιλεγμένοι* κλάδοι τη βλέπουν ακόμα στην κορυφή.
- Ένα `case` χωρίς προεπιλεγμένη περίπτωση και χωρίς κλάδο που να ταιριάζει πετάει ένα σφάλμα.

Το `case` μεταγλωττίζεται σε πίνακα αλμάτων όπου αυτό είναι δυνατόν, οπότε δεν είναι απλώς συντακτική ζάχαρη για μια αλυσίδα από `if`, είναι και γρήγορο.
