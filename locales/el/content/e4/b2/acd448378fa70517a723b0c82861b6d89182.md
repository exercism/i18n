# Εισαγωγή

Η Kotlin είναι μια **στατικά τυποποιημένη** γλώσσα προγραμματισμού που αναπτύχθηκε από την JetBrains. Αυτό σημαίνει ότι ο τύπος των μεταβλητών καθορίζεται κατά τη μεταγλώττιση.

## Μεταβλητές

Όπως και σε άλλες στατικά τυποποιημένες γλώσσες προγραμματισμού, ο τύπος κάθε μεταβλητής πρέπει να καθορίζεται κατά τη μεταγλώττιση. Μπορείς να αποφύγεις τις ρητές δηλώσεις τύπου όπου ο μεταγλωττιστής μπορεί να τον συμπεράνει από το περιβάλλον.

Στην Kotlin οι μεταβλητές είναι είτε αμετάβλητες (`val`) είτε μεταβλητές (`var`). Η τιμή μιας αμετάβλητης μεταβλητής δεν μπορεί να αλλάξει αφού της ανατεθεί η αρχική της τιμή. Τις περισσότερες φορές θα χρησιμοποιείς αυτού του είδους τη μεταβλητή.

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

Η τιμή μιας μεταβλητής (`var`) μπορεί να αλλάξει μία ή περισσότερες φορές:

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Οι άνω τελείες στην Kotlin είναι προαιρετικές, εκτός από μερικές ειδικές περιπτώσεις που θα δούμε αργότερα.

## Συναρτήσεις

Οι συναρτήσεις στην Kotlin ορίζονται με τη λέξη-κλειδί `fun` και είναι _πολίτες πρώτης κατηγορίας_ (κάτι που δεν έχει σχέση με τον αντικειμενοστρεφή προγραμματισμό). Αυτό σημαίνει ότι μπορείς να τις δηλώσεις απευθείας μέσα σε αρχεία (τις λεγόμενες `top-level functions`). Στη Java, για παράδειγμα, μπορείς να ορίσεις μεθόδους μόνο μέσα σε κλάσεις, όχι σε αρχεία:

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

Οι συναρτήσεις μπορούν να δέχονται ορίσματα. Κάθε όρισμα έχει όνομα και τύπο. Σε αντίθεση με τις μεταβλητές, ο τύπος των ορισμάτων δεν μπορεί να συναχθεί. Οι συναρτήσεις μπορούν να έχουν μηδέν ή περισσότερα ορίσματα:

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Οι συναρτήσεις στην Kotlin μπορεί να επιστρέφουν ή να μην επιστρέφουν κάποια τιμή:

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

Για να επιστρέψει μια συνάρτηση μια τιμή, χρησιμοποιείται η λέξη-κλειδί `return`:

```kotlin
fun getName(): String {
    return "Alice"
}
```

Οι συναρτήσεις μπορούν να έχουν παραμέτρους με προεπιλεγμένες τιμές. Αυτές οι τιμές χρησιμοποιούνται όταν παραλείπονται στο σημείο όπου καλείται η συνάρτηση:

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## Σχόλια

Χρησιμοποίησε το `//` για να ορίσεις σχόλιο μίας γραμμής:

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

ή τα `/*` και `*/` για να ορίσεις σχόλια πολλών γραμμών:

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
