# Προσθήκη οδηγιών

## Οδηγίες ειδικά για τη SML

Τα δυαδικά δέντρα αναζήτησης είναι χρήσιμα για κάθε διατεταγμένο τύπο δεδομένων, όχι μόνο για αριθμούς.

Η ενότητα 2.6 του [Notes on Programming SML/NJ][notes] πραγματεύεται τον πολυμορφισμό, ενώ η ενότητα 4.1 πραγματεύεται τη χρήση των συναρτήσεων _compare_.
