# Εισαγωγή

Μια διεπαφή μπορεί να κατανοηθεί ως η υπογραφή μιας κλάσης, επειδή περιγράφει τα δημόσια πεδία μιας κλάσης. Μια κλάση _υλοποιεί_ μια `interface` με τη λέξη-κλειδί `implments`.

Η σύνταξή της μοιάζει πολύ με αυτήν μιας κλάσης, με τη διαφορά ότι οι μέθοδοι εμφανίζονται ως υπογραφές χωρίς σώμα:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Τα πεδία που υλοποιούνται από μια διεπαφή **πρέπει** να χρησιμοποιούν πάντα τον ίδιο τροποποιητή ορατότητας. Για παράδειγμα, αν η μεταβλητή `a` είναι `public` σε μια διεπαφή, τότε και η υλοποίησή της πρέπει να είναι `public`.
