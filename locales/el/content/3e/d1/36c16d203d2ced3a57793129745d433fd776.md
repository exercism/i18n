# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις πάνω σε ένα σύστημα προγραμματισμού ραντεβού για ένα σαλόνι ομορφιάς.

Έχεις τρεις εργασίες, οι οποίες όλες θα αφορούν ημερομηνίες ραντεβού.

## 1. Έλεγξε αν ένα ραντεβού έχει ήδη περάσει

Υλοποίησε την υπορουτίνα `appointment_has_passed` που παίρνει μια συμβολοσειρά ημερομηνίας και ελέγχει αν το ραντεβού ήταν κάποια στιγμή στο παρελθόν:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Οι συμβολοσειρές ημερομηνίας θα δίνονται σε μορφή ημερομηνίας-ώρας ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Θα χρειαστεί να υλοποιήσεις την ιδιωτική υπορουτίνα `_parse_datetime`.
Σου προτείνονται μερικά module:

- [Time::Piece][time-piece] είναι ένα βασικό module του Perl.
- [DateTime::Tiny][datetime-tiny] είναι διαθέσιμο από το CPAN.

## 2. Έλεγξε αν το ραντεβού είναι απογευματινό

Υλοποίησε τη συνάρτηση `is_afternoon_appointment` που παίρνει μια συμβολοσειρά ημερομηνίας και ελέγχει αν το ραντεβού είναι απογευματινό (>= 12:00 και < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Περιγράψε την ώρα και την ημερομηνία του ραντεβού

Υλοποίησε τη συνάρτηση `describe_appointment` που παίρνει μια συμβολοσειρά ημερομηνίας και επιστρέφει μια περιγραφή αυτής της ημερομηνίας και ώρας:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Σημείωσε ότι η ώρα είναι στο εύρος 0-12 και δεν έχει αρχικό μηδενικό ή κενό.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
