# Υποδείξεις

## Γενικά

- Όλες οι διευθύνσεις μνήμης σε αυτή την άσκηση είναι ευθυγραμμισμένες στα 16 byte, οπότε οι ευθυγραμμισμένες μεταφορές (`movdqa` για ακέραιους, `movaps` για αριθμούς κινητής υποδιαστολής) είναι κατάλληλες.
  Μια ευθυγραμμισμένη διεύθυνση μπορεί επίσης να χρησιμοποιηθεί απευθείας ως τελεστέος πηγής στη μνήμη.

## 1. Μετέτρεψε μια εικόνα σε σειρά εμφάνισης

- Μέσα σε κάθε pixel των 4 byte, η μετατροπή ανταλλάσσει το byte στη μετατόπιση `0` (κόκκινο) με το byte στη μετατόπιση `2` (μπλε) και αφήνει τις μετατοπίσεις `1` (πράσινο) και `3` (άλφα) στη θέση τους.
  Το ίδιο μοτίβο επαναλαμβάνεται σε όλα τα τέσσερα pixel.
- Μια [αναδιάταξη][pshufb] μπορεί να χρησιμοποιηθεί για να αλλάξουν σειρά τα byte επί τόπου, σύμφωνα με τις θέσεις ενός διανύσματος ελέγχου.
- Το διάνυσμα ελέγχου μπορεί να οριστεί στη μνήμη.
- Μπορεί να υπάρχουν περισσότερα από ένα μπλοκ, και κάθε μπλοκ είναι 16 byte.

## 2. Γέμισε μια περιοχή με ένα χρώμα

- Το χρώμα είναι ένα μόνο pixel των 4 byte.
  Για να αποθηκευτεί 16 byte τη φορά, θα πρέπει πρώτα να [μεταδοθεί][pshufd] σε όλες τις τέσσερις λωρίδες ενός καταχωρητή `xmm`.
- Ένα pixel των 4 byte πρέπει πρώτα να [μεταφερθεί][pinsrd] σε έναν καταχωρητή `xmm` πριν μεταδοθεί.
- Κάθε γεμάτο μπλοκ είναι πανομοιότυπο, οπότε ο γεμάτος καταχωρητής μπορεί να δημιουργηθεί μία φορά και μετά να επαναχρησιμοποιηθεί.
- Μπορεί να υπάρχουν περισσότερα από ένα μπλοκ, και κάθε μπλοκ είναι 16 byte.

## 3. Πλέξε δύο γραμμές σάρωσης

- Οι εντολές [unpack][unpack] μπορούν να χρησιμοποιηθούν για να συμπλέξουν τα byte δύο τελεστέων.
- Και οι δύο εντολές unpack παίρνουν το πρώτο byte κάθε ζεύγους από τον τελεστέο προορισμού και το δεύτερο από τον τελεστέο πηγής.

## 4. Συσκεύασε μια φωτισμένη σειρά

- Οι εντολές [pack][pack] μπορούν να χρησιμοποιηθούν για να στενέψουν τις λωρίδες, περιορίζοντάς τες ταυτόχρονα στα όρια των τιμών.
- Οι εντολές pack παίρνουν τις χαμηλές λωρίδες από τον τελεστέο προορισμού και τις υψηλές λωρίδες από τον τελεστέο πηγής.

## 5. Χώρισε τις συντεταγμένες σε x και y

- [Οι αναδιατάξεις κινητής υποδιαστολής][shufps] μπορούν να χρησιμοποιηθούν για την επιλογή και την αναδιάταξη λωρίδων από δύο τελεστέους.
- Οι συντεταγμένες `x` βρίσκονται στις ζυγές λωρίδες (`0` και `2`) κάθε εισόδου, και οι συντεταγμένες `y` στις μονές λωρίδες (`1` και `3`).
