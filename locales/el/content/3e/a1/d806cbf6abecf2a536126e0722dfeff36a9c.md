# Εισαγωγή

Μια `string` στη C# είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης, κ.λπ.). Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσουν ένα στιγμιότυπο `string`:

```csharp
string fruit = "Apple";
```

Χειρίζεσαι τις συμβολοσειρές καλώντας τις μεθόδους τους. Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί ποτέ να αλλάξει. Οποιεσδήποτε μέθοδοι φαίνεται να τροποποιούν μια συμβολοσειρά, στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.

Πολλαπλές συμβολοσειρές μπορούν να συνενωθούν (προστεθούν) μαζί. Ο απλούστερος τρόπος για να το πετύχεις αυτό είναι χρησιμοποιώντας τον τελεστή `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Για οποιαδήποτε μορφοποίηση συμβολοσειράς πιο σύνθετη από την απλή συνένωση, προτιμάται η παρεμβολή συμβολοσειράς. Για να χρησιμοποιήσεις παρεμβολή σε μια συμβολοσειρά, βάλε το σύμβολο του δολαρίου (`$`) μπροστά της. Στη συνέχεια, μπορείς να χρησιμοποιήσεις άγκιστρα (`{}`) για να προσπελάσεις οποιεσδήποτε μεταβλητές μέσα στη συμβολοσειρά σου.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
