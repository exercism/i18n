# Προσθήκη οδηγιών

## Υποδείξεις

Αυτή η άσκηση αφορά την [αναδιαμόρφωση κώδικα](https://en.wikipedia.org/wiki/Refactoring),
γι' αυτό σου δίνουμε μια λύση που περνάει ήδη τα τεστ.

Η πρόκληση είναι να τη γράψεις ξανά μέχρι να νιώσεις περήφανος γι' αυτήν, και να μάθεις
κάτι στην πορεία.

Αν δεν ξέρεις από πού να ξεκινήσεις, ορίστε μερικές ιδέες:

- Προσπάθησε να μειώσεις την επανάληψη στο ελάχιστο.
- Προσπάθησε να κάνεις τον κώδικα ευανάγνωστο.

Πάρε τον χρόνο σου.

Άλλαζε ένα πράγμα τη φορά και έλεγχε αν η λύση σου περνάει ακόμα τα τεστ.

Καλή διασκέδαση!
