# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση      | Τύπος    | Περιγραφή                                                                          |
| ----------- | ---------- | -------- | ---------------------------------------------------------------------------------- |
| `$a0`       | είσοδος    | ακέραιος | πλευρά a                                                                           |
| `$a1`       | είσοδος    | ακέραιος | πλευρά b                                                                           |
| `$a2`       | είσοδος    | ακέραιος | πλευρά c                                                                           |
| `$v0`       | έξοδος     | ακέραιος | τύπος τριγώνου (`0` = σκαληνό, `1` = ισοσκελές, `2` = ισόπλευρο, `3` = μη έγκυρο)  |
| `$t0-9`     | προσωρινός | ό,τιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση                                          |
