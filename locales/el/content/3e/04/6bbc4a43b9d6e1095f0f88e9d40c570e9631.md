# Οδηγίες

Η Elyse, η επίδοξη μάγισσα, συνεχίζει την εκπαίδευσή της. Θα της δοθούν αρκετές στοίβες από κάρτες που χρειάζεται για να εκτελέσει τα κόλπα της.
Για να γίνουν τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10.

Σε αυτή την άσκηση, χρησιμοποίησε ενσωματωμένες μεθόδους για να αναλύσεις τα περιεχόμενα ενός πίνακα.

## 1. Βρες τη θέση μιας κάρτας

Η Elyse θέλει να μάθει τη θέση (index) μιας κάρτας στη στοίβα.

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. Προσδιόρισε αν μια κάρτα υπάρχει

Η Elyse θέλει να προσδιορίσει αν μια κάρτα υπάρχει στη στοίβα, με άλλα λόγια, αν η στοίβα περιέχει ένα συγκεκριμένο `number`.

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. Προσδιόρισε αν κάθε κάρτα είναι άρτια

Η Elyse θέλει να μάθει αν κάθε κάρτα είναι άρτια, με άλλα λόγια, αν κάθε αριθμός στη στοίβα είναι άρτιος `number`.

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. Έλεγξε αν η στοίβα περιέχει μια κάρτα με περιττή τιμή

Η Elyse θέλει να μάθει αν υπάρχει περιττός αριθμός στη στοίβα.

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. Πάρε την πρώτη περιττή κάρτα από τη στοίβα

Η Elyse θέλει να μάθει την τιμή της πρώτης κάρτας που είναι περιττή.

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. Προσδιόρισε τη θέση της πρώτης κάρτας που είναι άρτια

Η Elyse θέλει να μάθει τη θέση της πρώτης κάρτας που είναι άρτια.

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
