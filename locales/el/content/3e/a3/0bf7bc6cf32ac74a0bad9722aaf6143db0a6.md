# Εισαγωγή στους πίνακες

Το Bash παρέχει δύο τύπους παραμέτρων: "βαθμωτές" τιμές και πίνακες.
Μια βαθμωτή τιμή μπορεί να είναι μια συμβολοσειρά ή ένας αριθμός; αντιπροσωπεύει ένα μεμονωμένο "πράγμα".

Τις περισσότερες φορές, οι βαθμωτές τιμές αρκούν για να περιέχουν τα δεδομένα σου.
Κάποιες φορές όμως χρειάζεται να αποθηκεύσεις μια λίστα από βαθμωτές τιμές.
Σε αυτή την περίπτωση θα χρησιμοποιήσεις έναν _πίνακα_.

Υπάρχουν δύο είδη πινάκων:

* Οι αριθμητικά ευρετηριασμένοι πίνακες αντιστοιχίζουν έναν ακέραιο ως κλειδί σε μια τιμή συμβολοσειράς.
  (Άλλες γλώσσες μπορεί να το ονομάζουν αυτό "λίστα" ή "ακολουθία".)
* Οι συσχετιστικοί πίνακες αντιστοιχίζουν ένα κλειδί συμβολοσειράς σε μια τιμή συμβολοσειράς.
  (Άλλες γλώσσες μπορεί να το ονομάζουν αυτό "χάρτη" ή "λεξικό".)

Οι πρώτες ενότητες αυτού του κειμένου θα καλύψουν τους αριθμητικά ευρετηριασμένους πίνακες (που στο εξής θα αναφέρονται απλώς ως "πίνακες").
Λεπτομέρειες για τους συσχετιστικούς πίνακες θα εμφανιστούν στο τέλος.

~~~~exercism/caution
Οι πίνακες του Bash μπορούν να αποθηκεύσουν _μόνο_ βαθμωτές τιμές.
Δεν υπάρχει δυνατότητα δημιουργίας δισδιάστατου πίνακα (πίνακα από πίνακες).
~~~~

## Δήλωση και αρχικοποίηση μιας μεταβλητής πίνακα

Μπορείς να αρχικοποιήσεις έναν πίνακα αναθέτοντας σε μια μεταβλητή μια λίστα στοιχείων μέσα σε παρενθέσεις (ενδεχομένως κενή).

```bash
myarray=("one" "two" "three")
```

Όπως συμβαίνει με κάθε ανάθεση μεταβλητής, δεν πρέπει να υπάρχουν κενά γύρω από το σύμβολο ίσον.

Πρόσεξε ότι δεν υπάρχουν κόμματα που να χωρίζουν τα στοιχεία; είναι μια λίστα συμβολοσειρών χωρισμένων με κενά.

Στην πραγματικότητα, το πόσα κενά υπάρχουν μέσα στις παρενθέσεις είναι εντελώς αυθαίρετο.
Οι αλλαγές γραμμής επιτρέπονται; χρησιμοποίησε όσες θέλεις για να βελτιώσεις την αναγνωσιμότητα.

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

Αναθέτοντας μια λίστα συμβολοσειρών σε μια μεταβλητή πίνακα με αυτόν τον τρόπο, η πρώτη συμβολοσειρά αποθηκεύεται στη θέση μηδέν, η επόμενη στη θέση ένα, η επόμενη στη θέση δύο, και ούτω καθεξής.

Μπορείς να αρχικοποιήσεις έναν "αραιό πίνακα" προσδιορίζοντας τις θέσεις που χρειάζεσαι.

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
Για να το επαναλάβουμε: οι θέσεις των πινάκων ξεκινούν από το μηδέν.
Αυτό το απόσπασμα κώδικα βγάζει "true":

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

Μπορείς να χρησιμοποιήσεις την εντολή `declare` (ή `local` μέσα σε μια συνάρτηση) για να προσδιορίσεις ότι μια μεταβλητή θα περιέχει έναν πίνακα.

```bash
declare -a myarray
```

Είναι πιο ιδιωματικό να αναθέσεις απλώς μια (ίσως κενή) λίστα μέσα σε παρενθέσεις για να αρχικοποιήσεις τη μεταβλητή.

## Πρόσβαση στα στοιχεία ενός πίνακα

Όπως είδες στη σημείωση παραπάνω, η σύνταξη για να προσπελάσεις ένα στοιχείο πίνακα είναι `${myarray[$index]}`.
Η θέση δίνεται μέσα σε αγκύλες.
Τα άγκιστρα είναι υποχρεωτικά.

~~~~exercism/note
Για τους αριθμητικά ευρετηριασμένους πίνακες, η θέση είναι μια αριθμητική παράσταση.
Το εγχειρίδιο του Bash [αναφέρει][arithmetic]:

> Μέσα σε μια αριθμητική παράσταση, οι μεταβλητές του φλοιού μπορούν επίσης να αναφέρονται με το όνομά τους χωρίς να χρησιμοποιείται η σύνταξη επέκτασης παραμέτρου.

Αυτό σημαίνει ότι το `$` δεν απαιτείται για "απλή" επέκταση μεταβλητής.
Μπορείς να προσπελάσεις τα στοιχεία έτσι, που είναι λίγο πιο ευανάγνωστο:

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

Αν η θέση που δίνεται δεν υπάρχει στον πίνακα, το αποτέλεσμα της επέκτασης είναι μια κενή συμβολοσειρά.

## Ανάθεση σε έναν πίνακα

Για να αναθέσεις σε μια συγκεκριμένη καταχώριση του πίνακα, χρησιμοποίησε αυτή τη σύνταξη:

```bash
myarray[10]="hello"
```

Για να _προσθέσεις_ στοιχεία στο τέλος ενός πίνακα, χρησιμοποίησε τον τελεστή ανάθεσης με συνένωση `+=` και χρησιμοποίησε παρενθέσεις:

```bash
myarray+=("new element 1" "new element 2")
```

## Επανάληψη πάνω σε έναν πίνακα

Συνήθως θα χρειαστεί να επαναλάβεις πάνω στις _τιμές_ ενός πίνακα.
Χρησιμοποίησε έναν `for` βρόχο (όπως αυτόν που είδες στην έννοια [Επανάληψη][looping]):

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

Πρόσεξε την ειδική σύνταξη για την επέκταση του πίνακα: `"${myarray[@]}"`
Αυτή η μορφή επέκτασης παραμέτρου αντικαθιστά τις τιμές του πίνακα ως ξεχωριστές λέξεις.
Είναι κάπως ισοδύναμη με:

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

Η μορφή `"${myarray[@]}"` λειτουργεί με αραιούς πίνακες, επεκτεινόμενη μόνο στις τιμές που έχουν οριστεί.

Αυτή η ειδική επέκταση, όπου η θέση είναι το σύμβολο ampersand (`@`), είναι ειδική μόνο μέσα σε διπλά εισαγωγικά.

#### Άλλες ειδικές επεκτάσεις παραμέτρων

Ακολουθούν μερικά ακόμη κομμάτια ειδικής σύνταξης που τα χρειαζόμαστε για την επανάληψη πάνω σε έναν πίνακα.
Περιγράφονται στο εγχειρίδιο στην ενότητα [Επέκταση παραμέτρων του φλοιού][man-expn].

Για να βρεις το _μήκος_ ενός πίνακα, χρησιμοποίησε `${#myarray[@]}`, με ένα `#` πριν από το όνομα.
Το "μήκος" ενός πίνακα είναι ο αριθμός των στοιχείων του.

Για να εξαγάγεις τη λίστα με τις _θέσεις_ ενός πίνακα, χρησιμοποίησε `"${!myarray[@]}"`, με ένα `!` πριν από το όνομα και την επέκταση μέσα σε διπλά εισαγωγικά.
Για τους αριθμητικά ευρετηριασμένους πίνακες, οι θέσεις επεκτείνονται σε αριθμητική σειρά.

### Επανάληψη πάνω στις θέσεις ενός πίνακα

Μερικές φορές χρειάζεσαι και τη θέση μαζί με την τιμή.
Υπάρχουν μερικοί τρόποι να το κάνεις.

1. Όταν ξέρεις ότι οι θέσεις σχηματίζουν μια αδιάκοπη ακολουθία, μπορείς να χρησιμοποιήσεις έναν _αριθμητικό_ `for` βρόχο.

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   Πρόσεξε τη σύνταξη `${#myarray[@]}`, με τον χαρακτήρα `#` μπροστά από το όνομα του πίνακα.
   Επειδή η αρίθμηση των θέσεων στους πίνακες ξεκινά από το μηδέν, η τελευταία θέση του πίνακα είναι κατά ένα μικρότερη από το μήκος του.

2. Όταν ο πίνακας είναι αραιός, μπορείς να χρησιμοποιήσεις αυτή τη μορφή:

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   Πρόσεξε τη σύνταξη `${!myarray[@]}`, με τον χαρακτήρα `!` μπροστά από το όνομα του πίνακα.

## Εξέταση ενός πίνακα

Αν θέλεις να δεις τα περιεχόμενα ενός πίνακα, χρησιμοποίησε την εντολή `declare` με την επιλογή `-p`:

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

Αυτό βγάζει τα περιεχόμενα με την κανονική χρήση εισαγωγικών του φλοιού.

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## Συσχετιστικοί πίνακες

Για να το επαναλάβουμε, οι συσχετιστικοί πίνακες χρησιμοποιούν συμβολοσειρές ως θέσεις, όχι αριθμούς.
Όλα όσα γράφτηκαν παραπάνω ισχύουν και για τους συσχετιστικούς πίνακες, αλλά με μικρές διαφορές.
Γενικά, χρησιμοποιούμε τον όρο "κλειδί" και όχι "θέση": οι συσχετιστικοί πίνακες αντιστοιχίζουν κλειδιά σε τιμές.

### Δήλωση ενός συσχετιστικού πίνακα

Σε αντίθεση με τους πίνακες, οι συσχετιστικοί πίνακες **πρέπει** να δηλώνονται.
Χρησιμοποίησε την επιλογή `-A` της `declare` (ή `local` μέσα σε μια συνάρτηση):

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### Αρχικοποίηση ενός συσχετιστικού πίνακα

Τα ζεύγη κλειδιού-τιμής προσδιορίζονται μέσα στη λίστα με τις παρενθέσεις:

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

Αυτό βγάζει:

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
Να έχεις υπόψη σου ότι οι συσχετιστικοί πίνακες είναι **χωρίς σειρά**.
~~~~

Η δήλωση και η αρχικοποίηση μπορούν να γίνουν σε μία γραμμή.

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

Σε πρόσφατες εκδόσεις του Bash, η αρχικοποίηση μπορεί να χρησιμοποιήσει μια λίστα `(key value key value ...)`.

```bash
declare -A mymap=(first foo second bar third baz)
```

### Πρόσβαση στις τιμές

Για την πρόσβαση στα στοιχεία χρησιμοποιείται η ίδια σύνταξη όπως πριν: `${mymap[$key]}`.

Τα κλειδιά των συσχετιστικών πινάκων δεν αξιολογούνται σε αριθμητικό πλαίσιο.
Απαιτείται η συνήθης σύνταξη επέκτασης παραμέτρου.

### Ανάθεση σε έναν συσχετιστικό πίνακα

Η ανάθεση χρησιμοποιεί την ίδια σύνταξη όπως πριν:

```bash
mymap[$key]="$value"
```

### Επανάληψη

Μπορείς να χρησιμοποιήσεις έναν βρόχο `for value in "${mymap[@]}"` για να επαναλάβεις.
Ωστόσο, συνήθως θέλεις να έχεις και το κλειδί μαζί με την τιμή.

Χρησιμοποίησε τη σύνταξη `"${!mymap[@]}"` που είδαμε παραπάνω.

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

Αυτό βγάζει

```
second -> bar
first -> foo
third -> baz
```

Για να το τονίσουμε ξανά, τα κλειδιά δεν έχουν καμία σειρά.
