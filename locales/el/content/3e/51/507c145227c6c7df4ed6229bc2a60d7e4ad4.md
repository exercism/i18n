## Εισαγωγή

Ένας δείκτης είναι μια μεταβλητή ή σταθερά της οποίας η τιμή είναι η διεύθυνση μιας άλλης μεταβλητής ή σταθεράς.
Οι δείκτες είναι ένα ισχυρό και δυνητικά επικίνδυνο χαρακτηριστικό της C.
Μπορεί να είναι δύσκολο να κατανοήσεις τους δείκτες.

Οι μεταβλητές και οι σταθερές αποθηκεύουν την τιμή τους σε μια θέση μνήμης.
Αυτή η θέση στη μνήμη είναι γνωστή ως η διεύθυνση της μεταβλητής ή της σταθεράς.

Για να πάρουμε τη διεύθυνση μιας μεταβλητής χρησιμοποιούμε τον τελεστή διεύθυνσης, που είναι το `&`.
```c
int i = 5;
int *i_address = &i;
```

Ένας τύπος ακολουθούμενος από ένα `*` και μετά από ένα αναγνωριστικό είναι ο τρόπος για να δηλώσεις έναν δείκτη σε μεταβλητή αυτού του τύπου.
Το `*` είναι γνωστό ως ο τελεστής έμμεσης αναφοράς, επειδή αναφέρεται έμμεσα στην τιμή της οποίας ο δείκτης κρατά τη διεύθυνση.

Όταν δημιουργούμε έναν πίνακα ως εξής

```c
int my_ints[] = {1, 2};
```

Η τιμή του `my_ints` είναι στην πραγματικότητα η διεύθυνσή του, η οποία τυχαίνει να είναι ίδια με τη διεύθυνση του πρώτου στοιχείου του.
Η διεύθυνση του δεύτερου στοιχείου του θα είναι η διεύθυνση του πρώτου στοιχείου συν το μέγεθος ενός `int` στο σύστημα.

Γι' αυτό οι δείκτες δηλώνονται ως συγκεκριμένου τύπου.
Αν ένας δείκτης δεν ήξερε σε ποιον τύπο δείχνει, δεν θα ήξερε πόσα byte να προχωρήσει όταν του προσθέτεις `1`.
Η πρόσθεση του `1` σε έναν δείκτη δεν σημαίνει απαραίτητα ότι προσθέτουμε ένα byte στη διεύθυνση.
Σημαίνει ότι προσθέτουμε `1` επί το μήκος του τύπου του σε byte.
