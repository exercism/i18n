# Οδηγίες

Έχεις μια σειρά από πιτσαρίες στην πόλη σου και θέλεις να γράψεις μια διαδικτυακή εφαρμογή που θα σου επιτρέπει να συγκρίνεις δύο διαφορετικές πίτσες, ώστε να ξέρεις ποιος θα σου δώσει το μεγαλύτερο κομμάτι.

## 1. Γράψε μια συνάρτηση που υπολογίζει το μέγεθος των κομματιών και επιστρέφει nil για μη έγκυρη είσοδο.

Υλοποίησε τη συνάρτηση `sliceSize(diameter: Double?, slices: Int?) -> Double?`, η οποία, δεδομένης της διαμέτρου μιας πίτσας και του αριθμού των κομματιών ανά πίτσα, επιστρέφει το εμβαδόν ενός κομματιού.
Για αρνητικές διαμέτρους και για αριθμό κομματιών μικρότερο του 1, επέστρεψε `nil`, αφού δεν υπάρχει πίτσα με αρνητική διάμετρο και δεν υπάρχει τρόπος να κόψεις μια πίτσα σε λιγότερα από 1 κομμάτι.
Αν κάποια από τις δύο παραμέτρους είναι `nil`, επέστρεψε επίσης `nil`.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Επεξεργάσου την είσοδο από τη διαδικτυακή εφαρμογή σου για να βρεις το μεγαλύτερο κομμάτι.

Η διαδικτυακή εφαρμογή σου θα περάσει τέσσερις συμβολοσειρές στη συνάρτησή σου, `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
Η πρώτη και η δεύτερη συμβολοσειρά είναι η διάμετρος και ο αριθμός των κομματιών της πρώτης πίτσας αντίστοιχα, και η τρίτη και η τέταρτη είναι η διάμετρος και ο αριθμός των κομματιών της δεύτερης πίτσας αντίστοιχα.

Υλοποίησε τη `biggestSlice` έτσι ώστε να επιχειρεί να μετατρέψει τη διάμετρο και τον αριθμό των κομματιών κάθε πίτσας σε `Double` και `Int` αντίστοιχα.
Αν και οι δύο αυτές τιμές μπορούν να προκύψουν από τις συμβολοσειρές, χρησιμοποίησε την πρώτη σου συνάρτηση για να υπολογίσεις το εμβαδόν, διαφορετικά το εμβαδόν αυτού του κομματιού είναι `nil`.
Μόλις υπολογιστούν τα εμβαδά και των δύο κομματιών, σύγκρινε τα δύο εμβαδά χρησιμοποιώντας τους παρακάτω κανόνες:

1. Αν το εμβαδόν του κομματιού A είναι `Double` και του κομματιού B είναι `nil`, επέστρεψε "Slice A is bigger". Αν ισχύει το αντίστροφο, επέστρεψε "Slice B is bigger".
2. Αν και τα δύο εμβαδά είναι `Double`, επέστρεψε "Slice A is bigger" ή "Slice B is bigger" ανάλογα με το ποιο κομμάτι έχει το μεγαλύτερο εμβαδόν.
3. Αν και τα δύο εμβαδά είναι `nil`, ή αν και τα δύο είναι `Double` και είναι ίσα, επέστρεψε "Neither slice is bigger".

~~~~exercism/note
Ακόμα κι αν η είσοδος οδηγεί σε εμβαδόν κομματιού 0, το κομμάτι εξακολουθεί να θεωρείται έγκυρο και θα πρέπει να θεωρείται μεγαλύτερο από ένα κομμάτι με εμβαδόν `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
