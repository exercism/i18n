# Εισαγωγή

Μια **λέξη** είναι το όνομα που δίνει η Factor σε μια συνάρτηση. Με αφετηρία τη στοίβα δεδομένων από το `basics`, η έννοια αυτή αφορά τον ορισμό των δικών σου λέξεων: να κάνεις αριθμητικές πράξεις, να ονομάζεις σταθερές τιμές και να συνθέτεις λέξεις από άλλες λέξεις.

Ένας ορισμός ξεκινά με `:`, δίνει την επίδραση στη στοίβα, μετά ακολουθεί το σώμα και τέλος το `;`. Ο μεταγλωττιστής ελέγχει ότι το σώμα ταιριάζει με την επίδραση που δηλώθηκε:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Οι λέξεις ακέραιας αριθμητικής `+`, `-`, `*` παίρνουν η καθεμία δύο αριθμούς από τη στοίβα και βάζουν το αποτέλεσμα. Ζουν στο λεξιλόγιο `math`, οπότε ένα αρχείο που τις χρησιμοποιεί χρειάζεται το `math` στη γραμμή `USING:` του. Η κορυφή της στοίβας είναι ο δεξιός τελεστέος:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

Το `CONSTANT:` ονομάζει μια σταθερή τιμή. Μια σταθερά είναι και η ίδια μια λέξη: όταν την καλείς, βάζει την τιμή στη στοίβα:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

Το σώμα μιας λέξης μπορεί να καλέσει οποιαδήποτε λέξη βρίσκεται ήδη στο πεδίο εμβέλειας, ακόμη και λέξεις που όρισες νωρίτερα στο ίδιο αρχείο:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Ένα τελικό `?` στις εξόδους είναι η σύμβαση για "Boolean", και τόσο οι λέξεις όσο και οι σταθερές χρησιμοποιούν `lowercase-kebab-case`.
