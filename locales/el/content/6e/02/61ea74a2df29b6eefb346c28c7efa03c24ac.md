# Εισαγωγή

Στη γλώσσα Common Lisp, μια συνάρτηση μπορεί να έχει μερικά ορίσματα που είναι προαιρετικά.
Αυτά υποδηλώνονται στη λίστα παραμέτρων με τη λέξη-κλειδί `&optional`.
Μια παράμετρος θα δεθεί με την τιμή `nil` αν δεν δοθεί.
Αν υπάρχουν πολλές προαιρετικές παράμετροι, δεσμεύονται με τη σειρά.
Μπορούν να καθοριστούν προεπιλεγμένες τιμές για προαιρετικές παραμέτρους.
Τέλος, μπορεί να καθοριστεί ένα σύμβολο για κάθε προαιρετική παράμετρο, το οποίο θα δεθεί με αληθή ή ψευδή τιμή ανάλογα με το αν αυτή η παράμετρος δόθηκε από τον καλούντα της συνάρτησης (αυτό αναφέρεται ως "παράμετρος supplied-p").

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
