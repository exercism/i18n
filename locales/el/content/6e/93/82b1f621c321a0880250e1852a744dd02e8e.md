# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο να παρακολουθείς τα υψηλά σκορ για το πιο δημοφιλές παιχνίδι στην τοπική σου αίθουσα παιχνιδιών.

Έχεις 5 συναρτήσεις να υλοποιήσεις, που σχετίζονται κυρίως με τον χειρισμό ενός αντικειμένου που περιέχει υψηλά σκορ.

## 1. Δημιούργησε έναν νέο πίνακα υψηλών σκορ

Δημιούργησε μια συνάρτηση `create_score_board` που επιστρέφει ένα dict που χρησιμεύει ως πίνακας υψηλών σκορ.
Τα κλειδιά αυτού του αντικειμένου θα είναι τα ονόματα των παικτών, οι τιμές θα είναι τα σκορ τους.
Για τις ανάγκες των τεστ, θέλεις να συμπεριλάβεις απευθείας μία καταχώριση στο αντικείμενο.
Αυτή η αρχική καταχώριση θα πρέπει να αποτελείται από το `"The Best Ever"` ως όνομα παίκτη και το `1_000_000` ως σκορ.

```gleam
create_score_board()
// returns an object with one initial entry
```

## 2. Πρόσθεσε παίκτες σε έναν πίνακα σκορ

Για να προσθέσεις έναν παίκτη στον πίνακα υψηλών σκορ, όρισε τη συνάρτηση `add_player`.
Δέχεται 3 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον dict που αναπαριστά τον πίνακα σκορ.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά.
- Η τρίτη παράμετρος είναι το σκορ ως int.

Η συνάρτηση επιστρέφει ένα dict στο οποίο έχουν προστεθεί ο νέος παίκτης και το σκορ.

## 3. Αφαίρεσε παίκτες από έναν πίνακα σκορ

Αν οι παίκτες παραβιάσουν τους κανόνες της αίθουσας παιχνιδιών, αφαιρούνται χειροκίνητα από τον πίνακα υψηλών σκορ.
Όρισε τη συνάρτηση `remove_player` που παίρνει 2 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον dict που αναπαριστά τον πίνακα σκορ.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά.

Αυτή η συνάρτηση θα πρέπει να επιστρέφει το dict χωρίς τον παίκτη που αφαιρέθηκε.

Αν ο παίκτης δεν ήταν εξαρχής στον πίνακα, δεν θα πρέπει να αλλάξει τίποτα στον πίνακα, θα πρέπει να επιστραφεί ως έχει.

## 4. Αύξησε το σκορ ενός παίκτη

Αν ένας παίκτης τελειώσει άλλο ένα παιχνίδι στην αίθουσα παιχνιδιών, ένα συγκεκριμένο ποσό πόντων θα προστεθεί στο προηγούμενο σκορ του πίνακα.
Υλοποίησε τη συνάρτηση `update_score`, που παίρνει 3 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον dict που αναπαριστά τον πίνακα σκορ.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη του οποίου το σκορ θα πρέπει να αυξηθεί.
- Η τρίτη παράμετρος είναι το σκορ που θέλεις να **προσθέσεις** στο αποθηκευμένο υψηλό σκορ.

Η συνάρτηση θα πρέπει να επιστρέφει ένα dict με το ενημερωμένο σκορ.

Αν ο παίκτης δεν ήταν εξαρχής στον πίνακα, δεν θα πρέπει να αλλάξει τίποτα στον πίνακα, θα πρέπει να επιστραφεί ως έχει.

## 5. Εφάρμοσε τους πόντους μπόνους της Δευτέρας

Η αίθουσα παιχνιδιών κρατά έναν ξεχωριστό πίνακα σκορ τις Δευτέρες.
Στο τέλος της ημέρας, κάθε παίκτης σε αυτόν τον πίνακα παίρνει 100 επιπλέον πόντους.

Υλοποίησε τη συνάρτηση `apply_monday_bonus` που δέχεται έναν πίνακα σκορ.
Η συνάρτηση επιστρέφει ένα dict με τους πόντους μπόνους προστιθέμενους για κάθε παίκτη που αναγράφεται σε αυτόν τον πίνακα.
