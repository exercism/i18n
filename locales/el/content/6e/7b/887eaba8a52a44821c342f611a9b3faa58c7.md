# Οδηγίες

Υλοποίησε μια συνάρτηση που, όταν της δοθούν δύο σημεία στο δισδιάστατο
επίπεδο συντεταγμένων, παράγει ένα τρίτο σημείο, έτσι ώστε η ένωση αυτών
των σημείων να σχηματίζει ένα ισόπλευρο τρίγωνο. Η συνάρτηση θα επιστρέψει
δύο σημεία, επειδή υπάρχουν δύο πιθανά "τρίτα" σημεία που παράγουν ένα
ισόπλευρο τρίγωνο με δεδομένα τα δύο αρχικά σημεία. Αξίζει να σημειωθεί
ότι ένα ισόπλευρο τρίγωνο ορίζεται ως ένα τρίπλευρο σχήμα στο οποίο και
οι τρεις πλευρές έχουν ίσο μήκος.

Η συνάρτηση δέχεται ως είσοδο δύο πλειάδες της Python, καθεμία από τις
οποίες προσδιορίζει τις συντεταγμένες x και y κάθε σημείου, ως αριθμούς
κινητής υποδιαστολής. Για παράδειγμα, τα (0.0, 0.0) και (1.0, 1.0) θα
μπορούσαν να είναι είσοδοι.

Η συνάρτηση θα πρέπει να επιστρέφει μια πλειάδα που αποτελείται από δύο
πλειάδες, καθεμία από τις οποίες προσδιορίζει τις συντεταγμένες x και y
κάθε σημείου, ως αριθμούς κινητής υποδιαστολής. Για παράδειγμα, το
((0.0, 0.0), (1.0, 1.0)) θα μπορούσε να είναι μια πιθανή έξοδος.

Η συνάρτηση θα πρέπει να πετάει την ενσωματωμένη εξαίρεση ArithmeticError
της Python, αν ο επιλυτής Z3 παράγει ένα αποτέλεσμα που δεν είναι
ικανοποιήσιμο. Μια ArithmeticError θα πρέπει επίσης να πετάγεται αν και
τα δύο σημεία εισόδου είναι τα ίδια.

Η συνάρτηση δεν θα πρέπει να χρησιμοποιεί τη συνάρτηση "set_option()" της
βιβλιοθήκης z3 για να ορίζει καθολικές παραμέτρους. Αυτό γίνεται μέσα στις
περιπτώσεις δοκιμών, για να διασφαλιστεί ότι οι αριθμοί κινητής
υποδιαστολής έχουν την αναμενόμενη ακρίβεια (αριθμός δεκαδικών ψηφίων).

Εφόσον η ερμηνεία του μοντέλου μιας μεταβλητής Real του Z3 είναι ένα
στιγμιότυπο των AlgebraicNumRef, IntNumRef ή RatNumRef, παρέχεται μια
συνάρτηση για τη μετατροπή αυτού του στιγμιότυπου σε αριθμό κινητής
υποδιαστολής.
