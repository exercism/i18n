# Εισαγωγή

Σε πολλές αντικειμενοστρεφείς γλώσσες προγραμματισμού, είναι σύνηθες να επεκτείνεις συμπεριφορές δημιουργώντας μια [υποκλάση][wiki-subclass] από μια γονική κλάση, κληρονομώντας μεθόδους από τη γονική κλάση και ταυτόχρονα προσθέτοντας νέες.
Έτσι προκύπτει μια ιεραρχία αντικειμένων.

Η Julia _δεν έχει κλάσεις_, άρα κατ' επέκταση _δεν έχει υποκλάσεις_.
Πώς κληρονομούμε και επεκτείνουμε υπάρχουσες συμπεριφορές;

Σε προηγούμενες έννοιες είδαμε πώς να δημιουργείς μια ιεραρχία τύπων, καθώς και πώς η Julia χρησιμοποιεί την [πολλαπλή αποστολή][concept-multiple-dispatch] για να επιλέγει μεθόδους με βάση τους τύπους των ορισμάτων.

Η Julia έχει επίσης αρκετές άτυπες διεπαφές, που επιτρέπουν στους δικούς σου τύπους να συνδεθούν με συμπεριφορές που έχουν ήδη οριστεί για τους βασικούς τύπους.

Αυτό φαίνεται πιο εύκολα με τη διεπαφή του Επαναλήπτη.

## Επαναλήπτες

Προηγουμένως στο πρόγραμμα σπουδών, έχουμε δει αρκετούς τρόπους με τους οποίους η Julia μπορεί να επεξεργαστεί κάθε στοιχείο μιας συλλογής.

- [Βρόχοι][concept-loops], όπως `for item in items...`
- [Μετάδοση][concept-vector-operations]: `[1, 2, 3] .- 0.5`
- [Συναρτήσεις υψηλότερης τάξης][concept-hof]: `map(√, [1, 4, 9])`
- [Κατανοήσεις][concept-comprehensions]: `[x * y for x in 1:3 for y in 4:6 if isodd(x * y)]`
- [Γεννήτριες][concept-comprehensions]: `(x^2 for x in 1:1e6)`, οι οποίες αξιολογούνται τεμπέλικα.

Είναι σαφές ότι η Julia ξέρει να διατρέχει τις βασικές συλλογές στοιχείο προς στοιχείο: διανύσματα και διαστήματα στα παραπάνω παραδείγματα, αλλά και Σύνολα, Λεξικά κ.λπ.

Πώς προσθέτουμε αυτή τη δυνατότητα στις δικές μας προσαρμοσμένες συλλογές, ειδικά αν μπορούν να επαναλαμβάνονται τεμπέλικα σαν μια γεννήτρια;

### Ελάχιστες απαιτήσεις

Για να δημιουργήσουμε μια ακολουθία προς επανάληψη, χρειαζόμαστε (τουλάχιστον) δύο πράγματα:

1. Έναν τρόπο να πάρουμε το _πρώτο_ στοιχείο.
2. Έναν τρόπο να πάρουμε το _επόμενο_ στοιχείο από την τρέχουσα κατάσταση.

Η Julia το πετυχαίνει αυτό με μεθόδους της συνάρτησης `Base.iterate()` και τα εξής βήματα:

1. Καλείται αυτόματα πρώτα η `Base.iterate(iter)`.
    - Αν δεν υπάρχει τίποτα προς επανάληψη, επιστρέφει `nothing`.
    - Αλλιώς, επιστρέφει το `Tuple` του πρώτου στοιχείου που επιστρέφεται και της πρώτης κατάστασης: `(firstitem, firststate)`.
2. Η `Base.iterate(iter, state)` καλείται αυτόματα αν επιστράφηκε στοιχείο στην προηγούμενη επανάληψη, παίρνοντας το `firststate` ως όρισμα `state`.
    - Αν η επανάληψη τερματιστεί, επιστρέφει `nothing`.
    - Αλλιώς, επιστρέφει το `Tuple` του επόμενου στοιχείου και της επόμενης κατάστασης: `(nextitem, nextstate)`.
3. Επαναλαμβάνει το βήμα 2 μέχρι τον τερματισμό.

Όλα αυτά τα βήματα γίνονται "κάτω από το καπό", που σημαίνει ότι οι κλήσεις μεθόδων και η κατάσταση διαχειρίζονται εσωτερικά από το πρωτόκολλο επανάληψης (με την κατάσταση να παραμένει αδιαφανής), και μόνο το στοιχείο εκτίθεται σε δομές υψηλού επιπέδου, όπως οι βρόχοι.
Με άλλα λόγια, βλέπουμε μόνο το `item`, ενώ όλα τα υπόλοιπα παραμένουν σε ένα μαύρο κουτί.

Η [πολλαπλή αποστολή][concept-multiple-dispatch] είναι κεντρικής σημασίας εδώ.
Ο τύπος του `iter` καθορίζει ποιες μέθοδοι καλούνται, και ο αριθμός των ορισμάτων καθορίζει αν επιστρέφεται το πρώτο ή το επόμενο στοιχείο.

Οι μέθοδοι για τους βασικούς τύπους έχουν ήδη οριστεί: `Vector`, `Range`, `Set` κ.λπ. ([προς το παρόν][ref-iterations-collections] 14 τύποι συνολικά).

Για να μοιράζεται ο δικός μας `MyType` τις ίδιες συμπεριφορές, πρέπει πρώτα να ορίσουμε:
- `Base.iterate(iter::MyType)`
- `Base.iterate(iter::MyType, state)`

Όλα αυτά μπορεί να ακούγονται μπερδεμένα στη θεωρία, αλλά μπορεί να είναι αρκετά απλά.
Για παράδειγμα, φαντάσου ότι θέλουμε έναν τύπο που να δίνει τις δυνάμεις ενός δεδομένου ακεραίου `n`, μέχρι έναν μέγιστο αριθμό.

Πρώτα, όρισε έναν προσαρμοσμένο τύπο:

```julia
struct Powers
    n::Int      # base number to raise to a power
    count::Int  # maximum length of the sequence
end
```

Μπορούμε τώρα να ορίσουμε τις μεθόδους `iterate` για αυτόν τον τύπο, αλλά ποιο είναι το πρώτο στοιχείο και ποια η πρώτη κατάσταση;

Για να πάρουμε το πρώτο στοιχείο, ορισμένοι επαναλήπτες χρειάζονται περίπλοκη προετοιμασία, αλλά σε αυτή την απλοϊκή περίπτωση, μπορούμε να παρατηρήσουμε ότι το πρώτο στοιχείο που επιστρέφεται είναι απλώς ο βασικός αριθμός, οπότε αρκεί να ελέγξουμε αν η τιμή του `count` είναι μεγαλύτερη ή ίση με ένα.

Τώρα μπορούμε να εξετάσουμε την πρώτη κατάσταση, η οποία μεταφέρει πληροφορίες που χρησιμοποιούνται για την επόμενη επανάληψη.
Εξαρτάται από εσένα να αποφασίσεις ποιες πληροφορίες πρέπει να παρακολουθείς για να το κάνεις αυτό, και μπορεί να είναι οποιουδήποτε τύπου.

Σε αυτή την περίπτωση, θα μπορούσαμε απλώς να παρακολουθούμε τη "θέση" στην οποία θα υψώσουμε το `n`, ή μπορούμε να βρούμε μια πιο αποδοτική επιλογή χρησιμοποιώντας την πιο πρόσφατη δύναμη του `n` (δηλαδή το στοιχείο που επιστράφηκε) και την επόμενη "θέση" στην ακολουθία.
Αυτοί οι δύο αριθμοί μπορούν να τυλιχτούν σε ένα `Tuple` και να επιστραφούν ως `state`.

```julia
function Base.iterate(p::Powers)
    # if iteration should continue
    if 1 ≤ p.count
        # return (firstitem, firststate)
        return (p.n, (p.n, 2)) 
    end
    # else terminate iteration
    return nothing
end
```

Σε αυτό το παράδειγμα, το πρώτο στοιχείο (`p.n`) επιστρέφεται στον βρόχο και η πρώτη κατάσταση `(p.n, 2)` περνά στη μέθοδο `iterate(P::Powers, state)`.
Εκεί μπορούμε να επεξεργαστούμε την κατάσταση ώστε να παραγάγουμε το επόμενο στοιχείο πολλαπλασιάζοντας το τρέχον στοιχείο με τον βασικό αριθμό, αυξάνοντας έτσι τη δύναμή του κατά `1`.

```julia
function Base.iterate(p::Powers, state)
    # unpack the state
    curr, index = state

    # create next item                 
    next = curr * p.n

    # if iteration should continue
    if index ≤ p.count
        # return (nextitem, nextstate)
        return (next, (next, index + 1))
    end
    # else terminate iteration
    return nothing
end
```

Αν η τιμή της θέσης είναι ακόμη εντός του `count`, το `Tuple` επιστρέφεται με το στοιχείο `next` και το αυξημένο `Tuple` της κατάστασης.
Όταν η τιμή του `index` ξεπερνά το `count`, τότε επιστρέφεται `nothing`, για να δηλώσει ότι η επανάληψη τερματίστηκε.

Ίσως έχεις παρατηρήσει ότι οι μέθοδοι `iterate(p::Powers)` και `iterate(p::Powers, state)` έχουν αρκετά παρόμοια σώματα συνάρτησης.
Στην πραγματικότητα, αν είμαστε έξυπνοι, αυτή η ομοιότητα επιτρέπει μια πιο λιτή υλοποίηση χρησιμοποιώντας μόνο την έκδοση με δύο ορίσματα και ένα προεπιλεγμένο όρισμα για την κατάσταση: `Base.iterate(p::Powers, state=(1, 1))`
Έτσι, δεν θα χρειαζόμασταν την ξεχωριστή έκδοση με ένα όρισμα `iterate(p::Powers)`.
Αυτό γίνεται συχνά στην πράξη, όταν είναι εφικτό.

Μέχρι στιγμής, έχουμε ήδη κάποιες χρήσιμες λειτουργίες: για τις πρώτες 4 δυνάμεις του 3, μπορούμε να διατρέξουμε τα αποτελέσματα με έναν βρόχο, να ελέγξουμε αν ένας δεδομένος αριθμός βρίσκεται στα αποτελέσματα, και να εφαρμόσουμε συναρτήσεις συνάθροισης όπως η `sum()`.

```julia-repl
julia> for p in Powers(3, 4)
            println(p)
       end
3
9
27
81

julia> 9 ∈ Powers(3, 4) # ∈ is a synonym for in
true

julia> sum(Powers(3, 4))
120
```

### Επιπλέον μέθοδοι

Παρά την καλή αρχή, δεν λειτουργούν ακόμη όλα.

```julia-repl
julia> [p for p in Powers(3, 4)]
ERROR: MethodError: no method matching length(::Powers) (from the documentation][ref-interfaces])
The function `length` exists, but no method is defined for this combination of argument types.
You may need to implement the `length` method or define `IteratorSize` for this type to be `SizeUnknown`.
```

Πράγματι, η `length(Powers(3, 4))` δίνει ακριβώς το ίδιο μήνυμα σφάλματος.

Αυτό διορθώνεται εύκολα, καθώς το μήκος είναι μέρος του κατασκευαστή του τύπου: 4 σε αυτή την περίπτωση.
Αρκεί να ορίσουμε τη `Base.length()` για αυτόν τον τύπο, και μετά μπορούμε να χρησιμοποιήσουμε κατανοήσεις και `collect()` στην ακολουθία.

```julia-repl
julia> Base.length(P::Powers) = P.count

julia> length(Powers(3, 4))
4

julia> [p for p in Powers(3, 4)]
4-element Vector{Int64}:
  3
  9
 27
 81

julia> collect(Powers(3, 4))
4-element Vector{Any}:
  3
  9
 27
 81

julia> Set(Powers(3, 4))
Set{Int64} with 4 elements:
  81
  27
  9
  3
```

Για λόγους απόδοσης, το καλύτερο είναι να ορίσουμε και τη `Base.eltype()`: τον τύπο στοιχείου του αποτελέσματος.
Αυτό επιτρέπει σε συναρτήσεις όπως η `collect()` να προκαθορίσουν χώρο για το `Vector{Int}` εξόδου, αντί να κάνουν επανειλημμένα `push!()` σε ένα `Vector{Any}`.

Πρόσεξε τη σύνταξη, την οποία μπορεί να μην έχεις ξαναδεί: αυτή η μέθοδος ορίζεται στον _τύπο_, όχι σε ένα _στιγμιότυπο_ του τύπου.

```julia-repl
julia> Base.eltype(::Type{Powers}) = Int
```

Οι επαναλήπτες δεν _απαιτείται_ να έχουν πεπερασμένο μήκος.
Η χρήση "άπειρων" ακολουθιών είναι πιο περιορισμένη, αλλά η επανάληψη πάνω από αυτές μπορεί να είναι χρήσιμη, αρκεί να υπάρχει κάποιος τρόπος να βγεις από τον βρόχο με `break`.
Για παράδειγμα, θα μπορούσαμε να ορίσουμε μια παραλλαγή του `Powers` που να παράγει τιμές μικρότερες από ένα συγκεκριμένο όριο (ίσως `typemax(Int)`, για να αποφύγουμε την υπερχείλιση ακεραίων).

## Σύνοψη

Οι διεπαφές είναι αρκετά μπερδεμένες στην εξήγηση, επειδή η προσέγγιση της Julia είναι τόσο διαφορετική από τις περισσότερες άλλες γλώσσες.
Ειδικότερα, το όνομα της διεπαφής μπορεί να μην αναφέρεται ποτέ στην υλοποίηση: σε αντίθεση με τη [δημιουργία υποκλάσεων][wiki-subclass] ή τα [mixins][wiki-mixins].

Ωστόσο, στην πράξη είναι εκπληκτικά απλές:

1. Όρισε έναν κατάλληλο τύπο.
2. Βρες ποιες μέθοδοι απαιτούνται.
3. Υλοποίησε αυτές τις μεθόδους για τον προσαρμοσμένο τύπο σου: συνήθως μόνο λίγες μέθοδοι, αρκετά σύντομες και απλές.
4. Άφησε την [πολλαπλή αποστολή][concept-multiple-dispatch] να αναλάβει τα υπόλοιπα, αυτόματα.
