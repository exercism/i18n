# Εισαγωγή

Στη JavaScript, οι τιμές μπορεί να είναι διαφορετικών τύπων. Την αλλαγή του τύπου μιας μεταβλητής μπορείς να την κάνεις με ρητή _μετατροπή τύπου_.
Εκτός από αυτό, η JavaScript εκτελεί και _εξαναγκασμό τύπου_ (έμμεση μετατροπή τύπου) όταν το πλαίσιο το απαιτεί.

## Μετατροπή τύπου

Η JavaScript δεν έχει κάποια δομή για να κάνεις cast μια τιμή σε (διαφορετικό) τύπο, όπως πολλές άλλες γλώσσες, αλλά μπορείς να χρησιμοποιήσεις αντ' αυτού κάποιες ενσωματωμένες βοηθητικές συναρτήσεις.
Πιο συγκεκριμένα, οι `Boolean`, `Number` και `String` μπορούν να χρησιμοποιηθούν ως συναρτήσεις για τη μετατροπή μιας τιμής στον αντίστοιχο τύπο.

### Μετατροπή σε Boolean (τιμές truthy/falsy)

Με το `Boolean(value)` μπορείς να μετατρέψεις οποιαδήποτε τιμή σε boolean.
Υπάρχει ένα συγκεκριμένο σύνολο τιμών, οι λεγόμενες _falsy_ τιμές, που μετατρέπονται σε `false`.
Το πιο σημαντικό είναι ότι οι `false`, `0`, η κενή συμβολοσειρά, το `null`, το `undefined` και το `NaN` είναι falsy.

Για όλες τις άλλες τιμές, το `Boolean` επιστρέφει `true`.
Αυτές οι τιμές ονομάζονται _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Σημείωσε ότι, εξαιτίας των κανόνων που περιγράφηκαν, τα `'0'`, `'false'`, `[]` και `{}` είναι **truthy** στη JavaScript.

### Μετατροπή σε αριθμό

Το `Number(value)` μπορεί να χρησιμοποιηθεί για τη μετατροπή μιας τιμής σε αριθμό.
Τα κενά στην αρχή και στο τέλος μιας συμβολοσειράς αγνοούνται και μια κενή συμβολοσειρά μετατρέπεται σε `0`.
Αν προσπαθήσεις να μετατρέψεις μια μη πρωτόγονη τιμή ή μια συμβολοσειρά που δεν αντιπροσωπεύει αριθμό, το αποτέλεσμα είναι `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Μετατροπή σε συμβολοσειρά

Με το `String(value)` μπορείς να μετατρέψεις μια τιμή σε συμβολοσειρά.
Για τις πρωτόγονες τιμές, το αποτέλεσμα είναι αυτό που θα περίμενες.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Για τους πίνακες, η συνάρτηση `String` εφαρμόζει τη μετατροπή σε συμβολοσειρά σε κάθε στοιχείο και ενώνει τα αποτελέσματα με κόμμα.
Μπορείς επίσης να εφαρμόσεις ο ίδιος τη [μέθοδο `join`][mdn-join], π.χ. για να προσαρμόσεις το διαχωριστικό.
Σημείωσε ότι σε αυτές τις περιπτώσεις τα `null` και `undefined` μετατρέπονται σε κενή συμβολοσειρά.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Για τα αντικείμενα, από προεπιλογή το `String` επιστρέφει ένα κείμενο που δεν σε βοηθάει καθόλου.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Εξαναγκασμός τύπου

Σε ορισμένα πλαίσια, η JavaScript μετατρέπει αυτόματα μια τιμή σε άλλον τύπο δεδομένων προτού αξιολογήσει κάποια εντολή.
Αυτή η έμμεση μετατροπή ονομάζεται _εξαναγκασμός τύπου_.

### Πλαίσιο boolean

Όταν μια τιμή που δεν είναι boolean χρησιμοποιείται σε πλαίσιο boolean, η JavaScript εφαρμόζει τους ίδιους κανόνες με τη συνάρτηση `Boolean` για να μετατρέψει την τιμή έμμεσα.

Ο εξαναγκασμός σε boolean εμφανίζεται συνήθως:

- στη συνθήκη μιας [εντολής `if`][concept-conditionals]
- στον πρώτο τελεστέο του [τριαδικού τελεστή][mdn-ternary] `?`
- στον τελεστέο του λογικού τελεστή NOT `!`
- στους τελεστέους των λογικών τελεστών AND `&&` και OR `||` (το αποτέλεσμα της έκφρασης είναι ένας από τους τελεστέους, όχι απαραίτητα boolean)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Πλαίσιο συμβολοσειράς

Αν ο τελεστής πρόσθεσης `+` χρησιμοποιηθεί με πρωτόγονες τιμές και ο ένας τελεστέος είναι συμβολοσειρά, τότε και ο άλλος θα εξαναγκαστεί σε συμβολοσειρά.
Η λογική της μετατροπής είναι ίδια με αυτήν της συνάρτησης `String`.
Στη συνέχεια, οι δύο συμβολοσειρές συνενώνονται.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Αριθμητικό πλαίσιο

Πολλοί τελεστές εξαναγκάζουν τους τελεστέους σε αριθμούς (αν χρειάζεται) σύμφωνα με τη λογική της συνάρτησης `Number` που εξηγήθηκε παραπάνω.

- Αριθμητικοί τελεστές: `+` (αν δεν εμπλέκεται συμβολοσειρά), `-`, `*`, `/`, `%`, `**`
- Μονομερείς τελεστές συν και άρνησης: `+`, `-`
- Σχεσιακοί τελεστές (για τελεστέους που δεν είναι συμβολοσειρές): `>`, `>=`, `<`, `<=`
- Τελεστές bitwise: `|`, `&`, `^`, `~`

Ανατρέξε στη [λίστα τελεστών του MDN][mdn-operators] για περισσότερες λεπτομέρειες σχετικά με οποιονδήποτε από αυτούς τους τελεστές.

Για να αποφεύγεις λάθη, είναι καλή πρακτική να καλείς πάντα το `Number` ρητά πριν εφαρμόσεις αυτούς τους τελεστές.
