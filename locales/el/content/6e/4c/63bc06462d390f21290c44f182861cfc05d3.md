# Μάθηση

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά μπορεί να είναι δύσκολο να ξεκινήσεις για όσους μαθαίνουν τη Reason για πρώτη φορά. Οι παρακάτω πόροι μπορούν να σε βοηθήσουν να κάνεις την αρχή:

[Αρχική σελίδα της Reason](https://reasonml.github.io/)
[Ιστολόγιο προγραμματιστή](https://lucasmreis.github.io/blog/learning-reasonml-part-1/)

Η ReasonML μπορεί να χρησιμοποιήσει το [Belt](https://bucklescript.github.io/bucklescript/api/Belt.html), τη βασική βιβλιοθήκη που συνοδεύει το Bucklescript (το υποκείμενο σύστημα Ocaml πάνω στο οποίο στηρίζεται).
