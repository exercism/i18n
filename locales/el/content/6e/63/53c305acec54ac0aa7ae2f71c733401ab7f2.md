# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις ένα μέρος από βοηθητικές ρουτίνες που βοηθούν έναν προγραμματιστή να καθαρίσει ονόματα αναγνωριστικών.

Στις 6 εργασίες θα χτίσεις σταδιακά τις συναρτήσεις `transform`, που μετατρέπει μεμονωμένους χαρακτήρες, και `clean`, που μετατρέπει συμβολοσειρές.

Ένα έγκυρο αναγνωριστικό αποτελείται από μηδέν ή περισσότερα γράμματα, κάτω παύλες, παύλες, ερωτηματικά και emoji.

Αν περάσεις μια κενή συμβολοσειρά στη συνάρτηση `clean`, θα πρέπει να επιστρέφεται μια κενή συμβολοσειρά.

## 1. Αντικατέστησε κάθε παύλα που συναντάς με κάτω παύλα

Υλοποίησε τη συνάρτηση `transform` ώστε να αντικαθιστά κάθε παύλα με κάτω παύλα.

```fsharp
transform '-'  // => "_"
```

## 2. Αφαίρεσε όλα τα κενά διαστήματα

Αφαίρεσε όλους τους χαρακτήρες κενού διαστήματος.
Αυτό περιλαμβάνει τα κενά στην αρχή και στο τέλος.

```fsharp
transform ' '  // => ""
```

## 3. Μετέτρεψε το camelCase σε kebab-case

Τροποποίησε τη συνάρτηση `transform` ώστε να μετατρέπει το camelCase σε kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Παράλειψε τους χαρακτήρες που είναι ψηφία

Τροποποίησε τη συνάρτηση `transform` ώστε να παραλείπει κάθε χαρακτήρα που είναι αριθμητικός.

```fsharp
transform '7'  // => ""
```

## 5. Αντικατέστησε τα ελληνικά πεζά γράμματα με ερωτηματικά

Τροποποίησε τη συνάρτηση `transform` ώστε να αντικαθιστά κάθε ελληνικό γράμμα στο εύρος από 'α' έως 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Συνδύασε αυτές τις πράξεις για να δουλέψεις σε μια συμβολοσειρά

Υλοποίησε τη συνάρτηση `clean` ώστε να εφαρμόζει αυτές τις πράξεις σε ολόκληρη τη συμβολοσειρά.

Οι χαρακτήρες που βρίσκονται έξω από τους κανόνες θα πρέπει να περνούν αναλλοίωτοι.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Συναρμολόγηση μιας συμβολοσειράς από χαρακτήρες

Αυτό το θέμα θα καλυφθεί αναλυτικά αργότερα στο πρόγραμμα σπουδών.

Για την ώρα, μπορεί να σου φανεί χρήσιμο να ξέρεις ότι υπάρχει μια [συνάρτηση υψηλότερης τάξης][higher-order-function] που ονομάζεται [`String.collect`][string-collect] και μετατρέπει μια συλλογή από `char`s σε συμβολοσειρά, χρησιμοποιώντας μια συνάρτηση που δίνεις εσύ.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
