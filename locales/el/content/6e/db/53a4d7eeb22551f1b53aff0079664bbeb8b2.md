# Σχετικά

Η Haskell έχει έναν τύπο, τον `Num`, ο οποίος είναι ο βασικός τύπος για όλους τους αριθμητικούς τύπους.
Υπάρχουν τέσσερις κύριοι υποτύποι μέσα στον τύπο αριθμών: [`Int`][int], [`Integer`][integer], [`Double`][double]  και [`Float`][float].

Υπάρχουν δύο τύποι ακεραίων στην Haskell, οι οποίοι αναπαριστούν ακέραιους αριθμούς.
Ο `Int` είναι ακέραιος σταθερού μεγέθους, ενώ ο `Integer` είναι ακέραιος αυθαίρετης ακρίβειας.

Ένας `Integer` χωράει οποιονδήποτε αριθμό, όσο μεγάλος κι αν είναι, μέχρι το όριο της μνήμης του υπολογιστή σου, ενώ ο `Int` αντιστοιχεί στο σύνολο των θετικών και αρνητικών ακεραίων που μπορούν να παρασταθούν σε 32 ή 64 bit (εγγυημένα τουλάχιστον από -2^29 έως 2^29 - 1).

Σημείωσε ότι, όταν γράφεις αρνητικούς αριθμούς, καλό είναι να χρησιμοποιείς παρενθέσεις για να αποφεύγεις την ασάφεια.

```haskell
1

(-1)
```

Ο `Float` αντιστοιχεί στο σύνολο των πραγματικών αριθμών, με περιορισμό την ακρίβεια του υπολογιστή.
Οι πράξεις που ορίζονται στους αριθμούς συνήθως λειτουργούν στον έναν τύπο ή στον άλλον, αλλά όχι και στους δύο.
Ο `Double` είναι αριθμός κινητής υποδιαστολής διπλής ακρίβειας.

```haskell
10.5
```

## Μετατροπή μεταξύ ακεραίων και αριθμών κινητής υποδιαστολής

Χρησιμοποιώντας τη συνάρτηση `toFloat`, μπορείς να μετατρέψεις έναν `Int` ή `Integer` σε `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Υπάρχει επίσης η `fromIntegral`, η οποία μετατρέπει οποιονδήποτε αριθμητικό τύπο στον τύπο που απαιτείται, όπως αυτός συμπεραίνεται.

```haskell
fromIntegral 1
-- -> 1.0
```

Για να μετατρέψεις έναν `Float` σε `Int`, μπορείς να χρησιμοποιήσεις τις συναρτήσεις [`round`][round], [`floor`][floor] ή [`ceiling`][ceiling].
Η συνάρτηση `round` στρογγυλοποιεί στον πλησιέστερο ακέραιο, η `floor` στρογγυλοποιεί προς τα κάτω και η `ceiling` προς τα πάνω.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Αριθμητικοί τελεστές

Μπορείς να χρησιμοποιήσεις τους [βασικούς αριθμητικούς τελεστές][math] στους αριθμητικούς τύπους.
Οι τελεστές είναι `+`, `-`, `*`, `/` και `%`.
Όταν χρησιμοποιείς αυτούς τους τελεστές, οι τύποι των αριθμών πρέπει να ταιριάζουν.
Η συνάρτηση `fromIntegral` θα κάνει τη μετατροπή, ώστε να ταιριάζουν οι τύποι.

### Πρόσθεση & Αφαίρεση & Πολλαπλασιασμός

Ο τελεστής `+` χρησιμοποιείται για πρόσθεση, ο τελεστής `-` για αφαίρεση και ο τελεστής `*` για πολλαπλασιασμό.

| Τελεστής | Παράδειγμα    |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Διαίρεση

Η διαίρεση χρησιμοποιείται για να διαιρούμε αριθμούς.
Ο τελεστής `/` χρησιμοποιείται για διαίρεση.
Το αποτέλεσμα θα είναι πάντα αριθμός κινητής υποδιαστολής.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Σε ορισμένες γλώσσες προγραμματισμού, όταν διαιρείς με το μηδέν, το αποτέλεσμα θα είναι σφάλμα.

Στην Haskell, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι `Infinity` ή `-Infinity`.
Η μόνη εξαίρεση είναι η διαίρεση του μηδέν με το μηδέν, που έχει ως αποτέλεσμα `NaN` (Not a Number).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Διαίρεση ακεραίων

Η διαίρεση ακεραίων χρησιμοποιείται για να διαιρούμε ακέραιους αριθμούς και να παίρνουμε το ακέραιο μέρος του αποτελέσματος.
Η Haskell έχει δύο συναρτήσεις διαίρεσης ακεραίων, οι οποίες διαφέρουν στον τρόπο στρογγυλοποίησης όταν το αποτέλεσμα είναι αρνητικό:

- Ο `div` στρογγυλοποιεί προς τα κάτω, προς το αρνητικό άπειρο.
- Ο `quot` στρογγυλοποιεί προς το μηδέν.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς διαίρεση ακεραίων έχει ως αποτέλεσμα μια εξαίρεση.
Αυτό είναι διαφορετικό από την κανονική διαίρεση.
~~~~

### Υπόλοιπο

Το υπόλοιπο μιας διαίρεσης ακεραίων μπορεί να βρεθεί χρησιμοποιώντας το `mod` ή το `rem`.
Διαφέρουν ως προς το πρόσημο του αποτελέσματος όταν ένας από τους αριθμούς είναι αρνητικός:

- Το `mod` πάει μαζί με το `div`, και το αποτέλεσμα έχει το ίδιο πρόσημο με τον διαιρέτη.
- Το `rem` πάει μαζί με το `quot`, και το αποτέλεσμα έχει το ίδιο πρόσημο με τον διαιρετέο.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Για οποιαδήποτε `x` και `y` (με το `y` διάφορο του μηδενός), ισχύουν οι παρακάτω νόμοι:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Όταν και οι δύο αριθμοί είναι θετικοί, οι `div` και `quot` δίνουν το ίδιο αποτέλεσμα, όπως και οι `mod` και `rem`.
Σε αυτή την περίπτωση, οι `quot` και `rem` μπορεί να είναι ελαφρώς πιο αποδοτικοί, καθώς οι `div` και `mod` χρειάζονται επιπλέον βήματα για να χειριστούν αρνητικούς αριθμούς.
~~~~

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς `mod` ή `rem` έχει ως αποτέλεσμα μια εξαίρεση.
Αυτό είναι διαφορετικό από την κανονική διαίρεση.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Ύψωση σε δύναμη

Η Haskell έχει τρεις τελεστές ύψωσης σε δύναμη, οι οποίοι λειτουργούν διαφορετικά και δέχονται διαφορετικούς τύπους ορισμάτων.

- `**` Δέχεται δύο **αριθμούς κινητής υποδιαστολής** και χρησιμοποιεί λογαρίθμους για να υπολογίσει τη δύναμη.
- `^^` Δέχεται έναν αριθμό **κινητής υποδιαστολής** και τον υψώνει σε θετική ή αρνητική **ακέραια** δύναμη.
- `^` Δέχεται **οποιονδήποτε αριθμητικό τύπο** και τον υψώνει σε **θετική ακέραια** δύναμη.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Προτεραιότητα και παρενθέσεις

Η Haskell επιτρέπει παρενθέσεις (`()`), οι οποίες μπορούν να χρησιμοποιηθούν για την ομαδοποίηση εκφράσεων.
Αυτό είναι χρήσιμο όταν θέλεις να αλλάξεις τη σειρά των πράξεων.

Όταν χρησιμοποιείς πολλούς αριθμητικούς τελεστές, η σειρά των πράξεων είναι η ίδια όπως στα μαθηματικά, γνωστή και ως [PEMDAS][pemdas].
Ακολουθεί τη σειρά των παρενθέσεων (`()`), των δυνάμεων (`**`), του πολλαπλασιασμού (`*`) και της διαίρεσης (`/`), καθώς και της πρόσθεσης (`+`) και της αφαίρεσης (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
