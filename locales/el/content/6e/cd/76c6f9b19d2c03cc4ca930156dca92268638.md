# Εισαγωγή

Συχνά, θέλουμε να γράψουμε κώδικα που μπορεί να διακλαδωθεί με βάση μια συνθήκη. Αν και υπάρχουν πολλοί τρόποι να το κάνεις αυτό στην Elixir, ένας από τους πιο απλούς τρόπους είναι η χρήση του `cond/1`.

Στην πιο απλή του μορφή, το `cond` ακολουθεί το πρώτο μονοπάτι που αξιολογείται σε `true` με έναν ή περισσότερους κλάδους:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Αν κανένα μονοπάτι δεν αξιολογείται σε `true`, το περιβάλλον εκτέλεσης πετάει ένα σφάλμα.
