# Εισαγωγή

Η Swift παρέχει έναν ενσωματωμένο τύπο, γνωστό ως [`Bool`][bools], για να αναπαριστά τιμές αλήθειας: `true` και `false`.

## Λογικοί τελεστές

Η Swift παρέχει τρεις [λογικούς τελεστές][logical-operators] (`!`, `&&` και `||`) για να συνδυάζεις και να αξιολογείς Boolean εκφράσεις.

### Λογικό ΚΑΙ (`&&`)

Ο τελεστής [_και_][and] (`&&`) επιστρέφει `true` μόνο αν και οι δύο τελεστέοι είναι `true`.
Αν ένας από τους τελεστέους είναι `false`, επιστρέφει `false`.
Τοποθέτησε μια έκφραση ή μια Boolean τιμή σε κάθε πλευρά του συμβόλου `&&`:

```swift
true && true  // true
true && false // false
```

### Λογικό Ή (`||`)

Ο τελεστής [_ή_][or] (`||`) επιστρέφει `true` αν **τουλάχιστον ένας** από τους τελεστέους είναι `true`.
Επιστρέφει `false` μόνο όταν και οι δύο τελεστέοι είναι `false`.
Τοποθέτησε μια έκφραση ή μια Boolean τιμή σε κάθε πλευρά του συμβόλου `||`:

```swift
true || true   // true
true || false  // true
false || false // false
```

### Λογικό ΟΧΙ (`!`)

Ο τελεστής [_όχι_][not] (`!`) αντιστρέφει μια Boolean τιμή.
Επιστρέφει `true` αν η τιμή είναι `false` και `false` αν η τιμή είναι `true`.
Τοποθέτησε τον τελεστή `!` αμέσως πριν από την τιμή ή την έκφραση:

```swift
!true  // false
!false // true
```

## Χρήση παρενθέσεων (`()`)

Μπορείς να χρησιμοποιήσεις [παρενθέσεις][explicit-parentheses] για να ομαδοποιήσεις εκφράσεις και να ελέγξεις τη σειρά αξιολόγησης.
Στη Swift, οι εκφράσεις μέσα σε παρενθέσεις αξιολογούνται πρώτα:

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Η ομαδοποίηση με παρενθέσεις καθορίζει επίσης πώς εφαρμόζεται ο τελεστής _όχι_ σε σύνθετες εκφράσεις:

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
Χρησιμοποίησε παρενθέσεις όταν χρειάζεται να αποσαφηνίσεις τη σειρά αξιολόγησης ή να κάνεις τις σύνθετες συνθήκες πιο ευανάγνωστες.
Απόφευγε να προσθέτεις περιττές παρενθέσεις όταν η προεπιλεγμένη προτεραιότητα είναι ήδη σαφής.
~~~~
