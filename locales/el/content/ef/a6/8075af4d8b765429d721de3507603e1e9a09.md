# Επίλυση ασκήσεων με τον διαδικτυακό επεξεργαστή

Η επίλυση ασκήσεων online με τον διαδικτυακό επεξεργαστή του ιστότοπου σου επιτρέπει να ξεκινήσεις γρήγορα με ένα track.
Με τον διαδικτυακό επεξεργαστή δεν χρειάζεται να εγκαταστήσεις τίποτα στον υπολογιστή σου, όλα λειτουργούν μέσα στον browser (ακόμα και η εκτέλεση των tests).

## Επίλυση της άσκησης

Ο στόχος κάθε άσκησης είναι να φτιάξεις μια υλοποίηση που περνάει όλα τα tests.
Μια τέτοια υλοποίηση ονομάζεται _λύση_.

Για να ξεκινήσεις, πήγαινε στον ιστότοπο, γράψου σε ένα track και πήγαινε στη σελίδα της άσκησης.
Εκεί μπορείς να κάνεις κλικ στο κουμπί "Άνοιγμα στον επεξεργαστή".
Αυτό θα ανοίξει τον διαδικτυακό επεξεργαστή, ο οποίος δείχνει τις εξής πληροφορίες:

- Στην αριστερή πλευρά βρίσκεται ο επεξεργαστής στον οποίο θα γράψεις τη λύση σου
- Στη δεξιά πλευρά βρίσκονται οι οδηγίες που εξηγούν τι περιμένουμε από εσένα

Μετά μπορείς να ξεκινήσεις να γράφεις τη λύση σου.

Κάνοντας κλικ στο κουμπί "Εκτέλεση tests" θα ελεγχθεί αν η λύση σου περνάει τα tests της άσκησης.
Μόλις εκτελεστούν τα tests, τα αποτελέσματα θα εμφανιστούν στα δεξιά.

### Debugging

Ο διαδικτυακός επεξεργαστής δεν έχει ενσωματωμένο debugger.
Κάποια tracks υποστηρίζουν debugging μέσω print, όπου ο κώδικάς σου μπορεί να τυπώσει κείμενο που εμφανίζεται στα αποτελέσματα.
Αν ένα track το υποστηρίζει, οι οδηγίες για το πώς να χρησιμοποιήσεις αυτή τη δυνατότητα εμφανίζονται στη δεξιά πλευρά.

## Υποβολή της λύσης σου

Μόλις η λύση σου περάσει όλα τα tests, μπορείς να την υποβάλεις με το κουμπί "Υποβολή".
