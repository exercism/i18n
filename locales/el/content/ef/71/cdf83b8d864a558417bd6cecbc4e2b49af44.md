# Debug

Καθώς ο τρέχων test runner χρησιμοποιεί το [PonyTest](https://stdlib.ponylang.io/pony_test--index/), ο actor Main βρίσκεται στο test.pony και δεν θα πρέπει να τον επεξεργαστείς ως μέρος της λύσης σου.

Όπως συνηθίζεται στις εφαρμογές Pony, δεν παρέχουμε πρόσβαση στο `Env` παρά μόνο όταν χρειάζεται. Αυτό σημαίνει ότι, σχεδόν σε όλες τις περιπτώσεις, δε μπορείς να χρησιμοποιήσεις debugging τύπου printf με το `env.out.print()`.

Ωστόσο, η Pony διαθέτει ένα [debug](https://stdlib.ponylang.io/debug--index/) module που επιτρέπει σε προγράμματα που μεταγλωττίζονται με τη σημαία `-d` να έχουν ειδική πρόσβαση στα STDOUT και STDERR χωρίς πρόσβαση στο `Env`.

Αν χρειάζεσαι debugging τύπου printf, θα πρέπει να χρησιμοποιήσεις αυτή τη λειτουργία.

Παράδειγμα debug:

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
