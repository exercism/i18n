# Σχετικά

Τα πάντα στη Common Lisp είναι μια έκφραση.
Μια έκφραση είναι είτε ένα μεμονωμένο πράγμα (που ονομάζεται άτομο) είτε μια λίστα από πράγματα (οριοθετημένη με παρενθέσεις: `()`).

## Παράθεση

Όλες οι S-εκφράσεις, όπως τα σύμβολα, μπορούν να παρατεθούν:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Αυτή η παράθεση εμποδίζει την αξιολόγηση μιας S-έκφρασης, αντιμετωπίζοντάς την αντίθετα σαν δεδομένα.
Εδώ υπάρχει μια εξαιρετική [απάντηση στο Stack Overflow][so-quoting] που συζητά την παράθεση με λίγο περισσότερες λεπτομέρειες.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
