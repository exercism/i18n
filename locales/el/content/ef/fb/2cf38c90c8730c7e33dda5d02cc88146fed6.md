# Εισαγωγή

Οι εξαιρέσεις στην C# παρέχουν έναν δομημένο, ομοιόμορφο και ασφαλή ως προς τους τύπους τρόπο χειρισμού συνθηκών σφάλματος που προκύπτουν κατά την εκτέλεση. Ο σωστός χειρισμός των εξαιρέσεων και των σφαλμάτων είναι σημαντικός όταν προσπαθείς να αποτρέψεις καταρρεύσεις της εφαρμογής.

Στην C#, όλες οι εξαιρέσεις έχουν ως βασικό τύπο την κλάση `System.Exception`. Περιέχει σημαντικές ιδιότητες, όπως η `Message`, η οποία περιέχει μια περιγραφή αναγνώσιμη από τον άνθρωπο για τον λόγο για τον οποίο πετιέται η εξαίρεση.

Για να δηλώσεις ότι πρέπει να υπάρξει ένα σφάλμα σε ένα συγκεκριμένο σημείο του κώδικα, πρέπει να δημιουργήσεις ένα νέο αντικείμενο εξαίρεσης και μετά να το πετάξεις, χρησιμοποιώντας τη λέξη-κλειδί `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Όταν πετιέται μια εξαίρεση, το περιβάλλον εκτέλεσης έχει το καθήκον να βρει ένα κομμάτι κώδικα που είναι υπεύθυνο για τον χειρισμό αυτής της εξαίρεσης. Αν δεν βρεθεί κατάλληλος χειριστής, το περιβάλλον εκτέλεσης εμφανίζει το μήνυμα της μη χειρισμένης εξαίρεσης και παράλληλα σταματά την εκτέλεση του προγράμματος.

Για να δημιουργήσεις έναν χειριστή για μια εξαίρεση, η C# χρησιμοποιεί την εντολή try-catch, η οποία αποτελείται από ένα μπλοκ `try` και μία ή περισσότερες ρήτρες `catch`. Το μπλοκ `try` θα πρέπει να περιέχει και να προστατεύει κώδικα που μπορεί να οδηγήσει στο να πεταχτεί η εξαίρεση. Οι ρήτρες `catch` θα πρέπει να περιέχουν κώδικα που χειρίζεται τη συμπεριφορά του προγράμματος αφού συμβεί το σφάλμα. Είναι σημαντικό να σημειώσεις ότι η σειρά των εξαιρέσεων παίζει ρόλο μετά το μπλοκ `try`, καθώς όταν παρατίθενται πολλαπλές εξαιρέσεις, εκτελείται η πρώτη ρήτρα `catch` που ταιριάζει.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
