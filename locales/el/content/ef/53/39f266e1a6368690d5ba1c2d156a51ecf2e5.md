# Οδηγίες

Εργάζεσαι σε ένα φημισμένο δικηγορικό γραφείο που ειδικεύεται σε μοναδικά αιτήματα διαθηκών.

Σε αυτή την άσκηση, θα ανοίξεις ένα μυστηριώδες θησαυροφυλάκιο.
Είσαι ο εκτελεστής της κληρονομιάς και θα συνθέσεις τους επί μακρόν φυλαγμένους μυστικούς κωδικούς τριών οικογενειών για να πάρεις έναν αριθμό λογαριασμού και τον αντίστοιχο κωδικό.

Για να μην μπορεί καμία οικογένεια να ανοίξει το θησαυροφυλάκιο μόνη της, αυτό ανοίγει μόνο αν συνδυάσεις τις γνώσεις τους με έναν μυστικό τροποποιητή που γνωρίζεις από τη διαθήκη.

Έχεις τρεις εργασίες, όλες σχετικές με το να βοηθήσεις τις οικογένειες να ανοίξουν το θησαυροφυλάκιο.

# 1. Πάρε τη θέση σου μπροστά στις οικογένειες και απλώσε τα χαρτιά σου

Όρισε έναν χώρο ονομάτων με το όνομα `EstateExecutor`.
Ο κώδικας από τις επόμενες εργασίες θα πρέπει να οριστεί στο σώμα του χώρου ονομάτων `EstateExecutor`.

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

# 2. Βρες τον μυστικό αριθμό λογαριασμού

Αυτή είναι η μεγάλη σου στιγμή.
Μόνο εσύ έχεις το μυστικό κλειδί τροποποιητή για να αποκαλύψεις τον μυστικό αριθμό λογαριασμού.

Όρισε τη μέθοδο `assemble_account_number(secret_modifier)` που παίρνει ως όρισμα τον μυστικό τροποποιητή `Integer` και επιστρέφει τον συναρμολογημένο αριθμό λογαριασμού `Integer`.

Για να πάρεις τον σωστό αριθμό, πρέπει να αθροίσεις το `bank_number_part` από καθεμία από τις τρεις οικογένειες.

# 3. Τελευταίο βήμα: Βάλε τον μυστικό κωδικό

Οι οδηγίες στη διαθήκη σου ζητούν να προσθέσεις πρώτα όλα τα μπλε και μετά όλα τα κόκκινα θραύσματα.
Ο κωδικός που προκύπτει βγαίνει πολλαπλασιάζοντας τα δύο αθροίσματα.

Όρισε τη μέθοδο `assemble_code` που επιστρέφει τον κωδικό που προκύπτει, συνδυάζοντας τα θραύσματα από τις τρεις οικογένειες σε ένα μόνο αποτέλεσμα `Integer`.
Η μέθοδος δεν παίρνει κανένα όρισμα και βασίζεται αποκλειστικά στις πληροφορίες που βρίσκονται στους σχετικούς χώρους ονομάτων των οικογενειών.
