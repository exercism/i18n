## Ζεύγη

Το `Pair` είναι μια δομή δεδομένων που περιέχει ακριβώς δύο στοιχεία, προσβάσιμα μέσω των πεδίων `first` και `second`.

Μπορούν να κατασκευαστούν χρησιμοποιώντας το `x => y`:

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

Τα στοιχεία ενός `Pair` μπορούν να είναι διαφορετικού τύπου:

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

Τα `Pair` έχουν δύο κοινές χρήσεις στη Julia: τα λεξικά και τις αντικαταστάσεις.

### Αντικαταστάσεις

Πολλές μέθοδοι αντικατάστασης παίρνουν ένα `Pair` ως όρισμα, για να γίνει σαφές ποιο στοιχείο αντικαθίσταται.
Αυτό επιτρέπει σύνταξη όπως

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

όπου κάθε `4` στη συλλογή αντικαθίσταται από `0`, αντί για τη λιγότερο σαφή σύνταξη

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
