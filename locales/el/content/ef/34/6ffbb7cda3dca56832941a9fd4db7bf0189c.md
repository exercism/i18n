# Εισαγωγή

## `Base.@kwdef`

Μπορείς να χρησιμοποιήσεις τη μακροεντολή `Base.@kwdef` για να ορίσεις αυτόματα κατασκευαστές που δέχονται ορίσματα με λέξεις-κλειδιά για τον ορισμό ενός [struct][struct].
Σου επιτρέπει επίσης να ορίσεις προεπιλεγμένες τιμές για πεδία.

Για παράδειγμα, ο παρακάτω ορισμός

```julia
Base.@kwdef struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64 = mass / (0.01 * height)^2
end
```

ορίζει τρεις κατασκευαστές ταυτόχρονα

```julia-repl
julia> methods(HumanStats)
# 3 methods for type constructor:
[1] HumanStats(; birthyear, height, mass, bmi) [...]
[2] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[3] HumanStats(birthyear, height, mass, bmi) [...]
```

συμπεριλαμβανομένου ενός κατασκευαστή που βασίζεται σε ορίσματα με λέξεις-κλειδιά

```julia-repl
julia> HumanStats(
           birthyear = 2002,
           height = 193,
           mass = 83
       )
HumanStats(2002, 193, 83, 22.28247738194314)
```

ενώ ο τυπικός ορισμός

```julia
struct HumanStats
    birthyear::Int
    height::Int
    mass::Int
    bmi::Float64
end
```

ορίζει μόνο τους εξής δύο

```julia-repl
julia> methods(HumanStats)
# 2 methods for type constructor:
[1] HumanStats(birthyear::Int64, height::Int64, mass::Int64, bmi::Float64) [...]
[2] HumanStats(birthyear, height, mass, bmi) [...]
```

και θα απαιτούσε να ορίσεις χειροκίνητα έναν κατασκευαστή με λέξεις-κλειδιά.

### Πότε να χρησιμοποιείς το `Base.@kwdef`;

Οι κατασκευαστές με λέξεις-κλειδιά είναι ιδιαίτερα χρήσιμοι για την κατασκευή structs που δέχονται μεγάλο αριθμό ορισμάτων, ειδικά όταν ο τύπος ή η τιμή των ορισμάτων δεν σχετίζονται άμεσα με τη σημασία τους.

Ας δούμε τον παρακάτω ορισμό:

```julia
dirk = BasketballPlayer(1978, 1994, 2019, 213, 111, 42, 1998, [2011], 31560, 11489, 3651)
```

Δεν είναι σαφές τι σημαίνει κάθε τιμή χωρίς να γνωρίζεις τον ορισμό του τύπου.
Και ακόμη κι αν γνωρίζεις τον ορισμό, μάλλον θα πρέπει να ανατρέχεις στη σειρά ξανά και ξανά.

Ωστόσο, όταν χρησιμοποιείς έναν κατασκευαστή με λέξεις-κλειδιά, η σημασία τους είναι αμέσως προφανής:

```julia
dirk = BasketballPlayer(
    birthyear = 1978,
    career_start = 1994,
    career_end = 2019,
    height = 213,
    weight = 111,
    number = 42,
    drafted = 1998,
    championships = [2011],
    points = 31560,
    rebounds = 11489,
    assists = 3651
)
```

~~~~exercism/caution
Το `Base.@kwdef` δεν εξάγεται και δεν τεκμηριώνεται στο εγχειρίδιο, και επομένως δεν αποτελεί μέρος του [δημόσιου API της Julia][public-api].
Αυτό σημαίνει ότι τεχνικά δεν υπάρχει εγγύηση πως η διεπαφή του είναι σταθερή και μπορεί να αλλάξει ανάμεσα σε δευτερεύουσες εκδόσεις της Julia.

Ωστόσο, η μακροεντολή χρησιμοποιείται ευρέως σε όλο το οικοσύστημα, και είναι απίθανο να αλλάξει με τρόπο που σπάει τη συμβατότητα.

Για περισσότερες πληροφορίες, δες:

- ["Τι κάνει το `@kwdef`;"][discourse-kwdef]
- [Ζήτημα Julia #32659 για να προστεθεί το `@kwdef` στο Εγχειρίδιο][add-kwdef-to-manual]
- [Ζήτημα Julia #33192 για να εξαχθεί το `@kwdef`][export-kwdef]

~~~~
