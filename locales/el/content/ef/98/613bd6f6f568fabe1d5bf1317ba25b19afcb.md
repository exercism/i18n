# Εισαγωγή

## Συγκρίσεις

Στη C++, μπορείς να συγκρίνεις τιμές χρησιμοποιώντας τους τελεστές σύγκρισης.

| Σύγκριση          | Τελεστής  |
| ------------------| --------- |
| ίσο με            | `==`      |
| διάφορο του       | `!=`      |
| μικρότερο         | `<`       |
| μικρότερο ή ίσο   | `<=`      |
| μεγαλύτερο        | `>`       |
| μεγαλύτερο ή ίσο  | `>=`      |

Το αποτέλεσμα αυτών των συγκρίσεων είναι πάντα μια τιμή boolean (λογική τιμή):

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Οι τελεστές `==` και `!=` ελέγχουν αν μια τιμή είναι ίση ή όχι με μια άλλη, αντίστοιχα.
Ακολουθούν μερικά συνηθισμένα παραδείγματα:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Οι υπόλοιποι τελεστές ελέγχουν αν μια τιμή είναι μεγαλύτερη από (`>`), μεγαλύτερη ή ίση με (`>=`), μικρότερη από (`<`) και μικρότερη ή ίση με (`<=`) μια άλλη τιμή.
Αυτού του είδους η σύγκριση είναι διαθέσιμη για αριθμούς και συμβολοσειρές.
Όταν συγκρίνεις συμβολοσειρές, ακολουθείται η σειρά του λεξικού (γνωστή και ως λεξικογραφική σειρά).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## Εντολές `if`

Οι συνθήκες στη C++ μοιάζουν με τις συνθήκες σε άλλες γλώσσες.
Ο υποκείμενος τύπος κάθε πράξης συνθήκης είναι ο τύπος `bool`, ο οποίος μπορεί να έχει την τιμή `true` ή `false`.
Οι συνθήκες χρησιμοποιούνται συχνά ως μηχανισμοί ελέγχου ροής για να ελέγχουν διάφορες περιπτώσεις.

Μπορείς να χρησιμοποιήσεις μια εντολή `if`, η οποία εκτελεί τον κώδικά της αν η υποκείμενη συνθήκη είναι `true`, όπως εδώ:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Σε περιπτώσεις με περισσότερα από ένα ενδεχόμενα, πολλές εντολές `if` μπορούν να αλυσοδεθούν μεταξύ τους με τις εντολές `else if` και `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Από τη C++17 και μετά, οι εντολές if μπορούν επίσης να περιλαμβάνουν μια σύντομη εντολή αρχικοποίησης, η οποία μπορεί να χρησιμοποιηθεί για την αρχικοποίηση μιας ή περισσότερων μεταβλητών για την εντολή if.
Για παράδειγμα:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Σημείωση: όποιες μεταβλητές δημιουργούνται στην αρχικοποίηση δεν είναι προσβάσιμες μετά το τέλος της εντολής if.
