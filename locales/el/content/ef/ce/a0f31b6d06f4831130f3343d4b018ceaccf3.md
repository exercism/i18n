# Bools

Η Crystal έχει έναν τύπο γνωστό ως [`Bool`][bools].
Αντιπροσωπεύει τις τιμές `true` και `false`.

## Λογικοί τελεστές

Η Crystal έχει τρεις λογικούς τελεστές (`!`, `||`, `&&`), οι οποίοι συνδυάζουν Bool τιμές και δημιουργούν εκφράσεις που παράγουν διαφορετικές τιμές.

### And(`&&`)

Ο τελεστής [_and_][and] στη Crystal αντιπροσωπεύεται από το `&&` και επιστρέφει `true` αν και οι δύο τιμές είναι `true`· αλλιώς, επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _and_, μία Bool τιμή τοποθετείται στη δεξιά πλευρά του `&&` και μία άλλη στην αριστερή.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

Ο τελεστής [_or_][or] στη Crystal αντιπροσωπεύεται από το `||` και επιστρέφει `true` αν **τουλάχιστον μία** από τις τιμές που δίνονται είναι `true`.
Αν και οι δύο τιμές είναι `false`, τότε επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _or_, μία Bool τιμή θα πρέπει να τοποθετηθεί στη δεξιά πλευρά του `||` και μία άλλη στην αριστερή.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

Ο τελεστής _not_ στη Crystal αντιπροσωπεύεται από το `!` και επιστρέφει `true` αν η Bool τιμή που δίνεται είναι `false`, ενώ επιστρέφει `false` αν του δοθεί `true`.
Όταν χρησιμοποιείς τον τελεστή _not_, μία Bool τιμή θα πρέπει να τοποθετηθεί μετά τον τελεστή (`!`).

```crystal
!true
# => false

!false
# => true
```

## Χρήση παρενθέσεων(`()`)

Όταν δουλεύεις με Boolean τιμές, μπορείς να χρησιμοποιήσεις παρενθέσεις για να καθορίσεις ποιες Bool τιμές θα αξιολογηθούν πρώτα.
Το αποτέλεσμα μπορεί να διαφέρει ανάλογα με το πώς χρησιμοποιούνται οι παρενθέσεις.
Στη Crystal, ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Επειδή ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα, στο παρακάτω παράδειγμα ο τελεστής _not_ θα εφαρμοστεί στην έκφραση μέσα στις παρενθέσεις.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Να χρησιμοποιείς παρενθέσεις μόνο όταν επηρεάζουν το αποτέλεσμα· αλλιώς, παράλειψέ τις.
~~~~

## Truthy και falsey

Στη Crystal, οι "falsey" τιμές είναι: `false`, `nil` και οι μηδενικοί δείκτες· **όλα τα υπόλοιπα** είναι "truthy".
Αυτές οι τιμές μπορούν να χρησιμοποιηθούν με τους λογικούς τελεστές που αναφέρθηκαν παραπάνω.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Συμβάσεις ονομασίας μεθόδων με Boolean

Στη Crystal, συνηθίζεται μια μέθοδος που επιστρέφει μια τιμή truthy ή falsey να ονομάζεται με ένα ερωτηματικό (`?`).
Στις περισσότερες περιπτώσεις, αυτή η μέθοδος θα επιστρέψει μια τιμή Bool, αλλά δεν είναι απαραίτητο.
Αυτό σημαίνει ότι η μέθοδος μπορεί να χρησιμοποιηθεί σε σημεία όπου αναμένεται μια τιμή truthy ή falsy, για παράδειγμα ως συνθήκη σε μια εντολή `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Οι μέθοδοι που έχουν ερωτηματικό στο τέλος του ονόματός τους και δεν επιστρέφουν τιμή Bool συχνά επιστρέφουν `nil` αντ' αυτού. Το `nil` είναι _παρόμοιο με το `None` ή το `null` από άλλες γλώσσες_.
