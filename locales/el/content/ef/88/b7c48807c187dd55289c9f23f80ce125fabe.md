# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να δημιουργήσεις τον τύπο δεδομένων `LinkedList`
και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Θα βρεις μια εικονική δήλωση δεδομένων και υπογραφές τύπων που υπάρχουν ήδη,
αλλά είναι στο χέρι σου να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν ουσιαστικό τύπο δεδομένων,
newtype ή συνώνυμο τύπου.
