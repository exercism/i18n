# Εισαγωγή

Στη Go, το `map` είναι ένας ενσωματωμένος τύπος δεδομένων που αντιστοιχίζει κλειδιά σε τιμές.
Σε άλλες γλώσσες προγραμματισμού, ίσως να είσαι εξοικειωμένος με την έννοια του `map` ως λεξικό, πίνακα κατακερματισμού, αποθήκη κλειδιού/τιμής ή συσχετιστικό πίνακα.

Συντακτικά, το `map` μοιάζει κάπως έτσι:

```go
map[KeyType]ElementType
```

Είναι επίσης σημαντικό να ξέρεις ότι κάθε κλειδί είναι μοναδικό, που σημαίνει ότι αν αναθέσεις το ίδιο κλειδί δύο φορές, θα αντικατασταθεί η τιμή του αντίστοιχου κλειδιού.

Για να δημιουργήσεις ένα map, μπορείς να κάνεις:

```go
  // With map literal
  foo := map[string]int{}
```

ή

```go
  // or with make function
  foo := make(map[string]int)
```

Εδώ είναι μερικές πράξεις που μπορείς να κάνεις με ένα map

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

Αν προσπαθήσεις να ανακτήσεις την τιμή για ένα κλειδί που δεν υπάρχει στο map, θα σου επιστρέψει τη μηδενική τιμή του τύπου τιμών.
Αυτό μπορεί να σε μπερδέψει, ειδικά αν η προεπιλεγμένη τιμή του `ElementType` σου (για παράδειγμα, το 0 για έναν int) είναι μια έγκυρη τιμή.
Για να ελέγξεις αν ένα κλειδί υπάρχει στο map σου, μπορείς να χρησιμοποιήσεις

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
