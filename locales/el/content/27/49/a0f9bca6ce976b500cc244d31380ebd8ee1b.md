# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LVL>]: <MESSAGE>"`.

Αυτά είναι τα διάφορα επίπεδα καταγραφής:

- `TRC` (ίχνος)
- `DBG` (debug)
- `INF` (πληροφορία)
- `WRN` (προειδοποίηση)
- `ERR` (σφάλμα)
- `FTL` (θανατηφόρο)

Έχεις τρεις εργασίες.

## 1. Ανάλυση επιπέδου καταγραφής

Όρισε ένα enum `LogLevel` που έχει έξι στοιχεία, τα οποία αντιστοιχούν στα παραπάνω επίπεδα καταγραφής.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

Έπειτα, υλοποίησε τη (_static_) μέθοδο `LogLine.ParseLogLevel()` για να αναλύεις το επίπεδο καταγραφής μιας γραμμής καταγραφής:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Υποστήριξη άγνωστου επιπέδου καταγραφής

Δυστυχώς, κάποιες φορές μερικές γραμμές καταγραφής έχουν άγνωστο επίπεδο καταγραφής. Για να χειριστείς ομαλά αυτές τις γραμμές καταγραφής, πρόσθεσε ένα στοιχείο `Unknown` στο enum `LogLevel`, το οποίο θα πρέπει να επιστρέφεται όταν αναλύεται ένα άγνωστο επίπεδο καταγραφής:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Μετατροπή γραμμής καταγραφής σε σύντομη μορφή

Το επίπεδο καταγραφής μιας γραμμής καταγραφής είναι αρκετά αναλυτικό. Για να μειωθεί ο χώρος στον δίσκο που χρειάζεται για την αποθήκευση των γραμμών καταγραφής, αναπτύχθηκε μια σύντομη μορφή: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Το κωδικοποιημένο επίπεδο καταγραφής είναι μια απλή αντιστοίχιση ενός επιπέδου καταγραφής σε έναν αριθμό:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Υλοποίησε τη (_static_) μέθοδο `LogLine.OutputForShortLog()` που μπορεί να παράγει τη συντομευμένη μορφή γραμμής καταγραφής:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
