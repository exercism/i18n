# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που θα χρειαστείς για το μαγείρεμα της λαζάνιας.

~~~~exercism/note
Αυτές είναι οι εντολές που αναφέρονται σε αυτή την έννοια:

| Instruction | Description                     |
|-------------|---------------------------------|
| mov a, b    | αντιγράφει τα περιεχόμενα από το b στο a |
| add a, b    | a = a + b                       |
| sub a, b    | a = a - b                       |
| imul a, b   | a = a * b                       |
| call a      | καλεί τη συνάρτηση a            |
| ret         | επιστρέφει από μια συνάρτηση     |
~~~~

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο, σε λεπτά

Όρισε τη συνάρτηση `expected_minutes_in_oven`, η οποία δεν παίρνει καμία παράμετρο και επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στο φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο, σε λεπτά, είναι 40:

```c
expected_minutes_in_oven();
// => 40
```

## 2. Υπολόγισε τον χρόνο που απομένει στο φούρνο, σε λεπτά

Όρισε τη συνάρτηση `remaining_minutes_in_oven`, η οποία παίρνει ως παράμετρο τα πραγματικά λεπτά που έχει ήδη μείνει η λαζάνια στο φούρνο και επιστρέφει πόσα λεπτά πρέπει να μείνει ακόμη, με βάση τον αναμενόμενο χρόνο στο φούρνο, σε λεπτά, από την προηγούμενη εργασία.

```c
remaining_minutes_in_oven(30);
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας, σε λεπτά

Όρισε τη συνάρτηση `preparation_time_in_minutes`, η οποία παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να την προετοιμάσεις, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```c
preparation_time_in_minutes(2);
// => 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει, σε λεπτά

Όρισε τη συνάρτηση `elapsed_time_in_minutes`, η οποία παίρνει δύο παραμέτρους, με αυτή τη σειρά:

1. Τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια.
2. Τον αριθμό των λεπτών που έχει μείνει η λαζάνια στο φούρνο.

Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα της λαζάνιας.
Αυτό είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στο φούρνο μέχρι στιγμής.

```c
elapsed_time_in_minutes(3, 20);
// => 26
```
