# Προσθήκη στις οδηγίες

## Roc API

Χρησιμοποίησε μια αμετάβλητη τιμή `React`. Κάθε πράξη επιστρέφει έναν ενημερωμένο reactor. Κράτησε αυτή την τιμή για τις επόμενες πράξεις. Τα cell αναγνωρίζονται από το `cell_id` και τα callback από το `callback_id`. Και τα δύο αναγνωριστικά είναι συμβολοσειρές που δίνονται όταν καταχωρούνται. Η καταχώριση και η αφαίρεση callback παίρνουν και τα δύο αναγνωριστικά για να προσδιορίσουν το cell και το callback του.

Μια συνάρτηση υπολογισμού δέχεται μια λίστα με τιμές cell με την ίδια σειρά με τη λίστα `inputs` των αναγνωριστικών cell. Επιστρέφει `Ok(value)` όταν πετυχαίνει ή `Err(message)` με μια συμβολοσειρά που περιγράφει μια αποτυχία, όπως λάθος πλήθος εισόδων ή διαίρεση με το μηδέν. Οι εξαρτήσεις της πρέπει να υπάρχουν ήδη όταν προστίθεται το cell υπολογισμού. Και το `add_compute` και το `set_value` αναφέρουν σφάλματα υπολογισμού ως `ComputeFailed({ cell_id, message })`. Αν ένας υπολογισμός αποτύχει κατά τη διάρκεια μιας ενημέρωσης, δεν επιστρέφεται κανένας ενημερωμένος reactor και δεν εκτελείται κανένα callback. Ο αρχικός reactor παραμένει λειτουργικός.

Τα callback είναι καθαρές συναρτήσεις με τύπο `React.CellValue, React.CallbackLog -> React.CallbackLog`. Κάθε callback δέχεται τη νέα τιμή του cell και το τρέχον log και έπειτα επιστρέφει ένα ενημερωμένο log. Το `set_value` δέχεται μια καταγραφή που περιέχει `cell_id`, `value` και το αρχικό `log`, και επιστρέφει και τον ενημερωμένο reactor και το τελικό log. Πέρασε το log που επιστρέφει κάθε callback στο επόμενο callback. Η σειρά των callback δεν καθορίζεται.

Το `React.CallbackLog` είναι ψευδώνυμο για το `Dict(Str, List(I64))`: καταγράφει τις τιμές που δέχεται κάθε αναγνωριστικό callback. Τα tests περνούν ένα κενό log σε κάθε ενημέρωση εισόδου για να ελέγξουν ότι τα callback εκτελέστηκαν ακριβώς μία φορά ή δεν εκτελέστηκαν καθόλου.

Η καταχώριση ενός callback δεν το καλεί. Η αφαίρεση του ίδιου callback περισσότερες από μία φορές επιτρέπεται και δεν πρέπει να επηρεάζει άλλα callback. Όλα τα callback για μια ενημέρωση πρέπει να βλέπουν τις τελικές, σταθερές τιμές των cell.

## Υποδείξεις

<details>
<summary>Δείξε τις υποδείξεις</summary>

Μπορείς να αποθηκεύσεις συναρτήσεις σε καταγραφές μαζί με τα αναγνωριστικά cell ή callback τους. Για να καλέσεις μια συνάρτηση που είναι αποθηκευμένη σε ένα πεδίο καταγραφής, χρησιμοποίησε παρενθέσεις, όπως στο `(cell.compute)(values)` ή στο `(registration.callback)(value, log)`. Χωρίς αυτές τις παρενθέσεις, η Roc αντιμετωπίζει την κλήση ως μέθοδο στον τύπο της καταγραφής. Τα `List.map_try` και `List.fold_try` μπορούν να σε βοηθήσουν να εκτελέσεις διαδοχικά υπολογισμούς που μπορεί να αποτύχουν.

</details>
