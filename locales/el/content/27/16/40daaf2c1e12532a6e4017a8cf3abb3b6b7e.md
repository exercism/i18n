# Σχετικά

## Εισαγωγή

Οι γενικεύσεις είναι ένα χαρακτηριστικό της γλώσσας που επιτρέπει την επαναχρησιμοποίηση κώδικα.
Για παράδειγμα, δεν θα έπρεπε να έχει σημασία τι τύπο περιέχει μια λίστα για να υπολογίσουμε το μήκος της.
Γι' αυτό η συνάρτηση `length` χρησιμοποιεί μια γενικευμένη παράμετρο τύπου `a` στην υπογραφή τύπου της.

```elm
length : List a -> Int
```

## Παράμετροι σε τύπους

Όταν ένας τύπος είναι γενικευμένος ως προς έναν άλλο τύπο, χρησιμοποιούμε ένα πεζό όνομα για αυτόν τον άλλο τύπο και το ονομάζουμε παράμετρο τύπου.
Συνήθη παραδείγματα είναι οι προσαρμοσμένοι τύποι `List`, `Maybe` και `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Μια σημαντική παρατήρηση για τα ονόματα των παραμέτρων τύπου είναι ότι μπορούν να έχουν μήκος πολλών χαρακτήρων.
Ο μόνος περιορισμός είναι να είναι πεζά ονόματα.
Έτσι, όταν είναι χρήσιμο, συνηθίζουμε να τους δίνουμε περιγραφικά ονόματα.

Ένας τύπος μπορεί να είναι γενικευμένος ως προς πολλούς άλλους τύπους και επομένως να έχει πολλαπλές παραμέτρους τύπου.
Σε αυτήν την περίπτωση, κάθε ανεξάρτητος τύπος παίρνει ένα διαφορετικό πεζό όνομα.
Το ότι είναι ανεξάρτητοι δεν τους εμποδίζει να γίνουν ο ίδιος τύπος, απλώς τους επιτρέπει να είναι διαφορετικοί.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Τα ψευδώνυμα τύπων εγγραφής μπορούν επίσης να έχουν παραμέτρους τύπου, αν και είναι λιγότερο συνηθισμένο.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## Παράμετροι τύπου σε συναρτήσεις

Εφόσον οι τύποι μπορούν να είναι γενικευμένοι, το ίδιο μπορούν και οι συναρτήσεις.
Μπορούμε να γράψουμε συναρτήσεις που χειρίζονται γενικευμένους τύπους, όπως η `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Οι συναρτήσεις που παίρνουν άλλες συναρτήσεις ως παραμέτρους ονομάζονται συναρτήσεις ανώτερης τάξης και μπορούν κι αυτές να είναι γενικευμένες.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
