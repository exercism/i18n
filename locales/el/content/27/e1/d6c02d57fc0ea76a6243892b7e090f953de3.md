# Εισαγωγή

Ένα `string` στη F# είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.) και ορίζεται ως εξής:

```fsharp
let fruit = "Apple"
```

Οι συμβολοσειρές χειρίζονται είτε καλώντας τις μεθόδους τους είτε χρησιμοποιώντας τις συναρτήσεις του module `String`. Μόλις κατασκευαστεί μια συμβολοσειρά, η τιμή της δεν μπορεί να αλλάξει ποτέ. Οποιεσδήποτε μέθοδοι ή συναρτήσεις φαίνεται να τροποποιούν μια συμβολοσειρά, στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.

Οι συμβολοσειρές μπορούν να συνενωθούν ή να μορφοποιηθούν με μερικούς διαφορετικούς τρόπους.
* Μπορείς να χρησιμοποιήσεις τον τελεστή `+` για συνένωση:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Μπορείς να χρησιμοποιήσεις τη συνάρτηση `sprintf` για μορφοποίηση κειμένου, όπου έχεις placeholders σε ένα κείμενο μορφοποίησης (`%s` για ένα `string`) και δίνεις τις τιμές ως ορίσματα:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
