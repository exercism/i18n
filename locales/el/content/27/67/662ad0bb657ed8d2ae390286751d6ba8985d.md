# Εισαγωγή

Η ικανότητα κάτι να ορίζεται με βάση τον εαυτό του ονομάζεται αναδρομή. Στη F#, η αναδρομή συναντάται πιο συχνά σε αναδρομικές συναρτήσεις, δηλαδή σε συναρτήσεις που καλούν τον εαυτό τους.

Μια αναδρομική συνάρτηση χρειάζεται να έχει τουλάχιστον μία _βασική περίπτωση_ και τουλάχιστον μία _αναδρομική περίπτωση_. Μια _βασική περίπτωση_ επιστρέφει μια τιμή χωρίς να καλέσει ξανά τη συνάρτηση. Μια _αναδρομική περίπτωση_ καλεί ξανά τη συνάρτηση, τροποποιώντας την είσοδο ώστε κάποια στιγμή να ταιριάξει με τη βασική περίπτωση.

Οι αναδρομικές συναρτήσεις ορίζονται όπως οι κανονικές συναρτήσεις, αλλά με τον τροποποιητή `rec`. Χωρίς αυτόν τον τροποποιητή, μια συνάρτηση _δεν_ θα μπορεί να καλέσει τον εαυτό της και κάθε απόπειρα να το κάνει θα έχει ως αποτέλεσμα ένα σφάλμα μεταγλώττισης. Πρέπει, δηλαδή, να επιλέξεις ρητά την αναδρομή.

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

Η F# υποστηρίζει επίσης αναδρομικούς τύπους μέσω τύπων διακριτών ενώσεων. Σε έναν αναδρομικό τύπο διακριτής ένωσης, μία ή περισσότερες από τις περιπτώσεις του αναφέρονται στα δεδομένα τους στον ίδιο τον τύπο της διακριτής ένωσης. Όπως οι αναδρομικές συναρτήσεις, έτσι και οι αναδρομικοί τύποι πρέπει να έχουν μια βασική περίπτωση. Σε αντίθεση με τις αναδρομικές συναρτήσεις, οι αναδρομικοί τύποι δεν χρησιμοποιούν τη λέξη-κλειδί `rec`.

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
