# Εισαγωγή

Τα Map στην Elixir είναι η δομή δεδομένων για την αποθήκευση πληροφοριών σε ζεύγη κλειδιού-τιμής. Σε άλλες γλώσσες, μπορεί να τα συναντήσεις και ως συσχετιστικούς πίνακες (PHP), hashes (Perl 5, Raku) ή λεξικά (Python).

Τα κλειδιά και οι τιμές μπορούν να είναι οποιουδήποτε τύπου δεδομένων, αλλά αν το κλειδί είναι άτομο, μπορείς να χρησιμοποιήσεις μια συντομευμένη σύνταξη. Τα Map δεν εγγυώνται τη σειρά των καταχωρίσεών τους κατά την προσπέλαση ή την επιστροφή.

## Μορφές literal

Ένα κενό Map δηλώνεται απλώς με `%{}`. Αν θέλεις να προσθέσεις στοιχεία σε ένα literal Map, μπορείς να χρησιμοποιήσεις δύο μορφές:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Παρόλο που δεν υπάρχει κανονική μορφή, διάλεξε έναν συνεπή τρόπο για να γράφεις τα ζεύγη κλειδιού-τιμής ως literal.

## Συναρτήσεις του αρθρώματος Map

Η Elixir παρέχει πολλές συναρτήσεις για να δουλεύεις με Map στο _άρθρωμα Map_. Κάποιες συναρτήσεις του _αρθρώματος Map_ απαιτούν να περάσεις μια _ανώνυμη_ συνάρτηση στη συνάρτηση, για να βοηθήσει στον μετασχηματισμό του Map.
