# Εισαγωγή

Υπάρχουν βασικά δύο τύποι βρόχων:

1. Επανάληψη μέχρι να ικανοποιηθεί μια συνθήκη.
2. Επανάληψη πάνω στα στοιχεία μιας συλλογής.

Και οι δύο είναι δυνατοί στη Julia, αν και ο δεύτερος μπορεί να είναι πιο συνηθισμένος.

## Ο βρόχος `while`

Για προβλήματα ανοιχτού τύπου, όπου ο αριθμός των φορών που θα επαναληφθεί ο βρόχος είναι άγνωστος εκ των προτέρων, η Julia έχει τον βρόχο `while`.

Η βασική μορφή είναι αρκετά απλή:

```julia
while condition
    do_something()
end
```

Σε αυτή την περίπτωση, το πρόγραμμα θα συνεχίζει να εκτελεί τον βρόχο μέχρι η `condition` να μην είναι πια `true`.

Υπάρχουν δύο τρόποι για να βγεις νωρίς από τον βρόχο:

- Ένα `break` προκαλεί την έξοδο από τον βρόχο, με την εκτέλεση να συνεχίζεται στην επόμενη γραμμή μετά το `end` του βρόχου.
- Ένα `return x` σταματά την εκτέλεση της τρέχουσας συνάρτησης, περνώντας την τιμή επιστροφής `x` πίσω σε αυτόν που κάλεσε τη συνάρτηση.

Με αυτές τις επιλογές διαθέσιμες, μερικές φορές μπορεί να είναι βολικό να δημιουργήσεις έναν "άπειρο" βρόχο με `while true ... end` και μετά να βασιστείς στο να βρεις μια συνθήκη τερματισμού μέσα στο σώμα του βρόχου για να προκαλέσεις ένα `break` ή `return`.

## Επανάληψη πάνω σε μια συλλογή

Η πιο απλή απεικόνιση είναι η επανάληψη πάνω σε ένα εύρος.

Αν θέλουμε να κάνουμε κάτι 10 φορές:

```julia
for n in 1:10
    do_something(n)
end
```

Αν η τρέχουσα επανάληψη δεν ικανοποιεί κάποια συνθήκη, μπορείς να προσπεράσεις αμέσως στην επόμενη επανάληψη με ένα `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Σε πιο σύντομη μορφή, το μπλοκ `if` θα μπορούσε να αντικατασταθεί από `is_useless(n) && continue`.

Μπορείς να κάνεις επανάληψη και πάνω σε πολλούς άλλους τύπους συλλογών: στοιχεία σε έναν πίνακα, χαρακτήρες σε μια συμβολοσειρά, κλειδιά σε ένα λεξικό...

Τα παραδείγματα μέχρι στιγμής κάνουν επανάληψη πάνω στο εύρος `1:10`, όπου η τιμή είναι επίσης η θέση στον βρόχο.

Γενικότερα, μπορεί να χρειάζεται η θέση και όχι μόνο η τιμή.
Για αυτό χρησιμοποιείται η συνάρτηση `eachindex()`, για παράδειγμα `for i in eachindex(my_array) ... end`.

## Κατανοήσεις

Το να γράφεις ρητούς βρόχους τείνει να είναι λιγότερο συνηθισμένο στη Julia από ό,τι σε πολλές παραδοσιακές γλώσσες, επειδή υπάρχουν διάφορες πιο συνοπτικές επιλογές.

Μια ιδιαίτερα συνηθισμένη περίπτωση είναι όταν χρειάζεται να δημιουργήσουμε ένα νέο διάνυσμα από τα στοιχεία κάποιας άλλης συλλογής (διάνυσμα, συμβολοσειρά, σύνολο ... υπάρχουν πολλές δυνατότητες).

Όποιος αγαπά τις κατανοήσεις λιστών στην Python θα χαρεί να μάθει ότι η Julia μπορεί να χρησιμοποιήσει παρόμοια σύνταξη.

Η ουσία αυτού είναι να στήσεις έναν πολύ συμπαγή βρόχο μέσα σε ένα διάνυσμα.

Η πιο απλή σύνταξη έχει τη μορφή `result = [f(x) for x in some_collection]`.

Με έναν παραδοσιακό βρόχο, αυτό θα μπορούσε να γραφτεί:

```julia
result = []
for x in some_collection
    push!(result, f(x))
end
```

Προαιρετικά, μπορεί να προστεθεί μια συνθήκη στο τέλος, για να επιλεγούν μόνο τα στοιχεία της συλλογής που ταιριάζουν:

```julia-repl
# multiples of 3
julia> [n^2 for n in 1:10 if n%3 == 0]
3-element Vector{Int64}:
  9
 36
 81
```
