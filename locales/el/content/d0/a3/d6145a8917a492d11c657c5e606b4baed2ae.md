# Ειδικές οδηγίες για SQLite

Αυτή η άσκηση απαιτεί να ορίσεις τη στήλη `result` του πίνακα `etl` στη σωστή τιμή, με βάση το αντικείμενο JSON που βρίσκεται στη στήλη `input`. Τα κλειδιά στο αντικείμενο αποτελέσματος πρέπει να είναι ταξινομημένα αλφαβητικά.

## Σχήμα πίνακα

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
