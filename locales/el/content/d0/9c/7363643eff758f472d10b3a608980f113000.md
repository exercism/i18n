# Οδηγίες

Η γνωστή σου Erin πρέπει να τυπώσει χιλιάδες φυλλάδια για πολλές εκδηλώσεις και χρειάζεται τη βοήθειά σου! Σου ζήτησε να δημιουργήσεις τη διάταξη ενός φυλλαδίου που περιέχει μια κεφαλίδα, μια προαιρετική ημερομηνία και μια λίστα με καλλιτέχνες, τον καθένα συνδεδεμένο με ένα _εικονίδιο unicode_. Ο στόχος είναι να κάνεις `print` και να μοιράσεις το νέο σου, ωραίο σχέδιο φυλλαδίου, και θα χρειαστείς όλες τις δεξιότητες μορφοποίησης συμβολοσειρών στην Python για να τα καταφέρεις.

## 1. Δημιούργησε την κλάση με κεφαλαιοποιημένη κεφαλίδα

Η συνάρτηση `capitalize_header` θα πρέπει να δέχεται το όνομα μιας εκδήλωσης και να επιστρέφει την εκδοχή του ονόματος της εκδήλωσης με κεφαλαίο το πρώτο γράμμα.

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. Διαμόρφωσε την ημερομηνία

Δημιούργησε μια νέα μέθοδο `format_date` που δέχεται μια λίστα η οποία περιέχει μια μέρα, έναν μήνα και ένα έτος. Εμφανίζει τη μορφοποιημένη ημερομηνία με τη μορφή `<month_name> <date>, <year>`

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. Απόδωσε τα σημεία κώδικα unicode ως εικονίδια

Όταν καλείται η μέθοδος `display_icons`, η λίστα με τα σημεία κώδικα unicode που περνάς θα πρέπει να αποδοθεί και να επιστραφεί ως `list` με _εικονίδια_.

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. Εμφάνισε το έτοιμο φυλλάδιο

Τώρα θα χρησιμοποιήσεις όλες τις παραπάνω συναρτήσεις και θα τις συνδυάσεις στη συνάρτηση `print_leaflet`.
Θα πρέπει να δέχεται ένα `event_name`, μια λίστα με `icons`, μια λίστα με `authors` και μια λίστα `event_date`.

Η αφίσα θα πρέπει να ακολουθεί την παρακάτω διάταξη.

Το φυλλάδιο ακολουθεί μια συγκεκριμένη διάταξη σε σχήμα ορθογωνίου:

- Η πρώτη και η τελευταία σειρά περιέχουν 20 αστερίσκους. `"*"`
- Κάθε τμήμα χωρίζεται από μια κενή σειρά πάνω και κάτω από αυτό.
- Μια κενή σειρά περιέχει μόνο έναν αστερίσκο στην αρχή και έναν στο τέλος.
- Το πρώτο τμήμα είναι η κεφαλίδα του φυλλαδίου, αυτός ο τίτλος γράφεται με κεφαλαίο το πρώτο γράμμα.
- Το δεύτερο τμήμα είναι η προαιρετική ημερομηνία, αν δεν περαστεί ημερομηνία, αυτό το τμήμα θα πρέπει να είναι μια κενή σειρά.
- Το τρίτο και τελευταίο τμήμα είναι η λίστα με τους καλλιτέχνες, όπου κάθε καλλιτέχνης συνδέεται με το αντίστοιχο εικονίδιο.

```python
********************
*                  *
*    'Concert'     *
*                  *
*  June 22, 2020   *
*                  *
* John         🎸  *
* Benjamin     🎤  *
* Max          🎹  *
*                  *
********************
```
