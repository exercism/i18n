# Υποδείξεις

## Γενικά

- Πρέπει να χρησιμοποιήσεις διαφορετικές μορφές [ροής ελέγχου][control-flow] για να λύσεις αυτή την άσκηση.

## 1. Έλεγξε την κρισιμότητα

- Πρέπει να χρησιμοποιήσεις εντολές [if][if] ή [unless][unless] για να λύσεις αυτή την άσκηση.
- Πρέπει να χρησιμοποιήσεις [τελεστές σύγκρισης][equality-and-comparison] για να λύσεις αυτή την άσκηση.
- Για να συνδυάσεις πολλαπλές συνθήκες, μπορείς να χρησιμοποιήσεις [`&&`][and] και [`||`][or].

## 2. Προσδιόρισε το εύρος ισχύος εξόδου

- Μπορείς να δημιουργήσεις πολλαπλές διακλαδώσεις χρησιμοποιώντας `if` και `elsif`.

## 3. Μηχανισμός ασφαλείας

- Μπορείς να χρησιμοποιήσεις `if` και `elsif` για να δημιουργήσεις πολλαπλές διακλαδώσεις.
