# Tests

Για να τρέξεις τα tests, τρέξε την εντολή `go test` μέσα από τον φάκελο της άσκησης.

Αν η σουίτα tests περιέχει benchmarks, μπορείς να τα τρέξεις με τις επιλογές `--bench` και `--benchmem`:

    go test -v --bench . --benchmem

Έχε υπόψη σου ότι κάθε κριτής θα τρέξει τα benchmarks σε διαφορετικό μηχάνημα, με διαφορετικές προδιαγραφές, οπότε τα αποτελέσματα από αυτά τα benchmarks μπορεί να διαφέρουν.
