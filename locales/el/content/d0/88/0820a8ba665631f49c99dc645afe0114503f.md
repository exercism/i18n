# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις έναν freelancer να επικοινωνεί με έναν διαχειριστή έργου, παρέχοντας μερικά βοηθητικά εργαλεία για τον γρήγορο υπολογισμό ημερήσιων και μηνιαίων χρεώσεων, προαιρετικά με μια δεδομένη έκπτωση.

Αρχικά ορίζουμε μερικούς κανόνες ανάμεσα στον freelancer και τον διαχειριστή έργου:

Η ημερήσια χρέωση είναι 8 φορές την ωριαία χρέωση.
Ένας μήνας έχει 22 χρεώσιμες ημέρες.
Ο freelancer προσφέρεται να εφαρμόσει έκπτωση αν ο διαχειριστής έργου επιλέξει να τον αφήσει να χρεώνει ανά μήνα, κάτι που μπορεί να φανεί χρήσιμο αν υπάρχει ένας συγκεκριμένος προϋπολογισμός με τον οποίο πρέπει να δουλέψει ο διαχειριστής έργου.

Οι εκπτώσεις αναπαρίστανται ως δεκαδικοί αριθμοί που δηλώνουν ποσοστό, για παράδειγμα 25.0 (25%).

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

Υλοποίησε μια συνάρτηση που να υπολογίζει την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι float.

## 2. Υπολόγισε μια τιμή με έκπτωση

Υλοποίησε μια συνάρτηση που να υπολογίζει την τιμή μετά από μια έκπτωση.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

Η τιμή που επιστρέφεται πρέπει να είναι πάντα float, χωρίς καμία στρογγυλοποίηση.

## 3. Υπολόγισε τη μηνιαία χρέωση, με δεδομένες την ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση που να υπολογίζει τη μηνιαία χρέωση και να εφαρμόζει μια έκπτωση:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

Η μηνιαία χρέωση που επιστρέφεται πρέπει να στρογγυλοποιηθεί προς τα πάνω, στον πλησιέστερο ακέραιο (δηλαδή να πάρεις το ανώτατο όριο).

## 4. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένα έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση που παίρνει έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση, και υπολογίζει πόσες ημέρες εργασίας καλύπτονται.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

Ο αριθμός των ημερών που επιστρέφεται πρέπει να στρογγυλοποιηθεί προς τα κάτω, σε ένα δεκαδικό ψηφίο (δηλαδή να πάρεις το κατώτατο όριο).
