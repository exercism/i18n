# Συμβουλές

## Γενικά

- Η οικογένεια εντολών `cmovcc` δεν δέχεται άμεσες τιμές.
  Πρέπει να φορτώσεις οποιονδήποτε σταθερό αριθμό σε έναν καταχωρητή πριν τις χρησιμοποιήσεις.
- Η οικογένεια εντολών `setcc` λειτουργεί μόνο με τελεστέους 8 bit.
  Συχνά είναι απαραίτητο να τους επεκτείνεις με πρόσημο ή με μηδενικά αφού ορίσεις την κατάλληλη τιμή.

## 1. Πρόσθεσε μπόνους χωρίς να ξεχειλίσει η οθόνη

- Η ανώτατη τιμή είναι `999999`.
  Κάθε άθροισμα μεγαλύτερο από αυτή γίνεται `999999`.
- Μια σύγκριση που ακολουθείται από μια εντολή `cmovcc` μπορεί να αντικαταστήσει μια τιμή με μια άλλη όταν ισχύει μια συνθήκη.
- Η οικογένεια εντολών `cmovcc` δεν δέχεται άμεσες τιμές.
  Πρέπει να φορτώσεις οποιονδήποτε σταθερό αριθμό σε έναν καταχωρητή πριν τις χρησιμοποιήσεις.

## 2. Σύγκρινε δύο σκορ

- Μια μόνο σύγκριση μπορεί να ακολουθηθεί από περισσότερες από μία εντολές `setcc` ή `cmovcc`, ώστε να οριστούν ή να μετακινηθούν πολλαπλές τιμές, ανάλογα με τις ίδιες ή διαφορετικές σημαίες.
- Η οικογένεια εντολών `setcc` λειτουργεί μόνο με τελεστέους 8 bit.
- Ένας τελεστέος 8 bit με πρόσημο μπορεί να επεκταθεί με πρόσημο στα 64 bit με την εντολή `movsx`.

## 3. Επικύρωσε ένα ακατέργαστο σκορ

- Μια μόνο σύγκριση μπορεί να ακολουθηθεί από περισσότερες από μία εντολές `setcc` ή `cmovcc`, ώστε να οριστούν ή να μετακινηθούν πολλαπλές τιμές, ανάλογα με τις ίδιες ή διαφορετικές σημαίες.
- Το επίθεμα συνθήκης για σύγκριση με πρόσημο είναι `l`, για μικρότερο, και `g`, για μεγαλύτερο.

## 4. Παρακολούθησε τα δύο υψηλότερα σκορ

- Υπάρχουν δύο κορυφαίες τιμές.
  Ένας νέος υποψήφιος πρέπει να συγκρίνεται και με τις δύο.
- Μια μόνο σύγκριση μπορεί να ακολουθηθεί από περισσότερες από μία εντολές `setcc` ή `cmovcc`, ώστε να οριστούν ή να μετακινηθούν πολλαπλές τιμές, ανάλογα με τις ίδιες ή διαφορετικές σημαίες.
- Το επίθεμα συνθήκης για σύγκριση με πρόσημο είναι `l`, για μικρότερο, και `g`, για μεγαλύτερο.
