# Εισαγωγή

Η μεταβλητότητα είναι μια ιδιότητα της δέσμευσης μιας συγκεκριμένης τιμής σε μια μεταβλητή.
Μια μεταβλητή είναι είτε αμετάβλητη είτε μπορεί να μεταβληθεί.
Η τιμή μιας αμετάβλητης μεταβλητής δεν μπορεί να αλλάξει, ενώ η τιμή μιας μεταβλητής που μπορεί να μεταβληθεί αλλάζει.
Όλες οι μεταβλητές είναι αμετάβλητες από προεπιλογή.
