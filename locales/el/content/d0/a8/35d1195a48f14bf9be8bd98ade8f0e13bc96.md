# Tests

Για να τρέξεις τα tests, εκτέλεσε την παρακάτω εντολή:

```bash
make
```

## Tests που παραλείπονται

Το να λύσεις μια άσκηση σημαίνει να περάσουν όλα τα tests της.
Από προεπιλογή, όταν τρέχεις τα tests εκτελείται μόνο ένα test (το πρώτο).
Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει μόνο αυτό το ένα test.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο test αφαιρώντας τη γραμμή `TEST_IGNORE()`.
Όταν ενεργοποιηθούν όλα τα tests και η υλοποίησή σου τα περάσει όλα, θα έχεις λύσει την άσκηση!
