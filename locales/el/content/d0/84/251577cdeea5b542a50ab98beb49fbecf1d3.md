# Σχετικά

## Πολλαπλές τιμές επιστροφής

Στη Swift, οι συναρτήσεις μπορούν να [επιστρέψουν πολλαπλές τιμές][multiple-return-values] επιστρέφοντας μια πλειάδα:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    return (reverse: String(str.reversed()), length: str.count)
}

let result = reverseAndLength("Hello")
print(result.reverse) // Prints "olleH"
print(result.length)  // Prints 5
```

## Παράλειψη της λέξης-κλειδιού `return`

Όταν το σώμα μιας συνάρτησης αποτελείται από μία μόνο έκφραση, μπορείς να [παραλείψεις τη λέξη-κλειδί `return`][implicit-returns]:

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
    (reverse: String(str.reversed()), length: str.count)
}
```

Αυτή η σύνταξη της σιωπηρής επιστροφής ισχύει για όλες τις συναρτήσεις που επιστρέφουν μια τιμή, όχι μόνο για εκείνες που επιστρέφουν πλειάδες.

[multiple-return-values]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID164
[implicit-returns]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID607
