# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                        |
| -------- | --------- | ------- | -------------------------------- |
| `$a0`    | είσοδος   | ακέραιος | αριθμός τετραγώνου στο εύρος 1..64 |
| `$v0`    | έξοδος    | ακέραιος | τα χαμηλά 32 bit της εξόδου      |
| `$v1`    | έξοδος    | ακέραιος | τα υψηλά 32 bit της εξόδου       |
| `$t0-9`  | προσωρινός | οτιδήποτε | για προσωρινή αποθήκευση         |
