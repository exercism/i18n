# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις πάνω σε μια εφαρμογή προγραμματισμού ραντεβού για ένα σαλόνι ομορφιάς στη Νέα Υόρκη που άνοιξε στις 15 Σεπτεμβρίου του 2012.

Έχεις πέντε εργασίες, οι οποίες όλες θα αφορούν ημερομηνίες ραντεβού.
Οι ώρες είναι σε μορφή 24ώρου (χωρίς AM/PM).

## 1. Ανάλυσε την ημερομηνία ραντεβού που αποτελείται μόνο από αριθμούς

Υλοποίησε τη συνάρτηση `schedule_appointment()` ώστε να αναλύει μια κειμενική αναπαράσταση μιας ημερομηνίας ραντεβού και να τη μετατρέπει στην αντίστοιχη μορφή `DateTime`.

Σημείωσε ότι η είσοδος είναι με τη σειρά μήνας/ημέρα/έτος, όπως στις ΗΠΑ.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Έλεγξε αν ένα ραντεβού έχει ήδη περάσει

Υλοποίησε τη συνάρτηση `has_passed()` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού ήταν κάπου στο παρελθόν:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Έλεγξε αν το ραντεβού είναι το απόγευμα

Υλοποίησε τη συνάρτηση `is_afternoon_appointment()` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού είναι το απόγευμα (>= 12:00 και < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Περιέγραψε την ώρα και την ημερομηνία του ραντεβού

Υλοποίησε τη συνάρτηση `description()` που παίρνει μια ημερομηνία ραντεβού και επιστρέφει μια περιγραφή αυτής της ημερομηνίας και ώρας:

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. Επίστρεψε την ημερομηνία επετείου

Υλοποίησε τη συνάρτηση `anniversary_date()` που επιστρέφει την ημερομηνία επετείου του φετινού έτους, που είναι η 15η Σεπτεμβρίου:

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
