# Σχετικά

Οι αρχικοποιητές αντικειμένων είναι μια εναλλακτική λύση αντί για τους κατασκευαστές. Η σύνταξη είναι μια λίστα από ζεύγη όνομα πεδίου=τιμή, χωρισμένα με κόμμα, όπως φαίνεται παρακάτω:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Με τον ίδιο τρόπο μπορούν να αρχικοποιηθούν και οι συλλογές. Συνήθως αυτό γίνεται με λίστες χωρισμένες με κόμμα, όπως φαίνεται εδώ:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Αυτή η προσέγγιση (και η σύνταξη) μπορεί να χρησιμοποιηθεί με οποιαδήποτε κλάση υλοποιεί το `IEnumerable` και έχει μια μέθοδο `Add()`.

Τα πεδία μπορούν να παρατεθούν με οποιαδήποτε σειρά ή να παραλειφθούν εντελώς.

Τα λεξικά χρησιμοποιούν την παρακάτω σύνταξη:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Τα πεδία που αρχικοποιούνται πρέπει να είναι προσβάσιμα από αυτόν που καλεί. Συνήθως αυτό σημαίνει ότι πρέπει να είναι `public` ή `internal`.

Υπάρχει μια ισχυρή τάση που προωθεί την αμεταβλητότητα μεταξύ των σχεδιαστών της γλώσσας και των κορυφαίων επαγγελματιών, οπότε η μεταβλητότητα των αντικειμένων που αρχικοποιούνται με αυτόν τον τρόπο θεωρείται μειονέκτημα. Υπάρχουν προτάσεις να εισαχθεί μια ρήτρα `init` στην επερχόμενη έκδοση της γλώσσας, τη C# 9, που ίσως αντιμετωπίσει αυτό το ζήτημα.

- Η [τεκμηρίωση των αρχικοποιητών αντικειμένων][object-initializers] περιγράφει πώς να χρησιμοποιείς τους αρχικοποιητές.
- Η [τεκμηρίωση των αρχικοποιητών συλλογών][collection-initializers] δίνει μια πρώτη εικόνα για το πώς μπορούν να χρησιμοποιηθούν οι αρχικοποιητές με συλλογές όπως τα λεξικά και οι λίστες.
