# Προσθήκη στις οδηγίες

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να υλοποιήσεις τη συνάρτηση `score`,
που δέχεται μια ακολουθία από *ρίψεις* μπόουλινγκ και επιστρέφει το τελικό σκορ ή
το κατάλληλο σφάλμα:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Θα βρεις αυτούς τους ορισμούς ήδη στη θέση τους, αλλά από εσένα εξαρτάται
να ορίσεις τη συνάρτηση.

Να θυμάσαι ότι η σουίτα δοκιμών περιμένει οι ρίψεις να είναι αριθμημένες
ξεκινώντας από το μηδέν.
