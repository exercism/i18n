# Εισαγωγή

Σε μια καθαρά συναρτησιακή γλώσσα όπως η Elm, μια συνάρτηση που καλείται με τα ίδια ορίσματα πρέπει να επιστρέφει πάντα την ίδια τιμή.
Επομένως, μια συνάρτηση με υπογραφή τύπου `rand : Int` μπορεί να υλοποιηθεί μόνο ως `rand = 4`, κάτι που δεν προμηνύει τίποτα καλό για την παραγωγή τυχαίων ακεραίων.

Πώς λοιπόν παράγουμε τυχαίες τιμές στην Elm;
Χωρίζουμε το πρόβλημα στα δύο: πρώτα περιγράφουμε την τιμή που θέλουμε να παράγουμε με ένα `Random.Generator a` και μετά παράγουμε μια τιμή.

Ο πρώτος τρόπος για να παράγεις μια τιμή είναι να δημιουργήσεις ένα `Random.Seed` μέσω του `initialSeed : Int -> Seed` και έπειτα να χρησιμοποιήσεις το `step : Generator a -> Seed -> ( a, Seed )`, το οποίο επιστρέφει μια τιμή και ένα νέο seed.
Σημείωσε ότι και οι δύο αυτές συναρτήσεις είναι καθαρές, οπότε καλώντας τες δύο φορές με τα ίδια ορίσματα θα παραχθούν οι ίδιες τιμές.

Ο δεύτερος τρόπος για να παράγεις μια τιμή είναι να χρησιμοποιήσεις το `generate : (a -> msg) -> Generator a -> Cmd msg`, αλλά αυτό μπορεί να γίνει μόνο μέσα σε μια εφαρμογή Elm.
Σε αυτή την περίπτωση, το περιβάλλον εκτέλεσης της Elm μπορεί να χρησιμοποιήσει το `step` καθώς και εξωτερικούς, μη καθαρούς πόρους για να παράγει seeds.

Από εδώ και πέρα, θα επικεντρωθούμε στις γεννήτριες.

Ας υποθέσουμε, για χάρη των παραδειγμάτων, ότι έχουμε ορίσει, με τα `initialSeed` και `step`, μια συνάρτηση `generate : Int -> Generator a -> List a` που παράγει έναν αριθμό τιμών από μια γεννήτρια.

Το άρθρωμα `Random` παρέχει δύο βασικές γεννήτριες για την παραγωγή ακεραίων και αριθμών κινητής υποδιαστολής μέσα σε ένα συγκεκριμένο εύρος:

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

Αυτές οι τιμές μπορούν να συνδυαστούν σε πλειάδες ή σε λίστες τιμών:

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

Το πακέτο `elm-community/random-extra` παρέχει πολλές περισσότερες γεννήτριες για διάφορες δομές δεδομένων: συμβολοσειρές, ημερομηνίες, λεξικά, πίνακες, σύνολα κ.λπ.

Μπορούμε να δημιουργήσουμε γεννήτριες που επιστρέφουν μόνο μία τιμή χρησιμοποιώντας το `Random.constant`:

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

Μπορούμε να διαλέξουμε τυχαία από τα δεδομένα στοιχεία με ίση πιθανότητα χρησιμοποιώντας το `Random.uniform`:

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

Το `Random.uniform` παίρνει δύο ορίσματα (`Red` και `[Green, Blue]`) για να εγγυηθεί ότι υπάρχει τουλάχιστον μία τιμή για να διαλέξεις, αφού μια μεμονωμένη λίστα θα μπορούσε να είναι κενή.

Μπορούμε επίσης να ρυθμίσουμε τις πιθανότητες χρησιμοποιώντας το `Random.weighted`:

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

Οι τιμές δε χρειάζεται να αθροίζουν στο 100, θα επανακανονικοποιηθούν έτσι κι αλλιώς.

Μπορούμε να φτάσουμε στο εσωτερικό μιας γεννήτριας με το `Random.map`:

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

Μπορούμε επίσης να χρησιμοποιήσουμε το `Random.map2` μέχρι και το `Random.map5` για να συνδυάσουμε περισσότερες γεννήτριες:

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

Για πιο σύνθετες χρήσεις, έχουμε το `Random.andThen : (a -> Generator b) -> Generator a -> Generator b` που μπορεί να χρησιμοποιήσει την τιμή που παρήγαγε μια γεννήτρια για να δημιουργήσει μια άλλη:

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

Είναι μερικές φορές χρήσιμο να ορίσεις μια γεννήτρια με αναδρομή στον εαυτό της.
Σε αυτές τις περιπτώσεις, μπορεί να χρειαστεί να χρησιμοποιήσεις το `Random.lazy` για να εμποδίσεις τον μεταγλωττιστή να ξεδιπλώσει τη γεννήτρια άπειρα.

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

Αυτό το παράδειγμα είναι λίγο βαρύ, οπότε ας το αναλύσουμε.

Το `Peano` είναι ένας τύπος που αναπαριστά θετικούς ακεραίους: το `Zero` είναι 0, το `Next(Zero)` είναι 1, το `Next(Next(Zero))` είναι 2 κ.ο.κ.
Ορίζουμε το `peano` για να μας δίνει έναν τυχαίο αριθμό `Peano`.

Πρώτα απ' όλα, σημείωσε ότι το `Random.lazy` δεν προσθέτει τίποτα στη λογική, απλώς εμποδίζει τον μεταγλωττιστή να γράψει το `peano` μέσα στο `peano` επ' άπειρον.

Χρησιμοποιούμε το `Random.uniform` για να διαλέξουμε ανάμεσα στο μηδέν (με πιθανότητα 50%) και σε έναν άλλον αριθμό `Peano` συν ένα (με πιθανότητα 50%).
Ωστόσο, σε αντίθεση με το προηγούμενο παράδειγμα, το `Random.uniform` δε διαλέγει από τιμές (όπως το `Zero`) αλλά από γεννήτριες (όπως το `Random.constant Zero`), αφού θέλουμε να χρησιμοποιήσουμε το ίδιο το `peano`.
Αυτό σημαίνει ότι το `Random.uniform` θα επιστρέψει μια τιμή τύπου `Generator (Generator Peano)`, που δεν είναι αυτό που χρειαζόμαστε.

Για να "ισιώσουμε" τη γεννήτρια, τη διοχετεύουμε στο `Random.andThen : (a -> Generator b) -> Generator a -> Generator b`, όπου θέλουμε το `b` να είναι `Peano`.
Αφού το `Generator a` είναι `Generator (Generator Peano)`, το `a` πρέπει να είναι `Generator Peano`, και η συνάρτηση `(a -> Generator b)` πρέπει να έχει τύπο `(Generator Peano -> Generator Peano)`.
Δε θέλουμε να τροποποιήσουμε τίποτα, οπότε το `identity` είναι η σωστή επιλογή.

Τέλος, τι λογής αριθμούς θα παράγει το `peano`;
Ξέρουμε ότι θα παράγει 0 το 50% των φορών ή μια ακόμη επανάληψη του εαυτού του συν ένα το 50% των φορών.
Αυτό σημαίνει ότι οι αριθμοί θα είναι 0 (το 50% των φορών), 1 (το 25% των φορών), 2 (το 12% των φορών), 3 (το 6% των φορών) κ.ο.κ.
Το `peano` μπορεί να παράγει αυθαίρετα μεγάλους αριθμούς, αλλά με εκθετικά φθίνουσα πιθανότητα.
