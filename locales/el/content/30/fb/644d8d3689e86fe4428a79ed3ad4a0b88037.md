# Δοκιμές

Μπορείς να τρέξεις τις δοκιμές που παρέχονται μέσω του DrRacket ή μέσω της γραμμής εντολών.

Για να τρέξεις τη δοκιμή μέσω του DrRacket, απλώς άνοιξε το αρχείο δοκιμών και πάτησε το κουμπί 'Run' πάνω δεξιά.

Για να τρέξεις τη δοκιμή από τη γραμμή εντολών, απλώς τρέξε τη δοκιμή από τον κατάλογο της άσκησης. Για παράδειγμα, αν η σουίτα δοκιμών ονομάζεται `hello-world-test.rkt`, μπορείς να τρέξεις την ακόλουθη εντολή:

```
raco test hello-world-test.rkt
```

που θα εμφανίσει το εξής:

```
raco test: (submod "hello-world-test.rkt" test)
2 success(es) 0 failure(s) 0 error(s) 2 test(s) run
0
2 tests passed
```
