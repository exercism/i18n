# Προσθήκη στις οδηγίες

## Χειρισμός σφαλμάτων

Αυτή η άσκηση παρουσιάζει το crate `anyhow`, το οποίο κάνει εύκολο τον χειρισμό αυθαίρετων τύπων σφαλμάτων.
Ο σκοπός του είναι να διασφαλίσει ότι όταν γράφεις μια εφαρμογή, δεν χρειάζεται να ανησυχείς για το ποια
συγκεκριμένα σφάλματα επιστρέφει η συνάρτηση που καλείς, αλλά να κάνεις απλώς το σωστό όταν τα προωθείς.

Σημείωση: είναι στην πραγματικότητα κάπως κακή πρακτική να χρησιμοποιείς το `anyhow` όταν γράφεις μια βιβλιοθήκη, όπως κάνουμε εδώ· είναι πιο
ρητό και πιο χρήσιμο να γράψεις το δικό σου `Error` enum όταν γράφεις μια βιβλιοθήκη (ενδεχομένως με τη βοήθεια βοηθητικών
macros σαν αυτά που παρέχει το [`thiserror` crate](https://crates.io/crates/thiserror)). Ωστόσο, το κάνουμε
σκόπιμα και ρητά εδώ για να δείξουμε τη χρήση αυτού του crate.

Για να μάθεις περισσότερα για αυτό το crate, δες την [τεκμηρίωσή του](https://docs.rs/anyhow/1.0.32/anyhow/).

## Περαιτέρω ανάγνωση

Ενώ αυτή η άσκηση σου ζητά να υλοποιήσεις μόνο τις πιο βασικές συναρτήσεις του `grep`,
υπάρχει στην πραγματικότητα ένα project για την πλήρη επανυλοποίηση του `grep` σε Rust, το [ripgrep](https://github.com/BurntSushi/ripgrep).

Αν σου άρεσε η ιδέα να ξαναγράψεις τα βασικά βοηθητικά προγράμματα σε Rust, ρίξε μια ματιά στα παρακάτω projects:

- [fd](https://github.com/sharkdp/fd) - ένας κλώνος του `find`
- [exa](https://github.com/ogham/exa) - ένας κλώνος του `ls`
- [bat](https://github.com/sharkdp/bat) - ένας κλώνος του `cat`
- [coreutils](https://github.com/uutils/coreutils) - μια επανεγγραφή των GNU coreutils
