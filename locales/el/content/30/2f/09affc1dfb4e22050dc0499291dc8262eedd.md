# Σχετικά

Το `assocs` είναι ένα [πρωτόκολλο][assoc-protocol], όχι ένας μεμονωμένος τύπος δεδομένων. Οι πίνακες κατακερματισμού (`H{ }`), οι λίστες συσχέτισης (ακολουθίες από ζεύγη `{ key value }`) και οι δενδρικοί χάρτες το υλοποιούν όλοι, και οι περισσότερες λέξεις για τα assocs είναι εναλλάξιμες μεταξύ τους.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

Το πλήρες φάσμα είναι ευρύ (ταξινομημένη επανάληψη, χαρτογράφηση, φιλτράρισμα), αλλά η περισσότερη δουλειά σε επίπεδο άσκησης αφορά ένα μικρό σύνολο:

| λέξη        | αποτέλεσμα                                    |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` ξεχωρίζει το f ως τιμή από την απουσία |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`, μεταβάλλει          |
| `change-at` | `( key assoc quot -- )`, το `quot` είναι `( old -- new )` |
| `inc-at`    | `( key assoc -- )`, `+1`, εισάγει `1` αν λείπει |
| `delete-at` | `( key assoc -- )`, μεταβάλλει                |
| `>alist`    | `( assoc -- pairs )`                          |

Τα `sort-keys` και `sort-values` (στη `sorting`) ταξινομούν μια alist με βάση το επιλεγμένο πεδίο.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
