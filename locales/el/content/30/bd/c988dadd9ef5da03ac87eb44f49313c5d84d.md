# Οδηγίες

Ο στόχος σου είναι να φτιάξεις ένα χρονόμετρο που να παρακολουθεί με ακρίβεια τους χρόνους των γύρων.

Το χρονόμετρο χρησιμοποιεί τέσσερις εντολές (start, stop, lap και reset) για να παρακολουθεί:

1. Τον μετρούμενο χρόνο του τρέχοντος γύρου
2. Τους χρόνους των γύρων που έχουν καταγραφεί προηγουμένως

Ποιες εντολές μπορείς να χρησιμοποιήσεις εξαρτάται από την κατάσταση στην οποία βρίσκεται το χρονόμετρο:

1. Ready: αρχική κατάσταση
2. Running: μετράει τον χρόνο
3. Stopped: δεν μετράει τον χρόνο

| Εντολή | Αρχική κατάσταση | Τελική κατάσταση | Αποτέλεσμα                                               |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | Ξεκινάει τη μέτρηση του χρόνου                            |
| Start   | Stopped     | Running   | Συνεχίζει τη μέτρηση του χρόνου                           |
| Stop    | Running     | Stopped   | Σταματάει τη μέτρηση του χρόνου                           |
| Lap     | Running     | Running   | Προσθέτει τον τρέχοντα γύρο στους προηγούμενους γύρους και μετά μηδενίζει τον τρέχοντα γύρο |
| Reset   | Stopped     | Ready     | Μηδενίζει τον τρέχοντα γύρο και διαγράφει τους προηγούμενους γύρους |
