# Εισαγωγή

Στην Clojure, η δέσμευση μιας τιμής σε ένα όνομα ονομάζεται _var_. Οι var κορυφαίου επιπέδου (καθολικές) μοιάζουν με τις σταθερές σε άλλες γλώσσες, αλλά συνήθως ορίζονται ξανά για να διευκολύνουν τη δυναμική ανάπτυξη.

Οι var κορυφαίου επιπέδου ορίζονται με το `def`:

```clojure
(def fingers 10)
```

Μπορείς να χρησιμοποιήσεις τη μακροεντολή `defn` για να ορίσεις μια συνάρτηση που δέχεται μηδέν ή περισσότερα ορίσματα. Μια συνάρτηση επιστρέφει πάντα το αποτέλεσμα της τελευταίας έκφρασης στο σώμα της.

```clojure
(defn add [x y]
  (+ x y))
```

Καλείς μια συνάρτηση γράφοντας το όνομά της και περνώντας ένα όρισμα για κάθε παράμετρό της.

```clojure
(def five (add 2 3))
```

Οι συναρτήσεις και οι τιμές στην Clojure μπορούν να χρησιμοποιηθούν μόνο _αφού_ οριστούν. Αν χρησιμοποιήσεις κάτι πριν οριστεί, θα προκληθεί σφάλμα μεταγλώττισης.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

Στην Clojure, τα κενά δεν έχουν καμία σημασία πέρα από τη μορφοποίηση.

Οι συναρτήσεις και οι var της Clojure οργανώνονται σε namespaces. Ένα namespace ομαδοποιεί σχετική λειτουργικότητα και ορίζεται με τη μακροεντολή `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Η Clojure υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μίας γραμμής ξεκινούν με `;` και η μορφή `comment` χρησιμοποιείται για να αποτρέψει την αξιολόγηση όλων όσων βρίσκονται ανάμεσα στο `(comment` και το `)`.
