# Εισαγωγή

Τα περισσότερα προγράμματα εξαρτώνται από κάποιες βιβλιοθήκες. Το να τις διαχειρίζεσαι με το χέρι μπορεί να γίνει μπελάς. Ευτυχώς, το οικοσύστημα της Rust περιλαμβάνει από προεπιλογή το `cargo`! Το `cargo` μπορεί να διαχειριστεί τις εξαρτήσεις ενός έργου.

Στη Rust θα δεις συχνά εξωτερικά πακέτα να αναφέρονται ως "crates". Ένα crate είναι μια μονάδα μεταγλώττισης στη Rust. Ένα crate μπορεί να μεταγλωττιστεί σε εκτελέσιμο ή σε βιβλιοθήκη.

Τις περισσότερες φορές, το να προσθέσεις μια εξωτερική εξάρτηση είναι τόσο απλό όσο το να προσθέσεις μια γραμμή στο αρχείο `Cargo.toml` σου.

Σε αυτή την άσκηση, οι εξαρτήσεις [`enum-iterator`](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) και [`int-enum`](https://docs.rs/int-enum/0.5.0/int_enum/) έχουν προστεθεί για σένα.
