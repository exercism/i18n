# Εισαγωγή

Ο τύπος `char` της F# είναι μια τιμή 16 bit που αναπαριστά τα μικρότερα διευθυνσιοδοτήσιμα συστατικά του κειμένου και είναι αμετάβλητη από προεπιλογή.

Τα `char` μπορούν να οριστούν ως κυριολεκτικές τιμές με μονά εισαγωγικά:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Οι συμβολοσειρές είναι μια ακολουθία από `char`.

Ένα μεμονωμένο `char` μπορεί να ανακτηθεί από μια συμβολοσειρά με θέσεις που ξεκινούν από το μηδέν:

```fsharp
"Exercism"[4] //  =>  'c'
```

Η επανάληψη πάνω σε μια συμβολοσειρά επιστρέφει ένα `char` σε κάθε βήμα.

Το επόμενο παράδειγμα χρησιμοποιεί μια συνάρτηση υψηλότερης τάξης και μια ανώνυμη συνάρτηση, για ευκολία.
Αυτές θα καλυφθούν κανονικά αργότερα στο πρόγραμμα σπουδών, αλλά για την ώρα είναι ένας σύντομος τρόπος να γράψεις έναν βρόχο πάνω στους χαρακτήρες μιας συμβολοσειράς.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Όπως φαίνεται παραπάνω, ένα `char` μπορεί να μετατραπεί στην `int` τιμή του.
Αυτό λειτουργεί επίσης (*τουλάχιστον κάποιες φορές*) και για άλλα συστήματα γραφής:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Το υποκείμενο Int16 χρησιμοποιείται κατά τη σύγκριση χαρακτήρων:

```fsharp
'A' < 'D'  // =>  true
```

Επίσης, ένα `int` μπορεί να μετατραπεί σε `char`:

```fsharp
char 77  // => 'M'
```

Η βιβλιοθήκη `System.Char` περιέχει το πλήρες σύνολο μεθόδων που περιμένει κανείς από μια γλώσσα .NET, όπως μετατροπές σε κεφαλαία/πεζά:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
