# Εισαγωγή

Στη Factor, συνδυάζεις λέξεις απλώς γράφοντάς τις τη μία μετά την άλλη: η σειρά με την οποία τις γράφεις *είναι* ο τρόπος με τον οποίο ενώνονται. (Οι προγραμματιστές το ονομάζουν αυτό *σύνθεση συναρτήσεων*.) Το σώμα μιας λέξης είναι και το ίδιο μια ακολουθία λέξεων: καθεμιά καταναλώνει κάποιες τιμές από τη στοίβα και βάζει το αποτέλεσμα της στη στοίβα, και η επόμενη λέξη συνεχίζει από εκεί που άφησε η προηγούμενη. Οπότε, το να ορίσεις

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

*είναι* ήδη η σύνθεση των `cleanupname`, `first` και `1string`.

Αυτή η άσκηση παρουσιάζει επίσης τις **παραθέσεις**: ένα κομμάτι κώδικα που μπορείς να αποθηκεύσεις ως τιμή και να το τρέξεις αργότερα, αντί να το τρέξεις αμέσως.

## Παραθέσεις

Μια παράθεση είναι ένα κομμάτι κώδικα τυλιγμένο σε αγκύλες. Δεν τρέχει όταν τη γράφεις· κάθεται στη στοίβα ως τιμή:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

Το `call` τρέχει μια παράθεση:

```factor
3 [ 2 * ] call .    ! => 6
```

Γράφεις μια παράθεση όταν χρειάζεται να περάσεις κώδικα ως δεδομένα: για να τρέξει αργότερα ή για να περάσει σε έναν *συνδυαστή*, δηλαδή μια λέξη που παίρνει μια παράθεση ως είσοδο.

## `compose`

Το `compose ( quot1 quot2 -- combined )` κολλάει δύο παραθέσεις σε μία και τις τρέχει με τη σειρά που είναι γραμμένες:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Συνήθως θα δεις ότι το να ορίσεις μια μικρή λέξη με `:` ... `;` διαβάζεται καλύτερα από το `compose`, αλλά το `compose` είναι βολικό όταν χρειάζεται να φτιάξεις παραθέσεις επί τόπου. Όταν τα δομικά στοιχεία δεν είναι ήδη παραθέσεις, το `>quotation ( seq -- quot )` (από το [`quotations`][quotations]) μετατρέπει μια ακολουθία από τιμές και αναφορές σε λέξεις σε μια παράθεση που μπορεί να κληθεί:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Εφαρμογή μιας παράθεσης σε δύο εισόδους

Το `bi@ ( x y quot -- ... )` τρέχει την παράθεση στο `x` και ξανά στο `y`, αφήνοντας και τα δύο αποτελέσματα στη στοίβα:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

Η εργασία `couple` της άσκησης παίρνει δύο ονόματα· το `bi@` είναι ο φυσικός τρόπος να εφαρμόσεις το `initial` στο καθένα.

## Μερικές λέξεις για συμβολοσειρές

Η άσκηση χρειάζεται μια χούφτα μικρές λέξεις για συμβολοσειρές, από τρία λεξιλόγια: [`sequences`][sequences], [`ascii`][ascii] και [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (στο `splitting`): αντικατάσταση υποσυμβολοσειράς.
- `[ blank? ] trim` (το `trim` στο `sequences`, το `blank?` στο `ascii`): αφαιρεί τα κενά διαστήματα στην αρχή και στο τέλος.
- `1string ( char -- str )` (στο `strings`): τυλίγει έναν μεμονωμένο χαρακτήρα σε μια συμβολοσειρά.
- `>upper ( str -- upper )` (στο `ascii`): μετατρέπει μια συμβολοσειρά σε κεφαλαία.
- `append ( s1 s2 -- s )` (στο `sequences`): συνενώνει δύο συμβολοσειρές.
- `prepend ( s1 s2 -- s )` (στο `sequences`): συνενώνει πρώτα το `s2` και μετά το `s1` (το `append` με τις εισόδους του σε αντίστροφη σειρά).
- `glue ( s1 s2 sep -- s )` (στο `sequences`): συνενώνει δύο συμβολοσειρές με έναν διαχωριστή ανάμεσά τους.
- `surround ( seq pre post -- new )` (στο `sequences`): τυλίγει μια συμβολοσειρά με ένα πρόθεμα και ένα επίθημα.

Οι χαρακτήρες Unicode μπορούν να γραφτούν ως `\u{XXXX}` μέσα σε μια συμβολοσειρά, όπου το `XXXX` είναι το σημείο κώδικα σε δεκαεξαδική μορφή. Η καρδιά `\u{2764}` (❤) εμφανίζεται σε αυτή την άσκηση.

## Μορφοποιημένη έξοδος

Όταν τα `append`/`glue`/`surround` δεν είναι αρκετά εκφραστικά, το [`formatting`][formatting] παρέχει το `sprintf` σε στυλ printf:

```
sprintf ( inputs... format-string -- str )
```

Το `%s` παρεμβάλλει μια συμβολοσειρά, το `%d` έναν ακέραιο, το `%f` έναν αριθμό κινητής υποδιαστολής· προαιρετικοί τροποποιητές πλάτους, ακρίβειας και συμπλήρωσης μπαίνουν ανάμεσα στο `%` και το γράμμα του τύπου:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Για αμφίδρομη μετατροπή ανάμεσα σε αριθμούς και συμβολοσειρές, το [`math.parser`][math.parser] έχει τα `number>string` και `string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
