# Σχετικά

Το [nil][nil-dictionary] είναι μια αγγλική λέξη που σημαίνει "τίποτα" ή "μηδέν". Στην Elixir, το `nil` είναι μια ειδική τιμή που σημαίνει _απουσία_ τιμής.

```elixir
# I do not have a favorite color
favorite_color = nil
```

Το `nil` είναι ένα άτομο, αλλά συνήθως γράφεται ως `nil`, όχι ως `:nil`. Οι τιμές Boolean `true` και `false` είναι επίσης άτομα.

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

Μπορείς να ελέγξεις αν η τιμή μιας μεταβλητής είναι `nil` χρησιμοποιώντας το [`==`][kernel-equal], με αντιστοίχιση προτύπων ή χρησιμοποιώντας τον [φύλακα `is_nil`][kernel-is-nil].

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
