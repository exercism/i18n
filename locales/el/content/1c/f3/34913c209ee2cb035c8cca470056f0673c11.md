# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να παρακολουθείς τους διεθνείς κωδικούς κλήσης μέσω ενός χάρτη κατακερματισμού διεθνών κωδικών κλήσης.

Ο χάρτης χρησιμοποιεί έναν ακέραιο για τα κλειδιά του (τον κωδικό κλήσης) και μια συμβολοσειρά (όνομα χώρας) για τις τιμές του.

Έχεις 11 εργασίες που αφορούν κωδικούς κλήσης.

## 1. Δημιούργησε έναν προσυμπληρωμένο χάρτη κατακερματισμού

Υπάρχει ένας προσυμπληρωμένος χάρτης κατακερματισμού που περιέχει τους εξής 3 κωδικούς κλήσης: "United States of America" με κωδικό 1, "Brazil" με κωδικό 55 και "India" με κωδικό 91. Όρισε τη μεταβλητή `countries` ώστε να αποθηκεύσει τον προσυμπληρωμένο χάρτη κατακερματισμού:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Πρόσθεσε μια χώρα σε έναν χάρτη

Πρόσθεσε το "United Kingdom" με κωδικό κλήσης 44 στον χάρτη που δημιουργήθηκε στην εργασία 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Πάρε το όνομα της χώρας που αντιστοιχεί σε έναν κωδικό χώρας

Ανάκτησε το όνομα της χώρας με κωδικό κλήσης 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Ενημέρωσε το όνομα μιας χώρας

Άλλαξε το όνομα του "United States of America" σε "Les États-Unis":

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Έλεγξε ότι μια χώρα υπάρχει στον χάρτη

Έλεγξε ότι υπάρχει μια καταγραφή για τη "Brazil" στον χάρτη που δημιουργήθηκε στην εργασία 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Προσπάθησε να ενημερώσεις το όνομα μιας χώρας που δεν υπάρχει στον χάρτη

Προσπάθησε να αλλάξεις το όνομα μιας χώρας με κωδικό που δεν υπάρχει στον χάρτη, π.χ. 999. Αυτό δεν θα πρέπει να επιφέρει καμία αλλαγή στον χάρτη:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Αφαίρεσε μια χώρα από τον χάρτη

Αφαίρεσε τη χώρα "India" από τον χάρτη:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Βρες τη χώρα με το μεγαλύτερο όνομα

Επεξεργάσου τις τιμές του χάρτη για να βρεις αυτή με το μεγαλύτερο όνομα:

```clojure
(longest-name countries)
;;=> "United States of America"
```
