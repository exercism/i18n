# Προσθήκη στις οδηγίες

## Υλοποίηση

Στην Cairo, όπου δεν υπάρχει εγγενής υποστήριξη για αριθμούς κινητής υποδιαστολής, αναπαριστούμε τις κλασματικές τιμές χρησιμοποιώντας ακέραιους αριθμούς.

Αυτή η προσέγγιση είναι απαραίτητη στην ανάπτυξη blockchain, ώστε να διατηρείται η ακρίβεια στους υπολογισμούς.

Σε αυτή την άσκηση, χρησιμοποιούμε **αριθμητική σταθερής υποδιαστολής** μετατρέποντας τις τροχιακές περιόδους σε μικροδευτερόλεπτα.

Για παράδειγμα, η τροχιακή περίοδος του Ερμή, `0.2408467` γήινα έτη, γίνεται `240,846,700` μικροδευτερόλεπτα με πολλαπλασιασμό επί `1,000,000`.

Για να ληφθεί υπόψη η δεκαδική ακρίβεια, οι περιπτώσεις δοκιμών υποθέτουν ότι η ηλικία που προκύπτει έχει **δύο δεκαδικά ψηφία**, αναπαριστάμενα ως ακέραιοι.

Αυτό σημαίνει ότι μια ηλικία `31.69` ετών αποθηκεύεται ως `3169` στον κώδικα.

Για να το πετύχουμε αυτό, πολλαπλασιάζουμε επί 100 πριν εκτελέσουμε τη διαίρεση.

Ακολουθεί ένα παράδειγμα:

```rust
let mercury_orbital_period = 240_846_700; // in microseconds
let age_microseconds = age_seconds * 1_000_000;
// multiplying with 100 to retain 2 decimal places
age_microseconds * 100 / mercury_orbital_period
```

Με αυτή τη μέθοδο, διασφαλίζεις ότι οι κλασματικές τιμές αναπαρίστανται με ακρίβεια ως ακέραιοι, διατηρώντας παράλληλα την απαιτούμενη ακρίβεια των δύο δεκαδικών ψηφίων, κάτι που είναι κρίσιμο για να περάσουν οι δοκιμές.
