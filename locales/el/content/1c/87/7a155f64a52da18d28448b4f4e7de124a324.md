# Παράρτημα οδηγιών

## Μπόνους

Δοκίμασε τη συνάρτησή σου σε αυτή τη συμβολοσειρά: `uüu` και δες τι συμβαίνει.
Προσπάθησε να γράψεις μια συνάρτηση που αντιστρέφει σωστά αυτή τη συμβολοσειρά.
Υπόδειξη: συμπλέγματα γραφημάτων

Για να τρέξει το τεστ του μπόνους, αφαίρεσε τη σημαία ignore (`#[ignore]`) από το τελευταίο τεστ και εκτέλεσε τα τεστ με:

```bash
cargo test --features grapheme
```

Θα χρειαστεί να χρησιμοποιήσεις εξωτερικές βιβλιοθήκες (ένα `crate`, στην ορολογία της Rust) για την εργασία του μπόνους.
Ένα καλό μέρος για να ψάξεις είναι το [crates.io](https://crates.io/), το επίσημο αποθετήριο των crates.
Θυμήσου ότι ο test runner μας υποστηρίζει μόνο ένα περιορισμένο σύνολο από crates.
Η πλήρης λίστα βρίσκεται σε [αυτό το αρχείο](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) στην ενότητα `[dependencies]`.

[Δες την τεκμηρίωση](https://doc.rust-lang.org/cargo/guide/dependencies.html) για οδηγίες σχετικά με το πώς να χρησιμοποιείς εξωτερικά crates στα έργα σου.
