# Οδηγίες

Μια πυθαγόρεια τριάδα είναι ένα σύνολο από τρεις φυσικούς αριθμούς, {a, b, c}, για τους οποίους ισχύει,

```text
a² + b² = c²
```

και τέτοιοι ώστε,

```text
a < b < c
```

Για παράδειγμα,

```text
3² + 4² = 5².
```

Δεδομένου ενός ακέραιου N ως είσοδο, βρες όλες τις πυθαγόρειες τριάδες για τις οποίες ισχύει `a + b + c = N`.

Για παράδειγμα, με N = 1000, υπάρχει ακριβώς μία πυθαγόρεια τριάδα για την οποία ισχύει `a + b + c = 1000`: `{200, 375, 425}`.
