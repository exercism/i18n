# Σχετικά

_"Οι ημερομηνίες και οι ώρες είναι κάτι που το μαθαίνουμε σε μικρά παιδιά. Πόσο δύσκολο μπορεί να είναι;"_

Πολλοί προγραμματιστές έχουν κάνει αυτό το λάθος, και η εμπειρία που ακολουθεί έχει την τάση να έχει κακή επίδραση στην υγεία και την ευτυχία τους.

Όποιος κάνει μη τετριμμένο προγραμματισμό με ημερομηνίες και ώρες θα πρέπει τουλάχιστον να είναι προετοιμασμένος να κατανοήσει και να μετριάσει πιθανά προβλήματα.

Αυτό το κείμενο θα επιχειρήσει να δώσει μια επισκόπηση του πώς η Julia χειρίζεται ημερομηνίες και ώρες, αλλά θα χρειαστεί να συμβουλευτείς το [εγχειρίδιο][Dates] για περισσότερες λεπτομέρειες.
Υπάρχει επίσης ένα [Wikibook][Wikibook] που κάποιοι αναγνώστες μπορεί να βρουν πιο ξεκάθαρο στις εξηγήσεις του, και περιλαμβάνει ένα χρήσιμο [διάγραμμα][type-hierarchy] της ιεραρχίας τύπων.

## Το άρθρωμα `Dates`

Το μεγαλύτερο μέρος της βασικής λειτουργικότητας βρίσκεται στο `Dates`, ένα άρθρωμα που περιλαμβάνεται σε μια προεπιλεγμένη εγκατάσταση αλλά δεν αποτελεί μέρος της βασικής βιβλιοθήκης.

Για να χρησιμοποιήσεις το άρθρωμα, υπάρχουν δύο επιλογές:

1. Πρόσθεσε `import Dates` και μετά βάλε σε όλες τις κλήσεις συναρτήσεων το πρόθεμα `Dates.`
2. Πρόσθεσε `using Dates`, το οποίο φέρνει ολόκληρο το άρθρωμα στον τρέχοντα χώρο ονομάτων (_εκτός από μερικά προβληματικά ονόματα_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

Το άρθρωμα `Dates` είναι μεγάλο και πολύπλοκο, αλλά παρέχει τέσσερα κύρια είδη λειτουργικότητας:

- `Dates.Date`, το οποίο περιλαμβάνει ημέρα-μήνα-έτος αλλά όχι ώρα της ημέρας.
- `Dates.Time`, το οποίο περιλαμβάνει ώρα της ημέρας, με ακρίβεια νανοδευτερολέπτου, αλλά όχι ημερομηνία.
- `Dates.DateTime`, το οποίο συνδυάζει ημερομηνία και ώρα με ακρίβεια χιλιοστού του δευτερολέπτου.
- `Dates.Period`, το οποίο χειρίζεται διαστήματα χρόνου/ημερομηνίας.

Σημείωσε ότι ένα `DateTime` γενικά _δεν_ περιλαμβάνει πληροφορίες ζώνης ώρας (η Python θα το έλεγε "naive" datetime).
Μία εξαίρεση είναι η `now()`, η οποία παίρνει την τοπική ώρα από το ρολόι του συστήματός σου και μπορεί να τη μετατρέψει σε UTC αν χρειάζεται.

Άλλοι υπολογισμοί ζώνης ώρας χρειάζονται το πακέτο `TimeZones.jl`, το οποίο δεν αποτελεί μέρος μιας προεπιλεγμένης εγκατάστασης.
Από τον Ιούνιο του 2025, αυτό δεν είναι διαθέσιμο στο Exercism, αλλά μπορεί να προστεθεί στο μέλλον.

Ίσως οι πιο συχνές ανάγκες είναι:

- Να αναλύσεις μια κατάλληλη μορφή εισόδου για να κατασκευάσεις έναν τύπο `Dates`.
- Να πάρεις την απαιτούμενη αριθμητική μορφή ή μορφή συμβολοσειράς από έναν τύπο `Dates`.
- Να εφαρμόσεις μια μετατόπιση σε μια τιμή `Date`, `Time` ή `DateTime`.
- Να υπολογίσεις το διάστημα ανάμεσα σε δύο τέτοιες τιμές.
- Να πάρεις την τρέχουσα ημερομηνία (με την `today()`) ή/και ώρα (με την `now()`).

~~~~exercism/note
Για να μειωθεί η οπτική απόσπαση της προσοχής, ο περισσότερος κώδικας παραδειγμάτων στο υπόλοιπο αυτού του κειμένου υποθέτει `using Dates` και αποφεύγει να συμπεριλάβει το όνομα του αρθρώματος `Dates.` στις κλήσεις συναρτήσεων.
~~~~

### Μορφές ημερομηνίας και ώρας

Υπάρχουν πολλοί τρόποι να γράψεις ημερομηνίες και ώρες, οι οποίοι τείνουν να είναι πολιτισμικά συγκεκριμένοι.
Οι ημερομηνίες που αποτελούνται μόνο από αριθμούς, όπως "7/6/23", είναι αμφίσημες, μπερδεύουν και έχουν οδηγήσει σε πολλά ακριβά λάθη σε πολυεθνικούς οργανισμούς (_ο συγγραφέας το λέει αυτό από πικρή προσωπική εμπειρία_).

Το διεθνές πρότυπο ορίζεται στο [`ISO 8601`][ISO8601] και έχει δύο κύρια πλεονεκτήματα:

- Η ανάλυση είναι γρήγορη και χωρίς αμφισημίες.
- Η ταξινόμηση είναι εύκολη, καθώς η ημερομηνία/ώρα μπορεί να αντιμετωπιστεί ως κανονικό κείμενο και να ταξινομηθεί αλφαβητικά.

Είδαμε σε ένα προηγούμενο παράδειγμα ότι η `Date.now()` επέστρεψε `2025-06-21T16:03:04.161`.

Αυτή αποτελείται από διάφορα μέρη:

- `YYYY-MM-DD` για το τμήμα της ημερομηνίας.
- `hh:mm:ss` για το τμήμα της ώρας.
- Προαιρετικά, χιλιοστά του δευτερολέπτου (ή ακόμη μικρότερη μονάδα) μετά την υποδιαστολή.

Άλλες μορφές συμβολοσειρών θα συζητηθούν σε επόμενη ενότητα.

## Ημερομηνίες

Το `Dates.Date` είναι ένας σχετικά απλός τύπος μόνο για ημερομηνίες, χωρίς κατανόηση των ωρών ή των ζωνών ώρας.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

Υπάρχουν συναρτήσεις πρόσβασης για τα επιμέρους μέρη της ημερομηνίας, και αυτές έρχονται σε ζεύγη που ξεχωρίζουν από το αν γράφονται με πεζά ή κεφαλαία.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month

# various compound methods are also available, returning a tuple
julia> monthday(date1)
(6, 23)
```

### Συναρτήσεις ερωτημάτων

Υπάρχει μια ποικιλία [συναρτήσεων ερωτημάτων][query-func] με κάποια κατανόηση του ημερολογίου.
Το επόμενο παράδειγμα δείχνει μόνο μερικές.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## Ώρες

Το `Dates.Time` είναι ο βασικός τύπος μόνο για ώρες.
Δεν έχει καμία κατανόηση των ημερομηνιών: οι ώρες επιστρέφουν αυτόματα στο `Time(0, 0, 0)` τα μεσάνυχτα.

Η πλήρης μορφή του κατασκευαστή είναι `Time(hour, min, sec, millisec, microsec)` ή το αντίστοιχο σε ISO 8601.

Όλες οι παράμετροι είναι προαιρετικές και παίρνουν προεπιλεγμένη τιμή `0`.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time(14, 57, 25, 142, 32)`
14:57:25.142032

julia> Time("14:57:25.142")
14:57:25.142
```

Όπως και με το `Date`, τα επιμέρους μέρη είναι διαθέσιμα μέσω συναρτήσεων πρόσβασης:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## DateTimes

Το `Dates.DateTime` συνδυάζει τα περισσότερα χαρακτηριστικά των τύπων `Date` και `Time`.

Είναι η πιο ευέλικτη από αυτές τις τρεις κλάσεις, αν και η ακρίβεια του χρόνου περιορίζεται στα χιλιοστά του δευτερολέπτου (το `Time` φτάνει σε ακρίβεια νανοδευτερολέπτου).

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

Οι παράμετροι έτους, μήνα και ημέρας παίρνουν προεπιλεγμένη τιμή `1`, ενώ οι παράμετροι ώρας παίρνουν προεπιλεγμένη τιμή `0`.

Το να θυμάσαι σωστά όλες αυτές τις παραμέτρους μπορεί να είναι πρόκληση, οπότε η μορφή ISO ίσως είναι προτιμότερη.

Εναλλακτικά, ένα `DateTime` μπορεί να κατασκευαστεί από ένα `Date` και ένα `Time`, όπως στο παραπάνω παράδειγμα.

## Περίοδοι

Κάθε ένα από τα στοιχεία ημερομηνίας/ώρας έχει τον δικό του τύπο [`Period`][period], από το `Year` μέχρι το `Nanosecond`, που αντιπροσωπεύει ένα χρονικό διάστημα.
Αυτοί είναι ιδιαίτερα χρήσιμοι για αριθμητικές πράξεις.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

Υπάρχει επίσης ένας τύπος [`CompoundPeriod`][compound-period], ο οποίος μπορεί να συνδυάσει πολλούς τύπους `Period`.
Παραδόξως, αυτός χρειάζεται προς το παρόν το όνομα του αρθρώματος για να αποφευχθεί ένα σφάλμα χώρου ονομάτων (_κάτι που μοιάζει με bug_).

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> offset = Dates.CompoundPeriod(Year(21), Second(-61))
21 years, -61 seconds

julia> dt1 + offset
2046-06-23T14:56:24.142
```

Όταν αφαιρείς ημερομηνίες/ώρες, η περίοδος δίνεται σε ημέρες (για ημερομηνίες) ή σε νανοδευτερόλεπτα (για ώρες).
Μπορεί να σου φανεί χρήσιμο να τα κάνεις [`canonicalize`][canonicalize] σε ένα `CompoundPeriod`.

```julia-repl
julia> diff = Time(23, 14, 00) - Time(1, 23, 52)
78608000000000 nanoseconds

julia> canonicalize(diff)
21 hours, 50 minutes, 8 seconds

julia> typeof(canonicalize(diff))
Dates.CompoundPeriod
```

Όταν δουλεύεις με τύπους `Period`, η Julia προσπαθεί να είναι έξυπνη σχετικά με τις ανωμαλίες του ημερολογίου, όπως το μήκος του μήνα, στρογγυλοποιώντας όπου χρειάζεται.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## [Στρογγυλοποίηση][rounding]

Οι συναρτήσεις `floor`, `ceil` και `round` θα σου είναι γνωστές από τους ακέραιους/αριθμούς κινητής υποδιαστολής, αλλά λειτουργούν και με ημερομηνίες και ώρες.
Προσδιόρισε την `Period` στην οποία θέλεις να γίνει η στρογγυλοποίηση, ως δεύτερο όρισμα.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> floor(dt1, Minute(15))
2025-06-23T14:45:00

julia> ceil(dt1, Minute(30))
2025-06-23T15:00:00

julia> ceil(dt1, Month(1))
2025-07-01T00:00:00
```

## Αναπαραστάσεις συμβολοσειρών

Αναφέραμε προηγουμένως το πρότυπο ISO 8601, που είναι η προεπιλεγμένη αναπαράσταση ημερομηνίας/ώρας της Julia κατά τη μορφοποίηση ή την ανάλυση συμβολοσειρών.

Προφανώς, πολλές άλλες μορφές χρησιμοποιούνται συχνά, συχνά με πολιτισμικά συγκεκριμένους τρόπους.
Για να τις χειριστεί, η Julia έχει τον τύπο `DateFormat`, ο οποίος μπορεί να κατασκευαστεί από μια συμβολοσειρά μορφοποίησης οποιασδήποτε πολυπλοκότητας.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

Το παραπάνω παράδειγμα είναι πολύ απλό, απλώς μια ημερομηνία στη μορφή ημέρα/μήνας/έτος που συνηθίζεται στην Ευρώπη.
Δείχνονται δύο παραλλαγές της σύνταξης, αλλά το αποτέλεσμα είναι το ίδιο.

Ένα `DateFormat` μπορεί στη συνέχεια να χρησιμοποιηθεί για την ανάλυση οποιασδήποτε κατάλληλης συμβολοσειράς:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

Η δημιουργία ενός `DateFormat` συνεπάγεται σημαντική επιβάρυνση, οπότε το να κάνεις αυτό το βήμα μόνο μία φορά (όπως εδώ με το `dtfmt`) βοηθά στην απόδοση όταν διατρέχεις πολλές συμβολοσειρές ημερομηνίας/ώρας.

Οι μορφές μπορεί να είναι πολύ πιο σύνθετες από αυτό, οπότε δες το [εγχειρίδιο][dateformat] για λεπτομέρειες.

Οποιοσδήποτε γνωρίζει άλλες γλώσσες μπορεί να παρατηρήσει μια οικογενειακή ομοιότητα με τις δεκαετίες παλιές συναρτήσεις `strptime` και `strftime`.
Η έκδοση της Julia δανείζεται από αυτή την κληρονομιά, αλλά στοχεύει να είναι πιο συνοπτική και ευέλικτη.

Το ίδιο `DateFormat` μπορεί επίσης να χρησιμοποιηθεί για να βγάλεις μια ημερομηνία/ώρα σε οποιαδήποτε επιθυμητή μορφή συμβολοσειράς, χρησιμοποιώντας τη συνάρτηση [`Dates.format()`][format].

Δυστυχώς, φαίνεται να υπάρχει σύγκρουση χώρου ονομάτων με το `format` (τουλάχιστον από την Julia 1.11.5), οπότε είναι καλύτερο να συμπεριλάβεις το πρόθεμα `Dates.` ακόμη και μετά το `using Dates`.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

Όπως [τεκμηριώνεται][wiki-format], το `"e, u d"` δίνει τη συντομευμένη κειμενική αναπαράσταση για την ημέρα της εβδομάδας και τον μήνα.

Η κειμενική αναπαράσταση είναι προεπιλεγμένα στα αγγλικά.
Μπορούν να προστεθούν άλλες γλώσσες, αν και η υποστήριξη γι' αυτό είναι προς το παρόν υπο-βέλτιστη.
