# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις [τελεστές boolean (λογική τιμή)][reference] για να δουλεύεις με τιμές boolean.
- Μπορείς να συνδυάσεις πολλούς τελεστές σε μία μόνο έκφραση.

## 1. Έλεγξε αν μπορείς να κάνεις γρήγορη επίθεση

- Οι [τελεστές boolean][reference] μπορούν να εφαρμοστούν και σε παραμέτρους boolean.

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
