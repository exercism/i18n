# Εισαγωγή

**Οι αναδρομικές συναρτήσεις** είναι συναρτήσεις που καλούν τον εαυτό τους.

Μια _αναδρομική συνάρτηση_ πρέπει να έχει τουλάχιστον μία _βασική περίπτωση_ και τουλάχιστον μία _αναδρομική περίπτωση_.

Μια **βασική περίπτωση** επιστρέφει μια τιμή χωρίς να καλέσει ξανά τη συνάρτηση.
Μια **αναδρομική περίπτωση** καλεί ξανά τη συνάρτηση, τροποποιώντας την είσοδο έτσι ώστε κάποια στιγμή να ταιριάξει με τη βασική περίπτωση.

Ακολουθεί ένα παράδειγμα που μετράει τα στοιχεία ενός πίνακα.

```jq
def count:
  if length == 0 then
    0                       # base case
  else
    1 + (.[1:] | count)     # recursive case
  end;

([] | count),           # => 0
([11, 22, 33] | count)  # => 3
```

Μια _αναδρομική συνάρτηση_ μπορεί να έχει πολλές _βασικές περιπτώσεις_ ή/και πολλές _αναδρομικές περιπτώσεις_.
Για παράδειγμα, [η ακολουθία Fibonacci][wiki-fibonacci] είναι μια αναδρομική ακολουθία με δύο _βασικές περιπτώσεις_.

```jq
def fibonacci:
  if . == 0 then
    0
  elif . == 1 then
    1
  else
    (. - 1 | fibonacci) + (. - 2 | fibonacci)
  end;

10 | fibonacci          # => 55
```

Το να μετρήσεις τον αριθμό των εμφανίσεων μιας δεδομένης τιμής `x` σε μια λίστα έχει δύο _αναδρομικές περιπτώσεις_.

```jq
def count_occurrences(x):
  if length == 0 then
    0
  elif first == x then
    1 + (.[1:] | count_occurrences(x))
  else
    (.[1:] | count_occurrences(x))
  end;

[11, 22, 33, 22, 44] | count_occurrences(22)    # => 2
```

Στην πράξη, η επανάληψη πάνω σε λίστες και σε άλλες απαριθμήσιμες δομές δεδομένων γίνεται τις περισσότερες φορές με ενσωματωμένες συναρτήσεις,
όπως οι `map` και `reduce`, ή [χρησιμοποιώντας ροές][map-implementation] όπως `[.[] | select(...)]`.
Στο παρασκήνιο, ορισμένες ενσωματωμένες συναρτήσεις είναι [υλοποιημένες με αναδρομή][walk-implementation].
