# Οδηγίες

Ο Ιάπωνας φίλος σου ο Kuroko είναι streamer με διεθνή απήχηση.
Το πρόγραμμα των stream του Kuroko είναι αρκετά περίπλοκο, αφού κάθε stream φαίνεται να ξεκινά σε διαφορετική ώρα κάθε μέρα.

Σου ζητά να τον βοηθήσεις να φτιάξετε μια μικρή εφαρμογή που θα δείχνει το πρόγραμμά του στις τοπικές ζώνες ώρας των θεατών του: το Kuroko's Clock.
Έχει και μια επιπλέον απαίτηση: η εφαρμογή θα πρέπει να μπορεί να εμφανίζει την ώρα σε δύο διαφορετικές γλώσσες: ιαπωνικά και αμερικανικά αγγλικά.

## 1. Είναι ραντεβού

Όρισε μια συνάρτηση `showLocalDate : Locale -> Int -> Month -> Int -> String` που θα εμφανίζει μια (έγκυρη) τοπική ημερομηνία.

Στο locale `US`, η μορφή θα είναι `Month/Day/Year` χωρίς αρχικά μηδενικά.

Στο locale `JP`, η μορφή θα είναι `Year年Month月Day日`, επίσης χωρίς αρχικά μηδενικά.

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. Ώρα για σόου

Όρισε μια συνάρτηση `showLocalTime : Locale -> Int -> Int -> String` που θα εμφανίζει μια (έγκυρη) τοπική ώρα.

Στο locale `US`, οι ώρες θα εμφανίζονται σε 12ωρη μορφή μαζί με "PM" ή "AM", και τα λεπτά θα εμφανίζονται με αρχικά μηδενικά.

Στο locale `JP`, η ώρα θα εμφανίζεται σε 24ωρη μορφή πριν από το "時" και τα λεπτά θα εμφανίζονται χωρίς αρχικά μηδενικά πριν από το "分".

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. Μπες στη ζώνη

Όρισε μια συνάρτηση `showDateTime : Locale -> Zone -> Posix -> String` που θα εμφανίζει μια ημερομηνία και ώρα σε σχέση με μια ζώνη ώρας, σε ένα συγκεκριμένο locale.

Χρησιμοποίησε τις `showLocalDate` και `showLocalTime` για να εμφανίσεις το τελικό αποτέλεσμα.

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
