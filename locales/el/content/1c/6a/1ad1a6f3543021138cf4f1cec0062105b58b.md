# Υποδείξεις

## 1. Υλοποίησε ένα γενικό φίλτρο καταγραφών

- Δημιούργησε ένα νέο `[]Record` για να κρατήσεις τα φιλτραρισμένα αποτελέσματα
- Διάσχισε τις καταγραφές και κάλεσε τη συνάρτηση κατηγορήματος σε καθεμία
- Πρόσθεσε στο slice με τα αποτελέσματα μόνο τις καταγραφές για τις οποίες η κλήση της συνάρτησης κατηγορήματος πάνω τους επιστρέφει `true`

## 2. Φίλτραρε καταγραφές μέσα σε ένα χρονικό διάστημα

- Κάνε τη συνάρτηση να επιστρέφει μια ανώνυμη συνάρτηση που δέχεται ένα `Record` και επιστρέφει ένα `bool` που δείχνει αν η καταγραφή βρίσκεται μέσα στο χρονικό διάστημα που δέχεται ως όρισμα η `ByDaysPeriod`.
- Μέσα στην ανώνυμη συνάρτησή σου, έχεις πρόσβαση στο όρισμα `DaysPeriod` που δέχεται η `ByDaysPeriod`.
  Μαζί με το όρισμα `Record` της ανώνυμης συνάρτησης, φτιάξε μια λογική έκφραση που ελέγχει αν η ημέρα της καταγραφής βρίσκεται μέσα στο `DaysPeriod` που δέχεται η `ByDaysPeriod`.
  Επίστρεψε αυτή τη λογική έκφραση από την ανώνυμη συνάρτηση.

## 3. Φίλτραρε καταγραφές ανά κατηγορία

- Αυτό μοιάζει πολύ με την προηγούμενη εργασία, αλλά τώρα έχεις να κάνεις με μια κατηγορία αντί για ένα χρονικό διάστημα.
- Κάνε τη συνάρτηση να επιστρέφει μια ανώνυμη συνάρτηση που δέχεται ένα `Record` και επιστρέφει ένα `bool` που δείχνει αν η καταγραφή ανήκει στην κατηγορία που δέχεται ως όρισμα η `ByCategory`.
- Μέσα στην ανώνυμη συνάρτησή σου, έχεις πρόσβαση στο όρισμα της κατηγορίας που δέχεται η `ByCategory`.
  Μαζί με το όρισμα `Record` της ανώνυμης συνάρτησης, φτιάξε μια λογική έκφραση που ελέγχει αν η κατηγορία της καταγραφής είναι ίδια με την κατηγορία που δέχεται ως όρισμα η `ByCategory`.
  Επίστρεψε αυτή τη λογική έκφραση από την ανώνυμη συνάρτηση.

## 4. Υπολόγισε το συνολικό ποσό των εξόδων σε ένα διάστημα

- Χρησιμοποίησε τη συνάρτηση `ByDaysPeriod` που έφτιαξες στο βήμα 2 για να φτιάξεις μια συνάρτηση φίλτρου διαστήματος.
- Πέρασε αυτή τη συνάρτηση φίλτρου ως δεύτερο όρισμα στη συνάρτηση `Filter` που έφτιαξες στο βήμα 1. Έτσι μπορείς να φιλτράρεις τα αποτελέσματα με βάση ένα χρονικό διάστημα.
- Διάσχισε τις φιλτραρισμένες καταγραφές και άθροισε όλα τα ποσά τους.

## 5. Υπολόγισε τα συνολικά έξοδα για καταγραφές μιας κατηγορίας σε ένα διάστημα

- Χρησιμοποίησε τη συνάρτηση `ByCategory` που έφτιαξες στο βήμα 3 για να φτιάξεις μια συνάρτηση φίλτρου κατηγορίας.
- Πέρασε αυτή τη συνάρτηση φίλτρου ως δεύτερο όρισμα στη συνάρτηση `Filter` που έφτιαξες στο βήμα 1. Έτσι μπορείς να φιλτράρεις τα αποτελέσματα με βάση μια συγκεκριμένη κατηγορία.
- Αφού φιλτράρεις τις καταγραφές ανά κατηγορία, έλεγξε αν έχεις καταγραφές για αυτή την κατηγορία.
  Αν δεν έχεις, πρέπει να επιστρέψεις ένα σφάλμα.
- Αν έχεις καταγραφές που ανήκουν σε αυτή την κατηγορία, υπολόγισε τα συνολικά έξοδα για το δεδομένο χρονικό διάστημα χρησιμοποιώντας τη συνάρτηση `TotalByPeriod` που έφτιαξες στο βήμα 4.
