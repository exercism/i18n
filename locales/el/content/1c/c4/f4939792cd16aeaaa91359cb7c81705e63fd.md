# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις πέντε εργασίες, που όλες έχουν να κάνουν με τους αριθμούς των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Αποθηκεύεις τις μετρήσεις των πουλιών σου σε μορφή JSON.
Ένας πίνακας "main" αποθηκεύει πίνακες με τις εβδομαδιαίες μετρήσεις.
Κάθε εβδομαδιαία μέτρηση είναι ένας πίνακας με επτά ακέραιους, έναν αριθμό για κάθε ημέρα της εβδομάδας.
Προσθέτεις πάντα τις νέες εβδομάδες στο τέλος του κύριου πίνακα.
Υλοποίησε το φίλτρο που επιστρέφει τις μετρήσεις της προηγούμενης εβδομάδας.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν χθες

Υλοποίησε το φίλτρο ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου χθες.
Οι μετρήσεις των πουλιών είναι ταξινομημένες κατά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο να είναι η σημερινή μέτρηση.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Υπολόγισε τον συνολικό αριθμό των πουλιών που επισκέφτηκαν τον κήπο

Υλοποίησε το φίλτρο ώστε να επιστρέφει τον συνολικό αριθμό των πουλιών που έχουν επισκεφτεί τον κήπο σου αυτή την εβδομάδα.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Υπολόγισε τον αριθμό των ημερών αιχμής

Κάποιες μέρες έχουν περισσότερη κίνηση από άλλες.
Μια ημέρα αιχμής είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.
Υλοποίησε το φίλτρο ώστε να επιστρέφει τον αριθμό των ημερών αιχμής αυτής της εβδομάδας.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

Υλοποίησε το φίλτρο που επιστρέφει `true` αν υπήρξε οποιαδήποτε μέρα αυτή την εβδομάδα κατά την οποία μηδέν πουλιά επισκέφτηκαν τον κήπο· διαφορετικά, επιστρέφει `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
