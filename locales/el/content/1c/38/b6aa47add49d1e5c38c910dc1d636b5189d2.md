# Υποδείξεις

- Η τεκμηρίωση του πακέτου `Bitwise` βρίσκεται [εδώ][bitwise-docs].

## 1. Μετατόπισε τα bits προς τα πίσω

- Υπάρχουν δύο συναρτήσεις για μετατόπιση bits προς τα δεξιά, αλλά [μόνο μία][bitwise-shiftRightZfBy] εισάγει πάντα ένα 0.

## 2. Θέσε μερικά bits

- [Μία από τις συναρτήσεις bitwise][bitwise-or] θέτει πάντα ένα bit σε 1 όπου τα bits και στις δύο τιμές είναι 1.

## 3. Αντιστρέψε συγκεκριμένα bits

- Υπάρχει [μία συνάρτηση bitwise][bitwise-xor] που αντιστρέφει ένα bit όπου η μάσκα είναι 1.

## 4. Μηδένισε συγκεκριμένα bits

- [Μία από τις συναρτήσεις bitwise][bitwise-and] μηδενίζει τα bits όπου το bit στη μάσκα είναι 0.
- Ωστόσο, μπορεί να χρειαστεί να τη συνδυάσεις με [μία άλλη συνάρτηση][bitwise-complement] για να μηδενίσεις τα bits όπου η μάσκα είναι 1.

## 5. Αποκρυπτογράφησε ένα μήνυμα

- Εφάρμοσε τις άλλες συναρτήσεις που έγραψες στην είσοδο με την εξής σειρά, παίρνοντας την έξοδο της μίας και χρησιμοποιώντας την ως είσοδο για την επόμενη:

1. `setBits`
2. `flipBits`
3. `shiftBack`
4. `clearBits`

Για το βήμα 4, θα χρειαστεί να μετατρέψεις σε δεκαδικό τον δυαδικό αριθμό όπου το 1ο και το 5ο bit είναι στο 1 (10001).
