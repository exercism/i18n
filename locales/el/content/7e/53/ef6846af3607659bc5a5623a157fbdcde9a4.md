# Ο τριαδικός τελεστής

Ο τριαδικός τελεστής είναι ένας συντομότερος τρόπος να γράψεις απλές εντολές `if/else`.
Αν μια εντολή `if/else` περιέχει μόνο δύο κλάδους, έναν για όταν η συνθήκη είναι αληθής και έναν για όταν είναι ψευδής, μπορεί να ξαναγραφτεί ως τριαδικός τελεστής.

Οι τριαδικοί τελεστές χρησιμοποιούν έναν συνδυασμό από τα σύμβολα `?` και `:` για να χωρίσουν μια υπό συνθήκη έκφραση:
```ruby
condition ? true_branch : false_branch
```

Ο κώδικας στην αριστερή πλευρά του `?` είναι η συνθήκη και ο κώδικας στα δεξιά περιέχει τους δύο πιθανούς κλάδους, χωρισμένους με το `:`.
Αν η συνθήκη είναι _αληθής_, ο κώδικας στην _αριστερή_ πλευρά του `:` εκτελείται.
Αν η συνθήκη είναι _ψευδής_, τότε ο κώδικας στα _δεξιά_ του `:` εκτελείται.

Για παράδειγμα:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

μπορεί να ξαναγραφτεί ως:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
