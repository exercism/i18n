# Εισαγωγή

Η Ruby έρχεται με μια Τυπική Βιβλιοθήκη (συχνά συντομεύεται σε "stdlib") - μια συλλογή από κλάσεις για να δουλεύεις με πράγματα όπως ημερομηνίες, json και δικτύωση.
Παρέχει επίσης κάποιες χρήσιμες λειτουργίες που κάνουν τον κώδικά σου πιο εύκολο στη διαχείριση.

Το `OpenStruct` είναι μέρος της Τυπικής Βιβλιοθήκης και σου επιτρέπει να δημιουργήσεις εύκολα ένα αντικείμενο από ένα `Hash`.
Αντί να χρειάζεται να έχεις πρόσβαση χρησιμοποιώντας κλειδιά `Hash`, το `OpenStruct` μας επιτρέπει να χρησιμοποιούμε μεθόδους για να έχουμε πρόσβαση και να ορίζουμε τιμές.

Όταν χρησιμοποιείς κλάσεις από την Τυπική Βιβλιοθήκη, ή από οποιαδήποτε άλλη βιβλιοθήκη, πρέπει να κάνεις require αυτή την κλάση χρησιμοποιώντας τη μέθοδο `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ένα επιπλέον πλεονέκτημα αυτού είναι ότι μπορείς να επωφεληθείς από μια συντόμευση όταν χρησιμοποιείς σύνταξη μπλοκ.
Σε περιπτώσεις όπου ένα μπλοκ καλεί μία μόνο μέθοδο, μπορείς να αντικαταστήσεις το μπλοκ με `&:` ακολουθούμενο από το όνομα της μεθόδου.
Για παράδειγμα, αυτές οι δύο γραμμές είναι συνώνυμες:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
