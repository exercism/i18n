# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με τη μορφή `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία επίπεδα καταγραφής: `INFO`, `WARNING` και `ERROR`.

Έχεις τρεις εργασίες. Κάθε μία παίρνει μία μόνο γραμμή καταγραφής από τη στοίβα.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Όρισε τη `message` ώστε να επιστρέφει το μήνυμα της γραμμής καταγραφής. Τυχόν κενά στην αρχή ή στο τέλος πρέπει να αφαιρούνται.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Όρισε τη `log-level` ώστε να επιστρέφει το επίπεδο της γραμμής καταγραφής, με πεζά γράμματα.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Όρισε τη `reformat` ώστε να βάζει πρώτα το μήνυμα και μετά, μέσα σε παρενθέσεις, το επίπεδο καταγραφής με πεζά γράμματα.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Σημείωση:*** Όλες οι συμβολοσειρές σε αυτή την άσκηση είναι ASCII. Οι επόμενες ασκήσεις θα ασχοληθούν με τον χειρισμό συμβολοσειρών με υποστήριξη Unicode.
