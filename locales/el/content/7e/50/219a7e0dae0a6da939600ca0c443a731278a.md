# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις έξι εργασίες, όλες σχετικές με τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

Υλοποίησε τη συνάρτηση `today()` ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου σήμερα. Οι μετρήσεις των πουλιών είναι ταξινομημένες ανά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο τη σημερινή μέτρηση.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Αύξησε τη σημερινή μέτρηση

Υλοποίησε τη συνάρτηση `increment_todays_count()` για να αυξήσεις τη σημερινή μέτρηση:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη συνάρτηση `has_day_without_birds()` που επιστρέφει `TRUE` αν υπήρξε μέρα κατά την οποία μηδέν πουλιά επισκέφτηκαν τον κήπο· διαφορετικά, επέστρεψε `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο για τις πρώτες ημέρες

Υλοποίησε τη συνάρτηση `count_for_first_days()` που επιστρέφει τον αριθμό των πουλιών που έχουν επισκεφτεί τον κήπο σου από την αρχή της εβδομάδας, αλλά περιόρισε τη μέτρηση στον καθορισμένο αριθμό ημερών από την αρχή της εβδομάδας.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Κάποιες μέρες είναι πιο πολυάσχολες από άλλες. Πολυάσχολη μέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.
Υλοποίησε τη συνάρτηση `busy_days()` για να επιστρέφεις τον αριθμό των πολυάσχολων ημερών:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Υπολόγισε το τρέχον σύνολο των επισκέψεων πουλιών την τελευταία εβδομάδα

Είσαι περίεργος να μάθεις πόσα πουλιά συνολικά έχουν επισκεφτεί μέχρι στιγμής αυτή την εβδομάδα.
Υπολόγισε τα αθροιστικά σύνολα για κάθε ημέρα.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ταξινόμησε τα ονόματα των ημερών κατά το πόσο πολυάσχολες είναι

Υποψιάζεσαι ότι οι επισκέψεις των πουλιών επηρεάζονται από τα μοτίβα της κοντινής κυκλοφορίας στους δρόμους, και έτσι διαφέρουν τα σαββατοκύριακα εναντίον των καθημερινών.

Ταξινόμησε τις συντομογραφίες των ημερών σε _φθίνουσα_ σειρά ανάλογα με το πόσα πουλιά επισκέφτηκαν.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
