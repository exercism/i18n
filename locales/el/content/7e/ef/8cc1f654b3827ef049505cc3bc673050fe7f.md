# Εισαγωγή

Η R δεν διαθέτει ξεχωριστό τύπο δεδομένων για σύνολα, αλλά χρησιμοποιεί διάφορες συναρτήσεις για να εκτελεί παρόμοιες πράξεις σε διανύσματα.

Ο τελεστής `%in%` ελέγχει αν ένα στοιχείο ανήκει σε ένα σύνολο.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Στις σχετικές συναρτήσεις περιλαμβάνονται η `unique` (για την αφαίρεση των διπλότυπων), καθώς και οι `union()`, `intersect()`, `setdiff()` και `setequal()`, που εκτελούν πράξεις σε ζεύγη συνόλων.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Σε κάθε περίπτωση, οι `set_1` και `set_2` δεν αλλάζουν.
