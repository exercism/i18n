# Συναρτήσεις στο `jq`

Μπορείς να ορίσεις τις δικές σου **προσαρμοσμένες συναρτήσεις** στο `jq` για να ενθυλακώσεις όποια λογική χρειάζεσαι.
Οι _συναρτήσεις_ συμπεριφέρονται ακριβώς όπως οι ενσωματωμένες: παίρνουν μια είσοδο και παράγουν μηδέν, μία ή περισσότερες εξόδους.

## Ορισμός συνάρτησης

Μπορείς να ορίσεις μια _συνάρτηση_ `jq` με την εξής σύνταξη:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- ξεκινά με τη λέξη-κλειδί `def`,
- μια άνω κάτω τελεία πριν από το σώμα της συνάρτησης,
- το σώμα αποτελείται από μία μόνο έκφραση,
- τελειώνει με semicolon,
- όπως και στην υπόλοιπη σύνταξη του `jq`, μπορείς να χρησιμοποιήσεις όποια κενά θέλεις για αναγνωσιμότητα.

## Πού να τοποθετείς τις συναρτήσεις

Οι _συναρτήσεις_ πρέπει να ορίζονται πριν χρησιμοποιηθούν: αυτό είναι σφάλμα:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

Αυτό σημαίνει ότι πρέπει να τοποθετείς τις _συναρτήσεις_ στην αρχή του κώδικά σου σε `jq`, πριν από την "κύρια" έκφραση.

### Εμφωλευμένες συναρτήσεις

Οι _συναρτήσεις_ μπορούν να είναι εμφωλευμένες:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

Εδώ, η _συνάρτηση_ `B` είναι ορατή μόνο μέσα στο σώμα της `A`.

## Εμβέλεια

Μια _συνάρτηση_ εισάγει μια νέα **εμβέλεια** για μεταβλητές και εμφωλευμένες συναρτήσεις.

## Ορίσματα

Τα **ορίσματα** μιας _συνάρτησης_ χωρίζονται με _semicolons_, όχι με κόμματα.
Για παράδειγμα, μια _συνάρτηση_ που παίρνει έναν αριθμό, και μετά προσθέτει έναν αριθμό και πολλαπλασιάζει με έναν αριθμό:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

### Τα ορίσματα είναι _εκφράσεις_

Τα _ορίσματα_ μιας συνάρτησης είναι φίλτρα, όχι τιμές.
Υπό αυτή την έννοια, λειτουργούν σαν αυτό που άλλες γλώσσες περιγράφουν ως callbacks:

Χρησιμοποιώντας ως παράδειγμα τη συνάρτηση `add_mul`:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

Τι συμβαίνει εδώ;

- το όρισμα `adder` παίρνει την _έκφραση_ `. + 5`
  - όταν η συνάρτηση κάνει `. + adder`, αυτό γίνεται `. + . + 5`
  - αυτό αξιολογείται σε 25 αφού `. == 10`
- ομοίως, το όρισμα `multiplier` είναι η έκφραση `. - 2`
  - αυτό αξιολογείται σε 8
  - έπειτα το αποτέλεσμα είναι `25 * 8 == 200`

### Ορίσματα ως τιμές

Μερικές φορές θα θέλεις να "υλοποιήσεις" ένα _όρισμα_ σε μια μεταβλητή:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

Υπάρχει ένας συντομευμένος τρόπος για αυτό:

```jq
def my_func($arg):
    other stuff ...
;
```

Σημείωσε ότι αυτό είναι απλώς "συντακτική ζάχαρη": το όνομα `arg` χωρίς `$` εξακολουθεί να είναι στην εμβέλεια της _συνάρτησης_.

## Αριθμός ορισμάτων

Οι _συναρτήσεις_ χαρακτηρίζονται από τον **αριθμό ορισμάτων** τους, δηλαδή από το πόσα _ορίσματα_ δέχονται.

Οι _συναρτήσεις_ μπορούν να χρησιμοποιούν το ίδιο όνομα με διαφορετικό αριθμό ορισμάτων.
Η ενσωματωμένη συνάρτηση [`range`][man-range] το δείχνει αυτό: οι `range/1`, `range/2` και `range/3` συνυπάρχουν.

Αυτό μπορεί να φανεί χρήσιμο για τον ορισμό αναδρομικών συναρτήσεων που μεταφέρουν κατάσταση μέσω ορισμάτων.
Για παράδειγμα, η `map` _θα μπορούσε_ να υλοποιηθεί ως εξής:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## Αναδρομή

Το `jq` εκτελεί βελτιστοποίηση ουραίας κλήσης, αλλά μόνο για συναρτήσεις με μηδέν ορίσματα.

## Modules

Ένα _module_ του `jq` είναι ένα αρχείο που περιέχει μόνο συναρτήσεις.
Τα _modules_ περιλαμβάνονται σε ένα πρόγραμμα `jq` με τις εντολές [`include`][man-include] ή [`import`][man-import].
