# Οδηγίες

Η Elyse, μελλοντική μάγισσα, συνεχίζει την εκπαίδευσή της. Θα της δοθούν αρκετές στοίβες από κάρτες που χρειάζεται για να εκτελέσει τα κόλπα της.
Για να γίνουν τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10.

Σε αυτή την άσκηση, χρησιμοποίησε ενσωματωμένες μεθόδους για να αναλύσεις τα περιεχόμενα ενός διανύσματος.

## 1. Προσδιόρισε αν υπάρχει μια κάρτα

Η Elyse θέλει να προσδιορίσει αν μια κάρτα υπάρχει στη στοίβα, με άλλα λόγια, αν η στοίβα περιέχει έναν συγκεκριμένο αριθμό.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Βρες τη θέση μιας κάρτας

Η Elyse θέλει να μάθει τη θέση μιας κάρτας στη στοίβα.
Αν η κάρτα δεν είναι στη στοίβα, επέστρεψε `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Προσδιόρισε αν κάθε κάρτα είναι άρτια

Η Elyse θέλει να μάθει αν κάθε κάρτα είναι άρτια, με άλλα λόγια, αν κάθε αριθμός στη στοίβα είναι άρτιος.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Έλεγξε αν η στοίβα περιέχει μια κάρτα με περιττή τιμή

Η Elyse θέλει να μάθει αν υπάρχει περιττός αριθμός στη στοίβα.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Πάρε την πρώτη περιττή κάρτα από τη στοίβα

Η Elyse θέλει να μάθει την τιμή της πρώτης κάρτας που είναι περιττή.  
Αν δεν υπάρχει περιττή κάρτα στη στοίβα, επέστρεψε `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Προσδιόρισε τη θέση της πρώτης κάρτας που είναι άρτια

Η Elyse θέλει να μάθει τη θέση της πρώτης κάρτας που είναι άρτια.
Αν δεν υπάρχει άρτια κάρτα στη στοίβα, επέστρεψε `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
