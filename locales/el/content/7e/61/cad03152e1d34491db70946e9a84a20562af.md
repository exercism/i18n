# Οδηγίες

Η Elyse, μελλοντική μάγισσα, συνεχίζει την εκπαίδευσή της. Έχει μια τράπουλα που θέλει να χειριστεί.

Για να κάνει τα πράγματα πιο εύκολα, συνήθως ξεκινά μόνο με κάρτες με αριθμούς από το 1 έως το 10, αν και μερικά από τα κόλπα μπορεί να περιλαμβάνουν επιπλέον κάρτες.

## 1. Πάρε την πρώτη κάρτα

Η Elyse θα κάνει να εμφανιστεί η πρώτη κάρτα της τράπουλας, χωρίς να χρησιμοποιήσει τη θέση της ή το `first`. Είναι ακριβώς σαν μαγεία.

```clojure
(def deck [5 9 7 1 8])

(first-card deck)
;=> 5
```

## 2. Πάρε τη δεύτερη κάρτα

Η Elyse κάνει ένα ταχυδακτυλουργικό κόλπο και κάνει να εμφανιστεί η δεύτερη κάρτα της τράπουλας, χωρίς να χρησιμοποιήσει τη θέση της ή το `second`.

```clojure
(def deck [3 2 10 6 7])

(second-card deck)
;=> 2
```

## 3. Αντάλλαξε τις δύο πρώτες κάρτες

Η Elyse θα κάνει τις δύο πάνω κάρτες της τράπουλας να αλλάξουν θέση. Δεν χρειάζεται να καλέσει ούτε μία συνάρτηση.

```clojure
(def deck [10 7 3 8 5])

(swap-top-two-cards deck)
;=> [7 10 3 8 5]
```

## 4. Πέταξε την πάνω κάρτα

Η Elyse θα χωρίσει την τράπουλα σε δύο στοίβες. Η πρώτη στοίβα θα περιέχει μόνο την πάνω κάρτα της αρχικής τράπουλας, ενώ η δεύτερη στοίβα θα περιέχει όλες τις άλλες κάρτες.

```clojure
(def deck [2 5 4 9 3])

(discard-top-card deck)
;=> [2 [5 4 9 3]]
```

## 5. Βάλε κάρτες με φιγούρες

Η Elyse θα βάλει ένα σύνολο από κάρτες με φιγούρες (δηλαδή βαλές, ντάμα και ρήγας) στην τράπουλα, έτσι ώστε να γίνουν η δεύτερη, η τρίτη και η τέταρτη κάρτα αντίστοιχα.

```clojure
(def deck [5 4 7 10])

(insert-face-cards deck)
;=> [5 "jack" "queen" "king" 4 7 10]
```
