# Εκτέλεση των τεστ

Με εγκατεστημένο το `sbt`, μπορείς να εκτελέσεις τα τεστ από τη γραμμή εντολών με:

```bash
$ sbt test
```

Σημείωσε ότι το να εκτελείς το `sbt test` κάθε φορά θα είναι αργό, καθώς το `sbt` θα αρχικοποιείται ξανά σε κάθε κλήση.

Το `sbt` λειτουργεί σαν κέλυφος. Μόλις ξεκινήσει, μπορείς να τρέξεις εντολές μέσα του.

Για παράδειγμα, μπορείς να χρησιμοποιήσεις το `sbt` για να ξανατρέχεις τα τεστ σου κάθε φορά που αλλάζουν τα αρχεία πηγαίου κώδικα:
```bash
$ sbt
>~ test
```

Σημείωσε ότι όλα τα τεστ έχουν απενεργοποιηθεί εκτός από το πρώτο, ώστε να δουλέψεις πάνω σε αυτό.
Για να συνεχίσεις, απλώς αφαίρεσε τη λέξη-κλειδί `pending` από την αρχή κάθε τεστ.

Πήγαινε [εδώ](https://www.scala-sbt.org/) για να μάθεις περισσότερα για το `sbt`.


Τα τεστ μπορούν επίσης να εκτελεστούν μέσα στα παρακάτω ολοκληρωμένα περιβάλλοντα ανάπτυξης

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA με το Scala Plugin](https://www.jetbrains.com/idea/)
