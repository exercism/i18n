# `case`

[`case`][case] (συχνά αναφέρεται ως switch σε άλλες γλώσσες) είναι μια μορφή έκφρασης ελέγχου, όπως το if-else.
Το `case` επιτρέπει την αλυσιδωτή σύνδεση πολλαπλών εντολών if-else-if, μπορεί να είναι πιο ευανάγνωστο και επιτρέπει ισχυρές κατασκευές.

Ένα `case` ορίζεται από τη λέξη-κλειδί `case`, που ακολουθείται από μια προαιρετική έκφραση.
Στη συνέχεια, για κάθε περίπτωση, χρησιμοποιείται η λέξη-κλειδί `when`, που ακολουθείται από μια έκφραση η οποία συγκρίνεται με την έκφραση του `case`.
Η λέξη-κλειδί `when` δεν πρέπει να έχει εσοχή σε σχέση με τη λέξη-κλειδί `case`.
Μετά τη λέξη-κλειδί `when` βρίσκεται ο κώδικας που πρέπει να εκτελεστεί αν η έκφραση του `case` ταιριάζει με την έκφραση του `when`.
Το `case` επιτρέπει μια προαιρετική εντολή `else`, η οποία εκτελείται αν δεν ταιριάζει καμία άλλη περίπτωση.

Η έκφραση του `case` αξιολογείται και στη συνέχεια συγκρίνεται με κάθε έκφραση του `when`.
Η σύγκριση γίνεται με τον [τελεστή υπαγωγής περιπτώσεων (`===`)][case-subsumption].

```Crystal
case 1
when 1
  puts "One"
when 2
  puts "Two"
else
  puts "Other"
end
# => One

# This is the same as:
tmp = 1
if 1 === tmp
  puts "One"
elsif 2 === tmp
  puts "Two"
else
  puts "Other"
end
```

## Ο τελεστής υπαγωγής περιπτώσεων (`===`)

Ο τελεστής υπαγωγής περιπτώσεων (`===`) είναι λίγο διαφορετικός από τον τελεστή ισότητας (`==`).
Ο τελεστής ελέγχει αν η δεξιά πλευρά είναι μέλος του συνόλου που περιγράφει η αριστερή πλευρά.
Αυτό σημαίνει ότι έχει σημασία πού τοποθετείται κάθε τελεστέος.
Το πώς λειτουργεί αυτό εξαρτάται από τον τύπο της αριστερής πλευράς· για παράδειγμα, ένα `Range` θα ελέγξει αν η δεξιά πλευρά βρίσκεται μέσα στο εύρος, ή ένα `Object` θα ελέγξει αν η δεξιά πλευρά είναι στιγμιότυπο του `Object`.

```Crystal
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## `case` με πολλαπλές εκφράσεις

Το `case` επιτρέπει να ταιριάξεις πολλαπλές εκφράσεις σε ένα μόνο `case`, με κάθε πιθανή τιμή χωρισμένη με κόμμα.
Θα εκτελέσει τον κώδικα αν ταιριάζει έστω και μία από τις εκφράσεις.
Αυτό μπορεί να φανεί χρήσιμο για ένα μόνο `case` με πολλαπλές πιθανές τιμές.

```Crystal
case 1
when 1, 2
  puts "One or two"
else
  puts "Other"
end
```

## `case` με εύρη

Το `case` μπορεί επίσης να ελέγξει αν μια τιμή βρίσκεται μέσα σε ένα εύρος.
Αυτό γίνεται χρησιμοποιώντας ένα εύρος ως έκφραση του `when`.

```Crystal
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## `case` χωρίς έκφραση `case`

Όταν δεν χρειάζεται έκφραση `case`, μπορείς να την παραλείψεις.
Με αυτόν τον τρόπο, κάθε έκφραση του `when` αξιολογείται ως προς την αλήθεια της.
Και τις κάνει να συμπεριφέρονται σαν εντολές if-else-if.

```Crystal
case
when 1 == 1
  puts "One is equal to one"
when 1 > 2
  puts "One is greater than two"
else
  puts "Other"
end
```

## `when` σε μία γραμμή

Η Crystal επιτρέπει εντολές `case` σε μία γραμμή.
Αυτό μπορεί να χρησιμοποιηθεί όταν έχεις μια απλή εντολή μίας γραμμής.
Το `when` σε μία γραμμή γράφεται ως `when <expression> then <statement>.`
Και όταν χρησιμοποιείται στην εντολή `else`, γράφεται ως `else <statement>`.

```Crystal
case var
when 1 then puts "One"
when 2 then puts "Two"
else puts "Other"
end
```

## `case` με τύπους

Το `case` επιτρέπει το ταίριασμα με τύπους.
Η σύγκριση θα χρησιμοποιήσει τον τελεστή `is_a?` για να ελέγξει τον τύπο της μεταβλητής.
Για παράδειγμα, αυτό επιτρέπει έναν κλάδο για κάθε τύπο σε έναν τύπο ένωσης.

```Crystal
case var
when Int32
  puts "Int32"
when String
  puts "String"
else
  puts "Other"
end
```

## Σιωπηρό αντικείμενο

Το `case` επιτρέπει τη χρήση ενός σιωπηρού αντικειμένου.
Αυτό επιτρέπει, για παράδειγμα, μια έκφραση `when` να είναι κλήση μεθόδου πάνω στην έκφραση του `case`.
Ανάλογα με το αν η μέθοδος επιστρέφει μια τιμή που θεωρείται αληθής ή ψευδής, το `case` θα ταιριάξει ή όχι.

```Crystal
case 1
when .odd?
  puts "Odd"
when .even?
  puts "Even"
end
```
