# Εισαγωγή

Στη Common Lisp, μια συνάρτηση μπορεί να έχει ονομαστικές παραμέτρους (που αναφέρονται ως "παράμετροι λέξεων-κλειδιών").
Αυτές δηλώνονται στη λίστα lambda με τη λέξη-κλειδί `&key` της λίστας lambda.
Οι παράμετροι λέξεων-κλειδιών δεν είναι υποχρεωτικές παράμετροι.
Όπως οι προαιρετικές παράμετροι, μπορούν να πάρουν προεπιλεγμένες τιμές και σύμβολα στα οποία δεσμεύεται η κατάσταση «δόθηκε ή όχι».

Όταν καλείς μια συνάρτηση με παραμέτρους λέξεων-κλειδιών, το όνομα της παραμέτρου ως λέξη-κλειδί χρησιμοποιείται μπροστά από την τιμή της παραμέτρου.
Ο καλών της συνάρτησης μπορεί να δώσει τις παραμέτρους λέξεων-κλειδιών με οποιαδήποτε σειρά.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Χρειάζεται προσοχή όταν συνδυάζεις προαιρετικές παραμέτρους με παραμέτρους λέξεων-κλειδιών, γιατί το όνομα της λέξης-κλειδιού και το όρισμα μπορεί να καταναλωθούν από τις προαιρετικές παραμέτρους:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
