# Εισαγωγή

Όταν δουλεύεις με αντικείμενα `java.time` όπως το `LocalDate`, συχνά χρειάζεται να κάνεις σύνθετες προσαρμογές ημερομηνιών, όπως να βρεις τη "δεύτερη Τρίτη του μήνα".
Αντί να το υπολογίσεις με το χέρι, μπορείς να χρησιμοποιήσεις τους **`TemporalAdjusters`**.

Η βοηθητική κλάση `java.time.temporal.TemporalAdjusters` (πρόσεξε το τελικό 's' στον πληθυντικό) παρέχει στατικές μεθόδους για πολλές συνηθισμένες προσαρμογές ημερομηνιών.
Τις προσαρμογές αυτές τις εφαρμόζεις με τη μέθοδο `.with()` σε ένα χρονικό αντικείμενο (όπως το `LocalDate`).

```exercism/note
Η χρήση του `with(TemporalAdjuster)` επιστρέφει ένα _νέο_ στιγμιότυπο και δεν ενημερώνει το υπάρχον, αφού τα αντικείμενα του `java.time` είναι αμετάβλητα.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster: find the last day of the month
LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31
```

Ακολουθούν μερικοί βασικοί προσαρμοστές που είναι χρήσιμοι για υπολογισμούς προγραμματισμού:

## Εύρεση της νιοστής εμφάνισης μιας ημέρας της εβδομάδας

Χρησιμοποίησε το `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` για να βρεις τη νιοστή εμφάνιση μιας ημέρας της εβδομάδας.

```java
// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13
```

## Εύρεση της πρώτης/τελευταίας εμφάνισης ημέρας της εβδομάδας στον μήνα

Χρησιμοποίησε το `firstInMonth(DayOfWeek dayOfWeek)` ή το `lastInMonth(DayOfWeek dayOfWeek)`.

```java
// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

## Σχετικές προσαρμογές (επόμενη/προηγούμενη)

Προσαρμοστές όπως οι `next()`, `previous()`, `nextOrSame()` και `previousOrSame()` βρίσκουν την επόμενη ή την προηγούμενη εμφάνιση μιας δεδομένης ημέρας της εβδομάδας, σε σχέση με την τρέχουσα ημερομηνία.

- `next()`/`previous()`: Εξαιρούν την τρέχουσα ημερομηνία αν ταιριάζει.
- `nextOrSame()`/`previousOrSame()`: Περιλαμβάνουν την τρέχουσα ημερομηνία αν ταιριάζει.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Δικοί σου προσαρμοστές

Το `TemporalAdjuster` είναι ένα functional interface, οπότε μπορείς να γράψεις τον δικό σου προσαρμοστή ως lambda που παίρνει το χρονικό αντικείμενο προς προσαρμογή και επιστρέφει το προσαρμοσμένο.
Εφαρμόζεται με το `.with()` ακριβώς όπως οι προκαθορισμένοι προσαρμοστές και μπορεί να τους χρησιμοποιεί εσωτερικά.

```java
import java.time.temporal.TemporalAdjuster;

// An adjuster that moves a weekend date to the following Monday
TemporalAdjuster skipWeekend = temporal -> {
    DayOfWeek day = DayOfWeek.from(temporal);
    if (day == DayOfWeek.SATURDAY || day == DayOfWeek.SUNDAY) {
        return temporal.with(TemporalAdjusters.next(DayOfWeek.MONDAY));
    }
    return temporal;
};

LocalDate saturday = LocalDate.of(2024, Month.AUGUST, 17);
LocalDate monday = saturday.with(skipWeekend);
// => 2024-08-19
```

Η χρήση αυτών των προσαρμοστών από την κλάση `TemporalAdjusters` μπορεί να απλοποιήσει πολύ τις εργασίες χειρισμού ημερομηνιών.
