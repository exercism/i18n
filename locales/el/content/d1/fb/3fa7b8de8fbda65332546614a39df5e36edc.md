# Παράρτημα οδηγιών

## Υποδείξεις

Πρέπει να υλοποιήσεις τη συνάρτηση `responseFor` που επιστρέφει την απάντηση του Bob
για μια δεδομένη είσοδο. Μπορείς να χρησιμοποιήσεις την υπογραφή που δίνεται αν δεν είσαι σίγουρος
για τους τύπους, αλλά μην την αφήσεις να περιορίσει τη δημιουργικότητά σου:

```haskell
responseFor :: String -> String
```

Για να λύσεις αυτή την άσκηση, μπορείς να διαβάσεις σχετικά με:

- [Φρουρούς][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

Αυτή η άσκηση δουλεύει με κειμενικά δεδομένα. Για ιστορικούς λόγους, ο τύπος `String` της
Haskell είναι συνώνυμος με τον `[Char]`, δηλαδή μια λίστα χαρακτήρων. Για πιο
αποδοτικό χειρισμό κειμενικών δεδομένων, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς

- Διάβασε για [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη Haskell.
- Πρόσθεσε το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- Εισήγαγε το `Data.Text` με [τον ακόλουθο τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- Μπορείς τώρα να γράψεις π.χ. `responseFor :: Text -> Text` και να αναφερθείς στους συνδυαστές του `Data.Text` ως π.χ. `T.isSuffixOf`.
- Δες την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Μπορείς μετά να αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο Bob.hs:

    ```haskell
    responseFor :: Text -> Text
    ```

Αυτό το μέρος είναι εντελώς προαιρετικό.
