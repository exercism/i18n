# Συνεισφορά στο Exercism

Αυτό το τμήμα της τεκμηρίωσης εξετάζει πώς μπορείς να συνεισφέρεις στο Exercism.
Περιέχει πληροφορίες και προδιαγραφές για όλους τους διάφορους τομείς του Exercism, καθώς και οδηγούς για πράγματα όπως το πώς γίνεσαι συντηρητής και το πώς διαλέγεις μια ιστορία για μια άσκηση.

Για να πάρεις μια ιδέα για το πού θα μπορούσες να βοηθήσεις, ρίξε μια ματιά στη [λίστα εργασιών][tasks] μας.

Οι συνεισφορές στη βάση κώδικα γίνονται μέσω [GitHub][github].

[tasks]: https://exercism.org/contributing/tasks
[github]: /docs/building/github
