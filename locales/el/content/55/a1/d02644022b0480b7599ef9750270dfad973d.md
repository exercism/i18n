# Γενικά

[Ο οδηγός για τις συγκρίσεις στην Python][python comparisons tutorial] και τα [παραδείγματα συγκρίσεων στην Python][python comparisons examples] αποτελούν μια εξαιρετική εισαγωγή που καλύπτει το περιεχόμενο αυτής της άσκησης.

## 1. Υπολόγισε την τιμή ενός φύλλου

- Μπορείς να χρησιμοποιήσεις τον τελεστή σύγκρισης ισότητας `==` για να διαπιστώσεις αν ένα φύλλο είναι άσσος: `card == 'A'`.
- Μπορείς να χρησιμοποιήσεις τον τελεστή περιεκτικότητας `in` για να διαπιστώσεις αν μια υποσυμβολοσειρά περιέχεται μέσα σε μια συμβολοσειρά: `'Q' in 'KJQ'`.
- Μπορείς να χρησιμοποιήσεις τον [κατασκευαστή `int`][int constructor] για να μετατρέψεις ένα `str` που αναπαριστά ένα `int` σε `int`: `int('13')`.

## 2. Προσδιόρισε ποιο φύλλο έχει μεγαλύτερη τιμή

- Αφού ορίσεις τη συνάρτηση `value_of_card`, μπορείς να την καλέσεις από άλλες συναρτήσεις.
- Μπορείς να χρησιμοποιήσεις τους τελεστές σύγκρισης τιμών `>` και `<` για να διαπιστώσεις αν συγκεκριμένα φύλλα είναι _μεγαλύτερα από_ ή _μικρότερα από_ μια δεδομένη τιμή: `3 < 12`.
- Μπορείς να χρησιμοποιήσεις τον τελεστή σύγκρισης ισότητας `==` για να διαπιστώσεις αν δύο τιμές είναι ίσες μεταξύ τους.

## 3. Υπολόγισε την τιμή ενός άσσου

- Αφού ορίσεις τη συνάρτηση `value_of_card`, μπορείς να την καλέσεις από άλλες συναρτήσεις.
- Μπορείς να χρησιμοποιήσεις τον τελεστή σύγκρισης διάταξης `>` για να αποφασίσεις την κατάλληλη ενέργεια εδώ.

## 4. Προσδιόρισε το Μπλακτζάκ

- Θυμήσου ότι μπορείς να χρησιμοποιήσεις τη [σύνταξη `if`/`elif`/`else`][if syntax] για να χειριστείς διαφορετικούς συνδυασμούς φύλλων.
- Μπορείς να συνδυάσεις ΚΑΙ τους τελεστές σύγκρισης ΚΑΙ τους τελεστές boolean _αυθαίρετα_: `y < z < x` ή `(y or z) and (x or z)`
- Μπορείς να ξαναχρησιμοποιήσεις τη συνάρτηση `value_of_card` που έχεις ήδη υλοποιήσει.

## 5. Χωρισμός ζευγαριών

- Μπορείς να ξαναχρησιμοποιήσεις τη συνάρτηση `value_of_card` που έχεις ήδη υλοποιήσει.
- Μπορείς να χειριστείς ξεχωριστά την περίπτωση του `A` (όταν τουλάχιστον ένα από τα φύλλα είναι άσσος).

## 6. Διπλασιασμός του πονταρίσματος

- Ένας `A` που μετράει 11 δε θα επιτρέψει ποτέ τον διπλασιασμό αν στο χέρι υπάρχουν δύο φύλλα.
- Δεδομένου του πρώτου σημείου, _θα πρέπει_ να μπορείς να ξαναχρησιμοποιήσεις τη συνάρτηση `value_of_card` που έχεις ήδη υλοποιήσει.
- Μπορείς να συνδυάσεις τελεστές σύγκρισης _αυθαίρετα_: `y < z < x`.
- Μπορείς να χρησιμοποιήσεις την [υπό συνθήκη έκφραση][conditional expression] (_που μερικές φορές ονομάζεται "τριμερής τελεστής"_)
  για να συντομεύσεις απλές εντολές `if`/`else`: `13 if letter == 'M' else 3`.
