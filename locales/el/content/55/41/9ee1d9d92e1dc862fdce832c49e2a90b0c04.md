# Εισαγωγή

## Εμφωλευμένοι τύποι

Οι τύποι C# μπορούν να οριστούν μέσα στο πεδίο εμβέλειας μιας κλάσης ή struct. Ο περικλείων τύπος παρέχει ένα είδος χώρου ονομάτων. Η πρόσβαση στον τύπο γίνεται μέσω του περικλείοντος τύπου με σύνταξη τελείας.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Μπορείς να ορίσεις επίπεδα πρόσβασης για τους εσωτερικούς τύπους.

Τα ιδιωτικά μέλη του εξωτερικού τύπου βρίσκονται στο πεδίο εμβέλειας των μελών του εσωτερικού τύπου, αλλά όχι το αντίστροφο.
