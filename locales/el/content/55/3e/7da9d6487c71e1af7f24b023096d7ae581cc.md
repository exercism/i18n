# Υποδείξεις

## Γενικά

- [Οδηγός για την εργασία με απαριθμήσεις][docs.microsoft.com-enumeration-types].

## 1. Ανάλυσε το επίπεδο καταγραφής

- Υπάρχει μια [μέθοδος για να πάρεις ένα μέρος μιας συμβολοσειράς][docs.microsoft.com_system_string_substring].
- Μπορείς να χρησιμοποιήσεις μια [εντολή `switch`][docs.microsoft.com_keyword_switch] για να χειριστείς με κομψό τρόπο τα διάφορα επίπεδα καταγραφής.

## 2. Υποστήριξε άγνωστο επίπεδο καταγραφής

- Υπάρχει μια [ειδική περίπτωση switch][docs.microsoft.com_keyword_switch_default] που μπορεί να χρησιμοποιηθεί για να πιάσει περιπτώσεις που δεν έχουν προσδιοριστεί.

## 3. Μετέτρεψε τη γραμμή καταγραφής σε σύντομη μορφή

- Μπορείς να [εκχωρήσεις συγκεκριμένες τιμές σε μέλη απαρίθμησης][docs.microsoft.com_creating-an-enumeration-type].
- Η μετατροπή μιας απαρίθμησης σε αριθμό μπορεί να γίνει μέσω [μετατροπής τύπου][docs.microsoft.com_enumeration-types-casting] ή χρησιμοποιώντας μια [συμβολοσειρά μορφοποίησης][docs.microsoft.com_system.enum.tostring].
