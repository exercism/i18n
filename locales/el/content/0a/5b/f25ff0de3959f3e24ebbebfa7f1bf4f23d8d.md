# Οδηγίες

Η Chaitana έχει ένα πολύ δημοφιλές λουναπάρκ.
 Έχει μόνο ένα παιχνίδι, στο κέντρο ακριβώς ενός πανέμορφα διαμορφωμένου χώρου: το The Biggest Roller Coaster in the World(TM).
 Αν και υπάρχει μόνο αυτό το αξιοθέατο, άνθρωποι ταξιδεύουν από όλο τον κόσμο και στέκονται στην ουρά για ώρες για να έχουν την ευκαιρία να κάνουν βόλτα στο υπερ-κόστερ της Chaitana.

Υπάρχουν δύο ουρές για αυτό το παιχνίδι, καθεμία από τις οποίες αναπαρίσταται ως `list`:

1. Κανονική ουρά
2. Ουρά εξπρές (_γνωστή και ως Fast-track_), όπου οι άνθρωποι πληρώνουν επιπλέον για πρόσβαση κατά προτεραιότητα.


Σου ζητήθηκε να γράψεις κώδικα για να διαχειρίζεσαι καλύτερα τους επισκέπτες του πάρκου.
 Πρέπει να υλοποιήσεις τις παρακάτω συναρτήσεις όσο το δυνατόν πιο γρήγορα, πριν οι επισκέπτες (και το αφεντικό σου, η Chaitana!) αρχίσουν να γκρινιάζουν.
 Φρόντισε να διαβάσεις προσεκτικά.
 Κάποιες εργασίες σου ζητούν να αλλάξεις ή να ενημερώσεις την υπάρχουσα ουρά, ενώ άλλες σου ζητούν να φτιάξεις ένα αντίγραφό της.


## 1. Πρόσθεσέ με στην ουρά

Όρισε τη συνάρτηση `add_me_to_the_queue()` που παίρνει 4 παραμέτρους `<express_queue>, <normal_queue>, <ticket_type>, <person_name>` και επιστρέφει την κατάλληλη ουρά, ενημερωμένη με το όνομα του ατόμου.


1. Το `<ticket_type>` είναι ένα `int` με 1 == express_queue και 0 == normal_queue.
2. Το `<person_name>` είναι το όνομα (ως `str`) του ατόμου που θα προστεθεί στην αντίστοιχη ουρά.


```python
>>> add_me_to_the_queue(express_queue=["Tony", "Bruce"], normal_queue=["RobotGuy", "WW"], ticket_type=1, person_name="RichieRich")
...
["Tony", "Bruce", "RichieRich"]

>>> add_me_to_the_queue(express_queue=["Tony", "Bruce"], normal_queue=["RobotGuy", "WW"], ticket_type=0, person_name="HawkEye")
....
["RobotGuy", "WW", "HawkEye"]
```

## 2. Πού είναι οι φίλοι μου;

Ένα άτομο έφτασε αργά στο πάρκο, αλλά θέλει να μπει στην ουρά όπου περιμένουν οι φίλοι του.
 Ωστόσο, δεν έχει ιδέα πού στέκονται οι φίλοι του και δεν υπάρχει σήμα κινητού για να τους πάρει τηλέφωνο.

Όρισε τη συνάρτηση `find_my_friend()` που παίρνει 2 παραμέτρους, `queue` και `friend_name`, και επιστρέφει τη θέση στην ουρά του ονόματος του ατόμου.


1. Το `<queue>` είναι η `list` με τα άτομα που στέκονται στην ουρά.
2. Το `<friend_name>` είναι το όνομα του φίλου του οποίου τη θέση (τη σειρά στην ουρά) πρέπει να βρεις.

Θυμήσου:  Η αρίθμηση των θέσεων ξεκινά από το 0 από τα αριστερά και από το -1 από τα δεξιά.


```python
>>> find_my_friend(queue=["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], friend_name="Steve")
...
1
```


## 3. Μπορώ να μπω μαζί τους;

Τώρα που βρέθηκαν οι φίλοι του (στην εργασία #2 παραπάνω), αυτός που ήρθε αργά θα ήθελε να μπει μαζί τους, στη θέση τους στην ουρά.
Όρισε τη συνάρτηση `add_me_with_my_friends()` που παίρνει 3 παραμέτρους, `queue`, `index` και `person_name`.


1. Το `<queue>` είναι η `list` με τα άτομα που στέκονται στην ουρά.
2. Το `<index>` είναι η θέση στην οποία πρέπει να προστεθεί το νέο άτομο.
3. Το `<person_name>` είναι το όνομα του ατόμου που θα προστεθεί στη θέση index.

Επίστρεψε την ουρά, ενημερωμένη με το όνομα αυτού που ήρθε αργά.


```python
>>> add_me_with_my_friends(queue=["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], index=1, person_name="Bucky")
...
["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. Ένας κακός άνθρωπος στην ουρά

Μόλις άκουσες από την ουρά ότι υπάρχει ένας πολύ κακός άνθρωπος που σπρώχνει, φωνάζει και δημιουργεί προβλήματα.
 Πρέπει να πετάξεις έξω αυτόν τον ταραξία για την κακή του συμπεριφορά!


Όρισε τη συνάρτηση `remove_the_mean_person()` που παίρνει 2 παραμέτρους, `queue` και `person_name`.


1. Το `<queue>` είναι η `list` με τα άτομα που στέκονται στην ουρά.
2. Το `<person_name>` είναι το όνομα του ατόμου που πρέπει να πεταχτεί έξω.

Επίστρεψε την ουρά, ενημερωμένη χωρίς το όνομα του κακού ανθρώπου.

```python
>>> remove_the_mean_person(queue=["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], person_name="Eltran")
...
["Natasha", "Steve", "Wanda", "Rocket"]
```


## 5. Συνονόματοι

Μπορεί να μην έχεις δει δύο άσχετους ανθρώπους που μοιάζουν ακριβώς ίδιοι, αλλά _σίγουρα_ έχεις δει άσχετους ανθρώπους με το ίδιο ακριβώς όνομα (_συνονόματους_)!
 Σήμερα, φαίνεται ότι υπάρχουν πολλοί από αυτούς στο πάρκο.
  Θέλεις να μάθεις πόσες φορές εμφανίζεται ένα συγκεκριμένο όνομα στην ουρά.

Όρισε τη συνάρτηση `how_many_namefellows()` που παίρνει 2 παραμέτρους, `queue` και `person_name`.

1. Το `<queue>` είναι η `list` με τα άτομα που στέκονται στην ουρά.
2. Το `<person_name>` είναι το όνομα που πιστεύεις ότι μπορεί να εμφανίζεται πάνω από μία φορά στην ουρά.


Επίστρεψε τον αριθμό των εμφανίσεων του `person_name`, ως `int`.


```python
>>> how_many_namefellows(queue=["Natasha", "Steve", "Eltran", "Natasha", "Rocket"], person_name="Natasha")
...
2
```

## 6. Αφαίρεσε το τελευταίο άτομο

Δυστυχώς, σήμερα το πάρκο είναι υπερπλήρες και πρέπει να αφαιρέσεις το τελευταίο άτομο από την κανονική ουρά (_θα του δώσεις ένα κουπόνι για να έρθει ξανά στην ουρά εξπρές κάποια άλλη μέρα_).
 Θα πρέπει να ορίσεις τη συνάρτηση `remove_the_last_person()` που παίρνει 1 παράμετρο, το `queue`, που είναι η λίστα με τα άτομα που στέκονται στην ουρά.

Πρέπει να ενημερώσεις τη `list` και επίσης να `return` το όνομα του ατόμου που αφαιρέθηκε, ώστε να μπορέσεις να του γράψεις ένα κουπόνι.


```python
>>> remove_the_last_person(queue=["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
...
'Rocket'
```

## 7. Ταξινόμησε τη λίστα της ουράς

Για διοικητικούς σκοπούς, πρέπει να βάλεις όλα τα ονόματα μιας δεδομένης ουράς σε αλφαβητική σειρά.


Όρισε τη συνάρτηση `sorted_names()` που παίρνει 1 όρισμα, το `queue`, (τη `list` με τα άτομα που στέκονται στην ουρά), και επιστρέφει ένα `sorted` αντίγραφο της `list`.


```python
>>> sorted_names(queue=["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
...
['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
