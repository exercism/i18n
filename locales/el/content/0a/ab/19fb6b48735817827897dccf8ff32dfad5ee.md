# Υποδείξεις

## Γενικά

- Το `*T` μπορεί να χρησιμοποιηθεί για να δηλώσεις μεταβλητές που είναι δείκτες σε κάποιον τύπο `T`, π.χ. το `var i *int` δηλώνει μια μεταβλητή `i` που είναι δείκτης σε ένα `int`
- Μπορείς να πάρεις έναν δείκτη σε μια μεταβλητή (τη διεύθυνση μνήμης της) χρησιμοποιώντας τον τελεστή `&`, π.χ. `mypointer := &anIntVariable`.
- Μπορείς να πάρεις την τιμή που είναι αποθηκευμένη σε έναν δείκτη χρησιμοποιώντας τον τελεστή `*` πάνω σε έναν δείκτη, π.χ. `var i int = *aPointerToInt`.
  Αυτό λέγεται αποαναφορά του δείκτη.
- Ελέγχεις ότι ένας δείκτης δεν είναι `nil` πριν τον αποαναφέρεις.
  Αν προσπαθήσεις να αποαναφέρεις έναν δείκτη `nil`, θα πάρεις σφάλμα χρόνου εκτέλεσης.
- Αν δεν έχεις ξεκάθαρη εικόνα για το πώς λειτουργούν οι δείκτες, δοκίμασε να διαβάσεις το [Tour of Go: Pointers][go-tour-pointers] ή το [Go by Example: Pointers][go-by-example-pointers]

## 1. Δημιούργησε έναν μετρητή ψήφων

- Πρέπει να δημιουργήσεις έναν δείκτη σε ένα `int`, με άλλα λόγια, έναν `*int`.
- Μπορείς να χρησιμοποιήσεις τον τελεστή `&` σε μια μεταβλητή για να δημιουργήσεις δείκτη προς αυτήν, π.χ. `&myInt`
- Μπορείς να δημιουργήσεις δείκτη σε μια νέα μεταβλητή που ορίζεις εσύ, ή μπορείς να χρησιμοποιήσεις τη μεταβλητή του ορίσματος της συνάρτησης

## 2. Πάρε τον αριθμό των ψήφων από έναν μετρητή

- Μπορείς να χρησιμοποιήσεις τον τελεστή `*` σε έναν δείκτη για να τον αποαναφέρεις και να πάρεις την τιμή του, π.χ. `*myPointer`
- Η αποαναφορά δεικτών `nil` θα σου δώσει σφάλμα χρόνου εκτέλεσης.
  Να βεβαιώνεσαι πάντα ότι ένας δείκτης δεν είναι `nil` πριν τον αποαναφέρεις.

## 3. Αύξησε τις ψήφους ενός μετρητή

- Αν έχεις έναν δείκτη `var myPointer *int`, μπορείς να αναθέσεις στο `*myPointer` για να αλλάξεις την τιμή στην οποία δείχνει ο `myPointer`
- Για να πάρεις την τρέχουσα τιμή του δείκτη, πρέπει να τον αποαναφέρεις χρησιμοποιώντας τον τελεστή `*`, ή να καλέσεις τη συνάρτηση που έφτιαξες στην προηγούμενη εργασία.

## 4. Δημιούργησε τα αποτελέσματα των εκλογών

- Δημιούργησε ένα νέο `ElectionResult` ως literal ή ως μεταβλητή, με τα πεδία `Name` και `Votes` συμπληρωμένα με τις τιμές των ορισμάτων της συνάρτησης.
- Μπορείς να δημιουργήσεις δείκτη από μια μεταβλητή ή ένα literal χρησιμοποιώντας τον τελεστή `&` πριν από το όνομα της μεταβλητής/τη δήλωση του literal, π.χ. `&myVariable` ή `&ElectionResult{Name: "John", Votes: 1}`

## 5. Ανακοίνωσε τα αποτελέσματα

- Αν και λαμβάνεις έναν δείκτη σε ένα `ElectionResult`, μπορείς να προσπελάσεις τα πεδία του με τον συμβολισμό της τελείας `.`, σαν να μην ήταν δείκτης!
- Φτιάξε το μήνυμα προσπελαύνοντας τα πεδία `Name` και `Value` του struct.
- Ακόμα κι αν προσπελαύνεις πεδία από έναν δείκτη σε struct, δε χρειάζεται να κάνεις καμία αποαναφορά.
  Η Go θα αποαναφέρει αυτόματα τον δείκτη για σένα, όπως στο παρακάτω παράδειγμα:

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. Επανκαταμέτρηση ψήφων

- Μπορείς να σκεφτείς τα map σαν να είναι ήδη δείκτες.
  Αυτό σημαίνει ότι οι αλλαγές που κάνεις στο map μέσα στη συνάρτηση θα είναι ορατές και έξω από τη συνάρτηση.
- Για να αυξήσεις την τιμή ενός κλειδιού σε ένα `var m map[string]int`, έχεις αρκετές επιλογές: `m["mykey"] = m["mykey"] + 1`, `m["mykey"] += 1` ή `m["mykey"]++`.
