# Σειρά σχολιασμών συνάρτησης

Κατά σύμβαση, οι σχολιασμοί `@doc` πρέπει να μπαίνουν πριν από τους σχολιασμούς `@spec`, και οι σχολιασμοί `@spec` αμέσως πριν από τη συνάρτηση. Αν η συνάρτηση έχει πολλαπλές ρήτρες, οι σχολιασμοί της συνάρτησης πρέπει να μπαίνουν πριν από την πρώτη ρήτρα.

Παράδειγμα:

```elixir
@doc """
This function counts the number elements in a list
"""
@spec count(list(any())) :: integer()
def count([]), do: 0
def count([h | t]), do: 1 + count(t)
```
