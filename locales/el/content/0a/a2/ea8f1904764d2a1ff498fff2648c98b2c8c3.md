# Προσθήκη στις οδηγίες

Θα πρέπει να υλοποιήσεις αυτή την άσκηση χρησιμοποιώντας μια γραμματική οριστικών προτάσεων (DGC).
Οι DCG μπορούν να χρησιμοποιηθούν όχι μόνο για την ανάλυση ακολουθιών (λιστών), αλλά και για τη δημιουργία, τη συμπλήρωση και τον έλεγχο αυτών των ακολουθιών.

## Βιβλιοθήκη

Τα αρχεία υλοποίησης stub περιλαμβάνουν την ακόλουθη γραμμή:

```prolog
:- use_module(library(dcg/basics)).
```

Αυτό διασφαλίζει ότι η βιβλιοθήκη `dcg/basics` μπορεί να χρησιμοποιηθεί, κάτι που θα πρέπει να αρκεί για να λύσεις αυτή την άσκηση.
