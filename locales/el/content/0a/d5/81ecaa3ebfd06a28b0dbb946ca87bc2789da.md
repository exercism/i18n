# Αποσφαλμάτωση στο `jq`

Το `jq` διαθέτει ένα εύχρηστο φίλτρο [`debug`][debug].
Χρησιμοποίησέ το όσο αναπτύσσεις τις λύσεις των ασκήσεών σου για να επιθεωρήσεις τα δεδομένα που βρίσκονται αυτή τη στιγμή στο pipeline του jq.
Δες το [έγγραφο αποσφαλμάτωσης][debugging] για περισσότερες λεπτομέρειες.

[debug]: https://jqlang.org/manual/#debug
[debugging]: https://exercism.org/docs/tracks/jq/debugging
