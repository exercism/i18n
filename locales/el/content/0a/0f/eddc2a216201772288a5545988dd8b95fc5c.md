# μη χρησιμοποιείς τη μέθοδο main

Δοκίμασε να αφαιρέσεις τη μέθοδο `main` από τον κώδικά σου.
Οι δοκιμές των ασκήσεων δεν απαιτούν οι λύσεις να έχουν μέθοδο `main`, και η ύπαρξή της κάνει τον κώδικα λίγο πιο δύσκολο στο διάβασμα.

Συνήθως, μια μέθοδος `main` προστίθεται για να βοηθήσει στο debug του κώδικα.
Ωστόσο, καλύτερη προσέγγιση είναι να κάνεις debug στον κώδικα ενώ τρέχεις μία ή περισσότερες δοκιμές μονάδας.
Αυτό έχει το πρόσθετο πλεονέκτημα ότι μπορείς να επικεντρωθείς στο debug μιας συγκεκριμένης περίπτωσης δοκιμής.

Ορίστε μερικοί σύνδεσμοι που εξηγούν πώς να κάνεις debug σε κώδικα Java ενώ τρέχεις δοκιμές μονάδας σε διάφορα περιβάλλοντα ανάπτυξης (IDE):

- [Πώς να τρέχεις δοκιμές Java και να κάνεις debug στο Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Debug δοκιμών στο IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
