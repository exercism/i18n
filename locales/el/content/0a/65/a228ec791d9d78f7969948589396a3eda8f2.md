# Εισαγωγή

Ένας τύπος είναι _γενικός τύπος_ όταν μπορεί να περιέχει τιμές οποιουδήποτε τύπου μέσω μιας _παραμέτρου τύπου_.

Για παράδειγμα, αυτός ο τύπος `Box` έχει την παράμετρο τύπου `a` (γράφεται με πεζά γράμματα).

```gleam
pub type Box(a) {
  Box(a)
}
```

Η παράμετρος τύπου `a` είναι ένα σύμβολο που παριστάνει οποιονδήποτε τύπο, οπότε το `Box` μπορεί να χρησιμοποιηθεί με συμβολοσειρές, ακέραιους ή οποιονδήποτε άλλο τύπο.

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

Ένας τύπος μπορεί να έχει πολλές παραμέτρους τύπου, χωρίζοντάς τες με κόμματα.

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## Γενικές συναρτήσεις

Μπορείς να χρησιμοποιήσεις παραμέτρους τύπου και στις παραμέτρους των συναρτήσεων.

Αυτή η συνάρτηση παίρνει μια τιμή του τύπου `a` και καλεί δύο φορές μια συνάρτηση που παίρνει ένα `a` και επιστρέφει ένα `b`.

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
