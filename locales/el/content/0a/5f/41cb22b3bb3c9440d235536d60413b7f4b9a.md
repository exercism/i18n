Στόχος αυτής της άσκησης είναι να βελτιώσουμε την άσκηση Ελεγκτής Κωδικού Πρόσβασης.
Επειδή ένας κωδικός πρόσβασης θα παραβιάζει συνήθως περισσότερους από έναν κανόνες ταυτόχρονα, ένας χρήσιμος ελεγκτής κωδικών πρόσβασης πρέπει να ενημερώνει τον χρήστη για όλους τους κανόνες που παραβιάζονται, και όχι μόνο για τον πρώτο που θα εντοπιστεί.
Ο βελτιωμένος ελεγκτής κωδικών πρόσβασης πρέπει να υποδεικνύει μονομιάς όλους τους κανόνες που παραβιάζει ένας κωδικός πρόσβασης.

Οι κανόνες για αυτόν τον ελεγκτή κωδικών πρόσβασης είναι ίδιοι με εκείνους της προηγούμενης άσκησης Ελεγκτής Κωδικού Πρόσβασης:

- Πρέπει να έχει 12 ή περισσότερους χαρακτήρες
- Πρέπει να έχει τουλάχιστον ένα κεφαλαίο γράμμα
- Πρέπει να έχει τουλάχιστον ένα πεζό γράμμα
- Πρέπει να έχει τουλάχιστον ένα ψηφίο
- Πρέπει να έχει τουλάχιστον ένα σύμβολο από το σύνολο !@#$%^&\*

## 1. Τροποποίησε το discriminated union `PasswordError` ώστε οι επιμέρους τιμές να μπορούν να αντιμετωπίζονται ως σημαίες

Σημείωσε ότι τα τεστ δεν θα μεταγλωττιστούν μέχρι να ολοκληρωθεί αυτό το ουσιώδες βήμα.

## 2. Υλοποίησε τη συνάρτηση `checkPassword`

Η συνάρτηση `checkPassword` ελέγχει τον κωδικό πρόσβασης που δίνεται ως προς τους προαναφερθέντες κανόνες.
Η συνάρτηση πρέπει να επιστρέφει μια τιμή `Result`, όπου `Ok` επιστρέφεται όταν ο κωδικός πρόσβασης ικανοποιεί όλους τους κανόνες, και μια τιμή `Error` όταν αποτυγχάνει σε έναν ή περισσότερους κανόνες.
Αν ο κωδικός πρόσβασης που δίνεται αποτυγχάνει σε πολλούς κανόνες, η τιμή `PasswordError` πρέπει να αντιπροσωπεύει όλους τους κανόνες που αποτυγχάνουν.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Υλοποίησε τη συνάρτηση ``getStatusPhrases`

Η συνάρτηση `getStatusPhrases` επιστρέφει ένα σύνολο συμβολοσειρών, καθεμία από τις οποίες περιέχει μια φράση κατανοητή από τον άνθρωπο που αντιστοιχεί σε ένα από τα σφάλματα στο αποτέλεσμα που επιστρέφει η `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
