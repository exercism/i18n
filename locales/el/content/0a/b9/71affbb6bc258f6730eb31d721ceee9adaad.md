# Εισαγωγή

Η τιμή `null` στη JavaScript αντιπροσωπεύει τη σκόπιμη απουσία μιας τιμής αντικειμένου. Είναι ένας από τους πρωτογενείς τύπους της JavaScript.

```javascript
// I do not have an apple.
var apple = null;
apple; // => null

// null is treated as falsy for boolean operations, therefore
!apple; // => true
!!apple; // => false
```
