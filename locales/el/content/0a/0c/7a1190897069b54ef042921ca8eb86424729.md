# Προσθήκη στις οδηγίες

## Μερικές συμβουλές

Για τη συνάρτηση `filelike_objects_are_closed_on_exception`, το `filelike_object` θα είναι ένα στιγμιότυπο μιας προσαρμοσμένης κλάσης `FileLike` που ορίζεται στη σουίτα δοκιμών.
Αυτή η κλάση υλοποιεί τις παρακάτω μεθόδους:

- `open` και `close`, για ρητό άνοιγμα και κλείσιμο.
- `__enter__` και `__exit__`, για έμμεσο άνοιγμα και κλείσιμο.
- `do_something`, που μπορεί να πετάξει ή να μην πετάξει ένα `Exception`.
