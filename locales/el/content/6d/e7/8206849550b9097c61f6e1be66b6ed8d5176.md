# Σχετικά

Ένα σύνολο είναι μια συλλογή από μοναδικές τιμές. Η προεπιλεγμένη υλοποίηση ενός συνόλου στο .NET είναι το [`HashSet<T>`][HashSet].

Η κλάση `HashSet` χρησιμοποιεί τη [μέθοδο `GetHashCode()`][GetHashCode] κάθε στοιχείου.

Από προεπιλογή, η υλοποίηση της `GetHashCode()` για τύπους αναφοράς επιστρέφει έναν κατακερματισμό της θέσης μνήμης του. Αυτό σημαίνει ότι διαφορετικά αντικείμενα τύπου αναφοράς θα έχουν διαφορετικό κωδικό κατακερματισμού (αυτό είναι γνωστό ως ισότητα αναφοράς). Οι τύποι τιμών, από προεπιλογή, επιστρέφουν έναν κατακερματισμό των πεδίων/ιδιοτήτων τους. Αυτό σημαίνει ότι διαφορετικά αντικείμενα τύπου τιμής με τις ίδιες τιμές πεδίων/ιδιοτήτων θα έχουν τον ίδιο κωδικό κατακερματισμού (αυτό είναι γνωστό ως δομική ισότητα).

Μπορείς να παρακάμψεις την υλοποίηση της `GetHashCode()` στις δικές σου κλάσεις, κάτι που θα μπορούσες να χρησιμοποιήσεις για να έχει ένας τύπος αναφοράς δομική ισότητα.

[HashSet]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.hashset-1
[GetHashCode]: https://docs.microsoft.com/en-us/dotnet/api/system.object.gethashcode
