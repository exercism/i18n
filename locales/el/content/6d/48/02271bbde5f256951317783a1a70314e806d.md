# Εγκατάσταση

## Εγκατάσταση του .NET

Το track C# είναι χτισμένο πάνω στην πλατφόρμα [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), η οποία τρέχει σε Windows, Linux και macOS.
Για να φτιάξεις έργα .NET, μπορείς να χρησιμοποιήσεις τη γραμμή εντολών (CLI) του .NET.
Αυτή η γραμμή εντολών είναι μέρος του .NET SDK, το οποίο μπορείς να εγκαταστήσεις ακολουθώντας τις [οδηγίες εγκατάστασης](https://dotnet.microsoft.com/download/dotnet/8.0).
Σημείωση: το track C# απαιτεί έκδοση SDK 9.0 ή μεγαλύτερη.

Αφού ολοκληρώσεις την εγκατάσταση, μπορείς να ελέγξεις αν η γραμμή εντολών εγκαταστάθηκε σωστά τρέχοντας αυτή την εντολή σε ένα τερματικό:

```bash
dotnet --version
```

Αν η έξοδος είναι μια έκδοση μεγαλύτερη ή ίση με `9.0.100`, το .NET SDK έχει εγκατασταθεί σωστά.

## Χρήση IDE

Αν θέλεις μια πιο πλήρη εμπειρία επεξεργασίας, μάλλον θέλεις να χρησιμοποιήσεις ένα [IDE ή ολοκληρωμένο περιβάλλον ανάπτυξης](https://en.wikipedia.org/wiki/Integrated_development_environment).
Αυτά είναι τα πιο δημοφιλή IDE που υποστηρίζουν τη δημιουργία έργων .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) με την [επέκταση C#](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Σημείωση: επειδή η μορφή των έργων .NET διαφέρει σημαντικά από τις προηγούμενες εκδόσεις, τα παλαιότερα IDE (όπως το Visual Studio 2015) δεν υποστηρίζονται.
