# Εγκατάσταση

Οι λύσεις σε αυτό το track είναι γραμμένες σε assembly για RISC-V 32-bit και εκτελούνται υπό εξομοίωση, οπότε δε χρειάζεσαι υλικό RISC-V.
Κάθε άσκηση συνοδεύεται από ένα Makefile που χτίζει τα τεστ και τα εκτελεί.
Για να το χρησιμοποιήσεις, χρειάζεσαι τρία εργαλεία:

- Το [Zig][zig], που παρέχει τον συμβολομεταφραστή για RISC-V, τον μεταγλωττιστή C και τον συνδέτη μέσω του `zig cc`.
- Το [Make][make], που εκτελεί το χτίσιμο.
- Το `qemu-riscv32` από το [QEMU][qemu], που εκτελεί το παραγόμενο πρόγραμμα.

## macOS

Ξεκίνα μια εικονική μηχανή Linux με οποιαδήποτε κατάλληλη λύση εικονικοποίησης (π.χ. [Lima][lima]) και ακολούθησε παρακάτω την ενότητα για τη διανομή Linux που θα επιλέξεις.

## Windows

Χρησιμοποίησε το [Windows Subsystem for Linux][wsl] και ακολούθησε παρακάτω την ενότητα για τη διανομή Linux που θα επιλέξεις.
Εναλλακτικά, στήσε μια εικονική μηχανή Linux.

## Debian / Ubuntu

Εγκατέστησε το Make και τους εξομοιωτές του QEMU σε επίπεδο χρήστη:

```shell
sudo apt install make qemu-user
```

Έπειτα, εγκατέστησε το Zig 0.15.2 ή νεότερο, όπως περιγράφεται στην ενότητα [Άμεση λήψη][zig-install].

## Fedora

Εγκατέστησε και τα τρία εργαλεία με:

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

Εγκατέστησε και τα τρία εργαλεία με:

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

Εγκατέστησε και τα τρία εργαλεία με:

```shell
sudo zypper install zig make qemu-linux-user
```

## Έλεγχος της εγκατάστασής σου

Επιβεβαίωσε ότι βρίσκονται και τα τρία εργαλεία:

```shell
zig version
make --version
qemu-riscv32 --version
```

Έπειτα, κατέβασε μια άσκηση με το Exercism CLI και εκτέλεσε τα τεστ της:

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
