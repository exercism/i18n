# Εισαγωγή

Όταν κάνουμε αντιστοίχιση προτύπων σε μια τιμή στη Gleam, πρέπει να βεβαιωθούμε ότι τα πρότυπα καλύπτουν κάθε πιθανή τιμή του τύπου, αλλιώς ο κώδικας δε θα μεταγλωττιστεί.

Αυτή η συνάρτηση θα πρέπει να απορρίπτεται, καθώς δε χειρίζεται την περίπτωση όπου η λίστα είναι κενή:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

Τις περισσότερες φορές στα προγράμματα Gleam θέλουμε να χειριζόμαστε κάθε πιθανή περίπτωση, αλλά σε ορισμένα προγράμματα, όπως πρωτότυπα και γρήγορα scripts, μπορεί να θέλουμε να επικεντρωθούμε μόνο στο happy path και να μη γράψουμε κώδικα για τις άλλες περιπτώσεις. Εδώ έρχονται τα let assertions της Gleam.

Με τα let assertions ένα πρότυπο μπορεί να αντιστοιχεί μόνο σε μερικές από τις πιθανές τιμές ενός τύπου, και αν το πρότυπο δεν αντιστοιχεί σε μια τιμή, το πρόγραμμα θα καταρρεύσει. Χρησιμοποιώντας το `let assert` μπορούμε να γράψουμε την παραπάνω συνάρτηση ως εξής:

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Οι βιβλιοθήκες Gleam δεν πρέπει ποτέ να χρησιμοποιούν let assertions, καθώς μπορούν να καταρρεύσουν το πρόγραμμα. Αντ' αυτού, θα πρέπει να χρησιμοποιούν τον τύπο `Result` και να αφήνουν τον προγραμματιστή της εφαρμογής να αποφασίσει πώς θα χειριστεί τα σφάλματα.
