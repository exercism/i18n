# Εισαγωγή

Υπάρχουν δύο διαφορετικά είδη αριθμών στη Gleam: οι ακέραιοι και οι πραγματικοί.

Οι ακέραιοι είναι ακέραιοι αριθμοί.

```gleam
let integer = 3
// -> 3
```

Η Gleam έχει αρκετούς τελεστές που λειτουργούν με ακέραιους.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
