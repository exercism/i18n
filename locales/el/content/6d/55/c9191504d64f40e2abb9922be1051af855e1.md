# Σχετικά

Η Erlang είναι μια συναρτησιακή γλώσσα προγραμματισμού, που χρησιμοποιείται για τη δημιουργία κατανεμημένων συστημάτων πραγματικού χρόνου, τα οποία μπορούν να κλιμακωθούν εύκολα σε μέγεθος.

Είναι ιδανική για ταυτόχρονες εφαρμογές, όπως πλατφόρμες άμεσων μηνυμάτων και τραπεζικές πλατφόρμες, καθώς κάθε κλήση συνάρτησης έχει τη δική της διεργασία και λειτουργεί ανεξάρτητα.
Αυτό είναι χρήσιμο, γιατί ο κώδικας μπορεί να τρέξει για πολύ μεγάλο χρονικό διάστημα χωρίς να προκύψουν προβλήματα.
Επίσης, οι διεργασίες και η ανταλλαγή μηνυμάτων είναι ενσωματωμένες στη γλώσσα από προεπιλογή: δεν χρειάζεται καμία επιπλέον βιβλιοθήκη!

Σχεδιάστηκε μέσα στην Ericsson, μια σουηδική εταιρεία τηλεπικοινωνιών, για χρήση στα δίκτυά της, και σήμερα χρησιμοποιείται σε τηλεπικοινωνιακό εξοπλισμό.
