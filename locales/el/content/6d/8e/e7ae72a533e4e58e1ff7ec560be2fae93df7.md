# Πόροι

* Το [The Rust Programming Language](https://doc.rust-lang.org/book/) είναι ένας εξαιρετικός πόρος για να ξεκινήσεις με τη Rust αλλά και για να εμβαθύνεις σε συγκεκριμένα χαρακτηριστικά της.
* Το [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) σου δείχνει παραδείγματα από τα πιο συνηθισμένα πράγματα που θα γράφεις στη Rust.
* Με την [Rust API Documentation](http://doc.rust-lang.org/std/) μπορείς να ανακαλύψεις νέες μεθόδους και να δεις πώς λειτουργούν.
* Στο [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) μπορείς να αναζητήσεις το πρόβλημά σου και να δεις αν έχει ήδη απαντηθεί.  Μπορείς επίσης να κάνεις ερωτήσεις και να απαντήσεις σε ερωτήσεις άλλων.
* Το [Rust User Forum](http://users.rust-lang.org) είναι για γενικές συζητήσεις γύρω από τη Rust.
* Το [/r/rust](http://www.reddit.com/r/rust/) είναι το επίσημο subreddit της Rust.
* Ο επίσημος server του [The Rust Programming Language](https://discord.gg/rust-lang) στο [Discord](https://discordapp.com/) μπορεί να χρησιμοποιηθεί για γρήγορες ερωτήσεις και συζητήσεις γύρω από τη γλώσσα.
