# μη χρησιμοποιείς συναρτήσεις λιστών

Μη χρησιμοποιήσεις εξωτερικά modules (όπως τα List, Enum ή Stream) στην υλοποίησή σου. Το νόημα αυτής της άσκησης είναι να φτιάξεις ο ίδιος αυτές τις βασικές συναρτήσεις. Μπορείς να χρησιμοποιήσεις βασικές συναρτήσεις του Kernel (όπως την `Kernel.+/2` για πρόσθεση αριθμών), αλλά μη χρησιμοποιήσεις συναρτήσεις του Kernel για λίστες, όπως τις `++`, `--`, `hd`, `tl`, `in`, `for` και `length`.
