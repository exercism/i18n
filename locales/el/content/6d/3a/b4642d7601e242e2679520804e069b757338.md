# Προσθήκη στις οδηγίες

## Φτιάξε το δικό σου DSL

Σε αυτή την άσκηση, έχεις απόλυτη ελευθερία να σχεδιάσεις το DSL για γράφους των ονείρων σου.

Ίσως θα ήθελες να δημιουργήσεις ένα DSL βασισμένο σε λίστες από ετικέτες και καταγραφές, κάπως έτσι:

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

Ή μήπως θα προτιμούσες ένα DSL βασισμένο σε αλυσίδες κλήσεων συναρτήσεων, κάπως έτσι:

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

Ή μήπως έχεις ένα εντελώς διαφορετικό σχέδιο; Προχώρα! Τα τεστ απαιτούν μόνο να φτιάξεις μερικούς συγκεκριμένους γράφους, και ο τρόπος που θα τους φτιάξεις εξαρτάται απόλυτα από εσένα.

Παρ' όλα αυτά, ένα DSL είναι συνήθως καλύτερο όταν είναι σαφές, περιεκτικό και όχι υπερβολικά απρόσμενο (π.χ. η συνάρτηση `minus` προορίζεται για αφαίρεση, όχι για να χτίζεις μια ακμή ανάμεσα σε δύο κόμβους, όπως στο `node("a") - node("b")`).

Για να διπλασιάσεις τη διασκέδαση, μπορείς προαιρετικά να δοκιμάσεις να υλοποιήσεις μια συνάρτηση `to_dot` που μετατρέπει τον γράφο σου στη μορφή DOT!
