# Εισαγωγή

Όπως πολλές άλλες γλώσσες, η C++ έχει _δείκτες_.
Γνωρίζεις ήδη ότι οι _αναφορές_ και οι _δείκτες_ μοιάζουν, αλλά σκέψου τους ως ένα επίπεδο πιο κοντά στα ενδότερα του υπολογιστή σου.
Οι _δείκτες_ είναι μεταβλητές που κρατούν διευθύνσεις αντικειμένων.
Χρησιμοποιούνται για να αλληλεπιδράς άμεσα με αντικείμενα, επιτρέποντας τη δυναμική δέσμευση μνήμης και τον αποδοτικό χειρισμό δεδομένων στη C++.

Αν έρχεσαι πρώτη φορά σε επαφή με τους _δείκτες_, μπορεί να σου φανούν λίγο μυστηριώδεις, αλλά μόλις τους συνηθίσεις είναι αρκετά απλοί.

Αποτελούν κρίσιμο κομμάτι της C++, οπότε αφιέρωσε λίγο χρόνο για να τους κατανοήσεις πραγματικά.
Η στοιχειώδης εκδοχή τους σε αυτή την ενότητα ονομάζεται επίσης _χαζός δείκτης_ ή _ακατέργαστος δείκτης_.
Στη σύγχρονη C++ υπάρχουν επίσης οι _έξυπνοι δείκτες_, αλλά ο βασικός τύπος δεν είναι καθόλου έξυπνος και πρέπει να χειριστείς όλη τη δουλειά χειροκίνητα.

Πριν μπεις στις λεπτομέρειες, αξίζει να κατανοήσεις τη χρήση των _δεικτών_.
Οι _δείκτες_ είναι ένας τρόπος να μοιράζεσαι τη διεύθυνση ενός αντικειμένου με άλλα σημεία του προγράμματός μας, κάτι χρήσιμο για δύο σημαντικούς λόγους:

1. Όπως οι _αναφορές_, οι δείκτες αποφεύγουν τα αντίγραφα και βοηθούν στη μείωση του αποτυπώματος πόρων του προγράμματός σου.
1. Σε αντίθεση με τις _αναφορές_, οι δείκτες μπορούν να ανατεθούν ξανά ώστε να δείχνουν σε διαφορετικά αντικείμενα.
1. Οι δείκτες μπορούν επίσης να δείχνουν σε μια τιμή null, υποδηλώνοντας ότι τη δεδομένη στιγμή δεν δείχνουν σε κανένα αντικείμενο.

## Γενική σύνταξη

Η δήλωση ενός δείκτη στη C++ περιλαμβάνει τον καθορισμό του τύπου δεδομένων στον οποίο δείχνει ο δείκτης, ακολουθούμενο από έναν αστερίσκο (`*`) και το όνομα του δείκτη.
Όταν δηλώνονται δείκτες, δεν αρχικοποιούνται αυτόματα.
Χωρίς ρητή ανάθεση, ένας δείκτης συνήθως κρατά μια απροσδιόριστη τιμή, που συχνά αναφέρεται ως "διεύθυνση σκουπιδιών".
Ενώ ορισμένοι μεταγλωττιστές μπορεί να αρχικοποιούν τους δείκτες σε `nullptr`, αυτή η συμπεριφορά δεν είναι εγγυημένη σε όλους τους μεταγλωττιστές, οπότε είναι σημαντικό να μην βασίζεσαι σε αυτήν.
Είναι βέλτιστη πρακτική να αρχικοποιείς ρητά τους ακατέργαστους δείκτες και να επαληθεύεις ότι δεν είναι null πριν τους χρησιμοποιήσεις, για να αποφύγεις πιθανά προβλήματα.

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

Για να αναθέσεις τη διεύθυνση μιας μεταβλητής σε έναν δείκτη, χρησιμοποιείς τον τελεστή διεύθυνσης (`&`).
Η αποαναφορά ενός δείκτη γίνεται με τον _τελεστή έμμεσης προσπέλασης_ (`*`).

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

Προσοχή: η αποαναφορά πρέπει να γίνεται ρητά, ενώ οι _αναφορές_ λειτουργούσαν απλώς σαν ψευδώνυμο.

## Αριθμητική δεικτών

Η _αριθμητική δεικτών_ σου επιτρέπει να εκτελείς αριθμητικές πράξεις σε δείκτες, κάτι ιδιαίτερα χρήσιμο όταν δουλεύεις με πίνακες.
Η πρόσθεση ενός ακεραίου σε έναν δείκτη τον κάνει να δείχνει σε διαφορετικό στοιχείο.

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
Η αριθμητική δεικτών στη C++ μπορεί εύκολα να οδηγήσει σε __μη ορισμένη συμπεριφορά__ αν δεν τη χειριστείς προσεκτικά.
Η μη ορισμένη συμπεριφορά μπορεί να εκδηλωθεί με απροσδόκητα αποτελέσματα του προγράμματος, καταρρεύσεις ή ακόμη και ευπάθειες ασφαλείας.
Ένα διαβόητο παράδειγμα των συνεπειών της μη ορισμένης συμπεριφοράς συνέβη στην [έκρηξη του πυραύλου Ariane 5][ariane-flight-v88] το 1996, όπου μια εξαίρεση λογισμικού που προκλήθηκε από τη μετατροπή ενός αριθμού κινητής υποδιαστολής 64 bit σε έναν προσημασμένο ακέραιο 16 bit οδήγησε σε καταστροφική αποτυχία.

[ariane-flight-v88]: https://en.wikipedia.org/wiki/Ariane_flight_V88

## Πρόσβαση σε μεταβλητές-μέλη

Στη C++, ο τελεστής `->` χρησιμοποιείται για να προσπελάσεις τα μέλη ενός αντικειμένου μέσω ενός δείκτη προς αυτό το αντικείμενο.
Είναι μια συντομογραφία που απλοποιεί την πρόσβαση στα μέλη αντικειμένων που δείχνονται από δείκτες.
Για παράδειγμα, αν ο `ptr` είναι δείκτης σε ένα αντικείμενο με μεταβλητή-μέλος `x`, αντί να χρησιμοποιήσεις το `(*ptr).x`, μπορείς να χρησιμοποιήσεις απευθείας το `ptr->x`.
Αυτός ο τελεστής βελτιώνει την αναγνωσιμότητα του κώδικα και μειώνει τη φλυαρία όταν δουλεύεις με δείκτες προς αντικείμενα.

Να ένα σύντομο παράδειγμα, με μια _struct_ `Superhero` που έχει τη μεταβλητή-μέλος `superpower`.
Η συνάρτηση main δημιουργεί έναν δείκτη `dianaPrince` προς ένα αντικείμενο `Superhero` (που αντιπροσωπεύει τη Wonder Woman).
Ο τελεστής `->` χρησιμοποιείται για να προσπελάσει τη μεταβλητή-μέλος `superpower`, αναδεικνύοντας το εμβληματικό "Lasso of Truth" της Wonder Woman.

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## Δείκτες εναντίον αναφορών

Οι δείκτες και οι αναφορές επιτρέπουν και οι δύο έμμεση πρόσβαση σε αντικείμενα, αλλά διαφέρουν ως προς τις δυνατότητες και τους παράγοντες ασφάλειας που προσφέρουν.
Οι δείκτες προσφέρουν την ευελιξία να αλλάζουν το αντικείμενο στο οποίο δείχνουν και μπορούν να πάρουν την τιμή null.
Ωστόσο, αυτή η ευελιξία εισάγει κινδύνους, όπως η αποαναφορά δεικτών με τιμή null ή η δημιουργία εκκρεμών δεικτών.
Οι αναφορές, από την άλλη, δεν μπορούν να είναι null και δεσμεύονται σε έγκυρα αντικείμενα κατά τη δημιουργία τους, αποφεύγοντας αυτούς τους κινδύνους.
Δεδομένου ότι είναι ασφαλέστερες, οι αναφορές θα πρέπει να προτιμώνται έναντι των δεικτών, εκτός αν οι επιπλέον λειτουργίες που προσφέρουν οι δείκτες είναι απαραίτητες.
