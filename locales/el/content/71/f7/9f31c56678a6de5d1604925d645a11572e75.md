# Προτεινόμενοι πόροι μάθησης

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά μπορεί να είναι δύσκολο να ξεκινήσεις αν μαθαίνεις Ruby για πρώτη φορά. Αυτοί οι πόροι μπορούν να σε βοηθήσουν να κάνεις την αρχή:

* [Ruby in Twenty Minutes](https://www.ruby-lang.org/en/documentation/quickstart/)
* [Ruby Documentation](http://ruby-doc.org/)
* [RubyLearning.com (on wayback machine)](http://web.archive.org/web/20210813230808/https://rubylearning.com/) - Μαθήματα Ruby και σημειώσεις μελέτης
* [Learn to Program](http://pine.fm/LearnToProgram/) - Ένα βιβλίο (διαθέσιμο online) γραμμένο από τον Chris Pine
* [StackOverflow](http://stackoverflow.com/questions/tagged/ruby)
* [RubyMonk](https://rubymonk.com/)
* [Learn Ruby The Hard Way](http://learnrubythehardway.org/book/)
* [Codecademy.org's Ruby Course](https://www.codecademy.com/learn/ruby)
