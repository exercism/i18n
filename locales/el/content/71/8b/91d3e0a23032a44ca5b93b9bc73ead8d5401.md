# Instructions

Σε αυτή την άσκηση, θα διαχειρίζεσαι ένα σύστημα αποθέματος.

Το απόθεμα πρέπει να είναι οργανωμένο με βάση το όνομα του στοιχείου και να παρακολουθεί τον αριθμό των διαθέσιμων στοιχείων.

Θα χρειαστεί να χειριστείς την προσθήκη στοιχείων σε ένα απόθεμα.
Κάθε φορά που ένα στοιχείο εμφανίζεται σε μια δεδομένη λίστα, η ποσότητα του στοιχείου πρέπει να αυξάνεται κατά `1` στο απόθεμα.
Θα χρειαστεί επίσης να χειριστείς τη διαγραφή στοιχείων από ένα απόθεμα, μειώνοντας τις ποσότητες κατά `1` όταν ζητείται.

Τέλος, θα χρειαστεί να υλοποιήσεις μια συνάρτηση που θα επιστρέφει όλα τα ζεύγη κλειδιού-τιμής σε ένα δεδομένο απόθεμα ως `list` από `tuples`.


## 1. Δημιούργησε ένα απόθεμα με βάση μια λίστα

Υλοποίησε τη συνάρτηση `create_inventory(<input list>)` που δημιουργεί ένα "απόθεμα" από μια λίστα εισόδου με στοιχεία.
Θα πρέπει να επιστρέφει ένα `dict` που περιέχει κάθε όνομα στοιχείου μαζί με την αντίστοιχη ποσότητά του.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Πρόσθεσε στοιχεία από μια λίστα σε ένα υπάρχον λεξικό

Υλοποίησε τη συνάρτηση `add_items(<inventory dict>, <item list>)` που προσθέτει μια λίστα στοιχείων στο απόθεμα που της περνάς:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Μείωσε τα στοιχεία του αποθέματος

Υλοποίησε τη συνάρτηση `decrement_items(<inventory dict>, <items list>)` που παίρνει μια `list` από στοιχεία.
Η συνάρτηση σου πρέπει να αφαιρεί `1` από το πλήθος ενός στοιχείου για κάθε φορά που αυτό το στοιχείο εμφανίζεται στη `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

Τα πλήθη των στοιχείων στο απόθεμα δεν πρέπει να επιτρέπεται να πέσουν κάτω από το 0.
Αν ο αριθμός των φορών που ένα στοιχείο εμφανίζεται στη `list` εισόδου υπερβαίνει το διαθέσιμο πλήθος, η ποσότητα που αναγράφεται για αυτό το στοιχείο πρέπει να παραμένει στο 0.
Επιπλέον αιτήματα για αφαίρεση πλήθους πρέπει να αγνοούνται μόλις το πλήθος φτάσει στο μηδέν.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Αφαίρεσε εντελώς μια καταχώριση από το απόθεμα

Υλοποίησε τη συνάρτηση `remove_item(<inventory dict>, <item>)` που αφαιρεί εντελώς ένα στοιχείο και το πλήθος του από ένα απόθεμα:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Αν το στοιχείο δεν βρεθεί στο απόθεμα, η συνάρτηση πρέπει να επιστρέφει το αρχικό απόθεμα αμετάβλητο.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Επέστρεψε ολόκληρο το περιεχόμενο του αποθέματος

Υλοποίησε τη συνάρτηση `list_inventory(<inventory dict>)` που παίρνει ένα απόθεμα και επιστρέφει μια λίστα από `(item, quantity)` πλειάδες.
Η λίστα πρέπει να περιλαμβάνει μόνο τα _διαθέσιμα_ στοιχεία (_με ποσότητα μεγαλύτερη από το μηδέν_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
