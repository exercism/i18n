# Τεστ

Η διαδρομή Factor χρησιμοποιεί **Factor 0.102**.
Κάθε άσκηση συνοδεύεται από ένα ενσωματωμένο λεξιλόγιο `exercism-tools` που ορίζει τις λέξεις ανάλυσης `STOP-HERE` και `TASK:` καθώς και έναν εκτελεστή τεστ. Από τον κατάλογο της άσκησης, τρέξε:

```
factor -roots=. -run=exercism-tools <exercise>
```

Για παράδειγμα, για την άσκηση `hello-world`:

```
factor -roots=. -run=exercism-tools hello-world
```

Ο εκτελεστής τεστ τερματίζει με κωδικό κατάστασης 0 όταν όλα τα τεστ περνούν, και με μη μηδενικό κωδικό και διαγνωστική έξοδο όταν κάποιο τεστ αποτυγχάνει.

## Τεστ που παραλείπονται

Για να λύσεις μια άσκηση, πρέπει να περάσεις όλα τα τεστ της. Από προεπιλογή, όταν τρέχεις τα τεστ, εκτελείται μόνο ένα τεστ (το πρώτο). Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει μόνο αυτό το ένα τεστ.

Ο μηχανισμός είναι η γραμμή `STOP-HERE` στο αρχείο τεστ: κατά την ανάλυση λέει στη Factor να αγνοήσει όλα όσα βρίσκονται από κάτω, οπότε ο εκτελεστής τεστ βλέπει μόνο τα τεστ που βρίσκονται πάνω από αυτήν. Μόλις περάσει το πρώτο σου τεστ, μπορείς να ενεργοποιήσεις περισσότερα τεστ με δύο τρόπους:

- **Διάγραψε τη γραμμή `STOP-HERE`** για να ενεργοποιήσεις όλα τα υπόλοιπα τεστ με τη μία.
- **Μετακίνησε τη γραμμή `STOP-HERE` πιο κάτω** για να ενεργοποιείς τα τεστ ένα ένα, ή μία εργασία τη φορά. Οι ασκήσεις για έννοιες ομαδοποιούν τα τεστ κάτω από σημάνσεις `TASK:`, οπότε το να μετακινήσεις το `STOP-HERE` αμέσως πριν από την επόμενη σήμανση `TASK:` είναι ένα φυσικό βήμα.

Όταν ενεργοποιηθούν όλα τα τεστ και η υλοποίησή σου τα περνάει όλα, έχεις λύσει την άσκηση!
