# Δοκιμές

## Εκτέλεση δοκιμών

Όταν βρίσκεσαι στον κατάλογο μιας άσκησης, θα πρέπει να βλέπεις δύο υποκαταλόγους:

* Το `Sources/<Exercise>` περιέχει τη λύση σου στην άσκηση
* Το `Tests/<Exercise>Tests` περιέχει τις δοκιμές που πρέπει να τρέξεις για την άσκηση

Αν βρίσκεσαι στον σωστό κατάλογο (δηλαδή αυτόν που περιέχει τα `Sources` και `Tests`), μπορείς να τρέξεις τις δοκιμές για αυτή την άσκηση με την εντολή `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Όταν περάσεις μια δοκιμή, αφαίρεσε το `.enabled(if: RUNALL)` στη δήλωση `@Test` για να ενεργοποιήσεις την επόμενη δοκιμή. Εναλλακτικά, μπορείς να τρέξεις όλες τις δοκιμές με τη μεταβλητή περιβάλλοντος `RUNALL` ορισμένη σε `true` σε Linux ή macOS:

```bash
$ export RUNALL=true
```

Ή αν χρησιμοποιείς PowerShell σε Windows:

```powershell
set RUNALL=true
```

## Υποβολή της λύσης σου

Για να ανεβάσεις μια λύση στο Exercism, πρέπει να βρίσκεσαι στον κατάλογο που περιέχει τους καταλόγους `Sources` και `Tests`.

```bash
$ exercism submit 
```
