# Οδηγίες

Ως επίδοξη μάγισσα, η Elyse θέλει να εξασκηθεί στα βασικά.
Έχει μια στοίβα με κάρτες που θέλει να χειριστεί.

Για να κάνει τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες από το 1 έως το 10.

## 1. Δημιούργησε ένα slice με συγκεκριμένες κάρτες

Όταν εξασκείται με τις κάρτες της, στην Elyse αρέσει να ξεκινά με τις τρεις αγαπημένες της κάρτες από την τράπουλα: το 2, το 6 και το 9.
Γράψε μια συνάρτηση `FavoriteCards` που επιστρέφει ένα slice με αυτές τις κάρτες με αυτή τη σειρά.

```go
cards := FavoriteCards()
fmt.Println(cards)
// Output: [2 6 9]
```

## 2. Πάρε μια κάρτα από μια στοίβα

Επίστρεψε την κάρτα στη θέση `index` από τη στοίβα που δίνεται.

```go
card := GetItem([]int{1, 2, 4, 1}, 2) // card == 4
```

Αν η θέση είναι εκτός ορίων (δηλαδή αν είναι αρνητική ή μετά το τέλος της στοίβας), θέλουμε να επιστρέφουμε το `-1`:

```go
card := GetItem([]int{1, 2, 4, 1}, 10) // card == -1
```

~~~~exercism/note
Κατά σύμβαση στη Go, επιστρέφεται ένα σφάλμα αντί να επιστραφεί μια τιμή "εκτός ορίων".
Εδώ η τιμή "εκτός ορίων" είναι το `-1`, όταν αναμένεται ένας θετικός ακέραιος.
Όταν επιστρέφεται ένα σφάλμα, θεωρείται ιδιωματικό να επιστρέφεται και το [`zero value`](https://www.geeksforgeeks.org/zero-value-in-golang/) μαζί με το σφάλμα.
Η επιστροφή ενός σφάλματος μαζί με τη σωστή τιμή επιστροφής θα καλυφθεί σε επόμενη άσκηση.
~~~~

## 3. Αντάλλαξε μια κάρτα στη στοίβα

Αντάλλαξε την κάρτα στη θέση `index` με τη νέα κάρτα που δίνεται και επίστρεψε την τροποποιημένη στοίβα.
Σημείωσε ότι αυτό θα τροποποιήσει το slice εισόδου, κάτι που είναι η αναμενόμενη συμπεριφορά.

```go
index := 2
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 6 1]
```

Αν η θέση είναι εκτός ορίων (δηλαδή αν είναι αρνητική ή μετά το τέλος της στοίβας), θέλουμε να προσθέσουμε τη νέα κάρτα στο τέλος της στοίβας:

```go
index := -1
newCard := 6
cards := SetItem([]int{1, 2, 4, 1}, index, newCard)
fmt.Println(cards)
// Output: [1 2 4 1 6]
```

## 4. Πρόσθεσε κάρτες στην κορυφή της στοίβας

Πρόσθεσε την κάρτα ή τις κάρτες που ορίζονται στην παράμετρο `value` στην κορυφή της στοίβας.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice, 5, 1)
fmt.Println(cards)
// Output: [5 1 3 2 6 4 8]
```

Αν δεν δοθεί όρισμα για την παράμετρο `value`, τότε το αποτέλεσμα είναι ίσο με το αρχικό slice.

```go
slice := []int{3, 2, 6, 4, 8}
cards := PrependItems(slice)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```

## 5. Αφαίρεσε μια κάρτα από τη στοίβα

Αφαίρεσε την κάρτα στη θέση `index` από τη στοίβα και επίστρεψε τη στοίβα.
Σημείωσε ότι αυτό μπορεί να τροποποιήσει το slice εισόδου, κάτι που είναι εντάξει.

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 2)
fmt.Println(cards)
// Output: [3 2 4 8]
```

Αν η θέση είναι εκτός ορίων (δηλαδή αν είναι αρνητική ή μετά το τέλος της στοίβας), θέλουμε να αφήσουμε τη στοίβα όπως είναι:

```go
cards := RemoveItem([]int{3, 2, 6, 4, 8}, 11)
fmt.Println(cards)
// Output: [3 2 6 4 8]
```
