# Εισαγωγή

## Βασικά

Η Java είναι μια γλώσσα στατικής τυποποίησης, που σημαίνει ότι ο τύπος μιας μεταβλητής είναι γνωστός κατά τον χρόνο μεταγλώττισης.
Η ανάθεση μιας τιμής σε ένα όνομα αναφέρεται ως ορισμός μεταβλητής.
Μια μεταβλητή ορίζεται καθορίζοντας ρητά τον τύπο της.

```java
int explicitVar = 10;
```

Η ενημέρωση της τιμής μιας μεταβλητής γίνεται μέσω του τελεστή `=`.
Εδώ, το `=` δεν αντιπροσωπεύει μαθηματική ισότητα.
Απλώς αναθέτει μια τιμή σε μια μεταβλητή.
Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί να αλλάξει ποτέ.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Η Java είναι μια [αντικειμενοστρεφής γλώσσα][object-oriented-programming] και απαιτεί όλες οι συναρτήσεις να ορίζονται μέσα σε μια _κλάση_.
Η λέξη-κλειδί `class` χρησιμοποιείται για τον ορισμό μιας κλάσης.

```java
class Calculator {
    // ...
}
```

Μια συνάρτηση μέσα σε μια κλάση αναφέρεται ως _μέθοδος_.
Κάθε μέθοδος μπορεί να έχει μηδέν ή περισσότερες παραμέτρους.
Όλες οι παράμετροι πρέπει να έχουν ρητά τον τύπο τους, δεν υπάρχει συμπερασματολογία τύπων για τις παραμέτρους.
Παρομοίως, ο τύπος επιστροφής πρέπει επίσης να δηλώνεται ρητά.
Οι τιμές επιστρέφονται από τις μεθόδους χρησιμοποιώντας τη λέξη-κλειδί `return`.
Για να μπορεί μια μέθοδος να καλείται από άλλες κλάσεις, πρέπει να προστεθεί ο τροποποιητής πρόσβασης `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Η κλήση μιας μεθόδου γίνεται καθορίζοντας την κλάση και το όνομα της μεθόδου και περνώντας ορίσματα για κάθε παράμετρο της μεθόδου.

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Η εμβέλεια στη Java ορίζεται μεταξύ των χαρακτήρων `{` και `}`.

Η Java υποστηρίζει δύο τύπους σχολίων.
Τα σχόλια μονής γραμμής προηγούνται από `//` και τα σχόλια πολλαπλών γραμμών εισάγονται μεταξύ `/*` και `*/`.

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
