Σου έχει ανατεθεί να γράψεις μια υπηρεσία που δέχεται συμβάντα. Κάθε συμβάν έχει μια ημερομηνία συνδεδεμένη με αυτό, αλλά παρατηρείς ότι στο endpoint της υπηρεσίας σου υποβάλλονται 3 διαφορετικές μορφές:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Βλέπεις ότι υπάρχουν κάποιες ομοιότητες ανάμεσά τους και αποφασίζεις να γράψεις μερικά συνθέσιμα μοτίβα κανονικών εκφράσεων.

## 1. Αντιστοίχισε την ημέρα, τον μήνα και το έτος από μια ημερομηνία

Υλοποίησε τις `day`, `month` και `year` ώστε να επιστρέφουν ένα μοτίβο συμβολοσειράς το οποίο, όταν εκτελεστεί, θα αντιστοιχίζει τα αριθμητικά συστατικά στο `"01/01/1970"` (`dd/mm/yyyy`). Η ημέρα και ο μήνας μπορεί να εμφανίζονται ως `1` ή `01` (με μηδενικά στην αρχή για συμπλήρωση).

Μην ανησυχείς για τον έλεγχο σφαλμάτων. Μπορείς να υποθέσεις ότι πάντα θα σου δίνεται ένα έγκυρο αριθμητικό συστατικό.

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. Αντιστοίχισε την ημέρα της εβδομάδας και τον μήνα του έτους

Υλοποίησε τις `day-name` και `month-name` ώστε να επιστρέφουν ένα μοτίβο συμβολοσειράς το οποίο, όταν εκτελεστεί, θα αντιστοιχίζει αντίστοιχα οποιαδήποτε κατονομασμένη ημέρα της εβδομάδας και τον κατονομασμένο μήνα του έτους.

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. Σύλληψε την ημέρα, τον μήνα και το έτος

Υλοποίησε τις `capture-day`, `capture-month`, `capture-year`, `capture-day-name`, `capture-month-name` ώστε να επιστρέφουν έναν χάρτη που αντιστοιχίζει τα αντίστοιχα συστατικά στα ονόματα: `"day"`, `"month"`, `"year"`, `"day-name"`, `"month-name"`

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. Συνδύασε τις συλλήψεις για να συλλάβεις ολόκληρη την ημερομηνία

Υλοποίησε τις `capture-numeric-date`, `capture-month-name-date` και `capture-day-month-name-date` ώστε να επιστρέφουν έναν χάρτη με τα συστατικά από το μέρος 3, χρησιμοποιώντας την αντίστοιχη μορφή ημερομηνίας.

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
