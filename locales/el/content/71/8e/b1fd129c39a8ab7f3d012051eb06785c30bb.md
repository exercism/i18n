# Οδηγίες

Ο σύλλογος της κοινότητάς σου σου ζήτησε να υλοποιήσεις μια απλή εφαρμογή μητρώου για τη διαχείριση των εγγραφών στον κοινοτικό κήπο. Η δομή `Plot` σου έχει ήδη δοθεί.

## 1. Άνοιξε τον κήπο

Υλοποίησε τη συνάρτηση `CommunityGarden.start/1`. Θα πρέπει να δέχεται μια προαιρετική λίστα λέξεων-κλειδιών με επιλογές που θα προωθούνται στη _διεργασία agent_. Η αρχική κατάσταση του κήπου θα πρέπει να αρχικοποιείται ώστε να αναπαριστά μια κενή συλλογή παρτεριών. Θα πρέπει να επιστρέφει μια πλειάδα `:ok` με το pid του κήπου.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Εμφάνισε τις εγγραφές

Υλοποίησε τη συνάρτηση `CommunityGarden.list_registrations/1`. Θα πρέπει να δέχεται το `pid` του κοινοτικού κήπου. Θα πρέπει να επιστρέφει μια λίστα με τα αποθηκευμένα παρτέρια που είναι καταχωρισμένα.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> Σε αυτό το σημείο, δεν έχουμε προσθέσει τη δυνατότητα καταχώρισης παρτεριού, οπότε αυτή η λίστα θα πρέπει να είναι κενή

## 3. Καταχώρισε παρτέρια σε ένα άτομο

Υλοποίησε τη συνάρτηση `CommunityGarden.register/2`. Θα πρέπει να δέχεται το `pid` του κοινοτικού κήπου και ένα όνομα για να καταχωρίσει το παρτέρι. Όταν πετυχαίνει, θα πρέπει να επιστρέφει τη δομή `Plot` με το id του παρτεριού και το άτομο στο οποίο έχει καταχωριστεί.

Τα id θα πρέπει να είναι αύξοντα και μοναδικά. Μπορείς να κρατάς έναν μετρητή id στην κατάσταση του agent.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Απελευθέρωσε παρτέρια

Υλοποίησε τη συνάρτηση `CommunityGarden.release/2`. Θα πρέπει να δέχεται το `pid` και το `id` του παρτεριού που θα απελευθερωθεί. Θα πρέπει να επιστρέφει `:ok` όταν πετυχαίνει. Όταν ένα παρτέρι απελευθερώνεται, το id δεν επαναχρησιμοποιείται, χρησιμοποιείται μόνο ως μοναδικό αναγνωριστικό.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Πάρε ένα καταχωρισμένο παρτέρι

Υλοποίησε τη συνάρτηση `CommunityGarden.get_registration/2`. Θα πρέπει να δέχεται το `pid` και το `id` του παρτεριού που θα ελεγχθεί. Θα πρέπει να επιστρέφει το παρτέρι αν είναι καταχωρισμένο, και `:not_found` αν δεν είναι καταχωρισμένο.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
