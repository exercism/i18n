# Προσθήκη στις οδηγίες

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να δημιουργήσεις τον τύπο δεδομένων `Allergen`, με στιγμιότυπα των `Eq` και `Show`, και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `allergies`
- `isAllergicTo`

Θα βρεις μια εικονική δήλωση δεδομένων και τις υπογραφές τύπων ήδη στη θέση τους, αλλά εναπόκειται σε εσένα να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν τύπο δεδομένων με νόημα, ένα newtype ή ένα συνώνυμο τύπου.
