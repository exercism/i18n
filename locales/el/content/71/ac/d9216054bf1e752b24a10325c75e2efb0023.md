# Εισαγωγή

Οι περισσότερες λέξεις της Factor για ακολουθίες επιστρέφουν *νέες* ακολουθίες και αφήνουν ανέπαφες τις εισόδους τους, αλλά τόσο οι πίνακες όσο και τα διανύσματα υποστηρίζουν επίσης **μετάλλαξη επί τόπου**, όταν θέλεις να καταγράψεις κατάσταση που εξελίσσεται με τον χρόνο.

Οι `set-nth` και `change-nth` αλλάζουν μια θέση επί τόπου, και λειτουργούν τόσο σε πίνακα όσο και σε διάνυσμα. Το `<array>` δημιουργεί έναν μεταβλητό πίνακα σταθερού μήκους· τα literal `V{ }`, το `<vector>`, το `push` και το `pop` αποτελούν το σύνολο που αφορά μόνο τα διανύσματα, αφού οι πίνακες δε μπορούν να αλλάξουν μήκος. Το `clone` αντιγράφει την ακολουθία, ώστε οι περαιτέρω μεταλλάξεις να μην επηρεάσουν το αρχικό.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
