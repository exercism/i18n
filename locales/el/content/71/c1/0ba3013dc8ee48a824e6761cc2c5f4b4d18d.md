# Συγχρονισμός με το GitHub

Γεια σε όλους!

Τους τελευταίους μήνες δουλέψαμε σκληρά πάνω στο [Coding Fundamentals](https://exercism.org/courses/coding-fundamentals) και στο [Front-End Fundamentals Bootcamp](https://exercism.org/courses/front-end-fundamentals), που ήταν καταπληκτικές εμπειρίες για εμάς. Τώρα που ολοκληρώθηκαν, αφιερώνουμε λίγο χρόνο για να προσθέσουμε μερικές νέες δυνατότητες στην κύρια ιστοσελίδα του Exercism!

Σήμερα παρουσιάζουμε **δύο νέες δυνατότητες** στο Exercism:
1. Συγχρόνισε τις λύσεις σου με το GitHub.
2. Αποθήκευσε και εξερεύνησε τα Αγαπημένα σου.

## Συγχρόνισε τις λύσεις σου με το GitHub

Το να έχεις το δικό σου δημόσιο αντίγραφο ασφαλείας των λύσεών σου είναι κάτι που ο κόσμος ζητούσε για πολύ καιρό. 
Πολλοί συγχρονίζουν χειροκίνητα τις λύσεις τους με το GitHub ή έχουν γράψει ακόμα και δικά τους script για να το κάνουν, αλλά τώρα αυτή η δυνατότητα είναι **ενσωματωμένη στο Exercism!**

Μόλις ενεργοποιήσεις τη δυνατότητα, οι λύσεις σου θα αρχίσουν να δημιουργούν αυτόματα αντίγραφα ασφαλείας στο GitHub. Μπορείς να ρυθμίσεις αν το αντίγραφο ασφαλείας θα γίνεται μέσω Pull Requests ή commits, και να ανεβάσεις μαζικά όλες τις λύσεις σου!

Πριν από ένα μήνα το παρουσιάσαμε διακριτικά στους Insiders και μέχρι τώρα έχουμε δημιουργήσει αντίγραφα ασφαλείας για δεκάδες χιλιάδες λύσεις στο GitHub. Όσο περισσότεροι το χρησιμοποιούν, τόσο περισσότερο το εκτιμούν. Όπως είπε ένας Insider:

> Δεν είχα ισχυρά συναισθήματα για αυτή τη δυνατότητα όταν προτάθηκε αρχικά, αλλά τώρα που είναι εδώ, είμαι πάρα πολύ χαρούμενος που προχωρήσατε! Ήδη δεν μπορώ να φανταστώ το Exercism χωρίς αυτή.
> 
> \- W8CYE on Discord

Για να ξεκινήσεις, απλώς πήγαινε στη νέα [σελίδα ρυθμίσεων του GitHub Syncer](https://exercism.org/settings/github_syncer) και σύνδεσε ένα repo!

## Αγαπημένα

Σήμερα παρουσιάζουμε επίσης τα [Αγαπημένα του Exercism](https://exercism.org/favorites), έναν χώρο όπου μπορείς να αποθηκεύεις και να περιηγείσαι στις καλύτερες λύσεις που βρίσκεις στο Exercism.

Σχεδιασμένα ως τρόπος για να κρατάς ό,τι βρίσκεις ενδιαφέρον, εμπνευστικό ή εντυπωσιακό, τα Αγαπημένα σου επιτρέπουν να βάζεις αστέρι σε λύσεις καθώς περιηγείσαι στον ιστότοπο και μετά να επιστρέφεις και να τις ξαναβλέπεις όποτε θέλεις να εμβαθύνεις.

Για να προσθέσεις ένα αγαπημένο, απλώς κάνε κλικ στο κουμπί "Favorite" σε οποιαδήποτε λύση της κοινότητας. Θα δεις το κείμενο να αλλάζει σε "Favorited" και το αστέρι να γίνεται χρυσό!
Αν θέλεις να αφαιρέσεις ένα αγαπημένο, απλώς κάνε κλικ ξανά.

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="Στιγμιότυπο οθόνης της σελίδας λύσης της κοινότητας που δείχνει το κουμπί Favorite" style="width:100%; max-width:600px;" width="2182" height="980" />

Όλες οι λύσεις στις οποίες έχεις ήδη βάλει αστέρι έχουν μεταφερθεί αυτόματα στα Αγαπημένα σου. Μπορείς να έχεις πρόσβαση στα Αγαπημένα από το μενού Learn ή απευθείας από [αυτόν τον σύνδεσμο](https://exercism.org/favorites).

## Έρχονται κι άλλα!

Δουλεύουμε και πάνω σε άλλες συναρπαστικές δυνατότητες, όπως πιο προηγμένη αυτόματη ανατροφοδότηση, εξηγήσεις των λύσεων και πολύγλωσση μετάφραση του ιστότοπου. Όλα αυτά σχεδιάζουμε να τα παρουσιάσουμε μέσα στους επόμενους δύο μήνες. Μείνε συντονισμένος για τις λεπτομέρειες!
