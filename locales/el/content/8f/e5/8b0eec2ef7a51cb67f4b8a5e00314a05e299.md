# Ένταξη υπαλλήλων στη βάση δεδομένων

## Δήλωση προβλήματος

Η ABC Corp σχεδιάζει να διατηρεί όλες τις πληροφορίες πληρωμών μικροποσών προς τους υπαλλήλους σε μια βάση δεδομένων. Βοηθάς το οικονομικό τμήμα της ABC Corp να το υλοποιήσει. Καθώς η ABC Corp επεκτείνει τις δραστηριότητές της, η προσθήκη νέων υπαλλήλων στο σύστημα είναι συχνή απαίτηση λόγω των νέων προσλήψεων.

Η αποστολή σου είναι να προσθέσεις τα στοιχεία του νέου υπαλλήλου που σου δίνονται στον πίνακα `Employee` της βάσης δεδομένων και να επιστρέψεις την τιμή της αυτόματα παραγόμενης στήλης `employee_id` χωρίς να εκτελέσεις άλλο ερώτημα στη βάση δεδομένων για να τη βρεις. Αν προκύψει σφάλμα κατά την εκτέλεση, θα πρέπει να επιστραφεί το `-1`.

## Στοιχεία βάσης δεδομένων

Χρησιμοποίησε τη βάση δεδομένων H2 που σου δίνεται για αυτό το πρόβλημα.

> Το δείγμα αρχείου βάσης δεδομένων είναι το `gofigure.mv.db` και το όνομα της βάσης δεδομένων είναι `gofigure`. Βρίσκεται μέσα στον φάκελο `db`.

Οι παρακάτω πίνακες υπάρχουν ήδη στη δείγμα βάση H2 με μερικά δείγματα δεδομένων. Τα ονόματα των στηλών και οι τύποι δεδομένων δίνονται παρακάτω.

**Όνομα πίνακα** : `Employee`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `employee_id`     | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `name`            | συμβολοσειρά        |
| `city`            | συμβολοσειρά        |
| `department`      | συμβολοσειρά        |
| `age`             | ακέραιος        |

**Όνομα πίνακα**: `Payment`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `payment_id`      | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `date`            | ημερομηνία        |
| `amount`          | δεκαδικός        |
| `employee_id`     | ακέραιος        |
| `reason`          | συμβολοσειρά        |

* Το αρχείο βάσης δεδομένων είναι το `gofigure.mv.db`. Χρησιμοποίησε το JDBC URL ως `jdbc:h2:file:/path/to/db/file`
* Όνομα χρήστη: `root`
* Κωδικός πρόσβασης: `root`

## Περιορισμοί

* Χρησιμοποίησε το αρχείο βάσης δεδομένων H2 που παρέχεται στον φάκελο `db` για να επικυρώσεις τα ερωτήματα και το δείγμα Ballerina
* Χρησιμοποίησε την προσέγγιση maven dependency params για να προσθέσεις τον οδηγό της βάσης δεδομένων H2 ως εξάρτηση πλατφόρμας στο Ballerina.toml σου
* Μην εκτελέσεις άλλο ερώτημα στη βάση δεδομένων για να βρεις το αυτόματα παραγόμενο id


## Περιβάλλον δοκιμών

* Μπορείς να εκτελέσεις τις δοκιμές με `bal test`, και θα τρέξουν δοκιμές πάνω στη δείγμα βάση δεδομένων που δίνεται.

## Παραδείγματα

### Παράδειγμα 1

**Είσοδος** : dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**Έξοδος** : `4`

### Παράδειγμα 2

**Είσοδος** : dbFilePath: `"./db/invalidDB"`, name : `“John"`, city: `"Colombo"`, department : `"HR"`, age: `25`

**Έξοδος** : `-1`

## Υποδείξεις

* Χρησιμοποίησε το άρθρωμα [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) για να δουλέψεις με τη βάση δεδομένων
* Ανατρέξε στην ενότητα [Προαπαιτούμενα](https://lib.ballerina.io/ballerinax/java.jdbc/latest) για τα βήματα που χρειάζονται ώστε να προσθέσεις τον οδηγό JDBC ως εξάρτηση
* Χρησιμοποίησε την απομακρυσμένη μέθοδο [execute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-execute) για να εισάγεις δεδομένα
* Δες τα παραδείγματα [Λειτουργίες DML και DDL](https://ballerina.io/learn/by-example/mysql-execute-operation/)
