# Υποδείξεις

## 1. Ρύθμισε τους τύπους χρηστών και τα δικαιώματα.

- Για να χειριστείς κάθε απαριθμητή του `AccountStatus`, θα μπορούσες να χρησιμοποιήσεις μια εντολή `if`, αλλά μια [εντολή `switch`][switch] είναι εξαιρετική εναλλακτική.


## 2. Προβίβασε τα τρολ μόνο σε άλλα τρολ.

- Μπορείς να συγκρίνεις απαριθμήσεις όπως οποιονδήποτε άλλο τύπο με τους τελεστές `!=` και `==`.

## 3. Έλεγξε τα δικαιώματα για διαφορετικούς χρήστες.

- Αν λύσεις την εργασία με μια εντολή switch, οι [πτώσεις][fallthrough] μπορούν να φανούν χρήσιμες.
- Μπορείς να χρησιμοποιήσεις [διαδοχικές ετικέτες][fallthrough] και την ετικέτα [default][switch] για να ομαδοποιήσεις δικαιώματα.

## 4. Χορήγησε πρόσβαση στο παιχνίδι και ταίριαξε παίκτες.

- Το κύριο μέλημά σου είναι οι λογαριασμοί `guest` και `troll`. Για άλλους συνδυασμούς δεν χρειάζεται να χωρίσεις τη λογική σου.

## 5. Υλοποίησε ουρά προτεραιότητας.

- Αν ταξινομήσεις σωστά την απαρίθμηση `AccountStatus`, μπορείς να χρησιμοποιήσεις το `static_cast<int>` για να συγκρίνεις τους απαριθμητές με συμπαγή τρόπο.

[switch]: https://www.learncpp.com/cpp-tutorial/switch-statement-basics/
[fallthrough]: https://www.learncpp.com/cpp-tutorial/switch-fallthrough-and-scoping/
