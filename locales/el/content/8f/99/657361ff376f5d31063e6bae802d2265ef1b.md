Αφαίρεσε όλα τα περιττά literal.

Στη JavaScript δεν χρειάζεται να κάνεις `return` το literal `true` ή `false` για να επιστρέψεις ένα boolean. Μπορείς να επιστρέψεις απευθείας το αποτέλεσμα μιας έκφρασης.

```javascript
// instead of
if (some_expression) {
  return true;
} else {
  return false;
}

// ...in JavaScript, these can be returned directly
return some_expression;
```
