# Εισαγωγή

Η Python είναι μια γλώσσα προγραμματισμού με [δυναμική και ισχυρή][dynamic typing in python] τυποποίηση.
Χρησιμοποιεί τόσο [duck typing][duck typing] όσο και [gradual typing][gradual typing] μέσω των [type hints][type hints].

Ενώ η Python υποστηρίζει πολλά διαφορετικά _στιλ_ προγραμματισμού, εσωτερικά **τα πάντα στην Python είναι ένα [αντικείμενο][everythings an object]**.
Αυτό περιλαμβάνει αριθμούς, συμβολοσειρές, λίστες και ακόμη και συναρτήσεις.

Θα εμβαθύνουμε περισσότερο στο τι σημαίνουν όλα αυτά καθώς προχωράμε στη διαδρομή.

Αυτή η πρώτη άσκηση παρουσιάζει 4 σημαντικά χαρακτηριστικά της γλώσσας Python:
1.  Ανάθεση ονόματος (_μεταβλητές και σταθερές_),
2.  Συναρτήσεις (_η λέξη-κλειδί `def` και η λέξη-κλειδί `return`_),
3.  Σχόλια, και
4.  Docstrings.

<br>

## Ανάθεση ονόματος (Μεταβλητές & σταθερές)

Οι προγραμματιστές μπορούν να δεσμεύσουν [_ονόματα_][facts-and-myths-about-python-names] (που ονομάζονται επίσης _μεταβλητές_) σε οποιονδήποτε τύπο αντικειμένου χρησιμοποιώντας τον τελεστή ανάθεσης `=`: `<name> = <value>`.
Ένα όνομα μπορεί να ανατεθεί εκ νέου (ή να δεσμευτεί ξανά) σε διαφορετικές τιμές (διαφορετικούς τύπους αντικειμένων) κατά τη διάρκεια της ζωής του.


```python
>>> my_first_variable = 1  #<-- my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  #<-- my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." #<-- You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' #<-- Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### Σταθερές

Οι σταθερές είναι ονόματα που προορίζονται να ανατεθούν μόνο μία φορά σε ένα πρόγραμμα.
Θα πρέπει να ορίζονται σε επίπεδο [module][module] (αρχείου) και είναι συνήθως ορατές σε όλες τις συναρτήσεις και τις κλάσεις του προγράμματος.
Η χρήση του `SCREAMING_SNAKE_CASE` σηματοδοτεί ότι το όνομα δεν πρέπει να ανατεθεί εκ νέου ούτε η τιμή του να μεταβληθεί.


## Συναρτήσεις

Η λέξη-κλειδί `def` ξεκινά έναν [ορισμό συνάρτησης][function definition].
Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες τυπικές [παραμέτρους][parameters] μέσα σε `()` παρενθέσεις, ακολουθούμενες από `:` άνω και κάτω τελεία.
Οι εντολές για το _σώμα_ της συνάρτησης ξεκινούν από τη γραμμή που ακολουθεί το `def` και πρέπει να είναι _με εσοχή μέσα σε μπλοκ_.


```python
# The body of a function is indented by 2 spaces, & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     #this was only indented by 3 spaces
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


Οι συναρτήσεις επιστρέφουν _ρητά_ μια τιμή ή ένα αντικείμενο μέσω της λέξης-κλειδιού [`return`][return]:


```python
# Function definition on first line, explicit return used on final line.
>>> def add_two_numbers(number_one, number_two):
        return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing it 
# will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


Οι συναρτήσεις που δεν έχουν μια _ρητή_ έκφραση μετά το `return` επιστρέφουν _σιωπηρά_ το αντικείμενο [`None`][none].
Οι λεπτομέρειες του `None` θα καλυφθούν σε επόμενη άσκηση.
Για τους σκοπούς αυτής της άσκησης και της εξήγησης, το `None` είναι ένα σύμβολο κράτησης θέσης που αντιπροσωπεύει το τίποτα, ή το null:


```python

# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Οι συναρτήσεις που παραλείπουν το `return` επιστρέφουν επίσης _σιωπηρά_ το αντικείμενο [`None`][none].
Αυτό σημαίνει ότι αν δεν χρησιμοποιείς το `return` μέσα σε μια συνάρτηση, η Python επιστρέφει το αντικείμενο `None` για σένα.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


### Κλήση συναρτήσεων

Οι συναρτήσεις [_καλούνται_][calls] ή ενεργοποιούνται χρησιμοποιώντας το όνομά τους ακολουθούμενο από `()`.
Ο συμβολισμός με τελεία (`.`) χρησιμοποιείται για την κλήση συναρτήσεων που έχουν οριστεί μέσα σε μια κλάση ή ένα module.

```python
>>> def raise_to_power(number, power):
...     return number ** power
...

>>> raise_to_power(3,3) # <--Invoking the function with the arguments 3 and 3.
27


# A mismatch between the number of parameters and the number of arguments will raise an error.
>>> raise_to_power(4,)
...
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: raise_to_power() missing 1 required positional argument: 'power'


# Calling methods or functions in classes and modules.
>>> start_text = "my silly sentence for examples."
>>> str.upper(start_text)  # <--Calling the upper() method from the built-in str class on start_text.
'MY SILLY SENTENCE FOR EXAMPLES.'


# Importing the math module
>>> import math

>>> math.pow(2,4)  # <--Calling the pow() function from the math module.
16.0
```


## Σχόλια

Τα [σχόλια][comments] στην Python ξεκινούν με ένα `#` που δεν αποτελεί μέρος μιας συμβολοσειράς και τελειώνουν στο τέλος της γραμμής.
Σε αντίθεση με πολλές άλλες γλώσσες προγραμματισμού, η Python **δεν υποστηρίζει** σημάδια σχολίων πολλών γραμμών.
Κάθε γραμμή ενός μπλοκ σχολίων πρέπει να ξεκινά με τον χαρακτήρα `#`.


## Docstrings

Η πρώτη εντολή του σώματος μιας συνάρτησης μπορεί προαιρετικά να είναι ένα [_docstring_][docstring], το οποίο συνοψίζει περιεκτικά τον σκοπό της συνάρτησης ή του αντικειμένου.
Τα docstrings δηλώνονται με τριπλά διπλά εισαγωγικά (""") με εσοχή στο ίδιο επίπεδο με το μπλοκ κώδικα:


```python

# An example from PEP257 of a multi-line docstring
# reformatted to use Google style non-type hinted docstrings.
# Some additional details can be found in the Sphinx documentation:
# https://www.sphinx-doc.org/en/master/usage/extensions/napoleon.html#getting-started

def complex(real=0.0, imag=0.0):
    """Form a complex number.

    Keyword Arguments:
        real (float): The real part of the number (default 0.0)
        imag (float): The imaginary part of the number (default 0.0)
        
    """

    if imag == 0.0 and real == 0.0:
        return complex_zero

```


Τα docstrings διαβάζονται από αυτοματοποιημένα εργαλεία τεκμηρίωσης, όπως το [Sphinx][sphinx], και επιστρέφονται καλώντας το ειδικό χαρακτηριστικό `.__doc__` στο όνομα της συνάρτησης, της μεθόδου ή της κλάσης.
Οι γενικές συμβάσεις για τα docstrings περιγράφονται στο [PEP257][pep257], αλλά οι ακριβείς μορφές ποικίλλουν ανάλογα με το project και την ομάδα.
Οι ασκήσεις εννοιών του Exercism προσπαθούν να ακολουθούν το στυλ Google για κώδικα χωρίς type hints.

Τα docstrings μπορούν επίσης να λειτουργήσουν ως [ελαφριά unit tests][doctests], τα οποία θα καλυφθούν σε επόμενη άσκηση.


```python
# An example on a user-defined function using a Google style docstring. 
>>> def raise_to_power(number, power):
    """Raise a number to an arbitrary power.

    Parameters:
        number (int): The base number.
        power (int): The power to raise the base number to.
    
    Returns:
        int: The number raised to the specified power.
    
    Takes a number and raises it to the specified power, returning the result.

    """

    return number ** power
...

# Calling the .__doc__ attribute of the function and printing the result.
>>> print(raise_to_power.__doc__)
Raise a number to an arbitrary power.

Parameters:
    number (int): The base number.
    power (int): The power to raise the base number to.

Returns:
    int: The number raised to the specified power.

Takes a number and raises it to the specified power, returning the result.
```
