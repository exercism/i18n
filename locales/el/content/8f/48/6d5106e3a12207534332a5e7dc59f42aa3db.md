# Προσθήκη στις οδηγίες

## Σύνταξη Lean

Αυτή η άσκηση θα απαιτήσει να ορίσεις σύνταξη για μια DSL παρόμοια με τη γλώσσα DOT.

Αυτό το έργο θα απαιτήσει πιθανώς να χρησιμοποιήσεις συμβολισμούς ή μακροεντολές.
Ίσως θέλεις να ρίξεις μια ματιά σε μια [αναφορά][macro-reference].

~~~~exercism/note
Σε αυτή την άσκηση, οι ακμές αναπαρίστανται με ένα μόνο `-` ανάμεσα στους κόμβους, σε αντίθεση με το `--` που χρησιμοποιείται στην πραγματική γλώσσα DOT.
Έτσι αποφεύγονται οι συγκρούσεις με τη σύνταξη σχολίων μονής γραμμής της Lean.

Επίσης, κάθε εντολή τελειώνει με `;`, ακόμη και τα σχόλια σε επίπεδο γραφήματος.
~~~~

[macro-reference]: https://lean-lang.org/doc/reference/latest/Notations-and-Macros/#language-extension
