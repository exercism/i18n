# Παράμετροι

[comment]: # (Ορισμένες παράμετροι, όπως `_ as x`, δεν μπορούν να χρησιμοποιηθούν)

Μπορείς να την αφαιρέσεις ή να τη χρησιμοποιήσεις κάπου, αν μπορεί να χρησιμοποιηθεί.
