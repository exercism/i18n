# Εισαγωγή

Η χρήση του `try..rescue` είναι μια ισχυρή κατασκευή για να πιάνεις τα σφάλματα όταν αυτά προκύπτουν. Το να πιάνεις τα σφάλματα με `rescue` επιτρέπει στις συναρτήσεις να επιστρέφουν καθορισμένες τιμές όταν αυτό είναι απαραίτητο. Η κατασκευή `try..rescue` μας προσφέρει επίσης δύο επιπλέον δυνατότητες που μπορούμε να αξιοποιήσουμε:

- το μπλοκ `else`
  - Όταν το μπλοκ try ολοκληρωθεί με επιτυχία, το αποτέλεσμα αντιστοιχίζεται σε αυτό το μπλοκ.
- το μπλοκ `after`
  - Είτε το μπλοκ try ολοκληρωθεί με επιτυχία είτε πετάξει σφάλμα, ο κώδικας στο μπλοκ `after` εκτελείται πάντα, αρκεί το πρόγραμμα να τρέχει εκείνη τη στιγμή.
  - Το αποτέλεσμα του μπλοκ `after` δεν επιστρέφεται στην εμβέλεια κλήσης.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
