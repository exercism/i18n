# Εισαγωγή

Οι εξαιρέσεις στη Ruby, όπως και σε πολλές γλώσσες, παρέχουν έναν τρόπο να χειρίζεσαι απρόσμενα γεγονότα. Ο σωστός χειρισμός των εξαιρέσεων είναι σημαντικός όταν προσπαθείς να αποτρέψεις το πρόγραμμά σου από το να καταρρεύσει.

Όταν μια εξαίρεση πετιέται, είτε επειδή την πετάς ρητά είτε επειδή την πετάει ο διερμηνευτής της Ruby, το πρόγραμμα εκτρέπεται από την κανονική του λειτουργία και τελικά τερματίζεται με ένα μήνυμα σφάλματος:

```ruby
raise ArgumentError.new("Something went wrong!")
=> Traceback (most recent call last):
.
.
ArgumentError (Something went wrong!)
```

```ruby
1/0
=> Traceback (most recent call last):
.
.
ZeroDivisionError (divided by 0)
```

Αν θέλεις να σταματήσεις αυτή τη διαδικασία τερματισμού, πρέπει να αντιδράσεις στην εξαίρεση. Αυτό ονομάζεται "διάσωση" μιας εξαίρεσης:

```ruby
begin
  # ...any code that raises an exception
rescue
  puts 'Got an exception'
end
```

Αυτό το πρόγραμμα δεν θα καταρρεύσει και θα εμφανίσει "Got an exception". Αντί να τερματιστεί, η Ruby εκτελεί τον κώδικα στο μπλοκ rescue, το οποίο τυπώνει ένα μήνυμα.

Όπως τα πάντα στη Ruby, έτσι και οι εξαιρέσεις είναι αντικείμενα και συνήθως περιέχουν δεδομένα για την εξαίρεση. Έτσι μπορείς να πάρεις το αντικείμενο της εξαίρεσης:

```ruby
begin
  # ...any code that raises an exception
rescue => e
  puts "Exception class: #{ e.class.name }"
  puts "Exception Message:#{e.message}"
end
```

Στη Ruby είναι επίσης δυνατό να πετάξεις τις δικές σου εξαιρέσεις. Για παράδειγμα:

```ruby
begin
  raise ArgumentError.new("Invalid argument")
rescue ArgumentError => e
  puts e.message
end
```

Η προηγούμενη εξαίρεση είναι μία από τις ενσωματωμένες εξαιρέσεις της Ruby, αλλά είναι επίσης δυνατό να ορίσεις προσαρμοσμένες εξαιρέσεις και να τις πετάξεις:

```ruby
class CustomError < StandardError
end

raise CustomError.new("Something went wrong")
```
