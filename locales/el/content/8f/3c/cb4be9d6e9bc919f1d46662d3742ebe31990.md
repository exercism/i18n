# Οδηγίες

Είναι η Ημέρα του Αγίου Βαλεντίνου. Ο σύντροφός σου έχει μερικές ιδέες για
δραστηριότητες και σου ζητάει να βαθμολογήσεις την καθεμία: `yes`, `no` ή `maybe`.

Οι δραστηριότητες αναπαρίστανται ως πίνακες 2 στοιχείων `{ tag value }`,
όπου το `tag` είναι ένα από τα `board-game`, `chill`, `movie`, `restaurant`
ή `walk`.

| δραστηριότητα               | μορφή                       |
| ------------------------- | --------------------------- |
| Παίξε επιτραπέζιο παιχνίδι | `{ board-game f }`          |
| Χαλάρωσε                  | `{ chill f }`               |
| Δες μια ταινία `genre`     | `{ movie genre }`           |
| Φάε σε μαγαζί `cuisine`    | `{ restaurant cuisine }`    |
| Περπάτησε `km` χιλιόμετρα  | `{ walk km }`               |

Το είδος είναι ένα από τα `crime`, `horror`, `romance`, `thriller`. Η
κουζίνα είναι `korean` ή `turkish`.

## 1. Αξιολόγησε την κουζίνα

Όρισε τη `rate-restaurant` ώστε να παίρνει μια κουζίνα από τη στοίβα και να
επιστρέφει την έγκρισή σου:

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. Αξιολόγησε το είδος της ταινίας

Όρισε τη `rate-movie` ώστε να παίρνει ένα είδος και να επιστρέφει:

- `romance` → `yes`
- οτιδήποτε άλλο → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. Αξιολόγησε το περπάτημα

Όρισε τη `rate-walk` ώστε να παίρνει έναν αριθμό χιλιομέτρων και να
επιστρέφει:

- πάνω από `11` → `yes`
- πάνω από `6`, μέχρι `11` → `maybe`
- διαφορετικά → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. Αξιολόγησε τη δραστηριότητα

Όρισε τη `rate-activity` ώστε να παίρνει από τη στοίβα μια δραστηριότητα
`{ tag value }` και να επιστρέφει την έγκρισή σου. Επανάχρησιμοποίησε τις
βοηθητικές συναρτήσεις πιο πάνω:

- `board-game`, `chill` → πάντα `no`
- `movie` → ανάθεσέ το στη `rate-movie`
- `restaurant` → ανάθεσέ το στη `rate-restaurant`
- `walk` → ανάθεσέ το στη `rate-walk`

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. Μέτρησε τις εγκρίσεις

Όρισε τη `approval-counts` ώστε να παίρνει μια λίστα δραστηριοτήτων και να
επιστρέφει έναν πίνακα 3 στοιχείων `{ yes-count maybe-count no-count }` με το
πόσες βαθμολογήθηκαν με τον κάθε τρόπο.

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
