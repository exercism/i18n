# Τελεστής ανάλυσης εμβέλειας

Ο τελεστής ανάλυσης εμβέλειας (`::`) μάς επιτρέπει να αναφερόμαστε σε μια κλάση για να έχουμε πρόσβαση στις σταθερές ονομάτων της, στις στατές ιδιότητες ή στις στατές μεθόδους της.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Χρήση των `self` και `static` με τον τελεστή ανάλυσης εμβέλειας

Μπορεί να χρειαστεί ένα αντικείμενο να αναφερθεί στην εμβέλειά του. Για να γίνει αυτό, η λέξη-κλειδί `self` επιτρέπει σε μια κλάση να αναφέρεται στην εμβέλειά της. Η χρήση της λέξης-κλειδιού `self` αποσυνδέει την κλάση από το όνομά της, κάνοντας ευκολότερη τη συντήρηση του κώδικα με την πάροδο του χρόνου.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Χρησιμοποίησε τη λέξη-κλειδί `static` με τον τελεστή ανάλυσης εμβέλειας για να κάνεις "καθυστερημένη σύνδεση" της αναφοράς με την τρέχουσα κλάση-απόγονο.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Χρήση του `parent` με τον τελεστή ανάλυσης εμβέλειας

Η λέξη-κλειδί `parent` χρησιμοποιείται για να αναφερθούμε σε σταθερά, ιδιότητες ή μεθόδους της γονικής κλάσης. Συνήθως χρησιμοποιείται για να καλέσουμε τον κατασκευαστή της γονικής κλάσης όταν δημιουργείται ένα αντικείμενο:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Επιφυλάξεις

### Ορατότητα σταθερών, ιδιοτήτων και μεθόδων

Ο τελεστής ανάλυσης εμβέλειας εξακολουθεί να ακολουθεί τους κανόνες που ορίζουν οι τροποποιητές ορατότητας `public`, `private` και `protected`.
