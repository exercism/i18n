# Δικαιώματα λογαριασμών στον ιστότοπο

## Ιστορία

Σε αυτή την άσκηση θα ελέγχεις τα δικαιώματα λογαριασμών χρηστών σε ένα φόρουμ στο διαδίκτυο. Το φόρουμ υποστηρίζει τρία διαφορετικά δικαιώματα:

- Read
- Write
- Delete

Υπάρχουν τρία είδη λογαριασμών, καθένα με διαφορετικά προεπιλεγμένα δικαιώματα:

- Επισκέπτες: μπορούν να διαβάζουν αναρτήσεις.
- Χρήστες: μπορούν να διαβάζουν και να γράφουν αναρτήσεις.
- Συντονιστές: μπορούν να διαβάζουν, να γράφουν και να διαγράφουν αναρτήσεις.

Μερικές φορές τροποποιούνται μεμονωμένα δικαιώματα, για παράδειγμα δίνοντας σε έναν λογαριασμό επισκέπτη το δικαίωμα να γράφει κι αυτός αναρτήσεις.

## Εργασίες

Αυτές είναι ενδεικτικές εργασίες που ταιριάζουν στην άσκηση για τα δικαιώματα λογαριασμών στον ιστότοπο:

- Λήψη των προεπιλεγμένων δικαιωμάτων για έναν τύπο λογαριασμού
- Παραχώρηση ενός δικαιώματος
- Ανάκληση ενός δικαιώματος
- Έλεγχος ύπαρξης ενός δικαιώματος
