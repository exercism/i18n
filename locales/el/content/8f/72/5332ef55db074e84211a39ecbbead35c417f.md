## Οδηγίες

Η αποστολή σου είναι να δημιουργήσεις τους τέλειους λαβυρίνθους για τον Mickey και τη Minerva: αυτούς που έχουν μόνο μία λύση και κανένα απομονωμένο τμήμα.
Να τι πρέπει να ξέρεις:

- Ο λαβυρίνθος έχει ορθογώνιο σχήμα με ένα άνοιγμα στην αρχή και στο τέλος.
- Ο λαβυρίνθος έχει δωμάτια και διαδρόμους, που τέμνονται σε ορθή γωνία.
- Το πρόγραμμα πρέπει να δέχεται δύο παραμέτρους: γραμμές και στήλες. Ο λαβυρίνθος πρέπει να έχει μέγεθος από 5 έως 100 κελιά.
- Ένας λαβυρίνθος πλάτους `x` στηλών και ύψους `y` γραμμών πρέπει να έχει πλάτος `2x + 1` χαρακτήρες και ύψος `2y + 1` χαρακτήρες.
- Αν δεν δοθεί seed, δημιούργησε έναν τυχαίο λαβυρίνθο. Αν δοθεί το ίδιο seed πολλές φορές, ο λαβυρίνθος που προκύπτει πρέπει να είναι ο ίδιος κάθε φορά.
- Χρησιμοποίησε [χαρακτήρες σχεδίασης πλαισίων][Box-drawing] για να σχεδιάσεις τους τοίχους, και ένα σύμβολο βέλους (⇨) για την είσοδο στα αριστερά και την έξοδο στα δεξιά.

Ήρθε η ώρα να φτιάξεις μερικούς τέλειους λαβυρίνθους για αυτά τα τολμηρά ποντίκια!

### Παραδείγματα

1. Ο μικρός τετράγωνος λαβυρίνθος 5x5 κελιά (ή 11x11 χαρακτήρες)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. Ο ορθογώνιος λαβυρίνθος 6x18 κελιά
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
