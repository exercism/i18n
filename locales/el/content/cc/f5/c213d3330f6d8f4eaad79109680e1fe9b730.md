# Σχετικά

Οι [λίστες][list] είναι ένας βασικός τύπος δεδομένων στην Elixir για να κρατούν μια συλλογή τιμών. Οι λίστες είναι _αμετάβλητες_, που σημαίνει ότι δεν μπορούν να τροποποιηθούν. Κάθε πράξη που αλλάζει μια λίστα επιστρέφει μια νέα λίστα. Οι λίστες υλοποιούν το [πρωτόκολλο Enumerable][enum-protocol], που επιτρέπει τη χρήση συναρτήσεων των μονάδων [Enum][enum] και [Stream][stream].

Οι λίστες στην Elixir υλοποιούνται ως [συνδεδεμένες λίστες][linked-list-wiki] και όχι ως πίνακες με συνεχόμενες θέσεις μνήμης. Επομένως, η πρόσβαση σε ένα στοιχείο μιας λίστας απαιτεί γραμμικό χρόνο, ανάλογα με το μήκος της λίστας.

Οι λίστες μπορούν να γραφτούν σε μορφή παράθεσης στοιχείων, σε συμβολισμό κεφαλής-ουράς (που χρησιμοποιεί τον τελεστή `cons`, `|`) ή σε συνδυασμό και των δύο:

```elixir
# Literal Form
[]
[1]
[1, 2, 3]

# Head-tail Notation
[]
# same as [1]
[1 | []]
# same as [1, 2, 3]
[1 | [2 | [3 | []]]]

# Mixed
# same as [1, 2, 3]
[1 | [2, 3]]
```

Μπορεί επίσης να υπάρχουν περισσότερα από ένα στοιχεία πριν από τον τελεστή _cons_ (`|`).

```elixir
# Multiple prepends
[1, 2, 3 | [4, 5]]
```

Ο συμβολισμός κεφαλής-ουράς μπορεί να χρησιμοποιηθεί για να προσθέσεις στοιχεία στο τέλος μιας λίστας.

```elixir
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Η προσθήκη στοιχείων στο τέλος μιας λίστας κατά την επανάληψη θεωρείται αντιπρότυπο. Για να προσθέσεις ένα στοιχείο στο τέλος, πρέπει να διασχίσεις ολόκληρη τη λίστα και να το βάλεις εκεί, επομένως η προσθήκη ενός νέου στοιχείου σε κάθε επανάληψη θα απαιτούσε να διασχίζεις ολόκληρη τη λίστα σε κάθε επανάληψη.

Μπορούμε να πετύχουμε το ίδιο αποτέλεσμα προσθέτοντας ένα στοιχείο στην αρχή της ανεστραμμένης λίστας και μετά αντιστρέφοντας το αποτέλεσμα. Η προσθήκη στην αρχή είναι γρήγορη πράξη και απαιτεί σταθερό χρόνο.

```elixir
# Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

# Prepend to the start of a list (faster, due to the nature of linked lists)
[6 | [5 | [4 | [3, 2, 1]]]]
# then reverse!
```

Υπάρχουν αρκετές συνηθισμένες συναρτήσεις της `Kernel` για λίστες:

- Η [`hd/1`][hd] επιστρέφει την _κεφαλή_ μιας λίστας, δηλαδή το _πρώτο_ στοιχείο της.
- Η [`tl/1`][tl] επιστρέφει την _ουρά_ της λίστας, δηλαδή τη λίστα _χωρίς_ το _πρώτο_ στοιχείο.
- Η [`length/1`][length] επιστρέφει τον αριθμό των στοιχείων της λίστας.
- Η [`in/2`][in] επιστρέφει μια τιμή Boolean που δείχνει αν το στοιχείο είναι μέλος της λίστας.

Υπάρχει επίσης η [μονάδα `List`][list].

Οι λίστες μπορούν να περιέχουν οποιονδήποτε τύπο δεδομένων, ακόμα και ανάμειξη διαφορετικών τύπων.

```elixir
list = [1, :a, 2.0, "string"]
```
