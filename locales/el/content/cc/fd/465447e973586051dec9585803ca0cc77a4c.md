# Προσθήκη οδηγιών

## Λέξεις

Όρισε μια πλειάδα `game` και έναν κατασκευαστή `<game> ( -- game )` που επιστρέφει ένα νέο παιχνίδι χωρίς ρίψεις.

Δώσε αυτές τις λέξεις που λειτουργούν σε ένα παιχνίδι:

- `roll ( pins game -- )`: καταγράφει ότι ρίχτηκαν κάτω `pins` κορύνες. Πέτα ένα σφάλμα όταν η ρίψη είναι άκυρη:
  - `"Negative roll is invalid"` για αρνητικό αριθμό κορυνών.
  - `"Cannot roll after game is over"` όταν έχουν ριχτεί και τα δέκα καρέ (και τυχόν συμπληρωματικές ρίψεις).
  - `"Pin count exceeds pins on the lane"` όταν ρίχνονται κάτω περισσότερες κορύνες απ' όσες στέκονται.
- `score ( game -- n )`: το συνολικό σκορ για το παιχνίδι. Πέτα `"Score cannot be taken until the end of the game"` όταν το παιχνίδι δεν έχει ακόμη ολοκληρωθεί.

Σημείωσε ότι το `roll` επισκιάζει τη λέξη shuffle `roll` από το λεξιλόγιο `kernel`. Η σουίτα δοκιμών το αποσαφηνίζει με `FROM: bowling => roll ;`.
