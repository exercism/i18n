# Υποδείξεις

## Γενικά

- Το [πακέτο `roc-random`](https://github.com/kili-ilo/roc-random) είναι διαθέσιμο στην κεφαλή του αρχείου `simple-cipher-test.roc` (με ψευδώνυμο `random`).
  Μπορείς να το χρησιμοποιήσεις στη λύση σου αν θέλεις, για παράδειγμα κάνοντας import το `random.Random`.

- Το `Random.step(state, generator)` επιστρέφει `{ value, state }`, δηλαδή μια τιμή που παράχθηκε μαζί με την ενημερωμένη κατάσταση της γεννήτριας.
  Επίστρεψε αυτή την ενημερωμένη κατάσταση από τη `create_random`, ώστε η επόμενη κλήση να μπορεί να συνεχίσει την ακολουθία.

- Τα `Random.list` και `Random.map` μπορούν να σε βοηθήσουν να φτιάξεις μια γεννήτρια για ένα ολόκληρο κλειδί.
