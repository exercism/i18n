# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις πάνω σε κάποιες συναρτήσεις για να διαχειρίζεσαι ραντεβού.
Το σύστημα αποθηκεύει τα πάντα σε συμβολοσειρές με μορφή ISO 8601, αλλά οι άνθρωποι δεν χρησιμοποιούν έτσι το ημερολόγιο.
Χρειάζονται διάφορες συναρτήσεις για τη μετατροπή μεταξύ των διαφόρων μορφών.

## 1. Δημιούργησε ένα ραντεβού

Δημιούργησε ένα ραντεβού `n` ημέρες από τώρα, στην τρέχουσα ώρα.
Η συνάρτηση παίρνει `n` ημέρες και επιστρέφει την ώρα του ραντεβού `n` ημέρες από τώρα.

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

Αν η δεύτερη παράμετρος `now` δεν χρησιμοποιηθεί, θα πρέπει να χρησιμοποιηθεί η τρέχουσα ώρα.

## 2. Μετέτρεψε μια ημερομηνία σε χρονική σήμανση

Διάφορα εργαλεία λειτουργούν μόνο με τη διεθνώς τυποποιημένη μορφή ISO 8601.
Γράψε τη συνάρτηση `getAppointmentTimestamp` που παίρνει μια ημερομηνία και επιστρέφει μια συμβολοσειρά σε αυτή τη μορφή.

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. Πάρε τις λεπτομέρειες ενός ραντεβού

Οι χρονικές σημάνσεις είναι δύσκολο να διαβαστούν, οπότε μια συνάρτηση που παίρνει τις λεπτομέρειες του ραντεβού θα βοηθήσει.
Η συνάρτηση `getAppointmentDetails` παίρνει μια χρονική σήμανση σε μορφή ISO 8601 και επιστρέφει το έτος, τον μήνα, την ημέρα, την ώρα και το λεπτό.

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. Ενημέρωσε ένα ραντεβού με τις δοσμένες επιλογές

Η συνάρτηση θα λάβει ως πρώτο όρισμα την ώρα του ραντεβού και ως δεύτερο όρισμα ένα αντικείμενο με κάποιες επιλογές.
Πρέπει να ενημερώσεις το ραντεβού σύμφωνα με τις επιλογές του αντικειμένου και να επιστρέψεις τη νέα ημερομηνία του ραντεβού.
Το αντικείμενο επιλογών μπορεί να έχει πολλαπλές επιλογές.

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. Βρες τον διαθέσιμο χρόνο μεταξύ δύο ραντεβού

Η συνάρτηση θα λάβει δύο ραντεβού (χρονικές σημάνσεις) ως ορίσματα.
Πρέπει να επιστρέψεις τη διαφορά μεταξύ αυτών των δύο χρόνων σε δευτερόλεπτα.

Επειδή το μισό δευτερόλεπτο είναι σχεδόν χωρίς νόημα, στρογγυλοποίησε τον αριθμό πριν τον επιστρέψεις.

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. Έλεγξε αν ένα ραντεβού είναι έγκυρο τώρα ή όχι

Τέλος, όταν κλείνεται το ραντεβού, το σύστημα πρέπει να ελέγξει αν είναι έγκυρο.
Με άλλα λόγια, το ραντεβού πρέπει να είναι στο μέλλον και όχι στο παρελθόν.

Γράψε τη συνάρτηση `isValid` που παίρνει δύο ορίσματα, μια χρονική σήμανση ραντεβού (συμβολοσειρά) και την τρέχουσα ώρα ως χρονική σήμανση (συμβολοσειρά), και επιστρέφει `true` αν το ραντεβού είναι στο μέλλον, δεδομένης της τρέχουσας ώρας.

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
