# Έννοιες των Αριθμών Armstrong

> Ένας [αριθμός Armstrong](https://en.wikipedia.org/wiki/Narcissistic_number) είναι ένας αριθμός που ισούται με το άθροισμα των ψηφίων του, όπου κάθε ψηφίο είναι υψωμένο στη δύναμη του πλήθους των ψηφίων.

## Παράδειγμα λύσης

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## Έννοιες

- συναρτήσεις: απαραίτητες για την επαλήθευση της λύσης και τον καθορισμό της λογικής
- Σύνολα δοκιμών: απαραίτητα για την επαλήθευση της λύσης
- ακέραιοι: u32 για το όρισμα και τους ελέγχους ταυτότητας
- `&str`: απαραίτητο για τη μέτρηση του μήκους του αριθμού, καθώς η Rust έχει ισχυρή τυποποίηση
- `Option<T>`: απαραίτητο για την πρόσβαση στην πραγματική τιμή του `char::to_digit`
- μετατροπή τύπων: απαιτείται για την εφαρμογή αριθμητικών πράξεων
- χαρακτηριστικά των iterator:
  - turbofish για να γίνει δυνατή η λύση με μία μόνο έκφραση
  - `map` και `sum` για τη βολική αναγωγή της έκφρασης σε αυτό που χρειάζεται να ελέγξουμε
