# Εισαγωγή

Η PowerShell είναι μια δυναμικά και σιωπηρά τυποποιημένη γλώσσα σεναρίων από τη Microsoft (υποστηρίζει επίσης και ισχυρά τυποποιημένες μεταβλητές), με κύρια έμφαση στην αυτοματοποίηση εργασιών και τη διαχείριση διαμόρφωσης.

Η PowerShell υποστηρίζει προστακτικό, συναρτησιακό και αντικειμενοστραφή προγραμματισμό, ακόμη και στυλ αγωγού.

Η PowerShell χτίστηκε πάνω στην πλατφόρμα .NET και κυκλοφόρησε για πρώτη φορά το 2006.
Περιλαμβάνεται εξ ορισμού σε όλα τα σύγχρονα λειτουργικά συστήματα Windows και μπορεί να εγκατασταθεί σε Mac και Linux.


## Μεταβλητές

Υπάρχουν δύο συνηθισμένοι τρόποι για να ορίσεις μια μεταβλητή στην PowerShell.

Το όνομα μιας μεταβλητής στην PowerShell πρέπει να ξεκινά με `$` και χρησιμοποιείς τον τελεστή ανάθεσης `=` για να δεσμεύσεις το όνομα της μεταβλητής σε μια τιμή.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

Μπορείς επίσης να ορίσεις ρητά τον τύπο μιας μεταβλητής, αν θέλεις να επιβάλεις έναν συγκεκριμένο [τύπο][strong typed].
Η PowerShell θα κάνει ό,τι μπορεί για να μετατρέψει την τιμή από έναν τύπο σε έναν άλλο, αν αυτό είναι εφικτό.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### Σταθερές

Οι σταθερές στην PowerShell είναι μεταβλητές μόνο για ανάγνωση που δεν μπορούν να **αφαιρεθούν** αφού οριστούν.
Αυτό μας οδηγεί στον δεύτερο τρόπο ορισμού μεταβλητών, χρησιμοποιώντας το cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

Για έναν πιο αναλυτικό και προχωρημένο τρόπο δημιουργίας μιας νέας μεταβλητής με διάφορες επιλογές, δες το cmdlet [New-Variable][New-Variable].


## Συναρτήσεις

Οι [συναρτήσεις][functions] στην PowerShell ορίζονται με τη λέξη-κλειδί `function`.
Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες τυπικές [παραμέτρους][parameters] μέσα στις παρενθέσεις `()`, και ακολουθεί η δική της [εμβέλεια][scope] που ξεκινά με `{` και τελειώνει με `}`. 

```powershell
function Greeting {
    return "Hello!"
}
```

Οι συναρτήσεις στην PowerShell μπορούν να επιστρέφουν τιμές ρητά μέσω της λέξης-κλειδιού `return`, αφού κληθούν με τη σύνταξη `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

Μια πιο προχωρημένη ματιά στο πώς να γράψεις έναν λεπτομερή ορισμό συνάρτησης και στο πώς οι συναρτήσεις μπορούν να επιστρέφουν τιμές έμμεσα θα καλυφθεί στην ενότητα της έννοιας `Functions`.


## Σχόλια

Ένα μεμονωμένο σχόλιο στην PowerShell ξεκινά με `#` και τελειώνει στο τέλος της γραμμής.
Ένα μπλοκ σχολίων στην PowerShell ξεκινά με `<#` και τελειώνει με `#>`.
Μια πιο προχωρημένη παρουσίαση του μπλοκ σχολίων για τη δημιουργία Comment-Based Help θα καλυφθεί στην ενότητα της έννοιας `Functions`.

```powershell
function Main() {
    #This is a comment
}
```
