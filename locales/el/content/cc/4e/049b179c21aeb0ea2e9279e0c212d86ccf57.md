# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις με λογαριασμούς ταμιευτηρίου.
Κάθε χρόνο, το υπόλοιπο του λογαριασμού ταμιευτηρίου σου ενημερώνεται με βάση το επιτόκιό του.
Το επιτόκιο που σου δίνει η τράπεζά σου εξαρτάται από το ποσό των χρημάτων στον λογαριασμό σου (το υπόλοιπό του):

- 3.213% για αρνητικό υπόλοιπο (το υπόλοιπο γίνεται πιο αρνητικό).
- 0.5% για θετικό υπόλοιπο μικρότερο από `1000` δολάρια.
- 1.621% για θετικό υπόλοιπο μεγαλύτερο ή ίσο με `1000` δολάρια και μικρότερο από `5000` δολάρια.
- 2.475% για θετικό υπόλοιπο μεγαλύτερο ή ίσο με `5000` δολάρια.

Έχεις τέσσερις εργασίες, και καθεμία από αυτές θα ασχοληθεί με το υπόλοιπό σου και το επιτόκιό του.

## 1. Υπολόγισε το επιτόκιο

Υλοποίησε τη μέθοδο `SavingsAccount.interest_rate()` που παίρνει ως όρισμα ένα υπόλοιπο.
Η μέθοδος πρέπει να επιστρέφει το επιτόκιο για το δεδομένο υπόλοιπο.

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. Υπολόγισε τον τόκο

Υλοποίησε τη μέθοδο `SavingsAccount.interest()` που παίρνει ως όρισμα ένα υπόλοιπο.
Η μέθοδος πρέπει να επιστρέφει τον τόκο για το δεδομένο υπόλοιπο.

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

Υλοποίησε τη μέθοδο `SavingsAccount.annual_balance_update()` που παίρνει ως όρισμα ένα υπόλοιπο.
Η μέθοδος πρέπει να επιστρέφει το υπόλοιπο μετά από ένα χρόνο.

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. Υπολόγισε τα χρόνια που χρειάζονται μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

Υλοποίησε τη μέθοδο `SavingsAccount.years_before_desired_balance()` που παίρνει ως ορίσματα ένα υπόλοιπο και ένα υπόλοιπο-στόχο.
Η μέθοδος πρέπει να επιστρέφει τον αριθμό των χρόνων που θα χρειαζόταν για να φτάσεις στο υπόλοιπο-στόχο.

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
Όταν εφαρμόζεις απλό τόκο σε ένα αρχικό κεφάλαιο, το υπόλοιπο πολλαπλασιάζεται με το επιτόκιο και το γινόμενο των δύο είναι το ποσό του τόκου.

Ο σύνθετος τόκος, από την άλλη, εφαρμόζεται σε επαναλαμβανόμενη βάση.
Σε κάθε εφαρμογή, το ποσό του τόκου υπολογίζεται και προστίθεται στο αρχικό κεφάλαιο, ώστε οι επόμενοι υπολογισμοί τόκου να γίνονται πάνω σε μεγαλύτερο αρχικό κεφάλαιο.
~~~~
