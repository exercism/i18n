# Οδηγίες

Αυτό το τηλεκατευθυνόμενο αυτοκίνητο που αγόρασες πρόσφατα έχει εξελιχθεί σε ένα ολόκληρο νέο χόμπι. Διοργανώνεις αγώνες τηλεκατευθυνόμενων αυτοκινήτων.

Είχες σχεδόν τελειώσει τη συγγραφή ενός προγράμματος που θα επέτρεπε να τρέχεις προσομοιώσεις αγώνων, όταν η γάτα σου πήδηξε στο πληκτρολόγιό σου και διέγραψε μερικές γραμμές κώδικα. Τώρα το πρόγραμμά σου δε μεταγλωττίζεται πια...

## 1. Διόρθωσε το σφάλμα μεταγλώττισης `Race.__struct__/0 is undefined`

Πρόσθεσε ένα alias ώστε η ενότητα `NeedForSpeed.Race` να μπορεί να αναφέρεται με το συντομότερο όνομα `Race`.

## 2. Διόρθωσε το σφάλμα μεταγλώττισης `Car.__struct__/0 is undefined`

Πρόσθεσε ένα alias ώστε η ενότητα `NeedForSpeed.RemoteControlCar` να μπορεί να αναφέρεται με το συντομότερο όνομα `Car`.

## 3. Διόρθωσε το σφάλμα μεταγλώττισης `undefined function puts/1`

Η συνάρτηση `puts/1` προέρχεται από την ενότητα `IO`. Κάνε import τη συνάρτηση για να μπορείς να τη χρησιμοποιήσεις χωρίς να αναφέρεις την ενότητα.

## 4. Διόρθωσε το σφάλμα μεταγλώττισης `undefined function default_color/0`

Οι συναρτήσεις `default_color/0`, `red/0`, `cyan/0` και `green/0` προέρχονται όλες από την ενότητα `IO.ANSI`. Σχεδιάζεις να προσθέσεις υποστήριξη για άλλα χρώματα αυτοκινήτων, οπότε θέλεις να κάνεις import ολόκληρη την ενότητα. Δυστυχώς, η συνάρτηση `color/1` από την ενότητα `IO.ANSI` συγκρούεται με μία από τις τοπικές σου συναρτήσεις. Κάνε import ολόκληρη την ενότητα `IO.ANSI` εκτός από αυτή τη συνάρτηση.
