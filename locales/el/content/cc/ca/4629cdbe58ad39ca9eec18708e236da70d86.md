# Σχετικά

Τα [guards][guards] χρησιμοποιούνται ως συμπλήρωμα της [αντιστοίχισης προτύπων][exercism-pattern-matching]. Επιτρέπουν πιο σύνθετους ελέγχους. Μπορούν να χρησιμοποιηθούν σε [κάποιες, αλλά όχι όλες τις περιπτώσεις][where-guards-can-be-used] όπου μπορεί να χρησιμοποιηθεί η αντιστοίχιση προτύπων, για παράδειγμα σε ρήτρες συναρτήσεων ή ρήτρες case.

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- Τα guards ξεκινούν με τη λέξη-κλειδί `when`, την οποία ακολουθεί μια έκφραση Boolean.
- Οι εκφράσεις των guards είναι ειδικές συναρτήσεις που:
  - Πρέπει να είναι [καθαρές][pure-function] και να μην μεταβάλλουν καμία καθολική κατάσταση.
  - Πρέπει να επιστρέφουν αυστηρά τις τιμές `true` ή `false`.
- Στην [τεκμηρίωση της Elixir][kernel-guards] θα βρεις μια λίστα με τα πιο συνηθισμένα guards. Περιλαμβάνουν:
  - Ελέγχους τύπων: [`is_integer/1`][guard-is-integer], [`is_list/1`][guard-is-list], [`is_nil/1`][guard-is-nil] κ.λπ.
  - Αριθμητικούς τελεστές: [`+/2`][guard-plus], [`-/2`][guard-minus] κ.λπ.
  - Συγκρίσεις: [`==/2`][guard-equals], [`>/2`][guard-greater], [`</2`][guard-less] κ.λπ.
  - Τελεστές Boolean: [`and/2`][guard-and], [`or/2`][guard-or], [`not/1`][guard-not]
  - Τελεστή συμμετοχής: [`in/2`][guard-in]
- Μπορείς να ορίσεις το δικό σου guard με το [`defguard`][defguard].

  - Σύμφωνα με τη [σύμβαση ονοματοδοσίας][naming] της Elixir, τα ονόματα των guards πρέπει να ξεκινούν με `is_`.

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
