# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                                      |
| -------- | ------------ | ------- | --------------------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά εισόδου τερματισμένη με null            |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | πίνακας λέξεων με τα τελικά πλήθη νουκλεοτιδίων |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | για προσωρινή αποθήκευση                   |
