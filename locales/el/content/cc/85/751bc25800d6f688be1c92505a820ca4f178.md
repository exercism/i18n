# επαναχρησιμοποίηση συνάρτησης

Η επαναχρησιμοποίηση μιας συνάρτησης που έχεις ήδη γράψει μπορεί να βοηθήσει όταν γράφεις κώδικα που συντηρείται εύκολα.

Επαναχρησιμοποίησε τις υπάρχουσες συναρτήσεις:
- Η `initial/1` μπορεί να επαναχρησιμοποιήσει την `first_letter/1`
- Η `initials/1` μπορεί να επαναχρησιμοποιήσει την `initial/1`
- Η `pair/2` μπορεί να επαναχρησιμοποιήσει την `initials/1`
