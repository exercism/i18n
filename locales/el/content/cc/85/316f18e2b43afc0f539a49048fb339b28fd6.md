# Σχετικά

Στη C++, οι Boolean (λογικές τιμές) αντιπροσωπεύονται από τον τύπο `bool`.
Ένα `bool` είναι είτε `true` είτε `false`.

## Λογικοί τελεστές

Η C++ υποστηρίζει τρεις τελεστές Boolean: `!` (NOT), `&&` (AND) και `||` (OR).
Μπορείς επίσης να χρησιμοποιήσεις τις εναλλακτικές μορφές `not`, `and` και `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Προτεραιότητα

Ο καθένας από τους τρεις τελεστές Boolean έχει διαφορετική _προτεραιότητα τελεστών_.
Κατά συνέπεια, αξιολογούνται με αυτή τη σειρά: πρώτα το `!`, μετά το `&&` και τέλος το `||`.
Αν θέλεις να επιβάλεις διαφορετική σειρά, μπορείς να περικλείσεις μια Boolean έκφραση σε παρενθέσεις (δηλ. `()`), καθώς οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Μετατροπή

Αν χρησιμοποιήσεις `true` ή `false` σε θέση όπου περιμένεις έναν αριθμό, θα μετατραπούν σε `1` και `0` αντίστοιχα.
Αν χρησιμοποιήσεις έναν αριθμό σε μια Boolean πράξη, τα πάντα εκτός από το `0` αντιμετωπίζονται ως `true`, ακόμη και οι αρνητικές τιμές.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
