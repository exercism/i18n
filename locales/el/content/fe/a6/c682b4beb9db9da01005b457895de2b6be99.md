# Εισαγωγή

Η έννοια [`Basics`][basics] παρουσίασε δύο τρόπους για να ορίσεις μια συνάρτηση.

Πιο γενικά, η πολυγραμμική μορφή:

```julia
function muladd(x, y, z)
    x * y + z
end
```

Η μορφή "εκχώρησης", ή "μονής γραμμής", για σύντομους ορισμούς:
```julia
muladd(x, y, z) = x * y + z
```

Σε μια τρίτη, ακόμη πιο σύντομη μορφή, μπορείς να δημιουργήσεις μια σύντομη συνάρτηση που χρησιμοποιείται μία φορά, χωρίς όνομα:

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

Στην περίπτωση αυτή, το `x -> 2x` είναι μια "ανώνυμη συνάρτηση".
Είναι ισοδύναμο με αυτό που σε κάποιες άλλες γλώσσες ονομάζεται "συνάρτηση λάμδα".

Σημείωσε ότι τα πολλαπλά ορίσματα χρειάζονται παρενθέσεις, όπως στο `(x, y) -> x * y`.

Οι ανώνυμες συναρτήσεις είναι συνηθισμένες στον κώδικα Julia, ειδικά όταν συνδυάζονται με συναρτήσεις ανώτερης τάξης όπως οι `map()` και `filter()` (τις οποίες θα δούμε πιο αναλυτικά σε κάποια επόμενη έννοια).

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## Ορίσματα συναρτήσεων

Μέχρι τώρα στη διδακτέα ύλη, έχουμε δει μόνο συναρτήσεις που έχουν έναν συγκεκριμένο αριθμό ορισμάτων και απαιτούν από τις κλήσεις της συνάρτησης να τα παρέχουν όλα, με τη σωστή σειρά.
Αυτό θα ήταν περιοριστικό και άβολο, γι' αυτό υπάρχουν αρκετές άλλες επιλογές.

### Προαιρετικά ορίσματα

Όπως πολλές γλώσσες, η Julia επιτρέπει στους ορισμούς συναρτήσεων να παρέχουν προεπιλεγμένες τιμές για μεμονωμένα ορίσματα.

Η κλήση της συνάρτησης μπορεί τότε είτε να παρέχει μια τιμή για αυτό το όρισμα είτε να το παραλείπει και να βασίζεται στην προεπιλεγμένη τιμή.

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

Όλα τα ορίσματα _χωρίς_ προεπιλεγμένη τιμή πρέπει να έρχονται πριν από οποιοδήποτε όρισμα _με_ προεπιλεγμένη τιμή, που σημαίνει ότι το `f(x=2, y)` θα ήταν άκυρο.

### Ορίσματα με λέξεις-κλειδιά

Όλα τα παραδείγματα μέχρι τώρα χρησιμοποιούν `positional arguments`, όπου οι τιμές που παρέχονται σε μια κλήση συνάρτησης πρέπει να ταιριάζουν με τη σειρά των αντίστοιχων ορισμάτων στον ορισμό της συνάρτησης.

Όπως πολλές γλώσσες, η Julia επιτρέπει επίσης `keyword arguments`.
Οι κλήσεις συναρτήσεων πρέπει να προσδιορίζουν το όνομα του ορίσματος, αλλά στη συνέχεια μπορούν να δοθούν πολλά ορίσματα με λέξεις-κλειδιά με οποιαδήποτε σειρά.

Ένα ξεχωριστό χαρακτηριστικό της Julia είναι ότι στα ορίσματα με λέξεις-κλειδιά (αν υπάρχουν) στον ορισμό της συνάρτησης πρέπει να προηγείται ένα `;`, που τα χωρίζει από τα ορίσματα θέσης.
Μια κλήση συνάρτησης μπορεί να χρησιμοποιήσει είτε `;` είτε `,` ανάμεσα στο τελευταίο όρισμα θέσης και στο πρώτο όρισμα με λέξη-κλειδί.

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

Οι προεπιλεγμένες τιμές μπορούν προαιρετικά να οριστούν, ακριβώς όπως στα ορίσματα θέσης.

Είναι συνηθισμένο να καταλήγεις με σύνταξη όπως `myarg=myarg` μέσα σε μια κλήση συνάρτησης, όταν μια μεταβλητή με το ίδιο όνομα με την παράμετρο έχει υπολογιστεί εκ των προτέρων.
Σε αυτή την περίπτωση επιτρέπεται μια συντομευμένη σύνταξη:

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat και slurp

Αυτά είναι τα καθιερωμένα ονόματα για μια χρήσιμη πτυχή της σύνταξης της Julia, σε περίπτωση που αναρωτιόσουν.
Και τα δύο αναφέρονται στον τελεστή `...`.

#### Splat

Το splatting χρησιμοποιείται στις _κλήσεις_ συναρτήσεων, για να επεκτείνει συλλογές σε μεμονωμένες τιμές που απαιτεί η συνάρτηση.

Ίσως είναι πιο εύκολο να το δείξουμε παρά να το εξηγήσουμε:

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

Κάποιες "κλήσεις συναρτήσεων" κρύβονται πίσω από συντακτική ζάχαρη, οπότε το splatting μπορεί να χρησιμοποιηθεί και με λιγότερο προφανείς τρόπους.

Για παράδειγμα, η πολλαπλή εκχώρηση χρησιμοποιεί εσωτερικά μια συνάρτηση κατασκευής πλειάδας:

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

Τα ορίσματα με λέξεις-κλειδιά μπορούν επίσης να δοθούν μέσω splatting, συνήθως χρησιμοποιώντας μια `named tuple`. 
Ένα `Dict` λειτουργεί επίσης, αλλά τα κλειδιά πρέπει να είναι σύμβολα (οι συμβολοσειρές δεν λειτουργούν).

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Το slurping χρησιμοποιείται στον _ορισμό_ της συνάρτησης, για να συσκευάσει έναν αυθαίρετο αριθμό μεμονωμένων τιμών σε μια συλλογή.

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

Το όνομα του ορίσματος που συλλέγεται με slurping (εδώ το `more`) δεν έχει σημασία.
Ο τύπος αυτής της μεταβλητής επιλέγεται από τον μεταγλωττιστή, αλλά για τα ορίσματα θέσης πιθανότατα είναι `tuple` ή κάτι παρόμοιο.

Τα ορίσματα με λέξεις-κλειδιά μπορούν επίσης να συλλεχθούν με slurping, δίνοντας ένα `Dict` (ή κάτι παρόμοιο).

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

Οποιαδήποτε ορίσματα με λέξεις-κλειδιά μπορούν να χρησιμοποιηθούν στην κλήση.
Ο ορισμός της συνάρτησης αποφασίζει σε ποιες λέξεις-κλειδιά θα ανταποκριθεί και ποιες θα αγνοήσει.
