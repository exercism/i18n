# Υποδείξεις

## Γενικά

- [Go by example map][gobyexample-map]
- [Go maps in action][goblog-map]

## 1. Αποθήκευσε τη μονάδα μέτρησης στο πρόγραμμά σου

- Για να αποθηκεύσεις τη μέτρηση στο πρόγραμμά σου, μπορείς να χρησιμοποιήσεις ένα map literal, δες το [go blog about map][goblog-map]

## 2. Δημιούργησε έναν νέο λογαριασμό

- Για να δημιουργήσεις έναν νέο λογαριασμό, το μόνο που χρειάζεται να κάνεις είναι να αρχικοποιήσεις ξανά τον πελάτη, δες το [go blog about map][goblog-map]

## 3. Πρόσθεσε προϊόν στον λογαριασμό του πελάτη

- Για να ελέγξεις αν η μονάδα μέτρησης που δίνεται είναι σωστή, μπορείς να ελέγξεις τον map με τις μονάδες μέτρησης για ένα κλειδί χωρίς να ανακτήσεις κάποια τιμή, δες το [go blog about map][goblog-map]

## 4. Αφαίρεσε προϊόν από τον λογαριασμό του πελάτη

- Για να ελέγξεις αν το προϊόν που δίνεται βρίσκεται στον λογαριασμό του πελάτη, μπορείς να ελέγξεις τον map με τις μονάδες μέτρησης για ένα κλειδί χωρίς να ανακτήσεις κάποια τιμή, δες το [go blog about map][goblog-map]

- Για να ελέγξεις αν η μονάδα μέτρησης που δίνεται είναι σωστή, μπορείς να ελέγξεις τον map με τις μονάδες μέτρησης για ένα κλειδί χωρίς να ανακτήσεις κάποια τιμή, δες το [go blog about map][goblog-map]

## 5. Επίστρεψε τον αριθμό ενός συγκεκριμένου προϊόντος που βρίσκεται στον λογαριασμό του πελάτη

- Για να ελέγξεις αν το προϊόν που δίνεται βρίσκεται στον λογαριασμό του πελάτη, μπορείς να ελέγξεις τον map με τις μονάδες μέτρησης για ένα κλειδί χωρίς να ανακτήσεις κάποια τιμή, δες το [go blog about map][goblog-map]
