# Εισαγωγή

Η Lua χρησιμοποιεί δύο αναπαραστάσεις για τους αριθμούς: τους ακέραιους αριθμούς 64 bit και τους αριθμούς κινητής υποδιαστολής διπλής ακρίβειας. Υποστηρίζει το σύνηθες σύνολο αριθμητικών τελεστών: πρόσθεση, αφαίρεση, πολλαπλασιασμό, διαίρεση και αντίθεση. Επιπλέον, υποστηρίζει ακέραια διαίρεση, υπόλοιπο και ύψωση σε δύναμη.

| Τελεστής | Παράδειγμα          |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
