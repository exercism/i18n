# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο για να παρακολουθείς τα υψηλά σκορ για το πιο δημοφιλές παιχνίδι στην τοπική αίθουσα παιχνιδιών σου.

Έχεις 6 συναρτήσεις να υλοποιήσεις, που σχετίζονται κυρίως με τον χειρισμό ενός αντικειμένου που περιέχει τα υψηλά σκορ.

## 1. Δημιούργησε έναν νέο πίνακα υψηλών σκορ

Γράψε μια συνάρτηση `create_score_board` που δημιουργεί ένα αντικείμενο το οποίο χρησιμεύει ως πίνακας υψηλών σκορ.
Τα κλειδιά αυτού του αντικειμένου θα είναι τα ονόματα των παικτών, ενώ οι τιμές θα είναι τα σκορ τους.
Για σκοπούς δοκιμών, θέλεις να συμπεριλάβεις απευθείας μία καταχώριση στο αντικείμενο.
Αυτή η αρχική καταχώριση θα πρέπει να αποτελείται από το `"The Best Ever"` ως όνομα παίκτη και το `1000000` ως σκορ.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Πρόσθεσε παίκτες σε έναν πίνακα υψηλών σκορ

Για να προσθέσεις έναν παίκτη στον πίνακα υψηλών σκορ, υλοποίησε τη συνάρτηση `add_player`.
Δέχεται έναν πίνακα υψηλών σκορ ως είσοδο και χρειάζεται δύο παραμέτρους: το όνομα του παίκτη και το σκορ του παίκτη.
Η συνάρτηση επιστρέφει το αντικείμενο του πίνακα υψηλών σκορ με τον νέο παίκτη προσθεμένο.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Αν ο παίκτης βρίσκεται ήδη στον πίνακα, επέστρεψε τον πίνακα όπως είναι.

## 3. Αφαίρεσε παίκτες από έναν πίνακα υψηλών σκορ

Αν οι παίκτες παραβούν τους κανόνες της αίθουσας παιχνιδιών, αφαιρούνται χειροκίνητα από τον πίνακα υψηλών σκορ.
Υλοποίησε τη συνάρτηση `remove_player`, η οποία δέχεται έναν πίνακα ως είσοδο και μία παράμετρο, το όνομα του παίκτη που θα αφαιρεθεί.
Αυτή η συνάρτηση θα πρέπει να αφαιρεί την καταχώριση του συγκεκριμένου παίκτη από τον πίνακα και να επιστρέφει τον νέο πίνακα.
Αν ο παίκτης δεν βρισκόταν εξαρχής στον πίνακα, δεν θα πρέπει να συμβεί τίποτα στον πίνακα, και θα πρέπει να επιστραφεί όπως είναι.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Αύξησε το σκορ ενός παίκτη

Αν ένας παίκτης ολοκληρώσει άλλο ένα παιχνίδι στην αίθουσα παιχνιδιών, ένα συγκεκριμένο ποσό πόντων θα προστεθεί στο προηγούμενο σκορ του πίνακα.
Υλοποίησε τη συνάρτηση `update_score`, η οποία δέχεται έναν πίνακα υψηλών σκορ ως είσοδο και χρειάζεται δύο παραμέτρους: το όνομα του παίκτη και το ποσό του σκορ που θα προστεθεί.
Η συνάρτηση θα πρέπει να επιστρέφει τον πίνακα υψηλών σκορ αφού γίνει η ενημέρωση.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Αυτή η συνάρτηση θα πρέπει να προσθέτει τον παίκτη στον πίνακα αν δεν βρισκόταν ήδη σε αυτόν.

## 5. Εφάρμοσε τους πρόσθετους πόντους της Δευτέρας

Η αίθουσα παιχνιδιών κρατά έναν ξεχωριστό πίνακα υψηλών σκορ τις Δευτέρες.
Στο τέλος της ημέρας, κάθε παίκτης σε αυτόν τον πίνακα παίρνει 100 επιπλέον πόντους.

Υλοποίησε τη συνάρτηση `apply_monday_bonus`.
Η συνάρτηση προσθέτει τους πόντους μπόνους για κάθε παίκτη που είναι καταγεγραμμένος σε αυτόν τον πίνακα.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Βρες το συνολικό σκορ

Διαφορετικές αίθουσες παιχνιδιών συναγωνίζονται μεταξύ τους για να καθορίσουν ποια έχει τους καλύτερους παίκτες.
Η αίθουσα με το υψηλότερο συνολικό σκορ κερδίζει τη δόξα.

Γράψε μια συνάρτηση `total_score`.
Δέχεται έναν πίνακα υψηλών σκορ ως είσοδο και επιστρέφει το άθροισμα των σκορ όλων των παικτών.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
