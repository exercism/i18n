# Εισαγωγή

## Μεταβλητές

Θυμήσου ότι ένα πρόγραμμα `jq` είναι ένα _pipeline από εκφράσεις_.
**Η εκχώρηση μεταβλητής** ακολουθεί αυτόν τον κανόνα: μια _εκχώρηση μεταβλητής_ είναι μια έκφραση που μοιάζει με:

```jq
... | expr as $varname | ...
```

### Το φίλτρο δίνει ως έξοδο την είσοδο

Όπως η _έκφραση ταυτότητας_ `.`, η έξοδος της _εκχώρησης μεταβλητής_ είναι ίδια με την είσοδό της.
Ο ορισμός της τιμής της μεταβλητής είναι μια παρενέργεια.

Παράδειγμα, που δείχνει ότι το `.` μετά την εκχώρηση είναι το ίδιο με την αρχική είσοδο:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### Εμβέλεια μεταβλητής

Η εμβέλεια της μεταβλητής είναι "λεξική", δηλαδή η μεταβλητή θα βρίσκεται σε εμβέλεια για το υπόλοιπο του pipeline.
Οι μεταβλητές που ορίζονται μέσα σε συναρτήσεις (θα ασχοληθούμε με τις συναρτήσεις αργότερα) είναι "τοπικές" στη συνάρτηση.

### Ονόματα μεταβλητών

Η μεταβλητή πρέπει να ξεκινά με `$`.
Το υπόλοιπο του ονόματος της μεταβλητής είναι ένα **αναγνωριστικό**: ξεκινά με ένα γράμμα ή κάτω παύλα και ακολουθείται από γράμματα, αριθμούς ή κάτω παύλες.

### Εκχώρηση με αποδόμηση

Από το εγχειρίδιο:

> Πολλαπλές μεταβλητές μπορούν να δηλωθούν χρησιμοποιώντας μία μόνο έκφραση `as`, παρέχοντας ένα μοτίβο που _ταιριάζει με τη δομή της εισόδου_ (αυτό είναι γνωστό ως "αποδόμηση").

Παραδείγματα:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Το ταίριασμα του ονόματος της μεταβλητής με το _κλειδί του αντικειμένου_ προσφέρει μια συντόμευση:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### Σταθερές

Όπως φαίνεται στο παραπάνω παράδειγμα, οι μεταβλητές είναι βολικές για την αποθήκευση σταθερών.
Είναι καλύτερα να δίνεις ένα όνομα στις σταθερές παρά να εμφανίζονται "μαγικοί αριθμοί" μέσα στον κώδικα.

### Συχνά οι μεταβλητές δεν χρειάζονται

Συχνά είναι πιο ευανάγνωστο να παραλείπεις τις μεταβλητές.

Σκέψου τον υπολογισμό του μέσου όρου μιας λίστας αριθμών

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

σε σύγκριση με

```jq
[2, 4, 8, 7] | add / length
```

Αυτό αναδεικνύει μια από τις πιο ισχυρές πτυχές του `jq`: η είσοδος σε ένα φίλτρο παρέχεται σε _κάθε_ υποέκφραση:

- ο πίνακας εισόδου `[2,4,8,7]` περνά στο `add` (το οποίο αθροίζει τους αριθμούς εφαρμόζοντας τον τελεστή `+` σε όλα τα στοιχεία)
- _παράλληλα_, το `[2,4,8,7]` περνά επίσης στο `length`
- όταν αυτές οι υποεκφράσεις ολοκληρωθούν, τα αποτελέσματά τους διαιρούνται, επιστρέφοντας τη μέση τιμή των αριθμών του πίνακα εισόδου.

### Τελεστές `jq` που θα χρειαστείς για την άσκηση εκμάθησης

#### Ο τελεστής εναλλακτικής: `//`

Η έκφραση `a // b` δίνει ως έξοδο το `b` αν το `a` είναι ψευδές ή null, αλλιώς δίνει ως έξοδο το `a`.
Στο πλαίσιο του ορισμού μιας μεταβλητής, αυτό είναι πολύ βολικό για να παρέχεις μια προεπιλεγμένη τιμή:

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### Αριθμητικοί τελεστές

- Τα `+`, `-`, `*` είναι οι συνήθεις τελεστές αριθμητικής πρόσθεσης, αφαίρεσης και πολλαπλασιασμού.
