# Υποδείξεις

## Γενικά

- [The Python Tutorial][the python tutorial] μπορεί να αποτελέσει μια εξαιρετική εισαγωγή.
- Το [PEP 8][pep8] είναι ο οδηγός στυλ κώδικα της Python.
- Το [PEP 257][PEP257] περιγράφει αναλυτικά τις συμβάσεις για τα docstrings στην Python.
- Οι [αριθμοί][numbers] στην Python μπορούν να είναι ακέραιοι, αριθμοί κινητής υποδιαστολής ή μιγαδικοί.


## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να [ονομάσεις][naming] μια [σταθερά][constants] και να της [εκχωρήσεις][assignment] μια [ακέραια][numbers] τιμή.
  Αυτή η σταθερά πρέπει να είναι το πρώτο πράγμα μετά το docstring που βρίσκεται στην αρχή του αρχείου.
  Θυμήσου να αφαιρέσεις το σχόλιο #TODO αφού ορίσεις τη σταθερά.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][defining functions] με μία μόνο παράμετρο που αντιπροσωπεύει τον χρόνο που έχει περάσει μέχρι στιγμής.
- Χρησιμοποίησε τον [μαθηματικό τελεστή αφαίρεσης][numbers] για να αφαιρέσεις τιμές.
- Αυτή η συνάρτηση θα πρέπει να [επιστρέφει μια τιμή][return].

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][defining functions] με μία μόνο παράμετρο που αντιπροσωπεύει τον αριθμό των στρώσεων.
- Χρησιμοποίησε τον [μαθηματικό τελεστή πολλαπλασιασμού][numbers] για να πολλαπλασιάσεις τιμές.
- Μπορείς να ορίσεις μια _σταθερά_ PREPARATION_TIME για τον χρόνο σε λεπτά ανά στρώση, αντί να χρησιμοποιήσεις έναν ["μαγικό
  αριθμό"][magic-numbers] στον κώδικά σου.
- Αυτή η συνάρτηση θα πρέπει να [επιστρέφει μια τιμή][return].

## 4. Υπολόγισε τον συνολικό χρόνο μαγειρέματος (προετοιμασία + ψήσιμο) σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][defining functions] με δύο παραμέτρους.
- Θυμήσου: μπορείς πάντα να _καλέσεις_ μια συνάρτηση που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή πρόσθεσης][python as a calculator] για να αθροίσεις τιμές.
- Αυτή η συνάρτηση θα πρέπει να [επιστρέφει μια τιμή][return].

## 5. Ενημέρωσε τη συνταγή με σημειώσεις

- Το να [σχολιάζεις][comments] και να [τεκμηριώνεις][docstrings] τον κώδικά σου με σαφήνεια, σύμφωνα με το [PEP257][pep257], συνιστάται πάντα.
- Μερικά παραδείγματα docstrings σε στυλ Google μπορείς να τα βρεις στην τεκμηρίωση του Sphinx για το [module napoleon][napoleon].
