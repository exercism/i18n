# Οδηγίες

Υπολόγισε την ημερομηνία των συναντήσεων.

Συνήθως οι συναντήσεις γίνονται την ίδια μέρα της εβδομάδας. Σε αυτή την άσκηση θα πάρεις μια περιγραφή μιας ημερομηνίας συνάντησης και θα επιστρέψεις την πραγματική ημερομηνία της συνάντησης.

Παραδείγματα γενικών περιγραφών είναι:

- Η πρώτη Δευτέρα του Ιανουαρίου 2017
- Η τρίτη Τρίτη του Ιανουαρίου 2017
- Το wednesteenth του Ιανουαρίου 2017
- Η τελευταία Πέμπτη του Ιανουαρίου 2017

Οι χαρακτηρισμοί που πρέπει να αναλύσεις είναι:
first, second, third, fourth, fifth, last, monteenth, tuesteenth, wednesteenth,
thursteenth, friteenth, saturteenth, sunteenth

Σημείωσε ότι τα "monteenth", "tuesteenth" κ.λπ. είναι όλες επινοημένες λέξεις. Υπήρχε μια συνάντηση της οποίας τα μέλη συνειδητοποίησαν ότι υπάρχουν ακριβώς 7 αριθμημένες μέρες σε έναν μήνα που τελειώνουν σε '-teenth'. Επομένως, είναι βέβαιο ότι κάθε μέρα της εβδομάδας (Δευτέρα, Τρίτη, ...) θα έχει ακριβώς μία ημερομηνία που ονομάζεται με '-teenth' σε κάθε μήνα.

Δεδομένων παραδειγμάτων ημερομηνιών συνάντησης, που το καθένα περιέχει μήνα, μέρα, έτος και χαρακτηρισμό, υπολόγισε την ημερομηνία της πραγματικής συνάντησης. Για παράδειγμα, αν σου δοθεί "Η πρώτη Δευτέρα του Ιανουαρίου 2017", η σωστή ημερομηνία συνάντησης είναι 2017/1/2.
