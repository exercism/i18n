# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να σε βοηθήσει να μαγειρέψεις
καταπληκτικά λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που περνάς
μαγειρεύοντας τα λαζάνια.

## 1. Αποθήκευσε τον αναμενόμενο χρόνο ψησίματος σε μια σταθερά

Όρισε τη σταθερά `expected-bake-time`, η οποία πρέπει να επιστρέφει
πόσα λεπτά χρειάζονται τα λαζάνια για να ψηθούν στον φούρνο.

Σύμφωνα με το βιβλίο μαγειρικής, τα λαζάνια πρέπει να μείνουν στον
φούρνο συνολικά 40 λεπτά.

```factor
expected-bake-time .
! => 40
```

## 2. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη λέξη `preparation-time`. Παίρνει από τη στοίβα τον αριθμό
των στρώσεων που πρόσθεσες στα λαζάνια και αφήνει πίσω πόσα λεπτά
πέρασες προετοιμάζοντάς τα, υποθέτοντας ότι κάθε στρώση θέλει 2 λεπτά
για να ετοιμαστεί.

```factor
4 preparation-time .
! => 8
```

## 3. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Όρισε τη λέξη `remaining-time`. Παίρνει τον αριθμό των λεπτών που τα
λαζάνια έχουν ήδη περάσει στον φούρνο και αφήνει πίσω πόσα λεπτά
πρέπει να μείνουν ακόμα εκεί.

```factor
25 remaining-time .
! => 15
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη λέξη `total-working-time`. Παίρνει δύο ορίσματα από τη
στοίβα (πρώτα τον αριθμό των στρώσεων στα λαζάνια και μετά τον αριθμό
των λεπτών που τα λαζάνια βρίσκονται ήδη στον φούρνο) και αφήνει πίσω
τον συνολικό χρόνο μαγειρέματος μέχρι τώρα: τον χρόνο προετοιμασίας
συν τον χρόνο που έχουν ήδη περάσει στον φούρνο.

```factor
3 20 total-working-time .
! => 26
```
