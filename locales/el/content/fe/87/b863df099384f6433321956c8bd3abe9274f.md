# Υποδείξεις

## 1. Εκτύπωσε ένα σήμα για έναν υπάλληλο

- Για να κατασκευάσεις τις συμβολοσειρές στη Base R, η συνάρτηση [`sprintf`][ref-sprintf] είναι χρήσιμη.
- Για μια προσέγγιση με το Tidyverse, μπορείς να χρησιμοποιήσεις τη [`str_glue`][ref-str_glue] από τη βιβλιοθήκη `stringr`.

## 2. Εκτύπωσε ένα σήμα για έναν νέο υπάλληλο

- Κάνε διακλάδωση με βάση το [`is.na`][ref-isna].

## 3. Εκτύπωσε ένα σήμα για τον ιδιοκτήτη

- Κάνε διακλάδωση με βάση το [`is.null`][ref-isnull].

## 4. Υπολόγισε τον συνολικό μισθό των υπαλλήλων χωρίς ID

- Μπορείς να [φιλτράρεις][concept-vector-filtering] με βάση το [`is.na`][ref-isna] και μετά να χρησιμοποιήσεις τη [`sum`][ref-sum].
- Τι είναι το `salaries[is.na(ids)]` αν δεν υπάρχουν υπάλληλοι χωρίς ID; Θα ήταν χρήσιμο να το ελέγξεις αυτό σε μια κονσόλα R. Αν η R δεν είναι εγκατεστημένη στον υπολογιστή σου, διαδικτυακές κονσόλες όπως το [rdrr.io][web-rdrr] μπορεί να βοηθήσουν.
