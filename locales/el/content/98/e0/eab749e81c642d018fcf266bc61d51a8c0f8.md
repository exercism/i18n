# Παράρτημα οδηγιών

## Λέξεις

`classify ( n -- str )` επιστρέφει μία από τις συμβολοσειρές `"perfect"`, `"abundant"` ή `"deficient"`.

## Σφάλματα

Όταν η είσοδος είναι μηδέν ή αρνητική, πετάει τη συμβολοσειρά

```
"Classification is only possible for positive integers."
```

(αυτολεξεί, συμπεριλαμβανομένης της τελείας στο τέλος).
