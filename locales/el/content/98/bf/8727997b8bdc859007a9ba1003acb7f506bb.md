# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις λίγο κώδικα για να σε βοηθήσει να προετοιμαστείς για να αγοράσεις ένα όχημα.

Έχεις τρεις εργασίες: μία για να προσδιορίσεις αν χρειάζεσαι άδεια, μία για να σε βοηθήσει να διαλέξεις ανάμεσα σε δύο οχήματα και μία για να εκτιμήσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

Ορισμένα είδη οχημάτων απαιτούν άδεια οδήγησης για να τα οδηγήσεις.
Θεώρησε ότι μόνο τα είδη `"car"` και `"truck"` απαιτούν άδεια, όλα τα άλλα μπορούν να οδηγηθούν χωρίς άδεια.

Υλοποίησε τη συνάρτηση `needsLicense(kind)` που δέχεται το είδος του οχήματος και επιστρέφει μια Boolean τιμή που δείχνει αν χρειάζεσαι άδεια για αυτό το είδος οχήματος.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Διάλεξε ανάμεσα σε δύο πιθανά οχήματα για αγορά

Αξιολογείς τις επιλογές σου από τα διαθέσιμα οχήματα.
Καταφέρνεις να τις περιορίσεις σε δύο επιλογές, αλλά χρειάζεσαι βοήθεια για την τελική απόφαση.
Για αυτό, υλοποίησε τη συνάρτηση `chooseVehicle(option1, option2)` που δέχεται δύο οχήματα ως ορίσματα και επιστρέφει μια απόφαση που περιλαμβάνει την επιλογή που έρχεται πρώτη στη [λεξικογραφική σειρά][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες μια απόφαση, θέλεις να σιγουρευτείς ότι θα πάρεις δίκαιη τιμή στην αντιπροσωπεία.
Εφόσον ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια πρόχειρη εκτίμηση, θεώρησε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν ολοκαίνουριο.
Αν είναι τουλάχιστον 10 ετών, κοστίζει 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά λιγότερο από 10, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε τη συνάρτηση `calculateResellPrice(originalPrice, age)` που εφαρμόζει αυτή τη λογική χρησιμοποιώντας `if`, `else if` και `else` (υπάρχουν κι άλλοι τρόποι αν θέλεις να εξασκηθείς).
Δέχεται την αρχική τιμή και την ηλικία του οχήματος ως ορίσματα και επιστρέφει την εκτιμώμενη τιμή στην αντιπροσωπεία.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
