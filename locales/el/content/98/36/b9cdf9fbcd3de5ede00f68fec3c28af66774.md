# Υποδείξεις

Θυμήσου, οι χελώνες είναι ψυχρόαιμα ζώα, οπότε φρόντισε να είναι ζεστές πριν τις δώσεις πάπλωμα ή πουλόβερ.

## 1. Ταξινόμησε την ποσότητα!

- Η μετάθεση ταξινόμησης που επιστρέφεις πρέπει να είναι σε φθίνουσα σειρά.
- Φρόντισε να ταξινομήσεις τις ποσότητες σε φθίνουσα σειρά επιτόπου.
- Η `sortperm` μπορεί να δεχτεί παρόμοια ορίσματα με τη `sort`.
- Η σειρά με την οποία εκτελείς τις δύο παραπάνω πράξεις είναι πολύ σημαντική!

## 2. Ταξινόμησε τον πελάτη

- Πρέπει να επιστραφεί ένας νέος πίνακας με τους πελάτες ταξινομημένους (δηλαδή μην ταξινομήσεις επιτόπου)
- Θυμήσου ότι μια μετάθεση ταξινόμησης (δηλαδή ένας πίνακας θέσεων) μπορεί να χρησιμοποιηθεί όπως οι θέσεις.

## 3. Πρόγραμμα παραγωγής!

- Μπορείς να χρησιμοποιήσεις εδώ τις συναρτήσεις `sortquantity!()` και `sortcustomer()`.
- Θυμήσου ότι μια μετάθεση ταξινόμησης είναι απλώς μια μετάθεση των θέσεων.
- Για μια [αντίστροφη μετάθεση ταξινόμησης][invperm]:
    - Σκέψου ποια είναι η αρχική διάταξη των θέσεων για ένα αυθαίρετο `Vector`.
    - Τι μπορεί να γίνει σε *οποιαδήποτε* μετάθεση θέσεων για να επιστρέψει σε αυτό το σημείο εκκίνησης;
    - Τελευταία υπόδειξη... Τι κάνει η μετάθεση ταξινόμησης μιας μετάθεσης ταξινόμησης;
 
[invperm]: https://docs.julialang.org/en/v1/base/arrays/#Base.invperm
