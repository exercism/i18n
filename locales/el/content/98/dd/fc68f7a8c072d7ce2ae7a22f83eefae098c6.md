# Υποδείξεις

## 1. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

- Χρησιμοποίησε τον [τελεστή ισότητας][equality-operator] για να ελέγξεις αν η είσοδός σου ισούται με μια συγκεκριμένη συμβολοσειρά.
- Χρησιμοποίησε έναν από τους δύο [λογικούς τελεστές][logical-operators] που έμαθες στην έννοια boolean για να συνδυάσεις τις δύο προϋποθέσεις.
- **Δε** χρειάζεσαι εντολή if για να λύσεις αυτή την άσκηση. Μπορείς να επιστρέψεις απευθείας την boolean παράσταση που θα φτιάξεις.

## 2. Διάλεξε ανάμεσα σε δύο υποψήφια οχήματα προς αγορά

- Χρησιμοποίησε έναν [τελεστή σύγκρισης][comparison-operators] για να προσδιορίσεις ποια επιλογή έρχεται πρώτη στη λεξικογραφική σειρά.
- Χρησιμοποίησε ένα [πρότυπο συμβολοσειράς][string-templates] για να δημιουργήσεις την πρόταση σύστασης.

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

- Χρησιμοποίησε μια [εντολή if-else if-else][if-statement] για να προσδιορίσεις το ποσοστό.
- Στις δύο συνθήκες if χρησιμοποίησε [τελεστές σύγκρισης][comparison-operators] για να συγκρίνεις την ηλικία του αυτοκινήτου με τις οριακές τιμές.
- Για να υπολογίσεις το αποτέλεσμα, εφάρμοσε το ποσοστό στην αρχική τιμή. Για παράδειγμα, το `30% of x` μπορεί να υπολογιστεί διαιρώντας το `30` με το `100` και πολλαπλασιάζοντας με το `x`.
