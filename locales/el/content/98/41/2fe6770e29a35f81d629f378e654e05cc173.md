# Κατασκευαστές συμβολοσειρών

Μια `STR` δεν αλλάζει ποτέ. Έτσι, το `+` δεν μπορεί να προσθέσει σε μια υπάρχουσα: πρέπει να φτιάξει μια ολόκληρη καινούρια συμβολοσειρά με τα περιεχόμενα και των δύο.

Αυτό είναι εντάξει μία φορά. Μέσα σε έναν βρόχο, όχι:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Κάθε γύρος αντιγράφει ό,τι έχει χτιστεί μέχρι στιγμής σε μια νέα συμβολοσειρά και πετάει την παλιά. Δέκα γραμμές σημαίνουν δέκα αντίγραφα, το καθένα μεγαλύτερο από το προηγούμενο. Εκατό γραμμές σημαίνουν εκατό. Ο φόρτος εργασίας αυξάνεται με το *τετράγωνο* του αριθμού των γραμμών, και ένας βρόχος που φαίνεται αθώος γίνεται το αργό κομμάτι του προγράμματος.

## FSTR

Η `FSTR` είναι μια συμβολοσειρά που *μπορεί* να αλλάξει: ένας **κατασκευαστής συμβολοσειρών**. Η προσθήκη σε μια τέτοια συνήθως γράφει απλώς στον χώρο που υπάρχει ήδη, οπότε ένας βρόχος πάνω από εκατό γραμμές κάνει δουλειά περίπου εκατό γραμμών αντί για εκατό αντίγραφα.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Τρία πράγματα αξίζει να προσέξεις.

**Το `#FSTR` φτιάχνει μια κενή.** Το `#FSTR(100)` φτιάχνει μία με χώρο για εκατό χαρακτήρες ήδη δεσμευμένο, κάτι που αξίζει να κάνεις όταν ξέρεις το μέγεθος.

**Πρέπει να εκχωρήσεις πίσω το αποτέλεσμα.** `script := script + ...`, ποτέ `script + ...` μόνο του. Συνήθως το αποτέλεσμα είναι ο ίδιος κατασκευαστής που μπήκε, αλλά όταν έχει εξαντλήσει τον χώρο του είναι ένας μεγαλύτερος, καινούριος, και αν πετάξεις το αποτέλεσμα θα συνεχίσεις να γράφεις στον παλιό.

**`.str` στο τέλος.** Μια ρουτίνα που υπόσχεται `: STR` πρέπει να επιστρέψει μια `STR`, και το `.str` φτιάχνει μία από τον κατασκευαστή.

## Τι μπορεί να προστεθεί

Το `+` σε μια `FSTR` δέχεται μια συμβολοσειρά, έναν χαρακτήρα, έναν ακέραιο ή ένα boolean (λογική τιμή), οπότε συνήθως δεν χρειάζεται να κάνεις μετατροπή πρώτα:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Νέες γραμμές

Το `"\n"` μέσα σε μια συμβολοσειρά είναι μια νέα γραμμή: ένας χαρακτήρας, γραμμένος με δύο.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
