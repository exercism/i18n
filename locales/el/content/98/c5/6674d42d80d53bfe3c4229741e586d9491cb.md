# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων. Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (εκτός λειτουργίας) έως `10` (μέγιστη).

Στη χαμηλότερη μη μηδενική ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα κάθε ώρα. Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα, οπότε σε ταχύτητα `4` η γραμμή παράγει `4 * 221 = 884` αυτοκίνητα ανά ώρα. Ωστόσο, οι υψηλότερες ταχύτητες αυξάνουν την πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία στη συνέχεια πρέπει να απορριφθούν.

Έχεις τέσσερις εργασίες. Κάθε μία παίρνει από τη στοίβα μία μόνο ακέραια παράμετρο, την ταχύτητα της γραμμής συναρμολόγησης.

## 1. Ανέφερε αν η γραμμή λειτουργεί

Όρισε τη συνάρτηση `production-status` ώστε να επιστρέφει `"stopped"` όταν η ταχύτητα είναι `0` και `"running"` για οποιαδήποτε άλλη ταχύτητα:

```factor
0 production-status .
! => "stopped"
3 production-status .
! => "running"
```

## 2. Υπολόγισε το ποσοστό επιτυχίας

Όρισε τη συνάρτηση `success-rate` ώστε να επιστρέφει την πιθανότητα ένα προϊόν να παραχθεί χωρίς σφάλμα:

- `0`: `0.0`
- `1` έως `4`: `1.0`
- `5` έως `8`: `0.9`
- `9`: `0.8`
- `10`: `0.77`

```factor
10 success-rate .
! => 0.77
```

## 3. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Όρισε τη συνάρτηση `production-rate-per-hour` ώστε να επιστρέφει τον ρυθμό παραγωγής της γραμμής συναρμολόγησης ανά ώρα, λαμβάνοντας υπόψη το ποσοστό επιτυχίας.

Θα χρειαστεί να ορίσεις πρώτα τη σταθερά `base-speed` με τιμή `221`.

```factor
6 production-rate-per-hour .
! => 1193.4
```

Η τιμή που επιστρέφεται είναι κινητής υποδιαστολής.

## 4. Υπολόγισε τον αριθμό των λειτουργικών προϊόντων που παράγονται ανά λεπτό

Όρισε τη συνάρτηση `working-items-per-minute` ώστε να επιστρέφει πόσα λειτουργικά αυτοκίνητα παράγονται ανά λεπτό. Το αποτέλεσμα είναι ακέραιος αριθμός. Τα ημιτελή αυτοκίνητα δεν μετρώνται.

```factor
6 working-items-per-minute .
! => 19
```
