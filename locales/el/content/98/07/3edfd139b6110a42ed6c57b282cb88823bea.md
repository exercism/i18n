# Εισαγωγή

Οι κατακερματισμοί είναι ένας τύπος δεδομένων στην Perl που περιέχει μια μη διατεταγμένη συλλογή από κλειδιά συμβολοσειρών σε ζεύγη με βαθμωτές τιμές.

Μια μεταβλητή κατακερματισμού συνήθως συμπληρώνεται με την ανάθεση μιας λίστας σε αυτήν, π.χ. `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Οι λίστες συνήθως χωρίζονται με κόμματα, αλλά συχνά θα δεις αυτό που είναι γνωστό ως "παχύ κόμμα" `=>` να χωρίζει κλειδιά και τιμές σε μια λίστα.
Η συμπεριφορά του είναι σχεδόν ίδια με ένα κόμμα, αλλά έχει το πρόσθετο πλεονέκτημα να ερμηνεύει το στοιχείο στην αριστερή πλευρά ως συμβολοσειρά.

Οι κατακερματισμοί μπορούν να συμπληρωθούν με ανάθεση σε μεμονωμένα κλειδιά, π.χ. `$scores{Alice} = 10;`.

Οι τιμές ενός κατακερματισμού μπορούν να προσπελαστούν καθορίζοντας κλειδιά μέσω μιας σύνταξης με άγκιστρα, π.χ. `$scores{Bob} # 15`.

Τα κλειδιά σε έναν κατακερματισμό είναι μοναδικά.
Αν ένα κλειδί δοθεί πολλές φορές, θα κρατηθεί μόνο η τελευταία τιμή που δόθηκε.

## Συναρτήσεις

Οι συναρτήσεις για εργασία με κατακερματισμούς περιλαμβάνουν τις [keys][keys] και [values][values], για την ανάκτηση των αντίστοιχων τμημάτων ενός κατακερματισμού ως λίστα.
Οι λίστες που επιστρέφονται από τις συναρτήσεις [keys][keys] και [values][values] μπορούν να φανούν χρήσιμες σε συναρτήσεις λιστών όπως οι [grep][grep], [map][map] και [sort][sort], καθώς και σε [for][for] βρόχους.

Άλλες συναρτήσεις για κατακερματισμούς περιλαμβάνουν τις [exists][exists], για τον έλεγχο αν ένα κλειδί υπάρχει σε έναν κατακερματισμό (ακόμα κι αν η τιμή του είναι `undef`), και [delete][delete], για την αφαίρεση ενός κλειδιού από έναν κατακερματισμό.

## Διαφοροποίηση του συμβόλου

Όταν παίρνεις τιμές από έναν κατακερματισμό, το σύμβολο που δίνεται καθορίζει το αποτέλεσμα.
Η σύνταξη `{}` στο τέλος του ονόματος της μεταβλητής είναι αυτό που λέει στην Perl ότι προσπελαύνεις έναν κατακερματισμό με αυτό το όνομα.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Αν και επιτρέπεται, συνιστάται να μην μοιράζονται διαφορετικοί τύποι μεταβλητών το ίδιο όνομα, για χάρη της αναγνωσιμότητας.
