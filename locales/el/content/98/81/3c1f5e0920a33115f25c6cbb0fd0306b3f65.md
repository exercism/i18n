# Προσθήκη στις οδηγίες

## Λέξεις

Όρισε ένα tuple `custom-set` και δήλωσέ το ως στιγμιότυπο του mixin `set` με `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: κατασκευάζει ένα κενό σύνολο.
- `>custom-set ( seq -- set )`: χτίζει ένα σύνολο από μια ακολουθία,
  παραλείποντας σιωπηλά τα διπλότυπα.

Στη συνέχεια, παρέχε μεθόδους `M:` (από το `sets`) για τα `members`, `in?`,
`adjoin` και `set-like` στο `custom-set`. Με τη δήλωση `INSTANCE:`
και αυτές τις τέσσερις μεθόδους στη θέση τους, τα `null?`, `union`,
`intersect`, `diff`, `subset?`, `set=` και `intersects?` από το
λεξιλόγιο `sets` λειτουργούν όλα στο σύνολό σου μέσω των προεπιλεγμένων
υλοποιήσεων του πρωτοκόλλου. Οι δοκιμές καλούν αυτές τις λέξεις απευθείας.

Το `adjoin ( elt set -- )` είναι μεταλλακτικό: προσθέτει το `elt` στο
`set` επί τόπου, αν δεν υπάρχει ήδη.
