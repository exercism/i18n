# Παρτίδες Πληρωμών στη Βάση Δεδομένων

## Εκφώνηση προβλήματος

Πρέπει να εισάγεις μια παρτίδα δεδομένων πληρωμών στον πίνακα `Payment`. Ο στόχος σου είναι να διαβάσεις τα δεδομένα πληρωμών από το δεδομένο αρχείο εισόδου JSON και να χρησιμοποιήσεις τη λειτουργία `batchExecute` του JDBC Client για να εισάγεις τα δεδομένα πληρωμών στον πίνακα `Payment`. Το δειγματικό αρχείο εισόδου δίνεται ως `payments.json`.

Το περιεχόμενο του αρχείου εισόδου JSON βασίζεται στο παρακάτω σχήμα JSON.

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

Πρέπει να επιστρέψεις ως έξοδο τα αυτόματα δημιουργημένα αναγνωριστικά πληρωμών για τα δεδομένα πληρωμών που εισήχθησαν στην παρτίδα, χωρίς να εκτελέσεις άλλο ερώτημα στη βάση δεδομένων.

Μπορείς να υποθέσεις ότι τα `employee_id` που δίνονται στο αρχείο `payments.json` είναι έγκυρα και υπάρχουν ήδη στον πίνακα `Employee`.

## Λεπτομέρειες βάσης δεδομένων

Χρησιμοποίησε τη βάση δεδομένων H2 που παρέχεται για αυτό το πρόβλημα.

> Το δειγματικό αρχείο βάσης δεδομένων είναι το `gofigure.mv.db` και το όνομα της βάσης δεδομένων είναι `gofigure`. Δίνεται μέσα στον φάκελο `db`.

Οι παρακάτω πίνακες υπάρχουν ήδη στη δειγματική βάση δεδομένων H2 με μερικά δείγματα δεδομένων. Τα ονόματα των στηλών και οι τύποι δεδομένων δίνονται παρακάτω.

**Όνομα πίνακα**: `Employee`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `employee_id`     | ακέραιος, αυτόματα αυξανόμενο πρωτεύον κλειδί       |
| `name`            | συμβολοσειρά        |
| `city`            | συμβολοσειρά        |
| `department`      | συμβολοσειρά        |
| `age`             | ακέραιος        |

**Όνομα πίνακα**: `Payment`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `payment_id`      | ακέραιος, αυτόματα αυξανόμενο πρωτεύον κλειδί       |
| `date`            | ημερομηνία        |
| `amount`          | δεκαδικός        |
| `employee_id`     | ακέραιος        |
| `reason`          | συμβολοσειρά        |

* Το αρχείο της βάσης δεδομένων είναι το `gofigure.mv.db`. Χρησιμοποίησε το JDBC URL ως `jdbc:h2:file:/path/to/db/file`
* Όνομα χρήστη: `root`
* Κωδικός πρόσβασης: `root`

## Περιορισμοί

* Χρησιμοποίησε το αρχείο βάσης δεδομένων H2 που παρέχεται στον φάκελο `db` για να επικυρώσεις τα ερωτήματα και το δείγμα Ballerina
* Χρησιμοποίησε την προσέγγιση maven dependency params για να προσθέσεις τον οδηγό της βάσης δεδομένων H2 ως εξάρτηση πλατφόρμας στο Ballerina.toml
* Πρέπει να βρεις τα αυτόματα δημιουργημένα αναγνωριστικά πληρωμών χωρίς να εκτελέσεις άλλο ερώτημα στη βάση δεδομένων.

## Περιβάλλον δοκιμών

* Μπορείς να εκτελέσεις τις δοκιμές με `bal test` και θα τρέξει δοκιμές πάνω στη δειγματική βάση δεδομένων που δίνεται.

## Παραδείγματα

### Παράδειγμα 1

**Είσοδος:** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

Δείγμα δεδομένων του αρχείου `payments.json`:

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**Έξοδος:** `[1,2,3]`

## Υποδείξεις

* Χρησιμοποίησε την ενότητα [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) για να δουλέψεις με τη βάση δεδομένων
* Ανατρέξε στην ενότητα [Προαπαιτούμενα](https://lib.ballerina.io/ballerinax/java.jdbc/latest) για τα βήματα προσθήκης του οδηγού JDBC ως εξάρτησης
* Χρησιμοποίησε το [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) για να διαβάσεις το αρχείο εισόδου JSON
* Μετέτρεψε τις τιμές JSON σε τύπους ειδικούς για την εφαρμογή, ώστε να δουλέψεις με τα δεδομένα με ασφάλεια τύπων. Ανατρέξε στο παράδειγμα [Converting to user defined type](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)
* Χρησιμοποίησε το [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) και την απομακρυσμένη μέθοδο [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) για να δουλέψεις με τη βάση δεδομένων
* Ανατρέξε στο παράδειγμα [batch execute](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)
