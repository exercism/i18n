# Εισαγωγή

Το `case` (στο [`combinators`][combinators]) αποφασίζει με βάση μια τιμή, διατρέχοντας μια alist από ρήτρες και εκτελώντας το σώμα της πρώτης που ταιριάζει.

```
case ( obj assoc -- )
```

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

Κάθε ρήτρα είναι `{ value [ body ] }`. Η ισότητα ελέγχεται με `=`. Οι ρήτρες που ταιριάζουν εκτελούνται αφού η τιμή εισόδου έχει *ήδη καταναλωθεί*. Μια `[ body ]` στο τέλος (χωρίς τιμή) είναι η προεπιλογή. Εκτελείται με την είσοδο *ακόμα* στη στοίβα, οπότε το σώμα συνήθως ξεκινά με `drop`.

[combinators]: https://docs.factorcode.org/content/vocab-combinators.html
