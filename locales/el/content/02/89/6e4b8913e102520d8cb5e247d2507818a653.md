# Υποδείξεις

## 1. Δημιούργησε ένα διάνυσμα με όλα τα βαγόνια

- Ένας κλασικός βρόχος for/while με `push!` σε ένα `Vector` θα δουλέψει.
- Διαφορετικά, η συνάρτηση [`collect()`][collect] μπορεί να είναι πιο σύντομη.
- Εναλλακτικά, το splatting δουλεύει μέσα σε έναν κατασκευαστή διανύσματος:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Διόρθωσε το διάνυσμα των βαγονιών

- Είναι χρήσιμο να χωρίσεις τα μπροστινά βαγόνια και τη μηχανή από όλα τα υπόλοιπα, ώστε να μπορούν να ξανασυναρμολογηθούν στη σωστή σειρά.
- Η πολλαπλή ανάθεση με splatting μπορεί να σε βοηθήσει (δες την εισαγωγή).

## 3. Πρόσθεσε τις στάσεις που λείπουν

- Θυμήσου, αυτή η συνάρτηση δεν μεταβάλλει την είσοδο! Δημιούργησε ένα νέο `Dict`.
- Χρειάζεται μόνο το όνομα της στάσης, όχι ο αριθμός της στάσης, οπότε κάθε ζεύγος πρέπει να χωριστεί.
- Υπάρχουν πολλοί τρόποι για να φτιάξεις το διάνυσμα των ονομάτων:
  -  Βρόχος for/while με `push!()` σε ένα `Vector`.
  -  [Κατανόηση πίνακα][comprehensions]
  -  [`map()`][map] μιας συνάρτησης πάνω στο διάνυσμα.
  -  Το [Broadcasting][broadcasting] μιας [ανώνυμης][anonymous] συνάρτησης είναι επίσης δυνατό:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

- Αφού κάνεις slurp, το `more_route_information` είναι μια συλλογή `Pairs()`.
- Η συνάρτηση [`merge()`][merge] θα συνδυάσει δύο ή περισσότερα `Dict`s, αλλά θα δεχτεί επίσης μια συλλογή `Pairs()`.
  Η ρητή μετατροπή της συλλογής `Pairs()` σε `Dict` είναι δυνατή αλλά περιττή.
