# Οι έννοιες του Δίσεκτου

Προτιμώ το πρώτο παράδειγμα λύσης, γιατί η λακωνικότητά του ταιριάζει με αυτό που έχω δει στην ιδιωματική Rust. Αποφεύγει επίσης την προσθήκη της έννοιας του closure που κάνει η κανονική λύση.

## Έννοιες που εξήχθησαν

### Γενικά

- Λογική Boolean
  - Boolean
- Εκφράσεις
  - Οι συναρτήσεις στη Rust επιστρέφουν έμμεσα εκφράσεις
- Αριθμητική
  - υπόλοιπο

### Τύποι

- ανυπόγραφοι ακέραιοι - `u64`
- Boolean - `bool`

## Παράδειγμα άσκησης 1

Η λύση του χρήστη ["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Παράδειγμα άσκησης 2

[Κανονική λύση](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
