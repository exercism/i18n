# Υποδείξεις

## Γενικά

- Μπορείς να έχεις πρόσβαση στα επιμέρους components μιας πλειάδας προσθέτοντας ένα _.n_ στο όνομα της πλειάδας, όπου _n_ είναι η θέση του component, ξεκινώντας από το 0.

## 1. Πάρε το όνομα του παιχνιδιού

- Μπορείς να έχεις πρόσβαση στο όνομα του παιχνιδιού χρησιμοποιώντας τη σύνταξη `.n`.

## 2. Πρόσθεσε ένα νέο παιχνίδι στη βάση δεδομένων

- Μπορείς να δημιουργήσεις μια νέα πλειάδα χρησιμοποιώντας τη σύνταξη της πλειάδας `(name1: value1, name2: value2, ...)`.

## 3. Ενημέρωσε την ποσότητα ενός παιχνιδιού

- Μπορείς να χρησιμοποιήσεις έναν [`for` βρόχο][for-loop] για να διατρέξεις τον πίνακα με τις πλειάδες και να ενημερώσεις την ποσότητα του παιχνιδιού.
- Μπορείς να χρησιμοποιήσεις συναρτήσεις που υλοποίησες νωρίτερα για να πάρεις το όνομα του παιχνιδιού.
- Μπορείς να χρησιμοποιήσεις μια [εντολή συνθήκης][conditional-statement] για να ελέγξεις αν το όνομα του παιχνιδιού ταιριάζει με αυτό που θέλεις να ενημερώσεις.
- Μπορείς να χρησιμοποιήσεις τη σύνταξη `.n` για να ενημερώσεις την ποσότητα του παιχνιδιού, π.χ.: `toys.price = 3`.

## 4. Πρόσθεσε κλειδί κατηγορίας σε ένα παιχνίδι

- Μπορείς να χρησιμοποιήσεις έναν [`for` βρόχο][for-loop] για να διατρέξεις τον πίνακα με τις πλειάδες και να προσθέσεις το κλειδί κατηγορίας στο παιχνίδι.
- Η πλειάδα είναι αμετάβλητη, οπότε πρέπει να δημιουργήσεις μια νέα πλειάδα στην οποία θα έχεις προσθέσει το κλειδί κατηγορίας.

[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
