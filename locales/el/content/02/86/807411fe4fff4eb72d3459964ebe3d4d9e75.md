# Εισαγωγή

Με έναν `while` βρόχο μπορείς να εκτελέσεις κώδικα επαναλαμβανόμενα, όσο ικανοποιείται μια συγκεκριμένη συνθήκη.
Γράφεται με τη λέξη-κλειδί `while`, ακολουθούμενη από μια συνθήκη μέσα σε παρενθέσεις και από ένα μπλοκ κώδικα που περιέχει το _σώμα_ του βρόχου μέσα σε άγκιστρα.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

Η JavaScript έχει επίσης τον βρόχο do-while.
Εδώ η συνθήκη ελέγχεται αφού εκτελεστεί το σώμα του βρόχου.
Αυτό είναι χρήσιμο όταν η συνθήκη εξαρτάται από το αποτέλεσμα του κώδικα στο σώμα.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Μέσα στο σώμα ενός βρόχου μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `break` για να σταματήσεις εντελώς την εκτέλεση του βρόχου.
Αντίθετα, η λέξη-κλειδί `continue` σταματά μόνο την εκτέλεση της τρέχουσας επανάληψης και συνεχίζει με την επόμενη.
Με το `continue` μπορείς συχνά να αποφύγεις να τυλίξεις μεγάλα μέρη του σώματος του βρόχου μέσα σε μια εντολή `if`.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
