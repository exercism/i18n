# Σχετικά

Η [TypeScript](https://www.typescriptlang.org/) (TS) είναι ένα υπερσύνολο της JavaScript (JS), που δημιουργήθηκε στη Microsoft ως απάντηση στην απογοήτευση από την ανάπτυξη εφαρμογών μεγάλης κλίμακας σε JS. Σε ένα μεγάλο έργο JS, το να ξέρεις ποιες ιδιότητες έχουν τα δικά σου αντικείμενα και τι ορίσματα δέχονται οι συναρτήσεις σου (και τι τύπο χρειάζονται) μπορεί να γίνει δύσκολο. Παρομοίως, επειδή δεν υπάρχει η δυνατότητα να επιθεωρήσεις έξυπνα κώδικα JS, όταν συμπεριλαμβάνεις ένα πακέτο (για παράδειγμα από το `npm`), πρέπει να κρατάς ενημερωμένη την τεκμηρίωση για να ξέρεις ποιες μέθοδοι είναι διαθέσιμες και τι ορίσματα δέχονται. Η TS λύνει αυτά τα προβλήματα. Αυτή τη στιγμή είναι ένα έργο ανοιχτού κώδικα, φιλοξενημένο στο Github. Υποστηρίζει εργαλεία για κάθε browser καθώς και για το Node, σε κάθε host, σε κάθε λειτουργικό σύστημα. Η TS μεταγλωττίζεται σε ευανάγνωστη JavaScript βασισμένη σε πρότυπα.

Η TS προσθέτει στην JS ένα ευέλικτο σύστημα τύπων, εκτός από interfaces (προσαρμοσμένους τύπους) και την τροποποίηση της σύνταξης ορισμένων χαρακτηριστικών της ECMAScript, όπως οι κλάσεις. Οι τύποι είναι προαιρετικοί και ευέλικτοι (για παράδειγμα, μπορείς να ορίσεις ότι ένα όρισμα είναι συμβολοσειρά Ή αριθμός). Οι τύποι δίνουν τη δυνατότητα στα εργαλεία που διαθέτουν οι περισσότεροι επεξεργαστές κώδικα να βελτιώσουν την εμπειρία ανάπτυξης, με λειτουργίες όπως η αυτόματη συμπλήρωση κώδικα και ο εντοπισμός μεθόδων, τόσο στον δικό σου κώδικα όσο και στα πακέτα που χρησιμοποιείς. Υποστηρίζει πολλά επερχόμενα χαρακτηριστικά της ECMAScript (όπως async/await). Η TS μπορεί να γραφτεί σε αντικειμενοστρεφές ή συναρτησιακό στυλ. Είναι συμβατή με όλα τα υπάρχοντα πακέτα JS. Η TS μετατρέπεται σε καθαρή, ευανάγνωστη JS.

Δοκίμασέ το στο [playground](https://www.typescriptlang.org/play) και μείνε ενημερωμένος μέσω του [blog του TypeScript](https://devblogs.microsoft.com/typescript/) και του [λογαριασμού στο Twitter](https://twitter.com/typescript).
