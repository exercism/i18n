# Χειρισμός bit

Η Crystal διαθέτει bitwise τελεστές για τον χειρισμό του [`Int`][ints] σε δυαδικό επίπεδο.

## Τελεστές μετατόπισης

Η Crystal διαθέτει [τελεστές μετατόπισης][shift] για τη μετατόπιση bit προς τα αριστερά (`<<`) ή προς τα δεξιά (`>>`).

### Μετατόπιση αριστερά (`<<`)

Ο τελεστής μετατόπισης αριστερά (`<<`) μετατοπίζει τα bit προς τα αριστερά.
Η τιμή που θα μετατοπιστεί δίνεται στα αριστερά και ο αριθμός των θέσεων μετατόπισης στα δεξιά.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Αν ο αριθμός είναι αρνητικός, η μετατόπιση γίνεται προς τα δεξιά.

```crystal
0b0010 << -1
# => 0b0001
```

### Μετατόπιση δεξιά (`>>`)

Ο τελεστής μετατόπισης δεξιά (`>>`) μετατοπίζει τα bit προς τα δεξιά.
Όπως και ο τελεστής μετατόπισης αριστερά, η τιμή που θα μετατοπιστεί δίνεται στα αριστερά και ο αριθμός των θέσεων μετατόπισης στα δεξιά.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Και αντίστοιχα, αν ο αριθμός είναι αρνητικός, ο τελεστής μετατοπίζει προς τα αριστερά.

```crystal
0b0100 >> -1
# => 0b1000
```

## Δυαδικοί τελεστές

Η Crystal διαθέτει 3 [δυαδικούς τελεστές][binary] (`&`, `|`, `^`) και έναν τελεστή `~` για την εκτέλεση bitwise πράξεων.

### Bitwise AND (`&`)

Ο δυαδικός τελεστής AND (`&`) εκτελεί μια bitwise πράξη AND σε δύο τιμές.
Συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Το bit που προκύπτει γίνεται 1 αν και τα δύο bit είναι 1.
Σε διαφορετική περίπτωση, γίνεται 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### Bitwise OR (`|`)

Ο δυαδικός τελεστής OR (`|`) εκτελεί μια bitwise πράξη OR σε δύο τιμές.
Συγκρίνει επίσης κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν ένα από τα δύο bit είναι 1, το bit που προκύπτει γίνεται 1.
Σε διαφορετική περίπτωση, γίνεται 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### Bitwise XOR (`^`)

Ο δυαδικός τελεστής XOR (`^`) εκτελεί μια bitwise πράξη XOR.
Όπως και οι τελεστές bitwise AND και bitwise OR, συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν _μόνο ένα_ από αυτά είναι 1, το bit που προκύπτει είναι 1.
Σε διαφορετική περίπτωση, είναι 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### Bitwise NOT (`~`)

Τέλος, ο bitwise τελεστής NOT (`~`) αντιστρέφει κάθε bit της τιμής.
Σε αντίθεση με τους άλλους δυαδικούς τελεστές, αυτός είναι μονομελής τελεστής και δρα μόνο στην τιμή στα δεξιά.

```crystal
~0b1110_0010
# => 0b0001_1101
```
