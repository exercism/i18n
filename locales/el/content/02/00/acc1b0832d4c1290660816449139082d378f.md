# Εισαγωγή

Στην Elixir, μια πλειάδα είναι μια δομή δεδομένων που οργανώνει δεδομένα, περιέχοντας έναν σταθερό αριθμό στοιχείων οποιουδήποτε τύπου, αλλά χωρίς ρητά ονόματα για κάθε στοιχείο. Οι πλειάδες χρησιμοποιούνται συχνά στην Elixir για εργασίες που κάνουν εντατική ανάγνωση από τη μνήμη, καθώς η ανάγνωση ενός στοιχείου είναι πράξη σταθερού χρόνου. Συνήθως δε χρησιμοποιούνται όταν στοιχεία μπορεί να χρειαστεί να προστεθούν ή να αφαιρεθούν δυναμικά, επειδή αντί να τροποποιηθεί η υπάρχουσα πλειάδα, δημιουργείται μια νέα πλειάδα, η οποία απαιτεί εκ των προτέρων δέσμευση μνήμης.

Στην πράξη, οι πλειάδες δημιουργούνται στην Elixir με άγκιστρα. Τα στοιχεία μιας πλειάδας μπορούν να προσπελαστούν μεμονωμένα με τη συνάρτηση `elem/2`, χρησιμοποιώντας θέσεις που ξεκινούν από το 0:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Οι πλειάδες ως ομαδοποιημένη πληροφορία

Οι πλειάδες χρησιμοποιούνται συχνά στην πράξη για να αναπαραστήσουν ομαδοποιημένες πληροφορίες.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
