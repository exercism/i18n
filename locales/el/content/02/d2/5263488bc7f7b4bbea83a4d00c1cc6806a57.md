# Σχετικά

Μια [εντολή switch][switch] σου επιτρέπει να συγκρίνεις μια τιμή με πολλές πιθανές τιμές που μπορεί να ταιριάξουν.
Σου επιτρέπει να γράψεις πιο συνοπτικό κώδικα απ' ό,τι με πολλαπλές εντολές `else-if`.
Μια εντολή `switch` ξεκινά με τη λέξη-κλειδί `switch` ακολουθούμενη από την τιμή που θα συγκριθεί.
Έπειτα μπορείς να ορίσεις τις περιπτώσεις χρησιμοποιώντας τη λέξη-κλειδί `case` ακολουθούμενη από την τιμή με την οποία θα γίνει η σύγκριση.
Η λέξη-κλειδί `default` χρησιμοποιείται για να ορίσεις την προεπιλεγμένη περίπτωση, όταν καμία από τις περιπτώσεις δεν ταιριάζει.
Όπως οι εντολές `else-if`, έτσι και οι εντολές `switch` εκτελούν μόνο το μπλοκ κώδικα που σχετίζεται με την πρώτη περίπτωση που ταιριάζει.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Ας δούμε το παρακάτω παράδειγμα:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Αυτό θα μπορούσε αντ' αυτού να γραφτεί ως εξής:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Δέσμευση και ρήτρες `where`

Οι τιμές που συγκρίνονται σε μια εντολή `switch` μπορούν επίσης να δεσμευτούν σε ονόματα, τα οποία μπορούν να χρησιμοποιηθούν στο σώμα της περίπτωσης.
Μπορούν επίσης να χρησιμοποιηθούν σε ρήτρες `where`, οι οποίες είναι επιπλέον εκφράσεις Boolean που πρέπει να αξιολογούνται ως `true` για να ταιριάξει η περίπτωση.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
