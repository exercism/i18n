# Οδηγίες

Στο **Chrono Realms**, οι Time Keepers δεν έχουν να κάνουν μόνο με δέντρα χρονογραμμών, αλλά και με **Chrono Chains**, δηλαδή ακολουθίες συνδεδεμένων **TimeNodes**, όπου το καθένα αντιπροσωπεύει μια συγκεκριμένη στιγμή στον χρόνο.
Μια **Chrono Chain** είναι μια ευθεία διαδρομή διαδοχικών στιγμών, όπου κάθε **TimeNode** συνδέεται με το επόμενο.
Αυτές οι **Chrono Chains** είναι χρήσιμες όταν ταξιδεύεις μέσα από μια σειρά συγκεκριμένων γεγονότων, αφού επιτρέπουν στους Time Keepers να ακολουθήσουν μία μόνο χρονογραμμή.

Ωστόσο, για να χειριστούν αυτές τις δυνητικά μεγάλες **Chrono Chains**, οι Time Keepers χρησιμοποιούν **έξυπνους δείκτες (Box<T>)** ώστε να διαχειρίζονται και να διατρέχουν με ασφάλεια αυτές τις λίστες στιγμών, χωρίς περιττό διπλασιασμό δεδομένων στη μνήμη ή υπερχείλιση.
Κάθε **TimeNode** κρατάει μια αναφορά στον επόμενο κόμβο, σχηματίζοντας μια αναδρομική δομή.

Η αποστολή σου ως μαθητευόμενος είναι να υλοποιήσεις μια **Chrono Chain** ως αναδρομική δομή λίστας, χρησιμοποιώντας έξυπνους δείκτες.

Σε αυτή την άσκηση, θα:

1. Δημιουργήσεις ένα αναδρομικό enum `ChronoChain`, που αντιπροσωπεύει μια λίστα στιγμών.
2. Χρησιμοποιήσεις τον έξυπνο δείκτη `Box<T>` για να αποθηκεύσεις τους αναδρομικούς κόμβους.
3. Υλοποιήσεις μια συνάρτηση που δημιουργεί μια `ChronoChain` από έναν πίνακα τιμών `u32`.
4. Υλοποιήσεις μια συνάρτηση που διατρέχει τη `ChronoChain` και αθροίζει τις τιμές που είναι αποθηκευμένες στη λίστα.

## 1. Όρισε το αναδρομικό enum `ChronoChain`

Δημιούργησε ένα αναδρομικό enum `ChronoChain` με δύο παραλλαγές:

- `End`: Αντιπροσωπεύει το τέλος της λίστας.
- `Link`: Περιέχει μια τιμή `u32` και μια αναφορά σε `Box` στον επόμενο κόμβο της αλυσίδας.

## 2. Δημιούργησε μια συνάρτηση που φτιάχνει μια ChronoChain

Γράψε μια συνάρτηση `ChronoChain::build` που παίρνει έναν πίνακα τιμών `u32` και επιστρέφει μια `ChronoChain`, συνδέοντας τις τιμές διαδοχικά με έξυπνους δείκτες.

## 3. Υλοποίησε τη συνάρτηση αθροίσματος

Γράψε μια συνάρτηση `ChronoChain::sum` που διατρέχει αναδρομικά τη `ChronoChain` και αθροίζει τις τιμές όλων των κόμβων.

## Παράδειγμα χρήσης

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
