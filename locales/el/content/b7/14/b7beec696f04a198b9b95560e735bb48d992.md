# Οδηγίες

Διαχειρίζεσαι ένα ηλεκτρονικό κατάστημα μόδας. Η μεγάλη ετήσια έκπτωσή σου πλησιάζει, οπότε πρέπει να κάνεις απογραφή του αποθέματός σου για να σιγουρευτείς ότι όλα είναι έτοιμα.

Κάθε μεμονωμένο είδος στο απόθεμα αναπαρίσταται από ένα map, και ολόκληρο το απόθεμα είναι μια λίστα από τέτοια map.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ταξινόμησε τα είδη κατά τιμή

Υλοποίησε τη συνάρτηση `sort_by_price/1`. Θα πρέπει να παίρνει το απόθεμα και να το επιστρέφει ταξινομημένο κατά τιμή είδους, σε αύξουσα σειρά.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Βρες όλα τα είδη με τιμές που λείπουν

Αφού ταξινόμησες το απόθεμά σου κατά τιμή, παρατήρησες ότι πρέπει να έκανες λάθος όταν έκανες την απογραφή και ξέχασες να συμπληρώσεις τις τιμές για μερικά είδη.

Υλοποίησε τη συνάρτηση `with_missing_price/1`. Θα πρέπει να παίρνει το απόθεμα και να επιστρέφει μια λίστα με τα είδη που δεν έχουν τιμή.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Ενημέρωσε τα ονόματα των ειδών

Παρατήρησες ότι ονόματα ορισμένων ειδών περιέχουν μια λέξη που δεν θέλεις πια να χρησιμοποιείς. Τώρα πρέπει να ενημερώσεις όλα τα ονόματα των ειδών που περιέχουν αυτή τη λέξη.

Υλοποίησε τη συνάρτηση `update_names/3`. Θα πρέπει να παίρνει το απόθεμα, την παλιά λέξη που θέλεις να αφαιρέσεις και μια νέα λέξη που θέλεις να χρησιμοποιήσεις στη θέση της. Θα πρέπει να επιστρέφει μια λίστα με είδη που έχουν ενημερωμένα ονόματα.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Αύξησε την ποσότητα του είδους

Μερικά είδη πουλούσαν ιδιαίτερα καλά, οπότε παρήγγειλες περισσότερα, σε όλα τα μεγέθη.

Υλοποίησε τη συνάρτηση `increase_quantity/2`. Θα πρέπει να παίρνει ένα μεμονωμένο είδος και έναν αριθμό `n`, και να επιστρέφει αυτό το είδος με την ποσότητα για κάθε μέγεθος αυξημένη κατά `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Υπολόγισε τη συνολική ποσότητα του είδους

Για να ξέρεις πόσο χώρο χρειάζεσαι στην αποθήκη σου, πρέπει να ξέρεις πόσα κομμάτια από κάθε είδος έχεις συνολικά.

Υλοποίησε τη συνάρτηση `total_quantity/1`. Θα πρέπει να παίρνει ένα μεμονωμένο είδος και να επιστρέφει πόσα κομμάτια έχεις συνολικά, σε οποιοδήποτε μέγεθος.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
