# Εκτύπωση

Η εκτύπωση στο Cairo σου επιτρέπει να εμφανίζεις μηνύματα και τιμές στην κονσόλα, διευκολύνοντας την αποσφαλμάτωση των προγραμμάτων ή τη μετάδοση πληροφοριών κατά την εκτέλεση.

Το σύστημα εκτύπωσης είναι ταυτόχρονα ευέλικτο και απλό, και παρέχει εργαλεία για τη μορφοποίηση και την έξοδο δεδομένων διαφόρων τύπων.

## Τα βασικά της εκτύπωσης

Το Cairo παρέχει δύο βασικά μάκρο για την εκτύπωση κειμένου στην κονσόλα:

- **`println!`**: Εκτυπώνει το αποτέλεσμα σε νέα γραμμή.
- **`print!`**: Εκτυπώνει το αποτέλεσμα στην ίδια γραμμή, χωρίς να προσθέτει νέα γραμμή.

Και τα δύο μάκρο δέχονται ως κύριο όρισμα ένα `ByteArray`, το οποίο μπορεί να είναι μια απλή συμβολοσειρά ή μια μορφοποιημένη συμβολοσειρά με σύμβολα αντικατάστασης για τιμές.

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

Στο παραπάνω παράδειγμα:

- Τα σύμβολα αντικατάστασης `{}` αντικαθίστανται από τις τιμές των `x` και `y`.
- Το `println!` διασφαλίζει ότι η έξοδος τελειώνει με νέα γραμμή.

## Μορφοποίηση συμβολοσειρών

Κάποιες φορές μπορεί να χρειαστεί να δημιουργήσεις μια μορφοποιημένη συμβολοσειρά χωρίς να την εκτυπώσεις αμέσως.

Το μάκρο `format!` σου επιτρέπει να το κάνεις αυτό.

Λειτουργεί παρόμοια με το `println!`, αλλά επιστρέφει ένα `ByteArray` αντί να στέλνει την έξοδο στην κονσόλα.

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

Σε αυτό το παράδειγμα:

- Το `format!` συνδυάζει τα `s1`, `s2` και `s3` σε μία συμβολοσειρά, χωρίζοντάς τα με παύλες (`-`).
- Η συμβολοσειρά που προκύπτει μπορεί να ξαναχρησιμοποιηθεί ή να εκτυπωθεί αργότερα.

## Εκτύπωση προσαρμοσμένων τύπων δεδομένων

Από προεπιλογή, το Cairo μπορεί να εκτυπώσει μόνο βασικούς τύπους, όπως ακέραιους αριθμούς και συμβολοσειρές.

Αν προσπαθήσεις να εκτυπώσεις έναν προσαρμοσμένο τύπο, όπως ένα struct, θα συναντήσεις σφάλμα, εκτός αν ο τύπος υλοποιεί τα trait `Display` ή `Debug`.

### Χρήση του `Display` για προσαρμοσμένη μορφοποίηση

Το trait `Display` σου επιτρέπει να ορίσεις πώς πρέπει να εκτυπώνεται ένας προσαρμοσμένος τύπος.

Να ένα παράδειγμα:

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

Σε αυτό το παράδειγμα:

- Η συνάρτηση `fmt` ορίζει πώς το struct `Point` μετατρέπεται σε μια εκτυπώσιμη συμβολοσειρά.
- Το μάκρο `write!` προσθέτει τη μορφοποιημένη συμβολοσειρά στο `Formatter`.

### Αποσφαλμάτωση με το `Debug`

Για σκοπούς αποσφαλμάτωσης, το Cairo παρέχει το trait `Debug`.

Μπορείς να το παράγεις αυτόματα για τους περισσότερους τύπους, κάνοντάς το γρήγορο και εύκολο να εκτυπώσεις τις εσωτερικές λεπτομέρειες των struct σου.

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

Σε αυτό το παράδειγμα:

- Το `#[derive(Debug)]` δημιουργεί αυτόματα την υλοποίηση για το trait `Debug`.
- Το σύμβολο αντικατάστασης `{:?}` λέει στο `println!` να χρησιμοποιήσει το trait `Debug` για τη μορφοποίηση.

## Εκτύπωση σε δεκαεξαδικό

Το Cairo επιτρέπει την εκτύπωση ακεραίων σε δεκαεξαδική μορφή με το σύμβολο αντικατάστασης `{:x}`.

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

Αυτό είναι ιδιαίτερα χρήσιμο όταν δουλεύεις με αναπαραστάσεις δεδομένων χαμηλού επιπέδου.
