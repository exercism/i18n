# Εισαγωγή

Το Swift προσφέρει μια παραλλαγή της σύνταξής του όταν χειρίζεται closures, γνωστή ως trailing closures. Τα trailing closures προκύπτουν όταν η τελευταία παράμετρος στη λίστα παραμέτρων μιας συνάρτησης έχει τύπο συνάρτησης. Σε αυτή την περίπτωση, αν περνάς ένα closure, το closure μπορεί να γραφτεί _μετά_ την κλείνουσα παρένθεση και η ετικέτα του ορίσματος παραλείπεται. Σημείωσε ότι αν η συνάρτηση έχει μόνο μία παράμετρο, οι παρενθέσεις μπορούν να παραλειφθούν εντελώς.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
