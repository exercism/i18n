# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να προετοιμαστείς για την αγορά ενός νέου οχήματος.

Έχεις τρεις εργασίες: μία για να σε βοηθήσει να προσδιορίσεις την τιμή του οχήματος στο οποίο μπορείς να ανταπεξέλθεις οικονομικά, μία για να προσδιορίσεις αν θα χρειαστείς άδεια οδήγησης και μία για να σε βοηθήσει να υπολογίσεις το τέλος ταξινόμησης.

## 1. Υπολόγισε αν μπορείς να ανταπεξέλθεις στις μηνιαίες δόσεις για ένα συγκεκριμένο όχημα

Οι έμποροι οχημάτων στην πόλη σου τρέχουν όλοι μια πενταετή προσφορά με 0% επιτόκιο, την οποία θα ήθελες να εκμεταλλευτείς.
Υλοποίησε τη συνάρτηση `canibuy(vehicle, price, monthly_budget)` που δέχεται το όνομα του οχήματος που κοιτάς, την τιμή του και τον μηνιαίο προϋπολογισμό σου, και επιστρέφει μια συμβολοσειρά που σου λέει αν μπορείς να ανταπεξέλθεις οικονομικά στο όχημα ή όχι. Αν η μηνιαία δόση είναι εντός 10 από τον μηνιαίο προϋπολογισμό σου, θα θελήσεις να επιστρέψεις μια ειδική υπενθύμιση να κάνεις οικονομία:

```julia-repl
julia> canibuy("1974 Ford Pinto", 516, 100)
"Yes! I'm getting a 1974 Ford Pinto."

julia> canibuy("2014 Bugatti Veyron", 562_500, 5000)
"Damn! No 2014 Bugatti Veryon for me."

julia> canibuy("2020 Gazelle Medeo", 3000, 50)
"I'll have to be frugal if I want a 2020 Gazelle Medeo."
```

~~~~exercism/note
Οι αριθμοί στη Julia μπορούν να περιέχουν `_` για να ομαδοποιούν τα ψηφία μαζί.
Π.χ. το `562_500` ισούται με `562500`.
~~~~

## 2. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

Αν αποφασίσεις να αγοράσεις αυτοκίνητο, θα χρειαστείς άδεια οδήγησης.
Τα ποδήλατα δεν χρειάζονται άδεια.
Υλοποίησε τη συνάρτηση `licence(vehicle, kind)` που δέχεται το όνομα του οχήματος και το είδος του οχήματος (είτε `"car"` είτε `"bike"`) και επιστρέφει αν χρειάζεσαι άδεια:

```julia-repl
julia> licence("2014 Bugatti Veyron", "car")
"The 2014 Bugatti Veyron requires a licence to operate."

julia> licence("2020 Gazelle Medeo", "bike")
"The 2020 Gazelle Medeo requires no licence to operate."
```

## 3. Υπολόγισε το τέλος ταξινόμησης για το νέο σου όχημα

Το τέλος ταξινόμησης για το νέο σου όχημα βασίζεται στον παρακάτω τύπο:

- Τα ποδήλατα δεν χρειάζεται να ταξινομηθούν. Επομένως το τέλος είναι 0€.
- Για κάθε αυτοκίνητο ηλικίας 10 ετών ή μεγαλύτερο, το τέλος είναι σταθερό 25€.
- Για κάθε νεότερο αυτοκίνητο:
  1. Ξεκίνα με ένα βασικό κόστος που είναι είτε η Προτεινόμενη Τιμή Λιανικής του Κατασκευαστή (MSRP) για το αυτοκίνητο, είτε 25&nbsp;000€, όποιο από τα δύο είναι μεγαλύτερο.
  2. Για κάθε χρόνο ηλικίας, αφαίρεσε το 10% της βασικής τιμής.
  3. Διαίρεσε αυτή την τιμή με το 100. Αυτό είναι το τέλος ταξινόμησης που θα πρέπει να πληρώσεις.

Υλοποίησε τη συνάρτηση `fee(msrp, age, kind)` που δέχεται το MSRP του οχήματος, την ηλικία του σε χρόνια και το είδος του οχήματος (είτε `"car"` είτε `"bike"`), και επιστρέφει το τέλος ταξινόμησης για αυτό το όχημα, σύμφωνα με τον παραπάνω τύπο.

```julia-repl
julia> fee(562_500, 6, "car")
2250

julia> fee(25_000, 3, "car")
175

julia> fee(34_000, 30, "car")
25

julia> fee(3000, 0, "bike")
0
```
