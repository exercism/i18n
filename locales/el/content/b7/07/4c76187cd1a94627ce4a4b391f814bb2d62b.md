# Δοκιμές

Υπάρχει ένα σενάριο Perl με επέκταση `.t` που βρίσκεται στον κατάλογο `t/`, το οποίο θα χρησιμοποιηθεί για να δοκιμάσει τη λύση σου.
Μπορείς να τρέξεις τις δοκιμές χρησιμοποιώντας την εντολή:

```bash
`prove`
```

Η τεκμηρίωση σχετικά με τους ισχυρισμούς που χρησιμοποιούνται στα αρχεία δοκιμών βρίσκεται στο [Test2::Manual::Testing::Introduction][test2-manual].

[test2-manual]: https://metacpan.org/pod/Test2::Manual::Testing::Introduction
