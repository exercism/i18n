# Getters and setters

Τα getter και τα setter είναι μέθοδοι που σου επιτρέπουν να διαβάζεις και να γράφεις την τιμή της ιδιότητας ενός αντικειμένου.
Η Crystal έχει macros, κάτι που κάνει εύκολο τον ορισμό getter και setter για μια ιδιότητα.
Τα macros είναι ένας τρόπος να παράγεις κώδικα σε χρόνο μεταγλώττισης, κάτι που θα καλυφθεί αργότερα στην ενότητα για τα macros.

Στη Ruby αυτές οι μέθοδοι ορίζονται με τις μεθόδους `attr_reader`, `attr_writer` και `attr_accessor` και εκ πρώτης όψεως μοιάζουν πολύ με την υλοποίηση της Crystal.
Η Crystal τις έχει ορίσει ως τα macros `getter`, `setter` και `property`.

## Getters

Το `getter` είναι ένα macro που ορίζει μια μέθοδο η οποία επιστρέφει την τιμή μιας μεταβλητής στιγμιοτύπου.
Αυτό σημαίνει ότι δεν χρειάζεται πια να γράφεις `@` μπροστά από τη μεταβλητή στιγμιοτύπου όταν θέλεις να έχεις πρόσβαση σε αυτήν (σε μεθόδους, εκτός από το initialize)· αντ' αυτού, μπορείς να καλέσεις τη μέθοδο που έχει ορίσει το macro `getter`.

Το macro `getter` μπορεί να δεχτεί πολλές μεταβλητές στιγμιοτύπου, χωρίζοντάς τες με κόμμα.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Όπως βλέπεις, χρησιμοποιώντας το `getter` γράφεις λιγότερο κώδικα και αυτός διαβάζεται πιο εύκολα.
Επίσης, η Ruby και η Crystal διαφέρουν στο ότι η Crystal δέχεται και το όνομα της μεταβλητής και το symbol ως ορίσματα για το macro `getter`.
Τα symbols θα καλυφθούν αργότερα στην ενότητα για τα symbols.

## Setters

Το `setter` είναι ένα macro που ορίζει μια μέθοδο η οποία θέτει την τιμή μιας μεταβλητής στιγμιοτύπου.
Αυτό το macro δεν συναντάται τόσο συχνά και συνήθως χρησιμοποιείται αντ' αυτού το macro `property`.
Οι μέθοδοι που θα δημιουργηθούν θα έχουν τη μορφή `name_of_method=`· το `=` είναι αυτό που κάνει δυνατόν να οριστεί η ιδιότητα.

Ο ορισμός αυτής της μεθόδου είναι λίγο ιδιαίτερος, αφού το όρισμα που δέχεται η μέθοδος βρίσκεται μετά το σύμβολο `=`.
Αρκετές άλλες ειδικές μέθοδοι στη Crystal χρησιμοποιούν αυτή τη σύνταξη, όπως η μέθοδος `+`.

Όπως και με το macro `getter`, όταν θέλεις να ενημερώσεις την τιμή μιας μεταβλητής στιγμιοτύπου αφού έχεις ορίσει ένα `setter`, μπορείς να καλέσεις τη μέθοδο που έχει ορίσει το macro `setter`.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Το `property` είναι ένα macro που ορίζει και `getter` και `setter` για μια μεταβλητή στιγμιοτύπου.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
