# Εισαγωγή

## Οι βρόχοι `for`

Η εντολή `for` επαναλαμβάνει ένα μπλοκ κώδικα.
Η πρώτη της γραμμή ελέγχει πόσο συχνά επαναλαμβάνεται το μπλοκ:

```go
for init; condition; post {
    // loop body
}
```

- Η εντολή **init** εκτελείται μία φορά πριν από την πρώτη επανάληψη. Συνήθως εκεί δηλώνεται και αρχικοποιείται η μεταβλητή μετρητή που χρησιμοποιεί ο βρόχος.
- Η **condition** είναι μια Boolean (λογική τιμή) έκφραση που αξιολογείται πριν από κάθε επανάληψη. Ο βρόχος σταματά όταν αυτή αξιολογηθεί ως `false`.
- Η εντολή **post** εκτελείται μετά από κάθε ολοκληρωμένη επανάληψη. Μπορεί να χρησιμοποιηθεί για την ενημέρωση ενός μετρητή.

Μη βάλεις παρενθέσεις γύρω από το `init; condition; post`.
Ωστόσο, τα άγκιστρα `{ }` γύρω από το σώμα του βρόχου είναι πάντα απαραίτητα.

Αυτός ο βρόχος ξεκινά το `i` από το `1`, εκτυπώνει την τρέχουσα τιμή του `i`, την αυξάνει για την επόμενη επανάληψη και σταματά όταν το `i` φτάσει στο `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
