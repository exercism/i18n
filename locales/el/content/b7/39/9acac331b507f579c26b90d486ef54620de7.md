# Εισαγωγή

Στην Haxe, οι εξαιρέσεις είναι ένας ασφαλής τρόπος να χειρίζεσαι σφάλματα που συμβαίνουν όταν εκτελείται ο κώδικας. Όλες οι εξαιρέσεις πρέπει να περιέχουν ένα μήνυμα που περιγράφει το σφάλμα. Μπορούμε να _πετάμε_ εξαιρέσεις χρησιμοποιώντας τη λέξη-κλειδί `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Όταν πετιέται μια εξαίρεση, ο κώδικας ψάχνει για ένα κομμάτι που έχει ανατεθεί να χειριστεί το σφάλμα. Αν δε βρει κανένα, θα εμφανίσει το μήνυμα σφάλματος και ταυτόχρονα θα σταματήσει την εκτέλεση του προγράμματος.

Για να χειριστούμε εξαιρέσεις στην Haxe, χρησιμοποιούμε το μπλοκ `try-catch`. Αυτή η δομή αποτελείται από ένα μπλοκ `try` και ένα ή περισσότερα μπλοκ `catch`. Το μπλοκ `try` _προσπαθεί_ να εκτελέσει ένα κομμάτι κώδικα, ενώ το μπλοκ `catch` περιμένει μήπως πεταχτεί κάποια εξαίρεση για να την _πιάσει_, ώστε να μη σταματήσει η εκτέλεση. Όταν το μπλοκ `catch` πιάσει μια εξαίρεση, εκτελεί επίσης ό,τι υπάρχει μέσα στο μπλοκ:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Ο τύπος του ορίσματος του μπλοκ `catch` πρέπει να παραλείπεται.
