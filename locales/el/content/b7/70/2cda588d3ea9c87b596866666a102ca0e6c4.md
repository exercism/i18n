# Τύποι αριθμών

Η Crystal έχει μια ποικιλία από διαφορετικούς τύπους αριθμών για διάφορους σκοπούς.
Για παράδειγμα, κάποιοι τύποι είναι ταχύτεροι αλλά έχουν μικρότερο εύρος δυνατών τιμών από άλλους.
Κάποιοι έχουν μεγαλύτερο εύρος δυνατών τιμών αλλά είναι πιο αργοί.

Στην Crystal, υπάρχουν και προσημασμένοι και μη προσημασμένοι τύποι ακεραίων.
Οι προσημασμένοι τύποι ακεραίων μπορούν να είναι θετικοί ή αρνητικοί.
Οι μη προσημασμένοι τύποι ακεραίων μπορούν να είναι μόνο θετικοί.

## Τύποι προσημασμένων ακεραίων

Αυτοί είναι οι [προσημασμένοι τύποι ακεραίων][int] στην Crystal:

| Τύπος    | Μέγεθος (bit) | Εύρος                                                                                                       |
| -------- | ------------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8             | -128 έως 127                                                                                                |
| `Int16`  | 16            | -32_768 έως 32_767                                                                                          |
| `Int32`  | 32            | -2_147_483_648 έως 2_147_483_647                                                                            |
| `Int64`  | 64            | -9_223_372_036_854_775_808 έως 9_223_372_036_854_775_807                                                    |
| `Int128` | 128           | -170_141_183_460_469_231_731_687_303_715_884_105_728 έως 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Οι μικρότεροι τύποι χρησιμοποιούν λιγότερη μνήμη και είναι ταχύτεροι από τους μεγαλύτερους, αλλά έχουν μικρότερο εύρος δυνατών τιμών.

Όταν ξέρεις ότι οι τιμές θα βρίσκονται μέσα σε ένα συγκεκριμένο εύρος, το καλύτερο είναι να χρησιμοποιείς τον μικρότερο δυνατό τύπο για να εξοικονομήσεις μνήμη και να βελτιώσεις την απόδοση.

Ο προεπιλεγμένος τύπος ακέραιου είναι ο `Int32`.
Για να δηλώσεις έναν ακέραιο με συγκεκριμένο τύπο, μπορείς να χρησιμοποιήσεις το όνομα του τύπου ως επίθημα προσθέτοντας `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Μπορείς να χρησιμοποιήσεις τη μέθοδο `to_i<bit>` για να μετατρέψεις μεταξύ διαφορετικών τύπων ακεραίων.
Η μέθοδος `to_i` μετατρέπει στον προεπιλεγμένο τύπο ακέραιου, τον `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Τύποι μη προσημασμένων ακεραίων

Αυτοί είναι οι τύποι [μη προσημασμένων ακεραίων][uint] στην Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

Η μόνη διαφορά μεταξύ προσημασμένων και μη προσημασμένων ακεραίων είναι ότι οι μη προσημασμένοι ακέραιοι μπορούν να είναι μόνο θετικοί.
Για να δηλώσεις έναν μη προσημασμένο ακέραιο με συγκεκριμένο τύπο, μπορείς να χρησιμοποιήσεις το όνομα του τύπου ως επίθημα προσθέτοντας `<number>_u<bit>`.
Μπορείς να χρησιμοποιήσεις τη μέθοδο `to_u<bit>` για να μετατρέψεις μεταξύ διαφορετικών τύπων μη προσημασμένων ακεραίων.
Η μέθοδος `to_u` μετατρέπει στον προεπιλεγμένο τύπο μη προσημασμένου ακέραιου, τον `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Τύποι κινητής υποδιαστολής

Αυτοί είναι οι τύποι κινητής υποδιαστολής στην Crystal:

| Τύπος     | Μέγεθος (bit) | Εύρος                 |
| --------- | ------------- | --------------------- |
| `Float32` | 32            | 1.2E-38 έως 3.4E+38   |
| `Float64` | 64            | 2.3E-308 έως 1.7E+308 |

Υπάρχουν δύο διαφορετικοί [τύποι κινητής υποδιαστολής][float], ο ένας είναι πιο ακριβής από τον άλλο.

Ο προεπιλεγμένος τύπος κινητής υποδιαστολής είναι ο `Float64`.

Μπορείς να χρησιμοποιήσεις τη μέθοδο `to_f<bit>` για να μετατρέψεις μεταξύ διαφορετικών τύπων κινητής υποδιαστολής.
Η μέθοδος `to_f` μετατρέπει στον προεπιλεγμένο τύπο κινητής υποδιαστολής, τον `Float64`.

## Τύπος μετά από μια πράξη

Όταν εκτελείς μια πράξη μεταξύ δύο αριθμών, το αποτέλεσμα θα είναι του τύπου του αριθμού με τη μεγαλύτερη ακρίβεια.
Ο `Float` έχει μεγαλύτερη ακρίβεια από έναν ακέραιο και ένας ακέραιος έχει μεγαλύτερη ακρίβεια από έναν μη προσημασμένο ακέραιο.
Έπειτα, ο `Float64` έχει μεγαλύτερη ακρίβεια από τον Float32, και ούτω καθεξής.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Σε βάθος: μη προσημασμένοι εναντίον προσημασμένων ακεραίων

~~~~exercism/advanced
Κάτω από το καπό, αυτό που διαφοροποιεί τους μη προσημασμένους από τους προσημασμένους ακέραιους είναι ότι οι προσημασμένοι ακέραιοι χρησιμοποιούν το πρώτο bit για να αποθηκεύσουν το πρόσημο.
Το πρόσημο είναι είτε θετικό είτε αρνητικό.
Για τους μη προσημασμένους ακέραιους, το πρώτο bit χρησιμοποιείται για να αποθηκεύσει την τιμή.
Έτσι, για έναν προσημασμένο ακέραιο 32 bit, η μέγιστη τιμή είναι 2^31 - 1.
Για έναν μη προσημασμένο ακέραιο 32 bit, η μέγιστη τιμή είναι 2^32 - 1.

Αν θέλεις να μάθεις περισσότερα για την προσημασία, μπορείς να διαβάσεις περισσότερα σχετικά στη [Wikipedia](https://en.wikipedia.org/wiki/Signedness).
~~~~
