# Προσάρτημα οδηγιών

## Οδηγίες ειδικά για SQLite

Για να γεμίσεις τον πίνακα `results`, υπάρχουν τέσσερις "ιδιότητες" που πρέπει να λάβεις υπόψη:

* **scores**: Πρέπει να συγκεντρώσεις όλα τα σκορ για κάθε `game_id` και να τα αποθηκεύσεις σε μια συμβολοσειρά χωρισμένη με κόμματα.
  Τα σκορ πρέπει να εμφανίζονται με την ίδια σειρά που εισήχθησαν στον πίνακα `scores`.
* **latest**: Πρέπει να βρεις το τελευταίο σκορ που εισήχθη στον πίνακα `scores`.
* **personalBest**: Βρες το μέγιστο σκορ για κάθε `game_id`.
* **personalTopThree**: Βρες τα τρία υψηλότερα σκορ για κάθε `game_id` και συγκέντρωσέ τα σε μια συμβολοσειρά χωρισμένη με κόμματα, ταξινομημένη σε φθίνουσα σειρά.
