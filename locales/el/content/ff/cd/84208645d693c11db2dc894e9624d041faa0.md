# Σχετικά

Ένα `Map` χρησιμοποιείται για την αποθήκευση ζευγών **κλειδιού** και **τιμής**. Τα `Maps` αρχικοποιούνται όπως ακριβώς ένας πίνακας, αλλά χρησιμοποιούν τον τελεστή `=>` για τα map literal. Μπορείς επίσης να ορίσεις ρητά τους τύπους κλειδιού-τιμής τους, ή οι τύποι μπορούν να συναχθούν. Τα κλειδιά πρέπει να είναι μοναδικά, διαφορετικά πετιέται ένα σφάλμα.

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

Μπορείς να διατρέξεις ένα `Map` χρησιμοποιώντας έναν `for` βρόχο. Μπορείς να διατρέξεις είτε τις τιμές είτε τα κλειδιά:

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```

Εσωτερικά, το `Map` είναι ένας αφηρημένος τύπος. Κατά τη μεταγλώττιση, μετατρέπεται σε έναν από αρκετούς εξειδικευμένους τύπους, ανάλογα με τον τύπο του κλειδιού:

- `String`: `haxe.ds.StringMap`
- `Int`: `haxe.ds.IntMap`
- `EnumValue`: `haxe.ds.EnumValueMap`
- `{}`: `haxe.ds.ObjectMap`

Ο τύπος `Map` δεν υπάρχει κατά την εκτέλεση και έχει αντικατασταθεί από ένα από τα παραπάνω αντικείμενα.
