# Εισαγωγή

## Εντολές `switch`

Όπως μια _if/else_ εντολή, έτσι και μια εντολή `switch` σου επιτρέπει να αλλάξεις τη ροή του προγράμματος εκτελώντας κώδικα υπό συνθήκη.
Η διαφορά είναι ότι μια εντολή `switch` μπορεί να συγκρίνει μόνο την τιμή μιας έκφρασης πρωτογενούς τύπου ή συμβολοσειράς με προκαθορισμένες σταθερές τιμές.

Κάποιες λέξεις-κλειδιά είναι χρήσιμες όταν χρησιμοποιείς μια εντολή switch.

- `switch`: αυτή η λέξη-κλειδί σου επιτρέπει να δηλώσεις τη δομή του switch.
  Ακολουθείται από την έκφραση ή τη μεταβλητή που θα αλλάξει το αποτέλεσμα.
- `case`: θα χρησιμοποιήσεις αυτή τη λέξη-κλειδί για να δηλώσεις τις διαφορετικές περιπτώσεις για το αποτέλεσμα.
- `break`: η λέξη-κλειδί `break` είναι πολύ χρήσιμη για να σταματήσεις την εκτέλεση του switch στο τέλος της ροής που θέλεις.
  Αν την ξεχάσεις, το πρόγραμμα θα συνεχίσει και μπορεί να οδηγήσει σε απρόσμενα αποτελέσματα.
- `default`: όπως λέει και το όνομά της, χρησιμοποίησέ τη ως προεπιλεγμένο αποτέλεσμα όταν καμία άλλη περίπτωση δεν ταιριάζει με το αποτέλεσμα της έκφρασής σου.

Στην απλούστερη μορφή τους, ελέγχουν μια έκφραση πρωτογενούς τύπου ή συμβολοσειράς και παίρνουν μια απόφαση με βάση την τιμή της.
Για παράδειγμα:

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
