# Υποδείξεις

## 1. Δημιούργησε έναν νέο πίνακα υψηλών βαθμολογιών

- Οι συναρτήσεις [`dict.new`][new] και [`dict.from_list`][from_list] μπορούν να χρησιμοποιηθούν για τη δημιουργία ενός νέου λεξικού.

## 2. Πρόσθεσε παίκτες σε έναν πίνακα βαθμολογιών

- Η συνάρτηση [`dict.insert`][insert] μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα νέο ζεύγος κλειδιού-τιμής σε ένα λεξικό.

## 3. Αφαίρεσε παίκτες από έναν πίνακα βαθμολογιών

- Η συνάρτηση [`dict.delete`][delete] μπορεί να χρησιμοποιηθεί για να αφαιρέσεις ένα ζεύγος κλειδιού-τιμής από ένα λεξικό.

## 4. Αύξησε τη βαθμολογία ενός παίκτη

- Η συνάρτηση [`dict.get`][get] μπορεί να χρησιμοποιηθεί για να πάρεις την τιμή για ένα κλειδί σε ένα λεξικό.
- Η συνάρτηση [`dict.insert`][insert] μπορεί να χρησιμοποιηθεί για να αντικαταστήσεις ένα υπάρχον ζεύγος κλειδιού-τιμής σε ένα λεξικό.

## 5. Εφάρμοσε τους πόντους μπόνους της Δευτέρας

- Η συνάρτηση [`dict.map_values`][map_values] μπορεί να χρησιμοποιηθεί για να τροποποιήσεις όλες τις τιμές σε ένα λεξικό.
