# Εισαγωγή

## Nil

Το [Nil][nil-dictionary] είναι μια αγγλική λέξη που σημαίνει "τίποτα" ή "μηδέν". Στην Elixir, το `nil` είναι μια ειδική τιμή που σημαίνει _απουσία_ μιας τιμής.

```elixir
# I do not have a favorite color
favorite_color = nil
```

Σε άλλες γλώσσες προγραμματισμού, οι τιμές `null` ή `none` μπορεί να παίζουν παρόμοιο ρόλο.

## If

Εκτός από το `cond`, η Elixir παρέχει επίσης το μάκρο [`if/2`][getting-started-if], το οποίο είναι χρήσιμο όταν χρειάζεται να ελέγξεις μόνο μία συνθήκη.

Το [`if/2`][kernel-if] δέχεται μια συνθήκη και δύο επιλογές. Επιστρέφει την πρώτη επιλογή αν η συνθήκη είναι _truthy_, και τη δεύτερη επιλογή αν η συνθήκη είναι _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Είναι επίσης δυνατό να γράψεις μια έκφραση `if` σε μία μόνο γραμμή. Πρόσεξε το κόμμα μετά τη συνθήκη.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Αυτή η σύνταξη είναι χρήσιμη για πολύ σύντομες εκφράσεις, αλλά καλύτερα να την αποφεύγεις αν η έκφραση δεν χωράει σε μία μόνο γραμμή.

### _Truthy_ και _falsy_

Στην Elixir, όλοι οι τύποι δεδομένων αξιολογούνται σε μια τιμή _truthy_ ή _falsy_ όταν συναντώνται σε ένα boolean πλαίσιο (όπως μια έκφραση `if`). Όλα τα δεδομένα θεωρούνται _truthy_ **εκτός** από το `false` και το `nil`. Συγκεκριμένα, οι κενές συμβολοσειρές, ο ακέραιος `0` και οι κενές λίστες θεωρούνται όλα _truthy_ στην Elixir.
