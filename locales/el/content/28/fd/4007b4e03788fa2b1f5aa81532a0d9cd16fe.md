# Οδηγίες

Σε αυτή την άσκηση, παίζεις ένα παιχνίδι ρόλων με το όνομα "μάγοι και πολεμιστές". Για να παίξεις αυτό το παιχνίδι, χρειάζεσαι μια μέθοδο ρίψης ζαριού για κάθε περίσταση, ώστε να καθορίζονται διάφορα αποτελέσματα. Θα είναι το παραδοσιακό ζάρι με 18 πλευρές και αριθμούς από το 1 ως το 18. Οι παίκτες θα πρέπει επίσης να παράγουν μια τυχαία δύναμη ξόρκιου.

## 1. Δώσε τη δυνατότητα σε έναν παίκτη του _μάγοι και πολεμιστές_ να ρίξει ένα ζάρι

Υλοποίησε μια μέθοδο `RollDie()` στην κλάση `Player`.

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. Οι παίκτες χρειάζονται τη δύναμή τους. Δώσε έναν τρόπο να παράγουν δύναμη ξόρκιου

Υλοποίησε μια μέθοδο `GenerateSpellStrength()` στην κλάση του παίκτη.
Η δύναμη ξόρκιου είναι μεταξύ 0.0 και μέχρι αλλά χωρίς να συμπεριλαμβάνεται το 100.0.

Σημείωσε ότι η δύναμη ξόρκιου πρέπει να είναι αριθμός κινητής υποδιαστολής (όχι ακέραιος), ώστε να μειωθεί η πιθανότητα ισοπαλίας όταν συγκρίνονται οι δυνάμεις δύο αντιπάλων.

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
