# Η νοοτροπία της καθοδήγησης

## Τι _είναι_ μια νοοτροπία;

Πριν εξετάσουμε τη νοοτροπία της καθοδήγησης, μπορεί να είναι χρήσιμο να καταλάβουμε τι είναι μια νοοτροπία. Σύμφωνα με το Oxford English Dictionary, το `Mindset` είναι ένα "καθιερωμένο σύνολο στάσεων, ιδίως αυτών που θεωρούνται τυπικές για τις κοινωνικές ή πολιτισμικές αξίες μιας συγκεκριμένης ομάδας."
Ένα άτομο μπορεί να έχει ατομικό κίνητρο για να ασχοληθεί με μια δραστηριότητα, αλλά η νοοτροπία κατευθύνει ώστε το κίνητρο να είναι ευθυγραμμισμένο με τις αξίες μιας ομάδας.
Για τον μέντορα του Exercism, αυτό σημαίνει να προσεγγίζει τη διαδικασία της καθοδήγησης μέσα στο πνεύμα της κοινότητας του Exercism.

## Το πνεύμα της κοινότητας του Exercism

Μπορεί να είναι χρήσιμο να ανατρέξεις στην πρόθεση του Exercism όπως εκφράζεται στη σελίδα [Σχετικά][exercism-about].
Αξίζει να τα διαβάσεις και να τα σκεφτείς όλα, ειδικά τα εξής:

- "Χτίζουμε έναν χώρο όπου ο καθένας μπορεί να μάθει και να τελειοποιήσει τον προγραμματισμό δωρεάν, χωρίς να νιώσει ποτέ χαμένος ή ανόητος."
- "Το Exercism πρέπει να είναι ευχάριστο, προκλητικό και πολύτιμο."
- "Το Exercism πρέπει να ενθαρρύνει μια νοοτροπία ανάπτυξης, σαφή και ενσυναισθητική επικοινωνία και να τονίζει την αξία της κοινής μάθησης."
- "Το Exercism πρέπει να είναι ασφαλές και υποστηρικτικό."
- "Το Exercism εστιάζει στο ταξίδι της μάθησης, όχι στον προορισμό. Η διαδικασία και η απόλαυση της μάθησης είναι πιο σημαντικές από την απόλυτη πραγματολογική ορθότητα."

## Το πνεύμα του καθοδηγούμενου

Το πνεύμα ενός καθοδηγούμενου μπορεί να φαίνεται εκ πρώτης όψεως απωθητικό.

Μερικοί καθοδηγούμενοι μπορεί να έχουν κάτι στο σχόλιό τους που είναι αυτοϋποτιμητικό.
Μπορεί να πουν κάτι σαν "Δεν είμαι πολύ έξυπνος" ή "Δεν καταλαβαίνω" ή "Δεν τα καταφέρνω πολύ καλά σε αυτό".
Μπορεί να είναι δελεαστικό να απαντήσεις σε τέτοιες δηλώσεις απευθείας, με το πνεύμα ενσυναίσθησης και υποστήριξης του Exercism.
Ως μέντορας, όμως, μπορεί να είναι πιο αποτελεσματικό να εκφράσεις τα συγκεκριμένα πράγματα που σου αρέσουν στη λύση τους
παρά να τους δώσεις κάποιου είδους αόριστη ενθάρρυνση.
Αν δεν υπάρχει τίποτα που μπορείς ειλικρινά να επαινέσεις στη λύση τους, μπορείς να τους συγχαρείς που πέρασαν τα τεστ,
ή, αν δεν πέρασαν τα τεστ, τουλάχιστον να αναγνωρίσεις την προσπάθειά τους.

Μερικοί καθοδηγούμενοι μπορεί να ξεκινήσουν το σχόλιό τους με κάτι που μπορεί να φανεί αρνητικό.
Μπορεί να πουν κάτι σαν "Γιατί πρέπει να κάνω το τάδε;"
Μπορεί να νιώσεις σαν να παραπονιούνται με τον τρόπο του "Γιατί πρέπει να φάω τα μπιζέλια μου; Τα _μισώ_ τα μπιζέλια!"
Μπορεί να αποθαρρυνθείς από το να καθοδηγήσεις το άτομο, επειδή φαίνεται να ξεκινάει αντιπαραθετικά.
Αλλά αυτό που μπορεί να φαίνεται σαν απείθεια ή παράπονο μπορεί να είναι απλώς μια απλή ερώτηση, ακόμα κι αν διατυπώνεται κάπως απότομα.

```exercism/note
Πολλοί καθοδηγούμενοι δεν έχουν τα αγγλικά ως πρώτη γλώσσα.
Αυτός μπορεί να είναι ένας ακόμη λόγος για τον οποίο τα αρχικά σχόλια ενός καθοδηγούμενου μπορεί να φαίνονται λιγότερο φιλικά απ' ό,τι πραγματικά είναι.
```

Το καλύτερο είναι να αγνοήσεις το συναίσθημα που μπορεί να προκάλεσε το σχόλιό τους και απλώς να απαντήσεις στην ερώτηση.

Αυτά είναι μόνο δύο παραδείγματα που δείχνουν πώς το φαινομενικό πνεύμα του καθοδηγούμενου δεν πρέπει να επηρεάζει τη στάση του μέντορα απέναντί τους.

## Το πνεύμα του μέντορα

Το πνεύμα του μέντορα μπορεί να βασίζεται είτε στην υπερηφάνεια είτε στην ταπεινότητα.
Ένας μέντορας μπορεί να νιώθει ότι _δικαιούται_ να καθοδηγήσει επειδή είναι έξυπνος ή/και έχει ένα ορισμένο επίπεδο εμπειρίας.
Μπορεί να νιώθει ότι πρέπει να καθοδηγήσει επειδή ξέρει καλύτερα από τους άλλους.
Ένας μέντορας του οποίου το πνεύμα βασίζεται στην υπερηφάνεια μπορεί ακόμα να προσεγγίσει τον καθοδηγούμενο με υπομονή και ευγενική καθοδήγηση,
ακόμα κι αν αυτό γίνεται περισσότερο από μεγαλοψυχία παρά από ενσυναίσθηση.

Ή ένας μέντορας μπορεί να έχει το πνεύμα της ταπεινότητας.
Μπορεί να έχει πλήρη επίγνωση των προκλήσεων που αντιμετώπισε μαθαίνοντας να προγραμματίζει.
Μπορεί να ξέρει ότι δεν έχει όλες τις απαντήσεις, αλλά ξέρει _μερικές_, και είναι πρόθυμος να μοιραστεί τις γνώσεις που απέκτησε με κόπο.
Ένας μέντορας του οποίου το πνεύμα βασίζεται στην ταπεινότητα παραμένει άνθρωπος και μπορεί να μπει στον πειρασμό να απαντήσει σε μια δύσκολη συνεδρία καθοδήγησης με
απότομο ή εριστικό τρόπο.
Ακόμα και ένα άτομο με τις καλύτερες προθέσεις χρειάζεται να είναι σε επιφυλακή όταν έχει μια κακή μέρα.

Υπάρχει και ένα τρίτο πνεύμα, που είναι παραλλαγή του πνεύματος της υπερηφάνειας, και αυτό είναι το πνεύμα της ανασφάλειας.
Ένας μέντορας μπορεί να νιώθει ανασφάλεια για τη φήμη του και να αναζητά επιβεβαίωση από τους καθοδηγούμενους ως τρόπο αντιστάθμισης.
Μπορεί να κατακλύσει τον καθοδηγούμενο με τεράστιο όγκο δεδομένων και αναφορών για να δείξει πόσο καλά ενημερωμένος είναι.
Ο καθοδηγούμενος μπορεί να αποκομίσει χρήσιμες πληροφορίες από έναν τέτοιο καταιγισμό δεδομένων, αλλά αυτός είναι ο δευτερεύων στόχος του ανασφαλούς μέντορα.
Ο κύριος στόχος είναι να δείξει πόσο γνώστης είναι ο μέντορας.
Αν και έχει διαφορετικό κίνητρο, ο ανασφαλής μέντορας μπορεί ακόμα να πετύχει τους στόχους της νοοτροπίας του Exercism,
στον βαθμό που δε χάνει τον καθοδηγούμενο μέσα στις λεπτομέρειες.

## Το πνεύμα της αλήθειας

Η πραγματολογική ορθότητα είναι σίγουρα σημαντική και έχει τη θέση της.
Για παράδειγμα, είναι σημαντικό να μη χρησιμοποιούνται αυτοκρατορικές μονάδες μέτρησης εκεί όπου αναμένονται μετρικές μονάδες μέτρησης.
Διαφορετικά, [ένα Mars Climate Orbiter των 327 εκατομμυρίων δολαρίων μπορεί να συντριβεί][crash].
Σίγουρα, από κάποιον που χρησιμοποιεί μια γλώσσα επαγγελματικά αναμένεται να τηρεί την ορθότητα ως βασική απαίτηση.

Για κάποιον όμως που _μαθαίνει_ μια γλώσσα, οι απαιτήσεις είναι λίγο διαφορετικές.
Καταρχάς, δε θέλουμε να αποθαρρύνουμε το άτομο από το να συνεχίσει να μαθαίνει τη γλώσσα.
Για μερικούς μέντορες, ειδικά για εκείνους με πνεύμα υπερηφάνειας, μπορεί να υπάρχει ένα αίσθημα κατορθώματος στο να κάνουν κάποιον να συνειδητοποιήσει
ότι μπορεί να μην είναι κατάλληλος για μια συγκεκριμένη γλώσσα, ή ότι αυτό δεν είναι το σωστό στάδιο για να μάθει αυτή τη γλώσσα.
Αν και αυτό μπορεί να είναι ένα αποδεκτό αποτέλεσμα σε ορισμένα εργασιακά περιβάλλοντα, δεν είναι ένα αποτέλεσμα που εμπίπτει στη νοοτροπία του Exercism.

```exercism/note
Μια εξαίρεση σε αυτό αφορά κάποιον που μαθαίνει την πρώτη του γλώσσα προγραμματισμού.
Το Exercism προορίζεται για κάποιον που ξέρει ήδη να προγραμματίζει και θέλει να μάθει άλλη γλώσσα ή να βελτιώσει τις υπάρχουσες δεξιότητές του.
Η επερχόμενη πλατφόρμα Learn to Code θα απευθύνεται σε ανθρώπους που μόλις μαθαίνουν να προγραμματίζουν.
```

Συχνά, κάποιος που ζητά καθοδήγηση έχει μελετήσει μια γλώσσα προγραμματισμού για μερικές εβδομάδες ή μήνες και επιδιώκει να βελτιωθεί στα βασικά που έχει μάθει.
Αυτό το άτομο μπορεί να έχει ή να μην έχει εμπειρία με άλλη γλώσσα.
Αν αυτή είναι η πρώτη του γλώσσα, αλλά έχει κατακτήσει βασικές λέξεις-κλειδιά και έννοιες, τότε έχει καλές πιθανότητες να ωφεληθεί από την καθοδήγηση.
Μπορεί να χρειάζεται λίγη περισσότερη υπομονή και εξήγηση, κάτι που ο μέντορας μπορεί να μην είχε συνειδητοποιήσει όταν πρωτοαποδέχτηκε το αίτημα καθοδήγησης.
Ωστόσο, μόλις δεσμευτεί στην επαφή, η νοοτροπία του Exercism είναι είτε να είναι όσο πιο υποστηρικτικός και ενθαρρυντικός γίνεται, ακόμα κι αν αυτό απαιτεί
λίγη επιπλέον προσπάθεια, είτε να προτείνει ευγενικά να λήξει η συνεδρία ώστε ο καθοδηγούμενος να μπορέσει να υποβάλει ξανά αίτημα για άλλον μέντορα.

Φυσικά, οι καθοδηγούμενοι μπορεί να αποφασίσουν μόνοι τους να μη συνεχίσουν να ασχολούνται με μια γλώσσα.
Οι περισσότεροι πιθανότατα δε θα μας το πουν, αλλά απλώς θα σταματήσουν να λύνουν ασκήσεις για αυτή τη γλώσσα.
Κατά τη διάρκεια όμως μιας συνεδρίας καθοδήγησης, θα πρέπει να είμαστε πιστά υποστηρικτικοί και ενθαρρυντικοί.
Αλλά υπάρχουν διαφορετικοί τρόποι να το κάνουμε αυτό.
Ένας τρόπος που δε θέλουμε να ακολουθήσουμε είναι η [τοξική θετικότητα][toxic-positivity].
Για παράδειγμα, είναι λιγότερο βοηθητικό, και μπορεί να κάνει κάποιον να νιώσει "κατώτερος", αν επιμένουμε ενθαρρυντικά "Ξέρω ότι μπορείς να το καταλάβεις"
όταν δυσκολεύεται να καταλάβει κάτι.
Μπορεί να είναι πιο βοηθητικό να συνεχίσεις δοκιμάζοντας διαφορετικές εξηγήσεις και προσφέροντας άλλα παραδείγματα, παρά να
τον σπρώξεις απλώς με ενθάρρυνση που μπορεί να ακούγεται στα αυτιά του σαν "Έλα! Ακόμα δεν το έπιασες;"

Η λύση στην οποία φτάνει ένας καθοδηγούμενος, ακόμα και μετά από αρκετές επαναλήψεις με έναν μέντορα, μπορεί να μην είναι η πιο αποδοτική,
ή μπορεί να μη συμμορφώνεται _απόλυτα_ με τα πρότυπα προγραμματισμού.
Το να σπρώχνεις τον καθοδηγούμενο προς μια τέλεια λύση είναι παράδειγμα της απόλυτης πραγματολογικής ορθότητας που δεν είναι στο πνεύμα του Exercism.
Η λύση μπορεί να είναι [αρκετά καλή][good-enough], οπότε η τελειοποίηση της τεχνικής μπορεί να αφεθεί για άλλη συνεδρία καθοδήγησης.

## Το πνεύμα της υποχρέωσης

Ένας μέντορας μπορεί να μην είναι σίγουρος για τις υποχρεώσεις του.
Οι υποχρεώσεις είναι λίγες και απλές: να είσαι βοηθητικός και ενθαρρυντικός.
Αν κάποια στιγμή ο μέντορας νιώσει ότι δεν μπορεί να είναι τίποτα από τα δύο, τότε ίσως είναι καλύτερο να προτείνει ευγενικά να λήξει η συνεδρία,
ώστε ο καθοδηγούμενος να μπορέσει να υποβάλει ξανά αίτημα για άλλον μέντορα.
Μπορεί να είναι καλύτερο για τον μέντορα να καλέσει τον καθοδηγούμενο να τερματίσει τη συζήτηση, αλλά αν ο μέντορας νιώσει την ανάγκη να τερματίσει αυτός τη συζήτηση,
θα ήταν ευγενικό να το κάνει με ένα τελευταίο σχόλιο που εξηγεί τον λόγο.
Αν και μπορεί να είναι δελεαστικό να εστιάσεις στα λάθη του καθοδηγούμενου που έκαναν τη συνεδρία μη ικανοποιητική,
θα ήταν περισσότερο στο πνεύμα του Exercism για τον μέντορα να μην εστιάσει την ευθύνη στον καθοδηγούμενο.

## Το πνεύμα της συνεργασίας

Το συνεργατικό πνεύμα του Exercism εκφράζεται καλύτερα όχι απλώς δίνοντας τη (καλύτερη) λύση στην άσκηση,
αλλά περιγράφοντας άλλες προσεγγίσεις που θα μπορούσαν να χρησιμοποιηθούν και αφήνοντας στον καθοδηγούμενο να γράψει την υλοποίηση αυτών των προτάσεων.
Η λύση θα μπορούσε να τεθεί _προαιρετικά_ στη διάθεση του καθοδηγούμενου σε περίπτωση που κολλήσει.
Θα μπορούσε να είναι ένα απόσπασμα παραδείγματος σε μια πτυσσόμενη ενότητα λεπτομερειών, ή θα μπορούσε να είναι ένας σύνδεσμος προς μια δημοσιευμένη λύση.
Θα ήταν επιλογή του καθοδηγούμενου αν θα αναπτύξει την ενότητα ή θα ακολουθήσει τον σύνδεσμο.

Είναι πιθανό ο καθοδηγούμενος να αναγνωρίσει ότι προτιμά μια πρόταση, αλλά να πει ότι θα την κρατήσει στο μυαλό του για το μέλλον.
Ο μέντορας μπορεί να προτείνει να υποβληθεί μια άλλη επανάληψη που βασίζεται στην πρόταση,
αλλά ο καθοδηγούμενος μπορεί να αποφασίσει να τερματίσει τη συζήτηση χωρίς να τροποποιήσει την αρχική του λύση.
Αν και μπορεί να είναι λίγο ντροπιαστικό να έχει μια δημοσιευμένη λύση που φέρει ότι καθοδηγήθηκε από εσένα και που εσύ πιστεύεις ότι θα μπορούσε να είναι καλύτερη,
είναι στο πνεύμα της συνεργασίας να μην πιέσεις τον καθοδηγούμενο να υλοποιήσει την πρόταση αν φαίνεται απρόθυμος.

Ένας άλλος τρόπος με τον οποίο λειτουργεί το συνεργατικό πνεύμα είναι ο μέντορας να μαθαίνει από τον καθοδηγούμενο.
Κατά τη διάρκεια της συνεδρίας ο καθοδηγούμενος μπορεί να αναφέρει κάτι που ο μέντορας δεν ξέρει.
Δεν αναμένεται από έναν μέντορα να παρουσιάσει μια πρόσοψη "παντογνώστη".
Είναι απολύτως εντάξει για έναν μέντορα να εκφράσει ότι δεν ήξερε ή δεν είχε σκεφτεί κάτι που αναφέρει ο καθοδηγούμενος.
Το να αφήσεις τον καθοδηγούμενο να μάθει ότι του δίδαξες κάτι μπορεί να είναι μία από τις μεγαλύτερες ώθησεις που μπορείς να του δώσεις.
Είναι μέρος της συνεργατικής διαδικασίας μάθησης.
