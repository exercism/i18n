# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσεις να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που αφιερώνεις στο μαγείρεμα της λαζάνιας.

## 1. Αποθήκευσε τον αναμενόμενο χρόνο ψησίματος σε μια σταθερά

Όρισε τη σταθερά `expected_bake_time` που επιστρέφει πόσα λεπτά πρέπει να ψηθεί η λαζάνια στον φούρνο.

Σύμφωνα με το βιβλίο μαγειρικής, η λαζάνια πρέπει να μείνει στον φούρνο συνολικά 60 λεπτά.

```julia-repl
julia> expected_bake_time
60
```

## 2. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparation_time` που παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά σου πήρε η προετοιμασία της λαζάνιας, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```julia-repl
julia> preparation_time(4)
8
```

## 3. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Όρισε τη συνάρτηση `remaining_time` που παίρνει ως παράμετρο τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνει η λαζάνια στον φούρνο.

```julia-repl
julia> remaining_time(50)
10
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη συνάρτηση `total_working_time` που παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο.

Η συνάρτηση θα πρέπει να επιστρέφει πόσα λεπτά έχεις εργαστεί συνολικά για το μαγείρεμα της λαζάνιας, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο τη δεδομένη στιγμή.

```julia-repl
julia> total_working_time(3, 20)
26
```
