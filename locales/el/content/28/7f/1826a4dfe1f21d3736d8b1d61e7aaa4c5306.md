# Σχετικά

Στην Kotlin, οι Boolean αναπαρίστανται από τον τύπο `Boolean`, και οι τιμές τους μπορούν να είναι είτε `true` είτε `false`.

Η Kotlin υποστηρίζει τρεις ενσωματωμένους [τελεστές Boolean][reference]: τον `!` (άρνηση, γνωστή και ως NOT), τον `&&` (οκνηρή σύζευξη, γνωστή και ως AND) και τον `||` (οκνηρή διάζευξη, γνωστή και ως OR). Οι τελεστές `&&` και `||` χρησιμοποιούν _αξιολόγηση βραχυκυκλώματος_, που σημαίνει ότι η δεξιά πλευρά του τελεστή αξιολογείται μόνο όταν χρειάζεται.

```kotlin
true || false // => true
true && false // => false
```

Καθένας από τους τρεις τελεστές Boolean έχει διαφορετική [_προτεραιότητα τελεστών_][precedence]. Ως συνέπεια, αξιολογούνται με αυτή τη σειρά: πρώτα ο `!`, έπειτα ο `&&` και τέλος ο `||`. Αν θέλεις να "ξεφύγεις" από αυτούς τους κανόνες, μπορείς να περικλείσεις μια έκφραση Boolean σε παρενθέσεις (`()`), καθώς οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
