# Υποδείξεις

## Γενικά

-   Ένα ακέραιο λεκτικό μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

-   Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς παραμέτρους.

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

-   Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
-   Μπορείς να χρησιμοποιήσεις το στοιχείο που όρισες προηγουμένως και να αναφερθείς σε αυτό με το όνομά του.
-   Η τελευταία έκφραση σε μια συνάρτηση [επιστρέφεται αυτόματα][return-values] από τη συνάρτηση· δεν χρειάζεται να δηλώσεις ρητά ποια τιμή θα επιστρέψεις.
-   Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

-   Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
-   Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

-   Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
-   Μπορείς να [καλέσεις][functions] μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
-   Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.

[functions]: https://doc.rust-lang.org/book/ch03-03-how-functions-work.html
[return-values]: https://doc.rust-lang.org/book/ch03-03-how-functions-work.html#functions-with-return-values
[operators]: https://doc.rust-lang.org/book/appendix-02-operators.html
