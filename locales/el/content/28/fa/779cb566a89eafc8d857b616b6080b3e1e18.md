# Εισαγωγή

Στη Ruby, οι **πίνακες** είναι διατεταγμένες συλλογές οποιουδήποτε αντικειμένου, στις οποίες οι θέσεις είναι ακέραιοι αριθμοί.
Η αρίθμηση των θέσεων ενός πίνακα ξεκινά από το `0`.
Μια αρνητική θέση θεωρείται ότι μετράει από το τέλος του πίνακα, δηλαδή μια θέση `-1` δείχνει το τελευταίο στοιχείο του πίνακα, το `-2` το προτελευταίο στοιχείο και ούτω καθεξής.
Οι πίνακες της Ruby ενσωματώνουν το [module Enumerable][enumerable-module], που προσθέτει αρκετές μεθόδους διάσχισης και αναζήτησης, καθώς και τη δυνατότητα ταξινόμησης.

## Δημιουργία πίνακα

- Ένας πίνακας στη Ruby μπορεί να περιέχει αντικείμενα διαφορετικών τύπων.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Ανάθεση στοιχείων

Μπορείς να προσπελάσεις ή να αλλάξεις στοιχεία χρησιμοποιώντας θέσεις.
Μπορείς να προσπελάσεις υποπίνακες ορίζοντας μια αρχική θέση και ένα μέγεθος.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Οι αρνητικές θέσεις μετρούν προς τα πίσω από το τέλος του πίνακα.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Αναφορά στοιχείων

- Μπορείς να ανακτήσεις τα στοιχεία ενός πίνακα με τη μέθοδο #[].
- Επιστρέφει το στοιχείο στη θέση που δίνεις, ή έναν υποπίνακα που ξεκινά από τη θέση εκκίνησης και συνεχίζει για length στοιχεία.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Οι αρνητικές θέσεις μετρούν προς τα πίσω από το τέλος του πίνακα (το -1 είναι το τελευταίο στοιχείο)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Λήψη πληροφοριών για έναν πίνακα

Οι πίνακες παρακολουθούν συνεχώς το δικό τους μήκος.
Για να ρωτήσεις έναν πίνακα πόσα στοιχεία περιέχει, χρησιμοποίησε τα length, count ή size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Προσθήκη στοιχείων σε πίνακες

Μπορείς να προσθέσεις στοιχεία στο τέλος ενός πίνακα χρησιμοποιώντας είτε το `push` είτε το `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Αφαίρεση στοιχείων από έναν πίνακα

Η μέθοδος pop αφαιρεί το τελευταίο στοιχείο ενός πίνακα και το επιστρέφει:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
