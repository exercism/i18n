# Δοκιμές

## Ρύθμιση

Ακολούθησε τις [οδηγίες ρύθμισης για JavaScript][docs-exercism-javascript] για να εγκαταστήσεις τις απαραίτητες εξαρτήσεις.

## Απαιτήσεις

Εγκατέστησε τις εξαρτήσεις της άσκησης:

```shell
corepack pnpm install
```

Αν το `corepack` παραπονιέται ότι δεν είναι ενεργοποιημένο, μπορείς να το ενεργοποιήσεις τρέχοντας:

```bash
corepack enable pnpm
```

## Πώς να περάσεις τη σουίτα δοκιμών

Όλες οι ασκήσεις συνοδεύονται από μια σουίτα δοκιμών που σε βοηθά να επαληθεύσεις τη λύση σου πριν την υποβάλεις.
Μπορείς να εκτελέσεις αυτές τις δοκιμές ανοίγοντας μια γραμμή εντολών στον κατάλογο της άσκησης και στη συνέχεια τρέχοντας:

```bash
corepack pnpm test
```

Σε κάποιες σουίτες δοκιμών, όλες οι δοκιμές εκτός από την πρώτη έχουν παραλειφθεί.

Μόλις περάσεις μια δοκιμή, μπορείς να ενεργοποιήσεις την επόμενη αλλάζοντας το `xtest` σε `test`.

## Γράφοντας προσαρμοσμένες δοκιμές

Αν θέλεις να γράψεις επιπλέον, προσαρμοσμένες δοκιμές, δημιούργησε ένα νέο αρχείο `custom.spec.js` και υπόβαλέ το μαζί με τη λύση σου και το νέο αρχείο:

```shell
exercism submit numbers.js custom.spec.js
```
