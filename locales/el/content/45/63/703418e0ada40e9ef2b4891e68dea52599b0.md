# Σχετικά

Στην Elixir, για να διαλέξεις ένα τυχαίο στοιχείο από μια απαριθμήσιμη δομή δεδομένων (π.χ. λίστα, εύρος), χρησιμοποιούμε το [`Enum.random/1`][enum-random]. Αυτή η συνάρτηση διαλέγει ένα μόνο στοιχείο, με κάθε στοιχείο να έχει την ίδια πιθανότητα να επιλεγεί. Η επιλογή μιας μόνο τυχαίας τιμής από ένα εύρος εκτελείται σε σταθερό χρόνο, χωρίς να διατρέχει ολόκληρο το εύρος.

## Τυχαίοι ακέραιοι και γράμματα

- Επιλογή τυχαίου ακέραιου
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- Επιλογή τυχαίου γράμματος ως συμβολοσειρά
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- Επιλογή τυχαίου γράμματος ως charlist
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

Για να διαλέξεις περισσότερα από ένα στοιχεία από μια απαριθμήσιμη δομή δεδομένων, χρησιμοποίησε το [`Enum.take_random/2`][enum-take-random]. Για να ταξινομήσεις μια απαριθμήσιμη δομή δεδομένων σε τυχαία σειρά, χρησιμοποίησε το [`Enum.shuffle/1`][enum-shuffle].

## Τυχαίοι αριθμοί κινητής υποδιαστολής

Η Elixir δεν έχει δικές της συναρτήσεις για την επιλογή τυχαίου αριθμού κινητής υποδιαστολής. Για να το κάνουμε αυτό, πρέπει να χρησιμοποιήσουμε το module [`rand`][erl-rand] της Erlang, το οποίο τυχαίνει να είναι και αυτό που χρησιμοποιεί εσωτερικά το `Enum.random`.

- Επιλογή τυχαίου αριθμού κινητής υποδιαστολής (μεγαλύτερου ή ίσου με 0.0 και μικρότερου από 1.0):

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- Επιλογή τυχαίου αριθμού κινητής υποδιαστολής (μεγαλύτερου ή ίσου με το `a` και μικρότερου από το `b`):
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## Κανονική κατανομή

Όλες οι συναρτήσεις που αναφέρθηκαν παραπάνω επιλέγουν μια τυχαία τιμή με κάθε πιθανή τιμή να έχει την ίδια πιθανότητα να επιλεγεί. Αυτό ονομάζεται _ομοιόμορφη κατανομή_. Το module `rand` προσφέρει επίσης τις συναρτήσεις [`normal/0`][erl-rand-normal-0] και [`normal/2`][erl-rand-normal-2], που επιλέγουν έναν τυχαίο αριθμό κινητής υποδιαστολής με [κανονική κατανομή][normal-distribution].

## Σπόρος

Είναι σημαντικό να καταλάβεις ότι οι "τυχαίες" τιμές παράγονται από μια [_ψευδο_-τυχαία γεννήτρια αριθμών][prng]. Μια PRNG είναι ένας αλγόριθμος που, δεδομένης μιας αρχικής τιμής που ονομάζεται _σπόρος_, παράγει μια ακολουθία αριθμών που φαίνεται τυχαία, αλλά δεν είναι καθόλου τυχαία.

Αυτό το γεγονός μπορεί να φανεί χρήσιμο για debugging. Μπορείς να αναγκάσεις την ψευδοτυχαία γεννήτρια αριθμών της Erlang (και επομένως της Elixir) να παράγει τις ίδιες τιμές της ακολουθίας, επαναφέροντας τον σπόρο της με το [`:rand.seed/2`][rand-seed-2]. Το πρώτο όρισμα είναι ένας συγκεκριμένος αλγόριθμος PRNG και το δεύτερο μια πλειάδα τριών ακεραίων, ο σπόρος.

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## Κρυπτογραφία

Οι τυχαίες τιμές που επιστρέφουν το `Enum.random` και το module `rand` της Erlang δεν είναι [κρυπτογραφικά ασφαλείς][cryptographically-secure-rng]. Μην τις χρησιμοποιείς για να παράγεις κρυπτογραφικά κλειδιά, κωδικούς πρόσβασης ή nonces. Για αυτή την περίπτωση χρήσης, υπάρχει το [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes] της Erlang.
