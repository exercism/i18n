# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες, καθεμία από τις οποίες παίρνει μια γραμμή καταγραφής και σου ζητά να κάνεις κάτι με αυτήν.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `message` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

Οποιοδήποτε κενό διάστημα στην αρχή ή στο τέλος θα πρέπει να αφαιρείται:

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `log-level` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο θα πρέπει να επιστρέφεται με πεζά γράμματα:

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `reformat` που αναδιαμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής μέσα σε παρενθέσεις:

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
