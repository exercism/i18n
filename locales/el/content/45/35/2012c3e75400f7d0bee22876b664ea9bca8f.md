# Δήλωση Τύπου

Η PHP είναι μια _δυναμικά τυποποιημένη_ γλώσσα, που σημαίνει ότι μια μεταβλητή μπορεί να περιέχει οποιονδήποτε τύπο πληροφορίας.
Η PHP επιτρέπει ωστόσο την _προαιρετική_ δήλωση ισχυρού τύπου για ιδιότητες κλάσης, ορίσματα συνάρτησης και τιμές επιστροφής συνάρτησης.
Οι δηλώσεις ισχυρού τύπου στην PHP παρέχουν ισχυρισμούς τύπου κατά τον χρόνο εκτέλεσης, ωστόσο η PHP θα προσπαθήσει να εξαναγκάσει τους βαθμωτούς τύπους ώστε να ταιριάζουν με τη δήλωση, αν αυτό είναι δυνατό.
Η συμπεριφορά εξαναγκασμού μπορεί να απενεργοποιηθεί με τη δήλωση `strict_types` στην αρχή του αρχείου.

```php
<?php
declare(strict_types=1);
```

Επιπλέον, οι συναρτήσεις μπορούν να επιστρέφουν τον τύπο επιστροφής `void` για να δηλώσουν ότι δεν πρόκειται να επιστραφεί καμία τιμή από τη συνάρτηση.

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## Ενώσεις Τύπων

Αν ένα όρισμα συνάρτησης, μια τιμή επιστροφής ή μια ιδιότητα κλάσης μπορεί να είναι περισσότερων από έναν τύπων, μπορεί να δηλωθεί ένωση τύπων.

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Μεικτοί Τύποι

Όταν δουλεύουμε με κώδικα, μπορεί να μην μπορούμε να προσδιορίσουμε έναν τύπο.
Ξεκινώντας από την PHP 8.0, παρέχεται ένας τύπος διαφυγής με το όνομα `mixed`.
Ο `mixed` είναι ισοδύναμος με μια ένωση τύπων `object|resource|array|string|float|int|bool|null`.
