# Σχετικά

Ένα [`Dict`][dict] στην Elm είναι ένα αμετάβλητο λεξικό από μηδέν ή περισσότερα ζεύγη κλειδιού-τιμής.

Τα dict χειρίζονται με συναρτήσεις και τελεστές που ορίζονται στο [`Dict` module][dict-module].

Οι σχολιασμοί τύπων για τα dict γράφονται ως εξής:

```elm
Dict String (List Int) --> a dict with String keys and List Int values
Dict Int String --> a dict with Int keys and String values
```

Τα dict μπορούν να δημιουργηθούν ως εξής:

```elm
empty : Dict Int String
empty = Dict.empty

singleValue = Dict.singleton 5 "Value for key 5" --> Dict Int String

twoValues = Dict.fromList [ ( "Alice", 0 ), ( "Bob", 1 ) ] --> Dict String Int
```

Μπορείς να ανακτήσεις στοιχεία με το `get`.
Επειδή ένα κλειδί μπορεί να υπάρχει ή να μην υπάρχει στο dict, το αποτέλεσμα θα είναι τυλιγμένο σε ένα `Maybe`.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
keyExists = Dict.get 0 alice --> Just "Alice"
keyNotPresent = Dict.get 1 alice --> Nothing
```

Μπορείς να προσθέσεις στοιχεία με το `insert`.
Τα στοιχεία για κλειδιά που υπάρχουν ήδη στο dict αντικαθίστανται.

```elm
alice = Dict.fromList [ ( "Alice", 0 ) ]
aliceAndBob = Dict.insert "Bob" 1 alice  --> Dict.fromList [ ( "Alice", 0 ), ( "Bob", 1 ) ]
aliceAndAlice = Dict.insert "Alice" 1 alice  --> Dict.fromList [ ( "Alice", 1 ) ]
```

Μπορείς να ενημερώσεις στοιχεία με το `update`.
Αν το κλειδί δεν υπάρχει, η συνάρτηση ενημέρωσης θα κληθεί με `Nothing`.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
aliceUpperCase = Dict.update 0 (Maybe.map String.toUpper) alice --> Dict.fromList [ ( 0, "ALICE" ) ]
aliceNoCase = Dict.update 0 (\_ -> Nothing) alice --> Dict.empty
bobUpperCase = Dict.update 1 (\_ -> Just "BOB") alice --> Dict.fromList [ ( 0, "Alice" ), ( 1, "BOB" ) ]
bobNoCase = Dict.update 1 (\_ -> Nothing) alice --> Dict.fromList [ ( 0, "Alice" ) ]
```

Μπορείς να αφαιρέσεις στοιχεία με το `remove`.
Αν το κλειδί δεν υπάρχει, δεν γίνεται καμία αλλαγή.

```elm
alice = Dict.fromList [ ( 0, "Alice" ) ]
stillAlice = Dict.remove 1 --> ( 0, "Alice" )
empty = Dict.remove 0 alice --> Dict.empty
```

Μια λίστα με ζεύγη κλειδιού-τιμής μπορεί να μετατραπεί σε dict με το `fromList`.

```elm
alice = Dict.fromList [ ( 0, "Bob" ), ( 0, "Alice" ) ]
--> True Dict.fromList [ ( 0, "Alice" ) ]
```

Μπορείς να μετατρέψεις τα στοιχεία σε λίστα με το `toList`.
Η λίστα είναι ταξινομημένη κατά κλειδιά.

```elm
aliceAndBob = Dict.fromList [ ( 1, "Alice" ), ( 0, "Bob" ) ]
bobAndAlice = Dict.toList aliceAndBob
--> [ ( 0, "Bob" ), ( 1, "Alice" ) ]
```

Μπορείς να αφαιρέσεις πολλά στοιχεία με το `filter`.

```elm
aliceAndBob = Dict.fromList [ ( "Alice", 1 ), ( "Bob", 0 ) ]
bob = Dict.filter (\name count -> name == "Bob") aliceAndBob --> Dict.fromList [ ( "Bob", 0 ) ]
```

Μπορείς να μετασχηματίσεις στοιχεία με το `map`.

```elm
alice = Dict.fromList [ ( "Alice", 0 ) ]
newAlice = Dict.map (\player count -> count + 1) alice --> Dict.fromList [ ( "Alice", 1 ) ]
```

Τα dict μπορούν να συνδυαστούν ή να μετασχηματιστούν με το `merge`.

```elm
aliceAndBob = Dict.fromList [ ( "Alice", 1 ), ( "Bob", 1 ) ]
bobAndCedd = Dict.fromList [ ( "Bob", 1 ), ( "Cedd", 1 ) ]
firstDictCountsDouble = Dict.merge
        -- when only in aliceAndBob
        (\name count mergedCounts -> Dict.insert name (2 * count) mergedCounts)
        -- when in aliceAndBob and bobAndCedd
        (\name aliceAndBobCount bobAndCeddCount mergedCounts -> Dict.insert name (2 * aliceAndBobCount + bobAndCeddCount) mergedCounts)
        -- when only in bobAndCedd
        (\name count mergedCounts -> Dict.insert name count mergedCounts)
        -- the two dicts to merge
        aliceAndBob
        bobAndCedd
        -- the initial state of the merge
        Dict.empty
--> Dict.fromList [ ( "Alice", 2 ), ( "Bob", 3 ), ( "Cedd", 1 ) ]
```

Οποιαδήποτε συνάρτηση ή τελεστής φαίνεται να τροποποιεί ένα dict (για παράδειγμα προσθέτοντας ένα στοιχείο), στην πραγματικότητα επιστρέφει ένα νέο dict.
Η απόδοση συνήθως δεν είναι πρόβλημα, καθώς η υλοποίηση αποτρέπει περιττές δεσμεύσεις μνήμης και αντιγραφές.

Στην Elm, γενικά είναι καλύτερα να χρησιμοποιείς αφαιρέσεις υψηλότερου επιπέδου, όπως τις `Dict.map`, `Dict.filter` και `Dict.merge`, αντί για αφαιρέσεις χαμηλότερου επιπέδου όπως τις `Dict.get` και `Dict.remove`, αν και φυσικά εξαρτάται από τα συμφραζόμενα.
