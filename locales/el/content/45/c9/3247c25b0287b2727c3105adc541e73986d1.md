# Εισαγωγή

## Πακέτα

Στη Go μια εφαρμογή οργανώνεται σε πακέτα.
Ένα πακέτο είναι μια συλλογή από αρχεία πηγαίου κώδικα που βρίσκονται στον ίδιο φάκελο.
Όλα τα αρχεία πηγαίου κώδικα σε έναν φάκελο πρέπει να έχουν το ίδιο όνομα πακέτου στην κορυφή του αρχείου.
Κατά σύμβαση, τα πακέτα ονομάζονται όπως ο φάκελος στον οποίο βρίσκονται.

```go
package greeting
```

Η Go παρέχει μια εκτενή πρότυπη βιβλιοθήκη πακέτων που μπορείς να χρησιμοποιήσεις στο πρόγραμμά σου με τη λέξη-κλειδί `import`.
Τα πακέτα της πρότυπης βιβλιοθήκης εισάγονται με το όνομά τους.

```go
package greeting

import "fmt"
```

Στη συνέχεια, αναφέρεσαι σε ένα εισαγόμενο πακέτο με το όνομά του:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Η Go καθορίζει αν ένα στοιχείο μπορεί να κληθεί από κώδικα σε άλλα πακέτα με βάση τον τρόπο που δηλώνεται.
Για να κάνεις μια συνάρτηση, έναν τύπο, μια μεταβλητή, μια σταθερά ή ένα πεδίο δομής ορατά από άλλα πακέτα (γνωστό ως _εξαγόμενο_), το όνομα πρέπει να ξεκινά με κεφαλαίο γράμμα.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## Μορφοποίηση συμβολοσειρών

Η Go παρέχει ένα ενσωματωμένο πακέτο που ονομάζεται `fmt` (πακέτο μορφοποίησης), το οποίο προσφέρει μια ποικιλία συναρτήσεων για να χειρίζεσαι τη μορφή της εισόδου και της εξόδου.
Η πιο συχνά χρησιμοποιούμενη συνάρτηση είναι η `Sprintf`, η οποία χρησιμοποιεί ρήματα όπως `%s` για να ενσωματώσει τιμές σε μια συμβολοσειρά και επιστρέφει αυτήν τη συμβολοσειρά.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Στη Go, οι τιμές κινητής υποδιαστολής μορφοποιούνται βολικά με τα ρήματα της Sprintf: `%g` (συμπαγής αναπαράσταση), `%e` (εκθέτης) ή `%f` (χωρίς εκθέτη).
Και τα τρία ρήματα επιτρέπουν τον έλεγχο του πλάτους και της αριθμητικής θέσης του πεδίου.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Μπορείς να βρεις μια πλήρη λίστα με τα διαθέσιμα ρήματα στην [τεκμηρίωση του πακέτου μορφοποίησης][fmt-docs].

Το `fmt` περιέχει και άλλες συναρτήσεις για εργασία με συμβολοσειρές, όπως η `Println`, που απλώς εκτυπώνει στην κονσόλα τα ορίσματα που δέχεται, και η `Printf`, που μορφοποιεί την είσοδο με τον ίδιο τρόπο όπως η `Sprintf` πριν την εκτυπώσει.

[fmt-docs]: https://pkg.go.dev/fmt
