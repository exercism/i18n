# Οδηγίες

Δεδομένων δύο λιστών, προσδιόρισε αν η πρώτη λίστα περιέχεται στη δεύτερη λίστα, αν η δεύτερη λίστα περιέχεται στην πρώτη λίστα, αν και οι δύο λίστες περιέχονται η μία στην άλλη ή αν τίποτα από αυτά δεν ισχύει.

Συγκεκριμένα, μια λίστα A είναι υπολίστα της λίστας B αν, αφαιρώντας 0 ή περισσότερα στοιχεία από την αρχή της B και 0 ή περισσότερα στοιχεία από το τέλος της B, προκύπτει μια λίστα που είναι απολύτως ίση με την A.

Παραδείγματα:

 * A = [1, 2, 3], B = [1, 2, 3, 4, 5], η A είναι υπολίστα της B
 * A = [3, 4, 5], B = [1, 2, 3, 4, 5], η A είναι υπολίστα της B
 * A = [3, 4], B = [1, 2, 3, 4, 5], η A είναι υπολίστα της B
 * A = [1, 2, 3], B = [1, 2, 3], η A είναι ίση με τη B
 * A = [1, 2, 3, 4, 5], B = [2, 3, 4], η A είναι υπερλίστα της B
 * A = [1, 2, 4], B = [1, 2, 3, 4, 5], η A δεν είναι ούτε υπερλίστα ούτε υπολίστα ούτε ίση με τη B
