# Εισαγωγή

Οι πλειάδες είναι ένας ελαφρύς τρόπος να ομαδοποιήσεις ένα σταθερό σύνολο αυθαίρετων τύπων δεδομένων μαζί.
Οι πλειάδες μπορούν να έχουν αυθαίρετο αριθμό στοιχείων.
Μπορείς να αποκτήσεις πρόσβαση στα στοιχεία με αποδόμηση.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
