# Οδηγίες

Η εταιρεία στην οποία εργάζεσαι θέλει να μειώσει το αποτύπωμα άνθρακα της, γι' αυτό θέλει να γράψεις ένα πρόγραμμα που να υπολογίζει την κατανάλωση ισχύος και το κόστος λειτουργίας των ηλεκτρονικών της συσκευών.

## 1. Βρες τις επιπλέον ώρες

Ο εργοδότης σου έχει ένα πρόγραμμα που υπολογίζει τον χρόνο που χρειάζεται για να λειτουργήσουν διάφορες ηλεκτρονικές συσκευές.
Προς το παρόν, ο χρόνος αποθηκεύεται σε ώρες.
Όταν ο εργοδότης σου πρόσθεσε τις ώρες, παρατήρησε ότι η διάρκεια δεν ήταν σωστή.
Θέλει να προσθέσεις 3 επιπλέον ώρες στα δεδομένα χρόνου.
Θα ήθελε επίσης να μάθει πόσες "επιπλέον" ώρες απομένουν αφού μετατρέψεις τα δεδομένα σε "ολόκληρες" ημέρες (μια ημέρα είναι 24 ώρες).
Ο χρόνος προς μετατροπή μπορεί να μην αντιστοιχεί σε ολόκληρες ημέρες.

Υλοποίησε μια συνάρτηση `get_extra_hours()` που δέχεται έναν ακέραιο που περιέχει τον αριθμό των ωρών.
Η συνάρτηση πρέπει να κάνει την κατάλληλη προσαρμογή των "επιπλέον ωρών" και στη συνέχεια να κάνει `return` έναν ακέραιο που αντιπροσωπεύει πόσες ώρες πρέπει να αφαιρεθούν από το σύνολο για να προκύψει ο χρόνος σε "ολόκληρες" ημέρες.

```python
>>> get_extra_hours(25)
4
```

## 2. Βρες την τιμή kW

Ο εργοδότης σου θέλει να μάθει την κατανάλωση ισχύος των διαφόρων ηλεκτρονικών συσκευών σε kW.
Το kW σημαίνει κιλοβάτ, όπου το βατ είναι μονάδα ισχύος.
Το "kilo" στο όνομα της μονάδας είναι πρόθεμα του μετρικού συστήματος που σημαίνει 1000.
Ένα κιλοβάτ == 1000 βατ.

Υλοποίησε μια συνάρτηση `get_kW_value()` που δέχεται έναν ακέραιο που περιέχει τον αριθμό των βατ.
Η συνάρτηση πρέπει στη συνέχεια να κάνει `return` τα βατ ως κιλοβάτ, στρογγυλοποιημένα σε 1 δεκαδικό ψηφίο.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Βρες την τιμή kWh

Για να μπορεί να υπολογίσει το κόστος λειτουργίας των ηλεκτρονικών συσκευών, ο εργοδότης σου χρειάζεται να ξέρει την κατανάλωση ισχύος σε kWh.
Το kWh σημαίνει κιλοβατώρα, όπου η ώρα είναι μονάδα χρόνου.
Μία κιλοβατώρα == 1000 βατ για 1 ώρα.
Μία ώρα αποτελείται από 60 λεπτά και ένα λεπτό αποτελείται από 60 δευτερόλεπτα.
Μία ώρα ισούται με 3600 δευτερόλεπτα.
Για να υπολογίσεις την τιμή kWh, πρέπει να μετατρέψεις τα βατ σε kW και στη συνέχεια να κάνεις ακέραια διαίρεση του αποτελέσματος με το 3600.

Υλοποίησε μια συνάρτηση `get_kWh_value()` που δέχεται έναν ακέραιο που περιέχει τον αριθμό των βατ.
Η συνάρτηση πρέπει στη συνέχεια να κάνει `return` τις κιλοβατώρες ως ακέραιο.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Βρες την απόδοση

Οι ηλεκτρονικές συσκευές δεν είναι 100% αποδοτικές.
Γι' αυτό, ο εργοδότης σου θέλει να υπολογίσεις την _απόδοση_ των ηλεκτρονικών συσκευών.
Για να βρεις την απόδοση, πρέπει να διαιρέσεις τον συντελεστή ισχύος (_ένας δεκαδικός αριθμός μεταξύ 0 και 100_) με το 100.

Υλοποίησε μια συνάρτηση `get_efficiency()` που δέχεται έναν δεκαδικό αριθμό που περιέχει τον συντελεστή ισχύος.
Η συνάρτηση πρέπει στη συνέχεια να κάνει `return` την υπολογισμένη απόδοση ως δεκαδικό αριθμό.

```python
>>> get_efficiency(80)
0.8
```

## 5. Βρες το κόστος

Ο εργοδότης σου θέλει να μάθει το κόστος λειτουργίας των ηλεκτρονικών συσκευών.
Το κόστος λειτουργίας των ηλεκτρονικών συσκευών είναι η ισχύς που χρησιμοποιείται πολλαπλασιασμένη με το κόστος ανά kWh.
Η ισχύς που χρησιμοποιείται είναι η ισχύς που δίνεται διαιρεμένη με την υπολογισμένη απόδοση.

Υλοποίησε μια συνάρτηση `get_cost(<watts>,<power_factor>,<price>)` που δέχεται έναν ακέραιο που περιέχει τον αριθμό των βατ, έναν δεκαδικό αριθμό που έχει τον συντελεστή ισχύος και έναν δεκαδικό αριθμό που περιέχει το κόστος ανά kWh.
Η συνάρτηση πρέπει στη συνέχεια να κάνει `return` το κόστος λειτουργίας των ηλεκτρονικών συσκευών ως δεκαδικό αριθμό.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
