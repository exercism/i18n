# Υποδείξεις

## Γενικά

## 1. Υλοποίησε τη μέθοδο `new()`

- Η μέθοδος `new()` δέχεται τα ορίσματα με τα οποία θέλουμε να δημιουργήσουμε ένα στιγμιότυπο του `User`. Θα πρέπει να επιστρέφει ένα στιγμιότυπο του `User` με το όνομα, την ηλικία και το βάρος που δίνονται.

- Δες την [τεκμηρίωση για τις δομές][structs] για παραδείγματα ορισμού και δημιουργίας στιγμιότυπων δομών.

## 2. Υλοποίησε τις μεθόδους getter

- Οι μέθοδοι `name()`, `age()` και `weight()` είναι getters. Με άλλα λόγια, είναι υπεύθυνες για την επιστροφή του αντίστοιχου πεδίου από ένα στιγμιότυπο δομής.

- Δεν χρειάζεται να χρησιμοποιήσεις εντολή `return` στην Cairo, εκτός αν θέλεις ρητά μια συνάρτηση ή μια μέθοδος να επιστρέψει νωρίς. Διαφορετικά, είναι πιο ιδιωματικό να αξιοποιήσεις μια _έμμεση_ επιστροφή, παραλείποντας το σύμβολο `;` για το αποτέλεσμα που θέλουμε να επιστρέψει μια συνάρτηση ή μια μέθοδος. Δεν είναι _λάθος_ να χρησιμοποιήσεις ρητή επιστροφή, αλλά είναι πιο καθαρό να αξιοποιήσεις τις έμμεσες επιστροφές όπου αυτό είναι εφικτό.

```rust
fn foo() -> i32 {
    1
}
```

- Δες την [τεκμηρίωση για τις μεθόδους][methods] για περισσότερα παραδείγματα ορισμού μεθόδων σε δομές.

## 3. Υλοποίησε τις μεθόδους setter

- Οι μέθοδοι `set_age()` και `set_weight()` είναι setters, υπεύθυνες για την ενημέρωση του αντίστοιχου πεδίου σε ένα στιγμιότυπο δομής με το όρισμα εισόδου.

- Όπως ορίζουν οι υπογραφές αυτών των μεθόδων, οι μέθοδοι setter δεν θα πρέπει να επιστρέφουν τίποτα.

[methods]: https://book.cairo-lang.org/ch05-03-method-syntax.html
