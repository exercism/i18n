# Εύρη

[Τα εύρη][range] αντιπροσωπεύουν ένα διάστημα μεταξύ δύο τιμών.
Οι πιο συνηθισμένοι τύποι που υποστηρίζουν εύρη είναι οι `Int`, `Char` και `String`.
Μπορούν να χρησιμοποιηθούν για πολλά πράγματα, όπως η γρήγορη δημιουργία μιας συλλογής, ο τεμαχισμός συμβολοσειρών, ο έλεγχος του αν μια τιμή βρίσκεται σε ένα εύρος και η επανάληψη.
Δημιουργούνται χρησιμοποιώντας τον τελεστή εύρους `..` ή `...` (συμπεριληπτικό και αποκλειστικό, αντίστοιχα).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Ο λόγος που υπάρχουν δύο τελεστές εύρους είναι για να δημιουργείς εύρη που περιλαμβάνουν ή δεν περιλαμβάνουν την τελική τιμή, κάτι που μπορεί να είναι χρήσιμο όταν, για παράδειγμα, δουλεύεις με θέσεις μηδενικής βάσης.

Τα εύρη μπορούν επίσης να δημιουργηθούν χρησιμοποιώντας τον αρχικοποιητή `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Όταν δημιουργείς ένα εύρος στο Crystal χρησιμοποιώντας τους τελεστές εύρους `..` ή `...` και θέλεις να καλέσεις μια μέθοδο στο εύρος, πρέπει να βάλεις το εύρος σε παρενθέσεις.
Αυτό συμβαίνει γιατί αλλιώς η μέθοδος θα κληθεί στο 2ο όρισμα του τελεστή εύρους.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Λήψη υποσυμβολοσειρών

Όταν θέλεις να τεμαχίσεις μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον τελεστή εύρους για να πάρεις μια υποσυμβολοσειρά.
Δηλαδή, δημιουργώντας ένα εύρος με τη θέση αρχής και τέλους της υποσυμβολοσειράς.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Μπορείς επίσης να χρησιμοποιήσεις αρνητικές θέσεις για να πάρεις την υποσυμβολοσειρά από το τέλος της συμβολοσειράς.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Μέθοδοι των ευρών

Τα εύρη έχουν ένα σύνολο μεθόδων που μπορούν να χρησιμοποιηθούν για να δουλέψεις μαζί τους.
Για παράδειγμα, αυτές οι μέθοδοι μπορούν να χρησιμοποιηθούν για να πάρεις το άθροισμα όλων των τιμών στο εύρος ή να ελέγξεις αν το εύρος περιέχει μια τιμή.

| Μέθοδος                | Περιγραφή                                                             | Παράδειγμα                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Επιστρέφει το άθροισμα όλων των τιμών στο εύρος                          | `(1..5).sum # => 15`            |
| [`size`][size]          | Επιστρέφει το μέγεθος του εύρους                                           | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Επιστρέφει `true` αν το εύρος περιέχει τη δεδομένη τιμή, αλλιώς `false` | `(1..5).includes?(3) # => true` |

## Εύρη χωρίς τέλος και χωρίς αρχή

Ένα εύρος μπορεί να μην έχει τέλος και αρχή.
Το εύρος χωρίς τέλος ή χωρίς αρχή έχει ως τιμή αρχής ή τέλους το `nil`, αλλά το `nil` μπορεί να παραλειφθεί όταν ορίζεις το εύρος.

Η χρήση ευρών χωρίς αρχή και χωρίς τέλος είναι χρήσιμη όταν θέλεις, για παράδειγμα, να τεμαχίσεις μια συμβολοσειρά από την αρχή ή μέχρι το τέλος.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Αν δεν χρησιμοποιηθεί σε μια συλλογή, το εύρος χωρίς τέλος μπορεί να προκαλέσει μια ατελείωτη ακολουθία, αν δεν χρησιμοποιηθεί με προσοχή.
~~~~

## Εύρη χαρακτήρων

Οι χαρακτήρες μπορούν να χρησιμοποιηθούν σε εύρη και σου επιτρέπουν να πάρεις ένα διάστημα χαρακτήρων μεταξύ δύο χαρακτήρων.
Για παράδειγμα, αυτό μπορεί να σου φανεί χρήσιμο όταν θέλεις να πάρεις το αλφάβητο.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Εύρη συμβολοσειρών

Οι συμβολοσειρές μπορούν επίσης να χρησιμοποιηθούν σε εύρη, επιτρέποντάς σου να πάρεις ένα διάστημα συμβολοσειρών μεταξύ δύο συμβολοσειρών.
Αλλά η συμπεριφορά τους είναι ελαφρώς διαφορετική από αυτήν του `Char` όταν χρησιμοποιούνται πολλοί χαρακτήρες σε ένα εύρος συμβολοσειρών.
Η συμπεριφορά τους μπορεί να προκαλέσει σύγχυση όταν κάνεις πιο σύνθετα εύρη συμβολοσειρών, οπότε πρόσεχε.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## Προσαρμοσμένα αντικείμενα σε εύρη

~~~~exercism/advanced
Το Crystal σου επιτρέπει να χρησιμοποιείς προσαρμοσμένα αντικείμενα σε εύρη.
Η προϋπόθεση γι' αυτό είναι το αντικείμενο να υλοποιεί τα εξής:

- να συμπεριλαμβάνει το module `Comparable`
- τη μέθοδο `succ`
- τη μέθοδο `<=>`

Αυτές οι μέθοδοι κάνουν το εύρος να μπορεί να διατρέχει το αντικείμενο και να συγκρίνει τα αντικείμενα μέσα στο εύρος.

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
~~~~
