# Εισαγωγή

Είδαμε στην έννοια `Vectors` ότι ένα διάνυσμα μπορεί να χρησιμοποιηθεί σε μια έκφραση συνθήκης, δίνοντας ένα λογικό διάνυσμα.
Αυτό με τη σειρά του μπορεί να χρησιμοποιηθεί σε συναρτήσεις όπως οι `all()` και `any()`.

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

Η τεχνική είναι πολύ πιο ισχυρή από αυτό.

## Υποσύνολα διανύσματος

Επιλεγμένα στοιχεία ενός διανύσματος μπορούν να εξαχθούν με έναν αριθμό θέσης ή ένα διάνυσμα θέσεων:

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

Εναλλακτικά, χρησιμοποίησε ένα λογικό διάνυσμα για να φιλτράρεις το αρχικό διάνυσμα, επιστρέφοντας ένα υποσύνολο στοιχείων που αντιστοιχούν σε τιμή `TRUE`:

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

Από εκεί, ένα μικρό βήμα είναι η δημιουργία του διανύσματος Boolean (λογική τιμή) με μια έκφραση συνθήκης:

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## Εύρεση θέσεων

Η συνάρτηση `which()` δέχεται ένα όρισμα Boolean και επιστρέφει ένα διάνυσμα θέσεων που δίνουν `TRUE`.

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## Έλεγχος αν υπάρχει ένα στοιχείο

Οι προηγούμενες ενότητες αφορούσαν την εύρεση στοιχείων που ταιριάζουν με κάποιο κριτήριο.

Αν θέλεις απλώς να ξέρεις αν το διάνυσμα περιέχει ένα συγκεκριμένο στοιχείο, χρησιμοποίησε τον τελεστή `%in%`.

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

Αυτό είναι λειτουργικά ισοδύναμο με τον παρακάτω κώδικα, αλλά πολύ πιο βολικό:

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
