# Εισαγωγή

## Τα βασικά

Η [Lua](https://lua.org) είναι μια απλή αλλά ισχυρή, αποδοτική, ελαφριά και ενσωματώσιμη γλώσσα σεναρίων. Σχεδιάστηκε, υλοποιήθηκε και συντηρείται στο [PUC-RIO](https://www.puc-rio.br/) στη Βραζιλία από το 1993 από την ομάδα των Roberto Ierusalimschy, Waldemar Celes και Luiz Henrique de Figueiredo.

### Σχόλια

Τα σχόλια μίας γραμμής στη Lua ξεκινούν με `--` και τα σχόλια πολλαπλών γραμμών ξεκινούν με `--[[` και τελειώνουν με `]]`.
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### Μεταβλητές

Υπάρχουν τρεις τύποι μεταβλητών στη Lua: καθολικές μεταβλητές, τοπικές μεταβλητές και πεδία πίνακα. Για να κρατήσουμε τα πράγματα απλά, εδώ εξηγούνται μόνο οι τοπικές μεταβλητές. Από προεπιλογή όλες οι μεταβλητές είναι καθολικές, οπότε πρέπει να δηλώνουμε τις τοπικές μεταβλητές ως τέτοιες με τη λέξη-κλειδί `local`.
```lua
local x
```

Μια τιμή μπορεί να ανατεθεί σε μια μεταβλητή χρησιμοποιώντας τον τελεστή `=`.
```lua
local x = 1
```

Το πεδίο εφαρμογής μιας `local` μεταβλητής περιορίζεται στο μπλοκ όπου δηλώνεται. Ένα μπλοκ μπορεί να είναι το σώμα μιας δομής ελέγχου, το σώμα μιας συνάρτησης ή ένα αρχείο ή συμβολοσειρά όπου δηλώνεται η μεταβλητή.
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### Συναρτήσεις

Μια συνάρτηση δηλώνεται με τη λέξη-κλειδί `function` και, όπως οι μεταβλητές, είναι καθολική από προεπιλογή. Ένας ορισμός συνάρτησης έχει ένα όνομα, μια λίστα παραμέτρων και ένα σώμα. Η συνάρτηση εξέρχεται όταν φτάσει στη λέξη-κλειδί `return` και επιστρέφει όλες τις τιμές που παρατίθενται μετά από αυτήν. Χωρίς καθορισμένο `return`, η συνάρτηση θα επιστρέψει `nil`.

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### Πίνακες

Οι πίνακες είναι ο μόνος μηχανισμός δόμησης δεδομένων στη Lua και είναι πολύ ισχυροί. Χρησιμοποιούνται για την αναπαράσταση πινάκων, συνόλων, αντικειμένων, μονάδων και πολλών άλλων. Ουσιαστικά, ένας πίνακας στη Lua είναι ένας συνειρμικός πίνακας.
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

Αυτή είναι μόνο μια μικρή γνώση που χρειάζεται για την επόμενη ενότητα. Θα επανέλθουμε σε αυτό το θέμα λεπτομερώς αργότερα.

### Μονάδες

Μια μονάδα είναι μια συλλογή κώδικα που αποθηκεύεται σε ένα αρχείο πηγαίου κώδικα `.lua`. Ό,τι εξάγει η μονάδα αποθηκεύεται σε έναν πίνακα και αυτός ο πίνακας επιστρέφεται στο τέλος του αρχείου. Έτσι, ο πίνακας λειτουργεί βασικά ως ένα είδος χώρου ονομάτων.
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

Αυτή η μονάδα μπορεί στη συνέχεια να φορτωθεί σε ένα άλλο αρχείο μέσω της συνάρτησης `require`, η οποία επιστρέφει τον πίνακα.
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

Όταν βλέπουμε το `say.hello`, θα σκεφτόμασταν "τη συνάρτηση `hello` από τη μονάδα `say`". Αλλά γνωρίζοντας ότι το `say-hello.lua` μας επιστρέφει έναν πίνακα και κοιτάζοντας πίσω στην ενότητα για τους πίνακες, παρατηρούμε ότι στη Lua η έκφραση σημαίνει "πρόσβαση στον πίνακα `say` χρησιμοποιώντας τη συμβολοσειρά `hello` ως κλειδί".  

Αν και είναι καλή πρακτική μια μονάδα να επιστρέφει έναν πίνακα, είναι εξίσου δυνατό να επιστρέφει οποιονδήποτε άλλο τύπο, όπως μια συνάρτηση.

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
