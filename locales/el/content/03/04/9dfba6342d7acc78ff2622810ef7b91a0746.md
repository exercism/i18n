# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις το Betty's Bike Shop, ένα ηλεκτρονικό κατάστημα για ποδήλατα και ανταλλακτικά.
Έχεις τρεις εργασίες, με στόχο να εμφανίζονται σωστά οι τιμές των ποδηλάτων και των ανταλλακτικών στην ιστοσελίδα.

## 1. Εξήγαγε τη συνάρτηση `pence_to_pounds`

Ο συνάδελφός σου έχει ήδη γράψει τον σκελετό του module, τις ημιτελείς συναρτήσεις `pence_to_pounds` και `pounds_to_string`.
Ωστόσο, ξέχασε να εξάγει τη συνάρτηση `pence_to_pounds`, οπότε αυτή τη στιγμή δεν είναι ορατή από άλλα modules ή από τη σουίτα δοκιμών.

Εξήγαγε τη συνάρτηση `pence_to_pounds`.

## 2. Μετέτρεψε τις πέννες σε λίρες

Αυτή τη στιγμή, η τιμή αποθηκεύεται ως ακέραιος αριθμός *πεννών* (το κατάστημα ποδηλάτων εδρεύει στο Ηνωμένο Βασίλειο).
Στην ιστοσελίδα θέλουμε να δείχνουμε την τιμή σε *λίρες*, όπου 1,00 λίρα αντιστοιχεί σε 100 πέννες.
Η πρώτη σου εργασία είναι να υλοποιήσεις τη συνάρτηση `pence_to_pounds`, η οποία παίρνει ένα ποσό σε πέννες ως `Int` και το μετατρέπει στο αντίστοιχο ποσό σε λίρες ως `Float`.
Θα πρέπει επίσης να προσθέσεις annotations τύπων για αυτή τη συνάρτηση.

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. Μορφοποίησε την τιμή για εμφάνιση στην ιστοσελίδα

Επειδή τα ποδήλατα της Betty πωλούνται σε λίρες, οι τιμές πρέπει να εμφανίζονται με το σύμβολο "£".
Η δεύτερη εργασία σου είναι λοιπόν να υλοποιήσεις τη συνάρτηση `pounds_to_string`, η οποία παίρνει ένα ποσό σε λίρες ως `Float` και επιστρέφει την τιμή του ως `String`, με το σύμβολο της λίρας μπροστά.

Θα πρέπει να κάνεις εισαγωγή των modules `gleam/float` και `gleam/string` πριν τα χρησιμοποιήσεις.

Θα πρέπει επίσης να ορίσεις το annotation τύπου για τη συνάρτηση `pounds_to_string`.

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
