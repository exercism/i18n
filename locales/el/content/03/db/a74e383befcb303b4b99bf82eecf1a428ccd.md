# Εισαγωγή

Όταν κάνεις [αναδρομή][exercism-recursion] σε απαριθμήσιμα (λίστες, συμβολοσειρές bit, συμβολοσειρές), προκύπτουν συχνά δύο ζητήματα:

- πόση μνήμη χρειάζεται για να αποθηκευτεί το ίχνος των αναδρομικών κλήσεων της συνάρτησης
- πώς θα χτίσεις τη λύση αποδοτικά

Για να αντιμετωπίσεις αυτά τα ζητήματα, μπορείς να χρησιμοποιήσεις έναν _συσσωρευτή_.

Ο συσσωρευτής είναι μια μεταβλητή που περνιέται μαζί με τα δεδομένα. Χρησιμοποιείται για να μεταφέρει την τρέχουσα κατάσταση της εκτέλεσης της συνάρτησης, από τη μια κλήση στην επόμενη, μέχρι να φτάσεις στη _βασική περίπτωση_. Στη βασική περίπτωση, ο συσσωρευτής χρησιμοποιείται για να επιστραφεί η τελική τιμή της αναδρομικής κλήσης.

Οι συσσωρευτές πρέπει να αρχικοποιούνται από τον συγγραφέα της συνάρτησης, όχι από τον χρήστη της. Για να το πετύχεις αυτό, δήλωσε δύο συναρτήσεις: μια δημόσια συνάρτηση που παίρνει ως ορίσματα μόνο τα απαραίτητα δεδομένα και αρχικοποιεί τον συσσωρευτή, και μια ιδιωτική συνάρτηση που παίρνει επίσης έναν συσσωρευτή. Στην Elixir, είναι συνηθισμένο μοτίβο το όνομα της ιδιωτικής συνάρτησης να έχει πρόθεμα `do_`.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

Η χρήση ενός συσσωρευτή μάς επιτρέπει να μετατρέψουμε τις αναδρομικές συναρτήσεις σε συναρτήσεις _αναδρομής ουράς_. Μια συνάρτηση είναι αναδρομής ουράς αν το _τελευταίο_ πράγμα που εκτελεί είναι μια κλήση στον εαυτό της.
