# Εισαγωγή

## Επαναλήπτες

Ένας `Iterator` στη Gleam μοιάζει με μια λίστα στο ότι είναι μια διατεταγμένη συλλογή τιμών, όπου όλες οι τιμές είναι του ίδιου τύπου. Διαφέρει από μια λίστα στο ότι είναι οκνηρός, που σημαίνει ότι δεν αποθηκεύει όλες τις τιμές του στη μνήμη ταυτόχρονα, αλλά αντ' αυτού τις υπολογίζει καθώς χρειάζονται.

Αυτό είναι χρήσιμο όταν δουλεύεις με ακολουθίες που είναι πολύ μεγάλες ή ακόμα και άπειρες σε μέγεθος, καθώς μας επιτρέπει να δουλέψουμε με αυτές όταν δεν έχουμε αρκετή ελεύθερη μνήμη για να τις αποθηκεύσουμε όλες με τη μία.

Η ενότητα `gleam/iterator` ορίζει τον τύπο `Iterator` καθώς και συναρτήσεις για να δουλεύεις με επαναλήπτες.

Πολλές από τις συναρτήσεις για λίστες υπάρχουν επίσης για επαναλήπτες, όπως οι `map`, `filter` και `take`. Αυτές οι συναρτήσεις επιστρέφουν επαναλήπτες, οπότε στην πραγματικότητα δεν εκτελούν καμία εργασία μέχρι να καταναλωθεί ο επαναλήπτης.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

Η συνάρτηση `unfold` μπορεί να χρησιμοποιηθεί για να δημιουργεί επαναλήπτες από μια συνάρτηση που καλείται επανειλημμένα για να παράγει την επόμενη τιμή στην ακολουθία.

Εδώ η συνάρτηση `unfold` χρησιμοποιείται για να δημιουργήσει έναν επαναλήπτη που παράγει την ακολουθία Fibonacci:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

Η ακολουθία εδώ είναι άπειρη, οπότε η συνάρτηση `take` χρησιμοποιείται για να την κάνει πεπερασμένη πριν συλλεχθούν οι τιμές σε μια λίστα. Αν κληθεί η `to_list` σε έναν άπειρο επαναλήπτη, το πρόγραμμα θα τρέξει μέχρι να ξεμείνει από μνήμη και να καταρρεύσει.
