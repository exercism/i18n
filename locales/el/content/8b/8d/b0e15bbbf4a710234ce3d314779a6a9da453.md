# Οδηγίες

Γράφεις ένα ενσωματωμένο σύστημα για ένα μηχάνημα Take-A-Number. Είναι ένα πολύ απλό μοντέλο. Μπορεί να μοιράζει διαδοχικούς αριθμούς και να αναφέρει ποιος ήταν ο τελευταίος αριθμός που δόθηκε.

## 1. Ξεκίνα το μηχάνημα

Υλοποίησε τη συνάρτηση `start/0`. Θα πρέπει να δημιουργεί μια νέα διεργασία και να επιστρέφει το PID της διεργασίας. Η νέα διεργασία δεν χρειάζεται να κάνει τίποτα ακόμα.

```elixir
TakeANumber.start()
# => #PID<0.138.0>
```

Σημείωσε ότι κάθε φορά που τρέχεις αυτόν τον κώδικα, το PID μπορεί να είναι διαφορετικό.

## 2. Ανάφερε την κατάσταση του μηχανήματος

Τροποποίησε το μηχάνημα ώστε η νέα διεργασία που δημιουργήθηκε να είναι έτοιμη να λαμβάνει μηνύματα (ξεκίνα έναν _βρόχο λήψης_) με αρχική κατάσταση `0`. Θα πρέπει να μπορεί να λαμβάνει μηνύματα `{:report_state, sender_pid}`. Ως απάντηση σε αυτά τα μηνύματα, θα πρέπει να στέλνει την τρέχουσα κατάστασή του (τον τελευταίο αριθμό εισιτηρίου που δόθηκε) στο `sender_pid` και μετά να περιμένει περισσότερα μηνύματα.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:report_state, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 0
```

## 3. Δώσε αριθμούς

Τροποποίησε το μηχάνημα ώστε να μπορεί να λαμβάνει μηνύματα `{:take_a_number, sender_pid}`. Θα πρέπει να αυξάνει την κατάστασή του κατά 1, να στέλνει τη νέα κατάσταση στο `sender_pid` και μετά να περιμένει περισσότερα μηνύματα.

```elixir
machine_pid = TakeANumber.start()

# a client sending a message to the machine
send(machine_pid, {:take_a_number, self()})

# a client receiving a message from the machine
receive do
  msg -> msg
end

# => 1
```

## 4. Σταμάτησε το μηχάνημα

Τροποποίησε το μηχάνημα ώστε να μπορεί να λαμβάνει ένα μήνυμα `:stop`. Θα πρέπει να σταματήσει να περιμένει περισσότερα μηνύματα.

## 5. Αγνόησε τα απροσδόκητα μηνύματα

Τροποποίησε το μηχάνημα ώστε όταν λαμβάνει ένα απροσδόκητο μήνυμα, να το αγνοεί και να συνεχίζει να περιμένει περισσότερα μηνύματα.
