# Οδηγίες

Βρίσκεσαι στη διαδικασία ανάπτυξης του νέου, πολυαγαπημένου παιχνιδιού **Crystal Hunter**.
Στο παιχνίδι, είσαι ένας χαρακτήρας που κινείται τριγύρω και μαζεύει κρυστάλλους.
Ο παίκτης κερδίζει μαζεύοντας όλους τους κρυστάλλους.
Αν ο παίκτης έρθει σε επαφή με έναν ληστή, θα χάσει όλους τους κρυστάλλους του και το παιχνίδι.
Υπάρχει μια εξαίρεση σε αυτόν τον κανόνα: ο παίκτης μπορεί να έχει ενεργό power-up που τον κάνει αόρατο στους ληστές.

Ο στόχος σου είναι να γράψεις κάποιους κανόνες που θα χρησιμοποιηθούν στο παιχνίδι.

## 1. Όρισε αν ο χαρακτήρας παίρνει πόντους μπόνους

Στο παιχνίδι, ο χαρακτήρας παίρνει πόντους μπόνους αν αγγίξει έναν ληστή ενώ έχει ένα power-up.

Όρισε τη μέθοδο `Rules#bonus_points?` που παίρνει δύο ορίσματα (_αν ο χαρακτήρας έχει ενεργό power-up_ και _αν ο χαρακτήρας αγγίζει έναν ληστή_) και επιστρέφει μια τιμή Boolean (λογική τιμή) που δείχνει αν ο χαρακτήρας θα πάρει πόντους μπόνους.
Η μέθοδος θα πρέπει να επιστρέφει `true` μόνο αν ο χαρακτήρας έχει ενεργό power-up και αγγίζει έναν ληστή, και `false` σε κάθε άλλη περίπτωση.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Όρισε αν ο χαρακτήρας σκοράρει

Ο παίκτης κερδίζει πόντους στο παιχνίδι όταν μαζεύει έναν κρύσταλλο ή ένα power-up.

Όρισε τη μέθοδο `Rules#score?`, η οποία παίρνει δύο ορίσματα (_αν ο χαρακτήρας αγγίζει ένα power-up_ και _αν ο χαρακτήρας αγγίζει έναν κρύσταλλο_) και επιστρέφει μια τιμή Boolean που δείχνει αν ο χαρακτήρας σκόραρε ή όχι.
Η μέθοδος θα πρέπει να επιστρέφει `true` αν ο χαρακτήρας αγγίζει ένα power-up ή έναν κρύσταλλο και να επιστρέφει `false` σε κάθε άλλη περίπτωση.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Όρισε αν ο χαρακτήρας χάνει

Όρισε τη μέθοδο `Rules#lose?`, η οποία παίρνει δύο ορίσματα (_αν ο χαρακτήρας έχει ενεργό power-up_ και _αν ο χαρακτήρας αγγίζει έναν ληστή_) και επιστρέφει μια τιμή Boolean που δείχνει αν ο χαρακτήρας χάνει ή όχι.
Η μέθοδος θα πρέπει να επιστρέφει `true` αν ο χαρακτήρας αγγίζει έναν ληστή και δεν έχει ενεργό power-up και να επιστρέφει `false` σε κάθε άλλη περίπτωση.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Όρισε αν ο χαρακτήρας κερδίζει

Όρισε τη μέθοδο `Rules#win?`, η οποία παίρνει τρία ορίσματα (_αν ο χαρακτήρας έχει μαζέψει όλους τους κρυστάλλους_, _αν ο χαρακτήρας έχει ενεργό power-up_ και _αν ο χαρακτήρας αγγίζει έναν ληστή_) και επιστρέφει μια τιμή Boolean που δείχνει αν ο χαρακτήρας κερδίζει ή όχι.
Η μέθοδος θα πρέπει να επιστρέφει `true` αν ο χαρακτήρας έχει μαζέψει όλους τους κρυστάλλους και δεν έχει χάσει με βάση τα ορίσματα που ορίστηκαν στο μέρος 3, και να επιστρέφει `false` σε κάθε άλλη περίπτωση.

```crystal
Rules.new.win?(false, true, false)
# => false
```
