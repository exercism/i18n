# Οδηγίες

Μετά από έναν πρόσφατο έλεγχο ασφαλείας, σου ζητήθηκε να καθαρίσεις τα αρχειοθετημένα αρχεία καταγραφής του οργανισμού.

## 1. Εντόπισε τις αλλοιωμένες γραμμές καταγραφής

Χρειάζεσαι μια ιδέα για το πόσες γραμμές καταγραφής στο αρχείο σου δεν συμμορφώνονται με τα τρέχοντα πρότυπα.
Πιστεύεις ότι ένας απλός έλεγχος αποκαλύπτει αν μια γραμμή καταγραφής είναι έγκυρη.
Για να θεωρηθεί έγκυρη, μια γραμμή πρέπει να ξεκινά με μία από τις παρακάτω συμβολοσειρές:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Υλοποίησε τη συνάρτηση `is_valid_line` ώστε να επιστρέφει `True` αν η γραμμή καταγραφής είναι έγκυρη.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Χώρισε τη γραμμή καταγραφής

Λίγο αφού ξεκίνησες το έργο ανάλυσης των καταγραφών, συνειδητοποιείς ότι οι καταγραφές μιας εφαρμογής δεν χωρίζονται σε γραμμές όπως των άλλων. Σε αυτό το έργο, ό,τι θα έπρεπε να είναι ξεχωριστές γραμμές βρίσκεται σε μία μόνο γραμμή, ενωμένο με ιδιαίτερα βελάκια όπως `<--->` ή `<*~*~>`.

Στην πραγματικότητα, οποιαδήποτε συμβολοσειρά έχει πρώτο χαρακτήρα το `<`, τελευταίο χαρακτήρα το `>` και μηδέν ή περισσότερους από τους εξής χαρακτήρες `~`, `*`, `=` και `-` ανάμεσά τους μπορεί να χρησιμοποιηθεί ως διαχωριστικό στις καταγραφές αυτού του έργου.

Υλοποίησε τη συνάρτηση `split_line` που παίρνει μια γραμμή και επιστρέφει μια λίστα από συμβολοσειρές.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Σήμανε τις γραμμές με ονόματα χρηστών

Παρατήρησες ότι ορισμένες από τις γραμμές καταγραφής περιέχουν προτάσεις που αναφέρονται σε χρήστες.
Αυτές οι προτάσεις περιέχουν πάντα τη συμβολοσειρά `"User"`, ακολουθούμενη από έναν ή περισσότερους χαρακτήρες κενού και έπειτα από ένα όνομα χρήστη.
Αποφασίζεις να σημάνεις τέτοιες γραμμές.

Υλοποίησε μια συνάρτηση `tag_with_user_name` που επεξεργάζεται γραμμές καταγραφής:

- Οι γραμμές που δεν περιέχουν τη συμβολοσειρά `"User"` παραμένουν αμετάβλητες.
- Στις γραμμές που περιέχουν τη συμβολοσειρά `"User"`, πρόσθεσε στην αρχή της γραμμής το `[USER]` ακολουθούμενο από το όνομα χρήστη.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Μπορείς να υποθέσεις ότι:

- Κάθε εμφάνιση της συμβολοσειράς `"User"` ακολουθείται από έναν ή περισσότερους χαρακτήρες κενού και το όνομα χρήστη.
- Υπάρχει το πολύ μία εμφάνιση της συμβολοσειράς `"User"` σε κάθε γραμμή.
- Τα ονόματα χρηστών είναι μη κενές συμβολοσειρές που δεν περιέχουν κενά.
