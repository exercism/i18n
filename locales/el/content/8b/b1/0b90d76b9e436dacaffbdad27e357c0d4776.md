# Οδηγίες

Σε αυτή την άσκηση, θα υλοποιήσεις τη λογική της αποστολής για ένα νέο παιχνίδι RPG που αναπτύσσει ένας φίλος.
Η βασική ηρωίδα του παιχνιδιού είναι η Annalyn, ένα γενναίο κορίτσι με έναν άγριο και πιστό σκύλο.
Δυστυχώς, η καταστροφή χτυπά: ο καλύτερός της φίλος απήχθη ενώ έψαχνε για μούρα στο δάσος.
Η Annalyn θα προσπαθήσει να τον βρει και να τον ελευθερώσει, παίρνοντας προαιρετικά μαζί της τον σκύλο της σε αυτή την αποστολή.

Αφού πέρασε λίγο καιρό ακολουθώντας τα ίχνη του καλύτερού της φίλου, βρίσκει το στρατόπεδο όπου εκείνος κρατείται.
Αποδεικνύεται ότι υπάρχουν δύο απαγωγείς: ένας πανίσχυρος ιππότης και ένας πονηρός τοξότης.

Έχοντας βρει τους απαγωγείς, η Annalyn σκέφτεται ποιες από τις παρακάτω ενέργειες μπορεί να κάνει:

- _Γρήγορη επίθεση_: μια γρήγορη επίθεση μπορεί να γίνει αν ο ιππότης κοιμάται, καθώς χρειάζεται χρόνο για να φορέσει την πανοπλία του, οπότε θα είναι ευάλωτος.
- _Κατασκόπευση_: μπορείς να κατασκοπεύσεις την ομάδα αν τουλάχιστον ένας από αυτούς είναι ξύπνιος.
  Αλλιώς, η κατασκόπευση είναι χάσιμο χρόνου.
- _Σήμα στον κρατούμενο_: μπορείς να δώσεις σήμα στον κρατούμενο με ήχους πουλιών αν ο κρατούμενος είναι ξύπνιος και ο τοξότης κοιμάται, καθώς οι τοξότες είναι εκπαιδευμένοι στα σήματα με πουλιά, οπότε θα μπορούσαν να υποκλέψουν το μήνυμα.
- _Ελευθέρωση του κρατούμενου_: η Annalyn μπορεί να προσπαθήσει να μπει κρυφά στο στρατόπεδο για να ελευθερώσει τον κρατούμενο.
  Αυτό είναι ρίσκο και μπορεί να πετύχει μόνο με έναν από τους δύο παρακάτω τρόπους:
  - Αν η Annalyn έχει μαζί της τον σκύλο της, μπορεί να σώσει τον κρατούμενο αν ο τοξότης κοιμάται.
    Ο ιππότης φοβάται τον σκύλο και ο τοξότης δεν θα προλάβει να ετοιμαστεί πριν η Annalyn και ο κρατούμενος το σκάσουν.
  - Αν η Annalyn δεν έχει τον σκύλο της, τότε αυτή και ο κρατούμενος πρέπει να κινηθούν με μεγάλη μυστικότητα!
    Η Annalyn μπορεί να ελευθερώσει τον κρατούμενο αν ο κρατούμενος είναι ξύπνιος και ο ιππότης με τον τοξότη κοιμούνται και οι δύο, αλλά αν ο κρατούμενος κοιμάται δεν μπορεί να σωθεί: ο κρατούμενος θα τρομάξει από την ξαφνική εμφάνιση της Annalyn και θα ξυπνήσει τον ιππότη και τον τοξότη.

Έχεις τέσσερις εργασίες: να υλοποιήσεις τη λογική που καθορίζει αν οι παραπάνω ενέργειες είναι διαθέσιμες, με βάση την κατάσταση των τριών χαρακτήρων που βρίσκονται στο δάσος και το αν ο σκύλος της Annalyn είναι παρών ή όχι.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

Όρισε τη συνάρτηση `can_fast_attack()` που παίρνει μια Boolean τιμή που δείχνει αν ο ιππότης είναι ξύπνιος.
Η συνάρτηση επιστρέφει `true` αν μπορεί να γίνει γρήγορη επίθεση με βάση την κατάσταση του ιππότη.
Αλλιώς, επιστρέφει `false`:

```rust
let knight_awake = true;
can_fast_attack(knight_awake); // false
```

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

Όρισε τη συνάρτηση `can_spy()` που παίρνει τρεις Boolean τιμές, που δείχνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι.
Η συνάρτηση επιστρέφει `true` αν μπορείς να κατασκοπεύσεις την ομάδα, με βάση την κατάσταση των τριών χαρακτήρων.
Αλλιώς, επιστρέφει `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
can_spy(knight_awake, archer_awake, prisoner_awake); // true
```

## 3. Έλεγξε αν μπορείς να δώσεις σήμα στον κρατούμενο

Όρισε τη συνάρτηση `can_signal_prisoner()` που παίρνει δύο Boolean τιμές, που δείχνουν αν ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι.
Η συνάρτηση επιστρέφει `true` αν μπορείς να δώσεις σήμα στον κρατούμενο, με βάση την κατάσταση των δύο χαρακτήρων.
Αλλιώς, επιστρέφει `false`:

```rust
let archer_awake = false;
let prisoner_awake = true;
can_signal_prisoner(archer_awake, prisoner_awake); // true
```

## 4. Έλεγξε αν μπορείς να ελευθερώσεις τον κρατούμενο

Όρισε τη συνάρτηση `can_free_prisoner()` που παίρνει τέσσερις Boolean τιμές.
Οι τρεις πρώτες παράμετροι δείχνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι.
Η τελευταία παράμετρος δείχνει αν ο σκύλος της Annalyn είναι παρών.
Η συνάρτηση επιστρέφει `true` αν μπορείς να ελευθερώσεις τον κρατούμενο, με βάση την κατάσταση των τριών χαρακτήρων και την παρουσία του σκύλου της Annalyn.
Αλλιώς, επιστρέφει `false`:

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
let dog_present = false;
can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present); // false
```
