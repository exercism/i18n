# Εισαγωγή

Στη Gleam υπάρχουν δύο διαφορετικά είδη αριθμών: τα int και τα float.

Τα int είναι ακέραιοι αριθμοί.

```gleam
let integer = 3
// -> 3
```

Μπορείς επίσης να προσθέσεις κάτω παύλες στα int για λόγους σαφήνειας.

```gleam
1_000_000 // One million
```

Η Gleam έχει αρκετούς τελεστές που λειτουργούν με int.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
