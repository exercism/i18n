# Ροή εργασίας deploy

Η ροή εργασίας deploy χρησιμοποιείται για να κάνει deploy τα [εργαλεία track](/docs/building/tooling) σε:

1. [Docker Hub](https://hub.docker.com/): χρησιμοποιείται σε scripts ή για τοπικές δοκιμές.
   Δημόσια διαθέσιμο.
2. [ECR](https://aws.amazon.com/ecr/): χρησιμοποιείται στο περιβάλλον παραγωγής για τη δοκιμή λύσεων που έχουν υποβληθεί.
   Ιδιωτικό.

## Πηγή

Η ροή εργασίας ορίζεται στο αρχείο `.github/workflows/deploy.yml`.
