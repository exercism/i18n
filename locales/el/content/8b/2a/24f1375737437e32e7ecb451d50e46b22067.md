# Εισαγωγή

Το φιλτράρισμα είναι η διαδικασία δημιουργίας μιας ακολουθίας από μια άλλη ακολουθία, αντιγράφοντας από την αρχική ακολουθία όλα τα στοιχεία εκτός από ορισμένα.
Η επιλογή του ποια στοιχεία θα συμπεριληφθούν στη νέα ακολουθία μπορεί να γίνει με μια συνάρτηση κατηγόρημα (μια συνάρτηση που αξιολογείται σε Boolean (λογική τιμή)), ή με βάση την ισότητα με ένα συγκεκριμένο αντικείμενο.

## Αφαίρεση με βάση ένα κατηγόρημα

Η `remove-if` είναι μια συνάρτηση που παίρνει ως ορίσματα μια συνάρτηση κατηγόρημα και μια ακολουθία, και επιστρέφει μια ακολουθία με μόνο εκείνα τα στοιχεία για τα οποία το κατηγόρημα αξιολογήθηκε σε ψευδή τιμή.
Με άλλα λόγια, "αφαιρεί" όλα τα στοιχεία της ακολουθίας για τα οποία το κατηγόρημα αξιολογείται σε αληθή τιμή. Ωστόσο, πρόσεξε ότι αυτή η συνάρτηση δεν τροποποιεί την αρχική ακολουθία!
Αντ' αυτού, επιστρέφει μια νέα ακολουθία χωρίς τα στοιχεία αυτά. Αν το κατηγόρημα ήταν αληθές για όλες τις τιμές, τότε επιστρέφεται μια κενή ακολουθία.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Αφαίρεση ενός συγκεκριμένου στοιχείου

Αν θέλεις να αφαιρέσεις ένα συγκεκριμένο στοιχείο από μια ακολουθία, μπορείς να χρησιμοποιήσεις τη `remove`, η οποία παίρνει το στοιχείο προς αφαίρεση και μια ακολουθία.
Επιστρέφονται όλες οι τιμές της ακολουθίας που δεν είναι ίσες με το στοιχείο προς αφαίρεση.
ΣΗΜΕΙΩΣΗ: Η ισότητα ελέγχεται από προεπιλογή με το `eql`, το [γενικό κατηγόρημα ισότητας][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
