# Οδηγίες

Δεδομένων των ονομάτων των μαθητών και της τάξης τους, δημιούργησε έναν κατάλογο για το σχολείο.

Στο τέλος, θα πρέπει να μπορείς να:

- Πρόσθεσε το όνομα ενός μαθητή στον κατάλογο για μια τάξη
  - "Πρόσθεσε τον Jim στην τάξη 2."
  - "Εντάξει."
- Πάρε μια λίστα με όλους τους μαθητές που είναι εγγεγραμμένοι σε μια τάξη
  - "Ποιοι μαθητές είναι στην τάξη 2;"
  - "Αυτή τη στιγμή έχουμε μόνο τον Jim."
- Πάρε μια ταξινομημένη λίστα με όλους τους μαθητές σε όλες τις τάξεις. Οι τάξεις θα πρέπει να ταξινομούνται ως 1, 2, 3, κ.λπ., και οι μαθητές μέσα σε μια τάξη θα πρέπει να ταξινομούνται αλφαβητικά με το όνομά τους.
  - "Ποιοι είναι όλοι εγγεγραμμένοι στο σχολείο αυτή τη στιγμή;"
  - "Άσε με να σκεφτώ. Έχουμε
  Anna, Barb και Charlie στην τάξη 1,
  Alex, Peter και Zoe στην τάξη 2
  και Jim στην τάξη 5.
  Άρα η απάντηση είναι: Anna, Barb, Charlie, Alex, Peter, Zoe και Jim"

Σημείωσε ότι όλοι οι μαθητές μας έχουν μόνο ένα όνομα. (Είναι μια μικρή πόλη, τι θέλεις;)

## Για επιπλέον πόντους

Κατάφερες να περνούν τα tests και ο κώδικας να είναι καθαρός; Αν θέλεις, αυτά είναι μερικά επιπλέον πράγματα που θα μπορούσες να δοκιμάσεις:

- Αν δουλεύεις σε μια γλώσσα με μεταβλητές δομές δεδομένων και η υλοποίησή σου επιτρέπει σε εξωτερικό κώδικα να μεταβάλλει απευθείας την εσωτερική βάση δεδομένων του σχολείου, δες αν μπορείς να το αποτρέψεις. Μη διστάσεις να προσθέσεις επιπλέον tests.

Στη συνέχεια, μοιράσου τις σκέψεις σου σε ένα σχόλιο στην υποβολή. Αυτό το πείραμα έκανε τον κώδικα καλύτερο; Χειρότερο; Έμαθες τίποτα από αυτό;
