# Οδηγίες

Ο στόχος σου είναι να δημιουργήσεις έναν ελεγκτή κωδικού πρόσβασης.
Ένας ελεγκτής κωδικού πρόσβασης επικυρώνει τον κωδικό πρόσβασης που προτείνει ένας χρήστης, ώστε να βεβαιωθεί ότι πληροί ένα σύνολο απαιτήσεων που ορίζει ο οργανισμός που ελέγχει την πρόσβαση στον συγκεκριμένο πόρο.

Για αυτή την άσκηση, οι απαιτήσεις για τον κωδικό πρόσβασης είναι:
* Πρέπει να έχει 12 ή περισσότερους χαρακτήρες
* Πρέπει να έχει τουλάχιστον ένα κεφαλαίο γράμμα
* Πρέπει να έχει τουλάχιστον ένα πεζό γράμμα
* Πρέπει να έχει τουλάχιστον ένα ψηφίο
* Πρέπει να έχει τουλάχιστον ένα σύμβολο από το σύνολο !@#$%^&*

Η λύση σου πρέπει να χρησιμοποιεί ένα `Result` για να ενσωματώνει την κατάσταση επιτυχίας ή αποτυχίας.
Στην περίπτωση επιτυχίας, το `Result` πρέπει να μεταφέρει τον επικυρωμένο κωδικό πρόσβασης ως συμβολοσειρά.
Στην περίπτωση αποτυχίας, το `Result` πρέπει να μεταφέρει τον κανόνα που παραβιάστηκε.

~~~~exercism/note
Για αυτή την άσκηση, ο ελεγκτής κωδικού πρόσβασης θα είναι απλοϊκός: θα υποδεικνύει μόνο πότε έχει παραβιαστεί ένας μόνο κανόνας.
Μια επόμενη άσκηση θα εξετάσει έναν πιο ρεαλιστικό ελεγκτή κωδικού πρόσβασης, που μπορεί να υποδεικνύει πότε έχουν παραβιαστεί πολλοί κανόνες ταυτόχρονα.
~~~~

## 1. Υλοποίησε τη συνάρτηση `checkPassword`

Η συνάρτηση `checkPassword` ελέγχει τον κωδικό πρόσβασης που δίνεται με βάση τους προαναφερθέντες κανόνες. Σε περίπτωση αποτυχίας, υποδεικνύει τον κανόνα που παραβιάστηκε, ενσωματώνοντας μία από τις τιμές του `PasswordRule` στην τιμή του αποτελέσματος.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Υλοποίησε τη συνάρτηση ``getStatusMessage`

Η συνάρτηση `getStatusMessage` επιστρέφει μια συμβολοσειρά που περιέχει ένα μήνυμα αναγνώσιμο από τον άνθρωπο, το οποίο δηλώνει το νόημα του αποτελέσματος που επιστρέφει η `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
