# Debug

Όταν ένα test αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά και για ποια είσοδο. Μπορείς επίσης να εκμεταλλευτείς το γεγονός ότι θα εμφανίζεται και οποιαδήποτε [έξοδος στην κονσόλα][programiz.com-basic-input-output]. Μπορείς να γράψεις στην κονσόλα χρησιμοποιώντας:

```csharp
Console.WriteLine("Debug message");
```
