# Εισαγωγή

Τα δυαδικά ψηφία τελικά αντιστοιχούν άμεσα στα τρανζίστορ της CPU ή της RAM σου, και στο αν το καθένα είναι "ενεργό" ή "ανενεργό".

Ο χειρισμός χαμηλού επιπέδου, που ανεπίσημα ονομάζεται "bit-twiddling", είναι ιδιαίτερα σημαντικός στις γλώσσες προγραμματισμού συστημάτων.

Οι γλώσσες υψηλού επιπέδου όπως η Julia συνήθως αποκρύπτουν τις περισσότερες από αυτές τις λεπτομέρειες.
Ωστόσο, μια πλήρης γκάμα πράξεων σε επίπεδο bit είναι διαθέσιμη στη βασική γλώσσα.

***Σημείωση:*** Για να δεις δυαδική έξοδο αναγνώσιμη από άνθρωπο στο REPL, σχεδόν όλα τα παρακάτω παραδείγματα πρέπει να τυλιχτούν σε μια συνάρτηση `bitstring()`.
Αυτό αποσπά την προσοχή οπτικά, οπότε οι περισσότερες εμφανίσεις αυτής της συνάρτησης έχουν αφαιρεθεί.

## Πράξεις ολίσθησης bit

Οι ακέραιοι τύποι, με πρόσημο ή χωρίς πρόσημο, μπορούν να αναπαρασταθούν ως συμβολοσειρά από 1 και 0.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Οι ολισθήσεις bit απλώς μετακινούν τα πάντα αριστερά ή δεξιά κατά έναν καθορισμένο αριθμό θέσεων.
Με τύπους `UInt`, μερικά bit πέφτουν από το ένα άκρο και το άλλο άκρο γεμίζει με μηδενικά:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Κάθε ολίσθηση αριστερά διπλασιάζει την τιμή και κάθε ολίσθηση δεξιά τη μειώνει στο μισό (με περικοπή).
Αυτό είναι πιο προφανές στη δεκαδική αναπαράσταση:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Αυτή η ολίσθηση bit είναι πολύ ταχύτερη από την "κανονική" αριθμητική, κάνοντας την τεχνική πολύ δημοφιλή στον προγραμματισμό χαμηλού επιπέδου.

Με τους ακέραιους με πρόσημο, πρέπει να είμαστε λίγο πιο προσεκτικοί.

Οι ολισθήσεις αριστερά είναι σχετικά απλές:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Η ολίσθηση αριστερά θετικών ακέραιων με πρόσημο είναι επομένως ίδια με αυτήν των ακέραιων χωρίς πρόσημο.

Οι αρνητικές τιμές αποθηκεύονται σε [μορφή συμπληρώματος ως προς δύο][2complement], που σημαίνει ότι το αριστερότερο bit είναι 1.
Κανένα πρόβλημα για μια ολίσθηση αριστερά, αλλά όταν κάνουμε ολίσθηση δεξιά, πώς γεμίζουμε τα αριστερότερα bit;

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

Ο τελεστής `>>` εκτελεί αριθμητική ολίσθηση, διατηρώντας το bit προσήμου.

Ο τελεστής `>>>` εκτελεί λογική ολίσθηση, γεμίζοντας με μηδενικά σαν ο αριθμός να ήταν χωρίς πρόσημο.

## Λογική bit

Είδαμε σε προηγούμενη Έννοια ότι οι τελεστές `&&` (and), `||` (or) και `!` (not) χρησιμοποιούνται με τιμές Boolean.

Υπάρχουν οι ισοδύναμοι τελεστές `&` (bitwise and), `|` (bitwise or) και `~` (μια περισπωμένη, bitwise not) για να συγκρίνεις τα bit δύο ακεραίων.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Εδώ, η `xor()` είναι το αποκλειστικό Ή, που χρησιμοποιείται ως συνάρτηση.

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
