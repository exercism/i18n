# Υποδείξεις

## Γενικά

- Η [τεκμηρίωση του API του `Map`][map-docs] περιέχει μια λίστα με τις μεθόδους που είναι διαθέσιμες στη διεπαφή `Map`.

## 1. Επιστροφή των κωδικών σε ένα Map

- Θα χρειαστεί να ορίσεις ένα `Map` με [τέτοιο τρόπο][declaring-members] ώστε να μπορείς να το χρησιμοποιήσεις στις μεθόδους της κλάσης.

## 2. Προσθήκη καταχωρήσεων στο λεξικό

- Τα Map έχουν μια [μέθοδο][map-put-docs] για να προσθέτεις και να ενημερώνεις την τιμή ενός κλειδιού.

## 3. Αναζήτηση της χώρας ενός κωδικού κλήσης

- Τα Map έχουν μια [μέθοδο][map-get-docs] για να παίρνεις την τιμή ενός κλειδιού.

## 4. Να μην επιτρέπονται τα διπλότυπα

- Υπάρχει τρόπος να ελέγξεις αν το Map έχει ένα [κλειδί][map-contains-key-docs] ή μια [τιμή][map-contains-value-docs].

## 5. Εύρεση του κωδικού κλήσης μιας χώρας

- Υπάρχει ένας [τρόπος][map-entry-set-docs] να πάρεις μια επαναλήψιμη συλλογή από καταχωρήσεις ενός Map, που σου επιτρέπει να διατρέξεις τα ζεύγη κλειδιού-τιμής.

## 6. Ενημέρωση του κωδικού κλήσης μιας χώρας

- Μην ξεχάσεις ότι ο προηγούμενος κωδικός κλήσης της χώρας θα βρίσκεται μέσα στο Map.
- Υπάρχει μια [μέθοδος][map-remove-docs] για να αφαιρέσεις μια καταχώρηση από το Map.
