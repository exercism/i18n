# Οδηγίες ειδικά για SQLite

Η στήλη **result** πρέπει να περιέχει ένα αντικείμενο με αντικείμενα, κωδικοποιημένο σε JSON, όπου κάθε λέξη είναι κλειδί και το πλήθος της ακέραιος αριθμός.

Για παράδειγμα, πάρε την παραπάνω πρόταση: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
Το **result** για αυτή την είσοδο πρέπει να είναι:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Σχήμα πίνακα

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
