# Εισαγωγή

## Enum

Ένας _τύπος enum_ είναι ένας ειδικός τύπος δεδομένων που επιτρέπει σε μια μεταβλητή να είναι ένα σύνολο προκαθορισμένων σταθερών.
Η μεταβλητή πρέπει να είναι ίση με μία από τις τιμές που έχουν προκαθοριστεί για αυτήν.
Συνήθη παραδείγματα περιλαμβάνουν τις κατευθύνσεις της πυξίδας (τιμές των `NORTH`, `SOUTH`, `EAST` και `WEST`) και τις ημέρες της εβδομάδας.

Επειδή είναι σταθερές, τα ονόματα των πεδίων ενός τύπου enum είναι με κεφαλαία γράμματα.

### Ορισμός ενός τύπου enum

Στη γλώσσα προγραμματισμού Java, ορίζεις έναν τύπο enum χρησιμοποιώντας τη λέξη-κλειδί `enum`.
Για παράδειγμα, θα όριζες έναν τύπο enum για τις ημέρες της εβδομάδας ως εξής:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Θα πρέπει να χρησιμοποιείς τύπους enum κάθε φορά που χρειάζεται να αναπαραστήσεις ένα σταθερό σύνολο σταθερών.
Αυτό περιλαμβάνει φυσικούς τύπους enum, όπως οι πλανήτες του ηλιακού μας συστήματος και σύνολα δεδομένων όπου γνωρίζεις όλες τις πιθανές τιμές σε χρόνο μεταγλώττισης, για παράδειγμα, τις επιλογές σε ένα μενού, σημαίες γραμμής εντολών και ούτω καθεξής.

### Χρήση ενός τύπου enum

Ακολουθεί κώδικας που σου δείχνει πώς να χρησιμοποιήσεις το enum `DayOfWeek` που ορίστηκε παραπάνω:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Προσθήκη μεθόδων και πεδίων

Οι τύποι enum της γλώσσας προγραμματισμού Java είναι πολύ πιο ισχυροί από τους αντίστοιχούς τους σε άλλες γλώσσες.
Η δήλωση `enum` ορίζει μια _κλάση_ (που ονομάζεται _τύπος enum_).
Το σώμα της κλάσης enum μπορεί να περιλαμβάνει μεθόδους και άλλα πεδία:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Καλώντας τη μέθοδο `getNumberOfStars` σε ένα μέλος του τύπου enum `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
