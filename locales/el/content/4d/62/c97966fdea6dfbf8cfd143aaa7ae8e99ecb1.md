# Σχετικά

Οι προσδιοριστές κλάσης αποθήκευσης αφορούν τον τρόπο με τον οποίο οι μεταβλητές αποθηκεύονται στη μνήμη.
Σχετίζονται στενά με τη διάρκεια αποθήκευσης (που αναφέρεται και ως διάρκεια ζωής) μιας τιμής.

## auto: η προεπιλεγμένη κλάση αποθήκευσης για μεταβλητές εμβέλειας συνάρτησης ή μπλοκ

Επειδή οι μεταβλητές που ορίζονται μέσα σε ένα μπλοκ ή μια συνάρτηση είναι `auto` από προεπιλογή, δεν είναι συνηθισμένο να χρησιμοποιείται ρητά ο όρος.
Ένας ακόμη λόγος που το `auto` αποφεύγεται συχνά είναι ότι έχει διαφορετική σημασία στη C++.
Οι βάσεις κώδικα που συνδυάζουν C και C++ μπορεί να είναι λιγότερο μπερδεμένες αν αποφεύγουν τον προσδιοριστή αποθήκευσης `auto`.
Η διάρκεια ζωής μιας μεταβλητής `auto` ξεκινά όταν εισέρχεται στο μπλοκ της και τελειώνει όταν εξέρχεται από αυτό.
Σε μια μεταβλητή `auto` δεσμεύεται μνήμη, _αλλά χωρίς προεπιλεγμένη τιμή_, όταν εισέρχεται στο μπλοκ της.
Εξαίρεση αποτελούν οι πίνακες μεταβλητού μήκους (VLAs).
Η δέσμευση ενός VLA γίνεται στο σημείο όπου δηλώνεται ή ορίζεται μέσα στο μπλοκ του και τελειώνει όταν εξέρχεται από το μπλοκ.
Μια μεταβλητή `auto` μπορεί να αρχικοποιηθεί με οποιαδήποτε έγκυρη έκφραση.

## static: ο προσδιοριστής αποθήκευσης που δεν πρέπει να συγχέεται με τον τύπο σύνδεσης static

Μια μεταβλητή που ορίζεται έξω από ένα μπλοκ ή μια συνάρτηση έχει εμβέλεια αρχείου και πάντα έχει στατική διάρκεια αποθήκευσης.
Η εμβέλεια αρχείου σημαίνει ότι είναι προσβάσιμη οπουδήποτε μέσα στο αρχείο.
Η στατική αποθήκευση σημαίνει ότι υπάρχει από την αρχή της εκτέλεσης του προγράμματος μέχρι το τέλος.
Εκτός αν αρχικοποιηθεί ρητά, μια μεταβλητή `static` αρχικοποιείται με την προεπιλεγμένη μηδενική τιμή της.
Αν μια μεταβλητή εμβέλειας αρχείου χαρακτηριστεί με `static`, το `static` αναφέρεται στη σύνδεσή της.
Μια μεταβλητή εμβέλειας αρχείου που χαρακτηρίζεται `static` έχει εσωτερική σύνδεση, που σημαίνει ότι είναι προσβάσιμη μόνο μέσα στο αρχείο.
Αν μια μεταβλητή ορίζεται μέσα σε μια συνάρτηση ή σε ένα μπλοκ μέσα σε μια συνάρτηση και χαρακτηρίζεται `static`, έχει `static` διάρκεια αποθήκευσης.
Η τιμή της μεταβλητής `static` διατηρείται ανάμεσα στις κλήσεις της συνάρτησης ή του μπλοκ.

Στο παρακάτω παράδειγμα βλέπουμε δύο μεταβλητές `static` σε δράση.
Η πρώτη μεταβλητή `count` ορίζεται μέσα στη συνάρτηση `print_stuff` και διατηρεί την τιμή της ανάμεσα στις κλήσεις της συνάρτησης.
Η δεύτερη μεταβλητή `count` ορίζεται μέσα σε ένα αυθαίρετο μπλοκ και κρύβει (ή επισκιάζει) την πρώτη μεταβλητή `count` μέσα στο μπλοκ της.
Η δεύτερη μεταβλητή `count` διατηρεί ανεξάρτητα την τιμή της ανάμεσα στις εισόδους στο μπλοκ.

```c
#include <stdio.h>

void print_stuff(void) {
    // static variable is initialized to 0
    static int count;
    count++;
    printf("function count is %d\n", count);
    {
        // static variable is initialized to 0
        static int count;
        count++;
        printf("block count is %d\n", count);
    }
}

int main() {
    // prints
    // function count is 1
    // block count is 1
    print_stuff();
    // prints
    // function count is 2
    // block count is 2    
    print_stuff();
}
```

Αν μια μεταβλητή `static` αρχικοποιηθεί ρητά, αυτό πρέπει να γίνει με μια σταθερή έκφραση.
Μια σταθερή έκφραση είναι μια έκφραση που μπορεί να υπολογιστεί σε χρόνο μεταγλώττισης.

## extern: πώς να αποκτήσεις πρόσβαση σε μια μεταβλητή σε άλλη μονάδα μετάφρασης

Μια μονάδα μετάφρασης αποτελείται από ένα αρχείο πηγαίου κώδικα και οποιοδήποτε άλλο αρχείο περιλαμβάνει με `#include`.
Αν και μια μεταβλητή με εμβέλεια αρχείου μπορεί να δηλωθεί και να αρχικοποιηθεί ως `extern`, η λέξη-κλειδί `extern` συνήθως χρησιμοποιείται για να αναφερθεί σε μια υπάρχουσα μεταβλητή, όχι για να ορίσει μια νέα.
Η μεταβλητή στην οποία αναφέρεται το `extern` πρέπει να έχει εμβέλεια αρχείου.
Μια μεταβλητή σε εμβέλεια αρχείου έχει πάντα `static` αποθήκευση.
Μια μεταβλητή σε ένα αρχείο που περιλαμβάνεται πρέπει να έχει εξωτερική σύνδεση για να είναι προσβάσιμη από το αρχείο που την περιλαμβάνει.

Στο παρακάτω παράδειγμα χρησιμοποιούμε τη μεταβλητή `val` που δηλώνεται ως `extern`, ώστε να αναφέρεται στο `val` που ορίζεται στην εμβέλεια του αρχείου της.
Και οι δύο χρήσεις του `extern` ονομάζονται δηλώσεις αναφοράς, καθώς αναφέρονται σε μια μεταβλητή που ορίζεται αλλού.

```c
#include <stdio.h>

void set_val() {
    // this declares val which is defined elsewhere
    extern int val;
    val += 42;
    // prints val is 42
    printf("val is %d\n", val);
}

int main() {
    set_val();
    // this declares val which is defined elsewhere
    extern int val;
    val += 42;
    // prints val is 84
    printf("val is %d\n", val);
}
// this value could be defined in another source file.
// as a variable with static storage, it is initialized to zero
int val;
```

Αν αφαιρούνταν και οι δύο λέξεις-κλειδιά `extern`, το πρόγραμμα μπορεί να τύπωνε κάτι σαν

```
val is 22038
val is 42
```

Μια τέτοια έξοδος δείχνει ότι κάθε δήλωση του `val` χωρίς `extern` είναι μια δήλωση ορισμού και είναι ανεξάρτητη από τις άλλες δηλώσεις του `val`.
Η πλήρης αφαίρεση των δηλώσεων του `val` από τις `set_val` και `main` θα είχε ως αποτέλεσμα ένα σφάλμα μεταγλώττισης ότι το `val` δεν έχει δηλωθεί στις `set_val` και `main`.

Αν μια μεταβλητή που αναφέρεται ως `extern` βρίσκεται στο ίδιο αρχείο, μπορεί να έχει είτε εσωτερική είτε εξωτερική σύνδεση.
Ο ορισμός του `val` ως `static int val;` δεν θα είχε καμία επίδραση στη χρήση του `val` στις `set_val` ή `main`, εκτός από το ότι ο ορισμός θα έπρεπε να μετακινηθεί πάνω από αυτές για να μεταγλωττιστεί.
Αλλά αν το `val` οριζόταν πάνω από τις συναρτήσεις, δεν θα χρειαζόταν να δηλώσουν το `val` ως `extern`.

Το παρακάτω θα δούλευε

```c
#include <stdio.h>

// val defining declaration before the function definitions
static int val;

void set_val() {
    val += 42;
    // prints val is 42
    printf("val is %d\n", val);
}

int main() {
    set_val();
    val += 42;
    // prints val is 84
    printf("val is %d\n", val);
}
```

Το `static` θα μπορούσε να αφαιρεθεί από το `static int val;`, δίνοντας στο `val` εξωτερική σύνδεση,  και το `val` θα λειτουργούσε ακόμα το ίδιο στις `set_val` και `main`.
Αν ένα άλλο αρχείο πηγαίου κώδικα περιλάμβανε αυτό το αρχείο, θα μπορούσε να χρησιμοποιήσει το `val` μόνο αν το `val` είχε εξωτερική σύνδεση (δεν είχε δηλωθεί ως `static`) και το άλλο αρχείο δήλωνε `extern int val;`.

Μια μεταβλητή στην οποία αναφέρεται το `extern` δεν πρέπει μόνο να έχει `static` αποθήκευση, αλλά πρέπει επίσης να έχει εμβέλεια αρχείου.
Το παρακάτω παράδειγμα πιθανότατα δεν θα μεταγλωττιστεί, επειδή το `val`, αν και `static`, δεν έχει εμβέλεια αρχείου.

```c
#include <stdio.h>

void set_val() {
    // defined with static storage, but not in file scope
    static int val;
    val += 42;
    printf("val is %d\n", val);
}

int main() {
    set_val();
    extern int val;
    printf("val is %d\n", val);
}
```

## register: πώς να επιταχύνεις ενδεχομένως την πρόσβαση σε μια μεταβλητή

Μια μεταβλητή που χαρακτηρίζεται ως `register` εκφράζει την επιθυμία του προγραμματιστή να τοποθετηθεί η τιμή σε έναν καταχωρητή για γρήγορη πρόσβαση.
Μια μεταβλητή `register` είναι σαν μια μεταβλητή `auto` στο ότι πρέπει να βρίσκεται σε εμβέλεια συνάρτησης ή μπλοκ.
Επειδή η τιμή προορίζεται να τοποθετηθεί σε έναν καταχωρητή αντί για τη μνήμη, η πρόσβαση στη διεύθυνση της μεταβλητής θα έπρεπε να απαγορεύεται από τον μεταγλωττιστή, καθώς η διεύθυνση ενός καταχωρητή δεν μπορεί να ληφθεί.
Ωστόσο, μια διεύθυνση μνήμης μπορεί η ίδια να τοποθετηθεί σε έναν καταχωρητή.
Το παρακάτω παράδειγμα το δείχνει αυτό

```c
#include <stdio.h>

int main() {
    int i = 42;
    register int *i_ptr = &i;
    // prints i is 42, i_ptr is 0x7ffd0c2055c4 (or some other address)
    printf("i is %d, i_ptr is %p", i, i_ptr);
}
```

register` είναι ουσιαστικά μια υπόδειξη, καθώς οι μεταγλωττιστές είναι ελεύθεροι να επιλέξουν αν θα ακολουθήσουν αυτόν τον προσδιοριστή ή όχι, οπότε η τιμή μπορεί ή όχι να τοποθετηθεί πραγματικά σε έναν καταχωρητή.

## typedef: ο προσδιοριστής κλάσης αποθήκευσης που δεν είναι πραγματικά

Το `typedef` περιγράφεται ως προσδιοριστής κλάσης αποθήκευσης μόνο για συντακτικούς λόγους.
Αυτό συμβαίνει επειδή ένας προσδιοριστής κλάσης αποθήκευσης δεν μπορεί να χρησιμοποιηθεί με έναν άλλο προσδιοριστή κλάσης αποθήκευσης.
Έτσι, το `typedef auto int i = 42;` είναι εξίσου παράνομο με το `static auto int i = 42;`.
