# Εγκατάσταση

## Ubuntu (και οι περισσότερες άλλες διανομές που βασίζονται στο Debian)

Για να χτίσεις τον κώδικα τοπικά, θα χρειαστείς τα gcc και make, τα οποία μπορείς να εγκαταστήσεις με

```shell
sudo apt install gcc make
```

Αν δεν τρέχεις σε υλικό ARM64, εγκατέστησε τον εξομοιωτή [QEMU][] και το cross-toolchain GCC για ARM64 με

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Χρησιμοποίησε το [Windows Subsystem for Linux][] με μια διανομή που βασίζεται στο Debian και ακολούθησε τις οδηγίες για Ubuntu παραπάνω.
Εναλλακτικά, στήσε μια εικονική μηχανή Linux.

## macOS

Μπορείς να ξεκινήσεις μια εικονική μηχανή Linux με οποιαδήποτε κατάλληλη λύση εικονικοποίησης (π.χ. [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
