# Εισαγωγή

Κάθε στιγμιότυπο ενός struct ή μιας κλάσης έχει μια σιωπηρή τιμή με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο. Το `self` έχει πολλές χρήσεις, αλλά τις περισσότερες φορές χρησιμοποιείται για να ξεκαθαρίζει τα ονόματα των ιδιοτήτων και των μεθόδων του struct ή της κλάσης, όταν μπορεί να δημιουργηθεί σύγχυση.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```
