# Συμβουλές

## 1. Βρες τη θέση μιας κάρτας

- Οι θέσεις στον πίνακα ξεκινούν από το `0`.
- Υπάρχει μια [ενσωματωμένη][indexof_method_docs] μέθοδος για να πάρεις τη θέση μιας τιμής.

## 2. Προσδιόρισε αν υπάρχει μια κάρτα

- Υπάρχει μια [ενσωματωμένη][includes_method_docs] μέθοδος για να ελέγξεις αν η τιμή υπάρχει στον πίνακα

## 3. Προσδιόρισε αν κάθε κάρτα είναι ζυγή

- Υπάρχει μια [ενσωματωμένη][every_method_docs] μέθοδος για να ελέγξεις αν κάθε τιμή περνάει ένα κατηγόρημα

## 4. Έλεγξε αν η στοίβα περιέχει κάρτα με μονή τιμή

- Υπάρχει μια [ενσωματωμένη][some_method_docs] μέθοδος για να ελέγξεις αν τουλάχιστον μία τιμή περνάει ένα κατηγόρημα

## 5. Πάρε την πρώτη μονή κάρτα από τη στοίβα

- Υπάρχει μια [ενσωματωμένη][find_method_docs] μέθοδος για να πάρεις το πρώτο στοιχείο που περνάει ένα κατηγόρημα

## 6. Προσδιόρισε τη θέση της πρώτης κάρτας που είναι ζυγή

- Υπάρχει μια [ενσωματωμένη][findindex_method_docs] μέθοδος για να πάρεις την πρώτη θέση στον πίνακα όπου η τιμή
