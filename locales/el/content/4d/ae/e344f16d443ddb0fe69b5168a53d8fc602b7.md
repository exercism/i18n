# Εισαγωγή

## Συναρτήσεις callback

Οι συναρτήσεις callback είναι συναρτήσεις που περνιούνται ως ορίσματα.
Αυτό το μοτίβο προγραμματισμού δημιουργεί μια ακολουθία κλήσεων συναρτήσεων, τόσο στον σύγχρονο όσο και στον ασύγχρονο προγραμματισμό.
Το να γράψεις μια συνάρτηση callback δεν διαφέρει από το να γράψεις οποιαδήποτε συνάρτηση. Ωστόσο, η συνάρτηση callback πρέπει να ταιριάζει με την υπογραφή που ορίζει η συνάρτηση που την καλεί.

```javascript
const squareLength = 5;

// Caller function takes a callback function
function applyToSquare(callback) {
  return callback(squareLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(number) {
  return number * number;
}

applyToSquare(areaOfSquare); // => 25
```

Μπορείς επίσης να γράψεις callbacks ως έκφραση συνάρτησης, ως ανώνυμη έκφραση συνάρτησης ή ως έκφραση συνάρτησης βέλους:

```javascript
applyToSquare(function squarePerimeter(side) {
  return side * 4;
});

applyToSquare(function (side) {
  return side * 4;
});

applyToSquare((side) => {
  return side * 4;
});
```
