# Υποδείξεις

## 1. Πάρε το πρώτο γράμμα του τίτλου

- Υπάρχει [μια μέθοδος][index] που επιστρέφει ένα `Char` από μια `String` σε μια δεδομένη θέση.

## 2. Πάρε τα αρχικά των συγγραφέων

- Μπορείς να χρησιμοποιήσεις μεθόδους που έχουν ήδη υλοποιηθεί για να πάρεις το πρώτο γράμμα μιας `String`.
- Για να συνδυάσεις τιμές σε μια `String`, μπορείς να χρησιμοποιήσεις [παρεμβολή συμβολοσειρών][string-interpolation].

## 3. Αποκρυπτογράφησε το γράμμα

- Υπάρχει [μια μέθοδος][uppercase] για να ελέγξεις αν ένα `Char` είναι κεφαλαίο.
- Υπάρχει [μια μέθοδος][ord] για να πάρεις το σημείο κώδικα ενός `Char`.

## 4. Αποκρυπτογράφησε το κείμενο

- Μπορείς να χρησιμοποιήσεις [επανάληψη][while] για να τρέξεις κώδικα πολλές φορές.
