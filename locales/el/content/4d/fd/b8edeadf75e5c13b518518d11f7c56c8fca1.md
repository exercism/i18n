# Σχετικά

Η Ruby είναι μια δυναμική γλώσσα προγραμματισμού ανοιχτού κώδικα, με έμφαση στην απλότητα και την παραγωγικότητα. Έχει κομψή σύνταξη που διαβάζεται φυσικά και γράφεται εύκολα.

Η Ruby δημιουργήθηκε ως μια γλώσσα με προσεκτικές ισορροπίες. Ο δημιουργός της, [Yukihiro "Matz" Matsumoto](https://en.wikipedia.org/wiki/Yukihiro_Matsumoto), συνδύασε κομμάτια από τις αγαπημένες του γλώσσες (Perl, Smalltalk, Eiffel, Ada και Lisp) για να σχηματίσει μια νέα γλώσσα που ισορροπούσε τον συναρτησιακό με τον προστακτικό προγραμματισμό.

Έχει πει συχνά ότι «προσπαθεί να κάνει τη Ruby φυσική, όχι απλή», με τρόπο που να αντικατοπτρίζει τη ζωή.

Στη συνέχεια προσθέτει: «Η Ruby είναι απλή στην εμφάνιση, αλλά πολύ σύνθετη εσωτερικά, ακριβώς όπως το ανθρώπινο σώμα μας».

Μπορείς να διαβάσεις περισσότερα για τη γλώσσα Ruby [στην ιστοσελίδα της](https://www.ruby-lang.org/en/about/).
