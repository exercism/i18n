# Εισαγωγή

Σε προηγούμενες έννοιες αναφέρθηκε ότι η οδηγία `global` κάνει μια συνάρτηση ή μεταβλητή που έχει οριστεί σε ένα αρχείο πηγαίου κώδικα ορατή σε άλλα αρχεία.
Παρομοίως, η οδηγία `extern` ενημερώνει τον assembler ότι μια συνάρτηση ή μεταβλητή που χρησιμοποιείται στο τρέχον αρχείο πηγαίου κώδικα έχει οριστεί σε κάποιο άλλο.

Αυτές οι δύο οδηγίες είναι ο κύριος τρόπος με τον οποίο ο κώδικας assembly συνεργάζεται με άλλα αρχεία πηγαίου κώδικα για να επιτύχει τμηματοποίηση.

Για τους σκοπούς αυτών των οδηγιών, δεν έχει σημασία αν ο εξωτερικός κώδικας ορίζεται ή χρησιμοποιείται σε assembly ή σε γλώσσα υψηλού επιπέδου.
Έτσι, για παράδειγμα, ακόμη και μια συνάρτηση που έχει οριστεί σε γλώσσα υψηλού επιπέδου μπορεί να χρησιμοποιηθεί σε κώδικα x86-64 αν δηλωθεί ως `extern`.

Με τον ίδιο τρόπο, η σύμβαση κλήσης είναι κοινή για όλες αυτές τις συναρτήσεις, είτε έχουν οριστεί σε assembly είτε σε γλώσσες υψηλού επιπέδου, ακόμη και με το Λειτουργικό Σύστημα (ΛΣ).

Ωστόσο, επειδή στο assembly τα δεδομένα είναι απλώς μια ακολουθία από bytes, είναι σημαντικό να γνωρίζεις πώς η γλώσσα υψηλού επιπέδου με την οποία συνεργάζεσαι διαχειρίζεται τη μνήμη.

## Τύποι της C

Η γλώσσα C είναι μια συνηθισμένη επιλογή ως γλώσσα υψηλού επιπέδου για να συνεργαστείς με κώδικα assembly.
Κάνει το έργο της αλληλεπίδρασης με το ΛΣ ευκολότερο, προσφέροντας wrappers υψηλού επιπέδου για πολλές σημαντικές εργασίες, όπως η εκτύπωση στην οθόνη, η ανάγνωση από το πληκτρολόγιο ή η δέσμευση δυναμικής μνήμης.

Σε αυτό το track, τα tests είναι γραμμένα σε C, οπότε είναι σημαντικό να δώσουμε μια γενική επισκόπηση της γλώσσας.

~~~~exercism/note
Οποιοσδήποτε από τους τύπους που αναφέρονται παρακάτω μπορεί να χαρακτηριστεί με `const`.
Αυτό τους κάνει μόνο για ανάγνωση.
~~~~

### Αρχέγονοι τύποι

Υπάρχουν πολλοί αρχέγονοι τύποι στη C και το μέγεθός τους, σε bytes, μπορεί να ποικίλλει.
Κάποιοι από αυτούς συνοψίζονται στον παρακάτω πίνακα, με το τυπικό μέγεθός τους σε ένα σύστημα x86-64:

| τύπος     | αριθμός bytes   | ακέραιος/κινητής υποδιαστολής |
|-----------|-----------------|------------------------|
| _Bool     | 1               | ακέραιος               |
| char      | 1               | ακέραιος               |
| short     | 2               | ακέραιος               |
| int       | 4               | ακέραιος               |
| long      | 4 ή 8           | ακέραιος               |
| long long | 8               | ακέραιος               |
| float     | 4               | κινητής υποδιαστολής   |
| double    | 8               | κινητής υποδιαστολής   |

Καθένας από αυτούς τους ακέραιους τύπους μπορεί να είναι προσημασμένος (η προεπιλογή) ή απροσήμαντος.
Αν είναι απροσήμαντοι, αυτό πρέπει να δηλωθεί, για παράδειγμα: `unsigned int`.

Υπάρχουν ψευδώνυμα για τους ακέραιους τύπους, που έχουν οριστεί για να παρέχουν ακριβή έλεγχο του μεγέθους τους:

| ψευδώνυμο | αριθμός bytes |
|---------|-----------------|
| int8_t  | 1               |
| int16_t | 2               |
| int32_t | 4               |
| int64_t | 8               |

Αυτά τα ψευδώνυμα μπορούν να έχουν πρόθεμα `u` για να δηλώσουν απροσήμαντο τύπο, για παράδειγμα: `uint64_t`.

Άλλα αξιοσημείωτα ψευδώνυμα είναι:

| ψευδώνυμο  | τύπος                                          |
|--------|-----------------------------------------------|
| bool   | _Bool                                         |
| size_t | συνήθως ένας απροσήμαντος ακέραιος 8 bytes    |

Το `_Bool`, ή το ψευδώνυμό του `bool`, είναι μοναδικό στο ότι, παρόλο που καταλαμβάνει 1 ολόκληρο byte, μπορεί να πάρει μόνο μία από δύο τιμές: `true` (`1`) και `false` (`0`).

Οι τιμές αυτών των αρχέγονων τύπων περνούν ως ορίσματα σε συναρτήσεις και επιστρέφονται από αυτές σύμφωνα με τους συνήθεις κανόνες για ακέραιες τιμές και τιμές κινητής υποδιαστολής.

### Απαριθμήσεις

Μια **enum** είναι ένας τύπος που μπορεί να πάρει ένα από έναν αριθμό ρητά δηλωμένων στοιχείων:

```c
enum example {
    example_1,
    example_2,
    example_3,
    example_4
};
```

Στη C, οι enum μετατρέπονται σιωπηρά σε έναν ακέραιο τύπο, που είναι συνήθως `int`, δηλαδή ένας ακέραιος 4 bytes.

Από προεπιλογή, το πρώτο δυνατό στοιχείο μιας enum μετατρέπεται σε `0` και όλα τα επόμενα στοιχεία μετατρέπονται στον επόμενο ακέραιο.
Έτσι, στην `enum example` που ορίστηκε παραπάνω, το `example_1` θα είχε τιμή `0`, το `example_2` θα είχε τιμή `1` και ούτω καθεξής.

Είναι δυνατό να δηλώσεις την τιμή για οποιοδήποτε στοιχείο μιας enum και τότε, από προεπιλογή, το επόμενο στοιχείο θα έχει ως τιμή τον επόμενο ακέραιο:

```c
enum example_2 {
    example_1 = 4,
    example_2 = 8,
    example_3
}; // example_3 is equal to 9
```

### Διευθύνσεις μνήμης

Στη C, μια διεύθυνση μνήμης αναφέρεται μέσω ενός **δείκτη** προς έναν τύπο και συμβολίζεται με τον τελεστή `*`.
Έτσι, για παράδειγμα, το `int64_t *` αναφέρεται σε μια θέση μνήμης για ένα ή περισσότερα `int64_t`.

Οι διευθύνσεις αντιμετωπίζονται ως ακέραιοι 8 bytes, όπως συνήθως.

### Πίνακες

Οι πίνακες περνούν ως ορίσματα σε συναρτήσεις και επιστρέφονται από αυτές ως δείκτες προς το πρώτο τους στοιχείο.

```c
int64_t example_arr[] = {1, 2, 3}; // this is an array of 3 signed 8-byte integers
fn(example_arr); // this is a function that passes a pointer (int64_t *) to the beginning of the array as an argument
```

Κάθε στοιχείο σε έναν πίνακα έχει το μέγεθος του τύπου στοιχείου του πίνακα.
Ο `example_arr` που ορίστηκε παραπάνω, για παράδειγμα, έχει 3 στοιχεία των 8 bytes το καθένα, δηλαδή 24 bytes συνολικά.

Επειδή οι πίνακες δεν αποθηκεύουν το μήκος τους, συνήθως χρειάζεται μια ξεχωριστή τιμή που να δηλώνει τον αριθμό των στοιχείων, εκτός αν μια τιμή-φρουρός σηματοδοτεί το τέλος.

### Συμβολοσειρές

Οι συμβολοσειρές στη C είναι ένας πίνακας από `char`, που είναι ένας τύπος 1 byte.
Οι περισσότερες συμβολοσειρές αποτελούνται από χαρακτήρες ASCII και τερματίζονται με NUL, οπότε τελειώνουν όταν βρεθεί ένα byte με τιμή `0`.
Αυτό σημαίνει ότι το μήκος μιας συμβολοσειράς συνήθως δεν χρειάζεται να περαστεί ως ξεχωριστό όρισμα.
