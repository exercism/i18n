# Παράρτημα οδηγιών

## Σημείωση

Χτίσε αυτή την άσκηση κομμάτι κομμάτι και μη διστάσεις να ξεχωρίσεις χρήσιμες έννοιες σε μια νέα κλάση.
Οι προηγούμενες ασκήσεις θα πρέπει να σου δώσουν τη βάση για μια κομψή λύση.

Μπορεί επίσης να σου φανεί χρήσιμο να ξαναδείς κεφάλαια για την αντικειμενοστραφή σκέψη, για παράδειγμα [Inside Smalltalk - Chapter 1](http://sdmeta.gforge.inria.fr/FreeBooks/InsideST/InsideSmalltalk.pdf) ή [Smalltalk by Example - Chapter 9](http://sdmeta.gforge.inria.fr/FreeBooks/ByExample/11%20-%20Chapter%209%20-%20Object-Oriente.pdf)
