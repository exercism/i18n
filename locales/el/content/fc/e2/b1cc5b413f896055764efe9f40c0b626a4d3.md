# Χάρτες και Σύνολα

| Τύπος | Περιέχει | Αναζήτηση με |
| --- | --- | --- |
| `ARRAY{T}` | τιμές με σειρά | θέση |
| `FMAP{K,T}` | ζεύγη κλειδιού-στόχου | κλειδί |
| `FSET{T}` | τιμές, χωρίς επαναλήψεις | ιδιότητα μέλους |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

Το `m["emu"]` **δεν** είναι ο τρόπος να διαβάσεις έναν χάρτη. Το `FMAP` δεν έχει τέτοια ρουτίνα και αυτή η γραμμή δεν θα μεταγλωττιστεί. Το σωστό είναι `get`.

### Κλειδιά που Λείπουν

Το `get` για ένα κλειδί που δεν υπάρχει απαντά με την κενή τιμή για τον τύπο αντί να παραπονεθεί: `0`, `false` ή void. Ένα void `STR` δεν θα αποτύχει εκεί όπου παράγεται. Θα αποτύχει αργότερα, όπου κι αν χρησιμοποιηθεί στο τέλος. Το να καλείς πρώτα το `has_ind` είναι η συνήθεια που αξίζει να αποκτήσεις.

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

Τα σύνολα συνδυάζονται:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## Επανάθεση και Αντιγραφή

Το `insert` και το `delete` απαντούν με το δοχείο που θα χρησιμοποιήσεις από εδώ και πέρα. Συνήθως είναι το ίδιο αντικείμενο, αλλαγμένο επί τόπου. Όταν χρειάζεται να μεγαλώσει, είναι ένα νέο, μεγαλύτερο. Άρα:

```sather
   m := m.insert(k, v);     -- always
```

και το όνομα στα αριστερά είναι το μόνο που μπορείς να εμπιστευτείς μετά. Ένα άλλο όνομα για τον ίδιο χάρτη, παρμένο πριν από το `insert`, μπορεί να είναι ξεπερασμένο.

Για να κρατήσεις ένα ανεξάρτητο αντίγραφο, πάρε πρώτα ένα:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

με μία παγίδα: ένας χάρτης στον οποίο δεν έχει εισαχθεί ποτέ τίποτα είναι **void**, και το `copy` σε έναν void χάρτη αποτυγχάνει. Τα `insert`, `get`, `has_ind` και `size` τα βγάζουν πέρα με έναν void χάρτη (το `#FMAP{K,T}` είναι void, και η εισαγωγή σε αυτόν είναι ο τρόπος με τον οποίο ένας χάρτης πρωτοδημιουργείται), αλλά το `copy` όχι.

Τα `HMAP` και `HSET` είναι οι εκδοχές που αλλάζουν πάντα μόνο επί τόπου. Είναι πιο γρήγορες για να χτίσεις κάτι μεγάλο, αλλά είναι λάθος προεπιλογή όσο μαθαίνεις.

## Διάσχιση

| Επαναλήπτης | Δίνει |
| --- | --- |
| `m.ind!` | κάθε κλειδί |
| `m.target!` | κάθε στόχο |
| `m.pair!` | κάθε κλειδί και στόχο μαζί |
| `s.elt!` | κάθε τιμή ενός συνόλου |

Ούτε ο χάρτης ούτε το σύνολο έχουν σειρά. Δύο εκτελέσεις μπορεί να τα διατρέξουν με διαφορετικό τρόπο, οπότε μη γράψεις ποτέ κάτι που εξαρτάται από το ποιο έρχεται πρώτο.

```sather
   loop
      #OUT + guide.ind! + "\n";
   end;
```
