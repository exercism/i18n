# Εισαγωγή

Η εντολή `guard` στη Swift χρησιμοποιείται για πρόωρες επιστροφές από συναρτήσεις Swift όταν μια απαραίτητη συνθήκη, που πρέπει να πληρούται για να συνεχιστεί η περαιτέρω επεξεργασία, δεν πληρούται, π.χ.:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Εδώ, η εντολή `guard` ελέγχει αν η έκφραση Boolean που ακολουθεί τη λέξη-κλειδί `guard` αξιολογείται ως αληθής. Αν ναι, τότε η επεξεργασία συνεχίζεται με τον κώδικα που ακολουθεί την εντολή `guard` (εδώ `let root = myValue.squareRoot()`. Διαφορετικά, θα εκτελέσει τον κώδικα στη ρήτρα else. Σε αντίθεση με μια εντολή `if`, μια εντολή `guard` _πρέπει_ να έχει ρήτρα else, και σε αντίθεση με τη ρήτρα else μιας δομής if-else, η ρήτρα else μιας εντολής `guard` _πρέπει_ να εξέρχεται από την εμβέλεια της εντολής `guard`. Δηλαδή, πρέπει να χρησιμοποιεί μια εντολή μεταφοράς ελέγχου, όπως `return`, `continue`, `break`, ή πρέπει να πετάει ένα σφάλμα ή να τερματίζει το πρόγραμμα.
