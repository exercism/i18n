# Οδηγίες

Ξεκινάμε μια λέσχη τυριού, η οποία θα χρησιμοποιεί μηχανική μάθηση για να επιλέγει νέα τυριά και να τα προσφέρει στους πελάτες που αγαπούν το τυρί, με βάση το ιστορικό και τα γούστα τους.

Οι νέοι πελάτες καλούνται να συμπληρώσουν μια αρχική έρευνα, ώστε να συγκεντρώσουμε κάποια βασικά δεδομένα για αρχή.
Μέσα από αυτήν, διαπιστώθηκε ότι υπάρχει ένα υποσύνολο εμφατικών πελατών που δεν έχουν λεπτότητα στις κριτικές τους.
Καθώς αυτό μπορεί να προκαλέσει ανεπανόρθωτη μεροληψία σε έναν πιο εκλεπτυσμένο αλγόριθμο, έχει στηθεί ένας ξεχωριστός αλγόριθμος για να καλύπτει τις ανάγκες τους.
Σου ζητείται να παρέχεις κάποιες βοηθητικές συναρτήσεις για να τακτοποιήσεις τα δεδομένα τους.

~~~~exercism/note
Ενώ μπορεί να υπάρχουν διαφορετικοί τρόποι για να λύσεις τις παρακάτω εργασίες, καθεμία μπορεί να λυθεί με το πολύ δύο συναρτήσεις ανώτερης τάξης.
~~~~

## 1. Κατηγοριοποίησε τους πελάτες

Το σύστημα αξιολόγησης έχει βάση πέντε αστεριών, η οποία αποτελείται απλώς από τους ακέραιους `1:5`.
Οι εμφατικοί πελάτες δίνουν μόνο αξιολογήσεις `1` ή `5`, και θέλουμε να ξέρουμε αν ένας πελάτης εμφανίζει αυτή τη συμπεριφορά.

Υλοποίησε τη συνάρτηση `all_15()`, η οποία δέχεται ένα διάνυσμα αξιολογήσεων και επιστρέφει `true` αν όλες οι αξιολογήσεις είναι `1` ή `5`, και false διαφορετικά.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Ονόμασε τους πελάτες

Πρέπει να συσχετίσουμε το όνομα του πελάτη (ή το ID) με τις αξιολογήσεις του.

Υλοποίησε τη συνάρτηση `name_customers()`, η οποία δέχεται ένα διάνυσμα ονομάτων και μια λίστα αξιολογήσεων και τα "συμπλέκει" σε μια λίστα από λίστες.

Τα στοιχεία της εσωτερικής λίστας πρέπει να έχουν ονόματα `name` και `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Ξεχώρισε τους εμφατικούς πελάτες

Πρέπει να ξεχωρίσουμε τους πιο εμφατικούς πελάτες από τους υπόλοιπους.

Υλοποίησε τη συνάρτηση `emphatics()`, η οποία δέχεται πελάτες και αξιολογήσεις.
Επιστρέφει μια λίστα περιορισμένη σε όσους χρησιμοποιούν μόνο αξιολογήσεις με `1` ή `5` αστέρια.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Μετέτρεψε τις αξιολογήσεις σε δυαδικές

Επειδή οι εμφατικοί πελάτες χρησιμοποιούν μόνο αξιολογήσεις `1` και `5`, θα είναι πιο βολικό υπολογιστικά αν αυτές μετατραπούν σε `0` και `1`.

Υλοποίησε τη συνάρτηση `to_binary()`, η οποία δέχεται ένα διάνυσμα εμφατικών αξιολογήσεων.
Επιστρέφει δυαδικές αξιολογήσεις, όπου το `1` έχει μετατραπεί σε `0` και το `5` έχει μετατραπεί σε `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Υπολόγισε τους μέσους όρους των αξιολογήσεων με την πάροδο του χρόνου

Θέλεις να βελτιώνεις συνεχώς τις προτάσεις για κάθε επιμέρους πελάτη (όχι μόνο για τους εμφατικούς) με την πάροδο του χρόνου, καθώς καταλαβαίνεις καλύτερα τα γούστα τους.

Υλοποίησε τη συνάρτηση `satisfactions()`, η οποία δέχεται ένα διάνυσμα αξιολογήσεων.
Επιστρέφει ένα διάνυσμα με τους αθροιστικούς μέσους όρους των αξιολογήσεων μέχρι αυτό το σημείο.
Στρογγυλοποίησε τα αποτελέσματα σε 2 δεκαδικά ψηφία.

Ας ελπίσουμε ότι οι αριθμοί θα συνεχίσουν να μεγαλώνουν, για ευτυχισμένους πελάτες!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
