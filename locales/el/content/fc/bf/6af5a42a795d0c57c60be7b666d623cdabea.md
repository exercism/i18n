# Char

Το `Char` είναι ένας τύπος δεδομένων στη Crystal που αναπαριστά ένα σημείο κώδικα [Unicode][unicode] 32 bit.
Το μέγεθός τους τα κάνει οικονομικά σε μνήμη και τους δίνει συγκεκριμένες ιδιότητες που δεν έχουν οι συμβολοσειρές.
Δημιουργούνται με απλά εισαγωγικά (`'`) και επιτρέπουν να μπει μέσα μόνο ένα σημείο κώδικα Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Είναι αρκετά συνηθισμένο να δουλεύεις με Chars όταν δουλεύεις με συμβολοσειρές στη Crystal, αφού αρκετές μέθοδοι της κλάσης String επιστρέφουν Chars ή δέχονται Chars ως ορίσματα.
Για παράδειγμα, η μέθοδος [`String#[]`][index] επιστρέφει ένα Char, ή η μέθοδος [`String#chars`][chars] επιστρέφει μια συλλογή από Chars.

## Αύξηση / Μείωση

Επειδή το char είναι ένα σημείο Unicode 32 bit, υποστηρίζει αύξηση και μείωση, κι έτσι αν έχεις το `'a'` μπορείς να πάρεις το `'b'` προσθέτοντας ένα.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Υπάρχει επίσης μια μέθοδος που ονομάζεται [`Char#succ`][succ], η οποία επιστρέφει το επόμενο char στον πίνακα Unicode, και η [`Char#pred`][pred], η οποία επιστρέφει το προηγούμενο char στον πίνακα Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Συνένωση

Επειδή το Char προορίζεται να αναπαριστά μόνο ένα σημείο Unicode 32 bit, δύο chars δεν μπορούν να συνενωθούν.
Επομένως, τα Chars μπορούν να συνενωθούν μόνο με συμβολοσειρές.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Μέθοδοι ιδιοτήτων

Η Crystal έχει μερικές μεθόδους για να παίρνεις πληροφορίες για έναν χαρακτήρα, όπως αν είναι αριθμός ή γράμμα ή αν είναι πεζός ή κεφαλαίος.
Ακολουθεί μια λίστα με μερικές από τις μεθόδους, για την πλήρη λίστα δες το [Char API][char-api]:

| Μέθοδος                         | Περιγραφή                                            |
| ------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]        | Επιστρέφει `true` αν το Char είναι αριθμός           |
| [`Char#letter?`][letter]        | Επιστρέφει `true` αν το Char είναι γράμμα            |
| [`Char#lowercase?`][lowercase]  | Επιστρέφει `true` αν το Char είναι πεζό              |
| [`Char#uppercase?`][uppercase]  | Επιστρέφει `true` αν το Char είναι κεφαλαίο          |
| [`Char#ascii?`][ascii]          | Επιστρέφει `true` αν το Char είναι χαρακτήρας ASCII  |
| [`Char#whitespace?`][whitespace] | Επιστρέφει `true` αν το Char είναι χαρακτήρας κενού |

## Μετατροπή

### Μετατροπή μεταξύ σημείων κώδικα και Chars

Επειδή το Char είναι ένα σημείο Unicode 32 bit, μπορείς να μετατρέψεις μεταξύ Chars και σημείων κώδικα (Int).
Αυτό μπορεί να γίνει με τη μέθοδο [`Char#ord`][ord], η οποία θα επιστρέψει το σημείο κώδικα του Char, ή με τη μέθοδο [`Int#chr`][chr], η οποία θα επιστρέψει το Char του σημείου κώδικα.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Μετατροπή μεταξύ τύπων

Όπως και με τους άλλους τύπους δεδομένων, τα chars έχουν μερικές μεθόδους για μετατροπή μεταξύ τύπων.
Η πιο συνηθισμένη είναι η μέθοδος `Char#to_s`, η οποία μετατρέπει το Char σε συμβολοσειρά. Ωστόσο, υπάρχει επίσης η μέθοδος `Char#to_i`, η οποία μετατρέπει το Char σε Int, και η μέθοδος `Char#to_f`, η οποία μετατρέπει το Char σε Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
