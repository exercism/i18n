# Debug

Όταν μια δοκιμή αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά και για ποια είσοδο.

Η εκτύπωση τιμών και των περιεχομένων των μεταβλητών μπορεί επίσης να βοηθήσει στην κατανόηση του τι συμβαίνει.
Η PHP μπορεί να εκτυπώσει τιμές χρησιμοποιώντας:

- `echo 'Debug message';` για να εμφανίσεις μια συμβολοσειρά της επιλογής σου
- `var_dump($variable);` για να δεις καλύτερα μια τιμή, π.χ. τον τύπο που βλέπει η PHP
