# Υποδείξεις

## Γενικά

- Για να εξάγεις πολλά ορίσματα από τις παραμέτρους της συνάρτησης, μπορείς να τα πακετάρεις με το `...<args>`.
- Για να χρησιμοποιήσεις το rest και το spread, χρησιμοποίησε τον τελεστή `...`.

## 1. Δημιούργησε μια λίστα με όλα τα βαγόνια

- Πολλά ορίσματα στις παραμέτρους της συνάρτησης μπορούν να πακεταριστούν με τη σύνταξη [`...<args>` (spread)][spread-syntax] του τελεστή.

## 2. Μετακίνησε τα δύο πρώτα στοιχεία στο τέλος του πίνακα

- Μπορείς να αποδομήσεις μια σειρά από παραμέτρους χρησιμοποιώντας [μια ανάθεση αποδόμησης (`...`)][destructuring-assignment]. Αυτό σου επιτρέπει να εξάγεις τα δύο πρώτα στοιχεία ενός `array` κρατώντας τα υπόλοιπα άθικτα.
- Για να προσθέσεις έναν άλλο `array` σε έναν υπάρχοντα `array`, μπορείς να χρησιμοποιήσεις τον τελεστή `...` για να κάνεις "spread" τον `array`.

## 3. Πρόσθεσε τις τιμές που λείπουν

- Χρησιμοποιώντας αποδόμηση με τον τελεστή rest (`...`), μπορείς να εξάγεις το πρώτο στοιχείο ενός `array` κρατώντας τα υπόλοιπα άθικτα.
- Για να προσθέσεις έναν άλλο `array` σε έναν υπάρχοντα `array`, μπορείς να χρησιμοποιήσεις τον τελεστή `...` για να κάνεις "spread" τον `array`.

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

- Για να προσθέσεις ένα άλλο `object` σε ένα υπάρχον `object`, μπορείς να χρησιμοποιήσεις τον τελεστή `...` για να κάνεις "spread" το `object`.

## 5. Ξεχώρισε την ώρα άφιξης από τις πληροφορίες δρομολόγησης

- Για να εξάγεις μια τιμή από ένα `object` κρατώντας τα υπόλοιπα άθικτα, μπορείς να χρησιμοποιήσεις τον τελεστή rest (`...`).

[spread-syntax]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Spread_syntax
[destructuring-assignment]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Destructuring_assignment
