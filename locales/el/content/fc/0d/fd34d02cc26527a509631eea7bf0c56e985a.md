# Χαρακτήρες

Ένας **χαρακτήρας** είναι ένα μόνο γράμμα, ψηφίο, κενό ή σημείο. Ο τύπος του
Sather για έναν χαρακτήρα είναι `CHAR`, και ένας χαρακτήρας γράφεται μέσα σε
μονά εισαγωγικά.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Μονά εισαγωγικά για έναν χαρακτήρα, διπλά εισαγωγικά για μια συμβολοσειρά. Τα
`'M'` και `"M"` είναι διαφορετικοί τύποι και δεν μπορούν να ανταλλαγούν.

## Χαρακτήρες μέσα από μια συμβολοσειρά

Μια συμβολοσειρά είναι μια σειρά από χαρακτήρες, και οι αγκύλες φτάνουν σε έναν
χαρακτήρα με τη θέση του, μετρώντας από το μηδέν, όπως ακριβώς σε έναν πίνακα.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Ερωτήματα για έναν χαρακτήρα

| Κλήση | Απάντηση |
| --- | --- |
| `c.is_alpha` | είναι γράμμα; |
| `c.is_digit` | είναι ένα από τα `0`–`9`; |
| `c.is_upper` | είναι κεφαλαίο; |
| `c.is_lower` | είναι πεζό; |

Κάθε μία απαντά `true` ή `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Αλλαγή πεζών και κεφαλαίων

Το `.upper` δίνει το κεφαλαίο ενός γράμματος και το `.lower` το πεζό. Ό,τι δεν
είναι γράμμα επιστρέφεται αμετάβλητο.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Χαρακτήρες ως αριθμοί

Κάθε χαρακτήρας έχει έναν αριθμό. Το `.int` τον δίνει και το `.char`
μετατρέπει έναν αριθμό πίσω σε χαρακτήρα.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Οι ακριβείς αριθμοί σπάνια έχουν σημασία. Αυτό που έχει σημασία είναι ότι τα
γράμματα από το `a` ως το `z` είναι στη σειρά και το ένα δίπλα στο άλλο, οπότε
το `'c'.int - 'a'.int` είναι 2, δηλαδή πόσο μακριά βρίσκεται το `c` στο
αλφάβητο. Αυτό είναι που κάνει έναν τροχό κρυπτογράφησης να λειτουργεί.
