# Εισαγωγή

## Χαρακτήρες

Ο τύπος `char` της C# είναι μια ποσότητα 16 bit που αναπαριστά τα μικρότερα διευθυνσιοδοτήσιμα συστατικά του κειμένου.
Πολλά `char` μπορούν να σχηματίσουν μια συμβολοσειρά όπως η `"word"` ή τα `char` μπορούν να
υποστούν επεξεργασία ανεξάρτητα. Τα literal τους έχουν μονά εισαγωγικά, π.χ. `'A'`.

Τα `char` της C# υποστηρίζουν κωδικοποίηση UTF-16 Unicode, οπότε εκτός από το λατινικό σύνολο χαρακτήρων
μπορούν να αναπαρασταθούν σχεδόν όλα τα συστήματα γραφής που χρησιμοποιούνται στον κόσμο,
π.χ. το ελληνικό γράμμα `'β'`.

Υπάρχουν πολλές ενσωματωμένες μέθοδοι βιβλιοθήκης για την εξέταση και τον χειρισμό των `char`. Αυτές
μπορούν να βρεθούν ως στατικές μέθοδοι της κλάσης `System.Char`.

## Δομητής συμβολοσειρών

Τα `char` χρησιμοποιούνται μερικές φορές σε συνδυασμό με ένα αντικείμενο `StringBuilder`.
Αυτό το αντικείμενο έχει μεθόδους που επιτρέπουν να κατασκευαστεί μια συμβολοσειρά
χαρακτήρα προς χαρακτήρα και να χειριστεί. Στο τέλος της διαδικασίας
μπορείς να καλέσεις τη `ToString` πάνω του για να εξαγάγεις μια πλήρη συμβολοσειρά.
