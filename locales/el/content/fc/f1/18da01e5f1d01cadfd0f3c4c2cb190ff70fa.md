# Βρες συντηρητές

Για να πετύχει μια διαδρομή, είναι σημαντικό να υπάρχει μια χούφτα άνθρωποι που θα τη συντηρούν.
Αυτοί οι άνθρωποι είναι (όπως ήταν αναμενόμενο) γνωστοί ως οι _συντηρητές της διαδρομής_.
Τα καθήκοντα αυτών των συντηρητών μπορεί να κυμαίνονται από την αξιολόγηση PR, μέχρι τη διόρθωση bugs και την προσθήκη νέων ασκήσεων.

Το να υπάρχουν δύο-τρεις συντηρητές της διαδρομής είναι ιδιαίτερα σημαντικό μόλις ξεκινήσει η διαδρομή, καθώς οι μαθητές θα εγγράφονται και θα δουλεύουν τις ασκήσεις.

Η προσθήκη συντηρητών είναι μια χειροκίνητη διαδικασία.
Μπορείς να ζητήσεις να προστεθεί ένας συντηρητής ανοίγοντας ένα issue και κάνοντας tag το `@exercism/staff`.
