# Εισαγωγή

Τα closures στη Swift είναι αυτοτελή μπλοκ κώδικα που μπορούν να δεχτούν παραμέτρους, οι οποίες ενεργοποιούν τον υπολογισμό τους, και να επιστρέψουν τιμές. Τα closures συλλαμβάνουν επίσης τιμές από το περιβάλλον τους και τις χρησιμοποιούν στους υπολογισμούς τους. Καθώς είναι αυτοτελή, μπορούν να μεταβιβάζονται μέσα σε ένα πρόγραμμα όπως άλλες τιμές ή να εκχωρούνται σε σταθερές και μεταβλητές.

Τα closures μπορεί να ακούγονται πολύ σαν συναρτήσεις της Swift· και πράγματι είναι, για καλό λόγο. Οι συναρτήσεις στη Swift είναι απλώς ειδικές περιπτώσεις closures που απαιτείται να έχουν όνομα και ορίζονται με ελαφρώς διαφορετική σύνταξη.

Ενώ οι συναρτήσεις στη Swift είναι τεχνικά closures, όταν οι άνθρωποι αναφέρονται σε "closures" στη Swift, εννοούν τις εκφράσεις closure. Οι εκφράσεις closure γράφονται ως μια λίστα παραμέτρων ακολουθούμενη από έναν τύπο επιστροφής και τη λέξη-κλειδί `in` ακολουθούμενη από το σώμα του closure, όλα μέσα σε ένα ζεύγος αγκίστρων:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}
```

Αυτό ορίζει μια έκφραση closure τύπου `(Double, Double) -> Double` και μπορεί να εκτελεστεί με παρόμοιο τρόπο με μια συνάρτηση αυτού του τύπου, εφαρμόζοντάς την σε παραμέτρους του κατάλληλου τύπου:

```swift
{ (a: Double, b: Double) -> Double in
  return a + b / 2.0
}(10.0, 15.0)
// => 12.5
```

Όπως φαίνεται παραπάνω, τα closures, όπως και οι κανονικές συναρτήσεις, μπορούν να παραλείψουν τη λέξη-κλειδί `return` αν το σώμα του closure είναι μία μόνο έκφραση.
