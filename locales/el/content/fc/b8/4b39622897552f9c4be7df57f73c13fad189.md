# Εισαγωγή

## Βασικά

### Συναρτήσεις

Στη Gleam οι συναρτήσεις ορίζονται με τη σύνταξη `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Αυτή η συνάρτηση δέχεται δύο ορίσματα, και τα δύο τύπου `Int`, και επιστρέφει μια τιμή τύπου `Int`. Δεν υπάρχει λέξη-κλειδί `return` στη Gleam: η τιμή της τελευταίας έκφρασης σε μια συνάρτηση _επιστρέφεται πάντα σιωπηρά_.

Οι δηλώσεις τύπων για τα ορίσματα και ο τύπος επιστροφής είναι προαιρετικές, και η Gleam θα ελέγχει πάντα πλήρως τους τύπους του κώδικά σου. Συνήθως οι προγραμματιστές της Gleam δίνουν δηλώσεις τύπων στις συναρτήσεις τους για σαφήνεια, αλλά μπορείς να τις παραλείψεις αν θέλεις.

```gleam
pub fn add(x, y) {
  x + y
}
```

Μπορείς να καλέσεις μια συνάρτηση χρησιμοποιώντας τη σύνταξη `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Μεταβλητές

Στη Gleam οι μεταβλητές ορίζονται με τη σύνταξη `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Οι μεταβλητές μπορούν να δηλωθούν με δηλώσεις τύπων. Όπως και στα ορίσματα συναρτήσεων, αυτές είναι προαιρετικές, αν και οι περισσότεροι προγραμματιστές της Gleam παραλείπουν τις δηλώσεις τύπων για τις μεταβλητές για λόγους συντομίας.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### Κυριολεκτικές συμβολοσειρές

Στη Gleam οι συμβολοσειρές γράφονται με διπλά εισαγωγικά.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Σχόλια κώδικα

Τα σχόλια μπορούν να χρησιμοποιηθούν για να αφήσεις σημειώσεις σε άλλους προγραμματιστές που διαβάζουν τον πηγαίο κώδικα. Τα σχόλια στη Gleam είναι μεμονωμένες γραμμές που ξεκινούν με `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
