# Οδηγίες

Υλοποίησε την κωδικοποίηση και την αποκωδικοποίηση μήκους σειράς.

Η κωδικοποίηση μήκους σειράς (RLE) είναι μια απλή μορφή συμπίεσης δεδομένων, όπου οι σειρές (διαδοχικά στοιχεία δεδομένων) αντικαθίστανται από μία μόνο τιμή δεδομένων και το πλήθος της.

Για παράδειγμα, μπορούμε να αναπαραστήσουμε τους αρχικούς 53 χαρακτήρες με μόλις 13.

```text
"WWWWWWWWWWWWBWWWWWWWWWWWWBBBWWWWWWWWWWWWWWWWWWWWWWWWB"  ->  "12WB12W3B24WB"
```

Η RLE επιτρέπει την τέλεια ανακατασκευή των αρχικών δεδομένων από τα συμπιεσμένα δεδομένα, κάτι που την καθιστά συμπίεση δεδομένων χωρίς απώλειες.

```text
"AABCCCDEEEE"  ->  "2AB3CD4E"  ->  "AABCCCDEEEE"
```

Για λόγους απλότητας, μπορείς να υποθέσεις ότι η μη κωδικοποιημένη συμβολοσειρά θα περιέχει μόνο τα γράμματα A έως Z (είτε πεζά είτε κεφαλαία) και κενά διαστήματα.
Έτσι, τα δεδομένα προς κωδικοποίηση δεν θα περιέχουν ποτέ αριθμούς, και οι αριθμοί μέσα στα δεδομένα προς αποκωδικοποίηση αντιπροσωπεύουν πάντα το πλήθος του επόμενου χαρακτήρα.
