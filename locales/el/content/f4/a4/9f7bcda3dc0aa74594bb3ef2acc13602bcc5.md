# Μάθηση

Η Cairo είναι η πρώτη Turing-πλήρης γλώσσα για τη δημιουργία αποδείξιμων προγραμμάτων γενικού υπολογισμού. Είναι μια γλώσσα υψηλού επιπέδου, παρόμοια με τη Rust. Όπως η Rust, έχει σχεδιαστεί ώστε να επιτρέπει στους προγραμματιστές να γράφουν εύκολα κώδικα που είναι αποδοτικός και ασφαλής.

Πιστεύουμε πως ο καλύτερος τρόπος για να μάθεις είναι το παιχνίδι και η εξάσκηση, είτε φτιάχνοντας τα δικά σου έργα προγραμματισμού, είτε λύνοντας μικρά προβλήματα σαν αυτά εδώ στο Exercism!

Παρακάτω υπάρχουν μερικοί πόροι που μπορεί να σε βοηθήσουν να ξεκινήσεις δυναμικά το ταξίδι σου με τη Cairo:

- Η [Cairo Programming Language](https://www.cairo-lang.org/) παρουσιάζει τη γλώσσα Cairo και παραθέτει πολλούς σχετικούς πόρους για να μάθεις και να χρησιμοποιήσεις τη Cairo.
- Το [The Cairo Book](https://book.cairo-lang.org/) είναι ένας εξαιρετικός πόρος για να μάθεις τη Cairo καθώς και να εμβαθύνεις σε συγκεκριμένες δυνατότητές της.
- Η [Cairo Documentation](https://docs.cairo-lang.org/) εξηγεί τα δομικά στοιχεία και τη σημασιολογία της γλώσσας.
- Το [Cairo by Example](https://cairo-by-example.com/) σου δείχνει παραδείγματα από τα πιο συνηθισμένα πράγματα που θα γράφεις στη Cairo.
- Οι [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2) "Μια πλατφόρμα μάθησης με θεματική φαντασίας για προγραμματιστές Smart Contract."
- Το [Cairo Community Forum](https://community.cairo-lang.org/) απαντά σε ερωτήσεις κάθε επιπέδου.
