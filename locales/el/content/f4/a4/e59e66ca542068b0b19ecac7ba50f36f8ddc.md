# Αποδόμηση

Η αποδόμηση είναι η διαδικασία κατά την οποία διασπάμε στοιχεία στα συστατικά τους μέρη, δεσμεύοντας το καθένα σε μια μικρότερη μεταβλητή.

## Αποδόμηση πλειάδων

Η αποδόμηση πλειάδων είναι απλή: απλώς εκχώρησε νέα ονόματα μεταβλητών σε κάθε πεδίο της πλειάδας:

```rust
let (first, second) = (1, 2);
```

## Αποδόμηση δομών πλειάδας

Η αποδόμηση δομών πλειάδας είναι ίδια με την αποδόμηση πλειάδων, αλλά με την προσθήκη του ονόματος της δομής:

```rust
struct TupleStruct(&'static str, i32);
let my_tuple_struct = TupleStruct("foo", 123);
let TupleStruct(foo, num) = my_tuple_struct;
```

## Αποδόμηση δομών

Η αποδόμηση δομών είναι παρόμοια με την αποδόμηση δομών πλειάδας. Απλώς χρησιμοποίησε τα ονόματα των πεδίων:

```rust
struct ArabianNights {
    name: String,
    stories: usize,
}
let teller = ArabianNights { name: "Scheherazade".into(), stories: 1001 };
{
    let ArabianNights { name, stories } = teller;
    println!("{name} told {stories} stories");
}
```

## Μερική αποδόμηση

Ο τελεστής `..` μπορεί να χρησιμοποιηθεί για να αγνοήσεις κάποια πεδία κατά την αποδόμηση:

```rust
let ArabianNights { name, .. } = teller;
println!("{name} survived by her wits");
```

## Αποδόμηση υπό συνθήκη

Η αποδόμηση δομών και πλειάδων είναι αλάνθαστη. Ωστόσο, και τα enum μπορούν να αποδομηθούν, χρησιμοποιώντας τις γλωσσικές κατασκευές `if let`, `while let` και `match`.

```rust
if let Some(foo) = foo {
    println!("{foo:?}");
}
```
