# Εισαγωγή

Το *tuple* είναι ο τύπος της Factor για καταγραφές, struct και κλάσεις. Κάθε κλάση tuple έχει ένα σταθερό σύνολο από ονομαστικές υποδοχές, για τις οποίες η Factor δημιουργεί αυτόματα getters και setters.

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

Το `boa` ("με τη σειρά των ορισμάτων") γεμίζει τις υποδοχές από τη στοίβα, με τη σειρά δήλωσης. Το `new` δημιουργεί ένα στιγμιότυπο με κάθε υποδοχή στη δηλωμένη τιμή `initial:` της (ή `f`, αν δεν έχει οριστεί καμία).

Ο getter κάθε υποδοχής είναι `slot>>` και ο setter είναι `>>slot`. Ο setter *μεταβάλλει* το στιγμιότυπο, οπότε κάνε πρώτα `clone` αν χρειάζεσαι μη καταστροφική ενημέρωση:

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Οι προεπιλεγμένες τιμές των υποδοχών ορίζονται με `{ name initial: value }`. Χωρίς `initial:`, η προεπιλεγμένη τιμή είναι `f`.
