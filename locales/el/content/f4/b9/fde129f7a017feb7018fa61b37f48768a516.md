# Σχετικά

Τώρα ξέρεις πώς να κάνεις επανάληψη σε ένα slice ή σε ένα map στη Go.

Για υπενθύμιση, έμαθες ότι κάθε επανάληψη επιστρέφει δύο τιμές: τη θέση/κλειδί και ένα αντίγραφο του στοιχείου σε αυτή τη θέση/κλειδί.

## Επανάληψη σε ένα slice

Πανεύκολο: οι βρόχοι πάνω σε ένα slice ακολουθούν τη σειρά που περιμένεις.

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## Επανάληψη σε ένα map

Η επανάληψη πάνω σε ένα map φέρνει ένα νέο πρόβλημα.
Τώρα η σειρά είναι τυχαία.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
Μπορεί να φαίνεται ότι η παραπάνω έξοδος είναι λανθασμένη, καθώς θα περίμενε κανείς το πρώτο ζεύγος κλειδιού/τιμής στη δήλωση του map `9 10` να είναι το πρώτο που τυπώνεται και όχι το τελευταίο.
Ωστόσο, τα map δεν έχουν σειρά από τη φύση τους: δεν υπάρχει πρώτο ή τελευταίο ζεύγος κλειδιού/τιμής.
Γι' αυτό, όταν κάνεις επανάληψη πάνω στις καταχωρίσεις ενός map, η σειρά με την οποία θα επισκεφτούν οι καταχωρίσεις θα είναι τυχαία και δεν θα ακολουθεί κάποιο συγκεκριμένο μοτίβο.
Αυτό σημαίνει ότι η παραπάνω έξοδος είναι πιθανή, αλλά μπορεί να διαφέρει από αυτό που θα πάρεις αν δοκιμάσεις να το τρέξεις ο ίδιος.
Για να μάθεις περισσότερα σχετικά, δες [Go Language Spec: range clause](https://go.dev/ref/spec#RangeClause).
~~~~

## Επανάληψη παραλείποντας κλειδί ή τιμή

Στη Go, μια αχρησιμοποίητη μεταβλητή θα πετάξει ένα σφάλμα τη στιγμή της μεταγλώττισης.
Μερικές φορές χρειάζεσαι μόνο την τιμή, όπως στο πρώτο παράδειγμα:

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

Μπορείς να αντικαταστήσεις το `i` με `_`, που λέει στον μεταγλωττιστή ότι δεν χρησιμοποιούμε αυτή την τιμή:

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

Αν θέλεις να τυπώσεις μόνο τη θέση, μπορείς να αντικαταστήσεις το `x` με `_` ή απλώς να παραλείψεις τη δήλωση:

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

Τέλος, αν πρέπει να εκτελέσεις κάποια ενέργεια αλλά δεν σε ενδιαφέρουν ούτε οι τιμές ούτε τα κλειδιά του slice ή του map, μπορείς να παραλείψεις και τη θέση και την τιμή:

```go
xi := []int{10, 20, 30}
count := 0
for range xi {
  count++
}
// count value:
// 3
```
