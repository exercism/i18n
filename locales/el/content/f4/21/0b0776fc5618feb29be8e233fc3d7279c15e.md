# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [σταθερά][constants] που θα περιέχει την [ακέραια][integers] τιμή που καθορίζεται στη συνταγή.
- Το `::` που χρησιμοποιείται στο `Lasagna::EXPECTED_MINUTES_IN_OVEN` σημαίνει ότι το `EXPECTED_MINUTES_IN_OVEN` πρέπει να οριστεί μέσα στην κλάση `Lasagna`.

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία μόνο παράμετρο για τον πραγματικό χρόνο μέχρι στιγμής.
- Μπορείς να [επιστρέψεις έμμεσα έναν ακέραιο][return] από τη μέθοδο.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή αφαίρεσης][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία μόνο παράμετρο για τον αριθμό των στρώσεων.
- Μπορείς να [επιστρέψεις έμμεσα έναν ακέραιο][return] από τη μέθοδο.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή πολλαπλασιασμού][operators] για να πολλαπλασιάσεις τιμές.
- Θα μπορούσες να ορίσεις μια επιπλέον σταθερά για τον χρόνο σε λεπτά ανά στρώση, ή να χρησιμοποιήσεις έναν "μαγικό αριθμό" στον κώδικα.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με δύο ονομαστικές παραμέτρους: `number_of_layers` και `actual_minutes_in_oven`.
- Μπορείς να [επιστρέψεις έμμεσα έναν ακέραιο][return] από τη μέθοδο.
- Μπορείς να [καλέσεις][invocation] μία από τις άλλες μεθόδους που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή πρόσθεσης][operators] για να προσθέσεις τιμές.
