# Αφηρημένες Κλάσεις

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class JUGGLING < $ACT is
   name : STR is return "Juggling"; end;
   minutes : INT is return 5; end;
   create : SAME is return new; end;
end;
```

## Το $ είναι μέρος του ονόματος

Κάθε αφηρημένη κλάση έχει ένα `$` στην αρχή του ονόματός της, και μόνο οι αφηρημένες κλάσεις το έχουν. Έτσι, ένας τύπος που ξεκινά με `$` είναι ένας τύπος από τον οποίο δεν μπορείς να δημιουργήσεις αντικείμενο, και αυτό φαίνεται παντού όπου εμφανίζεται το όνομα.

## Τι μπορεί να μπει σε μία

Υπογραφές ρουτινών και iterator, που τελειώνουν στο ερωτηματικό. Χωρίς σώματα, χωρίς χαρακτηριστικά, χωρίς `create`. Μια αφηρημένη κλάση περιγράφει τι μπορείς να *ζητήσεις* από κάτι, ποτέ τι κρατάει μέσα της.

## Συμμόρφωση

```sather
class TRAPEZE < $ACT is
```

Η κλάση πρέπει να ορίζει κάθε ρουτίνα που αναφέρεται, με τύπους ορισμάτων και τύπο επιστροφής που ταιριάζουν. Ο έλεγχος γίνεται κατά τη μεταγλώττιση.

Μια κλάση μπορεί να συμμορφώνεται με πολλές:

```sather
class TRAPEZE < $ACT, $RISKY is
```

και οι αφηρημένες κλάσεις μπορούν να επεκτείνουν η μία την άλλη:

```sather
abstract class $TIMED_ACT < $ACT is
   overrun : INT;
end;
```

## Πού γίνεται η δυναμική αποστολή

Μια μεταβλητή αφηρημένου τύπου κρατάει μια αναφορά σε κάποιο αντικείμενο που συμμορφώνεται. Όταν καλείς μια ρουτίνα πάνω της, επιλέγεται η εκδοχή που ανήκει στην πραγματική κλάση του αντικειμένου, κατά τον χρόνο εκτέλεσης.

Αυτό είναι το μόνο σημείο όπου η Sather αποφασίζει κάτι κατά τον χρόνο εκτέλεσης. Μια κλήση σε μεταβλητή συγκεκριμένου τύπου καθορίζεται κατά τη μεταγλώττιση.

## typecase

Μερικές φορές το είδος έχει πραγματικά σημασία. Το `typecase` ρωτάει:

```sather
   typecase act
   when TRAPEZE then #OUT + "rig the net";
   else            #OUT + "nothing to rig";
   end;
```

Μέσα σε έναν κλάδο, η μεταβλητή έχει τον στενότερο τύπο. Καταφεύγεις σε αυτό σπάνια: ένα `typecase` πάνω σε κάθε είδος act είναι συνήθως μια ρουτίνα που ανήκε εξαρχής στην αφηρημένη κλάση.

## $OB

Το `$OB` είναι η αφηρημένη κλάση με την οποία συμμορφώνεται κάθε αντικείμενο. Είναι περιστασιακά χρήσιμο και κυρίως σημάδι ότι κάποιος τύπος έχει χαθεί στην πορεία.

## Γιατί όχι κληρονομικότητα;

Η Sather χωρίζει δύο πράγματα που οι περισσότερες γλώσσες ενώνουν. Το `<` λέει μόνο τι μπορεί να *κάνει* μια κλάση. Το να πάρεις μια υλοποίηση από αλλού είναι το `include`, που είναι η μεθεπόμενη άσκηση και αποτελεί ξεχωριστή απόφαση.
