# Εισαγωγή

Οι συσχετιστικοί πίνακες της Factor, δηλαδή οι κατακερματοπίνακες και τα συναφή, μοιράζονται ένα κοινό [πρωτόκολλο][assoc-protocol] από το [`assocs`][assocs]. Η κυριολεκτική γραφή ενός κατακερματοπίνακα είναι το `H{ }`:

```factor
H{ { "coal" 1 } { "wood" 2 } } .

"coal" H{ { "coal" 1 } { "wood" 2 } } at .   ! => 1
"gold" H{ { "coal" 1 } { "wood" 2 } } at .   ! => f
```

Συνήθεις λειτουργίες:

```
at        ( key assoc -- value/f )
key?      ( key assoc -- ? )
set-at    ( value key assoc -- )
delete-at ( key assoc -- )
inc-at    ( key assoc -- )
change-at ( key assoc quot -- )
keys      ( assoc -- keys )
values    ( assoc -- values )
>alist    ( assoc -- alist )
```

Οι κατακερματοπίνακες είναι *μεταβλητοί*: κάνε `clone` σε ένα κυριολεκτικό `H{ }` πριν το τροποποιήσεις, ώστε το κυριολεκτικό να μην μοιράζεται ανάμεσα στις κλήσεις.

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
