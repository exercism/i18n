# Οδηγίες

Η κοπέλα του Lucian γυρίζει σπίτι και εκείνος δεν έχει μαγειρέψει το επετειακό τους δείπνο!

Σε αυτή την άσκηση, θα γράψεις λίγο κώδικα για να βοηθήσεις τον Lucian να μαγειρέψει μια εξαίσια λαζάνια από το αγαπημένο του βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το μαγείρεμα της λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `ovenTime()` που δεν παίρνει κανένα όρισμα και επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στον φούρνο είναι 40 λεπτά:

```cpp
ovenTime();
// => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `remainingOvenTime(int actualMinutesInOven)` που παίρνει ως όρισμα τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο σε λεπτά από την προηγούμενη εργασία.

```cpp
remainingOvenTime(30);
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparationTime(int numberOfLayers)` που παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```cpp
preparationTime(2);
// => 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsedTime(int numberOfLayers, int actualMinutesInOven)` που παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα της λαζάνια, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο τη δεδομένη στιγμή.

```cpp
elapsedTime(3, 20);
// => 26
```
