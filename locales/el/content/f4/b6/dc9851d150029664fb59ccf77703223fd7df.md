# μορφοποίηση kernel

Εκτός από τη μέθοδο `format`, ένας συνηθισμένος τρόπος για να δημιουργείς συμβολοσειρές στη Ruby είναι να χρησιμοποιείς [παρεμβολή συμβολοσειρών](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Για παράδειγμα:

```ruby
# Rather than:
format("One for %%s, one for me.", %{name_variable})

# Consider:
"One for #{%{name_variable}}, one for me."
```
