# Σχετικά

Τα μπλοκ είναι μικρές ομάδες εντολών που μπορούν να εκτελεστούν πολλές φορές.
Μπορούν να θεωρηθούν ως κλεισίματα ή ανώνυμες συναρτήσεις.
Τα μπλοκ ορίζονται χρησιμοποιώντας τη σύνταξη `do...end` (πάνω), ή τα `{}` (κάτω).
Τα στυλ είναι εναλλάξιμα και υπάρχουν διαφορετικές απόψεις για το πότε πρέπει να χρησιμοποιείται το καθένα.

## Συντομευμένη σύνταξη
Σε περιπτώσεις όπου ένα μπλοκ καλεί μία μόνο μέθοδο, μπορείς να αντικαταστήσεις το μπλοκ με `&:` ακολουθούμενο από το όνομα της μεθόδου. Για παράδειγμα, αυτές οι δύο γραμμές είναι συνώνυμες:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
