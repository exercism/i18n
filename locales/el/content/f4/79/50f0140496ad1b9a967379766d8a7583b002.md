# Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις ένα βοηθητικό πρόγραμμα, ώστε να μη χρειάζεται να θυμάσαι τις τιμές των ζωνών.
Το πρόγραμμα θα παίρνει ως είσοδο 1, 4 ή 5 χρώματα και θα βγάζει τη σωστή τιμή σε ωμ.
Οι χρωματικές ζώνες κωδικοποιούνται ως εξής:

| Χρώμα  | Τιμή |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

Στο [`Resistor Color Trio`][resistor-color-trio-exercise] αποκωδικοποίησες τις τρεις πρώτες χρωματικές ζώνες.
Για παράδειγμα: το orange-orange-brown μεταφραζόταν στην κύρια τιμή `330`.
Σε αυτή την άσκηση θα χρειαστεί να προσθέσεις και την _ανοχή_.
Η ανοχή είναι η μέγιστη απόκλιση που μπορεί να έχει μια τιμή πάνω ή κάτω από την κύρια τιμή.
Για παράδειγμα, αν η τελευταία ζώνη είναι green, η μέγιστη ανοχή θα είναι `±0.5%`.

Η ζώνη ανοχής θα έχει μία από τις παρακάτω τιμές:

| Χρώμα  | Ανοχή |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

Η αντίσταση τεσσάρων ζωνών χτίζεται ως εξής:

| Ζώνη_1  | Ζώνη_2  | Ζώνη_3     | Ζώνη_4    |
| ------- | ------- | ---------- | --------- |
| Τιμή_1  | Τιμή_2  | Πολλαπλασιαστής | Ανοχή |

Παραδείγματα:

- το orange-orange-brown-green θα ήταν `330` ωμ με ανοχή `±0.5%`.
- το orange-orange-red-grey θα ήταν `3300` ωμ με ανοχή `±0.05%`.

Η διαφορά ανάμεσα σε μια αντίσταση τεσσάρων και σε μια αντίσταση πέντε ζωνών είναι ότι η αντίσταση πέντε ζωνών έχει μια επιπλέον ζώνη, που δηλώνει μια πιο ακριβή τιμή.

| Ζώνη_1  | Ζώνη_2  | Ζώνη_3  | Ζώνη_4     | Ζώνη_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Τιμή_1  | Τιμή_2  | Τιμή_3  | Πολλαπλασιαστής | Ανοχή |

Παραδείγματα:

- το orange-orange-orange-black-green θα ήταν `333` ωμ με ανοχή `±0.5%`.
- το orange-red-orange-blue-violet θα ήταν `323 million` ωμ με ανοχή `±0.1%`.

Υπάρχουν επίσης αντιστάσεις μιας ζώνης.
Οι αντιστάσεις μιας ζώνης έχουν μόνο το χρώμα black, με τιμή 0.

Το πρόγραμμά σου θα πρέπει να μετατρέπει μια `list` εισόδου με χρώματα ζωνών αντίστασης σε μια ένδειξη:

"... ohms ±...%"

Έτσι, μια `list` εισόδου `["orange", "orange", "black", "green"]` θα πρέπει να επιστρέφει:

"33 ohms ±0.5%"

Όταν έχουμε χιλιάδες ωμ, λέμε "kiloohms".
Είναι παρόμοιο με το να λες "χιλιόμετρο" για 1000 μέτρα και "χιλιόγραμμα" για 1000 γραμμάρια.

Έτσι, μια `list` εισόδου `["orange", "orange", "orange", "grey"]` θα πρέπει να επιστρέφει:

"33 kiloohms ±0.05%"

Όταν έχουμε εκατομμύρια ωμ, λέμε "megaohms".

Έτσι, μια `list` εισόδου `["orange", "orange", "blue", "red"]` θα πρέπει να επιστρέφει:

"33 megaohms ±2%"
