# Μαθαίνοντας Visual Basic

## Ιστότοποι

Το Visual Basic έχει εξελιχθεί σημαντικά με τα χρόνια και πολλά tutorials τρίτων αναφέρονται σε ξεπερασμένα εργαλεία ή δυνατότητες.
Η [επίσημη τεκμηρίωση του Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) είναι το πιο ενημερωμένο και αξιόπιστο μέρος για να ξεκινήσεις το ταξίδι σου.

## Το οικοσύστημα .NET

Το Visual Basic εκτελείται στο περιβάλλον εκτέλεσης .NET, μοιραζόμενο μεγάλο μέρος της βασικής λειτουργικότητας με τη C# και τη F#.
Επομένως, το να καταλάβεις πώς λειτουργεί το .NET θα σε κάνει καλύτερο προγραμματιστή VB.

- [Τι είναι το .NET;](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [Το γλωσσάρι του .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [Το Κοινό Σύστημα Τύπων (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
