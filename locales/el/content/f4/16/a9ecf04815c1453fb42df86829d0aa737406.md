# Προσθήκη οδηγιών

## Μορφή εξόδου

Δώσε ως έξοδο μια συμβολοσειρά που τερματίζεται με null, χρησιμοποιώντας ως διαχωριστικά ένα κόμμα και ένα κενό.

Ένα παράδειγμα εξόδου θα ήταν `"491, 914, 142"`

Αν η είσοδος δεν είναι έγκυρη, δώσε ως έξοδο μια κενή συμβολοσειρά.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                          |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά σειράς που τερματίζεται με null  |
| `$a1`    | είσοδος        | ακέραιος | μήκος τμήματος                   |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου που τερματίζεται με null  |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση     |
