# Ροή εργασίας "Δεν άλλαξαν σημαντικά αρχεία"

Όταν συγχωνεύεται ένα PR ενός track που αγγίζει μια άσκηση, προκαλεί τον επανέλεγχο _όλων_ των τελευταίων δημοσιευμένων επαναλήψεων των λύσεων των μαθητών.
Για δημοφιλείς ασκήσεις, αυτή είναι μια _πολύ_ ακριβή διαδικασία (70.000 εκτελέσεις test για το Hello World της Python, σε ακραία περίπτωση!).

Αυτή η ροή εργασίας ελέγχει αν οι αλλαγές σε ένα PR θα προκαλούσαν τον επανέλεγχο λύσεων και, αν ναι, προσθέτει ένα σχόλιο που εξηγεί τον κίνδυνο να συγχωνευτεί το PR _ως έχει_.
Εξηγεί επίσης πώς να συγχωνεύσεις το PR χωρίς επανέλεγχο λύσεων.

Για περισσότερες πληροφορίες, δες την τεκμηρίωση [Αποφυγή περιττών εκτελέσεων test](https://exercism.org/docs/building/tracks#h-avoiding-triggering-unnecessary-test-runs).

## Πηγή

Η ροή εργασίας ορίζεται στο αρχείο `.github/workflows/no-important-files-changed.yml`.
