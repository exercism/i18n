# Οδηγίες

Κανείς δεν ανεβαίνει στο τραπέζι στο τσίρκο αν δεν περάσουν οι έλεγχοι ασφάλειας.
Καταγράφεις τους ελέγχους, ώστε οι ίδιοι κανόνες να ισχύουν για όλους.

Και οι πέντε εργασίες μπαίνουν στην κλάση `SAFETY_CHECK`.

## 1. Είναι έτοιμο το στρώμα;

Το στρώμα είναι έτοιμο μόνο όταν είναι και κάτω και καθαρό.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. Υπάρχει κάτι για να προσγειωθείς;

Πρέπει να υπάρχει από κάτω είτε στρώμα είτε δίχτυ. Οποιοδήποτε από τα δύο αρκεί,
και το να υπάρχουν και τα δύο είναι εντάξει.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. Ποιος χρειάζεται ακόμα την ενημέρωση;

Όποιος δεν έχει ενημερωθεί χρειάζεται την ενημέρωση.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. Είναι αρκετά μεγάλος αυτός ο ακροβάτης;

Το τραπέζι προορίζεται για ακροβάτες 13 ετών και άνω.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Συνδύασέ τα όλα

Ένας ακροβάτης έχει την έγκριση για το τραπέζι όταν είναι αρκετά μεγάλος, έχει
ενημερωθεί και το στρώμα είναι έτοιμο.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Τα τέσσερα ορίσματα είναι η ηλικία, αν έχει ενημερωθεί, αν το στρώμα είναι κάτω
και αν το στρώμα είναι καθαρό.
