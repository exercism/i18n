# Υποδείξεις

## Γενικά

- Ένας βρόχος σε x86-64 υλοποιείται με άλμα σε μια προηγούμενη ετικέτα και μπορεί να τερματιστεί με άλμα σε μια ετικέτα εκτός του βρόχου.
- Για να προσπελάσεις περιεχόμενα που είναι αποθηκευμένα σε μια διεύθυνση στη μνήμη, πρέπει να κάνεις αποαναφορά σε αυτήν χρησιμοποιώντας `[]`.
- Το πρόθεμα για την προσπέλαση τιμών 4 byte στη μνήμη είναι `dword`.
- Ένας πίνακας αναπαρίσταται από τη διεύθυνσή του, η οποία είναι μια τιμή 8 byte σε x86-64.
- Αν μια συνάρτηση που καλείς τροποποιεί έναν καταχωρητή, πρέπει να αποθηκεύσεις οποιαδήποτε τιμή σε αυτόν τον καταχωρητή που θα χρησιμοποιηθεί αργότερα.

- Ένας βρόχος σε x86-64 υλοποιείται με άλμα σε μια προηγούμενη ετικέτα και μπορεί να τερματιστεί με άλμα σε μια ετικέτα εκτός του βρόχου.

- Μπορεί να μη χρειάζεσαι καμία φέτα από την αρχή ή ο πίνακας εισόδου να είναι κενός, οπότε πρέπει να ελέγξεις μια συνθήκη εξόδου πριν εκτελέσεις οποιαδήποτε επανάληψη του βρόχου.
- Μπορείς να χρησιμοποιήσεις το `sub` για να αφαιρέσεις την τιμή του τελεστέου πηγής από την τιμή του τελεστέου προορισμού.
- Μπορείς να χρησιμοποιήσεις το `inc` για να προσθέσεις 1 στην τιμή ενός τελεστέου προορισμού.
