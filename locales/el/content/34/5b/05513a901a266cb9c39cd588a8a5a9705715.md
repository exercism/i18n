# Υποδείξεις

## 1. Καθόρισε αν θα χρειαστείς άδεια οδήγησης

- Χρησιμοποίησε τον [τελεστή ισότητας] για να ελέγξεις αν η είσοδός σου ισούται με μια συγκεκριμένη συμβολοσειρά.
- Χρησιμοποίησε έναν από τους δύο [λογικούς τελεστές] για να συνδυάσεις τις δύο προϋποθέσεις.
- Δεν χρειάζεται να γράψεις μια εντολή `if` για να λύσεις αυτό το βήμα. Μπορείς να επιστρέψεις απευθείας τη λογική έκφραση που θα φτιάξεις.

## 2. Διάλεξε ανάμεσα σε δύο πιθανά οχήματα για αγορά

- Θα χρειαστείς την [έκφραση υπό συνθήκη] `if-then-else` για αυτό το βήμα.
- Χρησιμοποίησε έναν [τελεστή σύγκρισης] για να καθορίσεις ποια επιλογή έρχεται πρώτη σε λεξικογραφική σειρά.
- Τέλος, σχημάτισε την πρόταση σύστασης.
  Μπορείς να χρησιμοποιήσεις τη συνένωση ή την παρεμβολή συμβολοσειρών που έμαθες στην ενότητα Strings για να σχηματίσεις την πρόταση σύστασης.

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

- Ξεκίνα καθορίζοντας το ποσοστό με βάση την ηλικία του οχήματος.
  Χρησιμοποίησε μια έκφραση `if-elsif-else`.
- Για να υπολογίσεις το αποτέλεσμα, εφάρμοσε το ποσοστό στην αρχική τιμή.
  Για παράδειγμα, το `30% of x` μπορεί να υπολογιστεί πολλαπλασιάζοντας το `x` επί `30` και διαιρώντας με το `100`.
