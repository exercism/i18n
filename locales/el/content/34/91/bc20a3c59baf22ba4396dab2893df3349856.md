# Εισαγωγή

Η Python έχει τρεις διαφορετικούς τύπους ενσωματωμένων αριθμών: ακέραιους ([`int`][int]), κινητής υποδιαστολής ([`float`][float]) και μιγαδικούς ([`complex`][complex]).
Τα κλάσματα ([`fractions.Fraction`][fractions]) και οι δεκαδικοί ([`decimal.Decimal`][decimals]) είναι επίσης διαθέσιμα μέσω εισαγωγής από την τυπική βιβλιοθήκη.

Οι ακέραιοι αριθμοί, συμπεριλαμβανομένων των δεκαεξαδικών ([_`hex()`_][hex]), οκταδικών ([_`oct()`_][oct]) και δυαδικών ([_`bin()`_][bin]) αριθμών **χωρίς** δεκαδικά ψηφία, χαρακτηρίζονται επίσης ως `ints`.

Η Python υποστηρίζει πλήρως την αριθμητική μεταξύ αυτών των διαφορετικών τύπων αριθμών και θα μετατρέψει τους αριθμούς μικρότερου εύρους ώστε να ταιριάξουν με τους αντίστοιχους μεγαλύτερου εύρους, όταν χρησιμοποιούνται με τους δυαδικούς αριθμητικούς τελεστές (`+`, `-`, `*`, `/`, `//` και `%`).
