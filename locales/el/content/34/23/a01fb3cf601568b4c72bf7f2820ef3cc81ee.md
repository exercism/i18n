# Δοκιμές

## Εκτέλεση δοκιμών
Το track Haxe βασίζεται στο testing framework [Buddy](https://github.com/ciscoheat/buddy).
Μπορείς να το εγκαταστήσεις ως εξής:

```bash
haxelib install buddy
```

Για να τρέξεις τις δοκιμές, εκτέλεσε την παρακάτω εντολή:

```bash
haxe test.hxml
```

Στο αρχείο δοκιμών, κάθε μπλοκ describe αντιστοιχεί σε ένα τμήμα από τις δοκιμές της άσκησης, και κάθε δοκιμή είναι ένα μπλοκ `it` ή `xit`.
Τα μπλοκ `it` εκτελούνται όταν τρέχεις τις δοκιμές, αλλά τα μπλοκ `xit` είναι δοκιμές που εκκρεμούν.
Όταν υποβάλλεις μια λύση, ο test runner του Exercism θα εκτελέσει όλα τα μπλοκ `it` ή `xit`.
Όταν δουλεύεις τοπικά, μόνο η πρώτη δοκιμή θα εκτελεστεί από προεπιλογή.
Για να τρέξεις άλλες δοκιμές, άλλαξε τα αντίστοιχα μπλοκ `xit` σε μπλοκ `it` και ξανατρέξε το `haxe test.hxml`.


Επιπλέον, μερικές ασκήσεις μπορεί να απαιτούν την εγκατάσταση επιπλέον βιβλιοθηκών από το haxelib.
Όταν συμβεί αυτό, θα υπάρχει μια σημείωση στις οδηγίες της άσκησης.

## Επίλυση της άσκησης

Η επίλυση μιας άσκησης σημαίνει να περάσεις όλες τις δοκιμές της.
Για να σε βοηθήσουμε να ξεκινήσεις, κάθε άσκηση συνοδεύεται από ένα αρχείο υλοποίησης stub.
Μπορείς να χρησιμοποιήσεις αυτό το αρχείο ως σημείο εκκίνησης για να φτιάξεις τη λύση σου.
Μη διστάσεις να διαγράψεις ή να αλλάξεις αυτό το αρχείο αν πιστεύεις ότι είναι το σωστό.
Προσπάθησε να επικεντρώνεσαι σε μία δοκιμή τη φορά καθώς προχωράς προς τη λύση.
