# Σχετικά

Αντί να κάνεις απευθείας ευρετηρίαση σε μια συμβολοσειρά, πρέπει να υπολογίσεις μια τιμή τύπου `String.Index` και να δώσεις αυτή τη θέση. Σημείωσε ότι αυτές οι θέσεις δεν προορίζονται να είναι άμεσα κατανοητές από τον άνθρωπο από μόνες τους. Είναι αυτό που ονομάζεται _αδιαφανείς θέσεις_, καθώς οι άνθρωποι δεν χρειάζεται να ξέρουν τι βρίσκεται μέσα τους.

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// => "g"
print(index)
// => Index(_rawBits: 1376513)
```
