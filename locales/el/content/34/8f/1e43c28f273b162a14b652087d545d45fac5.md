# Εισαγωγή

Στη Java, οι Boolean (λογική τιμή) αναπαρίστανται από τον τύπο `boolean`, οι τιμές του οποίου μπορούν να είναι είτε `true` είτε `false`.

Η Java υποστηρίζει τρεις τελεστές Boolean:  

- `!` (NOT): αντιστρέφει τη Boolean τιμή  
- `&&` (AND): παίρνει δύο Boolean τιμές και το αποτέλεσμα είναι αληθές αν είναι και οι δύο αληθείς  
- `||` (OR): το αποτέλεσμα είναι αληθές αν τουλάχιστον μία από τις δύο Boolean τιμές είναι αληθής  

## Παραδείγματα

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
