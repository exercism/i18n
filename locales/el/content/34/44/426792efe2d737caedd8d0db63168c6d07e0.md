# Εισαγωγή

## Nil

Το `Nil` στη Gleam είναι ένας τύπος με μία μόνο τιμή, που ονομάζεται επίσης `Nil`. Μοιάζει με το `void` σε άλλες γλώσσες, καθώς χρησιμοποιείται όταν μια συνάρτηση δεν έχει κάποια πιο κατάλληλη τιμή να επιστρέψει.

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Οι τιμές στη Gleam δεν είναι "nil-able" ή "nullable", όπως σε κάποιες άλλες γλώσσες. Μια τιμή μπορεί να είναι `Nil` μόνο αν ο τύπος της είναι `Nil`, και μια τιμή οποιουδήποτε άλλου τύπου δεν μπορεί ποτέ να είναι `Nil`.

## IO

Όπως οι περισσότερες γλώσσες προγραμματισμού, έτσι και η Gleam έχει "παρενέργειες": οι συναρτήσεις μπορούν να διαβάζουν και να αλλάζουν την κατάσταση του κόσμου, καθώς και να επιστρέφουν μια τιμή.

Η μονάδα `gleam/io` στην πρότυπη βιβλιοθήκη της Gleam παρέχει συναρτήσεις για την εκτύπωση συμβολοσειρών στην κονσόλα.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Άλλα πακέτα μπορούν να παρέχουν άλλες συναρτήσεις IO, όπως το `simplifile`, ένα πακέτο που παρέχει συναρτήσεις για την ανάγνωση και την εγγραφή αρχείων.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
