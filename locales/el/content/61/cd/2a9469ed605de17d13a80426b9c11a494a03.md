# Εισαγωγή

Το [Nil][nil-dictionary] είναι μια αγγλική λέξη που σημαίνει "τίποτα" ή "μηδέν".
Στη Ruby, το `nil` χρησιμοποιείται για να εκφράσει την _απουσία_ ενός αντικειμένου.
Σε άλλες γλώσσες προγραμματισμού, οι τιμές `null` ή `none` μπορεί να παίξουν παρόμοιο ρόλο.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Η Ruby δίνει σε κάθε μεταβλητή στιγμιότυπου την προεπιλεγμένη τιμή `nil` όταν τη συναντήσει για πρώτη φορά, μέχρι να της δοθεί διαφορετική τιμή.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
