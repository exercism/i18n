# Οδηγίες

Ο χορευτικός θίασος ετοιμάζει την παράσταση του τέλους της χρονιάς: με πόσους τρόπους μπορούν να παραταχθούν οι χορευτές και πώς μοιράζεται η διάρκεια της παράστασης ανάμεσα στις πράξεις.

Και οι πέντε εργασίες μπαίνουν στην κλάση `FORMATION_COUNT`.

## 1. Πόσες παρατάξεις;

Με `n` χορευτές υπάρχουν `n` παραγοντικό τρόποι να τους παρατάξεις: `n` επιλογές για την πρώτη θέση, μετά `n-1` για την επόμενη, και ούτω καθεξής. Επέστρεψέ το ως `INTI`. Με μηδέν χορευτές υπάρχει ακριβώς μία παράταξη: η κενή.

```sather
FORMATION_COUNT::line_ups(5)
-- => 120
FORMATION_COUNT::line_ups(20)
-- => 2432902008176640000
```

## 2. Γράψε το ολόκληρο

Τον ίδιο αριθμό ως συμβολοσειρά, με όλα του τα ψηφία.

```sather
FORMATION_COUNT::line_ups_text(25)
-- => "15511210043330985984000000"
```

Ένα `INT` δεν μπορεί να χωρέσει αυτόν τον αριθμό, κι αυτό είναι το νόημα της εργασίας.

## 3. Το μερίδιο μιας πράξης

Μια παράσταση από `acts` ίσες πράξεις δίνει σε κάθε πράξη `1/acts` της διάρκειας. Επέστρεψέ το ως `RAT`.

```sather
FORMATION_COUNT::share(3)
-- => 1/3
```

## 4. Δύο πράξεις μαζί

Πρόσθεσε δύο μερίδια και επέστρεψε το σύνολο, με ακρίβεια.

```sather
FORMATION_COUNT::combined(FORMATION_COUNT::share(2), FORMATION_COUNT::share(3))
-- => 5/6
```

## 5. Γεμίζει την παράσταση;

Απάντησε αν ένα μερίδιο είναι ακριβώς ολόκληρη η παράσταση, δηλαδή ακριβώς ένα.

```sather
FORMATION_COUNT::covers_whole_show(#RAT(3, 3))
-- => true
FORMATION_COUNT::covers_whole_show(#RAT(2, 3))
-- => false
```
