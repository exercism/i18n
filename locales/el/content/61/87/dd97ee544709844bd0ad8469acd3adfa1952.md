# Υποδείξεις

## Γενικά

- Οι μετρήσεις των πουλιών ανά ημέρα αποθηκεύονται σε ένα πεδίο με όνομα `birdsPerDay`.
- Οι μετρήσεις των πουλιών ανά ημέρα είναι ένας πίνακας που περιέχει ακριβώς 7 ακέραιους αριθμούς.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

- Εφόσον κρατάμε την προηγούμενη εβδομάδα, το μόνο που χρειάζεται είναι να επιστρέψεις τις τιμές της προηγούμενης εβδομάδας.

## 2. Έλεγξε πόσα πουλιά ήρθαν σήμερα

- Θυμήσου ότι οι μετρήσεις είναι διατεταγμένες ανά ημέρα, από την παλαιότερη προς την πιο πρόσφατη, με το τελευταίο στοιχείο να αντιστοιχεί στη σημερινή ημέρα.
- Η πρόσβαση στο τελευταίο στοιχείο μπορεί να γίνει είτε χρησιμοποιώντας τη (σταθερή) θέση του (θυμήσου να αρχίζεις να μετράς από το μηδέν) είτε υπολογίζοντας τη θέση του με βάση το μέγεθος του πίνακα.

## 3. Αύξησε τη σημερινή μέτρηση

- Θέσε το στοιχείο που αντιστοιχεί στη σημερινή μέτρηση ίσο με τη σημερινή μέτρηση συν 1.

## 4. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

- Μπορείς να διατρέξεις τον πίνακα χρησιμοποιώντας έναν `for` βρόχο.
- Μια άλλη λύση είναι να χρησιμοποιήσεις το Java Stream API.

## 5. Υπολόγισε τον αριθμό των πουλιών που ήρθαν για τις πρώτες ημέρες

- Μπορείς να χρησιμοποιήσεις μια μεταβλητή για να κρατήσεις τη μέτρηση του αριθμού των πουλιών που ήρθαν.
- Μπορείς να διατρέξεις τον πίνακα χρησιμοποιώντας έναν `for` βρόχο.
- Μπορείς να ενημερώσεις τη μεταβλητή μέσα στον βρόχο.
- Θυμήσου: η αρίθμηση των θέσεων στους πίνακες ξεκινά από το `0`.

## 6. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

- Μπορείς να χρησιμοποιήσεις μια μεταβλητή για να κρατήσεις τον αριθμό των πολυάσχολων ημερών.
- Μπορείς να διατρέξεις τον πίνακα χρησιμοποιώντας έναν `foreach` βρόχο.
- Μπορείς να ενημερώσεις τη μεταβλητή μέσα στον βρόχο.
- Μπορείς να χρησιμοποιήσεις μια εντολή υπό συνθήκη μέσα στον βρόχο.
