# Εγκατάσταση

Ο πιο εύκολος τρόπος να εγκαταστήσεις τη Ceylon είναι απλώς να **μην** την εγκαταστήσεις.
Θα πρέπει να μπορείς να λύσεις τις περισσότερες ασκήσεις χρησιμοποιώντας το [διαδικτυακό IDE](http://try.ceylon-lang.org/) μας.

Ωστόσο, αν προτιμάς, μπορείς να εγκαταστήσεις τη διανομή γραμμής εντολών. Ο πιο εύκολος τρόπος για να το κάνεις αυτό είναι μέσω [SDKMAN](http://sdkman.io/), οπότε πρέπει να το εγκαταστήσεις πρώτα αν δεν το έχεις ακόμα, και μετά απλώς πληκτρολόγησε `sdk install ceylon` στο τερματικό σου.

Οι χρήστες OSX μπορούν επίσης να εγκαταστήσουν μέσω του [διαχειριστή πακέτων Homebrew](http://mxcl.github.com/homebrew/).

Οδηγίες εγκατάστασης για άλλες πλατφόρμες, καθώς και για το Ceylon IDE, ένα πρόσθετο για το Eclipse, είναι διαθέσιμες στην [επίσημη ιστοσελίδα](http://ceylon-lang.org/download/).
