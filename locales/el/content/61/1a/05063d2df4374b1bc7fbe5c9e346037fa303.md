# Σχετικά

[Τα λεξικά][dictionaries] αποτελούν έναν από τους τρεις βασικούς τύπους συλλογών της Swift.
Τα λεξικά αποθηκεύουν αντιστοιχίσεις μεταξύ _κλειδιών_, που είναι στοιχεία ενός τύπου, και _τιμών_, που είναι στοιχεία ενός άλλου τύπου (πιθανώς του ίδιου τύπου με αυτόν των κλειδιών).

Τα κυριολεκτικά λεξικών γράφονται ως μια σειρά από ζεύγη `key: value`, χωρισμένα με κόμματα, μέσα σε αγκύλες.
Τα κενά λεξικά μπορούν να γραφτούν βάζοντας μετά το όνομα του τύπου του λεξικού ένα ζεύγος παρενθέσεων, π.χ. `[Int: String]()`, ή, αν ο τύπος μπορεί να προσδιοριστεί από τα συμφραζόμενα, ως ένα απλό ζεύγος αγκυλών γύρω από μια άνω και κάτω τελεία, `[:]`.
Τα ονόματα τύπων για λεξικά γράφονται με έναν από δύο τρόπους: `Dictionary<K, V>` ή `[K: V]`, όπου `K` είναι ο τύπος των κλειδιών του λεξικού και `V` είναι ο τύπος των τιμών.
Όταν δημιουργείς ένα κενό λεξικό, ο τύπος πρέπει να προσδιορίζεται.

```swift
var addresses: Dictionary<String, String> = ["The Munsters": "1313 Mockingbird Lane", "The Simpsons": "742 Evergreen Terrace", "Buffy Summers": "1630 Revello Drive"]
var sequences: [String: [Int]] = ["Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4], "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37], "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]]
let constants = ["pi": 3.14159, "e": 2.71828, "phi": 1.618033, "avogadro": 6.02214076e23]
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

Στα στοιχεία ενός λεξικού μπορείς να έχεις πρόσβαση χρησιμοποιώντας τη σημειογραφία με αγκύλες, όπου μετά το όνομα του λεξικού ακολουθούν αγκύλες που περικλείουν το κλειδί για το οποίο θέλουμε την αντίστοιχη τιμή.

Σημείωσε, ωστόσο, ότι η τιμή που επιστρέφεται δεν είναι τύπου _Value_, αλλά προαιρετικού τύπου, _Value?_.
Αυτό συμβαίνει γιατί μπορεί να δώσεις ένα κλειδί που δεν υπάρχει στο λεξικό.
Σε αυτές τις περιπτώσεις, η Swift επιλέγει να επιστρέψει `nil` αντί να πετάξει ένα σφάλμα.

```swift
let munster: String? = addresses["The Munsters"]
// Returns "1313 Mockingbird Lane"
let carmichael = sequences["Carmichael"]
// Returns [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
let planck = constants["planck"]
// Returns nil
```

Για να αποφύγεις τον προαιρετικό τύπο της επιστροφής, μπορείς να δώσεις μια προεπιλεγμένη τιμή που θα επιστραφεί αν το κλειδί δεν βρεθεί στο λεξικό.

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828
let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []
let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

Αυτή η σημειογραφία με αγκύλες μπορεί να χρησιμοποιηθεί τόσο για να ανακτήσεις την τιμή που σχετίζεται με αυτό το κλειδί όσο και για να ορίσεις την τιμή που σχετίζεται με αυτό το κλειδί, με την προϋπόθεση ότι το λεξικό έχει οριστεί ως μεταβλητή (δηλαδή με `var`).
Αυτό μπορεί να χρησιμοποιηθεί για να ενημερώσεις την τιμή που σχετίζεται με ένα κλειδί ή για να προσθέσεις ένα νέο ζεύγος _key: value_ στο λεξικό.

```swift
sequence["Euler's totient"]?.append(contentsOf: [6,4])
sequence["Euler's totient"]
// Returns [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]
addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."
constants["Gelfond's"] = 23.140692
// compiler error: "Cannot assign through subscript: 'constants' is a 'let' constant"
```

Όπως και οι πίνακες, τα ζεύγη _key: value_ ενός λεξικού μπορούν να διατρέχονται ένα ένα με έναν βρόχο for-in.
Αυτού του είδους ο βρόχος παίρνει κάθε ζεύγος _key: value_ του λεξικού και το δεσμεύει σε ένα καθορισμένο όνομα για περαιτέρω επεξεργασία μέσα στο σώμα του βρόχου.
Το ζεύγος αναπαρίσταται ως πλειάδα και μπορεί να αποσυντεθεί όπως άλλες πλειάδες, ώστε να ανατεθεί κάθε στοιχείο σε ένα όνομα. Για παράδειγμα, για να εκτυπώσεις το βιβλίο διευθύνσεων, μπορείς να γράψεις:

```swift
for (name, address) in addresses {
  print("\(name) lives at \(address)")
}

// prints out:
// Betty Cooper lives at 111 Queens Ave.
// The Munsters lives at 1313 Mockingbird Lane
// The Simpsons lives at 742 Evergreen Terrace
// Buffy Summers lives at 1630 Revello Drive
```

Όπως και τα άλλα είδη συλλογών, τα λεξικά μπορούν να ταξινομηθούν σύμφωνα με αυθαίρετες συναρτήσεις ταξινόμησης.
Για να το κάνεις αυτό, πρέπει πρώτα να ορίσεις μια συνάρτηση που παίρνει δύο ζεύγη _key: value_, αναπαριστώμενα ως πλειάδες, και επιστρέφει ένα `Bool` τέτοιο ώστε η τιμή επιστροφής να είναι `true` αν το πρώτο ζεύγος _key: value_ πρέπει να εμφανίζεται στο ταξινομημένο αποτέλεσμα _πριν_ από το δεύτερο ζεύγος _key: value_.

Αυτή η συνάρτηση μπορεί στη συνέχεια να περαστεί στη μέθοδο `sorted(by:)` του λεξικού, η οποία θα επιστρέψει έναν ταξινομημένο πίνακα από ζεύγη _key: value_.
Π.χ. για να ταξινομήσεις το λεξικό `constants` με βάση την τιμή της σταθεράς συν τον αριθμό των χαρακτήρων στο όνομα της σταθεράς, μπορείς να γράψεις:

```swift
func weirdSort(_ lhs: (String, Double), _ rhs: (String, Double)) -> Bool {
  let left = lhs.1 + Double(lhs.0.count)
  let right = rhs.1 + Double(rhs.0.count)
  return left < right
}

let sortedConstants = constants.sorted(by: weirdSort)
// returns [(key "e", value 2.71828), (key "phi", value 1.618033), (key "pi", value 3.14159), (key "avogadro", value 6.02214076e+22)]
```
