# Σχετικά

Πολλοί [τύποι μελών struct και κλάσεων][expression-bodied-members] (με τα πεδία να αποτελούν την κύρια εξαίρεση) μπορούν να χρησιμοποιήσουν τη σύνταξη μέλους με σώμα έκφρασης. Ο ορισμός ενός μέλους με μια έκφραση συχνά παράγει πιο συνοπτικό και ευανάγνωστο κώδικα από τα παραδοσιακά μπλοκ/εντολές.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

Τα μέλη με σώμα έκφρασης δεν μπορούν να έχουν μπλοκ με πολλαπλές εντολές, αλλά όσοι έχουν υπόβαθρο στον συναρτησιακό προγραμματισμό πρέπει να προειδοποιηθούν ότι οτιδήποτε μπορεί να κάνει ένα παραδοσιακό μέλος μπορεί να επιτευχθεί με ένα από αυτά τα μέλη. Η "έκφραση" μπορεί να είναι μια πράξη ανάθεσης που δημιουργεί παρενέργειες ή μια κλήση μεθόδου, που σημαίνει ότι όλα είναι δυνατά.

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
