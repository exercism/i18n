# Οδηγίες

Η Mary είναι μεγάλη θαυμάστρια της τηλεοπτικής σειράς _Star Trek: The Next Generation_.
Παίζει συχνά παιχνίδια ρόλων με χαρτί και μολύβι, όπου εκείνη και οι φίλοι της προσποιούνται ότι είναι το πλήρωμα του _Starship Enterprise_.
Ο χαρακτήρας της Mary είναι ο Captain Picard, που σημαίνει ότι πρέπει να κρατάει το ημερολόγιο του πλοιάρχου.
Της αρέσει το δημιουργικό κομμάτι του παιχνιδιού, αλλά δεν της αρέσει να παράγει τυχαία δεδομένα επιτόπου.

Βοήθησε τη Mary δημιουργώντας τυχαίους γεννήτορες για δεδομένα που εμφανίζονται συχνά στο ημερολόγιο του πλοιάρχου.

~~~~exercism/note
Η αρχική υλοποίηση αυτής της άσκησης δέχεται ένα στιγμιότυπο `java.util.Random` ως όρισμα του κατασκευαστή.
Αυτό επιτρέπει στα tests της άσκησης να περνούν ένα στιγμιότυπο με προκαθορισμένο seed, κάνοντας τα αποτελέσματα των tests προβλέψιμα.

Επομένως, αναμένεται να χρησιμοποιήσεις το δοσμένο στιγμιότυπο `java.util.Random` στην υλοποίησή σου.
~~~~

## 1. Δημιούργησε έναν τυχαίο πλανήτη

Το _Starship Enterprise_ συναντάει πολλούς πλανήτες στα ταξίδια του.
Οι πλανήτες στο σύμπαν του Star Trek χωρίζονται σε κατηγορίες με βάση τις ιδιότητές τους.
Για παράδειγμα, η Γη είναι πλανήτης κλάσης `M`.
Όλες οι πιθανές κλάσεις πλανητών είναι: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` και `Y`.

Υλοποίησε τη μέθοδο `randomPlanetClass()`.
Θα πρέπει να επιστρέφει τυχαία μία από τις κλάσεις πλανητών.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Δημιούργησε έναν τυχαίο αριθμό νηολογίου διαστημοπλοίου

Το Enterprise (αριθμός νηολογίου `NCC-1701`) δεν είναι το μόνο διαστημόπλοιο που πετάει τριγύρω!
Όταν συναντιέται με ένα άλλο διαστημόπλοιο, η Mary πρέπει να καταγράψει τον αριθμό νηολογίου αυτού του διαστημοπλοίου.

Οι αριθμοί νηολογίου ξεκινούν με το πρόθεμα "NCC-" και στη συνέχεια χρησιμοποιούν έναν αριθμό από το `1000` έως το `9999` (συμπεριλαμβανομένων).

Υλοποίησε τη μέθοδο `randomShipRegistryNumber()` που επιστρέφει έναν τυχαίο αριθμό νηολογίου διαστημοπλοίου.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Δημιούργησε μια τυχαία αστρική ημερομηνία

Τι νόημα έχει ένα ημερολόγιο αν δεν περιλαμβάνει ημερομηνίες;

Μια αστρική ημερομηνία είναι ένας αριθμός κινητής υποδιαστολής.
Οι περιπέτειες του _Starship Enterprise_ από την πρώτη σεζόν του _The Next Generation_ διαδραματίζονται ανάμεσα στις αστρικές ημερομηνίες `41000.0` και `42000.0`.
Το "4" αντιπροσωπεύει τον 24ο αιώνα και το "1" την πρώτη σεζόν.

Υλοποίησε τη μέθοδο `randomStardate()` που επιστρέφει έναν αριθμό κινητής υποδιαστολής ανάμεσα στο `41000.0` (συμπεριλαμβανομένου) και στο `42000.0` (μη συμπεριλαμβανομένου).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
