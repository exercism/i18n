# Nil

Η Crystal έχει έναν τύπο που ονομάζεται [`Nil`][nil], ο οποίος μπορεί να έχει μόνο μία τιμή: `nil`.
Χρησιμοποιείται για να αναπαραστήσει την απουσία τιμής και είναι παρόμοιος με `null` ή `None` σε άλλες γλώσσες.

Τιμές Nil μπορούν να επιστραφούν από διάφορες μεθόδους, για παράδειγμα από τη μέθοδο [`String#[]?`][string-index], η οποία επιστρέφει `nil` αν η θέση είναι εκτός ορίων.

```crystal
"foo"[10]? # => nil
```

Η Crystal διαθέτει αυτό που είναι γνωστό ως **ΕΛΕΓΧΟΥΣ ΜΗΔΕΝΙΚΩΝ ΑΝΑΦΟΡΩΝ**, που σημαίνει ότι όλοι οι τύποι δεν μπορούν να πάρουν την τιμή `nil` από προεπιλογή.
Αυτό σημαίνει ότι δεν μπορείς να αναθέσεις `nil` σε μια μεταβλητή, εκτός αν τη δηλώσεις ρητά ως τύπο `Nil`.
Με τη σειρά του, αυτό σημαίνει ότι ο μεταγλωττιστής θα ελέγχει αυτόματα για μηδενικές αναφορές.

## Ψευδής τιμή

Μπορείς να χειριστείς τις τιμές `nil` με διάφορους τρόπους.
Το `nil` είναι μια [ψευδής][truthy-falsey] τιμή, όπως και το `false`.
Αυτό σημαίνει ότι σε εντολές και άλλα σημεία όπου αναμένεται μια ψευδής ή αληθής τιμή, θα αντιμετωπίζεται το ίδιο όπως το `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Αυτό σημαίνει ότι ο κλάδος που αξιολογείται ως αληθής δεν θα εκτελεστεί αν μια μεταβλητή που μπορεί να είναι `nil` έχει την τιμή `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Έλεγχος για `nil`

Η Crystal διαθέτει μια μέθοδο που μπορεί να χρησιμοποιηθεί για να ελέγξεις αν μια τιμή είναι `nil`.
Ονομάζεται [`nil?`][nil?] και είναι διαθέσιμη σε όλα τα αντικείμενα.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Αυτό είναι λίγο διαφορετικό όταν χρησιμοποιείς απλώς την τιμή σε μια εντολή `if`, καθώς στα προηγούμενα παραδείγματα τόσο το `false` όσο και το `nil` θα αντιμετωπίζονταν ως ψευδή.
Εδώ, μόνο το `nil` αντιμετωπίζεται ως ψευδής τιμή, αφού αν ήταν `false` δεν θα ήταν `nil`, οπότε θα ήταν αληθής τιμή.

## Ο τελεστής ή

Ο ευκολότερος τρόπος για να χειριστείς τιμές `nil` είναι να διασφαλίσεις ότι δεν θα γίνουν ποτέ `nil` εξαρχής.
Ο τελεστής ή ([`||`][or]) χρησιμοποιείται συχνά όταν έχεις να κάνεις με `Bools`, αλλά αν τον κατανοήσεις σωστά, μπορεί επίσης να χρησιμοποιηθεί για τον χειρισμό τιμών `nil`.
Ο τελεστής ή ελέγχει αν η πρώτη τιμή αξιολογείται ως αληθής. Αν όχι, χρησιμοποιείται η δεύτερη τιμή.
Αυτό μπορεί να χρησιμοποιηθεί ώστε αν η τιμή είναι `nil` να αξιολογείται ως ψευδής και έτσι να χρησιμοποιηθεί η δεύτερη τιμή.

```crystal
"foo"[10]? || "bar" # => "bar"
```
