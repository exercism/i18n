# Παράρτημα οδηγιών

Η κατεύθυνση προς την οποία κοιτάει το ρομπότ θα εκφράζεται ως ένας από τους παρακάτω αριθμούς:

- Βορράς = 0
- Ανατολή = 1
- Νότος = 2
- Δύση = 3

Όταν η είσοδος δεν είναι έγκυρη, επίστρεψε κατεύθυνση -1 (οι άλλες τιμές θα αγνοηθούν).

## Δεσμευμένη μνήμη

Ο buffer για τη συμβολοσειρά εισόδου χρησιμοποιεί τα byte 64-319 της γραμμικής μνήμης.

Η συμβολοσειρά εισόδου μπορεί να τροποποιηθεί αν το θέλεις.
