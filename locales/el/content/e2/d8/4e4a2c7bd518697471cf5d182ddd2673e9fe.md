# Προσθήκη οδηγιών

## Μορφή εξόδου

Κάθε εθνικότητα δηλώνεται με ένα μόνο γράμμα. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | έξοδος    | byte    | εθνικότητα αυτού που πίνει νερό |
| `$v1`    | έξοδος    | byte    | εθνικότητα του ιδιοκτήτη της ζέβρας |
| `$t0-9`  | προσωρινή | οποιοσδήποτε | για προσωρινή αποθήκευση     |
