# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Αν δεις ένα σφάλμα `panic:` όταν τρέχεις τα τεστ, αυτό συμβαίνει επειδή δεν έχεις υλοποιήσει μία από τις συναρτήσεις (θα πρέπει να λέει ποια) ή επειδή έχεις αφήσει τον κώδικα-πρότυπο στη θέση του. Πρέπει να αφαιρέσεις τη γραμμή `panic(...)` από τον κώδικα που σου δίνεται και να την αντικαταστήσεις με μια πραγματική υλοποίηση.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [σταθερά][constants] και να της αναθέσεις τον αναμενόμενο χρόνο ψησίματος σε λεπτά.
- Αν δεις το σφάλμα `undefined: OvenTime`, τότε έλεγξε ξανά ότι έχεις ορίσει τη σταθερά.
- Αν δεις το σφάλμα `invalid operation: got != tc.expected (mismatched types float64 and int)`, τότε πιθανότατα έχεις βάλει υποδιαστολή στο `OvenTime`, με αποτέλεσμα η Go να συμπεράνει ότι ο τύπος είναι αριθμός κινητής υποδιαστολής. Αφαίρεσε την υποδιαστολή και ο τύπος θα συμπεραθεί ως `int`.
- Αν δεις το σφάλμα `syntax error: non-declaration statement outside function body`, τότε μάλλον ξέχασες τη λέξη-κλειδί `const`.
- Αν δεις το σφάλμα `syntax error: unexpected :=, expecting =`, τότε μάλλον προσπαθείς να αναθέσεις τη σταθερά χρησιμοποιώντας το `:=` όπως σε μια μεταβλητή· οι σταθερές αναθέτονται με `=`, όχι με `:=`.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία μόνο παράμετρο.
- Πρέπει να [επιστρέψεις ρητά έναν ακέραιο][return] από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι [ακέραιος][integers].
- Μπορείς να [καλέσεις][calls] μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή της αφαίρεσης][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία μόνο παράμετρο.
- Πρέπει να [επιστρέψεις ρητά έναν ακέραιο][return] από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι [ακέραιος][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή του πολλαπλασιασμού][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον χρόνο εργασίας που έχει περάσει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Πρέπει να [επιστρέψεις ρητά έναν ακέραιο][return] από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι [ακέραιος][integers].
- Μπορείς να [καλέσεις][calls] μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή της πρόσθεσης][operators] για να προσθέσεις τιμές.
