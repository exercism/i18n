# Υποδείξεις

## Γενικά

- Τα slices στη Go έχουν μηδενική βάση.
  Η πρώτη θέση σε ένα slice είναι `0`.
- Η ενσωματωμένη συνάρτηση [`append`][append-builtin] είναι [`variadic`][variadic-gobyexample]
- Μπορείς να προσθέσεις τα στοιχεία ενός slice σε ένα άλλο slice χρησιμοποιώντας τη σημειογραφία με τις τρεις τελείες:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Δημιούργησε ένα slice με συγκεκριμένες κάρτες

- Για να δημιουργήσεις ένα slice προσυμπληρωμένο με κάποια δεδομένα, χρησιμοποίησε τη σημειογραφία slice literal: `s := []T{x1, x2, ..., xn}`.

## 2. Πάρε μια κάρτα από τη στοίβα

- Για να πάρεις το `n`-οστό στοιχείο ενός slice [χρησιμοποίησε θέση][go-slices].
- Για να ελέγξεις αν υπάρχει ένα στοιχείο σε ένα slice, χρησιμοποίησε μια συνθήκη και σύγκρινε τη θέση με το [μήκος του slice][len-builtin].

## 3. Αντάλλαξε μια κάρτα στη στοίβα

- Για να ορίσεις το `n`-οστό στοιχείο σε ένα slice, [χρησιμοποίησε θέση][go-slices] και ανάθεσέ του μια νέα τιμή.
- Για να προσθέσεις ένα νέο στοιχείο στο τέλος ενός slice, χρησιμοποίησε τη συνάρτηση `append`.

## 4. Πρόσθεσε κάρτες στην κορυφή της στοίβας

- Μπορείς να προσθέσεις στοιχεία στο μπροστινό μέρος ενός slice, προσθέτοντας τα στοιχεία του αρχικού slice στο slice του ορίσματος `value`.

## 5. Αφαίρεσε μια κάρτα από τη στοίβα

- Μπορείς να αφαιρέσεις ένα στοιχείο από ένα slice, προσθέτοντας το τμήμα μετά το `index` στο τμήμα πριν από το index.
