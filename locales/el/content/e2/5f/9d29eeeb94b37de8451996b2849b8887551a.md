# Debug

Όλη η έξοδος του script σου σε Red είναι ορατή στην κονσόλα, όταν τρέχεις κάθε τεστ. Μπορείς να κάνεις `print` ό,τι θέλεις, για παράδειγμα τις τιμές των λέξεων:

```red
print ["x =" x]
```

Επίσης, η συνάρτηση `probe` είναι πολύ χρήσιμη. Όταν αξιολογηθεί, αξιολογεί την είσοδό της, τυπώνει το αποτέλεσμα με τρόπο που αντικατοπτρίζει τον τύπο του και το επιστρέφει. Έτσι, στις περισσότερες περιπτώσεις είναι "διαφανής" και μπορείς να την εισάγεις μέσα σε εκφράσεις:

```red
x: 10
y: probe x + 5
```

Μερικές φορές η συνάρτηση `type?` (ναι, έχει ερωτηματικό στο όνομά της!) μπορεί να σου φανεί χρήσιμη για να ελέγξεις τον τύπο μιας τιμής:

```red
print ["x type:" type? x]
```

Υπάρχουν επίσης μερικές πιο προχωρημένες τεχνικές debug [καταγεγραμμένες στο Wiki του Red](https://github.com/red/red/wiki/%5BDOC%5D-Debugging).
