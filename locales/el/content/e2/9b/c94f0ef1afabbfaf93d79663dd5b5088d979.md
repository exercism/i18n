# Εισαγωγή συμβάντων

## Ιστορία

Σε αυτή την ιστορία, έχεις ένα πρόγραμμα που πρέπει να εισάγει συμβάντα, αλλά τα μηνύματα χρησιμοποιούν 3 διαφορετικές μορφές ημερομηνίας:

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

Δουλειά σου είναι να γράψεις κανονικές εκφράσεις που να αντιστοιχίζουν και να συλλαμβάνουν από κάθε τύπο.

Θίγει:

- αντιστοίχιση κυριολεκτικών χαρακτήρων
- ποσοδείκτες
- εναλλαγές
- κλάσεις χαρακτήρων
- άγκυρες

## Εργασίες

- Δημιούργησε μοτίβα για να αντιστοιχίζουν μικρά components
- Χτίσε πάνω σε αυτά και δημιούργησε μοτίβα που συλλαμβάνουν τα μικρά components
- Χτίσε πάνω σε αυτά και δημιούργησε μοτίβα που συλλαμβάνουν από τις μορφές ημερομηνίας που δίνονται
- Χτίσε πάνω σε αυτά και δημιούργησε κανονικές εκφράσεις που αντιστοιχίζουν και συλλαμβάνουν μόνο αυτή τη μορφή ημερομηνίας
