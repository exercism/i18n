# Προσθήκη στις οδηγίες

## Λέξεις

Όρισε μια πλειάδα `cmplx` με υποδοχές `real` και `imaginary`. Οι προσπελαστές των υποδοχών `real>>` και `imaginary>>` δίνονται δωρεάν με τον ορισμό της πλειάδας και είναι αυτοί που χρησιμοποιούν τα tests για να διαβάζουν τα components.

- `<cmplx> ( real imag -- cmplx )`: κατασκευάζει έναν μιγαδικό αριθμό.
- `>cmplx ( pair -- cmplx )`: φτιάχνει ένα `cmplx` από `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: επιστρέφει `{ real imaginary }`.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )`: αριθμητικές πράξεις μεταξύ δύο μιγαδικών αριθμών.
- `c-abs ( a -- |a| )`: απόλυτη τιμή (πραγματικός αριθμός).
- `c-conj ( a -- a* )`: συζυγής μιγαδικός.
- `c-exp ( z -- e^z )`: μιγαδική εκθετική.

Οι γενικές λέξεις `MATH:` του Factor (`+`, `-`, `*`, `/`) δρομολογούνται μόνο πάνω στην ενσωματωμένη μαθηματική ιεραρχία, γι' αυτό αυτή η άσκηση χρησιμοποιεί ειδικά ονόματα λέξεων αντί για μεθόδους σε αυτές τις γενικές λέξεις.

Τα tests για αριθμητική που συνδυάζει πραγματικούς με μιγαδικούς αριθμούς εξαιρούνται, καθώς κάθε πράξη εδώ είναι μεταξύ δύο τιμών `cmplx`.
