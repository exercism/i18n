# Οδηγίες

Σε αυτή την άσκηση είσαι μεγάλος φαν του αθλητισμού και μόλις ανακάλυψες το πάθος σου για το μπάσκετ του NBA.
Καθώς είσαι νέος στο μπάσκετ του NBA, εμβαθύνεις στην ιστορία του NBA, παρακολουθείς ομάδες, προπονητές και τα στατιστικά νικών/ηττών τους, και τα συγκρίνεις μεταξύ τους.

Επειδή δεν έχεις ακόμα αγαπημένη ομάδα, θα αναπτύξεις και έναν αλγόριθμο για να καταλάβεις αν αξίζει να υποστηρίξεις μια συγκεκριμένη ομάδα.
Έχεις επτά εργασίες που θα σε βοηθήσουν να αναπτύξεις τον δικό σου ιδιόκτητο αλγόριθμο _υποστήριξης ομάδας_.

## 1. Όρισε το μοντέλο

Όρισε το ψευδώνυμο τύπου `Coach` για μια καταγραφή με τα εξής δύο πεδία, με την εξής σειρά:

- `name`: το όνομα του προπονητή, τύπου `String`.
- `formerPlayer`: δηλώνει αν ο προπονητής ήταν παλιός παίκτης, τύπου `Bool`.

Όρισε το ψευδώνυμο τύπου `Stats` για μια καταγραφή με τα εξής δύο πεδία, με την εξής σειρά:

- `wins`: ο αριθμός των νικών, τύπου `Int`.
- `losses`: ο αριθμός των ηττών, τύπου `Int`.

Όρισε το ψευδώνυμο τύπου `Team` για μια καταγραφή με τα εξής τρία πεδία, με την εξής σειρά:

- `name`: το όνομα της ομάδας, τύπου `String`.
- `coach`: ο προπονητής της ομάδας, τύπου `Coach`.
- `stats`: τα στατιστικά της ομάδας, τύπου `Stats`.

## 2. Δημιούργησε μια ομάδα

Θέλεις να συνεργαστείς με κώδικα τρίτων που έχει την έννοια της ομάδας, αλλά καλεί τον κώδικά σου με τις παραμέτρους σε διαφορετική σειρά. Πρόσθεσε μια συνάρτηση `createTeam` με την εξής υπογραφή `String -> Stats -> Coach -> Team`.

## 3. Αντικατέστησε τον προπονητή

Καθώς οι ιδιοκτήτες των ομάδων του NBA είναι ανυπόμονοι, ανακάλυψες ότι τα άσχημα αποτελέσματα μιας ομάδας συχνά οδηγούσαν στην αντικατάσταση του προπονητή.
Υλοποίησε τη συνάρτηση `replaceCoach` που παίρνει ως παραμέτρους τον νέο προπονητή και την ομάδα, και επιστρέφει την ομάδα με τον νέο προπονητή:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Έλεγξε αν αξίζει να υποστηρίξεις μια ομάδα

Στο μέλλον σχεδιάζεις να φτιάξεις έναν περίπλοκο αλγόριθμο για το αν αξίζει να υποστηρίξεις μια ομάδα ή όχι, αλλά για την πρώτη προσπάθεια αποφάσισες ότι πρέπει να υποστηρίξεις κάθε ομάδα που έχει περισσότερες νίκες παρά ήττες.

Θέλεις αυτή η συνάρτηση να μπορεί να χρησιμοποιηθεί ξανά σε άλλα πλαίσια, οπότε χρησιμοποίησε μια επεκτάσιμη καταγραφή στην υπογραφή τύπου για να δέχεσαι οποιαδήποτε καταγραφή έχει τα σχετικά πεδία.
Για να κρατήσεις τη συνάρτηση όσο πιο συνοπτική γίνεται, θέλεις να χρησιμοποιήσεις αντιστοίχιση προτύπων για να πάρεις το `stats` από την παράμετρο της συνάρτησης.
Υλοποίησε τη συνάρτηση `rootForTeam` που παίρνει μια ομάδα και επιστρέφει `True` αν πρέπει να υποστηρίξεις αυτή την ομάδα· αλλιώς, επιστρέφει `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
