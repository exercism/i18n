# Σχετικά

Οι [μέθοδοι επέκτασης][extension-methods] σου επιτρέπουν να προσθέτεις μεθόδους σε υπάρχοντες τύπους χωρίς να δημιουργήσεις έναν νέο παράγωγο τύπο, χωρίς επαναμεταγλώττιση ή άλλη τροποποίηση του αρχικού τύπου.

Οι μέθοδοι επέκτασης είναι στατικές μέθοδοι, αλλά καλούνται σαν να ήταν μέθοδοι παρουσίας στον τύπο που επεκτείνουν. Αυτό το πετυχαίνουν χρησιμοποιώντας το `this` πριν από τον τύπο, υποδεικνύοντας ότι η παρουσία πάνω στην οποία βάζουμε το `.` περνιέται ως πρώτη παράμετρος. Για τον κώδικα που καλεί τη μέθοδο, δεν υπάρχει εμφανής διαφορά ανάμεσα στην κλήση μιας μεθόδου επέκτασης και των μεθόδων που ορίζονται σε έναν τύπο.

```csharp
namespace MyExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split().Length;
    }
}

"Hello World".WordCount();
// => 2
```

Οι μέθοδοι επέκτασης μπαίνουν σε εμβέλεια στο επίπεδο του χώρου ονομάτων. Αυτό σημαίνει ότι αν βρίσκεσαι σε διαφορετικό χώρο ονομάτων από αυτόν στον οποίο ορίζεται η μέθοδος επέκτασης, ο χώρος ονομάτων της πρέπει πρώτα να μπει σε μια οδηγία `using`. Για παράδειγμα, αν θέλαμε να χρησιμοποιήσουμε το παραπάνω παράδειγμα στον κώδικά μας, θα χρειαζόμασταν πρώτα μια οδηγία `using MyExtensions`. Αν βρίσκεσαι στον ίδιο χώρο ονομάτων με αυτόν στον οποίο ορίζεται η μέθοδος επέκτασης, μπορείς να χρησιμοποιήσεις τις μεθόδους επέκτασης χωρίς οδηγία `using`.

Ένα γνωστό παράδειγμα μεθόδων επέκτασης είναι οι [τυπικοί τελεστές ερωτημάτων][linq] του LINQ, που προσθέτουν δυνατότητες ερωτημάτων στους υπάρχοντες τύπους IEnumerable. Για να τους βάλουμε σε εμβέλεια, χρειαζόμαστε μια οδηγία `using System.Linq;`.

[linq]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/
[extension-methods]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/classes-and-structs/extension-methods
