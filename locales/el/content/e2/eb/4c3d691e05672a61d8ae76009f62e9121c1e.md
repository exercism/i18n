# Εισαγωγή

## Ταχυδακτυλουργία τύπων

Η ταχυδακτυλουργία τύπων μπορεί επίσης να αναφέρεται ως εξαναγκασμός τύπων.
Η ταχυδακτυλουργία τύπων συμβαίνει όταν δύο τιμές διαφορετικών τύπων εξαναγκάζονται στον ίδιο τύπο για να εκτελεστεί μια πράξη.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Αυτό μπορεί να γίνει έμμεσα (δες το παραπάνω παράδειγμα) ή ρητά με μετατροπή τύπου σε στυλ `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Οι επιτρεπόμενοι τύποι για χειροκίνητη μετατροπή τύπου είναι: `bool`, `int`, `float`, `string`, `array`, `object`.
Πιο συχνά, η μετατροπή τύπου χρησιμοποιείται για να μετατραπεί ένας ακέραιος (`int`) σε αριθμό κινητής υποδιαστολής (`float`) ή αντίστροφα.
