# Σχετικά

Τα hash είναι ένας τύπος δεδομένων στην Perl που περιέχει μια μη διατεταγμένη συλλογή από ζεύγη κλειδιών συμβολοσειρών και βαθμωτών τιμών.

Μια μεταβλητή hash συνήθως συμπληρώνεται με την εκχώρηση μιας λίστας σε αυτήν, π.χ. `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Οι λίστες συνήθως χωρίζονται με κόμματα, αλλά συχνά θα δεις αυτό που είναι γνωστό ως "παχύ κόμμα" `=>` να χωρίζει κλειδιά και τιμές σε μια λίστα. Η συμπεριφορά του είναι σχεδόν ίδια με αυτή του κόμματος, αλλά έχει το πρόσθετο πλεονέκτημα ότι ερμηνεύει το στοιχείο στην αριστερή πλευρά ως συμβολοσειρά.

Τα hash μπορούν να συμπληρωθούν με εκχώρηση σε μεμονωμένα κλειδιά, π.χ. `$scores{Alice} = 10;`.

Μπορείς να προσπελάσεις τις τιμές ενός hash δίνοντας τα κλειδιά μέσα σε άγκιστρα, π.χ. `$scores{Bob} # 15`.

Τα κλειδιά σε ένα hash είναι μοναδικά. Αν ένα κλειδί δοθεί πολλές φορές, θα διατηρηθεί μόνο η τελευταία τιμή που δόθηκε.

## Συναρτήσεις

Οι συναρτήσεις για εργασία με hash περιλαμβάνουν τις [keys][keys] και [values][values], που ανακτούν τα αντίστοιχα μέρη ενός hash ως λίστα. Οι λίστες που επιστρέφουν οι συναρτήσεις [keys][keys] και [values][values] μπορούν να φανούν χρήσιμες σε συναρτήσεις για λίστες, όπως οι [grep][grep], [map][map] και [sort][sort], καθώς και σε [for][for] βρόχους.

Άλλες συναρτήσεις για hash περιλαμβάνουν την [exists][exists], για να ελέγχεις αν ένα κλειδί υπάρχει σε ένα hash (ακόμη και αν η τιμή του είναι `undef`), και την [delete][delete], για να αφαιρείς ένα κλειδί από ένα hash.

## Διαφορές ανά σύμβολο

Όταν παίρνεις τιμές από ένα hash, το σύμβολο που δίνεις καθορίζει το αποτέλεσμα. Τα άγκιστρα `{}` στο τέλος του ονόματος της μεταβλητής είναι αυτό που λέει στην Perl ότι προσπελαύνεις ένα hash με αυτό το όνομα.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Αν και επιτρέπεται, συνιστάται να μην μοιράζονται διαφορετικοί τύποι μεταβλητών το ίδιο όνομα, για λόγους αναγνωσιμότητας.
