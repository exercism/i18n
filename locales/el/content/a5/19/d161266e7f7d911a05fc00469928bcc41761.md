# Οδηγίες

Έχεις προσληφθεί ως Βοηθός Μηχανικός Παραγωγής σε μια εταιρεία που φτιάχνει παπλώματα για χελώνες.

Οι παραγγελίες έρχονται στη διάρκεια της ημέρας ως όνομα ή αριθμός πελάτη και ποσότητα παραγγελίας.
Στη συνέχεια επεξεργάζονται το πρωί, πριν ξεκινήσει η παραγωγή της ημέρας.

Πας σπίτι με πλήρη αμοιβή μόλις εκτελεστούν όλες οι παραγγελίες της ημέρας, οπότε έχεις κίνητρο να συντομεύσεις τη μέρα εργασίας όσο το δυνατόν περισσότερο.
Επειδή κάθε παραγγελία εκτελείται από ένα μόνο μηχάνημα, το να προγραμματίζεις πρώτα τις μεγαλύτερες παραγγελίες επιτρέπει το κόστος εκκίνησης μιας εργασίας να μετακυλιστεί στις μικρότερες παραγγελίες, συντομεύοντας τον συνολικό χρόνο παραγωγής.
Γι' αυτό αποφάσισες να παρέχεις μερικές συναρτήσεις ταξινόμησης που θα βοηθήσουν αυτή την επιτάχυνση του προγραμματισμού, ώστε να πας σπίτι να πλέξεις ένα πουλόβερ για τη χελώνα σου.

## 1. Ταξινόμησε τις ποσότητες!

Όπως αναφέρθηκε, ο πίνακας των ποσοτήτων θα πρέπει να ταξινομηθεί από τη μεγαλύτερη στη μικρότερη.
Επειδή αυτοί οι πίνακες μπορεί να είναι αρκετά μεγάλοι, θα πρέπει να ταξινομούνται *επί τόπου*.
Για να παρακολουθείς τα πάντα σωστά, θα πρέπει επίσης να μπορείς να ταξινομήσεις τον πίνακα των πελατών ώστε να ταιριάζει με τις ποσότητες, οπότε θα χρειαστείς μια μετάθεση ταξινόμησης των ποσοτήτων.

Γράψε μια συνάρτηση `sortquantity!(qty)` που παίρνει ένα `Vector` από `Integer` ποσότητες.
Αυτή η συνάρτηση ταξινομεί το `qty` επί τόπου σε φθίνουσα σειρά και επιστρέφει μια μετάθεση ταξινόμησης αυτής της διάταξης.

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. Ταξινόμησε τον πελάτη

Όπως αναφέρθηκε παραπάνω, χρειάζεται να παρακολουθείς τους πελάτες σε μια καθορισμένη σειρά.

Γράψε μια συνάρτηση `sortcustomer(cust, srtperm)` που παίρνει ένα `Vector` πελατών `cust` και ένα `Vector` μετάθεσης ταξινόμησης `srtperm`.
Αυτή η συνάρτηση επιστρέφει έναν νέο πίνακα με τους πελάτες στη σειρά που ορίζει η μετάθεση ταξινόμησης.

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. Πρόγραμμα παραγωγής!

Τώρα μπορείς να τα βάλεις όλα μαζί για να κρατήσεις αυτές τις χελώνες ζεστές!
Μπορείς πλέον να ταξινομήσεις σωστά τις ποσότητες και τους πελάτες, αλλά χρειάζεται να μπορείς να ανακτήσεις την αρχική σειρά για την αποστολή.
Αυτό μπορεί να γίνει με μια αντίστροφη μετάθεση ταξινόμησης.

Γράψε μια συνάρτηση `production_schedule!(cust, qty)` που παίρνει ένα `Vector` πελατών και ένα `Vector` ποσοτήτων.
Αυτή η συνάρτηση ταξινομεί τις ποσότητες επί τόπου σε φθίνουσα σειρά.
Επιστρέφει ένα νέο `Vector` πελατών ταξινομημένο στην ίδια σειρά με τις ποσότητες και μια *αντίστροφη* μετάθεση ταξινόμησης που μπορεί να χρησιμοποιηθεί για να επαναφέρει τους ταξινομημένους πίνακες στην αρχική τους σειρά.

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
