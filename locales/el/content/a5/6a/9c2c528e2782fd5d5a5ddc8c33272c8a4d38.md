# Εισαγωγή

Οι χαρακτήρες στη Factor είναι ακέραιοι, δηλαδή σημεία κώδικα Unicode, οπότε οι αριθμητικοί τελεστές `<`, `>`, `=` σου δίνουν απευθείας διάταξη με διάκριση πεζών-κεφαλαίων. Το λεξιλόγιο [`unicode`][unicode] προσθέτει κατηγορήματα με επίγνωση του Unicode και μετατροπή πεζών και κεφαλαίων ενός μεμονωμένου χαρακτήρα.

## Κατηγορήματα χαρακτήρων

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Μετατροπή πεζών και κεφαλαίων

Τα `ch>upper` και `ch>lower` μετατρέπουν τα πεζά/κεφαλαία ενός μεμονωμένου χαρακτήρα. Τα `>upper` και `>lower` σε επίπεδο συμβολοσειράς τα εφαρμόζουν σε κάθε χαρακτήρα μιας συμβολοσειράς.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

Το `capitalize` μετατρέπει ολόκληρη τη συμβολοσειρά σε πεζά και στη συνέχεια κάνει κεφαλαίο τον πρώτο της χαρακτήρα, δηλαδή τη μορφή τίτλου μιας μόνο λέξης:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Κυριολεκτικά χαρακτήρων

Το `CHAR: A` αναλύεται στο ακέραιο σημείο κώδικα του `A`. Για ονομασμένους χαρακτήρες, χρησιμοποίησε τα ονόματα `space`, `tab`, `\n`, κ.λπ.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Σύμβολα

Όταν μια λέξη χρειάζεται να επιστρέψει μια ετικέτα αντί για μια τιμή (για παράδειγμα, `yes`/`no`/`maybe` αντί για ένα Boolean), δήλωσε κάθε ετικέτα ως *σύμβολο*. Ένα σύμβολο είναι μια λέξη που ωθεί τον εαυτό της στη στοίβα όταν καλείται, και δύο σύμβολα συγκρίνονται ως ίσα μόνο όταν έχουν το ίδιο όνομα.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

Το `SYMBOL: name` δηλώνει ένα σύμβολο· το `SYMBOLS: a b c ;` δηλώνει πολλά.
