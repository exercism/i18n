# Προσάρτηση οδηγιών

## Υλοποίηση

Αυτή η άσκηση απαιτεί να δημιουργήσεις μια δομή δεδομένων συνδεδεμένης λίστας που μπορεί να διατραβηχθεί.

1. Υλοποίησε την ιδιότητα `Count`, της οποίας η τιμή δεν θα πρέπει να μπορεί να αλλάξει από έξω.
2. Υλοποίησε τη μέθοδο `Push(T value)` που προσθέτει μια τιμή στην κεφαλή της λίστας.
3. Υλοποίησε τη μέθοδο `Pop()` που αφαιρεί και επιστρέφει μια τιμή από την κεφαλή.
4. Πρόσθεσε έναν κατασκευαστή που να επιτρέπει την αρχικοποίηση με μία μόνο τιμή ή με ένα αντικείμενο που μπορεί να διατραβηχθεί.
5. Υλοποίησε τη διεπαφή `IEnumerable<T>`. Για περισσότερες πληροφορίες, δες [ienumerable].
6. Βεβαιώσου ότι η μέθοδος `Reverse()` είναι διαθέσιμη.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
