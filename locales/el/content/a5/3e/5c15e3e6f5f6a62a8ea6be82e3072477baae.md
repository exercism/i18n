# Οδηγίες

Κάνε αναδιαμόρφωση σε έναν εκτυπωτή καθολικού.

Η άσκηση Ledger είναι μια άσκηση αναδιαμόρφωσης.
Υπάρχει κώδικας που τυπώνει ένα όμορφα μορφοποιημένο καθολικό, με δεδομένη μια τοπική ρύθμιση (αμερικανική ή ολλανδική) και ένα νόμισμα (δολάριο ΗΠΑ ή ευρώ).
Ο κώδικας όμως είναι αρκετά κακογραμμένος, αν και (κάπως παραδόξως) περνάει σταθερά όλες τις δοκιμές.

Ξαναγράψε αυτόν τον κώδικα.
Θυμήσου ότι στην αναδιαμόρφωση το κόλπο είναι να κάνεις μικρά βήματα, ώστε οι δοκιμές να περνούν συνέχεια.
Έτσι μπορείς πάντα να επιστρέφεις γρήγορα σε μια έκδοση που δουλεύει.
Εργαλεία ελέγχου εκδόσεων όπως το git μπορούν να βοηθήσουν και εδώ.

Κράτησε ένα αρχείο καταγραφής με τις αλλαγές που έκανες και γράψε ένα σχόλιο στην άσκηση που να περιέχει αυτό το αρχείο καταγραφής, αυτό θα βοηθήσει όσους την ελέγξουν.
