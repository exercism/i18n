# Παράρτημα οδηγιών

## Δεσμευμένη μνήμη

Ο buffer για τη συμβολοσειρά εισόδου χρησιμοποιεί τα byte 64-191 της γραμμικής μνήμης.

## Μορφή εισόδου

Η είσοδος έρχεται μορφοποιημένη ως μία συμβολοσειρά τριών γραμμών, με αλλαγή γραμμής στο τέλος καθεμιάς. Οι σταυροί και οι κύκλοι θα είναι πάντα κεφαλαία `X` και `O`.

Έτσι, ο πίνακας

```
X··
OXO
XOX
```
θα κωδικοποιηθεί ως

```
"X  \nOXO\nXOX\n"
```
