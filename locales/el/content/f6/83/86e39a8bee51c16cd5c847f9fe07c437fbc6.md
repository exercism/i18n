# Εισαγωγή

## Αριθμοί

Πολλές γλώσσες προγραμματισμού έχουν ειδικούς αριθμητικούς τύπους για να αναπαριστούν διαφορετικά είδη αριθμών, αλλά η JavaScript έχει μόνο δύο:

- `number`: ένας αριθμητικός τύπος δεδομένων στη μορφή κινητής υποδιαστολής διπλής ακρίβειας 64 bit (IEEE 754).
  Παραδείγματα είναι τα `-6`, `-2.4`, `0`, `0.1`, `1`, `3.14`, `16.984025`, `25`, `976`, `1024.0` και `500000`.
- `bigint`: ένας αριθμητικός τύπος δεδομένων που μπορεί να αναπαραστήσει _ακέραιους_ στη μορφή αυθαίρετης ακρίβειας.
  Παραδείγματα είναι τα `-12n`, `0n`, `4n` και `9007199254740991n`.

Αν χρειάζεσαι αυθαίρετη ακρίβεια ή δουλεύεις με εξαιρετικά μεγάλους αριθμούς, χρησιμοποίησε τον τύπο `bigint`.
Διαφορετικά, ο τύπος `number` είναι μάλλον η καλύτερη επιλογή.

### Στρογγυλοποίηση

Υπάρχει ένα ενσωματωμένο καθολικό αντικείμενο που ονομάζεται `Math` και παρέχει διάφορες [συναρτήσεις στρογγυλοποίησης][ref-math-object-rounding].
Για παράδειγμα, μπορείς να στρογγυλοποιήσεις προς τα κάτω (`floor`) ή προς τα πάνω (`ceil`) δεκαδικούς αριθμούς στους κοντινότερους ακέραιους.

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## Αριθμητικοί τελεστές

Η JavaScript παρέχει 6 διαφορετικούς τελεστές για να κάνεις βασικές αριθμητικές πράξεις με αριθμούς.

- `+`: Ο τελεστής πρόσθεσης χρησιμοποιείται για να βρεις το άθροισμα αριθμών.
- `-`: Ο τελεστής αφαίρεσης χρησιμοποιείται για να βρεις τη διαφορά δύο αριθμών
- `*`: Ο τελεστής πολλαπλασιασμού χρησιμοποιείται για να βρεις το γινόμενο δύο αριθμών.
- `/`: Ο τελεστής διαίρεσης χρησιμοποιείται για να διαιρέσεις δύο αριθμούς.

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`: Ο τελεστής υπολοίπου χρησιμοποιείται για να βρεις το υπόλοιπο μιας διαίρεσης.

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`: Ο τελεστής ύψωσης σε δύναμη χρησιμοποιείται για να υψώσεις έναν αριθμό σε μια δύναμη.

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### Σειρά πράξεων

Όταν χρησιμοποιείς πολλούς τελεστές σε μία γραμμή, η JavaScript ακολουθεί μια σειρά προτεραιότητας, όπως φαίνεται σε [αυτόν τον πίνακα προτεραιότητας][mdn-operator-precedence].
Για να το απλοποιήσουμε στο πλαίσιο μας, η JavaScript χρησιμοποιεί τον κανόνα PEDMAS (Παρενθέσεις, Εκθέτες, Διαίρεση/Πολλαπλασιασμός, Πρόσθεση/Αφαίρεση) που έχουμε μάθει στα μαθήματα στοιχειωδών μαθηματικών.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### Συντομευμένοι τελεστές ανάθεσης

Οι συντομευμένοι τελεστές ανάθεσης είναι ένας συντομότερος τρόπος να γράψεις κώδικα που εκτελεί αριθμητικές πράξεις σε μια μεταβλητή και αναθέτει τη νέα τιμή στην ίδια μεταβλητή.
Για παράδειγμα, θεώρησε δύο μεταβλητές `x` και `y`.
Τότε, το `x += y` είναι το ίδιο με το `x = x + y`.
Συχνά, αυτό χρησιμοποιείται με έναν αριθμό αντί για μια μεταβλητή `y`.
Και οι 5 υπόλοιπες πράξεις μπορούν επίσης να γίνουν με παρόμοιο τρόπο.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
