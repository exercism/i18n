# Οδηγίες

Κάθε ρόλος στη σχολική παράσταση έχει έναν αναπληρωτή: κάποιον που μπορεί να μπει στη θέση του και να κάνει ό,τι χρειάζεται ο ρόλος, χωρίς ο διευθυντής σκηνής να ξέρει ποιος είναι.

Και οι πέντε εργασίες μπαίνουν στην κλάση `UNDERSTUDY`. Οι δύο πρώτες είναι συνηθισμένες ρουτίνες, τις οποίες θα δεσμεύσουν οι επόμενες εργασίες.

## 1. Δύο τρόποι να πεις μια ατάκα

Γράψε τη `shout`, που επιστρέφει την ατάκα με κεφαλαία, και τη `whisper`, που την επιστρέφει με πεζά γράμματα, με `"..."` στην αρχή και στο τέλος.

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. Κάνε πρόβα μια ατάκα

Η `rehearse` παίρνει μια ατάκα και έναν τρόπο να την πεις και επιστρέφει το αποτέλεσμα. Το δεύτερο όρισμά της έχει τύπο `ROUT{STR}:STR`.

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. Ολόκληρη η σκηνή

Η `run_scene` παίρνει έναν πίνακα από ατάκες και έναν τρόπο να τις πεις και τις επιστρέφει όλες ειπωμένες έτσι, ενωμένες με `" "`.

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

Μια άδεια σκηνή είναι η κενή συμβολοσειρά.

## 4. Επίστρεψε έναν τρόπο να λες πράγματα

Η `understudy_for` παίρνει το όνομα ενός ύφους, `"shout"` ή οτιδήποτε άλλο, και επιστρέφει ένα `ROUT{STR}:STR`. Το `"shout"` δίνει τον τρόπο που φωνάζει. Οτιδήποτε άλλο δίνει τον τρόπο που ψιθυρίζει.

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. Προσδιόρισε ένα όρισμα

Γράψε τη `repeat`, που παίρνει έναν αριθμό φορών και μια ατάκα και επιστρέφει την ατάκα τόσες φορές, χωρίς τίποτα ανάμεσα:

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

Έπειτα γράψε τη `doubler`, που δεν παίρνει ορίσματα και επιστρέφει ένα `ROUT{STR}:STR` που επαναλαμβάνει δύο φορές ό,τι της δοθεί, δεσμεύοντας τη `repeat` με τον αριθμό ήδη συμπληρωμένο.

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
