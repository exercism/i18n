# Υποδείξεις

## Γενικά

- Οι θέσεις στον `Vector` ξεκινούν από το `1`.
- Οι τράπουλες δεν περιέχουν διπλά φύλλα.

## 1. Προσδιόρισε αν υπάρχει ένα φύλλο

- Υπάρχει μια μέθοδος [`in`/`∈`](https://docs.julialang.org/en/v1/base/collections/#Base.in) στη Base για να προσδιορίσεις αν μια συλλογή περιέχει μια τιμή.

## 2. Βρες τη θέση ενός φύλλου

- Υπάρχει μια μέθοδος [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) στη Base για να βρεις τη θέση του πρώτου στοιχείου μιας συλλογής που ταιριάζει με ένα δεδομένο κατηγόρημα.
- Το `==(x)` μπορεί να χρησιμοποιηθεί ως κατηγόρημα για να βρεις στοιχεία που είναι ίσα με το `x` σε μεθόδους που δέχονται συναρτήσεις κατηγορήματος.

## 3. Προσδιόρισε αν κάθε φύλλο είναι άρτιο

- Υπάρχει μια μέθοδος [`all`](https://docs.julialang.org/en/v1/base/collections/#Base.all-Tuple{AbstractArray,%20Any}) στη Base που επιστρέφει `true` αν όλα τα στοιχεία μιας συλλογής ικανοποιούν ένα δεδομένο κατηγόρημα.
- Η [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) είναι μια συνάρτηση κατηγορήματος.

## 4. Έλεγξε αν η τράπουλα περιέχει φύλλο με περιττή τιμή

- Υπάρχει μια μέθοδος [`any`](https://docs.julialang.org/en/v1/base/collections/#Base.any-Tuple{AbstractArray,%20Any}) στη Base που επιστρέφει `true` αν οποιοδήποτε στοιχείο μιας συλλογής ικανοποιεί ένα δεδομένο κατηγόρημα.
- Η [`isodd`](https://docs.julialang.org/en/v1/base/numbers/#Base.isodd) είναι μια συνάρτηση κατηγορήματος.

## 5. Προσδιόρισε τη θέση του πρώτου άρτιου φύλλου

- Υπάρχει μια μέθοδος [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) στη Base για να βρεις τη θέση του πρώτου στοιχείου μιας συλλογής που ταιριάζει με ένα δεδομένο κατηγόρημα.
- Η [`iseven`](https://docs.julialang.org/en/v1/base/numbers/#Base.iseven) είναι μια συνάρτηση κατηγορήματος.

## 6. Πάρε το πρώτο περιττό φύλλο από την τράπουλα

- Μπορείς να ανακτήσεις τη `n`-οστή τιμή σε ένα διάνυσμα `v` με το `v[n]`.
- Υπάρχει μια μέθοδος [`findfirst`](https://docs.julialang.org/en/v1/base/arrays/#Base.findfirst-Tuple{Function,%20Any}) στη Base για να βρεις τη θέση του πρώτου στοιχείου μιας συλλογής που ταιριάζει με ένα δεδομένο κατηγόρημα.
- Αν κανένα στοιχείο της δεδομένης συλλογής δεν ταιριάζει με το κατηγόρημα που δίνεται στο `findfirst`, το `findfirst` επιστρέφει `nothing`.
- Δες ξανά πώς λειτουργεί το `nothing` στη Julia: [concept:julia/nothingness](../../../../concepts/nothingness/about.md)
- Δες ξανά πώς λειτουργούν τα conditionals στη Julia: [concept:julia/conditionals](../../../../concepts/conditionals/about.md)
