# Προσθήκη στις οδηγίες

## Προσθήκη μεθόδων στην κλάση Array

Αυτή η άσκηση επικεντρώνεται στην προσθήκη μεθόδων στην κλάση `Array` στη Crystal.
Για να το κάνεις αυτό, θα χρειαστεί να ορίσεις μια κλάση με το όνομα `Array(T)`.
Και να βάλεις τις μεθόδους μέσα σε αυτή την κλάση.

```crystal
class Array(T)
  # your solution here
end
```

Η κλάση array είναι μια [generic][] κλάση, είναι επίσης [indexable][] και [enumerable][].
Ο πηγαίος κώδικας για την κλάση `Array` μπορεί να βρεθεί [εδώ][array].

[array]: https://github.com/crystal-lang/crystal/blob/7aa5cdd86/src/array.cr#L48
[generic]: https://crystal-lang.org/docs/syntax_and_semantics/generics.html
[indexable]: https://crystal-lang.org/api/Indexable.html
[enumerable]: https://crystal-lang.org/api/Enumerable.html
