# χρησιμοποιήθηκε string builder

Η συνάρτηση `%{function}` είναι χρήσιμη όταν συνενώνεις πολλά μικρά κομμάτια σε μια συμβολοσειρά.
Σε αυτή την περίπτωση, ο τελεστής `+=` είναι απλούστερος, ταχύτερος και χρησιμοποιεί λιγότερη μνήμη.
Αυτό μπορείς να το επαληθεύσεις τρέχοντας τα benchmarks όπως περιγράφονται στις οδηγίες της άσκησης.
