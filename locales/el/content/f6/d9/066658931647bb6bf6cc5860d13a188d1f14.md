# Οδηγίες

Σε αυτή την άσκηση είσαι μεγάλος φαν του αθλητισμού και μόλις ανακάλυψες πάθος για το μπάσκετ του NBA. Καθώς είσαι νέος στο μπάσκετ του NBA, εμβαθύνεις στην ιστορία του NBA, παρακολουθείς ομάδες, προπονητές και τα στατιστικά νικών/ηττών τους και τα συγκρίνεις μεταξύ τους.

Καθώς δεν έχεις ακόμα αγαπημένη ομάδα, θα αναπτύξεις επίσης έναν αλγόριθμο για να καταλάβεις αν πρέπει να υποστηρίξεις μια συγκεκριμένη ομάδα.

Έχεις επτά εργασίες για να σε βοηθήσουν να αναπτύξεις τον δικό σου αλγόριθμο _υποστήριξης-ομάδας_.

## 1. Όρισε το μοντέλο

Όρισε την καταγραφή `Coach` με τα εξής δύο πεδία:

- `Name`: το όνομα του προπονητή, τύπου `string`.
- `FormerPlayer`: υποδεικνύει αν ο προπονητής ήταν πρώην παίκτης, τύπου `bool`.

Όρισε την καταγραφή `Stats` με τα εξής δύο πεδία:

- `Wins`: ο αριθμός των νικών, τύπου `int`.
- `Losses`: ο αριθμός των ηττών, τύπου `int`.

Όρισε την καταγραφή `Team` με τα εξής τρία πεδία:

- `Name`: το όνομα της ομάδας, τύπου `string`.
- `Coach`: ο προπονητής της ομάδας, τύπου `Coach`.
- `Stats`: τα στατιστικά της ομάδας, τύπου `Stats`.

## 2. Δημιούργησε τον προπονητή μιας ομάδας

Υλοποίησε τη συνάρτηση `createCoach` που παίρνει ως παραμέτρους το όνομα του προπονητή και την κατάστασή του ως πρώην παίκτη και επιστρέφει την καταγραφή `Coach`:

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. Δημιούργησε τα στατιστικά μιας ομάδας

Υλοποίησε τη συνάρτηση `createStats` που παίρνει ως παραμέτρους τον αριθμό των νικών και τον αριθμό των ηττών και επιστρέφει την καταγραφή `Stats`:

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. Δημιούργησε μια ομάδα

Υλοποίησε τη συνάρτηση `createTeam` που παίρνει ως παραμέτρους το όνομα της ομάδας, τον προπονητή και την καταγραφή και επιστρέφει την καταγραφή `Team`:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. Αντικατέστησε τον προπονητή

Καθώς οι ιδιοκτήτες του NBA είναι ανυπόμονοι, ανακάλυψες ότι τα άσχημα αποτελέσματα μιας ομάδας συχνά οδηγούσαν στην αντικατάσταση του προπονητή. Υλοποίησε τη συνάρτηση `replaceCoach` που παίρνει ως παραμέτρους την ομάδα και τον νέο της προπονητή και επιστρέφει την ομάδα με τον νέο προπονητή:

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. Έλεγξε αν είναι η ίδια ομάδα

Καθώς ψάχνεις στα στατιστικά, κρατάς λίστες με ομάδες και τις καταγραφές τους. Μερικές φορές κάνεις λάθη και υπάρχουν διπλές καταχωρήσεις στη λίστα σου. Υλοποίησε τη συνάρτηση `isSameTeam` που παίρνει δύο ομάδες και επιστρέφει `true` αν είναι η ίδια ομάδα· αλλιώς, επιστρέφει `false`:

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. Έλεγξε αν πρέπει να υποστηρίξεις μια ομάδα

Έχοντας εξετάσει πολλές ομάδες και αγώνες, κατέληξες σε έναν αλγόριθμο. Αν ισχύει ένα από τα παρακάτω, υποστηρίζεις αυτή την ομάδα:

- Το όνομα του προπονητή είναι "Gregg Popovich"
- Ο προπονητής είναι πρώην παίκτης
- Το όνομα της ομάδας είναι "Chicago Bulls"
- Η ομάδα έχει κερδίσει 60 ή περισσότερους αγώνες
- Η ομάδα έχει περισσότερες ήττες από νίκες

Υλοποίησε τη συνάρτηση `rootForTeam` που παίρνει μια ομάδα και επιστρέφει `true` αν πρέπει να υποστηρίξεις αυτή την ομάδα· αλλιώς, `return` false:

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
