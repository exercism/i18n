# Εισαγωγή

## Ακέραιοι αριθμοί

Η C#, όπως πολλές στατικά τυπισμένες γλώσσες, παρέχει αρκετούς τύπους που αναπαριστούν ακέραιους αριθμούς, ο καθένας με το δικό του εύρος τιμών. Στο κάτω άκρο, ο τύπος `sbyte` έχει ελάχιστη τιμή -128 και μέγιστη τιμή 127. Όπως σε όλους τους ακέραιους τύπους, αυτές οι τιμές είναι διαθέσιμες ως `<type>.MinValue` και `<type>.MaxValue`. Στο πάνω άκρο, ο τύπος `long` έχει ελάχιστη τιμή -9.223.372.036.854.775.808 και μέγιστη τιμή 9.223.372.036.854.775.807. Στη μέση βρίσκονται οι τύποι `short` και `int`.

Τα εύρη καθορίζονται από το πλάτος αποθήκευσης του τύπου, όπως το δεσμεύει το σύστημα. Για παράδειγμα, ένα `byte` χρησιμοποιεί 8 bit και ένα `long` χρησιμοποιεί 64 bit.

Κάθε ένας από τους παραπάνω τύπους συνδυάζεται με έναν αντίστοιχο ανυπόγραφο τύπο: `sbyte`/`byte`, `short`/`ushort`, `int`/`uint` και `long`/`ulong`. Σε όλες τις περιπτώσεις, το εύρος των τιμών είναι από το 0 έως το αρνητικό του προσημασμένου μεγίστου επί 2 συν 1.

| Type   | Width  | Minimum                    | Maximum                     |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 bit  | -128                       | +127                        |
| short  | 16 bit | -32_768                    | +32_767                     |
| int    | 32 bit | -2_147_483_648             | +2_147_483_647              |
| long   | 64 bit | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 bit  | 0                          | +255                        |
| ushort | 16 bit | 0                          | +65_535                     |
| uint   | 32 bit | 0                          | +4_294_967_295              |
| ulong  | 64 bit | 0                          | +18_446_744_073_709_551_615 |

Μια μεταβλητή (ή μια παράσταση) ενός τύπου μπορεί εύκολα να μετατραπεί σε άλλον τύπο. Για παράδειγμα, σε μια εντολή ανάθεσης, αν ο τύπος της τιμής που ανατίθεται (lhs) εξασφαλίζει ότι η τιμή θα βρίσκεται μέσα στο εύρος του τύπου στον οποίο γίνεται η ανάθεση (rhs), τότε αρκεί μια απλή ανάθεση:

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

Από την άλλη, αν το εύρος του τύπου από τον οποίο γίνεται η ανάθεση δεν είναι υποσύνολο του εύρους τιμών του δέκτη, τότε απαιτείται μια πράξη cast, `()`, ακόμη και αν η συγκεκριμένη τιμή βρίσκεται μέσα στο εύρος του δέκτη:

```csharp
short s = 42;
uint ui = (uint)s;
```

### Μετατροπή bit

Η κλάση `BitConverter` παρέχει έναν βολικό τρόπο μετατροπής ακέραιων τύπων από και προς πίνακες byte.
