# Υποδείξεις

## 1. Κατηγοριοποίησε τους πελάτες

- Οι συναρτήσεις `any()` ή `all()` μπορούν να βοηθήσουν εδώ.
- Μπορείς να ορίσεις μια ξεχωριστή συνάρτηση για χρήση σε αυτές, ή να χρησιμοποιήσεις απευθείας μια ανώνυμη συνάρτηση.

## 2. Ξεχώρισε τους πελάτες με έντονη γνώμη

- Πρέπει να φιλτράρεις το λεξικό.
- Ένα λεξικό, από προεπιλογή, διατρέχει ένα `Pair` κλειδιού/τιμής στο οποίο μπορείς να έχεις πρόσβαση μέσω πεδίων (first/second) ή θέσης (1/2).
- Χρησιμοποίησε τη συνάρτηση `all_15()` σου.

## 3. Μετέτρεψε τις βαθμολογίες σε δυαδικές

- Χρειάζεσαι μια αντιστοίχιση του `1` στο `0` και του `5` στο `1`.
- Βεβαιώσου ότι το σχήμα του πίνακα εξόδου είναι το ίδιο με το σχήμα του πίνακα εισόδου.

## 4. Μετέτρεψε τις βαθμολογίες σε μήτρα

- Αυτό μπορεί να γίνει με τη `mapreduce()`.
- Χρησιμοποίησε τη συνάρτηση `tobinary()` για (μέρος της;) αντιστοίχισης.
- Μια μήτρα μπορεί να προκύψει ανάγοντας ένα διάνυσμα από διανύσματα με `hcat()` ή `vcat()`, ανάλογα με την είσοδο διανύσματος στήλης ή γραμμής, αντίστοιχα.
- Πρόσεξε την έξοδό σου. Είναι κάθε διάνυσμα βαθμολογίας μια γραμμή στη μήτρα; Η συνάρτηση `transpose()` μπορεί να φανεί χρήσιμη κάπου.
