# Εμφωλευμένες συναρτήσεις

Οι συναρτήσεις μπορούν να οριστούν [μέσα σε άλλες συναρτήσεις][nested-functions].
Αυτό χρησιμοποιείται συχνά για τη δημιουργία βοηθητικών συναρτήσεων, οι οποίες είναι χρήσιμες μόνο στη συνάρτηση που τις περικλείει και επομένως δεν χρειάζεται να λερώνουν τον εξωτερικό χώρο ονομάτων.

Αυτές οι συναρτήσεις ορίζονται και καλούνται ακριβώς όπως οι κανονικές συναρτήσεις, αλλά δεν είναι ορατές έξω από τη συνάρτηση που τις περικλείει.

```swift
func makeNumber(_ number: Int) -> Int {
  func double(_ x: Int) -> Int { 2 * x }
  func add(_ x: Int) -> Int { x + 1 }

  return number.isMultiple(of: 2) ? add(double(number)) : double(number)
}

makeNumber(3)
// Returns 6
makeNumber(4)
// Returns 9
```

[nested-functions]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Nested-Functions
