# Οδηγίες

Διατηρείς ένα μικρό μετεωρολογικό πόστο στην όχθη του Βλτάβα στην Πράγα και σε κάθε βάρδια σημειώνεις τις μετρήσεις θερμοκρασίας σε ένα αρχείο καταγραφής απλού κειμένου, μία μέτρηση ανά γραμμή. Πέντε μικρές λέξεις αναλαμβάνουν όλη τη δουλειά της καταγραφής για μία βάρδια.

Κάθε λέξη δέχεται το μονοπάτι προς το αρχείο καταγραφής.

## 1. Διάβασε κάθε μέτρηση

Όρισε τη `read-readings` ώστε να επιστρέφει όλες τις μετρήσεις του αρχείου καταγραφής ως πίνακα συμβολοσειρών, μία ανά γραμμή.

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. Βρες την τελευταία μέτρηση

Όρισε τη `latest-reading` ώστε να επιστρέφει την πιο πρόσφατη μέτρηση, δηλαδή την τελευταία γραμμή του αρχείου καταγραφής.

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. Διάβασε το ακατέργαστο αρχείο καταγραφής

Όρισε τη `log-text` ώστε να επιστρέφει ολόκληρο το αρχείο καταγραφής ως μία συμβολοσειρά, ακριβώς όπως είναι αποθηκευμένο.

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. Κατέγραψε μια μέτρηση

Όρισε τη `record-reading` ώστε να προσθέτει μια νέα μέτρηση στο τέλος του αρχείου καταγραφής ως δική της γραμμή, αφήνοντας τις προηγούμενες μετρήσεις ανέπαφες. Δεν επιστρέφει τίποτα.

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. Ξαναγράψε το αρχείο καταγραφής

Όρισε τη `rewrite-log` ώστε να αντικαθιστά ολόκληρο το αρχείο καταγραφής με έναν νέο πίνακα μετρήσεων, μία ανά γραμμή.

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
