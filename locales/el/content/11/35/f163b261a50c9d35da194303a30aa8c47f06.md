# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να δημιουργήσεις τον τύπο δεδομένων `Robot`,
ως μεταβλητή που μπορεί να αλλάξει, και τον τύπο δεδομένων `RunState`. Πρέπει επίσης να
υλοποιήσεις τις παρακάτω συναρτήσεις:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Θα βρεις μια εικονική δήλωση δεδομένων και υπογραφές τύπων να υπάρχουν ήδη,
αλλά εξαρτάται από εσένα να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν
τύπο δεδομένων με νόημα, ένα newtype ή ένα συνώνυμο τύπου. Για να μοντελοποιήσει
την κατάσταση, αυτή η άσκηση χρησιμοποιεί τη μονάδα
[`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State).
Πιο συγκεκριμένα, συνδυάζουμε τη μονάδα `State` με τη μονάδα `IO` χρησιμοποιώντας
τους [μετασχηματιστές μονάδων `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html).
Όλα τα τεστ εκτελούνται με το `initialState` ως την κατάσταση που τροφοδοτείται στο `evalStateT`.
