# Σχετικά

Το `TUPLE:` δηλώνει μια κλάση με ονομασμένες υποδοχές. Το Factor δημιουργεί αυτόματα μια λέξη κατασκευαστή (με την κατάληξη `new` στο όνομα της κλάσης), έναν κατασκευαστή `boa` ("κατά σειρά ορισμάτων"), μια κυριολεκτική σύνταξη `T{ class … }` και λέξεις προσπέλασης για κάθε υποδοχή.

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

Το σύστημα προσπέλασης στο [`accessors`][accessors] παρέχει τέσσερις παραλλαγές για κάθε υποδοχή: `name>>`, `>>name`, `change-name` και το ζεύγος μετάλλαξης `[ … ] change-name`. Τα `>>name` και `change-name` μεταλλάσσουν την πλειάδα. Κάνε πρώτα `clone` όταν θέλεις να αφήσεις το αρχικό ανέπαφο.

Οι πλειάδες υποστηρίζουν το `=` με δομική ισότητα και, κατά την εκτύπωση, εμφανίζουν τις μη προεπιλεγμένες τιμές των υποδοχών.

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
