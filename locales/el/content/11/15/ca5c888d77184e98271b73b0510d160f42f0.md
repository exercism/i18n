# Βοήθεια

## Εγκατάσταση του Cairo

Ανατρέξε στη [σελίδα βοήθειας του Exercism][help-page] για την εγκατάσταση του Cairo και πόρους μάθησης.

## Υποβολή της λύσης

Γενικά, καλό είναι να υποβάλλεις όλα τα αρχεία στα οποία υλοποίησες τη λύση σου (`src/lib.cairo` στις περισσότερες περιπτώσεις). Αν χρησιμοποιείς εξωτερικά crates, σκέψου να υποβάλεις και το αρχείο `Scarb.toml`. Αυτό θα κάνει τη διαδικασία αξιολόγησης πιο γρήγορη και πιο ξεκάθαρη.

## Σχόλια, Ζητήματα, Pull Requests

Στο [αποθετήριο του track][github] στο GitHub θα βρεις όλες τις ασκήσεις του Cairo. Αν έχεις σχόλια για κάποια άσκηση ή θέλεις να βοηθήσεις στην υλοποίηση νέων ασκήσεων, πήγαινε εκεί και άνοιξε ένα ζήτημα. Τα μέλη της ομάδας του track του Cairo θα χαρούν να βοηθήσουν!

Αν θέλεις να μάθεις περισσότερα για το Exercism, ρίξε μια ματιά στον [οδηγό συνεισφοράς].

## Υποβολή ημιτελών λύσεων

Μπορείς να υποβάλεις μια ημιτελή λύση, ώστε να δεις πώς ολοκλήρωσαν την άσκηση οι άλλοι.
