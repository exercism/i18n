# Οδηγίες

Ο Andrew, προγραμματιστής στην εταιρεία του, έφτιαξε πρόσφατα ένα ελαφρύ βοηθητικό εργαλείο παραγωγής ερωτημάτων SQL για ένα εργαλείο μετεγκατάστασης βάσεων δεδομένων.
Η πρώτη, αφελής υλοποίησή του δούλευε τέλεια για μικρά σύνολα δεδομένων.
Ωστόσο, κατά τη διάρκεια μεγάλων μετεγκαταστάσεων σε παραγωγικό περιβάλλον, η εφαρμογή άρχισε να καταναλώνει υπερβολική μνήμη και δυσκολευόταν κάτω από μεγάλο φόρτο.
Αφού μέτρησε την απόδοση της εφαρμογής, ο Andrew κατάλαβε ότι η απλή συνένωση συμβολοσειρών μέσα σε βρόχους ανάγκαζε τη Go να ανακατανέμει συνεχώς μνήμη.
Τώρα χρειάζεται τη βοήθειά σου για να αναδιαμορφώσει το εργαλείο χρησιμοποιώντας το `strings.Builder` της Go, ώστε η εφαρμογή να κλιμακώνεται ομαλά και να διαχειρίζεται μεγάλους όγκους κειμένου χωρίς να συνθλίβει τον σωρό μνήμης.

## 1. Δημιουργία ερωτημάτων SELECT

Υλοποίησε τη συνάρτηση `BuildSelectQuery`.
Δέχεται το όνομα ενός πίνακα (`string`) και ένα slice με ονόματα στηλών (`[]string`).
Θα πρέπει να επιστρέφει μια πλήρη εντολή SQL `SELECT` που τελειώνει με το σύμβολο `;`.
Αν το slice με τις στήλες είναι κενό ή `nil`, το ερώτημα θα πρέπει να καταφεύγει στον χαρακτήρα μπαλαντέρ `*` για να επιλέξει όλες τις στήλες.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Δημιουργία εντολών INSERT κατά παρτίδες

Υλοποίησε τη συνάρτηση `BuildBatchInserts`.
Δέχεται το όνομα ενός πίνακα (`string`) και ένα διδιάστατο slice που αναπαριστά γραμμές της βάσης δεδομένων (`[][]ColumnValue`).
Κάθε στοιχείο σε μια γραμμή συνδέει το όνομα μιας συγκεκριμένης στήλης με την τιμή της ως συμβολοσειρά.
Η συνάρτηση πρέπει να επιστρέφει ένα slice από ξεχωριστές συμβολοσειρές SQL `INSERT`.
Η δομημένη μορφή του slice εγγυάται προβλέψιμη και σταθερή σειρά στην έξοδο των ερωτημάτων.
Αν το slice εισόδου με τις γραμμές είναι κενό, επίστρεψε ένα κενό slice συμβολοσειρών.
Αν κάποια μεμονωμένη γραμμή είναι κενή, παράλειψέ την.
Οι τιμές συμβολοσειρών μέσα στη ρήτρα `VALUES` πρέπει να περικλείονται σε απλά εισαγωγικά `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
