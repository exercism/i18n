## Οδηγίες

Σε έχουν προσλάβει σε ένα κέντρο ανακύκλωσης.
Λόγω έλλειψης χώρου, όλα τα προϊόντα μπαίνουν στον ίδιο ιμάντα μεταφοράς, αλλά αυτό έχει οδηγήσει στο να αναμειγνύονται διαφορετικά υλικά μεταξύ τους, με αποτέλεσμα να γίνονται άχρηστα.
Για να το διορθώσεις, σου έχει ανατεθεί να φτιάξεις συναρτήσεις που αναγνωρίζουν τον τύπο ενός προϊόντος.

### 1. Έλεγξε αν μια τιμή είναι boolean (λογική τιμή)

Υλοποίησε τη συνάρτηση `isBoolean`, που ελέγχει αν μια τιμή είναι boolean.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Έλεγξε αν μια τιμή είναι ένας αριθμός.

Υλοποίησε τη συνάρτηση `isNumber`, που ελέγχει αν μια τιμή είναι ένας _πεπερασμένος_ `number` ή `bigint`, δηλαδή όχι `NaN` ή `Infinity`.

Μερικές φορές, η συσκευή ανάγνωσης ID αποτυγχάνει και διαβάζει μια μη αριθμητική τιμή ως `NaN` (Not a Number) ή `Infinity`.
Η συνάρτησή σου θα πρέπει να μπορεί να το χειριστεί σωστά κι αυτό.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Έλεγξε αν μια τιμή είναι αντικείμενο

Υλοποίησε τη συνάρτηση `isObject`, που θα πρέπει να ελέγχει αν η τιμή είναι αντικείμενο.
Στον ιμάντα, το `null` δεν είναι τίποτα και δεν θεωρείται αντικείμενο.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Έλεγξε αν μια συμβολοσειρά είναι αριθμητική

Υλοποίησε τη συνάρτηση `isNumericString`, που θα πρέπει να ελέγχει αν η τιμή είναι μια συμβολοσειρά που αποτελείται μόνο από ψηφία ή από ένα μείον ακολουθούμενο από ψηφία, που δηλώνει αρνητικό αριθμό.
Μόνο οι ακέραιοι θα πρέπει να λαμβάνονται υπόψη, τα δεκαδικά δεν θεωρούνται αριθμητικά για αυτόν τον έλεγχο του ρομπότ ανακύκλωσης.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Έλεγξε αν ένα αντικείμενο είναι ηλεκτρονικό

Υλοποίησε τη συνάρτηση `isElectronic`, που ελέγχει αν ένα αντικείμενο είναι στιγμιότυπο της παρεχόμενης κλάσης `ElectronicDevice` ή μιας από τις υποκλάσεις της.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Έλεγξε αν μια τιμή είναι μη κενός πίνακας

Υλοποίησε τη συνάρτηση `isNonEmptyArray`, που ελέγχει αν μια τιμή είναι μη κενός πίνακας.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Έλεγξε αν μια τιμή είναι κενός πίνακας

Υλοποίησε τη συνάρτηση `isEmptyArray`, που ελέγχει αν μια τιμή είναι κενός πίνακας.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Έλεγξε αν ένα αντικείμενο έχει ιδιότητα ή μέθοδο `type`

Υλοποίησε τη συνάρτηση `hasType`, που ελέγχει αν ένα αντικείμενο έχει ιδιότητα ή μέθοδο `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Πέτα ένα σφάλμα αν ένα αντικείμενο δεν έχει ιδιότητα ή μέθοδο `id`

Υλοποίησε τη συνάρτηση `assertHasId`, που θα πετάει ένα `Error` αν από ένα αντικείμενο λείπει η ιδιότητα `id`.

Αν ένα αντικείμενο έχει την ιδιότητα `id`, δεν θα πρέπει να επιστρέφει τίποτα.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Έλεγξε αν ένα αντικείμενο έχει ιδιότητα `id`

Υλοποίησε τη συνάρτηση `hasIdProperty`, που ελέγχει αν ένα αντικείμενο έχει ιδιότητα `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Έλεγξε αν ένα αντικείμενο έχει ορισμένη ιδιότητα `type`

Υλοποίησε τη συνάρτηση `hasDefinedType`, που ελέγχει αν ένα αντικείμενο έχει ιδιότητα `type` που δεν είναι `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
