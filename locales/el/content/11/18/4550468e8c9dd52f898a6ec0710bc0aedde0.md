# Οδηγίες

Τα HTTP endpoints είναι καλύτερα με έλεγχο τύπων. Η προσθήκη ενός τύπου καταγραφής σε ένα αίτημα POST διασφαλίζει ότι τα σωστά δεδομένα στέλνονται κάθε φορά.

## Στόχοι

- Τροποποίησε τον κώδικα που σου δίνεται.
- Πρόσθεσε τα απαραίτητα χαρακτηριστικά σε αυτή την καταγραφή ώστε να δέχεται δύο τελεστέους και έναν τελεστή.
- Πρόσθεσε μια συνάρτηση resource HTTP που να δέχεται αίτημα POST στη διαδρομή '/calc'
- Η συνάρτηση πρέπει να δέχεται τον τύπο καταγραφής Calculation ως payload και να επιστρέφει ένα γενικό αντικείμενο JSON

### Δέχεται

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Επιστρέφει

```json
{ "expression": "4+10.2", "result": 14.2 }
```
