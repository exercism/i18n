# Εισαγωγή

Είδαμε σε προηγούμενες Έννοιες ότι οι τύποι στη Julia σχηματίζουν μια ιεραρχία, με τον `Any` στην κορυφή.

Οι αφηρημένοι τύποι, όπως ο `Number`, έχουν υποτύπους, αλλά δεν μπορείς να δημιουργήσεις στιγμιότυπό τους.
Όταν ορίζεις μια μεταβλητή με αφηρημένο τύπο, _περιορίζεις_ τις τιμές της μεταβλητής σε οποιονδήποτε υποτύπο του αφηρημένου τύπου.
Για παράδειγμα:

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

Αυτό μας δίνει ένα είδος ευελιξίας ως προς το ποιες είσοδοι είναι έγκυρες.

Ωστόσο, ας υποθέσουμε ότι θέλουμε μια μεταβλητή να δέχεται και ακέραιες τιμές και τιμές συμβολοσειράς;
Αυτοί οι τύποι δεν βρίσκονται στον ίδιο κλάδο της ιεραρχίας.

Θα μπορούσαμε να θέσουμε τον τύπο σε `Any`, ή να τον αφήσουμε να πάρει αυτή την προεπιλογή, αλλά τότε χάνουμε κάθε έλεγχο των επιτρεπόμενων τύπων.

Για μια καλύτερη προσέγγιση, έχουμε τη σύνταξη `Union{ }`, με δύο ή περισσότερους τύπους μέσα στα άγκιστρα.

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

Ένα άλλο παράδειγμα χρησιμοποιεί την ίδια ένωση τύπων σε μια υπογραφή συνάρτησης:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

Εδώ δώσαμε στον τύπο ένα όνομα, το οποίο μπορεί να προσφέρει μια βολική συντομογραφία, αλλά δεν είναι απολύτως απαραίτητο.
Η συνάρτηση `g(z::Union{Integer, String}) = z^3` συμπεριφέρεται με τον ίδιο τρόπο.

Θα πούμε πολλά περισσότερα για τις υπογραφές συναρτήσεων στην Έννοια της Πολλαπλής Αποστολής.

## Ενώσεις με το nothing

Αρκετές άλλες γλώσσες έχουν τύπους που μπορεί να περιέχουν ή να μην περιέχουν τιμή, με ονόματα όπως `Option`, `Nullable` ή `Maybe`.

Η Julia δεν έχει ειδική σύνταξη για αυτό, αλλά οι ενώσεις τύπων είναι μια γενίκευση της ίδιας ιδέας.

Είδαμε στην Έννοια `Nothingness` ότι η Julia έχει διάφορους τρόπους να αναπαραστήσει μη-τιμές, όπως το `nothing` και το `missing`.
Οποιοδήποτε από αυτά μπορεί να συμπεριληφθεί σε μια ένωση τύπων.

Για παράδειγμα, όταν ορίζουμε κάποιου είδους συνδεδεμένη λίστα, χρειαζόμαστε έναν τρόπο να τερματίζουμε τη λίστα αν δεν υπάρχουν άλλοι κόμβοι.
Το `Nothing` είναι ο τύπος με μοναδική τιμή το `nothing`, και αυτός ο ορισμός του Node καθιστά δυνατό να σηματοδοτήσουμε το τέλος της αλυσίδας:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

Παρομοίως, το `missing` μπορεί να χρησιμοποιηθεί ως υποκατάστατο για απούσες τιμές, ειδικά σε συλλογές όπως τα διανύσματα.
Το παρακάτω παράδειγμα είναι αρκετά τεχνητό, αλλά οι απούσες τιμές είναι συνηθισμένες σε πραγματικά σύνολα δεδομένων.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
