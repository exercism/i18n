# Οδηγίες

Είσαι ο αξιωματικός βάρδιας σε ένα σκάφος που διαπλέει τον Βερίγγειο Πορθμό. Τρεις πηγές αναφέρουν τη θέση κάθε παγοπλάκας και κάθε ακρωτηρίου που φαίνεται:

- Το **γραφείο χαρτών** μιλάει με κατευθύνσεις πυξίδας: `north`, `east`, `south`, `west`. Μόνο μια κατεύθυνση, χωρίς απόσταση.
- Ο **ναυτίλος** μιλάει με *πολικές* συντεταγμένες από το τελευταίο στίγμα του σκάφους: ένα μέγεθος σε ναυτικά μίλια και μια διόπτευση σε μοίρες, δεξιόστροφα από τον βορρά (άρα το `0` είναι north, το `90` είναι east, το `180` είναι south, το `270` είναι west).
- Ο **παρατηρητής στο κατάρτι** μιλάει με *σχετικές* συντεταγμένες: μια απόσταση προς τα εμπρός και ένα από τα `ahead`, `starboard`, `behind`, `port`. Οι σχετικές διοπτεύσεις μετρούνται ως προς *την τρέχουσα πορεία του πλοίου*. Ο καπετάνιος ανακοινώνει αυτή την πορεία στη γέφυρα πριν από κάθε βάρδια.

Η δουλειά σου είναι να μετατρέψεις και τις τρεις σε ένα κοινό καρτεσιανό πλαίσιο `(x, y)`, ώστε να μπορεί να σχεδιαστεί ο χάρτης. Οι διοπτεύσεις είναι σε μοίρες. Το `(0, 1)` είναι ένα ναυτικό μίλι προς τον βορρά και το `(1, 0)` είναι ένα ναυτικό μίλι προς την ανατολή.

## 1. Το μοντέλο δεδομένων και οι καρτεσιανές συντεταγμένες για το cardinal

Πρώτα, όρισε τα κομμάτια που μοιράζεται όλη η άσκηση:

- Όρισε τρεις πλειάδες: `cardinal` (μία θέση, `direction`), `polar` (θέσεις `magnitude` και `bearing`) και `relative` (θέσεις `distance` και `bearing`).
- Δήλωσε τα σύμβολα των κατευθύνσεων με `SYMBOLS:`: `north`, `east`, `south`, `west`, `ahead`, `starboard`, `behind`, `port`.
- Δήλωσε μια δυναμική μεταβλητή `heading` με `SYMBOL:` (η εργασία 3 τη χρησιμοποιεί).
- Δήλωσε δύο γενικές λέξεις: `GENERIC: >cartesian ( direction -- x y )` και `GENERIC: flip ( direction -- direction' )`. Θα προσθέσεις τις μεθόδους τους στις επόμενες εργασίες.

Έπειτα, πρόσθεσε τη μέθοδο `M: cardinal` του `>cartesian`, που επιστρέφει το μοναδιαίο διάνυσμα για τη συγκεκριμένη κατεύθυνση.

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. Καρτεσιανές συντεταγμένες για το polar

Πρόσθεσε μια μέθοδο `M: polar` στο `>cartesian` που μετατρέπει την πολική μορφή σε `(x, y)`:

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. Καρτεσιανές συντεταγμένες για το relative

Πρόσθεσε μια μέθοδο `M: relative` στο `>cartesian`. Η ιδιαιτερότητα: μια σχετική διόπτευση μετριέται ως προς *την τρέχουσα πορεία* του πλοίου, η οποία δεν είναι μέρος της πλειάδας. Διάβασε τη μεταβλητή `heading` (που δηλώθηκε στην εργασία 1) με `heading get`, πρόσθεσε τη μετατόπιση της διόπτευσης (`ahead = 0`, `starboard = 90`, `behind = 180`, `port = 270`) και παράγαγε το καρτεσιανό σημείο. Ο καλών ορίζει το `heading` μέσα σε ένα μπλοκ `with-variable`.

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. Αναστροφή

Πρόσθεσε τις μεθόδους της γενικής λέξης `flip` (που δηλώθηκε στην εργασία 1) ώστε να επιστρέφει την αντίθετη κατεύθυνση.

- Για το `cardinal`: north ↔ south, east ↔ west.
- Για το `polar`: πρόσθεσε 180° στη διόπτευση (modulo 360).
- Για το `relative`: ahead ↔ behind, starboard ↔ port.

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. Πρόσθεση διοπτεύσεων

Όρισε το `add-bearings ( a b -- x y )` που μετατρέπει και τις δύο κατευθύνσεις σε καρτεσιανές συντεταγμένες και επιστρέφει το άθροισμά τους. Λειτουργεί για οποιονδήποτε συνδυασμό των `cardinal`, `polar` και `relative`. Αυτό είναι το κέρδος από τη χρήση μιας γενικής λέξης για το `>cartesian`.

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
