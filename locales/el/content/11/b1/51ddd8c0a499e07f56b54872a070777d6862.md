# Προσθήκη οδηγιών

Η ύψωση μιγαδικών αριθμών σε δύναμη απαιτεί μια εκθετική συνάρτηση, μια συνάρτηση ημιτόνου και μια συνάρτηση συνημιτόνου, καμία από τις οποίες δεν είναι διαθέσιμη στη WebAssembly. Ευτυχώς, μπορείς να χρησιμοποιήσεις μια [σειρά Taylor](https://en.wikipedia.org/wiki/Taylor_series) για να τις υπολογίσεις. Θα πρέπει να έχεις ακρίβεια τουλάχιστον `1/26!` για να συμφωνείς με τις αναμενόμενες τιμές.

## Εκθετική συνάρτηση

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## Συνάρτηση ημιτόνου

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## Συνάρτηση συνημιτόνου

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
