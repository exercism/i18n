# Tests

Για να τρέξεις τα tests από τη γραμμή εντολών, τρέξε την παρακάτω εντολή από τον κατάλογο της άσκησης:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## GUI

Για να τρέξεις τα tests μέσω του γραφικού περιβάλλοντος (GUI) του προσομοιωτή MARS, πρόσθεσε την υλοποίησή σου στο τέλος του `runner.mips` με `include`, αφού βγάλεις το σχόλιο από την τελευταία γραμμή.
