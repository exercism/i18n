## <a name="virtual-environments"></a>Εικονικά Περιβάλλοντα

Τα εικονικά περιβάλλοντα της Python προσφέρουν ελαφριά απομόνωση χρόνου εκτέλεσης και πακέτων.
 Μπορούν να σε βοηθήσουν να οργανώσεις τα έργα σου, κρατώντας τα πακέτα Python που εγκαθιστάς συγκεντρωμένα μέσα σε έναν συγκεκριμένο κατάλογο περιβάλλοντος.
Διαφορετικά περιβάλλοντα μπορούν να περιέχουν διαφορετικές εκδόσεις του χρόνου εκτέλεσης της Python μαζί με τις εξαρτήσεις κάποιου έργου ή βιβλιοθήκης.
Αυτό βοηθά να αποφύγεις bugs και ασυμβατότητες που προκαλούνται όταν αναβαθμίζεις μια βιβλιοθήκη για ένα έργο και αυτό "σπάει" μια εξάρτηση σε ένα άλλο.

Υπάρχουν πολλά εργαλεία *εικονικών περιβαλλόντων* και *παρόμοια με εικονικά περιβάλλοντα* σε χρήση σήμερα, καθώς και ένα αυξανόμενο κίνημα που προτιμά τα [inline script metadata][PEP723], τα [dev containers][dev containers] ή το [docker][docker] αντί για εικονικά περιβάλλοντα.
Είναι σημαντικό να δοκιμάσεις διαφορετικές στρατηγικές και να βρεις αυτή που ταιριάζει στο στυλ ανάπτυξης και στις ανάγκες του έργου σου.
Μην υποθέσεις ότι οι στρατηγικές εδώ ταιριάζουν σε όλους ή ότι είναι οι μόνες επιλογές σου.
Για μια πιο γενική επισκόπηση εργαλείων που δεν καλύπτονται εδώ, ρίξε μια ματιά σε [αυτή την ανάρτηση ιστολογίου του Bas Nijholt][bas nihholt] και μείνε περίεργος.


Υπάρχουν τρία βασικά εργαλεία *εικονικών περιβαλλόντων* που θα καλύψουμε εδώ: η [`venv`][venv] της βασικής βιβλιοθήκης της Python, το [`conda env`][condaenv] τρίτου κατασκευαστή, που χρησιμοποιεί τον διαχειριστή πακέτων [`conda`][conda] και (_συνήθως_) τη διανομή Anaconda της Python, και το [`uv`][uv], ο αντικαταστάτης των `pip` + `venv` τρίτου κατασκευαστή.
Και τα τρία είναι αρκετά απλά στη χρήση ή/και την εγκατάσταση.

Επιπλέον, τα [`PyEnv`][pyenv], [`Poetry`][poetry] και [virtualenvwrapper][virtualenvwrapper] είναι εργαλεία που μπορούν να σε βοηθήσουν να διαχειρίζεσαι πολλαπλές εκδόσεις της Python και πολλαπλά περιβάλλοντα Python στον ίδιο υπολογιστή.

### <a name="creating-a-virtual-environment-with-venv"></a>Δημιουργία εικονικού περιβάλλοντος με `venv`

Για να δημιουργήσεις ένα εικονικό περιβάλλον με τη `venv`, κάνε `cd` στον κατάλογο όπου θέλεις να αποθηκεύεις τα περιβάλλοντά σου.
Αυτός θα πρέπει να είναι ένας κατάλογος **ξεχωριστός από** τον κώδικα του έργου σου και ένας που **δεν** θα προσθέσεις στον έλεγχο εκδόσεων.
Στη συνέχεια, τρέξε την εντολή `venv` με το όνομα του φακέλου όπου θέλεις να αποθηκεύσεις αυτό το συγκεκριμένο **περιβάλλον**.
Η συνηθισμένη σύμβαση είναι να ονομάζεις αυτόν τον φάκελο `<project-name-here>_venv`:

**Windows**

```powershell
PS C:\Users\foobar> py -m venv {name_of_virtualenv}
```
Για να ενεργοποιήσεις το εικονικό περιβάλλον, τρέξε την παρακάτω εντολή:

```powershell
PS> .\{name_of_virtual_env}\Scripts\activate.bat
(venv) PS> _
```

<br>

**Linux/MacOS**

```bash
$ python3 -m venv {name_of_virtualenv}
created virtual environment ... in 8568ms
```

Για να ενεργοποιήσεις το εικονικό περιβάλλον, τρέξε την παρακάτω εντολή:

```bash
$ source {name_of_virtual_env}/bin/activate
(venv) $ _
```

Μόλις ενεργοποιηθεί μια `venv`, μπορείς να τρέξεις εντολές `pip` για εγκατάσταση πακέτων "μέσα" στο περιβάλλον.
Τα εγκατεστημένα πακέτα θα συσχετιστούν με την έκδοση Python της `venv` και θα βρίσκονται μέσα στο `{name_of_virtual_env}/Lib`.

Η _απενεργοποίηση_ ενός εικονικού περιβάλλοντος γίνεται καλώντας το σενάριο `deactivate`, που βρίσκεται στον ίδιο κατάλογο με το `activate`.

### <a name="creating-a-virtual-environment-using-conda"></a>Δημιουργία εικονικού περιβάλλοντος με `conda`

*Η τελευταία έκδοση της `conda` μπορεί να εγκατασταθεί μέσω του [miniconda][miniconda].*
Αυτό το [cheatsheet της `conda`][conda-cheatsheet] είναι πολύ χρήσιμο, όπως και τα [έγγραφα της `conda`][conda-docs].

Αρχικά δημιουργήθηκε ως διαχειριστής πακέτων Python για τη δημοφιλή [`Anaconda distribution`][anaconda] της "επιστημονικής Python", αλλά αργότερα η `conda` γενικεύτηκε και επεκτάθηκε.
Τα περιβάλλοντα conda είναι παρόμοια με τις `venv`, με βασική διαφορά ότι η conda μπορεί να δημιουργήσει εικονικά περιβάλλοντα και να εγκαταστήσει πακέτα για πολλές άλλες γλώσσες προγραμματισμού εκτός από την Python.

Οι γλώσσες που υποστηρίζει η conda περιλαμβάνουν τις `R`, `JavaScript`, `Ruby`, `Fortran`, `C/C++`, `Scala`, `Java` και άλλες.
Για μια σύγκριση των εντολών της conda εναντίον της venv, δες την [αναφορά εντολών][conda command ref] της conda.

### <a name="uv">UV

Εργασία σε έργα με το uv: [uv][uv-docs]

Το `uv` είναι ένα εργαλείο διαχείρισης πακέτων και έργων Python από την [Astral][astral], γραμμένο σε [Rust][rust programming language].
Σχεδιάστηκε για να αντικαταστήσει τα `pip`, `venv`, `poetry` και άλλα εργαλεία συσκευασίας/διαχείρισης εξαρτήσεων της Python.
Σε αντίθεση με τη `Conda` ή τη `Mamba`, το uv είναι ειδικευμένο/προσαρμοσμένο μόνο στην Python.
 Ωστόσο, το uv υποστηρίζει τη δημιουργία αρθρωμάτων επέκτασης της Python γραμμένων σε άλλες γλώσσες, όπως η Fortran.
Η Astral είναι επίσης η εταιρεία πίσω από το δημοφιλές linter [Ruff][ruff] και το [TY][ty], έναν στατικό ελεγκτή τύπων για τα type hints της Python, και τα δύο γραμμένα σε Rust.


Αντί να μπούμε σε λεπτομέρειες εδώ, η [τεκμηρίωση του UV][uv documentation] είναι η καλύτερη πηγή σου για εγκατάσταση και ρύθμιση.

### <a name="virtual-environment-wrapper">Περιτύλιγμα εικονικού περιβάλλοντος

Έγγραφα και υπόβαθρο: [virtualenvwrapper][virtualenvwrapper].

Το πακέτο `virtualenvwrapper` λειτουργεί πάνω από τη `venv` για να διαχειρίζεται όλα τα εικονικά περιβάλλοντά σου σε ένα σημείο.
 Μπορείς να δημιουργείς, να αντιγράφεις, να διαγράφεις και να εναλλάσσεσαι μεταξύ περιβαλλόντων με εντολές τύπου Linux, όπως `lsvirtualenv` (_για να εμφανίσεις τα περιβάλλοντα_) και `mkvirtualenv` (_για να δημιουργήσεις ένα περιβάλλον_).
  Επιτρέπει επίσης να προσθέτεις επιπλέον εργαλεία διαχείρισης μέσω επεκτάσεων.
  Μπορείς ακόμη και να δημιουργήσεις τις δικές σου επεκτάσεις για το εργαλείο, ακολουθώντας [αυτό το σεμινάριο][venv wrapper tutorial].

### <a name="pyenv"></a>PyEnv

Το `pyenv` είναι το fork για Python των δημοφιλών εργαλείων `rbenv`/`ruby-build`, τροποποιημένο για την Python.
Είναι ουσιαστικά ένα σύνολο σεναρίων και shims που επιτρέπουν τον ορισμό εκδόσεων Python τόσο σε καθολικό επίπεδο όσο και σε επίπεδο χρήστη.
Προσπαθεί να ακολουθεί την παράδοση του Unix: ένα εργαλείο ενός σκοπού, διακριτικό, που κάνει καλά ένα πράγμα.

Το `pyenv` και τα έγγραφά του βρίσκονται στο [GitHub][pyenv on github].

### <a name="visual-studio-code"></a>Visual Studio Code

Το [Visual studio code (VS Code)][vscode] είναι ένας δωρεάν επεξεργαστής κώδικα από τη Microsoft.
Περιλαμβάνει εξαιρετική υποστήριξη τόσο για [εικονικά περιβάλλοντα/περιβάλλοντα conda][virtual environments in vscode] όσο και για το [`docker`][docker in vscode] (_μέσω του [πρόσθετου docker][vs code docker plugin]_) και μπορεί να επεκταθεί με πολλά διαφορετικά πρόσθετα για [τεστ][python testing in vscode], [linting][linting python in vscode], [μορφοποίηση][formatting python in vscode] και [ανάπτυξη ιστού][python web dev in vscode].

#### <a name="python-for-vs-code"></a>Python για VS Code

_Αναγνωριστικό επέκτασης: ms-python.python_

![Κεφαλίδα επέκτασης Python στο VS Code](https://raw.githubusercontent.com/exercism/python/main/docs/img/VSCode-EXT-Python-Header.png)

### <a name="spyder-ide">Spyder IDE

Το [Spyder][spyder-ide] είναι ένα δωρεάν IDE Python ανοιχτού κώδικα, cross-platform, φτιαγμένο για την επιστημονική κοινότητα.
Συνήθως περιλαμβάνεται στη διανομή Anaconda της Python, αλλά μπορεί να [εγκατασταθεί μόνο του][spyder standalone installers] και να χρησιμοποιηθεί με οποιαδήποτε έκδοση Python.
Συνιστούμε μια αυτόνομη εγκατάσταση για μέγιστη ευελιξία και για να μην υπάρχουν συγκρούσεις πακέτων.

Το Spyder υποστηρίζει πλήρως περιβάλλοντα `venv` και `conda`.
Περιλαμβάνει ένα ενσωματωμένο διαδραστικό τερματικό [IPython][ipython], έναν διαδραστικό debugger και πλούσια υποστήριξη για γραφήματα και εξερεύνηση δεδομένων μέσα στον επεξεργαστή.
Επιπλέον συμπλήρωση κώδικα και linting παρέχονται μέσω του [kite][kite].
Ενσωματώσεις με [Jupyter Notebooks][spyder notebook plugin] και [εργαλεία για τεστ][spyder unittest plugin] παρέχονται μέσω πρόσθετων που αναπτύσσει η κοινότητα.
Μπορείς επίσης να γράψεις [δικά σου πρόσθετα][writing spyder plugins], χρησιμοποιώντας το API του Spyder.

### <a name="vim"></a>Vim

Το [Vim][vimdotorg] είναι μια δωρεάν και "βελτιωμένη" έκδοση του τυπικού επεξεργαστή κειμένου `vi` του Unix.
Είναι διαθέσιμο σε μεγάλη ποικιλία λειτουργικών συστημάτων και εκδόσεων Linux/Unix.
Ένας εξαιρετικός [οδηγός εγκατάστασης και ρύθμισης][vim setup at real python] είναι διαθέσιμος στο Real Python, και βολικά cheat sheets υπάρχουν στα [vimsheet][vim cheat sheet], [glump][glump vim cheatsheet] και [rtorr][rtorr vim cheat sheet].


Ακόμη κι αν αποφασίσεις ότι η επεξεργασία κώδικα Python στο `vim` δεν είναι για σένα, συνιστάται να εξοικειωθείς με ένα βασικό σύνολο εντολών.
Το `vim` ή το `vi` είναι συχνά ο "βασικός" ή "προεπιλεγμένος" επεξεργαστής κειμένου σε διανομές Linux και Unix και είναι ο προεπιλεγμένος επεξεργαστής για τα μηνύματα commit του `git` (_μεταξύ άλλων_) σε αυτά τα συστήματα.
Είναι πολύ πιθανό να βρεθείς σε ένα σύστημα *nix να χρειάζεται να επεξεργαστείς ένα αρχείο ρυθμίσεων με μόνο το `vi` διαθέσιμο, οπότε το να ξέρεις πώς να [βγεις από το vim][how do I quit vim] είναι (_τουλάχιστον_) καλή αυτοάμυνα.

<br>

### <a name="spacemacs"></a>Spacemacs

Το [Spacemacs][spacemacs] (_[αποθετήριο στο github][spacemacs github repo]_) είναι μια δωρεάν διανομή του Emacs, καθοδηγούμενη από την κοινότητα, που συνδυάζει λειτουργίες τόσο του Emacs όσο και του Vim.

- Η επίσημη τεκμηρίωση βρίσκεται [εδώ][spacemacs official docs]
- Αυτός ο [οδηγός][opensource spacemacs guide] στο opensource δίνει μια γρήγορη επισκόπηση των επιλογών εγκατάστασης και ρύθμισης.
- Το [python layer][spacemacs python layer] του spacemacs προσθέτει λειτουργίες για τεστ, linting, διαχείριση περιβαλλόντων και μορφοποίηση κώδικα.

### <a name="sublime-text"></a>Sublime text

Το [Sublime text][sublime text 4] είναι ένας επί πληρωμή επεξεργαστής κειμένου για προγραμματισμό, από τη *Sublime HQ Pty Ltd*.
Μοιάζει με το [VS Code](#visual-studio-code) και το [Atom][atom], με πολλά [πακέτα και πρόσθετα][sublime package control] για προσαρμογή.
Μπορείς επίσης να [αναπτύξεις δικά σου πρόσθετα][sublime plugin development] για τον επεξεργαστή, χρησιμοποιώντας Python.

- [Αγορά και εγκατάσταση][sublime purchasing and installing] του Sublime
- [Τεκμηρίωση][sublime official docs] και [τεκμηρίωση υποστήριξης][sublime support docs] του Sublime
- [Τεκμηρίωση της κοινότητας][sublime community docs] του Sublime
- Το Full Stack Python έχει έναν εξαιρετικό οδηγό για το [Sublime Text][sublime at fullstack python], με πολλούς συνδέσμους προς σεμινάρια.
- Το Real Python προσφέρει επίσης έναν εξαιρετικό οδηγό για τη [ρύθμιση του Sublime Text 3][sublime text at real python]
- Το έργο Chromium έχει επίσης οδηγίες [ρύθμισης και χρήσης][sublime chromium setup].
