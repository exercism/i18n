# Σχετικά

## Επανάληψη σε πίνακα

Ο `for` βρόχος σου επιτρέπει να διατρέχεις έναν πίνακα και να επαναλαμβάνεις τον κώδικα για κάθε στοιχείο:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

Στο παραπάνω παράδειγμα, το `fruit` είναι η μεταβλητή που κρατά την τιμή ενός μεμονωμένου στοιχείου του πίνακα `fruitList`. Ο μεταγλωττιστής διασφαλίζει ότι ο `fruitList` μπορεί να διατραχθεί, αλλιώς σταματά την εκτέλεση.

## Επανάληψη σε εύρος

Μπορείς να διατρέξεις αριθμούς χρησιμοποιώντας τον τελεστή εύρους. Ο τελεστής δέχεται δύο τελεστέους τύπου `Int` και γράφεται ως `min...max`. Το `min` περιλαμβάνεται και το `max` δεν περιλαμβάνεται (`min` <= i ΚΑΙ `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Επανάληψη σε ζεύγη κλειδιού-τιμής

Είναι δυνατόν να διατρέξεις συλλογές από ζεύγη κλειδιού-τιμής. Η μόνη διαφορά στη σύνταξη είναι ότι αντί για μία μόνο μεταβλητή, χρησιμοποιείται ένα αναγνωριστικό μεταβλητής κλειδιού, ακολουθούμενο από `=>`, ακολουθούμενο από το αναγνωριστικό μεταβλητής τιμής:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
