# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [μεταβλητή][vars] χρησιμοποιώντας το [def][def].

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Μπορείς να χρησιμοποιήσεις και να αναφερθείς με το όνομά της στη μεταβλητή που όρισες προηγουμένως.
- Το αποτέλεσμα της αξιολόγησης της τελευταίας έκφρασης σε μια συνάρτηση επιστρέφεται αυτόματα από τη συνάρτηση· όλες οι συναρτήσεις επιστρέφουν αυτή την τιμή.
- Για να αφαιρείς τιμές, μπορείς να χρησιμοποιήσεις τις βασικές συναρτήσεις για [πράξεις με αριθμούς][operators].

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Για να πολλαπλασιάζεις τιμές, μπορείς να χρησιμοποιήσεις τις βασικές συναρτήσεις για [πράξεις με αριθμούς][operators].

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Μπορείς να [καλέσεις][calling] μία από τις άλλες συναρτήσεις που όρισες προηγουμένως.
- Για να προσθέτεις τιμές, μπορείς να χρησιμοποιήσεις τις βασικές συναρτήσεις για [πράξεις με αριθμούς][operators].
