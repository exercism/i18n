# Υποδείξεις

## 1. Όρισε μια συνάρτηση που ελέγχει αν η λίστα γλωσσών είναι κενή

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να ελέγξεις αν είναι κενή.

## 2. Όρισε μια συνάρτηση που προσθέτει μια γλώσσα στη λίστα

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να προσθέσεις στοιχεία.
- Υπενθύμιση: οι μέθοδοι που επιστρέφουν `void` δεν χρειάζονται εντολές `return`.

## 3. Όρισε μια συνάρτηση που αφαιρεί μια γλώσσα από τη λίστα

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να αφαιρέσεις στοιχεία.
- Υπενθύμιση: οι μέθοδοι που επιστρέφουν `void` δεν χρειάζονται εντολές `return`.

## 4. Όρισε μια συνάρτηση που επιστρέφει το πρώτο στοιχείο της λίστας

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να πάρεις στοιχεία σε μια συγκεκριμένη θέση.

## 5. Όρισε μια συνάρτηση που επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να πάρεις το μέγεθος της λίστας.

## 6. Όρισε μια συνάρτηση που προσδιορίζει αν μια γλώσσα βρίσκεται στη λίστα

- Μία από τις [μεθόδους][list] του τύπου List μπορεί να χρησιμοποιηθεί για να ελέγξεις αν ένα στοιχείο περιέχεται στη λίστα.

## 7. Όρισε μια συνάρτηση που προσδιορίζει αν η λίστα είναι συναρπαστική

- Δοκίμασε να χρησιμοποιήσεις μια μέθοδο που έχει ήδη οριστεί στην κλάση.

[list]: https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/List.html
