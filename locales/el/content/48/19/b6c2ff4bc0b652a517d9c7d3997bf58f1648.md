# Οδηγίες

Κάνε αναδιαμόρφωση σε έναν αναλυτή Markdown.

Η άσκηση Markdown είναι άσκηση αναδιαμόρφωσης. Υπάρχει κώδικας που αναλύει μια δεδομένη συμβολοσειρά με [σύνταξη Markdown](https://guides.github.com/features/mastering-markdown/) και επιστρέφει το σχετικό HTML για αυτή τη συμβολοσειρά. Αν και αυτός ο κώδικας είναι γραμμένος με μπερδεμένο τρόπο και δύσκολος στην παρακολούθηση, με κάποιον τρόπο δουλεύει και όλα τα τεστ περνάνε! Η πρόκληση για σένα είναι να ξαναγράψεις αυτόν τον κώδικα ώστε να είναι πιο εύκολος στο διάβασμα και στη συντήρηση, φροντίζοντας παράλληλα να συνεχίσουν να περνάνε όλα τα τεστ.

Θα ήταν χρήσιμο να σημειώσεις σε σχόλια τι έκανες κατά την αναδιαμόρφωση, ώστε να μπορούν να το δουν όσοι κάνουν review, αλλά δεν είναι απολύτως απαραίτητο. Το πιο σημαντικό είναι να κάνεις τον κώδικα καλύτερο!
