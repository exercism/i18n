# Εισαγωγή

Οι [`Rational numbers`][rational] είναι κλάσματα με ακέραιο αριθμητή που διαιρείται με ακέραιο παρονομαστή.

Για παράδειγμα, μπορούμε να αποθηκεύσουμε το `2//3` ως ακριβές κλάσμα αντί για την κατά προσέγγιση τιμή `Float64` `0.6666...`

Το πλεονέκτημα είναι ότι (εκτός από την ακραία περίπτωση της [υπερχείλισης ακεραίων][integer-overflow]) ένας ρητός αριθμός παραμένει ακριβής, αποφεύγοντας τα σφάλματα στρογγυλοποίησης που συχνά είναι αναπόφευκτα με τους αριθμούς κινητής υποδιαστολής.

Μερικές ακόμη λεπτομέρειες υπάρχουν στη [σελίδα του εγχειριδίου][julia-rational] της Julia.

Οι ρητοί αριθμοί είναι ένας αρκετά απλός αριθμητικός τύπος και στοχεύουν να λειτουργούν όπως ακριβώς θα περίμενες.
Επειδή αποτελούν βασικό τύπο στη Julia από τις πρώτες κιόλας εκδόσεις, οι περισσότερες συναρτήσεις τους δέχονται ως είσοδο με τον ίδιο τρόπο όπως τους ακέραιους και τους αριθμούς κινητής υποδιαστολής.

## Δημιουργία ρητών αριθμών

Η δημιουργία είναι τόσο απλή όσο η χρήση του `//` ανάμεσα σε δύο ακέραιους.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Οι κοινοί παράγοντες αφαιρούνται αυτόματα, μετατρέποντας το κλάσμα στην ["απλούστερη μορφή"][lowest-terms] του: τους μικρότερους ακέραιους που αντιπροσωπεύουν με ακρίβεια το κλάσμα, και με μη αρνητικό παρονομαστή.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

Τα άπειρα αποτελέσματα γίνονται δεκτά, όχι όμως το [`NaN`][NaN].

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## Αριθμητική με ρητούς αριθμούς

Οι συνήθεις [`arithmetic operators`][operators] `+ - * / ^ %` λειτουργούν με τους ρητούς, ουσιαστικά το ίδιο όπως με τους άλλους αριθμητικούς τύπους.

Ακέραιοι και άλλα `Rational` μπορούν να συμπεριληφθούν και δίνουν αποτέλεσμα `Rational`.
Αν συμπεριλάβεις ένα `float` στην παράσταση, το αποτέλεσμα είναι `float`, με επακόλουθη (πιθανή) απώλεια ακρίβειας.

Αν θέλεις `float`, απλώς χρησιμοποίησε τη συνάρτηση `float()` για να μετατρέψεις έναν ρητό.
Είναι απολύτως φυσιολογικό να χρησιμοποιείς ρητούς αριθμούς για να διατηρήσεις την ακρίβεια σε έναν μακρύ υπολογισμό και μετά να μετατρέψεις σε float στο τέλος.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

Οι ρητοί μπορούν επίσης να συνδυαστούν με [μιγαδικούς αριθμούς][complex].
Οι μιγαδικοί αριθμοί συζητούνται σε [ξεχωριστή έννοια][complex-concept].

## Άλλες πράξεις

Στη Julia, οι ρητοί αριθμοί είναι απλώς αριθμοί.
Ο μεταγλωττιστής συνήθως μετατρέπει τους τύπους όπως χρειάζεται.

Ωστόσο, πρόσεξε ότι οι συγκρίσεις λειτουργούν για κλάσματα με πεπερασμένη δεκαδική αναπαράσταση:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Αλλά, σε αντίθετη περίπτωση, ένα `Rational` πρέπει να μετατραπεί σε `Float` για συγκρίσεις:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Οι μαθηματικές συναρτήσεις δέχονται ρητούς ως είσοδο, αλλά μπορεί να δώσουν αποτέλεσμα κινητής υποδιαστολής:

```julia-repl
julia> sqrt(9//16)
0.75
```
