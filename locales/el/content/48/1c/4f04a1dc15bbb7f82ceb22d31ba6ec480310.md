# Προσθήκη οδηγιών

## Οδηγίες ειδικά για το track

Τα tests για αυτή την άσκηση απαιτούν να χρησιμοποιήσεις επεκτάσεις, έναν μηχανισμό για την προσθήκη νέας λειτουργικότητας σε μια υπάρχουσα κλάση της οποίας τον πηγαίο κώδικα δεν ελέγχεις άμεσα, χωρίς να χρειάζεται να δημιουργήσεις υποκλάση της.
Για να μάθεις περισσότερα για τις υλοποιήσεις των επεκτάσεων στην Kotlin, ρίξε μια ματιά στην [επίσημη τεκμηρίωση](https://kotlinlang.org/docs/reference/extensions.html#extensions).

Οι μέθοδοι `customFoldLeft` και `customFoldRight` είναι συναρτήσεις "fold", μια έννοια γνωστή στον χώρο του συναρτησιακού προγραμματισμού, αλλά λιγότερο στον χώρο του αντικειμενοστρεφούς προγραμματισμού.
Αν θέλεις περισσότερες πληροφορίες, ρίξε μια ματιά σε αυτή τη σελίδα για το [fold](https://en.wikipedia.org/wiki/Fold_(higher-order_function)).
