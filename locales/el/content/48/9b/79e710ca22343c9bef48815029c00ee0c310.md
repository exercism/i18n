# Εισαγωγή

## Συναρτήσεις βέλους

Εκτός από τις δηλώσεις συνάρτησης και τις εκφράσεις συνάρτησης, η JavaScript έχει και μια άλλη πολύ συνοπτική σύνταξη για τον ορισμό μιας συνάρτησης.
Αυτές οι συναρτήσεις ονομάζονται _συναρτήσεις βέλους_.

Ορίστε μια σύγκριση ανάμεσα σε μια δήλωση συνάρτησης και μια συνάρτηση βέλους.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}
// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Αν το σώμα της συνάρτησης περιέχει μόνο μια εντολή return, όπως στο παραπάνω παράδειγμα, το `{}` και η λέξη-κλειδί `return` μπορούν να παραλειφθούν.
Αν υπάρχει μόνο μία παράμετρος, μπορούν να παραλειφθούν και οι παρενθέσεις `()`.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => num1 + num2;
const square = num => num * num;
```
<!-- prettier-ignore-end -->

Οι συναρτήσεις βέλους χρησιμοποιούνται συχνά για να ορίσουν σύντομες συναρτήσεις callback απευθείας μέσα στην κλήση της συνάρτησης.

<!-- prettier-ignore-start -->
```javascript
applyToSquare(number => number * number);
```
<!-- prettier-ignore-end -->

## Ανάλυση πίνακα

Οι [πίνακες][arrays-concept] έχουν ενσωματωμένες μεθόδους για την ανάλυση των περιεχομένων του πίνακα.
Οι περισσότερες από αυτές τις μεθόδους δέχονται ως όρισμα μια συνάρτηση που επιστρέφει αληθή ή ψευδή τιμή.
Μια τέτοια συνάρτηση ονομάζεται [`predicate`][predicate_in_programming].

Οι ενσωματωμένες μέθοδοι προορίζονται για χρήση _αντί για έναν `for` βρόχο_ ή για την ενσωματωμένη μέθοδο `forEach`:

Παράδειγμα ανάλυσης με έναν `for` βρόχο:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Παράδειγμα ανάλυσης με μια ενσωματωμένη μέθοδο:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Παρακάτω φαίνονται μερικές άλλες χρήσιμες ενσωματωμένες μέθοδοι που είναι διαθέσιμες για την ανάλυση ενός πίνακα.
Δες το [MDN][mdn-array-methods] για μια πλήρη λίστα μεθόδων πίνακα.

### `includes`

Η μέθοδος `includes(value)` προσδιορίζει αν ένας πίνακας περιέχει μια συγκεκριμένη τιμή.
Επιστρέφει `true` όταν η τιμή περιέχεται, αλλιώς `false`.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

### `every`

Η μέθοδος `every(predicate)` δέχεται μια συνάρτηση που είναι _ένα predicate_.
Ελέγχει αν όλα τα στοιχεία του πίνακα επιστρέφουν `true` όταν περαστούν στο predicate.
Με άλλα λόγια: η μέθοδος ελέγχει ότι όλα τα στοιχεία της περνούν το τεστ που δόθηκε στην κλήση της συνάρτησης.
Επιστρέφει `true` όταν κάθε στοιχείο περνά το τεστ του predicate, αλλιώς `false`.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

### `some`

Η μέθοδος `some(predicate)` είναι ίδια με τη μέθοδο `every`, αλλά επιστρέφει `true` αν τουλάχιστον ένα στοιχείο του πίνακα περάσει το τεστ του _predicate_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

### `find`

Η μέθοδος `find(predicate)` επιστρέφει την τιμή του πρώτου στοιχείου του πίνακα που περνά το τεστ του `predicate`.
Εκεί που η `some()` επιστρέφει `true` όταν περνά, η `find()` επιστρέφει την πραγματική τιμή μέσα στον πίνακα.
Η μέθοδος επιστρέφει `undefined` όταν κανένα από τα στοιχεία του πίνακα δεν περνά το τεστ του _predicate_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

### `findIndex`

Η `findIndex(predicate)` είναι ίδια με τη μέθοδο `find()`, αλλά επιστρέφει τη (πρώτη) _θέση_ του στοιχείου που περνά το τεστ του _predicate_ αντί για την `value`.
Η μέθοδος επιστρέφει `-1` όταν κανένα από τα στοιχεία του πίνακα δεν περνά το τεστ του _predicate_.

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
