# Εισαγωγή

Το Elixir διευκολύνει την εφαρμογή της **Αρχής Ανοικτού-Κλειστού**, επιτρέποντας στις συναρτήσεις να έχουν πολλαπλές ρήτρες. Έτσι, αντί για μια εκτεταμένη, καρφωτή λογική ελέγχου, μπορείς να γράψεις στοχευμένες συναρτήσεις που προσθέτουν ή αφαιρούν συμπεριφορά εύκολα.

Το Elixir προσφέρει _πολλαπλές ρήτρες συνάρτησης_ και _φρουρούς_ για να γράψεις:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

Κατά την εκτέλεση, το Elixir ελέγχει, από πάνω προς τα κάτω στο αρχείο πηγαίου κώδικα, ποια ρήτρα συνάρτησης θα καλέσει.

Οι μεταβλητές που δεν χρησιμοποιούνται πρέπει να ξεκινούν με μια κάτω παύλα.
