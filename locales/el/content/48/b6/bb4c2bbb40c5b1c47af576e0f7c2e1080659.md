# Υποδείξεις

## 1. Όρισε τη βαθμολογία ενός παίκτη στον κατακερματισμό `%Scores`

- Θέλεις να τροποποιήσεις τον κατακερματισμό `%Scores` ώστε να προσθέσεις νέες βαθμολογίες παικτών και να αντικαταστήσεις τις υπάρχουσες βαθμολογίες παικτών.
- Οι κατακερματισμοί δεν μπορούν να περιέχουν διπλότυπα κλειδιά: μια νεότερη τιμή σε μια λίστα αντικαθιστά μια παλαιότερη τιμή.

## 2. Πάρε τη βαθμολογία ενός παίκτη από τον κατακερματισμό `%Scores` 

- Θέλεις να χρησιμοποιήσεις το όνομα του παίκτη που σου δίνεται για να κάνεις `return` τη βαθμολογία του παίκτη από τον κατακερματισμό `%Scores`.

## 3. Αύξησε τη βαθμολογία ενός παίκτη στον κατακερματισμό `%Scores`

- Θέλεις να τροποποιήσεις τον κατακερματισμό `%Scores` ώστε να προσθέσεις τις βαθμολογίες των παικτών που υπάρχουν ήδη στις νέες βαθμολογίες που σου δίνονται.

## 4. Ταξινόμησε τους παίκτες στον κατακερματισμό `%Scores` με βάση το όνομα

- Θέλεις να κάνεις `return` τα ονόματα των παικτών από τον κατακερματισμό `%Scores` ως λίστα ταξινομημένη αλφαβητικά.


## 5. Ταξινόμησε τους παίκτες στον κατακερματισμό `%Scores` με βάση τη βαθμολογία

- Θέλεις να κάνεις `return` τα ονόματα των παικτών από τον κατακερματισμό `%Scores` ως λίστα ταξινομημένη κατά βαθμολογία, από την υψηλότερη στη χαμηλότερη.

## 6. Διάγραψε έναν παίκτη από τον κατακερματισμό `%Scores`

- Θέλεις να τροποποιήσεις τον κατακερματισμό `%Scores` ώστε να αφαιρέσεις το όνομα και τη βαθμολογία του παίκτη που σου δίνεται.
