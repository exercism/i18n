# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις ερωτευμένους του λυκείου να δηλώσουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας ένα κουτί ASCII με τα αρχικά τους:

```
❤-------------------❤
|  J. K.  +  M. B.  |
❤-------------------❤
```

## 1. Πάρε το πρώτο γράμμα του ονόματος

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart.first_letter/1`. Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα. Θα πρέπει να καθαρίζει τυχόν περιττά κενά από το όνομα.

```elixir
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 2. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart.initial/1`. Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα, κεφαλαίο, ακολουθούμενο από τελεία. Φρόντισε να επαναχρησιμοποιήσεις τη συνάρτηση `HighSchoolSweetheart.first_letter/1` που όρισες στο προηγούμενο βήμα.

```elixir
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 3. Χώρισε το πλήρες όνομα στο όνομα και στο επώνυμο

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart.initials/1`. Θα πρέπει να παίρνει ένα πλήρες όνομα, που αποτελείται από ένα όνομα και ένα επώνυμο χωρισμένα με ένα κενό, και να επιστρέφει τα αρχικά. Φρόντισε να επαναχρησιμοποιήσεις τη συνάρτηση `HighSchoolSweetheart.initial/1` που όρισες στο προηγούμενο βήμα.

```elixir
HighSchoolSweetheart.initials("Lance Green")
# => "L. G."
```

## 4. Βάλε τα αρχικά μέσα στο κουτί ASCII

Υλοποίησε τη συνάρτηση `HighSchoolSweetheart.pair/2`. Θα πρέπει να παίρνει δύο πλήρη ονόματα και να επιστρέφει τα αρχικά μέσα σε ένα κουτί ASCII. Δεν χρειάζεται να σχεδιάσεις το κουτί μόνος σου, αξιοποίησε το κουτί που υπάρχει στο σχόλιο του κώδικα. Φρόντισε να επαναχρησιμοποιήσεις τη συνάρτηση `HighSchoolSweetheart.initials/1` που όρισες στο προηγούμενο βήμα.

```elixir
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => """
# ❤-------------------❤
# |  B. M.  +  R. L.  |
# ❤-------------------❤
# """
```
