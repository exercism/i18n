# Δοκιμές

Εγκατέστησε τις εξαρτήσεις.

```sh
dart pub get
```

Τρέξε τις δοκιμές.

```sh
dart test
```

Για πιο αναλυτικά αποτελέσματα ανά δοκιμή, χρησιμοποίησε τον expanded reporter.

```sh
dart test -r expanded
```

Οι περισσότερες ασκήσεις έχουν πολλές δοκιμές, με όλες εκτός από την πρώτη να παραλείπονται εξ ορισμού.
Για να δουλέψεις τις δοκιμές μία προς μία, άλλαξε το `skip: true` σε `skip: false` σε κάθε δοκιμή καθώς προχωράς.

Εναλλακτικά, τρέξε όλες τις δοκιμές με μία φορά χωρίς να επεξεργαστείς το αρχείο.

```sh
dart test --run-skipped
```

Όλες οι δοκιμές εκτελούνται από τον online test runner κατά την υποβολή, μαζί και όσες παραλείπονται.
