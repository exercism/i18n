# Οδηγίες

Συντηρείς τον σταθμό επεξεργασίας μιας συστοιχίας σεισμογράφων, ενός δικτύου αισθητήρων που καταγράφουν πώς κινείται το έδαφος.

Οι μετρήσεις φτάνουν ως μπλοκ τιμών.
Κάποιες είναι μετατοπίσεις εδάφους αποθηκευμένες ως αριθμοί κινητής υποδιαστολής 32 bit, άλλες είναι ακατέργαστες μετρήσεις και λέξεις κατάστασης αποθηκευμένες ως ακέραιοι 32 bit.
Ο σταθμός επεξεργάζεται ένα ολόκληρο μπλοκ ταυτόχρονα, εφαρμόζοντας την ίδια πράξη σε κάθε τιμή.

Έχεις έξι εργασίες, καθεμία από τις οποίες επεξεργάζεται ένα μπλοκ τιμών που βρίσκεται στη μνήμη.
Λαμβάνεις τα τελούμενα μέσω διευθύνσεων μνήμης και γράφεις την απάντησή σου μέσω μιας διεύθυνσης αποτελέσματος.
Όλες οι διευθύνσεις μνήμης σε αυτή την άσκηση είναι ευθυγραμμισμένες στα 16 byte.

~~~~exercism/note
Οι υπολογισμοί σε αυτή την άσκηση πρέπει να γίνονται με χρήση διαδικών πράξεων SIMD και ολισθήσεων, όχι βαθμωτών πράξεων.
~~~~

## 1. Ανόρθωσε το ίχνος

Για την ανάλυση μεγέθους, σημασία έχει μόνο το μέγεθος κάθε μετατόπισης εδάφους, όχι η κατεύθυνσή της.
Το πρώτο βήμα επεξεργασίας μετατρέπει κάθε μέτρηση σε μη αρνητική τιμή.

Υλοποίησε τη συνάρτηση `rectify_trace`, η οποία υπολογίζει την απόλυτη τιμή κάθε μέτρησης.
Ένα μπλοκ περιέχει 4 μετρήσεις, καθεμία από τις οποίες είναι ένας αριθμός κινητής υποδιαστολής 32 bit.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 ανορθωμένες μετρήσεις.
- `trace`: διεύθυνση μνήμης των καταγεγραμμένων μετρήσεων, με 4 τιμές, καθεμία ένας αριθμός κινητής υποδιαστολής 32 bit.

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 2. Διάβασε την κλίμακα μιας δόνησης

Οι αναλυτές βαθμολογούν τις δονήσεις με βάση τη δύναμη του δύο: μια μέτρηση κοντά στο `8.0` βρίσκεται στην κλίμακα `3`, μια μέτρηση κοντά στο `0.25` βρίσκεται στην κλίμακα `-2`.
Αυτή η κλίμακα είναι ήδη αποθηκευμένη μέσα σε κάθε αριθμό κινητής υποδιαστολής, ως το πεδίο του εκθέτη του.

Ένας αριθμός κινητής υποδιαστολής 32 bit διατάσσεται ως ένα bit προσήμου στο bit 31, ένας εκθέτης 8 bit στα bit 30 έως 23 και ένα κλάσμα 23 bit στα bit 22 έως 0.
Ο αποθηκευμένος εκθέτης έχει πόλωση 127, οπότε η τιμή του αριθμού είναι `(-1)^sign * 1.fraction * 2^(exponent - 127)`.

Υλοποίησε τη συνάρτηση `reading_scale`, η οποία εξάγει τον εκθέτη κάθε μέτρησης χωρίς πόλωση, ως προσημασμένο ακέραιο 32 bit.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 κλίμακες, καθεμία ένας προσημασμένος ακέραιος 32 bit.
- `trace`: διεύθυνση μνήμης των ανορθωμένων μετρήσεων, με 4 τιμές, καθεμία ένας αριθμός κινητής υποδιαστολής 32 bit.

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.
Όλες οι μετρήσεις είναι κανονικοί, μη μηδενικοί αριθμοί κινητής υποδιαστολής.

## 3. Μείωσε την ανάλυση

Για μακροπρόθεσμη αποθήκευση, οι ακατέργαστες μετρήσεις μετατόπισης διατηρούνται σε χαμηλότερη ανάλυση: κάθε μέτρηση διαιρείται με μια δύναμη του δύο.

Οι μετρήσεις μετατόπισης είναι προσημασμένες: το έδαφος μπορεί να κινηθεί και προς τις δύο κατευθύνσεις.
Η σωστή διαίρεσή τους απαιτεί την ολίσθηση που διατηρεί το πρόσημο.

Υλοποίησε τη συνάρτηση `coarsen_displacements`, η οποία διαιρεί κάθε προσημασμένη μέτρηση με `2^shift`, στρογγυλοποιώντας προς το αρνητικό άπειρο.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 μετρήσεις με χαμηλότερη ανάλυση, καθεμία ένας προσημασμένος ακέραιος 32 bit.
- `counts`: διεύθυνση μνήμης των ακατέργαστων μετρήσεων, με 4 προσημασμένους ακέραιους 32 bit.
- `shift`: η δύναμη του δύο με την οποία γίνεται η διαίρεση, ως ανυπόγραφος ακέραιος 64 bit μεταξύ `0` και `31`.

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
Η εντολή `movq` μπορεί να χρησιμοποιηθεί για την αντιγραφή ενός ακέραιου 64 bit από έναν καταχωρητή γενικού σκοπού σε έναν καταχωρητή `xmm`, χωρίς να αλλάζει η υποκείμενη αναπαράσταση bit.
~~~~

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 4. Φίλτραρε τα κανάλια

Κάθε σταθμός συγχωνεύει δύο εκστρατείες καταγραφής και μετά απενεργοποιεί τα κανάλια που η αναφορά του υλισμικού του επισημαίνει ως ελαττωματικά.
Κάθε μπλοκ περιέχει 4 μάσκες καναλιών, καθεμία έναν ανυπόγραφο ακέραιο 32 bit, όπου κάθε bit αντιπροσωπεύει ένα κανάλι: `1` ενεργό, `0` ανενεργό.

Υλοποίησε τη συνάρτηση `gate_channels`, η οποία συνδυάζει τα κανάλια που είναι ενεργά σε οποιαδήποτε από τις δύο εκστρατείες και μετά καθαρίζει κάθε κανάλι που έχει επισημανθεί ως ελαττωματικό.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 φιλτραρισμένες μάσκες, καθεμία ένας ανυπόγραφος ακέραιος 32 bit.
- `enable_a`: διεύθυνση μνήμης των μασκών ενεργοποίησης της πρώτης εκστρατείας, με 4 ανυπόγραφους ακέραιους 32 bit.
- `enable_b`: διεύθυνση μνήμης των μασκών ενεργοποίησης της δεύτερης εκστρατείας, με 4 ανυπόγραφους ακέραιους 32 bit.
- `faulty`: διεύθυνση μνήμης των μασκών ελαττωματικών καναλιών, με 4 ανυπόγραφους ακέραιους 32 bit.

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 5. Ενάλλαξε τα bit βαθμονόμησης

Μία φορά την ημέρα ο σταθμός εκτελεί ένα πέρασμα βαθμονόμησης, αναστρέφοντας ένα επιλεγμένο σύνολο bit διαμόρφωσης σε κάθε λέξη κατάστασης και αφήνοντας κάθε άλλο bit ανέπαφο.
Αλλά κάποια bit είναι κλειδωμένα από το υλισμικό και δεν πρέπει να αλλάζουν ποτέ, ανεξάρτητα από το τι ζητάει το πέρασμα.
Η εκτέλεση του ίδιου περάσματος δύο φορές επαναφέρει την αρχική διαμόρφωση.

Υλοποίησε τη συνάρτηση `toggle_calibration`, η οποία αναστρέφει, σε κάθε λέξη κατάστασης, ακριβώς τα bit που είναι ορισμένα στην αντίστοιχη μάσκα εναλλαγής και δεν είναι ορισμένα στην αντίστοιχη μάσκα κλειδώματος.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 ενημερωμένες λέξεις κατάστασης, καθεμία ένας ανυπόγραφος ακέραιος 32 bit.
- `status`: διεύθυνση μνήμης των τρεχουσών λέξεων κατάστασης, με 4 ανυπόγραφους ακέραιους 32 bit.
- `toggle`: διεύθυνση μνήμης των μασκών εναλλαγής, με 4 ανυπόγραφους ακέραιους 32 bit.
- `locked`: διεύθυνση μνήμης των μασκών κλειδώματος, με 4 ανυπόγραφους ακέραιους 32 bit.

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

## 6. Ενίσχυσε το ίχνος

Κάθε κανάλι της συστοιχίας έχει τη δική του ρύθμιση απολαβής, εκφρασμένη ως δύναμη του δύο: απολαβή `3` πολλαπλασιάζει τη μέτρηση του καναλιού με `8`, απολαβή `-5` τη διαιρεί με `32`.

Ο σταθμός εφαρμόζει αυτές τις απολαβές χωρίς ούτε έναν πολλαπλασιασμό, χειριζόμενος το πεδίο του εκθέτη κάθε αριθμού κινητής υποδιαστολής.

Υλοποίησε τη συνάρτηση `amplify_trace`, η οποία πολλαπλασιάζει κάθε μέτρηση με το `2` υψωμένο στην απολαβή του καναλιού της, λειτουργώντας μόνο στα ακατέργαστα bit.

Αυτή η συνάρτηση δέχεται ως ορίσματα, με αυτή τη σειρά:

- `result`: διεύθυνση μνήμης για ένα buffer όπου γράφονται οι 4 ενισχυμένες μετρήσεις.
- `trace`: διεύθυνση μνήμης των μετρήσεων, με 4 τιμές, καθεμία ένας αριθμός κινητής υποδιαστολής 32 bit.
- `gains`: διεύθυνση μνήμης των απολαβών ανά κανάλι, με 4 προσημασμένους ακέραιους 32 bit.

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.
Όλες οι μετρήσεις είναι κανονικοί, μη μηδενικοί αριθμοί κινητής υποδιαστολής και κάθε ενισχυμένο αποτέλεσμα είναι επίσης κανονικό.
