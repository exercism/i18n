# Υποδείξεις

## Γενικά

- Η [τεκμηρίωση του API του `Set`][set-docs] περιέχει μια λίστα με τις μεθόδους που είναι διαθέσιμες στη διεπαφή `Set`.

## 1. Ξεκίνα μια συλλογή

- Η [κλάση `HashSet`][hashset-docs] έχει έναν κατασκευαστή που δέχεται μια `Collection`.

## 2. Μεγάλωσε τη συλλογή

- Δες την υπογραφή της [μεθόδου `add`][set-add-docs] που ορίζεται στη διεπαφή `Set`.

## 3. Ξεκίνα τις ανταλλαγές

- Μπορείς να δημιουργήσεις ένα αντίγραφο ενός `Set` τυλίγοντάς το σε ένα `new HashSet<>()`.
- Η [διεπαφή `Set`][set-docs] έχει μια μέθοδο που αφαιρεί όλα τα στοιχεία που περιέχονται σε μια άλλη `Collection`.

## 4. Εντόπισε τις κοινές κάρτες

- Μπορείς να δημιουργήσεις ένα αντίγραφο ενός `Set` τυλίγοντάς το σε ένα `new HashSet<>()`.
- Η [διεπαφή `Set`][set-docs] έχει μια μέθοδο που διατηρεί όλα τα στοιχεία που περιέχονται σε μια άλλη `Collection`.

## 5. Όλες οι κάρτες

- Μπορείς να δημιουργήσεις ένα αντίγραφο ενός `Set` τυλίγοντάς το σε ένα `new HashSet<>()`.
- Η [διεπαφή `Set`][set-docs] έχει μια μέθοδο που προσθέτει όλα τα στοιχεία που περιέχονται σε μια άλλη `Collection`.
