# PowerShell

Αυτοματοποίησε τα πάντα!
Γράψε σενάρια σε οποιοδήποτε λειτουργικό σύστημα για να διαχειρίζεσαι αρχεία, διεργασίες, ένα κέντρο δεδομένων ή υπηρεσίες cloud.
Εξερεύνησε διαδραστικά δομημένα δεδομένα όπως JSON, XML και CSV. Δούλεψε με κάθε διεπαφή διαχείρισης, από web APIs και CIM μέχρι εφαρμογές γραμμής εντολών.

# Σχετικά με το PowerShell

Η PowerShell είναι μια γλώσσα σεναρίων, ένα κέλυφος και ένα framework διαχείρισης ρυθμίσεων για .NET, ανοιχτού κώδικα και πολλαπλών πλατφορμών, και βοηθά τους επαγγελματίες της πληροφορικής και τους έμπειρους χρήστες να ελέγχουν και να αυτοματοποιούν σχεδόν τα πάντα.

Η PowerShell είναι χτισμένη πάνω στο .NET Framework και μετασχηματίζει την κλασική έννοια του unix pipe, επεκτείνοντάς την ώστε να μη μεταφέρει μόνο ροές κειμένου ή δυαδικών δεδομένων, αλλά να υποστηρίζει τη μεταφορά στιγμιοτύπων αντικειμένων που περιλαμβάνουν πληροφορίες τύπου (π.χ. ημερομηνίες και ώρες) και σύνθετη κατάσταση μαζί με τα δομημένα δεδομένα τους.
Εκεί που σε ένα παραδοσιακό κέλυφος μπορεί να χρησιμοποιείς επεξεργασία κειμένου για να εξαγάγεις συγκεκριμένες πληροφορίες από την έξοδο μιας εντολής, στην PowerShell έχεις πρόσβαση σε ιδιότητες και μεθόδους (καθώς και σε τρόπους επιθεώρησης των αντικειμένων ώστε να διαπιστώσεις ποιες ιδιότητες και μέθοδοι είναι διαθέσιμες).
Μπορείς να δουλέψεις με αρχεία CSV, να μετατρέψεις JSON σε hashtables, να περιηγηθείς σε έγγραφα XML και πολλά άλλα, κάνοντας εύκολα συνθέσιμες πολλές εργασίες που θα ήταν δύσκολες ή μη πρακτικές με ανάλυση κειμένου.

Η PowerShell είναι επεκτάσιμη.
Όχι μόνο μέσω μεμονωμένων εργαλείων γραμμής εντολών, όπως επεκτείνονται άλλα κέλυφη, αλλά μέσω σεναρίων, συναρτήσεων και cmdlets που διανέμονται σε modules και ενσωματώνονται πραγματικά πλήρως στο σύστημα βοήθειας της PowerShell, στον επεξεργαστή γραμμής εντολών με επισήμανση σύνταξης, στην αυτόματη ανακάλυψη παραμέτρων και στη συμπλήρωση με Tab.
Μπορείς μάλιστα να επεκτείνεις την απλή, εξερευνήσιμη σύνταξη "ιδιότητα + περιεχόμενο" του συστήματος αρχείων σε αποθήκες δεδομένων όπως το μητρώο των Windows και ο χώρος αποθήκευσης πιστοποιητικών, ο SQL Server, ακόμη και το Azure!

Η PowerShell περιλαμβάνει πολλές επιπλέον δυνατότητες:

- Ενσωματωμένα "cmdlets" για συνήθεις εργασίες διαχείρισης συστήματος, όπως η διαχείριση αρχείων, υπηρεσιών, διεργασιών, ακόμη και του μητρώου, των αρχείων καταγραφής συμβάντων και του Κοινού Μοντέλου Πληροφοριών (CIM), αιτήματα web και πολλά άλλα.
- Συμβατότητα με υπάρχοντα σενάρια και εργαλεία γραμμής εντολών.
- Επεκτάσιμες διεπαφές, και modules και εντολές που ανακαλύπτονται εύκολα.
- Πλήρης πρόσβαση στο .NET Framework, και επεκτασιμότητα μέσω assemblies .NET από το NuGet.
- Ένα πλούσιο ιστορικό εντολών με πληροφορίες για την επιτυχία και τη διάρκεια εκτέλεσης μιας εντολής.
- Ισχυρές δυνατότητες χειρισμού αντικειμένων. Τα αντικείμενα μπορούν να χειριστούν άμεσα, να σειριοποιηθούν και ακόμη να σταλούν σε άλλα εργαλεία ή βάσεις δεδομένων.

Λεπτομερής τεκμηρίωση για τη PowerShell, τη γλώσσα, τις βασικές έννοιες και τα χαρακτηριστικά της υπάρχει μαζί με τους εγκαταστάτες στη διεύθυνση https://docs.microsoft.com/en-us/powershell.
