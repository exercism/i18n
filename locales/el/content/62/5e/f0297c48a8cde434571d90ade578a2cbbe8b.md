# Υποδείξεις

## 1. Έλεγξε αν το φαγητό είναι σωστό

- Μπορείς να χρησιμοποιήσεις μια εντολή [`if`][if] για να ελέγξεις αν το φαγητό είναι σωστό.

## 2. Έλεγξε αν το ποτό είναι δηλητηριασμένο

- Υπάρχει [μια μέθοδος][downcase] για να μετατρέψεις μια συμβολοσειρά σε πεζούς χαρακτήρες.
- Μπορείς να ελέγξεις αν μια συμβολοσειρά περιέχει έναν συγκεκριμένο χαρακτήρα χρησιμοποιώντας το [`String#includes?`][includes?].

## 3. Αντικατέστησε το ποτό

- Μπορείς να χρησιμοποιήσεις ήδη υλοποιημένες μεθόδους για να ελέγξεις αν το ποτό είναι δηλητηριασμένο.
- Υπάρχει [ένας τελεστής][or] που μπορεί να χρησιμοποιηθεί για να επιστρέψει την πρώτη τιμή που αξιολογείται ως αληθής.

[if]: https://crystal-lang.org/reference/latest/syntax_and_semantics/if.html
[downcase]: https://crystal-lang.org/api/latest/String.html#downcase%28options%3AUnicode%3A%3ACaseOptions%3D%3Anone%29%3AString-instance-method
[includes?]: https://crystal-lang.org/api/latest/String.html#includes%3F%28search%3AChar%7CString%29%3ABool-instance-method
[or]: https://crystal-lang.org/reference/latest/syntax_and_semantics/or.html
