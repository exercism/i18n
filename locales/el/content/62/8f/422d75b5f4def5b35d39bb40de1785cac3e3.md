# Οδηγίες

Σε αυτή την άσκηση, θα υλοποιήσεις ένα μέρος από ένα σύνολο βοηθητικών ρουτινών που βοηθούν έναν προγραμματιστή να καθαρίζει ονόματα αναγνωριστικών.
Στις 5 εργασίες θα χτίσεις σταδιακά τη ρουτίνα `Clean`.
Ένα έγκυρο αναγνωριστικό αποτελείται από μηδέν ή περισσότερα γράμματα και κάτω παύλες.
Σε κάθε περίπτωση, η συμβολοσειρά εισόδου δεν είναι ποτέ null.
Αν δοθεί μια κενή συμβολοσειρά στη συνάρτηση `Clean`, θα πρέπει να επιστραφεί μια κενή συμβολοσειρά.
Σημείωσε ότι αυτός που καλεί θα πρέπει να αποφεύγει να καλεί τη ρουτίνα `Clean` με ένα κενό αναγνωριστικό, αφού τέτοια αναγνωριστικά δεν έχουν κανένα αποτέλεσμα.

## 1. Αντικατέστησε τυχόν κενά με κάτω παύλες

Υλοποίησε τη (_static_) μέθοδο `Identifier.Clean()` ώστε να αντικαθιστά τυχόν κενά με κάτω παύλες.
Αυτό ισχύει και για τα κενά στην αρχή και στο τέλος.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Αντικατέστησε τους χαρακτήρες ελέγχου με τη συμβολοσειρά "CTRL" σε κεφαλαία

Τροποποίησε τη (_static_) μέθοδο `Identifier.Clean()` ώστε να αντικαθιστά τους χαρακτήρες ελέγχου με τη συμβολοσειρά `"CTRL"` σε κεφαλαία γράμματα.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Μετέτρεψε το kebab-case σε camelCase

Τροποποίησε τη (_static_) μέθοδο `Identifier.Clean()` ώστε να μετατρέπει το kebab-case σε camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Παράλειψε όσους χαρακτήρες δεν είναι γράμματα

Τροποποίησε τη (_static_) μέθοδο `Identifier.Clean()` ώστε να παραλείπει όσους χαρακτήρες δεν είναι γράμματα.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Παράλειψε τα ελληνικά πεζά γράμματα

Τροποποίησε τη (_static_) μέθοδο `Identifier.Clean()` ώστε να παραλείπει οποιαδήποτε ελληνικά γράμματα στο εύρος από το 'α' έως το 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
