# Εισαγωγή

## Τυχαιότητα

Μπορείς να χρησιμοποιήσεις ένα στιγμιότυπο της κλάσης `java.util.Random` για να παράγεις τυχαίους αριθμούς στην Java.

### Τυχαίοι ακέραιοι

Μπορείς να παράγεις έναν τυχαίο ακέραιο με τη μέθοδο `nextInt()`.
Αυτή παράγει μια τιμή στο εύρος από `Integer.MIN_VALUE` έως `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Για να περιορίσεις το εύρος των τιμών που παράγονται, χρησιμοποίησε `nextInt(int)`.
Αυτή παράγει μια τιμή στο εύρος από `0` (συμπεριλαμβανομένου) έως το δεδομένο άνω όριο (μη συμπεριλαμβανομένου).

Για παράδειγμα, αυτό παράγει έναν τυχαίο αριθμό από `0` έως και `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Και αυτό παράγει έναν τυχαίο αριθμό από `10` έως και `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Τυχαίες τιμές double

Μπορείς να παράγεις μια τυχαία τιμή double με τη μέθοδο `nextDouble()`.
Αυτή παράγει μια τιμή στο εύρος από `0.0` έως `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Και αυτό παράγει έναν τυχαίο αριθμό από `100.0` έως `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
