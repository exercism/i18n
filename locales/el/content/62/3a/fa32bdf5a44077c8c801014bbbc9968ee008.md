# Υποδείξεις

## 1. Ολίσθησε τα bit προς τα πίσω

- Υπάρχουν δύο τελεστές για ολίσθηση προς τα δεξιά, αλλά μόνο ένας εισάγει πάντα ένα 0.

## 2. Θέσε μερικά bit

- Ένας από τους bitwise τελεστές θέτει πάντα ένα bit σε 1 όπου τα bit και στις δύο τιμές είναι 1.

## 3. Αντιστρέψε συγκεκριμένα bit

- Υπάρχει μια πράξη bit που αντιστρέφει ένα bit όπου η μάσκα είναι 1.

## 4. Καθάρισε συγκεκριμένα bit

- Μία από τις πράξεις bit καθαρίζει τα bit όπου το bit στη μάσκα είναι 0.
- Αλλά μπορεί να χρειαστεί να τη συνδυάσεις με έναν άλλο τελεστή για να καθαρίσεις τα bit όπου η μάσκα είναι 1.
