# Οδηγίες

Σε αυτή την άσκηση, παίζεις ένα παιχνίδι μαντεψιάς αριθμών με έναν φίλο σου. Οι κανόνες είναι απλοί: διαλέγεις κρυφά έναν αριθμό ανάμεσα στο `1` και στο `100` και ο φίλος σου προσπαθεί να μαντέψει ποιον αριθμό διάλεξες. Για να βοηθήσεις τον φίλο σου, απαντάς διαφορετικά ανάλογα με το πόσο κοντά ήταν η μαντεψιά στον αριθμό που διάλεξες (`42`). Αυτοί είναι οι κανόνες για τις διάφορες απαντήσεις:

- Αν η μαντεψιά είναι `42`: "Correct"
- Αν η μαντεψιά είναι `41` ή `43`: "So close"
- Αν η μαντεψιά είναι μικρότερη από `41`: "Too low"
- Αν η μαντεψιά είναι μεγαλύτερη από `43`: "Too high"

Έχεις τέσσερις εργασίες για να κωδικοποιήσεις τις απαντήσεις στις μαντεψιές.

## 1. Απάντησε σε μια σωστή μαντεψιά

Υλοποίησε τη συνάρτηση `reply` για να απαντήσεις σε μια σωστή μαντεψιά:

```fsharp
reply 42
// => "Correct"
```

## 2. Απάντησε σε μια κοντινή μαντεψιά

Τροποποίησε τη συνάρτηση `reply` για να απαντήσεις σε κοντινές μαντεψιές:

```fsharp
reply 41
// => "So close"
```

## 3. Απάντησε σε πολύ χαμηλές μαντεψιές

Τροποποίησε τη συνάρτηση `reply` για να απαντήσεις σε πολύ χαμηλές μαντεψιές:

```fsharp
reply 25
// => "Too low"
```

## 4. Απάντησε σε πολύ υψηλές μαντεψιές

Τροποποίησε τη συνάρτηση `reply` για να απαντήσεις σε πολύ υψηλές μαντεψιές:

```fsharp
reply 88
// => "Too high"
```
