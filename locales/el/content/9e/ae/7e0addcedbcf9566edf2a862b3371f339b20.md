# Σχετικά

Μια [`Tuple`][tuple] μοιάζει αρκετά με ένα [`Vector`][vector] (μονοδιάστατο `array`) από πολλές απόψεις.
Ωστόσο, υπάρχουν μερικές σημαντικές διαφορές.

- Οι πλειάδες γράφονται μέσα σε παρενθέσεις `( )` αντί για αγκύλες `[ ]`, αν και οι παρενθέσεις μπορούν να παραλειφθούν σε περιπτώσεις όπου το νόημα είναι σαφές.
- Οι πλειάδες δεν χρειάζεται να είναι ομοιογενείς: ο τύπος κάθε στοιχείου αποθηκεύεται ανεξάρτητα.
- Οι πλειάδες είναι αμετάβλητες.

Η αμεταβλητότητα επιτρέπει περισσότερες βελτιστοποιήσεις από τον μεταγλωττιστή και κάνει τις πλειάδες πιο αποδοτικές από τα Vector, οπότε προτιμώνται σε περιπτώσεις όπου η μεταβλητότητα δεν είναι απαραίτητη.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String}
```
Υπάρχει επίσης ένας κατασκευαστής `Tuple()`, που μετατρέπει οποιαδήποτε επαναλήψιμη συλλογή σε πλειάδα.
Χρήσιμα, αυτό αντιμετωπίζει μια συμβολοσειρά ως επαναλήψιμη συλλογή χαρακτήρων.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Σε οποιαδήποτε πλειάδα, μπορείς να προσπελάσεις τα στοιχεία με βάση τη θέση ή να τα διατρέξεις με έναν βρόχο.

Οποιαδήποτε καθαρά αριθμητική πλειάδα μπορεί επίσης να χρησιμοποιηθεί σε μαθηματικές συναρτήσεις όπως η `sum()`, ακριβώς όπως οι πίνακες.

## Αποσυσκευασία

Μια πλειάδα μπορεί να αποσυσκευαστεί σε μεμονωμένα στοιχεία χρησιμοποιώντας πολλαπλή ανάθεση.
Για στοιχεία που δεν χρειάζεσαι, χρησιμοποίησε την κάτω παύλα `_` ως εικονική μεταβλητή.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Για να αντιγράψεις όλα τα στοιχεία μιας πλειάδας σε μια άλλη πλειάδα (ή γενικότερα σε μια συλλογή), υπάρχει ο τελεστής [`splat`][splat] `...` που την αποσυσκευάζει.
Αυτό θα καλυφθεί με περισσότερες λεπτομέρειες στην Έννοια [Functions][functions].

```julia-repl
julia> new_tup = (tup..., π, '😊')
(1, "Julia", true, π, '😊')
```

## Ονομαστικές πλειάδες

Μια [`Tuple`][tuple] περιέχει μόνο τιμές.
Μια [`NamedTuple`][namedtuple] συνδυάζει κάθε τιμή με ένα όνομα.

Τα επιμέρους πεδία μπορούν στη συνέχεια να προσπελαστούν με συμβολισμό "τελείας":

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Το όνομα αποθηκεύεται εσωτερικά ως [`Symbol`][symbol] (ένας αμετάβλητος τύπος, και πριν από το όνομα μπαίνει η διπλή τελεία `:`), οπότε υπάρχει και εναλλακτική σύνταξη:

```julia-repl
julia> nt[:b]
7.3
```

Μερικές φορές είναι χρήσιμο να χωρίσεις τη δημιουργία μιας ονομαστικής πλειάδας σε δύο βήματα:

1. Όρισε τα πεδία ως προσαρμοσμένο τύπο δεδομένων.
2. Χρησιμοποίησέ τον ως κατασκευαστή για να μετατρέψεις μια πλειάδα σε ονομαστική πλειάδα.

```julia-repl
# Step 1
julia> Student = NamedTuple{(:name, :grade), Tuple{String, Int}}
@NamedTuple{name::String, grade::Int64}

julia> typeof(Student)
DataType

# Step 2
julia> s = Student( ("Helen", 3) )
(name = "Helen", grade = 3)

julia> dump(s)
@NamedTuple{name::String, grade::Int64}
  name: String "Helen"
  grade: Int64 3
```

Υπάρχουν εντυπωσιακά πολλοί άλλοι τρόποι για να δημιουργήσεις μια ονομαστική πλειάδα, οπότε ρίξε μια ματιά στην [τεκμηρίωση][namedtuple] αν σε ενδιαφέρει.

Είναι εύκολο να πάρεις ξεχωριστά είτε τα ονόματα (που λέγονται και "κλειδιά") είτε τις τιμές:

```julia-repl
julia> keys(s)
(:name, :grade)

julia> values(s)
("Helen", 3)
```

Σημείωσε ότι η επανάληψη πάνω σε μια ονομαστική πλειάδα παράγει μόνο τις _τιμές_, και τα _ονόματα_ αγνοούνται.

Αν τα ονόματα είναι επίσης χρήσιμα σε μια επανάληψη, χρειάζονται περισσότερα βήματα.
Η `NamedTuple` μπορεί να μετατραπεί σε ένα [`Vector`][vector] από [`Pairs`][pairs] (τα `Pair` είναι το θέμα μιας άλλης Έννοιας).

```julia-repl
julia> pairs(s)
pairs(::NamedTuple) with 2 entries:
  :name  => "Helen"
  :grade => 3

julia> collect(pairs(s))
2-element Vector{Pair{Symbol, Any}}:
  :name => "Helen"
  :grade => 3
```

Η ονομαστική πλειάδα μοιάζει λοιπόν αρκετά με λεξικό.
Ωστόσο, διαφέρει από ένα [`Dict`][dict] στη Julia με μερικούς σημαντικούς τρόπους:

- Ένα `Dict` είναι μεταβλητό· μια `NamedTuple`, όπως κάθε πλειάδα, είναι αμετάβλητη.
- Ένα `Dict` είναι ευέλικτο ως προς τον τύπο των κλειδιών που δέχεται· μια `NamedTuple` μπορεί να χρησιμοποιήσει μόνο σύμβολα ως κλειδιά.

Οι πλειάδες (ονομαστικές ή μη) είναι ένας πολύ συνηθισμένος τρόπος για να μεταφέρεις δομημένα δεδομένα προς και από συναρτήσεις.
Η αμεταβλητότητα είναι καλή σε αυτή την περίπτωση χρήσης, καθώς παρέχει ασφάλεια δεδομένων και επιτρέπει πιο επιθετικές βελτιστοποιήσεις από τον μεταγλωττιστή.
