# Οδηγίες

Σε αυτή την άσκηση δουλεύεις σε ένα μαγαζί με πίτσες που κάνει παράδοση σε πελάτες.

Προσφέρεις τρεις τύπους πίτσας:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Οι πελάτες μπορούν επίσης να διαλέξουν δύο επιπλέον επιλογές με μια μικρή επιπλέον χρέωση:

1. Επιπλέον σάλτσα: \$1
1. Επιπλέον υλικά: \$2

Όταν οι πελάτες κάνουν παραγγελία, προστίθεται μια επιπλέον χρέωση αν παραγγείλουν μόνο μία ή δύο πίτσες:

- 1 πίτσα: \$3
- 2 πίτσες: \$2

Έχεις τρεις εργασίες, καθεμία από τις οποίες θα δουλέψει με πίτσες και την τιμή τους.

## 1. Όρισε τους τύπους πίτσας και τις επιλογές

Όρισε τη διακριτή ένωση `Pizza` ώστε να αναπαριστά τους τύπους πίτσας και τις δύο επιπλέον επιλογές που μπορούν να προστεθούν σε μια πίτσα:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. Υπολόγισε την τιμή της πίτσας

Υλοποίησε τη συνάρτηση `pizzaPrice` για να υπολογίζει την τιμή μιας πίτσας:

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. Υπολόγισε την τιμή μιας παραγγελίας

Υλοποίησε τη συνάρτηση `orderPrice` για να υπολογίζει την τιμή μιας παραγγελίας:

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
