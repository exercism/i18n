# Υποδείξεις

## 1. Επίστρεψε μια λίστα με τα ονόματα των στοιχείων

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `iterator.map`][map] για να μετασχηματίσεις τα στοιχεία ενός iterator.

## 2. Επίστρεψε όποια στοιχεία είναι φθηνά

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `iterator.filter`][filter] για να αφαιρέσεις μερικά στοιχεία από έναν iterator.

## 3. Επίστρεψε όποια στοιχεία είναι εκτός αποθέματος

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `iterator.filter`][filter] για να αφαιρέσεις μερικά στοιχεία από έναν iterator.

## 4. Επίστρεψε το συνολικό απόθεμα

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `iterator.fold`][fold] για να μειώσεις έναν iterator σε μία μόνο τιμή.

[map]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#map
[filter]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#filter
[fold]: https://hexdocs.pm/gleam_stdlib/gleam/iterator.html#fold
