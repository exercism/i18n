# Σχετικά

- Η Elixir είναι δυναμικά τυποποιημένη.
  - Ο τύπος μιας μεταβλητής ελέγχεται μόνο κατά τον χρόνο εκτέλεσης.
- Χρησιμοποιώντας τον τελεστή αντιστοίχισης [`=`][match], μπορούμε να δεσμεύσουμε μια τιμή οποιουδήποτε τύπου σε ένα όνομα μεταβλητής:
  - Είναι δυνατό να επαναδεσμεύσουμε μεταβλητές.
  - Σε μια μεταβλητή μπορεί να δεσμευτεί μια τιμή οποιουδήποτε τύπου.

## Αρθρώματα

- Τα [αρθρώματα][modules] είναι η βάση της οργάνωσης του κώδικα στην Elixir.
  - Ένα άρθρωμα είναι ορατό σε όλα τα άλλα αρθρώματα.
  - Ένα άρθρωμα ορίζεται με το [`defmodule`][defmodule].

## Ονομαστικές συναρτήσεις

- Όλες οι [ονομαστικές συναρτήσεις][functions] πρέπει να ορίζονται μέσα σε ένα άρθρωμα.

  - Οι ονομαστικές συναρτήσεις ορίζονται με το [`def`][def].
  - Μια ονομαστική συνάρτηση μπορεί να γίνει ιδιωτική χρησιμοποιώντας το [`defp`][defp] αντί για το `def`.
  - Η τιμή της τελευταίας έκφρασης σε μια συνάρτηση _επιστρέφεται σιωπηρά_.
  - Οι σύντομες συναρτήσεις μπορούν επίσης να γραφτούν με σύνταξη μίας γραμμής.

  ```elixir
  def increment(n) do
    n + 1
  end

  defp private_increment(n) do
    n + 1
  end

  def short_increment(n), do: n + 1
  ```

- Οι συναρτήσεις καλούνται χρησιμοποιώντας το πλήρες όνομα της συνάρτησης μαζί με το όνομα του αρθρώματος.
  - Αν καλεστεί μέσα από το ίδιο της το άρθρωμα, το όνομα του αρθρώματος μπορεί να παραλειφθεί.
- Το πλήθος ορισμάτων μιας συνάρτησης χρησιμοποιείται συχνά όταν αναφερόμαστε σε μια ονομαστική συνάρτηση.

  - Το πλήθος ορισμάτων αναφέρεται στον αριθμό των ορισμάτων που δέχεται.

  ```elixir
  # add/3, because the arity is 3
  def add(x, y, z), do: x + y + z
  ```

## Συμβάσεις ονοματοδοσίας

Τα ονόματα αρθρωμάτων πρέπει να χρησιμοποιούν `PascalCase`. Ένα όνομα αρθρώματος πρέπει να ξεκινά με κεφαλαίο γράμμα `A-Z` και μπορεί να περιέχει γράμματα `a-zA-Z`, αριθμούς `0-9` και κάτω παύλες `_`.

Τα ονόματα μεταβλητών και συναρτήσεων πρέπει να χρησιμοποιούν `snake_case`. Ένα όνομα μεταβλητής ή συνάρτησης πρέπει να ξεκινά με πεζό γράμμα `a-z` ή κάτω παύλα `_`, μπορεί να περιέχει γράμματα `a-zA-Z`, αριθμούς `0-9` και κάτω παύλες `_`, και μπορεί να τελειώνει με ερωτηματικό `?` ή θαυμαστικό `!`.

## Ακέραιοι

Οι ακέραιες τιμές είναι ακέραιοι αριθμοί γραμμένοι με ένα ή περισσότερα ψηφία. Μπορείς να εκτελέσεις [βασικές μαθηματικές πράξεις][operators] πάνω τους.

## Συμβολοσειρές

Τα [κυριολεκτικά συμβολοσειράς][string] είναι ακολουθίες χαρακτήρων που περικλείονται σε διπλά εισαγωγικά.

```elixir
string = "this is a string! 1, 2, 3!"
```

## Τυπική βιβλιοθήκη

- Η τεκμηρίωση είναι διαθέσιμη στο διαδίκτυο στη διεύθυνση [hexdocs.pm/elixir][docs].
- Οι περισσότεροι ενσωματωμένοι τύποι δεδομένων έχουν ένα αντίστοιχο άρθρωμα, π.χ. `Integer`, `Float`, `String`, `Tuple`, `List`.
- Το άρθρωμα `Kernel` είναι ένα ειδικό άρθρωμα.
  - Παρέχει τις βασικές δυνατότητες πάνω στις οποίες χτίζεται η υπόλοιπη τυπική βιβλιοθήκη.
  - Εισάγεται αυτόματα.
  - Οι συναρτήσεις του μπορούν να χρησιμοποιηθούν χωρίς το πρόθεμα `Kernel.`.
