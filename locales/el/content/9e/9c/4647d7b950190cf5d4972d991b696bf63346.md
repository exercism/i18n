# Instructions

Η Jen εργάζεται στο δωμάτιο διαλογής σε ένα μεγάλο εργοστάσιο.
Το δωμάτιο διαλογής πρέπει να επεξεργάζεται ό,τι φτάνει σε αυτό, κατηγοριοποιώντας το με μια ετικέτα.
Η Jen είναι υπεύθυνη για πράγματα που έχουν προκατηγοριοποιηθεί ως αριθμοί και χρειάζεται ένα πρόγραμμα που θα τη βοηθήσει στη διαλογή.

Οι περισσότερες πρωτογενείς τιμές πρέπει να παίρνουν απλές ετικέτες.
Για τους αριθμούς, θέλει συμβολοσειρές που να λένε `"This is the number 2.0"` (αν ο αριθμός ήταν 2).
Η Jen θέλει την ίδια έξοδο για ακέραιους και δεκαδικούς.

Υπάρχουν μερικές διεπαφές `Box` που πρέπει να ξετυλιχτούν για να πάρουμε το περιεχόμενό τους.
Για ένα `NumberBox`, θέλει συμβολοσειρές που να λένε `"This is a box containing the number 3.0"` (αν η μέθοδος `Number()` επιστρέφει 3).
Για ένα `FancyNumberBox`, θέλει συμβολοσειρές που να λένε `"This is a fancy box containing the number 4.0"`, αλλά μόνο αν ο τύπος είναι `FancyNumber`.

Οτιδήποτε απρόσμενο πρέπει να λέει `"Return to sender"`, ώστε η Jen να μπορεί να το στείλει πίσω από όπου ήρθε.

## 1. Περιγράψε τους απλούς αριθμούς

Η Jen θέλει οι αριθμοί να επιστρέφουν συμβολοσειρές όπως `"This is the number 2.0"` (συμπεριλαμβανομένου ενός ψηφίου μετά την υποδιαστολή):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Περιγράψε ένα κουτί αριθμού

Η Jen θέλει τα κουτιά αριθμών να επιστρέφουν συμβολοσειρές όπως `"This is a box containing the number 2.0"` (και πάλι, συμπεριλαμβανομένου ενός ψηφίου μετά την υποδιαστολή):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Υλοποίησε μια μέθοδο που εξάγει τον αριθμό από ένα φανταχτερό κουτί αριθμού

Η Jen χρειάζεται μια βοηθητική συνάρτηση για να εξάγει τον αριθμό από ένα `FancyNumberBox`.
Αν το `FancyNumberBox` είναι ένα `FancyNumber`, εξήγαγε την τιμή του και μετέτρεψέ την από `string` σε `int`.
Κάθε άλλος τύπος `FancyNumberBox` πρέπει να επιστρέφει 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Περιγράψε ένα φανταχτερό κουτί αριθμού

Αν το `FancyNumberBox` είναι ένα `FancyNumber`, η Jen θέλει συμβολοσειρές που να λένε `"This is a fancy box containing the number 4.0"`.
Κάθε άλλος τύπος `FancyNumberBox` πρέπει να λέει `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

ΣΗΜΕΙΩΣΗ: πρέπει να χρησιμοποιήσουμε τη συνάρτηση `ExtractFancyNumber`!

## 5. Υλοποίησε τη συνάρτηση `DescribeAnything` που τις χρησιμοποιεί όλες

Αυτή είναι η κύρια συνάρτηση που χρειάζεται η Jen και δέχεται οποιαδήποτε είσοδο.
Η `DescribeAnything` πρέπει να αναθέτει στις άλλες συναρτήσεις με βάση τον τύπο της τιμής που περνάει ως όρισμα.
Πιο συγκεκριμένα:

- Τα `int` και `float64` πρέπει και τα δύο να αναθέτουν στη `DescribeNumber`
- Το `NumberBox` πρέπει να αναθέτει στη `DescribeNumberBox`
- Το `FancyNumberBox` πρέπει να αναθέτει στη `DescribeFancyNumberBox`
- οτιδήποτε άλλο πρέπει να έχει ως αποτέλεσμα `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
