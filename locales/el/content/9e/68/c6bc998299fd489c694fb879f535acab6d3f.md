# Τεστ

Για να χρησιμοποιήσεις το test runner, θα χρειαστεί να έχεις [εγκαταστήσει σωστά το Godot][installation].

## Εκτέλεση των τεστ

Το [test runner][] χρησιμοποιείται για να φορτώνει και να δοκιμάζει λύσεις.
Για να τρέξεις το test runner, κατέβασέ το τοπικά και μετά χρησιμοποίησε το `godot` για να το εκτελέσεις.
Στο μέλλον, το test runner θα κατεβαίνει αυτόματα μαζί με τις ασκήσεις όταν χρησιμοποιείς το `exercism download`.

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
