# Σχετικά

Για να μπορεί ένα αντικείμενο να συγκριθεί με ένα άλλο αντικείμενο, πρέπει να υλοποιεί τη διεπαφή `IComparable<T>`.
Αυτή η διεπαφή έχει μία μόνο μέθοδο που πρέπει να υλοποιηθεί: `int CompareTo(T other)`.

Υπάρχουν τρεις πιθανές τιμές επιστροφής για τη μέθοδο `CompareTo`:

- Τιμή μικρότερη από το μηδέν: το τρέχον αντικείμενο είναι μικρότερο από το άλλο αντικείμενο.
- Τιμή μεγαλύτερη από το μηδέν: το τρέχον αντικείμενο είναι μεγαλύτερο από το άλλο αντικείμενο.
- Τιμή ίση με το μηδέν: το τρέχον αντικείμενο είναι ίσο με το άλλο αντικείμενο.

```csharp
public class Book : IComparable<Book>
{
    public int PageCount { get; set; }

    public int CompareTo(Book other)
    {
        // If other is not a valid object reference, this instance is greater.
        if (other == null) return 1;

        // Compare books using their number of pages
        return PageCount.CompareTo(other.PageCount);
    }
}

var smallBook = new Book { PageCount = 99 };
var largeBook = new Book { PageCount = 3333 };

smallBook.CompareTo(largeBook);
// => -1
```
