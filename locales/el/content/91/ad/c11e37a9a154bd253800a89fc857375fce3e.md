# Σχετικά

Ένα `SYMBOL:` δεν *κρατάει* μια τιμή, είναι απλώς ένα όνομα. Η τιμή ζει σε έναν χώρο ονομάτων και το όνομα λειτουργεί ως κλειδί μέσα σε αυτόν.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Δύο εμβέλειες:

- **καθολική**: γράφεται/διαβάζεται με `set-global`, `get-global`, `change-global`. Οι τιμές παραμένουν για όλη τη διάρκεια ζωής της διεργασίας.
- **δυναμική**: γράφεται/διαβάζεται με `set`, `get`, `change`. Οι δεσμεύσεις ζουν για όλη τη διάρκεια μιας φόρμας `with-variable`, επιτρέποντας στον εξωτερικό κώδικα να "εισάγει" μια τιμή που βλέπει ο εσωτερικός κώδικας, χωρίς να χρειάζεται να αλλάξει κάθε υπογραφή ανάμεσά τους.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

Τα `SYMBOL:` και `SYMBOLS:` δηλώνουν σύμβολα κατά τη φόρτωση του λεξιλογίου, κάνοντάς τα κοινόχρηστες αναφορές μεταξύ αρχείων.
