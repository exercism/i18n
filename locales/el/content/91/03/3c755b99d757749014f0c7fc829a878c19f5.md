# Προσθήκη οδηγιών

## Υλοποίηση

Αυτό το πρόβλημα μπορεί να λυθεί εύκολα χρησιμοποιώντας την [ενσωματωμένη συνάρτηση `sqrt` της Roc](sqrt).

Ωστόσο, θα θέλαμε να σκεφτείς την πρόκληση να λύσεις αυτή την άσκηση χωρίς να χρησιμοποιήσεις ενσωματωμένες συναρτήσεις ή αρθρώματα.

Ενώ υπάρχει ένας μαθηματικός τύπος που μπορεί να βρει την τετραγωνική ρίζα _οποιουδήποτε_ αριθμού, έχουμε επιλέξει να έχουμε ως λύσεις μόνο [φυσικούς αριθμούς][natural-number] (θετικούς ακέραιους).

[sqrt]: https://www.roc-lang.org/docs/main/Num/#F64.sqrt
[natural-number]: https://en.wikipedia.org/wiki/Natural_number
