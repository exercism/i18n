# Προσθήκη στις οδηγίες

## Υποδείξεις

Αυτή η άσκηση απαιτεί να επεξεργαστείς μια συλλογή δεδομένων. Μπορείς να απλοποιήσεις τον κώδικά σου χρησιμοποιώντας το LINQ (Language Integrated Query).
Για περισσότερες πληροφορίες, δες [αυτή τη σελίδα](https://docs.microsoft.com/en-us/dotnet/articles/standard/using-linq).
