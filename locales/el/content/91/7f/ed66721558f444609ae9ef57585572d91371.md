# Υποδείξεις

## Γενικά

- Στον [οδηγό Ξεκινώντας][guide] της Elixir υπάρχει μια ωραία υπενθύμιση για τις επώνυμες συναρτήσεις.

## 1. Δώσε την απάντηση όταν η μαντεψιά ταιριάζει με τον μυστικό αριθμό

- Μπορείς να χρησιμοποιήσεις ένα [guard][guard] για να ελέγξεις αν οι αριθμοί είναι ίδιοι με τον τελεστή `===/2`.

## 2. Δώσε την απάντηση όταν η μαντεψιά είναι μεγαλύτερη από τον μυστικό αριθμό

- Μπορείς να προσθέσεις μια [ρήτρα συνάρτησης][multiple-fn-clauses] και [guards][guard] για να ελέγξεις αν η μαντεψιά είναι μεγαλύτερη από τον μυστικό αριθμό (`>/2`).

## 3. Δώσε την απάντηση όταν η μαντεψιά είναι μικρότερη από τον μυστικό αριθμό

- Μπορείς να προσθέσεις μια [ρήτρα συνάρτησης][multiple-fn-clauses] και [guards][guard] για να ελέγξεις αν η μαντεψιά είναι μικρότερη από τον μυστικό αριθμό (`</2`).

## 4. Δώσε τις απαντήσεις όταν η μαντεψιά είναι κατά ένα μεγαλύτερη ή κατά ένα μικρότερη από τον μυστικό αριθμό

- Μπορείς να προσθέσεις μια [ρήτρα συνάρτησης][multiple-fn-clauses] και [guards][guard] για να ελέγξεις αν η μαντεψιά είναι κατά ένα μικρότερη ή κατά ένα μεγαλύτερη από τον μυστικό αριθμό.
- Οι εκφράσεις guards μπορούν να χρησιμοποιήσουν το `and/2` ή το `or/2` για να συνδυάσουν λογικές εκφράσεις.
- Πρόσεξε τη σειρά των ρητρών συνάρτησης.

## 5. Δώσε την απάντηση όταν δεν υπάρχει μαντεψιά

- Μπορείς να χρησιμοποιήσεις ένα [προεπιλεγμένο όρισμα][default-arg] για τη μαντεψιά. Η προεπιλεγμένη τιμή δεν χρειάζεται να είναι ακέραιος αριθμός.
- Χρησιμοποίησε μια κεφαλίδα συνάρτησης πριν από όλες τις άλλες ρήτρες συνάρτησης, για να ορίσεις το προεπιλεγμένο όρισμα.

[default-arg]: https://hexdocs.pm/elixir/modules-and-functions.html#default-arguments
[guard]: https://hexdocs.pm/elixir/Kernel.html#guards
[guide]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
[multiple-fn-clauses]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
