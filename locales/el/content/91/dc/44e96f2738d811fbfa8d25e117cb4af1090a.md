# Οδηγίες

Ως λάτρης του σκακιού, θέλεις να γράψεις τη δική σου εκδοχή του παιχνιδιού.
Ναι, υπάρχουν ήδη πολλές υλοποιήσεις σκακιού διαθέσιμες στο διαδίκτυο, αλλά η δική σου θα είναι μοναδική!

Ξεκινάς υλοποιώντας ένα βασικό σύστημα κίνησης για τα κομμάτια.

Το παιχνίδι του σκακιού θα παίζεται σε μια σκακιέρα πλάτους οκτώ τετραγώνων και μήκους οκτώ τετραγώνων.
Τα τετράγωνα προσδιορίζονται από ένα γράμμα και έναν αριθμό.

## 1. Όρισε το εύρος των γραμμών και των στηλών

Το παιχνίδι θα πρέπει να αποθηκεύει τις γραμμές της σκακιέρας.
Οι γραμμές είναι οι οριζόντιες σειρές της σκακιέρας και αριθμούνται από το 1 έως το 8.

Το παιχνίδι θα πρέπει επίσης να αποθηκεύει τις στήλες της σκακιέρας.
Οι στήλες είναι οι κάθετες σειρές της σκακιέρας και προσδιορίζονται από τα γράμματα A έως H.

Όρισε τις σταθερές `Chess::RANKS` και `Chess::FILES` που αποθηκεύουν αντίστοιχα το εύρος των γραμμών και των στηλών.

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. Έλεγξε αν το τετράγωνο είναι έγκυρο

Το παιχνίδι θα πρέπει να ελέγχει αν ένα τετράγωνο είναι έγκυρο.
Ένα τετράγωνο είναι έγκυρο αν η γραμμή και η στήλη βρίσκονται μέσα στα εύρη των γραμμών και των στηλών.

Όρισε τη μέθοδο `Chess.valid_square?` που δέχεται τα ορίσματα `rank`, που περιέχει έναν ακέραιο με τη γραμμή, και `file`, που περιέχει έναν χαρακτήρα με τη στήλη.
Η μέθοδος θα πρέπει να επιστρέφει `true` αν η γραμμή και η στήλη βρίσκονται μέσα στο εύρος των γραμμών και των στηλών, και `false` διαφορετικά.

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. Πάρε το ψευδώνυμο του παίκτη

Το παιχνίδι θα πρέπει να παίρνει το ψευδώνυμο του παίκτη.
Το ψευδώνυμο αποτελείται από τους δύο πρώτους χαρακτήρες του μικρού ονόματος του παίκτη και τους δύο τελευταίους χαρακτήρες του επωνύμου του.
Το ψευδώνυμο θα πρέπει να γράφεται με κεφαλαία.

Όρισε τη μέθοδο `Chess.nickname` που δέχεται τα ορίσματα `first_name`, που περιέχει μια συμβολοσειρά με το μικρό όνομα του παίκτη, και `last_name`, που περιέχει μια συμβολοσειρά με το επώνυμο του παίκτη.
Η μέθοδος θα πρέπει να επιστρέφει το ψευδώνυμο του παίκτη ως συμβολοσειρά με κεφαλαία γράμματα.

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. Δημιούργησε το μήνυμα κίνησης

Το παιχνίδι θα πρέπει να δημιουργεί ένα μήνυμα για μια κίνηση, ώστε να λέει ποιος παίκτης μετακινήθηκε σε ποιο τετράγωνο.
Το μήνυμα θα πρέπει να χρησιμοποιεί το ψευδώνυμο του παίκτη και το τετράγωνο στο οποίο μετακινήθηκε.
Το παιχνίδι πρέπει επίσης να προσδιορίζει αν η κίνηση είναι έγκυρη, ελέγχοντας αν η στήλη και η γραμμή του τετραγώνου βρίσκονται μέσα στα εύρη των στηλών και των γραμμών.

Αν η κίνηση είναι έγκυρη, το μήνυμα θα πρέπει να είναι: `"{nickname} moved to {square}"`
Αν η κίνηση δεν είναι έγκυρη, το μήνυμα θα πρέπει να είναι: `"{nickname} attempted to move to {square}, but that is not a valid square"`

Όρισε τη μέθοδο `Chess.move_message` που δέχεται τα ορίσματα `first_name`, που περιέχει μια συμβολοσειρά με το `first_name` του παίκτη, `last_name`, που περιέχει μια συμβολοσειρά με το `last_name` του παίκτη, και `square`, που περιέχει μια συμβολοσειρά με το τετράγωνο στο οποίο μετακινήθηκε ο παίκτης.
Η μέθοδος θα πρέπει να επιστρέφει το μήνυμα για την κίνηση ως συμβολοσειρά.

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
