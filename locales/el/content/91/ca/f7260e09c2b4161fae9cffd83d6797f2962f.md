# Debug

Όταν αποτυγχάνει ένα test, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά και για ποια είσοδο.
Μπορείς επίσης να αξιοποιήσεις το γεγονός ότι θα εμφανιστεί και η [έξοδος στην κονσόλα][fmt-println].
Μπορείς να γράψεις στην κονσόλα χρησιμοποιώντας:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Σημείωση: Όταν κάνεις debug με τον επεξεργαστή μέσα στον περιηγητή, η χρήση, για παράδειγμα, του `fmt.Print` δεν θα προσθέσει αλλαγή γραμμής μετά την έξοδο, κάτι που μπορεί να προκαλέσει bug στο `go test --json` και να έχει ως αποτέλεσμα να χαλάσει η έξοδος του test.
