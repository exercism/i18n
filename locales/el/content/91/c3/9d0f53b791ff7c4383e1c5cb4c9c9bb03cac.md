# Οδηγίες

Η Elyse, η μελλοντική μάγισσα, συνεχίζει την εκπαίδευσή της.
Θα της δοθούν αρκετές τράπουλες που τις χρειάζεται για να κάνει τα κόλπα της.
Για να κάνει τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10.
Έχει μόνο μία από κάθε κάρτα, δεν υπάρχουν διπλότυπα στις τράπουλες της.

Σε αυτή την άσκηση, χρησιμοποίησε μεθόδους από τη βιβλιοθήκη Base της Julia για να αναλύσεις τα περιεχόμενα ενός πίνακα.

## 1. Προσδιόρισε αν υπάρχει μια κάρτα

Η Elyse θέλει να προσδιορίσει αν μια κάρτα υπάρχει στην τράπουλα, με άλλα λόγια, αν η τράπουλα περιέχει έναν συγκεκριμένο αριθμό.

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. Βρες τη θέση μιας κάρτας

Η Elyse θέλει να μάθει τη θέση (index) μιας κάρτας στην τράπουλα.
Αν η κάρτα δεν είναι στην τράπουλα, επίστρεψε `nothing`.

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. Προσδιόρισε αν κάθε κάρτα είναι άρτια

Η Elyse θέλει να μάθει αν κάθε κάρτα είναι άρτια, με άλλα λόγια, αν κάθε αριθμός στην τράπουλα είναι άρτιος.

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. Έλεγξε αν η τράπουλα περιέχει μια κάρτα με περιττή τιμή

Η Elyse θέλει να μάθει αν υπάρχει περιττός αριθμός στην τράπουλα.

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. Προσδιόρισε τη θέση της πρώτης άρτιας κάρτας

Η Elyse θέλει να μάθει τη θέση της πρώτης κάρτας που είναι άρτια.
Αν δεν υπάρχουν άρτιες κάρτες στην τράπουλα, επίστρεψε `nothing`.

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. Πάρε την πρώτη περιττή κάρτα από την τράπουλα

Η Elyse θέλει να μάθει την τιμή της πρώτης κάρτας που είναι περιττή.
Αν δεν υπάρχουν περιττές κάρτες στην τράπουλα, επίστρεψε `nothing`.

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
