# Οδηγίες

Μια φορά κι έναν καιρό ζούσε ένας εκκεντρικός προγραμματιστής σε ένα παράξενο σπίτι με κάγκελα στα παράθυρα.
Μια μέρα δέχτηκε μια δουλειά από μια διαδικτυακή πλατφόρμα αγγελιών εργασίας για να φτιάξει ένα ρομπότ για πάρτι.
Το ρομπότ υποτίθεται ότι χαιρετάει τους ανθρώπους και τους βοηθάει να καθίσουν στις θέσεις τους.
Η πρώτη έκδοση ήταν πολύ τεχνική και έδειχνε την έλλειψη ανθρώπινης επαφής του προγραμματιστή.
Μερικά από αυτά πέρασαν και στην επόμενη έκδοση.

## 1. Καλωσόρισε έναν νέο καλεσμένο στο πάρτι

Υλοποίησε τη συνάρτηση `Welcome` ώστε να επιστρέφει ένα μήνυμα υποδοχής με το όνομα που δίνεται:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Καλωσόρισε έναν νέο καλεσμένο στο πάρτι που έχει γενέθλια σήμερα

Υλοποίησε τη συνάρτηση `HappyBirthday` ώστε να επιστρέφει ένα μήνυμα γενεθλίων χρησιμοποιώντας το όνομα και την ηλικία του ατόμου που δίνονται.
Δυστυχώς ο προγραμματιστής είναι λίγο καυχησιάρης, οπότε το ρομπότ πρέπει να επιδείξει τη γνώση του για τα γενέθλια κάθε καλεσμένου.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Δώσε οδηγίες

Υλοποίησε τη συνάρτηση `AssignTable` ώστε να δίνει οδηγίες.
Πρέπει να δέχεται 5 παραμέτρους.

- Το όνομα του νέου καλεσμένου που θα χαιρετήσεις (`string`)
- Ο αριθμός του τραπεζιού (`int`)
- Το όνομα του διπλανού (`string`)
- Η κατεύθυνση για να βρεις το τραπέζι (`string`)
- Η απόσταση από το τραπέζι (`float64`)

Η ακριβής μορφή του αποτελέσματος φαίνεται στο παρακάτω παράδειγμα.

Το ρομπότ δίνει τον αριθμό του τραπεζιού σε μορφή 3 ψηφίων.
Αν ο αριθμός έχει λιγότερα από 3 ψηφία, παίρνει επιπλέον μηδενικά μπροστά για να φτάσει τα 3 ψηφία (π.χ. το 3 γίνεται 003).
Το ρομπότ αναφέρει επίσης την απόσταση του τραπεζιού.
Ευτυχώς μόνο με ακρίβεια που περιορίζεται σε 1 δεκαδικό ψηφίο.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
