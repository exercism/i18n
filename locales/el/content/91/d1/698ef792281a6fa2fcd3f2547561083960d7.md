# Εισαγωγή

## Πράξεις bitwise

Οι πράξεις bitwise μάς επιτρέπουν να επεξεργαζόμαστε μεμονωμένα ψηφία μέσα σε δυαδικούς αριθμούς.

Η Elm παρέχει αρκετούς τελεστές bitwise στο [άρθρωμα Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

### Βασικές πράξεις

Η τροποποίηση μεμονωμένων bit ενός αριθμού ονομάζεται _κάλυψη_.
Μια _μάσκα_ είναι ένας αριθμός όπου συγκεκριμένα bit έχουν τεθεί με έναν ιδιαίτερο τρόπο, ώστε να τροποποιήσουν έναν άλλο αριθμό χρησιμοποιώντας τελεστές bitwise όπως οι `and`, `or` και `xor`.

#### and

Ο `and` συνδυάζει δύο αριθμούς κρατώντας μόνο τα bit που είναι `1` και στους δύο.
Αυτό είναι χρήσιμο για να ελέγξεις αν ένα μεμονωμένο bit έχει τεθεί.
Για παράδειγμα, για να ελέγξεις αν το 4ο bit ενός αριθμού έχει τεθεί σε `1`, κάνε `and` με μια μάσκα `01000` (`8` στο δεκαδικό σύστημα) και δες αν το αποτέλεσμα είναι μη μηδενικό:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

Ο `or` συνδυάζει δύο αριθμούς θέτοντας κάθε bit σε `1` αν είναι `1` στον έναν ή και στους δύο αριθμούς.
Αυτό είναι χρήσιμο για να θέσεις ένα συγκεκριμένο bit σε `1`.
Για παράδειγμα, για να θέσεις το 2ο bit στο `10101` σε `1`, κάνε `or` με τη μάσκα `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### Αποκλειστικό ή (xor)

Ο `xor` συνδυάζει δύο αριθμούς θέτοντας κάθε bit σε `1` αν είναι `1` στον έναν αριθμό αλλά `0` στον άλλο.
Αυτό είναι χρήσιμο για να αντιστρέψεις ένα bit στην αντίθετη τιμή του:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### Συμπλήρωμα

Το `complement` αντιστρέφει κάθε bit ενός αριθμού (`0` γίνεται `1`, `1` γίνεται `0`).

Σημείωσε ότι έτσι οι θετικοί αριθμοί γίνονται αρνητικοί και οι αρνητικοί γίνονται θετικοί.
Αυτό συμβαίνει επειδή οι αρνητικοί αριθμοί στο δυαδικό σύστημα παριστάνονται με `1` στο αριστερότερο ψηφίο.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### Μετατόπιση bit

Οι παρακάτω τελεστές μετακινούν τα bit αριστερά ή δεξιά κατά έναν καθορισμένο αριθμό θέσεων, πολλαπλασιάζοντας ή διαιρώντας ουσιαστικά με δυνάμεις του 2.

Ο `shiftLeftBy` μετακινεί τα bit προς τα αριστερά, γεμίζοντας με `0` από τα δεξιά.
Για παράδειγμα, για να μετακινήσεις το `21` αριστερά κατά 3 θέσεις:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Αυτό είναι το ίδιο με το να πεις `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: Μετακινεί τα bit προς τα δεξιά:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Η μετατόπιση δεξιά κατά 2 θέσεις είναι το ίδιο με ακέραια διαίρεση με το 4.

Σημείωσε ότι αυτή η συνάρτηση αντιγράφει όποια τιμή βρίσκεται στο αριστερότερο bit.
Έτσι, οι αρνητικοί αριθμοί παραμένουν αρνητικοί:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Αν θέλεις να μετατοπίσεις δεξιά και να γεμίσεις με μηδενικά, χρησιμοποίησε το `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
