# Σχετικά

Οι αριθμοί κινητής υποδιαστολής είναι κλασματικοί ή ακέραιοι αριθμοί γραμμένοι με υποδιαστολή (όπως `3.14`, `-1.7`, `99.99`, `2048.0`).

Ο τύπος float στη Common Lisp χωρίζεται σε αρκετούς υποτύπους, καθένας με τα δικά του χαρακτηριστικά και τη δική του ακρίβεια: short-float, single-float, double-float και long-float.

Ο υπότυπος short-float καταλαμβάνει συνήθως τη λιγότερη μνήμη και προσφέρει τη χαμηλότερη ακρίβεια από τους τέσσερις υποτύπους. Είναι κατάλληλος για περιπτώσεις όπου η χρήση μνήμης αποτελεί ζήτημα, αλλά μια μικρότερη ακρίβεια είναι αποδεκτή.

Ο υπότυπος single-float προσφέρει ισορροπία ανάμεσα στη χρήση μνήμης και στην ακρίβεια. Χρησιμοποιείται συνήθως για γενικούς υπολογισμούς κινητής υποδιαστολής.

Ο υπότυπος double-float προσφέρει μεγαλύτερη ακρίβεια σε σύγκριση με τον single-float και είναι κατάλληλος για εφαρμογές που απαιτούν ακριβέστερους υπολογισμούς, όπως επιστημονικούς υπολογισμούς και αριθμητικές προσομοιώσεις.

Ο υπότυπος long-float προσφέρει τη μεγαλύτερη ακρίβεια από τους τέσσερις υποτύπους, αλλά μπορεί να απαιτεί περισσότερη μνήμη σε σύγκριση με τους άλλους. Χρησιμοποιείται συνήθως για εξειδικευμένες εφαρμογές που απαιτούν εξαιρετικά ακριβείς υπολογισμούς.

Αυτοί οι υπότυποι επιτρέπουν στους προγραμματιστές της Common Lisp να επιλέξουν το κατάλληλο επίπεδο ακρίβειας και χρήσης μνήμης ανάλογα με τις απαιτήσεις των συγκεκριμένων εφαρμογών τους.

Γενικά, αν δουλεύεις μόνο με ακέραιες τιμές, καλύτερα να προτιμάς τους ακέραιους, γιατί αυτοί δεν υφίστανται την ίδια απώλεια ακρίβειας που υφίστανται οι αριθμοί κινητής υποδιαστολής έπειτα από πολλούς υπολογισμούς.

## Αναφορά

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
