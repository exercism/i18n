# Υποδείξεις

## Γενικά

- Διάβασε για τη Σύνθεση Συναρτήσεων στο [εγχειρίδιο][function-composition-manual].
- Ρίξε μια ματιά στις [διαθέσιμες μεθόδους για τις _Συμβολοσειρές_][string-methods].

## 1. Καθάρισε το όνομα

- Υπάρχει μια [ενσωματωμένη μέθοδος][string-replace] για να αντικαταστήσεις όλες τις εμφανίσεις μιας υποσυμβολοσειράς μέσα σε μια συμβολοσειρά.
- Υπάρχει μια [ενσωματωμένη μέθοδος][string-strip] για να αφαιρέσεις τα κενά στην αρχή και στο τέλος μιας συμβολοσειράς.

## 2. Πάρε το πρώτο γράμμα του ονόματος

- Για να πάρεις έναν συγκεκριμένο χαρακτήρα από μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις [πρόσβαση ανά θέση][string-indexing].
- Ο πιο καθαρός τρόπος να το γράψεις είναι με τον τελεστή σύνθεσης `∘`.

## 3. Μορφοποίησε το πρώτο γράμμα ως αρχικό

- Υπάρχει μια [ενσωματωμένη μέθοδος][string-uppercase] για να μετατρέψεις όλους τους χαρακτήρες μιας συμβολοσειράς στην κεφαλαία τους μορφή.

## 4. Βάλε τα αρχικά μέσα στην καρδιά

- Μπορείς να χρησιμοποιήσεις χαρακτήρες unicode στις συμβολοσειρές με τον εξής τρόπο: `'\u<id>'`, όπου, στην περίπτωση του emoji της καρδιάς, το id είναι `2764`.
- Αυτό μπορεί να γίνει με [συνένωση][string-concatenation] ή [παρεμβολή][string-interpolation].
