# Υποδείξεις

## 1. Πάρε τα προεπιλεγμένα δικαιώματα για έναν τύπο λογαριασμού

- Όρισε το enum `Permission` με τιμές για τους παρακάτω τύπους δικαιωμάτων: `None`, `Read`, `Write` και `Delete`.
- Η χρήση σημαιών enum θα επέτρεπε να χρησιμοποιήσεις πράξεις bitwise χωρίς επιπλέον κώδικα για το enum `Permission`, [δες `enum` `Flags`][docs-enum-flags].
- Το μέλος enum `All` μπορεί να οριστεί ως συνδυασμός των μελών enum `Read`, `Write` και `Delete`.
- Όρισε το enum `AccountType` με τιμές για τους παρακάτω τύπους λογαριασμού: `Guest`, `User` και `Moderator`.
- Για να χειριστείς κάθε τύπο λογαριασμού, θα μπορούσες να χρησιμοποιήσεις μια εντολή `if`, αλλά η [εντολή `switch`][docs.microsoft.com-switch-keyword] είναι μια εξαιρετική εναλλακτική.
- Ο συνδυασμός σημαιών σημαίνει να θέσεις ένα συγκεκριμένο bit στο `1` χρησιμοποιώντας έναν από τους [τελεστές bitwise][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Παραχώρησε ένα δικαίωμα

- Ο συνδυασμός σημαιών σημαίνει να θέσεις ένα συγκεκριμένο bit στο `1` χρησιμοποιώντας έναν από τους [τελεστές bitwise][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Ανακάλεσε ένα δικαίωμα

- Η αφαίρεση μιας σημαίας σημαίνει να θέσεις ένα συγκεκριμένο bit στο `0` χρησιμοποιώντας έναν συνδυασμό από δύο [τελεστές bitwise][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Έλεγξε αν υπάρχει ένα δικαίωμα

- Ο έλεγχος ενός δικαιώματος μπορεί να γίνει ελέγχοντας το αποτέλεσμα της εφαρμογής ενός από τους [τελεστές bitwise][docs.microsoft.com-bitwise-and-shift-operators].
