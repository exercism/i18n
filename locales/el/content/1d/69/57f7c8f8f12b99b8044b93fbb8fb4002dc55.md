# Σχετικά

Η αντιστοίχιση μοτίβων είναι η διαδικασία διακλάδωσης ανάλογα με το αν μια τιμή ταιριάζει με δεδομένα μοτίβα, τα οποία μπορεί να είναι και εμφωλευμένα. Στο Haxe, η **αντιστοίχιση μοτίβων** γίνεται με μια έκφραση `switch` και με επιμέρους εκφράσεις `case`.

Ας δούμε αυτή τη δομή δεδομένων:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Τα μοτίβα αντιστοιχίζονται πάντα από πάνω προς τα κάτω.
- Η έκφραση του πιο πάνω μοτίβου που ταιριάζει με την τιμή εισόδου είναι αυτή που εκτελείται.
- Ένα μοτίβο `_` ταιριάζει με οτιδήποτε, οπότε το `case _:` ισοδυναμεί με το `default:`

## Αντιστοίχιση απαριθμήσεων

Οι απαριθμήσεις μπορούν να αντιστοιχιστούν με φυσικό τρόπο μέσω του κατασκευαστή τους:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
