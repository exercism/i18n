# Σχετικά

Στη C#, μια ιεραρχία _κλάσεων_ μπορεί να οριστεί με τη χρήση της _κληρονομικότητας_, η οποία επιτρέπει σε μια παράγωγη κλάση (`Car`) να κληρονομήσει τη συμπεριφορά και τα δεδομένα της γονικής της κλάσης (`Vehicle`). Αν δεν οριστεί γονική κλάση, η κλάση κληρονομεί από την κλάση `object`.

Οι γονικές κλάσεις μπορούν να παρέχουν λειτουργικότητα στις παράγωγες κλάσεις με τρεις τρόπους:

- Ορισμός μιας κανονικής μεθόδου.
- Ορισμός μιας [`virtual` μεθόδου][virtual-keyword], η οποία είναι σαν μια κανονική μέθοδος, μόνο που οι παράγωγες κλάσεις _μπορούν_ να την αλλάξουν.
- Ορισμός μιας [`abstract` μεθόδου][abstract-keyword], δηλαδή μιας μεθόδου χωρίς υλοποίηση, την οποία οι παράγωγες κλάσεις _πρέπει_ να υλοποιήσουν. Μια κλάση με `abstract` μεθόδους πρέπει να χαρακτηριστεί και αυτή ως [`abstract`][abstract-classes]. Οι αφηρημένες κλάσεις δεν μπορούν να δημιουργηθούν ως στιγμιότυπα.

Ο [προσδιοριστής πρόσβασης `protected`][protected-keyword] επιτρέπει την πρόσβαση σε ένα μέλος της γονικής κλάσης μέσα από μια παράγωγη κλάση, αλλά εμποδίζει την πρόσβαση από άλλες κλάσεις. Έτσι, οι παράγωγες κλάσεις μπορούν να έχουν πρόσβαση σε μέλη `public` και `protected` της γονικής κλάσης, αλλά όχι σε μέλη `private` της γονικής κλάσης.

Οι παράγωγες κλάσεις μπορούν να έχουν πρόσβαση σε μέλη της γονικής κλάσης μέσω της [λέξης-κλειδιού `base`][base-keyword].

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

// Cannot be inherited from
sealed class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Ο κατασκευαστής μιας παράγωγης κλάσης [καλεί αυτόματα τον κατασκευαστή της γονικής της κλάσης][constructors] _πριν_ εκτελέσει τη δική του λογική. Μπορούν να περαστούν ορίσματα στον κατασκευαστή της γονικής κλάσης με τη [λέξη-κλειδί `base`][base-keyword-constructor]. Επειδή οι αφηρημένες κλάσεις δεν μπορούν να δημιουργηθούν ως στιγμιότυπα, οι κατασκευαστές τους μπορούν να οριστούν ως `protected`.

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Όταν από μια γονική κλάση παράγονται περισσότερες από μία κλάσεις, οι δύο (ή περισσότερες) υποκλάσεις συχνά υλοποιούν διαφορετικές εκδοχές μιας μεθόδου της γονικής κλάσης. Αυτή είναι μια πολύ σημαντική αρχή που ονομάζεται [πολυμορφισμός][polymorphism]. Για παράδειγμα, σε μια παραλλαγή του παραπάνω παραδείγματος δείχνουμε πώς ο κώδικας που χρησιμοποιεί `Vehicle` μπορεί να αλλάξει τη συμπεριφορά του ανάλογα με το τι τύπου όχημα έχει δημιουργηθεί ως στιγμιότυπο.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```

Για να εμποδίσεις μια κλάση από το να κληρονομηθεί, πρόσθεσε τον [προσδιοριστή `sealed`][sealed-classes].
Κάποιοι προγραμματιστές προσπαθούν να αποφεύγουν την κληρονομικότητα από συγκεκριμένες κλάσεις (όπως συζητείται σε [αυτή την ερώτηση στο SO][pro-sealed]) και ο προσδιοριστής _sealed_ υποστηρίζει αυτή την προσέγγιση. Από την άλλη, πολλοί προγραμματιστές της C# τους θεωρούν εμπόδιο στη συντήρηση, όπως συζητείται σε μερικά από τα σχόλια σε [αυτή την ερώτηση][anti-sealed]. Η συμβουλή είναι να χρησιμοποιείς τον προσδιοριστή sealed με φειδώ, μέχρι να αποκτήσεις σιγουριά για τη χρήση του στις δικές σου απαιτήσεις.

Το παρακάτω [άρθρο][new-vs-override] περιγράφει το `new` ως εναλλακτική του προσδιοριστή `override`. Αυτό είναι χρήσιμο περιστασιακά, ίσως με μπερδεμένες ιεραρχίες κλάσεων ή/και κάποιου είδους σύγκρουση βιβλιοθηκών.
