# Σχετικά

## Εντολές υπό συνθήκη

Οι εντολές υπό συνθήκη είναι εντολές λήψης αποφάσεων που μπορούν είτε να εκτελέσουν παρενέργειες είτε να ελέγξουν τη ροή εκτέλεσης ενός προγράμματος.
Οι εντολές υπό συνθήκη περιλαμβάνουν τις `if`, `if/else`, `switch` και `ternary`.

Οι εντολές υπό συνθήκη χρησιμοποιούνται για να θέτουν ερωτήματα σχετικά με μια τιμή ή μια σχέση τιμών.
Το ερώτημα αξιολογείται σε μια απάντηση Boolean, αλλά η ίδια η εντολή `if` μπορεί να επιστρέψει οποιαδήποτε τιμή ή απλώς να εκτελέσει μια παρενέργεια.

## Οι εντολές `if`

Η απλούστερη εντολή `if` αξιολογεί μια έκφραση και εκτελεί μία γραμμή.
Η έκφραση που ελέγχεται βρίσκεται πάντα μέσα σε παρενθέσεις.

Μπορεί να εκτελέσει μια παρενέργεια

```c
if (count > 10)
    printf("count is greater than 10");
```

ή μπορεί να αλλάξει τη ροή εκτέλεσης


```c
if (count > 10)
    return sum;
```

Αν μια εντολή `if` εκτελεί περισσότερες από μία γραμμές, πρέπει να τις τοποθετήσει μέσα σε άγκιστρα

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Ορισμένες ομάδες προγραμματιστών μπορεί να ορίσουν ως πρότυπο ότι οι εντολές `if` πρέπει να χρησιμοποιούν πάντα άγκιστρα, ακόμη και για μία μόνο γραμμή.


## Οι εντολές `if` και `else`

Μια εντολή `if` μπορεί να συνδυαστεί με μια `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Οι εντολές `if` και `else if`


Η `else` μπορεί να συνδυαστεί με μια άλλη `if` για να δημιουργήσει αυτό που ονομάζεται `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## Η εντολή `switch`


Μερικές φορές μια `if-else-if ladder` αναπαρίσταται καλύτερα με μια `switch`.
Όπως και με την `if`, η έκφραση που ελέγχεται μπαίνει πάντα σε παρενθέσεις.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Η περίπτωση `default` εκτελείται αν η τιμή που ελέγχεται δεν ταιριάζει με καμία από τις προηγούμενες περιπτώσεις.

Αν μια περίπτωση `switch` δεν επιστρέφει, τότε συνήθως παρεμβάλλεται ένα `break` για να τερματίσει κάθε περίπτωση, αλλιώς η λογική "πέφτει" στην επόμενη περίπτωση.
Μερικές φορές η πτώση στην επόμενη περίπτωση χρησιμοποιείται σκόπιμα

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Όταν η πτώση στην επόμενη περίπτωση συμβαίνει ακούσια, είναι ένα bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Ένα switch μπορεί να είναι χρήσιμο όταν ελέγχουμε συγκεκριμένες τιμές αντί για ένα εύρος τιμών.
Μπορεί να είναι ταχύτερο από μια `if-else-if ladder`, επειδή ο μεταγλωττιστής μπορεί να βελτιστοποιήσει την εντολή `switch` με τρόπους που δεν μπορεί να εφαρμόσει σε μια αλυσίδα if-else-if.
Ένα switch μπορεί μερικές φορές να φαίνεται πιο ευανάγνωστο από μια αλυσίδα.

## Ο τριαδικός τελεστής (γνωστός και ως τελεστής υπό συνθήκη)

Ο τριαδικός τελεστής είναι μια εντολή υπό συνθήκη με τρία μέρη, που χρησιμοποιείται συχνά για τον ορισμό μιας τιμής.
Η έκφραση που θα ελεγχθεί βρίσκεται πριν από το ερωτηματικό και δεν χρειάζεται να είναι μέσα σε παρενθέσεις.
Η τιμή που επιστρέφεται αν είναι αληθές βρίσκεται πριν από την άνω και κάτω τελεία, ενώ η τιμή που επιστρέφεται αν είναι ψευδές βρίσκεται μετά.
Μπορεί να επιστραφεί είτε ένα κυριολεκτικό τιμής είτε μια μεταβλητή.

```c
int i = j > 5 ? 5: j;
```

Οι τριαδικοί τελεστές μπορούν να εμφωλευτούν για να μειώσουν τη συντακτική πολυπλοκότητα.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Συγκρίσεις υπό συνθήκη για τιμές κινητής υποδιαστολής

Λόγω του τρόπου με τον οποίο υλοποιούνται οι αριθμοί κινητής υποδιαστολής, μια απλή μαθηματική πράξη μπορεί να οδηγήσει σε σφάλμα στρογγυλοποίησης, το οποίο μπορεί να κάνει έναν έλεγχο ισότητας να μην επιστρέψει το αναμενόμενο αποτέλεσμα.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Μια τιμή ανοχής, γνωστή ως `epsilon`, μπορεί να χρησιμοποιηθεί για να προσδιορίσει ένα εύρος μέσα στο οποίο μια τιμή μπορεί να βρίσκεται και να θεωρείται ακόμη ίση όταν συγκρίνεται με μια άλλη τιμή.
Ορισμένες πλατφόρμες έχουν ενσωματωμένες σταθερές για το epsilon των float και double.
Ανατρέξε στην τεκμηρίωση του μεταγλωττιστή σου για να μάθεις περισσότερα.
Ο υπολογισμός του epsilon μπορεί να είναι πολύπλοκος και μπορεί να διαφέρει από πλατφόρμα σε πλατφόρμα, ακόμη και από μηχάνημα σε μηχάνημα.
Ακολουθεί ένα παράδειγμα προγράμματος που χρησιμοποιεί μια απλή σύγκριση.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

Πρόσεχε όταν συγκρίνεις `float` ή `double` για ισότητα!
