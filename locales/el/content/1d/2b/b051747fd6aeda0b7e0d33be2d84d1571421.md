# Παράρτημα οδηγιών

## Μορφή εξόδου

Δώσε τους στίχους ως συμβολοσειρά που τερματίζεται με null.

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος    | Περιγραφή                                  |
| ----------- | -------------- | -------- | ------------------------------------------ |
| `$a0`       | είσοδος        | ακέραιος | αρχικά μπουκάλια                           |
| `$a1`       | είσοδος        | ακέραιος | πόσα κατεβάζεις                            |
| `$a2`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματιζόμενη με null |
| `$t0-9`     | προσωρινός     | οποιοδήποτε | για προσωρινή αποθήκευση                  |
