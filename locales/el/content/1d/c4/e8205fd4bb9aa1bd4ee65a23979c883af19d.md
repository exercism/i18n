# Σχετικά

Το βασικό που πρέπει να θυμάσαι για τις συμβολοσειρές στη Java είναι ότι είναι αμετάβλητα αντικείμενα που αναπαριστούν κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.).
Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσεις ένα στιγμιότυπο της `String`:

```java
String fruit = "Apple";
```

Ο χειρισμός μιας συμβολοσειράς μπορεί να γίνει χρησιμοποιώντας τις μεθόδους της κλάσης [`String`][string-class].
Καθώς οι τιμές των συμβολοσειρών δεν μπορούν ποτέ να αλλάξουν αφού οριστούν, όλες οι μέθοδοι χειρισμού συμβολοσειρών επιστρέφουν μια νέα συμβολοσειρά.

Μια συμβολοσειρά οριοθετείται από χαρακτήρες διπλών εισαγωγικών (`"`).
Κάποιοι ειδικοί χαρακτήρες χρειάζονται διαφυγή με τον χαρακτήρα της ανάστροφης καθέτου (`\`).
Χαρακτήρες που χρειάζονται διαφυγή στη Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Τέλος, υπάρχουν πολλοί τρόποι για να συνενώσεις συμβολοσειρές.
Ο πιο απλός είναι ο τελεστής `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Για οποιαδήποτε μορφοποίηση συμβολοσειράς πιο σύνθετη από την απλή συνένωση, προτιμάται η μέθοδος `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Άλλες δυνατότητες είναι:

- να χρησιμοποιήσεις την κλάση [`StringBuilder`][string-builder]
- να χρησιμοποιήσεις τη μέθοδο [`String.concat`][string-concat]
