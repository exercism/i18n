# Προσθήκη στις οδηγίες

## Έξοδος

Σε αυτήν την άσκηση, θα υλοποιήσεις ένα ρήμα που παράγει το τρίγωνο του Πασκάλ μέχρι έναν δεδομένο αριθμό γραμμών. Η έξοδος του ρήματός σου μπορεί να μορφοποιηθεί με έναν από τους δύο παρακάτω τρόπους:

  1. Ως πίνακα από λίστες σε πλαίσια, όπου κάθε λίστα αναπαριστά μια γραμμή του τριγώνου του Πασκάλ.
  1. Ως πίνακα, όπου οι αριθμοί στοιχίζονται δεξιά και μηδενικά χρησιμοποιούνται για να γεμίσουν τα κενά στα αριστερά.

### Παράδειγμα εξόδου

Ακολουθούν δύο έγκυρες έξοδοι για το `pascal 3`:

  - Ως πίνακα από λίστες σε πλαίσια:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Ως πίνακα με συμπλήρωση:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
