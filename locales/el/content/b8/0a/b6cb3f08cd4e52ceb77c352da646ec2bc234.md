# Υποδείξεις

## 1. Βρες την κάρτα μέσα στην τράπουλα

- Υπάρχει μια [ενσωματωμένη μέθοδος][index] που μπορεί να βρει το πρώτο στοιχείο της συλλογής που πληροί τη συνθήκη που ορίζεται στο μπλοκ και να επιστρέψει τη θέση του ή `nil` αν δεν βρεθεί κανένα στοιχείο.

## 2. Κάνε όλους τους χαρακτήρες κεφαλαίους

- Υπάρχει μια [ενσωματωμένη μέθοδος][map] για να μετασχηματίσεις όλα τα στοιχεία της συλλογής.
- Υπάρχει μια [ενσωματωμένη μέθοδος][capitalize] που κεφαλαιοποιεί τις λέξεις μιας `String`.

## 3. Υπολόγισε το επίπεδο ισχύος όλων των καρτών

- Μπορείς να χρησιμοποιήσεις τη [μέθοδο `sum`] για να υπολογίσεις το συνολικό επίπεδο ισχύος όλων των καρτών.
- Η μέθοδος `sum` μπορεί επίσης να δεχτεί ένα μπλοκ για να μετασχηματίσει τα στοιχεία πριν τα αθροίσει.

## 4. Αποκωδικοποίησε μια κάρτα

- Υπάρχει μια [ενσωματωμένη μέθοδος][each_char_with_index] για να διατρέξεις τους χαρακτήρες μιας `String` μαζί με τη θέση τους.
