# Προσθήκη οδηγιών

## Υποδείξεις

Το άρθρωμα Sgf θα πρέπει να εξάγει ένα άρθρωμα parseSgf με την ακόλουθη υπογραφή:

```haskell
parseSgf :: Text -> Maybe (Tree (Map Text [Text]))
```

Μπορεί να σου φανεί χρήσιμο να αντιγράψεις τους παρακάτω ορισμούς για τα SgfTree και SgfNode:

```haskell
-- | A tree of nodes.
type SgfTree = Tree SgfNode

-- | A node is a property list, each key can only occur once.
-- Keys may have multiple values associated with them.
type SgfNode = Map Text [Text]
```
