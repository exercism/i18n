# Συνθήκες

Η Crystal έχει αυτό που ονομάζουμε εκφράσεις ελέγχου. Αυτές χρησιμοποιούνται για να ελέγχουν τον τρόπο με τον οποίο θα τρέξει το πρόγραμμα και παίρνουν μια αληθή ή ψευδή τιμή.
Υπάρχουν τελεστές που μπορούν να χρησιμοποιηθούν για να δημιουργήσουν αληθείς ή ψευδείς τιμές, αυτοί είναι γνωστοί ως [τελεστές ισότητας και σύγκρισης][equality-and-comparison].

Υπάρχουν δύο βασικές εκφράσεις ελέγχου που καθορίζουν ποιος κώδικας θα εκτελεστεί και ποιος όχι.
Με άλλα λόγια, ποιος από τους κλάδους θα εκτελεστεί.

Αυτές οι δύο είναι: η `if` και η έκφραση `unless`.

## Τελεστές σύγκρισης

Οι τελεστές σύγκρισης χρησιμοποιούνται για να συγκρίνουν τιμές και επιστρέφουν μια τιμή `true` ή `false`.
Αυτοί οι τελεστές απαιτούν δύο τιμές ίδιου τύπου για να συγκριθούν.
Αν οι τιμές δεν είναι ίδιου τύπου, τότε ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Ακολουθεί μια λίστα με τους τελεστές σύγκρισης και ένα παράδειγμα για το πότε δίνουν την τιμή `true`:

| Μέθοδος | Περιγραφή           | Παράδειγμα |
| ------ | --------------------- | ------- |
| <      | μικρότερο από             | 4 < 5   |
| <=     | μικρότερο ή ίσο με    | 4 <= 4  |
| >      | μεγαλύτερο από          | 3 > 1   |
| >=     | μεγαλύτερο ή ίσο με | 2 >= 2  |

## Τελεστές ισότητας

Οι τελεστές ισότητας είναι παρόμοιοι με τους τελεστές σύγκρισης, αλλά χρησιμοποιούνται για να ελέγξουν αν δύο τιμές είναι ίσες ή όχι.

Ο τελεστής `==` ελέγχει αν δύο τιμές είναι ίσες, συμπεριλαμβανομένου του τύπου της τιμής.
Αν οι τιμές είναι ίδιες, τότε επιστρέφει `true`, αλλιώς επιστρέφει `false`.
Ο τελεστής `==` μπορεί να συγκρίνει οποιονδήποτε τύπο τιμής με οποιονδήποτε άλλο τύπο τιμής.
Ο `!=` λειτουργεί με τον ίδιο τρόπο, αλλά επιστρέφει `true` αν οι τιμές δεν είναι ίσες και `false` αν είναι ίσες.

## Η εντολή if

Η [εντολή `if`][if] χρησιμοποιείται για να ελέγξει αν μια δεδομένη συνθήκη είναι αληθής ή ψευδής.
Αν η συνθήκη είναι αληθής, τότε ο κώδικας μέσα στην εντολή if θα εκτελεστεί.
Μια εντολή `if` τελειώνει με τη λέξη-κλειδί `end`.

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## Η εντολή unless

Η [εντολή `unless`][unless] λειτουργεί πολύ παρόμοια με την εντολή `if`, αλλά εκτελεί τον κώδικα μέσα στην εντολή `unless` αν η συνθήκη είναι ψευδής.

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## Η εντολή else

Η εντολή `else` μπορεί να χρησιμοποιηθεί μαζί με τις εντολές `if` και `unless`.
Η εντολή `else` θα εκτελεστεί αν ο κλάδος `if` ή ο κλάδος `unless` δεν εκτελεστεί.

~~~~exercism/warning
Ακόμα κι αν ο κλάδος `else` μπορεί να χρησιμοποιηθεί μαζί με το `unless,`, αυτό δεν συνιστάται, γιατί βλάπτει την αναγνωσιμότητα.
Αντ' αυτού, συνιστάται η χρήση του `if !condition` με κλάδο else.
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## "Αλυσιδωτές" εντολές if

Η εντολή `elsif` μπορεί να χρησιμοποιηθεί μαζί με την εντολή if.
Η εντολή `elsif` θα εκτελεστεί αν ο κλάδος if δεν εκτελεστεί και η συνθήκη της εντολής `elsif` είναι αληθής.
Οι εντολές `elsif` μπορούν να αλυσοδεθούν μεταξύ τους και θα εκτελεστεί η πρώτη αληθής συνθήκη.
Μπορεί επίσης να υπάρχει μια εντολή else στο τέλος της εντολής if, η οποία θα εκτελεστεί αν καμία από τις προηγούμενες εντολές δεν ήταν αληθής.

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## Τύποι με συνθήκες

Όταν ανατίθεται σε διαφορετικούς τύπους, η μεταβλητή θα φέρει και τους δύο τύπους.
Αυτό συμβαίνει επειδή ο μεταγλωττιστής δεν γνωρίζει ποιος κλάδος θα εκτελεστεί.
Αυτή η πολλαπλή ανάθεση, γνωστή και ως ένωση, θα εξηγηθεί σε επόμενες έννοιες.
Αυτό φαίνεται στο παρακάτω παράδειγμα:

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```

## Ο τριαδικός τελεστής

Η Crystal έχει έναν τριαδικό τελεστή, μια εντολή if-else σε μία γραμμή: `condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```
