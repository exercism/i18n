# Εισαγωγή

## Τιμές Boolean στη Julia

Οι αληθείς ή ψευδείς τιμές αναπαρίστανται από τον τύπο `Bool`.
Περιέχει μόνο δύο τιμές: `true` και `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Τελεστές Boolean

Υπάρχουν τρεις τελεστές Boolean στη Julia.

Το `&&` είναι το Boolean "και".
Αξιολογείται σε `true` αν οι εκφράσεις και στις *δύο* πλευρές του `&&` είναι `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

Το `||` είναι το Boolean "ή".
Αξιολογείται σε `true` αν μία έκφραση σε *οποιαδήποτε* από τις δύο πλευρές του `||` είναι `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

Το `!` είναι το Boolean "όχι".
Ανταλλάσσει τις τιμές `true` και `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Για μεγαλύτερες και πιο σύνθετες εκφράσεις, το καλύτερο είναι να χρησιμοποιείς παρενθέσεις ώστε να γίνεται σαφής η πρόθεσή σου.

```julia-repl
julia> (true || false) && (false && true)
false
```
