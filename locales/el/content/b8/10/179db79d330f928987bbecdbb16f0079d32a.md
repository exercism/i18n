# Εισαγωγή

Μια `string` στη Clojure είναι μια συμβολοσειρά της Java, η οποία είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.) και ορίζεται ως εξής:

```clojure
(def fruit "Apple")
```

Η βιβλιοθήκη `clojure.string` παρέχει πολλές τυπικές συναρτήσεις χειρισμού και επεξεργασίας συμβολοσειρών. Επιπλέον, όλες οι συνήθεις μέθοδοι της Java για τον χειρισμό συμβολοσειρών είναι διαθέσιμες μέσω interop.
