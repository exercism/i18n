# Εύρη

Τα [εύρη][range] αντιπροσωπεύουν ένα διάστημα ανάμεσα σε δύο τιμές.
Οι πιο συνηθισμένοι τύποι που υποστηρίζουν εύρη είναι οι `Int`, `Char` και `String`.
Μπορούν να χρησιμοποιηθούν για πολλά πράγματα, όπως για να δημιουργήσεις γρήγορα μια συλλογή, για να κόψεις συμβολοσειρές, για να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος και για επανάληψη.
Δημιουργούνται με τον τελεστή εύρους `..` ή `...` (συμπεριληπτικό και αποκλειστικό, αντίστοιχα).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

Ο λόγος που υπάρχουν δύο τελεστές εύρους είναι για να δημιουργούμε εύρη που συμπεριλαμβάνουν ή όχι την τελική τιμή, κάτι που μπορεί να φανεί χρήσιμο όταν, για παράδειγμα, δουλεύεις με θέσεις που ξεκινούν από το μηδέν.

Τα εύρη μπορούν επίσης να δημιουργηθούν χρησιμοποιώντας τον αρχικοποιητή `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Όταν δημιουργείς ένα εύρος στην Crystal χρησιμοποιώντας τους τελεστές εύρους `..` ή `...` και θέλεις να καλέσεις μια μέθοδο πάνω στο εύρος, πρέπει να κλείσεις το εύρος σε παρενθέσεις.
Αυτό συμβαίνει γιατί αλλιώς η μέθοδος θα κληθεί στο δεύτερο όρισμα του τελεστή εύρους.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Λήψη υποσυμβολοσειρών

Όταν θέλεις να κόψεις μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον τελεστή εύρους για να πάρεις μια υποσυμβολοσειρά.
Δηλαδή, δημιουργώντας ένα εύρος με τη θέση αρχής και τέλους της υποσυμβολοσειράς.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Μπορείς επίσης να χρησιμοποιήσεις αρνητικές θέσεις για να πάρεις την υποσυμβολοσειρά από το τέλος της συμβολοσειράς.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Μέθοδοι των ευρών

Τα εύρη διαθέτουν ένα σύνολο μεθόδων που μπορούν να χρησιμοποιηθούν για να δουλέψεις μαζί τους.
Για παράδειγμα, αυτές οι μέθοδοι μπορούν να χρησιμοποιηθούν για να πάρεις το άθροισμα όλων των τιμών του εύρους ή να ελέγξεις αν το εύρος περιλαμβάνει μια τιμή.

| Μέθοδος                | Περιγραφή                                                               | Παράδειγμα                      |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Επιστρέφει το άθροισμα όλων των τιμών του εύρους                        | `(1..5).sum # => 15`            |
| [`size`][size]          | Επιστρέφει το μέγεθος του εύρους                                        | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Επιστρέφει `true` αν το εύρος περιλαμβάνει τη δεδομένη τιμή, αλλιώς `false` | `(1..5).includes?(3) # => true` |

## Εύρη χωρίς τέλος και χωρίς αρχή

Ένα εύρος μπορεί να μην έχει τέλος ή να μην έχει αρχή.
Το εύρος χωρίς τέλος ή χωρίς αρχή έχει ως τιμή αρχής ή τέλους το `nil`, αλλά το `nil` μπορεί να παραλειφθεί όταν ορίζεις το εύρος.

Η χρήση ευρών χωρίς αρχή ή τέλος είναι χρήσιμη όταν θέλεις, για παράδειγμα, να κόψεις μια συμβολοσειρά από την αρχή ή μέχρι το τέλος.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Αν δεν χρησιμοποιηθεί σε μια συλλογή, το εύρος χωρίς τέλος μπορεί να προκαλέσει μια ατελείωτη ακολουθία, αν δεν το χρησιμοποιήσεις με προσοχή.
~~~~

## Εύρη Char

Οι χαρακτήρες μπορούν να χρησιμοποιηθούν σε εύρη και σου επιτρέπουν να πάρεις ένα διάστημα χαρακτήρων ανάμεσα σε δύο χαρακτήρες.
Για παράδειγμα, αυτό είναι βολικό όταν θέλεις να πάρεις το αλφάβητο.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Εύρη String

Και οι συμβολοσειρές μπορούν να χρησιμοποιηθούν σε εύρη, επιτρέποντάς σου να πάρεις ένα διάστημα συμβολοσειρών ανάμεσα σε δύο συμβολοσειρές.
Αλλά η συμπεριφορά τους είναι ελαφρώς διαφορετική από αυτήν του `Char` όταν χρησιμοποιούνται πολλοί χαρακτήρες σε ένα εύρος συμβολοσειρών.
Η συμπεριφορά τους μπορεί να γίνει μπερδεμένη όταν φτιάχνεις πιο σύνθετα εύρη συμβολοσειρών, οπότε πρόσεχε.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
