# Εισαγωγή στους Πίνακες

Στη Java, οι πίνακες είναι ένας τρόπος να αποθηκεύεις πολλαπλές τιμές του ίδιου τύπου σε μία μόνο δομή.
Σε αντίθεση με άλλες δομές δεδομένων, οι πίνακες έχουν σταθερό μέγεθος μόλις δημιουργηθούν.
Τα στοιχεία μπορούν να ανατεθούν σε έναν πίνακα ή να ανακτηθούν από αυτόν χρησιμοποιώντας μια θέση.
Οι πίνακες στη Java αριθμούν τις θέσεις τους ξεκινώντας από το μηδέν: η θέση του πρώτου στοιχείου είναι 0, η θέση του δεύτερου στοιχείου είναι 1, κ.λπ.

Ακολουθεί η τυπική σύνταξη για την αρχικοποίηση ενός πίνακα:

```java
type[] variableName = new type[size];
```

Το `type` είναι ο τύπος των στοιχείων του πίνακα και μπορεί να είναι ένας πρωτογενής τύπος (π.χ. `int`) ή μια κλάση (π.χ. `String`).

Το `size` είναι ο αριθμός των στοιχείων που θα χωρέσει αυτός ο πίνακας (ο οποίος δεν μπορεί να αλλάξει αργότερα).
Μετά τη δημιουργία του πίνακα, τα στοιχεία αρχικοποιούνται στις προεπιλεγμένες τιμές τους (συνήθως `0`, `false` ή `null`).

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

Οι πίνακες μπορούν επίσης να οριστούν χρησιμοποιώντας μια συντομευμένη σημειογραφία που σου επιτρέπει και να δημιουργήσεις τον πίνακα και να ορίσεις την τιμή του:

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

Καθώς ο μεταγλωττιστής μπορεί τώρα να καταλάβει πόσα στοιχεία θα έχει ο πίνακας, το μήκος μπορεί να παραλειφθεί.

Τα στοιχεία του πίνακα μπορούν να ανατεθούν και να προσπελαστούν χρησιμοποιώντας σημειογραφία θέσης με αγκύλες:

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

Η πρόσβαση σε μια θέση εκτός των έγκυρων θέσεων του πίνακα οδηγεί σε `IndexOutOfBoundsException`.

Οι πίνακες μπορούν να χειριστούν είτε καλώντας τις μεθόδους ή τις ιδιότητες ενός στιγμιοτύπου πίνακα, είτε χρησιμοποιώντας τις στατικές μεθόδους που ορίζονται στην κλάση `Arrays` (συνήθως χρησιμοποιούνται μόνο σε γενικό κώδικα).
Η ιδιότητα `length` περιέχει το μήκος ενός πίνακα.
Μπορείς να την προσπελάσεις ως εξής:

```java
int arrayLength = someArray.length;
```

Η Java παρέχει επίσης μια χρήσιμη βοηθητική κλάση [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html) που έχει πολλές χρήσιμες μεθόδους σχετικές με πίνακες (π.χ. `Arrays.equals`).

Η Java υποστηρίζει επίσης [πολυδιάστατους πίνακες](https://www.programiz.com/java-programming/multidimensional-array) όπως `int[][] arr = new int[3][4];` που μπορούν να είναι πολύ χρήσιμοι.

Το γεγονός ότι ένας πίνακας είναι επίσης μια _συλλογή_ σημαίνει ότι, εκτός από την πρόσβαση σε τιμές με θέση, μπορείς να διατρέξεις _όλες_ τις τιμές του χρησιμοποιώντας έναν βρόχο `for-each`:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

Αν θέλεις περισσότερο έλεγχο στο ποιες τιμές θα διατρέξεις, μπορείς να χρησιμοποιήσεις έναν `for` βρόχο:

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
