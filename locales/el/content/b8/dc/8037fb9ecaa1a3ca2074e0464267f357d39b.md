# Κλάσεις με Κατάσταση

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Γραμμένο | Διαβάζεται από έξω | Αλλάζει από έξω |
| --- | --- | --- |
| `attr x : INT` | ναι | ναι |
| `readonly attr x : INT` | ναι | όχι |
| `private attr x : INT` | όχι | όχι |

Το `readonly` είναι αυτό που θα προτιμήσεις εξ ορισμού. Αφήνει τον καθένα να
βλέπει το σκορ και επιμένει ότι η αλλαγή του περνάει από το `home_goal`, όπου
και ζουν οι κανόνες για το σκοράρισμα.

## create και new

Το `new` παράγει ένα αντικείμενο αυτής της κλάσης με κάθε ιδιότητα κενή.
Μπορεί να χρησιμοποιηθεί μόνο μέσα στην κλάση.

Το `create` είναι μια συνηθισμένη ρουτίνα με συμφωνημένο όνομα: το `#C(args)`
είναι ακριβώς το `C::create(args)`. Μια κλάση μπορεί να έχει πολλά, που
ξεχωρίζουν από τα ορίσματά τους, και μια κλάση χωρίς κανένα απλώς δεν μπορεί
να δημιουργηθεί με `#`.

## SAME

Το `SAME` αντιπροσωπεύει την κλάση μέσα στην οποία είναι γραμμένο. Στο
`create` είναι ο τύπος επιστροφής· χρησιμεύει επίσης σε ένα όρισμα, και είναι
αυτό που κάνει μια κληρονομημένη ρουτίνα να μιλάει για την κληρονομούσα
κλάση και όχι για εκείνη από την οποία προήλθε.

## Ρουτίνες χωρίς τύπο επιστροφής

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Χωρίς `:` και χωρίς τύπο. Μια τέτοια ρουτίνα καλείται ως εντολή και δεν μπορεί
να εμφανιστεί σε μια έκφραση. Είναι το σημάδι ότι το νόημα της κλήσης είναι η
αλλαγή που προκαλεί.

## self

Μέσα σε μια ρουτίνα, το `self` είναι το αντικείμενο στο οποίο κλήθηκε. Σπάνια
γράφεται, γιατί μια ιδιότητα ή ρουτίνα που αναφέρεται μόνη της εννοεί ήδη
αυτή του `self`. Χρειάζεται όταν το αντικείμενο πρέπει να περαστεί παρακάτω ή
να επιστραφεί:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

Τα `self`, `new`, `void`, `result`, `value` και `out` είναι όλα λέξεις που έχει
πάρει η Sather, και κανένα δεν μπορεί να χρησιμοποιηθεί ως δικό σου όνομα.

## Αναφορά, όχι τιμή

Ένα αντικείμενο προσεγγίζεται μέσω μιας αναφοράς. Δύο ονόματα για το ίδιο
ταμπλό σκορ βλέπουν το ίδιο σκορ:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

Το `immutable class`, πιο μετά, είναι ο τρόπος να πάρεις την άλλη
συμπεριφορά.
