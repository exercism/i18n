# Υποδείξεις

- Η συνάρτηση `format` θα χρειαστεί γι' αυτή την άσκηση.

## 1. Μορφοποίηση τριμηνιαίων τιμών

- Η `format` επιστρέφει πάντα `nil`, εκτός αν η παράμετρος stream είναι `nil`.
- Μπορείς να χρησιμοποιήσεις το `~A` για να μορφοποιήσεις μια τιμή.

## 2. Η αναφορά δύο τριμήνων

- Η προηγούμενη συνάρτησή σου είναι ιδανική για να δημιουργήσεις τις δύο γραμμές που χρειάζονται.
- Μπορείς να χρησιμοποιήσεις τα `~%` και `~&` για να δημιουργήσεις νέες γραμμές.

## 3. Αναγνώσιμο από άνθρωπο εναντίον Lisp Alien

- Η προηγούμενη συνάρτησή σου για τη μορφοποίηση τριμήνου είναι ιδανική για να δημιουργήσεις τις συμβολοσειρές που χρειάζονται.
- Μπορείς να χρησιμοποιήσεις το `~S` για να μορφοποιήσεις τιμές σε αναγνώσιμη μορφή.
