# Σχετικά

Τα [εύρη][range] αντιπροσωπεύουν ένα διάστημα μεταξύ δύο τιμών.
Τα εύρη χρησιμοποιούνται συνήθως με τύπους όπως οι `Int`, `String` και `Character` για να διατρέξεις ακολουθίες, να κόψεις συλλογές ή να ελέγξεις αν μια τιμή βρίσκεται εντός ορίων.

Η Swift παρέχει δύο βασικούς τελεστές εύρους:

- **Τελεστής κλειστού εύρους (`...`)**: Περιλαμβάνει και την αρχική και την τελική τιμή (το `1...5` περιλαμβάνει τις τιμές 1, 2, 3, 4 και 5).
- **Τελεστής ημιανοικτού εύρους (`..<`)**: Περιλαμβάνει την αρχική τιμή αλλά αποκλείει την τελική (το `1..<5` περιλαμβάνει τις τιμές 1, 2, 3 και 4).

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
Όταν καλείς μια μέθοδο απευθείας πάνω σε ένα literal εύρους, βάλε την έκφραση του εύρους μέσα σε παρενθέσεις, ώστε ο μεταγλωττιστής να αξιολογήσει πρώτα το εύρος:

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```

## Μετατροπή ενός εύρους σε πίνακα

Μπορείς να μετατρέψεις ένα εύρος αριθμών σε `Array` χρησιμοποιώντας τον αρχικοποιητή `Array(_:)`:

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## Κόψιμο ενός πίνακα με εύρη

Μπορείς να χρησιμοποιήσεις εύρη για να κόψεις υποτμήματα ενός πίνακα:

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## Ιδιότητες και μέθοδοι ευρών

Συνήθεις λειτουργίες στα εύρη περιλαμβάνουν:

| Μέλος                   | Περιγραφή                                                | Παράδειγμα                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | Επιστρέφει τον αριθμό των στοιχείων στο εύρος                | Το `(1...5).count` επιστρέφει `5`          |
| [`contains(_:)`][contains] | Επιστρέφει `true` αν το εύρος περιλαμβάνει την καθορισμένη τιμή | Το `(1...5).contains(3)` επιστρέφει `true` |

## Μονόπλευρα εύρη

Η Swift υποστηρίζει επίσης μονόπλευρα (μερικά) εύρη, όπου παραλείπεις είτε την αρχική είτε την τελική τιμή:

- `array[2...]`: Από τη θέση 2 μέχρι το τέλος της συλλογής.
- `array[...2]`: Από την αρχή της συλλογής μέχρι και τη θέση 2.
- `array[..<2]`: Από την αρχή της συλλογής μέχρι (αλλά χωρίς να περιλαμβάνει) τη θέση 2.

## Εύρη συμβολοσειρών και χαρακτήρων

Εύρη μπορούν επίσης να δημιουργηθούν ανάμεσα σε χαρακτήρες ή συμβολοσειρές που συμμορφώνονται με το `Comparable`:

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
