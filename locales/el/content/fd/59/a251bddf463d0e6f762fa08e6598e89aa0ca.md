# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων. Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (σβηστή) έως `10` (μέγιστη).

Στη χαμηλότερη ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα κάθε ώρα. Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα. Έτσι, με την ταχύτητα στο `4`, θα πρέπει να παράγει `4 * 221 = 884` αυτοκίνητα την ώρα. Ωστόσο, οι υψηλότερες ταχύτητες αυξάνουν την πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία μετά πρέπει να απορριφθούν.

Έχεις τρεις εργασίες.

## 1. Υπολόγισε το ποσοστό επιτυχίας

Υλοποίησε τη μέθοδο `success_rate()` για να υπολογίσεις την αναλογία δημιουργίας ενός αντικειμένου χωρίς σφάλμα για μια δεδομένη ταχύτητα. Ο παρακάτω πίνακας δείχνει πώς η ταχύτητα επηρεάζει το ποσοστό επιτυχίας:

- `0`: ποσοστό επιτυχίας 0%.
- `1` έως `4`: ποσοστό επιτυχίας 100%.
- `5` έως `8`: ποσοστό επιτυχίας 90%.
- `9`: ποσοστό επιτυχίας 80%.
- `10`: ποσοστό επιτυχίας 77%.

```R
success_rate(10)
# => 0.77
```

## 2. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Υλοποίησε τη μέθοδο `production_rate_per_hour()` για να υπολογίσεις τον ρυθμό παραγωγής της γραμμής συναρμολόγησης ανά ώρα, λαμβάνοντας υπόψη το ποσοστό επιτυχίας της:

```R
production_rate_per_hour(6)
# => 1193.4
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `double`.

## 3. Υπολόγισε τον αριθμό των λειτουργικών αντικειμένων που παράγονται ανά λεπτό

Υλοποίησε τη μέθοδο `working_items_per_minute()` για να υπολογίσεις πόσα λειτουργικά αυτοκίνητα παράγονται ανά λεπτό:

```R
working_items_per_minute(6)
# => 19
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι ακέραιος αριθμός: τα ημιτελή αντικείμενα δε συμπεριλαμβάνονται.
