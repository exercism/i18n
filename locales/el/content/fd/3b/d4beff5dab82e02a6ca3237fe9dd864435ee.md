# Τεστ

Για να τρέξεις τα τεστ μέσα από τον φάκελο της άσκησης, τρέξε την εντολή:

```sh
odin test .
```

Όσο κάνεις τεστ, το Odin μπορεί να "vet" τον κώδικά σου: μπορεί να ψάξει για πράγματα όπως αχρησιμοποίητα imports και μεταβλητές. Τρέξε τα τεστ σου με:

```sh
odin test . -vet
```

Για περισσότερες επιλογές, δες το `odin test -help`.
