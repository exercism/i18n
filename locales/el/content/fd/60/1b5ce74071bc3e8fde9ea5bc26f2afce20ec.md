# Οδηγίες

Δουλεύεις στο γραφείο του δήμου εδώ και καιρό και έχεις φτιάξει ένα σύνολο εργαλείων που κάνουν πιο γρήγορη την καθημερινή σου δουλειά, για παράδειγμα όταν συμπληρώνεις φόρμες.

Τώρα έρχεται ένας νέος συνάδελφος να δουλέψει μαζί σου και συνειδητοποίησες ότι τα εργαλεία σου μπορεί να μην είναι αυτονόητα.
Υπάρχουν πολλές περίεργες συνήθειες στο γραφείο σου, όπως το να συμπληρώνεις πάντα τις φόρμες με κεφαλαία γράμματα και να αποφεύγεις να αφήνεις πεδία κενά.

Ως πρώτο βήμα, αποφασίζεις να προσθέσεις δηλώσεις τύπων της PHP, ώστε ο νέος σου συνάδελφος να μπει αμέσως στο κλίμα και να αρχίσει να χρησιμοποιεί τα εργαλεία σου.

## 1. Δήλωσε τους τύπους για την κλάση `Address`

Πρόσθεσε δηλώσεις τύπου ιδιοτήτων σε καθεμία από τις δηλωμένες ιδιότητες της κλάσης `Address`.
Κάθε ιδιότητα της κλάσης πρέπει να δηλωθεί ως συμβολοσειρά.

## 2. Δήλωσε τους τύπους για να συμπληρώσεις τη φόρμα με κενές τιμές

Πρόσθεσε μια δήλωση τύπου παραμέτρου και μια δήλωση τύπου επιστροφής στη μέθοδο `blanks` της κλάσης `Form`.
Η μέθοδος πρέπει να δέχεται ένα ακέραιο μήκος και να επιστρέφει μια συμβολοσειρά που αναπαριστά την κενή γραμμή.

## 3. Δήλωσε τον τύπο όταν χωρίζεις μια τιμή σε ξεχωριστά γράμματα

Πρόσθεσε μια δήλωση τύπου παραμέτρου και μια δήλωση τύπου επιστροφής στη μέθοδο `letters` της κλάσης `Form`.
Η μέθοδος πρέπει να δέχεται μια συμβολοσειρά, που αναπαριστά λέξεις, και να επιστρέφει έναν πίνακα με γράμματα.

## 4. Δήλωσε τον τύπο όταν ελέγχεις αν μια τιμή χωράει σε μια φόρμα

Πρόσθεσε δηλώσεις τύπων παραμέτρων και μια δήλωση τύπου επιστροφής στη μέθοδο `checkLength` της κλάσης `Form`.
Η μέθοδος πρέπει να δέχεται μια συμβολοσειρά, δηλαδή μια λέξη, και έναν ακέραιο, το μέγιστο μήκος, και να επιστρέφει μια τιμή αληθή ή ψευδή.

## 5. Δήλωσε τον τύπο όταν μορφοποιείς μια διεύθυνση στη φόρμα

Πρόσθεσε μια δήλωση τύπου παραμέτρου, αξιοποιώντας την κλάση `Address` που ενημέρωσες προηγουμένως, και μια δήλωση τύπου επιστροφής στη μέθοδο `formatAddress` της κλάσης `Form`.
Η μέθοδος πρέπει να δέχεται ένα `Address` και να επιστρέφει μια μορφοποιημένη συμβολοσειρά.
