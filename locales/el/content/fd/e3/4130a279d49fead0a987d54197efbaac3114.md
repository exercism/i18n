# Εισαγωγή

Για να ορίσεις μια καθολική συνάρτηση στη Common Lisp, χρησιμοποιείς την έκφραση `defun`.
Αυτή η έκφραση παίρνει ως πρώτο όρισμα μια λίστα με παραμέτρους (μια κενή λίστα σημαίνει ότι η συνάρτηση δεν έχει παραμέτρους).
Ακολουθεί προαιρετικά μια συμβολοσειρά τεκμηρίωσης (δες παρακάτω) και μετά μηδέν ή περισσότερες εκφράσεις που αποτελούν το "σώμα" της συνάρτησης.

Οι συναρτήσεις μπορούν να έχουν μηδέν ή περισσότερες παραμέτρους.

```lisp
(defun no-args () (+ 1 1))

(defun add-one (x) (1+ x))

(defun add-nums (x y) (+ x y))
```

Καλείς μια συνάρτηση αξιολογώντας μια έκφραση που έχει ως πρώτο στοιχείο το σύμβολο που προσδιορίζει τη συνάρτηση και ως υπόλοιπα στοιχεία τα ορίσματα της συνάρτησης (αν υπάρχουν).

Η τιμή στην οποία αξιολογείται μια συνάρτηση είναι η τιμή της τελευταίας έκφρασης που αξιολογήθηκε στο σώμα της συνάρτησης.
Όλες οι συναρτήσεις αξιολογούνται σε κάποια τιμή.

```lisp
(add-nums 2 2) ;; => 4
```

Οι συναρτήσεις μπορούν επίσης να έχουν, προαιρετικά, μια συμβολοσειρά τεκμηρίωσης (γνωστή και ως 'docstring').
Αν υπάρχει, τοποθετείται μετά τη λίστα ορισμάτων αλλά πριν από το σώμα της συνάρτησης.
Μπορείς να έχεις πρόσβαση στη συμβολοσειρά τεκμηρίωσης μέσω της `documentation`.

```lisp
(defun add-nums (x y) "Add X and Y together" (+ x y))

(documentation 'add-nums 'function) ;; => "Add X and Y together"

;; Note that if one provides a docstring but fails to provide a body
;; then the docstring is interpreted by Common Lisp as the body, not
;; the docstring
(defun no-body ())
(no-body) ;; => NIL

(defun mistake () "This is not a docstring")
(mistake) ;; => "This is not a docstring"
(documentation 'mistake 'function) ;; => NIL
```
