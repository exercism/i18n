# Εισαγωγή

Αν θέλεις να φτιάξεις κάτι με ένα Raspberry Pi, πιθανότατα θα χρησιμοποιήσεις _αντιστάτες_.
Όπως και στις προηγούμενες ασκήσεις `Resistor Color Duo` και `Resistor Color Trio`, θα μετατρέπεις τις χρωματικές ζώνες των αντιστατών σε ετικέτες αναγνώσιμες από τον άνθρωπο.

- Κάθε αντιστάτης έχει μια τιμή αντίστασης.
- Οι αντιστάτες είναι μικροί, τόσο μικροί που αν τύπωνες πάνω τους την τιμή αντίστασης, θα ήταν δύσκολο να τη διαβάσεις.
  Για να ξεπεράσουν αυτό το πρόβλημα, οι κατασκευαστές τυπώνουν πάνω στους αντιστάτες χρωματιστές ζώνες που δηλώνουν την τιμή αντίστασής τους.
- Κάθε ζώνη λειτουργεί ως ψηφίο ενός αριθμού.
  Για παράδειγμα, αν τύπωναν μια καφέ ζώνη (τιμή 1) και μετά μια πράσινη ζώνη (τιμή 5), αυτό θα αντιστοιχούσε στον αριθμό 15.
