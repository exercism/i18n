# Δοκιμές

Μπορείς να τρέξεις τις δοκιμές ανοίγοντας μια γραμμή εντολών στον φάκελο της άσκησης και στη συνέχεια τρέχοντας την [εντολή `dotnet test`](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test).
Εναλλακτικά, τα περισσότερα IDE έχουν ενσωματωμένη υποστήριξη για την εκτέλεση δοκιμών, όπως το [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), το [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) και το [Visual Studio Code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Δες τη [σελίδα δοκιμών](https://exercism.org/docs/tracks/csharp/tests) για περισσότερες πληροφορίες.

## Παραλειπόμενες δοκιμές

Στην αρχή, μόνο η πρώτη δοκιμή θα είναι ενεργοποιημένη.
Αυτό γίνεται για να σε ενθαρρύνει να λύσεις την άσκηση ένα βήμα τη φορά.
Μόλις περάσει η πρώτη δοκιμή, αφαίρεσε την ιδιότητα `Skip` από την επόμενη δοκιμή και δούλεψε για να περάσει κι αυτή.
