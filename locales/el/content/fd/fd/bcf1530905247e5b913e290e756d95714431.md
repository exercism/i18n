# Εισαγωγή

Ένας *σωρός* είναι μια συλλογή που ξέρει πάντα το μικρότερο στοιχείο της και σου επιτρέπει να το αφαιρέσεις γρήγορα: είναι η φυσική υλοποίηση μιας *ουράς προτεραιότητας*. Οι σωροί ζουν στο λεξιλόγιο [`heaps`][heaps].

Το `<min-heap>` δημιουργεί έναν άδειο σωρό από τον οποίο βγαίνει πρώτο το μικρότερο κλειδί, ενώ το `<max-heap>` είναι το κατοπτρικό του. Κάθε στοιχείο είναι μια *τιμή* που αποθηκεύεται κάτω από ένα *κλειδί*, και το κλειδί είναι η προτεραιότητα:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Ένας σωρός είναι *μεταβλητός*: το `heap-push` τον αλλάζει επί τόπου. Το `heap-peek` επιστρέφει την τιμή και το κλειδί στην κορυφή χωρίς να τα αφαιρέσει, το `heap-pop` τα αφαιρεί και τα επιστρέφει, και το `heap-pop-all` αδειάζει τον σωρό σε μια λίστα συσχετίσεων με ζεύγη `{ key value }` κατά σειρά προτεραιότητας:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```
