# Εισαγωγή

Στη Go, μια σταθερά είναι μια απλή, αμετάβλητη τιμή που παίρνει ένα όνομα με τη λέξη-κλειδί `const`:

```go
const myWebsite = "Exercism"
```

Τέτοιες σταθερές δεν έχουν τύπο, αλλά τους δίνεται ένας προεπιλεγμένος τύπος με βάση τη σύνταξή τους όταν απαιτείται τύπος, όπως όταν περνούν σε μια μέθοδο.
Σταθερές με τύπο μπορούν να δημιουργηθούν προσθέτοντας ρητά έναν τύπο:

```go
const myWebsite string = "Exercism"
```

Η Go δεν έχει απαριθμήσεις όπως κάποιες άλλες γλώσσες, αλλά διαθέτει ένα προδηλωμένο αναγνωριστικό, το `iota`, για τη δημιουργία απαριθμημένων σταθερών.
Οι σταθερές μέσα σε ένα μπλοκ επαναλαμβάνονται σιωπηρά:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
