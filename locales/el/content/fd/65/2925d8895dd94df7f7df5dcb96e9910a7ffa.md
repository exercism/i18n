# Εισαγωγή

Οι πιο χρήσιμες λέξεις για ακολουθίες παίρνουν ένα *quotation* ως μία από τις εισόδους τους και με αυτό κατευθύνουν τη λειτουργία:

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

Το `map-sum` (επίσης στο `sequences`) αντιστοιχίζει ένα *quotation* σε όλη την ακολουθία και προσθέτει τα αποτελέσματα σε ένα μόνο πέρασμα. Το ίδιο μοτίβο διέπει το `sort-by` (στο [`sorting`][sorting]) και τα `minimum-by` / `maximum-by` (στο `sequences`).

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
