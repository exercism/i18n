# Εισαγωγή

Η Swift έχει ένα σύνολο εντολών που μπορούν να χρησιμοποιηθούν για να αλλάξουν την κανονική ροή ελέγχου των βρόχων.
Αυτές ονομάζονται εντολές μεταφοράς ελέγχου.
Έχεις ήδη δει το `return`. Αυτή η έννοια θα σου παρουσιάσει και άλλες, που περιλαμβάνουν τις `continue`, `break` και τις ετικέτες.
Δε θα καλύψουμε το `fallthrough` σε αυτή την έννοια, αλλά μπορείς να διαβάσεις γι' αυτό στο [βιβλίο της Swift][fallthrough].

## Συνέχεια

Μερικές φορές χρειάζεται να προσπεράσεις νωρίς την υπόλοιπη τρέχουσα επανάληψη ενός βρόχου και να πας στην επόμενη, χωρίς να ολοκληρώσεις τις υπόλοιπες εντολές της.
Γι' αυτό μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `continue`.
Όταν εκτελεστεί το `continue`, ο βρόχος πηγαίνει στον επόμενο έλεγχο για να δει αν μπορεί να τρέξει η επόμενη επανάληψη, δηλαδή στο `while` στους βρόχους while και repeat-while ή στον έλεγχο αν υπάρχει άλλο στοιχείο στην ακολουθία στους βρόχους for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Διακοπή

Το `break` χρησιμοποιείται για να βγεις νωρίς από έναν βρόχο.
Όταν εκτελεστεί το `break`, ο βρόχος τερματίζεται αμέσως και το πρόγραμμα συνεχίζει με την πρώτη εντολή μετά τον βρόχο.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Ετικέτες

Όταν οι βρόχοι είναι εμφωλευμένοι, υπάρχουν φορές που μπορεί να θέλεις να χρησιμοποιήσεις το `break` ή το `continue` για να τερματίσεις ή να ξεκινήσεις από την αρχή τους εξωτερικούς βρόχους που περιέχουν τον βρόχο στον οποίο χρησιμοποιείται το `break` ή το `continue`.
Σε τέτοιες περιπτώσεις, μπορείς να χρησιμοποιήσεις ετικέτες για να προσδιορίσεις τον βρόχο από τον οποίο θα βγεις ή που θα ξεκινήσει από την αρχή.
Ένας βρόχος μπορεί να πάρει ετικέτα βάζοντας ένα όνομα και άνω και κάτω τελεία πριν από το `while`, το `repeat` ή το `for` που ξεκινά τον βρόχο.

Για να δεις το αποτέλεσμα της χρήσης ετικετών με αυτόν τον τρόπο, δες τον παρακάτω βρόχο.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
