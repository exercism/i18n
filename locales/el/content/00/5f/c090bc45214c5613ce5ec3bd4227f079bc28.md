# Οδηγίες

Ενώ εργάζεσαι στην _Instruments of Texas_, σου έχει ανατεθεί να δουλέψεις πάνω σε μια πειραματική αριθμομηχανή Αντίστροφης Πολωνικής Σημειογραφίας [RPN] γραμμένη σε Elixir. Η ομάδα σου αντιμετωπίζει ένα πρόβλημα: κάποιες πράξεις πετούν σφάλματα και κάνουν τη διαδικασία να καταρρεύσει. Σου έχει ανατεθεί να γράψεις μια συνάρτηση που περιτυλίγει τη συνάρτηση πράξης, ώστε τα σφάλματα να μπορούν να αντιμετωπιστούν πιο κομψά με ιδιωματικό κώδικα Elixir.

## 1. Προειδοποίησε την ομάδα

Υλοποίησε τη συνάρτηση `calculate!/2` ώστε να καλεί τη συνάρτηση πράξης με τη στοίβα ως μοναδικό όρισμα. Η συνάρτηση πράξης ορίζεται κάπου αλλού, αλλά ξέρεις ότι μπορεί είτε να ολοκληρωθεί με επιτυχία είτε να πετάξει ένα σφάλμα.

```elixir
stack = []
operation = fn _ -> :ok end
RPNCalculator.calculate!(stack, operation)
# => :ok

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate!(stack, operation)
# => ** (ArgumentError) An error occurred
```

> Τα ονόματα συναρτήσεων που τελειώνουν σε `!` προειδοποιούν τους προγραμματιστές ότι αυτή η συνάρτηση μπορεί να πετάξει ένα σφάλμα

## 2. Περιτύλιξε το σφάλμα

Όταν κάνεις περισσότερη έρευνα, παρατηρείς ότι πολλές συναρτήσεις χρησιμοποιούν άτομα και πλειάδες για να δηλώσουν την επιτυχία ή την αποτυχία τους. Υλοποίησε τη `calculate/2` χρησιμοποιώντας αυτή τη στρατηγική.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate(stack, operation)
# => :error
```

## 3. Μεταβίβασε το μήνυμα

Κάποια από τα σφάλματα περιέχουν σημαντικές πληροφορίες που οι συνάδελφοί σου πρέπει να έχουν για να διασφαλίσουν τη σωστή λειτουργία του συστήματος. Υλοποίησε τη `calculate_verbose/2` για να μεταβιβάσεις το μήνυμα του σφάλματος. Το σφάλμα είναι ένα struct που έχει ένα πεδίο `:message`.

```elixir
stack = []
operation = fn _ -> "operation completed" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:ok, "operation completed"}

stack = []
operation = fn _ -> raise ArgumentError, "An error occurred" end
RPNCalculator.calculate_verbose(stack, operation)
# => {:error, "An error occurred"}
```
