# Οδηγίες

Μετέτρεψε έναν οκταδικό αριθμό, που παριστάνεται ως συμβολοσειρά (π.χ. '1735263'), στο δεκαδικό του ισοδύναμο χρησιμοποιώντας βασικές αρχές (δηλαδή όχι, δεν επιτρέπεται να χρησιμοποιήσεις ενσωματωμένες ή εξωτερικές βιβλιοθήκες για να κάνεις τη μετατροπή).

Υλοποίησε τη μετατροπή από οκταδικό σε δεκαδικό.
Δεδομένης μιας οκταδικής συμβολοσειράς εισόδου, το πρόγραμμά σου πρέπει να παράγει μια δεκαδική έξοδο.

## Σημείωση

- Υλοποίησε τη μετατροπή μόνος σου.
  Μη χρησιμοποιήσεις κάτι άλλο για να κάνει τη μετατροπή για σένα.
- Χειρίσου τις μη έγκυρες εισόδους ως οκταδικό 0.

## Σχετικά με το οκταδικό σύστημα (βάση 8)

Το δεκαδικό είναι ένα σύστημα βάσης 10.

Ένας αριθμός 233 στο δεκαδικό σύστημα μπορεί να γίνει κατανοητός
ως ένας γραμμικός συνδυασμός δυνάμεων του 10:

- Το δεξιότερο ψηφίο πολλαπλασιάζεται με 10^0 = 1
- Το επόμενο ψηφίο πολλαπλασιάζεται με 10^1 = 10
- ...
- Το n-οστό ψηφίο πολλαπλασιάζεται με 10^_(n-1)_.
- Όλες αυτές οι τιμές αθροίζονται.

Άρα:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

Το οκταδικό είναι παρόμοιο, αλλά χρησιμοποιεί δυνάμεις του 8 αντί για δυνάμεις του 10.

Άρα:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
