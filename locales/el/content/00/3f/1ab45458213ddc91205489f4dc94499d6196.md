# Εισαγωγή

Μια `Tuple` μοιάζει αρκετά με ένα `Vector` (μονοδιάστατο `array`) από πολλές απόψεις.
Ωστόσο, υπάρχουν μερικές σημαντικές διαφορές.

- Οι πλειάδες γράφονται σε παρενθέσεις `( )` και όχι σε αγκύλες `[ ]`, αν και οι παρενθέσεις μπορούν να παραλειφθούν σε περιπτώσεις όπου το νόημα είναι σαφές.
- Οι πλειάδες δεν χρειάζεται να είναι ομοιογενείς: ο τύπος κάθε στοιχείου αποθηκεύεται ανεξάρτητα.
- Οι πλειάδες είναι αμετάβλητες.

Η αμεταβλητότητα επιτρέπει περισσότερες βελτιστοποιήσεις από τον μεταγλωττιστή και κάνει τις πλειάδες πιο αποδοτικές από τα διανύσματα, οπότε καλό είναι να τις προτιμάς σε περιπτώσεις όπου η μεταβλητότητα δεν είναι απαραίτητη.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Υπάρχει επίσης ο κατασκευαστής `Tuple()`, ο οποίος μετατρέπει οποιαδήποτε επαναλήψιμη συλλογή σε πλειάδα.
Χρήσιμα, αντιμετωπίζει μια συμβολοσειρά ως επαναλήψιμη συλλογή χαρακτήρων.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Για κάθε πλειάδα, μπορείς να προσπελάσεις τα στοιχεία με βάση τη θέση τους ή να τα διατρέξεις με έναν βρόχο.

Κάθε καθαρά αριθμητική πλειάδα μπορεί επίσης να χρησιμοποιηθεί σε μαθηματικές συναρτήσεις όπως η `sum()`, ακριβώς όπως οι πίνακες.

## Αποσυσκευασία

Μπορείς να αποσυσκευάσεις μια πλειάδα σε μεμονωμένα στοιχεία χρησιμοποιώντας πολλαπλή ανάθεση.
Για στοιχεία που δεν χρειάζεσαι, χρησιμοποίησε την κάτω παύλα `_` ως ψευδομεταβλητή.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Οι προγραμματιστές Python θα είναι πολύ εξοικειωμένοι με αυτή τη σύνταξη πολλαπλής ανάθεσης.

## Πλειάδες με ονόματα

Μια `Tuple` περιέχει μόνο τιμές.
Μια `NamedTuple` συνδυάζει κάθε τιμή με ένα όνομα.

Στη συνέχεια, μπορείς να προσπελάσεις τα μεμονωμένα πεδία με τον συμβολισμό "dot":

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Το όνομα αποθηκεύεται εσωτερικά ως `Symbol` (ένας αμετάβλητος τύπος, και το όνομα έχει πρόθεμα άνω και κάτω τελεία `:`), οπότε υπάρχει και εναλλακτική σύνταξη:

```julia-repl
julia> nt[:b]
7.3
```

Είναι εύκολο να πάρεις ξεχωριστά είτε τα ονόματα (που ονομάζονται και "κλειδιά") είτε τις τιμές:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Σημείωσε ότι η επανάληψη πάνω σε μια πλειάδα με ονόματα παράγει μόνο τις _τιμές_, ενώ τα _ονόματα_ αγνοούνται.

Οι πλειάδες (με ή χωρίς ονόματα) είναι ένας πολύ συνηθισμένος τρόπος για να μεταφέρεις δομημένα δεδομένα προς και από συναρτήσεις.
Η αμεταβλητότητα είναι καλή σε αυτή την περίπτωση χρήσης, καθώς παρέχει ασφάλεια δεδομένων και επιτρέπει πιο επιθετικές βελτιστοποιήσεις του μεταγλωττιστή.
