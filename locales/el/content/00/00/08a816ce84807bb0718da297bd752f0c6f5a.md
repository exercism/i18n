# Εισαγωγή

Μια *κανονική έκφραση* (regex) είναι ένα μικρό μοτίβο που περιγράφει πώς
πρέπει να μοιάζει κάποιο κείμενο. Τα εργαλεία regex της Factor βρίσκονται
στο λεξιλόγιο [`regexp`][regexp], και ένα μοτίβο γράφεται ανάμεσα σε `R/ `
και `/`.

Οι περισσότεροι χαρακτήρες σε ένα μοτίβο σημαίνουν τον εαυτό τους. Λίγα
ειδικά κομμάτια παριστάνουν *είδη* χαρακτήρων ή *πόσους* να περιμένεις:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Έτσι, το `R/ [A-Z]{2}-\d{4}/` σημαίνει "δύο κεφαλαία, μια παύλα, τέσσερα ψηφία".

Το `matches?` ελέγχει αν μια *ολόκληρη* συμβολοσειρά ταιριάζει με το μοτίβο:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Άλλες λέξεις κοιτάζουν *μέσα* σε μια συμβολοσειρά: το `all-matching-subseqs`
επιστρέφει κάθε αντιστοίχιση, το `count-matches` τις μετράει, το
`re-contains?` αναφέρει αν υπάρχει κάποια αντιστοίχιση, και το `re-replace`
αντικαθιστά κάθε αντιστοίχιση με νέο κείμενο:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```
