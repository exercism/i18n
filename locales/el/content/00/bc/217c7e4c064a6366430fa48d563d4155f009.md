# Εισαγωγή

Ένας συνηθισμένος τρόπος για να εκτελείς κώδικα υπό συνθήκη στη JavaScript είναι η εντολή `if`.
Αποτελείται από τη λέξη-κλειδί `if`, μια συνθήκη μέσα σε παρενθέσεις και ένα μπλοκ κώδικα μέσα σε άγκιστρα.
Το μπλοκ κώδικα θα εκτελεστεί μόνο αν η συνθήκη αξιολογείται σε `true`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

Μπορεί να χρησιμοποιηθεί μόνη της ή σε συνδυασμό με τη λέξη-κλειδί `else`.

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

Για να εμφωλεύσεις άλλη μια συνθήκη στην εντολή `else`, μπορείς να χρησιμοποιήσεις το `else if`.

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
