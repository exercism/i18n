# Σχετικά

Στην Elixir, οι συναρτήσεις μπορούν να κληθούν δυναμικά.

Όλα τα ονόματα των αρθρωμάτων είναι άτομα. Όλα τα ονόματα των αρθρωμάτων της Elixir παίρνουν αυτόματα το πρόθεμα `Elixir.` όταν μεταγλωττίζονται.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Η Elixir μπορεί να προσδιορίσει μια συνάρτηση που θα κληθεί σε χρόνο εκτέλεσης, χρησιμοποιώντας το όνομα του αρθρώματος για αναζήτηση. Η αναζήτηση μπορεί να γίνει δυναμικά αν το όνομα του αρθρώματος είναι δεσμευμένο σε μια μεταβλητή.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
