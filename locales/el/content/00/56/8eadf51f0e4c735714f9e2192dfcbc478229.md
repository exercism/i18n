# Εισαγωγή

Μερικές φορές χρειάζεται να δεις μια ακολουθία ως μια σειρά από *κομμάτια* αντί για στοιχείο προς στοιχείο. Τα λεξιλόγια [`grouping`][grouping], [`splitting`][splitting] και [`splitting.monotonic`][splitting.monotonic] σου δίνουν τέσσερις τρόπους να το κάνεις.

## `group`: ασύνδετα κομμάτια μεγέθους *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Αν το μήκος της ακολουθίας δεν είναι πολλαπλάσιο του *n*, το τελευταίο κομμάτι είναι μικρότερο από *n*.

## `clump`: επικαλυπτόμενο συρόμενο παράθυρο μεγέθους *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Αν η ακολουθία είναι μικρότερη από *n*, το αποτέλεσμα είναι κενό.

## `split-when`: σπάσιμο όπου ένα κατηγόρημα είναι αληθές

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Κάθε στοιχείο έχει τη δική του κλήση κατηγορήματος· τα στοιχεία για τα οποία το κατηγόρημα είναι αληθές είναι τα *σημεία σπασίματος* και δε διατηρούνται στο αποτέλεσμα.

## `monotonic-split`: σπάσιμο σειρών όπου αποτυγχάνει ένας έλεγχος γειτονικών ζευγών

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

Το κατηγόρημα εκτελείται σε *γειτονικά ζεύγη*. Όσο επιστρέφει αληθές, η σειρά συνεχίζεται· όταν επιστρέφει `f`, ξεκινά ένα νέο κομμάτι. Με `[ = ]` παίρνεις σειρές ίσων στοιχείων· με `[ <= ]` παίρνεις μη φθίνουσες σειρές· και ούτω καθεξής.

## Πότε να χρησιμοποιήσεις το καθένα

- **`group`/`clump`**: ξέρεις το *μέγεθος* που θέλεις.
- **`split-when`**: ξέρεις πώς μοιάζει ένα *στοιχείο σπασίματος*.
- **`monotonic-split`**: ξέρεις τι κάνει δύο γειτονικά στοιχεία να *ανήκουν ακόμη μαζί*.
