# Τα βασικά

Ένα πρόγραμμα Sather αποτελείται από **κλάσεις**. Μια κλάση είναι ένα κουτί με όνομα που περιέχει ρουτίνες. Μια **ρουτίνα** είναι ένα κομμάτι εργασίας με όνομα που παράγει μια απάντηση.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Διαβάζοντας το από την αρχή:

- `class GREETER is` ανοίγει το κουτί και του δίνει όνομα. Τα ονόματα των κλάσεων γράφονται με κεφαλαία.
- `hello : STR is` ξεκινά μια ρουτίνα με όνομα `hello` που παράγει ένα `STR`, ένα κομμάτι κειμένου, που ονομάζεται *συμβολοσειρά*. Το `: STR` είναι μια υπόσχεση για το τι είδους απάντηση επιστρέφεται.
- `return "Hello!";` επιστρέφει την απάντηση. Το κείμενο γράφεται ανάμεσα σε διπλά εισαγωγικά.
- `end;` κλείνει τη ρουτίνα, και το δεύτερο `end;` κλείνει την κλάση.

Ό,τι βρίσκεται μετά το `--` σε μια γραμμή είναι ένα **σχόλιο**. Ο Sather το αγνοεί· υπάρχει για τους ανθρώπους.

```sather
-- This line is for the reader, not the computer.
```

Για να χρησιμοποιήσεις μια ρουτίνα από κάπου αλλού, γράψε το όνομα της κλάσης, δύο άνω και κάτω τελείες, και το όνομα της ρουτίνας:

```sather
GREETER::hello        -- this is "Hello!"
```

Μέσα στην ίδια κλάση μπορείς να παραλείψεις το όνομα της κλάσης:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Μια ρουτίνα που δεν παίρνει ορίσματα καλείται χωρίς παρενθέσεις: `hello`, όχι `hello()`.
