# Οδηγίες

Κάθε ζώνη ασφαλείας στο τσίρκο είναι πιστοποιημένη για φορτίο σε κιλά, και κανείς δεν
ανεβαίνει αν δεν ελεγχθούν πρώτα τα νούμερα.

Η κλάση `SAFETY_HARNESS` χρειάζεται τα παρακάτω. Ο σκελετός σου δίνει την κλάση και το
χαρακτηριστικό της· πρόσθεσε τα υπόλοιπα. Κάθε ρουτίνα παρακάτω φέρει ένα συμβόλαιο, και οι
υποδείξεις λένε ποιο.

## 1. Στήσε μια ζώνη ασφαλείας

Η `create` παίρνει το φορτίο για το οποίο είναι πιστοποιημένη η ζώνη ασφαλείας και
επιστρέφει μια ζώνη ασφαλείας. Ένα όριο μηδέν ή λιγότερο δεν είναι καθόλου ζώνη
ασφαλείας, οπότε αυτό είναι ένα `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. Πόσο περισσεύει;

Η `spare_capacity` παίρνει το φορτίο πάνω στη ζώνη ασφαλείας και επιστρέφει πόσο ακόμη θα
μπορούσε να σηκώσει. Το φορτίο δεν μπορεί να είναι αρνητικό και δεν μπορεί να ξεπερνά το
όριο: και τα δύο είναι `pre`. Η απάντηση δεν είναι ποτέ αρνητική, και αυτό είναι ένα `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. Πόσο γεμάτη είναι;

Η `percent_used` παίρνει το φορτίο και το επιστρέφει ως ποσοστό του ορίου, στρογγυλοποιημένο
προς τα κάτω. Το φορτίο δεν μπορεί να είναι αρνητικό, και η απάντηση δεν είναι ποτέ
αρνητική.

```sather
harness.percent_used(60)
-- => 50
```

## 4. Είναι ασφαλής;

Η `is_safe` παίρνει το φορτίο και απαντά αν το φορτίο είναι εντός του ορίου. Μπορείς να
ρωτήσεις για οποιοδήποτε φορτίο, ακόμη και για ένα παράλογο, οπότε δεν υπάρχει `pre` για το
φορτίο. Γράψε όμως ένα `post` που να λέει ότι η απάντηση είναι αληθής ακριβώς όταν το
φορτίο είναι εντός του ορίου.

```sather
harness.is_safe(200)
-- => false
```
