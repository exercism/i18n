# Συμβουλές

Ο κώδικάς σου θα πρέπει να περιέχει μια συνάρτηση frequency :: Int -> [Text] -> Map Char Int, η οποία παίρνει έναν αριθμό εργαζομένων που θα χρησιμοποιηθούν παράλληλα, καθώς και μια λίστα με κείμενα, και επιστρέφει τη συνολική συχνότητα κάθε γράμματος στο κείμενο.

## Συγκριτική αξιολόγηση

Έλεγξε πώς η αλλαγή του αριθμού των εργαζομένων επηρεάζει την απόδοση της λύσης σου, τρέχοντας τη συγκριτική αξιολόγηση. Χρησιμοποίησε το `stack bench` για να την τρέξεις. Μη διστάσεις να τροποποιήσεις το `bench/Benchmark.hs` για να εξερευνήσεις την απόδοση της λύσης σου σε διαφορετικά δεδομένα εισόδου.
