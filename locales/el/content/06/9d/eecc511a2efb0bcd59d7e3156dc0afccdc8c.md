# Προσθήκη στις οδηγίες

## Υποδείξεις

Χρειάζεται να υλοποιήσεις τη συνάρτηση `diamond` που τυπώνει έναν ρόμβο ο οποίος
ξεκινά από το `A` και έχει τον δεδομένο χαρακτήρα στα πλατύτερα σημεία του. Μπορείς
να χρησιμοποιήσεις την υπογραφή που δίνεται αν δεν είσαι σίγουρος για τους τύπους,
αλλά μην την αφήσεις να περιορίσει τη δημιουργικότητά σου:

```haskell
diamond :: Char -> Maybe [String]
```

Αυτή η άσκηση δουλεύει με κειμενικά δεδομένα. Για ιστορικούς λόγους, ο τύπος
`String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων. Για πιο
αποδοτικό χειρισμό κειμενικών δεδομένων, μπορεί να χρησιμοποιηθεί ο τύπος `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να

- Διαβάσεις για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types)
  στη Haskell.
- Προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- Κάνεις εισαγωγή του `Data.Text` με [τον ακόλουθο
  τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- Μπορείς τώρα να γράψεις π.χ. `diamond :: Char -> Maybe [Text]` και να αναφέρεσαι
  στους συνδυαστές του `Data.Text` ως π.χ. `T.pack`,
- Αναζητήσεις την τεκμηρίωση για το
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Μπορείς έπειτα να αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο
  Diamond.hs:

```haskell
diamond :: Char -> Maybe [Text]
```

Αυτό το μέρος είναι εντελώς προαιρετικό.
