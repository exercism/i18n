# Εισαγωγή

Η PHP παρέχει μια σειρά από τελεστές για την εκτέλεση αριθμητικών πράξεων. Η PHP ακολουθεί την καθιερωμένη μαθηματική σειρά πράξεων για τους αριθμητικούς τελεστές της. Οι τελεστές που παρέχει η PHP είναι:

* Ταυτότητα (+)
* Άρνηση (-)
* Πρόσθεση (+)
* Αφαίρεση (-)
* Πολλαπλασιασμός (*)
* Διαίρεση (/)
* Υπόλοιπο (%)
* Ύψωση σε δύναμη (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
