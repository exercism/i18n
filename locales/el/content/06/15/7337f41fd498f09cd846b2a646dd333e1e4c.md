# Εισαγωγή

Οι βρόχοι repeat-while είναι παρόμοιοι με τους βρόχους `while`, ωστόσο διαφέρουν στο ότι η έκφραση Boolean (λογική τιμή) εμφανίζεται και αξιολογείται _μετά_ την εκτέλεση του σώματος του βρόχου. Ως αποτέλεσμα, αυτοί οι βρόχοι εκτελούνται πάντα τουλάχιστον μία φορά.

```swift
repeat {
  print("This runs at least once")
} while false
print("Loop done")

// prints:
// This runs at least once
// Loop done
```
