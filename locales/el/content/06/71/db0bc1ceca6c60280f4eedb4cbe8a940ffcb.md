# Σχετικά

Τα δυαδικά ψηφία αντιστοιχούν τελικά άμεσα στα τρανζίστορ του επεξεργαστή ή της μνήμης RAM σου, και στο αν το καθένα είναι "αναμμένο" ή "σβηστό".

Ο χειρισμός χαμηλού επιπέδου, που ανεπίσημα ονομάζεται "bit-twiddling", είναι ιδιαίτερα σημαντικός στις γλώσσες συστημάτων.

Οι γλώσσες υψηλού επιπέδου, όπως η Julia, συνήθως κρύβουν τις περισσότερες από αυτές τις λεπτομέρειες. Ωστόσο, ένα πλήρες φάσμα πράξεων σε επίπεδο bit είναι [διαθέσιμο][bitwise] στη βασική γλώσσα.

***Σημείωση:*** Για να δεις δυαδική έξοδο που διαβάζεται από άνθρωπο στο REPL, σχεδόν όλα τα παρακάτω παραδείγματα πρέπει να τυλιχτούν σε μια συνάρτηση [`bitstring()`][bitstring]. Αυτό αποσπά την προσοχή οπτικά, οπότε οι περισσότερες εμφανίσεις αυτής της συνάρτησης έχουν αφαιρεθεί.

## Πράξεις ολίσθησης bit

Οι ακέραιοι τύποι, προσημασμένοι ή απρόσημοι, μπορούν να αναπαρασταθούν ως μια συμβολοσειρά από μηδενικά και άσσους.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Οι ολισθήσεις bit απλώς μετακινούν τα πάντα αριστερά ή δεξιά κατά έναν καθορισμένο αριθμό θέσεων. Με τους τύπους `UInt`, μερικά bit πέφτουν από το ένα άκρο και το άλλο άκρο γεμίζει με μηδενικά:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Κάθε ολίσθηση αριστερά διπλασιάζει την τιμή και κάθε ολίσθηση δεξιά τη μειώνει στο μισό (με περικοπή, όπου ισχύει). Αυτό φαίνεται πιο καθαρά στη δεκαδική αναπαράσταση:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Αυτού του είδους η ολίσθηση bit είναι πολύ ταχύτερη από την "κανονική" αριθμητική, γεγονός που κάνει την τεχνική πολύ δημοφιλή στον προγραμματισμό χαμηλού επιπέδου.

Με τους προσημασμένους ακέραιους, πρέπει να είμαστε λίγο πιο προσεκτικοί.

Οι ολισθήσεις αριστερά είναι σχετικά απλές:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Η ολίσθηση αριστερά θετικών προσημασμένων ακεραίων είναι επομένως ίδια με αυτή των απρόσημων ακεραίων.

Οι αρνητικές τιμές αποθηκεύονται σε μορφή [συμπληρώματος ως προς δύο][2complement], που σημαίνει ότι το αριστερότερο bit είναι 1. Κανένα πρόβλημα για μια ολίσθηση αριστερά, αλλά όταν ολισθαίνουμε δεξιά, πώς γεμίζουμε τα αριστερότερα bit;

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

Ο τελεστής `>>` εκτελεί [αριθμητική ολίσθηση][arithmetic], διατηρώντας το bit προσήμου.

Ο τελεστής `>>>` εκτελεί [λογική ολίσθηση][logical], γεμίζοντας με μηδενικά σαν ο αριθμός να ήταν απρόσημος.

Αν αυτό σου φαίνεται ακόμα ελλιπές, υπάρχει και μια συνάρτηση [`bitrotate()`][bitrotate].

## Λογικές πράξεις bit

Είδαμε σε μια προηγούμενη έννοια ότι οι τελεστές `&&` (and), `||` (or) και `!` (not) χρησιμοποιούνται με τιμές Boolean (λογική τιμή).

Υπάρχουν αντίστοιχοι τελεστές `&` (bitwise and), `|` (bitwise or) και `~` (μια περισπωμένη, bitwise not) για να συγκρίνεις τα bit δύο ακεραίων.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Εδώ, το `xor()` είναι το [αποκλειστικό ή][xor], χρησιμοποιημένο ως συνάρτηση (δείτε παρακάτω για εναλλακτικό συμβολισμό).

Παρεμπιπτόντως, οι τελεστές `&` και `|` μπορούν να χρησιμοποιηθούν και με τιμές Boolean. Σε αντίθεση με τα `&&` και `||`, τότε αξιολογούνται όλα τα μέρη της έκφρασης: δεν υπάρχει βραχυκύκλωμα.


## Άλλα σύμβολα

Η Julia λατρεύει τα μαθηματικά, και οι μαθηματικοί λατρεύουν τα αινιγματικά σύμβολα, γι' αυτό έχουμε κι άλλα σύμβολα για να παίξουμε.

```julia-repl
julia> 0b1011 ⊻ 0b0010 # xor() in infix notation
"00001001"

julia> 0b1011 ⊼ 0b0010 # not and
"11111101"

julia> 0b1011 ⊽ 0b0010 # not or
"11110100"
```

Σε επεξεργαστές που γνωρίζουν τη Julia, τα εισάγεις γράφοντας `\xor`, `\nand` και `\nor` συν ένα tab σε κάθε περίπτωση.

Αυτά τα σύμβολα δεν είναι και πολύ γνωστά, ακόμα και σε ανθρώπους που έχουν σπουδάσει μαθηματικά στο πανεπιστήμιο (ο συγγραφέας αυτής της έννοιας δεν τα είχε ξαναδεί ποτέ). Αν θέλεις να τα χρησιμοποιήσεις, πρόσεξε ποιον θα ζητήσεις να ελέγξει τον κώδικά σου!
