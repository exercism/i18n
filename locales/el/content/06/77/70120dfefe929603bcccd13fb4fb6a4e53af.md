# Εισαγωγή

Οι κανονικές εκφράσεις είναι ένας εξαιρετικά ευέλικτος τρόπος για _αντιστοίχιση προτύπων_ σε συμβολοσειρές, χρησιμοποιώντας μια Γλώσσα Ειδικού Σκοπού (DSL) σχεδιασμένη γι' αυτόν τον σκοπό.

Πολλές δυνατότητες των κανονικών εκφράσεων είναι ενσωματωμένες στη Base R, και μπορεί να δεις παραδείγματα σε παλαιότερο κώδικα.

Για νέο κώδικα, συνιστάται _ανεπιφύλακτα_ η χρήση της βιβλιοθήκης [`stringr`][web-stringr].

Όπως σημειώνεται στην [Έννοια Συμβολοσειρών][concept-strings], το `stringr` έχει καλή τεκμηρίωση, συνήθως γραμμένη από τον δημιουργό ή τους δημιουργούς του πακέτου.

- Έναν [ιστότοπο αναφοράς][web-stringr]
- Ένα [φύλλο συμβουλών][cheat-stringr].
- Ένα [κεφάλαιο για τις συμβολοσειρές][book-strings] και ένα [κεφάλαιο για τις κανονικές εκφράσεις][book-regex] στο "R for Data Science".

Πολλές από τις συναρτήσεις που έχουν ήδη συζητηθεί στην Έννοια [`Strings`][concept-strings] είναι σχεδιασμένες, κατά κανόνα, για αναζητήσεις με κανονικές εκφράσεις.

Κρατήσαμε την Έννοια Συμβολοσειρών σχετικά απλή, κάνοντας αντιστοίχιση μόνο σε κυριολεκτικές συμβολοσειρές, αλλά στη θέση τους μπορεί να χρησιμοποιηθεί οποιοδήποτε πρότυπο κανονικής έκφρασης.

Τυπικά, μια κανονική έκφραση δημιουργείται στη R καλώντας τη [`regex()`][ref-regex].
Για ευκολία, οι συναρτήσεις του `stringr` αντιμετωπίζουν κάθε συμβολοσειρά προτύπου ως κανονική έκφραση.
Στο παρακάτω παράδειγμα, η πρώτη `str_replace_all()` είναι συντακτική διευκόλυνση για τη δεύτερη εκδοχή:

```R
input <- "Some input string"

# "\\s" matches any whitespace character
input |> str_replace_all("\\s", "_")
[1] "Some_input_string"

input |> str_replace_all(regex("\\s"), "_")
[1] "Some_input_string"
```

Το [φύλλο συμβουλών][cheat-stringr] είναι ένας χρήσιμος οδηγός: όλες οι συναρτήσεις με όρισμα `pattern` (τυπωμένες με κόκκινο) δέχονται κανονική έκφραση, και η σελίδα 2 συνοψίζει τη σύνταξη των κανονικών εκφράσεων.

Σημείωσε ότι η συνάρτηση [`regex()`][ref-regex] μπορεί να είναι ακόμα σημαντική αν χρειαστεί να παρακάμψεις τις προεπιλογές, όπως τη διάκριση πεζών-κεφαλαίων ή τις τοπικές ρυθμίσεις.

```R
# default is case sensitive
"A Mixed Assortment" |> 
    str_replace_all(regex("[aeiou]", ignore_case = TRUE), "*")
#> [1] "* M*x*d *ss*rtm*nt"
```

Πολλοί κωδικοί κανονικών εκφράσεων περιλαμβάνουν ανάποδη κάθετο, όπως το `\s` που χρησιμοποιήθηκε παραπάνω.
Στις συνηθισμένες συμβολοσειρές της R, το `\` πρέπει να διαφύγει με διπλασιασμό, γι' αυτό γράφουμε `"\\s"`.

Οι ανάποδες κάθετοι μπορεί να πληθύνουν και να γίνουν μπερδεμένες, οπότε μπορεί να βοηθήσει η χρήση [ακατέργαστων συμβολοσειρών][book-raw] σε σύνθετες περιπτώσεις.

Από προεπιλογή, η σύνταξη για τον ορισμό μιας ακατέργαστης συμβολοσειράς είναι `r"( )"`, αλλά επιτρέπονται και άλλα διαχωριστικά.
Επειδή οι παρενθέσεις `( )` και οι αγκύλες `[ ]` είναι και οι δύο συνηθισμένες στη σύνταξη των κανονικών εκφράσεων (για ομάδες σύλληψης και ομάδες επιλογών), τα άγκιστρα `{ }` μπορεί να είναι καλή επιλογή.

```R
input |> str_replace_all(r"{\s\w}", "__")
#> [1] "Some__nput__tring"
```

## Εντοπισμός αντιστοιχιών

Ακολουθούν μερικές ερωτήσεις και συναρτήσεις που μπορούν να βοηθήσουν να τις απαντήσεις.

Μερικά παραδείγματα χρησιμοποιούν το `fruit`, ένα διάνυσμα με 80 ονόματα φρούτων που περιλαμβάνεται στο `stringr` για εξάσκηση.

_Περιέχει μια συμβολοσειρά κάποια αντιστοιχία;_
Η `str_detect()`, ή οι `str_starts()`, `str_ends()` για να αποφύγεις τη χρήση των αγκυρών `^` ή `$`.

```R
# berries begining with b
fruit |> str_detect("^b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE

# alternative syntax
fruit |> str_starts("b.*berry") |> head(15)
#> [1] FALSE FALSE FALSE FALSE FALSE  TRUE  TRUE FALSE FALSE  TRUE  TRUE FALSE FALSE FALSE FALSE
```

_Να επιστρέψεις μόνο τις συμβολοσειρές που περιέχουν αντιστοιχία;_
Χρησιμοποίησε τη `str_subset()` για να πάρεις τις συμβολοσειρές, τη `str_which()` για να πάρεις τις θέσεις.

```R
fruit |> str_subset("a...e")
[1] "apple"       "blackberry"  "mandarine"   "nectarine"   "pineapple"   "pomegranate" "raspberry"   "salal berry"
> fruit |> str_which("a...e")
[1]  1  7 48 51 62 64 70 73
```

_Πόσες αντιστοιχίες υπάρχουν σε κάθε συμβολοσειρά;_
Χρησιμοποίησε τη `str_count()`.

```R
# count vowels
fruit |> str_count("[aeiou]") |> head(10)
#> [1] 2 3 4 3 3 2 2 3 5 3
```

_Πού βρίσκεται η αντιστοιχία;_
Η `str_view()` για διαδραστική χρήση, η `str_locate()` ή η `str_locate_all()` γενικότερα.

```R
# str_view only shows matching elements, with match in < > delimiters
fruit |> str_view("a...e")
 [1] │ <apple>
 [7] │ bl<ackbe>rry
[48] │ mand<arine>
[51] │ nect<arine>
[62] │ pine<apple>
[64] │ pomegr<anate>
[70] │ r<aspbe>rry
[73] │ sal<al be>rry

# str_locate returns all elements
fruit |> str_locate("a...e") |> head(10)
      start end
 [1,]     1   5
 [2,]    NA  NA
 [3,]    NA  NA
 [4,]    NA  NA
 [5,]    NA  NA
 [6,]    NA  NA
 [7,]     3   7
 [8,]    NA  NA
 [9,]    NA  NA
[10,]    NA  NA
```

## Συλλήψεις

Συχνά, θέλουμε να μάθουμε _τι_ αντιστοιχεί.
Αυτό επιτυγχάνεται συμπεριλαμβάνοντας ομάδες σύλληψης σε παρενθέσεις μέσα στην κανονική έκφραση.

Είναι δυνατό να αναφερθείς ξανά σε συλλήψεις μέσα στην ίδια κανονική έκφραση, χρησιμοποιώντας `\1`, `\2`, κ.λπ.
Για παράδειγμα, βρίσκοντας επαναλαμβανόμενα ζεύγη γραμμάτων:

```R
fruit |> str_subset("(..)\\1")
[1] "banana"      "coconut"     "cucumber"    "jujube"      "papaya"      "salal berry"
```

Με παρόμοια σύνταξη, οι συλλήψεις μπορούν να χρησιμοποιηθούν σε συμβολοσειρές αντικατάστασης:

```R
# double to triple
fruit |> 
  str_subset("(..)\\1") |> 
  str_replace("(..)\\1", "\\1\\1\\1")
[1] "bananana"      "cococonut"     "cucucumber"    "jujujube"      "papapaya"      "salalal berry"
```

Συγκέντρωσε τις αντιστοιχίες για μεταγενέστερη επεξεργασία χρησιμοποιώντας τη συνάρτηση `str_match()` για την πρώτη μόνο αντιστοιχία, ή τη `str_match_all()` για όλες τις αντιστοιχίες.

Οι ομάδες σύλληψης έχουν την τάση να παράγουν περίπλοκη έξοδο σε οποιαδήποτε γλώσσα.
Η προσέγγιση της R (_η οποία είναι επίσης διανυσματοποιημένη ως πρόσθετη πρόκληση_) είναι να δημιουργήσει μια μήτρα από τη `str_match()`, με μία γραμμή ανά συμβολοσειρά εισόδου, τη στήλη 1 να περιέχει ολόκληρη τη συμβολοσειρά που ταιριάζει, και τις υπόλοιπες στήλες να περιέχουν τις διάφορες ομάδες σύλληψης.

Η χρήση ονομαστικών ομάδων μπορεί να είναι πλεονέκτημα, καθώς γίνονται ονόματα στηλών στη μήτρα αποτελεσμάτων.

```R
recipe <- "dissolve 25g sugar in 200ml water"
recipe |> str_match("(\\d+g) .* (\\d+ml)")
     [,1]                 [,2]  [,3]   
[1,] "25g sugar in 200ml" "25g" "200ml"

# use named capture groups
recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")
                          wt    vol    
[1,] "25g sugar in 200ml" "25g" "200ml"
```

~~~~exercism/note
Δεν έχουμε πει πολλά για τις μήτρες σε αυτή την ύλη, αν και υπάρχει ένα [έγγραφο έννοιας][concept-matrices-arrays] στο οποίο μπορείς να έχεις πρόσβαση.
Οι μήτρες δεν ταιριάζουν καλά με το οικοσύστημα του Tidyverse, παρόλο που αποτελούν μέρος της Base R εδώ και πολύ καιρό.

Σε σύντομη σύνοψη: αντιμετώπισε τις μήτρες σαν διανύσματα με 2 θέσεις, με τη σειρά `[rows, cols]`.
Άφησε κενή οποιαδήποτε από τις δύο θέσεις για να πάρεις ολόκληρη τη γραμμή/στήλη.

Όταν παίρνεις μία μόνο γραμμή `r` με `m[r,]` ή μία μόνο στήλη `c` με `m[,c]`, η τιμή που επιστρέφεται ισοπεδώνεται σε διάνυσμα από προεπιλογή.

```R
> amounts <- recipe |> str_match("(?<wt>\\d+g) .* (?<vol>\\d+ml)")

# get all of row 1, as a named vector
> amt1 <- amounts[1,]
> amt1
                                       wt                  vol 
"25g sugar in 200ml"                "25g"              "200ml" 

# get a vector element
amt1["wt"] |> unname()
[1] "25g"
```
~~~~

Αναπόφευκτα, η `str_match_all()` παράγει έξοδο με ακόμα περισσότερη δομή:

- Το αποτέλεσμα είναι μια λίστα, με ένα στοιχείο ανά συμβολοσειρά εισόδου.
- Αν υπάρχει μόνο μία συμβολοσειρά εισόδου, κάνε unlist στην έξοδο χρησιμοποιώντας `[[1]]`, όπως περιγράφεται στην Έννοια [Λίστες][concept-lists].
- Κάθε στοιχείο είναι μια μήτρα, με στήλες όπως στη `match()`.
- Κάθε γραμμή στη μήτρα είναι μια επιτυχής σύλληψη.

```R
mix <- "Mix 200g of sugar, 180g of flour and 150g of butter"

# raw output
> str_match_all(mix, "(\\d+)g")
[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# we just want the first list element
> str_match_all(mix, "(\\d+)g")[[1]]
     [,1]   [,2] 
[1,] "200g" "200"
[2,] "180g" "180"
[3,] "150g" "150"

# captures are in column 2, so get that as a vector
> str_match_all(mix, "(\\d+)g")[[1]][,2]
[1] "200" "180" "150"
```

Φυσικά, οι αντιστοιχίες μπορούν να αποτύχουν.
Το αποτέλεσμα τότε θα είναι η ειδική τιμή `NA`.
Να είσαι έτοιμος να το ελέγξεις, όπως περιγράφεται στην Έννοια [Τίποτα][concept-nothingness].

```R
# failed match
recipe |> str_match("(not here)")
     [,1] [,2]
[1,] NA   NA  
```
