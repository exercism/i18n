# Εισαγωγή

Οι τύποι που υλοποιούν τη διεπαφή `IEnumerable<T>` είναι γνωστοί ως _απαριθμήσιμοι_. Όλοι οι ενσωματωμένοι τύποι συλλογών υλοποιούν αυτή τη διεπαφή.

Μπορούμε να διατρέξουμε έναν απαριθμήσιμο τύπο με έναν βρόχο `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Για να υλοποιήσει το `IEnumerable<T>`, ένας τύπος πρέπει να υλοποιήσει μία μέθοδο: `IEnumerator<T> GetEnumerator()`. Όπως είδαμε, ένας απαριθμήσιμος τύπος αναθέτει την πραγματική επανάληψη πάνω σε μια συλλογή σε έναν τύπο `IEnumerator<T>`. Αυτή η διεπαφή έχει μία ιδιότητα και τρεις μεθόδους προς υλοποίηση:

- `public T Current { get; }`: λαμβάνει το τρέχον στοιχείο.
- `public bool MoveNext ();`: μετακινείται στο επόμενο στοιχείο, επιστρέφοντας `true` αν η μετακίνηση στο επόμενο στοιχείο ήταν επιτυχής και `false` αν όχι (δεν υπάρχουν άλλα στοιχεία).
- `public void Reset ();`: επαναφέρει τον απαριθμητή στην αρχική του κατάσταση (πριν από το πρώτο στοιχείο).
