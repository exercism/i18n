Τα πράγματα όμως είναι λίγο ακατάστατα: οι συντεταγμένες της Azara φαίνεται να είναι μορφοποιημένες και ταξινομημένες διαφορετικά από του Rui, και πρέπει να κοιτάζουν συνεχώς από τη μια λίστα στην άλλη για να καταλάβουν ποιοι θησαυροί πάνε με ποιες τοποθεσίες.
Καθώς είναι επίδοξοι fsharpies, ήρθαν σε σένα για βοήθεια, να γράψεις ένα μικρό πρόγραμμα (μια σειρά από συναρτήσεις, στην πραγματικότητα) για να οργανώσουν καλύτερα τις πληροφορίες του κυνηγιού τους.

## 1. Εξαγωγή συντεταγμένων

Υλοποίησε τη συνάρτηση `getCooordinate()` που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και επιστρέφει μόνο τη συντεταγμένη του χάρτη που εξάγεται.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Μορφοποίηση συντεταγμένων

Υλοποίησε τη συνάρτηση `convertCoordinate()` που παίρνει μια συντεταγμένη στη μορφή "2A" και επιστρέφει μια πλειάδα στη μορφή `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Αντιστοίχιση συντεταγμένων

Υλοποίησε τη συνάρτηση `compareRecords()` που παίρνει ένα ζεύγος `(treasure, coordinate)` και μια καταγραφή `(location, coordinate, quadrant)` και συγκρίνει τις συντεταγμένες από τη μία και την άλλη.
Επίστρεψε **`true`** αν οι συντεταγμένες "ταιριάζουν", και επίστρεψε **`false`** αν δεν ταιριάζουν.
Μορφοποίησε ξανά τις συντεταγμένες όπως χρειάζεται για ακριβή σύγκριση.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Συνδυασμός των καταγραφών που ταιριάζουν

Υλοποίησε τη συνάρτηση `createrecord()` που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και μια καταγραφή `(location, coordinate, quadrant)` από τη λίστα του Rui και επιστρέφει `(coordinate, location, quadrant, treasure)` **αν οι συντεταγμένες ταιριάζουν**.
Αν οι συντεταγμένες _δεν_ ταιριάζουν, επίστρεψε μια πλειάδα με την ίδια μορφή αλλά γεμάτη με `""`.
Μορφοποίησε ξανά τις συντεταγμένες όπως χρειάζεται για ακριβή σύγκριση.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
