# Οδηγίες

Γράψε μια συνάρτηση που να μετατρέπει συνηθισμένους αριθμούς σε [τακτικούς αριθμούς](https://en.wikipedia.org/wiki/Ordinal_numeral). Για το μηδέν (0) απλώς επίστρεψε το "0" ως συμβολοσειρά.

Οι τακτικοί αριθμοί είναι αριθμοί που περιγράφουν τη θέση ενός πράγματος σε μια λίστα. Σε αυτό το πλαίσιο θα χρησιμοποιηθούν τακτικοί αριθμοί, χρησιμοποιώντας την αγγλική γραφή του ονόματος ενός τακτικού αριθμού.

Οι τακτικοί αριθμοί είναι (τουλάχιστον, μία μορφή τους):

```
1st 2nd 3rd 4th 5th... 9th 10th 11th 12th... 20th 21st 22nd 23rd 24th... etc.
```

Έτσι, εισάγοντας έναν συνηθισμένο αριθμό προκύπτει το τακτικό του αντίστοιχο:

```
1 -> 1st
2 -> 2nd
3 -> 3rd
(and so on...)
```
