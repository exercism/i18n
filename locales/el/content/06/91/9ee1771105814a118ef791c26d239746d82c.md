# Οδηγίες

Σε αυτή την άσκηση θα γράψεις ένα γενικό (ή μαγικό!) TreasureChest, για να αποθηκεύσεις κάποιον θησαυρό.

## 1. Όρισε τον τύπο TreasureChest

Όρισε έναν παραμετρικό τύπο `TreasureChest{T}` με δύο πεδία.

- Ένα πεδίο `password` τύπου `String`, το οποίο θα χρησιμοποιηθεί για να αποθηκεύσει τον κωδικό πρόσβασης του σεντουκιού του θησαυρού.
- Ένα πεδίο `treasure` τύπου `T`, το οποίο θα χρησιμοποιηθεί για να αποθηκεύσει τον θησαυρό.
Αυτή η τιμή είναι γενική, ώστε ο θησαυρός να μπορεί να είναι οτιδήποτε.

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. Όρισε τη συνάρτηση get_treasure()

Αυτή η συνάρτηση πρέπει να δέχεται δύο ορίσματα.

- Μία `String` (για να δοκιμάσεις έναν κωδικό πρόσβασης)
- Έναν τύπο `TreasureChest`

Αυτή η συνάρτηση πρέπει να ελέγχει τον κωδικό πρόσβασης που δίνεται έναντι του πεδίου `password` στο `TreasureChest`.

- Αν οι κωδικοί πρόσβασης ταιριάζουν, τότε επέστρεψε τον θησαυρό.
- Αν οι κωδικοί πρόσβασης δεν ταιριάζουν, τότε επέστρεψε `nothing`.

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. Όρισε τη συνάρτηση multiply_treasure()

Αυτή η συνάρτηση πρέπει να δέχεται δύο ορίσματα.

- Έναν ακέραιο πολλαπλασιαστή `n`.
- Έναν τύπο `TreasureChest{T}`.

Η συνάρτηση πρέπει να επιστρέφει ένα νέο `TreasureChest{Vector{T}}`, με
- Τον ίδιο κωδικό πρόσβασης με το αρχικό
- Τον πολλαπλασιασμένο θησαυρό ως `Vector{T}` μήκους `n`, με τον αρχικό θησαυρό να επαναλαμβάνεται `n` φορές.

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
