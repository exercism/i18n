# Οδηγίες

Θεώρησε μια πολυωνυμική συνάρτηση της μορφής f(x) = ax^3 + bx^2 + cx + d. Τα τοπικά ελάχιστα ορίζονται ως f(x) < f(x - delta) και f(x) < f(x + delta). Χρησιμοποιώντας αυτόν τον ορισμό, εξήγαγε μια παράσταση για το τοπικό ελάχιστο και βρες επίσης ένα τοπικό ελάχιστο με τους δεδομένους συντελεστές (a, b, c, d). Οι συντελεστές θα περιγράφουν μια συνάρτηση με τουλάχιστον ένα ελάχιστο.
Επίστρεψε τη συντεταγμένη x στην οποία εμφανίζεται το ελάχιστο.
