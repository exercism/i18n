# Δοκιμές

Μπορείς να υλοποιήσεις μια άσκηση στο δικό σου σύστημα SAP. Ακολούθησε αυτά τα βήματα:

1. Δημιούργησε ένα πακέτο SAP για όλες τις ασκήσεις του Exercism στο σύστημά σου (προτεινόμενο όνομα: `$EXERCISM`)
2. Δημιούργησε ένα πακέτο SAP για κάθε άσκηση ως υποπακέτο (προτεινόμενο όνομα: `$EXERCISM_<name-of-exercise>`, παράδειγμα: `$EXERCISM_HELLO-WORLD`)
3. Δημιούργησε μια κλάση ABAP που αντιστοιχεί στην άσκηση (παράδειγμα: `ZCL_HELLO_WORLD`)
4. Αντίγραψε τον κώδικα προτύπου από το Exercism στην κλάση
5. Συντήρησε τις κλάσεις δοκιμών και αντίγραψε τον κώδικα από το Exercism στην κλάση δοκιμών

Τώρα μπορείς να ολοκληρώσεις την υλοποίηση της κλάσης και να τρέξεις τη δοκιμή μονάδας για να δεις αν η λύση σου λειτουργεί σωστά.

Σημείωση: Αυτή η διάταξη πακέτων θα σου επιτρέψει να κρατήσεις αντίγραφο ασφαλείας όλης της δουλειάς σου χρησιμοποιώντας το [abapGit](https://abapgit.org), δημιουργώντας ένα αποθετήριο για το πακέτο `$EXERCISM`.

Για περισσότερες λεπτομέρειες, δες την [τεκμηρίωση ABAP του Exercism](https://exercism.org/docs/tracks/abap).
