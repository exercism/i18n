# Εικονικό

## Οδηγίες ειδικά για τη MoonScript

Οι συμβολοσειρές ημερομηνίας και ώρας εισόδου και αναμενόμενου αποτελέσματος στα tests εκφράζονται στη ζώνη ώρας UTC.
Αυτό γίνεται για να εξαλειφθούν οι επιπτώσεις της θερινής ώρας στην τοπική σου ζώνη ώρας.

Η βασική πρόκληση σε αυτή την άσκηση είναι να κάνεις parse το timestamp εισόδου _σαν να βρίσκεσαι στη ζώνη ώρας UTC_.
Η ενσωματωμένη συνάρτηση `os.time` της Lua απλά δεν μπορεί να το κάνει αυτό.
Μπορεί να επιστρέψει μόνο την **τοπική** ώρα.
Και δεν είναι τόσο απλό όσο το να προσαρμόσεις αυτή την τοπική ώρα με τη διαφορά (σε δευτερόλεπτα) της ζώνης ώρας σου από την UTC:
πρέπει να γνωρίζεις τη διαφορά _τη στιγμή που κάνεις parse_, όχι τη _τρέχουσα_ διαφορά.

Η αριθμητική ημερομηνιών και ωρών είναι ένα **πολύ** περίπλοκο θέμα, και δεν θέλεις να χρειαστεί να εφεύρεις ξανά τον τροχό: θέλεις να μπορείς να βασιστείς σε μια καλά δοκιμασμένη βιβλιοθήκη για να πάνε όλα σωστά.

Το module `lua-tz` λειτουργεί καλά για αυτή την άσκηση.
Παρέχει τις συναρτήσεις `tz.time` και `tz.date`, που είναι άμεσες αντικαταστάσεις των ενσωματωμένων συναρτήσεων `os.time` και `os.date`, αλλά σου επιτρέπουν να δώσεις ένα όνομα ζώνης ώρας ως επιπλέον παράμετρο.

Έχουμε προσθέσει μερικά επιπλέον modules ημερομηνίας και ώρας στον test runner της MoonScript, αν θέλεις να πειραματιστείς μαζί τους.

* `lua-tz`: [σελίδα πληροφοριών του luarocks][lua-tz-rock], [ιστότοπος][lua-tz-home], [τεκμηρίωση][lua-tz-doc]
* `date`: [σελίδα πληροφοριών του luarocks][date-rock], [ιστότοπος][date-home], [τεκμηρίωση][date-doc]
* `luatz`: [σελίδα πληροφοριών του luarocks][luatz-rock], [ιστότοπος][luatz-home], [τεκμηρίωση][luatz-doc]
