# Εισαγωγή

Οι εκφράσεις συνθήκης χρησιμοποιούνται για να εκτελεστεί κώδικας ανάλογα με το **αν** μια συνθήκη είναι **αληθής** ή **ψευδής**. Αυτές οι εκφράσεις γράφονται ως εξής:

```haxe
if (condition) {
  expressions
};
```

Η έξοδος της συνθήκης είναι τύπου `Bool`, οπότε όταν η έξοδος είναι `true` οι εκφράσεις εκτελούνται.

Μερικές φορές, όταν η συνθήκη είναι στην πραγματικότητα `false`, θέλουμε να εκτελεστεί και ένα άλλο κομμάτι κώδικα. Εκεί μπαίνει στο παιχνίδι η έκφραση `else`. Το `else` εκτελεί εκφράσεις όταν η αρχική συνθήκη είναι `false`. Αλλά τι γίνεται αν θέλουμε να ελέγξουμε τη συνθήκη για πολλαπλές περιπτώσεις; Τότε χρησιμοποιούμε το `else if (condition)`. Ορίστε ένα πλήρες παράδειγμα:

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
