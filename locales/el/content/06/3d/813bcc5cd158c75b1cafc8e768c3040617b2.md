# Οδηγίες

Ξαφνικά νιώθεις ένα κύμα νοσταλγίας και μια έντονη επιθυμία να ξεσκονίσεις τις παλιές σου κάρτες Blorkemon™️.
Οι κάρτες Blorkemon™️ είναι ένα υπέροχο, παλιό καλό παιχνίδι ανταλλαγής καρτών.
Κάθε `Card` έχει πάνω της ζωγραφισμένο ένα τέρας Blorkemon™️, μαζί με ένα επίπεδο δύναμης επίθεσης, και αν είσαι τυχερός, η κάρτα μπορεί να είναι ακόμα και λαμπερή.

## 1. Σύγκρινε τα επίπεδα δύναμης

Κάθε κάρτα Blorkemon™️ φαίνεται πιο δυνατή από την επόμενη, αλλά καλύτερα να το ελέγξεις.

Υλοποίησε τη συνάρτηση `isMorePowerful`. Θα πρέπει να επιστρέφει `True` αν η κάρτα στο πρώτο της όρισμα είναι αυστηρά πιο δυνατή από την άλλη, και `False` διαφορετικά.

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. Βρες τη μεγαλύτερη δύναμη

Με ένα χέρι γεμάτο κάρτες Blorkemon™️, θα πρέπει να μπορείς να προετοιμάσεις την πιο καταστροφική επίθεση.

Υλοποίησε τη συνάρτηση `maxPower`, η οποία επιστρέφει το υψηλότερο επίπεδο δύναμης από δύο κάρτες.

```elm
maxPower newthree scientuna
    --> 120
```

## 3. Ταξινόμησε τις κάρτες

Θυμάσαι μάλλον ότι είχες τουλάχιστον μία κάρτα από κάθε Blorkemon™️, αλλά έχει περάσει καιρός από την τελευταία φορά που το τσέκαρες, οπότε καλύτερα να ταξινομήσεις τις κάρτες σου για να τις συγκρίνεις με την επίσημη λίστα στο Pulpapedia.

Υλοποίησε τη συνάρτηση `sortByMonsterName`, η οποία θα πρέπει να παίρνει μια λίστα από `Cards` και να επιστρέφει μια λίστα ταξινομημένη κατά όνομα τέρατος.

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. Οι πιο κουλ κάρτες πρώτα

Τα Blorkemon™️ είναι ό,τι πιο κουλ υπάρχει.
Δεν χρησιμοποιείς αυτόν τον χαρακτηρισμό απερίσκεπτα, έχεις μια επιστημονική μέθοδο για να το αποδείξεις.

Υλοποίησε τη συνάρτηση `sortByCoolness`, η οποία ταξινομεί μια λίστα καρτών βάζοντας πρώτες τις πιο κουλ.
Η κουλότητα μιας κάρτας καθορίζεται πρώτα από τη λάμψη της: όλες οι λαμπερές κάρτες είναι πολύ πιο κουλ από τις υπόλοιπες.
Ο δεύτερος παράγοντας είναι το επίπεδο δύναμης, όσο υψηλότερο τόσο το καλύτερο.

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. Λαμπερή Δύναμη

Η λάμψη δεν είναι μόνο για επίδειξη: σε μια μάχη ανάμεσα σε Blorkemon™️ με ίση δύναμη, το λαμπερό θα υπερισχύσει πάντα.
Αυτό ονομάζεται Λαμπερή Δύναμη.

Υλοποίησε τη συνάρτηση `compareShinyPower`, η οποία κωδικοποιεί αυτή την ιδιότητα.
Η `Order` δύο καρτών καθορίζεται από τα επίπεδα δύναμης αν αυτά είναι διαφορετικά, αλλά αν είναι ίσα, μια λαμπερή κάρτα θα είναι μεγαλύτερη.

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. Βάλε τα στοιχήματά σου

Σε ένα παιχνίδι με κάρτες Blorkemon™️, όλα επιτρέπονται, αλλά υπάρχει ακόμα μια τάση οι πιο δυνατές κάρτες να κερδίζουν.

Υλοποίησε τη συνάρτηση `expectedWinner` που επιστρέφει το όνομα του τέρατος με τις περισσότερες πιθανότητες να κερδίσει, όπως καθορίζεται από τη διάταξη της `compareShinyPower`.
Η συνάρτηση θα πρέπει να επιστρέφει το όνομα του τέρατος του αναμενόμενου νικητή, ή "too close to call" αν και οι δύο αντίπαλοι έχουν την ίδια Λαμπερή Δύναμη.

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
