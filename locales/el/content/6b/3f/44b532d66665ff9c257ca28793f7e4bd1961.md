# Εισαγωγή

Εργάζεσαι σε μια εταιρεία βιοτεχνολογίας που ειδικεύεται στην ανάπτυξη θεραπευτικών λύσεων.

Η ομάδα σου μόλις ανέλαβε ένα νέο έργο: να αναπτύξει μια στοχευμένη θεραπεία για έναν σπάνιο τύπο καρκίνου.

~~~~exercism/note
Είναι όλα πολύ περίπλοκα, αλλά η βασική ιδέα είναι ότι μερικές φορές το σώμα των ανθρώπων παράγει υπερβολική ποσότητα από μια συγκεκριμένη πρωτεΐνη.
Αυτό μπορεί να προκαλέσει κάθε λογής αναστάτωση.

Αν όμως καταφέρεις να δημιουργήσεις ένα πολύ συγκεκριμένο μόριο (που ονομάζεται micro-RNA), μπορεί να εμποδίσει την παραγωγή της πρωτεΐνης.

Αυτή η τεχνική ονομάζεται [Παρεμβολή RNA][rnai].

[rnai]: https://admin.acceleratingscience.com/ask-a-scientist/what-is-rnai/
~~~~
