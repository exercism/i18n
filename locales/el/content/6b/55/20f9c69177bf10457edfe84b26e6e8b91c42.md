# Οδηγίες

Η ομάδα σου εργάζεται πάνω σε μια εφαρμογή μετεωρολογίας.
Έχει ορίσει ένα API με διάφορους τύπους και σταθερές που αναπαριστούν μετεωρολογικά δεδομένα, δες το αρχείο `meteorology.go`.

Η αποστολή σου είναι να προσθέσεις κατάλληλες μεθόδους `String` σε όλους τους τύπους, ώστε να υλοποιούν τη διεπαφή `Stringer`.

## 1. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `TemperatureUnit`

Μετά από κάποια συζήτηση, η ομάδα συμφώνησε ότι η μονάδα θερμοκρασίας θα είναι είτε `Celsius` είτε `Fahrenheit`.
Οι τιμές θα πρέπει να μορφοποιούνται όπως φαίνεται στα παρακάτω παραδείγματα.

Κάνε τον τύπο `TemperatureUnit` να υλοποιεί τη διεπαφή `Stringer`, προσθέτοντάς του μια μέθοδο `String`.
Αυτή η μέθοδος πρέπει να επιστρέφει τη συμβολοσειρά `"°C"` αν η μονάδα θερμοκρασίας είναι Celsius ή `"°F"` αν η μονάδα θερμοκρασίας είναι Fahrenheit.

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `Temperature`

Οι τιμές θερμοκρασίας αποτελούνται από έναν ακέραιο και μια μονάδα θερμοκρασίας.
Θα πρέπει να μορφοποιούνται όπως στα παρακάτω παραδείγματα.

Για να συμβεί αυτό, κάνε τον τύπο `Temperature` να υλοποιεί τη διεπαφή `Stringer`, προσθέτοντάς του μια μέθοδο `String`.
Αυτή η μέθοδος πρέπει να επιστρέφει μια συμβολοσειρά με την αριθμητική τιμή της θερμοκρασίας και τη μονάδα θερμοκρασίας, χωρισμένες με ένα κενό: `<temperature> <unit>`:

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `SpeedUnit`

Μετά από μακρές συζητήσεις, η ομάδα συμφώνησε ότι η μονάδα ταχύτητας ανέμου θα είναι είτε `KmPerHour` είτε `MilesPerHour`.
Οι τιμές θα πρέπει να μορφοποιούνται όπως στα παρακάτω παραδείγματα.

Για να συμβεί αυτό, κάνε τον τύπο `SpeedUnit` να υλοποιεί τη διεπαφή `Stringer`, προσθέτοντάς του μια μέθοδο `String`.
Αυτή η μέθοδος πρέπει να επιστρέφει τη συμβολοσειρά `"km/h"` αν η μονάδα ταχύτητας είναι χιλιόμετρα την ώρα ή `"mph"` αν η μονάδα ταχύτητας είναι μίλια την ώρα:

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `Speed`

Οι τιμές ταχύτητας ανέμου αποτελούνται από έναν ακέραιο και μια μονάδα ταχύτητας.
Θα πρέπει να μορφοποιούνται όπως στο παρακάτω παράδειγμα.

Για να συμβεί αυτό, κάνε τον τύπο `Speed` να υλοποιεί τη διεπαφή `Stringer`, προσθέτοντάς του μια μέθοδο `String`.
Αυτή η μέθοδος πρέπει να επιστρέφει μια συμβολοσειρά με την αριθμητική τιμή της ταχύτητας και τη μονάδα ταχύτητας, χωρισμένες με ένα κενό: `<speed> <unit>`:

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `MeteorologyData`

Τα μετεωρολογικά δεδομένα καθορίζουν τοποθεσία, θερμοκρασία, διεύθυνση ανέμου, ταχύτητα ανέμου και υγρασία.
Θα πρέπει να μορφοποιούνται όπως στο παρακάτω παράδειγμα:

Για να συμβεί αυτό, κάνε τον τύπο `MeteorologyData` να υλοποιεί τη διεπαφή `Stringer`, προσθέτοντάς του μια μέθοδο `String`.
Αυτή η μέθοδος πρέπει να επιστρέφει τα μετεωρολογικά δεδομένα στην εξής μορφή:

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
