# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις το Betty's Bike Shop, ένα ηλεκτρονικό κατάστημα για ποδήλατα και ανταλλακτικά.
Έχεις τρεις εργασίες, με στόχο να εμφανίζονται σωστά οι τιμές των ποδηλάτων και των ανταλλακτικών στην ιστοσελίδα.

## 1. Εξήγαγε τη συνάρτηση `penceToPounds`

Ο συνάδελφός σου έχει ήδη γράψει τον σκελετό του module, δηλαδή τις μη ορισμένες συναρτήσεις `penceToPounds` και `poundsToString`.
Ωστόσο, ξέχασε να εξάγει τη συνάρτηση `penceToPounds`, οπότε αυτή τη στιγμή δεν είναι ορατή από άλλα modules ούτε από τη σουίτα δοκιμών.

Πρόσθεσε τη συνάρτηση `penceToPounds` στη λίστα με τις εξαγόμενες συναρτήσεις.

## 2. Μετέτρεψε τις πένες σε λίρες

Αυτή τη στιγμή, η τιμή αποθηκεύεται ως ακέραιος αριθμός *πενών* (το κατάστημα ποδηλάτων εδρεύει στο Ηνωμένο Βασίλειο).
Στην ιστοσελίδα, θέλουμε να δείχνουμε την τιμή σε *λίρες*, όπου 1,00 λίρα αντιστοιχεί σε 100 πένες.
Η δεύτερη εργασία σου είναι να υλοποιήσεις τη συνάρτηση `penceToPounds`, η οποία παίρνει ένα ποσό σε πένες ως `Int` και το μετατρέπει στο ισοδύναμό του σε λίρες ως `Float`.
Θα πρέπει επίσης να ορίσεις τη δήλωση τύπου για αυτή τη συνάρτηση.

```elm
penceToPounds 106
    --> 1.06
```

## 3. Μορφοποίησε την τιμή για εμφάνιση στην ιστοσελίδα

Επειδή τα ποδήλατα της Betty πωλούνται σε λίρες, οι τιμές θα πρέπει να εμφανίζονται με το σύμβολο "£".
Η τρίτη εργασία σου είναι λοιπόν να υλοποιήσεις τη συνάρτηση `poundsToString`, η οποία παίρνει ένα ποσό σε λίρες ως `Float` και επιστρέφει την τιμή του ως `String`, με το σύμβολο της λίρας μπροστά.
Το module `String` περιέχει τη συνάρτηση `String.fromFloat`, που θα σου φανεί χρήσιμη γι' αυτό.
Θα πρέπει να εισάγεις το module `String` πριν το χρησιμοποιήσεις.
Θα πρέπει επίσης να ορίσεις τη δήλωση τύπου για τη συνάρτηση `poundsToString`.

```elm
poundsToString 1.06
    --> "£1.06"
```
