# Σχετικά

Το `Iterator` στη Gleam μοιάζει με μια λίστα στο ότι είναι και αυτό μια διατεταγμένη συλλογή τιμών, όπου όλες οι τιμές έχουν τον ίδιο τύπο. Διαφέρει από τη λίστα στο ότι είναι οκνηρό: δεν αποθηκεύει όλες τις τιμές του στη μνήμη ταυτόχρονα, αλλά τις υπολογίζει καθώς τις χρειάζεται.

Αυτό είναι χρήσιμο όταν δουλεύεις με ακολουθίες που είναι πολύ μεγάλες ή ακόμα και άπειρες σε μέγεθος, καθώς σου επιτρέπει να δουλεύεις μαζί τους ακόμα και όταν δεν έχεις αρκετή ελεύθερη μνήμη για να τις αποθηκεύσεις όλες μαζί.

Το module `gleam/iterator` ορίζει τον τύπο `Iterator` καθώς και συναρτήσεις για να δουλεύεις με iterators.

Πολλές από τις συναρτήσεις για λίστες υπάρχουν και για iterators, όπως οι `map`, `filter` και `take`. Αυτές οι συναρτήσεις επιστρέφουν iterators, οπότε δεν κάνουν στην πραγματικότητα καμία δουλειά μέχρι να καταναλωθεί ο iterator.

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

Η συνάρτηση `unfold` μπορεί να χρησιμοποιηθεί για να δημιουργήσεις iterators από μια συνάρτηση που καλείται επανειλημμένα για να παράγει την επόμενη τιμή στην ακολουθία.

Εδώ η συνάρτηση `unfold` χρησιμοποιείται για να δημιουργήσει έναν iterator που παράγει την ακολουθία Fibonacci:

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

Η ακολουθία εδώ είναι άπειρη, οπότε χρησιμοποιείται η συνάρτηση `take` για να γίνει πεπερασμένη πριν συγκεντρωθούν οι τιμές σε μια λίστα. Αν κληθεί η `to_list` σε έναν άπειρο iterator, το πρόγραμμα θα τρέξει μέχρι να εξαντληθεί η μνήμη και να καταρρεύσει.
