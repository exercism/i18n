# Εισαγωγή

Μια `Tuple` μοιάζει αρκετά με έναν `Vector` (έναν `array` μίας διάστασης) σε πολλά σημεία.
Ωστόσο, υπάρχουν μερικές σημαντικές διαφορές.

- Οι πλειάδες γράφονται μέσα σε παρενθέσεις `( )` αντί για αγκύλες `[ ]`, αν και οι παρενθέσεις μπορούν να παραλειφθούν σε περιπτώσεις όπου το νόημα είναι σαφές.
- Οι πλειάδες δεν χρειάζεται να είναι ομοιογενείς: ο τύπος κάθε στοιχείου αποθηκεύεται ανεξάρτητα.
- Οι πλειάδες είναι αμετάβλητες.

Η αμεταβλητότητα επιτρέπει περισσότερες βελτιστοποιήσεις από τον μεταγλωττιστή και κάνει τις πλειάδες πιο αποδοτικές από τα διανύσματα, οπότε αξίζει να προτιμώνται σε περιπτώσεις όπου η μεταβλητότητα δεν είναι απαραίτητη.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

Υπάρχει επίσης ένας κατασκευαστής `Tuple()`, που μετατρέπει οποιαδήποτε συλλογή που μπορεί να διατραπεί σε πλειάδα.
Βολικά, αυτό αντιμετωπίζει τη συμβολοσειρά ως συλλογή χαρακτήρων που μπορεί να διατραπεί.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

Σε οποιαδήποτε πλειάδα, μπορείς να έχεις πρόσβαση στα στοιχεία με τη θέση τους ή να τα διατρέξεις με έναν βρόχο.

Οποιαδήποτε καθαρά αριθμητική πλειάδα μπορεί επίσης να χρησιμοποιηθεί σε μαθηματικές συναρτήσεις όπως η `sum()`, ακριβώς όπως οι πίνακες.

## Αποσυσκευασία

Μια πλειάδα μπορεί να αποσυσκευαστεί σε μεμονωμένα στοιχεία με πολλαπλή ανάθεση.
Για στοιχεία που δεν χρειάζεσαι, χρησιμοποίησε την κάτω παύλα `_` ως μεταβλητή-οδηγό.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Οι προγραμματιστές Python θα είναι πολύ εξοικειωμένοι με αυτή τη σύνταξη πολλαπλής ανάθεσης.

## Ονομαστικές πλειάδες

Μια `Tuple` περιέχει μόνο τιμές.
Μια `NamedTuple` αντιστοιχίζει κάθε τιμή με ένα όνομα.

Στη συνέχεια μπορείς να έχεις πρόσβαση σε κάθε πεδίο ξεχωριστά με τον συμβολισμό της τελείας:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

Το όνομα αποθηκεύεται εσωτερικά ως `Symbol` (ένας αμετάβλητος τύπος, με πρόθεμα άνω και κάτω τελεία `:`), οπότε υπάρχει διαθέσιμος και ένας εναλλακτικός συμβολισμός:

```julia-repl
julia> nt[:b]
7.3
```

Είναι εύκολο να πάρεις ξεχωριστά είτε τα ονόματα (που ονομάζονται και "κλειδιά") είτε τις τιμές:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Σημείωσε ότι η επανάληψη πάνω σε μια ονομαστική πλειάδα παράγει μόνο τις _τιμές_, και τα _ονόματα_ αγνοούνται.

Οι πλειάδες (ονομαστικές ή μη) είναι ένας πολύ συνηθισμένος τρόπος για να μεταφέρεις δομημένα δεδομένα από και προς συναρτήσεις.
Η αμεταβλητότητα είναι καλή σε αυτή την περίπτωση χρήσης, καθώς παρέχει ασφάλεια δεδομένων και επιτρέπει πιο επιθετικές βελτιστοποιήσεις από τον μεταγλωττιστή.
