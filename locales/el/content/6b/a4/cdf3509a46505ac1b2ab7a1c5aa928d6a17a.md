# Υποδείξεις

## Γενικά

- Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, συγκεντρώσου μόνο στον συνδυασμό των ορισμάτων για να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο pac-man μπορεί να φάει ένα φάντασμα

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή Boolean (λογική τιμή).
- Μπορείς να χρησιμοποιήσεις τον λογικό τελεστή and ([`&&`][logical operators]) για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 2. Όρισε αν ο pac-man σκοράρει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή Boolean.
- Μπορείς να χρησιμοποιήσεις τον λογικό τελεστή or ([`||`][logical operators]) για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 3. Όρισε αν ο pac-man χάνει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή Boolean.
- Μπορείς να χρησιμοποιήσεις τους τελεστές Boolean [`&&`][logical operators] και [`!`][logical operators] για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 4. Όρισε αν ο pac-man κερδίζει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή Boolean.
- Μπορείς να χρησιμοποιήσεις τους τελεστές Boolean [`&&`][logical operators] και [`!`][logical operators] για να συνδυάσεις τα ορίσματα και τα αποτελέσματα μιας από τις συναρτήσεις που υλοποίησες προηγουμένως.

[logical operators]: https://en.cppreference.com/w/cpp/language/operator_logical
