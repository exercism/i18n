# Σχετικά

## Modules

Ο κώδικας της Gleam οργανώνεται σε modules, και κάθε αρχείο είναι ένα module της Gleam.

Μέχρι τώρα έχουμε γράψει συναρτήσεις με τη σύνταξη `pub fn`, η οποία ορίζει μια συνάρτηση που είναι δημόσια διαθέσιμη σε άλλα modules. Οι συναρτήσεις που ορίζονται με `fn` είναι ιδιωτικές για το module στο οποίο ορίζονται και δεν μπορούν να χρησιμοποιηθούν από άλλα modules.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Τα modules της Gleam έχουν ονόματα, και το όνομα βασίζεται στη διαδρομή του αρχείου μέσα στον κατάλογο `src` ή `test`.

Για παράδειγμα, ένα module που ορίζεται στο `src\geometry\rectangle.gleam` (στα Windows) ή στο `src/geometry/rectangle.gleam` (σε λειτουργικά συστήματα τύπου UNIX) θα ονομαζόταν `geometry/rectangle`.

## Εισαγωγή συναρτήσεων από άλλα modules

Η πρόσβαση σε συναρτήσεις που ορίζονται σε άλλα modules γίνεται μέσω εισαγωγών.
Όλες οι συναρτήσεις που εκθέτει αυτό το module γίνονται προσβάσιμες όταν το εισάγεις.
Ο τρόπος όμως με τον οποίο τις προσπελαύνεις διαφέρει ανάλογα με το πώς εισάγεται το module.

Οι εισαγωγές με πρόθεμα είναι προεπιλεγμένες, και η πρόσβαση σε μια συνάρτηση ενός τέτοιου module (για παράδειγμα στη συνάρτηση `map` του module `gleam/list`) γίνεται βάζοντας μπροστά το όνομα του module (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

Από προεπιλογή, το όνομα με το οποίο αναφέρεσαι στο module είναι το τελευταίο κομμάτι του ονόματός του, εδώ το `int`, αλλά αυτό μπορεί να αλλάξει με τη λέξη-κλειδί `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Οι εισαγωγές χωρίς πρόθεμα σου δίνουν άμεση πρόσβαση στις συναρτήσεις που εκθέτει το module, χωρίς να χρειάζεται να βάλεις κάτι μπροστά.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Οι εισαγωγές με πρόθεμα προτιμώνται, γιατί κάνουν πιο ξεκάθαρο στον αναγνώστη από πού προέρχεται μια συνάρτηση και αποφεύγουν τις συγκρούσεις ονομάτων.
