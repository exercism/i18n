# Προσθήκη οδηγιών

## Υποδείξεις

- Για να αναλύσεις το κείμενο, θα μπορούσες να δοκιμάσεις τη βιβλιοθήκη [Sprache](https://github.com/sprache/Sprache/blob/develop/README.md). Μπορείς επίσης να βρεις ένα καλό tutorial [εδώ](https://www.thomaslevesque.com/2017/02/23/easy-text-parsing-in-c-with-sprache/).
- Μπορείς να λύσεις αυτή την άσκηση με έναν αλγόριθμο brute force, αλλά πιθανόν να έχει κακή απόδοση στον χρόνο εκτέλεσης.
  Προσπάθησε να βρεις μια πιο εξελιγμένη λύση.
- Υπόδειξη: Θα μπορούσες να δοκιμάσεις τον αλγόριθμο πρόσθεσης κατά στήλες που συνήθως διδάσκεται στο σχολείο.
