# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις ένα μερικό σύνολο βοηθητικών ρουτινών για να βοηθήσεις έναν προγραμματιστή να καθαρίσει ονόματα SqueakyClean.

Στις 4 εργασίες θα χτίζεις σταδιακά τη μέθοδο `clean`.
Ένα έγκυρο όνομα SqueakyClean αποτελείται από μηδέν ή περισσότερα γράμματα και κάτω παύλες.

Σε όλες τις περιπτώσεις, διασφαλίζεται ότι η συμβολοσειρά εισόδου δεν είναι null. Σημείωσε ότι η μέθοδος `clean` πρέπει να θεωρεί μια κενή συμβολοσειρά ως έγκυρη.

## 1. Αντικατέστησε όποια κενά συναντάς με κάτω παύλες

Υλοποίησε τη (_static_) μέθοδο `SqueakyClean.clean()` ώστε να αντικαθιστά όποια κενά με κάτω παύλες. Αυτό ισχύει επίσης για κενά στην αρχή και στο τέλος.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Μετέτρεψε το kebab-case σε camelCase

Τροποποίησε τη (_static_) μέθοδο `SqueakyClean.clean()` ώστε να μετατρέπει το kebab-case σε camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Μετέτρεψε το leetspeak σε κανονικό κείμενο

Τροποποίησε τη (_static_) μέθοδο `SqueakyClean.clean()` ώστε να μετατρέπει το [leetspeak][leet-speak] σε κανονικό κείμενο.

Για απλότητα, θα αντικαταστήσουμε μόνο τα `4`, `3`, `0`, `1` και `7` με `a`, `e`, `o`, `l` και `t`, αντίστοιχα.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Παράλειψε χαρακτήρες που δεν είναι γράμματα

Τροποποίησε τη (_static_) μέθοδο `SqueakyClean.clean()` ώστε να παραλείπει όποιους χαρακτήρες δεν είναι γράμματα.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
