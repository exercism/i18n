# Οδηγίες

Οι εργασίες για τον Υπολογιστή RPN στην _Instruments of Texas_ προχωρούν καλά. Η ομάδα σου θέλει τώρα να μπορεί να γράψει μια μορφή της εξίσωσης ως συμβολοσειρά σε έναν πόρο _IO_.

## 1. Άνοιξε ένα αρχείο

Η ομάδα σου δεν έχει αποφασίσει σε τι τύπο συσκευής θα γράψει την εξίσωση, οπότε προτείνεις να χρησιμοποιήσεις μια προσέγγιση _dynamic dispatch_ ώστε να μπορείς να εισάγεις τον πόρο στη συνάρτηση, αντί να βάλεις καρφωτή τιμή μέσα της. Υλοποίησε τη συνάρτηση `write/3` για να ανοίξεις μια _συσκευή IO_ χρησιμοποιώντας τον πόρο και το όνομα του αρχείου.

Μπορείς να υποθέσεις ότι το `resource` θα είναι πάντα ένα atom που αντιπροσωπεύει ένα module με συνάρτηση `open/1` που επιστρέφει `{:ok, io_device}`.

Όταν η συνάρτηση πετύχει, επίστρεψε μια πλειάδα ok με την εξίσωση.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. Προσπάθησε να γράψεις στη συσκευή IO

Τώρα που άνοιξες τη συσκευή IO, προσπάθησε να γράψεις σε αυτήν χρησιμοποιώντας το `IO.write/2`.

Επέκτεινε τη συνάρτηση `write/3` ώστε να εκτελέσει αυτήν την ενέργεια. Η απόπειρα εγγραφής μπορεί να πετάξει ένα σφάλμα· κάνε rescue από το σφάλμα και επίστρεψε μια πλειάδα σφάλματος:

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. Κλείσε τη συσκευή IO

Είναι καλή πρακτική να προσπαθείς πάντα να απελευθερώνεις τους πόρους που άνοιξες, ακόμα κι αν η συνάρτηση που χρησιμοποιεί τον πόρο πετάει ένα σφάλμα. Επέκτεινε τη συνάρτηση `write/3` ώστε να καλέσει τη συνάρτηση close του πόρου για να κλείσει τη _συσκευή IO_.

Μπορείς να υποθέσεις ότι το `resource` θα είναι πάντα ένα atom που αντιπροσωπεύει ένα module με συνάρτηση `close/1` που δέχεται μια _συσκευή IO_.
