# Σχετικά

Τα slices στη Go μοιάζουν με τις λίστες ή τους πίνακες σε άλλες γλώσσες.
Περιέχουν αρκετά στοιχεία ενός συγκεκριμένου τύπου (ή interface).

Τα slices στη Go βασίζονται στους πίνακες.
Οι πίνακες έχουν σταθερό μέγεθος.
Το slice, αντίθετα, είναι μια ευέλικτη όψη των στοιχείων ενός πίνακα, με δυναμικό μέγεθος.

Ένα slice γράφεται ως `[]T`, όπου `T` είναι ο τύπος των στοιχείων του slice:

```go
var empty []int                 // an empty slice
withData := []int{0,1,2,3,4,5}  // a slice pre-filled with some data
```

Μπορείς να πάρεις ή να ορίσεις ένα στοιχείο σε μια δεδομένη θέση με βάση το μηδέν, χρησιμοποιώντας τη σημειογραφία με αγκύλες:

```go
withData[1] = 5
x := withData[1] // x is now 5
```

Μπορείς να δημιουργήσεις ένα νέο slice από ένα υπάρχον slice παίρνοντας ένα εύρος στοιχείων.
Για άλλη μια φορά χρησιμοποιείς τη σημειογραφία με αγκύλες, αλλά αυτή τη φορά ορίζεις και μια αρχική (συμπεριλαμβανόμενη) και μια τελική (μη συμπεριλαμβανόμενη) θέση.
Αν δεν ορίσεις αρχική θέση, χρησιμοποιείται το 0.
Αν δεν ορίσεις τελική θέση, χρησιμοποιείται το μήκος του slice.

```go
newSlice := withData[2:4]
// => []int{2,3}
newSlice := withData[:2]
// => []int{0,1}
newSlice := withData[2:]
// => []int{2,3,4,5}
newSlice := withData[:]
// => []int{0,1,2,3,4,5}
```

Μπορείς να προσθέσεις στοιχεία σε ένα slice χρησιμοποιώντας τη συνάρτηση `append`.
Παρακάτω προσθέτουμε το `4` και το `2` στο slice `a`.

```go
a := []int{1, 3}
a = append(a, 4, 2)
// => []int{1,3,4,2}
```

Η συνάρτηση `append` επιστρέφει πάντα ένα νέο slice, και όταν θέλουμε απλώς να προσθέσουμε στοιχεία σε ένα υπάρχον slice, συνηθίζεται να το ξαναθέτουμε στη μεταβλητή slice που περνάμε ως πρώτο όρισμα, όπως κάναμε παραπάνω.

Η `append` μπορεί επίσης να χρησιμοποιηθεί για να ενώσεις δύο slices:

```go
nextSlice := []int{100,101,102}
newSlice  := append(withData, nextSlice...)
// => []int{0,1,2,3,4,5,100,101,102}
```

## Οι θέσεις στα slices

Όταν δουλεύεις με θέσεις σε slices, θα πρέπει πάντα να προστατεύεσαι με κάποιον τρόπο, με έναν έλεγχο που να βεβαιώνεται ότι η θέση υπάρχει πραγματικά.
Αν δεν το κάνεις, θα καταρρεύσει ολόκληρη η εφαρμογή.

## Κενά slices

Τα `nil` slices είναι το προεπιλεγμένο κενό slice.
Δεν έχουν κανένα μειονέκτημα σε σχέση με ένα slice που δεν περιέχει τιμές.
Η συνάρτηση `len` δουλεύει στα `nil` slices, μπορείς να προσθέσεις στοιχεία χωρίς να το αρχικοποιήσεις, και ούτω καθεξής.
Αν δημιουργείς ένα νέο slice, προτίμησε το `var s []int` (`nil` slice) αντί για το `s := []int{}` (κενό, μη `nil` slice).

## Απόδοση

Όταν δημιουργείς slices που θα γεμίσουν επαναληπτικά, υπάρχει ένα εύκολο κέρδος για τη βελτίωση της απόδοσης, αν το τελικό μέγεθος του slice είναι γνωστό.
Το κλειδί είναι να ελαχιστοποιήσεις τον αριθμό των φορών που χρειάζεται να δεσμευτεί μνήμη, κάτι που είναι αρκετά δαπανηρό και συμβαίνει όταν το slice μεγαλώσει πέρα από τον δεσμευμένο χώρο μνήμης του.
Ο ασφαλέστερος τρόπος να το κάνεις αυτό είναι να ορίσεις μια χωρητικότητα `cap` για το slice με `s := make([]int, 0, cap)` και μετά να κάνεις `append` στο slice όπως συνήθως.
Έτσι, ο χώρος για `cap` στοιχεία δεσμεύεται αμέσως, ενώ το μήκος του slice είναι μηδέν.
Στην πράξη, το `cap` είναι συχνά το μήκος ενός άλλου slice: `s := make([]int, 0, len(otherSlice))`.

## Η `append` δεν είναι καθαρή συνάρτηση

Η συνάρτηση `append` της Go είναι βελτιστοποιημένη για απόδοση και επομένως δεν κάνει αντίγραφο του slice εισόδου.
Αυτό σημαίνει ότι το αρχικό slice (η 1η παράμετρος της `append`) θα αλλάξει μερικές φορές.
