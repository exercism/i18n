# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις έναν ελεύθερο επαγγελματία να επικοινωνεί με τον διαχειριστή έργου, παρέχοντας μερικά βοηθητικά εργαλεία για τον γρήγορο υπολογισμό ημερήσιων και μηνιαίων χρεώσεων, προαιρετικά με μια δεδομένη έκπτωση.

Πρώτα ας ορίσουμε μερικούς κανόνες ανάμεσα στον ελεύθερο επαγγελματία και τον διαχειριστή έργου:

- Η ημερήσια χρέωση είναι 8 φορές η ωριαία χρέωση.
- Ένας μήνας έχει 22 τιμολογήσιμες ημέρες.

Μερικές φορές, ο ελεύθερος επαγγελματίας προσφέρει έκπτωση στην ημερήσια χρέωσή του (για παράδειγμα στους πιο πιστούς πελάτες του ή σε μη κερδοσκοπικούς πελάτες).

Οι εκπτώσεις αναπαριστώνται ως δεκαδικοί αριθμοί που εκφράζουν ποσοστό, για παράδειγμα `25.0` (25%).

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

Υλοποίησε μια συνάρτηση που υπολογίζει την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση:

```haskell
dailyRate 60
-- -> 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι double.

## 2. Υπολόγισε μια τιμή με έκπτωση

Υλοποίησε μια συνάρτηση που υπολογίζει την τιμή μετά από μια έκπτωση.

```haskell
applyDiscount 150 10
-- -> 135.0
```

Η τιμή που επιστρέφεται πρέπει πάντα να είναι double, χωρίς καμία στρογγυλοποίηση.

## 3. Υπολόγισε τη μηνιαία χρέωση με δεδομένη την ωριαία χρέωση και την έκπτωση

Υλοποίησε μια συνάρτηση που υπολογίζει τη μηνιαία χρέωση και εφαρμόζει μια έκπτωση:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

Η μηνιαία χρέωση που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα πάνω (οροφή) στον πλησιέστερο ακέραιο.

## 4. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένο προϋπολογισμό, ωριαία χρέωση και έκπτωση

Υλοποίησε μια συνάρτηση που δέχεται έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση, και υπολογίζει πόσες ημέρες εργασίας καλύπτει.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

Ο αριθμός των ημερών που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα κάτω (δάπεδο) σε ένα δεκαδικό ψηφίο.
