# Εισαγωγή

Η Unison αναπαριστά τις αληθείς και ψευδείς τιμές με τον τύπο `Boolean`. Υπάρχουν μόνο δύο τιμές: `true` και `false`.

```unison
trueVariable = true
falseVariable = false
```

Μπορούμε να υπολογίσουμε λογικές εκφράσεις χρησιμοποιώντας τους τελεστές and, or και not, που αναπαρίστανται με `&&`, `||` και `not` αντίστοιχα.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
