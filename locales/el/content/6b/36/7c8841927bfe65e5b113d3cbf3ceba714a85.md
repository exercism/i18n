# Προσθήκη στις οδηγίες

## Υποδείξεις

Πρέπει να υλοποιήσεις τις συναρτήσεις `decode` και `encode`, οι οποίες αποκωδικοποιούν και κωδικοποιούν μια `String` χρησιμοποιώντας ένα κρυπτογράφημα Affine.
Μπορείς να χρησιμοποιήσεις την υπογραφή που σου δίνεται αν δεν είσαι σίγουρος για τους τύπους, αλλά μην αφήσεις να περιορίσει τη δημιουργικότητά σου.

Αυτή η άσκηση δουλεύει με κειμενικά δεδομένα.
Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων.
Για πιο αποδοτικό χειρισμό κειμενικών δεδομένων, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς

- να προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- να κάνεις εισαγωγή του `Data.Text` με [τον παρακάτω τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- να χρησιμοποιήσεις τον τύπο `Text`, π.χ. `decode :: Text -> Text`, και να αναφέρεσαι στους συνδυαστές του `Data.Text` ως π.χ. `T.pack`.
- να ψάξεις την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- να αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο Affine.hs, δηλαδή:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Αυτό το μέρος είναι εντελώς προαιρετικό.
