# Σχετικά

Οι τιμές boolean στη F# αναπαρίστανται από τον τύπο `bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η F# υποστηρίζει τρεις [τελεστές boolean][operators]: τον `not` (NOT), τον `&&` (AND) και τον `||` (OR). Οι τελεστές `&&` και `||` χρησιμοποιούν _αξιολόγηση με βραχυκύκλωμα_, που σημαίνει ότι η δεξιά πλευρά του τελεστή αξιολογείται μόνο όταν χρειάζεται.

```fsharp
true || false // => true
true && false // => false
```

Οι τρεις τελεστές boolean έχουν ο καθένας διαφορετική [_προτεραιότητα τελεστών_][precedence]. Κατά συνέπεια, αξιολογούνται με αυτή τη σειρά: πρώτα ο `not`, μετά ο `&&` και τέλος ο `||`. Αν θέλεις να "ξεφύγεις" από αυτούς τους κανόνες, μπορείς να περικλείσεις μια έκφραση boolean σε παρενθέσεις (`()`), καθώς οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```fsharp
not true && false   // => false
not (true && false) // => true
```

[precedence]: https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/#operator-precedence
