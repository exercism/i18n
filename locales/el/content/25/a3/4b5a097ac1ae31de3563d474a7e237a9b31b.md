## Εκτέλεση των tests

1. Πήγαινε στη ρίζα του φακέλου της άσκησής σου στην PHP, που είναι το `<EXERCISM_WORKSPACE>/php`.
   Για να βρεις τον χώρο εργασίας σου στο Exercism, τρέξε

   ```shell
   exercism workspace
   ```

2. Εγκατέστησε το [PHPUnit] αν δεν το έχεις ήδη.
3. Εκτέλεσε τα tests με:

   ```shell
   phpunit test_file.php
   ```

   Για παράδειγμα, για να τρέξεις τα tests της άσκησης Hello World, θα έτρεχες:

   ```shell
   phpunit HelloWorldTest.php
   ```

[PHPUnit]: https://exercism.org/docs/tracks/php/installation#h-via-php-archive-phar
