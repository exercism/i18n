# Οδηγίες

Σε αυτή την άσκηση θα δημιουργείς αναφορές καιρού για έναν τοπικό σταθμό ειδήσεων.

## Δημιουργία αναφορών καιρού

Θα ξεκινήσεις με κάποιες συναρτήσεις που δεν έχουν ακόμη υλοποιηθεί και με το παρακάτω enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum WeatherCondition {
    Sunny,
    Rainy,
    Cloudy,
    Stormy
}
```

Θα χρειαστεί να μορφοποιήσεις μια αναφορά καιρού όπως η `"Today is <CONDITION> with a temperature of <TEMPERATURE> degrees Celsius."`.
Θα χρειαστεί να υλοποιήσεις τη συνάρτηση που παράγει τη σωστή αναφορά καιρού.

Για παράδειγμα, το παρακάτω απόσπασμα δείχνει μια αναμενόμενη έξοδο για τη συνάρτηση `get_weather_report` για μια "βροχερή" μέρα.

```rust
get_weather_report(WeatherCondition::Rainy, "25")
// Returns: "Today is RAINY with a temperature of 25 degrees Celsius."
```

Και για μια "ηλιόλουστη" μέρα:

```rust
get_weather_report(WeatherCondition::Sunny, "30")
// Returns: "Today is SUNNY with a temperature of 30 degrees Celsius."
```
