# Οδηγίες

Συνεργάζεσαι με μια ομάδα ανάπτυξης ιστού για τη συντήρηση της ιστοσελίδας μιας τοπικής ομάδας μπάσκετ. Η ομάδα ανάπτυξης ιστού δεν είναι πολύ εξοικειωμένη με την Elixir και ζητάει μια συνάρτηση που να μπορεί να εξάγει δεδομένα από μια σειρά εμφωλευμένων maps, ώστε να διευκολυνθεί η γρήγορη ανάπτυξη.

## 1. Εξαγωγή δεδομένων από μια εμφωλευμένη δομή από maps

Υλοποίησε τη συνάρτηση `extract_from_path/2`, η οποία δέχεται δύο ορίσματα:

- `data`: μια εμφωλευμένη δομή από maps με δεδομένα για την ομάδα μπάσκετ.
- `path`: μια συμβολοσειρά που αποτελείται από κλειδιά χωρισμένα με τελείες, για να πάρεις την τιμή που σχετίζεται με το τελευταίο κλειδί.

Αν η τιμή ή το κλειδί δεν υπάρχει σε οποιοδήποτε σημείο της διαδρομής, θα πρέπει να επιστρέφεται `nil`

```elixir
data = %{
  "team_mascot" => %{
    "animal" => "bear",
    "actor" => %{
      "first_name" => "Noel"
    }
  }
}

BasketballWebsite.extract_from_path(data, "team_mascot.animal")
# => "bear"
BasketballWebsite.extract_from_path(data, "team_mascot.colors")
# => nil
```

Χρησιμοποίησε το _Access Behaviour_ όταν υλοποιείς αυτή τη συνάρτηση.

Μη χρησιμοποιήσεις συναρτήσεις από τα module `Map` ή `Kernel` για να δουλέψεις με την εμφωλευμένη δομή από maps.

## 2. Αναδιαμόρφωση με χρήση των ενσωματωμένων συναρτήσεων

Ο συνάδελφός σου που ελέγχει τον κώδικά σου σου λέει για μια συνάρτηση του module `Kernel` που κάνει κάτι πολύ παρόμοιο με τη δική σου υλοποίηση.

Υλοποίησε τη `get_in_path/2` ώστε να χρησιμοποιεί αυτή τη συνάρτηση του module `Kernel`.

Τα ορίσματα που περιμένει είναι τα ίδια με αυτά του μέρους 1.

```elixir
BasketballWebsite.get_in_path(data, "team_mascot.actor.first_name")
# => "Noel"
```
