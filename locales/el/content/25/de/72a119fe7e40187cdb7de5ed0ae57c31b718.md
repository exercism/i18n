# Προσθήκη οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | είσοδος     | ακέραιος | x                          |
| `$a1`    | είσοδος     | ακέραιος | y                          |
| `$v0`    | έξοδος    | ακέραιος | κερδισμένοι βαθμοί              |
| `$t0-9`  | προσωρινός | οποιοσδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
