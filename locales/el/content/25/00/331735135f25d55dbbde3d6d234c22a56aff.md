# Σχετικά

Το βασικό πράγμα που πρέπει να θυμάσαι για τις συμβολοσειρές C# είναι ότι είναι αμετάβλητα αντικείμενα που αναπαριστούν κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης, κ.λπ.). Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσουν ένα στιγμιότυπο `string`:

```csharp
string fruit = "Apple";
```

Ο χειρισμός μιας συμβολοσειράς μπορεί να γίνει καλώντας μία από τις [μεθόδους][methods] ή τις [ιδιότητες][properties] της. Επειδή οι τιμές συμβολοσειρών δεν μπορούν ποτέ να αλλάξουν αφού οριστούν, όλες οι μέθοδοι χειρισμού συμβολοσειρών θα επιστρέφουν μια νέα συμβολοσειρά.

Μια συμβολοσειρά περικλείεται από χαρακτήρες διπλών εισαγωγικών (`"`). Κάποιοι ειδικοί χαρακτήρες χρειάζονται [διαφυγή][escaping] χρησιμοποιώντας τον χαρακτήρα backslash (`\`). Οι συμβολοσειρές μπορούν επίσης να έχουν πρόθεμα το σύμβολο at (`@`), που τις κάνει [αυτολεξεί συμβολοσειρά][verbatim] η οποία θα αγνοεί τυχόν διαφευγμένους χαρακτήρες.

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

Αν χρειάζεσαι μόνο ένα μέρος μιας συμβολοσειράς, μπορείς να χρησιμοποιήσεις τη [μέθοδο `Substring()`][substring] για να εξαγάγεις ακριβώς αυτό το μέρος:

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

Η [μέθοδος `IndexOf`()][indexof] μπορεί να χρησιμοποιηθεί για να βρεις τη θέση της πρώτης εμφάνισης μιας συμβολοσειράς μέσα σε μια συμβολοσειρά, επιστρέφοντας `-1` αν η καθορισμένη τιμή δεν βρέθηκε:

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

Τέλος, υπάρχουν [πολλοί τρόποι για να συνενώσεις μια συμβολοσειρά][concatenation]. Ο απλούστερος είναι χρησιμοποιώντας τον [τελεστή `+`][plus-operator].

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Για οποιαδήποτε μορφοποίηση συμβολοσειράς πιο σύνθετη από την απλή συνένωση, προτιμάται η [παρεμβολή συμβολοσειρών][interpolation]. Για να ενεργοποιήσεις την παρεμβολή σε μια συμβολοσειρά, βάλε το σύμβολο του δολαρίου (`$`) μπροστά της.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
