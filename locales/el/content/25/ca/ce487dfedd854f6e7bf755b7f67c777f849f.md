# Σχετικά

Μια παράμετρος rest ορίζεται από τη λέξη-κλειδί `&rest` της λίστας lambda. Αυτή η παράμετρος δεσμεύεται σε μια τιμή που είναι μια λίστα με όλα τα ορίσματα που παρέχει ο καλών και τα οποία δεν καταναλώνονται από άλλες παραμέτρους.

Ενώ πολλοί τύποι παραμέτρων μπορούν να συνδυαστούν με άλλους τύπους παραμέτρων (προαιρετικές παραμέτρους και παραμέτρους keyword), αυτό μπορεί να είναι προβληματικό και καλό είναι να το κάνεις προσεκτικά.
Δες την ενότητα ["Ανάμιξη διαφορετικών τύπων παραμέτρων"][pcl-function] στο Practical Common Lisp.

[pcl-function]: http://www.gigamonkeys.com/book/functions.html
