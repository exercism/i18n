# Εισαγωγή

## Μεταβλητές στιγμιοτύπου

Τα αντικείμενα μπορούν να κρατούν τη δική τους κατάσταση ορίζοντας _μεταβλητές στιγμιοτύπου_.
Αυτές οι μεταβλητές ζουν μέσα σε ένα αντικείμενο και συνήθως χρησιμοποιούνται για να αποθηκεύουν κάποια εσωτερική κατάσταση.

Οι μεταβλητές στιγμιοτύπου ξεκινούν πάντα με ένα `@`.
Μπορείς να δημιουργήσεις μια νέα μεταβλητή στιγμιοτύπου ορίζοντας μια μεταβλητή που ξεκινά με ένα `@`.
Για παράδειγμα:

```ruby
class Repeater
  def hear(something)
    # Save what's been heard into a new instance variable called @heard
    @heard = something
  end

  def repeat
    # Return the value of the instance variable
    @heard
  end
end

repeater = Repeater.new
repeater.hear("Hello, friend!")
print repeater.repeat # Prints "Hello, friend!"
```

Τα αντικείμενα συνήθως ορίζουν την αρχική τους κατάσταση σε μια μέθοδο `initialize`, η οποία καλείται αυτόματα όταν καλείς τη `new` σε μια κλάση.

```ruby
class Airplane
  def initialize
    @wings = 2
  end

  def wings
    @wings
  end
end

plane = Airplane.new
plane.wings # returns 2
```

Η μέθοδος `initialize` μπορεί επίσης να δέχεται ορίσματα, ώστε κάθε στιγμιότυπο να ξεκινά με προσαρμοσμένη κατάσταση:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Είναι καλή πρακτική να θεωρείς τις μεταβλητές _στιγμιοτύπου_ ιδιωτικές, ώστε να μην διαβάζονται και να μην τροποποιούνται από έξω.
Αντ' αυτού, ορίζουμε μεθόδους για να παίρνουμε και να θέτουμε τις τιμές τους.
Για παράδειγμα:

```ruby
class Suitcase
  def initialize
    @locked = false
  end

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def lock! # Methods which mutate state should have trailing `!`
    @locked = true
  end
end

suitcase = Suitcase.new
suitcase.locked? # false
suitcase.lock!
suitcase.locked? # true
```

## Nil

Το [Nil][nil-dictionary] είναι μια αγγλική λέξη που σημαίνει "τίποτα" ή "μηδέν".
Στη Ruby, το `nil` χρησιμοποιείται για να εκφράσει την _απουσία_ ενός αντικειμένου.
Σε άλλες γλώσσες προγραμματισμού, τιμές όπως `null` ή `none` μπορεί να παίζουν παρόμοιο ρόλο.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Η Ruby δίνει σε κάθε μεταβλητή στιγμιοτύπου την προεπιλεγμένη τιμή `nil` όταν τη συναντήσει για πρώτη φορά, μέχρι να της δοθεί κάποια άλλη τιμή.

```ruby
print @favourite_color # prints nil
@favourite_color = "blue"
print @favourite_color # prints "blue"
```

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
