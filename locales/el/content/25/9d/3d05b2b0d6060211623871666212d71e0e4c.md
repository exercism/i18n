# Οδηγίες

Κρατάς καθημερινές μετρήσεις για το πόσα πουλιά επισκέπτονται τον κήπο σου. Τα δεδομένα αποθηκεύονται ως πίνακας ακεραίων, με **πρώτη τη σημερινή μέτρηση**.

## 1. Η σημερινή μέτρηση

Όρισε τη `today` ώστε να παίρνει από τη στοίβα έναν πίνακα με τις καθημερινές μετρήσεις και να επιστρέφει τη σημερινή μέτρηση, ή `f` αν ο πίνακας είναι κενός.

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. Αύξησε τη σημερινή μέτρηση

Όρισε τη `increment-day-count` ώστε να επιστρέφει έναν νέο πίνακα με τη σημερινή μέτρηση αυξημένη κατά ένα. Αν η είσοδος είναι κενή, επέστρεψε `{ 1 }`.

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. Υπήρξε μέρα χωρίς πουλιά;

Όρισε τη `has-day-without-birds?` ώστε να επιστρέφει `t` αν τουλάχιστον μία μέρα κατέγραψε μηδέν πουλιά, αλλιώς `f`.

**Χρησιμοποίησε αναδρομή** αντί για `any?` ή άλλες λέξεις ανώτερης τάξης για ακολουθίες.

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. Σύνολο πουλιών από τότε που ξεκίνησες

Όρισε τη `total` ώστε να επιστρέφει το άθροισμα όλων των μετρήσεων.

**Χρησιμοποίησε αναδρομή** αντί για `sum`.

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. Πολυάσχολες μέρες

Μια πολυάσχολη μέρα είναι αυτή με πέντε ή περισσότερα πουλιά. Όρισε τη `busy-days` ώστε να επιστρέφει τον αριθμό των πολυάσχολων ημερών.

**Χρησιμοποίησε αναδρομή** αντί για `count`.

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
