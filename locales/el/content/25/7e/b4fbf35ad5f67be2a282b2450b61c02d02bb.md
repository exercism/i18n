# Οδηγίες

Όταν οι εξωγήινοι της Lisp πρωτοήρθαν στη Γη, συνάντησαν αμέτρητα παράξενα και θαυμάσια πράγματα, αλλά μία από τις αγαπημένες τους ανακαλύψεις ήταν τα "κατοικίδια". Ας είμαστε ειλικρινείς, ποιος εξωγήινος δεν θα ξετρελαινόταν με ένα κουτάβι ή ένα γατάκι;

Ο Ludwig, μετά τις πρόσφατες διακοπές του στη Γη, αποφάσισε ότι θέλει ένα δικό του κατοικίδιο! Το μόνο πρόβλημα; Πάρα πολλές επιλογές! Ίσως θα μπορούσες να γράψεις ένα πρόγραμμα που θα βοηθήσει τον Ludwig να βρει και να φροντίσει τον επόμενο χαριτωμένο φίλο του;

## 1. Διαλέγοντας ένα φιλαράκι

Αν και ο Ludwig είναι αποφασισμένος να αποκτήσει ένα κατοικίδιο, η σκέψη του δεν έχει προχωρήσει παραπέρα. Το πρώτο βήμα, λοιπόν, είναι να αποφασίσεις τι είδους κατοικίδιο θα πάρει!

Ο Ludwig θέλει να βρει ένα φιλαράκι με προσωπικότητα που να ταιριάζει με τη δική του. Θα μπορούσες να γράψεις για τον Ludwig μια συνάρτηση που λέγεται `pal-picker`, η οποία δέχεται κάποιο χαρακτηριστικό προσωπικότητας (μια λέξη-κλειδί) και επιστρέφει τον τύπο του κατοικιδίου (μια συμβολοσειρά) με το συγκεκριμένο χαρακτηριστικό;

Στη συγκεκριμένη περίπτωση:

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

Για άλλες, άγνωστες προσωπικότητες, η συνάρτησή σου θα πρέπει να αξιολογείται σε: `"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. Στο φυσικό τους περιβάλλον

Τώρα που ο Ludwig έχει έναν νέο φίλο, θα χρειαστεί ένα μέρος για να μείνει! Μπορείς να βοηθήσεις τον Ludwig να διαλέξει το κρεβάτι / ενυδρείο / κλουβί με το σωστό μέγεθος για το κατοικίδιό του;

Εδώ, ο Ludwig χρειάζεται μια συνάρτηση που λέγεται `habitat-fitter`, η οποία επιλέγει το κατάλληλο μέγεθος βιότοπου (μια λέξη-κλειδί) με βάση το βάρος του κατοικιδίου σε κιλά (έναν ακέραιο).

Οι βιότοποι που χρειάζεται κάθε μέγεθος κατοικιδίου είναι:

- Περισσότερο από ή ίσο με 40kg -> `:massive`
- Από 20kg έως 39kg (συμπεριλαμβανομένων) -> `:large`
- Από 10kg έως 19kg (συμπεριλαμβανομένων) -> `:medium`
- Από 1kg έως 9kg (συμπεριλαμβανομένων) -> `:small`
- Λιγότερο από ή ίσο με 0kg -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. Ώρα για φαγητό

Ένα πράγμα που έχουν κοινό όλα τα κατοικίδια της Γης είναι η ανάγκη τους για φαγητό! Αυτή η έννοια είναι κάπως εξωγήινη για τον Ludwig, ωστόσο, αφού έχει την τάση να ξεχνάει να ξαναγεμίσει το μπολ του κατοικιδίου του.

Ο Ludwig θα μπορούσε να χρησιμοποιήσει μια απλή συνάρτηση που λέγεται `feeding-time`, για να τον ειδοποιεί όταν το μπολ χρειάζεται ξαναγέμισμα. Η συνάρτηση θα δέχεται ένα ποσοστό πληρότητας (έναν ακέραιο) και θα επιστρέφει ένα μήνυμα με τη μορφή συμβολοσειράς.

Αν το επίπεδο της τροφής είναι:

- Πάνω από 20% -> `"All is well."`
- 20% ή λιγότερο -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. Κώδικας συμπεριφοράς

Με όλα τα βασικά τακτοποιημένα, ο Ludwig ανυπομονεί να δοκιμάσει μια σειρά από συναρπαστικά πράγματα, όπως το "χάιδεμα" και το παιχνίδι "fetch". Παρόλα αυτά, δεν είναι κατάλληλο κάθε κατοικίδιο για αυτές τις δραστηριότητες.

Ο Ludwig θα ήθελε ένα ζευγάρι συναρτήσεων, τις `pet` και `play-fetch`, που δέχονται τον τύπο του κατοικιδίου (ως συμβολοσειρά) και επιστρέφουν είτε τίποτα είτε ένα μήνυμα σαν αυτό: `"Maybe not with this pet..."`, αν η ενέργεια δεν ταιριάζει.

Θεώρησε ότι μόνο τα `"Dog"` παίζουν fetch και ότι όλα τα κατοικίδια εκτός από `"Fish"` μπορούν να χαϊδευτούν.

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
