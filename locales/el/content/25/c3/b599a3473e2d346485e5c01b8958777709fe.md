# Εισαγωγή στη χρήση εισαγωγικών

Μια συμβουλή που θα ακούν ξανά και ξανά οι νέοι προγραμματιστές bash:

> Βάλε εισαγωγικά στις μεταβλητές σου!

Γιατί συμβαίνει αυτό;

Όταν κάνεις επέκταση σε μια μεταβλητή (όπως `$name`), σχεδόν πάντα θέλεις να χρησιμοποιήσεις την _τιμή_ της μεταβλητής ως μία μόνο συμβολοσειρά (ή αριθμό).
Δεν θέλεις η τιμή να αντιμετωπιστεί αναπάντεχα ως δύο ή περισσότερες ξεχωριστές συμβολοσειρές.

## Η χρήση εισαγωγικών

Η χρήση εισαγωγικών είναι ο βασικός μηχανισμός που εξασφαλίζει ότι ένα κομμάτι κειμένου αντιμετωπίζεται ως μία μόνο λέξη.
Υπάρχουν δύο βασικοί τύποι εισαγωγικών.

### Διπλά εισαγωγικά

Τα διπλά εισαγωγικά επιτρέπουν μέσα τους την επέκταση παραμέτρων, την αριθμητική επέκταση και την υποκατάσταση εντολών.

```bash
echo "This is bash version $BASH_VERSION"
```

Μπορείς να συμπεριλάβεις ένα κυριολεκτικό διπλό εισαγωγικό μέσα σε μια συμβολοσειρά με διπλά εισαγωγικά, βάζοντας μπροστά του ένα backslash.

```bash
echo "She said \"Let me teach you about bash.\""
```

### Μονά εισαγωγικά

Τα μονά εισαγωγικά _δεν επιτρέπουν_ καμία επέκταση μέσα τους.

```bash
echo 'This is bash version $BASH_VERSION'
# ...^..................................^
# prints exactly: This is bash version $BASH_VERSION
```

Δεν είναι _δυνατόν_ να ενσωματώσεις ένα μονό εισαγωγικό μέσα σε μια συμβολοσειρά με μονά εισαγωγικά.

## Η σημασία της χρήσης εισαγωγικών

Τι ακριβώς είναι λάθος με το `echo $name`;

Όταν το κέλυφος αναλύει μια γραμμή κώδικα, εκτελεί [διάφορα είδη επεκτάσεων][expansions], με συγκεκριμένη σειρά.
Δύο από τις τελευταίες επεκτάσεις είναι η _κατάτμηση σε λέξεις_ και η _επέκταση ονομάτων αρχείων_.

### Κατάτμηση σε λέξεις

Οποιαδήποτε αποτελέσματα επέκτασης παραμέτρων, υποκατάστασης εντολών ή αριθμητικής επέκτασης _που δεν προέκυψαν μέσα σε διπλά εισαγωγικά_ είναι υποψήφια για κατάτμηση σε λέξεις.
Το κέλυφος παίρνει το αποτέλεσμα της επέκτασης και το χωρίζει σε οποιαδήποτε ακολουθία χαρακτήρων υπάρχει στην τιμή του `$IFS`.
Από προεπιλογή, αυτά είναι το διάστημα, το tab και η αλλαγή γραμμής.

Μπορούμε να το δούμε σε δράση με έναν βρόχο του κελύφους:

```bash
sentence="The quick brown fox jumps."
i=0
for word in "$sentence"; do echo "$((++i)) $word"; done
# ..........^.........^
```
παράγει
```none
1 The quick brown fox jumps.
```

Αλλά χωρίς εισαγωγικά:

```bash
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
παράγει
```none
1 The
2 quick
3 brown
4 fox
5 jumps.
```

Ας το δούμε με διαφορετική τιμή του `$IFS`:

```bash
csv="first,second,third"
IFS=","
for word in $csv; do echo "$word"; done
```
παράγει
```none
first
second
third
```

#### Απενεργοποίηση της κατάτμησης σε λέξεις

Μια τεχνική για να απενεργοποιήσεις την κατάτμηση σε λέξεις είναι να ορίσεις το `$IFS` σε μια κενή συμβολοσειρά

```bash
sentence="The quick brown fox jumps."
IFS=    # or explicitly, IFS=""
i=0
for word in $sentence; do echo "$((++i)) $word"; done
# .........^.........^
```
παράγει
```none
1 The quick brown fox jumps.
```

Ωστόσο, δεν συνιστάται να αφήνεις τις μεταβλητές χωρίς εισαγωγικά, εκτός αν απενεργοποιήσεις και την επέκταση ονομάτων αρχείων.
Θα δούμε πώς γίνεται αυτό παρακάτω.

### Επέκταση ονομάτων αρχείων

Τα πρότυπα "glob" χρησιμοποιούνται για να εκφράσουν ένα συνοπτικό μοτίβο που ταιριάζει με ένα σύνολο αρχείων.
Για παράδειγμα, μπορείς να ταιριάξεις όλα τα αρχεία Markdown σε έναν κατάλογο με το `*.md`.
Τα [πρότυπα glob][glob] υπάρχουν από την εφεύρεση του Unix.

Οι χαρακτήρες μπαλαντέρ του glob είναι:

* `*` ταιριάζει με μηδέν ή περισσότερα από οποιονδήποτε χαρακτήρα,
* `?` ταιριάζει με ακριβώς έναν οποιονδήποτε χαρακτήρα,
* `[...]` ταιριάζει με ακριβώς έναν χαρακτήρα από το σύνολο χαρακτήρων που αναγράφονται μέσα στις αγκύλες.

   ~~~~exercism/advanced
   <details><summary>
   Υπάρχουν πολλές λεπτομέρειες σχετικά με τα σύνολα χαρακτήρων.
   Κάνε κλικ εδώ για να τις δεις.
   </summary>

    * `[abc]` ταιριάζει με ακριβώς έναν χαρακτήρα που είναι είτε `a` είτε `b` είτε `c`.
        * για να συμπεριλάβεις μια κυριολεκτική κλειστή αγκύλη στην έκφραση, βάλ' την ως πρώτο χαρακτήρα μετά την αγκύλη ανοίγματος (μετά από ένα προαιρετικό `^`)
            * το `[][]` είναι ένα σύνολο χαρακτήρων που ταιριάζει είτε με κλειστή είτε με ανοιχτή αγκύλη.
            * ή κάνε escape με ένα backslash: `[[\]]`
    * `[x-y]` ταιριάζει με ακριβώς έναν χαρακτήρα που βρίσκεται στο _εύρος_ από το `x` έως το `y`
        * για να συμπεριλάβεις έναν κυριολεκτικό χαρακτήρα παύλας σε ένα σύνολο χαρακτήρων, πρέπει να είναι είτε ο πρώτος χαρακτήρας μετά την αγκύλη ανοίγματος (μετά από ένα προαιρετικό `^`) είτε ο τελευταίος χαρακτήρας πριν την αγκύλη κλεισίματος.
            * το `[-xy]` ή το `[xy-]` ταιριάζουν το καθένα με ακριβώς έναν χαρακτήρα που είναι `-` ή `x` ή `y`
            * ή κάνε escape με ένα backslash: `[x\-y]`
        * μπορούν να οριστούν πολλά εύρη, για παράδειγμα το `[0-9A-Fa-f]` ταιριάζει με ένα δεκαεξαδικό ψηφίο
    * `[^abc]` ταιριάζει με ακριβώς έναν χαρακτήρα που **ΔΕΝ** είναι `a` ή `b` ή `c`,
    * `[^x-y]` ταιριάζει με ακριβώς έναν χαρακτήρα που **ΔΕΝ** βρίσκεται στο εύρος από το `x` έως το `y`
    * `[[:character_class:]]` ταιριάζει με έναν χαρακτήρα που ανήκει στην ονομαζόμενη "character_class"
        * οι διαθέσιμες κλάσεις χαρακτήρων είναι:
            * `lower` -- πεζά γράμματα
            * `upper` -- κεφαλαία γράμματα
            * `alpha` -- γράμματα
            * `digit` -- ψηφία
            * `alnum` -- γράμματα και ψηφία
            * `space` -- κενά διαστήματα
            * `blank` -- οριζόντια κενά διαστήματα (διάστημα και tab)
            * `xdigit` -- δεκαεξαδικά ψηφία
            * `word` -- χαρακτήρες που επιτρέπονται σε ένα αναγνωριστικό (γράμματα, αριθμοί, κάτω παύλα)
            * `punct` -- σημεία στίξης
            * `cntrl` -- χαρακτήρες ελέγχου
            * `graph` -- "ορατοί" χαρακτήρες
            * `print` -- ορατοί χαρακτήρες συν το διάστημα
        * μπορούν να συνδυαστούν:
            * η κλάση `[[:alpha:]]` αποτελείται από τις `[[:lower:][:upper:]]`
            * η κλάση `[[:alnum:]]` αποτελείται από τις `[[:alpha:][:digit:]]`
            * η κλάση `[[:word:]]` αποτελείται από τις `[[:alnum:]_]`
            * η κάτω παύλα (οκταδικό 137) είναι και `[[:word:]]` και `[[:punct:]]`
            * η κλάση `[[:graph:]]` αποτελείται από τις `[[:alnum:][:punct:]]`
            * η κλάση `[[:print:]]` αποτελείται από τις `[[:graph:] ]` -- μόνο το διάστημα (οκταδικό 040) και κανένα άλλο κενό διάστημα.
   </details>
   ~~~~

#### Επανάληψη πάνω από μια λίστα αρχείων

Μπορείς να επαναλάβεις πάνω από μια λίστα αρχείων με έναν `for` βρόχο

```bash
for file in *.csv; do
    do_something_with "$file"
done
```

Πρόσεξε ότι η μεταβλητή `"$file"` είναι μέσα σε εισαγωγικά.
Το πρότυπο glob μπορεί να επιστρέψει αρχεία που περιέχουν κενά στο όνομά τους.
Πρέπει να βάλουμε τη μεταβλητή σε εισαγωγικά, ώστε η εντολή `do_something_with` να λάβει ακριβώς ένα όρισμα, το όνομα του αρχείου.

#### Τα πρότυπα glob δεν είναι κανονικές εκφράσεις

Τα πρότυπα glob **δεν είναι** κανονικές εκφράσεις.

* ταιριάζει με ακριβώς έναν χαρακτήρα
   * regex `.`
   * glob `?`
* ταιριάζει με μηδέν ή περισσότερους χαρακτήρες
   * regex `.*`
   * glob `*`
        * το πρότυπο glob `.*` σημαίνει "ταιριάξε ένα όνομα αρχείου όπου ο πρώτος χαρακτήρας είναι μια κυριολεκτική τελεία ακολουθούμενη από μηδέν ή περισσότερους οποιουσδήποτε χαρακτήρες".
* ταιριάζει με έναν ή περισσότερους χαρακτήρες
   * regex `.+`
   * glob `?*`
* τα σύνολα χαρακτήρων του regex και τα σύνολα χαρακτήρων του glob συμπεριφέρονται με τον ίδιο τρόπο.

#### Εισαγωγικά και επέκταση ονομάτων αρχείων

Υπάρχουν φορές που θέλεις να καταστείλεις την επέκταση ονομάτων αρχείων.
Μια τέτοια περίπτωση είναι ο χειρισμός εισόδου από τον χρήστη.
Σκέψου αυτό το απόσπασμα κώδικα

```bash
read -p "Enter something: " user_input
echo $user_input
```

Αν ο χρήστης εισάγει έναν αστερίσκο (`*`), τι θα τυπωθεί;
Η λίστα των αρχείων στον τρέχοντα κατάλογο.
Αυτό μάλλον δεν είναι αυτό που θέλεις να κάνεις.

Ένα άλλο παράδειγμα είναι να περάσεις πρότυπα ως ορίσματα σε προγράμματα που περιμένουν πρότυπα.
Το πρόγραμμα `tr` χρησιμοποιείται συχνά για την επεξεργασία κειμένου. Για να μετατρέψεις μια τιμή μεταβλητής σε πεζά, μπορείς να κάνεις το εξής

```bash
var="My Puppet"
echo "$var" | tr '[:upper:]' '[:lower:]'
```
παράγει
```none
my puppet
```

Ένα συνηθισμένο λάθος είναι να ξεχάσεις να βάλεις τα ορίσματα του `tr` σε εισαγωγικά: `tr [:upper:] [:lower:]`

~~~~exercism/caution
Γιατί είναι πρόβλημα αυτό;
Τα πρότυπα glob χωρίς εισαγωγικά θα επεκταθούν στη λίστα των αρχείων που ταιριάζουν.
Ας υποθέσουμε ότι αυτός που χρησιμοποιεί το σενάριό σου έχει αρχεία με ονόματα `p` και `u` και `w` στον τρέχοντα κατάλογο:

```bash
touch p u w
var="My Puppet"
echo "$var" | tr [:upper:] [:lower:]
```

Αυτό οδηγεί σε σφάλμα!

Το πρότυπο `[:upper:]` χωρίς εισαγωγικά ταιριάζει με οποιοδήποτε από τα `:`, `u`, `p`, `e` ή `r`.
Το πρότυπο `[:lower:]` χωρίς εισαγωγικά ταιριάζει με οποιοδήποτε από τα `:`, `l`, `o`, `w`, `e` ή `r`.
Το Bash ταιριάζει τα αρχεία `p` και `u` για το πρώτο πρότυπο και το αρχείο `w` για το δεύτερο πρότυπο, και το `tr` καλείται ως εξής

```bash
echo "$var" | tr p u w
```

Και αυτός είναι λάθος αριθμός ορισμάτων για το `tr`.
~~~~

#### Απενεργοποίηση της επέκτασης ονομάτων αρχείων

Μπορείς να χρησιμοποιήσεις την εντολή [`set`][set] για να απενεργοποιήσεις την επέκταση ονομάτων αρχείων.

```bash
echo *      # prints a list of files
set -f      # disable filename expansion
echo *      # prints a literal asterisk
set +f      # enable filename expansion
```

#### Έλεγχος της επέκτασης ονομάτων αρχείων

Υπάρχουν αρκετές ρυθμίσεις για την ενσωματωμένη εντολή [`shopt`][shopt] που ελέγχουν τον τρόπο λειτουργίας της επέκτασης ονομάτων αρχείων.
Μερικές ενδιαφέρουσες είναι:

* `shopt -s nocaseglob` -- εκτελεί αντιστοίχιση χωρίς διάκριση πεζών και κεφαλαίων
* `shopt -s extglob` -- ενεργοποιεί τα εκτεταμένα πρότυπα
* `shopt -s nullglob` -- αν δεν ταιριάζει κανένα αρχείο, αντικαθιστά το πρότυπο με τίποτα.
   Η προεπιλεγμένη συμπεριφορά είναι να αφήνει το πρότυπο στη θέση του ως κυριολεκτική συμβολοσειρά.
