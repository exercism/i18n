# Εισαγωγή στον χειρισμό bit

Η Java έχει τελεστές για τον χειρισμό των bit σε `byte`, `short`, `int`, `long` ή `char`.

## Τελεστές ολίσθησης

Χρησιμοποίησε τον `<<` για ολίσθηση των bit προς τα αριστερά και τον `>>` για ολίσθηση προς τα δεξιά.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

Ο τελεστής `<<` εισάγει πάντα μηδενικά στη δεξιά πλευρά.
Ωστόσο, ο `>>` εισάγει το ίδιο bit με το αριστερότερο bit (1 αν ο αριθμός είναι αρνητικός ή 0 αν είναι θετικός).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Χρησιμοποίησε τον `>>>` αντ' αυτού όταν, κατά την ολίσθηση προς τα δεξιά, θέλεις να εισάγονται μηδενικά.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## Πράξεις σε επίπεδο bit

### AND σε επίπεδο bit

Ο τελεστής AND σε επίπεδο bit (`&`) παίρνει δύο τιμές και εκτελεί μια πράξη AND σε κάθε bit.
Συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν είναι και τα δύο 1, τότε το bit του αποτελέσματος είναι 1.
Διαφορετικά, το bit του αποτελέσματος είναι 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### OR σε επίπεδο bit

Ο τελεστής OR σε επίπεδο bit (`|`) παίρνει δύο τιμές και εκτελεί μια πράξη OR σε κάθε bit.
Συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν τουλάχιστον ένα από τα δύο bit είναι 1, το bit του αποτελέσματος είναι 1.
Διαφορετικά, είναι 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### XOR σε επίπεδο bit

Ο τελεστής XOR σε επίπεδο bit (`^`) εκτελεί μια πράξη XOR bit προς bit σε δύο τιμές.
Όπως και οι τελεστές AND και OR σε επίπεδο bit, συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν μόνο ένα από τα δύο bit είναι 1, το bit του αποτελέσματος είναι 1.
Διαφορετικά, είναι 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### NOT σε επίπεδο bit (`~`)

Τέλος, ο τελεστής NOT σε επίπεδο bit (`~`) αντιστρέφει κάθε bit.
Σε αντίθεση με τους προηγούμενους τελεστές, αυτός είναι μονομελής τελεστής και δρα σε μία μόνο τιμή.

```java
~0b0110_0101;
// # => 0b1001_1010
```
