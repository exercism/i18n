# Λίστες

Το `LIST{T}` είναι μια διατεταγμένη συλλογή που μεγαλώνει, με έναν πίνακα από πίσω που αντικαθίσταται από έναν μεγαλύτερο όταν γεμίσει.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## Πίνακας ή λίστα;

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| μέγεθος | σταθερό από τη δημιουργία | αλλάζει |
| προσθήκη | όχι | ναι |
| αφαίρεση | όχι | ναι |
| πρόσβαση κατά θέση | `a[i]` | `l[i]` |
| επιβάρυνση | καμία | ένα μέγεθος και ελεύθερος χώρος |

Χρησιμοποίησε `ARRAY` όταν το μέγεθος είναι γνωστό και οριστικό: μια σειρά χορευτών, μια εβδομάδα μετρήσεων. Χρησιμοποίησε `LIST` όταν τα πράγματα έρχονται και φεύγουν.

## Επί τόπου, όχι συναρτησιακά

Τα `append`, `remove_index` και `[i] :=` αλλάζουν την ίδια τη λίστα. Δεν χρειάζεται να εκχωρήσεις τίποτα πίσω, και μια λίστα που δίνεις σε μια ρουτίνα δεν είναι ασφαλής από αυτό.

Αυτό είναι το αντίθετο των `FMAP` και `FSET`, και αξίζει να έχεις ξεκάθαρο ποιο κρατάς. Ο κανόνας: το `F` στην αρχή του ονόματος σημαίνει συναρτησιακό, και όλα τα υπόλοιπα αλλάζουν επί τόπου.

Για να δώσεις μια λίστα που τίποτα δεν μπορεί να χαλάσει, δώσε ένα αντίγραφο:

```sather
   return notes.copy;
```

## Το κόστος της προσθήκης

Η προσθήκη είναι φθηνή κατά μέσο όρο. Όταν ο πίνακας από πίσω γεμίσει, παίρνεται ένας νέος, διπλάσιου μεγέθους, και τα πάντα αντιγράφονται. Έτσι οι περισσότερες προσθήκες δεν κοστίζουν σχεδόν τίποτα και κάποιες σπάνιες κοστίζουν ένα αντίγραφο. Σε πολλές προσθήκες αυτό βγαίνει κατά μέσο όρο σταθερό κόστος για την καθεμία, γι' αυτό γίνεται ο διπλασιασμός αντί να μεγαλώνει κατά ένα κάθε φορά.

Το `remove_index` δεν είναι φθηνό: τα πάντα μετά τη θέση που αφαιρέθηκε μετακινούνται κατά μία προς τα πάνω. Η επανειλημμένη αφαίρεση από την αρχή μιας μεγάλης λίστας είναι αργή με τρόπο που εύκολα περνά απαρατήρητος.

## Χρήσιμες ρουτίνες

| Κλήση | Τι κάνει |
| --- | --- |
| `l.append(x)` | προσθέτει στο τέλος |
| `l.insert_before(i, x)` | προσθέτει σε μια θέση |
| `l.remove_index(i)` | βγάζει μια θέση |
| `l.has(x)` | είναι μέσα; |
| `l.copy` | ένα ανεξάρτητο αντίγραφο |
| `l.str` | τα περιεχόμενα, μέσα σε άγκιστρα |
| `l.elt!`, `l.ind!` | διατρέχουν τις τιμές ή τις θέσεις |
