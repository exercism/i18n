# Εισαγωγή

Ενώ η Swift έχει πολλούς διαφορετικούς τύπους, καθένας από αυτούς τους τύπους ανήκει σε μία από δύο διαφορετικές κατηγορίες, τους _τύπους τιμών_ και τους _τύπους αναφοράς_. Στη Swift, οι δομές είναι τύποι τιμών, ενώ οι κλάσεις είναι τύποι αναφοράς.

Η κύρια διαφορά μεταξύ τύπων τιμών και τύπων αναφοράς είναι ότι, όταν οι τύποι τιμών εκχωρούνται σε μια μεταβλητή ή σταθερά, ή όταν περνιούνται σε μια συνάρτηση, αυτό που εκχωρείται ή περνιέται είναι στην πραγματικότητα ένα αντίγραφο της τιμής, όχι η ίδια η τιμή. Η τροποποίηση ενός αντιγράφου μιας δομής δεν θα επηρεάσει τα άλλα αντίγραφα. Με τους τύπους αναφοράς, αυτό που εκχωρείται ή περνιέται είναι μια αναφορά στην τιμή, οπότε δύο διαφορετικά ονόματα μπορούν να αναφέρονται στο ίδιο στιγμιότυπο μιας κλάσης. Αυτό μπορεί να οδηγήσει σε τροποποίηση του αρχικού στιγμιότυπου όταν σε αυτό γίνεται προσπέλαση με διαφορετικό όνομα.
