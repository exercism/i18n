# Εισαγωγή

Οι `Complex numbers` δεν είναι περίπλοκοι.
Χρειάζονται απλώς ένα λιγότερο τρομακτικό όνομα.

Είναι τόσο χρήσιμοι, ειδικά στη μηχανική και τις επιστήμες, που η Julia τους συμπεριλαμβάνει ως τυπικούς αριθμητικούς τύπους, δίπλα στους ακέραιους και τους αριθμούς κινητής υποδιαστολής.

## Τα βασικά

Μια τιμή `complex` στη Julia είναι ουσιαστικά ένα ζεύγος αριθμών: συνήθως, αλλά όχι πάντα, κινητής υποδιαστολής.
Αυτά ονομάζονται "πραγματικό" και "φανταστικό" μέρος, για άτυχους ιστορικούς λόγους.
Και πάλι, το καλύτερο είναι να επικεντρωθείς στην υποκείμενη απλότητα και όχι στα περίεργα ονόματα.

Για να δημιουργήσεις μιγαδικούς αριθμούς από δύο πραγματικούς αριθμούς, αρκεί να προσθέσεις το επίθεμα `im` στο φανταστικό μέρος.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

Έτσι, υπάρχουν διάφοροι τύποι `Complex`, που προέρχονται από τον αντίστοιχο ακέραιο τύπο ή τύπο κινητής υποδιαστολής.

Για να δημιουργήσεις έναν μιγαδικό αριθμό από πραγματικές μεταβλητές, η παραπάνω σύνταξη δεν θα δουλέψει.
Γράφοντας `a + bim` μπερδεύεις τον συντακτικό αναλυτή, που νομίζει ότι το `bim` είναι όνομα (ανύπαρκτης) μεταβλητής.

Το `b*im` είναι δυνατό, αλλά ο προτιμότερος τρόπος χρησιμοποιεί τη συνάρτηση `complex()`, που αποφεύγει τις πράξεις του πολλαπλασιασμού και της πρόσθεσης.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

Για να προσπελάσεις τα μέρη ενός μιγαδικού αριθμού ξεχωριστά:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

Ή και τα δύο μαζί:

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

Οποιοδήποτε από τα δύο μέρη μπορεί να είναι μηδέν, και τότε οι μαθηματικοί μπορεί να πουν ότι ο αριθμός είναι "εντελώς πραγματικός" ή "εντελώς φανταστικός".
Ωστόσο, στη Julia παραμένει ένας μιγαδικός αριθμός.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

Μπορεί να έχεις ακούσει ότι "το `i` (ή το `j`) είναι η τετραγωνική ρίζα του -1".

Για την ώρα, το μόνο που σημαίνει αυτό είναι ότι το φανταστικό μέρος, _εξ ορισμού_, ικανοποιεί την ακόλουθη ισότητα:

```julia-repl
julia> 1im * 1im == -1
true
```

Είναι μια απλή ιδέα, αλλά οδηγεί σε ενδιαφέρουσες συνέπειες.

## Αριθμητική

Όλοι οι τυπικοί μαθηματικοί `operators` και οι στοιχειώδεις συναρτήσεις που χρησιμοποιούνται με αριθμούς κινητής υποδιαστολής και ακέραιους λειτουργούν και με μιγαδικούς αριθμούς. Ένα μικρό δείγμα:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## Συναρτήσεις

Υπάρχουν αρκετές συναρτήσεις, εκτός από τις `real()` και `imag()`, που έχουν ιδιαίτερη σχέση με τους μιγαδικούς αριθμούς.

- Η `conj()` απλώς αλλάζει το πρόσημο του φανταστικού μέρους ενός μιγαδικού αριθμού (_από + σε - ή αντίστροφα_).
    - Λόγω του τρόπου που λειτουργεί ο πολλαπλασιασμός μιγαδικών, αυτό είναι πιο χρήσιμο απ' ό,τι ίσως νομίζεις.
- Η `abs(<complex number>)` εγγυάται ότι επιστρέφει έναν πραγματικό αριθμό χωρίς φανταστικό μέρος.
- Η `abs2(<complex number>)` επιστρέφει το τετράγωνο της `abs(<complex number>)`: υπολογίζεται πιο γρήγορα από την `abs()` και είναι συχνά αυτό που χρειάζεται ένας υπολογισμός.
- Η `angle(<complex number>)` επιστρέφει τη γωνία φάσης σε ακτίνια.

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
Μια μερική εξήγηση, για όσους έχουν μαθηματικό μυαλό:

- Η αναπαράσταση `(real, imag)` του `z1` χρησιμοποιεί στην πραγματικότητα καρτεσιανές συντεταγμένες στο μιγαδικό επίπεδο.
- Ο ίδιος μιγαδικός αριθμός μπορεί να αναπαρασταθεί με τον συμβολισμό `(r, θ)`, χρησιμοποιώντας πολικές συντεταγμένες.
- Εδώ, τα `r` και `θ` δίνονται από τις `abs(z1)` και `angle(z1)` αντίστοιχα.

Ορίστε ένα παράδειγμα με κάποιες σταθερές:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

Ο πολικός συμβολισμός `(r, θ)` είναι τόσο χρήσιμος, που υπάρχουν ενσωματωμένες συναρτήσεις, οι `cis` (συντομογραφία του `cos(x) + isin(x)`) και `cispi` (συντομογραφία του `cos(πx) + isin(πx)`), που μπορούν να βοηθήσουν στην πιο αποδοτική κατασκευή του.

Η χρησιμότητα του πολικού συμβολισμού φαίνεται στην κομψή φόρμουλα του Euler, `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`, όπου `|x + iy| = 1`.
Με `|x + iy| = r`, έχουμε τη γενικότερη πολική μορφή `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`.
Σημείωσε ότι η εκθετική μορφή, ειδικότερα, είναι συμπαγής και εύκολη στον χειρισμό.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

Η κατά προσέγγιση ισότητα παραπάνω οφείλεται στο ότι οι συναρτήσεις `cis` και `cispi` μπορούν να δώσουν ωραιότερα αριθμητικά αποτελέσματα, με την `cispi` ειδικά όταν έχουμε ορίσματα που είναι αυθαίρετοι παράγοντες του π (π.χ. ακτίνια!).

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

Παρεμπιπτόντως, αυτό κάνει τους μιγαδικούς αριθμούς πολύ χρήσιμους για την εκτέλεση περιστροφών και ακτινικών μετατοπίσεων σε δύο διαστάσεις.

Για τις περιστροφές, ο μιγαδικός αριθμός `z = x + iy` μπορεί να περιστραφεί κατά γωνία `θ` γύρω από την αρχή των αξόνων με έναν απλό πολλαπλασιασμό: `z * ℯ^(iθ)`.
Σημείωσε ότι τα `x` και `y` εδώ είναι απλώς οι συνήθεις συντεταγμένες στο πραγματικό καρτεσιανό επίπεδο των δύο διαστάσεων, και μια θετική γωνία έχει ως αποτέλεσμα μια *αριστερόστροφη* περιστροφή, ενώ μια αρνητική γωνία έχει ως αποτέλεσμα μια *δεξιόστροφη*.

Εξίσου απλά, μια ακτινική μετατόπιση `Δr` μπορεί να γίνει προσθέτοντάς την στο μέτρο `r` ενός μιγαδικού αριθμού στην πολική μορφή (π.χ. `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
Πρόσεξε πώς το γωνιακό μέρος παραμένει το ίδιο και μόνο το μέτρο, `r`, μεταβάλλεται, όπως αναμενόταν.
