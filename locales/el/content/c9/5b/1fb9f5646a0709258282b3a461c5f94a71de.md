# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | είσοδος   | ακέραιος | έτος προς έλεγχο                                 |
| `$v0`    | έξοδος    | boolean | η είσοδος είναι δίσεκτο έτος (`0` = `false`, `1` = `true`) |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση          |
