## Εισαγωγή

Ένα άρθρωμα συνήθως φορτώνεται με τη λέξη-κλειδί `use`.
Αυτό ταυτόχρονα το φορτώνει και καλεί τη μέθοδο `import` πάνω του, εισάγοντας τυχόν εξαγόμενα σύμβολα.

Τα σύμβολα στον πίνακα `@EXPORT` του πακέτου εισάγονται από προεπιλογή.
Τα σύμβολα στον πίνακα `@EXPORT_OK` του πακέτου πρέπει να εισαχθούν ρητά.

Πριν από την έκδοση `v5.37` της Perl, ένα άρθρωμα έπρεπε να τελειώνει με μια αληθή τιμή (συνήθως `1`) για να δηλώσει ότι το άρθρωμα φορτώθηκε με επιτυχία.
Αυτό δεν είναι απαραίτητο όταν χρησιμοποιείς τη δυνατότητα [`module_true`][module_true].

## Εξαγωγή

Για να εισαχθεί ένα σύμβολο, πρέπει πρώτα να εξαχθεί.
Το άρθρωμα [Exporter][Exporter] περιλαμβάνεται στην Perl και είναι μία από τις πιο βολικές επιλογές για εξαγωγή.

Ορισμός του αρθρώματος:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Χρήση του αρθρώματος:
```perl
use Foo ('bar');

bar();
```

## Pragma

Ένα pragma είναι ένα άρθρωμα που επηρεάζει κάποια πτυχή της συμπεριφοράς της Perl.

Τα pragmas [`strict`][strict] και [`warnings`][warnings] συνιστώνται συνήθως, για να περιορίσουν μη ασφαλείς κατασκευές και να επισημάνουν πιθανά προβλήματα αντίστοιχα.
Το pragma `strict` ενεργοποιείται μαζί με το `use v5.12` ή νεότερο.
Το pragma `warnings` ενεργοποιείται μαζί με το `use v5.35` ή νεότερο.

Το pragma [`feature`][feature] σου επιτρέπει να ενεργοποιήσεις νεότερες και πειραματικές δυνατότητες της Perl.
Όταν στη λέξη-κλειδί `use` δοθεί μια συγκεκριμένη έκδοση της Perl, ενεργοποιεί το σύνολο δυνατοτήτων για εκείνη την έκδοση.

## Βασικά αρθρώματα

Μαζί με το [Exporter][Exporter], η Perl έχει μια μεγάλη ποικιλία από [βασικά αρθρώματα][perl-core-modules] διαθέσιμα προς χρήση.
Κάποια παραδείγματα χρήσιμα για ασκήσεις που μπορεί να συναντήσεις εδώ περιλαμβάνουν τα [List::Util][List::Util], [Time::Piece][Time::Piece] και [Math::BigRat][Math::BigRat].

## CPAN

Εκτός από τα βασικά αρθρώματα, το [CPAN][metacpan] έχει χιλιάδες επιπλέον αρθρώματα που έχει δημιουργήσει η κοινότητα της Perl, διαθέσιμα για εγκατάσταση.
Η διαδρομή Perl χρησιμοποιεί ένα [cpanfile][test-runner-cpanfile] για να εγκαταστήσει μια επιλογή αρθρωμάτων που μπορούν να χρησιμοποιηθούν με τον test runner της Perl του Exercism.
