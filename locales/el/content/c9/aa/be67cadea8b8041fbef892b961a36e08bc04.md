# Προσάρτημα οδηγιών

## Πρότυπο Builder

Σε αυτή την άσκηση θα χρειαστεί να φτιάξεις αρκετά struct χρησιμοποιώντας το `builder pattern`. Με λίγα λόγια, αυτό το πρότυπο σου επιτρέπει να χωρίσεις τη συνάρτηση κατασκευής του struct σου, που περιέχει πολλά ορίσματα, σε αρκετές ξεχωριστές συναρτήσεις. Αυτή η προσέγγιση σου δίνει τη δυνατότητα για συμπαγή αλλά εξαιρετικά ευέλικτη κατασκευή και διαμόρφωση struct. Μπορείς να διαβάσεις περισσότερα γι' αυτό στην [παρακάτω σελίδα](https://doc.rust-lang.org/1.0.0/style/ownership/builders.html).
