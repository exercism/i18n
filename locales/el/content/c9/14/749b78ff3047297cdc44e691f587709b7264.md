# Προτεινόμενοι πόροι μάθησης

Καλώς ήρθες στην εκμάθηση του ColdFusion (CFML)! Η CFML είναι μια δυναμική, χαλαρά τυποποιημένη γλώσσα scripting για την JVM. Έχει δύο διαφορετικούς τύπους αρχείων. Τα αρχεία `.cfm` (ColdFusion markup)_ είναι καθαρά διαδικαστικά και χρησιμοποιούν τη σύνταξη με ετικέτες για να φτιάχνουν HTML μέσω προτύπων. Θα τα χρησιμοποιούσες για τα views αν έχτιζες έναν ιστότοπο:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

Ο άλλος τύπος αρχείου είναι το `.cfc` (ColdFusion Component) και είναι ο τρόπος με τον οποίο δηλώνεις μια κλάση. Τα components χρησιμοποιούνται για επιχειρηματική λογική, μοντέλα και controllers. Αυτά συνήθως χρησιμοποιούν τη σύνταξη script, η οποία μοιάζει με JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
