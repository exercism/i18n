# Τεστ

## Εκτέλεση των τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την παρακάτω εντολή:

```bash
dotnet test
```

Για να τρέχουν τα τεστ αυτόματα κάθε φορά που αλλάζει ένα αρχείο πηγαίου κώδικα, εκτέλεσε την παρακάτω εντολή:

```bash
dotnet watch test
```

## Επίλυση της άσκησης

Για να λύσεις μια άσκηση, πρέπει να περνούν όλα τα τεστ της. Από προεπιλογή, όταν τρέχεις τα τεστ εκτελείται μόνο ένα τεστ (το πρώτο). Αυτό είναι σκόπιμο, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσει μόνο αυτό το ένα τεστ. Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ αφαιρώντας το `Skip = "Remove this Skip property to run this test"` από το χαρακτηριστικό `[Fact]` ή `[Theory]` του τεστ. Όταν ενεργοποιηθούν όλα τα τεστ και η υλοποίησή σου τα περάσει όλα, θα έχεις λύσει την άσκηση!

Για να σε βοηθήσουμε να ξεκινήσεις, κάθε άσκηση έρχεται με ένα αρχείο σκελετικής υλοποίησης. Μπορείς να χρησιμοποιήσεις αυτό το αρχείο ως αφετηρία για να χτίσεις τη λύση σου. Μη διστάσεις να διαγράψεις ή να αλλάξεις αυτό το αρχείο, αν πιστεύεις ότι είναι το σωστό.

## Χρήση πακέτων

Θα πρέπει να μπορείς να λύσεις τις περισσότερες ασκήσεις χωρίς να χρησιμοποιήσεις εξωτερικά πακέτα. Ωστόσο, για τις ασκήσεις όπου θέλεις πραγματικά να χρησιμοποιήσεις ένα εξωτερικό πακέτο, μπορείς να το προσθέσεις στο έργο σου εκτελώντας την παρακάτω εντολή:

```bash
dotnet add package [package-name]
```
