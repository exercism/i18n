# Εγκατάσταση

Ακολούθησε τις οδηγίες για το σύστημά σου στη σελίδα εγκατάστασης στο [golang.org](http://golang.org/doc/install).

## Έκδοση της Go

Αυτή η διαδρομή χρησιμοποιεί τη Go 1.26.

Θα μπορούσες να χρησιμοποιήσεις μια παλαιότερη έκδοση της Go τροποποιώντας το αρχείο `go.mod` κάθε άσκησης και αλλάζοντας τη γραμμή `go 1.26`.
Ωστόσο, τα tests χρησιμοποιούν δυνατότητες που εισήχθησαν στην Go 1.22 και δεν θα λειτουργήσουν χωρίς τροποποίηση με μια παλαιότερη έκδοση.
