# Μετασχηματισμός JSON καυσίμων

## Δήλωση προβλήματος

Κάθε υπάλληλος της ABC Corp λαμβάνει απεριόριστο επίδομα καυσίμων. Οι υπάλληλοι πρέπει να στέλνουν μια καταγραφή κάθε φορά που γεμίζουν τα οχήματά τους. Αυτές οι καταγραφές προστίθενται στο ίδιο αρχείο JSON και υποβάλλονται σε επεξεργασία στο τέλος του μήνα.

Ως μέλος της ομάδας ψηφιακών λειτουργιών, το καθήκον σου είναι να διαβάσεις αυτό το αρχείο JSON και να γράψεις τα αποτελέσματα σε ένα άλλο αρχείο JSON. Το αρχείο εξόδου πρέπει να περιέχει μια καταχώριση για κάθε υπάλληλο με τις ακόλουθες λεπτομέρειες:

- Αριθμός υπαλλήλου
- Αριθμός ανεφοδιασμών καυσίμου
- Συνολικό κόστος καυσίμου
- Συνολικά γαλόνια
- Συνολικά μίλια που διανύθηκαν

Σου δίνονται δύο ορίσματα `string`.

1. Διαδρομή του αρχείου JSON εισόδου.
1. Διαδρομή του αρχείου JSON εξόδου.

Το αρχείο JSON εισόδου περιέχει έναν πίνακα από αντικείμενα JSON. Κάθε αντικείμενο JSON έχει την ακόλουθη μορφή.


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

Το καθήκον σου είναι να μετασχηματίσεις την είσοδο JSON στην ακόλουθη μορφή JSON και να γράψεις το περιεχόμενο στη διαδρομή που σου δίνεται. Το αρχείο εξόδου πρέπει να περιέχει μια καταχώριση για κάθε υπάλληλο, ταξινομημένη σε αύξουσα σειρά κατά `employeeId`.

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## Περιορισμοί

- Αριθμός καταγραφών ανεφοδιασμού `n` στο αρχείο JSON εισόδου:  0 <= n <= 1000
- Αριθμός υπαλλήλων στην εταιρεία: 97
- Η τιμή του καυσίμου είναι ανά γαλόνι
- Καμία καταγραφή ανεφοδιασμού δεν λείπει

## Υποδείξεις

- Χρησιμοποίησε το [`ballerina/io` module](https://lib.ballerina.io/ballerina/io/latest) για να διαβάζεις και να γράφεις αρχεία JSON.
- Μετέτρεψε τις τιμές JSON σε τύπους ειδικούς για την εφαρμογή, ώστε να δουλεύεις με τα δεδομένα με ασφάλεια τύπων. Δες το [παράδειγμα μετατροπής σε τύπο ορισμένο από τον χρήστη](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type) στο Ballerina By Examples (BBE) για πληροφορίες.

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- Η [αποδόμηση καταγραφών](https://ballerina.io/learn/by-example/destructure-records-using-query) μπορεί να σου φανεί χρήσιμη για να μειώσεις τη φλυαρία του κώδικα.

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- Χρησιμοποίησε συναρτήσεις με σώμα έκφρασης για συναρτήσεις με μία μόνο έκφραση. Π.χ. συναρτήσεις που έχουν μόνο την εντολή return.

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
