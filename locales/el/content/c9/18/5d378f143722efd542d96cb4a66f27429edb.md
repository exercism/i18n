# Σχετικά

Οι κανονικές εκφράσεις στη Gleam ακολουθούν την προδιαγραφή **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), όπως συμβαίνει και με άλλες δημοφιλείς γλώσσες όπως η Java, η JavaScript ή η Ruby.

Το άρθρωμα `gleam/regex` προσφέρει συναρτήσεις για εργασία με κανονικές εκφράσεις.

~~~~exercism/note
Αυτή η άσκηση υποθέτει ότι γνωρίζεις ήδη τη σύνταξη των κανονικών εκφράσεων, συμπεριλαμβανομένων των κλάσεων χαρακτήρων, των ποσοδεικτών, των ομάδων και των συλλήψεων.

Αν θέλεις να ανανεώσεις τις γνώσεις σου στις κανονικές εκφράσεις, ρίξε μια ματιά σε μία από αυτές τις πηγές: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Ο πιο συνηθισμένος τρόπος για να δημιουργήσεις κανονικές εκφράσεις είναι με τη συνάρτηση `regex.from_string`.

```gleam
let assert Ok(re) = regex.from_string("test")
```

Η συνάρτηση `regex.from_string` επιστρέφει ένα `Error` αν η σύνταξη της κανονικής έκφρασης δεν είναι έγκυρη, γι' αυτό εδώ έχει χρησιμοποιηθεί ένα let assert, που διασφαλίζει ότι η κανονική έκφραση είναι έγκυρη.

Η συνάρτηση `regex.check` μπορεί να χρησιμοποιηθεί για να ελέγξεις αν μια κανονική έκφραση ταιριάζει με μια συμβολοσειρά.

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## Συλλήψεις

Αν θέλεις να συλλάβεις υποσυμβολοσειρές με μια κανονική έκφραση, μπορείς να χρησιμοποιήσεις τη συνάρτηση `regex.scan` για να πάρεις μια λίστα με τα ταιριάσματα.

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## Τροποποιητές

Η συμπεριφορά μιας κανονικής έκφρασης μπορεί να τροποποιηθεί αν τη δημιουργήσεις με τη συνάρτηση `regex.compile` και περάσεις κάποιες επιλογές.

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
