# Υπερφόρτωση συναρτήσεων

Δύο συναρτήσεις θεωρούνται διακριτές στη Swift αν έχουν διαφορετικό όνομα, _ή_ αν ισχύει οποιοδήποτε από τα παρακάτω:

- Έχουν διαφορετικό αριθμό παραμέτρων
- Οποιεσδήποτε εξωτερικές ετικέτες ορισμάτων είναι διαφορετικές
- Ο τύπος οποιασδήποτε παραμέτρου είναι διαφορετικός

Οι παρακάτω συναρτήσεις θεωρούνται διαφορετικές και μπορούν να οριστούν και να χρησιμοποιηθούν στο ίδιο πρόγραμμα:

```swift
// Original definition
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  // ...
}

// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  // ...
}

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
    // ...
}

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
    // ...
}
```

Οι συναρτήσεις θεωρούνται επίσης διακριτές αν αλλάζει μόνο η τιμή επιστροφής, αν και σε πολλές περιπτώσεις είναι απαραίτητο να δώσεις μια υπόδειξη στον μεταγλωττιστή με τη μορφή σχολιασμού τύπου, ώστε να ξέρει ποια έκδοση της συνάρτησης να καλέσει.
