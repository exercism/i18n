# Εκφράσεις match

Μια έκφραση match αξιολογεί μια τιμή και μια συνθήκη για να επιστρέψει μια έκφραση που θα αξιολογηθεί.
Όπως συμβαίνει και με τον τριαδικό τελεστή, αν η συνθήκη δεν ταιριάξει, η έκφραση επιστροφής δεν αξιολογείται.
Για να ταιριάξει μια συνθήκη, γίνεται ένας έλεγχος ταυτότητας [αυστηρής ισότητας ή `===`].

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

Για να κάνεις έναν έλεγχο ισότητας [`==`], μπορείς να αναδιατάξεις τη συνθήκη:

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

Σε μια έκφραση match, αν δεν ταιριάξει καμία συνθήκη, θα πεταχτεί ένα `UnhandledMatchError`.
