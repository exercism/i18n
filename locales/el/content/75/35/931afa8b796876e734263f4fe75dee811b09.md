# Οδηγίες

Δεδομένων δύο οποιωνδήποτε λιστών `A` και `B`, προσδιόρισε αν:

- Η λίστα `A` είναι ίση με τη λίστα `B`, ή
- Η λίστα `A` περιέχει τη λίστα `B` (η `A` είναι υπερλίστα της `B`), ή
- Η λίστα `A` περιέχεται στη λίστα `B` (η `A` είναι υπολίστα της `B`), ή
- Κανένα από τα παραπάνω δεν ισχύει, οπότε οι λίστες `A` και `B` είναι άνισες

Συγκεκριμένα, η λίστα `A` είναι ίση με τη λίστα `B` αν και οι δύο λίστες έχουν τις ίδιες τιμές με την ίδια σειρά.
Η λίστα `A` είναι υπερλίστα της `B` αν η `A` περιέχει μια υποακολουθία τιμών ίση με τη `B`.
Η λίστα `A` είναι υπολίστα της `B` αν η `B` περιέχει μια υποακολουθία τιμών ίση με την `A`.

Παραδείγματα:

- Αν `A = []` και `B = []` (και οι δύο λίστες είναι κενές), τότε οι `A` και `B` είναι ίσες
- Αν `A = [1, 2, 3]` και `B = []`, τότε η `A` είναι υπερλίστα της `B`
- Αν `A = []` και `B = [1, 2, 3]`, τότε η `A` είναι υπολίστα της `B`
- Αν `A = [1, 2, 3]` και `B = [1, 2, 3, 4, 5]`, τότε η `A` είναι υπολίστα της `B`
- Αν `A = [3, 4, 5]` και `B = [1, 2, 3, 4, 5]`, τότε η `A` είναι υπολίστα της `B`
- Αν `A = [3, 4]` και `B = [1, 2, 3, 4, 5]`, τότε η `A` είναι υπολίστα της `B`
- Αν `A = [1, 2, 3]` και `B = [1, 2, 3]`, τότε οι `A` και `B` είναι ίσες
- Αν `A = [1, 2, 3, 4, 5]` και `B = [2, 3, 4]`, τότε η `A` είναι υπερλίστα της `B`
- Αν `A = [1, 2, 4]` και `B = [1, 2, 3, 4, 5]`, τότε οι `A` και `B` είναι άνισες
- Αν `A = [1, 2, 3]` και `B = [1, 3, 2]`, τότε οι `A` και `B` είναι άνισες
