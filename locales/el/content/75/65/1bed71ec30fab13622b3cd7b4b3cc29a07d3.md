# Entry API

Το entry API είναι συχνά ο πιο ιδιωματικός τρόπος για να χειριστείς τα περιεχόμενα μιας δομής map. Ωστόσο, ασυνήθιστα για τη Rust, δεν έχει επισημοποιηθεί σε trait· είναι απλώς ένα σύνολο τύπων και μεθόδων που υλοποιούνται στους τύπους map της standard library.

Κατά βάση, η μέθοδος `map.entry()` παρέχει ένα `enum`:

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

Η χρησιμότητα προέρχεται από περαιτέρω μεθόδους που υλοποιούνται σε αυτό το `enum`. Για παράδειγμα, αν θέλεις να πάρεις και ενδεχομένως να μεταβάλεις την τιμή για ένα συγκεκριμένο κλειδί, και η προεπιλεγμένη τιμή του τύπου είναι κατάλληλη, μπορείς απλώς να κάνεις:

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

Για εφαρμογές όπως ένας μετρητής, αυτό κάνει τη ζωή πολύ εύκολη:

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

Σε περίπτωση που η προεπιλεγμένη τιμή του τύπου δεν είναι κατάλληλη για την εφαρμογή σου, μπορείς να δώσεις τη δική σου σταθερή προεπιλεγμένη τιμή με το `or_insert`, ή να την υπολογίσεις με το `or_insert_with`.

Σε ορισμένες περιπτώσεις, μπορεί να θέλεις να κάνεις έναν υπολογισμό πάνω σε μια υπάρχουσα τιμή πριν από οποιαδήποτε πιθανή εισαγωγή. Σε αυτές τις περιπτώσεις, το `and_modify` το επιτρέπει. Ωστόσο, αυτή η χρήση είναι κάπως σπάνια. Το `and_modify` χρησιμοποιείται πιο συχνά για να αποφύγεις την ανάγκη αποαναφοράς:

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

Περιστασιακά, είναι επιθυμητό να κάνεις match απευθείας στο entry. Αυτό επιτρέπεται:

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

Για περισσότερες πληροφορίες, δες [`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html) και [`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html).
