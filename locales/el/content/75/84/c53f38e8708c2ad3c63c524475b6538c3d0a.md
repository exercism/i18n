# Οδηγίες

Η Conda Airlines είναι η μεγαλύτερη αεροπορική εταιρεία στον κόσμο του προγραμματισμού, με πάνω από 10.000 πτήσεις την ημέρα!

Αυτή τη στιγμή αναθέτουν όλες τις θέσεις στους επιβάτες με το χέρι· αυτό θα πρέπει να αυτοματοποιηθεί.

Σου έχουν ζητήσει _εσένα_ να δημιουργήσεις λογισμικό που θα αυτοματοποιεί την ανάθεση θέσεων στους επιβάτες.
Απαιτούν το λογισμικό σου να είναι αποδοτικό στη μνήμη και στις επιδόσεις.

## 1. Δημιούργησε γράμματα θέσεων

Η Conda θέλει να δημιουργεί γράμματα θέσεων για τα αεροπλάνα της.
Ένα αεροπλάνο αποτελείται από σειρές θέσεων.
Κάθε σειρά έχει _4 θέσεις_.
Οι θέσεις σε κάθε σειρά ονομάζονται πάντα `A`, `B`, `C` και `D`.
Η πρώτη θέση στη σειρά είναι `A`, η δεύτερη θέση στη σειρά είναι `B`, και ούτω καθεξής.
Αφού φτάσει στο `D`, θα πρέπει να ξεκινά ξανά από το `A`.

Υλοποίησε μια συνάρτηση `generate_seat_letters(<number>)` που δέχεται ένα `int` που περιέχει πόσα γράμματα θέσεων θα δημιουργηθούν.
Η συνάρτηση θα πρέπει τότε να επιστρέφει ένα _iterable_ με γράμματα θέσεων.

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. Δημιούργησε θέσεις

Η Conda θέλει ένα σύστημα που να μπορεί να δημιουργεί έναν δεδομένο αριθμό θέσεων για τα αεροπλάνα της.
Κάθε αεροπλάνο έχει _4 θέσεις_ σε κάθε σειρά.
Οι σειρές ορίζονται με αριθμούς, ξεκινώντας από το `1` και ανεβαίνοντας.
Οι θέσεις θα πρέπει να είναι διατεταγμένες, όπως: `1A`, `1B`, `1C`, `1D`, `2A`, `2B`, `2C`, `2D`, `3A`, `3B`, `3C`, `3D`, ...

Ακολουθεί ένα παράδειγμα:

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|    Σειρά    |  5  | 21  |
| Γράμμα θέσης |  A  |  D  |
|  Αποτέλεσμα  | 5A  | 21D |

Πολλές αεροπορικές εταιρείες δεν έχουν τη _σειρά_ 13 στις πτήσεις τους, λόγω της προληπτικότητας των επιβατών.
Η Conda Airlines ακολουθεί επίσης αυτή τη σύμβαση, οπότε φρόντισε να _μην_ δημιουργείς θέσεις για τη _σειρά_ 13.

Υλοποίησε μια συνάρτηση `generate_seats(<number>)` που δέχεται ένα `int` που περιέχει πόσες θέσεις θα δημιουργηθούν.
Η συνάρτηση θα πρέπει τότε να επιστρέφει ένα _iterable_ με τις θέσεις.

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. Ανάθεσε θέσεις στους επιβάτες

Τώρα που έχεις μια συνάρτηση που δημιουργεί θέσεις, μπορείς να τη χρησιμοποιήσεις για να αναθέσεις θέσεις στους επιβάτες.

Υλοποίησε μια συνάρτηση `assign_seats(<passengers>)` που δέχεται μια `list` με ονόματα επιβατών.
Η συνάρτηση θα πρέπει τότε να επιστρέφει ένα _λεξικό_ με `passenger` ως _κλειδί_ και `seat_number` ως _τιμή_.

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. Κωδικοί εισιτηρίων

Η Conda Airlines θα ήθελε να έχει έναν μοναδικό κωδικό για κάθε εισιτήριο.
Επειδή είναι μια μεγάλη αεροπορική εταιρεία, έχουν πολλές πτήσεις.
Αυτό σημαίνει ότι υπάρχουν πολλές πτήσεις με τον ίδιο αριθμό θέσης.
Θέλουν να δημιουργήσεις ένα σύστημα που συνθέτει ένα μοναδικό εισιτήριο που είναι μια συμβολοσειρά _12_ χαρακτήρων.

Αυτός ο κωδικός ξεκινά με το `assigned_seat` ακολουθούμενο από το `flight_id`.
Το υπόλοιπο του κωδικού συμπληρώνεται με `0s`.

Υλοποίησε μια συνάρτηση `generate_codes(<seat_numbers>, <flight_id>)` που δέχεται μια `list` με `seat_numbers` και μια `string` με τον αριθμό πτήσης.
Η συνάρτηση θα πρέπει τότε να επιστρέφει έναν `generator` που παράγει ένα `ticket_number`.

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
