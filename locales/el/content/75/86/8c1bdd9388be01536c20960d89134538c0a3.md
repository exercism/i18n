# Instructions

Σε αυτή την άσκηση, θα αναπτύξουμε ένα απλό σύστημα ελέγχου για έναν πυρηνικό αντιδραστήρα.

Για να παράξει ο αντιδραστήρας ισχύ, πρέπει να βρίσκεται σε κατάσταση _κρισιμότητας_.
Αν ο αντιδραστήρας βρίσκεται σε κατάσταση μικρότερη της κρισιμότητας, μπορεί να υποστεί ζημιά.
Αν η κατάσταση του αντιδραστήρα ξεπεράσει την κρισιμότητα, μπορεί να υπερφορτωθεί και να οδηγήσει σε τήξη.
Θέλουμε να μειώσουμε τις πιθανότητες τήξης και να διαχειριστούμε σωστά την κατάσταση του αντιδραστήρα.

Οι παρακάτω τρεις εργασίες σχετίζονται όλες με τη συγγραφή κώδικα για τη διατήρηση της ιδανικής κατάστασης του αντιδραστήρα.

## 1. Έλεγξε την κρισιμότητα

Το πρώτο πράγμα που πρέπει να κάνει ένα σύστημα ελέγχου είναι να ελέγξει αν ο αντιδραστήρας βρίσκεται σε ισορροπία κρισιμότητας.
Ένας αντιδραστήρας λέγεται ότι είναι κρίσιμος αν ικανοποιεί τις παρακάτω συνθήκες:

- Η θερμοκρασία είναι μικρότερη από 800 K.
- Ο αριθμός των νετρονίων που εκπέμπονται ανά δευτερόλεπτο είναι μεγαλύτερος από 500.
- Το γινόμενο της θερμοκρασίας και των νετρονίων που εκπέμπονται ανά δευτερόλεπτο είναι μικρότερο από 500000.

Υλοποίησε τη μέθοδο `Reactor.criticality_balanced?` που δέχεται ως παραμέτρους τη `temperature`, μετρημένη σε kelvin, και το `neutrons_emitted`, και επιστρέφει `true` αν ικανοποιούνται οι συνθήκες κρισιμότητας, `false` αν όχι.

```crystal
Reactor.criticality_balanced?(750, 600)
# => true
```

## 2. Προσδιόρισε το εύρος της ισχύος εξόδου

Μόλις ο αντιδραστήρας αρχίσει να παράγει ισχύ, πρέπει να προσδιοριστεί η απόδοσή του.
Η απόδοση μπορεί να ομαδοποιηθεί σε 4 ζώνες:

1. `green` -> απόδοση 80% ή περισσότερο,
2. `orange` -> απόδοση μικρότερη από 80% αλλά τουλάχιστον 60%,
3. `red` -> απόδοση κάτω από 60%, αλλά ακόμη 30% ή περισσότερο,
4. `black` -> απόδοση μικρότερη του 30%.

Η τιμή του ποσοστού μπορεί να υπολογιστεί ως `(generated_power/theoretical_max_power)*100`
όπου `generated_power` = `voltage` \* `current`.
Σημείωσε ότι η τιμή του ποσοστού συνήθως δεν είναι ακέραιος αριθμός, οπότε φρόντισε να χρησιμοποιήσεις
σωστά τις συγκρίσεις `<` και `<=`.

Υλοποίησε τη μέθοδο `Reactor.reactor_efficiency`, με τρεις παραμέτρους: `voltage`, `current` και `theoretical_max_power`.
Αυτή η συνάρτηση θα πρέπει να επιστρέφει τη ζώνη απόδοσης του αντιδραστήρα : "green", "orange", "red" ή "black".

```crystal
Reactor.reactor_efficiency(200,50,15000)
# => "orange"
```

## 3. Μηχανισμός ασφαλείας

Η τελευταία σου εργασία αφορά τη δημιουργία ενός μηχανισμού ασφαλείας για την αποφυγή υπερφόρτωσης και τήξης.
Ο μηχανισμός αυτός θα καθορίζει αν ο αντιδραστήρας βρίσκεται κάτω, στο ή πάνω από το ιδανικό όριο κρισιμότητας.
Η κρισιμότητα μπορεί τότε να αυξηθεί, να μειωθεί ή να σταματήσει με την εισαγωγή (ή την αφαίρεση) ράβδων ελέγχου στον αντιδραστήρα.

Υλοποίησε τη μέθοδο `Reactor.fail_safe()`, που δέχεται 3 παραμέτρους: τη `temperature`, μετρημένη σε kelvin, το `neutrons_produced_per_second` και το `threshold`, και επιστρέφει έναν κωδικό κατάστασης για τον αντιδραστήρα.

- Αν `temperature * neutrons_produced_per_second` < 90% του `threshold`, επέστρεψε κωδικό κατάστασης "LOW"
  που υποδεικνύει ότι πρέπει να αφαιρεθούν ράβδοι ελέγχου για να παραχθεί ισχύς.

- Αν το `temperature * neutrons_produced_per_second` βρίσκεται εντός συν ή πλην 10% του `threshold`
  ο αντιδραστήρας βρίσκεται σε _κρισιμότητα_ και θα πρέπει να επιστραφεί ο κωδικός κατάστασης "NORMAL", που υποδεικνύει ότι ο
  αντιδραστήρας βρίσκεται σε βέλτιστη κατάσταση και οι ράβδοι ελέγχου βρίσκονται σε ιδανική θέση.

- Αν το `temperature * neutrons_produced_per_second` δεν βρίσκεται στα παραπάνω εύρη, ο αντιδραστήρας
  οδηγείται σε τήξη και πρέπει να επιστραφεί ο κωδικός κατάστασης "DANGER" για να τερματιστεί αμέσως η λειτουργία του αντιδραστήρα.

```crystal
temperature = 1000
neutrons_produced_per_second = 30
threshold = 5000
Reactor.fail_safe(temperature, neutrons_produced_per_second, threshold)
# => "DANGER"
```
