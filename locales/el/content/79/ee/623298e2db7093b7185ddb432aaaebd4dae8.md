# Προσάρτηση οδηγιών

## Μορφές εξόδου

Η συνάρτηση `treeFromTraversals` αναμένεται να επιστρέψει ένα αντικείμενο με 3 ιδιότητες:

- `value` Η τιμή του τρέχοντος κόμβου
- `left` Ένα αντικείμενο που περιέχει το αριστερό παιδί του κόμβου
- `right` Ένα αντικείμενο που περιέχει το δεξί παιδί του κόμβου

```javascript
{
    value: 'a',
    left: { value: 'i', left: {}, right: {} },
    right: { value: 'x', left: {}, right: {} },
}
```

Αν το δέντρο είναι κενό, θα πρέπει να επιστραφεί ένα κενό αντικείμενο.
