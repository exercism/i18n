# Σχετικά

Στη Common Lisp, οι ψευδείς τιμές αναπαρίστανται από την κενή λίστα (`()`) ή το σύμβολο `nil`. Αυτές οι τιμές μπορούν να παρατεθούν ή να μην παρατεθούν.

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Όλες οι άλλες τιμές στη Lisp αντιπροσωπεύουν την αλήθεια.
Υπάρχει επίσης το ειδικό σταθερό σύμβολο `t` που είναι πάντα ίσο με το `t` (και επομένως είναι πάντα αληθές).

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
