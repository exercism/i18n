# Οδηγίες

Γεια σου και πάλι, Πράκτορα Double-Null0111.

Οι δυνάμεις της UMBRA ξαναχτυπούν, και εξαρτάται από εσένα να ματαιώσεις το τελευταίο τους σχέδιο.
Η υπηρεσία πληροφοριών μας μάς ενημερώνει ότι αυτά τα Minions σχεδιάζουν να πυροδοτήσουν μια βομβίδα βρώμας στον χορό του Κυβερνήτη.

Επειδή τα Minions είναι τόσο αδέξια, συχνά οπλίζουν κατά λάθος τις βομβίδες βρώμας στα εργαστήρια και τα γραφεία τους.
Και επειδή συνεχώς ξεχνούν πώς να απενεργοποιήσουν τις βομβίδες βρώμας τους, έχουν υλοποιήσει ένα σύστημα που δημιουργεί τις οδηγίες απενεργοποίησης, οι οποίες αναφέρουν τη σειρά με την οποία πρέπει να κοπούν τα καλώδια με βάση τον αριθμό ID της βομβίδας.

Η δουλειά σου είναι να γράψεις τον κώδικα που θα σου επιτρέψει να απενεργοποιήσεις τη βομβίδα βρώμας στον χορό πριν εκραγεί.

## 1. Γράψε ένα closure που αντιστρέφει δύο καλώδια

Κάθε βομβίδα βρώμας έχει τρία καλώδια με διαφορετικά χρώματα.
Γράψε ένα closure που παίρνει μια πλειάδα `(String, String, String)` και επιστρέφει την πλειάδα με αντεστραμμένη τη σειρά των δύο πρώτων στοιχείων.
Ανάθεσε αυτό το closure στο όνομα `flip`.

Είναι σημαντικό να σημειώσεις ότι ο τύπος πρέπει να είναι ο `ChangeClosure` (ή κάποιος sendable τύπος), ο ορισμός του τύπου δίνεται στο αρχείο stub.
Διαφορετικά, ο κώδικας δεν θα μεταγλωττιστεί.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Γράψε ένα closure που περιστρέφει τα καλώδια

Γράψε ένα closure που παίρνει μια πλειάδα `(String, String, String)` και επιστρέφει την πλειάδα με τη σειρά των καλωδίων περιστραμμένη προς τα αριστερά.
Ανάθεσε αυτό το closure στο όνομα `rotate`.

Είναι σημαντικό να σημειώσεις ότι ο τύπος πρέπει να είναι ο `ChangeClosure` (ή κάποιος sendable τύπος), ο ορισμός του τύπου δίνεται στο αρχείο stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Υλοποίησε μια γεννήτρια ανακατέματος καλωδίων

Για να βρεις τη σειρά με την οποία πρέπει να κόψεις τα καλώδια της βομβίδας βρώμας, θα χρειαστεί να υλοποιήσεις μια συνάρτηση που παράγει τη σωστή συνάρτηση ανακατέματος με βάση τον αριθμό ID της βομβίδας βρώμας.

Υλοποίησε τη συνάρτηση:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

η οποία παίρνει ως είσοδο ένα closure που αντιστρέφει δύο καλώδια και ένα closure που περιστρέφει τα τρία καλώδια, και επιστρέφει ένα closure.
Αυτό το closure που επιστρέφεται παίρνει τον αριθμό ID της βομβίδας βρώμας και τη σειρά των τριών καλωδίων, και έπειτα υπολογίζει τη σειρά με την οποία πρέπει να κοπούν τα καλώδια.
Ο αριθμός ID αποτελείται από οκτώ bits, και κάθε bit καθορίζει αν θα αντιστραφούν ή θα περιστραφούν τα καλώδια.

Για κάθε bit του αριθμού ID, ξεκινώντας από το δεξιότερο bit, θα εφαρμόζεις το closure `flipper` στην πλειάδα των καλωδίων αν το bit είναι 0, και θα εφαρμόζεις το closure `rotator` αν είναι 1, δίνοντας τη νέα κατάσταση των καλωδίων.
Αφού εφαρμοστούν τα κατάλληλα closures και για τα οκτώ bits του ID, η τελική κατάσταση των καλωδίων είναι η σειρά με την οποία πρέπει να κοπούν.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
