# Εισαγωγή

Στη C#, το literal `null` χρησιμοποιείται για να δηλώσει την απουσία μιας τιμής. Ένας _nullable_ τύπος είναι ένας τύπος που επιτρέπει τιμές `null`.

Πριν από τη C# 8.0, οι τύποι αναφοράς ήταν πάντα nullable, ενώ οι τύποι τιμής δεν ήταν. Ωστόσο, ένας τύπος τιμής μπορεί να γίνει nullable, προσθέτοντάς του ένα ερωτηματικό (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Η πρόσβαση σε ένα μέλος μιας μεταβλητής της οποίας η τιμή είναι `null` θα μεταγλωττιστεί χωρίς πρόβλημα, αλλά θα έχει ως αποτέλεσμα να πεταχτεί ένα `NullReferenceException` κατά την εκτέλεση:

```csharp
string sentence = null;

// Throws NullReferenceException at runtime
sentence.Length;
```

Για να αντιμετωπίσεις αυτό το συνηθισμένο είδος λάθους, η C# 8 σου επιτρέπει να ενεργοποιήσεις προαιρετικά μια δυνατότητα που κάνει τους τύπους αναφοράς μη-nullable από προεπιλογή:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Για να χειριστείς με ασφάλεια nullable τιμές, θα πρέπει να ελέγξεις αν είναι `null` πριν τις χρησιμοποιήσεις:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

Ο τελεστής `??` σου επιτρέπει να επιστρέψεις μια προεπιλεγμένη τιμή όταν η τιμή είναι `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

Ο τελεστής `?.` σου επιτρέπει να καλέσεις μέλη με ασφάλεια σε μια τιμή που μπορεί να είναι `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```
