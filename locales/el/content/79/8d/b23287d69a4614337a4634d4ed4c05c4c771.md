# Υποδείξεις

## Γενικά

- Ίσως θα ήθελες να φτιάξεις ένα DSL βασισμένο σε λίστες από ετικέτες και καταγραφές, κάπως έτσι:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- Ή μήπως θα προτιμούσες ένα DSL βασισμένο σε αλυσίδες κλήσεων συναρτήσεων, κάπως έτσι:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  Ή μπορεί να έχεις ένα εντελώς διαφορετικό σχέδιο;
  Προχώρα!

- Παρ' όλα αυτά, ένα DSL είναι συνήθως καλύτερο όταν είναι σαφές, περιεκτικό και όχι υπερβολικά απρόσμενο (π.χ. η συνάρτηση `minus` προορίζεται για αφαίρεση, όχι για να χτίζεις μια ακμή ανάμεσα σε δύο κόμβους, όπως στο `node("a") - node("b")`).
