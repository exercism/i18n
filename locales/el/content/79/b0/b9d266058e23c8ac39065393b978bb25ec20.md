# Σχετικά

Η δυναμική μνήμη υλοποιείται από συναρτήσεις βιβλιοθήκης τις οποίες χρησιμοποιεί ο προγραμματιστής για να δεσμεύσει και να αποδεσμεύσει μνήμη κατά τον χρόνο εκτέλεσης.
Εφόσον ο προγραμματιστής ελέγχει τη δέσμευση και την αποδέσμευση της μνήμης, η δυναμική μνήμη είναι τόσο ασφαλής όσο είναι ο προγραμματιστής απαλλαγμένος από ανθρώπινα λάθη.
Για τον λόγο αυτό, η δυναμική μνήμη είναι μία από τις μεγαλύτερες πηγές bugs στον προγραμματισμό και ένας σημαντικός στόχος επιθέσεων χάκερ.

Η δυναμική μνήμη χρησιμοποιείται για μεταβλητές των οποίων το μέγεθος είναι γνωστό μόνο κατά τον χρόνο εκτέλεσης.
Αυτό είναι συνήθως χρήσιμο για πίνακες των οποίων ο αριθμός των στοιχείων μπορεί να διαφέρει από τη μία εκτέλεση στην επόμενη.
Οι πίνακες μεταβλητού μήκους (VLA) είναι ένας άλλος τρόπος να χειρίζεσαι πίνακες των οποίων το μέγεθος των στοιχείων είναι γνωστό μόνο κατά τον χρόνο εκτέλεσης.
Ένας VLA χρησιμοποιεί αυτόματη αποθήκευση, που σημαίνει ότι η μνήμη του καταστρέφεται όταν εγκαταλείψεις το μπλοκ στο οποίο ορίζεται.
(Για περισσότερα σχετικά με την αποθήκευση, δες την έννοια [προσδιοριστές κατηγορίας αποθήκευσης](https://github.com/exercism/c/tree/main/concepts/storage-class-specifiers).)
Οι VLA εισήχθησαν στη γλώσσα C με το C99, αλλά από το C11 και μετά οι VLA είναι προαιρετικοί, οπότε οι μεταγλωττιστές που υποστηρίζουν C11 και νεότερα δεν είναι υποχρεωμένοι να υποστηρίζουν VLA.
Μια λεπτομερής ανάλυση των πινάκων μεταβλητού μήκους ξεφεύγει από το πεδίο αυτού του άρθρου.

## malloc

Η `malloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται για τη δέσμευση δυναμικής μνήμης.
Αν η δέσμευση πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της δεσμευμένης μνήμης.
Αν η δέσμευση δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα της `malloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Ο δείκτης που επιστρέφεται είναι τύπου `pointer-to-void`, ο οποίος μπορεί χοντρικά να θεωρηθεί ένας "γενικός" δείκτης που μπορεί να μετατραπεί στον συγκεκριμένο τύπο που χρησιμοποιεί η μνήμη.
Η `malloc` έχει μία παράμετρο, το μέγεθος της επιθυμητής μνήμης σε byte.
Το συνολικό μέγεθος για τη δέσμευση ενός πίνακα είναι το μέγεθος του τύπου δεδομένων κάθε στοιχείου πολλαπλασιασμένο επί τον αριθμό των στοιχείων.
Ο τελεστής `sizeof` χρησιμοποιείται συνήθως για να πάρεις το μέγεθος του τύπου δεδομένων κάθε στοιχείου.
Το παρακάτω παράδειγμα το δείχνει αυτό

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Είναι σημαντικό να θυμάσαι ότι η μνήμη που μόλις δεσμεύει η `malloc` δεν αρχικοποιείται, αλλά μπορεί να περιέχει τυχαίες τιμές.
Πρόσεξε ότι το `sizeof` του δείκτη `numbers` δεν είναι ο αριθμός των στοιχείων του πίνακα ούτε το συνολικό ποσό της μνήμης που δεσμεύτηκε.
Το μέγεθος του δείκτη που επιστρέφει η `malloc` είναι το μέγεθος οποιουδήποτε δείκτη σε αυτό το συγκεκριμένο σύστημα.
Ο κώδικας του παραδείγματος εκτελέστηκε σε σύστημα 64 bit, οπότε το μέγεθος του δείκτη ήταν 8 byte (επί 8 bit ανά byte = 64 bit).
Ο τύπος του δείκτη μετατράπηκε σιωπηρά από pointer-to-void σε pointer-to-int.
Το αν ο pointer-to-int δείχνει σε ένα μόνο `int` ή σε έναν πίνακα από `ints` είναι κάτι που ο προγραμματιστής μπορεί να το χειριστεί όπως κρίνει.
Για παράδειγμα

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(1);
    if (!numbers) return -1;
    // treat numbers as a single value
    *numbers = 1;
    // prints numbers is 1
    printf("numbers is %d\n", *numbers);
    // treat numbers as an array
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    numbers[0] = 2;
    // prints The first element of the array is 2
    printf("The first element of the array is %d\n", numbers[0]);
    // treat numbers as a single value again
    // prints numbers is 2
    printf("numbers is %d\n", *numbers);    
    free(numbers);
    numbers = NULL;    
}
```

Αν οι τιμές πρόκειται σίγουρα να γραφτούν πριν διαβαστούν, τότε η χρήση της `malloc` μπορεί να είναι ένας αποδοτικός τρόπος να δεσμεύσεις μνήμη.
Αλλά αν υπάρχει περίπτωση οι τιμές να διαβαστούν πριν αρχικοποιηθούν, τότε η χρήση της `malloc` είναι ριψοκίνδυνη.
Ένας ασφαλέστερος τρόπος να δεσμεύσεις μνήμη είναι να χρησιμοποιήσεις τη `calloc`, η οποία αρχικοποιεί στο μηδέν τη μνήμη που μόλις δεσμεύτηκε.

Πρόσεξε ότι στα παραπάνω παραδείγματα χρησιμοποιήθηκε η `free(numbers)`.

## free

Η `free` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται για την αποδέσμευση μνήμης που έχει δεσμευτεί δυναμικά.
Η δυναμικά δεσμευμένη μνήμη παραμένει κατειλημμένη στη μνήμη μέχρι να την απελευθερώσει η `free`.
Ορισμένα λειτουργικά συστήματα μπορεί να απελευθερώνουν αυτόματα τη δυναμικά δεσμευμένη μνήμη όταν το πρόγραμμα τερματίζει, αλλά είναι καλή πρακτική να μη βασίζεσαι σε αυτό.
Η `free` έχει μία παράμετρο, έναν δείκτη στη μνήμη που δεσμεύτηκε δυναμικά.
Η χρήση ή η μη χρήση της `free` σχετίζεται με αρκετά προβλήματα μνήμης.

#### Διαρροή μνήμης

Το να μην απελευθερώνεις δυναμικά δεσμευμένη μνήμη αφού η αναφορά σε αυτή τη μνήμη φτάσει στο τέλος της διάρκειας ζωής της ή καταστραφεί με άλλον τρόπο, ονομάζεται διαρροή μνήμης.
Η μνήμη που διαρρέει είναι μνήμη που τη διεκδικεί το σύστημα αλλά δεν είναι πλέον προσβάσιμη από το πρόγραμμα.
Αυτό μπορεί να αποτελέσει ιδιαίτερο πρόβλημα αν δεσμεύεται μνήμη μέσα σε έναν βρόχο, δεν απελευθερώνεται στο τέλος του βρόχου και δεσμεύεται ξανά στην αρχή του.
Αν δεσμευτεί αρκετή μνήμη χωρίς να απελευθερωθεί, η κλήση για δέσμευση μνήμης θα αποτύχει επειδή δεν θα απομένει αρκετή μνήμη για δέσμευση.
Είναι σημαντικό να θυμάσαι ότι, αν και η δυναμικά δεσμευμένη μνήμη παραμένει κατειλημμένη από το σύστημα μέχρι να απελευθερωθεί, ο δείκτης στον οποίο ανατίθεται μπορεί να έχει μόνο εμβέλεια μπλοκ.
Για παράδειγμα, στα παραδείγματα με τη `malloc`, η μνήμη δεσμεύεται μέσα στη `my_function`.
Αυτή η μνήμη θα διέρρεε αν ο δείκτης προς αυτήν δεν επιστρεφόταν και δεν χρησιμοποιούνταν για να οριστεί ο δείκτης `numbers` στη `main`.
Έτσι, περνώντας αυτόν τον δείκτη `numbers` στη `free` απελευθερώνεις τη μνήμη που δεσμεύτηκε στη `my_function`.

#### Χρήση μετά την απελευθέρωση (**UAF**)

Αν προσπελάσεις τη μνήμη αφού απελευθερωθεί, οι τιμές μπορεί να είναι οτιδήποτε.
Στο παρακάτω παράδειγμα, η μνήμη στην οποία δείχνει το `numbers` απελευθερώνεται και στη συνέχεια διαβάζεται μέσα στη `printf`.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = (int *) malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(1);
    if (!numbers) return -1;
    *numbers = 1;
    // prints numbers is 1
    printf("numbers is %d\n", *numbers);
    free(numbers);
    // could  print anything, e.g.
    // The first element of the array is 18178656
    printf("The first element of the array is %d\n", numbers[0]);
}
```

Ο δείκτης `numbers`, αφού απελευθερωθεί, αναφέρεται ως αιωρούμενος δείκτης.
Ένας αιωρούμενος δείκτης μπορεί να αναφέρεται σε άλλη μνήμη από αυτή για την οποία προοριζόταν.
Έτσι, ένας αιωρούμενος δείκτης μπορεί να οδηγήσει σε αλλοίωση δεδομένων και σε αυθαίρετη υποκατάσταση και εκτέλεση κώδικα.
Ένας δείκτης σε δεσμευμένη μνήμη που δεν έχει καθαριστεί με ορισμό σε `NULL` μπορεί να χρησιμοποιηθεί για να παραβιαστεί το πρόγραμμα.
Στο παραπάνω παράδειγμα, αν το `numbers` οριστεί σε `NULL` ως εξής: `numbers = NULL;` αφού απελευθερωθεί, η επόμενη `printf` θα προκαλούσε τερματισμό του προγράμματος, αναφέροντας ίσως σφάλμα κατάτμησης όταν επιχειρήσει να διαβάσει το `numbers[0]`.

#### Διπλή απελευθέρωση

Αν η `free` κληθεί δύο φορές σε έναν δείκτη προς δυναμικά δεσμευμένη μνήμη, αυτό οδηγεί σε μη ορισμένη συμπεριφορά (**UB**).
Αυτό σημαίνει ότι ο μεταγλωττιστής μπορεί αυθαίρετα να το χειριστεί όπως θέλει.
Το παρακάτω παράδειγμα, μεταγλωττισμένο με δύο διαφορετικούς μεταγλωττιστές, μπορεί να έχει δύο διαφορετικά αποτελέσματα

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(1);
    if (!numbers) return -1;
    *numbers = 1;
    // prints numbers is 1
    printf("numbers is %d\n", *numbers);
    free(numbers);
    // numbers = NULL;
    // first compiler generates runtime error: double free detected in tcache 2
    // second compiler generates no error
    free(numbers);
}
```

Ο πρώτος και ο δεύτερος μεταγλωττιστής δεν παρήγαγαν σφάλμα χρόνου εκτέλεσης όταν το `numbers` ορίστηκε σε `NULL` ανάμεσα σε κάθε κλήση της `free`, αλλά αυτό δεν είναι εγγυημένο ότι θα λειτουργήσει με έναν τρίτο μεταγλωττιστή.
Μια συνηθισμένη αιτία διπλής απελευθέρωσης είναι να έχεις δύο δείκτες που δείχνουν στην ίδια δυναμικά δεσμευμένη μνήμη.
Ο ένας δείκτης μπορεί να δείχνει στην αρχή ενός πίνακα σε ένα σημείο του προγράμματος, και ο άλλος δείκτης μπορεί να χρησιμοποιείται για να διατρέχει τον πίνακα σε άλλο σημείο του προγράμματος.
Σε διαφορετικά σημεία του προγράμματος απελευθερώνεται ο καθένας από τους δείκτες, προκαλώντας έτσι διπλή απελευθέρωση.

## calloc

Η `calloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται και για τη δέσμευση δυναμικής μνήμης και για την αρχικοποίηση στο μηδέν της μνήμης που μόλις δεσμεύτηκε.
Αν η δέσμευση πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της δεσμευμένης μνήμης.
Αν η δέσμευση δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα της `calloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Ο δείκτης που επιστρέφεται είναι τύπου `pointer-to-void`, ο οποίος μπορεί χοντρικά να θεωρηθεί ένας "γενικός" δείκτης που μπορεί να μετατραπεί στον συγκεκριμένο τύπο που χρησιμοποιεί η μνήμη.
Η `calloc` έχει δύο παραμέτρους.
Η πρώτη παράμετρος αφορά το πόσα στοιχεία του καθορισμένου τύπου δεδομένων θα δεσμευτούν.
Η δεύτερη παράμετρος αφορά το μέγεθος του καθορισμένου τύπου δεδομένων που θα δεσμευτεί.

Στο παρακάτω παράδειγμα όλες οι εντολές `printf` θα πρέπει πάντα να εμφανίζουν `0`, αφού η `calloc` εγγυάται ότι μηδενίζει τις τιμές που μόλις δεσμεύτηκαν.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

Η `realloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται είτε για να επεκτείνει είτε για να συρρικνώσει υπάρχουσα δεσμευμένη μνήμη.
Αν η ανακατανομή πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της ανακατανεμημένης μνήμης.
Αν η ανακατανομή δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα της `realloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Η `realloc` έχει δύο παραμέτρους.
Η πρώτη παράμετρος είναι ένας δείκτης στην υπάρχουσα μνήμη που θα ανακατανεμηθεί.
Η δεύτερη παράμετρος είναι το μέγεθος σε byte της ανακατανεμημένης μνήμης.
Οι τιμές που είχαν οριστεί πριν επεκταθεί η μνήμη διατηρούνται.
Είναι σημαντικό να θυμάσαι ότι η μνήμη που προστίθεται όταν επεκτείνεις τη μνήμη δεν αρχικοποιείται στο μηδέν και οι τιμές της μπορεί να είναι οτιδήποτε.
Επίσης, η μνήμη που αφαιρείται όταν συρρικνώνεις τη μνήμη δεν αρχικοποιείται ούτε αυτή και μπορεί να διατηρήσει τις τιμές της.
Το παρακάτω παράδειγμα δείχνει την επέκταση και τη συρρίκνωση ενός πίνακα

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    free(numbers);
}
```

## Όταν το μέγεθος που περνάς είναι 0

Αν το μέγεθος που περνάς στη `malloc`, στη `calloc` ή στη `relloac` είναι `0`, τότε το τι θα συμβεί εξαρτάται από το πώς το υλοποιεί ο μεταγλωττιστής.
Ένας μεταγλωττιστής μπορεί είτε να επιστρέψει έναν δείκτη `NULL` είτε έναν μη μηδενικό δείκτη.
Για παράδειγμα, αν δεσμεύεις μνήμη για έναν δείκτη σε `char`, ο μεταγλωττιστής μπορεί να επιστρέψει είτε `NULL` είτε έναν μη μηδενικό δείκτη σε μια κενή συμβολοσειρά.
Για να αποφύγεις διαφορετικά αποτελέσματα με διαφορετικούς μεταγλωττιστές, το καλύτερο είναι να μη δεσμεύεις μνήμη με μέγεθος 0.
