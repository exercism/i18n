# Οδηγίες

Σε αυτή την άσκηση θα οργανώσεις αγώνες ανάμεσα σε διάφορα είδη τηλεκατευθυνόμενων αυτοκινήτων.
Κάθε αυτοκίνητο έχει τα δικά του χαρακτηριστικά και τρέχει σε πολλές διαφορετικές πίστες σε αγώνες κατά τη διάρκεια της σεζόν του τουρνουά.

~~~~exercism/note
Οι συναρτήσεις σε αυτή την άσκηση δηλώνονται σε ένα αρχείο πηγαίου κώδικα C με τις υπογραφές που δίνονται.
Ο κώδικας x86-64 assembly σου πρέπει να ακολουθεί αυτές τις προδιαγραφές.
~~~~

## 1. Δημιούργησε ένα τηλεκατευθυνόμενο αυτοκίνητο

Έχεις ορίσει μια δομή `car_t` για να αναπαριστάς ένα τηλεκατευθυνόμενο αυτοκίνητο:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Δώσε τη δυνατότητα δημιουργίας ενός τηλεκατευθυνόμενου αυτοκινήτου, ορίζοντας μια συνάρτηση `new_car` σε x86-64 assembly.
Το πεδίο `battery` ξεκινά πάντα με την τιμή `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Δημιούργησε νέα πίστα

Οι πίστες αναπαρίστανται από μια δομή `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

Το `enum surface_t` καταγράφει τις διαφορετικές επιφάνειες μιας πίστας:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Δώσε τη δυνατότητα δημιουργίας μιας νέας πίστας, ορίζοντας μια συνάρτηση `new_track` σε x86-64 assembly.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Δημιούργησε έναν αγώνα

Μέχρι 6 αυτοκίνητα συμμετέχουν σε κάθε αγώνα, κάνοντας έναν καθορισμένο αριθμό γύρων σε μια πίστα.
Οι αγώνες αναπαρίστανται από μια δομή `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Όρισε μια συνάρτηση `new_race` σε x86-64 assembly.
Στην αρχή, δεν υπάρχουν επιβεβαιωμένα αυτοκίνητα που συμμετέχουν στον αγώνα:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Επιβεβαίωσε τη συμμετοχή ενός αυτοκινήτου στον αγώνα

Όταν ο ιδιοκτήτης ενός αυτοκινήτου ζητά να συμμετάσχει αυτό σε έναν αγώνα, η συμμετοχή του επιβεβαιώνεται μόνο αν η λίστα δεν είναι ήδη γεμάτη.

Όρισε μια συνάρτηση `add_participant` σε x86-64 assembly.
Αν υπάρχει χώρος για έναν ακόμη συμμετέχοντα στον αγώνα, το αυτοκίνητο προστίθεται στη λίστα, ο μετρητής ενημερώνεται και η συμμετοχή του επιβεβαιώνεται.
Διαφορετικά, οι διοργανωτές του αγώνα πρέπει να ενημερώσουν τον ιδιοκτήτη του αυτοκινήτου ότι δεν μπορεί να συμμετάσχει αυτή τη φορά.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Δημιούργησε ένα τουρνουά

Κρατάς τους αγώνες που έχουν προγραμματιστεί για τη σεζόν σε μια δομή `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Όρισε μια συνάρτηση `add_race` σε x86-assembly, για να προσθέτεις έναν αγώνα στον πίνακα του τουρνουά και να ενημερώνεις και τον μετρητή του.
Μπορείς να θεωρήσεις ότι θα υπάρχει πάντα αρκετός χώρος στον πίνακα `races` για τον νέο αγώνα.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
