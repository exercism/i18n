# Εισαγωγή

## Σύγκριση Αριθμών

Στη JavaScript, οι αριθμοί μπορούν να συγκριθούν χρησιμοποιώντας τους παρακάτω σχεσιακούς τελεστές και τελεστές ισότητας.

| Σύγκριση                | Τελεστής  |
| ----------------------- | --------- |
| Μεγαλύτερο από          | `a > b`   |
| Μεγαλύτερο ή ίσο με     | `a >= b`  |
| Μικρότερο από           | `a < b`   |
| Μικρότερο ή ίσο με      | `a <= b`  |
| (Αυστηρή) Ισότητα       | `a === b` |
| Μη (αυστηρή) ισότητα    | `a !== b` |

Το αποτέλεσμα της σύγκρισης είναι πάντα μια τιμή Boolean (λογική τιμή), δηλαδή είτε `true` είτε `false`.

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## Σύγκριση Συμβολοσειρών

Στη JavaScript, οι παραπάνω τελεστές σύγκρισης μπορούν να χρησιμοποιηθούν και για τη σύγκριση συμβολοσειρών.
Σε αυτή την περίπτωση, εφαρμόζεται σειρά λεξικού (λεξικογραφική).
Μπορείς να βρεις μια λίστα με την ακριβή σειρά όλων των χαρακτήρων [εδώ][utf-16-list].

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## Αυστηρή Ισότητα

Μπορεί να αναρωτιέσαι για τα τρία σύμβολα ίσον για τον έλεγχο ισότητας στη JavaScript.
Το `===` αντιπροσωπεύει τον έλεγχο για _αυστηρή ισότητα_, που σημαίνει ότι δεν εκτελείται μετατροπή τύπων και τιμές διαφορετικών τύπων είναι πάντα άνισες.

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

Ο συνιστώμενος τρόπος για έλεγχο ισότητας στη JavaScript είναι η χρήση των `===` και `!==`.

Υπάρχουν επίσης τα `==` και `!=`, τα οποία αντιπροσωπεύουν τον έλεγχο για _χαλαρή ισότητα_.
Καλό είναι να τα αποφεύγεις, γιατί εφαρμόζουν έμμεση μετατροπή τύπων πριν εκτελέσουν τη σύγκριση.
Τα αποτελέσματα σε αυτές τις περιπτώσεις είναι δύσκολο να προβλεφθούν και μερικές φορές δεν είναι αυτό που θα περίμενες.

```javascript
0 == false;
// => true
```
