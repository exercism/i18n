# Tests

Για να τρέξεις το test suite:
```bash
tclsh exercise.test
```

## Tests που παραλείπονται

Το να λύσεις μια άσκηση σημαίνει να περάσεις όλα της τα tests. Από προεπιλογή, όταν τρέχεις τα tests εκτελείται μόνο ένα test (το πρώτο). Αυτό γίνεται επίτηδες, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσεις μόνο αυτό το ένα test. Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο test βάζοντας σε σχόλιο ή αφαιρώντας την εντολή `skip` που προηγείται.

Εναλλακτικά, για να τρέξεις όλα τα tests ανεξάρτητα από την κατάσταση "skipped" τους:
```bash
RUN_ALL=1 tclsh exercise.test
```
