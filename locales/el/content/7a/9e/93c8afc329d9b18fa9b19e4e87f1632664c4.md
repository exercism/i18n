# Δυαδικό, Οκταδικό και Δεκαεξαδικό

Το δυαδικό, το οκταδικό και το δεκαεξαδικό (_γνωστό και ως hex_) είναι διαφορετικά [αριθμητικά συστήματα][numeral-systems] με διαφορετικές βάσεις.
Το δυαδικό είναι βάσης 2, το οκταδικό είναι βάσης 8 και το δεκαεξαδικό είναι βάσης 16.
Οι συνηθισμένοι ακέραιοι στη Crystal είναι βάσης 10.
Το δυαδικό, το οκταδικό και το δεκαεξαδικό είναι όλα αναπαραστάσεις ακεραίων.
Αυτό σημαίνει ότι αναπαριστούν θετικούς και αρνητικούς αριθμούς (_μαζί και το μηδέν_) χωρίς κλάσματα ή δεκαδικά ψηφία και υποστηρίζουν όλες τις πράξεις που μπορούμε να κάνουμε με ακεραίους.

## Δυαδικό

Το [δυαδικό][binary] είναι ένα αριθμητικό σύστημα βάσης 2 που χρησιμοποιεί μόνο τα ψηφία 0 και 1.
Συνήθως αναπαριστά τις καταστάσεις 0 ("off") και 1 ("on") της ηλεκτρικής ροής μέσα από τρανζίστορ και διακόπτες στους υπολογιστές, καθώς και τα θετικά και αρνητικά φορτία στα μέσα μαγνητικής αποθήκευσης.
Το δυαδικό μπορεί να αναπαραστήσει όλους τους ακεραίους που χρησιμοποιούνται στη βάση 10.

Ένα απόσπασμα από το σύστημα βάσης 2 μοιάζει κάπως έτσι, αν και συνεχίζεται επ' άπειρον και δεν σταματά στο 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Έτσι, αν θέλουμε να αναπαραστήσουμε τον αριθμό 6, σε δυαδικό θα ήταν: 110

| Αξία θέσης    | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Δυαδικός αριθμός | 1   | 1   | 0   |

Και η πράξη θα ήταν: `4 + 2 + 0 = 6`

Άλλο ένα παράδειγμα: 19

| Αξία θέσης    | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Δυαδικός αριθμός | 1   | 0   | 0   | 1   | 1   |

Ο δυαδικός αριθμός θα ήταν: 10011
Και η πράξη θα ήταν: `16 + 0 + 0 + 2 + 1 = 19`

## Το δυαδικό στη Crystal

Στη Crystal, μπορούμε να αναπαραστήσουμε δυαδικά literals χρησιμοποιώντας το πρόθεμα `0b`.
Αν γράψουμε `0b10011`, η Crystal θα το ερμηνεύσει ως δυαδικό αριθμό και θα το μετατρέψει σε βάση 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Αν γράψεις έναν αριθμό με πρόθεμα `0b` που δεν είναι στο δυαδικό σύστημα, θα πετάξει ένα σφάλμα μεταγλώττισης.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Πράξεις με δυαδικούς αριθμούς

Εφόσον οι δυαδικοί αριθμοί είναι ακέραιοι, μπορούμε να εκτελέσουμε πάνω τους όλες τις πράξεις που μπορούμε και με τους ακεραίους.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Μετατροπή από και προς τη δυαδική αναπαράσταση

Η Crystal θα μετατρέψει αυτόματα ένα δυαδικό literal σε `Int32`.
Για να μετατρέψεις ένα `Int32` σε δυαδική αναπαράσταση, χρησιμοποίησε τη μέθοδο [`<int>.to_s(base)`][to_s] με το όρισμα της βάσης ορισμένο σε 2.
Η μέθοδος θα επιστρέψει μια συμβολοσειρά που αναπαριστά τον δυαδικό αριθμό:

```crystal
19.to_s(2)
# => "10011"
```

Για να μετατρέψεις μια συμβολοσειρά που αναπαριστά έναν δυαδικό αριθμό σε ακέραιο, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_i], περνώντας τη βάση (2) ως όρισμα:

```crystal
"10011".to_i(2)
# => 19
```

Αν δώσεις λάθος βάση (_ή μη έγκυρη δυαδική αναπαράσταση_), θα πετάξει ένα `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Μέθοδοι για δυαδικούς αριθμούς

Υπάρχουν ορισμένες μέθοδοι που μπορούν να χρησιμοποιηθούν σε ακεραίους για να πάρεις πληροφορίες για τη δυαδική αναπαράσταση του αριθμού.

Η [`<int>.bit_length`][bit_length] θα επιστρέψει τον αριθμό των bit που χρειάζονται για να αναπαρασταθεί ο αριθμός:

```crystal
19.bit_length
# => 5
```

Η [`<int>.bit(index)`][bit] θα επιστρέψει το bit στη δεδομένη θέση, ξεκινώντας από τα δεξιά (_λιγότερο σημαντικό bit_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Οκταδικό

Το [οκταδικό][octal] είναι ένα αριθμητικό σύστημα βάσης 8.
Χρησιμοποιεί τα ψηφία 0, 1, 2, 3, 4, 5, 6 και 7.

Στη Crystal, μπορούμε να αναπαραστήσουμε οκταδικούς αριθμούς χρησιμοποιώντας το πρόθεμα `0o`.
Όπως με το δυαδικό, η Crystal μετατρέπει αυτόματα μια οκταδική αναπαράσταση σε `Int32`.

```crystal
0o123
# => 83
```

Αν βάλεις πρόθεμα `0o` σε έναν αριθμό που δεν είναι στο οκταδικό σύστημα, θα πετάξει ένα σφάλμα μεταγλώττισης.

### Μετατροπή από και προς την οκταδική αναπαράσταση

Όπως με το δυαδικό, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_s(base)`][to_s] για να μετατρέψουμε ένα `Int32` σε οκταδική αναπαράσταση.
Και μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_s] για να μετατρέψουμε μια οκταδική αναπαράσταση σε `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Όπως με το δυαδικό, αν δώσεις λάθος βάση θα πετάξει ένα `ArgumentError`.

## Δεκαεξαδικό

Το [δεκαεξαδικό][hexadecimal] είναι ένα αριθμητικό σύστημα βάσης 16.
Χρησιμοποιεί τα ψηφία 0 - 9 και τα γράμματα A, B, C, D, E και F.
Το A είναι 10, το B είναι 11, το C είναι 12, το D είναι 13, το E είναι 14 και το F είναι 15.

Μπορούμε να αναπαραστήσουμε δεκαεξαδικούς αριθμούς στη Crystal χρησιμοποιώντας το πρόθεμα `0x`.
Όπως με το δυαδικό και το οκταδικό, η Crystal θα μετατρέψει αυτόματα τα δεκαεξαδικά literals σε `Int32`.

```crystal
#=> 0x123
291
```
 
Αν βάλεις πρόθεμα `0x` σε έναν μη δεκαεξαδικό αριθμό, θα πετάξει ένα σφάλμα μεταγλώττισης.

###  Μετατροπή από και προς τη δεκαεξαδική αναπαράσταση

Όπως με το δυαδικό, μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_s(base)`][to_i] για να μετατρέψουμε ένα `Int32` σε δεκαεξαδική αναπαράσταση.
Και μπορούμε να χρησιμοποιήσουμε τη μέθοδο [`<int>.to_i(base)`][to_s] για να μετατρέψουμε μια δεκαεξαδική αναπαράσταση σε `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Όπως με το δυαδικό και το οκταδικό, αν δώσεις λάθος βάση θα πετάξει ένα `ArgumentError`.

## Ακρίβεια

Όταν μετατρέπεις έναν αριθμό σε συμβολοσειρά, μπορείς να ορίσεις την ακρίβεια του αριθμού.
Δηλαδή τον **ελάχιστο** αριθμό ψηφίων που χρησιμοποιούνται για την αναπαράσταση του αριθμού.
Αν ο αριθμός έχει λιγότερα ψηφία από την ακρίβεια, θα προστεθούν μηδενικά στην αρχή της συμβολοσειράς.
Αυτό γίνεται περνώντας το όρισμα `precision` στη μέθοδο [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Κεφαλαία

Όταν μετατρέπεις έναν αριθμό σε συμβολοσειρά, μπορείς να ορίσεις αν θέλεις τα γράμματα στη συμβολοσειρά να γίνουν κεφαλαία.
Αυτό γίνεται περνώντας το όρισμα `upcase` στη μέθοδο [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
