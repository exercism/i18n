# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integer-value] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να [ορίσεις μια σταθερά][constant].

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να [ορίσεις μια συνάρτηση][function] με μία παράμετρο.
- Μπορείς να χρησιμοποιήσεις και να αναφερθείς στη σταθερά που όρισες προηγουμένως με το όνομά της.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][arithmetical-operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να [ορίσεις μια συνάρτηση][function] με μία παράμετρο.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][arithmetical-operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις [μια συνάρτηση με δύο παραμέτρους][multiple-parameters].
- Μπορείς να [καλέσεις μια από τις άλλες συναρτήσεις][function] που όρισες προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][arithmetical-operators] για να προσθέσεις τιμές.
