# Σχετικά

Η Chapel είναι μια γλώσσα προγραμματισμού σχεδιασμένη για παραγωγικό παράλληλο υπολογισμό μεγάλης κλίμακας. Είναι σχεδιασμένη ώστε ερευνητές και επαγγελματίες του χώρου να αξιοποιούν εύκολα τη δύναμη των υπολογιστών υψηλών επιδόσεων, χωρίς να θυσιάζουν την παραγωγικότητα και την αναγνωσιμότητα.

### Βασικά χαρακτηριστικά

- **Παραγωγικότητα**: ο κώδικας τείνει να διαβάζεται και να γράφεται εξίσου εύκολα όσο στην Python
- **Κλιμακωσιμότητα**: τρέχει σε φορητούς υπολογιστές, σε clusters, στο cloud και σε συστήματα υψηλών επιδόσεων
- **Ταχύτητα**: οι επιδόσεις της συναγωνίζονται ή ξεπερνούν εκείνες των C/C++, MPI και OpenMP
- **Φορητότητα**: μεταγλωττίζεται και τρέχει σε σχεδόν κάθε περιβάλλον \*nix
- **Ανοιχτός κώδικας**: φιλοξενείται στο GitHub, με άδεια ελεύθερης χρήσης.
