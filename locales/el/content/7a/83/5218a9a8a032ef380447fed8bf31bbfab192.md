# Υποδείξεις

## Γενικά

- Μην ξεχνάς να εξάγεις τις τρεις δημόσιες υπορουτίνες.
  Καταχώρισέ τις στον πίνακα `@EXPORT_OK`.

## 1. Έλεγξε αν μια δεδομένη ημερομηνία είναι στο παρελθόν

- Για την ανάλυση συμβολοσειρών ημερομηνίας, οι συμβολοσειρές θα δίνονται σε μορφή ISO 8601.
  Χρησιμοποίησε τη μεταβλητή πακέτου `$STRPTIME_FORMAT`.
- Οι μέθοδοι `Time::Piece->strptime` ή `DateTime::Tiny->from_string` θα σου φανούν χρήσιμες.

## 2. Έλεγξε αν μια δεδομένη ημερομηνία είναι το απόγευμα

- Το "απόγευμα" ξεκινά το μεσημέρι και τελειώνει πριν τις 18:00.

## 3. Ανάλυσε μια ημερομηνία σε μια συμβολοσειρά που περιγράφει ένα ραντεβού

- Χρησιμοποίησε τη μορφή `mm/dd/yyyy` για την ημερομηνία εξόδου.
  Για παράδειγμα: 12/31/2021
- Η μορφή της ώρας εξόδου χρησιμοποιεί την ώρα στο εύρος 0-12 χωρίς αρχικό μηδενικό ή κενό, και κεφαλαία ένδειξη ampm.
  Για παράδειγμα: 7:59 PM
- Αν χρησιμοποιείς το άρθρωμα Time::Piece, η μέθοδος `strftime` είναι κατάλληλη.
