# Οδηγίες

Ο φίλος σου ο Chandler σχεδιάζει να ταξιδέψει σε εξωτικά μέρη σε όλο τον κόσμο. Δυστυχώς, οι μαθηματικές του ικανότητες δεν είναι καλές. Ανησυχεί αρκετά μήπως τον εξαπατήσουν τα ανταλλακτήρια συναλλάγματος κατά τη διάρκεια του ταξιδιού του, και θέλει να του φτιάξεις μια αριθμομηχανή συναλλάγματος. Ορίστε οι προδιαγραφές του για την εφαρμογή:

## 1. Εκτίμησε την τιμή μετά την ανταλλαγή

Δημιούργησε τη συνάρτηση `exchange_money()`, που δέχεται 2 παραμέτρους:

1. `budget`: Το ποσό των χρημάτων που σκοπεύεις να ανταλλάξεις.
2. `exchange_rate`: Το ποσό του εγχώριου νομίσματος που ισούται με μία μονάδα ξένου νομίσματος.

Αυτή η συνάρτηση πρέπει να επιστρέφει την τιμή του νομίσματος που ανταλλάχθηκε.

**Σημείωση:** Αν το νόμισμά σου είναι το USD και θέλεις να ανταλλάξεις USD με EUR με ισοτιμία `1.20`, τότε `1.20 USD == 1 EUR`.

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. Υπολόγισε το νόμισμα που απομένει μετά από μια ανταλλαγή

Δημιούργησε τη συνάρτηση `get_change()`, που δέχεται 2 παραμέτρους:

1. `budget`: Το ποσό των χρημάτων πριν από την ανταλλαγή.
2. `exchanging_value`: Το ποσό των χρημάτων που *αφαιρείται* από το ποσό για να ανταλλαχθεί.

Αυτή η συνάρτηση πρέπει να επιστρέφει το ποσό των χρημάτων που *περισσεύει* από το αρχικό ποσό.

```python
>>> get_change(127.5, 120)
7.5
```

## 3. Υπολόγισε την τιμή των χαρτονομισμάτων

Δημιούργησε τη συνάρτηση `get_value_of_bills()`, που δέχεται 2 παραμέτρους:

1. `denomination`: Η τιμή ενός μεμονωμένου χαρτονομίσματος.
2. `number_of_bills`: Ο συνολικός αριθμός των χαρτονομισμάτων.

Αυτό το ανταλλακτήριο χειρίζεται μόνο μετρητά σε συγκεκριμένες υποδιαιρέσεις. Το συνολικό ποσό που λαμβάνεις πρέπει να διαιρείται με την τιμή ενός "χαρτονομίσματος" ή μονάδας, κάτι που μπορεί να αφήσει κλάσμα ή υπόλοιπο. Η συνάρτησή σου πρέπει να επιστρέφει μόνο τη συνολική τιμή των χαρτονομισμάτων (_χωρίς τα κλασματικά ποσά_) που θα σου έδινε πίσω το ανταλλακτήριο. Δυστυχώς, το ανταλλακτήριο κρατάει το υπόλοιπο/τα ρέστα ως επιπλέον μπόνους.

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. Υπολόγισε τον αριθμό των χαρτονομισμάτων

Δημιούργησε τη συνάρτηση `get_number_of_bills()`, που δέχεται `amount` και `denomination`.

Αυτή η συνάρτηση πρέπει να επιστρέφει τον _αριθμό των χαρτονομισμάτων_ που μπορείς να λάβεις μέσα στο δεδομένο _ποσό_. Με άλλα λόγια: πόσα _ολόκληρα χαρτονομίσματα_ χωρούν στο αρχικό ποσό; Θυμήσου ότι μπορείς να λάβεις μόνο _ολόκληρα χαρτονομίσματα_, όχι κλάσματα χαρτονομισμάτων, οπότε φρόντισε να διαιρέσεις αναλόγως. Στην πράξη, στρογγυλοποιείς _προς τα κάτω_ στο πλησιέστερο ολόκληρο χαρτονόμισμα/υποδιαίρεση.

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. Υπολόγισε το υπόλοιπο μετά την ανταλλαγή σε χαρτονομίσματα

Δημιούργησε τη συνάρτηση `get_leftover_of_bills()`, που δέχεται `amount` και `denomination`.

Αυτή η συνάρτηση πρέπει να επιστρέφει το _ποσό που περισσεύει_ και δεν μπορεί να επιστραφεί από το αρχικό _ποσό_, δεδομένης της τιμής του χαρτονομίσματος. Είναι πολύ σημαντικό να ξέρεις ακριβώς πόσα κρατάει το ανταλλακτήριο.

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. Υπολόγισε την τιμή μετά την ανταλλαγή

Δημιούργησε τη συνάρτηση `exchangeable_value()`, που δέχεται `budget`, `exchange_rate`, `spread` και `denomination`.

Η παράμετρος `spread` είναι το *ποσοστό που κρατείται* ως προμήθεια ανταλλαγής, γραμμένο ως ακέραιος. Πρέπει να μετατραπεί σε δεκαδικό διαιρώντας το με το 100. Αν `1.00 EUR == 1.20 USD` και το *spread* είναι `10`, η πραγματική ισοτιμία θα είναι: `1.00 EUR == 1.32 USD`, επειδή το 10% του 1.20 είναι 0.12 και αυτή η επιπλέον χρέωση προστίθεται στην ανταλλαγή.

Αυτή η συνάρτηση πρέπει να επιστρέφει τη μέγιστη τιμή του νέου νομίσματος αφού υπολογίσεις την *ισοτιμία* συν το *spread*. Θυμήσου ότι η *τιμή* του νομίσματος είναι ακέραιος αριθμός και δεν μπορεί να διαιρεθεί περαιτέρω.

**Σημείωση:** Η τιμή που επιστρέφεται πρέπει να είναι τύπου `int`.

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
