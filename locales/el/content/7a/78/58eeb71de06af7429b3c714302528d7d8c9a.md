# Εισαγωγή

Οι **εκφράσεις** `throw` είναι μια εναλλακτική επιλογή αντί για τις _εντολές_ `throw` και, ειδικότερα, μπορούν να προσθέσουν στις δυνατότητες των τριμερών και άλλων σύνθετων εκφράσεων.

```haxe
trace(true ? throw "This is an error" : "Everything is fine"); // ERROR: This is an error
```
