# Εισαγωγή

Θα αναφερόμαστε στη _γλώσσα_ ως **AWK** και στο _εκτελέσιμο_ που διερμηνεύει προγράμματα AWK ως **`awk`** ή **`gawk`**.

## Μοτίβα και ενέργειες

Ένα πρόγραμμα AWK αποτελείται από **ζεύγη μοτίβου-ενέργειας**

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

Ένα **μοτίβο** μπορεί να είναι ένα μοτίβο κανονικής έκφρασης για αντιστοίχιση με την είσοδο.
Μπορεί επίσης να είναι οποιαδήποτε έκφραση που καταλήγει σε τιμή αληθής/ψευδής.

Μια **ενέργεια** είναι μία ή περισσότερες εντολές AWK.
Τα άγκιστρα που την περικλείουν είναι υποχρεωτικά.

Αν το αποτέλεσμα του μοτίβου είναι _αληθές_, τότε αξιολογείται η αντίστοιχη ενέργεια.

## Καταγραφές και πεδία

Το AWK αναλύει την είσοδο σε μια σειρά από **καταγραφές**.
Κάθε καταγραφή χωρίζεται σε μηδέν ή περισσότερα **πεδία**.

Η προεπιλεγμένη συμπεριφορά είναι να:

- χωρίζει την είσοδο σε καταγραφές χρησιμοποιώντας τον χαρακτήρα νέας γραμμής ως "διαχωριστικό καταγραφών", ώστε κάθε _γραμμή_ να είναι μια καταγραφή.
- χωρίζει την καταγραφή σε πεδία χρησιμοποιώντας τα κενά ως "διαχωριστικό πεδίων", ώστε κάθε _λέξη_ να είναι ένα πεδίο.

## Μοτίβα και ενέργειες, συνέχεια

Το μοτίβο μπορεί να παραλειφθεί, οπότε η ενέργεια αξιολογείται _για κάθε καταγραφή εισόδου_.

Η ενέργεια μπορεί να παραλειφθεί, οπότε η προεπιλεγμένη ενέργεια είναι να εκτυπώνεται η τρέχουσα καταγραφή.

### Ειδικά μοτίβα

Υπάρχουν δύο ειδικά μοτίβα που χρησιμοποιούνται συχνά.

- Το `BEGIN` αξιολογεί τη σχετιζόμενη ενέργεια πριν καταναλωθεί οποιαδήποτε είσοδος.
- Το `END` αξιολογεί τη σχετιζόμενη ενέργεια αφού καταναλωθεί όλη η είσοδος.

## Μεταβλητές πεδίων

Αναφέρεσαι στα πεδία ως `$1`, `$2`, `$3` κ.λπ.

Η τρέχουσα καταγραφή είναι το `$0`.

Ορίστε μερικές άλλες συχνά χρησιμοποιούμενες ενσωματωμένες μεταβλητές.

### Ενσωματωμένες μεταβλητές που ελέγχουν την ανάλυση της εισόδου

- Το `RS` είναι το διαχωριστικό καταγραφών της εισόδου.
  Όπως αναφέρθηκε, η προεπιλεγμένη τιμή του είναι ο χαρακτήρας νέας γραμμής.
- Το `FS` είναι το διαχωριστικό πεδίων της εισόδου.

Αυτές οι μεταβλητές συχνά ορίζονται στο μπλοκ ενεργειών `BEGIN`.

### Ενσωματωμένες μεταβλητές που μεταφέρουν πληροφορίες

Αυτές οι μεταβλητές ορίζονται αυτόματα από το AWK κατά την εκτέλεση του προγράμματος.

- Το `NF` αποθηκεύει τον αριθμό των πεδίων στην τρέχουσα καταγραφή.
  - Για να πάρεις την τιμή του τελευταίου πεδίου, χρησιμοποίησε το `$NF`.
- Το `NR` αποθηκεύει τον τρέχοντα αριθμό καταγραφής.
  - Όταν επεξεργάζονται πολλαπλά αρχεία εισόδου, το `NR` θα περιέχει τον συνολικό αριθμό καταγραφών που έχουν υποστεί επεξεργασία μέχρι στιγμής.
- Το `FNR` αποθηκεύει τον τρέχοντα αριθμό καταγραφής του τρέχοντος αρχείου εισόδου.
  - Για να φανεί η διαφορά μεταξύ NR και FNR, ορίστε ένα συνηθισμένο ιδίωμα της AWK.
    ```awk
    NR == FNR {action}
    ```
    Αυτό σημαίνει "αν ο συσσωρευμένος αριθμός καταγραφών ισούται με τον αριθμό καταγραφής του τρέχοντος αρχείου".
    Αυτό μπορεί να ισχύει μόνο για καταγραφές στο _πρώτο αρχείο εισόδου_.

## Αληθείς και ψευδείς τιμές

Το AWK χρησιμοποιεί την ίδια έννοια της αλήθειας τιμών με τη C.

- Ο αριθμός `0` είναι ψευδής.
- Οποιοσδήποτε άλλος αριθμός είναι αληθής.

Επειδή το AWK είναι μια γλώσσα επεξεργασίας κειμένου, οι τιμές αλήθειας επεκτείνονται και στις συμβολοσειρές.

- Μια κενή συμβολοσειρά `""` είναι ψευδής.
- Οποιαδήποτε μη κενή συμβολοσειρά είναι αληθής.

## Σχόλια

Τα σχόλια ξεκινούν με τον χαρακτήρα `#` και εκτείνονται μέχρι το τέλος της γραμμής.

## Παραδείγματα

Σε συστήματα τύπου Unix, το `/etc/passwd` περιέχει πληροφορίες για τους χρήστες.
Κάθε χρήστης περιγράφεται σε ξεχωριστή γραμμή, με τα πεδία να χωρίζονται με άνω και κάτω τελείες.

Για να εμφανίσεις τα ονόματα χρηστών:

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

Πρόσεξε ότι η ενέργεια `{print $1}` δεν έχει μοτίβο, οπότε εκτελείται για κάθε καταγραφή.

Αν θέλουμε να περιορίσουμε την έξοδο μόνο στους χρήστες που χρησιμοποιούν το bash ως φλοιό σύνδεσης, μπορούμε να κάνουμε το εξής:

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
