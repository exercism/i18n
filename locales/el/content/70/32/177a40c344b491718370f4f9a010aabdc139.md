# Οδηγίες

Ένας ερευνητικός οργανισμός παρατήρησε ότι κάποιοι από τους νεότερους ερευνητές του χρησιμοποιούσαν μεθόδους όχι και τόσο βέλτιστες στην ανάλυσή τους.
Μία από αυτές τις μεθόδους είναι να μετατρέπουν αμέσως τις διακριτές πιθανότητες σε floats (δηλαδή πραγματικούς αριθμούς) πριν κάνουν περαιτέρω υπολογισμούς.

Οι ανώτεροι ερευνητές προτιμούν να χρησιμοποιούν ρητούς αριθμούς στους υπολογισμούς, κάτι που μπορεί να προσφέρει μεγαλύτερη ακρίβεια, και θα ήθελαν να μάθουν αν οι κακές πρακτικές των νεότερων ερευνητών έχουν επηρεάσει τα αποτελέσματα των μελετών.

Έγιναν δύο είδη μελετών:
- Έγιναν πολλά τεστ, καθένα από τα οποία επέστρεφε μια διακριτή πιθανότητα επιτυχίας, και στη συνέχεια υπολογίστηκε ο μέσος όρος αυτών των πιθανοτήτων.
- Ελέγχθηκαν πολλά ανεξάρτητα γεγονότα, και η συνολική πιθανότητα να συμβούν όλα τα γεγονότα υπολογίστηκε πολλαπλασιάζοντάς τα μεταξύ τους.

Οι ανώτεροι ερευνητές σου ζητούν να γράψεις συναρτήσεις που θα τους βοηθήσουν να προσδιορίσουν αν υπάρχουν σφάλματα στρογγυλοποίησης στις αναλύσεις από τη χρήση floats, και σου ζητούν να δώσεις έναν ακριβή ρητό αριθμό για το αποτέλεσμα αν υπάρχουν σφάλματα.

## 1. Δώσε τον λόγο των επιτυχιών προς τις δοκιμές

Η συνάρτηση `rationalize(successes, trials)` δέχεται δύο πίνακες, τους `successes` και `trials`.
Για μια θέση `i`, το `successes[i]` αντιστοιχεί στον αριθμό των επιτυχιών που σημειώθηκαν σε `trials[i]` δοκιμές.
Η συνάρτηση επιστρέφει έναν πίνακα ρητών αριθμών των επιτυχιών προς τον αριθμό των δοκιμών, με την ίδια σειρά με τους πίνακες εισόδου.

```julia-repl
julia> rationalize([1, 2, 3], [4, 5, 6])
3-element Vector{Rational{Int64}}:
 1//4
 2//5
 1//2
```

## 2. Βρες τις πραγματικές πιθανότητες που αντιστοιχούν στις επιτυχίες προς τις δοκιμές

Παρομοίως, η συνάρτηση `probabilities(successes, trials)` δέχεται δύο πίνακες, τους `successes` και `trials`.
Επιστρέφει έναν πίνακα από floats των επιτυχιών προς τον αριθμό των δοκιμών, με την ίδια σειρά με τους πίνακες εισόδου.

```julia-repl
julia> probabilities([1, 2, 3], [4, 5, 6])
3-element Vector{Float64}:
 0.25
 0.4
 0.5
```

## 3. Έλεγξε τον μέσο όρο των πιθανοτήτων

Η `checkmean(successes, trials)` δέχεται τους δύο πίνακες, `successes` και `trials`.
Ελέγχει τον μέσο όρο των πραγματικών πιθανοτήτων έναντι του μέσου όρου των ρητών πιθανοτήτων.
- Αν οι δύο πιθανότητες είναι ίσες, η `checkmean` επιστρέφει `true`
- Αν οι δύο πιθανότητες είναι διαφορετικές, η `checkmean` επιστρέφει τη ρητή πιθανότητα.

```julia-repl
julia> successes, trials = [9, 4, 7, 8, 6], [22, 22, 11, 17, 12];
julia> checkmean(successes, trials)
true

julia> successes, trials = [6, 5, 9, 8, 9], [21, 19, 13, 25, 22];
julia> checkmean(successes, trials)
1873629//4754750
```

## 4. Έλεγξε την ανεξάρτητη πιθανότητα

Η `checkprob(successes, trials)` δέχεται τους δύο πίνακες, `successes` και `trials`.
Ελέγχει τη συνολική πιθανότητα των float πιθανοτήτων έναντι της συνολικής πιθανότητας των ρητών πιθανοτήτων.
- Αν οι δύο πιθανότητες είναι ίσες, η `checkprob` επιστρέφει `true`
- Αν οι δύο πιθανότητες είναι διαφορετικές, η `checkprob` επιστρέφει τη ρητή πιθανότητα.

```julia-repl
julia> successes, trials = [2, 9, 4, 4, 5], [15, 11, 17, 19, 15];
julia> checkprob(successes, trials)
true

julia> successes, trials = [9, 8, 5, 4, 3], [22, 14, 19, 25, 18];
julia> checkprob(sucesses, trials)
12//7315
```
