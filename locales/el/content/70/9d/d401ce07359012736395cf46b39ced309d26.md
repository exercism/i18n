# Προσάρτηση οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση      | Τύπος     | Περιγραφή                           |
| ----------- | ---------- | --------- | ----------------------------------- |
| `$a0`       | είσοδος    | διεύθυνση | πίνακας βαρών αντικειμένων          |
| `$a1`       | είσοδος    | διεύθυνση | πίνακας τιμών αντικειμένων          |
| `$a2`       | είσοδος    | ακέραιος  | αριθμός αντικειμένων                |
| `$a3`       | είσοδος    | ακέραιος  | μέγιστο βάρος                       |
| `$v0`       | έξοδος     | ακέραιος  | μέγιστη τιμή                        |
| `$t0-9`     | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
