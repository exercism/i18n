# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες, καθεμία από τις οποίες θα παίρνει μια γραμμή καταγραφής και θα σου ζητά να κάνεις κάτι με αυτήν.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `message` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```julia-repl
julia> message("[ERROR]: Invalid operation")
"Invalid operation"
```

Τυχόν κενά στην αρχή ή στο τέλος πρέπει να αφαιρούνται:

```julia-repl
julia> message("[WARNING]:  Disk almost full\r\n")
"Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `log_level` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο πρέπει να επιστρέφεται με πεζά γράμματα:

```julia-repl
julia> log_level("[ERROR]: Invalid operation")
"error"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη συνάρτηση `reformat` που αναδιαμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής μέσα σε παρενθέσεις:

```julia-repl
julia> reformat("[INFO]: Operation completed")
"Operation completed (info)"
```

----

***Σημείωση:***  Όλες οι συμβολοσειρές σε αυτή την άσκηση είναι στα αγγλικά και περιορίζονται στο σύνολο χαρακτήρων ASCII.
Οι επόμενες έννοιες θα σου δώσουν την ευκαιρία να δουλέψεις με χαρακτήρες Unicode.
