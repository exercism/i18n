# Υποδείξεις

## Γενικά

- Θα χρειαστείς [εκφράσεις υπό συνθήκη][concept-conditionals] για αυτές τις ασκήσεις.

## 1. Σύγκριση χαρακτήρων

- Μπορείς να συγκρίνεις χαρακτήρες με συναρτήσεις όπως οι `char-greaterp`, `char-lessp` και `char=`.

## 2. Προσδιόρισε το "μέγεθος" του χαρακτήρα

- Η Common Lisp έχει δύο συναρτήσεις για να προσδιορίσεις αν ένας χαρακτήρας είναι κεφαλαίος ή πεζός: `upper-case-p` και `lower-case-p`.
- Ένας χαρακτήρας μπορεί να μην είναι ούτε κεφαλαίος ούτε πεζός.

## 3. Άλλαξε το "μέγεθος" του χαρακτήρα

- Η Common Lisp έχει δύο συναρτήσεις για να μετατρέψεις έναν χαρακτήρα σε κεφαλαίο ή πεζό: `char-upcase` και `char-downcase`.

## 4. Προσδιόρισε τον "τύπο" ενός χαρακτήρα

- Η Common Lisp έχει μια συνάρτηση κατηγόρημα `alpha-char-p` που σου λέει αν ένας χαρακτήρας είναι αλφαβητικός.
- Η Common Lisp έχει μια συνάρτηση κατηγόρημα `digit-char-p` που σου λέει αν ένας χαρακτήρας είναι αριθμητικός.
- Μπορείς να χρησιμοποιήσεις το `char=` για να δεις αν δύο χαρακτήρες είναι ίσοι.
- Ο χαρακτήρας κενού γράφεται #\Space στη Common Lisp.
- Ο χαρακτήρας αλλαγής γραμμής γράφεται #\Newline στη Common Lisp.
