# Προσθήκη οδηγιών

## Χρησιμοποίησε UTC

Για να λύσεις αυτό το πρόβλημα, θα χρειαστεί να μετατρέψεις μια τιμή `time_t` σε μια τιμή `struct tm`.
Η βιβλιοθήκη [`time.h`][time.h] σου δίνει δύο συναρτήσεις για να το κάνεις αυτό.
Βεβαιώσου ότι χρησιμοποιείς αυτή που οδηγεί σε χρόνο ημερολογίου εκφρασμένο σε **UTC**.

[time.h]: https://en.cppreference.com/w/c/chrono
