# Προσθήκη οδηγιών

Αυτή είναι μια καλή άσκηση για να πειραματιστείς με μη τυπικά κυριολεκτικά συμβολοσειρών και μεταπρογραμματισμό.

Μια σύντομη εισαγωγή στα μη τυπικά κυριολεκτικά συμβολοσειρών μπορείς να βρεις σε αυτό το [άρθρο ιστολογίου](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html). Ένας λεπτομερής οδηγός μεταπρογραμματισμού μπορείς να βρεις στο [εγχειρίδιο](https://docs.julialang.org/en/v1/manual/metaprogramming/).

Μπορείς να επεκτείνεις τη λύση σου προσθέτοντας τη λειτουργικότητα που περιγράφεται παρακάτω.

Το Μπόνους A απαιτεί μόνο τα βασικά όπως περιγράφονται στο άρθρο ιστολογίου. Το Μπόνους B απαιτεί σημαντικά περισσότερες γνώσεις μεταπρογραμματισμού στη Julia.

## Μπόνους A
Υλοποίησε ένα κυριολεκτικό συμβολοσειράς που λειτουργεί ως `ROT13` στη συμβολοσειρά:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Μπόνους B
Υλοποίησε κυριολεκτικά συμβολοσειρών `R<i>`, `i = 0, ..., 26`, που μετατοπίζουν τη συμβολοσειρά για τιμές `i`:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
