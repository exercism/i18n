# Οδηγίες

Σε αυτή την άσκηση, ας προσπαθήσουμε να λύσουμε ένα κλασικό πρόβλημα.

Ο Bob είναι κλέφτης.
Ύστερα από μήνες προσεκτικού σχεδιασμού, καταφέρνει επιτέλους να παραβιάσει τα συστήματα ασφαλείας ενός πολυτελούς διαμερίσματος.

Μπροστά του βρίσκονται πολλά αντικείμενα, καθένα με μια τιμή (v) και ένα βάρος (w).
Ο Bob, φυσικά, θέλει να μεγιστοποιήσει τη συνολική τιμή που μπορεί να αποκτήσει· θα έπαιρνε ευχαρίστως όλα τα αντικείμενα, αν μπορούσε.
Ωστόσο, προς φρίκη του, συνειδητοποιεί ότι το σακίδιο που κουβαλά μαζί του μπορεί να χωρέσει μόνο περιορισμένο βάρος (W).

Δεδομένου ενός σακιδίου με συγκεκριμένη χωρητικότητα (W), βοήθησε τον Bob να βρει τη μέγιστη τιμή που μπορεί να πάρει από τα αντικείμενα του σπιτιού.
Σημείωσε ότι ο Bob μπορεί να πάρει μόνο ένα από κάθε αντικείμενο.

Όλες οι τιμές που δίνονται θα είναι αυστηρά θετικές.
Τα αντικείμενα θα αναπαρίστανται ως λίστα αντικειμένων.
Κάθε αντικείμενο θα έχει ένα βάρος και μια τιμή.

Για παράδειγμα:

```none
Items: [
  { "weight": 5, "value": 10 },
  { "weight": 4, "value": 40 },
  { "weight": 6, "value": 30 },
  { "weight": 4, "value": 50 }
]

Knapsack Limit: 10
```

Στο παραπάνω παράδειγμα, το πρώτο αντικείμενο έχει βάρος 5 και τιμή 10, το δεύτερο αντικείμενο έχει βάρος 4 και τιμή 40, και ούτω καθεξής.

Σε αυτό το παράδειγμα, ο Bob πρέπει να πάρει το δεύτερο και το τέταρτο αντικείμενο για να μεγιστοποιήσει την τιμή του, η οποία, στην περίπτωση αυτή, είναι 90.
Δεν μπορεί να πάρει περισσότερο από 90, αφού το σακίδιό του έχει όριο βάρους 10.
