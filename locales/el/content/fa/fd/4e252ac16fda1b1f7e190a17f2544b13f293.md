# Instructions

Κάποιοι "άλλοι" προγραμματιστές έχουν δουλέψει πάνω στο project του τηλεκατευθυνόμενου αυτοκινήτου [exercise:csharp/remote-control-competition](). Σε κάλεσαν για να καθαρίσεις τον κώδικα.

## 1. Διαχώρισε τις αρμοδιότητες ανάμεσα στο ίδιο το αυτοκίνητο και στο σύστημα τηλεμετρίας

Αναδιαμόρφωσε την κλάση `RemoteControlCar` ώστε να ξεχωρίσεις τις μεθόδους και τις ιδιότητες τηλεμετρίας που προσπελαύνονται μέσω μιας ιδιότητας `Telemetry`.

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. Απότρεψε άλλον κώδικα από το να αποκτήσει υπερβολικές εξαρτήσεις από τον τύπο `Telemetry`

Βεβαιώσου ότι το στιγμιότυπο `Telemetry` δεν μπορεί να δημιουργηθεί έξω από την εμβέλεια του αυτοκινήτου.

## 3. Απότρεψε άλλον κώδικα από το να εξαρτάται από τη δομή `Speed`

Βεβαιώσου ότι η δομή `Speed` δεν μπορεί να χρησιμοποιηθεί έξω από την εμβέλεια της κλάσης `RemoteControlCar`.

## 4. Απότρεψε άλλον κώδικα από το να εξαρτάται από την απαρίθμηση `SpeedUnits`

Βεβαιώσου ότι η απαρίθμηση `SpeedUnits` δεν μπορεί να χρησιμοποιηθεί έξω από την εμβέλεια της κλάσης `RemoteControlCar`.
