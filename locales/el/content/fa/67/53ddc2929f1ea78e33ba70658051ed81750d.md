# Πρόγραμμα σπουδών - Η πρώτη άσκηση

Η πρώτη άσκηση θα πρέπει να καλύπτει την έννοια `basics` και να μην έχει προαπαιτούμενα. Θα πρέπει να παρέχει μόνο τις πληροφορίες που χρειάζονται για να μπορεί ο μαθητής να λύσει την άσκηση που έχει μπροστά του.

Πολλές διαδρομές έχουν ήδη υλοποιήσει μια άσκηση που καλύπτει το `basics`. Για να εξοικειωθείς με το τι διδάσκεται συνήθως σε μια τέτοια άσκηση, σου προτείνουμε να γραφτείς σε μερικές διαφορετικές διαδρομές που έχουν Λειτουργία Μάθησης και να λύσεις την πρώτη άσκηση έννοιας.

Κάθε γλώσσα είναι διαφορετική και μπορεί να διαπιστώσεις ότι χρειάζεται να εισαγάγεις περισσότερα από ό,τι κάνουν άλλες διαδρομές, ή λιγότερα. Για παράδειγμα, αν χρειάζεται να μεταγλωττίσεις ένα πρόγραμμα για να τρέξει, αυτό είναι κάτι που θα θέλεις να αναφέρεις στην εισαγωγή της άσκησης.

Άλλα πράγματα που καλύπτονται συχνά στην άσκηση `basics` είναι:

- ορισμοί συναρτήσεων ή μεθόδων
- κλήση συναρτήσεων
- πέρασμα ορισμάτων σε συναρτήσεις
- ανάθεση μιας τιμής σε ένα όνομα (μεταβλητές ή/και σταθερές)

Χρησιμοποίησε όσο το δυνατόν λιγότερους τύπους δεδομένων. Αν τα καταφέρνεις, χρησιμοποίησε μόνο ακέραιους, καθώς ο συμβολισμός τους είναι ο ίδιος στις περισσότερες γλώσσες και θα είναι γνωστός σε σχεδόν όλους.

Αν υπάρχει διαδρομή για μια γλώσσα παρόμοια με τη δική σου, ρίξε μια ματιά για να δεις αν μπορείς να κάνεις fork την άσκησή τους και να τη χρησιμοποιήσεις ως σημείο εκκίνησης.

Στόχευσε στη συντομία. Δε θέλεις να φορτώσεις τους μαθητές με πληροφορίες. Η εισαγωγή θα πρέπει να εξηγεί _τόσα μόνο όσα χρειάζεται_ ώστε ο μαθητής να μπορεί να κοιτάξει τον κώδικα και να αναγνωρίσει ποια είναι τα διάφορα μέρη του. Δε χρειάζεται να καταλάβουν σε βάθος τίποτα από αυτά, αλλά ούτε και να μείνουν να αναρωτιούνται τι είναι το καθένα.

Ο μαθητής θα πρέπει να χρειάζεται να _χρησιμοποιήσει_ ενεργά μόνο μία ή δύο έννοιες.
