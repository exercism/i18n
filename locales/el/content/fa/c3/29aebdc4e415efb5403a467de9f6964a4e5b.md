# Κλάσεις

Οι κλάσεις είναι μια κεντρική έννοια στον [αντικειμενοστραφή προγραμματισμό][object-oriented-programming].
[Στην Crystal, τα πάντα είναι αντικείμενα][everything-is-an-object], κάθε αντικείμενο έχει έναν τύπο και μπορεί να ανταποκρίνεται σε κάποιες μεθόδους.
Οι κλάσεις είναι πρότυπα για τη δημιουργία αντικειμένων, παρέχοντας αρχικές τιμές για την κατάσταση, όπως οι μεταβλητές, και υλοποιήσεις συμπεριφοράς, όπως οι μέθοδοι.
Τα αντικείμενα είναι στιγμιότυπα κλάσεων που περιέχουν όλες τις μεταβλητές στιγμιοτύπου και τις καταστάσεις.

## Ορισμός κλάσης

Μια κλάση ορίζεται με τη λέξη-κλειδί `class`, ακολουθούμενη από το όνομα της κλάσης γραμμένο σε `UpperCamelCase`.

```crystal
class Account
end
```

## Δημιουργία στιγμιοτύπου

Για να [δημιουργήσεις ένα στιγμιότυπο μιας κλάσης][new-initialize], κάλεσε το όνομα της κλάσης χρησιμοποιώντας τη μέθοδο `new`.

```crystal
class Account
end

account = Account.new
```

Στο παραπάνω παράδειγμα, η μεταβλητή `account` είναι ένα στιγμιότυπο της κλάσης `Account`.

Όταν δημιουργείς ένα στιγμιότυπο, μια ειδική μέθοδος που ονομάζεται `initialize` λειτουργεί ως κατασκευαστής.
Καλείται όταν δημιουργείται ένα στιγμιότυπο.
Ο κατασκευαστής σου επιτρέπει να ορίσεις την αρχική κατάσταση του στιγμιοτύπου.
Η μέθοδος `initialize` μπορεί να δεχτεί ορίσματα, τα οποία περνιούνται κατά τη δημιουργία ενός στιγμιοτύπου.

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
Η μέθοδος `initialize` δεν μπορεί να επιστρέψει χειροκίνητα μια τιμή. Αντίθετα, η `new` επιστρέφει το νέο στιγμιότυπο που δημιουργήθηκε.

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## Μέθοδοι στιγμιοτύπου

Μια μέθοδος στιγμιοτύπου είναι μια μέθοδος που είναι διαθέσιμη σε ένα στιγμιότυπο μιας κλάσης και μπορεί να κληθεί πάνω σε αυτό το στιγμιότυπο.
Οι μέθοδοι στιγμιοτύπου ορίζονται με τη λέξη-κλειδί `def`, ακολουθούμενη από το όνομα της μεθόδου.
Ορίζονται μέσα στον ορισμό της κλάσης.

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## Μεταβλητές στιγμιοτύπου

Οι [μεταβλητές στιγμιοτύπου][instance-variable] είναι μεταβλητές που είναι διαθέσιμες σε όλες τις μεθόδους του στιγμιοτύπου.
Για να προσπελάσεις μια μεταβλητή στιγμιοτύπου, πρέπει να ορίσεις μια μέθοδο στιγμιοτύπου.
Μπορούν να αρχικοποιηθούν στη μέθοδο `initialize`.
Ορίζονται με το πρόθεμα `@`.

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

Οι μεταβλητές στιγμιοτύπου μπορούν επίσης να οριστούν μέσα στον ορισμό της κλάσης.

```crystal
class Account
  @age = 0
end
```

### Μεταβλητές στιγμιοτύπου με αρχικοποίηση

Οι μεταβλητές στιγμιοτύπου μπορούν να αρχικοποιηθούν με ένα όρισμα που περνιέται στη μέθοδο `initialize`.
Επειδή η Crystal δεν μπορεί να συμπεράνει τον τύπο του ορίσματος που χρησιμοποιείται κατά την αρχικοποίηση, αυτός πρέπει να δηλώνεται.
Αν θέλεις να διαβάσεις περισσότερα για αυτό, μπορείς να δεις: [συμπερασμός τύπων][type-inference].
Για να δηλώσεις τον τύπο της μεταβλητής, μπορείς να χρησιμοποιήσεις το σύμβολο `:`, ακολουθούμενο από τον τύπο.
Για παράδειγμα, αν θέλεις να δημιουργήσεις μια μεταβλητή στιγμιοτύπου με όνομα `balance` τύπου `Int32`, μπορείς να κάνεις το εξής: `@balance : Int32`.
Ή, αν θέλεις να δημιουργήσεις μια μεταβλητή στιγμιοτύπου με όνομα `raining` τύπου `Bool`, μπορείς να κάνεις το εξής: `@raining : Bool`.

Υπάρχουν μερικοί τρόποι για να το υλοποιήσεις, είτε δηλώνοντας στη μέθοδο `initialize` το όρισμα με τον τύπο του και έπειτα αναθέτοντας τη μεταβλητή στιγμιοτύπου στο όρισμα, όπως στο παρακάτω παράδειγμα:

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

Ένας άλλος τρόπος είναι να δηλώσεις τον τύπο της μεταβλητής στιγμιοτύπου στον ορισμό της κλάσης με τη μορφή: `@<variable> : <Type>`, όπως στο παρακάτω παράδειγμα:

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

## Τροποποίηση μεταβλητών στιγμιοτύπου

Οι μέθοδοι μπορούν να τροποποιούν μεταβλητές στιγμιοτύπου.
Αυτές οι μέθοδοι μπορούν να κληθούν πάνω στο στιγμιότυπο της κλάσης.
Όταν μια μέθοδος τροποποιεί μια μεταβλητή στιγμιοτύπου, αυτή η αλλαγή είναι διαθέσιμη μόνο στο στιγμιότυπο της κλάσης στο οποίο την κάλεσες.

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## Μέθοδοι κλάσης

Οι [μέθοδοι κλάσης][class-methods] είναι μέθοδοι που ορίζονται για μια κλάση αλλά όχι για τα στιγμιότυπά της.
Προσφέρουν έναν τρόπο να δημιουργείς μεθόδους που δεν εξαρτώνται από την κατάσταση του στιγμιοτύπου.
Ορίζονται με τη λέξη-κλειδί `def`, ακολουθούμενη από `self.<method name>`.
Το `self` είναι μια αναφορά στον χώρο ονομάτων από τον οποίο καλείται το self.
Σε αυτή την περίπτωση, αναφέρεται στην κλάση `Account`.
Θα ήταν το ίδιο σαν να είχες γράψει `Account.`, αλλά το `self.` είναι ο προτιμότερος τρόπος.

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
