# Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις τους κανόνες για την ιστοσελίδα ενός κινηματογράφου.

## 1. Έλεγξε αν ένας θεατής δικαιούται την έκπτωση τρίτης ηλικίας

Ο κινηματογράφος προσφέρει έκπτωση για τις "συντάξεις γήρατος".
Όποιος είναι 60 ετών ή μεγαλύτερος πληρώνει 10.00 για εισιτήριο.
Όποιος είναι μικρότερος πληρώνει το πλήρες ποσό των 15.00.

Γράψε τη μέθοδο `Moviegoer#ticket_price` χρησιμοποιώντας μια τριαδική εντολή.

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. Έλεγξε αν ένας θεατής επιτρέπεται να δει τρομακτικές ταινίες

Ο κινηματογράφος έχει ένα απλοποιημένο σύστημα επαλήθευσης ηλικίας.
Αν είσαι 18 ή μεγαλύτερος, μπορείς να δεις τρομακτικές ταινίες.
Αν είσαι μικρότερος, δεν μπορείς.

Υλοποίησε τη μέθοδο `Moviegoer#watch_scary_movie?`.
Θα πρέπει να επιστρέφει αν κάποιος επιτρέπεται να δει την ταινία ή όχι.

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. Έλεγξε αν ένας θεατής δικαιούται δωρεάν ποπ κορν

Ο κινηματογράφος έχει ένα πρόγραμμα Movie Club.
Τα μέλη παίρνουν δωρεάν ποπ κορν όταν δουν οποιαδήποτε ταινία.

Υλοποίησε τη μέθοδο `Moviegoer.claim_free_popcorn!`.
Αν ο θεατής είναι μέλος του Movie Club, θα πρέπει να ανταμείβεται με το δωρεάν ποπ κορν του.
Αν δεν είναι, η μέθοδος θα πρέπει να πετάει την εξαίρεση `UnsupportedOperation` που ορίζεται στην αρχή του κώδικα.

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
Σε αυτή την άσκηση, αναμένεται να ορίσεις την εξαίρεση `UnsupportedOperation` για μια συγκεκριμένη εμβέλεια.
~~~~
