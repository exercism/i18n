# Εγκατάσταση

Ο πιο απλός τρόπος για να εγκαταστήσεις την PureScript είναι μέσω Node.js και NPM.

Αν δεν έχεις ήδη εγκατεστημένο το Node.js στον υπολογιστή σου, μπορείς να το κατεβάσεις από την [ιστοσελίδα του Node.js](https://nodejs.org/). Μόλις έχεις το Node.js έτοιμο και σε λειτουργία, πληκτρολόγησε αυτή την εντολή στο τερματικό για να εγκαταστήσεις τον μεταγλωττιστή της PureScript και το εργαλείο build Spago:

    npm install --global purescript spago

Περισσότερες πληροφορίες θα βρεις στο [αποθετήριο της PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
