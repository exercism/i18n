# Εισαγωγή

## Συμβολοσειρές

Στη Common Lisp οι συμβολοσειρές είναι [διανύσματα][concept-vectors] [χαρακτήρων][concept-characters]. Γράφονται ως χαρακτήρες μέσα σε διπλά εισαγωγικά (_π.χ._ "Hello World!").

Το κατηγόρημα `stringp` θα επιστρέψει αληθή τιμή μόνο αν η τιμή που του δίνεται είναι συμβολοσειρά.

Οι συμβολοσειρές μπορούν να χωριστούν σε υποσυμβολοσειρές με τη συνάρτηση `subseq`, στην οποία δίνεις τη συμβολοσειρά, μια θέση έναρξης και προαιρετικά μια θέση λήξης.
Η αρίθμηση των θέσεων ξεκινά από το μηδέν.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Οι συμβολοσειρές μπορούν να συγκριθούν ως προς την ισότητα με το `string=`.
Αν θέλεις να αγνοηθεί η διάκριση πεζών και κεφαλαίων των χαρακτήρων, μπορείς να χρησιμοποιήσεις το `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Λειτουργίες όπως η μετατροπή μιας συμβολοσειράς σε κεφαλαία, σε πεζά και η κεφαλαιοποίησή της μπορούν να γίνουν με τις `string-upcase`, `string-downcase` και `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
