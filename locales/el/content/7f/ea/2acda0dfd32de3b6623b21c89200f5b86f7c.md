# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο να παρακολουθείς τις υψηλές βαθμολογίες για το πιο δημοφιλές παιχνίδι στην τοπική αίθουσα arcade.

Έχεις 5 συναρτήσεις να υλοποιήσεις, που σχετίζονται κυρίως με τον χειρισμό ενός αντικειμένου που κρατά υψηλές βαθμολογίες.

## 1. Δημιούργησε έναν νέο πίνακα υψηλών βαθμολογιών

Δημιούργησε μια συνάρτηση `createScoreBoard` που δημιουργεί ένα αντικείμενο το οποίο λειτουργεί ως πίνακας υψηλών βαθμολογιών.
Τα κλειδιά αυτού του αντικειμένου θα είναι τα ονόματα των παικτών, οι τιμές θα είναι οι βαθμολογίες τους.
Για λόγους δοκιμών, θέλεις να συμπεριλάβεις απευθείας μία καταχώριση στο αντικείμενο.
Αυτή η αρχική καταχώριση θα πρέπει να αποτελείται από το `The Best Ever` ως όνομα παίκτη και το `1000000` ως βαθμολογία.

```javascript
createScoreBoard();
// returns an object with one initial entry
```

## 2. Πρόσθεσε παίκτες σε έναν πίνακα βαθμολογίας

Για να προσθέσεις έναν παίκτη στον πίνακα υψηλών βαθμολογιών, όρισε τη συνάρτηση `addPlayer`.
Δέχεται 3 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον αντικείμενο πίνακα βαθμολογίας.
- Η δεύτερη παράμετρος είναι το όνομα ενός παίκτη ως συμβολοσειρά.
- Η τρίτη παράμετρος είναι η βαθμολογία ως αριθμός.

Η συνάρτηση επιστρέφει το ίδιο αντικείμενο πίνακα βαθμολογίας που της πέρασες, αφού προσθέσει τον νέο παίκτη.

```javascript
addPlayer({ 'Dave Thomas': 0 }, 'José Valim', 486373);
// => {'Dave Thomas': 0, 'José Valim': 486373}
```

## 3. Αφαίρεσε παίκτες από έναν πίνακα βαθμολογίας

Αν οι παίκτες παραβιάζουν τους κανόνες της αίθουσας arcade, αφαιρούνται χειροκίνητα από τον πίνακα υψηλών βαθμολογιών.
Όρισε τη `removePlayer`, η οποία δέχεται 2 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον αντικείμενο πίνακα βαθμολογίας.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά.

Αυτή η συνάρτηση θα πρέπει να αφαιρεί την καταχώριση του συγκεκριμένου παίκτη από τον πίνακα και να επιστρέφει τον πίνακα στη συνέχεια.
Αν ο παίκτης δεν ήταν εξαρχής στον πίνακα, δεν θα πρέπει να συμβεί τίποτα στον πίνακα.
Θα πρέπει να επιστραφεί ως έχει.

```javascript
removePlayer({ 'Dave Thomas': 0 }, 'Dave Thomas');
// => {}

removePlayer({ 'Dave Thomas': 0 }, 'Rose Fanaras');
// => { 'Dave Thomas': 0 }
```

## 4. Αύξησε τη βαθμολογία ενός παίκτη

Αν ένας παίκτης ολοκληρώσει άλλο ένα παιχνίδι στην αίθουσα arcade, ένα συγκεκριμένο ποσό πόντων θα προστεθεί στην προηγούμενη βαθμολογία στον πίνακα.
Υλοποίησε τη `updateScore`, η οποία δέχεται 3 παραμέτρους:

- Η πρώτη παράμετρος είναι ένα υπάρχον αντικείμενο πίνακα βαθμολογίας.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη του οποίου η βαθμολογία θα πρέπει να αυξηθεί.
- Η τρίτη παράμετρος είναι η βαθμολογία που θέλεις να **προσθέσεις** στην αποθηκευμένη υψηλή βαθμολογία.

Η συνάρτηση θα πρέπει να επιστρέφει τον πίνακα βαθμολογίας αφού γίνει η ενημέρωση.

```javascript
updateScore({ 'Freyja Ćirić': 12771008 }, 'Freyja Ćirić', 73);
// => {"Freyja Ćirić", 12771081}
```

## 5. Εφάρμοσε τους πόντους μπόνους της Δευτέρας

Η αίθουσα arcade κρατά έναν ξεχωριστό πίνακα βαθμολογίας τις Δευτέρες.
Στο τέλος της ημέρας, κάθε παίκτης σε αυτόν τον πίνακα παίρνει 100 επιπλέον πόντους.

Υλοποίησε τη συνάρτηση `applyMondayBonus` που δέχεται έναν πίνακα βαθμολογίας.
Η συνάρτηση προσθέτει τους πόντους μπόνους για κάθε παίκτη που είναι καταγεγραμμένος σε αυτόν τον πίνακα.
Στη συνέχεια, ο πίνακας επιστρέφεται.

```javascript
const scoreBoard = {
  'Dave Thomas': 44,
  'Freyja Ćirić': 539,
  'José Valim': 265,
};

applyMondayBonus(scoreBoard);
// => { 'Dave Thomas': 144, 'Freyja Ćirić': 639, 'José Valim': 365 }
```
