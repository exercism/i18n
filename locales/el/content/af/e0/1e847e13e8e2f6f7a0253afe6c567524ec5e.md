# Σχετικά

Οι δύο κύριοι τύποι ιδιοτήτων είναι

1. οι αυτόματα υλοποιούμενες ιδιότητες, όπου οι προσπελαστές `get` και `set` δεν έχουν σώμα.
   Μπορεί να έχουν αρχικοποιηθεί ρητά ή όχι. Για παράδειγμα:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. εκείνες όπου οι προσπελαστές αξιολογούν εκφράσεις και εκτελούν εντολές. Ο κώδικας μπορεί
   να είναι τόσο απλός όσο η επιστροφή ή η ανάθεση τιμής σε ένα πεδίο υποστήριξης. Για παράδειγμα:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

Υπάρχει σημαντική επικάλυψη στη συμπεριφορά και στις δυνατότητες μεταξύ ιδιοτήτων και μεθόδων.
Όταν δεν είναι αυτόματα υλοποιούμενες, οι ιδιότητες μπορούν να περιέχουν οποιαδήποτε εντολή ή έκφραση
που μπορεί να εμφανιστεί μέσα στην εμβέλεια της κλάσης. Σε μια συνηθισμένη περίπτωση, συχνά
περιγράφονται ως ένα περιτύλιγμα γύρω από ένα πεδίο υποστήριξης.
Αν και τις περισσότερες φορές είναι προφανές αν θα υλοποιήσεις μια συμπεριφορά ως ιδιότητα ή ως μέθοδο σε μια
συγκεκριμένη περίπτωση, συχνά αποτελεί θέμα κρίσης για τον προγραμματιστή, και ειδικότερα πόσος κώδικας
θα πρέπει να εκτελείται μέσα στους προσπελαστές. Η επικύρωση σε έναν προσπελαστή set και ο απλός υπολογισμός ή η
μορφοποίηση σε έναν προσπελαστή get συναντώνται συχνά:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

Όπως τα άλλα μέλη της κλάσης, έτσι και οι ιδιότητες μπορούν να έχουν επίπεδα πρόσβασης.
Τις περισσότερες φορές, οι ιδιότητες έχουν ένα μη ιδιωτικό επίπεδο πρόσβασης, σύμφωνα με
τον βασικό τους σκοπό. Μερικές φορές, ένας από τους προσπελαστές έχει
διαφορετικό επίπεδο πρόσβασης από την ιδιότητα. Στην περίπτωση του `TareWeight`,
κάτω από τον μάλλον τεχνητό περιορισμό της "ασφάλειας", υπήρχε η δυνατότητα
να έχεις μια δημόσια ιδιότητα με ιδιωτικό προσπελαστή get. Αυτό σημαίνει ότι κώδικας εκτός
της κλάσης μπορεί να ορίσει την τιμή της ιδιότητας, αλλά μπορεί να τη διαβάσει (get) μόνο κώδικας μέσα
στην κλάση.

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

Υποστηρίζονται επίσης προσπελαστές set που δεν είναι δημόσιοι, αλλά πιο συνηθισμένη περίπτωση είναι
να παραλείπεται εντελώς ο προσπελαστής set. Αυτό συμβαίνει ίσως επειδή
η τιμή της ιδιότητας ορίζεται στον κατασκευαστή της κλάσης.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

Αυτή η άσκηση ασχολήθηκε με τη βασική χρήση των ιδιοτήτων. Θα βρεις πιο προχωρημένα
θέματα σε άλλες ασκήσεις:

- ιδιότητες με σώμα έκφρασης, προσπελαστές get και προσπελαστές set (καλύπτονται από τα μέλη με σώμα έκφρασης)
- ιδιότητες σε διεπαφές (καλύπτονται από τις Διεπαφές)
- ιδιότητες/αφηρημένες ιδιότητες σε αφηρημένες κλάσεις (καλύπτονται από την Κληρονομικότητα)
- χρήση της λέξης-κλειδιού `readonly` με ιδιότητες (καλύπτεται από την Αμεταβλητότητα)
- στατικές ιδιότητες (καλύπτονται από τα Στατικά)
- ευρετήρια (καλύπτονται από τα Ευρετήρια)
