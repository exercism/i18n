## Μια πολύ σύντομη ιστορία

Ο χειρισμός χαρακτήρων στους υπολογιστές ήταν πολύ πιο απλός τις προηγούμενες δεκαετίες, όταν οι προγραμματιστές θεωρούσαν ότι τα αγγλικά ήταν η μόνη σημαντική γλώσσα.
Δηλαδή: 26 γράμματα, κεφαλαία και πεζά, 10 ψηφία, μερικά σημεία στίξης, συν έναν κωδικό (0x07) για να χτυπήσει ένα κουδουνάκι, και όλα χωρούσαν σε 7 bits: το σύνολο χαρακτήρων ASCII.

Φυσικά, οι άνθρωποι άρχισαν να ρωτούν τι γίνεται με τα à, ä και Ł, μετά άλλοι άρχισαν να ρωτούν για τα ऄ, ஹ και ญ, και οι νέοι ήθελαν emojis 😱.
Τι να κάνουμε;

Για να μην τα πολυλογούμε, πολλοί έξυπνοι και υπομονετικοί άνθρωποι χρειάστηκε να συμμετάσχουν σε επιτροπές για χρόνια, επεξεργαζόμενοι τις λεπτομέρειες του συνόλου χαρακτήρων Unicode και κωδικοποιήσεων όπως το UTF-8, και πολλά προγράμματα χρειάστηκαν μια _πολύ_ περίπλοκη επανεγγραφή.
Επίσης, εισήχθησαν πολλά νέα bugs.

Για να μην καταστραφούν _τα πάντα_, ο σχεδιασμός Unicode/UTF-8 διασφαλίζει ότι οι πρώτοι 127 κωδικοί είναι ίδιοι με το ASCII _(ακόμα και το κουδουνάκι)_.

## Χαρακτήρες στη Julia

Οι γλώσσες που σχεδιάστηκαν μετά το 2005 περίπου έχουν το τεράστιο πλεονέκτημα ότι υπήρχε ήδη ένα αρκετά σταθερό πρότυπο Unicode.

Η Julia (κυκλοφόρησε για πρώτη φορά το 2012) μπόρεσε να υποθέσει ότι τα πάντα θα ήταν Unicode: χαρακτήρες, συμβολοσειρές, ονόματα μεταβλητών και συναρτήσεων, μαθηματικοί τελεστές...

Όπως λέει το εγχειρίδιο, "Η Julia κάνει την ενασχόληση με απλό κείμενο ASCII απλή και αποδοτική, και ο χειρισμός του Unicode είναι όσο το δυνατόν πιο απλός και αποδοτικός".
Προσέξτε το "όσο το δυνατόν", είναι σημαντικό κομμάτι της δήλωσης.

***Τα κυριολεκτικά χαρακτήρων γράφονται με μονά εισαγωγικά και είναι διακριτά από τις συμβολοσειρές που γράφονται με διπλά εισαγωγικά.***

Αυτό είναι προφανές σε όσους προέρχονται από τον κόσμο της C/C++, αλλά μπορεί να μπερδέψει όσους προγραμματίζουν σε Python και Javascript.

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

Από τα παραδείγματα βλέπουμε ότι ο τύπος είναι `Char` και ότι η Julia έχει επιπλέον πληροφορίες για την κατηγορία του χαρακτήρα.

Κοιτάζοντας πιο προσεκτικά, φαίνεται ότι αυτοί οι χαρακτήρες μπορούν να αναπαρασταθούν με 4 δεκαεξαδικά ψηφία.
Το πλήρες σύνολο χαρακτήρων χρειάζεται έως και 6 δεκαεξαδικά ψηφία.

Αυτοί οι αριθμοί ονομάζονται "code points" και προς το παρόν κυμαίνονται από U+0000 έως U+10FFFF.
Εμφανίζονται στο REPL, αλλά μέσα στον κώδικα χρησιμοποίησε τη `codepoints()` για να τους πάρεις.

Η μετατροπή μεταξύ `Char` και `Int` είναι απλή:

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

Ο μεταγλωττιστής επιτρέπει _μερικές_ μορφές ακέραιης αριθμητικής σε `Char`:

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## Συναρτήσεις για χαρακτήρες

Πολλές συναρτήσεις χειρισμού συμβολοσειρών μπορούν να λειτουργήσουν και με είσοδο `Char`.

- Για τα κατάλληλα αλφάβητα, άλλαξε πεζά σε κεφαλαία και αντίστροφα με τις `uppercase()` και `lowercase()`.
- Έλεγξε αν είναι κεφαλαία ή πεζά με τις `isuppercase()` και `islowercase()`.
- Έλεγξε τον τύπο του χαρακτήρα με:
  - `isletter()`, καλύπτει πολλά αλφάβητα
  - `isdigit()`, ελέγχει αυστηρά για 0:9
  - `isnumeric()`, ευρύτερη από την `isdigit`, οπότε `true` για το ¾ και για διάφορα μη ευρωπαϊκά συστήματα γραφής
  - `isxdigit()`, δεκαεξαδικά ψηφία
  - `isascii()`, χαρακτήρας προ-Unicode
  - `ispunct()`, σημεία στίξης
  - `isspace()`, οποιοσδήποτε χαρακτήρας κενού
  - `isprint()`, εκτυπώσιμοι χαρακτήρες (το αντίθετο είναι η `iscntrl()`)

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Μετατροπές μεταξύ διανύσματος Char και String

Για τη μετατροπή από String σε Vector από Char, μπορούμε να χρησιμοποιήσουμε τη `collect()`.

Για τη μετατροπή από Vector από Char σε String, υπάρχει ο κατασκευαστής `String()`.

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

Αυτό λειτουργεί με οποιουσδήποτε χαρακτήρες, όχι μόνο με ASCII.

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

Σημείωσε ότι ο κατασκευαστής `String()` λειτουργεί πάνω σε ένα Vector.
Για να _μετατρέψεις_ έναν μεμονωμένο `Char` σε συμβολοσειρά ενός χαρακτήρα, η συνάρτηση είναι η `string()`, με πεζό `s`.

```julia-repl
julia> string('a')
"a"
```

## Αποθήκευση

Όλα όσα είδαμε μέχρι τώρα στο κείμενο φαίνονται σχετικά απλά, οπότε όντως δεν υπάρχει και πολύ πράγμα για να ανησυχείς;

Δυστυχώς, αυτό είναι υπερβολικά αισιόδοξο!

Μια επιπλοκή προκύπτει από την ανάγκη για "έως και" 6 δεκαεξαδικά ψηφία ανά code point.
Αυτό σημαίνει ότι διαφορετικοί χαρακτήρες χρειάζονται διαφορετική ποσότητα χώρου στη μνήμη όταν κωδικοποιούνται σε UTF-8.

Ένα byte μπορεί να αποθηκεύσει μόνο αριθμούς χωρίς πρόσημο έως το 255, δύο δεκαεξαδικά ψηφία, οπότε το UTF-8 χρησιμοποιεί μεταβλητό αριθμό byte (1 έως 4) για να αποθηκεύσει ένα `Char`.
Αυτά ονομάζονται "code units" και η συνάρτηση `ncodeunits()` επιστρέφει τον αριθμό που χρειάζεται για έναν δεδομένο χαρακτήρα.

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

Επίσης, δεν έχουν όλα όσα μπορούν να εμφανιστούν στην οθόνη το δικό τους μοναδικό code point.
Κάποιοι οπτικά διακριτοί χαρακτήρες θεωρούνται ότι προέρχονται από άλλους, οπότε το Unicode τους αντιμετωπίζει ως έναν γονικό χαρακτήρα συν έναν τροποποιητή.
