# Θέση κράτησης

## Υλοποίηση πράξεων της List

Ο σκοπός αυτής της άσκησης είναι να υλοποιήσεις εσύ μερικές από τις μεθόδους της List.
Είναι φυσικό να χρησιμοποιήσεις ένα αντικείμενο List στο backend για να κρατήσεις τα δεδομένα.
Μην πειράξεις τις μεθόδους της List (όπως `where`, `map`, κ.λπ.).

Υπάρχουν μερικές "πρωτογενείς" πράξεις της List που είναι αναπόφευκτες, όπως:

* τεμαχισμός: `list[from..to]`
* προσθήκη: `list.add(item)`

## Πρωτόκολλο επαναλήπτη

Οι πράξεις της List που πρέπει να υλοποιήσεις έχουν να κάνουν με διάφορους τρόπους επανάληψης.
Διάβασε για [το πρωτόκολλο επαναλήπτη][iter].
Έπειτα θα μπορείς να κάνεις:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
