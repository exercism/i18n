# Να `grep` ή να μην `grep`; Ιδού το ερώτημα

## Προσαρμογές της διαδρομής AWK στις απαιτήσεις

Δεν είσαι υποχρεωμένος να υλοποιήσεις σωστή ανάλυση της γραμμής εντολών: τα flags δίνονται σε μια συμβολοσειρά χωρισμένη με κενά, που είναι απλό να τη χωρίσεις.
```sh
gawk -f grep.awk -v flags="l v" -v pattern="hello" file1.txt file2.txt
```

Όπως το πραγματικό grep, το πρόγραμμά σου θα επιστρέψει μια **μη μηδενική κατάσταση εξόδου** όταν _δεν βρεθούν αντιστοιχίες_.
