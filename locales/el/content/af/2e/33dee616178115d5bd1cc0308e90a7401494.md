# Ασκήσεις Πρακτικής

Οι Ασκήσεις Πρακτικής στοχεύουν να δώσουν στον μαθητή την ευκαιρία να εξασκηθεί στο να συνδυάζει πολλές έννοιες και να εξερευνά πώς να λύνει ένα πρόβλημα, χωρίς υποδείξεις, σε μια δεδομένη γλώσσα.

Κάθε άσκηση έχει προαπαιτούμενες έννοιες. Μια Άσκηση Πρακτικής ξεκλειδώνεται όταν ο μαθητής έχει ολοκληρώσει με επιτυχία τις Ασκήσεις Εννοιών για τις προαπαιτούμενες έννοιες.
