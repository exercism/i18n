# Σχετικά

Η μονάδα `Time` χρησιμοποιείται για την εμφάνιση ημερομηνιών / ωρών αναγνώσιμων από τον άνθρωπο.
Αν και είναι τεχνικά δυνατό να χειριστείς χρόνους με το `Time`, υπάρχουν πακέτα της κοινότητας του Elm που ταιριάζουν πολύ περισσότερο σε αυτή τη δουλειά, όπως το [`justinmimbs/date`][date] ή το [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Οι χρόνοι αναπαρίστανται από τον αδιαφανή τύπο `Posix`, που περικλείει τον χρόνο της εποχής Unix, τον αριθμό των χιλιοστών του δευτερολέπτου που έχουν περάσει από την 1η Ιανουαρίου 1970 τα μεσάνυχτα UTC.
Ένα `Posix` είναι μια μη αμφίσημη τιμή που δεν διαφέρει μεταξύ ζωνών ώρας, επομένως είναι καλή επιλογή για τη διατήρηση του χρόνου.
Σε μια εφαρμογή Elm, οι τιμές `Posix` συνήθως παρέχονται από εξωτερικές πηγές, όπως ο περιηγητής.

Είναι δυνατό να μετατρέψεις ένα `Posix` σε έναν αριθμό χιλιοστών του δευτερολέπτου και αντίστροφα με τις παρακάτω συναρτήσεις:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Ζώνες ώρας

Στην καθημερινή μας ζωή, εμείς οι άνθρωποι συνήθως δεν διαβάζουμε `Posix` και προτιμάμε την τοπική ώρα, η οποία εξαρτάται από την τοποθεσία μας στη Γη και από τους τοπικούς κανόνες θερινής ώρας.
Στην Elm, αυτή η πληροφορία κωδικοποιείται στον αδιαφανή τύπο `Zone`, που συνήθως παρέχεται από τον περιηγητή.

Υπάρχει μια ειδική `Zone` που είναι πάντα προσβάσιμη:

```elm
utc : Zone
```

## Ανθρώπινες ώρες

Με ένα `Posix` και μια `Zone`, έχουμε αρκετές πληροφορίες για να δείξουμε την τοπική ώρα σε οποιοδήποτε επίπεδο λεπτομέρειας.
Ακολουθεί μια λίστα με τις συναρτήσεις που μπορούν να χρησιμοποιηθούν γι' αυτό:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Θα έχεις προσέξει δύο ακόμη προσαρμοσμένους τύπους του `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Αφήνεται στους χρήστες να μετατρέψουν αυτούς τους προσαρμοσμένους τύπους σε τιμές αναγνώσιμες από τον άνθρωπο.
