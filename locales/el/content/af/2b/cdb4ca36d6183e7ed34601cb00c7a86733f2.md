# Εισαγωγή

Οι αδιαφανείς τύποι στη Gleam είναι προσαρμοσμένοι τύποι όπου μόνο το άρθρωμα που ορίζει τον τύπο μπορεί να κατασκευάσει τιμές αυτού του τύπου ή να κάνει αντιστοίχιση προτύπων σε αυτές. Αυτό είναι χρήσιμο για τη δημιουργία τύπων που πρέπει να χρησιμοποιούνται μόνο με έναν συγκεκριμένο τρόπο.

Οι αδιαφανείς τύποι ορίζονται με τη λέξη-κλειδί `opaque`.

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

Αυτός ο τύπος `PositiveInt` προορίζεται για περιπτώσεις όπου χρειάζεται ένας ακέραιος, αλλά πρέπει να είναι μηδέν ή μεγαλύτερος. Ένας συνηθισμένος `Int` της Gleam δε θα μπορούσε να χρησιμοποιηθεί, καθώς οι ακέραιοι μπορούν να είναι και αρνητικοί.

Το άρθρωμα που ορίζει αυτόν τον τύπο μπορεί να ορίσει μια συνάρτηση που παίρνει την εσωτερική ακέραια τιμή και μια συνάρτηση που δημιουργεί τον τύπο `PositiveInt`, η οποία θα επιστρέψει ένα σφάλμα αν η τιμή δεν είναι θετική.

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

Με αυτό το API, τα άλλα αρθρώματα δεν μπορούν να κατασκευάσουν ένα `PositiveInt` με αρνητική τιμή, οπότε κάθε συνάρτηση που δέχεται ένα `PositiveInt` μπορεί να είναι σίγουρη ότι η τιμή είναι θετική.
