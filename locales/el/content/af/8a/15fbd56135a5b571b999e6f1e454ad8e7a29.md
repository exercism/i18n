# Εισαγωγή

Αυτή η άσκηση θα σου μάθει τα θεμελιώδη δομικά στοιχεία της Ruby.
Καλύπτει πολύ έδαφος, αλλά μην ανησυχείς αν σου φανεί υπερβολικό, θα εμβαθύνουμε σε όλα πολύ περισσότερο καθώς προχωράμε στη διαδρομή.

Ένα από τα βασικά πράγματα που πρέπει να καταλάβεις για τη Ruby είναι ότι είναι μια [αντικειμενοστρεφής γλώσσα][object-oriented-programming] και ότι **τα πάντα στη Ruby είναι [αντικείμενα][object]**. Αριθμοί, συμβολοσειρές, πίνακες: όλα τους είναι αντικείμενα.

## Μεταβλητές και Σταθερές

Συνήθως χρησιμοποιούμε τα αντικείμενα δίνοντάς τους ονόματα, είτε με μεταβλητές είτε με σταθερές.

Οι μεταβλητές γράφονται πάντα σε [snake case][snake-case].
Μια μεταβλητή μπορεί να αναφέρεται σε διαφορετικά αντικείμενα κατά τη διάρκεια της ζωής της.
Για παράδειγμα, η `my_first_variable` μπορεί να οριστεί και να επαναοριστεί πολλές φορές με τον τελεστή `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Οι σταθερές, ωστόσο, προορίζονται να πάρουν τιμή μία μόνο φορά.
Πρέπει να ξεκινούν με κεφαλαίο γράμμα και συνήθως γράφονται με κεφαλαία, με τις λέξεις χωρισμένες με κάτω παύλες.
Για παράδειγμα:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

## Κλάσεις

Η Ruby οργανώνεται σε κλάσεις.
Οι κλάσεις ορίζονται με τη λέξη-κλειδί `class` ακολουθούμενη από το όνομα της κλάσης.
Τα αντικείμενα δημιουργούνται συνήθως με στιγμιοποίηση κλάσεων μέσω της μεθόδου `.new`.
Για παράδειγμα:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

## Μέθοδοι

Οι μονάδες λειτουργικότητας ενσωματώνονται σε μεθόδους, παρόμοιες με τις _συναρτήσεις_ σε άλλες γλώσσες.

Μια μέθοδος μπορεί να οριστεί με ορίσματα θέσης, ορίσματα με λέξεις-κλειδιά (που ορίζονται και καλούνται με τη σύνταξη `:`), ή να μην έχει καθόλου ορίσματα.

Οι μέθοδοι είτε επιστρέφουν σιωπηρά το αποτέλεσμα της τελευταίας εντολής που αξιολογήθηκε, είτε μπορούν να επιστρέψουν ρητά ένα αντικείμενο με τη λέξη-κλειδί `return`.

```ruby
class Calculator

  # Positional arguments
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Keyword arguments
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end
```

Οι μέθοδοι καλούνται με τη σύνταξη `.`:

```ruby
calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
