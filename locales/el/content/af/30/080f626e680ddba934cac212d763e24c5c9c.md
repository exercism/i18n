# Σχετικά

Πέρα από τις κλάσεις χαρακτήρων και τους ποσοδείκτες, οι κανονικές εκφράσεις μπορούν να περιγράψουν τη *δομή* και το *πλαίσιο* του κειμένου. Αυτά τα χαρακτηριστικά βρίσκονται στο ίδιο vocabulary [`regexp`][regexp], γραμμένα με το literal `R/ /`.

## Ομαδοποίηση και εναλλαγή

Οι παρενθέσεις `( )` ομαδοποιούν ένα μέρος ενός μοτίβου, ώστε ένας ποσοδείκτης ή ένα `|` ("αυτό ή εκείνο") να εφαρμόζεται σε ολόκληρη την ομάδα. Το `?` μετά από μια ομάδα την κάνει προαιρετική:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"cat"     R/ cat|dog/ matches? .           ! => t
"$100.50" R/ \$\d+(\.\d{2})?/ matches? .   ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (group optional)
```

## Άγκυρες

```
^    ! start of the string
$    ! end of the string
\b   ! a word boundary
```

Ένα *όριο λέξης* (`\b`) είναι το σημείο όπου ένας χαρακτήρας λέξης (ένα γράμμα, ένα ψηφίο ή μια κάτω παύλα) συναντά έναν μη χαρακτήρα λέξης, συμπεριλαμβανομένων των άκρων της συμβολοσειράς. Έτσι, το `\bcat\b` ταιριάζει με το `cat` μόνο όταν αυτό στέκεται μόνο του:

```factor
USING: regexp ;

"cat nap" R/ \bcat\b/ re-contains? .   ! => t
"scatter" R/ \bcat\b/ re-contains? .   ! => f
```

## Προοπτική

Μια *προοπτική* ελέγχει τι βρίσκεται ακριβώς πριν ή μετά από ένα σημείο, χωρίς να κάνει αυτούς τους χαρακτήρες μέρος του ταιριάσματος. Έχει μηδενικό πλάτος:

```
(?=...)    ! lookahead
(?!...)    ! negative lookahead
(?<=...)   ! lookbehind
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

## Επιλογές

Ένα γράμμα επιλογής μετά το τελικό `/` αλλάζει ολόκληρο το μοτίβο. Το `i` σημαίνει ότι δεν γίνεται διάκριση πεζών-κεφαλαίων:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

## Μετασχηματισμός κάθε ταιριάσματος

Το `map-matches` εκτελεί ένα quotation σε κάθε ταίριασμα και συλλέγει τα αποτελέσματα. Το `each-match` κάνει το ίδιο μόνο για παρενέργειες. Και τα δύο περνούν στο quotation τη θέση `start` του ταιριάσματος, τη θέση `end` και ολόκληρη τη συμβολοσειρά, ώστε το `subseq` να ανακτά το κείμενο που ταίριαξε:

```
map-matches ( string regexp quot: ( start end string -- obj ) -- seq )
each-match  ( string regexp quot: ( start end string --     ) --     )
```

```factor
USING: math regexp sequences ;

"a1 b22 c333" R/ \d+/ [ subseq length ] map-matches .
! => { 1 2 3 }
```

## Τι δεν υποστηρίζει το Factor

Η μηχανή κανονικών εκφράσεων του Factor δεν έχει **εξαγωγή ομάδων σύλληψης** (μια ομάδα `( )` δομεί το μοτίβο, αλλά δεν μπορείς να διαβάσεις πίσω το κείμενο που ταίριαξε), ούτε **οπισθοαναφορές** (`\1`), ούτε **τεμπέληδες/μη αδηφάγους** ποσοδείκτες (`*?`, `+?`). Η προοπτική είναι η ιδιωματική αντικατάσταση των ομάδων σύλληψης: ταιριάζεις το κομμάτι που θέλεις, αναγνωρισμένο από το πλαίσιο γύρω του.
