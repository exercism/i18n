# Εισαγωγή

[Flower Field][history] είναι μια τρυφερή επανεπινόηση του δημοφιλούς παιχνιδιού Ναρκαλιευτής.
Σκοπός του παιχνιδιού είναι να βρεις όλα τα λουλούδια στον κήπο χρησιμοποιώντας αριθμητικές υποδείξεις που δείχνουν πόσα λουλούδια βρίσκονται ακριβώς δίπλα (οριζόντια, κάθετα, διαγώνια) σε ένα τετράγωνο.
Το "Flower Field" κυκλοφόρησε σε περιφερειακές εκδόσεις των Microsoft Windows στην Ιταλία, τη Γερμανία, τη Νότια Κορέα, την Ιαπωνία και την Ταϊβάν.
