# Εισαγωγή

Η Haxe έχει ενσωματωμένη υποστήριξη για κανονικές εκφράσεις. Μπορούν να χρησιμοποιηθούν για να επαληθεύσεις τη μορφή μιας συμβολοσειράς, να μετασχηματίσεις μια συμβολοσειρά ή να εξαγάγεις δεδομένα που ακολουθούν κάποιο πρότυπο από ένα δεδομένο κείμενο.

Για να δημιουργήσεις μια κανονική έκφραση, γράψε ανάμεσα σε `~/` και `/`:

```haxe
var r = ~/haxe/i;
```

Ένας άλλος τρόπος για να το κάνεις αυτό είναι να χρησιμοποιήσεις το στιγμιότυπο `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Εδώ το `i` είναι μια σημαία που κάνει το πρότυπο να μην διακρίνει πεζά από κεφαλαία. Υπάρχουν κι άλλες σημαίες, όπως:

- `g`: καθολική αντικατάσταση.
- `m`: αντιστοίχιση πολλών γραμμών

Ανάμεσα στο `~/` και στο `/`, γράφεις τα πρότυπα των κανονικών εκφράσεων. Για παράδειγμα, θέλεις να αναζητήσεις μια συμβολοσειρά που περιέχει γράμματα από το A έως το Z. Εδώ μπορούμε να χρησιμοποιήσουμε το πρότυπο εύρους `[A-Z]`. Υπάρχουν πολλά πρότυπα εκφράσεων, όπως:

- `.`: οποιοσδήποτε χαρακτήρας
- `*`: επανάληψη μηδέν ή περισσότερες φορές
- `+`: επανάληψη μία ή περισσότερες φορές
- `[A-Z0-9]`: εύρη χαρακτήρων
