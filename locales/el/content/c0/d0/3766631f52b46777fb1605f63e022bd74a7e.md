# Εισαγωγή

Ένα αρχείο δεν είναι παρά μια ροή με ένα όνομα στον δίσκο. Το λεξιλόγιο [`io.files`][io.files]
σου δίνει δύο τρόπους να δουλέψεις με ένα αρχείο: βολικές λέξεις για ολόκληρο το αρχείο,
που διαβάζουν ή γράφουν τα πάντα με μία μόνο κλήση, και εργαλεία ανοίγματος ροών, για όταν
θέλεις να διαβάσεις ή να γράψεις σταδιακά.

Κάθε λέξη που αγγίζει ένα αρχείο παίρνει μια **κωδικοποίηση**: το σχήμα που μετατρέπει τα
bytes σε χαρακτήρες και αντίστροφα. Για κείμενο, αυτή είναι σχεδόν πάντα η
[`utf8`][utf8] από το `io.encodings.utf8`.

## Ανάγνωση ολόκληρου αρχείου

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

Η `file-contents` επιστρέφει ολόκληρο το αρχείο ως μία συμβολοσειρά; η `file-lines`
επιστρέφει έναν πίνακα με τις γραμμές του, χωρίς τις αλλαγές γραμμής.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Εγγραφή ολόκληρου αρχείου

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Και οι δύο **αντικαθιστούν** τα περιεχόμενα του αρχείου (δημιουργώντας το αν χρειάζεται).
Η `set-file-contents` γράφει μια συμβολοσειρά αυτολεξεί; η `set-file-lines` γράφει κάθε
στοιχείο μιας ακολουθίας σε δική του γραμμή, προσθέτοντας τις αλλαγές γραμμής για
λογαριασμό σου.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Προσθήκη σε ένα αρχείο

Για να προσθέσεις σε ένα αρχείο χωρίς να σβήσεις ό,τι υπάρχει ήδη, άνοιξέ το με έναν
συνδυαστή `with-…` και γράψε στη ροή του περιβάλλοντος μέσα στο παράθεμα:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Όπως κάθε συνδυαστής `with-…`, αυτοί είναι πλαίσια καταστροφέα: η λαβή του αρχείου
κλείνει όταν ολοκληρωθεί το παράθεμα, ακόμα κι αν πετάξει ένα σφάλμα.

[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
