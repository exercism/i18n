# Εισαγωγή

Η εντολή `guard` στη Swift χρησιμοποιείται για πρόωρες εξόδους από συναρτήσεις, βρόχους ή μεθόδους όταν μια απαιτούμενη συνθήκη δεν πληρούται:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Στο παραπάνω παράδειγμα, η εντολή `guard` αξιολογεί την έκφραση Boolean που ακολουθεί.
Αν η συνθήκη είναι `true`, η εκτέλεση συνεχίζεται με τον κώδικα μετά την εντολή `guard`.
Αν η συνθήκη είναι `false`, εκτελείται ο κώδικας μέσα στο μπλοκ `else`.

Σε αντίθεση με μια εντολή `if`:

- Μια εντολή `guard` **πρέπει** να περιλαμβάνει ρήτρα `else`.
- Η ρήτρα `else` **πρέπει** να μεταφέρει τον έλεγχο ώστε να βγει από την περιβάλλουσα εμβέλεια (για παράδειγμα, χρησιμοποιώντας `return`, `continue`, `break` ή πετώντας ένα σφάλμα).

Η εντολή `guard` χρησιμοποιείται συχνά για να επαληθεύει προϋποθέσεις με καθαρό τρόπο.
Για παράδειγμα, ας δούμε τη συνάρτηση sinc ($\text{sinc}(x) = \frac{\sin(x)}{x}$, με $\text{sinc}(0) = 1$ για να αποφεύγεται η διαίρεση με το μηδέν):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
