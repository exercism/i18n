# Υποδείξεις

## Γενικά

- Οι [πλειάδες][tuple] είναι δομές δεδομένων που είναι αμετάβλητες, έχουν σταθερό μέγεθος και μπορούν να περιέχουν οποιονδήποτε τύπο δεδομένων.
- Τα σύμβολα μπορούν να χρησιμοποιηθούν για να δηλώσουν πεπερασμένες καταστάσεις: αυτή η άσκηση χρησιμοποιεί τα `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` για να δηλώσει τις μονάδες που χρησιμοποιούνται.

## 1. Πάρε το αριθμητικό μέρος από ένα ζεύγος όγκου

- Σκέψου να ανακτήσεις το στοιχείο της πλειάδας με βάση τη θέση του, ώστε να επιστρέψεις το αριθμητικό μέρος του ζεύγους όγκου.

## 2. Μετέτρεψε το ζεύγος όγκου σε χιλιοστόλιτρα

- Χρησιμοποίησε λογική ροής ελέγχου για να καθορίσεις ποια λογική θα εφαρμόσεις με βάση τη μονάδα.
- Υλοποίησε τη μέθοδο για όλες τις μονάδες προς χιλιοστόλιτρα, συμπεριλαμβανομένων των χιλιοστόλιτρων προς χιλιοστόλιτρα.

## 3. Μετέτρεψε το ζεύγος όγκου χιλιοστόλιτρων σε άλλη μονάδα

- Χρησιμοποίησε λογική ροής ελέγχου για να καθορίσεις ποια λογική θα εφαρμόσεις με βάση τη μονάδα.
- Υλοποίησε τη μέθοδο για χιλιοστόλιτρα προς όλες τις μονάδες, συμπεριλαμβανομένων των χιλιοστόλιτρων προς χιλιοστόλιτρα.

## 4. Μετέτρεψε από οποιαδήποτε μονάδα σε οποιαδήποτε μονάδα

- Χρησιμοποίησε ξανά τις μεθόδους που έχεις ήδη δημιουργήσει για να κάνεις τη μετατροπή στη μέθοδο `KitchenCalculator.convert`.
