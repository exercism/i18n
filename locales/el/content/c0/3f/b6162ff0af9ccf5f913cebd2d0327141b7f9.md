# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη δέσμευση `expected_minutes_in_oven` για να ελέγξεις πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `remaining_minutes_in_oven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που τα λαζάνια βρίσκονται στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparation_time_in_minutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά δαπάνησες για την προετοιμασία των λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά προετοιμασίας.

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsed_time_in_minutes` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα των λαζάνια, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο αυτή τη στιγμή.

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
