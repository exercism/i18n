# Εισαγωγή

Ένα πρόγραμμα `jq` που συναντά ένα πρόβλημα όσο επεξεργάζεται μια τιμή (όταν ζητάς θέση από έναν αριθμό με συμβολοσειρά, όταν αναλύεις μη έγκυρο κείμενο JSON, όταν καλείς μια συνάρτηση με λάθος τύπο ορίσματος) πετάει ένα **σφάλμα χρόνου εκτέλεσης**.
Ένα σφάλμα χρόνου εκτέλεσης που δεν πιάνεται κάνει το `jq` να τυπώσει ένα μήνυμα στο _τυπικό σφάλμα_ και να τερματίσει με κωδικό κατάστασης `5`.

## Πώς πετάμε σφάλματα: `error` και `error(message)`

- Το `error` πετάει ένα σφάλμα του οποίου η τιμή είναι η **τιμή εισόδου**.
- Το `error(message)` πετάει ένα σφάλμα του οποίου η τιμή είναι το αποτέλεσμα του `message`.

Η τιμή του σφάλματος μπορεί να είναι _οποιαδήποτε_ τιμή JSON, όχι μόνο μια συμβολοσειρά.

```jq
42 | error("invalid value: \(.)")
# => "invalid value: 42"

42 | error
(not a string): 42
```

## Πώς πιάνουμε σφάλματα: `try` και `catch`

Τα σφάλματα μπορούν να πιαστούν με `try EXP catch HANDLER`.
Η πρώτη έκφραση εκτελείται· αν πετάξει σφάλμα, η έκφραση `HANDLER` εκτελείται **με την τιμή του σφάλματος ως είσοδο**.
Η έξοδος του `try catch` είναι η έξοδος όποιας έκφρασης έτρεξε τελευταία (είτε του `EXP` είτε του `HANDLER`).

```jq
{a: 42} | try .a catch "no index a in \(.)"
# => 42

true | try .a catch "cannot index a \(type)"
# => "cannot index a boolean"

true | try error("some exception") catch .
# => "some exception"
```

Η συντομότερη μορφή `try EXP` ισοδυναμεί με `try EXP catch empty`: το σφάλμα απορρίπτεται και δεν παράγεται καμία έξοδος.

```jq
[{}, true, {"a": 1}] | [.[] | try .a]
# => [null, 1]
```

## Καταστολή σφαλμάτων: ο τελεστής `?`

Ο τελεστής `?`, όταν χρησιμοποιείται ως `EXP?`, είναι συντομογραφία του `try EXP`.
Μετατρέπει μια έκφραση που αποτυγχάνει σε μια έκφραση που απλώς δεν παράγει έξοδο.

```jq
["1", "invalid", "3", 4] | [.[] | tonumber?]
# => [1, 3, 4]
```

Συχνά τον συναντάς μαζί με τους τελεστές πρόσβασης σε θέση: `.foo?` και `.[]?`.

## Τερματισμός του προγράμματος: `halt_error` και `halt`

Το `halt_error` σταματά το πρόγραμμα, τυπώνει την είσοδό του στο _τυπικό σφάλμα_ ως ακατέργαστο κείμενο και τερματίζει με τον κωδικό κατάστασης που του δίνεται, ο οποίος από προεπιλογή είναι `5`.
Το σχετικό φίλτρο `halt` σταματά το πρόγραμμα σιωπηλά με κωδικό κατάστασης `0`.

```jq
"Error: something went wrong" | halt_error(1)
```
