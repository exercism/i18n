# Εισαγωγή

## Αναφορές

### Αντίγραφα και αναφορές

Με τις γνώσεις που έχουμε μέχρι τώρα, είναι λίγο άβολο να ενημερώνεις μια μεταβλητή με τη βοήθεια μιας συνάρτησης.
Κάθε όρισμα συνάρτησης αντιμετωπίζεται σαν αντίγραφο και δεν αλλάζει την αρχική τιμή.
Ανάλογα με το μέγεθος του τύπου σου, αυτό μπορεί να έχει σοβαρές συνέπειες στην απόδοση του κώδικα σου.

```cpp
int adjust_salary(int base, int kids) {
    return base + kids * 500;
}
int now_a_mother_of_twins{2500};
adjust_salary(now_a_mother_of_twins, 2);

// now_a_mother_of_twins is still 2500
now_a_mother_of_twins = adjust_salary(now_a_mother_of_twins, 2);
// now_a_mother_of_twins is now 3500
```

Οι `References` μπορούν να θεωρηθούν ψευδώνυμα: οι αλλαγές πάνω τους επηρεάζουν την αρχική μεταβλητή.
Οι `References` χρησιμοποιούν ένα **ampersand** (`&`) στη δήλωση τύπου.

```cpp
int balance{1000};
int& budget{balance};
int pro_computer_wheels{699};
budget -= pro_computer_wheels;
// budget is now 301;
// balance is also 301;
```
Η επανατοποθέτηση (η αλλαγή της δέσμευσης μιας `reference`) δεν είναι δυνατή.
Δε μπορείς να έχεις μια `reference` που δεν έχει αρχικοποιηθεί.
Οι `References` πρέπει να αρχικοποιούνται με μια υπάρχουσα μεταβλητή.

```cpp
int main_acc{1'000'000};
int side_acc{-20};
int& savings{main_acc};
// => main_acc and savings are 1'000'000

// try to reseat savings to use main account
savings = side_acc;
// savings and main_acc are now -20
// as this uses the **value** of side_acc
savings += 20;
// savings and main_acc are now 0, side_acc is still -20

int& future_budget;
// => compiler error, reference must be bound!
```

### `void`

Με τη δύναμη των `references` μπορεί να μη χρειάζεται να επιστρέψεις καθόλου μια τιμή από μια συνάρτηση.
Σε αυτή την περίπτωση, το `void` χρησιμοποιείται ως τύπος επιστροφής.

```cpp
void increase_power(int& level) {
    level += 500;
}
int goku{8700};
increase_power(goku);
// goku's power level?
// It's over 9000!
```
