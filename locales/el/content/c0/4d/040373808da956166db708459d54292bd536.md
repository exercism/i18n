# Εισαγωγή

Εκτός από την εντολή `if`, υπάρχει και η εντολή `switch` για να εκτελείς κώδικα υπό συνθήκες. Χρησιμοποιείται όταν μία μεταβλητή πρέπει να συγκριθεί με πολλαπλές παραλλαγές. Για κάποια μεταβλητή x, η εντολή `switch` στη Haxe έχει την εξής σύνταξη.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

Η περίπτωση `default` εκτελείται όταν καμία άλλη περίπτωση δεν ταιριάζει.
