# Συνθήκες

Στην Python, οι εντολές `if`, `elif` (_σύντμηση του 'else and if'_) και `else` χρησιμοποιούνται για να [ελέγχεις τη ροή][control flow tools] της εκτέλεσης και να παίρνεις αποφάσεις μέσα σε ένα πρόγραμμα.
Σε αντίθεση με πολλές άλλες γλώσσες προγραμματισμού, οι εκδόσεις της Python 3.9 και παλαιότερες δεν προσφέρουν μια επίσημη εντολή case-switch, αλλά χρησιμοποιούν πολλαπλές εντολές `elif` για παρόμοιο σκοπό.

Η Python 3.10 εισάγει μια παραλλαγή της εντολής case-switch, που ονομάζεται `structural pattern matching` και θα καλυφθεί ξεχωριστά σε άλλη ενότητα.

Οι εντολές υπό συνθήκη χρησιμοποιούν εκφράσεις που πρέπει να καταλήγουν σε `True` ή `False`, είτε επιστρέφοντας απευθείας έναν τύπο `bool`, είτε αξιολογούμενες ως ["truthy" ή "falsy"][truth value testing].

```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

Όταν συνδυάζεται με `if`, ένα προαιρετικό μπλοκ κώδικα `else` εκτελείται όταν η αρχική συνθήκη του `if` αξιολογείται σε `False`:

```python
x = 5
y = 10

# The comparison '>' here returns the bool 'False',
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

Το `elif` επιτρέπει πολλαπλές αξιολογήσεις/διακλαδώσεις.

```python
x = 5
y = 10
z = 20

# The 'elif' statement allows for the checking of more conditions.
if x > y:
    print("x is greater than y and z")
elif y > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

Οι [πράξεις Boolean][boolean operations] και οι [συγκρίσεις][comparisons] μπορούν να συνδυαστούν με εντολές υπό συνθήκη για πιο σύνθετους ελέγχους:

```python
>>> def classic_fizzbuzz(number):
        if number % 3 == 0 and number % 5 == 0:
            say = 'FizzBuzz!'
        elif number % 5 == 0:
            say = 'Buzz!'
        elif number % 3 == 0:
            say = 'Fizz!'
        else:
            say = str(number)
        
        return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
