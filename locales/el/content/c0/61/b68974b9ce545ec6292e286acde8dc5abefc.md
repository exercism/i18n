# Εισαγωγή

Κάθε στιγμιότυπο ενός struct ή μιας κλάσης έχει μια σιωπηρή ιδιότητα με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο.
Η πιο συνηθισμένη χρήση του `self` είναι να ξεκαθαρίζει τη διαφορά ανάμεσα σε μια ιδιότητα του στιγμιότυπου και σε μια παράμετρο που έχει το ίδιο όνομα:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Οι τύποι της Swift παρέχουν επίσης τη λέξη-κλειδί `Self` με κεφαλαίο αρχικό, η οποία αναφέρεται στον *τύπο* του στιγμιότυπου και όχι στο ίδιο το στιγμιότυπο.
