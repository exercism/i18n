# Οδηγίες

Με δεδομένο ένα κείμενο εισόδου, βγάλε ως έξοδο το ανάστροφό του.

Χοντρικά, ο ανάστροφος ενός πίνακα:

```text
ABC
DEF
```

δίνεται από:

```text
AD
BE
CF
```

Οι γραμμές γίνονται στήλες και οι στήλες γίνονται γραμμές. Δες <https://en.wikipedia.org/wiki/Transpose>.

Αν η είσοδος έχει γραμμές διαφορετικού μήκους, λύνεται ως εξής:

- Συμπλήρωσε με κενά προς τα αριστερά.
- Μη συμπληρώνεις προς τα δεξιά.

Επομένως, παίρνοντας τον ανάστροφο αυτού του πίνακα:

```text
ABC
DE
```

προκύπτει:

```text
AD
BE
C
```

Και ο ανάστροφος του:

```text
AB
DEF
```

προκύπτει:

```text
AD
BE
 F
```

Γενικά, όλοι οι χαρακτήρες της εισόδου θα πρέπει να υπάρχουν και στην ανάστροφη έξοδο. Αυτό σημαίνει ότι αν μια στήλη στο κείμενο εισόδου περιέχει μόνο κενά στην κατώτατη γραμμή ή γραμμές της, η αντίστοιχη γραμμή της εξόδου θα πρέπει να περιέχει τα κενά στη δεξιότερη στήλη ή στήλες της.
