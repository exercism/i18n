# Σχετικά

Η Ceylon είναι μια γλώσσα προγραμματισμού γενικού σκοπού με σύνταξη παρόμοια με τη Java και τη C#. Είναι προστακτική, στατικά τυποποιημένη, δομημένη σε μπλοκ, αντικειμενοστρεφής και υψηλότερης τάξης. Με _στατικά τυποποιημένη_ εννοούμε ότι ο μεταγλωττιστής εκτελεί εκτεταμένο έλεγχο τύπων, με τη βοήθεια σημειώσεων τύπων που εμφανίζονται στον κώδικα. Με _αντικειμενοστρεφή_ εννοούμε ότι η γλώσσα υποστηρίζει τύπους ορισμένους από τον χρήστη και διαθέτει ονομαστικό σύστημα τύπων, όπου ένας τύπος είναι ένα σύνολο από χαρακτηριστικά και λειτουργίες με ονόματα, και ότι υποστηρίζει κληρονομικότητα και πολυμορφισμό υποτύπων. Με _υψηλότερης τάξης_ εννοούμε ότι κάθε στοιχείο του προγράμματος στο οποίο μπορεί να γίνει αναφορά (κάθε χαρακτηριστικό, κάθε λειτουργία και κάθε τύπος) είναι επίσης μια τιμή. Με _δομημένη σε μπλοκ_ εννοούμε ότι η γλώσσα διαθέτει λεκτική εμβέλεια και μια εξαιρετικά κανονική αναδρομική σύνταξη για δηλώσεις και εντολές.

Η Ceylon βελτιώνει τη γλώσσα και το σύστημα τύπων της Java για να μειώσει τη φλυαρία και να αυξήσει την ασφάλεια τύπων σε σύγκριση με τη Java και τη C#. Η Ceylon ενθαρρύνει ένα πιο συναρτησιακό, κάπως λιγότερο προστακτικό στυλ προγραμματισμού, με αποτέλεσμα κώδικα που είναι πιο εύκολο να τον κατανοήσεις και πιο εύκολο να τον αναδιαμορφώσεις.
