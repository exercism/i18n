# Οδηγίες

Η εργασία συνεχίζεται στο έργο του τηλεχειριζόμενου αυτοκινήτου. Το εύρος ζώνης στο σύστημα τηλεμετρίας είναι περιορισμένο και σου έχει ζητηθεί να υλοποιήσεις ένα πρωτόκολλο μηνυμάτων για τη μετάδοση δεδομένων τηλεμετρίας.

Τα δεδομένα μεταδίδονται μέσα σε έναν buffer (πίνακας byte). Όταν αποστέλλονται ακέραιοι, το μέγεθος του buffer μειώνεται με την εφαρμογή του πρωτοκόλλου που περιγράφεται παρακάτω.

Κάθε τιμή πρέπει να αναπαρίσταται στον μικρότερο δυνατό ακέραιο τύπο (οι τύποι `byte` και `sbyte` δεν περιλαμβάνονται, καθώς η εξοικονόμηση θα ήταν αμελητέα):

| Από                        | Έως                       | Τύπος    |
| -------------------------- | ------------------------- | -------- |
| 4_294_967_296              | 9_223_372_036_854_775_807 | `long`   |
| 2_147_483_648              | 4_294_967_295             | `uint`   |
| 65_536                     | 2_147_483_647             | `int`    |
| 0                          | 65_535                    | `ushort` |
| -32_768                    | -1                        | `short`  |
| -2_147_483_648             | -32_769                   | `int`    |
| -9_223_372_036_854_775_808 | -2_147_483_649            | `long`   |

Η τιμή πρέπει να μετατρέπεται στον κατάλληλο αριθμό byte για τον τύπο που της έχει ανατεθεί. Ο πλήρης buffer περιλαμβάνει ένα byte που υποδεικνύει τον αριθμό των πρόσθετων byte στον buffer (_byte προθέματος_), ακολουθούμενο από τα byte που περιέχουν τον ακέραιο (_byte ωφέλιμου φορτίου_).

Κάποιοι από τους τύπους χρησιμοποιούν τον ίδιο αριθμό byte (π.χ. οι τύποι `uint` και `int`). Κανονικά, θα είχαν το ίδιο _byte προθέματος_, αλλά αυτό θα έκανε την αποκωδικοποίηση προβληματική. Για να αντιμετωπιστεί αυτό, το πρωτόκολλο εισάγει ένα μικρό τρικ: για τους προσημασμένους τύπους, η τιμή του _byte προθέματος_ είναι `256` μείον τον αριθμό των πρόσθετων byte στον buffer.

Μόνο το byte προθέματος και ο αριθμός των επόμενων byte που υποδεικνύονται από το byte προθέματος θα αποσταλούν στην επικοινωνία. Εσωτερικά χρησιμοποιείται ένας buffer 9 byte (με μηδενικά στο τέλος, όταν χρειάζεται) τόσο από τις ρουτίνες αποστολής όσο και από τις ρουτίνες λήψης.

## 1. Κωδικοποίησε μια ακέραια τιμή έτοιμη για αποστολή

Υλοποίησε τη στατική μέθοδο `TelemetryBuffer.ToBuffer()` για να κωδικοποιήσεις έναν buffer παίρνοντας την παράμετρο που περνιέται στη μέθοδο.

```csharp
// Type: ushort, bytes: 2, signed: no, prefix byte: 2
TelemetryBuffer.ToBuffer(5)
// => {0x2, 0x5, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0, 0x0 };

// Type: int, bytes: 4, signed: yes, prefix byte: 256 - 4
TelemetryBuffer.ToBuffer(Int32.MaxValue)
// => {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 };
```

## 2. Αποκωδικοποίησε έναν buffer που έλαβες

Υλοποίησε τη στατική μέθοδο `TelemetryBuffer.FromBuffer()` για να αποκωδικοποιήσεις τον buffer που έλαβες και να επιστρέψεις την τιμή με τη μορφή `long`.

```csharp
TelemetryBuffer.FromBuffer(new byte[] {0xfc, 0xff, 0xff, 0xff, 0x7f, 0x0, 0x0, 0x0, 0x0 })
// => 2147483647
```

Αν το byte προθέματος έχει μη αναμενόμενη τιμή, τότε θα πρέπει να επιστραφεί το `0`.
