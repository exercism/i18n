# Εισαγωγή

Η Cairo παρέχει λεξικά ως μέρος των βασικών βιβλιοθηκών της, που αναπαρίστανται από τον τύπο `Felt252Dict<T>`.

Ο τύπος του κλειδιού σε ένα λεξικό της Cairo περιορίζεται στον `felt252`, κάτι που διαφέρει από άλλες γλώσσες, όπου μπορείς να ορίσεις τον τύπο του κλειδιού.

Για να δημιουργήσεις ένα λεξικό, μπορείς να χρησιμοποιήσεις τη μέθοδο `default` του trait `Default`, όπως:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

Οι βασικές πράξεις που χρησιμοποιούνται πιο συχνά είναι:

1. `insert(felt252, T) -> ()` για να γράψεις τιμές σε ένα στιγμιότυπο λεξικού και
2. `get(felt252) -> T` για να διαβάσεις τιμές από αυτό.

Και να πώς θα χρησιμοποιούσες αυτές τις πράξεις:

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

Αν προσπαθήσεις να ανακτήσεις την τιμή για ένα κλειδί που δεν υπάρχει στο λεξικό, θα επιστραφεί η μηδενική τιμή του τύπου τιμής.

Αυτό μπορεί να σε μπερδέψει, ειδικά αν η προεπιλεγμένη τιμή του τύπου τιμής σου (για παράδειγμα, το 0 για έναν ακέραιο) είναι μια έγκυρη τιμή.

Αυτό σημαίνει επίσης ότι δεν υπάρχει τρόπος να διαγράψεις δεδομένα από ένα λεξικό.

Κάτι που πρέπει να λάβεις υπόψη όταν ενσωματώνεις αυτή τη δομή στον κώδικά σου.
