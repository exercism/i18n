# Δοκιμές

## Clojure CLI

Οι ασκήσεις Clojure στο Exercism συνοδεύονται από ένα αρχείο `deps.edn` με ένα alias `:test` για να καλέσεις τον [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Αυτό θα σαρώσει τον κατάλογο `test` του project σου για δοκιμές που έχουν οριστεί με το `clojure.test` και θα τις εκτελέσει.

## Leiningen

Για να τρέξεις τις δοκιμές μιας άσκησης με το Leiningen, απλώς κάλεσε:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
