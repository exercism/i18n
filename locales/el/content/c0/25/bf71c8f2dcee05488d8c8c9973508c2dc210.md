# Εισαγωγή

Όπως είδαμε στην έννοια [`Nothingness`][concept-nothingness], η R έχει διάφορους τρόπους να αναπαριστά δεδομένα που απουσιάζουν (`NULL`), είναι άγνωστα (`NA`) ή μαθηματικά μη έγκυρα (`NaN`, `Inf`).
Γενικά, η R θα προσπαθήσει να τα χρησιμοποιήσει για να επισημάνει προβλήματα επί τόπου και να συνεχίσει χωρίς να πετάξει εξαίρεση.

## `stop()`

Μερικά προβλήματα είναι πολύ θεμελιώδη για να αφήσουν το πρόγραμμα να συνεχίσει.
Σε αυτή την περίπτωση, χρησιμοποίησε το `stop(msg)` για να τερματίσεις αμέσως το πρόγραμμα με ένα `Error` και να εκτυπώσεις το `msg`.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

Παρόμοια με το `assert` σε άλλες γλώσσες, αυτή είναι ένας βολικός περιτυλιγμός για τη `stop()`.
Οι παράμετροι είναι ένας αυθαίρετος αριθμός συνθηκών Boolean (λογικών τιμών) χωρισμένων με κόμμα, και το πρόγραμμα θα συνεχίσει μόνο αν είναι όλες `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

Η R έχει πολλούς τρόπους να χειρίζεται τα σφάλματα.
Βασίζονται στη Common Lisp και διαφέρουν σημαντικά από πολλές δημοφιλείς γλώσσες.

Ο απλούστερος είναι να περικλείσεις τον δυνητικά προβληματικό κώδικα σε `try()`.

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
#> Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## `warning()` και `message()`

Αυτές αποτελούν αποκρίσεις σε μη μοιραίες συνθήκες, για παράδειγμα:

- Για να προειδοποιήσεις για ένα πρόβλημα από το οποίο το πρόγραμμα θα μπορούσε τουλάχιστον εν μέρει να ανακάμψει.
- Για να ενημερώσεις τον χρήστη για την πρόοδο ενός προγράμματος που εκτελείται για πολλή ώρα.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

Η συνάρτηση `suppressWarnings()` μπορεί περιστασιακά να φανεί χρήσιμη μέσα στο Exercism, για να μην μπερδεύεις τον test runner με ανεπιθύμητη έξοδο.
