# Προσθήκη οδηγιών

## Παραλληλισμός

Ο test runner έχει πρόσβαση σε δύο πυρήνες από τις 28-07-2025.
Μια εξαντλητική προσέγγιση μπορεί να μην επωφεληθεί από τα [hyper](https://docs.raku.org/routine/hyper) ή [race](https://docs.raku.org/routine/race) που προσφέρει η raku.
Μπορείς να το ελέγξεις με:

~~~~raku
note Kernel.cpu-cores
# 2
~~~~
