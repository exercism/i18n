# Σχετικά

Η Έννοια [Ζεύγη και Λεξικά][pairs-dicts] συζήτησε τα βασικά του τύπου λεξικού της Julia.

Επειδή τα `Dict` είναι ένας σημαντικός και συχνά χρησιμοποιούμενος τύπος συλλογής, υπάρχουν επίσης πολλές συναρτήσεις για τον χειρισμό τους.

## Ανάκτηση καταχωρίσεων

Ο πιο απλός τρόπος για να ανακτήσεις μια καταχώριση είναι με το κλειδί της (όπως σε πολλές γλώσσες).
Ωστόσο, αν ζητήσεις ένα κλειδί που δεν υπάρχει, προκαλείται `KeyError`.

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

Θα μπορούσαμε να ελέγξουμε αν υπάρχει το κλειδί πριν προσπαθήσουμε να την ανακτήσουμε (με κάτι σαν `haskey(d, 4)` ή `4 ∈ keys(d)`), αλλά μπορεί να είναι χρήσιμο να πάρεις απλώς μια προεπιλεγμένη τιμή για κλειδιά που λείπουν.

Γι' αυτό έχουμε τη συνάρτηση [`get()`][get] και την παραλλαγή της που μεταβάλλει το `Dict`, τη [`get!()`][get-bang].
Διαφέρουν ως προς το αν το κλειδί που "λείπει" προστίθεται στο `Dict`.

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

Είδαμε στην προηγούμενη Έννοια ότι η `delete!()` αφαιρεί μια καταχώριση με βάση το κλειδί.
Αυτό μπορεί να συνδυαστεί με την ανάκτηση της τιμής, χρησιμοποιώντας τη συνάρτηση `pop!()`.

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## Επανάληψη

Η επανάληψη πάνω σε ένα `Dict` δίνει από προεπιλογή ζεύγη `key => value`.
Στα συστατικά τους έχεις πρόσβαση με τη συνήθη ονοματολογία `.first` και `.second`.

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

Συχνά θέλουμε να χρησιμοποιήσουμε μόνο τα κλειδιά ή μόνο τις τιμές, κάτι που είναι εύκολο.

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## Συγχώνευση

Ο συνδυασμός δύο `Dict` μπορεί να είναι χρήσιμος, αλλά πρέπει να είμαστε σαφείς ως προς το τι σκοπεύουμε να κάνουμε με κλειδιά που υπάρχουν σε περισσότερες από μία εισόδους.

Οι συναρτήσεις [`merge()`][merge] και [`merge!()`][merge-bang] συνδυάζουν οποιονδήποτε αριθμό από `Dict` που τους δίνεις, από τα αριστερά προς τα δεξιά.

Οι τιμές των κλειδιών που υπάρχουν ήδη απλώς αντικαθίστανται, οπότε το δεξιότερο `Dict` "κερδίζει".

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

Οι συναρτήσεις [`mergewith()`][mergewith] και [`mergewith!()`][mergewith-bang] μάς επιτρέπουν να δώσουμε μια συνάρτηση ως πρώτο όρισμα, για να ορίσουμε πώς θα συγχωνεύονται τα κλειδιά που επαναλαμβάνονται.
Η πρόσθεση είναι ένα απλό παράδειγμα.

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

Η συνένωση δύο διανυσμάτων είναι μια άλλη δημοφιλής πράξη κατά τη συγχώνευση.
Γι' αυτό, η Julia χρησιμοποιεί τη συνάρτηση [`vcat()`][vcat], για λόγους που εξηγούνται στην Έννοια [`Multi Dimensional Arrays`][multidim].

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

Για πολλαπλά [`Set`][sets], η αντίστοιχη συνάρτηση συγχώνευσης είναι η [`union`][union].

Σημείωσε ότι οι συναρτήσεις `mergewith` αποτελούν ένα καλό παράδειγμα [Συναρτήσεων Ανώτερης Τάξης][hof] στην πράξη.
