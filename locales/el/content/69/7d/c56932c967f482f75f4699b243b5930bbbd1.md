# Έλεγχος Ροής

Οι εκφράσεις `if` και οι βρόχοι ελέγχουν τη ροή της εκτέλεσης στη Cairo με:
`

- **Οι εκφράσεις `if`** εκτελούν κώδικα υπό συνθήκη, ανάλογα με το αν μια συνθήκη αξιολογείται σε `true`.
- **Οι βρόχοι** (όπως οι `loop`, `while` και `for`) εκτελούν κώδικα επανειλημμένα όσο μια συγκεκριμένη συνθήκη παραμένει αληθής ή μέχρι να εκπληρωθεί μια συνθήκη διακοπής.

Αυτές οι δομές είναι θεμελιώδεις για την υλοποίηση λογικής και επανάληψης στη Cairo.

## Οι εκφράσεις `if`

Οι εκφράσεις `if` στη Cairo σου επιτρέπουν να ελέγχεις τη ροή της εκτέλεσης με βάση συνθήκες.
Ακολουθούν μια δομή όπου ο κώδικας εκτελείται ανάλογα με το αν μια συνθήκη Boolean αξιολογείται σε `true` ή `false`.

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

Αυτό το παράδειγμα δείχνει ένα απλό μπλοκ `if` στη Cairo.
Το μήνυμα `"It's hot outside!"` εκτυπώνεται μόνο αν η συνθήκη `temperature > 25` αξιολογείται σε `true`.
Αν η συνθήκη είναι `false`, δεν εκτελείται κώδικας και το πρόγραμμα συνεχίζει.

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

Η εκτέλεση αυτού του κώδικα θα εκτυπώσει `"The number is less than 10."` στην κονσόλα.

### Χειρισμός πολλαπλών συνθηκών με `else if`

Μπορείς να χρησιμοποιήσεις πολλαπλές συνθήκες συνδυάζοντας το `if` και το `else` σε μια έκφραση `else if`.

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

Η εκτέλεση αυτού του κώδικα θα εκτυπώσει `"Grade: B"` στην κονσόλα.

### Χρήση του `if` σε μια εντολή `let`

Η έκφραση `if` στη Cairo μπορεί να χρησιμοποιηθεί στη δεξιά πλευρά μιας εντολής `let` για να αναθέσεις το αποτέλεσμα σε μια μεταβλητή.

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## Βρόχοι

Οι βρόχοι είναι μια θεμελιώδης δομή που επιτρέπει την επανάληψη μπλοκ κώδικα, καθιστώντας δυνατή την αποδοτική και ελεγχόμενη εκτέλεση εργασιών.
Οι βρόχοι μπορούν να διατρέχουν μια ακολουθία ή να εκτελούν κώδικα επανειλημμένα με βάση μια συνθήκη.
Η Cairo προσφέρει τρεις βασικές μορφές βρόχων:

- **loop**: Ένας βασικός βρόχος που εκτελείται επ' αόριστον, εκτός αν τον σταματήσεις ρητά με μια εντολή `break`.
- **while**: Συνεχίζει να εκτελείται όσο μια συγκεκριμένη συνθήκη παραμένει `true`.
  Σταματά όταν η συνθήκη γίνει `false`.
- **for**: Διατρέχει τα στοιχεία μιας συλλογής, όπως πίνακες, εκτελώντας κώδικα για κάθε στοιχείο.

### Επανάληψη κώδικα με `loop`

Η λέξη-κλειδί `loop` λέει στη Cairo να εκτελεί ένα μπλοκ κώδικα ξανά και ξανά για πάντα, ή μέχρι να της πεις ρητά να σταματήσει.

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Η εκτέλεση αυτού του κώδικα θα εκτυπώσει `"again!"` επ' αόριστον στην κονσόλα, μέχρι είτε να εξαντληθεί το gas του προγράμματος είτε να το σταματήσουμε χειροκίνητα.

> Σημείωση: Η Cairo μάς εμποδίζει να εκτελέσουμε ένα πρόγραμμα με άπειρους βρόχους, καθώς περιλαμβάνει έναν μετρητή gas.
> Ο μετρητής gas είναι ένας μηχανισμός που περιορίζει τον υπολογισμό που μπορεί να γίνει σε ένα πρόγραμμα.
> Το gas είναι μια μονάδα μέτρησης που εκφράζει το υπολογιστικό κόστος μιας εντολής.
> Όταν εξαντληθεί ο μετρητής gas, το πρόγραμμα θα σταματήσει.

Για να βγεις από έναν βρόχο, τοποθέτησε τη λέξη-κλειδί `break` μέσα στον βρόχο, ώστε να πεις στο πρόγραμμα πότε να σταματήσει την εκτέλεση.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Η λέξη-κλειδί `continue` λέει στο πρόγραμμα να περάσει στην επόμενη επανάληψη του βρόχου και να παραλείψει τον υπόλοιπο κώδικα αυτής της επανάληψης.

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

Η εκτέλεση αυτού του προγράμματος δεν θα εκτυπώσει την τιμή του `i` όταν αυτό είναι ίσο με `5`.

#### Επιστροφή τιμών από τον `loop`

Μπορείς να επιστρέψεις μια τιμή από έναν `loop` χρησιμοποιώντας τη λέξη-κλειδί `break` ακολουθούμενη από την τιμή που θέλεις να επιστρέψεις.
Αυτό σου επιτρέπει να βγεις από τον `loop` και να περάσεις ένα αποτέλεσμα στον υπόλοιπο κώδικά σου.

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### Υπό συνθήκη βρόχοι με `while`

Ο `while` εκτελεί κώδικα όσο μια συνθήκη είναι `true` και βγαίνει όταν η συνθήκη γίνει `false`.

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### Διάσχιση μιας συλλογής με `for`

Ο `for` διατρέχει κάθε στοιχείο μιας συλλογής, εκτελώντας κώδικα για κάθε στοιχείο.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
