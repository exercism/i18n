# Εισαγωγή

## Πλειάδες

Στην Elixir, η πλειάδα είναι μια δομή δεδομένων που οργανώνει δεδομένα, κρατώντας έναν σταθερό αριθμό στοιχείων οποιουδήποτε τύπου, αλλά χωρίς ρητά ονόματα για κάθε στοιχείο. Οι πλειάδες χρησιμοποιούνται συχνά στην Elixir για λειτουργίες με εντατική ανάγνωση μνήμης, καθώς η ανάγνωση ενός στοιχείου είναι λειτουργία σταθερού χρόνου. Συνήθως δεν χρησιμοποιούνται όταν στοιχεία μπορεί να χρειαστεί να προστεθούν ή να αφαιρεθούν δυναμικά, γιατί αντί να τροποποιηθεί η υπάρχουσα πλειάδα, δημιουργείται μια νέα πλειάδα, η οποία απαιτεί να δεσμευτεί μνήμη εκ των προτέρων.

Στην πράξη, οι πλειάδες δημιουργούνται στην Elixir χρησιμοποιώντας άγκιστρα. Τα στοιχεία μιας πλειάδας μπορούν να προσπελαστούν μεμονωμένα με τη συνάρτηση `elem/2`, όπου οι θέσεις ξεκινούν από το 0:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

### Οι πλειάδες ως ομαδοποιημένη πληροφορία

Στην πράξη, οι πλειάδες χρησιμοποιούνται συχνά για να αναπαραστήσουν ομαδοποιημένη πληροφορία.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```

## Αντιστοίχιση προτύπων

Η χρήση της αντιστοίχισης προτύπων κυριαρχεί στον ιδιωματικό κώδικα Elixir, ο οποίος βασίζεται σε βεβαιώσεις. Ίσως θυμάσαι ότι το `=/2` περιγράφεται ως τελεστής αντιστοίχισης και όχι ως τελεστής ανάθεσης. Όταν χρησιμοποιείς τον τελεστή αντιστοίχισης, αν το πρότυπο στα αριστερά ταιριάζει με τα δεξιά, τυχόν μεταβλητές στα αριστερά δεσμεύονται και επιστρέφεται η τιμή της δεξιάς πλευράς. Αν δεν υπάρξει αντιστοίχιση, πετάγεται ένα `MatchError`.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Θυμήσου: οι αντιστοιχίσεις γίνονται από τη δεξιά πλευρά προς την αριστερή.

Στο τελευταίο παράδειγμα, αν δεν χρειάζεσαι κάποια μεταβλητή σε μια αντιστοίχιση προτύπου, μπορείς να την αγνοήσεις αναφέροντας το `_`. Κάθε μεταβλητή που ξεκινά με `_` δεν παρακολουθείται από το runtime.

### Αντιστοίχιση προτύπων σε επώνυμες συναρτήσεις

Η αντιστοίχιση προτύπων είναι επίσης ένα χρήσιμο εργαλείο όταν δημιουργείς πολλαπλές ρήτρες συνάρτησης. Η αντιστοίχιση προτύπων μπορεί να χρησιμοποιηθεί στα ορίσματα των συναρτήσεων, κάτι που καθορίζει ποια ρήτρα συνάρτησης θα κληθεί, ξεκινώντας από την αρχή του αρχείου και προχωρώντας προς τα κάτω μέχρι την πρώτη αντιστοίχιση. Οι μεταβλητές μπορούν να δεσμευτούν στην κεφαλή της συνάρτησης και να χρησιμοποιηθούν στο σώμα της.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
