# Οδηγίες

Σε αυτή την άσκηση, θα επεξεργάζεσαι γραμμές από μια αναφορά καταγραφών.
Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες και η καθεμία παίρνει μια γραμμή καταγραφής και σου ζητά να κάνεις κάτι με αυτήν.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `log_line::message` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `log_line::log_level` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο πρέπει να επιστρέφεται με κεφαλαία γράμματα:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `log_line::reformat` που αναδιαμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής μέσα σε παρενθέσεις:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
