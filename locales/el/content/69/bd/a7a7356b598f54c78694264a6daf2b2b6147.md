# Σχετικά

Τα [χαρακτηριστικά του module][module-attr] μπορείς να τα χρησιμοποιήσεις σαν ["σταθερές"][attr-as-const], οι οποίες υπολογίζονται κατά τη μεταγλώττιση.

```elixir
defmodule Example do
  @number 2

  def number(), do: @number
end
```

Ωστόσο, δεν λειτουργούν ακριβώς σαν σταθερές, επειδή μπορείς να τα αντικαταστήσεις ορίζοντάς τα ξανά μέσα στο module:

```elixir
defmodule Example do
  @standard_message "Hello, World!"
  @standard_message "Overwritten!"

  def message(), do: @standard_message
end
```

[module-attr]: https://hexdocs.pm/elixir/module-attributes.html
[attr-as-const]: https://hexdocs.pm/elixir/module-attributes.html#as-constants
