# Προσθήκη στις οδηγίες

## Υλοποίηση

Εκτός από τη συνάρτηση _numbers_, που καθαρίζει τους αριθμούς τηλεφώνου, στο track Emacs Lisp χρειάζεται να γράψεις άλλες δύο συναρτήσεις, τις _area-code_ και _pprint_.

Κάθε μία από τις επιπλέον συναρτήσεις παίρνει τον αριθμό τηλεφώνου ως μοναδική της παράμετρο.

Η πρώτη συνάρτηση, η _area-code_, εξάγει τον κωδικό περιοχής από την είσοδο, ενώ η δεύτερη, η _pprint_, μετατρέπει την είσοδο σε συμβολοσειρά με τη μορφή
```
(NXX) NXX-XXXX
```
όπου τα `N` και `X` είναι όπως περιγράφονται παραπάνω.
