# Σχετικά με τους `for` βρόχους

Ο [`for` βρόχος](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) παρέχει έναν μηχανισμό για να εκτελείς μια ομάδα εντολών επαναληπτικά μέχρι να ικανοποιηθεί κάποια συνθήκη.
Ο βρόχος αποτελείται από τέσσερα μέρη:

```java
for (initialization; test; update) {
    body;
}
```

Η `initialization` ορίζει μια αρχική κατάσταση για τον βρόχο και εκτελείται ακριβώς μία φορά στην αρχή του βρόχου.
Συνήθως δηλώνει και εκχωρεί μια μεταβλητή που χρησιμοποιείται στην έκφραση ελέγχου και στην εντολή ενημέρωσης.
Για παράδειγμα:

```java
int i = 1
```

Η έκφραση `test` ελέγχει αν ο βρόχος πρέπει να τερματιστεί.
Αν αξιολογηθεί ως αληθής, θα εκτελεστούν το σώμα και στη συνέχεια η έκφραση ενημέρωσης.
Αν αξιολογηθεί ως ψευδής, δεν θα εκτελεστεί ούτε το σώμα ούτε η εντολή ενημέρωσης και η εκτέλεση συνεχίζεται μετά το κλείσιμο του άγκιστρου του βρόχου.
Συνήθως ελέγχει τη μεταβλητή που εκχωρείται στο μπλοκ αρχικοποίησης.
Για παράδειγμα:

```java
i <= 10
```

Αφού εκτελεστεί το σώμα του βρόχου, εκτελείται η έκφραση `update`.
Συνήθως αυξάνει ή μειώνει τη μεταβλητή του βρόχου κατά κάποια τιμή.
Για παράδειγμα:

```java
i++
```

Ένας `for` βρόχος που εκτυπώνει τα πρώτα τέσσερα τετράγωνα θα έμοιαζε κάπως έτσι:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

Αν θέλεις να διατρέξεις κάθε στοιχείο σε μια συλλογή, προτιμάται ένας `for-each` βρόχος, αλλά μπορεί να γίνει και με έναν `for` βρόχο ως εξής:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Ένας `for` βρόχος έχει όντως κάποια πλεονεκτήματα σε σχέση με έναν `for-each` βρόχο:

- Μπορείς να ξεκινήσεις ή να σταματήσεις στη θέση που θέλεις.
- Μπορείς να χρησιμοποιήσεις όποια συνθήκη τερματισμού boolean (λογική τιμή) θέλεις.
- Μπορείς να παραλείψεις στοιχεία προσαρμόζοντας την αύξηση της μεταβλητής του βρόχου.
- Μπορείς να επεξεργαστείς συλλογές από το τέλος προς την αρχή μετρώντας αντίστροφα.
- Μπορείς να χρησιμοποιήσεις `for` βρόχους σε σενάρια που δεν περιλαμβάνουν συλλογές.
