# Σχετικά

Οι μεμονωμένοι χαρακτήρες σε μια `String` μπορούν να προσπελαστούν με τη σύνταξη με θέσεις που χρησιμοποιείται και στους πίνακες.
Ωστόσο, οι [θέσεις][string-indices] που χρησιμοποιούνται για τις συμβολοσειρές _δεν_ είναι ακέραιοι αριθμοί και δεν μπορείς να δουλέψεις απευθείας μαζί τους.
Αντ' αυτού, πρέπει να υπολογιστούν με βάση κάποια άλλη γνωστή θέση, όπως το `startIndex`, που δείχνει τη θέση του πρώτου χαρακτήρα σε μια μη κενή συμβολοσειρά, χρησιμοποιώντας τις μεθόδους που είναι διαθέσιμες στις βιβλιοθήκες [`String`][string-docs] και [`NSString`][nsstring-docs] (όταν γίνει εισαγωγή του module `Foundation`, οι συμβολοσειρές στη Swift έχουν πρόσβαση σε όλες τις ιδιότητες και τις μεθόδους του NSString).

Για παράδειγμα, δίνεται η παρακάτω συμβολοσειρά:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Δεν μπορείς να γράψεις `csv[21]` για να πάρεις το "g" στο "orange". Αντ' αυτού, πρέπει να υπολογίσεις μια τιμή τύπου `String.Index` και να δώσεις αυτή τη θέση.
Σημείωσε ότι αυτές οι θέσεις δεν προορίζονται να είναι κατανοητές από τον άνθρωπο από μόνες τους.
Είναι αυτό που ονομάζεται _αδιαφανείς θέσεις_, καθώς ο άνθρωπος δεν χρειάζεται να ξέρει τι υπάρχει μέσα τους.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Σημείωσε, ωστόσο, ότι αν το offset δεν είναι έγκυρη θέση, δηλαδή αν θα επέστρεφε τη θέση πριν από το `startIndex` ή μετά το `endIndex`, η λειτουργία θα πετάξει ένα σφάλμα, προκαλώντας την κατάρρευση του προγράμματος.
Για να αποφύγεις αυτό το πρόβλημα, μπορείς να ορίσεις μια θέση περιορισμού.
Αυτή επιστρέφει μια προαιρετική θέση και θα επιστρέψει nil για θέσεις που κατά τα άλλα δεν είναι έγκυρες.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Επιπλέον, οι θέσεις δεν μπορούν να μοιραστούν μεταξύ συμβολοσειρών.
Για παράδειγμα, αν χρησιμοποιήσεις το `index` του "g" στο "orange" που υπολόγισες παραπάνω για να δείξεις μέσα στη συμβολοσειρά `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, δηλαδή το `fam[index]`, το πρόγραμμά σου θα καταρρεύσει.

Υπάρχουν πολλοί λόγοι για όλα αυτά, αλλά όλοι βασικά συνοψίζονται στο ότι "το Unicode είναι μπερδεμένο".

Γενικά, αν χρειάζεσαι τυχαία πρόσβαση σε μεμονωμένους χαρακτήρες, μάλλον θέλεις να χρησιμοποιήσεις κάποια άλλη δομή δεδομένων, όπως το `Array<Character>`.

## Μερικές χρήσιμες μέθοδοι

Η Swift διαθέτει τις μεθόδους `first` και `last` για να πάρεις τον πρώτο και τον τελευταίο χαρακτήρα μιας συμβολοσειράς.
Αυτές οι μέθοδοι επιστρέφουν έναν προαιρετικό χαρακτήρα, οπότε αν η συμβολοσειρά είναι κενή, θα επιστρέψουν nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Μπορείς επίσης να χρησιμοποιήσεις τις μεθόδους `prefix` και `suffix` για να πάρεις μια υποσυμβολοσειρά.
Αυτές οι μέθοδοι παίρνουν έναν ακέραιο ως όρισμα και επιστρέφουν μια υποσυμβολοσειρά που περιέχει τους πρώτους ή τους τελευταίους n χαρακτήρες της συμβολοσειράς.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Σε βάθος: θέσεις στο Unicode

~~~~exercism/advanced

Το [Unicode][unicode] είναι ένα πρότυπο για την κωδικοποίηση κειμένου και περιλαμβάνει έναν μεγάλο αριθμό χαρακτήρων από πολλές διαφορετικές γλώσσες και γραφές.
Είναι υπερσύνολο του ASCII, που σημαίνει ότι όλοι οι χαρακτήρες ASCII είναι και χαρακτήρες Unicode.
Το Unicode είναι κωδικοποίηση μεταβλητού μήκους, που σημαίνει ότι κάποιοι χαρακτήρες καταλαμβάνουν περισσότερα byte από άλλους.
Και το γιατί αυτό έχει σημασία θα εξηγηθεί στην επόμενη ενότητα.

Έτσι, για να δούμε το πρόβλημα στην πράξη, πρέπει να πάμε σε άλλες γλώσσες (εκτός από τα αγγλικά). Ας πάρουμε τον χαρακτήρα "ü" από τα γερμανικά (πρόσεξε ότι εδώ χρησιμοποιούμε την παραλλαγή των 2 byte, υπάρχει και εκδοχή του 1 byte).
Μπορεί με μια πρώτη ματιά να φαίνεται σαν ένας μόνο χαρακτήρας, αλλά στην πραγματικότητα είναι δύο χαρακτήρες: "u" και "¨", οπότε αν τύπωνες το μήκος της συμβολοσειράς "ü" θα ήταν 2 σε γλώσσες όπως η Python.
Ωστόσο, ως χρήστης ή προγραμματιστής θα λέγαμε ότι είναι ένας μόνο χαρακτήρας και η Swift συμφωνεί μαζί μας.
Αλλά γιατί το κάνει αυτό η Swift και η Python όχι;
Η απάντηση είναι ότι η Swift χρησιμοποιεί διαφορετική αναπαράσταση συμβολοσειρών από την Python.
Στην Python, οι συμβολοσειρές αναπαρίστανται ως ακολουθία byte, που σημαίνει ότι το μήκος μιας συμβολοσειράς είναι ο αριθμός των byte που καταλαμβάνει στη μνήμη.
Στη Swift, οι συμβολοσειρές αναπαρίστανται ως ακολουθία χαρακτήρων, που σημαίνει ότι το μήκος μιας συμβολοσειράς είναι ο αριθμός των χαρακτήρων που περιέχει.
Αυτή είναι μια πολύ σημαντική διάκριση, γιατί σημαίνει ότι στη Swift το μήκος μιας συμβολοσειράς δεν είναι απαραίτητα το ίδιο με τον αριθμό των byte που καταλαμβάνει στη μνήμη.
Αυτό με τη σειρά του είναι ο λόγος που δεν μπορούμε να χρησιμοποιήσουμε ακέραιους αριθμούς για να δείξουμε θέσεις μέσα στις συμβολοσειρές.
