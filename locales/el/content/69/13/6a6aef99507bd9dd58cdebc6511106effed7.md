# Οδηγίες

Σε αυτήν την άσκηση θα γράψεις κώδικα για να βοηθήσεις τον Larry the Lisp Alien να αναλύει και να μορφοποιεί συμβολοσειρές καταγραφής. Αυτές οι συμβολοσειρές καταγραφής έρχονται από διάφορα συστήματα και πρέπει να υποστούν επεξεργασία, ώστε τα μηνύματά τους να μπορούν να εμφανίζονται σε μια κατατοπιστική οθόνη παρακολούθησης.

Οι συμβολοσειρές καταγραφής έχουν τη μορφή `"[<level>]: <message>"`. Το επίπεδο θα είναι μία από τις ακόλουθες τιμές: `info`, `warn` ή `ohno`.

## 1. Εξήγαγε το μήνυμα

Όρισε μια συνάρτηση `log-message` που θα παίρνει μια συμβολοσειρά καταγραφής και θα αξιολογείται στο μήνυμα που περιέχει.

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. Προσδιόρισε τη σοβαρότητα

Το επίπεδο της συμβολοσειράς καταγραφής καθορίζει τη σοβαρότητά της.

- ένα επίπεδο `info` σημαίνει σοβαρότητα `:everything-ok`
- ένα επίπεδο `warn` σημαίνει σοβαρότητα `:getting-worried`
- ένα επίπεδο `ohno` σημαίνει σοβαρότητα `:run-for-cover`

Όρισε μια συνάρτηση `log-severity` που θα παίρνει μια συμβολοσειρά καταγραφής και θα αξιολογείται στη σωστή σοβαρότητα.

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. Αντιμετώπισε τις ιδιοτροπίες της πραγματικότητας

Δυστυχώς, μερικές φορές οι συμβολοσειρές καταγραφής δεν είναι πάντα σωστά μορφοποιημένες. Συγκεκριμένα, το επίπεδο καταγραφής μπορεί να μην είναι εξ ολοκλήρου πεζό, όπως ορίστηκε παραπάνω. Τροποποίησε τη `log-severity` ώστε να το χειρίζεται αυτό.

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. Αναδιαμόρφωσε το μήνυμα καταγραφής ανάλογα με τη σοβαρότητά του

Ανάλογα με τη σοβαρότητα, το μήνυμα πρέπει να τροποποιείται με διαφορετικούς τρόπους:

- σε μια σοβαρότητα `:everything-ok` το μήνυμα πρέπει να αλλάζει ώστε να είναι όλο πεζό.
- σε μια σοβαρότητα `:getting-worried` το μήνυμα πρέπει να αλλάζει ώστε κάθε λέξη να αρχίζει με κεφαλαίο γράμμα.
- σε μια σοβαρότητα `:run-for-cover` το μήνυμα πρέπει να αλλάζει ώστε να είναι όλο κεφαλαία.

Όρισε μια συνάρτηση `log-format` που παίρνει ένα μήνυμα καταγραφής και αξιολογείται σε ένα σωστά μορφοποιημένο μήνυμα.

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
