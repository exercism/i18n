# Οδηγίες

Γράφεις κώδικα για το σύστημα δεδομένων στο δάπεδο παραγωγής ενός εργοστασίου ανταλλακτικών αυτοκινήτων.
Εξαρτήματα κινητήρα και πλαισίου περνούν από μια σειρά σταθμών κατεργασίας.
Κάθε σταθμός παράγει μετρήσεις που πρέπει να συνδυαστούν, να συγκριθούν, να βαθμονομηθούν ή να κανονικοποιηθούν πριν εκτελεστεί το επόμενο στάδιο.
Οι συναρτήσεις που υλοποιείς εδώ είναι μία για κάθε σταθμό.

~~~~exercism/note
Οι υπολογισμοί σε αυτή την άσκηση θα πρέπει να γίνονται με εντολές SIMD, όχι με βαθμωτές πράξεις.
~~~~

## 1. Συνδύασε τις αποδόσεις από δύο γραμμές

Στο δάπεδο παραγωγής λειτουργούν δύο παράλληλες γραμμές συναρμολόγησης.
Στο τέλος κάθε βάρδιας, και οι δύο γραμμές αναφέρουν τις αποδόσεις τους για 4 κάδους εξαρτημάτων ως αριθμούς απλής ακρίβειας.
Ο πίνακας ελέγχου του επόπτη δείχνει τη συνδυασμένη απόδοση ανά κάδο, οπότε οι δύο αναφορές αθροίζονται κάδο προς κάδο.
Και τα τρία buffer διαχειρίζεται το σύστημα αναφορών και είναι πάντα ευθυγραμμισμένα στα 16 byte.

Όρισε μια συνάρτηση `sum_yields` που, δεδομένων των αποδόσεων ανά κάδο από τα `line_a` και `line_b`, γράφει το άθροισμα ανά κάδο στο `result`.
Τα ορίσματα, με τη σειρά, είναι:

1. `line_a`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 4 αριθμούς κινητής υποδιαστολής 32 bit
2. `line_b`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 4 αριθμούς κινητής υποδιαστολής 32 bit
3. `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte όπου η συνάρτηση θα γράψει 4 αριθμούς κινητής υποδιαστολής 32 bit

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής, αντίθετα το αποτέλεσμα αποθηκεύεται στο buffer που περνάς (`result`):

```c
line_a = {10.0, 20.0, 30.0, 40.0};
line_b = { 5.0, 15.0, 25.0, 35.0};
sum_yields(line_a, line_b, result);
// => result == {15.0, 35.0, 55.0, 75.0};
```

## 2. Υπολόγισε την κλιμακωμένη απόκλιση

Μεταξύ των εργασιών, ένας σταθμός δειγματοληψίας μετρά κατεργασμένα εξαρτήματα και τα συγκρίνει με τις διαστάσεις-στόχους.
Οι μετρημένες τιμές καταφθάνουν από ένα όργανο ακριβείας σε ένα buffer που είναι πάντα ευθυγραμμισμένο στα 16 byte.
Οι τιμές-στόχοι προέρχονται από το πακέτο εντολής εργασίας, το οποίο δεν έχει εγγύηση ευθυγράμμισης.
Η απόκλιση πολλαπλασιάζεται με έναν συντελεστή ευαισθησίας ανά άξονα πριν περάσει στον επόμενο έλεγχο ανοχών.
Για αυτό το στάδιο, ο επόμενος έλεγχος διαβάζει την απόκλιση απευθείας από έναν καταχωρητή SIMD και όχι από τη μνήμη.

Όρισε μια συνάρτηση `scaled_deviation` που, δεδομένων των `measured` και `target` και μιας `sensitivity`, γράφει την κλιμακωμένη απόκλιση στο `result`.
Τα ορίσματα, με τη σειρά, είναι:

1. `measured`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit
2. `target`: διεύθυνση μνήμης που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit (χωρίς εγγύηση ευθυγράμμισης)
3. `sensitivity`: διεύθυνση μνήμης που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit (χωρίς εγγύηση ευθυγράμμισης)
4. `result`: διεύθυνση μνήμης για ένα buffer όπου η συνάρτηση θα γράψει 2 αριθμούς κινητής υποδιαστολής 64 bit (χωρίς εγγύηση ευθυγράμμισης)

Η κλιμακωμένη απόκλιση είναι `(measured - target) * sensitivity`, ανά λωρίδα.

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής, αντίθετα το αποτέλεσμα αποθηκεύεται στο buffer που περνάς (`result`) ως ζεύγος αριθμών κινητής υποδιαστολής 64 bit.

```c
measured    = {10.5, 20.5};
target      = {10.0, 20.0};
sensitivity = { 2.0,  4.0};
scaled_deviation(measured, target, sensitivity, result);
// => result == {1.0, 2.0};
```

## 3. Βαθμονόμησε μια παρτίδα

Πριν τα εξαρτήματα μπουν στο τελικό τμήμα επιθεώρησης, οι μετρήσεις διαστάσεων από μια παρτίδα 4 εξαρτημάτων μετατρέπονται ξανά σε διπλή ακρίβεια και διορθώνονται για τη γνωστή θερμική μετατόπιση.

Οι 4 ακατέργαστες μετρήσεις φτάνουν ως αριθμοί απλής ακρίβειας.
Για κάθε σειρά 2 μετρήσεων, η βαθμονόμηση υπολογίζει `reference / (raw - offset)` και στη συνέχεια πολλαπλασιάζει αυτό το αποτέλεσμα με έναν σταθερό συντελεστή μετατροπής `0.5`.

Σημείωσε ότι το reference και το offset είναι τα ίδια και για τις δύο σειρές της παρτίδας.
Ο συντελεστής μετατροπής είναι ο ίδιος σε κάθε βαθμονόμηση, οπότε αντί να τον λαμβάνεις ως όρισμα, θα πρέπει να τον δηλώσεις ως συσκευασμένη σταθερά 16 byte στη μνήμη.

Όρισε μια συνάρτηση `calibrate_batch` που, δεδομένων μιας παρτίδας `raw`, ενός `reference`, ενός `offset` και ενός buffer `result`, γράφει τις βαθμονομημένες τιμές στο `result`.
Τα ορίσματα, με τη σειρά, είναι:

1. `raw`: διεύθυνση μνήμης που περιέχει 4 αριθμούς κινητής υποδιαστολής 32 bit (χωρίς εγγύηση ευθυγράμμισης)
2. `reference`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit
3. `offset`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit
4. `result`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte όπου η συνάρτηση θα γράψει 4 αριθμούς κινητής υποδιαστολής 64 bit (32 byte συνολικά)

Η συνάρτηση θα πρέπει, για κάθε μία από τις δύο σειρές της παρτίδας:

1. Να μετατρέπει τις 2 ακατέργαστες τιμές απλής ακρίβειας της σειράς σε διπλή ακρίβεια.
2. Να αφαιρεί το `offset` από το ζεύγος που προέκυψε.
3. Να διαιρεί το `reference` με το αποτέλεσμα.
4. Να πολλαπλασιάζει ανά λωρίδα κάθε αριθμό κινητής υποδιαστολής 64 bit με τον σταθερό συντελεστή μετατροπής `0.5`.
5. Να αποθηκεύει τους 2 αριθμούς κινητής υποδιαστολής 64 bit στα αντίστοιχα 16 byte του `result`.

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής, αντίθετα το αποτέλεσμα αποθηκεύεται στο buffer που περνάς (`result`):

```c
raw       = {10.0, 20.0, 25.0, 50.0};
reference = {100.0, 100.0};
offset    = {  5.0,  10.0};
calibrate_batch(raw, reference, offset, result);
// => result == {10.0, 5.0, 2.5, 1.25};
```

## 4. Κανονικοποίησε τις βαθμολογίες κατά μήκος μιας γραμμής

Στο τέλος της γραμμής, κάθε εξάρτημα έχει μια βαθμολογία ποιότητας που πρέπει να κανονικοποιηθεί πριν αναφερθεί.
Κάθε βαθμολογία πολλαπλασιάζεται με το δικό της κέρδος ανά εξάρτημα και στη συνέχεια διαιρείται με μια κλίμακα παραγωγής ανά άξονα.
Το buffer των κερδών περιέχει ένα κέρδος ανά εξάρτημα.

Η κλίμακα παραγωγής είναι η ίδια για όλη τη διαδικασία και περνά σε μια διεύθυνση μνήμης που περιέχει δύο αριθμούς κινητής υποδιαστολής 64 bit.
Οι βαθμολογίες ενημερώνονται **επί τόπου**: το ίδιο buffer που περιείχε τις αρχικές βαθμολογίες περιέχει τώρα τις κανονικοποιημένες βαθμολογίες.

Όρισε μια συνάρτηση `normalize_scores` που, δεδομένων ενός πίνακα `scores`, ενός πίνακα `gains`, μιας `scale` και ενός πλήθους `n`, κανονικοποιεί τις βαθμολογίες επί τόπου.
Τα ορίσματα, με τη σειρά, είναι:

1. `scores`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει `n` αριθμούς κινητής υποδιαστολής 64 bit (τροποποιείται επί τόπου)
2. `gains`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει `n` αριθμούς κινητής υποδιαστολής 64 bit
3. `scale`: διεύθυνση μνήμης ευθυγραμμισμένη στα 16 byte που περιέχει 2 αριθμούς κινητής υποδιαστολής 64 bit
4. `n`: ένας θετικός άρτιος ακέραιος 64 bit (ελάχιστο `2`), το πλήθος των βαθμολογιών που θα κανονικοποιηθούν

Οι δύο λωρίδες της κλίμακας εφαρμόζονται στα δύο στοιχεία κάθε ζεύγους.
Η πρώτη λωρίδα κλιμακώνει το πρώτο στοιχείο κάθε ζεύγους (λωρίδες σε άρτιες θέσεις), η δεύτερη λωρίδα κλιμακώνει το δεύτερο (λωρίδες σε περιττές θέσεις).
Κάθε βαθμολογία πολλαπλασιάζεται με το αντίστοιχο κέρδος της και στη συνέχεια διαιρείται με την κατάλληλη λωρίδα της κλίμακας: `score * gain / scale_lane`.

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής, αντίθετα το αποτέλεσμα αποθηκεύεται στο buffer εισόδου (`scores`), στην ίδια θέση με την αντίστοιχη `score` που κανονικοποιήθηκε:

```c
n      = 4
scores = {10.0, 20.0, 30.0, 40.0};
gains  = { 2.0,  1.5,  1.0,  0.5};
scale  = { 2.0,  4.0};
normalize_scores(scores, gains, scale, n);
// => scores == {10.0, 7.5, 15.0, 5.0};
```
