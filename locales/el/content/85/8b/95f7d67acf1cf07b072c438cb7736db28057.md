# Οδηγίες

Μέτρησε τους πόντους που έχουν σκοραριστεί σε ένα ταμπλό Go.

Στο παιχνίδι Go (γνωστό και ως baduk, igo, cờ vây και wéiqí) κερδίζεις πόντους περικυκλώνοντας πλήρως κενά σημεία τομής με τις πέτρες σου. Τα περικυκλωμένα σημεία τομής ενός παίκτη είναι γνωστά ως η περιοχή του.

Γράψε μια συνάρτηση που προσδιορίζει την περιοχή κάθε παίκτη. Μπορείς να υποθέσεις ότι τυχόν πέτρες που έχουν εγκλωβιστεί σε εχθρική περιοχή έχουν ήδη αφαιρεθεί από το ταμπλό.

Γράψε μια συνάρτηση που προσδιορίζει την περιοχή στην οποία ανήκει μια συγκεκριμένη συντεταγμένη.

Πολλά κενά σημεία τομής μπορούν να περικυκλωθούν ταυτόχρονα, και για την περικύκλωση μετρούν μόνο οι οριζόντιοι και οι κάθετοι γείτονες. Στο παρακάτω διάγραμμα, οι πέτρες που παίζουν ρόλο σημειώνονται με "O" και οι πέτρες που δεν παίζουν ρόλο σημειώνονται με "I" (αγνοούνται). Οι κενοί χώροι αντιπροσωπεύουν κενά σημεία τομής.

```text
+----+
|IOOI|
|O  O|
|O OI|
|IOI |
+----+
```

Για να είμαστε πιο ακριβείς, ένα κενό σημείο τομής αποτελεί μέρος της περιοχής ενός παίκτη αν όλοι οι γείτονές του είναι είτε πέτρες αυτού του παίκτη είτε κενά σημεία τομής που αποτελούν μέρος της περιοχής αυτού του παίκτη.

Για περισσότερες πληροφορίες, δες τη [Βικιπαίδεια](https://en.wikipedia.org/wiki/Go_%28game%29) ή τη [Sensei's Library](http://senseis.xmp.net/).
