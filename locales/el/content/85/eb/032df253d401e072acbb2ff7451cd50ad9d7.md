# Εισαγωγή

Ο Python αναπαριστά τις τιμές αληθής και ψευδής με τον τύπο [`bool`][bools], ο οποίος είναι υποκλάση του `int`.
Κάτω από αυτόν τον τύπο υπάρχουν μόνο δύο τιμές: `True` και `False`.
Αυτές οι τιμές μπορούν να εκχωρηθούν σε μια μεταβλητή:

```python
>>> true_variable = True
>>> false_variable = False
```

Μπορούμε να αποτιμήσουμε Boolean εκφράσεις χρησιμοποιώντας τους τελεστές `and`, `or` και `not`.

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
