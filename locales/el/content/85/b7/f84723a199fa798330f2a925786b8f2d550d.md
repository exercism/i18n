# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα που θα σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.
Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη σταθερά `expectedMinutesInOven`, που αποθηκεύει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```swift
expectedMinutesInOven
// Returns 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `remainingMinutesInOven(elapsedMinutes:)` που παίρνει το όρισμα `elapsedMinutes`, το οποίο περιέχει τον αριθμό των λεπτών που τα λαζάνια είναι ήδη στον φούρνο.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparationTimeInMinutes(layers:)` που παίρνει το όρισμα `layers`, το οποίο περιέχει τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά πέρασες προετοιμάζοντας τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη συνάρτηση `totalTimeInMinutes(layers:elapsedMinutes:)` που παίρνει δύο ορίσματα: η παράμετρος `layers` είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και η παράμετρος `elapsedMinutes` είναι ο αριθμός των λεπτών που τα λαζάνια είναι στον φούρνο.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει συνολικά μαγειρεύοντας τα λαζάνια, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στον φούρνο μέχρι στιγμής.

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
