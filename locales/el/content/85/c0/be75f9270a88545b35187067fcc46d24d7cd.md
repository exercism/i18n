Τα πράγματα όμως είναι λίγο ανοργάνωτα: οι συντεταγμένες της Azara φαίνεται να έχουν διαφορετική μορφή και σειρά από του Rui, και πρέπει να κοιτούν συνεχώς από τη μια λίστα στην άλλη για να καταλάβουν ποιοι θησαυροί πάνε με ποιες τοποθεσίες.
Καθώς είναι αρχάριοι προγραμματιστές Julia, ήρθαν σε σένα για βοήθεια, ώστε να γράψουν ένα μικρό πρόγραμμα (βασικά, ένα σύνολο από συναρτήσεις) που θα οργανώσει καλύτερα τις πληροφορίες του κυνηγιού τους.

## 1. Εξαγωγή συντεταγμένων

Υλοποίησε τη συνάρτηση `get_cooordinate()` που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και επιστρέφει μόνο τη συντεταγμένη του χάρτη που εξάγεται.

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. Μορφοποίηση συντεταγμένων

Υλοποίησε τη συνάρτηση `convert_coordinate()` που παίρνει μια συντεταγμένη στη μορφή "2A" και επιστρέφει μια πλειάδα στη μορφή `('2', 'A')`.

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. Αντιστοίχιση συντεταγμένων

Υλοποίησε τη συνάρτηση `compare_records()` που παίρνει ένα ζεύγος `(treasure, coordinate)` και μια καταγραφή `(location, coordinate, quadrant)` και συγκρίνει τις συντεταγμένες τους.
Επίστρεψε **`true`** αν οι συντεταγμένες "ταιριάζουν", και επίστρεψε **`false`** αν δεν ταιριάζουν.
Μορφοποίησε ξανά τις συντεταγμένες όπως χρειάζεται για σωστή σύγκριση.

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. Συνδυασμός των ταιριασμένων καταγραφών

Υλοποίησε τη συνάρτηση `create_record()` που παίρνει ένα ζεύγος `(treasure, coordinate)` από τη λίστα της Azara και μια καταγραφή `(location, coordinate, quadrant)` από τη λίστα του Rui και επιστρέφει `(coordinate, location, quadrant, treasure)` **αν οι συντεταγμένες ταιριάζουν**.

Αν οι συντεταγμένες _δεν_ ταιριάζουν, επίστρεψε μια κενή πλειάδα.
Μορφοποίησε ξανά τις συντεταγμένες όπως χρειάζεται για σωστή σύγκριση.

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
