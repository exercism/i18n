# Παράρτημα οδηγιών

## Υλοποίηση

Το όρισμα `diagram` ξεκινά κάθε γραμμή με ένα `\n`.
Αυτό επιτρέπει στα raw string literals της Go να παρουσιάζουν τα διαγράμματα στον πηγαίο κώδικα ωραία, ως δύο γραμμές στοιχισμένες αριστερά.
Για παράδειγμα, το test μπορεί να περιέχει το εξής.

```go
        diagram := `
VVCCGG
VVCCGG`
```

Αν το όρισμα `children` είναι `nil`, χρησιμοποίησε τη λίστα με τα παιδιά που ορίζεται στις παραπάνω οδηγίες.
Αν δεν είναι `nil`, χρησιμοποίησε την τιμή που δίνεται.
