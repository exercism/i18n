# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα που θα βοηθήσει έναν ελεύθερο επαγγελματία να επικοινωνεί με τους πελάτες του για τις τιμές ορισμένων έργων.
Θα γράψεις μερικές βοηθητικές συναρτήσεις για να υπολογίζεις γρήγορα το κόστος για τους πελάτες.

```exercism/note
Η μεταβλητή `ratePerHour` και η συνάρτηση `dayRate` έχουν σχέση με χρήματα.
Οι μονάδες μέτρησης είναι χρήματα ανά μονάδα χρόνου: ώρες και ημέρες αντίστοιχα.
```

## 1. Υπολόγισε την ημερήσια χρέωση με βάση την ωριαία χρέωση

Ένας πελάτης επικοινωνεί με τον ελεύθερο επαγγελματία για να ρωτήσει τις χρεώσεις του.
Ο ελεύθερος επαγγελματίας εξηγεί ότι **_δουλεύει 8 ώρες την ημέρα._**
Ωστόσο, ο ελεύθερος επαγγελματίας γνωρίζει μόνο την ωριαία χρέωσή του για το έργο.
Βοήθησέ τον να υπολογίσει μια ημερήσια χρέωση με βάση την ωριαία χρέωση.

```javascript
dayRate(89);
// => 712
```

Η ημερήσια χρέωση δεν χρειάζεται να στρογγυλοποιηθεί ούτε να μετατραπεί σε "σταθερή" ακρίβεια.

## 2. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένο έναν σταθερό προϋπολογισμό

Μια άλλη μέρα, ένας υπεύθυνος έργου προτείνει στον ελεύθερο επαγγελματία να δουλέψει σε ένα έργο με σταθερό προϋπολογισμό.
Με δεδομένο τον σταθερό προϋπολογισμό και την ωριαία χρέωση του ελεύθερου επαγγελματία, βοήθησέ τον να υπολογίσει πόσες ημέρες θα δουλέψει μέχρι να εξαντληθεί ο προϋπολογισμός.
Το αποτέλεσμα _πρέπει_ να **στρογγυλοποιηθεί προς τα κάτω** στον πλησιέστερο ακέραιο αριθμό.

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. Υπολόγισε τη χρέωση με έκπτωση για μεγάλα έργα

Συχνά, οι πελάτες του ελεύθερου επαγγελματία τον προσλαμβάνουν για έργα που διαρκούν πολλούς μήνες.
Σε αυτές τις περιπτώσεις, ο ελεύθερος επαγγελματίας αποφασίζει να προσφέρει έκπτωση για κάθε πλήρη μήνα, και οι υπόλοιπες ημέρες χρεώνονται με την ημερήσια χρέωση.
Η εξαιρετική σου ισορροπία μεταξύ επαγγελματικής και προσωπικής ζωής σημαίνει ότι δουλεύεις μόνο 22 ημέρες σε κάθε ημερολογιακό μήνα, οπότε **_κάθε μήνας έχει 22 ημέρες με χρέωση._**
Βοήθησέ τον να υπολογίσει το κόστος του για τέτοια έργα, με δεδομένη την ωριαία χρέωση, τον αριθμό των ημερών με χρέωση που περιέχει το έργο και ένα μηνιαίο ποσοστό έκπτωσης.
Η έκπτωση περνιέται πάντα ως αριθμός, όπου το `42%` γίνεται `0.42`. Το αποτέλεσμα _πρέπει_ να **στρογγυλοποιηθεί προς τα πάνω** στον πλησιέστερο ακέραιο αριθμό.

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
