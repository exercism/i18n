# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση         | Τύπος   | Περιγραφή                                        |
| ----------- | ------------- | ------- | ------------------------------------------------ |
| `$a0`       | είσοδος       | διεύθυνση | πρώτο χρώμα ως συμβολοσειρά τερματιζόμενη με null  |
| `$a1`       | είσοδος       | διεύθυνση | δεύτερο χρώμα ως συμβολοσειρά τερματιζόμενη με null |
| `$a2`       | είσοδος       | διεύθυνση | τρίτο χρώμα ως συμβολοσειρά τερματιζόμενη με null  |
| `$a3`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματιζόμενη με null         |
| `$t0-9`     | προσωρινός    | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση         |
