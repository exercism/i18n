# Εισαγωγή

## Τύποι συναρτήσεων

Αν αφαιρέσεις όλα τα ονόματα και τις ετικέτες από την υπογραφή μιας συνάρτησης Swift, αυτό που απομένει είναι ο τύπος της συνάρτησης.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Πρόσεξε ότι οι τύποι των δύο πρώτων συναρτήσεων είναι ίδιοι, `(String, Int) -> String`, παρόλο που οι δύο υπογραφές είναι διαφορετικές και οι δύο συναρτήσεις λειτουργούν με πολύ διαφορετικό τρόπο. Και οι δύο παίρνουν ένα `String` και ένα `Int` ως είσοδο και επιστρέφουν ένα `String`. Και, όπως φαίνεται από τον τύπο της τρίτης συνάρτησης, παρόλο που το σώμα της συνάρτησης δεν φαίνεται να επιστρέφει τίποτα, στην πραγματικότητα επιστρέφει σιωπηρά `()`, τη μοναδική τιμή του τύπου `Void`.

Αυτοί οι τύποι συναρτήσεων μπορούν να χρησιμοποιηθούν με τον ίδιο τρόπο όπως οποιοσδήποτε άλλος τύπος στη Swift, για παράδειγμα, μπορούν να χρησιμοποιηθούν στη δήλωση μεταβλητών ή σταθερών. Και επειδή οι συναρτήσεις είναι τιμές στη Swift, συναρτήσεις που υπάρχουν ήδη μπορούν να εκχωρηθούν σε αυτές τις σταθερές/μεταβλητές:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Όπως και με τις άλλες μεταβλητές/σταθερές, η τιμή που της εκχωρείς πρέπει να είναι του σωστού τύπου:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Τύποι συναρτήσεων ως τύποι παραμέτρων

Εφόσον οι τύποι συναρτήσεων μπορούν να χρησιμοποιηθούν οπουδήποτε μπορούν να χρησιμοποιηθούν άλλοι τύποι, έπεται ότι μπορούν να χρησιμοποιηθούν ως τύποι παραμέτρων, να μεταβιβαστούν σε άλλες συναρτήσεις και να κληθούν μέσα από αυτές.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Τύποι συναρτήσεων ως τύποι επιστροφής

Παρομοίως, οι τύποι συναρτήσεων μπορούν να χρησιμοποιηθούν ως τύποι επιστροφής για συναρτήσεις. Με άλλα λόγια, μπορείς να γράψεις συναρτήσεις που δημιουργούν και επιστρέφουν άλλες συναρτήσεις. Όταν δημιουργείς αυτές τις συναρτήσεις, η συνάρτηση που επιστρέφεται μπορεί να χρησιμοποιήσει τις άλλες παραμέτρους που μεταβιβάστηκαν στη συνάρτηση ή τις τοπικές μεταβλητές που δημιουργήθηκαν μέσα στη γονική συνάρτηση.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
