# Προσθήκη στις οδηγίες

## Υποδείξεις

Τα μοναδιαία τεστ παρέχουν παραδείγματα λέξεων. Δοκίμασε να ομαδοποιήσεις τα σύμφωνα ανεξάρτητα από τους συγκεκριμένους συνδυασμούς συμφώνων στα μοναδιαία τεστ.

Αυτή η άσκηση δουλεύει με δεδομένα κειμένου. Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με τον τύπο `[Char]`, μια λίστα χαρακτήρων. Για πιο αποδοτικό χειρισμό δεδομένων κειμένου, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να κάνεις τα παρακάτω:

- Διάβασε για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη Haskell.
- Πρόσθεσε το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- Κάνε import το `Data.Text` με [τον ακόλουθο τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

      import qualified Data.Text as T
      import           Data.Text (Text)

- Μπορείς τώρα να γράψεις π.χ. `translate :: Text -> Text` και να αναφέρεσαι σε combinators του `Data.Text` ως π.χ. `T.isSuffixOf`.
- Αναζήτησε την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Αυτό το μέρος είναι εντελώς προαιρετικό.
