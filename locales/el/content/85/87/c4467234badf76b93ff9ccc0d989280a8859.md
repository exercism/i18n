# Εισαγωγή

Ένα *disposable* είναι οτιδήποτε κρατά έναν πόρο του λειτουργικού συστήματος (ένα ανοιχτό αρχείο, ένα socket, ένα κλείδωμα που στηρίζεται σε πίνακα κατακερματισμού) και πρέπει να απελευθερωθεί όταν τελειώσεις μαζί του. Το [`destructors`][destructors] vocab του Factor τα τυλίγει σε ένα μικρό framework, ώστε ο καθαρισμός να γίνεται ακόμη και όταν μια εξαίρεση ξετυλίγει τη στοίβα.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

Το `with-disposal ( disposable quot -- )` εκτελεί το quotation με τον πόρο και τον αποδεσμεύει κατά την έξοδο. Για περισσότερους από έναν πόρους, άνοιξε ένα πεδίο με `with-destructors` και καταχώρισε τον καθένα με `&dispose` (αποδέσμευση στην κανονική έξοδο *και* σε περίπτωση σφάλματος) ή `|dispose` (αποδέσμευση μόνο σε περίπτωση σφάλματος).

Μια κλάση συμμετέχει στο framework επεκτείνοντας το `disposable` και υλοποιώντας το generic `dispose*`. Το framework το καλεί μία φορά και μόνο μία φορά για κάθε αντικείμενο. Η δημόσια λέξη που χρησιμοποιούν όσοι την καλούν είναι η `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
