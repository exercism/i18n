# Οδηγίες

Διαχειρίζεσαι τη θέση ασφαλείας σε έναν ερευνητικό σταθμό. Το προσωπικό φέρει *σήματα* των οποίων οι κωδικοί ακολουθούν έναν αυστηρό κανόνα, το αρχείο καταγραφής πρόσβασης είναι γεμάτο από αυτούς τους κωδικούς ανακατεμένους μέσα σε συνηθισμένο κείμενο, και το αρχείο πρέπει να καθαριστεί πριν μπορέσει να μοιραστεί. Οι κανονικές εκφράσεις είναι το κατάλληλο εργαλείο για καθεμιά από αυτές τις δουλειές.

Ένας έγκυρος κωδικός σήματος είναι **δύο κεφαλαία γράμματα, μια παύλα και μετά τέσσερα ψηφία**, για παράδειγμα `NS-1024`.

## 1. Έλεγξε έναν κωδικό σήματος

Όρισε τη `valid-badge?`, που παίρνει μια συμβολοσειρά σήματος και επιστρέφει `t` όταν *ολόκληρη* η συμβολοσειρά είναι έγκυρος κωδικός σήματος και `f` διαφορετικά.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Βγάλε κάθε κωδικό από μια γραμμή αρχείου καταγραφής

Όρισε τη `badge-codes`, που παίρνει μια γραμμή του αρχείου καταγραφής πρόσβασης και επιστρέφει μια ακολουθία με όλους τους κωδικούς σήματος που εμφανίζονται σε αυτή, με τη σειρά.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Μέτρησε τα ψηφία σε έναν κωδικό

Όρισε τη `digit-count`, που παίρνει μια συμβολοσειρά και επιστρέφει πόσα ψηφία περιέχει.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Απόκρυψε τους κωδικούς πρόσβασης

Οι γραμμές του αρχείου καταγραφής μερικές φορές καταγράφουν έναν κωδικό πρόσβασης ως `pass=` ακολουθούμενο από το μυστικό (οποιαδήποτε ακολουθία χαρακτήρων χωρίς κενά). Όρισε τη `redact`, που παίρνει μια γραμμή και την επιστρέφει με κάθε τέτοιο κωδικό πρόσβασης αντικατεστημένο από `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
