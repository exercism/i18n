# Tests

## Εκτέλεση των tests

Για να τρέξεις τα tests, εκτέλεσε την ακόλουθη εντολή:

```bash
dotnet test
```

## Επίλυση της άσκησης

Το να λύσεις μια άσκηση σημαίνει να περάσεις όλα τα tests της. Από προεπιλογή, όταν τρέχεις τα tests, εκτελείται μόνο ένα test (το πρώτο). Αυτό είναι σκόπιμο, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσει μόνο αυτό το ένα test. Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο test αφαιρώντας το `Skip = "Remove this Skip property to run this test"` από το χαρακτηριστικό `[<Fact>]` ή `[<Theory>]` του test. Όταν ενεργοποιηθούν όλα τα tests και η υλοποίησή σου τα περάσει όλα, θα έχεις λύσει την άσκηση!

Για να σε βοηθήσουμε να ξεκινήσεις, κάθε άσκηση συνοδεύεται από ένα αρχείο stub υλοποίησης. Μπορείς να χρησιμοποιήσεις αυτό το αρχείο ως σημείο εκκίνησης για να χτίσεις τη λύση σου. Μη διστάσεις να διαγράψεις ή να αλλάξεις αυτό το αρχείο, αν πιστεύεις ότι είναι το σωστό.

## Χρήση πακέτων

Θα μπορείς να λύσεις τις περισσότερες ασκήσεις χωρίς να χρησιμοποιήσεις εξωτερικά πακέτα. Ωστόσο, για τις ασκήσεις στις οποίες θέλεις πραγματικά να χρησιμοποιήσεις ένα εξωτερικό πακέτο, μπορείς να το προσθέσεις στο project σου τρέχοντας την ακόλουθη εντολή:

```bash
dotnet add package [package-name]
```
