# Εισαγωγή

## Αριθμοί

Στη Java υπάρχουν δύο διαφορετικοί τύποι αριθμών:

- Ακέραιοι αριθμοί: αριθμοί χωρίς ψηφία μετά την υποδιαστολή.
  Παραδείγματα είναι τα `-6`, `0`, `1`, `25`, `976` και `-500000`.
- Αριθμοί κινητής υποδιαστολής: αριθμοί με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή.
  Παραδείγματα είναι τα `-20.4`, `0.1`, `2.72`, `16.984025` και `1024.0`.

Οι δύο πιο συνηθισμένοι αριθμητικοί τύποι στη Java είναι ο `int` και ο `double`.
Ένας `int` είναι ένας ακέραιος 32 bit και ένας `double` είναι ένας αριθμός κινητής υποδιαστολής 64 bit.

Η αριθμητική γίνεται με τους τυπικούς αριθμητικούς τελεστές.
Οι αριθμοί μπορούν να συγκριθούν με τους τυπικούς τελεστές σύγκρισης αριθμών (π.χ. `5 > 4` και `4 <= 5`) καθώς και με τους τελεστές ισότητας (`==`) και ανισότητας (`!=`).

Η Java έχει δύο τύπους αριθμητικών μετατροπών:

1. Έμμεσες μετατροπές: δεν χάνονται δεδομένα και δεν απαιτείται πρόσθετη σύνταξη.
2. Άμεσες μετατροπές: μπορεί να χαθούν δεδομένα και απαιτείται πρόσθετη σύνταξη με τη μορφή _cast_.

Καθώς ένας `int` έχει μικρότερη ακρίβεια από έναν `double`, η μετατροπή από `int` σε `double` είναι ασφαλής και επομένως είναι έμμεση μετατροπή.
Ωστόσο, η μετατροπή από `double` σε `int` μπορεί να σημαίνει απώλεια δεδομένων, οπότε απαιτεί άμεση μετατροπή.

## Εντολές if-else

### Η εντολή _if-then_

Η πιο βασική εντολή ελέγχου ροής στη Java είναι η εντολή _if-then_.
Αυτή η εντολή χρησιμοποιείται για να εκτελεστεί ένα τμήμα κώδικα μόνο αν μια συγκεκριμένη συνθήκη είναι `true`.
Μια εντολή _if-then_ ορίζεται με τη ρήτρα `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Στο παραπάνω παράδειγμα, αν το αυτοκίνητο έχει ξεμείνει από καύσιμο, η κλήση της μεθόδου `Car.drive` δεν θα κάνει τίποτα.

### Η εντολή _if-then-else_

Η εντολή _if-then-else_ παρέχει έναν εναλλακτικό δρόμο εκτέλεσης για όταν η συνθήκη στη ρήτρα `if` αξιολογείται σε `false`.
Αυτός ο εναλλακτικός δρόμος εκτέλεσης ακολουθεί μια ρήτρα `if` και ορίζεται με τη ρήτρα `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Στο παραπάνω παράδειγμα, αν το αυτοκίνητο έχει ξεμείνει από καύσιμο, η κλήση της μεθόδου `Car.drive` θα καλέσει μια άλλη μέθοδο για να σταματήσει το αυτοκίνητο.

Η εντολή _if-then-else_ υποστηρίζει επίσης πολλαπλές συνθήκες με τη ρήτρα `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Στο παραπάνω παράδειγμα, αν οδηγήσεις το αυτοκίνητο με καύσιμο μικρότερο ή ίσο με `5`, το αυτοκίνητο θα κινηθεί, αλλά θα ανάψει η λυχνία καυσίμου.
Όταν το καύσιμο φτάσει στο `0`, το αυτοκίνητο θα σταματήσει να κινείται.
