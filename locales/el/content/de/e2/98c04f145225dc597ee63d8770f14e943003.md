# Σχετικά

Το `bit` είναι η πιο στοιχειώδης τιμή στην πληροφορική.
Η λέξη `bit` είναι σύντμηση του "binary digit", δηλαδή του δυαδικού ψηφίου.
Είναι μια μονάδα αποθήκευσης δεδομένων στο περιβάλλον εκτέλεσης, αρκετά μεγάλη ώστε να χωράει ένα αντικείμενο που μπορεί να έχει μία από δύο τιμές.
Ως εκ τούτου, έχει δυαδική τιμή είτε `1` είτε `0`.
Όλοι οι άλλοι τύποι δεδομένων αποτελούνται από πολλά `bits`.
Για παράδειγμα, ένα `byte` συνήθως αποτελείται από οκτώ `bits`.

## Πώς να γράφεις τιμές bit

Τα `Bits` αποτελούν ένα σύστημα αρίθμησης με βάση το 2.
Κάθε πολλαπλάσιο του `2` μπαίνει σε αυτό που θεωρούμε θέση των δεκάδων/εκατοντάδων/χιλιάδων κ.λπ., με τη διαφορά ότι οι "δεκάδες" θα ήταν "δύο", οι "εκατοντάδες" θα ήταν "τέσσερα", οι "χιλιάδες" θα ήταν "οκτώ" και ούτω καθεξής.
Έτσι, η δεκαδική τιμή `2` θα ήταν η δυαδική τιμή `10`, το `4` θα ήταν `100` και το `8` θα ήταν `1000`.
Όπως και στους δεκαδικούς αριθμούς, οι τιμές αυξάνονται καθώς προχωράς από τα δεξιά προς τα αριστερά.
Μπορούμε να σκεφτούμε ότι η δεκαδική τιμή `5` αναπαρίσταται ως `101` στο δυαδικό σύστημα, με ένα `1` στη θέση των "μονάδων" και ένα `1` στη θέση των "τεσσάρων".
Ωστόσο, τα δυαδικά literals δεν αποτελούν μέρος του προτύπου της γλώσσας C.
Οι μόνες δυαδικές τιμές που υποστηρίζει το πρότυπο της γλώσσας C είναι ένα μεμονωμένο `1` ή `0`.
Τα δυαδικά literals _υποστηρίζονται_ από ορισμένες μη τυπικές επεκτάσεις μεταγλωττιστών, όπως ο μεταγλωττιστής gnu, βάζοντας ως πρόθεμα το `0b` μπροστά από το literal.

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

Είναι σημαντικό να θυμάσαι ότι μια τέτοια σημειογραφία δεν υποστηρίζεται από όλους τους μεταγλωττιστές και θα μπορούσε να αποτελέσει εμπόδιο στη μεταφερσιμότητα του κώδικα μεταξύ διαφορετικών μεταγλωττιστών.

Ένας συνηθισμένος τρόπος για να γράψεις δυαδικές τιμές είναι να χρησιμοποιήσεις δεκαεξαδική σημειογραφία, που είναι ένα σύστημα αρίθμησης με βάση το 16.
Η δεκαεξαδική σημειογραφία της γλώσσας C βάζει ως πρόθεμα το `0x` ή το `0X` μπροστά από το literal.
Εφόσον η δεκαδική τιμή `16` αναπαρίσταται ως `1` στη θέση των δεκάδων, η δεκαδική τιμή `10` αναπαρίσταται ως `0xA` στο δεκαεξαδικό, η `11` ως `0xB`, η `12` ως `0xC`, η `13` ως `0xD`, η `14` ως `0xE` και η `15` ως `0xF`.
Έτσι, για παράδειγμα, η δεκαδική τιμή `42` θα γραφόταν ως `0x2A`: `2` επί `16` (= `32`) συν `10` (= `42`).

Στο δυαδικό σύστημα, μπορούμε να σκεφτούμε το `42` ως `00101010`: `32` συν `8` συν `2`.
Θα λέγαμε ότι το δεύτερο, το τέταρτο και το έκτο bit από τα δεξιά είναι "τεθειμένα", δηλαδή είναι `1` αντί για `0`.
Το δεύτερο bit είναι `2`, το τέταρτο bit είναι `8` και το έκτο bit είναι `32`.
Η θέση αυτών των τριών bit ορίζει την τιμή `42`.

## Μάσκες bit

Μια μάσκα bit μπορεί να είναι οποιαδήποτε τιμή που χρησιμοποιείται για τη θέση μεμονωμένων bit.
Για παράδειγμα, το αγγλικό αλφάβητο έχει είκοσι έξι γράμματα.
Μια τιμή με τουλάχιστον είκοσι έξι bit, όπως ένας ανυπόγραφος ακέραιος 32 bit, θα μπορούσε να χρησιμοποιηθεί ως μάσκα bit για να θέσει μια συνθήκη `true` ή `false` για κάθε γράμμα του αγγλικού αλφαβήτου.
Οποιαδήποτε τιμή έχει αρκετά bit για να καλύψει ένα απαιτούμενο σύνολο συνθηκών `true` ή `false` μπορεί να χρησιμεύσει ως μάσκα bit.
Η θέση και η ανάγνωση των μεμονωμένων bit γίνεται με τη χρήση τελεστών bitwise.

## Τελεστές bitwise

Ας πούμε ότι θέλουμε να παρακολουθούμε ποια γράμματα εμφανίζονται σε μια `string`.
Για το παράδειγμά μας, θα χρησιμοποιήσουμε μόνο τα είκοσι έξι γράμματα του αγγλικού αλφαβήτου.
Η μάσκα bit μας θα είναι ένας ανυπόγραφος ακέραιος 32 bit.
Ένα `0` θα δηλώνει ότι το γράμμα δεν εμφανίζεται.
Ένα `1` θα δηλώνει ότι το γράμμα εμφανίζεται μία ή περισσότερες φορές.
Στην αρχή, η αναπαράσταση bit της μάσκας bit μας θα είναι 32 `0s` στη σειρά: `00000000000000000000000000000000`.
Η δεξιότερη θέση θα είναι για το `A`.
Η δεύτερη από τα αριστερά θα είναι για το `B`, και ούτω καθεξής.
Ας πούμε ότι επεξεργαζόμαστε όλα τα γράμματα της συμβολοσειράς σε έναν βρόχο, οπότε θέλουμε μία γραμμή κώδικα που θα δουλεύει για τη θέση οποιουδήποτε γράμματος.

### Τελεστής bitwise ολίσθησης αριστερά: ένας τρόπος να τοποθετήσεις ένα bit

Το `<<` είναι ο τελεστής bitwise για ολίσθηση αριστερά.

Αν το γράμμα μας είναι το `A`, δεν θέλουμε να κάνουμε ολίσθηση αριστερά, αλλά αν το γράμμα μας είναι το `B`, θέλουμε να κάνουμε ολίσθηση αριστερά κατά μία θέση, και αν το γράμμα μας είναι το `C`, θέλουμε να κάνουμε ολίσθηση αριστερά κατά δύο θέσεις, και ούτω καθεξής.
Αν και μπορούμε να αντιληφθούμε τα `chars` ως γράμματα όπως το `A` ή το `B`, ένα `char` υλοποιείται ως ακέραιος τύπος στη μνήμη, οπότε μπορούμε να κάνουμε απλές πράξεις με ένα `char`.
Δεδομένης μιας μεταβλητής με όνομα `letter` που αναπαριστά το `char` που επεξεργαζόμαστε, μπορούμε να κάνουμε ολίσθηση αριστερά κατά τον απαιτούμενο αριθμό θέσεων, μετατοπίζοντας το `1` αριστερά κατά τη διαφορά ανάμεσα στο `letter` και το `char` του `A`, έτσι: `1 << letter - 'A'`.
Το `A` - `A` κάνει `0`, οπότε θα έκανε ολίσθηση αριστερά `0` θέσεις αν το `letter` είναι `A`.
Το `B` - `A` κάνει `1`, οπότε θα έκανε ολίσθηση αριστερά `1` θέση αν το `letter` είναι `B`, και ούτω καθεξής.

### Τελεστής bitwise συμπεριληπτικού Ή: ένας τρόπος να θέσεις ένα bit

Μόλις ξέρουμε _πού_ θέλουμε να θέσουμε ένα bit, μπορούμε να το θέσουμε χρησιμοποιώντας τον τελεστή bitwise συμπεριληπτικού Ή, που είναι το `|`.
Το αποτέλεσμα του τελεστή `|` θα είναι `1` σε κάθε θέση όπου είτε ο αριστερός είτε ο δεξιός τελεστέος έχει τεθειμένο bit.
Έτσι, το αποτέλεσμα του `0010 | 0001` θα ήταν `0011`.
(Είναι σημαντικό να θυμάσαι ότι η τιμή είναι `11` στο δυαδικό σύστημα, αλλά `3` στο δεκαδικό.)
Για να αναθέσεις το αποτέλεσμα σε μια τιμή, ο τελεστής `|` μπορεί να συνδυαστεί με τον τελεστή ανάθεσης για να θέσεις τα bit έτσι: `|=`.
Για να το κρατήσουμε απλό, το παρακάτω παράδειγμα δεν χρησιμοποιεί βρόχο, αλλά δείχνει πώς θα μπορούσαμε να επεξεργαστούμε τα γράμματα `ABA` σε μια μάσκα bit.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Θέτουμε το δεξιότερο τμήμα της μάσκας μας σε `0001` για το `A` και μετά θέτουμε τη μάσκα σε `0011` για το `B`.
Η θέση ενός ακόμη `A` δεν αλλάζει την υπάρχουσα μάσκα.
Θα μπορούσαμε να είχαμε αποφύγει να θέσουμε ξανά το bit, ελέγχοντας αν το `A` είχε ήδη τεθεί.

### Τελεστής bitwise AND: ένας τρόπος να διαβάσεις ένα bit

Το `&` είναι ο τελεστής bitwise AND.
Το αποτέλεσμα του τελεστή `&` θα είναι `1` σε κάθε θέση όπου και ο αριστερός και ο δεξιός τελεστέος έχει τεθειμένο bit.
Έτσι, το αποτέλεσμα του `0011 & 0001` θα ήταν `0001`.
Μπορούμε να το δούμε αυτό εν δράσει στο παρακάτω παράδειγμα.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Τελεστής bitwise αποκλειστικού Ή: ένας τρόπος να αντιστρέψεις ένα bit

Το `^` είναι ο τελεστής bitwise αποκλειστικού Ή.
Ένας τελεστής _συμπεριληπτικού_ Ή υπονοεί ότι υπάρχει ένας τελεστής _αποκλειστικού_ Ή με διαφορετική συμπεριφορά.
Το αποτέλεσμα του τελεστή `^` θα είναι `1` σε κάθε θέση όπου _μόνο ένας_ από τους αριστερούς ή δεξιούς τελεστέους έχει τεθειμένο bit.
Έτσι, το αποτέλεσμα του `0001 ^ 0011` θα ήταν `0010`.
Το δεξιότερο bit δεν θα τεθεί, επειδή _και οι δύο_ τελεστέοι έχουν `1` στη δεξιότερη θέση.
Η πράξη αποκλειστικού Ή σημειώνεται μερικές φορές ως XOR.
Αν το αποτέλεσμα μιας τιμής στην οποία έγινε XOR υποστεί και το ίδιο XOR, θα επιστραφεί η αρχική τιμή.
Αυτό μπορεί να χρησιμοποιηθεί για μια πολύ απλή κρυπτογράφηση, όπου το ίδιο κλειδί χρησιμοποιείται και για την κρυπτογράφηση και για την αποκρυπτογράφηση των δεδομένων.
Για παράδειγμα

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### Τελεστής bitwise ολίσθησης δεξιά: ένας τρόπος να υποδιπλασιάσεις μια τιμή

Το `>>` είναι ο τελεστής bitwise για ολίσθηση δεξιά.
Συνήθως, για κάθε θέση που τα bit μιας τιμής μετατοπίζονται δεξιά, το αποτέλεσμα είναι η τιμή διαιρεμένη διά δύο.
Για παράδειγμα

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

Αν η τιμή του δεξιού τελεστέου είναι αρνητική ή μεγαλύτερη ή ίση με το πλάτος του αριστερού τελεστέου μετά την προαγωγή του, η συμπεριφορά είναι απροσδιόριστη.
Αυτό ισχύει και για τον τελεστή ολίσθησης αριστερά.
Όταν χρησιμοποιείται ένας προσημασμένος ακέραιος αντί για έναν ανυπόγραφο ακέραιο, τότε μπορεί να παίξει ρόλο και το πρόσημο.
Το παρακάτω παράδειγμα δείχνει τη συμπεριφορά σε ένα σύστημα όταν γίνεται ολίσθηση πολύ αριστερά ή δεξιά για έναν προσημασμένο ακέραιο.

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

Εφόσον η συμπεριφορά είναι απροσδιόριστη, ένα διαφορετικό σύστημα μπορεί να δώσει διαφορετικά αποτελέσματα.
Όταν κάνεις ολίσθηση bit, είναι σημαντικό να κατανοείς τα όρια του τύπου δεδομένων που χρησιμοποιείς.

## Πεδία bit

Έχουμε δει πώς τα bit που είναι συσκευασμένα σε έναν απλό τύπο δεδομένων μπορούν να προσπελαστούν με βάση τη θέση τους.
Τα bit που είναι συσκευασμένα σε μια `struct` μπορούν να προσπελαστούν με βάση το όνομά τους.
Ένας τέτοιος τύπος δεδομένων ονομάζεται `bit field`.
Μια περίπτωση χρήσης των `bit fields` μπορεί να είναι όταν χρειάζεται μια συλλογή σημαιών ON/OFF και επιθυμείται η ελαχιστοποίηση της χρήσης μνήμης.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Η σύνταξη `unsigned int variable_name : 1;` δημιουργεί ένα πεδίο `1` bit μέσα σε ένα `unsigned int` που βρίσκεται μέσα στη struct.
Αντί για `unsigned int`, θα μπορούσε να χρησιμοποιηθεί ένα `signed int` ή, από τη C99 και μετά, ένας τύπος `bool`.
Μια struct που περιέχει πεδία bit μπορεί να περιέχει και πεδία άλλων τύπων δεδομένων, όπως το `number_of_lights` στο παραπάνω παράδειγμα.
