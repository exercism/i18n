# Εισαγωγή

Στην Global Verification Authority, μόλις σου ανέθεσαν μια κρίσιμη αποστολή.
Σε όλη την πόλη, από online αγορές μέχρι ασφαλείς συνδέσεις, αμέτρητες λειτουργίες βασίζονται στην ακρίβεια αριθμητικών αναγνωριστικών όπως οι αριθμοί πιστωτικών καρτών, οι αριθμοί τραπεζικών λογαριασμών, οι κωδικοί συναλλαγών και τα αναγνωριστικά παρακολούθησης.
Ο αλγόριθμος Luhn είναι ένας απλός τύπος αθροίσματος ελέγχου που βοηθά στον εντοπισμό λανθασμένων αριθμών.

Μια παρτίδα αναγνωριστικών μόλις έφτασε στο γραφείο σου.
Όλα τους πρέπει να περάσουν τη δοκιμή Luhn για να διασφαλιστεί ότι είναι γνήσια.
Αν κάποιο αποτύχει, θα χαρακτηριστεί μη έγκυρο, αποτρέποντας λάθη όπως λανθασμένες συναλλαγές ή αποτυχημένες επαληθεύσεις λογαριασμών.

Μπορείς να διασφαλίσεις ότι αυτό θα γίνει σωστά; Η ακεραιότητα πολλών υπηρεσιών εξαρτάται από εσένα.
