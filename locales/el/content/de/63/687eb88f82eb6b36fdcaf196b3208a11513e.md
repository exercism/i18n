# Προσθήκη στις οδηγίες

## Παραγωγή ψευδοτυχαίων τιμών στη Lean

Στις συναρτησιακές γλώσσες, οι περισσότερες συναρτήσεις είναι _καθαρές_.
Αυτό σημαίνει ότι επιστρέφουν πάντα την ίδια έξοδο για το ίδιο σύνολο ορισμάτων και δεν κάνουν τίποτα άλλο.
Με άλλα λόγια, οι καθαρές συναρτήσεις είναι ντετερμινιστικές.

Ωστόσο, εξ ορισμού, μια τυχαία τιμή είναι απρόβλεπτη και μη ντετερμινιστική.
Ακόμη και η [ψευδοτυχαιότητα][pseudorandomness], δηλαδή η επιστροφή μιας ακολουθίας αριθμών που _μοιάζουν_ τυχαίοι, δεν είναι και τόσο εύκολο να επιτευχθεί σε ένα καθαρό πλαίσιο.
Αυτό συμβαίνει επειδή μια [γεννήτρια ψευδοτυχαίων αριθμών (PRNG)][PRNG] πρέπει να παρακολουθεί την εσωτερική της κατάσταση για να επιστρέψει τον επόμενο αριθμό της ακολουθίας.

Η Lean προσφέρει δύο πιθανές προσεγγίσεις σε αυτό το πρόβλημα:

1. Χρησιμοποίησε μια μονάδα που καθιστά δυνατή την αλλαγή της εσωτερικής κατάστασης μιας γεννήτριας ψευδοτυχαίων αριθμών.
Υπάρχει μια έτοιμη διαθέσιμη συνάρτηση, `IO.rand`, που κάνει ακριβώς αυτό.

2. Χρησιμοποίησε καθαρές συναρτήσεις που παίρνουν μια γεννήτρια ως όρισμα και επιστρέφουν όχι μόνο την ψευδοτυχαία τιμή που παράγεται, αλλά και μια ενημερωμένη γεννήτρια, "προετοιμασμένη" για τον επόμενο αριθμό της ακολουθίας.

Αυτή η άσκηση χρησιμοποιεί τη δεύτερη προσέγγιση.
Μια γεννήτρια περνιέται σε κάθε συνάρτηση που πρέπει να παράγει μια ψευδοτυχαία τιμή, και η συνάρτηση αναμένεται να επιστρέψει τόσο την τιμή όσο και μια ενημερωμένη γεννήτρια.

Σημείωσε ότι μια δεδομένη γεννήτρια είναι ντετερμινιστική, δηλαδή παράγει _πάντα_ την ίδια τιμή.
Για να παραγάγεις την επόμενη ψευδοτυχαία τιμή σε μια ακολουθία, είναι απαραίτητο να χρησιμοποιήσεις την ενημερωμένη γεννήτρια.

## Έλεγχος της τυχαιότητας

Σε αυτή την άσκηση, η τυχαιότητα ελέγχεται με έναν [έλεγχο χι-τετράγωνο][chi-squared-test] σε [επίπεδο σημαντικότητας][p-value] `p < 0.0001`.

Αυτό σημαίνει ότι αν μια βαθμολογία ικανότητας παραχθεί σύμφωνα με τις οδηγίες, υπάρχει λιγότερη από 0,01% πιθανότητα μια σωστή υλοποίηση να αποτύχει στο τεστ από καθαρή τύχη.

Σημείωσε ότι, σύμφωνα με τις οδηγίες, μια βαθμολογία ικανότητας είναι _το άθροισμα των τριών μεγαλύτερων αποτελεσμάτων από τέσσερις ρίψεις ενός αμερόληπτου d6 (ζαριού έξι πλευρών)_.
