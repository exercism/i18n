# Υποδείξεις

## Γενικά

- Χρησιμοποίησε τον ενσωματωμένο [(συνδεδεμένο) τύπο λίστας][list].

## 1. Όρισε μια συνάρτηση που να επιστρέφει μια κενή λίστα γλωσσών

- Η συνάρτηση πρέπει να επιστρέφει `[]`.

## 2. Όρισε μια συνάρτηση που να προσθέτει μια γλώσσα στη λίστα

- Ένα στοιχείο μπορεί να προστεθεί στην αρχή μιας λίστας χρησιμοποιώντας το `:`.

## 3. Όρισε μια συνάρτηση που να αφαιρεί μια γλώσσα από τη λίστα

- Η Haskell [παρέχει μια συνάρτηση][tail] που επιστρέφει μια λίστα με το πρώτο στοιχείο αφαιρεμένο.

## 4. Όρισε μια συνάρτηση που να επιστρέφει το πρώτο στοιχείο της λίστας

- HaskellHaskell [παρέχει μια συνάρτηση][head] για να πάρεις το πρώτο στοιχείο από μια λίστα.

## 5. Όρισε μια συνάρτηση που να επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

- Η Haskell [παρέχει μια συνάρτηση][length] για να μετρήσεις το μήκος μιας λίστας.

## 6. Όρισε μια συνάρτηση που να προσδιορίζει αν η λίστα περιέχει μια λειτουργική γλώσσα

- Η συνάρτηση σου πρέπει να επιστρέφει μια τιμή boolean που να δείχνει αν το `"Haskell"` είναι μέλος της λίστας. 
  Η Haskell [παρέχει μια συνάρτηση][elem] για να ελέγξεις αν ένα στοιχείο ανήκει στη λίστα.
