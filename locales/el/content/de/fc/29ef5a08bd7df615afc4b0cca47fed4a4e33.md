# Εισαγωγή

Η εκτύπωση στην Cairo σου επιτρέπει να εμφανίζεις μηνύματα ή πληροφορίες αποσφαλμάτωσης κατά την εκτέλεση του προγράμματος.

## Τα βασικά

Η Cairo παρέχει δύο macros για εκτύπωση:

- `println!`: Τυπώνει ένα μήνυμα ακολουθούμενο από αλλαγή γραμμής.
- `print!`: Τυπώνει ένα μήνυμα χωρίς αλλαγή γραμμής.

```rust
println!("Hello, Cairo!"); 
println!("x = {}, y = {}", 10, 20); 
```

Τα placeholders `{}` αντικαθίστανται από τις τιμές που παρέχεις.

## Μορφοποίηση συμβολοσειρών

Χρησιμοποίησε το `format!` για να δημιουργήσεις ένα `ByteArray` χωρίς να το εκτυπώσεις αμέσως:

```rust
let result = format!("{}-{}-{}", "tic", "tac", "toe");
println!("{}", result); // Output: tic-tac-toe
```

## Προσαρμοσμένοι τύποι δεδομένων

Για προσαρμοσμένους τύπους, υλοποίησε το `Display` ή κάνε derive το `Debug` για εκτύπωση:

```rust
#[derive(Debug)]
struct Point { x: u8, y: u8 }

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Debug output: Point { x: 3, y: 4 }
```

## Εκτύπωση δεκαεξαδικών

Χρησιμοποίησε το `{:x}` για να εκτυπώσεις ακέραιους σε δεκαεξαδική μορφή:

```rust
println!("{:x}", 255); // Output: ff
```
