# Εισαγωγή

Οι γενικεύσεις σου επιτρέπουν να γράφεις κώδικα που λειτουργεί με πολλαπλούς τύπους χωρίς να επαναλαμβάνεις τον ίδιο κώδικα. Ορίζεις γενικευμένους τύπους χρησιμοποιώντας γωνιακές αγκύλες `<T>`, όπου το `T` είναι ένα σύμβολο θέσης για οποιονδήποτε τύπο.

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Το Cairo απαιτεί όρια trait για να προσδιορίσεις ποιες πράξεις πρέπει να υποστηρίζει ο γενικευμένος τύπος. Μπορείς να προσθέσεις περιορισμούς χρησιμοποιώντας τη σύνταξη `+`:

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

Και οι δομές μπορούν να είναι γενικευμένες:

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

Και τα traits μπορούν να είναι γενικευμένα, επιτρέποντάς τους να λειτουργούν με διαφορετικούς τύπους:

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

Οι συναρτήσεις μπορούν να δέχονται γενικευμένες παραμέτρους με όρια trait, κάνοντάς τες να λειτουργούν με οποιονδήποτε τύπο που υλοποιεί το απαιτούμενο trait:

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
