# Σχετικά

Τα dicts στη Gleam είναι η δομή δεδομένων για την αποθήκευση πληροφοριών σε ζεύγη κλειδιού-τιμής. Σε άλλες γλώσσες, αυτά μπορεί να είναι γνωστά και ως associative arrays, hashes ή λεξικά.

Οποιοσδήποτε τύπος μπορεί να χρησιμοποιηθεί για τα κλειδιά και τις τιμές σε ένα dict, και τα dicts δεν εγγυώνται τη σειρά των καταχωρήσεών τους όταν γίνεται πρόσβαση σε αυτά ή όταν επιστρέφονται.

## Εργασία με dicts

Τα dicts δημιουργούνται και χειρίζονται με συναρτήσεις από το module `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
