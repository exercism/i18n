# Προσθήκη στις οδηγίες

## Ορισμός σύνταξης

Σε αυτή την άσκηση, πρέπει να ορίσεις σύνταξη για τα χρώματα χρησιμοποιώντας το πρόθεμα `c*`, π.χ. `c*black`.
Αυτή η σύνταξη πρέπει να επεκτείνεται σε χρόνο μεταγλώττισης στην αντίστοιχη τιμή κάθε χρώματος ως `Fin 10`, σύμφωνα με τις οδηγίες.
Με τον ίδιο τρόπο, πρέπει να ορίσεις σύνταξη για έναν πίνακα με όλες τις τιμές των χρωμάτων χρησιμοποιώντας το `c*all`.

Αυτή η εργασία πιθανότατα θα απαιτήσει να χρησιμοποιήσεις είτε σημειογραφίες είτε μακροεντολές.
Ίσως θελήσεις να συμβουλευτείς μια [αναφορά][macro-reference].

Επειδή η νέα σύνταξη επεκτείνεται σε χρόνο μεταγλώττισης, οποιοδήποτε test θα αποτύγχανε να μεταγλωττιστεί, εκτός αν οριστεί όλη η απαιτούμενη σύνταξη.
Για αυτόν τον λόγο, αντί να βασιζόμαστε σε παραδοσιακά tests εκτέλεσης, ελέγχουμε όλες τις τιμές με θεωρήματα.
Αν ένα θεώρημα περάσει τον έλεγχο τύπων, μπορείς να το θεωρήσεις επιτυχημένο test.

Αν δουλεύεις τοπικά ή στο [διαδικτυακό playground][playground] της Lean, θα παίρνεις άμεση ανατροφοδότηση, μέσω του Lean InfoView, για το αν κάποιο θεώρημα πετυχαίνει ή αποτυγχάνει και γιατί αποτυγχάνει.

[macro-reference]: https://lean-lang.org/doc/reference/latest/Notations-and-Macros/#language-extension
[playground]: https://live.lean-lang.org/
