# Εισαγωγή

Οι συναρτήσεις για τη διαχείριση εισόδου και εξόδου παρέχονται από τη μονάδα `IO`.

## Έξοδος

Για να γράψεις μια συμβολοσειρά στην τυπική έξοδο, χρησιμοποίησε την `IO.puts`. Η `IO.puts` προσθέτει πάντα μια νέα γραμμή στο τέλος της συμβολοσειράς. Αν δεν θέλεις αυτή τη συμπεριφορά, χρησιμοποίησε την `IO.write`. Και οι δύο συναρτήσεις επιστρέφουν το atom `:ok` αν πετύχουν.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

Η `IO.puts` είναι χρήσιμη για την εγγραφή συμβολοσειρών, αλλά όχι για πολλά άλλα. Αν χρειάζεσαι ένα εργαλείο για debugging που θα σου επιτρέπει να γράψεις οποιαδήποτε τιμή στην τυπική έξοδο, χρησιμοποίησε την `IO.inspect`. Η `IO.inspect` επιστρέφει την τιμή που της δόθηκε αναλλοίωτη, οπότε μπορείς να την τοποθετήσεις σε οποιοδήποτε σημείο του κώδικά σου. Δέχεται επίσης πολλές επιλογές, για παράδειγμα `:label`, που σου επιτρέπουν να την ξεχωρίζεις από άλλες κλήσεις της `IO.inspect`.

## Είσοδος

Για να διαβάσεις μια γραμμή από την τυπική είσοδο, χρησιμοποίησε την `IO.gets`. Η `IO.gets` δέχεται ένα όρισμα: μια συμβολοσειρά που θα εκτυπώσει ως προτροπή για την είσοδο. Η `IO.gets` δεν προσθέτει νέα γραμμή μετά την προτροπή, αν τη χρειάζεσαι πρόσθεσέ την μόνος σου.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
