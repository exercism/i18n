# Εισαγωγή

Η Haxe έχει δύο τύπους αριθμών, τους ακέραιους και τους αριθμούς κινητής υποδιαστολής:

- `Int`: Αναπαριστά έναν ακέραιο αριθμό.
- `Float`: Αναπαριστά έναν αριθμό κινητής υποδιαστολής διπλής ακρίβειας 64 bit.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Ενώ κάθε `Int` μπορεί να χρησιμοποιηθεί εκεί όπου αναμένεται ένα `Float` (δηλαδή ένα `Int` **μπορεί να ανατεθεί** σε ένα `Float` ή **ενοποιείται** μαζί του), το αντίστροφο δεν ισχύει: η ανάθεση ενός `Float` σε ένα `Int` μπορεί να προκαλέσει απώλεια ακρίβειας και γι' αυτό δεν επιτρέπεται έμμεσα.
