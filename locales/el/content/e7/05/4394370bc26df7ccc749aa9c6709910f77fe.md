# Εισαγωγή

Μια [λίστα][list] είναι μια τροποποιήσιμη συλλογή στοιχείων σε _σειρά_.
 Οι λίστες μπορούν να περιέχουν αναφορά σε οποιονδήποτε (ή πολλαπλούς) τύπο δεδομένων - συμπεριλαμβανομένων άλλων λιστών ή δομών δεδομένων όπως [πλειάδες][tuples], [σύνολα][sets] ή [λεξικά][dicts].
 Μπορείς να κάνεις επανάληψη πάνω στο περιεχόμενο χρησιμοποιώντας τη δομή `for item in <list>`.
 Αν χρειάζεσαι και τη θέση μαζί με το περιεχόμενο, μπορείς να χρησιμοποιήσεις το `for index, item in enumerate(<list>)`.
 Στα στοιχεία μιας `list` έχεις πρόσβαση μέσω αριθμού `0-based index` από τα αριστερά, ή αριθμού `-1-based index` από τα δεξιά.
 Οι λίστες μπορούν να αντιγραφούν ολόκληρες ή εν μέρει χρησιμοποιώντας _συμβολισμό τεμαχισμού_ ή `<list>.copy()`.
 Η Python παρέχει πολλές χρήσιμες και βολικές [μεθόδους][list-methods] για να δουλεύεις με λίστες.
