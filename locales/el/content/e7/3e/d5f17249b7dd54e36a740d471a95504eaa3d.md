# Οδηγίες

Δουλεύεις πάνω στην υλοποίηση ενός παιχνιδιού ρόλων.
Ο χαρακτήρας του παίκτη αναπαρίσταται από το εξής:

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

Οι παίκτες σε αυτό το παιχνίδι πρέπει να φτάσουν στο επίπεδο 10 για να ξεκλειδώσουν μια δεξαμενή mana, την οποία μπορούν να χρησιμοποιούν για να ρίχνουν ξόρκια.
Πριν από αυτό το σημείο, το mana του Player είναι `Option::None`.

Δουλεύεις πάνω σε δύο λειτουργίες αυτού του παιχνιδιού: τον μηχανισμό αναβίωσης και τον μηχανισμό ρίψης ξόρκιων.

Η μέθοδος `revive` πρέπει να ελέγχει ότι ο Player είναι πράγματι νεκρός (η υγεία του έχει φτάσει στο 0) και, αν είναι, η μέθοδος πρέπει να επιστρέφει ένα νέο στιγμιότυπο Player με 100 υγεία.
Η μέθοδος `revive` πρέπει να διατηρεί το επίπεδο του Player.
Αν το επίπεδο του Player είναι 10 ή παραπάνω, πρέπει να αναβιώνει με 100 mana.
Αν το επίπεδο του Player είναι κάτω από 10, το mana του πρέπει να είναι `Option::None`.

```rust
let dead_player = Player { health: 0, mana: Option::None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: Option::None, level: 2 }
```

Αν η μέθοδος `revive` κληθεί σε έναν Player του οποίου η υγεία είναι 1 ή παραπάνω, τότε η μέθοδος πρέπει να επιστρέψει `Option::None`.

```rust
let alive_player = Player { health: 1, mana: Option::Some(15), level: 11 };
alive_player.revive()
// Returns Option::None
```

Η μέθοδος `cast_spell` παίρνει μια μεταβλητή αναφορά στον Player καθώς και μια παράμετρο `mana_cost` που δείχνει πόσο mana κοστίζει το ξόρκι.
Επιστρέφει την ποσότητα της ζημιάς που προκαλεί το ξόρκι που ρίχνεται.

- Αν ο παίκτης δεν έχει πρόσβαση σε δεξαμενή mana, η προσπάθεια να ρίξει το ξόρκι πρέπει να μειώνει την υγεία του κατά το κόστος mana του ξόρκιου.
  Η ζημιά που επιστρέφεται πρέπει να είναι 0.

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: Option::None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, Option::None);
  ```

- Αν ο παίκτης έχει δεξαμενή mana αλλά ανεπαρκές mana, η μέθοδος δεν πρέπει να επηρεάζει τη δεξαμενή.
Η ζημιά που επιστρέφεται πρέπει να είναι 0.

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Option::Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Option::Some(3));
  ```

- Διαφορετικά, το ξόρκι ρίχνεται με επιτυχία.
  Το `mana_cost` πρέπει να αφαιρείται από τη δεξαμενή mana του Player.
  Η ζημιά που επιστρέφεται πρέπει να είναι διπλάσια από το κόστος mana του ξόρκιου.

  ```rust
  let wizard = Player { health: 123, mana: Option::Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Option::Some(20));
  ```

Καλή διασκέδαση!
