# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο ακόμα κώδικα για να σε βοηθήσει να μαγειρέψεις τα υπέροχα λαζάνια σου από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Επίτρεψε την αλλαγή του αναμενόμενου χρόνου ψησίματος

Θέλεις να γράψεις μια βελτιωμένη συνάρτηση `remainingMinutesInOven` που παίρνει ως παράμετρο τον αριθμό των λεπτών που τα λαζάνια βρίσκονται στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.
Προηγουμένως, είχες βασιστεί σε μια σταθερή τιμή, το `expectedMinutesInOven`, που ερχόταν από έξω από τη συνάρτηση `remainingMinutesInOven`.
Αυτό ήταν και λίγο πιο φορτωμένο απ' όσο σου άρεσε και όχι αρκετά ευέλικτο, αφού δε σου επιτρέπει να αλλάξεις τον αναμενόμενο χρόνο στον φούρνο.

Για να τακτοποιήσεις τα πράγματα, όρισε τη συνάρτηση `remainingMinutesInOven` που παίρνει ως παράμετρο τον αριθμό των λεπτών που τα λαζάνια βρίσκονται στον φούρνο, καθώς και μια παράμετρο `expectedMinutesInOven` που έχει προεπιλεγμένη τιμή 40.
Η συνάρτησή σου πρέπει να επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Επίτρεψε διαφορετικούς αριθμούς στρώσεων

Είχες προηγουμένως γράψει μια συνάρτηση `preparationTimeInMinutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά πέρασες προετοιμάζοντας τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να προετοιμαστεί.
Ωστόσο, δεν είσαι ιδιαίτερα ευχαριστημένος με αυτή τη συνάρτηση, αφού πρέπει να μετρήσεις μόνος σου τον αριθμό των στρώσεων στα λαζάνια σου πριν καλέσεις αυτή τη συνάρτηση, και ποιος έχει χρόνο για όλα αυτά;

Για να κάνεις τα πράγματα πιο εύκολα για τον εαυτό σου, γράψε μια συνάρτηση, `preparationTimeInMinutes`, που παίρνει μια variadic παράμετρο `String` με το όνομα `layers`, όπου παραθέτεις τις διαφορετικές στρώσεις των λαζανιών σου.
Η συνάρτηση θα μετρήσει τότε τον αριθμό των στρώσεων στα λαζάνια σου και θα επιστρέψει τον χρόνο προετοιμασίας που απαιτείται.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Υπολόγισε ποσότητες νουντλς και σάλτσας

Πριν αρχίσεις να συναρμολογείς τα λαζάνια σου, θέλεις να βεβαιωθείς ότι έχεις αρκετή σάλτσα και νουντλς για να φτιάξεις τα λαζάνια των ονείρων σου.
Για κάθε στρώση νουντλς στα λαζάνια σου, θα χρειαστείς 3 νουντλς.
Για κάθε στρώση σάλτσας στα λαζάνια σου, θα χρειαστείς 0,2 λίτρα σάλτσας.

Όρισε τη συνάρτηση `quantities` που παίρνει μια variadic παράμετρο `String` με το όνομα `layers`, όπου παραθέτεις τις διαφορετικές στρώσεις των λαζανιών σου.
Η συνάρτηση θα προσδιορίσει τότε την ποσότητα νουντλς και σάλτσας που χρειάζεται για το γεύμα σου. Το αποτέλεσμα πρέπει να επιστρέφεται σε μια πλειάδα τύπου `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Μετέτρεψε τα λίτρα σε ουγγιές υγρού επιτόπου

Δυστυχώς, ο όγκος της σάλτσας που έχεις πρόχειρη αναγράφεται σε ουγγιές υγρού αντί για λίτρα.
Για να σε βοηθήσει να καταλάβεις αν έχεις αρκετή σάλτσα πρόχειρη, γράψε μια συνάρτηση, `toOz`, που παίρνει μια in-out παράμετρο πλειάδας, `(noodles: Int, sauce: Double)`, και μετατρέπει την ποσότητα της σάλτσας σε ουγγιές υγρού.
Σημείωσε ότι υπάρχουν 33,814 ουγγιές υγρού ανά λίτρο.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Προσδιόρισε το καλύτερο κρασί για σερβίρισμα

Τέλος, θέλεις να μάθεις τι είδος κρασιού να σερβίρεις με τα λαζάνια σου.
Έχεις ακούσει ότι πρέπει να σερβίρεις λευκό κρασί αν τα λαζάνια έχουν περισσότερη μοτσαρέλα, ρικότα και μπεσαμέλ απ' ό,τι κρέας και σάλτσα, και κόκκινο κρασί σε αντίθετη περίπτωση.
Γράψε μια συνάρτηση `redWine` που παίρνει μια variadic παράμετρο `String` με το όνομα `layers`, όπου παραθέτεις τις διαφορετικές στρώσεις των λαζανιών σου.
Η συνάρτηση θα χρησιμοποιήσει πέντε εμφωλευμένες συναρτήσεις για να προσδιορίσει τον αριθμό των στρώσεων μοτσαρέλας, ρικότας, μπεσαμέλ, σάλτσας και κρέατος στα λαζάνια, και θα συγκρίνει τους αριθμούς των στρώσεων για να προσδιορίσει αν πρέπει να σερβιριστεί κόκκινο κρασί, επιστρέφοντας `true` αν ναι και `false` αν όχι.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
