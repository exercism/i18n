# Προσθήκη οδηγιών

## Δεσμευμένη μνήμη

Το buffer για τη συμβολοσειρά εισόδου χρησιμοποιεί τα byte 64-191 της γραμμικής μνήμης.

## Πίνακες

Η WebAssembly δεν έχει την έννοια των πινάκων.
Για το test των χρωμάτων, επέστρεψε ένα buffer χαρακτήρων χωρισμένων με κόμμα, στη μορφή: `black,brown,red,orange,yellow,green,blue,violet,grey,white`

Στη συνέχεια θα πρέπει να δημιουργήσεις εσωτερικά έναν πίνακα από δομές, χρησιμοποιώντας μετατοπίσεις και μήκη, ώστε να δώσεις δομή σε αυτό το buffer.
