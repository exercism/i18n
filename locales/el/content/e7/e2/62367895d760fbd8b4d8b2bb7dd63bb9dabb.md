# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις ένα μερικό σύνολο από βοηθητικές ρουτίνες που βοηθούν έναν προγραμματιστή να καθαρίσει ονόματα αναγνωριστικών.

Στις 4 εργασίες θα χτίσεις σταδιακά τη ρουτίνα `clean`. Ένα έγκυρο αναγνωριστικό αποτελείται από μηδέν ή περισσότερα γράμματα και κάτω παύλες.

Σε όλες τις περιπτώσεις η συμβολοσειρά εισόδου είναι εγγυημένα μη-nil. Αν περαστεί μια κενή συμβολοσειρά στη συνάρτηση `clean`, θα πρέπει να επιστραφεί μια κενή συμβολοσειρά.

Σημείωσε ότι αυτός που καλεί θα πρέπει να αποφεύγει να καλεί τη ρουτίνα `clean` με κενό αναγνωριστικό, αφού τέτοια αναγνωριστικά είναι άχρηστα.

## 1. Αντικατέστησε όποια κενά συναντήσεις με κάτω παύλες

Υλοποίησε τη συνάρτηση `clean` ώστε να αντικαθιστά όποια κενά με κάτω παύλες. Αυτό ισχύει και για κενά στην αρχή και στο τέλος.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. Αντικατέστησε τους χαρακτήρες ελέγχου με τη συμβολοσειρά κεφαλαίων "CTRL"

Τροποποίησε τη συνάρτηση `clean` ώστε να αντικαθιστά τους χαρακτήρες ελέγχου με τη συμβολοσειρά κεφαλαίων `"CTRL"`.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. Μετέτρεψε το kebab-case σε camelCase

Τροποποίησε τη συνάρτηση `clean` ώστε να μετατρέπει το kebab-case σε camelCase.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. Παράλειψε τα ελληνικά πεζά γράμματα

Τροποποίησε τη συνάρτηση `clean` ώστε να παραλείπει όποια ελληνικά γράμματα στο εύρος από 'α' έως 'ω'.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
