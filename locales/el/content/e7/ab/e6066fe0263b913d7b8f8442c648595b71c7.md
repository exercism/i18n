# Προσθήκη στις οδηγίες

## Υποδείξεις

Για να περάσει το test, θα χρειαστεί να δημιουργήσεις κάποιους τύπους πάνω στους οποίους θα δουλέψει ο κώδικάς σου: χρειάζεσαι ένα αντικείμενο για το `School` που θα κρατά μια ακολουθία από `Student`, όπου το `Student` θα είναι μια πλειάδα από `string` και `int` που θα κρατά το όνομα και τον βαθμό των μαθητών.

Ορίστε λίγος κώδικας για τους τύπους που μπορεί να σου φανεί χρήσιμος για να ξεκινήσεις

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
