# καμία εξαγωγή με όνομα

Δεν βρέθηκε καμία [εξαγωγή](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) με το όνομα `%{export.name}`. Τα tests δεν θα περάσουν χωρίς αυτή.

Βεβαιώσου ότι υπάρχει μια εξαγωγή με το όνομα `%{export.name}` και πρόσθεσε το `export` μπροστά της:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
