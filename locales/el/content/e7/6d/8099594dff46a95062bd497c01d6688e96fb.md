# Εισαγωγή

## Αντιστοίχιση προτύπων με κυριολεκτικές τιμές

Ενώ οι εκφράσεις `if/else` μπορούν να χρησιμοποιηθούν για να εκτελέσουν λογική υπό συνθήκη, η Haskell έχει επίσης έναν πιο ισχυρό τρόπο να εκτελεί λογική υπό συνθήκη: την [αντιστοίχιση προτύπων][pattern-matching].
Με την αντιστοίχιση προτύπων, μια τιμή μπορεί να ελεγχθεί ως προς ένα ή περισσότερα _πρότυπα_.
Ένα παράδειγμα τέτοιου προτύπου είναι το _πρότυπο σταθεράς_, το οποίο αντιστοιχίζει μια τιμή με μια σταθερά (π.χ. `1` ή `"hello"`).

Όταν ορίζεις συναρτήσεις, μπορείς να ορίσεις ξεχωριστά σώματα συνάρτησης για διαφορετικά πρότυπα.
Αυτό οδηγεί σε καθαρό κώδικα που είναι απλός και ευανάγνωστος.
Μπορείς να κάνεις αντιστοίχιση προτύπων σε οποιονδήποτε τύπο δεδομένων: αριθμούς, χαρακτήρες, λίστες, πλειάδες, κ.λπ.

Για παράδειγμα, μια απλή συνάρτηση που παίρνει έναν ακέραιο αριθμό (`Int`) και τον φέρνει _1_ πιο κοντά στο _0_ θα μπορούσε να εκφραστεί έτσι:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Η αντιστοίχιση προτύπων αρχίζει να δείχνει την αξία της όταν χρησιμοποιείται μαζί με άλλα πρότυπα, για παράδειγμα το _πρότυπο μεταβλητής_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

Το παραπάνω παράδειγμα αντιμετωπίζει όλες τις εισόδους εκτός από το _0_ με τον ίδιο τρόπο και θα παρήγαγε λανθασμένα αποτελέσματα για αρνητικούς αριθμούς.
Αυτό μπορεί να λυθεί χρησιμοποιώντας πρότυπα με συνθήκες, γνωστά ως _φρουροί_, τα οποία εκφράζονται με το σύμβολο `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Στα παραπάνω παραδείγματα, δεν υπάρχει πρότυπο που να αντιστοιχίζεται σε όλες τις πιθανές εισόδους.
Ο μεταγλωττιστής θα το εντοπίσει και θα εμφανίσει μια προειδοποίηση.
Αυτό είναι ένα πολύ χρήσιμο χαρακτηριστικό της Haskell που βοηθά να διασφαλιστεί ότι καλύπτονται όλες οι πιθανές διαδρομές, ώστε να αποφεύγονται σφάλματα χρόνου εκτέλεσης.
Είναι γνωστό ως _εξαντλητικός έλεγχος_.
Για να λύσεις την προειδοποίηση, πρέπει να χειριστείς όλες τις περιπτώσεις.
Μέσα στους _φρουρούς_ μπορείς να χρησιμοποιήσεις την έκφραση `otherwise` ως συντακτική ζάχαρη για το `True`, ώστε να καλύψεις όλα τα υπόλοιπα πρότυπα.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Η αντιστοίχιση προτύπων θα ελέγξει μια τιμή ως προς κάθε πρότυπο από πάνω προς τα κάτω, μέχρι να βρει ένα πρότυπο που αντιστοιχίζεται και να εκτελέσει τη λογική που σχετίζεται με αυτό το πρότυπο.
**Η σειρά των προτύπων έχει σημασία!**
