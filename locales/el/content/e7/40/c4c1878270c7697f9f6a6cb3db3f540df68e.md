# Συναρτήσεις στη `jq`

Μπορείς να ορίσεις τις δικές σου **προσαρμοσμένες συναρτήσεις** στη `jq` για να ενθυλακώσεις όποια λογική χρειάζεσαι.
Οι _συναρτήσεις_ συμπεριφέρονται ακριβώς όπως οι ενσωματωμένες: παίρνουν μια είσοδο και παράγουν μηδέν, μία ή περισσότερες εξόδους.

## Ορισμός μιας συνάρτησης

Μπορείς να ορίσεις μια _συνάρτηση_ της `jq` με την εξής σύνταξη:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- ξεκινά με τη λέξη-κλειδί `def`,
- μια άνω και κάτω τελεία πριν από το σώμα της συνάρτησης,
- το σώμα αποτελείται από μία μόνο έκφραση,
- τελειώνει με άνω τελεία,
- όπως και στην υπόλοιπη σύνταξη της `jq`, μπορείς να χρησιμοποιείς όποια κενά θέλεις για ευαναγνωσιμότητα.

## Πού να βάζεις τις συναρτήσεις

Οι _συναρτήσεις_ πρέπει να ορίζονται πριν χρησιμοποιηθούν: αυτό είναι σφάλμα:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

Αυτό σημαίνει ότι πρέπει να βάζεις τις _συναρτήσεις_ στην αρχή του κώδικα `jq`, πριν από την "κύρια" έκφραση.

### Εμφωλευμένες συναρτήσεις

Οι _συναρτήσεις_ μπορούν να είναι εμφωλευμένες:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

Εδώ, η _συνάρτηση_ `B` είναι ορατή μόνο στο σώμα της `A`.

## Εμβέλεια

Μια _συνάρτηση_ εισάγει μια νέα **εμβέλεια** για μεταβλητές και εμφωλευμένες συναρτήσεις.

## Ορίσματα

Τα **ορίσματα** μιας _συνάρτησης_ χωρίζονται με _άνω τελείες_ και όχι με κόμματα.
Για παράδειγμα, μια _συνάρτηση_ που παίρνει έναν αριθμό και μετά προσθέτει έναν αριθμό και πολλαπλασιάζει με έναν αριθμό:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

<!-- prettier-ignore -->
~~~~exercism/note
Οι άνω τελείες χρειάζονται επειδή το κόμμα έχει ήδη έναν σκοπό στη `jq`: είναι τελεστής που ενώνει ροές.

Αν χρησιμοποιήσεις κόμμα αντί για άνω τελεία, θα προσπαθήσει να κάνει δύο κλήσεις σε μια συνάρτηση `add_mul` _με 1 όρισμα_, η οποία δεν υπάρχει και επομένως θα αποτύχει στην πρώτη απόπειρα κλήσης:

```jq
10 | add_mul(5, 4)
# error: add_mul/1 is not defined
```

Το κόμμα στο `5, 4` συνενώνει τους αριθμούς 5 και 4 σε μια ροή. 
Όταν καλούμε μια συνάρτηση με μια ροή ως όρισμα, η `jq` θα καλέσει αυτή τη συνάρτηση πολλές φορές, μία για κάθε τιμή της ροής. 
Αυτό είναι ένα παράδειγμα της "έμμεσης επανάληψης" που είναι εγγενής στις ροές της `jq`.
Το `10 | add_mul(5, 4)` είναι ισοδύναμο με το παρακάτω.

```jq
(10 | add_mul(5)), (10 | add_mul(4))
```
Τώρα μπορούμε να δούμε πώς εμφανίζεται το σφάλμα `add_mul/1 is not defined`.
~~~~

### Τα ορίσματα είναι _εκφράσεις_

Τα _ορίσματα_ μιας συνάρτησης είναι φίλτρα, όχι τιμές.
Με αυτή την έννοια, συμπεριφέρονται σαν αυτό που άλλες γλώσσες περιγράφουν ως callbacks:

Χρησιμοποιώντας ως παράδειγμα τη συνάρτηση `add_mul`:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

Τι συμβαίνει εδώ;

- το όρισμα `adder` παίρνει την _έκφραση_ `. + 5`
  - όταν η συνάρτηση κάνει `. + adder`, αυτό γίνεται `. + . + 5`
  - αυτό υπολογίζεται σε 25 αφού `. == 10`
- παρομοίως, το όρισμα `multiplier` είναι η έκφραση `. - 2`
  - αυτό υπολογίζεται σε 8
  - τότε το αποτέλεσμα είναι `25 * 8 == 200`

### Τα ορίσματα ως τιμές

Μερικές φορές θα θέλεις να "μετατρέψεις" ένα _όρισμα_ σε μεταβλητή:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

Υπάρχει ένας συντομευμένος τρόπος γι' αυτό:

```jq
def my_func($arg):
    other stuff ...
;
```

Σημείωσε ότι αυτό είναι απλώς "συντακτική ζάχαρη": το όνομα `arg` χωρίς `$` παραμένει στο πεδίο εμβέλειας της _συνάρτησης_.

<!-- prettier-ignore -->
~~~~exercism/caution
Για παράδειγμα, έγραψα κάτι σαν αυτό για να λύσω μια άσκηση:

```jq
# function that encodes the input value
def code:
    # expression here
    ;

def equals($code):
    (. | code) as $this_code
    | $code == $this_code
    ;

("some key value" | code) as $key
| ["array", "of", "values"]
| map(select(equals($key)))
```

και ξαφνιάστηκα που κάθε τιμή του πίνακα ήταν ίση με το κλειδί.

Αυτό συνέβη επειδή η jq έβλεπε τη συνάρτηση `equals` ως

```jq
def equals(code):
    code as $code
    | (. | code) as $this_code
    | $code == $this_code
    ;
```

Το **όρισμα** `code` υπερκάλυψε τη **συνάρτηση** `code` που είχε οριστεί προηγουμένως.
Αυτό σήμαινε ότι το `(. | code)` απλώς παράγει το **όρισμα** αντί να υπολογίζει έναν νέο κωδικό με βάση την τιμή εισόδου.
Έτσι, τα `$this_code` και `$code` ήταν πάντα τα ίδια.
~~~~

<!-- prettier-ignore-end -->

## Arity

Οι _συναρτήσεις_ έχουν ένα **arity**, δηλαδή τον αριθμό των _ορισμάτων_ που δέχονται.

Οι _συναρτήσεις_ μπορούν να χρησιμοποιούν το ίδιο όνομα με διαφορετικό **arity**.
Η ενσωματωμένη συνάρτηση [`range`][man-range] το δείχνει αυτό: τα `range/1`, `range/2` και `range/3` συνυπάρχουν.

Αυτό μπορεί να φανεί χρήσιμο για τον ορισμό αναδρομικών συναρτήσεων που μεταφέρουν κατάσταση μέσω ορισμάτων.
Για παράδειγμα, η `map` _θα μπορούσε_ να υλοποιηθεί ως εξής:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## Αναδρομή

Η `jq` εκτελεί βελτιστοποίηση ουράς, αλλά μόνο για συναρτήσεις με arity 0.

## Modules

Ένα module της `jq` είναι ένα αρχείο που περιέχει μόνο συναρτήσεις.
Τα modules συμπεριλαμβάνονται σε ένα πρόγραμμα jq με τις εντολές [`include`][man-include] ή [`import`][man-import].

[man-range]: https://jqlang.org/manual/#range
[man-import]: https://jqlang.org/manual/#import-relativepathstring-as-name
