# Exercism CLI

Το [Exercism CLI][cli] επιτρέπει στους μαθητές να κατεβάζουν ασκήσεις και να υποβάλλουν λύσεις στον ιστότοπο. Υποστηρίζει επίσης την εντολή `exercism test`, η οποία με τη σειρά της εκτελεί την εντολή του track για να τρέξουν τα tests.

## Προσθήκη νέας γλώσσας

Οι εντολές tests για κάθε track ορίζονται σε ένα [αρχείο ρυθμίσεων][test-configurations]. Μπορείς να προσθέσεις υποστήριξη για τη γλώσσα σου προσθέτοντας μια καταχώριση σε αυτό το [αρχείο ρυθμίσεων][test-configurations], όπου το κλειδί είναι το slug του track.

### Placeholders στις εντολές tests

Υπάρχουν τρία placeholders που μπορούν να χρησιμοποιηθούν στην εντολή για κάθε track:

- `{{test_files}}`: μια λίστα με τα αρχεία tests χωρισμένα με κενό (όπως τη βρίσκεις στο κλειδί `.files.test` στο αρχείο `.meta/config.json` της άσκησης)
- `{{solution_files}}`: μια λίστα με τα αρχεία της λύσης χωρισμένα με κενό (όπως τη βρίσκεις στο κλειδί `.files.solution` στο αρχείο `.meta/config.json` της άσκησης)
- `{{slug}}`: το slug της άσκησης (όπως το βρίσκεις στο κλειδί `slug` της άσκησης στο ριζικό αρχείο `config.json` του track)

Ορίστε ένα [παράδειγμα pull request][example-pr] που προσθέτει υποστήριξη για τη γλώσσα Arturo.
