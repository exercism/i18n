# Υποδείξεις

## Γενικά

Αυτή η άσκηση έχει πολλές πιθανές λύσεις και πολλά μονοπάτια που μπορείς να ακολουθήσεις στην πορεία.
Κανένα μονοπάτι δεν είναι προφανώς "καλύτερο" από κάποιο άλλο, αν και ένα συγκεκριμένο μονοπάτι μπορεί να είναι πιο ενδιαφέρον ή πιο κατάλληλο για αυτό που θέλεις να μάθεις ή να εξερευνήσεις τώρα.
Κάποια μονοπάτια μπορεί να ανταλλάσσουν ταχύτητα με σαφήνεια, άλλα μπορεί να καταναλώνουν περισσότερη μνήμη αλλά να είναι πιο επεκτάσιμα ή πιο εύκολα στη συντήρηση.
Σε ενθαρρύνουμε να δοκιμάσεις περισσότερες από μία στρατηγικές για να δεις τι θα συμβεί.

_______
-  Η Python έχει ένα ισχυρό σύνολο εργαλείων για να δουλεύεις με συμβολοσειρές. Τα [`str.split`][str.split], [`str.replace`][str.replace], [`str.lower`][str.lower] και [`str.strip`][str.strip] μπορούν να φανούν ιδιαίτερα χρήσιμα σε αυτή την άσκηση.
-  Οι μέθοδοι συμβολοσειρών μπορούν να αλυσιδωθούν μεταξύ τους (_αρκεί η μέθοδος να επιστρέφει `str`_))
-  Ενώ η `str.split()` είναι πολύ _συγκεκριμένη_, η `str.strip()` συμπεριφέρεται διαφορετικά και επιτρέπει πολλούς συνδυασμούς.
-  Το module [`string`][string] (σε αντίθεση με τη `str`) έχει κάποιες σταθερές που μπορούν να φανούν χρήσιμες για φιλτράρισμα και σύγκριση όταν επεξεργάζεσαι συμβολοσειρές.
________

-  Τα [λεξικά][dict] μπορούν να φανούν χρήσιμα για την καταμέτρηση του πότε τα στοιχεία (κλειδιά) εμφανίζονται περισσότερες από μία φορές σε μια συμβολοσειρά.
-  Το [`dict.setdefault()`][dict.setdefault] μπορεί να βοηθήσει στην επεξεργασία όταν ένα κλειδί μπορεί να λείπει από ένα λεξικό.
-  Το module [Collections][collections] υλοποιεί κάποιους πραγματικά χρήσιμους υποτύπους του βασικού `dict` (λεξικού), σχεδιασμένους ειδικά για πράγματα όπως η [καταμέτρηση][collections.counter].
________
-  Η εξερεύνηση του module [`re`][re] και των κανονικών εκφράσεων μπορεί να είναι διασκεδαστική, αλλά δεν είναι σε καμία περίπτωση απαραίτητη για να λύσεις αυτή την άσκηση.
-  Το [Regex101][regex101] είναι πολύ χρήσιμο για να πειραματιστείς με τη λογική των κανονικών εκφράσεων.
-  Τόσο το [`re.sub`][re.sub] όσο και το [`re.findall`][re.findall] μπορούν να είναι ενδιαφέρουσες στρατηγικές που μπορείς να χρησιμοποιήσεις.
________
-  Τα [comprehensions][comprehensions] μπορούν συχνά να "ισιώσουν" βρόχους όπου προστίθενται στοιχεία σε μια λίστα ή εισάγονται σε ένα λεξικό.
-  Οι [εκφράσεις γεννητριών][generator expressions] μπορούν συχνά να σταθούν στη θέση μιας list comprehension όταν χρειάζεται ένα iterable.
  Οι εκφράσεις γεννητριών αξιολογούνται με "τεμπέλικο" τρόπο και καταλαμβάνουν λιγότερο χώρο στη μνήμη από μια αντίστοιχη list comprehension.
