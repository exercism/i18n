# Εισαγωγή

Υπάρχουν τρεις βασικές εντολές υπό συνθήκη στη Julia:

- Παραστάσεις `if`
- Ο τριαδικός τελεστής
- Η αξιολόγηση βραχυκυκλώματος

## Παραστάσεις `if`

Οι παραστάσεις `if` στη Julia είναι παρόμοιες με αυτές που συναντάς σε άλλες γλώσσες:

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

Αν η παράσταση Boolean (λογική τιμή) που ακολουθεί το `if` αξιολογείται σε `true`, εκτελείται το πρώτο μπλοκ κώδικα και το δεύτερο παραλείπεται.
Αν η παράσταση Boolean που ακολουθεί το `if` αξιολογείται σε `false`, το πρώτο μπλοκ κώδικα παραλείπεται και εκτελείται το δεύτερο.
Το πρόγραμμα συνεχίζει την εκτέλεσή του από την πρώτη γραμμή κώδικα μετά τη λέξη-κλειδί `end`.

~~~~exercism/note
Στη Julia, η λέξη-κλειδί `end` σηματοδοτεί το τέλος όλων των παραστάσεων μπλοκ.
Αυτή η σύνταξη δεν είναι ειδική για τις παραστάσεις `if` ή για τους ορισμούς συναρτήσεων.
~~~~

Σε περιπτώσεις όπου το δεύτερο μπλοκ κώδικα θα ήταν απλώς άλλη μια παράσταση `if`, το `elseif` μάς επιτρέπει να αποφύγουμε την εμφώλευση παραστάσεων `if` μέσα στο μπλοκ:

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

Αν μια παράσταση `if` χρειάζεται να εκτελέσει κώδικα μόνο για μία από τις περιπτώσεις, δεν χρειάζεται να γράψεις τον κλάδο `else`.

## Τριαδικός τελεστής

Οι απλές εντολές `if-else` μπορούν να γραφτούν και με τον τριαδικό τελεστή `a ? b : c`.
Αν το `a` είναι αληθές, τότε θα αξιολογηθεί το `b`.
Διαφορετικά, αξιολογείται το `c`.

Για παράδειγμα, η παρακάτω συνάρτηση

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

μπορεί να γραφτεί και ως

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

Αυτό είναι ιδιαίτερα χρήσιμο όταν θέλεις να εκχωρήσεις διαφορετική τιμή σε μια μεταβλητή ανάλογα με μια συνθήκη.
Το `x = a ? b : c` θα εκχωρήσει το `b` στο `x` αν το `a` είναι `true` και διαφορετικά θα εκχωρήσει το `c` στο `x`.
Για παράδειγμα:

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## Αξιολόγηση βραχυκυκλώματος

Αν πολλές παραστάσεις Boolean συνδεθούν μεταξύ τους με τους τελεστές `&&` και `||`, η Julia θα αξιολογήσει μόνο τον ελάχιστο αριθμό παραστάσεων που είναι απαραίτητος για να προσδιοριστεί η τιμή ολόκληρης της αλυσίδας.

Για παράδειγμα, θεώρησε την αλυσίδα παραστάσεων `n > 0 && k > 10`.
Αν το `n` ισούται με `5`, το πρώτο μέρος της αλυσίδας, `n > 0`, είναι `true` και είναι απαραίτητο να αξιολογηθεί η δεύτερη παράσταση `k > 10` για να προσδιοριστεί αν ολόκληρη η παράσταση είναι `true`.
Ωστόσο, αν το `n` ισούται με `-5`, γνωρίζουμε ότι η αλυσίδα στο σύνολό της **δεν μπορεί** να είναι `true`, επειδή η πρώτη της παράσταση είναι `false`.

Αν αντίθετα εξετάσουμε το `n > 0 || k > 10`, συμβαίνει το αντίθετο.
Αν το `n` ισούται με `5`, το πρώτο μέρος της αλυσίδας, `n > 0`, είναι `true` και γνωρίζουμε ότι ολόκληρη η αλυσίδα θα είναι `true` ανεξάρτητα από τη δεύτερη παράσταση.
Ωστόσο, αν το `n` ισούται με `-5`, είναι απαραίτητο να αξιολογηθεί η δεύτερη παράσταση.

Αυτή η συμπεριφορά μπορεί να χρησιμοποιηθεί για να γράψεις πολύ σύντομες εντολές `if`:

```julia
if a
    b
end
```

είναι ισοδύναμο με

```julia
a && b
```

Η τελευταία παράσταση σε μια αλυσίδα `&&` και `||` δεν χρειάζεται να είναι παράσταση Boolean.
Θα συναντήσεις συχνά αυτή τη δυνατότητα να χρησιμοποιείται για πρόωρα σφάλματα ή επιστροφές.
Για παράδειγμα, χρησιμοποιώντας τη συνάρτηση `dessert(fruit)` από πάνω:

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
