# Σχετικά

Το χαρακτηριστικό Flags επιτρέπει στις τιμές που ορίζονται σε μια ένωση με διάκριση να αναπαρασταθούν ως θέσεις bit (δηλαδή σημαίες).
Ως σημαίες, τέτοιες τιμές μπορούν να συνδυαστούν, γεγονός που καθιστά δυνατό να αναπαρασταθούν πολλαπλές Boolean συνθήκες σε μία μόνο τιμή.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Μπορείς να θέσεις μια σημαία με τον τελεστή bitwise OR (`|||`), ενώ μπορείς να απενεργοποιήσεις μια σημαία με συνδυασμό του τελεστή bitwise AND (`&&&`) και του τελεστή άρνησης bitwise (`~~~`).
Ενώ ο έλεγχος της κατάστασης μιας σημαίας μπορεί να γίνει με τον τελεστή bitwise AND, μπορείς επίσης να χρησιμοποιήσεις τη μέθοδο HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Δες τη [Σύνοψη των bitwise τελεστών][bitwise-operators] για μια πλήρη λίστα με τους bitwise τελεστές που διαθέτει η γλώσσα F#.
