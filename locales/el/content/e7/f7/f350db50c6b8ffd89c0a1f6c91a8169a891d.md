# Υποδείξεις

## 1. Καθόρισε αν θα χρειαστείς άδεια οδήγησης

- Χρησιμοποίησε τον [τελεστή σύγκρισης ισότητας][comparison-operators] για να ελέγξεις αν η είσοδός σου είναι ίση με μια συγκεκριμένη συμβολοσειρά.
- Χρησιμοποίησε έναν από τους δύο [λογικούς τελεστές][logical-operators] που έμαθες στην έννοια Boolean για να συνδυάσεις τις δύο απαιτήσεις.
- **Δεν** χρειάζεσαι εντολή if για να λύσεις αυτή την εργασία.
  Μπορείς να επιστρέψεις απευθείας τη λογική έκφραση που θα φτιάξεις.

## 2. Διάλεξε ανάμεσα σε δύο πιθανά οχήματα για αγορά

- Χρησιμοποίησε έναν [τελεστή σύγκρισης][comparison-operators] για να καθορίσεις ποια επιλογή έρχεται πρώτη στη λεξικογραφική σειρά.
- Έπειτα, όρισε την τιμή μιας βοηθητικής μεταβλητής ανάλογα με το αποτέλεσμα αυτής της σύγκρισης, με τη βοήθεια μιας [εντολής if-else][if-statement].
- Τέλος, σχημάτισε την πρόταση σύστασης.
  Γι' αυτό μπορείς να χρησιμοποιήσεις τον τελεστή `+` για να συνενώσεις τις δύο συμβολοσειρές.

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

- Ξεκίνα καθορίζοντας το ποσοστό της αρχικής τιμής με βάση την ηλικία του οχήματος.
  Αποθήκευσέ το σε μια βοηθητική μεταβλητή.
  Χρησιμοποίησε μια [εντολή if-else if-else][if-statement], όπως αναφέρεται στις οδηγίες.
- Στις δύο συνθήκες if χρησιμοποίησε [τελεστές σύγκρισης][comparison-operators] για να συγκρίνεις την ηλικία του αυτοκινήτου με τις οριακές τιμές.
- Για να υπολογίσεις το αποτέλεσμα, εφάρμοσε το ποσοστό στην αρχική τιμή.
  Για παράδειγμα, το `30% of x` μπορεί να υπολογιστεί διαιρώντας το `30` με το `100` και πολλαπλασιάζοντας με το `x`.

[comparison-operators]: https://golang.org/ref/spec#Comparison_operators
[logical-operators]: https://golang.org/ref/spec#Logical_operators
[if-statement]: https://golang.org/ref/spec#If_statements
