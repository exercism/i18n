# Οδηγίες

Σε αυτήν την άσκηση, θα βοηθήσεις ερωτευμένα ζευγάρια από τα σχολικά τους χρόνια να διακηρύξουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας μια καρδιά ASCII με τα αρχικά τους:

```
❤ J.  +  M. ❤
```

## 1. Καθάρισε το όνομα

Υλοποίησε τη μέθοδο `HighSchoolSweetheart.clean_up_name`.
Πρέπει να παίρνει ένα όνομα, να αφαιρεί από αυτό όλους τους χαρακτήρες `-` και να τους αντικαθιστά με ένα διάστημα.
Πρέπει επίσης να αφαιρεί τυχόν κενά από την αρχή και το τέλος του ονόματος.

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. Πάρε το πρώτο γράμμα του ονόματος

Υλοποίησε τη μέθοδο `HighSchoolSweetheart.first_letter`.
Πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `HighSchoolSweetheart.clean_up_name` που όρισες στο προηγούμενο βήμα.

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Υλοποίησε τη μέθοδο `HighSchoolSweetheart.initial`.
Πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα, κεφαλαίο, ακολουθούμενο από τελεία.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `HighSchoolSweetheart.first_letter` που όρισες στο προηγούμενο βήμα.

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. Βάλε τα αρχικά μέσα στην καρδιά

Υλοποίησε τη μέθοδο `HighSchoolSweetheart.pair`.
Πρέπει να παίρνει δύο ονόματα και να επιστρέφει τα αρχικά με καρδιές emoji γύρω τους.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `HighSchoolSweetheart.initial` που όρισες στο προηγούμενο βήμα.

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
