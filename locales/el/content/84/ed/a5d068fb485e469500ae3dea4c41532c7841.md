# Προσάρτημα οδηγιών

## Μορφή εισόδου

Κάθε ντόμινο αποθηκεύεται ως ένα μόνο byte, με το αριστερό μισό στο υψηλό [nibble] και το δεξί μισό στο χαμηλό [nibble]. Για παράδειγμα, οι πέτρες `[2|1]`, `[2|3]`, και `[1|3]` αναπαρίστανται ως τα byte `0x21 0x23 0x13`.

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | είσοδος     | διεύθυνση | πίνακας από byte πετρών                             |
| `$a1`    | είσοδος     | ακέραιος | αριθμός πετρών                                 |
| `$v0`    | έξοδος    | boolean | τα ντόμινο μπορούν να σχηματίσουν αλυσίδα (`0` = `false`, `1` = `true`) |
| `$t0-9`  | προσωρινός | οποιοσδήποτε     | χρησιμοποιούνται για προσωρινή αποθήκευση                       |


[nibble]: https://en.wikipedia.org/wiki/Nibble
