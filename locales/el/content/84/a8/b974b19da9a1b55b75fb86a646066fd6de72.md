# Εισαγωγή

Στη Haxe, μια ιεραρχία κλάσεων μπορεί να οριστεί χρησιμοποιώντας την _κληρονομικότητα_, η οποία επιτρέπει σε μια παράγωγη κλάση (`Car`) να κληρονομήσει τη συμπεριφορά και τα δεδομένα της γονικής της κλάσης (`Vehicle`).

Στη γονική κλάση, μπορείς να έχεις:

- Μεθόδους που μπορούν να υπερκαλυφθούν
- Αφηρημένες μεθόδους που πρέπει να υλοποιηθούν από τις παράγωγες κλάσεις

```haxe
abstract class Vehicle {
  public function new() {}

  // Can be overridden
  public function drive() {
    // ...
  }

  // Must be implemented
  public abstract function getSpeed():Int;
}

class Car extends Vehicle {
  public function new() {
    super(); // Runs the parent class' constructor
  }

  public override function drive() {
    // ...
  }

  public function getSpeed():Int {
    // ...
  }
}
```

Αν η γονική κλάση έχει κατασκευαστή, χρησιμοποιούμε το `super()` για να τον καλέσουμε:

```haxe
abstract class Vehicle {
  var wheels:Int;

  public function new(wheels:Int) {
    this.wheels = wheels
  }
}

class Car extends Vehicle {
  var color:String;

  public function new(wheels:Int, color:String) {
    super(wheels);
    this.color = color;
  }
}

```
