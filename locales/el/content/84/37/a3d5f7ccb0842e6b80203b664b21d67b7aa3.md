# Υποδείξεις

## 1. Φτιάξε κάτι μεγαλειώδες

- Η αντιστοίχιση είναι η σωστή διαδικασία για να εφαρμόσεις μια συνάρτηση σε κάθε στοιχείο μιας ακολουθίας.
- Η `mapcar` είναι μια καλή συνάρτηση για να αντιστοιχίσεις μια συνάρτηση σε μια λίστα.

## 2. Μόνο τα καλύτερα

- Το φιλτράρισμα είναι η σωστή διαδικασία για να αφαιρέσεις ένα ή περισσότερα στοιχεία από μια ακολουθία, με αποτέλεσμα μια νέα ακολουθία.
- Η `remove` μπορεί να αφαιρέσει από μια ακολουθία τιμές που είναι ίσες με ένα συγκεκριμένο στοιχείο.
- Η `remove-if` μπορεί να αφαιρέσει τιμές για τις οποίες μια συνάρτηση κατηγορήματος αποτιμάται σε αληθή τιμή.
