# Εισαγωγή

Η αντιστοίχιση αναφέρεται στην εφαρμογή μιας συνάρτησης σε κάθε στοιχείο μιας ακολουθίας για να παραχθεί μια νέα ακολουθία.

Αυτό μπορεί να γίνει εύκολα σε μια λίστα με τη συνάρτηση `mapcar`.
Ας υποθέσουμε ότι έχουμε μια συνάρτηση `double` που πολλαπλασιάζει το όρισμά της με `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Πρόσεξε ότι το πρώτο όρισμα είναι μια συνάρτηση προς κλήση. Το `#'` είναι μια ειδική σύνταξη παράθεσης για να προσδιορίσεις μια συνάρτηση.

Η `double` κλήθηκε πρώτα με το πρώτο στοιχείο, μετά με το δεύτερο, κ.λπ.
Τα αποτελέσματα συλλέχθηκαν σε μια λίστα, η οποία είναι η τιμή στην οποία αποτιμάται η έκφραση.
