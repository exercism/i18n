# Προσθήκη στις οδηγίες

## Οδηγίες ειδικά για τη διαδρομή

Οι δοκιμές αυτής της άσκησης βασίζονται στη βιβλιοθήκη τρίτων `datetime` αντί για την κλάση `Date` της τυπικής βιβλιοθήκης. Στις δοκιμές μας, η τυπική κλάση Date δεν υποστήριζε τη [θερινή ώρα](https://en.wikipedia.org/wiki/Daylight_saving_time), κάτι που προκάλεσε προβλήματα σε πολλές περιπτώσεις δοκιμών. Ρίξε μια ματιά στην [επίσημη τεκμηρίωση](https://lib.haxe.org/p/datetime/) της βιβλιοθήκης `datetime` για τυχόν απορίες.
