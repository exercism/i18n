# Εισαγωγή

Στην Elixir, μπορούμε να ορίσουμε χαρακτηριστικά module που μπορούν να χρησιμοποιηθούν ως σταθερές στις συναρτήσεις μας.

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

Όταν χρησιμοποιούνται για να ορίσουν σταθερές module, τα χαρακτηριστικά μπορούν να είναι οποιαδήποτε έκφραση που μπορεί να αξιολογηθεί κατά τη μεταγλώττιση. Μετά τη μεταγλώττιση, τα χαρακτηριστικά module δεν είναι προσβάσιμα, καθώς επεκτείνονται κατά τη μεταγλώττιση, παρόμοια με τις μακροεντολές που ορίζονται σε γλώσσες όπως η C.
