# Σχετικά

Η ABAP υποστηρίζει τους συνήθεις αριθμητικούς τελεστές για αριθμητικές τιμές:

- `+` προσθέτει τιμές.
- `-` αφαιρεί τιμές.
- `*` πολλαπλασιάζει τιμές.
- `/` διαιρεί τιμές.
- `MOD` επιστρέφει το υπόλοιπο μιας ακέραιας διαίρεσης.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

Ο πολλαπλασιασμός και η διαίρεση αξιολογούνται πριν από την πρόσθεση και την αφαίρεση. Χρησιμοποίησε παρενθέσεις όταν ένας υπολογισμός πρέπει να ομαδοποιηθεί ρητά.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
