# Προσθήκη στις οδηγίες

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να δημιουργήσεις τον τύπο δεδομένων `Robot`
και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `bearing`
- `coordinates`
- `mkRobot`
- `move`

Θα βρεις ήδη στη θέση τους μια δήλωση εικονικών δεδομένων και τις υπογραφές τύπων,
αλλά εξαρτάται από εσένα να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν τύπο
δεδομένων που να έχει νόημα, ένα newtype ή έναν συνώνυμο τύπο.
