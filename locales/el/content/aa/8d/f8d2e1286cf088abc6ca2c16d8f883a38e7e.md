# Προσθήκη οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση      | Τύπος                 | Περιγραφή                                                 |
| ----------- | ---------- | --------------------- | --------------------------------------------------------- |
| `$a0`       | είσοδος    | διεύθυνση             | συμβολοσειρά εισόδου με τερματισμό null                   |
| `$v0`       | έξοδος     | boolean (λογική τιμή) | η είσοδος είναι παγγράμμα (`0` = `false`, `1` = `true`)   |
| `$t0-9`     | προσωρινός | οτιδήποτε             | χρησιμοποιούνται για προσωρινή αποθήκευση                  |
