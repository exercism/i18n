# Υποδείξεις

## Γενικά

- Χρησιμοποίησε το crate `enum-iterator` για να μπορείς να κάνεις επανάληψη πάνω σε enum. Ρίξε μια ματιά στην [τεκμηρίωση](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) για να δεις πώς.

- Χρησιμοποίησε το crate `int-enum` για να μπορείς να κάνεις μετατροπή από int σε enum. Δες την [τεκμηρίωση](https://docs.rs/int-enum/0.5.0/int_enum/) για λεπτομέρειες.

- Το trait `Debug` υπάρχει επειδή πιθανότατα θα το χρειαστείς.

- Θα χρειαστεί να επεκτείνεις τη λίστα με τα traits που παράγονται με `derive` στο enum χρωμάτων σου.
