# Δοκιμαστικό track

_Πριν_ ξεκινήσεις το track σου (δηλαδή, το κλειδί `"active"` είναι ακόμα `false` στο `config.json` του track), είναι σημαντικό το track να δοκιμαστεί.
Αυτό θα βοηθήσει να βρεθούν (συνηθισμένα) σφάλματα και επιτρέπει να διορθωθούν _πριν_ ξεκινήσει το track, κάτι που σημαίνει ότι οι μαθητές δε θα τα συναντήσουν ποτέ.

## Πώς να ενεργοποιήσεις το track για δοκιμή

Για να ενεργοποιήσεις το track για δοκιμή, πρέπει να προστεθεί στη βάση δεδομένων μας, κάτι που μπορούν να κάνουν μόνο οι διαχειριστές του ιστότοπου.
Άνοιξε ένα θέμα στο [φόρουμ](https://forum.exercism.org/c/exercism/building-exercism/125) ζητώντας το.

Σημείωσε ότι η προσθήκη του track στη βάση δεδομένων _δε_ θα ξεκινήσει το track, αλλά _θα_ το κάνει προσβάσιμο στον ιστότοπο για τους maintainers.

## Πώς να βρεις δοκιμαστές

Οι ιδανικοί χρήστες για να δοκιμάσουν το track είναι άλλοι maintainers του track, καθώς:

- Έχουν εμπειρία στη δημιουργία ενός track (και άρα ξέρουν τι θα έπρεπε να έχει δημιουργηθεί)
- Μπορούν να έχουν πρόσβαση σε track που δεν είναι ακόμα ενεργά

Για να βάλεις maintainers να δοκιμάσουν το track σου, άνοιξε ένα θέμα στο [φόρουμ](https://forum.exercism.org/c/exercism/building-exercism/125) ζητώντας το.
