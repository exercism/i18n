# Υποδείξεις

## Γενικά

- Το module `gleam/string` έχει πολλές χρήσιμες [συναρτήσεις για συμβολοσειρές][stdlib].

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

- Μπορείς να χρησιμοποιήσεις τον τελεστή `<>` στην αντιστοίχιση προτύπων για να ταιριάξεις την αρχή μιας συμβολοσειράς.
- Το module `gleam/string` έχει μια [συνάρτηση][trim] για να αφαιρείς τα κενά στην αρχή και στο τέλος μιας συμβολοσειράς.

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

- Το module `gleam/string` έχει μια [συνάρτηση][lowercase] για να μετατρέπεις μια συμβολοσειρά σε πεζά γράμματα.

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

- Μπορείς να χρησιμοποιήσεις τον τελεστή `<>` για να ενώσεις συμβολοσειρές μεταξύ τους.
