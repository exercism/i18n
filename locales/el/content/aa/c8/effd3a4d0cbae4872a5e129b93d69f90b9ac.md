# Σχετικά

Στη C#, οι Boolean τιμές αντιπροσωπεύονται από τον τύπο `bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η C# υποστηρίζει τέσσερις [Boolean τελεστές][operators]: `!` (όχι), `&&` (και),  `||` (ή), και `^` (αποκλειστικό ή). Οι τελεστές `&&` και `||` χρησιμοποιούν _αξιολόγηση βραχυκυκλώματος_, που σημαίνει ότι η δεξιά πλευρά του τελεστή αξιολογείται μόνο όταν χρειάζεται.

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

Οι τρεις Boolean τελεστές έχουν ο καθένας διαφορετική [_προτεραιότητα τελεστών_][precedence]. Κατά συνέπεια, αξιολογούνται με αυτή τη σειρά: πρώτα ο `not`, δεύτερος ο `&&`, τρίτος ο `^` και τέλος ο `||`. Αν θέλεις να "ξεφύγεις" από αυτούς τους κανόνες, μπορείς να περικλείσεις μια Boolean έκφραση σε παρενθέσεις (`()`), καθώς οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```csharp
!true && false   // => false
!(true && false) // => true
```
