# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                                          |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | είσοδος   | ακέραιος | αρχικός αριθμός                                   |
| `$v0`    | έξοδος    | ακέραιος | αναμενόμενος αριθμός βημάτων, -1 αν ο αριθμός δεν είναι έγκυρος |
| `$t0-9`  | προσωρινό | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση          |
