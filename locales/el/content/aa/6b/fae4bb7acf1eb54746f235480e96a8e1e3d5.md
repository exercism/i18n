# Σχετικά

Οι εντολές υπό συνθήκη εκτελούν διαφορετικό κώδικα ανάλογα με το αν μια συνθήκη είναι `true` ή `false`.

Μια [εντολή `if`][if_statement] εκτελεί το σώμα της μόνο όταν η συνθήκη της είναι `true`.
Η Go δεν έχει την έννοια των τιμών που θεωρούνται αληθείς ή ψευδείς, οπότε η συνθήκη πρέπει να είναι τύπου `bool`.
Εκφράσεις όπως `if mySlice { ... }` ή `if 1 { ... }` αποτελούν σφάλματα μεταγλώττισης.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Χρησιμοποίησε το `else if` για να ελέγξεις επιπλέον συνθήκες και το `else` ως εφεδρική επιλογή αν καμία δεν ταιριάζει.
Οι συνθήκες αξιολογούνται από πάνω προς τα κάτω και εκτελείται μόνο ο πρώτος κλάδος του οποίου η συνθήκη είναι αληθής.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Γενικά, η Go προτιμά να επιστρέφει νωρίς από την εξαιρετική περίπτωση και να αποφεύγει το `else`.

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

Μια εντολή `if` μπορεί επίσης να περιλαμβάνει μια σύντομη εντολή αρχικοποίησης.
Αυτό χρησιμοποιείται συχνά για να ελέγξεις ένα σφάλμα αμέσως μετά από μια κλήση:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

Οι μεταβλητές που δηλώνονται στην εντολή αρχικοποίησης έχουν εμβέλεια μόνο μέσα σε ολόκληρη την αλυσίδα `if`/`else`.
Αξιοσημείωτο είναι ότι η Go δεν έχει τριαδικό τελεστή, μια σκόπιμη σχεδιαστική επιλογή ώστε ο κώδικας να διαβάζεται εύκολα.

Για να μάθεις περισσότερα, δες το [Go by Example: If/Else][go_by_example_if].
