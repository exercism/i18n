# Σχετικά

Η `awk` είναι μια διερμηνευόμενη γλώσσα προγραμματισμού, σχεδιασμένη για την επεξεργασία κειμένου, που χρησιμοποιείται συνήθως ως εργαλείο εξαγωγής και αναφοράς δεδομένων.
Είναι βασικό χαρακτηριστικό των περισσότερων λειτουργικών συστημάτων τύπου Unix και διαθέτει [προδιαγραφή POSIX][posix].

Μπορούμε να πούμε ότι το προγραμματιστικό παράδειγμα της `awk` είναι "καθοδηγούμενο από τα δεδομένα":
ένα πρόγραμμα `awk` διαβάζει γραμμές (ή άλλες μονάδες κειμένου) και αναζητά αντιστοιχίσεις _μοτίβων_.
Όταν βρεθεί μια αντιστοίχιση, εκτελείται η καθορισμένη _ενέργεια_.

Ένα πρόγραμμα `awk` μοιάζει κάπως έτσι
```awk
pattern1 {action1}
pattern2 {action2}
...
```

Το _μοτίβο_ μπορεί να είναι μια κανονική έκφραση ή κάποια άλλη έκφραση που αποτιμάται σε μια τιμή αληθής/ψευδής.
Το _μοτίβο_ μπορεί να παραλειφθεί, οπότε η _ενέργεια_ εκτελείται για κάθε καταγραφή κειμένου.
Η _ενέργεια_ μπορεί να παραλειφθεί, οπότε η προεπιλεγμένη ενέργεια είναι να εκτυπωθεί η τρέχουσα καταγραφή.

Η `awk` είναι μια εξαιρετική προσθήκη στην εργαλειοθήκη του χρήστη.
Τα καταφέρνει πολύ καλά σε σύντομα προγράμματα "μιας γραμμής" που γράφονται στη γραμμή εντολών.
Ένα μόνο πρόγραμμα `awk` μπορεί να αντικαταστήσει τα περισσότερα pipelines των `grep`, `sed`, `tr`, `cut`

## Υλοποιήσεις

Η `awk` επινοήθηκε το 1977 από τους Alfred Aho, Peter Weinberger και Brian Kernighan (τα επώνυμα των οποίων μας έδωσαν το όνομα της γλώσσας).
Αυτή η υλοποίηση έγινε γνωστή ως "old awk".
Το 1985 κυκλοφόρησε μια βελτιωμένη έκδοση, γνωστή ως "BWK awk" ή "new awk" ή "the one-true-awk".
Αυτή είναι η έκδοση που διανέμεται με το macOS και με μερικές από τις διανομές \*BSD

Μια άλλη κοινή υλοποίηση είναι η `mawk`, η οποία βασίζεται σε έναν διερμηνευτή bytecode.
Η `mawk` είναι πολύ γρήγορη.
Η `mawk` είναι η προεπιλεγμένη `/usr/bin/awk` που διανέμεται σε πολλές διανομές Linux.

### GNU awk

Σε αυτό το track θα χρησιμοποιήσουμε το `gawk`, την υλοποίηση awk της GNU.
Το `gawk` μπορεί να μην έχει την ωμή ταχύτητα του `mawk`, αλλά είναι πλούσιο σε δυνατότητες, καλά τεκμηριωμένο και διαθέτει μερικές βολικές επιλογές γραμμής εντολών.

### Shebang

Ανάλογα με την πλατφόρμα, τα σενάρια awk μπορούν να εκτελεστούν προσθέτοντας μια γραμμή [shebang][shebang] στην αρχή του αρχείου.
Στα περισσότερα συστήματα, ένα από τα παρακάτω δύο shebangs θα πρέπει να δουλέψει.
Ωστόσο, επειδή δεν υπάρχει ένα shebang που να δουλεύει σε όλα τα συστήματα, έχουμε επιλέξει να τα παραλείψουμε.

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
