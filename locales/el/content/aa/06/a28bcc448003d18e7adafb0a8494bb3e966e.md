# Τα tests περνούν τοπικά αλλά όχι online;

Μερικές φορές τα tests σου περνούν τοπικά στον υπολογιστή σου αλλά όχι online.

Συνήθως υπάρχουν μερικοί λόγοι για αυτό:

## Δεν έχεις βγάλει το skip από όλα τα tests

Πολλές ασκήσεις του Exercism έρχονται με κάποια tests σε κατάσταση skip.
Στόχος είναι να λύνεις κάθε test με τη σειρά, βγάζοντας το επόμενο από το skip όσο προχωράς.
Μέχρι να φτάσεις στο τέλος της άσκησης, όλα τα tests θα πρέπει να έχουν βγει από το skip και να περνούν, και θα έχεις μια πλήρως λειτουργική λύση.
Έλεγξε την τεκμηρίωση στο [track στο οποίο δουλεύεις](/docs/tracks) για συγκεκριμένες λεπτομέρειες σχετικά με το πώς λειτουργεί το skip σε αυτή τη γλώσσα.

Όταν τρέχουμε τα tests online, βγάζουμε πρώτα τα πάντα από το skip.
Αν δεν έχεις αφήσει τα πάντα σε κατάσταση skip τοπικά, μπορεί επομένως να βρούμε κάποιες ακραίες περιπτώσεις που δεν έχεις σκεφτεί, και τα tests θα αποτύχουν.

## Χρησιμοποιούμε διαφορετικές εκδόσεις από εσένα

Οι test runners του Exercism χρησιμοποιούν μια συγκεκριμένη έκδοση της γλώσσας.
Μπορεί να μην είναι η πιο ενημερωμένη έκδοση της γλώσσας, καθώς πρέπει να ενημερώνουμε χειροκίνητα τους test runners όταν κυκλοφορούν νέες εκδόσεις της γλώσσας.

Αν τα tests αποτύχουν online, έλεγξε την έξοδο (κάνοντας κλικ στη λέξη "Failed") και προσπάθησε να εντοπίσεις τι μπορεί να είναι λάθος.
Αν διαπιστώσεις ότι το πρόβλημα οφείλεται σε αναντιστοιχία εκδόσεων, άνοιξε ένα issue στο σχετικό αποθετήριο test-runner στο GitHub.
Αυτό συνήθως ακολουθεί το μοτίβο `https://github.com/exercism/$SLUG-test-runner` (π.χ. `https://github.com/exercism/ruby-test-runner`).
