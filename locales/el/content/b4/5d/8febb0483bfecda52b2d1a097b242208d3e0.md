# Σχετικά

Ένα σύνολο είναι μια αμετάβλητη και μη διατεταγμένη συλλογή από μοναδικές τιμές. Όλα τα στοιχεία σε ένα σύνολο πρέπει να είναι του ίδιου τύπου.

Το άρθρωμα `gleam/set` ορίζει τον τύπο `Set` και παρέχει συναρτήσεις για εργασία με σύνολα.

Μπορείς να μετατρέπεις λίστες και σύνολα μεταξύ τους με τις `set.to_list` και `set.from_list`. Η σειρά των στοιχείων σε ένα σύνολο δεν είναι εγγυημένη.

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

Μπορείς να δημιουργείς και να γεμίζεις σύνολα με τις `set.new`, `set.insert` και `set.delete`.

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

Μπορείς να ελέγχεις τα περιεχόμενα ενός συνόλου με τις συναρτήσεις `set.contains` και `set.size`.

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

Τα σύνολα μπορούν να συνδυαστούν με τις `set.union` και `set.intersect`.

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

Μπορείς να φιλτράρεις σύνολα.

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
