# Εισαγωγή

Η AWK είναι μια πολύ μικρή γλώσσα και έχει μόνο λίγους βασικούς τύπους δεδομένων.
Σε αυτή την ενότητα θα δούμε αριθμούς και συμβολοσειρές.

## Αριθμοί

Οι αριθμοί στην AWK υλοποιούνται ως αριθμοί κινητής υποδιαστολής διπλής ακρίβειας.
Δεν υπάρχει διάκριση μεταξύ ακεραίων, float και double.

Η AWK κατανοεί σταθερές οκταδικών αριθμών (που ξεκινούν με `0`) και σταθερές δεκαεξαδικών αριθμών (που ξεκινούν με `0x` ή `0X`).

### Αριθμητικές πράξεις

Μπορείς να χρησιμοποιήσεις τους [τυπικούς αριθμητικούς τελεστές][ops-arith] `+`, `-`, `*`, `/`, `%`.
Ο τελεστής ύψωσης σε δύναμη είναι ο `^` (ορίζεται από το POSIX), αν και μπορεί να χρησιμοποιηθεί και ο `**`.
Υπάρχουν επίσης μερικές [ενσωματωμένες αριθμητικές συναρτήσεις][funcs-numeric], όπως τριγωνομετρικές συναρτήσεις, παραγωγή τυχαίων αριθμών και η `int(x)` για την περικοπή ενός αριθμού στον κοντινότερο ακέραιο μεταξύ του _x_ και του μηδενός.

Δεν υπάρχουν bitwise _τελεστές_.
Το gawk τους υλοποιεί ως συναρτήσεις.
Τα ορίσματα πρέπει να είναι μη αρνητικοί αριθμοί.

| συνάρτηση           | πράξη                                          |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | bitwise AND των ορισμάτων                      |
| `or(a, b [, ...])`  | bitwise OR των ορισμάτων                       |
| `xor(a, b [, ...])` | bitwise XOR των ορισμάτων                      |
| `lshift(v, count)`  | η τιμή του _v_ μετατοπισμένη αριστερά κατά _count_ bits  |
| `rshift(v, count)`  | η τιμή του _v_ μετατοπισμένη δεξιά κατά _count_ bits |
| `compl(v, count)`   | bitwise συμπλήρωμα του _v_                     |

## Συμβολοσειρές

Οι συμβολοσειρές της AWK είναι ακολουθίες χαρακτήρων.
Ορίζεις μια σταθερά συμβολοσειράς χρησιμοποιώντας διπλά εισαγωγικά.

~~~~exercism/caution
Το GNU awk επιτρέπει χαρακτήρες Unicode στις συμβολοσειρές: άλλες υλοποιήσεις της awk μπορεί όχι.
Συγκρίνοντας το `gawk` με το `mawk`, μια άλλη δημοφιλή υλοποίηση της AWK:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Πράξεις συμβολοσειρών

Υπάρχει μόνο μία πράξη συμβολοσειρών: η συνένωση.
Η συνένωση δεν έχει ειδικό τελεστή·
απλώς τοποθετώντας δύο συμβολοσειρές τη μία δίπλα στην άλλη, αυτές συνενώνονται:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
Το `print` είναι **εντολή**, όχι συνάρτηση.
Το `print` δεν απαιτεί παρενθέσεις.
~~~~

Η AWK διαθέτει πλήθος [συναρτήσεων χειρισμού συμβολοσειρών][funcs-string].
Θα τις γνωρίσουμε σε βάθος καθώς προχωράμε στη διαδρομή.

## Μετατροπή μεταξύ αριθμών και συμβολοσειρών

Δεν υπάρχουν ρητοί τελεστές για τη μετατροπή μεταξύ αριθμών και συμβολοσειρών.
Η AWK το κάνει αυτό έμμεσα, με βάση το πλαίσιο του προγράμματος.
Αυτό κάνει την εργασία με τις τιμές των πεδίων εισόδου πολύ απλή: η AWK συνήθως κάνει απλώς αυτό που θέλεις.

* Η `print x + y` θα μετατρέψει τις τιμές των μεταβλητών `x` και `y` σε αριθμούς χάρη στην αριθμητική πράξη `+`.
* Η `print x y` θα μετατρέψει τις τιμές των μεταβλητών `x` και `y` σε συμβολοσειρές χάρη στην πράξη συνένωσης.

Αν θέλεις να είσαι ρητός, το `0 + x` δίνει την αριθμητική αναπαράσταση του _x_ και το `"" x` δίνει την αναπαράσταση συμβολοσειράς του _x_.

### Από συμβολοσειρές σε αριθμούς

Ο τρόπος με τον οποίο η AWK μετατρέπει μια συμβολοσειρά σε αριθμό μπορεί να μπερδέψει.
Ένας απλός τρόπος να το σκεφτείς είναι ότι η AWK διαβάζει "αριθμητικούς χαρακτήρες" από την αρχή μιας συμβολοσειράς μέχρι να βρει έναν χαρακτήρα που δεν είναι αριθμός.
Μερικά παραδείγματα είναι:

* Το `"2.5"` μετατρέπεται στον αριθμό `2.5`·
* Το `"1e3"` μετατρέπεται στον αριθμό `1000` (επιστημονική σημειογραφία)·
* Το `"456abc"` μετατρέπεται στον αριθμό `456` (επειδή το `a` δεν είναι "ψηφίο", η μετατροπή σταματά εκεί).
* Το `"abc789"` μετατρέπεται στον αριθμό `0` (δεν υπάρχουν αριθμοί στην **αρχή** της συμβολοσειράς).

Οι πλήρεις λεπτομέρειες είναι [στο εγχειρίδιο][str-to-num].

## Προσδιορισμός του τύπου μιας μεταβλητής

Η [συνάρτηση `typeof(var)`][func-typeof] επιστρέφει τον τύπο ως συμβολοσειρά.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
παράγει
```none
42 string
43 number
```
