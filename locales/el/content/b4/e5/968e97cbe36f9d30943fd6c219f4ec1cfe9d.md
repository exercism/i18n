# Σχετικά με τους αριθμητικούς τελεστές

## Τελεστές

Η Go υποστηρίζει τους παρακάτω αριθμητικούς τελεστές:

| Τελεστής | Παράδειγμα     |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

Για ακέραια διαίρεση, το υπόλοιπο αγνοείται (π.χ. `5 / 2 == 2`).

Ο τελεστής `+` συνενώνει επίσης συμβολοσειρές: `"foo" + "bar" == "foobar"`.

## Αριθμητική με μικτούς τύπους

Η Go δεν επιτρέπει αριθμητικές πράξεις μεταξύ διαφορετικών αριθμητικών τύπων:

```go
x := 42
n := 2.0
value := n * x // invalid operation: n * x (mismatched types float64 and int)
```

Οι τελεστέοι πρέπει να είναι του ίδιου τύπου, κάτι που μερικές φορές απαιτεί ρητή μετατροπή:

```go
x := float64(42)
n := 2.0
value := n * x 
```

## Συντομευμένες αναθέσεις

Κάθε τελεστής έχει μια συντομευμένη μορφή ανάθεσης που ενημερώνει τη μεταβλητή επιτόπου:

```go
a := 1
a += 2 // same as a = a + 2 == 3

b := 2
b -= 2 // same as b = b - 2 == 0

c := 4
c *= 2 // same as c = c * 2 == 8

d := 8
d /= 2 // same as d = d / 2 == 4

e := 16
e %= 2 // same as e = e % 2 == 0
```

## Αύξηση και μείωση

Όταν τοποθετούνται μετά από μια μεταβλητή, οι εντολές αύξησης (`++`) και μείωσης (`--`) αυξάνουν ή μειώνουν την αποθηκευμένη αριθμητική τιμή της κατά 1.
Η τοποθέτησή τους πριν από μια μεταβλητή αποτελεί συντακτικό σφάλμα.

```go
a := 10
a++ // same as a += 1, a == 11

b := 10
b-- // same as b -= 1, b == 9
```

Επειδή είναι εντολές, δεν επιστρέφουν τιμή.
