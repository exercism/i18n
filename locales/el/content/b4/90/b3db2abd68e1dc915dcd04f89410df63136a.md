# Εισαγωγή

## Ιδιότητες

Μια ιδιότητα στη C# είναι ένα μέλος μιας κλάσης που παρέχει πρόσβαση στα δεδομένα μέσα σε αυτή την κλάση.
Όσοι καλούν μπορούν να ορίσουν ή να ανακτήσουν (get) τα δεδομένα. Οι ιδιότητες μπορούν είτε να είναι αυτόματα υλοποιημένες είτε να έχουν ένα πεδίο υποστήριξης. Περιλαμβάνουν έναν προσπελαστή set ή/και έναν προσπελαστή get.
Σε κάποιες άλλες γλώσσες, ένας "mutator" είναι περίπου ισοδύναμος με έναν προσπελαστή set και ένας "accessor" είναι περίπου ισοδύναμος με έναν προσπελαστή get, αν και η σύνταξή τους είναι εντελώς διαφορετική.

Όταν ορίζεις μια ιδιότητα, η τιμή εισόδου μπορεί να επικυρωθεί, να μορφοποιηθεί ή να υποστεί άλλους χειρισμούς, και στην πραγματικότητα μπορεί να εκτελεστεί οποιαδήποτε προγραμματιστική λειτουργία είναι διαθέσιμη στον κώδικα της κλάσης.

Παρομοίως, όταν ανακτάς μια ιδιότητα, τα δεδομένα μπορούν να υπολογιστούν ή να μορφοποιηθούν, και πάλι μπορεί να εκτελεστεί οποιαδήποτε προγραμματιστική λειτουργία είναι διαθέσιμη στην κλάση.

Οι ιδιότητες έχουν προσδιοριστές πρόσβασης (`public`, `private` κ.λπ.) με τον ίδιο τρόπο όπως και τα άλλα μέλη της κλάσης, αλλά ο προσπελαστής set μπορεί να έχει επίπεδο πρόσβασης ανεξάρτητο από τον προσπελαστή ανάκτησης (get) και αντίστροφα. Μια ιδιότητα δε χρειάζεται να έχει και τους δύο προσπελαστές, μπορεί να έχει μόνο έναν (είτε get είτε set).

Η βασική σύνταξη για να εκφράσεις ιδιότητες μπορεί να πάρει δύο μορφές:

### Ιδιότητες που υποστηρίζονται από πεδίο/έκφραση:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### Αυτόματα υλοποιημένες ιδιότητες

```
public int MyProperty { get; private set; } = 42;
```

Η αρχικοποίηση είναι προαιρετική.
