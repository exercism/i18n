# Προσθήκη οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                                                                           |
| ----------- | --------- | -------- | ------------------------------------------------------------------------------------- |
| `$a0`       | είσοδος   | ακέραιος | αριθμός                                                                               |
| `$v0`       | έξοδος    | ακέραιος | ταξινόμηση (`1` = `perfect`, `2` = `abundant`, `3` = `deficient`, `-1` = `error`)     |
| `$t0-9`     | προσωρινή | οποιοσδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση                                            |
