# Σχετικά

Οι σταθερές στη Gleam είναι ένας τρόπος για να δίνεις ονόματα σε τιμές. Ορίζονται με τη λέξη-κλειδί `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Όταν ορίζονται με τη λέξη-κλειδί `pub`, οι σταθερές ενός module είναι προσβάσιμες από άλλα modules, αλλιώς είναι προσβάσιμες μόνο μέσα από το module στο οποίο ορίζονται.
