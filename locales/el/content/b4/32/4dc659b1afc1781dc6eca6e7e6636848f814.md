# Οδηγίες

Η φίλη σου η βιβλιοθηκάριος σου ζήτησε να επεκτείνεις το λογισμικό της βιβλιοθήκης της, ώστε να υπολογίζει αυτόματα τα πρόστιμα καθυστέρησης.
Το τρέχον σύστημά της αποθηκεύει την ακριβή ημερομηνία και ώρα του δανεισμού ενός βιβλίου ως συμβολοσειρά ημερομηνίας και ώρας [ISO8601](https://en.wikipedia.org/wiki/ISO_8601).
Διευθύνει μια τοπική βιβλιοθήκη σε μια μικρή πόλη της Γκάνας, η οποία χρησιμοποιεί τη ζώνη ώρας GMT (UTC +0), δεν εφαρμόζει θερινή ώρα και δεν χρειάζεται να ανησυχεί για άλλες ζώνες ώρας.

## 1. Ανάλυσε τις αποθηκευμένες ημερομηνίες και ώρες

Υλοποίησε τη συνάρτηση `LibraryFees.datetime_from_string/1`. Θα πρέπει να δέχεται ως όρισμα μια συμβολοσειρά ημερομηνίας και ώρας ISO8601 και να επιστρέφει μια δομή `NaiveDateTime`.

```elixir
LibraryFees.datetime_from_string("2021-01-01T13:30:45Z")
# => ~N[2021-01-01 13:30:45]
```

## 2. Προσδιόρισε αν ένα βιβλίο δανείστηκε πριν το μεσημέρι

Αν ένα βιβλίο δανείστηκε πριν το μεσημέρι, ο αναγνώστης έχει 28 ημέρες για να το επιστρέψει. Αν δανείστηκε το μεσημέρι ή αργότερα, έχει 29 ημέρες.

Υλοποίησε τη συνάρτηση `LibraryFees.before_noon?/1`. Θα πρέπει να δέχεται μια δομή `NaiveDateTime` και να επιστρέφει μια boolean τιμή.

```elixir
LibraryFees.before_noon?(~N[2021-01-12 08:23:03])
# => true
```

## 3. Υπολόγισε την ημερομηνία επιστροφής

Με βάση την ημερομηνία και ώρα δανεισμού, υπολόγισε την ημερομηνία επιστροφής.

Υλοποίησε τη συνάρτηση `LibraryFees.return_date/1`. Θα πρέπει να δέχεται μια δομή `NaiveDateTime` και να επιστρέφει μια δομή `Date`, 28 ή 29 ημέρες αργότερα.

```elixir
LibraryFees.return_date(~N[2020-11-28 15:55:33])
# => ~D[2020-12-27]
```

## 4. Προσδιόρισε πόσο καθυστέρησε η επιστροφή του βιβλίου

Η βιβλιοθήκη έχει ενιαία χρέωση για τις καθυστερημένες επιστροφές. Για να μπορέσουμε να υπολογίσουμε το πρόστιμο, πρέπει να ξέρουμε πόσες ημέρες μετά την ημερομηνία επιστροφής επιστράφηκε στην πραγματικότητα το βιβλίο.

Υλοποίησε τη συνάρτηση `LibraryFees.days_late/2`. Θα πρέπει να δέχεται μια δομή `Date`, την προγραμματισμένη ημερομηνία επιστροφής, και μια δομή `NaiveDateTime`, την πραγματική ημερομηνία και ώρα επιστροφής.

Αν η πραγματική ημερομηνία επιστροφής είναι προγενέστερη ή ίδια με την προγραμματισμένη ημερομηνία και ώρα επιστροφής, η συνάρτηση θα πρέπει να επιστρέφει 0. Διαφορετικά, η συνάρτηση θα πρέπει να επιστρέφει τη διαφορά μεταξύ των δύο αυτών ημερομηνιών σε ημέρες.

Η βιβλιοθήκη καταγράφει και την ημερομηνία και την ώρα της πραγματικής επιστροφής του βιβλίου για στατιστικούς σκοπούς, αλλά δεν χρησιμοποιεί την ώρα κατά τον υπολογισμό των προστίμων καθυστέρησης.

```elixir
LibraryFees.days_late(~D[2020-12-27], ~N[2021-01-03 09:23:36])
# => 7
```

## 5. Προσδιόρισε αν το βιβλίο επιστράφηκε Δευτέρα

Η βιβλιοθήκη έχει μια ειδική προσφορά για την επιστροφή βιβλίων τις Δευτέρες.

Υλοποίησε τη συνάρτηση `LibraryFees.monday?/1`. Θα πρέπει να δέχεται μια δομή `NaiveDateTime` και να επιστρέφει μια boolean τιμή.

```elixir
LibraryFees.monday?(~N[2021-01-03 13:30:45Z])
# => false
```

## 6. Υπολόγισε το πρόστιμο καθυστέρησης

Υλοποίησε τη συνάρτηση `LibraryFees.calculate_late_fee/3`. Θα πρέπει να δέχεται τρία ορίσματα: δύο συμβολοσειρές ημερομηνίας και ώρας ISO8601, την ημερομηνία και ώρα δανεισμού και την πραγματική ημερομηνία και ώρα επιστροφής, και το πρόστιμο καθυστέρησης για μία ημέρα. Θα πρέπει να επιστρέφει το συνολικό πρόστιμο καθυστέρησης, ανάλογα με το πόσο καθυστέρησε η πραγματική επιστροφή του βιβλίου.

Συμπερίλαβε την ειδική προσφορά της Δευτέρας. Αν επιστρέψεις το βιβλίο Δευτέρα, το πρόστιμο καθυστέρησης έχει έκπτωση 50%, στρογγυλοποιημένη προς τα κάτω.

```elixir
# Sunday, 7 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-03T13:30:45Z", 100)
# => 700

# one day later, Monday, 8 days late
LibraryFees.calculate_late_fee("2020-11-28T15:55:33Z", "2021-01-04T09:02:11Z", 100)
# => 400
```
