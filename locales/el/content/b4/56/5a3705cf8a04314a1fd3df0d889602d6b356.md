# Βοήθεια

Αν αντιμετωπίζεις κάποιο πρόβλημα και χρειάζεσαι βοήθεια, μπορείς να χρησιμοποιήσεις έναν από τους παρακάτω πόρους:

- [η ετικέτα `c++-faq` στο StackOverflow](https://stackoverflow.com/tags/c%2b%2b-faq/info)
- [Συχνές ερωτήσεις για τη C++ από το isocpp.com](https://isocpp.org/faq)
- [Το CppReference](http://en.cppreference.com/) είναι μια wiki αναφορά για τη γλώσσα C++ και την πρότυπη βιβλιοθήκη
- [C traps and pitfalls](http://www.slideshare.net/LegalizeAdulthood/c-traps-and-pitfalls-for-c-programmers) είναι χρήσιμο αν είσαι αρχάριος στη C++, αλλά έχεις ήδη προγραμματίσει σε C
