# Προσάρτημα οδηγιών

## Υποδείξεις

Πρέπει να υλοποιήσεις τις συναρτήσεις `label` και `ohms`. Μπορείς να χρησιμοποιήσεις την υπογραφή που παρέχεται για τη `label`, αλλά μην την αφήσεις να περιορίσει τη δημιουργικότητά σου.

Αυτή η άσκηση δουλεύει με κειμενικά δεδομένα. Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων. Για πιο αποδοτικό χειρισμό κειμενικών δεδομένων, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να:

- διαβάσεις για [τους τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη Haskell.
- προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- κάνεις import το `Data.Text` με [τον ακόλουθο τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- γράψεις τώρα π.χ. `label :: Resistor -> Text` και να αναφέρεσαι σε συνδυαστές του `Data.Text` ως π.χ. `T.pack`.
- αναζητήσεις την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),

Αυτό το μέρος είναι εντελώς προαιρετικό.
