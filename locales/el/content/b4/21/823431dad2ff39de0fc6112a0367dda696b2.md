# Οδηγίες

Κρατάς τα βιβλία μιας μικρής εταιρείας και οι συναλλαγές της κάθε μέρας φτάνουν ως ακατάστατες γραμμές κειμένου. Θα χρησιμοποιήσεις κανονικές εκφράσεις για να επικυρώσεις ποσά, να βγάλεις νούμερα με βάση το σύμβολο που τα σημαδεύει και να επισημάνεις γραμμές που χρειάζονται πιο προσεκτική ματιά.

## 1. Επικύρωσε ένα ποσό

Ένα σωστά διαμορφωμένο ποσό αποτελείται από ένα `$`, ένα ή περισσότερα ψηφία και ένα *προαιρετικό* τμήμα λεπτών, δηλαδή μια τελεία ακολουθούμενη από ακριβώς δύο ψηφία: `$100` ή `$100.50`, αλλά όχι `$100.5`. Όρισε τη `valid-amount?`, που επιστρέφει `t` όταν ολόκληρη η συμβολοσειρά είναι ένα σωστά διαμορφωμένο ποσό.

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. Βγάλε τα ποσά σε δολάρια

Όρισε τη `dollar-amounts`, που επιστρέφει κάθε αριθμό που ακολουθεί αμέσως μετά από ένα `$` στη γραμμή, μόνο τα ψηφία, χωρίς το `$`, με τη σειρά.

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. Βγάλε τα ποσοστά

Όρισε τη `percentages`, που επιστρέφει κάθε αριθμό που ακολουθείται αμέσως από ένα `%`.

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. Επισήμανε μια γραμμή

Όρισε τη `flagged?`, που επιστρέφει `t` όταν η γραμμή αναφέρει `refund` ή `chargeback` με οποιονδήποτε συνδυασμό κεφαλαίων και πεζών γραμμάτων.

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
