# Εισαγωγή

Τα περισσότερα προγράμματα εξαρτώνται από κάποιες βιβλιοθήκες. Η χειροκίνητη διαχείρισή τους μπορεί να γίνει μεγάλος μπελάς. Ευτυχώς, το οικοσύστημα της Rust έρχεται ως στάνταρ με το `cargo`! Το `cargo` μπορεί να διαχειριστεί τις εξαρτήσεις ενός έργου.

Στη Rust θα δεις συχνά εξωτερικά πακέτα να αναφέρονται ως "crates". Ένα crate είναι μονάδα μεταγλώττισης στη Rust. Ένα crate μπορεί να μεταγλωττιστεί σε εκτελέσιμο ή σε βιβλιοθήκη.

Τις περισσότερες φορές, το να προσθέσεις μια εξωτερική εξάρτηση είναι τόσο απλό όσο το να προσθέσεις μια γραμμή στο αρχείο `Cargo.toml` σου.
