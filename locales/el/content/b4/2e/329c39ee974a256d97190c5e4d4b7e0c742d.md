# Υποδείξεις

## Γενικά

- Μην ανησυχείς για το πώς παράγονται τα ορίσματα, επικεντρώσου απλώς στο να συνδυάσεις τα ορίσματα για να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο pac-man μπορεί να φάει ένα φάντασμα

- Η συνάρτηση πρέπει να επιστρέφει μια [boolean][boolean] τιμή.
- Μπορείς να χρησιμοποιήσεις τον [boolean][boolean] τελεστή [`and/2`][boolean-and] για να συνδυάσεις τα ορίσματα για ένα αποτέλεσμα.

## 2. Όρισε αν ο pac-man σκοράρει

- Η συνάρτηση πρέπει να επιστρέφει μια [boolean][boolean] τιμή.
- Μπορείς να χρησιμοποιήσεις τον [boolean][boolean] τελεστή [`or/2`][boolean-or] για να συνδυάσεις τα ορίσματα για ένα αποτέλεσμα.

## 3. Όρισε αν ο pac-man χάνει

- Η συνάρτηση πρέπει να επιστρέφει μια [boolean][boolean] τιμή.
- Μπορείς να χρησιμοποιήσεις τους [boolean][boolean] τελεστές [`and/2`][boolean-and] και [`not/1`][boolean-not] για να συνδυάσεις τα ορίσματα για ένα αποτέλεσμα.

## 4. Όρισε αν ο pac-man κερδίζει

- Η συνάρτηση πρέπει να επιστρέφει μια [boolean][boolean] τιμή.
- Μπορείς να χρησιμοποιήσεις τους [boolean][boolean] τελεστές [`and/2`][boolean-and] και [`not/1`][boolean-not] για να συνδυάσεις τα ορίσματα και τα αποτελέσματα μιας από τις προηγουμένως υλοποιημένες συναρτήσεις.

[boolean]: https://hexdocs.pm/elixir/basic-types.html#booleans-and-nil
[boolean-and]: https://hexdocs.pm/elixir/Kernel.html#and/2
[boolean-or]: https://hexdocs.pm/elixir/Kernel.html#or/2
[boolean-not]: https://hexdocs.pm/elixir/Kernel.html#not/1
