# Οδηγίες

Είσαι ο ταμίας του πλοίου και διαχειρίζεσαι το απόθεμα του κελαριού. Το απόθεμα είναι ένα hashtable όπου κάθε κλειδί είναι ένα όνομα αντικειμένου και η τιμή είναι η ποσότητα που βρίσκεται σε απόθεμα.

## 1. Φτιάξε ένα απόθεμα από μια λίστα

Όρισε τη συνάρτηση `create-inventory` ώστε να δέχεται μια ακολουθία από ονόματα αντικειμένων και να επιστρέφει ένα hashtable που αντιστοιχίζει κάθε μοναδικό όνομα με την ποσότητά του.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Πρόσθεσε περισσότερα αντικείμενα

Όρισε τη συνάρτηση `add-items` ώστε να δέχεται ένα απόθεμα και μια ακολουθία αντικειμένων και να επιστρέφει ένα νέο απόθεμα του οποίου οι ποσότητες έχουν αυξηθεί κατά ένα για κάθε αντικείμενο της λίστας. Το αρχικό απόθεμα δεν πρέπει να τροποποιηθεί.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Μείωσε τις ποσότητες

Όρισε τη συνάρτηση `decrement-items` ώστε να δέχεται ένα απόθεμα και μια ακολουθία αντικειμένων και να επιστρέφει ένα νέο απόθεμα του οποίου οι ποσότητες έχουν μειωθεί κατά ένα για κάθε αντικείμενο της λίστας. Οι ποσότητες δεν πρέπει ποτέ να πέσουν κάτω από το μηδέν, και τα αντικείμενα που δεν υπάρχουν ήδη στο απόθεμα πρέπει να παραλείπονται (δεν εισάγονται αρνητικές καταχωρίσεις).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Αφαίρεσε ένα αντικείμενο εντελώς

Όρισε τη συνάρτηση `remove-item` ώστε να δέχεται ένα απόθεμα και ένα αντικείμενο και να επιστρέφει ένα νέο απόθεμα με το αντικείμενο αυτό αφαιρεμένο. Αν το αντικείμενο δεν υπάρχει, επέστρεψε ένα αμετάβλητο αντίγραφο.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Κάνε λίστα με τα διαθέσιμα αντικείμενα

Όρισε τη συνάρτηση `list-inventory` ώστε να δέχεται ένα απόθεμα και να επιστρέφει έναν πίνακα από ζεύγη `{ name quantity }` που περιέχει μόνο τα αντικείμενα των οποίων η ποσότητα είναι μεγαλύτερη από το μηδέν, ταξινομημένα αλφαβητικά κατά όνομα.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
