Ίσως θέλεις να αποδώσεις κι εσύ ο ίδιος αυτά τα widget σε έγγραφα Markdown, για παράδειγμα στο τέλος ενός εγγράφου, για να προτείνεις επιπλέον αναγνώσματα ή καλές ασκήσεις από τις οποίες μπορείς να μάθεις κάτι.

**Σημείωση:** Μπορείς επίσης να χρησιμοποιήσεις κανονικούς συνδέσμους για ενσωματωμένο κείμενο, στους οποίους θα προστεθούν αυτόματα τα tooltips. Δες [την τεκμηρίωση για την εσωτερική σύνδεση](/docs/building/markdown/internal-linking) για περισσότερες λεπτομέρειες.

## Χρήση

Τα widget μπορούν να χρησιμοποιηθούν οπουδήποτε μπορείς να χρησιμοποιήσεις Markdown, όπως σε τεκμηρίωση, σε προσεγγίσεις και σε συζητήσεις μεταξύ μαθητών και μέντορων.

Αποδίδονται με την εξής μορφή:

```md
[<type>:<id>]()
```

Τα μέρη `<type>` και `<id>` είναι μεταβλητά και εξαρτώνται από το widget που χρησιμοποιείται.

Η αναφορά του συνδέσμου, δηλαδή το περιεχόμενο των `()`, αγνοείται από τον ιστότοπο. Μπορείς να τα δείχνεις όπου θέλεις, για σκοπούς συντήρησης.

## Widget Exercise

Μορφή συνδέσμου: `[exercise:<track-slug>/<exercise-slug>]()`

### Παράδειγμα

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget Concept

Μορφή συνδέσμου: `[concept:<track-slug>/<concept-slug>]()`

### Παράδειγμα

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```
