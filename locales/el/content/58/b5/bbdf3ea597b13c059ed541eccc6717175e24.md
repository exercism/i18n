# Υποδείξεις

## Γενικά

- Χρησιμοποίησε τον ενσωματωμένο [(συνδεδεμένο) τύπο λίστας][list].

## 1. Όρισε μια συνάρτηση που να επιστρέφει μια κενή λίστα γλωσσών

- Η συνάρτηση πρέπει να επιστρέφει `[]`.

## 2. Όρισε μια συνάρτηση που να προσθέτει μια γλώσσα στη λίστα

- Ένα στοιχείο μπορεί να προστεθεί στην αρχή μιας λίστας χρησιμοποιώντας το `|`.

## 3. Όρισε μια συνάρτηση που να αφαιρεί μια γλώσσα από τη λίστα

- Η Elixir [παρέχει μια συνάρτηση][tl] που επιστρέφει μια λίστα χωρίς το πρώτο στοιχείο.

## 4. Όρισε μια συνάρτηση που να επιστρέφει το πρώτο στοιχείο της λίστας

- Η Elixir [παρέχει μια συνάρτηση][hd] για να πάρεις το πρώτο στοιχείο μιας λίστας.

## 5. Όρισε μια συνάρτηση που να επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

- Η Elixir [παρέχει μια συνάρτηση][length] για να μετρήσεις το μήκος μιας λίστας.

## 6. Όρισε μια συνάρτηση που να προσδιορίζει αν η λίστα περιέχει μια συναρτησιακή γλώσσα

- Η συνάρτησή σου πρέπει να επιστρέφει μια τιμή Boolean (λογική τιμή) που να δείχνει αν το `"Elixir"` είναι μέλος της λίστας. Η Elixir [παρέχει μια συνάρτηση][in] για να ελέγξεις αν ένα στοιχείο ανήκει σε μια λίστα.
