# Εισαγωγή

Γενικά, δεν θέλεις να ξαναεφεύρεις τον τροχό όταν προγραμματίζεις.
Για πολλούς καθιερωμένους αλγορίθμους, θα υπάρχει κάποιος που μπορεί να έχει κάνει ήδη τη δουλειά για σένα.

## Συμπερίληψη αρχείων

Για να συμπεριλάβει το περιεχόμενο άλλων αρχείων, η C++ χρησιμοποιεί την οδηγία `include`.
Αυτές οι συμπεριλήψεις πρέπει να δηλώνονται στην αρχή του αρχείου.
Κατά τη μεταγλώττιση, η γραμμή με την οδηγία αντικαθίσταται από το περιεχόμενο του αντίστοιχου αρχείου.
Τα namespaces διατηρούνται όπως είναι στο αρχικό αρχείο μετά τις συμπεριλήψεις.

## Η πρότυπη βιβλιοθήκη

Η πρότυπη βιβλιοθήκη προσφέρει πολλές κοινές συναρτήσεις, αλγορίθμους και δομές δεδομένων.
Η πρότυπη βιβλιοθήκη χρησιμοποιεί το namespace `std`.

Ένα παράδειγμα είναι η βιβλιοθήκη αριθμητικής της C, `cmath`.
Παρέχει πολλές κοινές μαθηματικές πράξεις.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Οι πρότυπες βιβλιοθήκες συμπεριλαμβάνονται με γωνιακές αγκύλες `<>` αντί για διπλά εισαγωγικά `"`.
Η διαφορά έγκειται στο σημείο όπου ο μεταγλωττιστής αναζητά τα αντίστοιχα αρχεία.
Στην έκδοση με τις γωνιακές αγκύλες, η αναζήτηση στο τρέχον έργο παραλείπεται και ξεκινά απευθείας στους καταλόγους συμπερίληψης του συστήματος.
Αν θέλεις να συμπεριλάβεις τοπικά αρχεία, θα χρησιμοποιούσες διπλά εισαγωγικά: `#include "myfile"`
~~~~
