# Υποδείξεις

## 1. Έλεγξε αν μια τιμή είναι boolean

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.

## 2. Έλεγξε αν μια τιμή είναι αριθμός.

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.
- Πρέπει να ελέγξεις για `Infinity` και `NaN`.
- Το `NaN` δεν είναι ποτέ ίσο με τον εαυτό του, αλλά υπάρχει μια [ενσωματωμένη συνάρτηση][isNaN] για να ελέγξεις αν μια τιμή είναι NaN.

## 3. Έλεγξε αν μια τιμή είναι αντικείμενο

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.
- Θα πρέπει να ελέγξεις για `null`.

## 4. Έλεγξε αν μια συμβολοσειρά είναι αριθμητική

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.
- Μπορείς να διατρέξεις μια συμβολοσειρά για να ελέγξεις αν όλοι οι χαρακτήρες είναι ψηφία.

## 5. Έλεγξε αν ένα αντικείμενο είναι ηλεκτρονικό

- Μπορείς να χρησιμοποιήσεις το `instanceof` για να ελέγξεις αν ένα αντικείμενο είναι στιγμιότυπο μιας κλάσης ή μιας από τις υποκλάσεις της.

## 6. Έλεγξε αν μια τιμή είναι μη κενός πίνακας

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.
- Μπορείς να ελέγξεις το μήκος ενός πίνακα για να βρεις πόσα στοιχεία περιέχει.

## 7. Έλεγξε αν μια τιμή είναι κενός πίνακας

- Μπορείς να χρησιμοποιήσεις το `typeof` για να βρεις τον τύπο μιας τιμής.
- Το `typeof` επιστρέφει μια συμβολοσειρά.
- Μπορείς να ελέγξεις το μήκος ενός πίνακα για να βρεις πόσα στοιχεία περιέχει.

## 8. Έλεγξε αν ένα αντικείμενο έχει την ιδιότητα ή τη μέθοδο `type`

- Μπορείς να χρησιμοποιήσεις τον τελεστή `in` για να ελέγξεις αν ένα αντικείμενο έχει μια ιδιότητα ή μια μέθοδο.

## 9. Πέταξε ένα σφάλμα αν ένα αντικείμενο δεν έχει την ιδιότητα ή τη μέθοδο `id`

- Μπορείς να χρησιμοποιήσεις τον τελεστή `in` για να ελέγξεις αν ένα αντικείμενο έχει μια ιδιότητα ή μια μέθοδο.
- Αν η ιδιότητα ή η μέθοδος `id` λείπει, η συνάρτησή σου θα πρέπει να πετάει ένα `Error`.

## 10. Έλεγξε αν ένα αντικείμενο έχει την ιδιότητα `id`

- Για να ελέγξεις αν ένα αντικείμενο έχει μια ιδιότητα (όχι μια μέθοδο), μπορείς να χρησιμοποιήσεις τη συνάρτηση `Object.hasOwn()`.

## 11. Έλεγξε αν ένα αντικείμενο έχει μια καθορισμένη ιδιότητα `type`

- Για να ελέγξεις αν ένα αντικείμενο έχει μια ιδιότητα (όχι μια μέθοδο), μπορείς να χρησιμοποιήσεις τη συνάρτηση `Object.hasOwn()`.
- Θα πρέπει να προσπελάσεις την ιδιότητα `type` και να ελέγξεις αν είναι καθορισμένη.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
