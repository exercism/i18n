# Σχετικά

Οι [φρουροί][guards] χρησιμοποιούνται ως συμπλήρωμα της [αντιστοίχισης προτύπων][exercism-pattern-matching].
Την οποία θα δούμε σε επόμενη ενότητα.
Οι φρουροί μάς επιτρέπουν να έχουμε διαφορετικές υλοποιήσεις μιας συνάρτησης ανάλογα με την τιμή της εισόδου.
Επιτρέπουν πιο σύνθετους ελέγχους.

Μια εντολή φρουρού ορίζεται από μια κάθετη γραμμή `|` που ακολουθείται από μια boolean έκφραση και τελειώνει με ένα σύμβολο ίσον `=` και το σώμα της συνάρτησης.
Μπορούν να υπάρχουν πολλές εντολές φρουρού για μία μόνο συνάρτηση.
Οι εντολές φρουρού αξιολογούνται από πάνω προς τα κάτω και η πρώτη που αξιολογείται σε `True` θα εκτελεστεί.
Μια εντολή φρουρού επιτρέπει και μια εντολή `otherwise`, η οποία λειτουργεί ως γενική περίπτωση για κάθε τιμή που δεν ταιριάζει με τις προηγούμενες εντολές φρουρού.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

Μπορούμε επίσης να ορίσουμε τη δική μας συνάρτηση και να τη χρησιμοποιήσουμε μέσα στην εντολή φρουρού.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
