# Μετατροπή Τύπων

Ο Cairo υποστηρίζει τη μετατροπή τύπων μέσω των trait `Into` και `TryInto` από τη βασική βιβλιοθήκη, που χρησιμοποιούνται συνήθως για ενσωματωμένους και προσαρμοσμένους τύπους.

Αυτά τα trait ορίζουν μεθόδους για τη μετατροπή τιμών μεταξύ τύπων:  

- **`Into`**: Για εγγυημένες, αλάνθαστες μετατροπές.  
- **`TryInto`**: Για μετατροπές που μπορεί να αποτύχουν, επιστρέφοντας `Option<T>`.

## Χρήση του `Into`

Το `Into` χειρίζεται μετατροπές όπου ο τύπος προορισμού μπορεί πάντα να φιλοξενήσει την τιμή προέλευσης.

```rust
fn main() {
    let my_u8: u8 = 10;
    let my_felt252: felt252 = my_u8.into(); // Infallible conversion
    let my_u256: u256 = my_felt252.into(); // Conversion to larger types
}
```

## Χρήση του `TryInto`

Το `TryInto` προορίζεται για περιπτώσεις όπου η μετατροπή μπορεί να αποτύχει, επιστρέφοντας `Option<T>`.

```rust
fn main() {
    let my_u256: u256 = 10;
    let my_felt252: felt252 = my_u256.try_into().unwrap(); // Success
    let my_large_u16: u16 = 2048;
    let my_large_u8: u8 = my_large_u16.try_into().unwrap(); // Panics because value doesn't fit in `u8`
}
```

## Μετατροπή Προσαρμοσμένων Τύπων

Μπορείς να υλοποιήσεις αυτά τα trait για δικούς σου τύπους.  

### Παράδειγμα: `Into`

```rust
#[derive(Drop)]
struct Rectangle {
    width: u64,
    height: u64,
}

#[derive(Drop)]
struct Square {
    side_length: u64,
}

impl SquareIntoRectangle of Into<Square, Rectangle> {
    fn into(self: Square) -> Rectangle {
        Rectangle { width: self.side_length, height: self.side_length }
    }
}
```

### Παράδειγμα: `TryInto`

```rust
impl RectangleIntoSquare of TryInto<Rectangle, Square> {
    fn try_into(self: Rectangle) -> Option<Square> {
        if self.height == self.width {
            Option::Some(Square { side_length: self.height })
        } else {
            Option::None
        }
    }
}
```

Αυτή η διάταξη παρέχει ευέλικτες και ασφαλείς ως προς τον τύπο μετατροπές, τόσο για ενσωματωμένους όσο και για προσαρμοσμένους τύπους στον Cairo.
