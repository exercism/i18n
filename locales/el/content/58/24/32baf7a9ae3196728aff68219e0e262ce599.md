# Συμβολοσειρά

Ο τύπος δεδομένων `String` είναι μια γραμμική ακολουθία χαρακτήρων κωδικοποιημένων σε UTF-8. Είναι χρήσιμος για την αποθήκευση κειμενικών δεδομένων.

## Δημιουργία συμβολοσειράς

Μια συμβολοσειρά μπορεί να δημιουργηθεί με τις συσχετισμένες συναρτήσεις `String::new()` ή `String::from()`. Πολλοί τύποι έχουν μια μέθοδο `to_string` που παράγει μια συμβολοσειρά, π.χ. από έναν αριθμό.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### Το macro `format!`

Επειδή η παραγωγή μιας μεγάλης συμβολοσειράς από μια επιλογή μικρότερων τύπων δεδομένων είναι μια συνηθισμένη λειτουργία, η Rust έχει επίσης έναν σύντομο τρόπο γραφής που παραλείπει τις λεπτομέρειες της κλήσης του `to_string`: το macro `format!`. Για παράδειγμα, θα μπορούσαμε να απλοποιήσουμε την κατασκευή της σύνθετης συμβολοσειράς παραπάνω ως εξής:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## Τμήματα συμβολοσειράς

Οι συμβολοσειρές έχουν στενή σχέση με τα τμήματα συμβολοσειράς. Τα τμήματα συμβολοσειράς είναι αμετάβλητες αναφορές σε μια περιοχή μνήμης γνωστού μεγέθους, που περιέχει μια γραμμική ακολουθία χαρακτήρων κωδικοποιημένων σε UTF-8. Οποιαδήποτε συμβολοσειρά μπορεί να μετατραπεί σε τμήμα συμβολοσειράς με δανεισμό μέσω του τελεστή αποαναφοράς (`&`). Για να μετατρέψεις ένα τμήμα συμβολοσειράς σε συμβολοσειρά, τόσο η μέθοδος `to_string()` όσο και η `String::from` είναι κατάλληλες.

Στον κώδικα Rust, μια κυριολεκτική συμβολοσειρά περικλείεται σε διπλά εισαγωγικά. Αυτές οι κυριολεκτικές συμβολοσειρές είναι πάντα τμήματα συμβολοσειράς, επειδή αναφέρονται σε μια αμετάβλητη περιοχή μνήμης μέσα στο εκτελέσιμο του προγράμματος.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Μεταβολή μιας συμβολοσειράς

Για να συνενώσεις έναν μεμονωμένο χαρακτήρα σε μια συμβολοσειρά, χρησιμοποίησε τη μέθοδο `push`. Για να συνενώσεις ένα τμήμα συμβολοσειράς σε μια συμβολοσειρά, χρησιμοποίησε τη μέθοδο `push_str` ή τον τελεστή `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Πρόσβαση στους χαρακτήρες μιας συμβολοσειράς

Επειδή οι συμβολοσειρές της Rust είναι κωδικοποιημένες σε UTF-8, οι επιμέρους χαρακτήρες δεν έχουν όλοι το ίδιο μέγεθος. Γι' αυτό ο τύπος δεδομένων `String` δεν παρέχει τελεστή ευρετηρίασης (`[]`). Για να έχεις πρόσβαση σε όλους τους χαρακτήρες ή σε έναν συγκεκριμένο χαρακτήρα μιας συμβολοσειράς, μπορείς να χρησιμοποιήσεις τη μέθοδο `chars()`. Αυτή διατρέχει διαδοχικά κάθε χαρακτήρα της συμβολοσειράς.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```

## Περισσότερα

Η `String` είναι ένας πλούσιος τύπος δεδομένων με αρκετές μεθόδους και macros γύρω της. Ρίξε μια ματιά στην [τεκμηρίωση της τυπικής βιβλιοθήκης](https://doc.rust-lang.org/std/string/struct.String.html) για όλες τις μεθόδους-μέλη και τις λειτουργίες που παρέχει η `String`.
