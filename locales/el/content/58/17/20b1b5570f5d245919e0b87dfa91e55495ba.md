# μη αναμενόμενη υποχρεωτική παράμετρος

Η παράμετρος \`${'parameter.name'}\` καλείται στα τεστ και με τιμή και χωρίς τιμή, αλλά _δεν έχει σημανθεί ως προαιρετική_, που σημαίνει ότι τα τεστ δεν θα περάσουν. Μια παράμετρος TypeScript μπορεί να σημανθεί ρητά ως προαιρετική χρησιμοποιώντας το επίθεμα `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

Ή, εναλλακτικά, ορίζοντας μια προεπιλεγμένη τιμή:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
