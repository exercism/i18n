# Παράρτημα οδηγιών

## Υλοποίηση

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να ορίσεις τον τύπο δεδομένων `Clock`, να προσθέσεις ένα στιγμιότυπο `BEq` και ένα στιγμιότυπο `ToString`, και να υλοποιήσεις τις συναρτήσεις:

* `create`, που παίρνει δύο ακέραιους, ενδεχομένως αρνητικούς, που αντιπροσωπεύουν ώρες και λεπτά αντίστοιχα, και δημιουργεί ένα έγκυρο Clock.
* `add`, που παίρνει ένα Clock και έναν αριθμό λεπτών που θα προστεθούν στην ώρα του Clock, δημιουργώντας ένα νέο Clock.
* `subtract`, που παίρνει ένα Clock και έναν αριθμό λεπτών που θα αφαιρεθούν από την ώρα του Clock, δημιουργώντας ένα νέο Clock.

Σημείωσε ότι ο τύπος Clock αντιπροσωπεύει ένα ρολόι 24 ωρών που πηγαίνει από "00:00" έως "23:59".

~~~~exercism/advanced
Σημείωσε ότι τόσο οι ώρες όσο και τα λεπτά σε ένα `Clock` έχουν όρια:

- `0 <= hour < 24`
- `0 <= minute < 60`

Είναι ιδιωματικό στη Lean να αναπαριστάς τέτοιους περιορισμούς στο επίπεδο του τύπου, ώστε οι μη έγκυρες τιμές να είναι _μη αναπαραστάσιμες_.
Ωστόσο, αυτό απαιτεί επίσης να _αποδείξεις_ ότι μια δεδομένη τιμή ικανοποιεί αυτούς τους περιορισμούς.
