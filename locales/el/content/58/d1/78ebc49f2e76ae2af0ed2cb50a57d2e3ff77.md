# Εισαγωγή

Ένα *disjoint set* (δομή union-find) κρατά μια συλλογή τιμών χωρισμένη σε μη επικαλυπτόμενες ομάδες και απαντά γρήγορα σε μία ερώτηση: βρίσκονται αυτές οι δύο τιμές στην ίδια ομάδα; Βρίσκεται στο λεξιλόγιο [`disjoint-sets`][disjoint-sets].

## Δημιουργία ενός disjoint set

Το `<disjoint-set>` δημιουργεί μια κενή δομή. Οι τιμές, τα *άτομα*, προστίθενται με το `add-atom` μία κάθε φορά, ή με το `add-atoms` από μια ακολουθία. Κάθε άτομο ξεκινά σε μια ομάδα μόνο του.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

Το disjoint set είναι *μεταβλητό*: το `add-atom`, το `add-atoms` και το `equate` το αλλάζουν επιτόπου αντί να επιστρέφουν ένα νέο. Το `keep` είναι χρήσιμο όταν θέλεις το disjoint set πίσω στη στοίβα αφού μία από αυτές τις λέξεις το έχει καταναλώσει.

## Συγχώνευση ομάδων

Το `equate` ενώνει τις δύο ομάδες που περιέχουν τα άτομά του. Η ένωση είναι μεταβατική: εξίσωσε δύο άτομα και μετά ένα από αυτά με ένα τρίτο, και τα τρία καταλήγουν σε μία ομάδα.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Αντιπρόσωποι

Κάθε ομάδα έχει ένα κανονικό μέλος, τον *αντιπρόσωπό* της. Το `representative` επιστρέφει τον αντιπρόσωπο, και δύο άτομα ανήκουν στην ίδια ομάδα ακριβώς όταν οι αντιπρόσωποί τους είναι ίσοι.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Το ποιο άτομο επιλέγει μια ομάδα ως αντιπρόσωπό της είναι εσωτερική λεπτομέρεια. Μην βασίζεσαι ποτέ στο ότι θα επιλεγεί ένα συγκεκριμένο άτομο, μόνο στο ότι δύο άτομα στην ίδια ομάδα συμφωνούν.
