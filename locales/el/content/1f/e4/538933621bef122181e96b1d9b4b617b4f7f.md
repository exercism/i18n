# Εισαγωγή

## Λεξικά

Ένα λεξικό είναι μια συλλογή στοιχείων, όπου κάθε στοιχείο αποτελείται από ένα κλειδί και μια τιμή, με τέτοιον τρόπο ώστε αν περάσεις ένα κλειδί σε μια μέθοδο του λεξικού, να επιστρέφεται η τιμή που του αντιστοιχεί. Έχει τον ίδιο ρόλο με τους χάρτες ή τους συσχετιστικούς πίνακες σε άλλες γλώσσες.

Ένα λεξικό μπορεί να δημιουργηθεί ως εξής:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ή

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Σημείωσε ότι οι τύποι του κλειδιού και της τιμής αποτελούν μέρος του ορισμού του λεξικού.

Μόλις δημιουργηθεί ένα λεξικό, μπορείς να προσθέσεις ή να αφαιρέσεις καταχωρήσεις χρησιμοποιώντας τις ενσωματωμένες μεθόδους `Add` και `Remove`.

Η ανάκτηση ή η ενημέρωση τιμών σε ένα λεξικό γίνεται με πρόσβαση στο λεξικό μέσω κλειδιού:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Μπορείς να ελέγξεις αν υπάρχει μια τιμή στο λεξικό με:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Η απαρίθμηση ενός λεξικού απαριθμεί τα ζεύγη κλειδιού/τιμής του. Τα λεξικά έχουν επίσης ιδιότητες που σου επιτρέπουν να απαριθμήσεις τα κλειδιά ή τις τιμές τους.
