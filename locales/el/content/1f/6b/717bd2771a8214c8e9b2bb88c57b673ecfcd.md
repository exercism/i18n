# Οδηγίες

Η βιβλιοθήκη του Luton είναι μια μεγάλη βιβλιοθήκη με μια μεγάλη συλλογή λογοτεχνίας, που περιλαμβάνει από βιβλία μέχρι τέχνη.
Η βιβλιοθήκη έχει ένα τμήμα όπου μελετούν τη λογοτεχνία και προσθέτουν βιβλία στο σύστημα του υπολογιστή.

Κάποια κομμάτια στοχεύουν να αυτοματοποιηθούν και σου ζητείται να βοηθήσεις.
Αυτό περιλαμβάνει από την αυτοματοποίηση των φορμών της διαδικασίας εγγραφής μέχρι τη βοήθεια στην αποκρυπτογράφηση κειμένων.

## 1. Βρες το πρώτο γράμμα του τίτλου

Τα βιβλία μιας βιβλιοθήκης υποτίθεται ότι είναι εύκολο να βρεθούν, γι' αυτό ταξινομούνται με βάση το πρώτο γράμμα του τίτλου.

Υλοποίησε τη μέθοδο `Library.first_letter`, η οποία παίρνει ένα όρισμα `title`, που περιέχει τον τίτλο του βιβλίου.
Η μέθοδος πρέπει να επιστρέφει το πρώτο γράμμα του τίτλου.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Βρες τα αρχικά του συγγραφέα

Η βιβλιοθήκη έχει πολλά βιβλία γραμμένα από διαφορετικούς συγγραφείς.
Οι συγγραφείς αναφέρονται συχνά με τα αρχικά τους, γι' αυτό η βιβλιοθήκη ζήτησε ένα σύστημα που δίνει τα αρχικά του συγγραφέα εισάγοντας το όνομα και το επώνυμο του συγγραφέα.
Τα αρχικά πρέπει να έχουν τη μορφή: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Υλοποίησε τη μέθοδο `Library.initials` που παίρνει δύο ορίσματα `first_name` και `last_name`, τα οποία περιέχουν το όνομα και το επώνυμο του συγγραφέα.
Η μέθοδος πρέπει να επιστρέφει τα αρχικά του συγγραφέα.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Αποκρυπτογράφησε ένα γράμμα

Κάποια λογοτεχνία είναι κρυπτογραφημένη και η βιβλιοθήκη έχει πολλά κρυπτογραφημένα κείμενα.
Η βιβλιοθήκη θα ήθελε ένα νέο σύστημα αποκρυπτογράφησης για ειδική κρυπτογράφηση.

Η κρυπτογράφηση λειτουργεί παίρνοντας το γράμμα και αντικαθιστώντας το με το γράμμα που προηγείται στο αλφάβητο.
Για παράδειγμα, το `a` γίνεται `z`, το `b` γίνεται `a`, το `c` γίνεται `b`, και ούτω καθεξής.

Η βιβλιοθήκη θα ήθελε να μπορεί να αποκρυπτογραφεί και κεφαλαία και πεζά γράμματα, διατηρώντας την ίδια γραφή με το αρχικό γράμμα.

Υλοποίησε τη μέθοδο `Library.decrypt_character`, η οποία παίρνει ένα όρισμα `character`, που περιέχει το γράμμα προς αποκρυπτογράφηση.
Η μέθοδος πρέπει να επιστρέφει το αποκρυπτογραφημένο γράμμα.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Αποκρυπτογράφησε ένα κείμενο

Η βιβλιοθήκη θα ήθελε επίσης να αποκρυπτογραφεί ένα ολόκληρο κείμενο, με την κρυπτογράφηση που παίρνει το προηγούμενο γράμμα στο αλφάβητο.

Ο αποκρυπτογραφητής πρέπει να αποκρυπτογραφεί μόνο γράμματα και να αφήνει όλους τους άλλους χαρακτήρες ως έχουν.

Υλοποίησε τη μέθοδο `Library.decrypt_text`, η οποία παίρνει ένα όρισμα `text`, που περιέχει το κείμενο προς αποκρυπτογράφηση.
Η μέθοδος πρέπει να επιστρέφει το αποκρυπτογραφημένο κείμενο.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
