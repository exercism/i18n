Οι παίκτες θα περιπλανηθούν στον χάρτη μαζεύοντας θησαυρούς στην πορεία.
Οι τοποθεσίες των θησαυρών και των μέρων έχουν διαφορετική μορφή, για να προσθέσουν μια επιπλέον πρόκληση.
Υπάρχουν επίσης κάποια ειδικά μέρη, όπου ορισμένοι θησαυροί μπορούν να ανταλλαχθούν με κάποιους άλλους, για να προσθέσουν μια επιπλέον ανατροπή στο παιχνίδι.
Η δουλειά σου είναι να γράψεις συναρτήσεις που θα τους βοηθήσουν με το παιχνίδι τους.

## 1. Μετάτρεψε τις τοποθεσίες

Υλοποίησε τη συνάρτηση `placeLocationToTreasureLocation` που παίρνει μια τοποθεσία μέρους (όπως `('C', 1)`) και τη μετατρέπει σε τοποθεσία θησαυρού (όπως `(1, 'C')`).

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. Σύγκρινε τοποθεσίες θησαυρού και μέρους

Υλοποίησε τη συνάρτηση `treasureLocationMatchesPlaceLocation` που παίρνει μια `PlaceLocation` (όπως `('C', 1)`) και επιστρέφει την τιμή αληθής αν ταιριάζει με μια `TreasureLocation` (όπως `(1, 'C')`).

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. Μέτρησε τις τοποθεσίες θησαυρού

Υλοποίησε τη συνάρτηση `countPlaceTreasures`, που παίρνει ένα μέρος (όπως `("Aqua Lagoon (Island of Mystery)", ('F', 1))`) και τη λίστα με τους θησαυρούς, και επιστρέφει τον αριθμό των θησαυρών που μπορούν να βρεθούν εκεί.

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. Ειδικά μέρη

Υλοποίησε τη συνάρτηση `specialCaseSwapPossible`, που παίρνει έναν θησαυρό (όπως `("Amethyst Octopus", (1, 'F'))`) και ένα μέρος (όπως `("Seaside Cottages ", ('C', 1))`), και επιστρέφει την τιμή αληθής για τους παρακάτω συνδυασμούς:

- Το Brass Spyglass μπορεί να ανταλλαχθεί με οποιονδήποτε άλλο θησαυρό στο Abandoned Lighthouse
- Το Amethyst Octopus μπορεί να ανταλλαχθεί με το Crystal Crab ή το Glass Starfish στο Stormy Breakwater
- Το Vintage Pirate Hat μπορεί να ανταλλαχθεί με το Model Ship in Large Bottle ή το Antique Glass Fishnet Float στο Harbor Managers Office

Προσπάθησε να υλοποιήσεις αυτή τη συνάρτηση ως εντολή case με μια ad hoc πλειάδα, αντί να χρησιμοποιήσεις εντολές if (αυτό είναι ένα κοινό ιδίωμα στην Elm).
