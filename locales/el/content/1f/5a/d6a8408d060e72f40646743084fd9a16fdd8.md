# Null

Το null είναι ένας πρωτογενής τύπος τιμής με μία μόνο τιμή: `null`.
Το null χρησιμοποιείται συχνά για να αναπαραστήσει το τίποτα.
Θεωρείται "falsey", αλλά διαφέρει από το `false` και από τις άλλες falsey τιμές.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Δουλεύοντας με τιμές null

Στην PHP, οι τιμές null μπορούν να αποτελέσουν συχνή αιτία σφάλματος, καθώς συχνά επιστρέφονται στη θέση μιας κατάστασης σφάλματος ή για να αναπαραστήσουν το τίποτα.
Για να μην προκύπτουν σφάλματα, συχνά χρειάζεται να κάνεις "έλεγχο για null", ώστε να βεβαιωθείς ότι η τιμή δεν είναι null πριν την επεξεργαστείς.

Ο συνεχής έλεγχος για null μπορεί να είναι επιρρεπής σε λάθη, γι' αυτό η PHP παρέχει δύο τελεστές για να δουλεύεις με τιμές null: τον τελεστή ασφαλούς πρόσβασης `?->` και τον τελεστή συνένωσης null `??`.
