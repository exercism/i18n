# Βασικά στοιχεία σύνταξης Haskell

## Σταθερές και συναρτήσεις

Τα προγράμματα Haskell αποτελούνται από ορισμούς και εκφράσεις.

Μια σταθερή τιμή ορίζεται με `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Οι συναρτήσεις ορίζονται με `name parameters... = expression`, με τις παραμέτρους να χωρίζονται μόνο με κενό.

```haskell
add number1 number2 = number1 + number2
```

Η κλήση μιας συνάρτησης είναι επίσης μια έκφραση και γίνεται καθορίζοντας το όνομά της και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης, χωρισμένα με κενά, όπως ακριβώς και στους ορισμούς συναρτήσεων.

```haskell
five = add 2 3
```

Οι παρενθέσεις μπορούν να χρησιμοποιηθούν για να καθορίσουν τη σειρά αξιολόγησης μιας έκφρασης.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Εσοχή / σημαντικά κενά

Η Haskell χρησιμοποιεί κενά και εσοχή για να καθορίσει τα όρια του κώδικα.
***Ο κώδικας που αποτελεί μέρος κάποιας έκφρασης θα πρέπει να έχει μεγαλύτερη εσοχή από την αρχή αυτής της έκφρασης.***

- Οι ορισμοί module, import και συναρτήσεων ανώτατου επιπέδου πρέπει να ξεκινούν στην πιο αριστερή στήλη.
- Αν μια έκφραση χωριστεί σε πολλές γραμμές, ο κώδικας που αποτελεί μέρος αυτής της έκφρασης πρέπει να έχει εσοχή κάτω από αυτήν την έκφραση με τουλάχιστον ένα κενό.
- Τα μέρη της έκφρασης που ομαδοποιούνται μαζί θα πρέπει να έχουν εσοχή με ίσο αριθμό κενών.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Modules

Τα modules εξάγουν συναρτήσεις.
Αυτό σημαίνει ότι μπορείς να χρησιμοποιήσεις τις συναρτήσεις που το module καθιστά διαθέσιμες στη δήλωση εξαγωγής του.
Ένα module μπορεί επίσης να ορίσει συναρτήσεις μόνο για εσωτερική χρήση.
Από προεπιλογή, οι συναρτήσεις που δεν έχουν εξαχθεί ρητά δεν μπορούν να χρησιμοποιηθούν από έξω από το module.

Στην αρχή ενός module, καθορίζουμε το όνομα του module.
Αν έχουμε ένα αρχείο που ονομάζεται Calculator.hs, τότε θα πρέπει να ονομάσουμε το module μας Calculator.
Στη συνέχεια, καθορίζουμε τις συναρτήσεις που εξάγει και μετά από αυτό, μπορούμε να αρχίσουμε να γράφουμε τις συναρτήσεις.
Ας ξεκινήσουμε λοιπόν με αυτό.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Σχόλια

Ένα σχόλιο είναι κάποιο κείμενο μέσα στο αρχείο Haskell που δεν διερμηνεύεται ως κώδικας.
Προορίζεται κυρίως για να το διαβάζεις εσύ και άλλοι προγραμματιστές.
Υπάρχει μια ελαφριά σύνταξη για σχόλια μίας γραμμής, βασισμένη σε διπλές παύλες.
Τα σχόλια πολλών γραμμών είναι επίσης δυνατά με το ζεύγος `{-` και `-}` ως οριοθέτες ανοίγματος και κλεισίματος.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
