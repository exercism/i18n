# Σχετικά

Οι `while` και `until` (στο [`kernel`][kernel]) είναι συνδυαστές βρόχων που βασίζονται σε παραθέσεις, για την περίπτωση που δεν ξέρεις από πριν τον αριθμό των επαναλήψεων:

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

Ο `while` συνεχίζει όσο η `pred` αφήνει μια τιμή που αξιολογείται ως αληθής. Ο `until` συνεχίζει όσο η `pred` αφήνει `f`. Και οι δύο σταματούν και επιστρέφουν όταν αντιστραφεί το κατηγόρημά τους.

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

Όταν μια μόνο τιμή που κυλάει στη στοίβα δεν αρκεί ως κατάσταση, ας πούμε μια λίστα που απομένει, ένα τρέχον άθροισμα και ένας μετρητής, όλα μαζί, το πιο καθαρό μοτίβο είναι να χρησιμοποιήσεις τοπικές μεταβλητές με όνομα για σαφήνεια. Οι τοπικές μεταβλητές παρουσιάζονται πιο αναλυτικά αργότερα στο πρόγραμμα σπουδών. Εδώ αρκεί να ξέρεις ότι το `:: word ( a b -- c )` δηλώνει τις εισόδους ως τοπικές μεταβλητές με όνομα, και ότι το `:> name!` προσθέτει μια τοπική μεταβλητή που μπορεί να αλλάξει και που το σώμα μπορεί να ενημερώσει με `value name!`.

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
