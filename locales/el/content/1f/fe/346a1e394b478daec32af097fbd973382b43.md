# Υποδείξεις

## Γενικά

- Ρίξε μια ματιά στις [συναρτήσεις που είναι διαθέσιμες στην _ενότητα συμβολοσειράς_][string-module-functions] για να ανακαλύψεις ποιες λειτουργίες σε συμβολοσειρές προσφέρει η βασική βιβλιοθήκη της Gleam.

## 1. Πάρε το πρώτο γράμμα του ονόματος

- Υπάρχει μια [συνάρτηση][string-first] για να πάρεις τον πρώτο χαρακτήρα από μια συμβολοσειρά.
- Υπάρχουν πολλές [συναρτήσεις][string-trim] που αφαιρούν κενά διαστήματα από την αρχή, το τέλος ή και από τα δύο άκρα μιας συμβολοσειράς.

## 2. Μορφοποίησε το πρώτο γράμμα ως αρχικό

- Υπάρχει μια [συνάρτηση][string-upcase] για να μετατρέπεις όλους τους χαρακτήρες μιας συμβολοσειράς στη μορφή κεφαλαίων τους.
- Ο τελεστής `<>` μπορεί να χρησιμοποιηθεί για τη συνένωση συμβολοσειρών.

## 3. Χώρισε το πλήρες όνομα σε όνομα και επώνυμο

- Υπάρχει μια [συνάρτηση][string-split] που χωρίζει μια συμβολοσειρά με βάση τους χαρακτήρες κενού.
- Μπορείς να εκχωρήσεις μερικά από τα πρώτα στοιχεία μιας λίστας σε μεταβλητές με αντιστοίχιση προτύπων στη λίστα.

## 4. Βάλε τα αρχικά μέσα στην καρδιά

- Ο τελεστής `<>` μπορεί να χρησιμοποιηθεί για τη συνένωση συμβολοσειρών.
