# Σχετικά

Η PHP είναι μια γλώσσα για την πλευρά του διακομιστή, ιδανική για ανάπτυξη ιστού. Το αρκτικόλεξο είναι αναδρομικό και σημαίνει _PHP: Hypertext Preprocessor_.

Η PHP είναι πολύ πιο ευέλικτη από το CGI scripting και χρησιμοποιείται συχνά για να προσθέσει διαδραστικότητα σε απλό HTML και να ενισχύσει τα web frameworks.

Η γλώσσα μπορεί να χρησιμοποιηθεί σε οποιοδήποτε λειτουργικό σύστημα. Η PHP υποστηρίζεται από τους πιο διαδεδομένους διακομιστές ιστού και συχνά εκτελείται μέσω μιας μονάδας διερμηνευτή. Έτσι συνδυάζεται στατικός κώδικας ιστού με δυναμικές ενσωματώσεις.

Η PHP δεν είναι μόνο ένα framework για διακομιστές ιστού. Είναι επίσης χρήσιμη για scripting στη γραμμή εντολών (ανάλυση χωρίς γραφικό περιβάλλον) και για την ανάπτυξη γραφικών περιβάλλοντων χρήστη.

Αξίζει να μάθεις PHP, γιατί:

- είναι μια γλώσσα ανοιχτού κώδικα
- έχει καλή τεκμηρίωση και υποστήριξη
- είναι συμβατή με τους πιο διαδεδομένους διακομιστές ιστού
- είναι εύκολη για να ξεκινήσεις να μαθαίνεις
- είναι εξαιρετικά κλιμακώσιμη και επεκτάσιμη
