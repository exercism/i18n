# Οδηγίες

Το να καλείς API είναι σημαντικό κομμάτι του να γράφεις κώδικα στο διαδίκτυο. Σε αυτή την άσκηση, θα χρειαστεί να ανακτήσεις δεδομένα από ένα endpoint και να βεβαιωθείς ότι ανακτήθηκαν με επιτυχία.

## Στόχοι

- Τροποποίησε τον κώδικα που σου δίνεται.
- Κάλεσε τον HTTP client και προσπάθησε να ανακτήσεις ένα ρητό. Το αποτέλεσμα αυτό θα πρέπει να είναι ένας τύπος ένωσης που αποτελείται από `string` και `error`.
- Αν το ρητό ανακτηθεί, εκτύπωσέ το στην κονσόλα (χρησιμοποιώντας το `io:println()`).
- Αν έχει προκύψει ένα `error`, εκτύπωσε το μήνυμα σφάλματος στην κονσόλα.
