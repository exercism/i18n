# Εισαγωγή

Στην Python, το `None` χρησιμοποιείται συχνά για να αναπαραστήσει την απουσία μιας τιμής: μια τιμή που κρατά τη θέση για να ορίσεις μια `null` (κενή) μεταβλητή, αντικείμενο ή όρισμα.

Αν έχεις ακούσει ή έχεις χρησιμοποιήσει έναν τύπο `NULL` ή `nil` σε κάποια άλλη γλώσσα προγραμματισμού, τότε αυτή η χρήση του `None` στην Python θα σου είναι οικεία.
Το `None` σε βοηθά να δηλώσεις μεταβλητές ή ορίσματα συνάρτησης χωρίς ακόμα τιμές.
Στη συνέχεια, μπορείς να εκχωρήσεις ξανά συγκεκριμένες τιμές σε αυτά αργότερα, αν χρειαστεί:


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

Το `None` θα αξιολογηθεί ως `False` όταν χρησιμοποιείται σε έλεγχο συνθήκης, οπότε είναι χρήσιμο για να επικυρώσεις την "παρουσία" ή την "απουσία" μιας τιμής, _οποιασδήποτε_ τιμής, ένα μοτίβο που χρησιμοποιείται συχνά όταν μια συνάρτηση ή μια διεργασία μπορεί να επιστρέψει ένα `error`, ένα `object` ή ένα μήνυμα.

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
