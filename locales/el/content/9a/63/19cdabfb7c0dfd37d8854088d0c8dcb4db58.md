# Σχετικά

Μια παράμετρος μιας μεθόδου μπορεί να γίνει προαιρετική, αν της αναθέσεις μια προεπιλεγμένη τιμή. Όταν μια παράμετρος είναι προαιρετική, εκείνος που καλεί τη μέθοδο δεν είναι υποχρεωμένος να δώσει όρισμα για αυτήν την παράμετρο, οπότε χρησιμοποιείται η προεπιλεγμένη τιμή. Οι [προαιρετικές παράμετροι][optional-arguments] _πρέπει_ να βρίσκονται στο τέλος της λίστας παραμέτρων. Δεν μπορούν να ακολουθούνται από μη προαιρετικές παραμέτρους. Αν μια μέθοδος έχει πολλαπλές προαιρετικές παραμέτρους, μπορείς να ορίσεις μόνο μερικές από αυτές χρησιμοποιώντας [ονομαστά ορίσματα][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

Η τιμή μιας προαιρετικής παραμέτρου πρέπει να είναι μία από τις εξής:

- Μια σταθερή έκφραση (π.χ. `"hi"`, `2`, `DayOfWeek.Friday`, `null` κ.λπ.)
- Μια έκφραση `new` ενός τύπου τιμής
- Μια έκφραση `default` ενός τύπου τιμής
