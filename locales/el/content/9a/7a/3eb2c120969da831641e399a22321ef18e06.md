# Σχετικά

## Οι βρόχοι `for`

Μια εντολή `for` επαναλαμβάνει ένα μπλοκ κώδικα.
Η πρώτη της γραμμή ελέγχει πόσες φορές θα επαναληφθεί το μπλοκ:

```go
for init; condition; post {
    // loop body
}
```

- Η εντολή **init** εκτελείται μία φορά πριν από την πρώτη επανάληψη. Συνηθίζεται να δηλώνεις και να αρχικοποιείς μια μεταβλητή μετρητή που χρησιμοποιεί ο βρόχος.
- Η **condition** είναι μια έκφραση boolean που αξιολογείται πριν από κάθε επανάληψη. Ο βρόχος σταματά όταν αυτή αξιολογηθεί σε `false`.
- Η εντολή **post** εκτελείται μετά από κάθε ολοκληρωμένη επανάληψη. Μπορεί να χρησιμοποιηθεί για να ενημερώσεις έναν μετρητή.

Μην βάζεις παρενθέσεις γύρω από το `init; condition; post`.
Ωστόσο, τα άγκιστρα `{ }` γύρω από το σώμα του βρόχου είναι πάντα απαραίτητα.

Αυτός ο βρόχος ξεκινά το `i` από το `1`, εκτυπώνει την τρέχουσα τιμή του `i`, αυξάνει την τιμή του για την επόμενη επανάληψη και σταματά όταν το `i` φτάσει στο `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Άλλες μορφές βρόχων

### Βρόχος μόνο με συνθήκη

Οι εντολές init και post μπορούν να παραλειφθούν.
Μια εντολή `for` με μόνο μια συνθήκη εξυπηρετεί τον ίδιο σκοπό με έναν βρόχο `while` σε άλλες γλώσσες.
Η Go δεν έχει λέξη-κλειδί `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Άπειρος βρόχος

Μια εντολή `for` μπορεί να γραφτεί χωρίς συνθήκη:

```go
for {
    // loop body
}
```

Αυτός ο βρόχος δεν τερματίζεται από μόνος του.
Η εκτέλεση πρέπει να βγει από τον βρόχο ρητά, για παράδειγμα με `break` ή `return`.

## Έλεγχος των βρόχων

### Break και Continue

Σε αυτόν τον βρόχο, το `break` βγαίνει από τον βρόχο:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

Το `continue` παραλείπει το υπόλοιπο σώμα του τρέχοντος βρόχου και ξεκινά την επόμενη επανάληψη:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### Break και Continue με ετικέτες

Με εμφωλευμένους βρόχους, ένα `break` ή `continue` χωρίς ετικέτα εφαρμόζεται στον πιο εσωτερικό βρόχο.
Βάλε ετικέτα σε έναν βρόχο που τον περικλείει τοποθετώντας ένα αναγνωριστικό ακολουθούμενο από άνω και κάτω τελεία στην αμέσως προηγούμενη γραμμή.
Έπειτα γράψε την ετικέτα του βρόχου μετά το `break` ή το `continue` για να κατευθύνεις την ενέργεια σε εκείνον:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
