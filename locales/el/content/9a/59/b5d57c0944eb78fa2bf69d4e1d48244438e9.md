# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά επισκέφτηκαν τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις έξι εργασίες, που όλες ασχολούνται με τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Για λόγους σύγκρισης, κρατάς πάντα κοντά σου ένα αντίγραφο των μετρήσεων της προηγούμενης εβδομάδας, οι οποίες ήταν: 0, 2, 5, 3, 7, 8 και 4. Όρισε τη δέσμευση `lastWeek` που περιέχει τις μετρήσεις της προηγούμενης εβδομάδας:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν χθες

Υλοποίησε τη συνάρτηση `yesterday` ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου χθες. Οι μετρήσεις των πουλιών είναι ταξινομημένες ανά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο να είναι η σημερινή μέτρηση.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Υπολόγισε τον συνολικό αριθμό των πουλιών που επισκέφτηκαν τον κήπο

Υλοποίησε τη συνάρτηση `total` ώστε να επιστρέφει τον συνολικό αριθμό των πουλιών που έχουν επισκεφτεί τον κήπο σου:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη συνάρτηση `dayWithoutBirds` που επιστρέφει `true` αν υπήρξε μέρα κατά την οποία κανένα πουλί δεν επισκέφτηκε τον κήπο· διαφορετικά, επέστρεψε `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Αύξησε τη σημερινή μέτρηση

Υλοποίησε τη συνάρτηση `incrementTodaysCount` ώστε να αυξάνει τη σημερινή μέτρηση και να επιστρέφει τις ενημερωμένες μετρήσεις:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Έλεγξε για μια ασυνήθιστη εβδομάδα

Τον τελευταίο χρόνο, έχεις παρατηρήσει ότι κάποιες εβδομάδες έχουν τα ίδια, ασυνήθιστα μοτίβα:
- Σε κάθε άρτια ημέρα της εβδομάδας, δεν υπήρχαν πουλιά
- Σε κάθε άρτια ημέρα της εβδομάδας, εντοπίστηκαν ακριβώς 10 πουλιά
- Σε κάθε περιττή ημέρα της εβδομάδας, εντοπίστηκαν ακριβώς 5 πουλιά

Υλοποίησε τη συνάρτηση `unusualWeek` που επιστρέφει `true` αν το μοτίβο των μετρήσεων πουλιών αυτής της εβδομάδας ταιριάζει με ένα από τα ασυνήθιστα μοτίβα:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Σημείωσε ότι η αρίθμηση των ημερών ξεκινά από το 1, όχι από το 0: το πρώτο στοιχείο του πίνακα αντιστοιχεί σε περιττή ημέρα)
