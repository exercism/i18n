# Σχόλιο TODO

Φαίνεται ότι άφησες κάποια σχόλια "TODO" ή "FIXME" στον κώδικα σου.

Αυτά τα σχόλια είναι ιδανικά για να σου θυμίζουν τι ήθελες να βελτιώσεις αργότερα στον κώδικα σου. Μην ξεχάσεις να κάνεις όλες αυτές τις βελτιώσεις πριν ολοκληρώσεις την άσκηση και να αφαιρέσεις τα σχόλια όταν δεν ισχύουν πια.
