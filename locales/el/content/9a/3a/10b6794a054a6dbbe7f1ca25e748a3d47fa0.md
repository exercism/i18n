# Σχετικά

Από προεπιλογή, οι μεταβλητές περιορίζονται στην εμβέλεια στην οποία ορίζονται. Αν οριστούν σε ένα αρχείο έξω από μια συνάρτηση ή μια κλάση, περιορίζονται στην εμβέλεια του αρχείου. Αν οριστούν μέσα σε μια συνάρτηση ή μια κλάση, περιορίζονται στην εμβέλεια της συνάρτησης ή της κλάσης.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Καθολική εμβέλεια

Η χρήση της λέξης-κλειδί `global` πριν από την ανάθεση μιας μεταβλητής δημιουργεί μια μεταβλητή με καθολική εμβέλεια. Αυτό το μοτίβο συχνά αποθαρρύνεται, καθώς δημιουργεί [κώδικα με στενή σύζευξη](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Στατική εμβέλεια

Η χρήση της λέξης-κλειδί `static` πριν από την ανάθεση ή τη δήλωση μιας μεταβλητής διατηρεί την εμβέλεια της μεταβλητής, αλλά η τιμή της διατηρείται μεταξύ των εμβελειών εκτέλεσης.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

Σε αυτό το παράδειγμα, η μεταβλητή `$count` αρχικοποιείται στο 0 _μόνο στην πρώτη κλήση της συνάρτησης_. Σε κάθε κλήση μετά την πρώτη, η τιμή θα περάσει στην επόμενη κλήση. Έτσι, κάθε κλήση της συνάρτησης επιστρέφει έναν ακέραιο που αυξάνεται.
