# Σχετικά

Η Bash είναι η γλώσσα που θα μάθεις να αγαπάς!

Πολλές από τις καθημερινές σου εργασίες στον υπολογιστή μπορούν να γίνουν με τα σύντομα scripts που μπορεί να παράγει. Σύντομα θα μάθεις ότι, ενώ τα περισσότερα πράγματα μπορούν να γίνουν μέσα από ένα γραφικό περιβάλλον χρήστη, μπορεί στην πραγματικότητα να είναι πολύ πιο γρήγορο να χρησιμοποιήσεις αυτή την ισχυρή γλώσσα! Ο διερμηνευτής εντολών συνήθως τρέχει σε ένα παράθυρο κειμένου, όπου οι χρήστες μπορούν να εισάγουν εντολές (οι λειτουργίες μπορούν επίσης να προέρχονται από κάποια αρχεία, γνωστά και ως scripts Bash).

Πιο επίσημα, η Bash (ακρωνύμιο του **B**ourne-**a**gain **sh**ell, ένα λογοπαίγνιο γύρω από το Bourne shell και τον όρο "born-again") είναι ένας διερμηνευτής εντολών του Unix. Προσφέρει μια σειρά από βελτιώσεις σε σχέση με αρκετά άλλα κελύφη (η Bash έχει χρήσιμες λειτουργίες όσον αφορά το ιστορικό εντολών, τον έλεγχο εργασιών και την επεξεργασία της γραμμής εντολών).

Ένας πολύ καλός τρόπος να σκεφτείς την Bash είναι ο εξής:

> Αν και οι περισσότεροι χρήστες βλέπουν το κέλυφος ως έναν διαδραστικό διερμηνευτή εντολών, στην πραγματικότητα είναι μια γλώσσα προγραμματισμού στην οποία κάθε γραμμή εκτελεί μια εντολή. Επειδή πρέπει να ικανοποιεί ταυτόχρονα τη διαδραστική και την προγραμματιστική πλευρά της εκτέλεσης εντολών, είναι μια παράξενη γλώσσα, διαμορφωμένη τόσο από την ιστορία όσο και από τον σχεδιασμό της. - Brian Kernighan και Rob Pike

_πηγή: Kernighan, Brian W.; Pike, Rob (1984). The UNIX Programming Environment. Englewood Cliffs: Prentice-Hall. ISBN 0-13-937699-2._

Αν και κυκλοφόρησε για πρώτη φορά πριν από αρκετές δεκαετίες, αφού την έγραψε ο Brian Fox του Ιδρύματος Ελεύθερου Λογισμικού, η Bash χρησιμοποιείται ακόμα καθημερινά σε όλο τον κόσμο! Από την αυτοματοποίηση μέχρι το δέσιμο ενός project, η γλώσσα είναι ακόμα τόσο ευέλικτη όσο ήταν πάντα. Ένα άλλο πλεονέκτημα της ηλικίας της γλώσσας είναι η πλούσια τεκμηρίωση που θα βρεις γύρω από αυτήν. Αν κολλήσεις κάποια στιγμή και δεν ξέρεις ακριβώς πώς να υλοποιήσεις μια άσκηση, ένα εξαιρετικό σημείο για να ξεκινήσεις είναι η ενσωματωμένη βοήθεια, διαθέσιμη μέσω της χρήσης των `info bash` ή `man bash`.

Αυτή η διαδρομή είναι για να σε βοηθήσει να αποκτήσεις λίγη εμπειρία σε αυτή την υπέροχη γλώσσα scripting.
