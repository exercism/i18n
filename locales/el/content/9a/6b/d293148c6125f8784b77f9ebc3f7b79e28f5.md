# Υποδείξεις

## Γενικά

- Φρόντισε να διαβάσεις την τεκμηρίωση για τους [αποκωδικοποιητές][decode] και τους [κωδικοποιητές][encode]
- Η [τεκμηρίωση του GitHub][github] που ενέπνευσε αυτή την άσκηση περιέχει περισσότερες πληροφορίες για τα αντικείμενα JSON
- Θα πρέπει να μπορείς να χρησιμοποιήσεις το [`Decode.decodeString`][decode-decodeString] για να δοκιμάσεις τους αποκωδικοποιητές σου σε αυθαίρετη είσοδο

## 1. Ταυτότητα, παρακαλώ!

Η εργασία μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- [`int`][decode-int]
- [`field`][decode-field]

## 2. Πώς με λένε, είπαμε;

Υπάρχουν δύο βασικοί τρόποι να λύσεις την εργασία:

- χρησιμοποιώντας το [`maybe`][decode-maybe]
- χρησιμοποιώντας το [`oneOf`][decode-oneOf] με δύο πιθανούς αποκωδικοποιητές, τον έναν με συνδυασμό των [`field`][decode-field], [`string`][decode-string], [`map`][decode-map], και τον άλλο με [`succeed`][decode-succeed]

## 3. Χρήστη; Ούτε που τον ξέρω!

Η εργασία μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- `decodeId` και `decodeName`
- `User` ως κατασκευαστής τύπου
- [`map5`][decode-map5]
- [`field`][decode-field]
- [`int`][decode-int]
- [`string`][decode-string]
- [`bool`][decode-bool]

## 4. Είμαι ένα δυνατό, ανεξάρτητο σχόλιο

Η εργασία μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- [`field`][decode-field]
- [`int`][decode-int]
- [`nullable`][decode-nullable]

## 5. Δεύτερη δουλειά

Η εργασία μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- [`field`][decode-field]
- [`string`][decode-string]
- [`andThen`][decode-andThen]
- μια εντολή case που ελέγχει το περιεχόμενο της συμβολοσειράς που αποκωδικοποιείται
- [`succeed`][decode-succeed]
- [`fail`][decode-fail]

## 6. Η αφύπνιση των συνδέσμων

Η εργασία μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- [`field`][decode-field]
- [`dict`][decode-dict]
- [`string`][decode-string]

## 7. Ναι, σχόλια

Το `decodeComment` μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- `decodeId`, `decodePullRequestReviewId`, `decodeUser`, `decodeSide`, `decodeLinks`
- `Comment` ως κατασκευαστής τύπου
- [`6`][decode-6]
- [`field`][decode-field]
- [`string`][decode-string]

Το `decodeComments` μπορεί να λυθεί με τις παρακάτω συναρτήσεις:

- `decodeComment`
- [`list`][decode-list]

## 8. Όλα δένονται

Όλες οι συναρτήσεις που απαιτούνται για αυτή την εργασία ορίζονται στην [τεκμηρίωση για τους κωδικοποιητές][encode], και ενδεχομένως μερικές από το [module `Maybe`][maybe]
