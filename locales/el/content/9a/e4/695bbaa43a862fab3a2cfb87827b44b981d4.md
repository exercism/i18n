# Εισαγωγή

Ο τύπος `Option` είναι ο μηχανισμός της γλώσσας F# για τον χειρισμό τιμών που μπορεί να υπάρχουν ή να μην υπάρχουν.
Παρέχει μια εναλλακτική, ασφαλή ως προς τους τύπους, στη χρήση του `null`, που είναι συνηθισμένη σε άλλες γλώσσες για τέτοιες τιμές.
Χρησιμοποιείται σε πολλές συναρτήσεις της πρότυπης βιβλιοθήκης της F#, οπότε η κατανόησή του είναι απαραίτητη για την αποτελεσματική χρήση της πρότυπης βιβλιοθήκης της F#.

## Χρήση 

Ο τύπος `Option` είναι ένας γενικός τύπος (έχει έναν υποκείμενο τύπο).  
Οι τιμές `Option` είναι είτε `Some value`, που αντιπροσωπεύει κάποια συγκεκριμένη τιμή, είτε `None`, που δεν αντιπροσωπεύει καμία τιμή.

Η παρακάτω συνάρτηση δείχνει πώς να δημιουργήσεις μια τιμή `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
Το `T option` είναι η μεταθεματική σύνταξη που ισοδυναμεί με το `Option<T>`; οι δύο μορφές σύνταξης μπορούν να χρησιμοποιηθούν εναλλάξ.
Ωστόσο, σύμφωνα με τον Οδηγό Στυλ της F#, η μεταθεματική σημειογραφία προτιμάται για τους τύπους `Option` (δείτε [την ενότητα του Οδηγού Στυλ της F# για τη μορφοποίηση τύπων και τις σημειώσεις τύπων](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Διαβάζοντας το περιεχόμενο μιας τιμής `Option`

Ο ιδιωματικός τρόπος για να διαβάσεις μια τιμή `Option` είναι μέσω αντιστοίχισης προτύπων, όπως φαίνεται στο παρακάτω παράδειγμα:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Ξετυλίγοντας Option με προεπιλεγμένες τιμές

Οι τιμές `Option` μπορούν να "ξετυλιχτούν" (να μετατραπούν στον τύπο που περιέχουν) παρέχοντας προεπιλεγμένες τιμές με τη συνάρτηση `Option.defaultValue`. 
Αυτό είναι ιδιαίτερα χρήσιμο όταν θέλεις να βεβαιωθείς ότι η τιμή δεν είναι `None`.
Για παράδειγμα:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
