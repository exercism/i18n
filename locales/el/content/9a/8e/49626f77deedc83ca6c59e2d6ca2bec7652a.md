# Σχετικά

Η Fortran είναι μια γενικής χρήσης, μεταγλωττισμένη, προστακτική γλώσσα προγραμματισμού.
Αναπτύχθηκε τη δεκαετία του 1950 και είναι η παλαιότερη γλώσσα προγραμματισμού υψηλού επιπέδου.
Είναι ιδιαίτερα χρήσιμη για αριθμητικούς και επιστημονικούς υπολογισμούς.

Η Fortran είναι φορητή και μπορεί να τρέξει σε σχεδόν οποιαδήποτε πλατφόρμα.
Καθώς η Fortran δίνει αξία στη σταθερότητα και στη συμβατότητα προς τα πίσω, τα προγράμματα Fortran μπορούν να λειτουργούν για δεκαετίες.

Η Fortran βελτιστοποιείται επί δεκαετίες ώστε να εκτελείται αποδοτικά, με αποτέλεσμα να κατατάσσεται σταθερά ανάμεσα στις γλώσσες με τις υψηλότερες επιδόσεις σε ενέργεια και χρόνο.
