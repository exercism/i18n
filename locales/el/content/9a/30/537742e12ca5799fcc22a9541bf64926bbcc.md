# Προσθήκη στις οδηγίες

## Δεσμευμένη μνήμη

Ο buffer για τη συμβολοσειρά εισόδου χρησιμοποιεί τα byte 64-191 της γραμμικής μνήμης.


## Μορφή εξόδου

Η σειρά των αριθμών αναμένεται ως ένας συνεχής πίνακας αριθμών u8· θα χωριστεί κατά μήκος κατά την αποσειριοποίηση:

```js
slice("123456", 3) => UInt8Array[1, 2, 3,   2, 3, 4,   3, 4, 5,   4, 5, 6]
// will be split into          [[1, 2, 3], [2, 3, 4], [3, 4, 5], [4, 5, 6]]
```
