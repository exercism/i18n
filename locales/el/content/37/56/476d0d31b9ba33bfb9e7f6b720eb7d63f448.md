# Εισαγωγή

Στον προγραμματισμό, είναι απαραίτητο να χειρίζεσαι τα σφάλματα ομαλά, ώστε οι απρόσμενες καταστάσεις να μην προκαλούν κατάρρευση του προγράμματος ή απρόβλεπτη συμπεριφορά.
Η Cairo παρέχει δύο βασικούς μηχανισμούς για τη διαχείριση σφαλμάτων:

1. **Μη ανακτήσιμα σφάλματα** με `panic`, που σταματούν αμέσως το πρόγραμμα.
2. **Ανακτήσιμα σφάλματα** με `Result`, που επιτρέπουν στο πρόγραμμα να χειρίζεται τα σφάλματα και να ανταποκρίνεται σε αυτά.

## Μη ανακτήσιμα σφάλματα με `panic`

Μερικές φορές, ένα πρόγραμμα συναντά ένα σφάλμα τόσο σοβαρό που δεν μπορεί να συνεχίσει.
Σε τέτοιες περιπτώσεις, η Cairo χρησιμοποιεί τη συνάρτηση `panic` για να σταματήσει αμέσως την εκτέλεση.
Αυτό είναι χρήσιμο όταν ένα σφάλμα, όπως η προσπάθεια πρόσβασης σε μια θέση εκτός ορίων, καθιστά αδύνατο για το πρόγραμμα να συνεχίσει λογικά.
Η συνάρτηση `panic` δέχεται ένα μήνυμα `ByteArray` που περιγράφει τον λόγο του σφάλματος.

Για παράδειγμα, στην Cairo:

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

Αυτό το παράδειγμα δείχνει ένα εξαναγκασμένο `panic`, το οποίο σταματά αμέσως το πρόγραμμα με ένα μήνυμα.

### Το μάκρο `assert!`

Το μάκρο `assert!` είναι ένα χρήσιμο εργαλείο για να επιβάλλεις συγκεκριμένες συνθήκες στον κώδικά σου.
Αν η συνθήκη στο `assert!` αξιολογηθεί σε `false`, το πρόγραμμα θα κάνει panic με ένα μήνυμα σφάλματος `ByteArray`.
Αυτό χρησιμοποιείται συχνά για να επαληθεύεις υποθέσεις κατά την ανάπτυξη και να διασφαλίζεις ότι οι τιμές πληρούν συγκεκριμένα κριτήρια.

Για παράδειγμα:

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

Αν το `x` δεν είναι μεγαλύτερο από το μηδέν, το πρόγραμμα θα κάνει panic με το μήνυμα `"x must be greater than zero"`. Το `assert!` είναι χρήσιμο για τον έλεγχο αναλλοίωτων και προϋποθέσεων χωρίς να γράφεις χειροκίνητα κώδικα διαχείρισης σφαλμάτων.

## Ανακτήσιμα σφάλματα με `Result`

Δεν χρειάζεται να σταματούν το πρόγραμμα όλα τα σφάλματα.
Κάποια μπορούν να αντιμετωπιστούν ομαλά, ώστε το πρόγραμμα να συνεχίσει.
Η απαρίθμηση `Result` της Cairo αναπαριστά αυτά τα ανακτήσιμα σφάλματα και έχει δύο παραλλαγές:

- Το `Result::Ok` δηλώνει επιτυχία.
- Το `Result::Err` αναπαριστά ένα σφάλμα.

Χρησιμοποιώντας το `Result`, μια συνάρτηση μπορεί να επιστρέψει είτε μια τιμή επιτυχίας είτε ένα σφάλμα, επιτρέποντας στη συνάρτηση που την καλεί να αποφασίσει τι θα κάνει στη συνέχεια.

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

Σε αυτό το παράδειγμα, αν το `b` είναι μηδέν, η συνάρτηση επιστρέφει ένα σφάλμα. Διαφορετικά, επιστρέφει το αποτέλεσμα της διαίρεσης.
