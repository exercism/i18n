# Προσθήκη οδηγιών

Αν η είσοδος δεν είναι έγκυρη, επέστρεψε ένα κενό μήκος.

## Δεσμευμένες διευθύνσεις

Ο buffer για την πρώτη συμβολοσειρά χρησιμοποιεί τα bytes 1024-2047 της γραμμικής μνήμης.
Ο buffer για τη δεύτερη συμβολοσειρά χρησιμοποιεί τα bytes 2048-3071 της γραμμικής μνήμης.
Ο buffer για την τρίτη συμβολοσειρά χρησιμοποιεί τα bytes 3072-4095 της γραμμικής μνήμης.

Το πρώτο τμήμα των bytes 0-1023 της γραμμικής μνήμης είναι ελεύθερο για χρήση.
