# Οδηγίες

Γεια σου, Πράκτορα Double-Null0111.

Η αποστολή σου, αν αποφασίσεις να την αποδεχτείς, είναι να γράψεις ένα ζευγάρι εργαλείων που θα σε βοηθήσουν να παρεισφρήσεις στα κεντρικά της UMBRA (United Minions Being Really Awful) και να ανακτήσεις τα σχέδια για το τελευταίο, πραγματικά φρικτό, σχέδιό τους.
Θα χρειαστείς τρία εργαλεία για να φέρεις εις πέρας αυτή την αποστολή.

## 1. Δημιούργησε έναν αριθμό ταυτότητας

Κάθε πρωτοπαλίκαρο έχει ένα μοναδικό αναγνωριστικό που αλλάζει κάθε μέρα και εξαρτάται από τον αριθμό των μυστικών που κρατάει και τον αριθμό των ωρών που κοιμάται.
Θα χρειαστεί να γράψεις μια συνάρτηση που παίρνει την ημέρα (ως `Int`) και δημιουργεί μια συνάρτηση παραγωγής αναγνωριστικών για αυτήν την ημέρα.
Η συνάρτηση παραγωγής αναγνωριστικών παίρνει δύο παραμέτρους:

1. τον αριθμό των μυστικών που κρατάει
2. τον αριθμό των ωρών που κοιμάται το πρωτοπαλίκαρο

Το αναγνωριστικό υπολογίζεται ως εξής:

1. πολλαπλασίασε τον αριθμό των μυστικών που κρατάει με τον αριθμό των ωρών που κοιμάται
2. πρόσθεσε την ημέρα (ως `Int`) στο αποτέλεσμα

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. Προστάτεψε τα σχέδια που ανέκτησες με έναν μυστικό κωδικό

Μόλις αποκτήσεις τα μυστικά σχέδια, θα πρέπει να τα προστατέψεις έτσι ώστε μόνο όσοι ξέρουν τον κωδικό να μπορούν να τα ανακτήσουν.
Για να το κάνεις αυτό, θα χρειαστεί να υλοποιήσεις τη συνάρτηση `protectSecret(secret: String, password: String) : (String) -> String`.
Αυτή η συνάρτηση θα επιστρέψει μια άλλη συνάρτηση που παίρνει ως είσοδο πιθανές συμβολοσειρές κωδικού.
Αν ο κωδικός που εισάγεται είναι σωστός, η νέα συνάρτηση επιστρέφει το κρυμμένο μυστικό, αλλά αν ο κωδικός είναι λάθος, η συνάρτηση επιστρέφει "Sorry. No hidden secrets here."

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. Βρες τον μυστικό κωδικό

Η βάση της UMBRA έχει αρκετά δωμάτια, φυλασσόμενα από έναν φρουρό ασφαλείας που θα σου ζητήσει τον μυστικό κωδικό.
Ο μυστικός κωδικός εξαρτάται από τον αριθμό του δωματίου.
Δυστυχώς, γνωρίζουμε μόνο το μισό του αλγορίθμου για τον υπολογισμό του κωδικού.
Το άλλο μισό μπορείς να το μάθεις ρωτώντας ένα από τα πρωτοπαλίκαρα.

Υλοποίησε τη συνάρτηση `getPassword` που παίρνει τα παρακάτω και επιστρέφει τον κωδικό:

1. τον αριθμό του δωματίου 
2. τη συνάρτηση του πρωτοπαλίκαρου που επιστρέφει τον μυστικό κωδικό

Ο μυστικός κωδικός προκύπτει καλώντας τη συνάρτηση του πρωτοπαλίκαρου με μια άλλη συνάρτηση που αναπαριστά τον αλγόριθμο που γνωρίζουμε εμείς.
Το δικό μας μέρος του αλγορίθμου:

1. παίρνει δύο αριθμούς και τους προσθέτει
2. πολλαπλασιάζει το αποτέλεσμα με το αναγνωριστικό του δωματίου

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
