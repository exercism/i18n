# Προσθήκη στις οδηγίες

## Υποδείξεις

Αυτή η άσκηση αφορά την [αναδιαμόρφωση κώδικα](https://en.wikipedia.org/wiki/Refactoring),
γι' αυτό σου δίνουμε μια λύση που περνάει ήδη τα tests.

Η πρόκληση είναι να τη γράψεις ξανά μέχρι να είσαι περήφανος γι' αυτήν, και να μάθεις
κάτι στην πορεία.

Αν δεν ξέρεις από πού να ξεκινήσεις, ορίστε μερικές ιδέες:

- Προσπάθησε να περιορίσεις την επανάληψη στο ελάχιστο.
- Προσπάθησε να κάνεις τον κώδικα ευανάγνωστο.
- Γενίκευσε τη λύση σου, ώστε η γριά να μπορεί να καταπιεί κι άλλα πράγματα.

Πάρε τον χρόνο σου.

Άλλαζε ένα πράγμα τη φορά και έλεγχε αν η λύση σου περνάει ακόμα τα tests.

Καλή διασκέδαση!
