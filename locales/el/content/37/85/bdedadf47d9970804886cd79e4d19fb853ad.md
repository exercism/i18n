# Επισήμανση σύνταξης

Υπάρχουν δύο τύποι επισήμανσης σύνταξης στον ιστότοπο:

1. Επισήμανση _στατικού_ κώδικα (αποσπάσματα κώδικα, επαναλήψεις και τέτοια).
   Δες τα [έγγραφα για τη στατική επισήμανση σύνταξης](/docs/building/tracks/new/syntax-highlighting/static) για περισσότερες πληροφορίες.
2. Επισήμανση _δυναμικού_ κώδικα (ο διαδικτυακός επεξεργαστής).
   Δες τα [έγγραφα για τη δυναμική επισήμανση σύνταξης](/docs/building/tracks/new/syntax-highlighting/dynamic) για περισσότερες πληροφορίες.

```exercism/note
Οι απαιτήσεις για τη στατική και τη δυναμική επισήμανση σύνταξης είναι _πολύ_ διαφορετικές, γι' αυτό χρησιμοποιούν διαφορετικές βιβλιοθήκες.
```
