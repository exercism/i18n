# Σχετικά

Οι [πλειάδες][tuple] χρησιμοποιούνται συχνά για να ομαδοποιούν πληροφορίες και διαφέρουν από τις λίστες στο ότι έχουν σταθερό μέγεθος και μπορούν να περιέχουν διαφορετικούς τύπους δεδομένων.
Οι πλειάδες δημιουργούνται με παρενθέσεις, `()`, και χρησιμοποιούνται συχνά για την επιστροφή πολλαπλών τιμών από μια συνάρτηση.

```haskell
tuple = (1, "abc", False)
```

Αυτό μπορεί να είναι χρήσιμο όταν, για παράδειγμα, θέλεις να αποθηκεύσεις μια συντεταγμένη σε έναν δισδιάστατο χώρο. Τότε ξέρεις ότι η πλειάδα θα έχει πάντα δύο στοιχεία, τις συντεταγμένες x και y.

```haskell
coordinate = (3, 4)
```

## Πρόσβαση στα στοιχεία

Αρκετά συχνά δουλεύεις με μικρές πλειάδες και μπορείς να έχεις πρόσβαση στα στοιχεία χρησιμοποιώντας τις συναρτήσεις `fst` και `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
