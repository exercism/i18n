# Προσθήκη οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Οι συναρτήσεις αναμένεται να επιστρέφουν το γινόμενο, τη μετατόπιση και το μήκος του πίνακα παραγόντων.
Οι παράγοντες γράφονται απλώς ως ζεύγη i32 στη μνήμη:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Για το μεγαλύτερο μονοψήφιο παλίνδρομο γινόμενο, θα έμοιαζε κάπως έτσι:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
