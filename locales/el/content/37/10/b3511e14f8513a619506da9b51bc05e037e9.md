# Εισαγωγή

Η Go δεν έχει την έννοια του κενού, του null ή του undefined για τις τιμές των μεταβλητών.
Οι μεταβλητές που δηλώνονται χωρίς ρητή αρχική τιμή παίρνουν εξ ορισμού τη μηδενική τιμή του αντίστοιχου τύπου τους.

Η μηδενική τιμή για τους πρωτογενείς τύπους, όπως οι τύποι Boolean, οι αριθμητικοί τύποι και οι συμβολοσειρές, είναι αντίστοιχα `false`, `0` και `""`.

Το αναγνωριστικό `nil`, που σημαίνει μηδέν, είναι η μηδενική τιμή για πιο σύνθετους τύπους, όπως δείκτες, συναρτήσεις, διεπαφές, φέτες, κανάλια και χάρτες.

Ο παρακάτω πίνακας παρουσιάζει αναλυτικά τη μηδενική τιμή για τους τύπους της Go.

| Τύπος     | Μηδενική τιμή |
| --------- | ------------- |
| Boolean   | `false`       |
| αριθμητικός | `0`         |
| συμβολοσειρά | `""`      |
| δείκτης   | `nil`         |
| συνάρτηση | `nil`         |
| διεπαφή   | `nil`         |
| φέτα      | `nil`         |
| κανάλι    | `nil`         |
| χάρτης    | `nil`         |

Ίσως παρατήρησες ότι οι τύποι struct απουσιάζουν από τον παραπάνω πίνακα.
Αυτό συμβαίνει επειδή η μηδενική τιμή ενός τύπου struct εξαρτάται από τα πεδία του.
Τα struct παίρνουν τη μηδενική τους τιμή όταν όλα τα πεδία τους πάρουν την αντίστοιχη μηδενική τιμή.
