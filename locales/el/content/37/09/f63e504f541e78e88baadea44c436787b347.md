# Συμβολοσειρές

Η Crystal διαθέτει έναν τύπο γνωστό ως [`String`][strings], που χρησιμοποιείται για την αναπαράσταση κειμένου.
Οι συμβολοσειρές της Crystal είναι ακολουθίες χαρακτήρων Unicode.
Οι συμβολοσειρές είναι αμετάβλητες, που σημαίνει ότι δεν μπορούν να αλλάξουν μόλις δημιουργηθούν.
Αυτό σημαίνει ότι δημιουργείται μια νέα συμβολοσειρά κάθε φορά που τροποποιείς μια συμβολοσειρά· επομένως, η αρχική συμβολοσειρά δεν τροποποιείται.

Για να ορίσεις μια συμβολοσειρά, χρησιμοποιείς διπλά εισαγωγικά `"`.

```crystal
"Hello World"
```

## Συνένωση

Για να συνενώσεις δύο συμβολοσειρές, χρησιμοποίησε τον τελεστή `+`.
Ο τελεστής `+` θα επιστρέψει μια νέα συμβολοσειρά που συνδυάζει τις δύο συμβολοσειρές.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Μετατροπή μεταξύ συμβολοσειρών και αριθμών

Η μέθοδος `to_i` μετατρέπει μια συμβολοσειρά σε ακέραιο.
Εναλλακτικά, η μέθοδος `to_f` μπορεί να χρησιμοποιηθεί για να επιστρέψει έναν αριθμό κινητής υποδιαστολής.
Αν η συμβολοσειρά δεν μπορεί να μετατραπεί σε αριθμό, τότε θα πεταχτεί ένα `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Ένας ακέραιος ή ένας αριθμός κινητής υποδιαστολής μπορεί να μετατραπεί σε συμβολοσειρά χρησιμοποιώντας τη μέθοδο `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Παρεμβολή

Η παρεμβολή είναι ένας βολικός τρόπος για να συνδυάζεις συμβολοσειρές και να ενσωματώνεις εκφράσεις μέσα σε συμβολοσειρές.
Για να κάνεις παρεμβολή σε μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον χαρακτήρα `#` ακολουθούμενο από άγκιστρα `{}` με την έκφραση μέσα στα άγκιστρα.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Η Crystal θα μετατρέψει αυτόματα το αποτέλεσμα της έκφρασης σε συμβολοσειρά.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Μέγεθος

Όταν χρειάζεται να μάθεις τον αριθμό των χαρακτήρων σε μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τη μέθοδο `size`, η οποία επιστρέφει το μήκος της συμβολοσειράς ως ακέραιο.
Το μέγεθος μιας συμβολοσειράς είναι μια αποθηκευμένη ιδιότητα της συμβολοσειράς, οπότε δεν χρειάζεται να υπολογίζει το μέγεθος κάθε φορά που καλείς τη μέθοδο, γεγονός που την κάνει πολύ γρήγορη.

```crystal
"Hello World".size
# => 11
```

## Πρόσβαση με θέση

Όταν θέλεις να πάρεις έναν συγκεκριμένο χαρακτήρα από μια συμβολοσειρά, χρησιμοποιείς την πρόσβαση με θέση.
Για να πάρεις έναν χαρακτήρα από ένα `String`, μπορείς να χρησιμοποιήσεις τη γνωστή σημειογραφία με αγκύλες.

~~~~exercism/note
Το `[]` είναι υλοποιημένο ως μέθοδος στιγμιοτύπου της `String`, όπου η θέση είναι το όρισμα της μεθόδου.
~~~~

Στη Crystal, ο πρώτος χαρακτήρας σε μια συμβολοσειρά βρίσκεται στη θέση 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Για να πάρεις έναν χαρακτήρα από το τέλος μιας συμβολοσειράς, μπορείς να πάρεις το μήκος της συμβολοσειράς μείον ένα για να βρεις τη θέση του τελευταίου χαρακτήρα, και για να πάρεις τον προτελευταίο χαρακτήρα, μπορείς να πάρεις το μήκος της συμβολοσειράς μείον δύο, και ούτω καθεξής.
Υπάρχει ένας συντομότερος τρόπος για αυτό, και είναι απλώς να χρησιμοποιήσεις αρνητική θέση, όπου ο τελευταίος χαρακτήρας βρίσκεται στη θέση -1, ο προτελευταίος χαρακτήρας στη θέση -2, και ούτω καθεξής.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Έλεγχος υποσυμβολοσειράς

Η Crystal υποστηρίζει τον έλεγχο αν μια συμβολοσειρά περιέχει μια υποσυμβολοσειρά χρησιμοποιώντας θέση.
Η ίδια σημειογραφία αγκύλων το κάνει, αλλά αντί για θέση, δίνεται μια υποσυμβολοσειρά.
Αν η υποσυμβολοσειρά βρεθεί στη συμβολοσειρά, τότε επιστρέφεται η υποσυμβολοσειρά· αλλιώς πετιέται ένα `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Αν θέλεις μια τιμή `Bool` για να δείξεις αν η υποσυμβολοσειρά βρέθηκε, τότε μπορείς να χρησιμοποιήσεις τη μέθοδο `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Διαφυγή

Κάποιοι χαρακτήρες δεν μπορούν να γραφτούν απευθείας σε μια συμβολοσειρά· αντίθετα, πρέπει να χρησιμοποιήσεις μια ακολουθία διαφυγής.
Για παράδειγμα, αν θέλεις να χρησιμοποιήσεις διπλά εισαγωγικά μέσα σε μια συμβολοσειρά, πρέπει να κάνεις διαφυγή των διπλών εισαγωγικών.
Μπορείς να χρησιμοποιήσεις τον χαρακτήρα `\` για να γράψεις μια ακολουθία διαφυγής ακολουθούμενη από τον χαρακτήρα που θέλεις να κάνεις διαφυγή.

Αυτοί είναι οι ειδικοί χαρακτήρες στη Crystal:

| Τιμή    | Περιγραφή                   |
| -------- | ----------------------------- |
| `\a`     | Ειδοποίηση                    |
| `\b`     | Οπισθοχώρηση                  |
| `\e`     | Διαφυγή                       |
| `\f`     | Αλλαγή σελίδας                |
| `\n`     | Αλλαγή γραμμής ή νέα γραμμή   |
| `\r`     | Επιστροφή στην αρχή γραμμής   |
| `\t`     | Οριζόντια στηλοθέτηση         |
| `\v`     | Κάθετη στηλοθέτηση            |
| `\\`     | Ανάποδη κάθετος               |
| `\'`     | Μονό εισαγωγικό               |
| `\"`     | Διπλό εισαγωγικό              |
| `\377`   | Οκταδικός χαρακτήρας ASCII    |
| `\xFF`   | Δεκαεξαδικός χαρακτήρας ASCII |
| `\uFFFF` | Δεκαεξαδικός χαρακτήρας Unicode |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Συμβολοσειρές πολλαπλών γραμμών

Για να γράψεις μια συμβολοσειρά πολλαπλών γραμμών, χρησιμοποιείς την ίδια σύνταξη όπως σε μια συμβολοσειρά μίας γραμμής, αλλά κάνεις μια νέα γραμμή για κάθε γραμμή που θέλεις στη συμβολοσειρά.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] είναι ένα πρότυπο για την κωδικοποίηση, την αναπαράσταση και την επεξεργασία κειμένου σε διαφορετικά συστήματα γραφής.
Το Unicode υποστηρίζει πάνω από 100.000 χαρακτήρες, συμπεριλαμβανομένων γραμμάτων, σημείων στίξης, συμβόλων και emoji.

Εφόσον η Crystal χρησιμοποιεί Unicode για τις συμβολοσειρές, μπορείς, για παράδειγμα, να βάλεις emoji μέσα σε συμβολοσειρές.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

Μερικές φορές, θέλεις να χρησιμοποιήσεις έναν χαρακτήρα που δεν είναι διαθέσιμος, για παράδειγμα, στον επεξεργαστή ή στο σύστημά σου.
Σε αυτή την περίπτωση, μπορείς να χρησιμοποιήσεις την ακολουθία διαφυγής Unicode για να γράψεις τον χαρακτήρα.

```crystal
"\u{1F310}"
# => "🌐"
```
