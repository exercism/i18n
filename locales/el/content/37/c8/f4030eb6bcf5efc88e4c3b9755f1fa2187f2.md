# Υποδείξεις

## Γενικά

- Κάνε μια επανάληψη στα μοτίβα κανονικών εκφράσεων από την εισαγωγή. Θυμήσου ότι όταν δημιουργείς το μοτίβο ως συμβολοσειρά, πρέπει να κάνεις escape σε κάποιους χαρακτήρες.
- Διάβασε για το [module `Regex`][regex-docs] στην τεκμηρίωση.
- Διάβασε για το [sigil κανονικών εκφράσεων][sigils-regex] στον οδηγό Getting Started.
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular-Expressions.info][website-regex-info].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Rex Egg - Το πιο τυραννοσαυρικό tutorial για regex στον κόσμο][website-rexegg].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegexOne - Μάθε κανονικές εκφράσεις με απλές, διαδραστικές ασκήσεις][website-regexone].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular Expressions 101 - ένα διαδικτυακό sandbox για regex][website-regex-101].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegExr - ένα διαδικτυακό sandbox για regex][website-regexr].

## 1. Εντόπισε αλλοιωμένες γραμμές log

- Χρησιμοποίησε το [sigil `r`][sigil-r] για να δημιουργήσεις μια κανονική έκφραση.
- Υπάρχει [ένας τελεστής][match-operator] που μπορεί να χρησιμοποιηθεί για να ελέγξεις μια συμβολοσειρά ως προς μια κανονική έκφραση. Υπάρχει επίσης μια [συνάρτηση του `Regex`][regex-match] και μια [συνάρτηση του `String`][string-match] που κάνουν το ίδιο.
- Μην ξεχάσεις να κάνεις escape σε χαρακτήρες που έχουν ειδική σημασία στις κανονικές εκφράσεις.

## 2. Χώρισε τη γραμμή log

- Υπάρχει μια [συνάρτηση του `Regex`][regex-split] καθώς και μια [συνάρτηση του `String`][string-split] που μπορούν να χωρίσουν μια συμβολοσειρά σε λίστα συμβολοσειρών με βάση μια κανονική έκφραση.
- Μην ξεχάσεις να κάνεις escape σε χαρακτήρες που έχουν ειδική σημασία στις κανονικές εκφράσεις.

## 3. Αφαίρεσε τα τεχνουργήματα από το log

- Υπάρχει μια [συνάρτηση του `Regex`][regex-replace] καθώς και μια [συνάρτηση του `String`][string-replace] που μπορούν να αλλάξουν το τμήμα μιας συμβολοσειράς που ταιριάζει με μια δεδομένη κανονική έκφραση σε μια άλλη συμβολοσειρά.
- Υπάρχει ένας [τροποποιητής][regex-modifiers] που μπορεί να κάνει ολόκληρη την κανονική έκφραση να μην κάνει διάκριση πεζών-κεφαλαίων.

## 4. Βάλε ετικέτες στις γραμμές με ονόματα χρηστών

- Υπάρχει μια [συνάρτηση του `Regex`][regex-run] που εφαρμόζει μια κανονική έκφραση σε μια συμβολοσειρά και επιστρέφει όλες τις συλλήψεις.
