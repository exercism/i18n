# Προσάρτημα οδηγιών

## Εκτύπωση δέντρου

Αυτή η άσκηση έχει κάποιες προκαθορισμένες μεθόδους κλάσης που βοηθούν στην εκτύπωση του δέντρου σε ωραία μορφή.
Ο κύριος σκοπός τους είναι να βοηθούν στην αποσφαλμάτωση και να παρέχουν επιπλέον σαφήνεια.
Αν υλοποιήσεις σωστά την υπόλοιπη κλάση, θα σου εκτυπώσει το δέντρο.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
