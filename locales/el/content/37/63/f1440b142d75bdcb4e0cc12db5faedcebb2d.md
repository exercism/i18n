# Σχόλιο boilerplate

Φαίνεται ότι άφησες τα σχόλια "PLEASE REMOVE THESE COMMENTS..." στον κώδικά σου.

Τα σχόλια που έχουν παλιώσει ή δεν είναι σχετικά μπορούν να βλάψουν τη σαφήνεια του κώδικά σου. Τα σχόλια πρέπει να ενημερώνονται ή/και να αφαιρούνται την ίδια στιγμή που επεξεργάζεσαι τον κώδικα.
