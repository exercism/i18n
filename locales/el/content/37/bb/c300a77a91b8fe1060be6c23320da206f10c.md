# Θέση συμπλήρωσης

## Οδηγίες ειδικά για τη jq

Σε αυτή την άσκηση, καλείσαι να ορίσεις μια συνάρτηση `toRna`.
Αυτή η συνάρτηση θα δέχεται ως είσοδο μια αλληλουχία DNA (ως συμβολοσειρά) και θα παράγει την αλληλουχία RNA που προκύπτει από τη μεταγραφή.

Ανατρέξε στον [ορισμό συναρτήσεων][def] στο εγχειρίδιο της jq.

[def]: https://jqlang.org/manual/#DefiningFunctions
