# Σχετικά

Η Common Lisp είναι ένα παρακλάδι της μακρόχρονης οικογένειας γλωσσών προγραμματισμού Lisp.  
Είναι μια πολυπαραδειγματική γλώσσα προγραμματισμού που σου επιτρέπει να επιλέγεις την προσέγγιση και το παράδειγμα ανάλογα με τον τομέα εφαρμογών σου.

Η Common Lisp έχει δυνατότητες γρήγορης προτυποποίησης και εξαιρετική υποστήριξη για τον αντικειμενοστρεφή προγραμματισμό.  
Διαθέτει επίσης ένα σύστημα μακροεντολών που σου επιτρέπει να προσαρμόζεις τη γλώσσα στις ανάγκες σου, και ένα περιβάλλον χρόνου εκτέλεσης που επιτρέπει την τροποποίηση εφαρμογών που εκτελούνται.

Για να μάθεις περισσότερα για την Common Lisp, ρίξε μια ματιά στην [αρχική σελίδα της Common Lisp][common-lisp-net]

[common-lisp-net]: https://common-lisp.net/
