# Οδηγίες

Κρατάς το πρόγραμμα πλόων για ένα μικρό νησιωτικό φέρι. Καταγράφεις τις αναχωρήσεις ως ημερομηνίες και χρειάζεσαι μερικές βοηθητικές συναρτήσεις για να δουλέψεις μαζί τους.

## 1. Κατέγραψε μια ημερομηνία πλου

Όρισε τη συνάρτηση `make-date` ώστε να παίρνει ένα έτος, έναν μήνα και μια μέρα και να επιστρέφει την αντίστοιχη χρονική σήμανση.

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. Ονόμασε την ημέρα της εβδομάδας

Όρισε τη συνάρτηση `weekday-name` ώστε να παίρνει τη χρονική σήμανση ενός πλου και να επιστρέφει το όνομα της ημέρας της εβδομάδας στην οποία πέφτει.

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. Δίσεκτα έτη

Όρισε τη συνάρτηση `leap?` ώστε να παίρνει ένα έτος και να επιστρέφει αν είναι δίσεκτο.

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. Ημέρες σε έναν μήνα

Όρισε τη συνάρτηση `month-length` ώστε να παίρνει ένα έτος και έναν μήνα και να επιστρέφει τον αριθμό των ημερών σε αυτόν τον μήνα (θυμήσου τον Φεβρουάριο).

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. Ημέρες αργότερα

Όρισε τη συνάρτηση `add-days` ώστε να παίρνει μια χρονική σήμανση και έναν αριθμό ημερών και να επιστρέφει τη χρονική σήμανση τόσες μέρες αργότερα.

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
