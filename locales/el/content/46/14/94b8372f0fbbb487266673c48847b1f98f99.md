# Τριμερής τελεστής

Οι _τριμερείς τελεστές_ μπορούν να θεωρηθούν ως μια συμπαγής εκδοχή του _if-else_.
Χρησιμοποιείται συνήθως σε (αλλά δεν περιορίζεται σε) εντολές επιστροφής και χρειάζεται μόνο μία γραμμή για να πάρει την απόφαση, επιστρέφοντας την αριστερή τιμή αν η έκφραση είναι `true` και τη δεξιά τιμή αν είναι `false`.

Πολλές απλές εκφράσεις _if/else_ μπορούν να απλοποιηθούν με τη χρήση _τριμερών τελεστών_.

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

Πώς όμως να αποφασίσεις ανάμεσα σε _if-else_ και _τριμερή_;
Λοιπόν, οι _τριμερείς τελεστές_ χρησιμοποιούνται σε απλά σενάρια, όπου χρειάζεται απλώς να επιστρέψεις μια τιμή με βάση μια συνθήκη και δεν απαιτείται κάποιος επιπλέον υπολογισμός.
Χρησιμοποίησε ένα _if-else_ για όλα τα υπόλοιπα, όπως εμφωλευμένες συνθήκες, μεγάλες εκφράσεις και όταν χρειάζεται περισσότερη από μία γραμμή για να καθοριστεί η τιμή επιστροφής.

Ενώ μπορείς να εμφωλεύσεις _τριμερείς τελεστές_, ο κώδικας συχνά γίνεται δυσανάγνωστος.
Σε αυτές τις περιπτώσεις, προτιμούνται τα εμφωλευμένα if.

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

Οι _τριμερείς τελεστές_ και οι εντολές _if/else_ είναι ένα καλό παράδειγμα ότι στον προγραμματισμό έχεις διαφορετικούς τρόπους να φτάσεις στο ίδιο αποτέλεσμα.
