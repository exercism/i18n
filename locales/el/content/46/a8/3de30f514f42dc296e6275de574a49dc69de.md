# Ενότητες και Διαδρομές στην Cairo

Η Cairo χρησιμοποιεί **ενότητες** για να οργανώνει τον κώδικα.

Οι ενότητες βοηθούν στη δομή των έργων και στον έλεγχο της ορατότητας στοιχείων, όπως οι συναρτήσεις, τα structs και τα traits.

## Ορισμός Ενοτήτων

Οι ενότητες ορίζονται με `mod` και μπορούν να είναι εμφωλευμένες:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Οι συναρτήσεις, τα structs και τα traits είναι **ιδιωτικά από προεπιλογή**.

Χρησιμοποίησε το `pub` για να είναι προσβάσιμα έξω από την ενότητά τους.

## Διαδρομές: Απόλυτες εναντίον σχετικών

Για να αναφερθείς σε ένα στοιχείο σε άλλη ενότητα, μπορείς να χρησιμοποιήσεις:

- **Απόλυτες διαδρομές** (ξεκινούν από το `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Σχετικές διαδρομές** (ξεκινούν από την τρέχουσα ενότητα):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Αυτό λειτουργεί αν το `front_of_house` βρίσκεται στην ίδια ενότητα.

## Εισαγωγή Ενοτήτων στην Εμβέλεια με `use`

Το να γράφεις συνεχώς πλήρεις διαδρομές δεν είναι βολικό.

Η λέξη-κλειδί `use` επιτρέπει συντομότερες αναφορές:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

Το `use` ισχύει **μόνο στην εμβέλεια όπου εμφανίζεται**. Αν χρειάζεται κάπου αλλού, πρέπει να επαναληφθεί.

### Ιδιωματική Χρήση του `use`

- Βάλε **ενότητες** στην εμβέλεια, όχι συναρτήσεις:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  Αντί για:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Για **traits, structs και enums**, χρησιμοποίησε την πλήρη διαδρομή:

  ```rust
  use core::num::traits::BitSize;
  ```

### Ψευδώνυμα με `as`

Μετονόμασε τις εισαγωγές όταν χρειάζεται:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Εισαγωγή Πολλαπλών Στοιχείων

Αντί για πολλές εντολές `use`, ομαδοποίησε τις εισαγωγές:

```rust
use shapes::{Square, Circle, Triangle};
```

## Επανεξαγωγή με `pub use`

Για να εκθέσεις μια ενότητα σε διαφορετική δομή, χρησιμοποίησε το `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Τώρα ο εξωτερικός κώδικας μπορεί να χρησιμοποιήσει το `restaurant::hosting::add_to_waitlist()` αντί για το `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Χρήση Εξωτερικών Πακέτων με το Scarb

Για να προσθέσεις μια εξάρτηση, ενημέρωσε το `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Χρησιμοποίησε το `scarb add <package>` για να προσθέσεις εξαρτήσεις και το `scarb rm <package>` για να τις αφαιρέσεις.

## Ο Τελεστής Glob (`*`)

Για να εισάγεις τα πάντα από μια ενότητα:

```rust
use core::num::traits::*;
```

Χρησιμοποίησέ τον με προσοχή, γιατί μπορεί να κάνει τον κώδικα πιο δυσανάγνωστο.
