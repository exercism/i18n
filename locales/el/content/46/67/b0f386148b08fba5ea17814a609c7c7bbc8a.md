# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | είσοδος     | ακέραιος | κατηγορία: `0` = choice, `1` = ones, `2` = twos, `3` = threes, `4` = fours, `5` = fives, `6` = sixes, `7` = little_straight, `8` = big_straight, `9` = full_house, `10` = four_of_a_kind, `11` = yacht |
| `$a2`    | είσοδος     | διεύθυνση | ζάρια (πίνακας λέξεων)                                          |
| `$v0`    | έξοδος     | ακέραιος | σκορ που προκύπτει                                            |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση                                 |
