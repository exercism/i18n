# Εισαγωγή

Ένα λεξικό (`dict`) στην Python είναι μια δομή δεδομένων που συσχετίζει [κατακερματίσιμα][term-hashable] _κλειδιά_ με _τιμές_ και είναι γνωστό σε άλλες γλώσσες προγραμματισμού ως [πίνακας κατακερματισμού][hashtable-wikipedia] με δυνατότητα αλλαγής μεγέθους, hashmap ή [συσχετιστικός πίνακας][associative-array].
Τα λεξικά είναι ο μόνος ενσωματωμένος [τύπος αντιστοίχισης][mapping-types-dict] της Python.


Τα `Keys` πρέπει να είναι κατακερματίσιμα και μοναδικά σε όλο το λεξικό.
Οι τύποι κλειδιών μπορούν να περιλαμβάνουν `numbers`, `str` ή `tuples` (με _αμετάβλητες_ τιμές).
Δεν μπορούν να περιέχουν _μεταβλητές_ δομές δεδομένων όπως `lists`, `dict`s ή `set`s.
Από την Python 3.7 και μετά, η σειρά των κλειδιών ενός `dict` είναι εγγυημένο ότι είναι η σειρά με την οποία εισάγονται οι καταχωρίσεις.

Οι `values` μπορούν να είναι οποιουδήποτε τύπου δεδομένων ή δομής.
Οι τιμές μπορούν επίσης να εμφωλεύονται _αυθαίρετα_, έτσι ώστε να μπορούν να περιέχουν λίστες από λίστες, υπολεξικά και άλλες προσαρμοσμένες ή σύνθετες δομές δεδομένων.

Δεδομένου ενός `key`, τα λεξικά μπορούν να ανακτήσουν μια `value` σε (κατά μέσο όρο) σταθερό χρόνο (_ανεξάρτητα από τον αριθμό των καταχωρίσεων_).
Σε σύγκριση με την αναζήτηση μιας τιμής μέσα σε μια `list` ή έναν `array` (_χωρίς να γνωρίζεις τη θέση `index`_), ένα `dict` χρησιμοποιεί σημαντικά περισσότερη μνήμη, αλλά έχει πολύ γρήγορη ανάκτηση.
Τα λεξικά είναι ιδιαίτερα χρήσιμα σε σενάρια όπου η συλλογή στοιχείων είναι μεγάλη και πρέπει να προσπελαύνεται και να ενημερώνεται συχνά.


## Δημιουργία λεξικών

Τα λεξικά μπορούν να δημιουργηθούν με πολλούς τρόπους.
Οι δύο πιο απλοί είναι η χρήση του κατασκευαστή `dict()` ή η δήλωση ενός _κυριολεκτικού_ λεξικού.

### Ο κατασκευαστής της κλάσης `dict()`

Ο `dict()` (_ο κατασκευαστής της κλάσης λεξικού_) μπορεί να χρησιμοποιηθεί με οποιοδήποτε επαναλήψιμο ζευγών `key`, `value` ή με μια σειρά _ορισμάτων_ `<name>=<value>`:

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### Κυριολεκτικά λεξικά

Ένα `dict` μπορεί επίσης να εισαχθεί απευθείας ως _κυριολεκτικό λεξικό_, χρησιμοποιώντας άγκιστρα (`{}`) που περικλείουν ζεύγη `key : value`:

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## Πρόσβαση σε τιμές ενός λεξικού

Μπορείς να προσπελάσεις μια καταχώριση σε ένα λεξικό χρησιμοποιώντας ένα _κλειδί_ μέσα σε αγκύλες (`[]`).
Αν ένα `key` δεν υπάρχει στο `dict`, πετιέται ένα `KeyError`:

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

Η πρόσβαση σε μια καταχώριση μέσω της μεθόδου `.get(<key>, <default value>)` μπορεί να αποφύγει το `KeyError`:

```python
>>> bear.get("color", 'not found')
'not found'
```

## Αλλαγή ή προσθήκη τιμών σε ένα λεξικό

Μπορείς να αλλάξεις την `value` μιας καταχώρισης αναθέτοντας στο _key_ της:

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

Νέα ζεύγη `key`:`value` μπορούν να _προστεθούν_ με τον ίδιο τρόπο:

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## Αφαίρεση (Pop) καταχωρίσεων λεξικού

Μπορείς να χρησιμοποιήσεις τη μέθοδο `.pop(<key>)` για να διαγράψεις μια καταχώριση λεξικού.
Η `.pop()` αφαιρεί το ζεύγος (`key`, `value`) και επιστρέφει την `value` για χρήση.
Όπως η `.get()`, η `.pop(<key>)` δέχεται κι ένα δεύτερο όρισμα (_`dict.pop(<key>, <default value>)`_) που θα επιστραφεί αν το `key` δεν βρεθεί.
Έτσι αποτρέπεται το πέταγμα ενός `KeyError`:

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## Επανάληψη πάνω σε ένα λεξικό

Όταν διατρέχεις ένα λεξικό με `for item in dict` ή `while item`, από προεπιλογή επαναλαμβάνεις μόνο τα _κλειδιά_.
Μπορείς να προσπελάσεις τις _τιμές_ μέσα στον ίδιο βρόχο χρησιμοποιώντας _αγκύλες_:

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

Μπορείς επίσης να χρησιμοποιήσεις τη μέθοδο `.items()`, η οποία επιστρέφει αυτόματα πλειάδες (`key`, `value`):

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

Παρομοίως, η μέθοδος `.keys()` θα επιστρέψει τα `keys` και η μέθοδος `.values()` θα επιστρέψει τις `values`.
