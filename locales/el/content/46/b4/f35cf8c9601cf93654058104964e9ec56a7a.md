# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [σταθερά][constants] που θα περιέχει την [ακέραια][integers] τιμή που δίνεται στη συνταγή.
- Η σταθερά πρέπει να οριστεί μέσα στην [κλάση][classes] `Lasagna`.
- Πρέπει να οριστεί έξω από μια μέθοδο.

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία μόνο παράμετρο για τον πραγματικό χρόνο μέχρι στιγμής.
- Μπορείς να χρησιμοποιήσεις τον μαθηματικό τελεστή (`-`) για να αφαιρέσεις τιμές.
- Μπορείς να χρησιμοποιήσεις τη [σταθερά][constants] που όρισες προηγουμένως.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία μόνο παράμετρο για τον αριθμό των στρώσεων.
- Μπορείς να χρησιμοποιήσεις τον μαθηματικό τελεστή (`*`) για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με δύο ονομαστικές παραμέτρους.
- Μπορείς να καλέσεις μία από τις άλλες μεθόδους που όρισες προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον μαθηματικό τελεστή (`+`) για να προσθέσεις τιμές.

[constants]: https://crystal-lang.org/reference/syntax_and_semantics/constants.html
[integers]: https://crystal-lang.org/reference/latest/syntax_and_semantics/literals/integers.html
[classes]: https://crystal-lang.org/reference/latest/syntax_and_semantics/classes_and_methods.html#classes-and-methods
[methods]: https://crystal-lang.org/reference/latest/tutorials/basics/60_methods.html
