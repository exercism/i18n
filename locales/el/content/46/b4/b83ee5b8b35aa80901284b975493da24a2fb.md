# Υποδείξεις

## Γενικά

- Οι ακέραιοι 8 bit επιστρέφονται στο `al`.
- Οι ακέραιοι 16 bit επιστρέφονται στο `ax` και μεταβιβάζονται στο `di`.
- Αν μια συνάρτηση που καλείς τροποποιεί έναν καταχωρητή, πρέπει να αποθηκεύσεις κάθε τιμή αυτού του καταχωρητή που θα χρειαστείς αργότερα.

## 5. Περιστροφή του ιδιωτικού κλειδιού

- Οι ακέραιοι 8 bit επιστρέφονται στο `al`.
- Οι ακέραιοι 16 bit επιστρέφονται στο `ax` και μεταβιβάζονται στο `di`.
- Αν μια συνάρτηση που καλείς τροποποιεί έναν καταχωρητή, πρέπει να αποθηκεύσεις κάθε τιμή αυτού του καταχωρητή που θα χρειαστείς αργότερα.
- Μπορείς να χρησιμοποιήσεις τις `extract_higher_bits` και `extract_lower_bits` που όρισες προηγουμένως.
- Μπορείς να ορίσεις έναν σταθερό ακέραιο στην αρχή του αρχείου χρησιμοποιώντας το `equ`.
- Υπάρχει μια εντολή που μπορεί να χρησιμοποιηθεί για να βρεις τον αριθμό των bits που είναι ενεργά σε έναν αριθμό 16 bit.
- Η εντολή [movzx][movzx] μπορεί να χρησιμοποιηθεί για να μετατρέψεις έναν αριθμό 8 bit σε αριθμό 16 bit, καθαρίζοντας όλα τα επιπλέον bits.
- Υπάρχει μια εντολή που μπορεί να χρησιμοποιηθεί για να περιστρέψει bits προς τα αριστερά κατά έναν αριθμό θέσεων που δίνεται από μια τιμή 8 bit στο `cl`.

- Μπορείς να χρησιμοποιήσεις τις `rotate_private_key`, `extract_higher_bits` και `extract_lower_bits` που όρισες προηγουμένως.
- Υπάρχει μια εντολή που θέτει ένα bit αν αυτό είναι ενεργό μόνο στη μία από τις δύο τιμές, όχι και στις δύο.
- Υπάρχει μια εντολή για να αντιστρέψεις όλα τα bits ενός αριθμού.
