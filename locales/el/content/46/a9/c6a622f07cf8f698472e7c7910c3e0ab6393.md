# Εικονικό

## Οδηγίες ειδικά για Tcl

Tcl σου επιτρέπει να εφαρμόσεις στρώματα "μετασχηματισμών" σε ανοιχτά κανάλια.
Αυτοί οι μετασχηματισμοί σου επιτρέπουν να χειριστείς τα εισερχόμενα/εξερχόμενα δεδομένα με οποιονδήποτε τρόπο.

Αναφορές:

* Η αρχική [πρόταση][tip230] για μετασχηματισμούς καναλιών.
* Η τεκμηρίωση της εντολής [`chan push`][chan].
* Η τεκμηρίωση του [`transchan`][transchan] που περιγράφει το API για μετασχηματισμούς καναλιών.

[tip230]: https://core.tcl-lang.org/tips/doc/trunk/tip/230.md
[transchan]: https://www.tcl-lang.org/man/tcl9.0/TclCmd/transchan.html
[chan]: https://www.tcl-lang.org/man/tcl9.0/TclCmd/chan.html#M33
