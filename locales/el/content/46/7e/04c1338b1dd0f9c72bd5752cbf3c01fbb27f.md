# Εισαγωγή

## Λίστες λέξεων-κλειδιών

Οι λίστες λέξεων-κλειδιών είναι μια δομή δεδομένων με ζεύγη κλειδιού-τιμής.

```elixir
[month: "April", year: 2018]
```

Οι λίστες λέξεων-κλειδιών είναι λίστες από [πλειάδες][exercism-tuples] `{key, value}` και μπορούν να γραφτούν και έτσι, αλλά η συντομότερη σύνταξη χρησιμοποιείται ευρύτερα.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Τα κλειδιά σε μια λίστα λέξεων-κλειδιών πρέπει να είναι [άτομα][exercism-atoms], αλλά οι τιμές μπορούν να είναι οτιδήποτε. Κάθε κλειδί μπορεί να χρησιμοποιηθεί περισσότερες από μία φορές. Τα ζεύγη κλειδιού-τιμής σε μια λίστα λέξεων-κλειδιών είναι διατεταγμένα.

Μπορείς να δουλέψεις με τις λίστες λέξεων-κλειδιών με τους ίδιους τρόπους που χρησιμοποιείς και για τις λίστες, ή μπορείς να χρησιμοποιήσεις το module `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
