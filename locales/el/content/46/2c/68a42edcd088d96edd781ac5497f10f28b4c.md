# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις ερωτευμένους μαθητές λυκείου να δηλώσουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας μια καρδιά ASCII με τα αρχικά τους:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Πάρε το πρώτο γράμμα του ονόματος

Υλοποίησε τη συνάρτηση `first_letter`. Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο γράμμα του. Θα πρέπει να καθαρίζει και τυχόν περιττά κενά από το όνομα.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Υλοποίησε τη συνάρτηση `initial`. Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο γράμμα του, κεφαλαίο, ακολουθούμενο από τελεία. Φρόντισε να επαναχρησιμοποιήσεις τη `first_letter` που όρισες στο προηγούμενο βήμα.

```gleam
initial("Robert")
// -> "R."
```

## 3. Χώρισε το πλήρες όνομα στο όνομα και το επώνυμο

Υλοποίησε τη συνάρτηση `initials`. Θα πρέπει να παίρνει ένα πλήρες όνομα, που αποτελείται από ένα όνομα και ένα επώνυμο χωρισμένα με ένα κενό, και να επιστρέφει τα αρχικά. Φρόντισε να επαναχρησιμοποιήσεις τη `initial` που όρισες στο προηγούμενο βήμα.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Βάλε τα αρχικά μέσα στην καρδιά

Υλοποίησε τη συνάρτηση `pair`. Θα πρέπει να παίρνει δύο πλήρη ονόματα και να επιστρέφει τα αρχικά μέσα σε μια καρδιά ASCII. Φρόντισε να επαναχρησιμοποιήσεις τη `initials` που όρισες στο προηγούμενο βήμα.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
