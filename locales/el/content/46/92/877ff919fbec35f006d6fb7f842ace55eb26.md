# Οδηγίες

Το μωσαϊκό του κέντρου τεχνών της κοινότητας ολοκλήρωσε την τοποθέτησή του τον περασμένο μήνα, και τώρα το ανακάλυψε η Magpie Marg. Τις περισσότερες μέρες ανταλλάσσει μία-δυο ψηφίδες με πιο γυαλιστερές από τον **θησαυρό** της εκεί κοντά, ή βγάζει μια ψηφίδα και εξαφανίζεται για μία ώρα.

Είσαι ο εθελοντής που καταγράφει κάθε αλλαγή. Το ίδιο το μωσαϊκό είναι ένας **πίνακας σταθερού μεγέθους**, με μία θέση για κάθε ψηφίδα, που κρατά μια συμβολοσειρά χρώματος ή `f` για "λείπει". Ο θησαυρός της Magpie Marg είναι ένα **vector** με χαλαρές ψηφίδες που έχει κλέψει.

## 1. Στρώσε μια φρέσκια σειρά

Όρισε τη λέξη `fresh-mosaic` ώστε να δέχεται ένα μήκος `n` και να επιστρέφει έναν πίνακα με `n` κενές θέσεις (καθεμία `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Τοποθέτησε μια ψηφίδα

Όρισε τη λέξη `place-tile` ώστε να δέχεται μια σειρά, μια θέση και ένα χρώμα, και να ενημερώνει τη σειρά επιτόπου, ώστε η συγκεκριμένη θέση να κρατά αυτό το χρώμα. Η λέξη δεν επιστρέφει τίποτα.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Ξεκόλλησε μια ψηφίδα

Όρισε τη λέξη `chip-tile` ώστε να δέχεται μια σειρά και μια θέση, και να ενημερώνει τη σειρά επιτόπου, ώστε η συγκεκριμένη θέση να γίνει ξανά `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Ξαναχρωμάτισε μια ψηφίδα

Όρισε τη λέξη `recolour-tile` ώστε να δέχεται μια σειρά, μια θέση και μια παράθεση με ένα όρισμα, και να ενημερώνει τη σειρά επιτόπου, εφαρμόζοντας την παράθεση στην ψηφίδα σε αυτή τη θέση.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Στιγμιότυπο πριν φτάσει η Marg

Όρισε τη λέξη `snapshot-mosaic` ώστε να δέχεται μια σειρά και να επιστρέφει ένα ανεξάρτητο αντίγραφο που δεν θα επηρεαστεί από μεταγενέστερες μεταβολές του πρωτότυπου.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Η Marg βάζει μια ψηφίδα στην τσέπη

Όρισε τη λέξη `stash-tile` ώστε να δέχεται τον θησαυρό της Marg (ένα vector) και ένα χρώμα, και να προσαρτά το χρώμα στον θησαυρό. Δεν επιστρέφει τίποτα.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Η Marg επιστρέφει μια ψηφίδα

Όρισε τη λέξη `return-tile` ώστε να δέχεται τον θησαυρό της Marg και να αφαιρεί και να επιστρέφει την ψηφίδα που αποθηκεύτηκε πιο πρόσφατα (αυτή στην κορυφή).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
