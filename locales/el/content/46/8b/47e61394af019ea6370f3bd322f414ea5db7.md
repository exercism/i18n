# Υποδείξεις

## 1. Ξεκινώντας από το μηδέν

- Για να δημιουργήσεις έναν πίνακα, μπορείς να χρησιμοποιήσεις το `make-array`.
- Οι διαστάσεις ενός πίνακα δίνονται ως λίστα στο `make-array`.
- Για να ορίσεις όλα τα στοιχεία σε μια αρχική τιμή, χρησιμοποίησε την παράμετρο-λέξη-κλειδί `:inital-element`.

## 2. Ξεκινώντας από έναν υπάρχοντα πίνακα

- Για να ορίσεις τα αρχικά περιεχόμενα ενός πίνακα, χρησιμοποίησε την παράμετρο-λέξη-κλειδί `:initial-contents`.

## 3. Συνθήκη νίκης

- Το `aref` μπορεί να χρησιμοποιηθεί για να πάρεις την τιμή ενός κελιού ενός πίνακα.
- Το `eq` μπορεί να χρησιμοποιηθεί για να προσδιορίσεις αν δύο σύμβολα είναι ίδια.
- Το `and` μπορεί να χρησιμοποιηθεί για να συνδυάσεις δύο εκφράσεις `eq` ώστε να συγκρίνεις τρία στοιχεία.

## 4. Σε μια γραμμή

- Τα ορίσματα του `aref` (για έναν δισδιάστατο πίνακα) είναι "γραμμή" και "στήλη".

## 5. Σε μια στήλη

- Τα ορίσματα του `aref` (για έναν δισδιάστατο πίνακα) είναι "γραμμή" και "στήλη".
