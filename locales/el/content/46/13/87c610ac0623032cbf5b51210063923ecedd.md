# Σχετικά

Οι **οριζόμενες από τον χρήστη** συναρτήσεις δημιουργούνται με τη λέξη-κλειδί `function`. Στη συνέχεια πρέπει να ακολουθεί το όνομα της συνάρτησης και μια λίστα ορισμάτων.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Οι συναρτήσεις μπορούν να κληθούν σε ένα αρχείο πριν οριστούν, καθώς ανυψώνονται στην αρχή της εμβέλειάς τους.

## Ονοματοδοσία

Τα ονόματα συναρτήσεων στην PHP ακολουθούν τους κανόνες των άλλων αναγνωριστικών: πρέπει να ξεκινούν με κάτω παύλα ή γράμμα και μετά μπορεί να ακολουθεί οποιοσδήποτε αριθμός από γράμματα, αριθμούς ή κάτω παύλες.
