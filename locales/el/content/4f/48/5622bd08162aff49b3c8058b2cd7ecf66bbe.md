# Εισαγωγή

## Αποτελέσματα

Η Gleam δεν χρησιμοποιεί εξαιρέσεις για τη διαχείριση σφαλμάτων. Αντ' αυτού, οι συναρτήσεις που μπορούν είτε να πετύχουν είτε να αποτύχουν επιστρέφουν τον γενικό τύπο `Result`.

Ο τύπος `Result` είναι ενσωματωμένος στη γλώσσα, οπότε δεν χρειάζεται να τον ορίσεις ή να τον εισάγεις, αλλά αν τον όριζες μόνος σου θα έμοιαζε κάπως έτσι:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Η παραλλαγή `Ok` επιστρέφεται όταν μια συνάρτηση πετύχει, και η παραλλαγή `Error` επιστρέφεται όταν μια συνάρτηση αποτύχει.

Τα Result είναι πολύ συνηθισμένα στη Gleam, και οι προγραμματιστές της Gleam χρησιμοποιούν συνήθως το [άρθρωμα `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html) για να κάνουν τη δουλειά μαζί τους πιο εύκολη.

Η συνάρτηση `result.map` μπορεί να χρησιμοποιηθεί για να καλέσεις μια συνάρτηση πάνω στην τιμή που βρίσκεται μέσα σε ένα Result, αν αυτό είναι `Ok`, ή για να περάσει ένα `Error` αναλλοίωτο.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

Η συνάρτηση `result.try` είναι παρόμοια, αλλά η συνάρτηση επανάκλησης αναμένεται να επιστρέψει ένα Result. Αυτό είναι χρήσιμο για να συνδέσεις σε αλυσίδα πολλές συναρτήσεις που επιστρέφουν Result.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
