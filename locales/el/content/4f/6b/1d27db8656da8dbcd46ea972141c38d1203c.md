# Debug

Για να βοηθήσουν στο debugging, υπάρχουν διάφορες μακροεντολές που ορίζονται σε ένα [αρχείο debug.mac][debug]. Μπορείς να τις καλέσεις με ένα ή περισσότερα ορίσματα του κατάλληλου τύπου και μεγέθους. Για παράδειγμα:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rel mem, rsi ; prints two NUL-terminated strings
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
debug_flag e        ; prints true if je would jump, and false otherwise
```

Για να χρησιμοποιήσεις οποιαδήποτε από αυτές τις μακροεντολές, πρέπει να συμπεριλάβεις το `debug.mac` στην κορυφή του αρχείου λύσης:

```x86asm
%include "debug.mac"
```

Σημείωσε ότι όλες οι μακροεντολές τροποποιούν προσωρινά το `rsp`. Για να κάνεις debug σε μια τιμή στη στοίβα, φόρτωσε πρώτα την τιμή, ή τη διεύθυνσή της, σε έναν άλλο καταχωρητή.

[debug]: https://github.com/exercism/x86-64-assembly/tree/main/templates/debug.mac
