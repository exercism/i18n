# Παράρτημα οδηγιών

## Υλοποίηση

Επειδή στη Cairo δεν είναι δυνατόν να διατρέξεις τα κλειδιά του `Felt252Dict`, τα tests θα επαληθεύουν μόνο ότι τα αναμενόμενα κλειδιά γραμμάτων έχουν τις σωστές τιμές στο λεξικό.

Τα tests είναι ρυθμισμένα ώστε να αγνοούν όλα τα άλλα κλειδιά που μπορεί να έχουν οριστεί στο λεξικό που προκύπτει.
