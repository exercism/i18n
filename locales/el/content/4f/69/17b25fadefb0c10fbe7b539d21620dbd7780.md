# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό.
Για να μην μπορούν οι άλλοι να το διαβάσουν εύκολα, το μήνυμα κρυπτογραφήθηκε με μια σειρά χειρισμών bit.
Θα χρειαστεί να γράψεις τις συναρτήσεις που θα σε βοηθήσουν να αποκρυπτογραφήσεις το μήνυμα.

## 1. Μετατόπισε τα bit προς τα πίσω

Το πρώτο βήμα για να αποκρυπτογραφήσεις το μήνυμα είναι να αναιρέσεις τη μετατόπιση της διαδικασίας κρυπτογράφησης, μετατοπίζοντας τα bit πίσω προς τα δεξιά.
Στη συνέχεια της διαδικασίας αποκρυπτογράφησης θα υπάρξουν κι άλλα βήματα που υποθέτουν ότι μπαίνουν μηδενικά από την αριστερή πλευρά.

Υλοποίησε τη συνάρτηση `shift_back()` που παίρνει μια τιμή και τον αριθμό των θέσεων μετατόπισης και εκτελεί τη μετατόπιση.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Όρισε μερικά bit

Στη συνέχεια, υπάρχουν μερικά bit που πρέπει να οριστούν σε 1.

Υλοποίησε τη συνάρτηση `set_bits()` που παίρνει μια τιμή και μια μάσκα και επιστρέφει το αποτέλεσμα του ορισμού των bit της τιμής σε 1.
Ένα bit από τη `value` πρέπει να οριστεί σε 1 όπου το bit της `mask` είναι επίσης 1.
Όλα τα άλλα bit πρέπει να μείνουν αμετάβλητα.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Αντιστρέψε συγκεκριμένα bit

Κάποια bit αντιστρέφονται κατά την κρυπτογράφηση.
Θα χρειαστεί να αντιστραφούν ξανά για να αποκρυπτογραφηθεί το μήνυμα.

Υλοποίησε τη συνάρτηση `flip_bits()` που παίρνει μια τιμή και τη μάσκα.
Η μάσκα δείχνει ποια bit της τιμής θα αντιστραφούν.
Αν το bit είναι 1 στη `mask`, το bit αντιστρέφεται στη `value`.
Όλα τα άλλα bit μένουν αμετάβλητα.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Μηδένισε συγκεκριμένα bit

Τέλος, υπάρχουν και ορισμένα bit που αποκρυπτογραφούνται πάντα σε 0.

Υλοποίησε τη συνάρτηση `clear_bits()` που παίρνει μια τιμή και μια μάσκα.
Τα bit της `value` πρέπει να οριστούν σε 0 όπου το bit της μάσκας είναι 1.
Όλα τα άλλα bit πρέπει να μείνουν αμετάβλητα.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
