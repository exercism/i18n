# Προσθήκη στις οδηγίες

## Δηλώσεις σταθερών

Σε αυτή την άσκηση σου ζητείται να δηλώσεις μια σειρά από σταθερές που χρησιμοποιούνται για να ξεχωρίζεις τους διαφορετικούς τύπους τριγώνων.
Διάλεξε τον τύπο δεδομένων που πιστεύεις ότι ταιριάζει καλύτερα γι' αυτό και φρόντισε να περάσουν τα tests.

Μετά, αξίζει ίσως να διαβάσεις για το προκαθορισμένο αναγνωριστικό `iota` της Go.
Υπάρχει και [ένα εξαιρετικό άρθρο γι' αυτό](https://splice.com/blog/iota-elegant-constants-golang/).
