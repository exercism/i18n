# Εκτέλεση δοκιμών

Από το τερματικό, μετακινήσου στον βασικό κατάλογο της άσκησης και έπειτα εκτέλεσε τις δοκιμές με:

```bash
$ gleam test
```

Αυτό θα εκτελέσει το αρχείο δοκιμών που βρίσκεται στον υποφάκελο `test`, ένα αρχείο που τελειώνει σε `_test.gleam`.

## Συναρτήσεις δοκιμών

Οι δοκιμές χρησιμοποιούν ένα [προσαρμοσμένο framework δοκιμών](https://github.com/exercism/gleam-test-runner/tree/main/runner). Οποιαδήποτε δημόσια συνάρτηση στον κατάλογο `test` με όνομα που τελειώνει σε `_test` θα θεωρείται δοκιμή από το framework δοκιμών.

Για παράδειγμα:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
