# Εισαγωγή

Η Python έχει δύο δομές επανάληψης.
Οι `while` βρόχοι για _αόριστη_ (μη μετρημένη) επανάληψη και οι `for` βρόχοι για _ορισμένη_ (μετρημένη) επανάληψη.
Οι λέξεις-κλειδιά `break`, `continue` και `else` βοηθούν στην προσαρμογή της συμπεριφοράς του βρόχου.
Οι συναρτήσεις `range(<length of sequence>)` και `enumerate(<iterable>)` βοηθούν στη μέτρηση των βρόχων και στην αρίθμηση θέσεων.


Οι `while` βρόχοι δεν έχουν καθορισμένο αριθμό επαναλήψεων προς εκτέλεση και συνεχίζουν για όσο η έκφραση του βρόχου, ή "έλεγχος", αποτιμάται σε `True`.
Ο βρόχος τερματίζεται όταν η έκφραση του βρόχου αποτιμάται σε `False`.

```python
while expression:
    set_of_statements
```

Οι `for` βρόχοι διατρέχουν τις τιμές οποιασδήποτε ακολουθίας και τερματίζονται όταν δεν υπάρχουν άλλες τιμές να επιστραφούν.
Η συνάρτηση `range(<length of sequence>)` παρέχει έναν μετρητή `loop` ή μια ακολουθία όταν δεν υπάρχει κάποια δομή δεδομένων ή άλλο επαναλήψιμο αντικείμενο για να διατρέξει ο βρόχος.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
