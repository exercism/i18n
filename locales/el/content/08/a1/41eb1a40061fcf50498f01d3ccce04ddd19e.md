# Εισαγωγή

Ο έλεγχος ροής στη Cairo σου επιτρέπει να ελέγχεις τη ροή εκτέλεσης των προγραμμάτων σου με βάση συνθήκες και επαναλήψεις.

## Εκτέλεση υπό συνθήκη

Χρησιμοποίησε εκφράσεις `if` για να εκτελέσεις κώδικα με βάση συνθήκες:

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

Το `if` είναι έκφραση, οπότε μπορεί να επιστρέψει τιμές:

```rust
let result = if condition { 5 } else { 10 };
```

## Βρόχοι

Χρησιμοποίησε το `loop` για να επαναλάβεις κώδικα.
Ένας βρόχος εκτελείται ατελείωτα αν δεν τον σταματήσεις· χρησιμοποίησε το `break` για να βγεις από τον βρόχο όταν ικανοποιηθεί μια συνθήκη.

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

Οι βρόχοι μπορούν να επιστρέψουν τιμές χρησιμοποιώντας το `break`:

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

Χρησιμοποίησε το `continue` για να περάσεις στην επόμενη επανάληψη:

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
