# Έννοιες που απαιτούνται για την άσκηση Μακροεντολές

Υπάρχουν πολλοί τρόποι για να λύσεις μια άσκηση, αλλά εγώ θα κοιτάξω το [κανονικό παράδειγμα](https://github.com/exercism/rust/blob/666c366fc0d39d9f6fd8e837facea8afe2153ae2/exercises/macros/example.rs) ως κύρια αναφορά μου για το ποιες έννοιες χρησιμοποιούνται.

Όταν αναφερόμαστε στη λίστα των εννοιών, εννοούμε [αυτή τη λίστα](https://github.com/exercism/v3/blob/master/languages/rust/reference/README.md)

Σημείωσε ότι, τόσο για τις ασκήσεις εννοιών όσο και για τις ασκήσεις εξάσκησης, η λίστα με τις προαπαιτούμενες έννοιες πρέπει να είναι όσο το δυνατόν μικρότερη. Ο στόχος εδώ δεν είναι να απαριθμήσουμε όλες τις έννοιες που μπορεί να χρησιμοποιηθούν σε όλες τις πιθανές προσεγγίσεις του προβλήματος. Είναι να απαριθμήσουμε το ελάχιστο σύνολο γνώσεων με το οποίο ένας αποφασισμένος μαθητής θα μπορούσε δυνητικά να λύσει το πρόβλημα.

Σημείωσε ότι αυτή η άσκηση είναι πολύ πιθανό να γίνει άσκηση εννοιών για την έννοια "Γράφοντας δηλωτικές μακροεντολές".

## Απαιτούμενες έννοιες

### Υπάρχουσες

- structs
- (α)μεταβλητότητα
- `Hashmap<K, V>`

### Που πρέπει να προστεθούν

- ανάθεση τιμής σε μεταβλητή (μέρος του `fundamentals`)
- εμβέλεια μεταβλητής / χώροι ονομάτων (μέρος του `fundamentals`)
- μέθοδοι και συσχετισμένες συναρτήσεις (εξαρτάται από `structs`)
