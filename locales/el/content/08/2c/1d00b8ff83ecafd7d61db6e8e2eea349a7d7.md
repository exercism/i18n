# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό.
Επειδή δεν ήθελε να το κάνει εύκολο για τους άλλους να το διαβάσουν, το μήνυμα κρυπτογραφήθηκε με μια σειρά από πράξεις πάνω στα bits.
Θα χρειαστεί να γράψεις τις συναρτήσεις που θα βοηθήσουν στην αποκρυπτογράφηση του μηνύματος.

## 1. Μετατόπισε τα bits πίσω

Το πρώτο βήμα για την αποκρυπτογράφηση του μηνύματος είναι να αναιρέσεις τη μετατόπιση της κρυπτογράφησης, μετατοπίζοντας τα bits πίσω προς τα δεξιά.
Στη συνέχεια της διαδικασίας αποκρυπτογράφησης υπάρχουν βήματα που υποθέτουν ότι από την αριστερή πλευρά εισάγονται 0.

Υλοποίησε τη συνάρτηση `shiftBack`, η οποία παίρνει μια τιμή και τον αριθμό των θέσεων μετατόπισης και εκτελεί τη μετατόπιση.

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. Θέσε κάποια bits

Έπειτα, υπάρχουν κάποια bits που πρέπει να τεθούν στο 1.

Υλοποίησε τη συνάρτηση `setBits`, η οποία παίρνει μια τιμή και μια μάσκα και επιστρέφει το αποτέλεσμα της θέσης των bits της τιμής στο 1.
Ένα bit της τιμής πρέπει να τεθεί στο 1 όπου και το αντίστοιχο bit της μάσκας είναι 1.
Όλα τα άλλα bits πρέπει να μείνουν αμετάβλητα.

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Αντιστρέψε συγκεκριμένα bits

Κάποια bits αντιστρέφονται κατά την κρυπτογράφηση.
Θα χρειαστεί να αντιστραφούν ξανά για να αποκρυπτογραφηθεί το μήνυμα.

Υλοποίησε τη συνάρτηση `flipBits`, η οποία παίρνει μια τιμή και τη μάσκα.
Η μάσκα δείχνει ποια bits της τιμής θα αντιστραφούν.
Αν το bit της μάσκας είναι 1, το αντίστοιχο bit της τιμής αντιστρέφεται.
Όλα τα άλλα bits μένουν αμετάβλητα.

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Μηδένισε συγκεκριμένα bits

Τέλος, υπάρχουν και ορισμένα bits που πάντα αποκρυπτογραφούνται σε 0.

Υλοποίησε τη συνάρτηση `clearBits`, η οποία παίρνει μια τιμή και μια μάσκα.
Τα bits της `value` πρέπει να τεθούν στο 0 όπου το bit της μάσκας είναι 1.
Όλα τα άλλα bits πρέπει να μείνουν αμετάβλητα.

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
