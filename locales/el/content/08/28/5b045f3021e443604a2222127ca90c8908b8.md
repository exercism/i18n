# Σχετικά

Στη Go, μπορούμε να συγκρίνουμε τιμές χρησιμοποιώντας τους τελεστές ισότητας και διάταξης.
Έχουμε 6 τέτοιους τελεστές:

| Σύγκριση          | Τελεστής  |
| ------------------| --------- |
| ίσο               | `==`      |
| άνισο             | `!=`      |
| μικρότερο         | `<`       |
| μικρότερο ή ίσο   | `<=`      |
| μεγαλύτερο        | `>`       |
| μεγαλύτερο ή ίσο  | `>=`      |

Το αποτέλεσμα μιας σύγκρισης είναι πάντα μια τιμή boolean:

```go
a := 3

a != 4 // true
a > 5  // false
```

## Τελεστές ισότητας

Οι τελεστές ισότητας `==` και `!=` ελέγχουν αν μια τιμή είναι ίση με μια άλλη ή όχι, αντίστοιχα.
Μπορούμε να χρησιμοποιήσουμε τους τελεστές ισότητας στα περισσότερα είδη της Go.
Ακολουθούν μερικά συνηθισμένα παραδείγματα:

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## Τελεστές διάταξης

Οι τελεστές διάταξης ελέγχουν αν μια τιμή είναι μεγαλύτερη από (`>`), μεγαλύτερη ή ίση με (`>=`), μικρότερη από (`<`) και μικρότερη ή ίση με (`<=`) μια άλλη τιμή.
Αυτού του είδους η σύγκριση είναι διαθέσιμη για αριθμούς, bytes, runes και συμβολοσειρές.
Όταν συγκρίνουμε συμβολοσειρές, ακολουθείται η σειρά του λεξικού (γνωστή και ως λεξικογραφική σειρά).

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
