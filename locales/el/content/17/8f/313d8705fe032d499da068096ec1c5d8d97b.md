# Εισαγωγή

Μια συμβολοσειρά είναι μια ακολουθία χαρακτήρων και συνήθως αναπαριστά κείμενο. Οι συμβολοσειρές της Rust είναι κωδικοποιημένες σε UTF-8, που σημαίνει ότι υποστηρίζουν μια μεγάλη ποικιλία γλωσσών και συνόλων χαρακτήρων, συμπεριλαμβανομένων των emoji. Οι συμβολοσειρές μπορούν να ενωθούν, να διαχωριστούν και να συνδυαστούν με διάφορους τρόπους· είναι ένας τύπος δεδομένων με πολύ συχνή χρήση.
