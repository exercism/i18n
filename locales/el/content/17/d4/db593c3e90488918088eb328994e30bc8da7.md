# προτίμησε ρητό τύπο επιστροφής

Για να προστατευτείς από τυχαίες αλλαγές, όριζε πάντα τον τύπο `return` στα
δημόσια API, όπως στις συναρτήσεις που γίνονται `export`:

\`\`\`typescript
  ${'signature'}: <return-type> {}
\`\`\`

Η TypeScript είναι πολύ καλή στο να συμπεραίνει τύπους και θα δώσει έναν τύπο `return` σε
όλες τις συναρτήσεις. Όμως μια τυχαία αλλαγή μπορεί να αλλάξει αυτόν τον τύπο που
συμπεραίνεται, και αυτό μπορεί να προκαλέσει ή να μην προκαλέσει σφάλμα μεταγλώττισης
στο σημείο της αλλαγής. Αν προσθέσεις ρητό τύπο επιστροφής, η μεταγλώττιση μπορεί να
αποτύχει ακριβώς στο σημείο της αλλαγής.
