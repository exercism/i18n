# Οδηγίες

Είσαι ο σηματωρός σε ένα περιπολικό σκάφος της ακτοφυλακής. Το σακίδιο της σημερινής μέρας χρειάζεται πέντε μικρές λέξεις έτοιμες πριν ξεκινήσει η πρωινή βάρδια.

## 1. Παράθεσε μια τιμή

Το ημερολόγιο καταγράφει κάθε παρατήρηση σε *μορφή πηγαίου κώδικα της Factor*, το ίδιο κείμενο που θα ξαναδιαβάσει ο αναλυτής. Όρισε τη `quote-value` για να μετατρέπει οποιαδήποτε τιμή στη συμβολοσειρά της μορφής πηγαίου κώδικα.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Αφαίρεσε το πλαίσιο της σημαίας

Οι εισερχόμενες σημαίες σήματος φτάνουν πλαισιωμένες με έναν χαρακτήρα σήμανσης σε κάθε άκρο. Όρισε τη `flag-body` για να επιστρέφει ό,τι βρίσκεται *ανάμεσα* στους δύο χαρακτήρες σήμανσης: πέταξε τον πρώτο χαρακτήρα, πέταξε τον τελευταίο.

Επίστρεψε ένα slice (μια προβολή) αντί να αντιγράψεις.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Χώρισε μια σημαία

Κάθε σημαία φέρει έναν σύντομο κωδικό προθέματος που ακολουθείται από το ωφέλιμο φορτίο. Όρισε τη `split-flag` ώστε να δέχεται μια σημαία και ένα μήκος κεφαλίδας, και να επιστρέφει *και* το slice της κεφαλίδας και το slice του σώματος.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Τριγώνισε από δύο αναγνώσεις

Δύο διαδοχικές αναγνώσεις σήματος δίνουν τρεις παράγωγες μετρήσεις: τη *διαφορά* τους `a - b`, το *μέσο σημείο* τους `(a + b) / 2` και τον *λόγο* τους `a / b`. Κάθε μέτρηση χρησιμοποιεί και τις δύο αναγνώσεις.

Όρισε τη `triangulate` ώστε να επιστρέφει και τις τρεις από ένα ζεύγος αναγνώσεων.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Σύνοψε τρεις αναγνώσεις

Τρεις διαδοχικές αναγνώσεις συνοψίζονται ως το **άθροισμα**, το **γινόμενο** και το **μέγιστό** τους. Κάθε στατιστικό μέγεθος χρησιμοποιεί και τις τρεις αναγνώσεις.

Όρισε τη `triangle-stats` ώστε να επιστρέφει και τα τρία.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
