# Προσθήκη στις οδηγίες

## Υλοποίηση

Μπορείς να χρησιμοποιήσεις βασικά χαρακτηριστικά της γλώσσας για να χτίσεις και να αποδομήσεις πίνακες μέσω αποδόμησης, καθώς και το literal πίνακα `[]`, αλλά δεν επιτρέπεται να χρησιμοποιήσεις καμία συνάρτηση από το `Array.prototype`.

Για να μπορέσεις να δοκιμάσεις τη λύση σου, φρόντισε να έχει υλοποιηθεί το `forEach`.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
