# Εισαγωγή

Όπως οι περισσότερες γλώσσες προγραμματισμού, η Gleam έχει "παρενέργειες", οπότε οι συναρτήσεις μπορούν να διαβάζουν και να αλλάζουν την κατάσταση του κόσμου, καθώς και να επιστρέφουν μια τιμή.

Το module `gleam/io` στην πρότυπη βιβλιοθήκη της Gleam παρέχει συναρτήσεις για την εκτύπωση συμβολοσειρών στην κονσόλα.

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

Άλλα πακέτα μπορεί να παρέχουν άλλες συναρτήσεις εισόδου/εξόδου, όπως το `simplifile`, ένα πακέτο που παρέχει συναρτήσεις για ανάγνωση και εγγραφή αρχείων.

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
