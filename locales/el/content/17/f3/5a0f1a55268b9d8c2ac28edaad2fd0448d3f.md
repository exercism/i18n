# Εισαγωγή

Ένα στιγμιότυπο της κλάσης `java.util.Random` μπορεί να χρησιμοποιηθεί για να παράγει τυχαίους αριθμούς στη Java.

## Τυχαίοι ακέραιοι

Ένας τυχαίος ακέραιος μπορεί να παραχθεί χρησιμοποιώντας τη μέθοδο `nextInt()`.
Αυτό θα παράγει μια τιμή στο εύρος από `Integer.MIN_VALUE` έως `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Για να περιορίσεις το εύρος των παραγόμενων τιμών, χρησιμοποίησε τη `nextInt(int)`.
Αυτό θα παράγει μια τιμή στο εύρος από `0` (συμπεριλαμβανομένου) έως το δεδομένο άνω όριο (μη συμπεριλαμβανομένου).

Για παράδειγμα, αυτό θα παράγει έναν τυχαίο αριθμό από `0` έως `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Και αυτό θα παράγει έναν τυχαίο αριθμό από `10` έως `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## Τυχαίοι double

Μια τυχαία τιμή double μπορεί να παραχθεί χρησιμοποιώντας τη μέθοδο `nextDouble()`.
Αυτό θα παράγει μια τιμή στο εύρος από `0.0` έως `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Και αυτό θα παράγει έναν τυχαίο αριθμό από `100.0` έως `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
