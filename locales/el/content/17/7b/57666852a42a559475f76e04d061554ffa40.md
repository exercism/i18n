# Instructions

Η εταιρεία σου έχει προσληφθεί για να δημιουργεί καταγραφές CSV από την είσοδο του χρήστη.

Χρειαζόμαστε έναν κατασκευαστή για μια καταγραφή CSV σύμφωνα με το πρότυπο που ορίζεται στο [RFC 4180](https://tools.ietf.org/html/rfc4180).

Αν και υπάρχει επίσημη προδιαγραφή, η εταιρεία σου χρειάζεται να υλοποιήσει μόνο την εξής λειτουργικότητα:
- δημιουργία ενός νέου κατασκευαστή καταγραφής
- προσθήκη ενός μεμονωμένου πεδίου στην καταγραφή
- σειριοποίηση της καταγραφής με βασική διαφυγή

Η βασική διαφυγή σημαίνει:

- Τα πεδία που περιέχουν αλλαγές γραμμής, διπλά εισαγωγικά και κόμματα πρέπει να περικλείονται σε διπλά εισαγωγικά.

- Αν χρησιμοποιούνται διπλά εισαγωγικά για να περικλείσουν πεδία, τότε ένα διπλό εισαγωγικό που εμφανίζεται μέσα σε ένα πεδίο πρέπει να διαφύγει, βάζοντας μπροστά του ένα άλλο διπλό εισαγωγικό.


## 1. Δημιούργησε έναν νέο κατασκευαστή

Θα χρειαστεί να υλοποιήσεις τη μέθοδο `new` για να δημιουργήσεις έναν νέο κατασκευαστή.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Πρόσθεσε μεμονωμένα πεδία στην καταγραφή

Θα χρειαστεί να υλοποιήσεις τη μέθοδο `add` για να προσθέτεις πεδία στον κατασκευαστή καταγραφής σου.
Η `add` δέχεται ως όρισμα αμετάβλητα τμήματα συμβολοσειράς, `&str`.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Σειριοποίησε την καταγραφή με βασική διαφυγή

Θα χρειαστεί να υλοποιήσεις τη μέθοδο `build`.
Η `build` καταναλώνει τον κατασκευαστή και επιστρέφει μια καταγραφή CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
