# Οδηγίες ειδικές για SQLite

Οι στήλες **list_one** και **list_two** περιέχουν μια λίστα ακεραίων κωδικοποιημένη σε JSON.

Παράδειγμα:

```json
[1, 2, 3]
```

## Σχήμα πίνακα

```sql
CREATE TABLE sublist (
    list_one TEXT NOT NULL,     -- json array
    list_two TEXT NOT NULL,     -- json array
    result   TEXT
);
```
