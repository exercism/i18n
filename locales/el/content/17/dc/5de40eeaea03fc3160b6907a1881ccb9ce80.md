# Οδηγίες

Σε αυτή την άσκηση δουλεύεις σε ένα μαγαζί με πίτσες που κάνει διανομή σε πελάτες.

Προσφέρεις τρία είδη πίτσας:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Οι πελάτες μπορούν επίσης να διαλέξουν δύο επιπλέον επιλογές με ένα μικρό επιπλέον κόστος:

1. Επιπλέον σάλτσα: \$1
1. Επιπλέον υλικά: \$2

Όταν οι πελάτες κάνουν μια παραγγελία, προστίθεται μια επιπλέον χρέωση αν παραγγείλουν μόνο μία ή δύο πίτσες:

- 1 πίτσα: \$3
- 2 πίτσες: \$2

Έχεις τρεις εργασίες, και καθεμιά τους δουλεύει με πίτσες και την τιμή τους.

## 1. Όρισε τους τύπους πίτσας και τις επιλογές

Όρισε τον προσαρμοσμένο τύπο `Pizza` που αναπαριστά τα διάφορα είδη πίτσας και τις επιλογές:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

Τα `ExtraSauce` και `ExtraToppings` θα πρέπει να περιβάλλουν τον τύπο `Pizza`.

## 2. Υπολόγισε την τιμή της πίτσας

Υλοποίησε τη συνάρτηση `pizza_price` για να υπολογίζεις την τιμή μιας πίτσας:

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. Υπολόγισε την τιμή μιας παραγγελίας

Υλοποίησε τη συνάρτηση `order_price` για να υπολογίζεις την τιμή μιας παραγγελίας πίτσας:

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
