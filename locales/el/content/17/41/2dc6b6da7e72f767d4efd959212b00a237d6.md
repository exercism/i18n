# Οδηγίες

Δουλεύεις πάνω στην υλοποίηση ενός συστήματος παρακολούθησης της υγείας. Στο πλαίσιο αυτού, πρέπει να παρακολουθείς τα στατιστικά υγείας των χρηστών.

Θα ξεκινήσεις με κάποιες συναρτήσεις χωρίς υλοποίηση σε ένα μπλοκ `impl`, καθώς και με τον ακόλουθο ορισμό struct:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Ο στόχος σου είναι να υλοποιήσεις τις μεθόδους χωρίς υλοποίηση στο `User` `struct` που ορίζεται στο μπλοκ `impl`.

Για παράδειγμα, η μέθοδος `new` πρέπει να επιστρέφει ένα στιγμιότυπο του `User` struct με τις καθορισμένες τιμές name, age και weight.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

Η μέθοδος `weight` πρέπει να επιστρέφει το βάρος του `User`.

```rust
bob.weight();
// Returns: 155.2
```

Η μέθοδος `set_age` πρέπει να ορίζει την ηλικία του `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

Καλή διασκέδαση!
