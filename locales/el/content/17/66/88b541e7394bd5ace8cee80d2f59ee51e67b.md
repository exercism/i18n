# Σχετικά

Οι μέθοδοι μπορούν να έχουν μια παράμετρο varargs που επιτρέπει στον καλούντα να ορίσει μηδέν ή περισσότερα ορίσματα σαν να ήταν κανονικές παράμετροι. Η μέθοδος θα λάβει αυτά τα ορίσματα σε έναν μόνο πίνακα.

Για να μετατρέψεις μια παράμετρο σε παράμετρο varargs, πρόσθεσε τη [λέξη-κλειδί `params`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params) στη δήλωση της παραμέτρου:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
