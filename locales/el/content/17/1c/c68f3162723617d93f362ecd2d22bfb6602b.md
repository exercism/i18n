# Εισαγωγή

## Αριθμοί

Η Swift παρέχει δύο βασικές κατηγορίες αριθμών: τους ακέραιους και τους αριθμούς κινητής υποδιαστολής.

- Οι [ακέραιοι][integers] αντιπροσωπεύουν αριθμούς χωρίς κλασματικό μέρος, όπως `0`, `1`, `-1`, `42` και `-273`.
- Οι [αριθμοί κινητής υποδιαστολής][floatingpoint] αντιπροσωπεύουν αριθμούς με κλασματικό μέρος, όπως `0.0`, `3.14` και `-1.36969e-10`.

Μπορείς να εισάγεις κάτω παύλες στα αριθμητικά λεκτικά για να βελτιώσεις την αναγνωσιμότητα: το `1_000_000` είναι ίδιο με το `1000000`.
Τα λεκτικά κινητής υποδιαστολής μπορούν να γραφτούν σε δεκαδική ή εκθετική μορφή.

Στις περισσότερες περιπτώσεις, χρησιμοποιείς τον [`Int`][int] για τους ακέραιους και τον [`Double`][double] για τους αριθμούς κινητής υποδιαστολής:

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## Αριθμητικοί τελεστές

Η Swift παρέχει τους τυπικούς [αριθμητικούς τελεστές][arithmetic-operators] για αριθμητικούς υπολογισμούς:

| Τελεστής | Περιγραφή       | Παράδειγμα |
| -------- | -------------- | ------- |
| `+`      | Πρόσθεση       | το `4 + 6` δίνει `10` |
| `-`      | Αφαίρεση       | το `15 - 10` δίνει `5` |
| `*`      | Πολλαπλασιασμός | το `2 * 3` δίνει `6`  |

~~~~exercism/caution
Η Swift είναι ασφαλής ως προς τους τύπους και δεν επιτρέπει την ανάμιξη διαφορετικών αριθμητικών τύπων σε αριθμητικές πράξεις.
Δεν μπορείς να προσθέσεις ή να πολλαπλασιάσεις απευθείας ένα `Int` και ένα `Double`. Πρέπει πρώτα να μετατρέψεις τον έναν τύπο ώστε να ταιριάζει με τον άλλον.
~~~~

### Διαίρεση

Ο τελεστής `/` εκτελεί τη διαίρεση.
Όταν και οι δύο τελεστέοι είναι ακέραιοι, η ακέραια διαίρεση αποκόπτει τυχόν κλασματικό υπόλοιπο:

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

Η διαίρεση ενός μη μηδενικού αριθμού κινητής υποδιαστολής με το μηδέν δίνει `inf` ή `-inf`.
Η διαίρεση του `0.0` με το `0.0` παράγει `nan` (όχι αριθμός).
Αντίθετα, η διαίρεση ενός ακέραιου με το μηδέν προκαλεί σφάλμα κατά τη μεταγλώττιση ή κατά την εκτέλεση:

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### Τελεστής υπολοίπου

Ο [τελεστής υπολοίπου][remainder-operator] (`%`) υπολογίζει το υπόλοιπο που απομένει μετά τη διαίρεση δύο ακεραίων:

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
Στη Swift, το `%` είναι ένας γνήσιος τελεστής *υπολοίπου* και όχι τελεστής modulo.
Το αποτέλεσμα παίρνει πάντα το πρόσημο του πρώτου τελεστέου (του διαιρετέου), ανεξάρτητα από το πρόσημο του δεύτερου τελεστέου:

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## Στρογγυλοποίηση αριθμών κινητής υποδιαστολής

Μπορείς να στρογγυλοποιήσεις έναν αριθμό κινητής υποδιαστολής χρησιμοποιώντας τη μέθοδο `rounded()`.
Από προεπιλογή, η `rounded()` στρογγυλοποιεί στον πλησιέστερο ακέραιο.
Μπορείς επίσης να δώσεις έναν συγκεκριμένο [κανόνα στρογγυλοποίησης][rounding-rule], όπως `.up` ή `.down`:

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## Εξαγωγή τύπου

Όταν δηλώνεις μια αριθμητική σταθερά ή μεταβλητή χωρίς επισημείωση τύπου, η Swift συμπεραίνει τον τύπο της:

- Οι ακέραιοι αριθμοί έχουν από προεπιλογή τύπο `Int`.
- Οι αριθμοί με υποδιαστολή έχουν από προεπιλογή τύπο `Double`.

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## Μετατροπή τύπου

Για να κάνεις πράξεις ανάμεσα σε τιμές διαφορετικών τύπων, μετέτρεψε τη μία τιμή χρησιμοποιώντας αρχικοποιητές τύπου όπως `Double(_:)` ή `Int(_:)`:

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
