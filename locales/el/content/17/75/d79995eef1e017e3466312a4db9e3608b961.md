# Εισαγωγή

Η αναδρομή είναι ένας τρόπος να επαναλαμβάνεις κώδικα μέσα σε μια συνάρτηση, καλώντας η συνάρτηση τον εαυτό της.
Μπορεί να θεωρηθεί ως ένας ακόμη τρόπος για βρόχους ή επανάληψη.
Όπως και στους βρόχους, μια έκφραση Boolean ή ένας έλεγχος `True`/`False` χρησιμοποιείται για να καθοριστεί πότε θα σταματήσει η αναδρομική εκτέλεση.
_Σε αντίθεση_ με τους βρόχους, η αναδρομή χωρίς τερματισμό στην Python δεν μπορεί να τρέξει επ' άπειρον.
Οι τιμές που χρησιμοποιούνται σε κάθε κλήση συνάρτησης τοποθετούνται στο δικό τους [πλαίσιο][stack-frame] στη [στοίβα του διερμηνευτή][what-is-the-call-stack] της Python.
Αν ο συνολικός αριθμός των κλήσεων συνάρτησης πιάνει περισσότερο χώρο από ό,τι χωράει η στοίβα, θα προκύψει σφάλμα.

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

Αυτό θα εκτυπώσει

```
The step is 1
The step is 2
After recursion
```

Μπορεί να υπάρχουν περιπτώσεις που, όταν εκφράζονται με αναδρομή αντί με βρόχους, διαβάζονται πιο εύκολα ή/και είναι πιο εύκολο να τις κατανοήσεις.
