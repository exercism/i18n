# Σχετικά

Το ClojureScript είναι ένας μεταγλωττιστής για τη Clojure που στοχεύει τη JavaScript. Παράγει κώδικα JavaScript που είναι συμβατός με την προηγμένη λειτουργία μεταγλώττισης του βελτιστοποιητικού μεταγλωττιστή Google Closure.

## Γιατί Clojure;

Η Clojure είναι μια δυναμική γλώσσα προγραμματισμού γενικού σκοπού που υποστηρίζει διαδραστική ανάπτυξη. Η Clojure είναι μια συναρτησιακή γλώσσα προγραμματισμού με ένα πλούσιο σύνολο αμετάβλητων, μόνιμων δομών δεδομένων. Ως διάλεκτος της Lisp, έχει τη φιλοσοφία "ο κώδικας είναι δεδομένα" και ένα ισχυρό σύστημα μακροεντολών.

## Γιατί JavaScript;

Η εξάπλωση του φυλλομετρητή και των εφαρμογών ιστού έδωσε στη JavaScript μια μοναδική εμβέλεια που καμία άλλη γλώσσα δεν μπορεί να φτάσει. Λόγω της σημασίας της, οι μηχανές JavaScript δέχονται επίσης εκτεταμένη έρευνα και βελτιστοποίηση, που επιτρέπει στη JavaScript να ανταγωνίζεται σε επιδόσεις πολλές πιο καθιερωμένες πλατφόρμες, όπως η JVM.

## Γιατί Google Closure;

Ως πάροχοι μερικών από τις πιο πολύπλοκες διαδικτυακές εφαρμογές πελάτη-υπηρεσίας που χρησιμοποιούνται σήμερα, η Google έχει επενδύσει σημαντικά στη δημιουργία της βιβλιοθήκης Closure και του μεταγλωττιστή Closure, που συνεργάζονται για να γίνει δυνατή η βελτιστοποίηση ολόκληρου του προγράμματος, παράγοντας προγράμματα με ελάχιστους χρόνους φόρτωσης ακόμη και όταν χρησιμοποιούν πολλές βιβλιοθήκες.

## Η ευκαιρία

Το ClojureScript συνδυάζει την εμβέλεια της πλατφόρμας JavaScript, την ευελιξία και τη διαδραστική ανάπτυξη της Clojure, και τη βελτιστοποίηση ολόκληρου του προγράμματος του Google Closure, για να προσφέρει την πιο ισχυρή γλώσσα για προγραμματισμό στον ιστό.
