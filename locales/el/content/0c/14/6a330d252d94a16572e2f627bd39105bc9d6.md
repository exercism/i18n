# Υποδείξεις

## 1. Υπολόγισε το επιτόκιο

- Αναμένεται να επιστρέψεις ένα ποσοστό.

## 2. Υπολόγισε τον τόκο

- Όταν υπολογίζεις τον τόκο, μπορεί να σου φανεί χρήσιμο να προσέξεις ότι η `interest_rate` επιστρέφει ένα ποσοστό.
- Μπορείς να χρησιμοποιήσεις τη συνάρτηση που ορίστηκε στην προηγούμενη εργασία (`interest_rate`) για να υπολογίσεις τον τόκο.

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Όταν υπολογίζεις την ετήσια ενημέρωση του υπολοίπου, χρησιμοποίησε τις συναρτήσεις που ορίστηκαν στα προηγούμενα βήματα.

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

- Για να υπολογίσεις τα χρόνια, μπορείς να συνεχίσεις να επαναλαμβάνεις μέχρι να φτάσεις στο επιθυμητό υπόλοιπο, χρησιμοποιώντας έναν [`for`][for] βρόχο.
- Υπάρχει ένας ειδικός [τελεστής][increment] για να αυξάνεις τις τιμές κατά 1.

[for]: https://www.learncpp.com/cpp-tutorial/introduction-to-loops-and-while-statements/
[increment]: https://www.learncpp.com/cpp-tutorial/increment-decrement-operators-and-side-effects/
