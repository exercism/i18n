# Προσαρμοσμένες Πινακίδες

## Ιστορία

Σε αυτή την άσκηση θα γράφεις κώδικα για να βοηθήσεις μια εταιρεία κατασκευής πινακίδων να δημιουργεί προσαρμοσμένα μηνύματα για τις πινακίδες της.

## Εργασίες

Αυτές είναι παραδειγματικές εργασίες που ταιριάζουν στην ιστορία ενός πελάτη που σχεδιάζει μια προσαρμοσμένη πινακίδα:

- Δημιούργησε ένα σύνολο χρήσιμων συμβολοσειρών
- Δημιούργησε ένα σύνολο χρήσιμων χαρακτήρων
- Συνδύασε φράσεις για να συνθέσεις μηνύματα
- Κατασκεύασε μια πινακίδα αποφοίτησης
- Υπολόγισε το κόστος μιας πινακίδας
