# Debug

Όταν ένα τεστ αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε λάθος και για ποια είσοδο. Μπορείς επίσης να εκμεταλλευτείς το γεγονός ότι θα εμφανίζεται και οποιαδήποτε [έξοδος στην κονσόλα][dotnetperls.com-console-vbnet]. Μπορείς να γράψεις στην κονσόλα χρησιμοποιώντας:

```vbnet
Console.WriteLine("Debug message");
```

[dotnetperls.com-console-vbnet]: https://www.dotnetperls.com/console-vbnet
