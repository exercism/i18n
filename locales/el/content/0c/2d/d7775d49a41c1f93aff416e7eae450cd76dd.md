# Προσθήκη στις οδηγίες

## Υλοποίηση

Αυτή η άσκηση εισάγει τον [ταυτοχρονισμό][oracle-docs-concurrency].
Για να περάσεις το τελευταίο test, ίσως σου φανεί χρήσιμη [η λέξη-κλειδί `synchronized` ή τα κλειδώματα][oracle-docs-synchronized].

Τα προβλήματα που προκύπτουν από την ταυτόχρονη εκτέλεση κώδικα είναι συχνά σποραδικά, γιατί εξαρτώνται από τη σειρά με την οποία εκτελείται ο κώδικας.
Γι' αυτό το τελευταίο test εκτελεί πολλά [νήματα][threads-api] αρκετές φορές, ώστε να αυξηθούν οι πιθανότητες να εντοπιστεί ένα bug.
Αυτό σημαίνει ότι το test αυτό θα πρέπει να αποτυγχάνει αν η υλοποίησή σου δεν είναι [ασφαλής ως προς τα νήματα][wiki-thread-safety], αλλά υπάρχει περίπτωση να περάσει απλώς επειδή δεν έγινε κάποια προσπάθεια ταυτόχρονης τροποποίησης.
Είναι απίθανο να συμβεί αυτό πολλές φορές στη σειρά, αφού η σειρά με την οποία εκτελείται ο κώδικας θα πρέπει να διαφέρει κάθε φορά που τρέχεις το test.
Έτσι, αν τρέξεις το τελευταίο test δύο-τρεις φορές και περνάει κάθε φορά, μπορείς να είσαι αρκετά σίγουρος ότι η υλοποίησή σου είναι σωστή.
