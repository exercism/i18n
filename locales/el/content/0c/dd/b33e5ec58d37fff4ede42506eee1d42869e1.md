# μην αλλάξεις τις υπογραφές που δίνονται

Όπως αναφέρεται στις οδηγίες, δεν πρέπει να τροποποιήσεις τις υπογραφές των `makeChest` και `makeTreasureChest`.
Θα πρέπει να παραμείνουν ακριβώς ως εξής:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
