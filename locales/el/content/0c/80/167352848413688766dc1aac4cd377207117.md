# Σχετικά

Η αναδρομή είναι ένας τρόπος να επαναλαμβάνεις κώδικα μέσα σε μια συνάρτηση, με τη συνάρτηση να καλεί τον εαυτό της.
Είναι ένας ακόμη τρόπος για βρόχους/επανάληψη. Όπως και στους βρόχους, η συνάρτηση θα πρέπει να ελέγχει μια Boolean έκφραση για να ξέρει πότε να σταματήσει.
Σε αντίθεση με τους βρόχους, μια αναδρομή που δεν τελειώνει ποτέ δεν θα τρέξει για πάντα.
Οι τιμές που χρησιμοποιούνται σε κάθε κλήση της συνάρτησης μπορεί να τοποθετηθούν στο δικό τους πλαίσιο στη στοίβα.
Αν το πλήθος των κλήσεων της συνάρτησης πιάσει περισσότερο χώρο από ό,τι διαθέτει η στοίβα, θα προκύψει σφάλμα υπερχείλισης στοίβας.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Αυτό θα τυπώσει

```
The number is 1
The number is 2
After recursion
```

Μπορεί να υπάρχουν καταστάσεις που διαβάζονται πιο εύκολα ή/και είναι πιο εύκολο να τις σκεφτείς όταν εκφράζονται με αναδρομή παρά όταν εκφράζονται με βρόχους.


## Κλήση ουράς

Κλήση ουράς είναι όταν η τελευταία εντολή μιας συνάρτησης καλεί μόνο τον εαυτό της και τίποτε άλλο.

Η κλήση ουράς είναι μια ειδική μορφή αναδρομής που μπορεί να επιτρέψει στον μεταγλωττιστή να βελτιστοποιήσει την αναδρομή σε βρόχο στον μεταγλωττισμένο κώδικα.
Έτσι παίρνεις ό,τι καλύτερο από τους δύο κόσμους: την αναγνωσιμότητα της αναδρομής με την απόδοση ενός βρόχου.
Η μεταγλώττιση της αναδρομής σε βρόχο ονομάζεται `tail call elimination` ή `tail call optimization.`

Όταν μια κλήση ουράς μεταγλωττίζεται σε βρόχο, δεν δημιουργείται νέο πλαίσιο στοίβας για κάθε κλήση της συνάρτησης.
Η συνάρτηση, στη διεύθυνση όπου κλήθηκε αρχικά, δέχεται τις ενημερωμένες τιμές, εξοικονομώντας έτσι χώρο στη στοίβα και βελτιώνοντας την απόδοση.

Αυτό το παράδειγμα δεν είναι κλήση ουράς, καθώς η συνάρτηση προσθέτει 1 στο αποτέλεσμα της κλήσης του εαυτού της

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

Αυτό θα τυπώσει

```
The number is 1
The number is 2
j is 3 after recursion
```

Για να το αναδιαμορφώσεις σε κλήση ουράς, κάνε το `j` παράμετρο της `printIncrement`

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

Μπορεί να διαπιστώσεις ότι μια κλήση ουράς είναι πιο εύκολο να τη σκεφτείς από μια αναδρομική κλήση που δεν είναι κλήση ουράς.
Ωστόσο, οι μεταγλωττιστές συνήθως δεν εγγυώνται ότι όλες οι κλήσεις ουράς θα βελτιστοποιηθούν.
Όταν χρησιμοποιείς αναδρομή, είναι πάντα σημαντικό να ξέρεις ότι οι επαναλήψεις δεν θα είναι τόσες πολλές ώστε να υπερχειλίσει η στοίβα.
