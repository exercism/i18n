# Σχετικά

Ο [τριμερής τελεστής][ternary-operator] είναι μια συνοπτική συντομογραφία μιας έκφρασης `if-else`.
Αξιολογεί μια συνθήκη και επιστρέφει μία από δύο τιμές, ανάλογα με το αν η συνθήκη είναι `true` ή `false`.

Ο τελεστής χρησιμοποιεί τρία μέρη: `condition ? trueExpression : falseExpression`.
Αν το `condition` αξιολογείται σε `true`, το `trueExpression` αξιολογείται και επιστρέφεται, διαφορετικά αξιολογείται και επιστρέφεται το `falseExpression`.

Ο τριμερής τελεστής είναι ιδανικός για απλές επιλογές μίας γραμμής:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Το παραπάνω παράδειγμα αποτελεί μια συμπαγή ισοδύναμη εκδοχή του παρακάτω κώδικα:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
