# Εισαγωγή

Όταν περνάς μια μεταβλητή σε μια συνάρτηση, η ιδιοκτησία της μεταφέρεται, με αποτέλεσμα να μην μπορείς να χρησιμοποιήσεις την αρχική μεταβλητή.
Αυτό μπορεί να είναι λίγο κουραστικό όταν έχεις πρόσβαση σε μια κατάσταση περισσότερες από μία φορές, αλλά ευτυχώς η Cairo έχει δύο δυνατότητες για να περνάς τιμές χωρίς να τις καταστρέφεις ή να τις μετακινείς, που ονομάζονται `references` και `snapshots`.
