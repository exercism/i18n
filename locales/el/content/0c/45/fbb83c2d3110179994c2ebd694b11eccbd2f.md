# Εισαγωγή

Η Swift παρέχει εντολές μεταφοράς ελέγχου για να αλλάζεις τη ροή εκτέλεσης των βρόχων και των εντολών `switch`.
Εκτός από το `return`, η Swift περιλαμβάνει τα `continue`, `break`, τις ετικέτες βρόχων και το `fallthrough`.

## Συνέχεια

Η εντολή `continue` λέει σε έναν βρόχο να σταματήσει την εκτέλεση της τρέχουσας επανάληψης και να ξεκινήσει αμέσως την επόμενη.
Σε έναν βρόχο `while` ή `repeat-while`, πηγαίνει κατευθείαν στον έλεγχο της συνθήκης.
Σε έναν βρόχο `for-in`, προχωρά στο επόμενο στοιχείο της ακολουθίας.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Διακοπή

Η εντολή `break` βγαίνει αμέσως από ολόκληρο τον βρόχο ή την εντολή `switch`.
Η εκτέλεση συνεχίζει από την πρώτη γραμμή κώδικα μετά τον βρόχο ή το `switch`.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Εντολές με ετικέτα

Σε εμφωλευμένους βρόχους, μπορεί να θέλεις το `break` ή το `continue` να επηρεάσει έναν εξωτερικό βρόχο και όχι τον πιο εσωτερικό.
Μπορείς να βάλεις ετικέτα σε έναν βρόχο γράφοντας πριν από αυτόν ένα όνομα και άνω και κάτω τελεία (`labelName:`).
Στη συνέχεια, μπορείς να περάσεις αυτή την ετικέτα στο `break` ή στο `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```
