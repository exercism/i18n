# Οδηγίες

Διαχειρίζεσαι έναν αποκλειστικό κινηματογράφο.
Για να παρακολουθήσουν μια ταινία, οι άνθρωποι πρέπει να αγοράσουν ετήσιες κάρτες και μετά μπορούν να βλέπουν ταινίες δωρεάν.

Ο κινηματογράφος σου τηρεί αρχείο με τις εισόδους.
Θέλεις να χρησιμοποιήσεις αυτό το αρχείο για να δεις ποια μέλη χρησιμοποίησαν την ετήσια κάρτα τους αυτόν τον μήνα.
Θέλεις επίσης να πάρεις πληροφορίες για την ηλικιακή σύνθεση των πελατών σου.
Συνειδητοποιείς ότι μπορείς να χρησιμοποιήσεις σύνολα για να πετύχεις αυτούς τους στόχους.

## Σύνολα

Ένα σύνολο είναι ο ιδανικός τύπος δεδομένων για να αποθηκεύσεις αυτού του είδους τα δεδομένα.

Ένα σύνολο είναι ένας τύπος δεδομένων που χρησιμοποιείται για την αποθήκευση διακριτών, μοναδικών τιμών χωρίς συγκεκριμένη σειρά.
Διακριτό και μοναδικό σημαίνει ότι ένα στοιχείο είτε βρίσκεται στο σύνολο είτε όχι. Σε αντίθεση με έναν πίνακα, δεν μπορεί να βρίσκεται στο σύνολο πολλές φορές.
Τα σύνολα συνήθως δεν έχουν σειρά. Αν απαριθμήσεις τα στοιχεία ενός συνόλου, η σειρά που θα πάρεις μπορεί να διαφέρει από τη σειρά με την οποία προστέθηκαν, ή ακόμα και από τη σειρά που πήρες στην προηγούμενη απαρίθμηση!

Μια θεμελιώδης ιδιότητα των συνόλων είναι ο έλεγχος συμμετοχής: η δυνατότητα να ελέγξεις αν ένα σύνολο περιέχει ένα στοιχείο.
Ο έλεγχος συμμετοχής είναι κεντρικός σχεδόν σε κάθε χρήση ενός συνόλου.

Η Go δεν παρέχει ενσωματωμένο τύπο δεδομένων για σύνολα.
Είναι σύνηθες να χρησιμοποιείς ένα `map[<type>]struct{}` ή `map[<type>]bool` στη θέση ενός συνόλου. Όπως και ένα σύνολο, ένα `map` επιτρέπει την προσθήκη διακριτών, μοναδικών στοιχείων και υποστηρίζει ελέγχους συμμετοχής.

## 1. Ένα μέρος για να αποθηκεύεις πληροφορίες για τους παρευρισκόμενους

Για να παρακολουθήσεις την προσέλευση και την ηλικιακή σύνθεση, θέλεις να χρησιμοποιήσεις ένα σύνολο.

Δεν θέλεις να γράψεις ξεχωριστά σύνολα για ονόματα και ηλικίες. Αντί γι' αυτό, μπορείς να χρησιμοποιήσεις ένα γενικό σύνολο και για τα δύο.
Όρισε έναν τύπο `Set` ως `map[T comparable]struct{}` για να αποθηκεύεις τους παρευρισκόμενους.
Γράψε μια συνάρτηση `NewSet[T comparable]()` που επιστρέφει ένα κενό `Set[T]`.

```go
names := NewSet[string]()
```

## 2. Καταγραφή παρευρισκομένων

Τώρα είσαι έτοιμος να καταγράψεις πληροφορίες για τους παρευρισκόμενους.

Γράψε μια μέθοδο `Add[T]()` που προσθέτει ένα στοιχείο στο σύνολο.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Έλεγχος παρευρισκομένων

Τώρα που έχεις ένα σύνολο με τους παρευρισκόμενους, μπορείς να ελέγξεις αν εμφανίστηκαν συγκεκριμένα μέλη και ηλικιακές ομάδες.
Γράψε μια μέθοδο `Contains[T](element)` που επιστρέφει αν ένα μέλος ή μια ηλικιακή ομάδα βρίσκεται στο `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Σύγκριση παρευρισκομένων

Πέρασε άλλος ένας μήνας και έχεις ένα νέο `Set` με ηλικιακές ομάδες.
Ο διευθυντής μάρκετινγκ σου θέλει να μάθει αν οι νέες κυκλοφορίες αυτού του μήνα άλλαξαν τις ηλικιακές ομάδες που εμφανίζονται.
Γράψε μια μέθοδο `Equals[T](other)` που προσδιορίζει αν δύο σύνολα έχουν τα ίδια στοιχεία.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
