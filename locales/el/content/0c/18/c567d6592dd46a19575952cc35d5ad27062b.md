# Οδηγίες

Η Tori είναι δημοσιογράφος που γράφει για το κλίμα και θέλει να γράψει ένα άρθρο για τον καιρό σε διάφορες πόλεις. Έχει δεδομένα για τον καιρό σε διάφορες πόλεις και θέλει να τις κατατάξει με βάση τη θερμοκρασία τους, αλλά κάποιες θερμοκρασίες είναι σε Φαρενάιτ και κάποιες σε Κελσίου. Χρειάζεται τη βοήθειά σου για να μετατρέψεις τις θερμοκρασίες στην ίδια μονάδα και να τις κατατάξεις.

## 1. Μετατροπή από Φαρενάιτ σε Κελσίου

Όρισε τη συνάρτηση `fahrenheit_to_celsius` που παίρνει ως όρισμα μια θερμοκρασία σε Φαρενάιτ και επιστρέφει τη θερμοκρασία σε Κελσίου.

Για να μετατρέψεις από Φαρενάιτ σε Κελσίου, αφαίρεσε 32 από την τιμή σε Φαρενάιτ και μετά διαίρεσε το αποτέλεσμα με το 1,8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Σύγκριση δύο θερμοκρασιών

Όρισε τη συνάρτηση `compare_temperature` που παίρνει δύο θερμοκρασίες και επιστρέφει μια τιμή `Order` που δείχνει αν η πρώτη θερμοκρασία είναι μικρότερη από, ίση με ή μεγαλύτερη από τη δεύτερη.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Ταξινόμηση πόλεων με βάση τη θερμοκρασία

Όρισε τη συνάρτηση `sort_cities_by_temperature` που παίρνει μια λίστα με πόλεις και τις επιστρέφει από την πιο κρύα στην πιο ζεστή.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
