# Εισαγωγή

Η JavaScript έχει ένα ενσωματωμένο αντικείμενο, το `Date`, το οποίο αποθηκεύει ημερομηνία και ώρα και παρέχει μεθόδους για τη διαχείρισή τους.

<!-- prettier-ignore -->
~~~exercism/caution
Βασίστηκε στην κλάση `java.util.Date` της Java, η οποία αντικαταστάθηκε στις αρχές της δεκαετίας του 2010, αλλά για λόγους συμβατότητας προς τα πίσω, το `Date` της JavaScript παραμένει.

Επειδή είναι γενικά δύσκολο να δουλέψεις με ημερομηνίες και επειδή ο χειρισμός των ζωνών ώρας είναι κακός ή ανύπαρκτος, υπάρχουν πολλές βιβλιοθήκες, όπως οι `moment.js`, `day.js`, `date-fns` και `luxon`.
Καμία από αυτές δεν είναι διαθέσιμη στο Exercism.

Στα δικά σου έργα, μη χρησιμοποιείς ένα παρωχημένο ή μη συντηρούμενο πακέτο όπως το `moment.js`, αλλά βασίσου σε πιο σύγχρονες εναλλακτικές, όπως το `luxon`, ή στο [Temporal][mdn-temporal], που δεν είναι ακόμη ευρέως διαθέσιμο.
Αυτή η άσκηση εστιάζει στο `Date`, το οποίο θα παραμείνει επίκαιρο μέχρι το τέλος της JavaScript.

[mdn-temporal]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Temporal
~~~

## Δημιουργία

Ένα αντικείμενο `Date` είναι ένα στιγμιότυπο της κλάσης `Date`.
Μπορεί να δημιουργηθεί χωρίς να περάσεις κανένα όρισμα στη συνάρτηση κατασκευαστή.
Αυτό έχει ως αποτέλεσμα ένα αντικείμενο `Date` που αντιπροσωπεύει την τρέχουσα ημερομηνία και ώρα:

```javascript
const now = new Date();
// => Thu Apr 14 2022 11:46:08 GMT+0530 (India Standard Time)
// Shows current day, date and time (in your time zone).
```

### Unix timestamp (αριθμός)

Αν περάσεις έναν αριθμό, αυτός θα ερμηνευτεί ως `timestamp`.
Ένα timestamp είναι ένας ακέραιος αριθμός που αντιπροσωπεύει τον αριθμό των **χιλιοστών του δευτερολέπτου** που έχουν περάσει από την **1η Ιανουαρίου 1970 [UTC][defn-utc]+0**.

```javascript
const epoch = new Date(0);
// Thu Jan 01 1970 01:00:00 GMT+0100 (Central European Standard Time)

const another = new Date(1749508766627);
// Tue Jun 10 2025 00:39:26 GMT+0200 (Central European Summer Time)
```

Κάποιος μπορεί να περιμένει ότι το `new Date(0)` θα δημιουργήσει το "πιο πρώιμο" αντικείμενο ημερομηνίας, αλλά η JavaScript θα μετατρέψει την ημερομηνία στην τοπική σου ζώνη ώρας, που σημαίνει ότι μόνο όσοι βρίσκονται σε [GMT / με UTC+0][defn-gmt] ζώνη ώρας θα πάρουν στην πραγματικότητα την τιμή [Unix epoch][defn-unix-epoch].

### ISO 8601 timestamp (συμβολοσειρά)

Μπορείς να περάσεις μια τιμή συμβολοσειράς που αντιπροσωπεύει μια ημερομηνία στη συνάρτηση κατασκευαστή `Date`.
Η **μόνη** μορφή που είναι συνεπής σε όλες τις υλοποιήσεις είναι η [απλοποιημένη εκδοχή][mdn-date-string-format] των διεθνώς αναγνωρισμένων και τυποποιημένων, λεγόμενων [συμβολοσειρών timestamp ISO 8601][defn-iso8601].

Μια χρονική στιγμή σε [UTC][defn-gmt] μοιάζει κάπως έτσι:

```text
YYYY-MM-DDTHH:mm:ss.mssZ
YYYYMMDDTHHmmss.mssZ
```

Όπου γίνονται οι ακόλουθες αντικαταστάσεις:

| Κλειδί | Περιγραφή                                     | Προεπιλογή |
| ------ | --------------------------------------------- | ---------- |
| YYYY   | Το ημερολογιακό έτος, σε 4 ψηφία              |            |
| MM     | Ο ημερολογιακός μήνας, σε 2 ψηφία             | 01         |
| DD     | Η ημερολογιακή ημέρα, σε 2 ψηφία              | 01         |
| T      | Το κυριολεκτικό γράμμα T, που χωρίζει την ημερομηνία από την ώρα | T          |
| HH     | Οι ώρες σε 24ωρο ρολόι, 2 ψηφία               | 00         |
| mm     | Τα λεπτά, 2 ψηφία                             | 00         |
| ss     | Τα δευτερόλεπτα, 2 ψηφία                      | 00         |
| mss    | Τα χιλιοστά του δευτερολέπτου, 3 ψηφία        | 000        |
| Z      | Το κυριολεκτικό γράμμα Z, ή μια μετατόπιση `+/-HH:mm` |            |

Το κυριολεκτικό γράμμα `Z` δηλώνει UTC (χωρίς ζώνη ώρας, χωρίς θερινή ώρα).

Επειδή υπάρχουν προεπιλεγμένες τιμές για τα περισσότερα συστατικά, είναι έγκυρο να παραλείψεις μέρη από το τέλος:

```text
YYYY-MM-DD
```

Η προεπιλεγμένη ώρα είναι 00:00:00.000

Αν το timestamp δεν τελειώνει σε `Z` και δεν τελειώνει με `+HH:mm` ή `-HH:mm` (που δηλώνει μετατόπιση ζώνης ώρας), τότε, για ιστορικούς λόγους, ισχύουν τα εξής:

> Όταν λείπει η μετατόπιση ζώνης ώρας, οι μορφές μόνο ημερομηνίας ερμηνεύονται ως ώρα UTC και οι μορφές ημερομηνίας-ώρας ερμηνεύονται ως τοπική ώρα.
> Η ερμηνεία ως ώρα UTC οφείλεται σε ένα ιστορικό σφάλμα της προδιαγραφής που δεν ήταν συνεπές με το ISO 8601, αλλά δεν μπορούσε να αλλάξει λόγω συμβατότητας με τον ιστό.
> Δες [Σπασμένος parser: ένα ζήτημα της πραγματικότητας του ιστού][ref-broken-parser].

### Το αντικείμενο Date

Ένα υπάρχον αντικείμενο ημερομηνίας μπορεί επίσης να χρησιμοποιηθεί ως όρισμα της συνάρτησης κατασκευαστή.
Αυτό δημιουργεί ένα αντίγραφο του υπάρχοντος αντικειμένου `Date` με την ίδια ημερομηνία και ώρα.

```javascript
const t1 = new Date();
const t2 = new Date(t1);
// Values of t1 and t2 will be the same.
```

### Δίνοντας μεμονωμένες τιμές για τα συστατικά ημερομηνίας και ώρας

Μπορείς να δημιουργήσεις μια ημερομηνία περνώντας τρεις αριθμούς.
Μπορείς να δημιουργήσεις μια ημερομηνία και ώρα περνώντας έξι αριθμούς.

```javascript
const date1 = new Date(95, 11, 17);
// Creates Date for Dec 17 1995 00:00 if your local timezone is equivalent to UTC.

const date2 = new Date(2013, 12, 5, 13, 24, 0);
// Creates Date for Jan 5 2014 13:24 if your local timezone is equivalent to UTC.
```

Η δεύτερη τιμή είναι ο `month`, που ξεκινά από το `0` για τον Ιανουάριο και φτάνει μέχρι το `11` για τον Δεκέμβριο.

## `Date.parse()`

Μπορεί να συναντήσεις αναφορές σε μια συνάρτηση ανάλυσης ημερομηνίας, τη `Date.parse`.
Επειδή υπάρχουν μόνο λίγες σταθερές (αλήθειες) για αυτή τη συνάρτηση και επειδή η υπόλοιπη υλοποίηση δεν είναι καθορισμένη (άρα ούτε τυποποιημένη), καλό είναι να μην τη χρησιμοποιείς.

## Πρόσβαση στα συστατικά του `Date`

Υπάρχουν διάφορες μέθοδοι στα αντικείμενα ημερομηνίας που επιστρέφουν τα συστατικά της ημερομηνίας:

```javascript
getFullYear(); // Get the year (4 digits)
getMonth(); // Get the month, from 0 to 11.
getDate(); // Get the day of month, from 1 to 31.
getHours(); // Get the hour in a 24 clock, from 0 to 23
getMinutes(); // Get the minutes, from 0 to 59
getSeconds(); // Get the seconds, from 0 to 59
getMilliseconds(); // Get the milliseconds, from 0 and 999
getDay(); // Get the day of week, from 0 (Sunday) to 6 (Saturday).
```

Καθεμία από αυτές έχει μια αντίστοιχη παραλλαγή `set` (π.χ. `setFullYear`) για να ενημερώσεις την τιμή.
Κάθε τιμή που υπερχειλίζει μετακυλίεται στο επόμενο συστατικό:

```javascript
const date = new Date('2025-02-28T12:42:00Z');
// => Fri Feb 28 2025 13:42:00 GMT+0100 (Central European Standard Time)

date.setDate(29);
// there was no February 29th in 2025.

date.getDate();
// => 1

date.toString();
// => Sat Mar 01 2025 13:42:00 GMT+0100 (Central European Standard Time)
```

Υπάρχουν παραλλαγές UTC για όλες τις μεθόδους, που αγνοούν την τοπική ζώνη ώρας.

## Μετατροπή από ημερομηνία

Τα αντικείμενα ημερομηνίας έχουν μια μέθοδο `getTime()` που επιστρέφει το timestamp UNIX σε χιλιοστά του δευτερολέπτου, δηλαδή τον αριθμό των χιλιοστών του δευτερολέπτου από τα μεσάνυχτα της αρχής της 1ης Ιανουαρίου 1970, UTC.
Επιπλέον, υπάρχει μια μέθοδος `toISOString()` για να μετατρέψεις ένα αντικείμενο ημερομηνίας σε συμβολοσειρά timestamp ISO 8601.

## Σύγκριση ημερομηνιών

Οι τελεστές μεγαλύτερο από (`>`) και μεγαλύτερο ή ίσο με (`>=`), καθώς και μικρότερο από (`<`) και μικρότερο ή ίσο με (`<=`), μπορούν να χρησιμοποιηθούν απευθείας ανάμεσα σε δύο ημερομηνίες ή σε μια ημερομηνία και έναν αριθμό.
Αυτό λειτουργεί επειδή η JavaScript θα προσπαθήσει να μετατρέψει την ημερομηνία σε μια πρωτόγονη τιμή.

<!-- prettier-ignore -->
~~~exercism/advanced
Όταν κάνεις μια σύγκριση ανάμεσα σε δύο ημερομηνίες ή σε μια ημερομηνία και έναν αριθμό, η JavaScript καλεί το [`[Symbol.toPrimitive]("number")`][mdn-to-primitive], το οποίο εσωτερικά καλεί το [`date.valueOf()`][mdn-date-value-of].
Το τελευταίο είναι το ίδιο με το να καλέσεις το [`date.getTime()`][mdn-date-get-time].

Αν δε θέλεις να βασίζεσαι σε αυτή τη συμπεριφορά, μετατρέψε πρώτα σε αριθμό χρησιμοποιώντας το `getTime()`.

~~~
