# Σχετικά

Εκτός από το `cond`, η Elixir παρέχει επίσης το μάκρο [`if/2`][getting-started-if], το οποίο είναι χρήσιμο όταν χρειάζεται να ελέγξεις μόνο μία συνθήκη.

Το [`if/2`][kernel-if] δέχεται μια συνθήκη και δύο επιλογές. Επιστρέφει την πρώτη επιλογή αν η συνθήκη είναι _truthy_ και τη δεύτερη αν η συνθήκη είναι _falsy_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

Αν δεν δοθεί η δεύτερη επιλογή, θα επιστραφεί `nil`.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

Μπορείς επίσης να γράψεις μια έκφραση `if` σε μία μόνο γραμμή. Πρόσεξε το κόμμα μετά τη συνθήκη.

```elixir
if age >= 16, do: "beer", else: "no beer"
```

Αυτή η σύνταξη είναι χρήσιμη για πολύ σύντομες εκφράσεις, αλλά καλό είναι να την αποφεύγεις αν η έκφραση δεν χωράει σε μία γραμμή.

## _Truthy_ και _falsy_

Στην Elixir, όλοι οι τύποι δεδομένων αξιολογούνται σε μια τιμή _truthy_ ή _falsy_ όταν συναντώνται σε boolean περιβάλλον (όπως μια έκφραση `if`). Όλα τα δεδομένα θεωρούνται _truthy_ **εκτός** από το `false` και το `nil`. Συγκεκριμένα, οι κενές συμβολοσειρές, ο ακέραιος `0` και οι κενές λίστες θεωρούνται όλα _truthy_ στην Elixir. Με αυτόν τον τρόπο, [η Elixir μοιάζει με τη Ruby αλλά διαφέρει από τη JavaScript, την Python ή τη PHP][falsy-various-langs].

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

Οι [`&&/2`][kernel-and], [`||/2`][kernel-or] και [`!/1`][kernel-not] είναι _truthy_ boolean τελεστές που δουλεύουν με οποιαδήποτε τιμή και συμπληρώνουν τους _αυστηρούς_ boolean τελεστές [`and/2`][kernel-boolean-and], [`or/2`][kernel-boolean-or] και [`not/1`][kernel-boolean-not].

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
