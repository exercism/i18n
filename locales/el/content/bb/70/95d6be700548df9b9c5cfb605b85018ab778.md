# Σχετικά

Ένας αριθμός κινητής υποδιαστολής είναι ένας αριθμός με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή. Παραδείγματα είναι τα `-2.4`, `0.1`, `3.14`, `16.984025` και `1024.0`.

Η F# έχει τρεις τύπους κινητής υποδιαστολής:

- `single`: 4 bytes (~6-9 ψηφία ακρίβειας). Γράφεται ως `2.45f` ή `2.45F`. Ο τύπος `float32` μπορεί να χρησιμοποιηθεί ως ψευδώνυμο.
- `float`: 8 bytes (~15-17 ψηφία ακρίβειας). Αυτός είναι ο πιο συνηθισμένος τύπος. Γράφεται ως `2.45` ή χρησιμοποιώντας εκθετικό συμβολισμό ως `2.3E+32` ή `2.3e+32`. Ο τύπος `double` μπορεί να χρησιμοποιηθεί ως ψευδώνυμο.
- `decimal`: 16 bytes (28-29 ψηφία ακρίβειας). Χρησιμοποιείται συνήθως όταν δουλεύουμε με νομισματικά δεδομένα, καθώς η ακρίβειά του οδηγεί σε λιγότερα σφάλματα στρογγυλοποίησης. Γράφεται ως `2.45m` ή `2.45M`.

Κάθε τύπος κινητής υποδιαστολής έχει τη δική του [ακρίβεια, κατά προσέγγιση εύρος και μέγεθος][floating-point-types]. Η ακρίβεια δείχνει πόσα ψηφία μετά το σύμβολο διαχωρισμού ψηφίων μπορούν να αποθηκευτούν. Αυτό σημαίνει ότι αν προσπαθήσεις να αποθηκεύσεις το PI σε έναν `single`, θα αποθηκευτούν μόνο τα πρώτα 6 έως 9 ψηφία (με το τελευταίο ψηφίο να στρογγυλοποιείται).

Η μετατροπή μεταξύ διαφορετικών τύπων κινητής υποδιαστολής γίνεται με τους [τελεστές μετατροπής][conversion-operators]:

```fsharp
let floatFromSingle = float 2.45f
```

Να είσαι πάντα προσεκτικός όταν ελέγχεις τις τιμές των τύπων κινητής υποδιαστολής για ισότητα, καθώς τιμές που φαίνεται να αντιπροσωπεύουν την ίδια τιμή μπορεί στην πραγματικότητα να είναι διαφορετικές. Δες [αυτό το άρθρο][precision-in-comparisons] για περισσότερες πληροφορίες (τα παραδείγματα κώδικα είναι σε C#).

Μπορείς να βρεις μια σύντομη εισαγωγή στους αριθμούς κινητής υποδιαστολής στο [0.30000000000000004.com][0.30000000000000004.com]. Η [σελίδα Float Toy][evanw.github.io-float-toy] έχει μια ωραία, γραφική εξήγηση για το πώς τα bits ενός αριθμού κινητής υποδιαστολής μετατρέπονται σε μια πραγματική τιμή κινητής υποδιαστολής.
