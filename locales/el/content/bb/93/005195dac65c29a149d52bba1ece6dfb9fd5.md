# Κλάσεις με Κατάσταση

Κάθε κλάση μέχρι τώρα ήταν ένα κουτί με ρουτίνες. Καθεμιά έπαιρνε τα ορίσματά της, υπολόγιζε μια απάντηση και ξεχνούσε τα πάντα.

Μια κλάση μπορεί όμως να **θυμάται** πράγματα. Ένας πίνακας σκορ πρέπει οπωσδήποτε: το σκορ εξαρτάται πλέον από κάθε γκολ από τότε που ξεκίνησε το παιχνίδι.

## Ιδιότητες

Το `attr` δίνει σε μια κλάση κάτι να θυμάται.

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

Κάθε `attr` γίνεται μια ρουτίνα που διαβάζει την τιμή, και μία που την αλλάζει:

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

Ιδιότητες του ίδιου τύπου μπορούν να μοιράζονται μια δήλωση, όπως και τα ορίσματα:

```sather
   attr home_score, away_score : INT;
```

## Αντικείμενα

Μια κλάση με ιδιότητες είναι ένα πρότυπο για τη δημιουργία **αντικειμένων**. Κάθε αντικείμενο έχει τα δικά του αντίγραφα των ιδιοτήτων, οπότε δύο πίνακες σκορ κρατούν δύο σκορ.

Το `new` φτιάχνει ένα αντικείμενο. Μπαίνει μέσα σε μια ρουτίνα που ονομάζεται `create`, η οποία μετά γεμίζει το αντικείμενο και το επιστρέφει:

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

Το `SAME` σημαίνει "αυτή η κλάση". Αν έγραφες `SCOREBOARD` εκεί, θα έλεγες το ίδιο πράγμα, αλλά το `SAME` συνεχίζει να δουλεύει ακόμα κι αν η κλάση μετονομαστεί.

## Δημιουργώντας ένα

Το `#` καλεί το `create`:

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

Χρησιμοποιείς το `#` από το `rehearsal-script`. Το `#FSTR` είναι ακριβώς αυτό.

## Ρουτίνες που αλλάζουν το αντικείμενο

Μέσα στην κλάση, μια ιδιότητα χρησιμοποιείται με το όνομά της, χωρίς αντικείμενο μπροστά. Εννοεί το αντικείμενο στο οποίο κλήθηκε η ρουτίνα.

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Το `home_goal` δεν δηλώνει τύπο επιστροφής, γιατί δεν απαντά τίποτα. Αντί γι' αυτό, αλλάζει το αντικείμενο. Κάλεσέ το ως εντολή:

```sather
   board.home_goal;
```

## Οι ιδιότητες ξεκινούν κενές

Μια ιδιότητα που δεν έχει ορίσει κανείς περιέχει μηδέν για ένα `INT`, `false` για ένα `BOOL` και void για μια συμβολοσειρά ή ένα αντικείμενο. Έτσι ένας νέος πίνακας σκορ δείχνει 0 με 0 χωρίς να χρειάζεται να το πει τίποτα.
