# Υποδείξεις

## Γενικά

- Ίσως σου φανεί χρήσιμο να έχεις μια λίστα με όλες τις [αριθμητικές πράξεις][arithmetic-operations] στην PHP.

## 1. Αναλογία ζύμης

- Μπορείς να λύσεις αυτή την εργασία χρησιμοποιώντας βασικούς αριθμητικούς τελεστές για πρόσθεση και πολλαπλασιασμό.

## 2. Μια πιτσιλιά σάλτσας

- Για να εξασφαλίσεις έναν ακέραιο αριθμό κονσερβών, θα χρειαστεί να στρογγυλοποιήσεις προς τα πάνω.
- Η PHP παρέχει [αριθμητικές συναρτήσεις][numeric-functions] που μπορούν να βοηθήσουν.

## 3. Λίγο τυρί, παρακαλώ

- Μπορείς να υψώσεις έναν αριθμό στον κύβο χρησιμοποιώντας τον [τελεστή ύψωσης σε δύναμη][arithmetic-operations].
- Για να εξασφαλίσεις έναν ακέραιο αριθμό πιτσών, θα χρειαστεί να στρογγυλοποιήσεις προς τα κάτω.
- Η PHP παρέχει [αριθμητικές συναρτήσεις][numeric-functions] που μπορούν να βοηθήσουν.
- Η PHP έχει μια [ενσωματωμένη σταθερά][pi-constant] για το pi (π).

## 4. Δίκαιη μοιρασιά

- Χρησιμοποίησε τον [τελεστή υπολοίπου][arithmetic-operations] (`%`) για να πάρεις το υπόλοιπο της διαίρεσης.

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
[numeric-functions]: https://www.php.net/manual/en/ref.math.php
