# Προσθήκη οδηγιών

## Σημείωση

Χωρίς να χρησιμοποιήσεις την ενσωματωμένη μέθοδο flattening, μπορείς να φτιάξεις τη δική σου, αλλά θα χρειαστεί να διακρίνεις τι είναι συλλογή και τι όχι.
Εναλλακτικά, αν αποφασίσεις να χρησιμοποιήσεις τις ενσωματωμένες μεθόδους flattening, θα χρειαστεί να δημιουργήσεις έναν νέο τύπο Stream για να παρακάμψεις τη λανθασμένη συμπεριφορά.
