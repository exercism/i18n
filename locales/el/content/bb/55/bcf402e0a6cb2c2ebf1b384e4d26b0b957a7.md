# Οδηγίες

Αυτή η άσκηση ασχολείται με την ανάλυση αρχείων καταγραφής.

Μετά από μια πρόσφατη επισκόπηση ασφαλείας, σου ζητήθηκε να καθαρίσεις τα αρχειοθετημένα αρχεία καταγραφής του οργανισμού.

Όλες οι συμβολοσειρές που περνούν στις μεθόδους είναι εγγυημένο ότι δεν είναι null και δεν έχουν κενά στην αρχή ή στο τέλος.

## 1. Εντόπισε παραμορφωμένες γραμμές καταγραφής

Χρειάζεσαι μια ιδέα για το πόσες γραμμές καταγραφής στο αρχείο σου δεν συμμορφώνονται με τα τρέχοντα πρότυπα. Πιστεύεις ότι ένας απλός έλεγχος αποκαλύπτει αν μια γραμμή καταγραφής είναι έγκυρη. Για να θεωρηθεί έγκυρη, μια γραμμή πρέπει να αρχίζει με μία από τις παρακάτω συμβολοσειρές:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Υλοποίησε τη μέθοδο `LogParser.IsValidLine()` ώστε να επιστρέφει `false` αν μια συμβολοσειρά δεν είναι έγκυρη, αλλιώς `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Χώρισε τη γραμμή καταγραφής

Μια νέα ομάδα μπήκε στον οργανισμό και ανακαλύπτεις ότι τα αρχεία καταγραφής της χρησιμοποιούν έναν παράξενο διαχωριστικό για τα "πεδία". Αντί για κάτι λογικό όπως μια άνω και κάτω τελεία ":" χρησιμοποιούν μια συμβολοσειρά όπως "<--->" ή "<=>" (επειδή είναι πιο όμορφη), στην πραγματικότητα οποιαδήποτε συμβολοσειρά που έχει πρώτο χαρακτήρα το "<" και τελευταίο χαρακτήρα το ">" και οποιονδήποτε συνδυασμό από τους παρακάτω χαρακτήρες "^", "\*", "=" και "-" ενδιάμεσα.

Υλοποίησε τη μέθοδο `LogParser.SplitLogLine()` που παίρνει μια γραμμή και επιστρέφει έναν πίνακα από συμβολοσειρές, καθεμία από τις οποίες περιέχει ένα πεδίο.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Μέτρησε τον αριθμό των γραμμών που περιέχουν έναν κωδικό πρόσβασης σε εισαγωγικά

Η ομάδα πρέπει να μάθει για κωδικούς πρόσβασης που εμφανίζονται μέσα σε κείμενο με εισαγωγικά, ώστε να μπορούν να εξεταστούν χειροκίνητα.

Υλοποίησε τη μέθοδο `LogParser.CountQuotedPasswords()` για να δώσεις μια ένδειξη της πιθανής έκτασης της χειροκίνητης εργασίας.

Εντόπισε τις γραμμές καταγραφής όπου το κυριολεκτικό κείμενο "password", το οποίο μπορεί να είναι σε οποιονδήποτε συνδυασμό κεφαλαίων ή πεζών, περιβάλλεται από εισαγωγικά.
Θα πρέπει να λάβεις υπόψη την πιθανότητα επιπλέον περιεχομένου μέσα στα εισαγωγικά, πριν και μετά το "password".

Οι γραμμές που περνούν στη ρουτίνα μπορεί να είναι έγκυρες ή όχι, όπως ορίζεται στην εργασία 1. Τις επεξεργαζόμαστε με τον ίδιο τρόπο, ανεξάρτητα από το αν είναι έγκυρες.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Αφαίρεσε τα κατάλοιπα από το αρχείο καταγραφής

Ανακάλυψες ότι κάποια προηγούμενη επεξεργασία των καταγραφών έχει σκορπίσει το κείμενο "end-of-line" ακολουθούμενο από έναν αριθμό γραμμής (χωρίς κενό ανάμεσα) μέσα στις καταγραφές.

Υλοποίησε τη μέθοδο `LogParser.RemoveEndOfLineText()` που παίρνει μια συμβολοσειρά, αφαιρεί το κείμενο end-of-line και επιστρέφει μια "καθαρή" συμβολοσειρά.

Οι γραμμές που δεν περιέχουν το κείμενο end-of-line πρέπει να επιστρέφονται χωρίς αλλαγές.

Απλώς αφαίρεσε τη συμβολοσειρά end-of-line. Μην επιχειρήσεις να προσαρμόσεις τα κενά.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Λίστα τις γραμμές με εξαιρετικά αδύναμους κωδικούς πρόσβασης, ώστε να τιμωρηθούν οι ένοχοι

Πριν διαγράψουμε τους κωδικούς πρόσβασης από το αρχείο, πρέπει να καταγράψουμε όλες τις περιπτώσεις όπου οι κωδικοί πρόσβασης αρχίζουν με το κείμενο "password".

Υλοποίησε τη μέθοδο `LogParser.ListLinesWithPasswords()` ώστε να τυπώνει τον κωδικό πρόσβασης που παραβαίνει τον κανόνα, ακολουθούμενο από την πλήρη γραμμή.

Οι γραμμές με κωδικούς πρόσβασης σε εισαγωγικά έχουν ήδη αφαιρεθεί και επεξεργάζεσαι τις γραμμές ανεξάρτητα από το αν είναι έγκυρες (όπως στην εργασία 1).

Οι γραμμές που περιέχουν έναν κωδικό πρόσβασης που παραβαίνει τον κανόνα πρέπει να επιστρέφονται με πρόθεμα "<password>: ".

Οι γραμμές που δεν περιέχουν έναν κωδικό πρόσβασης που παραβαίνει τον κανόνα πρέπει να επιστρέφονται με πρόθεμα "--------: ".

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
