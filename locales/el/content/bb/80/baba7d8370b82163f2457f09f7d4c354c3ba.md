# Εισαγωγή

## Χαρακτήρες

Ο πρωτογενής τύπος `char` της Java είναι μια αναπαράσταση 16 bit ενός μεμονωμένου χαρακτήρα. Πολλοί `char` μπορούν να σχηματίσουν μια συμβολοσειρά, όπως `"word"`, ή οι `char` μπορούν να υποστούν επεξεργασία ανεξάρτητα. Ένα κυριολεκτικό `char` περιβάλλεται από μονά εισαγωγικά (π.χ. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

## Πώς παίρνεις τους `char` από μια `String`

Η μέθοδος `String.toCharArray` επιστρέφει τους χαρακτήρες ενός `String` ως πίνακα. Όπως αναφέρθηκε στους πίνακες, μπορείς να χρησιμοποιήσεις έναν `for` βρόχο για να διατρέξεις τον πίνακα.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Η κλάση Character

Υπάρχουν πολλές ενσωματωμένες μέθοδοι βιβλιοθήκης για να εξετάζεις και να χειρίζεσαι `char`. Αυτές βρίσκονται ως στατικές μέθοδοι της κλάσης `java.lang.Character`. Ορίστε μερικά παραδείγματα:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## Πώς προσθέτεις ένα `char` σε μια `String`

Ο τελεστής `+` μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα `char` σε μια `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Πρόσεξε _να μην_ χρησιμοποιήσεις το `+` για να ενώσεις δύο `char` ώστε να σχηματίσεις μια `String`!
Η πρόσθεση δύο `char` με αυτόν τον τρόπο δίνει ένα `int`, _όχι_ μια `String`!
Για παράδειγμα:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Αυτό συμβαίνει γιατί η Java προάγει το `char` σε `int` (δες [4.2 Πρωτογενείς τύποι και τιμές][jls-primitives] της [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Ωστόσο, όταν υπάρχουν πολλοί χαρακτήρες που πρέπει να προστεθούν, μπορεί να είναι πιο αποδοτικό να χρησιμοποιήσεις ένα `StringBuilder` αντ' αυτού:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
