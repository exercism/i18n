# Οδηγίες

Η ομάδα σχεδιασμού σου περνάει από τους μετασχηματισμούς CSS στο Factor για ένα μέρος της δουλειάς διάταξης. Για να μείνει ευχαριστημένη η υπόλοιπη ομάδα, θα φτιάξεις μικρούς, επαναχρησιμοποιήσιμους μετασχηματισμούς ως quotations που παίρνουν ένα σημείο 2D και επιστρέφουν ένα σημείο 2D.

Ένα σημείο είναι ένας πίνακας δύο στοιχείων `{ x y }`.

## 1. Μετατόπισε τις συντεταγμένες

Όρισε τη `translate-2d` ώστε να παίρνει δύο τιμές `dx` και `dy` από τη στοίβα και να επιστρέφει ένα quotation που μετατοπίζει ένα σημείο κατά `(dx, dy)`.

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. Κλιμάκωσε τις συντεταγμένες

Όρισε τη `scale-2d` με τον ίδιο τρόπο, ώστε να επιστρέφει ένα quotation που κλιμακώνει ένα σημείο κατά `(sx, sy)`.

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. Σύνθεσε δύο μετασχηματισμούς

Όρισε τη `compose-transformations` ώστε να παίρνει δύο quotations μετασχηματισμού `f` και `g` και να επιστρέφει ένα μόνο quotation που εφαρμόζει πρώτα το `f` και μετά το `g`.

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. Εφάρμοσε έναν μετασχηματισμό

Όρισε τη `apply-transformation` ώστε να παίρνει από τη στοίβα ένα σημείο και ένα quotation μετασχηματισμού και να επιστρέφει το μετασχηματισμένο σημείο.

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. Μετασχημάτισε πολλά σημεία μεμιάς

Όρισε τη `transform-points` ώστε να παίρνει έναν πίνακα από σημεία και ένα quotation μετασχηματισμού, και να επιστρέφει τον πίνακα με τα μετασχηματισμένα σημεία.

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
