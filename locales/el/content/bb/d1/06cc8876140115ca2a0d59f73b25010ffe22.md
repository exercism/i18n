# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για να μαγειρέψεις τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη σταθερά `Lasagna::EXPECTED_MINUTES_IN_OVEN`, η οποία επιστρέφει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```ruby
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

Όρισε τη μέθοδο `Lasagna#remaining_minutes_in_oven`, η οποία παίρνει ως παράμετρο τα πραγματικά λεπτά που τα λαζάνια βρίσκονται ήδη στον φούρνο και επιστρέφει πόσα λεπτά πρέπει να μείνουν ακόμη τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```ruby
lasagna = Lasagna.new
lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna#preparation_time_in_minutes`, η οποία παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να τα προετοιμάσεις, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```ruby
lasagna = Lasagna.new
lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna#total_time_in_minutes`, η οποία παίρνει δύο ονομαστικές παραμέτρους: η παράμετρος `number_of_layers` είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και η παράμετρος `actual_minutes_in_oven` είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις αφιερώσει στο μαγείρεμα των λαζανιών, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο μέχρι στιγμής.

```ruby
lasagna = Lasagna.new
lasagna.total_time_in_minutes(number_of_layers: 3, actual_minutes_in_oven: 20)
# => 26
```
