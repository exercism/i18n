# Σχετικά

Οι τύποι της C# μπορούν να οριστούν μέσα στο πεδίο εφαρμογής μιας κλάσης ή ενός struct. Ο περικλείων τύπος παρέχει ένα είδος χώρου ονομάτων. Η πρόσβαση στον τύπο γίνεται μέσω του περικλείοντος τύπου, με σύνταξη τελείας.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Επίπεδα πρόσβασης

Μπορούν να εφαρμοστούν επίπεδα πρόσβασης στους εσωτερικούς τύπους. Για παράδειγμα, αν μια κλάση είναι `private`, τότε δεν μπορεί να φανεί έξω από το πεδίο εφαρμογής του περικλείοντος τύπου, και φυσικά τα στιγμιότυπα δεν μπορούν να φανούν ούτε να χρησιμοποιηθούν έξω από αυτό το πεδίο.

Τα ιδιωτικά μέλη της εξωτερικής κλάσης είναι στο πεδίο εφαρμογής για όλα τα μέλη της εσωτερικής κλάσης, αλλά μόνο τα μη ιδιωτικά μέλη της εσωτερικής κλάσης είναι στο πεδίο εφαρμογής για τα μέλη της εξωτερικής κλάσης. Για να έχει πρόσβαση η εσωτερική κλάση στα μέλη της εξωτερικής κλάσης, πρέπει να της δοθεί ένα στιγμιότυπο της εξωτερικής κλάσης.

Αυτό φαίνεται στο παρακάτω παράδειγμα:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Αποτροπή της ανεξάρτητης δημιουργίας στιγμιότυπων

Υπάρχει ένα μοτίβο για να εμποδίσεις τη δημιουργία στιγμιοτύπων ενός τύπου έξω από τον περικλείοντα τύπο. Εκθέτεις μια δημόσια διεπαφή, αλλά κρατάς την κλάση που την υλοποιεί ιδιωτική.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Σημείωση για προγραμματιστές Java

Οι εμφωλευμένες κλάσεις της C# είναι ένας συνδυασμός των static εμφωλευμένων κλάσεων και των εσωτερικών κλάσεων της Java. Στη C#, τα ιδιωτικά μέλη της περικλείουσας κλάσης είναι στο πεδίο εφαρμογής για τα μέλη της εμφωλευμένης κλάσης, αλλά δεν υπάρχει ειδική σύνταξη για τη δημιουργία στιγμιοτύπων τους και τη σύνδεσή τους με ένα στιγμιότυπο της περικλείουσας κλάσης. Πρέπει να χρησιμοποιήσεις κάποια παραλλαγή του μοτίβου που φαίνεται στα παραπάνω παραδείγματα.

Η C# έχει όντως static εμφωλευμένες κλάσεις, αλλά αυτές είναι απλώς περικλειόμενες κλάσεις με static συμπεριφορά.
