# Οδηγίες

Συντηρείς τη βιβλιοθήκη μακροεντολών πάνω στην οποία είναι χτισμένη η μηχανή στοιχειοθεσίας ενός περιοδικού.
Η ίδια η μηχανή, οι συναρτήσεις που σελιδοποιούν κάθε σελίδα, είναι σταθερή και δεν τη γράφεις εσύ.
Αυτό που γράφεις είναι ο μηχανισμός του χρόνου συναρμολόγησης από τον οποίο είναι χτισμένη.

Αυτή η άσκηση δεν απαιτεί να γράψεις καμία συνάρτηση, μόνο μακροεντολές.
Στη συνέχεια, αυτές οι μακροεντολές συμπεριλαμβάνονται και καλούνται σε συναρτήσεις που έχουν ήδη προκαθοριστεί σε άλλο αρχείο.

Έχεις τέσσερις εργασίες.

~~~~exercism/caution
Κάθε μακροεντολή καλείται με το ακριβές όνομα και την ακριβή σειρά ορισμάτων που δίνει η εργασία της, οπότε γράψε τις ακριβώς.
Αλλιώς το αρχείο δεν θα συναρμολογηθεί.
~~~~

## 1. Δώσε ονόματα στις σταθερές της μορφής

Η μορφή του περιοδικού είναι μια χούφτα σταθεροί αριθμοί, και το υπόλοιπο της διάταξης αναφέρεται σε αυτούς μόνο με το όνομά τους.
Θα πρέπει να δώσεις σε καθέναν ένα ευανάγνωστο όνομα στον χρόνο συναρμολόγησης:

- `COLUMN_COUNT` είναι `4`
- `COLUMN_STRIDE` είναι `18`
- `SPACE` είναι `0x20`, το κενό byte
- `RULE` είναι `0x3D`, το byte `=`
- `RULE_WIDTH` είναι `4`
- `PLAIN` είναι `0x2E`, το byte `.`
- `RULED` είναι `0x2D`, το byte `-`
- `BOXED` είναι `0x23`, το byte `#`

Η μηχανή τα αναφέρει με τη σειρά παραπάνω.

```c
out = {4, 18, 32, 61, 4, 46, 45, 35} // the eight named values, in order
```

## 2. Γράψε τη μακροεντολή `fill_run`

Η μηχανή γεμίζει με κενά ένα δοκίμιο και τοποθετεί τις γραμμές της επικεφαλίδας σφραγίζοντας μια σειρά από ένα μόνο byte.
Αποτύπωσε αυτό το βήμα ως μακροεντολή πολλαπλών γραμμών που η μηχανή μπορεί να καλέσει όπου χρειάζεται να γεμίσει μια σειρά.

Πρώτα, όρισε ένα ευανάγνωστο όνομα `COUNTER` για τον καταχωρητή `rcx`.
Έπειτα, όρισε τη μακροεντολή `fill_run` που θα γεμίζει έναν πίνακα με N αντίγραφα ενός byte.
Δέχεται τρία ορίσματα με αυτή τη σειρά:

1. τη διεύθυνση προορισμού, που περνιέται σε έναν καταχωρητή γενικού σκοπού 64 bit.
2. το πλήθος των byte (N) που θα γραφτούν, που περνιέται σε έναν καταχωρητή γενικού σκοπού 64 bit ή ως άμεση τιμή.
3. το byte που θα γραφτεί, που περνιέται ως άμεση τιμή.

```x86asm
fill_run rdi, rax, SPACE
fill_run rdx, RULE_WIDTH, RULE
```

Η μακροεντολή `fill_run` μπορεί να χαλάσει ελεύθερα τον `COUNTER`, αλλά κανέναν άλλο καταχωρητή.

Σημείωσε ότι το πλήθος των byte μπορεί να περαστεί σε έναν καταχωρητή γενικού σκοπού 64 bit, όπως ο `rax` ή ο `rsi`, ή ως άμεση τιμή, όπως το `10` ή το `4`.
Μπορείς να θεωρήσεις ότι αυτό το πλήθος δεν είναι ποτέ αρνητικό.

Αυτή η μακροεντολή καλείται τρεις φορές, σε δύο διαφορετικές συναρτήσεις.

```c
length = 8
page   = {32, 32, 32, 32, 32, 32, 32, 32}

width  = 8
page   = {61, 61, 61, 61, 32, 32, 32, 32} // '====' then spaces
```

## 3. Γράψε τη μακροεντολή `lay_columns`

Το πλέγμα είναι σταθερό για τη μορφή, οπότε οι αρχές των στηλών μπορούν να υπολογιστούν στον χρόνο συναρμολόγησης.

Όρισε τη μακροεντολή `lay_columns`, που γράφει `COLUMN_COUNT` μετατοπίσεις, καθεμία έναν ακέραιο 64 bit.
Δέχεται δύο ορίσματα με αυτή τη σειρά:

1. τη διεύθυνση προορισμού, που περνιέται σε έναν καταχωρητή γενικού σκοπού 64 bit
2. το αριστερό περιθώριο, που περνιέται σε έναν καταχωρητή γενικού σκοπού 64 bit

```x86asm
lay_columns rsi, rax
```

Το πλήθος των μετατοπίσεων που θα γραφτούν στη διεύθυνση προορισμού είναι σταθερό και ίσο με `COLUMN_COUNT`.

Κάθε μετατόπιση είναι μια τιμή 64 bit που υπολογίζεται με `offset[i] = margin + i * COLUMN_STRIDE`, όπου `i` είναι η θέση της μετατόπισης ξεκινώντας από το `0`, και `margin` είναι το δεύτερο όρισμα.

Αυτή η μακροεντολή μπορεί να χαλάσει τα δύο ορίσματα καταχωρητών της, αλλά κανένα άλλο.
Καλείται μία φορά.

```c
margin = 3
out    = {3, 21, 39, 57}
```

## 4. Γράψε τη μακροεντολή `set_header`

Καθεμία από τις τρεις μόνιμες ενότητες έχει στυλ επικεφαλίδας καθορισμένο από τη μορφή, οπότε το byte είναι γνωστό στον χρόνο συναρμολόγησης.

Όρισε τη `set_header`, που δέχεται δύο ορίσματα με αυτή τη σειρά:

1. τη διεύθυνση προορισμού.
2. ένα αναγνωριστικό στυλ, κυριολεκτικά, που περνιέται ως άμεση τιμή, όπου `0` σημαίνει απλό, `1` σημαίνει με γραμμή, και `2` σημαίνει με πλαίσιο.

Η διεύθυνση προορισμού είναι η έκφραση μιας ενεργού διεύθυνσης μνήμης.
Δέχεται έναν βασικό καταχωρητή που μπορεί να αθροιστεί με έναν καταχωρητή θέσης κλιμακωμένο με `1`, `2`, `4` ή `8`, και μια άμεση τιμή:

```x86asm
set_header rdx+8*rcx+2, 1
```

Διάλεξε το byte της επικεφαλίδας (`PLAIN`, `RULED`, ή `BOXED`) με συναρμολόγηση υπό συνθήκη (`%if` / `%elif` / `%else`) αντί για διακλάδωση κατά τον χρόνο εκτέλεσης.

Αυτή η μακροεντολή δεν πρέπει να χαλάσει κανέναν καταχωρητή.
Καλείται τρεις φορές στην ίδια συνάρτηση.

```c
pitch = 4
out   = {46, 0, 0, 0, 45, 0, 0, 0, 35} // '.', '-', '#'
```
