# Μπάρμαν

## Ιστορία

Είσαι ένας κορυφαίος mixologist και φτιάχνεις νόστιμα ποτά για τον κόσμο να τα απολαμβάνει στις βραδινές του εξόδους. Αλλά σκέφτηκες ότι θα μπορούσες να κάνεις τη ζωή σου πιο εύκολη γράφοντας λίγο κώδικα που θα σε βοηθάει στη δουλειά σου.

## Εργασίες

Αυτές είναι παραδείγματα εργασιών που ταιριάζουν στην ιστορία του freelancer που επικοινωνεί με έναν project manager:

- Υπολόγισε πόση ώρα χρειάζεται για να φτιαχτεί μια παραγγελία
- Αναπλήρωσε το απόθεμά σου σε φέτες λάιμ
- Ολοκλήρωσε τη βάρδιά σου
- Παρακολούθησε συγκεκριμένες παραγγελίες
