# Σχετικά

Οι συμβολοσειρές είναι ένας τύπος δεδομένων που αναπαριστά μια τιμή κειμένου.
Οι [`Strings`][strings-and-characters] στη Swift είναι μια συλλογή από `Character`, καθένα από τα οποία περιέχει μια [τιμή βαθμωτού Unicode][unicode-scalar-values].

Μπορείς να δημιουργήσεις μια συμβολοσειρά μέσα από ένα κυριολεκτικό συμβολοσειράς, που είναι μια σειρά χαρακτήρων κλεισμένη σε διπλά εισαγωγικά (`"`).
Για συμβολοσειρές πολλών γραμμών, μπορείς να χρησιμοποιήσεις τριπλά εισαγωγικά (`"""`).

```swift
let hello : String = "Hello, World!"

let poem : String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Οι συμβολοσειρές στη Swift αποκτούν επίσης όλη τη λειτουργικότητα της κλάσης [NSString][nsstring-docs], η οποία χρησιμοποιούνταν αρχικά στις βιβλιοθήκες Objective-C της Apple.

## Χαρακτήρας

Ο `Character` είναι ένας τύπος δεδομένων που αποθηκεύει μία μόνο [τιμή βαθμωτού Unicode][unicode-scalar-values], η οποία αποτελείται από ένα ή περισσότερα κωδικά σημεία Unicode.
Μια τιμή βαθμωτού Unicode είναι οποιοδήποτε [κωδικό σημείο][unicode] Unicode στην περιοχή από `U+0000` έως `U+D7FF` συμπεριλαμβανομένων ή από `U+E000` έως `U+10FFFF` συμπεριλαμβανομένων.

```swift
let aChar : Character = "A"
```

## Εξαγωγή τύπου

Η Swift μπορεί να συμπεράνει τον τύπο ενός κυριολεκτικού συμβολοσειράς και, εξ ορισμού, θα συμπεράνει ότι είναι `String`.
Μπορείς να δηλώσεις ρητά ότι μια συμβολοσειρά είναι `Character` χρησιμοποιώντας τον σχολιασμό τύπου `Character`, ο οποίος απαιτεί η τιμή να είναι ένας μόνο χαρακτήρας.

```swift
let aString = "A"
let aChar: Character = "A"
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Συνένωση

Στη Swift, οι συμβολοσειρές μπορούν να [συνενωθούν][] χρησιμοποιώντας τον τελεστή `+`.
Οι χαρακτήρες **δεν** μπορούν να συνενωθούν με συμβολοσειρές χρησιμοποιώντας τον τελεστή `+` χωρίς πρώτα να μετατραπεί ο χαρακτήρας σε συμβολοσειρά.

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Η μέθοδος [`append(_:)`][append] μεταβάλλει τη συμβολοσειρά προσθέτοντας στο τέλος της είτε μια συμβολοσειρά είτε έναν χαρακτήρα.

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Παρεμβολή συμβολοσειρών

Η [παρεμβολή συμβολοσειρών][string-interpolation] είναι ένας τρόπος να κατασκευάσεις μια συμβολοσειρά με βάση τιμές από διαφορετικές πηγές, όπως μεταβλητές και εκφράσεις.
Για να εισαγάγεις μια τιμή σε μια συμβολοσειρά με παρεμβολή συμβολοσειρών, τοποθετείς μια έκφραση ή τιμή μέσα σε παρενθέσεις που προηγούνται από έναν χαρακτήρα ανάστροφης καθέτου.

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Ιδιότητες συμβολοσειρών και χαρακτήρων

Οι συμβολοσειρές και οι χαρακτήρες έχουν μερικές διαφορετικές _ιδιότητες_ τις οποίες μπορείς να ερωτήσεις για να πάρεις πληροφορίες σχετικά με τη συμβολοσειρά ή τον χαρακτήρα.

### Ιδιότητες συμβολοσειράς

Ορίστε μερικές από τις πιο συνηθισμένες ιδιότητες συμβολοσειράς· για να τις βρεις όλες, δες την [τεκμηρίωση][string-docs].

| Ιδιότητα | Περιγραφή                                      | Παράδειγμα                    |
| --------- | ---------------------------------------------- | ------------------------------ |
| `isEmpty` | Επιστρέφει `true` αν η συμβολοσειρά είναι κενή | `"Hello".isEmpty equals false` |
| `count`   | Επιστρέφει τον αριθμό των χαρακτήρων στη συμβολοσειρά | `"Hello".count   equals 5`     |

### Ιδιότητες χαρακτήρα

Ορίστε μερικές από τις πιο συνηθισμένες ιδιότητες χαρακτήρα· για να τις βρεις όλες, δες την [τεκμηρίωση][string-docs].

| Ιδιότητα       | Περιγραφή                                     | Παράδειγμα                     |
| -------------- | --------------------------------------------- | ------------------------------ |
| `isLowercase`  | Επιστρέφει `true` αν ο χαρακτήρας είναι πεζός | `"a".isLowercase  equals true` |
| `isUppercase`  | Επιστρέφει `true` αν ο χαρακτήρας είναι κεφαλαίος | `"A".isUppercase  equals true` |
| `isNumber`     | Επιστρέφει `true` αν ο χαρακτήρας είναι αριθμός | `"1".isNumber     equals true` |
| `isWhitespace` | Επιστρέφει `true` αν ο χαρακτήρας είναι κενό διάστημα | `" ".isWhitespace equals true` |

## Μετατροπή τύπου

Για να μετατρέψεις έναν τύπο σε συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον αρχικοποιητή `String()`, ο οποίος δέχεται διάφορους τύπους, όπως `Int`, `Double`, `Character` και άλλους.

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Ειδικοί χαρακτήρες

Η Swift έχει μερικούς [ειδικούς χαρακτήρες][special-characters] που μπορούν να χρησιμοποιηθούν σε συμβολοσειρές.

| Τιμή     | Περιγραφή                     |
| -------- | ----------------------------- |
| `\0`     | Χαρακτήρας null               |
| `\\`     | Ανάστροφη κάθετος             |
| `\t`     | Οριζόντιος στηλοθέτης         |
| `\n`     | Αλλαγή γραμμής                |
| `\r`     | Επιστροφή φορείου             |
| `\'`     | Μονό εισαγωγικό               |
| `\"`     | Διπλό εισαγωγικό              |
| `\uFFFF` | Δεκαεξαδικός χαρακτήρας Unicode |

```swift
let quote : String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode : Character = "\u{1F496}"
print(unicode) // Prints 💖
```
