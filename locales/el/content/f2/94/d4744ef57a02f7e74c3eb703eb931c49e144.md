# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις μερικούς από τους κανόνες του [Blackjack][blackjack], όπως τον τρόπο που παίζεται και βαθμολογείται το παιχνίδι.

**Σημείωση**: Σε αυτή την άσκηση, το _`A`_ σημαίνει άσο, το _`J`_ σημαίνει βαλέ, το _`Q`_ σημαίνει ντάμα και το _`K`_ σημαίνει ρήγα.
Οι τζόκερ αφαιρούνται.
Υποθέτουμε μια [τυπική τράπουλα 52 φύλλων με γαλλικά χρώματα][standard_deck], αλλά στις περισσότερες εκδοχές, αρκετές τράπουλες ανακατεύονται μαζί για το παιχνίδι.

## 1. Υπολόγισε την τιμή ενός φύλλου

Στο Blackjack, εξαρτάται από κάθε παίκτη αν ένας άσος αξίζει 1 ή 11 πόντους (_περισσότερα γι' αυτό αργότερα_).
Τα φύλλα με φιγούρα (`J`, `Q`, `K`) βαθμολογούνται με 10 πόντους, ενώ κάθε άλλο φύλλο αξίζει την τιμή της «κουκκίδας» του (_δηλαδή την αριθμητική του τιμή_).

Όρισε τη συνάρτηση `value_of_card(<card>)` με παράμετρο `card`.
Η συνάρτηση θα πρέπει να επιστρέφει την _αριθμητική τιμή_ της συμβολοσειράς του φύλλου που δέχεται ως όρισμα.
Επειδή ένας άσος μπορεί να πάρει πολλαπλές τιμές (1 **ή** 11), αυτή η συνάρτηση θα πρέπει, για την ώρα, να ορίζει την τιμή ενός άσου στο 1.
Πιο μετά, θα υλοποιήσεις μια συνάρτηση που θα καθορίζει την τιμή ενός άσου, δεδομένου ενός υπάρχοντος χεριού.

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. Καθόρισε ποιο φύλλο έχει μεγαλύτερη τιμή

Όρισε τη συνάρτηση `higher_card(<card_one>, <card_two>)` με παραμέτρους `card_one` και `card_two`.
Για τη βαθμολόγηση, η τιμή του `J`, του `Q` ή του `K` είναι 10.
Η συνάρτηση θα πρέπει να επιστρέφει ποιο φύλλο έχει τη μεγαλύτερη τιμή για τη βαθμολόγηση.
Αν και τα δύο φύλλα έχουν ίση τιμή, επέστρεψέ τα και τα δύο.
Μπορείς να επιστρέψεις και τα δύο φύλλα χρησιμοποιώντας ένα κόμμα στην εντολή `return`:

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

Ένας άσος μπορεί να πάρει πολλαπλές τιμές, οπότε για αυτό το βήμα θα ορίσουμε τα φύλλα `A` στην τιμή 1.

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. Υπολόγισε την τιμή ενός άσου

Όπως αναφέρθηκε προηγουμένως, ένας άσος μπορεί να αξίζει _είτε_ 1 **είτε** 11 πόντους.
Οι παίκτες προσπαθούν να πλησιάσουν όσο το δυνατόν περισσότερο στους 21 πόντους, χωρίς να ξεπεράσουν το 21 (_δηλαδή να «σπάσουν»_).

Όρισε τη συνάρτηση `value_of_ace(<card_one>, <card_two>)` με παραμέτρους `card_one` και `card_two`, που είναι δύο φύλλα που βρίσκονται ήδη στο χέρι _πριν_ πάρεις άσο.
Η συνάρτηση θα πρέπει να αποφασίσει αν ο άσος που έρχεται θα πάρει τιμή 1 ή τιμή 11 και να επιστρέψει αυτή την τιμή.
Θυμήσου: η τιμή του χεριού με τον άσο πρέπει να είναι όσο το δυνατόν μεγαλύτερη, _χωρίς_ να ξεπερνά το 21.

**Υπόδειξη**: αν έχουμε ήδη έναν άσο στο χέρι, τότε η τιμή για τον άσο που έρχεται θα ήταν 1.

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. Καθόρισε ένα «φυσικό» ή «Blackjack» χέρι

Αν ένας παίκτης πάρει έναν άσο (`A`) και ένα δεκάρι (10, `K`, `Q` ή `J`) ως τα δύο πρώτα του φύλλα, τότε ο παίκτης έχει σκορ 21.
Αυτό είναι γνωστό ως χέρι **blackjack**.


Όρισε τη συνάρτηση `is_blackjack(<card_one>, <card_two>)` με παραμέτρους `card_one` και `card_two`, που είναι δύο φύλλα.
Καθόρισε αν το χέρι των δύο φύλλων είναι **blackjack** και επέστρεψε τη boolean (λογική τιμή) `True` αν είναι, αλλιώς `False`.

**Σημείωση**: Ο _υπολογισμός_ του σκορ μπορεί να γίνει με πολλούς τρόπους.
Αλλά αν είναι δυνατόν, θα θέλαμε να ελέγξεις αν υπάρχει ένας άσος και ένα δεκάρι **_μέσα_** στο χέρι (_ή σε μια συγκεκριμένη θέση_), αντί να _αθροίσεις_ τις τιμές του χεριού.

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. Χωρισμός ζευγαριών

Αν τα δύο πρώτα φύλλα ενός χεριού έχουν την ίδια τιμή (_για παράδειγμα, δύο εξάρια ή ένα `Q` και ένα `K`_), ο παίκτης μπορεί να επιλέξει να τα αντιμετωπίσει ως δύο ξεχωριστά χέρια.
Αυτό είναι γνωστό ως «χωρισμός ζευγαριών».

Όρισε τη συνάρτηση `can_split_pairs(<card_one>, <card_two>)` με παραμέτρους `card_one` και `card_two`, που είναι δύο φύλλα.
Καθόρισε αν αυτό το χέρι των δύο φύλλων μπορεί να χωριστεί σε δύο ζευγάρια.
Αν το χέρι μπορεί να χωριστεί, επέστρεψε τη boolean (λογική τιμή) `True`, αλλιώς επέστρεψε `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. Διπλασιασμός του πονταρίσματος

Όταν τα δύο αρχικά φύλλα που μοιράστηκαν έχουν σύνολο 9, 10 ή 11 πόντους, ο παίκτης μπορεί να τοποθετήσει ένα επιπλέον ποντάρισμα ίσο με το αρχικό του.
Αυτό είναι γνωστό ως «διπλασιασμός του πονταρίσματος».

Όρισε τη συνάρτηση `can_double_down(<card_one>, <card_two>)` με παραμέτρους `card_one` και `card_two`, που είναι δύο φύλλα.
Καθόρισε αν το χέρι των δύο φύλλων μπορεί να «διπλασιαστεί» και επέστρεψε τη boolean (λογική τιμή) `True` αν μπορεί, αλλιώς `False`.

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
