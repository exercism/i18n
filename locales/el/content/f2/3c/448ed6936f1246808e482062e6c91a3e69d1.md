## Επιπλέον επιλογές γραμμής εντολών για το `jq`

Θα παρατηρήσεις επιπλέον επιλογές για το `jq` στα tests.

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

Τι είναι αυτές;

- `-s`

  Αυτή είναι η λειτουργία "slurp".
  Αντί να χειρίζεται την είσοδο ως ροή αντικειμένων JSON,
  όλη η είσοδος μαζεύεται σε έναν πίνακα.

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  Μπορεί να έχεις δει ήδη το `-r`, για να βγάζει "ωμές" συμβολοσειρές (χωρίς εισαγωγικά).
  Αυτό είναι το αντίθετο.
  Κάθε γραμμή της εισόδου θεωρείται ότι είναι μια συμβολοσειρά.

  Δύο παραδείγματα:

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

Όταν βάλεις αυτές τις δύο επιλογές μαζί, _δεν_ παίρνεις έναν πίνακα από συμβολοσειρές:
παίρνεις ολόκληρη την είσοδο ως μία μόνο συμβολοσειρά, μαζί με τους χαρακτήρες αλλαγής γραμμής στο τέλος κάθε γραμμής.

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

Ο χειρισμός αυτού είναι μέρος της πρόκλησης αυτής της άσκησης.
