# Σημειώσεις για αυτή την άσκηση στη διαδρομή Python

Μπορείς να κάνεις τις εξής υποθέσεις για τα δεδομένα εισόδου των τεστ της συνάρτησης `sum_of_multiples`:

- Όλοι οι αριθμοί εισόδου είναι **_μη αρνητικοί `int`_** (_δηλαδή φυσικοί αριθμοί, συμπεριλαμβανομένου του μηδενός_).
- Πρέπει να δοθεί μια `list` παραγόντων, και τα στοιχεία της είναι μοναδικά και ταξινομημένα σε αύξουσα σειρά.
