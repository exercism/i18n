# Οδηγίες

Με δεδομένη μια ηλικία σε δευτερόλεπτα, υπολόγισε πόσο χρονών θα ήταν κάποιος σε έναν πλανήτη του Ηλιακού μας Συστήματος.

Ένα έτος της Γης ισούται με 365.25 ημέρες της Γης, ή 31,557,600 δευτερόλεπτα.
Αν σου έλεγαν ότι κάποιος είναι 1,000,000,000 δευτερόλεπτα, η ηλικία του θα ήταν 31.69 έτη της Γης.

Για τους άλλους πλανήτες, πρέπει να λάβεις υπόψη την τροχιακή τους περίοδο σε έτη της Γης:

| Πλανήτης | Τροχιακή περίοδος σε έτη της Γης |
| ------- | ----------------------------- |
| Ερμής   | 0.2408467                     |
| Αφροδίτη | 0.61519726                   |
| Γη      | 1.0                           |
| Άρης    | 1.8808158                     |
| Δίας    | 11.862615                     |
| Κρόνος  | 29.447498                     |
| Ουρανός | 84.016846                     |
| Ποσειδώνας | 164.79132                  |

~~~~exercism/note
Το πραγματικό μήκος μιας πλήρους περιφοράς της Γης γύρω από τον ήλιο είναι πιο κοντά στις 365.256 ημέρες (1 αστρικό έτος).
Το Γρηγοριανό ημερολόγιο έχει, κατά μέσο όρο, 365.2425 ημέρες.
Αν και όχι απολύτως ακριβής, το 365.25 είναι η τιμή που χρησιμοποιείται σε αυτή την άσκηση.
Δες το [Έτος στη Βικιπαίδεια][year] για περισσότερους τρόπους μέτρησης ενός έτους.

[year]: https://en.wikipedia.org/wiki/Year#Summary
~~~~
