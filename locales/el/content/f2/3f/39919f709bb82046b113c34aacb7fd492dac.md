# Σχετικά

Μια _συμβολοσειρά_ είναι ο τύπος δεδομένων της JavaScript για την αποθήκευση δεδομένων κειμένου.
Δεν υπάρχει ξεχωριστός τύπος δεδομένων για έναν μεμονωμένο χαρακτήρα.

## Δημιουργία συμβολοσειράς

Δημιουργείς μια συμβολοσειρά [literal][literal] τυλίγοντας το κείμενο σε μονά ή διπλά εισαγωγικά.
Στο Exercism χρησιμοποιούνται μονά εισαγωγικά.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Κάποιοι ειδικοί χαρακτήρες του κειμένου πρέπει να έχουν μπροστά τους ένα backslash `\`, δες τις [ακολουθίες διαφυγής στο MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Εκτός από τα μονά και τα διπλά εισαγωγικά, μπορείς να δημιουργήσεις μια συμβολοσειρά τυλίγοντας το κείμενο σε backticks (βαρείες).
Αυτή η σύνταξη επιτρέπει να συμπεριλάβεις μονά ή διπλά εισαγωγικά ακόμη και αλλαγές γραμμής χωρίς να χρειάζεται να τα κάνεις escape.
Επιτρέπει επίσης να ενσωματώσεις εκφράσεις, δες τις [Συμβολοσειρές προτύπων][mdn-template-strings] για περισσότερες λεπτομέρειες.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Οι συμβολοσειρές ως λίστες χαρακτήρων

Μια συμβολοσειρά μπορεί να αντιμετωπιστεί ως λίστα χαρακτήρων, όπου ο πρώτος χαρακτήρας έχει θέση `0`.
Μπορείς να προσπελάσεις έναν μεμονωμένο χαρακτήρα της συμβολοσειράς χρησιμοποιώντας αγκύλες και τη θέση του γράμματος που θέλεις να πάρεις.
Εναλλακτικά, υπάρχει και η μέθοδος `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Μπορείς να βρεις τον αριθμό των χαρακτήρων μιας συμβολοσειράς προσπελαύνοντας την ιδιότητα `length`.

```javascript
'cat'.length;
// => 3
```

## Συνένωση και μέθοδοι

Ο πιο απλός τρόπος για να συνενώσεις συμβολοσειρές είναι να χρησιμοποιήσεις τον τελεστή πρόσθεσης `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Οι συμβολοσειρές παρέχουν πολλές βοηθητικές μεθόδους, δες τα [έγγραφα του MDN για τις μεθόδους των συμβολοσειρών][mdn-string-methods] για μια πλήρη λίστα.
Η παρακάτω λίστα δείχνει μερικές από τις πιο συνηθισμένες βοηθητικές μεθόδους.

- [`toUpperCase`][mdn-to-upper-case] και [`toLowerCase`][mdn-to-lower-case] - αλλάζουν τα πεζά και τα κεφαλαία όλων των χαρακτήρων
- [`trim`][mdn-trim] - αφαιρεί τα κενά στην αρχή και στο τέλος
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] και [`endsWith`][mdn-ends-with] - ελέγχουν αν μια άλλη συμβολοσειρά είναι μέρος της δεδομένης συμβολοσειράς
- [`slice`][mdn-slice] - εξάγει ένα τμήμα της συμβολοσειράς

## Οι συμβολοσειρές είναι αμετάβλητες

Η εφαρμογή των παραπάνω μεθόδων δεν αλλάζει ποτέ την αρχική συμβολοσειρά. Αντ' αυτού δημιουργείται και επιστρέφεται μια νέα συμβολοσειρά.
Οι συμβολοσειρές (και οι άλλοι πρωτογενείς τύποι δεδομένων) είναι αμετάβλητες στη JavaScript.
Αυτό σημαίνει επίσης ότι δεν μπορείς να αντιστοιχίσεις έναν διαφορετικό χαρακτήρα σε κάποια θέση χρησιμοποιώντας τη σύνταξη με αγκύλες που φαίνεται παραπάνω (όπως θα έκανες στους πίνακες).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
