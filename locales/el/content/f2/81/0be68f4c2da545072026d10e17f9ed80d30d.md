# Οδηγίες

Σε αυτή την άσκηση θα οργανώσεις αγώνες ανάμεσα σε διάφορα είδη τηλεκατευθυνόμενων αυτοκινήτων.
Κάθε αυτοκίνητο έχει τη δική του ταχύτητα και τα δικά του χαρακτηριστικά κατανάλωσης μπαταρίας.

Τα αυτοκίνητα ξεκινούν με πλήρως φορτισμένες (100%) μπαταρίες.
Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο,
αυτό διανύει τόσα μέτρα όση είναι η ταχύτητά του και μειώνει το ποσοστό της υπόλοιπης μπαταρίας κατά την κατανάλωση μπαταρίας του.

Αν η μπαταρία ενός αυτοκινήτου είναι κάτω από το ποσοστό κατανάλωσης μπαταρίας του, δεν μπορείς να οδηγήσεις άλλο το αυτοκίνητο.

Κάθε πίστα αγώνων έχει τη δική της απόσταση.
Τα αυτοκίνητα δοκιμάζονται ελέγχοντας αν μπορούν να τερματίσουν την πίστα χωρίς να ξεμείνουν από μπαταρία.

## 1. Δημιούργησε ένα τηλεκατευθυνόμενο αυτοκίνητο

Όρισε ένα struct `Car` με τα ακόλουθα πεδία τύπου `int`:

- battery
- batteryDrain
- speed
- distance

Επίτρεψε τη δημιουργία ενός τηλεκατευθυνόμενου αυτοκινήτου ορίζοντας μια συνάρτηση `NewCar` που δέχεται την ταχύτητα του αυτοκινήτου σε μέτρα
και το ποσοστό κατανάλωσης μπαταρίας ως τις δύο παραμέτρους της (και οι δύο τύπου `int`) και επιστρέφει ένα στιγμιότυπο `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Δημιούργησε μια πίστα αγώνων

Όρισε έναν ακόμη τύπο struct με το όνομα `Track` και το πεδίο `distance` ακέραιου τύπου.
Επίτρεψε τη δημιουργία μιας πίστας αγώνων ορίζοντας μια συνάρτηση `NewTrack` που δέχεται την απόσταση της πίστας σε μέτρα ως τη μοναδική της παράμετρο (τύπου `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Οδήγησε το αυτοκίνητο

Υλοποίησε τη συνάρτηση `Drive` που ενημερώνει τον αριθμό των μέτρων που διανύθηκαν με βάση την ταχύτητα του αυτοκινήτου και μειώνει τη μπαταρία σύμφωνα με την κατανάλωση μπαταρίας.
Αν δεν υπάρχει αρκετή μπαταρία για άλλη μια οδήγηση, το αυτοκίνητο δεν θα κινηθεί:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Έλεγξε αν ένα τηλεκατευθυνόμενο αυτοκίνητο μπορεί να τερματίσει έναν αγώνα

Για να τερματίσει έναν αγώνα, ένα αυτοκίνητο πρέπει να μπορεί να διανύσει την απόσταση του αγώνα.
Αυτό σημαίνει να μην εξαντλήσει τη μπαταρία του πριν περάσει τη γραμμή τερματισμού.
Υλοποίησε τη συνάρτηση `CanFinish` που δέχεται ένα στιγμιότυπο `Car` και ένα στιγμιότυπο `Track` ως παράμετρο και επιστρέφει `true` αν το αυτοκίνητο μπορεί να τερματίσει τον αγώνα. Διαφορετικά, επιστρέφει `false`.

Υπόθεσε ότι βρίσκεσαι αυτή τη στιγμή στη γραμμή εκκίνησης του αγώνα και βάζεις μπροστά τη μηχανή του αυτοκινήτου για τον αγώνα.
Λάβε υπόψη ότι η μπαταρία του αυτοκινήτου μπορεί να μην είναι απαραίτητα πλήρως φορτισμένη όταν ξεκινάει ο αγώνας:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
