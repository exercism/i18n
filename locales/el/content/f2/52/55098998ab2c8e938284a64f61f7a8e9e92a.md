# Εισαγωγή

Ένα [`Set`][set-docs] είναι μια μη διατεταγμένη συλλογή που (σε αντίθεση με τη `List`) είναι εγγυημένο ότι δεν περιέχει διπλότυπες τιμές.

Η παράμετρος γενικού τύπου της διεπαφής `Set` δηλώνει τον τύπο των στοιχείων που περιέχει το `Set`:

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

Σημείωσε ότι η μέθοδος `Set.of()` δημιουργεί ένα [_μη τροποποιήσιμο_][unmodifiable-set-docs] στιγμιότυπο `Set`.
Αν προσπαθήσεις να καλέσεις μεθόδους όπως τις `add` και `remove` σε αυτό το στιγμιότυπο, θα προκύψει μια εξαίρεση κατά την εκτέλεση.

Για να δημιουργήσεις ένα τροποποιήσιμο `Set`, πρέπει να δημιουργήσεις στιγμιότυπο μιας κλάσης που υλοποιεί τη διεπαφή `Set`.
Η πιο χρησιμοποιημένη ενσωματωμένη κλάση που υλοποιεί αυτή τη διεπαφή είναι η κλάση [`HashSet`][hashset-docs].

```java
Set<Integer> ints = new HashSet<>();
```

Η διεπαφή `Set` επεκτείνει τις διεπαφές [`Collection`][collection-docs] και [`Iterable`][iterable-docs], και επομένως μοιράζεται πολλές μεθόδους με άλλους τύπους συλλογών.
Μια αξιοσημείωτη διαφορά από τη διεπαφή `Collection`, ωστόσο, είναι ότι μέθοδοι όπως οι `add` και `remove` επιστρέφουν `boolean` (αντί για `void`), το οποίο δηλώνει αν το στοιχείο περιέχονταν στο σύνολο όταν κλήθηκε αυτή η μέθοδος:

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
