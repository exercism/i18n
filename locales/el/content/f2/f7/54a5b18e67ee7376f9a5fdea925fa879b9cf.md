# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου.
Συνήθως χρησιμοποιείς σημάδια καταμέτρησης σε ένα τετράδιο για να μετράς τα πουλιά, αλλά για να δουλέψεις καλύτερα με τα δεδομένα σου, ψηφιοποίησες τις καταμετρήσεις των πουλιών των τελευταίων εβδομάδων.

## 1. Προσδιόρισε τον συνολικό αριθμό των πουλιών που έχεις μετρήσει μέχρι τώρα

Ας ξεκινήσουμε την ανάλυση των δεδομένων παίρνοντας μια γενική εικόνα.
Βρες πόσα πουλιά έχεις μετρήσει συνολικά από τότε που ξεκίνησες τις καταγραφές σου.

Υλοποίησε μια συνάρτηση `totalBirdCount` που δέχεται έναν πίνακα από `Int` που περιέχει τον αριθμό των πουλιών ανά ημέρα.
Θα πρέπει να επιστρέφει τον συνολικό αριθμό των πουλιών που μέτρησες.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου σε μια συγκεκριμένη εβδομάδα

Τώρα που πήρες μια γενική εικόνα των αριθμών καταμέτρησης των πουλιών σου, θέλεις να κάνεις μια πιο λεπτομερή ανάλυση.

Υλοποίησε μια συνάρτηση `birdsInWeek` που δέχεται έναν πίνακα με τις καταμετρήσεις των πουλιών ανά ημέρα και έναν αριθμό εβδομάδας.

Επιστρέφει τον συνολικό αριθμό των πουλιών που μέτρησες σε αυτή τη συγκεκριμένη εβδομάδα.
Μπορείς να υποθέσεις ότι οι εβδομάδες καταγράφονται πάντα ολόκληρες.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Διόρθωσε ένα λάθος στην καταμέτρηση

Συνειδητοποίησες ότι όλο αυτόν τον καιρό που προσπαθούσες να καταγράφεις τα πουλιά, υπήρχε ένα πουλί που κρυβόταν σε μια μακρινή γωνιά του κήπου.

Κατάλαβες ότι αυτό το πουλί περνούσε πάντα κάθε δεύτερη μέρα στον κήπο σου.

Δεν ξέρεις πού ακριβώς βρισκόταν τις ενδιάμεσες μέρες, αλλά σίγουρα όχι στον κήπο σου.

Το ένστικτό σου ως παρατηρητή πουλιών σου λέει επίσης ότι το πουλί ήταν στον κήπο σου την πρώτη μέρα που κατέγραψες στη λίστα σου.

Με αυτές τις νέες πληροφορίες, γράψε μια συνάρτηση `fixBirdCountLog` που παίρνει ως όρισμα έναν πίνακα με τα πουλιά που μετρήθηκαν ανά ημέρα και επιστρέφει τον πίνακα αφού διορθώσει το λάθος στην καταμέτρηση.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
