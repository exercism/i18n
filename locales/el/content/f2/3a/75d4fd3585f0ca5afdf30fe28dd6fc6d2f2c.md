# Οδηγίες

Ως μέλλουσα μάγισσα, η Elyse πρέπει να εξασκηθεί στα βασικά.
Έχει μια στοίβα από κάρτες που θέλει να χειριστεί.

Για να κάνει τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10, έτσι ώστε η στοίβα από κάρτες της να μπορεί να αναπαρασταθεί με έναν πίνακα αριθμών.
Η θέση μιας συγκεκριμένης κάρτας αντιστοιχεί στη θέση μέσα στον πίνακα.
Δηλαδή, η θέση 0 αναφέρεται στην πρώτη κάρτα, η θέση 1 στη δεύτερη κάρτα κ.ο.κ.

~~~~exercism/note
Όλες οι συναρτήσεις θα πρέπει να ενημερώνουν τον πίνακα με τις κάρτες και στη συνέχεια να επιστρέφουν τον τροποποιημένο πίνακα, ένας συνηθισμένος τρόπος εργασίας γνωστός ως μοτίβο Builder, που σου επιτρέπει να συνδέεις όμορφα τις συναρτήσεις μεταξύ τους.
~~~~

## 1. Πάρε μια κάρτα από τη στοίβα

Για να πάρεις μια κάρτα, επέστρεψε την κάρτα στη θέση `position` από τη δεδομένη στοίβα.

Υλοποίησε τη συνάρτηση `getCard(at:from:)` που παίρνει δύο ορίσματα: το `at` που είναι η θέση της κάρτας στη στοίβα, και το `from` που είναι η στοίβα με τις κάρτες.
Η συνάρτηση θα πρέπει να επιστρέφει την κάρτα στη θέση `index` από τη δεδομένη στοίβα.

```swift
let index = 2
getCard(at: index, from: [1, 2, 4, 1])
// returns 4
```

## 2. Άλλαξε μια κάρτα στη στοίβα

Κάνε λίγη ταχυδακτυλουργία και αντάλλαξε την κάρτα στη θέση `position` με την κάρτα αντικατάστασης που δίνεται.

Υλοποίησε τη συνάρτηση `setCard(at:in:to)` που παίρνει τρία ορίσματα: το `at` που είναι η θέση της κάρτας στη στοίβα, το `in` που είναι η στοίβα με τις κάρτες, και το `to` που είναι η νέα κάρτα για να αντικαταστήσει την κάρτα στη θέση `index`.
Η συνάρτηση θα πρέπει να επιστρέφει ένα αντίγραφο της στοίβας με την κάρτα στη θέση `index` αντικατεστημένη με τη νέα κάρτα.
Αν το δοσμένο `index` δεν είναι έγκυρη θέση στη στοίβα, η αρχική στοίβα θα πρέπει να επιστραφεί, αμετάβλητη.

```swift
let index = 2
let newCard = 6
setCard(at: index, in: [1, 2, 4, 1], to: newCard)
// returns [1, 2, 6, 1]
```

## 3. Εισήγαγε μια κάρτα στην κορυφή της στοίβας

Κάνε μια κάρτα να εμφανιστεί εισάγοντας μια νέα κάρτα στην κορυφή της στοίβας.

Υλοποίησε τη συνάρτηση `insert(_:atTopOf:)` που παίρνει δύο ορίσματα: τη νέα κάρτα που θα εισαχθεί, και τη στοίβα με τις κάρτες.
Η συνάρτηση θα πρέπει να επιστρέφει ένα αντίγραφο της στοίβας με τη νέα κάρτα που δίνεται προστιθέμενη στην κορυφή της στοίβας.

```swift
let newCard = 8
insert(newCard, atTopOf: [5, 9, 7, 1])
// returns [5, 9, 7, 1, 8]
```

## 4. Αφαίρεσε μια κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας την κάρτα στη δοσμένη θέση `position` από τη στοίβα.

Υλοποίησε τη συνάρτηση `removeCard(at:from:)` που παίρνει δύο ορίσματα: το `at` που είναι η θέση της κάρτας στη στοίβα, και το `from` που είναι η στοίβα με τις κάρτες.
Η συνάρτηση θα πρέπει να επιστρέφει ένα αντίγραφο της στοίβας με την κάρτα στη θέση `index` αφαιρεμένη.
Αν το δοσμένο `index` δεν είναι έγκυρη θέση στη στοίβα, η αρχική στοίβα θα πρέπει να επιστραφεί, αμετάβλητη.

```swift
let index = 2
removeCard(at: index, from: [3, 2, 6, 4, 8])
// returns [3, 2, 4, 8]
```

## 5. Εισήγαγε μια κάρτα στη στοίβα

Κάνε μια κάρτα να εμφανιστεί εισάγοντας μια νέα κάρτα στη δοσμένη θέση `position` μέσα στη στοίβα.

Υλοποίησε τη συνάρτηση `insert(_:at:from:)` που παίρνει τρία ορίσματα: τη νέα κάρτα που θα εισαχθεί, τη θέση στην οποία θα πρέπει να εισαχθεί η νέα κάρτα, και τη στοίβα με τις κάρτες.
Η συνάρτηση θα πρέπει να επιστρέφει ένα αντίγραφο της στοίβας με τη νέα κάρτα που δίνεται προστιθέμενη στη δοσμένη θέση.
Αν το δοσμένο `index` δεν είναι έγκυρη θέση στη στοίβα, η αρχική στοίβα θα πρέπει να επιστραφεί, αμετάβλητη.

```swift
let newCard = 8
insert(newCard, at: 2, from: [5, 9, 7, 1])
// returns [5, 9, 8, 7, 1]
```

## 6. Έλεγξε το μέγεθος της στοίβας

Έλεγξε αν το μέγεθος της στοίβας είναι ίσο με `stackSize` ή όχι.

Υλοποίησε τη συνάρτηση `checkSizeOfStack(_:_:)` που παίρνει δύο ορίσματα: το `stack` που είναι η στοίβα με τις κάρτες, και το `stackSize` που είναι το μέγεθος της στοίβας.
Η συνάρτηση θα πρέπει να επιστρέφει `true` αν το μέγεθος της στοίβας είναι ίσο με `stackSize` και `false` διαφορετικά.

```swift
let stackSize = 4
checkSizeOfStack([3, 2, 6, 4, 8], stackSize)
// returns false
```
