# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, χρειάζεται να δημιουργήσεις τον τύπο δεδομένων `BST`,
με instances `Eq` και `Show`, και να υλοποιήσεις τις συναρτήσεις:

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

Θα βρεις μια εικονική δήλωση δεδομένων και υπογραφές τύπων ήδη στη θέση τους,
αλλά εξαρτάται από εσένα να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν τύπο
δεδομένων, newtype ή συνώνυμο τύπου που να έχει νόημα.
