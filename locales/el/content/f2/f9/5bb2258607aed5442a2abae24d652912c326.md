# Προσθήκη στις οδηγίες

## Υλοποίηση

Όρισε μία μόνο συνάρτηση Go, τη MakeChain, η οποία δέχεται ένα slice από ντόμινα και προσπαθεί να κατασκευάσει μια νόμιμη αλυσίδα από ντόμινα.

Η MakeChain πρέπει να έχει την ακόλουθη υπογραφή:

```go
type Domino [2]int

func MakeChain(input []Domino) (chain []Domino, ok bool)
```

Το αποτέλεσμα `ok` τύπου bool δείχνει αν η δεδομένη λίστα από ντόμινα εισόδου μπορεί να τακτοποιηθεί σε μια νόμιμη αλυσίδα.
Μια κενή λίστα εισόδου θεωρείται νόμιμη, και ένα μόνο ντόμινο του οποίου οι πλευρές είναι ίδιες θεωρείται επίσης νόμιμο.

Το αποτέλεσμα "chain" είναι ένα slice από μηδέν ή περισσότερα ντόμινα, τακτοποιημένα σε μια σειρά που δείχνει τη νόμιμη αλυσίδα.
Είναι αποδεκτό (και αναμενόμενο) ότι τα ντόμινα στο "input" μπορεί να χρειαστεί να περιστραφούν, ώστε κάθε πλευρά να ταιριάζει με το γειτονικό της ντόμινο στην αλυσίδα.
Τα ντόμινα στην αρχή και στο τέλος της αλυσίδας πρέπει επίσης να ταιριάζουν μεταξύ τους στην εξωτερική τους πλευρά.

Αν το δεδομένο slice εισόδου από ντόμινα δεν μπορεί να τακτοποιηθεί σε μια νόμιμη αλυσίδα, η MakeChain μπορεί να επιστρέψει nil για το αποτέλεσμα "chain", αλλά πρέπει να επιστρέψει false για το αποτέλεσμα ok.

Επειδή μπορεί να υπάρχουν περισσότερες από μία νόμιμες διατάξεις αλυσίδας για μια δεδομένη λίστα εισόδου, όταν το `ok` είναι true, το πρόγραμμα δοκιμών θα ελέγξει την αλυσίδα μόνο για εγκυρότητα.
