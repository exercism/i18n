# Εισαγωγή

Τα περισσότερα δεδομένα στη Factor ζουν μέσα σε *ακολουθίες*. Οι πίνακες, τα διανύσματα και
οι συμβολοσειρές είναι όλα ακολουθίες και μοιράζονται ένα κοινό σύνολο λέξεων από το
λεξιλόγιο [`sequences`][sequences].

## Κυριολεκτικοί πίνακες

Ένας κυριολεκτικός πίνακας χρησιμοποιεί `{ }` με κενό διάστημα ανάμεσα στα στοιχεία:

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

Οι πίνακες έχουν σταθερό μήκος, οπότε λέξεις όπως τα `suffix` και `remove-nth`, που
αλλάζουν το πλήθος των στοιχείων, επιστρέφουν μια *νέα* ακολουθία αντί να μεγαλώσουν την
αρχική.

## Μήκος και πρόσβαση με θέσεις

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

Το `?nth` είναι η έκδοση που σέβεται τα όρια: μπορείς να δοκιμάσεις μια θέση χωρίς να
ελέγξεις πρώτα το μήκος.

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## Τεμαχισμός

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

Και τα δύο πετούν ένα σφάλμα αν το `n` είναι μεγαλύτερο από την ακολουθία. Αν το `n` είναι
πολύ μεγάλο, το `index-or-length` το μικραίνει ώσπου να φτάσει στο μήκος της ακολουθίας,
έτσι ώστε το τμήμα που ακολουθεί να μην ξεφύγει από το τέλος:

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

Οι παραλλαγές με αστερίσκο, τα `head*` και `tail*`, μετρούν από το τέλος: το `head*` πετάει
τα τελευταία `n`, ενώ το `tail*` κρατά τα τελευταία `n`:

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

Για ένα αυθαίρετο τμήμα ανάμεσα σε δύο θέσεις, το `subseq` παίρνει την *αρχή*
(περιλαμβάνεται) και το *τέλος* (δεν περιλαμβάνεται):

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

Όταν έχεις μια *αρχή και ένα μήκος*, πρόσθεσέ τα για να βρεις το τέλος:

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

(Αυτό είναι το διάστημα θέσεων `[2, 5)`, δηλαδή τρεις χαρακτήρες ξεκινώντας από τη θέση 2.)

Το αντίστροφο ερώτημα, δηλαδή *πού* εμφανίζεται μια υποακολουθία, το απαντά το
`subseq-index`, το οποίο επιστρέφει τη θέση όπου ξεκινά η πρώτη αντιστοιχία ή `f` όταν δεν
υπάρχει καμία:

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## Γέμισμα

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

Και τα δύο επεκτείνουν το `seq` ώσπου το μήκος του να είναι τουλάχιστον `n`. Αν το `seq`
έχει ήδη αυτό το μήκος, επιστρέφεται ως έχει.

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## Οι ίδιες λέξεις δουλεύουν και στις συμβολοσειρές

Μια συμβολοσειρά είναι μια ακολουθία χαρακτήρων, οπότε όλα τα παραπάνω δουλεύουν και στις
συμβολοσειρές. Το αποτέλεσμα είναι απλώς μια άλλη συμβολοσειρά αντί για πίνακα:

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## Συνάθροιση

Τα `sum` και `product` (στο [`sequences`][sequences])
προσθέτουν ή πολλαπλασιάζουν τα στοιχεία μιας αριθμητικής ακολουθίας:

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

Το `count` τρέχει ένα κατηγόρημα πάνω στην ακολουθία και επιστρέφει πόσα στοιχεία το έκαναν
αληθές:

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## Κατηγορήματα σε ολόκληρη την ακολουθία

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## Δημιουργία μιας νέας ακολουθίας

Το `suffix` προσθέτει ένα στοιχείο στο τέλος μιας ακολουθίας, ενώ το `prefix` προσθέτει ένα
στην αρχή. Το `unclip` ξεκολλάει το πρώτο στοιχείο και το `unclip-last` ξεκολλάει το
τελευταίο:

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

Ο συνδυασμός των `unclip-last` και `suffix` δίνει μια μη καταστροφική ενημέρωση του
τελευταίου στοιχείου (και τα `unclip` + `prefix` κάνουν το ίδιο για το πρώτο):

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## Μετατροπή ανάμεσα σε τύπους ακολουθιών

Τα `>array`, `>vector` και `>string` (στο [`arrays`][arrays] και στα αντίστοιχα λεξιλόγια)
αναγκάζουν μια ακολουθία να πάρει έναν ορισμένο, συγκεκριμένο τύπο. Χρήσιμο όταν μια πράξη
επέστρεψε ένα τμήμα ή μια γενική ακολουθία και χρειάζεσαι πίσω έναν πίνακα (ή συμβολοσειρά).

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
