# Παράρτημα οδηγιών

## Υποδείξεις

Πρέπει να υλοποιήσεις τη συνάρτηση `rotate`, η οποία παίρνει ένα `Int` και ένα `String` και έπειτα το κωδικοποιεί χρησιμοποιώντας ένα κρυπτογράφημα περιστροφής.
Μπορείς να χρησιμοποιήσεις την υπογραφή που σου δίνεται αν δεν είσαι σίγουρος για τους τύπους, αλλά μην αφήσεις αυτό να περιορίσει τη δημιουργικότητά σου.

Αυτή η άσκηση δουλεύει με δεδομένα κειμένου. Για ιστορικούς λόγους, ο τύπος
`String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων. Για πιο
αποδοτικό χειρισμό δεδομένων κειμένου, μπορεί να χρησιμοποιηθεί ο τύπος `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να

- διαβάσεις για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη
  Haskell.
- προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- κάνεις import το `Data.Text` [με τον ακόλουθο
  τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- χρησιμοποιήσεις τον τύπο `Text`, π.χ. `rotate :: Int -> Text -> Text`, και αναφερθείς
  στους συνδυαστές του `Data.Text` ως π.χ. `T.pack`.
- κοιτάξεις την τεκμηρίωση για το
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο RotationalCipher.hs, δηλαδή:

```haskell
rotate :: Int -> Text -> Text
```

Αυτό το μέρος είναι εντελώς προαιρετικό.
