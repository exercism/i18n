# Προσθήκη στις οδηγίες

## Οδηγίες ειδικά για την Odin

Για να λύσεις αυτή την άσκηση, θα χρειαστεί να παρακολουθείς τα ονόματα των ρομπότ που δημιούργησες. Η δομή δεδομένων `Robot_Storage` παρέχεται για αυτόν τον σκοπό.

Επειδή τα ονόματα των ρομπότ είναι `string` στην Odin και θα πρέπει να δεσμευτούν χειροκίνητα καθώς δημιουργείς τα ρομπότ, είναι δική σου ευθύνη να απελευθερώσεις τη σχετική μνήμη στη διαδικασία `delete_storage()`.
