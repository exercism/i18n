# Υποδείξεις

## Γενικά

- Χρησιμοποίησε τον ενσωματωμένο [τύπο πίνακα][array].

## 1. Όρισε μια μέθοδο που επιστρέφει έναν κενό πίνακα γλωσσών

- Η συνάρτηση πρέπει να επιστρέφει έναν κενό πίνακα με τύπο `Array(String)`.
- Η σύνταξη για να δημιουργήσεις έναν κενό πίνακα είναι `[]`.
  Ο τύπος μπορεί να δηλωθεί με `of String`.

## 2. Όρισε μια μέθοδο που προσθέτει μια γλώσσα στον πίνακα

- Μπορείς να προσθέσεις ένα στοιχείο στο τέλος ενός πίνακα με `<<`.

## 3. Όρισε μια μέθοδο που αφαιρεί μια γλώσσα από τον πίνακα

- Η Crystal [παρέχει μια μέθοδο][pop] για να αφαιρέσεις το τελευταίο στοιχείο από έναν πίνακα.

## 4. Όρισε μια μέθοδο που επιστρέφει το νιοστό στοιχείο του πίνακα

- Η Crystal [παρέχει μια μέθοδο][index] για να πάρεις το στοιχείο σε μια συγκεκριμένη θέση ενός πίνακα.

## 5. Όρισε μια μέθοδο που αναλύει μια συμβολοσειρά γλωσσών

- Η Crystal [παρέχει μια μέθοδο][split] για να μετατρέψεις μια συμβολοσειρά σε πίνακα χρησιμοποιώντας έναν διαχωριστικό.
