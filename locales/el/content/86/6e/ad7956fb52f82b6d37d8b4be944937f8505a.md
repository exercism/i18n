# Σχετικά

Στη Common Lisp ο χρόνος αναπαρίσταται με τρεις τρόπους

- Ο παγκόσμιος χρόνος είναι ένας απόλυτος χρόνος, ένας ακέραιος που παριστάνει τον αριθμό των δευτερολέπτων από το `1900-01-01T00:00:00Z` (δηλαδή τα μεσάνυχτα της 1ης Ιανουαρίου 1900 σε UTC).
- Ο αποκωδικοποιημένος χρόνος είναι μια πλειάδα 9 τιμών που μαζί παριστάνουν μια συγκεκριμένη ημερολογιακή στιγμή: δευτερόλεπτα, λεπτά, ώρα, ημέρα του μήνα, μήνας, έτος, ημέρα της εβδομάδας, ένδειξη θερινής ώρας, ζώνη ώρας.
(Τον συζητάμε αναλυτικά παρακάτω.)
- Ο εσωτερικός χρόνος είναι ένας θετικός ακέραιος σε "μονάδες εσωτερικού χρόνου" ορισμένες από την υλοποίηση, ο οποίος μπορεί να χρησιμοποιηθεί για μετρήσεις του χρόνου εκτέλεσης.

## Παγκόσμιος Χρόνος

Για να πάρεις τον τρέχοντα παγκόσμιο χρόνο χρησιμοποιείς τις `get-universal-time` ή `get-decoded-time`.
Η πρώτη επιστρέφει τα τρέχοντα δευτερόλεπτα από το `1900-01-01T00:00Z` και η δεύτερη επιστρέφει τα ίδια δεδομένα σε αποκωδικοποιημένη μορφή.

Σημείωσε ότι, εφόσον αυτός ο αριθμός είναι θετικός ακέραιος, είναι αδύνατο να κωδικοποιήσεις ημερομηνίες πριν από το 1900.

## Αποκωδικοποιημένος Χρόνος

Οι `decode-universal-time` και `encode-universal-time` είναι οι βασικές συναρτήσεις για την εργασία με χρόνο.
Η πρώτη παίρνει έναν παγκόσμιο χρόνο και επιστρέφει μια αποκωδικοποιημένη τιμή χρόνου ως [πολλαπλές τιμές][concept-multiple-values], ενώ η δεύτερη παίρνει τις τιμές του αποκωδικοποιημένου χρόνου ως ορίσματα και επιστρέφει έναν παγκόσμιο χρόνο.

Και οι δύο παίρνουν ένα προαιρετικό όρισμα ζώνης ώρας.
Δες παρακάτω τη μορφή της ζώνης ώρας.

Ο αποκωδικοποιημένος χρόνος είναι ένα σύνολο τιμών:

- *δευτερόλεπτα*: ένας ακέραιος μεταξύ 0 και 59
- *λεπτά*: ένας ακέραιος μεταξύ 0 και 59
- *ώρα*: ένας ακέραιος μεταξύ 0 και 23
- *ημέρα του μήνα*: ένας ακέραιος μεταξύ 1 και 31 (το ανώτατο όριο εξαρτάται βέβαια από τον μήνα και το έτος)
- *μήνας*: ένας ακέραιος μεταξύ 1 και 12
- *έτος*: ένας ακέραιος που δηλώνει το έτος.
- *ημέρα της εβδομάδας*: ένας ακέραιος μεταξύ 0 και 6. Το 0 σημαίνει Δευτέρα, το 1 σημαίνει Τρίτη κ.ο.κ. ... το 6 σημαίνει Κυριακή.
- *ένδειξη θερινής ώρας*: μια αληθής τιμή δείχνει ότι η θερινή ώρα είναι σε ισχύ.
- *ζώνη ώρας*: ένας αριθμός ωρών μεταξύ -24 και 24 που δηλώνει τη διαφορά από την UTC.
Ο αριθμός είναι ρητός και πρέπει να είναι πολλαπλάσιο του `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

Σημείωσε ότι υπάρχει μια ενδιαφέρουσα συμπεριφορά όταν δεν δίνεται η παράμετρος ζώνης ώρας.
Δες την τεκμηρίωση για τις [`decode-universal-time`][hyperspec-decode-universal-time] και [`encode-universal-time`][hyperspec-encode-universal-time] για λεπτομέρειες.

## Εσωτερικός Χρόνος

Ο εσωτερικός χρόνος είναι ένας θετικός ακέραιος αριθμός "μονάδων εσωτερικού χρόνου". Η διαφορά ανάμεσα σε δύο από αυτούς μπορεί να χρησιμοποιηθεί για να μετρήσεις χρόνο κατά τη διάρκεια της εκτέλεσης.

- Η `get-internal-real-time` επιστρέφει τον τρέχοντα "πραγματικό" χρόνο ή χρόνο "ρολογιού".
- Η `get-internal-run-time` εξαρτάται σε μεγάλο βαθμό από την υλοποίηση και μπορεί ή όχι να περιλαμβάνει χρόνο που δαπανάται, για παράδειγμα, σε σελιδοποίηση ή σε συλλογή απορριμμάτων.

Η μεταβλητή `internal-time-units-per-second` περιέχει μια τιμή που είναι ο αριθμός των "μονάδων εσωτερικού χρόνου" ανά δευτερόλεπτο για το τρέχον περιβάλλον Lisp που εκτελείται.
