# Υποδείξεις

## Γενικά

- Μπορεί να σου φανεί χρήσιμο να έχεις μια λίστα με όλες τις αριθμητικές πράξεις στη Lisp. Μπορείς να βρεις [μια πλήρη λίστα εδώ](http://www.lispworks.com/documentation/HyperSpec/Body/12_aa.htm)

## 1. Αναλογία ζύμης

- Η Common Lisp έχει [μια ενσωματωμένη σταθερά](http://www.lispworks.com/documentation/HyperSpec/Body/v_pi.htm) για το π
- Όσον αφορά τη στρογγυλοποίηση, η προδιαγραφή της CL παρέχει [μια σειρά από συναρτήσεις](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm)

## 2. Μια σταλιά σάλτσα

- Υπάρχει [ένας ενσωματωμένος τελεστής](http://www.lispworks.com/documentation/HyperSpec/Body/f_sqrt_.htm) που μπορεί να σε βοηθήσει να βρεις την τετραγωνική ρίζα ενός αριθμού

## 3. Λίγο τυρί, παρακαλώ

- Για να υψώσεις έναν αριθμό στο τετράγωνο ή στον κύβο, υπάρχει [μια ενσωματωμένη συνάρτηση ύψωσης σε δύναμη](http://www.lispworks.com/documentation/HyperSpec/Body/f_exp_e.htm)
- Ίσως θελήσεις να ρίξεις μια ματιά σε [αυτή τη σελίδα με πράξεις στρογγυλοποίησης](http://www.lispworks.com/documentation/HyperSpec/Body/f_floorc.htm) και να δεις μερικές από τις εναλλακτικές του `round`.

## 4. Δίκαιη μερίδα

- Αυτό το μέρος απαιτεί να χρησιμοποιήσεις μια συνάρτηση που ίσως δεν έχεις ξανασυναντήσει, τη [συνάρτηση υπολοίπου](https://en.wikipedia.org/wiki/Modulo_operation) (`mod`). Αυτή η συνάρτηση σου δίνει το υπόλοιπο της διαίρεσης δύο αριθμών.
- Για να συγκρίνεις το αποτέλεσμα του `mod` με έναν άλλο αριθμό, δες [αυτή τη σελίδα με τελεστές σύγκρισης](http://www.lispworks.com/documentation/HyperSpec/Body/f_eq_sle.htm).
