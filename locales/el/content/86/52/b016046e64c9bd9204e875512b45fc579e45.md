# Οδηγίες

Το κομμωτήριο στη Νέα Υόρκη που βοήθησες στην άσκηση Booking Up For Beauty τα πάει καλά, και πολλοί από τους πελάτες του έχουν γίνει τακτικοί.
Αντί να κλείνει κάθε επίσκεψη ξεχωριστά, ένας τακτικός πελάτης έχει μια πάγια συμφωνία: "κάθε δεύτερη Τρίτη", "την τελευταία Παρασκευή του μήνα" και τα λοιπά.
Ο ιδιοκτήτης του κομμωτηρίου σού ζήτησε ένα βοηθητικό εργαλείο που υπολογίζει τις ημερομηνίες πίσω από αυτές τις συμφωνίες, καθώς και τις ημερομηνίες της μηνιαίας ρουτίνας του κομμωτηρίου.

## 1. Βρες το πάγιο ραντεβού ενός τακτικού πελάτη

Υλοποίησε τη μέθοδο `SalonCalendar.standingAppointment()` που δέχεται ένα έτος, έναν μήνα, μια εμφάνιση (`1` για την πρώτη, `2` για τη δεύτερη κ.ο.κ.) και μια ημέρα της εβδομάδας.
Επιστρέφει την ημερομηνία εκείνης της εμφάνισης της ημέρας της εβδομάδας μέσα στον μήνα:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Βρες το ραντεβού τέλους του μήνα ενός τακτικού πελάτη

Μερικοί τακτικοί πελάτες προτιμούν την τελευταία εμφάνιση της ημέρας τους μέσα στον μήνα.
Υλοποίησε τη μέθοδο `SalonCalendar.lastAppointment()` που δέχεται ένα έτος, έναν μήνα και μια ημέρα της εβδομάδας, και επιστρέφει την ημερομηνία της τελευταίας εμφάνισης εκείνης της ημέρας της εβδομάδας μέσα στον μήνα:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Βρες την επόμενη διαθέσιμη ημέρα για έναν πελάτη χωρίς ραντεβού

Ένας πελάτης στη ρεσεψιόν ζητά "το επόμενο Σάββατο".
Αν η μέρα κατά την οποία ρωτά είναι ήδη Σάββατο, εννοεί αυτό το ίδιο το Σάββατο.
Υλοποίησε τη μέθοδο `SalonCalendar.nextAvailable()` που δέχεται μια ημερομηνία και μια ημέρα της εβδομάδας, και επιστρέφει την πρώτη ημερομηνία από τη δεδομένη ημερομηνία και μετά που πέφτει σε εκείνη την ημέρα της εβδομάδας:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Βρες την ημέρα κλεισίματος των βιβλίων

Το κομμωτήριο κλείνει τα βιβλία του την τελευταία μέρα κάθε μήνα.
Ωστόσο, το κομμωτήριο είναι κλειστό τα Σαββατοκύριακα, οπότε όταν η τελευταία μέρα του μήνα πέφτει Σάββατο ή Κυριακή, τα βιβλία κλείνουν την Παρασκευή που προηγείται.
Υλοποίησε τη μέθοδο `SalonCalendar.bookkeepingDay()` που δέχεται ένα έτος και έναν μήνα, και επιστρέφει την ημέρα κλεισίματος των βιβλίων εκείνου του μήνα:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Χρησιμοποίησε ξανά τον κανόνα του Σαββατοκύριακου για τη μέρα πληρωμής

Το προσωπικό πληρώνεται στις 15 κάθε μήνα, με τον ίδιο κανόνα του Σαββατοκύριακου: όταν η 15η πέφτει Σάββατο ή Κυριακή, η μέρα πληρωμής είναι η Παρασκευή που προηγείται.
Αντί να γράψεις τον κανόνα για δεύτερη φορά, μετέτρεψέ τον σε έναν προσαρμοστή που μπορείς να επαναχρησιμοποιήσεις.

Υλοποίησε τη μέθοδο `SalonCalendar.precedingWorkday()` που επιστρέφει έναν `TemporalAdjuster`, ο οποίος αφήνει μια εργάσιμη μέρα αμετάβλητη και μετακινεί ένα Σάββατο ή μια Κυριακή στην Παρασκευή που προηγείται.
Στη συνέχεια υλοποίησε τη μέθοδο `SalonCalendar.payday()`, που δέχεται ένα έτος και έναν μήνα, χρησιμοποιώντας αυτόν τον προσαρμοστή:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

Μη διστάσεις να γυρίσεις πίσω και να χρησιμοποιήσεις τον προσαρμοστή και στη `bookkeepingDay()`.
