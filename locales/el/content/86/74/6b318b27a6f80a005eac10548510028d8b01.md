# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις σε έναν προγραμματισμό ραντεβού για ένα σαλόνι ομορφιάς στη Νέα Υόρκη που άνοιξε στις 15 Σεπτεμβρίου του 2012.

Έχεις τέσσερις εργασίες, οι οποίες όλες θα αφορούν ημερομηνίες ραντεβού. Οι ημερομηνίες και οι ώρες θα χρησιμοποιούν μία από τις παρακάτω τρεις μορφές:

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

Τα τεστ θα ορίζουν αυτόματα την κουλτούρα σε `en-US` - δεν χρειάζεται να ορίσεις ή να προσδιορίσεις εσύ την κουλτούρα.

## 1. Ανάλυση της ημερομηνίας του ραντεβού

Υλοποίησε τη (_static_) μέθοδο `Appointment.Schedule()` ώστε να αναλύει μια κειμενική αναπαράσταση μιας ημερομηνίας ραντεβού και να τη μετατρέπει στην αντίστοιχη μορφή `DateTime`:

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. Έλεγξε αν ένα ραντεβού έχει ήδη περάσει

Υλοποίησε τη (_static_) μέθοδο `Appointment.HasPassed()` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού ήταν κάπου στο παρελθόν:

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. Έλεγξε αν το ραντεβού είναι το απόγευμα

Υλοποίησε τη (_static_) μέθοδο `Appointment.IsAfternoonAppointment()` που παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού είναι το απόγευμα (>= 12:00 και < 18:00):

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. Περιέγραψε την ώρα και την ημερομηνία του ραντεβού

Υλοποίησε τη (_static_) μέθοδο `Appointment.Description()` που παίρνει μια ημερομηνία ραντεβού και επιστρέφει μια περιγραφή αυτής της ημερομηνίας και ώρας:

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. Επίστρεψε την ημερομηνία της επετείου

Υλοποίησε τη (_static_) μέθοδο `Appointment.AnniversaryDate()` που επιστρέφει τη φετινή ημερομηνία της επετείου, η οποία είναι η 15η Σεπτεμβρίου:

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
