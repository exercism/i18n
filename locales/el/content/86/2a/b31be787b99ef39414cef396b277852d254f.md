# Εκμάθηση

Το Coq είναι ένα σύστημα διαχείρισης τυπικών αποδείξεων. Παρέχει μια τυπική γλώσσα για να γράφεις μαθηματικούς ορισμούς, εκτελέσιμους αλγορίθμους και θεωρήματα, μαζί με ένα περιβάλλον για την ημιδιαδραστική ανάπτυξη αποδείξεων που ελέγχονται από υπολογιστή.

Υπάρχουν κάποιοι δωρεάν πόροι για να μάθεις το Coq, όπως:

* Σειρά Software Foundations:
    + [Volume 1: Logical Foundations](https://softwarefoundations.cis.upenn.edu/lf-current/index.html)
    + [Volume 2: Programming Language Foundations](https://softwarefoundations.cis.upenn.edu/plf-current/index.html)
    + [Volume 3: Verified Functional Algorithms](https://softwarefoundations.cis.upenn.edu/vfa-current/index.html)
* Certified Programming with Dependent Types:
    + Το οποίο είναι διαθέσιμο δωρεάν στην [ιστοσελίδα του Adam Chipala](http://adam.chlipala.net/cpdt/).
