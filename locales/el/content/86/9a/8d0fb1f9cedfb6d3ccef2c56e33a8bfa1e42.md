# Εισαγωγή

Τα πρωτόκολλα είναι ένας μηχανισμός για να πετύχεις πολυμορφισμό στην Elixir, όταν θέλεις η συμπεριφορά να διαφέρει ανάλογα με τον τύπο δεδομένων.

Τα πρωτόκολλα ορίζονται με το `defprotocol` και περιέχουν μία ή περισσότερες κεφαλίδες συναρτήσεων.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Τα πρωτόκολλα μπορούν να υλοποιηθούν με το `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Ένα πρωτόκολλο μπορεί να υλοποιηθεί για οποιονδήποτε υπάρχοντα τύπο δεδομένων της Elixir ή για ένα struct.

Όταν καλείται μια συνάρτηση πρωτοκόλλου, η κατάλληλη υλοποίηση επιλέγεται αυτόματα με βάση τον τύπο του πρώτου ορίσματος.
