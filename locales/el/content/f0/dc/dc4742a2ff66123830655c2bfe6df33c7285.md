# Εισαγωγή

Στη Factor, ορίζεις μια νέα λέξη με `: name ( stack-effect ) body ;`. Το σώμα είναι μια ακολουθία λέξεων· η κλήση της νέας σου λέξης τις εκτελεί με τη σειρά.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Όταν μια ρουτίνα μεγαλώνει, μπορείς, και πρέπει, να την *παραγοντοποιήσεις*: να τραβήξεις ομάδες λέξεων σε μικρότερες επώνυμες λέξεις, καθεμία με μία δουλειά. Η γλώσσα πήρε το όνομά της από αυτό.

## Λεξιλόγια

Κάθε αρχείο `.factor` δηλώνει ένα λεξιλόγιο με `IN:`. Οι λέξεις σε ένα λεξιλόγιο μπορούν να καλέσουν λέξεις από ένα άλλο, καταγράφοντας το άλλο λεξιλόγιο στο `USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

Η διάταξη των καταλόγων ακολουθεί το όνομα του λεξιλογίου με τελείες: το λεξιλόγιο `my-vocab` βρίσκεται στο `my-vocab/my-vocab.factor`· το λεξιλόγιο `my-vocab.helpers` βρίσκεται στο `my-vocab/helpers/helpers.factor`. Ο φορτωτής της Factor ακολουθεί τις δηλώσεις `USING:` μεταβατικά, φορτώνοντας κάθε λεξιλόγιο κατά απαίτηση.
