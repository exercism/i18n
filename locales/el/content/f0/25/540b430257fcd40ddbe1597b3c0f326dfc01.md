# Σχετικά

Μια [`List`][lists] στην Elm είναι μια αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές του ίδιου τύπου.
Καθώς οι λίστες είναι αμετάβλητες, μόλις δημιουργηθεί μια λίστα, η τιμή της δεν μπορεί να αλλάξει ποτέ.
Οι λίστες στην Elm έχουν μια _κεφαλή_ (το πρώτο στοιχείο) και μια _ουρά_ (όλα όσα ακολουθούν το πρώτο στοιχείο).
Η ουρά μιας λίστας είναι η ίδια μια λίστα.

Οι σημειώσεις τύπων για λίστες μπορούν να οριστούν ως εξής

```elm
List String --> a list of String
List Int --> a list of Int
```

Οι λίστες μπορούν να οριστούν ως εξής:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

Ο πιο συνηθισμένος τρόπος για να προσθέσεις ένα στοιχείο σε μια λίστα είναι μέσω του τελεστή `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Μια λίστα μπορεί να επισυναφθεί χρησιμοποιώντας τον τελεστή `++` ή τη συνάρτηση `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Οι λίστες χειρίζονται με συναρτήσεις και τελεστές που ορίζονται στο [`List` άρθρωμα][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Οποιαδήποτε συνάρτηση ή τελεστής φαίνεται να τροποποιεί μια λίστα (όπως όταν προσθέτει ένα στοιχείο), στην πραγματικότητα επιστρέφει μια νέα λίστα.
Η απόδοση, ωστόσο, συνήθως δεν είναι πρόβλημα, καθώς η υλοποίηση των λιστών αποτρέπει περιττές δεσμεύσεις μνήμης/αντιγραφές.

Οι λίστες μπορούν επίσης να επεξεργαστούν με [αντιστοίχιση προτύπων][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
