# Σχετικά

Αν οι τύποι των παραμέτρων μπορούν να συναχθούν, η Swift επιτρέπει επίσης να παραλείπονται τα ονόματα των παραμέτρων και η λέξη-κλειδί `in` από τον ορισμό του closure. Αντ' αυτού, οι παράμετροι μπορούν να αναφέρονται με μια ειδική συντομευμένη σύνταξη, όπου το `$0` αντιστοιχεί στην πρώτη παράμετρο, το `$1` στη δεύτερη, κ.ο.κ.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Αυτό το στυλ χρησιμοποιείται πιο συχνά όταν περνάμε closures σε συναρτήσεις ανώτερης τάξης και εκτιμάται η συντομία.
