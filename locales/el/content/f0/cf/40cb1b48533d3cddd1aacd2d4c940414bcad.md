# Γενικά

Η [τεκμηρίωση της εντολής switch][switch-statement] παρέχει μια εισαγωγή στις εντολές `switch`.

## 1. Εμφάνισε περιγραφές των παικτών με βάση τον αριθμό της φανέλας τους

- Η εντολή [`break`][break] είναι χρήσιμη.

## 2. Χειρίσου άγνωστους αριθμούς φανέλας

- Η εντολή [`default`][default] είναι χρήσιμη.

## 3. Επέκτεινε την κάλυψη ώστε να περιλαμβάνει δραστηριότητα εκτός γηπέδου

- Η [αντιστοίχιση προτύπων με τύπους][switch-pattern-matching] είναι το κλειδί για αυτή την εργασία.
- Χρησιμοποίησε την εντολή [`default`][default] για να αντιστοιχίσεις οποιονδήποτε άλλο τύπο.

## 5. Κάνε αναφορά για τους προπονητές των συλλόγων

- Δες αυτή την [τεκμηρίωση][switch-when] για τη λέξη-κλειδί `when`.
