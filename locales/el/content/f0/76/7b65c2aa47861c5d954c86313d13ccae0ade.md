# Μην κανονικοποιείς τις εισόδους

Είναι λογικό να είσαι επιφυλακτικός με τις εισόδους, ώστε ένα πρόγραμμα να τρέχει σωστά κάτω από περισσότερες συνθήκες. Ωστόσο, η αυθαίρετη κανονικοποίηση εισόδων δεν συνιστάται στο Exercism. Σε επόμενες ασκήσεις θα υπάρχουν καθορισμένες είσοδοι που είναι μη κανονικοποιημένες, όπου θα περιμένουμε καθαρισμό και κανονικοποίηση της εισόδου. Κράτα το απλό για την ώρα.
