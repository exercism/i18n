# Οδηγίες

Καθώς ετοιμάζεσαι να ψήσεις μπισκότα για τους φίλους σου, ανακάλυψες ότι πρέπει να μετατρέψεις μερικές από τις μετρήσεις που χρησιμοποιεί η συνταγή.
Επειδή γνωρίζεις μόνο το μετρικό σύστημα, πρέπει να βρεις έναν τρόπο να μετατρέπεις τις συνηθισμένες αμερικανικές μονάδες μέτρησης του ψησίματος σε χιλιοστόλιτρα (mL), ώστε να σου είναι πιο εύκολο.

Χρησιμοποίησε αυτόν τον πίνακα μετατροπών για τη λύση σου:

| Μονάδα προς μετατροπή | όγκος | σε χιλιοστόλιτρα (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| αμερικανικό φλιτζάνι          | 1      | 240                 |
| αμερικανική ουγγιά υγρού  | 1      | 30                  |
| αμερικανικό κουταλάκι του γλυκού     | 1      | 5                   |
| αμερικανική κουταλιά της σούπας   | 1      | 15                  |

Επειδή έχεις ταλέντο στον προγραμματισμό και ακόμη μαθαίνεις, αποφασίζεις να χρησιμοποιήσεις τα χιλιοστόλιτρα ως ενδιάμεση μονάδα, που θα διευκολύνει τη μετατροπή από οποιαδήποτε μονάδα της λίστας σε οποιαδήποτε άλλη (ακόμη και στην ίδια).

## 1. Πάρε το αριθμητικό μέρος από ένα ζεύγος όγκου

Υλοποίησε τη συνάρτηση `getVolume`. Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να επιστρέφει μόνο το αριθμητικό μέρος.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Μετέτρεψε το ζεύγος όγκου σε χιλιοστόλιτρα

Υλοποίησε τη συνάρτηση `toMilliliter`. Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να μετατρέπει τον όγκο σε χιλιοστόλιτρα χρησιμοποιώντας τον πίνακα μετατροπών.

Χρησιμοποίησε πολλαπλές ρήτρες συνάρτησης και αντιστοίχιση προτύπων για να δημιουργήσεις τις συναρτήσεις για κάθε μονάδα. Τα άτομα που χρησιμοποιούνται για να δηλώσουν κάθε μονάδα είναι: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Επίστρεψε το αποτέλεσμα της μετατροπής τυλιγμένο σε μια πλειάδα.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Μετέτρεψε το ζεύγος όγκου από χιλιοστόλιτρα σε άλλη μονάδα

Υλοποίησε τη συνάρτηση `fromMilliliter`. Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον όγκο στην επιθυμητή μονάδα χρησιμοποιώντας τον πίνακα μετατροπών.

Χρησιμοποίησε πολλαπλές ρήτρες συνάρτησης και αντιστοίχιση προτύπων για να δημιουργήσεις τις συναρτήσεις για κάθε μονάδα. Τα άτομα που χρησιμοποιούνται για να δηλώσουν κάθε μονάδα είναι: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Μετέτρεψε από οποιαδήποτε μονάδα σε οποιαδήποτε μονάδα

Υλοποίησε τη συνάρτηση `convert`. Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον δεδομένο όγκο στην επιθυμητή μονάδα.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
