# Σχετικά

## Optionals

Η Swift χρησιμοποιεί τα [_optionals_][optionals] για να επιτρέπει στους προγραμματιστές να αναπαριστούν την πιθανή απουσία μιας τιμής.
Ένα optional είναι ένας τύπος που μπορεί είτε να περιέχει μια τιμή είτε να είναι [`nil`][nil], το οποίο αντιπροσωπεύει την απουσία μιας τιμής.
Η χρήση ενός optional απαιτεί από το πρόγραμμα να ελέγξει αν υπάρχει πραγματικά μια τιμή πριν τη χρησιμοποιήσει, αφού πρώτα το ξετυλίξει.

Οποιοσδήποτε τύπος μπορεί να γίνει optional αν προσθέσεις ένα `?` στο τέλος του ονόματος του τύπου.
Έτσι, ένας optional ακέραιος θα έχει τύπο `Int?` και μια optional συμβολοσειρά θα έχει τύπο `String?`.
Ο ορισμός σταθερών ή μεταβλητών optional τύπου και η ανάθεση τιμών σε αυτές γίνεται με τον ίδιο τρόπο όπως για τιμές μη optional τύπων.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Μπορείς να αναθέσεις την απουσία τιμής σε μια μεταβλητή optional τύπου, αναθέτοντάς της την ειδική τιμή `nil`.
Το `nil` μπορεί να χρησιμοποιηθεί με όλους τους optional τύπους, αλλά τα `nil` που ανατίθενται σε δύο διαφορετικούς optional τύπους δεν έχουν τον ίδιο τύπο και δεν μπορούν να ανταλλαχθούν ούτε καν να συγκριθούν.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Σημείωσε επίσης ότι, παρόλο που το `nil` μπορεί να ανατεθεί σε οποιονδήποτε optional τύπο, δεν μπορεί να ανατεθεί σε έναν μη optional τύπο (ακόμα κι αν αυτός δεν περιέχει στην πραγματικότητα `nil`).
Και σε μεθόδους που περιμένουν έναν μη optional τύπο δεν μπορεί να περαστεί ένας optional τύπος χωρίς να ξετυλιχθεί πρώτα.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Χρήση των optionals

Επειδή οι optional τύποι δεν είναι οι ίδιοι τύποι με τους βασικούς τους τύπους, οι δύο τύποι δεν μπορούν να χρησιμοποιηθούν με τους ίδιους τρόπους.
Για παράδειγμα, το `Int("123") + 1` προκαλεί ένα σφάλμα μεταγλώττισης: "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'".
Αυτό συμβαίνει επειδή το `Int("123")` επιστρέφει έναν optional τύπο `Int?`, όχι έναν τύπο `Int`, αφού αν η συμβολοσειρά δεν μπορεί να μετατραπεί σε ακέραιο, το αποτέλεσμα θα είναι `nil`.
Για να αποκτήσεις πρόσβαση στο `Int` από τη μετατροπή, πρέπει πρώτα να το "ξετυλίξεις".

Αυτό γίνεται συνήθως στη Swift με τις δομές `if-let` και `guard-let` για [_δέσμευση optional_][optional-binding], οι οποίες ελέγχουν για `nil` και ακολουθούν ένα μονοπάτι κώδικα με την ξετυλιγμένη τιμή δεσμευμένη σε ένα όνομα που ορίζεις εσύ, αν υπάρχει τιμή, και ένα διαφορετικό μονοπάτι κώδικα αν βρεθεί `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Αξίζει να σημειωθεί ότι η μεταβλητή `safeNum` έχει τύπο `Int` και όχι `Int?`.
Στο παρακάτω παράδειγμα, το `num` είναι τύπου `Int?` και το `safeNum` είναι τύπου `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Αυτή η _δέσμευση optional_ είναι σημαντική, γιατί ξετυλίγει (ή "αφαιρεί") τον optional τύπο από την τιμή, επιτρέποντας να χρησιμοποιηθεί ως μη optional τιμή.
Αν κάνεις απλώς έναν έλεγχο συνθήκης για το αν η τιμή είναι `nil`, η τιμή θα παραμείνει optional τύπου:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

Η επιλογή `guard-let` μπορεί επίσης να χρησιμοποιηθεί σε περιπτώσεις όπου θέλεις να κάνεις πρόωρη επιστροφή:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Σύγκριση optionals

Σημείωσε ότι, ακόμα κι αν ο βασικός τύπος ενός ζεύγους optionals μπορεί να συγκριθεί με τους τυπικούς τελεστές σύγκρισης, τα ίδια τα optionals δεν μπορούν να συγκριθούν.
Μπορούν μόνο να ελεγχθούν ως προς την ισότητα.
Δύο optionals είναι ίσα αν είναι και τα δύο `nil` ή αν οι τιμές που τυλίγουν είναι ίσες στους βασικούς τους τύπους.

Ωστόσο, μπορείς να γράψεις κώδικα για να κάνεις μια προσαρμοσμένη σύγκριση δύο optional τιμών.
Παρακάτω υπάρχει ένα παράδειγμα μιας εντολής `switch` που θα επιστρέψει `true` μόνο αν και οι δύο optional τιμές δεν είναι nil και η πρώτη τιμή είναι μικρότερη από τη δεύτερη.
Για να το κάνει αυτό, χρησιμοποιεί το _μοτίβο optional_ `varName?`, το οποίο ταιριάζει μόνο με optionals που δεν είναι nil, δεσμεύοντας την τιμή μέσα στο optional στο όνομα `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## Σύμπτυξη με nil

Υπάρχει άλλος ένας τρόπος για ξετύλιγμα, όπου μπορείς να χρησιμοποιήσεις μια [εφεδρική τιμή][fallback] αν υπάρχει `nil`.
Αυτό μπορεί να γίνει με τον _τελεστή σύμπτυξης nil_, `??`. Υποθέτοντας ότι το `x` είναι `Int?`, αν γράψεις `let y = x ?? 0`, τότε η Swift θα ελέγξει αν το x είναι `nil`.
Αν δεν είναι, τότε θα ξετυλίξει το `x` και θα αναθέσει την ξετυλιγμένη τιμή στο `y`, ενώ αν το `x` _είναι_ `nil`, τότε θα αναθέσει 0 στο `y`.

Επειδή το `x ?? y` είναι απλώς συντομογραφία του `x != nil ? x! : y`, αν το `x` δεν είναι nil, τότε η έκφραση `y` δεν αξιολογείται καθόλου.

Τέλος, αξίζει να σημειωθεί ότι ο τελεστής σύμπτυξης nil είναι δεξιά προσεταιριστικός, κάτι που μπορεί να οδηγήσει σε απροσδόκητα αποτελέσματα για όσους δεν το γνωρίζουν.

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```

Μπορείς να διαβάσεις περισσότερα για τον τελεστή σύμπτυξης nil στο [A Tour of Swift: Nil-Coalescing Operator][nil-coalescing].
