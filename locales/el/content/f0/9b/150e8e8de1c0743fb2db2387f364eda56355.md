# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

Το [print][print] είναι μια έκφραση που επιστρέφει μια τιμή.
Το Pyret επιτρέπει μόνο μία έκφραση μέσα σε ένα δεδομένο μπλοκ κώδικα, εκτός αν το εξωτερικό μπλοκ είναι σημασμένο με `block`.
Στο δεύτερο παράδειγμα, η προσθήκη του `block` στη δήλωση της συνάρτησης μάς επιτρέπει να τυπώσουμε το 42 πριν το επιστρέψουμε.

## Spies

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Μια εντολή spy δέχεται μια προαιρετική ετικέτα, μία ή περισσότερες μεταβλητές, και αναφέρει κάθε μεταβλητή και την τιμή της.
Επειδή δεν είναι έκφραση, μπορείς να χρησιμοποιήσεις ένα spy μέσα σε ένα μπλοκ χωρίς να χρειάζεται το εξωτερικό μπλοκ να είναι σημασμένο με `block`.

[print]: https://pyret.org/docs/latest/_global_.html#%28idx._%28gentag._57%29%29
[spy]: https://pyret.org/docs/latest/s_spies.html
