# Σχετικά

## Αριθμοί και αριθμητικοί τελεστές

Όλοι οι **αριθμοί**, είτε είναι ακέραιοι είτε όχι, είναι αριθμοί κινητής υποδιαστολής διπλής ακρίβειας IEEE754.
Η υλοποίηση της `jq` χρησιμοποιεί τον τύπο `double` της C.
Αυτό μας περιορίζει σε 53 bits ακρίβειας.

Οι συνήθεις τελεστές είναι διαθέσιμοι για χρήση με αριθμούς:

- αριθμητική: `+`, `-`, `*`, `/`, `%`
- σύγκριση: `==`, `!=`, `<`, `<=`, `>=`, `>`
- τυπικές [μαθηματικές συναρτήσεις][man-math]

  Για συναρτήσεις με μία είσοδο, διοχέτευσε την τιμή μέσα στη συνάρτηση

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Για συναρτήσεις με δύο εισόδους, οι συναρτήσεις αγνοούν την είσοδο και περιμένουν
  τις τιμές εισόδου ως παραμέτρους

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Ο διαχωριστής για τα ορίσματα της συνάρτησης είναι το `;`, όχι το κόμμα.

~~~~exercism/caution
Τι σημαίνει να λέμε "Αυτό μας περιορίζει σε 53 bits ακρίβειας";

Μια επίδειξη:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Αυτό φαίνεται καλό. Τι γίνεται αν ανεβάσουμε τον εκθέτη;

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Αυτοί οι αριθμοί δεν θα έπρεπε να είναι ίσοι.
Κάπως έτσι μοιάζει η "απώλεια ακρίβειας".
Αυτό σημαίνει ότι η `jq` δεν μπορεί να χειριστεί αυθαίρετα μεγάλους αριθμούς.

## Υποθετικές εκφράσεις

Η `jq` χρησιμοποιεί μια [έκφραση `if-then-else`][if-then-else] για τις **υποθετικές εκφράσεις**.
Ως _έκφραση_, τοποθετείται μέσα σε ένα pipeline.

Η σύνταξη είναι: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

Ο όρος `else` είναι προαιρετικός.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Οι επιπλέον συνθήκες χρησιμοποιούν το `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
