# Προσθήκη στις οδηγίες

## Σημείωση

Το κόλπο σε αυτή την άσκηση είναι να καταλάβεις πώς να διατρέχεις ένα εύρος αριθμών, καθώς και πώς να ελέγχεις μια Collection για πολλαπλάσια που διαιρούνται με έναν αριθμό.
Δοκίμασε να χρησιμοποιήσεις τον Spotter για να αναζητήσεις πιθανές κλάσεις και να περιηγηθείς στις κατηγορίες μεθόδων αυτών των κλάσεων.

Επίσης, θυμήσου ότι το περιβάλλον Pharo διαθέτει εκτενείς διασταυρωμένες αναφορές.
Μπορείς να κάνεις δεξί κλικ σε οποιαδήποτε κλάση ή μέθοδο και να περιηγηθείς στις "references" μιας κλάσης (για να δεις πώς μπορεί να δημιουργηθεί), καθώς και στους "senders" μιας μεθόδου (για να δεις πώς μπορεί να χρησιμοποιηθεί).
