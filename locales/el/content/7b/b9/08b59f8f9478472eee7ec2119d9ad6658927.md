Η Elixir έχει συγκεκριμένες συμβάσεις ονομασίας, και μία από αυτές αφορά το πώς να ονομάζεις τις [συναρτήσεις που επιστρέφουν Boolean (λογική τιμή)](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo):

> Οι συναρτήσεις που επιστρέφουν Boolean ονομάζονται με ένα ερωτηματικό στο τέλος.

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

Σημείωσε ότι τα guards, ορισμένες ενσωματωμένες συναρτήσεις και μάκρο που επιστρέφουν Boolean και επιτρέπονται σε guards ακολουθούν διαφορετική σύμβαση και ονομάζονται με πρόθεμα `is_` (`def is_integer`, `defguard is_foo`, `defmacro is_foo`). Οι δύο συμβάσεις δεν πρέπει να ανακατεύονται.
