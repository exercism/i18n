# Οδηγίες

Η Μεγαλειότητά σου διοργανώνει ένα δείπνο στην πρωτεύουσα της [Ένωσης του Κάλμαρ][kalmar_union], την Κοπεγχάγη.
Είναι το μεγαλύτερο πάρτι της χρονιάς και όλοι οι ευγενείς είναι καλεσμένοι.
Όμως φήμες διαδίδονται σε όλη τη χώρα ότι υπάρχει σχέδιο να δηλητηριαστεί η Μεγαλειότητά σου.

Η Μεγαλειότητά της ζήτησε από εσένα, τον βασιλικό ανιχνευτή δηλητηρίων, να ανακαλύψεις αν κάποιο φαγητό ή ποτό είναι δηλητηριασμένο.
Η Μεγαλειότητά σου σχεδιάζει να σερβίρει μόνο **Mushroom pasties** ως φαγητό, αλλά από ποτά υπάρχει μεγάλη ποικιλία.

## 1. Έλεγξε αν το φαγητό είναι σωστό

Υπάρχει μεγάλη πιθανότητα το φαγητό να είναι δηλητηριασμένο αν δεν είναι αυτό που παρήγγειλε η Μεγαλειότητά της.
Αν το φαγητό δεν είναι αυτό που παρήγγειλε η Μεγαλειότητά της, θα πρέπει να πεταχτεί.

Υλοποίησε τη μέθοδο `check_food?`, η οποία δέχεται το όρισμα `food`, που περιέχει το όνομα του φαγητού ως `String`.
Η μέθοδος θα πρέπει να επιστρέφει το φαγητό αν είναι `Mushroom pasties`, αλλιώς θα πρέπει να επιστρέφει `nil`.

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. Έλεγξε αν το ποτό είναι δηλητηριασμένο

Είναι πιθανό το ποτό να είναι δηλητηριασμένο, αλλά είναι λίγο πιο δύσκολο να καταλάβεις αν είναι.
Το ποτό είναι δηλητηριασμένο αν **δεν** περιέχει το γράμμα `i` στο όνομά του, δεν έχει σημασία αν είναι πεζό ή κεφαλαίο.
Το ποτό θα πρέπει να πεταχτεί αν είναι δηλητηριασμένο.

Υλοποίησε τη μέθοδο `check_drink?`, η οποία δέχεται το όρισμα `drink`, που περιέχει το όνομα του ποτού ως `String`.
Η μέθοδος θα πρέπει να επιστρέφει το ποτό αν δεν είναι δηλητηριασμένο, αλλιώς θα πρέπει να επιστρέφει `nil`.

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. Αντικατέστησε το ποτό

Η Μεγαλειότητά σου δεν θα ήθελε να ανησυχήσει τους καλεσμένους της για δηλητήριο στο φαγητό τους.
Επομένως, αν το ποτό είναι δηλητηριασμένο, θα πρέπει να αντικατασταθεί με ένα νέο ποτό, συγκεκριμένα **Apple juice**.

Υλοποίησε τη μέθοδο `replace_drink`, η οποία δέχεται το όρισμα `drink`, που περιέχει το όνομα του ποτού ως `String`.
Η μέθοδος θα πρέπει να επιστρέφει το ποτό αν δεν είναι δηλητηριασμένο, αλλιώς θα πρέπει να επιστρέφει `"Apple juice"`.

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
