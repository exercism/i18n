# Πλειάδες

Μια [πλειάδα][tuple] είναι μια πεπερασμένη διατεταγμένη λίστα στοιχείων που είναι αμετάβλητη.
Οι πλειάδες απαιτούν να έχουν όλες οι θέσεις σταθερό τύπο.
Αυτό με τη σειρά του σημαίνει ότι ο μεταγλωττιστής γνωρίζει τι τύπος βρίσκεται σε κάθε θέση.
Οι τύποι που χρησιμοποιούνται σε μια πλειάδα μπορούν να διαφέρουν σε κάθε θέση, αλλά οι τύποι πρέπει να είναι γνωστοί κατά τη μεταγλώττιση.

## Δημιουργία πλειάδας

Ανάλογα με το αν οι τύποι των τιμών της πλειάδας μπορούν να ερμηνευτούν κατά τη μεταγλώττιση, η πλειάδα μπορεί να δημιουργηθεί με διαφορετικούς τρόπους.
Αν οι τιμές είναι γνωστές κατά τη μεταγλώττιση, η πλειάδα μπορεί να δημιουργηθεί χρησιμοποιώντας τη σύνταξη literal πλειάδας, αλλιώς πρέπει να δηλωθούν ρητά.
Είναι επίσης σημαντικό οι τύποι των τιμών να ταιριάζουν με τους τύπους που καθορίζονται στην πλειάδα και ο αριθμός των τιμών να ταιριάζει με τον αριθμό των τύπων που καθορίζονται.
Ακολουθεί ένα παράδειγμα ορισμού μέσω σύνταξης literal πλειάδας:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Υπάρχει επίσης η δυνατότητα να δημιουργήσεις μια πλειάδα χρησιμοποιώντας την κλάση `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Εναλλακτικά, μπορείς να καθορίσεις ρητά τον τύπο της μεταβλητής που εκχωρείται στην πλειάδα.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Ο ρητός καθορισμός του τύπου της πλειάδας μπορεί να είναι χρήσιμος, καθώς επιτρέπει να ορίσεις ότι μια θέση πρέπει να περιέχει έναν τύπο ένωσης.
Αυτό σημαίνει ότι μια θέση μπορεί να περιέχει πολλούς τύπους.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Μετατροπή

### Δημιουργία πλειάδας από πίνακα

Μπορείς να δημιουργήσεις μια πλειάδα από έναν πίνακα χρησιμοποιώντας τη μέθοδο `from` της κλάσης `Tuple`.
Αυτό απαιτεί να καθοριστεί ο τύπος της πλειάδας.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Μετατροπή σε πίνακα

Μπορείς να μετατρέψεις μια πλειάδα σε πίνακα χρησιμοποιώντας τη μέθοδο `to_a`.
Ο τύπος στοιχείου του πίνακα που προκύπτει είναι η ένωση των τύπων κάθε πεδίου στην πλειάδα.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## Πρόσβαση σε στοιχεία

Όπως οι πίνακες, έτσι και οι πλειάδες χρησιμοποιούν θέσεις που ξεκινούν από το μηδέν, που σημαίνει ότι το πρώτο στοιχείο βρίσκεται στη θέση 0.
Ωστόσο, σε αντίθεση με τους πίνακες, ο τύπος κάθε στοιχείου είναι σταθερός και γνωστός κατά τη μεταγλώττιση, επομένως όταν παίρνεις ένα στοιχείο από μια πλειάδα με βάση τη θέση του, ο τύπος του στοιχείου εξαρτάται από τη θέση.
Για να αποκτήσεις πρόσβαση σε ένα στοιχείο μιας πλειάδας, μπορείς να χρησιμοποιήσεις τον τελεστή `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Μια άλλη διαφορά όσον αφορά την πρόσβαση σε στοιχεία από πίνακες είναι ότι αν καθορίζεται η θέση, τότε ο μεταγλωττιστής θα ελέγξει ότι η θέση είναι εντός των ορίων της πλειάδας.
Αυτό σημαίνει ότι θα πάρεις ένα σφάλμα κατά τη μεταγλώττιση αντί για σφάλμα κατά την εκτέλεση.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Ωστόσο, αν η θέση είναι αποθηκευμένη σε μια μεταβλητή, τότε ο μεταγλωττιστής δεν θα μπορεί να ελέγξει αν η θέση είναι εντός των ορίων της πλειάδας κατά τη μεταγλώττιση και αντ' αυτού θα εμφανίσει ένα σφάλμα κατά την εκτέλεση.

## Υποπλειάδα

Μπορείς να πάρεις μια υποπλειάδα από μια πλειάδα χρησιμοποιώντας τον τελεστή `[]` με ένα εύρος.
Αυτό που επιστρέφεται είναι μια νέα πλειάδα με τα στοιχεία από το καθορισμένο εύρος.
Το εύρος πρέπει να δοθεί κατά τη μεταγλώττιση, αλλιώς ο μεταγλωττιστής δεν θα μπορεί να γνωρίζει τους τύπους των στοιχείων στην υποπλειάδα.
Αυτό σημαίνει ότι το εύρος πρέπει να είναι ένα literal εύρους και να μην έχει εκχωρηθεί σε μια μεταβλητή.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Πότε να χρησιμοποιείς πλειάδα

Οι πλειάδες είναι χρήσιμες όταν θέλεις να ομαδοποιήσεις έναν σταθερό αριθμό τιμών μαζί, όπου οι τύποι των τιμών είναι γνωστοί κατά τη μεταγλώττιση.
Αυτό συμβαίνει επειδή οι πλειάδες απαιτούν λιγότερη μνήμη και είναι ταχύτερες από τους πίνακες λόγω της αμετάβλητης φύσης τους.
Μια άλλη περίπτωση χρήσης είναι η επιστροφή πολλαπλών τιμών από μια μέθοδο.
Αυτό είναι ιδιαίτερα χρήσιμο αν οι τιμές έχουν διαφορετικούς τύπους, καθώς κάθε θέση στην πλειάδα μπορεί να έχει διαφορετικό τύπο.

Οι πλειάδες δεν θα πρέπει να χρησιμοποιούνται όταν χρειάζεται μια δομή δεδομένων που μπορεί να μεγαλώσει ή να μικρύνει σε μέγεθος ή που χρειάζεται συχνά τροποποίηση.
