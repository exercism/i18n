# Εισαγωγή

Οι [βρόχοι repeat-while][repeat-loops] είναι παρόμοιοι με τους βρόχους `while`, αλλά με μια βασική διαφορά: ο έλεγχος της συνθήκης γίνεται *μετά* την εκτέλεση του σώματος του βρόχου και όχι πριν.
Ως αποτέλεσμα, ένας βρόχος `repeat-while` εκτελεί εγγυημένα το μπλοκ κώδικα του τουλάχιστον μία φορά.

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
