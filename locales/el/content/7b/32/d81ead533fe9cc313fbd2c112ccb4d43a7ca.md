# Πολιτική εισόδου στη λέσχη ποίησης

## Ιστορία

Μια νέα λέσχη ποίησης άνοιξε στην πόλη σου και σκέφτεσαι να πας. Επειδή στο παρελθόν έχουν συμβεί διάφορα, η λέσχη έχει μια πολύ συγκεκριμένη πολιτική εισόδου που θα πρέπει να μάθεις καλά πριν επιχειρήσεις να μπεις.

Στη λέσχη ποίησης υπάρχουν δύο πόρτες και οι δύο φυλάσσονται. Για να μπεις, θα πρέπει να ανακαλύψεις το συνθηματικό της ημέρας:

### Μπροστινή πόρτα

1. Ο φρουρός θα απαγγείλει ένα ποίημα, έναν στίχο τη φορά·
   - Θα πρέπει να απαντήσεις με το κατάλληλο γράμμα.
2. Ο φρουρός θα σου πει όλα τα γράμματα που απάντησες μαζεμένα·
   - Πρέπει να μορφοποιήσεις τα γράμματα ως μια λέξη με κεφαλαίο αρχικό γράμμα.

Για παράδειγμα, ένας από τους αγαπημένους τους συγγραφείς είναι ο Michael Lockwood, ο οποίος έχει γράψει το παρακάτω _ακροστιχικό_ ποίημα, που σημαίνει ότι το πρώτο γράμμα κάθε στίχου σχηματίζει μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φρουρός απαγγείλει **Stands so high**, θα απαντήσεις **S**, και όταν ο φρουρός απαγγείλει **Huge hooves too**, θα απαντήσεις **H**.

Τελικά το συνθηματικό που σημειώνεις είναι `Shire` και μπαίνεις μέσα.

### Πίσω πόρτα

Στο πίσω μέρος της λέσχης θα βρεις τους πιο διάσημους ποιητές, που είναι κάτι σαν την περιοχή VIP. Επειδή αυτό δεν είναι για όλους, η διαδικασία της πίσω πόρτας είναι λίγο πιο μπερδεμένη.

1. Ο φρουρός θα απαγγείλει ένα ποίημα, έναν στίχο τη φορά·
   - Θα πρέπει να απαντήσεις με το κατάλληλο γράμμα.
2. Ο φρουρός θα σου πει όλα τα γράμματα που απάντησες μαζεμένα, _αλλά μερικές φορές υπάρχουν κενά μετά από κάθε στίχο_:
   - Πρέπει να μορφοποιήσεις τα γράμματα ως μια λέξη με κεφαλαίο αρχικό γράμμα
   - και να ζητήσεις ευγενικά, προσθέτοντας `, please`

Για παράδειγμα, το ποίημα που αναφέρθηκε πριν είναι επίσης _τελεστιχικό_, που σημαίνει ότι το τελευταίο γράμμα κάθε στίχου σχηματίζει μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φρουρός απαγγείλει **Stands so high**, θα απαντήσεις **h**, και όταν ο φρουρός απαγγείλει **Huge hooves too**, θα απαντήσεις **o**.

Τελικά το συνθηματικό που σημειώνεις είναι `Horse, please` και μπορείς να γλεντήσεις με τους διάσημους ποιητές.
