# Προσθήκη οδηγιών

## Υποδείξεις

Πρέπει να υλοποιήσεις τη συνάρτηση `recite` που βγάζει τους στίχους του
"The Twelve Days of Christmas". Μπορείς να χρησιμοποιήσεις την υπογραφή που
σου δίνεται αν δεν είσαι σίγουρος για τους τύπους, αλλά μην την αφήσεις να
περιορίσει τη δημιουργικότητά σου.

Αυτή η άσκηση έχει να κάνει με κειμενικά δεδομένα. Για ιστορικούς λόγους, ο
τύπος `String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα από
χαρακτήρες. Για πιο αποδοτικό χειρισμό κειμενικών δεδομένων, μπορείς να
χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να

- διαβάσεις για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types)
  στην Haskell.
- προσθέσεις το `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- κάνεις import το `Data.Text` [με τον παρακάτω
  τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- γράψεις π.χ. `recite :: Int -> Int -> [Text]` και να αναφέρεσαι στους
  συνδυαστές του `Data.Text` ως π.χ. `T.pack`.
- κοιτάξεις την τεκμηρίωση για το
  [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο TwelveDays.hs, δηλαδή:

```haskell
recite :: Int -> Int -> [Text]
```

Αυτό το μέρος είναι εντελώς προαιρετικό.
