# Σχετικά

Ενώ ο τροποποιητής `readonly` εμποδίζει την αντικατάσταση της τιμής ή της αναφοράς σε ένα πεδίο, δεν προσφέρει καμία προστασία στα μέλη ενός τύπου αναφοράς.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Για να διασφαλίσεις ότι όλα τα μέλη ενός τύπου αναφοράς προστατεύονται, τα πεδία μπορούν να γίνουν `readonly` και οι αυτόματες ιδιότητες μπορούν να οριστούν χωρίς προσπελαστή `set`.

Η Βιβλιοθήκη Βασικών Κλάσεων (Base Class Library, BCL) παρέχει κάποιες εκδόσεις συλλογών μόνο για ανάγνωση, όπου υπάρχει η απαίτηση να εμποδίζεται η ενημέρωση των μελών μιας συλλογής. Αυτές παρέχονται με τη μορφή περιτυλιγμάτων:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
