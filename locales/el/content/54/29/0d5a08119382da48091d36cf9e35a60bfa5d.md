# Εισαγωγή

## Τελεστές σύγκρισης

Οι τελεστές σύγκρισης είναι παρόμοιοι με πολλές άλλες γλώσσες.

Για την ισότητα, οι τελεστές είναι `==` (ίσο) και `!=` (όχι ίσο).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Οι τελεστές μεγαλύτερο/μικρότερο από είναι επίσης συμβατικοί.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Διακλάδωση με `if`

Αυτή είναι η πλήρης μορφή μιας έκφρασης `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Οι παρενθέσεις `()` γύρω από κάθε συνθήκη είναι υποχρεωτικές.
- Μια συνθήκη πρέπει να αξιολογείται σε μια Boolean τιμή `true` ή `false`.
  Η Kotlin δεν έχει την έννοια του "truthy" και του "falsy" όπως συναντάται σε κάποιες γλώσσες.
- Τα άγκιστρα `{}` είναι προαιρετικά, αν υπάρχει μόνο μία έκφραση.
- Τόσο το `else if` όσο και το `else` είναι προαιρετικά, και μπορούν να υπάρχουν πολλά μπλοκ `else if`.

Η έκφραση `if` μπορεί επίσης να χρησιμοποιηθεί για να "επιλέξει" μια τιμή:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## Εναλλακτικές;

Από σκόπιμη επιλογή, η Kotlin _δεν_ έχει τον τριαδικό τελεστή `? :` που υπάρχει στη Java.
Προτιμάται μια συνοπτική μορφή του `if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
