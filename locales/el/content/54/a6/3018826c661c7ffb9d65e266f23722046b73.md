# Εισαγωγή στην αριθμητική στο κέλυφος Bash

Το Bash μπορεί να κάνει αριθμητικές πράξεις, αλλά _μόνο με ακέραιους αριθμούς_.
Αν χρειάζεται να κάνεις μαθηματικά κινητής υποδιαστολής, θα χρειαστεί να καλέσεις κάποιο εξωτερικό πρόγραμμα (όπως το [awk][awk] ή το [bc][bc]).

Οι αριθμητικοί τελεστές παρατίθενται (με σειρά προτεραιότητας) στο εγχειρίδιο: [Αριθμητική του κελύφους][arithmetic].

Επιπλέον, το Bash εκτελεί αριθμητικές πράξεις μόνο σε ορισμένα σημεία (γνωστά ως αριθμητικά "πλαίσια").

## Αριθμητική επέκταση

Η αριθμητική επέκταση μοιάζει με την [υποκατάσταση εντολής][cmd-sub], αλλά με διπλές παρενθέσεις.

```bash
$(( expression ))
```

Αυτή η σύνταξη επεκτείνεται στο αποτέλεσμα της αξιολόγησης της παράστασης.
Χρησιμοποιείται συχνά για να καταγράψεις το αποτέλεσμα σε μια μεταβλητή:

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
Το πόσα κενά θα βάλεις μέσα στις παρενθέσεις εξαρτάται από εσένα.
Είναι θέμα στυλ και αναγνωσιμότητας.

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

Ο φιλικός σου συγγραφέας προτιμά να προσθέτει κενά, ώστε η αριθμητική παράσταση να φαίνεται πιο καθαρά μέσα στις παρενθέσεις.
~~~~

## Αριθμητική συνθήκη

Η αριθμητική συνθήκη εκτελείται μέσα σε διπλές παρενθέσεις _χωρίς_ το αρχικό `$`:

```bash
(( expression ))
```

Αυτό δεν επεκτείνεται στο αποτέλεσμα.
Παράγει όμως μια _κατάσταση εξόδου_.

* Η κατάσταση εξόδου είναι 0 (επιτυχία) αν το αποτέλεσμα της παράστασης είναι **μη μηδενικό**.
* Η κατάσταση εξόδου είναι 1 (αποτυχία) αν το αποτέλεσμα της παράστασης είναι **μηδενικό**.

~~~~exercism/note
Μέσα στο `((` το Bash χρησιμοποιεί την ίδια έννοια του αληθούς και του ψευδούς όπως η γλώσσα C: το μηδέν είναι ψευδές, το μη μηδενικό είναι αληθές.
**Αυτό είναι το αντίθετο από το πώς το Bash αξιολογεί τις καταστάσεις εξόδου!**
~~~~

Αυτή η σύνταξη χρησιμοποιείται συνήθως σε δύο σημεία:

1. ως το μέρος COMMAND μιας εντολής `if` ή ενός `while` βρόχου.

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. ως αυτόνομη εντολή για να αλλάξεις την τιμή μιας μεταβλητής.

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   Πρόσεχε όταν χρησιμοποιείς αριθμητική με αυτόν τον τρόπο μαζί με το `set -e`.
   Αν η παράσταση αξιολογηθεί σε μηδέν, η κατάσταση εξόδου θα είναι μη μηδενική και το Bash θα τερματιστεί.

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   Για πιο αναλυτική συζήτηση σχετικά με τον τελεστή `++`, δες αυτό το άρθρο: [Μετεπαύξηση εναντίον προεπαύξησης][incr]

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## Άλλα σημεία με αριθμητικό πλαίσιο

Υπάρχουν μερικά ακόμη σημεία που αποτελούν αριθμητικά πλαίσια:

* Ο [αριθμητικός `for` βρόχος][looping-for].

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* Το μέρος της θέσης σε έναν πίνακα με αριθμητικές θέσεις.

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  Για περισσότερα σχετικά με τους πίνακες, διάβασε το έγγραφο της έννοιας [Arrays][arrays].

* Τα μέρη της μετατόπισης και του μήκους της επέκτασης `${var:offset:length}`.
* Η [ενσωματωμένη εντολή `let`][let].
  * Πρόσεξε ότι το `(( expression ))` προτιμάται από το `let "expresson"`.
    Σε αντίθεση με την αριθμητική συνθήκη, η παράσταση του `let` υπόκειται σε επέκταση ονόματος αρχείου και διαχωρισμό λέξεων, και απαιτεί τη χρήση εισαγωγικών.
* Η ανάθεση σε μεταβλητή, όταν η μεταβλητή έχει το "χαρακτηριστικό ακέραιου".

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  Κατά τη γνώμη του συγγραφέα, το `declare -i` έχει περιορισμένη χρήση.
  Το κύριο πλεονέκτημά του είναι ότι επιτρέπει "γυμνή" αριθμητική (χωρίς τη σύνταξη της αριθμητικής παράστασης).
  Αυτό μπορεί να μπερδέψει όσους διαβάζουν τον κώδικά σου, αφού οι αριθμητικές παραστάσεις αξιολογούνται σε απροσδόκητα σημεία.
  ~~~~

## Χρήση μεταβλητών σε αριθμητικές παραστάσεις

Να ένα χαρακτηριστικό των αριθμητικών πλαισίων που βελτιώνει την αναγνωσιμότητα.

```bash
height=10
width=20
area=$(( height * width ))
```

Πρόσεξες ότι τα σύμβολα δολαρίου `$` λείπουν από τις μεταβλητές στην αριθμητική παράσταση;
Το Bash σου το επιτρέπει.
Κάνει τις παραστάσεις πολύ πιο ευανάγνωστες.

Το εγχειρίδιο λέει,

> Μέσα σε μια παράσταση, οι μεταβλητές του κελύφους μπορούν επίσης να αναφέρονται με το όνομά τους χωρίς τη σύνταξη της επέκτασης παραμέτρων.

Λειτουργεί ακόμη και για στοιχεία πίνακα:

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

Όμως άλλες παραστάσεις παραμέτρων χρειάζεται να χρησιμοποιούν την ειδική τους σύνταξη.
Για παράδειγμα, ο διπλασιασμός του μήκους μιας συμβολοσειράς:

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

Και οι παράμετροι θέσης πρέπει επίσης.
Αν οι δύο πρώτες παράμετροι θέσης παριστάνουν το πλάτος και το ύψος:

```bash
area=$(( $1 * $2 ))
```
