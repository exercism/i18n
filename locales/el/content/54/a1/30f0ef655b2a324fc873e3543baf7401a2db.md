# Υποδείξεις

## Γενικά

- Στην Python, το `None` χρησιμοποιείται συχνά ως προσωρινή τιμή για να αναπαραστήσει την **απουσία τιμής** για μια μεταβλητή, αντικείμενο ή όρισμα.

## 1. Φτιάξε νέο διάγραμμα θέσεων

Θυμήσου, θα χρειαστεί πρώτα να δημιουργήσεις ένα άδειο λεξικό. Στη συνέχεια, γέμισε τα _κλειδιά_ του λεξικού με όσες θέσεις είναι διαθέσιμες και όρισε τις _τιμές_ τους σε μια **προσωρινή τιμή** για να δείξεις ότι είναι διαθέσιμες αλλά μη ανατεθειμένες.

## 2. Τακτοποίησε τις κρατήσεις

- Αν δεν υπάρχει λίστα καλεσμένων, θα θελήσεις να επιστρέψεις ένα `new_seating_chart()` γεμάτο με προσωρινές τιμές. Ένα `default argument` για τη συνάρτησή σου μπορεί να βοηθήσει εδώ. Αν έχεις λίστα καλεσμένων, μπορείς να ξεκινήσεις με ένα `new_seating_chart()`, και μετά να κάνεις βρόχο από το 1 έως τον αριθμό των καλεσμένων και να τους αναθέσεις σε θέσεις με τη σειρά.

## 3. Βρες όλες τις διαθέσιμες θέσεις

- Μπορείς να διατρέξεις όλα τα ζεύγη (κλειδί, τιμή) σε ένα λεξικό καλώντας `dict.items()`. Μπορείς να επαληθεύσεις ότι μια μεταβλητή ή τιμή είναι None μέσω μιας `if statement`, το `if var is None` θα επιστρέψει True αν η τιμή είναι `None`. Μπορείς να προσθέσεις πράγματα σε μια `list` καλώντας `list.append()`

## 4. Τρέχουσα χωρητικότητα θέσεων

- Μπορείς να διατρέξεις όλες τις τιμές στο αντικείμενο λεξικού καλώντας `dict.values()`. Οι θέσεις είναι διαθέσιμες όταν η τιμή τους είναι `None`.

## 5. Εξυπηρέτησε τους καλεσμένους που περιμένουν

- Πρέπει να βρεις τον τρέχοντα αριθμό κενών θέσεων και να ελέγξεις αν είναι μεγαλύτερος ή ίσος με τον αριθμό των καλεσμένων που περιμένουν. Αν οι καλεσμένοι μπορούν να εξυπηρετηθούν, θα χρειαστεί να καλέσεις το `find_all_available_seats()` για να πάρεις μια λίστα με αριθμούς θέσεων στους οποίους μπορείς να αναθέσεις καλεσμένους. Θυμήσου ότι το `range()` μπορεί να πάρει οποιοδήποτε είδος αριθμού ως όρισμα....**συμπεριλαμβανομένου** του αριθμού που επιστρέφεται από την κλήση του `len()` σε μια λίστα. Επίσης θυμήσου ότι χρησιμοποιώντας το `list[index_number]` θα επιστρέψει την **τιμή** που βρίσκεται στον **αριθμό θέσης** μέσα στις αγκύλες.

## 6. Άδειασε τις θέσεις

- Δεδομένου του διαγράμματος θέσεων `dict`, και μιας `list` με αριθμούς θέσεων, θα θελήσεις να δείξεις ότι η θέση είναι τώρα διαθέσιμη για άλλον καλεσμένο αντικαθιστώντας το όνομά τους με μια προσωρινή τιμή. Το να διατρέξεις τη λίστα με τους αριθμούς θέσεων και να ψάξεις για αυτές τις θέσεις στο λεξικό μπορεί να βοηθήσει εδώ.
