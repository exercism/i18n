# επαναχρησιμοποίηση συνάρτησης

Η επαναχρησιμοποίηση μιας συνάρτησης που έχεις ήδη γράψει μπορεί να σε βοηθήσει να γράψεις κώδικα που συντηρείται πιο εύκολα.

Επαναχρησιμοποίησε τις συναρτήσεις που υπάρχουν ήδη:
- Η `remaining_minutes_in_oven/1` μπορεί να επαναχρησιμοποιήσει την `expected_minutes_in_oven/0`
- Η `total_time_in_minutes/2` μπορεί να επαναχρησιμοποιήσει την `preparation_time_in_minutes/1`
