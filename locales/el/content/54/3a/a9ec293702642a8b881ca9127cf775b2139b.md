# Μάθηση

Η γλώσσα προγραμματισμού Pascal έχει μακρά ιστορία και μεγάλο μέρος της τεκμηρίωσης στο διαδίκτυο απευθύνεται σε αρχάριους. Τα περισσότερα από αυτά τα μαθήματα ασχολούνται με προγράμματα κονσόλας, όπου εκτυπώνεις πληροφορίες στην οθόνη ή/και διαβάζεις την είσοδο του χρήστη. Για παράδειγμα, ένα από τα πιο συνηθισμένα μαθήματα για αρχάριους είναι ένα πρόγραμμα που εκτυπώνει 'Hello World' στην οθόνη:

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

Όταν εκτελεστεί από μια κονσόλα/τερματικό, αυτό το πρόγραμμα θα εκτυπώσει 'Hello World' στην οθόνη.

Εδώ στο Exercism χρησιμοποιούμε αυτοματοποιημένα τεστ για να διασφαλίσουμε ότι οι λύσεις σου είναι σωστές, και γι' αυτό χρειάζεται να χρησιμοποιήσουμε **unit** αντί για **πρόγραμμα**. Η κύρια διαφορά είναι ότι θα χρειαστεί να επιστρέψεις μια τιμή από μια συνάρτηση αντί να εκτυπώσεις κάτι στο τερματικό:

```pascal
writeln('Hello World!');
```

έγινε

```pascal
result := 'Hello World!'
```

Οι εντολές write/writeln εξακολουθούν να είναι χρήσιμες για την εμφάνιση πληροφοριών ή για την απόκτηση μιας κειμενικής αναπαράστασης της εξόδου μιας εντολής, μιας μαθηματικής πράξης κ.λπ.
