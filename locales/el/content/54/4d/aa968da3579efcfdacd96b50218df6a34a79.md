# Οδηγίες

Δεδομένης μιας συμβολοσειράς που περιέχει αγκύλες `[]`, άγκιστρα `{}`, παρενθέσεις `()`, ή οποιονδήποτε συνδυασμό τους, επιβεβαίωσε ότι όλα τα ζεύγη είναι σωστά ταιριασμένα και εμφωλευμένα.
Η συμβολοσειρά μπορεί επίσης να περιέχει άλλους χαρακτήρες, τους οποίους για τους σκοπούς αυτής της άσκησης θα πρέπει να αγνοήσεις.
