# Βοήθεια

Μέρη όπου μπορείς να αναζητήσεις βοήθεια για ερωτήσεις σχετικά με την Tcl:

* Η ετικέτα `tcl` στο [Stack Overflow](https://stackoverflow.com/tags/tcl).
* Δες την ενότητα Resources της [σελίδας πληροφοριών της ετικέτας `tcl` στο Stack Overflow](https://stackoverflow.com/tags/tcl/info).
* Άνοιξε ένα issue στο αποθετήριο [exercism/tcl](https://github.com/exercism/tcl) στο GitHub.
