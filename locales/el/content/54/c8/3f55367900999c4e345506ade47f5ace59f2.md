# Υποδείξεις

## Γενικά

- [Αυτή η σελίδα][case-expressions] έχει μια ωραία εισαγωγή στις εκφράσεις case στη Gleam.

## 1. Απάντησε σε μια σωστή μαντεψιά

- Μπορείς να χρησιμοποιήσεις ένα κυριολεκτικό μοτίβο για να αντιστοιχίσεις έναν συγκεκριμένο αριθμό.

## 2. Απάντησε σε μια κοντινή μαντεψιά

- Μπορείς να χρησιμοποιήσεις είτε ένα κυριολεκτικό μοτίβο είτε ένα μοτίβο μεταβλητής και έναν φρουρό.

## 3. Απάντησε σε πολύ χαμηλές μαντεψιές

- Μπορείς να χρησιμοποιήσεις συνδυασμό ενός μοτίβου μεταβλητής και ενός φρουρού.

## 4. Απάντησε σε πολύ υψηλές μαντεψιές

- Μπορείς να χρησιμοποιήσεις συνδυασμό ενός μοτίβου μεταβλητής και ενός φρουρού, ή ένα μοτίβο αγνόησης.

[case-expressions]: https://gleam.run/book/tour/case-expressions.html
