# Εισαγωγή

Μια `String` στη Julia είναι μια αμετάβλητη, πεπερασμένη ακολουθία χαρακτήρων [Unicode](https://en.wikipedia.org/wiki/Unicode), σε κωδικοποίηση [UTF-8](https://en.wikipedia.org/wiki/UTF-8).

Ένα κυριολεκτικό `String` είναι μια ακολουθία χαρακτήρων μέσα σε διπλά εισαγωγικά:

```julia-repl
julia> "Christopher"
"Christopher"
```

Οι συμβολοσειρές μπορούν να συνενωθούν με τον τελεστή `*`:

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
Αν αναρωτιέσαι γιατί η Julia χρησιμοποιεί `*` αντί για `+` για τη συνένωση συμβολοσειρών, ρίξε μια ματιά στο [Εγχειρίδιο της Julia](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation).
~~~~

Κάποιοι ειδικοί χαρακτήρες χρειάζονται διαφυγή με μια ανάστροφη κάθετο μπροστά:

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Η Julia περιλαμβάνει από προεπιλογή πολλές χρήσιμες συναρτήσεις για εργασία με συμβολοσειρές:

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
