# Οδηγίες

Υπάρχουν δύο διαφορετικοί τύποι μοτέρ που μπορεί να παράγει ένας μόνο κατασκευαστής· από αυτό το σημείο και πέρα τα μοτέρ θα ονομάζονται μοτέρ A και μοτέρ B. Και τα δύο μοτέρ χρειάζονται 3 εξαρτήματα για την παραγωγή τους: καλωδίωση, διάτρηση και συναρμολόγηση. Κάθε μοτέρ απαιτεί διαφορετικό χρόνο για καθένα από αυτά τα στάδια της παραγωγής. Γενικά, μία μονάδα μοτέρ A απαιτεί t_a_1 ώρες για καλωδίωση, t_a_2 ώρες για διάτρηση και t_a_3 ώρες για συναρμολόγηση. Από την άλλη, μία μονάδα μοτέρ B απαιτεί t_b_1 ώρες για καλωδίωση, t_b_2 ώρες για διάτρηση και t_b_3 ώρες για συναρμολόγηση. Υλοποίησε μια συνάρτηση που, δεδομένου του συνολικού αριθμού ωρών που διατίθενται για κάθε στάδιο της παραγωγής (t_1 ώρες για καλωδίωση, t_2 ώρες για διάτρηση και t_3 ώρες για συναρμολόγηση) και των τιμών για κάθε τύπο μοτέρ (p_a, p_b), υπολογίζει τις βέλτιστες ποσότητες μοτέρ A και μοτέρ B που μεγιστοποιούν το κέρδος.

Η συνάρτηση θα έχει 4 συνολικά παραμέτρους εισόδου. Περιγράφονται παρακάτω:
1. a_hours: τριάδα με (t_a_1, t_a_2, t_a_3) σε ώρες
2. b_hours: τριάδα με (t_b_1, t_b_2, t_b_3) σε ώρες
3. total_hours: τριάδα με (t_1, t_2, t_3) σε ώρες
4. prices: δυάδα με (p_a, p_b) σε δολάρια

Η έξοδος θα πρέπει να είναι μία μόνο τριάδα που αποτελείται από (q_a, q_b, profit), όπου:
1. q_a: βέλτιστη ποσότητα μοτέρ A που θα παραχθεί
2. q_b: βέλτιστη ποσότητα μοτέρ B που θα παραχθεί
3. profit: η τιμή του κέρδους που μεγιστοποιείται, σε δολάρια

Άλλα σημαντικά σημεία που πρέπει να προσέξεις:
Τα q_a και q_b δεν μπορούν να είναι αριθμοί κινητής υποδιαστολής, γιατί ένα κλάσμα μοτέρ δεν μπορεί να παραχθεί.
Τα αποτελέσματα του μοντέλου Z3 για τις μεταβλητές θα πρέπει να μετατραπούν σε int πριν την έξοδο. Αν το αποτέλεσμα του μοντέλου Z3 είναι τύπου `IntNumRef`, μπορεί να χρησιμοποιηθεί η μέθοδος κλάσης `as_long()` για τη μετατροπή σε ακέραιο.
Αν το πρόβλημα είναι μη ικανοποιήσιμο λόγω μη έγκυρων εισόδων, τότε πέτα μια ενσωματωμένη εξαίρεση της Python, `ArithmeticError()`.
