# Εισαγωγή

Ο τύπος `char` της F# είναι μια τιμή 16 bit που αναπαριστά τα μικρότερα διευθυνσιοδοτήσιμα components του κειμένου και είναι αμετάβλητος εξ ορισμού.

Τα `char` ορίζονται ως κυριολεκτικά με μονά εισαγωγικά:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Οι συμβολοσειρές είναι μια ακολουθία από χαρακτήρες.

Μπορείς να πάρεις έναν μεμονωμένο `char` από μια συμβολοσειρά με θέσεις (μηδενικής βάσης):

```fsharp
"Exercism"[4] //  =>  'c'
```

Η επανάληψη πάνω σε μια συμβολοσειρά επιστρέφει ένα `char` σε κάθε βήμα.

Το επόμενο παράδειγμα χρησιμοποιεί μια συνάρτηση υψηλότερης τάξης και μια ανώνυμη συνάρτηση, για ευκολία.
Αυτές θα καλυφθούν κανονικά αργότερα στο πρόγραμμα σπουδών, αλλά για την ώρα είναι ουσιαστικά ένας συνοπτικός τρόπος να γράψεις έναν βρόχο πάνω στους χαρακτήρες μιας συμβολοσειράς.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Όπως φαίνεται παραπάνω, ένα `char` μπορεί να μετατραπεί στην `int` τιμή του.
Αυτό λειτουργεί επίσης (*τουλάχιστον μερικές φορές*) και για άλλα συστήματα γραφής:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Το υποκείμενο Int16 χρησιμοποιείται όταν συγκρίνεις χαρακτήρες:

```fsharp
'A' < 'D'  // =>  true
```

Επίσης, ένα `int` μπορεί να μετατραπεί σε `char`:

```fsharp
char 77  // => 'M'
```

Η βιβλιοθήκη `System.Char` περιέχει το πλήρες σύνολο των μεθόδων που αναμένονται από μια γλώσσα .NET, όπως μετατροπές σε κεφαλαία/πεζά:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
