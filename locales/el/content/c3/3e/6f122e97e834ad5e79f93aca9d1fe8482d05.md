# σύμβολο κράτησης θέσης

## Συμβουλές για τη `jq`

Αυτή η άσκηση αφορά τη λήψη ενός αντικειμένου εισόδου και τον μετασχηματισμό του σε ένα νέο αντικείμενο.
Μερικές ενσωματωμένες συναρτήσεις που μπορεί να βοηθήσουν:

- [`to_entries`][x_entries]
  - αυτή η συνάρτηση παίρνει ως είσοδο ένα αντικείμενο
  - βγάζει έναν _πίνακα_: κάθε στοιχείο του πίνακα είναι ένα αντικείμενο `{"key": "K", "value": V}`
    - κάθε `K` είναι ένα κλειδί από το αντικείμενο εισόδου
    - κάθε `V` είναι η αντίστοιχη τιμή του `K`.
- [`from_entries`][x_entries]
  - η αντίστροφη πράξη
  - παίρνει έναν πίνακα από αντικείμενα `{"key": K, "value": V}` και κατασκευάζει ένα αντικείμενο

Ένα παράδειγμα:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

βγάζει

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
