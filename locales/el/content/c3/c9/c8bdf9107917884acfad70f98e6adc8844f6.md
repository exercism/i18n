# Εισαγωγή

Το χαρακτηριστικό Flags επιτρέπει στις τιμές που ορίζονται σε μια διακριτή ένωση να αναπαρίστανται ως θέσεις bit (δηλ. σημαίες).
Ως σημαίες, αυτές οι τιμές μπορούν να συνδυαστούν, καθιστώντας δυνατή την αναπαράσταση πολλών boolean συνθηκών σε μία μόνο τιμή.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Ο ορισμός μιας σημαίας μπορεί να γίνει με τον τελεστή bitwise OR (`|||`), ενώ η ακύρωσή της με έναν συνδυασμό του τελεστή bitwise AND (`&&&`) και του τελεστή bitwise άρνησης (`~~~`).
Ο έλεγχος της κατάστασης μιας σημαίας μπορεί να γίνει με τον τελεστή bitwise AND, αλλά μπορείς να χρησιμοποιήσεις και τη μέθοδο `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Δες τη [Σύνοψη των bitwise τελεστών][bitwise-operators] για μια πλήρη λίστα με τους bitwise τελεστές που διαθέτει η γλώσσα F#.

[bitwise-operators]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/symbol-and-operator-reference/bitwise-operators#summary-of-bitwise-operators
