# Εισαγωγή

Τις περισσότερες φορές το Factor χειρίζεται την επανάληψη μέσω συνδυαστών όπως τα `each`, `map` και `count`. Μερικές φορές όμως, ο πιο καθαρός τρόπος να εκφράσεις έναν υπολογισμό είναι η **αναδρομή**: μια λέξη που καλεί τον εαυτό της.

## Ορισμός μιας αναδρομικής λέξης

Ένας ορισμός `:` μπορεί να καλέσει τον εαυτό του απευθείας:

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## Διακλάδωση: κενή ή όχι

Το `if-empty` (στο [`sequences`][sequences]) είναι η φυσική βασική περίπτωση της αναδρομής:

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

Το `emptyquot` εκτελείται αφού η (κενή) ακολουθία έχει ήδη καταναλωθεί· το `nonemptyquot` εκτελείται με την ακολουθία ακόμα στη στοίβα.

## `cond`: μια αλυσίδα διακλαδώσεων με συνθήκες

Όταν η αναδρομή σου έχει περισσότερες από δύο περιπτώσεις, το `cond` (στο [`combinators`][combinators]) κρατάει τον κώδικα ευανάγνωστο:

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## Μπροστινές αναφορές με `DEFER:`

Ένας ορισμός `:` μπορεί να καλέσει τον εαυτό του απευθείας, αλλά όταν δύο λέξεις καλούν *η μία την άλλη*, ο αναλυτής βλέπει την πρώτη πριν υπάρξει η δεύτερη. Το `DEFER:` δεσμεύει ένα όνομα ώστε ο πρώτος ορισμός να μπορεί να μεταγλωττιστεί:

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

Το `DEFER:` είναι επίσης χρήσιμο όταν μια βοηθητική λέξη διαβάζεται πιο φυσικά *μετά* τη λέξη που τη χρησιμοποιεί.
