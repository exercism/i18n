# Υποδείξεις

## Γενικά

- Ο χώρος ονομάτων `clojure.string` έχει πολλές χρήσιμες [συναρτήσεις χειρισμού συμβολοσειρών][string-ns].

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

- Η συνάρτηση [`split`][split] μπορεί να χρησιμοποιηθεί για να χωρίσεις μια συμβολοσειρά με βάση μια κανονική έκφραση.
- Η συνάρτηση [`trim`][trim] μπορεί να χρησιμοποιηθεί για να αφαιρέσεις τα κενά από τα άκρα μιας συμβολοσειράς.

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

- Μια `string` μπορεί να μετατραπεί σε πεζά χρησιμοποιώντας τη συνάρτηση [`lower-case`][lower-case].

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

- Η συνάρτηση [`str`][str] μπορεί να χρησιμοποιηθεί για να συνενώσεις συμβολοσειρές.
