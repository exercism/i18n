# Οδηγίες

Η φίλη σου η Leticia εργάζεται στο γραφείο Απολεσθέντων ενός σταθμού του μετρό.

Κάθε αντικείμενο που βρίσκεται προστίθεται ως νέα καταγραφή σε μια λίστα αντικειμένων για τη μέρα.
Στο τέλος του μήνα, κάθε αντικείμενο που δεν παραλήφθηκε μεταφέρεται σε έναν χώρο φύλαξης, σε ένα κουτί με ετικέτα που δείχνει την ημερομηνία που βρέθηκε.
Όλα αυτά γίνονται σε χαρτί, οπότε μερικές φορές τα πράγματα γίνονται δυσκίνητα!

~~~~exercism/note
Αυτές είναι οι εντολές που αναφέρονται σε αυτή την έννοια:

| Εντολή        | Περιγραφή                                                 |
|---------------|-----------------------------------------------------------|
| push a        | ωθεί το a στη στοίβα, μειώνοντας το `rsp` κατά το μέγεθος του a |
| pop a         | αφαιρεί το a από τη στοίβα, αυξάνοντας το `rsp` κατά το μέγεθος του a |
~~~~

## 1. Δημιούργησε μια καταγραφή για κάθε αντικείμενο

Το πρώτο πράγμα που πρέπει να κάνεις είναι να οργανώσεις όλα τα αντικείμενα, ώστε να μπορείς να τα αναζητήσεις πιο εύκολα.
Κάθε αντικείμενο ταυτοποιείται στην αποθήκευση από το ID του, μια περιγραφή, την ημερομηνία που βρέθηκε και έναν μεταβλητό αριθμό κατηγοριών.

Όρισε μια συνάρτηση `create_item_entry` που δεν έχει τιμή επιστροφής και εισάγει μια νέα καταγραφή για ένα αντικείμενο σε μια θέση μνήμης.
Αυτή η συνάρτηση μπορεί να πάρει οποιονδήποτε αριθμό παραμέτρων, από τις οποίες οι έξι πρώτες είναι πάντα:

1. Η διεύθυνση μιας θέσης στη μνήμη όπου πρέπει να αποθηκευτεί η καταγραφή.
2. Το ID του αντικειμένου, ως ανυπόγραφος ακέραιος 64 bit.
3. Η διεύθυνση μιας συμβολοσειράς με την περιγραφή του αντικειμένου.
4. Η μέρα που βρέθηκε το αντικείμενο, ως ανυπόγραφος ακέραιος 64 bit.
5. Ο μήνας που βρέθηκε το αντικείμενο, ως ανυπόγραφος ακέραιος 64 bit.
6. Ο αριθμός των κατηγοριών του αντικειμένου, ως ανυπόγραφος ακέραιος 64 bit.

Κάθε επόμενη παράμετρος είναι η διεύθυνση μιας συμβολοσειράς με μία από τις κατηγορίες.

Οι τιμές πρέπει να αποθηκεύονται στη θέση μνήμης που δίνεται με την ίδια σειρά με τα ορίσματα: ID, περιγραφή, μέρα, μήνας, αριθμός κατηγοριών και κάθε κατηγορία με τη σειρά της.

## 2. Δέσμευσε χώρο για μια μηνιαία λίστα αντικειμένων

Είναι δυσκίνητο να ψάχνεις αντικείμενα σε τόσες πολλές διαφορετικές λίστες.
Έτσι, αποφασίζεις να οργανώσεις τα πάντα σε μία μόνο λίστα για κάθε μήνα.
Αυτή η λίστα υλοποιείται ως πίνακας.

Όρισε τη συνάρτηση `create_monthly_list` που δεσμεύει χώρο στη μνήμη για έναν πίνακα και επιστρέφει τη διεύθυνση αυτής της θέσης μνήμης.
Παίρνει ως παραμέτρους:

1. Τη χωρητικότητα του πίνακα σε byte, ως ανυπόγραφο ακέραιο 64 bit.
2. Μια συνάρτηση δέσμευσης.

Η συνάρτηση δέσμευσης παίρνει ως παράμετρο έναν ανυπόγραφο ακέραιο 64 bit που αντιστοιχεί στο μέγεθος της μνήμης προς δέσμευση, σε byte, και επιστρέφει τη διεύθυνση του δεσμευμένου χώρου.

Σημείωσε ότι ο δεσμευμένος χώρος έχει _απροσδιόριστη_ τιμή, οπότε όλα τα byte σε αυτόν τον χώρο πρέπει να καθαριστούν, δηλαδή η τιμή τους πρέπει να οριστεί σε `0`.

## 3. Εισάγαγε ένα αντικείμενο στη μηνιαία λίστα

Κάθε μέρα, κάθε αντικείμενο που βρίσκεται πρέπει να εισάγεται στη μηνιαία λίστα.

Όρισε τη συνάρτηση `insert_found_item` που δεν έχει τιμή επιστροφής και παίρνει ως παραμέτρους:

1. Τη διεύθυνση μιας θέσης στη μνήμη όπου βρίσκεται η μηνιαία λίστα.
2. Τον τρέχοντα αριθμό καταγραφών που είναι ήδη αποθηκευμένες στη λίστα, ως ανυπόγραφο ακέραιο 64 bit.
3. Μια νέα καταγραφή που θα προστεθεί στη λίστα.

Μπορείς να θεωρήσεις ότι η νέα καταγραφή χωράει πάντα στη λίστα και ότι κάθε καταγραφή στη λίστα καταλαμβάνει 120 byte χώρου.

## 4. Εκτύπωσε ένα αντικείμενο

Η αναζήτηση μιας συγκεκριμένης καταγραφής θα ήταν πολύ πιο εύκολη αν η Leticia μπορούσε να τη δει τυπωμένη στην οθόνη.

Όρισε τη συνάρτηση `print_item` που παίρνει ως παραμέτρους:

1. Τη διεύθυνση ενός buffer όπου μπορεί να αποθηκευτεί μια εισαγωγική συμβολοσειρά ASCII τερματιζόμενη με NUL.
2. Τη διεύθυνση μιας θέσης στη μνήμη όπου βρίσκεται η μηνιαία λίστα.
3. Τη θέση της καταγραφής στον πίνακα για το αντικείμενο που πρέπει να εκτυπωθεί, ως ανυπόγραφο ακέραιο 64 bit.
4. Μια συνάρτηση εκτύπωσης.

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής και πρέπει να καλέσει τη συνάρτηση εκτύπωσης με τα ακόλουθα ορίσματα:

1. Τη διεύθυνση μιας θέσης μνήμης όπου είναι αποθηκευμένη η εισαγωγική συμβολοσειρά, ή `0` (ως ακέραιο 64 bit) αν δεν έχει περαστεί καμία συμβολοσειρά.
2. Τη θέση της καταγραφής στον πίνακα για το αντικείμενο που πρέπει να εκτυπωθεί, ως ανυπόγραφο ακέραιο 64 bit.
3. Το ID του αντικειμένου, ως ανυπόγραφο ακέραιο 64 bit.
4. Τη διεύθυνση μιας συμβολοσειράς με την περιγραφή του αντικειμένου.
5. Τη μέρα που βρέθηκε το αντικείμενο, ως ανυπόγραφο ακέραιο 64 bit.
6. Τον μήνα που βρέθηκε το αντικείμενο, ως ανυπόγραφο ακέραιο 64 bit.
7. Τον αριθμό των κατηγοριών του αντικειμένου, ως ανυπόγραφο ακέραιο 64 bit.
8. Τη διεύθυνση της συμβολοσειράς της πρώτης κατηγορίας.

Η εισαγωγική συμβολοσειρά είναι προαιρετική.
Αν χρησιμοποιηθεί στη συνάρτηση εκτύπωσης, αυτή η συμβολοσειρά πρέπει να τερματίζεται με NUL (να τελειώνει σε `0`) και να έχει το πολύ 50 χαρακτήρες, συνυπολογίζοντας ήδη τον τερματισμό NUL.
Διαφορετικά, πρέπει να περαστεί στη συνάρτηση εκτύπωσης η τιμή `0`.

Μπορείς να θεωρήσεις ότι κάθε αντικείμενο στη λίστα καταλαμβάνει 120 byte χώρου.
