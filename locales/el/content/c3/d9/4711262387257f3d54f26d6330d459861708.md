# Πίνακες

Ένας **πίνακας** κρατά μια σειρά από τιμές, όλες του ίδιου τύπου, με σειρά.

Ο τύπος γράφεται `ARRAY{T}`, όπου `T` είναι αυτό που περιέχει. Ένας πίνακας από
συμβολοσειρές είναι `ARRAY{STR}`; ένας πίνακας από ακέραιους αριθμούς είναι `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Οι τιμές ανάμεσα στα δύο σημάδια `|` είναι το **κυριολεκτικό του πίνακα**. Ο Sather
υπολογίζει το μέγεθος από το πόσες είναι.

## Πώς βγάζεις μια τιμή

Οι αγκύλες περιέχουν τη θέση:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

Η μέτρηση ξεκινά από το **μηδέν**, όχι από το ένα. Έτσι, η πρώτη τιμή βρίσκεται στη
θέση `0` και η τελευταία σε μια σειρά τριών βρίσκεται στη θέση `2`.

## Πόσες είναι;

Το `.size` δείχνει πόσες τιμές περιέχει ο πίνακας.

```sather
row.size    -- 3
```

Επειδή η μέτρηση ξεκινά από το μηδέν, η τελευταία θέση είναι πάντα `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Το να ζητάς μια θέση που δεν υπάρχει, όπως `row[3]` ή `row[-1]`, είναι ένα λάθος που
ο Sather δε θα εντοπίσει για σένα, οπότε αξίζει να γράφεις `.size - 1` αντί να μετράς
τις τιμές με το μάτι.

## Πώς διατρέχεις έναν πίνακα

Ο πίνακας και ο βρόχος πάνε μαζί. Μέτρα μια μεταβλητή προς τα πάνω μέσα από τις θέσεις
και χρησιμοποίησέ τη για να φτάσεις σε κάθε τιμή:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
