# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που αφιερώνεται στο μαγείρεμα της λαζάνιας.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη σταθερά `EXPECTED_MINUTES_IN_OVEN` στην κλάση `Lasagna`, που αποθηκεύει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```Crystal
Lasagna::EXPECTED_MINUTES_IN_OVEN
# => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

Όρισε τη μέθοδο `Lasagna#remaining_minutes_in_oven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που η λαζάνια βρίσκεται στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```Crystal
Lasagna.new.remaining_minutes_in_oven(30)
# => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna#preparation_time_in_minutes`, που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει τον αριθμό των λεπτών που αφιέρωσες για να την προετοιμάσεις, υποθέτοντας ότι κάθε στρώση θέλει 2 λεπτά για να προετοιμαστεί.

```Crystal
Lasagna.new.preparation_time_in_minutes(2)
# => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna#total_time_in_minutes` που παίρνει δύο ονομαστικές παραμέτρους: η παράμετρος `number_of_layers` είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και η παράμετρος `actual_minutes_in_oven` είναι ο αριθμός των λεπτών που η λαζάνια βρίσκεται στον φούρνο.
Η μέθοδος πρέπει να επιστρέφει τον συνολικό αριθμό λεπτών που έχεις δουλέψει για το μαγείρεμα της λαζάνιας, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου που έχει περάσει μέχρι στιγμής η λαζάνια στον φούρνο.

```Crystal
number_of_layers = 3
actual_minutes_in_oven = 20
Lasagna.new.total_time_in_minutes(number_of_layers, actual_minutes_in_oven)
# => 26
```
