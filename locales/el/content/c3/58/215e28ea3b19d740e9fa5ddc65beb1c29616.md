# Τεστ

## Εκτέλεση των τεστ

1. Κατέβασε μια άσκηση:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Πήγαινε στον φάκελο της άσκησης:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Τρέξε τα τεστ:

    ```bash
    $ ./gradlew test
    ```

Στις περισσότερες ασκήσεις, από προεπιλογή εκτελείται μόνο το πρώτο τεστ.  
Τα υπόλοιπα τεστ είναι επισημασμένα με `@Ignore` για να παραλείπονται.  
Καθώς λύνεις κάθε τεστ, αφαίρεσε το `@Ignore` από το επόμενο για να προχωρήσεις.

Αυτή είναι η συνηθισμένη πρακτική στην ανάπτυξη καθοδηγούμενη από τεστ (ή TDD, για συντομία).
Χρησιμοποιείται για να διασφαλίζει ότι δουλεύεις σε ένα πρόβλημα τη φορά.
