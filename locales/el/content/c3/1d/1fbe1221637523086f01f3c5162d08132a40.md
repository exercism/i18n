# Εισαγωγή

Η κλάση Lambda είναι μια συλλογή από συναρτησιακές μεθόδους, με σκοπό να χρησιμοποιήσουμε προγραμματισμό συναρτησιακού στυλ στη Haxe. Μας επιτρέπει να επεξεργαστούμε ένα ολόκληρο Iterable με μία φορά. Αυτό είναι συχνά προτιμότερο από ρουτίνες επανάληψης, καθώς είναι λιγότερο επιρρεπές σε σφάλματα και πιο ευανάγνωστο. Για ευκολία, οι κλάσεις Array και List περιέχουν μερικές από τις πιο συχνά χρησιμοποιούμενες μεθόδους της κλάσης Lambda.

Μερικές από τις συναρτήσεις της κλάσης `Lambda` είναι οι εξής:

- `Lambda.array`, `Lambda.list` Μετατρέπουν ένα Iterable σε Array ή List. Επιστρέφουν πάντα ένα νέο στιγμιότυπο.
- `Lambda.count` Μετρούν τον αριθμό των στοιχείων. Αν το Iterable είναι Array ή List, είναι πιο γρήγορο να χρησιμοποιήσεις την ιδιότητα length.
- `Lambda.has` Καθορίζει αν το συγκεκριμένο στοιχείο βρίσκεται μέσα στο Iterable.
- `Lambda.indexOf` Βρίσκει τη θέση του συγκεκριμένου στοιχείου.
- `Lambda.find` Βρίσκει το πρώτο στοιχείο της δεδομένης συνάρτησης αναζήτησης.
- `Lambda.concat` Συνενώνει δύο Iterables και επιστρέφει μια νέα List.
- `Lambda.filter` Βρίσκει τα στοιχεία που ικανοποιούν ένα κριτήριο και επιστρέφει μια νέα List.

Ένα παράδειγμα που δείχνει μερικές συναρτήσεις:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
