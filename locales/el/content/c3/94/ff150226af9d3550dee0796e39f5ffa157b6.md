# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις [τελεστές boolean][boolean-operators] για να δουλεύεις με βαθμωτές τιμές boolean.
- Πολλοί τελεστές μπορούν να συνδυαστούν σε μία μόνο έκφραση.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

- Ο λογικός τελεστής NOT (`!`) μπορεί να μπει πριν από μια έκφραση για να αντιστρέψει την τιμή της.

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

- Οι τελεστές boolean χρησιμοποιούνται συνήθως για να ελέγξεις αν δύο ή περισσότερες εκφράσεις είναι `TRUE` ή όχι`!`

## 3. Έλεγξε αν μπορεί να δοθεί σήμα στον κρατούμενο

- Οι τελεστές boolean εκτελούνται με σειρά προτεραιότητας (από την υψηλότερη στη χαμηλότερη): `!`, `&&`, `||`.
- Γενικά, η χρήση παρενθέσεων ενθαρρύνεται, ώστε να γίνεται πιο σαφής η πρόθεσή σου.

## 4. Έλεγξε αν μπορεί να ελευθερωθεί ο κρατούμενος

- Οι τελεστές boolean εκτελούνται με σειρά προτεραιότητας (από την υψηλότερη στη χαμηλότερη): `!`, `&&`, `||`.
- Γενικά, η χρήση παρενθέσεων ενθαρρύνεται, ώστε να γίνεται πιο σαφής η πρόθεσή σου.
