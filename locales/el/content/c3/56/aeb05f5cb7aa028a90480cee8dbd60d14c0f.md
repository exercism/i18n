# Δοκιμές

## Σύντομα

- Πήγαινε στον κατάλογο της άσκησης (π.χ. `~/Exercism/hello-world`).
- Ξεκίνα μια συνεδρία `jconsole` σε ένα τερματικό.
- Φόρτωσε το αρχείο της λύσης σου (π.χ. `load 'hello-world.ijs'`).
- Φόρτωσε το πλαίσιο δοκιμών μονάδας πληκτρολογώντας `load  'general/unittest'`.
- Δοκίμασε τη λύση σου πληκτρολογώντας `unittest 'test.ijs'`.
<br></br>
- Εναλλακτικά, μπορείς να τρέξεις τις δοκιμές με μία μόνο γραμμή, κάπως έτσι: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Συνεδρία jconsole

Ο τρόπος με τον οποίο έχουν στηθεί οι δοκιμές της διαδρομής ελπίζουμε να είναι όσο το δυνατόν πιο απλός.
Αν δουλεύεις μια άσκηση, ας πούμε την `hamming.ijs`, να πώς πρέπει να κυλήσει η δουλειά.
Επεξεργάσου το `hamming.ijs` γράφοντας τη λύση σου.
Χτίσε τη σταδιακά και διαδραστικά, πληκτρολογώντας πρώτα το εξής.

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Έπειτα, μέσα από την κονσόλα J, ξαναφόρτωσε πληκτρολογώντας

```j
load 'hamming.ijs'
```

Το επόμενο βήμα είναι να φορτώσεις το πλαίσιο δοκιμών μονάδας πληκτρολογώντας

```j
load 'general/unittest'
```

Για να τρέξεις τις δοκιμές, αφού έχεις φορτώσει τη λύση σου, πληκτρολόγησε

```j
unittest 'test.ijs'
```

Και μετά παρατήρησε τα αποτελέσματα.

## Γραμμή εντολών

Μπορείς να τρέξεις τις δοκιμές με μία εντολή σε μία μόνο γραμμή στο τερματικό, χρησιμοποιώντας τη σημαία -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
όπου κάθε όρισμα αντιπροσωπεύει μια εντολή που θα εκτελεστεί διαδοχικά.
