# Σχετικά

Πολλοί τελεστές μπορούν επίσης να χρησιμοποιηθούν ως [σύνθετες αναθέσεις][compound-assignment], που αποτελούν μια συντομευμένη σημειογραφία όπου το `x = op y` μπορεί να γραφτεί ως `x op= y`:

```csharp
var features = PhoneFeatures.Call;
features |= PhoneFeatures.Text;
features &= ~PhoneFeatures.Call;
```
