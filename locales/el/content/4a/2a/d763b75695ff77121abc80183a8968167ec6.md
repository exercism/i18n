# Οδηγίες

Έχεις προσληφθεί ως Ειδικός Κανονικών Εκφράσεων σε μια εταιρεία που αναπτύσσει ένα Chatbot.

Βρίσκεται σε ένα πολύ αρχικό στάδιο ανάπτυξης.
Η αποστολή σου είναι να χρησιμοποιήσεις Κανονικές Εκφράσεις για να βελτιώσεις την ικανότητα του Chatbot να κατανοεί και να παράγει φυσική γλώσσα.

## 1. Έλεγξε αν η εντολή είναι έγκυρη

Πέρα από έξυπνο, το Chatbot είναι και πιστός βοηθός.
Για να ζητήσει κάποιος κάτι από το Chatbot, πρέπει να πει τη λέξη "**Chatbot**" στην πρώτη θέση της εντολής.
Δεν έχει σημασία αν η λέξη-κλειδί είναι γραμμένη με ΚΕΦΑΛΑΙΑ ή με πεζά.
Το σημαντικό είναι η θέση της λέξης.

Υλοποίησε τη συνάρτηση `is_valid_command` που βοηθά το Chatbot να αναγνωρίζει πότε ο χρήστης δίνει μια εντολή.

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. Αφαίρεσε τα κρυπτογραφημένα emoji

Το Chatbot δυσκολεύεται να καταλάβει πώς οι άνθρωποι χρησιμοποιούν τα emoji για να εκφράσουν τα συναισθήματά τους.
Όταν το Chatbot λαμβάνει μηνύματα από χρήστες, κάθε emoji αναπαρίσταται ως η συμβολοσειρά "emoji" ακολουθούμενη από έναν _αριθμό id_.

Υλοποίησε τη μέθοδο `remove_emoji` που παίρνει μια συμβολοσειρά και αφαιρεί όλα τα emoji από το μήνυμα.

Οι γραμμές που δεν περιέχουν emoji θα πρέπει να επιστρέφονται αμετάβλητες.
Απλώς αφαίρεσε τη συμβολοσειρά "emoji".
Μην πειράξεις τα κενά.

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. Έλεγξε αν ο αριθμός τηλεφώνου είναι έγκυρος

Κάποια στιγμή στην αλληλεπίδραση με το Chatbot, ο χρήστης θα δώσει έναν αριθμό τηλεφώνου.
Το Chatbot μπορεί να καλέσει μόνο αριθμούς με συγκεκριμένη μορφή.

Υλοποίησε τη συνάρτηση `check_phone_number`.

Αν ο αριθμός είναι έγκυρος, το Chatbot απαντά με ένα μήνυμα που ευχαριστεί τον χρήστη και επιβεβαιώνει τον αριθμό.
Αν ο αριθμός δεν είναι έγκυρος, το Chatbot ενημερώνει τον χρήστη ότι ο αριθμός τηλεφώνου δεν είναι έγκυρος.

Η αναμενόμενη μορφή είναι `(+NN) NNN-NNN-NNN`, όπου το N είναι ένα ψηφίο.

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. Βρες τον σύνδεσμο της ιστοσελίδας

Το Chatbot είναι ένα λογισμικό με μεγάλη περιέργεια.
Παρόλο που μπορεί να ψάξει στο διαδίκτυο για ένα συγκεκριμένο θέμα, του αρέσει να ρωτά τους χρήστες για ωραίες ιστοσελίδες που μπορεί να επισκεφτεί, ώστε να βρει σχετικές πληροφορίες.

Παράδειγμα συνομιλίας:

> **Chatbot**: Γεια σου χρήστη, θα ήθελα να μάθω πώς να προγραμματίζω σε JavaScript. Ξέρεις καμία ωραία ιστοσελίδα όπου θα μπορούσα να μάθω;

> **Χρήστης**: Έμαθα πολλά από το exercism.org, έχει πολύ ωραίο υλικό εκεί.

Υλοποίησε τη συνάρτηση `get_domains` που επιστρέφει έναν πίνακα με domains ιστοσελίδων.

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. Χαιρέτησε τον χρήστη

Ένα ευγενικό Chatbot μιλά στους χρήστες με το όνομά τους.
Όταν ένας χρήστης συστήνεται, το Chatbot μας εντοπίζει το όνομά του και απαντά με έναν φιλικό χαιρετισμό.

Γράψε τη συνάρτηση `nice_to_meet_you`.

Αν η συμβολοσειρά εισόδου περιέχει "My name is Someone.", πιάσε το όνομα και επέστρεψε τη συμβολοσειρά "Nice to meet you, Someone.".

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. Πολύ απλή ανάλυση CSV

Υποκύπτοντας στον πειρασμό να προσθέσουμε κι άλλες λειτουργίες, θα προσθέσουμε στο Chatbot μια συνάρτηση ανάλυσης CSV.

Υλοποίησε τη συνάρτηση `parse_csv` που παίρνει μια συμβολοσειρά και επιστρέφει έναν πίνακα με τα πεδία που προκύπτουν.
Ο διαχωριστής πεδίων θα πρέπει να είναι "κόμμα μαζί με προαιρετικά κενά".

Δεν θα ασχοληθούμε με τις οριακές περιπτώσεις της μορφής CSV (όπως πεδία που περιέχουν κόμματα).

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
