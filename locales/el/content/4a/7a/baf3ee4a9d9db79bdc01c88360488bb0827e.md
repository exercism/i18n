# Εκμάθηση

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά μπορεί να είναι δύσκολο να ξεκινήσεις αν μαθαίνεις Pascal για πρώτη φορά. Οι παρακάτω πόροι μπορούν να σε βοηθήσουν να κάνεις την αρχή:

* Ο [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) φαίνεται καλό σημείο για να κάνεις τα πρώτα σου βήματα στην Pascal, αν δεν έχεις καθόλου εμπειρία με αυτή τη γλώσσα. Δεν χρειάζεσαι Delphi για να ολοκληρώσεις τις ασκήσεις που καλύπτει αυτός ο οδηγός. Ίσως είναι ένα καλό σημείο για εξάσκηση πριν πιάσεις τις ασκήσεις εδώ, οι οποίες όμως απαιτούν Delphi για να ολοκληρωθούν.
* Το [Pascal-Programming.info](http://www.pascal-programming.info/index.php) φαίνεται επίσης να έχει έναν καλό οδηγό για όσους έρχονται πρώτη φορά στη γλώσσα.
* Υπάρχουν πολλές ακόμη πηγές στο διαδίκτυο για την εκμάθηση της Pascal, πάρα πολλές για να τις απαριθμήσουμε εδώ.
