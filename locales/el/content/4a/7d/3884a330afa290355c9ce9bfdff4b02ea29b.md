# Εισαγωγή

Στην Kotlin, οι συναρτήσεις είναι πολίτες πρώτης κατηγορίας.
Αυτό σημαίνει ότι μπορούν να αποθηκευτούν σε μεταβλητές, να περαστούν ως ορίσματα και ακόμη να επιστραφούν από άλλες συναρτήσεις.
Για παράδειγμα, μπορούμε να αναθέσουμε μια συνάρτηση στη μεταβλητή `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Μια συνάρτηση μπορεί επίσης να επιστρέψει μια άλλη συνάρτηση:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Μόλις ανατεθεί, η συνάρτηση μπορεί να κληθεί μέσω της μεταβλητής σαν να ήταν απλώς μια άλλη συνάρτηση:
```kotlin
addOne(3)
// => 4
```

## Δήλωση τύπων συναρτήσεων

Ο τύπος μιας μεταβλητής ή μιας παραμέτρου μπορεί να δηλωθεί με τη σύνταξη `(parameter types) -> return type`.
Για παράδειγμα, δηλώνουμε μια μεταβλητή:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Και για μια παράμετρο συνάρτησης:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Εκφράσεις lambda

Μια έκφραση lambda είναι ένας συντομότερος τρόπος ορισμού μιας συνάρτησης.
Γράφονται στη μορφή `{ parameters -> body }`.
Η έκφραση επιστρέφει την τελευταία τιμή από την τελευταία εντολή στο σώμα.
Για παράδειγμα:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Η Kotlin μπορεί να συμπεράνει τύπους όταν υπάρχουν αρκετές πληροφορίες.
Για παράδειγμα, τα παραπάνω παραδείγματα μπορούν να γραφτούν και ως εξής:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## Το `it` για lambda με μία παράμετρο

Όταν η έκφραση έχει μόνο μία παράμετρο, η παράμετρος μπορεί να παραλειφθεί.
Η Kotlin τότε κάνει διαθέσιμη στο σώμα μια παράμετρο με το όνομα `it`.
Για παράδειγμα:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Πέρασμα trailing lambda

Όταν το τελευταίο όρισμα μιας συνάρτησης είναι μια lambda, η έκφραση lambda γράφεται αμέσως _μετά_ τις παρενθέσεις.
Για παράδειγμα:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
