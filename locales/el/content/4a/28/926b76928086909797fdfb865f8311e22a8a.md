# Υποδείξεις

## Γενικά

- Διάβασε σχετικά με το module `Enum` στον [επίσημο οδηγό Getting Started][getting-started-enum] ή στο [elixirschool.com][elixir-school-enum].
- Ρίξε μια ματιά στην τεκμηρίωση για την πλήρη [λίστα συναρτήσεων του module `Enum`][enum-functions].

## 1. Ταξινόμησε τα προϊόντα κατά τιμή

- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-sort-by] για την ταξινόμηση enumerables με μια συνάρτηση ταξινόμησης.

## 2. Βρες όλα τα προϊόντα χωρίς τιμή

- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-filter] για το φιλτράρισμα enumerables.

## 3. Ενημέρωσε τα ονόματα των προϊόντων

- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-map] για τον μετασχηματισμό κάθε στοιχείου σε ένα enumerable.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-replace] που μπορεί να αντικαταστήσει όλες τις εμφανίσεις μιας συμβολοσειράς με μια άλλη.

## 4. Αύξησε την ποσότητα του προϊόντος

- Τα maps υλοποιούν το πρωτόκολλο enumerable.
- Οι συναρτήσεις του `Enum` μετατρέπουν τα maps σε μια λίστα από tuples `{key, value}`.
- Υπάρχουν δύο διαφορετικές συναρτήσεις που μπορούν να μετατρέψουν ξανά μια λίστα από tuples `{key, value}` σε ένα map, χρησιμοποιώντας μια συνάρτηση μετασχηματισμού. [Η μία επιστρέφει πάντα ένα νέο map][map-new], ενώ [η άλλη σου επιτρέπει να διαλέξεις ένα collectible][enum-into].

## 5. Υπολόγισε τη συνολική ποσότητα του προϊόντος

- Τα maps υλοποιούν το πρωτόκολλο enumerable.
- Οι συναρτήσεις του `Enum` μετατρέπουν τα maps σε μια λίστα από tuples `{key, value}`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-reduce] για την αναγωγή ενός enumerable σε μία μόνο τιμή.
