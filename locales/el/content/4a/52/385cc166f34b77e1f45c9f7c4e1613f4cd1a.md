# Εισαγωγή

## Εισαγωγή μονάδων

Ενώ η Swift περιλαμβάνει πολλή λειτουργικότητα στην Τυπική Βιβλιοθήκη της, υπάρχει ακόμη περισσότερη λειτουργικότητα διαθέσιμη με τη μορφή εξωτερικών βιβλιοθηκών.
Αυτές οι βιβλιοθήκες μπορεί να προέρχονται από το ίδιο το έργο της Swift, όπως ο [Swift Argument Parser][argument-parser], από εταιρείες με βιβλιοθήκες κλειστού κώδικα, όπως το [Network Framework][network-framework] της Apple, ή να είναι βιβλιοθήκες τρίτων, όπως το [Swifty Beaver][swifty-beaver].

Μερικές από αυτές τις μονάδες, όπως το Network Framework ή το [Foundation][apple-foundation] (που είναι ίσως η πιο συχνά χρησιμοποιούμενη βιβλιοθήκη στη Swift), έρχονται μαζί με τη διανομή της Swift.
Οι εξωτερικές βιβλιοθήκες τρίτων πρέπει να προστεθούν στο έργο σου πριν μπορέσεις να τις εισαγάγεις, αν και αυτό ξεφεύγει από το πλαίσιο αυτής της άσκησης.

Η εισαγωγή μονάδων γίνεται γράφοντας τη λέξη-κλειδί `import` ακολουθούμενη από το όνομα της μονάδας. Έτσι, μπορείς να εισαγάγεις το Foundation προσθέτοντας τα παρακάτω στο πρόγραμμά σου.

```swift
import Foundation
```

Αυτό δίνει πρόσβαση σε όλους τους τύπους, τις τιμές και τη λειτουργικότητα μέσα σε αυτή τη μονάδα· για παράδειγμα, αν θέλεις να χρησιμοποιήσεις τη μέθοδο `components(separatedBy:)` του String, αυτή η μέθοδος γίνεται διαθέσιμη στο `String` με αυτή την εισαγωγή.

Αν και μπορούν να τοποθετηθούν στον κώδικα οπουδήποτε πριν από ένα κομμάτι κώδικα που χρησιμοποιεί κάτι από το περιεχόμενο της μονάδας, οι εντολές εισαγωγής συνήθως τοποθετούνται στην αρχή του αρχείου που τις χρησιμοποιεί, για μεγαλύτερη αναγνωσιμότητα.

## Θέσεις σε συμβολοσειρές

Μπορείς να προσπελάσεις μεμονωμένους χαρακτήρες σε ένα `String` χρησιμοποιώντας τον ίδιο τρόπο πρόσβασης με θέση που χρησιμοποιείς και με τους πίνακες.
Ωστόσο, οι [θέσεις][string-indices] που χρησιμοποιούνται για τις συμβολοσειρές _δεν_ είναι ακέραιοι αριθμοί και δεν μπορείς να δουλέψεις απευθείας μαζί τους.
Αντ' αυτού, πρέπει να υπολογιστούν με βάση κάποια άλλη γνωστή θέση, όπως το `startIndex`, που δείχνει τη θέση του πρώτου χαρακτήρα σε μια μη κενή συμβολοσειρά, χρησιμοποιώντας τις μεθόδους που είναι διαθέσιμες στις βιβλιοθήκες [`String`][string-docs] και [`NSString`][nsstring-docs] (όταν έχει εισαχθεί η μονάδα `Foundation`, οι συμβολοσειρές στη Swift έχουν πρόσβαση σε όλες τις ιδιότητες και τις μεθόδους της NSString).

Για παράδειγμα, δεδομένης της παρακάτω συμβολοσειράς:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

Δεν μπορείς να γράψεις `csv[21]` για να πάρεις το "g" στο "orange"· αντ' αυτού, πρέπει να υπολογίσεις μια τιμή τύπου `String.Index` και να δώσεις αυτή τη θέση.
Σημείωσε ότι αυτές οι θέσεις δεν προορίζονται να είναι κατανοητές από τον άνθρωπο από μόνες τους.
Είναι αυτό που ονομάζεται _αδιαφανείς θέσεις_, καθώς οι άνθρωποι δεν χρειάζεται να ξέρουν τι υπάρχει μέσα τους.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Σημείωσε, ωστόσο, ότι αν το offset δεν είναι έγκυρη θέση, δηλαδή αν επιστρέφει τη θέση πριν από το `startIndex` ή μετά το `endIndex`, η λειτουργία θα πετάξει ένα σφάλμα, τερματίζοντας το πρόγραμμα.
Για να αποτρέψεις αυτό το πρόβλημα, μπορείς να ορίσεις μια οριακή θέση.
Αυτή επιστρέφει μια προαιρετική θέση και θα επιστρέψει nil για θέσεις που κατά τα άλλα είναι μη έγκυρες.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Επιπλέον, οι θέσεις δεν μπορούν να μοιράζονται μεταξύ συμβολοσειρών.
Για παράδειγμα, χρησιμοποιώντας τη θέση `index` του "g" στο "orange" που υπολογίστηκε παραπάνω για να δείξεις μέσα στη συμβολοσειρά `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, δηλαδή `fam[index]`, θα τερματίσει το πρόγραμμά σου.

Υπάρχουν πολλοί λόγοι για όλα αυτά, αλλά όλοι βασικά συνοψίζονται στο ότι "το Unicode είναι μπερδεμένο".

Γενικά μιλώντας, αν χρειάζεσαι τυχαία πρόσβαση σε μεμονωμένους χαρακτήρες, πιθανότατα θέλεις να χρησιμοποιήσεις κάποια άλλη δομή δεδομένων, όπως έναν `Array<Character>`.

### Κάποιες χρήσιμες μέθοδοι

Η Swift έχει τις μεθόδους `first` και `last` για να πάρεις τον πρώτο και τον τελευταίο χαρακτήρα μιας συμβολοσειράς.
Αυτές οι μέθοδοι επιστρέφουν έναν προαιρετικό χαρακτήρα, οπότε αν η συμβολοσειρά είναι κενή, θα επιστρέψουν nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

Μπορείς επίσης να χρησιμοποιήσεις τις μεθόδους `prefix` και `suffix` για να πάρεις μια υποσυμβολοσειρά.
Αυτές οι μέθοδοι δέχονται έναν ακέραιο ως όρισμα και επιστρέφουν μια υποσυμβολοσειρά που περιέχει τους πρώτους ή τους τελευταίους n χαρακτήρες της συμβολοσειράς.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Μέθοδοι συμβολοσειρών

Το να δουλεύεις με συμβολοσειρές είναι κάτι συνηθισμένο στον προγραμματισμό.
Γι' αυτό η Swift παρέχει μια ποικιλία μεθόδων για τον χειρισμό συμβολοσειρών.
Αυτό το έγγραφο θα καλύψει μερικές από τις πιο συνηθισμένες μεθόδους και ιδιότητες συμβολοσειρών· μερικές από αυτές απαιτούν την εισαγωγή του framework Foundation.

### [`components(separatedBy:)`][components]

Όταν θέλεις να χωρίσεις μια συμβολοσειρά σε έναν πίνακα υποσυμβολοσειρών, μπορείς να χρησιμοποιήσεις τη μέθοδο `components(separatedBy:)`.
Έτσι, αν θέλεις να πάρεις κάθε λέξη σε μια πρόταση, μπορείς να χρησιμοποιήσεις τον χαρακτήρα του κενού ως διαχωριστικό.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

### [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Όταν θέλεις να ελέγξεις αν μια συμβολοσειρά αρχίζει ή τελειώνει με μια συγκεκριμένη υποσυμβολοσειρά, μπορείς να χρησιμοποιήσεις τις μεθόδους `hasPrefix(_:)` και `hasSuffix(_:)`.
Και οι δύο δέχονται μια συμβολοσειρά ως όρισμα και επιστρέφουν μια λογική τιμή που δείχνει αν η συμβολοσειρά αρχίζει ή τελειώνει με τη συγκεκριμένη υποσυμβολοσειρά.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

### [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Όταν θέλεις να αλλάξεις τα πεζά/κεφαλαία σε μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τις ιδιότητες `lowercased`, `uppercased` και `capitalized`.
Η ιδιότητα `lowercased` επιστρέφει μια νέα συμβολοσειρά με όλους τους χαρακτήρες πεζούς, η ιδιότητα `uppercased` επιστρέφει μια νέα συμβολοσειρά με όλους τους χαρακτήρες κεφαλαίους, και η ιδιότητα `capitalized` επιστρέφει μια νέα συμβολοσειρά με τον πρώτο χαρακτήρα κάθε λέξης κεφαλαίο.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

### [`replacingOccurrences(of:with:)`][replacingOccurrences]

Όταν θέλεις να αντικαταστήσεις όλες τις εμφανίσεις μιας υποσυμβολοσειράς μέσα σε μια συμβολοσειρά με μια άλλη υποσυμβολοσειρά, μπορείς να χρησιμοποιήσεις τη μέθοδο `replacingOccurrences(of:with:)`.
Αυτή η μέθοδος δέχεται δύο συμβολοσειρές ως ορίσματα: την υποσυμβολοσειρά που θα αντικατασταθεί και την υποσυμβολοσειρά με την οποία θα αντικατασταθεί. Επιστρέφει μια νέα συμβολοσειρά με όλες τις εμφανίσεις της συγκεκριμένης υποσυμβολοσειράς αντικατεστημένες.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

### [`joined(separator:)`][joined]

Αυτή δεν είναι μέθοδος του τύπου String, αλλά του τύπου Array.
Όταν θέλεις να ενώσεις έναν πίνακα συμβολοσειρών σε μία μόνο συμβολοσειρά με έναν συγκεκριμένο διαχωριστικό, μπορείς να χρησιμοποιήσεις τη μέθοδο `joined(separator:)`.
Αυτή η μέθοδος δέχεται μια συμβολοσειρά ως όρισμα και επιστρέφει μια νέα συμβολοσειρά με όλα τα στοιχεία του πίνακα ενωμένα μεταξύ τους, χωρισμένα με τη συγκεκριμένη συμβολοσειρά.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
