# Σχετικά

Μπορεί να είναι δύσκολο να βρεις μια γλώσσα προγραμματισμού που να είναι πιο εκφραστική. Η [Raku](https://raku.org/) είναι μια σύγχρονη, πολυπαραδειγματική γλώσσα. Η Raku προσφέρει μεθοδολογίες [προστακτικού](https://docs.raku.org/language/functions), [αντικειμενοστρεφούς](https://docs.raku.org/language/objects) και [συναρτησιακού προγραμματισμού](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[Από περιέργεια;](https://raku.org/) Ψάξε βαθύτερα στην [τεκμηρίωση](https://docs.raku.org/) ή στο [αποθετήριο](https://raku.land/) με τα module (σαν το pypi ή το CPAN).

Είναι μια εξαιρετικά [ευέλικτη](https://docs.raku.org/language/operators) γλώσσα, που [προσαρμόζεται](https://docs.raku.org/language/glossary#gradual_typing) στο στυλ προγραμματισμού σου, είτε πρόκειται για γρήγορα [one-liners](https://docs.raku.org/language/create-cli) για sysadmins, είτε για σενάρια που διαχειρίζονται την εισαγωγή δεδομένων σε μια βάση, είτε για ολόκληρο το φάσμα των module που χρειάζονται για να υλοποιήσεις μια [ολόκληρη ιστοσελίδα](https://cro.services/).

Η Raku μαθαίνει από άλλες γλώσσες:

* Ενισχύει τη μακροπρόθεσμη απήχηση της Perl με ένα σωστό σύστημα αντικειμένων, που περιλαμβάνει [ρόλους](https://docs.raku.org/language/typesystem#role), [νηματοποίηση](https://docs.raku.org/language/concurrency) και [αποστολή πολλαπλών μεθόδων](https://docs.raku.org/language/glossary#Multi-dispatch).
* Παίρνει τη νηματοποίηση από τη Java, [απλοποιημένη](https://docs.raku.org/language/concurrency) σε μια χούφτα μεθόδους.
* Η χρήση [διεπαφών ξένων συναρτήσεων](https://docs.raku.org/language/nativecall) από τη Lisp κάνει την πρόσβαση σε βιβλιοθήκες τόσο απλή όσο μία γραμμή κώδικα.
* Οι [κανονικές εκφράσεις](https://docs.raku.org/language/regexes) έχουν φτάσει πλέον στο 11, με την εισαγωγή των [γραμματικών](https://docs.raku.org/language/grammars) Parser Expression, που σου επιτρέπουν να χειριστείς τεράστια έργα ανάλυσης.
* Τα strictures και οι προειδοποιήσεις είναι πλέον αυτόματα, εξαλείφοντας τεράστιες περιοχές πιθανών σφαλμάτων.
* ... και ξέρει να κάνει [μαθηματικά](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ``` Δοκίμασέ το στην αγαπημένη σου γλώσσα!

Τα ρητά της Raku:
* "Η Raku είναι σχεδιασμένη να κάνει τις εύκολες δουλειές εύκολες, χωρίς να κάνει τις δύσκολες δουλειές αδύνατες."
* "Υπάρχουν πάνω από ένας τρόποι να το κάνεις. Τώρα μάλιστα με ακόμα περισσότερο -Ofun (βελτιστοποιημένο για διασκέδαση)."
