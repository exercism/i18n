# Μάθηση

Ενδιαφέρεσαι να ξεκινήσεις με τη Groovy ή να μάθεις περισσότερα όσο δουλεύεις πάνω στις ασκήσεις;

Δοκίμασε τη Groovy με

* [έναν περιηγητή που χρησιμοποιεί διαδικτυακό διερμηνευτή](https://www.jdoodle.com/execute-groovy-online)
* [το Groovy Console](http://groovy-lang.org/groovyconsole.html), πληκτρολογώντας `groovyConsole` στη γραμμή εντολών
* [το Groovy Shell](http://groovy-lang.org/groovyconsole.html), πληκτρολογώντας `groovysh` στη γραμμή εντολών

Κάνε μια γρήγορη περιήγηση στη Groovy με

* το [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) του Tim Rows, εξίσου καλό για προγραμματιστές που δεν γράφουν Java
* το [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* το [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) της SmartThings
* μερικά από τα [online Groovy Koans](http://www.groovy-koans.org/) της JDriven

Εμβάθυνε περισσότερο με

* την [Groovy Documentation](http://www.groovy-lang.org/documentation.html)
* το [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _το Βιβλίο_ για τη Groovy
* το [Making Java Groovy](https://www.manning.com/books/making-java-groovy) του Ken Kousen
