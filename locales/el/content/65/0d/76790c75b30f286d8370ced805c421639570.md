# Σχετικά

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] χρησιμοποιούνται για να συγκρίνουν τιμές και να επιστρέφουν μια τιμή `true` ή `false`.
Αυτοί οι τελεστές απαιτούν 2 τιμές προς σύγκριση του ίδιου τύπου.
Αν οι τιμές δεν είναι του ίδιου τύπου, τότε ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Ακολουθεί μια λίστα με τους τελεστές σύγκρισης και ένα παράδειγμα όπου δίνουν την τιμή `true`:

| Τελεστής | Περιγραφή           | Παράδειγμα |
| ------ | --------------------- | ------- |
| ==     | ίσο                 | 1 == 1  |
| !=     | όχι ίσο             | 1 != 2  |
| <      | μικρότερο από             | 4 < 5   |
| <=     | μικρότερο ή ίσο    | 4 <= 4  |
| >      | μεγαλύτερο από          | 3 > 1   |
| >=     | μεγαλύτερο ή ίσο | 2 >= 2  |

## Εντολές `if` και `else`

Μια [εντολή υπό συνθήκη][conditional-statement] σου επιτρέπει να εκτελέσεις κώδικα με βάση μια συνθήκη που είναι είτε `true` είτε `false`.
Η πιο απλή εντολή υπό συνθήκη είναι η [εντολή `if`][if], η οποία εκτελεί κώδικα όταν η συνθήκη είναι `true`.
Για να ορίσεις μια εντολή `if`, χρησιμοποιείς τη λέξη-κλειδί `if` ακολουθούμενη από τη συνθήκη και έπειτα τον κώδικα προς εκτέλεση μέσα σε άγκιστρα.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Η εντολή `if` μπορεί να συνδυαστεί με το `else`, ώστε να εκτελεστεί κώδικας όταν η συνθήκη είναι `false`.
Η εντολή `else` πρέπει να χρησιμοποιείται μαζί με μια εντολή `if` και δεν μπορεί να σταθεί μόνη της.
Για να ορίσεις μια εντολή `else`, χρησιμοποιείς τη λέξη-κλειδί `else` μετά τα άγκιστρα της εντολής `if` και έπειτα τον κώδικα προς εκτέλεση μέσα σε άγκιστρα.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Οι εντολές `if` μπορούν επίσης να αλυσιδωθούν μεταξύ τους με το `else if`, για να ελέγχουν πολλαπλές συνθήκες.
Ακολουθεί την ίδια λογική με τον ορισμό μιας εντολής `if`, μόνο που η λέξη-κλειδί είναι `else if` αντί για `if`.
Οι εντολές `if` δεν χρειάζονται απαραίτητα μια εντολή `else` για να είναι έγκυρες, αλλά μπορούν να έχουν μία αν χρειάζεται.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Έκφραση `if`

Οι εντολές `if` μπορούν επίσης να χρησιμοποιηθούν ως εκφράσεις, για να αναθέσεις μια τιμή σε μια μεταβλητή.
Η τελευταία εντολή μέσα στο μπλοκ της `if` χρησιμοποιείται ως η τιμή της έκφρασης `if`.
Αυτό είναι χρήσιμο όταν θέλεις να αναθέσεις μια τιμή σε μια μεταβλητή με βάση μια συνθήκη.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```

## Τριαδικός τελεστής

Ο [τριαδικός τελεστής][ternary-operator] είναι μια σύντομη μορφή της εντολής `if`-`else`.
Παίρνει μια έκφραση Boolean και δύο εκφράσεις χωρισμένες με άνω και κάτω τελεία.
Η πρώτη έκφραση αξιολογείται αν η έκφραση Boolean είναι αληθής, διαφορετικά αξιολογείται η δεύτερη.
Έχει την εξής μορφή: `Boolean-expression ? expression1 : expression2`.

Ο τριαδικός τελεστής είναι ιδανικός όταν θέλεις μια σύντομη μορφή της εντολής `if`-`else` και οι εκφράσεις είναι σύντομες:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Το παραπάνω παράδειγμα είναι συντομογραφία για τον παρακάτω κώδικα:
    
```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
