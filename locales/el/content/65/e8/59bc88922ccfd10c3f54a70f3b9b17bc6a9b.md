# Εισαγωγή

Οι κλάσεις είναι το βασικό δομικό στοιχείο για αντικειμενοστρεφή προγραμματισμό στη F#.

Μια κλάση στη F# αποτελείται από τα πεδία και τις μεθόδους της. Τα πεδία και οι μέθοδοι μιας κλάσης είναι γνωστά ως τα _μέλη_ της.

Οι κλάσεις στη F# ορίζονται με τη λέξη-κλειδί `type`. Οι μέθοδοι ορίζονται με τη λέξη-κλειδί `member` και είναι πάντα public. Για να ορίσεις (private) πεδία, μπορείς να χρησιμοποιήσεις δεσμεύσεις `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Οι κλάσεις είναι πρότυπα με τα οποία δημιουργείς αντικείμενα. Για να δημιουργήσεις ένα στιγμιότυπο μιας κλάσης, κάλεσε το όνομα της κλάσης σαν συνάρτηση. Ένα στιγμιότυπο μιας κλάσης είναι επίσης γνωστό ως _αντικείμενο_.

Μπορείς να έχεις πρόσβαση στα μέλη ενός αντικειμένου χρησιμοποιώντας τη σημειογραφία με τελεία.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
