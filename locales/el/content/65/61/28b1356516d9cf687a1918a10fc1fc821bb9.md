# μετατροπή πεδίου σε const

Σκέψου να μετατρέψεις το πεδίο `%{name}` σε `const`, καθώς η τιμή δεν προορίζεται να αλλάξει ποτέ. Η χρήση σταθερών δεν είναι μόνο πιο συνηθισμένη, αλλά υπάρχουν και κάποιες λεπτές διαφορές ανάμεσα σε `const` και `field`, που εξηγούνται σε [αυτή την ανάρτηση στο StackOverflow](https://stackoverflow.com/questions/755685/static-readonly-vs-const#755693).
