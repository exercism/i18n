# Προσάρτημα οδηγιών

## Υλοποίηση

Όρισε δύο συναρτήσεις: (Δύο; Ναι, μερικές φορές ζητάμε κάτι παραπάνω από τη Go.)

Η All επιστρέφει μια λίστα με όλες τις υποσυμβολοσειρές του s μήκους n.

`All(n int, s string) []string`

Η UnsafeFirst επιστρέφει την πρώτη υποσυμβολοσειρά του s μήκους n.

`UnsafeFirst(n int, s string) string`

Σε αυτό το σημείο θα μπορούσες να θεωρήσεις την άσκηση ολοκληρωμένη και να προχωρήσεις παρακάτω.

Μα περίμενε, ίσως κάνεις μια εύλογη ερώτηση: Γιατί η συνάρτηση ονομάζεται **Unsafe** First; Αν σε ενδιαφέρει, διάβασε παρακάτω για μια επιπλέον άσκηση.

## Επιπλέον άσκηση

Μόλις καταφέρεις να περνάει το `go test`, δοκίμασε το `go test -tags asktoomuch`.
Αυτό χρησιμοποιεί ένα _build tag_ για να ενεργοποιήσει ένα τεστ που δεν ήταν ενεργοποιημένο πριν.
Τα build tags επιτρέπουν την επιλογή των αρχείων που θα χρησιμοποιήσει το πακέτο.
Στη δική μας περίπτωση, θα καθορίζει ποια αρχεία τεστ θα χρησιμοποιηθούν.
Μπορείς να διαβάσεις περισσότερα γι' αυτά στην [τεκμηρίωση της Go](https://golang.org/pkg/go/build/#hdr-Build_Constraints).

Ίσως παρατηρήσεις ότι δεν μπορείς να ικανοποιήσεις αυτό το τεστ _asktoomuch_.
Χρειαζόμαστε έναν τρόπο να δείξουμε ότι σε ορισμένες περιπτώσεις δεν μπορείς να πάρεις τους πρώτους N χαρακτήρες της συμβολοσειράς.
Η UnsafeFirst δεν μπορεί να το κάνει αυτό, αφού επιστρέφει μόνο μια συμβολοσειρά.

Για να το διορθώσουμε, ας προσθέσουμε άλλη μια τιμή επιστροφής στη συνάρτηση.
Όρισε τη `First(int, string) (first string, ok bool)` και δοκίμασε με `go test -tags first`.

Το δεύτερο όρισμα επιστροφής `ok bool` είναι ένα συνηθισμένο και ιδιωματικό μοτίβο στη Go.
Για παράδειγμα, το βλέπεις στις [αναζητήσεις σε Map](https://blog.golang.org/go-maps-in-action) και στους [ισχυρισμούς τύπου](https://tour.golang.org/methods/15).
