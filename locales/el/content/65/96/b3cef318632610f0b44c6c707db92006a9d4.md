# Εισαγωγή

Ένας ορισμός με `:` μπορεί να καλέσει τον εαυτό του απευθείας. Ο μεταγλωττιστής της Factor συμπεραίνει την επίδραση στη στοίβα των αναδρομικών λέξεων όπως ακριβώς για κάθε άλλη. Δε χρειάζεται ειδική δήλωση για την απλή αναδρομή.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Τα δύο μέρη είναι η *βασική περίπτωση* της αναδρομής (εδώ, η κενή ακολουθία αθροίζει σε `0`) και το *αναδρομικό βήμα* (βγάλε ένα στοιχείο, κάνε αναδρομή στο υπόλοιπο, συνδύασε τα αποτελέσματα).

Τα `if-empty` και `unclip` είναι οι καθιερωμένοι σύντροφοι της αναδρομής σε ακολουθίες. Το `if-empty ( seq emptyquot nonemptyquot -- )` εκτελεί μία από τις δύο quotations ανάλογα με την ακολουθία. Το `unclip` βγάζει το πρώτο στοιχείο, ώστε το αναδρομικό βήμα να έχει κάτι πιο απλό.
