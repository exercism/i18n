# Οδηγίες

Σε αυτή την άσκηση θα χρησιμοποιήσεις ένα `HashMap`, μαζί με μεθόδους του entry API, για να λύσεις ένα απλό πρόβλημα αλγορίθμου.

Δεδομένου ενός `&[&str]` που αντιπροσωπεύει τις λέξεις ενός άρθρου περιοδικού, και ενός `&[&str]` που αντιπροσωπεύει τις λέξεις ενός σημειώματος που θέλεις να στείλεις, μπορείς να συνθέσεις το σημείωμά σου κόβοντας λέξεις από το περιοδικό και κολλώντας τις σε ένα γράμμα;

Σημειώσεις:

- Αυτό προϋποθέτει πραγματικό κόψιμο και κόλλημα, και το περιοδικό πρέπει να περιέχει τουλάχιστον τόσα αντίτυπα από κάθε λέξη όσα χρειάζεται το σημείωμα.
- Τα κεφαλαία γράμματα έχουν σημασία, και το γεγονός ότι κολλάς ένα σημείωμα φτιαγμένο από λέξεις ενός περιοδικού δεν σημαίνει ότι δέχεσαι να κάνεις γραμματικά λάθη.

Θα ξεκινήσεις με την παρακάτω υπογραφή συνάρτησης, η οποία είναι μόνο σκελετός:

```rust
pub fn can_construct_note(magazine: &[&str], note: &[&str]) -> bool {
    todo!()
}
```

Δεδομένης της παρακάτω εισόδου

```rust
let magazine = "two times three is not four".split_whitespace().collect::<Vec<&str>>();
let note = "two times two is four".split_whitespace().collect::<Vec<&str>>();
assert!(!can_construct_note(&magazine, &note));
```

Η συνάρτηση επιστρέφει `false`, αφού το περιοδικό περιέχει μόνο ένα στιγμιότυπο του `"two"` ενώ το σημείωμα χρειάζεται δύο από αυτά.

Η παρακάτω είσοδος θα πετύχει:

```rust
let magazine = "Astronomer Amy Mainzer spent hours chatting with Leonardo DiCaprio for Netflix's 'Don't Look Up'".split_whitespace().collect::<Vec<&str>>();
let note = "Amy Mainzer chatting with Leonardo DiCaprio"
    .split_whitespace()
    .collect::<Vec<&str>>();
assert!(can_construct_note(&magazine, &note));
```

Η συνάρτηση επιστρέφει `true`, αφού το περιοδικό περιέχει όλες τις λέξεις που χρειάζεται το σημείωμα.
