# Κλάσεις και ιδιότητες readonly

Οι κλάσεις και οι ιδιότητες readonly επιτρέπουν στις κλάσεις να ορίζουν δημόσιες ιδιότητες για εύκολη πρόσβαση, αλλά εμποδίζουν την τροποποίησή τους.
Για να δηλώσεις μια ιδιότητα ως readonly, πρέπει να προσθέσεις το `readonly` πριν από τον προσδιορισμό του τύπου.
Η ιδιότητα επιτρέπεται να πάρει τιμή μία φορά, αλλά οποιαδήποτε προσπάθεια να της ξαναδώσεις τιμή ή να τροποποιήσεις την τιμή της θα έχει ως αποτέλεσμα ένα Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Οι κλάσεις readonly βασίζονται σε αυτή τη συμπεριφορά και, αν δηλωθούν ως `readonly`, εφαρμόζουν τη δήλωση readonly σε κάθε ιδιότητα.
Επιπλέον, εμποδίζουν την προσθήκη δυναμικών ιδιοτήτων.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
