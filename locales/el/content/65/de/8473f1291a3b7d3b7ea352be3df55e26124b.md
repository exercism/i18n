# Σχετικά

Ένας ορισμός τύπου δημιουργεί έναν νέο ονομασμένο τύπο, διακριτό από κάθε άλλον τύπο, ακόμη και από έναν που έχει τον ίδιο υποκείμενο τύπο.

## Ορισμός τύπων

Ένας ορισμός τύπου ξεκινά με τη λέξη-κλειδί `type`, ακολουθούμενη από το όνομα του νέου τύπου και τον υποκείμενό του τύπο:

```go
type File []bool
```

Εδώ το `File` αναφέρεται σε μία μόνο κάθετη στήλη σε μια σκακιέρα, η οποία συνήθως χαρακτηρίζεται από το A έως το H.
Κάθε τετράγωνο σε αυτή τη στήλη αναπαρίσταται από μια τιμή Boolean που δηλώνει αν είναι κατειλημμένο ή όχι.
Τώρα που το `File` έχει οριστεί, μπορούμε να το χρησιμοποιήσουμε μέσα σε άλλους ορισμούς:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

Το `Chessboard` αντιστοιχίζει αναγνωριστικά στηλών σε τιμές `File`.
Κάθε `File` είναι ένα slice από Boolean που αναπαριστά τα τετράγωνα σε μία στήλη της σκακιέρας.
Χωρίς αυτούς τους ορισμούς τύπων, το `board` θα ήταν ένα `map[string][]bool`, κάτι που θα έκανε πιο δύσκολο να καταλάβουμε τι αναπαριστούμε.

## Οι ορισμένοι τύποι είναι διακριτοί

Παρόλο που το `Score` και το `int` κρατούν και τα δύο ακέραιες τιμές, η μετατροπή μεταξύ τους απαιτεί ρητή μετατροπή:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

Το `42` είναι σταθερά χωρίς τύπο, οπότε μπορεί να ανατεθεί απευθείας σε μια μεταβλητή `Score`.

Οι ορισμένοι τύποι μπορούν επίσης να έχουν μεθόδους, οι οποίες καλύπτονται στην έννοια Methods.

## Τύποι struct

Οι ορισμοί struct χρησιμοποιούν την ίδια λέξη-κλειδί `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Οι τύποι struct καλύπτονται στην έννοια Structs.

## Ψευδώνυμα τύπων

Ένα ψευδώνυμο τύπου δημιουργεί ένα άλλο όνομα για έναν υπάρχοντα τύπο, αντί να δημιουργήσει έναν νέο τύπο.
Επειδή ένα ψευδώνυμο και ο αρχικός του τύπος είναι πανομοιότυπα, οι τιμές τους μπορούν να χρησιμοποιηθούν εναλλάξιμα.
Τα ψευδώνυμα δηλώνονται χρησιμοποιώντας τη λέξη-κλειδί `type`, το όνομα του ψευδωνύμου, το σύμβολο ίσον (`=`) και τον υπάρχοντα τύπο.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
