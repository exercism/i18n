# χρησιμοποίησε μαθηματικές πράξεις αντί για μετατροπή τύπων

Η τελική τιμή αυτή τη στιγμή "κατασκευάζεται" τοποθετώντας ψηφία σε μια συμβολοσειρά και έπειτα ερμηνεύοντας αυτή τη συμβολοσειρά ως αριθμό. Αυτού του είδους η μετατροπή τύπων δεν χρειάζεται. Αντ' αυτού, δοκίμασε να γράψεις μια λύση χρησιμοποιώντας έναν πολλαπλασιασμό και μια πρόσθεση.
