# Εισαγωγή

Ένα `vector` στην Clojure είναι μια διαδοχική, με θέσεις, αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές. Αυτό σημαίνει ότι μόλις δημιουργηθεί ένα vector, δεν μπορεί να τροποποιηθεί. Οι συναρτήσεις για την επεξεργασία των vector θα επιστρέφουν ένα νέο vector, ενώ το αρχικό vector παραμένει αμετάβλητο. Οι τιμές σε ένα vector μπορούν να είναι ετερογενών τύπων. Τα vector μπορούν να οριστούν ως εξής:

```clojure
(def empty [])
(def single-value [5])
```

Τα στοιχεία μπορούν να ανακτηθούν από ένα vector χρησιμοποιώντας μια θέση. Τα vector της Clojure έχουν μηδενική βάση, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

Το αρχικό vector παραμένει αμετάβλητο:

```clojure
numbers
;;=> [2 3 5]
```

Για να θυμόμαστε την ενημερωμένη τιμή, πρέπει να τη μεταβιβάσουμε ή να την καταγράψουμε σε μια var:

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
