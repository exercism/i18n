# πρέπει να αποφύγεις τον προστακτικό βρόχο

Απόφυγε τη χρήση βρόχων `for` σε αυτή την άσκηση.

Σύμφωνα με την εισαγωγή, υπάρχουν ενσωματωμένες μέθοδοι στο αντικείμενο Array της JavaScript που είναι φτιαγμένες για ανάλυση.

Ρίξε μια ματιά στην εισαγωγή ή/και στην [τεκμηρίωση του MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Array#instance_methods) για το ποιες μέθοδοι μπορείς να χρησιμοποιήσεις.
