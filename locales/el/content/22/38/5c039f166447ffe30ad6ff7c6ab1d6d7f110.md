# Εισαγωγή

Η [αντιστοίχιση προτύπων][pattern-matching] επιτρέπει την εγγραφή εκφραστικού κώδικα με διακλαδώσεις και η [αποδόμηση][destructuring] προσφέρει κομψή δέσμευση τιμών σε μεταβλητές.
Και οι δύο είναι εξαιρετικά χρήσιμες για να τις κατακτήσεις ως προγραμματιστής Elm, και όταν χρησιμοποιούνται μαζί, βελτιώνουν πολύ την αναγνωσιμότητα του κώδικα.

## Απλή αντιστοίχιση προτύπων

Η αντιστοίχιση προτύπων δηλώνει κώδικα με διακλαδώσεις ανάλογα με το σχήμα των δεδομένων που επεξεργάζεσαι.
Ταιριάζει λοιπόν φυσικά με την έννοια των προσαρμοσμένων τύπων, που εκφράζουν τα πολλαπλά σχήματα που μπορούν να πάρουν κάποια δεδομένα.
Για παράδειγμα, δεδομένου ενός προσαρμοσμένου τύπου `Color` που ορίζεται ως `Blue` ή `Red`, μπορείς να γράψεις μια συνάρτηση `toString`, κάνοντας αντιστοίχιση προτύπων στο χρώμα ώστε να επιστρέφει τη σωστή συμβολοσειρά.

```elm
type Color = Blue | Red

toString : Color -> String
toString color =
    case color of
        Blue -> "blue"
        Red -> "red"
```

Η αντιστοίχιση προτύπων λειτουργεί επίσης για προσαρμοσμένους τύπους που δεν είναι απλή απαρίθμηση.
Ας εξετάσουμε μια συνάρτηση `hello`, που παίρνει ως παράμετρο ένα `Maybe String`, το οποίο περιέχει είτε το όνομα ενός προσώπου είτε τίποτα απολύτως.
Κάνοντας αντιστοίχιση προτύπων, μπορείς να δώσεις πεζά ονόματα στα δεδομένα ώστε να τα δεσμεύσεις σε εκείνη τη μεταβλητή, και να μπορείς να τη χρησιμοποιήσεις στη δεξιά πλευρά της αντιστοίχισης.

```elm
hello : Maybe String -> String
hello maybeName =
    case maybeName of
        Nothing -> "Hello stranger!"
        -- here we bind 'name' to the data inside the 'Just'
        Just name -> "Hello " ++ name ++ "!"
```

Η αντιστοίχιση προτύπων πρέπει να είναι εξαντλητική, αλλιώς ο μεταγλωττιστής θα αρνηθεί να μεταγλωττίσει.
Αλλά μερικές φορές δεν σε νοιάζουν κάποια δεδομένα ή κάποιοι κλάδοι μιας έκφρασης case.
Σε αυτές τις περιπτώσεις, αντί να ψάχνεις ένα όνομα μεταβλητής για δέσμευση και να έχεις κλάδους για όλες τις περιπτώσεις, μπορείς να χρησιμοποιήσεις τον μπαλαντέρ με την κάτω παύλα `_`.

```elm
type Entity = Friend { name: String } | Stranger | Alien

hello : Entity -> String
hello entity =
    case entity of
        -- here we don't care about the data held by 'Friend'
        Friend _ -> "Hi!"
        -- mandatory because pattern matching must be exhaustive,
        -- but for all other cases, we answer the same thing
        _ -> "Hello stranger!"
```

## Προχωρημένη αντιστοίχιση προτύπων

Εκτός από τους προσαρμοσμένους τύπους, μπορείς επίσης να κάνεις αντιστοίχιση προτύπων σε τύπους που έχουν literal, όπως `Char`, `String`, `Int` και `Floats`.

```elm
howMany : Int -> String
howMany count =
    case count of
        0 -> "none!"
        1 -> "there is one!"
        2 -> "a couple!"
        _ -> "too many to count!"

greekLetter : String -> String
greekLetter letter =
    case letter of
        "a" -> "alpha"
        "b" -> "beta"
        _ -> "I don't remember"
```

Για να κάνεις αντιστοίχιση σε περισσότερες από μία τιμές χωρίς εμφώλευση, ένα συνηθισμένο τρικ στην Elm είναι να συνδυάσεις τις τιμές προς αντιστοίχιση σε [_ad hoc tuples_][ad-hoc-tuples] ως εξής:

```elm
howManyGreekLetters : Int -> String -> String
howManyGreekLetters count letter =
    case ( count, letter ) of
        ( 0, _ ) -> "none!"
        ( 1, "a" ) -> "there is an alpha!"
        ( 1, "b" ) -> "there is a beta!"
        _ -> "at least two!"
```

Και επειδή οι λίστες είναι αγαπημένες στους προγραμματιστές των συναρτησιακών γλωσσών, [μπορείς να κάνεις αντιστοίχιση προτύπων και σε αυτές][pattern-match-lists], με την ίδια σύνταξη που χρησιμοποιείται για να τις φτιάξεις, χρησιμοποιώντας τον τελεστή `::`.

```elm
head : List a -> Maybe a
head list =
    case list of
        [] -> Nothing
        x :: _ -> Just x
```

Τέλος, η αντιστοίχιση προτύπων λειτουργεί ακόμη και αναδρομικά, επιτρέποντάς σου να εμβαθύνεις σε πολύπλοκους και αναδρομικούς τύπους.

```elm
type Activity = Work | Play Game
type Game = Boardgame String | VideoGame String

pickActivity : Activity -> Bool
pickActivity activity =
    case activity of
        -- The only thing we want is playing Catan
        Play (Boardgame "Catan") -> True
        _ -> False
```

## Αποδόμηση

Η αποδόμηση μοιάζει πολύ με την αντιστοίχιση προτύπων, με την έννοια ότι επιτρέπει τη δέσμευση μεταβλητών σε δεδομένα μέσα σε τύπους.
Η κύρια διαφορά είναι ότι αυτόν τον μηχανισμό τον ονομάζουμε "αποδόμηση" όταν υπάρχει μόνο ένα δυνατό σχήμα, και τον ονομάζουμε αντιστοίχιση προτύπων όταν υπάρχουν πολλαπλά σχήματα.
Η αποδόμηση συναντάται συχνά σε δεσμεύσεις `let`, σε ορίσματα συναρτήσεων και, φυσικά, σε εκφράσεις case, σε συνδυασμό με αντιστοίχιση προτύπων.

```elm
pairSum : ( Int, Int ) -> Int
pairSum pair =
    -- Destructuring of a pair in a 'let' binding
    let ( x, y ) = pair
    in x + y

-- Custom type containing a single variant
type Container = Box String

-- Destructuring of the container as function argument
-- to bind its content directly without the need of 'let' or 'case'.
unbox : Container -> String
unbox (Box str) =
    str

-- Destructuring combined with pattern matching
unboxMaybe : Maybe Container -> Maybe String
unboxMaybe maybeContainer =
    case maybeContainer of
        Nothing -> Nothing
        Just (Box "42") -> Just "The answer to the universe!"
        Just (Box str) -> Just str
```

Η αποδόμηση μπορεί να χρησιμοποιηθεί σε προσαρμοσμένους τύπους με μία μόνο παραλλαγή, σε πλειάδες, αλλά και σε καταγραφές, όπου είναι πολύ βολική.
Για να [αποδομήσεις μια καταγραφή][records-pattern-matching], μπορείς να χρησιμοποιήσεις οποιονδήποτε αριθμό από τα πεδία της: ένα, δύο, ..., ή όλα τα πεδία.

```elm
type alias Circle =
    { radius : Float
    , center : ( Float, Float )
    }

perimeter : Circle -> Float
perimeter { radius } =
    2 * pi * radius
```

Δυστυχώς, η σύνταξη της Elm δεν επιτρέπει αναδρομική αποδόμηση καταγραφών.
Στο προηγούμενο παράδειγμα με τον `Circle`, δεν υπάρχει τρόπος να έχεις πρόσβαση στις θέσεις `x`` and `y του κέντρου του κύκλου με μία και μόνο κίνηση.
Πρέπει πρώτα να έχεις πρόσβαση στο `center` και μετά να το αποδομήσεις για τις θέσεις `x` και `y`.

```elm
left : Circle -> Float
left { radius, center } =
    let ( x, _ ) = center
    in x - radius
```

Και έχουμε μια τελευταία συμβουλή!
Μερικές φορές θέλεις εύκολη πρόσβαση και σε ένα πράγμα ως σύνολο και σε ένα μέρος του.
Εδώ μπορεί να σου φανεί χρήσιμη η [λέξη-κλειδί `as`][as-keyword].
Σου επιτρέπει να δώσεις ένα ψευδώνυμο σε ένα πράγμα ως σύνολο, ενώ ταυτόχρονα μπορείς να αποδομήσεις το περιεχόμενό του.

```elm
-- Make the circle smaller if the radius is sufficiently big.
-- Otherwise, return the circle unchanged.
smaller : Float -> Circle -> Circle
smaller reduction ({ radius, center } as circle) =
    if reduction < radius then
        { radius = radius - reduction
        , center = center
        }
    else
        circle
```
