# Σχετικά

Οι ενσωματωμένοι τύποι αριθμών στη C++ χωρίζονται σε ακέραιους και σε αριθμούς κινητής υποδιαστολής.
Οι ακέραιοι είναι αριθμοί χωρίς δεκαδικό μέρος, όπως το `0`, το `691` ή το `-2`.
Οι αριθμοί κινητής υποδιαστολής είναι αριθμοί με υποδιαστολή, όπως το `6.02214076`, το `0.1` ή το `-1.616`.

## Ακέραιοι

Το παρακάτω παράδειγμα δείχνει τη δήλωση και την αρχικοποίηση τεσσάρων διαφορετικών μεταβλητών

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

Όταν αναθέτεις μια τιμή σε μια μεταβλητή `int`, μπορείς να το κάνεις απευθείας με ένα κυριολεκτικό.
Ένα κυριολεκτικό είναι ένας καρφωτός αριθμός, όπως το `9241`.
Υπάρχουν διαφορετικά ακέραια κυριολεκτικά για τις διάφορες βάσεις αναπαράστασης.
Τα δεκαδικά ακέραια κυριολεκτικά είναι τα πιο συνηθισμένα και χρησιμοποιούν τα ψηφία από το `0` έως το `9`.
Προσθέτοντας ένα ειδικό πρόθεμα, όπως το `0x`, μπορείς να χρησιμοποιήσεις και άλλες βάσεις.
Το παραπάνω παράδειγμα δείχνει τον αριθμό `9421` στις τέσσερις αναπαραστάσεις και με τα προθέματά του.
Όλες οι μεταβλητές αρχικοποιούνται στην ίδια τιμή.

Για περισσότερες λεπτομέρειες σχετικά με τα διαφορετικά συστήματα αναπαράστασης, ρίξε μια ματιά σε [ένα μικρό tutorial][cpp_numerical_bases].

Μπορείς να χρησιμοποιήσεις μια απόστροφο για να χωρίζεις τα ψηφία, ώστε να διαβάζονται πιο εύκολα.
Το `9'241` είναι το ίδιο με το `0b0100'100'0001'1001` ή το `92'4'1`.

## Αριθμοί κινητής υποδιαστολής

Τα κυριολεκτικά κινητής υποδιαστολής υπάρχουν σε δύο μορφές.
Εκτός από το διαισθητικό `0.0024`, μπορείς να χρησιμοποιήσεις και την επιστημονική του σημειογραφία, το `2.4e-3`.
Ο πιο συνηθισμένος τύπος κινητής υποδιαστολής είναι ο `double`.

## Αριθμητική

Η C++ υποστηρίζει τους `+`, `-`, `*`, `/`, `(` και `)` και `%` για να σχηματίζεις παραστάσεις.
Το αποτέλεσμα της πράξης μεταξύ δύο ακεραίων είναι επίσης ακέραιος.
Το `5 / 2` θα επιστρέψει `2`.
Όταν ένας από τους τύπους που εμπλέκονται είναι τύπου κινητής υποδιαστολής, το αποτέλεσμα θα είναι επίσης κινητής υποδιαστολής.
Τα `5.0 / 2` και `5 / 2.0` θα επιστρέψουν `2.5`.
Το `%` είναι ο τελεστής υπολοίπου και επιστρέφει το υπόλοιπο μιας ακέραιας διαίρεσης: το `5%3` είναι `2`.

## Ο τελεστής ανάθεσης

Ο τελεστής ανάθεσης αναθέτει σε μια μεταβλητή ένα κυριολεκτικό.
Η ανάθεση γίνεται πάντα από τα δεξιά προς τα αριστερά και ποτέ αντίστροφα.

```cpp
int length = 5;
int width = 2;
length = width;
```

Εδώ, η ακέραια τιμή `5` ανατίθεται στη μεταβλητή `length`.
Έπειτα, η ακέραια τιμή `2` ανατίθεται στη μεταβλητή `width`.
Τέλος, η τιμή του `width` αντιγράφεται στη μεταβλητή `length` και η προηγούμενη τιμή `5` χάνεται.
Σκέψου επίσης ότι αναθέτουμε την τιμή του `width` στο `length` μόνο τη στιγμή της πράξης ανάθεσης.
Επομένως, αν η τιμή του `width` αλλάξει αργότερα, δεν θα επηρεάσει την τιμή που παίρνει το `length`.

Ο τελεστής ανάθεσης μπορεί να συνδυαστεί με τους άλλους τελεστές (αριθμητικούς και bitwise), που είναι γνωστοί ως τελεστές `compound assignment`: `+=`, `-=`, `*=`, `/=`, `%=`.
Αυτοί οι τελεστές τροποποιούν την τρέχουσα τιμή μιας μεταβλητής εκτελώντας πάνω της μια πράξη.

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

Οι μεταβλητές `people` και `eggs` αρχικοποιούνται στο `0`.
Έπειτα, προσθέτουμε την ακέραια τιμή `2` στην υπάρχουσα τιμή `0` της μεταβλητής `people` και την αναθέτουμε πίσω στο `people`.
Το `people` γίνεται τώρα `2`.
Στη συνέχεια, προσθέτουμε `3` αυγά για κάθε άτομο, που βγαίνουν `6` αυγά συνολικά.
Τώρα προσθέτουμε αυτό το `6` στην υπάρχουσα τιμή `0` της μεταβλητής `eggs` και το αναθέτουμε πίσω στο `eggs`.
Το `eggs` θα είναι τώρα `6`.
Η ισοδύναμη παράσταση θα ήταν `people = people + 2` και `eggs = eggs + (3 * people)`.

## Μετατροπή τύπου

Η μετατροπή τύπου είναι η μετατροπή μιας τιμής από έναν τύπο σε έναν άλλο.
Αν χρειάζεται ένα `double`, στη θέση του μπορεί να χρησιμοποιηθεί ένα `int`.
Το παράδειγμα `5.0 / 2` από πάνω αντιμετωπίζεται με μια έμμεση μετατροπή του `2` σε `2.0`.
Ένα `double` που μετατρέπεται σε `int` μπορεί να χάσει πληροφορίες.
Είναι καλή πρακτική να κάνεις αυτές τις μετατροπές σε έναν άλλο τύπο T ρητές μέσω του `static_cast<T>`.
Η παλιά μετατροπή τύπου στυλ C μέσω `(T)` αποθαρρύνεται στη σύγχρονη C++, αλλά καλό είναι να τη γνωρίζεις παρ' όλα αυτά.

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## Ακρίβεια και αναπαράσταση

Οι αριθμοί στη C++ δεν μπορούν να είναι αυθαίρετα μεγάλοι.
Το `int` για παράδειγμα αναπαρίσταται με 32 bit.
Αυτό αρκεί για ένα σύνολο `2^32` αριθμών, περίπου 4 δισεκατομμύρια.
Συμπεριλαμβανομένου του `0`, αυτό ορίζει τον μεγαλύτερο και τον μικρότερο αριθμό `int` ως `-2^31` και `2^31 - 1`.

Οι αριθμοί κινητής υποδιαστολής συνήθως υλοποιούνται με ακρίβεια 15 δεκαδικών ψηφίων, αλλά η αναπαράστασή τους διαφέρει ανάλογα με το σύστημα στο οποίο εκτελείται το πρόγραμμα.
