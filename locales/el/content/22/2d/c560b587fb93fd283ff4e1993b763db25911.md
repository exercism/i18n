# Προσθήκη στις οδηγίες

Σε αυτή την άσκηση της Roc, οι πράξεις στον λογαριασμό είναι καθαρές: κάθε ενημέρωση επιστρέφει μια νέα τιμή λογαριασμού. Οι λογαριασμοί ξεκινούν κλειστοί, το ξανάνοιγμα μηδενίζει το υπόλοιπο, και οι καταθέσεις και οι αναλήψεις πρέπει να είναι θετικές. Οι μη έγκυρες πράξεις επιστρέφουν σφάλματα. Αυτή η άσκηση εστιάζει στη λογική του λογαριασμού και δεν ελέγχει τον ταυτοχρονισμό.

Στη Roc, γενικά αφήνουμε τον ταυτοχρονισμό στην πλατφόρμα, οπότε δεν υπάρχουν έλεγχοι ταυτοχρονισμού εδώ. Σε μια ταυτόχρονη εφαρμογή, αυτές οι καθαρές πράξεις θα εκτελούνταν μέσα σε έναν μηχανισμό που εφαρμόζει κάθε ενημέρωση του λογαριασμού με ατομικό τρόπο. Για παράδειγμα, η πλατφόρμα μπορεί να επεξεργάζεται τις εντολές του λογαριασμού διαδοχικά, ή μπορεί να βασίζεται σε συναλλαγές βάσης δεδομένων.

Μπορεί επίσης να θέλεις να ρίξεις μια ματιά στην άσκηση `parallel-letter-frequency`, όπου η πλατφόρμα δίνει στον κώδικα Roc πρόσβαση σε πρωτογενή στοιχεία παράλληλου υπολογισμού. Ο πραγματικός παραλληλισμός εξακολουθεί να διαχειρίζεται από την πλατφόρμα, αλλά ο κώδικας Roc αποκτά μεγαλύτερο έλεγχο πάνω του.
