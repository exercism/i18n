# Εισαγωγή

Μια `str` στην Python είναι μια [αμετάβλητη ακολουθία][text sequence] από [σημεία κώδικα Unicode][unicode code points].
Αυτά μπορεί να περιλαμβάνουν γράμματα, διακριτικά σημεία, χαρακτήρες τοποθέτησης, αριθμούς, σύμβολα νομισμάτων, emoji, σημεία στίξης, χαρακτήρες κενού και αλλαγής γραμμής και άλλα.

Οι συμβολοσειρές υλοποιούν όλες τις [κοινές πράξεις ακολουθιών][common sequence operations] και μπορούν να διατρεχτούν με τη σύνταξη `for item in <string>` ή `for index, item in enumerate(<string>)`.

Οι συμβολοσειρές μπορούν να συνενωθούν με `<str> + <other str>` ή `<str>.join(<iterable>)` και να χωριστούν μέσω `<str>.split(<separator>)`.
Προσφέρουν επίσης πολλές επιπλέον επιλογές μορφοποίησης, σύνθεσης και προτύπων.

Καθώς είναι αμετάβλητη, η τιμή ενός αντικειμένου `str` στη μνήμη δεν αλλάζει· οι μέθοδοι που φαίνεται να τροποποιούν μια συμβολοσειρά επιστρέφουν ένα νέο αντίγραφο ή στιγμιότυπο της `str`.

Για μια βαθύτερη ματιά στο τι πληροφορία κωδικοποιεί μια συμβολοσειρά (ή, _"πώς ξέρει ένας υπολογιστής να μετατρέπει τα μηδενικά και τους άσσους σε γράμματα;"_), [αυτή η ανάρτηση ιστολογίου είναι διαχρονικά χρήσιμη][joel-on-text].
Τα έγγραφα της Python παρέχουν επίσης ένα πολύ λεπτομερές [unicode HOWTO][unicode how-to] που συζητά την υποστήριξη της Python για την προδιαγραφή Unicode στις μονάδες `str`, `bytes` και `re`, ζητήματα τοπικών ρυθμίσεων και μερικά κοινά προβλήματα με την κωδικοποίηση και τη μετάφραση.
