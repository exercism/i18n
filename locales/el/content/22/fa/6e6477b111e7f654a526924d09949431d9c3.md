# Σχετικά

Ένα αρχείο είναι μια ροή με όνομα στον δίσκο. Το λεξιλόγιο [`io.files`][io.files]
προσφέρει δύο τρόπους για να δουλέψεις με ένα αρχείο: εύχρηστες λέξεις για
ολόκληρο το αρχείο, που διαβάζουν ή γράφουν τα πάντα με μία μόνο κλήση, και
ανοίγματα ροών (οι συνδυαστές `with-…`) για σταδιακή ανάγνωση ή εγγραφή. Και τα
δύο στηρίζονται στο ίδιο [πρωτόκολλο ροών][stream-protocol] με τις ροές στη μνήμη
από την έννοια `io-streams`: ένα `<file-reader>` και ένα `<string-reader>`
ανταποκρίνονται στις ίδιες λέξεις.

Κάθε λέξη για αρχεία παίρνει μια **κωδικοποίηση**, το σχήμα που αντιστοιχίζει
byte σε χαρακτήρες και αντίστροφα. Για κείμενο, αυτή είναι σχεδόν πάντα η
[`utf8`][utf8] από το `io.encodings.utf8`; η εργασία με δυαδικά δεδομένα
χρησιμοποιεί `latin1` ή μια κωδικοποίηση `<byte-array>`.

## Ανάγνωση ολόκληρου του αρχείου

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

Η `file-contents` επιστρέφει ολόκληρο το αρχείο ως μία συμβολοσειρά. Η
`file-lines` επιστρέφει τις γραμμές του ως πίνακα, με τους τερματιστές γραμμής
να έχουν αφαιρεθεί, κάτι βολικό όταν κάθε γραμμή είναι μια καταγραφή.

```factor
USING: io.encodings.utf8 io.files ;

"forecast.txt" utf8 file-contents   ! => "sunny\ncloudy\n"
"forecast.txt" utf8 file-lines      ! => { "sunny" "cloudy" }
```

## Εγγραφή ολόκληρου του αρχείου

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Και οι δύο **αντικαθιστούν** το αρχείο, δημιουργώντας το αν δεν υπάρχει.
Η `set-file-contents` γράφει μια συμβολοσειρά αυτούσια; η `set-file-lines`
γράφει κάθε στοιχείο μιας ακολουθίας σε δική του γραμμή, προσθέτοντας τους
χαρακτήρες αλλαγής γραμμής.

```factor
{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
! forecast.txt now holds "sunny\ncloudy\n"
```

## Ροές σε εμβέλεια

Όταν θέλεις να προσθέσεις κάτι σε ένα αρχείο ή να διαβάζεις και να γράφεις
κομμάτι κομμάτι, άνοιξέ το με έναν συνδυαστή `with-…` και χρησιμοποίησε τις
λέξεις ροής του περιβάλλοντος μέσα στην παράθεση:

```
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
with-file-appender   ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files ;

"log.txt" utf8 [ "another line" print ] with-file-appender
```

Η `with-file-writer` περικόπτει πρώτα το αρχείο; η `with-file-appender` διατηρεί
τα υπάρχοντα περιεχόμενα και γράφει μετά από αυτά. Καθεμιά είναι μια εμβέλεια
καταστροφέα: η λαβή του αρχείου κλείνει όταν τελειώσει η παράθεση, ακόμη κι αν
αυτή πετάξει ένα σφάλμα, την ίδια εγγύηση που παρέχουν οι συνδυαστές του
`boatswains-bilge`, εδώ ειδικευμένοι στα αρχεία.

## Ολόκληρο το αρχείο ή σε εμβέλεια;

Κατέφυγε στις `file-contents` / `file-lines` / `set-file-contents` /
`set-file-lines` όταν το αρχείο είναι αρκετά μικρό ώστε να χωρέσει στη μνήμη και
θέλεις να το έχεις όλο μαζί. Κατέφυγε στα ανοίγματα `with-…` όταν χρειάζεσαι να
προσθέσεις στο τέλος, να διαβάσεις ένα μεγάλο αρχείο ως ροή γραμμή προς γραμμή
με τη `readln`, ή να εναλλάσσεις αναγνώσεις και εγγραφές, σε κάθε περίπτωση
δηλαδή όπου το να κρατάς ολόκληρο το αρχείο στη μνήμη θα ήταν σπάταλο ή λάθος.
