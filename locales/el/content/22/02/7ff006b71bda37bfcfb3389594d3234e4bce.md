# Σχετικά

Μια λίστα στη Gleam είναι μια αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές. Οι τιμές σε μια λίστα πρέπει να έχουν όλες τον ίδιο τύπο. Επειδή οι λίστες είναι αμετάβλητες, μόλις κατασκευαστεί μια λίστα, η τιμή της δεν μπορεί ποτέ να αλλάξει. Οποιαδήποτε συνάρτηση ή τελεστής που φαίνεται να τροποποιεί μια λίστα (όπως η προσθήκη ενός στοιχείου) στην πραγματικότητα επιστρέφει μια νέα λίστα.

Οι λίστες μπορούν να οριστούν ως εξής:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

Ο πιο συνηθισμένος τρόπος για να προσθέσεις ένα στοιχείο σε μια λίστα είναι να το βάλεις στην αρχή της χρησιμοποιώντας τη σύνταξη spread:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Το module [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) στην πρότυπη βιβλιοθήκη της Gleam περιέχει πολλές χρήσιμες συναρτήσεις για εργασία με λίστες. Αυτό το module χρησιμοποιείται πολύ συχνά σε κώδικα Gleam, οπότε είναι καλό να το γνωρίζεις.

Τα μοτίβα λιστών μπορούν να χρησιμοποιηθούν σε εκφράσεις case για αντιστοίχιση σε λίστες και ανάθεση των τιμών που περιέχουν σε μεταβλητές:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Εκτός από την αντιστοίχιση σε λίστες ακριβούς μήκους, η σύνταξη spread μπορεί να χρησιμοποιηθεί για αντιστοίχιση σε λίστες με τουλάχιστον ένα συγκεκριμένο μήκος:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

Η σύνταξη spread μπορεί επίσης να χρησιμοποιηθεί για να αναθέσεις το υπόλοιπο της λίστας σε μια μεταβλητή:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Οι εκφράσεις case θα πρέπει να έχουν ένα μοτίβο για κάθε πιθανή τιμή του τύπου στον οποίο γίνεται η αντιστοίχιση, γι' αυτό συχνά χρησιμοποιείται ένα τελικό μοτίβο απόρριψης (`_`) για να χειρίζεται οποιεσδήποτε υπόλοιπες τιμές.
