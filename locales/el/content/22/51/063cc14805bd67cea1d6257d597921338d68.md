# Υποδείξεις

## 1. Υπολόγισε το επιτόκιο

- Από προεπιλογή, κάθε αριθμός κινητής υποδιαστολής που ορίζεται σε κώδικα Go αντιμετωπίζεται ως `float64`.
  Επειδή ο τύπος επιστροφής της συνάρτησης `InterestRate` είναι `float32`, δεν χρειάζεται να κάνεις μετατροπές τύπων.

## 2. Υπολόγισε τον τόκο

- Όταν υπολογίζεις τον τόκο, μπορεί να σου φανεί χρήσιμο να παρατηρήσεις ότι η `InterestRate` επιστρέφει ποσοστό.
- Μπορείς να χρησιμοποιήσεις τη συνάρτηση που ορίστηκε στην προηγούμενη εργασία (`InterestRate`) για να υπολογίσεις τον τόκο.
- Μπορεί να χρειαστεί να μετατρέψεις το αποτέλεσμα της `InterestRate` σε `float64`.

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Όταν υπολογίζεις την ετήσια ενημέρωση του υπολοίπου, χρησιμοποίησε τις συναρτήσεις που ορίστηκαν στα προηγούμενα βήματα.

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

- Για να υπολογίσεις τα χρόνια, μπορείς να συνεχίζεις να επαναλαμβάνεις μέχρι να φτάσεις στο επιθυμητό υπόλοιπο χρησιμοποιώντας έναν [`for` βρόχο](https://gobyexample.com/for).
- Υπάρχει ένας ειδικός [τελεστής](https://golang.org/ref/spec#IncDec_statements) για να αυξάνεις τις τιμές κατά 1.
