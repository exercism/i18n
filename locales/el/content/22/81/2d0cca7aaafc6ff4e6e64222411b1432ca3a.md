# Τεστ

Για να χρησιμοποιήσεις το test runner, θα χρειαστεί να έχεις [εγκαταστήσει σωστά το Godot][installation].

## Εκτέλεση των τεστ

Το [test runner][] χρησιμοποιείται για να φορτώνει και να δοκιμάζει λύσεις.
Όταν κατεβάσεις μια άσκηση τοπικά, μαζί της περιλαμβάνεται ένα αντίγραφο του test runner, καθώς και ένα script shell για να το εκτελέσεις.

Για να τρέξεις την άσκηση, απλώς εκτέλεσε το script `run_tests` στον κατάλογο της άσκησης χρησιμοποιώντας το `bash`.

Για παράδειγμα,

```bash
cd "$(exercism workspace)/gdscript/hello-world"
bash run_tests
```

[installation]: https://exercism.org/docs/tracks/gdscript/installation
[test runner]: https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
