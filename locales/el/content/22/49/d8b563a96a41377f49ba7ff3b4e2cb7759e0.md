# Οδηγίες

Η φίλη σου η Helma έφτιαξε ένα μικρό διαδικτυακό παιχνίδι που απέκτησε γρήγορα δημοτικότητα.
Λέγεται _HellMath_.
Η μικρή κοινότητα προσέλκυσε μερικά τρόλ που κάνουν το παιχνίδι και τα φόρουμ αρκετά δυσάρεστα.
Η Helma σου ζήτησε να δουλέψεις πάνω σε ένα νέο σύστημα δικαιωμάτων, που θα ξεχωρίζει όσους δημιουργούν προβλήματα.

Το φόρουμ υποστηρίζει τρεις διαφορετικές ενέργειες:

- Ανάγνωση
- Εγγραφή
- Διαγραφή

Υπάρχουν τέσσερις τύποι λογαριασμών, ο καθένας με διαφορετικά προεπιλεγμένα δικαιώματα:

- Επισκέπτες: μπορούν να διαβάζουν αναρτήσεις.
- Χρήστες και Τρόλ: μπορούν να διαβάζουν και να γράφουν αναρτήσεις.
- Συντονιστές: μπορούν να διαβάζουν, να γράφουν και να διαγράφουν αναρτήσεις, έχουν όλα τα δικαιώματα.

Η Helma παρατήρησε ότι δεν έχει νόημα να αποκλείεις λογαριασμούς τρόλ.
Η στρατηγική της είναι να τους δίνει την ψευδαίσθηση ότι ο χρόνος τους είναι "καλά επενδεδυμένος", αλλά οι αναρτήσεις τους εμφανίζονται μόνο σε άλλα τρόλ.
Σε ό,τι απαιτεί σειρά προτεραιότητας, τα τρόλ είναι τελευταία σε κάθε σειρά.
Όταν μπαίνουν σε ένα παιχνίδι, το σύνολο των διαθέσιμων παικτών περιορίζεται επίσης σε άλλα τρόλ.

Αυτή η πρακτική ονομάζεται [shadow-banning][shadow-ban].

## 1. Ρύθμισε τους τύπους χρηστών και τα δικαιώματα.

Πρώτα, όρισε μια απαρίθμηση `AccountStatus` που να αντιπροσωπεύει τους τέσσερις τύπους λογαριασμών: `troll`, `guest`, `user` και `mod`.

Έπειτα, όρισε μια απαρίθμηση `Action` που να αντιπροσωπεύει τους τρεις τύπους δικαιωμάτων: `read`, `write` και `remove`.


## 2. Πρόβαλε τα τρόλ μόνο σε άλλα τρόλ.

Κάθε ανάρτηση στα φόρουμ αποθηκεύει το `AccountStatus` αυτού που την ανάρτησε στα μεταδεδομένα της.
Βεβαιώσου ότι οι αναρτήσεις από τρόλ εμφανίζονται μόνο σε άλλα τρόλ.

Η Helma χρειάζεται μια συνάρτηση `display_post`, που δέχεται δύο ορίσματα τύπου `AccountStatus` και επιστρέφει ένα `bool`.
Το πρώτο όρισμα είναι η κατάσταση αυτού που ανάρτησε, το δεύτερο η κατάσταση αυτού που τη βλέπει.

```cpp
using namespace hellmath;
display_post(AccountStatus::troll, AccountStatus::user);
// => false
display_post(AccountStatus::mod, AccountStatus::guest);
// => true
```

## 3. Έλεγξε τα δικαιώματα για διαφορετικούς χρήστες.

Η Helma χρειάζεται έναν τρόπο να ελέγχει αν μια συγκεκριμένη ενέργεια επιτρέπεται για έναν χρήστη.

Υλοποίησε μια συνάρτηση `permission_check`, που δέχεται ένα `Action` ως πρώτο όρισμα και ένα `AccountStatus` με το οποίο θα γίνει ο έλεγχος.
Θα πρέπει να επιστρέφει ένα `bool` σύμφωνα με τα δικαιώματα που αναφέρονται στην εισαγωγή.

```cpp
permission_check(Action::remove, AccountStatus::guest);
// => false
permission_check(Action::write, AccountStatus::mod);
// => true
```

## 4. Χορήγησε πρόσβαση στο παιχνίδι και ταίριαξε παίκτες.

Για να κρατάει τους πραγματικούς παίκτες του παιχνιδιού υπόλογους για τις πράξεις τους, το _Hellmath_ αρνείται την πρόσβαση στους επισκέπτες.
Όπως αναφέρθηκε παραπάνω, η Helma θέλει τα τρόλ να τρολάρουν άλλα τρόλ.
Οι συνδέσεις παιχνιδιού μεταξύ των άλλων χρηστών δεν έχουν περιορισμούς.

Υλοποίησε τη συνάρτηση `valid_player_combination` που ελέγχει αν δύο παίκτες μπορούν να μπουν στο ίδιο παιχνίδι.
Η συνάρτηση έχει δύο παραμέτρους τύπου `AccountStatus` και επιστρέφει ένα `bool`.

```cpp
valid_player_combination(AccountStatus::guest, AccountStatus::mod);
// => false
valid_player_combination(AccountStatus::troll, AccountStatus::troll);
// => true
```

## 5. Υλοποίησε ουρά προτεραιότητας.

Με τη μαζική ανάπτυξη του παιχνιδιού και των φόρουμ, η Helma πρέπει τώρα να μοιράζει την υπολογιστική ισχύ και το εύρος ζώνης στους χρήστες.
Για να αντιμετωπίζονται έκτακτες καταστάσεις, οι συντονιστές παίρνουν την υψηλότερη προτεραιότητα.
Οι επισκέπτες μπαίνουν στην ουρά πίσω από τους κανονικούς χρήστες και τα τρόλ ταξινομούνται πίσω από όλους τους άλλους.

Υλοποίησε τη συνάρτηση `has_priority` που δέχεται δύο ορίσματα `AccountStatus` και επιστρέφει `true`, αν και μόνο αν ο πρώτος λογαριασμός έχει αυστηρά υψηλότερη προτεραιότητα από τον δεύτερο.

```cpp
has_priority(AccountStatus::guest, AccountStatus::mod);
// => false
has_priority(AccountStatus::user, AccountStatus::troll);
// => true
```
