# Σχετικά

Οι κλάσεις είναι ένα θεμελιώδες δομικό στοιχείο των προγραμμάτων σε Swift.
Σου επιτρέπουν να ομαδοποιείς σχετικές ιδιότητες (δεδομένα) και μεθόδους (συναρτήσεις) σε αυτοτελείς μονάδες λειτουργικότητας.

### Ορισμός κλάσεων

Για να ορίσεις μια κλάση, χρησιμοποίησε τη λέξη-κλειδί `class` ακολουθούμενη από το όνομα της κλάσης, με τον ορισμό της κλάσης μέσα σε άγκιστρα:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

Το σώμα μιας κλάσης μπορεί να περιέχει αποθηκευμένες ιδιότητες, οι οποίες ορίζονται και συμπεριφέρονται όπως οι συνηθισμένες σταθερές (`let`) ή μεταβλητές (`var`).

### Στιγμιότυπα

Ο ορισμός μιας κλάσης λειτουργεί ως προσχέδιο: ορίζει έναν νέο τύπο και περιγράφει πώς μοιάζουν οι τιμές του, αλλά δεν δημιουργεί από μόνος του κανένα στιγμιότυπο.

Για να δημιουργήσεις ένα *στιγμιότυπο* μιας κλάσης, κάλεσε τον αρχικοποιητή της γράφοντας το όνομα της κλάσης ακολουθούμενο από παρενθέσεις:

```swift
let someCharacter = GameCharacter()
```

Αυτό δημιουργεί ένα νέο στιγμιότυπο του οποίου οι ιδιότητες αρχικοποιούνται με τις προεπιλεγμένες τιμές που ορίζονται στον ορισμό της κλάσης.
Για προαιρετικές ιδιότητες χωρίς ρητές προεπιλεγμένες τιμές (όπως η `name`), η Swift τις θέτει ως προεπιλογή σε `nil`.

### Πρόσβαση στις ιδιότητες

Έχεις πρόσβαση στις ιδιότητες ενός στιγμιότυπου με *σημειογραφία με τελεία*: γράψε το όνομα του στιγμιότυπου, μια τελεία (`.`) και το όνομα της ιδιότητας.
Η σημειογραφία με τελεία λειτουργεί και για εμφωλευμένες ιδιότητες.

Μπορείς να χρησιμοποιήσεις τη σημειογραφία με τελεία για να διαβάσεις τιμές και, αν η ιδιότητα μπορεί να αλλάξει (`var`), να της αναθέσεις νέες τιμές:

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Μέθοδοι

Εκτός από ιδιότητες, οι κλάσεις μπορούν να ορίζουν *μεθόδους*, δηλαδή συναρτήσεις που σχετίζονται με την κλάση.

Όρισε τις μεθόδους μέσα στο σώμα της κλάσης χρησιμοποιώντας τη συνηθισμένη σύνταξη `func`.
Αν μια μέθοδος τροποποιεί μια ιδιότητα, αυτή η ιδιότητα πρέπει να δηλωθεί με `var`:

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

Κάλεσε τις μεθόδους σε ένα στιγμιότυπο χρησιμοποιώντας σημειογραφία με τελεία, ακριβώς όπως τις ιδιότητες:

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Κάθε στιγμιότυπο μιας κλάσης έχει μια έμμεση ιδιότητα με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο.
Αν και συχνά παραλείπεται όταν αναφέρεσαι σε ιδιότητες ή μεθόδους, το `self` χρησιμοποιείται συνήθως για να ξεχωρίζεις τα ονόματα των ιδιοτήτων από τα ονόματα των παραμέτρων μιας μεθόδου όταν αυτά ταυτίζονται.
