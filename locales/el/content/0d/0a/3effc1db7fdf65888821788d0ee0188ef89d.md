# Πόροι

* Το κανάλι IRC [#haskell](https://web.libera.chat/?channel=#haskell) στο Libera Chat, με στόχο να "ενθαρρύνει τη μάθηση και τη συζήτηση της Haskell, του συναρτησιακού προγραμματισμού και του προγραμματισμού γενικότερα". Περισσότερες πληροφορίες για το κανάλι IRC θα βρεις στη [σελίδα του wiki του Haskell για το κανάλι](https://wiki.haskell.org/IRC_channel).
* Το [Hoogle](https://www.haskell.org/hoogle/) είναι μια μηχανή αναζήτησης του API της Haskell. Σου επιτρέπει να δεις τι κάνει μια συνάρτηση αν το μόνο που ξέρεις είναι το όνομά της. Ίσως ακόμη πιο ενδιαφέρον, υποστηρίζει και αναζήτηση με υπογραφή τύπου: αν θέλεις να μάθεις ποιες συναρτήσεις έχουν την υπογραφή τύπου [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b]), το Hoogle σε βοηθά να το ανακαλύψεις!
* Το [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell) μπορείς να το χρησιμοποιήσεις για να αναζητήσεις το πρόβλημά σου και να δεις αν έχει ήδη απαντηθεί. Μπορείς επίσης να ρωτήσεις και να απαντήσεις.
* Το [/r/haskell](https://www.reddit.com/r/haskell) είναι το subreddit της Haskell.
* Η [σελίδα της κοινότητας του Haskell](https://www.haskell.org/community/) παραπέμπει σε αρκετές κοινότητες όπου συγκεντρώνονται και αλληλεπιδρούν οι Haskellers. Από εκεί μπορείς να διαλέξεις το μέσο επικοινωνίας που προτιμάς.
