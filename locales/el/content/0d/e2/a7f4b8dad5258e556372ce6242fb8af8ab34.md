# Προσθήκη στις οδηγίες

## Υλοποίηση

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να ορίσεις τον τύπο δεδομένων `stopwatch` και να υλοποιήσεις τις συναρτήσεις:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Θα βρεις ήδη έναν εικονικό ορισμό τύπου στη θέση του, αλλά από εσένα εξαρτάται να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν τύπο δεδομένων με νόημα.
