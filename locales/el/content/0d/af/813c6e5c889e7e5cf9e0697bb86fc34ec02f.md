# Εξαιρέσεις

Κάποιες ρουτίνες δεν μπορούν να απαντήσουν. Όταν της ζητηθεί ένα prop που δεν βρίσκεται στο τραπέζι, η `count_of` δεν έχει αριθμό να δώσει, και το μηδέν θα ήταν ψέμα, γιατί το μηδέν σημαίνει "δεν έχουμε κανένα από αυτά", όχι "δεν υπάρχει τέτοιο πράγμα".

Μια **εξαίρεση** είναι ο τρόπος με τον οποίο μια ρουτίνα λέει ότι δεν μπορεί να απαντήσει.

## Πέταγμα

Το `raise` εγκαταλείπει τη ρουτίνα και παραδίδει μια τιμή σε όποιον την κάλεσε.

```sather
   count_of(props : FMAP{STR,INT}, prop : STR) : INT is
      if ~props.has_ind(prop) then
         raise "Unknown prop: " + prop;
      end;
      return props.get(prop);
   end;
```

Τίποτα μετά από ένα `raise` δεν εκτελείται. Η ρουτίνα δεν επιστρέφει, οπότε δεν υπάρχει απάντηση για έλεγχο και ο καλών δεν έχει τρόπο να συνεχίσει σαν να υπήρχε.

Η τιμή που πετιέται είναι συνήθως μια συμβολοσειρά που λέει τι πήγε στραβά.

## Σύλληψη

Το `protect` εκτελεί ένα κομμάτι κώδικα, έτοιμο για την περίπτωση που πετάξει.

```sather
   protect
      taken ::= count_of(props, prop);
      #OUT + "There are " + taken;
   when $STR then
      #OUT + "Cannot: " + exception.str;
   end;
```

Αν τίποτα δεν πετάξει, το κομμάτι μετά το `protect` εκτελείται και ο κλάδος `when` παραλείπεται. Αν κάτι πετάξει, το υπόλοιπο του τμήματος `protect` εγκαταλείπεται και εκτελείται αντ' αυτού το αντίστοιχο `when`.

Το `when $STR then` πιάνει μια συμβολοσειρά που πετάχτηκε. Το `exception` είναι η τιμή που πετάχτηκε, διαθέσιμη μέσα στον κλάδο.

## Περνώντας παρακάτω

Μια ρουτίνα που δεν πιάνει μια εξαίρεση δεν χρειάζεται να κάνει τίποτα γι' αυτήν. Ταξιδεύει προς τα έξω, μέσα από κάθε καλούντα, ώσπου κάτι να την πιάσει:

```sather
   take_one(props : FMAP{STR,INT}, prop : STR) : INT is
      -- If this raises, take_one raises too. Nothing here says so.
      have ::= count_of(props, prop);
      ...
   end;
```

Αυτό είναι το νόημα των εξαιρέσεων. Η ρουτίνα που αντιλαμβάνεται το πρόβλημα και η ρουτίνα που ξέρει τι να κάνει γι' αυτό συνήθως δεν είναι η ίδια ρουτίνα, και ό,τι βρίσκεται ενδιάμεσα μπορεί να το αγνοήσει.
