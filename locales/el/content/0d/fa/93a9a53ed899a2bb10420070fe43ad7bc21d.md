# Εισαγωγή

## Πίνακες

Στη C#, οι δομές δεδομένων που μπορούν να κρατήσουν μηδέν ή περισσότερα στοιχεία ονομάζονται _συλλογές_. Ένας **πίνακας** είναι μια συλλογή που έχει σταθερό μέγεθος/μήκος και της οποίας τα στοιχεία πρέπει να είναι όλα του ίδιου τύπου. Τα στοιχεία μπορούν να ανατεθούν σε έναν πίνακα ή να ανακτηθούν από αυτόν χρησιμοποιώντας μια θέση. Οι πίνακες της C# βασίζονται στο μηδέν, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Οι πίνακες μπορούν επίσης να οριστούν χρησιμοποιώντας μια συντομευμένη σημειογραφία που σου επιτρέπει και να δημιουργήσεις τον πίνακα και να ορίσεις την τιμή του. Καθώς ο μεταγλωττιστής μπορεί τώρα να καταλάβει πόσα στοιχεία θα έχει ο πίνακας, το μήκος μπορεί να παραλειφθεί:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Οι πίνακες μπορούν να χειριστούν είτε καλώντας τις μεθόδους ή τις ιδιότητες ενός στιγμιότυπου πίνακα, είτε χρησιμοποιώντας τις στατικές μεθόδους που ορίζονται στην κλάση `Array`.

## Βρόχοι `for`

Ένας βρόχος `for` σου επιτρέπει να εκτελέσεις κώδικα επανειλημμένα μέχρι να ικανοποιηθεί μια συνθήκη.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Ένας βρόχος `for` αποτελείται από τέσσερα μέρη:

1. Ο αρχικοποιητής: εκτελείται μία φορά πριν την είσοδο στον βρόχο. Συνήθως χρησιμοποιείται για να ορίσει μεταβλητές που χρησιμοποιούνται μέσα στον βρόχο.
2. Η συνθήκη: εκτελείται πριν από κάθε επανάληψη του βρόχου. Ο βρόχος συνεχίζει να εκτελείται όσο αυτή αξιολογείται ως `true`.
3. Ο επαναλήπτης: εκτελείται μετά από κάθε επανάληψη του βρόχου. Συνήθως χρησιμοποιείται για να τροποποιήσει (συχνά: να αυξήσει/μειώσει) τη μεταβλητή ή τις μεταβλητές του βρόχου.
4. Το σώμα: ο κώδικας που εκτελείται σε κάθε επανάληψη του βρόχου.

## Βρόχοι `foreach`

Το γεγονός ότι ένας πίνακας είναι επίσης μια _συλλογή_ σημαίνει ότι, εκτός από την πρόσβαση σε τιμές με θέση, μπορείς να διατρέξεις _όλες_ τις τιμές του χρησιμοποιώντας έναν βρόχο `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
