# Σχετικά

Το [Gleam](https://gleam.run/) είναι σχεδιασμένο με τις παρακάτω αρχές κατά νου:

## Να είναι ασφαλές

Ένα εκφραστικό σύστημα τύπων, εμπνευσμένο από την οικογένεια γλωσσών ML, μας βοηθά να εντοπίζουμε και να αποτρέπουμε bugs κατά τη μεταγλώττιση, πολύ πριν φτάσουν στους χρήστες σου.

Για τα προβλήματα που το σύστημα τύπων δεν μπορεί να λύσει (όπως το να χτυπηθεί ο server σου από κεραυνό), το runtime [Erlang/OTP](https://learnyousomeerlang.com/what-is-otp) παρέχει καλά δοκιμασμένους μηχανισμούς για να αντιμετωπίζονται με χάρη οι αποτυχίες.

## Να είναι φιλικό

Το κυνήγι των bugs μπορεί να είναι αγχωτικό, γι' αυτό η ανατροφοδότηση από τον μεταγλωττιστή πρέπει να είναι όσο πιο καθαρή και χρήσιμη γίνεται. Θέλουμε να περνάμε περισσότερο χρόνο δουλεύοντας την εφαρμογή μας και λιγότερο ψάχνοντας για τυπογραφικά λάθη ή προσπαθώντας να αποκρυπτογραφήσουμε ακατανόητα μηνύματα σφάλματος.

Ως κοινότητα θέλουμε επίσης να είμαστε φιλικοί. Άνθρωποι κάθε καταγωγής, φύλου και επιπέδου εμπειρίας είναι ευπρόσδεκτοι και πρέπει να αντιμετωπίζονται με ίσο σεβασμό.

## Να είναι αποδοτικό

Το runtime Erlang/OTP είναι γνωστό για την ταχύτητά του και την ικανότητά του να κλιμακώνεται, επιτρέποντας σε οργανισμούς όπως η WhatsApp και η Ericsson να χειρίζονται αξιόπιστα τεράστιους όγκους κίνησης με χαμηλή καθυστέρηση. Το Gleam θα πρέπει να επωφελείται πλήρως από αυτό το runtime και να είναι τόσο γρήγορο όσο άλλες γλώσσες της BEAM, όπως η Erlang και η Elixir.

## Να είναι καλός πολίτης

Το Gleam κάνει εύκολη τη χρήση κώδικα γραμμένου σε άλλες γλώσσες της BEAM, όπως [Erlang](http://www.erlang.org/), [Elixir](https://elixir-lang.org/) και [LFE](http://lfe.io/), οπότε υπάρχει ένα πλούσιο οικοσύστημα εργαλείων και βιβλιοθηκών που μπορούν να αξιοποιήσουν οι χρήστες του Gleam.

Οι χρήστες άλλων γλωσσών της BEAM θα πρέπει με τη σειρά τους να μπορούν να αξιοποιούν το Gleam, είτε χρησιμοποιώντας διαφανώς βιβλιοθήκες γραμμένες σε Gleam, είτε προσθέτοντας modules Gleam στο υπάρχον έργο τους με ελάχιστη φασαρία.
