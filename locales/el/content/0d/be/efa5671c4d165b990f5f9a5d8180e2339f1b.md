# Σχετικά

Οι [προσαρμοσμένοι τύποι][custom-types] στην Elm αντιπροσωπεύουν έναν σταθερό αριθμό ονομασμένων περιπτώσεων. Κάθε τιμή αντιστοιχεί σε ακριβώς μία από τις ονομασμένες περιπτώσεις. Σε άλλες γλώσσες / περιβάλλοντα αυτοί είναι γνωστοί ως _τύποι αθροίσματος_, _διακριτές ενώσεις_, _επισημασμένες ενώσεις_ και _αλγεβρικοί τύποι δεδομένων_.

Κάθε περίπτωση μιας διακριτής ένωσης μπορεί προαιρετικά να έχει δεδομένα συνδεδεμένα μαζί της, και διαφορετικές περιπτώσεις μπορούν να έχουν διαφορετικούς τύπους δεδομένων. Αν καμία από τις περιπτώσεις δεν έχει δεδομένα συνδεδεμένα μαζί της, η διακριτή ένωση μοιάζει με αυτό που άλλες γλώσσες συνήθως αποκαλούν _απαρίθμηση_ (ή _enum_).

Ένας προσαρμοσμένος τύπος ορίζεται με τη λέξη-κλειδί `type` και απαιτεί ελάχιστη σύνταξη. Αποτελούν μία από τις πιο σημαντικές τεχνικές στον προγραμματισμό με Elm και χρησιμοποιούνται για να ταιριάζουν ακριβώς οι δυνατές τιμές στον κώδικα με τις έγκυρες τιμές στην πραγματική ζωή, κάτι που δεν αφήνει περιθώριο για άκυρα δεδομένα και κάνει τις [αδύνατες καταστάσεις αδύνατο να αναπαρασταθούν στον κώδικα][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Μπορείς να δημιουργήσεις μια τιμή για μια συγκεκριμένη περίπτωση αναφέροντας το όνομά της (`Spring`), όταν αυτή ορίζεται στο ίδιο module, ή έχει εισαχθεί με σύνταξη τύπου `import SeasonModule exposing (Season(..))`, ή αναφέροντας το πλήρως προσδιορισμένο όνομά της (`Season.Spring`) όταν έχει εισαχθεί με σύνταξη τύπου `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Οι προσαρμοσμένοι τύποι, όπως και τα πάντα στην Elm, έχουν _δομική ισότητα_, που σημαίνει ότι δύο τιμές για την ίδια περίπτωση και με τα ίδια (προαιρετικά) δεδομένα είναι ισοδύναμες.

Ο προτιμώμενος τρόπος για να δουλέψεις με προσαρμοσμένους τύπους είναι η [αντιστοίχιση προτύπων][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
