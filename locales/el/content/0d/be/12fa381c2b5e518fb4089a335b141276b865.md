# Εισαγωγή

Οι συναρτήσεις μπορούν να δηλώνουν προεπιλεγμένες τιμές για ένα ή περισσότερα ορίσματα. Ας δούμε αυτή τη συνάρτηση:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Όταν γίνεται μεταγλώττιση, η Elixir δημιουργεί έναν ορισμό συνάρτησης για το `number/0` (χωρίς ορίσματα) και το `number/1` (ένα όρισμα).

Αν περισσότερα από ένα ορίσματα έχουν προεπιλεγμένες τιμές, οι προεπιλεγμένες τιμές εφαρμόζονται στη συνάρτηση από αριστερά προς τα δεξιά, για να συμπληρώσουν τα ορίσματα που λείπουν.

Αν η συνάρτηση έχει περισσότερες από μία ρήτρες, τα προεπιλεγμένα ορίσματα πρέπει να ορίζονται σε μια κεφαλίδα συνάρτησης (μια συνάρτηση χωρίς σώμα) πριν από τις ρήτρες της συνάρτησης:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
