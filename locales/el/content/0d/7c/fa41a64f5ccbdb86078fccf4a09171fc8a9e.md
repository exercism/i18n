# Σχετικά

Οποιαδήποτε τιμή μπορεί να είναι ένα σφάλμα. Το `throw` (στο `kernel`) στέλνει σήμα· η επίδραση στην στοίβα της τρέχουσας λέξης εγκαταλείπεται και ο έλεγχος ξετυλίγεται ως το πλησιέστερο `recover` που τον περιβάλλει.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

Το `ERROR:` είναι μια λέξη ανάλυσης που ορίζει με μια κίνηση μια κλάση πλειάδας σφάλματος *και* μια λέξη κατασκευαστή:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Έτσι, κάθε προσαρμοσμένο σφάλμα αποκτά τη δική του κλάση, έναν φιλικό κατασκευαστή που πετάει το σφάλμα, και ένα κατηγόρημα κλάσης (`name?`) για να ελέγχεις τα σφάλματα που έχεις πιάσει:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Για καθαρισμό τύπου finally, δες το `cleanup` στο `continuations`. Για συνθήκες με δυνατότητα επανεκκίνησης, δες το `condition`.
