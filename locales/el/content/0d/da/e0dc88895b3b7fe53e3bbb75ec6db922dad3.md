# Εισαγωγή

## Τα βασικά

Θα υποθέσουμε ότι είσαι εξοικειωμένος με τη σύνταξη και τους τύπους δεδομένων της JSON.

Το jq λειτουργεί περνώντας τα δεδομένα JSON που έρχονται μέσα από _μία μόνο έκφραση_ (γραμμένη ως _σωλήνωση φίλτρων_) για να πετύχεις τα επιθυμητά μετασχηματισμένα δεδομένα.

<!-- prettier-ignore -->
~~~~exercism/note
Η γλώσσα `jq` υλοποιείται από το _πρόγραμμα_ `jq`.
Αυτό το πρόγραμμα παρέχει αρκετές βολικές επιλογές γραμμής εντολών που ελέγχουν πώς καταναλώνεται η είσοδος και πώς παρουσιάζεται η έξοδος.

Στα παρακάτω παραδείγματα θα συναντήσεις:

- `-n` ή `--null-input`

    Κανονικά, στο πρόγραμμα `jq` δίνεται ένα αρχείο για ανάγνωση ή στέλνεις δεδομένα στην είσοδό του.
    Η επιλογή `--null-input` σου επιτρέπει να παράγεις δεδομένα JSON χωρίς καμία είσοδο.

- `-c` ή `--compact-output`

    Το `jq` μορφοποιεί όμορφα την έξοδό του από προεπιλογή.
    Είναι εξαιρετικά χρήσιμο για τους ανθρώπους να βλέπουν τα δεδομένα όταν είναι ωραία μορφοποιημένα.
    Ωστόσο, αυτό δεν είναι απαραίτητο για τις μηχανές: η επιλογή `--compact-output` αφαιρεί τα κενά μορφοποίησης για να ελαχιστοποιήσει το μέγεθος του JSON που προκύπτει.

- `-f filename` ή `--from-file filename`

    Διάβασε το πρόγραμμα `jq` από το `filename` αντί να το δώσεις στη γραμμή εντολών.
    Τόσο το `sed` όσο και το `awk` χρησιμοποιούν την επιλογή `-f` για τον ίδιο σκοπό.
    Θα το δεις να χρησιμοποιείται στα scripts δοκιμών για τις ασκήσεις εξάσκησης.

Το υπόλοιπο αυτής της ενότητας θα επικεντρωθεί στη _γλώσσα_ `jq`.
~~~~

### Φίλτρα και σωλήνες

Τα **φίλτρα** είναι επίσης γνωστά ως **εκφράσεις**.

Ένα _φίλτρο_ παίρνει μια είσοδο και παράγει μια έξοδο.
Όπως ακριβώς δουλεύεις σε ένα κέλυφος unix, μπορείς να ενώσεις _φίλτρα_ με έναν σωλήνα `|` για να συνδέσεις την έξοδο ενός _φίλτρου_ με την είσοδο ενός άλλου.

### Το φίλτρο ταυτότητας: `.`

Αυτό είναι το πιο απλό _φίλτρο_.
Απλώς περνάει την είσοδό του στην έξοδό του.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### Πίνακες

Αυτή θα είναι μια γρήγορη εισαγωγή στην εργασία με **πίνακες**.
Θα καλύψουμε αυτό το θέμα με περισσότερες λεπτομέρειες αργότερα.

Τα στοιχεία ενός _πίνακα_ προσπελαύνονται με αγκύλες και η αρίθμησή τους ξεκινά από το μηδέν.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Ένα _φίλτρο_ μπορεί να φτιάξει έναν _πίνακα_ τυλίγοντας μια έκφραση μέσα σε `[` και `]`

- με μια γνωστή λίστα στοιχείων:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- για να συλλέξει μια ροή στοιχείων: για παράδειγμα,
  το `range` είναι μια συνάρτηση που παράγει μια ροή αριθμών

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Χρησιμοποιώντας το `[]` συλλέγεις τα αποτελέσματα της έκφρασης σε έναν πίνακα

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### Το κόμμα είναι τελεστής

Το _κόμμα_ δεν είναι απλώς σύνταξη που χωρίζει στοιχεία _πίνακα_.
Το **κόμμα** είναι ένας **τελεστής** που ενώνει ροές.

Για παράδειγμα, το `[1, 2, 3]` είναι ένα _φίλτρο_ που χρησιμοποιεί τον κατασκευαστή _πίνακα_ `[]` για να συλλέξει το αποτέλεσμα της ένωσης των τριών εκφράσεων `1`, `2` και `3`.

Πρόσεξες τις άνω τελείες στο `range(10; 70; 15)` παραπάνω;
Επειδή τα _κόμματα_ έχουν συγκεκριμένο σκοπό στη γλώσσα `jq`, οι συναρτήσεις που παίρνουν πολλά ορίσματα χρησιμοποιούν άνω τελείες για να χωρίσουν τα ορίσματα.

### Αντικείμενα

Μια γρήγορη εισαγωγή στα **αντικείμενα**.

Όπως σε πολλές γλώσσες προγραμματισμού, χρησιμοποίησε τελείες για να προσπελάσεις τις ιδιότητες ενός _αντικειμένου_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Οι αγκύλες μπορούν να χρησιμοποιηθούν και για _αντικείμενα_, αλλά τότε χρειάζονται εισαγωγικά για τις κυριολεκτικές συμβολοσειρές.
Αυτός είναι ένας τρόπος να δουλέψεις με κλειδιά που περιέχουν κενά.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Μπορείς να κατασκευάσεις ένα _αντικείμενο_ με `{}` και ζεύγη `key: value`.
Τα εισαγωγικά δεν απαιτούνται γύρω από _κλειδιά_ που είναι "απλές" συμβολοσειρές.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

παράγει

```none
{
  "question": 54,
  "answer": 42
}
```

Για να αντιμετωπίσεις το _κλειδί_ ως _έκφραση_, πρέπει να το τυλίξεις σε παρενθέσεις (το παρακάτω επίσης παράγει το ίδιο αποτέλεσμα με πάνω).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### Σωληνώσεις

Για παράδειγμα, δίνεται το `file.json` που περιέχει

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Ας υπολογίσουμε το μήκος του _πίνακα_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

_Διοχετεύουμε_ την έξοδο της έκφρασης `.key2` ως είσοδο στο `length`, το οποίο, όπως είναι φυσικό, παράγει τον αριθμό των στοιχείων του _πίνακα_.

### Τα φίλτρα μπορούν να αγνοήσουν την είσοδό τους

Σε αυτό το παράδειγμα, τα δεδομένα εισόδου JSON αγνοούνται και δεν επηρεάζουν την έξοδο:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### Τα φίλτρα μπορούν να παράγουν ροές δεδομένων

Ένα _φίλτρο_ μπορεί να παράγει περισσότερες από μία τιμές.
Για παράδειγμα, το _φίλτρο_ `.[]` παράγει κάθε στοιχείο ενός _πίνακα_ ως ξεχωριστή τιμή:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Η διοχέτευση ενός τέτοιου _φίλτρου_ σε ένα άλλο θα εκτελέσει το δεύτερο _φίλτρο_ **_για κάθε τιμή_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Αυτό μοιάζει με σιωπηρή επανάληψη.
Μόλις καταλάβεις αυτή την τεχνική, θα συνειδητοποιήσεις ότι πολύ ισχυρά _φίλτρα_ `jq` μπορούν να είναι πολύ συνοπτικά.

### Παρενθέσεις

Οι **παρενθέσεις** χρησιμοποιούνται για να ομαδοποιήσουν υποεκφράσεις και να επιβάλουν τη σειρά των πράξεων, όπως ακριβώς σε άλλες γλώσσες.
Στο `jq`, η ανάγκη γι' αυτές μπορεί να φαίνεται κάπως αναπάντεχη.

Για παράδειγμα, ας υποθέσουμε ότι θέλουμε να κατασκευάσουμε έναν _πίνακα_ με 2 στοιχεία: την τετραγωνική ρίζα του 9 και το _e_ υψωμένο στη δύναμη 1.
Οι δύο επιμέρους εκφράσεις είναι `9 | sqrt` και `1 | exp`.
Περιμένουμε η έξοδος να είναι ο _πίνακας_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Γιατί δεν πήραμε αυτό που περιμέναμε; Το `jq` το ερμηνεύει ως εξής:

```jq
[ ((9|sqrt), 1) | exp ]
```

Το `jq` φτιάχνει μια ροή δύο στοιχείων (`3` και `1`), τα οποία δίνονται το καθένα στο `exp`.

Πρέπει να διασφαλίσουμε ότι το `exp` παίρνει μόνο έναν αριθμό ως είσοδο.
Με άλλα λόγια, πρέπει να επιβάλουμε ο σωλήνας να αξιολογείται πριν από το κόμμα.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### Συναρτήσεις και τελεστές

Χωρίς να μπούμε σε μεγάλο βάθος (οι συναρτήσεις θα είναι θέμα για άλλη άσκηση), ορίστε μερικές χρήσιμες ενσωματωμένες συναρτήσεις:

- `length`

  Με έναν πίνακα ως είσοδο, παράγει τον αριθμό των στοιχείων του πίνακα.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Αυτός ο τελεστής κάνει διαφορετικά πράγματα ανάλογα με τον τύπο των τελεστέων του:
  προσθέτει αριθμούς,
  συνενώνει συμβολοσειρές,
  προσαρτά πίνακες,
  συγχωνεύει αντικείμενα.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  Το `add` είναι μια συνάρτηση που παίρνει έναν πίνακα και επιστρέφει ένα στοιχείο με όλα τα στοιχεία αθροισμένα σύμφωνα με τους κανόνες του `+`.
  Το `[1, 2, 3] | add` παράγει `6`.

- `map`

  Με έναν πίνακα ως είσοδο και ένα φίλτρο ως όρισμα, παράγει έναν πίνακα όπου το φίλτρο εφαρμόζεται σε κάθε στοιχείο

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Με _κάποια_ είσοδο και ένα φίλτρο ως όρισμα:
  - αν το φίλτρο που εφαρμόζεται στο όρισμα οδηγεί σε _αληθή_ τιμή, παράγει την είσοδο αμετάβλητη
  - διαφορετικά, δεν παράγει _τίποτα_ (όχι την τιμή `null`, πραγματικά καμία έξοδο)

  Για παράδειγμα, δίνονται κάποιοι αριθμοί, διάλεξε αυτούς που διαιρούνται με το 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Θυμήσου ότι το `range` παράγει μια _ροή_ αριθμών.
  Το `select` θα καλείται μία φορά για κάθε αριθμό.
  Παράγονται μόνο οι αριθμοί που "περνούν" την έκφραση.

  Συχνά χρειάζεται να διαλέξεις στοιχεία ενός πίνακα.
  Υπάρχουν μερικοί τρόποι να το κάνεις αυτό.

  Με είσοδο `["Anne", "Bob", "Cathy", "Dave"]`, διάλεξε τα ονόματα που έχουν μήκος 4.
  - χρησιμοποίησε το `map` και το `select` μαζί

    ```jq
    map(select(length == 4))
    ```

  - σπάσε τον πίνακα στα στοιχεία του, εφάρμοσε `select` σε αυτή τη ροή και μάζεψε τα αποτελέσματα

    ```jq
    [ .[] | select(length == 4) ]
    ```

### Σχόλια

Τα σχόλια ξεκινούν με τον χαρακτήρα `#` και συνεχίζουν μέχρι το τέλος της γραμμής.
