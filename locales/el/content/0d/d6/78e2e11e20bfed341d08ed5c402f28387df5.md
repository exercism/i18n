# Οδηγίες

Ο διευθυντής σκηνής θέλει το σενάριο της πρόβας δακτυλογραφημένο, και αρκετά
μέρη του φτιάχνονται επαναλαμβάνοντας ή ενώνοντας πράγματα μεταξύ τους.

Και οι τέσσερις εργασίες μπαίνουν στην κλάση `REHEARSAL_SCRIPT`.

## 1. Επανάλαβε ένα σύνθημα

Με δεδομένο ένα σύνθημα και έναν αριθμό, επίστρεψε το σύνθημα τόσες φορές,
χωρίς τίποτα ανάμεσα.

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

Αν επαναλάβεις κάτι μηδέν φορές, παίρνεις την κενή συμβολοσειρά.

## 2. Τα αρχικά του θιάσου

Με δεδομένη τη λίστα του θιάσου, επίστρεψε το πρώτο γράμμα κάθε ονόματος,
ενωμένα μεταξύ τους.

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. Αρίθμησε τις ατάκες

Με δεδομένες τις ατάκες μιας σκηνής, αρίθμησέ τις ξεκινώντας από το ένα,
καθεμιά στη δική της γραμμή.

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

Υπάρχει μια νέα γραμμή *ανάμεσα* στις ατάκες και καμία μετά την τελευταία. Μια
σκηνή χωρίς ατάκες είναι η κενή συμβολοσειρά.

## 4. Φώναξε μια ατάκα

Επίστρεψε μια ατάκα με όλα τα γράμματα κεφαλαία.

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
