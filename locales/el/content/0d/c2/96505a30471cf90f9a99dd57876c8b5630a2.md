# Οδηγίες

Ενώ ετοιμάζεσαι να ψήσεις μπισκότα για τους φίλους σου, διαπίστωσες ότι πρέπει να μετατρέψεις κάποιες από τις μετρήσεις που χρησιμοποιεί η συνταγή.
Γνωρίζοντας μόνο το μετρικό σύστημα, πρέπει να βρεις έναν τρόπο να μετατρέψεις συνηθισμένες αμερικανικές μετρήσεις ψησίματος σε χιλιοστόλιτρα (mL) για δική σου ευκολία.

Χρησιμοποίησε αυτόν τον πίνακα μετατροπών για τη λύση σου:

| Μονάδα προς μετατροπή | όγκος | σε χιλιοστόλιτρα (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| αμερικανικό φλιτζάνι | 1 | 240 |
| αμερικανική υγρή ουγγιά | 1 | 30 |
| αμερικανικό κουταλάκι του γλυκού | 1 | 5 |
| αμερικανική κουταλιά της σούπας | 1 | 15 |

Καθώς είσαι ένας ταλαντούχος εκπαιδευόμενος προγραμματιστής, αποφασίζεις να χρησιμοποιήσεις τα χιλιοστόλιτρα ως ενδιάμεση μονάδα για να διευκολύνεις τη μετατροπή από οποιαδήποτε μονάδα της λίστας σε οποιαδήποτε άλλη (ακόμη και στην ίδια).

## 1. Πάρε το αριθμητικό μέρος από ένα ζεύγος όγκου

Υλοποίησε τη μέθοδο `KitchenCalculator.get_volume`.
Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να επιστρέφει μόνο το αριθμητικό μέρος.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Μετέτρεψε το ζεύγος όγκου σε χιλιοστόλιτρα

Υλοποίησε τη μέθοδο `KitchenCalculator.to_milliliter`.
Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να μετατρέπει τον όγκο σε χιλιοστόλιτρα χρησιμοποιώντας τον πίνακα μετατροπών.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Μετέτρεψε το ζεύγος όγκου από χιλιοστόλιτρα σε άλλη μονάδα

Υλοποίησε τη μέθοδο `KitchenCalculator.from_milliliter`. 
Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον όγκο στην επιθυμητή μονάδα χρησιμοποιώντας τον πίνακα μετατροπών.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Μετέτρεψε από οποιαδήποτε μονάδα σε οποιαδήποτε μονάδα

Υλοποίησε τη μέθοδο `KitchenCalculator.convert`.
Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον δεδομένο όγκο στην επιθυμητή μονάδα.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
