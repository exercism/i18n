# Υποδείξεις

## 1. Προσδιόρισε πόση ώρα χρειάζεται για να αναμείξεις έναν χυμό

- Κοίτα ξανά την έννοια [Switch][concept-switch] για τρόπους προσέγγισης.

## 2. Αναπλήρωσε το απόθεμα από φετάκια λάιμ

- Κάνε βρόχο μέχρι να ικανοποιηθεί μία από τις συνθήκες στις οδηγίες.
- Μπορεί να σου φανεί χρήσιμο, αν και δεν είναι απαραίτητο, να έχεις μια μικρή βοηθητική συνάρτηση που συσχετίζει τα μεγέθη των λάιμ με τον αριθμό των φετιών που βγάζουν.
- Και πάλι, η έννοια [Switch][concept-switch] μπορεί να σου υποδείξει βολικές προσεγγίσεις.
- Επίστρεψε πόσα λάιμ κόπηκαν πραγματικά.

## 3. Κάνε λίστα με τους χρόνους ανάμιξης κάθε παραγγελίας στην ουρά

- Σε αυτό το στάδιο της ύλης, η ευκολότερη προσέγγιση χρησιμοποιεί έναν `for` βρόχο πάνω στο `orders`, αλλά μπορεί να γίνει και με το `seq_along`.
- Κάποια προηγούμενη εργασία μπορεί να σου δώσει μια χρήσιμη συνάρτηση.
- [`print()`][print-function] τους χρόνους με τη σειρά (δες την εισαγωγή για παράδειγμα).
- Δε χρειάζεται να επιστρέψεις τίποτα για αυτή την άσκηση.

## 4. Ολοκλήρωσε τη βάρδια

- Κάνε βρόχο όσο υπάρχουν παραγγελίες και έχει απομείνει λίγος χρόνος.
- Επίστρεψε ένα διάνυσμα με όσες παραγγελίες δεν ξεκίνησαν.
