# Σχετικά

Η JavaScript έχει έναν τελεστή αύξησης και έναν τελεστή μείωσης.
Τροποποιούν μια μεταβλητή επί τόπου.
Το `++` προσθέτει ένα σε έναν αριθμό, ενώ το `--` αφαιρεί ένα από έναν αριθμό.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

Το παραπάνω παράδειγμα δείχνει τον μεταθεματικό τελεστή αύξησης/μείωσης.
Σε αυτή την περίπτωση ο τελεστής τοποθετείται μετά τη μεταβλητή και η τιμή επιστροφής της έκφρασης είναι η τιμή της μεταβλητής _πριν_ από την αύξηση/μείωση.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

Υπάρχει επίσης η προθεματική παραλλαγή, όπου ο τελεστής τοποθετείται πριν από τη μεταβλητή.
Τότε η τιμή επιστροφής είναι η τιμή της μεταβλητής _μετά_ την αύξηση/μείωση.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
