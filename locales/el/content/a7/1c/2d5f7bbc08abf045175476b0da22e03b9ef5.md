# Οδηγίες

Η Lucy, η εξωγήινη της Lisp, αγαπάει τους αριθμούς και πιστεύει ότι μερικοί από αυτούς είναι "υπέροχοι".

Σου ζητάει να τη βοηθήσεις να γράψει συναρτήσεις που κάνουν τους αριθμούς πιο υπέροχους.

Το τι θεωρεί η Lucy υπέροχο έναν αριθμό μπορεί να αλλάξει, οπότε οι συναρτήσεις θα πρέπει να είναι ευέλικτες.

## 1. Κάν' τους υπέροχους

Για να μετατρέψεις μια λίστα αριθμών σε μια λίστα με πιο υπέροχους αριθμούς, θα χρειαστεί να γράψεις μια συνάρτηση `make-magnificent-maybe` που παίρνει μια συνάρτηση για εφαρμογή στους αριθμούς και μια λίστα αριθμών.
Θα πρέπει να αξιολογείται σε μια λίστα αριθμών που είναι πιο υπέροχοι (σύμφωνα με τη συνάρτηση που δίνεις).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Μόνο οι καλύτεροι

Αφού (ελπίζουμε) κάνει τους αριθμούς πιο υπέροχους, η Lucy θέλει να δει μόνο τους αριθμούς που είναι πραγματικά υπέροχοι.

Ξέρει σίγουρα ότι το 1 *ποτέ* δεν είναι υπέροχο, οπότε θα χρειαστεί απλώς να το αφαιρέσεις.

Αλλά κατά τα άλλα, η Lucy αλλάζει γνώμη καμιά φορά, οπότε και πάλι θα σου δώσει μια συνάρτηση που θα σου πει αν ένας αριθμός είναι υπέροχος ή όχι.

Θα χρειαστεί να γράψεις μια συνάρτηση `only-the-best` που παίρνει μια συνάρτηση και μια λίστα αριθμών και επιστρέφει μόνο τους καλύτερους αριθμούς (όχι το `1` και όχι αριθμούς για τους οποίους η συνάρτηση αξιολογείται ως αληθής).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
