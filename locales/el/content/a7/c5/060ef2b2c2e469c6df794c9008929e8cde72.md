# Εισαγωγή

Αυτή η άσκηση εισάγει τις συνθήκες: την επιλογή ανάμεσα σε δύο ή περισσότερες εναλλακτικές ενέργειες με βάση μια τιμή. Χτίζει πάνω στις Boolean τιμές που γνώρισες στην [Παρείσφρηση της Annalyn][annalyns] και στην αριθμητική ακεραίων από τη [Μετατροπή νομίσματος][currency-conversion].

## Λέξεις σύγκρισης

Όλες βρίσκονται στο [`math`][math] (και στο [`kernel`][kernel] για το `=`):

```
=  ( x y -- ? )    ! equal
<  ( x y -- ? )    ! less than
<= ( x y -- ? )    ! less than or equal
>  ( x y -- ? )    ! greater than
>= ( x y -- ? )    ! greater than or equal
```

```factor
3 3 = .     ! => t
2 3 < .     ! => t
3 3 <= .    ! => t
3 4 = not . ! => t    (inequality: combine = with not)
```

Το `zero?` (στο [`math`][math]) είναι συντομογραφία για τον συνηθισμένο έλεγχο `0 =`: καταναλώνει τον αριθμό και βάζει στη στοίβα αν ήταν μηδέν:

```
zero? ( n -- ? )    ! t when n is 0
```

## Έλεγχοι εύρους

Το `between?` (στο [`math.order`][math.order]) ελέγχει αν μια τιμή πέφτει μέσα σε ένα κλειστό διάστημα. Είναι βολικό όταν μια ενέργεια εξαρτάται από το σε ποια ζώνη πέφτει ένας αριθμός:

```
between? ( x lo hi -- ? )    ! lo <= x <= hi (inclusive)
```

```factor
5 1 10 between? .    ! => t
0 1 10 between? .    ! => f
10 1 10 between? .   ! => t   (inclusive at both ends)
```

Συχνά θα το δεις ως κατηγόρημα του `cond`, όπως `dup 1 4 between?`, για να διαλέξεις κλάδο με βάση το εύρος και όχι μια μεμονωμένη τιμή.

## Παραθέσεις

Οι παραπάνω λέξεις σύγκρισης παράγουν Boolean τιμές. Για να *δράσεις* πάνω σε μια Boolean τιμή, δίνεις στη συνθήκη μία ή περισσότερες **παραθέσεις**. Μια παράθεση είναι ένα κομμάτι κώδικα τυλιγμένο σε αγκύλες, `[ ... ]`. Όταν τη γράφεις, βάζεις τον κώδικα στη στοίβα ως τιμή αντί να τον εκτελέσεις. Στη συνέχεια, μια λέξη όπως η `if` αποφασίζει ποια παράθεση θα εκτελεστεί.

```factor
[ neg ]   ! a quotation that negates the top of the stack
[ ]       ! the empty quotation — does nothing
```

Μια επόμενη άσκηση καλύπτει τις παραθέσεις πλήρως. Για την ώρα, διάβασε το `[ ... ]` ως "τον κώδικα που θα εκτελεστεί για αυτόν τον κλάδο".

## `if`, `when`, `unless`

Η `if` (στο [`kernel`][kernel]) παίρνει μια Boolean τιμή και δύο παραθέσεις. Εκτελεί την πρώτη παράθεση όταν η Boolean τιμή είναι αληθής και τη δεύτερη όταν είναι ψευδής:

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

Η `when` εκτελεί την παράθεσή της μόνο όταν η Boolean τιμή είναι αληθής· η `unless` μόνο όταν είναι ψευδής:

```
when   ( ? quot -- )
unless ( ? quot -- )
```

## `if*`, `when*`, και `unless*`

Τρεις παραλλαγές του kernel αντιμετωπίζουν τη Boolean τιμή ως *τιμή* που αξίζει να κρατηθεί όταν είναι αληθής, κάτι χρήσιμο όταν μια λέξη επιστρέφει "το πράγμα, ή `f`":

```
if*     ( ? true false -- )    ! truthy: true is called WITH ? on stack
when*   ( ? true       -- )    ! truthy: true is called WITH ? on stack
unless* ( ? false      -- )    ! falsy: false runs and pushes a default
```

Η `if*` είναι η μορφή με δύο κλάδους. Ο κλάδος της αλήθειας καλείται με την τιμή ακόμα στη στοίβα· ο κλάδος του ψεύδους καλείται χωρίς αυτή:

```factor
42 [ ] [ "nothing" ] if* .   ! prints 42
f  [ ] [ "nothing" ] if* .   ! prints "nothing"
```

Η `unless*` είναι το κλασικό μοτίβο "τιμή ή προεπιλογή". Αν η τιμή είναι αληθής, μένει ως έχει· αν είναι `f`, η τιμή απορρίπτεται και η παράθεση εκτελείται για να βάλει ένα υποκατάστατο στη στοίβα:

```factor
"hello" [ "anonymous" ] unless* .   ! => "hello"
f       [ "anonymous" ] unless* .   ! => "anonymous"
```

Η `when*` είναι η μορφή της `if*` με έναν κλάδο: εκτελεί την παράθεσή της, με την τιμή ακόμα στη στοίβα, μόνο όταν η τιμή είναι αληθής, και απλώς απορρίπτει την τιμή όταν είναι `f`. Χρησιμοποίησέ την για να ενσωματώσεις ένα αποτέλεσμα τύπου "το πράγμα, ή `f`" σε μια τιμή που χτίζεται, χωρίς να μπεις στον κόπο να χειριστείς την περίπτωση του `f`:

```factor
0 41 [ + ] when* .   ! => 41   (truthy: 41 added to the running total)
0 f  [ + ] when* .   ! => 0    (falsy: f dropped, total left untouched)
```

## `cond`

Όταν έχεις πολλές εναλλακτικές ενέργειες για να διαλέξεις, η `cond` (στο [`combinators`][combinators]) είναι η φυσική επιλογή. Παίρνει έναν πίνακα από ζεύγη `{ predicate body }` και εκτελεί το σώμα του πρώτου κατηγορήματος που δίνει μια αληθή τιμή:

```factor
USING: combinators ;

: classify ( n -- label )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

Μερικές λεπτομέρειες που αξίζει να προσέξεις:

- Τα ζεύγη δοκιμάζονται με τη σειρά. Κερδίζει το πρώτο που ταιριάζει.
- Μια καταχώριση χωρίς κατηγόρημα (μόνο μία παράθεση) στο τέλος λειτουργεί ως προεπιλογή.
- Κάθε κατηγόρημα εξετάζει την είσοδο αλλά πρέπει να αφήνει τη στοίβα δεδομένων όπως τη βρήκε· το συνηθισμένο μοτίβο είναι `dup ... <test>`.
- Το σώμα του ζεύγους που επιλέχθηκε δέχεται την ίδια στοίβα που είδε το κατηγόρημα, οπότε συνήθως ξεκινά κάνοντας `drop` στην είσοδο και βάζοντας το αποτέλεσμα στη στοίβα.
