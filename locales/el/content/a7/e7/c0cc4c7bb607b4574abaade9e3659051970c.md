# Οδηγίες

Μόλις μπήκες σε μια ομάδα που συντηρεί ένα pipeline δεδομένων βασισμένο στο jq.
Στην πρώτη σου συνεδρία προγραμματισμού σε ζεύγη, ο νέος σου συνάδελφος αρχίζει να αναρωτιέται:
*"Ξέρεις πώς λειτουργούν εσωτερικά τα `add`, `reverse` και `map`; Ας το εξερευνήσουμε. Δοκίμασε να τα υλοποιήσεις μόνος σου με αναδρομή, χωρίς τα ενσωματωμένα φίλτρα."*

## 1. Υλοποίησε μια συνάρτηση που προσθέτει τους αριθμούς ενός πίνακα

Θα ξαναϋλοποιήσουμε το ενσωματωμένο φίλτρο `add` για να εξασκηθούμε στην αναδρομή.
Η _βασική περίπτωση_ είναι ότι ένας κενός πίνακας έχει άθροισμα **μηδέν**.

Υλοποίησέ το μόνος σου με μια αναδρομική συνάρτηση, μη χρησιμοποιήσεις το ενσωματωμένο `add`.

```jq
[5, 4, 6, 10] | array_add     # => 25
```

## 2. Αντιστρέψε έναν πίνακα

Θα ξαναϋλοποιήσουμε το ενσωματωμένο φίλτρο `reverse`.
Η _βασική περίπτωση_ είναι ότι ένας κενός πίνακας αντιστρέφεται σε έναν κενό πίνακα.

Υλοποίησέ το μόνος σου με μια αναδρομική συνάρτηση, μη χρησιμοποιήσεις το ενσωματωμένο `reverse`.

```sh
[5, 4, 6, 10] | array_reverse   # => [10, 6, 4, 5]
```

## 3. Εφάρμοσε map σε έναν πίνακα

Θα ξαναϋλοποιήσουμε το ενσωματωμένο φίλτρο `map`.
Η συνάρτηση παίρνει ένα φίλτρο ως παράμετρο, εκτελεί αυτό το φίλτρο για κάθε στοιχείο του πίνακα εισόδου και επιστρέφει τα αποτελέσματα σε έναν νέο πίνακα.
Η _βασική περίπτωση_ είναι ότι ένας κενός πίνακας αντιστοιχίζεται σε έναν κενό πίνακα.

Υλοποίησέ το μόνος σου με μια αναδρομική συνάρτηση, μη χρησιμοποιήσεις το ενσωματωμένο `map`.

```sh
[5, 4, 6, 10] | array_map(. + 10)   # => [15, 14, 16, 20]
```
