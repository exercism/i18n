# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα διαδοχικά ψηφία.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] χωρίς ορίσματα.
- Πρέπει να επιστρέψεις μια [ακέραια τιμή][integers].

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία παράμετρο.
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι μια [ακέραια τιμή][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία παράμετρο.
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι μια [ακέραια τιμή][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον χρόνο που πέρασε σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με δύο παραμέτρους.
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια μέθοδο.
- Η παράμετρος της μεθόδου είναι μια [ακέραια τιμή][integers].
- Μπορείς να [καλέσεις][invocation] μία από τις άλλες μεθόδους που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.
