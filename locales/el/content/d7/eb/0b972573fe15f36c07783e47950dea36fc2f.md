# Σχετικά

Η Elixir αναπαριστά τις τιμές αληθής και ψευδής με τον τύπο boolean. Υπάρχουν μόνο δύο τιμές: `true` και `false`. Αυτές οι τιμές μπορούν να συνδυαστούν με τελεστές boolean ([`and/2`][strict-and], [`or/2`][strict-or], [`not/1`][strict-not]):

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

Οι τελεστές [`and/2`][strict-and], [`or/2`][strict-or] και [`not/1`][strict-not] είναι αυστηρά boolean, που σημαίνει ότι απαιτούν το _πρώτο_ τους όρισμα να είναι boolean. Υπάρχουν επίσης ισοδύναμοι τελεστές boolean που λειτουργούν με ορίσματα κάθε τύπου: [`&&/2`][and], [`||/2`][or] και [`!/1`][not].

Οι τελεστές boolean χρησιμοποιούν _αξιολόγηση βραχυκυκλώματος_, που σημαίνει ότι η έκφραση στη δεξιά πλευρά του τελεστή αξιολογείται μόνο όταν χρειάζεται.

Κάθε τελεστής έχει διαφορετική προτεραιότητα: το `not/1` αξιολογείται πριν από το `and/2` και το `or/2`. Με τις παρενθέσεις μπορείς να αξιολογήσεις ένα μέρος της έκφρασης πριν από τα υπόλοιπα:

```elixir
not true and false
# => false

not (true and false)
# => true
```

Όταν γράφεις μια συνάρτηση που επιστρέφει τιμή boolean, είναι [ιδιωματικό να τελειώνει το όνομα της συνάρτησης][naming] με `?`. Την ίδια σύμβαση μπορείς να τη χρησιμοποιήσεις και για μεταβλητές που αποθηκεύουν τιμές boolean.

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
