# Σχετικά

Οι συμβολοσειρές στη Swift είναι μια συλλογή χαρακτήρων, όπου οι χαρακτήρες είναι, λίγο πολύ, ένα μεμονωμένο εκτυπώσιμο στοιχείο. Έτσι, οι συμβολοσειρές στη Swift μπορούν να περιέχουν χαρακτήρες Unicode και emoji.

Οι συμβολοσειρές δημιουργούνται εύκολα στη Swift μέσω κυριολεκτικών συμβολοσειρών. Τα κυριολεκτικά συμβολοσειρών είναι παρόμοια με αυτά που συναντάμε σε πολλές άλλες γλώσσες προγραμματισμού, χαρακτήρες που περικλείονται ανάμεσα σε ένα ζευγάρι διπλά εισαγωγικά (`"`). Ορισμένοι χαρακτήρες χρησιμοποιούν ειδικό συμβολισμό μέσα στις συμβολοσειρές, ώστε να μπορούν να αναπαρασταθούν σωστά, όπως ο χαρακτήρας αλλαγής γραμμής που γράφεται ως `\n` μέσα στις συμβολοσειρές ή ο χαρακτήρας διπλού εισαγωγικού που γράφεται ως `\"` μέσα σε μια συμβολοσειρά, ώστε ο μεταγλωττιστής να γνωρίζει ότι δεν είναι το διπλό εισαγωγικό που τερματίζει τη συμβολοσειρά.

Μια κενή συμβολοσειρά αναπαρίσταται από δύο διπλά εισαγωγικά χωρίς τίποτα ανάμεσά τους.

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
