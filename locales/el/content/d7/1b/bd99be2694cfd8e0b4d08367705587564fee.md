# Οδηγίες

Ο φίλος σου ο Kojo είναι μεγάλος λάτρης των αριθμών.
Έχει έναν μικρό ιστότοπο που λέγεται 'fun-with-numbers'.
Ο Kojo δεν είναι και τόσο καλός στον προγραμματισμό, γι’ αυτό σου ζήτησε βοήθεια.

Θα φτιάξεις δύο βοηθητικές συναρτήσεις για νέα παιχνίδια με αριθμούς στον ιστότοπο του Kojo και μια τρίτη για να ελέγχεις κάποια είσοδο που μπορεί να δώσει ο χρήστης.

## 1. Υπολόγισε το άθροισμα των αριθμών στον κουλοχέρη

Ένα από τα παιχνίδια στον ιστότοπο του Kojo μοιάζει με κουλοχέρη που δείχνει δύο ομάδες τροχών με ψηφία πάνω τους.
Κάθε ομάδα ψηφίων αντιπροσωπεύει έναν αριθμό.
Για τη μηχανική του παιχνιδιού, ο Kojo πρέπει να ξέρει το άθροισμα αυτών των δύο αριθμών.

Γράψε μια συνάρτηση `twoSum` που δέχεται δύο πίνακες ως παραμέτρους.
Κάθε πίνακας αποτελείται από έναν ή περισσότερους αριθμούς μεταξύ 0 και 9.
Η συνάρτηση πρέπει να ερμηνεύει κάθε πίνακα ως αριθμό και να επιστρέφει το άθροισμα αυτών των δύο αριθμών.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Προσδιόρισε αν ένας αριθμός είναι παλίνδρομος

Ένα άλλο παιχνίδι στον ιστότοπο είναι ένα μικρό κουίζ που λέγεται "Τυχεροί Αριθμοί".
Ο χρήστης μπορεί να εισάγει έναν αριθμό και μετά βλέπει αν ο αριθμός ανήκει σε κάποια μυστική ακολουθία ή μοτίβο.
Η ακολουθία ή το μοτίβο των "τυχερών αριθμών" αλλάζει κάθε μήνα και κάθε χρήστης έχει μόνο περιορισμένο αριθμό προσπαθειών για να το μαντέψει.

Οι τυχεροί αριθμοί αυτού του μήνα πρέπει να είναι αριθμοί που είναι παλίνδρομοι.
Οι παλινδρομικοί αριθμοί παραμένουν ίδιοι όταν αντιστρέφονται τα ψηφία τους.

Υλοποίησε τη νέα συνάρτηση `luckyNumber` που δέχεται έναν αριθμό ως παράμετρο.
Η συνάρτηση πρέπει να επιστρέφει `true` αν ο αριθμός είναι παλίνδρομος και `false` διαφορετικά.
Ο αριθμός εισόδου θα είναι πάντα θετικός ακέραιος.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Δημιούργησε ένα μήνυμα σφάλματος για μη έγκυρη είσοδο του χρήστη

Σε διάφορα σημεία του ιστότοπου υπάρχουν πεδία εισαγωγής όπου οι χρήστες μπορούν να εισάγουν αριθμούς και να πατήσουν ένα κουμπί για να ενεργοποιήσουν κάποια ενέργεια.
Ο Kojo θέλει να βελτιώσει την εμπειρία χρήσης του ιστότοπού του.
Θέλει να εμφανίζει ένα μήνυμα σφάλματος σε περίπτωση που ο χρήστης πατήσει το κουμπί αλλά το πεδίο περιέχει μια μη έγκυρη τιμή εισόδου.

Ορίστε μερικές ακόμη πληροφορίες για το πώς παρέχεται η τιμή ενός πεδίου εισαγωγής.

- Αν ο χρήστης πληκτρολογήσει κάτι σε ένα πεδίο, η σχετική τιμή είναι πάντα συμβολοσειρά, ακόμη κι αν ο χρήστης πληκτρολόγησε μόνο αριθμούς.
- Αν ο χρήστης πληκτρολογήσει κάτι αλλά μετά το διαγράψει, η μεταβλητή θα είναι κενή συμβολοσειρά.
- Προτού καν ο χρήστης αρχίσει να πληκτρολογεί, η μεταβλητή μπορεί να είναι `undefined` ή `null`.

Γράψε μια συνάρτηση `errorMessage` που δέχεται την είσοδο του χρήστη ως παράμετρο.
Αν ο χρήστης δεν έδωσε καμία είσοδο, η `errorMessage` πρέπει να επιστρέφει `'Required field'`.
Αν η είσοδος δεν αντιπροσωπεύει έναν μη μηδενικό αριθμό (σύμφωνα με τους κανόνες μετατροπής της JavaScript), πρέπει να επιστρέφεται `'Must be a number besides 0'`.
Σε όλες τις άλλες περιπτώσεις, μπορείς να υποθέσεις ότι η είσοδος είναι έγκυρη και η τιμή επιστροφής πρέπει να είναι κενή συμβολοσειρά.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
