# Τεστ

## Εκτέλεση των τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την παρακάτω εντολή:

```bash
make
```

## Επίλυση της άσκησης

Το να λύσεις μια άσκηση σημαίνει να περάσεις όλα τα τεστ της. Από προεπιλογή, όταν τρέχεις τα τεστ εκτελείται μόνο ένα τεστ (το πρώτο). Αυτό είναι σκόπιμο, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσει αυτό το ένα τεστ. Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ αφαιρώντας τη γραμμή `TEST_IGNORE()`. Όταν ενεργοποιηθούν όλα τα τεστ και η υλοποίησή σου τα περάσει όλα, θα έχεις λύσει την άσκηση!
