# Αυτοματοποιημένη ανατροφοδότηση

Όταν υποβάλλεις μια λύση, το Exercism θα αναλύσει αυτόματα τη λύση στο παρασκήνιο, αναζητώντας γνωστά προβλήματα για τα οποία μπορούμε να δώσουμε ανατροφοδότηση.
Τυχόν ανατροφοδότηση που συλλέγεται κατά τη διάρκεια αυτής της ανάλυσης θα εμφανίζεται αυτόματα στη σελίδα της επανάληψης που υπέβαλες.

## Τι γίνεται αν δουλεύω τοπικά χρησιμοποιώντας τη γραμμή εντολών;

Επειδή η αυτοματοποιημένη ανατροφοδότηση δημιουργείται μόνο για λύσεις που έχουν υποβληθεί, αν χρησιμοποιείς τη γραμμή εντολών, πρέπει πρώτα να υποβάλεις τη λύση και μετά να ελέγξεις τη σελίδα της λύσης στον ιστότοπο για να δεις αν υπάρχει αυτοματοποιημένη ανατροφοδότηση.
