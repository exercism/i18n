# Οδηγίες

Η νοσταλγία σου για τις κάρτες Blorkemon™️ δεν δείχνει σημάδια υποχώρησης, άρχισες μάλιστα να τις μαζεύεις ξανά και βάζεις και τους φίλους σου να συμμετέχουν.

Σε αυτή την άσκηση, μια συλλογή `Card` αναπαρίσταται με `Set Card`, αφού οι διπλότυπες κάρτες δεν έχουν σημασία όταν ο στόχος σου είναι να αποκτήσεις όλες τις υπάρχουσες κάρτες.

## 1. Ξεκίνα μια συλλογή

Θέλεις πραγματικά οι φίλοι σου να μπουν στην τρέλα σου με τα Blorkemon™️, και ο καλύτερος τρόπος είναι να ξεκινήσεις τη συλλογή τους χαρίζοντάς τους μία κάρτα.

Υλοποίησε τη `newCollection`, η οποία μετατρέπει μια κάρτα σε συλλογή.

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. Μεγάλωσε τη συλλογή

Μόλις αποκτήσεις μια συλλογή, αυτή αποκτά δική της ζωή και πρέπει να μεγαλώσει.

Υλοποίησε τη `addCard`, η οποία παίρνει μια `Card` και μια συλλογή και επιστρέφει μια `Tuple` με δύο τιμές: μια `Bool` που δείχνει αν η `Card` ήταν ήδη στη συλλογή, και τη συλλογή με την κάρτα προσθεμένη.

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. Ξεκίνα τις ανταλλαγές

Τώρα που οι φίλοι σου έχουν ξανατρελαθεί με τα Blorkemon™️, μπορείς να το εκμεταλλευτείς για να μεγαλώσεις τη δική σου συλλογή ανταλλάσσοντας κάρτες.

Δεν αξίζει κάθε ανταλλαγή, ούτε είναι πάντα εφικτή.
Δεν μπορείς να ανταλλάξεις μια κάρτα που δεν έχεις, και δεν πρέπει να ανταλλάξεις μια κάρτα με μια που έχεις ήδη.

Υλοποίησε τη `tradeCard`, η οποία παίρνει δύο κάρτες προς ανταλλαγή (τη δική σου και τη δική τους) και την τρέχουσα συλλογή σου.
Η τιμή επιστροφής είναι μια `Tuple` με δύο τιμές: μια `Bool` που δηλώνει αν η ανταλλαγή είναι εφικτή και αξίζει τον κόπο, και τη συλλογή με την οποία θα κατέληγες αν έκανες την ανταλλαγή (ακόμα κι αν στην πραγματικότητα δεν είναι εφικτή).

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. Κάθε κάρτα μπορεί να υπάρχει μόνο μία φορά

Βρίσκεις έναν παλιό θησαυρό από κάρτες σε ένα παζάρι.
Πρέπει να ταξινομήσεις τις κάρτες και να αφαιρέσεις τα διπλότυπα, για να συγκρίνεις τη λίστα με τη συλλογή σου.

Υλοποίησε τη `removeDuplicates`, η οποία ταξινομεί μια λίστα με κάρτες και επιστρέφει μια λίστα με ταξινομημένες, μοναδικές κάρτες.

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. Κάρτες που δεν έχουν

Ώρα να νιώσεις καλά για τη συλλογή σου.

Υλοποίησε τη `extraCards`, η οποία παίρνει τη συλλογή σου και κάποια άλλη συλλογή, και επιστρέφει τον αριθμό των καρτών που δεν έχει η άλλη συλλογή.

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. Κάρτες που τις έχουν όλοι

Εσύ και οι φίλοι σου που λατρεύουν τα Blorkemon™️ μαζεύεστε και αναρωτιέστε ποιες κάρτες είναι οι πιο συνηθισμένες.

Υλοποίησε τη `boringCards`, η οποία παίρνει μια λίστα με συλλογές και επιστρέφει μια λίστα με ταξινομημένες κάρτες που τις έχουν όλες οι συλλογές.

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. Όλες οι κάρτες

Έχετε μαζί, εσύ και οι φίλοι σου, όλες τις κάρτες Blorkemon™️;

Υλοποίησε τη `totalCards`, η οποία παίρνει μια λίστα με συλλογές και επιστρέφει τον συνολικό αριθμό των διαφορετικών καρτών σε όλες τις συλλογές.

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. Τα γυαλιστερά κερδίζουν

Ο ανιψιός σου έρχεται σύντομα να σε επισκεφτεί και θέλεις να τον εντυπωσιάσεις.
Στα παιδιά αρέσουν τα γυαλιστερά, έτσι δεν είναι;
Οι κάρτες Blorkemon™️ μπορεί να είναι γυαλιστερές!

Υλοποίησε τη `splitShinyCards`, η οποία παίρνει μια συλλογή και επιστρέφει μια `Tuple` με δύο λίστες από ταξινομημένες κάρτες: μία με όλες τις κάρτες που αρχίζουν με `"Shiny"` και μία με τις υπόλοιπες κάρτες.

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
