# Εισαγωγή

Κλάσεις όπως οι `LocalDate` και `LocalDateTime` περιγράφουν ένα _σημείο_ στον χρόνο.
Το πακέτο `java.time` έχει επίσης δύο κλάσεις που περιγράφουν μια _ποσότητα_ χρόνου:

- Το `java.time.Period` είναι μια ποσότητα χρόνου σε έτη, μήνες και ημέρες, όπως "2 μήνες και 5 ημέρες".
- Το `java.time.Duration` είναι μια ποσότητα χρόνου σε ώρες, λεπτά, δευτερόλεπτα, χιλιοστά του δευτερολέπτου και νανοδευτερόλεπτα, όπως "1 ώρα και 30 λεπτά".

Ένα `Period` ακολουθεί το ημερολόγιο, οπότε χρησιμοποιείται με ημερομηνίες και ημερομηνίες-ώρες.
Ένα `Duration` μετρά ακριβή χρόνο, οπότε χρησιμοποιείται με ώρες και ημερομηνίες-ώρες, αλλά όχι με ημερομηνίες.

```exercism/note
Όπως και οι άλλες κλάσεις του `java.time`, τα `Period` και `Duration` είναι αμετάβλητα.
Οι μέθοδοι που μοιάζουν να τα αλλάζουν επιστρέφουν στην πραγματικότητα ένα _νέο_ στιγμιότυπο.
```

## `Period`

Ένα `Period` δημιουργείται με μία από τις στατικές μεθόδους δημιουργίας του:

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Το αποτέλεσμα της `toString()` χρησιμοποιεί τη σημειογραφία [ISO-8601][iso-8601-durations]: `P` (για "period") ακολουθούμενο από τον αριθμό των ετών (`Y`), των μηνών (`M`) και των ημερών (`D`).

Ένα `Period` μπορεί να προστεθεί ή να αφαιρεθεί από μια ημερομηνία:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Επειδή οι μήνες έχουν διαφορετικό μήκος, η πρόσθεση μηνών μπορεί να καταλήξει σε μια ημέρα που δεν υπάρχει.
Σε αυτή την περίπτωση, το αποτέλεσμα μετακινείται προς τα πίσω στην τελευταία έγκυρη ημέρα του μήνα:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

Η `Period.between()` επιστρέφει την περίοδο από τη μία ημερομηνία (συμπεριλαμβανομένης) έως την άλλη (μη συμπεριλαμβανομένης):

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## Μέτρηση μονάδων με το `ChronoUnit`

Ένα `Period` κρατά χωριστά τα έτη, τους μήνες και τις ημέρες του.
Έτσι, η `getDays()` επιστρέφει μόνο το _τμήμα_ των ημερών της περιόδου, όχι τον συνολικό αριθμό ημερών.
Για να μετρήσεις τον συνολικό αριθμό μιας μονάδας ανάμεσα σε δύο ημερομηνίες, χρησιμοποίησε τη μέθοδο `between()` του [`java.time.temporal.ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

Το αποτέλεσμα είναι αρνητικό όταν η δεύτερη ημερομηνία είναι πριν από την πρώτη:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

Ένα `Duration` δημιουργείται επίσης με στατικές μεθόδους δημιουργίας:

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Στη σημειογραφία ISO-8601, το `T` χωρίζει το τμήμα της ημερομηνίας από το τμήμα της ώρας, γι' αυτό οι διάρκειες γράφονται ως `PT...`.

Ένα `Duration` μπορεί να προστεθεί ή να αφαιρεθεί από μια ημερομηνία-ώρα:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

Η `Duration.between()` επιστρέφει την ακριβή ποσότητα χρόνου ανάμεσα σε δύο ημερομηνίες-ώρες:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

Ένα `Duration` μπορεί να μετατραπεί σε μία μόνο μονάδα με μεθόδους όπως οι `toHours()`, `toMinutes()` και `toSeconds()`.
Αυτές επιστρέφουν τη _συνολική_ ποσότητα σε αυτή τη μονάδα, στρογγυλοποιημένη προς τα κάτω:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

Για να χωρίσεις ένα `Duration` στα μέρη του, όπως σε ένα ρολόι, χρησιμοποίησε τις μεθόδους `toXxxPart()`:

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
