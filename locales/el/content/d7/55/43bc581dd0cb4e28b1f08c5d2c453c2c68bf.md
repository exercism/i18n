# Ετικέτες αναλυτή

Οι ετικέτες αναλυτή χρησιμοποιούνται για να προσδιορίσουν _πώς_ έχει λυθεί μια λύση.

Στη συνέχεια, αυτές οι ετικέτες μπορούν να χρησιμοποιηθούν για:

- Σύνδεση μιας λύσης με προσεγγίσεις
- Σύνδεση μιας λύσης με έννοιες
- Αναζήτηση λύσεων με συγκεκριμένες ετικέτες

## Μορφή

Μια ετικέτα είναι μια συμβολοσειρά που έχει τη μορφή: `<category>:<thing>`.

Υποστηρίζουμε τέσσερις διαφορετικές κατηγορίες, από το υψηλότερο προς το χαμηλότερο επίπεδο:

| Κατηγορία   | Περιγραφή                                       | Εξειδίκευση                                | Παραδείγματα                          |
| ----------- | ----------------------------------------------- | ------------------------------------------ | ------------------------------------- |
| `paradigm`  | Ένα [παράδειγμα προγραμματισμού][programming-paradigms] | Πολύ υψηλού επιπέδου, δεν είναι ειδικό για κάθε track | `imperative`, `functional` |
| `technique` | Μια τεχνική που χρησιμοποιείται                 | Υψηλού επιπέδου, οι περισσότερες δεν είναι ειδικές για κάθε track | `recursion`, `immutability` |
| `construct` | Μια δομή της γλώσσας                            | Πολλές δεν είναι ειδικές για κάθε track    | `bitwise-and`, `for-loop`             |
| `uses`      | Χρήση ειδική για τη γλώσσα, όπως τύποι ή μέθοδοι | Χαμηλού επιπέδου, ειδική για κάθε track    | `DateTime.add_seconds`, `IEnumerable` |

Μερικά παραδείγματα ετικετών:

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## Συνήθως χρησιμοποιούμενες ετικέτες

Αν και κάθε track είναι ελεύθερο να βάζει ετικέτες στις λύσεις του όπως κρίνει, σου προτείνουμε να χρησιμοποιείς όπου γίνεται την παρακάτω λίστα με τις συνήθως χρησιμοποιούμενες ετικέτες.
Η χρήση ενός κοινού συνόλου ετικετών θα μας επιτρέψει να κάνουμε μερικά έξυπνα πράγματα, όπως τη διασύνδεση λύσεων μεταξύ διαφορετικών track.

| `paradigm:functional`      | χρησιμοποιεί [συναρτησιακό προγραμματισμό][functional-programming]. |
| `paradigm:generic`         | χρησιμοποιεί [γενικευμένο προγραμματισμό][generic-programming].  |
| `paradigm:imperative`      | χρησιμοποιεί [προστακτικό προγραμματισμό][imperative-programming]. |
| `paradigm:logic`           | χρησιμοποιεί [λογικό προγραμματισμό][logic-programming].         |
| `paradigm:meta`            | χρησιμοποιεί [μεταπρογραμματισμό][metaprogramming].              |
| `paradigm:object-oriented` | χρησιμοποιεί [αντικειμενοστρεφή προγραμματισμό][object-oriented-programming]. |
| `paradigm:procedural`      | χρησιμοποιεί [διαδικασιακό προγραμματισμό][procedural-programming]. |
| `paradigm:reflective`      | χρησιμοποιεί [ανακλαστικό προγραμματισμό][reflective-programming]. |
| `paradigm:stack-oriented`  | χρησιμοποιεί [προγραμματισμό προσανατολισμένο στη στοίβα][stack-oriented-programming]. |
