# Εισαγωγή

Ένα **αντικείμενο** JSON είναι, με ορολογία από άλλες γλώσσες, ένα "hash", ένα "map" ή ένα "dictionary".

Το JSON ορίζει ένα _αντικείμενο_ ως εξής:

> Ένα αντικείμενο είναι ένα μη διατεταγμένο σύνολο ζευγών **ονόματος**/**τιμής**.
> Ένα αντικείμενο ξεκινά με `{` αριστερό άγκιστρο και τελειώνει με `}` δεξί άγκιστρο.
> Κάθε _όνομα_ ακολουθείται από `:` άνω κάτω τελεία και τα ζεύγη _ονόματος/τιμής_ χωρίζονται με `,` κόμμα.

Το _όνομα_ **πρέπει να είναι συμβολοσειρά**.
Μια άλλη λέξη για το _όνομα_ είναι _κλειδί_.

Η _τιμή_ μπορεί να είναι οποιουδήποτε τύπου JSON.
Διαφορετικές _τιμές_ στο ίδιο αντικείμενο μπορούν να είναι διαφορετικών τύπων, όπως σε αυτό το παράδειγμα.

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

Σημείωσε ότι **δεν πρέπει να** υπάρχει κόμμα μετά το _τελευταίο_ ζεύγος κλειδιού-τιμής.

## Δημιουργία αντικειμένων

Χρησιμοποίησε άγκιστρα για να συλλέξεις τα ζεύγη ονόματος/τιμής.
Αν και τα ονόματα πρέπει να είναι συμβολοσειρές, δεν χρειάζεται να μπουν σε εισαγωγικά αν είναι **σαν αναγνωριστικά** (αποτελούνται δηλαδή από αλφαριθμητικούς χαρακτήρες και κάτω παύλα, και δεν ξεκινούν με ψηφίο).

```jq
{name: "Jane", age: 42}
```

Είναι έγκυρο να χρησιμοποιείς κλειδιά που δεν είναι _σαν αναγνωριστικά_.
Απλώς βάλε τα σε εισαγωγικά.

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

Αν το όνομα είναι το αποτέλεσμα μιας παράστασης, η παράσταση **πρέπει** να είναι σε παρενθέσεις.

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## Πρόσβαση με θέση

Οι τιμές ανακτώνται από ένα αντικείμενο με **σημειογραφία τελείας**.

```jq
{name: "Jane", age: 42} | .age    # => 42
```

Αν δεν μπορείς να αναφερθείς στο κλειδί ως αναγνωριστικό, χρησιμοποίησε **σημειογραφία αγκύλης**.

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## Προσθήκη ή αλλαγή ζευγών κλειδιού-τιμής

Για να προσθέσεις ένα νέο ζεύγος κλειδιού-τιμής σε έναν πίνακα ή να ενημερώσεις την τιμή ενός υπάρχοντος κλειδιού, χρησιμοποίησε τον τελεστή ανάθεσης `=`, με μια έκφραση θέσης στην αριστερή πλευρά.

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

Ο τελεστής `+` θα _συγχωνεύσει_ αντικείμενα.

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## Αφαίρεση κλειδιού

Χρησιμοποίησε τη συνάρτηση `del` για να αφαιρέσεις ένα κλειδί.
Επιστρέφει το ενημερωμένο αντικείμενο.

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

Η παράμετρος της `del` είναι μια **έκφραση θέσης** (με σημειογραφία τελείας ή αγκύλης) που αντιστοιχεί σε ένα κλειδί του αντικειμένου.
Η `jq` την ονομάζει **παράσταση διαδρομής**.
Δεν αρκεί να δώσεις απλώς μια συμβολοσειρά.

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## Συμμετοχή

- Για να ελέγξεις αν το αντικείμενο έχει ένα κλειδί, χρησιμοποίησε τη συνάρτηση `has`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- Έλεγξε αν ένα κλειδί βρίσκεται σε ένα αντικείμενο με το `in`.

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## Λίστα με όλα τα κλειδιά

Χρησιμοποίησε τη συνάρτηση `keys` για να εμφανίσεις μια λίστα με όλα τα κλειδιά.

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

Σημείωσε ότι η `keys` θα _ταξινομήσει_ τα κλειδιά.
Για να πάρεις τα κλειδιά με την αρχική τους σειρά, χρησιμοποίησε τη `keys_unsorted`.

Δεν υπάρχει αντίστοιχη συνάρτηση για να εμφανίσεις όλες τις _τιμές_.
Ωστόσο, το φίλτρο `.[]` εμφανίζει τις τιμές του αντικειμένου ως _ροή_, και αυτή η ροή μπορεί να συλλεχθεί με τον κατασκευαστή πίνακα `[...]`.

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## Επανάληψη

- Η συνάρτηση `map_values(filter)` εφαρμόζει το φίλτρο σε κάθε _τιμή_ του αντικειμένου.

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- Για να επαναλάβουμε πάνω σε ένα αντικείμενο, πρέπει πρώτα να το μετατρέψουμε σε πίνακα από αντικείμενα κλειδιού-τιμής.
  Η συνάρτηση `to_entries` το κάνει αυτό.

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  Σε αυτό το σημείο, μπορούμε να χρησιμοποιήσουμε συναρτήσεις επανάληψης πινάκων, όπως τη `map`.

- Η συνάρτηση `from_entries` είναι η αντίστροφη: μετατρέπει έναν πίνακα από αντικείμενα κλειδιού-τιμής σε ένα αντικείμενο.

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- Για να εφαρμόσεις ένα φίλτρο σε _κάθε_ ζεύγος κλειδιού-τιμής σε ένα αντικείμενο, χρησιμοποίησε τη συνάρτηση `with_entries(filter)`.

  Για παράδειγμα, δεδομένου ενός αντικειμένου που αντιστοιχίζει ένα όνομα σε μια ηλικία, τα κλειδιά και οι τιμές μπορούν να ανταλλαγούν ως εξής.

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  εμφανίζει

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  Η `with_entries(filter)` είναι το ίδιο με

  ```jq
  to_entries | map(filter) | from_entries
  ```
