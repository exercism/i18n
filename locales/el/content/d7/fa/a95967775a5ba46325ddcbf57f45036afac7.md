# Εισαγωγή

Οι μετατροπές τύπων στη Cairo σου επιτρέπουν να μετατρέπεις δεδομένα από έναν τύπο σε άλλον, κάνοντας τον χειρισμό των δεδομένων ευέλικτο και ασφαλή.

## Τα βασικά

Η Cairo παρέχει αρκετούς μηχανισμούς για μετατροπή τύπων:

### Άμεσο casting

Για συμβατούς αριθμητικούς τύπους, μπορείς να χρησιμοποιήσεις άμεσο casting:

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### Το trait `Into`

Το trait `Into` επιτρέπει τη μετατροπή από έναν τύπο σε άλλον:

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### Το trait `TryInto`

Για μετατροπές που μπορεί να αποτύχουν, χρησιμοποίησε το `TryInto`, το οποίο επιστρέφει ένα `Option`:

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## Προσαρμοσμένες μετατροπές τύπων

Μπορείς να υλοποιήσεις το `Into` για δικούς σου τύπους:

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## Θέματα ασφάλειας

- Χρησιμοποίησε το `TryInto` όταν η μετατροπή μπορεί να αποτύχει (π.χ. από μεγάλους σε μικρούς τύπους)
- Χρησιμοποίησε το `Into` όταν η μετατροπή πετυχαίνει πάντα
- Να χειρίζεσαι πάντα τις περιπτώσεις `Option::None` που προκύπτουν από το `TryInto`
- Λάβε υπόψη την υπερχείλιση και την υποχείλιση όταν μετατρέπεις μεταξύ προσημασμένων και απρόσημων τύπων
