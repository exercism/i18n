# Προεπισκόπηση: Exercism Insiders

Θέλω να σου πω λίγα λόγια για δύο νέα πράγματα που προσθέτουμε στο Exercism για να το βοηθήσουμε να γίνει οικονομικά βιώσιμο. Το δεύτερο, το Exercism Insiders, είναι κάτι που πιστεύω ότι θα σε ενθουσιάσει ιδιαίτερα. Και φρόντισε να το διαβάσεις μέχρι το τέλος, γιατί ανακοινώνω δύο ξεχωριστά χαρακτηριστικά, ένα από τα οποία είναι διαθέσιμο μόνο σε όσους υιοθετήσουν νωρίς.

Λοιπόν, πρώτα λίγο ιστορικό. Όταν η Katrina δημιούργησε το Exercism πριν από 10 χρόνια, δεν είχε καμία απολύτως διάθεση να εξελιχθεί σε κάποιου είδους μεγάλο προϊόν. Ήταν μια απλή πλατφόρμα που χρησιμοποιούσε με τους μαθητές της. Αλλά από μια ευτυχή συγκυρία, έγινε κάτι σημαντικό. Και 10 χρόνια μετά, έχουμε πλέον εκατομμύρια επισκέπτες τον μήνα. Φτάσαμε σε αυτό το σημείο με ένα εξωφρενικά μικρό budget. Στην πραγματικότητα, στα 8 χρόνια του Exercism μέχρι την κυκλοφορία της v3, ξοδέψαμε λιγότερα από 500.000 δολάρια, μόνο 60.000 τον χρόνο. Στο διάστημα αυτό, ξαναχτίσαμε την πλατφόρμα από την αρχή δύο φορές, δημιουργήσαμε 65 διαδρομές γλωσσών, είχαμε εκατομμύρια υποβολές, συζητήσεις, επαναλήψεις… Φτιάξαμε αυτοματοποιημένα συστήματα ανατροφοδότησης που έχουν δώσει ανατροφοδότηση πάνω από 800.000 φορές. Κάναμε πολλά. Με ελάχιστα μέσα.

Και μεγάλο μέρος του λόγου που αυτό ήταν εφικτό οφείλεται προφανώς στο ότι είμαστε ανοιχτού κώδικα. Χιλιάδες άνθρωποι έχουν συνεισφέρει στο Exercism, και μερικές εκατοντάδες ιδιαίτερα υπέροχοι άνθρωποι έχουν κάνει τη δουλειά να χτίσουν και να συντηρήσουν το περιεχόμενό μας. Αλλά με την επιτυχία της κυκλοφορίας της v3, φτάσαμε σε ένα σημείο όπου χρειαζόμασταν μια πραγματική ομάδα πλήρους απασχόλησης να δουλεύει στο Exercism για να συνεχίσει να λειτουργεί. Εκείνη την εποχή λάβαμε επίσης μια απίστευτα γενναιόδωρη δωρεά 500.000 δολαρίων, που σήμαινε ότι μπορούσαμε να προσλάβουμε μια μικρή ομάδα. Έτσι προσλάβαμε τον Aron για τη δουλειά στο front-end, τον Jonathan για να αναπτύξει και να διαχειριστεί την πλευρά της κοινότητας, και τη Loretta για τη συγκέντρωση πόρων και τις συνεργασίες.

Το αποτέλεσμα αυτής της δουλειάς ήταν πραγματικά εντυπωσιακό. Η καθημερινή χρήση της ιστοσελίδας έχει αυξηθεί περίπου 250% σε ετήσια βάση. Προσθέσαμε ένα σωρό αυτοματοποιημένες λειτουργίες mentoring, που σημαίνουν ότι πλέον δίνουμε άμεσα ανατροφοδότηση σε πάνω από 800.000 λύσεις. Η κοινότητά μας κάνει live streaming στο Twitch καθημερινά. Έχουμε ένα ζωντανό φόρουμ και έναν ενεργό server στο Discord. Αυξήσαμε επίσης τις μηνιαίες δωρεές μας από σχεδόν μηδέν σε πάνω από 6.000 δολάρια τον μήνα. Που είναι τεράστιο ποσό. Ωστόσο, η προσπάθειά μας να πείσουμε εταιρείες να μας στηρίξουν μέσω των προϋπολογισμών Εταιρικής Κοινωνικής Ευθύνης τους πήγε λιγότερο καλά, και ενώ οι 6.000 λίρες τον μήνα είναι καταπληκτικές, στην πραγματικότητα είναι μόνο το ένα πέμπτο από αυτό που χρειαζόμαστε, και η πλειοψηφία των δωρεών είναι μεμονωμένες προσφορές και όχι τακτική στήριξη. Έτσι, ο χρόνος μας τελειώνει για να είμαστε βιώσιμοι με την τρέχουσα ομάδα μας, και χωρίς αυτή την ομάδα δεν έχουμε τους πόρους να λειτουργήσουμε πραγματικά το Exercism. Όσο κι αν εύχομαι να είχε η εβδομάδα 400 ώρες για να κάνω όλα αυτά τα πράγματα, δεν τις έχει. Και δεν μπορώ. Χρειάζεται λοιπόν να βρούμε έναν τρόπο να μπορούμε να πληρώνουμε τους πάντες, και γρήγορα.

Αλλά επίσης θέλω το Exercism να μεγαλώσει. Όποιος έχει περάσει χρόνο μιλώντας μαζί μου τα τελευταία χρόνια ξέρει όλες τις ιδέες, τις ελπίδες και τις φιλοδοξίες που έχω για το Exercism, τα πράγματα που πιστεύω ότι μπορούμε να κάνουμε και θα ήταν καταπληκτικά. Αλλά για να το πετύχουμε, χρειαζόμαστε και μεγαλύτερη ομάδα, και να μπορούμε να πληρώνουμε πιο ανταγωνιστικούς μισθούς. Οπότε… χρειάζεται να βρούμε έναν τρόπο να τα διορθώσουμε.

Και υπάρχουν δύο πράγματα που θα δοκιμάσουμε.

Το πρώτο είναι να προσθέσουμε κάποια χορηγία στην ιστοσελίδα. Θα αναζητήσουμε συνεργάτες που πιστεύουμε ότι προσφέρουν εξαιρετικά προϊόντα και υπηρεσίες σε προγραμματιστές και θα τους προσκαλέσουμε να χορηγήσουν διαδρομές αλλά και τομείς όπως τα email μας και την υποδομή μας. Η χορηγία θα είναι μακροπρόθεσμη υπόθεση: οι εταιρείες θα χρειαστεί να δεσμευτούν μάλλον για τουλάχιστον 12 μήνες στήριξης. Και θέλουμε πραγματικά να τις αντιμετωπίζουμε ως συνεργασίες win-win. Σκέφτομαι ότι μπορούμε να κάνουμε πράγματα όπως να συνδημιουργήσουμε πραγματικά εξαιρετικό περιεχόμενο, να πάρουμε κάποιες συνεντεύξεις από ανώτερα στελέχη των εταιρειών τους, και επίσης να τους ζητήσουμε να προσφέρουν εκπτώσεις ή δωρεάν δοκιμές στους power-users μας. Περισσότερα για αυτό σε λίγο!

Υπάρχουν μερικά πράγματα που δεν θα κάνουμε. Αυτό δεν θα είναι διαφήμιση του τύπου pay-per-click. Δεν θα προσθέσουμε τίποτα που να παρακολουθεί τους χρήστες στην ιστοσελίδα, δεν θα μοιραστούμε τα στοιχεία κανενός, ούτε τίποτα τέτοιο. Ψάχνουμε καθαρά για οργανισμούς που θέλουν να στηρίξουν τη δωρεάν εκπαίδευση, να στηρίξουν το open source, να στηρίξουν πρωτοβουλίες από τη βάση σαν τη δική μας, και σε αντάλλαγμα σου λέμε ότι το κάνουν, και ελπίζουμε να σε ενθαρρύνουμε να ρίξεις τουλάχιστον μια ματιά στα προϊόντα τους. Ελπίζω επίσης πολλοί από αυτούς τους οργανισμούς να επιλέξουν να δωρίσουν στο Exercism και μέσω των τμημάτων Εταιρικής Κοινωνικής Ευθύνης τους. Θα δούμε.

Και μια παρένθεση εδώ: αν δουλεύεις σε μια εταιρεία που προσφέρει προϊόντα ή υπηρεσίες σε προγραμματιστές, ίσως θα ενδιαφερόταν να χορηγήσει το Exercism. Αν μπορούσες να μας συστήσεις κάπου, να μας φέρεις σε επαφή με το κατάλληλο άτομο, ή έστω να μας πεις ανώνυμα σε ποιον θα έπρεπε να απευθυνθούμε, θα ήταν τεράστια βοήθεια. Οπότε στείλε email στη Loretta (το email της είναι στην περιγραφή πιο κάτω) και θα βρούμε τι λειτουργεί καλύτερα!

Ξεκίνησα κάπως δύσπιστος με όλο αυτό, αλλά τώρα είμαι πραγματικά ενθουσιασμένος. Πιστεύω ότι οι πραγματικές συνεργασίες θα μπορούσαν να ανεβάσουν το Exercism σε άλλο επίπεδο και να προσφέρουν σπουδαία επιπλέον οφέλη σε όλα τα μέλη μας.

Αυτό είναι λοιπόν το πρώτο μέρος. Το δεύτερο μέρος είναι κάτι για το οποίο σίγουρα ενθουσιάζομαι, και ενθουσιάζομαι εδώ και πολύ καιρό, και αυτό είναι το Exercism Insiders.

Το Exercism Insiders θα είναι το νέο μας πρόγραμμα επιβραβεύσεων για ανθρώπους που στηρίζουν ενεργά το Exercism. Θα σου δίνουμε περισσότερη πρόσβαση στα παρασκήνια, μεγαλύτερη συμμετοχή στο μέλλον του Exercism, επιπλέον διασκεδαστικά χαρακτηριστικά, και επίσης θα ζητάμε από όλες τις εταιρείες με τις οποίες μιλάμε για χορηγία να προσφέρουν δωρεάν δοκιμές ή εκπτώσεις στους Insiders μας.

Για να είσαι Insider, ο γενικός κανόνας είναι ότι πρέπει να στηρίζεις ενεργά το Exercism. Κατά κύριο λόγο αυτό σημαίνει είτε ότι συνεισφέρεις ενεργά στον κώδικά μας, είτε ότι κάνεις ενεργά mentoring, είτε ότι έκανες πρόσφατα μια δωρεά. Ακόμα οριστικοποιούμε τις λεπτομέρειες, αλλά σκέφτομαι χοντρικά ότι κάθε φορά που κερδίζεις ένα συγκεκριμένο ποσό reputation, ή που μας κάνεις μια δωρεά, αυτό παρατείνει την πρόσβασή σου για 30 μέρες από εκείνο το σημείο. Αν είσαι τακτικός δωρητής ή τακτικός συνεισφέρων, τότε μάλλον θα δίνουμε και λίγο μεγαλύτερη περίοδο χάριτος, ώστε αν δεν έχεις εμφανιστεί για 30 μέρες, αλλά ήσουν παρών τους προηγούμενους 9 μήνες, να μην χάνεις απλώς την πρόσβαση. Και θα δίνουμε επίσης ισόβια συνδρομή σε ανθρώπους που έχουν κάνει τεράστιες συνεισφορές στο παρελθόν αλλά δεν είναι τώρα ενεργοί.

Οι Insiders θα σου δίνουν επίσης ένα badge που εμφανίζεται δίπλα στο όνομά σου στην ιστοσελίδα, flair στο φόρουμ, και έναν ρόλο στο Discord που σου δίνει πρόσβαση σε ειδικά ιδιωτικά κανάλια. Θα σημαίνει επίσης ότι σε πράγματα όπως οι κοινοτικές μας κλήσεις θα μπορείς να συμμετέχεις ενεργά, αντί απλώς να τις παρακολουθείς εκ των υστέρων. Θα δίνει πρόσβαση σε vlogs και συνεντεύξεις από τα παρασκήνια, και εξετάζουμε επίσης πράγματα όπως το να δίνουμε προτεραιότητα σε ερωτήσεις από Insiders στις συνεδρίες ερωτήσεων που διοργανώνουμε. Βασικά, αν είσαι μέρος αυτού που κάνει το Exercism πετυχημένο, θέλουμε να σε γιορτάσουμε και να σε πάρουμε μαζί μας σε όλη τη διαδρομή.

Ανέφερα στην αρχή ότι έχουμε δύο ξεχωριστά χαρακτηριστικά για όσους υιοθετήσουν νωρίς. Το πρώτο από αυτά είναι το Dark Mode. Ξέρω ότι είναι κάτι που πολλοί περίμεναν από καιρό, και να που επιτέλους ήρθε. Θα το κυκλοφορήσουμε ταυτόχρονα με το Insiders και θα είναι διαθέσιμο μόνο στους Insiders για τους πρώτους 3 μήνες. Οπότε αν θέλεις πρόσβαση σε αυτό, πήγαινε να κερδίσεις λίγο reputation συνεισφέροντας ή κάνοντας mentoring, ή γίνε τακτικός δωρητής.

Το δεύτερο χαρακτηριστικό είναι αυτό που στη Βρετανία περιγράφουμε ως marmite: ή θα το λατρέψεις ή θα το μισήσεις. Θα ενσωματώσουμε το ChatGPT στην ιστοσελίδα μας, ώστε αν κολλήσεις σε μια άσκηση να μπορείς να του ζητήσεις βοήθεια, και όταν τελειώσεις μια άσκηση θα παίρνεις αυτοματοποιημένη ανατροφοδότηση από αυτό. Στα πειράματά μας μέχρι τώρα, το ChatGPT ήταν καταπληκτικό περίπου τις μισές φορές και άχρηστο τις άλλες μισές, οπότε σε αυτό το στάδιο το αντιμετωπίζουμε ως ένα καθαρά διασκεδαστικό χαρακτηριστικό, αλλά πιστεύουμε ότι θα έχει πολλή πλάκα να πειραματιστούμε μαζί του. Αυτό θα είναι χαρακτηριστικό αποκλειστικά για Insiders για το προβλεπτό μέλλον, και για τον μήνα Μάιο μόνο όσοι ήταν Insiders την ημέρα κυκλοφορίας του Insiders θα έχουν πρόσβαση, οπότε αν θέλεις να παίξεις μαζί του, πρέπει να έχεις κερδίσει πρόσβαση Insiders πριν από την κυκλοφορία μας. Θα προσθέσουμε επίσης ένα ειδικό badge για όσους μας στήριξαν πριν κυκλοφορήσουμε το Insiders, και η μικρή ετικέτα Insiders δίπλα στο όνομά σου στην ιστοσελίδα θα αντικατοπτρίζει μόνιμα την πρώιμη στήριξή σου.

Θα κυκλοφορήσουμε μια landing page την επόμενη εβδομάδα με τις ακριβείς λεπτομέρειες και την εκκρεμή κατάστασή σου ως Insider, αλλά μια δωρεά τώρα σου εξασφαλίζει πρόσβαση, και θα ήταν καταπληκτικό να δούμε δωρεές να καταφθάνουν πριν από την κυκλοφορία μας, οπότε σκέψου σοβαρά να το κάνεις αν μπορείς!

Ένα πράγμα που θέλω να ξεκαθαρίσω είναι ότι κανένα από τα εκπαιδευτικά μας χαρακτηριστικά δεν πρόκειται να αρχίσει να κλειδώνεται πίσω από πληρωμή. Το Insiders θα είναι γεμάτο διασκεδαστικά χαρακτηριστικά, επιπλέον καλούδια στο UI και πρόσβαση στα παρασκήνια. Δεν θα είναι επιπλέον περιεχόμενο ούτε χαρακτηριστικά έτοιμα για παραγωγή. Οπότε αν δεν μπορείς να διαθέσεις τον χρόνο ή τα χρήματα για πρόσβαση στους Insiders, δεν θα έχεις χειρότερη εκπαιδευτική εμπειρία εξαιτίας αυτού. Αυτό είναι μια πολύ σημαντική κόκκινη γραμμή για εμάς.

Εντάξει, λοιπόν αυτά είναι τα δύο πράγματα: η χορηγία και οι Insiders. Η ελπίδα μας είναι ότι μέσα από αυτά, τόσο εταιρείες όσο και άτομα θα επιλέξουν να στηρίξουν οικονομικά το Exercism, και έτσι και να φτάσουμε σε ένα πιο βιώσιμο σημείο και να αρχίσουμε να βλέπουμε ένα μέλλον όπου θα μπορούμε πραγματικά να ανθίσουμε και να αρχίσουμε να χτίζουμε μερικές από τις συναρπαστικές ιδέες που έχουμε.

Λοιπόν, ευχαριστώ που το διάβασες. Ελπίζω να είσαι κι εσύ το ίδιο ενθουσιασμένος, ειδικά με τους Insiders. Ανυπομονώ να σου πω περισσότερα τις επόμενες εβδομάδες!
