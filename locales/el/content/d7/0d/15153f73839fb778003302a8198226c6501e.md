# Εγκατάσταση της Python

Αν η Python δεν είναι ήδη διαθέσιμη στο σύστημά σου, μπορείς να βρεις αναλυτικές οδηγίες ανά πλατφόρμα στην ενότητα [Python Setup and Usage][using python] της επίσημης τεκμηρίωσης.
Το Real Python προσφέρει επίσης έναν [ωραίο οδηγό][helpful guide] για την εγκατάσταση σε διάφορες πλατφόρμες, συμπεριλαμβανομένων των iOS και Android.

Τέλος, αυτές οι αναρτήσεις του Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] και [Why you should use `python -m pip`][python-m-pip], δίνουν πολύ χρήσιμες συμβουλές για το πώς να διαχειρίζεσαι εγκαταστάσεις και πακέτα της Python.

**Σημείωση για χρήστες MacOS:**  πριν από το MacOS Monterey (12.3), το `Python 2.7` ερχόταν προεγκατεστημένο με το λειτουργικό σύστημα.
Η χρήση του `Python 2.7` με το Exercism ή με τα περισσότερα άλλα προγράμματα δεν υποστηρίζεται.
Αντ' αυτού, θα πρέπει να εγκαταστήσεις την [Python 3][Python-three downloads] με μία από τις μεθόδους που περιγράφονται παρακάτω.
Από το MacOS Monterey (12.3) και μετά, καμία έκδοση της Python δεν έρχεται προεγκατεστημένη μέσω του MacOS.

Μερικοί γρήγοροι σύνδεσμοι προς την τεκμηρίωση ανά λειτουργικό σύστημα:

-  [Windows][windows] Επιπλέον, αυτό το άρθρο της Microsoft για την [εγκατάσταση της Python στα Windows][python-on-windows] είναι χρήσιμο.
-  [Unix & Linux Systems][unix-and-linux] (_αυτά ισχύουν σε μεγάλο βαθμό και για το MacOS_)
-  [MacOS][macos]

   Προτείνουμε επίσης να ρίξεις μια ματιά σε μερικές από τις μεθόδους που περιγράφονται στο άρθρο του Real Python [Installing Python][installing-python] ή στα άρθρα του Brett Cannon που συνδέονται παραπάνω.


Οι δοκιμές και τα εργαλεία του Exercism υποστηρίζουν αυτή τη στιγμή τις εκδόσεις `3.10` - `3.13.5` (_δοκιμές_) και την [`Python 3.13.5`][313-new-features] (_εργαλεία_).
Οι εξαιρέσεις σε αυτή την υποστήριξη σημειώνονται όπου εμφανίζονται.
Οι περισσότερες ασκήσεις θα λειτουργήσουν με `Python 3.6+`, ή ακόμα και με παλαιότερες εκδόσεις.
Ωστόσο, δεν εγγυόμαστε υποστήριξη για εκδόσεις που δεν αναφέρονται στις [Active Python Releases][active-python-releases].


Ανατρέξε στην [τεκμηρίωση της Python 3.13.x][3.13 docs] για το τι υποστηρίζεται αυτή τη στιγμή.
