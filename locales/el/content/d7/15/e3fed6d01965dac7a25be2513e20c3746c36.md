# Εγκατάσταση

Το Crystal είναι διαθέσιμο σε Linux, macOS και Windows.

Αυτό που πρέπει να σημειώσεις είναι ότι η υποστήριξη των Windows στο Crystal είναι πειραματική.
Δηλαδή μπορεί να υπάρχουν ορισμένες ακραίες περιπτώσεις που δεν δουλεύουν και μπορεί να μην είναι ιδανική για περιπτώσεις χρήσης σε παραγωγικό περιβάλλον.
Ωστόσο, για το Exercism και τη βασική χρήση, τα εγγενή Windows θα πρέπει να είναι σε μεγάλο βαθμό λειτουργικά.

Αν ψάχνεις μια εμπειρία χωρίς preview για ανάπτυξη σε Windows, συνιστάται να χρησιμοποιήσεις το [WSL (Windows Subsystem for Linux)][wsl].
Είναι μια **δωρεάν** λειτουργία των Windows 10 (1903+) και 11 που επιτρέπει στον προγραμματιστή να τρέξει ένα περιβάλλον Linux χωρίς να χρειάζεται εικονική μηχανή.

Χρησιμοποίησε έναν από τους [οδηγούς εγκατάστασης][installation guides] για οδηγίες σχετικά με την εγκατάσταση του Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
