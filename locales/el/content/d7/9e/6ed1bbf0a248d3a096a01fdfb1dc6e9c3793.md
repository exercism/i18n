# Οδηγίες

Σε αυτή την άσκηση, πρέπει να υλοποιήσεις μερικούς κανόνες από το [Pac-Man][Pac-Man], το κλασικό παιχνίδι arcade της δεκαετίας του 1980.

Έχεις τέσσερις κανόνες να υλοποιήσεις, όλοι σχετικοί με τις καταστάσεις του παιχνιδιού.

> _Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, συγκεντρώσου απλώς στο να συνδυάσεις τα ορίσματα ώστε να επιστρέψεις το επιθυμητό αποτέλεσμα._

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `eat_ghost()` που δέχεται δύο παραμέτρους (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean (λογική τιμή) τιμή αν ο Pac-Man μπορεί να φάει ένα φάντασμα.
 Η συνάρτηση πρέπει να επιστρέφει `True` μόνο αν ο Pac-Man έχει ενεργό power pellet και αγγίζει ένα φάντασμα.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `score()` που δέχεται δύο παραμέτρους (_αν ο Pac-Man αγγίζει ένα power pellet_ και _αν ο Pac-Man αγγίζει μια κουκκίδα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man σκοράρει.
 Η συνάρτηση πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα power pellet ή μια κουκκίδα.

```python
>>> score(True, True)
...
True
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `lose()` που δέχεται δύο παραμέτρους (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man χάνει.
 Η συνάρτηση πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό power pellet.

```python
>>> lose(False, True)
...
True
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `win()` που δέχεται τρεις παραμέτρους (_αν ο Pac-Man έχει φάει όλες τις κουκκίδες_, _αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man κερδίζει.
 Η συνάρτηση πρέπει να επιστρέφει `True` αν ο Pac-Man έχει φάει όλες τις κουκκίδες και δεν έχει χάσει με βάση τους κανόνες που ορίζονται στο μέρος 3.

```python
>>> win(False, True, False)
...
False
```
