# Εισαγωγή

Στη Go, ο [`Time`][time] είναι ένας τύπος που περιγράφει μια χρονική στιγμή.
Οι πληροφορίες ημερομηνίας και ώρας μπορούν να προσπελαστούν, να συγκριθούν και να τροποποιηθούν μέσω των μεθόδων του, αλλά υπάρχουν και κάποιες συναρτήσεις που καλούνται στο ίδιο το πακέτο `time`.
Η τρέχουσα ημερομηνία και ώρα μπορούν να ανακτηθούν μέσω της συνάρτησης [`time.Now`][now].

Η συνάρτηση [`time.Parse`][parse] μετατρέπει συμβολοσειρές σε τιμές του τύπου `Time`.
Η Go έχει έναν ιδιαίτερο τρόπο για να ορίσεις τη διάταξη που περιμένεις για τη μετατροπή.
Πρέπει να γράψεις ένα παράδειγμα της διάταξης χρησιμοποιώντας τις τιμές από αυτήν την ειδική χρονοσφραγίδα:
`Mon Jan 2 15:04:05 -0700 MST 2006`.

Για παράδειγμα:

```go
import "time"

func parseTime() time.Time {
    date := "Tue, 09/22/1995, 13:00"
    layout := "Mon, 01/02/2006, 15:04"

    t, err := time.Parse(layout,date) // time.Time, error
}

// => 1995-09-22 13:00:00 +0000 UTC
```

Η μέθοδος [`Time.Format()`][format] επιστρέφει μια αναπαράσταση του χρόνου ως συμβολοσειρά.
Όπως ακριβώς με τη συνάρτηση `Parse`, η επιθυμητή διάταξη ορίζεται και πάλι μέσω ενός παραδείγματος που χρησιμοποιεί τις τιμές από την ειδική χρονοσφραγίδα.

Για παράδειγμα:

```go
import (
    "fmt"
    "time"
)

func main() {
    t := time.Date(1995,time.September,22,13,0,0,0,time.UTC)
    formattedTime := t.Format("Mon, 01/02/2006, 15:04") // string
    fmt.Println(formattedTime)
}

// => Fri, 09/22/1995, 13:00
```

## Επιλογές διάταξης

Για μια προσαρμοσμένη διάταξη, χρησιμοποίησε συνδυασμό αυτών των επιλογών.
Στη Go υπάρχουν επίσης προκαθορισμένες [σταθερές μορφοποίησης][const] για ημερομηνία και χρονοσφραγίδα.

| Time        | Options                                        |
| ----------- | ---------------------------------------------- |
| Έτος        | 2006 ; 06                                      |
| Μήνας       | Jan ; January ; 01 ; 1                         |
| Ημέρα       | 02 ; 2 ; \_2 (για αρχικό 0)                    |
| Ημέρα εβδομάδας | Mon ; Monday                               |
| Ώρα         | 15 ( μορφή 24ώρου ) ; 3 ; 03 (π.μ. ή μ.μ.)     |
| Λεπτό       | 04 ; 4                                         |
| Δευτερόλεπτο | 05 ; 5                                        |
| Ένδειξη π.μ./μ.μ. | PM                                       |
| Ημέρα του έτους | 002 ; \_\_2                                |

Ο τύπος `time.Time` έχει διάφορες μεθόδους για την πρόσβαση σε μια συγκεκριμένη χρονική στιγμή. π.χ. Ώρα: [`Time.Hour()`][hour], Μήνας: [`Time.Month()`][month].
Περισσότερα για το πώς λειτουργεί αυτό μπορείς να βρεις στην [επίσημη τεκμηρίωση][time].

Το πακέτο [`time`][time] περιλαμβάνει έναν ακόμη τύπο, το [`Duration`][duration], που αναπαριστά χρόνο που έχει περάσει, καθώς και υποστήριξη για τοποθεσίες/ζώνες ώρας, χρονόμετρα και άλλες σχετικές λειτουργίες που θα καλυφθούν σε μια άλλη έννοια.
