# Bootcamp

Γεια σε όλους!

Είμαι πραγματικά ενθουσιασμένος που σου ανακοινώνω ότι από τον Ιανουάριο του 2025 θα διοργανώσουμε ένα **[Learn to Code Bootcamp](https://bootcamp.exercism.org)**!

## Λίγο ιστορικό

Θέλω εδώ και πολύ καιρό να βοηθήσω απόλυτους αρχάριους. 
Όπως ανέφερα στο άρθρο "[2M users but no money in the bank](https://exercism.org/blog/september-2024-restructure)" τον Σεπτέμβριο,
πάνω από το 95% των ανθρώπων που προσπαθούν να μάθουν προγραμματισμό τα παρατάνε, κάτι που θεωρώ απαράδεκτο.

Φτιάχνουμε μια νέα πλατφόρμα που θα σταθεί δίπλα στο Exercism και θα είναι αφιερωμένη σε αρχάριους, την οποία θα κυκλοφορήσουμε στα μέσα του 2025. 
Έχουμε ήδη βάλει πολλή προσπάθεια σε αυτό και είμαι πραγματικά περήφανος για το πώς εξελίσσεται.
Θα μιλήσω πολύ περισσότερο γι' αυτό τους επόμενους μήνες.

Αλλά πριν την κυκλοφορήσουμε, θα διοργανώσουμε ένα bootcamp 6 μηνών, που θα χρησιμοποιεί μέρος της τεχνολογίας που φτιάχνουμε. Αυτό θα μου επιτρέψει να έρθω πολύ κοντά στην εμπειρία μάθησης των μαθητών, να βελτιώσω και να εξελίξω την πλατφόρμα καθώς πραγματικοί άνθρωποι μαθαίνουν με αυτήν, και θα με βοηθήσει να καταλάβω πού κολλάνε οι μαθητές και να βρω πώς να τους βοηθήσω ακόμα περισσότερο.

## Λίγες λεπτομέρειες

Το bootcamp θα έχει δύο μέρη:
1. Εκμάθηση προγραμματισμού
2. Εκμάθηση front-end web ανάπτυξης

Οι μαθητές μπορούν να παρακολουθήσουν μόνο το πρώτο μέρος (3 μήνες, από τον Ιανουάριο έως τον Μάρτιο) ή ολόκληρο το μάθημα (6 μήνες, από τον Ιανουάριο έως τον Ιούλιο). 
Μπορεί επίσης να προσφέρω αργότερα μόνο το δεύτερο μέρος, για προγραμματιστές που θέλουν να μάθουν κάποιες δεξιότητες ανάπτυξης web.

Το bootcamp γίνεται εξ αποστάσεως, με μερική απασχόληση, και η τιμή του είναι όσο το δυνατόν χαμηλότερη, με 
τιμολόγηση προσαρμοσμένη στην τοπική αγοραστική δύναμη, καθώς και εκπτώσεις για μαθητές και για όσους είναι αυτή τη στιγμή άνεργοι.

Η όλη έμφαση δίνεται στη μάθηση μέσα από την πράξη. 
Όπως στο Exercism, οι άνθρωποι θα μάθουν γράφοντας πολύ κώδικα.
Θα ξεκινήσουμε με μικρότερες ασκήσεις και θα εξελιχθούμε σε μεγαλύτερα έργα.
Έτσι έμαθα κι εγώ πριν από τρεις δεκαετίες, και πιστεύω ακράδαντα ότι η μάθηση μέσα από την πράξη είναι ο καλύτερος τρόπος για να χτίσει το μυαλό μια διαισθητική και φυσική κατανόηση του πώς γίνεται κάτι.

Αντί να τα αναμασήσω όλα εγώ, το καλύτερο είναι μάλλον να ρίξεις μια ματιά στον **[ιστότοπο του Bootcamp](https://bootcamp.exercism.org)** για όλες τις λεπτομέρειες!

Υπάρχουν δύο τρόποι που μπορείς να βοηθήσεις!

## Βοήθησε κάνοντάς το γνωστό

Το πιο σημαντικό πράγμα που μπορείς να κάνεις για να βοηθήσεις είναι να παροτρύνεις όλους όσους γνωρίζεις να έρθουν και να γραφτούν!

Έχω γράψει πολλές φορές για το πόσο πολύτιμη θεωρώ ότι είναι η εκμάθηση προγραμματισμού για σχεδόν όλους σήμερα.
Ακόμα κι αν δεν θέλεις καριέρα στον χώρο της τεχνολογίας, ο προγραμματισμός είναι μια εξαιρετική δεξιότητα. Καλλιεργεί την κριτική σκέψη, σε βοηθά να καταλάβεις πώς λειτουργεί ένα μεγάλο μέρος του κόσμου, και, με τη δύναμη των LLMs, είναι όλο και πιο εύκολο για τους ανθρώπους να συνδυάζουν διάφορα μικρά κομμάτια κώδικα για να κάνουν χρήσιμα πράγματα.

Στήνουμε ένα πρόγραμμα συνεργατών όπου οι φίλοι ή οι ακόλουθοί σου μπορούν να πάρουν έκπτωση 20%, και εσύ παίρνεις 20% "προμήθεια" από την πώληση (την οποία μπορείς να επιλέξεις να μην πάρεις για να στηρίξεις το Exercism, αν προτιμάς!)
Αν σε ενδιαφέρει, [πες μου](mailto:bootcamp@exercism.org).

Οι ισόβιοι Insiders θα πάρουν επίσης μία δωρεάν θέση για να τη χρησιμοποιήσουν για έναν φίλο ή να τη χαρίσουν όπως θέλουν. 
Θα επικοινωνήσω ξεχωριστά με τους ισόβιους Insiders!

## Βοήθησε ως μέντορας

Το Exercism λειτουργεί καλύτερα όταν η κοινότητα ενώνεται για να κάνει δυνατά πράγματα που θα ήταν αδύνατα για τον καθένα ξεχωριστά!

Ένας από τους τομείς όπου θα ήθελα πολύ τη βοήθειά σου είναι η υποστήριξη των μαθητών του bootcamp, απαντώντας στις ερωτήσεις τους και βοηθώντας τους να ξεκολλήσουν, παρόμοια με την υποστήριξη που γίνεται σήμερα στο Discord και στο φόρουμ, αλλά με πιο οργανωμένο τρόπο.

Θα ακολουθήσουμε μια πολύ συγκεκριμένη προσέγγιση στη μάθηση, όπου εισάγουμε τις έννοιες με συγκεκριμένη σειρά και αφήνουμε τους μαθητές να εσωτερικεύσουν τις ιδέες μέσα από πάρα πολλή εξάσκηση.
Θα βασιστούμε σε μεγάλο βαθμό στη μεθοδολογία [Lie to children](https://en.wikipedia.org/wiki/Lie-to-children), ώστε να μην κατακλύζονται οι άνθρωποι ούτε να παρασύρονται σε περιοχές που θα περιέπλεκαν τα πράγματα. 

Αν σε ενδιαφέρει να υποστηρίξεις ή να καθοδηγήσεις απόλυτους αρχάριους και είσαι σύμφωνος με την προσέγγιση "Lie to Children" και με το να δουλεύεις μέσα στο framework που φτιάχνουμε, τότε θα χαρώ πολύ να σε ακούσω (στείλε μου email στο [bootcamp@exercism.org](mailto:bootcamp@exercism.org)!).

## Επίλογος

Είμαι πραγματικά, **πραγματικά** ενθουσιασμένος γι' αυτό. 
Ελπίζω να βοηθήσει πάρα πολλούς ανθρώπους, να μας βοηθήσει να βελτιώσουμε ένα προϊόν για το οποίο έχω πάθος, και να φέρει λίγα χρήματα στο Exercism για να κρατηθούμε όρθιοι. 
Μοιάζει με win-win-win.

Θα μιλήσω πολύ περισσότερο γι' αυτό τους επόμενους μήνες, αλλά στο μεταξύ θα εκτιμούσα πάρα πολύ την υποστήριξή σου στο να το κάνεις γνωστό και να δημιουργήσεις λίγο ντόρο! 

Ευχαριστώ που το διάβασες 🙂
