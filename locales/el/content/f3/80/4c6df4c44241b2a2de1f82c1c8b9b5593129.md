# Υποδείξεις

## 1. Δημιούργησε την κλάση `JuiceMaker`

- Ο κατασκευαστής πρέπει να δέχεται μια παράμετρο `Int` και μια παράμετρο `Jug`
- Η κλάση πρέπει επίσης να έχει τις ιδιότητες `capacity` και `jug`

## 2. Επέκτεινε την κανάτα όταν η χωρητικότητα είναι πάνω από 1.000 χιλιοστόλιτρα

- Τα μπλοκ `init` μπορούν να χρησιμοποιηθούν για να γίνει οποιαδήποτε απαραίτητη αρχικοποίηση κατά τη δημιουργία ενός αντικειμένου

## 3. Εγκατέστησε τον εκκινητή

- Πρόσθεσε έναν δευτερεύοντα κατασκευαστή
- Οι δευτερεύοντες κατασκευαστές πρέπει, όπως και πριν, να καλούν τον κύριο κατασκευαστή

## 4. Πρόσθεσε μια συνάρτηση `start`

- Η κλάση πρέπει να "θυμάται" την ταχύτητα

## 5. Πρόσθεσε μια συνάρτηση `stop`

- Όταν καλείται, η κλάση πρέπει να "θυμάται" ότι έχει σταματήσει (τουλάχιστον μέχρι να ξεκινήσει ξανά)

## 6. Πρόσθεσε μια συνάρτηση `lightColor`

- Αυτή η συνάρτηση θα πρέπει να ελέγχει με ποια ταχύτητα ξεκίνησε ο παρασκευαστής χυμού
- Αυτή η συνάρτηση θα πρέπει επίσης να ξέρει αν ο παρασκευαστής χυμού έχει σταματήσει

## 7. Κατασκεύασε με μια κοινή χωρητικότητα

- Η συνάρτηση `buildWithCommonCapacity` πρέπει να ορίζεται _έξω_ από την κλάση `JuiceMaker`
