# Οδηγίες

Σε αυτή την άσκηση, σου έχει ανατεθεί να γράψεις το λογισμικό για μια συσκευή κρυπτογράφησης που λειτουργεί εκτελώντας μετασχηματισμούς σε δεδομένα. Χρειάζεσαι έναν τρόπο να δημιουργείς ευέλικτα πολύπλοκες συναρτήσεις συνδυάζοντας απλούστερες συναρτήσεις μεταξύ τους.

Για κάθε εργασία, επέστρεψε μια ανώνυμη συνάρτηση που μπορεί να κληθεί από το περιβάλλον κλήσης.

## 1. Δημιούργησε έναν αθροιστή

Υλοποίησε τη `secret_add`. Θα πρέπει να επιστρέφει μια συνάρτηση που παίρνει ένα όρισμα και του προσθέτει το όρισμα που περνάς στη `secret_add`.

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. Δημιούργησε έναν αφαιρέτη

Υλοποίησε τη `secret_subtract`. Θα πρέπει να επιστρέφει μια συνάρτηση που παίρνει ένα όρισμα και του αφαιρεί το μυστικό που περνάς στη `secret_subtract`.

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. Δημιούργησε έναν πολλαπλασιαστή

Υλοποίησε τη `secret_multiply`. Θα πρέπει να επιστρέφει μια συνάρτηση που παίρνει ένα όρισμα και το πολλαπλασιάζει με το μυστικό που περνάς στη `secret_multiply`.

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. Δημιούργησε έναν διαιρέτη

Υλοποίησε τη `secret_divide`. Θα πρέπει να επιστρέφει μια συνάρτηση που παίρνει ένα όρισμα και το διαιρεί με το μυστικό που περνάς στη `secret_divide`.

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. Δημιούργησε έναν συνδυαστή συναρτήσεων

Υλοποίησε τη `secret_combine`. Θα πρέπει να επιστρέφει μια συνάρτηση που παίρνει ένα όρισμα και του εφαρμόζει με τη σειρά τις δύο συναρτήσεις που περνάς στη `secret_combine`.

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
