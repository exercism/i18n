# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό.
Επειδή δεν ήθελε να είναι εύκολο για τους άλλους να το διαβάσουν, το μήνυμα κρυπτογραφήθηκε με μια σειρά από χειρισμούς bits.
Θα χρειαστεί να γράψεις τις μεθόδους που θα βοηθήσουν στην αποκρυπτογράφηση του μηνύματος.

## 1. Ολίσθηση των bits προς τα πίσω

Το πρώτο βήμα για την αποκρυπτογράφηση του μηνύματος είναι να αναιρέσεις την ολίσθηση που έγινε κατά την κρυπτογράφηση, ολισθαίνοντας τα bits ξανά προς τα δεξιά.
Θα ακολουθήσουν κι άλλα βήματα στη διαδικασία αποκρυπτογράφησης που υποθέτουν ότι από την αριστερή πλευρά εισάγονται 0.

Υλοποίησε τη μέθοδο `Secrets.shiftBack`, η οποία παίρνει μια τιμή και τον αριθμό των θέσεων ολίσθησης και εκτελεί την ολίσθηση.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Ορισμός κάποιων bits

Στη συνέχεια, υπάρχουν κάποια bits που πρέπει να τεθούν σε 1.

Υλοποίησε τη μέθοδο `Secrets.setBits`, η οποία παίρνει μια τιμή και μια μάσκα και επιστρέφει το αποτέλεσμα της θέσης των bits της τιμής σε 1.
Ένα bit της τιμής πρέπει να τεθεί σε 1 όπου και το αντίστοιχο bit της μάσκας είναι 1.
Όλα τα άλλα bits πρέπει να παραμείνουν αμετάβλητα.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Αντιστροφή συγκεκριμένων bits

Κάποια bits αντιστρέφονται κατά την κρυπτογράφηση.
Θα χρειαστεί να αντιστραφούν ξανά για να αποκρυπτογραφηθεί το μήνυμα.

Υλοποίησε τη μέθοδο `Secrets.flipBits`, η οποία παίρνει μια τιμή και τη μάσκα.
Η μάσκα δείχνει ποια bits της τιμής θα αντιστραφούν.
Αν το bit στη μάσκα είναι 1, το bit αντιστρέφεται στην τιμή.
Όλα τα άλλα bits παραμένουν αμετάβλητα.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Μηδενισμός συγκεκριμένων bits

Τέλος, υπάρχουν και κάποια bits που αποκρυπτογραφούνται πάντα σε 0.

Υλοποίησε τη μέθοδο `Secrets.clearBits`, η οποία παίρνει μια τιμή και μια μάσκα.
Τα bits της `value` πρέπει να τεθούν σε 0 όπου το bit της μάσκας είναι 1.
Όλα τα άλλα bits πρέπει να παραμείνουν αμετάβλητα.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
