# Οδηγίες

Ο Karl θέλει να κρατάει μια λίστα με τις γλώσσες που θέλει να μάθει στην ιστοσελίδα Exercism.
Ο Karl πρέπει να μπορεί να προσθέτει νέες γλώσσες, να αφαιρεί παλιές και να ελέγχει αν κάποιες γλώσσες βρίσκονται στη λίστα.
Θα ήταν πολύ συναρπαστικό αν ο Karl ήθελε να μάθει Java ή Kotlin!

## 1. Όρισε μια συνάρτηση που ελέγχει αν η λίστα με τις γλώσσες είναι άδεια

Ο Karl πρέπει να ξέρει αν η λίστα με τις γλώσσες του αδειάσει ποτέ, ώστε να μπορεί να πάει να βρει κι άλλες για να μάθει!
Όρισε μια μέθοδο με το όνομα `isEmpty` που επιστρέφει `true` αν δεν υπάρχουν γλώσσες στη λίστα.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Όρισε μια συνάρτηση που προσθέτει μια γλώσσα στη λίστα

Ο Karl ανυπομονεί να μάθει Kotlin και Python!
Βοήθησε τον Karl να ξεκινήσει ορίζοντας μια μέθοδο με το όνομα `addLanguage`, η οποία παίρνει τη γλώσσα που θέλει να μάθει και την προσθέτει στη λίστα.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Όρισε μια συνάρτηση που αφαιρεί μια γλώσσα από τη λίστα

Ο Karl αποφάσισε ότι δεν θέλει να μάθει Scala αυτή τη στιγμή.
Βοήθησε τον Karl να τη βγάλει από τη λίστα ορίζοντας μια μέθοδο με το όνομα `removeLanguage`, η οποία παίρνει τη γλώσσα που αφαιρεί και τη βγάζει από τη λίστα.

```java
languageList.removeLanguage("Scala");
```

## 4. Όρισε μια συνάρτηση που επιστρέφει το πρώτο στοιχείο της λίστας

Ο Karl θέλει να θυμάται την πρώτη γλώσσα που πρόσθεσε στη λίστα (αυτή που βρίσκεται ακόμα στη λίστα).
Όρισε μια μέθοδο με το όνομα `firstLanguage` που επιστρέφει την πρώτη γλώσσα στη λίστα.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Όρισε μια συνάρτηση που επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

Ο Karl πρέπει να ξέρει πόσες γλώσσες προσπαθεί να μάθει.
Βοήθησε τον Karl να βρει την απάντηση ορίζοντας μια μέθοδο με το όνομα `count`, η οποία επιστρέφει τον αριθμό των γλωσσών στη λίστα.

```java
int two = languageList.count(); // 2
```

## 6. Όρισε μια συνάρτηση που προσδιορίζει αν μια γλώσσα βρίσκεται στη λίστα

Ο Karl προσπαθεί να θυμηθεί αν ήθελε να μάθει Python ή Ruby.
Όρισε μια μέθοδο με το όνομα `containsLanguage` που παίρνει τη γλώσσα για την οποία ρωτάει, για να μάθει ο Karl!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Όρισε μια συνάρτηση που προσδιορίζει αν η λίστα είναι συναρπαστική

Αν ο Karl θέλει να μάθει Java ή Kotlin, αυτό είναι πολύ συναρπαστικό!
Όρισε μια μέθοδο με το όνομα `isExciting` που επιστρέφει αληθής αν ο Karl θέλει να μάθει Java ή Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
