# Οδηγίες

Σε αυτήν την άσκηση, θα φτιάξεις τη διαχείριση σφαλμάτων για μια απλή αριθμομηχανή ακεραίων.
Η αριθμομηχανή θα πρέπει να υποστηρίζει πράξεις πρόσθεσης, πολλαπλασιασμού και διαίρεσης, επιστρέφοντας το αποτέλεσμα ως μια μορφοποιημένη συμβολοσειρά.
Θα υλοποιήσεις επίσης διαχείριση σφαλμάτων για να αντιμετωπίσεις τις μη έγκυρες πράξεις και τη διαίρεση με το μηδέν.

Στόχος είναι να έχεις μια αριθμομηχανή που λειτουργεί και επιστρέφει μια συμβολοσειρά στην παρακάτω μορφή:

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Υλοποίησε τις πράξεις της αριθμομηχανής

Η κύρια συνάρτηση για αυτήν την εργασία θα είναι η `SimpleCalculator::calculate`, η οποία δέχεται τρία ορίσματα: δύο ακεραίους και ένα `ByteArray` που αντιπροσωπεύει την πράξη.
Υλοποίησε τις παρακάτω πράξεις:

- **Πρόσθεση** με το σύμβολο `+`
- **Πολλαπλασιασμός** με το σύμβολο `*`
- **Διαίρεση** με το σύμβολο `/`

## 2. Διαχειρίσου τις μη έγκυρες πράξεις

Αν το σύμβολο της πράξης είναι κάτι άλλο εκτός από `+`, `*` ή `/`, η αριθμομηχανή θα πρέπει είτε να κάνει panic είτε να επιστρέψει ένα σφάλμα:

- Αν η πράξη είναι κενή συμβολοσειρά, κάνε panic με ένα μήνυμα σφάλματος `ByteArray` `"Operation cannot be an empty string"`.
- Για οποιαδήποτε άλλη μη έγκυρη πράξη, επίστρεψε `Result::Err("Operation is out of range")`.

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. Διαχειρίσου τα σφάλματα κατά τη διαίρεση με το μηδέν

Όταν επιχειρείς να διαιρέσεις με το `0`, η αριθμομηχανή θα πρέπει να κάνει panic με ένα μήνυμα σφάλματος που να δηλώνει ότι η διαίρεση με το μηδέν δεν επιτρέπεται.
Το αποτέλεσμα που επιστρέφεται θα πρέπει να είναι μια τιμή `felt252` ίση με `'Division by zero is not allowed'`.

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
