# Προσθήκη οδηγιών

## Υπόδειξη για την απόδοση

Όλες οι είσοδοι και οι έξοδοι είναι σε ASCII.
Οι τύποι `String` και `&str` της Rust είναι utf8, οπότε ενώ κάποιος θα περίμενε το `"Hello".chars()` να είναι απλό, στην πραγματικότητα χρειάζεται να ελέγχει κάθε χαρακτήρα για να δει αν έχει μήκος 1, 2, 3 ή 4 `u8`.
Αν ξέρουμε ότι ένα `&str` είναι ASCII, τότε μπορούμε να καλέσουμε το `.as_bytes()` και να αναφερθούμε στα υποκείμενα δεδομένα ως `&[u8]` (ένα τμήμα από byte).
Η επανάληψη πάνω σε ένα τμήμα από byte ASCII είναι πολύ πιο γρήγορη, καθώς δεν εμπλέκονται κωδικά σημεία. Κάθε byte ASCII έχει μήκος ένα `u8`.

Μπορείς να ολοκληρώσεις την πρόκληση χωρίς να κλωνοποιήσεις την είσοδο;
