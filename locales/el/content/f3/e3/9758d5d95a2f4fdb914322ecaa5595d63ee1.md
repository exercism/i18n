# Στατικές λέξεις-κλειδιά κλάσης

Μια κλάση είναι μια μονάδα οργάνωσης κώδικα στην PHP, που συχνά αντιπροσωπεύει ένα στιγμιότυπο ενός πράγματος/υπηρεσίας/διαδικασίας.
Χρησιμοποιώντας τις λέξεις-κλειδιά `static` και `self`, ιδιότητες και μέθοδοι μπορούν να υπάρχουν με αναφορά στην κλάση για όλα τα στιγμιότυπα (ή για κανένα στιγμιότυπο).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Περιορισμός

Οι στατικές μέθοδοι κλάσης μπορούν να καλέσουν μόνο άλλες στατικές ιδιότητες ή μεθόδους κλάσης από τη δική τους κλάση.
