# εικονικό

## Η επιλογή `--argjson`

Τα tests χρησιμοποιούν την επιλογή `--argjson n 1` του `jq`.
Αυτό δημιουργεί μια μεταβλητή jq με όνομα `$n` που περιέχει την τιμή `1` ως _**αριθμό**_.

Αντίθετα, η επιλογή `--arg n 1`
δημιουργεί μια μεταβλητή jq με όνομα `$n` που περιέχει την τιμή `"1"` ως _**συμβολοσειρά**_.

Στη λύση σου, χρησιμοποίησε το `$n` ως είσοδο για να βρεις τον n-οστό πρώτο αριθμό.

Δες την ενότητα [Κλήση του jq][man-invoke] στο εγχειρίδιο.

[man-invoke]: https://jqlang.org/manual/#invoking-jq
