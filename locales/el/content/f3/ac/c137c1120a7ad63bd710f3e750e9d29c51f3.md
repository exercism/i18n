## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά ως σταθερά

Όρισε τη [σταθερά][constants] `EXPECTED_BAKE_TIME` που αντιπροσωπεύει πόσα λεπτά πρέπει να ψηθεί η λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής σου, η λαζάνια πρέπει να είναι στον φούρνο για 40 λεπτά:

```python
>>> print(EXPECTED_BAKE_TIME)
40
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Ολοκλήρωσε τη συνάρτηση `bake_time_remaining()` που παίρνει ως όρισμα τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά χρειάζεται ακόμη να ψηθεί η λαζάνια με βάση τη σταθερά `EXPECTED_BAKE_TIME`.

```python
>>> bake_time_remaining(30)
10
```
