# Υποδείξεις

## 1. Δημιούργησε μια κενή λίστα

Η δημιουργία μιας κενής λίστας είναι ακριβώς το ίδιο με τη δημιουργία μιας λίστας με στοιχεία. Μπορείς να το κάνεις χρησιμοποιώντας `list` ή `quote` σε μια κενή λίστα.

## 2. Πρόσθεσε μια νέα γλώσσα στη λίστα

Η Clojure διαθέτει μια βασική συνάρτηση που μπορεί να [προσθέσει ένα στοιχείο στην αρχή μιας λίστας](https://clojuredocs.org/clojure.core/cons).

## 3. Έλεγξε τη γλώσσα που προστέθηκε τελευταία

Όπως και οι άλλες Lisp, η Clojure έχει μια συνάρτηση που [επιστρέφει το πρώτο στοιχείο μιας λίστας](https://clojuredocs.org/clojure.core/first).

## 4. Αφαίρεσε την πρώτη γλώσσα από τη λίστα

Ομοίως, η Clojure έχει επίσης μια συνάρτηση που [επιστρέφει μια λίστα χωρίς το πρώτο της στοιχείο](https://clojuredocs.org/clojure.core/rest).

## 5. Μέτρησε τις γλώσσες στη λίστα

Ο [αριθμός των στοιχείων](https://clojuredocs.org/clojure.core/count) σε μια λίστα μπορεί εύκολα να επιστραφεί χρησιμοποιώντας μια βασική συνάρτηση της Clojure.

## 6. Βάλε τα όλα μαζί

Θυμήσου ότι οι κλήσεις συναρτήσεων μπορούν να είναι εμφωλευμένες.
