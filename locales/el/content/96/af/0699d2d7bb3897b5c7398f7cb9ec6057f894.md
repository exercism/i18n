# Σχετικά

Όταν μοντελοποιείς δεδομένα που μπορούν να λάβουν μόνο ένα συγκεκριμένο σύνολο πιθανών καταστάσεων, όπως οι ημέρες της εβδομάδας, οι κατευθύνσεις της πυξίδας ή τα κουμπιά ενός χειριστηρίου, βασικοί τύποι όπως `Int` ή `String` έχουν σοβαρά μειονεκτήματα.
Με ακέραιους ή συμβολοσειρές, ο κώδικάς σου πρέπει να ελέγχει συνεχώς για μη έγκυρες τιμές (όπως έναν κωδικό κατάστασης `999` ή ένα ορθογραφικό λάθος όπως `"leftt"`), και οι ανθρώπινοι αναγνώστες δεν μπορούν εύκολα να καταλάβουν τι αντιπροσωπεύουν οι αριθμοί.

Η Swift λύνει αυτό το πρόβλημα με τις [_Enumerations_][enumerations] (συχνά συντομεύονται σε *enums*).
Ένα enum ορίζει έναν κοινό τύπο για μια ομάδα σχετιζόμενων, ονομασμένων τιμών. Επειδή ο μεταγλωττιστής γνωρίζει εκ των προτέρων όλες τις πιθανές περιπτώσεις, μπορεί να ελέγξει τον κώδικά σου για ακρίβεια και πληρότητα κατά τη μεταγλώττιση.
Τα enums μπορούν επίσης να έχουν μεθόδους, αρχικοποιητές και υπολογιζόμενες ιδιότητες.

## Ορισμός των Enums

Όρισε ένα enum χρησιμοποιώντας τη λέξη-κλειδί `enum`, ακολουθούμενη από το όνομα του τύπου, με τις περιπτώσεις του να παρατίθενται μέσα σε άγκιστρα.
Κατά σύμβαση της Swift, το όνομα του τύπου χρησιμοποιεί `UpperCamelCase`, ενώ κάθε περίπτωση χρησιμοποιεί `lowerCamelCase`:

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

Μπορείς επίσης να ορίσεις πολλαπλές περιπτώσεις σε μία γραμμή, χωρισμένες με κόμματα:

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

Για να αναφερθείς σε μια περίπτωση enum, γράψε το όνομα του τύπου enum, μια τελεία (`.`) και το όνομα της περίπτωσης. Μόλις ο τύπος είναι γνωστός ή μπορεί να συναχθεί από τον μεταγλωττιστή, μπορείς να παραλείψεις το όνομα του τύπου και να χρησιμοποιήσεις τη συντομότερη σημειογραφία τελείας:

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## Enums και εντολές switch

Τα enums συνεργάζονται άψογα με τις [εντολές `switch`][enums-and-switches].
Επειδή ένα `switch` στη Swift πρέπει να είναι εξαντλητικό, ο μεταγλωττιστής διασφαλίζει ότι χειρίζεσαι κάθε πιθανή περίπτωση:

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

Αν παραλείψεις οποιαδήποτε περίπτωση χωρίς να παρέχεις μια ρήτρα `default`, ο μεταγλωττιστής αναφέρει ένα σφάλμα:

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Το να απαριθμείς ρητά όλες τις περιπτώσεις είναι συχνά προτιμότερο από το να χρησιμοποιείς `default`. Με αυτόν τον τρόπο, αν προσθέσεις μια νέα περίπτωση στο μέλλον, ο μεταγλωττιστής θα σε ειδοποιήσει αμέσως να ενημερώσεις κάθε εντολή `switch` που χειρίζεται αυτό το enum.

## Μέθοδοι και Αρχικοποιητές

Τα enums μπορούν να ορίσουν μεθόδους και προσαρμοσμένους αρχικοποιητές, ακριβώς όπως οι κλάσεις και οι δομές. Μέσα σε μια μέθοδο enum, το `self` αναφέρεται στην τρέχουσα τιμή της περίπτωσης:

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## Ακατέργαστες τιμές

Οι περιπτώσεις ενός enum μπορούν να προ-συμπληρωθούν με προεπιλεγμένες τιμές που ονομάζονται [_ακατέργαστες τιμές_][raw-values].
Όλες οι ακατέργαστες τιμές σε ένα enum πρέπει να μοιράζονται τον ίδιο τύπο (όπως `Int`, `String` ή `Character`):

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

Μπορείς να αρχικοποιήσεις ένα enum από μια ακατέργαστη τιμή χρησιμοποιώντας το `init(rawValue:)`. Επειδή μπορεί να δοθεί μια μη έγκυρη ακατέργαστη τιμή, αυτός ο αρχικοποιητής επιστρέφει μια προαιρετική τιμή:

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Η Swift μπορεί να αντιστοιχίσει αυτόματα ακατέργαστες τιμές για enums `String` και `Int`:

- Για enums `String`, η ακατέργαστη τιμή κάθε περίπτωσης έχει ως προεπιλογή το όνομα της περίπτωσης.
- Για enums `Int`, οι ακατέργαστες τιμές ξεκινούν από το `0` και αυξάνονται κατά 1, εκτός αν οριστεί διαφορετικά.

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## Συσχετισμένες τιμές

Οι περιπτώσεις ενός enum μπορούν επίσης να αποθηκεύουν προσαρμοσμένες τιμές διαφόρων τύπων μαζί με κάθε περίπτωση, γνωστές ως [_συσχετισμένες τιμές_][associated-values]:

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

Ένα enum μπορεί να χρησιμοποιεί ακατέργαστες τιμές ή συσχετισμένες τιμές, αλλά όχι και τις δύο.

## Αναδρομικά Enums

Μια [αναδρομική απαρίθμηση][recursive-enumerations] είναι ένα enum που έχει ένα άλλο στιγμιότυπο του enum ως συσχετισμένη τιμή για μία ή περισσότερες περιπτώσεις.
Για να ενεργοποιήσεις την αναδρομή, σημείωσε την περίπτωση (ή ολόκληρο το enum) με τη λέξη-κλειδί `indirect`:

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
