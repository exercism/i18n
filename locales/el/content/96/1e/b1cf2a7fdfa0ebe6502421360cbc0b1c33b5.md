# Σχετικά

Στη C#, το [`null` literal][null-keyword] χρησιμοποιείται για να δηλώσει την απουσία μιας τιμής. Ένας _nullable_ τύπος είναι ένας τύπος που επιτρέπει τιμές `null`.

Πριν από τη C# 8.0, οι τύποι αναφοράς ήταν πάντα nullable και οι τύποι τιμών δεν ήταν. Ωστόσο, ένας [τύπος τιμής μπορεί να γίνει nullable][nullable-value-types] προσθέτοντας στο τέλος του ένα ερωτηματικό (`?`).

```csharp
string nullableReferenceType = "hello";
nullableReferenceType = null; // Valid as type is nullable

int nonNullableValueType = 5;
nonNullableValueType = null; // Compile error as type is not nullable

int? nullableValueType = 5; // Define nullable value type
nullableValueType = null;   // Valid as type is nullable
```

Η πρόσβαση σε ένα μέλος μιας μεταβλητής της οποίας η τιμή είναι `null` θα μεταγλωττιστεί κανονικά, αλλά θα έχει ως αποτέλεσμα να πεταχτεί ένα `NullReferenceException` κατά την εκτέλεση:

```csharp
string sentence = "What a nice day!";

// Throws NullReferenceException at runtime
sentence.Length;
```

Για να αντιμετωπιστεί αυτό το συνηθισμένο είδος λάθους, η C# 8 σου επιτρέπει να [ενεργοποιήσεις μια λειτουργία][nullable-csharp-8] που κάνει τους [τύπους αναφοράς μη-nullable από προεπιλογή][nullable-reference-types]:

```csharp
string nonNullableReferenceType = "book";
nonNullableReferenceType = null; // Compile warning (no error!)

string? nullableReferenceType = "movie";
nullableReferenceType = null; // Valid as type is nullable
```

Για να [δουλέψεις με ασφάλεια με nullable τιμές][nullable-types-tutorial], θα πρέπει να ελέγξεις αν είναι `null` πριν δουλέψεις μαζί τους:

```csharp
string NormalizedName(string? name)
{
    if (name == null)
    {
        return "UNKNOWN";
    }
    else
    {
        // Value is not null at this point, so no compile warning
        // and no runtime NullReferenceException being thrown
        return name.ToUpper();
    }
}

NormalizedName(null); // => "UNKNOWN"
NormalizedName("Elisabeth"); // => "ELISABETH"
```

Ο [τελεστής `??`][null-coalescing-operator] σου επιτρέπει να επιστρέψεις μια προεπιλεγμένη τιμή όταν η τιμή είναι `null`:

```csharp
string? name1 = "John";
name1 ?? "Paul"; // => "John"

string? name2 = null;
name2 ?? "George"; // => "George"
```

Ο [τελεστής `?.`][null-conditional-operator] σου επιτρέπει να καλέσεις μέλη με ασφάλεια σε μια τιμή που μπορεί να είναι `null`:

```csharp
string? fruit = "apple";
fruit?.Length; // => 5

string? vegetable = null;
vegetable?.Length; // => null
```

Αν ο μεταγλωττιστής θεωρεί ότι μια τιμή μπορεί να είναι `null` αλλά εσύ είσαι σίγουρος ότι δεν θα είναι, ο [τελεστής `!.`][null-forgiving-operator] μπορεί να χρησιμοποιηθεί για να καταστείλει την προειδοποίηση. Ωστόσο, χρησιμοποίησε αυτόν τον τελεστή μόνο ως τελευταία λύση.

```csharp
void PrintName(string? name)
{
    // Assume that the IsValid() method only return true
    // when its argument is not null
    if (IsValid(name))
    {
        // No compile warning
        Console.WriteLine(name!.Length);
    }
}
```
