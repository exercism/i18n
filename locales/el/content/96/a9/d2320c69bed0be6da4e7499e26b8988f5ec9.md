# Εισαγωγή

Ο τύπος `Result` είναι η λύση της γλώσσας Elm για την αναφορά σφαλμάτων και ένα μέσο που επιτρέπει την ανάκτηση από σφάλματα. Είναι κάπως παρόμοιος με τον τύπο `Maybe`, αλλά ενώ το Maybe μπορεί να επιστραφεί από συναρτήσεις που μπορεί να αποτύχουν, δε σου λέει τίποτα για το γιατί απέτυχε. Το `Result` περιλαμβάνει αυτό το πλαίσιο σχετικά με τον λόγο που κάτι απέτυχε.

Ο τύπος `Result` ορίζεται ως εξής:

```elm
type Result error value
  = Ok value
  | Err error
```

Αυτό είναι γνωστό ως ορισμός "προσαρμοσμένου τύπου" στην ορολογία της Elm.
Το `error` και το `value` στα `OK value` και `Error error` αντιπροσωπεύουν μια μεταβλητή τύπου, που σημαίνει ότι μπορεί να είναι οποιουδήποτε τύπου, όπως `Int`, `Bool` ή `String`.
Ως εκ τούτου, ένα `Result String Int` είναι μια μεταβλητή που αναμένεται να περιέχει ένα `Int`, και αν υπάρξει σφάλμα αυτό θα αναπαρίσταται ως `String`.
Υπάρχει ένα [άρθρωμα Result](https://package.elm-lang.org/packages/elm/core/latest/Result) με πολλές χρήσιμες βοηθητικές συναρτήσεις για το αποτέλεσμα.
