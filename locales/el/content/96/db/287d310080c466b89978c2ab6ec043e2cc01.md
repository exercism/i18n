# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα διαδοχικά ψηφία.
- Μια [τιμή χάρτη][maps] αποθηκεύει δεδομένα κλειδιού-τιμής

## 1. Με δεδομένα μια σκακιέρα και μια στήλη, μέτρησε πόσα τετράγωνα είναι κατειλημμένα

- Μπορείς να διατρέξεις έναν [χάρτη][maps]
- Έλεγξε αν η τιμή είναι αληθής.
  Αν είναι, αύξησέ την.
  Αυτό γίνεται για να μετρήσεις τα πιόνια.
- Πρέπει να [επιστρέψεις ρητά έναν ακέραιο][return] από μια συνάρτηση.

## 2. Με δεδομένα μια σκακιέρα και μια γραμμή, μέτρησε πόσα τετράγωνα είναι κατειλημμένα

- Πρώτα θα χρειαστεί να ελέγξεις ότι η γραμμή βρίσκεται εντός ορίων.
- Διάσχισε τη σκακιέρα με έναν βρόχο.
- Πρόσθεσε ένα αν το τετράγωνο είναι κατειλημμένο.

## 3. Μέτρησε πόσα τετράγωνα υπάρχουν στη δεδομένη σκακιέρα

- Υπάρχουν πολλοί τρόποι να το λύσεις.
- Αυτό θα πρέπει να επιστρέφει πόσα τετράγωνα είναι ρυθμισμένα σε μια σκακιέρα.

## 4. Μέτρησε πόσα τετράγωνα είναι κατειλημμένα στη δεδομένη σκακιέρα

- Πάρε το CountInFile για όλες τις στήλες της σκακιέρας.
