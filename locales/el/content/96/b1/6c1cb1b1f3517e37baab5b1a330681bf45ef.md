# Διαδρομή

Μια διαδρομή αποτελείται από πολλά διαφορετικά μέρη.

## Μεταδεδομένα

Η διαμόρφωση και τα μεταδεδομένα της διαδρομής ορίζονται στο αρχείο `config.json`. Περιέχει τις ασκήσεις, τις έννοιες και τις ρυθμίσεις του editor της διαδρομής, και πολλά άλλα. Ρίξε μια ματιά στην [τεκμηρίωση του config.json](/docs/building/tracks/config-json).

## Έννοιες

Όλες οι ασκήσεις εννοιών και εξάσκησης μιας διαδρομής αφορούν _έννοιες_. Αυτές οι έννοιες είναι από μόνες τους ξεχωριστές οντότητες. Δες την [τεκμηρίωση](/docs/building/tracks/concepts) για περισσότερες πληροφορίες.

Οι έννοιες που διδάσκονται στις ασκήσεις εννοιών της διαδρομής σχηματίζουν ένα _πρόγραμμα σπουδών_.
Το _πρόγραμμα σπουδών_ παρουσιάζεται στους μαθητές ως _χάρτης εννοιών_.
Δες την τεκμηρίωση του [_χάρτη εννοιών_](/docs/building/tracks/concept-map) για να μάθεις πώς να αναπτύξεις τον χάρτη εννοιών για ένα _πρόγραμμα σπουδών_.

Για περισσότερες πληροφορίες σχετικά με τον σχεδιασμό ενός προγράμματος σπουδών, δες την [τεκμηρίωση του προγράμματος σπουδών](/docs/building/tracks/syllabus).

## Ασκήσεις

Οι διαδρομές έχουν δύο τύπους ασκήσεων:

- Ασκήσεις εννοιών: είναι σχεδιασμένες για να διδάξουν μία ή περισσότερες έννοιες σε έναν μαθητή. Δες την [τεκμηρίωση](/docs/building/tracks/concept-exercises) για περισσότερες πληροφορίες.
- Ασκήσεις εξάσκησης: είναι σχεδιασμένες για εξάσκηση πάνω σε έννοιες που έχουν μαθευτεί. Δες την [τεκμηρίωση](/docs/building/tracks/practice-exercises) για περισσότερες πληροφορίες.

### Πιο βαθιά

Κάθε άσκηση έχει μια προαιρετική ενότητα Πιο βαθιά που μπορεί να περιέχει:

- [Προσεγγίσεις](/docs/building/tracks/approaches): διαφορετικούς τρόπους με τους οποίους μπορεί να λυθεί η άσκηση
- [Άρθρα](/docs/building/tracks/articles): περιγράφουν ενδιαφέρουσες πτυχές της άσκησης
- Βίντεο της κοινότητας: βίντεο που παρουσιάζουν την άσκηση, συνήθως με κάποιον να τη λύνει από το μηδέν

## Κοινόχρηστα αρχεία

Μερικά αρχεία δεν είναι ειδικά για μεμονωμένες ασκήσεις, αλλά ισχύουν για _όλες_ τις ασκήσεις. Δες την [τεκμηρίωση](/docs/building/tracks/shared-files) για περισσότερες πληροφορίες.

## Τεκμηρίωση

Κάθε διαδρομή έχει μερικά απαιτούμενα αρχεία τεκμηρίωσης. Δες την [τεκμηρίωση](/docs/building/tracks/docs) για περισσότερες πληροφορίες.

## Widgets

Κάποια μέρη της διαδρομής μπορούν να εμφανιστούν σε [widgets](/docs/building/markdown/widgets).

## Οδηγός στυλ

Όλα τα έγγραφα πρέπει να ακολουθούν τον [οδηγό στυλ](/docs/building/markdown/style-guide). Τα έγγραφα Markdown
πρέπει επίσης να ακολουθούν τα [πρότυπα Markdown](/docs/building/markdown/markdown).

## Συντήρηση

### Δικαιώματα αποθετηρίου

Κάθε διαδρομή λαμβάνει (αυτόματα) μια [κατηγορία συντήρησης](/docs/building/github/maintainers-repo-permissions#maintenance-category), η οποία καθορίζει τα [δικαιώματα του συντηρητή της διαδρομής στο αποθετήριο GitHub](/docs/building/github/maintainers-repo-permissions#repo-permissions).

### Πώς να αποφεύγεις περιττές εκτελέσεις tests

Όταν κάνεις merge ένα PR μιας διαδρομής που αγγίζει μια άσκηση, προκαλείς να ελεγχθούν ξανά _όλες_ οι τελευταίες δημοσιευμένες εκδόσεις των λύσεων των μαθητών.
Για δημοφιλείς ασκήσεις, αυτή είναι μια _πολύ_ ακριβή διαδικασία (70.000 εκτελέσεις tests για το Hello World της Python, σε ακραία περίπτωση!).

**Σε ενθαρρύνουμε να προσπαθήσεις να το αποφύγεις όταν δεν είναι απαραίτητο.**

Οι λύσεις **δεν** θα ελεγχθούν ξανά αν το commit που έγινε merge είτε:

- αγγίζει μόνο αρχεία `.docs` ή `.meta`, ή άλλα αρχεία με τα οποία δεν αλληλεπιδρούν οι χρήστες
- ή περιέχει το `[no important files changed]` στο σώμα του commit.

Οι λύσεις **θα** ελεγχθούν ξανά αν το commit που έγινε merge πληροί και τις δύο παρακάτω προϋποθέσεις:

- του λείπει το `[no important files changed]` από το σώμα του commit
- και αγγίζει ένα από τα παρακάτω αρχεία μιας άσκησης (όπως ορίζονται στο αρχείο `.meta/config.json` της):
  - αρχεία tests
  - αρχεία του editor
  - αρχεία invalidator

Μερικά παραδείγματα:

- [Python#3423](https://github.com/exercism/python/pull/3423): Αγγίζει μόνο αρχεία τεκμηρίωσης, οπότε δεν εκτελέστηκαν tests
- [Python#3437](https://github.com/exercism/python/commit/29a64a4889f94bafbd0062d7fc5052858523b25c): Έγινε merge με προσθήκη του `[no important files changed]`, οπότε δεν εκτελέστηκαν tests
- [Csharp#2138](https://github.com/exercism/csharp/pull/2138): Αφαιρέθηκαν τα κενά διαστήματα από τα tests. Η λέξη-κλειδί **δεν** προστέθηκε. Τα tests εκτελέστηκαν ξανά χωρίς λόγο.
