# Εισαγωγή

Η Haskell διαθέτει έναν τύπο, `Num`, ο οποίος είναι ο βασικός τύπος για όλους τους αριθμητικούς τύπους.
Υπάρχουν τέσσερις κύριοι υποτύποι μέσα στον τύπο Number: [`Int`][int], [`Integer`][integer], [`Double`][double] και [`Float`][float].

Υπάρχουν δύο τύποι ακεραίων στη Haskell, οι οποίοι αναπαριστούν ακέραιους αριθμούς.
Το `Int` είναι ένας ακέραιος σταθερού μεγέθους, ενώ το `Integer` είναι ένας ακέραιος αυθαίρετης ακρίβειας.
Ένα `Integer` κρατά οποιονδήποτε αριθμό, όσο μεγάλος κι αν είναι, μέχρι το όριο της μνήμης του υπολογιστή σου, ενώ το `Int` αντιστοιχεί στο σύνολο των θετικών και αρνητικών ακεραίων που μπορούν να παρασταθούν σε 32 ή 64 bits (εγγυημένα τουλάχιστον από -2^29 έως 2^29 - 1).

Σημείωσε ότι όταν γράφεις αρνητικούς αριθμούς, πρέπει να χρησιμοποιείς παρενθέσεις για να αποφεύγεις την ασάφεια.

```haskell
1

(-1)
```

Το `Float` αντιστοιχεί στο σύνολο των πραγματικών αριθμών, περιορισμένο από την ακρίβεια του υπολογιστή.
Οι πράξεις που ορίζονται στους αριθμούς συνήθως λειτουργούν στον έναν τύπο ή στον άλλον, αλλά όχι και στους δύο.
Το `Double` είναι ένας αριθμός κινητής υποδιαστολής με διπλή ακρίβεια.

```haskell
10.5
```

## Μετατροπή μεταξύ ακεραίων και αριθμών κινητής υποδιαστολής

Χρησιμοποιώντας τη συνάρτηση `toFloat`, μπορείς να μετατρέψεις ένα `Int` ή `Integer` σε `Float`.

```haskell
toFloat 1
-- -> 1.0
```

Υπάρχει επίσης η `fromIntegral`, η οποία μετατρέπει οποιονδήποτε αριθμητικό τύπο στον αριθμητικό τύπο που συνάγεται ως απαραίτητος.

```haskell
fromIntegral 1
-- -> 1.0
```

Για να μετατρέψεις ένα `Float` σε `Int`, μπορείς να χρησιμοποιήσεις τις συναρτήσεις [`round`][round], [`floor`][floor] ή [`ceiling`][ceiling].
Η συνάρτηση `round` στρογγυλοποιεί στον πλησιέστερο ακέραιο, η `floor` στρογγυλοποιεί προς τα κάτω και η `ceiling` προς τα πάνω.

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## Αριθμητικοί τελεστές

Μπορείς να χρησιμοποιήσεις τους [βασικούς αριθμητικούς τελεστές][math] στους αριθμητικούς τύπους.
Οι τελεστές είναι `+`, `-`, `*`, `/` και `%`.
Όταν χρησιμοποιείς αυτούς τους τελεστές, οι τύποι των αριθμών πρέπει να ταιριάζουν.
Η συνάρτηση `fromIntegral` θα κάνει τη μετατροπή ώστε να ταιριάζουν οι τύποι.

### Πρόσθεση, αφαίρεση και πολλαπλασιασμός

Ο τελεστής `+` χρησιμοποιείται για την πρόσθεση, ο τελεστής `-` για την αφαίρεση και ο τελεστής `*` για τον πολλαπλασιασμό.

| Τελεστής | Παράδειγμα        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Διαίρεση

Η διαίρεση χρησιμοποιείται για να διαιρείς αριθμούς.
Ο τελεστής `/` χρησιμοποιείται για τη διαίρεση.
Το αποτέλεσμα θα είναι πάντα ένας αριθμός κινητής υποδιαστολής.

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
Σε ορισμένες γλώσσες προγραμματισμού, όταν διαιρείς με το μηδέν, το αποτέλεσμα θα είναι σφάλμα.

Στη Haskell, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι `Infinity` ή `-Infinity`.
Η μόνη εξαίρεση είναι η διαίρεση του μηδέν με το μηδέν, που έχει ως αποτέλεσμα `NaN` (όχι αριθμός).

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## Ακέραια διαίρεση

Η ακέραια διαίρεση χρησιμοποιείται για να διαιρείς ακέραιους αριθμούς και να παίρνεις το ακέραιο μέρος του αποτελέσματος.
Η Haskell έχει δύο συναρτήσεις ακέραιας διαίρεσης, οι οποίες διαφέρουν στον τρόπο που στρογγυλοποιούν όταν το αποτέλεσμα είναι αρνητικό:

- Η `div` στρογγυλοποιεί προς τα κάτω, προς το αρνητικό άπειρο.
- Η `quot` στρογγυλοποιεί προς το μηδέν.

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς ακέραια διαίρεση έχει ως αποτέλεσμα μια εξαίρεση.
Αυτό διαφέρει από την κανονική διαίρεση.
~~~~

### Υπόλοιπο

Το υπόλοιπο μιας ακέραιας διαίρεσης μπορεί να βρεθεί χρησιμοποιώντας τη `mod` ή τη `rem`.
Διαφέρουν στο πρόσημο του αποτελέσματος όταν ένας από τους αριθμούς είναι αρνητικός:

- Η `mod` πάει μαζί με τη `div` και το αποτέλεσμά της έχει το ίδιο πρόσημο με τον διαιρέτη.
- Η `rem` πάει μαζί με τη `quot` και το αποτέλεσμά της έχει το ίδιο πρόσημο με τον διαιρετέο.

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

Για οποιαδήποτε `x` και `y` (με το `y` διάφορο του μηδενός), ισχύουν οι εξής νόμοι:

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
Όταν και οι δύο αριθμοί είναι θετικοί, οι `div` και `quot` δίνουν το ίδιο αποτέλεσμα, όπως και οι `mod` και `rem`.
Σε αυτή την περίπτωση, οι `quot` και `rem` μπορεί να είναι ελαφρώς πιο αποδοτικές, καθώς οι `div` και `mod` χρειάζονται επιπλέον βήματα για να χειριστούν αρνητικούς αριθμούς.
~~~~

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς τη `mod` ή τη `rem` έχει ως αποτέλεσμα μια εξαίρεση.
Αυτό διαφέρει από την κανονική διαίρεση.

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## Ύψωση σε δύναμη

Η Haskell έχει τρεις τελεστές "ύψωσης σε δύναμη" που λειτουργούν διαφορετικά και δέχονται διαφορετικούς τύπους ορισμάτων.

- Ο `**` δέχεται δύο **αριθμούς κινητής υποδιαστολής** και χρησιμοποιεί λογάριθμους για να υπολογίσει τη δύναμη.
- Ο `^^` δέχεται έναν **αριθμό κινητής υποδιαστολής** και τον υψώνει σε θετική ή αρνητική **ακέραια** δύναμη.
- Ο `^` δέχεται **οποιονδήποτε αριθμητικό τύπο** και τον υψώνει σε **θετική ακέραια** δύναμη.

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## Προτεραιότητα και παρενθέσεις

Η Haskell επιτρέπει παρενθέσεις (`()`), οι οποίες μπορούν να χρησιμοποιηθούν για την ομαδοποίηση παραστάσεων.
Αυτό είναι χρήσιμο όταν θέλεις να αλλάξεις τη σειρά των πράξεων.

Όταν χρησιμοποιείς πολλούς αριθμητικούς τελεστές, η σειρά των πράξεων είναι ίδια με αυτή στα μαθηματικά, γνωστή και ως [PEMDAS][pemdas].
Ακολουθεί τη σειρά των παρενθέσεων (`()`), των εκθετών (`**`), του πολλαπλασιασμού (`*`) και της διαίρεσης (`/`), και της πρόσθεσης (`+`) και της αφαίρεσης (`-`).

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
