# Προσθήκη οδηγιών

## Αποδεικνύοντας θεωρήματα στη Lean

Η απόδειξη θεωρημάτων είναι αναπόσπαστο κομμάτι της Lean.
Δίνει τη δυνατότητα στους προγραμματιστές να αποδεικνύουν ιδιότητες των προγραμμάτων τους, να συλλογίζονται τη συμπεριφορά τους και να κωδικοποιούν περιορισμούς και προδιαγραφές σε επίπεδο τύπων.

[Αυτό το κεφάλαιο][introduction] αποτελεί μια καλή εισαγωγή στην απόδειξη θεωρημάτων στη Lean.
Για μια πιο βαθιά ματιά, [αυτό το βιβλίο][advanced] αναφέρεται ως επίσημος πόρος στην ιστοσελίδα της Lean.

Η Lean προσφέρει πολλές τακτικές που μπορούν να αυτοματοποιήσουν αποδείξεις, ή μέρη τους.
Ίσως θελήσεις να δεις μια [αναφορά γλώσσας][reference].

~~~~exercism/advanced
Μπορούμε να χρησιμοποιήσουμε το χαρακτηριστικό του μεταγλωττιστή `csimp` σε ένα θεώρημα που αποδεικνύει την ισότητα μεταξύ δύο ορισμών.
Αυτό το χαρακτηριστικό δίνει εντολή στον μεταγλωττιστή να χρησιμοποιήσει τον δεύτερο ορισμό στη θέση του πρώτου:

```lean
@[csimp]
theorem custom_reverse_eq_spec_reverse : @Extra.custom_reverse = @List.reverse := by
    ... -- proof here

-- now any occurrence of `Extra.custom_reverse` may now compile to `List.reverse`.
```

Είναι ιδιαίτερα χρήσιμο σε περιπτώσεις όπου μια υλοποίηση είναι πιο αποδοτική αλλά λιγότερο σαφής.
Μπορούμε να γράψουμε μια απλή προδιαγραφή και να αφήσουμε τον μεταγλωττισμένο κώδικα να χρησιμοποιήσει την πιο αποδοτική υλοποίηση αντ' αυτής.
Πολλές συναρτήσεις των `List` και `Array` χρησιμοποιούν αυτό το μοτίβο.
~~~~
