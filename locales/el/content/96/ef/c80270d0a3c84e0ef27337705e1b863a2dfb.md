# Μετασχηματισμός XML δεδομένων καυσίμου

## Δήλωση προβλήματος

Κάθε εργαζόμενος της ABC Corp λαμβάνει απεριόριστο επίδομα καυσίμων. Οι εργαζόμενοι πρέπει να στέλνουν μια καταγραφή κάθε φορά που γεμίζουν τα οχήματά τους. Αυτές οι καταγραφές προστίθενται στο ίδιο αρχείο XML και υποβάλλονται σε επεξεργασία στο τέλος του μήνα.

Ως μέλος της ομάδας ψηφιακών λειτουργιών, η δουλειά σου είναι να διαβάσεις αυτό το αρχείο XML και να γράψεις τα αποτελέσματα σε ένα άλλο αρχείο XML. Το αρχείο εξόδου πρέπει να περιέχει μια καταχώριση για κάθε εργαζόμενο με τις παρακάτω λεπτομέρειες:

Σου δίνονται δύο ορίσματα `string`.

1. Διαδρομή του αρχείου XML εισόδου.
1. Διαδρομή του αρχείου XML εξόδου.

Το περιεχόμενο του αρχείου XML εισόδου θα ακολουθεί το παρακάτω σχήμα XML.

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema" 
    targetNamespace="http://www.so2w.org" 
    xmlns:tns="http://www.so2w.org" 
    elementFormDefault="qualified">

    <xs:element name="FuelEvents">
        <xs:complexType>
            <xs:sequence>
                <xs:element name="FuelEvent" type="tns:FuelUpEvent" nillable="true" minOccurs="0" maxOccurs="1000"/>
            </xs:sequence>
        </xs:complexType>
    </xs:element>

    <xs:complexType name="FuelEvent">
        <xs:sequence>
            <xs:element name="odometerReading" type="xs:integer"/>
            <xs:element name="gallons" type="xs:decimal"/>
            <xs:element name="gasPrice" type="xs:decimal"/>
        </xs:sequence>
        <xs:attribute name="employeeId" type="xs:integer" use="required"/>
    </xs:complexType>
</xs:schema>
```

Η δουλειά σου είναι να μετασχηματίσεις την είσοδο XML στην παρακάτω μορφή XML και να γράψεις το περιεχόμενο στη διαδρομή που σου δίνεται. Το αρχείο εξόδου πρέπει να περιέχει μια καταχώριση για κάθε εργαζόμενο, ταξινομημένη σε αύξουσα σειρά κατά `employeeId`.

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema"
   targetNamespace="http://www.so2w.org"
   xmlns:tns="http://www.so2w.org"
   elementFormDefault="qualified">
 
   <xs:element name="employeeFuelRecords">
       <xs:complexType>
           <xs:sequence>
               <xs:element name="employeeFuelRecord" type="tns:employeeFuelRecord" nillable="true" minOccurs="0" maxOccurs="97"/>
           </xs:sequence>
       </xs:complexType>
   </xs:element>
 
   <xs:complexType name="employeeFuelRecord">
       <xs:sequence>
           <xs:element name="gasFillUpCount" type="xs:integer"/>
           <xs:element name="totalFuelCost" type="xs:decimal"/>
           <xs:element name="totalGallons" type="xs:decimal"/>
           <xs:element name="totalMilesAccrued" type="xs:integer"/>
       </xs:sequence>
       <xs:attribute name="employeeId" type="xs:integer" use="required"/>
   </xs:complexType>
</xs:schema>
```

## Περιορισμοί

- Αριθμός καταγραφών ανεφοδιασμού `n` στο αρχείο XML εισόδου:  0 <= n <= 1000
- Αριθμός εργαζομένων στην εταιρεία: 97
- Η τιμή της βενζίνης είναι ανά γαλόνι
- Δεν λείπουν καταγραφές ανεφοδιασμού

## Παράδειγμα 1

- Είσοδος: `example01_input.xml`

```xml
<s:FuelEvents xmlns:s="http://www.so2w.org">
    <s:FuelEvent employeeId="2312">
        <s:odometerReading>230</s:odometerReading>
        <s:gallons>18.561</s:gallons>
        <s:gasPrice>4.56</s:gasPrice>
    </s:FuelEvent>
    <s:FuelEvent employeeId="2312">
        <s:odometerReading>500</s:odometerReading>
        <s:gallons>19.345</s:gallons>
        <s:gasPrice>4.89</s:gasPrice>
    </s:FuelEvent>
</s:FuelEvents>
```

- Έξοδος: `example01_output.xml`

```xml
<s:employeeFuelRecords xmlns:s="http://www.so2w.org">
    <s:employeeFuelRecord employeeId="2312">
        <s:gasFillUpCount>2</s:gasFillUpCount>
        <s:totalFuelCost>179.23521</s:totalFuelCost>
        <s:totalGallons>37.906</s:totalGallons>
        <s:totalMilesAccrued>270</s:totalMilesAccrued>
    </s:employeeFuelRecord>
</s:employeeFuelRecords>
```
