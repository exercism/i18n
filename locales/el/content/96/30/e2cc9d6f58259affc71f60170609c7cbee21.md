# Οδηγίες

Ως λάτρης του σκακιού, θα ήθελες να γράψεις τη δική σου εκδοχή του παιχνιδιού. Ναι, ίσως υπάρχουν ήδη πολλές υλοποιήσεις του σκακιού διαθέσιμες στο διαδίκτυο, αλλά η δική σου θα είναι μοναδική!

Αλλά πριν αφήσεις τη φαντασία σου ελεύθερη, πρέπει να φροντίσεις τα βασικά. Ας ξεκινήσουμε φτιάχνοντας τη σκακιέρα.

Κάθε τετράγωνο της σκακιέρας προσδιορίζεται από ένα ζεύγος γράμματος και αριθμού. Οι κάθετες σειρές των τετραγώνων, που ονομάζονται στήλες, φέρουν ετικέτες από το A έως το H. Οι οριζόντιες σειρές, που ονομάζονται γραμμές, είναι αριθμημένες από το 1 έως το 8.

## 1. Όρισε το εύρος των γραμμών

Υλοποίησε τη συνάρτηση `rank_range/0`. Θα πρέπει να επιστρέφει ένα εύρος ακεραίων, από το 1 έως το 8.

```elixir
Chessboard.rank_range()
```

## 2. Όρισε το εύρος των στηλών

Υλοποίησε τη συνάρτηση `file_range/0`. Θα πρέπει να επιστρέφει ένα εύρος ακεραίων, από το σημείο κωδικοποίησης του κεφαλαίου γράμματος A, έως το σημείο κωδικοποίησης του κεφαλαίου γράμματος H.

```elixir
Chessboard.file_range()
```

## 3. Μετέτρεψε το εύρος των γραμμών σε λίστα γραμμών

Υλοποίησε τη συνάρτηση `ranks/0`. Θα πρέπει να επιστρέφει μια λίστα ακεραίων, από το 1 έως το 8. Μη γράψεις τη λίστα στο χέρι, δημιούργησέ τη από το εύρος που επιστρέφει η συνάρτηση `rank_range/0`.

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. Μετέτρεψε το εύρος των στηλών σε λίστα στηλών

Υλοποίησε τη συνάρτηση `files/0`. Θα πρέπει να επιστρέφει μια λίστα με γράμματα (συμβολοσειρές), από το "A" έως το "H". Μη γράψεις τη λίστα στο χέρι, δημιούργησέ τη από το εύρος που επιστρέφει η συνάρτηση `file_range/0`.

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
