# Περιττή εντολή `if`

Αντί να δημιουργήσεις ένα μπλοκ `if (...) {}`, αξιοποίησε απευθείας την τιμή Boolean που μπορεί να επιστραφεί από τον έλεγχο της τιμής της παραμέτρου.

Για παράδειγμα, το παρακάτω:

```javascript
if (param === true) {
  return true;
}
```

μπορεί να μετατραπεί σε:

```javascript
return param === true;
```
