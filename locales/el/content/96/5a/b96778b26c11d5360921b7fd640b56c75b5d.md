# Οδηγίες

Ο λοστρόμος κάνει μια καθημερινή ενημέρωση βάρδιας στο κατάστρωμα: έναν σταθερό χαιρετισμό, ένα προσκλητήριο του πληρώματος που έχει βάρδια και στο τέλος ένα κλείσιμο για την απόλυση. Θα αναλύσεις την ενημέρωση σε μικρές ονομασμένες γραμμές και θα τις συνθέσεις.

Θα επεξεργαστείς **δύο αρχεία** για αυτή την άσκηση:

- `bosuns-briefing/helpers/helpers.factor` — μικρά επαναχρησιμοποιήσιμα κομμάτια. Λεξιλόγιο: `bosuns-briefing.helpers`.
- `bosuns-briefing/bosuns-briefing.factor` — το κύριο αρχείο που συνθέτει τα βοηθητικά. Λεξιλόγιο: `bosuns-briefing`.

## 1. Χαιρετισμός

Στο `helpers.factor`, όρισε το `greeting` ώστε να επιστρέφει τη σταθερή συμβολοσειρά έναρξης `"All hands, attention!"`.

```factor
greeting .
! => "All hands, attention!"
```

## 2. Γραμμή πληρώματος

Στο `helpers.factor`, όρισε το `crew-line` ώστε να παίρνει μια συμβολοσειρά ονόματος και να επιστρέφει αυτό το όνομα με πρόθεμα `"  - "` (δύο κενά, μια παύλα, ένα κενό).

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. Κλείσιμο

Στο `helpers.factor`, όρισε το `closing` ώστε να επιστρέφει τη σταθερή συμβολοσειρά απόλυσης `"Carry on."`.

```factor
closing .
! => "Carry on."
```

## 4. Κατάσταση πληρώματος

Στο `bosuns-briefing.factor`, όρισε το `roster` ώστε να παίρνει έναν πίνακα με ονόματα πληρώματος και να επιστρέφει μία συμβολοσειρά πολλών γραμμών, όπου κάθε όνομα είναι μορφοποιημένο από το `crew-line`, ενωμένα με αλλαγές γραμμής.

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. Ενημέρωση

Στο `bosuns-briefing.factor`, όρισε το `briefing` ώστε να παίρνει έναν πίνακα με ονόματα πληρώματος και να επιστρέφει την πλήρη ενημέρωση ως μία συμβολοσειρά: τον χαιρετισμό στην πρώτη γραμμή, την κατάσταση στις επόμενες γραμμές και το κλείσιμο στην τελευταία γραμμή. Χρησιμοποίησε τα βοηθητικά και το `roster`.

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
