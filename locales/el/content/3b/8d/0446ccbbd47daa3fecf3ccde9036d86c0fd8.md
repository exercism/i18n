# Παράρτημα οδηγιών

## Υλοποίηση

Υλοποίησε τις μεθόδους `get` και `post` της κλάσης `RestAPI`.

Θα πρέπει να γράψεις μόνο τις συναρτήσεις διαχείρισης, χωρίς να υλοποιήσεις έναν πραγματικό διακομιστή HTTP. Μπορείς να προσομοιώσεις τη βάση δεδομένων χρησιμοποιώντας ένα αντικείμενο στη μνήμη που θα περιέχει όλους τους αποθηκευμένους χρήστες. Ο κατασκευαστής της κλάσης `RestAPI` θα πρέπει να δέχεται ως όρισμα ένα στιγμιότυπο αυτής της βάσης δεδομένων (και να ορίζει μια προεπιλεγμένη τιμή γι' αυτό αν δεν έχει περαστεί όρισμα).

Για αυτή την υλοποίηση, σε περίπτωση ενός αιτήματος `GET`, το φορτίο θα πρέπει να αποτελεί μέρος του URL και να αντιμετωπίζεται σαν παραμέτρους ερωτήματος, για παράδειγμα `/users?users=Adam,Bob`.
