# Εισαγωγή

## Συμβολοσειρές

Θυμήσου ότι το `jq` υποστηρίζει τους ίδιους τύπους δεδομένων όπως το JSON.
Το JSON περιγράφει τις **συμβολοσειρές** ως εξής:

> Μια συμβολοσειρά είναι μια ακολουθία από μηδέν ή περισσότερους χαρακτήρες Unicode, μέσα σε διπλά εισαγωγικά, με χρήση διαφυγών με ανάποδη κάθετο.

### Ακολουθίες διαφυγής

Μέσα σε μια συμβολοσειρά, χρησιμοποίησε τον χαρακτήρα της ανάποδης κάθετου για να ενσωματώσεις "ειδικούς" χαρακτήρες:

- `\"` ένα κυριολεκτικό εισαγωγικό,
- `\\` μια κυριολεκτική ανάποδη κάθετος,
- χαρακτήρες κενού `\n`, `\t`, `\r`, `\f`, `\b`
- χαρακτήρες Unicode `\uAAAA`, όπου το `A` είναι ένα δεκαεξαδικό ψηφίο

### Μήκος συμβολοσειράς

Για να βρεις τον αριθμό των χαρακτήρων, χρησιμοποίησε τη συνάρτηση `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### Υποσυμβολοσειρές

Ο συμβολισμός **slice** μπορεί να χρησιμοποιηθεί για την εξαγωγή υποσυμβολοσειρών.
Η σύνταξη είναι `.[i:j]`.
Η υποσυμβολοσειρά που επιστρέφεται έχει μήκος `j - i` και περιέχει χαρακτήρες από τη θέση `i` (συμπεριλαμβανομένης) μέχρι τη θέση `j` (μη συμπεριλαμβανομένης).
Οποιαδήποτε από τις δύο θέσεις μπορεί να είναι αρνητική, οπότε μετράει προς τα πίσω από το τέλος της συμβολοσειράς.
Οποιαδήποτε από τις δύο θέσεις μπορεί να παραλειφθεί, οπότε αναφέρεται στην αρχή ή στο τέλος της συμβολοσειράς.
Οι θέσεις ξεκινούν από το μηδέν.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### Συνένωση

Χρησιμοποίησε το `+` για να ενώσεις συμβολοσειρές:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Χρησιμοποίησε το `add` όταν σου δίνεται ένας πίνακας από συμβολοσειρές:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### Διαχωρισμός και ένωση

Ο διαχωρισμός χρησιμοποιεί τη συνάρτηση `split/1` ή τον τελεστή `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Το αντίστροφο του `split/1` είναι το `join/1`.

Η μετατροπή μιας συμβολοσειράς σε πίνακα χαρακτήρων είναι συχνά απαραίτητη.
Υπάρχουν δύο τρόποι για να το κάνεις:

1. χώρισέ την με βάση την κενή συμβολοσειρά

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` σε πίνακα _κωδικών σημείων_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   Το `implode` είναι το αντίστροφο του `explode`.

### Βρες τη θέση μιας υποσυμβολοσειράς

Χρησιμοποίησε τη συνάρτηση `index/1`· η θέση ξεκινά από το μηδέν.

```jq
"hello" | index("el")'   # => 1
```

Αν η υποσυμβολοσειρά δεν υπάρχει μέσα στη συμβολοσειρά, το αποτέλεσμα είναι `null`.

```jq
"hello" | index("elk")   # => null
```

### Παρεμβολή συμβολοσειρών

Μέσα σε μια συμβολοσειρά, η ακολουθία `\(expression)` ενσωματώνει το _αποτέλεσμα_ αυτής της έκφρασης [μέσα στη συμβολοσειρά][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### Μετατροπή πεζών/κεφαλαίων

Χρησιμοποίησε τις συναρτήσεις `ascii_downcase` και `ascii_upcase`.

### Κανονικές εκφράσεις

Το `jq` έχει πλούσια υποστήριξη για κανονικές εκφράσεις: αυτό θα είναι το θέμα μιας επόμενης ενότητας.

[interpolate]: https://jqlang.org/manual/#string-interpolation
