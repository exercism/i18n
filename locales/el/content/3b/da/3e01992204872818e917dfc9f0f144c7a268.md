# Ενσωμάτωση κώδικα

```sather
   include WARM_UP;
   include WARM_UP count -> warm_up_count;
   include WARM_UP describe -> ;
   include WARM_UP count -> beats, describe -> ;
```

Ένα `include` αντιγράφει τον κώδικα μιας άλλης κλάσης σε αυτήν. Είναι μια λειτουργία που συμβαίνει κατά τη μεταγλώττιση, χωρίς κόστος και χωρίς σχέση κατά την εκτέλεση: οι δύο κλάσεις δεν συνδέονται μετά.

## Η ρήτρα

```
   include CLASS  old_name -> new_name , old_name -> ;
```

Κάθε καταχώριση μετονομάζει ένα χαρακτηριστικό. Το `-> ;` χωρίς νέο όνομα το αφήνει έξω. Ό,τι δεν αναφέρεται έρχεται ως έχει.

Η μετονομασία εφαρμόζεται σε ό,τι βλέπει το *εξωτερικό*. Οι κλήσεις ανάμεσα στις ρουτίνες που έχουν συμπεριληφθεί δουλεύουν ακόμα: αν το `describe` καλεί το `count` και το `count` μετονομάζεται σε `beats`, το `describe` καλεί το `beats`.

## Συμπερίληψη πολλών

```sather
   include WARM_UP;
   include COOL_DOWN;
```

επιτρέπεται, και έτσι αποκτά η Sather αυτό που οι άλλες γλώσσες ονομάζουν πολλαπλή κληρονομικότητα, χωρίς τα συνηθισμένα προβλήματα, γιατί μια σύγκρουση είναι σφάλμα μεταγλώττισης και η διόρθωση είναι να μετονομάσεις ή να αφήσεις ένα έξω. Τίποτα δεν λύνεται με μια σειρά προτεραιότητας που πρέπει να αποστηθίσεις.

## private include

```sather
   private include WARM_UP;
```

φέρνει τον κώδικα μέσα για χρήση της ίδιας της κλάσης χωρίς να τον εκθέτει. Χρήσιμο όταν θέλεις την υλοποίηση και όχι τη διεπαφή.

## Τα δύο μαζί

Το συνηθισμένο σχήμα για μια οικογένεια κλάσεων:

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class ACT_BASICS is
   minutes : INT is return 5; end;
end;

class JUGGLING < $ACT is
   include ACT_BASICS;
   name : STR is return "Juggling"; end;
end;
```

Το `< $ACT` λέει τι μπορεί να κάνει, ενώ το `include ACT_BASICS` παρέχει μέρος του πώς. Αν αλλάξεις γνώμη για το πώς, το `<` δεν μετακινείται.

## Γιατί γίνεται έτσι

Μια αφηρημένη κλάση δεν έχει κώδικα, οπότε δεν μπορεί να κληρονομηθεί κατά λάθος, και δεν υπάρχει κάτι σαν υπερκλάση της οποίας η συμπεριφορά αλλάζει κάτω από τα πόδια σου. Η επαναχρησιμοποίηση είναι ένα αντίγραφο που παίρνεται κατά τη μεταγλώττιση, από μια κλάση που έχεις ονομάσει, με κάθε μετονομασία καταγεγραμμένη.

Το κόστος είναι ότι η επαναχρησιμοποίηση πρέπει να ζητηθεί ρητά σε κάθε κλάση. Αυτό είναι το αντάλλαγμα: περισσότερα να πληκτρολογήσεις, τίποτα σιωπηρό.
