# Προτεινόμενοι πόροι μάθησης

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά μπορεί να είναι δύσκολο να ξεκινήσεις με αυτό για όσους μαθαίνουν ABAP για πρώτη φορά. Αυτοί οι δωρεάν πόροι μπορούν να σε βοηθήσουν να ξεκινήσεις:

* SAP Learning Journey [Learning the Basics of ABAP Programming](https://learning.sap.com/courses/learn-the-basics-of-abap-programming-on-sap-btp)
* [ABAP for Newbies Community](https://pages.community.sap.com/topics/abap/abap-for-newbies)
* [ABAP Language Documentation](https://help.sap.com/doc/abapdocu_latest_index_htm/latest/en-US/index.htm)
* [ABAP Starter](https://github.com/Keller-Michael/ABAP_starter)
* [ABAP Cheat Sheets](https://github.com/SAP-samples/abap-cheat-sheets)

Αν ξεκινάς τώρα με το ABAP, σου προτείνουμε να ολοκληρώσεις τις παρακάτω ενότητες του SAP Learning Journey:

- Getting Started
- ABAP Language Basics
- Local Classes

Μετά από αυτό, θα μπορείς να λύνεις ασκήσεις ABAP στο Exercism.

Αν φτάσεις σε πιο σύνθετες ασκήσεις, σου προτείνουμε να περάσεις και από τις παρακάτω ενότητες:

- Structures
- Complex Internal Tables

Αυτά τα θέματα μπορεί να σου φανούν χρήσιμα για να λύνεις πιο δύσκολες ασκήσεις στο Exercism.
