# Δημιουργία αρχείων με το Configlet

Όταν προσθέτεις μια νέα προσέγγιση, ένα νέο άρθρο ή μια νέα άσκηση, θα πρέπει να δημιουργήσεις αρχεία με πολύ συγκεκριμένα ονόματα.
Απαιτούν επίσης την προσθήκη ή την ενημέρωση αρχείων ρυθμίσεων.
Με την εντολή `create`, το [configlet](/docs/building/configlet) μπορεί να τα κάνει όλα αυτά για σένα.

## Χρήση

Η εντολή `create` μπορεί να χρησιμοποιηθεί για να δημιουργήσεις τα αρχεία που απαιτούνται για να προσθέσεις μια νέα προσέγγιση, άρθρο ή άσκηση, καθώς και για να τροποποιήσεις τυχόν αρχεία ρυθμίσεων.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## Δημιουργία άσκησης εξάσκησης

Η [τεκμηρίωση για την προσθήκη άσκησης εξάσκησης](/docs/building/tracks/practice-exercises/add) περιέχει λεπτομερείς οδηγίες για το πώς να προσθέσεις μια άσκηση εξάσκησης.

## Δημιουργία άσκησης εννοιών

Για να δημιουργήσεις μια άσκηση εννοιών, πρέπει να ορίσεις το slug της:

```shell
configlet create --concept-exercise bird-watcher
```

Αυτό θα δημιουργήσει τα απαιτούμενα αρχεία της άσκησης εννοιών, όπως ορίζονται στην [τεκμηρίωση για τις ασκήσεις εννοιών](/docs/building/tracks/concept-exercises).

Φυσικά, αυτό είναι μόνο το πρώτο βήμα για τη δημιουργία μιας άσκησης.
Στη συνέχεια θα πρέπει να:

- Προσθέσεις tests στο αρχείο tests
- Προσθέσεις μια υποδειγματική υλοποίηση
- Ορίσεις τα περιεχόμενα του αρχείου stub
- Γράψεις την εισαγωγή στο `.docs/introduction.md`
- Γράψεις τις οδηγίες στο `.docs/instructions.md`
- Μέσα στο αρχείο `.meta/config.json` της άσκησης:
  - Προσθέσεις το όνομα χρήστη στο GitHub των συγγραφέων της άσκησης στο κλειδί `authors`
- Μέσα στο αρχείο `config.json` της διαδρομής:
  - Ελέγξεις/ενημερώσεις τη δυσκολία της άσκησης
  - Προσθέσεις έννοιες στο κλειδί `concepts`
  - Προσθέσεις έννοιες στο κλειδί `prerequisites`

## Δημιουργία προσέγγισης

Για να δημιουργήσεις τα αρχεία μιας προσέγγισης, πρέπει να ορίσεις το slug της προσέγγισης και της άσκησής της:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

Αυτό θα δημιουργήσει τα απαιτούμενα αρχεία της προσέγγισης, όπως ορίζονται στην [τεκμηρίωση για τις προσεγγίσεις](/docs/building/tracks/approaches).

## Δημιουργία άρθρου

Για να δημιουργήσεις τα αρχεία ενός άρθρου, πρέπει να ορίσεις το slug του άρθρου και της άσκησής του:

```shell
configlet create --article performance --exercise collatz-conjecture
```

Αυτό θα δημιουργήσει τα απαιτούμενα αρχεία του άρθρου, όπως ορίζονται στην [τεκμηρίωση για τα άρθρα](/docs/building/tracks/articles).
