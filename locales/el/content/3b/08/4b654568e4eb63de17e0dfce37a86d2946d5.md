# Υποδείξεις

## Γενικά

Οι τιμές επιστροφής των συναρτήσεων είναι συγκεκριμένου τύπου, οπότε πρόσεξε.

## 1. Όρισε ένα ονομασμένο διάνυσμα

- Οι απαραίτητες πληροφορίες για τα ονόματα και τις τιμές βρίσκονται στις οδηγίες.
- Ο τρόπος κατασκευής ενός ονομασμένου διανύσματος καλύπτεται αναλυτικά στην εισαγωγή.

## 2. Επίστρεψε την τιμή που σχετίζεται με μια ζώνη

- Μπορείς να χρησιμοποιήσεις το ονομασμένο διάνυσμα `resistor_bands` για να το πετύχεις εύκολα.
- Πρέπει να επιστρέψεις μόνο μια αριθμητική τιμή.

## 3. Επίστρεψε την τιμή που σχετίζεται με δύο ζώνες

- Η συνάρτηση `band_value` μπορεί να σου φανεί χρήσιμη εδώ.
- Στην εισαγωγή υπάρχουν υποδείξεις για την προσπέλαση με θέσεις στα ονομασμένα διανύσματα.
- Υπάρχουν αρκετοί τρόποι για να κατασκευάσεις τον αριθμό, συνήθως με χειρισμό συμβολοσειρών ή αριθμητικά.
- Ο αριθμός που επιστρέφεται πρέπει να είναι μόνο μια αριθμητική τιμή.

## 4. Επίστρεψε τα ωμ που σχετίζονται με τις τρεις ζώνες

- Και οι δύο συναρτήσεις, `band_value` και `two_band_value`, είναι χρήσιμες εδώ.
- Οι δύο πρώτες τιμές στο διάνυσμα είναι για την τιμή των δύο ζωνών, ενώ η τρίτη είναι ο πολλαπλασιαστής.
- Και πάλι, μπορείς να πάρεις τον αριθμό με χειρισμό συμβολοσειρών ή με αριθμητικά μέσα.
- Ο αριθμός που επιστρέφεται πρέπει να είναι μόνο μια αριθμητική τιμή.
