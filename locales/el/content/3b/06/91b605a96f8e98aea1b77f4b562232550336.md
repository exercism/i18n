# Εντολές case

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Πώς γίνεται η αντιστοίχιση

Η τιμή μετά το `case` συγκρίνεται με κάθε τιμή `when` χρησιμοποιώντας το `=`, από
πάνω προς τα κάτω. Εκτελείται το πρώτο ταίριασμα, και μόνο αυτό. Τα υπόλοιπα
τμήματα `when` παραλείπονται και η εκτέλεση συνεχίζει μετά το `end`.

Μπορεί να χρησιμοποιηθεί οποιοσδήποτε τύπος υποστηρίζει το `=`: `INT`, `CHAR`,
`STR`, `BOOL`.

## Το else

Ένα `case` που δεν ταιριάζει με τίποτα και δεν έχει `else` πετάει ένα μοιραίο
σφάλμα κατά την εκτέλεση. Γράφε πάντα ένα. Όταν οι υπόλοιπες περιπτώσεις
πραγματικά δεν θα έπρεπε να συμβούν, πες το εκεί αντί να το παραλείψεις:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

Το `raise` έρχεται αργότερα. Μέχρι τότε, το να επιστρέφεις μια λογική
προεπιλεγμένη τιμή είναι εντάξει.

## Πότε να προτιμάς το if

Το `case` συγκρίνει μια τιμή με σταθερές. Για οτιδήποτε άλλο, χρειάζεσαι `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Το να προσπαθείς να χωρέσεις ένα εύρος σε ένα `case` παράγει κάτι πιο
μακροσκελές και χειρότερο από το `if` που αντικατέστησε.

## Το case ως έκφραση

Το `case` είναι εντολή, όχι έκφραση, οπότε αυτό δεν είναι Sather:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Επίστρεψε από μέσα από κάθε κλάδο ή ανάθεσε σε μια μεταβλητή μέσα σε κάθε
κλάδο.
