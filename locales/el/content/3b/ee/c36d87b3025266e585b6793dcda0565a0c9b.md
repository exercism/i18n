# Οδηγίες

Ως μελλοντική μάγισσα, η Elyse χρειάζεται να εξασκηθεί στα βασικά.

Έχει μια στοίβα από κάρτες που θέλει να χειριστεί.

Για να κάνει τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10.

Η στοίβα των καρτών αναπαρίσταται από έναν `Array`, με τη βάση της στοίβας στο μπροστινό μέρος του πίνακα και την κορυφή της στοίβας στο πίσω μέρος.

## 1. Εισαγωγή κάρτας στην κορυφή της στοίβας

Υλοποίησε τη συνάρτηση `insert_top` που επιστρέφει ένα αντίγραφο της στοίβας όπου η νέα κάρτα που δίνεται έχει προστεθεί στην κορυφή.

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. Αφαίρεση της κάρτας από την κορυφή της στοίβας

Υλοποίησε τη συνάρτηση `remove_top_card` που επιστρέφει ένα αντίγραφο της στοίβας, από το οποίο έχει αφαιρεθεί η κάρτα στην κορυφή.

Αν η στοίβα που δίνεται είναι κενή, θα πρέπει να επιστραφεί η αρχική στοίβα, χωρίς αλλαγές.

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. Εισαγωγή κάρτας στη βάση της στοίβας

Υλοποίησε τη συνάρτηση `insert_bottom` που επιστρέφει ένα αντίγραφο της στοίβας όπου η νέα κάρτα που δίνεται έχει προστεθεί στη βάση της στοίβας.

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. Αφαίρεση κάρτας από τη βάση της στοίβας

Υλοποίησε τη συνάρτηση `remove_bottom_card` που επιστρέφει ένα αντίγραφο της στοίβας, από το οποίο έχει αφαιρεθεί η κάρτα στη βάση.

Αν η στοίβα που δίνεται είναι κενή, θα πρέπει να επιστραφεί η αρχική στοίβα, χωρίς αλλαγές.

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. Έλεγχος του μεγέθους της στοίβας

Υλοποίησε τη συνάρτηση `check_size_of_stack` που ελέγχει αν το μέγεθος της στοίβας είναι ίσο με μια δεδομένη τιμή `stack_size` ή όχι.

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
