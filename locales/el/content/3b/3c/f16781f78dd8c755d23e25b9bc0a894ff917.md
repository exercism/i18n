# Οδηγίες

Σε αυτή την άσκηση θα προσομοιώσουμε τον πρώτο γύρο ενός παιχνιδιού [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Θα πάρεις δύο φύλλα και θα μπορείς να δεις το ανοιχτό φύλλο του ντίλερ. Όλα τα φύλλα αναπαρίστανται με μια συμβολοσειρά, όπως "ace", "king", "three", "two" κ.λπ. Οι αξίες κάθε φύλλου είναι:

| φύλλο | αξία  | φύλλο | αξία  |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**Σημείωση**: Συνήθως οι άσσοι μπορούν να πάρουν την αξία του 1 ή του 11, αλλά για λόγους απλότητας θα υποθέσουμε ότι μπορούν να πάρουν μόνο την αξία του 11.

Ανάλογα με τα δύο φύλλα σου και το φύλλο του ντίλερ, υπάρχει μια στρατηγική για τον πρώτο γύρο του παιχνιδιού, στην οποία έχεις τις εξής επιλογές:

    - Σταμάτημα (S)
    - Τράβηγμα χαρτιού (H)
    - Χωρισμός (P)
    - Αυτόματη νίκη (W)

Αν και δεν είναι ακόμη βέλτιστη, θα ακολουθήσεις τη στρατηγική που αναπτύσσει ο φίλος σου ο Alex, η οποία έχει ως εξής:

Κατηγορία: Μεγάλο Χέρι

- Αν έχεις ένα ζεύγος άσσων, πρέπει πάντα να τα χωρίζεις.
- Αν έχεις ένα Blackjack (δύο φύλλα που αθροίζουν σε αξία 21) και ο ντίλερ δεν έχει άσσο, φιγούρα ή δεκάρι, τότε κερδίζεις αυτόματα. Αν ο ντίλερ έχει κάποιο από αυτά τα φύλλα, τότε θα πρέπει να σταματήσεις και να περιμένεις να αποκαλυφθεί το άλλο φύλλο.

Κατηγορία: Μικρό Χέρι

- Αν τα φύλλα σου αθροίζουν 17 ή περισσότερο, πρέπει πάντα να σταματάς.
- Αν τα φύλλα σου αθροίζουν 11 ή λιγότερο, πρέπει πάντα να τραβάς χαρτί.
- Αν τα φύλλα σου αθροίζουν σε μια αξία στο διάστημα [12, 16], πρέπει πάντα να σταματάς, εκτός αν ο ντίλερ έχει 7 ή περισσότερο, οπότε πρέπει πάντα να τραβάς χαρτί.

Η συνολική λογική έχει ήδη υλοποιηθεί. Έχεις τέσσερις εργασίες:

## 1. Υπολόγισε τη βαθμολογία οποιουδήποτε φύλλου.

Υλοποίησε μια συνάρτηση που να υπολογίζει την αριθμητική αξία ενός φύλλου με βάση το όνομά του, χρησιμοποιώντας συνθήκες.

```java
parseCard("ace")
// returns 11
```

## 2. Προσδιόρισε αν δύο φύλλα σχηματίζουν Blackjack.

Υλοποίησε μια συνάρτηση που επιστρέφει `true` αν δύο φύλλα σχηματίζουν Blackjack και `false` διαφορετικά.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. Υλοποίησε τη λογική απόφασης για βαθμολογίες χεριού μεγαλύτερες από 20 πόντους.

Υλοποίησε μια συνάρτηση που επιστρέφει την αναπαράσταση με συμβολοσειρά μιας απόφασης με βάση τα φύλλα σου. Αυτή η συνάρτηση καλείται μόνο αν το `handScore` είναι μεγαλύτερο από 20. Θα δεχτεί 2 ορίσματα: `isBlackJack` και `dealerScore`. Πρέπει να υλοποιεί τις κουκκίδες στην κατηγορία "Μεγάλο Χέρι" παραπάνω.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. Υλοποίησε τη λογική απόφασης για βαθμολογίες χεριού με λιγότερους από 21 πόντους.

Υλοποίησε μια συνάρτηση που επιστρέφει την αναπαράσταση με συμβολοσειρά μιας απόφασης με βάση τα φύλλα σου. Αυτή η συνάρτηση καλείται μόνο αν το `handScore` είναι μικρότερο από 21. Θα δεχτεί 2 ορίσματα: `handScore` και `dealerScore`. Πρέπει να υλοποιεί τις κουκκίδες στην κατηγορία "Μικρό Χέρι" παραπάνω.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
