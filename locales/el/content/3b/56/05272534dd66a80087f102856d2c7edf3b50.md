# Μεταβλητότητα

Η Cairo, με τον σχεδιασμό της που προσανατολίζεται στο blockchain, εφαρμόζει από προεπιλογή ένα μοντέλο αμετάβλητης μνήμης.
Αυτό σημαίνει ότι μόλις μια τιμή γραφτεί στη μνήμη, δεν μπορεί να αντικατασταθεί, παρά μόνο να διαβαστεί.
Ωστόσο, η Cairo παρέχει έναν μηχανισμό για τη δημιουργία τροποποιήσιμων μεταβλητών με τη λέξη-κλειδί `mut`.
Όταν μια μεταβλητή δηλώνεται ως τροποποιήσιμη και η τιμή της αλλάξει, η νέα τιμή γράφεται σε ένα νέο κύτταρο μνήμης και η μεταβλητή ενημερώνεται ώστε να δείχνει στο νέο κύτταρο.
Αυτός ο μηχανισμός προσφέρει ευελιξία, διατηρώντας παράλληλα τα πλεονεκτήματα της αμεταβλητότητας.

Στο παρακάτω παράδειγμα, η `x` δηλώνεται ως αμετάβλητη μεταβλητή.
Αν αλλάξει η τιμή της `x`, ο μεταγλωττιστής θα πετάξει ένα σφάλμα.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Μπορούμε να δηλώσουμε την `x` ως τροποποιήσιμη μεταβλητή με τη λέξη-κλειδί `mut`.
Έτσι, η τιμή της `x` μπορεί να αλλάξει αφού δηλωθεί.

```rust
let mut x = 5;
x = 10;
```

Τελικά, το αν θα χρησιμοποιήσεις μεταβλητότητα ή όχι εξαρτάται από εσένα και από το τι θεωρείς πιο ξεκάθαρο στη συγκεκριμένη περίπτωση.

## Σταθερές

Όπως οι αμετάβλητες μεταβλητές, έτσι και οι σταθερές είναι τιμές που δεσμεύονται σε ένα όνομα και δεν επιτρέπεται να αλλάξουν, αλλά υπάρχουν μερικές διαφορές ανάμεσα στις σταθερές και τις μεταβλητές:

- Οι σταθερές δηλώνονται με τη λέξη-κλειδί `const`
- Δεν επιτρέπεται να χρησιμοποιήσεις το `mut` με σταθερές
- Ο τύπος της τιμής πρέπει πάντα να ορίζεται ρητά
- Οι σταθερές μπορούν να δηλωθούν μόνο στην καθολική εμβέλεια
- Οι σταθερές μπορούν να οριστούν μόνο με σταθερές εκφράσεις, όχι με το αποτέλεσμα μιας τιμής που υπολογίζεται κατά την εκτέλεση

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

Μπορείς να χρησιμοποιήσεις τη μακροεντολή `consteval_int!` για να δημιουργήσεις μια μεταβλητή `const` που είναι το αποτέλεσμα κάποιου υπολογισμού.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Επισκίαση

Είναι δυνατόν, και συχνά ιδιωματικό, να ξαναχρησιμοποιήσεις ένα όνομα μεταβλητής καθώς μια συγκεκριμένη τιμή μετασχηματίζεται, δηλώνοντάς την ξανά με πολλαπλές χρήσεις του `let`.
Αυτό είναι γνωστό ως _επισκίαση_.
Στην πράξη, η δεύτερη μεταβλητή επισκιάζει την πρώτη, αναλαμβάνοντας η ίδια όλες τις χρήσεις του ονόματος της μεταβλητής, μέχρι είτε να επισκιαστεί και η ίδια είτε να τελειώσει η εμβέλεια.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Χρησιμοποιώντας την επισκίαση, μπορούμε ακόμη και να αλλάξουμε τον τύπο της μεταβλητής, ενώ επαναχρησιμοποιούμε το ίδιο όνομα μεταβλητής.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
