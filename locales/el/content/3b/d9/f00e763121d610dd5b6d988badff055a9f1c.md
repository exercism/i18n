# επαναχρησιμοποίηση συνάρτησης

Η επαναχρησιμοποίηση μιας συνάρτησης που έχεις ήδη γράψει μπορεί να σε βοηθήσει όταν γράφεις κώδικα που συντηρείται εύκολα.

Χρησιμοποίησε ξανά αυτές τις συναρτήσεις στο `calculate_late_fee/3`:

- `datetime_from_string/1`
- `return_date/1`
- `days_late/2`
- `monday?/1`
