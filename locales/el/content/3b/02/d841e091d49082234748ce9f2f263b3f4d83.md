# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις [τελεστές boolean][boolean-operators] για να δουλέψεις με λογικές τιμές.
- Μπορείς να συνδυάσεις πολλούς τελεστές σε μία μόνο έκφραση.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

- Ο λογικός τελεστής NOT (`!`) μπορεί να μπει πριν από μια έκφραση για να αντιστρέψει την τιμή της.

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

- Οι τελεστές boolean χρησιμοποιούνται συνήθως για να αξιολογήσουν αν δύο ή περισσότερες εκφράσεις είναι αληθείς ή όχι.

## 3. Έλεγξε αν μπορείς να δώσεις σήμα στον κρατούμενο

- Οι τελεστές boolean εκτελούνται με τη σειρά προτεραιότητάς τους (από την υψηλότερη στη χαμηλότερη): `!`, `&&`, `||`.
- Γενικά, καλό είναι να χρησιμοποιείς παρενθέσεις, ώστε να γίνεται πιο σαφής η πρόθεσή σου.
- Για περισσότερες λεπτομέρειες, δες την ενότητα για την προτεραιότητα των τελεστών στην [επίσημη τεκμηρίωση της Julia][operator-precedence].

## 4. Έλεγξε αν πρέπει να εμφανιστεί η επιλογή "Free Prisoner"

- Οι τελεστές boolean εκτελούνται με τη σειρά προτεραιότητάς τους (από την υψηλότερη στη χαμηλότερη): `!`, `&&`, `||`.
- Γενικά, καλό είναι να χρησιμοποιείς παρενθέσεις, ώστε να γίνεται πιο σαφής η πρόθεσή σου.
