# Οδηγίες

Η Daphne δούλευε πάνω σε ένα σύστημα για να εκτελεί και να καταγράφει τα αποτελέσματα των πειραμάτων της. Κάποιο κομμάτι του κώδικα έχει γίνει λίγο φλύαρο και επαναληπτικό, οπότε σου ζήτησε να γράψεις μερικές εκφράσεις `use` για να τον καθαρίσεις.

## 1. Όρισε τη συνάρτηση `with_retry`

Μερικές φορές τα πειράματα μπορεί να αποτύχουν εξαιτίας ενός μεμονωμένου λάθους, οπότε αν ένα πείραμα αποτύχει, η Daphne θέλει να το δοκιμάσει ξανά για να δει αν δουλέψει τη δεύτερη φορά.

Όρισε τη συνάρτηση `with_retry`, η οποία παίρνει ως όρισμα μια συνάρτηση που επιστρέφει ένα αποτέλεσμα.

Αν η συνάρτηση επιστρέψει μια τιμή `Ok`, τότε η `with_retry` πρέπει να επιστρέψει αυτή την τιμή.

Αν η συνάρτηση επιστρέψει μια τιμή `Error`, τότε η `with_retry` πρέπει να καλέσει ξανά τη συνάρτηση και να επιστρέψει το αποτέλεσμα αυτής της κλήσης.

Η Daphne θα χρησιμοποιήσει τη συνάρτηση ως εξής:

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. Όρισε τη συνάρτηση `record_timing`

Η Daphne καταγράφει πόσο χρόνο χρειάζεται κάθε πείραμα για να εκτελεστεί, καλώντας μια συνάρτηση καταγραφής χρόνου πριν και μετά από κάθε πείραμα.

Όρισε τη συνάρτηση `record_timing`, η οποία παίρνει δύο ορίσματα:
- Μια συνάρτηση καταγραφής χρόνου, η οποία δεν παίρνει ορίσματα και επιστρέφει `Nil`.
- Μια συνάρτηση πειράματος, η οποία δεν παίρνει ορίσματα και επιστρέφει ένα αποτέλεσμα.

Η `record_timing` πρέπει να καλέσει τη συνάρτηση καταγραφής χρόνου, μετά να καλέσει τη συνάρτηση πειράματος, έπειτα να καλέσει ξανά τη συνάρτηση καταγραφής χρόνου και τέλος να επιστρέψει το αποτέλεσμα της συνάρτησης πειράματος.

Η Daphne θα χρησιμοποιήσει τη συνάρτηση ως εξής:

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. Όρισε τη συνάρτηση `run_experiment`

Τα πειράματα αποτελούνται από τρεις φάσεις. Την προετοιμασία, τη δράση και την καταγραφή. Και οι τρεις φάσεις επιστρέφουν αποτελέσματα και κάθε φάση χρειάζεται το επιτυχημένο αποτέλεσμα της προηγούμενης φάσης για να εκτελεστεί.

Όρισε τη συνάρτηση `run_experiment`, η οποία παίρνει τέσσερα ορίσματα:
- Το όνομα του πειράματος ως `String`.
- Μια συνάρτηση προετοιμασίας, η οποία δεν παίρνει ορίσματα και επιστρέφει ένα αποτέλεσμα.
- Μια συνάρτηση δράσης, η οποία παίρνει ως όρισμα την τιμή `Ok` της συνάρτησης προετοιμασίας και επιστρέφει ένα αποτέλεσμα.
- Μια συνάρτηση καταγραφής, η οποία παίρνει ως ορίσματα την τιμή `Ok` των συναρτήσεων προετοιμασίας και δράσης και επιστρέφει ένα αποτέλεσμα.

Αν και οι τρεις συναρτήσεις πετύχουν, τότε η `run_experiment` πρέπει να επιστρέψει `Ok(#(experiment_name, recording_data))`.

Αν οποιαδήποτε από τις συναρτήσεις επιστρέψει μια τιμή `Error`, τότε η `run_experiment` πρέπει να επιστρέψει αυτή την τιμή.

Η Daphne θα χρησιμοποιήσει τη συνάρτηση ως εξής:

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
