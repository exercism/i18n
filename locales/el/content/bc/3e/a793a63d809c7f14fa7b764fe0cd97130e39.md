# Σχετικά

Στην Elixir υπάρχουν δύο διαφορετικά είδη αριθμών: ακέραιοι και αριθμοί κινητής υποδιαστολής.

Οι ακέραιοι είναι ακέραιοι αριθμοί.

```elixir
integer = 3
# => 3
```

Μερικές χρήσιμες συναρτήσεις για εργασία με ακέραιους βρίσκονται στο module [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Οι μεγάλοι ακέραιοι (αλλά και οι αριθμοί κινητής υποδιαστολής) συνήθως μορφοποιούνται χωρίζοντας κάθε 3 ψηφία σε ομάδες με κάτω παύλα.

```elixir
1_000_000
# => 1000000
```

Το μέγιστο μέγεθος των αριθμών στην Elixir περιορίζεται μόνο από τη διαθέσιμη μνήμη του συστήματος, επειδή η Elixir χρησιμοποιεί [αριθμητική αυθαίρετης ακρίβειας][arbitrary-precision-arithmetic].

Η Elixir υποστηρίζει επίσης συντομευμένους συμβολισμούς για την εισαγωγή [δυαδικών, οκταδικών και δεκαεξαδικών ακεραίων][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Σύγκριση

Οι ακέραιοι και οι αριθμοί κινητής υποδιαστολής μπορούν να θεωρηθούν ίσοι ([`==`][kernel-equal]) αν έχουν την ίδια τιμή. Ωστόσο, επειδή είναι διαφορετικοί τύποι, δεν είναι ποτέ αυστηρά ίσοι ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
