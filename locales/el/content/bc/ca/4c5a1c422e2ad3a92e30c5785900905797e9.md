# Δικαιώματα αποθετηρίων συντηρητών

Ένας συντηρητής διαδρομής είναι κάποιος που είναι μέλος της ομάδας GitHub της διαδρομής.
Το να γίνεις μέλος μιας ομάδας διαδρομής γίνεται _μόνο με πρόσκληση_.

```exercism/note
Αν θέλεις να γίνεις συντηρητής διαδρομής, άνοιξε ένα θέμα στο [φόρουμ](https://forum.exercism.org/c/exercism/building-exercism/125).
```

## Κατηγορία συντήρησης

Υπάρχουν πέντε κατηγορίες συντήρησης:

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

Η κατηγορία συντήρησης μιας διαδρομής καθορίζεται από τρεις μεταβλητές:

1. Αν η διαδρομή είναι ενεργή (δηλαδή αν οι μαθητές μπορούν να εγγραφούν στη διαδρομή στον ιστότοπο)
2. Ο αριθμός των συντηρητών της διαδρομής
3. Ο αριθμός των συντηρητών της διαδρομής που είναι επίσης στην ομάδα GitHub `cross-track-maintainers`

Για να προσδιορίσεις την κατηγορία συντήρησης, βρες την πρώτη κατηγορία που ταιριάζει με τη διαδρομή από αυτόν τον πίνακα:

| Κατηγορία             | Ενεργή; | Αριθμός συντηρητών | Αριθμός συντηρητών διασταυρούμενων διαδρομών |
| --------------------- | ------- | ------------------ | ---------------------------------------------- |
| wip-track             | Όχι     | Οποιοσδήποτε       | Οποιοσδήποτε                                   |
| unmaintained          | Ναι     | 0                  | 0                                              |
| maintained-autonomous | Ναι     | > 0                | = Αριθμός συντηρητών                           |
| maintained-solitary   | Ναι     | 1                  | 0                                              |
| maintained            | Ναι     | > 1                | < Αριθμός συντηρητών                           |

## Δικαιώματα αποθετηρίου

Η κατηγορία συντήρησης χρησιμοποιείται για να ορίσει τα δικαιώματα του αποθετηρίου ή των αποθετηρίων GitHub της διαδρομής.

| Κατηγορία             | Απαιτεί αίτημα ενσωμάτωσης | Απαιτεί έγκριση αιτήματος ενσωμάτωσης | Έλεγχοι από την ομάδα διασταυρούμενων διαδρομών |
| --------------------- | -------------------------- | ------------------------------------- | ------------------------------------------------ |
| wip-track             | Όχι                        | Όχι                                   | Όχι                                              |
| unmaintained          | Ναι                        | Ναι                                   | Ναι                                              |
| maintained-solitary   | Ναι                        | Ναι                                   | Ναι                                              |
| maintained-autonomous | Ναι                        | Όχι                                   | Όχι                                              |
| maintained            | Ναι                        | Όχι                                   | Όχι                                              |

```exercism/caution
Η κατηγορία `wip-track` είναι η μόνη κατηγορία που επιτρέπει στους συντηρητές να κάνουν push στο `main`.
```

```exercism/caution
Τα αποθετήρια εργαλείων _πάντα_ απαιτούν έγκριση αιτήματος ενσωμάτωσης, καθώς το περιεχόμενό τους προστατεύεται μέσω ενός [αρχείου CODEOWNERS](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners).
```
