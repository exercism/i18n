# Εισαγωγή

Η Unison αναπαριστά τις αληθείς και τις ψευδείς τιμές με τον τύπο `Boolean`. Υπάρχουν μόνο δύο τιμές: `true` και `false`.

```unison
trueVariable = true
falseVariable = false
```

Μπορούμε να αποτιμήσουμε εκφράσεις Boolean χρησιμοποιώντας τους τελεστές and, που αναπαρίσταται με `&&`, or, που αναπαρίσταται με `||`, και τον τελεστή not, που αναπαρίσταται με `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Οι εκφράσεις Boolean στη Unison επιτρέπουν το βραχυκύκλωμα: αν το πρώτο όρισμα μιας έκφρασης `&&` είναι `false`, δεν υπάρχει λόγος να συνεχίσουμε την αποτίμηση του δεύτερου ορίσματος. Παρομοίως, αν το πρώτο όρισμα μιας έκφρασης `||` είναι `true`, η έκφραση θα επιστρέψει αμέσως `true`.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
