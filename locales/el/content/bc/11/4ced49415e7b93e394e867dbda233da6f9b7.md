# Εισαγωγή

Τα `char` χρησιμοποιούνται μερικές φορές σε συνδυασμό με ένα αντικείμενο `StringBuilder`. Αυτό το αντικείμενο έχει μεθόδους που σου επιτρέπουν να κατασκευάσεις μια συμβολοσειρά χαρακτήρα προς χαρακτήρα και να τη χειριστείς. Στο τέλος της διαδικασίας, μπορείς να καλέσεις τη `ToString` πάνω του για να πάρεις μια ολοκληρωμένη συμβολοσειρά.
