# Βοήθεια

Για να βρεις βοήθεια αν έχεις κάποια δυσκολία, μπορείς να χρησιμοποιήσεις έναν από τους παρακάτω πόρους:

- [TypeScript QuickStart](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [ECMAScript 2015 Language Specification](https://www.ecma-international.org/wp-content/uploads/ECMA-262_6th_edition_june_2015.pdf) (pdf)
- [Mozilla JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
- Το [/r/typescript](https://www.reddit.com/r/typescript) είναι το subreddit του TypeScript.
- Μπορείς να χρησιμοποιήσεις το [StackOverflow](https://stackoverflow.com/questions/tagged/typescript) για να αναζητήσεις το πρόβλημά σου και να δεις αν έχει ήδη απαντηθεί. Μπορείς επίσης να κάνεις και να απαντήσεις ερωτήσεις.
