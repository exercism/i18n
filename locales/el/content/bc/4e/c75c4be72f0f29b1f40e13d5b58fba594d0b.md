# Ζυγαριά

## Ιστορία

Σε αυτή την άσκηση θα μοντελοποιήσεις μια ζυγαριά.

Το βάρος μπορεί να οριστεί και να ανακτηθεί σε λίβρες ή κιλά και δεν μπορεί να είναι αρνητικό.

Το βάρος μπορεί να εμφανίζεται σε μονάδες SI ή σε αμερικανικές μονάδες, δηλαδή λίβρες και ουγγιές.

Στο βάρος μπορεί να εφαρμοστεί μια ρύθμιση απόβαρου (για παράδειγμα για να αφαιρεθεί το βάρος ενός δοχείου). Αυτή μπορεί να είναι οποιαδήποτε τιμή (ακόμη και αρνητική, ή μια τιμή που κάνει το εμφανιζόμενο βάρος αρνητικό), καθώς υπάρχουν αμφιβολίες για την ακρίβεια της ζυγαριάς. Για λόγους ασφαλείας, αυτή η τιμή δεν μπορεί να ανακτηθεί.

Σημείωσε ότι:

```
display-weight = input-weight - tare-adjustment
```

Οι αναλογίες μετατροπής είναι οι εξής:

- 16 ουγγιές σε μία λίβρα
- 2.20462 κιλά σε μία λίβρα

Για παράδειγμα:

- 60 κιλά == 132.2772 λίβρες
- 132.2772 λίβρες == 132 λίβρες 4 ουγγιές

## Εργασίες

Αυτές είναι ενδεικτικές εργασίες που ταιριάζουν στην άσκηση της ζυγαριάς:

- Να επιτρέπεται ο ορισμός του βάρους στη ζυγαριά
- Να διασφαλίζεται ότι ένα αρνητικό βάρος εισόδου απορρίπτεται
- Να επιτρέπεται η ανάκτηση του βάρους σε αμερικανικές μονάδες
- Να επιτρέπεται ο ορισμός των μονάδων της ζυγαριάς σε λίβρες
- Να επιτρέπεται η εφαρμογή ρύθμισης απόβαρου στη ζυγαριά
