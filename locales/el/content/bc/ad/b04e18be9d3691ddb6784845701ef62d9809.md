# Ξεκλείδωμα Ασκήσεων

Οι ασκήσεις ξεκλειδώνουν διαφορετικά ανάλογα με τον τύπο της διαδρομής:

1. Διαδρομές χωρίς ασκήσεις εκμάθησης: όλες οι ασκήσεις εξάσκησης είναι ξεκλείδωτες από την αρχή.
2. Διαδρομές με ασκήσεις εκμάθησης: ολοκλήρωσε τις ασκήσεις εκμάθησης για να ξεκλειδώσεις κι άλλες ασκήσεις εκμάθησης και εξάσκησης.

## Λειτουργία Εκμάθησης εναντίον Λειτουργίας Εξάσκησης

Η απαίτηση να ολοκληρώσεις τις ασκήσεις εκμάθησης για να ξεκλειδώσεις περισσότερες ασκήσεις ονομάζεται Λειτουργία Εκμάθησης (η οποία εισήχθη με το Exercism 3.0).
Η Λειτουργία Εκμάθησης είναι η προεπιλογή για κάθε χρήστη που γράφεται σε μια διαδρομή με ασκήσεις εκμάθησης, αλλά και για κάθε χρήστη από τον παλιό ιστότοπο.
Η Λειτουργία Εξάσκησης είναι το αντίθετο: όλες οι ασκήσεις είναι ξεκλείδωτες από την αρχή.

Σημείωσε ότι, είτε βρίσκεσαι σε Λειτουργία Εξάσκησης είτε σε Λειτουργία Εκμάθησης, μπορείς να ζητήσεις καθοδήγηση για μια συγκεκριμένη άσκηση.

### Χρήστης που επιστρέφει

Αν είσαι χρήστης που επιστρέφει και είχες χρησιμοποιήσει κάποια προηγούμενη έκδοση του Exercism, μπορεί να διαπιστώσεις ότι ασκήσεις που ήταν προηγουμένως διαθέσιμες έχουν τώρα κλειδώσει.
Ενώ προτείνουμε να μείνεις στη Λειτουργία Εκμάθησης και να λύσεις ασκήσεις εκμάθησης για να ξεκλειδώσεις κι άλλες ασκήσεις (η καθεμία χρειάζεται περίπου 5 λεπτά για να λυθεί, αν έχεις ευχέρεια σε μια γλώσσα), θα μπορούσες αντ' αυτού να περάσεις από τη Λειτουργία Εκμάθησης στη Λειτουργία Εξάσκησης.

### Αλλαγή λειτουργίας

Για να αλλάξεις λειτουργία, πήγαινε στη σελίδα της διαδρομής που έχεις γραφτεί και κάνε κλικ στο εικονίδιο "..." πάνω δεξιά.
Έπειτα, ανάλογα με την τρέχουσα λειτουργία σου, επίλεξε "Απενεργοποίηση Λειτουργίας Εκμάθησης" ή "Ενεργοποίηση Λειτουργίας Εκμάθησης" και επιβεβαίωσε ότι θέλεις να αλλάξεις λειτουργία.

Σημείωσε ότι προς το παρόν χρειάζεται λίγος χρόνος για να εμφανιστεί η τρέχουσα λειτουργία στη σελίδα των διαδρομών σου.
