# Συμβουλές

## Γενικά

- Υπάρχουν τρεις τελεστές Boolean (λογική τιμή) για να δουλεύεις με τιμές Boolean: `not`, `&&` και `||`.
- Μπορείς να συνδυάσεις πολλούς τελεστές σε μία μόνο έκφραση.

## 1. Όρισε αν ο pac-man μπορεί να φάει ένα φάντασμα

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή `Bool`.
- Μπορείς να χρησιμοποιήσεις τον τελεστή Boolean `&&` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 2. Όρισε αν ο pac-man σκοράρει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή `Bool`.
- Μπορείς να χρησιμοποιήσεις τον τελεστή Boolean `||` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 3. Όρισε αν ο pac-man χάνει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή `Bool`.
- Μπορείς να χρησιμοποιήσεις τους τελεστές Boolean `&&` και `not` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 4. Όρισε αν ο pac-man κερδίζει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή `Bool`.
- Μπορείς να χρησιμοποιήσεις τους τελεστές Boolean `&&` και `not` για να συνδυάσεις τα ορίσματα και το αποτέλεσμα μιας από τις συναρτήσεις που υλοποίησες προηγουμένως.
