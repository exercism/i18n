# Εισαγωγή

Μια έκφραση switch μπορεί να αντιστοιχίσει μια τιμή σε μία περίπτωση από ένα σύνολο μοτίβων και να επιστρέψει την αντίστοιχη τιμή ή να εκτελέσει την αντίστοιχη ενέργεια. Η αντιστοίχιση δηλώνεται με το σύμβολο `=>`. Επιπλέον, κάθε μοτίβο μπορεί να έχει έναν προαιρετικό φρουρό περίπτωσης που εισάγεται με τη λέξη-κλειδί `when`. Η έκφραση του φρουρού περίπτωσης πρέπει να αξιολογείται ως αληθής για να επιλεγεί αυτό το "σκέλος" του switch. Οι περιπτώσεις (γνωστές και ως _σκέλη του switch_) αξιολογούνται με τη σειρά που εμφανίζονται στο κείμενο και μόλις βρεθεί αντιστοίχιση, η διαδικασία διακόπτεται και επιστρέφεται η αντίστοιχη τιμή.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
