# Εισαγωγή

## Εξαιρέσεις

Οι εξαιρέσεις στη C# παρέχουν έναν δομημένο, ομοιόμορφο και ασφαλή ως προς τον τύπο τρόπο χειρισμού συνθηκών σφάλματος που συμβαίνουν κατά τη διάρκεια εκτέλεσης. Ο σωστός χειρισμός εξαιρέσεων και σφαλμάτων είναι σημαντικός όταν προσπαθείς να αποτρέψεις καταρρεύσεις εφαρμογών.

Στη C#, όλες οι εξαιρέσεις έχουν ως βασικό τύπο την κλάση `System.Exception`. Περιέχει σημαντικές ιδιότητες όπως το `Message`, το οποίο περιέχει μια περιγραφή κατανοητή από τον άνθρωπο για τον λόγο για τον οποίο πετιέται η εξαίρεση.

Για να δηλώσεις ότι πρέπει να υπάρξει ένα σφάλμα σε ένα συγκεκριμένο σημείο του κώδικα, πρέπει να δημιουργηθεί ένα νέο αντικείμενο εξαίρεσης και στη συνέχεια να πεταχτεί, χρησιμοποιώντας τη λέξη-κλειδί `throw`:

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

Όταν πεταχτεί μια εξαίρεση, το περιβάλλον εκτέλεσης έχει το καθήκον να βρει ένα κομμάτι κώδικα που είναι υπεύθυνο για τον χειρισμό αυτής της εξαίρεσης. Αν δεν βρεθεί κατάλληλος χειριστής, το περιβάλλον εκτέλεσης εμφανίζει το μήνυμα της μη χειριζόμενης εξαίρεσης και επιπλέον σταματά την εκτέλεση του προγράμματος.

Για να δημιουργήσεις έναν χειριστή για μια εξαίρεση, η C# χρησιμοποιεί την εντολή try-catch, η οποία αποτελείται από ένα μπλοκ `try` και μία ή περισσότερες ρήτρες `catch`. Το μπλοκ `try` πρέπει να περιέχει και να προστατεύει κώδικα που μπορεί να έχει ως αποτέλεσμα να πεταχτεί η εξαίρεση. Οι ρήτρες `catch` πρέπει να περιέχουν κώδικα που χειρίζεται τη συμπεριφορά του προγράμματος αφού συμβεί το σφάλμα. Είναι σημαντικό να σημειώσεις ότι η σειρά των εξαιρέσεων έχει σημασία μετά το μπλοκ `try`, καθώς όταν παρατίθενται πολλές εξαιρέσεις, εκτελείται η πρώτη ρήτρα `catch` που ταιριάζει.

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
