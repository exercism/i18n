# Πόροι

Η Cairo είναι ιδιαίτερα κατάλληλη για χρήση σε ένα δίκτυο χωρίς άδεια, όπως το [Starknet](https://www.starknet.io/), όπου μπορεί να παρέχει ισχυρή προστασία από επιθέσεις DoS και αντίσταση στη λογοκρισία. Μπορεί να έχει ενδιαφέρον να μάθεις γι' αυτή την πτυχή της γλώσσας. Το να μάθεις να δημιουργείς smart contracts στο Starknet θα βελτιώσει την εξοικείωσή σου με τη Cairo, καθώς θα λύνεις πραγματικά προβλήματα με τη γλώσσα, και θα σε μυήσει και στον κόσμο του Web3.

- [Starknet Documentation](https://docs.starknet.io/) μάθε τι είναι το Starknet, πώς λειτουργεί και πώς να αναπτύσσεις smart contracts πάνω του.
- [Starknet by Example](https://starknet-by-example.voyager.online/) "μια συλλογή παραδειγμάτων για το πώς να χρησιμοποιείς τη γλώσσα προγραμματισμού Cairo για να δημιουργείς smart contracts στο Starknet."
- [Starknet Basecamp](https://www.youtube.com/@starknet_foundation) "Το Basecamp είναι ένα δωρεάν bootcamp προγραμματισμού, σχεδιασμένο ειδικά για να διδάσκει στους προγραμματιστές πώς να δημιουργούν εφαρμογές web3 στο Starknet χρησιμοποιώντας τη Cairo."
- [Awesome Starknet](https://github.com/keep-starknet-strange/awesome-starknet) "Μια επιμελημένη λίστα με καταπληκτικούς πόρους, βιβλιοθήκες, εργαλεία και άλλα για το StarkNet".
- [Starklings](https://starklings.app/) "Ένα διαδραστικό σεμινάριο στον ιστό για να μάθεις Cairo και Starknet."
