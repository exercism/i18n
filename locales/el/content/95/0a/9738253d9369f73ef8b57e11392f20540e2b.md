# Εισαγωγή

Τα σφάλματα συμβαίνουν. Στην Elixir, ενώ συχνά λέγεται να "το αφήνεις να καταρρεύσει", υπάρχουν φορές που χρειάζεται να διασώσουμε την κλήση της συνάρτησης και να την επαναφέρουμε σε μια γνωστή καλή κατάσταση, ώστε να τηρήσουμε ένα συμβόλαιο λογισμικού. Σε ορισμένες γλώσσες, τα σφάλματα χρησιμοποιούνται ως τρόπος ελέγχου ροής, αλλά στην Elixir αυτό το μοτίβο αποθαρρύνεται. Συχνά μπορούμε να αναγνωρίσουμε συναρτήσεις που μπορεί να πετάξουν ένα σφάλμα μόνο από το όνομά τους: οι συναρτήσεις που πετούν σφάλματα έχουν `!` στο τέλος του ονόματός τους. Αυτό έρχεται σε αντίθεση με συναρτήσεις που επιστρέφουν `{:ok, value}` ή `:error`. Δες αυτά τα παραδείγματα από τη βιβλιοθήκη:

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
