# Υποδείξεις

## Γενικά

- Διάβασε για τα [bitstrings][bitstring] στον οδηγό Getting Started.
- Ρίξε μια ματιά στην τεκμηρίωση για την [ειδική μορφή bitstring][bitstring-form].
- Δες [πώς μετατρέπονται οι δεκαδικοί αριθμοί σε δυαδικούς][decimal-to-binary-youtube].
- Η Elixir υποστηρίζει [διαφορετικούς τρόπους γραφής ακεραίων][integer-literal], ανάμεσά τους και τη δυαδική σημειογραφία.

## 1. Υπολόγισε το μέγεθος bit της παλέτας

- Αυτή η εργασία δεν χρησιμοποιεί τον τύπο δεδομένων bitstring.
- Βρες τον μικρότερο θετικό αριθμό `n` για τον οποίο το 2 υψωμένο στη δύναμη `n` είναι μεγαλύτερο ή ίσο με τον αριθμό των χρωμάτων που πρέπει να αναπαραστήσουμε.
- Δημιούργησε μια αναδρομική συνάρτηση για αυτό.
- Ξεκίνα με μέγεθος bit ίσο με 1. Αν το 2 υψωμένο στο μέγεθος bit είναι μεγαλύτερο ή ίσο με τον αριθμό των χρωμάτων, βρήκες το μέγεθος bit. Αν όχι, πρόσθεσε 1 στο μέγεθος bit και έλεγξε ξανά (αναδρομή).
- Χρησιμοποίησε τον [τελεστή ύψωσης σε δύναμη `**`][power-operator] για να υψώσεις το 2 σε μια δεδομένη δύναμη.

## 2. Δημιούργησε μια κενή εικόνα

- Χρησιμοποίησε την [ειδική μορφή bitstring][bitstring-form] για να δημιουργήσεις ένα νέο bitstring.

## 3. Δημιούργησε μια δοκιμαστική εικόνα

- Χρησιμοποίησε την [ειδική μορφή bitstring][bitstring-form] για να δημιουργήσεις ένα νέο bitstring.
- Χρησιμοποίησε τον [τελεστή τύπου][type-operator] για να ορίσεις το μέγεθος bit κάθε τμήματος.

## 4. Πρόσθεσε ένα pixel στην αρχή μιας εικόνας

- Η [ειδική μορφή bitstring][bitstring-form] μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα νέο τμήμα σε ένα υπάρχον bitstring.
- Χρησιμοποίησε τον [τελεστή τύπου][type-operator] για να ορίσεις το μέγεθος bit τόσο του νέου τμήματος όσο και του υπάρχοντος bitstring.
- Χρησιμοποίησε τη συνάρτηση `PaintByNumber.palette_bit_size/1` που υλοποίησες προηγουμένως για να βρεις το μέγεθος bit του νέου τμήματος.
- Χρησιμοποίησε τον ειδικό τύπο `::bitstring` για να ορίσεις ότι το παλιό τμήμα έχει άγνωστο μέγεθος.

## 5. Πάρε το πρώτο pixel από μια εικόνα

- Η [ειδική μορφή bitstring][bitstring-form] μπορεί να χρησιμοποιηθεί για [αντιστοίχιση προτύπων σε bitstrings][bitstring-matching].
- Χρησιμοποίησε τη συνάρτηση `PaintByNumber.palette_bit_size/1` που υλοποίησες προηγουμένως για να βρεις το μέγεθος bit ενός pixel.
- Χρησιμοποίησε τον ειδικό τύπο `::bitstring` για να ορίσεις ότι το υπόλοιπο bitstring έχει άγνωστο μέγεθος.

## 6. Αφαίρεσε το πρώτο pixel από μια εικόνα

- Η [ειδική μορφή bitstring][bitstring-form] μπορεί να χρησιμοποιηθεί για [αντιστοίχιση προτύπων σε bitstrings][bitstring-matching].
- Χρησιμοποίησε τη συνάρτηση `PaintByNumber.palette_bit_size/1` που υλοποίησες προηγουμένως για να βρεις το μέγεθος bit ενός pixel.
- Χρησιμοποίησε τον ειδικό τύπο `::bitstring` για να ορίσεις ότι το υπόλοιπο bitstring έχει άγνωστο μέγεθος.

## 7. Συνένωσε δύο εικόνες

- Η [ειδική μορφή bitstring][bitstring-form] μπορεί να χρησιμοποιηθεί για να συνενώσεις δύο bitstrings.
- Χρησιμοποίησε τον ειδικό τύπο `::bitstring` για να ορίσεις ότι καθένα από τα τμήματα bitstring έχει άγνωστο μέγεθος.
