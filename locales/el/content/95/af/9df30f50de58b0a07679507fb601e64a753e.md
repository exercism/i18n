# Εισαγωγή

Οι Boolean (λογικές τιμές) στη Clojure αντιπροσωπεύονται από `true` ή `false`. Όλες οι τιμές είναι λογικά αληθείς ή ψευδείς. Οι μόνες "ψευδείς" τιμές είναι οι `false` και `nil`· όλες οι άλλες τιμές είναι λογικά αληθείς.

Οι συναρτήσεις κατηγορήματος (συναρτήσεις που επιστρέφουν Boolean) συνήθως τελειώνουν με ερωτηματικό (`?`), αλλά αυτό είναι μόνο κατά σύμβαση.

Η βασική βιβλιοθήκη περιλαμβάνει συναρτήσεις για λογικούς τελεστές, όπως `not`, `and` και `or`.
