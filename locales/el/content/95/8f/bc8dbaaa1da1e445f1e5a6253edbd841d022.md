# Σχετικά

Ο ορισμός μιας συλλογής περιλαμβάνει συνήθως ένα σύμβολο θέσης μέσα σε γωνιακές αγκύλες, συχνά το T κατά σύμβαση. Μια τέτοια συλλογή ονομάζεται γενικευμένος τύπος. Αυτό επιτρέπει στον χρήστη της συλλογής να καθορίσει τι τύπο στοιχείων θα αποθηκεύσει στη συλλογή. Στο παραπάνω παράδειγμα κώδικα δημιουργούμε ένα στιγμιότυπο μιας λίστας συμβολοσειρών.

Μια κλάση ή μια συνάρτηση γίνεται **γενικευμένη** χρησιμοποιώντας το χαρακτηριστικό `@:generic`. Αυτό κάνει τον μεταγλωττιστή να αναγνωρίζει την κλάση ή τη συνάρτηση ως γενικευμένη:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
