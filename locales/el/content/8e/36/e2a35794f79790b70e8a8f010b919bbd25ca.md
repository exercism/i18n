# Υποδείξεις

## 1. Υπενθύμισε στον Lenny τα σύμβολα

- Αν δυσκολεύεσαι να επιστρέψεις ένα σύμβολο από μια συνάρτηση, ίσως χρειαστεί να ρίξεις μια ματιά στο [quoting][so-quoting]!
- Θυμήσου ότι οι λέξεις-κλειδιά διαφέρουν ελαφρώς από τα συνηθισμένα σύμβολα και [πρέπει να προηγείται διαφορετικός χαρακτήρας][clhs-keywordp].

## 2. Βοήθησε τον Lenny να ξεχωρίσει τα άτομα από τα cons

- Η Common Lisp περιέχει συναρτήσεις κατηγορήματα για να προσδιορίζεις πολλά πράγματα. Ειδικότερα, δύο από αυτές είναι πολύ σχετικές [εδώ][clhs-conses]. Ψάξε για συναρτήσεις που έχουν στο όνομά τους "atom" ή "cons".
- Σημείωση: γενικά, οι συναρτήσεις κατηγορήματα τελειώνουν σε `p` ή `-p`. Η ονομασία του κατηγορήματος για τα άτομα είναι μια άτυχη ασυνέπεια.

## 3. Βοήθησε τον Lenny να χωρίσει τα cons του

- Όταν θέλεις να πάρεις το πρώτο στοιχείο και τα υπόλοιπα ενός sexpr, υπάρχουν μερικές επιλογές [εδώ][clhs-conses].
- Ψάξε συγκεκριμένα για _Accessors_ σε αντίθεση με συναρτήσεις.
- Μερικές επιλογές μπορεί να έχουν πιο διαισθητικά ονόματα απ' ό,τι περιμένεις!
