# Τεστ

## Clojure CLI

Οι ασκήσεις Clojure στο Exercism συνοδεύονται από ένα αρχείο `deps.edn` με ένα alias `:test` για να καλέσεις τον [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

## Leiningen

Μπορείς επίσης να χρησιμοποιήσεις το Leiningen για να τρέξεις το τεστ της άσκησης, εκτελώντας την παρακάτω εντολή από τον κατάλογο της άσκησης:

```bash
lein test
```

## REPL

Για να χρησιμοποιήσεις το REPL για να τρέξεις το τεστ της άσκησης, εκτέλεσε την παρακάτω εντολή από τον κατάλογο της άσκησης:

```bash
$ clj
```

-ή-

```bash
$ lein repl
```

Μετά, κάνε `require` στο test namespace της άσκησης και στο test namespace της Clojure:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

Μετά, κάλεσε τη `run-tests` στο `<exercise>-test`:

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
