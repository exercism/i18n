# Δοκιμές

Για να τρέξεις τις δοκιμές, τρέξε την εντολή `bal test --offline` μέσα από τον κατάλογο της άσκησης.

## Δοκιμές που παραλείπονται

Αρχικά, μόνο η πρώτη δοκιμή θα είναι ενεργοποιημένη.
Αυτό γίνεται για να σε ενθαρρύνει να λύσεις την άσκηση ένα βήμα τη φορά.
Μόλις περάσεις την πρώτη δοκιμή, αφαίρεσε την ιδιότητα `enable: false` από την επόμενη δοκιμή και προσπάθησε να περάσεις και αυτήν.
