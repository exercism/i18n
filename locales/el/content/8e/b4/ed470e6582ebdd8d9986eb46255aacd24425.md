# Οδηγίες

Μέτρησε τα ορθογώνια σε ένα διάγραμμα ASCII σαν αυτό παρακάτω.

```text
   +--+
  ++  |
+-++--+
|  |  |
+--+--+
```

Το παραπάνω διάγραμμα περιέχει αυτά τα 6 ορθογώνια:

```text


+-----+
|     |
+-----+
```

```text
   +--+
   |  |
   |  |
   |  |
   +--+
```

```text
   +--+
   |  |
   +--+


```

```text


   +--+
   |  |
   +--+
```

```text


+--+
|  |
+--+
```

```text

  ++
  ++


```

Μπορείς να υποθέσεις ότι η είσοδος είναι πάντα ένα σωστό ορθογώνιο (δηλαδή το μήκος κάθε γραμμής ισούται με το μήκος της πρώτης γραμμής).
