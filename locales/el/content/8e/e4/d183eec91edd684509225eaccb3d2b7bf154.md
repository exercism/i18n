# Υποδείξεις

## Γενικά

- Διάβασε για τις λίστες λέξεων-κλειδιών στον επίσημο οδηγό [Getting Started][getting-started-keyword-lists].
- Διάβασε για τις λίστες λέξεων-κλειδιών στο [elixirschool.com][elixir-school-keyword-lists].
- Ρίξε μια ματιά στην [τεκμηρίωση του `Keyword`][keyword].

## 1. Εξήγησε τα χρώματα των κρασιών

- Πρέπει να γράψεις τις πληροφορίες που δίνονται στον πίνακα ως λίστα λέξεων-κλειδιών.
- Ρίξε μια ματιά σε μερικά [παραδείγματα][keyword-examples] για το πώς ορίζεται μια λίστα λέξεων-κλειδιών.

## 2. Βρες όλα τα κρασιά ενός δεδομένου χρώματος

- Υπάρχει μια [ενσωματωμένη συνάρτηση][keyword-get-values] για να πάρεις τη λίστα με όλες τις τιμές για ένα δεδομένο κλειδί.

## 3. Βρες όλα τα κρασιά ενός δεδομένου χρώματος που εμφιαλώθηκαν ένα δεδομένο έτος

- Υπάρχει μια [ενσωματωμένη συνάρτηση][keyword-get] για να πάρεις μία μόνο τιμή για ένα δεδομένο κλειδί.
- Δεν χρειάζεται να υλοποιήσεις μόνος σου το φιλτράρισμα των μπουκαλιών. Αρκεί να χρησιμοποιήσεις υπό συνθήκη τη συνάρτηση `filter_by_year/2`, που είναι ήδη υλοποιημένη.

## 4. Βρες όλα τα κρασιά ενός δεδομένου χρώματος που εμφιαλώθηκαν σε μια δεδομένη χώρα

- Υπάρχει μια [ενσωματωμένη συνάρτηση][keyword-get] για να πάρεις μία μόνο τιμή για ένα δεδομένο κλειδί.
- Δεν χρειάζεται να υλοποιήσεις μόνος σου το φιλτράρισμα των μπουκαλιών. Αρκεί να χρησιμοποιήσεις υπό συνθήκη τη συνάρτηση `filter_by_country/2`, που είναι ήδη υλοποιημένη.
