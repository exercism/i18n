# Εισαγωγή

Η Haxe είναι ισχυρά τυποποιημένη, αλλά το σύστημα τύπων μπορεί να παρακαμφθεί όπου χρειάζεται. Η εκχώρηση μιας τιμής σε ένα όνομα αναφέρεται ως ορισμός μεταβλητής. Μια μεταβλητή μπορεί να οριστεί είτε καθορίζοντας ρητά τον τύπο της, είτε αφήνοντας τον μεταγλωττιστή της Haxe να συμπεράνει τον τύπο. Επομένως, οι παρακάτω δύο ορισμοί μεταβλητών είναι ισοδύναμοι:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Η ενημέρωση μιας μεταβλητής μπορεί να γίνει χρησιμοποιώντας τον τελεστή `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Ο μεταγλωττιστής θα πετάξει ένα σφάλμα όταν προσπαθείς να εκχωρήσεις μια τιμή της οποίας ο τύπος είναι διαφορετικός από αυτόν της μεταβλητής:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Μια συνάρτηση που βρίσκεται μέσα σε μια κλάση ονομάζεται _μέθοδος_. Οι μέθοδοι μπορούν να έχουν μηδέν ή περισσότερες παραμέτρους. Όλες οι παράμετροι πρέπει να έχουν ρητά καθορισμένο τύπο. Όπως ακριβώς οι παράμετροι, ο τύπος επιστροφής μιας μεθόδου δεν μπορεί να συμπεραθεί και πρέπει να δηλωθεί. Οι τιμές επιστρέφονται από τις μεθόδους χρησιμοποιώντας τη λέξη-κλειδί `return`:

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Η κλήση μιας μεθόδου γίνεται καθορίζοντας την κλάση και το όνομα της μεθόδου και περνώντας ορίσματα:

```haxe
var sum = add(1, 2) // sum = 3
```

Η εμβέλεια στη Haxe ορίζεται μεταξύ των χαρακτήρων `{` και `}`.

Η Haxe υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μονής γραμμής προηγούνται από `//` και τα σχόλια πολλαπλών γραμμών εισάγονται μεταξύ `/*` και `*/`.
