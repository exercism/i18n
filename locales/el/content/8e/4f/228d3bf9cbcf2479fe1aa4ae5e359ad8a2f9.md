# Υποδείξεις

Μερικά (όχι όλα) από τα τεστ υποθέτουν ότι η τιμή είναι `Int32`, οπότε απόφυγε να την αναγκάσεις να είναι κάτι άλλο.

## 1. Μετατόπισε τα bit προς τα πίσω

- Αυτή είναι μια μετατόπιση προς τα δεξιά.
- Πρόσεξε την οδηγία ότι τα αποτελέσματα πρέπει να συμπληρώνονται από αριστερά με μηδενικά.

## 2. Θέσε μερικά bit

- Θέτεις bit κάνοντας bitwise OR με μια μάσκα. Αυτό είναι εξαιρετικά συνηθισμένο.

## 3. Αντιστρέψε συγκεκριμένα bit

- Υπάρχει ένα παλιό αστείο μεταξύ των προγραμματιστών, ότι οι κρυπτογράφοι ανακάλυψαν το XOR και ξέχασαν να διαβάσουν το υπόλοιπο εγχειρίδιο.

## 4. Μηδένισε συγκεκριμένα bit

- Μια απλή λογική AND θα κάνει το αντίθετο από αυτό που χρειάζεσαι.
