# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις έναν ελεύθερο επαγγελματία να επικοινωνεί με τους πελάτες του σχετικά με τις τιμές συγκεκριμένων έργων.
Θα γράψεις μερικές βοηθητικές μεθόδους για να υπολογίζεις γρήγορα το κόστος για τους πελάτες.

```exercism/note
Η παράμετρος `rate_per_hour` και η μέθοδος `day_rate` σχετίζονται με χρήματα.
Οι μονάδες μέτρησης είναι χρήματα ανά μονάδα χρόνου: ώρες και ημέρες αντίστοιχα.
```

## 1. Υπολόγισε την ημερήσια χρέωση με βάση την ωριαία χρέωση

Ένας πελάτης επικοινωνεί με τον ελεύθερο επαγγελματία για να ρωτήσει για τις χρεώσεις του.
Ο ελεύθερος επαγγελματίας εξηγεί ότι **_δουλεύει 8 ώρες την ημέρα._**
Ωστόσο, ο ελεύθερος επαγγελματίας γνωρίζει μόνο την ωριαία χρέωσή του για το έργο.
Βοήθησέ τον να υπολογίσει την ημερήσια χρέωση με βάση την ωριαία χρέωση.

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

Η ημερήσια χρέωση δε χρειάζεται να στρογγυλοποιηθεί ή να μετατραπεί σε "σταθερή" ακρίβεια.

## 2. Υπολόγισε τον αριθμό των εργάσιμων ημερών με βάση έναν σταθερό προϋπολογισμό

Μια άλλη μέρα, ένας διαχειριστής έργου προτείνει στον ελεύθερο επαγγελματία να δουλέψει σε ένα έργο με σταθερό προϋπολογισμό.
Δεδομένου του σταθερού προϋπολογισμού και της ωριαίας χρέωσης του ελεύθερου επαγγελματία, βοήθησέ τον να υπολογίσει τον αριθμό των ημερών που θα δουλέψει μέχρι να εξαντληθεί ο προϋπολογισμός.
Το αποτέλεσμα _πρέπει_ να **στρογγυλοποιηθεί προς τα κάτω** στον πλησιέστερο ακέραιο αριθμό.

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. Υπολόγισε τη χρέωση με έκπτωση για μεγάλα έργα

Συχνά, οι πελάτες του ελεύθερου επαγγελματία τον προσλαμβάνουν για έργα που εκτείνονται σε πολλούς μήνες.
Σε αυτές τις περιπτώσεις, ο ελεύθερος επαγγελματίας αποφασίζει να προσφέρει έκπτωση για κάθε πλήρη μήνα, και οι υπόλοιπες ημέρες χρεώνονται με την ημερήσια χρέωση.
Η εξαιρετική ισορροπία μεταξύ επαγγελματικής και προσωπικής ζωής σου σημαίνει ότι δουλεύεις μόνο 22 ημέρες σε κάθε ημερολογιακό μήνα, οπότε **_κάθε μήνας έχει 22 χρεώσιμες ημέρες._**
Βοήθησέ τον να υπολογίσει το κόστος του για τέτοια έργα, δεδομένης μιας ωριαίας χρέωσης, του αριθμού των χρεώσιμων ημερών που περιέχει το έργο και ενός μηνιαίου ποσοστού έκπτωσης.
Η έκπτωση περνιέται πάντα ως αριθμός, όπου το `42%` γίνεται `0.42`. Το αποτέλεσμα _πρέπει_ να **στρογγυλοποιηθεί προς τα πάνω** στον πλησιέστερο ακέραιο αριθμό.

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
