# Προσάρτημα οδηγιών

## Σημειώσεις υλοποίησης

Η `Range` πρέπει να επιστρέφει μια λίστα με όλες τις πυθαγόρειες τριάδες με πλευρές στο διάστημα από `min` έως `max`, συμπεριλαμβανομένων των άκρων.

Η `Sum` πρέπει να επιστρέφει μια λίστα με όλες τις πυθαγόρειες τριάδες όπου το άθροισμα `a+b+c` (η περίμετρος) ισούται με `p`.
Τα τρία στοιχεία κάθε τριάδας που επιστρέφεται πρέπει να είναι σε σειρά, `t[0] <= t[1] <= t[2]`, και η λίστα με τις τριάδες πρέπει να είναι σε λεξικογραφική σειρά.
