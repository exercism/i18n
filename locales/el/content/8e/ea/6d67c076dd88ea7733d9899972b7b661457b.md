# Υποδείξεις

## Γενικά

- Μην ξεχνάς το `;` μετά από κάθε εντολή.
- Μπορείς να ορίσεις έναν ακέραιο με `int myInteger = 44;`.

## 1. Βρες τον χρόνο ψησίματος.

- Οι οδηγίες έχουν πληροφορίες για τον χρόνο της συνταγής.
- Μια συνάρτηση μπορεί να επιστρέψει μια τιμή με τη μορφή `return 2;`

## 2. Βρες τον χρόνο προετοιμασίας.

- Μπορείς να έχεις πρόσβαση στον αριθμό των στρώσεων μέσω της αντίστοιχης παραμέτρου.
- Μπορείς να κάνεις υπολογισμούς όταν ορίζεις έναν ακέραιο: `int myInteger = 3 + myOtherInteger;`

## 3. Υπολόγισε τον χρόνο που απομένει στον φούρνο

- Μπορείς να καλέσεις άλλες συναρτήσεις και να χρησιμοποιήσεις την τιμή που επιστρέφεται σαν μεταβλητή: `return 22 * myOtherCalculation();`

## 4. Υπολόγισε τον συνολικό χρόνο που αφιερώνεται στα λαζάνια

- Το αποτέλεσμα θα πρέπει να συνδυάζει τον χρόνο προετοιμασίας και τον χρόνο που τα λαζάνια βρίσκονται ήδη στον φούρνο.
