# Εισαγωγή

Η Swift διαθέτει ένα σύνολο εντολών που μπορούν να χρησιμοποιηθούν για να αλλάξουν την κανονική ροή ελέγχου των βρόχων.
Αυτές είναι γνωστές ως εντολές μεταβίβασης ελέγχου.
Έχεις ήδη δει το `return`; αυτή η έννοια θα παρουσιάσει άλλες, που περιλαμβάνουν `continue`, `break` και ετικέτες.

## Continue

Μερικές φορές είναι απαραίτητο να μεταβείς νωρίς στην επόμενη επανάληψη ενός βρόχου, χωρίς να ολοκληρώσεις τις υπόλοιπες εντολές της τρέχουσας επανάληψης του βρόχου.
Η λέξη-κλειδί `continue` μπορεί να χρησιμοποιηθεί γι' αυτό.
Όταν εκτελείται το `continue`, ο βρόχος μεταπηδά στον επόμενο έλεγχο για να δει αν μπορεί να εκτελεστεί η επόμενη επανάληψη του βρόχου, δηλαδή το `while` στους βρόχους while και repeat-while ή ο έλεγχος αν υπάρχει άλλο στοιχείο στην ακολουθία στους βρόχους for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Το break χρησιμοποιείται για να βγεις από έναν βρόχο πρόωρα.
Όταν εκτελείται το `break`, ο βρόχος θα τερματιστεί αμέσως και το πρόγραμμα θα συνεχίσει με την πρώτη εντολή μετά τον βρόχο.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Ετικέτες

Όταν οι βρόχοι είναι εμφωλευμένοι, υπάρχουν φορές που μπορεί να θέλεις να χρησιμοποιήσεις το `break` ή το `continue` για να βγεις ή να ξεκινήσεις ξανά τους εξωτερικούς βρόχους που περιέχουν τον βρόχο στον οποίο χρησιμοποιούνται το `break` ή το `continue`.
Σε τέτοιες περιπτώσεις, μπορούν να χρησιμοποιηθούν ετικέτες για να καθορίσουν τον βρόχο που θα τερματιστεί ή θα ξεκινήσει ξανά.
Ένας βρόχος μπορεί να επισημανθεί βάζοντας ένα όνομα ακολουθούμενο από άνω και κάτω τελεία πριν από το `while`, το `repeat` ή το `for` που ξεκινά τον βρόχο.

Για να δεις το αποτέλεσμα της χρήσης ετικετών με αυτόν τον τρόπο, δες τον παρακάτω βρόχο.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

Η λέξη-κλειδί `fallthrough` χρησιμοποιείται για να περάσεις στο επόμενο case σε μια εντολή switch.
Αυτό σημαίνει ότι ο κώδικας μέσα στο επόμενο case θα εκτελεστεί χωρίς να ελεγχθεί η συνθήκη ή οι συνθήκες του.
Αυτό θα κάνει την εντολή switch να συμπεριφέρεται όπως σε άλλες γλώσσες προγραμματισμού, όπου η εντολή `break` δεν απαιτείται για να βγεις από την εντολή switch αφού αντιστοιχιστεί ένα case.
Μπορείς να διαβάσεις περισσότερα για το `fallthrough` στο [βιβλίο της Swift][fallthrough].

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```

[fallthrough]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Fallthrough
