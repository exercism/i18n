# Προσθήκη οδηγιών

## Υλοποίηση

Είναι πιθανό να εξαντληθούν τα ονόματα των ρομπότ: μόλις έχει εκχωρηθεί κάθε δυνατό όνομα ρομπότ, θα πρέπει να επιστρέφεται ένα σφάλμα.

## Δοκιμή μπόνους

Μόλις καταφέρεις να περνάει το `go test`, θα δεις ότι στη σουίτα δοκιμών υπάρχει μια δοκιμή με το όνομα `TestCollisions`, η οποία παραλείπεται από προεπιλογή, καθώς μπορεί να πάρει πολλή ώρα.
Αυτή η δοκιμή δημιουργεί νέα ρομπότ μέχρι να μην μπορεί να εκχωρηθεί άλλο νέο όνομα στο ρομπότ.

Για να τρέξει η δοκιμή, αφαίρεσε αυτή τη γραμμή:

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

Για να περάσει αυτή η δοκιμή, θα πρέπει να διασφαλίσεις ότι το όνομα ενός ρομπότ δεν έχει χρησιμοποιηθεί προηγουμένως και ότι τα ονόματα μπορούν να εκχωρηθούν αποδοτικά.
