# Υπερφόρτωση Τελεστών

Η υπερφόρτωση τελεστών είναι ένα χαρακτηριστικό σε ορισμένες γλώσσες προγραμματισμού που επιτρέπει τον επαναπροσδιορισμό των βασικών τελεστών, όπως η πρόσθεση (`+`), η αφαίρεση (`-`), ο πολλαπλασιασμός (`*`) και η διαίρεση (`/`), ώστε να λειτουργούν με τύπους ορισμένους από τον χρήστη.

Αυτό μπορεί να κάνει τη σύνταξη του κώδικα πιο διαισθητική, επιτρέποντας να εκφράζονται οι πράξεις σε τύπους ορισμένους από τον χρήστη με τον ίδιο τρόπο όπως οι πράξεις σε πρωτογενείς τύπους.

Στη Cairo, η υπερφόρτωση τελεστών επιτυγχάνεται μέσω της υλοποίησης συγκεκριμένων trait.

Κάθε τελεστής έχει ένα σχετιζόμενο trait, και η υπερφόρτωσή του απαιτεί να δώσεις μια υλοποίηση αυτού του trait για έναν δικό σου τύπο.
Ωστόσο, είναι σημαντικό να χρησιμοποιείς την υπερφόρτωση τελεστών με σύνεση.

Η κακή χρήση μπορεί να προκαλέσει σύγχυση και να κάνει τον κώδικα πιο δύσκολο στη συντήρηση, για παράδειγμα όταν ο τελεστής που υπερφορτώνεται δεν έχει κάποιο σημασιολογικό νόημα.

Ας δούμε ένα παράδειγμα όπου δύο `Potions` πρέπει να συνδυαστούν.

Τα `Potions` έχουν δύο πεδία δεδομένων, τα mana και health.

Ο συνδυασμός δύο `Potions` θα πρέπει να προσθέτει τα αντίστοιχα πεδία τους.

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

Στον παραπάνω κώδικα, υλοποιούμε το trait `Add` για τον τύπο `Potion`.

Η συνάρτηση add παίρνει δύο ορίσματα: `lhs` και `rhs` (αριστερή και δεξιά πλευρά).

Το σώμα της συνάρτησης επιστρέφει ένα νέο στιγμιότυπο `Potion`, του οποίου οι τιμές των πεδίων είναι ένας συνδυασμός των `lhs` και `rhs`.

Όπως φαίνεται στο παράδειγμα, η υπερφόρτωση ενός τελεστή απαιτεί να προσδιορίσεις τον συγκεκριμένο τύπο που υπερφορτώνεται.

Το γενικό trait που υπερφορτώνεται είναι το `Add<T>`, και ορίζουμε μια συγκεκριμένη υλοποίηση για τον τύπο `Potion` με το `Add<Potion>`.
