# Σχετικά

Η Elm είναι μια υπέροχη γλώσσα για τη δημιουργία αξιόπιστων διαδικτυακών εφαρμογών. Έχει φιλικά μηνύματα σφάλματος, εξαιρετική απόδοση, μικρά αρχεία και καμία εξαίρεση κατά την εκτέλεση.

Το πιο διάσημο και πιο ευρέως αντιγραμμένο κομμάτι της Elm είναι πιθανότατα το The Elm Architecture, ένα απλό μοτίβο για τη δομή των διαδικτυακών εφαρμογών, και ο τρόπος με τον οποίο γράφονται όλες οι διαδικτυακές εφαρμογές σε Elm.

Η βασική ιδέα είναι ότι ο κώδικάς σου χτίζεται γύρω από ένα `Model` της κατάστασης της εφαρμογής σου, έναν τρόπο να κάνεις `update` το μοντέλο σου και έναν τρόπο να το δεις με τη `view`.

Το `Model` περιέχει την κατάσταση της εφαρμογής, δηλαδή όλα τα δεδομένα που χρειάζεται η εφαρμογή. Μπορεί να είναι οποιουδήποτε τύπου, αλλά σε κάθε χρήσιμη εφαρμογή είναι συνήθως μια [καταγραφή][record]. Αν φανταστείς μια απλή εφαρμογή με ένα πλαίσιο κειμένου και ένα κείμενο που δείχνει το ίδιο κείμενο ανεστραμμένο, το μοντέλο θα έμοιαζε με το παρακάτω. Μπορείς να δεις αυτό το παράδειγμα και στον [Elm Guide][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

Η `update` είναι μια συνάρτηση που καλείται με ένα `Msg` όταν υπάρχει κάποια αλλαγή (για παράδειγμα, όταν ο χρήστης κάνει κλικ σε ένα κουμπί). Παίρνει το `Msg` και το τρέχον `Model` και επιστρέφει ένα νέο `Model`. Το `Msg` μπορεί να είναι οποιουδήποτε τύπου, αλλά συνήθως είναι ένας [custom type][custom-type].

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

Όπως συμβαίνει με κάθε custom type, οι παραλλαγές του `Msg` μπορούν να περιέχουν όση αυθαίρετη πληροφορία χρειάζονται. Στο παραπάνω παράδειγμα, η παραλλαγή `TextChanged` περιλαμβάνει ένα `String`.

Η `view` είναι μια συνάρτηση που επιστρέφει HTML για να δείξει στον χρήστη μέσα στον browser. Παίρνει το τρέχον `Model` και επιστρέφει ένα `Html Msg` (τον τύπο που χρησιμοποιεί η Elm για να αναπαραστήσει HTML). Κάθε στοιχείο HTML (για παράδειγμα, το `<div>`) έχει μια αντίστοιχη συνάρτηση Elm (`Html.div`), στο πακέτο `Html`. Καθεμία από αυτές τις συναρτήσεις παίρνει δύο παραμέτρους: η πρώτη είναι μια λίστα με χαρακτηριστικά (από τα πακέτα `Html.Attributes` και `Html.Events`) και η δεύτερη είναι μια λίστα με θυγατρικά στοιχεία (συναρτήσεις από το πακέτο `Html`). Υπάρχει επίσης μια συνάρτηση `text` που αναπαριστά περιεχόμενο HTML τύπου συμβολοσειράς, η οποία παίρνει απλώς μια συμβολοσειρά ως παράμετρο, αλλά κατά τα άλλα χρησιμοποιείται με τον ίδιο τρόπο όπως όλες οι άλλες συναρτήσεις / στοιχεία του πακέτου `Html`.

Η συνάρτηση `view` μπορεί να ορίσει ότι ορισμένα συμβάντα, όπως το κλικ σε ένα κουμπί ή η επεξεργασία κειμένου σε ένα πλαίσιο κειμένου, έχουν ως αποτέλεσμα τη δημιουργία ενός `Msg`, το οποίο το Elm Runtime θα χρησιμοποιήσει για να καλέσει τη συνάρτηση `update`, να τροποποιήσει το `Model` και να παράγει ενημερωμένη HTML. Στον παρακάτω κώδικα αυτό γίνεται με το `Html.Events.onInput TextChanged`.

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

Το `Html.Events.onInput` περιμένει να του περάσεις μια συνάρτηση (`String -> Msg`), την οποία θα χρησιμοποιήσει για να δημιουργήσει το `Msg`. Διαφορετικά συμβάντα περιμένουν διαφορετικές συναρτήσεις, ανάλογα με την πληροφορία που μπορούν να παρέχουν· έτσι, για παράδειγμα, το `Html.Events.onCheck` (για πλαίσια ελέγχου) περιμένει `Bool -> Msg` και το `Html.Events.onClick` περιμένει απλώς ένα `Msg`.

Η γλώσσα Elm είναι καθαρά συναρτησιακή και δεν επιτρέπει καμία μεταβολή, οπότε το Elm Runtime αναλαμβάνει όλα όσα αλλάζουν. Μπορείς να δεις όλα τα διαφορετικά [HTML Elements][html-elements], [Element Attributes][element-attributes] και [HTML Events][html-events] στο μητρώο πακέτων της Elm.

Υπάρχουν 4 "επίπεδα" διαδικτυακών εφαρμογών που μπορείς να γράψεις σε Elm, τα οποία γίνονται προοδευτικά πιο ισχυρά και πιο σύνθετα (αν και η Elm παραμένει μια υπέροχα απλή γλώσσα και ένα υπέροχο οικοσύστημα). Όλα αυτά ορίζονται στο [πακέτο Browser][browser-package]:

- [sandbox][browser-sandbox]: αντιδρά σε είσοδο του χρήστη, όπως κουμπιά και πλαίσια ελέγχου
- [element][browser-element]: μιλάει με τον έξω κόσμο, μέσω HTTP και διαλειτουργικότητας με JavaScript
- [document][browser-document]: ελέγχει το `<title>` και το `<body>` μιας ιστοσελίδας
- [application][browser-application]: δημιουργεί πλήρεις εφαρμογές μίας σελίδας που χειρίζονται τη δρομολόγηση και τις αλλαγές στο URL

Αυτή η έννοια χρησιμοποιεί το [sandbox][browser-sandbox], καθώς είναι το πιο απλό (και επειδή είναι sandbox, είναι σχετικά εύκολο να δουλέψεις με τον διαδικτυακό επεξεργαστή του Exercism). Το module εισόδου ενός προγράμματος Elm πρέπει να ονομάζεται `Main` και η συνάρτηση που δημιουργεί την εφαρμογή πρέπει να ονομάζεται `main`, όπως παρακάτω.

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

Έχουμε ήδη δει τις συναρτήσεις `update` και `view`, και το [sandbox][browser-sandbox] απαιτεί επιπλέον μια συνάρτηση `init`, που επιστρέφει την αρχική κατάσταση του `Model`.
