# Οδηγίες

Αυτό το πρόβλημα είναι μοντελοποιημένο πάνω στον μη προεκτοπιστικό στατικό χρονοπρογραμματισμό λειτουργικών συστημάτων πραγματικού χρόνου, αλλά μοιάζει και με το Πρόβλημα Χρονοπρογραμματισμού Job-Shop (JSP) με έναν μόνο πόρο. Το πρόβλημα υποθέτει ότι όλες οι εργασίες είναι γνωστές στατικά. Με άλλα λόγια, οι χρόνοι απελευθέρωσης όλων των εργασιών σε αυτό το πρόβλημα είναι γνωστοί στην αρχή του προγράμματος. Στην πράξη, ο χρόνος απελευθέρωσης των εργασιών δεν είναι γνωστός στην αρχή ενός προγράμματος και μπορεί να παραχθεί οποιαδήποτε στιγμή μέσω I/O, διακοπών κ.λπ.

Δεδομένης μιας λίστας εργασιών με παραμέτρους, προσδιόρισε ένα χρονοπρόγραμμα στο οποίο οι εργασίες μπορούν να εκτελεστούν διαδοχικά χωρίς επικάλυψη. Επειδή το πρόβλημα είναι μοντελοποιημένο πάνω στον χρονοπρογραμματισμό διεργασιών RTOS, θα υποθέσουμε ότι απαιτείται μη μηδενικός χρόνος μεταξύ των εργασιών, γνωστός και ως επιβάρυνση εναλλαγής περιβάλλοντος. Υπάρχουν δύο διαφορετικοί τύποι εργασιών: περιοδικές και δυναμικές. Και οι δύο τύποι έχουν μια παράμετρο task ID, η οποία είναι μια συμβολοσειρά που χρησιμοποιείται για να ξεχωρίζουν οι διαφορετικές εργασίες στη λίστα εργασιών.

Μια **περιοδική εργασία** ορίζεται ως μια εργασία που εκτελείται περιοδικά. Με άλλα λόγια, η εργασία εκτελείται μία φορά κάθε T δευτερόλεπτα, όπου το T ορίζεται ως η περίοδος.
Μια περιοδική εργασία ορίζεται από τις παρακάτω παραμέτρους:
* Χρόνος έναρξης - η στιγμή που ξεκινά η πρώτη επανάληψη, ή στιγμιότυπο, της εργασίας
* Περίοδος - ο χρόνος μεταξύ της έναρξης των επαναλήψεων της εργασίας
* Χρόνος εκτέλεσης - ο χρόνος για τον οποίο εκτελείται κάθε επανάληψη
* Χρόνος λήξης - η στιγμή που η εργασία στο σύνολό της σταματά να χρονοπρογραμματίζεται

Μια **δυναμική εργασία** ορίζεται ως μια εργασία που εκτελείται μόνο μία φορά.
Μια δυναμική εργασία ορίζεται από τις παρακάτω παραμέτρους:
* Χρόνος απελευθέρωσης - η πρώτη στιγμή που η εργασία ΜΠΟΡΕΙ να χρονοπρογραμματιστεί (ΔΕΝ είναι το ίδιο με τον χρόνο έναρξης)
* Χρόνος εκτέλεσης - ο χρόνος για τον οποίο εκτελείται η εργασία
* Προθεσμία - η στιγμή μέχρι την οποία η εργασία πρέπει να έχει ολοκληρώσει την εκτέλεσή της

Υπάρχουν δύο είσοδοι στη συνάρτηση που πρέπει να υλοποιηθεί. Η πρώτη είσοδος είναι μια λίστα με στιγμιότυπα του `RealTimeTask`. Τα στιγμιότυπα του `RealTimeTask` θα δίνονται ως είσοδος είτε ως στιγμιότυπο του `PeriodicRealTimeTask` είτε ως στιγμιότυπο του `DynamicRealTimeTask`, με όλες τις παραμέτρους της εργασίας ως ακέραιους. Η ενσωματωμένη συνάρτηση `isinstance()` της Python μπορεί να χρησιμοποιηθεί για να ξεχωρίσεις τους δύο τύπους εργασιών στη λίστα. Η σειρά της λίστας δεν έχει σημασία: κοίτα μόνο τις παραμέτρους των εργασιών. Η δεύτερη είσοδος είναι ένας ακέραιος που καθορίζει την επιβάρυνση εναλλαγής περιβάλλοντος. Η επιβάρυνση εναλλαγής περιβάλλοντος θα είναι πάντα ένας μη αρνητικός ακέραιος.

Η έξοδος θα πρέπει να είναι ένα λεξικό όπου τα κλειδιά είναι το task ID από τα στιγμιότυπα του RealTimeTask, και η τιμή θα πρέπει να είναι μια λίστα με πλειάδες δύο στοιχείων. Η μορφή των πλειάδων δύο στοιχείων είναι (χρόνος έναρξης, χρόνος λήξης). Οι δυναμικές εργασίες θα πρέπει να περιέχουν μόνο μία πλειάδα δύο στοιχείων στη λίστα, ενώ οι περιοδικές εργασίες μπορεί να περιέχουν περισσότερες από μία. Η σειρά των πλειάδων δύο στοιχείων στη λίστα δεν έχει σημασία. Αν δεν μπορεί να δημιουργηθεί ένα έγκυρο χρονοπρόγραμμα από τη λίστα των εργασιών με τη δεδομένη επιβάρυνση εναλλαγής περιβάλλοντος, πέτα μια εξαίρεση `NoRtosStaticScheduleProducible`. Σημείωσε ότι τα αποτελέσματα του μοντέλου Z3 για τις μεταβλητές θα πρέπει να μετατραπούν σε ακέραιους πριν από την έξοδο. Αν το αποτέλεσμα του μοντέλου Z3 είναι τύπου `IntNumRef`, μπορεί να χρησιμοποιηθεί η μέθοδος κλάσης `as_long()` για τη μετατροπή σε ακέραιο.

Παρέχεται μια επιπλέον συνάρτηση που επιτρέπει στον χρήστη να οπτικοποιήσει τη διαδοχική σειρά των εργασιών. Αυτή η συνάρτηση μπορεί επίσης να ενεργοποιηθεί για μεμονωμένες περιπτώσεις δοκιμών, θέτοντας το όρισμα λέξης-κλειδιού `plot` σε `True` στη συνάρτηση `check()`. Για τη γραφική απεικόνιση και την επισήμανση κάθε εργασίας χρησιμοποιείται ένα διάγραμμα με σπασμένες οριζόντιες ράβδους. Για να χρησιμοποιήσεις αυτή τη συνάρτηση, πρέπει να είναι εγκατεστημένη η βιβλιοθήκη *matplotlib* της Python. Λεπτομέρειες εγκατάστασης για τη *matplotlib* μπορείς να βρεις [εδώ](https://matplotlib.org/stable/users/installing.html).
