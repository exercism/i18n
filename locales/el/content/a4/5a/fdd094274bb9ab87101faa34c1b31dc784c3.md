# Null

Το null είναι ένας πρωτογενής τύπος τιμής με μία και μόνο τιμή: `null`.
Το null χρησιμοποιείται συχνά για να αναπαραστήσει το τίποτα.
Θεωρείται "falsey", αλλά διαφέρει από το `false` και από τις άλλες τιμές falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Εργασία με τιμές null

Στην PHP, οι τιμές null μπορεί να αποτελούν συχνή αιτία σφαλμάτων, καθώς επιστρέφονται συχνά στη θέση μιας κατάστασης σφάλματος ή για να αναπαραστήσουν το τίποτα.
Για να μην προκύψουν σφάλματα, χρειάζεται συχνά να κάνεις "έλεγχο null", ώστε να βεβαιωθείς ότι η τιμή δεν είναι null πριν λειτουργήσεις πάνω της.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Ο επανειλημμένος έλεγχος null μπορεί εύκολα να οδηγήσει σε λάθη, οπότε η PHP παρέχει δύο τελεστές για την εργασία με τιμές null: τον τελεστή ασφαλούς πρόσβασης null `?->` και τον τελεστή συνένωσης null `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
