# Εισαγωγή

Η ειδική μορφή `import` σου επιτρέπει να χρησιμοποιείς συναρτήσεις από ένα εξωτερικό module χωρίς να χρησιμοποιείς το όνομα του module.

Η εισαγωγή ενός ολόκληρου εξωτερικού module μπορεί να δημιουργήσει συγκρούσεις με τις τοπικές συναρτήσεις που υπάρχουν ήδη. Για να το αποφύγεις αυτό, έχεις δύο επιλογές: `:except` και `:only`. Και οι δύο περιμένουν μια λίστα λέξεων-κλειδιών, όπου το κλειδί είναι το όνομα της συνάρτησης και η τιμή το πλήθος των ορισμάτων της.

Συνήθως τα imports προστίθενται στην αρχή του ορισμού του module.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
