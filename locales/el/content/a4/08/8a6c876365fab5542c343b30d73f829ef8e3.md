# Απαριθμήσεις

Οι απαριθμήσεις είναι ένας τύπος δεδομένων της Cairo που χρησιμοποιείται για να ορίσει ένα σύνολο προκαθορισμένων παραλλαγών, με σκοπό την αναγνωσιμότητα και την ασφάλεια του κώδικα.
Στη Cairo, οι παραλλαγές μιας `enum` μπορούν να δηλωθούν ώστε να περιέχουν διαφορετικούς τύπους δεδομένων (ακέραιους, δομές, πλειάδες, άλλες απαριθμήσεις κ.λπ.).

Το παρακάτω απόσπασμα κώδικα δείχνει πώς θα μπορούσαν να οριστούν οι απαριθμήσεις:

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

Η απαρίθμηση `Direction` που δηλώθηκε παραπάνω είναι μια απλή απαρίθμηση με τέσσερις παραλλαγές: `North`, `East`, `South` και `West`.
Η σύμβαση ονομασίας είναι να χρησιμοποιείς PascalCase για τις παραλλαγές της απαρίθμησης.
Κάθε παραλλαγή αντιπροσωπεύει μια ξεχωριστή τιμή του τύπου απαρίθμησης `Direction`.
Κάθε παραλλαγή σε αυτό το συγκεκριμένο παράδειγμα απαρίθμησης δεν έχει συσχετισμένη τιμή και μπορείς να δημιουργήσεις ένα στιγμιότυπό της με αυτή τη σύνταξη:

```rust
let direction = Direction::North;
```

Παρακάτω βλέπεις την ίδια απαρίθμηση `Direction`, αλλά με παραλλαγές που έχουν συσχετισμένες τιμές, οι οποίες αποθηκεύουν την ακριβή μοίρα της κατεύθυνσης:

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

Από αυτό το παράδειγμα είναι φανερό ότι κάθε παραλλαγή στην απαρίθμηση `Direction` έχει μια συσχετισμένη τιμή τύπου `u128`.
Μπορείς να δημιουργήσεις ένα στιγμιότυπο αυτού του είδους απαρίθμησης ως εξής:

```rust
let direction = Direction::North(10);
```

## Παράδειγμα σύνθετης απαρίθμησης με προσαρμοσμένους τύπους

Μια απαρίθμηση μπορεί να δηλωθεί με έναν συνδυασμό διαφορετικών τύπων δεδομένων ως παραλλαγές της.
Στο παρακάτω παράδειγμα, η `Action` είναι μια σύνθετη απαρίθμηση που έχει ως παραλλαγές της μια συλλογή από `Quit`, `Direction`, `SendMessage`, `ChangeAvatar` και `ProfileState`.

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## Υλοποιήσεις trait για απαριθμήσεις

Στη Cairo, μπορείς να ορίσεις traits και να τα υλοποιήσεις σε προσαρμοσμένες απαριθμήσεις.
Αυτό σου επιτρέπει να ορίσεις μεθόδους και χαρακτηριστικά που σχετίζονται με μια απαρίθμηση.
Παρακάτω υπάρχει ένα παράδειγμα όπου ορίζουμε μια απαρίθμηση `Message` και υλοποιούμε ένα trait `Processing` για αυτήν:

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

Δες πώς θα μπορούσε να χρησιμοποιηθεί το trait για να επεξεργαστεί ένα μήνυμα `Quit`:

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

Σε πολλές περιπτώσεις, οι απαριθμήσεις είναι πολύ χρήσιμες, ειδικά όταν χρησιμοποιούνται με τη ροή `match`, όπως παραπάνω στην υλοποίηση των traits.
Διάβασε περισσότερα για τη ροή `match` στο [The Cairo Book][match].
