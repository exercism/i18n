# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις λογικοί τελεστές, οι '!`(logical NOT), '||` (λογικό OR) και `&&` (λογικό AND), όταν δουλεύεις με τιμές Boolean.
- Πολλοί τελεστές μπορούν να συνδυαστούν σε μία έκφραση.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

- Ο λογικός τελεστής NOT (`!`) μπορεί να μπει πριν από μια έκφραση για να αντιστρέψει την τιμή της.

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

- Οι λογικοί τελεστές χρησιμοποιούνται συνήθως για να αξιολογήσουν αν δύο ή περισσότερες εκφράσεις είναι αληθείς ή όχι.

## 3. Έλεγξε αν μπορείς να δώσεις σήμα στον κρατούμενο

- Οι λογικοί τελεστές εκτελούνται με σειρά προτεραιότητας (από την υψηλότερη στη χαμηλότερη): `!`, `&&`, `||`.
