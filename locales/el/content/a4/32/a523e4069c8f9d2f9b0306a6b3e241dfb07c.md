# Σχετικά

## Ψευδώνυμα τύπων

Ένα ψευδώνυμο τύπου μπορεί να χρησιμοποιηθεί στη Gleam για να δώσει ένα βολικό όνομα σε έναν υπάρχοντα τύπο που διαφορετικά θα ήταν δυσκίνητος στη γραφή.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Όταν γράφεται με `pub type`, το ψευδώνυμο μπορεί να χρησιμοποιηθεί και εκτός της ενότητας στην οποία ορίζεται. Αν το `pub` παραλειφθεί, τότε το ψευδώνυμο είναι ιδιωτικό και δεν μπορεί να γίνει αναφορά σε αυτό από άλλες ενότητες.
