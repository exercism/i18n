# Εισαγωγή

Η έκφραση `let` (έστω) χρησιμοποιείται για να δημιουργεί μια τοπική εμβέλεια και είναι χρήσιμη σε μερικές περιπτώσεις:

- Για απλοποίηση εκφράσεων
- Για ονομασία των αποτελεσμάτων ενδιάμεσων εκφράσεων
- Για χωρισμό μιας έκφρασης σε μικρότερα κομμάτια αν αυτή μεγαλώνει

Μπορείς να κάνεις τα περισσότερα πράγματα μέσα σε μια έκφραση `let`, όπως η αποδόμηση (περισσότερες λεπτομέρειες σε επόμενες ασκήσεις), αλλά δεν είναι δυνατό να ορίσεις ένα νέο Custom Type ή ένα Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
