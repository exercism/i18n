# Συμβουλές

## Γενικά

- Η σύνταξη `0b00` μπορεί να χρησιμοποιηθεί για να ορίσεις ένα int σε δυαδική σύνταξη αντί για δεκαδική.

## 1. Κωδικοποίησε το νουκλεϊκό οξύ σε δυαδική τιμή

- Στον τύπο του νουκλεοτιδίου μπορείς να κάνεις αντιστοίχιση μοτίβου με μια έκφραση case.

## 2. Αποκωδικοποίησε τη δυαδική τιμή στο νουκλεϊκό οξύ

- Η δυαδική σύνταξη int μπορεί να χρησιμοποιηθεί σε μοτίβα.
- Επίστρεψε `Error(Nil)` αν το int δεν είναι έγκυρο νουκλεοτίδιο.

## 3. Κωδικοποίησε μια λίστα DNA

- Η συνάρτηση `encode_nucleotide` μπορεί να χρησιμοποιηθεί για να κωδικοποιήσεις ένα μεμονωμένο νουκλεοτίδιο.

## 4. Αποκωδικοποίησε ένα bitarray DNA

- Η δυαδική σύνταξη int μπορεί να χρησιμοποιηθεί μέσα σε ένα μοτίβο bit array.
- Επίστρεψε `Error(Nil)` αν το υπόλοιπο bit array δεν είναι αρκετά μεγάλο για να περιέχει ένα νουκλεοτίδιο.
