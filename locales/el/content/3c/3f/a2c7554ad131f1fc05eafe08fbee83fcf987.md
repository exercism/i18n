# Σχετικά

Οι λίστες είναι ένα παράδειγμα [γενικών κλάσεων][generics]. Θα δεις επίσης τα `HashSet<T>` και `Dictionary<T>` σε ασκήσεις που θα συναντήσεις νωρίς.

Αν χρειάζεσαι μια λίστα με διαφορετικούς τύπους, μπορείς να χρησιμοποιήσεις το `List<Object>`, αλλά θα χρειαστεί να κάνεις [μετατροπή προς τα κάτω][casting] στα στοιχεία που παίρνεις από τη λίστα.

Θα πρέπει επίσης να γνωρίζεις το `System.Collections.List`, το οποίο μπορεί να συναντήσεις σε παλαιότερο κώδικα. Στην πράξη, συμπεριφέρεται σαν `List<Object>`.

[generics]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/
[casting]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/types/casting-and-type-conversions
