# Σχετικά

Ένας buffer συμβολοσειρών είναι ένας αποδοτικός τρόπος να φτιάχνεις μια μεγάλη συμβολοσειρά προσθέτοντας στο τέλος μικρά στοιχεία. Σε αντίθεση με το String, ένα στιγμιότυπο του StringBuf δεν είναι αμετάβλητο, υπό την έννοια ότι μπορεί να περαστεί ως όρισμα σε συναρτήσεις που το τροποποιούν προσθέτοντας στο τέλος κι άλλες τιμές.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
