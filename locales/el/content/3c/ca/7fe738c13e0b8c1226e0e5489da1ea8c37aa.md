# Υποδείξεις

## Γενικά

- Διάβασε για τις διεργασίες στον επίσημο οδηγό [Getting Started][getting-started-processes].
- Διάβασε [αυτή την ανάρτηση][mullen-processes] σχετικά με τις διεργασίες στην Elixir.

## 1. Ξεκίνα τη μηχανή

- Η μηχανή πρέπει να τρέχει σε μια νέα διεργασία. Υπάρχει [μια ενσωματωμένη συνάρτηση που ξεκινά μια νέα διεργασία][kernel-spawn-1].
- Χρησιμοποίησε μια ανώνυμη συνάρτηση με μηδέν ορίσματα όταν ξεκινάς μια νέα διεργασία. Αυτή η συνάρτηση δεν χρειάζεται να κάνει τίποτα ακόμα.

## 2. Ανάφερε την κατάσταση της μηχανής

- Θα χρειαστείς μια νέα συνάρτηση με όνομα. Μπορείς να τη ονομάσεις, για παράδειγμα, `loop`.
- Αυτή η νέα συνάρτηση πρέπει να δέχεται ένα όρισμα, την κατάσταση.
- Η ανώνυμη συνάρτηση με μηδέν ορίσματα από το προηγούμενο βήμα μπορεί να καλέσει τη νέα συνάρτηση με όνομα, περνώντας της την αρχική κατάσταση.
- Η νέα συνάρτηση με όνομα πρέπει να ανταποκρίνεται σε μηνύματα.
- Υπάρχει [μια ενσωματωμένη συνάρτηση που περιμένει να φτάσει ένα μήνυμα στο γραμματοκιβώτιο της διεργασίας][kernel-receive].
- Υπάρχει [μια ενσωματωμένη συνάρτηση που στέλνει ένα μήνυμα σε μια άλλη διεργασία][kernel-send].
- Χρησιμοποίησε αναδρομή για να περιμένεις περισσότερα από ένα μηνύματα.

## 3. Δώσε αριθμούς

- Αυτό το βήμα είναι εννοιολογικά το ίδιο με το προηγούμενο βήμα. Η μόνη διαφορά είναι η ανάγκη να ενημερώσεις την κατάσταση της μηχανής.

## 4. Σταμάτα τη μηχανή

- Αυτό το βήμα δεν απαιτεί να στείλεις μηνύματα ως απάντηση.
- Μια διεργασία θα τερματιστεί αν δεν έχει άλλο κώδικα να εκτελέσει.
- Όταν χρειάζεται να δημιουργήσεις ένα "άδειο" μπλοκ κώδικα στην Elixir, μπορείς να χρησιμοποιήσεις το `nil` ως τη μόνη έκφραση σε αυτό το μπλοκ κώδικα.
- Αυτή είναι μια βασική περίπτωση της αναδρομικής συνάρτησης.

## 5. Αγνόησε τα απρόσμενα μηνύματα

- Αυτό το βήμα δεν απαιτεί να στείλεις μηνύματα ως απάντηση.
- Μπορείς να χρησιμοποιήσεις το `_` για να ταιριάξεις όλα τα μηνύματα που δεν ταίριαξαν με προηγούμενα μοτίβα.
