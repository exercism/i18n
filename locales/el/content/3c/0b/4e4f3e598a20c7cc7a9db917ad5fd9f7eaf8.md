# Εισαγωγή

Τα αντικείμενα μπορούν να διατηρούν τη δική τους κατάσταση ορίζοντας _μεταβλητές στιγμιοτύπου_, οι οποίες δημιουργούνται βάζοντας το `@` μπροστά από το όνομα μιας μεταβλητής.

```ruby
@name = 2
```

Τα αντικείμενα συνήθως ορίζουν την αρχική τους κατάσταση σε μια μέθοδο `initialize`, η οποία καλείται αυτόματα όταν καλείς `new` σε μια κλάση.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

Η μέθοδος `initialize` μπορεί επίσης να δέχεται ορίσματα, ώστε κάθε στιγμιότυπο να μπορεί να ξεκινά με μια προσαρμοσμένη κατάσταση:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Θεώρησε ότι οι _μεταβλητές στιγμιοτύπου_ είναι ιδιωτικές, χωρίς εξωτερικές αναγνώσεις και εγγραφές. Οι _μέθοδοι στιγμιοτύπου_ θα πρέπει να χρησιμοποιούνται για τη λήψη και τον ορισμό μεταβλητών στιγμιοτύπου:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
