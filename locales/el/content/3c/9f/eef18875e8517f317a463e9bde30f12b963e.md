# Εισαγωγή

Το Hashmap είναι μια συλλογή που χρησιμοποιείται για την αποθήκευση ζευγών κλειδιού-τιμής. Επιτρέπει τη χρήση αυθαίρετων τύπων ως κλειδιά και τιμές. Έχει γρήγορες λειτουργίες εισαγωγής και ανάκτησης και είναι πολύ χρήσιμο, π.χ. για καταμέτρηση συχνοτήτων, αποθήκευση σχέσεων κ.λπ. Διαθέτει επίσης το ισχυρό API `entry`, που το κάνει εργονομικό στη χρήση.
