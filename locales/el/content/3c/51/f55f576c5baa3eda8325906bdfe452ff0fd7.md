# βελτιστοποίησε την προεπιλεγμένη τιμή

Αντί να χρησιμοποιείς μια συνθήκη για διακλάδωση στην περίπτωση που δεν περνιέται καμία τιμή στο `twoFer`, όρισε την [προεπιλεγμένη τιμή](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Functions/Default_parameters) της παραμέτρου `%{parameter}` σε `'you'` για να αποφύγεις αυτή τη συνθήκη.
