# Εισαγωγή

## Τελεστές σύγκρισης

Οι τελεστές σύγκρισης στη Julia μοιάζουν με αυτούς πολλών άλλων γλωσσών, αν και προσφέρουν μερικές επιπλέον επιλογές για τους λάτρεις των μαθηματικών.

Για την ισότητα, οι τελεστές είναι `==` (ίσο) και `!=` ή `≠` (άνισο).

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

Επιπλέον, έχουμε τους διάφορους τελεστές μεγαλύτερο/μικρότερο.

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

Όπως συμβαίνει συχνά με τη Julia, ένας κατάλληλος επεξεργαστής κάνει εύκολη τη χρήση του μαθηματικού συμβόλου.
Πληκτρολόγησε `\ne`, `\le` ή `\ge` και μετά `TAB` για να πάρεις `≠`, `≤` ή `≥`.

Το προηγούμενο παράδειγμα χρησιμοποιεί μόνο αριθμούς, αλλά θα δούμε σε άλλα σημεία της ύλης ότι διάφοροι επιπλέον τύποι έχουν έννοια διάταξης και μπορούν να ελεγχθούν ως προς το μεγαλύτερο/μικρότερο.

Οι τελεστές σύγκρισης μπορούν να αλυσιδωθούν, κάτι που επιτρέπει μια σαφή και συνοπτική σύνταξη:

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

Το προηγούμενο παράδειγμα είναι συνώνυμο του `1 ≤ n && n ≤ 5`.

## Διακλάδωση με `if`

Αυτή είναι η πλήρης μορφή μιας εντολής `if`:

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

Δεν χρειάζονται παρενθέσεις `()` ούτε άγκιστρα `{}`, και η εσοχή υπάρχει "μόνο" για να βελτιώνει την αναγνωσιμότητα _(αλλά η αναγνωσιμότητα είναι πολύ σημαντική!)_.

Τόσο το `elseif` όσο και το `else` είναι προαιρετικά, και μπορούν να υπάρχουν πολλά μπλοκ `elseif`.
Ωστόσο, το `end` είναι υποχρεωτικό.

Είναι δυνατό να εμφωλεύσεις εντολές `if`, αν και ίσως θελήσεις να βοηθήσεις την αναγνωσιμότητα με τη στοχαστική χρήση παρενθέσεων, εσοχών και σχολίων.

Η συντομότερη μορφή μιας εντολής `if` θα ήταν κάπως έτσι:

```julia
if n < 0
    n = 0
end
```

Υπενθύμιση: μόνο εκφράσεις που αξιολογούνται σε `true` ή `false` μπορούν να χρησιμοποιηθούν ως συνθήκες.
Η Julia αποφεύγει σκόπιμα οποιαδήποτε έννοια "truthiness", οπότε μηδενικές τιμές, κενές συμβολοσειρές και κενοί πίνακες _δεν_ είναι ισοδύναμα με το `false`.

## Τριαδικός τελεστής

Μια απλή και συνηθισμένη περίπτωση είναι η επιλογή μιας από δύο τιμές με βάση μια συνθήκη.

Η Julia, όπως πολλές γλώσσες, έχει έναν τριαδικό τελεστή για να το κάνει πιο συνοπτικό.

Η σύνταξη είναι `conditional ? value_if_true : value_if_false`.

Έτσι, το προηγούμενο παράδειγμα θα μπορούσε να ξαναγραφτεί:

```julia
n = n < 0 ? 0 : n
```

Οι παρενθέσεις δεν απαιτούνται από τον μεταγλωττιστή, αλλά μπορεί να βελτιώσουν την αναγνωσιμότητα.
