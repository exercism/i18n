# Υποδείξεις

## 1. Υπολόγισε την τιμή οποιουδήποτε φύλλου

- Μια [`switch`][ref-switch] παλιού τύπου λειτουργεί καλά εδώ, αφού χρειάζεται να χειριστεί μόνο ένα φύλλο σε κάθε κλήση.
- Η χρήση της [`case_match`][ref-case_match] είναι μια άλλη επιλογή, αλλά σε αυτή την περίπτωση τα εισαγωγικά γύρω από τις συμβολοσειρές δεν μπορούν να παραλειφθούν.

## 2. Υλοποίησε τη λογική απόφασης για τον πρώτο γύρο

- Η [`case_when`][ref-case_when] είναι χρήσιμη σε αυτή την εργασία.
- Η εργασία μπορεί να λυθεί στη base R με μια σειρά από συνθήκες, αλλά με λιγότερη κομψότητα.

[ref-switch]: https://stat.ethz.ch/R-manual/R-devel/library/base/html/switch.html
[ref-case_match]: https://dplyr.tidyverse.org/reference/case_match.html
[ref-case_when]: https://dplyr.tidyverse.org/reference/case_when.html
