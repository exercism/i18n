# Εισαγωγή

Μια μέθοδος είναι μια συνάρτηση με ένα ειδικό όρισμα _δέκτη_.
Ο δέκτης εμφανίζεται στη δική του λίστα ορισμάτων, ανάμεσα στη λέξη-κλειδί `func` και το όνομα της μεθόδου.

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

Μπορείς να ορίσεις μια μέθοδο με δέκτη μόνο αν ο τύπος του είναι ορισμένος στο ίδιο πακέτο με τη μέθοδο.

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

Τη μέθοδο στη δομή μπορείς να την καλέσεις χρησιμοποιώντας τη σημειογραφία της τελείας.

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

Πρόσεξε τον τρόπο με τον οποίο καλέσαμε τη μέθοδο `Greetings()` στο στιγμιότυπο `Person` `p`.
Είναι ακριβώς όπως καλείς μεθόδους σε μια αντικειμενοστρεφή γλώσσα προγραμματισμού.

Θυμήσου: μια μέθοδος δεν είναι παρά μια συνάρτηση με όρισμα δέκτη.
Οι μέθοδοι βοηθούν να αποφεύγεις συγκρούσεις ονομάτων, καθώς μια μέθοδος είναι δεμένη με έναν συγκεκριμένο τύπο δέκτη, οπότε μπορείς να έχεις το ίδιο όνομα μεθόδου σε διαφορετικούς τύπους.

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

Υπάρχουν δύο είδη δεκτών: οι δέκτες τιμής και οι δέκτες δείκτη.

Όλες οι μέθοδοι που έχουμε δει μέχρι τώρα έχουν δέκτη τιμής, που σημαίνει ότι λαμβάνουν ένα αντίγραφο της τιμής που περνιέται στη μέθοδο. Αυτό σημαίνει ότι οποιαδήποτε τροποποίηση γίνει στον δέκτη μέσα στη μέθοδο δεν είναι ορατή σε αυτόν που καλεί τη μέθοδο.

Μπορείς να δηλώσεις μεθόδους με δέκτες δείκτη, ώστε να τροποποιήσεις την τιμή στην οποία δείχνει ο δέκτης.
Αυτό γίνεται βάζοντας ένα `*` μπροστά από το όνομα του τύπου.
Για παράδειγμα, με τον τύπο `rect`, ένας δέκτης δείκτη δηλώνεται ως `*rect`.
Τέτοιες τροποποιήσεις είναι ορατές και σε αυτόν που καλεί τη μέθοδο.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
