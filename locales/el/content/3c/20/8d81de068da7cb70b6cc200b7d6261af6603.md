# Σχετικά

## Συναρτήσεις διαφυγής

Υπάρχουν φορές που μια συνάρτηση ανώτερης τάξης παίρνει μια άλλη συνάρτηση ως παράμετρο και τη χρησιμοποιεί με τρόπο ώστε η συνάρτηση που περνιέται να καλείται _αφού_ τερματίσει η συνάρτηση ανώτερης τάξης. Αυτό είναι γνωστό ως διαφυγή από τη συνάρτηση ανώτερης τάξης, και η συνάρτηση που περνιέται αναφέρεται ως [συνάρτηση διαφυγής][escaping].

Αυτό συμβαίνει πιο συχνά σε ασύγχρονο κώδικα, αλλά μπορεί να προκύψει σε συναρτήσεις ανώτερης τάξης όπου η συνάρτηση που περνιέται (ή μια συνάρτηση που την καλεί) επιστρέφεται από τη συνάρτηση ανώτερης τάξης. Για παράδειγμα:

```swift
func emptyKitchen(_ order: String) -> String {
  "Sorry, we're all out of \(order)."
}

func prepare(order: String, kitchen: (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}
```

Εδώ, η συνάρτηση `prepare` δέχεται μια συνάρτηση για την παράμετρό της `kitchen`, στη συνέχεια κατασκευάζει μια νέα συνάρτηση `newKitchen` η οποία μπορεί να καλέσει την `kitchen`. Αυτή η συνάρτηση `newKitchen` επιστρέφεται μετά στον καλούντα. Η προσπάθεια να γράψεις αυτή τη συνάρτηση σε Swift έχει ως αποτέλεσμα το σφάλμα: _Escaping local function captures non-escaping parameter 'kitchen'_

Η Swift προκαλεί σφάλμα σε αυτή την περίπτωση επειδή υπάρχουν καταστάσεις όπου η εμφωλευμένη συνάρτηση ή αυτή που περνιέται μπορεί να συλλάβει μια τιμή που μπορεί να οδηγήσει σε διαρροές μνήμης. Το πώς συμβαίνει αυτό και το πώς να αποτρέψεις αυτές τις διαρροές είναι πέρα από το πεδίο αυτής της άσκησης. Ωστόσο, αυτό το σφάλμα μπορεί να ικανοποιηθεί τοποθετώντας το χαρακτηριστικό `@escaping` πριν από την υπογραφή τύπου της συνάρτησης που περνιέται.

```swift
func prepare(order: String, kitchen: @escaping (String) -> String) -> (String) -> String {
  func newKitchen(_ newOrder: String) -> String {
    if newOrder == order {
      return "One \(order) coming up!"
    } else {
      return kitchen(newOrder)
    }
  }
  return newKitchen
}

let restaurant =
  prepare(order: "sandwich",
          kitchen: prepare(order: "chicken",
                           kitchen: prepare(order: "steak",
                                            kitchen: emptyKitchen)))

restaurant("pork chop")
// => "Sorry, we're all out of pork chop."
restaurant("chicken")
// => "One chicken coming up!"
```

Αυτό το χαρακτηριστικό σηματοδοτεί στον μεταγλωττιστή της Swift ότι ο συγγραφέας γνωρίζει ότι μπορεί να προκύψουν διαρροές μνήμης επιτρέποντας σε αυτή τη συνάρτηση να διαφύγει.

[escaping]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID546
