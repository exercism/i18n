# Οδηγίες

Μετάφρασε αλληλουχίες RNA σε πρωτεΐνες.

Το RNA μπορεί να χωριστεί σε αλληλουχίες τριών νουκλεοτιδίων που ονομάζονται κωδικόνια και στη συνέχεια να μεταφραστεί σε μια πρωτεΐνη ως εξής:

RNA: `"AUGUUUUCU"` => μεταφράζεται σε

Κωδικόνια: `"AUG", "UUU", "UCU"`
=> που γίνονται μια πρωτεΐνη με την ακόλουθη αλληλουχία =>

Πρωτεΐνη: `"Methionine", "Phenylalanine", "Serine"`

Υπάρχουν 64 κωδικόνια που με τη σειρά τους αντιστοιχούν σε 20 αμινοξέα· ωστόσο, όλες οι αλληλουχίες κωδικονίων και τα αμινοξέα που προκύπτουν δεν είναι σημαντικά σε αυτή την άσκηση.
Αν λειτουργεί για ένα κωδικόνιο, το πρόγραμμα θα πρέπει να λειτουργεί για όλα.
Ωστόσο, μπορείς ελεύθερα να επεκτείνεις τη λίστα στη σουίτα δοκιμών για να τα συμπεριλάβεις όλα.

Υπάρχουν επίσης τρία κωδικόνια τερματισμού (γνωστά και ως κωδικόνια 'STOP')· αν συναντηθεί κάποιο από αυτά τα κωδικόνια (από το ριβόσωμα), η μετάφραση σταματά και η πρωτεΐνη τερματίζεται.

Όλα τα επόμενα κωδικόνια μετά από αυτό αγνοούνται, ως εξής:

RNA: `"AUGUUUUCUUAAAUG"` =>

Κωδικόνια: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Πρωτεΐνη: `"Methionine", "Phenylalanine", "Serine"`

Σημείωσε ότι το κωδικόνιο τερματισμού `"UAA"` τερματίζει τη μετάφραση και η τελική μεθειονίνη δεν μεταφράζεται στην αλληλουχία της πρωτεΐνης.

Παρακάτω είναι τα κωδικόνια και τα αμινοξέα που προκύπτουν και χρειάζονται για την άσκηση.

| Κωδικόνιο          | Αμινοξύ       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Μάθε περισσότερα για τη [μετάφραση πρωτεΐνης στη Wikipedia][protein-translation].

[protein-translation]: https://en.wikipedia.org/wiki/Translation_(biology)
