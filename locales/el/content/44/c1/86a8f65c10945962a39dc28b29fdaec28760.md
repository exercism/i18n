# Εισαγωγή

Οι Boolean (λογικές τιμές) στη Go αντιπροσωπεύονται από τον προδηλωμένο boolean τύπο `bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.
Είναι ένας ορισμένος τύπος.

```go
var closed bool    // boolean variable 'closed' implicitly initialized with 'false'
speeding := true   // boolean variable 'speeding' initialized with 'true'
hasError := false  // boolean variable 'hasError' initialized with 'false' 
```

Η Go υποστηρίζει τρεις λογικούς τελεστές που μπορούν να αξιολογήσουν εκφράσεις σε τιμές Boolean, επιστρέφοντας είτε `true` είτε `false`.

| Τελεστής    | Τι σημαίνει                                 |
| ----------- | --------------------------------------------- |
| `&&` (και)  | Είναι αληθής αν και οι δύο προτάσεις είναι αληθείς.       |
| `\|\|` (ή) | Είναι αληθής αν τουλάχιστον μία πρόταση είναι αληθής. |
| `!` (όχι)   | Είναι αληθής μόνο αν η πρόταση είναι ψευδής.    |
