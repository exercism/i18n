# Σχετικά

Τα hash-sets υλοποιούν το [`sets`][sets] [πρωτόκολλο][set-protocol] με κατακερματισμό στο παρασκήνιο, δίνοντας κατά μέσο όρο O(1) για εισαγωγή, αναζήτηση και διαγραφή.
Είναι μεταβλητά επί τόπου, κάτι που τα κάνει ιδανικά για το μοτίβο του *συνόλου επισκέψεων* στις διασχίσεις γράφων.

```factor
USING: hash-sets kernel sets ;

HS{ } clone                   ! fresh empty mutable set
"NS-1024" over adjoin         ! insert (no-op if already present)
"NS-1024" over in? .          ! => t  (membership test)
"WB-203" over adjoin
over cardinality .            ! => 2
"NS-1024" over delete         ! remove
over cardinality .            ! => 1
```

| word          | effect                                    |
|---------------|-------------------------------------------|
| `HS{ }`       | κενό literal hash-set (κοινόχρηστο, κάνε `clone`!) |
| `>hash-set`   | `( seq -- set )` — φτιάχνει ένα νέο σύνολο από μια ακολουθία (αφαιρεί τα διπλότυπα) |
| `adjoin`      | `( elt set -- )` — καταστροφική εισαγωγή     |
| `in?`         | `( elt set -- ? )` — συμμετοχή           |
| `delete`      | `( elt set -- )` — καταστροφική αφαίρεση     |
| `cardinality` | `( set -- n )` — αριθμός στοιχείων       |
| `null?`       | `( set -- ? )` — αληθής όταν το σύνολο είναι κενό |
| `members`     | `( set -- seq )` — απαρίθμηση ως ακολουθία  |
| `union`       | `( set1 set2 -- set )`                    |
| `intersect`   | `( set1 set2 -- set )`                    |
| `diff`        | `( set1 set2 -- set )`                    |
| `set-like`    | `( set exemplar -- set' )` — μετατρέπει το `set` στην κλάση του `exemplar` |

Για να φτιάξεις ένα σύνολο από δεδομένα που έχεις ήδη, το `>hash-set` μετατρέπει οποιαδήποτε ακολουθία σε ένα βήμα, απορρίπτοντας τα διπλότυπα: `{ 2 3 2 5 }
>hash-set` gives `HS{ 2 3 5 }`. It's the bulk counterpart to
growing a set with repeated `adjoin`.

Ένα λεπτό σημείο σχετικά με το `in?` εναντίον του `member?` (από το
`sequences`): και τα δύο ελέγχουν τη συμμετοχή, αλλά το `member?` κάνει
γραμμική σάρωση πάνω σε μια ακολουθία, ενώ το `in?` αναθέτει στη μέθοδο
πρωτοκόλλου του εκάστοτε τύπου συνόλου: για το `HS{ }`, αυτή είναι μια
αναζήτηση με κατακερματισμό. Χρησιμοποίησε το `in?` όταν το δοχείο των
"επισκέψεων" σου έχει παραπάνω από μια χούφτα καταχωρίσεις.

Το `null?` απαντά στο "είναι αυτό το σύνολο κενό;" χωρίς να υπολογίσει
ολόκληρο το `cardinality`· είναι ο φυσικός φρουρός για το "έχουμε κάτι
ακόμη να επεξεργαστούμε;". Για μια λίστα εργασιών που κρατιέται ως σύνολο,
το `[ set null? ] [ … ] until` την εξαντλεί μέχρι να αδειάσει.

## Ταιριάζει ωραία με τους πίνακες κατακερματισμού

Το `HS{ }` για το "έχει επισκεφθεί το X;" ταιριάζει φυσικά με το `H{ }` για
το "ποιοι είναι οι γείτονες του X;". Μια DFS από το βιβλίο είναι απλώς:

```factor
visited adjoin
stack push
[ stack empty? ] [
    stack pop dup neighbours-quot call [
        dup visited in? [ drop ] [
            [ visited adjoin ] [ stack push ] bi
        ] if
    ] each
] until
```

Το σύνολο επισκέψεων αφαιρεί τα διπλότυπα της δουλειάς· η στοίβα μεταφέρει
τους κόμβους του μετώπου (LIFO μέσω `push`/`pop`)· ο χάρτης γειτόνων (ένας
πίνακας κατακερματισμού) παρέχει τον γράφο. Η σειρά επίσκεψης δεν έχει
σημασία για ένα ερώτημα προσβασιμότητας, γι' αυτό αρκεί ένα διάνυσμα που
χρησιμοποιείται ως στοίβα: μια πραγματική BFS πάνω στην ίδια δομή αλλάζει
το διάνυσμα για ένα
[`<dlist>`][dlist] και κάνει dequeue από το μπροστινό μέρος αντ' αυτού.
