# Σχετικά

Η Elixir χρησιμοποιεί [_Behaviours_][behaviours] για να παρέχει κοινές γενικές διεπαφές, διευκολύνοντας παράλληλα τις επιμέρους υλοποιήσεις για κάθε module που υλοποιεί το behaviour. Ένα από αυτά τα behaviours είναι το _Access Behaviour_.

Το _Access Behaviour_ παρέχει μια κοινή διεπαφή για την ανάκτηση δεδομένων με βάση κλειδί από μια δομή δεδομένων. Υλοποιείται για maps και λίστες λέξεων-κλειδιών.

Το module [`Access`][access] ορίζει τα callbacks που απαιτούνται για τη διεπαφή. Τα modules [`Map`][map] και [`Keyword`][keyword] στη συνέχεια υλοποιούν τα απαιτούμενα callbacks [`fetch/2`][map-fetch], [`get_and_update/3`][map-get-and-update] και [`pop/2`][map-pop]

Για να χρησιμοποιήσεις το behaviour, μπορείς να βάλεις μετά από μια δεσμευμένη μεταβλητή _αγκύλες_ και στη συνέχεια να χρησιμοποιήσεις το κλειδί για να ανακτήσεις την τιμή που σχετίζεται με αυτό το κλειδί. Τα maps υποστηρίζουν κλειδιά οποιουδήποτε τύπου, ενώ οι λίστες λέξεων-κλειδιών μόνο κλειδιά atom.

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

Αν το κλειδί δεν υπάρχει στη δομή δεδομένων, τότε επιστρέφεται `nil`. Αυτό μπορεί να γίνει πηγή ανεπιθύμητης συμπεριφοράς, γιατί δεν πετάει ένα σφάλμα.

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

Σημείωσε ότι το ίδιο το `nil` υλοποιεί το Access Behaviour και επιστρέφει πάντα `nil` για οποιοδήποτε κλειδί.

```elixir
nil[:key]
# => nil
```

Τα structs δεν υλοποιούν το Access Behaviour.
