# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις σε μια εφαρμογή προγραμματισμού ραντεβού για ένα σαλόνι ομορφιάς στη Νέα Υόρκη, το οποίο άνοιξε στις 15 Σεπτεμβρίου του 2012.

Έχεις πέντε εργασίες, οι οποίες όλες θα έχουν να κάνουν με ημερομηνίες ραντεβού.
Οι ώρες είναι σε μορφή 24ώρου (χωρίς π.μ./μ.μ.).
Για να κρατήσουμε τα ζητήματα ζώνης ώρας όσο το δυνατόν πιο απλά, υπόθεσε ότι τα πάντα χρησιμοποιούν UTC.

## 1. Ανάλυση ημερομηνίας ραντεβού με όλα τα στοιχεία αριθμητικά

Υλοποίησε τη συνάρτηση `schedule_appointment()` ώστε να μετατρέπει μια κειμενική αναπαράσταση μιας ημερομηνίας ραντεβού στην αντίστοιχη μορφή `DateTime`.

Σημείωσε ότι η είσοδος είναι σε αμερικανική σειρά μήνας/ημέρα/έτος.

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. Έλεγχος αν ένα ραντεβού έχει ήδη περάσει

Υλοποίησε τη συνάρτηση `has_passed()`, η οποία παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού ήταν κάπου στο παρελθόν:

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. Έλεγχος αν το ραντεβού είναι το απόγευμα

Υλοποίησε τη συνάρτηση `is_afternoon_appointment()`, η οποία παίρνει μια ημερομηνία ραντεβού και ελέγχει αν το ραντεβού είναι το απόγευμα (>= 12:00 και < 18:00):

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. Έλεγχος της ημέρας της εβδομάδας για ένα ραντεβού

Υλοποίησε τη συνάρτηση `day_of_week()`, η οποία επιστρέφει την _αριθμητική_ ημέρα της εβδομάδας.
Το σαλόνι είναι κλειστό τις Κυριακές, οπότε η Δευτέρα είναι η ημέρα 1 και το Σάββατο η ημέρα 6.

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. Μετάθεση ενός ραντεβού

Όταν ένας πελάτης χρειάζεται να μεταθέσει ένα ραντεβού, αυτό γίνεται αυτόματα για την επόμενη Παρασκευή την ίδια ώρα της ημέρας (καθώς αυτή είναι η πιο ήσυχη μέρα της εβδομάδας).

Υλοποίησε τη συνάρτηση `reschedule()`, η οποία παίρνει το αρχικό ραντεβού (ως συμβολοσειρά κειμένου σε σειρά μήνας/ημέρα/έτος) και επιστρέφει ένα ραντεβού που έχει μετατεθεί.

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

Αν το αρχικό ραντεβού ήταν για Δευτέρα έως Πέμπτη, μετάθεσέ το στην Παρασκευή _αυτής_ της εβδομάδας.
Για ραντεβού Παρασκευής ή Σαββάτου, μετάθεσέ το στην Παρασκευή της _επόμενης_ εβδομάδας.
