# Εγκατάσταση

Ανατρέξε στο [System/Installation][install-link] για οδηγίες σχετικά με το πώς να ρυθμίσεις τα πάντα στο σύστημά σου.

~~~exercism/caution
Αν έχεις εγκατεστημένο το Java Development Kit (JDK), το εκτελέσιμο `jconsole` μπορεί ενδεχομένως να συγκρουστεί με την Java Console, η οποία χρησιμοποιεί το ίδιο όνομα.

Οι πιθανές λύσεις περιλαμβάνουν:

- Μετονόμασε το εκτελέσιμο `jconsole` της γλώσσας προγραμματισμού J σε κάτι μοναδικό (π.χ. `jconsole-jlang`).

- Προσάρμοσε τις μεταβλητές περιβάλλοντος του συστήματός σου ή το PATH ώστε να δώσεις προτεραιότητα στο `jconsole` της γλώσσας προγραμματισμού J.

- **Για χρήστες Linux**, υπάρχει ένα bash script στο `bin/install.sh` που θα δημιουργήσει έναν **συμβολικό σύνδεσμο** με το όνομα `ijconsole` στον κατάλογο `/usr/`. Μπορείς να χρησιμοποιήσεις αυτόν τον σύνδεσμο πληκτρολογώντας `ijconsole` στο τερματικό σου.
~~~

Αφού εγκατασταθεί η J, άνοιξε μια κονσόλα J στο τερματικό σου και πληκτρολόγησε τις παρακάτω εντολές για να εγκαταστήσεις το unit test framework:

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
