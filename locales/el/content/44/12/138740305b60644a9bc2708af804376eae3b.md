# Εισαγωγή

Η δημιουργία ενός στιγμιότυπου μιας κλάσης γίνεται καλώντας τον [_κατασκευαστή_][constructor] της μέσω του τελεστή `new`. Ένας κατασκευαστής είναι μια ειδική μέθοδος μέσα σε μια κλάση που σκοπός της είναι να αρχικοποιήσει την κλάση. Στη Haxe, η μέθοδος κατασκευαστή έχει το όνομα `new()`.

```haxe
class Library {
  private var books:Int;

  public function new() {
    this.books = 10; // Initialize the books field
  }
}

var library = new Library(); // This calls the constructor
```

Όπως ακριβώς οι κανονικές μέθοδοι, οι κατασκευαστές μπορούν να έχουν παραμέτρους. Αυτές οι παράμετροι (συνήθως) αποθηκεύονται σε ιδιωτικά πεδία και προσπελαύνονται αργότερα.

```haxe
class Building {
  private var numberOfStories:Int;
  private var totalHeight: Float;

  public function new(numberOfStories:Int, storyHeight:Float) {
    this.numberOfStories = numberOfStories;
    this.totalHeight = storyHeight * numberOfStories;
  }
}

var largeBuilding = new Building(55, 6.2);
```

**Δεν** μπορείς να δημιουργήσεις ένα νέο στιγμιότυπο μιας κλάσης αν δεν έχει κατασκευαστή. Επομένως, η χρήση ενός κενού κατασκευαστή είναι ο μόνος τρόπος.

```haxe
class Car {
  public var weight:Int = 1000;

  public function new() {}
}

var myCar = new Car();
```
