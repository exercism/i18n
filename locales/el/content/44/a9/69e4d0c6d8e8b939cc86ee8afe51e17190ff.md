# Σχετικά

Οι κλάσεις είναι ένα βασικό δομικό στοιχείο του προγραμματισμού σε Swift. Παρέχουν έναν τρόπο να ομαδοποιείς σχετικά δεδομένα και συναρτήσεις σε αυτοτελείς μονάδες λειτουργικότητας.

### Ορισμός κλάσεων

Για να ορίσεις μια κλάση, ξεκίνα με τη λέξη-κλειδί `class`, ακολουθούμενη από το όνομα του τύπου που ορίζεις, και ύστερα ακολουθεί το σώμα της κλάσης, μέσα σε άγκιστρα.

Το σώμα μπορεί να αποτελείται από αποθηκευμένες ιδιότητες, οι οποίες ορίζονται και συμπεριφέρονται ακριβώς όπως οι συνηθισμένες σταθερές ή μεταβλητές.

```swift
class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Στιγμιότυπα

Όπως σημειώθηκε παραπάνω, ο ορισμός μιας κλάσης είναι απλώς ο ορισμός ενός νέου _τύπου_. Είναι μόνο το προσχέδιο για το πώς θα μοιάζουν οι τιμές αυτού του τύπου, αλλά δεν δημιουργεί στην πραγματικότητα καμία τιμή αυτού του τύπου για να δουλέψεις μαζί της.

Για να δημιουργήσεις ένα _στιγμιότυπο_ αυτού του τύπου, πρέπει να γράψεις το όνομα του τύπου ακολουθούμενο από ένα ζεύγος παρενθέσεων.

```swift
let someCharacter = GameCharacter()
```

Αυτό θα δημιουργήσει τιμές αυτών των τύπων, όπου οι ιδιότητες συμπληρώνονται με τις προεπιλεγμένες τιμές που δίνονται στον ορισμό. Σημείωσε ότι σε προαιρετικές περιπτώσεις όπως η ιδιότητα `name` του GameCharacter, αν δεν δοθεί κάποια τιμή, η ιδιότητα παίρνει ως προεπιλογή την τιμή nil, ακριβώς όπως όταν ορίζεις συνηθισμένους προαιρετικούς τύπους όπου δεν παρέχεται αμέσως κάποια τιμή.

### Πρόσβαση στις ιδιότητες

Οι ιδιότητες μιας κλάσης είναι προσβάσιμες με _σημειογραφία με τελεία_, όπου μετά το όνομα της τιμής ακολουθεί μια τελεία (`.`) και το όνομα της ιδιότητας. Αν μια ιδιότητα μιας κλάσης έχει δικές της ιδιότητες, αυτή η σημειογραφία μπορεί να χρησιμοποιηθεί και για την πρόσβαση σε αυτές τις εμφωλευμένες ιδιότητες.

Αυτή η σημειογραφία μπορεί να χρησιμοποιηθεί τόσο για να ανακτήσεις την τιμή της ιδιότητας όσο και, όπου επιτρέπεται, για να την αλλάξεις.

```swift
someCharacter.name
// => nil
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Μέθοδοι

Όπως οι ιδιότητες, που αποθηκεύουν δεδομένα στις κλάσεις σου, μπορείς επίσης να ορίσεις _μεθόδους_, που αποθηκεύουν συναρτήσεις στην κλάση σου.

Οι μέθοδοι ορίζονται με τον ίδιο τρόπο όπως μια συνηθισμένη συνάρτηση, μόνο που βρίσκονται μέσα στο σώμα της κλάσης. Επιπλέον, αν μια ιδιότητα μπορεί να αλλάξει από μια μέθοδο, αυτή η ιδιότητα πρέπει να οριστεί με `var` και όχι με `let`, ακριβώς όπως οι συνηθισμένες μεταβλητές.

```swift

class GameCharacter {
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    if damage > 100 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
}
```

Αυτές οι μέθοδοι μπορούν να κληθούν με σημειογραφία με τελεία, ακριβώς όπως οι ιδιότητες.

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

Κάθε στιγμιότυπο κλάσης έχει μια έμμεση τιμή με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο. Υπάρχουν πολλές χρήσεις του `self`, αλλά συνήθως χρησιμοποιείται για να ξεκαθαρίζει τα ονόματα των ιδιοτήτων και των μεθόδων της κλάσης/struct όταν μπορεί να υπάρχει κάποια σύγχυση.
