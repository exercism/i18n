# Δεσμευμένες ρουτίνες

```sather
   part : ROUT{STR}:STR := bind(shout(_));
   part.call("who's there");
```

## bind

Το `bind` παίρνει μια κλήση στην οποία οποιοδήποτε μέρος μπορεί να αντικατασταθεί από `_`. Ό,τι δεν είναι `_` υπολογίζεται **τώρα** και διατηρείται· κάθε `_` γίνεται όρισμα της δεσμευμένης ρουτίνας, με τη σειρά που είναι γραμμένο.

```sather
   bind(repeat(2, _))         -- ROUT{STR}:STR
   bind(repeat(_, "Ha"))      -- ROUT{INT}:STR
   bind(repeat(_, _))         -- ROUT{INT,STR}:STR
```

## Οι τύποι

| Τύπος | Παίρνει | Απαντά |
| --- | --- | --- |
| `ROUT:INT` | τίποτα | `INT` |
| `ROUT{STR}` | ένα `STR` | τίποτα |
| `ROUT{STR}:STR` | ένα `STR` | ένα `STR` |
| `ROUT{INT,INT}:BOOL` | δύο `INT` | `BOOL` |

Το `ITER{...}` είναι η ίδια ιδέα για έναν iterator.

## call

Το `call` παρέχει τα υπόλοιπα ορίσματα. Μια δεσμευμένη ρουτίνα που δεν απαντά τίποτα καλείται με τον ίδιο τρόπο, ως εντολή.

## bind goes on the right of an assignment

Ένα `bind` μπορεί να δηλωθεί σε μια μεταβλητή ή να περαστεί ως όρισμα:

```sather
   part ::= bind(shout(_));                -- yes
   part : ROUT{STR}:STR := bind(shout(_)); -- yes
   rehearse("line", bind(shout(_)));       -- yes
```

αλλά δεν μπορεί να μπει κατευθείαν σε ένα `return`:

```sather
   return bind(shout(_));                  -- does not parse
```

Βάλε το σε μια μεταβλητή και επίστρεψε εκείνη. Το μήνυμα σφάλματος δείχνει το `bind` και αναφέρει κάτω παύλες, κάτι που δεν είναι προφανές από την ίδια τη γραμμή.

## Πού χρησιμοποιούνται

Η βιβλιοθήκη τις δέχεται όπου πρέπει να παρασχεθεί συμπεριφορά:

```sather
   names.sort_by(bind(shorter(_, _)));
   scores.count_if(bind(over(10, _)));
   scores.find_if(bind(is_even(_)));
```

Η ταξινόμηση είναι η πιο ξεκάθαρη περίπτωση: το `sort_by` ξέρει πώς να ταξινομεί και τίποτα για τη δική σου ιδέα της σειράς, και η δεσμευμένη ρουτίνα είναι το σημείο όπου τα δύο συναντιούνται.

## Ένας περιορισμός σε αυτόν τον μεταγλωττιστή

Το Sather 1.2 δεν υλοποιεί **dispatched** δεσμευμένες ρουτίνες, δηλαδή δέσμευση μιας ρουτίνας σε μια μεταβλητή αφηρημένου τύπου. Ο μεταγλωττιστής το λέει ξεκάθαρα:

```
Dispatched bound routines are not implemented yet
```

Κάνε bind σε έναν συγκεκριμένο τύπο ή σε μια κλάση και όλα καλά. Γι' αυτό ο ίδιος ο μηχανισμός δοκιμών της διαδρομής γράφει τους ελέγχους εξαιρέσεών του με το χέρι αντί να παίρνει μια δεσμευμένη ρουτίνα.

## Δεσμευμένες ρουτίνες ή αφηρημένες κλάσεις;

Και τα δύο επιτρέπουν σε αυτόν που καλεί να δώσει συμπεριφορά.

Μια δεσμευμένη ρουτίνα είναι μία ρουτίνα, δεν χρειάζεται κλάση και γράφεται εκεί όπου χρησιμοποιείται. Μια αφηρημένη κλάση κουβαλά αρκετές ρουτίνες και κάποια κατάσταση, και αξίζει όλη αυτή τη διαδικασία όταν αυτό που παρέχεται έχει πάνω από ένα κομμάτια.

Μία ρουτίνα να παραδώσεις: κάνε bind. Έναν συνεργάτη με αρκετές ρουτίνες: γράψε μια κλάση.
