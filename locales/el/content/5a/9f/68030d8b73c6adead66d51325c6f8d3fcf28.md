# Εισαγωγή

## Ξεκινώντας

### Μεταβλητές

Οι τιμές μπορούν να συνδεθούν με ονόματα ορίζοντας μια [μεταβλητή][constants-variables] και εκχωρώντας μια τιμή σε αυτή τη μεταβλητή.
Αυτό το όνομα μπορεί στη συνέχεια να χρησιμοποιηθεί για να αναφέρεται σε αυτή την τιμή σε όλο το πρόγραμμα.
Οι μεταβλητές είναι _μεταβλητές_, που σημαίνει ότι η τιμή τους μπορεί να αλλάξει οποιαδήποτε στιγμή.

Οι μεταβλητές ορίζονται με τη λέξη-κλειδί `var`.

```swift
var variableName = 10
```

Η Swift είναι μια γλώσσα ασφαλής ως προς τους τύπους και στατικά τυποποιημένη, που σημαίνει ότι όλες οι τιμές έχουν έναν τύπο σε χρόνο μεταγλώττισης.
Μπορείς είτε να καθορίσεις ρητά τον τύπο μιας μεταβλητής με [σχολιασμούς τύπου][type annotations] είτε να αφήσεις τον μεταγλωττιστή να [συμπεράνει τον τύπο][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Η ενημέρωση της τιμής μιας μεταβλητής γίνεται με τον τελεστή `=`.

~~~~exercism/note
Ο τύπος μιας μεταβλητής είναι σταθερός από τη στιγμή που θα οριστεί αρχικά.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Οι μεταβλητές μπορούν να δηλωθούν χωρίς να εκχωρηθεί κάποια τιμή, καθορίζοντας το όνομα και τον τύπο, αλλά δεν μπορούν να χρησιμοποιηθούν πριν τους εκχωρηθεί μια τιμή.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Σταθερές

Οι [σταθερές][constants-variables] μοιάζουν με τις μεταβλητές στο ότι συνδέονται με ένα όνομα και μια τιμή, αλλά η τιμή μιας σταθεράς δεν μπορεί να αλλάξει μόλις της εκχωρηθεί αρχικά και είναι επομένως _αμετάβλητη_.
Οι σταθερές ορίζονται με τη λέξη-κλειδί `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Πρόσθεση & Αφαίρεση & Πολλαπλασιασμός

Η Swift έχει [τελεστές][arithmetical-operators] για πρόσθεση, αφαίρεση και πολλαπλασιασμό.
Οι τελεστές είναι `+`, `-` και `*` αντίστοιχα.
  
```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Συναρτήσεις

Στη Swift, οι [συναρτήσεις][functions] είναι ένα κομμάτι κώδικα που επιτελεί μια εργασία.
Μια συνάρτηση έχει τύπο επιστροφής και έτσι μπορεί να χρησιμοποιηθεί ως τιμή και να περαστεί ως όρισμα σε άλλες συναρτήσεις.
Στη Swift, οι συναρτήσεις ορίζονται με τη λέξη-κλειδί `func` ακολουθούμενη από το όνομα της συνάρτησης, τα ορίσματα χωρισμένα με κόμματα και έναν τύπο επιστροφής.

Τα ορίσματα ορίζονται από μια ετικέτα ορίσματος, ένα όνομα παραμέτρου ακολουθούμενο από άνω και κάτω τελεία και έπειτα από έναν τύπο.
Ο τύπος επιστροφής ορίζεται από ένα `->` ακολουθούμενο από τον τύπο της τιμής επιστροφής.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Τα ορίσματα στη Swift είναι λίγο ξεχωριστά σε σύγκριση με άλλες γλώσσες, χρησιμοποιούν [ετικέτες ορίσματος][argument-labels].
Η ετικέτα ορίσματος χρησιμοποιείται κατά την κλήση της συνάρτησης.
Το όνομα παραμέτρου χρησιμοποιείται μέσα στο σώμα της συνάρτησης για να αναφέρεται στην τιμή του ορίσματος.
Αν δώσεις μόνο ένα όνομα στο όρισμα, θα χρησιμοποιηθεί και ως ετικέτα ορίσματος και ως όνομα παραμέτρου.
Όταν ορίσεις το όνομα της ετικέτας ορίσματος ως `_`, το όρισμα δεν θα έχει ετικέτα κατά την κλήση της συνάρτησης, π.χ.: `functionName(argumentValue)`

Για να καλέσεις μια συνάρτηση, χρησιμοποιείς το όνομα της συνάρτησης ακολουθούμενο από την ετικέτα ορίσματος και την τιμή του ορίσματος, όπως εδώ:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Όλα τα ορίσματα είναι αμετάβλητα από προεπιλογή και δεν μπορούν να αλλάξουν μέσα στη συνάρτηση.
Όταν μια συνάρτηση έχει τύπο επιστροφής, φρόντισε να επιστρέψεις μια τιμή αυτού του τύπου.
Αυτό γίνεται με τη λέξη-κλειδί `return` ακολουθούμενη από την τιμή που θα επιστρέψεις.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Όταν οι συναρτήσεις δεν επιστρέφουν κάποια τιμή, έχουν τύπο επιστροφής `Void`, που είναι το ίδιο με `()`, αλλά σε αυτές τις περιπτώσεις ο τύπος επιστροφής μπορεί να παραλειφθεί.

### Σχόλια

Η Swift υποστηρίζει δύο τύπους [σχολίων][comments].
Τα σχόλια μίας γραμμής προηγούνται από `//` και τα σχόλια πολλών γραμμών εισάγονται μεταξύ `/*` και `*/`.
