# Προσθήκη στις οδηγίες

## Ταυτοχρονισμός εναντίον παραλληλισμού

Η Go υποστηρίζει ταυτοχρονισμό μέσω "[goroutines](https://golangbot.com/goroutines/)", οι οποίες ξεκινούν με τη λέξη-κλειδί `go`.
Είναι ένας απλός, ελαφρύς και κομψός τρόπος να παρέχεις υποστήριξη ταυτοχρονισμού και αποτελεί ένα από τα μεγαλύτερα πλεονεκτήματα της γλώσσας.

Ίσως παρατηρήσεις ότι ενώ αυτή η άσκηση ονομάζεται _Parallel_ letter frequency, ο όρος "Parallel" δεν χρησιμοποιείται πολύ συχνά στη Go.
Οι Gophers προτιμούν τον όρο **Concurrent** για να περιγράψουν τη διαχείριση πολλαπλών ανεξάρτητων goroutines ("διεργασίες" ή "νήματα" σε άλλα πλαίσια γλωσσών).
Αν και αυτοί οι όροι χρησιμοποιούνται συχνά εναλλακτικά, οι Gophers θέλουν να είναι τεχνικά ακριβείς και χρησιμοποιούν το "concurrent" όταν συζητούν τις φαινομενικά ταυτόχρονες εκτελέσεις των goroutines.

Αν και μπορούμε να σχεδιάσουμε τα προγράμματά μας ώστε να τρέχουν παράλληλα, και κάποιες φορές μπορεί να φαίνεται ότι τρέχουν παράλληλα, χωρίς ακριβή γνώση του περιβάλλοντος εκτέλεσης του κώδικά μας το μόνο που μπορούμε να εγγυηθούμε είναι ότι οι διεργασίες θα εκτελούνται ταυτόχρονα.
Με άλλα λόγια, μπορεί να εκτελούνται σειριακά πιο γρήγορα απ' ό,τι μπορούμε να ξεχωρίσουμε, αλλά όχι αυστηρά ταυτόχρονα.

Για περισσότερα, ρίξε μια ματιά στην ανάρτηση του The Go Blog: [Concurrency is not parallelism](https://blog.golang.org/concurrency-is-not-parallelism).

## Πόροι για τον ταυτοχρονισμό

Αν είσαι καινούριος στις δυνατότητες ταυτοχρονισμού της Go, ορίστε μερικοί πόροι για να ξεκινήσεις.
Σου προτείνουμε να ρίξεις μια ματιά σε αυτά πριν ξεκινήσεις αυτή την άσκηση:

- [Concurrency in the Golang Book](https://www.golang-book.com/books/intro/10)
- [A Tour of Go's concurrency section](https://tour.golang.org/concurrency/1)
- [DigitalOcean Golang Tutorial: How To Run Multiple Functions Concurrently in Go](https://www.digitalocean.com/community/tutorials/how-to-run-multiple-functions-concurrently-in-go)
- [Synchronizing Go Routines with Channels and WaitGroups](https://dev.to/sophiedebenedetto/synchronizing-go-routines-with-channels-and-waitgroups-3ke2)
- [Buffered Channels and Worker Pools](https://golangbot.com/buffered-channels-worker-pools/)

Αν θέλεις να εμβαθύνεις πραγματικά, μπορείς να δοκιμάσεις το βιβλίο [Concurrency in Go](http://shop.oreilly.com/product/0636920046189.do) του [@kat-co](https://github.com/kat-co).

## Δοκιμές

Σε αυτή την άσκηση, τα unit tests δεν μπορούν να κρίνουν αν έγραψες μια καλή ταυτόχρονη λύση.
Αντ' αυτού, το καλύτερο είναι να λύσεις αυτή την άσκηση [τοπικά][cli] και να τρέξεις τα benchmarks με `go test -bench .`.
Σε μια καλή λύση, θα πρέπει να δεις ότι η ταυτόχρονη εκδοχή εμφανίζει μικρότερο αριθμό νανοδευτερολέπτων ανά πράξη (`ns/op`) από τη σειριακή εκδοχή.

[cli]: https://exercism.org/docs/using/solving-exercises/working-locally
