# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων. Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (εκτός λειτουργίας) έως `10` (μέγιστη).

Στη χαμηλότερη ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα την ώρα. Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα. Έτσι, με την ταχύτητα στο `4`, θα πρέπει να παράγει `4 * 221 = 884` αυτοκίνητα την ώρα. Ωστόσο, οι μεγαλύτερες ταχύτητες αυξάνουν την πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία μετά πρέπει να απορριφθούν. Ο παρακάτω πίνακας δείχνει πώς η ταχύτητα επηρεάζει το ποσοστό επιτυχίας:

- `1` έως `4`: ποσοστό επιτυχίας 100%.
- `5` έως `8`: ποσοστό επιτυχίας 90%.
- `9`: ποσοστό επιτυχίας 80%.
- `10`: ποσοστό επιτυχίας 77%.

Έχεις δύο εργασίες.

## 1. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Υλοποίησε τη μέθοδο `CarsAssemble.productionRatePerHour()` για να υπολογίσεις τον ρυθμό παραγωγής ανά ώρα της γραμμής συναρμολόγησης, λαμβάνοντας υπόψη την τρέχουσα ταχύτητα της γραμμής συναρμολόγησης και το ποσοστό επιτυχίας της:

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `double`.

## 2. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται το λεπτό

Υλοποίησε τη μέθοδο `CarsAssemble.workingItemsPerMinute()` για να υπολογίσεις πόσα λειτουργικά αυτοκίνητα παράγονται το λεπτό:

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `int`.
