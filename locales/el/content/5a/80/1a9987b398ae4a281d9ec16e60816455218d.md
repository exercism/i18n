# Εισαγωγή

Η Elixir υποστηρίζει πολλές συναρτήσεις για χειρισμό bit, που βρίσκονται στο _άρθρωμα Bitwise_.

- `band/2`: bitwise AND
- `bsl/2`: bitwise ολίσθηση αριστερά
- `bsr/2`: bitwise ολίσθηση δεξιά
- `bxor/2`: bitwise XOR
- `bor/2`: bitwise OR
- `bnot/1`: bitwise NOT

Ακολουθεί ένα παράδειγμα χρήσης μιας bitwise συνάρτησης:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Όλες οι bitwise συναρτήσεις λειτουργούν μόνο με ακέραιους.

Αν τρέχεις την έκδοση Elixir 1.9 ή παλιότερη, θα χρειαστεί να καλέσεις το `require Bitwise` στην αρχή του ορισμού του αρθρώματος για να μπορείς να χρησιμοποιήσεις το άρθρωμα _Bitwise_.
