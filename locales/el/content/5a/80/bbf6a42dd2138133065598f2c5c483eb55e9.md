# Σχετικά

Οι συναρτήσεις για την εργασία με αρχεία παρέχονται από τη μονάδα [`File`][file].

Για να διαβάσεις ένα ολόκληρο αρχείο, χρησιμοποίησε τη συνάρτηση [`File.read/1`][file-read]. Για να γράψεις σε ένα αρχείο, χρησιμοποίησε τη συνάρτηση [`File.write/2`][file-write].

Η μονάδα παρέχει επίσης συναρτήσεις για αντιγραφή, διαγραφή, μετονομασία κ.λπ. Τα ονόματά τους μοιάζουν με τα αντίστοιχα UNIX, για παράδειγμα:

- [`File.cp/3`][file-cp] - αντιγράφει ένα αρχείο.
- [`File.rm/1`][file-rm] - διαγράφει ένα αρχείο.
- [`File.rename/2`][file-rename] - μετονομάζει ή/και μετακινεί ένα αρχείο.
- [`File.mkdir/1`][file-mkdir] - δημιουργεί έναν κατάλογο.
- [`File.cwd/0`][file-cwd] - επιστρέφει τον τρέχοντα κατάλογο εργασίας.

Όλες οι παραπάνω συναρτήσεις της μονάδας `File` έχουν και μια παραλλαγή με `!`, η οποία πετάει ένα σφάλμα αντί να επιστρέψει μια πλειάδα σφάλματος (π.χ. [`File.read!/1`][file-read-bang]). Χρησιμοποίησε αυτή την παραλλαγή αν δεν σκοπεύεις να χειριστείς σφάλματα, όπως αρχεία που λείπουν ή έλλειψη δικαιωμάτων.

```elixir
File.read("does_not_exist")
# => {:error, :enoent}

File.read!("does_not_exist")
# => ** (File.Error) could not read file "does_not_exist": no such file or directory
#        (elixir 1.10.4) lib/file.ex:353: File.read!/1
```

## Αρχεία και διεργασίες

Κάθε φορά που γράφεις σε ένα αρχείο με τη συνάρτηση [`File.write/2`][file-write], ανοίγει ένας περιγραφέας αρχείου και δημιουργείται μια νέα [διεργασία][exercism-processes] της Elixir. Για αυτό τον λόγο, καλό είναι να αποφεύγεις το γράψιμο σε αρχείο μέσα σε βρόχο με τη συνάρτηση [`File.write/2`][file-write].

Αντ' αυτού, μπορείς να ανοίξεις ένα αρχείο με τη συνάρτηση [`File.open/2`][file-open]. Το δεύτερο όρισμα της [`File.open/2`][file-open] είναι μια λίστα με τρόπους λειτουργίας, που σου επιτρέπει να ορίσεις αν θέλεις να ανοίξεις το αρχείο για ανάγνωση ή για εγγραφή.

Οι πιο συνηθισμένοι τρόποι λειτουργίας είναι:

- `:read` - άνοιγμα για ανάγνωση, το αρχείο πρέπει να υπάρχει
- `:write` - άνοιγμα για εγγραφή, το αρχείο θα δημιουργηθεί αν δεν υπάρχει, το υπάρχον περιεχόμενο θα αντικατασταθεί
- `:append` - άνοιγμα για εγγραφή, το αρχείο θα δημιουργηθεί αν δεν υπάρχει, το υπάρχον περιεχόμενο θα διατηρηθεί

Για μια πλήρη λίστα όλων των τρόπων λειτουργίας, δες την τεκμηρίωση της [`File.open/2`][file-open].

Η [`File.open/2`][file-open] επιστρέφει το PID μιας διεργασίας που χειρίζεται το αρχείο. Για να διαβάσεις και να γράψεις στο αρχείο, χρησιμοποίησε συναρτήσεις της μονάδας [`IO`][io] και πέρασε αυτό το PID ως [συσκευή IO][io-io-devices].

Όταν τελειώσεις με το αρχείο, κλείσε το με τη συνάρτηση [`File.close/1`][file-close].

```elixir
file = File.open!("README.txt", [:write])
# => #PID<0.157.0>

IO.puts(file, "# README")
# => :ok

File.close(file)
# => :ok
```

## Ροή αρχείων

Το διάβασμα ενός αρχείου με τη συνάρτηση [`File.read/1`][file-read] θα φορτώσει ολόκληρο το αρχείο στη μνήμη μεμιάς. Αυτό μπορεί να είναι πρόβλημα όταν δουλεύεις με πολύ μεγάλα αρχεία. Για να τα χειριστείς αποδοτικά, μπορείς να χρησιμοποιήσεις τη συνάρτηση [`File.open/2`][file-open] και τη συνάρτηση [`IO.read/2`][io-read] για να διαβάσεις το αρχείο γραμμή προς γραμμή, ή μπορείς να κάνεις ροή του αρχείου με τη συνάρτηση [`File.stream/3`][file-stream]. Η ροή υλοποιεί και τα δύο πρωτόκολλα, [`Enumerable`][enumerable] και [`Collectable`][collectable], που σημαίνει ότι μπορεί να χρησιμοποιηθεί τόσο για ανάγνωση όσο και για εγγραφή.

```elixir
File.stream!("file.txt")
|> Stream.map(&(&1 <> "!"))
|> Stream.into(File.stream!("new_file.txt"))
|> Stream.run()
```

## Διαδρομές

Όλες οι συναρτήσεις που δουλεύουν με αρχεία απαιτούν μια διαδρομή αρχείου. Οι διαδρομές αρχείων μπορεί να είναι απόλυτες ή σχετικές ως προς τον τρέχοντα κατάλογο. Για τον χειρισμό διαδρομών, χρησιμοποίησε συναρτήσεις της μονάδας [`Path`][path]. Για συμβατότητα μεταξύ πλατφορμών, χρησιμοποίησε τη συνάρτηση [`Path.join/1`][path-join] για να δημιουργήσεις διαδρομές. Θα επιλέξει το διαχωριστικό που ταιριάζει στην πλατφόρμα.

```elixir
Path.expand(Path.join(["~", "documents", "important.txt"]))
"/home/user/documents/important.txt"
```
