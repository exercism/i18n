# Εισαγωγή

Η τάξη του νηπιαγωγείου μαθαίνει για την καλλιέργεια φυτών.
Η νηπιαγωγός σκέφτηκε ότι θα ήταν καλή ιδέα να δώσει στην τάξη σπόρους για να φυτέψουν και να μεγαλώσουν στο χώμα.
Για τον σκοπό αυτό, τα παιδιά έβαλαν μικρά ποτηράκια κατά μήκος των περβαζιών και φύτεψαν ένα είδος φυτού σε κάθε ποτηράκι.
Τα παιδιά είχαν την ευκαιρία να διαλέξουν τα αγαπημένα τους από τέσσερα διαθέσιμα είδη σπόρων: grass, clover, radishes και violets.
