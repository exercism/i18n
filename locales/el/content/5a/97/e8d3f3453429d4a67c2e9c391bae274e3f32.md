# Ειδικές οδηγίες για SQLite

* Η στήλη **digits** περιέχει μια λίστα ακεραίων κωδικοποιημένη σε JSON.
  Παράδειγμα:
  ```json
  [1,0,1,0,1,0]
  ```
* Η στήλη **result** πρέπει να περιέχει δεδομένα κωδικοποιημένα σε JSON: ένα αντικείμενο με τα ψηφία ως ακέραιους ή μια περιγραφή τυχόν σφαλμάτων.
  Παραδείγματα:
  ```json
  {"digits":[1,0,1,0,1,0]}
  ```
  ή
  ```json
  {"error":"some error description"}
  ```

## Σχήμα πίνακα

```sql
CREATE TABLE IF NOT EXISTS "all-your-base" (
  input_base  INTEGER NOT NULL,
  digits      TEXT    NOT NULL, -- json array
  output_base INTEGER NOT NULL,
  result      TEXT              -- json object
);
```
