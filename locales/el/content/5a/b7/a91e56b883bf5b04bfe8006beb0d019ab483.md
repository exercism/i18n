# Εισαγωγή

## Booleans (λογικές τιμές) στη R

Οι αληθείς ή ψευδείς τιμές αναπαρίστανται από τον τύπο `logical`.
Περιέχει μόνο δύο τιμές: `TRUE` και `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Τελεστές Boolean

Υπάρχουν πέντε τελεστές Boolean στη R, αλλά μόνο τρεις είναι σχετικοί σε αυτό το στάδιο του προγράμματος σπουδών.
Οι άλλοι δύο θα είναι σημαντικοί όταν δουλεύεις με διανύσματα, που καλύπτονται σε αρκετές επόμενες έννοιες.

Το `&&` είναι Boolean "και".
Αξιολογείται σε `TRUE` αν οι εκφράσεις και στις *δύο* πλευρές του `&&` είναι `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

Το `||` είναι Boolean "ή".
Αξιολογείται σε `TRUE` αν μια έκφραση σε *μία* από τις δύο πλευρές του `||` είναι `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

Το `!` είναι Boolean "όχι".
Αντιστρέφει τις τιμές `TRUE` και `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Για μεγαλύτερες και πιο περίπλοκες εκφράσεις, είναι καλύτερο να χρησιμοποιείς παρενθέσεις για να κάνεις την πρόθεσή σου σαφή.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
