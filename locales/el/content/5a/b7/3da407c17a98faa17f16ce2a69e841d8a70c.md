# Char

Το `Char` είναι ένας τύπος δεδομένων στη Crystal που αναπαριστά ένα σημείο κώδικα [Unicode][unicode] 32 bit.
Το μέγεθός τους τα κάνει αποδοτικά στη μνήμη και τους δίνει ειδικές ιδιότητες που δεν έχουν οι συμβολοσειρές.
Δημιουργούνται με μονά εισαγωγικά (`'`) και επιτρέπουν να τοποθετηθεί μέσα τους μόνο ένα σημείο κώδικα Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Είναι αρκετά συνηθισμένο να δουλεύεις με Char όταν δουλεύεις με συμβολοσειρές στη Crystal, αφού αρκετές μέθοδοι στην κλάση String επιστρέφουν Char ή δέχονται Char ως ορίσματα.
Για παράδειγμα, η μέθοδος [`String#[]`][index] επιστρέφει ένα Char ή η μέθοδος [`String#chars`][chars] επιστρέφει μια συλλογή από Char.

## Αύξηση / Μείωση

Επειδή το Char είναι σημείο Unicode 32 bit, υποστηρίζει αύξηση και μείωση· έτσι, αν έχεις το `'a'`, μπορείς να πάρεις το `'b'` προσθέτοντας ένα.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

Υπάρχει επίσης μια μέθοδος που ονομάζεται [`Char#succ`][succ], η οποία επιστρέφει το επόμενο Char στον πίνακα Unicode, και η [`Char#pred`][pred], η οποία επιστρέφει το προηγούμενο Char στον πίνακα Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Συνένωση

Επειδή τα Char προορίζονται να αναπαριστούν μόνο ένα σημείο Unicode 32 bit, δύο Char δεν μπορούν να συνενωθούν.
Επομένως, τα Char μπορούν να συνενωθούν μόνο με συμβολοσειρές.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Μέθοδοι ιδιοτήτων

Η Crystal έχει μερικές μεθόδους για να παίρνεις πληροφορίες για έναν χαρακτήρα, όπως αν είναι αριθμός ή γράμμα ή αν είναι κεφαλαίος ή πεζός.
Ακολουθεί μια λίστα με μερικές από τις μεθόδους, για την πλήρη λίστα δες το [API του Char][char-api]:

| Μέθοδος                          | Περιγραφή                                            |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Επιστρέφει `true` αν το Char είναι αριθμός           |
| [`Char#letter?`][letter]         | Επιστρέφει `true` αν το Char είναι γράμμα            |
| [`Char#lowercase?`][lowercase]   | Επιστρέφει `true` αν το Char είναι πεζό              |
| [`Char#uppercase?`][uppercase]   | Επιστρέφει `true` αν το Char είναι κεφαλαίο          |
| [`Char#ascii?`][ascii]           | Επιστρέφει `true` αν το Char είναι χαρακτήρας ASCII  |
| [`Char#whitespace?`][whitespace] | Επιστρέφει `true` αν το Char είναι χαρακτήρας κενού διαστήματος |

## Μετατροπή

### Μετατροπή μεταξύ σημείων κώδικα και Char

Επειδή τα Char είναι σημείο κώδικα Unicode 32 bit, μπορείς να μετατρέψεις μεταξύ Char και σημείων κώδικα (Int).
Αυτό μπορεί να γίνει με τη μέθοδο [`Char#ord`][ord], η οποία επιστρέφει το σημείο κώδικα του Char, ή με τη μέθοδο [`Int#chr`][chr], η οποία επιστρέφει το Char του σημείου κώδικα.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Μετατροπή μεταξύ τύπων

Όπως και με τους άλλους τύπους δεδομένων, τα Char έχουν μερικές μεθόδους για μετατροπή μεταξύ τύπων.
Η πιο συνηθισμένη είναι η μέθοδος `Char#to_s`, η οποία μετατρέπει το Char σε String. Ωστόσο, υπάρχει και η μέθοδος `Char#to_i`, η οποία μετατρέπει το Char σε Int, και η μέθοδος `Char#to_f`, η οποία μετατρέπει το Char σε Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Διαφυγή

Όπως και με τις συμβολοσειρές, υπάρχουν κάποιοι χαρακτήρες που δεν μπορούν να γραφτούν απευθείας, και για να τους γράψεις χρειάζεται να χρησιμοποιήσεις διαφυγή.
Μπορείς να χρησιμοποιήσεις τον χαρακτήρα `\` για να γράψεις μια ακολουθία διαφυγής, ακολουθούμενη από τον χαρακτήρα που θέλεις να γράψεις με διαφυγή.

Αυτοί είναι οι ειδικοί χαρακτήρες στη Crystal:

| Τιμή    | Περιγραφή                     |
| -------- | ----------------------------- |
| `\a`     | Συναγερμός                    |
| `\b`     | Οπισθοχώρηση                  |
| `\e`     | Διαφυγή                       |
| `\f`     | Αλλαγή σελίδας                |
| `\n`     | Τροφοδοσία γραμμής ή αλλαγή γραμμής |
| `\r`     | Επιστροφή φορέα               |
| `\t`     | Οριζόντιο tab                 |
| `\v`     | Κατακόρυφο tab                |
| `\\`     | Ανάστροφη κάθετος             |
| `\'`     | Μονό εισαγωγικό               |
| `\"`     | Διπλό εισαγωγικό              |
| `\377`   | Οκταδικός χαρακτήρας ASCII    |
| `\xFF`   | Δεκαεξαδικός χαρακτήρας ASCII |
| `\uFFFF` | Δεκαεξαδικός χαρακτήρας Unicode |
