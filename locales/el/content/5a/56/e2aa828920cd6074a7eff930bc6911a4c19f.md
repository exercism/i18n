# Οδηγίες

Η Μαίρη είναι μεγάλη φαν της τηλεοπτικής σειράς _Star Trek: The Next Generation_. Παίζει συχνά παιχνίδια ρόλων με χαρτί και μολύβι, όπου αυτή και οι φίλοι της υποδύονται το πλήρωμα του _Starship Enterprise_. Ο χαρακτήρας της Μαίρης είναι ο Πλοίαρχος Πικάρ, που σημαίνει ότι πρέπει να κρατάει το ημερολόγιο του πλοιάρχου. Αγαπάει το δημιουργικό κομμάτι του παιχνιδιού, αλλά δεν της αρέσει να βγάζει τυχαία δεδομένα επιτόπου.

Βοήθησε τη Μαίρη φτιάχνοντας γεννήτριες τυχαίων δεδομένων για όσα εμφανίζονται συχνά στο ημερολόγιο του πλοιάρχου.

## 1. Δημιούργησε έναν τυχαίο πλανήτη

Το _Starship Enterprise_ συναντά πολλούς πλανήτες στα ταξίδια του. Οι πλανήτες στο σύμπαν του Star Trek χωρίζονται σε κατηγορίες με βάση τις ιδιότητές τους. Για παράδειγμα, η Γη είναι πλανήτης κλάσης M. Όλες οι πιθανές κλάσεις πλανητών είναι: D, H, J, K, L, M, N, R, T και Y.

Υλοποίησε τη συνάρτηση `random_planet_class/0`. Θα πρέπει να επιστρέφει τυχαία μία από τις κλάσεις πλανητών.

```elixir
CaptainsLog.random_planet_class()
# => "K"
```

## 2. Δημιούργησε έναν τυχαίο αριθμό νηολογίου διαστημοπλοίου

Το Enterprise (αριθμός νηολογίου NCC-1701) δεν είναι το μόνο διαστημόπλοιο που πετάει εκεί έξω! Όταν συναντάει ένα άλλο διαστημόπλοιο, η Μαίρη χρειάζεται να καταγράψει τον αριθμό νηολογίου του.

Οι αριθμοί νηολογίου ξεκινούν με το πρόθεμα "NCC-" και στη συνέχεια χρησιμοποιούν έναν αριθμό από το 1000 έως το 9999 (συμπεριλαμβανομένων).

Υλοποίησε τη συνάρτηση `random_ship_registry_number/0`, που επιστρέφει έναν τυχαίο αριθμό νηολογίου διαστημοπλοίου.

```elixir
CaptainsLog.random_ship_registry_number()
# => "NCC-1947"
```

## 3. Δημιούργησε μια τυχαία αστρική ημερομηνία

Τι νόημα έχει ένα ημερολόγιο αν δεν περιλαμβάνει ημερομηνίες;

Η αστρική ημερομηνία είναι ένας αριθμός κινητής υποδιαστολής. Οι περιπέτειες του _Starship Enterprise_ από την πρώτη σεζόν του _The Next Generation_ διαδραματίζονται μεταξύ των αστρικών ημερομηνιών 41000.0 και 42000.0. Το "4" αντιστοιχεί στον 24ο αιώνα και το "1" στην πρώτη σεζόν.

Υλοποίησε τη συνάρτηση `random_stardate/0`, που επιστρέφει έναν αριθμό κινητής υποδιαστολής μεταξύ 41000.0 (συμπεριλαμβανομένου) και 42000.0 (μη συμπεριλαμβανομένου).

Η υλοποίηση θα πρέπει να χρησιμοποιεί συνάρτηση της Erlang.

```elixir
CaptainsLog.random_stardate()
# => 41458.15721310934
```

## 4. Μορφοποίησε την αστρική ημερομηνία

Στο ημερολόγιο του πλοιάρχου, οι αστρικές ημερομηνίες συνήθως στρογγυλοποιούνται σε ένα δεκαδικό ψηφίο.

Υλοποίησε τη συνάρτηση `format_stardate/1`, που θα παίρνει έναν αριθμό κινητής υποδιαστολής και θα επιστρέφει μια συμβολοσειρά με τον αριθμό στρογγυλοποιημένο σε ένα δεκαδικό ψηφίο.

Η υλοποίηση θα πρέπει να χρησιμοποιεί συνάρτηση της Erlang.

```elixir
CaptainsLog.format_stardate(41458.15721310934)
# => "41458.2"
```
