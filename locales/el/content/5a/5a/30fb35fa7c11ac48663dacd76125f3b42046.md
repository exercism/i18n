# Σχετικά

Οι συναρτήσεις μπορούν να δηλώνουν [προεπιλεγμένες τιμές][default-arguments] για ένα ή περισσότερα ορίσματα.

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- Κατά τη μεταγλώττιση του παραπάνω παραδείγματος, η Elixir δημιουργεί έναν ορισμό συνάρτησης για το `number/0` (χωρίς ορίσματα) και το `number/1` (ένα όρισμα).
- Αν περισσότερα από ένα ορίσματα έχουν προεπιλεγμένες τιμές, οι προεπιλεγμένες τιμές θα εφαρμοστούν στη συνάρτηση από αριστερά προς τα δεξιά για να συμπληρώσουν τα ορίσματα που λείπουν.
- Αν η συνάρτηση έχει πολλαπλές ρήτρες, απαιτείται να γράψεις μια [κεφαλίδα συνάρτησης][function-header] για τα προεπιλεγμένα ορίσματα.
- Οποιαδήποτε έκφραση μπορεί να χρησιμεύσει ως προεπιλεγμένη τιμή.
- Οι ανώνυμες συναρτήσεις δεν μπορούν να έχουν προεπιλεγμένα ορίσματα.

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
