# Εισαγωγή

Ένα μπλοκ είναι ένα σύνολο εντολών και δηλώσεων που ομαδοποιούνται σε μία συντακτική μονάδα.
Τα μπλοκ ορίζονται συχνά, αλλά όχι πάντα, μέσα σε άγκιστρα.
Τα μπλοκ μπορούν να είναι εμφωλευμένα μέσα σε συναρτήσεις και μέσα σε άλλα μπλοκ.

Μια συνάρτηση λειτουργεί κάπως σαν ένα μπλοκ.
Ένα αναγνωριστικό για μια μεταβλητή που ορίζεται σε μια συνάρτηση δεν είναι ορατό έξω από τη συνάρτηση, όπως ακριβώς ένα αναγνωριστικό για μια μεταβλητή που ορίζεται σε ένα μπλοκ δεν είναι ορατό έξω από το μπλοκ.
Δύο μεταβλητές σε δύο συναρτήσεις μπορούν να έχουν το ίδιο όνομα, αφού οι δύο συναρτήσεις δε βλέπουν η μία μέσα στην άλλη, όπως ακριβώς δύο μεταβλητές σε δύο μπλοκ μπορούν να έχουν το ίδιο όνομα, αφού τα δύο μπλοκ δε βλέπουν το ένα μέσα στο άλλο.
Όμως οι συναρτήσεις και τα μπλοκ δεν είναι ταυτόσημα.
Μια συνάρτηση δεν μπορεί να είναι εμφωλευμένη μέσα σε μια άλλη συνάρτηση, αλλά ένα μπλοκ μπορεί να είναι εμφωλευμένο μέσα σε ένα άλλο μπλοκ.

Στο παρακάτω παράδειγμα, το `number` ορίζεται μέσα στη συνάρτηση `main`.
Το `flag` ορίζεται μέσα στο μπλοκ `if`, το οποίο είναι εμφωλευμένο μέσα στη συνάρτηση `main`.
Οι μεταβλητές που ορίζονται μέσα σε ένα μπλοκ είναι έγκυρες μόνο μέσα σε αυτό το μπλοκ.
Έτσι, η προσπάθεια να μεταγλωττιστεί ο κώδικας οδηγεί σε σφάλμα μεταγλώττισης.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

Το μήνυμα σφάλματος μπορεί να είναι μπερδεμένο, καθώς το `flag` _χρησιμοποιείται_ νωρίτερα στη συνάρτηση.
Ωστόσο, το `flag` ορίζεται μέσα σε ένα μπλοκ μέσα στη συνάρτηση.
Το εσωτερικό μπλοκ μπορεί να "δει" τη μεταβλητή `number` στην εξωτερική συνάρτηση, αλλά η εξωτερική συνάρτηση δεν μπορεί να "δει" τη μεταβλητή `flag` που ορίζεται μέσα στο εσωτερικό μπλοκ της.
Μόλις η εκτέλεση βγει από το μπλοκ, η μεταβλητή `flag` καταστρέφεται αυτόματα και δεν είναι πλέον διαθέσιμη στο πρόγραμμα.
Η ίδια η συνάρτηση `main` βλέπει το αναγνωριστικό `flag` για πρώτη φορά στην τελευταία εντολή `printf`.
Αν αφαιρεθεί η τελευταία εντολή `printf`, το πρόγραμμα θα μεταγλωττιστεί και θα εκτυπώσει `1` όταν εκτελεστεί.
Αυτό συμβαίνει επειδή η μεταβλητή `flag` είναι έγκυρη στο μπλοκ που περιέχει την πρώτη εντολή `printf`.

Από το `C99` και μετά, οι εντολές `if`, `for`, `while` και `do` μίας γραμμής θεωρούνται επίσης μπλοκ.
Στο παρακάτω παράδειγμα, αν και το `i` δεν ορίζεται μέσα σε άγκιστρα, υπάρχει μόνο στο μπλοκ που ορίζει η εντολή `for` και δεν είναι ορατό στην εξωτερική συνάρτηση `main`.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Αν αφαιρεθεί η τελευταία εντολή `printf`, το πρόγραμμα θα μεταγλωττιστεί και θα εκτυπώσει `0 2 4 6 8 10 ` όταν εκτελεστεί.
Κάποιες γλώσσες, όπως η Go και η Rust, είναι ρητές ως προς το ότι οι εντολές υπό συνθήκη και οι βρόχοι μίας γραμμής αποτελούν μπλοκ.
Απαιτούν τέτοιες εντολές μίας γραμμής να περικλείονται παρ' όλα αυτά σε άγκιστρα.
