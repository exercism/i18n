## Γενικά

- Για να ορίσεις μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις διπλά εισαγωγικά `"`.
- Για να συνενώσεις συμβολοσειρές, μπορείς να χρησιμοποιήσεις τον τελεστή `+`.
- Μπορείς να χρησιμοποιήσεις το `#{}` για να παρεμβάλεις μια συμβολοσειρά μέσα σε μια άλλη.

## 1. Καλωσόρισε έναν νέο καλεσμένο στο πάρτι

- Μια συμβολοσειρά μπορεί να συνενωθεί με μια άλλη συμβολοσειρά χρησιμοποιώντας τον τελεστή `+`.

## 2. Καλωσόρισε έναν νέο καλεσμένο στο πάρτι που έχει γενέθλια σήμερα

- Για να μετατρέψεις έναν αριθμό σε συμβολοσειρά, μπορείς να χρησιμοποιήσεις τη μέθοδο `to_s`.

## 3. Δώσε οδηγίες

- Για να στρογγυλοποιήσεις έναν αριθμό, μπορείς να χρησιμοποιήσεις τη μέθοδο `round`.
- Για να πάρεις έναν χαρακτήρα από μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τη μέθοδο `[]`, η οποία δέχεται έναν ακέραιο που είναι μια θέση.
