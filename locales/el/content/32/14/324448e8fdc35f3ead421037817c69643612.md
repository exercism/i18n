# Οδηγίες

Ενώ σχεδιάζεις μια βραδιά παιχνιδιών με φίλους, η παρέα αποφασίζει να ξαναθυμηθεί τα αγαπημένα παιδικά τους παιχνίδια. Ο Γερμανός φίλος σου προτείνει το _Mensch ärgere Dich nicht_ (_Άνθρωπε, μην θυμώνεις_), ένα κλασικό παιχνίδι σε πολλές ευρωπαϊκές χώρες (παρόμοιο με το αγγλικό _Ludo_ ή το βορειοαμερικανικό _Parcheesi_).

Για να προετοιμαστείς για το παιχνίδι, αποφασίζεις να υλοποιήσεις τη συνάρτηση ρίψης ζαριών σε Elixir.

Στο _Mensch ärgere Dich nicht_, οι παίκτες ρίχνουν ένα ζάρι 6 πλευρών για να καθορίσουν την επόμενη κίνησή τους. Αν είναι τυχεροί και φέρουν 6, μπορούν να ξαναρίξουν και να κινηθούν ξανά.

## 1. Κάνε μία ρίψη με ένα ζάρι 6 πλευρών

Υλοποίησε τη συνάρτηση `d6/0` που θα επιλέγει τυχαία έναν ακέραιο μεταξύ 1 και 6 σε κάθε κλήση.

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. Συνέχισε να ρίχνεις όσο φέρνεις εξάρια

Υλοποίησε τη συνάρτηση `roll/0`. Πρέπει να επιστρέφει ένα stream από ρίψεις ζαριών. Οι ρίψεις των ζαριών πρέπει να ακολουθούν τους κανόνες του παιχνιδιού. Αν φέρω έξι, μπορώ να ξαναρίξω. Αλλιώς, σταμάτα να ρίχνεις. Χρησιμοποίησε τη συνάρτηση `d6/0` που ορίστηκε στο προηγούμενο βήμα.

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. Επέτρεψε τη χρήση πειραγμένου ζαριού

Για να είναι πιο εύκολο να δοκιμάσεις τον κώδικά σου, επέτρεψε τη χρήση πειραγμένου ζαριού.

Επέκτεινε τη συνάρτηση `roll/0`. Πρέπει να δέχεται ένα προαιρετικό όρισμα: μια συνάρτηση. Αν έχει περαστεί το όρισμα, χρησιμοποίησέ το για τη ρίψη του ζαριού. Αλλιώς, χρησιμοποίησε ως εναλλακτική τη `MenschAergereDichNicht.d6/0`.

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
