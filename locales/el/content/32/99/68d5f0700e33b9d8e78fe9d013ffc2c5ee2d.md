# Εισαγωγή

## Η λέξη-κλειδί `auto` στη C++

Στη C++, η λέξη-κλειδί `auto` είναι ένα ισχυρό χαρακτηριστικό που εισήχθη στη C++11 και χρησιμοποιείται για να δηλώνεις μεταβλητές με τύπο που συμπεραίνεται.
Ο μεταγλωττιστής συμπεραίνει τον τύπο της μεταβλητής με βάση τον αρχικοποιητή της, κάτι που κάνει τον κώδικα πιο ευανάγνωστο και πιο εύκολο στη συντήρηση.

## Παράδειγμα χρήσης

Δες το παρακάτω παράδειγμα, όπου το `auto` χρησιμοποιείται για να δηλώσεις μεταβλητές:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

Σε κάθε περίπτωση, ο τύπος της μεταβλητής συμπεραίνεται από την τιμή με την οποία αρχικοποιείται.

## Συμπερασματολογία τύπων

Η λέξη-κλειδί `auto` σε βοηθά να γράφεις πιο σύντομο και πιο ευανάγνωστο κώδικα, μειώνοντας τη φλυαρία των ρητών τύπων.

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

Σε αυτόν τον βρόχο, το `auto` συμπεραίνει τον τύπο του `purple_wedding_pie` ως `std::vector<std::string>`, αποφεύγοντας την ανάγκη να προσδιορίσεις ξανά ρητά τον τύπο.

## Συμβατότητα

Η λέξη-κλειδί `auto` είναι συμβατή με διάφορες δομές της C++, γεγονός που την κάνει ένα ευέλικτο εργαλείο στον σύγχρονο προγραμματισμό σε C++.

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

Σε επόμενες έννοιες θα βλέπουμε συχνά τη λέξη-κλειδί `auto` με εκφράσεις λάμδα, `for` βρόχους βασισμένους σε εύρος και επαναλήπτες.

## Έξυπνοι δείκτες

Οι έξυπνοι δείκτες είναι ένα σύγχρονο χαρακτηριστικό της C++ που έχει σχεδιαστεί για να παρέχει αυτόματη διαχείριση μνήμης, βοηθώντας στην αποφυγή διαρροών μνήμης και εκκρεμών δεικτών, που συνήθως συνδέονται με τους ακατέργαστους δείκτες.
Λειτουργούν ως περιβλήματα γύρω από τους ακατέργαστους δείκτες, προσθέτοντας επιπλέον λειτουργικότητα, όπως την αυτόματη αποδέσμευση μνήμης όταν ο δείκτης δεν χρειάζεται πια.

## Γενική σύνταξη

Οι έξυπνοι δείκτες συνήθως υλοποιούνται ως πρότυπα κλάσεων στην πρότυπη βιβλιοθήκη της C++.
Οι δύο πιο συχνά χρησιμοποιούμενοι έξυπνοι δείκτες είναι οι `std::unique_ptr` και `std::shared_ptr`.

## Μοναδικοί δείκτες

Ο `std::unique_ptr` είναι ένας έξυπνος δείκτης που κατέχει το αντικείμενο αποκλειστικά.
Διασφαλίζει ότι ανά πάσα στιγμή μόνο ένα αντικείμενο `std::unique_ptr` κατέχει τον πόρο.
Όταν ο `std::unique_ptr` που κατέχει τον πόρο καταστραφεί ή επαναρυθμιστεί, καταστρέφει αυτόματα το αντικείμενο και απελευθερώνει τη μνήμη του.

```cpp
#include <memory>
// Declaring and defining a unique pointer
auto rightful_king_of_england = std::make_unique<std::string>("Excalibur");

// Unique pointers cannot be copied or assigned
auto mordred = rightful_king_of_england; // Error: Cannot copy a unique_ptr
```

## Πλεονεκτήματα του `std::make_unique()`

Όταν δημιουργείς έναν `std::unique_ptr`, είναι προτιμότερο να χρησιμοποιείς τον `std::make_unique()` αντί να χρησιμοποιείς απευθείας το `new` για να δεσμεύσεις μνήμη.
Ο `std::make_unique()` προσφέρει αρκετά πλεονεκτήματα:
1. **Ασφάλεια έναντι εξαιρέσεων**: Ο `std::make_unique()` εγγυάται ασφάλεια έναντι εξαιρέσεων.
  Αν πεταχτεί μια εξαίρεση κατά την κατασκευή του αντικειμένου, η μνήμη θα αποδεσμευτεί αυτόματα, αποτρέποντας διαρροές μνήμης.
2. **Σαφήνεια**: Η χρήση του `std::make_unique()` κάνει τον κώδικα πιο σαφή και πιο σύντομο.
  Εξαλείφει την ανάγκη να προσδιορίσεις ρητά τον τύπο που δεσμεύεται, αφού τα ορίσματα του προτύπου συμπεραίνονται αυτόματα.
3. **Ευκαιρίες βελτιστοποίησης**: Οι μεταγλωττιστές έχουν τη δυνατότητα να βελτιστοποιήσουν τον `std::make_unique()` πιο αποτελεσματικά από ό,τι τη χειροκίνητη δέσμευση μνήμης με το `new`, κάτι που μπορεί να οδηγήσει σε καλύτερες επιδόσεις.
4. **Αποφυγή κακής χρήσης**: Η διαγραφή του υποκείμενου πόρου είναι δυνατή όταν ο `std::unique_ptr` κατασκευάζεται χειροκίνητα.
  Αυτό θα οδηγούσε σε απροσδιόριστη συμπεριφορά, όταν ο `std::unique_ptr` προσπαθεί να τον διαγράψει στο τέλος της εμβέλειάς του.

## Κοινοί δείκτες

Ο `std::shared_ptr` είναι ένας έξυπνος δείκτης που επιτρέπει σε πολλά αντικείμενα `std::shared_ptr` να μοιράζονται την κυριότητα του ίδιου πόρου.
Παρακολουθεί πόσοι κοινοί δείκτες αναφέρονται στον πόρο και αποδεσμεύει τη μνήμη μόνο όταν ο τελευταίος κοινός δείκτης που κατέχει τον πόρο βγει από την εμβέλεια ή επαναρυθμιστεί.

```cpp
// Declaring and defining a shared pointer to a dynamically allocated string
auto martian_congressional_republic = std::make_shared<std::string>("protomolecule");

// Creating more shared pointer that shares ownership
auto outer_planets_alliance = martian_congressional_republic;
auto united_nations = martian_congressional_republic;
```

~~~~exercism/caution
Στη C++17 και σε παλαιότερες εκδόσεις, η χρήση του `std::shared_ptr` με πίνακες μέσω του `std::make_shared<T[]>` δεν υποστηρίζεται άμεσα.
Αν και είναι δυνατή η δέσμευση πινάκων με το `std::make_shared<T[]>`, η δημιουργία κοινών δεικτών απευθείας από αυτούς μπορεί να οδηγήσει σε απροσδιόριστη συμπεριφορά, λόγω διαφορών στη διαχείριση μνήμης ανάμεσα σε μεμονωμένα αντικείμενα και πίνακες.
Αντ' αυτού, σκέψου να χρησιμοποιήσεις το `std::vector` ή προσαρμοσμένες συναρτήσεις διαγραφής για να διαχειρίζεσαι αποτελεσματικά πίνακες με κοινούς δείκτες.
Να διασφαλίζεις πάντα τη συμβατότητα με τον μεταγλωττιστή σου και την υλοποίηση της πρότυπης βιβλιοθήκης σου, όταν ασχολείσαι με δεσμεύσεις πινάκων και κοινούς δείκτες στη C++17.
~~~~

## Πλεονεκτήματα του `std::make_shared()`

Όπως ο `std::make_unique()`, έτσι και ο `std::make_shared()` προσφέρει οφέλη όπως καλύτερη αποδοτικότητα μνήμης, ασφάλεια έναντι εξαιρέσεων και αναγνωσιμότητα.
Συνδυάζει τη δέσμευση μνήμης για το μπλοκ ελέγχου και το διαχειριζόμενο αντικείμενο σε μία μόνο λειτουργία, βελτιώνοντας την αποδοτικότητα και μειώνοντας τον κίνδυνο διαρροών μνήμης.
Επιπλέον, η αυτόματη συμπερασματολογία των ορισμάτων του προτύπου απλοποιεί τον κώδικα και βελτιώνει την αναγνωσιμότητα.
Η χρήση του `std::make_shared()` προάγει καθαρότερο, ασφαλέστερο και πιο αποδοτικό κώδικα όταν δουλεύεις με αντικείμενα `std::shared_ptr` στη C++.

## Συμβουλές χρήσης

Χρησιμοποίησε έξυπνους δείκτες κατά προεπιλογή: `std::unique_ptr` για αποκλειστική κυριότητα και `std::shared_ptr` για κοινή κυριότητα.
Κράτα τους ακατέργαστους δείκτες για αναφορές χωρίς κυριότητα ή όταν συνεργάζεσαι με παλαιό κώδικα.
Στις περισσότερες περιπτώσεις, ο `std::unique_ptr` αρκεί για αποκλειστική κυριότητα, καθώς προσφέρει ελαφριά διαχείριση μνήμης χωρίς την επιβάρυνση της μέτρησης αναφορών.
Ο `std::shared_ptr` πρέπει να χρησιμοποιείται με φειδώ, καθώς εισάγει επιβάρυνση και πολυπλοκότητα, εκτός αν χρειάζεται πραγματικά κοινή κυριότητα.
