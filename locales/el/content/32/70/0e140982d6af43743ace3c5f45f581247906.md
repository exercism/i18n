# Σχετικά

Όταν γράφουμε συναρτήσεις σε Haskell, μπορούμε να αξιοποιήσουμε την [αντιστοίχιση προτύπων][pattern-matching].
Η αντιστοίχιση προτύπων είναι ένα πολύ ισχυρό χαρακτηριστικό της Haskell, που σου επιτρέπει να αντιστοιχίζεις με κατασκευαστές δεδομένων και να δεσμεύεις μεταβλητές στις τιμές που περιέχονται μέσα τους.
Όπως υποδηλώνει και το όνομα, αυτό που κάνουμε είναι να αντιστοιχίζουμε τιμές με πρότυπα, και αν η τιμή ταιριάζει με το πρότυπο, μπορούμε να δεσμεύσουμε μεταβλητές στις τιμές μέσα στο πρότυπο.
Η αντιστοίχιση προτύπων βασίζεται κυρίως σε αυτές τις έννοιες: αναγνώριση τιμών, δέσμευση μεταβλητών και διάσπαση τιμών στα μέρη τους.

~~~~exercism/note
Η αντιστοίχιση προτύπων σε γλώσσες όπως η Elixir είναι λίγο διαφορετική από την αντιστοίχιση προτύπων στη Haskell.
Η Elixir, για παράδειγμα, επιτρέπει πολλά ίδια ονόματα δέσμευσης σε ένα πρότυπο, ενώ η Haskell όχι.
~~~~


Ας πάρουμε για παράδειγμα αυτή τη συνάρτηση:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Εδώ έχουμε μια συνάρτηση `lucky` που παίρνει ένα `Int` και επιστρέφει μια `String`.
Έχουμε ορίσει δύο πρότυπα για τη συνάρτηση, ένα που αντιστοιχίζεται με τον αριθμό `7` και ένα που αντιστοιχίζεται με οποιονδήποτε άλλο αριθμό. Το όνομα μπορεί να είναι ό,τι θέλεις (αρκεί να ακολουθεί τη σύμβαση ονοματοδοσίας της Haskell), αλλά εδώ χρησιμοποιούμε το `x`.
Αν ο αριθμός είναι `7`, η συνάρτηση θα επιστρέψει `"Lucky number seven!"`, αλλιώς θα επιστρέψει `"Sorry, you're out of luck, pal!"`.
Αυτό που αξίζει να προσέξεις εδώ είναι ότι τα πρότυπα ελέγχονται από πάνω προς τα κάτω, οπότε αν είχαμε ανταλλάξει τη σειρά των προτύπων, η συνάρτηση θα επέστρεφε πάντα `"Lucky number seven!"`.

## Πρότυπα λιστών

Ένα πολύ συνηθισμένο πρότυπο είναι η αντιστοίχιση με λίστες, παίρνοντας την κεφαλή και την ουρά της λίστας.
Αυτό οφείλεται στη φύση των λιστών ως συνδεδεμένων λιστών.
Ακολουθεί ένα παράδειγμα συνάρτησης που επιστρέφει την κεφαλή και την ουρά μιας λίστας:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Έχουμε δύο πρότυπα εδώ, ένα που αντιστοιχίζεται με μια κενή λίστα και ένα που αντιστοιχίζεται με μια λίστα που έχει τουλάχιστον ένα στοιχείο.
Αυτό συμβαίνει γιατί αν η λίστα είναι κενή, χρειάζεται να έχουμε μια περίπτωση γι' αυτό, αλλιώς θα προέκυπτε σφάλμα χρόνου εκτέλεσης.
Αν η λίστα δεν είναι κενή, μπορούμε να αντιστοιχίσουμε την κεφαλή της λίστας με το `x` και την ουρά της λίστας με το `xs`.
Αυτό γίνεται με τον τελεστή `:` (cons), ο οποίος χρησιμοποιείται για να προσθέσεις ένα στοιχείο στην αρχή μιας λίστας.
Στην αντιστοίχιση προτύπων όμως μας επιτρέπει να διασπάσουμε μια λίστα στην κεφαλή και την ουρά της, κάνοντας κατά κάποιον τρόπο το αντίθετο.

Το `xs` είναι ένα συνηθισμένο όνομα για την ουρά μιας λίστας, τονίζει ότι πρόκειται για λίστα, αλλά αν δούλευες με μια εμφωλευμένη λίστα, θα μπορούσες να χρησιμοποιήσεις το `xss` για να τονίσεις ότι είναι λίστα από λίστες.

## Πρότυπα πλειάδων

Όπως με τις λίστες, μπορούμε επίσης να αντιστοιχίζουμε με πλειάδες.
Ορίστε ένα παράδειγμα συνάρτησης που παίρνει μια πλειάδα και επιστρέφει το πρώτο και το δεύτερο στοιχείο:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Εδώ έχουμε ένα πρότυπο που αντιστοιχίζεται με μια πλειάδα δύο στοιχείων, το πρώτο στοιχείο δεσμεύεται στο `x` και το δεύτερο στοιχείο δεσμεύεται στο `y`.

## Πρότυπα wildcard

Μερικές φορές δεν μας ενδιαφέρει η τιμή μιας μεταβλητής, θέλουμε απλώς να αντιστοιχίσουμε με το πρότυπο.
Εδώ έρχεται το πρότυπο wildcard, το οποίο συμβολίζεται με μια κάτω παύλα `_`.

Ας δούμε ένα παράδειγμα συνάρτησης που επιστρέφει το πρώτο στοιχείο μιας λίστας:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Εδώ λέμε ότι δεν χρειαζόμαστε την ουρά της λίστας, οπότε χρησιμοποιούμε το πρότυπο wildcard για να την αγνοήσουμε.

## Πρότυπα τύπων

Μπορούμε επίσης να αντιστοιχίζουμε με τύπους, κάτι που γίνεται χρησιμοποιώντας τον κατασκευαστή του συγκεκριμένου τύπου.
Μπορούμε επίσης να εξάγουμε τιμές από τον τύπο, όπως κάναμε με τις πλειάδες.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Στο πρώτο πρότυπο αντιστοιχίζουμε με τον κατασκευαστή `Guest`, και στο δεύτερο πρότυπο αντιστοιχίζουμε με τον κατασκευαστή `User` και δεσμεύουμε την τιμή που περιέχει στο `name`.
