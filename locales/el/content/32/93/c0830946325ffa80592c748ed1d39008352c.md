# χρησιμοποίησε σωστό όνομα μεθόδου

Το όνομα της μεθόδου πρέπει να ταιριάζει ακριβώς με αυτό που χρησιμοποιήθηκε στα tests.

Μετονόμασε τη μέθοδο σε `%{methodName}`.

**ΣΗΜΕΙΩΣΗ**: Μην τροποποιήσεις τα tests ώστε να ταιριάζουν με διαφορετικό όνομα μεθόδου.
Γενικά, προσπάθησε να προσθέτεις μόνο επιπλέον tests (αν το θέλεις).
