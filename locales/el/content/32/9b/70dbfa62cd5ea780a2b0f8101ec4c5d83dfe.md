# Εισαγωγή

Εκτός από την εντολή `if`, η JavaScript διαθέτει και την εντολή `switch`, με την οποία εκτελείς λογική υπό συνθήκη.
Χρησιμοποιείται όταν μία μόνο μεταβλητή πρέπει να συγκριθεί με πολλαπλές παραλλαγές.
Η σύγκριση γίνεται ελέγχοντας την αυστηρή ισότητα (`===`), δες την [έννοια σύγκριση][concept-comparison].
Για κάποια μεταβλητή `x`, η εντολή `switch` στην JavaScript έχει την παρακάτω σύνταξη.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

Η περίπτωση `default` είναι προαιρετική και χρησιμοποιείται όταν θέλεις να εκτελέσεις κάποιον κώδικα, αν καμία από τις άλλες επιλογές δεν ταιριάζει με τη μεταβλητή.

Οι εντολές `break` παραπάνω χρειάζονται, επειδή από προεπιλογή η εκτέλεση στην JavaScript συνεχίζει στην επόμενη περίπτωση.
Αυτό σημαίνει ότι χωρίς καμία εντολή `break` θα εκτελεστεί όλος ο κώδικας των περιπτώσεων που βρίσκονται μετά την πρώτη επιλογή που ταιριάζει, ακόμα κι αν το `x` δεν ταίριαζε με αυτές τις επιλογές.
Αυτή η συμπεριφορά, να συνεχίζει δηλαδή η εκτέλεση στην επόμενη περίπτωση από προεπιλογή, είναι μια συνηθισμένη παγίδα όταν χρησιμοποιείς το `switch` στην JavaScript.
Μέσα σε μια συνάρτηση, μπορείς να χρησιμοποιήσεις και το `return` αντί για το `break`, για να αποφύγεις αυτό το πρόβλημα.
