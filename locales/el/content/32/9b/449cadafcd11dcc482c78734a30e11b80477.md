# Υποδείξεις

## Γενικά

- Διάβασε για τις [comprehensions][elixir-comprehensions] στον οδηγό Getting Started.
- Διάβασε για τις [λίστες][elixir-lists] στον οδηγό Getting Started.
- Διάβασε για τα [maps][elixir-maps] στον οδηγό Getting Started.
- Διάβασε για τις [keyword lists][elixir-kwlists] στον οδηγό Getting Started.

## 1. Πρότεινε έναν συνδυασμό

- Στη list comprehension, χρησιμοποίησε δύο _γεννήτριες_ για να δημιουργήσεις το καρτεσιανό γινόμενο.

## 2. Φιλτράρισμα των ασύμβατων συνδυασμών ρούχων

- Μπορείς να χρησιμοποιήσεις την _αντιστοίχιση προτύπων_ για να αποδομήσεις μέσα στη _γεννήτρια_ και να δεσμεύσεις τα πεδία σε μια μεταβλητή.
- Χρησιμοποίησε μια έκφραση _φίλτρου_ που να επιστρέφει false όταν τα βασικά χρώματα ταιριάζουν.

## 3. Φιλτράρισμα με βάση την τιμή του συνδυασμού

- Υπάρχουν αρκετές [συναρτήσεις για keyword lists][kw-module] που μπορείς να χρησιμοποιήσεις για να ανακτήσεις επιλογές από μια keyword list.
- Χρησιμοποίησε μια έκφραση _φίλτρου_ που να επιστρέφει false όταν η συνδυασμένη τιμή είναι μεγαλύτερη από τη μέγιστη τιμή.
