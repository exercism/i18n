# Σχετικά

Οι πλειάδες χρησιμοποιούνται συχνά για να ομαδοποιούμε άτυπα κάποιες πληροφορίες. Ένα συνηθισμένο μοτίβο στην Elixir είναι να ομαδοποιούμε τις τιμές επιστροφής μιας συνάρτησης μαζί με μια κατάσταση.

```elixir
File.read("hello.txt")
# => {:ok, "World"}

File.read("invalid.txt")
# => {:error, :enoent}
```

- Τα literal μιας πλειάδας περικλείονται σε άγκιστρα, `{}`.
- Οι πλειάδες μπορούν να περιέχουν οποιονδήποτε τύπο δεδομένων σε συνεχόμενη μνήμη, η οποία δεσμεύεται όταν δημιουργείται η πλειάδα.
- Οι πλειάδες επιτρέπουν ανάγνωση σε σταθερό χρόνο.
- Όταν χειρίζεσαι μια πλειάδα, αντί να τροποποιείς την υπάρχουσα, δημιουργείται μια νέα.
- Τα χαρακτηριστικά απόδοσης των πλειάδων τις κάνουν ιδανικές για να αποθηκεύεις μαζί σχετικές πληροφορίες, αλλά όχι για να αποθηκεύεις συλλογές στοιχείων που χρειάζονται επανάληψη ή που μπορεί να μεγαλώσουν ή να μικρύνουν. Στη δεύτερη περίπτωση, [μια λίστα είναι πιο κατάλληλη][getting-started-lists-or-tuples].
- Τα modules [`Kernel`][kernel-module] και [`Tuple`][tuple-module] έχουν χρήσιμες συναρτήσεις για να δουλεύεις με πλειάδες.
