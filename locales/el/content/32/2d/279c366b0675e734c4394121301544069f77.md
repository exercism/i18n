# Εισαγωγή

Μερικές φορές δεν χρειάζεσαι την επιβάρυνση της δημιουργίας ενός αντικειμένου με κατάσταση.
Σε αυτές τις περιπτώσεις, μπορείς να χρησιμοποιήσεις ένα `module`.

Ένα `module` είναι πολύ παρόμοιο με μια κλάση (στην πραγματικότητα, το `Module` είναι πρόγονος της `Class` στην ιεραρχία αντικειμένων). Η κύρια διαφορά είναι ότι αντί να χρησιμοποιούμε μεθόδους στιγμιοτύπων, χρησιμοποιούμε μεθόδους κλάσης.
Οι μέθοδοι κλάσης ξεκινούν με `self.` και καλούνται απευθείας σε ένα `module`.

Για παράδειγμα:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
