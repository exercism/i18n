# Οδηγίες

Βρίσκεσαι στη διαδικασία ανάπτυξης του νέου, πολύ αγαπητού παιχνιδιού **Wings Quest**.
Στο παιχνίδι είσαι ένα πουλί που κινείται τριγύρω και μαζεύει σπόρους.
Ο παίκτης κερδίζει όταν μαζέψει όλους τους σπόρους.
Αν ο παίκτης έρθει σε επαφή με έναν αετό, τότε θα χάσει όλους τους σπόρους του και θα χάσει το παιχνίδι.
Υπάρχει μια εξαίρεση σε αυτόν τον κανόνα: ο παίκτης μπορεί να έχει ένα ενεργό power-up που τον κάνει να πετάει ψηλότερα από τα άλλα πουλιά.

Ο στόχος σου είναι να γράψεις κάποιους κανόνες που θα χρησιμοποιηθούν στο παιχνίδι.

## 1. Όρισε αν το πουλί παίρνει πόντους μπόνους

Στο παιχνίδι, το πουλί παίρνει πόντους μπόνους αν αγγίξει έναν αετό ενώ έχει ένα power-up.

Όρισε τη συνάρτηση `bonusPoints(powerUpActive:touchingEagle:)` που παίρνει δύο ορίσματα: το `powerUpActive`, που δείχνει αν το πουλί έχει ενεργό power-up, και το όρισμα `touchingEagle`, που δείχνει αν το πουλί αγγίζει έναν αετό.
Η συνάρτηση πρέπει να επιστρέφει `true` μόνο αν το πουλί έχει ενεργό power-up και αγγίζει έναν αετό, αλλιώς `false`.

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. Όρισε αν το πουλί σκοράρει

Στο παιχνίδι, ο παίκτης παίρνει πόντους όταν μαζεύει έναν σπόρο ή ένα power-up.

Όρισε τη συνάρτηση `score(touchingPowerUp:touchingSeed:)` που παίρνει δύο ορίσματα: το `touchingPowerUp`, που δείχνει αν το πουλί αγγίζει ένα power-up, και το όρισμα `touchingSeed`, που δείχνει αν το πουλί αγγίζει έναν σπόρο.
Η συνάρτηση πρέπει να επιστρέφει `true` αν το πουλί αγγίζει ένα power-up ή έναν σπόρο, αλλιώς να επιστρέφει `false`.

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. Όρισε αν το πουλί χάνει

Όρισε τη συνάρτηση `lose(powerUpActive:touchingEagle:)` που παίρνει δύο ορίσματα: το `powerUpActive`, που δείχνει αν το πουλί έχει ενεργό power-up, και το όρισμα `touchingEagle`, που δείχνει αν το πουλί αγγίζει έναν αετό.
Η συνάρτηση πρέπει να επιστρέφει `true` αν ο χαρακτήρας αγγίζει έναν αετό και δεν έχει ενεργό power-up, αλλιώς να επιστρέφει `false`.

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. Όρισε αν το πουλί κερδίζει

Όρισε τη συνάρτηση `win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)` που παίρνει τα ορίσματα:

- `hasPickedUpAllSeeds` αν το πουλί έχει μαζέψει όλους τους σπόρους.
- `powerUpActive` αν το πουλί έχει ενεργό power-up.
- `touchingEagle` αν το πουλί αγγίζει έναν αετό.

Η συνάρτηση πρέπει να επιστρέφει `true` αν το πουλί έχει μαζέψει όλους τους σπόρους και δεν έχει χάσει με βάση τα ορίσματα που ορίστηκαν στο μέρος 3, αλλιώς να επιστρέφει `false`.

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
