# Βοήθεια

Αν έχεις κάποιο πρόβλημα και χρειάζεσαι βοήθεια, μπορείς να χρησιμοποιήσεις έναν από τους παρακάτω πόρους:

- [CF SCript Cheatsheet](http://www.petefreitag.com/cheatsheets/coldfusion/cfscript/)
- [CFML Slack](https://cfml-slack.herokuapp.com/)
- [Community Resource Page](http://carehart.org/cf411/)
- [Lucee Server Discourse Forum](https://dev.lucee.org/)
- [Twitter](https://twitter.com/search?q=coldfusion&src=typd)
- Το [/r/coldfusion](https://www.reddit.com/r/coldfusion/) είναι το subreddit του ColdFusion.
- Μπορείς να χρησιμοποιήσεις το [StackOverflow](http://stackoverflow.com/questions/tagged/coldfusion) για να αναζητήσεις το πρόβλημά σου και να δεις αν έχει απαντηθεί ήδη. Μπορείς επίσης να κάνεις ερωτήσεις και να απαντήσεις σε ερωτήσεις άλλων.
