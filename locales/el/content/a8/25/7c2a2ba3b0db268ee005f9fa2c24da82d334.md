# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις κώδικα που θα βοηθήσει έναν ελεύθερο επαγγελματία να συνεννοηθεί με έναν διαχειριστή έργου.
Η αποστολή σου είναι να φτιάξεις μερικά βοηθητικά εργαλεία για να υπολογίζεις γρήγορα την ημερήσια και τη μηνιαία χρέωση, προαιρετικά με κάποια έκπτωση.

Πρώτα ορίζουμε μερικούς κανόνες ανάμεσα στον ελεύθερο επαγγελματία και στον διαχειριστή έργου:

- Η ημερήσια χρέωση είναι 8 φορές η ωριαία χρέωση.
- Ο μήνας έχει 22 ημέρες χρέωσης.

Μερικές φορές, ο ελεύθερος επαγγελματίας προσφέρεται να εφαρμόσει έκπτωση στην ημερήσια χρέωσή του (για παράδειγμα, στους πιο πιστούς πελάτες του ή σε πελάτες μη κερδοσκοπικών οργανισμών).

Οι εκπτώσεις αναπαρίστανται ως δεκαδικοί αριθμοί που εκφράζουν ποσοστά, για παράδειγμα `25.0` (25%).

~~~~exercism/note
Αυτά είναι τα επιθήματα των εντολών κινητής υποδιαστολής:

| Suffix | Operand size |
|--------|--------------|
| `ss`   | 32-bit       |
| `sd`   | 64-bit       |

Αυτές είναι μερικές από τις εντολές που αναφέρονται σε αυτή την έννοια:

| Instruction       | Description                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | αντιγράφει το b στο a                                  |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | μετατρέπει τον ακέραιο b στον αριθμό κινητής υποδιαστολής a |
| roundss/roundsd a, b, c | στρογγυλοποιεί τον αριθμό κινητής υποδιαστολής b σύμφωνα με το c και τον αποθηκεύει στο a |
| cvtss2si/cvtsd2si a, b  | μετατρέπει τον αριθμό κινητής υποδιαστολής b στον ακέραιο a |
| comiss/comisd a, b      | κάνει σύγκριση μεταξύ των a και b, εξαίρεση αν είναι `NaN` |
| ucomiss/ucomisd a, b    | κάνει σύγκριση μεταξύ των a και b, θέτει το `PF` αν είναι `NaN` |

Αυτοί είναι οι αριθμοί ελέγχου στρογγυλοποίησης στις `roundss` και `roundsd`:

| Number | Mode         |
|:-------|:-------------|
| 0      | Πλησιέστερη  |
| 1      | Δάπεδο (προς τα κάτω) |
| 2      | Οροφή (προς τα πάνω)  |
| 3      | Αποκοπή      |
~~~~

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη ωριαία χρέωση

Υλοποίησε μια συνάρτηση με το όνομα `daily_rate` που να υπολογίζει την ημερήσια χρέωση, δεδομένης ως παραμέτρου μιας ωριαίας χρέωσης, ως αριθμού κινητής υποδιαστολής 64-bit.
Το συμβόλαιο ορίζει ότι μια ημέρα έχει 8 ώρες χρέωσης.

```c
daily_rate(60)
// => 480.0
```

Η ημερήσια χρέωση που επιστρέφεται θα πρέπει να είναι αριθμός κινητής υποδιαστολής 64-bit.

## 2. Υπολόγισε μια τιμή με έκπτωση

Υλοποίησε μια συνάρτηση `apply_discount` που να υπολογίζει την τιμή μετά από έκπτωση.
Θα πρέπει να δέχεται δύο παραμέτρους: την αρχική τιμή και το ποσοστό έκπτωσης, και τις δύο ως αριθμούς κινητής υποδιαστολής 64-bit.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

Η τιμή που επιστρέφεται θα πρέπει να είναι πάντα αριθμός κινητής υποδιαστολής 64-bit.

## 3. Υπολόγισε τη μηνιαία χρέωση, με δεδομένες μια ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση `monthly_rate` που να υπολογίζει τη μηνιαία χρέωση με έκπτωση.
Δέχεται δύο παραμέτρους, μια ωριαία χρέωση και το ποσοστό έκπτωσης, και τις δύο ως αριθμούς κινητής υποδιαστολής 64-bit.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

Η μηνιαία χρέωση που επιστρέφεται θα πρέπει να στρογγυλοποιείται προς τα πάνω (οροφή) στον πλησιέστερο ακέραιο 64-bit.

## 4. Υπολόγισε τον αριθμό των πλήρων εργάσιμων ημερών, με δεδομένα έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση `days_in_budget` που δέχεται ως παραμέτρους:

1. Έναν προϋπολογισμό, ως ανυπόγραφο ακέραιο 64-bit.
2. Μια ωριαία χρέωση, ως αριθμό κινητής υποδιαστολής 64-bit.
3. Ένα ποσοστό έκπτωσης, ως αριθμό κινητής υποδιαστολής 64-bit.

Αυτή η συνάρτηση θα πρέπει να επιστρέφει τον αριθμό των πλήρων ημερών εργασίας που καλύπτει ο προϋπολογισμός.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

Ο αριθμός των ημερών που επιστρέφεται θα πρέπει να στρογγυλοποιείται προς τα κάτω (δάπεδο) στον πλησιέστερο ακέραιο 32-bit.
