# Απενεργοποίηση βόμβας

## Ιστορία

Γεια σου και πάλι, Πράκτορα Double-Null0111.

Οι δυνάμεις της UMBRA αναστατώνονται ξανά και από εσένα εξαρτάται να ματαιώσεις το τελευταίο τους σχέδιο. Η υπηρεσία πληροφοριών μας μάς ενημερώνει ότι αυτοί οι Minions σχεδιάζουν να πυροδοτήσουν μια βρωμοβόμβα στον χορό του Κυβερνήτη.

Επειδή οι Minions είναι τόσο αδέξιοι, συχνά οπλίζουν κατά λάθος τις βρωμοβόμβες στα εργαστήρια και στα γραφεία τους. Και επειδή ξεχνούν συνέχεια πώς να απενεργοποιούν τις βρωμοβόμβες τους, έχουν φτιάξει ένα σύστημα που παράγει τις οδηγίες απενεργοποίησης, οι οποίες αναφέρουν τη σειρά με την οποία πρέπει να κοπούν τα καλώδια, με βάση τον αριθμό ταυτότητας της βόμβας.

Η δουλειά σου είναι να γράψεις τον κώδικα που θα σου επιτρέψει να απενεργοποιήσεις τη βρωμοβόμβα στον χορό πριν εκραγεί.

## Εργασίες

Αυτές είναι παραδείγματα εργασιών που ταιριάζουν στην ιστορία του μυστικού πράκτορα που απενεργοποιεί μια βρωμοβόμβα:

- Γράψε ένα closure για να αντιστρέψεις δύο καλώδια
- Γράψε ένα closure για να περιστρέψεις τα καλώδια
- Υλοποίησε μια γεννήτρια που ανακατεύει τα καλώδια
