# χωρίς rescue

Μη χρησιμοποιείς εξαιρέσεις για έλεγχο ροής.
Προσπάθησε να λύσεις αυτή την άσκηση χωρίς να χρησιμοποιήσεις `rescue`.

Αν χρησιμοποιείς μια συνάρτηση της βασικής βιβλιοθήκης με όνομα που τελειώνει σε `!` (πετάει σφάλματα), ψάξε για μια αντίστοιχη συνάρτηση χωρίς το `!` (συχνά επιστρέφει `{:ok, result}` ή `{:error, message}`).

Σημείωση: αν βλέπεις αυτό το αυτόματο σχόλιο στη λύση σου, άλλα αυτόματα σχόλια μπορεί να μην είναι ακριβή.
Διόρθωσε πρώτα αυτό το πρόβλημα!

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
