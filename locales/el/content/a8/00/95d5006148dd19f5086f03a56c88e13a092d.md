# Ρητή επιστροφή

Αφαίρεσε τη ρητή επιστροφή για να απλοποιήσεις τη μέθοδο.

Στη Ruby, μια μέθοδος επιστρέφει το αποτέλεσμα της τελευταίας εντολής που αξιολογήθηκε. Η ρητή χρήση της λέξης-κλειδί `return` είναι λοιπόν περιττή, εκτός από όταν επιστρέφεις νωρίς μέσα σε μια μέθοδο.

Για παράδειγμα, αυτό θα εκτυπώσει `16`, καθώς η μέθοδος `multiply` επιστρέφει το αποτέλεσμα του `a * b`, που είναι η τελευταία της έκφραση.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
