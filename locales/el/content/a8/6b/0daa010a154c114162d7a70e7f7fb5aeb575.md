# Υποδείξεις

## Γενικά

- Για να εξαγάγεις πολλά ορίσματα στις παραμέτρους της συνάρτησης, μπορείς να τα πακετάρεις με τον τελεστή `*arguments` για **πίνακα** ή `**keyword_arguments` για ορίσματα με λέξεις-κλειδιά.
- Για πακετάρισμα ή ξεπακετάρισμα, χρησιμοποίησε τους τελεστές splat (`*` ή `**`).

## 1. Δημιούργησε μια λίστα με όλα τα βαγόνια

- Πολλά ορίσματα στις παραμέτρους της συνάρτησης μπορείς να τα πακετάρεις με τον τελεστή `*arguments`.

## 2. Διόρθωσε τη λίστα με τα βαγόνια

- Χρησιμοποιώντας ξεπακετάρισμα με τον τελεστή splat (`*`), μπορείς να εξαγάγεις τα δύο πρώτα στοιχεία ενός **πίνακα** κρατώντας τα υπόλοιπα άθικτα.
- Για να προσθέσεις έναν άλλο **πίνακα** μέσα σε έναν υπάρχοντα **πίνακα**, μπορείς να χρησιμοποιήσεις τον τελεστή splat (`*`) για να "απλώσεις" τον **πίνακα**.

## 3. Πρόσθεσε τις στάσεις που λείπουν

- Μπορείς να χρησιμοποιήσεις το `**keyword_arguments` ως όρισμα μεθόδου για να περάσεις οποιοδήποτε πλήθος ορισμάτων με λέξεις-κλειδιά.
- Χρησιμοποιώντας το `**<hash>` ως όρισμα, θα ξεπακετάρεις ένα `Hash` σε ορίσματα με λέξεις-κλειδιά.
- Μπορείς να βάλεις ορίσματα με λέξεις-κλειδιά μέσα σε ένα `{}`, που είναι ένας άλλος τρόπος για να δημιουργήσεις ένα `Hash`.
- Για να βγάλεις τις τιμές από ένα `Hash`, μπορείς να χρησιμοποιήσεις τη μέθοδο `Hash#values`.

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

- Χρησιμοποιώντας το `**{some_hash: value}` ως όρισμα, θα ξεπακετάρεις το `Hash` σε ορίσματα με λέξεις-κλειδιά.
