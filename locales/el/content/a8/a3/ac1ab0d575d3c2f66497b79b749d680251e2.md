# Εισαγωγή

Ο `for` βρόχος είναι μία από τις πιο συχνά χρησιμοποιούμενες εντολές για να εκτελείς κάποια λογική επανειλημμένα.
Στη JavaScript, αποτελείται από τη λέξη-κλειδί `for`, μια _κεφαλίδα_ μέσα σε παρενθέσεις και ένα μπλοκ κώδικα που περιέχει το _σώμα_ του βρόχου μέσα σε άγκιστρα.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

Η αρχικοποίηση συνήθως ορίζει μια μεταβλητή μετρητή, η συνθήκη ελέγχει αν ο βρόχος πρέπει να συνεχιστεί ή να σταματήσει και το βήμα αυξάνει τον μετρητή στο τέλος κάθε επανάληψης.
Τα επιμέρους τμήματα της κεφαλίδας χωρίζονται μεταξύ τους με ερωτηματικά.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Ο ορισμός του βήματος γίνεται συχνά με τον τελεστή αύξησης ή μείωσης της JavaScript, όπως φαίνεται στο παραπάνω παράδειγμα.
Αυτοί οι τελεστές τροποποιούν μια μεταβλητή επιτόπου.
Το `++` προσθέτει ένα σε έναν αριθμό, το `--` αφαιρεί ένα από έναν αριθμό.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
