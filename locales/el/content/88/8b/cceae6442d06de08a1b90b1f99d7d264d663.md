# Υποδείξεις

## 1. Πάρε την πρώτη κάρτα

- Ο [οδηγός αυτός][destructuring_resource] έχει μια καλή επισκόπηση της σειριακής αποδόμησης. Θα βρεις ένα παράδειγμα δέσμευσης ονομάτων σε τιμές.

## 2. Πάρε τη δεύτερη κάρτα

- Μπορείς να χρησιμοποιήσεις placeholders για να αγνοήσεις μία ή περισσότερες τιμές στη δέσμευση.

## 3. Αντάλλαξε τις δύο πρώτες κάρτες

- Μπορείς να χρησιμοποιήσεις το `&` για να συνδυάσεις τα υπόλοιπα στοιχεία σε μια ακολουθία.

## 4. Απόρριψε την πάνω κάρτα

- Μπορείς να χρησιμοποιήσεις το `:as all` για να δεσμεύσεις ολόκληρο το διάνυσμα στο σύμβολο `all`.

## 5. Εισάγαγε κάρτες με φιγούρες

- Μπορείς να βρεις περισσότερες πληροφορίες για το πού να κάνεις αποδόμηση [εδώ][where-to-destructure].

[destructuring_resource]: https://clojure.org/guides/destructuring#_sequential_destructuring
[where-to-destructure]: https://clojure.org/guides/destructuring#_where_to_destructure
