# Αριθμοί

Η Crystal έχει έναν τύπο, τον `Number`, ο οποίος είναι ο βασικός τύπος για όλους τους αριθμητικούς τύπους.
Μέσα στον τύπο Number υπάρχουν δύο κύριοι υποτύποι: ο [`Int`][int] και ο [`Float`][float].

Το `Int` είναι σύντμηση του integer και αναπαριστά ακέραιους αριθμούς.
Το `Int` μπορεί να είναι και αρνητικό και θετικό, χωρίς υποδιαστολή.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

Το `Float` αναπαριστά αριθμούς με υποδιαστολή.
Τα `Float` μπορούν να είναι και αρνητικά και θετικά.

```crystal
10.5.class
# => Float64
```

## Μετατροπή μεταξύ `Int` και `Float`

Χρησιμοποιώντας τις μεθόδους 'to_i' και 'to_f', μπορείς να μετατρέψεις μεταξύ `Int` και `Float`.
Ο αριθμός στρογγυλοποιείται προς τα κάτω όταν μετατρέπεις από `Float` σε `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Αριθμητικοί τελεστές

Μπορείς να χρησιμοποιήσεις τους [βασικούς αριθμητικούς τελεστές][math] στα `Int` και `Float`.
Οι τελεστές είναι `+`, `-`, `*`, `/` και `%`.
Όταν χρησιμοποιείς αυτούς τους τελεστές, μπορείς να συνδυάζεις `Int` και `Float` όπως θέλεις.

### Πρόσθεση, αφαίρεση και πολλαπλασιασμός

Ο τελεστής `+` χρησιμοποιείται για πρόσθεση, ο τελεστής `-` για αφαίρεση και ο τελεστής `*` για πολλαπλασιασμό.

| Τελεστής | Παράδειγμα     |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Διαίρεση

Η διαίρεση χρησιμοποιείται για να διαιρείς αριθμούς.
Ο τελεστής `/` χρησιμοποιείται για διαίρεση.
Το αποτέλεσμα είναι πάντα ένα Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Σε ορισμένες γλώσσες προγραμματισμού, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι ένα σφάλμα.

Στην Crystal, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι `Infinity` ή `-Infinity`.
Η μόνη εξαίρεση είναι η διαίρεση του μηδενός με το μηδέν, που έχει ως αποτέλεσμα `NaN` (Not a Number).
Το `Infinity` και το `NaN` είναι ειδικές τιμές στον τύπο `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

### Υπόλοιπο

Η πράξη του υπολοίπου χρησιμοποιείται για να βρεις το υπόλοιπο μιας διαίρεσης.
Ο τελεστής `%` χρησιμοποιείται για το υπόλοιπο.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς το υπόλοιπο έχει ως αποτέλεσμα ένα DivisionByZeroError.
Αυτό διαφέρει από την κανονική διαίρεση.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Στρογγυλοποίηση

Η μέθοδος `round` δέχεται ένα προαιρετικό όρισμα: τον αριθμό των δεκαδικών ψηφίων στα οποία θα στρογγυλοποιήσει.
Ο προεπιλεγμένος αριθμός δεκαδικών ψηφίων είναι 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

## Προτεραιότητα και παρενθέσεις

Η Crystal επιτρέπει παρενθέσεις (`()`), οι οποίες μπορούν να χρησιμοποιηθούν για να ομαδοποιήσεις εκφράσεις.
Αυτό είναι χρήσιμο όταν θέλεις να αλλάξεις τη σειρά των πράξεων.

Όταν χρησιμοποιείς πολλούς αριθμητικούς τελεστές, η σειρά των πράξεων είναι ίδια με αυτήν στα μαθηματικά, γνωστή και ως [PEMDAS][pemdas].
Ακολουθεί τη σειρά: παρενθέσεις (`()`), δυνάμεις (`**`), πολλαπλασιασμός (`*`) και διαίρεση (`/`), πρόσθεση (`+`) και αφαίρεση (`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
