# Οδηγίες

Μετά από πρόσφατο έλεγχο ασφαλείας, σου ζητήθηκε να καθαρίσεις τα αρχειοθετημένα αρχεία καταγραφής του οργανισμού.

## 1. Εντόπισε παραμορφωμένες γραμμές καταγραφής

Χρειάζεσαι μια εικόνα για το πόσες γραμμές καταγραφής στο αρχείο σου δεν συμμορφώνονται με τα τρέχοντα πρότυπα.
Πιστεύεις ότι ένας απλός έλεγχος αποκαλύπτει αν μια γραμμή καταγραφής είναι έγκυρη.
Για να θεωρηθεί έγκυρη, μια γραμμή πρέπει να ξεκινά με μία από τις παρακάτω συμβολοσειρές:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

Υλοποίησε τη συνάρτηση `valid_line?/1` ώστε να επιστρέφει `true` αν η γραμμή καταγραφής είναι έγκυρη.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. Χώρισε τη γραμμή καταγραφής

Λίγο αφότου ξεκίνησες το έργο ανάλυσης καταγραφών, συνειδητοποιείς ότι οι καταγραφές μιας εφαρμογής δεν χωρίζονται σε γραμμές όπως οι υπόλοιπες. Σε αυτό το έργο, αυτό που θα έπρεπε να είναι ξεχωριστές γραμμές βρίσκεται αντ' αυτού σε μία μόνο γραμμή, συνδεδεμένο με ιδιόμορφα βελάκια όπως `<--->` ή `<*~*~>`.

Στην πραγματικότητα, οποιαδήποτε συμβολοσειρά έχει πρώτο χαρακτήρα το `<`, τελευταίο χαρακτήρα το `>`, και οποιονδήποτε συνδυασμό από τους παρακάτω χαρακτήρες `~`, `*`, `=`, και `-` στο ενδιάμεσο μπορεί να χρησιμοποιηθεί ως διαχωριστικό στις καταγραφές αυτού του έργου.

Υλοποίησε τη συνάρτηση `split_line/1` που παίρνει μια γραμμή και επιστρέφει μια λίστα από συμβολοσειρές.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Αφαίρεσε τα artifacts από την καταγραφή

Ανακάλυψες ότι κάποια ανάντη επεξεργασία των καταγραφών έχει διασκορπίσει το κείμενο "end-of-line" ακολουθούμενο από έναν αριθμό γραμμής (χωρίς ενδιάμεσο κενό) σε όλες τις καταγραφές.

Υλοποίησε τη συνάρτηση `remove_artifacts/1` ώστε να παίρνει μια συμβολοσειρά, να αφαιρεί κάθε εμφάνιση του κειμένου end-of-line (χωρίς διάκριση πεζών-κεφαλαίων) και να επιστρέφει μια καθαρή γραμμή καταγραφής.

Οι γραμμές που δεν περιέχουν το κείμενο end-of-line πρέπει να επιστρέφονται αμετάβλητες.

Απλώς αφαίρεσε τη συμβολοσειρά end-of-line, δεν χρειάζεται να προσαρμόσεις τα κενά διαστήματα.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. Βάλε ετικέτα στις γραμμές με ονόματα χρηστών

Παρατήρησες ότι κάποιες από τις γραμμές καταγραφής περιλαμβάνουν προτάσεις που αναφέρονται σε χρήστες.
Αυτές οι προτάσεις περιέχουν πάντα τη συμβολοσειρά `"User"`, ακολουθούμενη από έναν ή περισσότερους χαρακτήρες κενού διαστήματος, και έπειτα από ένα όνομα χρήστη.
Αποφασίζεις να βάλεις ετικέτα σε τέτοιες γραμμές.

Υλοποίησε μια συνάρτηση `tag_with_user_name/1` που επεξεργάζεται γραμμές καταγραφής:

- Οι γραμμές που δεν περιέχουν τη συμβολοσειρά `"User"` παραμένουν αμετάβλητες.
- Για τις γραμμές που περιέχουν τη συμβολοσειρά `"User"`, πρόσθεσε στην αρχή της γραμμής το `[USER]` ακολουθούμενο από το όνομα χρήστη.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

Μπορείς να υποθέσεις ότι:

- Κάθε εμφάνιση της συμβολοσειράς `"User"` ακολουθείται από έναν ή περισσότερους χαρακτήρες κενού διαστήματος και το όνομα χρήστη.
- Υπάρχει το πολύ μία εμφάνιση της συμβολοσειράς `"User"` σε κάθε γραμμή.
- Τα ονόματα χρηστών είναι μη κενές συμβολοσειρές που δεν περιέχουν κενό διάστημα.
