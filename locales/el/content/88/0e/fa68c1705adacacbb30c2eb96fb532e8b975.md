# Εισαγωγή

## Κανονικές εκφράσεις

Οι κανονικές εκφράσεις στη Gleam ακολουθούν την προδιαγραφή **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), όπως και άλλες δημοφιλείς γλώσσες, όπως η Java, η JavaScript ή η Ruby.

Το module `gleam/regexp` από το πακέτο `gleam_regexp` προσφέρει συναρτήσεις για να δουλεύεις με κανονικές εκφράσεις.

~~~~exercism/note
Αυτή η άσκηση υποθέτει ότι γνωρίζεις ήδη τη σύνταξη των κανονικών εκφράσεων, συμπεριλαμβανομένων των κλάσεων χαρακτήρων, των ποσοδεικτών, των ομάδων και των συλλήψεων.

Αν θέλεις να ανανεώσεις τις γνώσεις σου για τις κανονικές εκφράσεις, ρίξε μια ματιά σε μία από αυτές τις πηγές: [Regular-Expressions.info](https://www.regular-expressions.info), [Rex Egg](https://www.rexegg.com/), [RegexOne](https://regexone.com/), [Regular Expressions 101](https://regex101.com/), [RegExr](https://regexr.com/).
~~~~

Ο πιο συνηθισμένος τρόπος για να δημιουργήσεις κανονικές εκφράσεις είναι να χρησιμοποιήσεις τη συνάρτηση `regexp.from_string`.

```gleam
let assert Ok(re) = regexp.from_string("test")
```

Οι συναρτήσεις δημιουργίας κανονικών εκφράσεων επιστρέφουν ένα σφάλμα αν η σύνταξη της κανονικής έκφρασης δεν είναι έγκυρη, οπότε εδώ έχει χρησιμοποιηθεί ένα let-assertion για να διασφαλιστεί ότι η κανονική έκφραση είναι έγκυρη.

Η συνάρτηση `regexp.check` μπορεί να χρησιμοποιηθεί για να ελέγξεις αν μια κανονική έκφραση ταιριάζει με μια συμβολοσειρά.

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### Συλλήψεις

Αν θέλεις να συλλάβεις υποσυμβολοσειρές με μια κανονική έκφραση, μπορείς να χρησιμοποιήσεις τη συνάρτηση `regexp.scan`, η οποία επιστρέφει μια λίστα με αντιστοιχίσεις.

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### Τροποποιητές

Μπορείς να τροποποιήσεις τη συμπεριφορά μιας κανονικής έκφρασης, δημιουργώντας την με τη συνάρτηση `regexp.compile` και περνώντας της επιλογές.

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
