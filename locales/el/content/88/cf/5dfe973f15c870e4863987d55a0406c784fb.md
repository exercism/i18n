# Πόροι

## Μάθηση

- [Nim basics](https://narimiran.github.io/nim-basics/) - για αρχάριους προγραμματιστές.
- [Nim tutorial, part 1](https://nim-lang.org/docs/tut1.html) - για όσους έχουν ήδη κάποια εμπειρία στον προγραμματισμό.
- [Learn X in Y minutes for Nim](https://learnxinyminutes.com/docs/nim/) - μια επισκόπηση της σύνταξης.
- [Nim for Python programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-Python-Programmers)
- [Nim for C programmers](https://github.com/nim-lang/Nim/wiki/Nim-for-C-programmers)
- [Nim in Action](https://www.manning.com/books/nim-in-action) - διαθέσιμο ως έντυπο βιβλίο ή ως eBook.

Δες την επίσημη σελίδα [Learn Nim](https://nim-lang.org/learn.html) για περισσότερα.

## Τεκμηρίωση

- [Nim Manual](https://nim-lang.org/docs/manual.html) - οι προδιαγραφές της γλώσσας Nim.
- [Searchable index](https://nim-lang.org/docs/theindex.html)

Δες την επίσημη σελίδα [Nim Documentation](https://nim-lang.org/documentation.html) για περισσότερα.
