# Εισαγωγή

Οι έξυπνοι δείκτες στη Cairo είναι προηγμένες δομές δεδομένων που εξασφαλίζουν ασφαλή και αποδοτική διαχείριση μνήμης, προσθέτοντας χαρακτηριστικά ασφάλειας στους συνηθισμένους δείκτες και αποτρέποντας κοινά προβλήματα, όπως η αποαναφορά μηδενικών δεικτών ή η πρόσβαση σε μη αρχικοποιημένη μνήμη.

## Τι είναι ένας έξυπνος δείκτης;

Ένας έξυπνος δείκτης συμπεριφέρεται σαν έναν συνηθισμένο δείκτη, αλλά παρακολουθεί την ιδιοκτησία και εξασφαλίζει ασφαλή πρόσβαση στη μνήμη, αποτρέποντας προβλήματα όπως η αποαναφορά μηδενικών ή εκκρεμών δεικτών.

## Τύποι έξυπνων δεικτών

Η Cairo παρέχει αρκετούς τύπους έξυπνων δεικτών, όπως οι `Box<T>` και `Nullable<T>`:

- **`Box<T>`**: Αποθηκεύει δεδομένα σε ένα ειδικό τμήμα μνήμης, ιδανικό για μεγάλα δεδομένα ή δεδομένα δυναμικού μεγέθους.
                Επιτρέπει τη μεταφορά ιδιοκτησίας χωρίς αντιγραφή των δεδομένων.
- **`Nullable<T>`**: Δείχνει είτε σε μια έγκυρη τιμή τύπου `T` είτε στο `null`, χρήσιμος για τον χειρισμό προαιρετικών τιμών.

## Ασφάλεια μνήμης

Οι έξυπνοι δείκτες βοηθούν στην αποτροπή μη ασφαλούς πρόσβασης στη μνήμη, εξασφαλίζοντας ότι η μνήμη αποδεσμεύεται αυτόματα όταν δεν χρειάζεται πλέον, μειώνοντας έτσι τον κίνδυνο διαρροών μνήμης.

### Παράδειγμα: Χρήση του `Box<T>` για αναδρομικούς τύπους

Οι έξυπνοι δείκτες όπως ο `Box<T>` επιτρέπουν τον ασφαλή χειρισμό αναδρομικών τύπων, όπως σε ένα δυαδικό δέντρο, δεσμεύοντας μνήμη αποδοτικά και αποφεύγοντας την άπειρη αναδρομή.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Οφέλη στην απόδοση

Οι έξυπνοι δείκτες βελτιώνουν την απόδοση περνώντας αναφορές στα δεδομένα αντί να αντιγράφουν μεγάλες δομές, μειώνοντας την επιβάρυνση της μνήμης.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
