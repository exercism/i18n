# Εισαγωγή

Οι χαρακτήρες στη Factor είναι ακέραιοι, δηλαδή σημεία κώδικα Unicode, οπότε οι αριθμητικοί τελεστές `<`, `>`, `=` σου δίνουν απευθείας ταξινόμηση με διάκριση πεζών-κεφαλαίων. Το λεξιλόγιο [`unicode`][unicode] προσθέτει κατηγορήματα που γνωρίζουν το Unicode και μετατροπή πεζών-κεφαλαίων για έναν μεμονωμένο χαρακτήρα.

## Κατηγορήματα χαρακτήρων

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Μετατροπή πεζών-κεφαλαίων

Τα `ch>upper` και `ch>lower` μετατρέπουν έναν μεμονωμένο χαρακτήρα από πεζό σε κεφαλαίο και αντίστροφα. Τα `>upper` και `>lower`, που λειτουργούν σε επίπεδο συμβολοσειράς, τα εφαρμόζουν σε κάθε χαρακτήρα της συμβολοσειράς.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
