# Εισαγωγή

Μερικές φορές ένα συγκεκριμένο κομμάτι κώδικα χρειάζεται να χρησιμοποιηθεί πάνω από μία φορά. Αν συμβαίνει αυτό, μπορεί να είναι βολικό να βάλεις τον κώδικα μέσα σε μια συνάρτηση. Μια συνάρτηση συνήθως εκτελεί μόνο μία συγκεκριμένη ενέργεια. Στη Rust, η λέξη-κλειδί ```fn``` χρησιμοποιείται για να ορίσεις συναρτήσεις. Ο κώδικας που ανήκει στη συνάρτηση βρίσκεται πάντα ανάμεσα σε άγκιστρα (δηλαδή `{}`). Η συνάρτηση με το όνομα `main` είναι ξεχωριστή, γιατί είναι το σημείο εισόδου των προγραμμάτων. Από αυτή τη συνάρτηση μπορείς να καλέσεις άλλες συναρτήσεις.

```rust
fn say_my_name(name: &str) -> &str {
    name
}
```

Οι συναρτήσεις μπορούν επίσης να δέχονται παραμέτρους, όπως ```name: &str``` στην ```say_my_name()```. Οι συναρτήσεις μπορούν επίσης να επιστρέφουν τιμές, όπως το `-> &str` παραπάνω.
