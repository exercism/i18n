# Ταξινόμηση

Το να βάζεις πράγματα σε σειρά είναι αρκετά συνηθισμένο, ώστε η βιβλιοθήκη να το κάνει για σένα.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

Το `sort` δουλεύει σε οτιδήποτε ξέρει ήδη να συγκρίνει τον εαυτό του. Οι αριθμοί και οι συμβολοσειρές το κάνουν, γιατί έχουν ένα `is_lt`.

## Ταξινόμηση με τον δικό σου κανόνα

Οι περισσότερες σειρές δεν είναι η ενσωματωμένη. Η κατάταξη στο νέτμπολ δεν είναι αλφαβητική ούτε με βάση το μήκος του ονόματος: είναι με βάση τους βαθμούς και μετά με βάση τη διαφορά τερμάτων για τις ομάδες που ισοβαθμούν. Δεν υπάρχει τρόπος να το μαντέψει αυτό το `ARRAY`.

Έτσι, δίνεις εσύ τη σειρά, ως δεσμευμένη ρουτίνα:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

Το `insertion_sort_by` παίρνει ένα `ROUT{T,T}:BOOL`, μια ρουτίνα που παίρνει δύο από τα πράγματα που ταξινομούνται και απαντά αν το πρώτο πάει πριν από το δεύτερο. Καλεί αυτή τη ρουτίνα όσες φορές χρειάζεται και βάζει τον πίνακα στη σειρά που υποδηλώνουν οι απαντήσεις.

Γι' αυτό χρησίμευε το `understudy`. Η βιβλιοθήκη ξέρει να ταξινομεί και δεν ξέρει τίποτα για τη δική σου αντίληψη της σειράς· η δεσμευμένη ρουτίνα είναι εκεί όπου συναντιούνται τα δύο.

## Γράφοντας τη σύγκριση

Η ρουτίνα απαντά **αληθής όταν το πρώτο όρισμα έρχεται πρώτο**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Για έναν κανόνα με περισσότερα από ένα μέρη, χειρίσου τα μέρη με σειρά σημασίας:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

Το πρώτο `if` το ξεκαθαρίζει όποτε διαφέρουν οι βαθμοί. Μόνο όταν είναι ίσοι έχει λόγο και η δεύτερη γραμμή. Αν έγραφες πρώτα το κριτήριο ισοπαλίας, οι βαθμοί δεν θα είχαν ποτέ σημασία.

## Η ταξινόμηση αλλάζει τον πίνακα

Το `insertion_sort_by` βάζει τον ίδιο τον πίνακα σε σειρά και δεν απαντά τίποτα:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Αν η αρχική σειρά έχει σημασία, ταξινόμησε ένα αντίγραφο:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
