# Σχετικά

Η [Ballerina](https://ballerina.io/) είναι μια μεταγλωττισμένη, συναλλακτική, στατικά και ισχυρά τυποποιημένη γλώσσα προγραμματισμού με σύνταξη κειμένου και γραφικών. Η Ballerina ενσωματώνει θεμελιώδεις έννοιες της ολοκλήρωσης κατανεμημένων συστημάτων στη γλώσσα και προσφέρει ένα ασφαλές ως προς τους τύπους, ταυτόχρονο περιβάλλον για την υλοποίηση μικροϋπηρεσιών με κατανεμημένες συναλλαγές, αξιόπιστη ανταλλαγή μηνυμάτων, επεξεργασία ροών και ροές εργασίας.

Η Ballerina είναι μια γλώσσα σχεδιασμένη ώστε η ολοκλήρωση να είναι απλή. Βασισμένη στις αλληλεπιδράσεις των διαγραμμάτων ακολουθίας, η Ballerina έχει ενσωματωμένη υποστήριξη για κοινά μοτίβα ολοκλήρωσης και συνδέσμους, όπως κατανεμημένες συναλλαγές, αντιστάθμιση και διακόπτες κυκλώματος. Με υποστήριξη πρώτης κατηγορίας για JSON και XML, η Ballerina κάνει απλή και αποτελεσματική τη δημιουργία ισχυρής ολοκλήρωσης σε τερματικά σημεία δικτύου.
