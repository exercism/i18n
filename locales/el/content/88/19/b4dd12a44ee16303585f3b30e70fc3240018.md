# Boolean

Η Swift έχει έναν τύπο γνωστό ως [`Bool`][bools], ο οποίος χρησιμοποιείται για να αναπαριστά τις τιμές `true` και `false`.

## Λογικοί τελεστές

Η Swift έχει 3 [λογικούς τελεστές (`!`, `||`, `&&`)][logical-operators] που χρησιμοποιούνται για να συνδυάζουν Bool και να φτιάχνουν εκφράσεις που παράγουν διαφορετικές τιμές.

### Και(`&&`)

Ο [_τελεστής και_][and] στη Swift αναπαρίσταται με `&&` και επιστρέφει `true` αν και οι δύο τιμές που δίνονται είναι `true`, αλλιώς επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _και_, ένα Bool τοποθετείται στη δεξιά πλευρά του `&&` και ένα άλλο στην αριστερή πλευρά.

```Swift
true && true  // true
true && false // false
```

### Ή(`||`)

Ο [_τελεστής ή_][or] στη Swift αναπαρίσταται με `||` και επιστρέφει `true` αν **τουλάχιστον μία** από τις τιμές που δίνονται είναι `true`. Αν και οι δύο τιμές είναι `false`, τότε επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _ή_, ένα bool πρέπει να τοποθετείται στη δεξιά πλευρά του `||` και ένα άλλο στην αριστερή πλευρά.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Όχι(`!`)

Ο [_τελεστής όχι_][not] στη Swift αναπαρίσταται με `!` και επιστρέφει `true` αν το Bool που δίνεται είναι `false`, και επιστρέφει `false` αν δοθεί `true`.
Όταν χρησιμοποιείς τον τελεστή _όχι_, ένα Bool πρέπει να τοποθετείται μετά τον τελεστή (`!`).

```swift
!true  // false
!false // true
```

## Χρήση παρενθέσεων(`()`)

Όταν δουλεύεις με booleans, μπορείς να χρησιμοποιήσεις [ρητές παρενθέσεις][explicit-parentheses] για να αποφασίσεις ποια Bool θα αξιολογηθούν πρώτα.
Το αποτέλεσμα μπορεί να διαφέρει ανάλογα με το πώς χρησιμοποιούνται οι παρενθέσεις.
Στη Swift, ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Εφόσον ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα, στο παρακάτω παράδειγμα ο τελεστής _όχι_ εφαρμόζεται στην έκφραση μέσα στις παρενθέσεις.

```Swift
!true && false   // false
!(true && false) // true
```
