# Εισαγωγή του ANSI με :except

Οι οδηγίες αναφέρουν το εξής: "Σκοπεύεις να προσθέσεις υποστήριξη για άλλα χρώματα αυτοκινήτων, οπότε θέλεις να εισαγάγεις ολόκληρο το module", χωρίς τη συνάρτηση `color` που έρχεται σε σύγκρουση. Για να το κάνεις αυτό, χρησιμοποίησε την επιλογή `:except` ως εξής:

```elixir
import IO.ANSI, except: [color: 1]
```
