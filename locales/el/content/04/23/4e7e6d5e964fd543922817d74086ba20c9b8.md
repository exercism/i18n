# Μεταβλητότητα

Η μεταβλητότητα είναι μια ιδιότητα μιας συγκεκριμένης δέσμευσης στη Rust. Μια δέσμευση είναι είτε αμετάβλητη είτε μεταβλητή. Η τιμή μιας αμετάβλητης δέσμευσης δεν μπορεί να αλλάξει· η τιμή μιας μεταβλητής δέσμευσης μπορεί να αλλάξει. Όλες οι δεσμεύσεις είναι αμετάβλητες εξ ορισμού.

## Δεσμεύσεις

Μια δέσμευση είναι η συσχέτιση ανάμεσα σε ένα συγκεκριμένο όνομα μεταβλητής όπως εμφανίζεται στον πηγαίο κώδικα και σε μια συγκεκριμένη περιοχή μνήμης όπως εμφανίζεται κατά την εκτέλεση. Αυστηρά μιλώντας, οι δεσμεύσεις υπάρχουν μόνο κατά τη μεταγλώττιση: πριν από τη μεταγλώττιση δεν έχει πραγματικά δεσμευτεί μνήμη, και μετά τη μεταγλώττιση ο κώδικας μηχανής ασχολείται αποκλειστικά με διευθύνσεις μνήμης αντί για ονομασμένες μεταβλητές.

Οι δεσμεύσεις συνήθως δημιουργούνται με τη λέξη-κλειδί `let`. Επιπλέον, δεσμεύσεις δημιουργούνται από παραμέτρους συναρτήσεων και σε ορισμένες άλλες περιπτώσεις.

Οι δεσμεύσεις μπορούν να έχουν διάφορες ιδιότητες, η σημαντικότερη από τις οποίες είναι η μεταβλητότητα. Μια μεταβλητή δέσμευση είναι εκείνη για την οποία είναι νόμιμο να αλλάξει η τιμή της δεσμευμένης μνήμης. Η Rust παρακολουθεί και επιβάλλει αυστηρά τη μεταβλητότητα κάθε δέσμευσης, ώστε να συμβάλλει στη διασφάλιση της ορθότητας των προγραμμάτων, απορρίπτοντας προγράμματα που επιχειρούν εσφαλμένα να τροποποιήσουν μια δέσμευση που θα έπρεπε να είναι αμετάβλητη.

## Μεταβλητότητα

Στην πράξη, η μεταβλητότητα είναι συχνά απλή. Χρησιμοποιώντας τη λέξη-κλειδί `mut` στον ορισμό της δέσμευσης, αποκτάς τη δυνατότητα να αλλάξεις την τιμή.

```rust,ignore
let x = 1;
// this does not compile because `x` is immutable
x = 2;
```

```rust
let mut x = 1;
x = 2;
// 🎉🎆🎉🎆🎉
```

### Υποβιβασμός από Μεταβλητή σε Αμετάβλητη

Μια δέσμευση μπορεί πάντα να υποβιβαστεί από μεταβλητή σε αμετάβλητη. Αυτή η λειτουργία είναι διαφανής.

```rust
fn debug(n: i32) {
    dbg!(n);
}

fn main() {
    let mut x = 1;
    x += 2;
    debug(x);                // emits "n = 3"
}
```

### Προαγωγή από Αμετάβλητη σε Μεταβλητή

Γενικά, είναι δυνατό να προαχθεί μια τιμή από αμετάβλητη σε μεταβλητή οποιαδήποτε στιγμή μεταφέρεται η ιδιοκτησία.

```rust
let x = "hello".to_string();
let mut y = x;               // (1)
y += ", world";
dbg!(y);
```

Στο `(1)`, η ιδιοκτησία της συμβολοσειράς μεταφέρεται από το `x` στο `y`, κάτι που μας επιτρέπει να προάγουμε την τιμή σε μεταβλητή.

### Μεταβλητότητα στις Παραμέτρους Συναρτήσεων

Υπάρχουν δύο διαφορετικοί τρόποι για να είναι μεταβλητές οι παράμετροι μιας συνάρτησης. Ο πρώτος και πιο συνηθισμένος μοιάζει με το πέρασμα με αναφορά στη C:

```rust
fn increment(n: &mut i32) {  // (1)
    *n += 1;
}

fn main() {
    let mut x = 1;           // (2)
    increment(&mut x);       // (3)
    dbg!(x);                 // emits "x = 2"
}
```

Σε αυτό το παράδειγμα, η μεταβλητότητα επισημάνθηκε ρητά σε τρία σημεία. Και οι τρεις δηλώσεις μεταβλητότητας απαιτούνται για να λειτουργήσουν οι μεταβλητές αναφορές.
Στο `(2)`, η δέσμευση `x` δηλώνεται ως μεταβλητή. Αυτή η δέσμευση είναι ο κορυφαίος κάτοχος της τιμής.
Στο `(3)`, αυτή η τιμή δανείζεται μεταβλητά, για να περαστεί στη συνάρτηση `increment`.
Στο `(1)`, δημιουργείται μια νέα, μεταβλητή δέσμευση `n` στην κατάλληλη αναφορά.

Υπάρχει και ένα άλλο στυλ μεταβλητότητας παραμέτρων, λιγότερο συνηθισμένο αλλά μερικές φορές ακόμα χρήσιμο. Σε αυτό το στυλ, η τιμή είναι ιδιοκτησία, αλλά η δέσμευση είναι μεταβλητή.

```rust
fn increment_internally(mut n: i32) {   // (1)
    n += 1;
    dbg!(n);                            // emits "n = 2"
}

fn main() {
    let x = 1;                          // (2)
    increment_internally(x);            // (3)
    dbg!(x);                            // emits "x = 1"
}
```

Αυτό το παράδειγμα απαιτεί λιγότερες ρητές επισημάνσεις, γιατί στην πραγματικότητα είναι μια μεταφορά ιδιοκτησίας με ενσωματωμένη προαγωγή μεταβλητότητας. Λειτουργεί επειδή το `i32` είναι τύπος `Copy` που αντιγράφει δεδομένα διαφανώς.
Στο `(1)` δηλώνουμε ότι η `increment_internally` δέχεται ένα μεταβλητό, ιδιοκτησιακό `i32` με όνομα `n` ως παράμετρό της.
Στο `(2)` δηλώνουμε ότι το `x` είναι αμετάβλητη δέσμευση στην τιμή `1`.
Στο `(3)` το `x` αντιγράφεται σε μια νέα θέση στη μνήμη. Το `x` παραμένει αμετάβλητο. Το `n` είναι μεταβλητό.

Είναι φυσικά δυνατό να συνδυάσεις τις μορφές, δίνοντας μια μεταβλητή δέσμευση σε μια μεταβλητή αναφορά (`mut n: &mut i32` κ.λπ.), αλλά σπάνια αυτό είναι όντως το επιθυμητό.

### Μεταβλητότητα Χωρίς `let`

Αρκετές κατασκευές στη Rust (`if let`, `match`, κ.λπ.) μπορούν επίσης να δημιουργήσουν δεσμεύσεις. Αυτές οι δεσμεύσεις μπορούν επίσης να είναι μεταβλητές.

```rust
fn maybe_increment(n: &mut Option<i32>) {
    if let Some(ref mut n) = n {
        *n += 1;
    }
}

fn main() {
    for mut v in [Some(1), None] {
        maybe_increment(&mut v);
        dbg!(v);
    }
}
```

Αυτό το παράδειγμα παράγει πρώτα `v = Some(2)` και μετά `v = None`.

## Επισκίαση

Είναι δυνατό, και συχνά ιδιωματικό, να ξαναχρησιμοποιήσεις ένα όνομα μεταβλητής καθώς μια συγκεκριμένη τιμή μετασχηματίζεται, δηλώνοντάς το ξανά με πολλαπλές κλήσεις `let`. Αυτό είναι γνωστό ως επισκίαση.

```rust
let s = "my string";
let s = s.to_uppercase();
dbg!(s);                               // emits "s = MY STRING"
let s = s.split_whitespace().count();
dbg!(s);                               // emits "s = 2"
```

Ωστόσο, αυτό δεν είναι περίπτωση μεταβλητότητας· οι αρχικές τιμές καταρχήν υπάρχουν ακόμα. Δεδομένων τύπων που δεν είναι `Drop`, ο μεταγλωττιστής μπορεί να επιλέξει να μεταβάλει μια θέση μνήμης αντί να δεσμεύσει μια νέα. Ωστόσο, δεν θα το κάνει ποτέ αυτό για έναν τύπο `Drop` ή αν η παλιά δέσμευση χρησιμοποιηθεί ξανά.

```rust
let x = 1;

// creating a scope like this forces bindings created internally to drop
// when the scope is exited
{
    let x = 10;
    dbg!(x);                   // emits "x = 10"
}

dbg!(x);                       // emits "x = 1"
```
