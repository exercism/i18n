# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο να κρατάς τα υψηλά σκορ για το πιο δημοφιλές παιχνίδι στην τοπική αίθουσα παιχνιδιών.

## 1. Όρισε έναν νέο map υψηλών σκορ

Για να φτιάξεις έναν νέο map υψηλών σκορ, όρισε τη συνάρτηση `HighScore.new/0`, η οποία δεν παίρνει κανένα όρισμα και επιστρέφει έναν νέο, κενό map υψηλών σκορ.

```elixir
HighScore.new()
# => %{}
```

## 2. Πρόσθεσε παίκτες στον map υψηλών σκορ

Για να προσθέσεις έναν παίκτη στον map υψηλών σκορ, όρισε τη συνάρτηση `HighScore.add_player/3`, η οποία παίρνει 3 ορίσματα:

- Το πρώτο όρισμα είναι ο map με τα σκορ.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά.
- Το τρίτο όρισμα είναι το σκορ ως ακέραιος αριθμός. Το όρισμα είναι προαιρετικό, υλοποίησε το τρίτο όρισμα με προεπιλεγμένη τιμή 0.

Αποθήκευσε το προεπιλεγμένο αρχικό σκορ σε ένα χαρακτηριστικό ενότητας. Θα το χρειαστείς ξανά.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Αφαίρεσε παίκτες από τον map υψηλών σκορ

Για να αφαιρέσεις έναν παίκτη από τον map υψηλών σκορ, όρισε τη συνάρτηση `HighScore.remove_player/2`, η οποία παίρνει 2 ορίσματα:

- Το πρώτο όρισμα είναι ο map με τα σκορ.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Επανάφερε το σκορ ενός παίκτη

Για να επαναφέρεις το σκορ ενός παίκτη, όρισε τη συνάρτηση `HighScore.reset_score/2`, η οποία παίρνει 2 ορίσματα:

- Το πρώτο όρισμα είναι ο map με τα σκορ.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου το σκορ θέλεις να επαναφέρεις.

Η συνάρτηση θα πρέπει να δουλεύει και αν ο παίκτης δεν έχει σκορ.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Ενημέρωσε το σκορ ενός παίκτη

Για να ενημερώσεις το σκορ ενός παίκτη προσθέτοντας στο προηγούμενο σκορ, όρισε τη συνάρτηση `HighScore.update_score/3`, η οποία παίρνει 3 ορίσματα:

- Το πρώτο όρισμα είναι ο map με τα σκορ.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου το σκορ θέλεις να ενημερώσεις.
- Το τρίτο όρισμα είναι το σκορ που θέλεις να **προσθέσεις** στο αποθηκευμένο υψηλό σκορ.

Η συνάρτηση θα πρέπει να δουλεύει και αν ο παίκτης δεν έχει προηγούμενο σκορ - υπέθεσε ότι το προηγούμενο σκορ είναι 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Πάρε μια λίστα με παίκτες

Για να πάρεις μια λίστα με παίκτες, όρισε τη συνάρτηση `HighScore.get_players/1`, η οποία παίρνει 1 όρισμα:

- Το πρώτο όρισμα είναι ο map με τα σκορ.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
