# Γεννήτριες test

Η διαδρομή C# χρησιμοποιεί μια [γεννήτρια test](https://exercism.org/docs/building/tooling/test-generators) για να δημιουργεί αυτόματα τα test των ασκήσεων εξάσκησης.
Εκμεταλλεύεται το γεγονός ότι οι περισσότερες ασκήσεις που ορίζονται στο [αποθετήριο problem-specifications](https://github.com/exercism/problem-specifications/) έχουν επίσης ένα αρχείο `canonical-data.json`, το οποίο περιέχει τυποποιημένες εισόδους και εξόδους test που μπορούν να χρησιμοποιηθούν για την υλοποίηση της άσκησης.

## Βήματα

Για να δημιουργήσει τα test μιας άσκησης εξάσκησης, η γεννήτρια test:

1. Διαβάζει τις περιπτώσεις test της άσκησης από το αρχείο `canonical-data.json` της
2. Χρησιμοποιεί το αρχείο `tests.toml` για να παραλείψει τις εξαιρούμενες περιπτώσεις test
3. Αποδίδει τις περιπτώσεις test χρησιμοποιώντας το πρότυπο γεννήτριας της άσκησης
4. Μορφοποιεί το αποδοθέν πρότυπο χρησιμοποιώντας το Roslyn
5. Γράφει το μορφοποιημένο πρότυπο στο αρχείο test της άσκησης

### Βήμα 1: ανάγνωση του αρχείου `canonical-data.json`

Η γεννήτρια test αναλύει τις περιπτώσεις test από το `canonical-data.json` της άσκησης χρησιμοποιώντας τον [χώρο ονομάτων System.Text.Json](https://learn.microsoft.com/en-us/dotnet/api/system.text.json).

Επειδή κάποια κανονικά δεδομένα χρησιμοποιούν εμφώλευση, η περίπτωση test που προκύπτει από την ανάλυση περιλαμβάνει ένα επιπλέον πεδίο `path`, το οποίο περιέχει τις ιδιότητες `description` τυχόν γονικών στοιχείων, καθώς και την ίδια την ιδιότητα `description` της περίπτωσης test.

### Βήμα 2: παράλειψη των εξαιρούμενων test από το αρχείο `tests.toml`

Κάθε άσκηση έχει ένα αρχείο `tests.toml`, στο οποίο μεμονωμένα test μπορούν να εξαιρεθούν/απενεργοποιηθούν.
Η γεννήτρια test αφαιρεί όλες τις περιπτώσεις test που είναι σημασμένες ως εξαιρούμενες (`include = false`).

### Βήμα 3: απόδοση των περιπτώσεων test

Στη συνέχεια, οι περιπτώσεις test (ενδεχομένως μετασχηματισμένες) περνούν στο αρχείο `.meta/Generator.tpl`, το οποίο ορίζει πώς πρέπει να αποδοθούν τα test με βάση αυτές τις περιπτώσεις.

### Βήμα 4: μορφοποίηση του αποδοθέντος προτύπου με το Roslyn

Στη συνέχεια, το αποδοθέν πρότυπο μορφοποιείται με το [Roslyn](https://github.com/dotnet/roslyn).
Αυτό έχει τα εξής πλεονεκτήματα:

- Οι ασκήσεις μορφοποιούνται με συνέπεια
- Δεν χρειάζεται να ανησυχείς πολύ για τα κενά και τη στοίχιση όταν γράφεις πρότυπα

### Βήμα 5: εγγραφή του αποδοθέντος προτύπου στο αρχείο test της άσκησης

Τέλος, η έξοδος του αποδοθέντος προτύπου γράφεται στο αρχείο test της άσκησης.

## Πρότυπα

Τα πρότυπα αποδίδονται χρησιμοποιώντας τη [βιβλιοθήκη Scriban](https://github.com/scriban/scriban/).

## Διεπαφή γραμμής εντολών

Υπάρχουν δύο τρόποι για να εκτελεστεί η γεννήτρια test:

1. `bin/update-tests.ps1`: ενημερώνει τα test για όλες τις ασκήσεις που έχουν πρότυπο γεννήτριας
2. `bin/update-tests.ps1 -e <slug>`: ενημερώνει τα test για τη συγκεκριμένη άσκηση, αν έχει πρότυπο γεννήτριας
