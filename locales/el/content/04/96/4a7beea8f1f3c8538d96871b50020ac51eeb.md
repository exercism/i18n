# δεν χρησιμοποιούνται προεπιλεγμένα ορίσματα

Κανένα [προεπιλεγμένο όρισμα][default argument] δεν χρησιμοποιείται στον ορισμό της συνάρτησης αυτής της λύσης.
Τα [προεπιλεγμένα ορίσματα στην Python][default arguments in python] μπορούν να σε βοηθήσουν να προστατευτείς από περιπτώσεις όπου μια συνάρτηση καλείται χωρίς το αναμενόμενο όρισμα ή όπου δεν υπάρχει διαθέσιμο όρισμα για να περάσεις.
Τα `Default arguments` μπορούν επίσης να βοηθήσουν να αποφύγεις περιττό κώδικα υπό συνθήκη ή περιττούς ελέγχους μέσα σε μια συνάρτηση.

Αυτή η λύση μπορεί να βελτιωθεί αν αξιοποιήσεις ένα `default argument` σε συνδυασμό είτε με [str.format][str.format] είτε με [f-strings][f-strings] (_γνωστά και ως "formatted string literals" ή "interpolated strings"_).

Το [String Formatting in Python][string formatting in python] από το Real Python μπορεί να είναι ένα καλό σημείο εκκίνησης για να μάθεις για τις επιλογές μορφοποίησης συμβολοσειρών της Python.
