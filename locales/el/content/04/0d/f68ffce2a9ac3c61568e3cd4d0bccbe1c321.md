# Εικονική κεφαλίδα

## Βιβλιοθήκη συναρτήσεων

Αυτή είναι η πρώτη άσκηση που συναντάμε όπου η λύση που γράφουμε δεν είναι ένα σενάριο "main". Γράφουμε μια βιβλιοθήκη που θα γίνεται "source" σε άλλα σενάρια που θα καλούν τις συναρτήσεις μας.

### Bash namerefs

Αυτή η άσκηση απαιτεί τη χρήση μεταβλητών `nameref`. Αυτό απαιτεί έκδοση bash τουλάχιστον 4.0. Αν χρησιμοποιείς την προεπιλεγμένη έκδοση bash στο MacOS, θα χρειαστεί να εγκαταστήσεις μια άλλη έκδοση: δες [Εγκατάσταση του Bash](https://exercism.io/tracks/bash/installation)

Τα namerefs είναι ένας τρόπος να περάσεις μια μεταβλητή σε μια συνάρτηση _κατ' αναφορά_. Έτσι, η μεταβλητή μπορεί να τροποποιηθεί μέσα στη συνάρτηση και η ενημερωμένη τιμή είναι διαθέσιμη στο πεδίο κλήσης. Να ένα παράδειγμα:
```bash
prependElements() {
    local -n __array=$1
    shift
    __array=( "$@" "${__array[@]}" )
}

my_array=( a b c )
echo "before: ${my_array[*]}"    # => before: a b c

prependElements my_array d e f
echo "after: ${my_array[*]}"     # => after: d e f a b c
```
