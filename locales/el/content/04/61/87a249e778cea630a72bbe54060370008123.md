# Εντολή switch

Η εντολή `switch` διευκολύνει τη συγγραφή μιας δομής ελέγχου υπό συνθήκη `if..elseif..else`.

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      $message = 'First letter of the english alphabet';
      break;
    case 'z':
      $message = 'Last letter of the english alphabet';
      break;
    case 'l':
    default:
      $message = 'A letter, neither the first nor the last of the alphabet';
  }
  return $message;
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Ένα ξεχωριστό χαρακτηριστικό των εντολών `switch` είναι η συμπεριφορά "fall-through" κάθε `case`.
Πρόσεξε στο παράδειγμα τη συγκεκριμένη θέση των εντολών `break`.
Χωρίς εντολή `break`, κάθε `case` θα εκτελεστεί από την αρχή του πρώτου `case` μέχρι να αξιολογηθεί μια εντολή `break`.
Η σειρά των εντολών `case` μέσα σε ένα `switch` έχει σημασία, γιατί αξιολογούνται μόνο τα `case` μέχρι το πρώτο που ταιριάζει.

> Μια προειδοποίηση: Η συμπεριφορά "fall-through" διευκολύνει τον διαμοιρασμό κώδικα ανάμεσα σε παρόμοια `case`, αλλά μπορεί επίσης να γίνει πηγή ανεπιθύμητης συμπεριφοράς και bugs αν ξεχαστεί η εντολή `break`.

Κάθε `case` εκτελεί μια μη αυστηρή (χαλαρή) σύγκριση:

```php
function matches($value): string
{
  switch ($value) {
    case false:
      return 'matches false';
    case true:
      return 'matches true';
  }
}

// matches([]) => 'matches false'
// matches(0) => 'matches false'
// matches(null) => 'matches false'
// matches('') => 'matches false'

// matches([1]) => 'matches true'
// matches(1) => 'matches true'
// matches('a') => 'matches true'
```

## Μοτίβο switch χωρίς break

Ας υποθέσουμε ότι η παραπάνω συνάρτηση του παραδείγματος ξαναγράφεται:

```php
function getMessage(string $letter): string
{
  switch ($letter) {
    case 'a':
      return 'First letter of the english alphabet';
    case 'z':
      return 'Last letter of the english alphabet';
    case 'l':
    default:
      return 'A letter, neither the first nor the last of the alphabet';
  }
}

// getMessage('a') => 'First letter of the english alphabet'
// getMessage('z') => 'Last letter of the english alphabet'
// getMessage('l') => 'A letter, neither the first nor the last of the alphabet'
// getMessage('k') => 'A letter, neither the first nor the last of the alphabet'
```

Η συμπεριφορά της συνάρτησης παραμένει ίδια, αλλά η απευθείας επιστροφή από την εντολή switch αποφεύγει την πιθανή παράλειψη της εντολής `break`.

## Μοτίβο switch με έκφραση συνθήκης

Ένα άλλο μοτίβο χρήσης της εντολής switch είναι να συγκρίνεις κάθε case χρησιμοποιώντας μια έκφραση:

```php
function compareSum(int $sum): string
{
  switch (true) {
    case $sum < 10:
      return 'Less than 10';
    case $sum > 10:
      return 'More than 10';
    default:
      return 'Sum is 10';
  }
}
```

Αυτό δίνει κάποια ευελιξία για να γράψεις πιο ποικίλες εκφράσεις και να συνθέσεις συναρτήσεις όταν αξιολογείς ποιον κλάδο `case` θα εκτελέσεις.
