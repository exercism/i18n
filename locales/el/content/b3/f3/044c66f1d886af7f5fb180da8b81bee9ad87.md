# Οδηγίες

Αναδιαμόρφωσε έναν αναλυτή Markdown.

Η άσκηση Markdown είναι μια άσκηση αναδιαμόρφωσης.
Υπάρχει κώδικας που αναλύει μια δεδομένη συμβολοσειρά με [σύνταξη Markdown][markdown] και επιστρέφει την αντίστοιχη HTML για αυτή τη συμβολοσειρά.
Αν και αυτός ο κώδικας είναι γραμμένος μπερδεμένα και δύσκολος να τον παρακολουθήσεις, με κάποιο τρόπο δουλεύει και όλα τα τεστ περνούν!
Η πρόκλησή σου είναι να ξαναγράψεις αυτόν τον κώδικα ώστε να είναι πιο ευανάγνωστος και πιο εύκολος στη συντήρηση, φροντίζοντας ταυτόχρονα να συνεχίσουν να περνούν όλα τα τεστ.

Θα ήταν χρήσιμο να σημειώσεις σε σχόλια τι έκανες κατά την αναδιαμόρφωση, ώστε να μπορούν να το δουν οι αξιολογητές, αλλά δεν είναι απολύτως απαραίτητο.
Το πιο σημαντικό είναι να κάνεις τον κώδικα καλύτερο!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
