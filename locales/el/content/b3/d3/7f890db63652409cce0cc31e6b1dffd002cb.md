# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις κώδικα που θα σε βοηθήσει να προετοιμαστείς για να αγοράσεις ένα όχημα.

Έχεις τρεις εργασίες: μία για να προσδιορίσεις αν θα χρειαστείς να βγάλεις άδεια, μία για να σε βοηθήσει να επιλέξεις ανάμεσα σε δύο οχήματα και μία για να εκτιμήσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

Κάποια είδη οχημάτων απαιτούν άδεια οδήγησης για τη λειτουργία τους.
Θεώρησε ότι μόνο τα είδη `car` και `truck` απαιτούν άδεια, ενώ όλα τα υπόλοιπα μπορούν να λειτουργήσουν χωρίς άδεια.

Υλοποίησε τη συνάρτηση `needs_license(kind)` που παίρνει το είδος του οχήματος και επιστρέφει μια τιμή Boolean που δείχνει αν χρειάζεσαι άδεια για αυτό το είδος οχήματος.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Διάλεξε ανάμεσα σε δύο υποψήφια οχήματα προς αγορά

Αξιολογείς τις επιλογές σου για τα διαθέσιμα οχήματα.
Καταφέρνεις να τις περιορίσεις σε δύο επιλογές, αλλά χρειάζεσαι βοήθεια για να πάρεις την τελική απόφαση.
Για αυτό, υλοποίησε τη συνάρτηση `choose_vehicle(option1, option2)` που παίρνει δύο οχήματα ως ορίσματα και επιστρέφει μια απόφαση που είναι απλώς η επιλογή που έρχεται πρώτη κατά λεξικογραφική σειρά.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες την απόφασή σου, θέλεις να βεβαιωθείς ότι θα πάρεις μια δίκαιη τιμή στην αντιπροσωπεία.
Επειδή ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια χοντρική εκτίμηση, θεώρησε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν ολοκαίνουργιο.
Αν είναι περισσότερο από 10 ετών, κοστίζει το 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά όχι παλαιότερο από 10 ετών, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε τη συνάρτηση `calculate_resale_price(original_price, age)`.
Παίρνει την αρχική τιμή και την ηλικία του οχήματος ως ορίσματα και επιστρέφει την εκτιμώμενη τιμή στην αντιπροσωπεία.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
