# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τη λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο στον φούρνο σε λεπτά

Όρισε την αμετάβλητη μεταβλητή `expectedMinutesInOven` που επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο.
Πρέπει να είναι εξαγμένη.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στον φούρνο σε λεπτά είναι 40:

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. Υπολόγισε τον χρόνο που απομένει στον φούρνο σε λεπτά

Υλοποίησε τη διαδικασία `remainingMinutesInOven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο στον φούρνο σε λεπτά από την προηγούμενη εργασία.

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη διαδικασία `preparationTimeInMinutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υλοποίησε τη διαδικασία `totalTimeInMinutes` που παίρνει δύο παραμέτρους: η παράμετρος `numberOfLayers` είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και η παράμετρος `actualMinutesInOven` είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο.
Η διαδικασία πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο τη δεδομένη στιγμή.

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
