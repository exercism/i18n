# Παρωχημένες ασκήσεις

Η διαγραφή μιας άσκησης είναι μια καταστρεπτική ενέργεια, καθώς θα διέγραφε όλες τις λύσεις των χρηστών για αυτή την άσκηση.
Γι' αυτό, οι ασκήσεις δεν μπορούν **ποτέ** να διαγραφούν.
Αντ' αυτού, επιτρέπουμε να χαρακτηρίζονται ως παρωχημένες.

Ο χαρακτηρισμός μιας άσκησης ως παρωχημένης έχει τις εξής συνέπειες:

- Οι χρήστες που έχουν κατεβάσει ή ξεκινήσει την άσκηση μπορούν να έχουν πρόσβαση στην υπάρχουσα λύση τους όπως συνήθως
- Οι χρήστες που **δεν** έχουν κατεβάσει ή ξεκινήσει την άσκηση, δεν θα τη βλέπουν και δεν θα μπορούν να την ξεκινήσουν.

## Χαρακτηρισμός μιας άσκησης ως παρωχημένης

Για να χαρακτηρίσεις μια άσκηση ως παρωχημένη, απλώς άλλαξε την καταχώρισή της στο `config.json` ως εξής:

- **`status`**: ορίζεται σε `"deprecated"`
- **`prerequisites`**: ορίζεται σε `[]`
- **`practices`**: ορίζεται σε `[]` (μόνο για Ασκήσεις Εξάσκησης)
- **`concepts`**: ορίζεται σε `[]` (μόνο για Ασκήσεις Εννοιών)

**Όλες οι άλλες ιδιότητες πρέπει να παραμείνουν ίδιες.**

**Όλα τα αρχεία της άσκησης πρέπει να παραμείνουν άθικτα.**
