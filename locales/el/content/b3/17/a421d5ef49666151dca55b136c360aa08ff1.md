# Σχετικά

Στη Gleam, οι τιμές αληθείς και ψευδείς αναπαρίστανται με τον τύπο `Bool`. Υπάρχουν μόνο δύο τιμές: `True` και `False`. Αυτές οι τιμές μπορούν να ανατεθούν σε μια μεταβλητή:

```gleam
let true_variable = True
let false_variable = False
```

Οι τελεστές `&&`, `||` και `!` μπορούν να χρησιμοποιηθούν για τον χειρισμό τιμών Boolean:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Οι τελεστές `&&` και `||` χρησιμοποιούν αξιολόγηση με βραχυκύκλωμα, που σημαίνει ότι η έκφραση στη δεξιά πλευρά του τελεστή αξιολογείται μόνο αν χρειάζεται.

Κάθε τελεστής έχει διαφορετική προτεραιότητα: το `!` αξιολογείται πριν από τα `&&` και `||`. Τα άγκιστρα μπορούν να χρησιμοποιηθούν για να αξιολογηθεί ένα μέρος της έκφρασης πριν από τα υπόλοιπα:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
