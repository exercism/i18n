# Σχετικά

Η εμβέλεια μιας τιμής σχετίζεται με το πού στο πρόγραμμα μπορεί να προσπελαστεί αυτή η τιμή.

## Οι τέσσερις τύποι εμβέλειας: μπλοκ, συνάρτησης, πρωτοτύπου συνάρτησης, αρχείου

### Εμβέλεια μπλοκ

Μια τιμή με εμβέλεια μπλοκ μπορεί να προσπελαστεί μόνο μέσα από το μπλοκ όπου ορίζεται.
Για περισσότερα σχετικά με τα μπλοκ, δες την [έννοια του μπλοκ](../blocks/introduction.md#Introduction).

### Εμβέλεια συνάρτησης

Η εμβέλεια συνάρτησης είναι ένα ειδικό είδος εμβέλειας που ισχύει για ετικέτες που χρησιμοποιούνται με εντολές `goto`.
Δύο ετικέτες με το ίδιο όνομα δεν μπορούν να χρησιμοποιηθούν στην ίδια συνάρτηση, ακόμα και αν οι ετικέτες ορίζονται σε ξεχωριστά μπλοκ μέσα στη συνάρτηση.

### Εμβέλεια πρωτοτύπου συνάρτησης

Η εμβέλεια πρωτοτύπου συνάρτησης είναι ένα άλλο ειδικό είδος εμβέλειας που ισχύει μόνο για παραμέτρους που ονομάζονται μέσα στο πρωτότυπο (που αναφέρεται και ως δήλωση, έχοντας κατά νου ότι δεν είναι όλες οι δηλώσεις πρωτότυπα).
Το όνομα μιας παραμέτρου είναι συνήθως προαιρετικό σε μια δήλωση συνάρτησης.
Η εμβέλεια ενός ονόματος έχει σημασία μόνο μέσα στη δήλωση.
Στο παρακάτω παράδειγμα, το αναγνωριστικό `len` ορίζεται και στη συνέχεια αναφέρεται αργότερα στη δήλωση της συνάρτησης.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Σημείωσε ότι μέσα σε μια δήλωση τα ονόματα πρέπει να ταιριάζουν όταν αναφέρεσαι στην ίδια μεταβλητή.
Αν η `my_func` δηλωνόταν ως `void my_func(int len, int numbers[length]);` τότε θα παραγόταν ένα σφάλμα μεταγλώττισης περίπου σαν αυτό

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Ένας ορισμός συνάρτησης δεν είναι υποχρεωτικό να χρησιμοποιεί το ίδιο όνομα για μια παράμετρο που χρησιμοποιήθηκε στη δήλωση της συνάρτησης.
Στο παραπάνω παράδειγμα, το `len` χρησιμοποιήθηκε στη δήλωση και το `length` χρησιμοποιήθηκε στον ορισμό, αποδεικνύοντας έτσι ότι η εμβέλεια του αναγνωριστικού `len` ήταν μόνο μέσα στη δήλωση της συνάρτησης.

### Εμβέλεια αρχείου

Μια τιμή με εμβέλεια αρχείου μπορεί να προσπελαστεί από οπουδήποτε στο αρχείο.
Κάθε τέτοια τιμή ορίζεται έξω από μια συνάρτηση.
