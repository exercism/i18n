# Βρόχοι `for`

Η επανάληψη είναι μια θεμελιώδης έννοια στον προγραμματισμό που σου επιτρέπει να εκτελέσεις ένα μπλοκ κώδικα πολλές φορές.
Στη Swift, υπάρχουν δύο τύποι βρόχων: οι [βρόχοι `for-in`][for-loops] και οι `while` βρόχοι.
Σε αυτό το κεφάλαιο, θα μάθεις για τους βρόχους `for-in`.

Οι βρόχοι `for` σου επιτρέπουν να κάνεις επανάληψη πάνω σε μια ακολουθία τιμών, παίρνοντας κάθε στοιχείο με τη σειρά του και δεσμεύοντάς το σε μια μεταβλητή που επιλέγεις εσύ.
Η Swift σου επιτρέπει να κάνεις επανάληψη πάνω σε διάφορες ακολουθίες, όπως εύρη, πίνακες και συμβολοσειρές (και άλλους τύπους που θα καλυφθούν αργότερα).
Όταν γίνει επανάληψη πάνω σε κάθε στοιχείο της ακολουθίας, ο βρόχος τερματίζεται.

Οι βρόχοι `for` δηλώνονται με τη λέξη-κλειδί `for`, ακολουθούμενη από ένα όνομα μεταβλητής, τη λέξη-κλειδί `in` και μια ακολουθία τιμών πάνω στην οποία θα γίνει επανάληψη.
Η μεταβλητή που δίνεται στον βρόχο `for-in` είναι αμετάβλητη, που σημαίνει ότι δεν μπορείς να αλλάξεις την τιμή της μέσα στον βρόχο.
Ας δούμε ένα παράδειγμα βρόχου `for-in` που κάνει επανάληψη πάνω σε έναν πίνακα αριθμών:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
Η μεταβλητή `number` δηλώνεται στον βρόχο `for-in` και είναι διαθέσιμη μόνο μέσα στην εμβέλεια του βρόχου.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Επανάληψη πάνω σε ένα εύρος

Μπορείς επίσης να κάνεις επανάληψη πάνω σε ένα εύρος αριθμών χρησιμοποιώντας έναν βρόχο `for-in`.
Αυτό σου επιτρέπει να εκτελέσεις ένα μπλοκ κώδικα συγκεκριμένο αριθμό φορών. Για παράδειγμα, το εύρος `1...5` θα κάνει επανάληψη πάνω στους αριθμούς 1, 2, 3, 4 και 5, οπότε ο βρόχος θα εκτελεστεί 5 φορές.
Μερικές φορές μπορεί να θέλεις να κάνεις επανάληψη πάνω σε θέσεις, σε μια δομή δεδομένων όπως ένας πίνακας, οπότε μπορείς να χρησιμοποιήσεις ένα εύρος `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Επανάληψη πάνω σε μια συμβολοσειρά

Μπορείς επίσης να κάνεις επανάληψη πάνω σε μια συμβολοσειρά χρησιμοποιώντας έναν βρόχο `for-in`.
Αυτό σου επιτρέπει να κάνεις επανάληψη πάνω σε κάθε χαρακτήρα της συμβολοσειράς. Πρόσεξε ιδιαίτερα ότι ο τύπος που δίνεται στον βρόχο είναι `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Η Swift παρέχει επίσης μια συνάρτηση `stride` που σου επιτρέπει να δημιουργήσεις μια ακολουθία πάνω από ένα εύρος με συγκεκριμένο βήμα.
Στην οποία μπορείς μετά να κάνεις επανάληψη χρησιμοποιώντας έναν βρόχο `for-in`.
Η `stride` ορίζεται ως [`stride(from:to:by:)`][stride-to] ή [`stride(from:through:by:)`][stride-through]. Η πρώτη μορφή είναι αποκλειστική και η δεύτερη είναι συμπεριληπτική.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Πρόσεξε ότι η παράμετρος `to` είναι αποκλειστική, οπότε ο βρόχος θα κάνει επανάληψη μέχρι τον αριθμό πριν από την παράμετρο `to`, ενώ η παράμετρος `through` είναι συμπεριληπτική, οπότε σε αυτή την περίπτωση θα περιλάβει και το `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
