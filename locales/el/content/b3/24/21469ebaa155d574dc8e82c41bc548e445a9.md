# Σχετικά

Μια **word** είναι το όνομα που δίνει η Factor σε μια συνάρτηση. Στο `basics` γνώρισες τη στοίβα δεδομένων και τις shuffle words· εδώ ορίζεις τις δικές σου word, που υπολογίζουν με τις εισόδους τους.

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

Ένας ορισμός αποτελείται από `:`, ένα stack effect, το σώμα και, στο τέλος, `;`. Τα ονόματα μέσα στο `( … -- … )` είναι για τον αναγνώστη· αυτό που ελέγχει ο μεταγλωττιστής είναι ο *αριθμός* των εισόδων και των εξόδων. Μια ασυμφωνία είναι σφάλμα κατά τη μεταγλώττιση, το οποίο πιάνει μια κατηγορία από bugs που, σε μια δυναμικά τυποποιημένη γλώσσα χωρίς αυτού του είδους τη δήλωση, θα ήταν σφάλματα χρόνου εκτέλεσης.

Οι word της ακέραιης αριθμητικής `+`, `-`, `*` προέρχονται από το λεξιλόγιο `math` και καθεμιά τους καταναλώνει δύο αριθμούς από την κορυφή της στοίβας. Η κορυφή της στοίβας είναι ο δεξιός τελεστέος, οπότε το `8 3 -` υπολογίζει το `8 - 3`.

Το `CONSTANT:` ορίζει ένα όνομα για μια σταθερή τιμή· καλώντας το όνομα, βάζεις την τιμή στη στοίβα, ακριβώς όπως με οποιαδήποτε άλλη word. Βάλε τις σταθερές στην αρχή του αρχείου, πριν από κάθε word που τις χρησιμοποιεί.

Το σώμα μιας word μπορεί να καλέσει οποιαδήποτε word βρίσκεται ήδη σε εμβέλεια: προηγούμενους ορισμούς στο ίδιο αρχείο, word από εισαγόμενα λεξιλόγια και τις σταθερές που έχεις δηλώσει. Η σύνθεση μικρών word, καθεμιάς με έναν μόνο σκοπό, είναι ο συνηθισμένος τρόπος για να χτίσεις ένα πρόγραμμα.

Κατά σύμβαση:

- Οι word και οι σταθερές χρησιμοποιούν `lowercase-kebab-case`.
- Τα κατηγορήματα τελειώνουν σε `?` και παράγουν ένα Boolean (`even?`, `empty?`).
- Οι word που αλλάζουν την είσοδό τους έχουν συχνά το ίδιο όνομα με την εκδοχή που δεν την αλλάζει, και η διάκριση γίνεται μόνο από τα συμφραζόμενα.
