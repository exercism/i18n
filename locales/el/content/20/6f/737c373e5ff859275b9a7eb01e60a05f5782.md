# Οδηγίες

Η ομάδα χορού παρατάσσεται σε σειρές και εσύ παρακολουθείς ποιος στέκεται πού.

Όλες οι πέντε εργασίες μπαίνουν στην κλάση `DANCE_FORMATION`.

## 1. Πόσοι είναι στη σειρά;

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. Ποιος είναι επικεφαλής;

Επικεφαλής είναι όποιος στέκεται πρώτος.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. Ποιος κλείνει τη σειρά;

Αυτός που κλείνει τη σειρά είναι όποιος στέκεται τελευταίος, όσο μεγάλη κι αν είναι η σειρά.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. Ο αρχικός σχηματισμός

Η ομάδα ξεκινάει πάντα με την ίδια σειρά: Mia, Ana, Ben. Επίστρεψε αυτή τη σειρά.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Αυτή η ρουτίνα δεν παίρνει ορίσματα.

## 5. Μέτρησε τα βήματα

Κάθε χορευτής έχει έναν αριθμό βημάτων να κάνει. Πρόσθεσέ τα.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Μια κενή σειρά έχει μηδέν βήματα.
