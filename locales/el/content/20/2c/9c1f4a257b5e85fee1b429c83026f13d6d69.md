# Προσθήκη στις οδηγίες

## Υποδείξεις

Για αυτή την άσκηση σου είναι χρήσιμα τα παρακάτω χαρακτηριστικά της F#:
- Το [(..) start finish](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-operators.html#(..)) σου επιτρέπει να δημιουργήσεις με συντομία ένα εύρος τιμών.
- Το [List.sumBy](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-collections-listmodule.html#sumBy) είναι ένας συνοπτικός τρόπος για να εφαρμόσεις μια συνάρτηση σε μια λίστα και μετά να αθροίσεις τα αποτελέσματα.
