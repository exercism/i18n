# Εισαγωγή

Η PHP επιτρέπει τη δήλωση συναρτήσεων μέσα σε άλλες συναρτήσεις. Αυτές οι συναρτήσεις δεν χρειάζεται να έχουν όνομα, αλλά μπορούν να ανατεθούν σε μεταβλητές ή ακόμα και να περαστούν απευθείας σε άλλη συνάρτηση που απαιτεί μια παράμετρο συνάρτησης.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
