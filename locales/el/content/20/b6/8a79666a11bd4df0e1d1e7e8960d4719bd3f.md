# πρόταση να κάνεις το bonus test

Σκέψου να επεκτείνεις τη λύση ώστε να περνάει και το test case `test_grapheme_clusters`, που ενεργοποιείται με feature.
Το να κατανοήσεις πώς μπορούν να χειριστούν τα γραφήματα του Unicode και πώς να [χρησιμοποιήσεις εξωτερικά crates](https://doc.rust-lang.org/cargo/guide/dependencies.html), έχει μεγάλα οφέλη μακροπρόθεσμα.
