# Προαγωγή ιδιοτήτων μέσω κατασκευαστή

Σε κλάσεις που δηλώνουν πολλές ιδιότητες, το να δηλώνεις ξεχωριστά την κλάση, τις ιδιότητές της και έναν κατασκευαστή που ορίζει τις ιδιότητες απαιτεί επανάληψη.
Με την προαγωγή ιδιοτήτων μέσω κατασκευαστή μπορούμε να μειώσουμε την επανάληψη.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
