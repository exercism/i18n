# Σχετικά

Το [`sequences`][sequences] λεξιλόγιο ορίζει ένα μόνο
[πρωτόκολλο][sequence-protocol] που το υλοποιούν όλα: οι πίνακες (`{ … }`), τα διανύσματα
(`V{ … }`), οι συμβολοσειρές, τα εύρη και τα τμήματα. Ό,τι μπορείς να κάνεις με το ένα,
μπορείς να το κάνεις και με τα υπόλοιπα.

| λέξη        | αποτέλεσμα                            |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (με βάση το 0)      |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (όλα εκτός από τα τελευταία n) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (τα τελευταία n)   |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (μήκος όταν δεν υπάρχει) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

Οι πίνακες έχουν σταθερό μήκος, οπότε οι πράξεις `prefix`/`suffix`/`append`/`prepend`
επιστρέφουν όλες νέες ακολουθίες αντί να μεγαλώνουν την αρχική.
Τα διανύσματα αλλάζουν μέγεθος, οι `push` και `pop` λειτουργούν επί τόπου, αλλά το `clone`
είναι το σωστό σημείο εκκίνησης αν θέλεις ένα νέο αντίγραφο.

## Μετατροπές

Τα `>array`, `>string` και `>vector` (στα αντίστοιχα λεξιλόγιά τους)
μετατρέπουν οποιαδήποτε ακολουθία στον ονομαζόμενο συγκεκριμένο τύπο. Χρησιμοποίησέ τα όταν ο
καλών θέλει μια συγκεκριμένη αναπαράσταση, ή για να παραγάγεις ένα τμήμα
ή άλλη οκνηρή ακολουθία.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
