# Εισαγωγή

Η αριθμητική υπερχείλιση συμβαίνει όταν ένας υπολογισμός, όπως μια αριθμητική πράξη ή μια μετατροπή τύπου, έχει ως αποτέλεσμα μια τιμή που είναι μεγαλύτερη από τη χωρητικότητα του τύπου που τη δέχεται.

Οι εκφράσεις τύπου `int` και `long`, καθώς και οι αντίστοιχες χωρίς πρόσημο, θα αναδιπλωθούν σιωπηλά σε αυτές τις περιπτώσεις.

Η συμπεριφορά των υπολογισμών με ακέραιους μπορεί να τροποποιηθεί χρησιμοποιώντας τη λέξη-κλειδί `checked`. Όταν προκύψει υπερχείλιση μέσα σε ένα μπλοκ `checked`, πετιέται ένα στιγμιότυπο της `OverflowException`.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

Οι εκφράσεις τύπου `float` και `double` θα λάβουν την ειδική τιμή του απείρου.

Οι εκφράσεις τύπου `decimal` θα πετάξουν ένα στιγμιότυπο της `OverflowException`.
