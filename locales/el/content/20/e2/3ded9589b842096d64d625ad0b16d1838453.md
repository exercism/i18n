# Υποδείξεις

## Γενικά

- Ο τύπος [ByteArray][bytearray] περιέχει μερικές χρήσιμες ενσωματωμένες μεθόδους, οπότε γενικά θα πρέπει να υλοποιήσεις τις δικές σου βοηθητικές συναρτήσεις για τον χειρισμό ByteArray.
- Το `ByteArray` στην πραγματικότητα αναπαριστά έναν πίνακα από bytes και όχι "chars", όπως σε πολλές άλλες γλώσσες.
- Η εργασία με σύντομες και μεγάλες συμβολοσειρές ταυτόχρονα μπορεί να είναι δύσκολη, γι' αυτό μερικές βοηθητικές συναρτήσεις είναι ήδη υλοποιημένες και μπορείς να τις χρησιμοποιήσεις για αυτή την άσκηση.

## 1. Δημιούργησε το μήνυμα καλωσορίσματος

- Οι συμβολοσειρές μπορούν να συνενωθούν με τον τελεστή `+`.
- Έλεγξε αν μπορείς να χρησιμοποιήσεις κάποια από τις βοηθητικές συναρτήσεις.

## 2. Πρόσθεσε ένα περίτεχνο περίγραμμα

- Μπορείς να προσθέσεις χαρακτήρες `'*'` σε έναν βρόχο.
- Η αλλαγή γραμμής είναι ένας ειδικός χαρακτήρας διαφυγής.

## 3. Καθάρισε τα παλιά διαφημιστικά μηνύματα

- Βρες τις θέσεις αρχής και τέλους του καθαρού μηνύματος.
- Πιθανότατα θα χρειαστεί να αντιγράψεις τους χαρακτήρες του καθαρού μηνύματος σε ένα νέο ByteArray έναν προς έναν.
