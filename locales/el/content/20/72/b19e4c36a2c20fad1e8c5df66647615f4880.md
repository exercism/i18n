# Εισαγωγή

Κάποιοι βρόχοι δεν μπορούν να γραφτούν ως "κάνε αυτό για κάθε στοιχείο μιας ακολουθίας": πρέπει να συνεχίζεις μέχρι να αλλάξει κάποια συνθήκη. Ο συνδυαστής `while` της Factor είναι το εργαλείο για αυτό: μια παράθεση κατηγορήματος λέει "συνέχισε;", μια παράθεση σώματος κάνει τη δουλειά ενός βήματος, και το `while` επαναλαμβάνει μέχρι η παράθεση κατηγορήματος να δώσει `f`.

## `while` και `until`

```
while ( pred body -- )
until ( pred body -- )
```

Οι `pred` και `body` είναι και οι δύο παραθέσεις που λειτουργούν στη στοίβα δεδομένων. Το `while` επαναλαμβάνει όσο η `pred` αφήνει μια τιμή που αξιολογείται ως αληθής· το `until` κάνει το αντίθετο: επαναλαμβάνει *μέχρι* η `pred` να γίνει αληθής (δηλαδή, όσο η `pred` αφήνει `f`).

Μια μόνο τιμή κατάστασης μπορεί να κυλήσει στη στοίβα ανάμεσα στο κατηγόρημα και το σώμα:

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

Ιχνηλάτηση: το κατηγόρημα `dup 0 >` ρίχνει μια ματιά στον μετρητή που τρέχει· το σώμα `dup . 1 -` τον εκτυπώνει και τον μειώνει κατά ένα· ο βρόχος σταματά μόλις ο μετρητής φτάσει στο `0`. Το `drop` στο τέλος πετάει αυτό το τελευταίο `0` από τη στοίβα.

## `while*`: κράτησε την τιμή του κατηγορήματος

```
while* ( pred body -- )
```

Το `while` νοιάζεται μόνο αν το κατηγόρημά του άφησε μια αληθή τιμή, και πετάει την ίδια την τιμή πριν τρέξει το σώμα. Το `while*` αντίθετα *δίνει αυτή την τιμή στο σώμα*. Καταφεύγεις σε αυτό όποτε ο έλεγχος και το σώμα θέλουν το ίδιο φρεσκοϋπολογισμένο πράγμα: μια αναζήτηση, ένα ταίριασμα, ένα token που διαβάστηκε.

Εδώ κάθε όνομα δείχνει στο επόμενο μέσα σε μια αλυσίδα. Το κατηγόρημα αναζητά το τρέχον όνομα· όσο υπάρχει επόμενο όνομα, το `while*` το περνά στο σώμα, το οποίο το εκτυπώνει και συνεχίζει από εκεί:

```factor
USING: assocs kernel locals prettyprint ;

:: print-chain ( start links -- )
    start [ links at ] [ dup . ] while* ;

"a" H{ { "a" "b" } { "b" "c" } } print-chain
! prints "b" then "c"
```

Το `links at` επιστρέφει το επόμενο όνομα, ή `f` όταν ένα όνομα δεν έχει καταχώριση. Όσο επιστρέφει κάποιο όνομα, το `while*` δίνει αυτό το όνομα στο `dup .`, το οποίο το εκτυπώνει και το αφήνει ως κλειδί για την επόμενη αναζήτηση. Το πρώτο `f` σταματά τον βρόχο: το `while*` το πετάει, οπότε δεν περισσεύει τίποτα.

## Πολλαπλές τιμές κατάστασης με τοπικές μεταβλητές

Όταν ο βρόχος κουβαλά περισσότερες από μία τιμές, ας πούμε μια λίστα που απομένει και ένα τρέχον άθροισμα, το πάνω-κάτω στη στοίβα γίνεται κουραστικό. Το πιο καθαρό μοτίβο είναι να δηλώσεις *τοπικές μεταβλητές* με το `::`:

```
:: word ( inputs -- outputs ) ... ;
```

Μέσα στο σώμα, το `:> name!` προσθέτει μια τοπική μεταβλητή που μπορεί να τροποποιηθεί· οι αναγνώσεις χρησιμοποιούν το `name`, οι εγγραφές το `name!` (το οποίο καταναλώνει τη νέα τιμή από τη στοίβα και την αναθέτει).

```factor
USING: kernel locals math sequences ;

! Walk a sequence from the front, summing as we go
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0   :> running!
    [ rest empty? ] [
        rest unclip [ rest! ] dip
        running + running!
    ] until
    running ;
```

Δύο τοπικές μεταβλητές εδώ (οι `rest` και `running`) καλύπτουν όλη την κατάσταση του βρόχου: το κατηγόρημα τις εξετάζει, το σώμα τις ενημερώνει, και η τελική τιμή επιστρέφεται στο τέλος.

Το `unclip ( seq -- rest first )` αφαιρεί το πρώτο στοιχείο μιας ακολουθίας, κάτι βολικό όταν ο βρόχος θέλει να καταναλώσει μια λίστα ένα στοιχείο σε κάθε επανάληψη. Η μορφή `[ rest! ] dip` ενημερώνει το `rest` με την ουρά που απομένει, ενώ αφήνει το στοιχείο που μόλις αφαιρέθηκε πάνω στη στοίβα για να το χρησιμοποιήσει το σώμα.
