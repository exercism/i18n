# Υποδείξεις

## 1. Υλοποίησε τη μέθοδο calculate για να υποστηρίζει μερικές βασικές πράξεις

- Χρησιμοποίησε μια [εντολή `switch`][switch-statement-docs] για να ταιριάξεις διαφορετικές πράξεις.

## 2. Χειρίσου τις μη έγκυρες πράξεις

- Δεν μπορείς να ελέγξεις για `null` μέσα σε μια εντολή `switch`.
- Χρησιμοποίησε μια περίπτωση `default` για οτιδήποτε άλλο στο τέλος του switch.

## 3. Χειρίσου την εξαίρεση που πετιέται όταν διαιρείς με το μηδέν

- Χρησιμοποίησε ένα [μπλοκ `try-catch`][exception-handling-docs] για να πιάσεις την `ArithmeticException` που πετιέται όταν διαιρείς με το μηδέν.
- Η κλάση `IllegalOperationException` έχει έναν κατασκευαστή που παίρνει ένα μήνυμα και μια αιτία ως παραμέτρους του.

[switch-statement-docs]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/switch.html
[exception-handling-docs]: https://docs.oracle.com/javase/tutorial/essential/exceptions/handling.html
