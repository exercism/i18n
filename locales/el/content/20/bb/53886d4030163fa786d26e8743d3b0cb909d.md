# Αποδόμηση και Πολλαπλή Ανάθεση

Η αποδόμηση αναφέρεται στην πράξη της εξαγωγής των στοιχείων μιας συλλογής, όπως ενός `Array` ή ενός `Hash`.
Οι αποδομημένες τιμές μπορούν στη συνέχεια να ανατεθούν σε μεταβλητές μέσα στην ίδια εντολή.

Η [πολλαπλή ανάθεση][multiple assignment] είναι η δυνατότητα να αναθέτεις πολλές μεταβλητές ώστε να αποδομήσεις τιμές μέσα σε μία εντολή.
Αυτό επιτρέπει στον κώδικα να είναι πιο συνοπτικός και ευανάγνωστος, και γίνεται χωρίζοντας με κόμμα τις μεταβλητές που θα ανατεθούν, όπως `first, second, third = [1, 2, 3]`.

Ο τελεστής splat (`*`) και ο διπλός τελεστής splat (`**`) χρησιμοποιούνται συχνά σε πλαίσια αποδόμησης.
Ο τελεστής splat (`*`) μπορεί να χρησιμοποιηθεί για να συνδυάσει πολλούς **πίνακες** σε έναν **πίνακα**, _αποδομώντας_ τον καθένα σε έναν νέο κοινό **πίνακα**.
Ο διπλός τελεστής splat (`**`) μπορεί να χρησιμοποιηθεί για να συνδυάσει πολλά **hash** σε ένα **hash**, _αποδομώντας_ το καθένα σε ένα νέο κοινό **hash**.
Αυτή είναι μια σύνταξη που χρησιμοποιείται για να ξεχωρίζει από την περίπτωση πολλών τιμών που γίνονται δεκτές ως ορίσματα θέσης, εκείνη όπου δεχόμαστε οποιαδήποτε ή πολλά ορίσματα με λέξεις-κλειδιά.

Όταν ο τελεστής splat (`*`) χρησιμοποιείται χωρίς κάποια συλλογή, _συσκευάζει_ (ή συνθέτει) έναν αριθμό τιμών σε έναν **πίνακα**.
Αυτό χρησιμοποιείται συχνά στην πολλαπλή ανάθεση για να ομαδοποιήσει όλα τα "υπόλοιπα" στοιχεία που δεν έχουν ξεχωριστές αναθέσεις σε μία μόνο μεταβλητή.

Στη Ruby είναι συνηθισμένο να χρησιμοποιείς αυτή τη συμπεριφορά αποδόμησης/σύνθεσης όταν χρησιμοποιείς ή ορίζεις μεθόδους που δέχονται οποιονδήποτε αριθμό ορισμάτων θέσης ή λέξεων-κλειδιών.
Θα δεις συχνά αυτά τα ορίσματα να ορίζονται ως `def some_method(*args, **kwargs)` και να χρησιμοποιούνται ως `some_method(*some_array, **some_hash)`.

~~~~exercism/caution
Τα `*<variable_name>` και `**<variable_name>` δεν πρέπει να συγχέονται με τα `*` και `**`.
Ενώ τα `*` και `**` χρησιμοποιούνται για πολλαπλασιασμό και ύψωση σε δύναμη αντίστοιχα, τα `*<variable_name>` και `**<variable_name>` χρησιμοποιούνται ως τελεστές σύνθεσης και αποδόμησης.
~~~~

[multiple assignment]: https://docs.ruby-lang.org/en/master/syntax/assignment_rdoc.html#label-Multiple+Assignment
