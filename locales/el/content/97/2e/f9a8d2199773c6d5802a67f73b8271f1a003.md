# Σχετικά

Για να εκτελείς επανειλημμένα κάποια λογική, μπορείς να χρησιμοποιήσεις βρόχους. Ένας από τους πιο συνηθισμένους τύπους βρόχων στη C# είναι ο `while` βρόχος, ο οποίος συνεχίζει να επαναλαμβάνεται μέχρι να αξιολογηθεί μια συνθήκη Boolean (λογική τιμή) σε `false`.

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 1;
}
```
