# Μαθαίνοντας PowerShell

Ένα εξαιρετικό μέρος για να ξεκινήσεις να μαθαίνεις PowerShell είναι να διαλέξεις έναν πόρο μάθησης στην [ενότητα μάθησης][learning section] στον ιστότοπο του PowerShell.
Αυτό έχει τεράστιο όγκο πληροφοριών και συνδέσμους για μια ευρεία γκάμα θεμάτων του PowerShell.

Το PowerShell διαθέτει επίσης ένα πολύ πλήρες, αυτοτεκμηριωμένο σύστημα βοήθειας.
Μπορείς να εξερευνήσεις μεγάλο μέρος από αυτά που προσφέρει το PowerShell χρησιμοποιώντας το cmdlet `Get-Help`.
Από μέσα στο PowerShell, δοκίμασε:

```PowerShell
Get-Help about
```

Θα δεις περίπου 3 σελίδες θεμάτων που μπορείς να εξερευνήσεις.
Δύο ακόμη συναρτήσεις που θα σου φανούν πολύ χρήσιμες είναι:

- Get-Command
- Get-Member

Θέλεις να μάθεις τι κάνουν;
Δοκίμασε `Get-Help Get-Command` και `Get-Help Get-Member`, φυσικά.

## Ρήματα και ουσιαστικά στο PowerShell

Το PowerShell ακολουθεί ένα αρκετά αυστηρό σχήμα ρήμα-ουσιαστικό για την ονομασία των cmdlets του.
Στην αρχή, αυτό μπορεί να ξενίσει τους έμπειρους προγραμματιστές.
Ενώ μπορείς να ονομάσεις τις συναρτήσεις σου όπως θέλεις, το να εξοικειωθείς με τα καθιερωμένα ρήματα και να τα υιοθετήσεις θα βελτιώσει τον προγραμματισμό σου σε PowerShell.

Για να δεις μια λίστα με όλα τα εγκεκριμένα ρήματα, απλώς τρέξε:

```PowerShell
Get-Verb
```
