# Υποδείξεις

## Γενικά

- [Αυτή η σελίδα][pattern-matching] έχει μια ωραία εισαγωγή στην αντιστοίχιση μοτίβων στην F#.

## 1. Απάντησε σε μια σωστή μαντεψιά

- Μπορείς να χρησιμοποιήσεις ένα [σταθερό μοτίβο][constant-patterns] για να ταιριάξεις με έναν συγκεκριμένο αριθμό.

## 2. Απάντησε σε μια κοντινή μαντεψιά

- Μπορείς να χρησιμοποιήσεις είτε ένα [σταθερό μοτίβο][constant-patterns] είτε ένα [μοτίβο μεταβλητής][variable-patterns] και έναν [φρουρό][guards].

## 3. Απάντησε σε πολύ χαμηλές μαντεψιές

- Μπορείς να συνδυάσεις ένα [μοτίβο μεταβλητής][variable-patterns] με έναν [φρουρό][guards].

## 4. Απάντησε σε πολύ υψηλές μαντεψιές

- Μπορείς να συνδυάσεις ένα [μοτίβο μεταβλητής][variable-patterns] με έναν [φρουρό][guards].
