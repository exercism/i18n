# Debug

Όταν ένα test αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά και για ποια είσοδο. Μπορείς επίσης να χρησιμοποιήσεις το γεγονός ότι οποιαδήποτε έξοδος στην `console` θα εμφανίζεται επίσης. Μπορείς να γράψεις στην κονσόλα χρησιμοποιώντας:

```javascript
console.log('Debug message');
```
