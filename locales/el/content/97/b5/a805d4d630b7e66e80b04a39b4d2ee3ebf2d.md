# Εισαγωγή

## Αριθμοί κινητής υποδιαστολής

Ένας αριθμός κινητής υποδιαστολής είναι ένας αριθμός με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή. Παραδείγματα είναι οι `-2.4`, `0.1`, `3.14`, `16.984025` και `1024.0`.

Διαφορετικοί τύποι κινητής υποδιαστολής μπορούν να αποθηκεύσουν διαφορετικό αριθμό ψηφίων μετά την υποδιαστολή. Αυτό αναφέρεται ως η ακρίβειά τους.

Η C# έχει τρεις τύπους κινητής υποδιαστολής:

- `float`: 4 bytes (ακρίβεια ~6-9 ψηφίων). Γράφεται ως `2.45f`.
- `double`: 8 bytes (ακρίβεια ~15-17 ψηφίων). Αυτός είναι ο πιο συνηθισμένος τύπος. Γράφεται ως `2.45` ή `2.45d`.
- `decimal`: 16 bytes (ακρίβεια 28-29 ψηφίων). Χρησιμοποιείται συνήθως όταν δουλεύεις με νομισματικά δεδομένα, καθώς η ακρίβειά του μειώνει την πιθανότητα σφαλμάτων στρογγυλοποίησης. Γράφεται ως `2.45m`.

Όπως φαίνεται, κάθε τύπος μπορεί να αποθηκεύσει διαφορετικό αριθμό ψηφίων. Για παράδειγμα, αν προσπαθήσεις να αποθηκεύσεις το PI σε έναν `float`, θα αποθηκευτούν μόνο τα πρώτα 6 δεκαδικά ψηφία (με το τελευταίο αποθηκευμένο ψηφίο στρογγυλοποιημένο).

## `while` βρόχοι

Σε αυτή την άσκηση μπορεί να θέλεις να χρησιμοποιήσεις έναν βρόχο. Υπάρχουν αρκετοί τρόποι να γράψεις βρόχους στη C#, αλλά ο `while` βρόχος είναι ο πιο κατάλληλος εδώ:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while` βρόχοι

Αν ο κώδικας σε έναν βρόχο πρέπει να εκτελεστεί πάντα τουλάχιστον μία φορά, μπορείς να χρησιμοποιήσεις έναν βρόχο `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
