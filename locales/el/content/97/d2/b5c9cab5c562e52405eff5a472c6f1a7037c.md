# Οδηγίες

Σε αυτή την άσκηση θα διοργανώσεις αγώνες ανάμεσα σε διάφορα είδη τηλεχειριζόμενων αυτοκινήτων.
Κάθε αυτοκίνητο έχει τα δικά του χαρακτηριστικά ταχύτητας και κατανάλωσης μπαταρίας.

Τα αυτοκίνητα ξεκινούν με γεμάτη μπαταρία (100%). Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο,
αυτό διανύει τόσα μέτρα όση είναι η ταχύτητά του και μειώνει το υπόλοιπο ποσοστό της μπαταρίας κατά την κατανάλωσή του.

Αν η μπαταρία ενός αυτοκινήτου είναι κάτω από το ποσοστό κατανάλωσής του, δεν μπορείς να οδηγήσεις άλλο το αυτοκίνητο.

Κάθε πίστα αγώνα έχει το δικό της μήκος. Τα αυτοκίνητα δοκιμάζονται ελέγχοντας αν μπορούν να τερματίσουν την πίστα χωρίς να ξεμείνουν από μπαταρία.

## 1. Δημιούργησε ένα τηλεχειριζόμενο αυτοκίνητο

Όρισε μια λίστα `car` με τα παρακάτω στοιχεία:

- speed
- battery_drain
- battery
- distance_traveled

Να επιτρέπεις τη δημιουργία ενός τηλεχειριζόμενου αυτοκινήτου ορίζοντας μια συνάρτηση `new_car` που παίρνει την ταχύτητα του αυτοκινήτου σε μέτρα
και το ποσοστό κατανάλωσης της μπαταρίας ως τις δύο παραμέτρους της και επιστρέφει μια λίστα `car`.

Για ένα καινούριο αυτοκίνητο, η μπαταρία είναι στο 100% και η απόσταση που έχει διανυθεί είναι μηδέν.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Δημιούργησε μια πίστα αγώνα

Όρισε μια άλλη λίστα που ονομάζεται `track` με το μοναδικό στοιχείο `track_length`.
Να επιτρέπεις τη δημιουργία μιας πίστας αγώνα ορίζοντας μια συνάρτηση `new_track` που παίρνει την απόσταση της πίστας σε μέτρα:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Έλεγξε αν η μπαταρία έχει εξαντληθεί

Υλοποίησε τη συνάρτηση `battery_drained()` που δείχνει αν η μπαταρία έχει εξαντληθεί.
Μια μπαταρία θεωρείται εξαντλημένη αν δεν υπάρχει αρκετή για να κινηθεί άλλη μία φορά.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Οδήγησε το αυτοκίνητο

Υλοποίησε τη συνάρτηση `drive` που ενημερώνει τον αριθμό των μέτρων που διανύθηκαν με βάση την ταχύτητα του αυτοκινήτου και μειώνει τη μπαταρία σύμφωνα με την κατανάλωσή της.
Αν δεν υπάρχει αρκετή μπαταρία για να κινηθεί άλλη μία φορά, το αυτοκίνητο δεν θα μετακινηθεί.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Έλεγξε αν ένα τηλεχειριζόμενο αυτοκίνητο μπορεί να τερματίσει έναν αγώνα

Για να τερματίσει έναν αγώνα, ένα αυτοκίνητο πρέπει να μπορεί να διανύσει το μήκος του αγώνα. Αυτό σημαίνει να μην εξαντλήσει τη μπαταρία του πριν περάσει τη γραμμή τερματισμού. 

Υλοποίησε τη συνάρτηση `can_finish` που παίρνει ένα `car` και ένα `track` ως παραμέτρους της και επιστρέφει `TRUE` αν το αυτοκίνητο μπορεί να τερματίσει τον αγώνα· αλλιώς, επέστρεψε `FALSE`.

Υπέθεσε ότι βρίσκεσαι αυτή τη στιγμή στη γραμμή εκκίνησης του αγώνα και βάζεις μπροστά τη μηχανή του αυτοκινήτου για τον αγώνα. Λάβε υπόψη ότι η μπαταρία του αυτοκινήτου μπορεί να μην είναι απαραίτητα πλήρως φορτισμένη όταν ξεκινάει ο αγώνας.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Αποθήκευσε αν το αυτοκίνητο μπορεί να τερματίσει μια πίστα με γεμάτη μπαταρία

Έχεις δημιουργήσει αρκετές πίστες διαφορετικού μήκους και χρειάζεται να αποθηκεύσεις αν το αυτοκίνητό σου μπορεί να τις ολοκληρώσει με γεμάτη μπαταρία.

Υλοποίησε τη συνάρτηση `store_track` που παίρνει ένα αυτοκίνητο, μια πίστα και ένα όνομα πίστας, και επιστρέφει ένα ενημερωμένο αυτοκίνητο με ένα επιπλέον στοιχείο.
Αυτό το στοιχείο θα πρέπει να έχει το `name` της πίστας, και η τιμή θα πρέπει να είναι μια υπολίστα με το `track_length` και κατά πόσο το αυτοκίνητο μπορεί να την `complete`.

Το αυτοκίνητο που δίνεται στο όρισμα μπορεί να μην είναι πλήρως φορτισμένο, οπότε φρόντισε να επαναφέρεις τη μπαταρία και την απόσταση που έχει διανυθεί πριν το χρησιμοποιήσεις.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
