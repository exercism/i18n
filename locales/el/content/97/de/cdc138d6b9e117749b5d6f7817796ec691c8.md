# Εισαγωγή

Πέρα από τις κλάσεις χαρακτήρων και τους ποσοδείκτες, οι κανονικές εκφράσεις μπορούν να περιγράψουν *δομή* και *συμφραζόμενα*. Αυτά τα χαρακτηριστικά ζουν στο ίδιο λεξιλόγιο [`regexp`][regexp] και στο ίδιο literal `R/ /`.

Οι παρενθέσεις `( )` ομαδοποιούν ένα μέρος ενός μοτίβου, ώστε ένας ποσοδείκτης ή ένα `|` ("αυτό ή εκείνο") να εφαρμόζεται σε ολόκληρη την ομάδα· το `?` μετά από μια ομάδα την κάνει προαιρετική:

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

Οι άγκυρες καθηλώνουν ένα μοτίβο σε μια θέση: `^` (αρχή), `$` (τέλος) και `\b` (όριο λέξης).

Ένα *lookaround* ταιριάζει με βάση αυτά που περιβάλλουν ένα σημείο, χωρίς να το καταναλώνει:

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

Ένα γράμμα επιλογής μετά το τελικό `/` αλλάζει ολόκληρο το μοτίβο· το `i` το κάνει να αγνοεί τη διάκριση πεζών-κεφαλαίων:

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Η Factor χρησιμοποιεί lookaround στη θέση των ομάδων σύλληψης: δεν έχει εξαγωγή ομάδων σύλληψης, back-references ή τεμπέληδες ποσοδείκτες.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
