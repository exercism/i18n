# Προσθήκη οδηγιών

## Υλοποίηση

Για να ολοκληρώσεις αυτή την άσκηση, χρειάζεται να δημιουργήσεις τον τύπο δεδομένων `LinkedList` και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Θα βρεις ήδη έτοιμες μια εικονική δήλωση τύπου και τις υπογραφές τύπων, αλλά εσύ θα ορίσεις τις συναρτήσεις και θα δημιουργήσεις έναν τύπο δεδομένων με νόημα.
