# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις λίγο κώδικα για να σε βοηθήσει να προετοιμαστείς για την αγορά ενός οχήματος.

Έχεις τρεις εργασίες: μία για να καθορίσεις αν χρειάζεσαι άδεια οδήγησης, μία για να σε βοηθήσει να επιλέξεις ανάμεσα σε δύο οχήματα, και μία για να υπολογίσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Καθόρισε αν θα χρειαστείς άδεια οδήγησης

Ορισμένοι τύποι οχημάτων απαιτούν άδεια οδήγησης για να τα οδηγήσεις.
Υπόθεσε ότι μόνο οι τύποι `"car"` και `"truck"` απαιτούν άδεια, ενώ όλα τα υπόλοιπα μπορούν να οδηγηθούν χωρίς άδεια.

Υλοποίησε τη συνάρτηση `needs_license(kind)` που παίρνει τον τύπο οχήματος ως συμβολοσειρά και επιστρέφει μια τιμή Boolean που δείχνει αν χρειάζεσαι άδεια για αυτόν τον τύπο οχήματος.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Διάλεξε ανάμεσα σε δύο πιθανά οχήματα για αγορά

Αξιολογείς τις επιλογές σου από τα διαθέσιμα οχήματα.
Καταφέρνεις να τις περιορίσεις σε δύο επιλογές, αλλά χρειάζεσαι βοήθεια για να πάρεις την τελική απόφαση.
Για αυτό, υλοποίησε τη συνάρτηση `choose_vehicle(option1, option2)` που παίρνει δύο οχήματα ως ορίσματα και επιστρέφει μια απόφαση που περιλαμβάνει την επιλογή που έρχεται πρώτη στη λεξικογραφική σειρά.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

Η συμβολοσειρά που επιστρέφεται θα πρέπει να ακολουθεί το μοτίβο "<CHOSEN_VEHICLE> is clearly the better choice.", όπου το `<CHOSEN_VEHICLE>` είναι η επιλογή που διαλέγεις από τα ορίσματα που δίνονται.

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες μια απόφαση, θέλεις να βεβαιωθείς ότι θα πάρεις μια δίκαιη τιμή στην αντιπροσωπεία.
Επειδή ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια πρόχειρη εκτίμηση, υπόθεσε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν ολοκαίνουργιο.
Αν είναι τουλάχιστον 10 ετών, κοστίζει το 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά λιγότερο από 10, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε τη συνάρτηση `calculate_resell_price(original_price, age)` που εφαρμόζει αυτή τη λογική χρησιμοποιώντας `if`, `else if` και `else` (υπάρχουν και άλλοι τρόποι αν θέλεις να εξασκηθείς).
Παίρνει την αρχική τιμή και την ηλικία του οχήματος ως ορίσματα και επιστρέφει την εκτιμώμενη τιμή στην αντιπροσωπεία.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Σημείωση: η τιμή επιστροφής είναι τύπου `double`.
