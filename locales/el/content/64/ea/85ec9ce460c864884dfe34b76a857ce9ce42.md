# Εισαγωγή

## Η λέξη-κλειδί `auto` στη C++

Στη C++, η λέξη-κλειδί `auto` είναι μια ισχυρή δυνατότητα που εισήχθη στη C++11 και χρησιμοποιείται για τη δήλωση μεταβλητών με τύπο δεδομένων που συμπεραίνεται.
Ο μεταγλωττιστής συμπεραίνει τον τύπο της μεταβλητής με βάση τον αρχικοποιητή της, κάτι που μπορεί να κάνει τον κώδικα πιο ευανάγνωστο και πιο εύκολο στη συντήρηση.

## Παράδειγμα χρήσης

Δες το παρακάτω παράδειγμα, όπου το `auto` χρησιμοποιείται για τη δήλωση μεταβλητών:

```cpp
auto dragon_population{3};          // dragon_population is deduced as an integer
auto westeros{7.7777};              // westeros is deduced as a double
auto wedding_location{"The Twins"}; // wedding_location is deduced as a const char*, not std::string
```

Σε κάθε περίπτωση, ο τύπος της μεταβλητής συμπεραίνεται από την τιμή με την οποία αρχικοποιείται.

## Εξαγωγή τύπου

Η λέξη-κλειδί `auto` σε βοηθά να γράψεις πιο συνοπτικό και ευανάγνωστο κώδικα, καθώς μειώνει τη φλυαρία των ρητών τύπων.

```cpp
const std::vector<std::string> pigeon_pie{"flour", "butter", "pigeon", "salt"};
auto purple_wedding_pie{pigeon_pie};
purple_wedding_pie.emplace_back("the strangler");
```

Σε αυτόν τον βρόχο, το `auto` συμπεραίνει τον τύπο του `purple_wedding_pie` ως `std::vector<std::string>`, αποφεύγοντας την ανάγκη να καθορίσεις ρητά τον τύπο ξανά.

## Συμβατότητα

Η λέξη-κλειδί `auto` είναι συμβατή με διάφορες δομές της C++, γεγονός που την κάνει ευέλικτο εργαλείο στον σύγχρονο προγραμματισμό C++.

```cpp
auto& element{array[0]};           // reference to an element
const auto object{otherObject};    // const type version of otherObject's type
auto* ptr{&x};                     // pointer to x with the same type as x, but as a pointer.
```

Σε μια επόμενη ενότητα θα δούμε συχνά τη λέξη-κλειδί `auto` με εκφράσεις lambda, `for` βρόχους βασισμένους σε εύρος και επαναλήπτες.
