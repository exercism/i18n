# Εισαγωγή

## Χρόνος

Η έννοια του _χρόνου_ αντιμετωπίζεται στο .NET με το struct `DateTime`. Υπάρχουν ρουτίνες για τη μετατροπή μεταξύ τοπικής ώρας και UTC. Η αριθμητική μπορεί να γίνει με τη βοήθεια του `TimeSpan`.

## Ζώνη ώρας

Η κλάση `TimeZoneInfo` παρέχει ρουτίνες για τον χειρισμό των διαφορών μεταξύ ζωνών ώρας. Η κλάση `TimeZoneInfo` περιέχει επίσης μεθόδους που διευκολύνουν τον χειρισμό της θερινής ώρας.

Η κλάση `CultureInfo` υποστηρίζει μορφές ημερομηνίας και ώρας που εξαρτώνται από τις τοπικές ρυθμίσεις.

Για να υποστηρίξεις τον προγραμματισμό σε πολλαπλές πλατφόρμες, η κλάση `RuntimeInformation` σου επιτρέπει να εντοπίσεις σε ποιο λειτουργικό σύστημα εκτελείται ο κώδικάς σου: Linux, Windows ή OSX.
