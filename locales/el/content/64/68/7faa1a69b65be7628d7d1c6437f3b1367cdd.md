# Προσθήκη στις οδηγίες

## Υλοποίηση

Όρισε μία μόνο Go func, τη Cost, η οποία υπολογίζει το κόστος για μια δεδομένη λίστα βιβλίων με βάση τις καθορισμένες εκπτώσεις.

Χρησιμοποίησε την ακόλουθη υπογραφή για τη func Cost:

```go
func Cost(books []int) int
```

Η Cost θα επιστρέψει το συνολικό κόστος (μετά τις εκπτώσεις) σε σεντ.
Για παράδειγμα, για ένα μόνο βιβλίο, το κόστος είναι 800 σεντ, που ισούται με $8.00.
Για αυτή την άσκηση χρειάζονται μόνο ακέραιοι υπολογισμοί.
