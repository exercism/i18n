# Εισαγωγή

Οι `Complex numbers` δεν είναι περίπλοκοι.
Χρειάζονται απλώς ένα λιγότερο ανησυχητικό όνομα.

Είναι τόσο χρήσιμοι, ειδικά στη μηχανική και τις επιστήμες, που η R τους περιλαμβάνει ως τυπικούς ατομικούς τύπους, μαζί με τους integer, double, logical, character και raw.

## Τα βασικά

Ένας `complex` αριθμός στην R είναι μία μόνο τιμή.
Στην πράξη όμως, μπορεί να θεωρηθεί ως ένα ζεύγος αριθμών.
Αυτά ονομάζονται το "πραγματικό" και το "φανταστικό" μέρος, για άτυχους ιστορικούς λόγους.
Και πάλι, το καλύτερο είναι να εστιάσεις στη βασική απλότητα και όχι στα περίεργα ονόματα.

Για να δημιουργήσεις μιγαδικούς αριθμούς από δύο πραγματικούς αριθμούς, απλώς πρόσθεσε το επίθημα `i` στο φανταστικό μέρος.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

Για να δημιουργήσεις έναν μιγαδικό αριθμό από πραγματικές μεταβλητές, η παραπάνω σύνταξη δεν θα δουλέψει.
Γράφοντας `r + imi` μπερδεύεις τον parser, κάνοντάς τον να νομίζει ότι το `imi` είναι όνομα (ανύπαρκτης) μεταβλητής.

Είτε πολλαπλασίασε το φανταστικό μέρος με `1i` είτε χρησιμοποίησε τη συνάρτηση [`complex()`][ref-complex]:

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

Μπορεί να αναρωτιέσαι, γιατί `i` και όχι `j`;

Οι περισσότεροι μηχανικοί προτιμούν το `j`.
Οι περισσότεροι επιστήμονες και μαθηματικοί προτιμούν τον μαθηματικό συμβολισμό `i` για το _φανταστικό_, αλλά αυτός ο συμβολισμός συγκρούεται με τη χρήση του `i` για να σημαίνει _ρεύμα_ στη μηχανική ηλεκτρολογίας.

Η R επέλεξε το `i`, η Python επέλεξε το `j`, και η Julia απέφυγε τη διαμάχη επιλέγοντας το `im`.
Πρόσεχε όταν εναλλάσσεις μεταξύ γλωσσών προγραμματισμού [STEM][wiki-STEM].

Για να προσπελάσεις τα μέρη ενός μιγαδικού αριθμού ξεχωριστά:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

Οποιοδήποτε από τα δύο μέρη μπορεί να είναι μηδέν, και οι μαθηματικοί μπορεί τότε να μιλήσουν για τον αριθμό ως "εντελώς πραγματικό" ή "εντελώς φανταστικό".
Ωστόσο, παραμένει μιγαδικός αριθμός στην R.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

Μπορεί να έχεις ακούσει ότι το `i` (ή το `j`) είναι η τετραγωνική ρίζα του -1.

Για την ώρα, το μόνο που σημαίνει αυτό είναι ότι το φανταστικό μέρος _εξ ορισμού_ ικανοποιεί την παρακάτω ισότητα:

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

Αυτή είναι μια απλή ιδέα, αλλά οδηγεί σε ενδιαφέρουσες συνέπειες.

## Αριθμητική

Οι περισσότεροι τελεστές που χρησιμοποιούνται με floats και ακέραιους λειτουργούν επίσης με μιγαδικούς αριθμούς:

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## Συναρτήσεις

Οι περισσότερες μαθηματικές συναρτήσεις λειτουργούν με μιγαδικές εισόδους.

Υπάρχουν αρκετές συναρτήσεις, πέρα από τις `Re()` και `Im()`, με ιδιαίτερη σημασία για τους μιγαδικούς αριθμούς.

- Η `Conj()` απλώς αντιστρέφει το πρόσημο του φανταστικού μέρους ενός μιγαδικού αριθμού (_από + σε - ή και αντίστροφα_).
  - Λόγω του τρόπου με τον οποίο λειτουργεί ο πολλαπλασιασμός μιγαδικών, αυτό είναι πιο χρήσιμο απ' όσο νομίζεις.
- Η `abs(<complex number>)` επιστρέφει σίγουρα έναν πραγματικό αριθμό χωρίς φανταστικό μέρος (το "μέτρο" της), και η `Mod(<complex number>)` είναι συνώνυμη.
- Η `Arg(<complex number>)` επιστρέφει τη γωνία φάσης σε ακτίνια.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
