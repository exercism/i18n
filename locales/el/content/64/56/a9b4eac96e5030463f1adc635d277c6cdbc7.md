# Υποδείξεις

## Γενικά

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Το πρόθεμα για πρόσβαση σε τιμές 8 byte στη μνήμη είναι `qword`.

## 1. Έλεγξε ποιες ήταν οι καταμετρήσεις την προηγούμενη εβδομάδα

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Το πρόθεμα για πρόσβαση σε τιμές 8 byte στη μνήμη είναι `qword`.
- Για να αποκτήσεις πρόσβαση σε περιεχόμενα που είναι αποθηκευμένα σε μια διεύθυνση στη μνήμη, πρέπει να την αποαναφέρεις χρησιμοποιώντας `[]`.

## 2. Έλεγξε ποιες είναι οι τρέχουσες καταμετρήσεις για αυτή την εβδομάδα

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Το πρόθεμα για πρόσβαση σε τιμές 8 byte στη μνήμη είναι `qword`.
- Οι μη αρχικοποιημένες μεταβλητές ορίζονται στο _section .bss_.
- Θα πρέπει να χρησιμοποιήσεις και τον `rax` και τον `rdx` για να επιστρέψεις δύο ακέραιους από μια συνάρτηση.

## 3. Αποθήκευσε την καταμέτρηση για κάθε μέρα

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Το πρόθεμα για πρόσβαση σε τιμές 8 byte στη μνήμη είναι `qword`.
- Το πρόθεμα για πρόσβαση σε τιμές 1 byte στη μνήμη είναι `byte`.
- Μπορείς να εισάγεις ή να ανακτήσεις byte μαζικά χρησιμοποιώντας το πρόθεμα για μεγαλύτερο μέγεθος δεδομένων όταν αποκτάς πρόσβαση στη μνήμη.
- Μπορείς να ελέγξεις συνθήκες χρησιμοποιώντας [cmp][cmp].
- Μπορείς να διακλαδωθείς υπό συνθήκη χρησιμοποιώντας [jcc][jcc].
- Μπορείς να χρησιμοποιήσεις [inc][inc] για να προσθέσεις 1 στην τιμή ενός τελεστέου προορισμού.

## 4. Έλεγξε πόσα πουλιά επισκέφθηκαν σήμερα

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Το πρόθεμα για πρόσβαση σε τιμές 8 byte στη μνήμη είναι `qword`.
- Οι ακέραιες τιμές 1 byte επιστρέφονται στον `al`.
- Μπορείς να χρησιμοποιήσεις [dec][dec] για να αφαιρέσεις 1 από την τιμή ενός τελεστέου προορισμού.

## 5. Ενημέρωσε τη σημερινή καταμέτρηση

- Μια αποτελεσματική διεύθυνση μπορεί να υπολογιστεί με την εντολή [lea][lea].

- Μπορείς να χρησιμοποιήσεις [add][add] με έναν τελεστέο προορισμού στη μνήμη.
