# Προσθήκη οδηγιών

## Μορφή εξόδου

Δώσε την αλληλουχία πρωτεϊνών ως συμβολοσειρά τερματισμένη με null, με έναν χαρακτήρα αλλαγής γραμμής μετά από κάθε πρωτεΐνη.

Ένα παράδειγμα εξόδου θα ήταν `"Methionine\nPhenylalanine\nSerine\n"`

Αν η είσοδος δεν είναι έγκυρη, δώσε μια κενή συμβολοσειρά.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά εισόδου τερματισμένη με null  |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματισμένη με null |
| `$t0-9`  | προσωρινός    | οποιοσδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση    |
