# Οδηγίες

Η αποστολή σου είναι να μετατρέψεις περιγραφές ημερομηνίας παράδοσης σε _πραγματικές_ ημερομηνίες παράδοσης, με βάση πότε ξεκίνησε η συνάντηση.

Υπάρχουν δύο τύποι περιγραφών ημερομηνίας παράδοσης:

1. Σταθερές: ένα προκαθορισμένο σύνολο λέξεων.
2. Μεταβλητές: λέξεις που έχουν ένα μεταβλητό μέρος, αλλά ακολουθούν ένα προκαθορισμένο σύνολο μοτίβων.

## Σταθερές περιγραφές ημερομηνίας παράδοσης

Υπάρχουν τρεις σταθερές περιγραφές ημερομηνίας παράδοσης:

- `"NOW"`
- `"ASAP"` (το συντομότερο δυνατό)
- `"EOW"` (τέλος της εβδομάδας)

Ο παρακάτω πίνακας δείχνει πώς να τις μεταφράσεις:

| Περιγραφή | Έναρξη συνάντησης | Ημερομηνία παράδοσης |
| ----------- | ----------------------------- | ----------------------------------- |
| `"NOW"`     | -                             | Δύο ώρες μετά την έναρξη της συνάντησης |
| `"ASAP"`    | Πριν τις 13:00                | Σήμερα στις 17:00 |
| `"ASAP"`    | Στις 13:00 ή αργότερα         | Αύριο στις 13:00 |
| `"EOW"`     | Δευτέρα, Τρίτη ή Τετάρτη      | Παρασκευή στις 17:00 |
| `"EOW"`     | Πέμπτη ή Παρασκευή            | Κυριακή στις 20:00 |

## Μεταβλητές περιγραφές ημερομηνίας παράδοσης

Υπάρχουν δύο μοτίβα μεταβλητών περιγραφών ημερομηνίας παράδοσης:

- `"<N>M"` (N-ος μήνας)
- `"Q<N>"` (N-ο τρίμηνο)

| Περιγραφή | Έναρξη συνάντησης | Ημερομηνία παράδοσης |
| ----------- | ------------------------- | --------------------------------------------------------- |
| `"<N>M"`    | Πριν από τον N-ο μήνα     | Στις 8:00 την _πρώτη_ εργάσιμη ημέρα του N-ου μήνα του φετινού έτους |
| `"<N>M"`    | Μετά τον N-ο μήνα ή μέσα σε αυτόν | Στις 8:00 την _πρώτη_ εργάσιμη ημέρα του N-ου μήνα του επόμενου έτους |
| `"Q<N>"`    | Πριν από το N-ο τρίμηνο ή μέσα σε αυτό | Στις 8:00 την _τελευταία_ εργάσιμη ημέρα του N-ου τριμήνου του φετινού έτους |
| `"Q<N>"`    | Μετά το N-ο τρίμηνο       | Στις 8:00 την _τελευταία_ εργάσιμη ημέρα του N-ου τριμήνου του επόμενου έτους |

~~~~exercism/note
Μια εργάσιμη ημέρα είναι Δευτέρα, Τρίτη, Τετάρτη, Πέμπτη ή Παρασκευή.

Ένα έτος έχει τέσσερα τρίμηνα, καθένα με τρεις μήνες:
1. Ιανουάριος/Φεβρουάριος/Μάρτιος
2. Απρίλιος/Μάιος/Ιούνιος
3. Ιούλιος/Αύγουστος/Σεπτέμβριος
4. Οκτώβριος/Νοέμβριος/Δεκέμβριος.
~~~~
