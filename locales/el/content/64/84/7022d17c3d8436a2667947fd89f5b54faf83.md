# Αφηρημένες Κλάσεις

Μια παράσταση τσίρκου είναι μια λίστα με νούμερα. Το ζογκλέρ, το τραπέζιο και τα ακροβατικά είναι διαφορετικά πράγματα με διαφορετικό περιεχόμενο, αλλά ο άνθρωπος που συντάσσει τη σειρά των εμφανίσεων χρειάζεται μόνο δύο πράγματα από το καθένα: το όνομά του και πόσο διαρκεί.

Μια **αφηρημένη κλάση** περιγράφει ακριβώς αυτά και τίποτα παραπάνω.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Το όνομά της ξεκινά με `$`. Απαριθμεί ρουτίνες χωρίς σώμα: μόνο υπογραφές, καθεμία να τελειώνει στο ερωτηματικό. Δεν μπορεί να δημιουργηθεί τίποτα από αυτήν: δεν υπάρχει `create` ούτε `new`.

## Συμμόρφωση

Μια πραγματική κλάση υπόσχεται ότι είναι `$ACT` γράφοντας το όνομά της μετά το `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

Το `<` διαβάζεται "είναι ένα". Η κλάση πρέπει να παρέχει κάθε ρουτίνα που απαριθμεί η αφηρημένη κλάση, με τα ίδια ορίσματα και τον ίδιο τύπο επιστροφής. Το να ξεχάσεις μία είναι σφάλμα μεταγλώττισης, όχι έκπληξη κατά την εκτέλεση.

Μια κλάση μπορεί να προσθέσει ό,τι άλλο θέλει. Το `TRAPEZE` μπορεί να έχει ένα ύψος που δεν έχει κανένα άλλο νούμερο. Η αφηρημένη κλάση ούτε το ξέρει ούτε την ενδιαφέρει.

## Χρήση του τύπου

Το `$ACT` είναι ένας τύπος, οπότε οτιδήποτε μπορεί να δηλωθεί με αυτόν:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Ο πίνακας αυτός κρατά αντικείμενα από τρεις διαφορετικές κλάσεις ταυτόχρονα, κάτι που ένα `ARRAY{JUGGLING}` δεν θα μπορούσε.

## Αποστολή

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

Το `acts.elt!` είναι ένα `$ACT`. Ποιο `minutes` θα τρέξει αποφασίζεται όταν εκτελεστεί η γραμμή, από το τι είναι στην πραγματικότητα το αντικείμενο: `JUGGLING::minutes` για το ζογκλέρ, `TRAPEZE::minutes` για το τραπέζιο. Αυτή η επιλογή λέγεται **αποστολή**.

Η ρουτίνα που κάνει την πρόσθεση δεν ρωτά ποτέ τι είδους νούμερο έχει. Για να προσθέσεις ένα τέταρτο είδος νούμερου αρκεί να γράψεις μία νέα κλάση και να μην αλλάξεις τίποτα άλλο, κι αυτός είναι ο λόγος που τα κάνουμε με αυτόν τον τρόπο.
