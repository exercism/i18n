# Εισαγωγή

Το JSON ορίζει έναν **πίνακα** ως εξής:

> Ένας πίνακας είναι μια διατεταγμένη συλλογή τιμών.
> Ένας πίνακας αρχίζει με `[` αριστερή αγκύλη και τελειώνει με `]` δεξιά αγκύλη.
> Οι τιμές χωρίζονται με `,` κόμμα.

Οι πίνακες μπορούν να περιέχουν μηδέν ή περισσότερες τιμές JSON _κάθε είδους_.
Τα στοιχεία ενός πίνακα δεν χρειάζεται να είναι όλα του ίδιου τύπου.

## Δημιουργία πινάκων

Χρησιμοποίησε αγκύλες για να συγκεντρώσεις στοιχεία σε έναν πίνακα.

```jq
[1, 2, 3]
```

Τα στοιχεία μιας _ροής_ μπορούν να συλλεχθούν σε έναν πίνακα, κλείνοντάς την σε αγκύλες.

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

## Μέγεθος

Η συνάρτηση `length` επιστρέφει τον αριθμό των στοιχείων σε έναν πίνακα.

## Θέσεις και τεμαχισμός

Οι θέσεις σε έναν πίνακα ξεκινούν από το μηδέν.

Μπορείς να ανακτήσεις ένα στοιχείο από έναν πίνακα με μια έκφραση αγκύλης:
το `.[2]` παίρνει το τρίτο στοιχείο.

Οι αρνητικές θέσεις μετρούν προς τα πίσω από το τέλος του πίνακα:
το `.[-1]` παίρνει το τελευταίο στοιχείο, ενώ το `.[-2]` είναι το προτελευταίο.

Ένα **τμήμα** είναι μια υποακολουθία του πίνακα.
Το `.[10:15]` επιστρέφει 5 στοιχεία ξεκινώντας από τη θέση 10, ενώ η τελική θέση _δεν περιλαμβάνεται_.

Υπάρχουν μερικές συναρτήσεις ευκολίας:

- Το `first` παίρνει το πρώτο στοιχείο.
- Το `last` παίρνει το τελευταίο στοιχείο.
- Το `nth(n)` παίρνει το στοιχείο στη θέση `n`.

## Επανάληψη

Το `jq` παρέχει πολλές συναρτήσεις που καλύπτουν τη συνήθη λειτουργικότητα της επανάληψης:

- Το `map(expr)` επιστρέφει έναν νέο πίνακα όπου το `expr` εφαρμόζεται σε κάθε στοιχείο με τη σειρά.

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- Το `select(expr)` είναι μια συνάρτηση που εφαρμόζει το `expr` σε μια _μεμονωμένη τιμή_.
  Αν το αποτέλεσμα της έκφρασης είναι αληθές, τότε η τιμή επιστρέφεται.
  Αν το αποτέλεσμα είναι ψευδές, _τίποτα_ δεν επιστρέφεται: όχι `null`, αλλά στην πραγματικότητα τίποτα.

  Για να το εφαρμόσεις σε έναν πίνακα, συνδύασέ το με το `map`.

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  Εναλλακτικά, εφάρμοσε το `select` σε μια _ροή_ και συγκέντρωσε τα αποτελέσματα.

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- Τα `any(condition)` και `all(condition)` επιστρέφουν μια Boolean (λογική τιμή) που δείχνει αν οποιοδήποτε ή όλα τα στοιχεία του πίνακα ικανοποιούν τη συνθήκη.

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
