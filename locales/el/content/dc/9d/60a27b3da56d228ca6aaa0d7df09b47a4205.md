# Σχετικά

Μερικές φορές, όταν μια συνάρτηση δέχεται πολλά ορίσματα, μπορεί να είναι δύσκολο να θυμάσαι τη σειρά με την οποία πρέπει να δοθούν. Για καλύτερη αναγνωσιμότητα, η Gleam επιτρέπει στα ορίσματα να έχουν ετικέτα με ένα όνομα.

Για να βάλεις ετικέτα σε ένα όρισμα, γράφεις το όνομα της ετικέτας πριν από το όνομα του ορίσματος, χωρισμένα με ένα κενό.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Όταν καλείς μια συνάρτηση με ορίσματα με ετικέτα, μπορείς να δώσεις τα ορίσματα με οποιαδήποτε σειρά. Καθεμία από αυτές τις κλήσεις της `replace` είναι ισοδύναμη:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Οι ετικέτες είναι πάντα προαιρετικές. Ακόμα κι αν μια συνάρτηση έχει ορίσματα με ετικέτα, μπορείς να την καλέσεις και χωρίς ετικέτες.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Όταν ορίζεις μια συνάρτηση με ορίσματα με ετικέτα, όλα τα ορίσματα μετά το πρώτο όρισμα με ετικέτα πρέπει να έχουν και αυτά ετικέτα.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
