# Εισαγωγή

Η Βικιπαίδεια περιγράφει μια εντολή `switch` ως "έναν τύπο μηχανισμού ελέγχου επιλογής που επιτρέπει στην τιμή μιας μεταβλητής ή μιας παράστασης να αλλάξει τη ροή ελέγχου του προγράμματος".

Ο μηχανισμός περιλαμβάνει τις εξής λέξεις-κλειδιά: `switch`, `case`, `break` και `default`.

Στην απλούστερη μορφή τους ελέγχουν μια παράσταση πρωτογενούς τύπου ή συμβολοσειράς και παίρνουν μια απόφαση με βάση την τιμή της. Για παράδειγμα:

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

Στην πιο εξελιγμένη μορφή τους εισάγουν downcasting `case <Type> <variable>:` και φρουρούς (`when`).

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
