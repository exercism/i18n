# χωρίς debug

Οι συναρτήσεις `Debug` (`Debug.todo`, `Debug.toString` και `Debug.log`) είναι πολύ χρήσιμες κατά την ανάπτυξη, αλλά δεν πρέπει ποτέ να φτάσουν στο παραγωγικό περιβάλλον, να δημοσιευτούν σε ένα πακέτο ή να αποτελέσουν μέρος της τελικής λύσης σου.

Καλό θα ήταν να τις αφαιρέσεις πριν δημοσιεύσεις τη λύση σου.
