# Εισαγωγή

## Γενικοί τύποι

Ένας ορισμός συλλογής περιλαμβάνει συνήθως μια θέση μέσα σε γωνιακές αγκύλες, συχνά το `T` κατά σύμβαση. Μια τέτοια συλλογή ονομάζεται γενικός τύπος. Αυτό επιτρέπει στον χρήστη της συλλογής να καθορίσει τι τύπου στοιχεία θα αποθηκεύονται στη συλλογή. Στο παρακάτω παράδειγμα κώδικα, δημιουργούμε ένα στιγμιότυπο μιας λίστας συμβολοσειρών.

## Λίστες

Οι λίστες στη C# είναι συλλογές από πρωτογενείς τιμές ή στιγμιότυπα δομών ή κλάσεων. Υλοποιούνται στη βιβλιοθήκη βασικών κλάσεων ως `List<T>`, όπου το `T` είναι ο τύπος του στοιχείου στη λίστα. Το API παρέχει ένα πλούσιο σύνολο μεθόδων για τη δημιουργία και τον χειρισμό λιστών.

Στις λίστες μπορούν να προστεθούν και να αφαιρεθούν στοιχεία. Μεγαλώνουν και μικραίνουν ανάλογα με τις ανάγκες.

```csharp
var listOfStrings = new List<string>();
```
