# Προσθήκη στις οδηγίες

## Δοκιμές

Οι δοκιμές θα εκτελέσουν ορισμένες λειτουργίες ταυτόχρονα.
Πρέπει να φροντίσεις ώστε οι λειτουργίες στο Account να το αφήνουν σε συνεπή κατάσταση.
Για παράδειγμα: πολλές goroutines μπορεί να καταθέτουν και να κάνουν ανάληψη χρημάτων ταυτόχρονα, και δύο αναλήψεις που συμβαίνουν ταυτόχρονα δεν θα πρέπει να μπορούν να κάνουν το υπόλοιπο αρνητικό.

Όταν δουλεύεις τοπικά, για να ελέγξεις ότι ο κώδικάς σου χειρίζεται σωστά τον ταυτοχρονισμό και δεν εισάγει data races, τρέξε τις δοκιμές με το flag `-race` ενεργό.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
