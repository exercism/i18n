# Εισαγωγή

Στη Go 1.18, η Go πρόσθεσε υποστήριξη για **generics**.
Τα generics σου επιτρέπουν να γράφεις συναρτήσεις και δομές δεδομένων που λειτουργούν με διαφορετικούς τύπους χωρίς να αντιγράφεις κώδικα.

## Γιατί generics;

Στη Go, οι συναρτήσεις και οι τύποι συνήθως λειτουργούν με συγκεκριμένους τύπους, όπως `int` ή `string`.
Πριν από τα generics, είχες δύο επιλογές για να υποστηρίξεις πολλούς τύπους.
Πρώτον, μπορούσες να γράψεις πολλές συναρτήσεις με διαφορετικά ονόματα, όπως `SumInts` και `SumFloats`.
Αυτή η προσέγγιση δημιουργεί διπλότυπο κώδικα που είναι δύσκολο να συντηρηθεί.
Δεύτερον, μπορούσες να χρησιμοποιήσεις την κενή διεπαφή `any` (`interface{}`).
Ωστόσο, η κενή διεπαφή αφαιρεί τους ελέγχους τύπων κατά τη μεταγλώττιση και απαιτεί βεβαιώσεις τύπου κατά την εκτέλεση.
Τα generics λύνουν αυτό το πρόβλημα παρέχοντας ασφάλεια τύπων και αποφεύγοντας τον διπλότυπο κώδικα.

## Γενικές συναρτήσεις

Ορίζεις μια γενική συνάρτηση προσθέτοντας **παραμέτρους τύπου** σε αγκύλες `[...]` μετά το όνομα της συνάρτησης.
Ακολουθεί ένα παράδειγμα γενικής συνάρτησης που επιστρέφει μια slice με αντίστροφη σειρά:

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

Σε αυτό το παράδειγμα, το `T` είναι μια παράμετρος τύπου.
Μπορείς να σκεφτείς το `T` ως κάτι που στέκεται στη θέση ενός πραγματικού τύπου.
Η λέξη-κλειδί `any` μέσα στις αγκύλες είναι ένας **περιορισμός τύπου**.
Ο περιορισμός λέει στον μεταγλωττιστή ποιοι τύποι επιτρέπονται για το `T`.
Εδώ, το `any` σημαίνει ότι το `T` μπορεί να είναι οποιοσδήποτε τύπος.

### Κλήση γενικών συναρτήσεων

Μπορείς να καλέσεις μια γενική συνάρτηση περνώντας τον πραγματικό τύπο σε αγκύλες.
Αυτός ο πραγματικός τύπος ονομάζεται **όρισμα τύπου**.

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

Στις περισσότερες περιπτώσεις, ο μεταγλωττιστής της Go μπορεί να εντοπίσει αυτόματα τον τύπο από τα ορίσματα της συνάρτησης.
Αυτό το χαρακτηριστικό ονομάζεται **εξαγωγή τύπου**.
Με την εξαγωγή τύπου, δεν χρειάζεται να γράψεις το όρισμα τύπου μέσα σε αγκύλες.

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

Σε αυτό το παράδειγμα, ο μεταγλωττιστής βλέπει ότι το `words` είναι μια slice από συμβολοσειρές, οπότε συμπεραίνει πως το `T` είναι `string`.

## Περιορισμοί τύπου

Κάθε παράμετρος τύπου πρέπει να έχει έναν περιορισμό.
Ένας περιορισμός καθορίζει ποιους τύπους μπορείς να χρησιμοποιήσεις ως ορίσματα τύπου.
Ο περιορισμός καθορίζει επίσης τις πράξεις που επιτρέπεται να εκτελέσεις σε τιμές αυτού του τύπου.

### Ο περιορισμός `any`

Ο περιορισμός `any` επιτρέπει οποιονδήποτε τύπο.
Στη Go, το `any` είναι ψευδώνυμο για την κενή διεπαφή `interface{}`.
Επειδή το `any` επιτρέπει κάθε τύπο, η συνάρτηση μπορεί να εκτελέσει μόνο πράξεις που δουλεύουν με όλους τους τύπους της Go.
Για παράδειγμα, αν έχεις δύο τιμές `any` που περιέχουν slices, δεν μπορούν να συγκριθούν με `==`, καθώς οι slices δεν μπορούν να συγκριθούν με `==`.

### Ο περιορισμός `comparable`

Η Go παρέχει έναν ενσωματωμένο περιορισμό που ονομάζεται `comparable`.
Ο περιορισμός `comparable` επιτρέπει οποιονδήποτε τύπο που υποστηρίζει τους τελεστές `==` και `!=`.
Οι συγκρίσιμοι τύποι περιλαμβάνουν Boolean, αριθμούς, συμβολοσειρές, δείκτες, κανάλια και struct ή πίνακες που αποτελούνται από συγκρίσιμους τύπους.

Ακολουθεί ένα παράδειγμα συνάρτησης που ελέγχει αν μια slice περιέχει ένα συγκεκριμένο στοιχείο:

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

Επειδή το `T` χρησιμοποιεί τον περιορισμό `comparable`, η χρήση του `elem == target` είναι έγκυρη.
Αν αντικαταστήσεις το `comparable` με `any`, ο μεταγλωττιστής θα αναφέρει ένα σφάλμα.

### Προσαρμοσμένοι περιορισμοί με σύνολα τύπων σε διεπαφές

Ξεκινώντας από τη Go 1.18, οι διεπαφές μπορούν να ορίζουν σύνολα τύπων εκτός από μεθόδους.
Μπορείς να χρησιμοποιήσεις τον χαρακτήρα κάθετης γραμμής `|` για να απαριθμήσεις τους επιτρεπόμενους τύπους σε μια διεπαφή.

```go
type Number interface {
    int | int64 | float64
}
```

Τώρα μπορείς να χρησιμοποιήσεις το `Number` ως περιορισμό για μια συνάρτηση:

```go
func Double[T Number](value T) T {
    return value * 2
}
```

Επειδή όλοι οι τύποι στο `Number` υποστηρίζουν τον τελεστή `*`, η Go επιτρέπει το `value * 2` μέσα στη συνάρτηση.

### Η προσέγγιση υποκείμενου τύπου `~`

Μερικές φορές δημιουργείς έναν προσαρμοσμένο ορισμό τύπου με βάση έναν πρωταρχικό τύπο:

```go
type MyInt int
```

Ο περιορισμός `Number` που ορίστηκε παραπάνω επιτρέπει μόνο τους ακριβείς τύπους `int`, `int64` και `float64`.
Αν περάσεις μια τιμή `MyInt` στη `Double`, ο μεταγλωττιστής παράγει ένα σφάλμα, επειδή το `MyInt` δεν ταιριάζει με το `int`.
Για να επιτρέψεις οποιονδήποτε τύπο του οποίου ο υποκείμενος τύπος είναι `int`, πρόσθεσε το σύμβολο `~` πριν από τον τύπο:

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

Τώρα μπορείς να χρησιμοποιήσεις τη `Double` με τιμές τύπου `MyInt`.

### Ο περιορισμός `cmp.Ordered`

Η τυπική βιβλιοθήκη παρέχει τον περιορισμό `cmp.Ordered` στο [πακέτο `cmp`][doc-cmp].
Ο περιορισμός `cmp.Ordered` επιτρέπει οποιονδήποτε τύπο που υποστηρίζει τους τελεστές σύγκρισης `<`, `<=`, `>` και `>=`.

## Γενικοί τύποι

Μπορείς επίσης να χρησιμοποιήσεις παραμέτρους τύπου για να ορίσεις γενικούς τύπους, όπως struct.
Ακολουθεί ένα παράδειγμα γενικής δομής δεδομένων `Stack`:

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

Όταν δηλώνεις μια μεταβλητή γενικού τύπου, πρέπει να δώσεις το όρισμα τύπου σε αγκύλες:

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

Η εξαγωγή τύπου λειτουργεί μόνο για γενικές συναρτήσεις.
Πρέπει πάντα να καθορίζεις το όρισμα τύπου όταν δημιουργείς τιμές ενός γενικού τύπου.

## Πότε να χρησιμοποιείς generics

Τα generics είναι ένα ισχυρό χαρακτηριστικό, αλλά δεν χρειάζεται να τα χρησιμοποιείς για κάθε πρόβλημα.

Χρησιμοποίησε generics σε περιπτώσεις όπως οι εξής:
- Κατασκευάζεις δομές δεδομένων, όπως δέντρα, συνδεδεμένες λίστες ή caches, που λειτουργούν με οποιονδήποτε τύπο στοιχείου.
- Γράφεις βοηθητικές συναρτήσεις που λειτουργούν σε slices ή maps οποιουδήποτε τύπου, όπως φιλτράρισμα, ταξινόμηση ή αναζήτηση.
- Χρειάζεσαι την ίδια ακριβώς υλοποίηση για πολλούς τύπους και θέλεις ασφάλεια τύπων κατά τη μεταγλώττιση.

Χρησιμοποίησε αντίθετα διεπαφές σε περιπτώσεις όπως οι εξής:
- Σε ενδιαφέρει η συμπεριφορά και οι μέθοδοι, παρά ο υποκείμενος τύπος δεδομένων.
  Για παράδειγμα, αν θέλεις να διαβάζεις και να επεξεργάζεσαι δεδομένα από πηγές διαφόρων τύπων (αρχεία, δίκτυο, TTY), θα χρησιμοποιούσες `func Process(src io.Reader)` αντί για `func Process[T](src T)`.
- Διαφορετικοί τύποι απαιτούν διαφορετικές υλοποιήσεις μεθόδων για να κάνουν τη δουλειά τους.
