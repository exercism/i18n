# Σχετικά

Συνήθως, οι συναρτήσεις δέχονται μόνο έναν σταθερό αριθμό ορισμάτων.
Ωστόσο, αν βάλεις `...` πριν από τον τύπο της τελευταίας παραμέτρου, η συνάρτηση μπορεί να δεχτεί οποιονδήποτε αριθμό ορισμάτων στο τέλος.
Έτσι, η τελευταία παράμετρος γίνεται μια _παράμετρος μεταβλητού αριθμού_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

Μέσα στη συνάρτηση, η παράμετρος μεταβλητού αριθμού είναι ένα slice:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

Μια συνάρτηση μπορεί να έχει κι άλλες παραμέτρους πριν από την παράμετρο μεταβλητού αριθμού.
Μια συνάρτηση μπορεί να έχει το πολύ μία παράμετρο μεταβλητού αριθμού, και αυτή πρέπει να είναι η τελευταία παράμετρος.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## Επέκταση ενός slice

Για να περάσεις ένα slice στην παράμετρο μεταβλητού αριθμού, βάλε `...` μετά από αυτό:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

Το `...` είναι έγκυρο μόνο όταν περνάς ένα slice σε μια παράμετρο μεταβλητού αριθμού.
