# Υποδείξεις

## 1. Γενικά

- Διάβασε για τα αρχεία στον επίσημο οδηγό [Ξεκινώντας][getting-started-file].
- Διάβασε για τα αρχεία στο [joyofelixir.com][joy-of-elixir-file].
- Ρίξε μια ματιά στην [τεκμηρίωση του module `File`][file].

## 1. Διάβασε διευθύνσεις email από ένα αρχείο

- Υπάρχει μια [ενσωματωμένη συνάρτηση][file-read] για να διαβάσεις τα περιεχόμενα ενός αρχείου μονομιάς.

## 2. Άνοιξε ένα αρχείο καταγραφής για εγγραφή

- Υπάρχει μια [ενσωματωμένη συνάρτηση][file-open] για το άνοιγμα ενός αρχείου.
- Το δεύτερο όρισμα αυτής της συνάρτησης είναι μια λίστα από τρόπους λειτουργίας που σου επιτρέπει να ορίσεις ότι το αρχείο πρέπει να ανοίξει για εγγραφή.

## 3. Κατέγραψε ένα σταλμένο email

- Συναρτήσεις για ανάγνωση και εγγραφή σε ένα αρχείο που άνοιξε με το [`File.open!/1`][file-open] θα βρεις στο module [`IO`][io].
- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-puts] για να γράψεις μια συμβολοσειρά σε ένα αρχείο, ακολουθούμενη από μια νέα γραμμή.

## 4. Κλείσε το αρχείο καταγραφής

- Υπάρχει μια [ενσωματωμένη συνάρτηση][file-close] για το κλείσιμο ενός αρχείου.

## 5. Στείλε το ενημερωτικό δελτίο

- Όλες οι απαραίτητες λειτουργίες στα αρχεία έχουν ήδη υλοποιηθεί στα προηγούμενα βήματα.
- Πριν γράψεις σε ένα αρχείο, πρέπει πρώτα να το ανοίξεις.
- Αφού ολοκληρωθούν όλες οι λειτουργίες εγγραφής σε ένα αρχείο, θα πρέπει να το κλείσεις.
