# Εγκατάσταση

- macOS: τρέξε `brew install futhark`
- linux: τρέξε `brew install futhark`
- Windows: είτε χρησιμοποίησε το WSL είτε ακολούθησε [τις ειδικές οδηγίες για Windows][windows-specific-instructions]

Εναλλακτικούς τρόπους εγκατάστασης θα βρεις στις [επίσημες οδηγίες εγκατάστασης][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
