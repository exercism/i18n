# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να φτιάξεις μια καταπληκτική λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το ψήσιμο της λαζάνιας.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε μια σταθερά με το όνομα `$expected_minutes_in_oven`.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Αυτή η τιμή παίρνει ως είσοδο τα πραγματικά λεπτά που έχει ήδη ψηθεί η λαζάνια και επιστρέφει πόσα λεπτά πρέπει ακόμα να παραμείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Ο χρόνος προετοιμασίας είναι όσος χρόνος χρειάζεται για να ετοιμαστεί η λαζάνια πριν μπει στον φούρνο.
Χρειάζονται 2 λεπτά για να προετοιμάσεις κάθε στρώση.

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υπολόγισε πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας.
Αυτό είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο μέχρι στιγμής.

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
