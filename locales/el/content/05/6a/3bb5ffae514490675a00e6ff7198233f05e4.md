# Υποδείξεις

## 1. Δημιούργησε ένα νέο ταμπλό υψηλών σκορ

- Δημιούργησε ένα νέο αντικείμενο χρησιμοποιώντας άγκιστρα.
- Γράψε το κλειδί ως συμβολοσειρά, ώστε το κλειδί να μπορεί να περιέχει κενά.
- Χώρισε το κλειδί από την τιμή με άνω και κάτω τελεία.

## 2. Πρόσθεσε παίκτες σε ένα ταμπλό σκορ

- Χρησιμοποίησε συμβολισμό με αγκύλες για να προσθέσεις ένα κλειδί με όνομα που είναι αποθηκευμένο σε μια μεταβλητή (το όρισμα).
- Χρησιμοποίησε τον τελεστή ανάθεσης (`=`) για να ορίσεις μια τιμή για το νέο κλειδί.
- Εναλλακτικά, χρησιμοποίησε τον [τελεστή `+`][man-plus] για να συγχωνεύσεις το εισερχόμενο αντικείμενο με ένα νέο.
- Θυμήσου ότι χρειάζονται παρενθέσεις γύρω από εκφράσεις για κλειδιά αντικειμένων.

## 3. Αφαίρεσε παίκτες από ένα ταμπλό σκορ

- Χρησιμοποίησε την [έκφραση del][man-del].
- Αναφέρσου στο κλειδί όπως έκανες στην προηγούμενη εργασία (συμβολισμός με αγκύλες).
- Θυμήσου ότι το όρισμα του `del` είναι μια _έκφραση θέσης_, όχι απλώς μια συμβολοσειρά.

## 4. Αύξησε το σκορ ενός παίκτη

- Πρώτα σκέψου πώς θα εκφράσεις τη νέα τιμή που θέλεις να αναθέσεις.
- Έπειτα χρησιμοποίησε τον τελεστή ανάθεσης, όπως στην εργασία 2, για να ορίσεις αυτή τη νέα τιμή.
- Αν δεν το έχεις κάνει ήδη, μπορείς να χρησιμοποιήσεις τον [αριθμητικό τελεστή ανάθεσης με ενημέρωση][man-update-assignment] `+=`.

## 5. Εφάρμοσε τους μπόνους πόντους της Δευτέρας

- Εδώ είναι καλή στιγμή να χρησιμοποιήσεις τα `to_entries`/`from_entries`, ή το `with_entries` για να κάνεις επανάληψη πάνω στο αντικείμενο
- Για κάθε κλειδί, όρισε τη νέα τιμή όπως έκανες στην εργασία 4.

## 6. Βρες το συνολικό σκορ

- Θέλουμε να κάνουμε επανάληψη πάνω στις _τιμές_ του αντικειμένου.
  Μπορούμε να χρησιμοποιήσουμε το [`map_values`][man-map_values] ή το [`.[]`][man-brackets] για να βγάλουμε μια ροή τιμών.
- Η έκφραση `add` μπορεί να χρησιμοποιηθεί για να βρεις το άθροισμα μιας λίστας αριθμών.
