# Εισαγωγή

## Δήλωση τύπων

Οι δηλώσεις τύπων στην PHP παρέχουν ελέγχους τύπων κατά τον χρόνο εκτέλεσης για ορίσματα συναρτήσεων, τιμές επιστροφής και ιδιότητες κλάσεων.
Στις συναρτήσεις, μπορεί να προστεθεί ένας τύπος επιστροφής `void` για να δηλωθεί ότι η συνάρτηση δεν επιστρέφει καμία τιμή.
Οι δηλωμένοι τύποι λειτουργούν επίσης ως έλεγχοι κατά τον χρόνο εκτέλεσης ότι οι συναρτήσεις επιστρέφουν μια τιμή με λογικό τύπο.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Ενώσεις τύπων

Αν ένα όρισμα συνάρτησης, μια τιμή επιστροφής ή μια ιδιότητα κλάσης μπορεί να είναι περισσότερων από έναν τύπων, μπορεί να δηλωθεί μια ένωση τύπων.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Μικτοί τύποι

Όταν δουλεύουμε με κώδικα, μπορεί να μην μπορούμε να προσδιορίσουμε έναν τύπο.
Από την PHP 8.0 και μετά, παρέχεται ένας τύπος διαφυγής με το όνομα `mixed`.
Το `mixed` ισοδυναμεί με μια ένωση τύπων των `object|resource|array|string|float|int|bool|null`.
