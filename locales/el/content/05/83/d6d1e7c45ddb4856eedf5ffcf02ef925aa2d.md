# Εισαγωγή

Το Αφηρημένο Συντακτικό Δέντρο (Abstract Syntax Tree, AST), γνωστό και ως _quoted expression_, είναι ένας τρόπος αναπαράστασης του κώδικα ως δεδομένα.

Κάθε κόμβος στο AST είναι μια πλειάδα τριών στοιχείων.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

Το πρώτο στοιχείο, ένα άτομο, είναι η πράξη. Το δεύτερο στοιχείο, μια λίστα λέξεων-κλειδιών, είναι τα μεταδεδομένα. Το τρίτο στοιχείο είναι μια λίστα ορισμάτων, η οποία περιέχει άλλους κόμβους. Οι κυριολεκτικές τιμές, όπως οι ακέραιοι, τα άτομα και οι συμβολοσειρές, αναπαρίστανται στο AST ως οι ίδιες αντί ως πλειάδες τριών στοιχείων.

## Μετατροπή κώδικα σε AST

Η μετατροπή κώδικα Elixir σε AST και AST πίσω σε κώδικα είναι μέρος της τυπικής βιβλιοθήκης. Μπορείς να βρεις συναρτήσεις για να δουλέψεις με AST στα αρθρώματα `Code` (π.χ. για να μετατρέψεις μια συμβολοσειρά με κώδικα σε AST) και `Macro` (π.χ. για να διατρέξεις το AST ή να το μετατρέψεις σε συμβολοσειρά).

Σημείωσε ότι όλες οι συναρτήσεις της τυπικής βιβλιοθήκης χρησιμοποιούν το όνομα "quoted" για να δηλώσουν το AST (συντομογραφία του _quoted expression_).

Η ειδική μορφή που μετατρέπει κώδικα σε AST ονομάζεται `quote`. Δέχεται ένα μπλοκ κώδικα και επιστρέφει το AST του.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

## Περιπτώσεις χρήσης

Η δυνατότητα αναπαράστασης του κώδικα ως AST βρίσκεται στην καρδιά του μεταπρογραμματισμού στην Elixir. Οι _μακροεντολές_, που είναι ένας τρόπος να γράψεις κώδικα Elixir ο οποίος παράγει κώδικα Elixir, λειτουργούν επιστρέφοντας AST ως αποτέλεσμα.

Μια άλλη περίπτωση χρήσης των AST είναι η στατική ανάλυση κώδικα, όπως το Analyzer, το εργαλείο του Exercism, που ίσως το ξέρεις ήδη ως το μικρό bot που αφήνει σχόλια στις λύσεις σου.
