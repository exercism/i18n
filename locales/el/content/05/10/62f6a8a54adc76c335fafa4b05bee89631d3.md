# Εισαγωγή στα Βασικά

Η [Go](https://golang.org) είναι μια στατικά τυποποιημένη, μεταγλωττισμένη γλώσσα προγραμματισμού.
Η σύνταξη της Go είναι παρόμοια με αυτή της C.
Η γλώσσα συχνά αναφέρεται ως Golang εξαιτίας του παλιού ονόματος τομέα της, golang.org, αλλά το σωστό όνομα είναι Go.

Η έννοια των Βασικών θα παρουσιάσει τρία σημαντικά χαρακτηριστικά της γλώσσας: Πακέτα, Συναρτήσεις και Μεταβλητές.

## Πακέτα

Οι εφαρμογές σε Go οργανώνονται σε πακέτα.
Ένα πακέτο είναι μια συλλογή αρχείων πηγαίου κώδικα που βρίσκονται στον ίδιο κατάλογο.
Όλα τα αρχεία πηγαίου κώδικα σε έναν κατάλογο πρέπει να έχουν το ίδιο όνομα πακέτου.
Συνηθίζεται το όνομα του πακέτου να είναι ο τελευταίος κατάλογος στη διαδρομή εισαγωγής.
Για παράδειγμα, τα αρχεία στο [πακέτο "math/rand"](https://golang.org/src/math/rand/) ξεκινούν με την εντολή `package rand`.
Όταν ένα πακέτο εισάγεται, μόνο οντότητες (συναρτήσεις, τύποι, μεταβλητές, σταθερές) των οποίων τα ονόματα αρχίζουν με κεφαλαίο γράμμα μπορούν να χρησιμοποιηθούν ή να είναι προσβάσιμες.
Ο προτεινόμενος τρόπος ονομασίας στη Go είναι τα αναγνωριστικά να ονομάζονται με `camelCase`, εκτός από εκείνα που προορίζονται να είναι προσβάσιμα σε άλλα πακέτα, τα οποία θα πρέπει να είναι `PascalCase`.

```go
package lasagna
```

## Μεταβλητές

Η Go είναι στατικά τυποποιημένη, που σημαίνει ότι όλες οι μεταβλητές [πρέπει να έχουν καθορισμένο τύπο](https://en.wikipedia.org/wiki/Type_system) κατά τη μεταγλώττιση.

Οι μεταβλητές μπορούν να οριστούν καθορίζοντας ρητά έναν τύπο:

```go
var explicit int // Explicitly typed
```

Μπορείς επίσης να χρησιμοποιήσεις έναν αρχικοποιητή, και ο μεταγλωττιστής θα αποδώσει στη μεταβλητή τύπο που ταιριάζει με τον τύπο του αρχικοποιητή.

```go
implicit := 10   // Implicitly typed as an int
```

Αφού δηλωθούν, οι μεταβλητές μπορούν να πάρουν τιμές χρησιμοποιώντας τον τελεστή `=`.
Αφού δηλωθεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Σταθερές

Οι σταθερές κρατούν ένα κομμάτι δεδομένων ακριβώς όπως οι μεταβλητές, αλλά η τιμή τους δεν μπορεί να αλλάξει κατά την εκτέλεση του προγράμματος.

Οι σταθερές ορίζονται με τη λέξη-κλειδί `const` και μπορούν να είναι αριθμοί, χαρακτήρες, συμβολοσειρές ή Boolean (λογικές τιμές):

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Συναρτήσεις

Οι συναρτήσεις της Go δέχονται μηδέν ή περισσότερες παραμέτρους.
Οι παράμετροι πρέπει να έχουν ρητό τύπο, δεν υπάρχει εξαγωγή τύπου.

Οι τιμές επιστρέφονται από τις συναρτήσεις με τη λέξη-κλειδί `return`.

Μια συνάρτηση καλείται καθορίζοντας το όνομα της συνάρτησης και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης.

Σημείωσε ότι η Go υποστηρίζει δύο τύπους σχολίων.
Τα σχόλια μίας γραμμής προηγούνται από `//` και τα σχόλια πολλών γραμμών τοποθετούνται ανάμεσα σε `/*` και `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
