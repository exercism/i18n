# Οδηγίες

Σε αυτή την άσκηση θα παράγεις ημιδομημένα μηνύματα καταγραφής.

## 1. Παράγαγε ημιδομημένα μηνύματα

Θα ξεκινήσεις με μερικές ατελείς συναρτήσεις και την παρακάτω απαρίθμηση:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

Ο στόχος σου είναι να παράγεις ένα μήνυμα καταγραφής ως εξής: `"[<LEVEL>]: <MESSAGE>"`.
Θα χρειαστεί να υλοποιήσεις συναρτήσεις που αντιστοιχούν στα επίπεδα καταγραφής.

Για παράδειγμα, το παρακάτω απόσπασμα δείχνει μια αναμενόμενη έξοδο για τη συνάρτηση `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Και για το `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Καλή διασκέδαση!

## 2. Προαιρετική περαιτέρω εξάσκηση

Υπάρχει ένα test σε αυτή τη σουίτα που ελέγχεται από feature gate.
Τα feature gates απενεργοποιούν εντελώς τη μεταγλώττιση για ορισμένα τμήματα του προγράμματός σου.
Θα τα καλύψουμε αργότερα.
Για την ώρα, απλώς να ξέρεις ότι υπάρχει ένα test που χτίζεται και εκτελείται μόνο όταν χρησιμοποιείς έναν ειδικό τρόπο εκτέλεσης των test:

```sh
cargo test --features add-a-variant
```

Αυτό το test έχει σκοπό να σου δείξει πώς να προσθέσεις μια παραλλαγή στην απαρίθμησή σου.
