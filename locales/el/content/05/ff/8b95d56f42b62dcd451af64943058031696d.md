# Υποδείξεις

## 1. Όρισε τον αδιαφανή τύπο `TreasureChest`.

- Οι αδιαφανείς τύποι ορίζονται με τη λέξη-κλειδί `opaque`.

## 2. Όρισε τη συνάρτηση `create`.

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `string.length`][length] για να βρεις το μήκος μιας συμβολοσειράς.

## 3. Όρισε τη συνάρτηση `open`.

- Μπορείς να χρησιμοποιήσεις τον τελεστή `==` για να συγκρίνεις δύο συμβολοσειρές ως προς την ισότητα.

[length]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#length
