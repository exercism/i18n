# Εισαγωγή

Ένα `bit` είναι η πιο στοιχειώδης τιμή στους υπολογιστές.
Η λέξη `bit` είναι σύντμηση του "binary digit", δηλαδή του δυαδικού ψηφίου.
Είναι μια μονάδα αποθήκευσης δεδομένων στο περιβάλλον εκτέλεσης, αρκετά μεγάλη ώστε να μπορεί να περιέχει ένα αντικείμενο που μπορεί να έχει μία από δύο τιμές.
Ως εκ τούτου, έχει δυαδική τιμή είτε `1` είτε `0`.
Όλοι οι άλλοι τύποι δεδομένων αποτελούνται από πολλά `bits`.
Για παράδειγμα, ένα `byte` συνήθως αποτελείται από οκτώ `bits`.

## Μάσκες bit

Μια μάσκα bit μπορεί να είναι οποιαδήποτε τιμή που χρησιμοποιείται για τον ορισμό μεμονωμένων bit.
Για παράδειγμα, το αγγλικό αλφάβητο έχει είκοσι έξι γράμματα.
Μια τιμή τουλάχιστον είκοσι έξι bit, όπως ένας ανυπόγραφος ακέραιος 32 bit, θα μπορούσε να χρησιμοποιηθεί ως μάσκα bit για να ορίσει μια συνθήκη `true` ή `false` για κάθε αγγλικό γράμμα.
Οποιαδήποτε τιμή έχει αρκετά bit για να χειριστεί ένα απαιτούμενο σύνολο συνθηκών `true` ή `false` μπορεί να λειτουργήσει ως μάσκα bit.
Ο ορισμός και η ανάγνωση των μεμονωμένων bit γίνονται με τη χρήση τελεστών bitwise.

## Τελεστές bitwise

Ας πούμε ότι θέλουμε να παρακολουθούμε ποια γράμματα εμφανίζονται σε μια `string`.
Για το παράδειγμά μας, θα χρησιμοποιήσουμε μόνο τα είκοσι έξι γράμματα του αγγλικού αλφαβήτου.
Η μάσκα bit μας θα είναι ένας ανυπόγραφος ακέραιος 32 bit.
Ένα `0` θα αντιπροσωπεύει ότι το γράμμα δεν εμφανίζεται.
Ένα `1` θα αντιπροσωπεύει ότι το γράμμα εμφανίζεται μία ή περισσότερες φορές.
Στην αρχή, η δυαδική αναπαράσταση της μάσκας bit μας θα είναι 32 `0s` στη σειρά: `00000000000000000000000000000000`.
Η θέση τέρμα δεξιά θα είναι για το `A`.
Η δεύτερη από τα αριστερά θα είναι για το `B`, και ούτω καθεξής.
Ας πούμε ότι επεξεργαζόμαστε όλα τα γράμματα της συμβολοσειράς σε έναν βρόχο, οπότε θέλουμε μία γραμμή κώδικα που θα λειτουργεί για τον ορισμό οποιουδήποτε γράμματος.

### Τελεστής bitwise ολίσθησης αριστερά: ένας τρόπος να τοποθετήσεις ένα bit

Ο `<<` είναι ο τελεστής bitwise για ολίσθηση αριστερά.

Αν το γράμμα μας είναι `A`, δεν θέλουμε να κάνουμε ολίσθηση αριστερά, αλλά αν το γράμμα μας είναι `B`, θέλουμε να κάνουμε ολίσθηση αριστερά κατά μία θέση, κι αν το γράμμα μας είναι `C`, θέλουμε να κάνουμε ολίσθηση αριστερά κατά δύο θέσεις, και ούτω καθεξής.
Αν και μπορούμε να αντιλαμβανόμαστε τα `chars` ως γράμματα όπως το `A` ή το `B`, ένα `char` υλοποιείται ως ακέραιος τύπος στη μνήμη, οπότε μπορούμε να κάνουμε απλή αριθμητική με ένα `char`.
Δεδομένης μιας μεταβλητής με όνομα `letter` που αντιπροσωπεύει το `char` που επεξεργαζόμαστε, μπορούμε να κάνουμε ολίσθηση αριστερά κατά τον απαιτούμενο αριθμό θέσεων μετατοπίζοντας το `1` αριστερά κατά τη διαφορά ανάμεσα στο `letter` και το `char` του `A`, ως εξής: `1 << letter - 'A'`.
Το `A` - `A` είναι `0`, οπότε θα κάνει ολίσθηση αριστερά κατά `0` θέσεις αν το `letter` είναι `A`.
Το `B` - `A` είναι `1`, οπότε θα κάνει ολίσθηση αριστερά κατά `1` θέση αν το `letter` είναι `B`, και ούτω καθεξής.

### Τελεστής bitwise συμπεριληπτικού Ή: ένας τρόπος να ορίσεις ένα bit

Μόλις ξέρουμε _πού_ θέλουμε να ορίσουμε ένα bit, μπορούμε πραγματικά να το ορίσουμε χρησιμοποιώντας τον τελεστή bitwise συμπεριληπτικού Ή (OR), που είναι ο `|`.
Το αποτέλεσμα του τελεστή `|` θα είναι `1` σε κάθε θέση όπου είτε ο αριστερός είτε ο δεξιός τελεστέος έχει ένα bit ορισμένο.
Έτσι, το αποτέλεσμα του `0010 | 0001` θα ήταν `0011`.
(Είναι σημαντικό να θυμάσαι ότι η τιμή είναι `11` στο δυαδικό σύστημα, αλλά `3` στο δεκαδικό.)
Για να αναθέσεις το αποτέλεσμα σε μια τιμή, ο τελεστής `|` μπορεί να συνδυαστεί με τον τελεστή ανάθεσης για να ορίσει τα bit ως εξής: `|=`.
Για να το κρατήσουμε απλό, το παρακάτω παράδειγμα δεν χρησιμοποιεί βρόχο, αλλά δείχνει πώς θα μπορούσαμε να επεξεργαστούμε τα γράμματα `ABA` σε μια μάσκα bit.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Ορίζουμε το δεξιότερο τμήμα της μάσκας μας σε `0001` για το `A` και μετά ορίζουμε τη μάσκα σε `0011` για το `B`.
Ο ορισμός ενός ακόμη `A` δεν επιφέρει καμία αλλαγή στην υπάρχουσα μάσκα.
Θα μπορούσαμε να είχαμε αποφύγει να ξαναορίσουμε το bit κοιτάζοντας αν το `A` είχε ήδη οριστεί.

### Τελεστής bitwise AND: ένας τρόπος να διαβάσεις ένα bit

Ο `&` είναι ο τελεστής bitwise AND.
Το αποτέλεσμα του τελεστή `&` θα είναι `1` σε κάθε θέση όπου τόσο ο αριστερός όσο και ο δεξιός τελεστέος έχει ένα bit ορισμένο.
Έτσι, το αποτέλεσμα του `0011 & 0001` θα ήταν `0001`.
Μπορούμε να το δούμε αυτό εν δράσει στο παρακάτω παράδειγμα.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Τελεστής bitwise αποκλειστικού Ή: ένας τρόπος να αντιστρέψεις ένα bit

Ο `^` είναι ο τελεστής bitwise αποκλειστικού Ή (XOR).
Ένας _συμπεριληπτικός_ τελεστής Ή υπονοεί ότι υπάρχει ένας _αποκλειστικός_ τελεστής Ή με διαφορετική συμπεριφορά.
Το αποτέλεσμα του τελεστή `^` θα είναι `1` σε κάθε θέση όπου _μόνο ένας_ από τους αριστερούς ή δεξιούς τελεστέους έχει ένα bit ορισμένο.
Έτσι, το αποτέλεσμα του `0001 ^ 0011` θα ήταν `0010`.
Το δεξιότερο bit δεν θα οριστεί επειδή _και οι δύο_ τελεστέοι έχουν `1` στη δεξιότερη θέση.
Η πράξη αποκλειστικού Ή σημειώνεται μερικές φορές ως XOR.
Αν το αποτέλεσμα μιας τιμής στην οποία εφαρμόστηκε XOR εφαρμοστεί ξανά με XOR, θα επιστρέψει την αρχική τιμή.
Αυτό μπορεί να χρησιμοποιηθεί για μια πολύ απλή κρυπτογράφηση, όπου το ίδιο κλειδί χρησιμοποιείται και για την κρυπτογράφηση και για την αποκρυπτογράφηση των δεδομένων.
Για παράδειγμα

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Πεδία bit

Έχουμε δει πώς bit συσκευασμένα σε έναν απλό τύπο δεδομένων μπορούν να προσπελαστούν με βάση τη θέση τους.
Bit συσκευασμένα σε μια `struct` μπορούν να προσπελαστούν με βάση το όνομα.
Ένας τέτοιος τύπος δεδομένων ονομάζεται `bit field`.
Μια περίπτωση χρήσης για `bit fields` μπορεί να είναι όταν χρειάζεται μια συλλογή σημαιών ON/OFF και επιθυμείται η ελαχιστοποίηση της χρήσης μνήμης.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

Η σύνταξη `unsigned int variable_name : 1;` δημιουργεί ένα πεδίο `1` bit μέσα σε ένα `unsigned int` που βρίσκεται μέσα στη `struct`.
Αντί για `unsigned int`, θα μπορούσε να χρησιμοποιηθεί ένα `signed int` ή, από τη C99 και μετά, ένας τύπος `bool`.
Μια `struct` που περιέχει πεδία bit μπορεί επίσης να περιέχει πεδία άλλων τύπων δεδομένων, όπως το `number_of_lights` στο παραπάνω παράδειγμα.
