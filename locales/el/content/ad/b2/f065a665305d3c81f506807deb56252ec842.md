# Εικονικό

## Οδηγίες ειδικά για την Tcl

Σε αυτή την άσκηση θα γράψεις τη δική σου εντολή ελέγχου (όπως `foreach` ή `while`).
Θα χρειαστείς τις εντολές [`upvar`][upvar] και [`uplevel`][uplevel].

Η σελίδα man του `uplevel` περιέχει ένα παράδειγμα δομής ελέγχου `do ... while ...` που θα σε βοηθήσει να λύσεις αυτή την άσκηση.

Μπορεί επίσης να σου φανεί χρήσιμη αυτή η συζήτηση στο wiki της Tcl, [New Control Structures][wiki].


[upvar]: https://www.tcl-lang.org/man/tcl8.6/TclCmd/upvar.htm
[uplevel]: https://www.tcl-lang.org/man/tcl8.6/TclCmd/uplevel.htm
[wiki]: https://wiki.tcl-lang.org/page/New+Control+Structures
