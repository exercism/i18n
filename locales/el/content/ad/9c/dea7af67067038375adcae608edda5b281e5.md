# Εισαγωγή

Όταν χρειάζεσαι μια ακολουθία από `n` τιμές όπου η καθεμία εξαρτάται από τη θέση της, το Factor σου δίνει το `<iota>`, μια εικονική ακολουθία των ακεραίων `0, 1, …, n-1`, και τη `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

Το `<iota>` δεν δεσμεύει τους ακεραίους εκ των προτέρων· η `map` τα διατρέχει με τη σειρά, εφαρμόζοντας το quotation σε καθένα.

Αν το αποτέλεσμα για κάθε θέση είναι κωδικός χαρακτήρα, το `>string` μετατρέπει το αποτέλεσμα σε συμβολοσειρά, τον φυσικό τρόπο να συναρμολογήσεις μια σειρά χαρακτήρων από αποφάσεις που βασίζονται στη θέση:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
