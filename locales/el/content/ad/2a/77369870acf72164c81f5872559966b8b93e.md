# Εισαγωγή

## Ψευδώνυμα τύπων

Ένα ψευδώνυμο τύπου μπορεί να χρησιμοποιηθεί στη Gleam για να δώσει ένα βολικό όνομα σε έναν υπάρχοντα τύπο που διαφορετικά θα ήταν δύσκολο να γραφτεί.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Όταν γράφεται με `pub type`, το ψευδώνυμο μπορεί να χρησιμοποιηθεί έξω από τη μονάδα στην οποία ορίζεται. Αν παραλειφθεί το `pub`, τότε το ψευδώνυμο είναι ιδιωτικό και δεν μπορεί να αναφερθεί σε άλλες μονάδες.
