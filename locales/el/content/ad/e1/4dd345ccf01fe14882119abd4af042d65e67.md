# Εκτέλεση των τεστ

Διάλεξε το λειτουργικό σου σύστημα:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Άνοιξε ένα Command Prompt.
2. Κατέβασε την πρώτη άσκηση:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Πήγαινε στον κατάλογο της άσκησης:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Τρέξε τα τεστ:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Μην ανησυχείς αν τα τεστ αποτύχουν στην αρχή, έτσι ξεκινάς κάθε άσκηση.)_

5. Λύσε την άσκηση. Βρες και μελέτησε τον οδηγό `instructions.append.md` ([δες το στο GitHub](https://github.com/exercism/java/blob/main/exercises/practice/hello-world/.docs/instructions.append.md#tutorial)).

Καλή τύχη! Καλή διασκέδαση!
