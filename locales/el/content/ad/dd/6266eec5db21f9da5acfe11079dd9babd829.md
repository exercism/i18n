# Εισαγωγή

## Δομές

Οι δομές είναι μια επέκταση χτισμένη πάνω στα [maps][exercism-maps], η οποία παρέχει ελέγχους κατά τη μεταγλώττιση και προεπιλεγμένες τιμές. Μια δομή παίρνει το όνομά της από το module στο οποίο ορίζεται. Για να ορίσεις μια δομή, χρησιμοποίησε την κατασκευή `defstruct`. Η κατασκευή συνήθως ακολουθεί αμέσως μετά τον ορισμό του module. Το `defstruct` δέχεται είτε μια λίστα από atoms (για προεπιλεγμένες τιμές `nil`) είτε μια λίστα με λέξεις-κλειδιά (για συγκεκριμένες προεπιλεγμένες τιμές). Τα πεδία χωρίς προεπιλεγμένες τιμές πρέπει να προηγούνται των πεδίων με προεπιλεγμένες τιμές.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Πρόσβαση στα πεδία και ενημέρωση

Επειδή οι δομές είναι χτισμένες πάνω στα maps, μπορούμε να χρησιμοποιήσουμε τις περισσότερες συναρτήσεις των maps για να πάρουμε και να χειριστούμε τιμές. Το _Access Behaviour_ **δεν** υλοποιείται για τις δομές. Αντιθέτως, προτείνεται να χρησιμοποιείς τον _τελεστή στατικής πρόσβασης_ `.` για να έχεις πρόσβαση στα πεδία μιας δομής.

- λήψη/ανάκτηση τιμών πεδίων:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- ενημέρωση τιμών πεδίων

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Αντιστοίχιση προτύπων

Οι δομές μπορούν να χρησιμοποιηθούν στην αντιστοίχιση προτύπων με ή χωρίς το όνομα της δομής.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Συμπεριλαμβάνοντας το όνομα της δομής στο πρότυπο, μπορείς να βεβαιωθείς ότι και οι δύο πλευρές, αριστερά και δεξιά, είναι δομές του ίδιου τύπου.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Επιβολή αρχικοποίησης τιμών πεδίων

Μπορούμε να χρησιμοποιήσουμε το χαρακτηριστικό module `@enforce_keys` με μια λίστα από κλειδιά πεδίων, ώστε να διασφαλίσουμε ότι οι τιμές αρχικοποιούνται όταν δημιουργείται η δομή. Αν ένα κλειδί δεν περιλαμβάνεται στη λίστα, η τιμή του θα είναι `nil`, όπως φαίνεται στο παραπάνω παράδειγμα. Αν ένα υποχρεωτικό κλειδί δεν αρχικοποιηθεί, πετιέται ένα σφάλμα.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
