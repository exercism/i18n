# Οδηγίες

Η αποστολή σου είναι να καθορίσεις τι θα πεις καθώς χαρίζεις το επιπλέον μπισκότο.

Αν ξέρεις το όνομα του ατόμου (π.χ. αν το όνομά του είναι Do-yun), τότε θα πεις:

```text
One for Do-yun, one for me.
```

Αν δεν ξέρεις το όνομα του ατόμου, θα πεις _you_ αντί γι' αυτό.

```text
One for you, one for me.
```

Ορίστε μερικά παραδείγματα:

| Όνομα  | Διάλογος                    |
| :----- | :-------------------------- |
| Alice  | One for Alice, one for me.  |
| Bohdan | One for Bohdan, one for me. |
|        | One for you, one for me.    |
| Zaphod | One for Zaphod, one for me. |
