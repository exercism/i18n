# Εισαγωγή

Οι Boolean (λογικές τιμές) στη C++ αναπαρίστανται από τον τύπο `bool`.
Μια τιμή `bool` είναι είτε `true` είτε `false`.

## Λογικοί τελεστές

Η C++ υποστηρίζει τρεις λογικούς τελεστές: `!` (ΟΧΙ), `&&` (ΚΑΙ) και `||` (Ή).
Μπορείς επίσης να χρησιμοποιήσεις τις εναλλακτικές εκδόσεις `not`, `and` και `or`.

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## Προτεραιότητα

Ο καθένας από τους τρεις λογικούς τελεστές έχει διαφορετική _προτεραιότητα τελεστών_.
Κατά συνέπεια, αξιολογούνται με αυτή τη σειρά: πρώτα το `!`, μετά το `&&` και τέλος το `||`.
Αν θέλεις να επιβάλεις διαφορετική σειρά, μπορείς να κλείσεις μια boolean έκφραση σε παρενθέσεις (δηλ. `()`), αφού οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```cpp
!true && false   // => false
!(true and false) // => true
```

## Μετατροπή

Αν χρησιμοποιήσεις το `true` ή το `false` σε θέση όπου περιμένουμε έναν αριθμό, θα μετατραπούν σε `1` και `0` αντίστοιχα.
Αν χρησιμοποιήσεις έναν αριθμό σε μια Boolean πράξη, όλα εκτός από το `0` αντιμετωπίζονται ως `true`, ακόμη και οι αρνητικές τιμές.

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
