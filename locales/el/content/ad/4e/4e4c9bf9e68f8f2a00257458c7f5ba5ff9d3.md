# Εισαγωγή

## Enumerations

Μέχρι τώρα έχουμε ασχοληθεί κυρίως με αριθμούς και συμβολοσειρές.
Για να μοντελοποιήσουμε τον πραγματικό κόσμο, μπορεί να θέλουμε έναν περιορισμένο αριθμό τιμών που μπορεί να πάρει μια μεταβλητή.
Μπορεί να θέλεις έναν ξεχωριστό τύπο με λίγες διακριτές τιμές και διακριτά ονόματα.
Για παράδειγμα, σε ένα εργοστάσιο skateboard, το υλικό της σανίδας να είναι επιλογή μόνο ανάμεσα σε maple, bamboo ή plastic.

Θα μπορούσες να χρησιμοποιήσεις ακέραιους για να κωδικοποιήσεις αυτές τις τιμές, αλλά θα έπρεπε να γράψεις επιπλέον κώδικα για να ελέγξεις αν έρχεται από το σύστημα κάποια μη έγκυρη τιμή για το υλικό.
Η σημασία αυτών των [_μαγικών αριθμών_][magic numbers] είναι δύσκολο να εντοπιστεί μέσα στον πηγαίο κώδικα και εύκολα προκαλούν μπερδέματα.
Τα `enumerations` μπορούν να χρησιμοποιηθούν για να ενθαρρύνουν εκφραστικό κώδικα και να περιορίσουν τα ακούσια λάθη σύγκρισης.

## Παράδειγμα χρήσης

Ο ειδικός όρος για αυτό το είδος είναι `scoped enumeration`.
Το παρακάτω απόσπασμα δείχνει πώς να γράψεις ένα `DeckMaterial` `enumeration`.
Πρόσεξε τη λέξη-κλειδί `enum class` και το `;` στο τέλος του ορισμού:

```cpp
enum class DeckMaterial {
    maple,
    bamboo,
    plastic
};
```
Τώρα, δες μια συνάρτηση τιμολόγησης στο κατάστημα skateboard και πρόσεξε τον τελεστή ανάλυσης εμβέλειας (`::`) που προσδιορίζει ένα `enumerator` από το `enumeration`:

```cpp
double deck_price(double base_price, DeckMaterial material) {
    if(material == DeckMaterial::plastic) {
        return base_price * 0.9;
    }
    return base_price * 1.3;
}
```

## Εμβέλεια

Φαντάσου ότι έχεις ένα δεύτερο `enumeration` για το υλικό των τροχών:

```cpp
enum class WheelMaterial {
    steel,
    clay,
    plastic
};
```
Αν και οι τροχοί και η σανίδα μπορούν και τα δύο να είναι κατασκευασμένα από _plastic_, τα δύο δεν μπορούν να μπερδευτούν.
Είναι διαφορετικοί _τύποι_: `DeckMaterial` plastic και `WheelMaterial` plastic.
Κάθε `enumeration` θα έχει τα `enumerators` του στη δική του εμβέλεια, στο δικό του `namespace`.
Γι' αυτό ονομάζονται `scoped enumerations`.

## Unscoped Enumerations
Ίσως σκέφτεσαι ότι, αφού υπάρχει η ονομασία `scoped`, θα πρέπει να υπάρχουν και `unscoped` enumerations, και θα είχες δίκιο.
Τα `Unscoped enumerations` γίνονται όλο και λιγότερο δημοφιλή, επειδή μοιράζονται όλα τον ίδιο καθολικό namespace.
Λόγω αυτής της κοινής χρήσης, δεν θα μπορούσες να έχεις δύο `unscoped enumerations` με τα ίδια `enumerators`, όπως το _plastic_ στο παραπάνω παράδειγμα.

Επίσης, τα `unscoped enumerations` μετατρέπονται σιωπηρά σε ακέραιους.
Δες το παρακάτω παράδειγμα για ένα αναπάντεχο αποτέλεσμα:

```cpp
enum CitrusFruits {
    lemons,  // 0
    oranges, //1
};

enum IceCream {
    walnut,  // 0
    apples,  // 1
};

bool comparison{apples == oranges};
// => true

// Example from above:
bool comparison{DeckMaterial::plastic == WheelMaterial::plastic};
// => Does not compile!
```

Αν θέλεις να μετατρέψεις `scoped enumerations` σε ακέραιους, μπορείς να χρησιμοποιήσεις το `static_cast<int>`.
