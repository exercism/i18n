# Οδηγίες

Η Lilly λατρεύει τη μαγειρική.
Θέλει να κάνει ένα πάρτι πίτσας με τους φίλους της.
Για να αξιοποιήσει στο έπακρο τα υλικά της, πρέπει να ξέρει πόση ποσότητα από το καθένα χρειάζεται πριν ξεκινήσει.

Για να το λύσει αυτό, η Lilly έχει σχεδιάσει ένα πρόγραμμα που αυτοματοποιεί μέρος του σχεδιασμού, αλλά χρειάζεται τη βοήθειά σου για να το ολοκληρώσει.
Θα βοηθήσεις τη Lilly να κάνει το αναλογικά τέλειο πάρτι πίτσας;

## 1. Αναλογία ζύμης

Η Lilly λατρεύει τις λεπτές, τραγανές πίτσες με πιο λεπτή κόρα.
Η ζύμη που χρειάζεται για το κέντρο είναι το λιγότερο 200g, αλλά κάθε άτομο που σερβίρεται χρειάζεται άλλα 20g ζύμης.

`grams = pizzas * ((persons * 20) + 200)`

Η Lilly χρειάζεται μια συνάρτηση που:

- Παίρνει τον αριθμό των πιτσών
- Τον αριθμό των ατόμων που θα σερβίρει κάθε πίτσα
- Και επιστρέφει τη ζύμη που χρειάζεται, στρογγυλοποιημένη στο πλησιέστερο γραμμάριο.

Για παράδειγμα, για να φτιάξεις 4 πίτσες που ταΐζουν 8 άτομα:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. Λίγη σάλτσα

Η Lilly είναι σχολαστική όταν απλώνει τη σάλτσα της, αλλά το μέγεθος των πιτσών της μπορεί να μην είναι σταθερό.
Από την εμπειρία της, ξέρει ότι χρειάζονται 125mL σάλτσας ανά πίτσα.
Η Lilly χρειάζεται μια συνάρτηση που υπολογίζει πόσα κουτάκια σάλτσας πρέπει να αγοράσει.

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

Για παράδειγμα, αν η Lilly χρειάζεται να φτιάξει 8 πίτσες και κάθε κουτάκι είναι 250mL:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. Λίγο τυρί, παρακαλώ

Το τυρί έρχεται σε τέλειους κύβους και πωλείται ανά μέγεθος.

Ο τύπος που χρησιμοποιεί η Lily δεν είναι ο τύπος για το εμβαδόν της πίτσας, αφού _δεν_ θέλει το τυρί να καλύπτει ολόκληρη την επιφάνεια.
Αποφάσισε να χρησιμοποιήσει τον παρακάτω τύπο για να προσδιορίσει πόσες πίτσες με κάποια διάμετρο (`diameter`) μπορούν να φτιαχτούν από έναν κύβο τυριού με κάποιο μήκος πλευράς (`cheese_dimension`):

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

Δημιούργησε μια συνάρτηση που:

- Παίρνει το μήκος πλευράς ενός κύβου τυριού
- Παίρνει το επιθυμητό πάχος της στρώσης τυριού
- Παίρνει τη διάμετρο της πίτσας
- Και χρησιμοποιεί τον τύπο της Lilly για να επιστρέψει τον αριθμό των πιτσών που μπορούν να φτιαχτούν, στρογγυλοποιημένο προς τα κάτω.

Για παράδειγμα, με έναν κύβο τυριού 25x25x25cm, στρώση τυριού πάχους 0,5cm και πίτσες διαμέτρου 30cm:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. Δίκαιη μοιρασιά

Τέλος, η Lilly θέλει οι πίτσες της να κόβονται σε 8 κομμάτια η καθεμία και να μοιράζονται δίκαια στους φίλους της.

Δημιούργησε μια συνάρτηση που:

- Παίρνει έναν αριθμό πιτσών και έναν αριθμό φίλων
- και επιστρέφει τον αριθμό των κομματιών που θα περισσέψουν αν κάθε άτομο πάρει ίσο αριθμό κομματιών.

Για παράδειγμα:

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
