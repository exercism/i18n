# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, χρειάζεται να δημιουργήσεις τον τύπο δεδομένων `School`
και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `add`
- `empty`
- `grade`
- `sorted`

Θα βρεις ήδη στη θέση τους μια εικονική δήλωση δεδομένων και τις υπογραφές τύπων,
αλλά από εσένα εξαρτάται να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν
ουσιαστικό τύπο δεδομένων, newtype ή συνώνυμο τύπου.
