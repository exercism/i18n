# Εισαγωγή

## Μαθηματικές συναρτήσεις

Οι τετραγωνικές ρίζες, οι γωνίες και οι καμπύλες ανάπτυξης είναι δύσκολο να υπολογιστούν μόνο με `+`, `-`, `*` και `/`. Το λεξιλόγιο [`math.functions`][math.functions] έχει λέξεις που τις υπολογίζουν για σένα, και το [`math.constants`][math.constants] έχει το π. Όπως κάθε άλλη λέξη, η καθεμία παίρνει τις εισόδους της από τη στοίβα και αφήνει εκεί την απάντησή της.

## Τετραγωνικές ρίζες

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

Μια σκάλα μήκους 5 μέτρων, με το πόδι της 3 μέτρα μακριά από έναν τοίχο, φτάνει 4 μέτρα ψηλά σε αυτόν:

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## Το π

Το `pi` (από το `math.constants`) σπρώχνει το π, δηλαδή πόσες φορές η διάμετρος ενός κύκλου χωράει στην περιφέρειά του:

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## Οι γωνίες είναι σε ακτίνια

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

Τα `sin`, `cos` και `tan` παίρνουν μια γωνία, αλλά όχι σε μοίρες. Χρησιμοποιούν **ακτίνια**, όπου μισή στροφή είναι π και όχι 180. Το να τους δώσεις μοίρες δεν είναι σφάλμα: απλώς δίνουν αθόρυβα λάθος απάντηση.

Το `deg>rad` μετατρέπει μοίρες σε ακτίνια και το `rad>deg` κάνει την αντίστροφη μετατροπή. Είναι το ίδιο με το να πολλαπλασιάσεις επί π και να διαιρέσεις με το 180, ή το αντίστροφο:

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

Μετέτρεψε τις μοίρες σε ακτίνια πριν καλέσεις το `sin`:

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

Μια ράμπα μήκους 10 μέτρων με κλίση 30 μοιρών ανεβαίνει 5 μέτρα. Η απάντηση τυπώνεται ως `4.999999999999999`, επειδή οι μαθηματικές συναρτήσεις δίνουν τον κοντινότερο float, όχι την ακριβή τιμή. Χωρίς τη μετατροπή, το `30 sin` αντιμετωπίζει το 30 ως ακτίνια (σχεδόν πέντε ολόκληρες στροφές) και η ράμπα θα "ανέβαινε" `-9.88` μέτρα.

## Εύρεση γωνίας

Το `fatan2` πάει αντίστροφα: αν του δώσεις πόσο ψηλά και πόσο οριζόντια, απαντά τη γωνία σε ακτίνια. Βρίσκεται στο [`math.libm`][math.libm]. Η απόσταση *πάνω* πηγαίνει πρώτη στη στοίβα και μετά η απόσταση *οριζόντια*:

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

Η γωνία μετριέται από τη θετική *οριζόντια* κατεύθυνση. Το `fatan2` κοιτάζει τα πρόσημα και των δύο αποστάσεων, οπότε μπορεί να απαντήσει οπουδήποτε από −180 έως 180 μοίρες.

## Δυνάμεις του δέκα: 10^ και log10

Το `10^` υψώνει το 10 σε μια δύναμη:

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

Το `log10` πάει προς την αντίθετη κατεύθυνση. Απαντά στην ερώτηση: το 10 σε ποια δύναμη δίνει αυτόν τον αριθμό; Αυτή η απάντηση είναι ο **λογάριθμος** του αριθμού:

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ και log

Τα `e^` και `log` είναι το ίδιο ζευγάρι, με το *e* (περίπου 2.718) στη θέση του 10. Το `e^` υψώνει το *e* σε μια δύναμη και το `log` απαντά στην ερώτηση: το *e* σε ποια δύναμη δίνει αυτόν τον αριθμό;

```
e^  ( x -- y )
log ( x -- y )
```

Οι μαθηματικοί χρησιμοποιούν το *e* για οτιδήποτε μεγαλώνει ή μικραίνει κατά το ίδιο ποσοστό σε κάθε βήμα. Τα χρήματα που κερδίζουν τόκο είναι ένα παράδειγμα, και ένα φλιτζάνι τσάι που κρυώνει είναι ένα άλλο:

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

Το `log` αναιρεί το `e^`. Έτσι απαντάς στο αντίστροφο ερώτημα: σε πόσα λεπτά η διαφορά θα πέσει στους 40 βαθμούς;

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
