# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις τη λογική της αποστολής για ένα νέο παιχνίδι RPG που αναπτύσσει ένας φίλος.

Η βασική ηρωίδα του παιχνιδιού είναι η Annalyn, ένα γενναίο κορίτσι με έναν άγριο και πιστό σκύλο. Δυστυχώς, όμως, η καταστροφή χτυπά: ο καλύτερός της φίλος απήχθη ενώ έψαχνε για μούρα στο δάσος.

Η Annalyn θα προσπαθήσει να βρει και να ελευθερώσει τον καλύτερό της φίλο, παίρνοντας προαιρετικά μαζί της τον σκύλο της σε αυτή την αποστολή.

Αφού πέρασε κάποιο διάστημα ακολουθώντας τα ίχνη του καλύτερού της φίλου, βρίσκει το στρατόπεδο στο οποίο κρατείται. Αποδεικνύεται ότι υπάρχουν δύο απαγωγείς: ένας πανίσχυρος ιππότης και ένας πονηρός τοξότης.

Έχοντας βρει τους απαγωγείς, η Annalyn σκέφτεται ποιες από τις παρακάτω ενέργειες μπορεί να κάνει:

- _Γρήγορη επίθεση_: μπορεί να γίνει γρήγορη επίθεση αν ο ιππότης κοιμάται, καθώς χρειάζεται χρόνος για να φορέσει την πανοπλία του, οπότε θα είναι ευάλωτος.
- _Κατασκόπευση_: μπορεί να κατασκοπευτεί η ομάδα αν τουλάχιστον ένας από αυτούς είναι ξύπνιος. Διαφορετικά, η κατασκόπευση είναι χάσιμο χρόνου.
- _Σηματοδότηση του κρατούμενου_: μπορεί να δοθεί σήμα στον κρατούμενο με ήχους πουλιών αν ο κρατούμενος είναι ξύπνιος και ο τοξότης κοιμάται, καθώς οι τοξότες είναι εκπαιδευμένοι στη σηματοδότηση με πουλιά, οπότε θα μπορούσαν να υποκλέψουν το μήνυμα.
- _Απελευθέρωση του κρατούμενου_: η Annalyn μπορεί να προσπαθήσει να μπει κρυφά στο στρατόπεδο για να ελευθερώσει τον κρατούμενο.
  Αυτό είναι ρίσκο και μπορεί να πετύχει μόνο με έναν από δύο τρόπους:
  - Αν η Annalyn έχει μαζί της τον σκύλο της, μπορεί να σώσει τον κρατούμενο αν ο τοξότης κοιμάται.
    Ο ιππότης φοβάται τον σκύλο και ο τοξότης δε θα προλάβει να ετοιμαστεί πριν η Annalyn και ο κρατούμενος δραπετεύσουν.
  - Αν η Annalyn δεν έχει τον σκύλο της, τότε αυτή και ο κρατούμενος πρέπει να είναι πολύ πονηροί!
    Η Annalyn μπορεί να ελευθερώσει τον κρατούμενο αν ο κρατούμενος είναι ξύπνιος και ο ιππότης και ο τοξότης κοιμούνται και οι δύο, αλλά αν ο κρατούμενος κοιμάται δε μπορεί να σωθεί: ο κρατούμενος θα αιφνιδιαστεί από την ξαφνική εμφάνιση της Annalyn και θα ξυπνήσει τον ιππότη και τον τοξότη.

Έχεις τέσσερις εργασίες: να υλοποιήσεις τη λογική που καθορίζει αν οι παραπάνω ενέργειες είναι διαθέσιμες με βάση την κατάσταση των τριών χαρακτήρων που βρίσκονται στο δάσος και αν ο σκύλος της Annalyn είναι παρών ή όχι.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

Υλοποίησε τη μέθοδο `canFastAttack()` που παίρνει μία τιμή Boolean (λογική τιμή) που δηλώνει αν ο ιππότης είναι ξύπνιος. Αυτή η μέθοδος επιστρέφει `true` αν μπορεί να γίνει γρήγορη επίθεση με βάση την κατάσταση του ιππότη. Διαφορετικά, επιστρέφει `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Έλεγξε αν μπορεί να κατασκοπευτεί η ομάδα

Υλοποίησε τη μέθοδο `canSpy()` που παίρνει τρεις Boolean τιμές, που δηλώνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η μέθοδος επιστρέφει `true` αν μπορεί να κατασκοπευτεί η ομάδα, με βάση την κατάσταση των τριών χαρακτήρων. Διαφορετικά, επιστρέφει `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Έλεγξε αν μπορεί να δοθεί σήμα στον κρατούμενο

Υλοποίησε τη μέθοδο `canSignalPrisoner()` που παίρνει δύο Boolean τιμές, που δηλώνουν αν ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η μέθοδος επιστρέφει `true` αν μπορεί να δοθεί σήμα στον κρατούμενο, με βάση την κατάσταση των δύο χαρακτήρων. Διαφορετικά, επιστρέφει `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Έλεγξε αν μπορεί να ελευθερωθεί ο κρατούμενος

Υλοποίησε τη μέθοδο `canFreePrisoner()` που παίρνει τέσσερις Boolean τιμές. Οι τρεις πρώτες παράμετροι δηλώνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η τελευταία παράμετρος δηλώνει αν ο σκύλος της Annalyn είναι παρών. Η μέθοδος επιστρέφει `true` αν μπορεί να ελευθερωθεί ο κρατούμενος με βάση την κατάσταση των τριών χαρακτήρων και την παρουσία του σκύλου της Annalyn. Διαφορετικά, επιστρέφει `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
