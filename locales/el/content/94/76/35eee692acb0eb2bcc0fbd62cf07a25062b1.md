# Οδηγίες

Είσαι ένα ξωτικό που δουλεύει στο τμήμα εφοδιασμού του Άγιου Βασίλη και το αφεντικό σου έχει αναθέσει δύο εργασίες για την αναβάθμιση του λογισμικού του συστήματος.

## 1. Πάρε το όνομα του παιχνιδιού

Το σύστημα πρέπει να μπορεί να πάρει το όνομα ενός παιχνιδιού από τη βάση δεδομένων.
Η βάση δεδομένων αποτελείται από πλειάδες τύπου `(name: String, quantity: Int)`.

Υλοποίησε τη συνάρτηση `getName(_:)`, που παίρνει ένα όρισμα το οποίο περιέχει μια πλειάδα τύπου `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Πρόσθεσε ένα νέο παιχνίδι στη βάση δεδομένων

Η αγορά παιχνιδιών είναι μια γρήγορη και συνεχώς μεταβαλλόμενη αγορά, αυτό που είναι δημοφιλές αλλάζει πολύ γρήγορα.
Γι' αυτό χρειάζεται μια συνάρτηση που δημιουργεί ένα νέο παιχνίδι.

Υλοποίησε τη συνάρτηση `createToy(name:amount:)`, που παίρνει ένα όρισμα `name` το οποίο περιέχει το όνομα του παιχνιδιού και ένα όρισμα `amount` το οποίο περιέχει την ποσότητα του παιχνιδιού.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Ενημέρωσε την ποσότητα ενός παιχνιδιού

Τα ξωτικά στο εργαστήρι του Άγιου Βασίλη φτιάχνουν συνέχεια κι άλλα παιχνίδια και ο Άγιος Βασίλης πρέπει να παρακολουθεί την ποσότητα κάθε παιχνιδιού.
Για να γίνει αυτό, το σύστημα πρέπει να μπορεί να ενημερώνει την ποσότητα ενός παιχνιδιού στη βάση δεδομένων.

Υλοποίησε τη συνάρτηση `updateQuantity(_:toy:Amount:)`, που παίρνει τα εξής ορίσματα:
- `toys`, το οποίο περιέχει έναν πίνακα από πλειάδες τύπου `(name: String, quantity: Int)`.
- `toy`, το οποίο περιέχει το όνομα του παιχνιδιού που θα ενημερωθεί.
- `amount`, το οποίο περιέχει τη νέα ποσότητα του παιχνιδιού.

Μπορείς να υποθέσεις ότι το παιχνίδι βρίσκεται ήδη στη βάση δεδομένων και δεν χρειάζεται να το ελέγξεις.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Πρόσθεσε κλειδί κατηγορίας σε ένα παιχνίδι

Ο Άγιος Βασίλης θέλει να μπορεί να κατηγοριοποιεί τα παιχνίδια στη βάση δεδομένων.
Έτσι ώστε να μπορεί να βρίσκει εύκολα τα παιχνίδια όταν χρειάζεται να κάνει μια παράδοση και να μπορεί να ταξινομεί τα παιχνίδια στη βάση δεδομένων.

Ωστόσο, όταν το σύστημα υλοποιήθηκε για πρώτη φορά, το κλειδί κατηγορίας ξεχάστηκε.
Τώρα το σύστημα πρέπει να μπορεί να προσθέτει ένα κλειδί κατηγορίας σε ένα παιχνίδι στη βάση δεδομένων.

Υλοποίησε τη συνάρτηση `addCategory(_:category:)`, που παίρνει τα εξής ορίσματα:
- `toys`, το οποίο περιέχει έναν πίνακα από πλειάδες τύπου `(name: String, quantity: Int)`.
- `category`, το οποίο περιέχει το κλειδί κατηγορίας που θα προστεθεί στα παιχνίδια.

Μπορείς να υποθέσεις ότι το παιχνίδι βρίσκεται ήδη στη βάση δεδομένων και δεν χρειάζεται να το ελέγξεις.
Μπορείς επίσης να υποθέσεις ότι δεν υπάρχει ήδη κλειδί κατηγορίας στο παιχνίδι.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
