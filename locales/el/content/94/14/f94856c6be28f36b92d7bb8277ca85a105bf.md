# Εισαγωγή

## Βρόχοι `for`

Η εντολή `for` επαναλαμβάνει ένα μπλοκ κώδικα.
Η πρώτη της γραμμή ελέγχει πόσο συχνά επαναλαμβάνεται το μπλοκ:

```go
for init; condition; post {
    // loop body
}
```

- Το στοιχείο **init** εκτελείται μία φορά πριν από την πρώτη επανάληψη. Συνηθίζεται να δηλώνεις και να αρχικοποιείς μια μεταβλητή μετρητή που χρησιμοποιεί ο βρόχος.
- Το στοιχείο **condition** είναι μια έκφραση Boolean (λογική τιμή) που αξιολογείται πριν από κάθε επανάληψη. Ο βρόχος σταματά όταν αυτή αξιολογηθεί ως `false`.
- Το στοιχείο **post** εκτελείται μετά από κάθε ολοκληρωμένη επανάληψη. Μπορείς να το χρησιμοποιήσεις για να ενημερώσεις έναν μετρητή.

Μην περικλείεις το `init; condition; post` σε παρενθέσεις.
Ωστόσο, τα άγκιστρα γύρω από το σώμα του βρόχου είναι πάντα απαραίτητα.

Αυτός ο βρόχος ξεκινά το `i` από το `1`, εκτυπώνει την τρέχουσα τιμή του `i`, την αυξάνει για την επόμενη επανάληψη και σταματά όταν το `i` φτάσει στο `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
