# Υποδείξεις

## Γενικά

- Μια ακέραια τιμή μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [δέσμευση][bindings].

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Μπορείς να χρησιμοποιήσεις τη δέσμευση που όρισες προηγουμένως και να την αναφέρεις με το όνομά της.
- Η τελευταία έκφραση σε μια συνάρτηση [επιστρέφεται αυτόματα][return-values] από τη συνάρτηση. Δε χρειάζεται να δηλώσεις ρητά ποια τιμή θα επιστραφεί.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον χρόνο που πέρασε σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Μπορείς να [καλέσεις][calling] μία από τις άλλες συναρτήσεις που όρισες προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.
