# Οδηγίες

Η Elena είναι η νέα διευθύντρια ποιότητας σε ένα εργοστάσιο εφημερίδων.
Επειδή μόλις έφτασε στην εταιρεία, αποφάσισε να εξετάσει μερικές από τις διαδικασίες του εργοστασίου για να δει τι θα μπορούσε να βελτιωθεί.

Ανακάλυψε ότι οι τεχνικοί κάνουν πολλούς ελέγχους ποιότητας με το χέρι.

Βλέπει ότι υπάρχει καλή ευκαιρία για αυτοματοποίηση και σου ζητάει, ως ελεύθερος επαγγελματίας προγραμματιστής, να αναπτύξεις ένα λογισμικό που θα παρακολουθεί μερικές από τις μηχανές.

## 1. Παρακολούθησε το επίπεδο υγρασίας του δωματίου

Η πρώτη σου αποστολή είναι να γράψεις ένα λογισμικό που θα παρακολουθεί το επίπεδο υγρασίας του δωματίου παραγωγής.
Υπάρχει ήδη ένας αισθητήρας συνδεδεμένος με το λογισμικό της εταιρείας που επιστρέφει περιοδικά το ποσοστό υγρασίας του δωματίου.

Πρέπει να υλοποιήσεις μια συνάρτηση στο λογισμικό που θα πετάει ένα σφάλμα αν το ποσοστό υγρασίας είναι πολύ υψηλό.
Η συνάρτηση θα πρέπει να ονομάζεται `check_humidity_level` και να παίρνει το ποσοστό υγρασίας ως παράμετρο.

Θα πρέπει να διακόψεις με ένα σφάλμα (το μήνυμα δεν έχει σημασία) αν το ποσοστό ξεπερνά το 70%.
Διαφορετικά, εμφάνισε ένα μήνυμα που περιέχει "humidity test passed" και επέστρεψε `TRUE` για να επιβεβαιώσεις ότι η μέτρηση είναι καλή.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Εντόπισε την υπερθέρμανση

Η Elena είναι πολύ ευχαριστημένη με την πρώτη σου ανάθεση και σου ζητάει να ασχοληθείς με την παρακολούθηση της θερμοκρασίας των μηχανών.
Καθώς συζητάς με έναν τεχνικό, τον Greg, σου λέει ότι αν η θερμοκρασία μιας μηχανής ξεπερνά τους 500°C, οι τεχνικοί αρχίζουν να ανησυχούν για υπερθέρμανση.

Η μηχανή είναι εξοπλισμένη με έναν αισθητήρα που μετρά την εσωτερική της θερμοκρασία.
Πρέπει να ξέρεις ότι ο αισθητήρας είναι πολύ ευαίσθητος και χαλάει συχνά.
Σε αυτή την περίπτωση, οι τεχνικοί θα χρειαστεί να τον αλλάξουν.

Η δουλειά σου είναι να υλοποιήσεις μια συνάρτηση `report_overheating` που παίρνει τη θερμοκρασία ως παράμετρο και πετάει ένα σφάλμα αν ο αισθητήρας είναι χαλασμένος ή αν η μηχανή αρχίζει να υπερθερμαίνεται.

Επειδή αργότερα θα χρειαστεί να αντιδράσεις διαφορετικά ανάλογα με το σφάλμα, χρειάζεσαι έναν μηχανισμό για να ξεχωρίζεις τα δύο είδη σφαλμάτων.

- Αν ο αισθητήρας είναι χαλασμένος, η θερμοκρασία θα είναι `NULL`.
  Σε αυτή την περίπτωση, θα πρέπει να διακόψεις με ένα μήνυμα σφάλματος που περιέχει το "Sensor Broken" ως μέρος της συμβολοσειράς.
- Όταν ο αισθητήρας λειτουργεί, αν η θερμοκρασία ξεπερνά τους 600°C, θα πρέπει να διακόψεις με ένα μήνυμα που περιέχει τη θερμοκρασία.
- Αν η θερμοκρασία ξεπερνά τους 500°C αλλά όχι τους 600°C, θα πρέπει να εμφανίσεις μια προειδοποίηση που περιέχει τη θερμοκρασία και να επιστρέψεις `FALSE`.
- Διαφορετικά, όλα είναι καλά, οπότε εμφάνισε το μήνυμα `"temperature check passed: t °C"`, όπου `t` είναι η θερμοκρασία, και επέστρεψε `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Παρακολούθησε τη μηχανή

Τώρα που η μηχανή σου μπορεί να εντοπίζει σφάλματα και έχεις ένα δικό σου σφάλμα μηχανής, προσθέτεις μια συνάρτηση-περιτύλιγμα που μπορεί να αναφέρει πώς λειτουργούν όλα.
Πέρα από την επιστροφή των καταγραφών από τις προηγούμενες συναρτήσεις, αυτό το περιτύλιγμα θα πρέπει επίσης να προσθέτει καταγραφές ανάλογα με τους τύπους αποτυχίας που προκύπτουν.

- Έλεγξε την υγρασία και τη θερμοκρασία.
- Αν υπάρχουν προβλήματα, άφησε απλώς τις `check_humidity_level()` και `report_overheating()` να εμφανίσουν τις καταγραφές τους.
- Αν όλα είναι καλά, πρόσθεσε ένα μήνυμα που περιέχει το "All OK".

Υλοποίησε μια συνάρτηση `monitor_the_machine()` που παίρνει την υγρασία και τη θερμοκρασία ως ορίσματα.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
