# Εισαγωγή

Το `str` στην Python είναι μια [αμετάβλητη ακολουθία][text sequence] από [σημεία κώδικα Unicode][unicode code points].
Αυτά μπορεί να περιλαμβάνουν γράμματα, διακριτικά σημάδια, χαρακτήρες τοποθέτησης, αριθμούς, σύμβολα νομισμάτων, emoji, σημεία στίξης, διάφορα κενά, αλλαγές γραμμής και πολλά άλλα.

Οι συμβολοσειρές υλοποιούν όλες τις [κοινές λειτουργίες ακολουθίας][common sequence operations] και μπορείς να τις διατρέξεις χρησιμοποιώντας τη σύνταξη `for item in <str>` ή `for index, item in enumerate(<str>)`.
Μπορούν να συνενωθούν χρησιμοποιώντας `<str> + <other str>` ή `<str>.join(<iterable>)`, να χωριστούν με `<str>.split(<separator>)` και προσφέρουν πολλαπλές επιλογές μορφοποίησης και σύνθεσης.

Για να εργαστείς περαιτέρω με συμβολοσειρές, η Python παρέχει ένα πλούσιο σύνολο [μεθόδων συμβολοσειράς][str-methods] που μπορούν να βοηθήσουν στην αναζήτηση, τον καθαρισμό, τον μετασχηματισμό, τη μετάφραση και πολλές άλλες λειτουργίες.

Καθώς είναι _αμετάβλητο_, η τιμή ενός αντικειμένου `str` στη μνήμη δεν αλλάζει, και οι μέθοδοι που φαίνεται να τροποποιούν μια συμβολοσειρά επιστρέφουν ένα νέο αντίγραφο ή στιγμιότυπο αυτού του αντικειμένου `str`.

[common sequence operations]: https://docs.python.org/3/library/stdtypes.html#common-sequence-operations
[str-methods]: https://docs.python.org/3/library/stdtypes.html#string-methods
[text sequence]: https://docs.python.org/3/library/stdtypes.html#text-sequence-type-str
[unicode code points]: https://stackoverflow.com/questions/27331819/whats-the-difference-between-a-character-a-code-point-a-glyph-and-a-grapheme
