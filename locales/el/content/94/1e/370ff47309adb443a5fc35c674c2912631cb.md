# Μεγάλα έξοδα στη βάση δεδομένων

## Εκφώνηση προβλήματος

Η ABC Corp θέλει να βρεις το όνομα και το τμήμα των υπαλλήλων των οποίων οι εγγραφές πληρωμών είναι μεγαλύτερες από ένα δεδομένο ποσό (π.χ. `3000.00`).

Δημιούργησε μια καταγραφή με όνομα `HighPayment` για να επιστρέψεις τα απαιτούμενα δεδομένα. Ο ορισμός της καταγραφής είναι ο εξής.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Χρησιμοποίησε τη λειτουργία `query` του πελάτη JDBC για να πάρεις τα απαιτούμενα δεδομένα από τη βάση δεδομένων.

> ΣΗΜΕΙΩΣΗ: Ταξινόμησε το αποτέλεσμα κατά `payment_id` σε αύξουσα σειρά.

## Στοιχεία βάσης δεδομένων

Χρησιμοποίησε τη βάση δεδομένων H2 που παρέχεται για αυτό το πρόβλημα.

> Το αρχείο της δειγματικής βάσης δεδομένων είναι το `gofigure.mv.db` και το όνομα της βάσης δεδομένων είναι `gofigure`. Δίνεται μέσα στον φάκελο `db`.

Οι παρακάτω πίνακες υπάρχουν ήδη στη δειγματική βάση δεδομένων H2 μαζί με μερικά δείγματα δεδομένων. Τα ονόματα των στηλών και οι τύποι δεδομένων δίνονται παρακάτω.

**Όνομα πίνακα** : `Employee`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `employee_id`     | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `name`            | συμβολοσειρά        |
| `city`            | συμβολοσειρά        |
| `department`      | συμβολοσειρά        |
| `age`             | ακέραιος        |

**Όνομα πίνακα**: `Payment`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `payment_id`      | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `date`            | ημερομηνία        |
| `amount`          | δεκαδικός        |
| `employee_id`     | ακέραιος        |
| `reason`          | συμβολοσειρά        |

* Το αρχείο της βάσης δεδομένων είναι το `gofigure.mv.db`. Χρησιμοποίησε το JDBC URL ως `jdbc:h2:file:/path/to/db/file`
* Όνομα χρήστη: `root`
* Κωδικός πρόσβασης: `root`

## Περιορισμοί

* Χρησιμοποίησε το αρχείο βάσης δεδομένων H2 που παρέχεται στον φάκελο `db` για να επαληθεύσεις τα ερωτήματα και το δείγμα της Ballerina
* Χρησιμοποίησε την προσέγγιση με παραμέτρους εξάρτησης του maven για να προσθέσεις τον οδηγό της βάσης δεδομένων H2 ως εξάρτηση πλατφόρμας στο Ballerina.toml σου

## Περιβάλλον δοκιμών

* Μπορείς να τρέξεις τα test με `bal test`, τα οποία θα εκτελεστούν πάνω στη δειγματική βάση δεδομένων που δίνεται.

## Υποδείξεις

* Χρησιμοποίησε το άρθρωμα [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) για να δουλέψεις με τη βάση δεδομένων
* Ανατρέξε στην ενότητα [Προαπαιτούμενα](https://lib.ballerina.io/ballerinax/java.jdbc/latest) για τα βήματα προσθήκης του οδηγού JDBC ως εξάρτησης
* Χρησιμοποίησε την απομακρυσμένη μέθοδο [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) για να ανακτήσεις δεδομένα από τη βάση δεδομένων
* Δες το παράδειγμα [Απλό ερώτημα](https://ballerina.io/learn/by-example/mysql-query-operation)
* Χρησιμοποίησε τον τύπο [stream](https://ballerina.io/learn/by-example/stream-type) της Ballerina για να έχεις πρόσβαση στα δεδομένα
* Χρησιμοποίησε SQL joins για να βρεις το ζητούμενο σύνολο δεδομένων από τη βάση δεδομένων
