# Εισαγωγή

Στη Cairo, οι τιμές Boolean (λογική τιμή) αντιπροσωπεύονται από τον προκαθορισμένο τύπο `bool`, που μπορεί να πάρει ως τιμή είτε `true` είτε `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Η Cairo υποστηρίζει τρεις λογικούς τελεστές που μπορούν να αξιολογήσουν εκφράσεις σε τιμές Boolean, επιστρέφοντας είτε `true` είτε `false`.

| Τελεστής    | Τι σημαίνει                                  |
| ----------- | -------------------------------------------- |
| `&&` (and)  | Είναι αληθές αν και οι δύο προτάσεις είναι αληθείς. |
| `\|\|` (or) | Είναι αληθές αν τουλάχιστον μία πρόταση είναι αληθής. |
| `!` (not)   | Είναι αληθές μόνο αν η πρόταση είναι ψευδής.  |
