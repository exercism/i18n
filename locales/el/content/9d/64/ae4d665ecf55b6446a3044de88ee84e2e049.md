# Προσάρτημα οδηγιών

## Υλοποίηση

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να υλοποιήσεις το struct ορίζοντας τον τύπο δεδομένων `school` και υλοποιώντας τις συναρτήσεις:

- newSchool
- add
- roster
- grade

Το κεφάλαιο 3 του [Notes on Programming SML/NJ][notes] εξετάζει τη χρήση signatures και structs.

[notes]: https://www.cs.cornell.edu/riccardo/prog-smlnj/notes-011001.pdf
