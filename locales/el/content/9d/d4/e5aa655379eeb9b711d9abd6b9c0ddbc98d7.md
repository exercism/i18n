# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο να παρακολουθείς τις υψηλές βαθμολογίες για το πιο δημοφιλές παιχνίδι στην τοπική αίθουσα arcade.

## 1. Πρόσθεσε παίκτες στον πίνακα υψηλών βαθμολογιών

Για να προσθέσεις έναν παίκτη στον πίνακα υψηλών βαθμολογιών, όρισε δύο μεθόδους `add_player!` που δέχονται τα εξής ορίσματα:

- Το πρώτο όρισμα είναι το λεξικό με τις βαθμολογίες.
- Το δεύτερο όρισμα είναι το όνομα ενός παίκτη ως συμβολοσειρά.
- Το τρίτο όρισμα είναι η βαθμολογία ως ακέραιος αριθμός.
  Αυτό το όρισμα είναι προαιρετικό, και όταν δεν δίνεται τιμή, η βαθμολογία πρέπει να ορίζεται σε 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Αφαίρεσε παίκτες από τον πίνακα υψηλών βαθμολογιών

Για να αφαιρέσεις έναν παίκτη από τον πίνακα υψηλών βαθμολογιών, όρισε τη συνάρτηση `remove_player!`, που δέχεται 2 ορίσματα:

- Το πρώτο όρισμα είναι το λεξικό με τις βαθμολογίες.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Ενημέρωσε τη βαθμολογία ενός παίκτη

Για να ενημερώσεις τη βαθμολογία ενός παίκτη αντικαθιστώντας την προηγούμενη, όρισε τη συνάρτηση `update_score!`, που δέχεται 3 ορίσματα:

- Το πρώτο όρισμα είναι το λεξικό με τις βαθμολογίες.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου τη βαθμολογία θέλεις να ενημερώσεις.
- Το τρίτο όρισμα είναι η βαθμολογία στην οποία θέλεις να οριστεί η αποθηκευμένη βαθμολογία.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Μηδένισε τη βαθμολογία ενός παίκτη

Για να μηδενίσεις τη βαθμολογία ενός παίκτη, όρισε τη συνάρτηση `reset_score!`, που δέχεται 2 ορίσματα:

- Το πρώτο όρισμα είναι το λεξικό με τις βαθμολογίες.
- Το δεύτερο όρισμα είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου τη βαθμολογία θέλεις να μηδενίσεις.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Πάρε μια λίστα με τους παίκτες

Για να πάρεις μια λίστα με τους παίκτες, όρισε τη συνάρτηση `players`, που δέχεται 1 όρισμα:

- Το πρώτο όρισμα είναι το λεξικό με τις βαθμολογίες.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
