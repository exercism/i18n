# Προσθήκη στις οδηγίες

## Υλοποίηση

Η άσκηση απαιτεί να γράψεις μια κλάση που παρέχει μια μέθοδο για κάθε παιδί του νηπιαγωγείου.
Μπορείς να κάνεις τη δουλειά σου λιγότερο επαναληπτική (και πιο διασκεδαστική!) αν, αντί να ορίσεις χειροκίνητα 12 διαφορετικές μεθόδους, χρησιμοποιήσεις λίγο μεταπρογραμματισμό.
Αν δεν είσαι σίγουρος από πού να ξεκινήσεις, ρίξε μια ματιά στις μεθόδους `method_missing` ή `define_method`.
