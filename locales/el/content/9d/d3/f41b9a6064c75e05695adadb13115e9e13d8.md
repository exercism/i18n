# Παράρτημα οδηγιών

## Για προχωρημένους

Συνηθίζεται να καλείς το [#to_enum][to_enum] όταν ορίζεις μεθόδους για ένα γενικό Enumerable, σε περίπτωση που δεν περαστεί κάποιο μπλοκ.

Ακολουθεί ένα επιπλέον test που θα μπορούσες να προσθέσεις:

```ruby
def test_accumulate_when_block_is_deferred
  skip
  accumulate_enumerator = [1, 2, 3].accumulate
  accumulated_result = accumulate_enumerator.map do |number|
    number * number
  end
  assert_equal [1, 4, 9], accumulated_result
end
```

[to_enum]: https://docs.ruby-lang.org/en/master/Object.html#method-i-to_enum
