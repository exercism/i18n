# Υποδείξεις

## 1. Ανάκτησε μια κάρτα από μια στοίβα

- Οι θέσεις στα `Vector` ξεκινούν από το `1`.
- Μπορείς να ανακτήσεις την `n`-οστή τιμή σε ένα διάνυσμα `v` με `v[n]`.

## 2. Αντάλλαξε μια κάρτα στη στοίβα

- Τα `Vector` είναι μεταβλητά. Μπορείς να αλλάξεις τα περιεχόμενά τους οποιαδήποτε στιγμή, εκχωρώντας μια νέα τιμή.

## 3. Βάλε μια κάρτα στην κορυφή της στοίβας

- Υπάρχει μια μέθοδος [`push!`][push] στη Base για να προσθέσεις μια νέα τιμή στο τέλος μιας συλλογής.

## 4. Αφαίρεσε μια κάρτα από τη στοίβα

- Υπάρχει μια μέθοδος [`deleteat!`][deleteat] στη Base για να διαγράψεις ένα στοιχείο από ένα `Vector` σε μια δεδομένη θέση.

## 5. Αφαίρεσε την πάνω κάρτα από τη στοίβα

- Υπάρχει μια μέθοδος [`pop!`][pop] στη Base για να αφαιρέσεις ένα στοιχείο από το τέλος μιας συλλογής.

## 6. Βάλε μια κάρτα στο κάτω μέρος της στοίβας

- Υπάρχει μια μέθοδος [`pushfirst!`][pushfirst] στη Base για να βάλεις μια νέα τιμή στην αρχή μιας συλλογής.

## 7. Αφαίρεσε μια κάρτα από το κάτω μέρος της στοίβας

- Υπάρχει μια μέθοδος [`popfirst!`][popfirst] στη Base για να αφαιρέσεις ένα στοιχείο από την αρχή μιας συλλογής.

## 8. Έλεγξε το μέγεθος της στοίβας

- Υπάρχει μια μέθοδος [`length`][length] στη Base για να ανακτήσεις το μήκος μιας συλλογής.
