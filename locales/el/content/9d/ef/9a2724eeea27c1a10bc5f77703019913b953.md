# Εισαγωγή

## Casting

Το casting και η μετατροπή τύπου είναι διαφορετικοί τρόποι για να μετατρέψεις μια παράσταση από έναν τύπο δεδομένων σε έναν άλλον.

Μια παράσταση μπορεί να υποστεί casting σε έναν άλλον τύπο με τον τελεστή casting `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Αν οι τύποι δεν είναι συμβατοί, το πρόγραμμα πετάει ένα στιγμιότυπο της `InvalidCastException`. Στην περίπτωση των αριθμών, αυτό σημαίνει ότι ο τύπος που δέχεται την τιμή δεν μπορεί να αναπαραστήσει την τιμή που μετατρέπεται. Στην περίπτωση των κλάσεων, ο ένας από τους τύπους πρέπει να προέρχεται από τον άλλον (αυτό ισχύει προφανώς και για τις δομές).

Μια εναλλακτική στο _casting_ είναι η _μετατροπή τύπου_ με τον τελεστή `is`. Αυτή εφαρμόζεται συνήθως σε τύπους αναφοράς και σε τύπους που δέχονται null.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Αν χρειάζεται να εντοπίσεις τον ακριβή τύπο ενός αντικειμένου, τότε ο τελεστής `is` μπορεί να είναι κάπως επιεικής, καθώς θα επιστρέψει την τιμή αληθής για μια κλάση και για οποιαδήποτε από τις κλάσεις και τις διεπαφές από τις οποίες αυτή προέρχεται, άμεσα ή έμμεσα. Σε αυτή την περίπτωση, η λύση είναι τα `typeof` και `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
