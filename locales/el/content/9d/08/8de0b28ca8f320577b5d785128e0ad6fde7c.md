# Εισαγωγή

Είδαμε σε προηγούμενες έννοιες ότι οι τύποι στη Julia σχηματίζουν μια ιεραρχία, με το `Any` στην κορυφή.

Οι αφηρημένοι τύποι όπως ο `Number` έχουν υποτύπους, αλλά οι ίδιοι δεν μπορούν να δημιουργηθούν ως στιγμιότυπα.
Ο καθορισμός μιας μεταβλητής σε έναν αφηρημένο τύπο _περιορίζει_ τις τιμές της μεταβλητής ώστε να είναι οποιοσδήποτε υπότυπος του αφηρημένου τύπου.
Για παράδειγμα:

```julia-repl
julia> x::Number = 3
3
julia> typeof(x)  # one subtype of Number
Int64
julia> x = 4.2
4.2
julia> typeof(x) # another subtype of Number
Float64
julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

Αυτό μας δίνει ένα είδος ευελιξίας στο να περιορίζουμε ποιες είσοδοι είναι έγκυρες.

Ωστόσο, ας υποθέσουμε ότι θέλουμε μια μεταβλητή να δέχεται τόσο ακέραιες όσο και τιμές συμβολοσειράς;
Αυτοί οι τύποι δεν βρίσκονται στον ίδιο κλάδο της ιεραρχίας.

Θα μπορούσαμε να ορίσουμε τον τύπο ως `Any`, ή να τον αφήσουμε να έχει ως προεπιλογή το `Any`, αλλά τότε χάνουμε κάθε έλεγχο των επιτρεπόμενων τύπων.

Για μια καλύτερη προσέγγιση, έχουμε τη σύνταξη `Union{ }`, με δύο ή περισσότερους τύπους μέσα στα άγκιστρα.

```julia-repl
julia> y::Union{Integer, String} = 4
4
julia> typeof(y)
Int64
julia> y = "works"
"works"
julia> typeof(y)
String
julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

Ένα άλλο παράδειγμα χρησιμοποιεί την ίδια ένωση τύπων σε υπογραφή συνάρτησης:

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}
julia> f(z::IntOrString) = z^3
f (generic function with 1 method)
julia> f(2) # integers are cubed
8
julia> f("ab") # strings are repeated 3 times
"ababab"
```

Εδώ, δώσαμε στον τύπο ένα όνομα, που μπορεί να προσφέρει βολική συντομογραφία αλλά δεν είναι απολύτως απαραίτητο.
Η συνάρτηση `g(z::Union{Integer, String}) = z^3` συμπεριφέρεται με τον ίδιο τρόπο.

Θα υπάρχουν πολλά περισσότερα να πούμε για τις υπογραφές συναρτήσεων στην έννοια Multiple Dispatch.

## Ενώσεις με το τίποτα

Αρκετές άλλες γλώσσες έχουν τύπους που μπορεί να περιέχουν ή να μην περιέχουν μια τιμή, με ονόματα όπως `Option`, `Nullable` ή `Maybe`.

Η Julia δεν έχει ειδική σύνταξη για αυτό, αλλά οι ενώσεις τύπων είναι μια γενίκευση της ίδιας ιδέας.

Είδαμε στην έννοια `Nothingness` ότι η Julia έχει διάφορους τρόπους να αναπαριστά μη τιμές, όπως τα `nothing` και `missing`.
Οποιοδήποτε από αυτά μπορεί να συμπεριληφθεί σε μια ένωση τύπων.

Για παράδειγμα, ορίζοντας κάποιου είδους συνδεδεμένη λίστα, χρειαζόμαστε έναν τρόπο να τερματίζουμε τη λίστα αν δεν υπάρχουν άλλοι κόμβοι.
`Nothing` είναι ο τύπος με μοναδική τιμή `nothing`, και αυτός ο ορισμός του Node καθιστά δυνατό να σηματοδοτήσουμε το τέλος της αλυσίδας:

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

Παρομοίως, το `missing` μπορεί να χρησιμοποιηθεί ως σύμβολο θέσης για τιμές που λείπουν, ειδικά σε συλλογές όπως τα διανύσματα.
Το παρακάτω παράδειγμα είναι πολύ επιτηδευμένο, αλλά οι τιμές που λείπουν είναι συνηθισμένες σε πραγματικά σύνολα δεδομένων.

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)
julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
