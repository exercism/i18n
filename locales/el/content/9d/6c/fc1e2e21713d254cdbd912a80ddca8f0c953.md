# Σχετικά

[Οι verbatim συμβολοσειρές][verbatim-strings] επιτρέπουν συμβολοσειρές πολλαπλών γραμμών. Ξεκινούν με ένα @. Μπορούν να χρησιμοποιηθούν με παρεμβολή συμβολοσειρών. Απλώς πρόσθεσε ένα "\$" πριν από το εισαγωγικό.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
