# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή σε ένα εργοστάσιο αυτοκινήτων.

## 1. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά ώρα

Τα αυτοκίνητα παράγονται σε μια γραμμή συναρμολόγησης.
Η γραμμή συναρμολόγησης έχει μια συγκεκριμένη ταχύτητα, η οποία μπορεί να αλλάξει.
Όσο πιο γρήγορη είναι η ταχύτητα της γραμμής συναρμολόγησης, τόσο περισσότερα αυτοκίνητα παράγονται.
Ωστόσο, η αλλαγή της ταχύτητας της γραμμής συναρμολόγησης αλλάζει και τον αριθμό των αυτοκινήτων που παράγονται επιτυχώς, δηλαδή των αυτοκινήτων χωρίς κανένα σφάλμα στην παραγωγή τους.

Υλοποίησε μια συνάρτηση που δέχεται τον αριθμό των αυτοκινήτων που παράγονται ανά ώρα και το ποσοστό επιτυχίας και υπολογίζει τον αριθμό των επιτυχημένων αυτοκινήτων που παράγονται ανά ώρα.
Το ποσοστό επιτυχίας δίνεται ως ποσοστό, από `0` έως `100`:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι `float64`.

## 2. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά λεπτό

Υλοποίησε μια συνάρτηση που δέχεται τον αριθμό των αυτοκινήτων που παράγονται ανά ώρα και το ποσοστό επιτυχίας και υπολογίζει πόσα αυτοκίνητα παράγονται επιτυχώς κάθε λεπτό:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι `int`.

## 3. Υπολόγισε το κόστος παραγωγής

Κάθε αυτοκίνητο κοστίζει κανονικά 10.000 δολάρια για να παραχθεί μεμονωμένα, ανεξάρτητα από το αν είναι επιτυχημένο ή όχι.
Με λίγο προγραμματισμό όμως, 10 αυτοκίνητα μπορούν να παραχθούν μαζί για 95.000 δολάρια.

Για παράδειγμα, 37 αυτοκίνητα μπορούν να παραχθούν με τον εξής τρόπο:
37 = 3 x ομάδες των δέκα + 7 μεμονωμένα αυτοκίνητα

Άρα το κόστος για 37 αυτοκίνητα είναι:
3\*95.000+7\*10.000=355.000

Υλοποίησε τη συνάρτηση `CalculateCost` που υπολογίζει το κόστος παραγωγής ενός αριθμού αυτοκινήτων, ανεξάρτητα από το αν είναι επιτυχημένα:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Σημείωση:** η τιμή επιστροφής πρέπει να είναι `uint`.
