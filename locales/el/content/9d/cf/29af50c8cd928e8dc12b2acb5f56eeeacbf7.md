# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να φτιάξεις καταπληκτικά λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τρεις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το μαγείρεμα των λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε το `expectedMinutesInOven` ώστε να υπολογίζει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```elm
expectedMinutesInOven
    --> 40
```

## 2. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε το `preparationTimeInMinutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων στα λαζάνια και επιστρέφει πόσα λεπτά χρειάζονται για να προετοιμαστούν τα λαζάνια, υποθέτοντας ότι κάθε στρώση θέλει 2 λεπτά για να ετοιμαστεί.

```elm
preparationTimeInMinutes 3
    --> 6
```

## 3. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsedTimeInMinutes` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων στα λαζάνια και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα των λαζάνια, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο εκείνη τη στιγμή.

```elm
elapsedTimeInMinutes 3 20
    --> 26
```
