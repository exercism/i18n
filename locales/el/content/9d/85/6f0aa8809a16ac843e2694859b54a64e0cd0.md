# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις μια εταιρεία πινακίδων να δημιουργεί προσαρμοσμένα μηνύματα για τις πινακίδες της.

## 1. Δημιούργησε ένα σύνολο χρήσιμων συμβολοσειρών

Όρισε τις παρακάτω σταθερές συμβολοσειρές που θα χρησιμοποιηθούν για τη δημιουργία πινακίδων:

- `birthday`: Περιέχει την τιμή "Birthday"
- `valentine`: Περιέχει την τιμή "Valentine's Day"
- `anniversary`: Περιέχει τη συμβολοσειρά "Anniversary"

## 2. Δημιούργησε ένα σύνολο χρήσιμων χαρακτήρων

Όρισε τους παρακάτω σταθερούς χαρακτήρες που θα χρησιμοποιηθούν για τη δημιουργία πινακίδων:

- `space`: Περιέχει την τιμή " " (ένα μόνο κενό)
- `exclamation`: Περιέχει την τιμή "!"

## 3. Συνδύασε φράσεις για να χτίσεις μηνύματα

Υλοποίησε τη συνάρτηση `buildSign(for:name:)`, η οποία παίρνει το όρισμα `for` που περιέχει μία από τις τρεις συμβολοσειρές που όρισες στην πρώτη εργασία και το όρισμα `name` που είναι μια συμβολοσειρά που περιέχει το όνομα του ατόμου για το οποίο προορίζεται η πινακίδα.
Θα χρησιμοποιήσεις τη συνένωση για να χτίσεις το μήνυμα της πινακίδας και θυμήσου να επαναχρησιμοποιήσεις τις σταθερές που έχεις ήδη ορίσει.
Η συνάρτηση θα πρέπει να επιστρέφει το μήνυμα της πινακίδας ως συμβολοσειρά.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Φτιάξε μια πινακίδα αποφοίτησης

Υλοποίησε τη συνάρτηση `graduationFor(name:year:)`, η οποία παίρνει το όρισμα `name` που είναι μια συμβολοσειρά που περιέχει το όνομα του ατόμου για το οποίο προορίζεται η πινακίδα και το όρισμα `year` που είναι ένας ακέραιος που περιέχει το έτος αποφοίτησης του ατόμου.
Θα χρησιμοποιήσεις συμβολοσειρές προτύπων για να χτίσεις το μήνυμα της πινακίδας.
Η συνάρτηση θα πρέπει να επιστρέφει το μήνυμα της πινακίδας ως συμβολοσειρά.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Υπολόγισε το κόστος μιας πινακίδας

Υλοποίησε τη συνάρτηση `costOf(sign:)`, η οποία παίρνει το όρισμα `sign` που είναι μια συμβολοσειρά που περιέχει το μήνυμα της πινακίδας.
Η πινακίδα έχει βασική τιμή 20 στο νόμισμα που δίνεται. Επιπλέον, κάθε γράμμα κοστίζει 2 (τα κενά συμπεριλαμβάνονται στον υπολογισμό).
Η συνάρτηση θα πρέπει να επιστρέφει το κόστος της πινακίδας ως ακέραιο.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
