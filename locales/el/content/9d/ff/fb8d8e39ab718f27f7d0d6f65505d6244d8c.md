# Προσθήκη στις οδηγίες

Η έξοδος θα πρέπει να είναι οργανωμένη σε [διάταξη κατά γραμμές](https://en.wikipedia.org/wiki/Row-_and_column-major_order): πρώτα όλες οι λέξεις της πρώτης γραμμής, μετά οι λέξεις της δεύτερης γραμμής, και ούτω καθεξής.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                           |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | είσοδος      | ακέραιος | μέγεθος                             |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | πίνακας λέξεων, σε διάταξη κατά γραμμές |
| `$v0`    | έξοδος       | ακέραιος | αριθμός λέξεων στον πίνακα          |
| `$t0-9`  | προσωρινή    | οποιοσδήποτε | για προσωρινή αποθήκευση            |
