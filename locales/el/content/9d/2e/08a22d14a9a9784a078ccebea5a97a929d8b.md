# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο ακόμα κώδικα που σχετίζεται με την προετοιμασία και το ψήσιμο της υπέροχης λαζάνιας σου από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες.
Η πρώτη σχετίζεται με το ίδιο το μαγείρεμα, οι άλλες τέσσερις με την τέλεια προετοιμασία.

## 1. Υπολόγισε τον χρόνο προετοιμασίας

Για την επόμενη λαζάνια που θα ετοιμάσεις, θέλεις να βεβαιωθείς ότι έχεις κρατήσει αρκετό χρόνο, ώστε να απολαύσεις το μαγείρεμα.
Έχεις ήδη σχεδιάσει από πόσα στρώματα θα αποτελείται η λαζάνια σου.
Τώρα θέλεις να υπολογίσεις πόσο χρόνο θα πάρει η προετοιμασία με βάση αυτό.

Υλοποίησε μια συνάρτηση `preparationTime` που δέχεται ένα διάνυσμα με τα στρώματα ως `string` και τον μέσο χρόνο προετοιμασίας ανά στρώμα σε λεπτά ως `int`.
Η συνάρτηση πρέπει να επιστρέφει την εκτίμηση για τον συνολικό χρόνο προετοιμασίας με βάση τον αριθμό των στρωμάτων ως `int`.
Αν δεν περάσεις τον μέσο χρόνο προετοιμασίας, τότε θα πρέπει να χρησιμοποιηθεί η προεπιλεγμένη τιμή `2`.

```cpp
std::vector<std::string> layers{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"};
preparationTime(layers, 3)
// => 18
preparationTime(layers)
// => 12
```

## 2. Υπολόγισε τις ποσότητες νουντλς και σάλτσας που χρειάζεσαι

Εκτός από το να κρατήσεις τον χρόνο, θέλεις επίσης να βεβαιωθείς ότι έχεις αρκετή σάλτσα και νουντλς για να φτιάξεις τη λαζάνια των ονείρων σου.
Για κάθε στρώμα νουντλς στη λαζάνια σου, θα χρειαστείς 50 γραμμάρια νουντλς.
Για κάθε στρώμα σάλτσας στη λαζάνια σου, θα χρειαστείς 0,2 λίτρα σάλτσας.

Όρισε τη συνάρτηση `quantities` που παίρνει ως παράμετρο ένα διάνυσμα με τα στρώματα ως `string`.
Η συνάρτηση θα προσδιορίζει τότε την ποσότητα νουντλς και σάλτσας που χρειάζεται για να φτιάξεις το γεύμα σου.
Το αποτέλεσμα πρέπει να επιστραφεί ως `amount` _struct_, που έχει ήδη οριστεί για σένα.
Το `amount` έχει δύο μεταβλητές-μέλη: η μία για το βάρος των `noodles` ως `int` και η δεύτερη για τον όγκο της `sauce` ως `double`.

```cpp
struct amount { int noodles; double sauce; };

amount needed{quantities({"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})};
// needed.noodles => 100
// needed.sauce => 0.4
```

## 3. Πρόσθεσε το μυστικό συστατικό

Πριν λίγο καιρό επισκέφτηκες έναν φίλο και έφαγες λαζάνια εκεί.
Ήταν καταπληκτική και είχε κάτι το ξεχωριστό.
Ο φίλος σου έστειλε τη λίστα με τα υλικά και σου είπε ότι το τελευταίο στοιχείο της λίστας είναι το "μυστικό συστατικό" που έκανε το γεύμα τόσο ξεχωριστό.
Τώρα θέλεις να προσθέσεις κι εσύ αυτό το μυστικό συστατικό στη συνταγή σου.

Γράψε μια συνάρτηση `addSecretIngredient` που δέχεται δύο `vector of strings` ως παραμέτρους.
Η πρώτη παράμετρος είναι μια _αναφορά_ στα υλικά της δικής σου συνταγής, και το δεύτερο _διάνυσμα_ συμβολοσειρών περιέχει τα υλικά που σου έστειλε ο φίλος σου.
Το τελευταίο στοιχείο στη λίστα με τα υλικά σου είναι πάντα `"?"`.
Η συνάρτηση πρέπει να το αντικαταστήσει με το τελευταίο στοιχείο της λίστας του φίλου σου.
**Σημείωση:** η `addSecretIngredient` δεν επιστρέφει τίποτα - πρέπει να τροποποιήσεις απευθείας τη λίστα με τα υλικά σου.
Η λίστα με τα υλικά του φίλου σου μπορεί επίσης να είναι αναφορά (για βελτίωση της απόδοσης), αλλά **δεν** πρέπει να τροποποιηθεί.
Βεβαιώσου ότι η λίστα δεν θα τροποποιηθεί, χρησιμοποιώντας μια αναφορά `const`.

```cpp
std::vector<std::string> friendsList{"noodles", "sauce", "mozzarella", "kampot pepper"};
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};

addSecretIngredient(myList, friendsList);
// myList => {"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Κλιμάκωσε τη συνταγή

Οι ποσότητες που αναγράφονται στο βιβλίο μαγειρικής σου φτάνουν μόνο για λαζάνια δύο μερίδων.
Επειδή θέλεις να μαγειρέψεις για περισσότερα άτομα την επόμενη φορά, θέλεις να υπολογίσεις τις ποσότητες για διαφορετικό αριθμό μερίδων.

Υλοποίησε μια συνάρτηση `scaleRecipe` που παίρνει δύο παραμέτρους.

- Ένα διάνυσμα με τις ποσότητες `double` που χρειάζονται για 2 μερίδες.
- Τον αριθμό των μερίδων που θέλεις να μαγειρέψεις.

Η συνάρτηση πρέπει να επιστρέφει ένα νέο διάνυσμα με τις ποσότητες που χρειάζονται για τον επιθυμητό αριθμό μερίδων.
Θέλεις όμως να κρατήσεις την αρχική συνταγή.
Αυτό σημαίνει ότι το όρισμα `quantities` δεν πρέπει να τροποποιηθεί μέσα σε αυτή τη συνάρτηση.

```cpp
std::vector<double> quantities{1.2, 3.6, 10.5};
scaleRecipe(quantities, 4);
// => { 2.4, 7.2, 21 }
```

## 5. Ξεκλείδωσε το οικογενειακό μυστικό

Θυμάσαι ιστορίες από την παιδική σου ηλικία, παραμύθια για τη μεγάλη θεία σου, τη φύλακα των βαθύτερων γαστρονομικών μυστικών της οικογένειας.
Ο θρύλος λέει ότι κρατά το κλειδί για να ξεκλειδώσεις γεύσεις πέρα από κάθε φαντασία, αλλά οι μέθοδοί της είναι ανορθόδοξες.
Δεν ασχολείται με λίστες ή μετρήσεις· σου μιλά ψιθυριστά, αποκαλύπτοντας μόνο ένα υλικό τη φορά.

Με ένα μείγμα ενθουσιασμού και ανησυχίας, αποφασίζεις να επικοινωνήσεις με τη μεγάλη θεία σου.
Όπως περίμενες, απαντά με τον αινιγματικό της τρόπο, προσφέροντάς σου ένα μόνο μυστικό συστατικό, τυλιγμένο στο μυστήριο.

Η συνεισφορά της μεγάλης θείας σου προσθέτει ένα στρώμα πολυπλοκότητας, που θέλεις να το χρησιμοποιήσεις στη συνταγή σου.
Υλοποίησε μια άλλη εκδοχή της συνάρτησης `addSecretIngredient` που δέχεται δύο ορίσματα: μια αναφορά σε ένα διάνυσμα που αντιπροσωπεύει τη λίστα με τα υλικά σου και μία μεμονωμένη συμβολοσειρά που αντιπροσωπεύει την αινιγματική προσφορά της μεγάλης θείας σου.

```cpp
std::vector<std::string> myList{"noodles", "meat", "sauce", "mozzarella", "?"};
std::string secretIngredient{"spice melange"};
addSecretIngredient(myList, secretIngredient);
// myList => {"noodles", "meat", "sauce", "mozzarella", "spice melange"}
```
