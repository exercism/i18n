# Σχετικά

Ο δεσμός περιγράφει από πού στον κώδικα μπορεί να προσπελαστεί ένα αναγνωριστικό.
Οι τιμές με εμβέλεια μπλοκ, συνάρτησης ή πρωτότυπου συνάρτησης δεν έχουν δεσμό.
Αυτό σημαίνει ότι δεν μπορούν να προσπελαστούν από έξω από την εμβέλειά τους.
Για περισσότερα σχετικά με την εμβέλεια, δες την [έννοια της εμβέλειας](../scope/introduction.md#Introduction).

## Εξωτερικός δεσμός

Τα αναγνωριστικά με εμβέλεια αρχείου έχουν εξωτερικό δεσμό από προεπιλογή.
Ένα αναγνωριστικό με εξωτερικό δεσμό μπορεί να κληθεί από οποιοδήποτε αρχείο του προγράμματος.

## Εσωτερικός δεσμός

Ένα αναγνωριστικό με εμβέλεια αρχείου μπορεί να αποκτήσει εσωτερικό δεσμό χρησιμοποιώντας το προσδιοριστικό `static`.
Ένα αναγνωριστικό με εσωτερικό δεσμό μπορεί να χρησιμοποιηθεί μόνο μέσα στο αρχείο του.

Για παράδειγμα

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Ο στατικός δεσμός δεν πρέπει να συγχέεται με τη στατική διάρκεια αποθήκευσης.
Για περισσότερα σχετικά με τη στατική διάρκεια αποθήκευσης, δες την [έννοια της διάρκειας αποθήκευσης](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).

Αν μια τιμή (σε αντίθεση με μια συνάρτηση) δηλώνεται σε ένα αρχείο κεφαλίδας αλλά ορίζεται στο αρχείο πηγαίου κώδικα ως αναγνωριστικό εμβέλειας αρχείου με `static` και αρχικοποιημένη τιμή, η αρχικοποιημένη τιμή της δεν θα είναι προσπελάσιμη από έξω από το αρχείο πηγαίου κώδικά της.
Μπορεί να μεταγλωττιστεί, να συνδεθεί και να εκτελεστεί χωρίς σφάλμα, αλλά η τιμή θα είναι η μηδενική τιμή για το αναγνωριστικό, ακόμα κι αν η τιμή δηλώνεται με `extern`.
(Για περισσότερα σχετικά με το `extern`, δες την [έννοια του extern](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#extern-how-to-access-a-variable-in-another-translation-unit).)
Ένα αναγνωριστικό εμβέλειας αρχείου που έχει σημειωθεί ως `static` σε ένα αρχείο πηγαίου κώδικα δεν πρέπει να δηλώνεται στο αρχείο κεφαλίδας του.
