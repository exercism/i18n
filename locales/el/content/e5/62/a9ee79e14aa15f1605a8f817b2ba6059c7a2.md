# Εισαγωγή

Μια *κανονική έκφραση* (regex) είναι ένα μικρό μοτίβο που περιγράφει πώς πρέπει να
μοιάζει κάποιο κείμενο. Αντί να ελέγχεις ο ίδιος μια συμβολοσειρά χαρακτήρα προς
χαρακτήρα, γράφεις τη μορφή που θέλεις μία φορά και αφήνεις τη Factor να κάνει την
αντιστοίχιση. Τα εργαλεία regex της Factor βρίσκονται στο λεξιλόγιο [`regexp`][regexp].

## Γράφοντας ένα μοτίβο

Στη Factor γράφεις ένα regex ανάμεσα στα `R/ ` και `/`:

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

Οι περισσότεροι χαρακτήρες σε ένα μοτίβο σημαίνουν απλώς τον εαυτό τους, δηλαδή το
`R/ cat/` ταιριάζει με το κείμενο `cat`. Η δύναμη προέρχεται από λίγα ειδικά κομμάτια
που παριστάνουν *είδη* χαρακτήρων ή *πόσα* από αυτά.

### Κλάσεις χαρακτήρων: "ένας χαρακτήρας από ένα σύνολο"

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

Μια κλάση ταιριάζει με *έναν* ακριβώς χαρακτήρα. Το `[A-Z]` ταιριάζει με το `Q` αλλά
όχι με το `QQ`.

### Ποσοδείκτες: "πόσες φορές"

Βάλε ένα από αυτά *μετά* από ένα κομμάτι για να δηλώσεις πόσες φορές μπορεί να
επαναληφθεί:

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

Έτσι, το `\d{4}` σημαίνει τέσσερα ψηφία στη σειρά, και το `[A-Z]+` σημαίνει ένα ή
περισσότερα κεφαλαία γράμματα. Συνδυάζοντάς τα, το `R/ [A-Z]+-\d+/` περιγράφει "ένα
ή περισσότερα κεφαλαία, μια παύλα και μετά ένα ή περισσότερα ψηφία", δηλαδή κείμενο
σαν το `SALE-2024`. Εδώ το `-` είναι ένας συνηθισμένος χαρακτήρας: έξω από τα `[ ]` μια
παύλα ταιριάζει απλώς με μια παύλα (μέσα σε μια κλάση, όπως στο `[A-Z]`, ορίζει ένα
εύρος).

## Αντιστοίχιση μιας ολόκληρης συμβολοσειράς

Το `matches?` απαντά στο "ταιριάζει ολόκληρη αυτή η συμβολοσειρά με το μοτίβο;", δηλαδή
το μοτίβο πρέπει να καλύπτει κάθε χαρακτήρα, από την αρχή ως το τέλος:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

Ακόμα κι αν το `SALE-2024` βρίσκεται μέσα στο `"GET SALE-2024"`, το `matches?` εξακολουθεί
να λέει `f`: οι επιπλέον χαρακτήρες είναι μέρος της συμβολοσειράς και δεν ταιριάζουν με
το μοτίβο. Όταν σε νοιάζει μόνο αν το μοτίβο εμφανίζεται *κάπου*, χρησιμοποίησε το
`re-contains?`, το οποίο επιστρέφει `t` ακριβώς εκεί που το `matches?` επέστρεψε `f`:

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## Εύρεση αντιστοιχιών μέσα σε μεγαλύτερο κείμενο

Το `re-contains?` σου λέει μόνο *αν* το μοτίβο υπάρχει μέσα. Οι επόμενες λέξεις
κοιτάζουν μέσα και αναφέρουν *τι* ταίριαξε: το `all-matching-subseqs` επιστρέφει κάθε
σημείο όπου ταιριάζει το μοτίβο, ως ακολουθία συμβολοσειρών, και το `count-matches`
απλώς τα μετράει:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## Αντικατάσταση αντιστοιχιών

Το `re-replace` αντικαθιστά κάθε αντιστοιχία με ένα κομμάτι κειμένου αντικατάστασης και
επιστρέφει τη νέα συμβολοσειρά:

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

Το λεξιλόγιο `regexp` έχει κι άλλες λέξεις που αξίζει να γνωρίζεις. Ακολούθησε τους
συνδέσμους για λεπτομέρειες: [`first-match`][first-match] (μόνο την πρώτη αντιστοιχία)
και [`re-split`][re-split] (χωρίζει μια συμβολοσειρά σε κάθε σημείο όπου ταιριάζει το
μοτίβο).

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
[first-match]: https://docs.factorcode.org/content/word-first-match%2Cregexp.html
[re-split]: https://docs.factorcode.org/content/word-re-split%2Cregexp.html
