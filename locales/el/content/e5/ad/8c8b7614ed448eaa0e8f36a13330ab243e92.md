# Τεστ

Τρέξε τα τεστ με:

```shell
npm run test
```

Μπορείς επίσης να τρέξεις το Jest σε λειτουργία "watch", η οποία θα ξανατρέχει αυτόματα τα τεστ σου κάθε φορά που αποθηκεύεις αλλαγές στον κώδικα ή στο module των τεστ:

```shell
npm run watch
```

## Κατανόηση των παραλειπόμενων τεστ

Η μέθοδος skip λέει στη σουίτα τεστ να μην τρέξει κάποιο τεστ. Αυτή η συνάρτηση μπορεί να χρησιμοποιηθεί και με τα ψευδώνυμα: `it.skip(name, fn)` ή `xit(name, fn)` ή `xtest(name, fn)`

- Γιατί παραλείπονται;

Για να μπορούν οι χρήστες να συγκεντρώνονται σε ένα τεστ τη φορά και να τα ενεργοποιούν ένα ένα όσο εξελίσσουν τη λύση.

- Πώς ενεργοποιούνται;

Άλλαξε το `xtest` σε `test`.

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
