# Οδηγίες

Σε αυτή την άσκηση, θα υλοποιήσεις τη λογική της αποστολής για ένα νέο παιχνίδι RPG που αναπτύσσει ένας φίλος σου. Η βασική ηρωίδα του παιχνιδιού είναι η Annalyn, ένα γενναίο κορίτσι με έναν άγριο και πιστό σκύλο. Δυστυχώς, η καταστροφή χτυπά, καθώς η καλύτερή της φίλη απήχθη ενώ έψαχνε για μούρα στο δάσος. Η Annalyn θα προσπαθήσει να βρει και να ελευθερώσει την καλύτερή της φίλη, παίρνοντας προαιρετικά τον σκύλο της μαζί της σε αυτή την αποστολή.

Αφού πέρασε λίγο χρόνο ακολουθώντας τα ίχνη της καλύτερής της φίλης, βρίσκει το στρατόπεδο όπου κρατείται η καλύτερή της φίλη. Αποδεικνύεται ότι υπάρχουν δύο απαγωγείς: ένας πανίσχυρος ιππότης και ένας πονηρός τοξότης.

Έχοντας βρει τους απαγωγείς, η Annalyn σκέφτεται ποιες από τις παρακάτω ενέργειες μπορεί να κάνει:

- Γρήγορη επίθεση: μπορείς να κάνεις γρήγορη επίθεση αν ο ιππότης κοιμάται, καθώς χρειάζεται χρόνο για να φορέσει την πανοπλία του, οπότε θα είναι ευάλωτος.
- Κατασκόπευση: μπορείς να κατασκοπεύσεις την ομάδα αν τουλάχιστον ένας από αυτούς είναι ξύπνιος. Διαφορετικά, η κατασκόπευση είναι χάσιμο χρόνου.
- Σήμα στον κρατούμενο: μπορείς να στείλεις σήμα στον κρατούμενο με ήχους πουλιών αν ο κρατούμενος είναι ξύπνιος και ο τοξότης κοιμάται, καθώς οι τοξότες είναι εκπαιδευμένοι στο σήμα με πουλιά, οπότε θα μπορούσαν να υποκλέψουν το μήνυμα.
- _Ελευθέρωσε τον κρατούμενο_: Η Annalyn μπορεί να προσπαθήσει να μπει κρυφά στο στρατόπεδο για να ελευθερώσει τον κρατούμενο.
  Αυτό είναι ριψοκίνδυνο και μπορεί να πετύχει μόνο με έναν από τους δύο παρακάτω τρόπους:
  - Αν η Annalyn έχει μαζί της τον σκύλο της, μπορεί να σώσει τον κρατούμενο αν ο τοξότης κοιμάται.
    Ο ιππότης φοβάται τον σκύλο και ο τοξότης δεν θα προλάβει να ετοιμαστεί πριν η Annalyn και ο κρατούμενος δραπετεύσουν.
  - Αν η Annalyn δεν έχει τον σκύλο της, τότε αυτή και ο κρατούμενος πρέπει να κινηθούν πολύ κρυφά!
    Η Annalyn μπορεί να ελευθερώσει τον κρατούμενο αν ο κρατούμενος είναι ξύπνιος και ο ιππότης με τον τοξότη κοιμούνται και οι δύο, αλλά αν ο κρατούμενος κοιμάται δεν μπορεί να σωθεί: θα τρομάξει από την ξαφνική εμφάνιση της Annalyn και θα ξυπνήσει τον ιππότη και τον τοξότη.

Έχεις τέσσερις εργασίες: να υλοποιήσεις τη λογική που καθορίζει αν οι παραπάνω ενέργειες είναι διαθέσιμες με βάση την κατάσταση των τριών χαρακτήρων που βρίσκονται στο δάσος και αν ο σκύλος της Annalyn είναι παρών ή όχι.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

Υλοποίησε τη μέθοδο `canFastAttack()`, η οποία παίρνει μια τιμή Boolean (λογική τιμή) που δείχνει αν ο ιππότης είναι ξύπνιος. Η μέθοδος επιστρέφει `true` αν μπορεί να γίνει γρήγορη επίθεση με βάση την κατάσταση του ιππότη. Διαφορετικά, επιστρέφει `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

Υλοποίησε τη μέθοδο `canSpy()`, η οποία παίρνει τρεις τιμές Boolean, που δείχνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η μέθοδος επιστρέφει `true` αν μπορείς να κατασκοπεύσεις την ομάδα, με βάση την κατάσταση των τριών χαρακτήρων. Διαφορετικά, επιστρέφει `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Έλεγξε αν μπορείς να στείλεις σήμα στον κρατούμενο

Υλοποίησε τη μέθοδο `canSignalPrisoner()`, η οποία παίρνει δύο τιμές Boolean, που δείχνουν αν ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η μέθοδος επιστρέφει `true` αν μπορείς να στείλεις σήμα στον κρατούμενο, με βάση την κατάσταση των δύο χαρακτήρων. Διαφορετικά, επιστρέφει `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Έλεγξε αν μπορείς να ελευθερώσεις τον κρατούμενο

Υλοποίησε τη μέθοδο `canFreePrisoner()`, η οποία παίρνει τέσσερις τιμές Boolean. Οι τρεις πρώτες παράμετροι δείχνουν αν ο ιππότης, ο τοξότης και ο κρατούμενος, αντίστοιχα, είναι ξύπνιοι. Η τελευταία παράμετρος δείχνει αν ο σκύλος της Annalyn είναι παρών. Η μέθοδος επιστρέφει `true` αν μπορείς να ελευθερώσεις τον κρατούμενο με βάση την κατάσταση των τριών χαρακτήρων και την παρουσία του σκύλου της Annalyn. Διαφορετικά, επιστρέφει `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
