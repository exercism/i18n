# Εισαγωγή

## Γενική σύνταξη

Ο `for` βρόχος είναι μία από τις πιο συχνά χρησιμοποιούμενες εντολές για την επαναλαμβανόμενη εκτέλεση κάποιας λογικής.
Στη Go αποτελείται από τη λέξη-κλειδί `for`, μια κεφαλίδα και ένα μπλοκ κώδικα που περιέχει το σώμα του βρόχου μέσα σε άγκιστρα.
Η κεφαλίδα αποτελείται από 3 στοιχεία που χωρίζονται με το σύμβολο `;`: init, condition και post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Το στοιχείο **init** είναι κώδικας που εκτελείται μόνο μία φορά, πριν ξεκινήσει ο βρόχος.
- Το στοιχείο **condition** πρέπει να είναι κάποια έκφραση που αξιολογείται σε Boolean (λογική τιμή) και ελέγχει πότε πρέπει να σταματήσει ο βρόχος.
  Ο κώδικας μέσα στον βρόχο θα εκτελείται όσο αυτή η συνθήκη αξιολογείται ως αληθής.
  Μόλις αυτή η έκφραση αξιολογηθεί ως ψευδής, δεν θα εκτελεστούν άλλες επαναλήψεις του βρόχου.
- Το στοιχείο **post** είναι κώδικας που εκτελείται στο τέλος κάθε επανάληψης.

**Σημείωση:** Σε αντίθεση με άλλες γλώσσες, δεν υπάρχουν παρενθέσεις `()` γύρω από τα τρία στοιχεία της κεφαλίδας.
Στην πραγματικότητα, η εισαγωγή τέτοιων παρενθέσεων είναι σφάλμα μεταγλώττισης.
Ωστόσο, τα άγκιστρα `{ }` γύρω από το σώμα του βρόχου είναι πάντα απαραίτητα.

## Οι `for` βρόχοι - Ένα παράδειγμα

Το στοιχείο init συνήθως αρχικοποιεί μια μεταβλητή μετρητή, το στοιχείο condition ελέγχει αν ο βρόχος πρέπει να συνεχιστεί ή να σταματήσει και το στοιχείο post συνήθως αυξάνει τον μετρητή στο τέλος κάθε επανάληψης.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Αυτός ο βρόχος θα εκτυπώσει τους αριθμούς από το `1` έως το `9` (συμπεριλαμβανομένου του `9`).
Ο ορισμός του βήματος γίνεται συχνά με μια εντολή αύξησης ή μείωσης, όπως φαίνεται στο παραπάνω παράδειγμα.
