# Tests

Για κάθε παράδειγμα χρειάζονται τα παρακάτω γενικά βήματα.

Πρώτα, πήγαινε στον κατάλογο της άσκησης που θέλεις να εξασκηθείς, στην
προκειμένη περίπτωση τη `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

Στη συνέχεια τρέξε τα tests. Ο στόχος `test` του make εξαρτάται από το
`compile`, οπότε τρέχοντας `make test` θα σιγουρευτείς ότι ο πηγαίος
κώδικάς σου έχει μεταγλωττιστεί και μετά θα προχωρήσει στην εκτέλεση
των tests.


```bash
$ make test
```

Συγχαρητήρια! Έχεις tests που αποτυγχάνουν!!!

Τώρα διάβασε το `README.md` για να δεις τι πρέπει να κάνεις ώστε να
περάσουν όλα τα tests σου.


Διόρθωσε το πρώτο σφάλμα που αναφέρει το test και τρέξε ξανά τα tests.

```bash
$ make test
```

Συνέχισε διορθώνοντας το επόμενο test που αποτυγχάνει στον πηγαίο κώδικά
σου και τρέχοντας τα tests, μέχρι να περάσουν όλα.

Μόλις περάσουν όλα τα tests σου, ρίξε μια τελευταία ματιά στον κώδικά σου
στον κατάλογο `src` για να βεβαιωθείς ότι είσαι ευχαριστημένος με αυτόν
και υπέβαλέ τον για αξιολόγηση.

Πάρε ανατροφοδότηση, αναθεώρησε τη λύση, υπέβαλέ την, δοκίμασε την
επόμενη άσκηση και επανάλαβε, μέχρι να φτάσεις στον διαφωτισμό της LFE.
