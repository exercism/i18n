# Προσθήκη στις οδηγίες

~~~~exercism/note

Η παραπάνω περιγραφή αναφέρει [_μαθηματικά σύνολα_][math-sets], αλλά και ότι μια Πυθαγόρεια τριάδα {a, b, c} _**πρέπει**_ να είναι διατεταγμένη έτσι ώστε a < b < c (_αύξουσα σειρά_). 

Αυτό κάνει τον τύπο [`set`][python-sets] της Python ακατάλληλο για αυτή την άσκηση, αφού είναι εκ φύσεως _μη διατεταγμένος_. 
Αντ' αυτού, θα πρέπει να επιστρέψεις μια [`list`][python-list] από `list`s (_π.χ. `[[a, b, c]]`_). 
Μπορείς να δημιουργήσεις τις τριάδες με όποια σειρά θέλεις, αφού η σειρά της εξωτερικής `list` αγνοείται στα τεστ. 

[math-sets]: https://en.wikipedia.org/wiki/Set_(mathematics)
[python-sets]: https://docs.python.org/3/tutorial/datastructures.html#sets
[python-list]: https://docs.python.org/3/tutorial/datastructures.html#more-on-lists
