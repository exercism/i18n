# Σχετικά

Στη Go, οι συναρτήσεις είναι τιμές πρώτης κατηγορίας.
Αυτό σημαίνει ότι μπορείς να κάνεις με τις συναρτήσεις τα ίδια πράγματα που μπορείς να κάνεις με όλες τις άλλες τιμές: να αναθέσεις συναρτήσεις σε μεταβλητές, να τις περάσεις ως ορίσματα σε άλλες συναρτήσεις ή ακόμη και να επιστρέψεις συναρτήσεις από άλλες συναρτήσεις.

Παρακάτω δημιουργούμε δύο συναρτήσεις, τις `engGreeting` και `espGreeting`, και τις αναθέτουμε στη μεταβλητή `greeting`:

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

Οι τιμές συναρτήσεων σου δίνουν τη δυνατότητα να παραμετροποιείς συναρτήσεις όχι μόνο με δεδομένα αλλά και με συμπεριφορά.
Στο παρακάτω παράδειγμα, περνάμε συμπεριφορά στη συνάρτηση `dialog` μέσω της παραμέτρου `greetingFunc`:

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

Η τιμή μιας μη αρχικοποιημένης μεταβλητής τύπου συνάρτησης είναι `nil`.
Επομένως, η κλήση μιας τιμής συνάρτησης `nil` προκαλεί panic.

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

Οι τιμές συναρτήσεων μπορούν να συγκριθούν με το `nil`.
Αυτό μπορεί να σου φανεί χρήσιμο για να αποφύγεις περιττά panic στο πρόγραμμα.

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## Τύποι συναρτήσεων

Η χρήση τιμών συναρτήσεων είναι εφικτή χάρη στους τύπους συναρτήσεων στη Go.
Ένας τύπος συνάρτησης δηλώνει το σύνολο όλων των συναρτήσεων με την ίδια ακολουθία τύπων παραμέτρων και την ίδια ακολουθία τύπων αποτελέσματος.
Μπορείς να δηλώσεις τύπους ορισμένους από τον χρήστη πάνω σε τύπους συναρτήσεων.
Για παράδειγμα, η συνάρτηση `dialog` από τα προηγούμενα παραδείγματα μπορεί να ενημερωθεί ως εξής:

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## Ανώνυμες συναρτήσεις

Ένα άλλο ισχυρό εργαλείο που έχεις στη διάθεσή σου χάρη στην υποστήριξη συναρτήσεων πρώτης κατηγορίας είναι οι ανώνυμες συναρτήσεις.
Οι ανώνυμες συναρτήσεις ορίζονται στο σημείο όπου χρησιμοποιούνται, χωρίς κάποιο όνομα μετά τη λέξη-κλειδί `func`.
Τέτοιες συναρτήσεις έχουν πρόσβαση στις μεταβλητές της συνάρτησης που τις περικλείει.

Για παράδειγμα:

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

Μια κλήση στη `fib` δηλώνει τις μεταβλητές `n1` και `n2` και επιστρέφει μια ανώνυμη συνάρτηση που, με τη σειρά της, αλλάζει τις τιμές αυτών των μεταβλητών κάθε φορά που καλείται η συνάρτηση.
Η Ν-οστή κλήση της ανώνυμης συνάρτησης επιστρέφει τον Ν-οστό αριθμό της ακολουθίας Fibonacci ξεκινώντας από το 0. Η εσωτερική ανώνυμη συνάρτηση έχει πρόσβαση στις τοπικές μεταβλητές (`n1` και `n2`) της συνάρτησης `fib` που την περικλείει.
Αυτός είναι ένας εξαιρετικός τρόπος ώστε οι τιμές συναρτήσεων να διατηρούν κατάσταση μεταξύ των κλήσεων.
Λέμε ότι η ανώνυμη συνάρτηση είναι ένα closure των μεταβλητών `n1` και `n2`.
Τα closures χρησιμοποιούνται ευρέως στον προγραμματισμό και μπορεί να δεις και άλλες γλώσσες να τα υποστηρίζουν.
