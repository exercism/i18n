# Οδηγίες

Καλώς ήρθες στον κόσμο του *ChronoRealms*, μιας μαγικής χώρας όπου ισχυροί Timekeepers ελέγχουν τη ροή του χρόνου.

Σε αυτό το βασίλειο, οι Timekeepers διαχειρίζονται τα "TimeShards", ειδικές μονάδες που μπορούν να προστεθούν, να αφαιρεθούν, να συγκριθούν και ακόμη να ελεγχθεί η ισότητά τους.

Το καθήκον σου είναι να βοηθήσεις τους Timekeepers υλοποιώντας προσαρμοσμένους τελεστές για τον χειρισμό αυτών των TimeShards.

Οι Timekeepers θέλουν να δημιουργήσεις ένα προσαρμοσμένο struct `TimeShard` που υποστηρίζει τις παρακάτω λειτουργίες:

1. **Πρόσθεση και αφαίρεση TimeShards**: Οι Timekeepers πρέπει να μπορούν να προσθέτουν και να αφαιρούν TimeShards για να ελέγχουν τη χρονογραμμή.
2. **Σύγκριση TimeShards**: Μερικές φορές, τα TimeShards πρέπει να συγκρίνονται για να δούμε ποιο είναι μεγαλύτερο ή αν είναι ίσα.
3. **Έλεγχος ισότητας**: Οι Timekeepers πρέπει να ελέγχουν αν δύο TimeShards είναι πανομοιότυπα ως προς την τιμή.

Η αποστολή σου είναι να υλοποιήσεις τα παρακάτω traits για το struct `TimeShard`:

1. **Πρόσθεση (`Add`)**: Δίνει τη δυνατότητα πρόσθεσης δύο στιγμιοτύπων `TimeShard` μεταξύ τους.
2. **Αφαίρεση (`Sub`)**: Δίνει τη δυνατότητα αφαίρεσης ενός `TimeShard` από ένα άλλο.
3. **Ισότητα (`PartialEq`)**: Επιτρέπει στους Timekeepers να ελέγχουν αν δύο στιγμιότυπα `TimeShard` είναι ίδια.
4. **Σύγκριση (`PartialOrd`)**: Επιτρέπει τη σύγκριση δύο στιγμιοτύπων `TimeShard` για να δούμε ποιο είναι μεγαλύτερο ή μικρότερο.

Ένα `TimeShard` θα αναπαρίσταται από ένα struct που περιέχει μια ακέραια τιμή (`i32`).

Υλοποίησε τα απαραίτητα traits για να κάνεις τη δουλειά των Timekeepers πιο εύκολη.

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
