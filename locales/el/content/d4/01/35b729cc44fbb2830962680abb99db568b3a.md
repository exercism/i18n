# Υποδείξεις

## Γενικά
- Ο [τύπος][types] μιας μεταβλητής καθορίζεται από την τιμή της μεταβλητής: το *10* ως `Int`, το *'Hello'* ως `String` ή το *2.0* ως `double`.

## 1. Όρισε τον σταθερό αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια σταθερή μεταβλητή και να της αναθέσεις μια ακέραια τιμή.
- Μπορείς να ορίσεις σταθερές μέσω του [cmdlet New-Variable][new variable].

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][defining functions] με μία παράμετρο.
- Χρησιμοποίησε τον [μαθηματικό τελεστή για την αφαίρεση][arithmetic] για να αφαιρέσεις τιμές.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει μια τιμή][return].

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][defining functions] με μία παράμετρο.
- Χρησιμοποίησε τον [μαθηματικό τελεστή για τον πολλαπλασιασμό][arithmetic] για να πολλαπλασιάσεις τιμές.
- Θα μπορούσες να ορίσεις μια επιπλέον _σταθερά_ για τον χρόνο σε λεπτά ανά στρώση, αντί να χρησιμοποιήσεις έναν "μαγικό αριθμό" στον κώδικα σου.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει μια τιμή][return] ακέραιου τύπου.

## 4. Υπολόγισε τον συνολικό χρόνο μαγειρέματος (προετοιμασία + ψήσιμο) σε λεπτά

- Όρισε μια [συνάρτηση][defining functions] με δύο παραμέτρους.
- Μπορείς να _καλέσεις_ μια συνάρτηση που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για την πρόσθεση][arithmetic] για να αθροίσεις τιμές.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει μια τιμή][return] ακέραιου τύπου.

## 5. Ενημέρωσε τη συνταγή με σημειώσεις

- Όρισε μια συνάρτηση χωρίς παράμετρο.
- Αυτή η συνάρτηση πρέπει να επιστρέφει μια τιμή συμβολοσειράς.
