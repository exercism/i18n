# Τεστ

Για να δοκιμάσεις τη λύση σου, άνοιξε το τερματικό και τρέξε

```
mason test
```

στον φάκελο της άσκησης (αυτόν που περιέχει το αρχείο `Mason.toml` και τους φακέλους `src/` και `test/`).

Αν πιστεύεις ότι το μήνυμα σφάλματος δεν είναι αρκετά κατατοπιστικό, μπορείς να δοκιμάσεις το παρακάτω για να πάρεις ένα πιο αναλυτικό.

```
mason test --show
```
