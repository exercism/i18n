# Οδηγίες

Μόλις προσλήφθηκες σε μια νέα υπηρεσία ταξί που προσπαθεί να ξεχωρίσει από τις άλλες προσφορές σε μια ήδη κορεσμένη αγορά.
Για να το πετύχει αυτό, ο διευθύνων σύμβουλος αποφάσισε να προσφέρει μια εξαιρετικά πολυτελή υπηρεσία στο Μανχάταν, με συνοδούς σε κάθε διασταύρωση που βοηθούν τους πελάτες πριν και μετά τη διαδρομή τους.
Τώρα, πρέπει να γράψεις κώδικα που θα βοηθήσει στις λειτουργίες της υπηρεσίας.

## 1. Απλός μιγαδικός αριθμός

Ο διευθύνων σύμβουλός σου αποφάσισε ότι, εφόσον το Μανχάταν έχει διάταξη δρόμων που μοιάζει κυρίως με πλέγμα, οι μιγαδικοί αριθμοί είναι ένας βολικός τρόπος για να αναπαραστήσεις τις διασταυρώσεις των δρόμων.
Έτσι, οι θετικοί και οι αρνητικοί πραγματικοί αριθμοί αναπαριστούν την ανατολή και τη δύση, και οι θετικοί και οι αρνητικοί φανταστικοί αριθμοί τον βορρά και τον νότο, αντίστοιχα.

Καθώς η δημιουργία ενός μιγαδικού αριθμού στη γλώσσα R είναι λίγο, ε... ιδιαίτερη, σου ζητήθηκε να υλοποιήσεις μια απλή συνάρτηση μιγαδικών αριθμών.

Υλοποίησε τη συνάρτηση `simplex(a, b)`, η οποία δέχεται τους ακέραιους `a` και `b`.
Επίστρεψε τον μιγαδικό αριθμό `a+bi`.

```r
simplex(1, 1)
#> 1+1i

simplex(-3, 4)
#> -3+4i
```

## 2. Πάρε τις κατευθύνσεις για τον οδηγό

Όταν ένας πελάτης δίνει τη διασταύρωση προορισμού, οι οδηγοί σου θα παίρνουν κατευθύνσεις για το πώς να φτάσουν εκεί.
Αυτές οι κατευθύνσεις έχουν τη μορφή μιγαδικού αριθμού, όπου το πραγματικό μέρος αναπαριστά πόσα τετράγωνα προς βορρά/νότο πρέπει να πάνε και το φανταστικό μέρος την απόσταση ανατολή/δύση.
Για να συμβαδίζει με μια καθιερωμένη πυξίδα, ο υπεύθυνος έργου σου αποφάσισε ότι ο βορράς θα είναι στη θετική φανταστική κατεύθυνση και ο νότος στην αρνητική φανταστική κατεύθυνση.
Ομοίως, η ανατολή είναι στη θετική πραγματική κατεύθυνση και η δύση στην αρνητική πραγματική κατεύθυνση.

Υλοποίησε τη συνάρτηση `driver_directions(start, end)`, η οποία δέχεται τις συντεταγμένες της διασταύρωσης αφετηρίας `start` και τις συντεταγμένες του προορισμού `end`.
Επίστρεψε έναν μιγαδικό αριθμό που αναπαριστά πόσα τετράγωνα προς ανατολή/δύση + βορρά/νότο πρέπει να διανύσει ο οδηγός.

```r
driver_directions(0+0i, 7+5i)
#> 7+5i

driver_directions(-2+3i, 4-5i)
#> 6-8i
```

## 3. Πάρε την απόσταση Μανχάταν

Ο πελάτης χρεώνεται ένα ποσό για την απόσταση που πρέπει να καλύψει το ταξί.
Καθώς το Μανχάταν έχει διάταξη δρόμων που μοιάζει με πλέγμα, τα ταξί μπορούν να κινηθούν μόνο κατά μήκος αυτών των διαδρομών.
Αυτή η δομή οδηγεί σε ένα μέτρο απόστασης που είναι αναγκασμένο να ακολουθεί τις γραμμές του πλέγματος.
Η απόσταση μπορεί να βρεθεί αθροίζοντας είτε τον αριθμό των γραμμών που διανύθηκαν είτε τον αριθμό των διασταυρώσεων στις οποίες έφτασες (δηλαδή χωρίς να υπολογίζεται η διασταύρωση αφετηρίας).
Αυτό το μέτρο ονομάζεται συνήθως απόσταση Μανχάταν ή νόρμα L1.

Υλοποίησε τη συνάρτηση `manhattan(start, end)`, η οποία δέχεται τις διασταυρώσεις `start` και `end`.
Επίστρεψε την απόσταση Μανχάταν μεταξύ των διασταυρώσεων `start` και `end`.

```r
manhattan(0+0i, 3+4i)
#> 7

manhattan(-2-3i, -1+1i)
#> 5
```

## 4. Πάρε την απόσταση "σε ευθεία γραμμή"

Ο διευθύνων σύμβουλος κατάφερε να πείσει τις επενδυτικές τράπεζες να συμμετάσχουν, υπογραμμίζοντας ότι η υπηρεσία δεν είναι μόνο εξαιρετικά πολυτελής αλλά και οικολογική, επειδή θα χρησιμοποιεί εκπαιδευμένα κοράκια για να μεταφέρουν μηνύματα ανάμεσα στους συνοδούς στις διασταυρώσεις (οι οποίοι μεταβιβάζουν πληροφορίες για τους επιβάτες, για μια εξατομικευμένη εμπειρία).
Φαίνεται ότι κανένας από τους τραπεζίτες δεν μπήκε στον κόπο να κάνει τη δέουσα έρευνα για το γιατί ακριβώς αυτό είναι φιλικό προς το περιβάλλον, ή ακόμη και για το τι είδους διευθύνων σύμβουλος απολαμβάνει να εκπαιδεύει κοράκια στον ελεύθερό του χρόνο, επειδή τα χρήματα των επενδύσεων έρχονταν βροχή.

Αυτή η υπηρεσία χρεώνεται επίσης με βάση την απόσταση που διανύεται.
Ωστόσο, επειδή τα κοράκια μπορούν να πετάξουν, δεν χρειάζεται να ακολουθήσουν το δίκτυο δρόμων σε πλέγμα και μπορούν να πάρουν τον συντομότερο δρόμο.
Φυσικά, αυτό μπορεί να μην ισχύει όταν υπάρχουν τεράστιοι ουρανοξύστες, αλλά ο διευθύνων σύμβουλος βάζει αυτή την υπηρεσία στο Μανχάταν του Κάνσας (γνωστό και ως "The Little Apple"), όπου τα κοράκια μπορούν εύκολα να πετάξουν πάνω από τα χαμηλά κτίρια.
Η πιθανή ζήτηση για μια τέτοια υπηρεσία στο Μανχάταν του Κάνσας, και το πώς θα νιώσουν οι ντόπιοι πεζοί με όλα αυτά τα πουλιά να πετούν από πάνω, είναι θέματα για άλλη μέρα.

Υλοποίησε τη συνάρτηση `as_crow_flies(start, end)`, η οποία δέχεται τις διασταυρώσεις `start` και `end`.
Επίστρεψε την απόσταση σε ευθεία γραμμή μεταξύ των δύο.

```r
as_crow_flies(0+0i, 3+4i)
#> 5
```

## 5. Πάρε τις κατευθύνσεις για τα κοράκια

Ο διευθύνων σύμβουλός σου έχει εκπαιδεύσει τα κοράκια να ακολουθούν κατευθύνσεις παρόμοιου τύπου με αυτές των οδηγών.
Ωστόσο, ο διευθύνων σύμβουλος αγαπά το Νότιο Ημισφαίριο και εκπαίδευσε τα κοράκια χρησιμοποιώντας διαφορετική πυξίδα από αυτήν που χρησιμοποιεί ο υπεύθυνος έργου σου για το υπόλοιπο σύστημα.
Ο διευθύνων σύμβουλός σου αποδεικνύεται αρκετά εκκεντρικός άνθρωπος.
Η πυξίδα του διευθύνοντος συμβούλου έχει τον βορρά στην αρνητική φανταστική κατεύθυνση και τον νότο στη θετική φανταστική κατεύθυνση.
Αυτό είναι το αντίθετο από τις κατευθύνσεις βορρά/νότου των οδηγών, ενώ η ανατολή/δύση παραμένουν ίδιες.

Υλοποίησε τη συνάρτηση `crows_directions(start, end)`, η οποία δέχεται τις διασταυρώσεις `start` και `end`.
Επίστρεψε τον μιγαδικό αριθμό που αντιστοιχεί στις κατευθύνσεις του οδηγού, αλλά με τον βορρά/νότο ανεστραμμένο.

```r
driver_directions(0+0i, 7+5i)
#> 7-5i

driver_directions(-2+3i, 4-5i)
#> 6+8i
```
