# Εισαγωγή

Στη Cairo, η υπερφόρτωση τελεστών σου επιτρέπει να ορίσεις προσαρμοσμένη συμπεριφορά για τυπικούς τελεστές όπως `+`, `-`, `==`, `<` κ.λπ., όταν δουλεύεις με δικούς σου τύπους.

Αυτό γίνεται υλοποιώντας συγκεκριμένα traits για τους προσαρμοσμένους τύπους σου.

## Βασικά traits για τελεστές

### `Add` και `Sub`

Τα traits `Add` και `Sub` σου επιτρέπουν να ορίσεις πώς λειτουργούν η πρόσθεση (`+`) και η αφαίρεση (`-`) με τον τύπο σου:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

Το trait `PartialEq` επιτρέπει τη σύγκριση ισότητας (`==` και `!=`) μεταξύ στιγμιοτύπων του τύπου σου.

Αυτό μπορεί συχνά να παραχθεί αυτόματα χρησιμοποιώντας το `#[derive(PartialEq)]`.

### `PartialOrd`

Το trait `PartialOrd` επιτρέπει πράξεις σύγκρισης (`<`, `>`, `<=`, `>=`) μεταξύ στιγμιοτύπων του τύπου σου.

Απαιτεί να υλοποιήσεις τουλάχιστον τη μέθοδο `lt` (μικρότερο από):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
