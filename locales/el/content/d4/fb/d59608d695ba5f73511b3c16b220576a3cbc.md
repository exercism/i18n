# Εισαγωγή

Το πακέτο `java.time`, που εισήχθη στην Java 8, περιέχει αρκετές κλάσεις για να δουλεύεις με ημερομηνίες και ώρα.

## `LocalDate`

Η κλάση `java.time.LocalDate` αντιπροσωπεύει μια ημερομηνία χωρίς ζώνη ώρας στο [ημερολογιακό σύστημα ISO-8601][iso-8601], όπως `2007-12-03`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

Μπορείς να συγκρίνεις ημερομηνίες με άλλες ημερομηνίες:

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

Ένα στιγμιότυπο `LocalDate` διαθέτει μεθόδους getter για να ανακτήσεις από αυτό επιμέρους στοιχεία της ημερομηνίας:

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

Ένα στιγμιότυπο `LocalDate` διαθέτει μεθόδους για να προσθέσεις χρονικές μονάδες σε αυτό:

```exercism/note
Αυτές οι μέθοδοι επιστρέφουν ένα _νέο_ στιγμιότυπο `LocalDate` και δεν ενημερώνουν το υπάρχον στιγμιότυπο, καθώς η κλάση `LocalDate` είναι αμετάβλητη.
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

## `LocalDateTime`

Η κλάση `java.time.LocalDateTime` αντιπροσωπεύει μια ημερομηνία και ώρα χωρίς ζώνη ώρας στο [ημερολογιακό σύστημα ISO-8601][iso-8601], όπως `2007-12-03T10:15:30`:

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

Μπορείς να μετατρέψεις ένα στιγμιότυπο `LocalDate` σε `LocalDateTime`:

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

## Μορφοποίηση ημερομηνιών και ωρών

Τόσο το `LocalDate` όσο και το `LocalDateTime` χρησιμοποιούν την τυπική σημειογραφία [ISO-8601][iso-8601] κατά τη μετατροπή από και προς ένα `String`.

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

Δεν είναι δυνατό να μετατρέψεις ένα `LocalDate` ή ένα `LocalDateTime` από ένα `String` σαν αυτό χρησιμοποιώντας διαφορετική μορφή.
Αντίθετα, για να μορφοποιήσεις ημερομηνίες χρησιμοποιώντας μια προσαρμοσμένη μορφή, θα πρέπει να χρησιμοποιήσεις το `java.time.format.DateTimeFormatter`:

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

Μπορείς επίσης να ορίσεις ένα locale όταν δημιουργείς την προσαρμοσμένη μορφή, ώστε να μορφοποιείς και να μετατρέπεις για διαφορετικές περιοχές:

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
