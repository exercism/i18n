# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Σκοπός                     |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | είσοδος   | ακέραιος | δεδομένη τιμή              |
| `$v0`    | έξοδος    | ακέραιος | διαφορά τετραγώνων         |
| `$t0-9`  | προσωρινός | οποιοσδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
