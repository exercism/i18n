# Περιγραφή

Σε αυτή την άσκηση, θα φτιάξεις ένα βοηθητικό πρόγραμμα, ώστε να μη χρειάζεται να θυμάσαι τις τιμές των ζωνών.
Το πρόγραμμα θα δέχεται 1, 4 ή 5 χρώματα ως είσοδο και θα βγάζει τη σωστή τιμή σε ohms.
Οι χρωματικές ζώνες κωδικοποιούνται ως εξής:

| Χρώμα       | Τιμή |
|-------------|-------|
| Black       | 0     |
| Brown       | 1     |
| Red         | 2     |
| Orange      | 3     |
| Yellow      | 4     |
| Green       | 5     |
| Blue        | 6     |
| Violet      | 7     |
| Gray        | 8     |
| White       | 9     |
|-------------|-------|

Στο [`Resistor Color Trio`][resistor-color-trio-exercise] αποκωδικοποίησες τις τρεις πρώτες χρωματικές ζώνες.
Για παράδειγμα: το orange-orange-brown μεταφράζεται στην κύρια τιμή `330`.
Σε αυτή την άσκηση θα χρειαστεί να προσθέσεις και την _ανοχή_.
Η ανοχή είναι το μέγιστο ποσό κατά το οποίο μια τιμή μπορεί να είναι πάνω ή κάτω από την κύρια τιμή.
Για παράδειγμα, αν η τελευταία ζώνη έχει χρώμα green, η μέγιστη ανοχή θα είναι `±0.5%`.

Η ζώνη ανοχής θα έχει μία από αυτές τις τιμές:

| Χρώμα  | Ανοχή |
|--------|----------:|
| Grey   | ±0.05%    |
| Violet | ±0.10%    |
| Blue   | ±0.25%    |
| Green  | ±0.50%    |
| Brown  | ±1.00%    |
| Red    | ±2.00%    |
| Gold   | ±5.00%    |
| Silver | ±10.00%   |
|--------|-----------|

Η αντίσταση τεσσάρων ζωνών χτίζεται ως εξής:

| Ζώνη_1  | Ζώνη_2  | Ζώνη_3     | Ζώνη_4    |
| ------- | ------- | ---------- | --------- |
| Τιμή_1  | Τιμή_2  | Πολλαπλασιαστής | Ανοχή |

Παραδείγματα:

- Το orange-orange-brown-green θα ήταν `330` ohms με ανοχή `±0.5%`.
- Το orange-orange-red-grey θα ήταν `3300` ohms με ανοχή `±0.05%`.

Η διαφορά ανάμεσα σε μια αντίσταση τεσσάρων και πέντε ζωνών είναι ότι η αντίσταση πέντε ζωνών έχει μια επιπλέον ζώνη που δηλώνει μια πιο ακριβή τιμή.

| Ζώνη_1  | Ζώνη_2  | Ζώνη_3  | Ζώνη_4     | Ζώνη_5    |
| ------- | ------- | ------- | ---------- | --------- |
| Τιμή_1  | Τιμή_2  | Τιμή_3  | Πολλαπλασιαστής | Ανοχή |

Παραδείγματα:

- Το orange-orange-orange-black-green θα ήταν `333` ohms με ανοχή `±0.5%`.
- Το orange-red-orange-blue-violet θα ήταν `323 million` ohms με ανοχή `±0.1%`.

Υπάρχουν επίσης αντιστάσεις με μία ζώνη.
Οι αντιστάσεις με μία ζώνη έχουν μόνο το χρώμα black με τιμή 0.

Το πρόγραμμα σου πρέπει να μετατρέπει μια `list` εισόδου με χρώματα ζωνών αντίστασης σε μια ετικέτα:

"... ohms ±...%"

Έτσι, μια `list` εισόδου `["orange", "orange", "black", "green"]` πρέπει να επιστρέφει:

"33 ohms ±0.5%"

Όταν έχουμε χιλιάδες ohms, λέμε "kiloohms".
Είναι σαν να λέμε "kilometer" για 1000 μέτρα και "kilograms" για 1000 γραμμάρια.

Έτσι, μια `list` εισόδου `["orange", "orange", "orange", "grey"]` πρέπει να επιστρέφει:

"33 kiloohms ±0.05%"

Όταν έχουμε εκατομμύρια ohms, λέμε "megaohms".

Έτσι, μια `list` εισόδου `["orange", "orange", "blue", "red"]` πρέπει να επιστρέφει:

"33 megaohms ±2%"
