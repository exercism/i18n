# Οδηγίες

Φτιάχνεις μια μικρή αριθμομηχανή Αντίστροφης Πολωνικής Σημειογραφίας (RPN).
Η κατάσταση της αριθμομηχανής είναι μια *στοίβα τιμών*, που
αναπαρίσταται ως πίνακας Factor, και μια *πράξη* είναι ένα quotation που
παίρνει μια τέτοια στοίβα και επιστρέφει μια νέα.

```factor
{ 3 4 }   ! the calculator's stack: 3 is below 4
[ ... ]   ! an operation that consumes some values and pushes a result
```

## 1. Υλοποίησε την πρόσθεση

Όρισε το `add-op` ώστε να βγάζει τις δύο πάνω τιμές από τη στοίβα, να
βάζει το άθροισμά τους στη στοίβα και να επιστρέφει τη νέα στοίβα.

```factor
{ 3 4 } add-op .
! => { 7 }

{ 1 2 3 4 } add-op .
! => { 1 2 7 }
```

## 2. Υλοποίησε τον πολλαπλασιασμό

Όρισε το `multiply-op` με τον ίδιο τρόπο, αλλά για πολλαπλασιασμό.

```factor
{ 3 4 } multiply-op .
! => { 12 }
```

## 3. Εφάρμοσε μία μόνο πράξη

Όρισε το `apply-op` ώστε να παίρνει από τη στοίβα δεδομένων μια στοίβα
και μια πράξη (ένα quotation) και να επιστρέφει τη νέα στοίβα της
αριθμομηχανής.

```factor
{ 3 4 } [ add-op ] apply-op .
! => { 7 }
```

## 4. Υπολόγισε ένα πρόγραμμα

Όρισε το `evaluate` ώστε να παίρνει μια αρχική στοίβα και έναν πίνακα
από πράξεις και να εφαρμόζει κάθε πράξη με τη σειρά, επιστρέφοντας την
τελική στοίβα.

```factor
{ 3 4 5 } { [ add-op ] [ multiply-op ] } evaluate .
! => { 27 }
```

## 5. Υπολόγισε με βάση το όνομα

Τώρα το πρόγραμμα είναι μια λίστα από *ονόματα τελεστών*
(συμβολοσειρές) και η αριθμομηχανή αναζητά κάθε όνομα σε ένα assoc που
αντιστοιχίζει ονόματα σε πράξεις.

Όρισε το `evaluate-named` ώστε να παίρνει μια αρχική στοίβα, ένα assoc
από ονομασμένες πράξεις και έναν πίνακα από ονόματα, και να επιστρέφει
την τελική στοίβα.

```factor
{ 3 4 5 } H{ { "+" [ add-op ] } { "*" [ multiply-op ] } } { "+" "*" }
evaluate-named .
! => { 27 }
```

## 6. Διαίρεση με ασφάλεια

Μια πραγματική αριθμομηχανή δεν πρέπει να παράγει σιωπηλά σκουπίδια
όταν της ζητείται να διαιρέσει με το μηδέν. Η κλάση σφάλματος
`zero-divisor-error` είναι ήδη ορισμένη για σένα. Υλοποίησε το
`divide-op` κατ' αναλογία με το `add-op` και το `multiply-op`, με τη
διαφορά ότι πετάει με `throw` ένα νέο `zero-divisor-error` όταν ο
διαιρέτης στην κορυφή της στοίβας είναι `0`.

```factor
{ 12 4 } divide-op .
! => { 3 }

{ 1 5 6 2 } divide-op .
! => { 1 5 3 }

{ 5 0 } divide-op
! throws zero-divisor-error
```
