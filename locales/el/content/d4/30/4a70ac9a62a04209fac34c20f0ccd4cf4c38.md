# Οδηγίες

Δουλεύεις σε ένα φημισμένο δικηγορικό γραφείο που ειδικεύεται σε μοναδικές υποθέσεις διαθηκών.

Σε αυτή την άσκηση, θα ανοίξεις ένα μυστηριώδες θησαυροφυλάκιο.
Είσαι ο εκτελεστής της κληρονομιάς και θα συνθέσεις τους επί μακρόν φυλαγμένους μυστικούς κωδικούς τριών οικογενειών για να βρεις έναν αριθμό λογαριασμού και τον αντίστοιχο κωδικό.

Για να μην μπορεί καμία οικογένεια να ανοίξει το θησαυροφυλάκιο μόνη της, αυτό μπορεί να ανοιχτεί μόνο αν συνδυάσεις τις γνώσεις τους με έναν μυστικό τροποποιητή που γνωρίζεις από την τελευταία διαθήκη.

Έχεις τρεις εργασίες, όλες σχετικές με το να βοηθήσεις τις οικογένειες να ανοίξουν το θησαυροφυλάκιο.

## 1. Πάρε τη θέση σου μπροστά στις οικογένειες και στρώσε τα χαρτιά σου

Όρισε έναν χώρο ονομάτων με το όνομα `estate_executor`.
Ο κώδικας των επόμενων εργασιών θα πρέπει να οριστεί μέσα στο σώμα του χώρου ονομάτων `estate_executor`.

```cpp
namespace some_name {
    // The space between the curly brackets
    // is called body of the  namespace.
}
```

## 2. Βρες τον μυστικό αριθμό λογαριασμού

Αυτή είναι η μεγάλη σου στιγμή.
Μόνο εσύ έχεις το μυστικό κλειδί τροποποιητή για να αποκαλύψεις τον μυστικό αριθμό λογαριασμού.

Όρισε τη συνάρτηση `assemble_account_number(int secret_modifier)` που παίρνει ως όρισμα τον μυστικό τροποποιητή και επιστρέφει τον συναρμολογημένο αριθμό λογαριασμού ως `int`.

Για να βρεις τον σωστό αριθμό, πρέπει να αθροίσεις το `bank_number_part` από καθεμιά από τις τρεις οικογένειες.

## 3. Τελευταίο βήμα: Εισάγε τον μυστικό κωδικό

Οι οδηγίες στη διαθήκη σου ζητούν να προσθέσεις πρώτα όλα τα μπλε και μετά όλα τα κόκκινα τμήματα.
Ο κωδικός που προκύπτει είναι το γινόμενο των δύο αθροισμάτων.

Όρισε τη συνάρτηση `assemble_code()` που επιστρέφει τον κωδικό που προκύπτει, συνδυάζοντας τα τμήματα από τις τρεις οικογένειες σε έναν μόνο `integer`.
Η συνάρτηση δεν παίρνει κανένα όρισμα και βασίζεται αποκλειστικά στις πληροφορίες που υπάρχουν στους σχετικούς χώρους ονομάτων των οικογενειών.
