# Σχετικά

Στη Common Lisp, οι καθολικές, επώνυμες συναρτήσεις ορίζονται με το `defun`.

Αυτή η μορφή δέχεται ως πρώτο όρισμα μια λίστα παραμέτρων για τη συνάρτηση που ορίζεται (η λίστα των παραμέτρων ονομάζεται και "λίστα λάμδα").
Στη συνέχεια, μπορεί προαιρετικά να δεχτεί μια συμβολοσειρά που χρησιμοποιείται ως τεκμηρίωση για αυτή τη συνάρτηση.
Τέλος, υπάρχουν μηδέν ή περισσότερες εκφράσεις που αποτελούν το σώμα της συνάρτησης.

Καλείς μια συνάρτηση χρησιμοποιώντας το όνομα της συνάρτησης ως πρώτο στοιχείο μιας έκφρασης, ακολουθούμενο από τα ορίσματα που θέλεις να περάσεις σε αυτή.

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

Οι συναρτήσεις μπορούν επίσης να δέχονται [προαιρετικές παραμέτρους][concept-optional-parameters], [παραμέτρους λέξεων-κλειδιών][concept-keyword-parameters], [παραμέτρους rest][concept-rest-parameters].
Αυτές θα τις συζητήσουμε σε επόμενες έννοιες.

Το όνομα της συνάρτησης βρίσκεται στο πεδίο εμβέλειας μέσα στο σώμα της συνάρτησης, ώστε να μπορεί να γίνει αναδρομή.

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
