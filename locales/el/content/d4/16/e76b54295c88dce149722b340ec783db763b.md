# Υποδείξεις

## Γενικά

- Δες ξανά τα μοτίβα κανονικών εκφράσεων από την εισαγωγή. Θυμήσου ότι, όταν δημιουργείς το μοτίβο από μια συμβολοσειρά, πρέπει να κάνεις escape σε ορισμένους χαρακτήρες.
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular-Expressions.info][website-regex-info].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Rex Egg - The world's most tyrannosauical regex tutorial][website-rexegg].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegexOne - Μάθε κανονικές εκφράσεις με απλές, διαδραστικές ασκήσεις][website-regexone].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [Regular Expressions 101 - ένα διαδικτυακό sandbox για regex][website-regex-101].
- Ρίξε μια ματιά σε αυτή την ιστοσελίδα για κανονικές εκφράσεις: [RegExr - ένα διαδικτυακό sandbox για regex][website-regexr].

## 1. Εντόπισε τις παραμορφωμένες γραμμές log

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `regexp.from_string`][from-string] για να μεταγλωττίσεις μια κανονική έκφραση.
- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `regexp.check`][check] για να ελέγξεις αν μια κανονική έκφραση ταιριάζει με μια συμβολοσειρά.
- Μην ξεχνάς να κάνεις escape σε χαρακτήρες που έχουν ειδική σημασία στις κανονικές εκφράσεις.

## 2. Χώρισε τη γραμμή log

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `regexp.split`][split] για να χωρίσεις μια συμβολοσειρά χρησιμοποιώντας μια κανονική έκφραση.
- Μην ξεχνάς να κάνεις escape σε χαρακτήρες που έχουν ειδική σημασία στις κανονικές εκφράσεις.

## 3. Σημείωσε τις γραμμές με ονόματα χρηστών

- Μπορείς να χρησιμοποιήσεις τη [συνάρτηση `regexp.scan`][scan] για να συλλάβεις τμήματα μιας συμβολοσειράς χρησιμοποιώντας μια κανονική έκφραση.
- Μην ξεχνάς να κάνεις escape σε χαρακτήρες που έχουν ειδική σημασία στις κανονικές εκφράσεις.
