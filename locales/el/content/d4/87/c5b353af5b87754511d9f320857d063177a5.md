# Υποδείξεις

## 1. Προσδιόρισε πόσο χρόνο χρειάζεται για να αναμείξεις έναν χυμό

- Η Julia δεν έχει την εντολή `switch`, σε αντίθεση με πολλές άλλες γλώσσες.
- Η σύνταξη `if` ... `elsefif` ... `else` καλύφθηκε στην έννοια Conditionals.

## 2. Αναπλήρωσε το απόθεμα από φέτες λάιμ

- Ένας `while` βρόχος μπορεί να τρέχει μέχρι να έχεις αρκετές φέτες λάιμ.
- Η συνάρτηση `popfirst!()` καλύφθηκε στην έννοια Vectors.

## 3. Κατέγραψε τους χρόνους ανάμειξης κάθε παραγγελίας στην ουρά

- Η επανάληψη πάνω σε έναν πίνακα είναι εύκολη με `for` ... `in`.
- Για να φτιάξεις έναν νέο πίνακα, μπορείς να χρησιμοποιήσεις την `push!()`, η οποία καλύφθηκε στην έννοια Vectors.
- Αργότερα στο πρόγραμμα σπουδών θα εξερευνήσουμε διάφορους άλλους τρόπους για να το κάνουμε αυτό στη Julia.
