# Προσθήκη στις οδηγίες

## Υλοποίηση

Οι συναρτήσεις σε αυτή την άσκηση δέχονται έναν πίνακα που περιέχει έναν ή περισσότερους αριθμούς, καθένας από τους οποίους αντιπροσωπεύει ένα "σκορ παιχνιδιού".

Τα σκορ του παίκτη μπορούν να διαβαστούν από

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

Η `personal_top_three()` θα πρέπει να γράφει τα κορυφαία σκορ του παίκτη στο

| `output`   |
|---|
| `output[0]` |
| ... |
