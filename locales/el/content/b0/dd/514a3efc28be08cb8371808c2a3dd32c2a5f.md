# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις λίγο κώδικα που θα σε βοηθήσει να προετοιμαστείς για να αγοράσεις ένα όχημα.

Έχεις τρεις εργασίες: μία για να προσδιορίσεις αν θα χρειαστείς άδεια οδήγησης, μία που θα σε βοηθήσει να διαλέξεις ανάμεσα σε δύο οχήματα και μία για να εκτιμήσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

Ορισμένα είδη οχημάτων χρειάζονται άδεια οδήγησης για να τα οδηγήσεις.
Θεώρησε ότι μόνο τα είδη `'car'` και `'truck'` χρειάζονται άδεια, ενώ όλα τα άλλα μπορείς να τα οδηγήσεις χωρίς άδεια.

Υλοποίησε τη συνάρτηση `needsLicense(kind)` που παίρνει το είδος του οχήματος και επιστρέφει Boolean (λογική τιμή) που δηλώνει αν χρειάζεσαι άδεια για αυτό το είδος οχήματος.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Διάλεξε ανάμεσα σε δύο πιθανά οχήματα για αγορά

Αξιολογείς τις επιλογές σου από τα διαθέσιμα οχήματα.
Καταφέρνεις να τις περιορίσεις σε δύο επιλογές, αλλά χρειάζεσαι βοήθεια για να πάρεις την τελική απόφαση.
Για αυτό, υλοποίησε τη συνάρτηση `chooseVehicle(option1, option2)` που παίρνει δύο οχήματα ως ορίσματα και επιστρέφει μια απόφαση που περιλαμβάνει την επιλογή που έρχεται πρώτη στη λεξικογραφική σειρά.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες την απόφασή σου, θέλεις να βεβαιωθείς ότι θα πάρεις μια δίκαιη τιμή στην αντιπροσωπεία.
Επειδή ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια χοντρική εκτίμηση, υπέθεσε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν ολοκαίνουργιο.
Αν είναι πάνω από 10 ετών, κοστίζει 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά όχι πάνω από 10 ετών, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε τη συνάρτηση `calculateResellPrice(originalPrice, age)` που εφαρμόζει αυτή τη λογική χρησιμοποιώντας `if`, `else if` και `else` (υπάρχουν και άλλοι τρόποι αν θέλεις να εξασκηθείς).
Παίρνει την αρχική τιμή και την ηλικία του οχήματος ως ορίσματα και επιστρέφει την εκτιμώμενη τιμή στην αντιπροσωπεία.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
