# Οδηγίες

Υλοποίησε μια συνάρτηση χρησιμοποιώντας προτασιακή λογική για να αναδημιουργήσεις τις παρακάτω ιδιότητες:

1. A & B == (A' | B')' (νόμος του DeMorgan)
2. [A -> (A -> B)] -> (A -> B)
3. A & (B' -> A') -> B

Η συνάρτηση πρέπει να επιστρέφει τα τρία θεωρήματα γραμμένα σε συμβολισμό Z3.  
Χρησιμοποίησε τη συνάρτηση prove() για να επιβεβαιώσεις την ορθότητα των θεωρημάτων σου.  
Επίστρεψε τα τρία θεωρήματα, με τη σειρά, στο τέλος της συνάρτησης.
