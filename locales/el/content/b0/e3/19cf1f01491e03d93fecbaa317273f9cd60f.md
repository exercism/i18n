# Υποδείξεις

## Γενικά

- [Παρεμβολή συμβολοσειρών][string-interpolation]: οδηγός για το πώς να χρησιμοποιείς την παρεμβολή συμβολοσειρών.
- [Τύποι μορφοποίησης][formatting-types]: οι διαθέσιμοι τύποι μορφοποίησης που μπορείς να χρησιμοποιήσεις.
- [Τυπικές συμβολοσειρές μορφοποίησης αριθμών][standard-numeric-format-strings]: απαριθμεί τις τυπικές συμβολοσειρές μορφοποίησης αριθμών.
- [Προσαρμοσμένες συμβολοσειρές μορφοποίησης αριθμών][custom-numeric-format-strings]: περιγράφει πώς να ορίζεις προσαρμοσμένες συμβολοσειρές μορφοποίησης αριθμών.
- [Τυπικές συμβολοσειρές μορφοποίησης ημερομηνίας και ώρας][standard-date-and-time-format-strings]: απαριθμεί τις τυπικές συμβολοσειρές μορφοποίησης ημερομηνίας και ώρας.
- [Προσαρμοσμένες συμβολοσειρές μορφοποίησης ημερομηνίας και ώρας][custom-date-and-time-format-strings]: περιγράφει πώς να ορίζεις προσαρμοσμένες συμβολοσειρές μορφοποίησης ημερομηνίας και ώρας.
- [`String.Format()`][string-format]: API της βιβλιοθήκης.

## 1. Εμφάνισε το όνομα του ζευγαριού χωρισμένο από μια καρδιά

- Ρίξε μια ματιά στη συζήτηση για την [παρεμβολή συμβολοσειρών][string-interpolation].

## 2. Εμφάνισε τα αρχικά του ζευγαριού σε μια καρδιά από ascii art

- Αυτό το [άρθρο][verbatim-strings] εξηγεί τις κυριολεκτικές συμβολοσειρές.
- Αυτό το [έγγραφο][string-format] εξηγεί τη `String.Format()`.

## 3. Οι Γερμανοί μαθητές ανταλλαγής πρέπει να νιώσουν σαν στο σπίτι τους με δηλώσεις που σέβονται την τοπική ρύθμιση.

- Για να δουλέψεις με συμβολοσειρές με παρεμβολή, δες την τεκμηρίωση για το [`FormattableString`][formattable-string]. Για αρχή, ίσως είναι καλύτερα να χρησιμοποιήσεις [σύνθετη μορφοποίηση][composite-formatting].
- Θα χρειαστεί να δουλέψεις με το [`CultureInfo`][culture-info]. Σημείωσε ότι υλοποιεί τη διεπαφή [`IFormatProvider`][format-provider].
