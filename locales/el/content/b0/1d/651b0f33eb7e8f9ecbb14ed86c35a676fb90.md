# προτίμησε σταθερά σε ανώτατο επίπεδο

Σκέψου να εξαγάγεις τον αριθμό `GIGASECOND` σε μια σταθερά:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Μόνο οι συναρτήσεις, οι κλάσεις και οι σταθερές που είναι `export`ed είναι ορατές και προσβάσιμες από έξω. Συνήθως έχει νόημα να δίνεις ένα όνομα στους [μαγικούς αριθμούς](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), κάτι που βελτιώνει τη συντηρησιμότητα. Αυτές οι σταθερές μπορούν να μένουν στο ίδιο αρχείο χωρίς να εκτίθενται σε άλλον κώδικα.
