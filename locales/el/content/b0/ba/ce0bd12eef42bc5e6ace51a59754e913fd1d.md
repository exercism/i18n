# Όλοι οι συνδυασμοί υλοποιημένοι

Αν και αυτή η λύση περνάει τα τεστ, είναι στενά συνδεδεμένη με τις συγκεκριμένες περιπτώσεις.
Φαντάσου όλους τους νέους συνδυασμούς που θα έπρεπε να προστεθούν αν ζητηθούν μία ή περισσότερες επιπλέον περιπτώσεις.
Θα γινόταν γρήγορα δύσκολο στη συντήρηση.
Δοκίμασε να συνενώσεις τις συμβολοσειρές, για παράδειγμα χρησιμοποιώντας τον τελεστή `+=`.
