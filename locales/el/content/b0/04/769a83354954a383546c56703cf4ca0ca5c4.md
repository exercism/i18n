# Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις τη διαχείριση σφαλμάτων για μια απλή αριθμομηχανή.

Ο στόχος είναι να έχεις μια αριθμομηχανή που λειτουργεί και επιστρέφει μια συμβολοσειρά με το εξής μοτίβο: `16 + 51 = 67`, όταν της δίνεις τα ορίσματα `16`, `51` και `+`.

```ruby
SimpleCalculator.calculate(16, 51, "+")
# => "16 + 51 = 67"
SimpleCalculator.calculate(32, 6, "*")
# => "32 * 6 = 192"
SimpleCalculator.calculate(512, 4, "/")
# => "512 / 4 = 128"
```

## 1. Χειρίσου τον κώδικα που μπορεί να πετάει σφάλματα μέσα στη μέθοδο `calculate`

Η κύρια μέθοδος που θα υλοποιήσεις σε αυτή την εργασία θα είναι η μέθοδος κλάσης `SimpleCalculator.calculate()`.
Δέχεται τρία ορίσματα.
Τα δύο πρώτα ορίσματα είναι αριθμοί πάνω στους οποίους θα γίνει μια πράξη.
Το τρίτο όρισμα είναι τύπου συμβολοσειράς και για αυτή την άσκηση χρειάζεται να υλοποιήσεις τις εξής πράξεις:

- πρόσθεση χρησιμοποιώντας τη συμβολοσειρά `+`
- πολλαπλασιασμό χρησιμοποιώντας τη συμβολοσειρά `*`
- διαίρεση χρησιμοποιώντας τη συμβολοσειρά `/`

## 2. Χειρίσου τις μη έγκυρες πράξεις

Ενημέρωσε τη μέθοδο `SimpleCalculator.calculate()` ώστε να πετάει μια εξαίρεση `UnsupportedOperation` για άγνωστα σύμβολα πράξεων.

```ruby
SimpleCalculator.calculate(1, 2, '-')
# => Raises an UnsupportedOperation
```

~~~~exercism/note
Σε αυτή την άσκηση, αναμένεται να ορίσεις την εξαίρεση `UnsupportedOperation` για ένα συγκεκριμένο πεδίο εφαρμογής.
~~~~

## 3. Χειρίσου τα μη έγκυρα ορίσματα

Ενημέρωσε τη μέθοδο `SimpleCalculator.calculate()` ώστε να πετάει μια εξαίρεση `ArgumentError` για μη έγκυρους τύπους ορισμάτων.

```ruby
SimpleCalculator.calculate(1, '2', '*')
# => Raises an ArgumentError
```

## 4. Χειρίσου τις εξαιρέσεις DivideByZero

Ενημέρωσε τη μέθοδο `SimpleCalculator.calculate()` ώστε να χειρίζεται τις εξαιρέσεις `ZeroDivisionError`.
Ο κώδικας διαχείρισης θα πρέπει να επιστρέφει τη συμβολοσειρά με περιεχόμενο `Division by zero is not allowed.`.
Καμία άλλη εξαίρεση δεν θα πρέπει να χειρίζεται η μέθοδος `SimpleCalculator.calculate()`.

```ruby
SimpleCalculator.calculate(512, 0, "/")
# => returns "Division by zero is not allowed."
```
