# Εισαγωγή

Ένα πρότυπο είναι μια συμβολοσειρά ή ένα αρχείο που χρησιμοποιείται για να παράγει οποιουδήποτε είδους έξοδο συμβολοσειράς, ανάλογα με την είσοδο.

```haxe
var sample = "My name is ::name::";
var template = new haxe.Template(sample);
var myName = {name: "Joe"};
var output = template.execute(myName);

trace(output); // My name is Joe
```

Μεταξύ άλλων, μπορείς να χρησιμοποιήσεις και συνθήκες για να ελέγχεις μέσα στα πρότυπα:

```haxe
var sample = "::if isAwake:: I'm awake ::else:: Zzzzz ::end::";
var template = new haxe.Template(sample);
var awake = {isAwake: false};
var output = template.execute(awake);

trace(output); // Zzzzz
```
