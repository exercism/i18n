# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                                      |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | είσοδος      | διεύθυνση | συμβολοσειρά ερώτησης τερματιζόμενη με null |
| `$v0`    | έξοδος       | ακέραιος | αποτέλεσμα, 0 αν η ερώτηση δεν είναι έγκυρη |
| `$t0-9`  | προσωρινός   | οποιοσδήποτε | για προσωρινή αποθήκευση               |
