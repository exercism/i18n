# Σχετικά

Η Go περιέχει βασικούς αριθμητικούς τύπους που μπορούν να αναπαραστήσουν σύνολα είτε ακέραιων τιμών είτε τιμών κινητής υποδιαστολής.
Υπάρχουν διαφορετικοί τύποι ανάλογα με το μέγεθος της τιμής που χρειάζεσαι και την αρχιτεκτονική του υπολογιστή όπου εκτελείται η εφαρμογή (π.χ. 32-bit και 64-bit).

Αυτή η έννοια θα επικεντρωθεί σε δύο τύπους αριθμών:

- `int`: π.χ. `0`, `255`, `2147483647`.
   Ένας προσημασμένος ακέραιος που έχει μέγεθος τουλάχιστον 32 bit (εύρος τιμών: από -2147483648 έως 2147483647).
   Αυτό όμως εξαρτάται από την αρχιτεκτονική του συστήματος.
   Οι περισσότεροι σύγχρονοι υπολογιστές είναι 64 bit, οπότε το `int` θα έχει μέγεθος 64 bit (εύρος τιμών: από -9223372036854775808 έως 9223372036854775807).

- `float64`: π.χ. `0.0`, `3.14`.
   Περιέχει το σύνολο όλων των αριθμών κινητής υποδιαστολής 64 bit.

Για έναν πλήρη κατάλογο των διαθέσιμων αριθμητικών τύπων και περισσότερες λεπτομέρειες, δες τους παρακάτω πόρους:

- [Go builtin type declarations][go-builtins]
- [Digital Ocean - Understanding Data Types in Go][do-understanding-types]
- [Arden Labs - Understanding Type in Go][arden-understanding-types]

Η Go υποστηρίζει το τυπικό σύνολο αριθμητικών τελεστών `+`, `-`, `*`, `/` και `%` (υπόλοιπο, όχι modulo).

Στη Go, η εκχώρηση μιας τιμής μεταξύ διαφορετικών τύπων απαιτεί ρητή μετατροπή.
Για παράδειγμα, για να μετατρέψεις ένα `int` σε `float64`, θα έπρεπε να κάνεις το εξής:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
