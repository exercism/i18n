# Εύρη

Τα [εύρη][range] αντιπροσωπεύουν ένα διάστημα μεταξύ δύο τιμών.
Οι πιο συνηθισμένοι τύποι που υποστηρίζουν εύρη είναι οι `Int`, `String` και `Date`.
Μπορούν να χρησιμοποιηθούν για πολλά πράγματα, όπως για να δημιουργήσεις γρήγορα μια συλλογή, να κόψεις έναν πίνακα, να ελέγξεις αν μια τιμή βρίσκεται σε ένα εύρος ή για επανάληψη.
Δημιουργούνται με τον τελεστή εύρους `...` ή `..<` (συμπεριληπτικό και αποκλειστικό, αντίστοιχα).

```swift
1...5 // A range containing 1, 2, 3, 4, 5
1..<5 // A range containing 1, 2, 3, 4
```

Ο λόγος ύπαρξης δύο τελεστών εύρους είναι η δημιουργία ευρών που περιλαμβάνουν ή αποκλείουν την τελική τιμή, κάτι που μπορεί να φανεί χρήσιμο όταν, για παράδειγμα, δουλεύεις με θέσεις που ξεκινούν από το μηδέν.

~~~~exercism/note
Όταν δημιουργείς ένα εύρος στη Swift με τους τελεστές εύρους `...` ή `..<` και θέλεις να καλέσεις μια μέθοδο πάνω στο εύρος, πρέπει να βάλεις το εύρος μέσα σε παρενθέσεις.
Αυτό συμβαίνει γιατί αλλιώς η μέθοδος θα κληθεί στο 2ο όρισμα του τελεστή εύρους.

```swift
(1...5).contains(3) // Returns true
1...5.contains(3) // => Error: value of type 'Int' has no member 'contains'
```
~~~~

## Μετέτρεψε ένα εύρος σε πίνακα

Για να μετατρέψεις ένα εύρος σε πίνακα, μπορείς να χρησιμοποιήσεις τον αρχικοποιητή `Array`.
Αυτό μπορεί να είναι χρήσιμο όταν θέλεις να δημιουργήσεις μια συλλογή τιμών, χωρίς να χρειάζεται να τις γράψεις μία προς μία.

```swift
let range = 1...5
let array = Array(range)
// Returns [1, 2, 3, 4, 5]
```

## Κόψε έναν πίνακα

Τα εύρη μπορούν να χρησιμοποιηθούν για να κόψεις έναν πίνακα.

```swift
let array = [1, 2, 3, 4, 5]
// Returns [1, 2, 3, 4, 5]
let slice = array[1...3]
// Returns [2, 3, 4]
```

## Μέθοδοι ευρών

Τα εύρη έχουν ένα σύνολο μεθόδων που μπορούν να χρησιμοποιηθούν για να δουλέψεις μαζί τους.
Για παράδειγμα, αυτές οι μέθοδοι μπορούν να χρησιμοποιηθούν για να πάρεις το άθροισμα όλων των τιμών του εύρους ή να ελέγξεις αν το εύρος περιλαμβάνει μια τιμή.

| Μέθοδος               | Περιγραφή                                                               | Παράδειγμα                            |
| --------------------- | ----------------------------------------------------------------------- | ------------------------------------- |
| `count`               | Επιστρέφει το μέγεθος του εύρους                                        | `(1...5).count // returns 5`          |
| [`contains`][contains] | Επιστρέφει `true` αν το εύρος περιλαμβάνει τη δεδομένη τιμή, αλλιώς `false` | `(1...5).contains(3) // Returns true` |

## Εύρη χωρίς τέλος και χωρίς αρχή

Ένα εύρος μπορεί να είναι χωρίς τέλος και χωρίς αρχή.

Η χρήση ευρών χωρίς τέλος και χωρίς αρχή είναι χρήσιμη όταν θέλεις, για παράδειγμα, να κόψεις έναν πίνακα από την αρχή ή μέχρι το τέλος.

~~~~exercism/caution
Αν δεν χρησιμοποιηθεί πάνω σε μια συλλογή, το εύρος χωρίς τέλος μπορεί να προκαλέσει μια ατέρμονη ακολουθία, αν δεν χρησιμοποιηθεί με προσοχή.
~~~~

## Εύρη συμβολοσειρών

Οι συμβολοσειρές μπορούν να χρησιμοποιηθούν σε εύρη και σου επιτρέπουν να πάρεις ένα διάστημα συμβολοσειρών ανάμεσα σε δύο συμβολοσειρές.
Για παράδειγμα, αυτό μπορεί να σου φανεί βολικό όταν θέλεις να πάρεις το αλφάβητο.

```swift
"a"..."z" // A range containing ["a", "b", "c", ..., "z"]
```
