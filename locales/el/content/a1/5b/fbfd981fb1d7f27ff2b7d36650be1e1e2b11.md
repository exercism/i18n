# Τεστ

## Εκτέλεση των τεστ

Έχοντας ολοκληρώσει τα [βήματα εγκατάστασης][test-installation-steps], θα πρέπει να μπορείς να ξεκινήσεις από οποιονδήποτε κατάλογο άσκησης (π.χ., `~/exercism/gdscript/two-fer`) και να τρέξεις το script (που βρίσκεται ένα επίπεδο πιο πάνω, στο `../`) για να δοκιμάσεις την τοπική σου λύση σε αυτή την άσκηση:

```sh
../test-local-gdscript-solution.sh
```

## Επίλυση μιας άσκησης

Το να λύσεις μια άσκηση σημαίνει να κάνεις όλα τα τεστ της να περάσουν.

Για να ξεκινήσεις πιο εύκολα, κάθε άσκηση έρχεται με ένα αρχείο GDScript με το όνομα της άσκησης (π.χ., `exercism/gdscript/two-fer/two_fer.gd`).
Μπορείς να χρησιμοποιήσεις αυτό το αρχείο ως σημείο εκκίνησης για να φτιάξεις τη λύση σου.
Μπορείς να το αλλάξεις ελεύθερα όπως χρειάζεται, αλλά τα τεστ περιμένουν τα ονόματα των συναρτήσεων να είναι όπως δόθηκαν αρχικά.

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
