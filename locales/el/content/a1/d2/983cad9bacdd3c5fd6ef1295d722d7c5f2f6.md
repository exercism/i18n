# Εισαγωγή

## Ορισμός μεταβλητών

Ο ορισμός μιας μεταβλητής σημαίνει την ανάθεση μιας τιμής σε ένα όνομα. Στη Scala υπάρχουν δύο είδη μεταβλητών, τα val και τα var.

Το `val` είναι αμετάβλητο, οπότε η τιμή του δεν μπορεί να αλλάξει ξανά μετά την πρώτη ανάθεση:

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

Το `var`, αντίθετα, μπορεί να δεχτεί εκ νέου ανάθεση σε μια νέα τιμή του ίδιου τύπου:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Η Scala είναι μια στατικά τυποποιημένη γλώσσα, που σημαίνει ότι τα πάντα έχουν έναν τύπο στον χρόνο μεταγλώττισης. Μια μεταβλητή μπορεί να οριστεί είτε δηλώνοντας ρητά τον τύπο της, είτε αφήνοντας τον μεταγλωττιστή της Scala να συμπεράνει τον τύπο της με βάση την τιμή που της ανατίθεται (αυτό ονομάζεται εξαγωγή τύπου). Επομένως, οι παρακάτω δύο ορισμοί μεταβλητών είναι ισοδύναμοι:

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί να αλλάξει ποτέ.

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## Ορισμός μεθόδων μέσα σε κλάσεις

Η Scala είναι μια _αντικειμενοστρεφής γλώσσα_ και απαιτεί όλες οι μέθοδοι να ορίζονται μέσα σε μια _κλάση_. Η λέξη-κλειδί `class` χρησιμοποιείται για τον ορισμό μιας κλάσης.

```scala
class Calculator {
  // ...
}
```

Μέσα σε μια κλάση, οι μέθοδοι μπορούν να οριστούν ξεκινώντας με τη λέξη-κλειδί `def` ακολουθούμενη από ένα όνομα. Κάθε μέθοδος μπορεί να έχει μηδέν ή περισσότερες παραμέτρους, οι οποίες παρατίθενται χωρισμένες με κόμμα μέσα σε παρενθέσεις. Όλες οι παράμετροι πρέπει να έχουν ρητό τύπο, δεν υπάρχει εξαγωγή τύπου για τις παραμέτρους. Μετά τη λίστα των παραμέτρων, ο τύπος επιστροφής της μεθόδου ορίζεται χωρισμένος με μια ακόμη άνω και κάτω τελεία.

Ο ορισμός της μεθόδου ακολουθείται από το σύμβολο `=` για να ξεκινήσει το σώμα της μεθόδου. Στο παρακάτω παράδειγμα το σώμα της μεθόδου αποτελείται από δύο εντολές, οι οποίες περικλείονται σε άγκιστρα.

Η μέθοδος θα επιστρέψει την τιμή της τελευταίας έκφρασης, στην περίπτωση αυτή η μέθοδος `add` επιστρέφει την τιμή της μεταβλητής `sum`:

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

Υπάρχουν μερικές βελτιώσεις που μπορούν να γίνουν για να συντομεύσουν αυτή τη μέθοδο και να βελτιώσουν την αναγνωσιμότητα:

- εφόσον η μεταβλητή `sum` χρησιμοποιείται μόνο μία φορά για την επιστροφή της τιμής, μπορεί να παραλειφθεί
- οι μέθοδοι που αποτελούνται από μία μόνο εντολή δε χρειάζονται άγκιστρα
- ο τύπος επιστροφής της μεθόδου μπορεί να εξαχθεί, όπως ακριβώς και για τους τύπους των μεταβλητών

Αυτό οδηγεί στην παρακάτω μονογραμμική μέθοδο με την ίδια λειτουργικότητα:

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## Δημιουργία στιγμιοτύπων κλάσεων και κλήση μεθόδων

Η κλήση μιας μεθόδου γίνεται δημιουργώντας πρώτα ένα στιγμιότυπο μιας κλάσης και έπειτα καλώντας τη μέθοδο πάνω σε αυτό το στιγμιότυπο με ορίσματα:

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Σχόλια

Η Scala υποστηρίζει δύο είδη σχολίων, σχόλια μίας γραμμής και σχόλια πολλών γραμμών:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
