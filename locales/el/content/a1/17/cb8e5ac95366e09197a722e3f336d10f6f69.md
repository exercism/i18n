# Οδηγίες

Θα βοηθήσεις δύο ερωτευμένους από το λύκειο να δηλώσουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας μια καρδιά unicode με τα αρχικά τους:

```
❤ J.  +  M. ❤
```

## 1. Καθάρισε το όνομα

Όρισε τη `cleanupname`, που παίρνει ένα όνομα από τη στοίβα. Αντικατέστησε κάθε `-` με ένα κενό, και μετά αφαίρεσε τα κενά διαστήματα στην αρχή και στο τέλος.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Πάρε το πρώτο γράμμα του ονόματος

Όρισε τη `firstletter`, που παίρνει ένα όνομα. Χρησιμοποίησε ξανά τη `cleanupname` από την προηγούμενη εργασία, μετά πάρε τον πρώτο χαρακτήρα του αποτελέσματος και επέστρεψέ τον ως συμβολοσειρά ενός χαρακτήρα.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Όρισε τη `initial`, που παίρνει ένα όνομα. Χρησιμοποίησε ξανά τη `firstletter` από την προηγούμενη εργασία, μετέτρεψέ τη σε κεφαλαίο και μετά πρόσθεσε μια `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Βάλε τα αρχικά μέσα στην καρδιά

Όρισε τη `couple`, που παίρνει δύο ονόματα από τη στοίβα. Χρησιμοποίησε ξανά τη `initial` από την προηγούμενη εργασία σε κάθε όνομα και μετά σύνθεσε το αποτέλεσμα:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
