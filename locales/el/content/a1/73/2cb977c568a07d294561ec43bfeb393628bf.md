# Τεστ

## Εκτέλεση τεστ

Εκτέλεσε την προδιαγραφή των τεστ με:

```bash
$ gradle test
```

## Ενεργοποίηση περισσότερων τεστ

Μόλις ο κώδικας σου περάσει όλα τα ενεργά τεστ, ενεργοποίησε ένα ακόμη τεστ αφαιρώντας το `@Ignore` που προηγείται του επόμενου τεστ που σε ενδιαφέρει. Κάν' το είτε διαγράφοντας τη γραμμή `@Ignore` είτε μετατρέποντάς την σε σχόλιο, προσθέτοντας δύο κάθετες στην αρχή της γραμμής.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
