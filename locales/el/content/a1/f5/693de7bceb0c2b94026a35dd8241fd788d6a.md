# Οδηγίες

Διαχειρίζεσαι ένα σύστημα που αποτελείται από μερικές εφαρμογές οι οποίες παράγουν πολλά logs. Θέλεις να γράψεις ένα μικρό πρόγραμμα που θα συγκεντρώνει αυτά τα logs και θα τους δίνει ετικέτες ανάλογα με το επίπεδο σοβαρότητάς τους. Όλες οι εφαρμογές στο σύστημά σου χρησιμοποιούν τους ίδιους κωδικούς log, αλλά μερικές από τις παλιές εφαρμογές δεν υποστηρίζουν όλους τους κωδικούς.

| Κωδικός log           | Ετικέτα log | Υποστηρίζεται σε παλιές εφαρμογές; |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | όχι                       |
| 1                     | debug     | ναι                       |
| 2                     | info      | ναι                       |
| 3                     | warning   | ναι                       |
| 4                     | error     | ναι                       |
| 5                     | fatal     | όχι                       |
| άλλο / μη υποστηριζόμενο | unknown   | -                         |

## 1. Προσδιόρισε την ετικέτα του log

Υλοποίησε τη συνάρτηση `LogLevel.to_label/2`. Θα πρέπει να δέχεται έναν ακέραιο κωδικό και μια Boolean (λογική τιμή) που σου λέει αν το log προέρχεται από παλιά εφαρμογή, και να επιστρέφει την ετικέτα μιας γραμμής log ως atom.

Οι κωδικοί log που δεν αναφέρονται στον πίνακα θα πρέπει να επιστρέφουν ετικέτα _unknown_. Οι κωδικοί log που στον πίνακα εμφανίζονται ως μη υποστηριζόμενοι σε παλιές εφαρμογές θα πρέπει επίσης να επιστρέφουν ετικέτα _unknown_ αν το log προέρχεται από παλιά εφαρμογή.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Στείλε μια ειδοποίηση

Κάποιος πρέπει να ειδοποιείται όταν συμβαίνουν απρόσμενα πράγματα.

Υλοποίησε τη συνάρτηση `LogLevel.alert_recipient/2` για να προσδιορίσεις σε ποιον πρέπει να σταλεί η ειδοποίηση. Η συνάρτηση θα πρέπει να δέχεται έναν ακέραιο κωδικό και μια Boolean τιμή που σου λέει αν το log προέρχεται από παλιά εφαρμογή, και να επιστρέφει το όνομα του παραλήπτη ως atom.

Χρησιμοποίησε τη συνάρτηση `LogLevel.to_label/2` από την προηγούμενη εργασία. Αν η ετικέτα του log είναι _error_ ή _fatal_, στείλε την ειδοποίηση στην ομάδα _ops_. Αν λάβεις ένα log με ετικέτα _unknown_ από παλιό σύστημα, στείλε την ειδοποίηση στην ομάδα _dev1_, ενώ οι άλλες ετικέτες _unknown_ θα πρέπει να στέλνονται στην ομάδα _dev2_. Όλες οι υπόλοιπες ετικέτες log μπορούν να αγνοηθούν με ασφάλεια επιστρέφοντας _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
