# Σχετικά

Η εντολή `guard` στη Swift χρησιμοποιείται για πρώιμες εξόδους από συναρτήσεις, βρόχους ή μεθόδους, όταν δεν πληρούται μια απαραίτητη συνθήκη:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Στο παραπάνω παράδειγμα, το `guard` αξιολογεί την έκφραση Boolean που ακολουθεί.
Αν η συνθήκη είναι `true`, η εκτέλεση συνεχίζεται με τον κώδικα που ακολουθεί την εντολή `guard`.
Αν η συνθήκη είναι `false`, εκτελείται ο κώδικας μέσα στο μπλοκ `else`.

Σε αντίθεση με μια εντολή `if`:

- Μια εντολή `guard` **πρέπει** να περιλαμβάνει ρήτρα `else`.
- Η ρήτρα `else` **πρέπει** να μεταφέρει τον έλεγχο έξω από το πεδίο εμβέλειας που την περιβάλλει (για παράδειγμα, χρησιμοποιώντας `return`, `continue`, `break` ή πετώντας ένα σφάλμα).

Το `guard` χρησιμοποιείται συχνά για τον καθαρό έλεγχο των προϋποθέσεων.
Για παράδειγμα, σκέψου τη συνάρτηση sinc ($\text{sinc}(x) = \frac{\sin(x)}{x}$, με $\text{sinc}(0) = 1$ για να αποφεύγεται η διαίρεση με το μηδέν):

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)             // returns 1
sinc(Double.pi / 2) // returns 0.6366197723675814
```
