# Εγκατάσταση του MoonScript

Πρώτα, ακολούθησε τις οδηγίες εγκατάστασης στο [track Lua][lua-install] για να εγκαταστήσεις τη Lua και το busted.

Έπειτα, εγκατέστησε το MoonScript με

```console
$ luarocks install --local moonscript
```

[lua-install]: https://exercism.org/docs/tracks/lua/installation
