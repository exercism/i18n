# Υποδείξεις

## 1. Κατηγοριοποίηση ενός αριθμού

* Οι συναρτήσεις `evenp` ή `oddp` μπορούν να χρησιμοποιηθούν για να προσδιορίσεις αν ένας αριθμός είναι άρτιος ή περιττός.
* Η συνάρτηση `append` μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα στοιχείο στην αρχή μιας λίστας.
* Οι συναρτήσεις `car` και `cdr` είναι χρήσιμες για να πάρεις το πρώτο ή το δεύτερο στοιχείο ενός ζεύγους.

## 2. Κατηγοριοποίηση πολλών αριθμών

* Η πρώτη παράμετρος της `reduce` είναι μια συνάρτηση που δέχεται δύο ορίσματα: την τρέχουσα συσσωρευμένη τιμή και το στοιχείο προς επεξεργασία.
* Η `reduce` δέχεται μια παράμετρο `:initial-value`, η τιμή της οποίας θα είναι η πρώτη συσσωρευμένη τιμή που περνάει στη συνάρτηση.
