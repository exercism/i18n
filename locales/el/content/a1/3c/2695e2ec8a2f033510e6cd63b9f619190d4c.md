# Προσάρτημα οδηγιών

## Παράδειγμα εισόδου

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

Αυτό σημαίνει ότι οι είσοδοί σου είναι:
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## Χειρισμός μη έγκυρων εισόδων

Αν κάποια από τις τιμές εισόδου είναι μη έγκυρη, το ρήμα σου θα πρέπει να επιστρέφει ένα `empty` (π.χ. `0$0` ή `''`).

### Παραδείγματα

- Αν η _βάση εισόδου_ είναι μικρότερη από 2:
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- Αν η _βάση εξόδου_ είναι μικρότερη από 2:
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- Αν τα _ψηφία_ περιέχουν τιμές μεγαλύτερες ή ίσες με τη βάση εισόδου:
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
