# Υποδείξεις

## Γενικά

Αυτή η άσκηση θα σε βάλει να γράψεις φίλτρα `jq` για τέσσερις εργασίες.
Επειδή ένα πρόγραμμα `jq` είναι μία _μόνο έκφραση_, αυτά τα τέσσερα φίλτρα πρέπει να ενωθούν με κόμματα.
Χρησιμοποίησε παρενθέσεις γύρω από τις υποεκφράσεις για να ελέγξεις τη σειρά των πράξεων.

## 1. Εξήγαγε το όνομα της λίστας αγορών

- Στο περιεχόμενο του αρχείου έχεις πρόσβαση με το φίλτρο `.`.
- Σε μια ιδιότητα αντικειμένου έχεις πρόσβαση με συμβολισμό τελείας ή με συμβολισμό αγκύλης.

## 2. Μέτρησε πόσα υλικά χρειάζονται

- Πρέπει να εξάγεις το μήκος ενός πίνακα.

## 3. Πόση ζάχαρη;

- Πρέπει να επιλέξεις το υλικό με όνομα "sugar".
- Πρέπει να έχεις πρόσβαση σε μία από τις ιδιότητές του.

## 4. Αντιστοίχισε τα υλικά που μπορούν να αντικατασταθούν

- Πρέπει να συνενώσεις δύο πίνακες.
- Πρέπει να επιλέξεις συγκεκριμένα στοιχεία από τον πίνακα που προκύπτει.
- Πρέπει να δημιουργήσεις ένα αντικείμενο κλειδί:τιμή για καθένα από αυτά τα στοιχεία.
- Πρέπει να συγχωνεύσεις αυτά τα αντικείμενα σε ένα μόνο αντικείμενο.
