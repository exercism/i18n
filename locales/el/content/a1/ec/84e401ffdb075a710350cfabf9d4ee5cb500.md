# Εισαγωγή

Η βασική βιβλιοθήκη της Gleam υλοποιεί έναν τύπο `Queue` στο module `gleam/queue`. Είναι παρόμοιος με τον τύπο `List`, αλλά έχει μερικές βασικές διαφορές:

- Ο τύπος `Queue` δεν έχει κάποια σύνταξη για κυριολεκτικές τιμές, την οποία να μπορείς να χρησιμοποιήσεις για να κατασκευάσεις ουρές ή για να κάνεις αντιστοίχιση μοτίβων πάνω τους.
- Στοιχεία μπορούν να προστεθούν και να αφαιρεθούν αποδοτικά τόσο από το μπροστινό όσο και από το πίσω μέρος του τύπου `Queue`, ενώ ο τύπος `List` μπορεί να προσθέτει και να αφαιρεί στοιχεία αποδοτικά μόνο από το μπροστινό μέρος.

Τις περισσότερες φορές θα θέλεις να χρησιμοποιείς τον τύπο `List`, αλλά όταν χρειάζεται να μπορείς να προσθέτεις και να αφαιρείς από το τέλος μιας συλλογής, ο τύπος `Queue` είναι καλή επιλογή.

Μπορείς να δημιουργήσεις ουρές με τις συναρτήσεις `queue.new` και `queue.from_list`:

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

Μπορείς να προσθέσεις στοιχεία στην ουρά με τις συναρτήσεις `queue.push_front` και `queue.push_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

Μπορείς να αφαιρέσεις στοιχεία από την ουρά με τις συναρτήσεις `queue.pop_front` και `queue.pop_back`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

Μπορείς να μετατρέψεις μια ουρά σε λίστα με τη συνάρτηση `queue.to_list`:

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## Ισότητα ουρών

Λόγω του τρόπου με τον οποίο υλοποιούνται οι ουρές, δύο ουρές με τα ίδια στοιχεία στην ίδια σειρά μπορεί να μην είναι ίσες σύμφωνα με τον τελεστή `==`, ο οποίος συγκρίνει τις τιμές δομικά. Για παράδειγμα:

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

Αν χρειάζεται να συγκρίνεις δύο ουρές για ισότητα, μπορείς να χρησιμοποιήσεις τη συνάρτηση `queue.is_logically_equal`.

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
