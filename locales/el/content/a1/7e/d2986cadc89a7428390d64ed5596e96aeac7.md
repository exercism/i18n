# Τεστ

Χρησιμοποιούμε το [PonyTest](https://stdlib.ponylang.io/pony_test--index/) από τη stdlib για να γράψουμε τα τεστ που ελέγχουν τη λύση σου. Για να ελέγξεις τη λύση σου, μεταγλώττισε και τρέξε τον κώδικά σου.

Για παράδειγμα, η συνεδρία σου για το "Hello World" μπορεί να μοιάζει κάπως έτσι:

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
