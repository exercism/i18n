# Μάθηση

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά μπορεί να είναι δύσκολο να ξεκινήσεις αν μαθαίνεις Common Lisp για πρώτη φορά.
Οι παρακάτω πόροι μπορούν να σε βοηθήσουν να ξεκινήσεις:

* [A Road to Common Lisp][road-to-cl], μια ανάρτηση σε ιστολόγιο που εξηγεί τη διαδρομή ενός ανθρώπου προς την Common Lisp και τις απόψεις του για το πώς να ξεκινήσεις με αυτήν
* [Practical Common Lisp][practical-cl], ένα πλήρες βιβλίο για την εκμάθηση της Common Lisp, διαθέσιμο δωρεάν online (καθώς και σε έντυπη μορφή)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  από διάφορους συνεισφέροντες
* [Awesome Common Lisp Learning][awesome-cl]

Δες επίσης, μέσα σε αυτό το track του Exercism για την Common Lisp: [Important Resources][track-resources].
