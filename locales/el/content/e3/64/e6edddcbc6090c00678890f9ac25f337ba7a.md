# Υποδείξεις

## Γενικά

- Ο [τύπος άτομου περιγράφεται εδώ][atom].

## 1. Προσδιόρισε την ετικέτα καταγραφής

- Μπορείς να χρησιμοποιήσεις την [ειδική μορφή `cond/1`][cond] για να χειριστείς με κομψό τρόπο τους διάφορους κωδικούς καταγραφής.
- Μπορείς να χρησιμοποιήσεις τους [τελεστές ισότητας][equality] για να συγκρίνεις ακέραιους ως προς την αυστηρή ισότητα τύπων.
- Υπάρχει ένας [τρόπος να ορίσεις έναν προεπιλεγμένο κλάδο][cond] σε μια έκφραση cond, που μπορεί να χρησιμοποιηθεί για να πιάνεις περιπτώσεις που δεν έχουν οριστεί.

## 2. Στείλε μια ειδοποίηση

- Μπορείς να χρησιμοποιήσεις την [ειδική μορφή `cond/1`][cond] για να αποφασίσεις αν πρέπει να σταλεί μια ειδοποίηση.
- Μπορείς να χρησιμοποιήσεις τους [τελεστές ισότητας][equality] για να συγκρίνεις άτομα ως προς την ισότητα.

[equality]: https://hexdocs.pm/elixir/Kernel.html#==/2
[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
