# Προσθήκη στις οδηγίες

## Ειδικές οδηγίες για αυτό το track

```exercism/note
Οι αφελείς λύσεις μπορεί να αργήσουν πολύ να περάσουν τα τεστ που περιλαμβάνουν τετραψήφιους παράγοντες, πιθανότατα περισσότερο από το χρονικό όριο που διαθέτει ο διαδικτυακός εκτελεστής δοκιμών.
Ίσως χρειαστεί να δουλέψεις την άσκηση τοπικά για να κάνεις profiling στη λύση σου.
Υπάρχουν αποδοτικές λύσεις για αυτή την άσκηση, αλλά είναι απαιτητικές.
```
