# Υποδείξεις
Μια συνηθισμένη χρήση του `Either` είναι να δηλώνει έναν υπολογισμό που μπορεί ενδεχομένως να καταλήξει σε σφάλμα
(αν το ίδιο το σφάλμα δεν σε ενδιαφέρει, τότε ο απλούστερος τύπος `Option` ίσως είναι καλύτερη επιλογή).
Όταν δεν υπάρχει σφάλμα, το αποτέλεσμα είναι συνήθως ένα `Right` (μνημονικό: η "σωστή" τιμή),
ενώ ένα σφάλμα είναι ένα `Left`, για παράδειγμα ένα `Left[String]` που περιέχει ένα μήνυμα σφάλματος.
Σημείωσε ότι στη Scala 2.12 το `Either` είναι right-biased εξ ορισμού, οπότε λειτουργεί όπως περιμένεις για πράξεις όπως `filter`, `map`, `flatMap` ή μέσα σε for-comprehension.
Αν δεν είσαι εξοικειωμένος με το `Either`, μπορείς να διαβάσεις [αυτό το σεμινάριο](http://danielwestheide.com/blog/2013/01/02/the-neophytes-guide-to-scala-part-7-the-either-type.html). Να έχεις όμως υπόψη σου ότι αυτό το σεμινάριο αφορά εκδόσεις της Scala πριν από τη 2.12. Στη Scala 2.12 μπορείς να αγνοήσεις άφοβα το `RightProjection` και να παραλείψεις το `.right`.
Το `Either` είναι ένα λεγόμενο [Monad](https://en.wikipedia.org/wiki/Monad_(functional_programming)) που καλύπτει μια "υπολογιστική πτυχή",
στην περίπτωση αυτή τη διαχείριση σφαλμάτων.
Η σωστή χρήση των Monads μπορεί να δώσει πολύ περιεκτικό, αλλά συνάμα κομψό
και ευανάγνωστο κώδικα. Η λανθασμένη χρήση μπορεί εύκολα να φέρει το αντίθετο αποτέλεσμα.
Δες [αυτό το βίντεο](https://www.youtube.com/watch?v=Mw_Jnn_Y5iA) για να μάθεις περισσότερα.
## Συνηθισμένες παγίδες που καλό είναι να αποφεύγεις
Υπάρχουν μερικοί εμπειρικοί κανόνες για το `Either`:
1. Αν δεν το χρειάζεσαι, μην το χρησιμοποιείς. Αντί για
```scala
def add1(x: Int): Either[String, Int] = Right(x + 1)
```
καλύτερα να έχεις
```scala
def add1(x: Int): Int = x + 1
```
(υπάρχει το `Either.map` για να εφαρμόζεις τέτοιες απλές συναρτήσεις,
ώστε να μη χρειάζεται να τις φορτώνεις με `Either`).
2. Μην κάνεις "unwrap" αν δεν το χρειάζεσαι πραγματικά.
Συχνά υπάρχουν έτοιμες συναρτήσεις για τον σκοπό σου. Ενδείξεις πρόωρου
unwrapping είναι τα `isLeft/isRight` ή το pattern matching. Για παράδειγμα, αντί για
```scala
val x: Either[String, Int] = ...

if (x.isRight) x.right.get + 1 else x.left.get
// or
x match {
  case Right(n) => n + 1
  case Left(s) => s
}
```
καλύτερα να έχεις
```scala
x fold (identity, _ + 1)
```
3. Μπορείς να χρησιμοποιήσεις Monads μέσα σε for-comprehension, με εξαιρετικά αποτελέσματα.
Αυτό είναι σκόπιμο όταν θέλεις να "συνθέσεις" πολλά στιγμιότυπα `Either`. Αντί για
```scala
val xo: Either[String, Int] = ...
val yo: Either[String, Int] = ...
val zo: Either[String, Int] = ...

xo.flatMap(x =>
  yo.flatMap(y =>
    zo.map(z =>
	    x + y + z)))
```
καλύτερα να έχεις
```scala
for {
  x <- xo
  y <- yo
  z <- zo
} yield x + y + z
```
