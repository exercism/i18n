# Οδηγίες

Υπάρχει ένα κατάστημα ηλεκτρικών ειδών κοντά σου που λέγεται "Tech Palace".
Ο ιδιοκτήτης του καταστήματος εγκατέστησε πρόσφατα μια μεγάλη οθόνη για να προβάλλει διαφημιστικά μηνύματα και να δείχνει έναν ξεχωριστό χαιρετισμό όταν οι πελάτες σκανάρουν στην είσοδο τις λεγόμενες κάρτες πιστότητάς τους.
Η οθόνη αποτελείται από πολλά μικρά φωτάκια LED και μπορεί να εμφανίσει πολλές γραμμές κειμένου.

Ο ιδιοκτήτης του καταστήματος χρειάζεται τη βοήθειά σου με τον κώδικα που χρησιμοποιείται για να δημιουργεί το κείμενο για τη νέα οθόνη.

## 1. Δημιούργησε το μήνυμα καλωσορίσματος

Για τους περισσότερους πελάτες που σκανάρουν τις κάρτες πιστότητάς τους, ο ιδιοκτήτης θέλει να βλέπει στην οθόνη το `Welcome to the Tech Palace, ` ακολουθούμενο από το όνομα του πελάτη με κεφαλαία γράμματα.

Υλοποίησε τη συνάρτηση `welcome` που δέχεται το όνομα του πελάτη και επιστρέφει το επιθυμητό μήνυμα ως συμβολοσειρά.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Πρόσθεσε ένα εντυπωσιακό περίγραμμα

Για τους πιστούς πελάτες που αγοράζουν πολλά από το κατάστημα, ο ιδιοκτήτης θέλει η οθόνη καλωσορίσματος να είναι πιο εντυπωσιακή, προσθέτοντας μια γραμμή με αστέρια πριν και μετά το μήνυμα καλωσορίσματος.
Δεν είναι ακόμη σίγουρος πόσα αστέρια πρέπει να έχει κάθε γραμμή, οπότε θέλει αυτό να είναι παραμετροποιήσιμο.

Γράψε μια συνάρτηση `add_border` που δέχεται ως ορίσματα ένα μήνυμα καλωσορίσματος και τον αριθμό των αστεριών ανά γραμμή.
Πρέπει να επιστρέφει μια συμβολοσειρά που αποτελείται από 3 γραμμές: μια γραμμή με τον επιθυμητό αριθμό αστεριών, μετά το μήνυμα καλωσορίσματος όπως ακριβώς δόθηκε, και μετά άλλη μια γραμμή με αστέρια.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Καθάρισε τα παλιά διαφημιστικά μηνύματα

Πριν εγκατασταθεί αυτή η νέα οθόνη, το κατάστημα είχε μια παρόμοια οθόνη που μπορούσε να εμφανίζει μόνο σταθερές, μη παραμετροποιήσιμες γραμμές.
Ο ιδιοκτήτης θα ήθελε να ξαναχρησιμοποιήσει μερικά από τα παλιά διαφημιστικά μηνύματα στη νέα οθόνη.
Ωστόσο, τα δεδομένα περιέχουν ήδη κάποια άβολα κενά διαστήματα που είχαν χρησιμοποιηθεί για να ευθυγραμμίζεται το κείμενο ανάμεσα σε πολλές οθόνες που ήταν στοιβαγμένες η μία πάνω στην άλλη.
Η δουλειά σου είναι να καθαρίσεις τα μηνύματα ώστε να μπορούν να ξαναχρησιμοποιηθούν.

Υλοποίησε μια συνάρτηση `clean` που δέχεται το παλιό διαφημιστικό μήνυμα.
Η συνάρτηση πρέπει πρώτα να αφαιρεί όλα τα κενά στην αρχή και στο τέλος του κειμένου και να το επιστρέφει.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
