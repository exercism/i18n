# Υποδείξεις

## Γενικά

- [Σταθερές][const]

## 1. Αναπαράστησε το σταθερό επιτόκιο ενός δανείου

- Η σταθερά θα πρέπει να είναι χωρίς τύπο, αλλά πρέπει να είναι αποδεκτή οπουδήποτε μπορεί να χρησιμοποιηθεί ένα float.
  Η συνάρτηση θα πρέπει να επιστρέφει τη σταθερά.

## 2. Αναπαράστησε τον αριθμό των ημερών ενός έτους

- Η συνάρτηση θα πρέπει να επιστρέφει τη σταθερά.

## 3. Αναπαράστησε τους μήνες του έτους

- Υπάρχει ένα [αναγνωριστικό][iota] για τη δημιουργία απαριθμημένων σταθερών.
  Ένα μπλοκ μοιάζει [έτσι][block].
  Η συνάρτηση θα πρέπει να δέχεται ένα όρισμα και να το επιστρέφει.

## 4. Αναπαράστησε έναν αριθμό λογαριασμού

- Η σταθερά θα πρέπει να είναι χωρίς τύπο, αλλά πρέπει να είναι αποδεκτή οπουδήποτε μπορεί να χρησιμοποιηθεί μια συμβολοσειρά.
  Η συνάρτηση θα πρέπει να επιστρέφει τη σταθερά.

[const]: https://golang.org/doc/effective_go.html#constants
[iota]: https://golang.org/ref/spec#Iota
[block]: https://golang.org/pkg/debug/macho/#pkg-constants
