# Το να είσαι καλό μέλος της κοινότητας του Exercism

Θέλουμε το Exercism να είναι ένα υπέροχο μέρος για να περνάς χρόνο, όποιος κι αν είσαι.
Για να διασφαλίσουμε ότι το Exercism είναι όντως αυτό, δίνουμε μεγάλη έμφαση στο να είμαστε καλά μέλη της κοινότητας.

Αυτό έχει αποτυπωθεί επίσημα στον [Κώδικα Δεοντολογίας](https://exercism.org/code-of-conduct) μας, αλλά μπορεί να συνοψιστεί απλά σε μία φράση: **Να είσαι ευγενικός.**

Υπάρχουν μερικές αρχές που αξίζει να έχεις κατά νου καθώς συνεισφέρεις στο Exercism.
Είτε κάνεις καθοδήγηση, είτε μαθαίνεις, είτε χαλαρώνεις σε κάποιον χώρο συνομιλίας, είτε βοηθάς να χτιστούν πράγματα στο GitHub, αν ακολουθήσεις αυτές τις ιδέες, θα ανακαλύψεις ότι το Exercism μπορεί να είναι ένα απίστευτα διασκεδαστικό και ικανοποιητικό μέρος για να περνάς χρόνο:

- Θεώρησε δεδομένες τις καλές προθέσεις
- Το να κάνεις λάθος είναι καταπληκτικό
- Δεν ξέρεις αυτά που δεν ξέρεις
- Διαφώνησε εποικοδομητικά
- Διάλεξε προσεκτικά τα λόγια σου

## Θεώρησε δεδομένες τις καλές προθέσεις

Η συντριπτική πλειονότητα των ανθρώπων που ασχολούνται με το Exercism συμμετέχει επειδή _θέλει να βοηθήσει τους άλλους_.
Ίσως είναι παθιασμένοι με την τεχνολογία, ίσως τους ενδιαφέρει η εκπαίδευση, αλλά πάνω απ' όλα θέλουν να βρίσκονται σε έναν χώρο όπου χτίζουν κάτι θετικό μαζί με άλλους.

Αυτό σημαίνει ότι η πλειονότητα των συζητήσεων γίνεται ανάμεσα σε δύο ανθρώπους που θέλουν το καλύτερο ο ένας για τον άλλο και επίσης για το Exercism.

Μερικές φορές, όταν προκύπτουν διαφωνίες, είναι εύκολο να βιαστείς να συμπεράνεις ότι ο άλλος γίνεται δύσκολος, ή ότι δεν ακούει, ή ότι δεν καταλαβαίνει το σημείο σου.
Είναι εύκολο να φανταστείς τον άλλο να αισθάνεται αυτάρεσκος, να χαϊδεύει το εγώ του, ενώ σε εξοργίζει με τις "λάθος" απόψεις του.
Στην πραγματικότητα, είναι πολύ πιο πιθανό αυτός ο άνθρωπος να προσπαθεί να επικοινωνήσει κάτι που θεωρεί σημαντικό και να μη βρίσκει λόγια ή τρόπους που να είναι σαφείς για τους άλλους.

Όταν κάνουμε ένα βήμα πίσω και θεωρούμε δεδομένο ότι όλοι όσοι συμμετέχουν **προσπαθούν** να είναι ευγενικοί, προσπαθούν να κάνουν το σωστό και προσπαθούν να είναι σαφείς, γίνεται πολύ πιο εύκολο για εμάς να χαλαρώσουμε τη λαβή του δικού μας εγώ και να προσπαθήσουμε **ενεργά** να ακούσουμε την οπτική του άλλου.

Πράγμα που μας οδηγεί στο επόμενο...

## Το να κάνεις λάθος είναι καταπληκτικό

Το να μαθαίνεις ότι κάνεις λάθος σε κάτι είναι το _καλύτερο πράγμα που μπορεί να σου συμβεί_, γιατί τώρα είσαι **λιγότερο λάθος** απ' ό,τι ήσουν πριν.
Αν είσαι άνθρωπος που νοιάζεται να σκέφτεται επιστημονικά, να αναζητά τη γνώση και να έχει δίκιο στα πράγματα, τότε το να ανακαλύπτεις ότι κάνεις λάθος είναι το πιο συναρπαστικό πράγμα που μπορεί να συμβεί.

Έτσι, όταν μπαίνεις σε μια συζήτηση στο Exercism, δες την ως μια ευκαιρία όχι να αποδείξεις ότι έχεις δίκιο, αλλά να ανακαλύψεις πού μπορεί να κάνεις λάθος. Κάνοντάς το, μπορεί να γίνεις πιο σωστός απ' ό,τι ήσουν πριν.

Ο Adam Grant έγραψε [ένα ολόκληρο βιβλίο για αυτό](https://www.adamgrant.net/book/think-again/).
Σε αυτό παραθέτει τον [Ray Dalio](https://en.wikipedia.org/wiki/Ray_Dalio) να λέει: "Αν δεν κοιτάς πίσω στον εαυτό σου και δεν σκέφτεσαι, 'Ουάου, πόσο ανόητος ήμουν πριν ένα χρόνο', τότε μάλλον δεν έμαθες και πολλά τον τελευταίο χρόνο".

## Δεν ξέρεις αυτά που δεν ξέρεις

Το Exercism είναι χτισμένο πάνω στην αρχή ότι **δεν ξέρουμε αυτά που δεν ξέρουμε**.
Ολόκληρη η πλατφόρμα λειτουργεί γύρω από καθοδηγητές που επισημαίνουν κενά γνώσης που δεν ξέρεις ότι έχεις.
Και είναι μια απίστευτη εμπειρία όταν και οι δύο πλευρές είναι ανοιχτές σε νέες πληροφορίες (πολύ συχνά οι _καθοδηγητές_ είναι αυτοί που συνειδητοποιούν ότι δεν ήξεραν κάτι οι ίδιοι, βλέποντας νέο κώδικα και στρατηγικές από έναν μαθητή!)

Είναι εύκολο να θυμάσαι αυτό το συναίσθημα όταν είσαι μαθητής σε μια συνεδρία καθοδήγησης, αλλά αυτό το πνεύμα ανοιχτότητας είναι εξίσου σημαντικό παντού αλλού μέσα στο Exercism.
Όταν πιστεύεις ότι κάτι στον ιστότοπο είναι χάλια, ξεκίνα ρωτώντας τον εαυτό σου τι πράγματα μπορεί να _μην_ ξέρεις. Μια απόφαση που φαίνεται γελοία από τη δική σου οπτική μπορεί να δείχνει ένα κενό στη γνώση σου, όσο μπορεί να δείχνει ότι η απόφαση είναι όντως **γελοία**.

Ρίξε μια ματιά στο άρθρο μας για τον [Φράχτη του Chesterton](/docs/community/being-a-good-community-member/chestertons-fence) για μερικά πρακτικά παραδείγματα του πώς εφαρμόζεται αυτή η αρχή.

## Διαφώνησε εποικοδομητικά

Ένα τεράστιο μέρος του να χτίζεις ένα επιτυχημένο προϊόν, και μια επιτυχημένη κοινότητα, βασίζεται στο να φέρνουν οι άνθρωποι διαφορετικές γνώμες και οπτικές και να τις συζητούν με στόχο να βρουν μια κοινή αλήθεια. Μπορεί μάλιστα να απαιτεί κάποια διαφωνία γύρω από την αποδεκτή αλήθεια για να φτάσουμε σε μια καλύτερη αλήθεια.
Το να διαφωνούμε μεταξύ μας είναι, επομένως, κρίσιμο component του Exercism.
Το να διαφωνείς εποικοδομητικά με τους ανθρώπους είναι δεξιότητα, μία που είναι δύσκολο να την κατακτήσεις.

Ορίστε μερικά σημεία-οδηγοί για το πώς να διαφωνείς _εποικοδομητικά_ μέσα στην κοινότητά μας:

### 1. Ρώτα τον εαυτό σου αν χρειάζεται να εμπλακείς

Βρήκες ένα πρόβλημα και νιώθεις ότι κάποιος πρέπει να το μάθει.
Το πρώτο πράγμα που πρέπει να αναρωτηθείς είναι: πρέπει όντως να το μάθει;
Το να πεις σε κάποιον ότι κάτι είναι λάθος θα _κάνει τα πράγματα καλύτερα_;
Προσθέτεις θόρυβο ή σήμα;

Τις περισσότερες φορές, το να πεις σε κάποιον ότι κάνει λάθος είναι εξαιρετικό.
Τον βοηθάς να καλύψει ένα κενό γνώσης και βοηθάς να γίνει το Exercism καλύτερο.
Αλλά μερικές φορές δεν αξίζει τον θόρυβο ή την ενέργεια, και το να διορθώσεις κάποιον απλώς τον κάνει να αισθανθεί χειρότερα για τον εαυτό του.
Έτσι, πριν ορμήσεις, βεβαιώσου ότι είναι το σωστό για τους άλλους που συνεισφέρουν.

### 2. Μην πέφτεις από πάνω κι εσύ

Στενά συνδεδεμένο με το πρώτο σημείο, η φυλετική μας φύση νιώθει συχνά την ανάγκη να σχολιάσει όταν βλέπει κάποιον να εκφράζει μια κοινή (ή αντίθετη) γνώμη.
Το βλέπεις συχνά στο GitHub, με ανθρώπους να προσθέτουν emoji 👍 και 👎 σε κάθε σχόλιο ή να γεμίζουν ένα νήμα με ένα σχόλιο "Κι εγώ!".
Πολλοί βλέπουν μια δημόσια διαφωνία και νιώθουν ότι πρέπει να "ενισχύσουν" όσους συμφωνούν μαζί τους.

Αν δεν λες κάτι καινούριο ή κάτι χρήσιμο, ρώτα τον εαυτό σου αν _χρειάζεται_ να πεις κάτι καθόλου.

- Κάνει αυτό το 👎 κάποιον να αισθανθεί απλώς χάλια με τον εαυτό του;
- Θα τον εδραιώσει απλώς ακόμη περισσότερο στη θέση του και θα τον κάνει αμυντικό;
- Το να προσθέσεις ένα 👍 κάνει κάποιον άλλο να νιώσει ότι έχει δίκιο, φουσκώνει το εγώ του και κάνει πιο δύσκολη την ενσυναίσθηση με την αντίθετη άποψη;
- Το να προσθέσεις ένα σχόλιο "Κι εμένα μου είναι χαλασμένο!" προσθέτει ένα _χρήσιμο_ δεδομένο για τον maintainer, ή είναι απλώς περισσότερη πίεση και επείγον;

Κάθε κατάσταση είναι διαφορετική, αλλά σκέψου πριν κάνεις κλικ ή πληκτρολογήσεις.

### 3. Μην το κάνεις προσωπικό

Λοιπόν, μπήκες σε μια διαφωνία.
**Τέλεια!** 🎉
Τώρα, _κάνε την να αξίζει_.

Θυμήσου, δεν διαφωνείς με ένα πρόσωπο, διαφωνείς με την **τρέχουσα** άποψή του για κάτι.
Φρόντισε να του δώσεις χώρο να αλλάξει αυτή την άποψη _χωρίς_ να νιώσει ότι χάνει το πρόσωπό του.
Δώσε του τη δυνατότητα να δει την αξία της δικής σου άποψης χωρίς να τον κάνεις να αισθανθεί ανόητος.
**Μην το κάνεις προσωπικό.**

Ένα ξεκάθαρο προειδοποιητικό σημάδι είναι η ανάγκη να παραθέσεις αυτά που είπε κάποιος για να του δείξεις πού έκανε λάθος ή πού αντέφασκε τον εαυτό του.
Το να αντιφάσκει κάποιος τον εαυτό του είναι συχνά σημάδι **εξελισσόμενης σκέψης.**
Δεν αποδεικνύει ότι κάνει _λάθος_, αποδεικνύει ότι αφήνει το μυαλό του να είναι δημιουργικό.  
Εξερευνά διαφορετικούς δρόμους και συνδυάζει τα πράγματα με διαφορετικό τρόπο.
Ενθάρρυνέ το!

Και θυμήσου να είσαι ο εαυτός σου.
Δεν _χρειάζεται_ να επισημάνεις ότι συμφωνείς με το Χ ή ότι το Ψ είναι σαφώς σωστό.
Δεν έχει να κάνει με πρόσωπα, έχει να κάνει με το _να βρεις την καλύτερη λύση_.
Πρόσθεσε σήμα, όχι θόρυβο.

### 4. Αποδέξου τις αποφάσεις

Συχνά οι διαφωνίες δεν καταλήγουν σε συμπεράσματα με τα οποία συμφωνούν όλοι.
Στην πραγματικότητα, στο Exercism σχεδόν τα πάντα είναι ένα είδος συμβιβασμού.
Θα είσαι, επομένως, σχεδόν πάντα λίγο δυσαρεστημένος με το αποτέλεσμα.

Είναι κρίσιμο για το να είσαι καλό μέλος της κοινότητας να αποδέχεσαι τις αποφάσεις και να τις αγκαλιάζεις, ακόμη κι αν διαφωνείς με αυτές.

Οι αποφάσεις πρέπει να περιλαμβάνουν πολλές οπτικές και τελικά θα περιέχουν πολλά ανταλλάγματα.
Αυτό που είναι καλό για μία γλωσσική διαδρομή μπορεί να είναι λίγο χειρότερο για μια άλλη.
Κάποια αρχιτεκτονική ή οργανωτική κατεύθυνση μπορεί να σου προκαλέσει περισσότερη δουλειά απ' ό,τι σε κάποιον άλλο.
Μια θεώρηση που αφορά όλο τον ιστότοπο ή όλη την κοινότητα μπορεί να κριθεί πιο σημαντική από αυτή που αφορά ειδικά τη δική σου διαδρομή.

Αν νιώθεις ότι δεν καταλαβαίνεις γιατί πάρθηκε μια απόφαση, μη διστάσεις να ρωτήσεις.
Αλλά μόλις σου εξηγηθεί η απόφαση, το βάρος πέφτει πάνω σου να την αποδεχτείς ακόμη κι αν δεν σου αρέσει.
Αν όλοι προσπαθούν να το κάνουν αυτό, την επόμενη φορά που μια απόφαση **θα** πάει όπως θέλεις εις βάρος της ευχαρίστησης κάποιου άλλου, δεν θα νιώσεις την ενοχή ή την πικρία του, και θα μπορείς να εστιάσεις την ενέργειά σου σε πιο παραγωγικά ζητήματα.

Και να εμπιστεύεσαι ότι οι αποφάσεις παίρνονται με _**καλή πίστη**_, όλοι προσπαθούν να κάνουν ό,τι είναι καλύτερο για την κοινότητα, την πλατφόρμα και τους μαθητές μας.

## Διάλεξε προσεκτικά τα λόγια σου

Υπάρχουν πολλοί τρόποι να δείξεις ευγένεια μέσα στο Exercism, αλλά ο πιο ισχυρός είναι να σκεφτείς πώς τα λόγια σου επηρεάζουν τους άλλους.

Σε έναν διαπολιτισμικό χώρο γεμάτο ανθρώπους από διαφορετικά υπόβαθρα, που μοιράζονται διαφορετικές πεποιθήσεις, συστήματα αξιών και φυσικές γλώσσες, το να επικοινωνείς καθαρά είναι υπερδύναμη.
Είναι εύκολο να ξέρεις πώς θέλεις να _ακουστούν_ τα λόγια σου, αλλά είναι δύσκολο να ξέρεις πώς οι άλλοι _αντιλαμβάνονται τα λόγια σου_.

Διάβασε το [Τα λόγια που χρησιμοποιούμε](/docs/community/being-a-good-community-member/the-words-that-we-use) για να μάθεις περισσότερα για το γιατί αυτό έχει τόση σημασία.
