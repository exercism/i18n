# Υποδείξεις

Οι τρεις πρώτες εργασίες καλούν όλες την ίδια συνάρτηση `print_name_badge()`.
Η υλοποίησή της μπορεί να χτιστεί βήμα βήμα, προσθέτοντας τη λογική για τις εργασίες 2 και 3 καθώς προχωράς.

## 1. Δημιούργησε ένα σήμα για έναν υπάλληλο

- Αυτή είναι η προεπιλεγμένη περίπτωση, απλώς συνδύασε τα 3 ορίσματα σε μια κατάλληλη συμβολοσειρά.
- Η [παρεμβολή συμβολοσειρών][interpolation] είναι πιθανώς η πιο εύκολη προσέγγιση.

## 2. Δημιούργησε ένα σήμα για έναν νέο υπάλληλο

- Τώρα το ID είναι `missing,`, οπότε η μορφή της συμβολοσειράς-στόχου είναι διαφορετική.
- Η [`ismissing()][ismissing] είναι χρήσιμη εδώ.
- Η Julia έχει έναν [τριαδικό τελεστή][ternary] με συνοπτική σύνταξη.

## 3. Δημιούργησε ένα σήμα για τον ιδιοκτήτη

- Τώρα το τμήμα είναι `nothing`.
- Υπάρχει μια συνάρτηση [`isnothing()`][isnothing].

## 4. Υπολόγισε τον συνολικό μισθό των υπαλλήλων χωρίς ID

- Λείπει [κάποιο][any] ID; Αν όχι, η τιμή επιστροφής είναι μηδέν.
- Για να ξεχωρίσεις τις καταγραφές με ID που λείπει, μπορεί να σε βοηθήσει να ξεκινήσεις κάνοντας [zip][zip] στα διανύσματα `ids` και `salaries`.
- Υπάρχουν αρκετοί τρόποι να διατρέξεις το διάνυσμα πλειάδων που προκύπτει, χωρίς να γράψεις έναν ρητό βρόχο.
  - Με στυλ Python, με [comprehension][comprehension] ενός διανύσματος.
  - Συναρτησιακά, με τη [`map()`][map] και μια [ανώνυμη συνάρτηση][anonymous].
  - Διανυσματικά, με [broadcasting][broadcasting] μιας [ανώνυμης συνάρτησης][anonymous].
- Στο τέλος, θα έχεις μια [`sum()`][sum] πάνω σε ένα τροποποιημένο διάνυσμα μισθών.
   - Οι μισθοί των υπαλλήλων με ID μπορούν είτε να παραλειφθούν είτε να μηδενιστούν.
