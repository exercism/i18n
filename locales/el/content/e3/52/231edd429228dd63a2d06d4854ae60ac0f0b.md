# Εγκατάσταση

## Στοχευόμενη έκδοση

Οι δοκιμές για αυτό το track χρησιμοποιούν την εικόνα Docker `alpine:3.24.1`, η οποία, από τον Σεπτέμβριο του 2026, χρησιμοποιεί `sqlite3 version 3.53.4`.
Προσπαθούμε να διασφαλίσουμε ότι τα εργαλεία που παρέχει αυτό το track θα δουλεύουν στην τελευταία έκδοση LTS του Ubuntu.
Αν και μπορεί να έχεις εγκαταστήσει νεότερες εκδόσεις, καλό είναι να γνωρίζεις ότι ορισμένες δυνατότητες μπορεί να μη δουλεύουν με τον εκτελεστή δοκιμών μας.
Μπορείς να συγκρίνεις τις δυνατότητες στο [ιστορικό εκδόσεων της SQLite][version-history].

## Windows

Για να εγκαταστήσεις την SQLite στα Windows, ακολούθησε αυτά τα βήματα:

1. Κατέβασε τα προμεταγλωττισμένα δυαδικά αρχεία για Windows από την [επίσημη σελίδα λήψης][sqlite-download].
2. Αποσυμπίεσε το ZIP αρχείο που κατέβασες σε έναν φάκελο της επιλογής σου.
   Για παράδειγμα, `C:\Program Files\sqlite3`.
3. Πρόσθεσε τον φάκελο που περιέχει το `sqlite3.exe` στη μεταβλητή περιβάλλοντος PATH του συστήματος.
   Η διαδικασία είναι λίγο διαφορετική για κάθε έκδοση των Windows, αλλά οι πληροφορίες είναι εύκολο να βρεθούν με μια αναζήτηση.
   Για παράδειγμα, [οδηγίες για τα Windows 11][windows-11-install] και [Windows 10][windows-10-install].

## macOS

Στο macOS, η SQLite είναι προεγκατεστημένη.
Ωστόσο, αν χρειάζεσαι νεότερη έκδοση, μπορείς να χρησιμοποιήσεις το [Homebrew][homebrew]:

```bash
brew install sqlite
```

## Ubuntu / Debian

Σε Ubuntu και σε συστήματα που βασίζονται στο Debian, μπορείς να εγκαταστήσεις την SQLite με το apt:

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

Σε CentOS, Fedora και συστήματα που βασίζονται στο Red Hat, μπορείς να εγκαταστήσεις την SQLite με το yum ή το dnf:

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

Στο Arch Linux, μπορείς να εγκαταστήσεις την SQLite με το pacman:

```bash
sudo pacman -S sqlite
```

## Άλλοι τρόποι εγκατάστασης και παλαιότερες εκδόσεις

Δες τη [σελίδα λήψης της SQLite][sqlite-download] για περισσότερες πληροφορίες και εναλλακτικούς τρόπους εγκατάστασης.
Η ενότητα `Build Product Names and Info` περιέχει το πρότυπο ονομασίας για τις διάφορες εκδόσεις της SQLite, οπότε θα μπορείς να αναζητήσεις την έκδοση που θέλεις με τη μηχανή αναζήτησης που προτιμάς.
