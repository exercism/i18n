# Εισαγωγή

Η *Συνδυαστική* είναι ο κλάδος των μαθηματικών που μελετά την καταμέτρηση και την καταγραφή των τρόπων με τους οποίους μπορούν να επιλεγούν ή να διαταχθούν τα στοιχεία μιας συλλογής. Το λεξιλόγιο [`math.combinatorics`][math.combinatorics] που διαθέτει η Factor καλύπτει τα δύο βασικά ερωτήματα:

- **Συνδυασμοί**: επιλογές όπου η σειρά *δεν* έχει σημασία.
- **Μεταθέσεις**: διατάξεις όπου η σειρά *έχει* σημασία.

Κάθε ερώτημα έχει μια λέξη *καταμέτρησης* που επιστρέφει έναν αριθμό και μια λέξη *απαρίθμησης* που επιστρέφει τις πραγματικές επιλογές, καθώς και μια παραλλαγή ροής `each-` που καλεί μια παράθεση για καθεμία:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
