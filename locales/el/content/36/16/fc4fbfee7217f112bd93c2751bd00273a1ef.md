# Γενικά

- Βεβαιώσου ότι έχεις κατανοήσει καλά πώς να δημιουργείς και να ενημερώνεις λίστες.
- Η [τεκμηρίωση][python lists] της Python για τις `lists` μπορεί να σου φανεί πολύ χρήσιμη.
- Η [ενότητα του οδηγού][more on lists] της Python για τις `lists` είναι επίσης καλή πηγή.

## 1. Πρόσθεσέ με στην ουρά

- Μια εντολή `if-else` μπορεί να σε βοηθήσει να βρεις με ποιον τύπο εισιτηρίου έχεις να κάνεις.
- Στη συνέχεια, μπορείς να κάνεις `append()` στο άτομο στην ουρά με βάση τον τύπο εισιτηρίου.

## 2. Πού είναι οι φίλοι μου

- Πρέπει να βρεις το `index()` του ονόματος του φίλου μέσα στην ουρά.

## 3. Μπορώ να μπω κι εγώ μαζί τους;

- Αφού ξέρεις το `index()`, μπορείς να κάνεις `insert()` τον φίλο στην ουρά σε εκείνο το σημείο.

## 4. Ένα κακό άτομο στην ουρά

- Ξέρεις το όνομα του κακού ατόμου, οπότε μπορείς να το κάνεις `remove()` από την ουρά.

## 5. Συνονόματοι

-  Το να κάνεις `count()` στις εμφανίσεις του `name` στην ουρά μπορεί να είναι καλή στρατηγική εδώ.

## 6. Αφαίρεσε το τελευταίο άτομο

- Αν και θα μπορούσες να κάνεις `remove()` στο άτομο με το όνομά του, το να το βγάλεις με `pop()` μπορεί να είναι πιο γρήγορο.

## 7. Ταξινόμησε τη λίστα της ουράς

- Μην ξεχνάς ότι πρέπει να αποφύγεις να μεταβάλεις την ουρά και να χάσεις την αρχική της σειρά.
- Μόλις έχεις ένα `copy()`, η ταξινόμηση με `sort()` θα πρέπει να είναι απλή.
- Ψάχνουμε για _αύξουσα_ ταξινόμηση, ή _αλφαβητική από το a ως το z_.
