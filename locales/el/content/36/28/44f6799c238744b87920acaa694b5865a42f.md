# Υποδείξεις

## 1. Αφαίρεσε τα διπλότυπα κομμάτια

- Μπορείς να δεις ένα παράδειγμα δημιουργίας ενός Set από έναν πίνακα στην [τεκμηρίωση του MDN][mdn-relation-to-arrays].
- Βεβαιώσου ότι θα μετατρέψεις το Set σου ξανά σε πίνακα πριν το επιστρέψεις.
- Γύρνα ξανά στην [έννοια της αποδόμησης πίνακα][concept-array-destructuring] για να θυμηθείς πώς να χρησιμοποιείς τον τελεστή spread.

## 2. Έλεγξε αν ένα κομμάτι έχει ήδη προστεθεί

- Υπάρχει μια [ενσωματισμένη μέθοδος][mdn-set-has] για να ελέγξεις αν ένα στοιχείο βρίσκεται σε ένα Set.

## 3. Πρόσθεσε ένα κομμάτι

- Υπάρχει μια [ενσωματισμένη μέθοδος][mdn-set-add] για να προσθέσεις ένα στοιχείο σε ένα Set.
- Βεβαιώσου ότι δεν καλείς χειροκίνητα το `Set.has()` για να ελέγξεις την παρουσία του στοιχείου πριν το προσθέσεις· το `Set.add()` το αναλαμβάνει για σένα!

## 4. Διέγραψε ένα κομμάτι

- Υπάρχει μια [ενσωματισμένη μέθοδος][mdn-set-delete] για να αφαιρέσεις ένα στοιχείο από ένα Set.
- Βεβαιώσου ότι δεν καλείς χειροκίνητα το `Set.has()` για να ελέγξεις την παρουσία του στοιχείου πριν το διαγράψεις· το `Set.delete()` το αναλαμβάνει για σένα!

## 5. Φτιάξε μια λίστα με τους μοναδικούς καλλιτέχνες

- Υπάρχουν [μερικοί διαφορετικοί τρόποι][mdn-set-iteration] για να κάνεις επανάληψη πάνω σε ένα Set.
- Υπάρχει μια [ενσωματισμένη μέθοδος][mdn-string-split] για να χωρίσεις μια συμβολοσειρά σε υποσυμβολοσειρές.
- Γύρνα ξανά στην [έννοια της αποδόμησης πίνακα][concept-array-destructuring] για να θυμηθείς πώς να προσπεράσεις ένα στοιχείο όταν κάνεις αποδόμηση ενός πίνακα.
