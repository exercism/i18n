# Επαναλήπτες

Ο επαναλήπτης είναι μια ρουτίνα που το όνομά της τελειώνει σε `!` και που μπορεί να κληθεί μόνο μέσα σε έναν `loop` βρόχο. Κάθε φορά που ο βρόχος επαναλαμβάνεται, παράγει την επόμενη τιμή του· όταν εξαντληθεί, ο βρόχος τελειώνει αμέσως.

```sather
   loop
      total := total + counts.elt!;
   end;
```

Η Sather δεν έχει εντολή `for`. Αυτό είναι που την αντικαθιστά, και είναι το χαρακτηριστικό για το οποίο είναι γνωστή η γλώσσα.

## Όσοι αξίζει να ξέρεις από νωρίς

| Επαναλήπτης | Δίνει |
| --- | --- |
| `a.elt!` | κάθε στοιχείο του `a`, με τη σειρά |
| `a.ind!` | κάθε θέση του `a`: 0, 1, 2 … |
| `n.upto!(m)` | `n`, `n+1` … `m` |
| `n.downto!(m)` | `n`, `n-1` … `m` |
| `n.times!` | εκτελείται `n` φορές, χωρίς να δίνει τίποτα |
| `n.up!` | `n`, `n+1`, … και δεν τελειώνει ποτέ |
| `s.elt!` | κάθε χαρακτήρας μιας συμβολοσειράς |

Τα `until!`, `while!` και `break!` είναι επίσης επαναλήπτες. Γι' αυτό τελειώνουν σε `!` και γι' αυτό λειτουργούν μόνο μέσα σε έναν βρόχο.

## Πού πάει η κλήση

Μια κλήση επαναλήπτη μπορεί να εμφανιστεί οπουδήποτε μπορεί να εμφανιστεί μια έκφραση, ακόμη και στη μέση μιας συνθήκης:

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

Κάθε *σημείο* στο πρόγραμμα όπου γράφεται ένας επαναλήπτης κρατά τη δική του θέση. Αν γράψεις `counts.elt!` δύο φορές στο ίδιο σώμα βρόχου, κάνεις δύο ανεξάρτητες διαδρομές στον πίνακα, κάτι που σχεδόν ποτέ δεν είναι αυτό που θέλεις:

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

Ζήτα το μία φορά και βάλε την τιμή σε μια μεταβλητή.

## Πώς τελειώνει ο βρόχος

Ο βρόχος τελειώνει μόλις εξαντληθεί *οποιοσδήποτε* επαναλήπτης μέσα του, όχι όταν εξαντληθούν όλοι. Με έναν επαναλήπτη αυτό είναι προφανές. Με πολλούς, είναι ο κανόνας που πιάνει τους πάντες, και είναι το θέμα της επόμενης άσκησης.

## Ποιον να προτιμήσεις

Προτίμησε το `elt!` όταν θέλεις τις τιμές και το `ind!` όταν θέλεις τις θέσεις. Κατέφυγε στο `upto!` πάνω στο διάστημα `0 .. a.size - 1` μόνο όταν τα χρειάζεσαι και τα δύο ταυτόχρονα ή όταν η απάντηση είναι μια θέση και όχι μια τιμή.
