# Εισαγωγή

Αν οι τύποι των παραμέτρων μπορούν να συμπεραθούν, η Swift επιτρέπει επίσης να παραλείπονται τα ονόματα των παραμέτρων και η λέξη-κλειδί `in` από τον ορισμό του closure. Οι παράμετροι μπορούν αντ' αυτού να αναφέρονται με μια ειδική συντομευμένη σύνταξη, όπου το `$0` αναφέρεται στην πρώτη παράμετρο, το `$1` στη δεύτερη, κ.ο.κ.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```
