# Εισαγωγή

## Αντιστοίχιση

Η αντιστοίχιση αναφέρεται στην εφαρμογή μιας συνάρτησης σε κάθε στοιχείο μιας ακολουθίας, ώστε να προκύψει μια νέα ακολουθία.

Αυτό μπορεί να γίνει εύκολα σε μια λίστα με τη συνάρτηση `mapcar`.
Ας υποθέσουμε ότι έχουμε μια συνάρτηση `double` που πολλαπλασιάζει το όρισμά της με το `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Παρατήρησε ότι το πρώτο όρισμα είναι μια συνάρτηση που θα κληθεί. Το `#'` είναι μια ειδική σύνταξη παράθεσης που καθορίζει μια συνάρτηση.

Η `double` κλήθηκε πρώτα με το πρώτο στοιχείο, μετά με το δεύτερο, κ.ο.κ.
Τα αποτελέσματα συγκεντρώθηκαν σε μια λίστα, η οποία είναι η τιμή στην οποία αποτιμάται η παράσταση.

## Φιλτράρισμα

Το φιλτράρισμα είναι η διαδικασία δημιουργίας μιας ακολουθίας από μια άλλη ακολουθία, αντιγράφοντας όλα τα στοιχεία της αρχικής ακολουθίας εκτός από ορισμένα.
Η επιλογή των στοιχείων που θα συμπεριληφθούν στη νέα ακολουθία μπορεί να γίνει με μια συνάρτηση κατηγόρημα, δηλαδή μια συνάρτηση που αποτιμάται σε τιμή boolean (λογική τιμή), ή με έλεγχο ισότητας με ένα συγκεκριμένο αντικείμενο.

### Αφαίρεση με κατηγόρημα

Η `remove-if` είναι μια συνάρτηση που παίρνει ως ορίσματα μια συνάρτηση κατηγόρημα και μια ακολουθία, και επιστρέφει μια ακολουθία με μόνο εκείνα τα στοιχεία για τα οποία το κατηγόρημα αποτιμήθηκε σε ψευδή τιμή.
Με άλλα λόγια, "αφαιρεί" όλα τα στοιχεία της ακολουθίας για τα οποία το κατηγόρημα αποτιμάται σε αληθή τιμή. Ωστόσο, πρόσεξε ότι αυτή η συνάρτηση δεν τροποποιεί την αρχική ακολουθία!
Αντ' αυτού, επιστρέφει μια νέα ακολουθία χωρίς τα αντίστοιχα στοιχεία. Αν το κατηγόρημα ήταν αληθές για όλες τις τιμές, τότε επιστρέφεται μια κενή ακολουθία.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Αφαίρεση συγκεκριμένου στοιχείου

Αν θέλεις να αφαιρέσεις ένα συγκεκριμένο στοιχείο από μια ακολουθία, μπορείς να χρησιμοποιήσεις τη `remove`, η οποία παίρνει το στοιχείο προς αφαίρεση και μια ακολουθία.
Επιστρέφονται όλες οι τιμές της ακολουθίας που δεν είναι ίσες με το στοιχείο προς αφαίρεση.
ΣΗΜΕΙΩΣΗ: Η ισότητα ελέγχεται από προεπιλογή με το `eql`, το [γενικό κατηγόρημα ισότητας][concept-equality].

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
