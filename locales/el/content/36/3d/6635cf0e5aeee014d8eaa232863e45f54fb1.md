# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη σταθερά `OvenTime` με τον αριθμό λεπτών που πρέπει να μείνουν τα λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```go
OvenTime
// => 40
```

## 4. Υπολόγισε τον χρόνο εργασίας που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `ElapsedTime` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις εργαστεί για το μαγείρεμα των λαζανιών, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει μέχρι στιγμής στον φούρνο.
