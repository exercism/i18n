# Τεστ

## Εκτέλεση των τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την παρακάτω εντολή:

```bash
call {slug}Test.bat
```

## Επίλυση της άσκησης

Για να λύσεις μια άσκηση, πρέπει να περάσουν όλα τα τεστ της.
Όταν περάσουν όλα τα τεστ, έχεις λύσει την άσκηση!

Για να σε βοηθήσουμε να ξεκινήσεις, κάθε άσκηση συνοδεύεται από ένα αρχείο υλοποίησης stub.
Μπορείς να χρησιμοποιήσεις αυτό το αρχείο ως σημείο εκκίνησης για να χτίσεις τη λύση σου.
Μη διστάσεις να διαγράψεις ή να αλλάξεις αυτό το αρχείο, αν πιστεύεις ότι είναι το σωστό.
