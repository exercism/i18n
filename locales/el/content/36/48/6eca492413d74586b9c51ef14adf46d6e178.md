# Σχετικά

Ο τύπος `Maybe` είναι η λύση της γλώσσας Elm για προαιρετικές τιμές.
Γι' αυτόν τον λόγο υπάρχει στις υπογραφές τύπων πολλών βασικών συναρτήσεων της Elm και η κατανόησή του είναι κρίσιμη.

## Ορισμός και μεταβλητή τύπου

Ο τύπος `Maybe` ορίζεται ως εξής:

```elm
type Maybe a = Nothing | Just a
```

Αυτό είναι γνωστό ως ορισμός "προσαρμοσμένου τύπου" στην ορολογία της Elm.
Οι προσαρμοσμένοι τύποι παρουσιάζονται με περισσότερες λεπτομέρειες σε άλλη έννοια αυτής της διαδρομής, αλλά δεν θα τους χρειαστούμε για να κατανοήσουμε ειδικά τον `Maybe`.
Το `a` στα `Maybe a` και `Just a` αντιπροσωπεύει μια μεταβλητή τύπου, που σημαίνει ότι μπορεί να είναι οποιοσδήποτε τύπος, όπως `Int`, `Bool` ή `String`.
Έτσι, ένα `Maybe String` είναι μια μεταβλητή που περιέχει προαιρετικά ένα `String`, ενώ ένα `Maybe Int` θα περιείχε προαιρετικά ένα `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

Η κατακόρυφη μπάρα `|` στον ορισμό τύπου του `Maybe` σημαίνει "Ή".
Δηλώνει ότι μια τιμή αυτού του τύπου μπορεί είτε να είναι `Nothing` είτε να είναι `Just` κάτι τύπου `a`.
Έτσι, ας φανταστούμε ότι το όνομα και η ηλικία δεν δόθηκαν από αυτό το άτομο, θα είχαμε τα εξής.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Ανάγνωση του περιεχομένου μιας τιμής Maybe

Το διάβασμα του περιεχομένου μιας τιμής `Maybe` γίνεται μέσω της "αντιστοίχισης προτύπων".
Η αντιστοίχιση προτύπων παρουσιάζεται επίσης με περισσότερες λεπτομέρειες σε άλλη έννοια, οπότε θα εστιάσουμε μόνο στο πώς λειτουργεί η αντιστοίχιση προτύπων σε ένα `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Κάθε φορά που χρησιμοποιείς μια τιμή `Maybe`, ο μεταγλωττιστής της Elm θα ελέγξει ότι ο κώδικάς σου καλύπτει όλες τις περιπτώσεις, ώστε να μην μπορείς ποτέ να κάνεις αντιστοίχιση προτύπων σε ένα `Maybe` και να χειρίζεσαι μόνο την περίπτωση όπου υπάρχει ένα `Just someValue`.
Αυτό μπορεί να φαίνεται ενοχλητικό στην αρχή, αλλά είναι ένα από τα μεγαλύτερα πλεονεκτήματα της γλώσσας Elm.
Θα αποτρέψει εκατοντάδες bugs και κάνει την αναδιαμόρφωση κώδικα με οδηγό τον μεταγλωττιστή μια ατρόμητη και ανταποδοτική εμπειρία.

## Περισσότερες συναρτήσεις για τον χειρισμό του `Maybe`

Υπάρχουν επίσης αρκετές χρήσιμες συναρτήσεις στο module `Maybe` για τον χειρισμό τύπων `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
