# χρήση split συμβολοσειρών

Χρησιμοποίησε τον ενσωματωμένο τύπο `rune` για να δουλέψεις με μεμονωμένους χαρακτήρες στη Go.
Μια `string` μπορεί να μετατραπεί σε `[]rune` (μια slice από runes) με:

```go
aRunes := []rune(a)
```

Ο διαχωρισμός της συμβολοσειράς σε πολλές μικρές συμβολοσειρές (μία για κάθε rune) δουλεύει, αλλά είναι αναποτελεσματικός.
