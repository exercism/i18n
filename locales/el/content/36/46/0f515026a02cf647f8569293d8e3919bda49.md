# Σχετικά

Η ABAP διαθέτει αρκετούς αριθμητικούς τύπους. Οι πιο συνηθισμένοι για μικρές εισαγωγικές ασκήσεις είναι ο `i` για ακέραιες τιμές και ο `p` για συσκευασμένες δεκαδικές τιμές.

Χρησιμοποίησε τον `i` όταν μια τιμή πρέπει να είναι ακέραιος αριθμός, όπως το πλήθος των ημερών. Χρησιμοποίησε έναν δεκαδικό τύπο όταν μια τιμή μπορεί να περιέχει δεκαδικά ψηφία, όπως μια ωριαία χρέωση.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Οι συσκευασμένοι αριθμοί χρησιμοποιούνται συχνά σε επιχειρηματικές εφαρμογές όταν απαιτείται ένας σταθερός αριθμός δεκαδικών ψηφίων. Η ABAP διαθέτει επίσης δεκαδικούς αριθμούς κινητής υποδιαστολής (`decfloat16` και `decfloat34`) και δυαδικούς αριθμούς κινητής υποδιαστολής (`f`). Οι δυαδικοί αριθμοί κινητής υποδιαστολής μπορεί να είναι χρήσιμοι για επιστημονικούς υπολογισμούς, αλλά δεν είναι καλή προεπιλογή για παραδείγματα που αφορούν χρήματα, επειδή πολλά δεκαδικά κλάσματα δεν μπορούν να αναπαρασταθούν με ακρίβεια.
