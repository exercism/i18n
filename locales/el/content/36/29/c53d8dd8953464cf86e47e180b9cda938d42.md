# Σχετικά

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] χρησιμοποιούνται για τη σύγκριση τιμών και επιστρέφουν μια τιμή `true` ή `false`.
Αυτοί οι τελεστές απαιτούν οι 2 τιμές που συγκρίνονται να είναι του ίδιου τύπου.
Αν οι τιμές δεν είναι του ίδιου τύπου, ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Ακολουθεί μια λίστα με τους τελεστές σύγκρισης και ένα παράδειγμα για το πότε δίνουν τιμή `true`:

| Μέθοδος | Περιγραφή           | Παράδειγμα |
| ------ | --------------------- | ------- |
| ==     | ίσο                 | 1 == 1  |
| !=     | όχι ίσο             | 1 != 2  |
| <      | μικρότερο από            | 4 < 5   |
| <=     | μικρότερο ή ίσο    | 4 <= 4  |
| >      | μεγαλύτερο από          | 3 > 1   |
| >=     | μεγαλύτερο ή ίσο | 2 >= 2  |

## Εντολές if και else

Μια [εντολή υπό συνθήκη][conditional-statement] σου επιτρέπει να εκτελέσεις κώδικα με βάση μια συνθήκη που είναι είτε `true` είτε `false`.
Η πιο βασική εντολή υπό συνθήκη είναι η [εντολή `if`][if], η οποία εκτελεί κώδικα όταν η συνθήκη είναι `true`.
Για να δηλώσεις μια εντολή `if`, χρησιμοποιείς τη λέξη-κλειδί `if`, ακολουθούμενη από τη συνθήκη και μετά τον κώδικα που θα εκτελεστεί μέσα σε άγκιστρα.

```swift
let wheelCount = 4
if wheelCount == 4 {
  print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Η `if` μπορεί να συνδυαστεί με την `else` για να εκτελέσει κώδικα όταν η συνθήκη είναι `false`.
Η εντολή `else` πρέπει να χρησιμοποιείται μαζί με μια εντολή `if` και δεν μπορεί να χρησιμοποιηθεί μόνη της.
Για να δηλώσεις μια εντολή `else`, χρησιμοποιείς τη λέξη-κλειδί `else` μετά τα άγκιστρα μιας εντολής `if`, ακολουθούμενη από τον κώδικα που θα εκτελεστεί μέσα σε άγκιστρα.

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
  print("You will need an umbrella")
} else {
  print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Οι εντολές `if` μπορούν επίσης να αλυσωθούν μεταξύ τους με `else if` για να ελεγχθούν πολλαπλές συνθήκες.
Ακολουθεί την ίδια αρχή με τη δήλωση μιας εντολής `if`, αλλά η λέξη-κλειδί είναι `else if` αντί για `if`.
Μια εντολή `if` δεν χρειάζεται εντολή `else` για να είναι έγκυρη, αλλά μπορεί να έχει μία αν χρειάζεται.

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Έκφραση if

Οι εντολές `if` μπορούν επίσης να χρησιμοποιηθούν ως εκφράσεις για να αναθέσεις μια τιμή σε μια μεταβλητή.
Η τελευταία εντολή στο μπλοκ `if` χρησιμοποιείται ως η τιμή της έκφρασης `if`.
Αυτό μπορεί να είναι χρήσιμο όταν θέλεις να αναθέσεις μια τιμή σε μια μεταβλητή με βάση μια συνθήκη.

```swift
let CpuBits = 32
let largest = if CpuBits == 64 {
  "x86_64"
} else {
  "x86_32"
}

print(largest)
// Prints "x86_32"
```
