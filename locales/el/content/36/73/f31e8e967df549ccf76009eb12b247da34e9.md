# Εισαγωγή

Η Julia, όπως οι περισσότερες γλώσσες προγραμματισμού, παρέχει μια πλούσια ποικιλία τύπων συλλογών.

Κάποιες είναι εγγενώς διατεταγμένες (όπως τα `Vectors` και οι `Arrays` μεγαλύτερης διάστασης), οπότε μπορούμε να προσπελάσουμε τα στοιχεία τους με βάση τη θέση.
Άλλες συλλογές δεν έχουν σειρά (`Sets`, `Dicts`) και τα στοιχεία τους πρέπει να προσπελαύνονται με κλειδί ή τιμή.

Στην πιο απλή περίπτωση, ας υποθέσουμε ότι έχουμε ένα `Vector` από `Ints` και θέλουμε να το ταξινομήσουμε σε αύξουσα σειρά.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Απλό!
Η συνάρτηση `sort()` έχει προφανές όνομα και, όπως φαίνεται, επιστρέφει τον ταξινομημένο `Vector`.

_Πλάκα κάνω!_
Σε αυτό το σημείο της ύλης, ίσως υποψιάζεσαι (σωστά) ότι υπάρχουν αποχρώσεις που πρέπει να συζητήσουμε.

## Συναρτήσεις που μεταλλάσσουν εναντίον συναρτήσεων που δεν μεταλλάσσουν

Αφού τρέξεις το `sort(v)`, τι είναι το `v`;

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

Το αρχικό διάνυσμα παραμένει αμετάβλητο.
Η `sort()` είναι μια συνάρτηση που ***δεν μεταλλάσσει*** την είσοδό της: επιστρέφει ένα _αντίγραφο_ της.

Αυτός είναι καλός σχεδιασμός σε πολλά πλαίσια: έχουμε μια [καθαρή συνάρτηση][wiki-pure-func] της οποίας η συμπεριφορά είναι εύκολο να αναλυθεί, ακόμη και σε παράλληλο, κατανεμημένο κώδικα.

Από την άλλη, ας υποθέσουμε ότι έχουμε έναν πίνακα με ένα δισεκατομμύριο συμβολοσειρές και θέλουμε να τον ταξινομήσουμε.

Η ταξινόμηση πιθανότατα είναι αργή.
Επιπλέον, πρέπει να αντιγράψουμε τα πάντα (_αργό!_) και να δεσμεύσουμε αρκετή μνήμη (_αρκετά Gigabyte!_) για να αποθηκεύσουμε το αντίγραφο.

Σύγκρινε με αυτόν τον αρκετά παρόμοιο κώδικα:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Τώρα ο `Vector` εισόδου ταξινομείται επιτόπου, χωρίς αντιγραφή, και η αρχική σειρά χάνεται οριστικά.

Αυτό μπορεί να είναι αποδοτικό, μπορεί να έχει bugs και να οδηγήσει σε απρόσμενες παρενέργειες, μπορεί να μπερδέψει άλλους που χρησιμοποιούν τον κώδικά σου.
_Διάλεξε προσεκτικά!_

Η `sort!()` είναι μια "συνάρτηση που μεταλλάσσει", και κατά (_πολύ ισχυρή_) σύμβαση, κάθε συνάρτηση που μεταλλάσσει τις εισόδους της έχει ένα `!` στο τέλος του ονόματός της, ως προειδοποίηση προς τους προγραμματιστές.

## Με βάση τι ταξινομούμε;

Η ταξινόμηση τιμών `Int64` είναι σχετικά απλή: ακόμη και μικρά παιδιά καταλαβαίνουν ότι το 2 είναι μεγαλύτερο από το 1 και μικρότερο από το 3.

Άλλοι τύποι μπορεί να είναι πιο πολύπλοκοι, αλλά γενικά ισχύει `x < y` αν `isless(x, y) == true`.
Η Julia παρέχει υλοποιήσεις της `isless()` για τους περισσότερους βασικούς τύπους.

Για παράδειγμα, οι χαρακτήρες Unicode (για τα ευρωπαϊκά γράμματα, τα κεφαλαία ταξινομούνται πριν από τα πεζά):

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

Μπορούμε επίσης να εφαρμόσουμε οποιαδήποτε αυθαίρετη συνάρτηση στα στοιχεία πριν από την ταξινόμηση, όπως την `abs` για να αγνοήσουμε το πρόσημο ή την `uppercase` για ταξινόμηση που δεν ξεχωρίζει πεζά από κεφαλαία:

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

## Πίνακας θέσεων ταξινόμησης

Αν τα στοιχεία που ταξινομούνται είναι μεγάλα αντικείμενα, μπορεί να είναι πιο εύκολο να δουλέψεις με τη θέση τους.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Επειδή το `langs` είναι ένας Vector, κάθε θέση είναι ένας ακέραιος στο [διάστημα][concept-range] `1:length(langs)`.
Η έξοδος της `sortperm()` είναι μια [μετάθεση][wiki-permutation] αυτών των ακεραίων, που αντιστοιχεί σε μια ταξινόμηση του διανύσματος εισόδου.

## Μερική ταξινόμηση

Χρειάζεται το πρόγραμμά σου να ταξινομηθεί ολόκληρη η είσοδος;
Σε περιπτώσεις όπου μας ενδιαφέρουν μόνο οι πρώτες ή οι τελευταίες λίγες καταχωρήσεις, μπορεί να είναι σημαντικά πιο γρήγορο να κάνεις μια [μερική ταξινόμηση][wiki-partial-sort].

Η Julia παρέχει τις συναρτήσεις `partialsort()` και `partialsort!()`, οι οποίες εγγυώνται ότι η συγκεκριμένη καταχώρηση ή περιοχή καταχωρήσεων είναι σωστή, αλλά δεν δίνουν καμία εγγύηση για το υπόλοιπο της εισόδου.

Το δεύτερο όρισμα μπορεί να είναι είτε ακέραιος είτε διάστημα, που αντιπροσωπεύει τη θέση ή τις θέσεις της ταξινομημένης εισόδου:

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```
