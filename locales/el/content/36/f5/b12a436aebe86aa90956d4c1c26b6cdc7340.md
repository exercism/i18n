# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                               |
| -------- | --------- | ------- | --------------------------------------- |
| `$a0`    | είσοδος   | διεύθυνση | συμβολοσειρά τριαδικών χαρακτήρων τερματισμένη με null |
| `$v0`    | έξοδος    | ακέραιος | δεκαδική τιμή της συμβολοσειράς εισόδου |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
