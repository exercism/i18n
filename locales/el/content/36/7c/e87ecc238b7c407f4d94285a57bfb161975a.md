# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος στον φούρνο σε λεπτά

- Πρέπει να αναθέσεις τη σωστή τιμή στη σταθερά `$EXPECTED-MINUTES-IN-OVEN`.

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Μπορείς να αφαιρέσεις αριθμούς μεταξύ τους χρησιμοποιώντας τον [ενδιάθετο τελεστή `-`][&infix:<->].

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Μπορείς να πολλαπλασιάσεις αριθμούς χρησιμοποιώντας τους [ενδιάθετους τελεστές `*` ή `×`][&infix:<*>].

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Μπορείς να καλέσεις άλλες συναρτήσεις που έχουν οριστεί και ίσως σου φανούν χρήσιμες, π.χ. `function($arg)`.
- Μπορείς να προσθέσεις αριθμούς μεταξύ τους χρησιμοποιώντας τον [ενδιάθετο τελεστή `+`][&infix:<+>].

## 5. Δημιούργησε μια ειδοποίηση ότι οι λαζάνιες είναι έτοιμες

- Μπορείς να δημιουργήσεις μια συμβολοσειρά περικλείοντας κείμενο είτε σε απλά `'foo'` είτε σε διπλά `"bar"` εισαγωγικά.
  Δες τις [Δομές εισαγωγικών][quoting].

[&infix:<+>]: https://docs.raku.org/language/operators#infix_+
[&infix:<*>]: https://docs.raku.org/language/operators#infix_*
[&infix:<->]: https://docs.raku.org/language/operators#infix_-
[quoting]: https://docs.raku.org/language/quoting
