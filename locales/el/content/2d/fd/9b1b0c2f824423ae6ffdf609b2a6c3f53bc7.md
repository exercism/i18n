# Οδηγίες

Δουλεύεις πάνω σε ένα παιχνίδι που προορίζεται για ένα ενσωματωμένο σύστημα χαμηλής κατανάλωσης και πρέπει να γράψεις μερικές βοηθητικές συναρτήσεις που θα χρησιμοποιηθούν από άλλα μέρη του παιχνιδιού.

## 1. Υπολόγισε το πηλίκο και το υπόλοιπο μιας διαίρεσης

Το πηλίκο είναι το αποτέλεσμα μιας διαίρεσης.

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

Παράδειγμα:

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. Διάλεξε τα στοιχεία σε άρτιες θέσεις από έναν iterator

Αυτό θα βοηθήσει να ενεργοποιήσεις μια βελτιστοποίηση του buffer οθόνης, όπως υπόσχεται το αφεντικό σου.

Οι iterator είναι στοιχεία που εκθέτουν τις μεθόδους που ορίζει το [`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html). Αυτή η τεκμηρίωση είναι αρκετά εκτενής, γιατί προσφέρουν πολλές μεθόδους. Ακολουθούν τα πιο σχετικά χαρακτηριστικά:

- Ένας iterator είναι μια ροή στοιχείων αυθαίρετου μήκους
- Έχουν μια [μέθοδο `enumerate`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate) που επιστρέφει μια πλειάδα `(i, val)` για κάθε τιμή
- Έχουν μια [μέθοδο `filter`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter) που χρησιμοποιεί ένα closure για να καθορίσει αν θα αποδώσει ένα στοιχείο του iterator
- Έχουν μια [μέθοδο `map`](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map) που χρησιμοποιεί ένα closure για να τροποποιήσει τα στοιχεία του iterator

Επειδή η συνάρτησή σου μπορεί να τρέξει σε οποιοδήποτε είδος iterator, χρησιμοποιεί το `impl` για να δηλώσει ότι πρόκειται για ένα στιγμιότυπο ενός trait και όχι για ένα απλό στοιχείο. Παρομοίως, η σύνταξη `<Item=T>` σημαίνει απλώς ότι δεν έχει σημασία τι είδους στοιχείο παράγει ο iterator. Η συνάρτησή σου μπορεί να παράγει τα άρτια στοιχεία οποιουδήποτε iterator.

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

Παραδείγματα:

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. Υπολόγισε την απόσταση manhattan μιας θέσης από την αρχή των αξόνων

Για ευκολία στην αντιστοίχιση, έχεις ένα tuple struct `Position`:

```rust
struct Position(i16, i16);
```

Πρέπει να υλοποιήσεις μια μέθοδο `manhattan` στο `Position` που επιστρέφει την [απόσταση manhattan](https://en.wikipedia.org/wiki/Taxicab_geometry) αυτής της θέσης από την αρχή των αξόνων (`Position(0, 0)`).

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

Παράδειγμα:

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
