# Σχετικά

Η Swift παρέχει εντολές μεταβίβασης ελέγχου για να αλλάζεις τη ροή εκτέλεσης των βρόχων και των εντολών switch.
Εκτός από το `return`, η Swift περιλαμβάνει τα `continue`, `break`, τις ετικέτες βρόχων και το `fallthrough`.

## Continue

Η εντολή `continue` λέει σε έναν βρόχο να σταματήσει να εκτελεί την τρέχουσα επανάληψη και να ξεκινήσει αμέσως την επόμενη.
Σε έναν βρόχο `while` ή `repeat-while`, μεταπηδά κατευθείαν στον έλεγχο της συνθήκης.
Σε έναν βρόχο `for-in`, προχωρά στο επόμενο στοιχείο της ακολουθίας.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

Η εντολή `break` τερματίζει αμέσως ολόκληρο τον βρόχο ή την εντολή switch.
Η εκτέλεση συνεχίζεται από την πρώτη γραμμή κώδικα μετά τον βρόχο ή την εντολή switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Εντολές με ετικέτες

Σε εμφωλευμένους βρόχους, μπορεί να θέλεις το `break` ή το `continue` να επηρεάζει έναν εξωτερικό βρόχο και όχι τον πιο εσωτερικό.
Μπορείς να βάλεις ετικέτα σε έναν βρόχο γράφοντας μπροστά του ένα όνομα και άνω και κάτω τελεία (`labelName:`).
Στη συνέχεια, μπορείς να περάσεις αυτή την ετικέτα στο `break` ή στο `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

Στη Swift, οι εντολές `switch` δεν περνούν στο επόμενο case από προεπιλογή· η εκτέλεση σταματά αυτόματα στο τέλος του case που αντιστοιχίστηκε.
Αν θέλεις ρητά η εκτέλεση να συνεχίσει στο επόμενο case χωρίς να αξιολογηθεί το μοτίβο του, χρησιμοποίησε τη λέξη-κλειδί `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
