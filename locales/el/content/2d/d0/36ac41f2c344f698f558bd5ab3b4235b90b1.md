# Οδηγίες

Βοηθάς σε μια έρευνα για τα πουλιά. Κάθε μέρα κάποιος κάθεται σε μια κρυψώνα και μετράει ό,τι περνάει πετώντας, και οι μετρήσεις της ημέρας επιστρέφουν ως πίνακας.

Και οι πέντε εργασίες μπαίνουν στην κλάση `BIRD_SURVEY`.

## 1. Το σύνολο

Άθροισε τη μέτρηση κάθε ημέρας.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Μια έρευνα χωρίς καθόλου μέρες μετράει μηδέν πουλιά.

## 2. Η καλύτερη μέρα

Επίστρεψε τη μεγαλύτερη μέτρηση. Αν δεν υπήρχαν μέρες, η απάντηση είναι μηδέν.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Οι μέρες με πολλά πουλιά

Πόσες μέρες είχαν μέτρηση πάνω από κάποιον αριθμό;

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Το "πάνω από" σημαίνει πάνω από: μια μέτρηση ακριβώς 2 δεν προσμετράται.

## 4. Κρυψώνες για έλεγχο

Την πρώτη μέρα της έρευνας ελέγχεις μία κρυψώνα, τη δεύτερη μέρα δύο, και ούτω καθεξής. Πόσοι έλεγχοι κρυψώνας γίνονται συνολικά;

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Δηλαδή 1 + 2 + 3 + 4.

## 5. Η πρώτη μέρα με πολλά πουλιά

Ποια μέρα ήταν η πρώτη με μέτρηση πάνω από κάποιον αριθμό; Οι μέρες αριθμούνται από το μηδέν, όπως οι θέσεις στον πίνακα. Αν καμία μέρα δεν είχε τόσο πολλά πουλιά, η απάντηση είναι `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
