# Σχετικά

Ο τελεστής `|>` ονομάζεται [τελεστής pipe][pipe]. Μπορείς να τον χρησιμοποιήσεις για να συνδέσεις σε αλυσίδα κλήσεις συναρτήσεων με τέτοιον τρόπο ώστε η τιμή επιστροφής της προηγούμενης κλήσης συνάρτησης να περνά ως πρώτο όρισμα στην επόμενη κλήση συνάρτησης.

```elixir
String.replace_suffix(String.upcase(String.duplicate("go ", 3)), " ", "!")

# versus

"go "
|> String.duplicate(3)
|> String.upcase()
|> String.replace_suffix(" ", "!")
```

Μπορείς επίσης να τον χρησιμοποιήσεις σε μία μόνο γραμμή:

```elixir
"go " |> String.duplicate(3) |> String.upcase() |> String.replace_suffix(" ", "!")
```

Οι συναρτήσεις του `Kernel` συνήθως χρησιμοποιούνται παντού χωρίς το όνομα του module `Kernel`, αλλά το όνομα του module χρειάζεται όταν χρησιμοποιείς αυτές τις συναρτήσεις σε μια αλυσίδα pipe. Για παράδειγμα, το `2 * 3 == 6` μπορεί επίσης να γραφτεί ως:

```elixir
2 |> Kernel.*(3) |> Kernel.==(6)
```

Είναι θέμα προσωπικής προτίμησης το πότε να χρησιμοποιείς τον τελεστή pipe και πότε όχι. Μερικοί προγραμματιστές της Elixir συνηθίζουν να ακολουθούν αυτούς τους κανόνες:

- Μη χρησιμοποιείς τον τελεστή pipe όταν κάνεις μία μόνο κλήση συνάρτησης.

  ```elixir
  # do
  String.split("hello", "")

  # don't
  "hello" |> String.split("")
  ```

- Μη δημιουργείς ανώνυμες συναρτήσεις απευθείας μέσα στην αλυσίδα pipe.

  ```elixir
  # do
  take_n_letters = fn n -> Enum.take(?a..?z, n) end
  2 |> Kernel.*(3) |> take_n_letters.()

  # don't
  2 |> Kernel.*(3) |> (fn n -> Enum.take(?a..?z, n) end).()
  ```

- Ξεκίνα πάντα μια αλυσίδα pipe με μια μεταβλητή ή μια τιμή literal, όχι με κλήση συνάρτησης.

  ```elixir
  # do
  "hello" |> String.upcase() |> String.split("")

  # don't
  String.upcase("hello") |> String.split("")
  ```

[pipe]: https://hexdocs.pm/elixir/Kernel.html#%7C%3E/2
