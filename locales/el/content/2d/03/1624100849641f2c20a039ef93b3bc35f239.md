# Γραφείο Σχεδιασμού Ιστού

## Ιστορία

Η εταιρεία σχεδιασμού σου έχει δουλέψει κυρίως με μετασχηματισμούς CSS για να φτιάχνει ιστοσελίδες. Έπειτα από κάποια συζήτηση, παίρνετε την απόφαση να αρχίσετε να χρησιμοποιείτε τη JavaScript για να εκτελείτε δυναμικά κάποιους από τους υπολογισμούς. Κάποιοι από τους συμπαίκτες σου έχουν λιγότερη εμπειρία με τη JavaScript, οπότε αποφασίζεις να χρησιμοποιήσεις ένα closure συνάρτησης για να δημιουργήσεις έναν επαναχρησιμοποιήσιμο μετασχηματισμό για ζεύγη συντεταγμένων `{x, y}`.

## Εργασίες

- Δημιούργησε μια συνάρτηση της οποίας τα ορίσματα χρησιμοποιούνται ως closure σε μια συνάρτηση που επιστρέφεται.

  - Μια συνάρτηση για δισδιάστατη μετατόπιση, όπου η εξωτερική συνάρτηση καθορίζει το ποσό της μετατόπισης, και η συνάρτηση που επιστρέφεται δέχεται μια συντεταγμένη x, y και επιστρέφει τις μετατοπισμένες συντεταγμένες.
  - Μια συνάρτηση για δισδιάστατη κλιμάκωση, όπου η εξωτερική συνάρτηση καθορίζει το ποσό της κλιμάκωσης, και η συνάρτηση που επιστρέφεται δέχεται μια συντεταγμένη x, y και επιστρέφει τις μετατοπισμένες συντεταγμένες.
  - Μια συνάρτηση που επιστρέφει μια συνάρτηση που συνθέτει δύο συναρτήσεις, στην ουσία μια συνάρτηση για `g(f(x))`

- Δημιούργησε μια συνάρτηση που κάνει memoize μια συνάρτηση.
