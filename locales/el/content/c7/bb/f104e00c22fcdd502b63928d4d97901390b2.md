# Εισαγωγή

Η Julia, όπως οι περισσότερες γλώσσες προγραμματισμού, παρέχει μια πλούσια ποικιλία τύπων συλλογών.

Κάποιες έχουν εκ φύσεως σειρά (όπως τα `Vectors` και τα πολυδιάστατα `Arrays`), οπότε μπορούμε να προσπελάσουμε τα στοιχεία τους με βάση τη θέση.
Άλλες συλλογές δεν έχουν σειρά (`Sets`, `Dicts`) και τα στοιχεία τους πρέπει να προσπελαύνονται με κλειδί ή τιμή.

Στην απλούστερη περίπτωση, ας υποθέσουμε ότι έχουμε ένα `Vector` από `Ints` και θέλουμε να το ταξινομήσουμε σε αύξουσα σειρά.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Απλό!
Η συνάρτηση `sort()` έχει προφανές όνομα και, όπως φαίνεται, επιστρέφει τον ταξινομημένο `Vector`.

_Πλάκα κάνω!_
Σε αυτό το σημείο του προγράμματος σπουδών, ίσως υποψιάζεσαι (σωστά) ότι υπάρχουν αποχρώσεις που πρέπει να συζητήσουμε.

## Τροποποιητικές εναντίον μη τροποποιητικών συναρτήσεων

Αφού τρέξεις το `sort(v)`, τι είναι το `v`;

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

Το αρχικό διάνυσμα παραμένει αμετάβλητο.
Η `sort()` είναι μια ***μη τροποποιητική*** συνάρτηση που επιστρέφει ένα _αντίγραφο_ της εισόδου της.

Αυτός είναι καλός σχεδιασμός σε πολλά πλαίσια: έχουμε μια καθαρή συνάρτηση της οποίας η συμπεριφορά είναι εύκολο να αναλυθεί, ακόμη και σε παράλληλο, κατανεμημένο κώδικα.

Από την άλλη, ας υποθέσουμε ότι είχαμε έναν πίνακα με ένα δισεκατομμύριο συμβολοσειρές και θέλαμε να τον ταξινομήσουμε.

Η ταξινόμηση είναι πιθανώς αργή.
Επιπλέον, πρέπει να αντιγράψουμε τα πάντα (_αργό!_) και να δεσμεύσουμε αρκετή μνήμη (_αρκετά Gigabyte!_) για να αποθηκεύσουμε το αντίγραφο.

Σύγκρινε αυτόν τον αρκετά παρόμοιο κώδικα:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Τώρα ο `Vector` εισόδου ταξινομείται επιτόπου, χωρίς αντιγραφή, και η αρχική σειρά χάνεται οριστικά.

Αυτό μπορεί να είναι αποδοτικό, μπορεί να έχει bugs και να οδηγήσει σε απροσδόκητες παρενέργειες, μπορεί να μπερδέψει άλλους που χρησιμοποιούν τον κώδικά σου.
_Διάλεξε προσεκτικά!_

Η `sort!()` είναι μια "τροποποιητική συνάρτηση" και, κατά (_πολύ ισχυρή_) σύμβαση, κάθε συνάρτηση που τροποποιεί τα ορίσματά της έχει ένα `!` στο τέλος του ονόματός της, ως προειδοποίηση για τους προγραμματιστές.

## Πίνακας θέσεων ταξινόμησης

Αν τα στοιχεία που ταξινομούνται είναι μεγάλα αντικείμενα, μπορεί να είναι ευκολότερο να δουλέψεις με τη θέση τους.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Επειδή το `langs` είναι `Vector`, κάθε θέση είναι ένας ακέραιος στο διάστημα `1:length(langs)`.
Η έξοδος της `sortperm()` είναι μια μετάθεση αυτών των ακεραίων, που αντιστοιχεί σε μια ταξινόμηση του διανύσματος εισόδου.
