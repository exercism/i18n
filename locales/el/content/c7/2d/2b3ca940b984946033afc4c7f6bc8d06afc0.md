# Προσθήκη στις οδηγίες

Στη διαδρομή Python, αυτή η άσκηση σου ζητά να δημιουργήσεις μια _κλάση_ `SpaceAge` (_[concept:python/classes]()_) που περιλαμβάνει μεθόδους για όλους τους πλανήτες του ηλιακού συστήματος.
Οι μέθοδοι πρέπει να ακολουθούν τη σύμβαση ονομασίας `on_<planet name>`.

Κάθε μέθοδος πρέπει να `return` την ηλικία (_"στον" συγκεκριμένο πλανήτη_) σε χρόνια, στρογγυλοποιημένη σε δύο δεκαδικά ψηφία:

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
