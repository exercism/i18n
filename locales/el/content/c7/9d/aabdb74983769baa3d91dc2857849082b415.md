# Οδηγίες

Σε αυτή την άσκηση είναι η ημέρα του Αγίου Βαλεντίνου και σχεδιάζεις τι θα κάνεις με το ταίρι σου.
Το ταίρι σου έχει πολλές ιδέες και σου ζητά να τις βαθμολογήσεις, για να βρείτε την καλύτερη δραστηριότητα.

Το ταίρι σου προτείνει τις παρακάτω ιδέες:

- Να παίξεις ένα επιτραπέζιο παιχνίδι
- Να χαλαρώσεις
- Να δεις μια ταινία
- Να πας σε εστιατόριο
- Να κάνεις μια βόλτα

Έχεις έξι εργασίες που θα σε βοηθήσουν να επιλέξεις τη δραστηριότητα της ημέρας του Αγίου Βαλεντίνου.

## 1. Όρισε την έγκριση

Για κάθε ιδέα που προτείνει το ταίρι σου, απαντάς με μία από τρεις επιλογές: yes, no ή maybe.

Όρισε τον αλγεβρικό τύπο δεδομένων `Approval` για να αναπαραστήσεις αυτές τις επιλογές με τις εξής τρεις περιπτώσεις: `Yes`, `No` ή `Maybe`.

## 2. Όρισε τις κουζίνες

Το ταίρι σου έχει επιλέξει δύο πιθανά εστιατόρια: ένα με κορεάτικη κουζίνα και ένα με τουρκική κουζίνα.

Όρισε τον αλγεβρικό τύπο δεδομένων `Cuisine` για να αναπαραστήσεις αυτά τα εστιατόρια με τις εξής δύο περιπτώσεις: `Korean` ή `Turkish`.

## 3. Όρισε τα είδη ταινιών

Υπάρχουν πάρα πολλές ταινίες για να διαλέξεις, οπότε, για να στενέψει ο κύκλος, το ταίρι σου αναφέρει και το αγαπημένο του είδος.

Όρισε τον αλγεβρικό τύπο δεδομένων `Genre` για να αναπαραστήσεις τις εξής περιπτώσεις ειδών: `Crime`, `Horror`, `Romance` ή `Thriller`.

## 4. Όρισε τη δραστηριότητα

Όπως αναφέρθηκε, το ταίρι σου έχει σκεφτεί πέντε πιθανές δραστηριότητες: να παίξεις ένα επιτραπέζιο παιχνίδι, να χαλαρώσεις, να δεις μια ταινία, να πας σε εστιατόριο και να κάνεις μια βόλτα.

Όρισε τον αλγεβρικό τύπο δεδομένων `Activity` για να αναπαραστήσεις αυτούς τους τύπους δραστηριοτήτων:

- `BoardGame`: χωρίς συσχετισμένα δεδομένα.
- `Chill`: χωρίς συσχετισμένα δεδομένα.
- `Movie`: έχει το `Genre` του ως συσχετισμένα δεδομένα.
- `Restaurant`: έχει το `Cuisine` του ως συσχετισμένα δεδομένα.
- `Walk`: έχει ένα `Int` που αντιπροσωπεύει τον αριθμό των χιλιομέτρων που θα περπατήσεις ως συσχετισμένα δεδομένα.

## 5. Βαθμολόγησε τη δραστηριότητα

Επιτέλους, είσαι έτοιμος να βαθμολογήσεις τις ιδέες του ταιριού σου.
Να πώς νιώθεις για την κάθε ιδέα του ταιριού σου:

- Να παίξεις ένα επιτραπέζιο παιχνίδι: no.
- Να χαλαρώσεις: no.
- Να δεις μια ταινία: yes αν είναι ρομαντική ταινία· αλλιώς, no.
- Να πας σε εστιατόριο: yes αν η κουζίνα είναι κορεάτικη, maybe αν είναι τουρκική.
- Να κάνεις μια βόλτα: yes αν η βόλτα είναι λιγότερο από τρία χιλιόμετρα· maybe αν είναι μεταξύ τριών και πέντε χιλιομέτρων (συμπεριλαμβανομένων)· αλλιώς, no.

Υλοποίησε μια συνάρτηση με όνομα `rateActivity` που παίρνει μια τιμή `Activity` και επιστρέφει το `Approval` με βάση τα παραπάνω συναισθήματα.
Για παράδειγμα:

```haskell
rateActivity (Restaurant Turkish)
-- -> Maybe
```
