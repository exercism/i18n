## Επεξεργαστές κώδικα

### Δωρεάν/Ανοιχτού κώδικα

- [VS Code](https://code.visualstudio.com)

  Το VS Code είναι ένας επεξεργαστής κώδικα ανοιχτού κώδικα. Μπορείς να βρεις πληροφορίες για το πώς να ρυθμίσεις το TypeScript [εδώ](https://code.visualstudio.com/docs/languages/typescript). Το VS Code είναι ένας δημοφιλής επεξεργαστής για TypeScript, επειδή η Microsoft συντηρεί και το VS Code και το TypeScript, οπότε δουλεύει καλά με τη γλώσσα. Το VS Code υποστηρίζει TS χωρίς καμία επιπλέον ρύθμιση. Μάλιστα, το VS Code είναι γραμμένο σε TypeScript!

  Ένα συχνό πρόβλημα με το VS Code και το TS είναι όταν η έκδοση του επεξεργαστή σου και η έκδοση του project σου είναι διαφορετικές, κάτι που μπορεί να κάνει το VS Code να εμφανίσει ένα μήνυμα σφάλματος που ίσως σε μπερδέψει. Οδηγίες για το πώς να χειριστείς αυτό το σφάλμα υπάρχουν [εδώ](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions).

### Με άδεια χρήσης

- [Sublime Text](https://www.sublimetext.com)

  Το Sublime Text είναι ένας δημοφιλής επεξεργαστής κώδικα με υποστήριξη για τις περισσότερες γλώσσες μέσω plugins που μπορείς να εγκαταστήσεις. Είναι δωρεάν για δοκιμή, αλλά θα σου ζητείται τακτικά να αγοράσεις μια άδεια, η οποία αυτή τη στιγμή κοστίζει 70 δολάρια ΗΠΑ.

- [WebStorm](https://www.jetbrains.com/webstorm/)

  Το WebStorm είναι ένα πλήρως εξοπλισμένο IDE (Ολοκληρωμένο Περιβάλλον Ανάπτυξης) για JavaScript/TypeScript. Υποστηρίζει TypeScript χωρίς καμία επιπλέον ρύθμιση και διαθέτει ενσωματωμένες δοκιμές, αποσφαλμάτωση και ανάλυση κώδικα. Είναι δωρεάν για δοκιμή για 30 ημέρες και μετά μια ετήσια άδεια κοστίζει 129 δολάρια ΗΠΑ τον πρώτο χρόνο.
