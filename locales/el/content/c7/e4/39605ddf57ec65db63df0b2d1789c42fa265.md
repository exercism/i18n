# Οδηγίες

Θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με το μαγείρεμα της συνταγής σου.

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο σε λεπτά

Όρισε τη σταθερά `$EXPECTED-MINUTES-IN-OVEN` με τον αριθμό των λεπτών που θα πρέπει να μείνουν τα λαζάνια στο φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο σε λεπτά είναι 40:

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στο φούρνο σε λεπτά

Τροποποίησε την υπορουτίνα `remaining-minutes-in-oven`, η οποία δέχεται ως όρισμα τα πραγματικά λεπτά που βρίσκονται τα λαζάνια στο φούρνο, ώστε να επιστρέφει πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στο φούρνο, με βάση τον αναμενόμενο χρόνο στο φούρνο σε λεπτά από την προηγούμενη εργασία.

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Τροποποίησε την υπορουτίνα `preparation-time-in-minutes`, η οποία δέχεται ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια, ώστε να επιστρέφει πόσα λεπτά σου πήρε για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση θέλει 2 λεπτά προετοιμασίας.

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Τροποποίησε την υπορουτίνα `total-time-in-minutes` που δέχεται δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια, και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που βρίσκονται τα λαζάνια στο φούρνο.
Η υπορουτίνα θα πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα των λαζανιών, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στο φούρνο αυτή τη στιγμή.

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

Τροποποίησε την υπορουτίνα `oven-alarm`, η οποία δε δέχεται κανένα όρισμα, ώστε να επιστρέφει ένα μήνυμα που να δηλώνει ότι τα λαζάνια είναι έτοιμα να φαγωθούν.

```raku
oven-alarm()
# => 'Ding!'
```
