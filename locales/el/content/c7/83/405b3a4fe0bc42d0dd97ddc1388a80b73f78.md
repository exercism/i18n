# Προσάρτημα οδηγιών

Μπορείς να επιστρέψεις τα σαγματικά σημεία με οποιαδήποτε σειρά.

## Υποδείξεις

Για αυτή την άσκηση, θα χρειαστεί να δημιουργήσεις ένα σύνολο παραγόντων χρησιμοποιώντας πλειάδες.
Για περισσότερες πληροφορίες σχετικά με τις πλειάδες, δες [πλειάδες][tuples].

[tuples]: https://docs.microsoft.com/en-us/dotnet/api/system.tuple
