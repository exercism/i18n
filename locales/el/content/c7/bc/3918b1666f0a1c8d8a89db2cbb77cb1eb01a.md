# Εισαγωγή

Στη Java, η υπερφόρτωση μεθόδων είναι ένα χαρακτηριστικό που επιτρέπει σε μια κλάση να έχει περισσότερες από μία μεθόδους με το ίδιο όνομα, εφόσον οι λίστες παραμέτρων τους είναι διαφορετικές.
Σχετίζεται με τον πολυμορφισμό κατά τον χρόνο μεταγλώττισης (ή στατικό πολυμορφισμό).
Αυτή η έννοια είναι κρίσιμη για τη
δημιουργία μεθόδων που εκτελούν παρόμοιες εργασίες αλλά δέχονται διαφορετικά δεδομένα εισόδου.

## Γιατί να υπερφορτώνουμε μεθόδους;

Η υπερφόρτωση μεθόδων αυξάνει την αναγνωσιμότητα του προγράμματος.
Διαφορετικές μέθοδοι μπορούν να έχουν το ίδιο όνομα αλλά
διαφορετικές παραμέτρους.
Ανάλογα με τον αριθμό των παραμέτρων ή τον τύπο τους, καλείται η αντίστοιχη μέθοδος.

## Πώς να υπερφορτώσουμε μεθόδους;

Το κλειδί για την υπερφόρτωση μεθόδων είναι η υπογραφή της μεθόδου.
Δύο μέθοδοι θεωρούνται διαφορετικές αν έχουν διαφορετικές υπογραφές.
Υπάρχουν δύο τρόποι να υπερφορτώσεις μια μέθοδο:

1. **Διαφορετικός αριθμός παραμέτρων**: Οι μέθοδοι μπορούν να έχουν το ίδιο όνομα αλλά διαφορετικό αριθμό παραμέτρων.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **Διαφορετικοί τύποι παραμέτρων**: Οι μέθοδοι μπορούν να έχουν το ίδιο όνομα και τον ίδιο αριθμό παραμέτρων αλλά με
   διαφορετικούς τύπους.

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

## Σημεία που πρέπει να θυμάσαι

- Οι υπερφορτωμένες μέθοδοι πρέπει να αλλάζουν τη λίστα ορισμάτων.
- Οι υπερφορτωμένες μέθοδοι μπορούν επίσης να αλλάζουν τον τύπο επιστροφής, αλλά η αλλαγή μόνο του τύπου επιστροφής δεν
  συνιστά υπερφόρτωση μεθόδων.
- Οι μέθοδοι μπορούν να υπερφορτωθούν στην ίδια κλάση ή σε μια υποκλάση.

Σε αυτή την έννοια, θα εξερευνήσουμε διάφορα παραδείγματα και λεπτομέρειες της υπερφόρτωσης μεθόδων στη Java.
