# Εισαγωγή

[concept:csharp/resource-cleanup]() χρησιμοποιεί τη διεπαφή `IDispose` για να δηλώσει ότι ο πόρος κάποιου αντικειμένου ή άλλη κατάσταση του προγράμματος έπρεπε να αποδεσμευτεί ή να επαναφερθεί όταν το αντικείμενο δεν ήταν πλέον απαραίτητο (και ότι η εξάρτηση από τον garbage collector δεν θα το πετύχαινε αυτό ούτε θα παρείχε το απαιτούμενο επίπεδο ελέγχου) και ότι η μέθοδος `IDisposable.Dispose()` ήταν το φυσικό σημείο για τέτοιες εργασίες καθαρισμού.

Υπάρχει ένας άλλος μηχανισμός, το μπλοκ `using`, που επιτρέπει, από τη σκοπιά του καλούντος, όλη η διαχείριση της διάρκειας ζωής των πόρων να συγκεντρωθεί σε μία μόνο εντολή.

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

Στο παραπάνω παράδειγμα, οι πόροι του συστήματος αρχείων που σχετίζονται με το `file` θα αποδεσμευτούν και θα επιστραφούν στο λειτουργικό σύστημα όταν βγούμε από το μπλοκ `using`.

Για να λειτουργήσει το μοτίβο, η μεταβλητή στην εντολή `using` πρέπει να είναι τύπος αναφοράς που υλοποιεί τη διεπαφή `IDisposable` και πρέπει να αποδεσμεύει πόρους ή να επαναφέρει την κατάσταση του προγράμματος στη μέθοδο `Dispose()`.

Η C# 8 εισάγει μια βελτίωση στο μοτίβο. Μια εντολή `using` μπορεί να τοποθετηθεί στην αρχή ενός μπλοκ.

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Οι προγραμματιστές Java μπορεί να το αναγνωρίσουν ως ανάλογο του μηχανισμού _αυτόματης διαχείρισης πόρων_ που εισήχθη στη Java 7.
