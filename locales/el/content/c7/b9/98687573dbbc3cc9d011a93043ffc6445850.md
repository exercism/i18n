# Υποδείξεις

## Γενικά

- Μπορείς να χρησιμοποιήσεις την [κλάση Random][random-class] για να δημιουργήσεις τυχαίους αριθμούς.
- Διάβασε περισσότερα στο άρθρο: [Random Number Generators in Java 17][random-number-generators].

## Δημιουργία λαβυρίνθου

Μπορείς να χρησιμοποιήσεις οποιονδήποτε αλγόριθμο για να δημιουργήσεις έναν τέλειο λαβύρινθο. Ο [recursive backtracker][recursive-backtracker] είναι καλή επιλογή.
