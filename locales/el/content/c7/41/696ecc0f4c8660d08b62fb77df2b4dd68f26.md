# Πίνακες

Οι πίνακες στην PHP είναι διατεταγμένοι χάρτες.
Ένας χάρτης είναι μια δομή δεδομένων που συσχετίζει ένα κλειδί με μια τιμή.
Οι πίνακες είναι ευέλικτοι και μπορούν να αντιμετωπιστούν ως γραμμικός πίνακας (όπως στη `C` ή στη `Java`), λίστα [διάνυσμα], πίνακας κατακερματισμού, λεξικό, συλλογή, στοίβα ή ουρά.

Ένα κλειδί είναι προαιρετικό, αλλά αν δοθεί πρέπει να είναι είτε `int` είτε `string`.
Όταν δεν δίνεται κλειδί, η PHP χρησιμοποιεί από προεπιλογή ακέραια κλειδιά σε αύξουσα σειρά, ξεκινώντας από το `0`.

```php
$no_keys = ["my", "first", "array"];
$integer_keys = [0 => "my", 1 => "first", 2 => "array"];

$no_keys == $integer_keys // => equal returns true
$no_keys === $integer_keys // => strictly equal returns true
```

Ένας πίνακας μπορεί να αποθηκεύσει τιμές όλων των τύπων.
Κάθε τιμή μπορεί να έχει διαφορετικό τύπο.

## Χρήση πινάκων

Οι πίνακες μπορούν να δηλωθούν ως literal (γραμμένοι στον κώδικα, όπως έγινε παραπάνω) ή να δημιουργηθούν και να τροποποιηθούν με συναρτήσεις.
Χρησιμοποίησε τον τελεστή θέσης για πρόσβαση, ανάθεση και προσάρτηση τιμών:

```php
$prime_numbers = [2, 3, 5, 6];

$prime_numbers[3] = 7; // replace 6 with 7

$prime_numbers[] = 11; // array now contains [2, 3, 5, 7, 11]
```
