## Tuple

Τα [tuple][tuple] χρησιμοποιούνται συχνά για να ομαδοποιούν πληροφορίες και διαφέρουν από τις λίστες στο ότι έχουν σταθερό μέγεθος και μπορούν να περιέχουν δεδομένα διαφορετικών τύπων.
Τα tuple δημιουργούνται με παρενθέσεις, `()`, και χρησιμοποιούνται συχνά για να επιστρέφει μια συνάρτηση πολλαπλές τιμές.

```haskell
tuple = (1, "abc", False)
```

Αυτό μπορεί να φανεί χρήσιμο όταν, για παράδειγμα, θέλεις να αποθηκεύσεις μια συντεταγμένη σε έναν δισδιάστατο χώρο: τότε ξέρεις ότι το tuple θα έχει πάντα δύο στοιχεία, τη συντεταγμένη x και τη συντεταγμένη y.

```haskell
coordinate = (3, 4)
```

### Πρόσβαση στα στοιχεία

Αρκετά συχνά δουλεύεις με μικρά tuple και μπορείς να έχεις πρόσβαση στα στοιχεία τους με τις συναρτήσεις `fst` και `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

## Αντιστοίχιση προτύπων

Όταν γράφουμε συναρτήσεις σε Haskell, μπορούμε να αξιοποιήσουμε ένα [διεκδικητικό ύφος][assertive-style] με [αντιστοίχιση προτύπων][pattern-match-doc]:
Η αντιστοίχιση προτύπων είναι ένα πολύ ισχυρό χαρακτηριστικό της Haskell που σου επιτρέπει να αντιστοιχίζεις κατασκευαστές δεδομένων και να δεσμεύεις μεταβλητές στις τιμές που βρίσκονται μέσα τους.
Όπως υποδηλώνει το όνομα, αυτό που κάνουμε είναι να αντιστοιχίζουμε τιμές με πρότυπα, και αν η τιμή ταιριάζει με το πρότυπο, μπορούμε να δεσμεύσουμε μεταβλητές στις τιμές που περιέχει το πρότυπο.
Η αντιστοίχιση προτύπων βασίζεται κυρίως σε αυτές τις έννοιες: αναγνώριση τιμών, δέσμευση μεταβλητών και διάσπαση τιμών.

Πάρε για παράδειγμα αυτή τη συνάρτηση:

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

Εδώ έχουμε μια συνάρτηση `lucky` που δέχεται ένα `Int` και επιστρέφει ένα `String`.
Έχουμε ορίσει δύο πρότυπα για τη συνάρτηση, ένα που αντιστοιχίζει τον αριθμό `7` και ένα που αντιστοιχίζει οποιονδήποτε άλλο αριθμό. Το όνομα μπορεί να είναι οτιδήποτε (αρκεί να ακολουθεί τη σύμβαση ονοματοδοσίας της Haskell), αλλά εδώ χρησιμοποιούμε το `x`.
Αν ο αριθμός είναι `7`, η συνάρτηση θα επιστρέψει `"Lucky number seven!"`, αλλιώς θα επιστρέψει `"Sorry, you're out of luck, pal!"`.
Αυτό που αξίζει να σημειώσεις εδώ είναι ότι τα πρότυπα ελέγχονται από πάνω προς τα κάτω, οπότε αν είχαμε ανταλλάξει τη σειρά τους, η συνάρτηση θα επέστρεφε πάντα `"Lucky number seven!"`.

### Πρότυπα λιστών

Ένα πολύ συνηθισμένο πρότυπο είναι η αντιστοίχιση με λίστες, παίρνοντας την κεφαλή και την ουρά της λίστας.
Αυτό οφείλεται στη φύση των λιστών ως συνδεδεμένων λιστών.
Ορίστε ένα παράδειγμα συνάρτησης που επιστρέφει την κεφαλή και την ουρά μιας λίστας:

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

Έχουμε δύο πρότυπα εδώ, ένα που αντιστοιχίζει μια κενή λίστα και ένα που αντιστοιχίζει μια λίστα με τουλάχιστον ένα στοιχείο.
Αυτό συμβαίνει γιατί αν η λίστα είναι κενή, χρειάζεται να έχουμε μια περίπτωση γι' αυτό, αλλιώς θα προέκυπτε σφάλμα χρόνου εκτέλεσης.
Αν η λίστα δεν είναι κενή, μπορούμε να αντιστοιχίσουμε την κεφαλή της λίστας με το `x` και την ουρά της με το `xs`.
Αυτό γίνεται με τον τελεστή `:` (cons), ο οποίος χρησιμοποιείται για να προσθέσουμε ένα στοιχείο στην αρχή μιας λίστας.
Στην αντιστοίχιση προτύπων όμως μας επιτρέπει να διασπάσουμε μια λίστα σε κεφαλή και ουρά, κάνοντας κατά κάποιον τρόπο το αντίθετο.

Το `xs` είναι ένα συνηθισμένο όνομα για την ουρά μιας λίστας και δείχνει ότι πρόκειται για λίστα, αλλά αν δούλευες με εμφωλευμένη λίστα, θα μπορούσες να χρησιμοποιήσεις το `xss` για να δείξεις ότι είναι λίστα από λίστες.

### Πρότυπα tuple

Όπως και με τις λίστες, μπορούμε επίσης να κάνουμε αντιστοίχιση με tuple.
Ορίστε ένα παράδειγμα συνάρτησης που δέχεται ένα tuple και επιστρέφει το πρώτο και το δεύτερο στοιχείο:

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

Εδώ έχουμε ένα πρότυπο που αντιστοιχίζει ένα tuple με δύο στοιχεία: το πρώτο στοιχείο δεσμεύεται στο `x` και το δεύτερο στο `y`.

### Πρότυπα μπαλαντέρ

Μερικές φορές δεν μας ενδιαφέρει η τιμή μιας μεταβλητής, θέλουμε απλώς να κάνουμε την αντιστοίχιση με το πρότυπο.
Εδώ μπαίνει το πρότυπο μπαλαντέρ, το οποίο συμβολίζεται με μια κάτω παύλα `_`.

Ορίστε ένα παράδειγμα συνάρτησης που επιστρέφει το πρώτο στοιχείο μιας λίστας:

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

Εδώ δηλώνουμε ότι δεν χρειαζόμαστε την ουρά της λίστας, οπότε χρησιμοποιούμε το πρότυπο μπαλαντέρ για να την αγνοήσουμε.

### Πρότυπα τύπων

Μπορούμε επίσης να κάνουμε αντιστοίχιση με τύπους, χρησιμοποιώντας τον κατασκευαστή του συγκεκριμένου τύπου.
Μπορούμε επίσης να εξάγουμε τιμές από τον τύπο, όπως κάναμε με τα tuple.

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

Στο πρώτο πρότυπο αντιστοιχίζουμε τον κατασκευαστή `Guest`, και στο δεύτερο αντιστοιχίζουμε τον κατασκευαστή `User` και δεσμεύουμε την τιμή που περιέχει στο `name`.

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
