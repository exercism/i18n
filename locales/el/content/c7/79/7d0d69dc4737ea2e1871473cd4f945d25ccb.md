# Προσθήκη στις οδηγίες

Στο [concept:python/unpacking-and-multiple-assignment](https://github.com/exercism/python/tree/main/concepts/unpacking-and-multiple-assignment), έμαθες πολλές τεχνικές για να δουλεύεις με `lists`/`tuples` αυθαίρετου μήκους, όπως και με ορίσματα συναρτήσεων αυθαίρετου μήκους.
Αυτή η άσκηση είναι ένα εξαιρετικό σημείο για να εξασκήσεις αυτές τις τεχνικές.

## Πώς υλοποιείται αυτή η άσκηση για την Python

Οι περιπτώσεις δοκιμών αυτού του track προσθέτουν ένα επιπλέον όρισμα με λέξη-κλειδί, με το όνομα `qualifier`.
Χρησιμοποίησε την τιμή αυτού του ορίσματος με λέξη-κλειδί για να τροποποιήσεις τον τελευταίο στίχο της παροιμίας σου.
