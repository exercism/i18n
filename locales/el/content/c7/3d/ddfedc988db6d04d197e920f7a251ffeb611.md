Τα μπλοκ κώδικα χρησιμοποιούνται κατά κόρον στη Raku.
Είναι θεμελιώδη για τις συναρτήσεις, αλλά και σε εργαλεία όπως τα `grep` και `map`, ως μπλοκ των εντολών `if`, `for`, `while` και `given`, ακόμη και ως θέσεις πίνακα.

## Ρουτίνες

Τα `Subs` και τα `Methods` είναι τύποι των `Routines` στη Raku.

Μια ρουτίνα μπορεί να τερματιστεί ανά πάσα στιγμή με μια τιμή επιστροφής, χρησιμοποιώντας τη λέξη-κλειδί [`return`][control-return], ένα χρήσιμο εργαλείο για τη δημιουργία συναρτήσεων.
Αν δεν έχει οριστεί κάποιο `return`, η τελευταία εντολή της ρουτίνας θα είναι η σιωπηρή τιμή επιστροφής της.

Μια ρουτίνα μπορεί να έχει μια [`Signature`][language/signatures] μέσα σε παρενθέσεις, πριν από το μπλοκ κώδικα.

Το [`Routine`][type/Routine] είναι υποκλάση του [`Block`][type/Block].

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

Θα δούμε τις μεθόδους σε μια ξεχωριστή έννοια που αφορά τις κλάσεις και τα αντικείμενα.

## Μπλοκ

Ένα [`Block`][type/Block] είναι ένα επαναχρησιμοποιήσιμο αντικείμενο κώδικα, που συνήθως χρησιμοποιείται για τη δημιουργία συναρτήσεων λάμδα.

Η τελευταία εντολή ενός μπλοκ είναι η σιωπηρή τιμή επιστροφής του.

Ένα μπλοκ μπορεί να έχει μια [`Signature`][language/signatures] με πρόθεμα `->`, πριν από το μπλοκ κώδικα.

Το [`Block`][type/Block] είναι υποκλάση του [`Code`][type/Code], που είναι η απόλυτη βασική κλάση όλων των αντικειμένων κώδικα στη Raku.

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Υπογραφές

Μια [`Signature`][language/signatures] αποτελείται από μηδέν ή περισσότερες [`Parameters`][type/Parameter], χωρισμένες με κόμματα.

Στο τέλος μιας υπογραφής, μπορείς να ορίσεις έναν τύπο επιστροφής με ένα [βέλος τύπου επιστροφής][signatures-return-type-arrow] `-->`.

Με μια υπογραφή μπορείς να προσδιορίσεις τα ορίσματα που θα δέχεται ένα `Block`.

Σε αυτή την έννοια θα κρατήσουμε τις υπογραφές απλές, χρησιμοποιώντας μόνο παραμέτρους θέσης με μεταβλητές βαθμωτού τύπου και έναν τύπο επιστροφής.
Θα επεκταθούν σε άλλες έννοιες.

## Πολλαπλή αποστολή

Η Raku επιτρέπει να γράψεις πολλές ρουτίνες με το ίδιο όνομα αλλά διαφορετικές υπογραφές, χρησιμοποιώντας τη λέξη-κλειδί `multi`.
Αυτό το χαρακτηριστικό είναι γνωστό ως [πολλαπλή αποστολή][multi-dispatch].
Όταν η ρουτίνα καλείται με το όνομά της, το περιβάλλον εκτέλεσης καθορίζει τον κατάλληλο υποψήφιο και τον καλεί.

Θα το δούμε πιο αναλυτικά σε μια έννοια για τους τύπους.

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

Όταν ο αστερίσκος `*` του [`Whatever`][type/Whatever] χρησιμοποιείται σε συνδυασμό με τους περισσότερους τελεστές, δημιουργείται ένα αντικείμενο [`WhateverCode`][type/WhateverCode].
Αυτό σου επιτρέπει να δημιουργήσεις μπλοκ με απλούστερη σύνταξη.

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
