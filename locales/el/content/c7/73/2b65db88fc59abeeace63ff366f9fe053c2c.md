# Υποδείξεις

## Γενικά

- Οι προηγούμενες έννοιες [structs][], [maps][] και [methods][] είναι χρήσιμες εδώ.


## 1. Παρακολούθηση συμμετεχόντων

- Η έννοια [type definition][] εξηγεί πώς να ορίσεις έναν νέο τύπο.
- Χρησιμοποίησε τη `make()` για να δημιουργήσεις ένα νέο στιγμιότυπο `map`.
- Για να προσθέσεις μια τιμή στο map, χρησιμοποίησε το `struct{}{}` για να δημιουργήσεις ένα στιγμιότυπο του κενού `struct{}`.

## 2. Έλεγχος συμμετεχόντων

- Αν ένα στοιχείο βρίσκεται στο map, το σύνολο περιέχει αυτή την τιμή.
- Το [two value assignment][] μπορεί να χρησιμοποιηθεί για να ελέγξεις αν ένα map περιέχει ένα στοιχείο.

## 3. Σύγκριση συμμετεχόντων

- Δύο σύνολα είναι ίδια όταν όλες οι τιμές του καθενός περιέχονται στο άλλο σύνολο.
- Το `range` μπορεί να χρησιμοποιηθεί για να ελέγξεις όλα τα στοιχεία του συνόλου.
