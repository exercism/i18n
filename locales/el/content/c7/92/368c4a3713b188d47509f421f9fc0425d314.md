# Εισαγωγή

Μια `string` στη Clojure είναι μια συμβολοσειρά της Java, η οποία είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.).

Η βιβλιοθήκη `clojure.string` παρέχει πολλές τυπικές συναρτήσεις χειρισμού και επεξεργασίας συμβολοσειρών. Επιπλέον, όλες οι συνήθεις μέθοδοι της Java για χειρισμό συμβολοσειρών είναι διαθέσιμες μέσω διαλειτουργικότητας.
