# Οδηγίες

Εργάζεσαι ως διαχειριστής συστημάτων σε μια μεγάλη εταιρεία στο Μόναχο της Γερμανίας. Μία από τις αρμοδιότητές σου είναι η διαχείριση λογαριασμών email.

Ακούς παράπονα από ανθρώπους που λένε ότι δε μπορούν να γράψουν email στον κύριο Müller. Γρήγορα συνειδητοποιείς ότι οι περισσότεροι στην εταιρεία χρησιμοποιούν ένα παλιό πρόγραμμα email που δεν αναγνωρίζει το `müller@firma.de` ως έγκυρη διεύθυνση email εξαιτίας του μη ASCII χαρακτήρα.

Το να λες στους ανθρώπους να εγκαταλείψουν το αγαπημένο τους παλιό πρόγραμμα email είναι χαμένη μάχη, οπότε αποφασίζεις να δημιουργήσεις καθαρισμένα ψευδώνυμα για όλους τους λογαριασμούς email.

## 1. Καθάρισε τα υπάρχοντα ονόματα χρηστών αφαιρώντας τα πάντα εκτός από πεζά γράμματα

Υλοποίησε τη συνάρτηση `sanitize/1`. Θα πρέπει να δέχεται ένα όνομα χρήστη ως λίστα χαρακτήρων και να επιστρέφει το όνομα χρήστη αφού αφαιρεθούν όλοι οι χαρακτήρες εκτός από τα πεζά γράμματα.

```elixir
Username.sanitize(~c"schmidt1985")
# => ~c"schmidt"
```

## 2. Επέτρεψε τις κάτω παύλες

Επέκτεινε τη συνάρτηση `sanitize/1`. Δεν πρέπει να αφαιρεί τις κάτω παύλες από το όνομα χρήστη.

```elixir
Username.sanitize(~c"mark_fischer$$$")
# => ~c"mark_fischer"
```

## 3. Αντικατέστησε τους γερμανικούς χαρακτήρες

Υπάρχουν 4 χαρακτήρες μη ASCII στο γερμανικό αλφάβητο, και όλοι τους έχουν ευρέως αναγνωρισμένα υποκατάστατα ASCII.

| Γερμανικός χαρακτήρας | Υποκατάστατο ASCII |
| ---------------- | ---------------- |
| ä                | ae               |
| ö                | oe               |
| ü                | ue               |
| ß                | ss               |

Επέκτεινε τη συνάρτηση `sanitize/1`. Πρέπει να αντικαθιστά τους γερμανικούς χαρακτήρες σύμφωνα με τον πίνακα. Μπορείς να υποθέσεις με ασφάλεια ότι όλα τα ονόματα χρηστών είναι ήδη πεζά.

```elixir
Username.sanitize(~c"cäcilie_weiß")
# => ~c"caecilie_weiss"
```
