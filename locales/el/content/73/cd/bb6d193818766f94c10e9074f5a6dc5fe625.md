# Προσθήκη στις οδηγίες

## Χειρισμός γραφηματικών συστάδων

- Η [ενσωματωμένη κλάση `RegEx`][regex] μπορεί να χρησιμοποιηθεί για να βρεις γραφηματικές συστάδες.
- Το μοτίβο κανονικής έκφρασης `\X` αντιστοιχίζεται με γραφηματικές συστάδες.
- Οι ανάποδες κάθετοι (χαρακτήρες `\`) χρειάζονται διαφυγή μέσα σε κανονικές συμβολοσειρές (`"\\X"`), αλλά όχι σε [ακατέργαστες συμβολοσειρές][literals] (`r"\X"`).
- Η `RegEx` έχει μια [μέθοδο][search_all] που επιστρέφει έναν πίνακα από `RegExMatch`.
- Κάθε αντικείμενο αντιστοίχισης έχει [μια μέθοδο][get_string] που επιστρέφει το αποτέλεσμα της αναζήτησης ως συμβολοσειρά.

[regex]: https://docs.godotengine.org/en/stable/classes/class_regex.html
[literals]: https://docs.godotengine.org/en/stable/tutorials/scripting/gdscript/gdscript_basics.html#literals
[search_all]: https://docs.godotengine.org/en/stable/classes/class_regex.html#class-regex-method-search-all
[get_string]: https://docs.godotengine.org/en/stable/classes/class_regexmatch.html#class-regexmatch-method-get-string
