# Σχετικά

Οι [εκφράσεις switch][switch-expressions] συμπεριφέρονται με παρόμοιο τρόπο με τις [εντολές switch][switch-statements] που καλύπτονται στο [concept:csharp/switch-statements](). Υποστηρίζουν ένα είδος πίνακα αποφάσεων που αντιστοιχίζει συνθήκες εισόδου σε ενέργειες ή τιμές.

Στον πυρήνα της έκφρασης switch βρίσκεται η _αντιστοίχιση προτύπων_. Στην άσκηση κώδικα αντιστοιχίσαμε τιμές με πρότυπα `const`. Σε αυτή την περίπτωση, οι είσοδοι του `switch` είναι μια _έκφραση εύρους_, η οποία αντιστοιχίζεται με τιμές const και με τις τιμές που χρησιμοποιούν οι _φρουροί περίπτωσης_.

Οι περιπτώσεις (γνωστές και ως _σκέλη switch_) αξιολογούνται με τη σειρά που εμφανίζονται στο κείμενο και η διαδικασία διακόπτεται, επιστρέφοντας την αντίστοιχη τιμή, μόλις βρεθεί αντιστοίχιση.

Η περίπτωση `_`, που είναι η τελευταία στη λίστα, είναι χρήσιμη για να διασφαλίσεις ότι η αντιστοίχιση είναι εξαντλητική και για να αποφύγεις πιθανά σφάλματα χρόνου εκτέλεσης.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

Ένα "σκέλος" του `switch` επιλέγεται όταν το πρότυπο αντιστοιχίζεται με τη μεταβλητή εύρους και κάποιος φρουρός περίπτωσης αξιολογείται ως αληθής.

Οι εκφράσεις switch υποστηρίζουν επίσης [πρότυπα τύπων][pattern-matching] και αναδρομική αντιστοίχιση.
