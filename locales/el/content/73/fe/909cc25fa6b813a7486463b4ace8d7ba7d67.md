# Εισαγωγή

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] συγκρίνουν δύο τιμές του ίδιου τύπου και επιστρέφουν μια τιμή `Bool` (`true` ή `false`).
Αν προσπαθήσεις να συγκρίνεις τιμές διαφορετικών τύπων, ο μεταγλωττιστής παράγει ένα σφάλμα.

Οι βασικοί τελεστές σύγκρισης στη Swift είναι:

| Τελεστής | Περιγραφή              | Παράδειγμα         |
| -------- | ------------------------ | --------------- |
| `==`     | ίσο με                 | `1 == 1` (true) |
| `!=`     | όχι ίσο με                 | `1 != 2` (true) |
| `<`      | μικρότερο από                | `4 < 5`  (true) |
| `<=`     | μικρότερο ή ίσο με    | `4 <= 4` (true) |
| `>`      | μεγαλύτερο από             | `3 > 1`  (true) |
| `>=`     | μεγαλύτερο ή ίσο με | `2 >= 2` (true) |

## Εντολές `if` και `else`

Μια [εντολή υπό συνθήκη][conditional-statement] εκτελεί κώδικα με βάση το αν μια συνθήκη αξιολογείται σε `true` ή `false`.
Η πιο συνηθισμένη εντολή υπό συνθήκη είναι η [εντολή `if`][if], η οποία εκτελεί ένα μπλοκ κώδικα μόνο όταν η συνθήκη της είναι `true`.
Για να γράψεις μια εντολή `if`, χρησιμοποιείς τη λέξη-κλειδί `if`, ακολουθούμενη από τη συνθήκη και το μπλοκ κώδικα μέσα σε άγκιστρα:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Μπορείς να συνδυάσεις το `if` με μια ρήτρα `else`, ώστε να εκτελέσεις εναλλακτικό κώδικα όταν η συνθήκη είναι `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Για να ελέγξεις πολλαπλές συνθήκες διαδοχικά, αλυσίδωσε τις εντολές μεταξύ τους με το `else if`.
Μια εντολή `if` δεν απαιτεί κλάδο `else`, αλλά μπορείς να συμπεριλάβεις έναν, για να χειριστείς τις περιπτώσεις όπου καμία συνθήκη δεν ταιριάζει:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Εκφράσεις `if`

Στη σύγχρονη Swift, οι εντολές `if` μπορούν επίσης να χρησιμοποιηθούν ως εκφράσεις που παράγουν μια τιμή.
Κάθε κλάδος αξιολογείται σε μια τιμή, κάτι που κάνει εύκολη την ανάθεση αποτελεσμάτων υπό συνθήκη:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## Τριαδικός τελεστής

Ο [τριαδικός τελεστής][ternary-operator] είναι μια σύντομη μορφή της εντολής `if`-`else`.
Παίρνει μια έκφραση Boolean και δύο εκφράσεις χωρισμένες με άνω και κάτω τελεία.
Η πρώτη έκφραση αξιολογείται αν η έκφραση Boolean είναι αληθής, διαφορετικά αξιολογείται η δεύτερη.
Έχει την εξής μορφή: `Boolean-expression ? expression1 : expression2`.

Ο τριαδικός τελεστής είναι ιδανικός όταν θέλεις μια σύντομη μορφή της εντολής `if`-`else` και οι εκφράσεις είναι σύντομες:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

Το παραπάνω παράδειγμα είναι συντομογραφία για τον παρακάτω κώδικα:
    
```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
