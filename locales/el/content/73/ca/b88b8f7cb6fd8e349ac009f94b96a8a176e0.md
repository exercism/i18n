# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα που θα σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το μαγείρεμα της λαζάνιας.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `Lasagna.expected_minutes_in_oven/0`, η οποία δεν παίρνει κανένα όρισμα και επιστρέφει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```elixir
Lasagna.expected_minutes_in_oven()
# => 40
```

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Όρισε τη συνάρτηση `Lasagna.remaining_minutes_in_oven/1`, η οποία παίρνει ως όρισμα τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνει η λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```elixir
Lasagna.remaining_minutes_in_oven(30)
# => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `Lasagna.preparation_time_in_minutes/1`, η οποία παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σού παίρνει 2 λεπτά.

```elixir
Lasagna.preparation_time_in_minutes(2)
# => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Όρισε τη συνάρτηση `Lasagna.total_time_in_minutes/2`, η οποία παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο αυτή τη στιγμή.

```elixir
Lasagna.total_time_in_minutes(3, 20)
# => 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

Όρισε τη συνάρτηση `Lasagna.alarm/0`, η οποία δεν παίρνει κανένα όρισμα και επιστρέφει ένα μήνυμα που δείχνει ότι η λαζάνια είναι έτοιμη για φάγωμα.

```elixir
Lasagna.alarm()
# => "Ding!"
```
