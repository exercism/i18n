# Εισαγωγή

Όταν οι τύποι δεν μπορούν να μετατραπούν σιωπηρά, πρέπει να χρησιμοποιήσεις έναν τελεστή ρητής μετατροπής.
Ο τελεστής μετατροπής δεν είναι τίποτα άλλο από τον τύπο προορισμού μέσα σε παρενθέσεις πριν από την τιμή που θέλεις να μετατρέψεις:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```
