# Εισαγωγή

Υπάρχουν βασικά δύο τύποι βρόχων:

1. Επανάληψη μέχρι να ικανοποιηθεί μια συνθήκη.
2. Επανάληψη πάνω από τα στοιχεία μιας συλλογής.

Και οι δύο είναι εφικτοί στην R, αν και ο πρώτος μπορεί να είναι πιο συνηθισμένος.

## `while` και `repeat`

Για προβλήματα ανοιχτού τύπου, όπου ο αριθμός των περασμάτων από τον βρόχο δεν είναι γνωστός εκ των προτέρων, η R έχει τον `while` βρόχο με συνθήκη και τον `repeat` βρόχο χωρίς συνθήκη (ισοδύναμο με `while (TRUE)`).

Η βασική μορφή είναι αρκετά απλή:

```R
while (condition) {
  do_something()
}
```

Σε αυτή την περίπτωση, το πρόγραμμα θα συνεχίσει να κάνει περάσματα από τον βρόχο μέχρι η `condition` να μην είναι πια `TRUE`.

Υπάρχουν δύο τρόποι να βγεις νωρίς από τον βρόχο:

- Ένα `break` προκαλεί την έξοδο από τον βρόχο, με την εκτέλεση να συνεχίζεται στην επόμενη γραμμή μετά το άγκιστρο κλεισίματος `}` του βρόχου.
- Ένα `return(x)` σταματά την εκτέλεση της τρέχουσας συνάρτησης και περνά την τιμή επιστροφής `x` πίσω σε όποιον κάλεσε τη συνάρτηση.

Με αυτές τις επιλογές διαθέσιμες, μερικές φορές μπορεί να σε βολέψει να δημιουργήσεις έναν "άπειρο" βρόχο με `repeat { ... }` και μετά να βασιστείς στο ότι θα βρεις μια συνθήκη τερματισμού μέσα στο σώμα του βρόχου, ώστε να προκαλέσεις ένα `break` ή ένα `return`.

Αυτές οι τρεις παραλλαγές είναι ισοδύναμες και όλες τελειώνουν με `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Επανάληψη πάνω από ένα διάνυσμα

Αυτό συχνά δεν είναι απαραίτητο στην R.
Όπως έχει συζητηθεί και σε άλλες έννοιες, πολλές συναρτήσεις λειτουργούν σε ολόκληρα διανύσματα.

Ωστόσο, μερικές φορές οι ρητοί βρόχοι είναι αναπόφευκτοι.
Αυτό ισχύει ειδικά όταν:

- Το σώμα του βρόχου έχει παρενέργειες, όπως εκτύπωση ή είσοδο/έξοδο αρχείων.
- Η επανάληψη συνεχίζεται μέχρι να επιτευχθεί κάποιο κριτήριο, μετά από έναν απρόβλεπτο αριθμό επαναλήψεων.

Η συνθήκη του βρόχου πρέπει να είναι μέσα σε παρενθέσεις.
Όπως και με τα σώματα των συναρτήσεων, τα άγκιστρα είναι προαιρετικά (αν και συχνά περιλαμβάνονται) για σώματα βρόχου μιας γραμμής.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Αν η τρέχουσα επανάληψη δεν ικανοποιεί κάποια συνθήκη, μπορείς να μεταβείς αμέσως στην επόμενη επανάληψη με ένα `next`:

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

Αν χρειάζεσαι την αριθμητική θέση, χρησιμοποίησε το `seq_along()`.

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Η χρήση του `i in 1:length(v)` _δεν_ συνιστάται, καθώς μπορεί να προκαλέσει προβλήματα όταν το `length(v)` είναι μηδέν.
Το διάστημα `1:0` είναι ισοδύναμο με το `c(1, 0)`, οπότε το σώμα του βρόχου θα εκτελεστεί και πιθανότατα θα αποτύχει.
Η συνάρτηση `seq_along()` είναι σχεδιασμένη να χειρίζεται σωστά αυτή την περίπτωση.
