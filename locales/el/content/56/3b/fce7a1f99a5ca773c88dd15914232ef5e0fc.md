# Σχετικά

[Οι λίστες][list] είναι ένας βασικός τύπος δεδομένων στη Haskell για να κρατούν μια συλλογή τιμών.
Οι λίστες είναι _αμετάβλητες_, που σημαίνει ότι δεν μπορούν να τροποποιηθούν.
Κάθε πράξη που αλλάζει μια λίστα επιστρέφει μια νέα λίστα.
Υπάρχουν αρκετές συναρτήσεις στο Prelude που σου επιτρέπουν να δουλέψεις με λίστες.

Οι λίστες στη Haskell υλοποιούνται ως [συνδεδεμένες λίστες][linked-list-wiki] και όχι ως πίνακες με συνεχόμενες θέσεις μνήμης.
Επομένως, η πρόσβαση σε ένα στοιχείο μιας λίστας απαιτεί γραμμικό χρόνο που εξαρτάται από το μήκος της λίστας.

Οι λίστες μπορούν να γραφτούν σε μορφή literal, σε σημειογραφία κεφαλής-ουράς (που χρησιμοποιεί τον τελεστή `cons` `:`), ή σε συνδυασμό των δύο:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

Η σημειογραφία κεφαλής-ουράς μπορεί να χρησιμοποιηθεί για να προσθέσεις στοιχεία στο τέλος μιας λίστας.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Η προσθήκη στοιχείων στο τέλος μιας λίστας κατά την επανάληψη θεωρείται αντιπρότυπο.
Η προσθήκη ενός στοιχείου στο τέλος απαιτεί να διασχίσεις ολόκληρη τη λίστα και να το βάλεις στο τέλος, επομένως η προσθήκη ενός νέου στοιχείου σε κάθε επανάληψη θα απαιτούσε να διασχίζεις ολόκληρη τη λίστα σε κάθε επανάληψη.

Μπορούμε να πετύχουμε το ίδιο αποτέλεσμα προσθέτοντας ένα στοιχείο στην αρχή της ανεστραμμένης λίστας και μετά αντιστρέφοντας το αποτέλεσμα. Η προσθήκη στην αρχή είναι γρήγορη πράξη και απαιτεί σταθερό χρόνο.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Υπάρχουν αρκετές συνηθισμένες συναρτήσεις του Prelude για λίστες:

- Η [`head`][head] επιστρέφει την _κεφαλή_ μιας λίστας, δηλαδή το _πρώτο_ στοιχείο της.
- Η [`tail`][tail] επιστρέφει την _ουρά_ της λίστας, δηλαδή τη λίστα _χωρίς_ το _πρώτο_ στοιχείο.
- Η [`length`][length] επιστρέφει τον αριθμό των στοιχείων της λίστας.
- Η [`elem`][elem] επιστρέφει μια boolean τιμή που δείχνει αν το στοιχείο ανήκει στη λίστα.

Υπάρχει επίσης το [module `Data.List`][list].

## Τύποι λιστών

Στη Haskell, οι λίστες είναι **ομοιογενείς**.
Αυτό σημαίνει ότι όλα τα στοιχεία μιας λίστας έχουν τον ίδιο τύπο.
Όταν προσπαθήσεις να βάλεις στοιχεία διαφορετικών τύπων στην ίδια λίστα, θα πάρεις ένα σφάλμα τύπου.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

Η δήλωση τύπου μιας λίστας είναι `[a]`, όπου a είναι ο τύπος που κρατά η λίστα, για παράδειγμα `String` ή `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
