# Υποδείξεις

## Γενικά

## 1. Παρακολούθηση των γύρων πόκερ

- Οι λίστες στην Python μπορούν να [κατασκευαστούν][constructed] με πολλούς τρόπους.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return] μια `list`.

## 2. Διατήρηση όλων των γύρων στο ίδιο σημείο

- Οι τύποι ακολουθίας, όπως η `list`, υποστηρίζουν [κοινές πράξεις][common sequence operations].
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return] μια `list`.

## 3. Εύρεση προηγούμενων γύρων

- Οι τύποι ακολουθίας, όπως η `list`, υποστηρίζουν μερικές [κοινές πράξεις][common sequence operations].
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return] μια `bool`.

## 4. Μέσος όρος των τιμών των φύλλων

- Για να βρεις τον μέσο όρο, αυτή η συνάρτηση πρέπει να μετρήσει πόσα στοιχεία υπάρχουν στη `list` και να αθροίσει τις τιμές τους. Έπειτα, να επιστρέψει το άθροισμα διαιρεμένο με το πλήθος.

## 5. Εναλλακτικοί μέσοι όροι

- Οι τύποι ακολουθίας, όπως η `list`, υποστηρίζουν μερικές [κοινές πράξεις][common sequence operations].
- Για να προσπελάσεις ένα στοιχείο, χρησιμοποίησε τον συμβολισμό με τις αγκύλες (`<list>[]`).
- Θυμήσου ότι το πρώτο στοιχείο της `list` βρίσκεται στη θέση 0 από την **αριστερή** πλευρά.
- Στην Python, η αρνητική αρίθμηση θέσεων ξεκινά από το -1 από τη **δεξιά** πλευρά. Αυτό σημαίνει ότι μπορείς να βρεις το τελευταίο στοιχείο μιας `list` χρησιμοποιώντας το `<list>[-1]`.
- Σκέψου πώς θα μπορούσες να επαναχρησιμοποιήσεις τον κώδικα από τις συναρτήσεις που έχεις ήδη υλοποιήσει.

## 6. Περισσότερες τεχνικές υπολογισμού μέσου όρου

- Οι τύποι ακολουθίας, όπως η `list`, υποστηρίζουν ήδη μερικές [κοινές πράξεις][common sequence operations].
- Σκέψου να επαναχρησιμοποιήσεις τον κώδικα από τις συναρτήσεις που μόλις υλοποίησες.
- Η σύνταξη slice υποστηρίζει μια _τιμή βήματος_ (`<list>[<start>:<stop>:<step>]`).

## 7. Κανόνες του γύρου μπόνους

- Οι λίστες είναι _μεταβλητές_. Μόλις δημιουργηθεί μια `list`, μπορείς να τροποποιήσεις, να διαγράψεις ή να προσθέσεις οποιονδήποτε τύπο στοιχείου θέλεις.
- Η Python παρέχει ένα ευρύ φάσμα [τρόπων τροποποίησης λιστών][ways to modify `lists`].
