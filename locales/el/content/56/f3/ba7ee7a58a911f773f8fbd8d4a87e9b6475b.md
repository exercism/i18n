# Εισαγωγή

Η Common Lisp επιτρέπει στον προγραμματιστή να γράψει "σχόλια" που ο υπολογιστής αγνοεί.
Τα σχόλια μίας γραμμής ξεκινούν με ένα ή περισσότερα ερωτηματικά (`;`) και, περιστασιακά, μπορεί να δεις το εξής:

```lisp
(code...) ; => value
```

Όπου το σχόλιο χρησιμοποιείται για να δείξει ποια τιμή επιστρέφει η Common Lisp αφού τρέξει τον κώδικα σε αυτή τη γραμμή.

Είναι ιδιωματικό να χρησιμοποιείς ένα μόνο ερωτηματικό για ένα σύντομο σχόλιο στο τέλος μιας γραμμής, δύο για ένα μεγαλύτερο σχόλιο πάνω από ένα τμήμα κώδικα, τρία για ένα μακροσκελές σχόλιο που περιγράφει κάτι όπως μια συνάρτηση, και τέσσερα για ένα σχόλιο όπως μια κεφαλίδα στην κορυφή ενός αρχείου πηγαίου κώδικα.
