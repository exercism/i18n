# Εισαγωγή

Η Go είναι στατικά τυποποιημένη, οπότε κάθε μεταβλητή έχει έναν τύπο που είναι γνωστός κατά τη μεταγλώττιση.
Μόλις δηλωθεί, ο τύπος μιας μεταβλητής δεν μπορεί να αλλάξει.

## Δημιουργία μεταβλητής

Η εντολή `var` μπορεί να δηλώσει τον τύπο μιας νέας μεταβλητής, να ορίσει την τιμή της ή να κάνει και τα δύο μαζί:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Μέσα σε μια συνάρτηση, μπορεί να χρησιμοποιηθεί και η σύντομη εντολή ανάθεσης `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Μια μεταβλητή στη Go έχει πάντα μια τιμή.
Αν δεν οριστεί κάποια κατά τη δήλωση, η Go παρέχει μία [μηδενική τιμή][zero-values], ανάλογα με τον τύπο της μεταβλητής.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Ενημέρωση μεταβλητής

Μέσα σε μια συνάρτηση, ο τελεστής ανάθεσης `=` μπορεί να ορίσει μια νέα τιμή για μια υπάρχουσα μεταβλητή:

```go
count := 1
count = 2
```

Η νέα τιμή πρέπει να έχει τον ίδιο τύπο με τη μεταβλητή:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
