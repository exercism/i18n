# Παράρτημα οδηγιών

## Το `Print` δεν βάζει εισαγωγικά στις τιμές συμβολοσειρών

Αυτή η άσκηση περιλαμβάνει τον χειρισμό αριθμητικών βαθμολογιών.
#[a: 1]` and `#[a: "1"]` δεν είναι τα ίδια:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Μια συνηθισμένη πρακτική αποσφαλμάτωσης είναι να εκτυπώνεις τιμές με το `print`.
Ωστόσο, η έξοδος δεν θα προσθέσει εισαγωγικά γύρω από τις συμβολοσειρές.
Επομένως, μια αριθμητική συμβολοσειρά όπως η `"1"` όταν εκτυπώνεται φαίνεται ίδια με τον ακέραιο `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
Στην έξοδο των δοκιμών για αυτή την άσκηση, μπορεί να δεις ένα αποτέλεσμα όπως `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
Τα δύο λεξικά που συγκρίνονται φαίνονται ίδια όταν εκτυπώνονται.
Ωστόσο, το πρώτο λεξικό έχει τιμές αριθμητικών συμβολοσειρών και το δεύτερο έχει ακέραιες τιμές, οπότε δεν είναι τα ίδια. 
Κατά την αποσφαλμάτωση, μπορείς να χρησιμοποιήσεις το `inspect` για να ελέγξεις τα περιεχόμενα του λεξικού σου.

## Το `Express` βάζει εισαγωγικά στις τιμές συμβολοσειρών

Το `express` μετατρέπει μια τιμή σε κώδικα Arturo και επιστρέφει μια συμβολοσειρά που περιέχει αυτή την αναπαράσταση κώδικα.
Σε αυτό το αποτέλεσμα, όλες οι τιμές συμβολοσειρών θα περικλείονται σε εισαγωγικά.
Ως αποτέλεσμα, το `express "1"` θα επιστρέψει `"1"`, όχι `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
