# Εγκατάσταση

Μπορείς να κατεβάσεις το Phix για πλατφόρμες Windows ή Linux από [τον επίσημο ιστότοπο][Download].

Μετά την εγκατάσταση, η διάταξη των καταλόγων θα πρέπει να ταιριάζει με αυτήν που δίνεται στην [τεκμηρίωση][Installation].

Δοκίμασε εκτελώντας 'p -test'.

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
