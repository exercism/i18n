# Εισαγωγή

Μια Boolean (λογική τιμή) έκφραση είναι ένα ερώτημα που τίθεται σε μία ή περισσότερες τιμές και μπορεί να απαντηθεί με `true` ή `false`.
Μια αληθής έκφραση επιστρέφει `1`. Μια ψευδής έκφραση επιστρέφει `0`.
Επίσης, οι αριθμοί έχουν τιμές αληθείς/ψευδείς. Το μηδέν είναι `false`, ενώ κάθε μη μηδενική τιμή είναι `true`.

Ο παλιός κώδικας σε C είτε χρησιμοποιεί απευθείας τον τύπο `int` για τιμές Boolean, είτε ο προγραμματιστής έχει ορίσει σταθερές όπως `TRUE` και `FALSE`, ώστε να αντιστοιχίσει το `1` και το `0` σε μια αναπαράσταση Boolean.

Με την έκδοση C99 προστέθηκε ο τύπος `_Bool`.
Το αρχείο κεφαλίδας `stdbool.h` ορίζει τρία νέα Boolean σύμβολα: `bool`, `true` και `false`.
Το `true` αντιστοιχίζεται στο `1`, το `false` στο `0` και το `bool` στο `_Bool`.
Έτσι τώρα, αντί να χρησιμοποιούν απευθείας `int` ή να φτιάχνουν τις δικές τους αντιστοιχίσεις Boolean, οι προγραμματιστές μπορούν να συμπεριλάβουν το `stdbool.h` και να έχουν αυτόματα Boolean σύμβολα στον κώδικά τους.

## Τελεστές σύγκρισης

Η C υποστηρίζει έξι τελεστές σύγκρισης: `==` (Ίσο), `!=` (Όχι ίσο), `>` (Μεγαλύτερο από), `<` (Μικρότερο από), `>=` (Μεγαλύτερο ή ίσο με), `<=` (Μικρότερο ή ίσο με).
Αυτοί οι τελεστές συγκρίνουν τις σχέσεις μεταξύ τιμών και τις ανάγουν σε Boolean τιμές.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Τελεστές Boolean

Η C υποστηρίζει τρεις Boolean τελεστές: `||` (Ή), `&&` (Και) και `!` (Όχι).

Ο `!` χρησιμοποιείται με έναν τελεστέο.
Αντιστρέφει τη Boolean τιμή του τελεστέου.
Για παράδειγμα, το `0` είναι `false`, αλλά το `!0` είναι `true`.

Οι `||` και `&&` χρησιμοποιούνται με δύο τελεστέους.
Ο τελεστέος στα δεξιά αξιολογείται μόνο όταν ο τελεστέος στα αριστερά δεν καθορίζει ήδη το αποτέλεσμα της έκφρασης.
Δηλαδή, ο `||` αξιολογεί τον τελεστέο στα δεξιά του μόνο όταν ο τελεστέος στα αριστερά του αξιολογείται σε `false`.
Ο `&&` αξιολογεί τον τελεστέο στα δεξιά του μόνο όταν ο τελεστέος στα αριστερά του αξιολογείται σε `true`.
