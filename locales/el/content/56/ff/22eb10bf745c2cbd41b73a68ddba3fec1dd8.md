# Σχετικά

Οι πίνακες είναι ο τύπος ακολουθίας σταθερού μήκους της Factor: μπορείς να αλλάξεις τα
στοιχεία αλλά όχι το μήκος.
Τα literal χρησιμοποιούν `{ … }` με κενό διάστημα ανάμεσα στα στοιχεία· το
λεξιλόγιο `arrays` προσθέτει μικρούς κατασκευαστές που βγάζουν τιμές από
τη στοίβα:

| λέξη     | αποτέλεσμα                                          |
|----------|-----------------------------------------------------|
| `1array` | `( a     -- { a } )`                                |
| `2array` | `( a b   -- { a b } )`                              |
| `3array` | `( a b c -- { a b c } )`                            |
| `<array>`| `( n elt -- array )`, δηλαδή `n` αντίγραφα του `elt` |
| `array?` | `( obj   -- ? )`, κατηγόρημα τύπου                  |

Μερικές [πρωτοκόλλου][sequence-protocol] λέξεις από το `sequences` εμφανίζονται τόσο συχνά μαζί με
τους πίνακες που αξίζει να τις ξέρεις ως σύνολο:

| λέξη      | αποτέλεσμα                                              |
|-----------|---------------------------------------------------------|
| `concat`  | `( seqs -- seq )`, ισιώνει μια ακολουθία από ακολουθίες  |
| `join`    | `( seqs glue -- seq )`, ισιώνει με διαχωριστικό          |
| `reverse` | `( seq -- newseq )`                                     |
| `index`   | `( elt seq -- i/f )`, θέση του στοιχείου ή `f`           |
| `member?` | `( elt seq -- ? )`, έλεγχος συμμετοχής                   |

```factor
USING: arrays sequences ;

3 4 2array .                       ! => { 3 4 }
{ { 1 2 } { 3 4 } } concat .       ! => { 1 2 3 4 }
{ 1 2 3 4 } reverse .              ! => { 4 3 2 1 }
"b" { "a" "b" "c" } index .        ! => 1
"b" { "a" "b" "c" } member? .      ! => t
```

Τα `all-unique?` και `members` από το [`sets`][sets] δέχονται επίσης οποιαδήποτε
ακολουθία: κάτι χρήσιμο όταν θέλεις να αφαιρέσεις τα διπλότυπα από τα στοιχεία ενός πίνακα
ή να τα ελέγξεις για διπλότυπα χωρίς να κάνεις πρώτα μετατροπή σε σύνολο κατακερματισμού.

[sets]: https://docs.factorcode.org/content/vocab-sets.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
