# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό.
Επειδή δεν ήθελε να είναι εύκολο για τους άλλους να το διαβάσουν, το μήνυμα κρυπτογραφήθηκε με μια σειρά από χειρισμούς bit.
Θα χρειαστεί να γράψεις τις συναρτήσεις που θα βοηθήσουν στην αποκρυπτογράφηση του μηνύματος.

## 1. Μετατόπισε τα bit προς τα πίσω

Το πρώτο βήμα για την αποκρυπτογράφηση του μηνύματος είναι να αναιρέσεις τη μετατόπιση της κρυπτογράφησης, μετατοπίζοντας τα bit πίσω προς τα δεξιά.
Στη συνέχεια της διαδικασίας αποκρυπτογράφησης υπάρχουν βήματα που υποθέτουν ότι τα `0` εισάγονται από την αριστερή πλευρά.

Υλοποίησε τη συνάρτηση `shiftBack` που παίρνει έναν αριθμό θέσεων μετατόπισης και μια τιμή και εκτελεί τη μετατόπιση.

```elm
shiftBack 2 42 --> 10
```

## 2. Θέσε κάποια bit

Έπειτα, υπάρχουν κάποια bit που πρέπει να τεθούν σε `1`.

Υλοποίησε τη συνάρτηση `setBits` που παίρνει μια μάσκα και μια τιμή και επιστρέφει το αποτέλεσμα της θέσης των bit της τιμής σε `1`.
Ένα bit της τιμής πρέπει να τεθεί σε `1` όπου το bit στη μάσκα είναι επίσης `1`.
Όλα τα άλλα bit πρέπει να μείνουν αμετάβλητα.

```elm
setBits 66 212 --> 64
```

## 3. Αντιστρέψε συγκεκριμένα bit

Κάποια bit αντιστρέφονται κατά την κρυπτογράφηση.
Θα πρέπει να αντιστραφούν ξανά για να αποκρυπτογραφηθεί το μήνυμα.

Υλοποίησε τη συνάρτηση `flipBits` που παίρνει μια μάσκα και μια τιμή.
Η μάσκα δείχνει ποια bit της τιμής θα αντιστραφούν.
Αν το bit στη μάσκα είναι `1`, το bit αντιστρέφεται στην τιμή.
Όλα τα άλλα bit μένουν αμετάβλητα.

```elm
flipBits 23 157 --> 138
```

## 4. Μηδένισε συγκεκριμένα bit

Υπάρχουν επίσης κάποια bit που αποκρυπτογραφούνται πάντα σε 0.

Υλοποίησε τη συνάρτηση `clearBits` που παίρνει μια μάσκα και μια τιμή.
Τα bit του `value` πρέπει να τεθούν σε 0 όπου το bit στη μάσκα είναι 1.
Όλα τα άλλα bit πρέπει να μείνουν αμετάβλητα.

```elm
clearBits 2 15 --> 13
```

## 5. Αποκρυπτογράφησε ένα μήνυμα

Τώρα που έχεις όλες τις συναρτήσεις που χρειάζεσαι, μπορείς να αποκωδικοποιήσεις το μήνυμα του φίλου σου.
Υλοποίησε τη συνάρτηση `decrypt` που εκτελεί τις εξής πράξεις:

1. Θέσε τα bit από το έτος γέννησης του φίλου σου (1996)
2. Αντιστρέψε το αποτέλεσμα με το έτος που γνωριστήκατε για πρώτη φορά (2009)
3. Μετατόπισε τα bit προς τα πίσω κατά τον αριθμό των μαθημάτων που παρακολουθείτε μαζί (5)
4. Μηδένισε το πρώτο και το πέμπτο bit.

```elm
decrypt 380182 --> 11840
```

Υλοποίησε τη συνάρτηση `decrypt` με όλες τις συναρτήσεις που υλοποίησες στις προηγούμενες εργασίες.
