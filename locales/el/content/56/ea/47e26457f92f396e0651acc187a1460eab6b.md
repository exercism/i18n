# Οδηγίες

Η φίλη σου η Li Mei έχει ένα μπαρ με χυμούς, όπου πουλάει νόστιμους χυμούς από ανάμεικτα φρούτα.
Είσαι τακτικός πελάτης στο μαγαζί της και συνειδητοποίησες ότι θα μπορούσες να κάνεις τη ζωή της φίλης σου πιο εύκολη.
Αποφασίζεις να χρησιμοποιήσεις τις ικανότητές σου στον προγραμματισμό για να βοηθήσεις τη Li Mei στη δουλειά της.

## 1. Υπολόγισε πόση ώρα χρειάζεται για να φτιαχτεί ένας χυμός

Στη Li Mei αρέσει να λέει στους πελάτες της εκ των προτέρων πόσο θα περιμένουν για έναν χυμό από το μενού που παρήγγειλαν.
Δυσκολεύεται να θυμάται τους ακριβείς αριθμούς, γιατί ο χρόνος που χρειάζεται για να φτιαχτούν οι χυμοί ποικίλλει.
Ο `'Pure Strawberry Joy'` θέλει 0,5 λεπτά, οι `'Energizer'` και `'Green Garden'` θέλουν 1,5 λεπτό ο καθένας, ο `'Tropical Island'` θέλει 3 λεπτά και ο `'All or Nothing'` θέλει 5 λεπτά.
Για όλα τα άλλα ποτά (π.χ. ειδικές προσφορές) μπορείς να υποθέσεις χρόνο προετοιμασίας 2,5 λεπτά.

Για να βοηθήσεις τη φίλη σου, γράψε μια συνάρτηση `timeToMixJuice` που παίρνει ως όρισμα έναν χυμό από το μενού και επιστρέφει τον αριθμό των λεπτών που χρειάζονται για να φτιαχτεί αυτό το ποτό.

```javascript
timeToMixJuice('Tropical Island');
// => 3

timeToMixJuice('Berries & Lime');
// => 2.5
```

## 2. Ανανέωσε το απόθεμα σε φέτες λάιμ

Πολλές από τις δημιουργίες της Li Mei περιλαμβάνουν φέτες λάιμ, είτε ως συστατικό είτε ως στολίδι.
Έτσι, όταν ξεκινά τη βάρδιά της το πρωί, πρέπει να σιγουρευτεί ότι το δοχείο με τις φέτες λάιμ είναι γεμάτο για την ημέρα που έρχεται.

Υλοποίησε τη συνάρτηση `limesToCut`, η οποία παίρνει τον αριθμό των φετών λάιμ που πρέπει να κόψει η Li Mei και έναν πίνακα που αντιπροσωπεύει το απόθεμα σε ολόκληρα λάιμ που έχει διαθέσιμα.
Από ένα λάιμ `'small'` μπορεί να πάρει 6 φέτες, από ένα `'medium'` 8 φέτες και από ένα `'large'` 10.
Πάντα κόβει τα λάιμ με τη σειρά που εμφανίζονται στη λίστα, ξεκινώντας από το πρώτο στοιχείο.
Συνεχίζει μέχρι να φτάσει στον αριθμό των φετών που χρειάζεται ή μέχρι να ξεμείνει από λάιμ.

Η Li Mei θα ήθελε να ξέρει εκ των προτέρων πόσα λάιμ πρέπει να κόψει.
Η συνάρτηση `limesToCut` πρέπει να επιστρέφει τον αριθμό των λάιμ που πρέπει να κοπούν.

```javascript
limesToCut(25, ['small', 'small', 'large', 'medium', 'small']);
// => 4
```

## 3. Τελείωσε τη βάρδια

Η Li Mei δουλεύει πάντα μέχρι τις 3 το μεσημέρι.
Μετά την αντικαθιστά ο υπάλληλός της, ο Dmitry.
Συχνά υπάρχουν ποτά που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμα όταν τελειώνει η βάρδια της Li Mei.
Τότε ο Dmitry ετοιμάζει τους υπόλοιπους χυμούς.

Για να κάνεις την παράδοση πιο εύκολη, υλοποίησε μια συνάρτηση `remainingOrders`, η οποία παίρνει τον αριθμό των λεπτών που απομένουν στη βάρδια της Li Mei και έναν πίνακα με τους χυμούς που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμα.
Η συνάρτηση πρέπει να επιστρέφει τις παραγγελίες που δεν προλαβαίνει να ξεκινήσει η Li Mei πριν από το τέλος της εργάσιμης μέρας της.

Ο χρόνος που απομένει στη βάρδια θα είναι πάντα μεγαλύτερος από 0.
Ο πίνακας με τους χυμούς προς ετοιμασία δεν θα είναι ποτέ άδειος.
Επιπλέον, οι παραγγελίες ετοιμάζονται με τη σειρά που εμφανίζονται στον πίνακα.
Αν η Li Mei ξεκινήσει να φτιάχνει έναν συγκεκριμένο χυμό, θα τον τελειώσει πάντα, ακόμα κι αν χρειαστεί να δουλέψει λίγο παραπάνω.
Αν δεν έχουν μείνει παραγγελίες που πρέπει να αναλάβει ο Dmitry, πρέπει να επιστραφεί ένας κενός πίνακας.

```javascript
remainingOrders(5, ['Energizer', 'All or Nothing', 'Green Garden']);
// => ['Green Garden']
```
