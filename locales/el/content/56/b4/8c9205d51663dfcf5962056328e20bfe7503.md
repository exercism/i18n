# Οδηγίες

Η Bellebrook Basketball League είναι μια λίγκα με πολλές ομάδες, καθεμία με το ρόστερ των παικτών της.
Μια νέα σεζόν πρόκειται να ξεκινήσει και χρειάζονται ένα νέο σύστημα έκδοσης εισιτηρίων για να πουλάνε εισιτήρια για τους αγώνες.
Την περασμένη σεζόν πουλούσαν τα εισιτήρια στην είσοδο του σταδίου, αλλά η δημοτικότητα εκτοξεύτηκε και αποφάσισαν να πουλάνε τα εισιτήρια online αυτή τη σεζόν, για να ανταπεξέλθουν στην αυξημένη ζήτηση.

Η λίγκα επικοινώνησε μαζί σου και σου ζήτησε να δημιουργήσεις ένα σύστημα για να διαχειρίζεσαι τις πωλήσεις εισιτηρίων.

## 1. Δημιούργησε ένα σύστημα έκδοσης εισιτηρίων

Πρώτα, χρειάζεται να δημιουργήσεις ένα σύστημα έκδοσης εισιτηρίων για να διαχειρίζεσαι τις πωλήσεις εισιτηρίων.
Το σύστημα έκδοσης εισιτηρίων πρέπει να λέει πόσα εισιτήρια είναι διαθέσιμα για έναν αγώνα.

Για κάθε αγώνα πρέπει να δημιουργείται ένα στιγμιότυπο μιας κλάσης με το όνομα `TicketSystem`.
Η αρχική κατάσταση πρέπει να περιέχει τις εξής πληροφορίες:

1. Πόσα εισιτήρια είναι διαθέσιμα για τον αγώνα.
2. Σε ποιο στάδιο παίζεται ο αγώνας.

Κατασκεύασε μια αρχική κατάσταση από ορίσματα που δηλώνουν τον αριθμό των διαθέσιμων εισιτηρίων και σε ποιο στάδιο παίζεται ο αγώνας.
Η αρχική κατάσταση πρέπει να αποτελείται από τις μεταβλητές στιγμιοτύπου `@tickets_available` και `@stadium`.
Αυτές πρέπει να περιέχουν το πρώτο και το δεύτερο όρισμα που δίνονται, αντίστοιχα.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Πάρε τον αριθμό των διαθέσιμων εισιτηρίων

Πρώτα, χρειάζεται να δημιουργήσεις μια μέθοδο που επιστρέφει τον αριθμό των διαθέσιμων εισιτηρίων για έναν δεδομένο αγώνα.

Όρισε ένα module με το όνομα `TicketingReservation` πάνω από την κλάση που έχεις ήδη ορίσει.
Αυτό το module πρέπει να συμπεριληφθεί στην κλάση `TicketSystem`.

Μέσα στο module, όρισε μια μέθοδο με το όνομα `tickets_available`.
Αυτή η μέθοδος πρέπει να επιστρέφει τον αριθμό των διαθέσιμων εισιτηρίων.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Παράγγειλε εισιτήρια

Πρέπει να δημιουργήσεις μια μέθοδο που ελέγχει αν υπάρχουν διαθέσιμα εισιτήρια για έναν δεδομένο αγώνα.
Ο αγώνας πρέπει να έχει 100 εισιτήρια σε αποθεματικό.
Αυτό γίνεται για να διασφαλιστεί ότι υπάρχουν πάντα διαθέσιμα εισιτήρια για όσους αγοράζουν εισιτήρια στην είσοδο του σταδίου.

Μέσα στο module `TicketingReservation`, όρισε μια μέθοδο με το όνομα `order_ticket?`.
Η μέθοδος πρέπει να επιστρέφει `true` αν υπάρχουν τουλάχιστον 100 διαθέσιμα εισιτήρια και `false` διαφορετικά.
Αν υπάρχουν τουλάχιστον 100 διαθέσιμα εισιτήρια, η μέθοδος πρέπει επίσης να μειώνει τον αριθμό των διαθέσιμων εισιτηρίων κατά 1.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Μήνυμα παραγγελίας

Το σύστημα έκδοσης εισιτηρίων πρέπει να έχει μηνύματα που οι χρήστες καταλαβαίνουν εύκολα.
Και τα μηνύματα πρέπει να είναι προσωπικά, οπότε πρέπει να περιλαμβάνουν το όνομα του χρήστη.

Αν η αγορά του εισιτηρίου ήταν επιτυχής, ο χρήστης πρέπει να λαμβάνει ένα μήνυμα που του λέει ότι η αγορά ήταν επιτυχής, ποιος είναι ο αριθμός του εισιτηρίου του και σε ποιο στάδιο παίζεται ο αγώνας.
Ο αριθμός του εισιτηρίου πρέπει να είναι ο αριθμός των διαθέσιμων εισιτηρίων πριν από την παραγγελία.

Αν η αγορά ήταν επιτυχής, το μήνυμα πρέπει να μοιάζει με αυτό: `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Αν η αγορά δεν ήταν επιτυχής, το μήνυμα πρέπει να μοιάζει με αυτό: `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

Μέσα στο module `TicketingReservation,` όρισε μια μέθοδο με το όνομα `order_message` που παίρνει ένα όρισμα `name` που περιέχει το όνομα του αγοραστή.
Η μέθοδος πρέπει να επιστρέφει μια συμβολοσειρά με το μήνυμα.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
