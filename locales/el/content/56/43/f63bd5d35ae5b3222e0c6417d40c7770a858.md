# Εισαγωγή

## Συμβολοσειρές

Οι συμβολοσειρές είναι μια σειρά χαρακτήρων, μέσα σε εισαγωγικά.
Υποστηρίζονται και τα μονά και τα διπλά εισαγωγικά.

```php
<?php

$where = "Spain";
$what = 'rain';
```

### Επέκταση μεταβλητής σε συμβολοσειρές

Στις συμβολοσειρές με διπλά εισαγωγικά, αν γίνει αναφορά σε μια μεταβλητή που βρίσκεται στο πεδίο εμβέλειάς της, η τιμή της εισάγεται μέσα στη συμβολοσειρά.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

### Υποστήριξη κωδικοποίησης χαρακτήρων

Ιστορικά, οι συναρτήσεις συμβολοσειρών στην PHP υποστήριζαν μόνο χαρακτήρες ASCII και δεν υποστήριζαν τις σύγχρονες κωδικοποιήσεις Unicode.
Κάθε χαρακτήρας ASCII καταλαμβάνει 1 byte, ενώ οι χαρακτήρες Unicode μπορεί να έχουν μήκος 1-4 byte.
Αν χρειάζεται να χειριστείς συμβολοσειρές Unicode με ασφάλεια, δες τις [εκδόσεις πολλαπλών byte][multi-byte-fns] των παλιών συναρτήσεων.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
