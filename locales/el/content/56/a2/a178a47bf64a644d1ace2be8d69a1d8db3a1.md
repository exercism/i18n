# Σχετικά

Στη Haxe, οι εξαιρέσεις είναι ένας ασφαλής τρόπος να χειρίζεσαι σφάλματα που προκύπτουν κατά την εκτέλεση του κώδικα. Όλες οι εξαιρέσεις θα πρέπει να περιέχουν ένα μήνυμα που περιγράφει το σφάλμα. Μπορούμε να _πετάξουμε_ εξαιρέσεις χρησιμοποιώντας τη λέξη-κλειδί `throw`:

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

Όταν πετιέται μια εξαίρεση, ο κώδικας ψάχνει για ένα κομμάτι κώδικα που έχει ανατεθεί να χειριστεί το σφάλμα. Αν δεν βρει κάποιο, θα εμφανίσει το μήνυμα σφάλματος και παράλληλα θα σταματήσει την εκτέλεση του προγράμματος.

Για να χειριστείς εξαιρέσεις στη Haxe, χρησιμοποιείς το μπλοκ `try-catch`. Αυτή η εντολή μπλοκ αποτελείται από ένα μπλοκ `try` και ένα ή περισσότερα μπλοκ `catch`. Το μπλοκ `try` _προσπαθεί_ να εκτελέσει ένα κομμάτι κώδικα, ενώ το μπλοκ `catch` περιμένει σε περίπτωση που πεταχτεί μια εξαίρεση για να την _πιάσει_, ώστε να μη σταματήσει η εκτέλεση. Όταν το μπλοκ `catch` πιάσει μια εξαίρεση, εκτελεί επίσης ό,τι υπάρχει μέσα στο μπλοκ:

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

Ο τύπος του ορίσματος του μπλοκ `catch` θα πρέπει να παραλείπεται.

Είναι σημαντικό να σημειωθεί ότι οι εξαιρέσεις θα πρέπει να χρησιμοποιούνται σε περιπτώσεις όπου συμβαίνει κάτι εξαιρετικό, ένα σφάλμα που χρειάζεται ειδικό χειρισμό. Δεν θα πρέπει να χρησιμοποιούνται για τη ροή ελέγχου ενός προγράμματος, καθώς αυτό θεωρείται κακός σχεδιασμός, που συχνά οδηγεί σε κακή απόδοση και συντηρησιμότητα.
