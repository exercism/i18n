# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να εκτυπώνεις κονκάρδες με ονόματα για τους εργαζόμενους ενός εργοστασίου. Οι εργαζόμενοι έχουν ένα αναγνωριστικό, ένα όνομα και το όνομα του τμήματός τους. Οι ετικέτες των κονκάρδων των εργαζομένων έχουν την εξής μορφή: `"[id] - name - DEPARTMENT"`.

## 1. Εκτύπωσε μια κονκάρδα για έναν εργαζόμενο

Υλοποίησε τη συνάρτηση `NameBadge.print/3`. Θα πρέπει να δέχεται ένα αναγνωριστικό, ένα όνομα και ένα τμήμα. Θα πρέπει να επιστρέφει την ετικέτα της κονκάρδας, με το όνομα του τμήματος σε κεφαλαία γράμματα.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Εκτύπωσε μια κονκάρδα για έναν νέο εργαζόμενο

Λόγω μιας ιδιορρυθμίας του υπολογιστικού συστήματος, οι νέοι εργαζόμενοι μερικές φορές δεν έχουν ακόμη αναγνωριστικό όταν αρχίζουν να εργάζονται στο εργοστάσιο. Επειδή οι κονκάρδες είναι υποχρεωτικές, θα λαμβάνουν μια προσωρινή κονκάρδα χωρίς το πρόθεμα του αναγνωριστικού.

Επέκτεινε τη συνάρτηση `NameBadge.print/3`. Όταν λείπει το αναγνωριστικό, θα πρέπει να εκτυπώνει μια κονκάρδα χωρίς αυτό.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Εκτύπωσε μια κονκάρδα για τον ιδιοκτήτη

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει κονκάρδα ανά πάσα στιγμή. Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα. Σε αυτή την περίπτωση, η ετικέτα θα πρέπει να εκτυπώνει `"OWNER"` αντί για το όνομα του τμήματος.

Επέκτεινε τη συνάρτηση `NameBadge.print/3`. Όταν λείπει το τμήμα, υπέθεσε ότι η κονκάρδα ανήκει στον ιδιοκτήτη της εταιρείας.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Σημείωσε ότι είναι πιθανό ο ιδιοκτήτης να είναι και νέος εργαζόμενος.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
