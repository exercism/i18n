# Οδηγίες

Σε αυτή την άσκηση, θα εφαρμόσεις τους [κανόνες του παιχνιδιού Go](https://matmoore.github.io/learngo/). Οι ίδιοι οι κανόνες είναι ήδη γραμμένοι, το μόνο που χρειάζεται είναι να τους εφαρμόσεις για να ενημερώσεις το Game και να χειριστείς τυχόν σφάλματα / παραβιάσεις των κανόνων.

Το παιχνίδι αναπαρίσταται ως εξής:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

Υπάρχουν 4 κανόνες στο παιχνίδι:

- Κάθε σημείο μπορεί να έχει μόνο μία πέτρα.
- Οι αντίπαλες πέτρες μπορούν να αιχμαλωτιστούν.
- Δε μπορείς να τοποθετήσεις μια πέτρα εκεί που θα αιχμαλώτιζε τον εαυτό της.
- Δε μπορείς να χρησιμοποιήσεις το ίδιο σημείο δύο φορές.

## 1. Εφάρμοσε τους κανόνες

Γράψε το περιεχόμενο της συνάρτησης `apply_rules`, η οποία παίρνει ένα αρχικό `Game` και ένα σύνολο κανόνων, και επιστρέφει το νέο `Game` αφού εφαρμοστούν οι κανόνες.

Τρεις από τους κανόνες ελέγχουν για παραβιάσεις των κανόνων και μπορούν να επιστρέψουν ένα σφάλμα, οπότε έχουν τύπο επιστροφής `Result(Game, String)`. Αν κάποιος από αυτούς τους κανόνες αποτύχει, θα πρέπει να επιστραφεί το αρχικό παιχνίδι, αλλά με το πεδίο `error` ενημερωμένο με το σχετικό σφάλμα.

Ο άλλος κανόνας δεν ελέγχει για παραβιάσεις και επομένως δε μπορεί να αποτύχει (αν και μπορεί να επιστρέψει ένα `Game` που έχει αλλάξει), οπότε έχει τύπο επιστροφής `Game`.

Αν όλοι οι κανόνες περάσουν, τότε τυχόν αλλαγές στο `Game` από τους κανόνες θα πρέπει να διατηρηθούν, και ο παίκτης θα πρέπει να αλλάξει.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
