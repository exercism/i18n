# Εγκατάσταση

Για να βρεις τις προτεινόμενες οδηγίες εγκατάστασης για την πλατφόρμα σου, πήγαινε στο [the official Rust website].

Το να έχεις εγκαταστήσει την αλυσίδα εργαλείων δεν είναι το πάν!
Η υποστήριξη IDE είναι τεράστια ώθηση στην παραγωγικότητα, κάτι που οι περισσότεροι προγραμματιστές έχουν πλέον συνηθίσει να θεωρούν δεδομένο.
Αν χρησιμοποιείς το Visual Studio Code, ρίξε μια ματιά στην [τεκμηρίωσή του για την υποστήριξη της Rust][vscode].
Σου συνιστούμε επίσης ανεπιφύλακτα να ενεργοποιήσεις το [linting με το clippy][vscode-linting]!

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
