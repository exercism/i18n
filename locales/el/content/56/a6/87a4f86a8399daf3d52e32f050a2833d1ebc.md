# Εισαγωγή

Τα μπλοκ είναι μικρές ομάδες εντολών που μπορούν να εκτελεστούν πολλές φορές.
Μπορούν να θεωρηθούν ως κλεισίματα ή ανώνυμες συναρτήσεις.
Τα μπλοκ ορίζονται χρησιμοποιώντας τη σύνταξη `do...end` (παραπάνω) ή τα `{}` (παρακάτω).
Τα στυλ είναι εναλλάξιμα και υπάρχουν διαφορετικές απόψεις για το πότε πρέπει να χρησιμοποιείται το καθένα.
