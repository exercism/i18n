# Σχετικά

## Περισσότερες μέθοδοι απαρίθμησης

Στην Απαρίθμηση γνώρισες τις μεθόδους απαρίθμησης `count`, `any?`, `select`, `all` και `map`.
Να μια σύνοψη εκείνων, με μερικές επιπλέον προσθήκες:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number > 20 }   #=> false
fibonacci.none?  { |number| number > 20 }   #=> true
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
fibonacci.select { |number| number >= 5 }   #=> [5, 8, 13]
fibonacci.find   { |number| number >= 5 }   #=> 5

# Some methods work with or without a block
fibonacci.sum  #=> 33
fibonacci.sum { |number| number * number }  #=> 273

# There are also methods to help with nested arrays:
animals = [ ['cat', 'bob'], ['horse', 'caris'], ['mouse', 'arya'] ]
animals.flatten  #=> ["cat", "bob", "horse", "caris", "mouse", "arya"]
```

## Απαρίθμηση hash

Η απαρίθμηση αντικειμένων `Hash` είναι ακριβώς ίδια με την απαρίθμηση αντικειμένων `Array`, με τη διαφορά ότι το μπλοκ δέχεται δύο ορίσματα: το κλειδί και την τιμή:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
pet_names.each { |animal, name| ... }
```

Αν χρειάζεσαι μόνο μία από τις τιμές, μπορείς να χρησιμοποιήσεις το ειδικό σύμβολο `_` για να δείξεις ότι η μία τιμή δεν χρειάζεται.
Αυτό βοηθάει τόσο ως προς τη σαφήνεια για τον προγραμματιστή όσο και ως βελτιστοποίηση της απόδοσης.

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
pet_names.map { |_, name| name }  #=> ["bob, "caris", "arya"]
```

## Εμφωλευμένες απαριθμήσεις

Μπορείς επίσης να κάνεις απαρίθμηση σε εμφωλευμένα μπλοκ και να συνδέσεις μεθόδους σε αλυσίδα.
Για παράδειγμα, αν έχουμε έναν πίνακα από hash με ζώα και θέλουμε να εξάγουμε τα ζώα με σύντομα ονόματα, μπορεί να θέλουμε να κάνουμε κάτι σαν το εξής:

```ruby
pets = [
  { animal: "cats", names: ["bob", "fred", "sandra"] },
  { animal: "horses", names: ["caris", "black beard", "speedy"] },
  { animal: "mice", names: ["arya", "jerry"] }
]

pets.map { |pet|
  pet[:names].select { |name| name.length <= 5 }
}.flatten.sort
#=> ["arya", "bob", "caris", "fred", "jerry"]
```
