# Υποδείξεις

## Γενικά

- Διάβασε για το [IO][getting-started-io] στον οδηγό Getting Started.
- Διάβασε για το [debugging με το `IO.inspect/2`][getting-started-debugging-io-inspect] στον οδηγό Getting Started.
- Διάβασε για το [`IO` module][module-io] στην τεκμηρίωση.

## 1. Καλωσόρισε τον νέο παίκτη

- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-puts] που γράφει μια συμβολοσειρά στην τυπική έξοδο.

## 2. Ρώτησε για το όνομα του χαρακτήρα

- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-gets] που διαβάζει μια συμβολοσειρά από την τυπική έξοδο. Μπορεί επίσης να γράψει ένα μήνυμα, οπότε δεν χρειάζεται να χρησιμοποιήσεις ξεχωριστή συνάρτηση για να γράψεις την ερώτηση.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-trim] στο module `String` που μπορεί να αφαιρέσει τα κενά στην αρχή και στο τέλος της εισόδου.

## 3. Ρώτησε για την κλάση του χαρακτήρα

- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-gets] που διαβάζει μια συμβολοσειρά από την τυπική έξοδο. Μπορεί επίσης να γράψει ένα μήνυμα, οπότε δεν χρειάζεται να χρησιμοποιήσεις ξεχωριστή συνάρτηση για να γράψεις την ερώτηση.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-trim] στο module `String` που μπορεί να αφαιρέσει τα κενά στην αρχή και στο τέλος της εισόδου.

## 4. Ρώτησε για το επίπεδο του χαρακτήρα

- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-gets] που διαβάζει μια συμβολοσειρά από την τυπική έξοδο. Μπορεί επίσης να γράψει ένα μήνυμα, οπότε δεν χρειάζεται να χρησιμοποιήσεις ξεχωριστή συνάρτηση για να γράψεις την ερώτηση.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-trim] στο module `String` που μπορεί να αφαιρέσει τα κενά στην αρχή και στο τέλος της εισόδου.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-to-integer] στο module `String` που μπορεί να μετατρέψει μια συμβολοσειρά σε ακέραιο.

## 5. Συνδύασε τα προηγούμενα βήματα σε ένα

- Χρησιμοποίησε ξανά τις συναρτήσεις που υλοποίησες στα προηγούμενα βήματα.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][io-inspect], χρήσιμη για debugging, που μπορεί να γράψει στην τυπική έξοδο κάτι περισσότερο από συμβολοσειρές. Αυτή η συνάρτηση δέχεται επιλογές, για παράδειγμα μια συμβολοσειρά που θα γραφτεί πριν από την τιμή που της περνάς.
- Η συνάρτηση και η επιλογή της που αναφέρθηκαν παραπάνω θα προσθέσουν στο τέλος αυτής της συμβολοσειράς μια άνω και κάτω τελεία και ένα κενό για σένα.
