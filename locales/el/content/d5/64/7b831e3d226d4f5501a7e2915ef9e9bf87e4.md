# Εισαγωγή

Η δημιουργία ενός στιγμιότυπου μιας _κλάσης_ γίνεται καλώντας τον _κατασκευαστή_ της μέσω του τελεστή `new`. Ο κατασκευαστής είναι ένα ειδικό είδος μεθόδου με σκοπό να αρχικοποιήσει ένα νεοδημιουργημένο στιγμιότυπο. Οι κατασκευαστές μοιάζουν με τις συνηθισμένες μεθόδους, αλλά χωρίς τύπο επιστροφής και με όνομα που ταιριάζει με το όνομα της κλάσης.

```csharp
class Library
{
    private int books;

    public Library()
    {
        // Initialize the books field
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Όπως οι συνηθισμένες μέθοδοι, έτσι και οι κατασκευαστές μπορούν να έχουν παραμέτρους. Οι παράμετροι του κατασκευαστή συνήθως αποθηκεύονται ως (ιδιωτικά) πεδία για να προσπελαστούν αργότερα, ή αλλιώς χρησιμοποιούνται σε κάποιον υπολογισμό που γίνεται μία φορά. Μπορούν να περαστούν ορίσματα στους κατασκευαστές, όπως ακριβώς περνάμε ορίσματα σε συνηθισμένες μεθόδους.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2)
```
