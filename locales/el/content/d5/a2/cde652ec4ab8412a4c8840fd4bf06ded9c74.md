# Οδηγίες

Μετέτρεψε έναν αριθμό, που αναπαρίσταται ως μια ακολουθία ψηφίων σε μια βάση, σε οποιαδήποτε άλλη βάση.

Υλοποίησε τη γενική μετατροπή βάσης.
Δεδομένου ενός αριθμού στη βάση **a**, που αναπαρίσταται ως μια ακολουθία ψηφίων, μετέτρεψέ τον στη βάση **b**.

## Σημείωση

- Προσπάθησε να υλοποιήσεις τη μετατροπή μόνος σου.
  Μην χρησιμοποιήσεις κάτι άλλο για να κάνει τη μετατροπή για σένα.

## Σχετικά με τον [Θεσιακό Συμβολισμό][positional-notation]

Στον θεσιακό συμβολισμό, ένας αριθμός στη βάση **b** μπορεί να κατανοηθεί ως ένας γραμμικός συνδυασμός δυνάμεων του **b**.

Ο αριθμός 42, *στη βάση 10*, σημαίνει:

`(4 * 10^1) + (2 * 10^0)`

Ο αριθμός 101010, *στη βάση 2*, σημαίνει:

`(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)`

Ο αριθμός 1120, *στη βάση 3*, σημαίνει:

`(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)`

Νομίζω πως κατάλαβες την ιδέα!

*Ναι. Αυτοί οι τρεις αριθμοί παραπάνω είναι ακριβώς οι ίδιοι. Συγχαρητήρια!*
