# Εγκατάσταση

Για να εγκαταστήσεις τη Roc, ακολούθησε τις οδηγίες στο [roc-lang.org/install](https://roc-lang.org/install).
Χρειάζεται να εγκαταστήσεις μόνο τη Roc, και προαιρετικά τις επεκτάσεις/πρόσθετα του editor που θέλεις, δεν χρειάζεται να εγκαταστήσεις τη Rust ή τη Zig (χρησιμοποιούνται για να χτιστεί η ίδια η Roc).
