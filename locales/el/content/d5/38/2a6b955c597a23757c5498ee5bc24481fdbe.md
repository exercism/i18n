# Σχετικά

Η C είναι μια στατικά τυποποιημένη γλώσσα, που σημαίνει ότι τα πάντα έχουν έναν τύπο στον χρόνο μεταγλώττισης.
Η επιλογή ενός ονόματος για μια [μεταβλητή][variable] και ο καθορισμός του τύπου της ονομάζεται δήλωση μεταβλητής.

Μια μεταβλητή δηλώνεται καθορίζοντας ρητά τον τύπο της.
Ένα όνομα μεταβλητής [πρέπει να ακολουθεί κάποιους κανόνες][name-rules], όπως να ξεκινά με ένα γράμμα ή μια κάτω παύλα.
Κάποια ονόματα δεν μπορούν να χρησιμοποιηθούν καθώς είναι δεσμευμένα [για λέξεις-κλειδιά][reserved-keywords] ή [άλλα αναγνωριστικά][reserved-identifiers].

Ο καθορισμός ή η ενημέρωση της μεταβλητής γίνεται με εκχώρηση τιμής στη μεταβλητή.
Ο καθορισμός της τιμής ορίζει αυτή τη μεταβλητή.
Ο ορισμός της μεταβλητής είναι επίσης γνωστός ως αρχικοποίηση.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Η τιμή μιας μεταβλητής μπορεί να εκχωρηθεί και να ενημερωθεί χρησιμοποιώντας τον [`=` απλό τελεστή εκχώρησης][assignment-operator].
Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

Η C είναι μια [προστακτική][imperative] [διαδικαστική][procedural] γλώσσα.
Όλοι οι υπολογισμοί εκτελούνται ως μέρος μιας σειράς [εντολών][statements] που αποτελούν μέρος μιας [συνάρτησης][function] ή πολλών συναρτήσεων.

Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες [παραμέτρους][parameters].
Κατά τον ορισμό μιας συνάρτησης, όλες οι παράμετροι και η τιμή επιστροφής πρέπει να έχουν ρητά καθορισμένο τύπο.
Οι τιμές επιστρέφονται από τις συναρτήσεις χρησιμοποιώντας τη [`return` λέξη-κλειδί][return-keyword].
Οι συναρτήσεις έχουν εξωτερική [κλάση αποθήκευσης][storage_class] από προεπιλογή, που σημαίνει ότι υπάρχει για όλη τη διάρκεια ζωής του προγράμματος και μπορεί να είναι ορατή εξωτερικά από το αρχείο.
Για να αποφευχθεί αυτό, μπορεί να προστεθεί η λέξη-κλειδί `static` για να καθοριστεί εσωτερική ορατότητα.

```c
static int add(int x, int y) {
  return x + y;
}
```

Στο παραπάνω παράδειγμα, οι μεταβλητές `x` και `y` μπορούν να χρησιμοποιηθούν μόνο μέσα στη συνάρτηση, δηλαδή έχουν εμβέλεια συνάρτησης.
Η [εμβέλεια][scope] είναι η ιδέα ότι η τιμή που σχετίζεται με ένα όνομα (ενός στοιχείου προγράμματος) είναι προσβάσιμη μόνο μέσα στην "περιοχή" κώδικα όπου ορίζεται.
Οι κύριες περιοχές κώδικα στη C είναι:

- αρχείο
- συνάρτηση
- μπλοκ (όπως μέσα σε βρόχους και άλλες δομές)

Οι συναρτήσεις καλούνται καθορίζοντας το όνομα της συνάρτησης και περνώντας ορίσματα για κάθε μία από τις παραμέτρους της συνάρτησης.

```c
int sum = add(1, 2);
```

Η C υποστηρίζει δύο τύπους [σχολίων][comments].
Τα σχόλια μιας γραμμής προηγούνται από `//` (από τη C99) και τα σχόλια πολλαπλών γραμμών εισάγονται μεταξύ `/*` και `*/`.
