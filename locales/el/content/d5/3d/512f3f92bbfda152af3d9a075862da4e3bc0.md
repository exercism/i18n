# Τεστ στη γραμμή εντολών

Εκτέλεσε τα τεστ με:

```bash
scarb cairo-test
```

Όλα τα τεστ εκτός από το πρώτο αγνοούνται. Αφού καταφέρεις να περάσει το πρώτο τεστ, άνοιξε το αρχείο πηγαίου κώδικα των τεστ που βρίσκεται στον κατάλογο `tests` και αφαίρεσε τη σημαία `#[ignore]` από το επόμενο τεστ και κάνε τα τεστ να περάσουν ξανά. Κάθε ξεχωριστό τεστ είναι μια συνάρτηση που έχει πάνω της τη σημαία `#[test]`. Συνέχισε, μέχρι να περάσεις κάθε τεστ.

Αν θέλεις να τρέξεις _όλα_ τα τεστ χωρίς να επεξεργαστείς το αρχείο πηγαίου κώδικα των τεστ, χρησιμοποίησε:

```bash
scarb cairo-test --include-ignored
```

Για να τρέξεις ένα συγκεκριμένο τεστ ανεξάρτητα από το αν αγνοείται ή όχι, για παράδειγμα το `some_test`, μπορείς να χρησιμοποιήσεις:

```bash
scarb cairo-test -f some_test
```

Για να μάθεις περισσότερα για τα τεστ της Cairo, δες τη διαδικτυακή [τεκμηρίωση για τα τεστ][cairo-tests].

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
