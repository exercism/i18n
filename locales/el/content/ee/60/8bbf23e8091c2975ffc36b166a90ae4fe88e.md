# Εισαγωγή

Το Elixir χρησιμοποιεί τα _Behaviour_ στον κώδικα για να παρέχει κοινές, γενικές διεπαφές, ενώ παράλληλα διευκολύνει ειδικές υλοποιήσεις για κάθε module που υλοποιεί κάποιο από αυτά. Ένα τέτοιο κοινό παράδειγμα είναι το _Access Behaviour_.

Το _Access Behaviour_ παρέχει μια κοινή διεπαφή για την ανάκτηση δεδομένων από μια δομή δεδομένων βασισμένη σε κλειδιά. Το _Access Behaviour_ είναι υλοποιημένο για maps και λίστες λέξεων-κλειδιών, αλλά ας δούμε τη χρήση του στα maps για να πάρουμε μια ιδέα. Το _Access Behaviour_ καθορίζει ότι, όταν έχεις ένα map, μπορείς να βάλεις _αγκύλες_ αμέσως μετά και να χρησιμοποιήσεις το κλειδί για να ανακτήσεις την τιμή που αντιστοιχεί σε αυτό.

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

Αν το κλειδί δεν υπάρχει στη δομή δεδομένων, τότε επιστρέφεται το `nil`. Αυτό μπορεί να αποτελέσει πηγή ανεπιθύμητης συμπεριφοράς, επειδή δεν πετάει σφάλμα. Σημείωσε ότι το ίδιο το `nil` υλοποιεί το Access Behaviour και επιστρέφει πάντα `nil` για οποιοδήποτε κλειδί.
