# Υποδείξεις

## Γενικά

- Οι βρόχοι [`while`][while-loops] χρησιμοποιούνται για _αόριστη_ (χωρίς μέτρημα) επανάληψη.
- Οι βρόχοι [`for`][for-loops] χρησιμοποιούνται για _ορισμένη_ (με μέτρημα) επανάληψη.
- Οι λέξεις-κλειδιά [`break` και `continue`][control flow] σε βοηθούν να προσαρμόσεις τη συμπεριφορά του βρόχου.
- Η [`range(<start>, <stop>, <step>)`][range] μπορεί να χρησιμοποιηθεί για να δημιουργήσεις μια ακολουθία για έναν μετρητή βρόχου.
- Η ενσωματωμένη [`enumerate()`][enumerate] θα επιστρέψει ζεύγη (`<value>`, `<index>`) για να τα διατρέξεις.

Το να είσαι επίσης εξοικειωμένος με τα παρακάτω μπορεί να σε βοηθήσει να ολοκληρώσεις τις εργασίες:

- [`lists`][list]: πρόσβαση με θέση, εμφωλευμένες λίστες, [`<list>.append()`][append and pop], [`<list>.pop()`][append and pop].
- [`str`][str]: ο κατασκευαστής `str()`, η χρήση του `+` για συνένωση συμβολοσειρών, προαιρετικά, [`f-strings`][f-strings].

## 1. Στρογγυλοποίηση βαθμολογιών

- Οι βρόχοι `While` συνεχίζουν να εκτελούνται μέχρι η συνθήκη ελέγχου τους να αξιολογηθεί σε `False`.
- Η `<list>.pop()` αφαιρεί και επιστρέφει το τελευταίο στοιχείο σε μια `list`.
- Οι κενές λίστες αξιολογούνται σε `False` (τα περισσότερα κενά αντικείμενα στην Python είναι "Falsy")

## 2. Μαθητές που δεν περνούν

- Δε χρειάζεται να δηλώσεις μετρητές `loop` ή `index` όταν διατρέχεις ένα αντικείμενο με έναν `for` βρόχο.
- Ένας μετρητής αποτελεσμάτων όμως χρειάζεται να στηθεί και να _αυξηθεί κατά ένα_, και θα θελήσεις να κάνεις `return` το πλήθος των μαθητών που δεν περνούν όταν τερματίσει ο βρόχος.

## 3. Τα "καλύτερα"

- Δε χρειάζεται να δηλώσεις μετρητές `loop` ή `index` όταν διατρέχεις ένα αντικείμενο με έναν `for` βρόχο.
- Το να έχεις μια κενή `list` στην οποία θα προσθέτεις τους "καλύτερους" βαθμούς είναι χρήσιμο εδώ.
- Η `<list>.append()` μπορεί να σε βοηθήσει να προσθέσεις πράγματα στη `list` αποτελεσμάτων.

## 4. Υπολογισμός βαθμών με γράμματα

- Αυτά είναι _κατώτατα όρια_. Το _κατώτατο όριο_ για ένα "D" είναι βαθμολογία **41**, αφού ένα "F" είναι **<= 40**.
- Η [`range()`][range] μπορεί να φανεί χρήσιμη εδώ για να δημιουργήσεις μια ακολουθία με τα σωστά βήματα "F" -> "A".
- Η [`round()`][round] χωρίς παραμέτρους θα στρογγυλοποιήσει ωραία τα βήματα.
- Όπως και στην εργασία "τα καλύτερα", η `<list>.append()` μπορεί να φανεί χρήσιμη εδώ για να προσθέσεις στοιχεία από τη `range()` σε μια `list` αποτελεσμάτων.

## 5. Αντιστοίχιση ονομάτων με βαθμολογίες

- Η [`enumerate()`][enumerate] μπορεί να φανεί χρήσιμη εδώ.
- Αν και οι δύο λίστες έχουν το ίδιο μήκος και είναι ταξινομημένες με τον ίδιο τρόπο, θα μπορούσες να χρησιμοποιήσεις το `index` από τη μία για να ανακτήσεις το `value` από την άλλη;

## 6. Μια "τέλεια" βαθμολογία

- Μπορεί να υπάρχει ή να μην υπάρχει μαθητής με βαθμολογία 100, και δεν μπορείς να επιστρέψεις `[]` χωρίς να ελέγξεις **όλες** τις βαθμολογίες.
- Οι εντολές [`control flow`][control flow] `continue` και `break` μπορεί να φανούν χρήσιμες εδώ για να προσπεράσεις ανεπιθύμητες τιμές.
