# Υποδείξεις

## Γενικά

- Για να δημιουργήσεις τις μεθόδους getter και setter, θα πρέπει να χρησιμοποιήσεις τις μακροεντολές `getter`, `setter` και `property`.

## 1. Δημιούργησε μια αρχική κατάσταση για τη μηχανή ζύγισης

- Για να αρχικοποιήσεις τη μηχανή ζύγισης, θα πρέπει να χρησιμοποιήσεις τη μέθοδο `initialize`.
- Η μέθοδος θα πρέπει να παίρνει δύο ορίσματα, `precision` και `metric`, τα οποία θα πρέπει να είναι `Int32` και `Bool`, αντίστοιχα.
  Αυτά θα πρέπει να χρησιμοποιηθούν για να ορίσουν τις μεταβλητές στιγμιοτύπου `@precision` και `@metric`.
- Η μεταβλητή στιγμιοτύπου `@weight` θα πρέπει να οριστεί σε `0.0`.

## 2. Επέτρεψε στη μηχανή ζύγισης να έχει ακρίβεια

- Η μακροεντολή `getter` σου επιτρέπει να ορίσεις μια μέθοδο που επιστρέφει την τιμή μιας μεταβλητής στιγμιοτύπου.

## 3. Επέτρεψε να ορίζεται το βάρος στη μηχανή ζύγισης

- Η μακροεντολή `property` σου επιτρέπει να ορίσεις μια μέθοδο που διαβάζει και ορίζει την τιμή μιας μεταβλητής στιγμιοτύπου.

## 4. Επέτρεψε στη μηχανή να εναλλάσσεται μεταξύ μετρικών και αυτοκρατορικών μονάδων

- Η μακροεντολή `setter` σου επιτρέπει να ορίσεις μια μέθοδο που ορίζει την τιμή μιας μεταβλητής στιγμιοτύπου.
