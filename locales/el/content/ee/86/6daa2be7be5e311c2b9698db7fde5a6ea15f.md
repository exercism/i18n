# Η μέθοδος είναι πολύ μεγάλη

Σκέψου να σπάσεις την παρακάτω μέθοδο (ή τις παρακάτω μεθόδους) σε κλήσεις προς άλλες μεθόδους που έχουν σημασιολογικό νόημα: `%{methodNames}`

Η μέθοδος έχει περισσότερες γραμμές κώδικα από όσες απαιτεί συνήθως αυτή η άσκηση.
Αυτό μπορεί να είναι αποδεκτό, αλλά ίσως δείχνει ότι η μέθοδος κάνει από μόνη της πολλή δουλειά και θα έπρεπε να αναθέτει ένα μέρος της σε άλλες μεθόδους.
Προσπάθησε να κρατάς τα πάντα μέσα σε μια μέθοδο σε ένα επίπεδο αφαίρεσης.
Για παράδειγμα, η επανάληψη πάνω στα στοιχεία ενός βρόχου θα μπορούσε να βρίσκεται σε μία μέθοδο, ενώ ο χειρισμός κάθε μεμονωμένου στοιχείου θα μπορούσε να βρίσκεται σε άλλη.
