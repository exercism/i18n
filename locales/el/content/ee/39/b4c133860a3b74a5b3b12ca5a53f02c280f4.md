# Οδηγίες

Η κοπέλα του Lucian γυρίζει σπίτι, και εκείνος δεν έχει μαγειρέψει ακόμα το δείπνο της επετείου τους!

Σε αυτή την άσκηση, θα γράψεις κώδικα για να βοηθήσεις τον Lucian να μαγειρέψει εξαιρετικά λαζάνια από το αγαπημένο του βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες που έχουν να κάνουν με τον χρόνο που αφιερώνεις στο μαγείρεμα των λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος στον φούρνο, σε λεπτά

Όρισε τη σταθερά `EXPECTED_MINUTES_IN_OVEN`, που αντιπροσωπεύει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Πρέπει να την εξαγάγεις. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι `40`.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος στον φούρνο, σε λεπτά

Υλοποίησε τη συνάρτηση `remainingMinutesInOven`, που παίρνει ως _παράμετρο_ τα πραγματικά λεπτά που βρίσκονται τα λαζάνια στον φούρνο και _επιστρέφει_ πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στον φούρνο, με βάση τον **αναμενόμενο χρόνο ψησίματος σε λεπτά** από την προηγούμενη εργασία.

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη συνάρτηση `preparationTimeInMinutes`, που παίρνει ως _παράμετρο_ τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και _επιστρέφει_ πόσα λεπτά σου πήρε για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να την ετοιμάσεις.

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υλοποίησε τη συνάρτηση `totalTimeInMinutes`, που παίρνει _δύο παραμέτρους_: η παράμετρος `numberOfLayers` είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια, και η παράμετρος `actualMinutesInOven` είναι ο αριθμός των λεπτών που βρίσκονται τα λαζάνια στον φούρνο. Η συνάρτηση θα πρέπει να _επιστρέφει_ πόσα λεπτά έχεις δουλέψει συνολικά για το μαγείρεμα των λαζάνια, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στον φούρνο αυτή τη στιγμή.

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
