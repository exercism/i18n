# Υποδείξεις

## Γενικά

- Η [σελίδα της Wikipedia για τη Definite Clause Grammar](https://en.wikipedia.org/wiki/Definite_clause_grammar) δίνει μια εξαιρετική επισκόπηση των DCG
- Ο [οδηγός Prolog DCG](https://www.metalevel.at/prolog/dcg) περιέχει μια πολύ χρήσιμη εισαγωγή στα DCG της Prolog
- Η [τεκμηρίωση του SWIPL για το dcg/basics](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) απαριθμεί τις ενσωματωμένες πρωτόγονες λειτουργίες που μπορείς να χρησιμοποιήσεις

## 3. Υποστήριξε όλα τα κενά διαστήματα (εκτός από τις αλλαγές γραμμής)

- Υπάρχει μια [ενσωματωμένη πρωτόγονη λειτουργία](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) που μπορείς να χρησιμοποιήσεις για αυτό

## 4. Ανάλυσε το ημισφαίριο του γεωγραφικού πλάτους

- Οι κανόνες DCG μπορούν να έχουν μεταβλητές, όπως τα συνηθισμένα γεγονότα ή οι κανόνες
- Οι κανόνες DCG μπορούν να έχουν πολλαπλές δηλώσεις, όπως τα συνηθισμένα γεγονότα ή οι κανόνες

## 5. Ανάλυσε το ημισφαίριο του γεωγραφικού μήκους

- Οι κανόνες DCG μπορούν να έχουν μεταβλητές, όπως τα συνηθισμένα γεγονότα ή οι κανόνες
- Οι κανόνες DCG μπορούν να έχουν πολλαπλές δηλώσεις, όπως τα συνηθισμένα γεγονότα ή οι κανόνες

## 6. Ανάλυσε τις μοίρες

- Υπάρχει μια [ενσωματωμένη πρωτόγονη λειτουργία](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) που μπορείς να χρησιμοποιήσεις για αυτό

## 7. Ανάλυσε τις μοίρες του γεωγραφικού πλάτους

- Μπορείς να ξαναχρησιμοποιήσεις τον κανόνα `degrees`
- Η γλωσσική δομή `{}//1` μπορεί να χρησιμοποιηθεί για να καλέσεις κατηγορήματα της Prolog μέσα από έναν κανόνα

## 9. Ανάλυσε το γεωγραφικό πλάτος

- Η μορφή ενός γεωγραφικού πλάτους είναι: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>`
- Ξαναχρησιμοποίησε τους κανόνες που έχεις ήδη υλοποιήσει

## 10. Ανάλυσε το γεωγραφικό μήκος

- Η μορφή ενός γεωγραφικού μήκους είναι: `<LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- Ξαναχρησιμοποίησε τους κανόνες που έχεις ήδη υλοποιήσει

## 11. Ανάλυσε τη συντεταγμένη

- Η μορφή μιας συντεταγμένης είναι: `<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>`
- Ξαναχρησιμοποίησε τους κανόνες που έχεις ήδη υλοποιήσει
