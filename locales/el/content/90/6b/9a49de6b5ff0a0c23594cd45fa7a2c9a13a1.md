# Οδηγίες

Η ESA (Διαστημική Υπηρεσία του Exercism) βρίσκεται σε πλήρη εξέλιξη, σχεδιάζοντας μια νέα αποστολή στον [Φόβο][phobos], έναν δορυφόρο του Άρη.
Ο στόχος της αποστολής είναι να προσγειώσει έναν ανιχνευτή στην επιφάνεια του Φόβου και να στείλει πίσω δεδομένα για την επιφάνεια.
Η ESA ζήτησε τη βοήθειά σου για να φτιάξεις τον υπολογιστή πλοήγησης του ανιχνευτή.
Ο υπολογιστής πλοήγησης έχει περιορισμένη μνήμη, οπότε πρέπει να κρατήσουμε τη χρήση της μνήμης όσο το δυνατόν χαμηλότερη.
Γι' αυτό, πρέπει να χρησιμοποιήσουμε τους κατάλληλους τύπους δεδομένων.

## 1. Σταθερές πλοήγησης

Ο υπολογιστής πλοήγησης χρειάζεται να γνωρίζει την απόσταση ανάμεσα σε κάποια αντικείμενα στο διάστημα για να κάνει τους σωστούς υπολογισμούς. Η απόσταση μετριέται σε km.

Όρισε τις παρακάτω σταθερές:

- `NEPTUNE_DISTANCE` με την τιμή `4_400_000_000` που θα πρέπει να αποθηκευτεί ως `Int64`
- `MARS_DISTANCE` με την τιμή `227_940_000` που θα πρέπει να αποθηκευτεί ως `Int32`
- `ATMOSPHERE_DISTANCE` με την τιμή `10_000` που θα πρέπει να αποθηκευτεί ως `Int16`

## 2. Σωστή ανάλυση εμβαδού

Ο υπολογιστής πλοήγησης χρειάζεται να γνωρίζει το εμβαδόν κάποιων αντικειμένων στο διάστημα για να κάνει τους σωστούς υπολογισμούς.
Ένα εμβαδόν **ΔΕΝ** μπορεί να είναι αρνητικό.
Οι μηχανικοί είχαν σχεδιάσει το πρόγραμμα να παράγει ένα σφάλμα υπερχείλισης όταν το εμβαδόν ήταν αρνητικό.
Ωστόσο, οι μηχανικοί ξέχασαν να αλλάξουν τον προσημασμένο ακέραιο σε απρόσημο ακέραιο.

Επομένως, οι μηχανικοί θα ήθελαν ένα πρόγραμμα που μετατρέπει έναν προσημασμένο ακέραιο σε απρόσημο ακέραιο.

Υλοποίησε τη μέθοδο `Navigation#correct_area_analysis` που παίρνει ένα `measurement` ως όρισμα και επιστρέφει το εμβαδόν ως απρόσημο ακέραιο με 32 bits.

~~~~exercism/note
Το εμβαδόν που δίνεται θα χωράει πάντα σε έναν απρόσημο ακέραιο με 32 bits.
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. Υπολόγισε την ταχύτητα

Ο υπολογιστής πλοήγησης χρειάζεται να γνωρίζει την ταχύτητα του ανιχνευτή.
Η ταχύτητα μετριέται σε m/s.

Για να υπολογίσουμε την ταχύτητα, χρειάζεται να γνωρίζουμε την απόσταση που διανύθηκε και τον χρόνο που χρειάστηκε για να διανυθεί αυτή η απόσταση.
Έπειτα, πάρε την απόσταση και διαίρεσέ τη με τον χρόνο.

Η ταχύτητα μπορεί να μην είναι ακριβής και δεν θα είναι ποτέ ένας μεγάλος αριθμός.
Γι' αυτό, μπορούμε να χρησιμοποιήσουμε ένα `Float32`.

Υλοποίησε τη μέθοδο `Navigation#calculate_velocity` που παίρνει `distance` και `time` ως ορίσματα και επιστρέφει την ταχύτητα ως `Float` με 32 bits.

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
