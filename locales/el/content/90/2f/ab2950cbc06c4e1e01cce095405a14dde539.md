# Συμβόλαια

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0 and load <= limit
      post result >= 0
   is
      return limit - load;
   end;
```

| Ρήτρα | Δηλώνει | Ποιανού ευθύνη αν παραβιαστεί |
| --- | --- | --- |
| `pre` | τι πρέπει να ισχύει κατά την είσοδο | του καλούντος |
| `post` | τι ισχύει κατά την επιστροφή | της ρουτίνας |

Και τα δύο δέχονται ένα `BOOL`, και τα δύο μπορούν να χρησιμοποιούν τα ορίσματα
της ρουτίνας και τα χαρακτηριστικά του αντικειμένου. Το `post` μπορεί επίσης να
χρησιμοποιεί το `result`, την τιμή που επιστρέφεται.

## assert

Μέσα στο σώμα μιας ρουτίνας, το `assert` δηλώνει κάτι που πρέπει να είναι αληθές
σε εκείνο το σημείο:

```sather
      assert load <= limit;
```

Ελέγχεται με τον ίδιο διακόπτη με τα υπόλοιπα.

## Αναλλοίωτα κλάσης

Μια κλάση μπορεί να δηλώνει κάτι που ισχύει για κάθε αντικείμενό της ανάμεσα
στις κλήσεις:

```sather
   invariant : BOOL is
      return checks >= 0 and limit > 0;
   end;
```

Ελέγχεται στην είσοδο και στην έξοδο κάθε δημόσιας ρουτίνας, όταν ο έλεγχος
είναι ενεργός.

## Πώς ενεργοποιείται

| Σημαία | Τι ελέγχει |
| --- | --- |
| `-chk` | τα πάντα: pre, post, assert, invariant, όρια, αριθμητικές πράξεις |
| `-chk_no` | τίποτα |

Πρόσεξε ότι το `-chk_pre` από μόνο του *δεν* ενεργοποιεί τον έλεγχο
προϋποθέσεων σε αυτόν τον μεταγλωττιστή· αυτό που δουλεύει είναι το `-chk`. Μια
παραβίαση τυπώνει τη ρουτίνα και τη γραμμή του πηγαίου κώδικα και σταματά το
πρόγραμμα. Δεν είναι εξαίρεση, και το `protect` δεν θα την πιάσει.

Η συνήθης πρακτική είναι να αναπτύσσεις και να δοκιμάζεις με `-chk` και να
παραδίδεις χωρίς αυτό, ώστε οι έλεγχοι να μην κοστίζουν τίποτα στο πρόγραμμα που
παραδίδεται. Αυτό αξίζει μόνο αν τα τεστ περνούν πραγματικά από αυτά τα
μονοπάτια.

## Τι κάνει ένα συμβόλαιο καλό

Πες τι χρειάζεται η ρουτίνα, όχι πώς λειτουργεί:

```sather
   pre load >= 0 and load <= limit        -- yes
   pre load /= 47                         -- what?
```

Ένα `post` που επαναλαμβάνει το σώμα δεν διδάσκει τίποτα σε κανέναν:

```sather
   post result = limit - load             -- says the body twice
   post result >= 0                       -- says something worth knowing
```

## Κληρονομικότητα

Ένας υποτύπος μπορεί να εξασθενίσει ένα `pre` και να ενισχύσει ένα `post`, να
δέχεται περισσότερα και να υπόσχεται περισσότερα, αλλά ποτέ το αντίστροφο, γιατί
κώδικας γραμμένος με βάση τον υπερτύπο θα έσπαγε. Αυτός είναι ο κανόνας που
υπάρχουν τα συμβόλαια για να τον κάνουν ελέγξιμο.
