# ενότητα για τα σχόλια

Η Go έχει [εξαιρετικές οδηγίες](https://golang.org/doc/effective_go.html) για το πώς να γράφεις σχόλια. Υπάρχει μια τυπική μορφή που μπορείς να χρησιμοποιήσεις για σχόλια τεκμηρίωσης, τα οποία στη συνέχεια μπορούν να μετατραπούν αυτόματα σε όμορφη τεκμηρίωση από το εργαλείο `godoc`.

Το σχόλιο του πακέτου πρέπει να ξεκινά με τη λέξη `Package` ακολουθούμενη από το όνομα του πακέτου, όπως εδώ:

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

Για εξαγόμενες συναρτήσεις, μεθόδους, σταθερές και μεταβλητές πακέτου, το σχόλιο πρέπει να ξεκινά με το όνομα και να συνεχίζει με μια φράση με ρήμα:

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

Το wiki [CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) ορίζει επιπλέον ότι τα σχόλια τεκμηρίωσης πρέπει να είναι πλήρεις προτάσεις, που τελειώνουν με τελεία.

Εκτός από τη βελτιστοποίηση της αναγνωσιμότητας, η τήρηση των συστάσεων βελτιώνει την εμφάνιση του κώδικά σου στα [εργαλεία τεκμηρίωσης της Go](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/) όπως το [godoc.org](http://godoc.org), το `godoc` και το `go doc`.

Αφιέρωσε λίγο χρόνο για να διαβάσεις την ενότητα για τα σχόλια τεκμηρίωσης στον επίσημο οδηγό στυλ, [Effective Go](https://golang.org/doc/effective_go.html), για να δεις το σκεπτικό πίσω από αυτές τις επιλογές.
