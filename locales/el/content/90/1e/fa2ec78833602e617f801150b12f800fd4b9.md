# Εισαγωγή

Ένας `array` στη F# είναι μια μεταβλητή συλλογή από μηδέν ή περισσότερες τιμές με σταθερό μήκος. Αυτό σημαίνει ότι μόλις δημιουργηθεί ένας πίνακας, το μέγεθός του δεν μπορεί να αλλάξει, αλλά οι τιμές του μπορούν. Οι τιμές σε έναν πίνακα πρέπει όλες να έχουν τον ίδιο τύπο. Οι πίνακες μπορούν να οριστούν ως εξής:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Τα στοιχεία μπορούν να εκχωρηθούν σε έναν πίνακα ή να ανακτηθούν από αυτόν χρησιμοποιώντας μια θέση. Οι πίνακες της F# έχουν μηδενική βάση, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Οι πίνακες είτε χειρίζονται με συναρτήσεις και τελεστές που ορίζονται στο άρθρωμα `Array`, είτε χειροκίνητα χρησιμοποιώντας αντιστοίχιση προτύπων με το _πρότυπο πίνακα_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

Μπορείς επίσης να _απορρίψεις_ μια τιμή κατά την αντιστοίχιση προτύπων· όταν _δεν_ σε ενδιαφέρει μια τιμή σε μια συγκεκριμένη περίπτωση (δηλαδή δεν πρόκειται να _χρησιμοποιήσεις_ μια τιμή) μπορείς να χρησιμοποιήσεις μια κάτω παύλα (`'_'`) για να το δηλώσεις αυτό:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

Η μονή κάτω παύλα (`'_'`) πρέπει πάντα να έρχεται _τελευταία_ στην αντιστοίχιση προτύπων. Κάθε τιμή που _δεν_ ταιριάζει με καμία από τις άλλες περιπτώσεις θα χειρίζεται από αυτήν την περίπτωση.
