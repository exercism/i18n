# Οδηγίες

Υλοποίησε έναν αξιολογητή για ένα πολύ απλό υποσύνολο της Forth.

Η [Forth][forth]
είναι μια γλώσσα προγραμματισμού βασισμένη σε στοίβα.
Υλοποίησε έναν πολύ βασικό αξιολογητή για ένα μικρό υποσύνολο της Forth.

Ο αξιολογητής σου πρέπει να υποστηρίζει τις παρακάτω λέξεις:

- `+`, `-`, `*`, `/` (ακέραια αριθμητική)
- `DUP`, `DROP`, `SWAP`, `OVER` (χειρισμός στοίβας)

Μπορείς να χρησιμοποιήσεις tuple ως στοίβα, ώστε να αποφύγεις τους κωδικούς εντολών της fift και του asm που σχετίζονται με τη στοίβα.

Για να κρατήσουμε τα πράγματα απλά, ο μόνος τύπος δεδομένων που χρειάζεται να υποστηρίξεις είναι ακέραιοι με πρόσημο, μεγέθους τουλάχιστον 16 bit.

Πρέπει να χρησιμοποιήσεις τους παρακάτω κανόνες για τη σύνταξη: ένας αριθμός είναι μια ακολουθία από ένα ή περισσότερα (ASCII) ψηφία, και μια λέξη είναι μια ακολουθία από ένα ή περισσότερα γράμματα, ψηφία, σύμβολα ή σημεία στίξης που δεν αποτελεί αριθμό.
(Η Forth πιθανώς χρησιμοποιεί ελαφρώς διαφορετικούς κανόνες, αλλά αυτοί είναι αρκετά κοντά.)
