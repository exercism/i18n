# Συμβουλές

## 1. Προσδιόρισε ποια εφαρμογή εξέπεμψε ένα log

- Μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `range` για να διατρέξεις τα runes μιας συμβολοσειράς.
- Μπορείς να συγκρίνεις runes με άλλα runes χρησιμοποιώντας μια εντολή `if`.
- Ένας χαρακτήρας μέσα σε μονά εισαγωγικά είναι `rune` στη Go.

## 2. Διόρθωσε τα χαλασμένα logs

- Μπορείς να χρησιμοποιήσεις συνένωση συμβολοσειρών για να φτιάξεις τη διορθωμένη γραμμή του log, ένα rune τη φορά.
- Για να δουλέψει αυτή η συνένωση, ίσως χρειαστεί πρώτα να μετατρέψεις κάθε `rune` σε συμβολοσειρά.
- Μπορείς να μετατρέψεις ένα rune `r` σε `string` με το `string(r)`.

## 3. Προσδιόρισε αν ένα log μπορεί να εμφανιστεί

- Τα runes μπορεί να είναι 1, 2, 3 ή 4 byte, οπότε η ενσωματωμένη συνάρτηση `len` μπορεί να μην αντικατοπτρίζει με ακρίβεια τον αριθμό των χαρακτήρων σε μια συμβολοσειρά.
