# Σχετικά

Μια [καταγραφή][records] είναι μια συλλογή από πεδία (τα οποία μπορούν να είναι διαφορετικών τύπων) που ανήκουν μαζί. Για να [ορίσεις μια καταγραφή][define], χρησιμοποιείς τη λέξη-κλειδί `type`. Τα πεδία μιας καταγραφής ορίζονται ανάμεσα στους χαρακτήρες `{` και `}` και κάθε πεδίο έχει ένα όνομα _και_ έναν τύπο.

```fsharp
type Address =
    { Street: string
      HouseNumber: int }
```

Για να [δημιουργήσεις μια καταγραφή][create], όρισε τα ονόματα των πεδίων και ανάθεσέ τους μια τιμή ανάμεσα στους χαρακτήρες `{` και `}`. Κατά τη δημιουργία μιας καταγραφής, πρέπει να ανατεθεί μια τιμή σε όλα τα πεδία της. Τα πεδία μπορούν να οριστούν με οποιαδήποτε σειρά, δε χρειάζεται να ακολουθούν τη σειρά του ορισμού του τύπου της καταγραφής. Για να προσπελάσεις τις τιμές των πεδίων ενός στιγμιοτύπου καταγραφής, χρησιμοποιείς τη σημειογραφία με τελεία.

```fsharp
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

oldAddress.Street      // => "Main Street"
oldAddress.HouseNumber // 17
```

Όταν ορίζεις ή δημιουργείς μια καταγραφή, κάθε πεδίο πρέπει είτε να βρίσκεται σε ξεχωριστή γραμμή είτε να χωρίζεται με άνω τελείες (`;`) όταν βρίσκεται σε μία μόνο γραμμή:

```fsharp
type Address = { Street: string; HouseNumber: int }

let oldAddress: Address = { Street = "Main Street"; HouseNumber = 17 }
```

Αν τα ονόματα των πεδίων μιας καταγραφής είναι μοναδικά, οι σημειώσεις τύπου είναι προαιρετικές, καθώς ο μεταγλωττιστής θα μπορεί να συμπεράνει τον τύπο αυτόματα. Αν ο συνδυασμός των ονομάτων των πεδίων _δεν_ είναι μοναδικός, μπορείς να βοηθήσεις τον μεταγλωττιστή να επιλέξει τη σωστή καταγραφή είτε χρησιμοποιώντας έναν ρητό τύπο για τη δέσμευση της καταγραφής είτε βάζοντας ως πρόθεμα σε ένα ή περισσότερα πεδία τον τύπο της καταγραφής:

```fsharp
type Boat = { Weight: int; Length: int }
type Car = { Weight: int; Length: int }

// Let compiler infer type. As there are multiple matching record types,
// the last matching type is used (Car)
let typeEqualsLastMatch = { Weight = 5000; Length = 15 }

// Use type annotation on binding to force type to Boat
let typeAnnotation: Boat = { Weight = 5000; Length = 15 }

// Use fully qualified name for field to force type to Boat
let fullyQualifiedField = { Boat.Weight = 5000; Length = 15}
```

Καθώς οι καταγραφές είναι αμετάβλητες, μόλις δημιουργηθεί μια καταγραφή, οι τιμές των πεδίων της δε μπορούν ποτέ να αλλάξουν. Αν θέλεις να αλλάξεις τις τιμές μιας καταγραφής, η λέξη-κλειδί `with` σου επιτρέπει να [δημιουργήσεις ένα αντίγραφο μιας υπάρχουσας καταγραφής, αλλά με νέες τιμές για ένα ή περισσότερα πεδία][create].

```fsharp
// Copy the old address but change the house number
let newAddress = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Οι καταγραφές έχουν [_δομική ισότητα_][equality], που σημαίνει ότι δύο στιγμιότυπα της ίδιας καταγραφής με πανομοιότυπες τιμές είναι ισοδύναμα:

```fsharp
let address1 = { Street = "Main Street"; HouseNumber = 17 }
let address2 = { Street = "Main Street"; HouseNumber = 17 }
let address3 = { Street = "Broadway"; HouseNumber = 17 }

address1 = address2 // => true
address1 = address3 // => false
```

Εκτός από το ότι μπορείς να χρησιμοποιήσεις τη σημειογραφία με τελεία για να προσπελάσεις τα πεδία μιας καταγραφής, οι καταγραφές μπορούν επίσης να _αποδομηθούν_ σε δεσμεύσεις και σε αντιστοίχιση προτύπων χρησιμοποιώντας το [πρότυπο καταγραφής][record-patterns]:

```fsharp
let myAddress = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
