# Οδηγίες

Σε αυτές τις οδηγίες θα γράψεις κώδικα που θα σε βοηθήσει να μαγειρέψεις μια λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με το μαγείρεμα της συνταγής σου.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε το πεδίο `lasagna.oven_time` του πίνακα με τα λεπτά που πρέπει να μείνει η λαζάνια στο φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```lua
lasagna.oven_time
-- => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `lasagna.remaining_oven_time` που παίρνει ως όρισμα τα πραγματικά λεπτά που η λαζάνια βρίσκεται στο φούρνο και επιστρέφει πόσα λεπτά πρέπει να μείνει ακόμα η λαζάνια στο φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `lasagna.preparation_time` που παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά ξόδεψες προετοιμάζοντας τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. Υπολόγισε τον χρόνο εργασίας που πέρασε σε λεπτά

Όρισε τη συνάρτηση `lasagna.elapsed_time` που παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που η λαζάνια βρίσκεται στο φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που η λαζάνια έχει περάσει στο φούρνο αυτή τη στιγμή.

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
