# Σχετικά

Η Scala είναι μια γλώσσα προγραμματισμού που κλιμακώνεται μαζί σου: από μικρά σενάρια μέχρι μεγάλες εφαρμογές για πολλαπλές πλατφόρμες.

Η Scala συνδυάζει τον αντικειμενοστραφή και τον συναρτησιακό προγραμματισμό σε μία συνοπτική γλώσσα υψηλού επιπέδου. Οι στατικοί τύποι της Scala βοηθούν στην αποφυγή bugs σε πολύπλοκες εφαρμογές, ενώ τα περιβάλλοντα εκτέλεσης JVM, JavaScript και Native της επιτρέπουν να χτίσεις συστήματα υψηλών επιδόσεων με εύκολη πρόσβαση σε τεράστια οικοσυστήματα βιβλιοθηκών.

* Χαρακτηριστικά
    * Διαλειτουργικότητα με το JVM - Η Scala τρέχει στο JVM, οπότε οι στοίβες Java και Scala μπορούν να αναμιχθούν για απρόσκοπτη ενσωμάτωση.
    * Διαλειτουργικότητα με JS και Native - Η Scala μπορεί να τρέξει στον browser και σε native συσκευές, χάρη στα [Scala.js](https://www.scala-js.org/) και [Scala Native](https://github.com/scala-native/scala-native)
    * Εξαγωγή τύπων - Η Scala είναι στατικά τυποποιημένη. Ωστόσο, παρέχει εξαγωγή τύπων για να αμβλύνει το βάρος ενός προηγμένου συστήματος τύπων.
    * Αντικειμενοστραφής - Η Scala είναι μια καθαρά αντικειμενοστραφής γλώσσα με την έννοια ότι κάθε τιμή είναι ένα αντικείμενο. Οι τύποι δεδομένων και οι συμπεριφορές των αντικειμένων περιγράφονται από κλάσεις και traits. Οι αφαιρέσεις κλάσεων επεκτείνονται με υποκλάση και με έναν ευέλικτο μηχανισμό σύνθεσης βασισμένο σε mixins, ώστε να αποφεύγονται τα προβλήματα της πολλαπλής κληρονομικότητας.
    * Συναρτησιακός - Η Scala είναι επίσης μια συναρτησιακή γλώσσα με την έννοια ότι κάθε συνάρτηση είναι μια τιμή. Παρέχει ελαφριά σύνταξη για τον ορισμό ανώνυμων συναρτήσεων, υποστηρίζει συναρτήσεις υψηλότερης τάξης, επιτρέπει την εμφώλευση συναρτήσεων και υποστηρίζει currying. Οι case classes της Scala και η ενσωματωμένη υποστήριξη για αντιστοίχιση προτύπων μοντελοποιούν τους αλγεβρικούς τύπους που χρησιμοποιούνται σε πολλές συναρτησιακές γλώσσες προγραμματισμού. Τα αντικείμενα singleton παρέχουν έναν εύχρηστο τρόπο ομαδοποίησης συναρτήσεων που δεν είναι μέλη κάποιας κλάσης.
    * Ταυτοχρονισμός και Κατανομή - Χρησιμοποίησε παράλληλες πράξεις δεδομένων σε συλλογές, χρησιμοποίησε actors για ταυτοχρονισμό και κατανομή, ή futures για ασύγχρονο προγραμματισμό.
