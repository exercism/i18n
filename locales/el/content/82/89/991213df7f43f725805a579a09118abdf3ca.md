# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                                              |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | είσοδος   | διεύθυνση | πρώτο χρώμα ως συμβολοσειρά τερματισμένη με null        |
| `$a1`    | είσοδος   | διεύθυνση | δεύτερο χρώμα ως συμβολοσειρά τερματισμένη με null      |
| `$a2`    | είσοδος   | διεύθυνση | τρίτο χρώμα ως συμβολοσειρά τερματισμένη με null (ενδεχομένως κενό) |
| `$v0`    | έξοδος    | ακέραιος | τιμή αντίστασης                                        |
| `$t0-9`  | προσωρινός | οτιδήποτε | για προσωρινή αποθήκευση                               |
