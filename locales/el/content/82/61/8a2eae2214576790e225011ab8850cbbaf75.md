# Διανύσματα ως στοίβα

Μια στοίβα είναι μια γραμμική δομή δεδομένων βελτιστοποιημένη για πρόσβαση από το ένα άκρο. Μια κατάλληλη μεταφορά είναι ένας σωρός από φύλλα χαρτιού περασμένα σε έναν άξονα: τα νέα φύλλα χαρτιού προστίθενται πάντα στο ίδιο άκρο και αφαιρούνται με την αντίστροφη σειρά από αυτήν με την οποία προστέθηκαν. Τα φύλλα που προστέθηκαν πρώτα αφαιρούνται τελευταία και όσα προστέθηκαν τελευταία αφαιρούνται πρώτα.

Η δομή δεδομένων `Vec` της Rust είναι κατάλληλη για χρήση ως στοίβα. Η μέθοδος [`push`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push) προσθέτει στοιχεία στο τέλος του διανύσματος. Η μέθοδος [`pop`](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop) αφαιρεί το τελευταίο στοιχείο από το διάνυσμα. Τόσο η `push` όσο και η `pop` απαιτούν μόνο αποσβεσμένο χρόνο `O(1)`.

## Παράδειγμα

Σε αυτό το παράδειγμα, χρησιμοποιούμε ένα διάνυσμα ως στοίβα για έναν απλό υπολογιστή [RPN](https://en.wikipedia.org/wiki/Reverse_Polish_notation). Ο πλήρης πηγαίος κώδικας βρίσκεται στο [playground](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736).

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
