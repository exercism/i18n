# Εισαγωγή

Η αντιστοίχιση προτύπων είναι η διαδικασία με την οποία η ροή του προγράμματος διακλαδώνεται ανάλογα με το αν μια τιμή ταιριάζει με δοσμένα, ενδεχομένως βαθιά, πρότυπα. Στη Haxe, η **αντιστοίχιση προτύπων** γίνεται με την έκφραση `switch` και με μεμονωμένες εκφράσεις `case`.

Δες αυτή τη δομή δεδομένων:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Τα πρότυπα αντιστοιχίζονται πάντα από πάνω προς τα κάτω.
- Το πιο πάνω πρότυπο που ταιριάζει με την τιμή εισόδου είναι αυτό του οποίου η έκφραση εκτελείται.
- Ένα πρότυπο `_` ταιριάζει με οτιδήποτε, οπότε το `case _:` είναι ίσο με το `default:`

## Αντιστοίχιση enum

Τα enum μπορούν να αντιστοιχιστούν με τον κατασκευαστή τους με φυσικό τρόπο:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
