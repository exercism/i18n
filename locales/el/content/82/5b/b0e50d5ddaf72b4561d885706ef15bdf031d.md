# Εισαγωγή

Στη C#, οι δομές δεδομένων που μπορούν να περιέχουν μηδέν ή περισσότερα στοιχεία ονομάζονται _συλλογές_. Ένας **πίνακας** είναι μια συλλογή που έχει σταθερό μέγεθος/μήκος και της οποίας όλα τα στοιχεία πρέπει να είναι του ίδιου τύπου. Τα στοιχεία μπορούν να ανατεθούν σε έναν πίνακα ή να ανακτηθούν από αυτόν χρησιμοποιώντας μια θέση. Οι πίνακες στη C# έχουν μηδενική βάση, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Οι πίνακες μπορούν επίσης να οριστούν χρησιμοποιώντας έναν συντομευμένο συμβολισμό που σου επιτρέπει και να δημιουργήσεις τον πίνακα και να ορίσεις τις τιμές του. Καθώς ο μεταγλωττιστής μπορεί πλέον να καταλάβει πόσα στοιχεία θα έχει ο πίνακας, το μήκος μπορεί να παραλειφθεί:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Οι πίνακες μπορούν να υποστούν επεξεργασία είτε καλώντας τις μεθόδους ή τις ιδιότητες ενός στιγμιοτύπου πίνακα, είτε χρησιμοποιώντας τις στατικές μεθόδους που ορίζονται στην κλάση `Array`.
