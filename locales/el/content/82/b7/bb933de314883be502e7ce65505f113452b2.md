# Οδηγίες

Σε αυτή την άσκηση, θα επεξεργάζεσαι μηνύματα log με έξι επίπεδα σοβαρότητας.

Κάθε γραμμή log είναι μια συμβολοσειρά με την εξής μορφή: `"[<LVL>]: <MESSAGE>"`.

Αυτά είναι τα διάφορα επίπεδα log:

| ΕΠΙΠΕΔΟ   | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Ανάλυση του επιπέδου του log

Όρισε ένα enum `LogLevel` που έχει έξι στοιχεία, τα οποία αντιστοιχούν στα επίπεδα log που ορίστηκαν παραπάνω.
Στη συνέχεια, όρισε τη συνάρτηση `parse_log_level`, η οποία παίρνει ως παράμετρο το μήνυμα log και επιστρέφει το μέλος του enum που αντιστοιχεί στο επίπεδό του.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Υποστήριξη άγνωστου επιπέδου log

Δυστυχώς, κάποια μηνύματα log εμφανίζονται περιστασιακά με _άγνωστη_ σοβαρότητα. Για να χειριστείς ομαλά αυτά τα "μυστηριώδη" μηνύματα log στη συνάρτηση `parse_log_level`, πρόσθεσε ένα μέλος `Unknown` στο enum `LogLevel`, το οποίο επιστρέφεται όταν αναλύεται ένα άγνωστο επίπεδο log:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Μετατροπή ενός μηνύματος log στη σύντομη μορφή

Το επίπεδο log μιας γραμμής log είναι αρκετά αναλυτικό. Για να μειωθεί ο χώρος στον δίσκο που χρειάζεται για την αποθήκευση των μηνυμάτων log, ορίζεται μια σύντομη μορφή: `"[<CODE_LEVEL>]:<MESSAGE>"`.

Οι κωδικοί των επιπέδων log ακολουθούν μια απλή αντιστοίχιση:

| ΕΠΙΠΕΔΟ   | ΚΩΔΙΚΟΣ |
| --------- | ------- |
| `Trace`   | `0`     |
| `Debug`   | `1`     |
| `Info`    | `4`     |
| `Warning` | `5`     |
| `Error`   | `6`     |
| `Fatal`   | `7`     |
| `Unknown` | `42`    |

Όρισε τη συνάρτηση `convert_to_short_log()`, η οποία παίρνει δύο παραμέτρους:

1. Επίπεδο log - Το επίπεδο του log που στάλθηκε. π.χ.: `LogLevel.Error`.
2. Μήνυμα log - Το μήνυμα τύπου `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Δημιουργία ψευδώνυμου

Φαίνεται πως ο χρήστης έχει δημιουργήσει μηνύματα log για το `LogLevel.Warn` αντί για το `LogLevel.Warning`. Δημιούργησε ένα `alias` για το `LogLevel.Warning` και επέστρεψε το νέο μέλος ψευδώνυμο στη συνάρτηση `get_warn_alias`.

Αυτό μπορεί να γίνει στο ίδιο enum `LogLevel` που έχει ήδη οριστεί στην αρχή του αρχείου. Και τα δύο LogLevel πρέπει να δείχνουν στην ίδια τιμή: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Όλα τα ονόματα και οι τιμές των μελών

Όρισε τη συνάρτηση `get_members()`.

Αυτή η συνάρτηση πρέπει να επιστρέφει μια λίστα από πλειάδες `(name, value)` που περιέχουν όλα τα μέλη του enum `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
