# Προσάρτημα οδηγιών

## Μορφή εξόδου

Η μέθοδος `solve()` αναμένεται να επιστρέψει ένα αντικείμενο με τις εξής ιδιότητες:

- `moves` - ο αριθμός των ενεργειών με τους κουβάδες που χρειάζονται για να φτάσεις στην ποσότητα-στόχο
  (περιλαμβάνει το γέμισμα του αρχικού κουβά),
- `goalBucket` - το όνομα του κουβά που έφτασε στην ποσότητα-στόχο,
- `otherBucket` - η ποσότητα που περιέχει ο άλλος κουβάς.

Παράδειγμα:

```json
{
  "moves": 5,
  "goalBucket": "one",
  "otherBucket": 2
}
```
