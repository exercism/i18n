# Προσθήκη οδηγιών

## Υλοποίηση

Παραδοχές:

1. Το μηδέν αναπαρίσταται πάντα στις εξόδους ως [0] αντί για [].
2. Σε καμία άλλη περίπτωση δεν υπάρχουν αρχικά μηδενικά σε οποιεσδήποτε εξόδους.
3. Τα αρχικά μηδενικά γίνονται δεκτά στις εισόδους.
4. Μια κενή ακολουθία ψηφίων εισόδου θεωρείται μηδέν και όχι σφάλμα.

Χειρίσου τις προβληματικές περιπτώσεις επιστρέφοντας ένα σφάλμα του οποίου η μέθοδος `Error()` επιστρέφει ένα από τα παρακάτω μηνύματα:

- input base must be >= 2
- output base must be >= 2
- all digits must satisfy 0 <= d < input base
