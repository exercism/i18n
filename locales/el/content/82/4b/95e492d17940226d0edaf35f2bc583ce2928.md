# Οδηγίες

Η Mika, η διοργανώτρια εκδηλώσεων, πήρε προαγωγή στη δουλειά της και, ως μέρος των νέων της αρμοδιοτήτων, έχει αναλάβει τη βάση δεδομένων των εκδηλώσεων. Γρήγορα πρόσεξε ότι πολλά από τα δεδομένα είναι αποθηκευμένα με τρόπους που κάνουν τη δουλειά μαζί τους δύσκολη, οπότε συνεργάζεστε για να τα τακτοποιήσετε με ένα script μιας χρήσης.

Επειδή το script θα τρέξει μόνο μία φορά και γνωρίζεις καλά τη δομή των δεδομένων, θεωρείς ότι εδώ ταιριάζει να χρησιμοποιήσεις τις _let assertions_ της Gleam.

## 1. Εξαγωγή σφαλμάτων

Κάθε προηγούμενη εκδήλωση έχει μια λίστα με προβλήματα που συνέβησαν κατά τη διάρκειά της. Αυτά έχουν αποθηκευτεί ως αποτελέσματα, αλλά είναι πάντα η παραλλαγή `Error`.


Υλοποίησε τη συνάρτηση `extract_error`, η οποία παίρνει ένα αποτέλεσμα που αναμένεται να είναι πάντα `Error` και επιστρέφει την τιμή σφάλματος που περιέχει.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Αφαίρεση προθέματος ομάδας

Τα ονόματα των ομάδων έχουν το πρόθεμα "Team ", αλλά αυτό δεν χρειάζεται. Υλοποίησε τη συνάρτηση `remove_team_prefix` για να αφαιρείς το πρόθεμα από το όνομα μιας ομάδας.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Διαχωρισμός περιοχής και ομάδας

Κάθε εκδήλωση διοργανώνεται από μια ομάδα και κάθε ομάδα ανήκει σε μια περιοχή. Στη βάση δεδομένων είναι αποθηκευμένες σε μία μόνο συμβολοσειρά, χωρισμένες με κόμμα.

Υλοποίησε τη συνάρτηση `split_region_and_team` για να χωρίζεις τη συμβολοσειρά σε μια πλειάδα δύο συμβολοσειρών, μία για την περιοχή και μία για την ομάδα. Το πρόθεμα "Team " πρέπει να αφαιρείται από το όνομα της ομάδας.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
