# Εκμάθηση

Ο καλύτερος τρόπος για να ξεκινήσεις με τη Ceylon αυτή τη στιγμή είναι να διαβάσεις τη [γρήγορη εισαγωγή](http://ceylon-lang.org/documentation/1.3/introduction/),
στη συνέχεια να κάνεις την [ξενάγηση](http://ceylon-lang.org/documentation/1.3/tour/) ή/και την [αναλυτική περιήγηση](http://ceylon-lang.org/documentation/1.3/walkthrough/).

Μπορείς να γράψεις και να τρέξεις τα πρώτα σου προγράμματα στο [web IDE](http://try.ceylon-lang.org/) μας, οπότε δεν χρειάζεται καν να εγκαταστήσεις τίποτα για να ξεκινήσεις.

Και φυσικά μπορείς να επικοινωνήσεις με την ομάδα και τους άλλους χρήστες στη [σελίδα μας στο Gitter](https://gitter.im/ceylon/user).
