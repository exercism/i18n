# Σχετικά

Οι [κατανοήσεις λιστών][for] παρέχουν έναν μηχανισμό για τον εύκολο και δηλωτικό μετασχηματισμό _Enumerables_. Αποτελούν _συντακτική ζάχαρη_ για την επανάληψη μέσα από enumerables στην Elixir.

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

Μια κατανοόηση λίστας έχει τρία μέρη:

1. _γεννήτριες_:
   - Τιμές που απαριθμούνται από δομές που υλοποιούν το πρωτόκολλο [_Enumerable_][enumerable].
   - Εκφράσεις αντιστοίχισης προτύπων για την αποδόμηση των απαριθμημένων τιμών.
2. _Φίλτρα_: Συνθήκες Boolean, που χρησιμοποιούνται για να επιλέξουν ποιες απαριθμημένες τιμές θα χρησιμοποιηθούν κατά τη δημιουργία των νέων τιμών.
3. _Collectables_: Μια δομή που υλοποιεί το πρωτόκολλο [_Collectable_][collectable], και χρησιμοποιείται για τη συλλογή των νέων τιμών.

Υπάρχουν κατανοήσεις λιστών μίας και πολλών γραμμών. Όταν χρησιμοποιούνται περισσότερες από μία γεννήτριες, απαριθμείται το [καρτεσιανό γινόμενο][cartesian-product] των τιμών που παράγονται. Αυτό σημαίνει ότι κάθε τιμή που παράγει η πρώτη γεννήτρια θα συνδυαστεί μία φορά με κάθε τιμή που παράγει η δεύτερη γεννήτρια.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

Η τιμή μέσα στο μπλοκ do εισάγεται στο _collectable_ **για κάθε τιμή που παράγεται** από το _enumerable_.

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

Η αντιστοίχιση προτύπων μπορεί να γίνει μέσα στην κατανόηση λίστας, είτε στην αριστερή πλευρά του `<-` είτε σε δική της γραμμή.

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
