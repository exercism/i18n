# Οδηγίες

Ως μελλοντική μάγισσα, η Elyse πρέπει να εξασκηθεί στα βασικά. Έχει μια στοίβα φύλλα που θέλει να χειριστεί.

Για να γίνουν τα πράγματα λίγο πιο απλά, χρησιμοποιεί μόνο τα φύλλα 1 έως 10, ώστε η στοίβα της να μπορεί να αναπαρασταθεί με έναν πίνακα αριθμών. Η θέση ενός συγκεκριμένου φύλλου αντιστοιχεί στη θέση του μέσα στον πίνακα. Αυτό σημαίνει ότι η θέση 0 αντιστοιχεί στο πρώτο φύλλο, η θέση 1 στο δεύτερο φύλλο κ.ο.κ.

<!-- prettier-ignore-start -->
~~~~exercism/note
Όλες οι συναρτήσεις εκτός από δύο πρέπει να ενημερώνουν τον πίνακα με τα φύλλα και μετά να επιστρέφουν τον τροποποιημένο πίνακα, ένας συνηθισμένος τρόπος εργασίας γνωστός ως μοτίβο Builder, που σου επιτρέπει να συνδέεις ωραία τις συναρτήσεις μεταξύ τους σαν αλυσίδα.

Οι δύο εξαιρέσεις είναι η `getItem`, που πρέπει να επιστρέφει το φύλλο στη θέση που δίνεται, και η `checkSizeOfStack`, που πρέπει να επιστρέφει `true` αν το μέγεθος που δίνεται ταιριάζει.
~~~~
<!-- prettier-ignore-end -->

## 1. Πάρε ένα φύλλο από τη στοίβα

Για να πάρεις ένα φύλλο, επέστρεψε το φύλλο στη θέση `position` από τη στοίβα που δίνεται.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Αντάλλαξε ένα φύλλο στη στοίβα

Κάνε ένα ταχυδακτυλουργικό κόλπο και αντάλλαξε το φύλλο στη θέση `position` με το φύλλο αντικατάστασης που δίνεται.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Βάλε ένα φύλλο στην κορυφή της στοίβας

Κάνε ένα φύλλο να εμφανιστεί βάζοντας ένα νέο φύλλο στην κορυφή της στοίβας.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Αφαίρεσε ένα φύλλο από τη στοίβα

Κάνε ένα φύλλο να εξαφανιστεί αφαιρώντας από τη στοίβα το φύλλο στη θέση `position` που δίνεται.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Αφαίρεσε το πάνω φύλλο από τη στοίβα

Κάνε ένα φύλλο να εξαφανιστεί αφαιρώντας το φύλλο στην κορυφή της στοίβας.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Βάλε ένα φύλλο στον πάτο της στοίβας

Κάνε ένα φύλλο να εμφανιστεί βάζοντας ένα νέο φύλλο στον πάτο της στοίβας.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Αφαίρεσε ένα φύλλο από τον πάτο της στοίβας

Κάνε ένα φύλλο να εξαφανιστεί αφαιρώντας το φύλλο στον πάτο της στοίβας.
Επέστρεψε την τροποποιημένη στοίβα.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Έλεγξε το μέγεθος της στοίβας

Έλεγξε αν το μέγεθος της στοίβας είναι ίσο με `stackSize` ή όχι.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
