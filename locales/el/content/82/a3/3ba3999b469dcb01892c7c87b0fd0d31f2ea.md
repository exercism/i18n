# Αμετάβλητες Κλάσεις

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## Τι αλλάζει

| | συνηθισμένη κλάση | αμετάβλητη κλάση |
| --- | --- | --- |
| ανάθεση | μοιράζεται το αντικείμενο | αντιγράφει την τιμή |
| μπορεί να είναι void | ναι | όχι |
| συγγραφέας του `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | ναι | όχι; το `x : SAME` υπάρχει ήδη |

Ένα αμετάβλητο αντικείμενο δεν μπορεί να είναι void, οπότε το `void(b)` είναι πάντα ψευδές και καμία ρουτίνα πάνω του δεν μπορεί να αποτύχει επειδή λείπει αντικείμενο. Αυτό εξαλείφει μια ολόκληρη κατηγορία λαθών, με το τίμημα να μην μπορείς ποτέ να πεις "δεν υπάρχει ακόμη bearing".

## Πού ζει η τιμή

Η τιμή αποθηκεύεται εκεί που βρίσκεται η μεταβλητή, μέσα σε ένα άλλο αντικείμενο ή στη στοίβα, αντί να προσπελαύνεται μέσω αναφοράς. Έτσι, ένας `ARRAY{BEARING}` κρατά τα ίδια τα bearings, όχι δείκτες προς αυτά, κάτι που τον κάνει μικρότερο και πιο γρήγορο όταν τον διατρέχεις.

Το κόστος είναι η αντιγραφή: όταν περνάς ένα μεγάλο αμετάβλητο αντικείμενο, αυτό αντιγράφεται κάθε φορά. Το καλύτερο είναι να τα κρατάς μικρά.

## Οι ρουτίνες των χαρακτηριστικών

Το `readonly attr degrees : INT` δίνει δύο ρουτίνες:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

Η δεύτερη υπάρχει ακόμη και κάτω από `readonly`, γιατί δεν αλλάζει τίποτα: δημιουργεί μια νέα τιμή. Κάτω από ένα σκέτο `attr` είναι δημόσια, ενώ κάτω από `private attr` δεν είναι.

## is_eq και str

Κανένα από τα δύο δεν παρέχεται. Γράψε `is_eq` για το `=`, και `str` ώστε το αντικείμενο να μπορεί να εκτυπωθεί και να ενωθεί με συμβολοσειρές:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

Γράφοντας `str`, η κλάση συμμορφώνεται με το `$STR`, κι αυτό είναι που επιτρέπει στα `+` και `#OUT` να τη δεχτούν.

## Οι ενσωματωμένες

Τα `INT`, `BOOL`, `CHAR`, `FLTD` και `TUP` είναι όλα αμετάβλητες κλάσεις. Δεν έχουν τίποτα το ιδιαίτερο: είναι γραμμένα σε Sather στη βιβλιοθήκη με τον ίδιο τρόπο και συμπεριφέρονται όπως συμπεριφέρονται για τους λόγους παραπάνω.
