# Εισαγωγή

## Υπερφόρτωση μεθόδων

_Η υπερφόρτωση μεθόδων_ επιτρέπει σε πολλές μεθόδους στην ίδια κλάση να έχουν το ίδιο όνομα. Οι υπερφορτωμένες μέθοδοι πρέπει να διαφέρουν μεταξύ τους είτε ως προς:

- Τον αριθμό των παραμέτρων
- Τον τύπο των παραμέτρων

Δεν υπάρχει υπερφόρτωση μεθόδων με βάση τον τύπο επιστροφής.

Ο μεταγλωττιστής θα συμπεράνει αυτόματα ποια υπερφορτωμένη μέθοδο θα καλέσει με βάση τον αριθμό των παραμέτρων και τον τύπο τους.

## Ονομαζόμενα ορίσματα

Μέχρι τώρα έχουμε δει ότι τα ορίσματα που περνούν σε μια μέθοδο αντιστοιχίζονται με τις δηλωμένες παραμέτρους της μεθόδου με βάση τη θέση. Μια εναλλακτική προσέγγιση, ειδικά όταν μια ρουτίνα παίρνει μεγάλο αριθμό ορισμάτων, είναι ο καλών να μπορεί να αντιστοιχίζει τα ορίσματα καθορίζοντας το αναγνωριστικό της δηλωμένης παραμέτρου.

Το παρακάτω δείχνει τη σύνταξη:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```

## Προαιρετικές παράμετροι

Μια παράμετρος μεθόδου μπορεί να γίνει προαιρετική αν της εκχωρηθεί μια προεπιλεγμένη τιμή. Όταν καλείται μια μέθοδος με προαιρετικές παραμέτρους, ο καλών δε χρειάζεται να περάσει τιμή γι' αυτές. Αν δεν περαστεί τιμή για μια προαιρετική παράμετρο, θα χρησιμοποιηθεί η προεπιλεγμένη τιμή της.

Οι προαιρετικές παράμετροι _πρέπει_ να βρίσκονται στο τέλος της λίστας παραμέτρων· δε μπορούν να ακολουθούνται από μη προαιρετικές παραμέτρους.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
