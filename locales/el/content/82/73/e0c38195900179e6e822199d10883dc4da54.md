Υπάρχουν επίσης μερικές [Διαδικτυακές Κοινότητες][awesome-cl-communities] που μπορεί να είναι καλά μέρη για να ζητήσεις βοήθεια.

## Μορφοποίηση

Η Common Lisp δεν ενδιαφέρεται για την εσοχή και τη διάταξη του κώδικα,
ούτε για το αν χρησιμοποιείς κενά ή tab, αλλά για τις υποβολές στο exercism
αυτό είναι ένα σημαντικό ζήτημα.
Το widget κώδικα του Exercism.org δεν χειρίζεται καλά την ανάμιξη χαρακτήρων tab και κενών, οπότε συνιστάται να χρησιμοποιείς μόνο κενά, ώστε
ο κώδικας να είναι πιο ευανάγνωστος για τους ανθρώπους που θα τον ελέγξουν.
Έλεγξε τις ρυθμίσεις του editor σου για το πώς θα το πετύχεις.
Παρακάτω υπάρχουν οδηγίες για δημοφιλείς editors για την Common Lisp.

### VIM

Χρησιμοποίησε τις παρακάτω εντολές για να βεβαιωθείς ότι το VIM χρησιμοποιεί μόνο κενά για
εσοχή:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(ή σε μία μόνο γραμμή με `:set tabstop=2 shiftwidth=2 expandtab`). Μπορείς
να το προσθέσεις στο αρχείο `~/.vimrc` για να το χρησιμοποιείς συνέχεια.

### Emacs

Το Emacs είναι πολύ κατάλληλο για την επεξεργασία κώδικα Common Lisp και διαθέτει πολλά
ισχυρά πρόσθετα πακέτα. Το μόνο που χρειάζεται να κάνεις με ένα απλό
Emacs για να δουλέψει καλά με το exercism.org είναι να
αξιολογήσεις τον παρακάτω κώδικα:

`(setq-default indent-tabs-mode nil)`

Μπορείς να το βάλεις στο `~/.emacs` (ή στο `~/.emacs.d/init.el`) ώστε
να ορίζεται κάθε φορά που ξεκινάει το Emacs.

Ένα προτεινόμενο πρόσθετο για το Emacs και την Common Lisp είναι το
[SLIME][slime], το οποίο προσφέρει στενή ενσωμάτωση
με το REPL, κάνοντας την επαναληπτική σύνταξη κώδικα και τις δοκιμές πολύ εύκολες.
