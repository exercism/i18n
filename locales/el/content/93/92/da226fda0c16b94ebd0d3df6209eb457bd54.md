# Σχετικά

Οι λίστες στη C# είναι συλλογές από πρωτογενείς τιμές ή στιγμιότυπα από struct ή κλάσεις. Υλοποιούνται στη βιβλιοθήκη βασικών κλάσεων ως [`List<T>`][lists-docs], όπου το `T` είναι ο τύπος του στοιχείου της λίστας. Το API εκθέτει ένα πλούσιο σύνολο μεθόδων για τη δημιουργία και τον χειρισμό λιστών.

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

Ο ορισμός μιας συλλογής περιλαμβάνει συνήθως ένα σύμβολο θέσης μέσα σε γωνιακές αγκύλες, συχνά το `T` κατά σύμβαση. Αυτό επιτρέπει σε όποιον χρησιμοποιεί τη συλλογή να καθορίσει τι τύπου στοιχεία θα αποθηκεύονται σε αυτήν.

Σε αντίθεση με [concept:csharp/arrays](), οι λίστες μπορούν να αλλάζουν δυναμικά το μέγεθός τους.

## LINQ

Αν και το ενσωματωμένο API του `List<T>` είναι πλούσιο (περιλαμβάνει αντιστοιχίσεις και φίλτρα όπως τα `ConvertAll`, `FindAll` και `Foreach`) και η [σύνταξη επανάληψης][for-each] του είναι πολύ καθαρή, και σίγουρα χρειάζεται να εξοικειωθείς με αυτό το API, το Language Integrated Query ([LINQ][linq]) είναι διαθέσιμο για πολλές εργασίες, είναι ακόμη πιο ισχυρό και ευρέως χρησιμοποιούμενο και έχει το πλεονέκτημα ότι παρέχει μια σταθερή διεπαφή σε συλλογές της βιβλιοθήκης, συλλογές τρίτων και τις δικές σου κλάσεις.
