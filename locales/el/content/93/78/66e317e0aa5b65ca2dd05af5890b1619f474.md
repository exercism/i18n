# Υπόλοιπο

Οι συγκρίσεις με το υπόλοιπο είναι απολύτως έγκυρες στη Crystal, αλλά ένας πιο ευανάγνωστος τρόπος για να συγκρίνεις το υπόλοιπο μιας διαίρεσης είναι με τη μέθοδο [`divisible_by?`][divisible_by].
Για παράδειγμα:

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.divisible_by?(2)
```

[divisible_by]: https://crystal-lang.org/api/latest/Int.html#divisible_by%%3F%%28num%%29%%3ABool-instance-method
