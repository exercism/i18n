# Υποδείξεις

Η εισαγωγή περιέχει τα περισσότερα από όσα χρειάζεσαι για αυτή την άσκηση.
Η εργασία 5 (η απεικόνιση) μπορεί να γίνει νωρίτερα για να σε βοηθήσει με την οπτικοποίηση, αλλά πρόσεξε να λάβεις υπόψη τις διαφορετικές πιθανές τιμές των κουκκίδων.

## 1. Όρισε το λογότυπο `Matrix` του Exercism

- Γίνε δημιουργικός! Ωστόσο, μπορείς απλώς να κάνεις αντιγραφή και επικόλληση από τις οδηγίες.

## 2. Όρισε συναρτήσεις που κάνουν το λογότυπο να κατσουφιάσει

- Θυμήσου ότι οι συναρτήσεις που τελειώνουν σε `!` μεταβάλλουν την είσοδο (την τροποποιούν επί τόπου), ενώ οι υπόλοιπες όχι.
- Η `frown!` μπορεί να υλοποιηθεί με ανάθεση σε συγκεκριμένα στοιχεία ή (λιγότερο αποδοτικά) εναλλάσσοντας δύο γραμμές.
- Η `frown` θα είναι πολύ παρόμοια με τη `frown!`, μόνο που επιστρέφει ένα `copy` του πίνακα εισόδου.

## 3. Συναρμολόγησε έναν τοίχο αυτοκόλλητων

- Χρησιμοποίησε τη συνάρτηση `frown()`.
- Οι συναρτήσεις `vcat()` και `hcat()`, ή τα αντίστοιχά τους, είναι οι φίλοι σου εδώ.
- Πρόσεξε ότι υπάρχει μια γραμμή από `1` (δηλαδή `X`) που χωρίζει το πάνω μισό από το κάτω μισό.
- Η συνάρτηση `ones()` μπορεί να χρησιμοποιηθεί αν θέλεις, αλλά πρόσεξε το σχήμα της.

## 4. Μετέτρεψε τις κουκκίδες σε πλήθος pixel ανά στήλη

- Το broadcasting είναι ένας εξαιρετικός τρόπος για να το κάνεις αυτό με συντομία.
- Για να κάνεις broadcasting, θα χρειαστείς ένα διάνυσμα *γραμμής* με το πλήθος των κουκκίδων κάθε στήλης.
- Για να πάρεις ένα διάνυσμα με το πλήθος των κουκκίδων ανά στήλη, μπορείς να εφαρμόσεις μια συνάρτηση στον `Matrix` με καθορισμένο το `dims`.

## 5. Απεικόνισε έναν πίνακα κουκκίδων

- Οι κουκκίδες (π.χ. `1`, `2`, κ.λπ.) και τα `0` πρέπει να μετατραπούν σε `"X"` και `" "`, αντίστοιχα.
- Η χρήση της `eachrow()` για έναν εσωτερικό βρόχο μπορεί να φανεί χρήσιμη εδώ, αλλά δεν είναι απαραίτητη.
- Η συνάρτηση `join()` μπορεί επίσης να βοηθήσει ώστε τα πράγματα να γίνουν πιο συνοπτικά και θα μπορούσε ακόμη και να εφαρμοστεί με broadcasting.
