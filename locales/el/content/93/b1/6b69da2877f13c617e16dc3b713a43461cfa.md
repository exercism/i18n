# Εισαγωγή

## Συναρτήσεις callback

Οι συναρτήσεις callback είναι συναρτήσεις που περνιούνται ως ορίσματα. Αυτό το πρότυπο προγραμματισμού δημιουργεί μια ακολουθία κλήσεων συναρτήσεων τόσο στον σύγχρονο όσο και στον ασύγχρονο προγραμματισμό. Η σύνταξη μιας συνάρτησης callback δεν διαφέρει από τη σύνταξη μιας συνάρτησης· ωστόσο, η συνάρτηση callback πρέπει να ταιριάζει με την υπογραφή που ορίζει η συνάρτηση που την καλεί.

```javascript
const sideLength = 5;

// Caller function takes a callback function
function applySideLength(callback) {
  return callback(sideLength);
}

// Callback must expect the possible argument from the calling function
function areaOfSquare(side) {
  return side * side;
}

applySideLength(areaOfSquare); // => 25
```

Μπορείς επίσης να γράψεις τις συναρτήσεις callback ως έκφραση συνάρτησης:

```javascript
applySideLength(function squarePerimeterLength(side) {
  return side * 4;
});
```
