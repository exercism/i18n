# Σχετικά

Η Perl είναι μια γλώσσα προγραμματισμού που δημιούργησε ο Larry Wall και κυκλοφόρησε για πρώτη φορά το 1987.

## Πακέτα και modules

Ένα πακέτο είναι μια συλλογή κώδικα, που συχνά βρίσκεται μέσα σε ένα αρχείο module με το ίδιο όνομα και την επέκταση `.pm`.
Το module μπορεί στη συνέχεια να εισαχθεί σε ένα άλλο αρχείο, συνήθως με τη λέξη-κλειδί `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Μεταβλητές

Υπάρχουν βαθμωτές (`$foo`), μεταβλητές πίνακα (`@bar`) και μεταβλητές hash (`%baz`).
Για να κρατήσουμε τα πράγματα απλά, εδώ θα χρησιμοποιηθούν μόνο βαθμωτές μεταβλητές.
Μια βαθμωτή τιμή μπορεί να είναι η εξής: μια συμβολοσειρά, ένας αριθμός, μια Boolean (λογική τιμή) ή μια [αναφορά][perlreftut] σε κάτι.
Η απουσία τιμής είναι το `undef`.


Οι λέξεις-κλειδιά `my` και `our` δηλώνουν μια μεταβλητή στο λεξικό πεδίο, π.χ. `my $foo;`.
Με το `our`, η μεταβλητή συνδέεται επίσης ως ψευδώνυμο με μια μεταβλητή πακέτου με το ίδιο όνομα.
Υπάρχουν και άλλοι τρόποι δήλωσης μεταβλητών που δεν θα καλυφθούν εδώ.

Μπορείς να αναθέσεις μια τιμή σε μια μεταβλητή με τον τελεστή `=`, π.χ. `$foo = 1;`, κάτι που μπορεί να γίνει ταυτόχρονα με τη δήλωση της μεταβλητής, π.χ. `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Υπορουτίνες

Η λέξη-κλειδί `sub` δηλώνει μια [υπορουτίνα][perlsub].
Η λέξη-κλειδί `return` τερματίζει την υπορουτίνα, επιστρέφοντας τις καθορισμένες τιμές ή μια κενή λίστα αν δεν δοθεί τίποτα.
Χωρίς καθορισμένο `return`, η τιμή που επιστρέφεται καθορίζεται από το πλαίσιο (βαθμωτό, λίστας ή κενού) στο οποίο χρησιμοποιείται η υπορουτίνα και από την τελευταία εντολή της.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Οι πρόσφατες εκδόσεις της Perl σου επιτρέπουν να καθορίσεις τυπικές παραμέτρους σε μια [υπογραφή][perlsubsig].
Η λίστα παραμέτρων μπορεί να περιέχει βαθμωτές μεταβλητές, μεταβλητές πίνακα ή μεταβλητές hash.
Μια κενή λίστα παραμέτρων σημαίνει ότι η υπορουτίνα δέχεται μηδέν ορίσματα.
Οι παλαιότερες εκδόσεις της Perl απαιτούσαν την ανάκτηση των ορισμάτων από την ειδική μεταβλητή `@_`, κάτι που δεν θα καλυφθεί εδώ.
