# Εισαγωγή

## Λίστες

Μια `list` στη F# είναι μια αμετάβλητη συλλογή από μηδέν ή περισσότερες τιμές. Οι τιμές σε μια λίστα πρέπει όλες να έχουν τον ίδιο τύπο. Καθώς οι λίστες είναι αμετάβλητες, μόλις κατασκευαστεί μια λίστα, η τιμή της δεν μπορεί ποτέ να αλλάξει. Οποιεσδήποτε συναρτήσεις/τελεστές φαίνεται να τροποποιούν μια λίστα (όπως η προσθήκη ενός στοιχείου), στην πραγματικότητα επιστρέφουν μια νέα λίστα.

Οι λίστες μπορούν να οριστούν ως εξής:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

Ο πιο συνηθισμένος τρόπος για να προσθέσεις ένα στοιχείο σε μια λίστα είναι μέσω του τελεστή `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Μια λίστα F# έχει μια _κεφαλή_ (το πρώτο στοιχείο) και μια _ουρά_ (ό,τι ακολουθεί μετά το πρώτο στοιχείο). Η ουρά μιας λίστας είναι η ίδια μια λίστα.

Οι λίστες είτε χειρίζονται με συναρτήσεις και τελεστές που ορίζονται στο module `List`, είτε χειροκίνητα με αντιστοίχιση προτύπων χρησιμοποιώντας τα μοτίβα _λίστας_ και _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

Μπορείς επίσης να _αγνοήσεις_ μια τιμή κατά την αντιστοίχιση προτύπων. Όταν _δεν_ σε νοιάζει μια τιμή σε μια συγκεκριμένη περίπτωση (δηλαδή δεν πρόκειται να _χρησιμοποιήσεις_ μια τιμή), μπορείς να χρησιμοποιήσεις μια κάτω παύλα (`'_'`) για να το δηλώσεις αυτό:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

Το μονό `'_'` πρέπει πάντα να έρχεται _τελευταίο_ στην αντιστοίχιση προτύπων. Κάθε τιμή που _δεν_ ταιριάζει με καμία από τις άλλες περιπτώσεις θα χειρίζεται από αυτή την περίπτωση.
