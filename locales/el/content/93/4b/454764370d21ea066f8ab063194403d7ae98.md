# Αμετάβλητες Κλάσεις

Ένας `SCOREBOARD` είναι κάτι που αλλάζει. Δύο ονόματα για έναν πίνακα αποτελεσμάτων βλέπουν το ίδιο σκορ, γιατί υπάρχει μόνο ένας πίνακας και τα δύο ονόματα δείχνουν σε αυτόν.

Μια διόπτευση δεν είναι έτσι. Το `350 degrees` δεν γίνεται κάτι άλλο· απλώς *είναι*. Οι αριθμοί συμπεριφέρονται έτσι, το ίδιο και οι συμβολοσειρές, και το ίδιο μπορούν να κάνουν και δικές σου κλάσεις.

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Δύο λέξεις αλλάζουν τα πάντα. Ένα αντικείμενο μιας αμετάβλητης κλάσης είναι μια **τιμή**, όχι κάτι στο οποίο δείχνει κάποιος:

- αντιγράφεται όταν εκχωρείται ή όταν περνιέται ως όρισμα, ώστε να μην μπορεί κανείς άλλος να αλλάξει το δικό σου·
- δεν μπορεί ποτέ να είναι void·
- και δεν μπορεί να εκχωρηθεί τιμή στα χαρακτηριστικά του.

## Αλλάζοντας ένα φτιάχνοντας ένα άλλο

Εφόσον το `degrees := 90` δεν επιτρέπεται, το `attr` δίνει κάτι άλλο: μια ρουτίνα που παίρνει τη νέα τιμή και επιστρέφει **ένα νέο αντικείμενο** με την τιμή αλλαγμένη.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

Το αρχικό μένει ανέγγιχτο. Αυτό είναι όλο το μοτίβο, και έτσι γράφεται το `create`:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Εδώ δεν υπάρχει `new`. Ένα αμετάβλητο αντικείμενο υπάρχει πάντα, οπότε το `b : SAME` είναι ήδη ένα, με κάθε χαρακτηριστικό στην κενή του τιμή.

Μια ρουτίνα που "αλλάζει" μια διόπτευση, επομένως, επιστρέφει μια καινούρια:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Σύγκριση

Οι τιμές συγκρίνονται με βάση αυτό που περιέχουν, όχι με βάση το ποιο αντικείμενο είναι, αλλά πρέπει να πεις και πώς. Γράψε `is_eq` και το `=` θα το χρησιμοποιήσει:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Χωρίς αυτό, το `=` σε δύο διοπτεύσεις δεν θα μεταγλωττιστεί.

## Ποια να διαλέξεις

Χρησιμοποίησε μια αμετάβλητη κλάση όταν το πράγμα δεν έχει ταυτότητα και τίποτα πάνω του δεν μπορεί λογικά να αλλάξει: μια διόπτευση, ένα σημείο, μια ημερομηνία, ένα μήκος. Χρησιμοποίησε μια συνηθισμένη κλάση όταν το πράγμα είναι ένα συγκεκριμένο πράγμα στο οποίο συμβαίνουν πράγματα: ένας πίνακας αποτελεσμάτων, ένα harness, ένα αρχείο.

Το κριτήριο είναι αν το "ίδιο" σημαίνει "ίσο" ή "αυτό ακριβώς το ίδιο".
