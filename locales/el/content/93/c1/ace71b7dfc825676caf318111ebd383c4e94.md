# Προσθήκη οδηγιών

## Εργασία με ημερομηνίες στην Arturo

Σε αυτή την άσκηση, θα αναλύεις ημερομηνίες από συμβολοσειρές και θα μορφοποιείς ημερομηνίες σε συμβολοσειρές. Αυτό είναι λίγο διαφορετικό από αυτό που μπορεί να έχεις συνηθίσει σε κάποια άλλη γλώσσα προγραμματισμού. Ρίξε μια ματιά στο αρχείο Hints για περισσότερες πληροφορίες.
