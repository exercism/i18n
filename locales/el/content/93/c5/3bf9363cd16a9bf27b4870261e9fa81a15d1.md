# Αναμειξία τύπων

Η αναμειξία τύπων είναι επίσης γνωστή ως εξαναγκασμός τύπων.
Αναμειξία τύπων έχουμε όταν δύο τιμές διαφορετικού τύπου εξαναγκάζονται στον ίδιο τύπο για να εκτελεστεί μια πράξη.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

Όταν αξιολογείται η παράσταση, η τιμή της συμβολοσειράς μετατρέπεται έμμεσα σε `int` για να ανταποκριθεί στις προσδοκίες του τελεστή `*`.
Η απόφαση για το ποιος τύπος θα εξαναγκαστεί λαμβάνεται από την PHP σύμφωνα με τους κανόνες της πράξης, και αυτοί οι κανόνες ποικίλλουν σε μεγάλο βαθμό.

Εξαναγκασμός τύπων συμβαίνει επίσης όταν καλούμε συναρτήσεις και μεθόδους:

```php
strlen(12321);
# => 5
```

## Μετατροπή τύπων

Αντί να βασιζόμαστε στον έμμεσο εξαναγκασμό, μπορούμε να αναγκάσουμε ρητά μια τιμή να αξιολογηθεί ως συγκεκριμένου τύπου, χρησιμοποιώντας μετατροπή τύπων σε στυλ `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Αυτό μετατρέπει την τιμή στον τύπο που ορίζεται μέσα στις παρενθέσεις `(...)`.
Όλοι οι πρωτογενείς τύποι μπορούν να χρησιμοποιηθούν ως τύπος-στόχος: `bool`, `int`, `float`, `string`, `array`, `object`.

## Μόνο προσωρινή μετατροπή

Η αναμειξία ή η μετατροπή τύπων **δεν αλλάζει** τον τύπο της τιμής που είναι αποθηκευμένη σε μια μεταβλητή.
Μετατρέπεται μόνο η είσοδος της πράξης.

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## Απώλεια πληροφοριών

Όταν μια τιμή εξαναγκάζεται σε άλλον τύπο, μπορεί να υπάρξει απώλεια πληροφοριών στη διαδικασία:

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

Η εξάρτηση από τη μετατροπή τύπων, είτε ρητή είτε έμμεση, μπορεί να προκαλέσει σφάλματα σε ένα μεγαλύτερο σύστημα.

## Ρητή μετατροπή τύπων σε `array` και `object`

Οι τιμές μπορούν επίσης να μετατραπούν σε τύπους `array` και `object`.
Αν μια τιμή που δεν είναι πίνακας ή αντικείμενο μετατραπεί σε `array`, μετατρέπεται σε ένα μόνο στοιχείο μέσα σε έναν πίνακα:

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

Όταν μετατρέπεται σε `object`, η τιμή ορίζεται σε μια δημόσια ιδιότητα με το όνομα `scalar`:

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> Η `stdClass` είναι ο τύπος μιας ανώνυμης κλάσης ενσωματωμένης στην PHP.
