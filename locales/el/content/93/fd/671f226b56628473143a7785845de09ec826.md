# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε εργοστάσιο αυτοκινήτων. Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (εκτός λειτουργίας) έως `10` (μέγιστη).

Στη χαμηλότερη ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα την ώρα. Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα. Έτσι, με την ταχύτητα ρυθμισμένη στο `4`, θα πρέπει να παράγει `4 * 221 = 884` αυτοκίνητα την ώρα. Ωστόσο, οι υψηλότερες ταχύτητες αυξάνουν τη πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία στη συνέχεια πρέπει να απορριφθούν. Ο παρακάτω πίνακας δείχνει πώς η ταχύτητα επηρεάζει το ποσοστό επιτυχίας:

- `0`: ποσοστό επιτυχίας 0%.
- `1` έως `4`: ποσοστό επιτυχίας 100%.
- `5` έως `8`: ποσοστό επιτυχίας 90%.
- `9`: ποσοστό επιτυχίας 80%.
- `10`: ποσοστό επιτυχίας 77%.

Έχεις τρεις εργασίες.

## 1. Υπολόγισε το ποσοστό επιτυχίας

Υλοποίησε τη συνάρτηση `successRate` για να υπολογίσεις το ποσοστό επιτυχίας με βάση την ταχύτητα παραγωγής:

```fsharp
successRate 6
// => 0.9
```

## 2. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Υλοποίησε τη συνάρτηση `productionRatePerHour` για να υπολογίσεις τον ρυθμό παραγωγής της γραμμής συναρμολόγησης ανά ώρα, λαμβάνοντας υπόψη το ποσοστό επιτυχίας της:

```fsharp
productionRatePerHour 6
// => 1193.4
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `float`.

## 3. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά λεπτό

Υλοποίησε τη συνάρτηση `workingItemsPerMinute` για να υπολογίσεις πόσα λειτουργικά αυτοκίνητα παράγονται ανά λεπτό:

```fsharp
workingItemsPerMinute 6
// => 19
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `int`.
