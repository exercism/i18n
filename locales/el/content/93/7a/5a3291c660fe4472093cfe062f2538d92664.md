# Εισαγωγή

Τα struct είναι μια επέκταση χτισμένη πάνω στους [χάρτες][exercism-maps], που παρέχουν ελέγχους κατά τη μεταγλώττιση και προεπιλεγμένες τιμές. Ένα struct παίρνει το όνομά του από το module στο οποίο ορίζεται. Για να ορίσεις ένα struct χρησιμοποιείς την κατασκευή `defstruct`. Η κατασκευή αυτή συνήθως ακολουθεί αμέσως μετά τον ορισμό του module. Το `defstruct` δέχεται είτε μια λίστα από atoms (για προεπιλεγμένες τιμές `nil`) είτε μια keyword list (για συγκεκριμένες προεπιλεγμένες τιμές). Τα πεδία χωρίς προεπιλεγμένες τιμές πρέπει να προηγούνται των πεδίων με προεπιλεγμένες τιμές.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

## Πρόσβαση στα πεδία και ενημέρωση

Επειδή τα struct είναι χτισμένα πάνω σε χάρτες, μπορούμε να χρησιμοποιήσουμε τις περισσότερες συναρτήσεις των χαρτών για να πάρουμε και να χειριστούμε τιμές. Το _Access Behaviour_ **δεν** υλοποιείται για τα struct. Αντ' αυτού, συνιστάται να χρησιμοποιείς τον _τελεστή στατικής πρόσβασης_ `.` για να έχεις πρόσβαση στα πεδία ενός struct.

- για να πάρεις/να ανακτήσεις τιμές πεδίων:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- για να ενημερώσεις τιμές πεδίων

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

## Αντιστοίχιση προτύπων

Τα struct μπορούν να χρησιμοποιηθούν σε αντιστοίχιση προτύπων με ή χωρίς το όνομα του struct.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Βάζοντας το όνομα του struct στο πρότυπο, μπορείς να βεβαιωθείς ότι και η αριστερή και η δεξιά πλευρά είναι struct του ίδιου τύπου.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

## Επιβολή αρχικοποίησης των τιμών των πεδίων

Μπορούμε να χρησιμοποιήσουμε το χαρακτηριστικό module `@enforce_keys` με μια λίστα από κλειδιά πεδίων για να βεβαιωθούμε ότι οι τιμές αρχικοποιούνται όταν δημιουργείται το struct. Αν ένα κλειδί δεν είναι στη λίστα, η τιμή του θα είναι `nil`, όπως φαίνεται στο παραπάνω παράδειγμα. Αν ένα κλειδί που επιβάλλεται δεν αρχικοποιηθεί, πετιέται ένα σφάλμα.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
