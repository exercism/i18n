# Υποδείξεις

## 1. Εκτύπωσε ένα σήμα για έναν υπάλληλο

- Μπορείς να χρησιμοποιήσεις το [πρότυπο συμβολοσειράς][string-template] για να δημιουργήσεις συμβολοσειρές περιγραφής.
- Υπάρχει μια [ενσωματωμένη μέθοδος για τη μετατροπή μιας συμβολοσειράς σε κεφαλαία][to-upper-case].

## 2. Εκτύπωσε ένα σήμα για έναν νέο υπάλληλο

- Θα πρέπει να ελέγξεις αν το αναγνωριστικό είναι `null` πριν το χρησιμοποιήσεις.
- Μπορείς να χρησιμοποιήσεις έναν [τελεστή ισότητας][kotlin-operators] για να ελέγξεις αν μια τιμή είναι `null`.

## 3. Εκτύπωσε ένα σήμα για τον ιδιοκτήτη

- Μπορείς να χρησιμοποιήσεις τον [τελεστή Elvis][elvis-operator] για να χρησιμοποιήσεις μια εναλλακτική τιμή όταν μια μεταβλητή είναι `null`.
