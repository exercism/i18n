# Σχετικά

Τέσσερις λέξεις από το [`grouping`][grouping] και το
[`splitting`][splitting] καλύπτουν σχεδόν κάθε ανάγκη του τύπου
"κόψε μια ακολουθία σε κομμάτια":

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| λέξη              | αποτέλεσμα                                                              |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`, μη επικαλυπτόμενα κομμάτια μεγέθους *n*          |
| `clump`           | `( seq n -- clumps )`, επικαλυπτόμενα παράθυρα μεγέθους *n*             |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`, σπάσιμο όταν το quot είναι αληθές |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`, σπάσιμο όταν το quot για *γειτονικά* στοιχεία είναι `f` |

Ένα χρήσιμο νοητικό μοντέλο:

- **`group` / `clump`** κοιτούν τα μεγέθη· η παράμετρος *n* λέει
  πόσο μεγάλο είναι κάθε παράθυρο.
- **`split-when`** κοιτάει *μεμονωμένα στοιχεία*· το κατηγόρημα
  αποφασίζει αν κάθε στοιχείο αποτελεί "σπάσιμο".
- **`monotonic-split`** κοιτάει *ζεύγη*· το κατηγόρημα αποφασίζει
  αν δύο γειτονικά στοιχεία ανήκουν ακόμα στην ίδια σειρά.

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
