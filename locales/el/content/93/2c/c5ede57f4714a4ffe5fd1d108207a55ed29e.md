# Εισαγωγή

Η τιμή `null` δηλώνει την _απουσία_ μιας τιμής. Ένας **nullable** τύπος είναι ένας τύπος που επιτρέπει σε μια μεταβλητή να πάρει την τιμή `null`. Για να κάνεις οποιονδήποτε τύπο nullable, τον τυλίγεις με `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Για να ελέγξεις αν μια τιμή είναι αυτή τη στιγμή `null`, χρησιμοποίησε απλώς μια έκφραση `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
