# Εισαγωγή στις βεβαιώσεις τύπου

Οι διεπαφές στη Go μπορούν να δημιουργήσουν ασάφεια ως προς τον υποκείμενο τύπο.
Μια βεβαίωση τύπου μάς επιτρέπει να εξαγάγουμε την υποκείμενη συγκεκριμένη τιμή μιας τιμής διεπαφής, με αυτή τη σύνταξη: `interfaceVariable.(concreteType)`.

Για παράδειγμα:

```go
var input interface{} = 12
number := input.(int)
```

ΣΗΜΕΙΩΣΗ: αυτό θα προκαλέσει panic αν η μεταβλητή διεπαφής δεν περιέχει τιμή του συγκεκριμένου τύπου.

Μπορούμε να ελέγξουμε αν μια τιμή διεπαφής περιέχει έναν συγκεκριμένο τύπο, αξιοποιώντας και τις δύο τιμές επιστροφής της βεβαίωσης τύπου: την υποκείμενη τιμή και μια τιμή boolean που δηλώνει αν η βεβαίωση πέτυχε.
Για παράδειγμα:

```go
str, ok := input.(string) // no panic if input is not a string
```

Αν το `input` περιέχει ένα `string`, τότε το `str` θα είναι η υποκείμενη τιμή και το `ok` θα είναι αληθής.
Αν το `input` δεν περιέχει ένα `string`, τότε το `str` θα είναι η μηδενική τιμή του τύπου `string` (δηλ. `""`, η κενή συμβολοσειρά) και το `ok` θα είναι ψευδής.
Δεν προκαλείται panic σε καμία περίπτωση.

## Διακόπτες τύπου

Ένας **διακόπτης τύπου** μπορεί να εκτελέσει πολλές βεβαιώσεις τύπου στη σειρά.
Έχει την ίδια σύνταξη με μια βεβαίωση τύπου (`interfaceVariable.(concreteType)`), αλλά το `concreteType` αντικαθίσταται από τη λέξη-κλειδί `type`.
Να ένα παράδειγμα:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
