# Προσθήκη στις οδηγίες

## Φτιάξε το δικό σου DSL

Σε αυτή την άσκηση, έχεις απόλυτη ελευθερία να σχεδιάσεις το DSL για γράφους των ονείρων σου.

Τα τεστ απαιτούν μόνο να φτιάξεις μερικούς συγκεκριμένους γράφους, και ο τρόπος που θα τους φτιάξεις εξαρτάται απόλυτα από εσένα.

Για να διπλασιάσεις τη διασκέδαση, μπορείς προαιρετικά να δοκιμάσεις να υλοποιήσεις μια συνάρτηση `to_dot` που μετατρέπει τον γράφο σου στη μορφή DOT!

## Αναπαράσταση γράφου

Όρισε το DSL σου στο `Graph.roc` και μετά χρησιμοποίησέ το για να κατασκευάσεις τους γράφους που ζητά το stub.
Τα δύο αναγνωριστικά κόμβων σε κάθε `EdgeId` πρέπει να είναι ταξινομημένα αλφαβητικά.

| Ορισμός | Γράφος προς κατασκευή |
| --- | --- |
| `empty_graph` | Ένας κενός γράφος |
| `graph_with_one_node` | Ένας κόμβος |
| `graph_with_one_node_with_attribute` | Ένας κόμβος με ένα χαρακτηριστικό |
| `graph_with_one_edge` | Μία ακμή |
| `graph_with_one_attribute` | Ένα χαρακτηριστικό γράφου |
| `graph_with_nodes_edges_and_attributes` | Κόμβοι, ακμές και χαρακτηριστικά |
| `multiple_edges_on_one_line` | Πολλαπλές ακμές σε μία γραμμή |
| `only_1_edge_between_nodes` | Μόνο μία ακμή ανάμεσα σε κάθε ζεύγος κόμβων |
