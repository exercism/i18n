# Εισαγωγή

## Χώροι ονομάτων

Οι χώροι ονομάτων είναι ένας τρόπος να ομαδοποιείς κώδικα που σχετίζεται και να αποφεύγεις τις συγκρούσεις ονομάτων, και υπάρχουν γενικά σε κάθε κώδικα, εκτός από τις πιο τετριμμένες περιπτώσεις.

Η σύνταξη είναι η εξής:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Οι τύποι που περικλείονται σε χώρους ονομάτων αναφέρονται έξω από το πεδίο του χώρου ονομάτων βάζοντας μπροστά στο όνομα του τύπου τη σύνταξη με τελεία. Εναλλακτικά, και πιο συνηθισμένα, μπορείς να τοποθετήσεις μια οδηγία `using` στην αρχή του αρχείου (ή μέσα σε έναν χώρο ονομάτων) και ο τύπος μπορεί να χρησιμοποιηθεί χωρίς το πρόθεμα. Μέσα στον ίδιο χώρο ονομάτων δε χρειάζεται να προσδιορίσεις τα ονόματα των τύπων.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Μπορείς να δώσεις ένα ψευδώνυμο σε έναν χώρο ονομάτων με τη σύνταξη `using MyAlias = MySpace;` και μετά να χρησιμοποιήσεις το ψευδώνυμο οπουδήποτε θα μπορούσε να χρησιμοποιηθεί ο χώρος ονομάτων.
