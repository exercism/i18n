# Εισαγωγή

Ο τύπος `Result` επιτρέπει σε μια συνάρτηση να επιστρέψει μία μόνο τιμή που υποδεικνύει όλα τα παρακάτω:

- Αν η λειτουργία πέτυχε ή απέτυχε
- Σε περίπτωση επιτυχίας, την τιμή που προκύπτει από τη λειτουργία
- Σε περίπτωση αποτυχίας, τον λόγο της αποτυχίας

## Χρήση

Το `Result` είναι ένας γενικός τύπος που περιέχει δύο υποκείμενους τύπους:

- Τον τύπο της τιμής που προκύπτει από μια επιτυχημένη λειτουργία
- Τον τύπο που αντιπροσωπεύει τον λόγο της αποτυχίας σε περίπτωση αποτυχίας

Ο τύπος `Result` είναι επίσης μια [discriminated union][discriminated-union] με τις εξής πιθανές περιπτώσεις:

- `Ok <value>` που αντιπροσωπεύει ένα επιτυχημένο αποτέλεσμα
- `Error <reason>` που αντιπροσωπεύει μια αποτυχία

Η παρακάτω συνάρτηση δείχνει πώς να δημιουργήσεις μια τιμή `Result`:

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Σε αυτό το παράδειγμα, η τιμή `Ok` είναι μια συμβολοσειρά (το όνομα που δόθηκε), και η τιμή `Error` είναι επίσης μια συμβολοσειρά (η αιτία του σφάλματος, σε μορφή αναγνώσιμη από τον άνθρωπο).

## Διαβάζοντας το περιεχόμενο μιας τιμής `Result`

Θεώρησε τον ακόλουθο ορισμό τύπου και την υπογραφή συνάρτησης:

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Ο κώδικας που καλεί τη συνάρτηση `openFile` μπορεί να χρησιμοποιήσει αντιστοίχιση προτύπων για να χειριστεί τις περιπτώσεις επιτυχίας και αποτυχίας, όπως στο παρακάτω παράδειγμα:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```

[discriminated-union]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/discriminated-unions
