# Debug

Όταν ένα test αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε λάθος και για ποια είσοδο.
Μπορείς να εξετάσεις αυθαίρετες τιμές στο πρόγραμμά σου περνώντας τις στη μέθοδο `debug` (διαθέσιμη στο `exercism/test_runner`).
Αυτό θα καταγράψει τις τιμές και θα σου δείξει την έξοδο.


```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
