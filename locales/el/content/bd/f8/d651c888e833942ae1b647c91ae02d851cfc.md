# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Αν δεις ένα σφάλμα `panic` όταν τρέχεις τα tests, αυτό συμβαίνει επειδή δεν έχεις υλοποιήσει μία από τις συναρτήσεις (θα πρέπει να λέει ποια) ή επειδή έχεις αφήσει τον κώδικα-πρότυπο στη θέση του.
  Πρέπει να αφαιρέσεις τη γραμμή `panic!(...)` από τον κώδικα που σου δίνεται και να την αντικαταστήσεις με μια πραγματική υλοποίηση.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς παραμέτρους.
- Πρέπει να [επιστρέψεις][return] τον αναμενόμενο χρόνο ψησίματος σε λεπτά από τη συνάρτηση.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Η παράμετρος της συνάρτησης είναι μια [ακέραια τιμή][integers].
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια συνάρτηση.
- Μπορείς να [καλέσεις][functions] μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Η παράμετρος της συνάρτησης είναι μια [ακέραια τιμή][integers].
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια συνάρτηση.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον χρόνο εργασίας που πέρασε σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Η παράμετρος της συνάρτησης είναι μια [ακέραια τιμή][integers].
- Πρέπει να [επιστρέψεις ρητά μια ακέραια τιμή][return] από μια συνάρτηση.
- Μπορείς να [καλέσεις][functions] μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.
