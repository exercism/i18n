# Γραμμή εντολών

Μπορείς να τρέξεις τα tests ανοίγοντας μια γραμμή εντολών στον κατάλογο της άσκησης και τρέχοντας την [εντολή `stack test`][docs-stack-test]. Αν ο κώδικάς σου μεταγλωττίζεται, αυτή η εντολή θα σου δείξει ποια tests πέρασαν και ποια απέτυχαν. Όταν ένα test αποτύχει, προσπάθησε να το κάνεις να περάσει και τρέξε τα tests ξανά.

Μόλις περάσουν όλα τα tests, μπορείς να υποβάλεις τη λύση σου ανοίγοντας μια γραμμή εντολών στον κατάλογο της άσκησης και τρέχοντας την [εντολή `exercism submit`][docs-exercism-cli].

[docs-stack-test]: https://docs.haskellstack.org/en/stable/build_command/
[docs-exercism-cli]: https://exercism.io/cli
