# Σχετικά

## Κληρονομικότητα

Η Java υποστηρίζει την κληρονομικότητα ως βασική λειτουργία της, ώστε να επιτυγχάνονται πολλές αρχές του αντικειμενοστρεφούς προγραμματισμού, όπως η αφαίρεση.

Μια κλάση μπορεί να επεκτείνει μια άλλη κλάση χρησιμοποιώντας τη λέξη-κλειδί `extends` και μπορεί να κληρονομήσει από μια διεπαφή χρησιμοποιώντας τη λέξη-κλειδί `implements`.

## Τροποποιητές Πρόσβασης

Οι τροποποιητές πρόσβασης ορίζουν κανόνες για τις μεταβλητές μέλους και τις μεθόδους μιας κλάσης, σχετικά με την πρόσβαση σε αυτές από άλλες κλάσεις (ή από οπουδήποτε στον κώδικα).

Υπάρχουν τέσσερις τροποποιητές πρόσβασης:

- `private`
- `public`
- `protected`
- προεπιλεγμένος (Δεν απαιτείται λέξη-κλειδί)

Μπορείς να διαβάσεις περισσότερα [σε αυτό το άρθρο][access-modifiers]

## Κληρονομικότητα εναντίον Σύνθεσης

Αυτές οι έννοιες είναι πολύ παρόμοιες και συχνά συγχέονται.

- Η κληρονομικότητα σημαίνει ότι το παιδί έχει σχέση IS-A με τη γονική κλάση.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Εδώ, το `Dog` IS-A `Animal`

- Η σύνθεση αντιπροσωπεύει μια σχέση HAS-A.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Εδώ, το `Car` HAS-A `Engine`
