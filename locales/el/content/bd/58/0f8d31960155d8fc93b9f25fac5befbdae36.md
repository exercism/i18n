# Εισαγωγή

## Ξεκινώντας

### Μεταβλητές

Μπορείς να αποθηκεύσεις και να ονομάσεις τιμές ορίζοντας μια [μεταβλητή][constants-variables].
Αφού ορίσεις μια μεταβλητή, μπορείς να χρησιμοποιήσεις το όνομά της για να αναφέρεσαι σε αυτή την τιμή σε όλο τον κώδικά σου.
Οι μεταβλητές είναι _μεταβλητές_, που σημαίνει ότι οι τιμές τους μπορούν να αλλάξουν αφού οριστούν.

Όρισε μια μεταβλητή με τη λέξη-κλειδί `var`:

```swift
var variableName = 10
```

Η Swift είναι μια γλώσσα με στατικούς τύπους, που σημαίνει ότι κάθε τιμή έχει γνωστό τύπο κατά τη μεταγλώττιση.
Μπορείς να δηλώσεις ρητά έναν τύπο με μια [σημείωση τύπου][type annotations] ή να αφήσεις τον μεταγλωττιστή της Swift να [συμπεράνει τον τύπο][type-inferring] από την τιμή που αναθέτεις:

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

Μπορείς να ενημερώσεις την τιμή μιας μεταβλητής με τον τελεστή ανάθεσης (`=`):

~~~~exercism/note
Ο τύπος μιας μεταβλητής δεν μπορεί να αλλάξει αφού δηλωθεί.

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Μπορείς να δηλώσεις μια μεταβλητή χωρίς αρχική τιμή προσδιορίζοντας τον τύπο της, αλλά πρέπει να της αναθέσεις μια τιμή πριν τη χρησιμοποιήσεις:

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### Σταθερές

Οι [σταθερές][constants-variables] επίσης συσχετίζουν ένα όνομα με μια τιμή, αλλά οι τιμές τους δεν μπορούν να αλλάξουν μετά την ανάθεση.
Είναι _αμετάβλητες_.
Όρισε μια σταθερά με τη λέξη-κλειδί `let` (έστω):

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Αριθμητικοί τελεστές

Η Swift παρέχει τους βασικούς [αριθμητικούς τελεστές][arithmetical-operators] για απλές μαθηματικές πράξεις:

- Πρόσθεση: `+`
- Αφαίρεση: `-`
- Πολλαπλασιασμός: `*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Συναρτήσεις

Στη Swift, οι [συναρτήσεις][functions] είναι αυτοτελή κομμάτια κώδικα που εκτελούν μια συγκεκριμένη εργασία.
Οι συναρτήσεις μπορούν να δέχονται εισόδους, να επιστρέφουν μια τιμή και να περνούν ως τιμές σε άλλες συναρτήσεις.
Όρισε μια συνάρτηση με τη λέξη-κλειδί `func`, ακολουθούμενη από το όνομα της συνάρτησης, μια λίστα παραμέτρων μέσα σε παρενθέσεις και έναν προαιρετικό τύπο επιστροφής:

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Οι συναρτήσεις στη Swift χρησιμοποιούν [ετικέτες ορίσματος][argument-labels], που κάνουν τον κώδικα να διαβάζεται σαν φυσικές προτάσεις:

- Η **ετικέτα ορίσματος** χρησιμοποιείται όταν καλείς τη συνάρτηση.
- Το **όνομα παραμέτρου** χρησιμοποιείται μέσα στο σώμα της συνάρτησης για να προσπελάσεις την τιμή.

Αν δώσεις μόνο ένα όνομα, η Swift το χρησιμοποιεί και ως ετικέτα ορίσματος και ως όνομα παραμέτρου:

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

Αν δεν θέλεις ετικέτα ορίσματος όταν καλείς τη συνάρτηση, γράψε μια κάτω παύλα (`_`) πριν από το όνομα της παραμέτρου:

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

Όλες οι παράμετροι μιας συνάρτησης είναι σταθερές (`let`) από προεπιλογή, που σημαίνει ότι οι τιμές τους δεν μπορούν να τροποποιηθούν μέσα στο σώμα της συνάρτησης.

Για να επιστρέψεις μια τιμή από μια συνάρτηση, προσδιόρισε τον τύπο επιστροφής μετά το `->` και χρησιμοποίησε τη λέξη-κλειδί `return`:

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

Όταν μια συνάρτηση δεν επιστρέφει κάποια τιμή, ο τύπος επιστροφής της είναι `Void` (ισοδύναμος με μια κενή πλειάδα, `()`).
Σε τέτοιες συναρτήσεις μπορείς να παραλείψεις και τον τύπο επιστροφής `-> Void` και την εντολή `return`.

### Σχόλια

Η Swift υποστηρίζει δύο μορφές [σχολίων][comments]:

- Τα **σχόλια μιας γραμμής** ξεκινούν με `//` και συνεχίζουν μέχρι το τέλος της γραμμής.
- Τα **σχόλια πολλών γραμμών** περικλείονται ανάμεσα σε `/*` και `*/`.

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
