# Εισαγωγή

Μια _συμβολοσειρά_ είναι ο τύπος δεδομένων της JavaScript για την αποθήκευση δεδομένων κειμένου.

## Δημιουργία συμβολοσειράς

Δημιουργείς μια συμβολοσειρά τυλίγοντας το κείμενο σε μονά ή διπλά εισαγωγικά.
Στο Exercism χρησιμοποιούνται μονά εισαγωγικά.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Οι συμβολοσειρές ως λίστες χαρακτήρων

Μια συμβολοσειρά μπορεί να αντιμετωπιστεί ως λίστα χαρακτήρων όπου ο πρώτος χαρακτήρας έχει θέση `0`.
Μπορείς να προσπελάσεις έναν μεμονωμένο χαρακτήρα της συμβολοσειράς χρησιμοποιώντας αγκύλες και τη θέση του γράμματος που θέλεις να ανακτήσεις.

```javascript
'cat'[1];
// => 'a'
```

Μπορείς να προσδιορίσεις τον αριθμό των χαρακτήρων σε μια συμβολοσειρά προσπελαύνοντας την ιδιότητα `length`.

```javascript
'cat'.length;
// => 3
```

## Συνένωση και μέθοδοι

Ο πιο απλός τρόπος για να συνενώσεις συμβολοσειρές είναι να χρησιμοποιήσεις τον τελεστή πρόσθεσης `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Οι συμβολοσειρές παρέχουν πολλές βοηθητικές μεθόδους· δες την [τεκμηρίωση του MDN για τις μεθόδους συμβολοσειρών][mdn-string-methods] για μια πλήρη λίστα.
Η παρακάτω λίστα δείχνει μερικές από τις πιο συχνά χρησιμοποιούμενες βοηθητικές μεθόδους.

- [`toUpperCase`][mdn-to-upper-case] και [`toLowerCase`][mdn-to-lower-case] - μετατρέπουν όλους τους χαρακτήρες σε κεφαλαία ή πεζά
- [`trim`][mdn-trim] - αφαιρεί τα κενά στην αρχή και στο τέλος
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] και [`endsWith`][mdn-ends-with] - προσδιορίζουν αν μια άλλη συμβολοσειρά είναι μέρος της δεδομένης συμβολοσειράς
- [`slice`][mdn-slice] - εξάγει ένα τμήμα της συμβολοσειράς

Οι συμβολοσειρές είναι αμετάβλητες στη JavaScript. Έτσι, μια "τροποποίηση", π.χ. μέσω κάποιων από τις παραπάνω μεθόδους, θα δημιουργήσει πάντα μια νέα συμβολοσειρά αντ' αυτού.
