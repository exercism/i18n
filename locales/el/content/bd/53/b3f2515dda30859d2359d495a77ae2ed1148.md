# δημιουργήθηκε επιπλέον μεταβλητή για το όνομα

Η δημιουργία μιας επιπλέον μεταβλητής για να κρατήσει το όνομα είναι περιττή, καθώς η Go δεν περνά τις μεταβλητές με αναφορά.
Η εκ νέου ανάθεση στο `name` δεν θα αλλάξει την τιμή πέρα από το πεδίο ισχύος της συνάρτησης `ShareWith`.
Επειδή η Go δεν παρέχει τρόπο να δώσεις προεπιλεγμένες τιμές στις παραμέτρους μιας συνάρτησης,
είναι σύνηθες ιδίωμα στη Go να αναθέτεις ξανά την τιμή για να δώσεις μια προεπιλεγμένη τιμή.
