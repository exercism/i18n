# Προσθήκη οδηγιών

## Οδηγίες ειδικά για τη διαδρομή

Μπορεί να παρατηρήσεις ότι μερικές περιπτώσεις δοκιμών φαίνονται άδικες.
Ωστόσο, μπορεί να είναι άδικες για βάσιμο λόγο.
Για παράδειγμα, είναι συνηθισμένο να δίνουμε σε μικρούς ή αρχάριους παίκτες n επιπλέον πιόνια σε καθορισμένες θέσεις στο ταμπλό, οπότε μπορεί να προκύψουν ασυμφωνίες στον αριθμό των πιονιών σε ένα κατά τα άλλα απόλυτα νόμιμο παιχνίδι.

Σε κάθε περίπτωση, αυτή η άσκηση ενδιαφέρεται μόνο για τον προσδιορισμό του νικητή σε ένα παιχνίδι που μπορεί να έχει ποικιλία παραμέτρων, όπως το μήκος του ταμπλό και τα επιπλέον πιόνια.
Δεν την ενδιαφέρει καμία άλλη κατάσταση του παιχνιδιού, όπως ποιος μετακίνησε πού, πότε ή ποιανού είναι η σειρά.

Έτσι, μην παραξενεύεσαι με εκείνα τα φαινομενικά άδικα παιχνίδια.
