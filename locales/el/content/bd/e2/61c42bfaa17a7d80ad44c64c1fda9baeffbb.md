# Σχετικά

Ένα λεξιλόγιο είναι η μονάδα οργάνωσης στη Factor: μια ονομασμένη συλλογή ορισμών λέξεων.

```factor
USING: kernel ;
IN: greetings.formal

: hello ( name -- str ) "Greetings, " prepend ;
```

## Διάταξη αρχείων και καταλόγων

Τα ονόματα λεξιλογίων χρησιμοποιούν το `.` ως διαχωριστικό. Η διαδρομή ακολουθεί τις τελείες:

| Λεξιλόγιο             | Αρχείο                                     |
| ---                    | ---                                        |
| `greetings`            | `greetings/greetings.factor`               |
| `greetings.formal`     | `greetings/formal/formal.factor`           |
| `greetings.casual`     | `greetings/casual/casual.factor`           |

Ο φορτωτής της Factor αναζητά λεξιλόγια διατρέχοντας τις *ρίζες λεξιλογίων*, τη ρίζα του έργου και την ενσωματωμένη βιβλιοθήκη basis, μέχρι να βρει έναν κατάλογο του οποίου το όνομα ταιριάζει με κάθε τμήμα διαδρομής. Το τελευταίο τμήμα επαναλαμβάνεται ως όνομα αρχείου.

## `USING:` και `IN:`

Το `USING:` (μαζί με το `USE:` για ένα λεξιλόγιο τη φορά) φέρνει άλλα λεξιλόγια στη διαδρομή αναζήτησης του τρέχοντος αρχείου. Το `IN:` δηλώνει σε ποιο λεξιλόγιο *ανήκουν* οι λέξεις που ορίζονται σε αυτό το αρχείο: τα πλήρως προσδιορισμένα ονόματά τους ξεκινούν με αυτό το πρόθεμα.

```factor
USING: kernel sequences greetings.formal ;
IN: greetings

: greet-everyone ( names -- strs )
    [ hello ] map ;
```

Εδώ το `greet-everyone` βρίσκεται στο `greetings`, καλεί το `hello` από το `greetings.formal` και το `map` από το `sequences`.

## Γιατί να χωρίσεις μια λύση σε λεξιλόγια

Ο διαχωρισμός κώδικα σε λεξιλόγια σου επιτρέπει να:

- Ομαδοποιείς μικρές βοηθητικές λέξεις κατά ευθύνη, μακριά από τη ρουτίνα υψηλού επιπέδου που τις συνθέτει.
- Επαναχρησιμοποιείς τις βοηθητικές λέξεις από αλλού χωρίς να τραβάς μέσα την κύρια ρουτίνα.
- Διαβάζεις κάθε αρχείο ως ένα ενιαίο συνεκτικό επίπεδο αφαίρεσης.

Ο φορτωτής της Factor είναι αρκετά γρήγορος και τεμπέλης ώστε ο διαχωρισμός *προς τα κάτω* σε μικρότερα λεξιλόγια να είναι φθηνός· η σύμβαση στη βασική βιβλιοθήκη είναι να παραγοντοποιείς επιθετικά.
