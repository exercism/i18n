# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις ερωτευμένα ζευγάρια του λυκείου να διακηρύξουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης, δημιουργώντας μια καρδιά unicode με τα αρχικά τους:

```
❤ J.  +  M. ❤
```

## 1. Καθάρισε το όνομα

Υλοποίησε τη μέθοδο `cleanupname`.
Θα πρέπει να παίρνει ένα όνομα και να αφαιρεί από αυτό όλους τους χαρακτήρες `-`, αντικαθιστώντας τους με ένα κενό.
Θα πρέπει επίσης να αφαιρεί τα κενά από την αρχή και το τέλος του ονόματος.

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. Πάρε το πρώτο γράμμα του ονόματος

Υλοποίησε τη μέθοδο `firstletter`.
Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα ως συμβολοσειρά.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `cleanupname` που όρισες στο προηγούμενο βήμα και να τη συνθέσεις με άλλες συναρτήσεις.

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. Μορφοποίησε το πρώτο γράμμα ως αρχικό

Υλοποίησε τη μέθοδο `initial`.
Θα πρέπει να παίρνει ένα όνομα και να επιστρέφει το πρώτο του γράμμα, κεφαλαίο, ακολουθούμενο από μια τελεία.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `firstletter` που όρισες στο προηγούμενο βήμα.

```julia-repl
initial("Robert")
"R."
```

## 4. Βάλε τα αρχικά μέσα στην καρδιά

Υλοποίησε τη μέθοδο `couple`.
Θα πρέπει να παίρνει δύο ονόματα και να επιστρέφει τα αρχικά με emoji καρδιές γύρω τους.
Φρόντισε να ξαναχρησιμοποιήσεις τη μέθοδο `initial` που όρισες στο προηγούμενο βήμα.

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
