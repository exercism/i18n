# Οδηγίες

Υλοποίησε ένα βασικό αντιδραστικό σύστημα.

Ο αντιδραστικός προγραμματισμός είναι ένα παράδειγμα προγραμματισμού που εστιάζει στο πώς οι τιμές υπολογίζονται η μία σε σχέση με την άλλη, ώστε μια αλλαγή σε μια τιμή να διαδίδεται αυτόματα σε άλλες τιμές, όπως σε ένα υπολογιστικό φύλλο.

Υλοποίησε ένα βασικό αντιδραστικό σύστημα με κύτταρα με τιμές που μπορούν να οριστούν ("κύτταρα εισόδου") και κύτταρα με τιμές που υπολογίζονται σε σχέση με άλλα κύτταρα ("κύτταρα υπολογισμού"). Υλοποίησε ενημερώσεις έτσι ώστε όταν μια τιμή εισόδου αλλάξει, οι τιμές να διαδίδονται ώστε να φτάσουν σε μια νέα σταθερή κατάσταση του συστήματος.

Επιπλέον, τα κύτταρα υπολογισμού θα πρέπει να επιτρέπουν την καταχώριση συναρτήσεων επιστροφής κλήσης για ειδοποίηση αλλαγών. Κάλεσε τις συναρτήσεις επιστροφής κλήσης ενός κυττάρου όταν η τιμή του κυττάρου σε μια νέα σταθερή κατάσταση έχει αλλάξει από την προηγούμενη σταθερή κατάσταση.
