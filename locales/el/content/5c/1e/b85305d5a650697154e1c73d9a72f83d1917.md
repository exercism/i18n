# Οδηγίες

Σε αυτή την άσκηση θα παίξεις με ένα τηλεκατευθυνόμενο αυτοκίνητο, που επιτέλους μάζεψες αρκετά χρήματα για να αγοράσεις.

Τα αυτοκίνητα ξεκινούν με γεμάτες (100%) μπαταρίες.
Κάθε φορά που οδηγείς το αυτοκίνητο χρησιμοποιώντας το τηλεχειριστήριο, διανύει 20 μέτρα και καταναλώνει ένα τοις εκατό της μπαταρίας.
Το παρατσούκλι του αυτοκινήτου δεν είναι γνωστό μέχρι να δημιουργηθεί.

Το τηλεκατευθυνόμενο αυτοκίνητο έχει μια φανταχτερή οθόνη LED που δείχνει δύο πληροφορίες:

- Η συνολική απόσταση που έχει διανύσει, εμφανιζόμενη ως: `"<METERS> meters"`.
- Η υπολειπόμενη φόρτιση μπαταρίας, εμφανιζόμενη ως: `"Battery at <PERCENTAGE>%"`.

Αν η μπαταρία είναι στο 0%, δεν μπορείς πια να οδηγήσεις το αυτοκίνητο και η ένδειξη μπαταρίας θα δείχνει `"Battery empty"`.

## 1. Δημιούργησε ένα ολοκαίνουργιο τηλεκατευθυνόμενο αυτοκίνητο

Υλοποίησε τη συνάρτηση `new_remote_control_car/0` ώστε να επιστρέφει ένα ολοκαίνουργιο αντικείμενο τηλεκατευθυνόμενου αυτοκινήτου:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Δημιούργησε ένα ολοκαίνουργιο τηλεκατευθυνόμενο αυτοκίνητο με παρατσούκλι

Υλοποίησε τη συνάρτηση `new_remote_control_car/1` ώστε να επιστρέφει ένα ολοκαίνουργιο αντικείμενο τηλεκατευθυνόμενου αυτοκινήτου με ένα δεδομένο παρατσούκλι:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Εμφάνισε την απόσταση

Υλοποίησε τη συνάρτηση `display_distance/0` που παίρνει ως είσοδο ένα αντικείμενο αυτοκινήτου και επιστρέφει τη συμβολοσειρά απόστασης όπως εμφανίζεται στην οθόνη LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Εμφάνισε το ποσοστό μπαταρίας

Υλοποίησε τη συνάρτηση `display_battery/0` που παίρνει ως είσοδο ένα αντικείμενο αυτοκινήτου και επιστρέφει τη συμβολοσειρά ποσοστού μπαταρίας όπως εμφανίζεται στην οθόνη LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Αν η μπαταρία είναι στο 0%, η ένδειξη μπαταρίας θα δείχνει `"Battery empty"`.

## 5. Η οδήγηση αλλάζει την μπαταρία και την απόσταση που διανύθηκε

Υλοποίησε τη συνάρτηση `drive/0` που:

- παίρνει ως είσοδο ένα αντικείμενο αυτοκινήτου
- αυξάνει κατά 20 τα μέτρα που διανύθηκαν
- καταναλώνει 1% της μπαταρίας
- επιστρέφει το τροποποιημένο αντικείμενο αυτοκινήτου

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Λάβε υπόψη την οδήγηση με άδεια μπαταρία

Ενημέρωσε τη συνάρτηση `drive/0` ώστε να μην αυξάνει την απόσταση που διανύθηκε ούτε να μειώνει το ποσοστό μπαταρίας όταν η μπαταρία είναι άδεια (στο 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
