# Μάθηση

Καθώς η Red δεν είναι ακριβώς ένα ολοκληρωμένο προϊόν (βρίσκεται σε στάδιο άλφα), όλα αλλάζουν γρήγορα. Γι' αυτό δεν υπάρχουν πολλά εκπαιδευτικά βοηθήματα, ούτε και ιδιαίτερα εκτενής τεκμηρίωση γενικότερα. Η Red μόλις τώρα αρχίζει να κερδίζει δημοτικότητα. Υπάρχουν όμως μερικές σελίδες που αξίζει να αναφέρουμε και που μπορούν να σε βοηθήσουν να ξεκινήσεις το ταξίδι σου.

* Το [Learn X in Y minutes](https://learnxinyminutes.com/docs/red/) ξεχωρίζει ως μια αρκετά μοντέρνα και όχι ιδιαίτερα αναλυτική πηγή.
* Το [Helpin'Red](http://helpin.red/) είναι ένας πραγματικά περιεκτικός οδηγός βήμα προς βήμα, με πολλά παραδείγματα για να δοκιμάσεις κι εσύ.
* Το [Getting Started With Red](http://redprogramming.com/Getting%20Started.html) είναι άλλο ένα κλασικό.
* Καθώς η Red βασίζεται στη Rebol, μπορείς να βρεις πολλές χρήσιμες πληροφορίες στο [Learn REBOL](http://www.re-bol.com/rebol.html), από τον ίδιο συγγραφέα.
* Αν κολλήσεις, υπάρχει πάντα κάποιος έτοιμος να σε βοηθήσει στο [Red Gitter chat](https://gitter.im/red/help).
