# Υποδείξεις

## Γενικά

- Υπάρχουν πολλοί τρόποι να λύσεις αυτή την άσκηση, και ο σχεδιασμός της στρατηγικής σου είναι βασικό μέρος της πρόκλησης.
- Όπως σε άλλα tracks, η είσοδος είναι `Vector{String}`.
- Επειδή η Julia έχει έναν εγγενή τύπο [`Matrix`][matrix] στη βασική γλώσσα, μπορεί να σου είναι πιο εύκολο να μετατρέψεις το ταμπλό σε κάποιο είδος `Matrix` (`String`, `Char`, `Int`...).
- Πρόσεξε τις ακραίες περιπτώσεις, που ανεβάζουν τη δυσκολία της άσκησης από εύκολη σε μέτρια.
  - Είναι δυνατόν να κάνεις μια κίνηση που κερδίζει σε 2 διαστάσεις ταυτόχρονα.
  - Ποιοι συνδυασμοί διαστάσεων είναι δυνατοί και έγκυροι;

## Για όσους έχουν κλίση στα μαθηματικά

- Το [`LinearAlgebra` module][linearalgebra] είναι διαθέσιμο στον test runner.
- Μπορεί να περιέχει χρήσιμες συναρτήσεις, όπως τη [`diag()`][diag].
- Αυτή είναι απλώς μια επιλογή για όσους έχουν τη διάθεση. Η χρήση της γραμμικής άλγεβρας δεν είναι καθόλου απαραίτητη.


[linearalgebra]: https://docs.julialang.org/en/v1/stdlib/LinearAlgebra/
[matrix]: https://docs.julialang.org/en/v1/base/arrays/#Base.Matrix
[diag]: https://docs.julialang.org/en/v1/stdlib/LinearAlgebra/#LinearAlgebra.diag
