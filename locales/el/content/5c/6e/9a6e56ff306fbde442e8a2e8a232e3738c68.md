# Εισαγωγή

Το ότι ένας πίνακας είναι επίσης μια _συλλογή_ σημαίνει ότι, εκτός από την πρόσβαση σε τιμές μέσω θέσης, μπορείς να διατρέξεις όλες τις τιμές του χρησιμοποιώντας έναν `foreach` βρόχο:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
