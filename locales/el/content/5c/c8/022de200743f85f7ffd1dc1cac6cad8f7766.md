# Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις τον χειρισμό σφαλμάτων για μια απλή αριθμομηχανή ακεραίων.
Για να μην περιπλέκουμε τα πράγματα, σου δίνονται έτοιμες μέθοδοι για την πρόσθεση, τον πολλαπλασιασμό και τη διαίρεση.

Στόχος είναι να έχεις μια αριθμομηχανή που δουλεύει και επιστρέφει μια συμβολοσειρά με το εξής μοτίβο: `16 + 51 = 67`, όταν της δίνεις τα ορίσματα `16`, `51` και `+`.

```java
CalculatorConundrum calculator = new CalculatorConundrum();

calculator.calculate(16, 51, "+");
// => returns "16 + 51 = 67"

calculator.calculate(32, 6, "*");
// => returns "32 * 6 = 192"

calculator.calculate(512, 4, "/");
// => returns "512 / 4 = 128"
```

## 1. Υλοποίησε τη μέθοδο calculate ώστε να υποστηρίζει μερικές βασικές πράξεις

Η κύρια μέθοδος που θα υλοποιήσεις σε αυτή την εργασία είναι η `CalculatorConundrum.calculate()`.
Δέχεται τρία ορίσματα.
Τα δύο πρώτα ορίσματα, `operand1` και `operand2`, είναι ακέραιοι αριθμοί πάνω στους οποίους θα γίνει μια πράξη.
Το τρίτο όρισμα, `operation`, είναι τύπου String και σε αυτή την άσκηση χρειάζεται να υλοποιήσεις τις εξής πράξεις:

- την πρόσθεση με τη συμβολοσειρά `+`
- τον πολλαπλασιασμό με τη συμβολοσειρά `*`
- τη διαίρεση με τη συμβολοσειρά `/`

## 2. Χειρίσου τις μη έγκυρες πράξεις

Ενημέρωσε τη μέθοδο `CalculatorConundrum.calculate()` ώστε να χειρίζεται τις μη έγκυρες πράξεις:

- Όταν το όρισμα `operation` είναι `null`, πρέπει να πεταχτεί μια `IllegalArgumentException` με μήνυμα `Operation cannot be null`.
- Όταν το όρισμα `operation` είναι `""`, πρέπει να πεταχτεί μια `IllegalArgumentException` με μήνυμα `Operation cannot be empty`.
- Όταν το όρισμα `operation` είναι κάποια άλλη πράξη εκτός από `+`, `*` ή `/`, πρέπει να πεταχτεί μια `IllegalOperationException` με μήνυμα `Operation '{operation}' does not exist`.

```java
calculator.calculate(10, 1, null);
// => throws IllegalArgumentException with message "Operation cannot be null"

calculator.calculate(10, 1, "");
// => throws IllegalArgumentException with message "Operation cannot be empty"

calculator.calculate(10, 1, "-");
// => throws IllegalOperationException with message "Operation '-' does not exist"
```

## 3. Χειρίσου την εξαίρεση που πετιέται όταν διαιρείς με το μηδέν

Στην Java, αν προσπαθήσεις να διαιρέσεις με το μηδέν, πετιέται μια `ArithmeticException`.
Ενημέρωσε τη μέθοδο `CalculatorConundrum.calculate()` ώστε να πιάνει αυτή την εξαίρεση και μετά να πετάει μια `IllegalOperationException` με μήνυμα `Division by zero is not allowed` και αιτία την `ArithmeticException` που έπιασε.

```java
calculator.calculate(512, 0, "/");
// => throws IllegalOperationException with message "Division by zero is not allowed"
```
