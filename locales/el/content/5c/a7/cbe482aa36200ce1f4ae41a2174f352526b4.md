# Nil

Η Crystal έχει έναν τύπο που ονομάζεται [`Nil`][nil], ο οποίος μπορεί να έχει μόνο μία τιμή: `nil`.
Χρησιμοποιείται για να αναπαραστήσει την απουσία μιας τιμής και είναι παρόμοιος με το `null` ή το `None` σε άλλες γλώσσες.

Τιμές `nil` μπορούν να επιστραφούν από διάφορες μεθόδους, για παράδειγμα η [`String#[]?`][string-index], η οποία επιστρέφει `nil` αν η θέση είναι εκτός ορίων.

```crystal
"foo"[10]? # => nil
```

Η Crystal έχει αυτό που είναι γνωστό ως **NULL REFERENCE CHECKS**, που σημαίνει ότι όλοι οι τύποι είναι μη-nil από προεπιλογή.
Αυτό σημαίνει ότι δε μπορείς να αναθέσεις `nil` σε μια μεταβλητή, εκτός αν τη δηλώσεις ρητά ως τύπο `Nil`.
Με τη σειρά του, αυτό σημαίνει ότι ο μεταγλωττιστής θα ελέγχει αυτόματα τις αναφορές null.

## Τιμή falsey

Μπορούν να ακολουθηθούν ορισμένες προσεγγίσεις για να χειριστείς τιμές `nil`.
Το `nil` είναι μια τιμή [falsey][truthy-falsey], όπως ακριβώς και το `false`.
Αυτό σημαίνει ότι σε εντολές και σε άλλα σημεία όπου αναμένεται μια τιμή falsey ή truthy, θα αντιμετωπιστεί το ίδιο όπως το `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Αυτό σημαίνει ότι ο κλάδος truthy δεν θα εκτελεστεί αν μια μεταβλητή που δέχεται nil έχει τιμή `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Έλεγχος για nil

Η Crystal έχει μια μέθοδο που μπορείς να χρησιμοποιήσεις για να ελέγξεις αν μια τιμή είναι `nil`.
Ονομάζεται [`nil?`][nil?] και είναι διαθέσιμη σε όλα τα αντικείμενα.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Αυτό είναι λίγο διαφορετικό όταν χρησιμοποιείς απλώς την τιμή σε μια εντολή `if`, αφού στα προηγούμενα παραδείγματα τόσο το false όσο και το nil αντιμετωπίζονταν ως false.
Εδώ μόνο το `nil` αντιμετωπίζεται ως falsey, αφού αν ήταν false δεν θα ήταν nil και επομένως θα ήταν truthy.

## Ο τελεστής ή

Ο ευκολότερος τρόπος να χειριστείς τιμές `nil` είναι να φροντίσεις να μη γίνουν ποτέ `nil` εξαρχής.
Ο τελεστής ή ([`||`][or]) χρησιμοποιείται συχνά όταν δουλεύεις με `Bools`, αλλά αν τον κατανοήσεις σωστά, μπορεί να χρησιμοποιηθεί και για να χειριστείς τιμές `nil`.
Ο τελεστής ή ελέγχει αν η πρώτη τιμή είναι truthy, αν δεν είναι, χρησιμοποιείται η δεύτερη τιμή.
Μπορείς να το χρησιμοποιήσεις ώστε, αν η τιμή είναι `nil`, να είναι falsey και έτσι να χρησιμοποιηθεί η δεύτερη τιμή.

```crystal
"foo"[10]? || "bar" # => "bar"
```

## not_nil!

~~~~exercism/caution 
Αυτή η προσέγγιση θα πρέπει να θεωρείται η τελευταία λύση και να χρησιμοποιείται μόνο αν είσαι **σίγουρος** ότι η τιμή δεν είναι nil.
Αν είναι δυνατόν, χρησιμοποίησε τις άλλες προσεγγίσεις.
~~~~

Η [`not_nil!`][not_nil] είναι μια μέθοδος που σου επιτρέπει να πεις στον μεταγλωττιστή ότι μια τιμή δεν είναι nil, και έτσι ο τύπος της δεν μπορεί να είναι nil.
Το κάνει αυτό πετώντας μια εξαίρεση αν η τιμή είναι nil.

```crystal
foo = "foo"[4]?
foo.not_nil!
# => Error: Nil assertion failed (NilAssertionError)
```
