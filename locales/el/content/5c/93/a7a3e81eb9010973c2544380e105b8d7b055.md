# Βρόχοι

Υπάρχουν τρεις βασικοί τύποι βρόχων στη Swift: οι βρόχοι while, οι οποίοι επαναλαμβάνουν ένα μπλοκ κώδικα όσο ισχύει μια συνθήκη που έχεις ορίσει, οι βρόχοι repeat-while, που μοιάζουν με τους βρόχους while αλλά εκτελούν εγγυημένα το μπλοκ κώδικα τουλάχιστον μία φορά, και οι βρόχοι for-in, που εκτελούν ένα μπλοκ κώδικα μία φορά για κάθε στοιχείο μιας συλλογής.
