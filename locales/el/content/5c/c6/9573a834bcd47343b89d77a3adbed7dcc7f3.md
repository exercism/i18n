# Πρόγραμμα ύλης - Επόμενες ασκήσεις

Αφού έχεις υλοποιήσει την πρώτη σου άσκηση έννοιας, οι επόμενες ασκήσεις θα πρέπει να χτίσουν πάνω σε αυτήν.

Μας αρέσει να υπάρχουν τρεις με πέντε ασκήσεις που δεν έχουν άλλα προαπαιτούμενα εκτός από την έννοια `basics`.

Καλές επιλογές είναι τα βασικά πρωτογενή στοιχεία ή οι τύποι δεδομένων της γλώσσας σου.
Π.χ. Boolean, βασικοί αριθμητικοί τύποι, συμβολοσειρές και άτομα.

Αξίζει να ρίξεις μια ματιά στις ασκήσεις εννοιών άλλων διαδρομών, για να δεις αν υπάρχει κάποια κατάλληλη για τη δική σου διαδρομή.

Πρόσεξε ότι η εισαγωγή μιας έννοιας δεν σημαίνει ότι χρειάζεται να την εξηγήσεις εξαντλητικά.
Μπορείς πάντα να αναβάλεις την πολυπλοκότητα.
Η γλώσσα μπορεί να έχει δώδεκα διαφορετικούς αριθμητικούς τύπους που είναι χρήσιμοι σε διαφορετικά σενάρια.
Η άσκηση μπορεί απλώς να αναφέρει ότι υπάρχουν κι άλλοι, εισάγοντας μόνο τον πιο συνηθισμένο ακέραιο τύπο και τον πιο συνηθισμένο τύπο κινητής υποδιαστολής.

Κάποιοι βασικοί τύποι δεδομένων είναι πολύ περίπλοκοι για να εισαχθούν άμεσα.
Για παράδειγμα, οι συμβολοσειρές μπορεί να είναι λίστες από χαρακτήρες.
Σε μια τέτοια περίπτωση, θα πρέπει να αναβάλεις την εισαγωγή των συμβολοσειρών και να σχεδιάσεις μια άσκηση έννοιας για τους χαρακτήρες και μια άλλη για τις λίστες.
Στη συνέχεια, μπορείς να προσθέσεις μια άσκηση για τις συμβολοσειρές που έχει και τις δύο αυτές ασκήσεις ως προαπαιτούμενα.

Μερικές φορές, δουλεύοντας πάνω σε μια άσκηση, θα συνειδητοποιήσεις ότι είναι πιο περίπλοκη απ' ό,τι περίμενες.
Δεν πειράζει καθόλου.
Σημείωσε την έννοια που πρέπει να διδαχθεί ως προαπαιτούμενο.
Έπειτα, κάνε σαν να υπάρχει μια τέτοια άσκηση και ολοκλήρωσε την άσκηση στην οποία δουλεύεις έχοντας στο μυαλό σου αυτή την απλοποίηση.
Μετά, γύρνα πίσω και δημιούργησε μια νέα άσκηση για την έννοια που χρειάζεται ως προαπαιτούμενο.
Θυμήσου να σημειώσεις την άσκηση ως `wip` μέχρι να προστεθεί η προαπαιτούμενη άσκηση.

Κάτι άλλο που μπορεί να συμβεί σε αυτό το σημείο είναι να ανακαλύψεις ότι έχεις κυκλικές εξαρτήσεις.
Πρέπει να εισαγάγεις δύο έννοιες, αλλά η καθεμία βασίζεται στην άλλη.
Σε αυτή την περίπτωση, μπορεί να μπορέσεις να χρησιμοποιήσεις ένα stub.
Τότε μπορείς να εξηγήσεις ότι η εξαρτημένη έννοια υπάρχει, αλλά να τους καθησυχάσεις ότι δεν χρειάζεται να την καταλάβουν ακόμη.
Μια άλλη επιλογή θα ήταν να δώσεις μια στοιχειώδη εισαγωγή, αρκετή για να ξεπεράσει ο μαθητής το εμπόδιο, καθησυχάζοντάς τον παράλληλα ότι η έννοια θα καλυφθεί πιο αναλυτικά αργότερα.

## Παραλειπόμενες ασκήσεις

Αν επιλέξεις **να μην** υλοποιήσεις μια άσκηση επειδή δεν ταιριάζει στη διαδρομή σου (π.χ. μια άσκηση χαμηλού επιπέδου για μια διαδρομή υψηλού επιπέδου), σημείωσέ την ως _foregone_.
Για να το κάνεις, πρόσθεσε το slug της άσκησης στον πίνακα `exercises.foregone` στο αρχείο [config.json](/docs/building/tracks/config-json#h-foregone-exercises) της διαδρομής σου.

Εκτός από το ότι κάνει ρητή την επιλογή σου να μην υλοποιήσεις μια άσκηση, οποιοδήποτε εργαλείο (όπως το [configlet](/docs/building/configlet)) θα αγνοεί επίσης τις παραλειπόμενες ασκήσεις.

Για περισσότερες πληροφορίες, δες [την τεκμηρίωση](/docs/building/tracks/config-json#h-foregone-exercises).
