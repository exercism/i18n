# Προσθήκη οδηγιών

## Υποτύποι

Αυτή η άσκηση ορίζει έναν υποτύπο που ονομάζεται `Positive`, για όλους τους φυσικούς αριθμούς μεγαλύτερους του 0.
Ένας υποτύπος μπορεί να θεωρηθεί ως ένα ζεύγος `⟨x, h⟩`, όπου x είναι η τιμή και h είναι η απόδειξη της εγκυρότητάς της.

Μπορείς να αποκτήσεις πρόσβαση στην τιμή μέσα σε έναν υποτύπο (x, στην περίπτωση αυτή) χρησιμοποιώντας .val, για παράδειγμα, `x.val`.
Μπορείς να αποκτήσεις πρόσβαση στην απόδειξή του χρησιμοποιώντας .property, για παράδειγμα, `x.property`.
Μπορείς επίσης να αποκτήσεις πρόσβαση και στα δύο μέσω αντιστοίχισης προτύπων, όπως συνήθως.

Για να κατασκευάσεις μια τιμή για έναν υποτύπο, είναι απαραίτητο να αποδείξεις την εγκυρότητά της, στην περίπτωση αυτή, ότι ο αριθμός είναι μεγαλύτερος του 0.

Υπάρχουν αρκετά λήμματα και θεωρήματα στη Lean που μπορούν να χρησιμεύσουν ως σημείο εκκίνησης γι' αυτή την απόδειξη.
Για παράδειγμα, το `Nat.zero_lt_succ` είναι ένα λήμμα που δηλώνει ότι για κάθε φυσικό αριθμό `n`: `0 < n + 1`.
