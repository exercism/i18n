# Οδηγίες

Ο φίλος σου ο Linus είναι μηχανοδηγός και οδηγεί εμπορικά τρένα ανάμεσα σε πόλεις.
Αν και είναι καταπληκτικός στον χειρισμό των τρένων, δεν τα πάει το ίδιο καλά με τη διαχείριση logistics ή με τους υπολογιστές.
Θα ήθελε να ζητήσει τη βοήθειά σου στον προγραμματισμό, για να οργανώσει τις λεπτομέρειες των τρένων και να διορθώσει λάθη στα δεδομένα των δρομολογίων.

~~~~exercism/note
Αυτή η άσκηση θα μπορούσε εύκολα να λυθεί με τεμαχισμό, ευρετηρίαση και διάφορες μεθόδους της `dict`.
Ωστόσο, θα θέλαμε να εξασκηθείς στο πακετάρισμα, στο ξεπακετάρισμα και στην πολλαπλή ανάθεση λύνοντας καθεμία από τις παρακάτω εργασίες.
~~~~

## 1. Δημιούργησε μια λίστα με όλα τα βαγόνια

Ο φίλος σου καταγράφει το αναγνωριστικό (ID) κάθε βαγονιού, αλλά ποτέ δεν είναι σίγουρος πόσα βαγόνια θα πρέπει να επεξεργαστεί το σύστημα κάθε φορά. Θα ήταν πολύ πιο εύκολο για το υπόλοιπο πρόγραμμα logistics να έχει αυτά τα δεδομένα πακεταρισμένα σε μία ενιαία `list`.

Υλοποίησε μια συνάρτηση `get_list_of_wagons()` που δέχεται οποιονδήποτε αριθμό ID βαγονιών.
Κάθε ID θα είναι ένας θετικός ακέραιος.
Η συνάρτηση θα πρέπει στη συνέχεια να κάνει `return` τα δοσμένα ID ως μία ενιαία `list`.

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. Διόρθωσε τη λίστα των βαγονιών

Σε αυτό το σημείο, αρχίζεις να αποκτάς μια αίσθηση για τα δεδομένα και για το πώς χρησιμοποιούνται στο πρόγραμμα logistics.
Το σύστημα ID δίνει πάντα στη μηχανή ένα ID **1**, ενώ στα υπόλοιπα βαγόνια του τρένου δίνει ένα τυχαία επιλεγμένο ID μεγαλύτερο του **1**.

Ο φίλος σου έπρεπε να συνδέσει δύο νέα βαγόνια στο τρένο και ξέχασε να ενημερώσει το σύστημα!
Τώρα, τα δύο πρώτα βαγόνια στη `list` του τρένου πρέπει να μετακινηθούν στο τέλος, αλλιώς τα πάντα θα είναι σε λάθος σειρά.

Για να γίνουν τα πράγματα πιο περίπλοκα, ο φίλος σου μόλις ανακάλυψε μια δεύτερη `list` που φαίνεται να περιέχει ID βαγονιών που έλειπαν.
Το μόνο που θυμάται είναι ότι, μόλις μετακινηθούν τα νέα βαγόνια, τα ID από αυτή τη δεύτερη `list` θα πρέπει να τοποθετηθούν αμέσως μετά τη μηχανή που έχει οριστεί.

Ο Linus θα σου ήταν πραγματικά ευγνώμων αν διόρθωνες τα λάθη του και ενοποιούσες τα δεδομένα.

Υλοποίησε μια συνάρτηση `fix_list_of_wagons()` που δέχεται δύο `lists` που περιέχουν ID βαγονιών.
Θα πρέπει να μετακινήσει τα δύο πρώτα στοιχεία της πρώτης `list` στο τέλος και να εισαγάγει τις τιμές από τη δεύτερη `list` πίσω (_στα δεξιά_) από το ID της μηχανής (**1**).
Η συνάρτηση θα πρέπει στη συνέχεια να κάνει `return` μια `list` με τις τροποποιήσεις.

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Πρόσθεσε τις στάσεις που λείπουν

Τώρα που όλα τα δεδομένα των βαγονιών είναι σωστά, ο Linus θα ήθελε να ενημερώσεις τις πληροφορίες δρομολόγησης του συστήματος.
Κατά μήκος μιας διαδρομής μεταφοράς, ένα τρένο μπορεί να κάνει στάσεις σε μερικούς διαφορετικούς σταθμούς για να παραλάβει ή/και να παραδώσει φορτίο.
Κάθε διαδρομή μπορεί να έχει διαφορετικό αριθμό από αυτά τα ενδιάμεσα σημεία παράδοσης.
Ο φίλος σου θα ήθελε να ενημερώσεις τη `dict` δρομολόγησης του συστήματος με οποιεσδήποτε πληροφορίες παράδοσης λείπουν ή είναι επιπλέον.

Υλοποίησε μια συνάρτηση `add_missing_stops()` που δέχεται μια `dict` δρομολόγησης ακολουθούμενη από έναν μεταβλητό αριθμό ορισμάτων με λέξεις-κλειδιά.
Αυτά τα ορίσματα μπορεί να έχουν τη μορφή μιας `dict` που περιέχει μία ή περισσότερες στάσεις, ή οποιουδήποτε αριθμού ζευγών λέξεων-κλειδιών της μορφής `stop_number=city`.
Η συνάρτησή σου θα πρέπει στη συνέχεια να επιστρέψει τη `dict` δρομολόγησης ενημερωμένη με ένα επιπλέον `key` που περιέχει μια `list` με όλες τις στάσεις που προστέθηκαν, με τη σειρά.

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

Ο Linus δουλεύει πάνω στο πρόγραμμα δρομολόγησης και παρατήρησε ότι ορισμένες διαδρομές λείπουν κάποιες σημαντικές λεπτομέρειες.
Οι αρχικές πληροφορίες της διαδρομής έχουν κατασκευαστεί ως `dict` και ο φίλος σου θα ήθελε να ενημερώσεις αυτή τη `dict` με ό,τι μπορεί να λείπει.
Κάθε διαδρομή στο σύστημα απαιτεί ελαφρώς διαφορετικές λεπτομέρειες, οπότε ο Linus θα προτιμούσε πραγματικά μια γενική λύση.

Υλοποίησε μια συνάρτηση με το όνομα `extend_route_information()` που δέχεται δύο `dicts`.
Η πρώτη `dict` περιέχει τις πόλεις αφετηρίας και προορισμού ανάμεσα στις οποίες εκτελείται η διαδρομή του τρένου.

Η δεύτερη `dict` περιέχει άλλες λεπτομέρειες της διαδρομής, όπως ταχύτητα του τρένου, μήκος ή θερμοκρασία.
Η συνάρτηση θα πρέπει να επιστρέψει μια ενοποιημένη `dict` με όλες τις πληροφορίες δρομολόγησης.

~~~~exercism/note
Η δεύτερη `dict` μπορεί να περιέχει διαφορετικές ή περισσότερες ιδιότητες από αυτές που φαίνονται στο παράδειγμα.
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. Διόρθωσε το αμαξοστάσιο

Όταν ο Linus επιθεωρούσε το αμαξοστάσιο, παρατήρησε ότι τα βαγόνια δεν αποθηκεύονταν με τη σωστή σειρά.
Εκτός από ένα ID, κάθε βαγόνι έχει ένα χρώμα που αντιστοιχεί στον τύπο του φορτίου που μεταφέρει.
Τα βαγόνια αποθηκεύονται στο αμαξοστάσιο σε πλέγματα, όπου κάθε στήλη του πλέγματος έχει βαγόνια του ίδιου χρώματος.

Ωστόσο, το σύστημα logistics δείχνει ότι οι `lists` με τα βαγόνια που πρόκειται να αποθηκευτούν στο αμαξοστάσιο έχουν τις _γραμμές_ τους ομαδοποιημένες κατά χρώμα.
Αλλά για να λειτουργεί σωστά το πλέγμα αποθήκευσης, κάθε _γραμμή_ θα πρέπει να έχει τρία διαφορετικά χρώματα, ώστε οι _στήλες_ να ευθυγραμμίζονται κατά χρώμα.
Ο φίλος σου θα ήθελε να τακτοποιήσεις τις `lists` του αμαξοστασίου, ώστε τα βαγόνια να αποθηκεύονται σωστά.

Υλοποίησε μια συνάρτηση με το όνομα `fix_wagon_depot()` που δέχεται μια `list` με τρία στοιχεία.
Κάθε στοιχείο της `list` είναι μια υπολίστα (ή "γραμμή") που περιέχει τρία `tuples`.
Κάθε `tuple` είναι ένα ζεύγος `(<wagon ID>, <wagon color>)`.

Η συνάρτησή σου θα πρέπει να επιστρέψει μια `list` με τις τρεις "γραμμές" `lists` αναδιατεταγμένες, ώστε τα βαγόνια να ανταλλαγούν στις σωστές θέσεις τους.

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
