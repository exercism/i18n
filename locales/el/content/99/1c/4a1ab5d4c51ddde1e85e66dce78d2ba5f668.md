# Σχετικά

Οι βιβλιοθήκες βασικών κλάσεων του .NET παρέχουν την κλάση [`Regex`][regex] για την επεξεργασία κανονικών εκφράσεων.

Δες αυτό το [άρθρο][regex-comparison] για μια σύγκριση της C# με άλλες παραλλαγές κανονικών εκφράσεων.

## Ομάδες σύλληψης

Μια πτυχή που πρέπει να λάβεις υπόψη είναι οι ομάδες σύλληψης, οι οποίες επιστρέφουν τμήματα του κειμένου που ταιριάζουν με διάφορα μέρη του μοτίβου της κανονικής έκφρασης. Ο τρόπος με τον οποίο χειρίζεσαι τις ομάδες σύλληψης θέλει λίγο χρόνο για να τον συνηθίσεις. Δες αυτή την [τεκμηρίωση][capture].

Σημείωσε ότι υπάρχει μια ιεραρχία όταν εμπλέκονται ομάδες σύλληψης, `(?<capture-name>pattern)`:

- όπου επιστρέφεται ένα σύνολο από μηδέν ή περισσότερα ταιριάσματα (ένα για κάθε ταίριασμα που βρίσκεται στο κείμενο).
- Κάθε ταίριασμα περιέχει έναν αριθμό ομάδων σύλληψης
- Κάθε ομάδα περιέχει έναν αριθμό συλλήψεων.

Επιπλέον:

- Το `Match` κληρονομεί από το `Group`
- Το `Group` κληρονομεί από το `Capture`

Προσοχή:

- Ο ασφαλέστερος τρόπος είναι να χρησιμοποιείς ονομαστικές συλλήψεις.
- Οι ομάδες σύλληψης εμφανίζονται γενικά στη συλλογή `Groups` με την ίδια σειρά που εμφανίζονται στο κείμενο.
- Το `Groups[0]` φαίνεται να αντιστοιχεί σε ολόκληρο το ταίριασμα.
- Το `Groups[<capture name>].Value` είναι σχεδόν σίγουρα αυτό που σε ενδιαφέρει. Οι μεμονωμένες συλλήψεις (εκτός από το `Caputures[0]`) φαίνεται να προορίζονται για διαγνωστικούς σκοπούς, αν υπάρχουν.

## Επιλογές κανονικών εκφράσεων

Εξοικειώσου με το [`RegexOptions`][regex-options].

Εκτός από τις συνήθεις επιλογές `IgnoreCase`, υπάρχουν και εκείνες για το `MultiLine`, που είναι χρήσιμο για την επεξεργασία πολλών γραμμών κειμένου με τη μία, και το `IgnorePatternWhitespace`, το οποίο, σε συνδυασμό με κυριολεκτικές συμβολοσειρές, παρεμβολή συμβολοσειρών και σχόλια, μπορεί να είναι πολύ εκφραστικό, όπως φαίνεται σε αυτό το παράδειγμα:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Μια άλλη επιλογή που αξίζει να προσέξεις είναι το `RegexOptions.Compiled` για [μεταγλωττισμένες][regex-compilation] κανονικές εκφράσεις.
