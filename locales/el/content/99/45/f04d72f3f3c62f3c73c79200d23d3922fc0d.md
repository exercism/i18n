# Οδηγίες

Σημείωση: Αυτή η άσκηση είναι συνέχεια της άσκησης `need-for-speed`.

Σε αυτή την άσκηση θα οργανώσεις αγώνες ανάμεσα σε διάφορους τύπους τηλεκατευθυνόμενων αυτοκινήτων.
Κάθε αυτοκίνητο έχει τα δικά του χαρακτηριστικά ταχύτητας και κατανάλωσης μπαταρίας.

Τα αυτοκίνητα ξεκινούν με πλήρεις μπαταρίες (100%).
Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο, διανύει απόσταση σε μέτρα ίση με την ταχύτητα του αυτοκινήτου και μειώνει το υπόλοιπο ποσοστό μπαταρίας κατά την κατανάλωση μπαταρίας του.

Αν η μπαταρία ενός αυτοκινήτου είναι κάτω από το ποσοστό κατανάλωσης μπαταρίας του, δεν μπορείς πλέον να οδηγήσεις το αυτοκίνητο.

Το τηλεκατευθυνόμενο αυτοκίνητο έχει μια εντυπωσιακή οθόνη LED που εμφανίζει δύο πληροφορίες:

- Η συνολική απόσταση που έχει διανύσει, όπως εμφανίζεται: `"Driven <METERS> meters"`.
- Η υπολειπόμενη φόρτιση μπαταρίας, όπως εμφανίζεται: `"Battery at <PERCENTAGE>%"`.

Κάθε πίστα αγώνα έχει τη δική της απόσταση.
Δοκιμάζουμε τα αυτοκίνητα ελέγχοντας αν μπορούν να τερματίσουν την πίστα χωρίς να ξεμείνουν από μπαταρία.

## 1. Οδήγησε το αυτοκίνητο

Υλοποίησε τη μέθοδο `Drive` στο `Car` που ενημερώνει τον αριθμό των μέτρων που έχουν διανυθεί με βάση την ταχύτητα του αυτοκινήτου και μειώνει την μπαταρία σύμφωνα με την κατανάλωση μπαταρίας:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Σημείωση: Δεν πρέπει να προσπαθήσεις να οδηγήσεις το αυτοκίνητο αν αυτό θα έχει ως αποτέλεσμα η μπαταρία του αυτοκινήτου να πέσει κάτω από 0.

## 2. Εμφάνισε την απόσταση που έχει διανυθεί

Υλοποίησε μια μέθοδο `DisplayDistance` στο `Car` που επιστρέφει την απόσταση όπως εμφανίζεται στην οθόνη LED ως `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Εμφάνισε το ποσοστό μπαταρίας

Υλοποίησε τη μέθοδο `DisplayBattery` στο `Car` που επιστρέφει το ποσοστό μπαταρίας όπως εμφανίζεται στην οθόνη LED ως `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Έλεγξε αν ένα τηλεκατευθυνόμενο αυτοκίνητο μπορεί να τερματίσει έναν αγώνα

Για να τερματίσει έναν αγώνα, το αυτοκίνητο πρέπει να μπορεί να διανύσει την απόσταση του αγώνα.
Αυτό σημαίνει να μην έχει καταναλώσει την μπαταρία του πριν περάσει τη γραμμή τερματισμού.
Υλοποίησε τη μέθοδο `CanFinish` που δέχεται ως παράμετρο ένα `trackDistance int` και επιστρέφει `true` αν το αυτοκίνητο μπορεί να τερματίσει τον αγώνα, αλλιώς επιστρέφει `false`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
