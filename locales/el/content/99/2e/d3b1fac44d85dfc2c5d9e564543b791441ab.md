# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση | Τύπος | Περιγραφή |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | είσοδος        | ακέραιος | N, το άθροισμα των πλευρών του τριγώνου  |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | τιμές του a                     |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | τιμές του b                     |
| `$a3`    | είσοδος/έξοδος | διεύθυνση | τιμές του c                     |
| `$v0`    | έξοδος       | ακέραιος | πλήθος των τριάδων           |
| `$t0-9`  | προσωρινός    | οποιοσδήποτε     | για προσωρινή αποθήκευση        |
