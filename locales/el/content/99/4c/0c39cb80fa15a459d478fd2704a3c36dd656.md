# Εισαγωγή

Η Python αναπαριστά τις αληθείς και ψευδείς τιμές με τον τύπο [`bool`][bools], ο οποίος είναι υποκλάση του `int`.
 Υπάρχουν μόνο δύο τιμές σε αυτόν τον τύπο: `True` και `False`.
  Αυτές οι τιμές μπορούν να δεσμευτούν σε μια μεταβλητή:

```python
>>> true_variable = True
>>> false_variable = False
```

Μπορούμε να αξιολογήσουμε Boolean (λογική τιμή) εκφράσεις χρησιμοποιώντας τους τελεστές `and`, `or` και `not`:

```python
>>> true_variable = True and True
>>> false_variable = True and False

>>> true_variable = False or True
>>> false_variable = False or False

>>> true_variable = not False
>>> false_variable = not True
```

[bools]: https://docs.python.org/3/library/stdtypes.html#typebool
