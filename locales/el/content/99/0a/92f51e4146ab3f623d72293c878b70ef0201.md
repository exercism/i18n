# χρησιμοποίησε παρεμβολή συμβολοσειρών

[comment]: # (Αυτή η προειδοποίηση εμφανίζεται όταν η λύση δεν χρησιμοποιεί παρεμβολή συμβολοσειρών)

Χρησιμοποίησε την [παρεμβολή συμβολοσειρών](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) για να εισάγεις την παράμετρο `name` στη συμβολοσειρά εξόδου.

- Όπου είναι δυνατόν, στο track Elixir του Exercism συνιστάται να χρησιμοποιείς παρεμβολή συμβολοσειρών αντί για συνένωση συμβολοσειρών, για λόγους αναγνωσιμότητας.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Οποιαδήποτε έκφραση Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) μπορεί να μπει στη σύνταξη της παρεμβολής συμβολοσειρών

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
