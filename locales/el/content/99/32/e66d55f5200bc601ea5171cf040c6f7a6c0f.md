# Εισαγωγή

Πριν εισαχθεί η κλάση `Promise`, υπήρχε μόνο ένας τρόπος να χειριστείς ασύγχρονο κώδικα: το _μοτίβο callback_.

Ένα callback είναι μια συνάρτηση που περνιέται ως όρισμα σε μια άλλη συνάρτηση και καλείται όταν ολοκληρωθεί κάποια ενέργεια μέσα σε αυτή την άλλη συνάρτηση. Ένα συνηθισμένο μοτίβο για αυτές τις συναρτήσεις callback είναι να δέχονται ένα "error" ως πρώτη παράμετρο (δες το παράδειγμα παρακάτω).

```javascript
function callback(error, arg2, arg3) {}
```

Πώς σχετίζεται αυτό με τον ασύγχρονο κώδικα;

Ιστορικά, τα callbacks έχουν χρησιμοποιηθεί για να μπορούμε να κάνουμε κάποια δουλειά αφού ολοκληρωθεί μια ασύγχρονη εργασία, χωρίς να μπλοκάρουμε ολόκληρο το πρόγραμμα.

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

Στο παραπάνω παράδειγμα, η συνάρτηση `fetchProduct` (η οποία είναι ασύγχρονη) δέχεται ένα callback ως δεύτερο όρισμα, το οποίο καθορίζει τι θα γίνει όταν ανακτηθούν τα δεδομένα του προϊόντος.
