# Σχετικά

Η JavaScript είναι μια γλώσσα προγραμματισμού που επιτρέπει στις ιστοσελίδες να είναι δυναμικές. Είναι μια διερμηνευόμενη γλώσσα, που σημαίνει ότι δεν χρειάζεται να μεταγλωττιστεί: αντίθετα, ο διερμηνευτής (όπως ένα πρόγραμμα περιήγησης ιστού) θα αναλύσει τον κώδικα και θα τον μετατρέψει σε κώδικα που μπορεί να εκτελέσει το μηχάνημά του, ιδανικό για τη δημιουργία δυναμικών ιστοσελίδων που τρέχουν σε οποιοδήποτε πρόγραμμα περιήγησης _σε οποιονδήποτε υπολογιστή_!

Η JavaScript δεν χρησιμοποιείται μόνο στο πρόγραμμα περιήγησης. Περιβάλλοντα εκτέλεσης JavaScript, όπως το [Node.js][web-nodejs] και το [Deno][web-deno], σου επιτρέπουν να γράφεις, να ξεκινάς και να εξυπηρετείς αιτήματα σε διακομιστές ιστού.
Άλλα frameworks, όπως το [Electron][web-electron], χρησιμοποιούν τη JavaScript για να γράψεις _εφαρμογές για πολλαπλές πλατφόρμες_ για Windows, Linux και macOS.
Η ανάπτυξη εφαρμογών για κινητά είναι επίσης δυνατή, με τη χρήση των [React Native][web-react-native], [Ionic][web-ionic] και διάφορων άλλων, ενώ το [Expo][web-expo] σου επιτρέπει πλέον να στοχεύεις Android, iOS και τον ιστό, όλα ταυτόχρονα.

Η ECMAScript είναι το [πρότυπο][web-ecma] που ορίζει τη JavaScript.

> "Η ECMAScript έχει εξελιχθεί σε μία από τις πιο ευρέως χρησιμοποιούμενες γλώσσες προγραμματισμού γενικού σκοπού.
> Είναι περισσότερο γνωστή ως η γλώσσα που είναι ενσωματωμένη στα προγράμματα περιήγησης ιστού, αλλά έχει επίσης υιοθετηθεί ευρέως για εφαρμογές διακομιστών και ενσωματωμένες εφαρμογές."
> Πηγή: [ECMA International Language Specification][web-ecma-2019]

Ξεκινώντας από την 6η έκδοση (γνωστή συνήθως ως ES2015 ή ES6) το 2015, μια νέα έκδοση του προτύπου θα κυκλοφορεί κάθε χρόνο.
Η 6η έκδοση ήταν μια μεγάλη αναβάθμιση που έφερε πολλές βελτιώσεις σε σχέση με την ES5, όπως, μεταξύ άλλων, τα template strings, την εκφραστική σύνταξη των arrow functions και καθαρότερη σύνταξη για τον ορισμό κλάσεων.

Αλλά επειδή νέα σύνταξη και νέα χαρακτηριστικά έρχονται στη JavaScript _κάθε χρόνο_, η υποστήριξη αυτών των αλλαγών είναι συχνά ελλιπής στα [τρέχοντα προγράμματα περιήγησης][web-compat-browsers] και στο [τελευταίο Node.js][web-compat-node].
Αυτό δεν σημαίνει ότι δεν μπορείς να τη χρησιμοποιήσεις.
Εργαλεία όπως το [Babel][web-babel] προσφέρουν [transpilation][wiki-transpilation] για τα περισσότερα χαρακτηριστικά, επιτρέποντάς σου να _γράψεις_ σαν να είναι το μέλλον.

**Σημείωση**: Αυτό το track υποστηρίζει την τελευταία σύνταξη ECMAScript μέσω του Babel και του plugin [@babel/preset-env][web-babel-preset-env], και νέα πειραματικά χαρακτηριστικά ενεργοποιούνται με κάθε ενημέρωση αυτού του plugin, ακολουθώντας τον ρυθμό κυκλοφορίας των προδιαγραφών.
Προσαρμόζεται αυτόματα στην _τοπική σου εγκατάσταση του Node.js_.
Αυτό σημαίνει ότι δεν χρειάζεται να ανησυχείς για το τι υποστηρίζεται και τι όχι.
