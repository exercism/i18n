# Προσθήκη οδηγιών

## Συμβουλή

Μια συνάρτηση με *τύπο επιστροφής* μπορεί να επιστρέψει μόνο δεδομένα αυτού του *τύπου* και `null`.
Ωστόσο, αυτός που καλεί τη συνάρτηση περιμένει μόνο έναν τύπο δεδομένων.

Παράδειγμα:
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
Για να γίνει πιο σαφές ότι αυτή η συνάρτηση μπορεί να επιστρέψει και `null` ή περισσότερους τύπους δεδομένων, χρησιμοποίησε το `dynamic`.
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
