# Υποδείξεις

## 1. Δημιούργησε ένα σύνολο χρήσιμων συμβολοσειρών

- Οι [συμβολοσειρές][strings-and-characters] ορίζονται ως literals περικλείοντας μηδέν ή περισσότερους χαρακτήρες μέσα σε διπλά εισαγωγικά (`"`).

## 2. Δημιούργησε ένα σύνολο χρήσιμων χαρακτήρων

- Οι [χαρακτήρες][strings-and-characters] ορίζονται ως literals περικλείοντας ακριβώς έναν χαρακτήρα μέσα σε διπλά εισαγωγικά (`"`).
- Οι χαρακτήρες που ορίζονται ως literals πρέπει να έχουν ρητά μια δήλωση τύπου `Character`, ώστε να μην τους ερμηνεύει ο μεταγλωττιστής ως συμβολοσειρές.

## 3. Συνδύασε φράσεις για να συνθέσεις μηνύματα

- Οι συμβολοσειρές μπορούν να συνενωθούν χρησιμοποιώντας [τον κατάλληλο τελεστή συμβολοσειρών][string-docs].
- Οι χαρακτήρες δεν μπορούν να συνενωθούν με συμβολοσειρές. 
  Πρέπει πρώτα να μετατραπούν σε συμβολοσειρές.

## 4. Φτιάξε μια πινακίδα αποφοίτησης

- Η [παρεμβολή συμβολοσειρών][string-interpolation] γίνεται τοποθετώντας την έκφραση, της οποίας την τιμή θέλεις να βάλεις στη συμβολοσειρά, μέσα σε ένα ζεύγος παρενθέσεων, πριν από τις οποίες βρίσκεται ο χαρακτήρας της ανάστροφης καθέτου.

## 5. Υπολόγισε το κόστος μιας πινακίδας

- Η Swift έχει [μια ιδιότητα συμβολοσειράς][string-count-docs] που επιστρέφει τον αριθμό των χαρακτήρων σε μια συμβολοσειρά.
