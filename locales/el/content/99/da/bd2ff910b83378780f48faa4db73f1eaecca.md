# Debug

Όταν ένα test αποτυγχάνει, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε λάθος και για ποια είσοδο.
Μπορείς να εξετάσεις οποιεσδήποτε τιμές στο πρόγραμμά σου περνώντας τες στη μέθοδο `debug`.
Αυτή θα καταγράψει τις τιμές και θα σου δείξει την έξοδο.

```ruby
debug "The value is #{value}."
debug "The input is #{input.inspect}"
```
