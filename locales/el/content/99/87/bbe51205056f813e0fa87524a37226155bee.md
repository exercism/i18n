# Εγκατάσταση του Kotlin

Εκτός από το CLI του Exercism και τον αγαπημένο σου επεξεργαστή κειμένου, για να εξασκηθείς με ασκήσεις Exercism σε Kotlin χρειάζεσαι:

* το **Java Development Kit** (JDK): ο Kotlin μεταγλωττίζεται σε κώδικα byte της Java, οπότε χρειάζεται να εγκαταστήσεις το JDK, το οποίο περιλαμβάνει και ένα Java Runtime *και* εργαλεία ανάπτυξης (κυρίως τον μεταγλωττιστή της Java), και
* το **Gradle**: ένα εργαλείο δόμησης ειδικά για έργα βασισμένα στην JVM, που υποστηρίζει την Kotlin.

Διάλεξε το λειτουργικό σου σύστημα:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... ή ...

* αν προτιμάς να μη χρησιμοποιήσεις κάποιον διαχειριστή πακέτων, μπορείς να [εγκαταστήσεις χειροκίνητα](#h-install-manually).

Προαιρετικά, μπορείς επίσης να χρησιμοποιήσεις ένα [Java IDE](#h-java-ides).

## Windows

Άνοιξε μια γραμμή εντολών με δικαιώματα διαχειριστή.  (Αν χρειάζεσαι βοήθεια για να ανοίξεις μια γραμμή εντολών με δικαιώματα διαχειριστή, δες [πώς να ανοίξεις μια αναβαθμισμένη γραμμή εντολών στα Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (ή στα [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Αν δεν έχεις εγκαταστήσει το Chocolatey, κάν' το τώρα:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Εγκατέστησε το JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Σου προτείνουμε να κλείσεις τη γραμμή εντολών με δικαιώματα διαχειριστή και να ανοίξεις μια νέα γραμμή εντολών: δεν χρειάζεσαι δικαιώματα διαχειριστή για να εξασκηθείς σε ασκήσεις του Exercism.

Τώρα μπορείς να ξεκινήσεις με τη διαδρομή Kotlin του Exercism!

Για να ξεκινήσεις, δες "[Εκτέλεση των tests](https://exercism.org/docs/tracks/kotlin/tests)".

## macOS

Παρακάτω υπάρχουν οδηγίες εγκατάστασης με την πιο συνηθισμένη μέθοδο, το Homebrew.  Αν προτιμάς, μπορείς επίσης να [εγκαταστήσεις στο macOS χωρίς το Homebrew](#h-installing-on-macos-without-homebrew).

### Εγκατάσταση

1. Αν δεν έχεις εγκαταστήσει ακόμα το [Homebrew](http://brew.sh), κάν' το τώρα:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Κάνε tap στο [Homebrew Cask](https://caskroom.github.io/): αυτό μας επιτρέπει να εγκαταστήσουμε έτοιμα δυαδικά αρχεία, όπως το JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Εγκατέστησε το JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

Τώρα μπορείς να ξεκινήσεις με τη διαδρομή Kotlin του Exercism!

Για να ξεκινήσεις, δες "[Εκτέλεση των tests](https://exercism.org/docs/tracks/kotlin/tests)".

* [Debian](#h-debian)
* [Άλλες διανομές Linux](#h-other-linux-distributions)

### Debian

Αν χρησιμοποιείς Debian ή παράγωγά της (όπως Ubuntu ή Linux Mint), χρησιμοποίησε το APT:

*(επιβεβαιωμένο σε: Ubuntu 14, 16 και 18)*

1. Εγκατέστησε το JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


Τώρα μπορείς να ξεκινήσεις με τη διαδρομή Kotlin του Exercism!

### Άλλες διανομές Linux

Υπάρχουν πολλοί τρόποι να εγκαταστήσεις το JDK 11, αλλά ένας από τους πιο εύκολους είναι το SDKMAN,
που σου επιτρέπει να εγκαταστήσεις το OpenJDK 11 χωρίς κόπο. Ακολούθησε τα παρακάτω βήματα:

1. Εγκατέστησε το SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (αν δεν δουλέψει, ρίξε μια ματιά στις οδηγίες που θα βρεις εδώ: https://sdkman.io/install )
1. Εγκατέστησε το openjdk11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

Τώρα μπορείς να ξεκινήσεις με τη διαδρομή Kotlin του Exercism!

## Java IDE

Υπάρχουν πολλά Java IDE διαθέσιμα.  Τα τρία πιο δημοφιλή είναι:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (κατέβασε την έκδοση "Community")
  - από τους δημιουργούς του Kotlin, αυτό το IDE προσφέρει την καλύτερη υποστήριξη για τη γλώσσα.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (κατέβασε το πακέτο "Java SE")

και υπάρχουν [κι άλλα](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
