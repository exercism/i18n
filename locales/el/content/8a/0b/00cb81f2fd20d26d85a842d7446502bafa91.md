# Εισαγωγή

Όπως πολλές γλώσσες, έτσι και η Common Lisp περιέχει ακέραιους αριθμούς.
Πρόκειται για ακέραιους αριθμούς χωρίς υποδιαστολή (όπως `-6`, `0`, `25`, `1234`, κ.λπ.)

Η Common Lisp δεν ορίζει όρια στο μέγεθος των ακεραίων.
Οι ακέραιοι μπορούν να είναι οσοδήποτε μεγάλοι (ή μικροί, αν είναι αρνητικοί).

Γενικά, αν δουλεύεις μόνο με ακέραιους αριθμούς, καλό είναι να προτιμάς τους ακέραιους, αφού δεν έχουν την ίδια απώλεια ακρίβειας που έχουν οι αριθμοί κινητής υποδιαστολής ύστερα από πολλούς υπολογισμούς.
