# Σχετικά

Οι εντολές υπό συνθήκη της Factor παίρνουν όλες **quotations** ως κλάδους τους, δηλαδή κώδικα γραμμένο σε αγκύλες, `[ ... ]`, που ωθείται ως τιμή αντί να εκτελεστεί, ώσπου η εντολή υπό συνθήκη να τον επιλέξει. (Τα ίδια τα quotations καλύπτονται πλήρως σε επόμενη άσκηση.)

Οι τρεις βασικές βρίσκονται στο `kernel`:

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

Δύο παραλλαγές με αστερίσκο αντιμετωπίζουν το Boolean ως τιμή που αξίζει να χρησιμοποιηθεί όταν είναι αληθές, το καθιερωμένο ζεύγος "τιμή ή `f`":

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

Για περισσότερους από δύο κλάδους, το `cond` (στο `combinators`) διατρέχει έναν πίνακα από ζεύγη `{ predicate body }` και εκτελεί το σώμα του πρώτου κατηγορήματος που ενεργοποιείται. Το συμβατικό μοτίβο χρησιμοποιεί `dup` σε κάθε κατηγόρημα ώστε να διατηρείται η είσοδος, και το σώμα ξεκινά με ένα `drop` για να την απορρίψει πριν ωθήσει το αποτέλεσμα:

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

Μια τελική καταχώριση χωρίς κατηγόρημα είναι ο προεπιλεγμένος κλάδος.
