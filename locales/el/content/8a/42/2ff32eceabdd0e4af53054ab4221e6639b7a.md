# Tests

Κάθε άσκηση περιέχει ένα αρχείο tests.
Τρέξε τα tests χρησιμοποιώντας το πρόγραμμα `bats`.

```bash
bats hello_world.bats
```

Αν χρειάζεται να τυπώσεις debug output όταν τρέχεις τα tests τοπικά, δες το [Debugging τοπικά][debugging].

Το `bats` θα χρειαστεί να εγκατασταθεί.
Δες τη σελίδα [Tests στο track Bash][tests] για οδηγίες εγκατάστασης του `bats` στο σύστημά σου.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Βοήθεια για τις συναρτήσεις assert

Τα tests χρησιμοποιούν συναρτήσεις από τη βιβλιοθήκη [bats-assert][bats-assert].
Εκεί θα βρεις βοήθεια για τις διάφορες συναρτήσεις `assert*`.

[bats-assert]: https://github.com/bats-core/bats-assert

## Tests που παραλείπονται

Για να λύσεις μια άσκηση, πρέπει να περάσουν όλα τα tests της.
Από προεπιλογή, όταν τρέχεις τα tests εκτελείται μόνο ένα test (το πρώτο).
Αυτό γίνεται σκόπιμα, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσει μόνο αυτό το ένα test.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο test σχολιάζοντας ή αφαιρώντας την επόμενη σημείωση:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Παράκαμψη των παραλείψεων

Για να τρέξεις όλα τα tests, συμπεριλαμβανομένων αυτών με σημειώσεις `skip`, μπορείς να τρέξεις:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Μπορεί να σε βολέψει να χρησιμοποιήσεις μια συνάρτηση περιτυλίγματος για να γλιτώσεις πληκτρολόγηση:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Έπειτα τρέξε τα tests μόνο με:

```bash
bats
```
