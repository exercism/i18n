# Εισαγωγή

Αυτή η άσκηση βασίζεται στην ακέραια αριθμητική από
[Τα Λαχταριστά Λαζάνια της Λία][lasagna]. Εδώ θα δουλέψεις με αριθμούς
κινητής υποδιαστολής και θα διαλέξεις τη σωστή λέξη διαίρεσης για τη
δουλειά.

## Ακέραιοι και αριθμοί κινητής υποδιαστολής

Ο Factor ξεχωρίζει τους ακέραιους (`1`, `42`, `1_000_000`) από τους
αριθμούς κινητής υποδιαστολής (`1.0`, `3.14`, `6.02e23`). Αν αναμείξεις
έναν ακέραιο και έναν αριθμό κινητής υποδιαστολής στον ίδιο υπολογισμό,
το αποτέλεσμα βγαίνει ως αριθμός κινητής υποδιαστολής:

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

Μπορείς να βάλεις κάτω παύλες μέσα σε έναν αριθμό για να ομαδοποιήσεις
τα ψηφία (`1_000_000`), και ο Factor απλώς τις αγνοεί.

## Λέξεις διαίρεσης

Ο Factor έχει ξεχωριστές λέξεις για τη διαίρεση. Όλες βρίσκονται στο
λεξιλόγιο [`math`][math].

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

Το `/` παράγει ένα `ratio` (τον ακριβή ρητό τύπο του Factor) για δύο
ακέραιους, ή ένα `float` αν μία από τις δύο εισόδους είναι αριθμός
κινητής υποδιαστολής. Το `/f` επιβάλλει αποτέλεσμα κινητής υποδιαστολής
ακόμα και για δύο ακέραιους. Το `/i` περικόπτει πάντα προς το μηδέν.

## Έλεγχος

Κατηγορήματα αριθμών από τα [`math`][math], [`math.functions`][math.functions]
και [`math.primes`][math.primes]:

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## Από κινητής υποδιαστολής σε ακέραιο

Τα `floor`, `ceiling` και `round` από το λεξιλόγιο
[`math.functions`][math.functions] επιστρέφουν όλα αριθμό κινητής
υποδιαστολής (`3.0`, όχι `3`). Για να πάρεις πραγματικό ακέραιο, συνέχισε
με `>integer`:

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## Δυνάμεις και απόλυτη τιμή

Τα `sq`, `^` και `abs` (στο [`math.functions`][math.functions])
υπολογίζουν τετράγωνα, δυνάμεις με οποιονδήποτε εκθέτη και απόλυτες
τιμές:

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## Ελάχιστο και μέγιστο

Τα `min ( x y -- z )` και `max ( x y -- z )` (στο
[`math.order`][math.order]) επιστρέφουν τον μικρότερο ή τον μεγαλύτερο
από δύο αριθμούς:

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

Η πιο συνηθισμένη χρήση είναι ο *περιορισμός*: καθηλώνεις μια τιμή σε ένα
κατώτατο όριο με το `max` (π.χ. το `0 max` κρατά μια τιμή μη αρνητική) ή
σε ένα ανώτατο όριο με το `min`.

## Κατηγορήματα διάταξης

Το `math.order` παρέχει επίσης τα `before?`, `after?`, `before=?` και
`after=?`, κατηγορήματα σύγκρισης που δουλεύουν με κάθε τύπο που μπορεί να
διαταχθεί, όπως αριθμούς, συμβολοσειρές και χαρακτήρες:

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

Χρησιμοποίησέ τα αντί για τα `<`/`<=` όταν οι τιμές μπορεί να είναι
συμβολοσειρές: οι αριθμητικοί τελεστές δε λειτουργούν σε συμβολοσειρές.
