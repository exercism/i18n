# Σχετικά

Για να εκτελείς κάποια λογική επανειλημμένα, μπορείς να χρησιμοποιήσεις βρόχους. Αν ο κώδικας μέσα σε έναν βρόχο πρέπει να εκτελεστεί πάντα τουλάχιστον μία φορά, μπορείς να χρησιμοποιήσεις έναν `do`/`while` βρόχο:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Τον χρησιμοποιείς λιγότερο συχνά από έναν `while` βρόχο, αλλά σε ορισμένες περιπτώσεις οδηγεί σε κώδικα που μοιάζει πιο φυσικός.
