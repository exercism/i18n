# Προσθήκη στις οδηγίες

Ψάχνεις ένα σημείο για να ξεκινήσεις; Ορίστε μερικά πράγματα που ίσως θέλεις να τακτοποιήσεις:

- Μία συνάρτηση κάνει τα πάντα
- Διπλότυπη λογική και επαναλαμβανόμενη δουλειά
- Βαθιά εμφώλευση
- Δυσνόητα ονόματα
- Διάσπαρτοι κανόνες μορφοποίησης
- Ανεξήγητες σταθερές
- Περιττή μεταβλητή κατάσταση
- Σιωπηρές εφεδρικές τιμές enum
- Βοηθητικές συναρτήσεις με άσχετες αρμοδιότητες
- Κενές συμβολοσειρές στη θέση σφαλμάτων
- Χειροκίνητη ανάλυση και μορφοποίηση ημερομηνιών (δοκίμασε αντ' αυτού να εισάγεις και να χρησιμοποιήσεις το `isodate.Date`)
- Χειροκίνητος χειρισμός Unicode (δοκίμασε αντ' αυτού να εισάγεις και να χρησιμοποιήσεις το `unicode.Grapheme`)

Διάλεξε ό,τι σου τραβάει την προσοχή και κράτα τα tests πράσινα!
