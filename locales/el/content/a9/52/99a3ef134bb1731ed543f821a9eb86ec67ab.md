# Εισαγωγή

Ο τελεστής `|>` ονομάζεται τελεστής pipe. Μπορεί να χρησιμοποιηθεί για να συνδέσεις κλήσεις συναρτήσεων μεταξύ τους, έτσι ώστε η τιμή που επιστρέφει η προηγούμενη κλήση συνάρτησης να περνά στην επόμενη κλήση συνάρτησης.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Ο παραπάνω κώδικας είναι ισοδύναμος με τον εξής:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Ο τελεστής pipe περνά την τιμή είτε ως πρώτο όρισμα στην κλήση συνάρτησης είτε ως μοναδικό όρισμα σε μια νέα κλήση, διαλέγοντας όποιο από τα δύο θα είχε τον σωστό τύπο.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Μερικές φορές θέλουμε να περάσουμε την τιμή σε κάποια άλλη θέση. Σε αυτή την περίπτωση, μπορεί να χρησιμοποιηθεί το placeholder `_` για να δείξεις πού πρέπει να εισαχθεί η τιμή.

```gleam
100
|> some_function(1, _, 2)
```
