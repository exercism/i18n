# Debug

Όταν ένα test αποτύχει ή ο κώδικάς σου δεν μεταγλωττίζεται, θα εμφανιστεί ένα σφάλμα στην κονσόλα. Αν δεν σε βοηθήσει, μπορείς να τρέξεις την [εντολή `stack ghci`][docs-stack-ghci] και να μπεις στο [διαδραστικό REPL][docs-ghci]. Εκεί μπορείς να δοκιμάσεις τις συναρτήσεις σου και να πειραματιστείς μέχρι να καταλάβεις πώς να διορθώσεις τον κώδικά σου.

[docs-stack-ghci]: https://docs.haskellstack.org/en/stable/ghci/
[docs-ghci]: https://downloads.haskell.org/~ghc/latest/docs/html/users_guide/ghci.html
