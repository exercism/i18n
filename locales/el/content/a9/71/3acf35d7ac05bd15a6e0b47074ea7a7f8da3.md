# Εισαγωγή

Η συμβολοσειρά στη Factor είναι μια ακολουθία χαρακτήρων. Οι περισσότερες λέξεις από το λεξιλόγιο [`sequences`][sequences] λειτουργούν και με συμβολοσειρές, πέρα από τις ειδικές λέξεις χειρισμού συμβολοσειρών στα [`splitting`][splitting], [`ascii`][ascii] και σε συναφή λεξιλόγια.

## Κυριολεκτικά συμβολοσειρών

Οι συμβολοσειρές γράφονται μέσα σε διπλά εισαγωγικά. Υποστηρίζονται οι συνήθεις ακολουθίες διαφυγής: `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Μήκος και θέσεις

Επειδή μια συμβολοσειρά είναι ακολουθία, οι λέξεις `length` και `nth` του λεξιλογίου [`sequences`][sequences] λειτουργούν απευθείας πάνω της.

Η `length` επιστρέφει τον αριθμό των χαρακτήρων:

```factor
"hello" length .    ! => 5
```

Η `nth` παίρνει μια θέση με βάση το 0 και την ακολουθία, και επιστρέφει το στοιχείο σε αυτή τη θέση. Για μια συμβολοσειρά, το στοιχείο είναι ένας *χαρακτήρας*, δηλαδή ένα σημείο κώδικα (ένας ακέραιος), όχι μια υποσυμβολοσειρά ενός χαρακτήρα:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## Από έναν χαρακτήρα πίσω σε συμβολοσειρά

Για να μετατρέψεις ένα μεμονωμένο σημείο κώδικα σε συμβολοσειρά ενός χαρακτήρα, χρησιμοποίησε τη `1string ( char -- str )` από το λεξιλόγιο [`strings`][strings]. Το `CHAR:` είναι η μορφή του κυριολεκτικού σημείου κώδικα τη στιγμή της ανάλυσης:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Διαχωρισμός

Το λεξιλόγιο [`splitting`][splitting] κόβει μια συμβολοσειρά σε κομμάτια.

Η `split1` κόβει στο *πρώτο* σημείο εμφάνισης ενός διαχωριστικού και επιστρέφει και τα δύο μισά:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

Η `split` κόβει σε *οποιονδήποτε* από τους χαρακτήρες ενός συνόλου διαχωριστικών, παράγοντας ενδεχομένως κενά κομμάτια:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

Η `harvest` (στο λεξιλόγιο [`sequences`][sequences]) πετάει τα κενά κομμάτια:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Επιλέγοντας ένα κομμάτι

Αφού μια συμβολοσειρά χωριστεί σε πίνακα από κομμάτια, οι `first`, `second`, `third` και `fourth` (στο λεξιλόγιο [`sequences`][sequences]) επιστρέφουν το κομμάτι σε αυτή τη θέση:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Όταν θέλεις όλα τα πρώτα κομμάτια στη στοίβα ταυτόχρονα, οι `first2` και `first3` ξεδιπλώνουν δύο ή τρία από αυτά σε ένα βήμα:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Πάνω σε μια συμβολοσειρά την ίδια, η `first` επιστρέφει τον πρώτο **χαρακτήρα**, δηλαδή ένα σημείο κώδικα, και όχι μια υποσυμβολοσειρά:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Αποκοπή κενών διαστημάτων

Η `[ blank? ] trim` (από το λεξιλόγιο [`sequences`][sequences], με τη `blank?` από το λεξιλόγιο [`ascii`][ascii]) αφαιρεί τα κενά στην αρχή και στο τέλος:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Μετατροπή πεζών/κεφαλαίων

Οι `>lower` και `>upper` (από το λεξιλόγιο [`ascii`][ascii]) επιστρέφουν μια νέα συμβολοσειρά με αλλαγμένα πεζά/κεφαλαία:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Συνένωση

Δύο λέξεις του λεξιλογίου [`sequences`][sequences] συνθέτουν συμβολοσειρές:

Η `surround` τυλίγει μια συμβολοσειρά με ένα πρόθεμα και ένα επίθημα:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

Η `glue` ενώνει δύο συμβολοσειρές με ένα διαχωριστικό ανάμεσά τους:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
