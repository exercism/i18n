# Σχετικά

Ένας βρόχος είναι ένας τρόπος να εκτελούμε επανειλημμένα μία ή περισσότερες εντολές σε ένα σύνολο.
Κάθε εκτέλεση ενός συνόλου εντολών ονομάζεται επανάληψη.

## `while` βρόχος

Ένας `while` βρόχος εκτελεί ένα σύνολο εντολών όσο μια Boolean έκφραση στην αρχή του βρόχου είναι αληθής.
Όταν η Boolean έκφραση είναι ψευδής, ο βρόχος σταματά να εκτελείται και η εκτέλεση προχωρά στην επόμενη γραμμή κώδικα μετά τον βρόχο.

Αν η Boolean έκφραση αξιολογείται ως ψευδής από την αρχή, ο `while` βρόχος δεν θα εκτελεστεί καθόλου και η εκτέλεση θα προχωρήσει στην επόμενη γραμμή κώδικα μετά τον βρόχο.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Είναι σημαντικό να υπάρχει μια συνθήκη για να τερματίζεται ο βρόχος, αλλιώς είναι ένας ατέρμονος βρόχος που θα μπλοκάρει κάθε πρόοδο του κώδικα.
Αν από τον παραπάνω κώδικα αφαιρούσαμε το `++` από το `i`, θα ήταν ένας ατέρμονος βρόχος.

## `do` βρόχος

Σε έναν `do` βρόχο, η Boolean έκφραση ελέγχεται στο κάτω μέρος του βρόχου.
Ένας `do` βρόχος θα εκτελεστεί πάντα τουλάχιστον μία φορά, όπως στο παρακάτω παράδειγμα

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Με έναν `while` βρόχο, αυτό θα ήταν πιο φλύαρο

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` βρόχος

Συχνά ένας βρόχος ενημερώνει μια μεταβλητή και τελειώνει όταν η μεταβλητή φτάσει σε μια συγκεκριμένη τιμή.
Ένας `for` βρόχος είναι ένας τρόπος να αρχικοποιούμε, να ενημερώνουμε και να ελέγχουμε μία ή περισσότερες μεταβλητές σε μία γραμμή μέσα σε παρενθέσεις.
Το πρώτο τμήμα είναι για την αρχικοποίηση της μεταβλητής, το δεύτερο τμήμα για τον έλεγχο της μεταβλητής, και το τρίτο τμήμα για την ενημέρωση της τιμής της μεταβλητής.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Αυτό είναι λιγότερο φλύαρο από τον αντίστοιχο `while` βρόχο, και όμως παραμένει ευανάγνωστο.

Τα τμήματα αρχικοποίησης και ενημέρωσης του `for` βρόχου μπορούν να χειριστούν περισσότερες από μία μεταβλητές χρησιμοποιώντας τον τελεστή κόμμα για να διαχωρίζουν εκφράσεις μέσα στις συνθήκες.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Αυτό θα εκτυπώσει

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

Κανένα από τα τμήματα του `for` βρόχου δεν χρειάζεται να οριστεί.
Μια κενή έκφραση ελέγχου αξιολογείται ως αληθής, οπότε ένας `for` βρόχος θα μπορούσε να χρησιμοποιηθεί για να ορίσει έναν ατέρμονο βρόχο ως εξής

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Αυτό είναι παρόμοιο με τον `while` βρόχο στο ότι το `i` αρχικοποιείται πριν από τον βρόχο και αυξάνεται μέσα στον βρόχο.
Επίσης, το `i` ελέγχεται μέσα στον βρόχο και ο βρόχος τελειώνει με την εντολή `break`.

## Εντολή `break`

Μερικές φορές ένας βρόχος μπορεί να χρειάζεται να τερματιστεί σε μια ειδική συνθήκη που δεν ελέγχεται στη Boolean έκφρασή του.
Η εντολή `break` θα τερματίσει τον βρόχο και η εκτέλεση θα προχωρήσει στην επόμενη γραμμή κώδικα μετά τον βρόχο.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Αυτό θα εκτυπώσει

```
i is 0
j is 5
After the loop
```

## Εντολή `continue`

Μερικές φορές ένας βρόχος μπορεί να χρειάζεται να ξεκινήσει την επόμενη επανάληψή του χωρίς να ολοκληρώσει την τρέχουσα επανάληψη.
Η εντολή `continue` σταματά την εκτέλεση της τρέχουσας επανάληψης και συνεχίζει την εκτέλεση στην αρχή της επόμενης επανάληψης.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Αυτό θα εκτυπώσει

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

Δεν εκτυπώνει τις τιμές για τα `i` και `j` όταν είναι και τα δύο `2`.
