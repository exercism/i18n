# Υποδείξεις

## Γενικά

- [Τα structs και οι κλάσεις][structs-and-classes] έχουν παρόμοια σύνταξη ορισμού.

## 1. Όρισε ένα struct Size

- Οι ιδιότητες πρέπει να ορίζονται ως `var`s αν μπορούν να αλλάξουν.
- Στις ιδιότητες height και width πρέπει να δοθούν οι προεπιλεγμένες τιμές 80 και 60, αντίστοιχα.
- Οι μέθοδοι σε ένα struct πρέπει να σημειώνονται ως `mutating` αν αλλάζουν ιδιότητες του struct.

## 2. Όρισε ένα struct Position

- Οι ιδιότητες πρέπει να ορίζονται ως `var`s αν μπορούν να αλλάξουν.
- Στις ιδιότητες x και y πρέπει να δοθεί η προεπιλεγμένη τιμή 0.
- Οι μέθοδοι σε ένα struct πρέπει να σημειώνονται ως `mutating` αν αλλάζουν ιδιότητες του struct.

## 3. Όρισε την κλάση Window

- Τα structs μπορούν να αρχικοποιηθούν με διαφορετικές τιμές ιδιοτήτων χρησιμοποιώντας [αρχικοποιητές κατά μέλος][memberwise-initializers].
- Οι σταθερές ιδιότητες πρέπει να ορίζονται με `let`.
- Η ιδιότητα `contents` πρέπει να είναι προαιρετική, καθώς μπορεί να μην έχει τιμή.
- Πρέπει να ορίσεις έναν κενό αρχικοποιητή για την κλάση (`init() {}`).

## 4. Πρόσθεσε μια μέθοδο για αλλαγή μεγέθους των παραθύρων

- Η μέθοδος πρέπει να δέχεται μια παράμετρο `to` τύπου `Size`.
- Μπορείς να εξάγεις το width και το height από την παράμετρο `to` χρησιμοποιώντας σημειογραφία με τελείες.

## 5. Πρόσθεσε μια μέθοδο για μετακίνηση των παραθύρων

- Η μέθοδος πρέπει να δέχεται μια παράμετρο `to` τύπου `Position`.
- Μπορείς να εξάγεις το x και το y από την παράμετρο `to` χρησιμοποιώντας σημειογραφία με τελείες.

## 6. Πρόσθεσε μια μέθοδο που ορίζει τα περιεχόμενα ενός παραθύρου

- Στη Swift μπορείς να έχεις δύο μεθόδους με το ίδιο όνομα αλλά διαφορετικές παραμέτρους.
- Όρισε μια μέθοδο με παράμετρο `title` που ορίζει την ιδιότητα `title`.
- Όρισε μια μέθοδο με παράμετρο `text` που ορίζει την ιδιότητα `contents`.
- Όρισε μια μέθοδο display που εκτυπώνει τον τίτλο και τα περιεχόμενα του παραθύρου.

## 7. Δημιούργησε έναν αρχικοποιητή για την κλάση Window

- Η κλάση πρέπει να έχει δύο αρχικοποιητές: έναν που δε δέχεται παραμέτρους και έναν που δέχεται παραμέτρους.
- Ο νέος αρχικοποιητής πρέπει να έχει τις παραμέτρους `title` και `contents`, και πρέπει επίσης να δέχεται τις προαιρετικές παραμέτρους `size` και `position`
    Αν δε δοθούν παράμετροι, πρέπει να χρησιμοποιούνται οι προεπιλεγμένες τιμές.
- Οι προαιρετικές παράμετροι μπορούν να επιτευχθούν με τη χρήση [προεπιλεγμένων τιμών παραμέτρων][default-parameters-vales].
