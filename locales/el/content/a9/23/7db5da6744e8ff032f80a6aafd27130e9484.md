# Εισαγωγή

## Πίνακες

Στη Ruby, οι **πίνακες** είναι διατεταγμένες συλλογές οποιουδήποτε αντικειμένου, με ακέραιες θέσεις.
Η αρίθμηση των θέσεων ενός πίνακα ξεκινά από το `0`.
Μια αρνητική θέση θεωρείται ότι μετράει από το τέλος του πίνακα. Για παράδειγμα, η θέση `-1` δείχνει το τελευταίο στοιχείο του πίνακα, η `-2` είναι το προτελευταίο στοιχείο του πίνακα, και ούτω καθεξής.

### Δημιουργία πινάκων

Οι πίνακες συνήθως δημιουργούνται με τον συμβολισμό `[]`.
Μπορούν να περιέχουν αντικείμενα οποιουδήποτε τύπου.

```ruby
array = [1, "two", 3.0]
```

### Πρόσβαση σε στοιχεία

Τα στοιχεία ενός πίνακα μπορούν να ανακτηθούν με τις θέσεις τους χρησιμοποιώντας τη μέθοδο `#[]`.
Αυτή επιστρέφει το στοιχείο στη συγκεκριμένη θέση ή επιστρέφει έναν υποπίνακα που ξεκινά από τη θέση εκκίνησης και συνεχίζει για ένα καθορισμένο μήκος.
Οι αρνητικές θέσεις μετρούν προς τα πίσω από το τέλος του πίνακα.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### Βοηθητικές μέθοδοι

Υπάρχουν πολλές χρήσιμες βοηθητικές μέθοδοι για τους πίνακες.
Ορίστε μερικές από τις πιο συνηθισμένες:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## Απαρίθμηση

Αντί να χρησιμοποιούμε βρόχους για να διατρέξουμε συλλογές, στη Ruby χρησιμοποιούμε απαρίθμηση.

Η απαρίθμηση είναι η διαδικασία να διατρέχουμε μια συλλογή (εδώ έναν πίνακα) και να εκτελούμε κάποια ενέργεια σε κάθε αντικείμενο.  Η απαρίθμηση είναι βασική έννοια στη Ruby και χρησιμοποιείται για πράγματα όπως ταξινόμηση, ομαδοποίηση, mapping, reducing και πολλά άλλα.

Μια απαρίθμηση που τυπώνει κάθε λέξη ενός πίνακα θα έμοιαζε κάπως έτσι:

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

Σε αυτό το παράδειγμα, καλέσαμε τη μέθοδο `.each` στον πίνακα μας και της περάσαμε ένα _μπλοκ_ που δέχεται μία παράμετρο (`word`) και την τυπώνει.

Θα δούμε τα _μπλοκ_ πολύ πιο αναλυτικά αργότερα στο track, αλλά για την ώρα σκέψου τα σαν ανώνυμες συναρτήσεις που μπορούν να δέχονται μηδέν ή περισσότερα ορίσματα.
Μπορούν να οριστούν με τη σύνταξη `do...end` (πάνω) ή με τη σύνταξη `{}` (κάτω).

Ορίστε μερικά ακόμη παραδείγματα μεθόδων πινάκων που χρησιμοποιούν μπλοκ:

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
