# Σχετικά

Το μάκρο `use` μάς επιτρέπει να επεκτείνουμε γρήγορα τη μονάδα μας με λειτουργικότητα που παρέχει μια άλλη μονάδα. Όταν κάνουμε `use` μια μονάδα, αυτή η μονάδα μπορεί να εισάγει κώδικα στη μονάδα μας: μπορεί για παράδειγμα να ορίσει συναρτήσεις, να κάνει `import` ή `alias` άλλες μονάδες, ή να ορίσει χαρακτηριστικά μονάδας.

Αν έχεις κοιτάξει ποτέ τα αρχεία δοκιμών κάποιων από τις ασκήσεις Elixir εδώ στο Exercism, πιθανότατα θα πρόσεξες ότι όλα ξεκινούν με `use ExUnit.Case`. Αυτή η μία γραμμή κώδικα είναι αυτό που κάνει τα μάκρο `test` και `assert` διαθέσιμα στη μονάδα δοκιμών.

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## Το μάκρο `__using__/1`

Το τι ακριβώς συμβαίνει όταν κάνεις `use` μια μονάδα το υπαγορεύει το μάκρο `__using__/1` αυτής της μονάδας. Παίρνει ένα όρισμα, μια λίστα λέξεων-κλειδιών με επιλογές, και επιστρέφει μια [παρατιθέμενη έκφραση][concept-ast]. Ο κώδικας σε αυτήν την παρατιθέμενη έκφραση εισάγεται στη μονάδα μας όταν καλούμε το `use`.

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

Οι επιλογές μπορούν να δοθούν ως δεύτερο όρισμα όταν καλείς το `use`, π.χ. `use ExUnit.Case, async: true`. Όταν δεν δίνονται ρητά, προεπιλέγονται σε μια κενή λίστα.

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
