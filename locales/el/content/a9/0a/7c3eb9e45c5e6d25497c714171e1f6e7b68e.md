# Εισαγωγή

[Οι δομές και οι κλάσεις][structs-and-classes] είναι τα βασικά δομικά στοιχεία για τη δημιουργία προσαρμοσμένων τύπων στη Swift.
Και οι δύο σου επιτρέπουν να ομαδοποιείς σχετικές ιδιότητες (δεδομένα) και μεθόδους (συμπεριφορά) σε επαναχρησιμοποιήσιμες μονάδες.
Οι περισσότεροι βασικοί τύποι στη Swift, όπως οι `Int`, `Double` και `String`, καθώς και τύποι συλλογών όπως οι `Array` και `Dictionary`, υλοποιούνται ως δομές.

Για αναλυτικούς οδηγούς για κάθε τύπο, δες:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Επιλογή Ανάμεσα σε Δομές και Κλάσεις

Ενώ και οι δομές και οι κλάσεις σου επιτρέπουν να ορίσεις προσαρμοσμένους τύπους, διαφέρουν θεμελιωδώς στον τρόπο με τον οποίο μεταφέρονται στη μνήμη:

- **Οι δομές είναι τύποι τιμών**: Όταν αντιγράφεις ή περνάς μια δομή, η Swift δημιουργεί ένα ανεξάρτητο αντίγραφο των δεδομένων της.
Οι αλλαγές που γίνονται σε ένα αντίγραφο δεν επηρεάζουν τα άλλα αντίγραφα.
- **Οι κλάσεις είναι τύποι αναφοράς**: Όταν αντιγράφεις ή περνάς ένα στιγμιότυπο κλάσης, η Swift μοιράζεται μια αναφορά στο υπάρχον στιγμιότυπο.
Οι αλλαγές που γίνονται μέσω μιας αναφοράς επηρεάζουν αμέσως όλες τις άλλες αναφορές που δείχνουν στο ίδιο στιγμιότυπο.

Η Swift δίνει έμφαση στην ασφάλεια και την προβλέψιμη συμπεριφορά, κάτι που κάνει τις δομές την προεπιλεγμένη σύσταση για τους περισσότερους προσαρμοσμένους τύπους.
Η χρήση τύπων τιμών διασφαλίζει ότι η μεταβολή δεδομένων σε ένα σημείο του προγράμματός σου δεν προκαλεί απροσδόκητες παρενέργειες αλλού.

Σε γενικές γραμμές:

- **Χρησιμοποίησε μια δομή** όταν μοντελοποιείς δεδομένα που αντιπροσωπεύουν ανεξάρτητες τιμές (όπως συντεταγμένες, σχήματα, γεωμετρικές διαστάσεις ή μορφοποιημένες καταγραφές).
- **Χρησιμοποίησε μια κλάση** όταν μοντελοποιείς οντότητες που έχουν ξεχωριστές ταυτότητες ή απαιτήσεις κοινής διάρκειας ζωής (όπως στοιχεία ελέγχου UI, συνδέσεις βάσης δεδομένων ή χειριστές αρχείων).
