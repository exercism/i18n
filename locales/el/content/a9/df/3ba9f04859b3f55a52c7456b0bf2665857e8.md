# Οδηγίες

Καθώς συνεχίζεις τη δουλειά σου στην _Instruments of Texas_, γίνεται πρόοδος στην υλοποίηση σε Elixir της αριθμομηχανής RPN. Η ομάδα σου θα ήθελε να μπορεί να πετάει σφάλματα πιο συγκεκριμένα από τα γενικά σφάλματα που παρέχει η βασική βιβλιοθήκη. Κάνεις κάποια έρευνα, αλλά έχεις αποφασίσει να υλοποιήσεις δύο νέα σφάλματα που υλοποιούν το _Exception Behaviour_.

## 1. Σφάλμα για τη διαίρεση με το μηδέν

Η διαίρεση ενός αριθμού με το μηδέν παράγει ένα απροσδιόριστο αποτέλεσμα, το οποίο η ομάδα αποφασίζει ότι αναπαρίσταται καλύτερα με ένα σφάλμα.

Υλοποίησε το άρθρωμα `DivisionByZeroError` ώστε να έχει το μήνυμα σφάλματος: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Σφάλμα κατά την υποχείλιση της στοίβας

Οι αριθμομηχανές RPN χρησιμοποιούν μια _στοίβα_ για να κρατούν τους αριθμούς πριν γίνει πάνω τους κάποια πράξη. Η ομάδα αναπαριστά αυτή τη _στοίβα_ με μια λίστα αριθμών (ακέραιων και κινητής υποδιαστολής), π.χ.: `[3, 4.0]`. Κάθε πράξη χρειάζεται έναν συγκεκριμένο αριθμό αριθμών στη στοίβα για να εκτελέσει τον υπολογισμό της. Όταν δεν υπάρχουν αρκετοί αριθμοί στη στοίβα, αυτό ονομάζεται σφάλμα υποχείλισης στοίβας. Υλοποίησε την εξαίρεση `StackUnderflowError` που παρέχει ένα προεπιλεγμένο μήνυμα και προαιρετικό επιπλέον πλαίσιο

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Γράψε μια συνάρτηση διαίρεσης

Υλοποίησε τη συνάρτηση `divide/1` που παίρνει μια στοίβα _(μια λίστα με δύο αριθμούς)_ και:

- πετάει _υποχείλιση στοίβας_ όταν η στοίβα δεν περιέχει αρκετούς αριθμούς
- πετάει _διαίρεση με το μηδέν_ όταν ο διαιρέτης είναι 0 (πρόσεξε ότι η στοίβα των αριθμών αποθηκεύεται σε αντίστροφη σειρά)
- εκτελεί τη διαίρεση όταν δεν πετάγεται κανένα σφάλμα

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> Πρόσεξε ότι η σειρά της λίστας είναι αντεστραμμένη!
