# Εισαγωγή

Τα dict στη Gleam είναι η δομή δεδομένων για την αποθήκευση πληροφοριών σε ζεύγη κλειδιού-τιμής. Σε άλλες γλώσσες, μπορεί επίσης να είναι γνωστά ως συσχετιστικοί πίνακες, hashes ή λεξικά.

Οποιοσδήποτε τύπος μπορεί να χρησιμοποιηθεί για τα κλειδιά και τις τιμές σε ένα dict, και δεν εγγυώνται τη σειρά των καταχωρήσεων όταν προσπελαύνονται ή επιστρέφονται.

## Εργασία με dict

Τα dict δημιουργούνται και χειρίζονται χρησιμοποιώντας συναρτήσεις από το module `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
