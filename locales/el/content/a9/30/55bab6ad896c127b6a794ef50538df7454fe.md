# Σχετικά

Στη Haxe, οι iterator χρησιμοποιούνται για να διατρέξεις μια τιμή με έναν `for` βρόχο. Υπάρχουν δύο τύποι iterator:

- Ο `Iterator`, ο οποίος διατρέχει μια τιμή.
- Τα δεδομένα `Iterable`, τα οποία σου επιτρέπουν να διατρέξεις έναν τύπο δεδομένων.

Και οι δύο αυτές έννοιες αντιπροσωπεύονται από τα `Iterator<T>` και `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Μπορείς να διατρέξεις οποιαδήποτε κλάση που ενοποιείται με έναν από αυτούς τους τύπους, χρησιμοποιώντας έναν `for` βρόχο. Αν μια κλάση ορίζει τις μεθόδους `hasNext` και `next`, θεωρείται iterator, αλλιώς αν ορίζει μια μέθοδο `iterator`, θεωρείται τύπος iterable:

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

Στο παραπάνω παράδειγμα, η κλάση `MyStringIterator` θεωρείται iterator, καθώς υλοποιεί και τις δύο μεθόδους `hasNext` και `next`, γεγονός που την κάνει συμβατή με το `Iterator<String>`.

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

Εδώ, η κλάση `MyArrayWrap` θεωρείται τύπος δεδομένων iterable, καθώς είναι συμβατή με το `Iterable<Array<T>>`.
