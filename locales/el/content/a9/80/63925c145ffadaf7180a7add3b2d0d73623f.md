# Οδηγίες

Υλοποίησε διάφορα είδη χειρισμού σφαλμάτων και διαχείρισης πόρων.

Ένα σημαντικό σημείο του προγραμματισμού είναι το πώς να χειρίζεσαι τα σφάλματα και να κλείνεις πόρους ακόμα κι όταν προκύπτουν σφάλματα.

Αυτή η άσκηση απαιτεί να χειριστείς διάφορα σφάλματα.
Επειδή ο χειρισμός σφαλμάτων εξαρτάται σε μεγάλο βαθμό από τη συγκεκριμένη γλώσσα προγραμματισμού, θα χρειαστεί να συμβουλευτείς τα tests του track σου για να δεις τι ακριβώς απαιτείται.
