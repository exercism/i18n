# Σχετικά

## Αριθμητικοί τελεστές

Η JavaScript παρέχει 6 διαφορετικούς τελεστές για να εκτελείς βασικές αριθμητικές πράξεις με αριθμούς.

- `+`: Ο τελεστής πρόσθεσης χρησιμοποιείται για να βρεις το άθροισμα δύο αριθμών.

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`: Ο τελεστής αφαίρεσης χρησιμοποιείται για να βρεις τη διαφορά δύο αριθμών

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`: Ο τελεστής πολλαπλασιασμού χρησιμοποιείται για να βρεις το γινόμενο δύο αριθμών

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`: Ο τελεστής διαίρεσης χρησιμοποιείται για να διαιρέσεις δύο αριθμούς.
  Επειδή οι αριθμοί στη JavaScript είναι πάντα αριθμοί κινητής υποδιαστολής, δεν υπάρχει ακέραια διαίρεση.

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`: Ο τελεστής υπολοίπου χρησιμοποιείται για να βρεις το υπόλοιπο μιας διαίρεσης.

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`: Ο τελεστής ύψωσης σε δύναμη χρησιμοποιείται για να υψώσεις έναν αριθμό σε μια δύναμη.
  Είναι το ίδιο με τη χρήση του [`Math.pow()`][mdn-math-pow]

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## Σειρά πράξεων

Όταν χρησιμοποιείς πολλούς τελεστές σε μία γραμμή, η JavaScript ακολουθεί μια σειρά προτεραιότητας, όπως φαίνεται σε [αυτόν τον πίνακα προτεραιότητας][mdn-operator-precedence].
Για να το απλοποιήσουμε στο δικό μας πλαίσιο, η JavaScript χρησιμοποιεί τον κανόνα PEDMAS (Παρενθέσεις, Εκθέτες, Διαίρεση/Πολλαπλασιασμός, Πρόσθεση/Αφαίρεση) που μάθαμε στα μαθηματικά του δημοτικού.

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## Συντομευμένοι τελεστές εκχώρησης

Οι συντομευμένοι τελεστές εκχώρησης είναι ένας συντομότερος τρόπος να γράψεις κώδικα που εκτελεί αριθμητικές πράξεις σε μια μεταβλητή και εκχωρεί τη νέα τιμή στην ίδια μεταβλητή.
Για παράδειγμα, σκέψου δύο μεταβλητές, τις `x` και `y`.
Τότε, το `x += y` είναι το ίδιο με το `x = x + y`.
Συχνά, αυτό χρησιμοποιείται με έναν αριθμό αντί για μια μεταβλητή `y`.
Οι άλλες 5 πράξεις μπορούν επίσης να γίνουν με παρόμοιο τρόπο.

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
