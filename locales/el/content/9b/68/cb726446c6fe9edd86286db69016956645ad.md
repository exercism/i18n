## MacOS

Πρώτα, εγκατέστησε τη Lua και το [Luarocks][2] χρησιμοποιώντας το [Homebrew][1]:

```shell
$ brew install lua luarocks
```

Στη συνέχεια, εγκατέστησε το [Busted][3], το framework δοκιμών για τη Lua:

```shell
$ luarocks install --local busted
```

Πρόσθεσε το `~/.luarocks/bin` στο `$PATH` του συστήματός σου

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

Λάβε υπόψη ότι αυτό είναι μόνο προσωρινό.
Για να το προσθέσεις μόνιμα στο `$PATH`, θα πρέπει να το προσθέσεις στο `.bashrc`, στο `.zshrc` ή στο `config.fish`, ανάλογα με το ποιο κέλυφος χρησιμοποιείς.

Στη συνέχεια, τρέξε τις δοκιμές σου:

```shell
$ busted
```

## Windows 10: WSL

Πρώτα πρέπει να ενεργοποιήσεις το [WSL (Windows Subsystem for Linux)][7] χρησιμοποιώντας το [PowerShell][8] (Administrator):

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

Αυτό απαιτεί επανεκκίνηση.

Στη συνέχεια, εγκατέστησε το Ubuntu από το [Microsoft Store][9], **ή** κατέβασέ το και μετά εγκατέστησέ το χρησιμοποιώντας το PowerShell:

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

Στη συνέχεια, ενημέρωσε τη λίστα πακέτων σου:

```shell
PS> wsl
$ sudo apt-get update
```

Τώρα είσαι έτοιμος να εγκαταστήσεις το [LuaRocks][2] και το [Busted][3] ακολουθώντας τις [οδηγίες για το Ubuntu](#ubuntu) παραπάνω.

Μόλις τελειώσεις, μπορείς να τρέξεις τις δοκιμές σου απευθείας από οποιαδήποτε γραμμή εντολών των Windows:

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### Εγκατάσταση του Gitbash

Αυτό το βήμα είναι προαιρετικό. Ίσως χρειαστεί να προσαρμόσεις ελαφρώς τα παρακάτω βήματα, αν προτιμάς να χρησιμοποιήσεις την εγγενή γραμμή εντολών των Windows ή κάποια άλλη.

Κατέβασέ το από [εδώ][10].
Οδηγίες εγκατάστασης [εδώ][11].

### Εγκατάσταση του Docker

Ακολούθησε τις οδηγίες για να εγκαταστήσεις το [Docker for Windows][12].
Μόλις ολοκληρώσεις την εγκατάσταση, μπορείς να τρέξεις την παρακάτω εντολή για να βεβαιωθείς ότι εγκαταστάθηκε σωστά.

```shell
$ docker --version
```

_Μπορεί να συναντήσεις ένα σφάλμα όταν προσπαθήσεις να τρέξεις το Docker για πρώτη φορά._

`cannot enable hyper-v service`

_Αν συμβεί αυτό, μπορείς να ακολουθήσεις αυτές τις οδηγίες για να [ενεργοποιήσεις το Hyper V][13]. Ίσως χρειαστεί να απενεργοποιήσεις τη ρύθμιση, να επανεκκινήσεις τον υπολογιστή σου και να την ενεργοποιήσεις ξανά μετά την εκκίνηση._

### Εγκατάσταση του busted

Μόλις εγκαταστήσεις το Gitbash και το Docker, θα μπορείς να εγκαταστήσεις ένα "container" του busted.

Στο Gitbash, τρέξε τα παρακάτω:

Κατέβασε αυτό το ευρέως χρησιμοποιούμενο Docker container τρέχοντας τα παρακάτω:

```shell
$ docker pull imega/busted
```

Δημιούργησε μια συνάρτηση, ώστε να μη χρειάζεται να πληκτρολογείς ολόκληρη την εντολή κάθε φορά.
Πρόσθεσε το παρακάτω στο `.bashrc` σου:

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

Τώρα, στη γραμμή εντολών σου, μπορείς να μεταβείς στον κατάλογο στον οποίο θέλεις να τρέξεις τις δοκιμές σου. Τρέξε τα παρακάτω:

```shell
$ dbusted $PWD
```

Θα πρέπει να δεις την έξοδο από τις δοκιμές σου με το busted.
