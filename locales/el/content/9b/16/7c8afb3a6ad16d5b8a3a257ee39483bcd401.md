# Σχετικά

Το `TUPLE: child < parent extra-slots ;` δηλώνει μια κλάση της οποίας τα στιγμιότυπα είναι επίσης στιγμιότυπα της κλάσης `parent`. Η αναζήτηση πεδίων διατρέχει την ιεραρχία: ένα `child` έχει κάθε πεδίο που δήλωσε η γονική κλάση, συν τα δικά του, με αυτή τη σειρά.

```factor
TUPLE: vessel name tonnage ;
TUPLE: cargo-vessel < vessel capacity ;
TUPLE: tanker < cargo-vessel fuel-type ;
```

## Η σειρά ορισμάτων του `boa`

Ο αυτόματα παραγόμενος κατασκευαστής `boa` παίρνει τα πεδία με τη σειρά δήλωσης, *πρώτα τα πεδία του γονέα*. Για τον `tanker` παραπάνω:

```
tanker boa ( name tonnage capacity fuel-type -- tanker )
```

Η σειρά των πεδίων καθορίζεται από την αλυσίδα κληρονομικότητας. Δεν υπάρχει τρόπος να παρεμβάλεις εναλλάξ πεδία της γονικής και της θυγατρικής κλάσης, και η αναδιάταξη των πεδίων ενός γονέα είναι ασύμβατη αλλαγή για το `boa` κάθε απογόνου.

## Ιεραρχία κατηγορημάτων

Κάθε δήλωση `TUPLE:` παράγει ένα κατηγόρημα κλάσης (`name?`). Με την κληρονομικότητα, τα κατηγορήματα γίνονται εμφωλευμένα:

```factor
"Esso" 50000 100000 "diesel" tanker boa .

! all three predicates fire
dup tanker?        .   ! => t
dup cargo-vessel?  .   ! => t
dup vessel?        .   ! => t
```

Το `instance?` (από το [`classes`][classes]) θέτει το ίδιο ερώτημα με την κλάση ως όρισμα στη στοίβα αντί να είναι ενσωματωμένη σε ένα όνομα λέξης. Δηλαδή, το `obj tanker instance?` είναι το `obj tanker?`:

```factor
USING: classes ;

"Esso" 50000 100000 "diesel" tanker boa
dup vessel instance? .   ! => t
```

Επειδή η κλάση είναι πλέον μια τιμή, το ίδιο σημείο κλήσης μπορεί να ελέγξει με όποια κλάση του δοθεί, κάτι που ένα σταθερό κατηγόρημα `name?` δεν μπορεί να κάνει.

Η μεταβατική σχέση `is-a` είναι επίσης αυτή που διατρέχει η αποστολή μεθόδων με `M:`. Μια μέθοδος που ορίζεται στο `vessel` εφαρμόζεται σε κάθε `cargo-vessel` και κάθε `tanker`, εκτός αν ενεργοποιηθεί πρώτα μια πιο συγκεκριμένη υπερκάλυψη. Αυτή η πλευρά καλύπτεται στο [`generics`][generics].

## Κληρονομικότητα λέξεων πρόσβασης

Οι λέξεις πρόσβασης (`slot>>`, `>>slot`, `change-slot`) προέρχονται από το [`accessors`][accessors] και δεν είναι δεσμευμένες με την κλάση για την οποία δημιουργήθηκαν: κάθε tuple που *έχει* το πεδίο μπορεί να τις χρησιμοποιήσει.

```factor
USING: accessors ;

"Esso" 50000 100000 "diesel" tanker boa
[ 1 + ] change-tonnage tonnage>> .   ! => 50001
```

Το `change-tonnage` δημιουργήθηκε για το `vessel`, αλλά λειτουργεί σε ένα `tanker`, επειδή κάθε `tanker` είναι `vessel`.

## Τι δεν είναι αυτό

- **Mixins** (`MIXIN:` / `INSTANCE:`): μια κλάση μπορεί να ενταχθεί σε πολλά mixin. Η σχέση είναι πολλά-προς-πολλά και χρησιμοποιείται κυρίως για γενικευμένη αποστολή μεθόδων πάνω σε ένα κοινό πρωτόκολλο. Η έννοια streams τα παρουσιάζει στο πλαίσιο της.
- **Κλάσεις κατηγορημάτων** (`PREDICATE:`): αποσπούν μια υποκλάση από μια υπάρχουσα κλάση μέσω ενός κατηγορήματος χρόνου εκτέλεσης. Πρόκειται για ξεχωριστό χαρακτηριστικό της Factor, δεν καλύπτεται εδώ.
