# Σχετικά

Στην PHP, μπορείς να καλέσεις μια μεταβλητή ως συνάρτηση εφαρμόζοντας παρενθέσεις [`()`] σε αυτήν. Όταν η PHP προσπαθεί να καλέσει τη συνάρτηση, θα αναζητήσει μια συνάρτηση με το ίδιο όνομα με την τιμή της μεταβλητής.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## Κλήση στατικών συναρτήσεων κλάσης

Μπορείς να καλέσεις στατικές συναρτήσεις κλάσης με τον ίδιο τρόπο:

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## Κλήση συναρτήσεων στιγμιοτύπου κλάσης

Μπορείς επίσης να καλέσεις τη συνάρτηση ενός στιγμιοτύπου κλάσης:

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
