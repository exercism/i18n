# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να υλοποιήσεις τη συνάρτηση `wordCount`,
η οποία παίρνει ένα *κείμενο* και επιστρέφει πόσες φορές εμφανίζεται κάθε *λέξη*.

Αν λύνεις αυτή την άσκηση για πρώτη φορά, καλό είναι να μείνεις στην υπογραφή
που δίνεται:

```haskell
wordCount :: String -> [(String, Int)]
```

Αργότερα, ίσως είναι καλή ιδέα να ξαναδείς αυτό το πρόβλημα και να παίξεις με άλλους
τύπους δεδομένων και βιβλιοθήκες:

- `Text`, από το πακέτο *text*.
- `Map`, από το πακέτο *containers*.
- `MultiSet`, από το πακέτο *multiset*

Η σουίτα δοκιμών σχεδιάστηκε σκόπιμα ώστε να δέχεται σχεδόν οποιαδήποτε υπογραφή
τύπου έχει νόημα, οπότε σε ενθαρρύνουμε να βρεις αυτή που θεωρείς καλύτερη.
