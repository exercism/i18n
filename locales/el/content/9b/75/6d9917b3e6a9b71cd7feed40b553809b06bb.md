# Οδηγίες

Κάνε refactoring σε έναν αναλυτή Markdown.

Η άσκηση Markdown είναι άσκηση refactoring.
Υπάρχει κώδικας που αναλύει μια δεδομένη συμβολοσειρά με [σύνταξη Markdown][markdown] και επιστρέφει το αντίστοιχο HTML για αυτή τη συμβολοσειρά.
Αν και αυτός ο κώδικας είναι γραμμένος μπερδεμένα και δύσκολος στην παρακολούθηση, με κάποιο τρόπο δουλεύει και όλα τα τεστ περνάνε!
Η πρόκληση για σένα είναι να ξαναγράψεις αυτόν τον κώδικα ώστε να είναι πιο εύκολος στην ανάγνωση και στη συντήρηση, εξασφαλίζοντας παράλληλα ότι όλα τα τεστ συνεχίζουν να περνάνε.

Θα ήταν χρήσιμο να σημειώσεις σε σχόλια τι έκανες στο refactoring, ώστε να μπορούν να το δουν όσοι θα το ελέγξουν, αλλά δεν είναι απολύτως απαραίτητο.
Το πιο σημαντικό είναι να κάνεις τον κώδικα καλύτερο!

[markdown]: https://guides.github.com/features/mastering-markdown/
