# Οδηγίες

Η τοπική λέσχη ποίησης ξεκινά μια νέα σεζόν. Οι ποιητές γίνονται μέλη της λέσχης και, όποτε δύο από αυτούς γράφουν μαζί ένα ποίημα, γίνονται μέρος του ίδιου *κύκλου συγγραφής*. Η λέσχη θέλει να παρακολουθεί ποιος μοιράζεται κύκλο με ποιον, και σου ζήτησαν να γράψεις τις λέξεις που θα το διαχειρίζονται.

Ένα ξένο σύνολο είναι η ιδανική λύση: κάθε ποιητής είναι ένα μεμονωμένο στοιχείο και ένας κύκλος συγγραφής είναι μια ομάδα.

## 1. Άνοιξε τη λέσχη

Όρισε το `new-club`, το οποίο παίρνει μια ακολουθία ποιητών και επιστρέφει ένα καινούργιο ξένο σύνολο με όλους τους ποιητές καταχωρισμένους. Κάθε ποιητής ξεκινά σε δικό του κύκλο συγγραφής.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Κατέγραψε μια συνεργασία

Όρισε το `collaborate`, το οποίο παίρνει δύο ποιητές και μια λέσχη. Συγχωνεύει τους κύκλους συγγραφής των δύο ποιητών και επιστρέφει τη λέσχη, ώστε οι συνεργασίες να καταγράφονται η μία μετά την άλλη.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Βρες τον κύκλο ενός ποιητή

Όρισε το `circle-of`, το οποίο παίρνει έναν ποιητή και μια λέσχη και επιστρέφει τον αντιπρόσωπο του κύκλου συγγραφής αυτού του ποιητή. Δύο ποιητές που μοιράζονται κύκλο αναφέρουν πάντα τον ίδιο αντιπρόσωπο.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. Μοιράζεσαι κύκλο;

Όρισε το `same-circle?`, το οποίο παίρνει δύο ποιητές και μια λέσχη και επιστρέφει `t` όταν και οι δύο ποιητές ανήκουν στον ίδιο κύκλο συγγραφής και `f` διαφορετικά. Σύγκρινε τους αντιπροσώπους των ποιητών αντί να χρησιμοποιήσεις έναν ενσωματωμένο έλεγχο ισοδυναμίας.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
