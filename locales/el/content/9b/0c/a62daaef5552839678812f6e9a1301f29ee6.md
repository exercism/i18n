# Εισαγωγή

Η Go περιέχει βασικούς αριθμητικούς τύπους που μπορούν να αναπαραστήσουν σύνολα τιμών είτε ακέραιων είτε κινητής υποδιαστολής.

Αυτή η έννοια θα επικεντρωθεί σε δύο τύπους αριθμών:

- `int`: π.χ. `0`, `255`, `2147483647`.
   Ένας προσημασμένος ακέραιος που έχει μέγεθος τουλάχιστον 32 bit (εύρος τιμών: από -2147483648 έως 2147483647).
   Αυτό όμως εξαρτάται από την αρχιτεκτονική του συστήματος.
   Οι περισσότεροι σύγχρονοι υπολογιστές είναι 64 bit, επομένως το `int` θα έχει μέγεθος 64 bit (εύρος τιμών: από -9223372036854775808 έως 9223372036854775807).

- `float64`: π.χ. `0.0`, `3.14`.
   Περιέχει το σύνολο όλων των αριθμών κινητής υποδιαστολής 64 bit.

Η Go υποστηρίζει το τυπικό σύνολο αριθμητικών τελεστών `+`, `-`, `*`, `/` και `%` (υπόλοιπο, όχι modulo).

Στη Go, η ανάθεση μιας τιμής μεταξύ διαφορετικών τύπων απαιτεί ρητή μετατροπή.
Για παράδειγμα, για να μετατρέψεις ένα `int` σε `float64`, θα χρειαστεί να κάνεις το εξής:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
