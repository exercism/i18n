# Προσθήκη στις οδηγίες

## Υλοποίηση

Τα tests απαιτούν έναν constructor που δέχεται έναν πίνακα. Τα εσωτερικά της δικής σου υλοποίησης του custom set μπορούν να χρησιμοποιούν άλλες δομές δεδομένων, αλλά ίσως χρειαστεί να υλοποιήσεις έναν εξωτερικό constructor που δέχεται ακριβώς έναν πίνακα, για να περάσουν τα tests.

Ορισμένες μέθοδοι έχουν ισοδύναμο τελεστή unicode. Για παράδειγμα, το `intersect(CustomSet([1, 2, 3, 4]), CustomSet([]))` είναι ισοδύναμο με το `CustomSet([1, 2, 3, 4]) ∩ CustomSet([])`.
