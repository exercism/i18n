# Εύρη

Τα [εύρη][range] αντιπροσωπεύουν ένα διάστημα μεταξύ δύο τιμών.
Οι πιο συνηθισμένοι τύποι που υποστηρίζουν εύρη είναι οι `Integer` και `String`.
Μπορούν να χρησιμοποιηθούν για πολλά πράγματα, όπως η γρήγορη δημιουργία μιας συλλογής, το κόψιμο συμβολοσειρών, ο έλεγχος αν μια τιμή βρίσκεται μέσα σε ένα εύρος και η επανάληψη.
Δημιουργούνται με τον τελεστή εύρους `..` ή `...` (περιεκτικό και αποκλειστικό αντίστοιχα).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

Ο λόγος που υπάρχουν δύο τελεστές εύρους είναι για να μπορείς να δημιουργείς εύρη που περιλαμβάνουν ή όχι την τελική τιμή, κάτι που είναι χρήσιμο, για παράδειγμα, όταν δουλεύεις με θέσεις που ξεκινούν από το μηδέν.

Τα εύρη μπορούν επίσης να δημιουργηθούν με τον κατασκευαστή `Range`, το `new`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Όταν δημιουργείς ένα εύρος στη Ruby με τους τελεστές εύρους `..` ή `...` και θέλεις να καλέσεις μια μέθοδο πάνω στο εύρος, πρέπει να βάλεις το εύρος μέσα σε παρενθέσεις.
Αυτό συμβαίνει γιατί, αλλιώς, η μέθοδος θα κληθεί στο 2ο όρισμα του τελεστή εύρους.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Λήψη υποσυμβολοσειρών

Όταν θέλεις να κόψεις μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον τελεστή εύρους για να πάρεις μια υποσυμβολοσειρά.
Δηλαδή, δημιουργώντας ένα εύρος με τη θέση αρχής και τέλους της υποσυμβολοσειράς.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

Μπορείς επίσης να χρησιμοποιήσεις αρνητικές θέσεις για να πάρεις την υποσυμβολοσειρά από το τέλος της συμβολοσειράς.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Μέθοδοι εύρους

Τα εύρη έχουν ένα σύνολο μεθόδων που μπορούν να χρησιμοποιηθούν για να δουλέψεις μαζί τους.
Για παράδειγμα, αυτές οι μέθοδοι μπορούν να χρησιμοποιηθούν για να πάρεις το άθροισμα όλων των τιμών στο εύρος ή να ελέγξεις αν το εύρος περιλαμβάνει μια τιμή.

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Επιστρέφει το άθροισμα όλων των τιμών στο εύρος                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Επιστρέφει το μέγεθος του εύρους                                        | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Επιστρέφει `true` αν το εύρος περιλαμβάνει τη δεδομένη τιμή, αλλιώς `false` | `(1..5).include?(3) # => true` |

## Εύρη χωρίς τέλος και χωρίς αρχή

Ένα εύρος μπορεί να είναι χωρίς τέλος και χωρίς αρχή.
Το εύρος χωρίς τέλος ή χωρίς αρχή έχει ως τιμή αρχής ή τέλους το `nil`, αλλά όταν ορίζεις το εύρος μπορείς να παραλείψεις το `nil`.

Η χρήση ευρών χωρίς αρχή και χωρίς τέλος είναι χρήσιμη όταν θέλεις, για παράδειγμα, να κόψεις μια συμβολοσειρά από την αρχή ή μέχρι το τέλος.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
Αν δεν χρησιμοποιηθεί πάνω σε μια συλλογή, το εύρος χωρίς τέλος μπορεί να δημιουργήσει μια ατέρμονη ακολουθία, αν δεν το χρησιμοποιήσεις με προσοχή.
~~~~

## Εύρη συμβολοσειρών

Οι συμβολοσειρές μπορούν επίσης να χρησιμοποιηθούν σε εύρη και σου επιτρέπουν να πάρεις ένα διάστημα συμβολοσειρών ανάμεσα σε δύο συμβολοσειρές.
Η συμπεριφορά μπορεί να είναι λίγο απρόβλεπτη με ορισμένες συμβολοσειρές, οπότε καλό είναι να το χρησιμοποιείς με προσοχή.

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
