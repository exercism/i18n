# Οδηγίες

Στο εργαστήριο έρευνας DNA σου, έχεις δοκιμάσει διάφορους τρόπους συμπίεσης των ερευνητικών δεδομένων σου για να εξοικονομήσεις χώρο αποθήκευσης. Ένας συνεργάτης σου προτείνει να μετατρέψεις τα δεδομένα DNA σε δυαδική αναπαράσταση:

| Νουκλεϊκό οξύ | Κωδικός |
| ------------ | ------- |
| ένα κενό     | `0000`  |
| A            | `0001`  |
| C            | `0010`  |
| G            | `0100`  |
| T            | `1000`  |

Το σκέφτεσαι, καθώς ενδέχεται να μειώσει στο μισό το απαιτούμενο κόστος αποθήκευσης δεδομένων, αλλά εις βάρος της αναγνωσιμότητας από τον άνθρωπο. Αποφασίζεις να γράψεις ένα module για κωδικοποίηση και αποκωδικοποίηση των δεδομένων σου, ώστε να αξιολογήσεις την εξοικονόμηση.

## 1. Κωδικοποίησε νουκλεϊκό οξύ σε δυαδική τιμή

Υλοποίησε τη συνάρτηση `encode_nucleotide/1` ώστε να δέχεται το σημείο κώδικα για το νουκλεϊκό οξύ και να επιστρέφει την ακέραια τιμή του κωδικοποιημένου κωδικού.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Αποκωδικοποίησε τη δυαδική τιμή σε νουκλεϊκό οξύ

Υλοποίησε τη συνάρτηση `decode_nucleotide/1` ώστε να δέχεται την ακέραια τιμή του κωδικοποιημένου κωδικού και να επιστρέφει το σημείο κώδικα για το νουκλεϊκό οξύ.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Κωδικοποίησε μια λίστα χαρακτήρων DNA

Υλοποίησε τη συνάρτηση `encode/1` ώστε να δέχεται μια λίστα χαρακτήρων που αντιπροσωπεύει νουκλεϊκά οξέα και κενά και να επιστρέφει ένα bitstring με τα κωδικοποιημένα δεδομένα.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Αποκωδικοποίησε ένα bitstring DNA

Υλοποίησε τη συνάρτηση `decode/1` ώστε να δέχεται ένα bitstring που αντιπροσωπεύει νουκλεϊκά οξέα και κενά και να επιστρέφει τα αποκωδικοποιημένα δεδομένα ως λίστα χαρακτήρων.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
