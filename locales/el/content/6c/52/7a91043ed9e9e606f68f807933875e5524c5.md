# Εισαγωγή

## Απαριθμήσεις

Ο τύπος `enum` στη C# αντιπροσωπεύει ένα σταθερό σύνολο από ονομασμένες σταθερές (μια απαρίθμηση). Ο κύριος σκοπός του είναι να παρέχει έναν τρόπο ασφαλή ως προς τον τύπο για να αλληλεπιδράς με αριθμητικές σταθερές, περιορίζοντας τις διαθέσιμες τιμές σε ένα προκαθορισμένο σύνολο. Μπορούμε να ορίσουμε ένα απλό enum ως εξής:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Αν δεν οριστούν ρητά, τα μέλη του enum θα λάβουν αυτόματα αυξανόμενες ακέραιες τιμές, με την πρώτη τιμή να είναι μηδέν. Μπορούμε επίσης να ορίσουμε τιμές ρητά:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
