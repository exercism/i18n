# περιττό return

Οι βέλτιστες πρακτικές της Scala υποδεικνύουν ότι η λέξη-κλειδί `return` πρέπει να αποφεύγεται. Στη Scala, το αποτέλεσμα της τελευταίας έκφρασης σε μια συνάρτηση επιστρέφεται αυτόματα. Η ρητή χρήση του `return` στο τέλος μιας συνάρτησης μπορεί να έχει ανεπιθύμητες παρενέργειες. [Πες "όχι" στο `return`](https://blog.knoldus.com/scala-best-practices-say-no-to-return/).
