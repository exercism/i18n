# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να εκτυπώνεις κονκάρδες ονόματος για υπαλλήλους εργοστασίου.

## 1. Εκτύπωσε μια κονκάρδα για έναν υπάλληλο

Οι υπάλληλοι έχουν ένα αναγνωριστικό, ένα όνομα και ένα όνομα τμήματος. Οι ετικέτες των κονκαρδών των υπαλλήλων έχουν την εξής μορφή: `"[id] - name - DEPARTMENT"`. Υλοποίησε τη (_static_) μέθοδο `Badge.Print()` ώστε να επιστρέφει την ετικέτα της κονκάρδας ενός υπαλλήλου:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Σημείωσε ότι το τμήμα πρέπει να γράφεται με κεφαλαία γράμματα στην ετικέτα.

## 2. Εκτύπωσε μια κονκάρδα για έναν νέο υπάλληλο

Λόγω μιας ιδιομορφίας του υπολογιστικού συστήματος, οι νέοι υπάλληλοι μερικές φορές δεν έχουν ακόμη αναγνωριστικό όταν ξεκινούν να εργάζονται στο εργοστάσιο. Καθώς οι κονκάρδες είναι υποχρεωτικές, θα λαμβάνουν μια προσωρινή κονκάρδα χωρίς το πρόθεμα του αναγνωριστικού. Τροποποίησε τη (_static_) μέθοδο `Badge.Print()` ώστε να υποστηρίζει νέους υπαλλήλους που δεν έχουν ακόμη αναγνωριστικό:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Εκτύπωσε μια κονκάρδα για τον ιδιοκτήτη

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει κονκάρδα ανά πάσα στιγμή. Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα. Σε αυτή την περίπτωση, η ετικέτα πρέπει να εμφανίζει `"OWNER"` αντί για το όνομα του τμήματος. Τροποποίησε τη (_static_) μέθοδο `Badge.Print()` ώστε να εμφανίζει μια ετικέτα για τον ιδιοκτήτη:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Σημείωσε ότι είναι πιθανό ο ιδιοκτήτης να είναι και νέος υπάλληλος:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
