# Εισαγωγή

## Struct και κλάσεις

Τα struct και οι κλάσεις είναι δύο από τα βασικά δομικά στοιχεία του προγραμματισμού σε Swift. Και τα δύο είναι τρόποι ομαδοποίησης σχετικών δεδομένων και συναρτήσεων σε αυτοτελείς μονάδες λειτουργικότητας. Και όταν ορίζεις ένα struct ή μια κλάση, ορίζεις έναν νέο τύπο που θα χρησιμοποιηθεί στο Swift, όπως ακριβώς χρησιμοποίησες τους τύπους με τους οποίους έχεις ήδη δουλέψει, όπως `Int` και `String`.

Υπάρχουν πολλές ομοιότητες μεταξύ struct και κλάσεων στη Swift. Μεταξύ άλλων ομοιοτήτων, και τα δύο μπορούν να αποθηκεύουν τιμές σε _ιδιότητες_ και να παρέχουν λειτουργικότητα μέσω της χρήσης _μεθόδων_.

Το καθένα παρέχει κάποιες επιπλέον λειτουργίες, οι οποίες είναι εκτός του πεδίου αυτής της άσκησης.

### Ορισμός struct και κλάσεων

Τόσο τα struct όσο και οι κλάσεις ορίζονται με περίπου τον ίδιο τρόπο. Ξεκινούν με την κατάλληλη λέξη-κλειδί ακολουθούμενη από το όνομα του τύπου που ορίζεται, και στη συνέχεια ακολουθεί το σώμα του struct/της κλάσης, τοποθετημένο μέσα σε άγκιστρα.

Το σώμα μπορεί να αποτελείται από αποθηκευμένες ιδιότητες, οι οποίες ορίζονται και συμπεριφέρονται ακριβώς όπως οι συνηθισμένες σταθερές ή μεταβλητές.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### Στιγμιότυπα

Όπως σημειώθηκε παραπάνω, ο ορισμός ενός struct ή μιας κλάσης είναι απλώς ο ορισμός ενός νέου _τύπου_. Είναι απλώς το σχέδιο για το πώς θα μοιάζουν οι τιμές αυτού του τύπου, αλλά δεν δημιουργεί στην πραγματικότητα καμία τιμή αυτού του τύπου για να δουλέψεις.

Για να δημιουργήσεις ένα _στιγμιότυπο_ αυτού του τύπου, πρέπει να γράψεις το όνομα του τύπου ακολουθούμενο από ένα ζεύγος παρενθέσεων.

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

Αυτό θα δημιουργήσει τιμές αυτών των τύπων, όπου οι ιδιότητες συμπληρώνονται με τις προεπιλεγμένες τιμές που παρέχονται στον ορισμό. Σημείωσε ότι σε προαιρετικές περιπτώσεις όπως η ιδιότητα `name` του GameCharacter, εκτός αν παρέχεται μια τιμή, η ιδιότητα θα έχει προεπιλεγμένη τιμή nil, όπως ακριβώς συμβαίνει με τον ορισμό κανονικών προαιρετικών τύπων όπου δεν παρέχεται άμεσα μια τιμή.

Με τα struct, η Swift παρέχει αυτόματα κάτι που ονομάζεται _αρχικοποιητής κατά μέλη_, όπου οι τιμές για τις ιδιότητες του struct μπορούν να παρέχονται μέσα στις παρενθέσεις, οι οποίες θα υπερισχύσουν των προεπιλεγμένων τιμών στον ορισμό.

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### Πρόσβαση σε ιδιότητες

Οι ιδιότητες struct και κλάσεων μπορούν να προσπελαστούν χρησιμοποιώντας _συμβολισμό με τελεία_, όπου το όνομα της τιμής ακολουθείται από μια τελεία (`.`) και το όνομα της ιδιότητας. Εάν μια ιδιότητα ενός struct ή μιας κλάσης έχει τις δικές της ιδιότητες, αυτός ο συμβολισμός με τελεία μπορεί να χρησιμοποιηθεί για την πρόσβαση και σε αυτές τις εμφωλευμένες ιδιότητες.

Αυτός ο συμβολισμός μπορεί να χρησιμοποιηθεί τόσο για την ανάκτηση της τιμής της ιδιότητας όσο και, όπου επιτρέπεται, για την αλλαγή της.

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### Μέθοδοι

Όπως οι ιδιότητες, που αποθηκεύουν δεδομένα στα struct και στις κλάσεις σου, μπορείς επίσης να ορίσεις _μεθόδους_ που αποθηκεύουν συναρτήσεις στο struct ή στην κλάση σου.

Οι μέθοδοι ορίζονται με τον ίδιο τρόπο όπως μια κανονική συνάρτηση, μόνο που βρίσκονται μέσα στο σώμα του struct ή της κλάσης. Σημείωσε ότι εάν μια συνάρτηση αλλάζει την τιμή μιας ιδιότητας σε ένα struct, πρέπει να προηγείται η λέξη-κλειδί `mutating`. Επιπλέον, εάν μια ιδιότητα μπορεί να αλλάξει από μια μέθοδο, αυτή η ιδιότητα πρέπει να οριστεί χρησιμοποιώντας `var` αντί για `let`, όπως ακριβώς οι κανονικές μεταβλητές.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

Αυτές οι μέθοδοι μπορούν να κληθούν χρησιμοποιώντας συμβολισμό με τελεία, όπως ακριβώς οι ιδιότητες.

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

Κάθε στιγμιότυπο ενός struct ή μιας κλάσης έχει μια σιωπηρή ιδιότητα με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο.
Η πιο συνηθισμένη χρήση του `self` είναι να αποσαφηνίσει τη διάκριση ανάμεσα σε μια ιδιότητα στιγμιότυπου και σε μια παράμετρο που έχει το ίδιο όνομα:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Οι τύποι της Swift παρέχουν επίσης μια λέξη-κλειδί `Self` με κεφαλαίο αρχικό γράμμα, η οποία αναφέρεται στον *τύπο* του στιγμιότυπου και όχι στο ίδιο το στιγμιότυπο.
