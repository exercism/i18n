# Υποδείξεις

## 1. Υπολόγισε το επιτόκιο

- Μπορείς να ανατρέξεις στην έννοια [συνθήκες][conditionals] αν χρειάζεται να θυμηθείς πώς να επιστρέφεις τιμές με βάση μια τιμή εισόδου.

## 2. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Η συνάρτηση [`bigdec`][bigdec] μπορεί να χρησιμοποιηθεί για να μετατρέψει έναν αριθμό σε [BigDecimal][bigdecimal].

## 3. Υπολόγισε πόσα χρήματα θα δωρίσεις

- Η συνάρτηση [`int`][int] μπορεί να χρησιμοποιηθεί για να μετατρέψει έναν αριθμό σε ακέραιο αριθμό.

[bigdec]: https://clojuredocs.org/clojure.core/bigdec
[bigdecimal]: https://docs.oracle.com/javase/8/docs/api/java/math/BigDecimal.html
[conditionals]: https://exercism.org/tracks/clojure/concepts/conditionals
[int]: https://clojuredocs.org/clojure.core/int
