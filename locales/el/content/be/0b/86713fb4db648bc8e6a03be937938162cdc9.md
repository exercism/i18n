# Εισαγωγή

Στη Go, το `for range` επαναλαμβάνει ένα μπλοκ κώδικα για τις τιμές που προέρχονται από μια έκφραση range.
Η έκφραση range καθορίζει αν κάθε επανάληψη θα δίνει μία ή δύο τιμές.

## Εκφράσεις range

### Επανάληψη σε ένα slice

Το `range` πάνω σε ένα slice δίνει τη θέση και την τιμή κάθε στοιχείου, με τη σειρά:

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### Επανάληψη σε ένα map

Το `range` πάνω σε ένα map δίνει κάθε κλειδί και τιμή, αλλά η σειρά της επανάληψης δεν είναι εγγυημένη.
Η Go τυχαιοποιεί σκόπιμα τη σειρά επανάληψης των map, οπότε το ίδιο πρόγραμμα μπορεί να παράγει διαφορετική έξοδο σε κάθε εκτέλεση.

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### Επανάληψη σε ένα string

Το `range` πάνω σε ένα string δίνει τη θέση του byte και κάθε rune (σημείο κώδικα Unicode).
Στο παρακάτω παράδειγμα, το `子` καταλαμβάνει τρία byte, οπότε το `猫` ξεκινά στη θέση byte `3`, όχι `1`.

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

Αν χρειάζεσαι θέσεις rune αντί γι' αυτό, μετέτρεψε το string σε ένα slice από rune:

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### Επανάληψη σε έναν ακέραιο

Το `range` μπορεί να διατρέξει απευθείας έναν ακέραιο, δίνοντας τιμές από το `0` ώς τον ακέραιο, χωρίς να συμπεριλαμβάνεται ο ίδιος.
Το μηδέν και οι αρνητικές τιμές είναι έγκυρες, αλλά δεν παράγουν καμία επανάληψη.

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### Επανάληψη σε έναν iterator

Το `range` δέχεται έναν iterator τύπου `iter.Seq[V]` ή `iter.Seq2[K, V]`.
Ένας iterator είναι μια συνάρτηση που παράγει μια ακολουθία τιμών, μία κάθε φορά.
Το `range` μπορεί έπειτα να διατρέξει αυτές τις τιμές.

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### Επανάληψη σε ένα channel

Τέλος, το `range` μπορεί να λαμβάνει τιμές που στέλνονται μέσω ενός channel μέχρι αυτό το channel να κλείσει κάπου αλλού.
Τα channel καλύπτονται με περισσότερες λεπτομέρειες αργότερα στο syllabus του track.

## Παράλειψη της θέσης ή της τιμής

Η Go δεν θα μεταγλωττίσει αν μια μεταβλητή δηλωθεί αλλά δεν χρησιμοποιηθεί ποτέ.

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

Αν χρειάζεσαι μόνο την τιμή, ανάθεσε τη θέση ή το κλειδί στο `_`, ώστε να τα αγνοήσεις.

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

Αν χρειάζεσαι μόνο τη θέση, παράλειψέ την εντελώς:

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

Αν δεν χρειάζεσαι ούτε τη θέση ούτε την τιμή, μπορείς να παραλείψεις και τα δύο:

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
