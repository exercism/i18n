# Υποδείξεις

## Γενικά

- Ρίξε μια ματιά στην αναφορά [Αυτόματη μετατροπή τύπων][ref-type-juggling]
- Ρίξε μια ματιά στην αναφορά μετατροπής τύπων για [ακέραιους][ref-type-cast-int] και [συμβολοσειρές][ref-type-cast-string]
- Ρίξε μια ματιά στην αναφορά για τις [αριθμητικές συμβολοσειρές][ref-numeric-strings]

## 1. Υπολόγισε το άθροισμα των αριθμών στον κουλοχέρη

- Μπορείς να χρησιμοποιήσεις την [`implode`][ref-implode] για να συνδυάσεις τα ψηφία.
  Η `implode` θα μετατρέψει έμμεσα τα ψηφία του πίνακα σε συμβολοσειρές και θα επιστρέψει μια συμβολοσειρά.
- Για να αθροίσεις τους αριθμούς, δες την έννοια των [αριθμητικών πράξεων][ref-arithmetic-ops].
  Οι αριθμητικοί τελεστές θα μετατρέψουν έμμεσα τις συμβολοσειρές σε ακέραιους ή δεκαδικούς.

## 2. Προσδιόρισε αν ένας αριθμός είναι παλίνδρομος

- Αυτή η εργασία μπορεί να λυθεί συγκρίνοντας τον αριθμό που σου δίνεται με την ανεστραμμένη εκδοχή του.
  Για να το κάνεις αυτό, πρέπει πρώτα να αντιστρέψεις τον αριθμό που σου δίνεται.
  Στη συνέχεια, επέστρεψε το αποτέλεσμα της σύγκρισης των δύο εκδοχών.
- Μπορείς να χρησιμοποιήσεις τη [`strrev`][ref-strrev] για να πάρεις τον ανεστραμμένο αριθμό.
  Η `strrev` θα μετατρέψει έμμεσα τον αριθμό σε συμβολοσειρά και θα επιστρέψει μια συμβολοσειρά.
- Τέλος, μπορείς να [συγκρίνεις][ref-comparison-ops] τον αριθμό που σου δίνεται με την ανεστραμμένη συμβολοσειρά.
  Όταν γράφεις τη συνθήκη για αυτό, αξιοποίησε τη [σύγκριση][ref-comparison-ops] που κάνει μετατροπή τύπων.
  Η PHP θα μετατρέψει την ανεστραμμένη συμβολοσειρά σε αριθμό για αυτή τη σύγκριση.
- Το αποτέλεσμα της σύγκρισης είναι `bool`, που είναι ο τύπος που πρέπει να επιστρέψεις.

## 3. Δημιούργησε ένα μήνυμα σφάλματος για μη έγκυρη είσοδο χρήστη

- Μπορείς να χρησιμοποιήσεις [εντολές `if`][ref-if-statement] για να ελέγξεις τις διάφορες συνθήκες.
- Πρώτα, κάλυψε την περίπτωση όπου η τιμή δεν περιέχει κανέναν χαρακτήρα.
- Στη συνέχεια, αντιμετώπισε την περίπτωση όπου η είσοδος δεν είναι αριθμός ή `0`.
  Οι κανόνες μετατροπής τύπων των [τελεστών σύγκρισης][ref-comparison-ops] είναι εναντίον σου σε αυτή την περίπτωση.
  Κάνουν την PHP να συγκρίνει συμβολοσειρές σε ορισμένες περιπτώσεις και αυτό δίνει λανθασμένα αποτελέσματα.
  Χρησιμοποίησε τη ρητή μετατροπή σε `int` που έμαθες στην εισαγωγή.
  Έτσι, μπορείς να βασιστείς στους [τελεστές σύγκρισης][ref-comparison-ops] για έναν αριθμό μεγαλύτερο από `0`.
