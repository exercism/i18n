# Σχετικά

Μια `List` είναι πολύ παρόμοια με έναν [`Array`][array]. Ωστόσο, υπάρχουν σημαντικές διαφορές που δεν θέλεις να προσπεράσεις:

1. Δεν μπορείς να αναφερθείς σε μια θέση μιας λίστας με τετράγωνες αγκύλες, δηλ. `[0]`.
2. Μια λίστα δεν μπορεί να αρχικοποιηθεί.
3. Δεν υπάρχουν list comprehensions.
4. Μια λίστα μπορεί να τροποποιεί ελεύθερα τα στοιχεία της ενώ τη διατρέχεις με μια επανάληψη.

Η `List` είναι μέλος του πακέτου `haxe.ds`, οπότε κάθε φορά που θέλεις να χρησιμοποιήσεις λίστες, πρέπει να κάνεις import το πακέτο της:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
