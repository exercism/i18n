# Βοήθεια

## Ξεκινώντας

Δες τις σελίδες βοήθειας για την [εγκατάσταση](https://exercism.io/tracks/haskell/installation) και τη [μάθηση](https://exercism.io/tracks/haskell/learning).

## Σχόλια, Ζητήματα, Pull Requests

Το αποθετήριο [exercism/haskell](https://github.com/exercism/haskell) στο GitHub είναι το σπίτι για όλες τις ασκήσεις της Haskell.

Αν έχεις σχόλια για μια άσκηση ή θέλεις να βοηθήσεις στην υλοποίηση μιας νέας, πήγαινε εκεί και άνοιξε ένα ζήτημα. Θα κάνουμε ό,τι μπορούμε για να σε βοηθήσουμε!
