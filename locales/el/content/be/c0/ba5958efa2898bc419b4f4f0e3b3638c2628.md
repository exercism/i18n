# Σχετικά

Μια *κανονική έκφραση* (regex) είναι ένα μικρό μοτίβο που περιγράφει τη μορφή ενός κειμένου. Τα εργαλεία regex της Factor βρίσκονται στο λεξιλόγιο [`regexp`][regexp] και ένα μοτίβο γράφεται ως literal ανάμεσα στο `R/ ` και το `/`.

Οι περισσότεροι χαρακτήρες σε ένα μοτίβο ταιριάζουν με τον εαυτό τους. Η εκφραστική δύναμη προέρχεται από τις κλάσεις χαρακτήρων και τους ποσοδείκτες:

```
\d        ! a digit 0–9            \s   ! whitespace
\D        ! any non-digit          \S   ! non-whitespace
[A-Z]     ! one capital letter     .    ! any one character
[^0-9]    ! any char except a digit

{4}       ! exactly 4              +    ! one or more
{2,5}     ! between 2 and 5        *    ! zero or more
?         ! optional               |    ! either side (alternation)
```

Έτσι, το `R/ [A-Z]{2}-\d{4}/` ταιριάζει με "δύο κεφαλαία, μια παύλα, τέσσερα ψηφία".

## Αντιστοίχιση ολόκληρης της συμβολοσειράς εναντίον αναζήτησης

Το `matches?` πετυχαίνει μόνο όταν ολόκληρη η συμβολοσειρά ταιριάζει με το μοτίβο. Οι άλλες λέξεις αναζητούν *μέσα* σε μια συμβολοσειρά:

```
matches?             ( string regexp -- ? )
re-contains?         ( string regexp -- ? )
count-matches        ( string regexp -- n )
all-matching-subseqs ( string regexp -- seq )
first-match          ( string regexp -- slice/f )
re-split             ( string regexp -- seq )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .         ! => t
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ matches? .   ! => f   (extra text)
"id NS-1024 ok" R/ [A-Z]{2}-\d{4}/ re-contains? .   ! => t

"a1b2c3" R/ \d/ count-matches .   ! => 3
"a1b2c3" R/ \d/ re-replace .      ! NOTE: see re-replace below
```

## Φέτες

Τα `first-match` και `re-split` επιστρέφουν αντικείμενα `slice`, δηλαδή ελαφριές όψεις μέσα στην αρχική συμβολοσειρά αντί για νέες συμβολοσειρές. Μετέτρεψε μια φέτα σε συμβολοσειρά με το `>string` όταν χρειάζεσαι μια αυτόνομη συμβολοσειρά (για παράδειγμα, για να τη συγκρίνεις με ένα string literal). Το `all-matching-subseqs` επιστρέφει ήδη συμβολοσειρές.

## Αντικατάσταση

Το `re-replace` αντικαθιστά κάθε ταίριασμα με μια συμβολοσειρά αντικατάστασης και επιστρέφει το αποτέλεσμα:

```factor
USING: regexp ;

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

## Δημιουργία μοτίβου σε χρόνο εκτέλεσης

Το `R/ /` αναλύεται όταν φορτώνει το αρχείο. Για να φτιάξεις ένα μοτίβο από μια συμβολοσειρά που υπολογίζεται σε χρόνο εκτέλεσης, χρησιμοποίησε το `<regexp>`:

```
<regexp> ( string -- regexp )
```
