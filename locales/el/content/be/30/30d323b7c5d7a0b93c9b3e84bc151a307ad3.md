# Σχετικά

Διαθέσιμες από την έκδοση `PHP 8.0.0`, οι **Δηλώσεις Τύπων Ένωσης** δέχονται τιμές πολλαπλών διαφορετικών τύπων, αντί για έναν μόνο τύπο. Οι ορισμοί τύπων ένωσης γίνονται με τη χρήση της κάθετης γραμμής (`|`) για τον διαχωρισμό των τύπων.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Λεπτομέρειες

- Οι τύποι `null` μπορούν να δηλωθούν ως _nullable_ χρησιμοποιώντας είτε `?Type` είτε `Type1|Type2|null`.
- Οι διπλότυποι ή περιττοί τύποι που δηλώνονται οδηγούν σε σφάλμα κατά τη μεταγλώττιση.
- Το `void` δε μπορεί να χρησιμοποιηθεί ως μέρος μιας δήλωσης τύπου ένωσης.
