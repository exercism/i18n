# Εισαγωγή

Αντί να χρησιμοποιείς απευθείας μια θέση μέσα σε μια συμβολοσειρά, πρέπει αντ' αυτού να υπολογίσεις μια τιμή τύπου `String.Index` και να δώσεις αυτή τη θέση. Σημείωσε ότι αυτές οι θέσεις δεν προορίζονται να είναι κατανοητές από ανθρώπους από μόνες τους. Αυτές είναι αυτό που αποκαλείται _αδιαφανείς θέσεις_, καθώς οι άνθρωποι δεν έχουν ανάγκη να ξέρουν τι περιέχουν.

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// => "g"
print(index)
// => Index(_rawBits: 1376513)
```
