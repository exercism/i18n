# Προσθήκη οδηγιών

## Οδηγίες ειδικά για το track

Η Phix δεν έχει πραγματικά δείκτες, γιατί δεν τους χρειάζεται.
Ο τύπος ακολουθίας θα πρέπει να είναι πάντα η πρώτη σου σκέψη όταν σκέφτεσαι πώς θα αποθηκεύσεις δεδομένα (περνώντας σε λεξικά στη μνήμη και σε βάσεις δεδομένων στον δίσκο, ανάλογα με τις ανάγκες), και στην πραγματικότητα είναι πολύ πιθανό να ξεπερνούν τις πιο παραδοσιακά διδαγμένες συνδεδεμένες λίστες σε ίσως το 99% όλων των περιπτώσεων.
Μπορούν να συρρικνώνονται και να μεγαλώνουν κατά βούληση, χωρίς χειροκίνητη συντήρηση, κάτι που όχι μόνο εξαλείφει αμέσως τον βασικό λόγο για τον οποίο κάποιος χρησιμοποιεί ακόμη συνδεδεμένες λίστες, αλλά μπορεί να εξαλείψει ακόμη και τη συντήρηση που χρειάζονται συνήθως οι ίδιες οι συνδεδεμένες λίστες.

Αυτή η απλή άσκηση έχει δύο στόχους: να σου γνωρίσει τις ακολουθίες και μερικές απλές πράξεις πάνω τους, και να σβήσει κάθε επιθυμία για μπελαλίδικες δομές βασισμένες σε δείκτες, που απλώς δεν έχουν θέση στη Phix.
