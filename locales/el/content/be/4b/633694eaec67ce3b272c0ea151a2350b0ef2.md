# Προσθήκη στις οδηγίες

## Υποδείξεις

- Για να αναλύσεις το κείμενο, θα μπορούσες να δοκιμάσεις τη βιβλιοθήκη [FParsec](http://www.quanttec.com/fparsec/tutorial.html).
- Μπορείς να λύσεις αυτή την άσκηση με έναν αλγόριθμο brute force, αλλά αυτό πιθανώς θα έχει κακή απόδοση κατά την εκτέλεση. Προσπάθησε να βρεις μια πιο εκλεπτυσμένη λύση. Υπόδειξη: Θα μπορούσες να δοκιμάσεις τον αλγόριθμο πρόσθεσης κατά στήλες που συνήθως διδάσκεται στο σχολείο.
