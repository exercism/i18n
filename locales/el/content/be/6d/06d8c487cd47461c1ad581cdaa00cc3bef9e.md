# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Τελεστής Ανάλυσης Εμβέλειας

Ο τελεστής ανάλυσης εμβέλειας (`::`) μάς επιτρέπει να αναφερόμαστε σε μια κλάση, ώστε να έχουμε πρόσβαση στις σταθερές, στις στατικές ιδιότητες ή στις στατικές μεθόδους της.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Χρήση των `self` και `static` με τον τελεστή ανάλυσης εμβέλειας

Μπορεί ένα αντικείμενο να χρειαστεί να αναφερθεί στη δική του εμβέλεια. Για να γίνει αυτό, η λέξη-κλειδί `self` επιτρέπει σε μια κλάση να αναφερθεί στη δική της εμβέλεια. Η χρήση της λέξης-κλειδιού `self` αποσυνδέει την κλάση από το όνομά της, κάνοντας πιο εύκολη τη συντήρηση του κώδικα με τον χρόνο.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Ωστόσο, το `self` δεσμεύεται λεξικά στην κλάση στην οποία εμφανίζεται.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Ο υπολογισμός του `MyOtherClass::getMyValue` έχει πάλι ως αποτέλεσμα `1` και όχι `99`. Για να το παρακάμψεις αυτό, χρησιμοποίησε τη λέξη-κλειδί `static` με τον τελεστή ανάλυσης εμβέλειας, ώστε να γίνει "late bind" της αναφοράς στην τρέχουσα κλάση-απόγονο.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Χρήση του `parent` με τον τελεστή ανάλυσης εμβέλειας

Μπορεί να χρειαστεί να αναφερθείς συγκεκριμένα σε μια σταθερά, μια ιδιότητα ή μια μέθοδο που είναι διαθέσιμη από τη γονική εμβέλεια:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Στον αντικειμενοστρεφή προγραμματισμό, το `parent` χρησιμοποιείται συνήθως για να καλέσει τον κατασκευαστή της γονικής κλάσης όταν δημιουργείται ένα αντικείμενο:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Επιφυλάξεις

### Ορατότητα σταθερών, ιδιοτήτων και μεθόδων

Ο τελεστής ανάλυσης εμβέλειας εξακολουθεί να ακολουθεί τους κανόνες που θέτουν οι τροποποιητές ορατότητας `public`, `private` και `protected`.
