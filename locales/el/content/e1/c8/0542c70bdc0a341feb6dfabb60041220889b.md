# Υποδείξεις

## Γενικά

- Διάβασε για την αναδρομή στον επίσημο [οδηγό Ξεκινώντας][getting-started-recursion].
- Διάβασε για την αναδρομή στο [elixirschool.com][elixir-school-recursion].
- Χρησιμοποίησε συναρτήσεις με πολλαπλές ρήτρες και αντιστοίχιση προτύπων.
- Προσπάθησε να χωρίσεις ένα πρόβλημα σε μια βασική περίπτωση και μια αναδρομική περίπτωση. Για παράδειγμα, ας πούμε ότι θέλεις να μετρήσεις πόσα μπισκότα υπάρχουν στο βάζο με τα μπισκότα με μια αναδρομική προσέγγιση. Η βασική περίπτωση είναι ένα άδειο βάζο: έχει μηδέν μπισκότα. Αν το βάζο δεν είναι άδειο, τότε ο αριθμός των μπισκότων στο βάζο ισούται με ένα μπισκότο συν τον αριθμό των μπισκότων στο βάζο αφού αφαιρέσεις ένα μπισκότο.

## 1. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

- Αυτή η εργασία δεν χρειάζεται αναδρομή.
- Η πρόσβαση στο πρώτο στοιχείο μιας λίστας μπορεί να γίνει με [αντιστοίχιση προτύπων][getting-started-pattern-matching].

## 2. Αύξησε τον σημερινό αριθμό

- Αυτή η εργασία δεν χρειάζεται αναδρομή.
- Η πρόσβαση στο πρώτο στοιχείο μιας λίστας μπορεί να γίνει με [αντιστοίχιση προτύπων][getting-started-pattern-matching].

## 3. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

- Χρησιμοποίησε αναδρομή για να διατρέξεις τα στοιχεία της λίστας μέχρι να βρεθεί μια μέρα χωρίς επισκέψεις πουλιών.
- Η βασική περίπτωση είναι μια κενή λίστα.

## 4. Υπολόγισε τον συνολικό αριθμό των πουλιών που επισκέφτηκαν

- Χρησιμοποίησε αναδρομή για να διατρέξεις κάθε στοιχείο της λίστας.
- Η βασική περίπτωση είναι μια κενή λίστα.

## 5. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

- Χρησιμοποίησε αναδρομή για να διατρέξεις κάθε στοιχείο της λίστας.
- Η βασική περίπτωση είναι μια κενή λίστα.
- Μια συνάρτηση μπορεί να έχει περισσότερες από μία αναδρομικές περιπτώσεις.
- Χρησιμοποίησε έναν [φρουρό][kernel-equal-or-greater-than] για μία από τις ρήτρες της συνάρτησης.
