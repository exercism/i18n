# Εισαγωγή

Ένας σημαντικός τρόπος για την οργάνωση του κώδικα είναι οι χώροι ονομάτων.
Δύο συναρτήσεις μπορεί να έχουν σύγκρουση ονομάτων, η οποία μπορεί να λυθεί βάζοντάς τες σε διαφορετικούς χώρους ονομάτων.
Οι χώροι ονομάτων μπορούν να είναι εμφωλευμένοι, κάτι που μπορεί να βοηθήσει στη δομή μεγάλων βάσεων κώδικα.
Η πρόσβαση στους χώρους ονομάτων γίνεται μέσω του τελεστή ανάλυσης εμβέλειας `::`.

Το παρακάτω παράδειγμα δείχνει τη χρήση δύο διαφορετικών συναρτήσεων `foo`.
Χρησιμοποιούνται μαζί προτάσσοντας τους αντίστοιχους χώρους ονομάτων τους.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
