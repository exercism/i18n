# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις μια εταιρεία επιγραφών να δημιουργεί προσαρμοσμένα μηνύματα για τις πινακίδες της.

## 1. Φτιάξε μια πινακίδα περίστασης

Υλοποίησε τη μέθοδο `build_sign( )` που δέχεται μια συμβολοσειρά ως παράμετρο `occasion` και μια συμβολοσειρά με το όνομα κάποιου ως παράμετρο `name`. Οι δύο παράμετροι θα ενσωματωθούν σε ένα πρότυπο συμβολοσειράς, ώστε να παραχθεί το μήνυμα της πινακίδας.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Φτιάξε μια πινακίδα γενεθλίων

Υλοποίησε τη μέθοδο `build_birthday_sign( )` που δέχεται μια ηλικία και, ανάλογα με την ηλικία, καθορίζει μέρος του μηνύματος της πινακίδας. Αν η ηλικία είναι 50 ή μεγαλύτερη, η πινακίδα θα περιλαμβάνει τη λέξη _mature_, διαφορετικά θα περιλαμβάνει τη λέξη _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Φτιάξε μια πινακίδα αποφοίτησης

Υλοποίησε τη μέθοδο `graduation_for( )` που δέχεται ένα όνομα ως παράμετρο συμβολοσειράς και ένα έτος ως αριθμητική παράμετρο, και χρησιμοποιεί πρότυπα συμβολοσειράς για να δημιουργήσει μια φράση για μια πινακίδα, όπου ένας χαρακτήρας νέας γραμμής χωρίζει τις δύο γραμμές του μηνύματος.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Υπολόγισε το κόστος μιας πινακίδας

Υλοποίησε τη συνάρτηση `cost_of( sign currency )` που δέχεται μια συμβολοσειρά με τα περιεχόμενα της πινακίδας και μια συμβολοσειρά που αντιπροσωπεύει το νόμισμα.
Η πινακίδα έχει βασική τιμή 20 στο δοσμένο νόμισμα. Επιπλέον, κάθε γράμμα κοστίζει 2. (Τα κενά περιλαμβάνονται στον υπολογισμό.)
Η φράση που επιστρέφεται περιλαμβάνει το κόστος δημιουργίας της πινακίδας, γραμμένο με δύο ψηφία μετά την υποδιαστολή, ακολουθούμενο από τη συμβολοσειρά του νομίσματος.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
