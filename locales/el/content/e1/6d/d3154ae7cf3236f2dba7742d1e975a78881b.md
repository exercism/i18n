# Τεστ

Πήγαινε στον κατάλογο που περιέχει το κατάλληλο αρχείο `${slug}_test.sql`, όπου το `${slug}` είναι το όνομα της άσκησης, με παύλες αντί για κενά και όλα τα γράμματα πεζά (π.χ. `hello-world_test.sql` για την άσκηση `Hello World`).

```bash
sqlite3 -bail < ${slug}_test.sql
```

Μπορείς να χρησιμοποιήσεις εντολές `SELECT` για αποσφαλμάτωση.
Η έξοδος θα προωθηθεί στο `user_output.md` και θα εμφανιστεί στον διαδικτυακό επεξεργαστή αν αποτύχουν τα τεστ.

Μπορείς να βρεις περισσότερες πληροφορίες στη [τεκμηρίωση του track sqlite σχετικά με τα τεστ](https://exercism.org/docs/tracks/sqlite/tests).
