# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][integers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Οι [σταθερές συμβολοσειρών][string] είναι μια ακολουθία χαρακτήρων που περικλείεται από διπλά εισαγωγικά.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς ορίσματα.
- Πρέπει να επιστρέψεις έναν [ακέραιο][integers].

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με ένα όρισμα.
- Πρέπει να [επιστρέψεις σιωπηρά έναν ακέραιο][return] από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][operators] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με ένα όρισμα.
- Πρέπει να [επιστρέψεις σιωπηρά έναν ακέραιο][return] από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο ορίσματα.
- Πρέπει να [επιστρέψεις σιωπηρά έναν ακέραιο][return] από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][integers].
- Μπορείς να καλέσεις μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][operators] για να προσθέσεις τιμές.

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς ορίσματα.
- Πρέπει να επιστρέψεις μια [συμβολοσειρά][string].
