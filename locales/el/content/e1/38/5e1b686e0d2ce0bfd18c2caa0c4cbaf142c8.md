# Σχετικά

## Γενική σύνταξη

Ο `for` βρόχος είναι μία από τις πιο συχνά χρησιμοποιούμενες εντολές για να εκτελείς κάποια λογική επανειλημμένα.
Στη Go αποτελείται από τη λέξη-κλειδί `for`, μια κεφαλίδα και ένα μπλοκ κώδικα που περιέχει το σώμα του βρόχου μέσα σε άγκιστρα.
Η κεφαλίδα αποτελείται από 3 μέρη που χωρίζονται με άνω τελείες `;`: init, condition και post.

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- Το μέρος **init** είναι κώδικας που εκτελείται μόνο μία φορά πριν ξεκινήσει ο βρόχος.
- Το μέρος **condition** πρέπει να είναι μια έκφραση που αξιολογείται σε boolean και ελέγχει πότε πρέπει να σταματήσει ο βρόχος.
  Ο κώδικας μέσα στον βρόχο θα εκτελείται όσο αυτή η συνθήκη είναι αληθής.
  Μόλις η έκφραση αξιολογηθεί ως ψευδής, δεν θα εκτελεστεί καμία άλλη επανάληψη του βρόχου.
- Το μέρος **post** είναι κώδικας που θα εκτελεστεί στο τέλος κάθε επανάληψης.

**Σημείωση:** Σε αντίθεση με άλλες γλώσσες, δεν υπάρχουν παρενθέσεις `()` γύρω από τα τρία μέρη της κεφαλίδας.
Μάλιστα, αν βάλεις τέτοιες παρενθέσεις, προκύπτει σφάλμα μεταγλώττισης.
Ωστόσο, τα άγκιστρα `{ }` γύρω από το σώμα του βρόχου είναι πάντα απαραίτητα.

## Οι `for` βρόχοι: ένα παράδειγμα

Το μέρος init συνήθως ορίζει μια μεταβλητή μετρητή, το μέρος condition ελέγχει αν ο βρόχος πρέπει να συνεχιστεί ή να σταματήσει και το μέρος post συνήθως αυξάνει τον μετρητή στο τέλος κάθε επανάληψης.

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

Αυτός ο βρόχος θα εκτυπώσει τους αριθμούς από το `1` έως το `9` (συμπεριλαμβανομένου του `9`).
Το βήμα ορίζεται συχνά με μια εντολή αύξησης ή μείωσης, όπως φαίνεται στο παραπάνω παράδειγμα.

## Προαιρετικά μέρη της κεφαλίδας

Τα μέρη init και post της κεφαλίδας είναι προαιρετικά:

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

Παραλείποντας τα μέρη init και post σε έναν `for` βρόχο όπως παραπάνω, δημιουργείς έναν `while` βρόχο στη Go.
Δεν υπάρχει λέξη-κλειδί `while`.
Αυτό είναι ένα παράδειγμα της αρχής της Go ότι οι έννοιες πρέπει να είναι ορθογώνιες.
Επειδή υπάρχει ήδη μια έννοια που καλύπτει τη συμπεριφορά ενός `while` βρόχου, δηλαδή ο `for` βρόχος, το `while` δεν προστέθηκε ως επιπλέον έννοια.

## Break και Continue

Μέσα στο σώμα ενός βρόχου μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `break` για να σταματήσεις εντελώς την εκτέλεση του βρόχου:

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

Αντίθετα, η λέξη-κλειδί `continue` σταματά μόνο την εκτέλεση της τρέχουσας επανάληψης και συνεχίζει με την επόμενη:

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## Άπειρος `for` βρόχος

Το μέρος της συνθήκης στην κεφαλίδα του βρόχου είναι επίσης προαιρετικό.
Μάλιστα, μπορείς να γράψεις έναν βρόχο χωρίς καθόλου κεφαλίδα:

```go
for {
  // Endless loop...
}
```

Αυτός ο βρόχος θα τελειώσει μόνο αν τερματιστεί το πρόγραμμα ή αν υπάρχει `break` στο σώμα του.

## Ετικέτες και `goto`

Όταν χρησιμοποιείς το `break`, η Go σταματά την εκτέλεση του πιο εσωτερικού βρόχου.
Αντίστοιχα, όταν χρησιμοποιείς το `continue`, η Go εκτελεί την επόμενη επανάληψη του πιο εσωτερικού βρόχου.

Ωστόσο, αυτό δεν είναι πάντα επιθυμητό.
Μπορείς να χρησιμοποιήσεις ετικέτες μαζί με τα `break` και `continue` για να ορίσεις ακριβώς από ποιον βρόχο θέλεις να βγεις ή να συνεχίσεις, αντίστοιχα.

Σε αυτό το παράδειγμα δημιουργούμε μια ετικέτα `OuterLoop`, που αναφέρεται στον πιο εξωτερικό βρόχο.
Στον πιο εσωτερικό βρόχο, για να δηλώσουμε ότι θέλουμε να βγούμε από τον πιο εξωτερικό βρόχο, χρησιμοποιούμε το `break` ακολουθούμενο από το όνομα της ετικέτας του πιο εξωτερικού βρόχου:

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

Η χρήση ετικετών με το `continue` θα λειτουργούσε επίσης, οπότε η Go θα συνέχιζε στην επόμενη επανάληψη του βρόχου στον οποίο αναφέρεται η ετικέτα.

Η Go έχει επίσης τη λέξη-κλειδί `goto`, η οποία λειτουργεί με παρόμοιο τρόπο και σου επιτρέπει να πηδήξεις από ένα σημείο του κώδικα σε ένα άλλο σημείο κώδικα με ετικέτα.

**Προσοχή:** Αν και η Go επιτρέπει να πηδήξεις σε ένα σημείο κώδικα που έχει σημαδευτεί με ετικέτα, η χρήση αυτού του χαρακτηριστικού της γλώσσας μπορεί εύκολα να κάνει τον κώδικα πολύ δυσανάγνωστο.
Για αυτόν τον λόγο, η χρήση ετικετών συχνά δεν συνιστάται.
