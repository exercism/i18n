# Σχετικά

Ένας [`while` βρόχος][while-loops] είναι μια εντολή ροής ελέγχου που επιτρέπει την εκτέλεση κώδικα όσο μια συγκεκριμένη συνθήκη είναι αληθής.
Η Swift παρέχει δύο είδη βρόχων: τον βρόχο `while` και τον βρόχο `repeat-while`.
Η συνθήκη του βρόχου `while` αξιολογείται πριν εκτελεστεί το σώμα του βρόχου· αν η συνθήκη είναι ψευδής, το σώμα του βρόχου δεν θα εκτελεστεί καθόλου.
Οι βρόχοι `while` στη Swift έχουν την εξής δομή:

```swift
while <#condition#> {
  <#code#>
}
```

Εδώ ο βρόχος θα εκτελεστεί όσο το `count` είναι μεγαλύτερο από 0, και έτσι θα εκτυπώσει τους αριθμούς 2, 1 και το "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Ένας [`repeat-while` βρόχος][while-loops] μοιάζει με έναν βρόχο `while`, αλλά η συνθήκη αξιολογείται αφού εκτελεστεί το σώμα του βρόχου.
Αυτό σημαίνει ότι το σώμα του βρόχου θα εκτελεστεί πάντα τουλάχιστον μία φορά, ακόμα κι αν η συνθήκη είναι ψευδής.
Οι βρόχοι `repeat-while` στη Swift έχουν την εξής δομή:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Εδώ ο βρόχος θα εκτελεστεί μόνο μία φορά, αφού η συνθήκη είναι ψευδής.
Επειδή είναι βρόχος `repeat-while`, το σώμα του βρόχου θα εκτελεστεί μία φορά πριν αξιολογηθεί η συνθήκη.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

[repeat-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Repeat-While
