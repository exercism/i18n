# Σχετικά

Οι κλάσεις μπορούν να χρησιμοποιηθούν στην Kotlin για την ενθυλάκωση δεδομένων και συμπεριφοράς.
Μια κλάση δηλώνεται με τη λέξη-κλειδί `class`.
Για παράδειγμα:

```kotlin
class Car
```

Δημιούργησε ένα στιγμιότυπο της κλάσης καλώντας την.

```kotlin
val instance = Car()
```

## Ιδιότητες

Στα παραπάνω παραδείγματα, η κλάση `Car` δηλώθηκε χωρίς καμία ιδιότητα.
Οι ιδιότητες της κλάσης μπορούν να δηλωθούν στο σώμα της, ανάμεσα σε `{}`, χρησιμοποιώντας `var` για μεταβλητές ιδιότητες και `val` για αμετάβλητες.
Για παράδειγμα:

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

Εναλλακτικά, οι ιδιότητες μπορούν να οριστούν σε έναν κατασκευαστή που τις παίρνει ως παραμέτρους.

## Κατασκευαστές

Η Kotlin έχει δύο τύπους κατασκευαστών, τον [κύριο][primary-constructors] και τους [δευτερεύοντες κατασκευαστές][secondary-constructors].
Ο κύριος κατασκευαστής δηλώνεται στην ίδια γραμμή με τη δήλωση της κλάσης.
Για παράδειγμα:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

Η λέξη-κλειδί `constructor` μπορεί να παραλειφθεί αν δεν υπάρχουν annotations και τροποποιητές ορατότητας:

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Η Kotlin επιτρέπει να οριστεί η κλάση με σώμα αν περιέχει μόνο ιδιότητες, χωρίς να χρειάζονται άγκιστρα `{}`:

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

Μια κλάση μπορεί να έχει μόνο έναν κύριο κατασκευαστή.
Οι δευτερεύοντες κατασκευαστές είναι επιπλέον κατασκευαστές που μπορούν να προστεθούν δηλώνοντάς τους στο σώμα της κλάσης με τη λέξη-κλειδί `constructor`.
Για παράδειγμα:

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

Οι δευτερεύοντες κατασκευαστές πρέπει να καλούν τον κύριο κατασκευαστή μέσω του `this`.

## Μπλοκ αρχικοποίησης

Ο κύριος κατασκευαστής ορίζει τις ιδιότητες της κλάσης.
Αν χρειάζεται να γίνουν περισσότερα κατά τη δημιουργία του αντικειμένου, μπορούν να χρησιμοποιηθούν μπλοκ `init` για πρόσθετες ενέργειες.

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## Συναρτήσεις

Οι συναρτήσεις μπορούν να οριστούν στο σώμα της κλάσης.
Για παράδειγμα:

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## Ορατότητα

Οι ιδιότητες και οι συναρτήσεις μπορούν να είναι `private`, `public`, `internal` ή `protected`.

- `private`: μπορεί να προσπελαστεί μόνο μέσα στην κλάση
- `protected`: μπορεί να προσπελαστεί από οτιδήποτε μέσα στην κλάση, καθώς και από τυχόν υποκλάσεις
- `internal`: μπορεί να προσπελαστεί από οτιδήποτε μέσα στο ίδιο [module][kotlin-modules]
- `public`: μπορεί να προσπελαστεί από άλλα components που χρησιμοποιούν την κλάση

Για παράδειγμα:

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```

[kotlin-modules]: https://kotlinlang.org/spec/packages-and-imports.html#modules
[primary-constructors]: https://kotlinlang.org/docs/classes.html#primary-constructor
[secondary-constructors]: https://kotlinlang.org/docs/classes.html#secondary-constructors
