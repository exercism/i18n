# Εισαγωγή

Στην Common Lisp οι συμβολοσειρές είναι [διανύσματα][concept-vectors] [χαρακτήρων][concept-characters]. Γράφονται ως χαρακτήρες μέσα σε διπλά εισαγωγικά (_π.χ._ "Hello World!").

Το κατηγόρημα `stringp` θα επιστρέψει αληθή τιμή μόνο αν η τιμή που του δίνεται είναι συμβολοσειρά.

Οι συμβολοσειρές μπορούν να χωριστούν σε υποσυμβολοσειρές με τη συνάρτηση `subseq`, η οποία δέχεται τη συμβολοσειρά, μια θέση εκκίνησης και προαιρετικά μια θέση τέλους.
Η αρίθμηση των θέσεων ξεκινά από το μηδέν.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Οι συμβολοσειρές μπορούν να συγκριθούν ως προς την ισότητα με το `string=`.
Αν θέλεις να αγνοηθεί η διάκριση πεζών-κεφαλαίων των χαρακτήρων, τότε μπορείς να χρησιμοποιήσεις το `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Εργασίες όπως η μετατροπή σε κεφαλαία, η μετατροπή σε πεζά και η κεφαλαιοποίηση συμβολοσειρών μπορούν να γίνουν με το `string-upcase`, το `string-downcase` και το `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
