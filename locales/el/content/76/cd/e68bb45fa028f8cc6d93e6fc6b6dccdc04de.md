# Υποδείξεις

## Γενικά

- Μια ακέραια τιμή μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] χωρίς καμία παράμετρο.
- Πρέπει να επιστρέψεις μια ακέραια τιμή (δες τους [ενσωματωμένους τύπους][built-in types]).

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία παράμετρο.
- Η παράμετρος της μεθόδου είναι ακέραιος αριθμός.
- Πρέπει να επιστρέψεις μια ακέραια τιμή (δες τους [ενσωματωμένους τύπους][built-in types]).
- Μπορείς να χρησιμοποιήσεις τον τελεστή `-` για να αφαιρείς τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με μία παράμετρο.
- Η παράμετρος της μεθόδου είναι ακέραιος αριθμός.
- Πρέπει να επιστρέψεις μια ακέραια τιμή (δες τους [ενσωματωμένους τύπους][built-in types]).
- Μπορείς να χρησιμοποιήσεις τον τελεστή `*` για να πολλαπλασιάζεις τιμές.

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

- Πρέπει να ορίσεις μια [μέθοδο][methods] με δύο παραμέτρους.
- Οι παράμετροι της μεθόδου είναι ακέραιου τύπου.
- Πρέπει να επιστρέψεις μια ακέραια τιμή (δες τους [ενσωματωμένους τύπους][built-in types]).
- Μπορείς να [καλέσεις][invocation] μία από τις άλλες μεθόδους που όρισες προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον τελεστή `+` για να προσθέτεις τιμές.

[methods]: https://docs.scala-lang.org/overviews/scala-book/methods-first-look.html
[built-in types]: https://docs.scala-lang.org/overviews/scala-book/built-in-types.html
[invocation]: https://docs.scala-lang.org/style/method-invocation.html
