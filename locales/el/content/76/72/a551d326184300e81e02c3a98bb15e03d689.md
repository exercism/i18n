# Επιστροφή

Στην Crystal, η τελευταία έκφραση σε μια μέθοδο επιστρέφει την τιμή της.
Ωστόσο, μερικές φορές χρειάζεται να επιστρέψεις μια τιμή πριν από την τελευταία έκφραση.
Γι' αυτό μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `return`, η οποία επιστρέφει την τιμή της έκφρασης που ακολουθεί.
Ο κώδικας που είναι γραμμένος μετά τη λέξη-κλειδί `return` δεν θα εκτελεστεί.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
Η λέξη-κλειδί `return` πρέπει να παραλείπεται όταν η τελευταία έκφραση σε μια μέθοδο είναι η τιμή που πρέπει να επιστραφεί.
~~~~
