# Σχετικά

Το `reduce` είναι το γενικό fold του Factor: διατρέχει μια ακολουθία, περνώντας έναν συσσωρευτή μέσα από μια δυαδική quotation που παίρνει τον τρέχοντα συσσωρευτή και το επόμενο στοιχείο και παράγει τον νέο συσσωρευτή.

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

Μια προσαρμοσμένη αρχική τιμή επιτρέπει στο `reduce` να εκφράσει folds που το `sum` ή το `product` δεν μπορούν. Για παράδειγμα, η μεγαλύτερη τιμή σε μια ακολουθία, με προεπιλεγμένη τιμή αν χάνει κάθε στοιχείο:

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

Η αρχική τιμή `0` συμμετέχει στη σύγκριση, οπότε μια ακολουθία με μόνο αρνητικά στοιχεία παράγει `0` και όχι τη μικρότερη τιμή της.

## `produce`: το unfold

Το δυϊκό του `reduce` είναι το `produce` (στη βιβλιοθήκη [`sequences`][sequences]): εκεί που το `reduce` *καταναλώνει* μια ακολουθία, το `produce` *παράγει* μία. Μια quotation-κατηγόρημα ελέγχει την τρέχουσα κατάσταση· όσο αυτή επιστρέφει αληθή τιμή, μια quotation-σώμα παράγει το επόμενο στοιχείο.

```
produce ( pred quot -- seq )
```

Το `reduce` και το `produce` μαζί σχηματίζουν το ζεύγος fold/unfold του Factor.

## Σωρευτικές αναγωγές

Η οικογένεια των σωρευτικών λέξεων στο [`math.statistics`][math.statistics] επιστρέφει μια ακολουθία ίδιου μήκους με την είσοδο, όπου κάθε στοιχείο είναι η αναγωγή πάνω στο πρόθεμα μέχρι και τη θέση εκείνη:

| word          | running operation |
|---------------|-------------------|
| `cum-sum`     | τρέχον άθροισμα    |
| `cum-product` | τρέχον γινόμενο    |
| `cum-min`     | τρέχον ελάχιστο    |
| `cum-max`     | τρέχον μέγιστο     |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

Οι σωρευτικές αναγωγές είναι χρήσιμες όταν θέλεις να δεις *πώς* εξελίχθηκε ένα μέγεθος κατά μήκος της ακολουθίας, και όχι μόνο την τελική του τιμή. Χρήσιμο είναι επίσης να τις συνδέσεις σε αλυσίδα: η έξοδος μιας σωρευτικής αναγωγής είναι και η ίδια μια ακολουθία, έτοιμη να τροφοδοτήσει την επόμενη.

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
