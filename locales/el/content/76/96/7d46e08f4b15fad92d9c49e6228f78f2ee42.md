# Υποδείξεις

## 1. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `TemperatureUnit`

- Ο τύπος `TemperatureUnit` έχει ήδη δημιουργηθεί για σένα και αντιπροσωπεύει μια μονάδα θερμοκρασίας
- Σημείωσε ότι υπάρχουν ήδη 2 σταθερές που έχουν δημιουργηθεί για σένα και είναι αυτού του τύπου: `Celsius` και `Fahrenheit`, που αντιπροσωπεύουν μια θερμοκρασία σε Κελσίου και Φαρενάιτ, αντίστοιχα
- Πρόσθεσε μια μέθοδο `String()` στον τύπο `TemperatureUnit`, ώστε να ικανοποιεί τη διεπαφή `Stringer`.
  Αυτή η μέθοδος πρέπει να επιστρέφει τη συμβολοσειρά `"°C"` αν η μονάδα θερμοκρασίας είναι Κελσίου ή `"°F"` αν η μονάδα θερμοκρασίας είναι Φαρενάιτ

## 2. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο  `Temperature`

- Πρόσθεσε μια μέθοδο `String()` στον τύπο `Temperature`, ώστε να ικανοποιεί τη διεπαφή `Stringer`
- Η μέθοδος `String()` πρέπει να επιστρέφει μια συμβολοσειρά με την αριθμητική τιμή της θερμοκρασίας και τη μονάδα θερμοκρασίας, χωρισμένες με ένα κενό (`<temperature> <unit>`)
- Το struct `Temperature` περιέχει μια `TemperatureUnit` και ένα `int`.
  Μπορείς να χρησιμοποιήσεις το [fmt.Sprintf][sprintf] για να σε βοηθήσει να μορφοποιήσεις αυτή τη συμβολοσειρά
- Εφόσον η `TemperatureUnit` υλοποιεί ήδη τη διεπαφή `Stringer` (από την εργασία 1), οι συναρτήσεις του πακέτου `fmt`, όπως η [fmt.Sprintf][sprintf], θα ξέρουν πώς να τη μορφοποιήσουν όταν χρησιμοποιείς τα [ρήματα μορφοποίησης][fmt] `%v` ή `%s`

## 3. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `SpeedUnit`

- Ο τύπος `SpeedUnit` έχει ήδη δημιουργηθεί για σένα και αντιπροσωπεύει μια μονάδα θερμοκρασίας
- Σημείωσε ότι υπάρχουν ήδη 2 σταθερές που έχουν δημιουργηθεί για σένα και είναι αυτού του τύπου: `KmPerHour` και `MilesPerHour`, που αντιπροσωπεύουν μια ταχύτητα σε χιλιόμετρα την ώρα και μίλια την ώρα, αντίστοιχα
- Πρόσθεσε μια μέθοδο `String()` στον τύπο `SpeedUnit`, ώστε να ικανοποιεί τη διεπαφή `Stringer`.
  Αυτή η μέθοδος πρέπει να επιστρέφει τη συμβολοσειρά `"km/h"` αν η μονάδα ταχύτητας είναι χιλιόμετρα την ώρα ή `"mph"` αν η μονάδα ταχύτητας είναι μίλια την ώρα.

## 4. Υλοποίησε τη διεπαφή `Stringer` για το `Speed`

- Πρόσθεσε μια μέθοδο `String()` στον τύπο `Speed`, ώστε να ικανοποιεί τη διεπαφή `Stringer`
- Η μέθοδος `String()` πρέπει να επιστρέφει μια συμβολοσειρά με την αριθμητική τιμή της ταχύτητας και τη μονάδα ταχύτητας, χωρισμένες με ένα κενό (`<speed> <unit>`)
- Το `Speed` περιέχει μια `SpeedUnit` και ένα `int`.
  Μπορείς να χρησιμοποιήσεις το [fmt.Sprintf][sprintf] για να σε βοηθήσει να μορφοποιήσεις αυτή τη συμβολοσειρά
- Εφόσον το struct `TemperatureUnit` υλοποιεί ήδη τη διεπαφή `Stringer` (από την εργασία 3), οι συναρτήσεις του πακέτου `fmt`, όπως η [fmt.Sprintf][sprintf], θα ξέρουν πώς να τη μορφοποιήσουν όταν χρησιμοποιείς τα [ρήματα μορφοποίησης][fmt] `%v` ή `%s`
- Για να εισάγεις ένα `%` στην τελική συμβολοσειρά όταν χρησιμοποιείς το [fmt.Sprintf][sprintf], χρησιμοποίησε `%%` στη συμβολοσειρά μορφοποίησης.

## 5. Υλοποίησε τη διεπαφή `Stringer` για τον τύπο `MeteorologyData`

- Το `Speed` περιέχει τα πεδία `Temperature` και `Speed`, μεταξύ άλλων πεδίων.
  Μπορείς να χρησιμοποιήσεις το [fmt.Sprintf][sprintf] για να σε βοηθήσει να μορφοποιήσεις αυτή τη συμβολοσειρά
- Η μέθοδος `String` πρέπει να επιστρέφει τα μετεωρολογικά δεδομένα στην εξής μορφή: `"<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity"`
- Εφόσον οι τύποι `Temperature` και `Speed` υλοποιούν ήδη τη διεπαφή `Stringer` (από τις εργασίες 2 και 4), οι συναρτήσεις του πακέτου `fmt`, όπως η [fmt.Sprintf][sprintf], θα ξέρουν πώς να τα μορφοποιήσουν όταν χρησιμοποιείς τα [ρήματα μορφοποίησης][fmt] `%v` ή `%s`

[fmt]: https://pkg.go.dev/fmt
[sprintf]: https://pkg.go.dev/fmt#Sprintf
