# Οδηγίες

Ως λάτρης του σκακιού, θα ήθελες να γράψεις τη δική σου εκδοχή του παιχνιδιού.
Ναι, μπορεί να υπάρχουν ήδη πολλές υλοποιήσεις του σκακιού διαθέσιμες στο διαδίκτυο, αλλά η δική σου θα είναι μοναδική!

Κάθε τετράγωνο της σκακιέρας προσδιορίζεται από ένα ζεύγος γράμματος και αριθμού:

- Οι οριζόντιες σειρές τετραγώνων, που ονομάζονται ranks, αριθμούνται από το 1 έως το 8.
- Οι κάθετες στήλες τετραγώνων, που ονομάζονται files, φέρουν ετικέτες από το A έως το H.

```text
   A B C D E F G H
 8 # _ _ _ # _ _ # 8
 7 _ _ _ _ _ _ _ _ 7
 6 _ _ _ _ # _ _ # 6
 5 _ # _ _ _ _ _ # 5
 4 _ _ _ _ _ _ # # 4
 3 # _ # _ _ _ _ # 3
 2 _ _ _ _ _ _ _ # 2
 1 # _ _ _ _ _ _ # 1
   A B C D E F G H
```

## 1. Δεδομένης μιας σκακιέρας και ενός file, μέτρησε πόσα τετράγωνα είναι κατειλημμένα

Υλοποίησε τη συνάρτηση `CountInFile(board Chessboard, file string) int`.
Θα πρέπει να μετράει τον συνολικό αριθμό των κατειλημμένων τετραγώνων διατρέχοντας ένα map.
Επίστρεψε έναν ακέραιο.
Επίστρεψε πλήθος μηδέν (`0`) αν το file που δόθηκε δεν βρίσκεται στο map.

```go
CountInFile(board, "A")
// => 3
```

## 2. Δεδομένης μιας σκακιέρας και ενός rank, μέτρησε πόσα τετράγωνα είναι κατειλημμένα

Υλοποίησε τη συνάρτηση `CountInRank(board Chessboard, rank int) int`.
Θα πρέπει να μετράει τον συνολικό αριθμό των κατειλημμένων τετραγώνων διατρέχοντας το rank που δόθηκε.
Επίστρεψε έναν ακέραιο.
Επίστρεψε πλήθος μηδέν (`0`) αν το rank που δόθηκε δεν είναι έγκυρο (όχι μεταξύ `1` και `8`, συμπεριλαμβανομένων).

```go
CountInRank(board, 2)
// => 1
```

## 3. Μέτρησε πόσα τετράγωνα υπάρχουν στη σκακιέρα που δόθηκε

Υλοποίησε τη συνάρτηση `CountAll(board Chessboard) int`.
Θα πρέπει να μετράει πόσα τετράγωνα υπάρχουν στη σκακιέρα και να επιστρέφει έναν ακέραιο.
Εφόσον δεν χρειάζεται να ελέγξεις το περιεχόμενο των τετραγώνων, σκέψου να χρησιμοποιήσεις range παραλείποντας και το `index` και το `value`.

```go
CountAll(board)
// => 64
```

## 4. Μέτρησε πόσα τετράγωνα είναι κατειλημμένα στη σκακιέρα που δόθηκε

Υλοποίησε τη συνάρτηση `CountOccupied(board Chessboard) int`.
Θα πρέπει να μετράει πόσα τετράγωνα είναι κατειλημμένα στη σκακιέρα.
Επίστρεψε έναν ακέραιο.

```go
CountOccupied(board)
// => 15
```
