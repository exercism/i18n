# Εισαγωγή

Αν θέλεις να φτιάξεις κάτι με ένα Raspberry Pi, πιθανότατα θα χρησιμοποιήσεις _αντιστάτες_.
Όπως και στις προηγούμενες ασκήσεις `Resistor Color Duo` και `Resistor Color Trio`, θα μεταφράζεις τις χρωματιστές λωρίδες του αντιστάτη σε ετικέτες που μπορεί να διαβάσει ένας άνθρωπος.

- Κάθε αντιστάτης έχει μια τιμή αντίστασης.
- Οι αντιστάτες είναι μικροί, τόσο μικροί που αν τύπωνες την τιμή αντίστασης πάνω τους, θα ήταν δύσκολο να τη διαβάσεις.
  Για να ξεπεράσουν αυτό το πρόβλημα, οι κατασκευαστές τυπώνουν πάνω στους αντιστάτες χρωματιστές λωρίδες που δηλώνουν την τιμή αντίστασής τους.
- Κάθε λωρίδα λειτουργεί ως ψηφίο ενός αριθμού.
  Για παράδειγμα, αν τύπωναν μια λωρίδα brown (τιμή 1) ακολουθούμενη από μια λωρίδα green (τιμή 5), θα αντιστοιχούσε στον αριθμό 15.

## Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις ένα βοηθητικό πρόγραμμα, ώστε να μην χρειάζεται να θυμάσαι τις τιμές των λωρίδων.
Το πρόγραμμα θα δέχεται ως είσοδο 1, 4 ή 5 χρώματα και θα βγάζει τη σωστή τιμή, σε ωμ.
Οι χρωματιστές λωρίδες κωδικοποιούνται ως εξής:

- Black: 0
- Brown: 1
- Red: 2
- Orange: 3
- Yellow: 4
- Green: 5
- Blue: 6
- Violet: 7
- Grey: 8
- White: 9

Στο `resistor-color trio` αποκωδικοποίησες τα τρία πρώτα χρώματα.
Για παράδειγμα: το orange-orange-brown αντιστοιχούσε στην κύρια τιμή `330`.
Σε αυτή την άσκηση θα χρειαστεί να προσθέσεις και την _ανοχή_ στο μείγμα.
Η ανοχή είναι το μέγιστο ποσό κατά το οποίο μια τιμή μπορεί να είναι πάνω ή κάτω από την κύρια τιμή.
Για παράδειγμα, αν η τελευταία λωρίδα είναι green, η μέγιστη ανοχή θα είναι ±0.5%.

Η λωρίδα ανοχής θα έχει μία από αυτές τις τιμές:

- Grey - 0.05%
- Violet - 0.1%
- Blue - 0.25%
- Green - 0.5%
- Brown - 1%
- Red - 2%
- Gold - 5%
- Silver - 10%

Ο αντιστάτης τεσσάρων λωρίδων συντίθεται ως εξής:

| Λωρίδα_1 | Λωρίδα_2 | Λωρίδα_3   | Λωρίδα_4 |
| -------- | -------- | ---------- | -------- |
| Τιμή_1   | Τιμή_2   | Πολλαπλασιαστής | Ανοχή    |

Δηλαδή

- το orange-orange-brown-green θα ήταν 330 ωμ με ανοχή ±0.5%.
- το orange-orange-red-grey θα ήταν 3300 ωμ με ανοχή ±0.05%.

Η διαφορά ανάμεσα σε έναν αντιστάτη τεσσάρων και έναν πέντε λωρίδων είναι ότι ο αντιστάτης πέντε λωρίδων έχει μια επιπλέον λωρίδα που δηλώνει μια πιο ακριβή τιμή.

| Λωρίδα_1 | Λωρίδα_2 | Λωρίδα_3 | Λωρίδα_4   | Λωρίδα_5 |
| -------- | -------- | -------- | ---------- | -------- |
| Τιμή_1   | Τιμή_2   | Τιμή_3   | Πολλαπλασιαστής | Ανοχή    |

Δηλαδή

- το orange-orange-orange-black-green θα ήταν 333 ωμ με ανοχή ±0.5%.
- το orange-red-orange-blue-violet θα ήταν 323M ωμ με ανοχή ±0.10.

Υπάρχουν επίσης αντιστάτες μίας λωρίδας.
Οι αντιστάτες μίας λωρίδας έχουν μόνο το χρώμα black με τιμή 0.

Αυτή η άσκηση αφορά τη μετάφραση των χρωμάτων των λωρίδων του αντιστάτη σε μια ετικέτα:

"... ohms ...%"

Έτσι, μια είσοδος με "orange", "orange", "black", "green" θα πρέπει να επιστρέφει:

"33 ohms ±0.5%"

Όταν υπάρχουν περισσότερα από χίλια ωμ, λέμε "kiloohms".
 Αυτό είναι παρόμοιο με το να λέμε "χιλιόμετρο" για 1000 μέτρα και "χιλιόγραμμα" για 1000 γραμμάρια.

Έτσι, μια είσοδος με "orange", "orange", "orange", "grey" θα πρέπει να επιστρέφει:

"33 kiloohms ±0.05%"

Όταν υπάρχουν περισσότερα από ένα εκατομμύριο ωμ, λέμε "megaohms".

Έτσι, μια είσοδος με "orange", "orange", "blue", "red" θα πρέπει να επιστρέφει:

"33 megaohms ±2%"
