# Υποδείξεις

## 1. Αντικατέστησε τυχόν κενά με κάτω παύλες

- Το [παρακάτω σεμινάριο][chars-tutorial] είναι χρήσιμο.
- Μπορείς να ανακτήσεις `char` από μια συμβολοσειρά χρησιμοποιώντας τη μέθοδο [charAt][char-at].
- Θα πρέπει να χρησιμοποιήσεις ένα [`StringBuilder`][string-builder] για να φτιάξεις τη συμβολοσειρά εξόδου.
- Δες την τεκμηρίωση της [Character][chars-docs] για μια μέθοδο που εντοπίζει κενά διαστήματα. Θυμήσου ότι είναι στατική μέθοδος.
- Τα κυριολεκτικά `char` περικλείονται σε μονά εισαγωγικά.

## 2. Μετέτρεψε το kebab-case σε camel-case

- Δες την τεκμηρίωση της [Character][chars-docs] για μια μέθοδο που μετατρέπει έναν χαρακτήρα σε κεφαλαία. Θυμήσου ότι είναι στατική μέθοδος.

## 3. Μετέτρεψε το leetspeak σε κανονικό κείμενο

- Δες την τεκμηρίωση της [Character][chars-docs] για μια μέθοδο που εντοπίζει πότε ένας χαρακτήρας είναι ψηφίο. Θυμήσου ότι είναι στατική μέθοδος.

## 4. Παράλειψε τους χαρακτήρες που δεν είναι γράμματα

- Δες την τεκμηρίωση της [Character][chars-docs] για μια μέθοδο που εντοπίζει πότε ένας χαρακτήρας είναι γράμμα. Θυμήσου ότι είναι στατική μέθοδος.
