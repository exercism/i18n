# Εισαγωγή

## Boolean στην R

Οι τιμές αληθείς ή ψευδείς αναπαρίστανται από τον τύπο `logical`.
Περιέχει μόνο δύο τιμές: `TRUE` και `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Τελεστές Boolean

Υπάρχουν πέντε τελεστές Boolean στην R, αλλά μόνο τρεις είναι σχετικοί σε αυτό το στάδιο της ύλης.
Οι άλλοι δύο θα είναι σημαντικοί όταν δουλεύεις με διανύσματα, που καλύπτονται σε αρκετές επόμενες έννοιες.

`&&` είναι το Boolean "and".
Αποτιμάται σε `TRUE` αν οι εκφράσεις και στις *δύο* πλευρές του `&&` είναι `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` είναι το Boolean "or".
Αποτιμάται σε `TRUE` αν μια έκφραση σε *οποιαδήποτε* από τις δύο πλευρές του `||` είναι `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` είναι το Boolean "not".
Ανταλλάσσει τις τιμές `TRUE` και `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Για μεγαλύτερες και πιο περίπλοκες εκφράσεις, είναι καλύτερο να χρησιμοποιείς παρενθέσεις για να κάνεις την πρόθεσή σου σαφή.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
