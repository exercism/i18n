# Σχετικά

Η Go παρέχει ένα ενσωματωμένο πακέτο που ονομάζεται `fmt` (πακέτο μορφοποίησης) και προσφέρει μια ποικιλία συναρτήσεων για να χειρίζεσαι τη μορφή της εισόδου και της εξόδου.
Η πιο συχνά χρησιμοποιούμενη συνάρτηση είναι η `Sprintf`, η οποία χρησιμοποιεί _ρήματα_ όπως το `%s` για να παρεμβάλει τιμές μέσα σε μια συμβολοσειρά και επιστρέφει αυτή τη συμβολοσειρά.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Στη Go, οι τιμές κινητής υποδιαστολής μορφοποιούνται βολικά με τα ρήματα της Sprintf: `%g` (συμπαγής αναπαράσταση), `%e` (εκθέτης) ή `%f` (χωρίς εκθέτη).
Και τα τρία ρήματα επιτρέπουν τον έλεγχο του πλάτους και της αριθμητικής θέσης του πεδίου.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Μπορείς να βρεις μια πλήρη λίστα με τα διαθέσιμα ρήματα στην [τεκμηρίωση του πακέτου μορφοποίησης][fmt-docs].

Το `fmt` περιέχει κι άλλες συναρτήσεις για την εργασία με συμβολοσειρές, όπως η `Println`, που απλώς εκτυπώνει τα ορίσματα που δέχεται στην κονσόλα, και η `Printf`, που μορφοποιεί την είσοδο με τον ίδιο τρόπο όπως η `Sprintf` πριν την εκτυπώσει.

[fmt-docs]: https://pkg.go.dev/fmt
