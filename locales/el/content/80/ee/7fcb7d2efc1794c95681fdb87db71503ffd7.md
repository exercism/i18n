# Υποδείξεις για την άσκηση Χωράφι με Λουλούδια στη Bash

Αυτή η άσκηση φαίνεται να απαιτεί έναν δισδιάστατο πίνακα.
Η Bash προσφέρει μόνο μονοδιάστατους πίνακες, είτε με αριθμητικές θέσεις είτε συσχετιστικούς [πίνακες][array].

Οι πολυδιάστατοι πίνακες μπορούν να προσομοιωθούν με τη χρήση συσχετιστικών πινάκων: κωδικοποίησε τις θέσεις σε μια συμβολοσειρά χωρισμένη με κόμματα, για να τη χρησιμοποιήσεις ως κλειδί του πίνακα.

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
