# Προσθήκη στις οδηγίες

## Σημειώσεις υλοποίησης

Ο ορισμός της διεπαφής `Cipher` βρίσκεται στο `cipher.go`.

Οι υλοποιήσεις σου θα πρέπει να συμμορφώνονται με τη διεπαφή `Cipher`.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Αναμένεται ότι η `Encode` θα αγνοεί όλες τις τιμές στη συμβολοσειρά που δεν είναι A-Za-z, και δεν θα εμφανίζονται στην έξοδο.
Η έξοδος θα είναι επίσης κανονικοποιημένη σε πεζά.

Οι συναρτήσεις που χρησιμοποιούνται για τη λήψη των κρυπταλγορίθμων είναι:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

Το όρισμα για τη `NewShift` πρέπει να είναι στο εύρος 1 έως 25 ή -1 έως -25.
Το μηδέν δεν επιτρέπεται.
Για μη έγκυρα ορίσματα, η `NewShift` επιστρέφει nil.

Το όρισμα για τη `NewVigenere` πρέπει να αποτελείται μόνο από πεζά γράμματα a-z.
Οι τιμές που αποτελούνται εξ ολοκλήρου από το γράμμα 'a' δεν επιτρέπονται.
Για μη έγκυρα ορίσματα, η `NewVigenere` επιστρέφει `nil`.
