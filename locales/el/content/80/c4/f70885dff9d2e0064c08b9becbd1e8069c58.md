# Οδηγίες

Η Lilly, η εξωγήινη της Lisp, λατρεύει το μαγείρεμα. Θέλει να κάνει ένα πάρτι πίτσας με τους φίλους της, αλλά για να αξιοποιήσει στο έπακρο τα υλικά της, θα ήθελε να ξέρει ακριβώς πόσο από κάθε υλικό θα χρειαστεί πριν ξεκινήσει.

Για να το λύσει αυτό, η Lilly έχει φτιάξει ένα πρόχειρο πρόγραμμα για να αυτοματοποιήσει μέρος του σχεδιασμού, αλλά χρειάζεται τη βοήθειά σου για να το ολοκληρώσει.
Θα βοηθήσεις τη Lilly να κάνει το αναλογικά τέλειο πάρτι πίτσας;

## 1. Αναλογία ζύμης

Πρώτα από όλα, κάθε υπέροχη πίτσα ξεκινά με μια νόστιμη ζύμη!

Η Lilly προτιμά τις λεπτές, τραγανές πίτσες με πιο χοντρή κόρα.
Η ζύμη που χρειάζεται για το κέντρο είναι σταθερή, 200g, αλλά κάθε 20cm κόρας απαιτούν 45g ζύμης.

Ευτυχώς, η Lilly υπολόγισε την εξίσωση για τα γραμμάρια ζύμης (g) με βάση τον αριθμό των πιτσών (n) και τη διάμετρό τους (d):

`g = n * (((45 * pi * d) / 20) + 200)`

Η Lilly χρειάζεται μια συνάρτηση που:
* Παίρνει τον αριθμό των πιτσών (n) και τη διάμετρό τους (d)
* Και επιστρέφει τη ζύμη που χρειάζεται, στρογγυλοποιημένη στο κοντινότερο γραμμάριο (g).

Για παράδειγμα, για να φτιάξεις 4 πίτσες με διάμετρο 30cm:

```lisp
(dough-calculator 4 30) ; => 1648
```

## 2. Λίγη σάλτσα

Η Lilly είναι σχολαστική όταν απλώνει τη σάλτσα της, αλλά το μέγεθος των πιτσών της μπορεί να μην είναι σταθερό.

Για να βρει τη διάμετρο (d), χρησιμοποιεί την παρακάτω εξίσωση, με τη σάλτσα που έχει απλώσει (s) ως μεταβλητή:

`d = square-root of ((40 * s) / (3 * pi))`

Η Lilly χρειάζεται μια συνάρτηση που υπολογίζει τη διάμετρο της πίτσας (d) από κάθε χιλιοστόλιτρο σάλτσας που έχει απλωθεί (s).

Για παράδειγμα, δεδομένου ότι η Lilly έχει χρησιμοποιήσει 250ml σάλτσας:

```lisp
(size-from-sauce 250) ; => 32.57
```

## 3. Λίγο τυρί, παρακαλώ

Στον πλανήτη της Lilly, όλα τα τυριά έρχονται σε τέλειους κύβους και πωλούνται με βάση το μέγεθος.
(Τι περίμενες; Εξωγήινος πλανήτης είναι, άλλωστε...)

Για άλλη μια φορά, η Lilly υπολόγισε μια εξίσωση για τον αριθμό των πιτσών (n) κάποιας διαμέτρου (d) που φτιάχνονται από έναν κύβο τυριού με μήκος πλευράς (l):

`n = (2 * (l^3)) / (3* pi * (d^2))`

Φτιάξε μια συνάρτηση που:
* Παίρνει το μήκος της πλευράς ενός κύβου τυριού (l) και τη διάμετρο των πιτσών (d),
* Και επιστρέφει τον αριθμό των πιτσών (n) που φτιάχνονται, στρογγυλοποιώντας προς τα κάτω.

Για παράδειγμα, δεδομένου ενός κύβου τυριού 25x25x25cm και πιτσών με διάμετρο 30cm:

```lisp
(pizzas-per-cube 25 30) ; => 3
```

## 4. Δίκαιη μοιρασιά

Τέλος, η Lilly θέλει οι πίτσες της να κόβονται σε 8 κομμάτια η καθεμία και να μοιράζονται δίκαια στους φίλους της.

Φτιάξε μια συνάρτηση που:
* Παίρνει έναν αριθμό πιτσών και έναν αριθμό φίλων
* και επιστρέφει `T` αν οι πίτσες μοιράζονται δίκαια στους φίλους και `NIL` διαφορετικά.

Για παράδειγμα:

```lisp
;; For splitting 3 pizzas between 4 friends
(fair-share-p 3 4) ; => T
;; For splitting 2 pizzas between 3 friends
(fair-share-p 2 3) ; => NIL
```
