# Δοκιμές

Για να τρέξεις τις δοκιμές, πρώτα εγκατέστησε το πακέτο `z3-solver`:

```
pip install z3-solver
```

Στη συνέχεια, μπορείς να τρέξεις τις δοκιμές εκτελώντας την παρακάτω εντολή από τον φάκελο της άσκησης:

```
python <snake_case_exercise>_test.py
```

όπου στη θέση του `<snake_case_exercise>` βάζεις το όνομα της άσκησης.
