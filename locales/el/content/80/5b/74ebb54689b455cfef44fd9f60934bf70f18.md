# Χαρακτήρες

Το `CHAR` είναι ένας χαρακτήρας, γραμμένος ανάμεσα σε απλά εισαγωγικά.

```sather
   c : CHAR := 'M';
```

## Ειδικοί χαρακτήρες

Κάποιοι χαρακτήρες δεν μπορούν να πληκτρολογηθούν απευθείας και γράφονται με backslash:

| Γράφεται | Είναι |
| --- | --- |
| `'\n'` | μια νέα γραμμή |
| `'\t'` | ένα tab |
| `'\''` | ένα απλό εισαγωγικό |
| `'\\'` | ένα backslash |

## Ερωτήσεις

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## Πεζά και κεφαλαία

Τα `.upper` και `.lower` αλλάζουν το πεζό ή κεφαλαίο ενός γράμματος και δεν αγγίζουν τίποτα άλλο, οπότε είναι ασφαλή για έναν χαρακτήρα που δεν έχεις ελέγξει.

## Αριθμοί

```sather
'a'.int           -- 97
97.char           -- 'a'
```

Τα `.int` και `.char` είναι ακριβώς αντίθετα. Τα χρήσιμα στοιχεία για την αρίθμηση είναι ότι τα `'a'` έως `'z'` είναι διαδοχικά, τα `'A'` έως `'Z'` είναι διαδοχικά και τα `'0'` έως `'9'` είναι διαδοχικά, οπότε:

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## Κυκλική περιστροφή

Ο τροχός κρυπτογράφησης γυρίζει πέρα από το `z` και ξαναγυρίζει στο `a`. Το `%` κάνει ακριβώς αυτό:

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Το `%` της Sather δεν δίνει ποτέ αρνητικό αποτέλεσμα όταν το δεξί μέλος είναι θετικό, οπότε αυτό δουλεύει και για το γύρισμα του τροχού προς τα πίσω, όχι μόνο προς τα μπροστά.

## Χαρακτήρες και συμβολοσειρές

Το `STR` είναι μια σειρά από byte και το `CHAR` είναι ένα byte. Στα αγγλικά κείμενα ένα byte είναι ένα γράμμα, οπότε το `"Marlowe".size` είναι 7 και το `"Marlowe"[0]` είναι `'M'`. Σε κείμενα με τόνους ή άλλο αλφάβητο, ένα γράμμα μπορεί να πιάσει πολλά byte, και κανένα από αυτά τα δύο δεν ισχύει.
