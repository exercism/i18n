# Υποδείξεις

Για να το συλλάβεις καλύτερα: η άσκηση χρησιμοποιεί μιγαδικούς αριθμούς για να κωδικοποιήσει διασταυρώσεις σε ένα πλέγμα.
Επειδή οι μιγαδικοί αριθμοί μπορούν να θεωρηθούν ως ένα ζεύγος δύο αριθμών, αυτό μπορεί επίσης να ξαναφανταστεί ως το διδιάστατο επίπεδο x-y, με άξονα x = πραγματικό άξονα και άξονα y = φανταστικό άξονα.

## 1. Απλός μιγαδικός αριθμός

- Αυτή είναι μια απλή συνάρτηση-περιτύλιγμα.
- Δες την Εισαγωγή για το πώς να δημιουργήσεις έναν μιγαδικό αριθμό χρησιμοποιώντας μεταβλητές.
- Πρόσεξε ότι, αν δεν χρησιμοποιήσεις τα ορίσματα με λέξη-κλειδί, τα ορίσματα θέσης για τη `complex()` μπορεί να μην είναι αυτά που περιμένεις.

## 2. Βρες τις κατευθύνσεις του οδηγού

- Αυτή η συνάρτηση απαιτεί μία μόνο μαθηματική πράξη.
- Η σειρά της πράξης έχει σημασία (δηλαδή δεν είναι συμμετρική).

## 3. Βρες την απόσταση Μανχάταν

- Θυμήσου, αυτός είναι ο συνολικός αριθμός των διασταυρώσεων (χωρίς να υπολογίζεται η αρχική διασταύρωση) από τις οποίες περνάει το ταξί ακολουθώντας τις γραμμές του πλέγματος.
- Η συνάρτηση `driver_directions` μπορεί να σου φανεί χρήσιμη.
- Άλλες συναρτήσεις που μπορεί να σου φανούν χρήσιμες είναι οι [`Re()` και `Im()`][complex-ref].

## 4. Βρες την απόσταση "σε ευθεία γραμμή"

- Αυτή είναι η απόσταση σε ευθεία γραμμή ανάμεσα στις δύο διασταυρώσεις.
- Μπορείς να το σκεφτείς ως την υποτείνουσα της διαδρομής που διαγράφει μια απόσταση Μανχάταν με μία στροφή.
- Αυτή είναι επίσης γνωστή ως [ευκλείδεια απόσταση][euclid-ref] ή νόρμα L2.
- Η συνάρτηση `driver_directions` μπορεί να σου φανεί χρήσιμη.
- Δες την Εισαγωγή για μια άλλη συνάρτηση μιγαδικών αριθμών που μπορεί προαιρετικά να χρησιμοποιηθεί για να βρεις το μέτρο.

## 5. Βρες τις κατευθύνσεις του κόρακα

- Η συνάρτηση `driver_directions` μπορεί να σου φανεί χρήσιμη.
- Αυτή η συνάρτηση αντιστρέφει τις κατευθύνσεις βορρά/νότου των κατευθύνσεων του οδηγού.
- Αυτό αντιστρέφει τη φαινόμενη θέση ως προς τον "άξονα x".
- Δες την Εισαγωγή για μια άλλη συνάρτηση που μπορεί προαιρετικά να χρησιμοποιηθεί.

[complex-ref]: https://www.rdocumentation.org/packages/base/versions/3.5.3/topics/complex
