# Υποδείξεις

## 1. Όρισε τους τύπους `Usd`, `Eur` και `Jpy`

- Οι τύποι `Usd`, `Eur` και `Jpy` μπορούν να οριστούν χωρίς κατασκευαστές, χρησιμοποιώντας τη σύνταξη `pub type TypeName`.

## 2. Όρισε τον τύπο `Money`.

- Ο τύπος `Money` θα πρέπει να έχει μια παράμετρο τύπου-φάντασμα για το νόμισμα.

## 3. Όρισε τις συναρτήσεις `dollar`, `euro` και `yen`

- Η δήλωση τύπου επιστροφής των συναρτήσεων `dollar`, `euro` και `yen` θα πρέπει να είναι `Money(currency)`, όπου `currency` είναι η κατάλληλη παράμετρος τύπου του τύπου `Money`.

## 4. Όρισε τη συνάρτηση `total`

- Η δήλωση τύπου επιστροφής της συνάρτησης `total` θα πρέπει να χρησιμοποιεί την ίδια παράμετρο τύπου με το όρισμα.
