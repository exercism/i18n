# Μάθηση

Η assembly για ARM64 είναι μια απλή γλώσσα assembly.
Ίσως μπορέσεις να ξεκινήσεις με [ένα φύλλο αναφοράς][reference-sheet].

Η ARM παρέχει επίσης [ψηφιακή αναφορά][official-reference] για την αρχιτεκτονική ARM64 (AArch64/ARMv8).

Ελπίζουμε να απολαύσεις τη μάθηση του assembly για ARM και να δουλέψεις πάνω στις ασκήσεις.

Αυτή είναι μια πύλη για να γνωρίσεις το τηλέφωνό σου ή υλικό ανάπτυξης βασισμένο σε ARM64 (τα πιο πρόσφατα μοντέλα Raspberry Pi είναι ένα παράδειγμα).

[reference-sheet]: https://www.cs.swarthmore.edu/~kwebb/cs31/resources/ARM64_Cheat_Sheet.pdf
[official-reference]: https://developer.arm.com/documentation
