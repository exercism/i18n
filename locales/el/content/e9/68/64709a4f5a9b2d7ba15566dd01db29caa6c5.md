# Προσθήκη στις οδηγίες

## Προκλήσεις

- Μπορείς να υλοποιήσεις αυτή τη λύση χωρίς να χρησιμοποιήσεις κανέναν `for` βρόχο; (δηλαδή χρησιμοποιώντας [iterators][iterators] αντ' αυτού)
- Αν και θα ήταν σχετικά απλό να έχεις δύο δομές δεδομένων στο `Matrix` (μία για τις γραμμές και μία για τις στήλες), μπορείς να υλοποιήσεις αυτή τη λύση χωρίς να χρειάζεται να κρατάς δύο ξεχωριστά αντίγραφα της εισόδου στη struct σου;

## Χρήσιμες μέθοδοι

- [`filter()`][filter]
- [`lines()`][lines]
- [`split()`][split]
