# Προσθήκη στις οδηγίες

## Assert

Σε αυτή την άσκηση, ας πούμε ότι θέλουμε αυτός που καλεί τη συνάρτηση να είναι υπεύθυνος να καλέσει τη `classify` μόνο με μη μηδενική είσοδο. Οπότε φρόντισε η συνάρτηση `classify` να κάνει assert ότι η είσοδός της δεν είναι μηδέν. Για περισσότερες λεπτομέρειες, δες το [Zig Language Reference][zig-reference] και την υλοποίηση του [`std.debug.assert`][assert].

Ωστόσο, πρόσεξε ότι αυτή η άσκηση δεν δοκιμάζει προς το παρόν είσοδο 0 (επειδή το `std.testing` [δεν υποστηρίζει ακόμα να περιμένεις ένα panic][proposal]).

[zig-reference]: https://ziglang.org/documentation/0.16.0/#unreachable
[assert]: https://ziglang.org/documentation/0.16.0/std/#std.debug.assert
[proposal]: https://github.com/ziglang/zig/issues/1356
