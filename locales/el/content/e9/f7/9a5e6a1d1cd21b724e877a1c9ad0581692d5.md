# Οδηγίες

Είσαι ο ασύρματος τηλεγραφητής σε ένα φορτηγό πλοίο. Το σήμα φτάνει
μέσα από μια θορυβώδη γραμμή, όπου οι μηχανές του πλοίου, τα
παράσιτα του καιρού και οι περιστασιακές ξένες φωνές είναι
ανακατεμένα με τον πραγματικό Μορς που ακούς. Για να πιάσεις το
μήνυμα, περνάς το καλώδιο μέσα από μια συσκευή *ταινίας* που αφαιρεί
τα πάντα εκτός από τα έγκυρα σύμβολα Μορς (`.`, `-`, και το κενό που
χωρίζει τα γράμματα).

Η δουλειά σου είναι να φτιάξεις την ταινία ως προσαρμοσμένη ροή
εισόδου Factor.

## 1. Όρισε την ταινία

Όρισε μια πλειάδα `tape` που επεκτείνει το `disposable` και κρατά μία
υποδοχή, `wire`, για την υποκείμενη ροή εισόδου.

```factor
TUPLE: tape < disposable wire ;
```

Έπειτα γράψε τον κατασκευαστή `<tape> ( wire -- tape )`. Χρησιμοποίησε
το `new-disposable` (όχι το `new`) ώστε το framework καταστροφέων να
καταχωρίσει την ταινία, και αποθήκευσε την υποκείμενη ροή στην υποδοχή
`wire`.

## 2. Ενσωμάτωσε το mixin input-stream

Δήλωσε το `tape` ως `input-stream`:

```factor
INSTANCE: tape input-stream
```

Αυτό κάνει τους προεπιλεγμένους συνδυαστές του πρωτοκόλλου να
κατευθύνονται στην κλάση σου.

## 3. Διάβασε ένα σύμβολο Μορς

Υλοποίησε το `M: tape stream-read1 ( tape -- elt/f )`. Διάβασε bytes
από το υποκείμενο καλώδιο μέχρι να συναντήσεις ένα από τα `CHAR: .`,
`CHAR: -` ή `CHAR: \s` (κενό). Επίστρεψε αυτό το byte. Αν το καλώδιο
επιστρέψει `f` (τέλος ροής), επίστρεψε και `f`. Η ταινία τελείωσε.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Ανάθεσε τον τύπο στοιχείου

Υλοποίησε το `M: tape stream-element-type ( tape -- type )` αναθέτοντας
στο καλώδιο. Η ταινία δεν αλλάζει το είδος των στοιχείων που
διαβάζονται.

## 5. Καθάρισε

Υλοποίησε το `M: tape dispose* ( tape -- )`. Το framework καλεί τη
μέθοδό σου ακριβώς μία φορά ανά `dispose`. Απλώς κάνε dispose στο
υποκείμενο καλώδιο.

Με αυτά τα πέντε κομμάτια στη θέση τους, η ταινία λειτουργεί ως
κανονική ροή εισόδου. Τα `with-input-stream`, `stream-read` και οι
άλλες λέξεις του πρωτοκόλλου δρομολογούνται αυτόματα στις μεθόδους σου.
