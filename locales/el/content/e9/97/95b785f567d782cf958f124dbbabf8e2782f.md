# Tests

Για να τρέξεις τα tests που παρέχονται, θα χρειαστείς το gem Minitest. Άνοιξε ένα παράθυρο τερματικού και τρέξε την παρακάτω εντολή για να εγκαταστήσεις το minitest:

```
gem install minitest
```


Τρέξε τα tests από τον κατάλογο της άσκησης με την παρακάτω εντολή:

```
ruby <snake-case-exercise>_test.rb
```

Αντικατέστησε το `<snake-case-exercise>` με το όνομα της άσκησής σου σε snake_case.

## Έγχρωμη έξοδος

Μπορείς να κάνεις `require 'minitest/pride'` ή να τρέξεις την παρακάτω εντολή για να πάρεις έγχρωμη έξοδο:

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
