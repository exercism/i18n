# Νήματα

Αυτή η άσκηση εισάγει τα νήματα για να ελέγξει πόσο ανθεκτικός είναι ο τραπεζικός σου λογαριασμός σε ταυτόχρονες λειτουργίες. Λίγο υλικό για διάβασμα σχετικά με τα νήματα της Tcl:

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf),
  ένα κεφάλαιο από το _Practical Programming in Tcl and Tk, 4th Ed._,
πνευματικά δικαιώματα 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * Σημείωση: αυτό το κεφάλαιο αναφέρει "Οι περισσότερες δυαδικές διανομές της Tcl δεν έχουν υποστήριξη νημάτων". Αυτό δεν ισχύει πλέον: οι διανομές της Tcl πλέον χτίζονται με υποστήριξη νημάτων (αναφ. [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md))
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm) από την τεκμηρίωση της Tcl.

## Εγκατάσταση

Ορισμένες διανομές της Tcl δεν περιλαμβάνουν το πακέτο Thread της Tcl από προεπιλογή: μπορεί να χρειαστεί να εγκατασταθεί ξεχωριστά.
Επαλήθευσέ το με
```bash
$ echo 'package require Thread' | tclsh
```
Αν αυτό δεν παράγει _κανένα αποτέλεσμα_, τότε το πακέτο Thread είναι ήδη εγκατεστημένο.

Εκτέλεσε `apt install tcl-thread` (ή `dnf install tcl-thread`) όπως απαιτείται.
