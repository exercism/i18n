# Συνθήκες

```sather
   if score >= 5 then
      return "Recalled";
   else
      return "Thank you";
   end;
```

Η ερώτηση ανάμεσα στο `if` και το `then` πρέπει να είναι `BOOL`. Η Sather δεν δέχεται αριθμό εκεί, οπότε δεν υπάρχει η συνήθεια του στυλ της C να αντιμετωπίζεται το μηδέν ως ψευδές.

## Η μορφή

```sather
   if first_question then
      ...
   elsif second_question then
      ...
   elsif third_question then
      ...
   else
      ...
   end;
```

Οι ερωτήσεις γίνονται από πάνω προς τα κάτω και κερδίζει η πρώτη που απαντά καταφατικά. Όλα όσα βρίσκονται από κάτω της παραλείπονται χωρίς καν να ερωτηθούν. Γι' αυτό μια αλυσίδα πρέπει να πηγαίνει από τον πιο συγκεκριμένο έλεγχο στον λιγότερο συγκεκριμένο: αν βάλεις το `score >= 5` πάνω από το `score >= 8`, το δεύτερο δεν φτάνει ποτέ να εξεταστεί.

Το `else` είναι προαιρετικό. Το `elsif` μπορεί να επαναληφθεί όσες φορές χρειαστεί.

## Οι συνθήκες είναι εντολές, όχι τιμές

Το `if` δεν παράγει από μόνο του κάποια τιμή, οπότε αυτό δεν είναι Sather:

```sather
   -- wrong
   grade := if score > 5 then "pass" else "fail" end;
```

Είτε επέστρεψε από μέσα από κάθε κλάδο, είτε ανάθεσε σε μια μεταβλητή μέσα σε κάθε κλάδο.

## Πότε να μη χρησιμοποιείς συνθήκη

Μια ρουτίνα που απαντά σε μια ερώτηση πρέπει να επιστρέφει την ίδια την ερώτηση:

```sather
   -- say this
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;

   -- not this
   old_enough(age : INT) : BOOL is
      if age >= 13 then return true; else return false; end;
   end;
```

Το δεύτερο δεν λέει τίποτα που να μη λέει το πρώτο, με τριπλάσιο μήκος.

## Εμφώλευση

Ένα `if` μπορεί να περιέχει ένα άλλο `if`. Συχνά όμως δεν χρειάζεται: δύο ερωτήσεις που πρέπει να ισχύουν και οι δύο μπορούν να ενωθούν με `and`, κάτι που διαβάζεται καλύτερα.

```sather
   if score >= 8 and sings then
      return "Lead";
   end;
```
