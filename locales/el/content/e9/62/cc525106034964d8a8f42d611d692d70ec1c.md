# Εκτέλεση των test της Ceylon

Για να τρέξουν τα test, ο κώδικάς σου πρέπει πρώτα να μεταγλωττιστεί με την εντολή [`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html).

Τα test τα τρέχουμε με την εντολή [`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html).

Η εντολή `ceylon test` περιμένει ένα όνομα module στο οποίο θα τρέξει τα test.
Στη διαδρομή της Ceylon, κάθε άσκηση έχει ένα μόνο module.

Έτσι, μπορείς να τρέξεις τα test με:

```bash
ceylon compile && ceylon test $(basename source/*)
```
