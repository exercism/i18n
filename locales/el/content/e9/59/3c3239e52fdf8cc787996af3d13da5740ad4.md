# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | είσοδος     | ακέραιος | θέση πρώτου αριθμού                |
| `$v0`    | έξοδος     | ακέραιος | τιμή του νιοστού πρώτου αριθμού            |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
