# Αριθμοί

Η Crystal έχει έναν τύπο, τον `Number`, που είναι ο βασικός τύπος για όλους τους αριθμητικούς τύπους.
Μέσα στον τύπο Number υπάρχουν δύο κύριοι υποτύποι: ο [`Int`][int] και ο [`Float`][float].

Το `Int` είναι σύντμηση του integer και αναπαριστά ακέραιους αριθμούς.
Το `Int` μπορεί να είναι και αρνητικό και θετικό, χωρίς υποδιαστολή.

```crystal
1.class
# => Int32

-1.class
# => Int32
```

Το `Float` αναπαριστά αριθμούς με υποδιαστολή.
Τα `Float` μπορούν να είναι και αρνητικά και θετικά.

```crystal
10.5.class
# => Float64
```

## Μετατροπή μεταξύ `Int` και `Float`

Χρησιμοποιώντας τις μεθόδους "to_i" και "to_f", μπορείς να μετατρέψεις μεταξύ `Int` και `Float`.
Ο αριθμός στρογγυλοποιείται προς τα κάτω όταν μετατρέπεται από `Float` σε `Int`.

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## Αριθμητικοί τελεστές

Μπορείς να χρησιμοποιήσεις τους [βασικούς αριθμητικούς τελεστές][math] σε `Int` και `Float`.
Οι τελεστές είναι `+`, `-`, `*`, `/` και `%`.
Όταν χρησιμοποιείς αυτούς τους τελεστές, μπορείς να αναμειγνύεις `Int` και `Float`.

### Πρόσθεση & Αφαίρεση & Πολλαπλασιασμός

Ο τελεστής `+` χρησιμοποιείται για την πρόσθεση, ο τελεστής `-` για την αφαίρεση και ο τελεστής `*` για τον πολλαπλασιασμό.

| Τελεστής | Παράδειγμα     |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### Διαίρεση

Η διαίρεση χρησιμοποιείται για να διαιρείς αριθμούς.
Ο τελεστής `/` χρησιμοποιείται για τη διαίρεση.
Το αποτέλεσμα θα είναι πάντα Float.

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
Σε κάποιες γλώσσες προγραμματισμού, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι ένα σφάλμα.

Στην Crystal, όταν διαιρείς με το μηδέν, το αποτέλεσμα είναι `Infinity` ή `-Infinity`.
Η μόνη εξαίρεση είναι η διαίρεση του μηδέν με το μηδέν, που έχει ως αποτέλεσμα `NaN` (Not a Number).
Τα `Infinity` και `NaN` είναι ειδικές τιμές στον τύπο `Float`.

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## Ακέραια διαίρεση

Η ακέραια διαίρεση χρησιμοποιείται για να διαιρείς αριθμούς και να παίρνεις το ακέραιο μέρος του αποτελέσματος.
Το αποτέλεσμα στρογγυλοποιείται πάντα προς τα κάτω σε Int.

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς ακέραια διαίρεση έχει ως αποτέλεσμα ένα `DivisionByZeroError`.
Αυτό διαφέρει από την κανονική διαίρεση.
~~~~

### Υπόλοιπο

Ο τελεστής υπολοίπου χρησιμοποιείται για να παίρνεις το υπόλοιπο μιας διαίρεσης.
Ο τελεστής `%` χρησιμοποιείται για το υπόλοιπο.

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
Η διαίρεση με το μηδέν όταν χρησιμοποιείς το υπόλοιπο έχει ως αποτέλεσμα ένα DivisionByZeroError.
Αυτό διαφέρει από την κανονική διαίρεση.

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## Ύψωση σε δύναμη

Η ύψωση σε δύναμη χρησιμοποιείται για να υψώσεις έναν αριθμό σε δύναμη.
Ο τελεστής `**` χρησιμοποιείται για την ύψωση σε δύναμη.
Το αποτέλεσμα μιας πράξης με ένα `Float` και ένα `Int` θα είναι `Float`.

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## Στρογγυλοποίηση

Η μέθοδος `round` δέχεται ένα προαιρετικό όρισμα: τον αριθμό των δεκαδικών ψηφίων στα οποία θα γίνει η στρογγυλοποίηση.
Ο προεπιλεγμένος αριθμός δεκαδικών ψηφίων είναι 0.

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### Στρογγυλοποίηση προς τα πάνω και προς τα κάτω

Μπορείς επίσης να στρογγυλοποιήσεις προς τα πάνω ή προς τα κάτω σε ένα `Int` χρησιμοποιώντας τις μεθόδους `ceil` και `floor`.
Η μέθοδος `ceil` στρογγυλοποιεί προς τα πάνω και η μέθοδος `floor` προς τα κάτω.

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## Προτεραιότητα και παρενθέσεις

Η Crystal επιτρέπει παρενθέσεις(`()`), οι οποίες μπορούν να χρησιμοποιηθούν για να ομαδοποιείς εκφράσεις.
Αυτό είναι χρήσιμο όταν θέλεις να αλλάξεις τη σειρά των πράξεων.

Όταν χρησιμοποιείς πολλούς αριθμητικούς τελεστές, η σειρά των πράξεων είναι ίδια όπως στα μαθηματικά, γνωστή και ως [PEMDAS][pemdas].
Ακολουθεί τη σειρά: παρενθέσεις(`()`), δυνάμεις(`**`), πολλαπλασιασμός(`*`) και διαίρεση(`/`), και πρόσθεση(`+`) και αφαίρεση(`-`).

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
