# Σχετικά

Ένας **αριθμός κινητής υποδιαστολής** είναι ένας αριθμός που μπορεί να έχει κλασματικό μέρος, όπως `-1.23` ή `3.1415`.

Για να αναπαραστήσει έναν τέτοιο αριθμό ως ακολουθία byte, το x86-64 χρησιμοποιεί το πρότυπο [IEEE-754][ieee].
Οι δύο πιο συνηθισμένες μορφές σε αυτό το πρότυπο είναι οι αριθμοί κινητής υποδιαστολής απλής ακρίβειας και οι αριθμοί κινητής υποδιαστολής διπλής ακρίβειας.
Το x86-64 υποστηρίζει και τις δύο.

Ένας αριθμός κινητής υποδιαστολής απλής ακρίβειας έχει πλάτος 32 bit, ενώ ένας διπλής ακρίβειας έχει πλάτος 64 bit.

~~~~exercism/note
Καθώς οι αριθμοί κινητής υποδιαστολής είναι μια προσέγγιση του συνόλου των πραγματικών αριθμών, οι πράξεις με αυτούς μπορεί να δώσουν ανακριβή αποτελέσματα.

Για μια διεξοδική εξήγηση, ανατρέξε στο [Παράρτημα D][guide] του Numerical Computation Guide της Oracle, "What Every Computer Scientist Should Know About Floating-Point Arithmetic".

Η [σελίδα Float Toy][toy] έχει μια ωραία, γραφική εξήγηση για το πώς τα bit ενός αριθμού κινητής υποδιαστολής μετατρέπονται σε μια πραγματική τιμή κινητής υποδιαστολής.

[guide]: https://docs.oracle.com/cd/E19957-01/806-3568/ncg_goldberg.html
[toy]: https://evanw.github.io/float-toy
~~~~

## Καταχωρητές XMM

Στο x86-64 υπάρχουν 16 ειδικοί καταχωρητές για αριθμητική κινητής υποδιαστολής, με ονόματα `xmm0` έως `xmm15`.

Αυτοί οι καταχωρητές έχουν πλάτος τουλάχιστον 128 bit, αλλά οι πρόσφατοι επεξεργαστές το αυξάνουν στα 256 bit ή στα 512 bit.
Ωστόσο, στην πράξη, οι περισσότεροι αριθμοί κινητής υποδιαστολής χρησιμοποιούν μόνο τα χαμηλότερα 32 bit ή 64 bit, ανάλογα με την επιθυμητή ακρίβεια.

## Μετατροπή μεταξύ αριθμών

Υπάρχει μια οικογένεια εντολών για τη μετατροπή μεταξύ μορφών αριθμών: `cvtxx2yy`.

Τα `xx` και `yy` δεν είναι κυριολεκτικές τιμές, αλλά σύμβολα αντικατάστασης:

- Το `xx` είναι ένα σύμβολο αντικατάστασης για τον τύπο του τελεστέου προέλευσης.
- Το `yy` είναι ένα σύμβολο αντικατάστασης για τον τύπο του τελεστέου προορισμού.

Αυτό το σύμβολο αντικατάστασης μπορεί να πάρει πολλές μορφές, μεταξύ των οποίων:

| placeholder | meaning               |
| ----------- | --------------------- |
| `si`        | προσημασμένος ακέραιος |
| `ss`        | αριθμός κινητής υποδιαστολής 32 bit |
| `sd`        | αριθμός κινητής υποδιαστολής 64 bit |

Για παράδειγμα:

```x86asm
cvtsi2ss xmm0, eax ; converts a 32-bit signed integer to a single-precision floating-point
cvtsd2si rax, xmm1 ; converts a double-precision floating-point to a 64-bit signed integer
```

Σημείωσε ότι είναι δυνατό να μετατρέψεις έναν ακέραιο 32 bit σε αριθμό κινητής υποδιαστολής 64 bit ή έναν ακέραιο 64 bit σε αριθμό κινητής υποδιαστολής 32 bit.
Παρομοίως, είναι επίσης δυνατό να μετατρέψεις έναν αριθμό κινητής υποδιαστολής 32 bit σε ακέραιο 64 bit ή έναν αριθμό κινητής υποδιαστολής 64 bit σε ακέραιο 32 bit.
Με άλλα λόγια, το μέγεθος των δύο τελεστέων σε μια εντολή `cvtxx2yy` _δεν χρειάζεται να είναι το ίδιο_:

```x86asm
cvtsi2sd xmm0, eax ; converts a 32-bit signed integer to a double-precision floating-point
cvtsi2ss xmm0, rax ; converts a 64-bit signed integer to a single-precision floating-point
cvtss2si rax, xmm0 ; converts a single-precision floating-point to a 64-bit signed integer
cvtsd2si eax, xmm0 ; converts a double-precision floating-point to a 32-bit signed integer
```

Όταν ο αριθμός κινητής υποδιαστολής δεν μπορεί να εκφραστεί ακριβώς ως ακέραιος, η `cvtxx2si` στρογγυλοποιεί τον αριθμό σύμφωνα με τον έλεγχο στρογγυλοποίησης σε έναν ειδικό καταχωρητή που ονομάζεται `mxcsr`.
Αυτός μπορεί να είναι στρογγυλοποίηση στον πλησιέστερο, προς τα κάτω, προς τα πάνω ή αποκοπή.
Δεν υπάρχει εγγυημένη προεπιλεγμένη ρύθμιση κατά την είσοδο στη συνάρτηση.

Σημείωσε ότι ένα ακριβές αποτέλεσμα δεν στρογγυλοποιείται και, επομένως, δεν επηρεάζεται από τον έλεγχο στρογγυλοποίησης.
Για παράδειγμα, το `42.0` θα μετατρεπόταν _πάντα_ σε `42`.

Υπάρχει μια παρόμοια οικογένεια εντολών με μορφή `cvttxx2si` (με ένα επιπλέον `t`) που αποκόπτει πάντα το αποτέλεσμα.

## Στρογγυλοποίηση

Η οικογένεια εντολών `roundxx` μετατρέπει έναν αριθμό κινητής υποδιαστολής στον τελεστέο προέλευσης σε έναν στρογγυλοποιημένο αριθμό κινητής υποδιαστολής που αποθηκεύεται στον τελεστέο προορισμού.

Εδώ, το `xx` είναι ένα σύμβολο αντικατάστασης για τον τύπο των τελεστέων, ως συνήθως: `ss` για απλής ακρίβειας και `sd` για διπλής ακρίβειας.

Αυτές οι εντολές παίρνουν έναν σταθερό αριθμό ως τρίτο τελεστέο.
Αυτός ο αριθμός υποδεικνύει τον τρόπο στρογγυλοποίησης:

| Number | Mode         |
| :----- | :----------- |
| 0      | Πλησιέστερος |
| 1      | Δάπεδο (προς τα κάτω) |
| 2      | Οροφή (προς τα πάνω)  |
| 3      | Αποκοπή      |

Για παράδειγμα:

```x86asm
roundss xmm0, xmm1, 1 ; this rounds down (takes the floor) a 32-bit floating-point in xmm1 and stores it in xmm0
roundsd xmm2, xmm2, 2 ; this rounds up (takes the ceil) a 64-bit floating-point in xmm2 and stores it in xmm2
```

Καθώς αυτές οι εντολές παράγουν ένα ακριβές αποτέλεσμα, μπορούν να χρησιμοποιηθούν ως προετοιμασία για μια `cvtxx2si`.

## Αριθμητικές εντολές

Πολλές πράξεις με αριθμούς κινητής υποδιαστολής χρησιμοποιούν εντολές με παρόμοιο όνομα με το αντίστοιχό τους για ακέραιους, προσθέτοντας όμως το απαραίτητο σύμβολο αντικατάστασης (`ss` ή `sd`) στο τέλος.
Αυτές οι εντολές έχουν δύο τελεστέους, με τη συνήθη σημασιολογία, ακόμη και εκείνες που εκτελούν πολλαπλασιασμό ή διαίρεση:

```x86asm
addss xmm1, xmm2 ; xmm1 = xmm1 + xmm2 (all 32-bit floating-point)
mulsd xmm4, xmm5 ; xmm4 = xmm4 * xmm5 (all 64-bit floating-point)
divss xmm0, xmm3 ; xmm0 = xmm0 / xmm3 (all 32-bit floating-point)
```

## Μετακίνηση

Οι εντολές για μετακίνηση από έναν καταχωρητή XMM σε έναν άλλο είναι οι `movss` ή `movsd`:

```x86asm
movss xmm1, xmm0 ; this copies a 32-bit floating-point from xmm0 to xmm1
movsd xmm6, xmm4 ; this copies a 64-bit floating-point from xmm4 to xmm6
```

**Δεν** είναι δυνατό να μετακινήσεις μια άμεση τιμή (έναν σταθερό προσημασμένο ακέραιο) απευθείας σε έναν καταχωρητή xmm.
Αυτός ο αριθμός πρέπει πρώτα να μετακινηθεί σε έναν καταχωρητή γενικού σκοπού και μετά να μετατραπεί με την `cvtsi2xx`:

```x86asm
mov rax, 10        ; rax is a 64-bit integer with value 10
cvtsi2sd xmm0, rax ; xmm0 is a 64-bit floating-point with value 10.0
```

## Συγκρίσεις

Υπάρχουν δύο ομάδες εντολών για σύγκριση μεταξύ δύο αριθμών κινητής υποδιαστολής.
Έχουν τη μορφή `comixx` και `ucomixx`, όπου το `xx` είναι είτε `ss` είτε `sd`.
Και οι δύο θέτουν σημαίες στο `rflags` ως συνήθως, ακολουθώντας την ίδια σημασιολογία με την `cmp`.

Η διαφορά μεταξύ τους είναι ότι η `ucomixx` θέτει τη `parity flag (PF)` αν ένας από τους δύο αριθμούς κινητής υποδιαστολής έχει τιμή `NaN`, ενώ η `comixx` πετάει μια εξαίρεση σε αυτήν την περίπτωση.

Η σύγκριση μεταξύ τιμών κινητής υποδιαστολής είναι _χωρίς πρόσημο_:

```x86asm
ucomisd xmm0, xmm1
ja .greater         ; 'ja' must be used for "greater", not 'jg'
jb .lesser          ; 'jb' must be used for "lesser", not 'jl'
```

## Άλλες εντολές

Υπάρχουν πολλές ακόμη εντολές για εργασία με αριθμούς κινητής υποδιαστολής, που υλοποιούν συνήθεις πράξεις.
Μερικές από αυτές είναι:

| Instruction | Description                                      |
| :---------- | :----------------------------------------------- |
| `sqrtxx`    | Υπολογίζει την τετραγωνική ρίζα (`sqrt(x)`)      |
| `rcpss`     | Υπολογίζει τον αντίστροφο (`1/x`)                |
| `rsqrtss`   | Υπολογίζει τον αντίστροφο της τετραγωνικής ρίζας (`1/sqrt(x)`) |
| `minxx`     | Υπολογίζει το ελάχιστο (`min(x, y)`)             |
| `maxxx`     | Υπολογίζει το μέγιστο (`max(x, y)`)              |

Όπου χρησιμοποιείται ένα σύμβολο αντικατάστασης `xx`, μπορεί να πάρει τη μορφή `ss` ή `sd`, ως συνήθως.
Ωστόσο, οι `rcpss` και `rsqrtss` λειτουργούν μόνο με αριθμούς κινητής υποδιαστολής απλής ακρίβειας.

Όλες αυτές οι εντολές έχουν δύο τελεστέους.

## Σύμβαση κλήσης

Στο System V ABI, τα πρώτα οκτώ ορίσματα κινητής υποδιαστολής περνιούνται στις συναρτήσεις με τη σειρά, από το `xmm0` έως το `xmm7`.
Οι τιμές κινητής υποδιαστολής επιστρέφονται από τις συναρτήσεις στο `xmm0` και, αν χρειάζεται, στο `xmm1`.

Όλοι οι καταχωρητές `xmm` είναι ελεύθερα διαθέσιμοι προς χρήση, κανένας από αυτούς δεν είναι δεσμευμένος για τον καλούντα.

## Μνήμη

Οι τιμές κινητής υποδιαστολής μπορούν να οριστούν στη μνήμη ακολουθώντας την ίδια σημασιολογία με τους ακέραιους του ίδιου μεγέθους.
Ο NASM (The Netwide Assembler, ο assembler που χρησιμοποιεί αυτό το track) επιτρέπει επίσης τη δήλωση τιμών κινητής υποδιαστολής σε επιστημονικό συμβολισμό.

```x86asm
section .data
    pi dq 3.141592653589793 ; this is a double-precision floating-point value
    exp_num dd 1.e5 ; this is a single precision floating-point value equal to 1 * 10⁵
    exp_num2 dd 1.e+5 ; this is a single precision floating-point value equal to 1 * 10⁵
    frac dq 1.e-10 ; this is a double precision floating-point value equal to 1 * 10⁻¹⁰, i.e., 0.0000000001
```

## AVX/AVX2

Οι επεκτάσεις AVX/AVX2 στην αρχιτεκτονική x86-64 εισάγουν νέες μορφές τριών τελεστέων για τις εντολές κινητής υποδιαστολής, διαχωρίζοντας τον προορισμό από τις πηγές.
Παίρνουν ένα πρόθεμα `v` (για _διάνυσμα_) για να διακρίνονται από τη μορφή SSE παλαιότερης γενιάς που είδαμε παραπάνω:

```x86asm
vaddss xmm0, xmm1, xmm2 ; xmm0 = xmm1 + xmm2 (32-bit floating-point)
vmulsd xmm2, xmm3, xmm4 ; xmm2 = xmm3 * xmm4 (64-bit floating-point)
```

Σε αυτό το track, έχουμε περιοριστεί σε εντολές και καταχωρητές έως τις προηγούμενες επεκτάσεις SSE.
Αυτό αρκεί για να διδαχθούν τα βασικά και εξασφαλίζει συμβατότητα με ένα ευρύ φάσμα CPU.

Ωστόσο, ο test-runner υποστηρίζει πλήρως το AVX και το AVX2.
Είσαι ελεύθερος να τα χρησιμοποιήσεις.
