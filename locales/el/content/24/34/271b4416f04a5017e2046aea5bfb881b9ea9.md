# Οδηγίες

Ο Larry είναι ένας Lisp Alien που του αρέσει να γράφει κώδικα για να παίζει παιχνίδια.
Σήμερα θέλει να γράψει μερικές συναρτήσεις για να τον βοηθήσουν με ένα παιχνίδι που μοιάζει πολύ με το τρίλιζα.

Όπως το τρίλιζα, αυτό το παιχνίδι παίζεται σε ένα ταμπλό που είναι ένα πλέγμα 3x3.

## 1. Ξεκινώντας από το μηδέν

Πρώτα ο Larry χρειάζεται μια συνάρτηση για να φτιάξει ένα κενό ταμπλό, τη `make-empty-board`.
Όλα τα κελιά του ταμπλό θα πρέπει να είναι `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Ξεκινώντας από ένα υπάρχον ταμπλό

Στη συνέχεια ο Larry χρειάζεται μια συνάρτηση για να φτιάξει ένα ταμπλό από μια λίστα με σειρές.
Για παράδειγμα:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Συνθήκη νίκης

Αν υπάρχει περίπτωση όπου υπάρχουν 3 ίδια σύμβολα σε μια σειρά, τότε αυτός ο παίκτης έχει κερδίσει.
Ο Larry θα χρειαστεί μια συνάρτηση, τη `all-the-same-p`, η οποία, δεδομένου ενός πίνακα με 3 στοιχεία, θα αξιολογείται σε `T` αν όλα τα στοιχεία είναι το ίδιο σύμβολο.
(Η `eq` μπορεί να χρησιμοποιηθεί για να προσδιορίσει αν δύο σύμβολα είναι τα ίδια.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. Σε μια σειρά

Τώρα ο Larry χρειάζεται έναν τρόπο να πάρει τα στοιχεία μιας σειράς.
Η συνάρτηση `row` θα παίρνει ένα ταμπλό και έναν αριθμό σειράς και θα πρέπει να επιστρέφει έναν πίνακα με τα στοιχεία αυτής της σειράς.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. Σε μια στήλη

Τέλος, ο Larry χρειάζεται έναν τρόπο να πάρει τα στοιχεία μιας στήλης.
Η συνάρτηση `column` θα παίρνει ένα ταμπλό και έναν αριθμό στήλης και θα πρέπει να επιστρέφει έναν πίνακα με τα στοιχεία αυτής της στήλης.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
