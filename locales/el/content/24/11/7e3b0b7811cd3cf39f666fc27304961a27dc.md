# Εισαγωγή

## Αποδόμηση πίνακα

Το συντακτικό αποδόμησης πίνακα της JavaScript είναι ένας σύντομος τρόπος να εξάγεις τιμές από έναν πίνακα και να τις εκχωρήσεις σε ξεχωριστές μεταβλητές.

Σε αυτό το παράδειγμα, κάθε τιμή του πίνακα `numberOfMoons` εκχωρείται στον αντίστοιχο πλανήτη:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```

Με λίγα λόγια:

- Το συντακτικό σου επιτρέπει να ονομάσεις στοιχεία ενός πίνακα με βάση τη _θέση_ τους, καθώς και να εναλλάξεις μεταβλητές μέσω επανεκχώρησης.
- Το συντακτικό αποδόμησης είναι διαθέσιμο μέσα σε παραμέτρους συνάρτησης, και είναι διαθέσιμο σε οποιοδήποτε επαναλήψιμο.
- Αν αφήσεις μια θέση χωρίς όνομα (μη γράφοντας _κανένα_ όνομα μεταβλητής), αυτή η θέση αγνοείται σιωπηλά.

## Αποδόμηση αντικειμένου

Στη JavaScript υπάρχει επίσης συντακτικό αποδόμησης για να εξάγεις ιδιότητες από ένα αντικείμενο και να τις εκχωρήσεις σε ξεχωριστές μεταβλητές.

Σε αυτό το παράδειγμα, σύμβολα καιρού εξάγονται από το αντικείμενο `weather`:

```javascript
const weather = {
  sun: '☀️',
  sun_behind_small_cloud: '🌤️',
  sun_behind_cloud: '⛅',
  sun_behind_large_cloud: '🌥️',
  sun_behind_rain_cloud: '🌦️',
  cloud: '☁️',
  cloud_with_rain: '🌧️',
  cloud_with_snow: '🌨️',
  cloud_with_lightning: '🌩️',
  cloud_with_lightning_and_rain: '⛈️',
};

const { sun, cloud, cloud_with_lightning: thunder } = weather;

sun;
// => '☀️'

cloud;
// => '☁️'

thunder;
// => '🌩️'
```

Με λίγα λόγια:

- Το συντακτικό σου επιτρέπει και να εξάγεις ιδιότητες και να τις εξάγεις δίνοντάς τους νέο όνομα.
- Το συντακτικό αποδόμησης είναι διαθέσιμο μέσα σε παραμέτρους συνάρτησης.
