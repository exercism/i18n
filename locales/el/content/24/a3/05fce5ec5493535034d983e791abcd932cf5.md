# Εισαγωγή

Καθώς η Clojure είναι μια συναρτησιακή γλώσσα, οι συναρτήσεις της είναι πολίτες πρώτης κατηγορίας. Αυτό σημαίνει ότι μπορούν να περαστούν σε άλλες συναρτήσεις και να παραχθούν από αυτές, ακριβώς όπως τα δεδομένα. Η Clojure ειδικότερα συνοδεύεται από ένα πλούσιο σύνολο συναρτήσεων υψηλότερης τάξης που παράγουν νέες συναρτήσεις με βάση υπάρχουσες. Θα εξετάσουμε εδώ τέσσερις σημαντικές περιπτώσεις: `partial`, `comp`, `memoize` και `juxt`. Αυτές οι συναρτήσεις που παράγουν συναρτήσεις ανήκουν σε μια ευρύτερη κατηγορία συναρτήσεων υψηλότερης τάξης, όπως οι `map`, `reduce`, `apply`, `complement`, για να αναφέρουμε μερικές, οι οποίες λειτουργούν πάνω σε υπάρχουσες συναρτήσεις.

## partial

Γενικά, δίνοντας μια υπάρχουσα συνάρτηση `my-function`, με παραμέτρους `p1, p2, ..., pN`, μπορούμε να καθηλώσουμε μερικές από τις παραμέτρους της `p1, p2, ..., pM` ώστε να έχουν σταθερές τιμές `v1, v2, ..., vM`. Αυτό το κάνουμε εφαρμόζοντας το `partial` ως εξής: `(partial my-function v1 v2 ... vM)`. 

Το αποτέλεσμα είναι μια νέα συνάρτηση που εφαρμόζει την αρχική `my-function` καθηλώνοντας `p1=v1, p2=v2, ..., pM=vM`. Η νέα μας συνάρτηση παίρνει ως είσοδο τις υπόλοιπες παραμέτρους `pM+1, pM+2, ..., pN`, των οποίων οι τιμές δεν έχουν δοθεί κατά την εφαρμογή του `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Ως απλό παράδειγμα, ας ορίσουμε μια συνάρτηση `inc-by-9` που αυξάνει κατά 9, ένα σταθερό ποσό, ό,τι κι αν της δώσουμε. Θα μπορούσαμε να υλοποιήσουμε μια τέτοια συνάρτηση ως εξής:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Ως δεύτερο παράδειγμα, έχουμε μια συνάρτηση `generic-greetings` που χρησιμοποιεί το όνομα του ατόμου που θέλουμε να χαιρετήσουμε μαζί με ένα αρχικό και ένα τελικό μήνυμα:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Και χρησιμοποιούμε το `partial` ώστε να έχουμε πάντα ένα συγκεκριμένο μήνυμα χαιρετισμού:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

Το `comp` μπορεί να χρησιμοποιηθεί για να δημιουργήσουμε τη σύνθεση οποιουδήποτε αριθμού συναρτήσεων θέλουμε να συνθέσουμε. Γενικά, η σύνθεση `N` συναρτήσεων `f1, f2, ..., fN` σημαίνει την εφαρμογή αυτών των συναρτήσεων με διαδοχική σειρά, περνώντας την έξοδο της προηγούμενης συνάρτησης στην επόμενη. Στον μαθηματικό συμβολισμό αυτό εκφράζεται ως:

```
f1 (f2 (... fN(x)))
```

Στη Clojure, αυτό είναι ισοδύναμο με το να κάνουμε:
```clojure
(f1 (f2 (... (fN x))))
```

Χρησιμοποιώντας το comp, μπορούμε να δημιουργήσουμε μια νέα συνάρτηση που εκτελεί αυτή τη σύνθεση για εμάς:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Ως παράδειγμα, ας πούμε ότι θέλουμε να αθροίσουμε μια σειρά αριθμών και μετά να πολλαπλασιάσουμε το αποτέλεσμα επί 6. Μπορούμε να το κάνουμε ως εξής:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

Το `memoize` επιτρέπει την επαναχρησιμοποίηση προηγουμένως υπολογισμένων αποτελεσμάτων που σχετίζονται με μια δεδομένη είσοδο. Με την ίδια είσοδο, η *memoized* συνάρτηση επιστρέφει το ίδιο αποτέλεσμα χωρίς να χρειάζεται να το υπολογίσει ξανά. Εκμεταλλεύεται το γεγονός ότι οι συναρτήσεις της `clojure` είναι, από προεπιλογή, *αναφορικά διαφανείς*: με την ίδια είσοδο παράγουν πάντα την ίδια έξοδο, γεγονός που καθιστά εύκολη την επαναχρησιμοποίηση προηγούμενων υπολογισμών. 

Για να δούμε πώς λειτουργεί αυτό, ας χρησιμοποιήσουμε μια τεχνητή περίπτωση όπου η συνάρτηση κοιμάται για δύο δευτερόλεπτα πριν παράγει την έξοδο, ώστε να μπορούμε εύκολα να συγκρίνουμε τον *χρόνο υπολογισμού* πριν και μετά τη χρήση του `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

Το `juxt` παράγει μια συνάρτηση που εφαρμόζει, με σειρά από αριστερά προς τα δεξιά, τις συναρτήσεις που της περνάμε. Το αποτέλεσμα είναι ένα διάνυσμα με τα επιμέρους αποτελέσματα κάθε συνάρτησης ως συνιστώσες του διανύσματος: 

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Ως απλό παράδειγμα, παράγουμε μια συνάρτηση που υπολογίζει το γινόμενο του x με διαδοχικούς παράγοντες, από το 2 έως το 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
