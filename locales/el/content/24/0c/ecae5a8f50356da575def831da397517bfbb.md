# Εισαγωγή

Οι ακέραιοι μπορούν να θεωρηθούν όχι μόνο ως αριθμητικές τιμές, αλλά και ως μοτίβα από μπιτ. Το λεξιλόγιο [`math`][math] της Factor έχει τις τυπικές πράξεις χαμηλού επιπέδου πάνω σε αυτά τα μοτίβα μπιτ, και το λεξιλόγιο [`math.bitwise`][bitwise] προσθέτει μερικές βοηθητικές συναρτήσεις για την εργασία με τιμές σταθερού πλάτους.

## Μετατοπίσεις μπιτ

Το `shift ( m n -- m' )` μετατοπίζει τα μπιτ του `m`. Ένα *θετικό* `n` μετατοπίζει προς τα αριστερά (πολλαπλασιάζοντας επί 2 σε κάθε βήμα), ενώ ένα *αρνητικό* `n` μετατοπίζει προς τα δεξιά (διαιρώντας διά 2 σε κάθε βήμα):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

Για θετικούς ακέραιους, η μετατόπιση προς τα δεξιά απορρίπτει μπιτ από το κάτω μέρος και γεμίζει με μηδενικά. Για *αρνητικούς* ακέραιους, το `shift` της Factor είναι αριθμητικό: διατηρεί το μπιτ προσήμου, γεμίζοντας εννοιολογικά από τα αριστερά με αντίγραφα του μπιτ προσήμου. (Οι ακέραιοι της Factor έχουν αυθαίρετη ακρίβεια, οπότε "τα αριστερά" εκτείνονται όσο χρειάζεται.)

## Λογική σε επίπεδο μπιτ

Οι τέσσερις βασικές λογικές πράξεις είναι:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

Το `bitnot` του `0b1011` είναι `-12` επειδή οι ακέραιοι της Factor έχουν αυθαίρετη ακρίβεια: η αναστροφή των μπιτ του `0b1011` είναι εννοιολογικά "όλοι άσσοι με τα χαμηλά τέσσερα να έχουν γίνει `0100`", το οποίο, διαβασμένο ως προσημασμένος μεγάλος ακέραιος, είναι `-12`.

## Αντιμετώπιση μιας τιμής ως N μπιτ

Το `bits ( x n -- y )` από το `math.bitwise` κάνει μάσκα στο `x` ώστε να κρατήσει τα χαμηλά `n` μπιτ του. Αυτός είναι ο τρόπος της Factor για να "επανερμηνεύσεις μια τιμή ως έναν ακέραιο N μπιτ χωρίς πρόσημο":

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Αυτό το δεύτερο παράδειγμα έχει σημασία για αυτή την άσκηση. Αν ξεκινήσεις με μια αρνητική τιμή Int32 σε συμπλήρωμα ως προς δύο και θέλεις να τη μετατοπίσεις δεξιά "λογικά" (γέμισμα με μηδενικά από τα αριστερά) κατά `amount`, το ιδίωμα της Factor είναι:

```
( value -- shifted )
32 bits  amount neg  shift
```

Κάνε πρώτα μάσκα στα 32 μπιτ για να περάσεις στην ερμηνεία χωρίς πρόσημο και μετά μετατόπισε. Επειδή η τιμή μετά τη μάσκα είναι μη αρνητική, το `shift` απλώς απορρίπτει μπιτ από το κάτω μέρος και συμπληρώνει με μηδενικά.
