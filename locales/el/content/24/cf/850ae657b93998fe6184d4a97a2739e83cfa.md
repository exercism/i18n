# Εισαγωγή

Η δυναμική μνήμη υλοποιείται από συναρτήσεις βιβλιοθήκης που ο προγραμματιστής χρησιμοποιεί για να δεσμεύει και να αποδεσμεύει μνήμη κατά την εκτέλεση του προγράμματος.
Εφόσον ο προγραμματιστής ελέγχει τη δέσμευση και την αποδέσμευση της μνήμης, η δυναμική μνήμη είναι τόσο ασφαλής όσο είναι απαλλαγμένος από ανθρώπινα σφάλματα ο προγραμματιστής.
Για τον λόγο αυτό, η δυναμική μνήμη είναι μία από τις κυριότερες πηγές bugs στον προγραμματισμό και ένας από τους βασικούς στόχους επιθέσεων χάκερ.

## malloc

Το `malloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται για τη δέσμευση δυναμικής μνήμης.
Αν η δέσμευση πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της δεσμευμένης μνήμης.
Αν η δέσμευση δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα του `malloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Ο δείκτης που επιστρέφεται είναι τύπου `pointer-to-void`, ο οποίος μπορεί χοντρικά να θεωρηθεί ως ένας "γενικός" δείκτης που μπορεί να μετατραπεί στον συγκεκριμένο τύπο που χρησιμοποιεί η μνήμη.
Το `malloc` έχει μία παράμετρο, το μέγεθος της επιθυμητής μνήμης σε byte.
Το συνολικό μέγεθος για τη δέσμευση ενός πίνακα είναι το μέγεθος του τύπου δεδομένων κάθε στοιχείου επί τον αριθμό των στοιχείων.
Ο τελεστής `sizeof` χρησιμοποιείται συνήθως για να πάρεις το μέγεθος του τύπου δεδομένων κάθε στοιχείου.
Το παρακάτω παράδειγμα το δείχνει αυτό

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Είναι σημαντικό να θυμάσαι ότι η μνήμη που δεσμεύει το `malloc` δεν αρχικοποιείται, αλλά μπορεί να περιέχει τυχαίες τιμές.
Σημείωσε ότι το `sizeof` του δείκτη `numbers` δεν είναι ο αριθμός των στοιχείων του πίνακα ούτε το συνολικό ποσό μνήμης που δεσμεύτηκε.
Το μέγεθος του δείκτη που επιστρέφει το `malloc` είναι το μέγεθος οποιουδήποτε δείκτη σε αυτό το συγκεκριμένο σύστημα.
Ο κώδικας του παραδείγματος εκτελέστηκε σε σύστημα 64 bit, οπότε το μέγεθος του δείκτη ήταν 8 byte (επί 8 bit ανά byte = 64 bit).
Ο τύπος του δείκτη μετατράπηκε έμμεσα από pointer-to-void σε pointer-to-int.
Θα μπορούσε επίσης να έχει μετατραπεί ρητά ως εξής: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Αν η τιμή (ή οι τιμές) πρόκειται οπωσδήποτε να γραφτεί πριν διαβαστεί, τότε η χρήση του `malloc` μπορεί να είναι αποδοτικός τρόπος δέσμευσης μνήμης.
Αν όμως υπάρχει πιθανότητα η τιμή (ή οι τιμές) να διαβαστεί πριν αρχικοποιηθεί, τότε η χρήση του `malloc` είναι ριψοκίνδυνη.
Ένας ασφαλέστερος τρόπος δέσμευσης μνήμης είναι η χρήση του `calloc`, το οποίο αρχικοποιεί σε μηδέν τη νεοδεσμευμένη μνήμη.

Σημείωσε στα παραπάνω παραδείγματα ότι χρησιμοποιήθηκε το `free(numbers)`.

## free

Το `free` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται για την αποδέσμευση μνήμης που έχει δεσμευτεί δυναμικά.
Η δυναμικά δεσμευμένη μνήμη παραμένει κατειλημμένη στη μνήμη μέχρι να την αποδεσμεύσει το `free`.
Κάποια λειτουργικά συστήματα μπορεί να αποδεσμεύουν αυτόματα τη δυναμικά δεσμευμένη μνήμη όταν τελειώνει το πρόγραμμα, αλλά είναι καλή πρακτική να μην βασίζεσαι σε αυτό.
Το `free` έχει μία παράμετρο, έναν δείκτη στη μνήμη που δεσμεύτηκε δυναμικά.
Ένας δείκτης που δεν ορίζεται σε `NULL` αφού αποδεσμευτεί ονομάζεται dangling pointer.
Ένας dangling pointer μπορεί να δείχνει σε άλλη μνήμη από αυτήν για την οποία προοριζόταν.
Έτσι, ένας dangling pointer μπορεί να οδηγήσει σε αλλοίωση δεδομένων και σε αυθαίρετη αντικατάσταση και εκτέλεση κώδικα.
Ένας δείκτης σε δεσμευμένη μνήμη που δεν έχει καθαριστεί με ορισμό σε `NULL` μπορεί να χρησιμοποιηθεί για να παραβιαστεί το πρόγραμμα.
Είναι καλή πρακτική να ορίζεις έναν δείκτη σε `NULL` αφού τον περάσεις στο `free`.

## calloc

Το `calloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται και για τη δέσμευση δυναμικής μνήμης και για την αρχικοποίηση της νεοδεσμευμένης μνήμης σε μηδέν.
Αν η δέσμευση πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της δεσμευμένης μνήμης.
Αν η δέσμευση δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα του `calloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Ο δείκτης που επιστρέφεται είναι τύπου `pointer-to-void`, ο οποίος μπορεί χοντρικά να θεωρηθεί ως ένας "γενικός" δείκτης που μπορεί να μετατραπεί στον συγκεκριμένο τύπο που χρησιμοποιεί η μνήμη.
Το `calloc` έχει δύο παραμέτρους.
Η πρώτη παράμετρος δηλώνει πόσα στοιχεία του συγκεκριμένου τύπου δεδομένων θα δεσμευτούν.
Η δεύτερη παράμετρος δηλώνει το μέγεθος του συγκεκριμένου τύπου δεδομένων που θα δεσμευτεί.

Στο παρακάτω παράδειγμα όλες οι εντολές `printf` θα πρέπει να δείχνουν πάντα `0`, αφού το `calloc` εγγυημένα μηδενίζει τις νεοδεσμευμένες τιμές.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

Το `realloc` είναι μια συνάρτηση που δηλώνεται στο `stdlib.h` και χρησιμοποιείται είτε για να επεκτείνει είτε για να συρρικνώσει υπάρχουσα δεσμευμένη μνήμη.
Αν η ανακατανομή πετύχει, επιστρέφεται ένας δείκτης που δείχνει στη διεύθυνση του πρώτου byte της μνήμης μετά την ανακατανομή.
Αν η ανακατανομή δεν πετύχει, επιστρέφεται `NULL`.
Είναι συνετό να ελέγχεις το αποτέλεσμα του `realloc` για `NULL` και να το χειρίζεσαι ομαλά αν αποτύχει.
Το `realloc` έχει δύο παραμέτρους.
Η πρώτη παράμετρος είναι ένας δείκτης στην υπάρχουσα μνήμη που θα ανακατανεμηθεί.
Η δεύτερη παράμετρος είναι το μέγεθος σε byte της μνήμης μετά την ανακατανομή.
Οι τιμές που είχαν οριστεί πριν από την επέκταση της μνήμης διατηρούνται.
Είναι σημαντικό να θυμάσαι ότι η μνήμη που προστίθεται όταν επεκτείνεις τη μνήμη δεν αρχικοποιείται σε μηδέν και οι τιμές της μπορεί να είναι οτιδήποτε.
Επίσης, η μνήμη που αφαιρείται όταν συρρικνώνεις τη μνήμη δεν αρχικοποιείται και μπορεί να διατηρεί τις τιμές της.
Το παρακάτω παράδειγμα δείχνει την επέκταση και τη συρρίκνωση ενός πίνακα

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
