# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να εκτυπώνεις σήματα με ονόματα για τους υπαλλήλους ενός εργοστασίου.

## 1. Εκτύπωσε ένα σήμα για έναν υπάλληλο

Οι υπάλληλοι έχουν ένα αναγνωριστικό, όνομα και όνομα τμήματος. Οι ετικέτες των σημάτων των υπαλλήλων έχουν την εξής μορφή: `"[id] - name - DEPARTMENT"`.
Υλοποίησε τη μέθοδο `Badge.print()` ώστε να επιστρέφει την ετικέτα σήματος ενός υπαλλήλου:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Σημείωσε ότι το τμήμα πρέπει να είναι γραμμένο με κεφαλαία στην ετικέτα.

## 2. Εκτύπωσε ένα σήμα για έναν νέο υπάλληλο

Λόγω μιας ιδιοτροπίας του υπολογιστικού συστήματος, οι νέοι υπάλληλοι μερικές φορές δεν έχουν ακόμη αναγνωριστικό όταν ξεκινούν να εργάζονται στο εργοστάσιο.
Καθώς τα σήματα είναι υποχρεωτικά, θα λαμβάνουν ένα προσωρινό σήμα χωρίς το πρόθεμα αναγνωριστικού. Τροποποίησε τη μέθοδο `Badge.print()` ώστε να υποστηρίζει νέους υπαλλήλους που δεν έχουν ακόμη αναγνωριστικό:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Εκτύπωσε ένα σήμα για τον ιδιοκτήτη

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει σήμα συνεχώς.
Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα. Σε αυτή την περίπτωση, η ετικέτα πρέπει να εκτυπώνει `"OWNER"` αντί για το όνομα του τμήματος.
Τροποποίησε τη μέθοδο `Badge.print()` ώστε να εκτυπώνει μια ετικέτα για τον ιδιοκτήτη:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Σημείωσε ότι είναι πιθανό ο ιδιοκτήτης να είναι και νέος υπάλληλος:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
