# Οδηγίες

Η Mecha Munch™, μια εταιρεία που αυτοματοποιεί τις αγορές τροφίμων, μόλις σε προσέλαβε για να δουλέψεις στην εφαρμογή παραγγελιών της.
Η ομάδα σου έχει αναλάβει να φτιάξει ένα MVP (_[ελάχιστο βιώσιμο προϊόν][mvp]_) που διαχειρίζεται όλες τις βασικές λειτουργίες του καλαθιού αγορών, επιτρέποντας στους χρήστες να προσθέτουν, να αφαιρούν και να ταξινομούν τις παραγγελίες τροφίμων τους.
Ευτυχώς, μια άλλη ομάδα αναλαμβάνει όλα τα ζητήματα με τα χρήματα και την ολοκλήρωση της παραγγελίας!

## 1. Προσθήκη προϊόντων στο καλάθι αγορών του χρήστη

Το MVP πρέπει να επιτρέπει στον χρήστη να προσθέτει προϊόντα στο καλάθι αγορών του.
Αυτό μπορεί να είναι ένα μεμονωμένο προϊόν ή πολλά προϊόντα μαζί.
Επειδή πρόκειται για MVP, η ποσότητα του προϊόντος δηλώνεται με _επαναλήψεις_.
Αν ένας χρήστης θέλει να προσθέσει 2 Πορτοκάλια, το "Oranges" θα εμφανίζεται δύο φορές στο iterable εισόδου.
Αν ο χρήστης έχει ήδη το προϊόν στο καλάθι του, η ποσότητα στο καλάθι πρέπει να αυξηθεί κατά 1.
Αν το προϊόν είναι _νέο_ στο καλάθι, πρέπει να προστεθεί με ποσότητα 1.

Δημιούργησε τη συνάρτηση `add_items!(<cart>, <items>)`, που παίρνει ως ορίσματα ένα λεξικό για το καλάθι και ένα iterable με τα προϊόντα προς προσθήκη.
Πρέπει να επιστρέφει το ενημερωμένο λεξικό του καλαθιού αγορών για τον χρήστη.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Ενημέρωση της ενότητας "Ιδέες" για συνταγές

Η εφαρμογή έχει μια ενότητα "ιδέες" που είναι γεμάτη με έτοιμες συνταγές από διάφορες κουζίνες.
Ο χρήστης μπορεί να διαλέξει οποιαδήποτε από αυτές τις συνταγές και να προστεθούν αυτόματα όλα τα υλικά της στο καλάθι αγορών του.
Ο υπεύθυνος του έργου σου ζήτησε να δημιουργήσεις έναν τρόπο για να επεξεργάζεσαι αυτές τις συνταγές της ενότητας "ιδέες", αφού η ομάδα περιεχομένου αλλάζει συνεχώς υλικά και ποσότητες.

Δημιούργησε τη συνάρτηση `update_recipes!(<ideas>, <updates>)`, που παίρνει ως ορίσματα ένα λεξικό "ιδεών" και ένα λεξικό με ενημερώσεις συνταγών.

## 3. Αποστολή του καλαθιού αγορών του χρήστη στο κατάστημα για εκτέλεση της παραγγελίας

Η εφαρμογή χρειάζεται να στέλνει το καλάθι ενός χρήστη στο κατάστημα για εκτέλεση της παραγγελίας.
Ωστόσο, όσοι συλλέγουν τα προϊόντα στο κατάστημα πρέπει να ξέρουν πού βρίσκεται το κάθε προϊόν, μέσω ενός μοναδικού κωδικού διαδρόμου.
Το "καλάθι εκτέλεσης παραγγελίας" πρέπει να είναι ταξινομημένο με βάση τους κωδικούς διαδρόμου των προϊόντων, ώστε να βοηθά όσους συλλέγουν τα προϊόντα να είναι πιο αποδοτικοί.

Δημιούργησε τη συνάρτηση `send_to_store(<cart>, <aislecodes>)`, που παίρνει το καλάθι αγορών ενός χρήστη και ένα λεξικό με τους αριθμούς διαδρόμου του καταστήματος.
Η συνάρτηση πρέπει να επιστρέφει ένα συνδυασμένο "καλάθι εκτέλεσης παραγγελίας" που περιέχει ένα ζεύγος `aislecode => quantity` για κάθε προϊόν που παραγγέλνει ο πελάτης.
Τα προϊόντα πρέπει να εμφανίζονται με τη σειρά των κωδικών διαδρόμου τους.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Ενημέρωση του αποθέματος του καταστήματος ώστε να αντικατοπτρίζει ό,τι παρήγγειλε ο χρήστης.

Η εφαρμογή δεν μπορεί απλώς να καταχωρεί παραγγελίες πελατών χωρίς τέλος.
Κάποια στιγμή, το κατάστημα θα ξεμείνει από διάφορα προϊόντα.
Έτσι, το MVP της εφαρμογής σου πρέπει να ενημερώνει το απόθεμα του καταστήματος κάθε φορά που ένας χρήστης στέλνει την παραγγελία του στο κατάστημα.
Διαφορετικά, οι πελάτες θα παραγγέλνουν προϊόντα που δεν είναι στην πραγματικότητα διαθέσιμα.

Δημιούργησε τη συνάρτηση `update_store_inventory!(<inventory>, <cart>)`, που παίρνει ένα `cart` και ένα `inventory`.
Η συνάρτηση πρέπει να μειώνει τις ποσότητες του αποθέματος του καταστήματος κατά τον αριθμό που "παραγγέλθηκε" στο "cart" και μετά να επιστρέφει ένα λεξικό με όσα προϊόντα έχουν εξαντληθεί (δηλαδή έχουν φτάσει στο `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Νέα παραγγελία για τα εξαντλημένα προϊόντα.

Πέρα από την ενημέρωση του αποθέματος, η εφαρμογή σου μπορεί να βοηθήσει και στην αναπλήρωσή του.
Το MVP σου πρέπει να μπορεί να ετοιμάζει μια μίνι παραγγελία με όσα προϊόντα έχουν εξαντληθεί μετά την παραγγελία ενός πελάτη.
Αυτό θα κάνει πιο απλή την ενεργοποίηση μιας μεγάλης παραγγελίας.
Επιπλέον, μερικές φορές υπάρχουν προϊόντα προσφοράς περιορισμένου χρόνου που δεν βρίσκονται στη λίστα αποθέματος.
Αν αυτά εξαντληθούν πριν τελειώσει η περίοδος προσφοράς, σημαίνει ότι ήταν δημοφιλή και μπορούν να προστεθούν στη λίστα αποθέματος.

Δημιούργησε τη συνάρτηση `reorder!(<outofstock>, <stock>)`, που παίρνει `outofstock` και `stock`.
Το λεξικό `stock` περιέχει τα συνήθη είδη αποθέματος και τις ποσότητες αναπαραγγελίας τους.
Το λεξικό `outofstock` είναι το αποτέλεσμα της `update_store_inventory!`, δηλαδή ένα λεξικό με προϊόντα μηδενικής ποσότητας.
Οι ποσότητες του `outofstock` πρέπει να ενημερωθούν ώστε να αντικατοπτρίζουν αυτές του `stock` και να επιστραφούν.
Επίσης, όσα προϊόντα υπάρχουν στο `outofstock` αλλά όχι στο `stock` πρέπει να προστεθούν στο `stock` με προεπιλεγμένη ποσότητα `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
