# Εισαγωγή

Οι κατανοήσεις προσφέρουν έναν μηχανισμό για να μετασχηματίζεις _Enumerable_ με εύκολο και δηλωτικό τρόπο.

Για να δηλώσεις μια πολύ απλή κατανόηση, μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `for`, ακολουθούμενη από μια _γεννήτρια_ και ένα _μπλοκ do_ που δημιουργεί τις νέες τιμές από τις απαριθμούμενες τιμές.

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

Οι κατανοήσεις μπορούν επίσης να έχουν _φίλτρα_. Οι τιμές που δεν περνούν το φίλτρο αφαιρούνται από την τελική λίστα:

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

Μπορείς να δηλώσεις πιο σύνθετες κατανοήσεις σε πολλές γραμμές:

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

Ένα _καρτεσιανό γινόμενο_ μπορεί να δημιουργηθεί με πολλαπλές γεννήτριες. Αυτό σημαίνει ότι κάθε τιμή που παράγει η πρώτη γεννήτρια θα ζευγαρώσει μία φορά με κάθε τιμή που παράγει η δεύτερη γεννήτρια:

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
