# Μπουτίκ Μόδας

## Ιστορία

Διατηρείς μια online μπουτίκ μόδας. Η Black Friday πλησιάζει, οπότε πρέπει να κάνεις απογραφή στο απόθεμά σου για να σιγουρευτείς ότι όλα είναι έτοιμα.

Κάθε μεμονωμένο είδος του αποθέματος αναπαρίσταται από ένα map/λεξικό, και ολόκληρο το απόθεμα είναι μία λίστα/ένας πίνακας από τέτοια map/λεξικά.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Εργασίες

- Ταξινόμησε τα είδη κατά τιμή
- Βρες όλα τα είδη με τιμές που λείπουν
- Αύξησε την ποσότητα του είδους
- Υπολόγισε τη συνολική ποσότητα του είδους
