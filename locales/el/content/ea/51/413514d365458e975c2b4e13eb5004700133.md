# Γενικοί Τύποι Δεδομένων

Οι γενικοί τύποι στη Cairo σου επιτρέπουν να γράφεις επαναχρησιμοποιήσιμο κώδικα που λειτουργεί με διάφορους τύπους, αποφεύγοντας τη διπλοτυπία και ενισχύοντας τη συντηρησιμότητα.

Μπορείς να χρησιμοποιείς γενικούς τύπους με συναρτήσεις, struct, enum, trait και μεθόδους.

## Γενικές Συναρτήσεις

Μια γενική συνάρτηση λειτουργεί με διαφορετικούς τύπους χωρίς να χρειάζεται ξεχωριστές υλοποιήσεις.

Για παράδειγμα:

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Εδώ, το `T` είναι ένα σύμβολο κράτησης θέσης για οποιονδήποτε τύπο.

Ωστόσο, η Cairo απαιτεί όρια trait για να διασφαλίσει ότι ο γενικός τύπος πληροί συγκεκριμένες προϋποθέσεις.

Αν το `T` πρέπει να υποστηρίζει το `Drop`, μπορούμε να ενημερώσουμε την υπογραφή:

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Τα όρια trait, όπως το `Drop` ή το `PartialOrd`, προσθέτουν περιορισμούς στους γενικούς τύπους για συγκεκριμένες λειτουργίες.

## Ανώνυμοι Περιορισμοί

Αν μια υλοποίηση trait δεν χρησιμοποιείται άμεσα σε μια συνάρτηση, μπορείς να γράψεις ανώνυμους περιορισμούς χρησιμοποιώντας το `+`:

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

Έτσι αποφεύγεις να ονομάζεις trait όπως το `TPartialOrd`, μειώνοντας τη φλυαρία.

## Struct με Γενικούς Τύπους

Οι γενικοί τύποι στα struct επιτρέπουν στα πεδία να είναι ευέλικτα.

Για παράδειγμα:

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

Αν ένα struct χρειάζεται πολλούς γενικούς τύπους, πρόσθεσε απλώς περισσότερα σύμβολα κράτησης θέσης:

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## Enum με Γενικούς Τύπους

Και τα enum μπορούν να περιέχουν γενικούς τύπους δεδομένων.

Για παράδειγμα:

```rust
enum Option<T> {
    Some: T,
    None,
}
```

Το enum `Option<T>` μπορεί να αναπαραστήσει μια προαιρετική τιμή οποιουδήποτε τύπου.

Παρομοίως, το `Result<T, E>` σου επιτρέπει να ορίζεις τύπους επιτυχίας και αποτυχίας:

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## Γενικές Μέθοδοι

Και οι μέθοδοι μπορούν να χρησιμοποιούν γενικούς τύπους.

Για παράδειγμα:

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

Μπορείς επίσης να ορίσεις μεθόδους για συγκεκριμένους γενικούς τύπους, όπως το `Wallet<u128>`:

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## Ανάμειξη Γενικών Τύπων

Οι γενικοί τύποι μπορούν να χειριστούν σύνθετους συνδυασμούς.

Για παράδειγμα, συνδυάζοντας δύο στιγμιότυπα `Wallet` διαφορετικών τύπων:

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

Προσθέτοντας περιορισμούς `+Drop`, ο μεταγλωττιστής διασφαλίζει τον σωστό χειρισμό των πόρων.

Οι γενικοί τύποι είναι ισχυροί, αλλά απαιτούν προσεκτική διαχείριση των περιορισμών.

Χρησιμοποίησέ τους για να γράφεις επαναχρησιμοποιήσιμο, ανεξάρτητο από τον τύπο και σύντομο κώδικα.
