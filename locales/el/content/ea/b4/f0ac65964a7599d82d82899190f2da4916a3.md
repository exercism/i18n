# Προσθήκη στις οδηγίες

## Πώς είναι δομημένη αυτή η άσκηση στην Python


Η Python προσφέρει πλήθος μαθηματικών συναρτήσεων με τη μορφή του [math module][math-module] και ενσωματωμένων συναρτήσεων, όπως ο τελεστής ύψωσης σε δύναμη `**`, η [`pow()`][pow] και η [`sum()`][sum].
Ωστόσο, θα θέλαμε να σκεφτείς την πρόκληση να λύσεις αυτή την άσκηση χωρίς αυτές τις ενσωματωμένες συναρτήσεις ή τα modules.

Ενώ υπάρχει ένας μαθηματικός τύπος που βρίσκει την τετραγωνική ρίζα _οποιουδήποτε_ αριθμού, εμείς επιλέξαμε να έχουμε ως λύσεις μόνο [φυσικούς αριθμούς][nautral-number] (θετικούς ακέραιους).  
Είναι δυνατόν να υπολογίσεις την τετραγωνική ρίζα οποιουδήποτε φυσικού αριθμού χρησιμοποιώντας μόνο φυσικούς αριθμούς στον υπολογισμό.


[math-module]: https://docs.python.org/3/library/math.html
[pow]: https://docs.python.org/3/library/functions.html#pow
[sum]: https://docs.python.org/3/library/functions.html#sum
[nautral-number]: https://en.wikipedia.org/wiki/Natural_number
