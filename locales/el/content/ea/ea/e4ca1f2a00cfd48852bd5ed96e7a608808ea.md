# Εισαγωγή

Μια εντολή `switch` αξιολογεί μια έκφραση και εκτελεί το πρώτο `case` που ταιριάζει με την τιμή της.
Είναι συχνά μια πιο καθαρή εναλλακτική σε μεγάλες αλυσίδες `if ... else if`.
Για παράδειγμα,

```go
operatingSystem := "windows"

if operatingSystem == "windows" {
    // do something if the operating system is windows
} else if operatingSystem == "linux" {
    // do something if the operating system is linux
} else if operatingSystem == "macos" {
    // do something if the operating system is macos
} else {
    // do something if the operating system is none of the above
}
```

μπορεί να ξαναγραφτεί ως:

```go
operatingSystem := "windows"

switch operatingSystem {
case "windows":
    // do something if the operating system is windows
case "linux":
    // do something if the operating system is linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

Πολλαπλές τιμές μπορούν να ομαδοποιηθούν σε ένα μόνο `case` με ένα κόμμα.
Το `case` αυτό ταιριάζει αν η έκφραση είναι ίση με οποιαδήποτε από τις τιμές:

```go
switch operatingSystem {
case "windows", "linux":
    // do something if the operating system is windows or linux
case "macos":
    // do something if the operating system is macos
default:
    // do something if the operating system is none of the above
}
```

Η έκφραση μετά το `switch` μπορεί επίσης να παραλειφθεί εντελώς.
Κάθε `case` περιέχει τότε μια έκφραση boolean και εκτελείται το πρώτο case που είναι αληθές.

```go
age := 21

switch {
case age > 20 && age < 30:
    // do something if age is between 20 and 30
case age == 10:
    // do something if age is equal to 10
default:
    // do something else for every other case
}
```
