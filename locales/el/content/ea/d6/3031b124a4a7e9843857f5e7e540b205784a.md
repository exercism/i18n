# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις [τελεστές Boolean][operators] για να δουλέψεις με τιμές Boolean.
- Πολλοί τελεστές μπορούν να συνδυαστούν σε μία μόνο έκφραση.

## 1. Έλεγξε αν μπορεί να γίνει γρήγορη επίθεση

- Οι [τελεστές Boolean][operators] μπορούν επίσης να εφαρμοστούν σε παραμέτρους Boolean.

[operators]: https://haxe.org/manual/expression-operators-binops.html
