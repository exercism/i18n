# Υποδείξεις

## Γενικά

- Το [σεμινάριο για τις συμβολοσειρές][python-str-doc] στα Python Docs δίνει μια επισκόπηση του τύπου `str` της Python.
- Οι μέθοδοι συμβολοσειρών [`str.join()`][str-join] και [`str.split()`][str-split] είναι πολύ χρήσιμες όταν επεξεργάζεσαι συμβολοσειρές.
- Η σελίδα των Python Docs για τους [τύπους ακολουθιών][common sequence operations] παρουσιάζει τις λειτουργίες που είναι κοινές σε όλες τις ακολουθίες, όπως `strings`, `lists`, `tuples` και `ranges`.

Η άσκηση έχει τέσσερις δραστηριότητες, καθεμία με ένα σύνολο κειμένου ή λέξεων για να δουλέψεις.

## 1. Πρόσθεσε ένα πρόθεμα σε μια λέξη

- Μικρές συμβολοσειρές μπορούν να συνενωθούν με τον τελεστή `+`.

## 2. Πρόσθεσε προθέματα σε ομάδες λέξεων

- Είτε το πιστεύεις είτε όχι, το [`str.join()`][str-join] είναι το μόνο που χρειάζεσαι εδώ. **Δε χρειάζεται βρόχος**.
- Τα tests θα δίνουν στη συνάρτησή σου μια `list`. Δε θα χρειαστεί να αλλάξεις αυτή τη `list` αν βρεις μια καλή συμβολοσειρά διαχωρισμού.
- Θυμήσου ότι οι συμβολοσειρές διαχωρισμού μπαίνουν ανάμεσα στα στοιχεία και τα "κολλούν" μεταξύ τους σε μία συμβολοσειρά. Τα διαχωριστικά μπαίνουν _χωρίς_ κενό, αν και μπορείς να συμπεριλάβεις χαρακτήρες κενού μέσα τους.
- Όπως το [`str.split()`][str-split], έτσι και το `str.join()` μπορεί να επεξεργαστεί μια συμβολοσειρά οποιουδήποτε μήκους, που αποτελείται από οποιαδήποτε σημεία κώδικα unicode. _Σε αντίθεση_ με το `str.split()`, μπορεί επίσης να επεξεργαστεί iterables οποιουδήποτε μήκους, όπως `list`, `tuple` και `set`.

## 3. Αφαίρεσε ένα επίθημα από μια λέξη

- Μπορείς να πάρεις χαρακτήρες από μια συμβολοσειρά με τη θέση τους ή με αποκοπή ενός τμήματος, ξεκινώντας είτε από τα αριστερά (από το 0) είτε από τα δεξιά (από το -1).
- Αν θέλεις το τελευταίο σημείο κώδικα μιας συμβολοσειράς οποιουδήποτε μήκους, μπορείς να χρησιμοποιήσεις το `[-1]`.
- Τα τρία τελευταία γράμματα μιας συμβολοσειράς μπορούν να "αποκοπούν" χρησιμοποιώντας αρνητική θέση. π.χ. `beautiful'[:-3] == 'beauti`

## 4. Απόσπασε και μετέτρεψε μια λέξη

- Η χρήση του [`str.split()`][str-split] επιστρέφει μια `list` από συμβολοσειρές που έχουν σπάσει στα κενά.
- Οι `lists` είναι ακολουθίες και μπορούν να προσπελαστούν με θέση.
- Το [`str.split()`][str-split] μπορεί να χρησιμοποιηθεί απευθείας με θέση: `'Exercism rocks!'.split()[0] == 'Exercism'`
- Πρόσεχε τη στίξη! Οι τελείες μπορούν να αφαιρεθούν με αποκοπή: `'dark.'[:-1] == 'dark'`
