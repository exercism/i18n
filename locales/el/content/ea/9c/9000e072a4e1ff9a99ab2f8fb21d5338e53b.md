# Εισαγωγή

Στην Python, [ένα enum](https://docs.python.org/3/library/enum.html) είναι ένα σύνολο από ονόματα που είναι δεσμευμένα σε μοναδικές τιμές `literal` ή `constant`. Τα enum ορίζονται με κληρονομικότητα από μια κλάση `Enum`. Οι ενσωματωμένοι τύποι enum είναι διαθέσιμοι στο module `enum` και η κλάση `Enum` μπορεί να εισαχθεί με `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Σημείωσε ότι οι τιμές των μελών του enum μπορούν να είναι οποιοσδήποτε τύπος δεδομένων, όπως str, tuple, float κ.λπ.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Όταν αναθέτεις την ίδια τιμή σε δύο μέλη ενός enum, το μέλος που ανατίθεται τελευταίο θα είναι ψευδώνυμο του πρώτου. Δεν επιτρέπεται να χρησιμοποιήσεις το ίδιο όνομα για δύο μέλη ενός enum.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Η επανάληψη στα μέλη του enum μπορεί να γίνει με την τυπική σύνταξη `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Τα μέλη του enum μπορούν να συγκριθούν χρησιμοποιώντας το [`is` (_τελεστή ταυτότητας_)](https://www.w3schools.com/python/ref_keyword_is.asp) ή το `is not`. Οι `==` ή `!=` (_τελεστές ισότητας_) λειτουργούν με τον ίδιο τρόπο.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Για να προσπελάσεις ένα μέλος του enum για μια δεδομένη τιμή, μπορείς να χρησιμοποιήσεις το `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
