# Debug

Για να σε βοηθήσει στο debugging, μπορείς να χρησιμοποιήσεις [`print` ή παρόμοιες συναρτήσεις][cl-print] για να γράψεις στην τυπική έξοδο, η οποία θα είναι ορατή στην έξοδο των tests.

Για παράδειγμα, αν προσθέσεις `(print "hello there")` μέσα στη συνάρτηση που γράφεις, θα γίνει ορατό στις εκτελέσεις των tests (εφόσον το test εκτελεί αυτή τη συνάρτηση).

Ένα "κόλπο": αν έχεις πολλά πράγματα να τυπώσεις, συγκέντρωσέ τα σε μια λίστα και τύπωσέ την: `(print (list :this "that" 'the-other))`.

[cl-print]: http://www.lispworks.com/documentation/HyperSpec/Body/f_wr_pr.htm
