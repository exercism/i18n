# Εισαγωγή

Εκτός από τις δηλώσεις συνάρτησης και τις εκφράσεις συνάρτησης, η JavaScript έχει και μια άλλη, πολύ συνοπτική σύνταξη για τον ορισμό μιας συνάρτησης.
Αυτές οι συναρτήσεις ονομάζονται _συναρτήσεις βέλους_.

Σε αυτή την έννοια, θα επικεντρωθούμε στη σύνταξη που χρησιμοποιείται για να γράψεις μια συνάρτηση βέλους.
Υπάρχουν διαφορές στον τρόπο που λειτουργεί μια συνάρτηση βέλους, όπως η δέσμευση του _this_, οι οποίες θα καλυφθούν σε άλλες έννοιες.

Ακολουθεί μια σύγκριση ανάμεσα σε μια δήλωση συνάρτησης και σε μια συνάρτηση βέλους.

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

Παραπάνω, θα δεις ότι η σύνταξη της συνάρτησης βέλους:

1. αφαιρεί τη λέξη-κλειδί `function`
2. έχει δηλώσει το αναγνωριστικό `addUpTwoNumbers` ως `const`
3. προσθέτει ένα παχύ βέλος `=>`

Αν το σώμα της συνάρτησης περιέχει μόνο μια εντολή return, όπως στο παραπάνω παράδειγμα, τα `{}` και η λέξη-κλειδί `return` μπορούν να παραλειφθούν.

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

Στην ειδική περίπτωση που μια συνάρτηση βέλους επιστρέφει μόνο ένα αντικείμενο, χρειάζονται παρενθέσεις γύρω από το αντικείμενο για να μπορείς να παραλείψεις την εντολή return.

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

Η χρήση παρενθέσεων γύρω από τις παραμέτρους εξαρτάται από τον αριθμό των παραμέτρων.

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
