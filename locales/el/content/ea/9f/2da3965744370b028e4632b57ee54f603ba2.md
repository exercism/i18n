# Εισαγωγή

## Σταθερές

Ο τροποποιητής `const` μπορεί (και γενικά θα πρέπει) να εφαρμοστεί σε οποιοδήποτε πεδίο του οποίου η τιμή είναι γνωστή κατά τον χρόνο μεταγλώττισης και δεν αλλάζει κατά τη διάρκεια ζωής του προγράμματος.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Ο τροποποιητής `readonly` μπορεί (και γενικά θα πρέπει) να εφαρμοστεί σε οποιοδήποτε πεδίο που δε μπορεί να γίνει `const`, όταν η τιμή του δεν αλλάζει κατά τη διάρκεια ζωής του προγράμματος και ορίζεται είτε από έναν ενσωματωμένο αρχικοποιητή είτε κατά τη δημιουργία του στιγμιότυπου (από τον κατασκευαστή ή από μια μέθοδο που καλεί ο κατασκευαστής).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## Αμυντική αντιγραφή

Σε περιπτώσεις όπου η ασφάλεια είναι κρίσιμη (ή ακόμη και απλώς σε μια μεγάλη βάση κώδικα, όπου οι προγραμματιστές έχουν διαφορετικές προτεραιότητες και σκοπούς) θα πρέπει να αποφεύγεις να επιτρέπεις να παρακαμφθεί το δημόσιο API μιας κλάσης, δεχόμενος και αποθηκεύοντας παραμέτρους μιας μεθόδου που μπορούν να τροποποιηθούν ή εκθέτοντας ένα μέλος μιας κλάσης που μπορεί να τροποποιηθεί μέσω μιας τιμής επιστροφής ή ως παράμετρο `out`.

## Συλλογές μόνο για ανάγνωση

Ενώ ο τροποποιητής `readonly` εμποδίζει να αντικατασταθεί η τιμή ή η αναφορά σε ένα πεδίο, δεν προσφέρει καμία προστασία για τα μέλη ενός τύπου αναφοράς.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Για να διασφαλίσεις ότι όλα τα μέλη ενός τύπου αναφοράς προστατεύονται, τα πεδία μπορούν να γίνουν `readonly` και μπορούν να οριστούν αυτόματες ιδιότητες χωρίς προσπελαστή `set`.

Η Βιβλιοθήκη Βασικών Κλάσεων (BCL) παρέχει κάποιες εκδόσεις συλλογών μόνο για ανάγνωση, εκεί όπου απαιτείται να σταματήσει η ενημέρωση των μελών μιας συλλογής. Αυτές προσφέρονται ως περιτυλίγματα:

- Το `ReadOnlyDictionary<T>` εκθέτει ένα `Dictionary<T>` ως μόνο για ανάγνωση.
- Το `ReadOnlyCollection<T>` εκθέτει μια `List<T>` ως μόνο για ανάγνωση.
