# Υποδείξεις

## 1. Έλεγξε το επίπεδο υγρασίας του δωματίου

- Απλή λογική if...else.
- Ένας τριαδικός τελεστής αρκεί.
- Αυτή η εργασία χρησιμοποιεί μια συνάρτηση `error()`, όχι `throw()`.
- Χρειάζεται επίσης η μακροεντολή `@info`.
- Διάβασε την ενότητα για την καταγραφή στην εισαγωγή, για να δεις πώς δημιουργούνται τα μηνύματα καταγραφής.

## 2. Έλεγξε για υπερθέρμανση

- Υπάρχουν δύο συνθήκες σφάλματος που πρέπει να ελέγξεις.
- Κάθε μία χρειάζεται ένα `throw()` αν αποτύχει.
- Χρειάζεται η μακροεντολή `@info` για την περίπτωση επιτυχίας.

## 3. Όρισε ένα προσαρμοσμένο σφάλμα

- Δες την εισαγωγή για ένα παράδειγμα ορισμού προσαρμοσμένου σφάλματος.
- Τα πεδία και τα προσαρμοσμένα μηνύματα εκτύπωσης είναι δυνατά, αλλά δεν απαιτούνται.

## 4. Παρακολούθησε τη μηχανή

- Μπορείς να χρησιμοποιήσεις τις συναρτήσεις `humiditycheck` και `temperaturecheck`, αλλά αυτό δεν είναι απολύτως απαραίτητο.
- Αν τις χρησιμοποιήσεις, θα πρέπει να μπορείς να ελέγξεις ανεξάρτητα αν και οι δύο συναρτήσεις πετούν σφάλματα και να προσθέσεις τις κατάλληλες καταγραφές.
- Μια μεταβλητή που ορίζεται έξω από ένα μπλοκ `try...catch` μπορεί, αν χρειαστεί, να ενημερωθεί από μέσα από το μπλοκ.
- Υπενθύμιση: αν αποτύχει ο ένας έλεγχος ή και οι δύο, χρειάζεται να πετάξεις μόνο ένα `MachineError` αφού προστεθούν οι καταγραφές.
