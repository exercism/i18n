# Εισαγωγή

## Εντολές συνθήκης

Οι εντολές συνθήκης είναι εντολές λήψης αποφάσεων, που είτε εκτελούν παρενέργειες είτε ελέγχουν τη ροή εκτέλεσης ενός προγράμματος.
Στις εντολές συνθήκης περιλαμβάνονται οι εντολές `if`, `if/else`, `switch` και `ternary`.

Οι εντολές συνθήκης χρησιμοποιούνται για να θέτουμε ερωτήσεις για μια τιμή ή για τη σχέση μεταξύ τιμών.
Η ερώτηση αξιολογείται σε μια απάντηση Boolean (λογική τιμή), αλλά η ίδια η εντολή `if` μπορεί να επιστρέψει οποιαδήποτε τιμή ή απλώς να εκτελέσει μια παρενέργεια.

## Εντολές if

Η πιο απλή εντολή `if` αξιολογεί μια παράσταση και εκτελεί μία γραμμή.
Η παράσταση που ελέγχεται περικλείεται πάντα σε παρενθέσεις.

Μπορεί να εκτελέσει μια παρενέργεια

```c
if (count > 10)
    printf("count is greater than 10");
```

ή μπορεί να αλλάξει τη ροή εκτέλεσης


```c
if (count > 10)
    return sum;
```

Αν μια εντολή `if` εκτελεί περισσότερες από μία γραμμές, πρέπει να τις τοποθετήσει μέσα σε άγκιστρα

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Κάποιες ομάδες προγραμματισμού μπορεί να καθιερώσουν οι εντολές `if` να χρησιμοποιούν πάντα άγκιστρα, ακόμα και για μία μόνο γραμμή.


## if / else

Μια εντολή `if` μπορεί να συνδυαστεί με ένα `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if / else if


Το `else` μπορεί να συνδυαστεί με άλλο `if` για να δημιουργήσει αυτό που ονομάζεται `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


Μερικές φορές μια `if-else-if ladder` αναπαρίσταται καλύτερα με ένα `switch`.
Όπως και με το `if`, η παράσταση που ελέγχεται μπαίνει πάντα σε παρενθέσεις.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

Η περίπτωση `default` εκτελείται αν η τιμή που ελέγχεται δεν ταιριάζει με καμία από τις προηγούμενες περιπτώσεις.

Αν μια περίπτωση `switch` δεν κάνει επιστροφή, τότε συνήθως παρεμβάλλεται ένα `break` για να τερματίσει κάθε περίπτωση, αλλιώς η λογική "πέφτει" στην επόμενη περίπτωση.
Μερικές φορές η πτώση στην επόμενη περίπτωση χρησιμοποιείται σκόπιμα

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Όταν η πτώση στην επόμενη περίπτωση συμβαίνει ακούσια, πρόκειται για bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Ένα switch μπορεί να είναι χρήσιμο όταν ελέγχουμε συγκεκριμένες τιμές αντί για ένα εύρος τιμών.
Μπορεί να είναι ταχύτερο από μια `if-else-if ladder`, επειδή ο μεταγλωττιστής μπορεί να βελτιστοποιήσει την εντολή `switch` με τρόπους που δεν μπορεί να κάνει με μια ladder.
Ένα switch μπορεί μερικές φορές να φαίνεται πιο ευανάγνωστο από μια ladder.

## Ο τριμερής τελεστής (τελεστής συνθήκης)

Ο τριμερής τελεστής είναι μια εντολή συνθήκης με τρία μέρη, που χρησιμοποιείται συχνά για τον ορισμό μιας τιμής.
Η παράσταση που θα ελεγχθεί βρίσκεται πριν από το ερωτηματικό και δεν είναι απαραίτητο να βρίσκεται σε παρενθέσεις.
Η τιμή που επιστρέφεται αν η συνθήκη είναι αληθής βρίσκεται πριν από την άνω και κάτω τελεία, ενώ η τιμή που επιστρέφεται αν είναι ψευδής βρίσκεται μετά.
Μπορεί να επιστραφεί είτε μια κυριολεκτική τιμή είτε μια μεταβλητή.

```c
int i = j > 5 ? 5: j;
```

Οι τριμερείς τελεστές μπορούν να εμφωλευτούν, για να μειωθεί ο συντακτικός θόρυβος.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
