# Περιγραφή

Σήμερα, οι περισσότεροι άνθρωποι στον κόσμο χρησιμοποιούν αραβικούς αριθμούς (0–9).
Αν όμως ταξίδευες πίσω δύο χιλιάδες χρόνια, θα έβλεπες ότι οι περισσότεροι Ευρωπαίοι χρησιμοποιούσαν ρωμαϊκούς αριθμούς αντ' αυτών.

Για να γράψουμε έναν ρωμαϊκό αριθμό χρησιμοποιούμε τα παρακάτω λατινικά γράμματα, καθένα από τα οποία έχει μια τιμή:

| M    | D   | C   | L   | X   | V   | I   |
| ---- | --- | --- | --- | --- | --- | --- |
| 1000 | 500 | 100 | 50  | 10  | 5   | 1   |

Ένας ρωμαϊκός αριθμός είναι μια ακολουθία από αυτά τα γράμματα και η τιμή του είναι το άθροισμα των τιμών των γραμμάτων.
Για παράδειγμα, το `XVIII` έχει τιμή 18 (`10 + 5 + 1 + 1 + 1 = 18`).

Υπάρχει όμως ένας κανόνας που κάνει τα πράγματα πιο περίπλοκα: **το ίδιο γράμμα δεν μπορεί να χρησιμοποιηθεί περισσότερες από τρεις φορές διαδοχικά**.
Αυτό σημαίνει ότι δεν μπορούμε να εκφράσουμε αριθμούς όπως το 4 με το φαινομενικά φυσικό `IIII`.
Αντ' αυτού, για αυτούς τους αριθμούς, χρησιμοποιούμε μια μέθοδο αφαίρεσης μεταξύ δύο γραμμάτων.
Έτσι, σκεφτόμαστε το `4` όχι ως `1 + 1 + 1 + 1` αλλά ως `5 - 1`.
Και, κάπως μπερδευτικά για τη σύγχρονη αντίληψή μας, γράφουμε πρώτα τον μικρότερο αριθμό.
Αυτό ισχύει μόνο στις εξής περιπτώσεις: 4 (`IV`), 9 (`IX`), 40 (`XL`), 90 (`XC`), 400 (`CD`) και 900 (`CM`).

Η σειρά έχει σημασία στους ρωμαϊκούς αριθμούς!
Τα γράμματα (και οι ειδικοί συνδυασμοί παραπάνω) πρέπει να είναι ταξινομημένα κατά φθίνουσα τιμή από αριστερά προς τα δεξιά.

Ορίστε μερικά παραδείγματα:

```text
 105 => CV
---- => --
 100 => C
+  5 =>  V
```

```text
 106 => CVI
---- => --
 100 => C
+  5 =>  V
+  1 =>   I
```

```text
 104 => CIV
---- => ---
 100 => C
+  4 =>  IV
```

Και ένα τελευταίο πιο σύνθετο παράδειγμα:

```text
 1996 => MCMXCVI
----- => -------
 1000 => M
+ 900 =>  CM
+  90 =>    XC
+   5 =>      V
+   1 =>       I
```
