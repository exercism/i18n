# Πόροι

- [Julia Style Guide](https://docs.julialang.org/en/v1/manual/style-guide/): Οδηγός για το πώς να γράφεις ιδιωματικό κώδικα σε Julia.
- [Performance Tips](https://docs.julialang.org/en/v1/manual/performance-tips/): Τεχνικές για να κάνεις τα προγράμματά σου πιο γρήγορα.
- [Julia Manual](https://docs.julialang.org/): Αναλυτικές εξηγήσεις και παραδείγματα για κάθε δυνατότητα της Julia.
- [juliabloggers.com](https://www.juliabloggers.com/): Συγκεντρωτής αναρτήσεων ιστολογίου για τη Julia.
- [Julia Discourse](https://discourse.julialang.org/): Συζητήσεις για τη γλώσσα.
- [Julia YouTube channel](https://www.youtube.com/user/JuliaLanguage): Αρχείο ομιλιών του JuliaCon.
