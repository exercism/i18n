# Εισαγωγή

## Boolean

Στη Java, οι Boolean (λογικές τιμές) αναπαρίστανται από τον τύπο `boolean`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η Java υποστηρίζει τρεις τελεστές Boolean:  

- `!` (NOT): αντιστρέφει τη Boolean τιμή  
- `&&` (AND): παίρνει δύο Boolean τιμές και επιστρέφει `true` αν είναι και οι δύο `true`
- `||` (OR): επιστρέφει `true` αν κάποια από τις δύο Boolean τιμές είναι `true`

### Παραδείγματα

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
