# Εισαγωγή

Ο ορισμός μιας συλλογής συνήθως περιλαμβάνει ένα σύμβολο θέσης μέσα σε γωνιακές αγκύλες, συχνά το T κατά σύμβαση. Μια τέτοια συλλογή αναφέρεται ως γενικός τύπος. Αυτό επιτρέπει στον χρήστη της συλλογής να καθορίσει τι τύπου στοιχεία θα αποθηκεύσει στη συλλογή. Στο παραπάνω παράδειγμα κώδικα δημιουργούμε ένα στιγμιότυπο μιας λίστας συμβολοσειρών.

Μια κλάση ή μια συνάρτηση γίνεται **γενική** χρησιμοποιώντας το χαρακτηριστικό `@:generic`. Αυτό κάνει τον μεταγλωττιστή να αναγνωρίσει την κλάση ή τη συνάρτηση ως γενική:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
