# Υποδείξεις

## Γενικά

- Οι συναρτήσεις είναι απλώς διευθύνσεις μνήμης και μπορείς να τις χειριστείς όπως οποιαδήποτε διεύθυνση μνήμης.
- Οι διευθύνσεις μνήμης είναι ακέραιες τιμές 64 bit, που περνιούνται και επιστρέφονται στους συνηθισμένους καταχωρητές.
- Μπορείς να κάνεις `call` ή `jmp` σε μια συνάρτηση που είναι αποθηκευμένη σε καταχωρητή ή στη μνήμη.

## 1. Θυμήσου μια συναλλαγή

- Οι συναρτήσεις είναι απλώς διευθύνσεις μνήμης και μπορείς να τις χειριστείς όπως οποιαδήποτε διεύθυνση μνήμης.
- Οι διευθύνσεις μνήμης είναι ακέραιες τιμές 64 bit, που περνιούνται και επιστρέφονται στους συνηθισμένους καταχωρητές.
- Η `remember_transaction` πρέπει να αποθηκεύει μια συνάρτηση σε μια μόνιμη θέση μνήμης.
- Στην `apply_remembered`, το όρισμα που θα περαστεί στην αποθηκευμένη συνάρτηση είναι ήδη αποθηκευμένο στον σωστό καταχωρητή (`rdi`).

## 2. Το εγχειρίδιο της τράπεζας

- Ο πίνακας αποστολής είναι απλώς ένας πίνακας και μπορεί να προσπελαστεί μέσω θέσεων όπως οποιοσδήποτε πίνακας.
- Κάθε καταχώριση στον πίνακα αποστολής είναι μια συνάρτηση και οι συναρτήσεις είναι ακέραιες τιμές 64 bit (8 byte).
- Στη `select_transaction`, το όρισμα για τη συναλλαγή βρίσκεται αρχικά στον `rdx` και πρέπει να μεταφερθεί στον `rdi` πριν καλέσεις τη συνάρτηση.
- Η κλήση στη συναλλαγή που αποστέλλεται βρίσκεται σε θέση ουράς, οπότε μπορείς να χρησιμοποιήσεις μια ουριαία κλήση (`jmp`).

## 3. Επεξεργάσου μια μηνιαία κατάσταση

- Κάθε καταχώριση στον πίνακα είναι μια συνάρτηση και οι συναρτήσεις είναι ακέραιες τιμές 64 bit (8 byte).
- Οποιοσδήποτε καταχωρητής που σώζεται από τον καλούντα μπορεί να αλλοιωθεί από μια εξωτερική συνάρτηση, οπότε θα πρέπει να αποθηκεύσεις κάθε απαραίτητη τιμή πριν καλέσεις μια τέτοια συνάρτηση.
  Οι καταχωρητές που σώζονται από τον καλούντα είναι οι `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` και `r11`.
- Οι καταχωρητές που σώζονται από την καλούμενη συνάρτηση, όπως οι `rbx`, `rbp`, `r12`, `r13`, `r14` και `r15`, δεν τροποποιούνται από τη συνάρτηση που καλείται.
  Ωστόσο, πρέπει να αποθηκεύσεις την αρχική τους τιμή πριν τους χρησιμοποιήσεις και να την επαναφέρεις πριν επιστρέψεις.
- Η στοίβα θα πρέπει να είναι ευθυγραμμισμένη στα 16 byte πριν καλέσεις μια εξωτερική συνάρτηση.
  Στο σημείο εισόδου, το `rsp` είναι 8 μικρότερο από ένα πολλαπλάσιο του 16.
- Για έναν κενό πίνακα, δεν εφαρμόζεται καμία συναλλαγή και η συνάρτηση θα πρέπει να επιστρέφει το αρχικό υπόλοιπο χωρίς αλλαγή.

## 4. Επεξεργάσου με φρουρό

- Κάθε καταχώριση στον πίνακα είναι μια συνάρτηση και οι συναρτήσεις είναι ακέραιες τιμές 64 bit (8 byte).
- Οποιοσδήποτε καταχωρητής που σώζεται από τον καλούντα μπορεί να αλλοιωθεί από μια εξωτερική συνάρτηση, οπότε θα πρέπει να αποθηκεύσεις κάθε απαραίτητη τιμή πριν καλέσεις μια τέτοια συνάρτηση.
- Οι καταχωρητές που σώζονται από την καλούμενη συνάρτηση, όπως οι `rbx`, `rbp`, `r12`, `r13`, `r14` και `r15`, δεν τροποποιούνται από τη συνάρτηση που καλείται.
  Ωστόσο, πρέπει να αποθηκεύσεις την αρχική τους τιμή πριν τους χρησιμοποιήσεις και να την επαναφέρεις πριν επιστρέψεις.
- Η στοίβα θα πρέπει να είναι ευθυγραμμισμένη στα 16 byte πριν καλέσεις μια εξωτερική συνάρτηση.
  Στο σημείο εισόδου, το `rsp` είναι 8 μικρότερο από ένα πολλαπλάσιο του 16.
- Η συνάρτηση φρουρός παίρνει ως όρισμα το αποτέλεσμα κάθε συναλλαγής.
  Αυτή η τιμή πρέπει να βρίσκεται στον `rdi` πριν καλέσεις τη συνάρτηση φρουρό.
- Η συνάρτηση φρουρός επιστρέφει `0` για ένα μη έγκυρο αποτέλεσμα και μη μηδενική τιμή για ένα έγκυρο.
  Ένα έγκυρο αποτέλεσμα ενημερώνει το τρέχον υπόλοιπο και τον αριθμό των εγκεκριμένων συναλλαγών.
- Η συνάρτηση επιστρέφει δύο μη αρνητικούς ακέραιους 64 bit: το τελικό υπόλοιπο πρέπει να βρίσκεται στον `rax` και ο αριθμός των εγκεκριμένων συναλλαγών στον `rdx`.
