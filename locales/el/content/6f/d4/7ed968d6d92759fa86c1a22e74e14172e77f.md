# Υποδείξεις

## Γενικά

- Διάβασε την τεκμηρίωση για τα [σύνολα][set]
- Η τεκμηρίωση για τις [λίστες][lists] μπορεί επίσης να σου φανεί χρήσιμη

## 1. Ξεκίνα μια συλλογή

- Η πιο κατάλληλη συνάρτηση του `Set` είναι η [`Set.singleton`][singleton]

## 2. Μεγάλωσε τη συλλογή

- Χρησιμοποίησε τη [συνάρτηση `Set.insert`][insert]
- Χρησιμοποίησε τη [συνάρτηση `Set.member`][member]

## 3. Ξεκίνα τις συναλλαγές

- Χρησιμοποίησε τη [συνάρτηση `Set.member`][member]
- Χρησιμοποίησε τη [συνάρτηση `Set.insert`][insert]
- Χρησιμοποίησε τη [συνάρτηση `Set.remove`][remove]

## 4. Μπορεί να υπάρχει μόνο ένα από το καθένα

- Ένα `Set` έχει την ιδιότητα να περιέχει μόνο μοναδικές τιμές
- Χρησιμοποίησε τη [συνάρτηση `Set.fromList`][fromList]
- Χρησιμοποίησε τη [συνάρτηση `Set.toList`][toList]
- Είναι εγγυημένο ότι το `Set.toList` επιστρέφει μια ταξινομημένη λίστα

## 5. Κάρτες που δεν έχουν

- Χρησιμοποίησε τη [συνάρτηση `Set.diff`][diff]
- Χρησιμοποίησε τη [συνάρτηση `Set.size`][size]

## 6. Κάρτες που έχουν όλοι

- Χρησιμοποίησε τις [συναρτήσεις `List.foldl` ή `List.foldr`][fold]
- Χρησιμοποίησε αντιστοίχιση προτύπων στη λίστα για να ξεχωρίσεις τις κενές από τις μη κενές λίστες
- Χρησιμοποίησε τη [συνάρτηση `Set.intersect`][intersect]
- Χρησιμοποίησε τη [συνάρτηση `Set.toList`][toList]
- Είναι εγγυημένο ότι το `Set.toList` επιστρέφει μια ταξινομημένη λίστα

## 7. Όλες οι κάρτες

- Χρησιμοποίησε τις [συναρτήσεις `List.foldl` ή `List.foldr`][fold]
- Χρησιμοποίησε το [`Set.empty`][empty] ως συσσωρευτή
- Χρησιμοποίησε τη [συνάρτηση `Set.union`][union]
- Χρησιμοποίησε τη [συνάρτηση `Set.size`][size]

## 8. Shiny για τη νίκη

- Χρησιμοποίησε τη [συνάρτηση `Set.partition`][partition]
- Χρησιμοποίησε τη [συνάρτηση `String.startsWith`][startsWith]
- Χρησιμοποίησε τη [συνάρτηση `Set.toList`][toList]
- Είναι εγγυημένο ότι το `Set.toList` επιστρέφει μια ταξινομημένη λίστα
