# Εγκατάσταση

## Απαιτήσεις

* Ένας επεξεργαστής x86 64-bit
* Ένας σύγχρονος μεταγλωττιστής C
* Το εργαλείο κατασκευής Make
* Ο Netwide Assembler (NASM)

Σημείωσε ότι αυτή η διαδρομή υποστηρίζει μόνο τη σύμβαση κλήσης του System V AMD64 ABI. Οι χρήστες των Windows θα χρειαστεί να εγκαταστήσουν το Windows Subsystem for Linux (WSL) ή να στήσουν μια εικονική μηχανή Linux.

## Linux

Εγκατέστησε το απαιτούμενο λογισμικό χρησιμοποιώντας τον διαχειριστή πακέτων του συστήματός σου:

* Ubuntu, Debian: `$ sudo apt-get install gcc make nasm`
* Fedora: `$ sudo dnf install gcc make nasm`
* CentOS, RHEL: `$ sudo yum install gcc make nasm`
* Arch Linux: `$ sudo pacman -S gcc make nasm`
* OpenSUSE: `$ sudo zypper install gcc make nasm`

## macOS

Εγκατέστησε τα Xcode Command Line Tools:

```bash
$ xcode-select --install
```

Εγκατέστησε το NASM χρησιμοποιώντας το [Homebrew](http://brew.sh/):

```bash
$ brew install nasm
```

## Windows

Για να εγκαταστήσεις το WSL, δες https://docs.microsoft.com/en-us/windows/wsl/install-win10.
