# Αριθμοί κινητής υποδιαστολής

Το `FLTD` περιέχει έναν αριθμό που μπορεί να έχει κλασματικό μέρος. Ένα literal χρειάζεται υποδιαστολή και ένα `d`:

```sather
   440.0d
   0.5d
   -2.25d
```

Το `FLT` είναι η ίδια ιδέα με τη μισή ακρίβεια. Αυτό το track χρησιμοποιεί `FLTD` παντού. Δεν υπάρχει λόγος να καταφύγεις στο `FLT`, εκτός αν η μνήμη είναι περιορισμένη.

## Αριθμητική

| Τελεστής | Σημασία |
| --- | --- |
| `+` `-` `*` | όπως για το `INT` |
| `/` | διαίρεση, κρατώντας το κλασματικό μέρος |

Δεν υπάρχει `%` για το `FLTD`.

Και οι δύο τελεστέοι πρέπει να είναι `FLTD`. Το να ανακατέψεις ένα `INT` μέσα είναι σφάλμα μεταγλώττισης, όχι σιωπηλή μετατροπή, και αυτό είναι πλεονέκτημα: το μοναδικό σημείο όπου αυτό πονάει είναι ακριβώς εκεί όπου οι άνθρωποι το κάνουν λάθος.

## Μετατροπή

```sather
   7.fltd            -- 7.0, an INT made into an FLTD
   7.5d.int          -- 7, the fraction thrown away
   7.5d.round        -- 8, to the nearest whole number
   7.5d.floor        -- 7.0, down to a whole number
   7.5d.ceiling      -- 8.0, up to a whole number
```

Κάνε τη μετατροπή πριν τη διαίρεση, ποτέ μετά: το `n.fltd / 2.0d` κρατά το μισό, ενώ το `(n / 2).fltd` το έχει ήδη χάσει.

## Χρήσιμες ρουτίνες

```sather
   (-2.5d).abs       -- 2.5
   2.0d.sqrt         -- 1.41421
   (2.0d).max(3.0d)  -- 3.0
```

## Η κινητή υποδιαστολή είναι προσεγγιστική

Ένα `FLTD` κρατά μια πολύ κοντινή προσέγγιση, όχι την ακριβή τιμή. Τα περισσότερα δεκαδικά κλάσματα δεν μπορούν να αποθηκευτούν με ακρίβεια, με τον ίδιο τρόπο που το ένα τρίτο δεν μπορεί να γραφτεί με ακρίβεια στο δεκαδικό σύστημα. Έτσι:

```sather
0.1d + 0.2d          -- very nearly 0.3, but not exactly
```

Δύο συνέπειες που αξίζει να θυμάσαι:

**Μην συγκρίνεις με `=`.** Δύο υπολογισμοί που θα έπρεπε να δίνουν την ίδια απάντηση συχνά διαφέρουν στα τελευταία ψηφία. Ρώτησε αντ' αυτού αν είναι κοντά:

```sather
   (a - b).abs < 0.0001d
```

**Η πρόσθεση πολλών μικρών τιμών χάνει ακρίβεια.** Κάθε πρόσθεση στρογγυλοποιεί λίγο, και τα σφάλματα συσσωρεύονται.

Όταν οι τιμές πρέπει να είναι ακριβείς, ειδικά τα χρήματα, μέτρα σε ακέραιες μονάδες με `INT` (σεντ αντί για δολάρια) αντ' αυτού.

## Εκτύπωση

Το `.str` δείχνει περίπου έξι σημαντικά ψηφία, που είναι λιγότερα από την ακρίβεια που πραγματικά κρατιέται:

```sather
   #OUT + (1.0d / 3.0d).str;      -- 0.333333
```
