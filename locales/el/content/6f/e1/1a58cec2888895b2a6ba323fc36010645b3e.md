# Οδηγίες

Η αποστολή σου είναι, με δεδομένο ένα διάγραμμα, να προσδιορίσεις για ποια φυτά είναι υπεύθυνο κάθε παιδί της τάξης του νηπιαγωγείου.

Στην τάξη υπάρχουν 12 παιδιά:

- Alice, Bob, Charlie, David, Eve, Fred, Ginny, Harriet, Ileana, Joseph, Kincaid, και Larry.

Φυτεύονται τέσσερα διαφορετικά είδη σπόρων:

| Φυτό  | Κωδικοποίηση στο διάγραμμα |
| ------ | ---------------- |
| Grass  | G                |
| Clover | C                |
| Radish | R                |
| Violet | V                |

Κάθε παιδί παίρνει τέσσερα κύπελλα, δύο σε κάθε σειρά:

```text
[window][window][window]
........................ # each dot represents a cup
........................
```

Η δασκάλα τους αναθέτει τα κύπελλα στα παιδιά αλφαβητικά με βάση τα ονόματά τους, που σημαίνει ότι η Alice έρχεται πρώτη και ο Larry τελευταίος.

Ακολουθεί ένα παράδειγμα διαγράμματος που αναπαριστά τα φυτά της Alice:

```text
[window][window][window]
VR......................
RG......................
```

Στην πρώτη σειρά, πιο κοντά στα παράθυρα, έχει ένα violet και ένα radish.
Στη δεύτερη σειρά έχει ένα radish και λίγο grass.

Το πρόγραμμά σου θα λάβει τα φυτά από αριστερά προς τα δεξιά, ξεκινώντας από τη σειρά που βρίσκεται πιο κοντά στα παράθυρα.
Από αυτό, θα πρέπει να μπορεί να προσδιορίσει ποια φυτά ανήκουν σε κάθε μαθητή.

Για παράδειγμα, αν του δοθεί ότι ο κήπος μοιάζει κάπως έτσι:

```text
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

Τότε, αν του ζητηθούν τα φυτά της Alice, θα πρέπει να δώσει:

- Violets, radishes, violets, radishes

Ενώ, αν ζητηθούν τα φυτά του Bob, θα δώσει:

- Clover, grass, clover, clover
