# Εισαγωγή

## Συμβολοσειρές

Ένα `String` στη Java είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.).
Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσουν ένα στιγμιότυπο `String`:

```java
String fruit = "Apple";
```

Χειριζόμαστε τις συμβολοσειρές καλώντας τις μεθόδους τους.
Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί ποτέ να αλλάξει.
Οποιεσδήποτε μέθοδοι φαίνονται να τροποποιούν μια συμβολοσειρά, στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.
Η κλάση `String` παρέχει μερικές _static_ μεθόδους για να μετασχηματίζουν τις συμβολοσειρές.
