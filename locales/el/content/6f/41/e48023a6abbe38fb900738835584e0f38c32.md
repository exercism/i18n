# Εγκατάσταση

## Εγκατάσταση του .NET

Το track F# βασίζεται στην πλατφόρμα [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), η οποία λειτουργεί σε Windows, Linux και macOS. Για να δημιουργήσεις έργα .NET, μπορείς να χρησιμοποιήσεις τη γραμμή εντολών (Command Line Interface, CLI) του .NET. Αυτή η γραμμή εντολών αποτελεί μέρος του .NET SDK, το οποίο μπορείς να εγκαταστήσεις ακολουθώντας τις [οδηγίες εγκατάστασης](https://dotnet.microsoft.com/download). Σημείωση: το track F# απαιτεί έκδοση SDK 8.0 ή μεγαλύτερη.

Αφού ολοκληρώσεις την εγκατάσταση, μπορείς να επαληθεύσεις αν η γραμμή εντολών εγκαταστάθηκε με επιτυχία τρέχοντας αυτή την εντολή σε ένα τερματικό:

```bash
dotnet --version
```

Αν η έξοδος είναι μια έκδοση μεγαλύτερη ή ίση με `8.0.100`, το .NET SDK έχει εγκατασταθεί με επιτυχία.

## Χρήση IDE

Αν θέλεις μια πιο πλήρη εμπειρία επεξεργασίας, πιθανότατα θέλεις να χρησιμοποιήσεις ένα IDE. Αυτά είναι τα πιο δημοφιλή IDE που υποστηρίζουν τη δημιουργία έργων .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) με την [επέκταση Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Σημείωση: επειδή η μορφή των έργων .NET διαφέρει σημαντικά από τις προηγούμενες εκδόσεις, τα παλαιότερα IDE (όπως το Visual Studio 2015) δεν υποστηρίζονται.
