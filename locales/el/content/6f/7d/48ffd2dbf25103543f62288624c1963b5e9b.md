# Εισαγωγή

Από [το εγχειρίδιο][man-types]

> Το jq υποστηρίζει το ίδιο σύνολο τύπων δεδομένων με τη JSON: αριθμούς, συμβολοσειρές, booleans, πίνακες, αντικείμενα (που στη γλώσσα της JSON είναι hashes με κλειδιά μόνο συμβολοσειρών) και "null".

Ας επικεντρωθούμε στους **αριθμούς**.

## Αριθμοί και αριθμητικοί τελεστές

Όλοι οι αριθμοί, είτε είναι ακέραιοι είτε όχι, είναι αριθμοί κινητής υποδιαστολής διπλής ακρίβειας IEEE754.
Αυτό μας περιορίζει σε 53 bits ακρίβειας.

Οι συνήθεις τελεστές είναι διαθέσιμοι για χρήση με αριθμούς:

- αριθμητικοί: `+`, `-`, `*`, `/`, `%`
- σύγκρισης: `==`, `!=`, `<`, `<=`, `>=`, `>`
- οι τυπικές [μαθηματικές συναρτήσεις][man-math]

  Για συναρτήσεις με μία είσοδο, διοχέτευσε την τιμή μέσα στη συνάρτηση

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Για συναρτήσεις με δύο εισόδους, οι συναρτήσεις αγνοούν την είσοδο και περιμένουν
  τις εισόδους ως παραμέτρους (θυμήσου ότι οι παράμετροι χωρίζονται με ερωτηματικά)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Το ερωτηματικό είναι ο διαχωριστικός χαρακτήρας των ορισμάτων μιας συνάρτησης, όχι το κόμμα.

## Άλλες εκφράσεις της `jq`

Για να λύσεις την άσκηση, θα χρειαστεί να ξέρεις τις εκφράσεις υπό συνθήκη.

### Εκφράσεις υπό συνθήκη

Η `jq` χρησιμοποιεί μια [έκφραση `if-then-else`][if-then-else] για τις **εκφράσεις υπό συνθήκη**.
Ως _έκφραση_, τοποθετείται μέσα σε ένα pipeline.

Η σύνταξη είναι: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Η ρήτρα `else` είναι προαιρετική.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Οι πρόσθετες συνθήκες χρησιμοποιούν το `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
