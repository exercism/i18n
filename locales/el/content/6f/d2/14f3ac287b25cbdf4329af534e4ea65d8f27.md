# Μπλοκ & Proc

Ένα [μπλοκ][block] είναι ένα κομμάτι κώδικα που μπορεί να περαστεί σε μια μέθοδο.
Αυτό είναι γνωστό ως [ανώνυμη συνάρτηση ή λάμδα][anonymous function] σε άλλες γλώσσες προγραμματισμού.
Μια μέθοδος μπορεί να μετατρέψει ένα μπλοκ σε [Proc][proc], το οποίο αναπαριστά ένα μπλοκ κώδικα.

```crystal
def my_method(&block)
  1 + yield
end

my_method { 2 }
# => 3
```

Τα μπλοκ και τα Proc χρησιμοποιούνται πολύ συχνά στη Crystal, για πράγματα όπως η επανάληψη και τα callbacks.
Αλλά και για να δημιουργήσεις [DSL (Γλώσσες Ειδικού Σκοπού)][dsl]. Κάποια παραδείγματα DSL είναι το web framework [Kemal][kemal] ή το testing framework [Spec][spec] (το οποίο χρησιμοποιείται για να ελέγχεις τις λύσεις σου σε Crystal).

## Μπλοκ

Για να δημιουργήσεις μια μέθοδο που μπορεί να δεχτεί ένα μπλοκ, πρέπει να βάλεις ένα ampersand (`&`) πριν από το τελευταίο όρισμα.
Αυτό θα μετατρέψει το μπλοκ σε Proc και θα το εκχωρήσει στο όρισμα.
Έπειτα, χρησιμοποιώντας το `yield`, θα εκτελέσεις το μπλοκ που δίνεται στη μέθοδο.

```crystal
def my_method(&block)
  1 + yield
end
```

Για να περάσεις ένα μπλοκ υπάρχουν δύο τρόποι: είτε χρησιμοποιώντας τις λέξεις-κλειδιά `do ... end` είτε χρησιμοποιώντας άγκιστρα (`{}`).
Η κύρια διαφορά μεταξύ τους είναι η προτεραιότητα: το `do ... end` υποστηρίζει μπλοκ πολλών γραμμών, ενώ τα άγκιστρα (`{}`) όχι.

```crystal
my_method do
  2
end
# => 3

my_method { 2 }
# => 3
```

## Yield

Το [`yield`][yield] είναι μια λέξη-κλειδί που εκτελεί το μπλοκ που δίνεται στη μέθοδο.
Αυτό σημαίνει ότι το μπλοκ δεν θα εκτελεστεί ποτέ αν δεν κληθεί το `yield`.
Μπορεί επίσης να δεχτεί ορίσματα, τα οποία θα περαστούν στο μπλοκ.
Δεν υπάρχει όριο στον αριθμό των ορισμάτων που μπορούν να περαστούν στο μπλοκ.
Για να χρησιμοποιήσεις τα ορίσματα μέσα στο μπλοκ, χρησιμοποιείς τη σύνταξη `|x, y, ...|`.
Εδώ τα x, y, ... είναι τα ονόματα των ορισμάτων.

```crystal
def my_method(&block)
  1 + yield 2
end

# With curly braces:

my_method { |x| x * 3 }
# => 7

# With do ... end:

my_method do |x|
  x * 3
end
# => 7
```

Στο παραπάνω παράδειγμα, στο μπλοκ δίνεται το όρισμα `2`, το μπλοκ το πολλαπλασιάζει με το `3` και επιστρέφει `6`.
Έπειτα, η μέθοδος προσθέτει `1` στο αποτέλεσμα και επιστρέφει `7`.

Αν ο αριθμός των ορισμάτων που δίνονται στο `yield` είναι μεγαλύτερος από τον αριθμό των ορισμάτων που περιμένει το μπλοκ, θα πεταχτεί ένα σφάλμα.

```crystal
def my_method(&block)
  1 + yield
end

my_method { |x| x * 3 }
# Error: too many block parameters (given 1, expected maximum 0)
```

## Τύποι μπλοκ

Τα μπλοκ μπορούν να γραφτούν ρητά ή έμμεσα.
Τα έμμεσα μπλοκ είναι τα πιο συνηθισμένα και είναι αυτά που φαίνονται στα παραπάνω παραδείγματα.
Μπορείς ακόμη και να δώσεις στο μπλοκ διαφορετικούς τύπους ορισμάτων και ο μεταγλωττιστής θα συμπεράνει τους τύπους και θα δημιουργήσει έναν τύπο ένωσης.

```crystal
def my_method(&block)
  yield "a"
  yield 1
end

my_method do |x|
  p typeof(x)
end

# output: (String | Int32)
```

Όταν γράφεις ρητά μπλοκ, μπορείς να προσδιορίσεις τους τύπους των ορισμάτων και τον τύπο επιστροφής.
Αυτό γίνεται με τη σύνταξη `Arg1Type, Arg2Type, ... -> ResultType`.
Εδώ τα ορίσματα χωρίζονται με κόμματα (`,`), και ο τύπος αποτελέσματος χωρίζεται με `->`.

```crystal
def my_method(&block : Int32, Int32 -> Int32)
  1 + yield(2, 3)
end

my_method { |x, y| x * y }
# => 7
```

Όπως συμβαίνει και με άλλους ρητούς τύπους, ο μεταγλωττιστής θα επιβάλει οι τύποι να είναι αυτοί που αναμένονται.
Αν το μπλοκ δεν ταιριάζει με τον τύπο που δίνεται στη μέθοδο, θα πεταχτεί ένα σφάλμα.

## Proc

Το [`Proc`][proc] έχει πολύ ισχυρή σχέση με τα μπλοκ.
Η βασική διαφορά είναι ότι το `Proc` είναι ένας τύπος, ενώ το μπλοκ δεν είναι.
Ένα `Proc` αναπαριστά έναν δείκτη συνάρτησης και μπορεί να περαστεί ως μεταβλητή.

Για να ορίσεις ένα `Proc`, χρησιμοποιείς τη σύνταξη του proc literal `->(args) { ... }`.
Τα ορίσματα χωρίζονται με κόμματα (`,`), και το μπλοκ περικλείεται από `{ ... }`.
Για να καλέσεις ένα Proc, χρησιμοποιείς τη μέθοδο `call` και της περνάς τα ορίσματα.
Οι τύποι των παραμέτρων είναι υποχρεωτικοί.
Ο τύπος επιστροφής συμπεραίνεται από το σώμα του proc, αλλά μπορεί επίσης να δοθεί ρητά.

```crystal
my_proc = ->(x : Int32, y : Int32) : Int32 { x * y }
my_proc.call(2, 3)
# => 6
```

## Σύλληψη μπλοκ

Η [σύλληψη μπλοκ][capturing-blocks] είναι ένας τρόπος να δημιουργήσεις ένα `Proc` από ένα μπλοκ.
Αυτό γίνεται χρησιμοποιώντας τον τελεστή `&` πριν από το τελευταίο όρισμα μιας μεθόδου.
Αυτό θα μετατρέψει το μπλοκ σε `Proc` και θα το εκχωρήσει στο όρισμα.

```crystal
def my_method(&block)
  block.call
end

my_method { 1 + 2 }
# => 3
```

### Πέρασμα proc σε μεθόδους

Τα Proc μπορούν να περαστούν σε μεθόδους που περιμένουν ένα μπλοκ.
Αυτό μπορεί να είναι βολικό όταν θέλεις να μπορείς να περάσεις διαφορετικά μπλοκ ανάλογα με κάποια συνθήκη.

```crystal
def my_method(&block)
  yield 5
end

my_proc = -> (x) { x * 2 }
my_method(&my_proc)
# => 10
```

### Δήλωση του τύπου των μεταβλητών

Όταν δηλώνεις μια μεταβλητή, μπορείς να χρησιμοποιήσεις τη σύνταξη `: Type` για να δηλώσεις τον τύπο της μεταβλητής.
Για τα Proc, χρησιμοποιείς τη σύνταξη `Proc((ArgType, ...), ResultType)`.
Ο τελευταίος τύπος θα είναι πάντα ο τύπος επιστροφής και οι υπόλοιποι θα είναι οι τύποι των ορισμάτων.
Δηλαδή, αν υπάρχει μόνο ένας τύπος, αυτός θα είναι ο τύπος επιστροφής και το proc δεν θα δέχεται κανένα όρισμα.

```crystal
my_proc : Proc(Int32, Int32, Int32) = ->(x, y) { x * y }
other_proc : Proc(Int32) = -> { 1 }
```
