# Εισαγωγή

Το ζογκλάρισμα της στοίβας είναι εντάξει για σύντομες λέξεις. Όταν μια λέξη έχει πολλές
εισόδους και θέλεις να αναφέρεσαι σε αυτές με το όνομά τους, η Factor προσφέρει
τα *locals*: ονομασμένες δεσμεύσεις που εισάγονται με `::` (για ορισμούς
λέξεων) ή `[| | ]` (για inline λάμδα), και τα δύο προέρχονται από
το [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Μέσα σε ένα quotation, το `[| inputs | body ]` είναι ένα λάμδα με ονομασμένες
εισόδους:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
