# Χρήση guards

[comment]: # (Αυτό το σφάλμα εμφανίζεται όταν η λύση δεν χρησιμοποιεί καθόλου guards)

Χρησιμοποίησε [guards](https://hexdocs.pm/elixir/master/guards.html) για να εμποδίσεις τη `two_fer/1` να εκτελέσει κώδικα με μη δυαδικά ορίσματα.

> Θυμήσου, στην Elixir οι [συμβολοσειρές](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) θεωρούνται [δυαδικά δεδομένα](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Μπορείς να δοκιμάσεις αυτό το guard στον `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
