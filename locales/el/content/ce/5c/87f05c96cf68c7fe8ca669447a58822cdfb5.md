# Εισαγωγή

Το σύστημα σφαλμάτων της Factor έχει τρία κομμάτια: το `throw` (στο
[`kernel`][kernel]) πετάει ένα σφάλμα, το `recover` (στο
[`continuations`][continuations]) πιάνει ένα, και το `ERROR:` ορίζει
μια κλάση σφάλματος με τύπο πλειάδας.

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

Το `recover ( try recovery -- )` εκτελεί το *try* quotation. Αν πετάξει
σφάλμα, το σφάλμα ωθείται στη στοίβα και εκτελείται το *recovery* quotation.

Το `ERROR:` δηλώνει και την κλάση *και* μια λέξη-κατασκευαστή που
πετάει ένα νέο στιγμιότυπο:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
