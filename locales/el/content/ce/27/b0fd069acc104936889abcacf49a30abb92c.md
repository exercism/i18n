# Υποδείξεις

## 1. Περιέγραψε έναν χαρακτήρα

- Τροποποίησε τους [κατασκευαστές][constructor-syntax] των κλάσεων `Wizard` και `Warrior` ώστε να περνούν τον τύπο του χαρακτήρα τους στον [κατασκευαστή της βασικής κλάσης][instance-constructors].
- Αποθήκευσε τον τύπο του χαρακτήρα ως [πεδίο][fields] στην κλάση `Character`.
- Η κλάση `Character` κληρονομεί σιωπηρά από την κλάση `object`, της οποίας [τη μέθοδο `ToString()` μπορείς να παρακάμψεις][override-tostring].

## 2. Κάνε τους χαρακτήρες μη ευάλωτους από προεπιλογή

- Υλοποίησε τη μέθοδο `Vulnerable()` στην κλάση `Character` ώστε να επιστρέφει πάντα `false`.

## 3. Επίτρεψε στους Μάγους να προετοιμάσουν ένα ξόρκι

- Πρόσθεσε ένα πεδίο στην κλάση `Wizard` για να αποθηκεύεις αν έχει προετοιμαστεί ένα ξόρκι και ενημέρωσέ το στη μέθοδο `PrepareSpell()`.
- Το ξόρκι θα πρέπει να ξεκινά ως μη προετοιμασμένο.

## 4. Κάνε τους Μάγους ευάλωτους όταν δεν έχουν προετοιμάσει ξόρκι

- Παράκαμψε τη μέθοδο `Vulnerable()` στην κλάση `Wizard` ώστε οι Μάγοι να είναι ευάλωτοι αν δεν έχουν προετοιμάσει ξόρκι.

## 5. Υπολόγισε τους πόντους ζημιάς για έναν Μάγο

- Χρησιμοποίησε μια [εντολή υπό συνθήκη][if-else] για να επιστρέψεις τους πόντους ζημιάς, λαμβάνοντας υπόψη την τιμή του πεδίου προετοιμασίας ξορκιού.

## 6. Υπολόγισε τους πόντους ζημιάς για έναν Πολεμιστή

- Μπορείς να καλέσεις μια μέθοδο στο στιγμιότυπο `Character` που περνιέται για να προσδιορίσεις την ευαλωτότητά του.
- Χρησιμοποίησε μια [εντολή υπό συνθήκη][if-else] για να επιστρέψεις τους πόντους ζημιάς, λαμβάνοντας υπόψη την ευαλωτότητα του στόχου.
