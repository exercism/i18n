# Προσθήκη στις οδηγίες

## Κάποιες επιπλέον σημειώσεις για την υλοποίηση σε C++

Αυτή η άσκηση χρησιμοποιεί το [`unordered_set`][set]
Πιθανότατα θα χρειαστείς τη συνάρτηση [`emplace`][emplace] για να προσθέσεις στοιχεία στο σύνολο.

Μπορεί να πέσεις πάνω στο [`const`][const], γιατί δεν έχει εμφανιστεί ακόμα στην ύλη.
Όταν μπαίνει μπροστά από μια μεταβλητή, λειτουργεί σαν δικλίδα ασφαλείας.
Οι μεταβλητές `const` δε μπορούν να αλλάξουν.
Αυτή η άσκηση περιλαμβάνει επίσης τη λέξη-κλειδί [`unsigned`][unsigned].
Αυτό διπλασιάζει το εύρος του ακέραιου στον οποίο μπαίνει μπροστά, αλλά δεν του επιτρέπει να γίνει αρνητικός.
