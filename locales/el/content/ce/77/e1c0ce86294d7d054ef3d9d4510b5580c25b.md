# Οδηγίες

Αναπτύσσεις ένα σύστημα για να βοηθήσεις το προσωπικό της ιστοσελίδας ενός ποδοσφαιρικού συλλόγου να κάνει ρεπορτάζ για τους αγώνες.
Αυτό το σύστημα μπορεί να αναλύει διάφορες πτυχές του αγώνα, εντός και εκτός γηπέδου, και τις μετατρέπει σε μια ροή γεγονότων.

## 1. Εμφάνισε περιγραφές των παικτών με βάση τον αριθμό της φανέλας τους

Η ομάδα παίζει πάντα με διάταξη 4-3-3 και δεν συμφώνησε ποτέ με την αλλαγή των κανόνων του 1965 που επέτρεπε αλλαγές παικτών, πόσο μάλλον με τις διευρυμένες ομάδες.

Οι περιγραφές των παικτών είναι οι εξής:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 -> "center back"
5 -> "right back"
6, 7 & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Υλοποίησε τη στατική μέθοδο `PlayAnalyzer.AnalyzeOnField()` ώστε να εμφανίζει μια περιγραφή παίκτη με βάση τον αριθμό της φανέλας του.

```csharp
PlayAnalyzer.AnalyzeOnField(10);
// => "striker"
```

## 2. Χειρίσου άγνωστους αριθμούς φανέλας

Τροποποίησε τη μέθοδο `PlayAnalyzer.AnalyzeOnField()` ώστε να αναφέρει `UNKNOWN` όταν επεξεργάζεται ένας αριθμός φανέλας εκτός του εύρους 1-11.

## 3. Επέκτεινε την κάλυψη ώστε να περιλαμβάνει δραστηριότητα εκτός γηπέδου

Υλοποίησε τη μέθοδο `PlayAnalyzer.AnalyzeOffField()` ώστε να εμφανίζει περιγραφές δραστηριοτήτων και προσώπων γύρω από τον αγωνιστικό χώρο.
Αυτή η μέθοδος δέχεται διαφορετικούς τύπους δεδομένων που πρέπει να αναλυθούν και να μετατραπούν στο κατάλληλο κείμενο για να βοηθήσουν τους δημοσιογράφους.

Για αρχή, θα καλύψουμε δεδομένα για το γήπεδο:

- Τον τρέχοντα αριθμό φιλάθλων στο γήπεδο (οποιοσδήποτε `int`)
- Ανακοινώσεις που γίνονται από το σύστημα μεγαφώνων του γηπέδου (οποιαδήποτε `string`)

Οι άγνωστοι τύποι δεδομένων δεν πρέπει να επεξεργάζονται, οπότε αν η μέθοδος λάβει δεδομένα διαφορετικού τύπου, θα πρέπει να επιστραφεί μια κενή συμβολοσειρά.

```csharp
PlayAnalyzer.AnalyzeOffField(5000);
// => "There are 5000 supporters at the match."

PlayAnalyzer.AnalyzeOffField("5 minutes to go!");
// => "5 minutes to go!"

PlayAnalyzer.AnalyzeOffField(0.5);
// => ""
```

## 4. Ανάφερε περιστατικά κατά τη διάρκεια του αγώνα

Τροποποίησε τη μέθοδο `PlayAnalyzer.AnalyzeOffField()` ώστε να εμφανίζει περιγραφές των περιστατικών που συμβαίνουν κατά τη διάρκεια του αγώνα.

Τα περιστατικά μπορεί να είναι οποιαδήποτε υποκλάση του τύπου `Incident` και θα περιέχουν μια περιγραφή του περιστατικού.
Οι τραυματισμοί είναι ένα ιδιαίτερο είδος περιστατικού, επειδή προκαλούν τη διακοπή του αγώνα, οπότε θα πρέπει να αντιμετωπίζονται διαφορετικά.

```csharp
PlayAnalyzer.AnalyzeOffField(new Foul());
// => "The referee deemed a foul."

PlayAnalyzer.AnalyzeOffField(new Injury(8));
// => "Oh no! Player 8 is injured. Medics are on the field."
```

## 5. Ανάφερε τους προπονητές των συλλόγων

Τροποποίησε τη μέθοδο `PlayAnalyzer.AnalyzeOffField()` ώστε να αναφέρει τους προπονητές των συλλόγων που είναι παρόντες στον αγώνα.

Οι προπονητές είναι στιγμιότυπα του τύπου `Manager` και έχουν ένα όνομα και το όνομα του συλλόγου που προπονούν.
Ο σύλλογος του προπονητή μπορεί να είναι άγνωστος, οπότε θα οριστεί σε `null`.
Αν ο σύλλογος ενός προπονητή δεν είναι γνωστός, δεν θα πρέπει να αποτελεί μέρος της περιγραφής.

```csharp
PlayAnalyzer.AnalyzeOffField(new Manager("José Mário dos Santos Mourinho Félix", null));
// => "José Mário dos Santos Mourinho Félix"

PlayAnalyzer.AnalyzeOffField(new Manager("Jürgen Klopp", "Liverpool"));
// => "Jürgen Klopp (Liverpool)"
```
