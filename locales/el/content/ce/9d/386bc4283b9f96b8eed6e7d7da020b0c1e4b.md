# Υποδείξεις

## 1. Ανάλυσε την ημερομηνία του ραντεβού

- Η κλάση `LocalDateTime` έχει μια μέθοδο για να [αναλύσει][localdatetime-parse] ένα `String` σε ένα `LocalDateTime`.
- Χρησιμοποίησε ένα [`DateTimeFormatter`][datetimeformatter-docs] με προσαρμοσμένο μοτίβο για να αναλύσεις μια μη τυπική μορφή ημερομηνίας/ώρας.

## 2. Έλεγξε αν ένα ραντεβού έχει ήδη περάσει

- Τα στιγμιότυπα `LocalDateTime` έχουν [μεθόδους][localdatetime-methods] για να τα συγκρίνεις με άλλα `LocalDateTime`.
- Υπάρχει μια [μέθοδος][localdatetime-methods] για να ανακτήσεις την τρέχουσα ημερομηνία και ώρα.

## 3. Έλεγξε αν το ραντεβού είναι απογευματινό

- Η πρόσβαση στο τμήμα ώρας ενός στιγμιότυπου `LocalDateTime` μπορεί να γίνει μέσω μιας από τις [μεθόδους][localdatetime-methods] του.

## 4. Περιέγραψε την ώρα και την ημερομηνία του ραντεβού

- Χρησιμοποίησε ένα [`DateTimeFormatter`][datetimeformatter-docs] με προσαρμοσμένο μοτίβο για να μορφοποιήσεις το `LocalDateTime`.
- Τα tests τρέχουν σαν να τρέχουν σε μηχάνημα στις Ηνωμένες Πολιτείες, οπότε βεβαιώσου ότι ο μορφοποιητής [χρησιμοποιεί το σωστό locale][datetimeformatter-ofpattern-with-locale].

## 5. Επιστρέψε την ημερομηνία επετείου

- Η κλάση `LocalDate` έχει μια [μέθοδο][localdate-methods] για να ανακτήσεις την τρέχουσα ημερομηνία.
- Η πρόσβαση στο έτος ενός στιγμιότυπου `LocalDate` μπορεί να γίνει μέσω μιας από τις [μεθόδους][localdate-methods] του.
