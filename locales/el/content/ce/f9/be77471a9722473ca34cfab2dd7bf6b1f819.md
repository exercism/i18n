# Hints

## Γενικά

- Ρίξε μια ματιά στην [τεκμηρίωση του `elm/time`][elm-time] για να δουλέψεις με ημερομηνίες και ώρες
- Η εισαγωγή παρουσιάζει τις περισσότερες από τις απαραίτητες έννοιες για να λύσεις την άσκηση

## 1. Είναι ημερομηνία

- Η [συνάρτηση `String.fromInt`][fromInt] μπορεί να μετατρέψει αριθμούς σε συμβολοσειρές
- Θα χρειαστεί να μετατρέψεις τους μήνες στην αριθμητική τους αναπαράσταση. Σκέψου να δημιουργήσεις μια βοηθητική συνάρτηση
- Για την ιαπωνική τοπική ρύθμιση, μπορείς να κάνεις αντιγραφή και επικόλληση των χαρακτήρων από τις οδηγίες (年, 月, 日), οι αριθμοί δε θα πρέπει να μορφοποιούνται με ιαπωνική κωδικοποίηση

## 2. Ώρα για σόου

- Η [συνάρτηση `modBy`][modBy] μπορεί να βοηθήσει στη μετατροπή ώρας
- Χρησιμοποίησε τη [`String.padLeft`][padLeft] για να διασφαλίσεις ότι τα λεπτά έχουν αρχικά μηδενικά
- Για την ιαπωνική τοπική ρύθμιση, μπορείς να κάνεις αντιγραφή και επικόλληση των χαρακτήρων από τις οδηγίες (時, 分), οι αριθμοί δε θα πρέπει να μορφοποιούνται με ιαπωνική κωδικοποίηση

## 3. Μπες στη ζώνη

- Οι συναρτήσεις [`Time.toYear`][toYear], [`Time.toMonth`][toMonth] και [`Time.toDay`][toDay] μπορούν να σε βοηθήσουν να πάρεις τα τμήματα της ημερομηνίας
- Οι συναρτήσεις [`Time.toHour`][toHour] και [`Time.toMinute`][toMinute] μπορούν να σε βοηθήσουν να πάρεις τα τμήματα της ώρας
- Συνδύασε τα αποτελέσματα από τις `showLocalDate` και `showLocalTime`
