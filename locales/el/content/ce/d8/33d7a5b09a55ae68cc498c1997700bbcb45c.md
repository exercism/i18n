# Περιγραφή

Μια πυθαγόρεια τριάδα είναι ένα σύνολο τριών φυσικών αριθμών, {a, b, c}, για τους οποίους ισχύει ότι

```text
a² + b² = c²
```

και ότι

```text
a < b < c
```

Για παράδειγμα,

```text
3² + 4² = 5².
```

Δεδομένου ενός ακέραιου αριθμού N, βρες όλες τις πυθαγόρειες τριάδες για τις οποίες `a + b + c = N`.

Για παράδειγμα, με N = 1000, υπάρχει ακριβώς μία πυθαγόρεια τριάδα για την οποία `a + b + c = 1000`: `{200, 375, 425}`.
