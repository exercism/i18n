# Προσθήκη στις οδηγίες

## Σημειώσεις ειδικά για τη Rust

Αυτό αλλάζει ελαφρώς στη Rust, σε σύγκριση με τις εκδόσεις αυτής της άσκησης σε άλλες γλώσσες. Αντί να σου ζητάμε να επιστρέφεις σφάλματα για τιμές εκτός εύρους, χρησιμοποιούμε το ισχυρό σύστημα τύπων της Rust για να περιορίσουμε την είσοδο. Είναι πολύ πιο εύκολο να φτιάξεις μια συνάρτηση που να χειρίζεται όλες τις έγκυρες εισόδους, παρά να απαιτείς από τον χρήστη του module σου να χειρίζεται σφάλματα.

### Επέκταση

Πρόσθεσε τη δυνατότητα μετατροπής μέχρι τη μέγιστη τιμή για το u64: `18_446_744_073_709_551_615`.

Για μια ιδέα για την έξοδο που θα πρέπει να έχει, κοίταξε την τελευταία περίπτωση δοκιμής.
