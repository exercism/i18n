# Εισαγωγή

Ένα `String` στη Haxe είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης, κ.λπ.). Τα διπλά εισαγωγικά χρησιμοποιούνται για να ορίσουν ένα στιγμιότυπο `String`:

```haxe
var fruit:String = "Apple";
```

Οι συμβολοσειρές χειρίζονται καλώντας τις μεθόδους της συμβολοσειράς. Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί ποτέ να αλλάξει. Οποιεσδήποτε μέθοδοι φαίνεται να τροποποιούν μια συμβολοσειρά στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.

Πολλαπλές συμβολοσειρές μπορούν να συνενωθούν (να προστεθούν) μαζί. Ο απλούστερος τρόπος για να το πετύχεις αυτό είναι χρησιμοποιώντας τον τελεστή `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Για οποιαδήποτε μορφοποίηση συμβολοσειράς πιο σύνθετη από την απλή συνένωση, προτιμάται η παρεμβολή συμβολοσειρών. Για να χρησιμοποιήσεις παρεμβολή σε μια συμβολοσειρά, βάλε την ανάμεσα σε χαρακτήρες μονών εισαγωγικών (`'`). Στη συνέχεια, μπορείς να χρησιμοποιήσεις το σύμβολο του δολαρίου (`$`) για να ενεργοποιήσεις την παρεμβολή:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
