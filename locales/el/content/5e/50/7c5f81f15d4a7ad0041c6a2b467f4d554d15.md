# Σχετικά

Το [`fold`][fold] είναι ένας [καταναλωτικός προσαρμογέας επαναλήπτη][consuming iterator adaptor] που εφαρμόζει μια συνάρτηση σε κάθε στοιχείο της επανάληψης, συσσωρεύοντας το αποτέλεσμα σε μια νέα τιμή.

Κάθε επανάληψη του `fold` δέχεται δύο ορίσματα. Το πρώτο είναι μια αρχική τιμή για τον συσσωρευτή. Το δεύτερο είναι ένα closure που δέχεται και το ίδιο δύο ορίσματα: τον συσσωρευτή και ένα στοιχείο. Η τιμή επιστροφής του closure είναι η επόμενη τιμή του συσσωρευτή.
Μόλις εξαντληθεί ο επαναλήπτης, επιστρέφεται η τελική τιμή του συσσωρευτή.

Το `fold` μπορεί να χρησιμοποιηθεί όταν θέλεις να μετασχηματίσεις μια συλλογή σε μία μόνο τιμή. Για παράδειγμα, αν θέλεις το άθροισμα όλων των άρτιων αριθμών

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Τυπώνει `30`.

Αυτό που μπορεί να γίνει με το `fold` μπορεί συχνά να γίνει με μια άλλη συνάρτηση ή συναρτήσεις. Για το παραπάνω, το να κάνεις [`filter`][filter] στο `(1..=10)` και μετά [`sum`][sum] θα ήταν πιο σύντομο και θα έδινε το ίδιο αποτέλεσμα, κάπως έτσι

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Άλλες συναρτήσεις που χρησιμοποιούνται πιο συχνά από το `fold` περιλαμβάνουν τις [`product`][product] και [`collect`][collect].

Ο συσσωρευτής μπορεί να χρησιμοποιηθεί και για μη αριθμητικές τιμές. Για παράδειγμα

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Τυπώνει `FeeFiFoFum`
