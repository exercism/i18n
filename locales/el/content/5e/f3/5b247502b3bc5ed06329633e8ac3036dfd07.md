# Σχετικά

Μια [εντολή switch][switch] συγκρίνει μια τιμή με πολλά πιθανά μοτίβα που μπορεί να ταιριάξουν.
Προσφέρει μια πιο καθαρή και πιο ευανάγνωστη εναλλακτική από το να συνδυάζεις πολλαπλές εντολές `if-else`.

Μια εντολή `switch` ξεκινά με τη λέξη-κλειδί `switch` ακολουθούμενη από την τιμή που θα ελεγχθεί.
Κάθε πιθανή αντιστοίχιση εισάγεται με τη λέξη-κλειδί `case`.
Η λέξη-κλειδί `default` ορίζει μια εφεδρική περίπτωση που εκτελείται όταν καμία από τις ρητές περιπτώσεις δεν ταιριάζει.
Όπως οι αλυσίδες `if-else`, έτσι και μια εντολή `switch` εκτελεί μόνο το μπλοκ κώδικα που σχετίζεται με την πρώτη περίπτωση που ταιριάζει.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Ας δούμε την παρακάτω αλυσίδα `if-else`:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Αυτό μπορεί να γραφτεί πιο καθαρά με μια εντολή `switch`:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Δέσμευση τιμών και ρήτρες `where`

Μια περίπτωση `switch` μπορεί να δεσμεύσει τις τιμές που ταιριάζουν σε προσωρινές σταθερές ή μεταβλητές, ώστε να χρησιμοποιηθούν στο σώμα της συγκεκριμένης περίπτωσης.
Οι περιπτώσεις μπορούν επίσης να περιλαμβάνουν ρήτρα `where`, για να ελέγχονται επιπλέον συνθήκες Boolean πριν από την αντιστοίχιση:

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
