# Υποδείξεις

## Γενικά

- Ρίξε μια ματιά στην [αναφορά γλώσσας για τους πίνακες][ref-arrays]
- Ρίξε μια ματιά στην [αναφορά συναρτήσεων για πίνακες][ref-array-functions]

## 1. Όρισε μια συνάρτηση που να επιστρέφει μια κενή λίστα γλωσσών

- Ρίξε μια ματιά στην [αναφορά γλώσσας][ref-arrays]
- Μπορείς να επιστρέψεις έναν κενό πίνακα

## 2. Τροποποίησε τη συνάρτηση ώστε να δημιουργεί μια λίστα από οποιονδήποτε αριθμό γλωσσών

- Δες την αναφορά συναρτήσεων για [ορίσματα μεταβλητού μήκους][variable-arguments]

## 3. Όρισε μια συνάρτηση που να προσθέτει μια γλώσσα στη λίστα

- Δημιούργησε μια νέα συνάρτηση για να κάνεις τη λειτουργία
- Χρησιμοποίησε ξανά μια [υπάρχουσα συνάρτηση][ref-array-functions] ή χρησιμοποίησε τη [σύνταξη εισαγωγής][square-bracket-syntax]

## 4. Όρισε μια συνάρτηση που να αφαιρεί ένα στοιχείο από τη λίστα γλωσσών

- Δημιούργησε μια νέα συνάρτηση για να κάνεις τη λειτουργία
- Χρησιμοποίησε ξανά μια [υπάρχουσα συνάρτηση][ref-array-functions] για να κάνεις τη λειτουργία

## 5. Όρισε μια συνάρτηση που να παίρνει το πρώτο στοιχείο της λίστας

- Δημιούργησε μια νέα συνάρτηση για να κάνεις τη λειτουργία
- Χρησιμοποίησε τη [σύνταξη θέσης][index-syntax] για να πάρεις το πρώτο στοιχείο

## 6. Όρισε μια συνάρτηση που να επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

- Δημιούργησε μια νέα συνάρτηση για να κάνεις τη λειτουργία
- Χρησιμοποίησε ξανά μια [υπάρχουσα συνάρτηση][ref-array-functions] για να κάνεις τη λειτουργία
