# Αναφορά Rust

## Έννοιες

Οι ασκήσεις εννοιών της Rust διδάσκουν έννοιες, από τα βασικά μέχρι την κατάκτηση της γλώσσας. Ταξινομούνται και παρατίθενται παρακάτω.

Οι έννοιες του Exercism υπάρχουν για να υπηρετούν όσους μαθαίνουν με πρακτικούς τρόπους, γι' αυτό και διαφέρουν από τις αφηρημένες ιδέες. Αυτό το έγγραφο ορίζει τι σημαίνουν αυτές οι έννοιες στη Rust. Προσθέσαμε την παρακάτω οπτική ομαδοποίηση για να βοηθήσουμε τους συντηρητές των track να φτιάξουν ένα αποτελεσματικό έγγραφο αναφοράς. Τέτοιες ομαδοποιήσεις _δεν_ αποτελούν παιδαγωγικές διαιρέσεις. Έτσι, μην αναφέρεσαι σε αυτές όταν διδάσκεις.

Τα πλαίσια ελέγχου δείχνουν ποιες έννοιες διδάσκονται ήδη στη λίστα αντιστοίχισης ασκήσεων.

## Αντιστοίχιση ασκήσεων εννοιών

Ενώ το ιδανικό είναι να υπάρχει μία μόνο άσκηση εννοιών για καθεμία από τις έννοιες που παρατίθενται παραπάνω, η οποία να διδάσκει ακριβώς μία έννοια και να απαιτεί μόνο τα προαπαιτούμενά της, κάτι τέτοιο δεν είναι απολύτως πρακτικό. Για παράδειγμα, θα ήταν δύσκολο να σχεδιάσεις μια άσκηση που να διδάσκει τι είναι οι συναρτήσεις χωρίς να απαιτεί καμία γνώση πρωτογενών τύπων· παρομοίως, θα ήταν δύσκολο να διδάξεις πρωτογενείς τύπους, με μια σουίτα δοκιμών, χωρίς καμία γνώση συναρτήσεων.

Οι ασκήσεις σε αυτόν τον πίνακα θα πρέπει να σχηματίζουν ένα DAG που τελικά θα καλύπτει όλες τις έννοιες που παρατίθενται παραπάνω.

| άσκηση                 | προαπαιτούμενα                               | διδάσκει                                                  | αφήγηση                                                                          |
| ---------------------- | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | συναρτήσεις, σουίτες δοκιμών                             | επιστροφή του literal `&str` `"hello world"`                                     |
| `compiled-calculator`    | `hello-world`                                | ακέραιοι, ανάθεση μεταβλητής                             | εκτέλεσε μια σειρά μαθηματικών πράξεων και επέστρεψε σιωπηρά το αποτέλεσμα       |
| `conditionals`           | `hello-world`                                | συνθήκες                                                 | να δομηθεί ως `if` / `else if` / `else` με τρεις κλάδους, με σιωπηρή επιστροφή   |
| `slices`                 | `hello-world`, `compiled-calculator`         | slices                                                   | εξαγωγή ενός slice από μια παράμετρο που είναι slice ακεραίων                    |
| `loops`                  | `slices`                                     | βασική επανάληψη πάνω σε ένα slice                       | ιδανικά με πρώιμη επιστροφή, ώστε να είναι δύσκολο να εκφραστεί ως iterator      |
| `iterator-use`           | `slices`                                     | χρήση iterator, `collect`                                |
| `integer-sizes`          | `compiled-calculator`                        | ακέραιοι εκτός από `i32`, μετατροπή τύπου                | ακόμα όλοι με πρόσημο                                                            |
| `unsigned-ints`          | `integer-sizes`                              | ακέραιοι χωρίς πρόσημο                                   |
| `indexing`               | `integer-sizes`, `slices`                    | ευρετηρίαση, `usize`                                     |
| `floats`                 | `compiled-calculator`                        | αριθμοί κινητής υποδιαστολής                             | πιθανώς η ίδια άσκηση υπολογιστή, με μη ακέραια αποτελέσματα                     |
| `bools`                  | `compiled-calculator`                        | Boolean, λογικοί τελεστές                                |
| `char`                   | `compiled-calculator`                        | ο τύπος δεδομένων `char`                                 | θα πρέπει να περιλαμβάνει μερικά παραδείγματα με wide chars                      |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | σημείωση: αμετάβλητο!                                                             |
| `string-use`             | `str-use`                                    | `String`                                                 | σημείωση: με ιδιοκτησία, μεταβλητό                                               |
| `format-macro`           | `string-use`                                 | μακροεντολή `format!`                                    |
| `str-vs-string`          | `str-use`, `string-use`                      | συνδυασμός, μετατροπή, κόστη κ.λπ.                       |
| `generics-basics`        | `integer-sizes`, `floats`                    | χρήση εξωτερικών traits ως όρια, βασικά generics         | πιθανώς πάλι ο υπολογιστής, απλώς γενικευμένος                                   |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | δημιουργία και χρήση μιας δομής για τη διαχείριση δεδομένων | η `Person` έχει όνομα, ύψος και πλήθος παπουτσιών που κατέχει                   |
| `implicit-return`        | `compiled-calculator`                        | εμβέλειες, εκφράσεις, σιωπηρή επιστροφή                  |
| `explicit-return`        | `implicit-return`, `conditionals`            | ρητή εντολή `return`                                     |
| `methods`                | `structs`, `explicit-return`                 | μπλοκ `impl`, μέθοδοι                                    |
| `tuples`                 | `structs`                                    | πλειάδες                                                 | δίδαξέ τες ως ανώνυμες δομές, δίδαξε τη σύνταξη `.0`                              |
| `tuple-structs`          | `tuples`, `structs`                          | δομές πλειάδας (επώνυμες πλειάδες)                       |
| `basic-enums`            | `unsigned-ints`                              | βασικές απαριθμήσεις (χωρίς πεδία), `match`              |
| `enums`                  | `basic-enums`, `tuple-structs`               | σύνταξη πλειάδας για παραλλαγές απαρίθμησης              |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | αμεταβλητότητα εξ ορισμού, ρητή μεταβλητότητα            |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | πιθανώς θα εξαρτάται μόνο από το `option` ή το `result`, ανάλογα με την υλοποίηση |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | χειροκίνητη υλοποίηση ενός trait                         | πιθανώς να υλοποιεί το `Iterator`                                                |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
