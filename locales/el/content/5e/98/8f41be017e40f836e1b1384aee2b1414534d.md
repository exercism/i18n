# Δοκιμές στο track MoonScript

Οι δοκιμές στο track MoonScript είναι ακριβώς ίδιες με τις [δοκιμές στο track Lua][lua-tests].
Από τον κατάλογο μιας άσκησης, πληκτρολόγησε:

```console
$ busted
```

## Εκκρεμή τεστ

Αυτό το track ακολουθεί τη μεθοδολογία [Ανάπτυξη Καθοδηγούμενη από Τεστ][tdd] του Exercism.
Σου δίνεται μια πλήρης σουίτα τεστ, αλλά μόνο το πρώτο τεστ είναι "ενεργό".

Για να ενεργοποιήσεις τα τεστ, άλλαξε την εντολή ενός τεστ από `pending` σε `it`.

Αν σου αρέσει να τρέχεις όλα τα τεστ όλη την ώρα, μπορείς να χρησιμοποιήσεις ένα εργαλείο γραμμής εντολών για να τα αλλάξεις όλα μαζί.
Ορίστε ένα παράδειγμα με τη perl (η οποία είναι εγκατεστημένη σχεδόν παντού):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Όταν εργάζεσαι στον online editor, ο test runner θα τρέξει αυτόματα όλα τα τεστ.

## Χρήση του LuaRocks

Η Lua από μόνη της είναι μια πολύ μικρή γλώσσα.
Το [LuaRocks][luarocks] είναι ο διαχειριστής πακέτων για αρθρώματα της Lua.

Μπορείς ελεύθερα να χρησιμοποιήσεις οποιοδήποτε άρθρωμα στις λύσεις σου, αλλά δεν θα είναι όλα διαθέσιμα στον online test runner.
Ο test runner παρέχει τα εξής:

**Ήδη διαθέσιμα ως εξαρτήσεις του `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Ήδη διαθέσιμα ως εξαρτήσεις της MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Ημερομηνία και ώρα**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
