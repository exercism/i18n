# Εισαγωγή

Το `when` είναι η λέξη-κλειδί στο φιλτράρισμα εξαιρέσεων. Τοποθετείται μετά την εντολή `catch` και μπορεί να δεχτεί μια έκφραση Boolean που περιέχει οποιεσδήποτε τιμές βρίσκονται στο πεδίο εφαρμογής εκείνη τη στιγμή. Αν η έκφραση αποτιμάται ως αληθής, τότε εκτελείται το μπλοκ κώδικα που σχετίζεται με αυτή την εντολή `catch`. Διαφορετικά, ελέγχεται η επόμενη εντολή `catch`, αν υπάρχει.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
