# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που κρατάει καθημερινό μητρώο για τα πουλιά
που επισκέπτονται τον κήπο σου. Οι μετρήσεις αποθηκεύονται σε έναν πίνακα, με την
παλαιότερη μέρα πρώτη.

## 1. Η σημερινή μέτρηση

Όρισε το `today` ώστε να παίρνει τον πίνακα με τις καθημερινές μετρήσεις από τη
στοίβα και να επιστρέφει τη μέτρηση για τη σημερινή μέρα.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Αύξησε τη σημερινή μέτρηση

Όρισε το `increment-todays-count` ώστε να επιστρέφει έναν νέο πίνακα με τη σημερινή
μέτρηση αυξημένη κατά ένα. Ο αρχικός πίνακας δεν πρέπει να τροποποιηθεί.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. Υπήρξε μέρα χωρίς πουλιά;

Όρισε το `has-day-without-birds?` ώστε να επιστρέφει `t` αν τουλάχιστον μία μέρα
κατέγραψε μηδέν πουλιά, αλλιώς `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Άθροισε τις πρώτες λίγες μέρες

Όρισε το `count-for-first-days` ώστε να παίρνει έναν πίνακα με μετρήσεις και έναν
αριθμό `n`, και να επιστρέφει το άθροισμα των πρώτων `n` μετρήσεων.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Μέτρησε τις γεμάτες μέρες

Μια γεμάτη μέρα είναι μια μέρα με πέντε ή περισσότερα πουλιά. Όρισε το `busy-days`
ώστε να επιστρέφει τον αριθμό των γεμάτων ημερών στον πίνακα.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Συμπλήρωσε τις μέρες που λείπουν

Αν δεν παρατήρησες κάθε μέρα ενός διαστήματος `n` ημερών, συμπλήρωσε τις μέρες που
λείπουν στο τέλος με `0`. Όρισε το `pad-missing-days` ώστε να παίρνει έναν πίνακα με
μετρήσεις και ένα μήκος-στόχο `n`, και να επιστρέφει έναν πίνακα μήκους τουλάχιστον
`n` του οποίου οι επιπλέον θέσεις είναι `0`. Οι υπάρχουσες μετρήσεις πρέπει να
διατηρηθούν αναλλοίωτες· αν η είσοδος έχει ήδη μήκος τουλάχιστον `n`, επέστρεψέ την
αναλλοίωτη.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
