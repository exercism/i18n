# Σχετικά

Μια συνάρτηση είναι ένα μπλοκ οργανωμένου, επαναχρησιμοποιήσιμου κώδικα που χρησιμοποιείται για την εκτέλεση κάποιας ενέργειας.
Υπάρχουν πολλοί τρόποι για να ορίσεις συναρτήσεις στη JavaScript.
Εδώ θα δούμε τις _δηλώσεις συνάρτησης_ και τις _εκφράσεις συνάρτησης_.
Άλλες δυνατότητες, όπως οι [arrow functions][concept-arrow-functions], θα καλυφθούν σε άλλες έννοιες.

## Δήλωση συνάρτησης

Ο καθιερωμένος τρόπος για να ορίσεις μια συνάρτηση στη JavaScript είναι η _δήλωση συνάρτησης_, που ονομάζεται επίσης _ορισμός συνάρτησης_ ή _εντολή συνάρτησης_.

Αποτελείται από τη λέξη-κλειδί `function`, το όνομα της συνάρτησης και μια λίστα παραμέτρων χωρισμένων με κόμμα, μέσα σε παρενθέσεις.
Ακολουθεί το σώμα της συνάρτησης (η συλλογή εντολών που καθορίζει τι κάνει μια συνάρτηση), μέσα σε άγκιστρα.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

## Χρήση μιας συνάρτησης

Στη JavaScript, μια συνάρτηση καλείται αναφέροντας το όνομα της συνάρτησης ακολουθούμενο από παρενθέσεις που περιέχουν τα ορίσματα.

```javascript
someName(arg1, arg2, arg3);
```

Το να αναφέρεις απλώς το όνομα της συνάρτησης **δεν** καλεί τη συνάρτηση στη JavaScript.

```javascript
function sayHello() {
  console.log('Hello, World!');
}

sayHello;
// => [Function: sayHello]
// The text representations varies between environments.

sayHello();
// => 'Hello, World!'
```

## Παράμετροι

Όταν δουλεύεις με παραμέτρους μέσα στο σώμα της συνάρτησης, να έχεις υπόψη σου τις πιθανές παρενέργειες στην αρχική τιμή που πέρασε στη συνάρτηση.
Στη JavaScript, ένα όρισμα είναι ένα αντίγραφο μιας αναφοράς στην αρχική τιμή.
Το τι σημαίνει αυτό στην πράξη εξαρτάται από τον τύπο δεδομένων του ορίσματος.

- Οι τιμές των [πρωτόγονων τύπων δεδομένων][mdn-primitives] είναι _αμετάβλητες_.
  Όλες οι "τροποποιήσεις" δημιουργούν πάντα μια νέα πρωτόγονη τιμή.
  Γι' αυτό, η αρχική τιμή δεν επηρεάζεται ποτέ από το τι συμβαίνει στο όρισμα μέσα στο σώμα της συνάρτησης.

  ```javascript
  const num = 0;

  function increase(number) {
    number = number + 1;
  }

  increase(num);
  num;
  // => 0
  ```

- Διαφορετικά είναι τα πράγματα για τιμές όπως τα _αντικείμενα_, οι _πίνακες_ και οι _συναρτήσεις_.
  Εφόσον η αναφορά αντιγράφεται, μια εκ νέου ανάθεση δεν θα επηρεάσει την αρχική τιμή.
  Ωστόσο, επειδή έχεις να κάνεις με ένα [ρηχό αντίγραφο][wikipedia-shalllow-copy], η τροποποίηση του ορίσματος μέσα στο σώμα της συνάρτησης θα αλλάξει και την αρχική τιμή που πέρασε.

  ```javascript
  const nums = [0, 1, 2, 3, 4];

  function pushFive(arr) {
    arr.push(5);
  }

  pushFive(nums);
  nums;
  // => [0, 1, 2, 3, 4, 5]
  ```

Από προεπιλογή, όλες οι παράμετροι που ορίζονται στη δήλωση της συνάρτησης είναι προαιρετικές στη JavaScript.
Αν σε μια συνάρτηση δοθούν λιγότερα ορίσματα από όσες είναι οι παράμετροι, τα ορίσματα που λείπουν θα είναι `undefined` μέσα στο σώμα της συνάρτησης, δες [Null and Undefined][concept-null-undefined].
Σε πολλές περιπτώσεις, έχει περισσότερο νόημα να αρχικοποιήσεις μια παράμετρο με μια _προεπιλεγμένη_ τιμή, αν δεν περαστεί καμία τιμή ή κάποια ιδιότητα `undefined`.
Αυτό μπορεί να γίνει ορίζοντας προεπιλεγμένες παραμέτρους απευθείας στον ορισμό της συνάρτησης.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

Μια συνάρτηση μπορεί να κληθεί με περισσότερα ορίσματα από όσες ήταν οι παράμετροι στον ορισμό της.
Όλα τα ορίσματα, μαζί και αυτά τα επιπλέον, βρίσκονται στον [πίνακα "arguments"][mdn-arguments-object].

Είναι επίσης δυνατό να ορίσεις συναρτήσεις που δέχονται οποιονδήποτε αριθμό ορισμάτων (συναρτήσεις μεταβλητού αριθμού ορισμάτων), δες τις παραμέτρους rest στους [Rest and Spread Operators][concept-rest-and-spread] για περισσότερες λεπτομέρειες.

## Εντολή `return`

Μια εντολή `return` τερματίζει την εκτέλεση της συνάρτησης και καθορίζει μια τιμή που θα επιστραφεί σε αυτόν που κάλεσε τη συνάρτηση. Μια συνάρτηση μπορεί να έχει πολλές εντολές `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

Το αποτέλεσμα μιας συνάρτησης που δεν επιστρέφει καμία τιμή ή που δεν έχει εντολή `return` είναι `undefined`.
Δεν υπάρχουν υπονοούμενες εντολές `return` στη JavaScript.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

Στη JavaScript, μπορείς να επιστρέψεις μόνο μία τιμή.
Αν θέλεις να περάσεις περισσότερες πληροφορίες, πρέπει πρώτα να τις συνδυάσεις σε μία οντότητα, συνήθως σε ένα [αντικείμενο][concept-objects] ή σε έναν [πίνακα][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Έκφραση συνάρτησης

Μια δήλωση συνάρτησης είναι μια αυτόνομη εντολή.
Αλλά μερικές φορές είναι χρήσιμο να ορίσεις μια συνάρτηση ως μέρος μιας άλλης έκφρασης, π.χ. σε μια ανάθεση, ως παράμετρο συνάρτησης ([callback][concept-callbacks]) ή ως τιμή μέσα σε ένα [αντικείμενο][concept-objects].
Αυτό μπορεί να γίνει με μια έκφραση συνάρτησης.
Έχει την ίδια σύνταξη με μια δήλωση συνάρτησης, μόνο που το όνομα της συνάρτησης μπορεί να παραλειφθεί, δημιουργώντας μια _ανώνυμη συνάρτηση_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```

## Εμβέλεια

Μια συνάρτηση εισάγει ένα νέο περιβάλλον εκτέλεσης στη JavaScript.
Οι μεταβλητές που ορίζονται μέσα σε μια συνάρτηση δεν είναι προσβάσιμες έξω από αυτήν.
Αλλά οι μεταβλητές που ορίζονται στη γονική εμβέλεια (την εμβέλεια όπου ορίστηκε η ίδια η συνάρτηση) είναι προσβάσιμες μέσα στη συνάρτηση.
Η [τεκμηρίωση του MDN για την εμβέλεια][mdn-scope] δείχνει παραδείγματα αυτής της συμπεριφοράς.

Ρίξε μια ματιά στα [closures][concept-closures] για να μάθεις περισσότερα για την εμβέλεια των μεταβλητών στη JavaScript.
