# Εκτέλεση των τεστ

Διάλεξε το λειτουργικό σου σύστημα:

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. Άνοιξε ένα Command Prompt.
2. Κατέβασε την πρώτη άσκηση:

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. Πήγαινε στον κατάλογο της άσκησης:

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. Τρέξε τα τεστ:

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _(Μην ανησυχείς αν τα τεστ αποτύχουν στην αρχή, έτσι ξεκινάς κάθε άσκηση.)_

5. Λύσε την άσκηση. Βρες και δούλεψε τον οδηγό `instructions.append.md` ([δες το στο GitHub][hello-world-tutorial]).

Καλή τύχη! Καλή διασκέδαση!

4. Λύσε την άσκηση. Βρες και δούλεψε τον οδηγό `instructions.append.md` ([δες το στο GitHub][hello-world-tutorial]).

Καλή τύχη! Καλή διασκέδαση!

## Linux

1. Στο παράθυρο τερματικού, κατέβασε την πρώτη άσκηση:

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. Πήγαινε στον κατάλογο της άσκησης:

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. Τρέξε τα τεστ:

   ```sh
   ./gradlew test
   ```

   _(Μην ανησυχείς αν τα τεστ αποτύχουν στην αρχή, έτσι ξεκινάς κάθε άσκηση.)_

   Αν σου εμφανιστεί το παρακάτω σφάλμα:

   ```sh
   ./gradlew: Permission denied
   ```

   Τότε το αρχείο δεν έχει δικαίωμα εκτέλεσης. Για να το διορθώσεις, τρέξε:

   ```sh
   chmod +x ./gradlew
   ```

   Και τώρα θα πρέπει να μπορείς να τρέξεις την προηγούμενη εντολή.

4. Λύσε την άσκηση. Βρες και δούλεψε τον οδηγό `instructions.append.md` ([δες το στο GitHub][hello-world-tutorial]).

Καλή τύχη! Καλή διασκέδαση!
