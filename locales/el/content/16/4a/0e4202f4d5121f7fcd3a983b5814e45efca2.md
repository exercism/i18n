# Εισαγωγή

Πολλά προγράμματα χρειάζονται (_φαινομενικά_) τυχαίες τιμές για να προσομοιώσουν γεγονότα του πραγματικού κόσμου.

Συνήθη, οικεία παραδείγματα είναι:
- Ρίψη κέρματος: μια τυχαία τιμή από `('Heads', 'Tails')`.
- Ρίψη ζαριού: ένας τυχαίος ακέραιος από το 1 έως το 6.
- Ανακάτεμα μιας τράπουλας: μια τυχαία διάταξη μιας λίστας καρτών.
- Η δημιουργία δέντρων και θάμνων σε μια τρισδιάστατη προσομοίωση γραφικών.

Η παραγωγή _πραγματικά_ τυχαίων τιμών με έναν υπολογιστή είναι μια [εκπληκτικά δύσκολη τεχνική πρόκληση][truly-random], οπότε μπορεί να δεις αυτά τα αποτελέσματα να αναφέρονται ως "ψευδοτυχαία".

Στην πράξη, μια καλά σχεδιασμένη βιβλιοθήκη όπως το module [`random`][random] στην τυπική βιβλιοθήκη της Python είναι γρήγορη, ευέλικτη και δίνει αποτελέσματα που αρκούν άνετα για τις περισσότερες εφαρμογές στη μοντελοποίηση, την προσομοίωση και τα παιχνίδια.

Σε αυτή τη σύντομη εισαγωγή, δείχνουμε τις τέσσερις πιο συχνά χρησιμοποιούμενες συναρτήσεις του module.
Σε ενθαρρύνουμε να εξερευνήσεις την πλήρη τεκμηρίωση του [`random`][random], καθώς υπάρχουν πολλά εργαλεία και επιλογές.


~~~~exercism/caution

Το module `random` __ΔΕΝ__ πρέπει να χρησιμοποιείται για εφαρμογές ασφάλειας ή κρυπτογραφίας!!

Αντ' αυτού, η Python παρέχει το module [`secrets`][secrets].
Αυτό είναι ειδικά βελτιστοποιημένο για κρυπτογραφική ασφάλεια.
Μερικά από τα προηγούμενα ζητήματα και τους λόγους για τη δημιουργία του module secrets μπορείς να τα βρεις στο [PEP 506][PEP 506].

[secrets]: https://docs.python.org/3.11/library/secrets.html#module-secrets
[PEP 506]: https://peps.python.org/pep-0506/
~~~~


Πριν χρησιμοποιήσεις τα εργαλεία του module `random`, πρέπει πρώτα να το εισάγεις:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Για να μην πληκτρολογείς κάθε φορά το όνομα του module, μπορείς να εισάγεις συγκεκριμένες συναρτήσεις με το όνομά τους:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` και `randint()`

Όπως φαίνεται στο πρώτο παράδειγμα παραπάνω, η συνάρτηση `randrange()` έχει τρεις μορφές:

1. `randrange(stop)` δίνει έναν ακέραιο `n` τέτοιον ώστε `0 <= n < stop`
2. `randrange(start, stop)` δίνει έναν ακέραιο `n` τέτοιον ώστε `start <= n < stop`
3. `randrange(start, stop, step)` δίνει έναν ακέραιο `n` τέτοιον ώστε `start <= n < stop`
    και ο `n` βρίσκεται στην ακολουθία `start, start + step, start + 2*step...`

Για τη συνηθέστερη περίπτωση όπου `step == 1`, το `randint(a, b)` μπορεί να είναι πιο βολικό και πιο ευανάγνωστο.
Τα πιθανά αποτελέσματα του `randint()` _περιλαμβάνουν_ το πάνω όριο, οπότε το `randint(a, b)` είναι το ίδιο με τη χρήση του `randrange(a, b+1)`.



## `choice()` και `choices()`

Αυτές οι δύο συναρτήσεις υποθέτουν ότι ξεκινάς από κάποια [ακολουθία][sequence-types] ή άλλο περιέκτη.
Συνήθως πρόκειται για μια `list` ή, με κάποιους περιορισμούς, για ένα `tuple` ή ένα `set` (_ένα `tuple` είναι αμετάβλητο και το `set` δεν έχει σειρά_).

Η συνάρτηση `choice()` επιστρέφει ένα μέλος επιλεγμένο τυχαία από μια δεδομένη ακολουθία, και η `choices()` επιστρέφει έναν καθορισμένο αριθμό μελών (`k`) επιλεγμένα τυχαία από μια δεδομένη ακολουθία.
Στα παραδείγματα παραπάνω υποθέσαμε ένα δίκαιο κέρμα με ίση πιθανότητα για κορώνα ή γράμματα, αλλά μπορούν να οριστούν και βάρη.

Για παράδειγμα, αν ένα σακούλι περιέχει 10 κόκκινες μπάλες και 15 πράσινες μπάλες και θέλουμε να βγάλουμε μία στην τύχη:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
