# Εισαγωγή

Στη Go, ένα `struct` είναι μια ακολουθία από ονομασμένα στοιχεία που ονομάζονται _πεδία_, κάθε πεδίο έχει ένα όνομα και έναν τύπο.
Το όνομα ενός πεδίου πρέπει να είναι μοναδικό μέσα στο `struct`.
Τα `struct` μπορούν να συγκριθούν με τις _κλάσεις_ στο παράδειγμα του αντικειμενοστρεφούς προγραμματισμού.

## Ορισμός ενός `struct`

Δημιουργείς ένα νέο `struct` χρησιμοποιώντας τις λέξεις-κλειδιά `type` και `struct` και ορίζεις ρητά το όνομα και τον τύπο των πεδίων.
Για παράδειγμα, εδώ ορίζουμε το `struct` `Shape`, που κρατά το όνομα ενός σχήματος και το μέγεθός του:

```go
type Shape struct {
    name string
    size int
}
```

Τα ονόματα πεδίων στα `struct` ακολουθούν τη σύμβαση της Go: τα πεδία των οποίων το όνομα ξεκινά με πεζό γράμμα είναι ορατά μόνο σε κώδικα του ίδιου πακέτου, ενώ εκείνα των οποίων το όνομα ξεκινά με κεφαλαίο γράμμα είναι ορατά και σε άλλα πακέτα.

## Δημιουργία στιγμιότυπων ενός `struct`

Αφού ορίσεις το `struct`, χρειάζεται να δημιουργήσεις ένα νέο στιγμιότυπο ορίζοντας τα πεδία χρησιμοποιώντας το όνομά τους, με οποιαδήποτε σειρά:

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

Για να διαβάσεις ή να τροποποιήσεις τα πεδία ενός στιγμιότυπου, χρησιμοποίησε τον συμβολισμό `.`:

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

Τα πεδία στα οποία δεν έχει εκχωρηθεί αρχική τιμή, θα έχουν τη μηδενική τους τιμή.
Για παράδειγμα:

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

Μπορείς να δημιουργήσεις ένα στιγμιότυπο ενός `struct` χωρίς να χρησιμοποιήσεις τα ονόματα των πεδίων, αρκεί να ορίσεις τα πεδία _με τη σειρά_:

```go
s := Shape {
	"Oval",
	20,
}
```

Ωστόσο, αυτή η σύνταξη θεωρείται _εύθραυστος κώδικας_, καθώς μπορεί να σπάσει όταν προστεθεί ένα πεδίο, ειδικά όταν το νέο πεδίο είναι διαφορετικού τύπου.
Στο παρακάτω παράδειγμα προσθέτουμε ένα επιπλέον πεδίο στο `Shape`:

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## Συναρτήσεις "New"

Μερικές φορές είναι ωραίο να έχεις συναρτήσεις που μας βοηθούν να δημιουργούμε στιγμιότυπα `struct`.
Κατά σύμβαση, αυτές οι συναρτήσεις συνήθως ονομάζονται `New` ή τα ονόματά τους ξεκινούν με `New`, αλλά επειδή είναι απλώς κανονικές συναρτήσεις, μπορείς να τους δώσεις όποιο όνομα θέλεις.
Μπορεί να σου θυμίζουν κατασκευαστές σε άλλες γλώσσες, αλλά στη Go είναι απλώς κανονικές συναρτήσεις.

Στο παρακάτω παράδειγμα, μία από αυτές τις συναρτήσεις `New` χρησιμοποιείται για να δημιουργήσει ένα νέο στιγμιότυπο του `Shape` και να ορίσει αυτόματα μια προεπιλεγμένη τιμή για το `size` του σχήματος:

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

Η χρήση συναρτήσεων `New` μπορεί να έχει τα εξής πλεονεκτήματα:

* επικύρωση των τιμών που δίνονται
* χειρισμός προεπιλεγμένων τιμών
* καθώς οι συναρτήσεις `New` συχνά δηλώνονται στο ίδιο πακέτο με τα `struct` που αρχικοποιούν, μπορούν να αρχικοποιήσουν ακόμη και ιδιωτικά πεδία του `struct`
