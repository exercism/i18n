# μορφοποίηση συμβολοσειράς

Εκτός από τη μέθοδο `String#%%`, ένας συνηθισμένος τρόπος για να δημιουργείς συμβολοσειρές στη Ruby είναι να χρησιμοποιείς την [παρεμβολή συμβολοσειρών](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Για παράδειγμα:

```ruby
# Rather than:
"One for %%s, one for me." %% %{name_variable}

# Consider:
"One for #{%{name_variable}}, one for me."
```
