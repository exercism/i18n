# Υποδείξεις

## 1. Προσδιόρισε αν τα λαζάνια είναι έτοιμα

- Χρησιμοποίησε μια [εντολή `if`][mdn-if-else] για να επιστρέψεις ένα αποτέλεσμα με βάση κάποια συνθήκη.
- Η εργασία λύνεται καλύτερα αν ελέγξεις πρώτα τις δύο συγκεκριμένες συνθήκες.
- Θυμήσου ότι οι παράμετροι που λείπουν θα είναι `undefined` και μπορείς να ελέγξεις αν μια μεταβλητή είναι `undefined` χρησιμοποιώντας τον τελεστή αυστηρής ισότητας `===`.

## 2. Εκτίμησε τον χρόνο προετοιμασίας

- Χρησιμοποίησε μια προεπιλεγμένη παράμετρο για να ορίσεις τον μέσο χρόνο προετοιμασίας σε περίπτωση που δε δόθηκε όταν κλήθηκε η συνάρτηση.
- Ξαναδές τους [πίνακες][concept-arrays] για να βρεις πώς να προσδιορίσεις τον αριθμό των στρώσεων (μήκος του πίνακα στρώσεων).

## 3. Υπολόγισε τις ποσότητες από νουντλς και σάλτσα που χρειάζονται

- Πρώτα, όρισε δύο μεταβλητές για να παρακολουθείς την ποσότητα από νουντλς και σάλτσα.
  Όρισέ τις με `let` (έστω) ώστε να μπορείς να αλλάξεις την τιμή αργότερα στον κώδικά σου.
  Επίσης, εκχώρησε μια κατάλληλη αρχική τιμή.
- Χρησιμοποίησε έναν [`for` βρόχο][concept-for-loops] για να διατρέξεις τις στρώσεις.
- Αν συναντήσεις μια στρώση `'noodles'` ή `'sauce'` μέσα στον βρόχο σου, αύξησε ανάλογα την ποσότητα που είναι αποθηκευμένη στην αντίστοιχη μεταβλητή.
- Χρησιμοποίησε ένα [αντικείμενο][concept-objects] για να επιστρέψεις και τα δύο αποτελέσματα.

## 4. Πρόσθεσε το μυστικό συστατικό

- Ξαναδές τους [πίνακες][concept-arrays] για να βρεις πώς να ανακτήσεις ένα στοιχείο από έναν πίνακα και πώς να προσθέσεις κάτι στο τέλος ενός πίνακα.
- Η θέση του τελευταίου στοιχείου σε έναν πίνακα `a` είναι `a.length - 1`.
- Η συνάρτηση δε θα πρέπει να έχει εντολή `return`.

## 5. Κλιμάκωσε τη συνταγή

- Πρώτα, υπολόγισε τον παράγοντα που πρέπει να εφαρμόσεις σε όλες τις ποσότητες με βάση τις επιθυμητές μερίδες.
- Ένας τρόπος για να διασφαλίσεις ότι τα ορίσματα δεν τροποποιούνται είναι να χρησιμοποιήσεις ένα νέο αντικείμενο για να αποθηκεύσεις τα αποτελέσματα.
- Χρησιμοποίησε έναν [`for...in` βρόχο][mdn-for-in] για να διατρέξεις όλες τις καταχωρήσεις στην αρχική συνταγή και να συμπληρώσεις το αντικείμενο ανάλογα.
