# Οδηγίες

Ο φίλος σου ο Johannes λατρεύει να φτιάχνει μόνος του hardware (DIY, δηλαδή «φτιάξε το μόνος σου»).
Μόλις έφτιαξε έναν αποχυμωτή και ο Johannes είναι πολύ ενθουσιασμένος με αυτόν.
Ο στόχος του Johannes είναι να μπορεί να φτιάχνει φρέσκο χυμό κάθε πρωί.

Ο αποχυμωτής του Johannes έχει πολλά εντυπωσιακά χαρακτηριστικά.
Όπως ένα ενσωματωμένο σύστημα μέτρησης, που μπορεί να σου πει πόσος χυμός υπάρχει στο ποτήρι.
Έχει επίσης ένα χρονόμετρο, που σου λέει πόση ώρα λειτουργεί η μηχανή.

Ο Johannes δεν είναι ο καλύτερος στον προγραμματισμό, αλλά θέλει να φτιάξει ένα πρόγραμμα για να ελέγχει τη μηχανή.
Γι' αυτό σου ζήτησε να τον βοηθήσεις.

## 1. Λυχνία αποσφαλμάτωσης

Η μηχανή έχει μια λυχνία αποσφαλμάτωσης, είναι απλός μηχανισμός: αν η μηχανή έχει τροφοδοσία, η λυχνία αποσφαλμάτωσης είναι αναμμένη.
Το πρόγραμμα θα τρέξει μόνο αν η λυχνία αποσφαλμάτωσης είναι αναμμένη.

Αυτή η μέθοδος πρέπει να είναι μια μέθοδος κλάσης με το όνομα `JuiceMaker`.

Όρισε τη μέθοδο κλάσης `JuiceMaker.debug_light_on?` που επιστρέφει `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Αρχικοποίησε τη μηχανή

Όταν η μηχανή παίρνει τροφοδοσία, θα πρέπει να δημιουργεί ένα στιγμιότυπο μιας κλάσης με το όνομα `JuiceMaker`.
Η μηχανή υποτίθεται ότι έχει μια αρχικοποιημένη κατάσταση.
Η αρχικοποιημένη κατάσταση πρέπει να κρατά τις εξής πληροφορίες:

1. Αν η μηχανή λειτουργεί ή όχι. Αυτό πρέπει να είναι πάντα `false` όταν η μηχανή ενεργοποιείται.
2. Την ποσότητα χυμού στο ποτήρι· αυτός θα είναι ένας αισθητήρας που θα μετρά την ποσότητα χυμού στο ποτήρι.

Όρισε την αρχικοποιημένη κατάσταση, η οποία παίρνει ως παράμετρο την ποσότητα χυμού στο ποτήρι, και κατασκεύασε την αρχικοποιημένη κατάσταση.
Η αρχικοποιημένη κατάσταση πρέπει να περιέχει μια μεταβλητή στιγμιοτύπου `@running` που ορίζεται σε `false`, και μια μεταβλητή στιγμιοτύπου `@fluid` που βασίζεται σε ένα όρισμα που δίνεται όταν αρχικοποιείται η κλάση.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Ενεργοποίησε τη μηχανή

Η μηχανή μπορεί να ενεργοποιηθεί και να απενεργοποιηθεί.
Πρέπει να ορίσεις μια μέθοδο για να ενεργοποιήσεις τη μηχανή.
Όταν η μηχανή ενεργοποιείται, η κατάσταση λειτουργίας πρέπει να οριστεί σε `true`.

Όρισε τη μέθοδο `JuiceMaker#start` που ενεργοποιεί τη μηχανή.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Κατάσταση της μηχανής

Η μηχανή πρέπει να μπορεί να σου πει την κατάστασή της.
Πρέπει να επιστρέφει `true` αν η μηχανή λειτουργεί, και `false` αν η μηχανή δε λειτουργεί.

Όρισε τη μέθοδο `JuiceMaker#running?` που επιστρέφει την κατάσταση της μηχανής.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Πρόσθεσε χυμό

Η μηχανή μπορεί να προσθέσει χυμό στο ποτήρι.
Η μηχανή μπορεί να πει πόσος χυμός προστίθεται στο ποτήρι.
Η μηχανή χρειάζεται βοήθεια για να ξέρει πόσος χυμός υπάρχει στο ποτήρι αφού προστεθεί ο χυμός.

Όρισε τη μέθοδο `JuiceMaker#add_fluid`, η οποία παίρνει ως παράμετρο την ποσότητα χυμού που προστίθεται και ενημερώνει την ποσότητα χυμού στο ποτήρι.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Απενεργοποίησε τη μηχανή

Η μηχανή μπορεί να ενεργοποιηθεί και να απενεργοποιηθεί.
Πρέπει να ορίσεις μια μέθοδο για να απενεργοποιήσεις τη μηχανή
Αυτή η μέθοδος θα καλείται μόνο όταν η μηχανή λειτουργεί.
Όταν η μηχανή απενεργοποιείται, η κατάσταση λειτουργίας πρέπει να οριστεί σε `false`.
Η μηχανή χρειάζεται επίσης βοήθεια για να προσδιορίσει πόσος χυμός υπάρχει στο ποτήρι αφού απενεργοποιηθεί.
Η μηχανή καταναλώνει πέντε μονάδες χυμού το λεπτό.

Όρισε τη μέθοδο `JuiceMaker#stop` που παίρνει ως παράμετρο τον αριθμό των λεπτών που λειτουργούσε η μηχανή και επιστρέφει την ποσότητα χυμού στο ποτήρι αφού απενεργοποιηθεί η μηχανή.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
