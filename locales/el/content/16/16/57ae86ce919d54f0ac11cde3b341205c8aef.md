# Προσάρτημα οδηγιών

## Διεργασία Node

Σε αντίθεση με άλλες ασκήσεις, το `grep.js` _δεν_ εισάγεται μέσα στο αρχείο δοκιμών `grep.spec.js`. Αντίθετα, θα χρησιμοποιηθεί σαν να είναι εκτελέσιμο. Για να γίνει αυτό εφικτό, το αρχείο `grep.js` έχει στηθεί με ένα shebang και ένα σχόλιο που εξηγεί τι κάνει αυτό:

```javascript
#!/usr/bin/env node

// The above line is a shebang. On Unix-like operating systems, or environments,
// this will allow the script to be run by node, and thus turn this JavaScript
// file into an executable. In other words, to execute this file, you may run
// the following from your terminal:
//
// ./grep.js args
//
// If you do not have a Unix-like operating system or environment, for example
// Windows without WSL, you can use the following inside a window terminal,
// such as cmd.exe:
//
// node grep.js args
//
// Read more about shebangs here: https://en.wikipedia.org/wiki/Shebang_(Unix)
```

Οι δοκιμές θα ξεκινήσουν μια νέα _διεργασία_ node, εκτελώντας το `grep.js`.

## Ανάγνωση ορισμάτων

Για να ανακτήσεις τα ορίσματα με τα οποία ξεκίνησε η _διεργασία_, χρησιμοποίησε το `process.argv`.

## Ανάγνωση αρχείων

Η συνάρτηση `readLines` έχει δοθεί έτοιμη. Δεν χρειάζεται να μετατρέψεις τη διαδρομή του αρχείου για να τη χρησιμοποιήσεις. Η συνάρτηση `readlines` θα _επιλύσει_ τη διαδρομή από τον τρέχοντα κατάλογο εργασίας, ο οποίος, για τις διεργασίες του `grep.js`, είναι ο κατάλογος της άσκησης.

## Εγγραφή εξόδου

Για να γράψεις έξοδο, χρησιμοποίησε

- `console.log` για εγγραφή στη ροή τυπικής εξόδου,
- `console.error` για εγγραφή στη ροή τυπικού σφάλματος.

Οι δοκιμές θεωρούν την εκτέλεση επιτυχημένη (resolved) αν δεν γραφτεί τίποτα στη ροή τυπικού σφάλματος, και ανεπιτυχή (rejected) αν γραφτεί κάτι στη ροή τυπικού σφάλματος.
