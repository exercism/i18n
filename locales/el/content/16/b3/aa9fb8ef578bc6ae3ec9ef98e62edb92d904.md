# Εισαγωγή

Συνήθως, οι συναρτήσεις δέχονται μόνο έναν σταθερό αριθμό ορισμάτων.
Ωστόσο, αν βάλεις το `...` μπροστά από τον τύπο της τελευταίας παραμέτρου, η συνάρτηση μπορεί να δεχτεί οποιονδήποτε αριθμό ορισμάτων στο τέλος.
Αυτό κάνει την τελευταία παράμετρο μια _variadic παράμετρο_.

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}
```

Μέσα στη συνάρτηση, η variadic παράμετρος είναι ένα slice:

```go
sum(1, 2, 3)    // nums is []int{1, 2, 3}
sum(1, 2, 3, 4) // nums is []int{1, 2, 3, 4}
sum()           // nums is []int{}
```

Μια συνάρτηση μπορεί να έχει μη variadic παραμέτρους πριν από τη variadic παράμετρο.
Μια συνάρτηση μπορεί να έχει το πολύ μία variadic παράμετρο και αυτή πρέπει να είναι η τελευταία παράμετρος.

```go
func greet(greeting string, names ...string) {
    for _, name := range names {
        fmt.Printf("%s, %s!\n", greeting, name)
    }
}
```

## Επέκταση ενός slice

Για να περάσεις ένα slice στη variadic παράμετρο, βάλε `...` μετά από αυτό:

```go
nums := []int{1, 2, 3}
sum(nums...) // equivalent to sum(1, 2, 3)
```

Το `...` είναι έγκυρο μόνο όταν περνάς ένα slice σε μια variadic παράμετρο.
