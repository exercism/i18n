# Υποδείξεις

## 1. Δημιούργησε έναν τυχαίο πλανήτη

- Η Java δεν παρέχει κάποια συνάρτηση για να διαλέξεις τυχαία ένα στοιχείο από μια συλλογή.
- Θυμήσου ότι μπορείς να πάρεις ένα στοιχείο από έναν πίνακα μέσω της θέσης του, η οποία είναι ακέραιος αριθμός.

## 2. Δημιούργησε έναν τυχαίο αριθμό νηολογίου διαστημόπλοιου

- Η κλάση `java.util.Random` παρέχει μια μέθοδο για να δημιουργήσεις έναν τυχαίο `int` μεταξύ του 0 και ενός δεδομένου μέγιστου.

## 3. Δημιούργησε μια τυχαία αστρική ημερομηνία

- Η μέθοδος της κλάσης `java.util.Random` για τη δημιουργία ενός τυχαίου `double` επιστρέφει πάντα έναν αριθμό μεταξύ `0.0` και `1.0`.
