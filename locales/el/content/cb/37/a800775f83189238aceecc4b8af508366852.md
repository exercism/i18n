# Σχετικά

Οι ενσωματωμένοι τύποι της Swift έχουν αρκετά προβλήματα όταν χρησιμοποιούνται για να μοντελοποιήσουν κάτι με έναν μέτριο αριθμό πιθανών καταστάσεων ή τιμών, όπως οι 63 επίσημοι κωδικοί κατάστασης HTTP, ή τα 8 κουμπιά του χειριστηρίου NES.

Για παράδειγμα, κάποιος μπορεί να προσπαθήσει να χρησιμοποιήσει υπάρχοντες τύπους όπως συμβολοσειρές ή ακέραιους για να αναπαραστήσει τις τιμές τους, παρόμοια με ό,τι έγινε με τους κωδικούς κατάστασης HTTP, αλλά αυτό οδηγεί σε μερικά διαφορετικά προβλήματα. Ένα πρόβλημα είναι ότι, ενώ ένας υπολογιστής μπορεί να μην έχει πρόβλημα να επεξεργάζεται έγκυρες τιμές όπως 103, 226 και 505, το ίδιο το πρόγραμμα πρέπει επίσης να ελέγχει συνεχώς ότι δεν λαμβάνει μη έγκυρες τιμές όπως 213, 427, 512 ή 601. Ταυτόχρονα, ο _προγραμματιστής_ είναι υπεύθυνος να διασφαλίζει ότι κάθε έγκυρη τιμή ελέγχεται κατά την εξέταση ενός κωδικού για να δράσει πάνω του, ώστε να μην χάνεται κάποιος έγκυρος κωδικός.

Ένα άλλο πρόβλημα είναι ότι χάνεται το σημασιολογικό νόημα. Ένας άνθρωπος που διαβάζει (ή γράφει) ένα πρόγραμμα μπορεί να δυσκολεύεται να θυμηθεί ότι οι τιμές 103, 226 και 505 αντιπροσωπεύουν "Early Hints", "IM Used" και "HTTP Version Not Supported". Παρομοίως, κάποιος θα μπορούσε να μοντελοποιήσει έναν διακόπτη χρησιμοποιώντας ένα `Bool`, καθώς και τα δύο έχουν μόνο δύο καταστάσεις, αλλά τι αντιπροσωπεύει το `true` για τον διακόπτη; σημαίνει ότι ο διακόπτης είναι ανοιχτός ή ότι είναι κλειστός;

Κάποιος θα μπορούσε να το μετριάσει αυτό χρησιμοποιώντας μια συμβολοσειρά για να αναπαραστήσει την έκδοση κειμένου του κωδικού κατάστασης ή της κατάστασης του διακόπτη, αλλά αυτό μπορεί να προκαλέσει σφάλματα όταν κάποιος προσπαθεί να συγκρίνει έναν εισερχόμενο κωδικό κατάστασης με το "HTTP Version not Supoorted" αντί για το αναμενόμενο "HTTP Version not Supported". Αυτά τα σφάλματα είναι συνηθισμένα και δύσκολο να εντοπιστούν.

Ως προσέγγιση για την επίλυση αυτού του προβλήματος, η Swift, όπως πολλές σύγχρονες γλώσσες, προσφέρει ένα χαρακτηριστικό της γλώσσας που το ονομάζει [_Enumerations_][enumerations] ή _Enums_ για συντομία.

Τα Enums στη Swift είναι ένας μηχανισμός δημιουργίας νέων τύπων που κατοικούνται από έναν πεπερασμένο αριθμό ονομασμένων τιμών, οι οποίες μπορούν να φέρουν πρόσθετες συσχετισμένες πληροφορίες και οι οποίες μπορούν να ελεγχθούν κατά τη μεταγλώττιση για πληρότητα και ακρίβεια χρήσης. Επιπλέον, τα enums μπορούν να έχουν ιδιότητες και μεθόδους προσαρτημένες σε αυτά, παρέχοντας πρόσθετες πληροφορίες και λειτουργικότητα με βάση την τρέχουσα τιμή του enum.

## Ορισμός των Enums

Τα πιο βασικά enums ορίζονται στη Swift με τη λέξη-κλειδί `enum`, ακολουθούμενη από το όνομα του τύπου και στη συνέχεια το σώμα του enum μέσα σε άγκιστρα, το οποίο περιλαμβάνει μια λίστα με τις τιμές του enum, που εισάγονται με τη λέξη-κλειδί `case`. Ακολουθώντας τον [οδηγό στυλ της Swift][api-design-guidelines], το όνομα του τύπου θα πρέπει να είναι σε UpperCamelCase, ενώ οι τιμές θα πρέπει να είναι σε lowerCamelCase.

```swift
enum NESButton {
  case up
  case down
  case left
  case right
  case a
  case b
  case select
  case start
}
```

Για συντομία, πολλαπλές περιπτώσεις μπορούν επίσης να γραφτούν σε μία γραμμή, χωρισμένες με κόμματα, με μία μόνο λέξη-κλειδί `case`.

```swift
enum NESButton {
  case up, down, left, right, a, b, select, start
}
```

Αυτό ορίζει έναν νέο τύπο με όνομα `NESButton` με πιθανές τιμές `up`, `down`, `left`, `right`, `a`, `b`, `select` και `start`. Σε αυτές τις τιμές μπορεί κανείς να αναφερθεί ακολουθώντας το όνομα του τύπου με μια τελεία (`.`) και την τιμή. Σε περιπτώσεις όπου το όνομα του τύπου μπορεί να συναχθεί, χρειάζονται μόνο η τελεία και η τιμή. Αυτές οι τιμές μπορούν στη συνέχεια να χρησιμοποιηθούν όπως οποιεσδήποτε άλλες τιμές στη Swift.

```swift
var lastPressed = NESButton.up

// Now that the type of lastPressed is set as NESButton
lastPressed = .down

let konamiCode = [NESButton.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

Παρατήρησε ότι, καθώς όλα τα στοιχεία ενός πίνακα πρέπει να είναι του ίδιου τύπου, χρειάζεται να δώσουμε το όνομα του τύπου μόνο για ένα από τα στοιχεία, τα υπόλοιπα μπορούν να είναι απλώς οι τιμές. Το όνομα του τύπου δεν θα απαιτούνταν για κανένα από αυτά αν η σταθερά είχε τη σωστή σχολίαση τύπου, π.χ. `let konamiCode: [NESButton] = …`.

## Enums και εντολές switch

Τα Enums χρησιμοποιούνται συχνά [μαζί με εντολές `switch`][enums-and-switches] οι οποίες χρησιμοποιούνται για να καθορίσουν την ενέργεια που θα γίνει με βάση την τιμή του enum.

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}

// prints "You pressed the LEFT button"
```

Καθώς οι εντολές `switch` απαιτείται να είναι εξαντλητικές, ο μεταγλωττιστής θα σε ειδοποιήσει αν δεν αναπαρίστανται όλες οι περιπτώσεις.

```swift
switch lastPressed {
case .up, .down, .left, .right:
  print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

Αυτό είναι ιδιαίτερα χρήσιμο αν προστεθούν περιπτώσεις στα enums καθώς το πρόγραμμα εξελίσσεται. Ο μεταγλωττιστής μπορεί να επισημάνει όλα τα σημεία όπου μη εξαντλητικές εντολές switch χρειάζεται να ενημερωθούν για να συμπεριλάβουν τη νέα περίπτωση.

Σημείωσε ότι μπορεί κανείς να διορθώσει το παραπάνω σφάλμα χρησιμοποιώντας μια περίπτωση `default` στο `switch`.

```swift
lastPressed = .select
switch lastPressed {
case .up, .down, .left, .right:
  print("You pressed a direction button.")
default:
  print("You pressed a non-direction button.")
}
// prints: "You pressed a non-directional button."
```

Ωστόσο, αυτό κάνει αυτόματα οποιοδήποτε `switch` εξαντλητικό, οπότε αν προσθέταμε, ας πούμε, περιπτώσεις διαγώνιων κατευθύνσεων, όπως `.upAndLeft` στο enum, δεν θα γνωρίζαμε να ενημερώσουμε αυτό το switch και θα μας έλεγαν λανθασμένα ότι πατήθηκε ένα μη κατευθυντικό κουμπί. Για να το αποτρέψουμε αυτό, είναι καλύτερο να απαριθμούμε ρητά όλες τις περιπτώσεις όπου είναι δυνατόν.

```swift
lastPressed = .select
switch lastPressed {
case .up, .down, .left, .right:
  print("You pressed a direction button.")
case .a, .b, .select, .start:
  print("You pressed a non-direction button.")
}
// prints: "You pressed a non-directional button."
```

Καθώς ο μεταγλωττιστής γνωρίζει όλες τις πιθανές τιμές ενός enum, μπορεί επίσης να ανιχνεύσει σφάλματα όπως ορθογραφικά λάθη που παρεισφρέουν σε προγράμματα όπου χρησιμοποιούνται συμβολοσειρές για την αναπαράσταση τιμών.

```swift
lastPressed = .selcet
// Error: Type 'NESButton' has no member 'selcet'
```

## Μέθοδοι

Όπως οι άλλοι τύποι στη Swift, τα enums μπορούν να περιέχουν μεθόδους που επιτρέπουν στο enum να παρέχει λειτουργικότητα με βάση την τρέχουσα τιμή του enum.

Οι μέθοδοι είναι ανάλογες με τις συναρτήσεις, μόνο που ορίζονται μέσα στο σώμα του enum και είναι δεμένες με την τρέχουσα τιμή του enum. Προσπελαύνονται μέσω _σημειογραφίας τελείας_ όπου το όνομα της τιμής του enum ακολουθείται από μια τελεία (`.`) και το όνομα της μεθόδου και τις παραμέτρους της.

Μέσα στη μέθοδο, η τιμή του enum μπορεί να αναφερθεί ως `self`, και στην υπογραφή τύπου, αν κάποιος δέχεται ως παράμετρο ή επιστρέφει μια τιμή του enum, μπορεί να αναφερθεί στον τύπο ως `Self`.

### Αρχικοποιητές

Οι αρχικοποιητές είναι ειδικές μέθοδοι που χρησιμοποιούνται για να ρυθμίσουν μια τιμή του enum. Ο ορισμός τους μοιάζει πολύ με αυτόν μιας μεθόδου, μόνο που δεν υπάρχει η λέξη-κλειδί `func`, ούτε τύπος επιστροφής, και το όνομα πρέπει να είναι `init` και ο αρχικοποιητής _πρέπει_ να αναθέσει μια τιμή του enum στο `self`. Οι αρχικοποιητές καλούνται είτε μέσω σημειογραφίας τελείας είτε περνώντας τις παραμέτρους του αρχικοποιητή στο όνομα του enum.

Τα enums μπορούν επίσης να έχουν αρχικοποιητές που μπορούν να αποτύχουν, οι οποίοι επιστρέφουν προαιρετικές τιμές enum. Αυτοί χρησιμοποιούνται όταν μπορεί να μην υπάρχει έγκυρη τιμή για αρχικοποίηση με βάση την είσοδο του αρχικοποιητή και μπορεί να ανατεθεί `nil` στο self αντ' αυτού. Σε αυτές τις περιπτώσεις, το όνομα του αρχικοποιητή γράφεται ως `init?`, αν και το ερωτηματικό παραλείπεται όταν καλείται ο αρχικοποιητής.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```

### Ακατέργαστες τιμές

Τα enums μπορούν επίσης να φέρουν μαζί τους μια εσωτερική τιμή γνωστή ως [_ακατέργαστη τιμή_][raw-values]. Οι ακατέργαστες τιμές πρέπει να είναι όλες του ίδιου τύπου, ο οποίος δηλώνεται στον ορισμό του enum. Έτσι θα μπορούσαμε να αντιστοιχίσουμε, π.χ., τιμές Character στο enum `NESButton` μας τροποποιώντας τον ορισμό:

```swift
enum NESButton: Character {
  case up = "⬆️"
  case down = "⬇️"
  case left = "⬅️"
  case right = "➡️"
  case a = "🅰️"
  case b = "🅱️"
  case select = "✅"
  case start = "🚦"
}
```

Εδώ, το `: Character` λέει στον μεταγλωττιστή ότι οι ακατέργαστες τιμές θα είναι τύπου `Character` και η ανάθεση της ακατέργαστης τιμής ακολουθεί κάθε τιμή.

Οι ακατέργαστες τιμές μπορούν να προσπελαστούν μέσω της αυτόματα παραγόμενης ιδιότητας `rawValue` κάθε τιμής.

```swift
NESButton.left.rawValue
// => "⬅️"
NESButton.b.rawValue
// => "🅱️"
```

Οι ακατέργαστες τιμές μπορούν επίσης να χρησιμοποιηθούν για την αρχικοποίηση τιμών του τύπου enum. Σημείωσε ότι η τιμή επιστροφής είναι προαιρετική, καθώς μπορεί να περαστεί μια μη έγκυρη ακατέργαστη τιμή.

```swift
let upButton = NESButton.init(rawValue: "⬆️")
// => Optional(.up)
let invalid = NESButton.init(rawValue: "🙄")
// => nil
```

Η Swift μπορεί να αντιστοιχίσει σιωπηρά ακατέργαστες τιμές για ακατέργαστες τιμές `String` και `Int`. Αν καθοριστεί τύπος ακατέργαστης τιμής `String`, η ακατέργαστη τιμή θα αντιστοιχιστεί σιωπηρά στο όνομα της τιμής ως String, εκτός αν η σιωπηρή τιμή παρακαμφθεί με ρητή ανάθεση.

Αν καθοριστεί τύπος ακατέργαστης τιμής `Int`, η ακατέργαστη τιμή θα αντιστοιχιστεί σιωπηρά σε έναν ακέραιο μεγαλύτερο κατά 1 από την ακατέργαστη τιμή της προηγούμενης περίπτωσης, εκτός αν παρακαμφθεί με ρητή ανάθεση. Η προεπιλεγμένη ακατέργαστη τιμή για την πρώτη περίπτωση είναι 0, εκτός αν οριστεί διαφορετικά.

```swift
enum Coin: String {
  case heads
  case tails = "eagle"
}

Coin.head.rawValue
// => "heads"
Coin.tails.rawValue
// => "eagle"

enum Dwarf: Int {
  case grumpy, sleepy, sneezy, happy = 8, bashful, dopey, doc
}

Dwarf.grumpy.rawValue
// => 0
Dwarf.sneezy.rawValue
// => 2
Dwarf.happy.rawValue
// => 8
Dwarf.bashful.rawValue
// => 9
```

### Συσχετισμένες τιμές

Τα enums στη Swift μπορούν επίσης να φέρουν έναν άλλο τύπο πληροφορίας γνωστό ως [_συσχετισμένες τιμές_][associated-values]. Με τις συσχετισμένες τιμές, κάθε περίπτωση του enum μπορεί να έχει διαφορετικό τύπο τιμής που μπορεί να μεταφερθεί μαζί με την τιμή του enum. Οι τύποι των συσχετισμένων τιμών καθορίζονται στη δήλωση του enum. Αυτές οι τιμές μπορούν στη συνέχεια να εξαχθούν και να χρησιμοποιηθούν μέσω αντιστοίχισης προτύπων.

```swift
enum Suit: Character {
  case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"

  func print() {
    switch self {
    case .ace(let suit): print("A\(suit.rawValue)")
    case .king(let suit): print("K\(suit.rawValue)")
    case .queen(let suit): print("Q\(suit.rawValue)")
    case .jack(let suit): print("J\(suit.rawValue)")
    case let .number(suit, value): print("\(value)\(suit.rawValue)")
    }
  }
}

enum Card {
  case ace(Suit), king(Suit), queen(Suit), jack(Suit)
  case number(Suit, Int)
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

aceOfSpades.print()
// prints "A♠️"

twoOfHearts.print()
// prints "2♥️"
```

Σημείωσε ότι τα enums μπορούν να έχουν είτε ακατέργαστες τιμές, είτε συσχετισμένες τιμές, είτε καμία από τις δύο, αλλά δεν μπορούν να έχουν και τις δύο.

### Αναδρομικά Enums

Όπως φάνηκε στο προηγούμενο παράδειγμα, ο συσχετισμένος τύπος μιας περίπτωσης enum μπορεί να είναι οποιουδήποτε τύπου, συμπεριλαμβανομένου αυτού ενός enum. Σε ορισμένες περιπτώσεις, μπορεί να είναι επιθυμητό ο τύπος μιας συσχετισμένης τιμής να είναι ο τύπος του enum που περιέχει αυτή την περίπτωση. Αυτό μπορεί να γίνει στη Swift γράφοντας τη λέξη-κλειδί `indirect` μπροστά από κάθε περίπτωση που χρησιμοποιεί αυτούς τους [αναδρομικούς συσχετισμένους τύπους][recursive-enumerations], ή βάζοντας `indirect` μπροστά από τη λέξη-κλειδί `enum` μπροστά από τη λέξη-κλειδί `enum` για να κάνετε όλες τις περιπτώσεις του enum έμμεσες.

```swift
enum BinaryTree {
  case leaf(value: Int)
  indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

enum BinaryTree {
  case leaf(value: Int)
  indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(left: .leaf(value: 1), value: 3, right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9)))
```
