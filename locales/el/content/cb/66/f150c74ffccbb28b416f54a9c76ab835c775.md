# Οδηγίες

Σε αυτή την άσκηση θα ορίσεις κάποιες σταθερές που θα χρησιμοποιηθούν στη λειτουργία μιας τράπεζας.

Έχεις πέντε εργασίες:

## 1. Αναπαράστησε το σταθερό επιτόκιο ενός δανείου

Δημιούργησε την αριθμητική σταθερά `FixedInterestRate` χωρίς τύπο για να κρατά την τιμή 5% (5/100), και μετά υλοποίησε τη συνάρτηση `GetFixedInterestRate` ώστε να την επιστρέφει:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Αναπαράστησε τον αριθμό των ημερών σε έναν χρόνο

Δημιούργησε τη σταθερά `DaysPerYear` με τύπο `int` για να κρατά την τιμή 365, και μετά υλοποίησε τη συνάρτηση `GetDaysPerYear` ώστε να την επιστρέφει:

```go
GetDaysPerYear()
// => 365
```

## 3. Αναπαράστησε τους μήνες του χρόνου

Σε ένα μπλοκ, χρησιμοποίησε τον απαριθμητή της Go για να δημιουργήσεις δώδεκα αριθμητικές σταθερές χωρίς τύπο που θα κρατούν τις τιμές 1 έως 12 για τους μήνες του χρόνου.
Ονόμασέ τις `Jan`, `Feb`, `Mar`, κ.λπ., και μετά υλοποίησε τη συνάρτηση `GetMonth` ώστε να επιστρέφει την τιμή για έναν δεδομένο μήνα:

```go
GetMonth(Jan)
// => 1
```

## 4. Αναπαράστησε έναν αριθμό λογαριασμού

Δημιούργησε τη σταθερά συμβολοσειράς `AccountNo` χωρίς τύπο για να κρατά την τιμή XF348IJ, και μετά υλοποίησε τη συνάρτηση `GetAccountNumber` ώστε να την επιστρέφει:

```go
GetAccountNumber()
// => "XF348IJ"
```
