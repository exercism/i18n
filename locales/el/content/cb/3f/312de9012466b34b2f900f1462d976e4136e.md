# Χρήση του τελεστή συνένωσης null αντί για IsNullOrEmpty

Αντί να χρησιμοποιείς `string.IsNullOrEmpty` για να προσδιορίσεις αν θα πρέπει να χρησιμοποιηθεί το προεπιλεγμένο όνομα, δοκίμασε τον [τελεστή συνένωσης null](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/null-coalescing-operator) για να απλοποιήσεις τον κώδικα και σκέψου τη διαφορά στη συμπεριφορά.
