# Οδηγίες

Σε αυτή την άσκηση θα παίξεις με ένα τηλεχειριζόμενο αυτοκίνητο, για το οποίο μάζεψες επιτέλους αρκετά χρήματα για να το αγοράσεις.

Τα αυτοκίνητα ξεκινούν με γεμάτες (100%) μπαταρίες. Κάθε φορά που οδηγάς το αυτοκίνητο με το τηλεχειριστήριο, διανύει 20 μέτρα και καταναλώνει το ένα τοις εκατό της μπαταρίας.

Το τηλεχειριζόμενο αυτοκίνητο έχει μια εντυπωσιακή οθόνη LED που δείχνει δύο πληροφορίες:

- Τη συνολική απόσταση που έχει διανύσει, όπως εμφανίζεται: `"Driven <METERS> meters"`.
- Την υπολειπόμενη φόρτιση της μπαταρίας, όπως εμφανίζεται: `"Battery at <PERCENTAGE>%"`.

Αν η μπαταρία είναι στο 0%, δεν μπορείς να οδηγήσεις άλλο το αυτοκίνητο και η ένδειξη της μπαταρίας θα δείχνει `"Battery empty"`.

Έχεις έξι εργασίες, καθεμία από τις οποίες θα δουλέψει με στιγμιότυπα τηλεχειριζόμενου αυτοκινήτου.

## 1. Αγόρασε ένα ολοκαίνουριο τηλεχειριζόμενο αυτοκίνητο

Υλοποίησε τη (_static_) μέθοδο `JedliksToyCar.buy()` ώστε να επιστρέφει ένα ολοκαίνουριο στιγμιότυπο τηλεχειριζόμενου αυτοκινήτου:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Εμφάνισε την απόσταση που έχει διανυθεί

Υλοποίησε τη μέθοδο `JedliksToyCar.distanceDisplay()` ώστε να επιστρέφει την απόσταση όπως εμφανίζεται στην οθόνη LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Εμφάνισε το ποσοστό της μπαταρίας

Υλοποίησε τη μέθοδο `JedliksToyCar.batteryDisplay()` ώστε να επιστρέφει το ποσοστό της μπαταρίας όπως εμφανίζεται στην οθόνη LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Ενημέρωσε τον αριθμό των μέτρων που διανύθηκαν όταν οδηγάς

Υλοποίησε τη μέθοδο `JedliksToyCar.drive()` που ενημερώνει τον αριθμό των μέτρων που έχουν διανυθεί:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Ενημέρωσε το ποσοστό της μπαταρίας όταν οδηγάς

Ενημέρωσε τη μέθοδο `JedliksToyCar.drive()` ώστε να ενημερώνει το ποσοστό της μπαταρίας:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Εμπόδισε την οδήγηση όταν η μπαταρία έχει αδειάσει

Ενημέρωσε τη μέθοδο `JedliksToyCar.drive()` ώστε να μην αυξάνει την απόσταση που έχει διανυθεί ούτε να μειώνει το ποσοστό της μπαταρίας όταν η μπαταρία έχει αδειάσει (στο 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
