# Εισαγωγή

Η Python είναι μια [δυναμικά και ισχυρά τυποποιημένη][dynamic typing in python] γλώσσα προγραμματισμού.
Χρησιμοποιεί τόσο [duck typing][duck typing] όσο και [βαθμιαία τυποποίηση][gradual typing], μέσω των [υποδείξεων τύπων][type hints].
Η Python δίνει μεγάλη έμφαση στην αναγνωσιμότητα του κώδικα και (_παρόμοια με τη Haskell_) χρησιμοποιεί [σημαντική στοίχιση][significant indentation] για να δηλώσει ορισμούς συναρτήσεων, μεθόδων και κλάσεων.

Η Python δημιουργήθηκε από τον Guido van Rossum και κυκλοφόρησε για πρώτη φορά το 1991.

Τα _στυλ_ του προστακτικού, του δηλωτικού (π.χ. συναρτησιακού) και του αντικειμενοστρεφούς προγραμματισμού υποστηρίζονται όλα, αλλά εσωτερικά **[τα πάντα στην Python είναι αντικείμενο][everythings an object]**.

Θα εμβαθύνουμε στο τι σημαίνουν όλα αυτά καθώς προχωράμε στις έννοιες της διαδρομής Python.

Αυτή η πρώτη έννοια (`basics`)  παρουσιάζει 4 σημαντικά χαρακτηριστικά της γλώσσας Python:
1.  Ανάθεση ονόματος (_μεταβλητές και σταθερές_),
2.  Συναρτήσεις (_η λέξη-κλειδί `def` και η λέξη-κλειδί `return`_),
3.  Σχόλια, και
4.  Docstrings.

<br>

## Ανάθεση ονόματος (Μεταβλητές & Σταθερές)

Οι προγραμματιστές μπορούν να δεσμεύσουν [_ονόματα_][facts-and-myths-about-python-names] (που ονομάζονται και _μεταβλητές_) σε οποιονδήποτε τύπο αντικειμένου χρησιμοποιώντας τον τελεστή ανάθεσης `=`: `<name> = <value>`.
Ένα όνομα μπορεί να ανατεθεί ξανά (ή να δεσμευτεί ξανά) σε διαφορετικές τιμές (διαφορετικούς τύπους αντικειμένων) κατά τη διάρκεια της ζωής του:


```python
>>> my_first_variable = 1  # <--my_first_variable bound to an integer object of value one.
>>> my_first_variable = 2  # <--my_first_variable re-assigned to integer value 2.

>>> print(type(my_first_variable))
<class 'int'>

>>> print(my_first_variable)
2

>>> my_first_variable = "Now, I'm a string." # <--You may re-bind a name to a different object type and value.
>>> print(type(my_first_variable))
<class 'str'>

>>> my_first_variable = 'You can call me "str".' # <--Strings can be declared using single or double quote marks.
>>> print(my_first_variable)
You can call me "str".
```


### Σταθερές

Οι σταθερές είναι ονόματα που προορίζονται να ανατεθούν μόνο μία φορά σε ένα πρόγραμμα, αν και η Python δεν θα εμποδίσει την εκ νέου ανάθεση.
Η χρήση του `SCREAMING_SNAKE_CASE` δείχνει σε όποιον διαβάζει τον κώδικα ότι το όνομα **δεν** πρέπει να ανατεθεί ξανά, ούτε να μεταβληθεί η τιμή του.
Οι σταθερές πρέπει να ορίζονται σε επίπεδο [ενότητας][module] (αρχείου) και είναι συνήθως ορατές σε όλες τις συναρτήσεις και κλάσεις ενός προγράμματος.



## Συναρτήσεις

Η λέξη-κλειδί `def` ξεκινά έναν [ορισμό συνάρτησης][function definition].
Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες τυπικές [παραμέτρους][parameters] μέσα σε παρενθέσεις `()`, που ακολουθούνται από άνω και κάτω τελεία `:`.
Οι εντολές για το _σώμα_ της συνάρτησης ξεκινούν στην επόμενη γραμμή μετά το `def` και πρέπει να είναι _στοιχισμένες σε μπλοκ_.


```python
# The body of this function is indented by 2 spaces & prints the sum of the numbers.
def add_two_numbers(number_one, number_two):
  total = number_one + number_two
  print(total)  

>>> add_two_numbers(3, 4)
7


# Inconsistent indentation in your code blocks will raise an error.
>>> def add_three_numbers_misformatted(number_one, number_two, number_three):
...     result = number_one + number_two + number_three   # This was indented by 4 spaces.
...    print(result)     # <--This was only indented by 3 spaces.
...
...
  File "<stdin>", line 3
    print(result)
    ^
IndentationError: unindent does not match any outer indentation level
```


Οι συναρτήσεις επιστρέφουν _ρητά_ μια τιμή ή ένα αντικείμενο μέσω της λέξης-κλειδιού [`return`][return]:


```python
# Function definition on first line, explicit return used on final line.
def add_two_numbers(number_one, number_two):
  return number_one + number_two   


# Calling the function in the Python shell returns the sum of the numbers.
>>> add_two_numbers(3, 4)
7

# Assigning the function call to a variable and printing 
# the variable will also return the value.
>>> sum_with_return = add_two_numbers(5, 6)
>>> print(sum_with_return)
11
```


Οι συναρτήσεις που δεν έχουν μια _ρητή_ έκφραση μετά το `return` θα επιστρέψουν _σιωπηρά_ το αντικείμενο [`None`][none].
Οι λεπτομέρειες του `None` θα καλυφθούν σε επόμενη έννοια.
Για τους σκοπούς αυτής της άσκησης και της εξήγησης, το `None` είναι ένας δείκτης θέσης που αντιπροσωπεύει το τίποτα, ή το null:


```python
# This function will return `None`
def square_a_number(number):
    square = number * number
    return # <-- note that this return is not followed by an expression

# Calling the function in the Python shell appears 
# to not return anything at all.
>>> square_a_number(2)
>>>


# Using print() with the function call shows that 
# the function is actually returning the **None** object.
>>> print(square_a_number(2))
None
```

Οι συναρτήσεις που παραλείπουν το `return` θα επιστρέψουν επίσης _σιωπηρά_ το αντικείμενο [`None`][none].
Αυτό σημαίνει ότι αν δεν χρησιμοποιήσεις το `return` σε μια συνάρτηση, η Python θα επιστρέψει το αντικείμενο `None` για σένα.

```python
# This function omits a return keyword altogether.
def add_two_numbers(number_one, number_two):
  result = number_one + number_two

>>> add_two_numbers(5, 7)
>>> print(add_two_numbers(5, 7))
None

# Assigning the function call to a variable and printing 
# the variable will also show None.
>>> sum_without_return = add_two_numbers(5, 6)
>>> print(sum_without_return)
None
```


## Σχόλια

Τα [σχόλια][comments] στην Python ξεκινούν με ένα `#` που δεν αποτελεί μέρος μιας συμβολοσειράς και τελειώνουν στο τέλος της γραμμής.
Σε αντίθεση με πολλές άλλες γλώσσες προγραμματισμού, η Python **δεν υποστηρίζει** σημάδια σχολίων πολλαπλών γραμμών.
Κάθε γραμμή ενός μπλοκ σχολίων πρέπει να ξεκινά με τον χαρακτήρα `#`.


## Docstrings

Η πρώτη εντολή του σώματος μιας συνάρτησης μπορεί προαιρετικά να είναι ένα [_docstring_][docstring], που συνοψίζει με συντομία τον σκοπό της συνάρτησης ή του αντικειμένου.
Τα docstrings διαβάζονται από αυτοματοποιημένα εργαλεία τεκμηρίωσης όπως το [Sphinx][sphinx] και επιστρέφονται καλώντας το ειδικό χαρακτηριστικό `.__doc__` στη συνάρτηση, τη μέθοδο ή το όνομα της κλάσης.
Οι γενικές συμβάσεις για τα docstrings περιγράφονται στο [PEP257][pep257], αλλά οι ακριβείς μορφές ποικίλλουν ανάλογα με το έργο και την ομάδα.
Τα docstrings δηλώνονται με τριπλά διπλά εισαγωγικά (""") στοιχισμένα στο ίδιο επίπεδο με το μπλοκ κώδικα:
