# Απόφυγε τις επιστροφές κυριολεκτικών τιμών Boolean

Αντί να επιστρέφεις κυριολεκτικές τιμές Boolean μετά από μια συνθήκη, μπορείς να επιστρέψεις απευθείας τη συνθήκη.

Παράδειγμα:

```java
// instead of
if (someExpression) {
  return true;
} else {
  return false;
}

// ... return the expression directly
return someExpression;
```
