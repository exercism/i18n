# Συμβόλαια

Τα ορίσματα και ο τύπος επιστροφής μιας ρουτίνας λένε τι *είδος* πράγματος μπαίνει και
βγαίνει. Δεν μπορούν να πουν ότι ένα βάρος πρέπει να είναι θετικό, ή ότι ένα πλαίσιο
δοκιμών δεν αναφέρει ποτέ μεγαλύτερη ελεύθερη χωρητικότητα από όση έχει.

Ένα **συμβόλαιο** τα λέει αυτά, στην ίδια την κεφαλίδα της ρουτίνας, εκεί όπου θα τα δει
όποιος τη διαβάσει.

## pre

Το `pre` δηλώνει τι πρέπει να ισχύει όταν καλείται η ρουτίνα. Μπαίνει ανάμεσα στον τύπο
επιστροφής και το `is`.

```sather
   spare_capacity(load : INT) : INT
      pre load >= 0
   is
      return limit - load;
   end;
```

Αυτό είναι μια απαίτηση προς τον **καλούντα**: μην την καλείς με αρνητικό load.

## post

Το `post` δηλώνει τι θα ισχύει όταν η ρουτίνα απαντήσει. Μέσα του, το `result` είναι η
τιμή που επιστρέφει.

```sather
   percent_used(load : INT) : INT
      pre load >= 0
      post result >= 0
   is
      return load * 100 / limit;
   end;
```

Αυτή είναι μια υπόσχεση προς τον καλούντα. Μια ρουτίνα που έχει και τα δύο είναι μια
συμφωνία: δώσε μου αυτό, και θα σου δώσω εκείνο.

Πολλές συνθήκες ενώνονται με `and`, όπως κάνουν όλα τα booleans:

```sather
      pre load >= 0 and load <= limit
```

## Τα συμβόλαια δεν είναι εξαιρέσεις

Μια εξαίρεση που πετιέται αφορά κάτι που μπορεί να συμβεί. Ένα σπασμένο συμβόλαιο σημαίνει
ένα **bug**: κάποιος κάλεσε τη ρουτίνα λάθος, ή η ρουτίνα δεν έκανε αυτό που έλεγε.

Έτσι, ένα σπασμένο συμβόλαιο δεν πετάει κάτι που να μπορείς να το πιάσεις. Όταν ο έλεγχος
συμβολαίων είναι ενεργοποιημένος, το πρόγραμμα σταματάει και τυπώνει ποια ρουτίνα και ποια
συνθήκη. Όταν είναι απενεργοποιημένος, η συνθήκη δεν ελέγχεται καν, και το πρόγραμμα
συνεχίζει σε ό,τι ανοησία ακολουθεί.

Γι' αυτό ένα συμβόλαιο είναι μια πρόταση για την ορθότητα, και όχι ένας τρόπος να
χειρίζεσαι εσφαλμένη είσοδο. Αν περιμένεις εσφαλμένη είσοδο, έλεγξέ τη και κάνε `raise`.
Αν η εσφαλμένη είσοδος σημαίνει ότι αυτός που καλεί έχει κάνει λάθος, πες το με `pre`.

## Ενεργοποίηση του ελέγχου

Αυτή η Sather ελέγχει τα συμβόλαια όταν δοθεί στον μεταγλωττιστή το `-chk`:

```
sacomp -chk mine.sa -main MAIN -o mine
```

Χωρίς αυτό, τα `pre` και `post` είναι τεκμηρίωση που ο μεταγλωττιστής τη διάβασε και
συμφώνησε ότι είναι καλά σχηματισμένη, και τίποτα παραπάνω. Οι δοκιμές για αυτή την άσκηση
είναι φτιαγμένες χωρίς το `-chk`, οπότε δεν μπορούν να εντοπίσουν για σένα ένα σπασμένο
συμβόλαιο: ελέγχουν ότι οι ρουτίνες κάνουν το σωστό όταν τις χρησιμοποιείς σωστά.
