# Προσθήκη στις οδηγίες

## Υλοποίησε τις δικές σου λειτουργίες λίστας

Η Rust διαθέτει ένα πλούσιο σύστημα iterator, οπότε η χρήση του για τη λύση αυτής της άσκησης είναι τετριμμένη.
Προσπάθησε να λύσεις την άσκηση χωρίς να καταφύγεις σε μεθόδους iterator όπως οι 
`map()`, `flatten()`, `filter()`, `count()`, `fold()`, `chain()`, `rev()` και παρόμοιες.
Οι μέθοδοι `next()` και `next_back()` δε μετράνε.

## Αποφεύγοντας τις δεσμεύσεις μνήμης

Η άσκηση λύνεται χωρίς να εισάγεις επιπλέον δεσμεύσεις μνήμης στη λύση σου.
Δες αν μπορείς να δημιουργήσεις τον δικό σου τύπο iterator αντί να δημιουργήσεις έναν iterator από μια συλλογή.
