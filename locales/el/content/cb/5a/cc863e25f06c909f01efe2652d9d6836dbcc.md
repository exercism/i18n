# Οδηγίες

Ως λάτρης του σκακιού, θέλεις να γράψεις τη δική σου εκδοχή του παιχνιδιού.
Ναι, υπάρχουν ήδη πολλές υλοποιήσεις σκακιού διαθέσιμες στο διαδίκτυο, αλλά η δική σου θα είναι μοναδική!

Ξεκινάς υλοποιώντας μια σκακιέρα.

Το παιχνίδι του σκακιού θα παίζεται σε μια σκακιέρα πλάτους οκτώ τετραγώνων και μήκους οκτώ τετραγώνων.
Τα τετράγωνα προσδιορίζονται από ένα γράμμα και έναν αριθμό.

## 1. Όρισε το εύρος γραμμών και στηλών

Το παιχνίδι θα πρέπει να αποθηκεύει τις γραμμές της σκακιέρας.
Οι γραμμές είναι οι σειρές της σκακιέρας και αριθμούνται από το 1 έως το 8.

Το παιχνίδι θα πρέπει επίσης να αποθηκεύει τις στήλες της σκακιέρας.
Οι στήλες είναι οι κολόνες της σκακιέρας και προσδιορίζονται από τα γράμματα A έως H.

Όρισε τις σταθερές `ranks` και `files` που αποθηκεύουν το εύρος των γραμμών και των στηλών αντίστοιχα.

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. Έλεγξε αν το τετράγωνο είναι έγκυρο

Το παιχνίδι θα πρέπει να ελέγχει αν ένα τετράγωνο είναι έγκυρο.
Ένα τετράγωνο είναι έγκυρο αν η γραμμή και η στήλη βρίσκονται μέσα στα εύρη των γραμμών και των στηλών.

Όρισε τη μέθοδο `isValidSquare(rank:file:)` που δέχεται τα ορίσματα `rank`, το οποίο περιέχει ένα `Int` της γραμμής, και `file`, το οποίο περιέχει μια `String` της στήλης.
Η μέθοδος θα πρέπει να επιστρέφει `true` αν η γραμμή και η στήλη βρίσκονται μέσα στο εύρος των γραμμών και των στηλών, και `false` διαφορετικά.

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. Πάρε τη γραμμή

Το παιχνίδι θα αποθηκεύει όλα τα τετράγωνα της σκακιέρας σε έναν μονοδιάστατο πίνακα.
Τα τετράγωνα σχηματίζονται ως συμβολοσειρά της γραμμής και της στήλης, π.χ. "1A", "8B", "4G" κ.λπ.
Για να πάρει τη γραμμή ενός τετραγώνου, το παιχνίδι θα πρέπει να υπολογίσει τη θέση του πρώτου τετραγώνου της γραμμής.

Όρισε τη μέθοδο `getRow(rank:)` που δέχεται το όρισμα `rank`, το οποίο περιέχει ένα `Int` της γραμμής.
Η μέθοδος θα πρέπει να επιστρέφει έναν πίνακα από συμβολοσειρές που αναπαριστούν τα τετράγωνα της γραμμής.

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
