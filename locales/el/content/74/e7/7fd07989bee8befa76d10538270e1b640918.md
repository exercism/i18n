# Το ερώτημα του ενός δισεκατομμυρίου δολαρίων του HTTP

## Διατύπωση προβλήματος

Σου ζητήθηκε να βρεις τους `x` κορυφαίους δισεκατομμυριούχους με βάση την καθαρή περιουσία τους σε ένα δεδομένο σύνολο χωρών (αριθμός χωρών = `N`). Για να το υλοποιήσεις αυτό, σου έχει δοθεί πρόσβαση σε ένα API που επιστρέφει τα στοιχεία των δισεκατομμυριούχων ανά χώρα.

Για να απλοποιήσεις την πρόσβαση στο API, μπορείς να χρησιμοποιήσεις τον [connector-πελάτη `ims/billionairehub`](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) για να συνδεθείς στο API, το οποίο επιστρέφει τα στοιχεία των δισεκατομμυριούχων ανά χώρα.

## Περιορισμοί

* 1 <= N <= 5
* 1 <= x <= 10

```

```


## Περιβάλλον δοκιμών

* Το Client ID και το Client Secret για τη σύνδεση στο API των δισεκατομμυριούχων σου έχουν δοθεί στο `tests/Config.toml`. Μπορείς να τα χρησιμοποιήσεις για να αρχικοποιήσεις τον πελάτη.
* Χρησιμοποίησε το `bal test` για να τρέξεις και να δοκιμάσεις την υλοποίησή σου.

## Υποδείξεις

* Ο [πελάτης](https://lib.ballerina.io/ims/billionairehub/1.0.0/clients/Client) του πακέτου `ims/billionairehub` μπορεί να χρησιμοποιηθεί για να καλέσεις το API που επιστρέφει τους δισεκατομμυριούχους ανά χώρα. Συγκεκριμένα, μπορείς να χρησιμοποιήσεις την απομακρυσμένη μέθοδο `getBillionaires("<country>")`.
* Μπορείς πρώτα να βρεις τους πλουσιότερους ανθρώπους ανά χώρα και μετά να τους συνδυάσεις για να βρεις τους `x` κορυφαίους
* Οι [εκφράσεις query](https://ballerina.io/learn/by-example/query-expressions/) θα σε βολέψουν για φιλτράρισμα και ταξινόμηση
