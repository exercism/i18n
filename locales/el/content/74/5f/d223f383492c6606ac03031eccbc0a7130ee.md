# Υποδείξεις

## Γενικά

## 1. Υπολόγισε το επιτόκιο

- Η χρήση μιας εντολής `if` ή `case` μπορεί να φανεί χρήσιμη όταν ελέγχεις συνθήκες.

## 2. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Όταν υπολογίζεις την ετήσια απόδοση, μπορεί να σου φανεί χρήσιμο να μετατρέψεις προσωρινά ένα αρνητικό υπόλοιπο σε θετικό. Η κλάση `Float` έχει μια μέθοδο που μετατρέπει τόσο τις θετικές όσο και τις αρνητικές τιμές στην απόλυτη τιμή τους.

## 3. Υπολόγισε τα χρόνια πριν φτάσεις στο επιθυμητό υπόλοιπο

- Για να υπολογίσεις τα χρόνια, μπορείς να συνεχίσεις να επαναλαμβάνεις μέχρι να φτάσεις στο επιθυμητό υπόλοιπο.
