# Σχετικά

Οι δομές δεδομένων που μπορούν να περιέχουν μηδέν ή περισσότερα στοιχεία ονομάζονται _συλλογές_. Ένας **πίνακας** είναι μια συλλογή με σταθερό μέγεθος/μήκος, της οποίας όλα τα στοιχεία πρέπει να είναι του ίδιου τύπου. Μπορείς να αναθέσεις στοιχεία σε έναν πίνακα ή να τα ανακτήσεις από αυτόν χρησιμοποιώντας μια θέση. Οι πίνακες στη C# ξεκινούν από το μηδέν, που σημαίνει ότι η θέση του πρώτου στοιχείου είναι πάντα μηδέν:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Οι πίνακες μπορούν επίσης να οριστούν με μια συντομευμένη σημειογραφία που σου επιτρέπει και να δημιουργήσεις τον πίνακα και να ορίσεις την τιμή του. Καθώς ο μεταγλωττιστής μπορεί πλέον να καταλάβει πόσα στοιχεία θα έχει ο πίνακας, το μήκος μπορεί να παραλειφθεί:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Μπορείς να χειριστείς τους πίνακες καλώντας τις [μεθόδους][array-methods] ή τις [ιδιότητες][array-properties] ενός στιγμιοτύπου πίνακα, ή χρησιμοποιώντας τις στατικές μεθόδους που ορίζονται στην [`Array` κλάση][array-class].

## Επανάληψη

Ένας πίνακας είναι επίσης μια _συλλογή_, που σημαίνει ότι μπορείς να διατρέξεις _όλες_ τις τιμές του χρησιμοποιώντας έναν [`foreach` βρόχο][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Θα μπορούσες να χρησιμοποιήσεις έναν [`for` βρόχο][for-statement] για να διατρέξεις έναν πίνακα:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Ωστόσο, γενικά ένας `foreach` βρόχος προτιμάται από έναν `for` βρόχο για τους παρακάτω λόγους:

- Ένας `foreach` βρόχος εγγυάται ότι θα διατρέξει _όλες_ τις τιμές. Με έναν `for` βρόχο, είναι εύκολο να παραλείψεις στοιχεία, για παράδειγμα λόγω ενός σφάλματος κατά ένα.
- Ένας `foreach` βρόχος είναι πιο _δηλωτικός_, ο κώδικάς σου δηλώνει _τι_ θέλεις να κάνει, αντί για έναν `for` βρόχο που δηλώνει _πώς_ θέλεις να το κάνεις.
- Ένας `foreach` βρόχος είναι αλάνθαστος, ενώ με τους `for` βρόχους είναι εύκολο να κάνεις ένα σφάλμα κατά ένα.
- Ένας `foreach` βρόχος λειτουργεί με όλους τους τύπους συλλογών, συμπεριλαμβανομένων εκείνων που δεν υποστηρίζουν πρόσβαση σε στοιχεία μέσω θέσης.

Για να εγγυηθεί ότι ένας `foreach` βρόχος θα διατρέξει _όλες_ τις τιμές, ο μεταγλωττιστής δεν επιτρέπει την ενημέρωση μιας συλλογής μέσα σε έναν `foreach` βρόχο:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Ένας `for` βρόχος έχει όντως κάποια πλεονεκτήματα σε σχέση με έναν `foreach` βρόχο:

- Μπορείς να ξεκινήσεις ή να σταματήσεις στη θέση που θέλεις.
- Μπορείς να χρησιμοποιήσεις όποια Boolean (λογική τιμή) συνθήκη τερματισμού θέλεις.
- Μπορείς να παραλείψεις στοιχεία προσαρμόζοντας την αύξηση της μεταβλητής του βρόχου.
- Μπορείς να επεξεργαστείς συλλογές από το τέλος προς την αρχή μετρώντας αντίστροφα.
- Μπορείς να χρησιμοποιήσεις `for` βρόχους σε σενάρια που δεν περιλαμβάνουν συλλογές.

Σχετικά θέματα:

- Αξίζει να γνωρίζεις ότι η C# υποστηρίζει [πολυδιάστατους πίνακες][multi-dimensional-arrays] όπως `int[,] arr = new int[10, 5]`, που μπορούν να είναι πολύ χρήσιμοι.
- Αξίζει επίσης να γνωρίζεις ότι μπορείς να δημιουργήσεις στιγμιότυπα αντικειμένων τύπου [`System.Array`][system-array-object] με `Array.CreateInstance`. Τέτοια αντικείμενα έχουν μικρή χρησιμότητα, κυρίως για διαλειτουργικότητα με κώδικα VB.NET. Δεν είναι εναλλάξιμα με τους τυπικούς πίνακες (`T[]`). Μπορούν να έχουν κατώτερο όριο διάφορο του μηδενός.

Και τα δύο παραπάνω θέματα συζητούνται πιο αναλυτικά σε μια μεταγενέστερη άσκηση.
