# Εισαγωγή

Μια συνάρτηση υψηλότερης τάξης είναι μια συνάρτηση που:

- Δέχεται μια συνάρτηση ως όρισμα
- Επιστρέφει μια συνάρτηση

Ένα όρισμα συνάρτησης είναι απλώς ένα κανονικό όρισμα, με τη διαφορά ότι μπορείς να το καλέσεις.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
