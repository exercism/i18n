# Εισαγωγή στους `for` βρόχους

Ο [`for` βρόχος](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) παρέχει έναν μηχανισμό για να εκτελείται επανειλημμένα μια ομάδα εντολών, μέχρι να ικανοποιηθεί κάποια συνθήκη.
Ο βρόχος αποτελείται από τέσσερα μέρη:

```java
for (initialization; test; update) {
    body;
}
```

Το τμήμα `initialization` ορίζει μια αρχική κατάσταση για τον βρόχο και εκτελείται ακριβώς μία φορά, στην αρχή του βρόχου.
Συνήθως δηλώνει και εκχωρεί μια μεταβλητή που χρησιμοποιείται στην έκφραση `test` και στην εντολή `update`.
Για παράδειγμα:

```java
int i = 1
```

Η έκφραση `test` ελέγχει αν ο βρόχος πρέπει να τερματιστεί.
Αν αξιολογηθεί σε `true`, θα εκτελεστούν το σώμα και μετά η έκφραση `update`.
Αν αξιολογηθεί σε `false`, δεν θα εκτελεστούν ούτε το σώμα ούτε η εντολή `update` και η εκτέλεση συνεχίζεται μετά το άγκιστρο κλεισίματος του βρόχου.
Συνήθως ελέγχει τη μεταβλητή που εκχωρήθηκε στο τμήμα `initialization`.
Για παράδειγμα:

```java
i <= 10
```

Αφού εκτελεστεί το σώμα του βρόχου, εκτελείται η έκφραση `update`.
Συνήθως αυξάνει ή μειώνει τη μεταβλητή του βρόχου κατά κάποια τιμή.
Για παράδειγμα:

```java
i++
```

Ένας `for` βρόχος που τυπώνει τα πρώτα τέσσερα τετράγωνα θα έμοιαζε κάπως έτσι:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

Η έξοδος θα ήταν:

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

Αν θέλεις να διατρέξεις κάθε στοιχείο μιας συλλογής, προτιμότερος είναι ένας βρόχος `for-each`, αλλά μπορεί να γίνει και με έναν `for` βρόχο, όπως εδώ:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Ένας `for` βρόχος έχει όντως κάποια πλεονεκτήματα σε σχέση με έναν βρόχο `for-each`:

- Μπορείς να ξεκινήσεις ή να σταματήσεις στη θέση που θέλεις.
- Μπορείς να χρησιμοποιήσεις όποια συνθήκη τερματισμού θέλεις (Boolean).
- Μπορείς να παραλείψεις στοιχεία προσαρμόζοντας την αύξηση της μεταβλητής του βρόχου.
- Μπορείς να επεξεργαστείς συλλογές από το τέλος προς την αρχή, μετρώντας αντίστροφα.
- Μπορείς να χρησιμοποιήσεις `for` βρόχους σε περιπτώσεις που δεν περιλαμβάνουν συλλογές.
