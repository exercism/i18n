# Οδηγίες

Σε αυτή την άσκηση, πρέπει να μεταφράσεις μερικούς κανόνες από το κλασικό παιχνίδι Pac-Man σε συναρτήσεις C++.

Έχεις τέσσερις κανόνες να μεταφράσεις, όλους σχετικούς με τις καταστάσεις του παιχνιδιού.

> Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, συγκεντρώσου απλώς στο να συνδυάσεις τα ορίσματα ώστε να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `can_eat_ghost` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή (λογική τιμή) αν ο Pac-Man μπορεί να φάει το φάντασμα. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής μόνο αν ο Pac-Man έχει ενεργό χάπι δύναμης και αγγίζει ένα φάντασμα.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `scored` που παίρνει δύο ορίσματα (_αν ο Pac-Man αγγίζει ένα χάπι δύναμης_ και _αν ο Pac-Man αγγίζει μια κουκκίδα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man σκόραρε. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man αγγίζει ένα χάπι δύναμης ή μια κουκκίδα.

```cpp
scored(true, true);
// => true
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `lost` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man χάνει. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό χάπι δύναμης.

```cpp
lost(false, true);
// => true
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `won` που παίρνει τρία ορίσματα (_αν ο Pac-Man έχει φάει όλες τις κουκκίδες_, _αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man κερδίζει. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man έχει φάει όλες τις κουκκίδες και δεν έχει χάσει με βάση τα ορίσματα που ορίζονται στο μέρος 3.

```cpp
won(false, true, false);
// => false
```
