# Οδηγίες

Σε αυτή την άσκηση, θα εφαρμόσεις τους [κανόνες του παιχνιδιού Go](https://matmoore.github.io/learngo/). Οι ίδιοι οι κανόνες είναι ήδη γραμμένοι, εσύ απλώς χρειάζεται να τους εφαρμόσεις για να ενημερώσεις το Game και να χειριστείς τυχόν σφάλματα ή παραβιάσεις των κανόνων.

Το παιχνίδι αναπαρίσταται ως εξής:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

Υπάρχουν 4 κανόνες στο παιχνίδι:

- Κάθε σημείο μπορεί να έχει μόνο μία πέτρα (`oneStonePerPointRule`)
- Οι πέτρες του αντιπάλου μπορούν να αιχμαλωτιστούν! (`captureRule`)
- Δεν μπορείς να τοποθετήσεις μια πέτρα εκεί που θα αιχμαλωτίσει τον εαυτό της (`libertyRule`)
- Δεν μπορείς να χρησιμοποιήσεις το ίδιο σημείο δύο φορές (`koRule`)

## 1. Εφάρμοσε τους κανόνες

Γράψε το περιεχόμενο της συνάρτησης `applyRules`, η οποία παίρνει ένα αρχικό `Game` και ένα σύνολο κανόνων και επιστρέφει το νέο `Game` αφού εφαρμοστούν οι κανόνες.

Τα `oneStonePerPointRule`, `libertyRule` και `koRule` ελέγχουν όλα για παραβιάσεις των κανόνων και μπορεί να επιστρέψουν ένα σφάλμα, οπότε έχουν τύπο επιστροφής `Result String Game`. Αν αποτύχει κάποιος από αυτούς τους κανόνες, θα πρέπει να επιστραφεί το αρχικό παιχνίδι, αλλά με το πεδίο `error` ενημερωμένο με το σχετικό σφάλμα.

Το `captureRule` δεν ελέγχει για παραβιάσεις και άρα δεν μπορεί να αποτύχει (αν και μπορεί να επιστρέψει ένα αλλαγμένο `Game`), οπότε έχει τύπο επιστροφής `Game`.

Αν περάσουν όλοι οι κανόνες, τότε θα πρέπει να διατηρηθούν τυχόν αλλαγές στο `Game` από τους κανόνες και να αλλάξει ο παίκτης. Η συνάρτηση `changePlayer` παρέχεται για αυτόν τον σκοπό.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
