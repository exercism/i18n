# Σχετικά

Το parsing είναι η διαδικασία μετασχηματισμού κειμένου σε δεδομένα με νόημα.
Οι συναρτήσεις του πακέτου `String` είναι περιοριστικές ως προς αυτό και οι κανονικές εκφράσεις είναι δύσκολες στη χρήση, οπότε ο ιδιωματικός τρόπος για να κάνεις parse στην Elm είναι με το πακέτο `elm/parser`.

Ας δούμε βήμα βήμα ένα παράδειγμα όπου γράφουμε έναν parser για (ένα υποσύνολο της) γλώσσας προγραμματισμού [LOLCODE][lolcode].
Ας δούμε το παρακάτω πρόγραμμα με τα σχόλιά του:

```
HAI 1                 # program version 1
CAN HAS STDIO?        # import stdio
VISIBLE "HAI WORLD!"  # print "HAI WORLD!"
KTHXBYE               # end of program
```

Πρώτα, ας γράψουμε έναν τύπο της Elm που να αναπαριστά τις πιθανές εντολές:

```elm
type Command
    = Version Int
    | Import String
    | Print String
```

Το πρόγραμμα LOLCODE μας μπορεί τότε να μοντελοποιηθεί ως `List Command`.
Ας ξεκινήσουμε με έναν parser για τη γραμμή `HAI 1`:

```elm
versionP : Parser Command
versionP =
    Parser.succeed Version
        |. Parser.keyword "HAI"
        |. Parser.spaces
        |= Parser.int
```

Το `versionP` χτίζεται με μια _σωλήνωση parser_.
Ο τελεστής `(|.)` σημαίνει "κάνε parse τη συμβολοσειρά αλλά πέταξε το αποτέλεσμα" και ο `(|=)` σημαίνει "κάνε parse τη συμβολοσειρά και κράτησε το αποτέλεσμα".
Σε αυτό το παράδειγμα, το `Parser.keyword "HAI"` θα καταναλώσει ένα "HAI", αλλά το αποτέλεσμα αυτό αγνοείται.
Το `Parser.spaces` θα καταναλώσει οποιονδήποτε αριθμό χαρακτήρων ' ', '\n' και '\r', αλλά κι αυτό θα αγνοηθεί.
Το `Parser.int` θα κάνει parse έναν ακέραιο, και η τιμή αυτού του ακεραίου (ας πούμε 1) θα περαστεί στο `Parser.succeed Version` στην κορυφή και ο parser θα καταφέρει να επιστρέψει την τιμή `Version 1`.

Αν αποτύχει οποιοσδήποτε από τους parser στη σωλήνωση, θα επιστρέψει ένα `Parser.DeadEnd` και ολόκληρος ο parser θα αποτύχει.
Έναν parser μπορείς να τον τρέξεις με το `Parser.run`:

```elm
Parser.run versionP "HAI 1"
    --> Ok (Version 1)
Parser.run versionP "HAI 2"
    --> Ok (Version 2)
Parser.run versionP "BYE 2"
    --> Err [{ problem = ExpectingKeyword "HAI", col = 1, row = 1 }]
Parser.run versionP "HAI MOM"
    --> Err [{ problem = ExpectingInt, col = 5, row = 1 }]
```

Ας πιάσουμε τώρα τη γραμμή "CAN HAS STDIO?" με

```elm
importP : Parser Command
importP =
    Parser.succeed Import
        |. Parser.keyword "CAN HAS"
        |. Parser.spaces
        |= packageP
        |. Parser.symbol "?"
```

Το `importP` είναι επίσης μια σωλήνωση parser, αλλά αυτή τη φορά τελειώνει με `Parser.symbol`, που είναι κατάλληλο για να κάνει parse σύμβολα όπως το "?".
Η τιμή που θέλουμε να κρατήσουμε (το όνομα του πακέτου προς εισαγωγή) γίνεται parse από

```elm
packageP : Parser String
packageP =
    Parser.chompWhile Char.isAlphaNum
        |> Parser.getChompedString
        |> Parser.map String.toLower
```

Επειδή δεν ξέρουμε ποιο θα είναι το όνομα του πακέτου, δεν μπορούμε να χρησιμοποιήσουμε το `Parser.keyword`, οπότε αντ' αυτού χρησιμοποιούμε το `Parser.chompWhile`, που θα καταναλώσει έναν έναν τους χαρακτήρες όσο ικανοποιούν κάποια συνθήκη (εδώ, να είναι αλφαριθμητικοί χαρακτήρες).
Αυτοί οι χαρακτήρες που καταναλώθηκαν συλλέγονται έπειτα από το `Parser.getChompedString`, που επιστρέφει ένα `Parser String`.
Σε αυτή την περίπτωση, θέλουμε να κανονικοποιήσουμε τα ονόματα των πακέτων, οπότε χρησιμοποιούμε το `Parser.map` για να τροποποιήσουμε τη συμβολοσειρά που περιέχει ο parser και να τη μετατρέψουμε σε πεζά.

```elm
Parser.run importP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS StDiO?"
    --> Ok (Import "stdio")
Parser.run importP "CAN HAS STDIO"
    -->  Err [{ problem = ExpectingSymbol "?", col = 14, row = 1 }]
```

Στη συνέχεια, το `VISIBLE "HAI WORLD!"` γίνεται parse από

```elm
printP : Parser Command
printP =
    Parser.succeed Print
        |. Parser.keyword "VISIBLE"
        |. Parser.spaces
        |. Parser.symbol "\""
        |= stringP
        |. Parser.symbol "\""

stringP : Parser String
stringP =
    Parser.chompWhile (\c -> c /= '"')
        |> Parser.getChompedString

Parser.run printP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
```

Τώρα έχουμε έναν parser για κάθε εντολή.
Φυσικά, σε ένα γενικό πρόγραμμα, η σειρά αυτών των εντολών δεν μπορεί να προβλεφθεί, οπότε φτιάχνουμε έναν γενικό parser εντολών

```elm
commandP : Parser Command
commandP =
    Parser.oneOf
        [ versionP
        , importP
        , printP
        ]
```

Το `Parser.oneOf` θα δοκιμάσει τον έναν parser μετά τον άλλον, με τη σειρά που δίνεται.
Αν ένας parser αποτύχει, δοκιμάζεται ο επόμενος, αλλά αν πετύχει, το αποτέλεσμά του επιστρέφεται χωρίς να δοκιμαστούν οι υπόλοιποι parser.
Αν αποτύχουν όλοι οι parser, το `Parser.oneOf` αποτυγχάνει.

```elm
Parser.run commandP "HAI 2"
    --> Ok (Version 2)
Parser.run commandP "CAN HAS STDIO?"
    --> Ok (Import "stdio")
Parser.run commandP "VISIBLE \"HAI WORLD!\""
    --> Ok (Print "HAI WORLD!")
Parser.run commandP "O NOES"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 1 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 1 }
    --      ]
```

Πρόσεξε πως κάθε αποτυχημένη προσπάθεια παράγει ένα `Parser.DeadEnd`, που το συλλέγει το `Parser.oneOf`.

Για να κάνουμε parse ένα ολόκληρο πρόγραμμα, πρέπει να κάνουμε parse πολλές εντολές διαδοχικά με

```elm
programP : Parser (List Command)
programP =
    Parser.sequence
        { start = ""
        , separator = "\n"
        , end = "KTHXBYE"
        , spaces = Parser.succeed ()
        , item = commandP
        , trailing = Parser.Optional
        }
```

Το `Parser.sequence` είναι ένας πολύ προσαρμόσιμος parser με αρκετές επιλογές.
Τα `start`, `separator` και `end` παίρνουν συμβολοσειρές που χωρίζουν τα στοιχεία της ακολουθίας. Για να κάνουμε parse μια λίστα της Elm, θα χρησιμοποιούσαμε τα "[", "," και "]".
Το `spaces` δίνει ευελιξία, καθώς παίρνει έναν parser που θα χειριστεί τυχόν κενά ανάμεσα στα στοιχεία και τους διαχωριστές. Για να κάνουμε parse μια λίστα της Elm, θα χρησιμοποιούσαμε το `Parser.spaces`, αλλά σε αυτή την περίπτωση δεν δεχόμαστε καθόλου κενά, οπότε χρησιμοποιούμε το `Parser.succeed ()`, που πετυχαίνει αμέσως χωρίς να καταναλώσει στην πραγματικότητα τίποτα.
Το `item` παίρνει τον parser του στοιχείου και, τέλος, το `trailing` μας αφήνει να αποφασίσουμε αν οι τελικοί διαχωριστές είναι `Parser.Forbidden`, `Parser.Mandatory` ή `Parser.Optional`.

```elm
Parser.run programP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run programP "KTHXBYE"
    --> Ok []
Parser.run programP "HAI 2\nCAN HAS STDIO?\n"
    --> Err [ { problem = ExpectingKeyword "HAI", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "CAN HAS", col = 1, row = 3 }
    --      , { problem = ExpectingKeyword "VISIBLE", col = 1, row = 3 }
    --      , { problem = Expecting "KTHXBYE", col = 1, row = 3 }
    --      ]
```

Όταν οι parser πετυχαίνουν, σταματούν να καταναλώνουν τη συμβολοσειρά

```elm
Parser.run Parser.int "1"
    --> Ok 1
Parser.run Parser.int "1 BTW VISIBLE \"U SEE NOTHING\""
    --> Ok 1
```

Έτσι, αν θέλουμε να βεβαιωθούμε ότι κάναμε parse ό,τι υπάρχει στη συμβολοσειρά, μπορούμε να χρησιμοποιήσουμε το `Parser.end`

```elm
fullProgramP : Parser (List Command)
fullProgramP =
    programP
        |. Parser.spaces
        |. Parser.end

Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run fullProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE\nBTW VISIBLE \"U SEE NOTHING\""
    --> Err [{ problem = ExpectingEnd, col = 1, row = 4 }]
```

Τέλος, μερικές φορές χρειάζεται να αποφασίσουμε να αποτύχει ένας parser ανάλογα με το περιεχόμενο που έκανε parse.
Για παράδειγμα, αν χρειαζόμασταν έναν parser που να αποτυγχάνει σε προγράμματα που ξεκινούν με δύο εντολές "HAI" στη σειρά, θα μπορούσαμε να χρησιμοποιήσουμε

```elm
singleVersionProgramP : Parser (List Command)
singleVersionProgramP =
    fullProgramP
        |> Parser.andThen
            (\commands ->
                case commands of
                    (Version _) :: (Version _) :: _ ->
                        Parser.problem "Multiple versions defined"

                    _ ->
                        Parser.succeed commands
            )
```

Το `Parser.andThen` μπορεί να εξετάσει το περιεχόμενο ενός parser και επιστρέφει έναν νέο parser ανάλογα με την τιμή του.
Εδώ, στη μία περίπτωση αποτύχαμε τον parser με ένα προσαρμοσμένο μήνυμα χρησιμοποιώντας το `Parser.problem`, και στην άλλη επιστρέψαμε την αρχική τιμή.

```elm
Parser.run singleVersionProgramP "HAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Ok [Version 2, Import "stdio"]
Parser.run singleVersionProgramP "HAI 1\nHAI 2\nCAN HAS STDIO?\nKTHXBYE"
    --> Err [{ problem = Problem "Multiple versions defined", col = 8, row = 4 }]
```
