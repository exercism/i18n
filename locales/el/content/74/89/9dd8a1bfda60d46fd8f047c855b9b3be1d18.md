# Εισαγωγή

Ο χειρισμός κειμένου είναι μια συνηθισμένη εργασία στον προγραμματισμό.
Η Swift, μαζί με το framework Foundation, παρέχει πολλές βολικές μεθόδους και ιδιότητες για να εξετάζεις, να μετασχηματίζεις και να χειρίζεσαι συμβολοσειρές.

## Χωρισμός συμβολοσειρών με `components(separatedBy:)`

Για να χωρίσεις μια συμβολοσειρά σε έναν πίνακα από υποσυμβολοσειρές με βάση έναν διαχωριστικό, χρησιμοποίησε τη μέθοδο `components(separatedBy:)` (απαιτεί το import του Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Έλεγχος προθεμάτων και καταλήξεων με `hasPrefix(_:)` και `hasSuffix(_:)`

Για να ελέγξεις αν μια συμβολοσειρά ξεκινά ή τελειώνει με μια συγκεκριμένη ακολουθία χαρακτήρων, χρησιμοποίησε τις μεθόδους `hasPrefix(_:)` και `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Αλλαγή πεζών και κεφαλαίων

Μπορείς να αλλάξεις τα πεζά ή τα κεφαλαία μιας συμβολοσειράς χρησιμοποιώντας αυτές τις τυπικές μεθόδους και ιδιότητες:

- `lowercased()`: Επιστρέφει ένα αντίγραφο της συμβολοσειράς με πεζούς χαρακτήρες.
- `uppercased()`: Επιστρέφει ένα αντίγραφο της συμβολοσειράς με κεφαλαίους χαρακτήρες.
- `capitalized`: Επιστρέφει ένα αντίγραφο όπου το πρώτο γράμμα κάθε λέξης είναι κεφαλαίο (από το Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Αντικατάσταση υποσυμβολοσειρών με `replacingOccurrences(of:with:)`

Για να αντικαταστήσεις όλες τις εμφανίσεις μιας υποσυμβολοσειράς-στόχου με μια άλλη συμβολοσειρά, χρησιμοποίησε τη μέθοδο `replacingOccurrences(of:with:)` (από το Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Ένωση συμβολοσειρών με `joined(separator:)`

Η μέθοδος `joined(separator:)` ανήκει σε συλλογές συμβολοσειρών, όπως ο `[String]`.
Ενώνει τα στοιχεία σε μία μόνο συμβολοσειρά χρησιμοποιώντας έναν διαχωριστικό:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
