# Εισαγωγή

Οι τριαδικοί τελεστές επιτρέπουν να ορίζονται συνθήκες `if` μέσα σε εκφράσεις αντί σε μπλοκ εντολών. Αυτό θυμίζει προσεγγίσεις του συναρτησιακού προγραμματισμού και συχνά κάνει τον κώδικα πιο εκφραστικό και λιγότερο επιρρεπή σε λάθη.

Ο τριαδικός τελεστής συνδυάζει 3 εκφράσεις: μια συνθήκη, ακολουθούμενη από μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι αληθής (το μέρος `if`, που εισάγεται με `?`) και μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι ψευδής (το μέρος `else`, που εισάγεται με `:`).

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
