# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου.
Συνήθως χρησιμοποιείς ένα σημειωματάριο για να μετράς τα πουλιά, αλλά για να δουλέψεις καλύτερα με τα δεδομένα σου, ψηφιοποίησες τις μετρήσεις πουλιών των τελευταίων εβδομάδων.

## 1. Προσδιόρισε τον συνολικό αριθμό πουλιών που έχεις μετρήσει μέχρι τώρα

Ας ξεκινήσουμε την ανάλυση των δεδομένων παίρνοντας μια εικόνα από ψηλά.
Βρες πόσα πουλιά μέτρησες συνολικά από τότε που ξεκίνησες τις καταγραφές σου.

Υλοποίησε μια συνάρτηση `TotalBirdCount` που δέχεται ένα slice από `int` που περιέχει τον αριθμό πουλιών ανά ημέρα.
Θα πρέπει να επιστρέφει τον συνολικό αριθμό πουλιών που μέτρησες.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σε μια συγκεκριμένη εβδομάδα

Τώρα που απέκτησες μια γενική αίσθηση των αριθμών των πουλιών σου, θέλεις να κάνεις μια πιο λεπτομερή ανάλυση.

Υλοποίησε μια συνάρτηση `BirdsInWeek` που δέχεται ένα slice με τον αριθμό πουλιών ανά ημέρα και έναν αριθμό εβδομάδας.

Επιστρέφει τον συνολικό αριθμό πουλιών που μέτρησες σε αυτή τη συγκεκριμένη εβδομάδα.
Μπορείς να υποθέσεις ότι οι εβδομάδες καταγράφονται πάντα ολόκληρες.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Διόρθωσε ένα λάθος στη μέτρηση

Συνειδητοποίησες ότι όλο τον καιρό που προσπαθούσες να καταγράψεις τα πουλιά, υπήρχε ένα πουλί που κρυβόταν σε μια μακρινή γωνιά του κήπου.

Κατάλαβες ότι αυτό το πουλί περνούσε πάντα μέρα παρά μέρα στον κήπο σου.

Δεν ξέρεις ακριβώς πού βρισκόταν τις ενδιάμεσες μέρες, σίγουρα όμως όχι στον κήπο σου.

Το ένστικτό σου ως παρατηρητή πουλιών σου λέει επίσης ότι το πουλί ήταν στον κήπο σου την πρώτη μέρα που κατέγραψες στη λίστα σου.

Με αυτές τις νέες πληροφορίες, γράψε μια συνάρτηση `FixBirdCountLog` που παίρνει ως όρισμα ένα slice με τα πουλιά που μετρήθηκαν ανά ημέρα και επιστρέφει το slice αφού διορθώσει το λάθος στη μέτρηση.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
