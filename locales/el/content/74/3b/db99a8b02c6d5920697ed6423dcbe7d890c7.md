# PaySwitch - Μετατροπέας Μισθού

## Δήλωση προβλήματος

Μια εταιρεία που ονομάζεται **Insure Everyone** πληρώνει τους υπαλλήλους της σε ξένα νομίσματα. Όμως, λόγω νομοθετικών απαιτήσεων, ο μισθός πρέπει να μετατρέπεται στο τοπικό νόμισμα. Οι υπάλληλοί της βρίσκονται σε όλο τον κόσμο.
Το τμήμα ανθρώπινου δυναμικού της Insure Everyone ζητά τη βοήθεια ενός ταλαντούχου προγραμματιστή για να φτιάξει ένα πρόγραμμα που θα μετατρέπει τον μισθό κάθε υπαλλήλου στο αντίστοιχο τοπικό νόμισμα. Η Insure Everyone βασίζεται σε συναλλαγματικές ισοτιμίες που παρέχονται από ένα εξωτερικό API.

Με δεδομένο το εξωτερικό API συναλλαγματικών ισοτιμιών, πρέπει να γράψεις μια συνάρτηση που δέχεται ένα `source currency`, τον `salary` (σε νόμισμα προέλευσης) και το `local currency` του υπαλλήλου, και επιστρέφει τον μισθό στο τοπικό νόμισμα.

## Περιορισμοί

* 500 <= `salary` <= 10000
* Τα `sourceCurrency` και `targetCurrency` είναι [κωδικοί νομισμάτων ISO (αλφαβητικοί)](https://en.wikipedia.org/wiki/ISO_4217#Active_codes). Η είσοδος των δοκιμών μπορεί να περιέχει μη έγκυρους κωδικούς νομισμάτων.
* Η ακρίβεια της ισοτιμίας που επιστρέφεται θα μετριέται μέχρι `5` δεκαδικά ψηφία.

* Source Currency: USD
* Target Currency: GBP

{
    "base": "USD",
    "rates": {
        // omitted

        // omitted
    }
}
