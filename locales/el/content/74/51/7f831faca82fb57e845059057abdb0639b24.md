# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση         | Τύπος     | Περιγραφή                                          |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | πίνακας λέξεων με τις χωρητικότητες των κουβάδων              |
| `$a1`    | είσοδος        | ακέραιος | αρχικός κουβάς (1 ή 2)                          |
| `$a2`    | είσοδος        | ακέραιος | όγκος-στόχος                                  |
| `$a3`    | είσοδος/έξοδος | διεύθυνση | πίνακας λέξεων με τα τελικά περιεχόμενα των κουβάδων          |
| `$v0`    | έξοδος       | ακέραιος | αριθμός απαιτούμενων ενεργειών, -1 αν δεν είναι δυνατό |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | χρησιμοποιείται για προσωρινή αποθήκευση                     |
