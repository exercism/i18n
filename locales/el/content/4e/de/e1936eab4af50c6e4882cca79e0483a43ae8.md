# Σχετικά

Τα Boolean (λογικές τιμές) στην Java αντιπροσωπεύονται από τον τύπο `boolean`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η Java υποστηρίζει τρεις [τελεστές boolean][operators]:

- `!` (NOT): αντιστρέφει την τιμή boolean
- `&&` (AND): παίρνει δύο boolean και δίνει true αν είναι και τα δύο true
- `||` (OR): δίνει true αν τουλάχιστον ένα από τα δύο boolean είναι true

Οι τελεστές `&&` και `||` χρησιμοποιούν _βραχυκυκλωμένη αξιολόγηση_, που σημαίνει ότι η δεξιά πλευρά του τελεστή αξιολογείται μόνο όταν χρειάζεται.

Αυτοί είναι επίσης γνωστοί ως συνθηκικοί ή λογικοί τελεστές.
Το `!` μερικές φορές χαρακτηρίζεται ως πράξη bitwise στην τεκμηρίωση, αλλά έχει τη συμβατική σημασιολογία _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Οι τρεις τελεστές boolean έχουν ο καθένας διαφορετική [_προτεραιότητα τελεστών_][precedence].
Κατά συνέπεια, αξιολογούνται με την εξής σειρά: πρώτα το `not`, μετά το `&&`, και τέλος το `||`.
Αν θέλεις να 'ξεφύγεις' από αυτούς τους κανόνες, μπορείς να περικλείσεις μια boolean έκφραση σε παρενθέσεις (`()`), καθώς οι παρενθέσεις έχουν ακόμη μεγαλύτερη προτεραιότητα τελεστών.

```java
!true && false   // => false
!(true && false) // => true
```

[precedence]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/operators.html
