# Οδηγίες

Συντηρείς το κιτ δημιουργίας κώδικα ενός σταθμού σημάτων. Κάθε μακροεντολή είναι ένα *στένσιλ*: ένα μικρό πρότυπο που ο μεταγλωττιστής χρησιμοποιεί για να τυπώσει εξειδικευμένο κώδικα σε κάθε σημείο κλήσης.

Γράφεις μόνο τις τέσσερις μακροεντολές. Το αρχείο δοκιμών ορίζει μικρές λέξεις-περιτυλίγματα που *καλούν* τις μακροεντολές σου (μια μακροεντολή μπορεί να παρατηρηθεί μόνο μέσω του κώδικα που παράγει) και μετά ελέγχει τα αποτελέσματα εκτέλεσης των περιτυλιγμάτων. Άφησε τα περιτυλίγματα όπως είναι.

Για κάθε εργασία, το σώμα λαμβάνει στη στοίβα τα literal ορίσματα του σημείου κλήσης και πρέπει να αφήσει **μία παράθεση**. Οι γραμμές "compiles to" δείχνουν τον γραμμικό κώδικα που πρέπει να παράγει η παράθεσή σου.

## 1. Δύο φορές

Το `twice` παίρνει μια literal παράθεση και επιστρέφει μια παράθεση που εκτελεί την αρχική δύο φορές στη σειρά.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N επαναλήψεις

Το `repeat-quot` παίρνει μια literal παράθεση και ένα literal πλήθος `n`, και επιστρέφει μια παράθεση που εκτελεί την αρχική `n` φορές στη σειρά. Με `n = 0` επιστρέφει την κενή παράθεση `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Σύνθεση πολλών

Το `compose-many` παίρνει έναν literal πίνακα από παραθέσεις και επιστρέφει μία μόνο παράθεση που εκτελεί την καθεμιά διαδοχικά. Ένας κενός πίνακας επιστρέφει την κενή παράθεση.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Ξεδιπλωμένη επανάληψη

Το `each-literal` παίρνει μια literal ακολουθία και μια παράθεση. Επιστρέφει μια παράθεση που, για κάθε στοιχείο της ακολουθίας, βάζει αυτό το στοιχείο στη στοίβα και μετά εκτελεί την παράθεση: επανάληψη που συμβαίνει σε χρόνο μεταγλώττισης, οπότε ο κώδικας που παράγεται είναι γραμμικός.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Αυτή είναι η πιο δομική από τις τέσσερις: τόσο το μήκος της ακολουθίας *όσο και* οι τιμές των στοιχείων της διαμορφώνουν τον κώδικα που παράγεται. Οι υποδείξεις παρουσιάζουν βήμα βήμα το χτίσιμό της.
