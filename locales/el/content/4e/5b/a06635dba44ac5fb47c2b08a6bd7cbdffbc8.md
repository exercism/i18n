# Εισαγωγή

Όταν δουλεύεις με πίνακες, μερικές φορές θέλεις να εκτελέσεις κώδικα για κάθε τιμή του πίνακα.
Αυτό ονομάζεται επανάληψη ή βρόχος πάνω στον πίνακα.

Εδώ θα δούμε την περίπτωση όπου δε θέλεις να τροποποιήσεις τον πίνακα στη διαδικασία.
Για να μετασχηματίσεις πίνακες, δες αντ' αυτού την [έννοια των μετασχηματισμών πινάκων][concept-array-transformations].

## Ο `for` βρόχος

Ο πιο βασικός τρόπος για να κάνεις επανάληψη πάνω σε έναν πίνακα είναι να χρησιμοποιήσεις έναν `for` βρόχο, δες την [έννοια των `for` βρόχων][concept-for-loops].

```javascript
const numbers = [6.0221515, 10, 23];

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}
// => 6.0221515
// => 10
// => 23
```

## Ο `for...of` βρόχος

Όταν θέλεις να δουλέψεις με την τιμή απευθείας σε κάθε επανάληψη και δε χρειάζεσαι καθόλου τη θέση, μπορείς να χρησιμοποιήσεις έναν `for...of` βρόχο.

Ο `for...of` λειτουργεί όπως ο βασικός `for` βρόχος που φαίνεται παραπάνω, αλλά αντί να πρέπει να ασχοληθείς με τη _θέση_ ως μεταβλητή μέσα στον βρόχο, σου δίνεται απευθείας η _τιμή_.

```javascript
const numbers = [6.0221515, 10, 23];

// Because re-assigning number inside the loop will be very
// confusing, disallowing that via const is preferable.
for (const number of numbers) {
  console.log(number);
}
// => 6.0221515
// => 10
// => 23
```

Όπως ακριβώς στους κανονικούς `for` βρόχους, μπορείς να χρησιμοποιήσεις το `continue` για να σταματήσεις την τρέχουσα επανάληψη και το `break` για να σταματήσεις εντελώς την εκτέλεση του βρόχου.

## Η μέθοδος `forEach`

Κάθε πίνακας περιλαμβάνει μια μέθοδο `forEach` που μπορεί να χρησιμοποιηθεί για να κάνεις επανάληψη πάνω στα στοιχεία του πίνακα.

Το `forEach` δέχεται ένα [callback][concept-callbacks] ως παράμετρο.
Η συνάρτηση callback καλείται μία φορά για κάθε στοιχείο του πίνακα.
Το τρέχον στοιχείο, η θέση του και ολόκληρος ο πίνακας περνιούνται στο callback ως ορίσματα.
Συχνά χρησιμοποιείται μόνο το τρέχον στοιχείο ή η θέση.

```javascript
const numbers = [6.0221515, 10, 23];

numbers.forEach((number, index) => console.log(number, index));
// => 6.0221515 0
// => 10 1
// => 23 2
```

Δεν υπάρχει τρόπος να σταματήσεις την επανάληψη μόλις ξεκινήσει ο βρόχος `forEach`.
Οι εντολές `break` και `continue` δεν υπάρχουν σε αυτό το πλαίσιο.
