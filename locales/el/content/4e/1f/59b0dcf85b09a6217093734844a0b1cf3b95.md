# Οδηγίες

Η αποστολή σου είναι να αναλύσεις μια συμβολοσειρά Smart Game Format (SGF) και να επιστρέψεις μια δενδρική δομή δεδομένων που αναπαριστά το παιχνίδι.

Μια συμβολοσειρά SGF αναπαριστά ένα δέντρο κόμβων. Ολόκληρο το δέντρο περικλείεται σε παρενθέσεις `()`. Κάθε κόμβος του δέντρου δηλώνεται με ένα ερωτηματικό `;`, που ακολουθείται από μια ακολουθία ιδιοτήτων. Μια ιδιότητα αποτελείται από ένα αναγνωριστικό με κεφαλαία γράμματα (π.χ. `AB`), που ακολουθείται από μία ή περισσότερες τιμές περικλεισμένες σε αγκύλες `[]`.

Για παράδειγμα, η συμβολοσειρά `(;FF[4]C[root])` αναπαριστά ένα δέντρο με έναν μόνο ριζικό κόμβο. Αυτός ο κόμβος έχει δύο ιδιότητες:
- Την ιδιότητα `FF` με τιμή `4`
- Την ιδιότητα `C` με τιμή `root`

**Παραλλαγές (Δέντρα και Κλαδιά)**
Το SGF υποστηρίζει παραλλαγές παιχνιδιών με εμφώλευση δέντρων. Ένα δέντρο μπορεί να έχει πολλά θυγατρικά δέντρα, τα οποία επίσης περικλείονται σε παρενθέσεις.
Για παράδειγμα, το `(;A[B](;C[D])(;E[F]))` αναπαριστά έναν ριζικό κόμβο με ιδιότητα `A`, ο οποίος έχει δύο θυγατρικά κλαδιά:
1. Έναν κόμβο με ιδιότητα `C` και τιμή `D`
2. Έναν κόμβο με ιδιότητα `E` και τιμή `F`

**Μορφοποίηση και διαφυγή χαρακτήρων**
Οι τιμές μέσα στις αγκύλες μπορούν να περιέχουν χαρακτήρες διαφυγής. Μια ανάστροφη κάθετος `\` που ακολουθείται από οποιονδήποτε χαρακτήρα αναπαριστά αυτόν τον χαρακτήρα κατά γράμμα (π.χ. το `\]` πρέπει να αναλυθεί ως ένα κατά γράμμα `]`). Επιπλέον, αν μια αλλαγή γραμμής προηγείται από ανάστροφη κάθετο, λειτουργεί ως συνέχεια γραμμής και πρέπει να αφαιρεθεί από την τιμή. Όλες οι άλλες αλλαγές γραμμής μέσα σε μια τιμή πρέπει να διατηρηθούν.

**Χειρισμός σφαλμάτων**
Πρέπει να πετάς ένα σφάλμα για κάθε μη έγκυρη συμβολοσειρά SGF. Ακολουθούν παραδείγματα μη έγκυρου SGF:
- Ένα δέντρο που δεν ξεκινά με παρενθέσεις `()`.
- Ένας κόμβος που δεν ξεκινά με ερωτηματικό `;`.
- Αναγνωριστικά ιδιοτήτων που δεν αποτελούνται εξ ολοκλήρου από κεφαλαία γράμματα.
- Αγκύλες που λείπουν ή παρενθέσεις που δεν ταιριάζουν.

### Δομή δεδομένων

Η συνάρτηση ανάλυσης που θα γράψεις πρέπει να επιστρέφει μια αναπαράσταση του δέντρου. Μια συνηθισμένη προσέγγιση είναι να αναπαριστάς κάθε δέντρο ως ένα αντικείμενο με δύο πεδία:
- `properties`: Ένα αντικείμενο (ή Map) όπου τα κλειδιά είναι τα αναγνωριστικά των ιδιοτήτων (συμβολοσειρές) και οι τιμές είναι πίνακες συμβολοσειρών (αφού μια ιδιότητα μπορεί να έχει πολλές τιμές).
- `children`: Ένας πίνακας που περιέχει τα θυγατρικά δέντρα.


Παράδειγμα:

Είσοδος: `(;FF[4]C[root])`
Έξοδος: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Είσοδος: `(;A[B](;C[D])(;E[F]))`
Έξοδος: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
