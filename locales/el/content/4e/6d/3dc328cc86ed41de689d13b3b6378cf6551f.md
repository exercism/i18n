# Εισαγωγή

## Η εντολή _if-then_

Η πιο βασική εντολή ελέγχου ροής στη Java είναι η εντολή _if-then_.
Αυτή η εντολή χρησιμοποιείται για να εκτελείται ένα τμήμα κώδικα μόνο όταν μια συγκεκριμένη συνθήκη είναι `true`.
Μια εντολή _if-then_ ορίζεται με τη ρήτρα `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

Στο παραπάνω παράδειγμα, αν το αυτοκίνητο έχει ξεμείνει από καύσιμο, η κλήση της μεθόδου `Car.drive` δεν θα κάνει τίποτα.

## Η εντολή _if-then-else_

Η εντολή _if-then-else_ παρέχει μια εναλλακτική διαδρομή εκτέλεσης για όταν η συνθήκη στη ρήτρα `if` αποτιμάται σε `false`.
Αυτή η εναλλακτική διαδρομή εκτέλεσης ακολουθεί μια ρήτρα `if` και ορίζεται με τη ρήτρα `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

Στο παραπάνω παράδειγμα, αν το αυτοκίνητο έχει ξεμείνει από καύσιμο, η κλήση της μεθόδου `Car.drive` θα καλέσει μια άλλη μέθοδο για να σταματήσει το αυτοκίνητο.

Η εντολή _if-then-else_ υποστηρίζει επίσης πολλαπλές συνθήκες χρησιμοποιώντας τη ρήτρα `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

Στο παραπάνω παράδειγμα, οδηγώντας το αυτοκίνητο όταν το καύσιμο είναι μικρότερο ή ίσο με `5`, το αυτοκίνητο θα κινηθεί, αλλά θα ανάψει η λυχνία καυσίμου.
Όταν το καύσιμο φτάσει στο `0`, το αυτοκίνητο θα σταματήσει να κινείται.
