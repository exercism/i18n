# Οδηγίες

Εσύ και οι επιχειρηματικοί σου συνεργάτες έχετε μια μικρή εταιρεία catering. Μόλις συμφωνήσατε να διοργανώσετε μια εκδήλωση για έναν τοπικό σύλλογο μαγειρικής, με τα "αγαπημένα του συλλόγου" πιάτα. Ο σύλλογος δεν έχει εμπειρία στη διοργάνωση μεγάλων εκδηλώσεων και χρειάζεται βοήθεια στην οργάνωση, στα ψώνια, στην προετοιμασία και στο σερβίρισμα. Αποφάσισες να γράψεις μερικά μικρά σκριπτ Python, για να επιταχύνεις όλη τη διαδικασία του σχεδιασμού.

## 1. Καθάρισε τα συστατικά των πιάτων

Οι συνταγές της εκδήλωσης προστέθηκαν από διάφορες πηγές και τα συστατικά τους φαίνεται να έχουν διπλές (_ή και περισσότερες_) καταχωρίσεις. Δεν θέλεις να καταλήξεις να αγοράσεις περισσότερα υλικά από όσα χρειάζεσαι!
 Πριν ξεκινήσουν τα ψώνια και το μαγείρεμα, η λίστα συστατικών κάθε πιάτου πρέπει να "καθαριστεί".

Υλοποίησε τη συνάρτηση `clean_ingredients(<dish_name>, <dish_ingredients>)`, που παίρνει το όνομα ενός πιάτου και μια `list` με συστατικά.
 Η συνάρτηση πρέπει να επιστρέφει ένα `tuple` με το όνομα του πιάτου ως πρώτο στοιχείο, ακολουθούμενο από το `set` των συστατικών χωρίς διπλότυπα.


```python
>>> clean_ingredients('Punjabi-Style Chole', ['onions', 'tomatoes', 'ginger paste', 'garlic paste', 'ginger paste', 'vegetable oil', 'bay leaves', 'cloves', 'cardamom', 'cilantro', 'peppercorns', 'cumin powder', 'chickpeas', 'coriander powder', 'red chili powder', 'ground turmeric', 'garam masala', 'chickpeas', 'ginger', 'cilantro'])

>>> ('Punjabi-Style Chole', {'garam masala', 'bay leaves', 'ground turmeric', 'ginger', 'garlic paste', 'peppercorns', 'ginger paste', 'red chili powder', 'cardamom', 'chickpeas', 'cumin powder', 'vegetable oil', 'tomatoes', 'coriander powder', 'onions', 'cilantro', 'cloves'})
```

## 2. Κοκτέιλ και mocktails

Η εκδήλωση θα περιλαμβάνει και κοκτέιλ και "mocktails", δηλαδή μικτά ποτά _χωρίς_ το αλκοόλ.
 Πρέπει να βεβαιωθείς ότι τα ποτά "mocktail" είναι πραγματικά χωρίς αλκοόλ και ότι τα κοκτέιλ όντως _περιέχουν_ αλκοόλ.

Υλοποίησε τη συνάρτηση `check_drinks(<drink_name>, <drink_ingredients>)`, που παίρνει το όνομα ενός ποτού και μια `list` με συστατικά.
 Η συνάρτηση πρέπει να επιστρέφει το όνομα του ποτού ακολουθούμενο από "Mocktail" αν το ποτό δεν έχει αλκοολούχα συστατικά, και το όνομα του ποτού ακολουθούμενο από "Cocktail" αν το ποτό περιέχει αλκοόλ.
  Για τους σκοπούς αυτής της άσκησης, τα κοκτέιλ θα περιέχουν αλκοόλ μόνο από τη σταθερά ALCOHOLS στο `sets_categories_data.py`:

```python
>>> from sets_categories_data import ALCOHOLS 

>>> check_drinks('Honeydew Cucumber', ['honeydew', 'coconut water', 'mint leaves', 'lime juice', 'salt', 'english cucumber'])
...
'Honeydew Cucumber Mocktail'

>>> check_drinks('Shirley Tonic', ['cinnamon stick', 'scotch', 'whole cloves', 'ginger', 'pomegranate juice', 'sugar', 'club soda'])
...
'Shirley Tonic Cocktail'
```

## 3. Κατηγοριοποίησε τα πιάτα

Η λίστα καλεσμένων περιλαμβάνει συνδαιτυμόνες με διαφορετικές διατροφικές ανάγκες, και το προσωπικό σου θα πρέπει να χωρίσει τα πιάτα σε Vegan, Vegetarian, Paleo, Keto και Omnivore.
Ένα πιάτο ανήκει σε μια κατηγορία μόνο αν όλα τα συστατικά του υπάρχουν στο σύνολο συστατικών της κατηγορίας.

Υλοποίησε τη συνάρτηση `categorize_dish(<dish_name>, <dish_ingredients>)`, που παίρνει το όνομα ενός πιάτου και ένα `set` με τα συστατικά του πιάτου.
Η συνάρτηση πρέπει να επιστρέφει μια συμβολοσειρά με τη μορφή `dish name: <CATEGORY>` (_σε ποια κατηγορία γεύματος ανήκει το πιάτο_).
Όλα τα πιάτα που δίνονται θα "ταιριάζουν" σε μία από τις κατηγορίες που εισάγονται από το `sets_categories_data.py` (VEGAN, VEGETARIAN, PALEO, KETO ή OMNIVORE).

```python
>>> from sets_categories_data import VEGAN, VEGETARIAN, PALEO, KETO, OMNIVORE


>>> categorize_dish('Sticky Lemon Tofu', {'tofu', 'soy sauce', 'salt', 'black pepper', 'cornstarch', 'vegetable oil', 'garlic', 'ginger', 'water', 'vegetable stock', 'lemon juice', 'lemon zest', 'sugar'})
...
'Sticky Lemon Tofu: VEGAN'

>>> categorize_dish('Shrimp Bacon and Crispy Chickpea Tacos with Salsa de Guacamole', {'shrimp', 'bacon', 'avocado', 'chickpeas', 'fresh tortillas', 'sea salt', 'guajillo chile', 'slivered almonds', 'olive oil', 'butter', 'black pepper', 'garlic', 'onion'})
...
'Shrimp Bacon and Crispy Chickpea Tacos with Salsa de Guacamole: OMNIVORE'
```

## 4. Επισήμανε τα αλλεργιογόνα και τις απαγορευμένες τροφές

Κάποιοι καλεσμένοι έχουν αλλεργίες και επιπλέον διατροφικούς περιορισμούς.
Αυτά τα συστατικά πρέπει να επισημαίνονται/να σχολιάζονται για κάθε πιάτο, ώστε να μη δημιουργούν προβλήματα.

Υλοποίησε τη συνάρτηση `tag_special_ingredients(<dish>)`, που παίρνει ένα `tuple` με το όνομα του πιάτου στην πρώτη θέση και μια `list` ή ένα `set` με τα συστατικά του πιάτου στη δεύτερη θέση.
Επίστρεψε το όνομα του πιάτου ακολουθούμενο από το `set` των συστατικών που χρειάζονται ειδική σημείωση στην περιγραφή του πιάτου.
Τα συστατικά ενός πιάτου μέσα σε μια `list` μπορεί να έχουν ή να μην έχουν διπλότυπα.
 Για τους σκοπούς αυτής της άσκησης, όλα τα αλλεργιογόνα ή τα ειδικά συστατικά που χρειάζονται επισήμανση βρίσκονται στη σταθερά SPECIAL_INGREDIENTS που εισάγεται από το `sets_categories_data.py`.

```python
>>> from sets_categories_data import SPECIAL_INGREDIENTS

>>> tag_special_ingredients(('Ginger Glazed Tofu Cutlets', ['tofu', 'soy sauce', 'ginger', 'corn starch', 'garlic', 'brown sugar', 'sesame seeds', 'lemon juice']))
...
('Ginger Glazed Tofu Cutlets', {'garlic','soy sauce','tofu'})

>>> tag_special_ingredients(('Arugula and Roasted Pork Salad', ['pork tenderloin', 'arugula', 'pears', 'blue cheese', 'pine nuts', 'balsamic vinegar', 'onions', 'black pepper']))
...
('Arugula and Roasted Pork Salad', {'pork tenderloin', 'blue cheese', 'pine nuts', 'onions'})
```

## 5. Σύνταξε μια "κύρια λίστα" με συστατικά

Για να προετοιμαστείς για τις παραγγελίες και τα ψώνια, θα χρειαστεί να συντάξεις μια "κύρια λίστα" με συστατικά για όλα όσα υπάρχουν στο μενού (_οι ποσότητες θα συμπληρωθούν αργότερα_).

Υλοποίησε τη συνάρτηση `compile_ingredients(<dishes>)`, που παίρνει μια `list` με πιάτα και επιστρέφει ένα set με όλα τα συστατικά όλων των πιάτων της λίστας.
Κάθε επιμέρους πιάτο αντιπροσωπεύεται από το `set` των συστατικών του.

```python
dishes = [ {'tofu', 'soy sauce', 'ginger', 'corn starch', 'garlic', 'brown sugar', 'sesame seeds', 'lemon juice'},
           {'pork tenderloin', 'arugula', 'pears', 'blue cheese', 'pine nuts',
           'balsamic vinegar', 'onions', 'black pepper'},
           {'honeydew', 'coconut water', 'mint leaves', 'lime juice', 'salt', 'english cucumber'}]

>>> compile_ingredients(dishes)
...
{'arugula', 'brown sugar', 'honeydew', 'coconut water', 'english cucumber', 'balsamic vinegar', 'mint leaves', 'pears', 'pork tenderloin', 'ginger', 'blue cheese', 'soy sauce', 'sesame seeds', 'black pepper', 'garlic', 'lime juice', 'corn starch', 'pine nuts', 'lemon juice', 'onions', 'salt', 'tofu'}
```

## 6. Ξεχώρισε τα ορεκτικά για σερβίρισμα σε δίσκους

Οι οικοδεσπότες σου έδωσαν μια λίστα με πιάτα που θα ήθελαν να ετοιμαστούν ως ορεκτικά "μιας μπουκιάς", για να σερβιριστούν σε δίσκους.
 Πρέπει να τα ξεχωρίσεις από την κύρια λίστα των πιάτων που ετοιμάζονται ως μεγαλύτερες μερίδες.

Υλοποίησε τη συνάρτηση `separate_appetizers(<dishes>, <appetizers>)`, που παίρνει μια `list` με ονόματα πιάτων και μια `list` με ονόματα ορεκτικών.
Η συνάρτηση πρέπει να επιστρέφει τη `list` με τα ονόματα των πιάτων αφού αφαιρεθούν τα ονόματα των ορεκτικών.
Είτε η `list` `<dishes>` είτε η `<appetizers>` μπορεί να περιέχει διπλότυπα και ίσως χρειάζεται αφαίρεση διπλοτύπων.

```python
dishes =    ['Avocado Deviled Eggs','Flank Steak with Chimichurri and Asparagus', 'Kingfish Lettuce Cups',
             'Grilled Flank Steak with Caesar Salad','Vegetarian Khoresh Bademjan','Avocado Deviled Eggs',
             'Barley Risotto','Kingfish Lettuce Cups']
          
appetizers = ['Kingfish Lettuce Cups','Avocado Deviled Eggs','Satay Steak Skewers',
              'Dahi Puri with Black Chickpeas','Avocado Deviled Eggs','Asparagus Puffs',
              'Asparagus Puffs']
              
>>> separate_appetizers(dishes, appetizers)
...
['Vegetarian Khoresh Bademjan', 'Barley Risotto', 'Flank Steak with Chimichurri and Asparagus', 
 'Grilled Flank Steak with Caesar Salad']
```

## 7. Βρες συστατικά που χρησιμοποιούνται σε μία μόνο συνταγή

Σε κάθε κατηγορία (_Vegan, Vegetarian, Paleo, Keto, Omnivore_), θα ξεχωρίσεις τα συστατικά που εμφανίζονται σε ένα μόνο πιάτο.
Αυτά τα συστατικά "singleton" θα ανατεθούν σε έναν ειδικό αγοραστή, για να μη ξεχαστούν στη βιασύνη να γίνουν όλα τα υπόλοιπα.

Υλοποίησε τη συνάρτηση `singleton_ingredients(<dishes>, <INTERSECTIONS>)`, που παίρνει μια `list` με πιάτα και μια σταθερά `<CATEGORY>_INTERSECTIONS` για την ίδια κατηγορία.
Κάθε πιάτο αντιπροσωπεύεται από ένα `set` με τα συστατικά του.
Κάθε `<CATEGORY>_INTERSECTIONS` είναι ένα `set` με συστατικά που εμφανίζονται σε περισσότερα από ένα πιάτα της κατηγορίας.
Χρησιμοποιώντας πράξεις συνόλων, η συνάρτηση πρέπει να επιστρέφει ένα `set` με συστατικά "singleton" (_συστατικά που εμφανίζονται σε ένα μόνο πιάτο της κατηγορίας_).

```python
from sets_categories_data import example_dishes, EXAMPLE_INTERSECTION

>>> singleton_ingredients(example_dishes, EXAMPLE_INTERSECTION)
...
{'garlic powder', 'sunflower oil', 'mixed herbs', 'cornstarch', 'celeriac', 'honey', 'mushrooms', 'bell pepper', 'rosemary', 'parsley', 'lemon', 'yeast', 'vegetable oil', 'vegetable stock', 'silken tofu', 'tofu', 'cashews', 'lemon zest', 'smoked tofu', 'spaghetti', 'ginger', 'breadcrumbs', 'tomatoes', 'barley malt', 'red pepper flakes', 'oregano', 'red onion', 'fresh basil'}
```
