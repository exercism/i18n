# Σχετικά

Η Swift είναι μια μεταγλωττισμένη, πολυπαραδειγματική γλώσσα.
Με τους παρακάτω στόχους:

- Να έχει χαρακτηριστικά ασφαλείας για την αποτροπή σφαλμάτων στην παραγωγή

- Να έχει συγκρίσιμη ταχύτητα με γλώσσες βασισμένες στη C

- Να έχει σύνταξη που είναι απόλαυση να τη διαβάζεις και να τη γράφεις

Η Swift αναπτύχθηκε ως αντικαταστάτης της Objective-C, η οποία ήταν η κύρια γλώσσα που χρησιμοποιούνταν για την ανάπτυξη εφαρμογών iOS και macOS.
Η Swift αναπτύχθηκε από την Apple Inc.
Η γλώσσα κυκλοφόρησε για πρώτη φορά το 2014.
Σήμερα είναι ανοιχτού κώδικα και είναι διαθέσιμη σε όλες τις συσκευές Apple, στο Linux και στα Windows.

## Ξεκινώντας

### Μεταβλητές

Οι τιμές μπορούν να συσχετιστούν με ονόματα ορίζοντας μια [μεταβλητή][constants-variables] και εκχωρώντας μια τιμή σε αυτή τη μεταβλητή.
Στη συνέχεια, αυτό το όνομα μπορεί να χρησιμοποιηθεί για να αναφέρεται σε αυτή την τιμή σε όλο το πρόγραμμα.
Οι μεταβλητές είναι _μεταβλητές_, που σημαίνει ότι η τιμή μπορεί να αλλάξει οποιαδήποτε στιγμή.

Οι μεταβλητές ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `var`.

```swift
var variableName = 10
```

Η Swift είναι μια γλώσσα ασφαλής ως προς τους τύπους, στατικά τυποποιημένη, που σημαίνει ότι όλες οι τιμές έχουν τύπο κατά τη μεταγλώττιση.
Μπορείς είτε να προσδιορίσεις ρητά τον τύπο μιας μεταβλητής με [σχολιασμούς τύπων][type annotations] είτε να αφήσεις τον μεταγλωττιστή να [συμπεράνει τον τύπο][type-inferring].
```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Η ενημέρωση της τιμής μιας μεταβλητής γίνεται χρησιμοποιώντας τον τελεστή `=`.

~~~~exercism/note
Ο τύπος μιας μεταβλητής είναι σταθερός μόλις οριστεί αρχικά.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Οι μεταβλητές μπορούν να δηλωθούν χωρίς να τους εκχωρηθεί τιμή, προσδιορίζοντας το όνομα και τον τύπο, αλλά δε μπορούν να χρησιμοποιηθούν προτού τους εκχωρηθεί μια τιμή.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Σταθερές

Οι [σταθερές][constants-variables] είναι παρόμοιες με τις μεταβλητές στο ότι συσχετίζονται με ένα όνομα και μια τιμή, αλλά η τιμή μιας σταθεράς δεν μπορεί να αλλάξει μόλις εκχωρηθεί αρχικά και επομένως είναι _αμετάβλητη_.
Οι σταθερές ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `let`.

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Πρόσθεση & Αφαίρεση & Πολλαπλασιασμός

Η Swift έχει [τελεστές][arithmetical-operators] για πρόσθεση, αφαίρεση και πολλαπλασιασμό.
Οι τελεστές είναι `+`, `-` και `*` αντίστοιχα.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Συναρτήσεις

Στη Swift, οι [συναρτήσεις][functions] είναι ένα τμήμα κώδικα που εκτελεί μια εργασία.
Μια συνάρτηση έχει τύπο επιστροφής και μπορεί έτσι να χρησιμοποιηθεί ως τιμή και να περαστεί ως όρισμα σε άλλες συναρτήσεις.
Στη Swift, οι συναρτήσεις ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `func` ακολουθούμενη από το όνομα της συνάρτησης, ορίσματα χωρισμένα με κόμματα και έναν τύπο επιστροφής.

Τα ορίσματα ορίζονται από μια ετικέτα ορίσματος, ένα όνομα παραμέτρου ακολουθούμενο από άνω και κάτω τελεία και έπειτα από έναν τύπο.
Ο τύπος επιστροφής ορίζεται από ένα `->` ακολουθούμενο από τον τύπο της τιμής επιστροφής.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Τα ορίσματα στη Swift είναι λίγο ξεχωριστά σε σύγκριση με άλλες γλώσσες, χρησιμοποιούν [ετικέτες ορισμάτων][argument-labels].
Η ετικέτα ορίσματος χρησιμοποιείται κατά την κλήση της συνάρτησης.
Το όνομα παραμέτρου χρησιμοποιείται μέσα στο σώμα της συνάρτησης για να αναφέρεται στην τιμή του ορίσματος.
Αν εκχωρήσεις μόνο ένα όνομα στο όρισμα, θα χρησιμοποιηθεί και ως ετικέτα ορίσματος και ως όνομα παραμέτρου.
Όταν εκχωρείς το όνομα της ετικέτας ορίσματος ως: `_`, το όρισμα δε θα έχει ετικέτα κατά την κλήση της συνάρτησης, π.χ.: `functionName(argumentValue)`

Για να καλέσεις μια συνάρτηση, χρησιμοποιείς το όνομα της συνάρτησης ακολουθούμενο από την ετικέτα ορίσματος και την τιμή του ορίσματος, όπως εδώ:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Όλα τα ορίσματα είναι αμετάβλητα από προεπιλογή και δε μπορούν να αλλάξουν μέσα στη συνάρτηση.
Όταν μια συνάρτηση έχει τύπο επιστροφής, φρόντισε να επιστρέψεις μια τιμή αυτού του τύπου.
Αυτό γίνεται χρησιμοποιώντας τη λέξη-κλειδί `return` ακολουθούμενη από την τιμή προς επιστροφή.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Όταν οι συναρτήσεις δεν επιστρέφουν κάποια τιμή, έχουν τύπο επιστροφής `Void`, που είναι το ίδιο με `()`, αλλά ο τύπος επιστροφής μπορεί επίσης να παραλειφθεί σε αυτές τις περιπτώσεις.

Η Swift υποστηρίζει δύο τύπους [σχολίων][comments].
