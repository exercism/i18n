# Οδηγίες

Η Lilly η Lisp Alien επέστρεψε και μαγειρεύει ξανά! Αυτή τη φορά θα φτιάξει τα Λαζάνια Lisp Alien, που δεν διαφέρουν και τόσο από τα ανθρώπινα λαζάνια.

Η Lilly θα χρειαστεί μερικές συναρτήσεις για να υπολογίσει τον χρόνο ψησίματος των λαζανιών. Και καθεμία από αυτές χρειάζεται καλή τεκμηρίωση, ώστε η Lilly να μη ξεχάσει τι κάνει η καθεμία.

Μπορείς να βοηθήσεις τη Lilly να γράψει συναρτήσεις που θα τη βοηθήσουν να υπολογίσει τον χρόνο ψησίματος των λαζανιών;

## 1. Όρισε τον αναμενόμενο χρόνο στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `expected-time-in-oven` που δεν παίρνει καμία παράμετρο και επιστρέφει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με την παράδοση των Lisp Alien (όπως ακριβώς μαγείρευε και η γονική μονάδα της Lilly), ο αναμενόμενος χρόνος στον φούρνο σε λεπτά είναι 337:

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. Υπολόγισε τον χρόνο που απομένει στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `remaining-minutes-in-oven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που τα λαζάνια βρίσκονται ήδη στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο στον φούρνο σε λεπτά από την προηγούμενη εργασία.

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparation-time-in-minutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσε η Lilly στα λαζάνια και επιστρέφει πόσα λεπτά πέρασε η Lilly προετοιμάζοντας τα λαζάνια, υποθέτοντας ότι κάθε στρώση θέλει 19 λεπτά για να ετοιμαστεί.

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsed-time-in-minutes` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσε η Lilly στα λαζάνια και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχει αφιερώσει η Lilly στο μαγείρεμα των λαζανιών, δηλαδή το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο εκείνη τη στιγμή.

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
