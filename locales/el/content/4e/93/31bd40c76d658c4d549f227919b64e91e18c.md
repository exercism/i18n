# Προσθήκη στις οδηγίες

## Οδηγίες ειδικές για το track

### Μορφή εισόδου

Η είσοδος θα έχει τη μορφή συμβολοσειράς.
Για να παραμείνει αυτή η άσκηση φιλική για αρχάριους, δε χρειάζεται να περιμένεις αριθμούς με πολλαπλά ψηφία.

Τα byte 64-191 της γραμμικής μνήμης είναι δεσμευμένα για τη συμβολοσειρά εισόδου.

### Μορφή εξόδου

Η έξοδος αναμένεται σε ζεύγη γραμμής και στήλης ως u8, άμεσα συνενωμένα.

Για παράδειγμα, αν υπάρχουν τρία σημεία σέλας

γραμμή: 2, στήλη: 1
γραμμή: 2, στήλη: 2
γραμμή: 2, στήλη: 3

τότε η αναμενόμενη έξοδος θα ήταν οι τιμές u8 `2, 1, 2, 2, 2, 3`
