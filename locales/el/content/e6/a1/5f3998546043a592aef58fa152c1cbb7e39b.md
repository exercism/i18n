# Οδηγίες

Οι ακροάσεις για τη σχολική παράσταση τελείωσαν και ο σκηνοθέτης χρειάζεται να καταγράψει τις αποφάσεις.

Και οι τέσσερις εργασίες μπαίνουν στην κλάση `CASTING_CALL`.

## 1. Η ετυμηγορία

Κάθε ερμηνευτής βαθμολογείται με άριστα το δέκα. Με οκτώ ή παραπάνω παίρνουν ρόλο· από πέντε έως επτά καλούνται ξανά· κάτω από πέντε τούς ευχαριστούν.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. Ποια ομάδα;

Οι ερμηνευτές κάτω των 13 είναι Juniors. Από 13 έως 15 είναι Middles. Δεκαέξι και πάνω, Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Πότε να ξανάρθουν

Οι Juniors καλούνται ξανά στις τέσσερις, οι Middles στις πέντε και όλοι οι υπόλοιποι στις έξι.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

Το όρισμα είναι το όνομα μιας ομάδας, γραμμένο ακριβώς όπως το γράφει η εργασία 2.

## 4. Τι να γράψεις στο φύλλο

Όποιος πήρε οκτώ ή παραπάνω και μπορεί να τραγουδήσει είναι `"Lead"`. Οκτώ ή παραπάνω χωρίς τραγούδι είναι `"Speaking part"`. Όλοι οι υπόλοιποι είναι `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
