# Προσθήκη στις οδηγίες

## Μέγιστη ακέραια τιμή

Σύμφωνα με [την τεκμηρίωση της PHP][php-int] υπάρχει μια μέγιστη ακέραια τιμή:

> Το μέγεθος ενός `int` εξαρτάται από την πλατφόρμα, αν και συνήθως η μέγιστη τιμή είναι περίπου δύο δισεκατομμύρια (δηλαδή 32 bit με πρόσημο).
> Οι πλατφόρμες 64 bit έχουν συνήθως μέγιστη τιμή περίπου 9E18.
> Η PHP δεν υποστηρίζει `int` χωρίς πρόσημο.

Με άλλα λόγια, η PHP δεν μπορεί να αναπαραστήσει ως ακέραιο κανέναν αριθμό `2^63` ή μεγαλύτερο.
Κάποια από τα τεστ αυτής της άσκησης απαιτούν ακέραιους 64 bit (`2^64`), που ξεπερνούν τον περιορισμό μεγέθους ακεραίων της PHP.

[Η PHP μετατρέπει αυτόματα][php-int-to-float] τα `int` σε `float`, όταν οι αριθμοί γίνουν πολύ μεγάλοι:

> Αν η PHP συναντήσει έναν αριθμό πέρα από τα όρια του τύπου `int`, θα τον ερμηνεύσει ως `float`.
> Επίσης, μια πράξη που έχει ως αποτέλεσμα έναν αριθμό πέρα από τα όρια του τύπου `int` θα επιστρέψει `float`.

Όμως ο τύπος `float` [έχει περιορισμένη ακρίβεια][php-float-precision].
Και ο Βασιλιάς μισεί την ανακρίβεια.
Έτσι, ο Βασιλιάς αποφάσισε να περιμένει τα αποτελέσματα των υπολογισμών ως συμβολοσειρά που εκφράζει την ακέραια τιμή, αντί να εκφράζει την απάντηση ως `int` ή `float`.
Και θέλει ακέραιους υπολογισμούς, όχι απλώς μια τεμπέλικη μετατροπή στο τέλος.

Μπορείς να το λύσεις αποφεύγοντας αριθμούς που είναι μεγαλύτεροι από ό,τι επιτρέπει άμεσα η γλώσσα;
Και σε παρακαλώ μη χρησιμοποιήσεις ούτε άλλες βιβλιοθήκες PHP όπως οι `gmp` ή `bc`.
