# Σχετικά

Η CoffeeScript είναι μια γλώσσα που μεταγλωττίζεται σε JavaScript και χρησιμοποιείται για τη δημιουργία δυναμικών ιστοσελίδων (τόσο στον περιηγητή ιστού όσο και στον διακομιστή).
Ο μεταγλωττιστής χρησιμοποιείται για να μετατρέπει τον κώδικα CoffeeScript σε JavaScript πριν από την εκτέλεση, ώστε να διατηρούνται η συμβατότητα και η ίδια απόδοση με τη JavaScript, ενώ παράλληλα προσφέρονται πολλές νέες δυνατότητες!

Η CoffeeScript δημιουργήθηκε για να προσφέρει έναν απλοποιημένο τρόπο γραφής JavaScript, βασισμένη σε έναν συνδυασμό των γλωσσών Ruby και Python.
Μια διαφορά είναι η χρήση της εσοχής και των βελών για την αντικατάσταση του πολύλογου κώδικα συναρτήσεων της JavaScript, καθώς και η εισαγωγή χρήσιμων δυνατοτήτων από συναρτησιακές γλώσσες, όπως η αντιστοίχιση προτύπων.

Η CoffeeScript είναι μία από τις πολλές νέες γλώσσες που μεταγλωττίζονται σε JavaScript, μαζί με τη TypeScript και τη Flow. Η κοινότητα μεγαλώνει και αυτού του είδους οι γλώσσες είναι πολύ δημοφιλείς.
