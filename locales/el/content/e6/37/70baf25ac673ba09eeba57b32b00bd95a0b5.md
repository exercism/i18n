# Εισαγωγή

Όταν μια παράθεση χρειάζεται να *θυμάται* τιμές από το περιβάλλον της,
το Factor προσφέρει δύο εργαλεία: το `curry`/`compose` από το [`kernel`][kernel],
και τη σύνταξη fry `'[ … ]` από το [`fry`][fry].

Το `curry` βάζει μία τιμή στην αρχή μιας παράθεσης:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

Το `compose` κολλάει δύο παραθέσεις μαζί:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Για περισσότερες από μία ή δύο συλλήψεις, το fry είναι πιο καθαρό. Κάθε σύμβολο
κράτησης θέσης `_` συμπληρώνεται, με τη σειρά, με μια τιμή που βγαίνει από τη στοίβα:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

Το fry φτάνει επίσης και μέσα σε εμφωλευμένες παραθέσεις.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
