# Πίνακες

Στην Cairo, ένας πίνακας είναι μια δομή δεδομένων που σου επιτρέπει να αποθηκεύεις μια συλλογή στοιχείων του ίδιου τύπου.
Οι πίνακες στην Cairo έχουν περιορισμένες δυνατότητες τροποποίησης.
Μπορείς μόνο να προσθέτεις στοιχεία στο τέλος ενός πίνακα και να αφαιρείς στοιχεία από την αρχή.
Οι πίνακες είναι, στην πραγματικότητα, ουρές των οποίων οι τιμές δεν μπορούν να τροποποιηθούν.

## Κατασκευή Πίνακα

Οι πίνακες κατασκευάζονται κυρίως χρησιμοποιώντας το trait `ArrayTrait`, με οποιονδήποτε από τους παρακάτω 4 τρόπους για να κατασκευάσεις έναν πίνακα στοιχείων `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Κάθε κλήση `append()` βάζει έναν νέο αριθμό στο τέλος του πίνακα.

## Αφαίρεση Στοιχείων από έναν Πίνακα

Ο μόνος τρόπος για να αφαιρέσεις στοιχεία από έναν πίνακα στην Cairo είναι από την αρχή.
Αυτή η λειτουργία πραγματοποιείται με τη μέθοδο `pop_front()`, η οποία επιστρέφει ένα `Option` που μπορεί να ξετυλιχθεί, περιέχοντας το στοιχείο που αφαιρέθηκε, ή `Option::None` αν ο πίνακας είναι κενός.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Πρόσβαση σε Τιμές ενός Πίνακα

Για να αποκτήσεις πρόσβαση στα στοιχεία ενός πίνακα, μπορείς να χρησιμοποιήσεις τις μεθόδους `get()` ή `at()` του πίνακα, οι οποίες επιστρέφουν διαφορετικούς τύπους.
Ισοδύναμο με το `arr.at(index)` είναι ο τελεστής με αγκύλες `arr[index]`.

### Χρήση της μεθόδου get()

Η μέθοδος `get()` είναι σαν να αναζητάς ένα στοιχείο σε μια λίστα με τον αριθμό του.
Να πώς λειτουργεί:

- Το `arr.get(index)` σου επιτρέπει να ανακτήσεις ένα στοιχείο σε μια συγκεκριμένη θέση του πίνακα.
- Επιστρέφει `Option::Some(value)` αν το στοιχείο στη δεδομένη θέση υπάρχει, ή `Option::None` αν η θέση είναι εκτός ορίων.

Αυτή η μέθοδος είναι ιδανική όταν θέλεις να χειριστείς περιπτώσεις όπου η θέση μπορεί να είναι άκυρη χωρίς να καταρρεύσει το πρόγραμμά σου.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Χρήση της μεθόδου at()

Η μέθοδος `at()` σου δίνει απευθείας ένα στιγμιότυπο του στοιχείου σε μια συγκεκριμένη θέση, χρησιμοποιώντας τη λειτουργία `unbox()` για να εξαγάγεις την αποθηκευμένη τιμή από το box.
Συντομογραφία αυτής της μεθόδου είναι η χρήση του τελεστή με αγκύλες `arr[index]`.
Αν προσπαθήσεις να αποκτήσεις πρόσβαση σε μια θέση που δεν υπάρχει (εκτός ορίων), το πρόγραμμα θα πανικοβληθεί με ένα σφάλμα.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Μέθοδοι που σχετίζονται με το μέγεθος

Για να προσδιορίσεις τον αριθμό των στοιχείων σε έναν πίνακα, χρησιμοποίησε τη μέθοδο `len()`.
Η τιμή επιστροφής είναι τύπου `usize`.

Αν θέλεις να ελέγξεις αν ένας πίνακας είναι κενός ή όχι, μπορείς να χρησιμοποιήσεις τη μέθοδο `is_empty()`, η οποία επιστρέφει `true` αν ο πίνακας είναι κενός και `false` διαφορετικά.

## `Span`

Το `Span` είναι ένα struct που αναπαριστά ένα στιγμιότυπο ενός `Array`.
Είναι σχεδιασμένο να παρέχει ασφαλή και ελεγχόμενη πρόσβαση στα στοιχεία ενός πίνακα χωρίς να τροποποιεί τον αρχικό πίνακα.
Το `Span` είναι ιδιαίτερα χρήσιμο για τη διασφάλιση της ακεραιότητας των δεδομένων και την αποφυγή προβλημάτων δανεισμού όταν περνάς πίνακες μεταξύ συναρτήσεων ή όταν εκτελείς λειτουργίες μόνο για ανάγνωση.

> Όλες οι μέθοδοι που παρέχονται από το `Array` μπορούν επίσης να χρησιμοποιηθούν με το `Span`, εκτός από τη μέθοδο `append()`.

Για να δημιουργήσεις ένα `Span` από έναν `Array`, κάλεσε τη μέθοδο `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## Ο τύπος `Array` σταθερού μεγέθους

Γράφουμε τις τιμές σε έναν πίνακα σταθερού μεγέθους ως μια λίστα χωρισμένη με κόμματα μέσα σε αγκύλες.
Ο τύπος του πίνακα γράφεται χρησιμοποιώντας αγκύλες με τον τύπο κάθε στοιχείου, ένα semicolon και μετά τον αριθμό των στοιχείων του πίνακα.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Σημείωση: μόνο πίνακες σταθερού μεγέθους μπορούν να χρησιμοποιηθούν ως σταθερές

Στα στοιχεία ενός πίνακα σταθερού μεγέθους μπορείς να αποκτήσεις πρόσβαση είτε αποδομώντας τον πίνακα είτε μετατρέποντάς τον σε `Span`, το οποίο υποστηρίζει πρόσβαση με θέση.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
