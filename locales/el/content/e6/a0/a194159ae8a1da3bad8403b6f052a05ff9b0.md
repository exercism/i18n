# Εισαγωγή

Οι λίστες στη C# είναι συλλογές από πρωτογενείς τιμές ή στιγμιότυπα δομών ή κλάσεων. Υλοποιούνται στη βιβλιοθήκη βασικών κλάσεων ως `List<T>`, όπου το `T` είναι ο τύπος του στοιχείου στη λίστα. Το API εκθέτει ένα πλούσιο σύνολο μεθόδων για τη δημιουργία και τον χειρισμό λιστών.

Στις λίστες μπορείς να προσθέτεις και να αφαιρείς στοιχεία. Μεγαλώνουν και μικραίνουν ανάλογα με τις ανάγκες.

```csharp
var listOfStrings = new List<string>();
```
