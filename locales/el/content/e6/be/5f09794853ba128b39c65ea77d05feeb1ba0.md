# Προσθήκη οδηγιών

Σε περίπτωση σφάλματος, επέστρεψε μια κενή συμβολοσειρά.

## Δεσμευμένες Διευθύνσεις

Ο buffer για τη συμβολοσειρά εισόδου χρησιμοποιεί τα byte 64-319 της γραμμικής μνήμης.

Μπορείς να τροποποιήσεις αυτόν τον buffer στη θέση του, αν θέλεις να αποφύγεις επιπλέον δεσμεύσεις μνήμης.
