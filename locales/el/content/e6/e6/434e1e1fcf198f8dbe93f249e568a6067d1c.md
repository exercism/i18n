# Υποδείξεις

## 1. Κάνε τη χρήση του `preparation-time-in-minutes` πιο εύκολη

- Μια "παράμετρος rest" θα συγκεντρώσει σε μια λίστα όλα τα ορίσματα που δεν έχουν καταναλωθεί από άλλες παραμέτρους.
- Μια "παράμετρος rest" δηλώνεται στη λίστα παραμέτρων lambda με τη λέξη-κλειδί `&rest` της λίστας παραμέτρων lambda.
- Μπορείς να χρησιμοποιήσεις τη συνάρτηση `length` για να πάρεις τον αριθμό των στοιχείων σε μια λίστα.

## 2. Επίτρεψε την αλλαγή του αναμενόμενου χρόνου ψησίματος

- Μια προαιρετική παράμετρος μπορεί να δοθεί ή όχι.
- Μια προαιρετική παράμετρος μπορεί να έχει προεπιλεγμένη τιμή.
- Οι προαιρετικές παράμετροι δηλώνονται με τη λέξη-κλειδί `&optional` της λίστας παραμέτρων lambda.

## 3. Η Lilly θυμάται άλλον έναν προτιμώμενο τρόπο μαγειρέματος

- Μπορείς να ορίσεις μια "παράμετρο supplied-p" μαζί με την προαιρετική παράμετρο, για να προσδιορίσεις αν ο καλών έχει δώσει την παράμετρο.

## 4. Μοιράζοντας τα περισσεύματα

- Οι παράμετροι-κλειδιά έχουν όνομα και είναι προαιρετικές.
- Οι παράμετροι-κλειδιά δηλώνονται με τη λέξη-κλειδί `&key` της λίστας παραμέτρων lambda.

## 5. Κάνοντας υποθέσεις

- Οι παράμετροι-κλειδιά μπορούν να έχουν προεπιλεγμένες τιμές.

## 6. Τυπική ποσότητα περισσευμάτων

- Οι παράμετροι-κλειδιά μπορούν να έχουν μια "παράμετρο supplied-p", όπως οι προαιρετικές παράμετροι.
