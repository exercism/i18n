# Προσάρτημα οδηγιών

## Τελεστές ρητών αριθμών

Οι αριθμητικές συναρτήσεις υποστηρίζουν κανονικές κλήσεις συναρτήσεων, στατική αποστολή (δηλαδή σύνταξη κλήσης μεθόδου) και τελεστές:

| Κλήση συνάρτησης | Κλήση μεθόδου | Τελεστής |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

Υλοποίησε τη `reduce` ώστε να ανάγει έναν ρητό αριθμό στους ελάχιστους όρους του, για παράδειγμα από `6 / 8` σε `3 / 4`.
