# Οδηγίες

Σε αυτή την άσκηση, πρέπει να μετατρέψεις κάποιους κανόνες από το κλασικό παιχνίδι Pac-Man σε συναρτήσεις Gleam.

Έχεις τέσσερις κανόνες να μετατρέψεις, όλοι σχετικοί με τις καταστάσεις του παιχνιδιού.

> Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, απλώς επικεντρώσου στον συνδυασμό των ορισμάτων για να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `eat_ghost` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή Boolean (λογική τιμή) αν ο Pac-Man μπορεί να φάει το φάντασμα. Η συνάρτηση θα πρέπει να επιστρέφει `True` μόνο αν ο Pac-Man έχει ενεργό χάπι δύναμης και αγγίζει ένα φάντασμα.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `score` που παίρνει δύο ορίσματα (_αν ο Pac-Man αγγίζει ένα χάπι δύναμης_ και _αν ο Pac-Man αγγίζει μια κουκκίδα_) και επιστρέφει μια τιμή Boolean αν ο Pac-Man σκόραρε. Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα χάπι δύναμης ή μια κουκκίδα.

```gleam
score(True, True)
// -> True
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `lose` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή Boolean αν ο Pac-Man χάνει. Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό χάπι δύναμης.

```gleam
lose(False, True)
// -> True
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `win` που παίρνει τρία ορίσματα (_αν ο Pac-Man έχει φάει όλες τις κουκκίδες_, _αν ο Pac-Man έχει ενεργό χάπι δύναμης_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή Boolean αν ο Pac-Man κερδίζει. Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man έχει φάει όλες τις κουκκίδες και δεν έχει χάσει με βάση τα ορίσματα που ορίζονται στο μέρος 3.

```gleam
win(False, True, False)
// -> False
```
