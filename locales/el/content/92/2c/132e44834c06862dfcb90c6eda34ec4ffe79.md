# Σχετικά

Τα στιγμιότυπα των struct και των κλάσεων έχουν το καθένα μια σιωπηρή τιμή με το όνομα `self`, η οποία αναφέρεται στο ίδιο το στιγμιότυπο. Υπάρχουν πολλές χρήσεις για το `self`, αλλά η πιο συνηθισμένη είναι να ξεκαθαρίζει τα ονόματα των ιδιοτήτων και των μεθόδων του struct ή της κλάσης όταν μπορεί να προκύψει σύγχυση.

```swift
struct MySelf {
  var x = 0

  mutating func move(x: Int) {
    // here if we just say x = x it is unclear if we mean
    // the property x or the method parameter x, so we use
    // self for clarity
    self.x = x
  }
}
```

Τα struct και οι κλάσεις έχουν επίσης μια τιμή `Self`, η οποία αναφέρεται στον τύπο του struct ή της κλάσης και όχι στο στιγμιότυπο του struct ή της κλάσης.
