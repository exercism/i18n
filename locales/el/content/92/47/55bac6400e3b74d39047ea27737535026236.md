# Οδηγίες

Ένα νέο κλαμπ ποίησης άνοιξε στην πόλη και σκέφτεσαι να το επισκεφτείς.
Επειδή έχουν συμβεί περιστατικά στο παρελθόν, το κλαμπ έχει μια πολύ συγκεκριμένη πολιτική στην πόρτα, την οποία θα πρέπει να μάθεις καλά πριν επιχειρήσεις να μπεις.

Υπάρχουν δύο πόρτες στο κλαμπ ποίησης και οι δύο είναι φυλασσόμενες.
Για να μπεις, θα πρέπει να βρεις τον κωδικό της ημέρας:

## 1. Χώρισε μια συμβολοσειρά σε ξεχωριστές γραμμές

Το πρώτο πράγμα που πρέπει να κάνεις είναι να χωρίσεις το ποίημα σε ξεχωριστές γραμμές.
Ο φρουρός θα απαγγείλει ένα ποίημα και εσύ θα πρέπει να το χωρίσεις σε γραμμές.

Υλοποίησε τη συνάρτηση `splitOnNewlines` που παίρνει μια συμβολοσειρά και τη χωρίζει σε έναν πίνακα συμβολοσειρών, χρησιμοποιώντας τον χαρακτήρα αλλαγής γραμμής ως διαχωριστικό.
Η συνάρτηση θα πρέπει να επιστρέφει έναν πίνακα συμβολοσειρών, όπου κάθε συμβολοσειρά είναι μια γραμμή του ποιήματος.

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. Μπροστινή πόρτα

1. Ο φρουρός θα απαγγείλει ένα ποίημα
2. Θα πρέπει να χωρίσεις το ποίημα σε ξεχωριστές γραμμές.
3. Θα πρέπει να πάρεις το πρώτο γράμμα κάθε γραμμής.
   - Αν η γραμμή είναι κενή, θα πρέπει να χρησιμοποιήσεις το `_` αντ' αυτού.
4. Θα πρέπει να ενώσεις τα γράμματα, τα οποία θα σχηματίσουν μια λέξη.

Για παράδειγμα, ένας από τους αγαπημένους τους συγγραφείς είναι ο Michael Lockwood, ο οποίος έχει γράψει το παρακάτω _ακροστιχικό_ ποίημα, που σημαίνει ότι το πρώτο γράμμα κάθε στίχου σχηματίζει μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φρουρός απαγγείλει το ποίημα, θα το χωρίσεις σε ξεχωριστές γραμμές και θα απαντήσεις με τα πρώτα γράμματα κάθε γραμμής, δηλαδή `["S", "H", "I", "R", "E"]`.

Στη συνέχεια, ο φρουρός θα σου δώσει τη λέξη που σχηματίζεται από τον πίνακα γραμμάτων με τον οποίο απάντησες, για να τη μετατρέψεις σε μορφή με κεφαλαίο πρώτο γράμμα.
Τελικά, ο κωδικός που θα επιστρέψεις είναι `"SHIRE"` και θα μπεις μέσα.

Υλοποίησε τη συνάρτηση `frontDoorPassword` που παίρνει μια συμβολοσειρά που αντιπροσωπεύει το ποίημα.
Η συνάρτηση θα πρέπει να επιστρέφει τον κωδικό που θα έδινες στον φρουρό.

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. Πίσω πόρτα

Στο πίσω μέρος του κλαμπ θα βρεις τους πιο διάσημους ποιητές, κάτι σαν την περιοχή VIP.
Επειδή αυτό δεν είναι για όλους, η διαδικασία της πίσω πόρτας είναι λίγο πιο περίπλοκη.

1. Ο φρουρός θα απαγγείλει ένα ποίημα.
2. Θα πρέπει να χωρίσεις το ποίημα σε γραμμές.
3. Θα πρέπει να πάρεις το τελευταίο γράμμα κάθε γραμμής.
   - Μερικές φορές η γραμμή θα έχει κενά στο τέλος, οπότε θα πρέπει να τα αφαιρέσεις.
4. Θα πρέπει να συναρμολογήσεις τα γράμματα και μετά να προσθέσεις το `", please"` στο τέλος της λέξης που σχηματίζουν τα γράμματα.

Για παράδειγμα, το ποίημα που αναφέρθηκε προηγουμένως είναι επίσης _τελεστιχικό_, που σημαίνει ότι το τελευταίο γράμμα κάθε στίχου σχηματίζει μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φρουρός απαγγείλει το ποίημα, θα το χωρίσεις σε ξεχωριστές γραμμές, θα αφαιρέσεις τυχόν κενά στο τέλος και θα απαντήσεις με τα τελευταία γράμματα κάθε γραμμής, δηλαδή `["h", "o", "r", "s", "e"]`.

Στη συνέχεια, ο φρουρός θα σου δώσει τη λέξη που σχηματίζεται από τον πίνακα γραμμάτων με τον οποίο απάντησες, για να τη μετατρέψεις σε μορφή με κεφαλαίο πρώτο γράμμα και να προσθέσεις στο τέλος το `", please"`.
Τελικά, ο κωδικός που θα επιστρέψεις είναι `"horse, please"` και θα μπεις μέσα.

Υλοποίησε τη συνάρτηση `backDoorPassword` που παίρνει μια συμβολοσειρά που αντιπροσωπεύει το ποίημα.
Η συνάρτηση θα πρέπει να επιστρέφει τον κωδικό που θα έδινες στον φρουρό.

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. Μυστικό δωμάτιο

Μέσα στο πίσω δωμάτιο του κλαμπ υπάρχει άλλη μια πόρτα που οδηγεί στο μυστικό δωμάτιο, στο οποίο μπορούν να μπουν μόνο οι κορυφαίοι ποιητές.

1. Ο φρουρός θα απαγγείλει ένα ποίημα.
2. Θα πρέπει να χωρίσεις το ποίημα σε γραμμές.
3. Θα πρέπει να πάρεις το i<sup>th</sup> γράμμα της i<sup>th</sup> γραμμής. 
4. Θα πρέπει να συναρμολογήσεις τα γράμματα και μετά να προσθέσεις το `"!"` στο τέλος της λέξης που σχηματίζουν τα γράμματα.
5. Θα πρέπει να βάλεις τη λέξη σε μορφή με κεφαλαία γράμματα.

Για παράδειγμα, μια τροποποιημένη εκδοχή του ποιήματος που αναφέρθηκε προηγουμένως ταιριάζει με αυτό το μοτίβο:

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

Όταν ο φρουρός απαγγείλει το ποίημα, θα το χωρίσεις σε ξεχωριστές γραμμές, θα αφαιρέσεις τυχόν κενά στο τέλος και θα απαντήσεις με τα i<sup>th</sup> γράμματα κάθε γραμμής, δηλαδή ["S", "u", "p", "e", "r"].

Στη συνέχεια, ο φρουρός θα σου δώσει τη λέξη που σχηματίζεται από τον πίνακα γραμμάτων με τον οποίο απάντησες, για να τη βάλεις σε μορφή με κεφαλαία γράμματα και να προσθέσεις στο τέλος το `"!"`.
Τελικά, ο κωδικός που θα επιστρέψεις είναι `SUPER!` και θα μπεις μέσα.

Υλοποίησε τη συνάρτηση `secretRoomPassword` που παίρνει μια συμβολοσειρά που αντιπροσωπεύει το ποίημα.
Η συνάρτηση θα πρέπει να επιστρέφει τον κωδικό που θα έδινες στον φρουρό.

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
