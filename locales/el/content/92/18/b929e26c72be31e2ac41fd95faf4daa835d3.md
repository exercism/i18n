# Οδηγίες

Δουλεύεις και πάλι πάνω στο σύστημα ORM (Object Relationship Mapping) που παρουσιάστηκε στο [exercise:csharp/object-relational-mapping]().

Η ανάλυση της χρήσης του ORM δείχνει ότι το 95% των συναλλαγών εκτελείται μέσα από μία μόνο μέθοδο, και αποφασίστηκε ότι θα ήταν πιο σωστό να υπάρχει μία μόνο μέθοδος του ORM που να ανοίγει, να γράφει και να ολοκληρώνει μια συναλλαγή.

Η βάση δεδομένων έχει τις εξής μεθόδους στιγμιοτύπου:

- Η `Database.BeginTransaction()` ξεκινά μια συναλλαγή στη βάση δεδομένων.
- Η `Database.Write(string data)` γράφει δεδομένα στη βάση δεδομένων μέσα στη συναλλαγή. Αν λάβει εσφαλμένα δεδομένα, πετάει μια εξαίρεση. Αν προσπαθήσεις να καλέσεις αυτή τη μέθοδο χωρίς να έχει κληθεί πρώτα η `BeginTransaction()`, θα πεταχτεί μια εξαίρεση. Αν πετύχει, η εσωτερική κατάσταση της βάσης δεδομένων αλλάζει σε `DataWritten`.
- Η `Database.EndTransaction()` ολοκληρώνει τη συναλλαγή στη βάση δεδομένων. Μπορεί να πετάξει μια εξαίρεση αν δεν μπορεί να κλείσει τη συναλλαγή ή αν δεν έχει κληθεί η `Database.BeginTransaction()`.
- Μια κλήση στη `Database.Dispose()` καθαρίζει τη βάση δεδομένων αν πεταχτεί κάποια εξαίρεση στη διάρκεια μιας συναλλαγής. Αυτό αλλάζει την κατάσταση της βάσης δεδομένων σε `Closed`.

## 1. Γράψε στη βάση δεδομένων

Υλοποίησε τη μέθοδο `Orm.Write()` ώστε να ξεκινά μια συναλλαγή στη βάση δεδομένων, να γράφει τα δεδομένα που της περνάς και να ολοκληρώνει τη συναλλαγή. Όλες οι εξαιρέσεις, συμπεριλαμβανομένης της `InvalidOperationException`, πρέπει να περνούν στον καλούντα χωρίς να καταγραφούν ή να υπάρξει οποιαδήποτε άλλη παρέμβαση.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. Γράψε στη βάση δεδομένων και επέστρεψε στον καλούντα μια ένδειξη για το αν η εγγραφή πέτυχε

Έχουν περάσει μερικοί μήνες από τότε που παρουσιάστηκε η `Orm.Write()` και υπάρχει διχογνωμία στην ομάδα. Πολλοί προγραμματιστές θα ήθελαν το _ORM_ να χειρίζεται τα σφάλματα όταν πετιούνται εξαιρέσεις και απλώς να επιστρέφει στον καλούντα μια ένδειξη επιτυχίας.

Υλοποίησε τη μέθοδο `Orm.WriteSafely()` ώστε να ξεκινά μια συναλλαγή στη βάση δεδομένων, να γράφει τα δεδομένα που της περνάς και να ολοκληρώνει τη συναλλαγή (όπως παραπάνω). Πρέπει να επιστρέφει `true` αν η _εγγραφή_ πέτυχε, αλλιώς `false`. Μην προσπαθήσεις να καταγράψεις την εξαίρεση.

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
