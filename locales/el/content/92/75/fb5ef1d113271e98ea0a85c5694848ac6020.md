# Τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την εντολή `v test .` μέσα από τον κατάλογο της άσκησης.

Αν θέλεις να δεις όλα τα τεστ που έτρεξαν μαζί με στατιστικά για την ταχύτητα, χρησιμοποίησε `v -stats test .`

Για περισσότερες πληροφορίες σχετικά με τα τεστ στη V, δες [την τεκμηρίωση](https://github.com/vlang/v/blob/master/doc/docs.md#testing).
