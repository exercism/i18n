# Σχετικά

Στη Go, μια εφαρμογή οργανώνεται σε πακέτα.
Ένα πακέτο είναι μια συλλογή από αρχεία πηγαίου κώδικα που βρίσκονται στον ίδιο φάκελο.
Όλα τα αρχεία πηγαίου κώδικα σε έναν φάκελο πρέπει να έχουν το ίδιο όνομα πακέτου στην αρχή του αρχείου.
Κατά σύμβαση, τα πακέτα ονομάζονται όπως ο φάκελος στον οποίο βρίσκονται.

```go
package greeting
```

Η Go παρέχει μια εκτενή πρότυπη βιβλιοθήκη από πακέτα που μπορείς να χρησιμοποιήσεις στο πρόγραμμά σου με τη λέξη-κλειδί `import`.
Τα πακέτα της πρότυπης βιβλιοθήκης εισάγονται με το όνομά τους.

```go
package greeting

import "fmt"
```

Μπορείς να εισάγεις πολλά πακέτα ταυτόχρονα, γράφοντάς τα μέσα σε παρενθέσεις.

```go
package greeting

import (
    "errors"
    "fmt"
)
```

Τα πακέτα τρίτων εισάγονται με τη διεύθυνση URL της τοποθεσίας του πακέτου.
Μπορείς να δώσεις ένα ψευδώνυμο σε ένα πακέτο κατά την εισαγωγή.
Αυτό μπορεί να χρησιμοποιηθεί για να αποφύγεις συγκρούσεις ονομάτων πακέτων:

```go
package greeting

import (
	"errors"

	errs "github.com/pkg/errors"
)
```

Στη συνέχεια, αναφέρεσαι σε ένα εισαγμένο πακέτο με το όνομα ή το ψευδώνυμό του:

```go
// using the internal errors package
errors.New("Connection not established")

// using the errors package located at github.com/pkg/errors by alias
errs.New("Connection not established")
```

Η Go καθορίζει αν ένα στοιχείο μπορεί να κληθεί από κώδικα σε άλλα πακέτα με βάση τον τρόπο που δηλώνεται.
Για να κάνεις μια συνάρτηση, έναν τύπο, μια μεταβλητή ή μια σταθερά ορατά εξωτερικά (γνωστό ως [`exported`](https://golang.org/ref/spec#Exported_identifiers)), το όνομα πρέπει να ξεκινά με κεφαλαίο γράμμα.
Αυτό είναι ανάλογο με το πώς άλλες γλώσσες προγραμματισμού, όπως η Java, χρησιμοποιούν τροποποιητές πρόσβασης όπως τα `public` και `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

Το ίδιο ισχύει και για τα ονόματα πεδίων σε προσαρμοσμένους τύπους `struct`: τα ονόματα πεδίων που ξεκινούν με κεφαλαίο γράμμα είναι ορατά εξωτερικά, ενώ εκείνα που ξεκινούν με πεζό δεν είναι.
