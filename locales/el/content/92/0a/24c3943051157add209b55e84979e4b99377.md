# Οδηγίες

Σε αυτή την άσκηση θα βοηθήσεις στη διαχείριση των καθημερινών λειτουργιών ενός μικρού αρτοποιείου, χρησιμοποιώντας τις δομές ελέγχου ροής στη Cairo.

## 1. Υπολόγισε το σύνολο της παραγγελίας

Υλοποίησε τη συνάρτηση `calculate_total` που υπολογίζει το κόστος μιας παραγγελίας με βάση τον τύπο του γλυκίσματος και την ποσότητα:

- Croissant: 3 νομίσματα το καθένα
- Muffin: 2 νομίσματα το καθένα
- Cookie: 1 νόμισμα το καθένα

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Εφάρμοσε εκπτώσεις όγκου

Υλοποίησε τη συνάρτηση `apply_discount` που εφαρμόζει εκπτώσεις με βάση το σύνολο της παραγγελίας.
Εφάρμοσε την ποσοστιαία έκπτωση στο σύνολο και μετά στρογγυλοποίησε προς τα κάτω στον πλησιέστερο ακέραιο αριθμό νομισμάτων (floor).

- Παραγγελίες ≥ 20 νομίσματα: έκπτωση 10%
- Παραγγελίες ≥ 10 νομίσματα: έκπτωση 5%
- Παραγγελίες < 10 νομίσματα: χωρίς έκπτωση

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Δημιούργησε πρόγραμμα ψησίματος

Υλοποίησε τη συνάρτηση `baking_schedule` που δημιουργεί ένα καθημερινό πρόγραμμα ψησίματος.
Το αρτοποιείο ψήνει σε παρτίδες των 5 παραγγελιών την ώρα:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Χρησιμοποίησε κατάλληλες δομές ελέγχου ροής (`if`/`else`, `loop`) για να λύσεις κάθε πρόβλημα αποτελεσματικά.
