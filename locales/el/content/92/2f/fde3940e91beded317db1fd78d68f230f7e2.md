# Οδηγίες

Βρίσκεσαι στο ραδιοπαράπηγμα της ακτής και παρακολουθείς τη "φασαρία" του καναλιού: τα μηνύματα φτάνουν στο καλώδιο, τα καταγράφεις και στέλνεις απαντήσεις πίσω. Πέντε μικρές λέξεις αρκούν για τη δουλειά μιας βάρδιας.

Τα τεστ σου περνούν εισόδους `<string-reader>` (κίνηση που έρχεται) και χρησιμοποιούν `<string-writer>` για την εξερχόμενη, αλλά κάθε λέξη εδώ δουλεύει με τον ίδιο τρόπο με ένα πραγματικό `<file-reader>` ή socket.

## 1. Άκουσέ τα όλα

Όρισε το `hear-out` ώστε να καταναλώνει μια ροή εισόδου και να τη συγκεντρώνει σε μία συμβολοσειρά.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Μέτρησε τα μηνύματα

Όρισε το `count-messages` ώστε να διαβάζει κάθε γραμμή από μια ροή εισόδου και να επιστρέφει πόσες ήταν.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Επανάλαβε την τελευταία κλήση

Όρισε το `echo-back` ώστε να διαβάζει κάθε γραμμή και να επιστρέφει **την τελευταία σε κεφαλαία**, την τυπική απάντηση του ασυρμάτου "είπες X".

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Μετάδωσε ένα μήνυμα

Όρισε το `broadcast` ώστε να γράφει ένα μήνυμα σε μια δοσμένη ροή εξόδου και να κάνει flush σε αυτήν, ώστε να σταλεί αμέσως. Δεν επιστρέφει τίποτα.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Κατέγραψε την έξοδο μιας παράθεσης

Όρισε το `capture` ώστε να εκτελεί μια παράθεση με έναν νέο string-writer ως την τρέχουσα ροή εξόδου και να επιστρέφει ό,τι τύπωσε η παράθεση. Η παράθεση δεν παίρνει κανένα όρισμα, απλώς γράφει στην τρέχουσα ροή, όπως συνήθως.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
