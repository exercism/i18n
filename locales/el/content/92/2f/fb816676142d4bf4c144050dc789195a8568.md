# Ο τύπος Boolean

Στο Cairo, ο τύπος Boolean (λογική τιμή) είναι απαραίτητος για λογικές πράξεις και εντολές υπό συνθήκη. Οι τιμές Boolean στο Cairo έχουν μέγεθος ενός `felt252`, εξασφαλίζοντας αποδοτική χρήση του χώρου και διατηρώντας ταυτόχρονα την απλότητα της λογικής του αληθούς και του ψευδούς.

Ο τύπος Boolean στο Cairo δηλώνεται με τη λέξη-κλειδί `bool`. Αυτό επιτρέπει τη δήλωση και τον χειρισμό μεταβλητών Boolean στη γλώσσα. Για παράδειγμα, δες το παρακάτω παράδειγμα:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

Σε αυτό το παράδειγμα δηλώνονται δύο μεταβλητές Boolean. Στη μεταβλητή `t` εκχωρείται η τιμή `true` και δηλώνεται έμμεσα ως Boolean, ενώ η μεταβλητή `f` χαρακτηρίζεται ρητά με τον τύπο `bool` και της εκχωρείται η τιμή `false`.

Ένα σημαντικό σημείο που πρέπει να προσέξεις είναι ότι, όταν δηλώνεις μια μεταβλητή Boolean στο Cairo, είναι υποχρεωτικό να χρησιμοποιήσεις ως τιμή ένα από τα literal `true` ή `false`. Αυτό σημαίνει ότι ακέραια literal, όπως το `0` ή το `1`, δε μπορούν να χρησιμοποιηθούν στη θέση του `false` ή του `true`. Η αυστηρή εφαρμογή αυτού του κανόνα εξασφαλίζει την ασφάλεια τύπων και αποτρέπει πιθανά λογικά σφάλματα στην ανάπτυξη smart contracts.

## Τελεστές Boolean στο Cairo

- `||` (λογικό OR): Επιστρέφει `true` αν τουλάχιστον ένας από τους τελεστέους είναι `true`.
- `&&` (λογικό AND): Επιστρέφει `true` αν και οι δύο τελεστέοι είναι `true`.
- `!` (λογικό NOT): Επιστρέφει την αντίθετη τιμή Boolean του τελεστέου.

## Παράδειγμα κώδικα

Το παρακάτω απόσπασμα κώδικα δείχνει πώς να χρησιμοποιείς τον τύπο Boolean στο Cairo. Δείχνει τη δήλωση μεταβλητών Boolean, την εκχώρηση Boolean εκφράσεων και τη χρήση assertions για την επαλήθευση της ορθότητας της λογικής Boolean:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
