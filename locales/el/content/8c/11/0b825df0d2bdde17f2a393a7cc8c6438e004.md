# Εισαγωγή στις εντολές και τα ορίσματα

Αυτή η διαδρομή δεν αφορά το πώς να χρησιμοποιείς το bash ως διαδραστικό κέλυφος.
Αφορά την εκμάθηση του πώς να γράφεις προγράμματα με το bash, τη γλώσσα προγραμματισμού.

Ένα πρόγραμμα bash, ή _σενάριο_, είναι μια ακολουθία εντολών αποθηκευμένη σε ένα αρχείο.
Το bash (το εκτελέσιμο αρχείο) διαβάζει το αρχείο και εκτελεί τις εντολές με τη σειρά.

## Το shebang

Η πρώτη γραμμή ενός σεναρίου είναι συνήθως μια _οδηγία διερμηνευτή_, γνωστή και ως _hashbang_ ή _shebang_:

```bash
#!/usr/bin/env bash
```

Όταν το λειτουργικό σύστημα εκτελεί ένα μη δυαδικό αρχείο, διαβάζει την πρώτη γραμμή.
Αν η γραμμή ξεκινά με `#!`, ο πυρήνας τη χρησιμοποιεί για να καθορίσει ποιος διερμηνευτής θα εκτελέσει το αρχείο.
Το `#!` πρέπει να βρίσκεται στην αρχή ακριβώς του αρχείου, χωρίς κενά ή κενές γραμμές πριν από αυτό.

Εδώ, το `env` ψάχνει στο `PATH` το εκτελέσιμο `bash`.
Μπορεί επίσης να δεις το απλούστερο `#!/bin/bash`, το οποίο έχει καρφωτή τη θέση του διερμηνευτή· η μορφή με το `env` είναι πιο φορητή.

~~~~exercism/note
Μην ξεγελαστείς από σενάρια ή παραδείγματα στο διαδίκτυο που χρησιμοποιούν το `/bin/sh` ως διερμηνευτή.
**Το `sh` δεν είναι `bash`!**
Το bash είναι "συμβατό με το sh" και μπορεί να εκτελέσει τα περισσότερα σενάρια `sh`, αλλά ορισμένα χαρακτηριστικά του bash θα σπάσουν ή θα συμπεριφερθούν απροσδόκητα στο `sh`.
~~~~

## Σχόλια

Μια γραμμή που ξεκινά με `#` είναι ένα _σχόλιο_ και το bash την αγνοεί.
Ένα σχόλιο μπορεί επίσης να ακολουθεί μια εντολή στην ίδια γραμμή: ό,τι βρίσκεται από το `#` μέχρι το τέλος της γραμμής αγνοείται.
Τα σχόλια υπάρχουν για τους ανθρώπους που διαβάζουν το σενάριο.

## Λέξεις και ορίσματα

Το Bash διαβάζει εντολές από την είσοδό του (η οποία είναι συνήθως είτε ένα τερματικό είτε ένα αρχείο).
Κάθε γραμμή εισόδου που διαβάζει αντιμετωπίζεται ως _εντολή_, δηλαδή μια οδηγία που πρέπει να εκτελεστεί.
(Υπάρχουν μερικές προχωρημένες περιπτώσεις, όπως εντολές που εκτείνονται σε πολλές γραμμές, οι οποίες θα συζητηθούν αργότερα.)

Το Bash χωρίζει κάθε εντολή σε **λέξεις** που ορίζονται από χαρακτήρες κενού διαστήματος (κενά και στηλοθέτες).
Η πρώτη λέξη είναι το όνομα της _εντολής_ που θα εκτελεστεί.
Όλες οι υπόλοιπες λέξεις γίνονται _ορίσματα_ αυτής της εντολής (επιλογές, ονόματα αρχείων κ.λπ.).

Μια εντολή μπορεί να είναι μια _ενσωματωμένη εντολή_ του bash, όπως η `echo`, ή ένα _εκτελέσιμο_ πρόγραμμα, όπως τα `head`, `awk` ή `sed`.

## Η εντολή `echo`

Η `echo` εκτυπώνει τα ορίσματά της, χωρισμένα με ένα κενό διάστημα, και τελειώνει με μια αλλαγή γραμμής:

```bash
echo flour sugar eggs
```

εμφανίζει:

```text
flour sugar eggs
```

Το πλήθος των κενών ανάμεσα στα ορίσματα δεν έχει σημασία:

```bash
echo flour       sugar        eggs
```

```text
flour sugar eggs
```

Αν καλέσεις την `echo` χωρίς κανένα όρισμα, εκτυπώνει μια κενή γραμμή.

## Οι επιλογές είναι απλώς ορίσματα

Πολλές εντολές δέχονται _επιλογές_ που αλλάζουν τον τρόπο που συμπεριφέρονται.
Για το bash, μια επιλογή δεν έχει τίποτα το ιδιαίτερο: είναι μια λέξη όπως οποιαδήποτε άλλη, χωρισμένη από τις γειτονικές της με κενό διάστημα.
Η ίδια η εντολή αποφασίζει πώς θα ερμηνεύσει τα ορίσματά της.
Κατά σύμβαση, οι επιλογές ξεκινούν με `-`.

Η εντολή `head` εκτυπώνει τις πρώτες γραμμές ενός αρχείου.
Δεδομένου ενός αρχείου `list.txt`:

```bash
head -n 2 list.txt
```

Το bash χωρίζει αυτή τη γραμμή σε τέσσερις λέξεις:

| Λέξη       | Ρόλος                                       |
| ---------- | ------------------------------------------- |
| `head`     | η εντολή που θα εκτελεστεί                  |
| `-n`       | μια επιλογή, που λέει στην `head` να μετρήσει _γραμμές_ |
| `2`        | η τιμή για την επιλογή `-n`                 |
| `list.txt` | το αρχείο που θα διαβαστεί                  |

Το bash περνά τις τρεις τελευταίες λέξεις στην `head` χωρίς αλλαγή.
Είναι η `head` που καταλαβαίνει ότι μετά το `-n` ακολουθεί ένας αριθμός και ότι η υπόλοιπη λέξη είναι ένα αρχείο.

Επειδή το κενό διάστημα είναι αυτό που χωρίζει τις λέξεις, έχει σημασία πού το βάζεις.
Το `head -n 2` δίνει στην `head` δύο ορίσματα (το `-n` και το `2`), ενώ το `head -n2` της δίνει ένα (το `-n2`).
Πολλές εντολές δέχονται και τις δύο μορφές, αλλά αυτό εξαρτάται από την εντολή.
Το bash δεν νοιάζεται· χωρίζει μόνο τη γραμμή σε λέξεις.

## Ορίσματα σε εισαγωγικά

Τα [εισαγωγικά][Quotes] ομαδοποιούν λέξεις σε ένα _μοναδικό όρισμα_.
Τα κενά μέσα στα εισαγωγικά διατηρούνται και οι ίδιοι οι χαρακτήρες των εισαγωγικών δεν αποτελούν μέρος του ορίσματος:

```bash
echo "flour       sugar        eggs"
```

```text
flour       sugar        eggs
```

Αν ένα όρισμα, όπως ένα όνομα αρχείου, περιέχει κενά, βάλε το σε εισαγωγικά:

```bash
head -n 1 my shopping list.txt     # three files: "my", "shopping", "list.txt"
head -n 1 "my shopping list.txt"   # one file
```

## Εκτέλεση σεναρίου

Για να εκτελέσεις ένα σενάριο, πέρασέ το ως όρισμα στην εντολή `bash`:

```bash
bash myscript
```

Όταν το χρησιμοποιείς έτσι, η γραμμή `#!` είναι απλώς ένα σχόλιο.
Λες στο λειτουργικό σύστημα πώς να εκτελέσει το αρχείο.

Εναλλακτικά, σημείωσε το αρχείο σεναρίου ως εκτελέσιμο και εκτέλεσέ το όπως οποιοδήποτε άλλο πρόγραμμα:

```bash
chmod +x myscript
./myscript
```

Τώρα το λειτουργικό σύστημα χρησιμοποιεί τη γραμμή `#!` για να καθορίσει ποιον διερμηνευτή θα χρησιμοποιήσει.
