# Μέθοδοι πινάκων

Οι πίνακες είναι μια συνηθισμένη δομή δεδομένων με την οποία δουλεύουμε.
Γι' αυτό υπάρχει μια συλλογή μεθόδων που μπορείς να χρησιμοποιήσεις για να δουλέψεις με πίνακες.
Περιλαμβάνει ταξινόμηση, αντιστροφή, εισαγωγή και πολλά άλλα.

Κάποιες από αυτές τις μεθόδους είναι καταστροφικές, που σημαίνει ότι τροποποιούν τον αρχικό πίνακα.
Άλλες είναι μη καταστροφικές, δηλαδή επιστρέφουν έναν νέο πίνακα και δεν τροποποιούν τον αρχικό.

Ορίστε μερικές από τις πιο συνηθισμένες μεθόδους που μπορείς να χρησιμοποιήσεις όταν δουλεύεις με πίνακες:

## insert

Όταν εισάγεις ένα στοιχείο σε έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`insert`][insert], η οποία παίρνει ως ορίσματα μια θέση και ένα στοιχείο.
Το στοιχείο θα εισαχθεί στη θέση που όρισες και το υπόλοιπο του πίνακα θα μετακινηθεί προς τα δεξιά.
Αν η θέση είναι εκτός ορίων, τότε θα πεταχτεί ένα `IndexError`.

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

Όταν θέλεις να διαγράψεις ένα συγκεκριμένο στοιχείο από έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`delete`][delete], η οποία παίρνει ως όρισμα ένα στοιχείο.
Η μέθοδος επιστρέφει το στοιχείο που αφαιρέθηκε.
Αν το στοιχείο δεν υπάρχει στον πίνακα, τότε θα επιστραφεί `nil`.

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

Όταν θέλεις να πάρεις το πρώτο ή το τελευταίο στοιχείο ενός πίνακα, μπορείς να χρησιμοποιήσεις τις μεθόδους [`first`][first] και [`last`][last].
Αυτές οι μέθοδοι παίρνουν ένα προαιρετικό όρισμα που καθορίζει πόσα στοιχεία θα επιστραφούν.
Μπορούν να βελτιώσουν την αναγνωσιμότητα σε σύγκριση με τη χρήση της θέσης `0` ή `-1`, ή τη χρήση ενός εύρους.
Αν ο πίνακας είναι κενός, θα πεταχτεί ένα `Enumerable::EmptyError`.

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

Όταν θέλεις να αντιστρέψεις έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`reverse`][reverse], η οποία επιστρέφει έναν νέο πίνακα με τα στοιχεία σε αντίστροφη σειρά.
Είναι σημαντικό να σημειώσεις ότι η `reverse` επιστρέφει έναν νέο πίνακα και δεν τροποποιεί τον αρχικό πίνακα.
Αν θέλεις να τροποποιήσεις τον αρχικό πίνακα, πρόσθεσε ένα `!` στο τέλος του ονόματος της μεθόδου.

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

Η μέθοδος append (`<<`) είναι χρήσιμη όταν θέλεις να προσθέσεις αντικείμενα σε έναν πίνακα.
Ωστόσο, όταν συνδυάζεις δύο πίνακες, μπορείς να χρησιμοποιήσεις τον τελεστή [`+`][concat], ο οποίος επιστρέφει έναν νέο πίνακα με τα στοιχεία και των δύο πινάκων.

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

Αν προσθέσεις έναν πίνακα σε έναν άλλο πίνακα, ο πίνακας θα προστεθεί ως ένα μόνο στοιχείο.

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

Όταν ελέγχεις αν ένας πίνακας είναι κενός, μπορείς να χρησιμοποιήσεις τη μέθοδο [`empty?`][empty?], η οποία επιστρέφει `true` αν ο πίνακας είναι κενός και `false` διαφορετικά.
Αυτό βελτιώνει την αναγνωσιμότητα σε σύγκριση με τον έλεγχο του μήκους του πίνακα ως προς το `0`.

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

Όταν θέλεις να πάρεις τη θέση ενός στοιχείου σε έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`index`][index], η οποία παίρνει ως όρισμα ένα στοιχείο.
Αν το στοιχείο δεν υπάρχει στον πίνακα, τότε θα επιστραφεί `nil`.

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

Όταν θέλεις να μάθεις τον αριθμό των στοιχείων σε έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`size`][size].

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

Όταν θέλεις να μετρήσεις πόσες φορές υπάρχει ένα στοιχείο σε έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`count`][count].

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

Όταν θέλεις να ταξινομήσεις έναν πίνακα, μπορείς να χρησιμοποιήσεις τη μέθοδο [`sort`][sort], η οποία επιστρέφει έναν νέο πίνακα με τα στοιχεία ταξινομημένα.
Όπως και με τη `reverse`, αυτή η μέθοδος επιστρέφει έναν νέο πίνακα και δεν τροποποιεί τον αρχικό πίνακα.

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
