# Εικονική κεφαλίδα

## Να κάνεις `grep` ή να μην κάνεις `grep`; Αυτό είναι το ερώτημα

Αν και αυτή η άσκηση μπορεί να λυθεί τετριμμένα περνώντας απλώς τα ορίσματα στο `grep`, υλοποίησε αυτή την άσκηση χρησιμοποιώντας μόνο bash. Ο στόχος αυτού του track του Exercism είναι να μάθεις να χρησιμοποιείς τις ενσωματωμένες εντολές του bash για να λύνεις προβλήματα.

Για να λύσεις αυτή την άσκηση, θα χρειαστεί να:

* αναλύσεις τα ορίσματα της γραμμής εντολών: το [`getopts`](https://stackoverflow.com/tags/getopts/info) είναι χρήσιμο γι' αυτό.
* διατρέξεις τις γραμμές ενός αρχείου: αυτό είναι το [bash FAQ #1](https://mywiki.wooledge.org/BashFAQ/001)
* χρησιμοποιήσεις αντιστοίχιση κανονικών εκφράσεων: το bash μπορεί να το κάνει αυτό με τον τελεστή `=~` μέσα στο [`[[ ... ]]`](https://www.gnu.org/software/bash/manual/bash.html#index-_005b_005b)
