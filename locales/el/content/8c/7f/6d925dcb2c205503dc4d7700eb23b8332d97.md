# Εισαγωγή

Το `call` (στο [`kernel`][kernel]) εκτελεί ένα quotation. Όταν το
stack effect του quotation δεν μπορεί να συναχθεί, συνήθως επειδή
το quotation προέρχεται από κάπου αλλού, δήλωσε ρητά το stack effect στο
`call`:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Επειδή τα quotations είναι τιμές, ένας πίνακας μπορεί να περιέχει ένα μείγμα από αριθμούς
και quotations, κάνοντας "ένα πρόγραμμα" απλώς μια άλλη ακολουθία:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
