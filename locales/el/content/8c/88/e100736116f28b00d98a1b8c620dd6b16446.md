# Οδηγίες

Αν θέλεις να φτιάξεις κάτι χρησιμοποιώντας ένα Raspberry Pi, πιθανότατα θα χρειαστείς _αντιστάσεις_.
Για αυτή την άσκηση, πρέπει να ξέρεις δύο πράγματα γι' αυτές:

- Κάθε αντίσταση έχει μια τιμή αντίστασης.
- Οι αντιστάσεις είναι μικρές, τόσο μικρές που αν τύπωνες την τιμή αντίστασης πάνω τους, θα ήταν δύσκολο να τη διαβάσεις.

Για να ξεπεράσουν αυτό το πρόβλημα, οι κατασκευαστές τυπώνουν χρωματιστές ζώνες πάνω στις αντιστάσεις για να δηλώσουν τις τιμές αντίστασής τους.
Κάθε ζώνη έχει μια θέση και μια αριθμητική τιμή.

Οι δύο πρώτες ζώνες μιας αντίστασης έχουν ένα απλό σχήμα κωδικοποίησης: κάθε χρώμα αντιστοιχεί σε έναν μόνο αριθμό.

Η τρίτη ζώνη είναι ένας πολλαπλασιαστής.

Σε αυτή την άσκηση θα φτιάξεις ένα χρήσιμο πρόγραμμα, ώστε να μη χρειάζεται να θυμάσαι τις τιμές των ζωνών.

Περισσότερες πληροφορίες για την κωδικοποίηση χρωμάτων των αντιστάσεων μπορείς να βρεις στο [άρθρο της Wikipedia για τον ηλεκτρονικό κωδικό χρωμάτων][e-color-code].

## 1. Όρισε ένα ονομασμένο διάνυσμα

Τα χρώματα κωδικοποιούνται ως εξής:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Δημιούργησε το ονομασμένο διάνυσμα `resistor_bands`, το οποίο θα πρέπει να έχει τα χρώματα ως ονόματα και τους αριθμούς ως τιμές.

## 2. Επίστρεψε την τιμή που σχετίζεται με μια ζώνη

Πρώτα, θα θέλεις να μπορείς να βρίσκεις τη μεμονωμένη τιμή για οποιαδήποτε χρωματιστή ζώνη.

Όρισε μια συνάρτηση `band_value(band)` που δέχεται μια `string` με το χρώμα μιας ζώνης.
Η συνάρτηση επιστρέφει την τιμή που αντιστοιχεί σε αυτό το χρώμα.

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. Επίστρεψε την τιμή που σχετίζεται με δύο ζώνες

Οι δύο πρώτες ζώνες σε μια αντίσταση συνδυάζονται για να σχηματίσουν έναν μόνο αριθμό.
Αν οι δύο πρώτες ζώνες έχουν αντίστοιχα τους αριθμούς `m` και `n`, συνδυάζονται για να σχηματίσουν τον ενιαίο αριθμό `mn`.

Όρισε μια συνάρτηση `two_band_value(bands)` που δέχεται ένα `vector` από `string`s με τα χρώματα δύο ζωνών.
Η συνάρτηση επιστρέφει την τιμή που αντιστοιχεί στον συνδυασμό αυτών των δύο χρωμάτων.

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. Επίστρεψε τα ohm που σχετίζονται με τις τρεις ζώνες

Τέλος, θα χρειαστεί να βρεις τη συνολική τιμή σε ohm χρησιμοποιώντας τις δύο πρώτες ζώνες μαζί με την τρίτη.
Για να το κάνεις αυτό, θα χρειαστεί να βρεις την τιμή των δύο ζωνών και έναν πολλαπλασιαστή.
Ο πολλαπλασιαστής μπορεί να ιδωθεί ως το πόσα μηδενικά προσθέτονται στην τιμή των δύο ζωνών.

Όρισε μια συνάρτηση `ohms(bands)` που δέχεται ένα `vector` από `string`s με τα χρώματα τριών ζωνών.
Η συνάρτηση επιστρέφει την τιμή σε ohm που αντιστοιχεί στον συνδυασμό των τριών χρωμάτων.

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
