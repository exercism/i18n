## 1. Πρόσθεσε ένα άτομο στην ουρά

- Υπάρχει [μια μέθοδος][append] για να προσθέσεις ένα στοιχείο σε έναν πίνακα.

## 2. Πού είναι οι φίλοι μου;

- Υπάρχει [μια μέθοδος][index] για να βρεις τη θέση ενός στοιχείου σε έναν πίνακα.

## 3. Μπορώ να έρθω κι εγώ μαζί τους;

- Μπορείς να χρησιμοποιήσεις μεθόδους που έχουν ήδη οριστεί για να βρεις τη θέση του φίλου και να εισάγεις το άτομο σε αυτή τη θέση.
- Υπάρχει [μια μέθοδος][insert] για να εισάγεις ένα στοιχείο σε μια συγκεκριμένη θέση ενός πίνακα.

## 4. Κακός άνθρωπος στην ουρά

- Υπάρχει [μια μέθοδος][delete] για να διαγράψεις ένα στοιχείο από έναν πίνακα.

## 5. Ταξινόμησε τη λίστα της ουράς

- Υπάρχει [μια μέθοδος][sort] για να ταξινομήσεις έναν πίνακα.
