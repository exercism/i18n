# Οδηγίες

Προσδιόρισε αν ένα δεδομένο σύνολο από τρία ντόμινο μπορεί να τακτοποιηθεί με τέτοιο τρόπο ώστε να σχηματίζει μια σωστή αλυσίδα ντόμινο (οι κουκκίδες στο ένα μισό μιας πέτρας να ταιριάζουν με τις κουκκίδες στο γειτονικό μισό μιας διπλανής πέτρας) και ώστε οι κουκκίδες στα μισά των πετρών που δεν έχουν γείτονα (η πρώτη και η τελευταία πέτρα) να ταιριάζουν μεταξύ τους. Κάποιες περιπτώσεις ελέγχου μπορεί να χρησιμοποιούν διπλότυπες πέτρες σε μια λύση αλυσίδας. Επίστρεψε `True` αν μπορεί να σχηματιστεί μια σωστή αλυσίδα ντόμινο και `False` διαφορετικά.

```text
For example, given: [(2,1),(2,3),(1,3)]
    True

For example, given: [(1,2),(4,1),(2,3)]
    False
```
