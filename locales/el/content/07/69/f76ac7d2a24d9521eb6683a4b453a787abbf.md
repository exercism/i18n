# Πώς να γράφεις ένα καλό αίτημα υποστήριξης

Χρειάζεσαι βοήθεια με μια άσκηση στο Exercism;
Αύξησε τις πιθανότητές σου να πάρεις μια καλή απάντηση, μαθαίνοντας πώς να γράφεις ένα καλό αίτημα υποστήριξης, και ενθάρρυνε την κοινότητά μας να σε βοηθήσει.

Ακολουθούν μερικές βασικές συμβουλές.

## Χρησιμοποίησε μπλοκ κώδικα, όχι εικόνες

Όταν θέλεις να μοιραστείς κώδικα (είτε κώδικα που έχεις γράψει είτε οδηγίες), χρησιμοποίησε ένα μπλοκ κώδικα, όχι μια εικόνα.

Ως προγραμματιστές, διαβάζουμε κώδικα πολύ πιο γρήγορα από το να μεγεθύνουμε μια εικόνα για να δούμε τι λέει.
Και πολλοί από τους χρήστες μας χρησιμοποιούν αναγνώστες οθόνης, που δε μπορούν να διαβάσουν εικόνες.
Οπότε, αν θέλεις να είσαι καλό μέλος της κοινότητας, να ενθαρρύνεις τους εθελοντές μας να σε βοηθήσουν και να δείχνεις επαγγελματίας, μοιράσου τον κώδικά σου ως κείμενο, όχι ως εικόνα!

Για παράδειγμα, μπορείς να γράψεις το εξής:

````
```
for number in range(10):
  total += number;
```
````

Αυτό θα εμφανιστεί έτσι:

```
for number in range(10):
  total += number;
```

Μπορείς μάλιστα να πάρεις επισήμανση σύνταξης προσθέτοντας τη γλώσσα στο άνοιγμα του μπλοκ κώδικα:

````
```python
for number in range(10):
  total += number;
```
````

που γίνεται:

```python
for number in range(10):
  total += number;
```
