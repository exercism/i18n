# Δοκιμή της άσκησης

Ακολούθησε τα παρακάτω βήματα για να αναπτύξεις μια λύση για μια άσκηση και να τη δοκιμάσεις τοπικά.

## Κατέβασε την άσκηση

Άνοιξε το Command Prompt και εκτέλεσε την παρακάτω εντολή με το όνομα της άσκησης που προτιμάς για να την κατεβάσεις.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Ανάπτυξε τη λύση σου

1. Εκτέλεσε την παρακάτω εντολή για να μεταβείς στον κατάλογο της άσκησης που μόλις κατέβασες.

     >**Συμβουλή:** Η θέση του καταλόγου στην παρακάτω εντολή εξαρτάται από το λειτουργικό σου σύστημα και από τον χώρο εργασίας σου στο Exercism. Μπορείς να βρεις τη θέση του χώρου εργασίας σου εκτελώντας την εντολή `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Ακολούθησε τις οδηγίες που σου δίνονται και ανάπτυξε μια λύση για την άσκηση.

## Δοκίμασε τη λύση σου

Κάποιες ασκήσεις Ballerina έχουν μία μόνο δοκιμή, ενώ άλλες έχουν πολλές. Οι δοκιμές βρίσκονται στο αντίστοιχο αρχείο δοκιμών του καταλόγου `/tests` μέσα στον ριζικό κατάλογο της άσκησης.

### Δοκιμή άσκησης με μία δοκιμή

Εκτέλεσε την παρακάτω εντολή για να τρέξεις τη δοκιμή της άσκησης.

Από προεπιλογή, μόνο η πρώτη δοκιμή είναι ενεργοποιημένη. Αυτό γίνεται σκόπιμα, γιατί έτσι μπορείς να επικεντρωθείς στο να περάσει μόνο αυτή η μία δοκιμή. 
     
```sh
bal test
```

### Δοκιμή άσκησης με πολλές δοκιμές

Ακολούθησε τα παρακάτω βήματα για να δοκιμάσεις μια άσκηση με πολλές δοκιμές.

1. Μόλις περάσει η πρώτη δοκιμή, ενεργοποίησε την επόμενη αφαιρώντας την ιδιότητα `enable: false` από την επισημείωση `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Εκτέλεσε την παρακάτω εντολή για να τρέξεις τη δοκιμή που ενεργοποίησες.

   ```sh
     bal test
   ```

3. Επανάλαβε τα δύο παραπάνω βήματα για να ενεργοποιήσεις τις υπόλοιπες δοκιμές.

Ολοκλήρωσες με επιτυχία την άσκηση ενεργοποιώντας όλες τις δοκιμές και φροντίζοντας η υλοποίησή σου να περνάει από κάθε μία.
