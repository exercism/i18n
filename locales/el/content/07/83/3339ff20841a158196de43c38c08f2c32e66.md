# Εισαγωγή

Στο επίπεδο του υλικού, [τα τρανζίστορ μπορούν να είναι μόνο ενεργά ή ανενεργά][how-transistors-work]: δύο καταστάσεις που παραδοσιακά αναπαριστούμε με `1` και `0`.
Αυτά είναι τα [`binary digits`][binary-digits], που συντομεύονται σε [`bits`][bits].
Η εξοικείωση με τα `bits` και το `binary` είναι ιδιαίτερα σημαντική για προγραμματιστές συστημάτων που δουλεύουν σε γλώσσες χαμηλού επιπέδου.
Ωστόσο, για το μεγαλύτερο μέρος της ιστορίας των υπολογιστών, η προτεραιότητα του προγραμματισμού ήταν να βρίσκει ολοένα και πιο εξελιγμένους τρόπους για να _αφαιρεί_ αυτή τη δυαδική πραγματικότητα.


Στην Python (και σε πολλές άλλες [γλώσσες προγραμματισμού υψηλού επιπέδου][high-level-language]) δουλεύουμε με `int`, `float`, `string` και άλλους ορισμένους _τύπους_, μέχρι και με μορφές ήχου και βίντεο.
Τα εσωτερικά της Python φροντίζουν (_αργά ή γρήγορα_) να μετατρέπουν όλα τα δεδομένα υψηλότερου επιπέδου σε bits.


Παρ' όλα αυτά, η χρήση [τελεστών bitwise][python-bitwise-operators] και [πράξεων bitwise][python-bitwise-operations] μπορεί μερικές φορές να προσφέρει σημαντικά πλεονεκτήματα στην ταχύτητα και στην αποδοτικότητα της μνήμης, ακόμα και σε μια γλώσσα υψηλού επιπέδου όπως η Python.
