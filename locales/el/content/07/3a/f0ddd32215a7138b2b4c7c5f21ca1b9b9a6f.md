# Σχετικά

Υπάρχουν βασικά δύο τύποι βρόχων:

1. Βρόχος μέχρι να ικανοποιηθεί μια συνθήκη.
2. Βρόχος πάνω στα στοιχεία μιας συλλογής.

Και οι δύο είναι [εφικτοί στην R][web-loops], αν και ο πρώτος είναι ίσως πιο συνηθισμένος.

## `while` και `repeat`

Για προβλήματα ανοιχτού τύπου, όπου ο αριθμός των επαναλήψεων δεν είναι γνωστός εκ των προτέρων, η R διαθέτει τον βρόχο [`while`][ref-control] με συνθήκη και τον βρόχο [`repeat`][ref-control] χωρίς συνθήκη (ισοδύναμο με `while (TRUE)`).

Η βασική μορφή είναι αρκετά απλή:

```R
while (condition) {
  do_something()
}
```

Σε αυτή την περίπτωση, το πρόγραμμα θα συνεχίσει να εκτελεί τον βρόχο μέχρι η `condition` να μην είναι πλέον `TRUE`.

Υπάρχουν δύο τρόποι να βγεις νωρίς από τον βρόχο:

- Ένα `break` προκαλεί την έξοδο από τον βρόχο, και η εκτέλεση συνεχίζεται στην επόμενη γραμμή μετά το άγκιστρο κλεισίματος `}` του βρόχου.
- Ένα `return(x)` σταματά την εκτέλεση της τρέχουσας συνάρτησης και μεταβιβάζει την τιμή επιστροφής `x` πίσω στον καλούντα.

Με αυτές τις επιλογές, μερικές φορές είναι βολικό να δημιουργήσεις έναν "άπειρο" βρόχο με `repeat { ... }` και στη συνέχεια να βασιστείς στο να βρεις μια συνθήκη τερματισμού μέσα στο σώμα του βρόχου, ώστε να προκαλέσεις ένα `break` ή ένα `return`.

Αυτές οι τρεις παραλλαγές είναι ισοδύναμες και όλες καταλήγουν με `x == 0.4444...`

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## Επανάληψη πάνω σε ένα διάνυσμα (ή άλλη συλλογή)

Αυτό είναι συχνά περιττό στην R.
Όπως συζητήθηκε σε άλλες έννοιες, πολλές συναρτήσεις λειτουργούν σε ολόκληρα διανύσματα.

Ωστόσο, οι ρητοί βρόχοι είναι μερικές φορές αναπόφευκτοι.
Αυτό ισχύει ιδιαίτερα όταν:

- Το σώμα του βρόχου έχει παρενέργειες, όπως εκτύπωση ή είσοδο/έξοδο αρχείων.
- Ο βρόχος συνεχίζεται μέχρι να ικανοποιηθεί κάποιο κριτήριο, μετά από απρόβλεπτο αριθμό επαναλήψεων.

Η συνθήκη του βρόχου πρέπει να βρίσκεται μέσα σε παρενθέσεις.
Όπως και με τα σώματα συναρτήσεων, τα άγκιστρα είναι προαιρετικά (αλλά συχνά περιλαμβάνονται) για σώματα βρόχου μιας γραμμής.

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

Αν η τρέχουσα επανάληψη δεν ικανοποιεί κάποια συνθήκη, μπορείς να παραλείψεις αμέσως στην επόμενη επανάληψη με ένα `next`:

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

Αν χρειάζεσαι την αριθμητική θέση, χρησιμοποίησε το [`seq_along()`][ref-seq_along].

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

Το `i in 1:length(v)` _δεν_ συνιστάται, καθώς μπορεί να προκαλέσει προβλήματα όταν το `length(v)` είναι μηδέν.
Το διάστημα `1:0` είναι ισοδύναμο με το `c(1, 0)`, οπότε το σώμα του βρόχου θα εκτελεστεί και πιθανότατα θα αποτύχει.
Η συνάρτηση `seq_along()` είναι σχεδιασμένη να χειρίζεται σωστά αυτή την περίπτωση.
