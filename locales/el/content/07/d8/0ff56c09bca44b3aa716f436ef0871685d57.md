# Σχετικά

Οι `Complex numbers` δεν είναι περίπλοκοι.
Χρειάζονται απλώς ένα λιγότερο ανησυχητικό όνομα.

Είναι τόσο χρήσιμοι, ειδικά στη μηχανική και τις επιστήμες, που η Julia συμπεριλαμβάνει τους [μιγαδικούς αριθμούς][complex] ως τυπικούς αριθμητικούς τύπους μαζί με τους ακέραιους και τους αριθμούς κινητής υποδιαστολής.

## Τα βασικά

Μια τιμή `complex` στη Julia είναι ουσιαστικά ένα ζεύγος αριθμών: συνήθως, αλλά όχι πάντα, κινητής υποδιαστολής.
Αυτά ονομάζονται το "πραγματικό" και το "φανταστικό" μέρος, για δυστυχείς ιστορικούς λόγους.
Και πάλι, το καλύτερο είναι να επικεντρωθείς στην υποκείμενη απλότητα και όχι στα παράξενα ονόματα.

Για να δημιουργήσεις μιγαδικούς αριθμούς από δύο πραγματικούς αριθμούς, απλώς πρόσθεσε την κατάληξη `im` στο φανταστικό μέρος.

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

Έτσι υπάρχουν διάφοροι τύποι `Complex`, που προέρχονται από τον αντίστοιχο ακέραιο ή τύπο κινητής υποδιαστολής.

Για να δημιουργήσεις έναν μιγαδικό αριθμό από πραγματικές μεταβλητές, η παραπάνω σύνταξη δεν θα δουλέψει.
Γράφοντας `a + bim` μπερδεύεις τον parser ώστε να νομίζει ότι το `bim` είναι ένα (ανύπαρκτο) όνομα μεταβλητής.

Το να γράψεις `b*im` είναι δυνατό, αλλά η προτιμώμενη μέθοδος χρησιμοποιεί τη συνάρτηση `complex()`.

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

Μπορεί να αναρωτιέσαι: γιατί `im` και όχι `i` ή `j`;

Οι περισσότεροι μηχανικοί είναι ευχαριστημένοι με το `j`.
Οι περισσότεροι επιστήμονες και μαθηματικοί προτιμούν τον μαθηματικό συμβολισμό `i` για το _φανταστικό_, αλλά αυτός ο συμβολισμός συγκρούεται με τη χρήση του `i` για να σημαίνει _ένταση ρεύματος_ στη Μηχανική Ηλεκτρολόγων.

Το [εγχειρίδιο][complex] αναφέρει ότι "Η χρήση του i των μαθηματικών ή του j των μηχανικών για αυτή τη γενική σταθερά απορρίφθηκε, καθώς είναι τόσο δημοφιλή ονόματα μεταβλητών θέσης".

Από ευτυχή σύμπτωση, αυτό αποφεύγει και τους μακροσκελείς καβγάδες μεταξύ μηχανικών και όλων των υπολοίπων.
Είσαι ελεύθερος να κρίνεις μόνος σου αν αυτό επηρέασε την απόφαση.

Για να προσπελάσεις τα μέρη ενός μιγαδικού αριθμού ξεχωριστά:

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

Οποιοδήποτε από τα δύο μέρη μπορεί να είναι μηδέν, και τότε οι μαθηματικοί μπορεί να πουν ότι ο αριθμός είναι "εξ ολοκλήρου πραγματικός" ή "εξ ολοκλήρου φανταστικός".
Ωστόσο, στη Julia παραμένει μιγαδικός αριθμός.

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

Μπορεί να έχεις ακούσει ότι "το `i` (ή το `j`) είναι η τετραγωνική ρίζα του -1".

Για την ώρα, το μόνο που σημαίνει αυτό είναι ότι το φανταστικό μέρος _εξ ορισμού_ ικανοποιεί την παρακάτω ισότητα:

```julia-repl
julia> 1im * 1im == -1
true
```

Είναι μια απλή ιδέα, αλλά οδηγεί σε ενδιαφέρουσες συνέπειες.

## Αριθμητική

Όλοι οι τυπικοί μαθηματικοί `operators` και οι στοιχειώδεις συναρτήσεις που χρησιμοποιούνται με αριθμούς κινητής υποδιαστολής και ακεραίους δουλεύουν επίσης με μιγαδικούς αριθμούς. Ένα μικρό δείγμα:

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

Η εξήγηση των κανόνων για τον πολλαπλασιασμό και τη διαίρεση μιγαδικών αριθμών είναι εκτός του πεδίου αυτής της έννοιας (_και είναι απίθανο να χρειαστεί να εκτελέσεις αυτές τις πράξεις "με το χέρι" πολύ συχνά_).

Οποιαδήποτε [μαθηματική][math-complex] ή [ηλεκτρολογική][engineering-complex] εισαγωγή στους μιγαδικούς αριθμούς θα το καλύψει, αν θέλεις να εμβαθύνεις στο θέμα.

Εναλλακτικά, το Exercism έχει μια άσκηση εξάσκησης `Complex Numbers`, όπου μπορείς να υλοποιήσεις μια κλάση μιγαδικών αριθμών με αυτές τις πράξεις από πρώτες αρχές.

Η ακέραια διαίρεση είναι (ως επί το πλείστον) ___όχι___ δυνατή στους μιγαδικούς αριθμούς, οπότε οι τελεστές `//`, `÷` και `%` θα αποτύχουν για τον τύπο μιγαδικών αριθμών.
Μια εξαίρεση είναι η χρήση του `//` με μιγαδικούς _ακεραίους_ για να πάρεις μιγαδικούς ρητούς αριθμούς, αλλά αυτό μάλλον δεν είναι συχνά χρήσιμο.

## Συναρτήσεις

Οι περισσότερες μαθηματικές συναρτήσεις θα δουλέψουν με μιγαδικά ορίσματα.

Ωστόσο, το να δίνεις πραγματικά ορίσματα και να περιμένεις μιγαδικό αποτέλεσμα συνήθως δεν δουλεύει.
Πρόκειται για μια βελτιστοποίηση απόδοσης που θα βγάλει περισσότερο νόημα αφού δεις την έννοια της πολλαπλής αποστολής.

```julia-repl
julia> sin(1.5 + 2.0im)
3.752771340479298 + 0.25655395609048176im

julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt was called with a negative real argument but will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).

julia> sqrt(-1 + 0im)
0.0 + 1.0im
```

Υπάρχουν αρκετές συναρτήσεις, πέρα από τις `real()` και `imag()`, με ιδιαίτερη σημασία για τους μιγαδικούς αριθμούς.
Προσπέρασέ τες αν δεν βγάζουν νόημα για σένα!

- Η `conj()` αντιστρέφει απλώς το πρόσημο του φανταστικού μέρους ενός μιγαδικού αριθμού (_από + σε - ή αντίστροφα_).
    - Λόγω του τρόπου που λειτουργεί ο πολλαπλασιασμός μιγαδικών, αυτό είναι πιο χρήσιμο απ' ό,τι μπορεί να νομίζεις.
- Η `abs(<complex number>)` είναι εγγυημένο ότι επιστρέφει έναν πραγματικό αριθμό χωρίς φανταστικό μέρος.
- Η `abs2(<complex number>)` επιστρέφει το τετράγωνο της `abs(<complex number>)`: υπολογίζεται πιο γρήγορα από την `abs()`, και συχνά είναι αυτό που χρειάζεται ένας υπολογισμός.
- Η `angle(<complex number>)` επιστρέφει τη γωνία φάσης σε ακτίνια.

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
Μια μερική εξήγηση, για τους μαθηματικά σκεπτόμενους _(και πάλι, μπορείς άνετα να την προσπεράσεις)_:

- Η αναπαράσταση `(real, imag)` του `z1` χρησιμοποιεί στην πράξη καρτεσιανές συντεταγμένες στο μιγαδικό επίπεδο.
- Ο ίδιος μιγαδικός αριθμός μπορεί να αναπαρασταθεί με τον συμβολισμό `(r, θ)`, χρησιμοποιώντας πολικές συντεταγμένες.
- Εδώ, τα `r` και `θ` δίνονται από τις `abs(z1)` και `angle(z1)` αντίστοιχα.

Ακολουθεί ένα παράδειγμα που χρησιμοποιεί κάποιες σταθερές:

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

Έτσι, μια απλή παράσταση με τρεις από τις σημαντικότερες σταθερές στη φύση, τα `e`, `i` (ή `j`) και `pi`, δίνει ως αποτέλεσμα το `-1`.
Κάποιοι πιστεύουν ότι αυτό είναι το ομορφότερο αποτέλεσμα σε όλα τα μαθηματικά.
Χρονολογείται γύρω στο 1740.

Ο πολικός συμβολισμός `(r, θ)` είναι τόσο χρήσιμος, που υπάρχουν ενσωματωμένες συναρτήσεις, οι `cis` (συντομογραφία του `cos(x) + isin(x)`) και `cispi` (συντομογραφία του `cos(πx) + isin(πx)`), οι οποίες μπορούν να βοηθήσουν στην πιο αποδοτική κατασκευή του.

Η χρησιμότητα του πολικού συμβολισμού φαίνεται στον κομψό τύπο του Euler, `ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`, όπου `|x + iy| = 1`.
Με `|x + iy| = r`, έχουμε τη γενικότερη πολική μορφή `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`.
Σημείωσε ότι η εκθετική μορφή, ειδικότερα, είναι συμπαγής και εύκολη στον χειρισμό.

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

Η κατά προσέγγιση ισότητα παραπάνω οφείλεται στο ότι οι συναρτήσεις [`cis`][cis] και [`cispi`][cispi] μπορούν να δώσουν πιο όμορφα αριθμητικά αποτελέσματα, με την `cispi` ειδικότερα όταν έχει να κάνει με ορίσματα που είναι αυθαίρετοι παράγοντες του π (π.χ. ακτίνια!).

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

Παρεμπιπτόντως, αυτό κάνει τους μιγαδικούς αριθμούς πολύ χρήσιμους για την εκτέλεση περιστροφών και ακτινικών μετατοπίσεων σε 2D.

Για περιστροφές, ο μιγαδικός αριθμός `z = x + iy` μπορεί να περιστραφεί κατά γωνία `θ` γύρω από την αρχή των αξόνων με έναν απλό πολλαπλασιασμό: `z * ℯ^(iθ)`.
Σημείωσε ότι τα `x` και `y` εδώ είναι απλώς οι συνήθεις συντεταγμένες στο πραγματικό 2D καρτεσιανό επίπεδο, και μια θετική γωνία έχει ως αποτέλεσμα *αριστερόστροφη* περιστροφή, ενώ μια αρνητική γωνία έχει ως αποτέλεσμα *δεξιόστροφη*.

Παρομοίως απλά, μια ακτινική μετατόπιση `Δr` μπορεί να γίνει προσθέτοντάς την στο μέτρο `r` ενός μιγαδικού αριθμού στην πολική μορφή (π.χ. `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`).
Πρόσεξε πώς το γωνιακό μέρος μένει το ίδιο και μόνο το μέτρο, `r`, μεταβάλλεται, όπως αναμενόταν.

## Προαιρετική ενότητα: συχνές ερωτήσεις για τους μιγαδικούς αριθμούς

Αυτό το μέρος μπορεί να παραλειφθεί, εκτός αν σε ενδιαφέρει.

### Δεν είναι αυτό κάποιο παράξενο νέο κομμάτι των καθαρών μαθηματικών;

Ήταν παράξενο και νέο τον 16ο αιώνα.

500 χρόνια αργότερα, είναι κεντρικό σε μεγάλο μέρος της μηχανικής και των φυσικών επιστημών.

### Γιατί να τα χρησιμοποιήσει κανείς;

Αποδεικνύεται ότι οι μιγαδικοί αριθμοί είναι ο απλούστερος τρόπος να περιγράψεις οτιδήποτε περιστρέφεται ή οτιδήποτε έχει κυματοειδή ιδιότητα.
Έτσι χρησιμοποιούνται ευρέως στη μηχανική ηλεκτρολόγων, στην επεξεργασία ήχου, στη φυσική, στα βιντεοπαιχνίδια και στη ναυσιπλοΐα, για να αναφέρουμε μόνο μερικές εφαρμογές.

Μπορείς να δεις πράγματα να περιστρέφονται.
Οι μιγαδικοί αριθμοί μπορεί να μην κάνουν τον κόσμο να γυρίζει, αλλά είναι εξαιρετικοί στο να εξηγούν _τι συμβαίνει_ όταν ο κόσμος γυρίζει: κοίταξε οποιαδήποτε δορυφορική εικόνα μιας μεγάλης καταιγίδας.

Λιγότερο προφανώς, ο ήχος είναι κυματοειδής, το φως είναι κυματοειδές, τα ραδιοσήματα είναι κυματοειδή, και ακόμη και η οικονομία της χώρας σου είναι τουλάχιστον εν μέρει κυματοειδής.

Μεγάλο μέρος αυτής της επεξεργασίας κυμάτων μπορεί να γίνει με τριγωνομετρικές συναρτήσεις (τις `sin()` και `cos()`), αλλά αυτό γίνεται μπερδεμένο αρκετά γρήγορα.

Οι μιγαδικές εκθετικές είναι ___πολύ___ πιο εύκολες στον χειρισμό.

### Αλλά δεν χρειάζομαι τους μιγαδικούς αριθμούς!

Αυτό ισχύει μόνο αν ζεις σε μια σπηλιά και μαζεύεις την τροφή σου.

Αν το διαβάζεις αυτό σε οποιουδήποτε είδους οθόνη, εξαρτάσαι απόλυτα από κάποιες χρήσιμες προόδους του 20ού αιώνα που έγιναν μέσω της χρήσης μιγαδικών αριθμών.

1. __Τσιπ ημιαγωγών__.
    - Αυτά δεν βγάζουν νόημα στην κλασική φυσική και μπορούν να εξηγηθούν (και να σχεδιαστούν) μόνο από την κβαντομηχανική (ΚΜ).
    - Στην ΚΜ, τα πάντα είναι μιγαδικής τιμής εξ ορισμού. (_είναι κυματομορφές μέχρι κάτω_)

2. __Ο αλγόριθμος του Γρήγορου Μετασχηματισμού Fourier__.
    - Ο FFT είναι μια εφαρμογή των μιγαδικών αριθμών, και βρίσκεται σε _όλα_ όσα σχετίζονται με τη μετάδοση ήχου, την επεξεργασία ήχου, τις φωτογραφίες και το βίντεο.

    - Το MP3 και άλλες μορφές ήχου χρησιμοποιούν τον FFT για συμπίεση, ώστε να χωράει περισσότερος ήχος σε μικρότερο χώρο αποθήκευσης.
    - Η συμπίεση JPEG και το βίντεο MP4, ανάμεσα σε πολλές άλλες μορφές εικόνας και βίντεο, χρησιμοποιούν επίσης τον FFT για συμπίεση.

    - Ο FFT χρησιμοποιείται επίσης στα ψηφιακά φίλτρα που επιτρέπουν στους πύργους κινητής τηλεφωνίας να ξεχωρίζουν το προσωπικό σου σήμα κινητής από όλων των άλλων.

Έτσι, πιθανότατα χρησιμοποιείς τεχνολογία που βασίζεται σε υπολογισμούς μιγαδικών αριθμών χιλιάδες φορές το δευτερόλεπτο.
