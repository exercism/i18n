# Προσάρτημα

## Το "Null" στην Tcl

Η Tcl δεν έχει τιμή `null` ή `nil`.
Στην πράξη, η κενή συμβολοσειρά χρησιμοποιείται συχνά για να δηλώσει "καμία τιμή".
Αυτό όμως μπορεί να είναι προβληματικό σε περιπτώσεις όπου μια κενή συμβολοσειρά είναι στην πραγματικότητα μια έγκυρη τιμή, για παράδειγμα σε μια λίστα που αναπαριστά μια γραμμή δεδομένων CSV.

Για αυτή την άσκηση, θεώρησε την κενή συμβολοσειρά ως τιμή null που πρέπει να απορριφθεί.
