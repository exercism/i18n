# απόφυγε τις εντολές εκτύπωσης

Δοκίμασε να αφαιρέσεις εντολές όπως η `System.out.println()` από τον κώδικα σου.
Οι δοκιμές της άσκησης απαιτούν η λύση να _επιστρέφει_ τιμές από τις μεθόδους αντί να τις εκτυπώνει.

Συνήθως, τέτοιες εντολές προστίθενται για να σε βοηθήσουν να κάνεις debug στον κώδικα.
Ωστόσο, καλύτερη προσέγγιση είναι να κάνεις debug στον κώδικα ενώ τρέχεις ένα ή περισσότερα unit tests.
Αυτό έχει το επιπλέον πλεονέκτημα ότι μπορείς να επικεντρωθείς στο debug μιας συγκεκριμένης δοκιμής.

Ορίστε μερικοί σύνδεσμοι που εξηγούν πώς να κάνεις debug σε κώδικα Java ενώ τρέχεις unit tests σε διάφορα IDE:

- [Εκτέλεση και debug δοκιμών Java στο Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Debug δοκιμών στο IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
