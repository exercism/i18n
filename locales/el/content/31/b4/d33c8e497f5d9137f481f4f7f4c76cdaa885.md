# Εισαγωγή

## Φιλτράρισμα εξαιρέσεων

Το `when` είναι η λέξη-κλειδί για το φιλτράρισμα των εξαιρέσεων. Τοποθετείται μετά την εντολή catch και μπορεί να πάρει μια έκφραση Boolean (λογική τιμή) που περιέχει οποιεσδήποτε τιμές βρίσκονται στο πεδίο εμβέλειας εκείνη τη στιγμή. Αν η έκφραση είναι αληθής, τότε εκτελείται το μπλοκ που σχετίζεται με αυτή την εντολή `catch`, αλλιώς ελέγχεται η επόμενη εντολή `catch`, αν υπάρχει.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Εξαιρέσεις οριζόμενες από τον χρήστη

Μια εξαίρεση οριζόμενη από τον χρήστη είναι οποιαδήποτε κλάση ορίζεις στον κώδικά σου και η οποία προέρχεται από το `System.Exception`. Υπόκειται σε όλους τους κανόνες της κληρονομικότητας κλάσεων, αλλά επιπλέον ο μεταγλωττιστής και ο χρόνος εκτέλεσης της γλώσσας αντιμετωπίζουν αυτές τις κλάσεις με ειδικό τρόπο, επιτρέποντας τη ρίψη και τη σύλληψη των στιγμιοτύπων τους έξω από την κανονική ροή ελέγχου, όπως συζητήθηκε στην άσκηση `exceptions`.

Οι εξαιρέσεις οριζόμενες από τον χρήστη χρησιμοποιούνται συχνά για να μεταφέρουν επιπλέον πληροφορίες, όπως ένα μήνυμα και άλλα σχετικά δεδομένα, ώστε αυτές να γίνουν διαθέσιμες στις ρουτίνες που συλλαμβάνουν την εξαίρεση.
