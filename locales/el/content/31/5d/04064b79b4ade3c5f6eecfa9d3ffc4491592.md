# χρήση placeholder του fmt για συμβολοσειρές

Στη Go, οι προγραμματιστές προτιμούν συνήθως placeholders που είναι ειδικοί για κάθε τύπο αντί για το γενικό `%%v`. Υπάρχουν δύο λόγοι γι' αυτό. Πρώτον, οι πιο συγκεκριμένοι placeholders έχουν συχνά επιπλέον επιλογές, για παράδειγμα η μορφή `%%f` για τιμές `float` μπορεί να καθορίσει και την ακρίβεια: `%%.2f`. Ο δεύτερος λόγος είναι ότι το `%%v` δέχεται οποιονδήποτε τύπο τιμής. Αν ο τύπος μιας μεταβλητής αλλάξει κατά τη διάρκεια ενός refactoring, το `%%v` θα εκτυπώσει την προεπιλεγμένη τιμή για αυτόν τον τύπο, κάτι που μπορεί να μην είναι η επιθυμητή συμπεριφορά. Ένας placeholder ειδικού τύπου θα κάνει τον linter να παραπονεθεί, εντοπίζοντας το σφάλμα πριν γίνει deploy στην παραγωγή.
