# Σχετικά

Οι [κλάσεις](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes) είναι το βασικό δομικό στοιχείο για αντικειμενοστρεφή προγραμματισμό στην F#.

Μια κλάση στην F# αποτελείται από τα πεδία και τις μεθόδους της. Τα πεδία και οι μέθοδοι μιας κλάσης ονομάζονται _μέλη_ της.

Οι κλάσεις στην F# ορίζονται με τη λέξη-κλειδί `type`. Οι μέθοδοι ορίζονται με τη λέξη-κλειδί `member` και είναι πάντα δημόσιες. Για να ορίσεις (ιδιωτικά) πεδία, μπορείς να χρησιμοποιήσεις δεσμεύσεις `let`.

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

Οι κλάσεις είναι πρότυπα με τα οποία δημιουργείς αντικείμενα. Για να δημιουργήσεις ένα στιγμιότυπο μιας κλάσης, κάλεσε το όνομα της κλάσης σαν συνάρτηση. Ένα στιγμιότυπο μιας κλάσης λέγεται και _αντικείμενο_.

Μπορείς να προσπελάσεις τα μέλη ενός αντικειμένου χρησιμοποιώντας τη σημειογραφία με τελεία.

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
