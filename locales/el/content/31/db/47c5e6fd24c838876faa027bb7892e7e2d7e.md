# Οδηγίες

Η Elaine δουλεύει ένα νέο παιδικό παιχνίδι με ζώα και μαγικά ραβδιά.
Ήρθε η ώρα να γράψεις κώδικα για συναρτήσεις που ρίχνουν ένα ζάρι, παράγουν τυχαία ενέργεια ραβδιού και ανακατεύουν ένα slice.

## 1. Ρίξε ένα ζάρι

Υλοποίησε μια συνάρτηση `RollADie`.

Αυτό θα είναι το παραδοσιακό ζάρι με είκοσι πλευρές και αριθμούς από το 1 έως το 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Δημιούργησε ενέργεια ραβδιού

Υλοποίησε μια συνάρτηση `GenerateWandEnergy`.
Η ενέργεια του ραβδιού πρέπει να είναι ένας τυχαίος αριθμός κινητής υποδιαστολής μεγαλύτερος ή ίσος με 0.0 και μικρότερος από 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Ανακάτεψε ένα slice

Το παιχνίδι περιλαμβάνει οκτώ διαφορετικά ζώα:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Γράψε μια συνάρτηση `ShuffleAnimals` που επιστρέφει ένα slice με τα οκτώ ζώα σε τυχαία σειρά.
