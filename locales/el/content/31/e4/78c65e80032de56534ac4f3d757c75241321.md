# Εισαγωγή

Στη Go μια εφαρμογή οργανώνεται σε πακέτα.
Ένα πακέτο είναι μια συλλογή από αρχεία πηγαίου κώδικα που βρίσκονται στον ίδιο φάκελο.
Όλα τα αρχεία πηγαίου κώδικα σε έναν φάκελο πρέπει να έχουν το ίδιο όνομα πακέτου στην κορυφή του αρχείου.
Κατά σύμβαση, τα πακέτα ονομάζονται όπως ο φάκελος στον οποίο βρίσκονται.

```go
package greeting
```

Η Go παρέχει μια εκτενή τυπική βιβλιοθήκη πακέτων που μπορείς να χρησιμοποιήσεις στο πρόγραμμά σου με τη λέξη-κλειδί `import`.
Τα πακέτα της τυπικής βιβλιοθήκης εισάγονται με το όνομά τους.

```go
package greeting

import "fmt"
```

Στη συνέχεια, ένα εισαγμένο πακέτο προσπελαύνεται με το όνομα του πακέτου:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Η Go καθορίζει αν ένα στοιχείο μπορεί να κληθεί από κώδικα σε άλλα πακέτα με βάση τον τρόπο δήλωσής του.
Για να γίνουν μια συνάρτηση, ένας τύπος, μια μεταβλητή, μια σταθερά ή ένα πεδίο struct εξωτερικά ορατά (γνωστά ως _εξαγόμενα_), το όνομα πρέπει να ξεκινά με κεφαλαίο γράμμα.
Αυτό είναι ανάλογο με το πώς άλλες γλώσσες προγραμματισμού, όπως η Java, χρησιμοποιούν τροποποιητές πρόσβασης όπως τα `public` και `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
