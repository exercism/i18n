# αλλαγή κωδικού σημείου σε συμβολοσειρά απευθείας

Ο ευκολότερος τρόπος για να μετατρέψεις το κωδικό σημείο ενός χαρακτήρα σε συμβολοσειρά που περιέχει αυτόν τον χαρακτήρα είναι να χρησιμοποιήσεις την ειδική μορφή `<<>>`. Δεν χρειάζεται να χρησιμοποιήσεις μια λίστα χαρακτήρων ως ενδιάμεσο βήμα.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
