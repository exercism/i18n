# Σχετικά

Μια στατική επέκταση σου επιτρέπει να επεκτείνεις ψευδο-τύπους που υπάρχουν ήδη, χωρίς να τροποποιείς τον πηγαίο κώδικά τους. Αυτό επιτυγχάνεται με την εντολή `using`. Οι στατικές επεκτάσεις μπορούν να γίνουν ένα ισχυρό εργαλείο που σου επιτρέπει να εμπλουτίζεις τύπους χωρίς στην πραγματικότητα να τους αλλάζεις.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
