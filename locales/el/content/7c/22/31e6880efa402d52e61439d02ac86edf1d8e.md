# Προαγωγή Ιδιοτήτων Κατασκευαστή

Σε κλάσεις που δηλώνουν πολλές ιδιότητες, η ξεχωριστή δήλωση της κλάσης, των ιδιοτήτων της και ενός κατασκευαστή για τον ορισμό των ιδιοτήτων απαιτεί επανάληψη.
Χρησιμοποιώντας την προαγωγή ιδιοτήτων κατασκευαστή μπορούμε να μειώσουμε την επανάληψη.

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
