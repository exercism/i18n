# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις λίγο ακόμα κώδικα που σχετίζεται με την προετοιμασία και το μαγείρεμα των υπέροχων λαζάνια σου από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες.
Η πρώτη σχετίζεται με το ίδιο το μαγείρεμα, ενώ οι άλλες τέσσερις αφορούν την τέλεια προετοιμασία.

## 1. Προσδιόρισε αν τα λαζάνια είναι έτοιμα

Όταν έχεις λαζάνια στον φούρνο, θέλεις να ξέρεις αν μπορείς να τα βγάλεις κιόλας ή όχι.
Για να σιγουρευτείς ότι τα λαζάνια δεν θα καούν στον φούρνο, συνήθως βάζεις ένα χρονόμετρο.
Μερικές φορές όμως το ξεχνάς.

Γράψε μια συνάρτηση `cookingStatus` που δέχεται ως παράμετρο τον χρόνο που απομένει στο χρονόμετρο σε λεπτά.
Η συνάρτηση έχει τρία πιθανά αποτελέσματα.

- Αν το χρονόμετρο δείχνει `0`, θα πρέπει να επιστρέφει `'Lasagna is done.'`.
- Αν το χρονόμετρο δείχνει οποιονδήποτε άλλο αριθμό, το αποτέλεσμα θα πρέπει να είναι `'Not done, please wait.'`.
- Αν η συνάρτηση κληθεί χωρίς τιμή χρονόμετρου, το αποτέλεσμα θα πρέπει να είναι `'You forgot to set the timer.'`.

Το χρονόμετρο δε θα δείχνει ποτέ τιμή κάτω από το 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Εκτίμησε τον χρόνο προετοιμασίας

Για τα επόμενα λαζάνια που θα ετοιμάσεις, θέλεις να σιγουρευτείς ότι έχεις κρατήσει αρκετό χρόνο, ώστε να απολαύσεις το μαγείρεμα.
Έχεις ήδη κάνει ένα σχέδιο με όλες τις στρώσεις που θα έχουν τα λαζάνια σου.
Τώρα θέλεις να υπολογίσεις κατά προσέγγιση πόσο χρόνο θα πάρει η προετοιμασία με βάση αυτό.

Υλοποίησε μια συνάρτηση `preparationTime` που δέχεται έναν πίνακα με στρώσεις και τον μέσο χρόνο προετοιμασίας ανά στρώση σε λεπτά.
Η συνάρτηση θα πρέπει να επιστρέφει την εκτίμηση για τον συνολικό χρόνο προετοιμασίας με βάση τον αριθμό των στρώσεων.
Αν η συνάρτηση κληθεί χωρίς να δοθεί ο μέσος χρόνος προετοιμασίας, θα πρέπει να υποτεθεί ότι είναι `2` λεπτά.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Υπολόγισε τις ποσότητες ζυμαρικών και σάλτσας που χρειάζονται

Εκτός από τον χρόνο που κρατάς, θέλεις επίσης να σιγουρευτείς ότι έχεις αρκετή σάλτσα και ζυμαρικά για να μαγειρέψεις τα λαζάνια των ονείρων σου.
Για κάθε στρώση ζυμαρικών στα λαζάνια σου, θα χρειαστείς 50 γραμμάρια ζυμαρικά.
Για κάθε στρώση σάλτσας στα λαζάνια σου, θα χρειαστείς 0,2 λίτρα σάλτσα.

Όρισε τη συνάρτηση `quantities` που παίρνει ως παράμετρο έναν πίνακα με στρώσεις.
Στη συνέχεια, η συνάρτηση θα προσδιορίσει την ποσότητα των ζυμαρικών και της σάλτσας που χρειάζονται για το γεύμα σου.
Το αποτέλεσμα θα πρέπει να επιστραφεί ως αντικείμενο με κλειδιά `noodles` και `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Πρόσθεσε το μυστικό συστατικό

Πριν από λίγο καιρό επισκέφτηκες έναν φίλο και έφαγες λαζάνια εκεί.
Ήταν καταπληκτικά και είχαν κάτι το ξεχωριστό.
Ο φίλος σου έστειλε τη λίστα με τα υλικά και σου είπε ότι το τελευταίο στοιχείο της λίστας είναι το "μυστικό συστατικό" που έκανε το γεύμα τόσο ξεχωριστό.
Τώρα θέλεις να προσθέσεις κι εσύ αυτό το μυστικό συστατικό στη συνταγή σου.

Γράψε μια συνάρτηση `addSecretIngredient` που δέχεται ως παραμέτρους δύο πίνακες με υλικά.
Η πρώτη παράμετρος είναι η λίστα που σου έστειλε ο φίλος σου και η δεύτερη είναι η λίστα υλικών της δικής σου συνταγής.
Η συνάρτηση θα πρέπει να προσθέσει το τελευταίο στοιχείο της λίστας του φίλου σου στο τέλος της δικής σου λίστας.
Ο πίνακας που αντιπροσωπεύει τη συνταγή σου θα πρέπει να τροποποιηθεί απευθείας και η συνάρτηση δε θα πρέπει να επιστρέφει τίποτα.
Ωστόσο, το πρώτο όρισμα δε θα πρέπει να τροποποιηθεί.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Κλιμάκωσε τη συνταγή

Οι ποσότητες που αναγράφονται στο βιβλίο μαγειρικής σου φτάνουν μόνο για δύο μερίδες λαζάνια.
Επειδή την επόμενη φορά θέλεις να μαγειρέψεις για περισσότερα άτομα, θέλεις να υπολογίσεις τις ποσότητες για διαφορετικό αριθμό μερίδων.

Υλοποίησε μια συνάρτηση `scaleRecipe` που παίρνει δύο παραμέτρους.

- Ένα αντικείμενο συνταγής που περιέχει τις ποσότητες που χρειάζονται για 2 μερίδες.
  Τη μορφή του αντικειμένου μπορείς να τη δεις στο παρακάτω παράδειγμα.
- Τον αριθμό των μερίδων που θέλεις να μαγειρέψεις.

Η συνάρτηση θα πρέπει να επιστρέφει ένα αντικείμενο συνταγής με τις ποσότητες που χρειάζονται για τον επιθυμητό αριθμό μερίδων.
Θέλεις όμως να κρατήσεις την αρχική συνταγή.
Αυτό σημαίνει ότι σε αυτή την εργασία το όρισμα της συνταγής δε θα πρέπει να τροποποιηθεί.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
