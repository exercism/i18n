# Παράρτημα οδηγιών

## Υποδείξεις

Για αυτή την άσκηση, οι παρακάτω δυνατότητες της F# θα σου φανούν χρήσιμες:

- [BigInt](https://docs.microsoft.com/en-us/dotnet/api/system.numerics.biginteger?view=net-5.0)
- [Seq.sumBy](https://fsharp.github.io/fsharp-core-docs/reference/fsharp-collections-seqmodule.html#sumBy) είναι ένας συνοπτικός τρόπος για να εφαρμόσεις μια συνάρτηση σε μια ακολουθία και μετά να αθροίσεις τα αποτελέσματα
