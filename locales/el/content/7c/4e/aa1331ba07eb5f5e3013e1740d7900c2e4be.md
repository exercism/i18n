# Σχετικά

Η C# είναι μια στατικά τυποποιημένη γλώσσα, που σημαίνει ότι τα πάντα έχουν έναν τύπο κατά τον χρόνο μεταγλώττισης. Η επιλογή ενός ονόματος για μια [μεταβλητή][variable] αναφέρεται ως ορισμός μεταβλητής. Μόλις οριστεί μια μεταβλητή, ο καθορισμός ή η ενημέρωση μιας τιμής ονομάζεται ανάθεση μεταβλητής. Μια μεταβλητή μπορεί να οριστεί είτε καθορίζοντας ρητά τον τύπο της, είτε χρησιμοποιώντας τη [λέξη-κλειδί `var`][var] ώστε ο μεταγλωττιστής της C# να συμπεράνει τον τύπο της με βάση την τιμή που ανατίθεται. Η χρήση του `var` είναι γνωστή ως _εξαγωγή τύπου_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Η τιμή μιας μεταβλητής μπορεί να ανατεθεί και να ενημερωθεί χρησιμοποιώντας τον [τελεστή `=`][assignment]. Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Η C# είναι μια αντικειμενοστρεφής γλώσσα και απαιτεί όλες οι [συναρτήσεις][function] να ορίζονται μέσα σε μια _κλάση_, οι οποίες ορίζονται χρησιμοποιώντας τη [λέξη-κλειδί `class`][classes]. Τα αντικείμενα (ή _στιγμιότυπα_) δημιουργούνται χρησιμοποιώντας τη λέξη-κλειδί `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Μια συνάρτηση μέσα σε μια κλάση αναφέρεται ως _μέθοδος_. Κάθε [μέθοδος][methods] μπορεί να έχει μηδέν ή περισσότερες παραμέτρους. Όλες οι παράμετροι πρέπει να έχουν ρητό τύπο, δεν υπάρχει εξαγωγή τύπου για τις παραμέτρους. Παρομοίως, ο τύπος επιστροφής πρέπει επίσης να είναι ρητός. Οι τιμές επιστρέφονται από τις μεθόδους χρησιμοποιώντας τη [λέξη-κλειδί `return`][return]. Για να μπορεί μια μέθοδος να καλείται από κώδικα σε άλλα αρχεία, πρέπει να προστεθεί ο τροποποιητής πρόσβασης `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Οι μέθοδοι καλούνται χρησιμοποιώντας τη σύνταξη με τελεία (`.`) σε ένα στιγμιότυπο, καθορίζοντας το όνομα της μεθόδου που θα κληθεί και περνώντας ορίσματα για κάθε παράμετρο της μεθόδου. Τα ορίσματα μπορούν προαιρετικά να καθορίσουν το όνομα της αντίστοιχης παραμέτρου.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Αν η μέθοδος που θα κληθεί ορίζεται στην ίδια κλάση με τη μέθοδο που την καλεί, το όνομα της κλάσης μπορεί να παραληφθεί.

Αν μια μέθοδος δεν χρησιμοποιεί καμία _κατάσταση_ αντικειμένου, η μέθοδος μπορεί να γίνει _στατική_ χρησιμοποιώντας τον τροποποιητή `static`. Οι στατικές μέθοδοι καλούνται επίσης χρησιμοποιώντας τη σύνταξη με τελεία (`.`), αλλά καλούνται στην ίδια την κλάση αντί σε ένα στιγμιότυπο της κλάσης.

Αν μια κλάση έχει μόνο στατικές μεθόδους, μπορεί και αυτή να γίνει στατική χρησιμοποιώντας τον τροποποιητή `static`. Αυτό εκφράζει την πρόθεση της κλάσης.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

Η εμβέλεια στη C# ορίζεται μεταξύ των χαρακτήρων `{` και `}`.

Η C# υποστηρίζει δύο τύπους [σχολίων][comments]. Τα σχόλια μονής γραμμής προηγούνται από `//` και τα σχόλια πολλαπλών γραμμών εισάγονται μεταξύ `/*` και `*/`.

Οι ακέραιες τιμές ορίζονται ως ένα ή περισσότερα (συνεχόμενα) ψηφία και υποστηρίζουν τους [προεπιλεγμένους μαθηματικούς τελεστές][operators].

Ένα όνομα μεταβλητής [πρέπει να ακολουθεί κάποιους κανόνες][identifier-names], όπως να ξεκινά είτε με γράμμα είτε με κάτω παύλα, και [θα πρέπει να ακολουθεί τη σύμβαση ονοματοδοσίας της C#][naming-guidelines]. Αν ένα όνομα μεταβλητής συγκρούεται με μια δεσμευμένη [λέξη-κλειδί της C#][csharp-keywords], πρέπει να γίνει διαφυγή του χρησιμοποιώντας το `@`. Η χρήση αυτού του συμβολισμού δεν συνιστάται, αλλά μπορεί να συναντηθεί σε εξαιρετικές περιπτώσεις, για παράδειγμα: `var @this`, `var @class` ή `var @var`.

Υπάρχουν μερικές έννοιες που είναι τόσο θεμελιώδεις για μια γλώσσα της οικογένειας της C, όπως η C#, ώστε εμφανίζονται φυσικά σε σχεδόν κάθε μη τετριμμένο κομμάτι κώδικα. Αυτές είναι η [μεταβολή][mutation] και η [εμβέλεια][scope]. Η μεταβολή είναι η ιδέα ότι μια μεταβλητή μπορεί να αλλάξει την τιμή της κατά τη διάρκεια ζωής ενός προγράμματος. Η εμβέλεια είναι η ιδέα ότι η τιμή που σχετίζεται με ένα όνομα (ενός στοιχείου προγράμματος) είναι προσβάσιμη μόνο μέσα στην "περιοχή" κώδικα όπου ορίζεται. Οι κύριες περιοχές κώδικα στη C# είναι η _κλάση/struct_ και η _συνάρτηση_ (συνήθως μέθοδοι) αλλά μπορούν επίσης να περιλαμβάνουν τα σώματα βρόχων και άλλων δομών.
