# Οδηγίες

Ο Leslie, ο εξωγήινος της Lisp, πρέπει να κάνει κάποια ψώνια. Είναι πολύ σημαντικό να έχει μια λίστα αγορών. Πρέπει να μπορεί κανείς να προσθέτει πράγματα σε αυτήν και να αφαιρεί πράγματα από αυτήν.

Φυσικά, ένα απλό στυλό και χαρτί δεν αρκούν για έναν εξωγήινο της Lisp. Άλλωστε, το "List" είναι το μεγαλύτερο μέρος της λέξης "Lisp"! Πρέπει να υπάρχουν κάποιες συναρτήσεις γραμμένες που να βοηθούν στην παρακολούθηση των ψωνιών.

Μπορείς να βοηθήσεις τον Leslie να κρατάει τη λίστα αγορών;

## 1. Δημιουργία μιας νέας λίστας

Καταρχάς, ο Leslie πρέπει να δημιουργήσει μια κενή λίστα. Μια συνάρτηση με το όνομα `new-list` θα ήταν ιδανική γι' αυτό.

```lisp
(new-list) ; => ()
```

Ωχ όχι... Ο Leslie έχει ήδη στο μυαλό του μερικά πράγματα, οπότε χρειάζεται μια συνάρτηση που παίρνει τρία στοιχεία (ευτυχώς ο Leslie φτιάχνει λίστες με τρία μόνο στοιχεία. Ούτε περισσότερα, ούτε λιγότερα!) και δημιουργεί μια νέα λίστα αγορών με αυτά τα πράγματα. Γράψε μια συνάρτηση, τη `list-of-things`, η οποία παίρνει τρία στοιχεία και επιστρέφει μια λίστα με αυτά.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Προσθήκη πραγμάτων στη λίστα.

Πριν πάει στο κατάστημα, ο Leslie κοιτάζει στο ντουλάπι για να δει τι χρειάζεται. Βοήθησέ τον γράφοντας τη συνάρτηση `add-to-list`, η οποία προσθέτει ένα στοιχείο στην αρχή μιας λίστας.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. Ποιο είναι το επόμενο πράγμα (ή πράγματα) της λίστας;

Όταν κάνει ψώνια, ο Leslie θέλει να ξέρει τι να ψάξει μετά. Του αρέσει επίσης να ρίχνει μια ματιά πιο μπροστά στη λίστα για να δει το δεύτερο, το τρίτο ή ακόμα και το 23ο στοιχείο (τον τυχερό του αριθμό).

- Η `first-thing` θα αξιολογείται στο πρώτο πράγμα της λίστας
- Η `second-thing` θα αξιολογείται στο δεύτερο πράγμα
- Η `third-thing` θα αξιολογείται στο τρίτο πράγμα
- Η `twenty-third-thing` θα αξιολογείται στο εικοστό τρίτο πράγμα

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Αφαίρεση ενός πράγματος από τη λίστα

Ο Leslie θέλει να βρει το πρώτο στοιχείο της λίστας και να το αφαιρέσει από το ράφι. Βοήθησέ τον γράφοντας μια συνάρτηση `remove-first-item`, η οποία δίνει μια λίστα με όλα τα στοιχεία της λίστας εισόδου εκτός από το πρώτο.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Μεγαλύτερες λίστες από μικρότερες

Ο Leslie συνειδητοποίησε ότι κατά λάθος έφτιαξε δύο λίστες αγορών, όχι μία! Γράψε μια συνάρτηση, τη `list-append`, η οποία επιστρέφει μια λίστα με τα στοιχεία της πρώτης λίστας ακολουθούμενα από αυτά της δεύτερης λίστας.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. Πόσο ακόμα;

Ο Leslie αρχίζει να ανησυχεί ότι αυτή η εξόρμηση για ψώνια θα πάρει πολύ ώρα. Πόσα πράγματα έχει τελικά αυτή η λίστα; Γράψε μια συνάρτηση `just-how-long` που θα του πει πόσο μεγάλη είναι η λίστα του.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
