# Σχετικά

Τα [σύμβολα][symbols] είναι ονομασμένα αναγνωριστικά που μπορούν να χρησιμοποιηθούν για να αναφέρονται σε μια τιμή.
Τα σύμβολα δημιουργούνται μέσω ενός κυριολεκτικού συμβόλου, δηλαδή βάζοντας μπροστά από ένα όνομα τον χαρακτήρα `:`, π.χ. `:foo`.
Μπορούν επίσης να γραφτούν και με εισαγωγικά, π.χ. `:"foo"`, κάτι που επιτρέπει, για παράδειγμα, κενά στο όνομα.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Τα σύμβολα χρησιμοποιούνται σε πολλά σημεία της γλώσσας, μεταξύ άλλων ως κλειδιά σε namedtuples και για την αναπαράσταση ονομάτων μεθόδων και μεταβλητών.

## Τα σύμβολα στην Crystal

Τα σύμβολα στην Crystal είναι αρκετά διαφορετικά από αυτά της Ruby.
Στην Crystal, ένα σύμβολο είναι ένα είδος σταθεράς και γι' αυτό ορίζεται σε χρόνο μεταγλώττισης.
Αυτό σημαίνει ότι τα σύμβολα δε μπορούν να δημιουργηθούν δυναμικά, κάτι που είναι εφικτό στη Ruby.

Τα σύμβολα στην Crystal αναπαρίστανται ως `Int32` και αυτό τα κάνει πολύ αποδοτικά.

## Μετατροπή

Τα σύμβολα μπορούν να μετατραπούν σε συμβολοσειρές, αλλά όχι το αντίστροφο.
Αυτό συμβαίνει επειδή τα σύμβολα δημιουργούνται σε χρόνο μεταγλώττισης, ενώ οι συμβολοσειρές σε χρόνο εκτέλεσης.

```crystal
:foo.to_s # => "foo"
```
