# Υποδείξεις

Όλες αυτές οι εργασίες απαιτούν η γραμμή καταγραφής να χωριστεί σε ξεχωριστά μέρη.

- Δες τη συνάρτηση [`split()`][split] για τις διαθέσιμες επιλογές.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

- Η συνάρτηση `split()` επιστρέφει ένα διάνυσμα συμβολοσειρών.
- Πρέπει να πάρεις το κατάλληλο στοιχείο αυτού του διανύσματος.
- Τα κενά στην αρχή και στο τέλος μπορούν να αφαιρεθούν με τη συνάρτηση [`strip()`][strip].

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

- Η συνάρτηση [`lowercase()`][lowercase] είναι χρήσιμη εδώ.
- Μπορείς να πάρεις ένα τμήμα μιας συμβολοσειράς ASCII χρησιμοποιώντας ένα εύρος.
- Η θέση `end` αναφέρεται στο τελευταίο στοιχείο ενός διανύσματος.
- Εναλλακτικά, μπορείς να λύσεις την εργασία χρησιμοποιώντας τη συνάρτηση [`replace()`][replace] για να αφαιρέσεις ανεπιθύμητους χαρακτήρες.

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

- Η [παρεμβολή συμβολοσειρών][interpolation] είναι ίσως η πιο απλή προσέγγιση εδώ.
- Εναλλακτικά, κάποιοι (με εμπειρία από άλλες γλώσσες) μπορεί να προτιμήσουν τη συνάρτηση [`@sprintf()`][sprintf].
