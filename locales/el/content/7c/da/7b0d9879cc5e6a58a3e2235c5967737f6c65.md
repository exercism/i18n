# Εισαγωγή

Μια παράμετρος μεθόδου μπορεί να γίνει προαιρετική αν της εκχωρηθεί μια προεπιλεγμένη τιμή. Όταν καλείς μια μέθοδο με προαιρετικές παραμέτρους, δεν χρειάζεται να περάσεις τιμή για αυτές. Αν δεν περαστεί καμία τιμή για μια προαιρετική παράμετρο, θα χρησιμοποιηθεί η προεπιλεγμένη τιμή της.

Οι προαιρετικές παράμετροι πρέπει να βρίσκονται στο τέλος της λίστας παραμέτρων. Δεν μπορούν να ακολουθούνται από μη προαιρετικές παραμέτρους.

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

Η προαιρετική παράμετρος μπορεί να οριστεί σε `null` χρησιμοποιώντας τον τελεστή `?` πριν από το όνομα της μεταβλητής:

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
