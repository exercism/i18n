# Σχετικά

## Προαιρετικές τιμές

Η Swift χρησιμοποιεί [_προαιρετικές τιμές_][optionals] για να επιτρέπει στους προγραμματιστές να αναπαριστούν την πιθανή απουσία μιας τιμής.
Μια προαιρετική τιμή είναι ένας τύπος που μπορεί είτε να περιέχει μια τιμή είτε να είναι [`nil`][nil], το οποίο αντιπροσωπεύει την απουσία μιας τιμής.
Η χρήση μιας προαιρετικής τιμής απαιτεί από ένα πρόγραμμα να την ξετυλίξει πρώτα και να ελέγξει αν υπάρχει όντως μια τιμή πριν τη χρησιμοποιήσει.

Οποιοσδήποτε τύπος μπορεί να γίνει προαιρετικός, προσθέτοντας ένα `?` στο τέλος του ονόματος του τύπου.
Έτσι, ένας προαιρετικός ακέραιος θα είχε τύπο `Int?` και μια προαιρετική συμβολοσειρά θα είχε τύπο `String?`.
Ο ορισμός σταθερών ή μεταβλητών προαιρετικού τύπου και η ανάθεση τιμών σε αυτές γίνεται με τον ίδιο τρόπο όπως για τιμές μη προαιρετικών τύπων.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Μπορείς να αναθέσεις την απουσία μιας τιμής σε μια μεταβλητή προαιρετικού τύπου, αναθέτοντάς της την ειδική τιμή `nil`.
Το `nil` μπορεί να χρησιμοποιηθεί με όλους τους προαιρετικούς τύπους, αλλά τα `nil` που ανατίθενται σε δύο διαφορετικούς προαιρετικούς τύπους δεν έχουν τον ίδιο τύπο και δεν μπορούν να ανταλλαχθούν ή ακόμη και να συγκριθούν.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Σημείωσε επίσης ότι, παρόλο που το `nil` μπορεί να ανατεθεί σε οποιονδήποτε προαιρετικό τύπο, δεν μπορεί να ανατεθεί σε έναν μη προαιρετικό τύπο (ακόμη κι αν αυτός δεν περιέχει στην πραγματικότητα `nil`).
Και σε μια μέθοδο που περιμένει έναν μη προαιρετικό τύπο δεν μπορείς να περάσεις έναν προαιρετικό τύπο χωρίς να τον ξετυλίξεις πρώτα.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Χρήση προαιρετικών τιμών

Επειδή οι προαιρετικοί τύποι δεν είναι οι ίδιοι τύποι με τους βασικούς τους τύπους, οι δύο τύποι δεν μπορούν να χρησιμοποιηθούν με τους ίδιους τρόπους.
Για παράδειγμα: το `Int("123") + 1` προκαλεί το σφάλμα μεταγλωττιστή "Value of optional type 'Int?' must be unwrapped to a value of type 'Int'".
Αυτό συμβαίνει επειδή το `Int("123")` επιστρέφει έναν προαιρετικό τύπο `Int?`, όχι έναν τύπο `Int`, αφού αν η συμβολοσειρά δεν μπορεί να μετατραπεί σε ακέραιο, το αποτέλεσμα θα είναι `nil`.
Για να αποκτήσεις πρόσβαση στο `Int` από τη μετατροπή, πρέπει πρώτα να το "ξετυλίξεις".

Αυτό γίνεται συνήθως στη Swift χρησιμοποιώντας τις δομές `if-let` και `guard-let` για [_προαιρετική δέσμευση_][optional-binding], οι οποίες ελέγχουν για `nil` και ακολουθούν ένα μονοπάτι κώδικα με την ξετυλιγμένη τιμή δεσμευμένη σε ένα όνομα που δίνεις, αν υπάρχει τιμή, και ένα διαφορετικό μονοπάτι κώδικα αν βρεθεί `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Αξίζει να σημειωθεί ότι η μεταβλητή `safeNum` έχει τύπο `Int` και όχι `Int?`.
Στο παρακάτω παράδειγμα, το `num` είναι τύπου `Int?` και το `safeNum` είναι τύπου `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Αυτή η _προαιρετική δέσμευση_ είναι σημαντική επειδή ξετυλίγει (ή "αφαιρεί") τον προαιρετικό τύπο από την τιμή, επιτρέποντας να χρησιμοποιηθεί ως μη προαιρετική τιμή.
Αν απλώς έκανες έναν έλεγχο συνθήκης για το αν η τιμή είναι `nil`, η τιμή θα ήταν ακόμη προαιρετικού τύπου:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

Η επιλογή `guard-let` μπορεί επίσης να χρησιμοποιηθεί σε περιπτώσεις όπου επιθυμείς πρόωρη επιστροφή:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Σύγκριση προαιρετικών τιμών

Σημείωσε ότι, ακόμη κι αν ο βασικός τύπος ενός ζεύγους προαιρετικών τιμών μπορεί να συγκριθεί χρησιμοποιώντας τους συνηθισμένους τελεστές σύγκρισης, οι ίδιες οι προαιρετικές τιμές δεν μπορούν να συγκριθούν.
Μπορούν μόνο να ελεγχθούν ως προς την ισότητα.
Δύο προαιρετικές τιμές είναι ίσες αν είναι και οι δύο `nil` ή αν οι τιμές που τυλίγουν είναι ίσες στους βασικούς τους τύπους.

Ωστόσο, μπορεί να γραφτεί κώδικας που να εκτελεί μια προσαρμοσμένη σύγκριση δύο προαιρετικών τιμών.
Παρακάτω υπάρχει ένα παράδειγμα μιας εντολής `switch` που θα επιστρέψει `true` μόνο αν και οι δύο προαιρετικές τιμές δεν είναι `nil` και η πρώτη τιμή είναι μικρότερη από τη δεύτερη.
Για να το κάνει αυτό, χρησιμοποιεί το _προαιρετικό μοτίβο_ `varName?`, το οποίο ταιριάζει μόνο με προαιρετικές τιμές που δεν είναι `nil`, δεσμεύοντας την τιμή μέσα στην προαιρετική τιμή στο όνομα `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
