# Υποδείξεις

## Γενικά

- Υπάρχουν αρκετές διαθέσιμες συναρτήσεις στην τυπική βιβλιοθήκη για εκφράσεις Boolean. Ρίξε μια ματιά σε αυτές στον χώρο ονομάτων `Boolean` στο [Unison share](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/Boolean).
- Η δυνατότητα Each σου επιτρέπει να δουλεύεις με μια λίστα στοιχείων σαν να είναι ένα μόνο στοιχείο, εκτελώντας τη συνάρτηση που θέλεις στο "κάθε" στοιχείο. Μπορεί επίσης να χρησιμοποιηθεί για να δημιουργήσεις συνδυασμούς στοιχείων, καλώντας το Each σε δύο διαφορετικές λίστες.
- Ρίξε μια ματιά στη [συνάρτηση `guard` του `Each`](https://share.unison-lang.org/@unison/code/latest/namespaces/public/base/latest/;/types/abilities/Each). Μπορεί να σου φανεί χρήσιμη όταν θέλεις να επιστρέψεις κάτι υπό συνθήκη από τη δυνατότητα `Each`.
- Δεδομένου του αριθμού των μοναδικών συνδυασμών που είναι δυνατοί σε αυτό το πρόβλημα, μπορεί να αντιμετωπίσεις θέματα πολυπλοκότητας χώρου ή χρόνου. Υπάρχουν αρκετοί μηχανισμοί για τη βελτιστοποίηση της αναζήτησης. Ρίξε μια ματιά στους αλγόριθμους [backtracking](https://www.geeksforgeeks.org/backtracking-algorithms/) ή [branch and bound](https://www.geeksforgeeks.org/branch-and-bound-algorithm/?ref=lbp).
