# Ιστοσελίδα ομάδας μπάσκετ

## Σενάριο

Δουλεύεις πάνω σε μια ιστοσελίδα για μια ομάδα μπάσκετ. Η ιστοσελίδα εμφανίζει πολλά δεδομένα, αλλά δυστυχώς αυτό που εμφανίζεται αλλάζει συχνά. Καθώς τα δεδομένα είναι αποθηκευμένα σε ένα μόνο αντικείμενο, αυτό δεν είναι δύσκολο, αλλά είναι χρονοβόρο και βαρετό. Αποφάσισες λοιπόν να αυτοματοποιήσεις τα πράγματα.

## Εργασίες

Αυτά είναι παραδείγματα εργασιών που ταιριάζουν με το σενάριο του αυτοματισμού της ιστοσελίδας:

- Στόχος σου είναι να επιτρέψεις στην ομάδα περιεχομένου να επιλέγει η ίδια ποια δεδομένα θα εμφανίζονται. Θα το κάνουν ορίζοντας μια διαδρομή προς τα δεδομένα που θα εμφανιστούν στον επεξεργαστή περιεχομένου της ιστοσελίδας. Η εργασία σου είναι να δημιουργήσεις μια συνάρτηση extract που δέχεται ένα αντικείμενο και μια διαδρομή, χωρισμένα με τον χαρακτήρα της τελείας. Επίστρεψε την τιμή σε αυτή τη διαδρομή ή μια προεπιλεγμένη τιμή.

## Πρόσθετες εργασίες

Το σενάριο μπορεί να συνεχιστεί, για παράδειγμα:

- Η ομάδα περιεχομένου είναι πολύ ενθουσιασμένη με αυτή τη νέα λειτουργικότητα και έχει ήδη ζητήσει να προστεθεί μια νέα δυνατότητα. Θα ήθελαν να μπορούν να εμφανίζουν δεδομένα συγκεκριμένων στοιχείων σε έναν πίνακα.
