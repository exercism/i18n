# Εισαγωγή

Ενώ οι εκφράσεις `if/else` μπορούν να χρησιμοποιηθούν για την εκτέλεση υπό συνθήκη λογικής, η Haskell διαθέτει και έναν πιο ισχυρό τρόπο για να εκτελεί υπό συνθήκη λογική: την [αντιστοίχιση προτύπων][pattern-matching].
Με την αντιστοίχιση προτύπων, μια τιμή μπορεί να ελεγχθεί απέναντι σε ένα ή περισσότερα _πρότυπα_.
Ένα παράδειγμα τέτοιου προτύπου είναι το _σταθερό πρότυπο_, το οποίο αντιστοιχίζει μια τιμή με μια σταθερά (π.χ. `1` ή `"hello"`).

Όταν ορίζεις συναρτήσεις, μπορείς να ορίσεις ξεχωριστά σώματα συνάρτησης για διαφορετικά πρότυπα.
Αυτό οδηγεί σε καθαρό κώδικα που είναι απλός και ευανάγνωστος.
Μπορείς να κάνεις αντιστοίχιση προτύπων σε οποιονδήποτε τύπο δεδομένων, όπως αριθμούς, χαρακτήρες, λίστες, πλειάδες κ.λπ.

Για παράδειγμα, μια απλή συνάρτηση που παίρνει έναν ακέραιο (`Int`) και τον κάνει κατά _1_ πιο κοντά στο _0_ θα μπορούσε να εκφραστεί ως εξής:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

Η αντιστοίχιση προτύπων αρχίζει να λάμπει όταν χρησιμοποιείται μαζί με άλλα πρότυπα, για παράδειγμα το _πρότυπο μεταβλητής_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

Το παραπάνω παράδειγμα αντιμετωπίζει όλες τις εισόδους εκτός από το _0_ με τον ίδιο τρόπο και θα παρήγαγε λανθασμένα αποτελέσματα για αρνητικούς αριθμούς.
Αυτό μπορεί να λυθεί με τη χρήση υπό συνθήκη προτύπων, γνωστών ως _φρουρών_, που εκφράζονται με το σύμβολο `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

Στα παραπάνω παραδείγματα δεν έχουν όλες οι δυνατές είσοδοι ένα πρότυπο που να ταιριάζει.
Ο μεταγλωττιστής θα το εντοπίσει και θα εμφανίσει μια προειδοποίηση.
Αυτό είναι ένα πολύ χρήσιμο χαρακτηριστικό της Haskell που βοηθά να διασφαλίζεται ότι καλύπτονται όλα τα δυνατά μονοπάτια, ώστε να αποφεύγονται σφάλματα χρόνου εκτέλεσης.
Είναι γνωστό ως _εξαντλητικός έλεγχος_.
Για να λύσεις την προειδοποίηση, πρέπει να χειριστείς όλες τις περιπτώσεις.
Μέσα στους _φρουρούς_ μπορείς να χρησιμοποιήσεις την έκφραση `otherwise` ως συντακτική ζάχαρη για το `True`, ώστε να πιάσεις όλα τα υπόλοιπα πρότυπα.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

Η αντιστοίχιση προτύπων ελέγχει μια τιμή απέναντι σε κάθε πρότυπο από πάνω προς τα κάτω, μέχρι να βρει ένα πρότυπο που ταιριάζει και να εκτελέσει τη λογική που σχετίζεται με αυτό το πρότυπο.
**Η σειρά των προτύπων έχει σημασία!**
