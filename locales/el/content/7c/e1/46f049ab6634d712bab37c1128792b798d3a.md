# Σχετικά

Η C είναι μια γλώσσα γενικού σκοπού, που χρησιμοποιείται σε ένα ευρύ φάσμα εφαρμογών, από ενσωματωμένους υπολογιστές μέχρι συστάδες υπολογιστών υψηλών επιδόσεων.

Η C συναντάται συνήθως σε εφαρμογές χαμηλού επιπέδου, καθώς αποτελεί μια καλή εναλλακτική στις δυσανάγνωστες γλώσσες assembly. Μπορεί να μεταγλωττιστεί σε assembly ώστε να διατηρήσει το ίδιο επίπεδο απόδοσης, αυξάνοντας παράλληλα την αναγνωσιμότητα και προσφέροντας ένα μικρό επίπεδο ασφάλειας με τους στατικούς τύπους!

Η C δημιουργήθηκε από τον Dennis Ritchie στα Bell Labs και χρησιμοποιήθηκε για την επαναϋλοποίηση του λειτουργικού συστήματος Unix. Σήμερα είναι μία από τις πιο διαδεδομένες γλώσσες προγραμματισμού, με πολλούς μεταγλωττιστές να υποστηρίζουν το μεγαλύτερο μέρος του διαθέσιμου υλικού και των πλατφορμών. Υπάρχουν πολλοί διαθέσιμοι πόροι και υποστήριξη για να σε βοηθήσουν να ξεκινήσεις!
