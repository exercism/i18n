# Οδηγίες

Σε αυτή την άσκηση θα παίξεις με ένα τηλεκατευθυνόμενο αυτοκίνητο, για το οποίο τελικά μάζεψες αρκετά χρήματα για να το αγοράσεις.

Τα αυτοκίνητα ξεκινούν με πλήρεις (100%) μπαταρίες. Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο, διανύει 20 μέτρα και καταναλώνει ένα τοις εκατό της μπαταρίας. Το ψευδώνυμο του αυτοκινήτου δεν είναι γνωστό μέχρι να δημιουργηθεί.

Το τηλεκατευθυνόμενο αυτοκίνητο έχει μια εντυπωσιακή οθόνη LED που δείχνει δύο πληροφορίες:

- Τη συνολική απόσταση που έχει διανύσει, που εμφανίζεται ως: `"<METERS> meters"`.
- Το υπόλοιπο φορτίο της μπαταρίας, που εμφανίζεται ως: `"Battery at <PERCENTAGE>%"`.

Αν η μπαταρία είναι στο 0%, δεν μπορείς πια να οδηγήσεις το αυτοκίνητο και η ένδειξη της μπαταρίας θα δείχνει `"Battery empty"`.

## 1. Δημιούργησε ένα ολοκαίνουργιο τηλεκατευθυνόμενο αυτοκίνητο

Υλοποίησε τη συνάρτηση `RemoteControlCar.new/0` ώστε να επιστρέφει ένα ολοκαίνουργιο struct τηλεκατευθυνόμενου αυτοκινήτου:

```elixir
RemoteControlCar.new()
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "none"
#    }
```

Το ψευδώνυμο απαιτείται από το struct. Βεβαιώσου ότι αρχικοποιείται μια τιμή στη συνάρτηση `new`, αλλά όχι στο struct.

## 2. Δημιούργησε ένα ολοκαίνουργιο τηλεκατευθυνόμενο αυτοκίνητο με ψευδώνυμο

Υλοποίησε τη συνάρτηση `RemoteControlCar.new/1` ώστε να επιστρέφει ένα ολοκαίνουργιο struct τηλεκατευθυνόμενου αυτοκινήτου με ένα ψευδώνυμο που δίνεται:

```elixir
RemoteControlCar.new("Blue")
# => %RemoteControlCar{
#      battery_percentage: 100,
#      distance_driven_in_meters: 0,
#      nickname: "Blue"
#    }
```

## 3. Εμφάνισε την απόσταση

Υλοποίησε τη συνάρτηση `RemoteControlCar.display_distance/1` ώστε να επιστρέφει την απόσταση όπως εμφανίζεται στην οθόνη LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_distance(car)
# => "0 meters"
```

Βεβαιώσου ότι η συνάρτηση δέχεται ως όρισμα μόνο ένα struct `RemoteControlCar`.

## 4. Εμφάνισε το ποσοστό της μπαταρίας

Υλοποίησε τη συνάρτηση `RemoteControlCar.display_battery/1` ώστε να επιστρέφει το ποσοστό της μπαταρίας όπως εμφανίζεται στην οθόνη LED:

```elixir
car = RemoteControlCar.new()
RemoteControlCar.display_battery(car)
# => "Battery at 100%"
```

Βεβαιώσου ότι η συνάρτηση δέχεται ως όρισμα μόνο ένα struct `RemoteControlCar`. Αν η μπαταρία είναι στο 0%, η ένδειξη της μπαταρίας θα δείχνει "Battery empty".

## 5. Η οδήγηση αλλάζει τη μπαταρία και την απόσταση που διανύθηκε

Υλοποίησε τη συνάρτηση `RemoteControlCar.drive/1` που:

- αυξάνει κατά 20 τον αριθμό των μέτρων που διανύθηκαν
- καταναλώνει 1% της μπαταρίας

```elixir
RemoteControlCar.new("Red")
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 99,
#      distance_driven_in_meters: 20,
#      nickname: "Red"
#    }
```

Βεβαιώσου ότι η συνάρτηση δέχεται ως όρισμα μόνο ένα struct `RemoteControlCar`.

## 6. Λάβε υπόψη την οδήγηση με άδεια μπαταρία

Ενημέρωσε τη συνάρτηση `RemoteControlCar.drive/1` ώστε να μην αυξάνει την απόσταση που διανύθηκε ούτε να μη μειώνει το ποσοστό της μπαταρίας όταν η μπαταρία έχει αποφορτιστεί (στο 0%):

```elixir
%RemoteControlCar{
  battery_percentage: 0,
  distance_driven_in_meters: 1980,
  nickname: "Red"
}
|> RemoteControlCar.drive()

# => %RemoteControlCar{
#      battery_percentage: 0,
#      distance_driven_in_meters: 1980,
#      nickname: "Red"
#    }
```
