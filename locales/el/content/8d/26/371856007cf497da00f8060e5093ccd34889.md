# Οδηγίες

Εσύ και οι φίλοι σου λατρεύετε να παίζετε παιχνίδια ρόλων με χαρτί και μολύβι, αλλά παρατήρησες ότι είναι δύσκολο να έρθουν νέα άτομα στην παρέα σου. Συχνά δυσκολεύονται με τη δημιουργία χαρακτήρα. Δεν ξέρουν από πού να αρχίσουν. Για να βοηθήσεις τους νέους παίκτες, αποφάσισες να γράψεις ένα μικρό πρόγραμμα που θα τους καθοδηγεί στη διαδικασία.

## 1. Καλωσόρισε τον νέο παίκτη

Υλοποίησε τη συνάρτηση `RPG.CharacterSheet.welcome/0`. Θα πρέπει να εκτυπώνει ένα μήνυμα καλωσορίσματος και να επιστρέφει `:ok`.

```elixir
RPG.CharacterSheet.welcome()
# > Welcome! Let's fill out your character sheet together.
# => :ok
```

## 2. Ρώτησε το όνομα του χαρακτήρα

Υλοποίησε τη συνάρτηση `RPG.CharacterSheet.ask_name/0`. Θα πρέπει να εκτυπώνει μια ερώτηση, να περιμένει μια απάντηση και να επιστρέφει την απάντηση χωρίς κενά στην αρχή και στο τέλος.

```elixir
RPG.CharacterSheet.ask_name()
# > What is your character's name?
# < Mathilde
# => "Mathilde"
```

## 3. Ρώτησε την κλάση του χαρακτήρα

Υλοποίησε τη συνάρτηση `RPG.CharacterSheet.ask_class/0`. Θα πρέπει να εκτυπώνει μια ερώτηση, να περιμένει μια απάντηση και να επιστρέφει την απάντηση χωρίς κενά στην αρχή και στο τέλος.

```elixir
RPG.CharacterSheet.ask_class()
# > What is your character's class?
# < healer
# => "healer"
```

## 4. Ρώτησε το επίπεδο του χαρακτήρα

Υλοποίησε τη συνάρτηση `RPG.CharacterSheet.ask_level/0`. Θα πρέπει να εκτυπώνει μια ερώτηση, να περιμένει μια απάντηση και να επιστρέφει την απάντηση ως ακέραιο.

```elixir
RPG.CharacterSheet.ask_level()
# > What is your character's level?
# < 2
# => 2
```

## 5. Συνδύασε τα προηγούμενα βήματα σε ένα

Υλοποίησε τη συνάρτηση `RPG.CharacterSheet.run/0`. Θα πρέπει να καλωσορίζει τον νέο παίκτη, να ρωτάει το όνομα, την κλάση και το επίπεδο του χαρακτήρα και να επιστρέφει το φύλλο χαρακτήρα ως map. Θα πρέπει επίσης να εκτυπώνει το map με την ετικέτα "Your character".

```elixir
RPG.CharacterSheet.run()
# > Welcome! Let's fill out your character sheet together.
# > What is your character's name?
# < Mathilde
# > What is your character's class?
# < healer
# > What is your character's level?
# < 2
# > Your character: %{class: "healer", level: 2, name: "Mathilde"}
# => %{class: "healer", level: 2, name: "Mathilde"}
```
