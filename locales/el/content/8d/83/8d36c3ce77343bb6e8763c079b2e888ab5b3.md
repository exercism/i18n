# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο σου κάθε μέρα.

Αποφάσισες να πας την παρατήρηση πουλιών σε ένα νέο επίπεδο και να υλοποιήσεις μερικά εργαλεία που θα σε βοηθήσουν να παρακολουθείς και να επεξεργάζεσαι τα δεδομένα.

Έχεις επιλέξει να αποθηκεύσεις τα δεδομένα ως λίστα από ακέραιους αριθμούς.
Ο πρώτος αριθμός στη λίστα είναι ο αριθμός των πουλιών που επισκέφτηκαν τον κήπο σου σήμερα, ο δεύτερος χθες, και ούτω καθεξής.

```exercism/note
Σε εφαρμογές του πραγματικού κόσμου, θα πρέπει πάντα να χρησιμοποιείς τα βασικά modules όποτε αυτό είναι εφικτό. Ωστόσο, για τον σκοπό της εκμάθησης της αναδρομής, μη χρησιμοποιήσεις καμία από τις συναρτήσεις της `List` σε αυτή την άσκηση.
```

## 1. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

Υλοποίησε τη συνάρτηση `today`.
Θα πρέπει να δέχεται μια λίστα με τους ημερήσιους αριθμούς πουλιών και να επιστρέφει τον σημερινό αριθμό.
Αν η λίστα είναι κενή, θα πρέπει να επιστρέφει `Nothing`, αλλιώς ο αριθμός θα είναι τυλιγμένος σε ένα `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Αύξησε τον σημερινό αριθμό

Υλοποίησε τη συνάρτηση `incrementDayCount`.
Θα πρέπει να δέχεται μια λίστα με τους ημερήσιους αριθμούς πουλιών και να αυξάνει τον σημερινό αριθμό κατά 1.
Αν η λίστα είναι κενή, επίστρεψε το `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη συνάρτηση `hasDayWithoutBirds`.
Θα πρέπει να δέχεται μια λίστα με τους ημερήσιους αριθμούς πουλιών.
Θα πρέπει να επιστρέφει `True` αν υπήρξε τουλάχιστον μία μέρα που κανένα πουλί δεν επισκέφτηκε τον κήπο, και `False` διαφορετικά.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Υπολόγισε τον συνολικό αριθμό επισκέψεων πουλιών

Υλοποίησε τη συνάρτηση `total`.
Θα πρέπει να δέχεται μια λίστα με τους ημερήσιους αριθμούς πουλιών και να επιστρέφει τον συνολικό αριθμό πουλιών που επισκέφτηκαν τον κήπο σου από τότε που ξεκίνησες να συλλέγεις τα δεδομένα.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Μερικές μέρες είναι πιο πολυάσχολες από άλλες.
Πολυάσχολη μέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.

Υλοποίησε τη συνάρτηση `busyDays`.
Θα πρέπει να δέχεται μια λίστα με τους ημερήσιους αριθμούς πουλιών και να επιστρέφει τον αριθμό των πολυάσχολων ημερών.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
