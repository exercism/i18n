# Σχετικά

Η Haxe είναι μια γλώσσα με ισχυρή τυποποίηση, αλλά το σύστημα τύπων μπορεί να παρακαμφθεί όπου χρειάζεται. Η ανάθεση μιας τιμής σε ένα όνομα ονομάζεται ορισμός μεταβλητής. Μια μεταβλητή μπορεί να οριστεί είτε δηλώνοντας ρητά τον τύπο της, είτε αφήνοντας τον μεταγλωττιστή της Haxe να συμπεράνει τον τύπο χρησιμοποιώντας τη [`var` λέξη-κλειδί](var). Επομένως, οι παρακάτω δύο ορισμοί μεταβλητής είναι ισοδύναμοι:

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

Η ενημέρωση μιας μεταβλητής μπορεί να γίνει με τον τελεστή `=`:

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

Ο μεταγλωττιστής θα πετάξει ένα σφάλμα όταν προσπαθήσεις να αναθέσεις μια τιμή της οποίας ο τύπος είναι διαφορετικός από αυτόν της μεταβλητής:

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

Στη Haxe, ο κώδικας γράφεται συνήθως μέσα σε μια _συνάρτηση_, που ονομάζεται επίσης [_μέθοδος_](method). Αυτές οι συναρτήσεις μπορούν να δέχονται παραμέτρους (ορίσματα) και να επιστρέφουν τιμές χρησιμοποιώντας τη λέξη-κλειδί `return`. Οι συναρτήσεις καλούνται με τη σύνταξη `()`. Όλες οι συναρτήσεις πρέπει να έχουν τύπο επιστροφής.

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

Η εμβέλεια στη Haxe ορίζεται μεταξύ των χαρακτήρων `{` και `}`.

Η Haxe υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μιας γραμμής προηγούνται από `//` και τα σχόλια πολλών γραμμών εισάγονται μεταξύ `/*` και `*/`.

[oop]: https://en.wikipedia.org/wiki/Object-oriented_programming
