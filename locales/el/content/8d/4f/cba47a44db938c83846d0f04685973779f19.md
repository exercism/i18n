# Εισαγωγή

Όλες οι συναρτήσεις στο [module `Enum`][exercism-enum] είναι _άμεσες_. Όταν εκτελείς πολλαπλές πράξεις πάνω σε απαριθμήσιμα με το module `Enum`, κάθε πράξη παράγει ένα ενδιάμεσο αποτέλεσμα.

Το module `Stream` είναι μια _οκνηρή_ εναλλακτική στο _άμεσο_ module `Enum`. Προσφέρει πολλές από τις ίδιες συναρτήσεις με το `Enum`, αλλά αντί να παράγει ενδιάμεσα αποτελέσματα, χτίζει μια σειρά υπολογισμών που εκτελούνται μόνο αφού το stream περαστεί σε μια συνάρτηση από το module `Enum`.

Τα streams υλοποιούν το _[πρωτόκολλο][exercism-protocols] Enumerable_ και είναι συνθέσιμα, δηλαδή μπορείς να τα συνδυάσεις μεταξύ τους σε αλυσίδα για να φτιάξεις πιο σύνθετη λειτουργικότητα.

[exercism-enum]: https://exercism.org/tracks/elixir/concepts/enum
[exercism-protocols]: https://exercism.org/tracks/elixir/concepts/protocols
