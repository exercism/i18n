# Βοήθεια

Παρακάτω θα βρεις μερικούς πόρους για να βρεις βοήθεια αν αντιμετωπίσεις κάποιο πρόβλημα:

- [Η κύρια ιστοσελίδα του project Futhark][main] φιλοξενεί [τεκμηρίωση][docs], [παραδείγματα][examples], μια [αναφορά γλώσσας][language-reference] και άλλα.
- Το [Parallel Programming in Futhark][book] είναι ένα βιβλίο που έχει σχεδιαστεί ως εισαγωγή στη γλώσσα.
- [Η κοινότητα του Exercism στο Discord][exercism-discord]
- Το κανάλι `#futhark` στο [Libera][libera]
- Το [κανάλι Gitter του futhark][gitter]
- Το [/r/futhark/][reddit] είναι ένα subreddit για γλώσσες τύπου APL.

Επιπλέον, το [StackOverflow][so] είναι ένα καλό μέρος για να αναζητήσεις το πρόβλημα ή την ερώτησή σου και να δεις αν έχει ήδη απαντηθεί.
Αν όχι, μπορείς πάντα να [ρωτήσεις][ask-so] ή να [απαντήσεις][answer-so] στην ερώτηση κάποιου άλλου.
