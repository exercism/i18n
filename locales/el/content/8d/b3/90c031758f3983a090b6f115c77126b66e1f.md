# Οδηγίες

Αναπτύσσεις ένα σύστημα διαχείρισης περιεχομένου για έναν ιστότοπο που φιλοξενεί άρθρα, αναρτήσεις ιστολογίου και άλλο γραπτό περιεχόμενο.
Σου έχει ανατεθεί να υλοποιήσεις έναν χειριστή εργασιών που θα επεξεργάζεται εργασίες σε μια ουρά προτεραιότητας.
Ο χειριστής εργασιών θα λαμβάνει εργασίες και, με βάση τον φόρτο του διακομιστή και την προτεραιότητά τους, θα αποφασίζει ποια εργασία θα εκτελέσει στη συνέχεια.
Αν ο διακομιστής είναι υπό μεγάλο φόρτο, τότε ο αριθμός προτεραιότητας πρέπει να είναι υψηλότερος για να εκτελεστεί η εργασία.
Ο διακομιστής θα αλλάζει δυναμικά τον φόρτο με βάση τον φόρτο.

## 1. Αρχικοποίησε τον `TaskHandler`

Ο TaskHandler πρέπει να αρχικοποιηθεί με μια ουρά και ένα προεπιλεγμένο load_level.

Υλοποίησε τον αρχικοποιητή της κλάσης `TaskHandler` που παίρνει ως όρισμα έναν `Array` από `String` με τα ονόματα των εργασιών και τον αποθηκεύει σε μια μεταβλητή στιγμιοτύπου με το όνομα `@tasks`.
Ο αρχικοποιητής θα πρέπει επίσης να δημιουργεί τη μεταβλητή στιγμιοτύπου `@task_condition_logic` που αποθηκεύει ένα `Proc` το οποίο παίρνει ένα `Int32` και επιστρέφει αληθής αν το όρισμα είναι ίσο ή μεγαλύτερο από το 0 και ψευδής αν είναι μικρότερο από το 0.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
# => #<TaskHandler:0x7fd8d4cfbf00 @tasks=["task1", "task2", "task3"], @task_condition_logic=#<Proc(Int32, Bool):0x562536a4a330>>
```

## 2. Ενημέρωσε τη λογική συνθήκης εργασιών

Ο διακομιστής πρέπει να μπορεί να ενημερώνει τη λογική συνθήκης εργασιών με βάση τον φόρτο του διακομιστή.

Υλοποίησε τη μέθοδο `TaskHandler#update_task_condition_logic` που παίρνει ένα μπλοκ ως όρισμα και το μπλοκ θα πρέπει να αποθηκεύεται στη μεταβλητή στιγμιοτύπου `@task_condition_logic`.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
task_handler.update_task_condition_logic { |load| load > 1 }
# => #<TaskHandler:0x7f068118cf00 @tasks=["task1", "task2", "task3"], @task_condition_logic=#<Proc(Int32, Bool):0x562df99d0370>>
```

## 3. Εκτέλεσε την επόμενη εργασία

Ο διακομιστής πρέπει να μπορεί να εκτελέσει την επόμενη εργασία στην ουρά.

Η πρώτη εργασία στον πίνακα `@tasks` είναι η επόμενη εργασία που θα εκτελεστεί.
Η εργασία θα πρέπει να εκτελείται αν το επίπεδο προτεραιότητας της δεδομένης εργασίας, όταν περαστεί στο proc `@task_condition_logic`, επιστρέφει αληθής.

Θα επιστρέφει μηνύματα ανάλογα με το αν η εργασία εκτελέστηκε ή όχι.
Αν η εργασία εκτελέστηκε, θα πρέπει να επιστρέφει: `"Completed <task>"`.
Αν η εργασία δεν εκτελέστηκε, θα πρέπει να επιστρέφει: `"Could not complete <task>"`.

Αν η εργασία εκτελέστηκε, θα πρέπει να αφαιρείται από τον πίνακα `@tasks`.

Υλοποίησε τη μέθοδο `TaskHandler#execute_next_task` που παίρνει ως όρισμα το επίπεδο προτεραιότητας της επόμενης εργασίας ως `Int32` και επιστρέφει ένα `String` ανάλογα με το αν η εργασία εκτελέστηκε ή όχι.

```crystal
task_handler = TaskHandler.new(["task1", "task2", "task3"])
task_handler.update_task_condition_logic { |load| load > 1 }
task_handler.execute_next_task(2)
# => "Completed task1"

task_handler.execute_next_task(1)
# => "Could not complete task2"
```
