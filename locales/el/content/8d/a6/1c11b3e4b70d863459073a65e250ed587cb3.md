# Οδηγίες

Μετέτρεψε έναν δυαδικό αριθμό, που αναπαρίσταται ως συμβολοσειρά (π.χ. '101010'), στο δεκαδικό του ισοδύναμο, ξεκινώντας από τις βασικές αρχές.

Υλοποίησε τη μετατροπή από δυαδικό σε δεκαδικό.
Δεδομένης μιας δυαδικής συμβολοσειράς εισόδου, το πρόγραμμά σου θα πρέπει να παράγει μια δεκαδική έξοδο.
Το πρόγραμμα θα πρέπει να χειρίζεται μη έγκυρες εισόδους.

## Σημείωση

- Υλοποίησε μόνος σου τη μετατροπή.
  Μην χρησιμοποιήσεις κάτι άλλο για να κάνει τη μετατροπή για σένα.

## Σχετικά με το δυαδικό σύστημα (βάση 2)

Το δεκαδικό είναι ένα σύστημα βάσης 10.

Ο αριθμός 23 στη δεκαδική γραφή μπορεί να γίνει κατανοητός ως ένας γραμμικός συνδυασμός δυνάμεων του 10:

- Το δεξιότερο ψηφίο πολλαπλασιάζεται με 10^0 = 1
- Το επόμενο ψηφίο πολλαπλασιάζεται με 10^1 = 10
- ...
- Το _n_-οστό ψηφίο πολλαπλασιάζεται με 10^_(n-1)_.
- Όλες αυτές οι τιμές αθροίζονται.

Έτσι: `23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

Το δυαδικό σύστημα είναι παρόμοιο, αλλά χρησιμοποιεί δυνάμεις του 2 αντί για δυνάμεις του 10.

Έτσι: `101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`.
