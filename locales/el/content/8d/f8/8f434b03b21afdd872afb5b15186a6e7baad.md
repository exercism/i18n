# Συνεισφέροντες

Οι Συνεισφέροντες του Exercism είναι οι άνθρωποι που βοηθούν στη δημιουργία των γλωσσικών διαδρομών και των εργαλείων του Exercism.

**Ο καθένας μπορεί να γίνει Συνεισφέρων στο Exercism**: δεν υπάρχουν προϋποθέσεις ή απαιτήσεις για να ξεκινήσεις, και καλωσορίζουμε ενεργά ανθρώπους από κάθε υπόβαθρο.
Πάνω από 4.000 άνθρωποι έχουν βοηθήσει στην κατασκευή του Exercism μέχρι σήμερα!

Υπάρχουν πολλοί διαφορετικοί τρόποι για να βοηθήσεις στο Exercism:

- Γράψε ασκήσεις
- Ανάπτυξε τις έννοιες μιας διαδρομής
- Βελτίωσε την τεκμηρίωση
- Κατασκεύασε εργαλεία που λείπουν (π.χ. Test Runners ή Code Analyzers)
- Διόρθωσε bugs
- Βελτίωσε το περιεχόμενο μιας διαδρομής.

...και πολλά άλλα.

Επισκέψου την αποκλειστική μας [ενότητα Συνεισφοράς](/contributing) για να δεις όλες τις εργασίες που χρειάζονται αυτή τη στιγμή.
