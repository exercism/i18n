# Οδηγίες

Ο φίλος σου ο Linus είναι μηχανοδηγός και οδηγεί εμπορικά τρένα ανάμεσα σε πόλεις.
Αν και είναι καταπληκτικός στο χειρισμό των τρένων, δεν τα καταφέρνει το ίδιο καλά με τα logistics ή τους υπολογιστές.
Θα ήθελε να ζητήσει τη βοήθειά σου στον προγραμματισμό για να οργανώσει τις λεπτομέρειες των τρένων και να διορθώσει λάθη στα δεδομένα των διαδρομών.

~~~~exercism/note
Αυτή η άσκηση θα μπορούσε εύκολα να λυθεί με slicing, indexing και διάφορες μεθόδους `Dict`.
Ωστόσο, θα θέλαμε να εξασκηθείς στο packing (δηλαδή slurping), στο unpacking (δηλαδή splatting) και στην πολλαπλή ανάθεση, λύνοντας καθεμία από τις παρακάτω εργασίες.
~~~~

## 1. Δημιούργησε ένα διάνυσμα με όλα τα βαγόνια

Ο φίλος σου καταγράφει το αναγνωριστικό (ID) κάθε βαγονιού, αλλά ποτέ δεν είναι σίγουρος πόσα βαγόνια θα χρειαστεί να επεξεργαστεί το σύστημα κάθε φορά.
Θα ήταν πολύ πιο εύκολο για το υπόλοιπο πρόγραμμα logistics αν αυτά τα δεδομένα ήταν πακεταρισμένα σε ένα ενιαίο `Vector`.

Υλοποίησε μια συνάρτηση `get_vector_of_wagons(args...)` που δέχεται έναν αυθαίρετο αριθμό αναγνωριστικών βαγονιών.
Κάθε αναγνωριστικό θα είναι ένας θετικός ακέραιος.
Στη συνέχεια, η συνάρτηση θα πρέπει να `return` τα δοσμένα αναγνωριστικά ως ένα μοναδικό `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Διόρθωσε το διάνυσμα με τα βαγόνια

Σε αυτό το σημείο, αρχίζεις να αποκτάς αίσθηση των δεδομένων και του τρόπου που χρησιμοποιούνται στο πρόγραμμα logistics.
Το σύστημα αναγνωριστικών αναθέτει πάντα στη μηχανή το αναγνωριστικό **1**, ενώ στα υπόλοιπα βαγόνια του τρένου ανατίθεται ένα τυχαία επιλεγμένο αναγνωριστικό μεγαλύτερο από **1**.

Ο φίλος σου έπρεπε να συνδέσει δύο νέα βαγόνια στο τρένο και ξέχασε να ενημερώσει το σύστημα!
Τώρα, τα δύο πρώτα βαγόνια στο `Vector` του τρένου πρέπει να μετακινηθούν στο τέλος, αλλιώς όλα θα είναι σε λάθος σειρά.

Για να γίνουν τα πράγματα πιο περίπλοκα, ο φίλος σου μόλις ανακάλυψε ένα δεύτερο `Vector` που φαίνεται να περιέχει αναγνωριστικά βαγονιών που λείπουν.
Το μόνο που θυμάται είναι ότι, μόλις μετακινηθούν τα νέα βαγόνια, τα αναγνωριστικά από αυτό το δεύτερο `Vector` θα πρέπει να τοποθετηθούν ακριβώς μετά την καθορισμένη μηχανή.

Ο Linus θα σου ήταν πραγματικά ευγνώμων αν διόρθωνες τα λάθη του και ενοποιούσες τα δεδομένα.

Υλοποίησε μια συνάρτηση `fix_vector_of_wagons(each_wagons_id, missing_wagons)` που δέχεται δύο `Vector` που περιέχουν αναγνωριστικά βαγονιών.
Θα πρέπει να μετακινήσει τα δύο πρώτα στοιχεία του πρώτου `Vector` στο τέλος και να εισάγει τις τιμές από το δεύτερο `Vector` πίσω (_στα δεξιά_) από το αναγνωριστικό της μηχανής (**1**).
Στη συνέχεια, η συνάρτηση θα πρέπει να `return` ένα `Vector` με τις τροποποιήσεις.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Πρόσθεσε τις στάσεις που λείπουν

Τώρα που όλα τα δεδομένα των βαγονιών είναι σωστά, ο Linus θα ήθελε να ενημερώσεις τις πληροφορίες δρομολόγησης του συστήματος.
Κατά μήκος μιας διαδρομής μεταφοράς, ένα τρένο μπορεί να κάνει στάσεις σε μερικούς διαφορετικούς σταθμούς για να παραλάβει ή/και να αφήσει φορτίο.
Κάθε ταξίδι μπορεί να έχει διαφορετικό αριθμό από αυτά τα ενδιάμεσα σημεία παράδοσης.
Ο φίλος σου θα ήθελε να ενημερώσεις το `Dict` δρομολόγησης του συστήματος με οποιεσδήποτε πληροφορίες παράδοσης λείπουν ή είναι επιπλέον.

Υλοποίησε μια συνάρτηση `add_missing_stops(route, stops...)` που δέχεται ένα `Dict` δρομολόγησης ακολουθούμενο από μεταβλητό αριθμό ζευγών `stop_number => city`.
Στη συνέχεια, η συνάρτηση θα πρέπει να επιστρέψει το `Dict` δρομολόγησης ενημερωμένο με ένα επιπλέον `key` που περιέχει ένα `Vectors` με όλες τις στάσεις που προστέθηκαν, με τη σειρά.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

Ο Linus δουλεύει πάνω στο πρόγραμμα δρομολόγησης και παρατήρησε ότι σε ορισμένες διαδρομές λείπουν μερικές σημαντικές λεπτομέρειες.
Οι αρχικές πληροφορίες διαδρομής έχουν κατασκευαστεί ως `Dict` και ο φίλος σου θα ήθελε να ενημερώσεις αυτό το `Dict` με ό,τι μπορεί να λείπει.
Κάθε διαδρομή στο σύστημα απαιτεί ελαφρώς διαφορετικές λεπτομέρειες, οπότε ο Linus θα προτιμούσε πραγματικά μια γενική λύση.

Υλοποίησε μια συνάρτηση με το όνομα `extend_route_information(route; more_route_information...)` που δέχεται ένα `Dict` το οποίο περιέχει τις πόλεις προέλευσης και προορισμού μεταξύ των οποίων εκτελείται η διαδρομή του τρένου, καθώς και μεταβλητό αριθμό ορισμάτων με λέξεις-κλειδιά που περιέχουν λεπτομέρειες δρομολόγησης, όπως την ταχύτητα του τρένου, το μήκος ή τη θερμοκρασία.
Η συνάρτηση θα πρέπει να επιστρέψει ένα ενοποιημένο `Dict` με όλες τις πληροφορίες δρομολόγησης.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
