# Οδηγίες

Με δεδομένη μια συμβολοσειρά ψηφίων, υπολόγισε το μεγαλύτερο γινόμενο για μια συνεχόμενη υποσυμβολοσειρά ψηφίων μήκους n.

Για παράδειγμα, για την είσοδο `'1027839564'`, το μεγαλύτερο γινόμενο για μια σειρά 3 ψηφίων είναι 270 (9 * 5 * 6), και το μεγαλύτερο γινόμενο για μια σειρά 5 ψηφίων είναι 7560 (7 * 8 * 3 * 9 * 5).

Σημείωσε ότι αυτές οι σειρές χρειάζεται μόνο να καταλαμβάνουν *γειτονικές θέσεις* στην είσοδο· τα ψηφία δεν χρειάζεται να είναι *αριθμητικά διαδοχικά*.

Για την είσοδο `'73167176531330624919225119674426574742355349194934'`, το μεγαλύτερο γινόμενο για μια σειρά 6 ψηφίων είναι 23520.
