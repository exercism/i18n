# Εισαγωγή

Όλος ο κώδικας της Common Lisp αποτελείται από S-Expressions (Symbolic Expressions). Συντομογραφικά ονομάζονται sexprs. Κάθε sexpr είναι είτε ένα άτομο είτε ένα cons. Όταν οι S-Expressions αξιολογούνται, επιστρέφουν αυτόματα κάποια τιμή, η οποία παίρνει τη θέση της έκφρασης. Όταν γράφεις τις δικές σου συναρτήσεις (χρησιμοποιώντας `defun`), η τελευταία τιμή μέσα στο σώμα της `defun` επιστρέφεται αυτόματα:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```
