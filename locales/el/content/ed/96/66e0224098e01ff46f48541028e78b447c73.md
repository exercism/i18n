# Σχετικά

Η [Clojure](http://clojure.org) είναι μια δυναμική γλώσσα προγραμματισμού που στοχεύει την Εικονική Μηχανή Java (JVM).
Σχεδιασμένη ως γλώσσα γενικού σκοπού, η Clojure συνδυάζει την προσιτότητα μιας γλώσσας σεναρίων με μια ισχυρή υποδομή για πολυνηματικό προγραμματισμό.

Η Clojure είναι κατά κύριο λόγο μια συναρτησιακή γλώσσα προγραμματισμού και διαθέτει ένα πλούσιο σύνολο από αμετάβλητες, επίμονες [δομές δεδομένων](http://clojure.org/data_structures).

Η Clojure είναι ανοιχτού κώδικα, και πληροφορίες για το πώς μπορείς να συνεισφέρεις στη γλώσσα [βρίσκονται εδώ](http://clojure.org/contributing).

Ο Rich Hickey, ο δημιουργός της Clojure, ήθελε μια σύγχρονη Lisp για συναρτησιακό προγραμματισμό, που να συμβιώνει με την καθιερωμένη πλατφόρμα Java και να είναι σχεδιασμένη για ταυτοχρονισμό. Έτσι γεννήθηκε η Clojure.

Ακολουθούν δύο αποφθέγματα που αποτυπώνουν τους στόχους της Clojure:

* _Το καλό σχέδιο δεν έχει να κάνει με το να κάνεις μεγαλεπήβολα σχέδια, αλλά με το να αποσυναρμολογείς τα πράγματα._
* _Ο προγραμματισμός δεν έχει να κάνει με το να πληκτρολογείς... έχει να κάνει με το να σκέφτεσαι._
