# Σχετικά

Μια [εντολή `switch`][switch] σου επιτρέπει να συγκρίνεις μια τιμή με πολλαπλές πιθανές τιμές που ταιριάζουν.
Σου επιτρέπει να γράψεις πιο συνοπτικό κώδικα από το να χρησιμοποιείς πολλαπλές εντολές `else-if`.
Μια εντολή `switch` ξεκινά με τη λέξη-κλειδί `switch` ακολουθούμενη από την τιμή που θα συγκριθεί.
Στη συνέχεια, μπορείς να ορίσεις τις περιπτώσεις χρησιμοποιώντας τη λέξη-κλειδί `case` ακολουθούμενη από την τιμή με την οποία θα συγκριθεί.
Η λέξη-κλειδί `default` χρησιμοποιείται για να ορίσεις την προεπιλεγμένη περίπτωση όταν καμία από τις περιπτώσεις δεν ταιριάζει.
Όπως και οι εντολές `else-if`, οι εντολές `switch` εκτελούν μόνο το μπλοκ κώδικα που σχετίζεται με την πρώτη περίπτωση που ταιριάζει.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Δες το παρακάτω παράδειγμα:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Αυτό θα μπορούσε αντ' αυτού να γραφτεί ως:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
