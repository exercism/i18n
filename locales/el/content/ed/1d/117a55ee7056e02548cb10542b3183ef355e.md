# Εισαγωγή

Οι συναρτήσεις αντιμετωπίζονται ως πολίτες πρώτης κατηγορίας στην Elixir. Αυτό σημαίνει ότι:

- Επώνυμες και ανώνυμες συναρτήσεις μπορούν να ανατεθούν σε μεταβλητές.
- Επώνυμες και ανώνυμες συναρτήσεις μπορούν να περάσουν από εδώ και από εκεί σαν δεδομένα, ως ορίσματα και ως τιμές επιστροφής.
- Οι ανώνυμες συναρτήσεις μπορούν να δημιουργηθούν δυναμικά.

Οι ανώνυμες συναρτήσεις, σε αντίθεση με τις επώνυμες, δεν έχουν κάποια στατική αναφορά διαθέσιμη σε αυτές, είναι διαθέσιμες μόνο αν ανατεθούν σε μια μεταβλητή ή αν κληθούν αμέσως.

Μπορεί να χρησιμοποιήσουμε ανώνυμες συναρτήσεις για να:

- Κρύψουμε δεδομένα χρησιμοποιώντας λεξική εμβέλεια (γνωστή και ως κλείσιμο).
- Δημιουργήσουμε συναρτήσεις δυναμικά, σε χρόνο εκτέλεσης.

Οι ανώνυμες συναρτήσεις ξεκινούν με τη λέξη-κλειδί `fn`, τα ορίσματα χωρίζονται από το σώμα της συνάρτησης με το σύμβολο `->`, και τελειώνουν με ένα `end`. Όπως και στις επώνυμες συναρτήσεις, η τελευταία έκφραση της συνάρτησης _επιστρέφεται έμμεσα_ στη συνάρτηση που την κάλεσε.

Για να καλέσεις μια αναφορά συνάρτησης, πρέπει να βάλεις ένα `.` ανάμεσα στη μεταβλητή της αναφοράς και τη λίστα των ορισμάτων:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Μπορείς μάλιστα να χρησιμοποιήσεις τη συντομευμένη σημειογραφία σύλληψης για να το κάνεις πιο σύντομο:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
