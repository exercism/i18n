# πρόταση αφαίρεσης του `extern crate`

Σκέψου να αφαιρέσεις το `extern crate`, καθώς [δεν χρειάζεται πλέον](https://doc.rust-lang.org/stable/edition-guide/rust-2018/module-system/path-clarity.html#no-more-extern-crate) στην έκδοση 2018 της Rust, την οποία οι ασκήσεις της διαδρομής Rust είναι ρυθμισμένες να χρησιμοποιούν.
