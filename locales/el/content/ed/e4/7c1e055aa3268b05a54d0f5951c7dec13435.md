# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων. Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (εκτός λειτουργίας) μέχρι `10` (μέγιστη).

Στη χαμηλότερη ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα την ώρα. Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα. Έτσι, με την ταχύτητα στο `4`, θα πρέπει να παράγει `4 * 221 = 884` αυτοκίνητα την ώρα. Ωστόσο, οι υψηλότερες ταχύτητες αυξάνουν την πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία μετά πρέπει να απορρίπτονται. Ο παρακάτω πίνακας δείχνει πώς η ταχύτητα επηρεάζει το ποσοστό επιτυχίας:

- `1` έως `4`: 100% ποσοστό επιτυχίας.
- `5` έως `8`: 90% ποσοστό επιτυχίας.
- `9` και `10`: 77% ποσοστό επιτυχίας.

Έχεις δύο εργασίες.

## 1. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Γράψε μια μέθοδο που υπολογίζει τον ρυθμό παραγωγής της γραμμής συναρμολόγησης ανά ώρα, λαμβάνοντας υπόψη το ποσοστό επιτυχίας της:

```rust
assembly_line::production_rate_per_hour(6)
// Returns: 1193.4
```

Σημείωσε ότι η τιμή επιστροφής είναι `f64`.

## 2. Υπολόγισε τον αριθμό των λειτουργικών αυτοκινήτων που παράγονται ανά λεπτό

Γράψε μια μέθοδο που υπολογίζει πόσα λειτουργικά αυτοκίνητα παράγονται ανά λεπτό:

```rust
assembly_line::working_items_per_minute(6)
// Returns: 19
```

Σημείωσε ότι η τιμή επιστροφής είναι `u32`.
