# Πρόσθεσε τις αρχικές ασκήσεις

Αφού υλοποιήσεις την άσκηση `hello-world`, η επόμενη δουλειά είναι να υλοποιήσεις άλλες 20+ ασκήσεις.

## Τύποι ασκήσεων

Μπορείς να υλοποιήσεις δύο τύπους ασκήσεων:

- Ασκήσεις Εννοιών: είναι σχεδιασμένες να διδάσκουν μία ή περισσότερες έννοιες σε έναν μαθητή. Ρίξε μια ματιά στην [τεκμηρίωση](/docs/building/tracks/concept-exercises) για περισσότερες πληροφορίες.
- Ασκήσεις Εξάσκησης: είναι σχεδιασμένες για να εξασκείς έννοιες που έχεις μάθει. Ρίξε μια ματιά στην [τεκμηρίωση](/docs/building/tracks/practice-exercises) για περισσότερες πληροφορίες.

Γενικά, προτείνουμε τα νέα tracks να ξεκινούν υλοποιώντας Ασκήσεις Εξάσκησης, καθώς είναι πιο εύκολες στην υλοποίηση και απαιτούν λιγότερη προκαταρκτική σκέψη.
Οι Ασκήσεις Εννοιών μπορούν πάντα να προστεθούν αργότερα, μόλις το track σου λειτουργεί σωστά.

## Διάλεξε ασκήσεις

Για να βοηθήσουμε τα tracks να υλοποιήσουν Ασκήσεις Εξάσκησης, φτιάξαμε το [αποθετήριο exercism/problem-specifications](https://github.com/exercism/problem-specifications).
Αυτό το αποθετήριο περιέχει [μεταδεδομένα για πάνω από 100 Ασκήσεις Εξάσκησης](https://github.com/exercism/problem-specifications/tree/main/exercises), τα οποία διαφορετικά tracks μπορούν να χρησιμοποιήσουν για να υλοποιήσουν τη δική τους εκδοχή αυτών των ασκήσεων.
Γι' αυτόν τον λόγο, θα δεις τις ίδιες ασκήσεις υλοποιημένες σε πολλά διαφορετικά tracks.

Πώς όμως διαλέγεις τις 20+ από αυτή τη λίστα με τις 100+ ασκήσεις;
Ορίστε μερικές κατευθυντήριες γραμμές.

### Διάλεξε ασκήσεις που κάνουν τους μαθητές να εξασκούν μια μεγάλη ποικιλία εννοιών

Υπάρχει μεγάλη ποικιλία στις έννοιες που χρησιμοποιούνται στις 100+ ασκήσεις.
Στόχευσε να υλοποιήσεις ασκήσεις που κάνουν τους μαθητές να εξασκούν μια μεγάλη ποικιλία εννοιών.
Έτσι, αντί να υλοποιήσεις 20 ασκήσεις που επικεντρώνονται στις συμβολοσειρές, δοκίμασε να υλοποιήσεις ασκήσεις που επικεντρώνονται σε διαφορετικές έννοιες.

### Διάλεξε ασκήσεις με διαφορετικούς βαθμούς δυσκολίας

Κάποιες ασκήσεις θα είναι πιο δύσκολο να υλοποιηθούν από άλλες.
Στόχευσε να υλοποιήσεις ασκήσεις με διαφορετικούς βαθμούς δυσκολίας: μερικές εύκολες, μερικές μέτριες και μερικές δύσκολες.

Το πόσο δύσκολη είναι μια άσκηση εξαρτάται από αρκετούς παράγοντες, όπως οι έννοιες που εμπλέκονται και η γλώσσα του track.
Μπορεί να βοηθήσει να δεις πώς μοιάζει η άσκηση σε άλλα tracks που την έχουν υλοποιήσει, ώστε να πάρεις μια καλύτερη αίσθηση του πώς θα μπορούσε να μοιάζει η υλοποίηση.

Ορίστε μερικοί βαθμοί δυσκολίας με ασκήσεις:

| Δυσκολία     | Ασκήσεις                                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Εύκολη       | [darts][darts], [gigasecond][gigasecond], [isogram][isogram], [leap][leap], [resistor-color][resistor-color], [space-age][space-age]                           |
| Μέτρια       | [allergies][allergies], [bob][bob], [meetup][meetup], [protein-translation][protein-translation], [raindrops][raindrops], [secret-handshake][secret-handshake] |
| Δύσκολη      | [alphametics][alphametics], [forth][forth], [react], [pov][pov], [zebra-puzzle][zebra-puzzle], [zipper][zipper]                                                |

### Διάλεξε ασκήσεις που ταιριάζουν στο track σου

Δεν ταιριάζουν όλες οι ασκήσεις στο track σου.
Καλό είναι να διαλέγεις μόνο τις ασκήσεις που ταιριάζουν στο track σου: καλύτερα να _μην_ υλοποιήσεις μια άσκηση παρά να υλοποιήσεις κάποια που δεν έχει νόημα.
Για παράδειγμα, η [άσκηση lens-person](https://github.com/exercism/problem-specifications/tree/main/exercises/lens-person) βάζει τον μαθητή να δουλέψει με _φακούς_, τους οποίους δεν υποστηρίζουν πολλές γλώσσες.

Αν βρεις μια άσκηση που δεν ταιριάζει στο track σου, μπορείς να προσθέσεις το slug της στον πίνακα `exercises.foregone` στο [αρχείο config.json του track](/docs/building/tracks/config-json).
Έτσι, τα εργαλεία θα αγνοούν αυτή την άσκηση.

## Υλοποίησε τις ασκήσεις

Αφού διάλεξες τις ασκήσεις που θέλεις να συμπεριλάβεις στο track σου, το επόμενο βήμα είναι να τις υλοποιήσεις.
Η [τεκμηρίωση για την προσθήκη Άσκησης Εξάσκησης](/docs/building/tracks/practice-exercises/add) περιέχει λεπτομερείς οδηγίες για το πώς να προσθέσεις μια Άσκηση Εξάσκησης.
