# Εισαγωγή

Οι συναρτήσεις στην Python είναι αντικείμενα πρώτης κατηγορίας, που σημαίνει ότι μπορούν επίσης να περαστούν ως ορίσματα σε άλλες συναρτήσεις.
Οι διακοσμητές είναι [συναρτήσεις ανώτερης τάξης][hofunc] που παίρνουν ως όρισμα μια άλλη συνάρτηση και την επιστρέφουν αφού επεκτείνουν ή τροποποιήσουν τη συμπεριφορά της.
Οι διακοσμητές ορίζονται με τον ίδιο τρόπο όπως κάθε άλλη συνάρτηση, αλλά εφαρμόζονται στη γραμμή πάνω από τις συναρτήσεις που διακοσμούν, χρησιμοποιώντας το σύμβολο `@` πριν από τα ονόματά τους (`@my_decorator`). Παρόλο που μπορούν να δεχτούν πολλά ορίσματα, οι διακοσμητές πρέπει να δεχτούν _τουλάχιστον_ τη συνάρτηση που διακοσμούν ως όρισμα.

[hofunc]:https://en.wikipedia.org/wiki/Higher-order_function
