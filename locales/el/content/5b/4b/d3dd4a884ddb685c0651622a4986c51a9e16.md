# Υποδείξεις

## Γενικά

- Μπορείς να ολοκληρώσεις όλες αυτές τις εργασίες χωρίς να χρησιμοποιήσεις την εντολή `if`.

## 1. Προσδιόρισε αν θα χρειαστείς άδεια οδήγησης

- Χρησιμοποίησε τον [τελεστή ισότητας][cmp] για να ελέγξεις αν το πρώτο πεδίο ισούται με μια συγκεκριμένη συμβολοσειρά.
- Χρησιμοποίησε μια κανονική έκφραση για να ελέγξεις αν το δεύτερο πεδίο περιέχει τις απαιτούμενες υποσυμβολοσειρές.
- Χρησιμοποίησε έναν από τους δύο [Boolean τελεστές][bool] για να συνδυάσεις τις δύο προϋποθέσεις.

## 2.Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

- Χρησιμοποίησε τους [τελεστές σύγκρισης][cmp] για να προσδιορίσεις ποια έκπτωση θα χρησιμοποιήσεις.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
