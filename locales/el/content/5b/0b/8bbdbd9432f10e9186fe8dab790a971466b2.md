# Οδηγίες

Το νέο αεροδρόμιο στο Βερολίνο προσέλαβε προγραμματιστές για το εργαστήριο ρομπότ του και ξεκινάς τη δουλειά σου εκεί.
Έχουν αδέξια ρομπότ που μοιάζουν κάπως ανθρωπόμορφα και προσπαθούν να τα χρησιμοποιήσουν για να βελτιώσουν την εξυπηρέτηση πελατών.

Η πρώτη σου εργασία στη δουλειά είναι να γράψεις ένα πρόγραμμα ώστε το ρομπότ να μπορεί να χαιρετά τους ανθρώπους στη μητρική τους γλώσσα, αφού σκανάρουν τα διαβατήριά τους στο γκισέ του αυτόματου check-in.

Το ρομπότ είναι περήφανο για τις ικανότητές του, οπότε πάντα λέει πρώτα ποια γλώσσα μπορεί να μιλήσει και μετά χαιρετά τον άνθρωπο.
Για παράδειγμα, αν κάποιος σκανάρει ένα γερμανικό διαβατήριο, το ρομπότ θα πει:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Δημιούργησε την αφηρημένη λειτουργικότητα χαιρετισμού

Δεν θα γράψεις ο ίδιος τον κώδικα για τις διάφορες γλώσσες, οπότε πρέπει να δομήσεις τον κώδικα του ρομπότ έτσι ώστε άλλοι προγραμματιστές να μπορούν εύκολα να προσθέσουν κι άλλες γλώσσες αργότερα.

Ως πρώτο βήμα, όρισε μια διεπαφή `Greeter` με δύο μεθόδους.

- `LanguageName` που επιστρέφει το όνομα της γλώσσας (μία `string`) στην οποία το ρομπότ υποτίθεται ότι θα χαιρετήσει τον επισκέπτη.
- `Greet` που δέχεται το όνομα ενός επισκέπτη (μία `string`) και επιστρέφει μία `string` με το μήνυμα χαιρετισμού σε μια συγκεκριμένη γλώσσα.

Στη συνέχεια, υλοποίησε μια συνάρτηση `SayHello` που δέχεται ως ορίσματα το όνομα του επισκέπτη και οτιδήποτε υλοποιεί τη διεπαφή `Greeter` και επιστρέφει τη συμβολοσειρά χαιρετισμού που θέλεις.
Για παράδειγμα, φαντάσου μια γερμανική υλοποίηση του `Greeter` για την οποία το `LanguageName` επιστρέφει `"German"` και το `Greet` επιστρέφει `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Υλοποίησε τα ιταλικά

Τώρα η δουλειά σου είναι να κάνεις το ρομπότ να λειτουργεί για ανθρώπους που σκανάρουν ιταλικά διαβατήρια.

Για αυτό, δημιούργησε μια δομή `Italian` και υλοποίησε τις δύο μεθόδους που χρειάζονται ώστε η δομή να ικανοποιεί τη διεπαφή `Greeter` που όρισες στην εργασία 1.
Μπορείς να χαιρετήσεις κάποιον στα ιταλικά με `"Ciao {name}!"`.

## 3. Υλοποίησε τα πορτογαλικά

Πριν τελειώσεις τη μέρα σου, υποτίθεται ότι θα ολοκληρώσεις και τη λειτουργικότητα για να χαιρετάς ανθρώπους στα πορτογαλικά.

Για αυτό, δημιούργησε μια δομή `Portuguese` και υλοποίησε και εδώ τις δύο μεθόδους που χρειάζονται ώστε η δομή να ικανοποιεί τη διεπαφή `Greeter`.
Μπορείς να χαιρετήσεις κάποιον στα πορτογαλικά με `"Olá {name}!"`.
