# Υποδείξεις

## Γενικά

- Διάβασε για την [αντιστοίχιση προτύπων][pattern-matching] στον επίσημο οδηγό.
- Ρίξε μια ματιά σε αυτό το cheat-sheet για την [αποδόμηση][destructuring].
- Η αντιστοίχιση προτύπων για καταγραφές [εξηγείται εδώ][records-pattern-matching] με περισσότερες λεπτομέρειες.

## 1. Εντόπισε τα κενά σχόλια

- Μπορείς να χρησιμοποιήσεις το `(a, b)` απευθείας στο όρισμα της συνάρτησης, αν το όρισμα είναι ζεύγος.
- Μπορείς να αντικαταστήσεις τις τιμές που λαμβάνεις αλλά δεν χρησιμοποιείς με το wildcard `_`.
- Για να ελέγξεις αν μια συμβολοσειρά είναι κενή, δες την [τεκμηρίωση του `String`][string-docs].

## 2. Μέτρησε τον αριθμό των σχολίων από τον δημιουργό

- Μπορείς να αποδομήσεις έναν προσαρμοσμένο τύπο με μία μόνο παραλλαγή `type Box = Box AB` απευθείας σε ένα όρισμα συνάρτησης, έτσι: `(Box ab)`.
- Μπορείς να κάνεις αντιστοίχιση προτύπων στο πεδίο `a` μιας καταγραφής `{a : A, b : B}` χρησιμοποιώντας: `{ a }`.
- Μπορείς να χρησιμοποιήσεις και τις δύο παραπάνω τεχνικές ταυτόχρονα για προσαρμοσμένους τύπους που περιέχουν μια καταγραφή.
- Δεν μπορείς να κάνεις αντιστοίχιση προτύπων απευθείας στο ζεύγος `ab` από μια καταγραφή `{ ab : (A, B) }`. Πρέπει πρώτα να κάνεις αντιστοίχιση προτύπων στο `{ ab }` και μετά να χρησιμοποιήσεις το `( a, b) = ab` σε έναν δεσμό `let`.
- Για να βρεις τον αριθμό των στοιχείων που ικανοποιούν μια συνθήκη σε μια λίστα, χρησιμοποίησε τις [συναρτήσεις της `List`][list-docs].
- Μπορείς να αποδομήσεις ζεύγη απευθείας στα ορίσματα ανώνυμων συναρτήσεων.

## 3. Εντόπισε tickets που έχουν ανατεθεί στην ομάδα ανάπτυξης

- Όπως και στην Εργασία 2, μπορείς να αντιστοιχίσεις τα σχετικά πεδία μιας "boxed" καταγραφής στο όρισμα της συνάρτησης.
- Μπορείς να χρησιμοποιήσεις την αντιστοίχιση προτύπων αναδρομικά για να αντιστοιχίσεις μια εμφωλευμένη τιμή όπως το `Just (Box "42")`.
- Μπορείς να χρησιμοποιήσεις το wildcard `_` για να αντιστοιχίσεις οτιδήποτε σε μια εντολή `case`.

## 4. Ανάθεσε tickets σε υπαλλήλους πληροφορικής

- Όπως και στις Εργασίες 2 και 3, μπορείς να αντιστοιχίσεις τα σχετικά πεδία μιας "boxed" καταγραφής στο όρισμα της συνάρτησης.
- Επιπλέον, μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `as` για να κάνεις αντιστοίχιση προτύπων σε ένα πεδίο και ταυτόχρονα να δεσμεύσεις ολόκληρη την καταγραφή: `(Box ({ a } as ab))`.
- Μπορείς να κάνεις αντιστοίχιση προτύπων στις τιμές ενός προσαρμοσμένου τύπου με την εντολή `case`.
- Χρησιμοποίησε τον κατασκευαστή τύπου `Ticket` για να επιστρέψεις ένα ticket.
- Χρησιμοποίησε τη [σύνταξη ενημέρωσης καταγραφών][record-update] για να τροποποιήσεις καταγραφές.
