# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα που θα σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το μαγείρεμα των λαζάνια.

~~~~exercism/note
Μπορείς είτε να χρησιμοποιήσεις εξαγωγή τύπων, όπου δεν δηλώνεις κανέναν τύπο, είτε ρητή δήλωση τύπων, όπου δηλώνεις τους τύπους.
Αν επιλέξεις το δεύτερο, χρησιμοποίησε το `int` ως τύπο.
~~~~

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη δέσμευση `expectedMinutesInOven` για να ελέγξεις πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 40:

```fsharp
expectedMinutesInOven
// => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `remainingMinutesInOven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που τα λαζάνια είναι στον φούρνο και επιστρέφει πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```fsharp
remainingMinutesInOven 30
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparationTimeInMinutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```fsharp
preparationTimeInMinutes 2
// => 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsedTimeInMinutes` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και η δεύτερη παράμετρος είναι τα λεπτά που τα λαζάνια είναι στον φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα των λαζάνια, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο μέχρι στιγμής.

```fsharp
elapsedTimeInMinutes 3 20
// => 26
```
