# Οδηγίες

Σε αυτή την άσκηση θα γράψεις ένα γενικευμένο (/ μαγικό!) TreasureChest, για να αποθηκεύσεις λίγο θησαυρό.

## 1. Όρισε τον γενικευμένο προσαρμοσμένο τύπο TreasureChest

Όρισε έναν προσαρμοσμένο τύπο `TreasureChest` με μία μόνο παραλλαγή.

Η παραλλαγή θα πρέπει να έχει μια συσχετισμένη τιμή `String`, η οποία θα χρησιμοποιηθεί για την αποθήκευση του κωδικού πρόσβασης του σεντουκιού του θησαυρού.

Η παραλλαγή θα πρέπει επίσης να έχει μια συσχετισμένη γενικευμένη τιμή, η οποία θα χρησιμοποιηθεί για την αποθήκευση του θησαυρού.
Αυτή η τιμή είναι γενικευμένη, ώστε ο θησαυρός να μπορεί να είναι οτιδήποτε.

## 2. Όρισε τη συνάρτηση getTreasure

Αυτή η συνάρτηση θα πρέπει να δέχεται δύο παραμέτρους

- μια `String` (για να δοκιμάσεις έναν κωδικό πρόσβασης)
- έναν γενικευμένο προσαρμοσμένο τύπο `TreasureChest`

Αυτή η συνάρτηση θα πρέπει να ελέγχει την προσπάθεια κωδικού πρόσβασης που δίνεται με το `String` μέσα στο `TreasureChest`.

Η συνάρτηση θα πρέπει να επιστρέφει ένα `Maybe`.

Αν οι κωδικοί πρόσβασης ταιριάζουν, τότε επέστρεψε `Just` με τη γενικευμένη τιμή από το `TreasureChest` (τον θησαυρό!)

Αν οι κωδικοί πρόσβασης δεν ταιριάζουν, τότε επέστρεψε `Nothing`.

## 3. Όρισε τη συνάρτηση multiplyTreasure

Αυτή η (συνάρτηση ανώτερης τάξης) θα πρέπει να δέχεται δύο παραμέτρους

- μια συνάρτηση πολλαπλασιαστή που δέχεται μία γενικευμένη παράμετρο και επιστρέφει μια λίστα του ίδιου γενικευμένου τύπου
- έναν γενικευμένο προσαρμοσμένο τύπο `TreasureChest`, επίσης με τον ίδιο γενικευμένο τύπο

Αυτή η συνάρτηση θα πρέπει να καλεί τη συνάρτηση πολλαπλασιαστή με τον θησαυρό που βρίσκεται στο σεντούκι.

Η συνάρτηση θα πρέπει να επιστρέφει ένα νέο TreasureChest, με τον ίδιο κωδικό πρόσβασης με το αρχικό και με τον πολλαπλασιασμένο θησαυρό (την τιμή επιστροφής)
