# Εισαγωγή

Με τη Factor μπορείς να μοντελοποιήσεις ημερομηνίες και ώρες χρησιμοποιώντας το λεξιλόγιο [`calendar`][calendar]. Μια χρονική στιγμή είναι ένα `timestamp`; ένα χρονικό διάστημα είναι ένα `duration`.

## Δημιουργία μιας ημερομηνίας

Το `<date>` (στο [`calendar`][calendar]) δημιουργεί ένα `timestamp` τα μεσάνυχτα της δεδομένης ημέρας:

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

Το `>date<` χωρίζει ένα timestamp ξανά στα μέρη του:

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## Εξέταση μιας ημερομηνίας

Το `day-of-week` επιστρέφει την ημέρα της εβδομάδας ως ακέραιο, `0` για την Κυριακή έως `6` για το Σάββατο. Το `day-names` (στο [`calendar.english`][english]) είναι η αντίστοιχη λίστα με ονόματα, οπότε το `day-names nth` μετατρέπει τον αριθμό σε λέξη:

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

Το `leap-year?` δέχεται ένα έτος (ή ένα timestamp) και το `days-in-month` επιστρέφει το μήκος του μήνα ενός timestamp, λαμβάνοντας ήδη υπόψη τα δίσεκτα έτη:

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## Αριθμητική ημερομηνιών

Λέξεις όπως `days`, `weeks` και `hours` δημιουργούν ένα `duration`, και το `time+` μετατοπίζει ένα timestamp κατά ένα:

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

Η αριθμητική μεταφέρεται σωστά πέρα από τα όρια μήνα και έτους, και δύο timestamps που ονομάζουν την ίδια στιγμή συγκρίνονται ως ίσα με το `=`.

## Ώρες της ημέρας

Το `<timestamp>` δημιουργεί ένα πλήρες timestamp, μέχρι το δευτερόλεπτο. Το τελευταίο όρισμά του είναι η απόκλιση από την UTC; το `instant` (ένα μηδενικό `duration`) κρατά το timestamp στην UTC:

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

Το `>time<` είναι το αντίστοιχο του `>date<` και χωρίζει ένα timestamp στην ώρα, το λεπτό και το δευτερόλεπτό του:

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

Τα `seconds` και `minutes` δημιουργούν ένα `duration` ακριβώς όπως τα `days`, `weeks` και `hours`, οπότε οποιοδήποτε από αυτά μπορεί να περαστεί στο `time+`:

```
seconds ( x -- duration )
minutes ( x -- duration )
```

Τα επιμέρους πεδία ενός timestamp διαβάζονται με τους προσπελαστές `year>>`, `month>>`, `day>>`, `hour>>`, `minute>>` και `second>>`:

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
