# Παράρτημα οδηγιών

## Υποδείξεις

Σε αυτή την άσκηση, σου δώσαμε τον ορισμό του
[αλγεβρικού τύπου δεδομένων](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses)
με το όνομα `Planet`.
Πρέπει να υλοποιήσεις τη συνάρτηση `ageOn`, που υπολογίζει πόσων
ετών θα ήταν κάποιος σε έναν `Planet`, δεδομένης μιας ηλικίας σε δευτερόλεπτα.

Μπορείς να χρησιμοποιήσεις την υπογραφή που σου δίνουμε αν δεν είσαι σίγουρος για τους τύπους, αλλά
μην την αφήσεις να περιορίσει τη δημιουργικότητά σου:

```haskell
ageOn :: Planet -> Float -> Float
```
