# Εισαγωγή

Η Factor είναι μια *συνενωτική* γλώσσα: κάθε λέξη διαβάζει τις εισόδους της από μια κοινόχρηστη **στοίβα δεδομένων** και σπρώχνει τις εξόδους της πίσω σε αυτήν. Δεν υπάρχει άλλος τρόπος να περάσεις τιμές.

Γράφοντας ένα literal το σπρώχνεις στην κορυφή της στοίβας· ο κώδικας διαβάζεται από αριστερά προς τα δεξιά:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Μια δήλωση *επίδρασης στη στοίβα* τεκμηριώνει το συμβόλαιο μιας λέξης:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` λέει ότι η λέξη βγάζει δύο τιμές και αφήνει δύο πίσω με την άλλη σειρά. Τα ονόματα είναι τεκμηρίωση, μόνο ο *αριθμός* των εισόδων και εξόδων ελέγχεται από τον μεταγλωττιστή, και η κορυφή της στοίβας είναι το δεξιότερο όνομα.

Οι καθημερινές **λέξεις αναδιάταξης** του `kernel` αναδιατάσσουν την κορυφή της στοίβας:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Οι λέξεις ορίζονται με `:` και τελειώνουν με `;`· ο μεταγλωττιστής απορρίπτει έναν ορισμό του οποίου το σώμα δεν ταιριάζει με τη δηλωμένη επίδραση.
