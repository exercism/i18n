# Σχετικά

Στη C# υπάρχουν τρεις τύποι κινητής υποδιαστολής: `double`, `float` και `decimal`. Ο πιο συχνά χρησιμοποιούμενος τύπος είναι ο `double`, ενώ ο `decimal` χρησιμοποιείται συνήθως όταν δουλεύεις με νομισματικά δεδομένα. Ένας `double` γράφεται ως `2.45` ή `2.45d`, ένας `float` ως `2.45f` και ένας `decimal` ως `2.45m`.

Κάθε τύπος κινητής υποδιαστολής έχει τη δική του [ακρίβεια, κατά προσέγγιση εύρος και μέγεθος][docs-microsoft.com-characteristics-of-the-floating-point-types].

Κάποιες μετατροπές μεταξύ τύπων κινητής υποδιαστολής είναι [αυτόματες (έμμεσες)][docs-microsoft.com-implicit-numeric-conversion], ενώ άλλες είναι [χειροκίνητες (άμεσες)][docs-microsoft.com-explicit-numeric-conversion].

```csharp
decimal account = 125m * (decimal)1.2f;
```

Να προσέχεις πάντα όταν ελέγχεις τιμές τύπων κινητής υποδιαστολής για ισότητα, καθώς τιμές που φαίνεται να αντιπροσωπεύουν την ίδια τιμή μπορεί στην πραγματικότητα να είναι διαφορετικές. Δες [αυτό το άρθρο][docs.microsoft.com_precision-in-comparisons] για περισσότερες πληροφορίες.

Μπορείς να βρεις μια σύντομη εισαγωγή στους αριθμούς κινητής υποδιαστολής στο [0.30000000000000004.com][0.30000000000000004.com]. Η [σελίδα Float Toy][evanw.github.io-float-toy] έχει μια ωραία, γραφική εξήγηση για το πώς τα bits ενός αριθμού κινητής υποδιαστολής μετατρέπονται σε μια πραγματική τιμή κινητής υποδιαστολής.
