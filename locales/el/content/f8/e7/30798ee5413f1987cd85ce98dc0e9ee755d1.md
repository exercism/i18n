# Εισαγωγή

Τα [λεξικά][dictionaries] είναι ένας από τους βασικούς τύπους συλλογών της Swift.
Ένα λεξικό αποθηκεύει μη διατεταγμένες αντιστοιχίσεις μεταξύ μοναδικών κλειδιών και των αντίστοιχων τιμών τους.
Όλα τα κλειδιά σε ένα λεξικό πρέπει να είναι του ίδιου τύπου, και όλες οι τιμές πρέπει επίσης να μοιράζονται τον ίδιο τύπο.

Τα literal των λεξικών γράφονται ως ζεύγη `key: value` χωρισμένα με κόμματα, μέσα σε αγκύλες:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Οι τύποι λεξικών μπορούν να γραφτούν ρητά με δύο τρόπους: `Dictionary<Key, Value>` ή με τη συντομευμένη σύνταξη `[Key: Value]`.

Για να δημιουργήσεις ένα κενό λεξικό, δήλωσε ρητά τους τύπους των κλειδιών και των τιμών του:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Πρόσβαση σε τιμές

Μπορείς να προσπελάσεις τιμές χρησιμοποιώντας τον συμβολισμό με αγκύλες: βάλε το κλειδί μέσα σε αγκύλες μετά το όνομα του λεξικού.
Επειδή ένα κλειδί μπορεί να μην υπάρχει στο λεξικό, η πρόσβαση με αγκύλες επιστρέφει έναν *προαιρετικό* τύπο (`Value?`).
Αν το κλειδί υπάρχει, η Swift επιστρέφει την τιμή που περικλείεται· αν όχι, επιστρέφει `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Για να αποφύγεις να δουλεύεις με προαιρετικούς τύπους, μπορείς να δώσεις μια προεπιλεγμένη τιμή χρησιμοποιώντας την παράμετρο `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Τροποποίηση λεξικών

Για μεταβλητά λεξικά που δηλώνονται με `var`, μπορείς να προσθέσεις ή να ενημερώσεις ζεύγη κλειδιού-τιμής χρησιμοποιώντας ανάθεση με αγκύλες:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Διάσχιση ενός λεξικού

Μπορείς να διατρέξεις κάθε ζεύγος κλειδιού-τιμής ενός λεξικού χρησιμοποιώντας έναν βρόχο `for-in`.
Κάθε στοιχείο παρέχεται ως πλειάδα `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Ταξινόμηση λεξικών

Επειδή τα λεξικά δεν έχουν σειρά, η ταξινόμησή τους παράγει έναν πίνακα από ζεύγη κλειδιού-τιμής.
Μπορείς να περάσεις ένα closure στη μέθοδο `sorted(by:)` που συγκρίνει δύο πλειάδες `(key, value)` και επιστρέφει `true` αν η πρώτη πλειάδα πρέπει να εμφανιστεί πριν από τη δεύτερη:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
