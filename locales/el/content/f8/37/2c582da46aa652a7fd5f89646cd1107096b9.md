# Έννοιες του Luhn

Το Luhn είναι ένας αλγόριθμος επικύρωσης που συνδυάζει κειμενικούς και αριθμητικούς ελέγχους. Οι λύσεις σε Rust προτιμούν συναρτησιακές προσεγγίσεις.

## Γενικά

### Πρωταρχικοί τύποι

- `&str` και `char`
  - οι μαθητές πρέπει να κατανοήσουν τη διάκριση του μεμονωμένου `char` από το `&str`, ώστε να αποκλείουν ή να συμπεριλαμβάνουν σωστά τμήματα της δεδομένης εισόδου
- ακέραιος
  - η κατανόηση των ακεραίων είναι σημαντική για να γίνει η απαιτούμενη αριθμητική επικύρωση
- booleans (λογικές τιμές)
  - απαραίτητες για ελέγχους ταυτότητας και τελικές συγκρίσεις

### Χαρακτηριστικά των iterator

- αλυσίδωση
  - είναι σημαντικό να κατανοήσεις εδώ τις αλυσίδες iterator, για να λύσεις το πρόβλημα με διατεταγμένο τρόπο.
- `map`, `filter`, turbofish, ενδεχομένως `fold`
  - ο συνδυασμός των map και filter παρέχει ένα βασικό μοτίβο σχεδίασης για προβλήματα επικύρωσης σαν αυτό. Οι λύσεις με `fold` προσφέρουν ακόμη μεγαλύτερη συντομία.
  - το turbofish χρειάζεται σε ορισμένες λύσεις για να δηλώσεις στη Rust ποιον τύπο δημιουργείς από μια αλυσιδωτή έκφραση

## Παράδειγμα λύσης 1

η [λύση](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) του york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Παράδειγμα λύσης 2

Κανονική

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
