# Pow

Η χρήση των `pow`, `sqrt` ή `**` είναι απολύτως έγκυρη και σε πολλές περιπτώσεις μπορεί να είναι απαραίτητη.
Ωστόσο, όταν θέλουμε μια απόσταση στον καρτεσιανό χώρο, μπορούμε να χρησιμοποιήσουμε τη [μέθοδο `hypot`][hypot], η οποία επιστρέφει την υποτείνουσα ενός ορθογώνιου τριγώνου με πλευρές x και y.

```crystal
# Rather than:
Math.sqrt(number ** 2 + another_number ** 2)

# Consider:
Math.hypot(number, another_number)
```

[hypot]: https://crystal-lang.org/api/Math.html#hypot%28value1%2Cvalue2%29-instance-method
