# Οδηγίες ειδικά για SQLite

* Η στήλη **candidates** περιέχει μια λίστα από συμβολοσειρές κωδικοποιημένη σε JSON.
  Παράδειγμα:
  ```json
  ["stone","tones","banana","tons","notes","Seton"]
  ```
* Η στήλη **result** πρέπει να περιέχει επίσης μια λίστα από συμβολοσειρές κωδικοποιημένη σε JSON.

## Σχήμα πίνακα

```sql
CREATE TABLE anagram (
  subject    TEXT NOT NULL,
  candidates TEXT NOT NULL,     -- json array of strings
  result     TEXT               -- json array of strings
);
```
