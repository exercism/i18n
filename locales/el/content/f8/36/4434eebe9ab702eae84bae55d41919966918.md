# Οδηγίες

Ως μελλοντική μάγισσα, η Elyse χρειάζεται να εξασκηθεί στα βασικά. Έχει μια στοίβα από κάρτες που θέλει να χειριστεί.

Για να τα κάνει λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10, ώστε η στοίβα της να μπορεί να αναπαρασταθεί από ένα διάνυσμα αριθμών.
Η θέση μιας συγκεκριμένης κάρτας αντιστοιχεί στη θέση της μέσα στο διάνυσμα.

## 1. Πάρε μια κάρτα από τη στοίβα

Για να πάρεις μια κάρτα, επέστρεψε την κάρτα στη θέση `position` από τη στοίβα που σου δίνεται.

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. Άλλαξε μια κάρτα μέσα στη στοίβα

Κάνε ένα μαγικό τρικ και άλλαξε την κάρτα στη θέση `position` με την κάρτα αντικατάστασης που σου δίνεται.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. Είσαγε μια κάρτα στην κορυφή της στοίβας

Κάνε μια κάρτα να εμφανιστεί, εισάγοντας μια νέα κάρτα στην κορυφή της στοίβας.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. Αφαίρεσε μια κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί, αφαιρώντας από τη στοίβα την κάρτα στη θέση `position` που σου δίνεται.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. Έλεγξε το μέγεθος της στοίβας

Έλεγξε αν το μέγεθος της στοίβας είναι ίσο με `stack_size` ή όχι.

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. Αφαίρεσε την κορυφαία κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί, αφαιρώντας την κάρτα στην κορυφή της στοίβας.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. Είσαγε μια κάρτα στον πάτο της στοίβας

Κάνε μια κάρτα να εμφανιστεί, εισάγοντας μια νέα κάρτα στον πάτο της στοίβας.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. Αφαίρεσε μια κάρτα από τον πάτο της στοίβας

Κάνε μια κάρτα να εξαφανιστεί, αφαιρώντας την κάρτα στον πάτο της στοίβας.
Επέστρεψε την ενημερωμένη στοίβα.

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
