# Σχετικά

## Συναρτήσεις

Στη Gleam οι συναρτήσεις ορίζονται με τη σύνταξη `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Αυτή η συνάρτηση δέχεται δύο ορίσματα, και τα δύο τύπου `Int`, και επιστρέφει μια τιμή τύπου `Int`. Δεν υπάρχει λέξη-κλειδί `return` στη Gleam, η τιμή της τελευταίας έκφρασης σε μια συνάρτηση _επιστρέφεται πάντα έμμεσα_.

Οι σημειώσεις τύπου για τα ορίσματα και ο τύπος επιστροφής είναι προαιρετικά, και η Gleam θα ελέγχει πάντα πλήρως τους τύπους του κώδικά σου. Συνήθως οι προγραμματιστές της Gleam δίνουν στις συναρτήσεις τους σημειώσεις τύπου για σαφήνεια, αλλά μπορείς να τις παραλείψεις αν θέλεις.

```gleam
pub fn add(x, y) {
  x + y
}
```

Μια συνάρτηση μπορεί να κληθεί με τη σύνταξη `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Μεταβλητές

Στη Gleam οι μεταβλητές ορίζονται με τη σύνταξη `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Οι μεταβλητές μπορούν να δηλωθούν με σημειώσεις τύπου. Όπως τα ορίσματα συναρτήσεων, αυτές είναι προαιρετικές, αν και οι περισσότεροι προγραμματιστές της Gleam θα παραλείψουν τις σημειώσεις τύπου για τις μεταβλητές.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Κυριολεκτικά συμβολοσειρών

Στη Gleam οι συμβολοσειρές γράφονται με διπλά εισαγωγικά.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Σχόλια κώδικα

Τα σχόλια μπορούν να χρησιμοποιηθούν για να αφήνεις σημειώσεις σε άλλους προγραμματιστές που διαβάζουν τον πηγαίο κώδικα. Τα σχόλια στη Gleam είναι μεμονωμένες γραμμές που προηγούνται από `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
