# Εισαγωγή

## Ορίσματα με ετικέτες

Μερικές φορές, όταν μια συνάρτηση δέχεται πολλά ορίσματα, μπορεί να είναι δύσκολο να θυμηθείς τη σειρά με την οποία πρέπει να δοθούν. Για χάρη της αναγνωσιμότητας, η Gleam επιτρέπει να βάζεις στα ορίσματα μια ετικέτα με όνομα.

Για να βάλεις ετικέτα σε ένα όρισμα, γράψε το όνομα της ετικέτας πριν από το όνομα του ορίσματος, χωρισμένα με ένα κενό.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Όταν καλείς μια συνάρτηση με ορίσματα που έχουν ετικέτες, μπορείς να δώσεις τα ορίσματα με οποιαδήποτε σειρά. Κάθε μία από αυτές τις κλήσεις στη `replace` είναι ισοδύναμη:

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Οι ετικέτες είναι πάντα προαιρετικές. Ακόμα κι αν μια συνάρτηση έχει ορίσματα με ετικέτες, μπορείς να την καλέσεις και χωρίς ετικέτες.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
