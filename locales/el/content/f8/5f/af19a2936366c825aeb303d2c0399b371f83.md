# Οδηγίες

Η φίλη σου η Li Mei έχει ένα μπαρ χυμών όπου πουλάει νόστιμους χυμούς από ανάμεικτα φρούτα.
Είσαι τακτικός πελάτης στο μαγαζί της και κατάλαβες ότι θα μπορούσες να κάνεις τη ζωή της φίλης σου πιο εύκολη.
Αποφασίζεις να χρησιμοποιήσεις τις ικανότητές σου στον προγραμματισμό για να βοηθήσεις τη Li Mei στη δουλειά της.

## 1. Υπολόγισε πόσο χρόνο χρειάζεται για να φτιαχτεί ένας χυμός

Στη Li Mei αρέσει να λέει στους πελάτες της εκ των προτέρων πόσο θα περιμένουν για έναν χυμό από το μενού που παρήγγειλαν.
Της είναι δύσκολο να θυμάται τους ακριβείς αριθμούς, γιατί ο χρόνος που χρειάζεται για να αναμειχθούν οι χυμοί ποικίλλει:

| ID  | Drink               | Time |
| --- | ------------------- | ---- |
| 1   | Pure Strawberry Joy | 1    |
| 2   | Energizer           | 3    |
| 3   | Green Garden        | 3    |
| 4   | Tropical Island     | 4    |
| 5   | All or Nothing      | 5    |
| 6   | Feel Good           | 4    |
| 7   | Today’s Special     | 7    |
| 8   | Client's Choice     | 10   |

Γράψε μια συνάρτηση `time_to_make_juice` που δέχεται ένα ID για έναν χυμό, ως αριθμό 32-bit, και επιστρέφει τον χρόνο που χρειάζεται για να φτιαχτεί ο χυμός, επίσης ως αριθμό 32-bit.

```c
time_to_make_juice(2);
// => 3
```

## 2. Υπολόγισε πόσο χρόνο χρειάζεται για να φτιαχτούν όλοι οι χυμοί που παραγγέλθηκαν

Η Li Mei χρειάζεται να ανανεώνει περιοδικά τα εφόδιά της, οπότε θέλει να ξέρει εκ των προτέρων πόσο χρόνο θα χρειαστεί για να ετοιμάσει όλες τις παραγγελίες που εκκρεμούν αυτή τη στιγμή.

Για να βοηθήσεις τη φίλη σου, γράψε μια συνάρτηση `time_to_prepare` που δέχεται έναν πίνακα με τα ID κάθε χυμού που παραγγέλθηκε και τον αριθμό των χυμών στον πίνακα.
Αυτή η συνάρτηση πρέπει να επιστρέφει τον συνολικό χρόνο που θα χρειαστεί για να ετοιμαστούν όλα τα ποτά του πίνακα.

Μπορείς να θεωρήσεις ότι κάθε ID, ο αριθμός των ID στον πίνακα και η τιμή επιστροφής είναι όλα αριθμοί 32-bit.
Το αποτέλεσμα θα χωράει πάντα σε έναν αριθμό 32-bit.

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. Αναπλήρωσε το απόθεμα σε φέτες λάιμ

Πολλές από τις δημιουργίες της Li Mei περιλαμβάνουν φέτες λάιμ, είτε ως συστατικό είτε ως μέρος της διακόσμησης.
Έτσι, όταν ξεκινάει τη βάρδια της το πρωί, πρέπει να βεβαιωθεί ότι το δοχείο με τις φέτες λάιμ είναι γεμάτο για την ημέρα που έρχεται.

Υλοποίησε τη συνάρτηση `limes_to_cut`, η οποία δέχεται τον αριθμό των φετών λάιμ που χρειάζεται να κόψει η Li Mei, έναν πίνακα που αντιπροσωπεύει το απόθεμα από ολόκληρα λάιμ που έχει διαθέσιμα, και τον αριθμό των λάιμ στον πίνακα.

Κάθε λάιμ αντιπροσωπεύεται στον πίνακα από έναν χαρακτήρα που δηλώνει το μέγεθός του.
Διαφορετικά μεγέθη λάιμ μπορούν να δώσουν στη Li Mei διαφορετικό αριθμό φετών:

| Μέγεθος | Φέτες |
| ---- | ------ |
| 'S'  | 6      |
| 'M'  | 8      |
| 'L'  | 10     |

~~~~exercism/note
Ο χαρακτήρας είναι ένας αριθμός 8-bit που μπορεί να χρησιμοποιηθεί όπως οποιοσδήποτε αριθμός 8-bit:

| Χαρακτήρας | Τιμή |
|-----------|-------|
| 'S'       | 83    |
| 'M'       | 77    |
| 'L'       | 76    |

Μπορεί επίσης να χρησιμοποιηθεί απευθείας σε εντολές, καθώς είναι ισοδύναμος με την τιμή του:

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Η Li Mei κόβει πάντα τα λάιμ με τη σειρά που εμφανίζονται στον πίνακα, ξεκινώντας από το πρώτο στοιχείο.
Συνεχίζει μέχρι να φτάσει στον αριθμό των φετών που χρειάζεται ή μέχρι να τελειώσουν τα λάιμ.

Η Li Mei θα ήθελε να ξέρει εκ των προτέρων πόσα λάιμ χρειάζεται να κόψει.

Μπορείς να θεωρήσεις ότι ο αριθμός των φετών που χρειάζονται, ο αριθμός των λάιμ στον πίνακα και η τιμή επιστροφής είναι όλα αριθμοί 32-bit.
Το αποτέλεσμα θα χωράει πάντα σε έναν αριθμό 32-bit.

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. Ολοκλήρωσε τη βάρδια

Η Li Mei δουλεύει πάντα μέχρι τις 3 το μεσημέρι.
Μετά αναλαμβάνει ο υπάλληλός της, ο Dmitry.
Συχνά υπάρχουν ποτά που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμα όταν τελειώνει η βάρδια της Li Mei.
Τότε ο Dmitry ετοιμάζει τους υπόλοιπους χυμούς.

Για να γίνει πιο εύκολη η παράδοση, υλοποίησε μια συνάρτηση `remaining_orders` που δέχεται:

- Τον αριθμό των λεπτών που απομένουν στη βάρδια της Li Mei.
- Έναν πίνακα με τα ID κάθε χυμού που έχει παραγγελθεί αλλά δεν έχει ετοιμαστεί ακόμα.

Η συνάρτηση πρέπει να επιστρέφει τον αριθμό των παραγγελιών που ετοίμασε η Li Mei πριν από το τέλος της εργάσιμης ημέρας της.

Ο χρόνος που απομένει στη βάρδια θα είναι πάντα μεγαλύτερος από 0.
Ο πίνακας με τους χυμούς προς ετοιμασία δεν θα είναι ποτέ κενός και η βάρδια θα τελειώνει πάντα πριν φτάσει στο τέλος του πίνακα.
Επιπλέον, οι παραγγελίες ετοιμάζονται με τη σειρά που εμφανίζονται στον πίνακα.
Αν η Li Mei αρχίσει να αναμειγνύει έναν συγκεκριμένο χυμό, θα τον ολοκληρώσει πάντα, ακόμα κι αν χρειαστεί να δουλέψει λίγο παραπάνω.

Μπορείς να θεωρήσεις ότι ο αριθμός των λεπτών που απομένουν, κάθε ID στον πίνακα και η τιμή επιστροφής είναι όλα αριθμοί 32-bit.
Το αποτέλεσμα θα χωράει πάντα σε έναν αριθμό 32-bit.

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
