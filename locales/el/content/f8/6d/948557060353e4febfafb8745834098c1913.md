# Υποδείξεις

## Γενικά

- Διάβασε για τη βασική αριθμητική στον επίσημο [οδηγό Getting Started][getting-started-basic-arithmetic].
- Ρίξε μια ματιά στις ενότητες [`Float`][float-functions] και [`Kernel`][kernel-arithmetic-operators] για να μάθεις για συναρτήσεις και τελεστές που δουλεύουν με float.

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

- Οι [βασικές αριθμητικές πράξεις][kernel-arithmetic-operators] στις οποίες το ένα όρισμα είναι ακέραιος και το άλλο είναι float επιστρέφουν float.

## 2. Υπολόγισε μια τιμή με έκπτωση

- Οι [βασικές αριθμητικές πράξεις][kernel-arithmetic-operators] στις οποίες το ένα όρισμα είναι ακέραιος και το άλλο είναι float επιστρέφουν float.

## 3. Υπολόγισε τη μηνιαία χρέωση, με δεδομένη την ωριαία χρέωση και μια έκπτωση

- Υπάρχει μια [ενσωματωμένη συνάρτηση][kernel-trunc] για τη μετατροπή float σε ακέραιο.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][float-ceil] για τη στρογγυλοποίηση float προς τα πάνω.

## 4. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένο έναν προϋπολογισμό, την ωριαία χρέωση και μια έκπτωση

- Υπάρχει μια [ενσωματωμένη συνάρτηση][float-floor] για τη στρογγυλοποίηση float προς τα κάτω με την επιθυμητή ακρίβεια.
