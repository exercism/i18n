# Σχετικά

Οι [πλειάδες][tuples] χρησιμοποιούνται για να συνδυάζουν πολλές τιμές σε μία σύνθετη τιμή, όπου κάθε τιμή μπορεί να έχει διαφορετικό τύπο.
Η σύνθετη τιμή έχει έναν τύπο που είναι ο συνδυασμός των τύπων των επιμέρους τιμών.
Όπως οι πίνακες, έτσι και οι πλειάδες είναι διατεταγμένες συλλογές.
Ωστόσο, σε αντίθεση με τους πίνακες, οι πλειάδες έχουν σταθερό μέγεθος, οπότε για να αλλάξεις τον αριθμό των στοιχείων μιας πλειάδας, πρέπει να δημιουργήσεις μια νέα πλειάδα.

Για να δημιουργήσεις μια πλειάδα, περικλείεις τις τιμές σε παρενθέσεις, χωρισμένες με κόμματα:

```swift
let order = ("biscuits", 2.99, 3)
```

Μπορείς επίσης να ορίσεις τον τύπο κάθε τιμής στην πλειάδα:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Για να εξαγάγεις τις επιμέρους τιμές από μια πλειάδα, μπορείς να χρησιμοποιήσεις τη σύνταξη `.n`, όπου το _n_ είναι η θέση του στοιχείου στο οποίο θέλεις να έχεις πρόσβαση, ξεκινώντας από το 0:

```swift
let orderItem = order.0
// Returns "biscuits"

let orderQuantity = order.2
// Returns 3
```

## Πλειάδες με ονόματα

Οι πλειάδες μπορούν να πάρουν ονόματα, δίνοντας μια ετικέτα για κάθε τιμή:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Αυτό μπορεί να είναι χρήσιμο για να γίνει η πλειάδα πιο ευανάγνωστη και κατανοητή από μόνη της, ειδικά όταν η πλειάδα χρησιμοποιείται ως τιμή επιστροφής από μια συνάρτηση.

Επίσης, σου επιτρέπει να έχεις πρόσβαση στις επιμέρους τιμές με τα ονόματά τους:

```swift
let orderItem = order.item
// Returns "biscuits"
let orderQuantity = order.quantity
// Returns 3
```

Όπως και με τις πλειάδες χωρίς ονόματα, μπορείς να ορίσεις τον τύπο κάθε τιμής σε μια πλειάδα με ονόματα:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Τροποποίηση πλειάδων

Τα στοιχεία μιας πλειάδας μπορούν να τροποποιηθούν, κάτι που γίνεται με τη σύνταξη `.n`.

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

order
// Returns ("cookies", 1.99, 5)
```

## Πολλαπλές τιμές επιστροφής

Οι συναρτήσεις στη Swift μπορούν να επιστρέψουν μόνο μία τιμή.
Ωστόσο, επειδή μια πλειάδα είναι μία τιμή, μπορείς να συσκευάσεις πολλές τιμές σε μια πλειάδα και να επιστρέψεις αυτή την πλειάδα από μια συνάρτηση.
Αυτό σου επιτρέπει ουσιαστικά να [επιστρέψεις πολλαπλές τιμές από μια συνάρτηση][multiple-return-values].

Ακολουθεί ένα παράδειγμα συνάρτησης που επιστρέφει μια πλειάδα με πηλίκο και υπόλοιπο:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
  let quotient = dividend / divisor
  let remainder = dividend % divisor
  return (quotient, remainder)
}
```

## Αποδόμηση πλειάδας

Μπορείς να αποδομήσεις μια πλειάδα στα επιμέρους συστατικά της, παρέχοντας τόσες μεταβλητές όσα είναι τα στοιχεία της πλειάδας.
Η χρήση της αποδόμησης πλειάδας μπορεί να αυξήσει την αναγνωσιμότητα του κώδικά σου, αφού σου επιτρέπει να δώσεις ουσιαστικά ονόματα στις επιμέρους τιμές.

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

item
// Returns "biscuits"
```

Η αποδόμηση μπορεί να γίνει και με βρόχους `for`-`in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
  print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
