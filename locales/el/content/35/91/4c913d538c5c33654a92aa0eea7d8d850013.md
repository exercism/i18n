# Υποδείξεις

## 1. Υπολόγισε το επιτόκιο

- Χρησιμοποίησε μια έκφραση υπό συνθήκη ως εντολή [`if`][if] και σύγκρινε το `balance` με τα διάφορα διαστήματα.
- Μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `return` για πρόωρη επιστροφή από μια μέθοδο.

## 2. Υπολόγισε τους τόκους

- Όταν υπολογίζεις τους τόκους, μπορεί να σου φανεί χρήσιμο να παρατηρήσεις ότι το `interest_rate` επιστρέφει ένα ποσοστό.

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Όταν υπολογίζεις την ετήσια ενημέρωση του υπολοίπου, μπορείς να χρησιμοποιήσεις μεθόδους που έχεις ορίσει σε προηγούμενα βήματα.

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

- Για να υπολογίσεις τα χρόνια, μπορείς να επαναλαμβάνεις μέχρι να φτάσεις στο επιθυμητό υπόλοιπο. Αυτό μπορεί να γίνει με έναν [`while`][while] βρόχο.

[if]: https://crystal-lang.org/reference/latest/syntax_and_semantics/if.html
[while]: https://crystal-lang.org/reference/latest/syntax_and_semantics/while.html
