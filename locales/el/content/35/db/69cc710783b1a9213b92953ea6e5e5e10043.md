# Το gofmt δεν χρησιμοποιήθηκε

Τρέξε το `gofmt` στη λύση, το οποίο βοηθά στη μορφοποίηση κώδικα στη Go.

Η μορφοποίηση κώδικα στη Go είναι πολύ σημαντική για την κοινότητα.
Τα περισσότερα IDE μπορούν να ρυθμιστούν ώστε να μορφοποιούν αυτόματα τον κώδικα σε κάθε αποθήκευση. Για παράδειγμα:

- Το Visual Studio Code έχει [εξαιρετική υποστήριξη Go](https://code.visualstudio.com/docs/languages/go)
- Το Vim έχει επίσης μια [φανταστική επέκταση Go](https://github.com/fatih/vim-go)
- Το [Jetbrains Goland](https://www.jetbrains.com/go/) είναι ένα ολόκληρο IDE για Go

Για να τρέξεις το `gofmt` χειροκίνητα:

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
