# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις ερωτευμένους του λυκείου να δηλώσουν τον έρωτά τους στα μέσα κοινωνικής δικτύωσης.

## 1. Εμφάνισε το όνομα του ζευγαριού χωρισμένο με μια καρδιά

Υλοποίησε τη στατική μέθοδο `HighSchoolSweethearts.DisplaySingleLine()` ώστε να παίρνει δύο ονόματα και να τα εμφανίζει χωρισμένα με μια καρδιά.
Το μορφοποιημένο κείμενο πρέπει να έχει πλάτος 61 χαρακτήρες, με την καρδιά στο κέντρο της συμβολοσειράς.

Όλα τα ονόματα είναι σίγουρο ότι χωράνε άνετα στο πλάτος της γραμμής.

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

## 2. Εμφάνισε τα αρχικά του ζευγαριού σε μια καρδιά από ascii art

Υλοποίησε τη στατική μέθοδο `HighSchoolSweethearts.DisplayBanner()` που εμφανίζει τα δύο ζεύγη αρχικών χωρισμένα με ένα σύμβολο συν.

```csharp
HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");
```

## 3. Οι Γερμανοί μαθητές ανταλλαγής πρέπει να νιώσουν σαν στο σπίτι τους με δηλώσεις που σέβονται τις τοπικές ρυθμίσεις.

Υλοποίησε τη στατική μέθοδο `HighSchoolSweethearts.DisplayGermanExchangeStudents()` που δείχνει την ημερομηνία έναρξης της σχέσης και τη διάρκεια για τους Γερμανούς μαθητές ανταλλαγής μας.

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
