# Βρόχοι

Ένας **βρόχος** κάνει το ίδιο πράγμα ξανά και ξανά.

```sather
   loop
      ...
   end;
```

Από μόνος του δεν σταματά ποτέ, οπότε κάτι μέσα του πρέπει να τον τερματίσει.

## Κάπου για να κρατάς το μέτρημα

Ένας βρόχος χρειάζεται σχεδόν πάντα μια τιμή που αλλάζει όσο προχωράει. Αυτή είναι μια
**μεταβλητή**, και το `::=` δημιουργεί μία:

```sather
   total ::= 0;
```

Η μεταβλητή λέγεται `total`, ξεκινά από το `0`, και η Sather καταλαβαίνει από το `0`
ότι κρατά ένα `INT`. Μετά από αυτό, το `:=` βάζει μέσα μια νέα τιμή:

```sather
   total := total + 5;
```

Διάβασέ το από τα δεξιά προς τα αριστερά: πάρε αυτό που είναι τώρα το `total`, πρόσθεσε
5, και βάλε την απάντηση πίσω στο `total`.

Μια μεταβλητή που φτιάχνεται έτσι ζει μέχρι το τέλος της ρουτίνας.

## until!

Το `until!` παίρνει μια ερώτηση. Κάθε φορά που ο βρόχος κάνει έναν γύρο, η ερώτηση
τίθεται ξανά, και όταν η απάντηση είναι αληθής ο βρόχος σταματά επιτόπου.

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

Το `n` μετράει 1, 2, 3 ... και ο βρόχος τελειώνει την πρώτη φορά που το `n` ξεπερνά
το `last`. Χωρίς το `n := n + 1`, η ερώτηση δεν θα άλλαζε ποτέ απάντηση και ο βρόχος
θα έτρεχε για πάντα.

Το `until!` δεν χρειάζεται να είναι στην πρώτη γραμμή. Βάλε το εκεί όπου η ερώτηση έχει
νόημα: στην αρχή, ο βρόχος μπορεί να μην εκτελεστεί καθόλου, ενώ στο τέλος εκτελείται
πάντα τουλάχιστον μία φορά.

Το `!` είναι μέρος του ονόματος. Η Sather σημαδεύει έτσι ορισμένα πράγματα. Το τι
σημαίνει αυτό το σημάδι θα το δούμε παρακάτω.

## break!

Το `break!` τερματίζει τον βρόχο αμέσως, χωρίς καμία ερώτηση. Είναι χρήσιμο όταν ο
λόγος για να σταματήσεις εμφανίζεται στη μέση της δουλειάς.

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

Τα `until!` και `break!` έχουν νόημα μόνο μέσα σε έναν `loop`. Κανένα από τα δύο δεν
μπορεί να χρησιμοποιηθεί μόνο του.
