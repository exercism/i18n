# Εισαγωγή

Αυτή η άσκηση εξετάζει κάποιες λεπτομέρειες των παραμέτρων των μεθόδων και τη χρήση τους στη C#.

Οι παράμετροι μεταφέρουν πληροφορίες από τη μέθοδο που καλεί στη μέθοδο που καλείται.

- Η συμπεριφορά των παραμέτρων μπορεί να τροποποιηθεί με τη χρήση τροποποιητών, όπως οι `ref` και `out`.

- Μια παράμετρος με τον τροποποιητή `out` μεταφέρει μια τιμή πίσω από τη μέθοδο που καλείται σε αυτόν που καλεί. Η παράμετρος μπορεί να περαστεί στη μέθοδο που καλείται χωρίς να έχει αρχικοποιηθεί, και σε κάθε περίπτωση αντιμετωπίζεται μέσα στη μέθοδο που καλείται σαν να μην είχε αρχικοποιηθεί κατά την είσοδο. Η κατανόηση της συμπεριφοράς και των κανόνων που αφορούν τους τροποποιητές παραμέτρων αποκτιέται πιο εύκολα μέσα από παραδείγματα (δες παρακάτω) και μηνύματα του μεταγλωττιστή.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Οι παράμετροι `out` πρέπει να εκχωρούνται μέσα στη μέθοδο που καλείται.

- Μια παράμετρος με τον τροποποιητή `ref` περνά μια τιμή μέσα στη μέθοδο που καλείται. Όταν η μέθοδος επιστρέφει, αυτός που κάλεσε θα βρει σε αυτή την παράμετρο οποιεσδήποτε αλλαγές έκανε η μέθοδος που κλήθηκε.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Οι παράμετροι `ref` πρέπει να είναι μεταβλητές, αφού η μέθοδος που καλείται θα λειτουργεί απευθείας πάνω στην παράμετρο όπως τη βλέπει αυτός που καλεί.
- Οι τροποποιητές `out` και `ref` απαιτούνται τόσο στην υπογραφή της μεθόδου που καλείται όσο και στο σημείο κλήσης.
