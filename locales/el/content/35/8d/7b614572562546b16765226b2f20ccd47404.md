# χρήση προδιαγραφής

[comment]: # (Αυτή η προειδοποίηση εμφανίζεται όταν η λύση δεν έχει προδιαγραφή τύπων)

Συμπερίλαβε [προδιαγραφές τύπων](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs) (`@spec`) για να μεταφέρεις το συμβόλαιο ανάμεσα στις εισόδους και την έξοδο της συνάρτησης.

- Η Elixir είναι μια γλώσσα με δυναμικούς τύπους, που σημαίνει ότι οι έλεγχοι τύπων γίνονται μόνο κατά την εκτέλεση. Η χρήση προδιαγραφών τύπων επιτρέπει σε linters και σε εργαλεία στατικής ανάλυσης όπως το [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html) (βασισμένο στο [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) της Erlang) να αξιολογούν τον κώδικα για ανεπιθύμητες συμπεριφορές.
- Μπορείς να βρεις μια [πλήρη λίστα](https://hexdocs.pm/elixir/typespecs.html#basic-types) με όλους τους ενσωματωμένους τύπους στην [τεκμηρίωση της γλώσσας](https://hexdocs.pm/elixir/typespecs.html#content)
- οι τύποι μπορούν να οριστούν με ή χωρίς παρενθέσεις: `atom()` εναντίον `atom`
  - στο Exercism, το στυλ της Elixir είναι να τους γράφεις χωρίς παρενθέσεις.

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
