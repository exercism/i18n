# Εισαγωγή

Όταν μια παράθεση χρειάζεται να *θυμάται* τιμές από το περιβάλλον της (αυτό που άλλες γλώσσες αποκαλούν *closure*), η Factor χρησιμοποιεί δύο εργαλεία: τη λέξη `curry` και τη σύνταξη *fry* `'[ ]`.

## `curry`: σύλληψη μιας τιμής

Το `curry` (στο λεξιλόγιο [`kernel`][kernel]) παίρνει μια τιμή και μια παράθεση και επιστρέφει μια νέα παράθεση με αυτή την τιμή ενσωματωμένη:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

Εφάρμοσε το `curry` δύο φορές για να συλλάβεις δύο τιμές:

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`: ένωση δύο παραθέσεων

Το `compose` (στο λεξιλόγιο [`kernel`][kernel]) ενώνει δύο παραθέσεις μεταξύ τους:

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Παραθέσεις fry: σύλληψη πολλών τιμών

Για περισσότερες από μία ή δύο συλλήψεις, οι αλυσιδωτές κλήσεις `curry` γίνονται δυσανάγνωστες. Το *fry* χρησιμοποιεί `'[ … ]` με ένα ή περισσότερα σύμβολα θέσης `_`. Κάθε `_` αντικαθίσταται από μια τιμή που αφαιρείται από τη στοίβα δεδομένων, με σειρά:

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

Και το `curry` και το fry *καταναλώνουν* τις τιμές τους από τη στοίβα τη στιγμή που δημιουργείται το closure. Η παραπάνω γραμμή δεν αφήνει τίποτα στη στοίβα και αποτελεί άμεση αντικατάσταση για το `[ + + ] curry curry`.

Τα σύμβολα θέσης συμπληρώνονται από αριστερά προς τα δεξιά με τιμές της στοίβας από κάτω προς τα πάνω: το `2 3 '[ _ _ ]` είναι `[ 2 3 ]`, όχι `[ 3 2 ]`.

Το fry φτάνει επίσης *μέσα* σε εμφωλευμένες παραθέσεις, κάτι που σου επιτρέπει να τοποθετήσεις τις τιμές που έχουν συλληφθεί ακριβώς εκεί που τις θέλεις:

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

Το `_` βρίσκεται μέσα στην εσωτερική `[ … ]`, αλλά το fry εξακολουθεί να το συμπληρώνει.

## `call` με δηλωμένη επίδραση

Όταν τελικά εκτελέσεις μια αποθηκευμένη παράθεση, δήλωσε την επίδρασή της στη στοίβα στο `call` ώστε ο μεταγλωττιστής να μπορεί να την ελέγξει ως προς τους τύπους:

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## Διανυσματική αριθμητική

Το λεξιλόγιο [`math.vectors`][math.vectors] συνδυάζει δύο ακολουθίες ίδιου μήκους στοιχείο προς στοιχείο. Τα `v+` και `v*` τις προσθέτουν ή τις πολλαπλασιάζουν. Τα `vmax` και `vmin` κρατούν το μεγαλύτερο ή το μικρότερο από κάθε συνιστώσα. Κάθε μία επιστρέφει έναν πίνακα 2 στοιχείων:

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
