# Οδηγίες

Σε αυτή την άσκηση, θα γράψεις κώδικα που θα σε βοηθήσει να προετοιμαστείς για να αγοράσεις ένα όχημα.

Έχεις τρεις εργασίες: να καθορίσεις αν θα χρειαστεί να βγάλεις δίπλωμα οδήγησης, να διαλέξεις ανάμεσα σε δύο οχήματα και να υπολογίσεις την αποδεκτή τιμή για ένα μεταχειρισμένο όχημα.

## 1. Καθόρισε αν θα χρειαστείς δίπλωμα οδήγησης

Κάποια είδη οχημάτων απαιτούν δίπλωμα οδήγησης για να τα οδηγήσεις.
Θεώρησε ότι μόνο τα είδη `"car"` και `"truck"` απαιτούν δίπλωμα· όλα τα υπόλοιπα μπορούν να οδηγηθούν χωρίς δίπλωμα.

Υλοποίησε τη συνάρτηση `needs_license`, η οποία παίρνει το είδος του οχήματος και επιστρέφει Boolean (λογική τιμή) που δείχνει αν χρειάζεσαι δίπλωμα για αυτό το είδος οχήματος.

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. Διάλεξε ανάμεσα σε δύο υποψήφια οχήματα για αγορά

Έχεις αξιολογήσει τις επιλογές σου από τα διαθέσιμα οχήματα.
Κατάφερες να τις περιορίσεις σε δύο επιλογές, αλλά χρειάζεσαι βοήθεια για να πάρεις την τελική απόφαση.
Υλοποίησε τη συνάρτηση `choose_vehicle`, η οποία παίρνει ως είσοδο έναν πίνακα με δύο οχήματα και επιστρέφει μια απόφαση: την επιλογή που έρχεται πρώτη σε λεξικογραφική σειρά.

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. Υπολόγισε μια εκτίμηση για την τιμή ενός μεταχειρισμένου οχήματος

Τώρα που πήρες την απόφασή σου, θέλεις να σιγουρευτείς ότι θα πάρεις μια δίκαιη τιμή στην αντιπροσωπεία.
Εφόσον ενδιαφέρεσαι να αγοράσεις ένα μεταχειρισμένο όχημα, η τιμή εξαρτάται από το πόσο παλιό είναι το όχημα.
Για μια χονδρική εκτίμηση, θεώρησε ότι αν το όχημα είναι λιγότερο από 3 ετών, κοστίζει το 80% της αρχικής τιμής που είχε όταν ήταν ολοκαίνουργιο.
Αν είναι πάνω από 10 ετών, κοστίζει το 50%.
Αν το όχημα είναι τουλάχιστον 3 ετών αλλά όχι μεγαλύτερο από 10 ετών, κοστίζει το 70% της αρχικής τιμής.

Υλοποίησε τη συνάρτηση `resell_price`, η οποία εφαρμόζει αυτή τη λογική χρησιμοποιώντας `if`, `elif` και `else`.
Παίρνει ένα αντικείμενο που περιέχει την αρχική τιμή και την ηλικία του οχήματος και επιστρέφει την εκτιμώμενη τιμή στην αντιπροσωπεία.

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
