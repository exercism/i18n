# Τριαδικός τελεστής

Ο τριαδικός τελεστής προσφέρει μια εναλλακτική σύνταξη για να εκτελέσεις μια σύγκριση `if..else..` και να επιστρέψεις μια τιμή.

## Σύνταξη

Η PHP παρέχει μια εντολή `if`, όπου μια ενέργεια μπορεί να αξιολογηθεί με βάση το κατά πόσο μια συνθήκη "αληθεύει".

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Εναλλακτικά, ο τριαδικός τελεστής μπορεί να αναπαραστήσει την ίδια πράξη:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

Η σύνταξη της σύγκρισης είναι σύντομη και αναπαρίσταται ως `(condition) ? (evaluate if true) : (evaluate if false);`.
