# Σχετικά

Θυμήσου ότι το `jq` υποστηρίζει τους ίδιους τύπους δεδομένων με τη JSON.
Η JSON περιγράφει τις **συμβολοσειρές** ως εξής:

> Μια συμβολοσειρά είναι μια ακολουθία από μηδέν ή περισσότερους χαρακτήρες Unicode, κλεισμένη σε διπλά εισαγωγικά, χρησιμοποιώντας διαφυγές με backslash.

## Ακολουθίες διαφυγής

Μέσα σε μια συμβολοσειρά, χρησιμοποίησε τον χαρακτήρα backslash για να ενσωματώσεις "ειδικούς" χαρακτήρες:

- `\"` ένα κυριολεκτικό εισαγωγικό,
- `\\` ένα κυριολεκτικό backslash,
- χαρακτήρες κενού `\n`, `\t`, `\r`, `\f`, `\b`
- χαρακτήρες unicode `\uAAAA`, όπου το `A` είναι δεκαεξαδικό ψηφίο

## Μήκος συμβολοσειράς

Για να βρεις τον αριθμό των χαρακτήρων, χρησιμοποίησε τη συνάρτηση [`length`][length].

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

Για να βρεις τον αριθμό των πραγματικών _bytes_, χρησιμοποίησε τη συνάρτηση [`utf8bytelength`][utf8bytelength].

```sh
$ jq -cn --args  '$ARGS.positional[] | utf8bytelength' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
27
```

## Υποσυμβολοσειρές

Ο συμβολισμός [**slice**][slice] μπορεί να χρησιμοποιηθεί για την εξαγωγή υποσυμβολοσειρών.
Η σύνταξη είναι `.[i:j]`.
Η υποσυμβολοσειρά που επιστρέφεται έχει μήκος `j - i` και περιέχει χαρακτήρες από τη θέση `i` (συμπεριλαμβανομένης) έως τη θέση `j` (μη συμπεριλαμβανομένης).
Οποιαδήποτε από τις δύο θέσεις μπορεί να είναι αρνητική, οπότε μετράει προς τα πίσω από το τέλος της συμβολοσειράς.
Οποιαδήποτε από τις δύο θέσεις μπορεί να παραλειφθεί, οπότε αναφέρεται στην αρχή ή στο τέλος της συμβολοσειράς.
Οι θέσεις ξεκινούν από το μηδέν.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Συνένωση

Χρησιμοποίησε το [`+`][+] για να ενώσεις συμβολοσειρές:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Χρησιμοποίησε το [`add`][add] όταν έχεις έναν πίνακα από συμβολοσειρές:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Διαχωρισμός και ένωση

Ο διαχωρισμός χρησιμοποιεί τη συνάρτηση [`split/1`][split/1] ή τον τελεστή [`/`][/]:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Το αντίστροφο του [`split/1`][split/1] είναι το [`join/1`][join/1].

Η μετατροπή μιας συμβολοσειράς σε πίνακα χαρακτήρων είναι συχνά απαραίτητη.
Υπάρχουν δύο τρόποι για να το κάνεις αυτό:

1. διαχωρισμός με κενή συμβολοσειρά

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. [`explode`][explode] σε πίνακα από _κωδικά σημεία_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   Το [`implode`][implode] είναι το αντίστροφο του [`explode`][explode].

## Βρες τη θέση μιας υποσυμβολοσειράς

Χρησιμοποίησε τη συνάρτηση [`index/1`][index/1]· η θέση ξεκινά από το μηδέν.

```jq
"hello" | index("el")'   # => 1
```

Αν η υποσυμβολοσειρά δεν υπάρχει μέσα στη συμβολοσειρά, το αποτέλεσμα είναι `null`

```jq
"hello" | index("elk")   # => null
```

Άλλες χρήσιμες συναρτήσεις είναι οι [`rindex/1`][index/1] και [`indices`][indices].

## Παρεμβολή συμβολοσειρών

Μέσα σε μια συμβολοσειρά, η ακολουθία `\(expression)` ενσωματώνει το _αποτέλεσμα_ αυτής της έκφρασης [στη συμβολοσειρά][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Μετατροπή πεζών και κεφαλαίων

Χρησιμοποίησε τις συναρτήσεις [`ascii_downcase`][ascii_downcase] και [`ascii_upcase`][ascii_downcase] για να αλλάξεις τα πεζά και τα κεφαλαία μιας συμβολοσειράς.

## Μετατροπή συμβολοσειράς σε αριθμό

Χρησιμοποίησε τη συνάρτηση [`tonumber`][tonumber] για να δημιουργήσεις έναν αριθμό από μια συμβολοσειρά.

Αυτό πετάει ένα σφάλμα αν η συμβολοσειρά δεν μπορεί να μετατραπεί σε αριθμό, οπότε μπορεί να χρειαστεί το [`try-catch`][try-catch].

```jq
$ jq -cn --args '$ARGS.positional[] | [., tonumber]' 42 3.14 oops 1e6 0xbeef
["42",42]
["3.14",3.14]
jq: error (at <unknown>): Invalid numeric literal at EOF at line 1, column 4 (while parsing 'oops')

$ echo $?
5

$ jq -cn --args '$ARGS.positional[] | try [., tonumber] catch "not a number"' 42 3.14 oops 1e6 0xbeef
["42",42]
["3.14",3.14]
"not a number"
["1e6",1000000]
"not a number"
```

Σημείωσε ότι οι [αριθμοί JSON][json-numbers] δεν περιλαμβάνουν δεκαεξαδικές ή οκταδικές μορφές που υποστηρίζουν κάποιες γλώσσες.

## Άλλες συναρτήσεις

Δες [το εγχειρίδιο][manual] για περισσότερες λεπτομέρειες σχετικά με αυτές τις συναρτήσεις:

- επανάληψη μιας συμβολοσειράς: `*`
- έλεγχος περιεκτικότητας: `contains/1`, `inside/1`, `indices/1`, `index/1`, `rindex/1`, `startswith/1`, `endswith/1`
- περικοπή: `lsrimstr/1`, `rtrimstr/1`
- συναρτήσεις μορφοποίησης: `@text`, `@json`, `@html`, `@uri`, `@csv`, `@tsv`, `@sh`, `@base64`, `@base64d`
