# Οδηγίες

Δουλεύεις σε ένα ηλεκτρονικό κατάστημα μόδας.
Σου έρχεται η ιδέα για μια λειτουργία της ιστοσελίδας όπου προτείνονται σύνολα στον χρήστη.
Αυτό που έχει ενδιαφέρον είναι τα πιθανά σύνολα, οι τιμές τους και η εξάλειψη των ασύμβατων επιλογών.

~~~~

## 1. Δημιούργησε ένα κομμάτι ρούχου


Υλοποίησε τη συνάρτηση `clothingitem()` ώστε να δέχεται δύο `Tuple`, το ένα με `categories` και το άλλο με τις αντίστοιχες `qualities`.
Η συνάρτηση πρέπει να επιστρέφει ένα `Dict` με τα `categories` ως κλειδιά και τα `qualities` ως τιμές.

```julia-repl
julia> categories = ("item_name", "price", "color", "base_color");

julia> qualities = ("Descriptive Name", 99.00, "Ochre Red", "red");

julia> clothingitem(categories, qualities)
Dict{String, Any} with 4 entries:
  "price"      => 99.0
  "item_name"  => "Descriptive Name"
  "base_color" => "red"
  "color"      => "Ochre Red"
```

Η συνάρτηση σου πρέπει να μπορεί να χειριστεί οποιονδήποτε αριθμό `categories`.

## 2. Πρότεινε συνδυασμούς

Υλοποίησε τη συνάρτηση `get_combinations()` ώστε να δέχεται ένα `Tuple` με πάνω ρούχα και ένα `Tuple` με κάτω ρούχα.
Η συνάρτηση πρέπει να επιστρέφει το `cartesian product` των πλειάδων ως δισδιάστατο πίνακα (δηλ. `Matrix`).
Κάθε στοιχείο είναι ένας συνδυασμός `(top, bottom)` με τη μορφή `Tuple`.
Τα πάνω ρούχα αλλάζουν καθώς κατεβαίνεις τις γραμμές, τα κάτω ρούχα αλλάζουν καθώς προχωράς στις στήλες.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt"),
        Dict("item_name" => "Casual shirt")
        );

julia> bottoms = (
        Dict("item_name" => "Jeans"),
        Dict("item_name" => "Dress trousers")
       );

julia> get_combinations(tops, bottoms)
2×2 Matrix{Tuple{Dict{String, String}, Dict{String, String}}}:
 (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Jeans"))   (Dict("item_name"=>"Dress shirt"), Dict("item_name"=>"Dress trousers"))
 (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Jeans"))  (Dict("item_name"=>"Casual shirt"), Dict("item_name"=>"Dress trousers"))
```

## 3. Άθροισε τις τιμές των συνόλων

Κάθε κομμάτι ρούχου έχει ένα πεδίο `price` που σχετίζεται με αυτό, οπότε θα ήταν χρήσιμο να μπορείς να συγκρίνεις τη συνολική τιμή των συνόλων.
Υλοποίησε τη συνάρτηση `get_prices()`, η οποία δέχεται έναν πίνακα με συνδυασμούς ρούχων.
Η συνάρτηση πρέπει να επιστρέφει έναν πίνακα με το ίδιο σχήμα, που να περιέχει τις τιμές των συνόλων στις αντίστοιχες θέσεις τους.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combomatrix = get_combinations(tops, bottoms);

julia> get_prices(combomatrix)
2×2 Matrix{Int}::
 65  110
 50   95

julia> filteredmatrix = filter_clashing(combomatrix)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))

julia> get_prices(filteredmatrix)
1-element Vector{Int}:
 50
```

## 4. Φίλτραρε τα ασύμβατα σύνολα

Κάθε κομμάτι ρούχου έχει ένα πεδίο `base_color`.
Χρησιμοποίησε αυτό το πεδίο για να αφαιρέσεις όλους τους συνδυασμούς όπου το πάνω και το κάτω ρούχο έχουν το ίδιο βασικό χρώμα.
Υλοποίησε τη συνάρτηση `filter_clashing()` ώστε να δέχεται έναν πίνακα με συνδυασμούς ρούχων.
Επίστρεψε έναν μονοδιάστατο πίνακα (δηλ. `Vector`) με τους συνδυασμούς που ταιριάζουν.

```julia-repl
julia> tops = (
        Dict("item_name" => "Dress shirt", "base_color" => "blue", "price" => 35),
        Dict("item_name" => "Casual shirt", "base_color" => "black", "price" => 20)
       );

julia> bottoms = (
        Dict("item_name" => "Jeans", "base_color" => "blue", "price" => 30),
        Dict("item_name" => "Dress trousers", "base_color" => "black", "price" => 75)
       );

julia> combos = get_combinations(tops, bottoms);

julia> filter_clashing(combos)
1-element Vector{Tuple{Dict{String, Any}, Dict{String, Any}}}:
 (Dict("price" => 20, "item_name" => "Casual shirt", "base_color" => "black"), Dict("price" => 30, "item_name" => "Jeans", "base_color" => "blue"))
```
