# καρφωτές περιπτώσεις δοκιμών

Αυτή η λύση έχει βάλει καρφωτές τιμές σε ορισμένα από τα δεδομένα δοκιμών.

Γενικά, οι λύσεις δεν θα πρέπει να βασίζονται στα συγκεκριμένα δεδομένα που ελέγχονται. Αντίθετα, οι λύσεις θα πρέπει να λύνουν το πρόβλημα για οποιαδήποτε είσοδο.

Αφαίρεσε τις καρφωτές τιμές των δεδομένων δοκιμών από τη λύση.
