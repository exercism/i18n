# Σχετικά

Οι χαρακτήρες στη Factor είναι *ακέραιοι* (σημεία κώδικα Unicode), οπότε τα απλά αριθμητικά `<`, `>`, `=` σου δίνουν ήδη διάταξη με διάκριση πεζών/κεφαλαίων. Το λεξιλόγιο [`unicode`][unicode] προσθέτει επιπλέον κατηγορήματα που κατανοούν το Unicode και μετατροπή πεζών/κεφαλαίων μεμονωμένου χαρακτήρα.

## Κατηγορήματα

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## Μετατροπή πεζών/κεφαλαίων

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

Τα `>upper`, `>lower` και `>title` σε επίπεδο συμβολοσειράς εφαρμόζουν αυτές τις μετατροπές σε κάθε χαρακτήρα μιας συμβολοσειράς.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
