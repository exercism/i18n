# Υποδείξεις

## 1. Δημιούργησε το αναγνωριστικό των λιμανιών

- Πρέπει να ορίσεις μια [σταθερά][constants] που θα περιέχει την τιμή συμβόλου που δίνεται στις οδηγίες.

## 2. Πάρε τα αναγνωριστικά για άλλα λιμάνια

- Μπορείς να [τεμαχίσεις][slice] μια συμβολοσειρά για να πάρεις μέρη της.
- Οι `Strings` έχουν μια [μέθοδο][upcase] για να μετατρέπουν τα γράμματα σε κεφαλαία.
- Οι `Strings` έχουν μια [μέθοδο][to_sym] για να μετατρέψουν μια συμβολοσειρά σε σύμβολο.

## 3. Προσδιόρισε σε ποιον τερματικό σταθμό πρέπει να δέσει ένα πλοίο

- Το Symbol έχει μια [μέθοδο][to_s] για να μετατρέψει ένα σύμβολο σε συμβολοσειρά.
- Μπορείς να [τεμαχίσεις][slice] μια συμβολοσειρά για να πάρεις μέρη της.
- Χρησιμοποίησε τη συνθήκη [`if`][doc-if], για να ελέγξεις αν το πλοίο μεταφέρει `"OIL"` ή `"GAS"`.
