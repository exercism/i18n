# Υποδείξεις

## Γενικά

- [Οδηγός για τους αριθμούς][numbers].

## 1. Υπολόγισε τον ρυθμό παραγωγής ανά δευτερόλεπτο

- Ο προσδιορισμός του ποσοστού επιτυχίας μπορεί να γίνει μέσω μιας [εντολής υπό συνθήκη][if-statement].
- Η Java επιτρέπει να εφαρμοστεί ο πολλαπλασιασμός σε δύο διαφορετικούς τύπους αριθμών (όπως ένας `int` και ένας `double`). Θα επιστρέψει αυτόματα τον "ευρύτερο" τύπο δεδομένων.
- Οι αριθμοί μπορούν να συγκριθούν χρησιμοποιώντας τους ενσωματωμένους [τελεστές σύγκρισης][comparison-operators] και [τελεστές ισότητας][comparison-operators].

## 2. Υπολόγισε τον αριθμό των λειτουργικών προϊόντων που παράγονται ανά δευτερόλεπτο

- Ενώ ένας `int` μπορεί να μετατραπεί αυτόματα σε `double`, το αντίστροφο δεν ισχύει. Ο λόγος είναι ότι ένας `int` έχει μικρότερη ακρίβεια από έναν `double`, οπότε πρέπει να εφαρμοστεί στρογγυλοποίηση, ενώ και το εύρος των αριθμών που μπορεί να αναπαραστήσει ένας `int` είναι μικρότερο από αυτό ενός `double`. Για να εξαναγκάσεις αυτή τη μετατροπή, μπορείς να χρησιμοποιήσεις μια [μετατροπή σε int][cast-int].
