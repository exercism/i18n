# Tests

Πριν προσπαθήσεις να εκτελέσεις τα tests, βεβαιώσου ότι ο φάκελος της άσκησης έχει στηθεί σωστά ακολουθώντας τα βήματα εγκατάστασης, δηλαδή το `corepack yarn install` και τη ρύθμιση του Editor SDK.

Εκτέλεσε τα tests με:

```bash
$ corepack yarn test
```

## Παραλειμμένα tests

Στις σουίτες tests, όλα τα tests εκτός από το πρώτο έχουν παραλειφθεί.

Μόλις καταφέρεις να περάσει ένα test, μπορείς να ενεργοποιήσεις το επόμενο αλλάζοντας το `xit` σε `it`.
Επιπλέον, τα tests μπορούν να ομαδοποιηθούν με το `xdescribe`.
Ενεργοποίησε την ομάδα αλλάζοντας το σε `describe`.
Τέλος, κάποιες ασκήσεις μπορεί να έχουν προαιρετικά tests `it.skip`.
Αφαίρεσε το `.skip` για να εκτελέσεις το προαιρετικό test.
