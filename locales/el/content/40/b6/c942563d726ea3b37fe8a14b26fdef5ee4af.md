# Σχετικά

Οι φανατικοί της Go (που αποκαλούνται _gophers_) περιγράφουν τη Go ως μια γλώσσα που έχει την εκφραστικότητα δυναμικών γλωσσών όπως η Python ή η Ruby, μαζί με την απόδοση μεταγλωττισμένων γλωσσών όπως η C ή η C++.

Η γλώσσα είναι ανοιχτού κώδικα και ξεκίνησε από μηχανικούς της Google.
Είναι γραμμένη με σύνταξη στυλ C, έχει στατικά τυποποιημένες μεταβλητές, διαχειρίζεται τη μνήμη μέσω garbage collection και μεταγλωττίζεται σε αυτόνομα εκτελέσιμα αρχεία.

Η Go ξεχωρίζει για τις [δυνατότητες ταυτοχρονισμού](https://golang.org/doc/effective_go.html#concurrency) που είναι ενσωματωμένες στον πυρήνα της γλώσσας, για τα πακέτα δικτύωσης στην τυπική βιβλιοθήκη ([όπως έναν διακομιστή ιστού](https://pkg.go.dev/net/http)), καθώς και για τη γρήγορη μεταγλώττιση και την ταχύτητα εκτέλεσης.
Ο απλός, μινιμαλιστικός και συνεπής σχεδιασμός της γλώσσας χαρίζει μια απολαυστική εμπειρία, ενώ τα άφθονα και προσεγμένα εργαλεία της αντιμετωπίζουν παραδοσιακά προβλήματα, όπως τη [συνεπή μορφοποίηση](https://pkg.go.dev/cmd/gofmt) και την [τεκμηρίωση](https://pkg.go.dev/golang.org/x/tools/cmd/godoc).

Η αρχική σελίδα της Go είναι το [go.dev](https://go.dev/) και υπάρχει ένα εξαιρετικό διαδραστικό σεμινάριο στο [tour.go.dev](https://tour.go.dev/).
