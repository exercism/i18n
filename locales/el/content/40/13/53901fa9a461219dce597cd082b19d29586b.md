# Εισαγωγή

Επειδή όλοι οι βασικοί τύποι δεδομένων της Clojure είναι αμετάβλητοι, η γλώσσα προσφέρει *τύπους αναφοράς*, οι οποίοι επιτρέπουν ελεγχόμενη μεταβολή. Οι απλούστεροι και πιο συχνά χρησιμοποιούμενοι από αυτούς ονομάζονται Atoms.

Τα Atoms δημιουργούνται με τη συνάρτηση `atom`, η οποία παίρνει μια αρχική τιμή:

```clojure
(def players (atom ()))
```

Την τρέχουσα τιμή του atom τη λαμβάνεις με αποαναφορά, είτε με το `deref` είτε με τη συντομογραφία `@`:

```clojure
@players
;;=> ()
```

Μπορείς να τροποποιήσεις την τρέχουσα τιμή του atom `players` χρησιμοποιώντας το `swap!`, το οποίο ενημερώνει την τιμή εφαρμόζοντας μια συνάρτηση:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

Η συνάρτηση `reset!` αντικαθιστά την τιμή ενός atom χωρίς να λαμβάνει υπόψη την τρέχουσα τιμή του:

```clojure
(reset! players ())
```
