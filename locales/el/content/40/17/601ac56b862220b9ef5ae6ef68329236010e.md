# Σχετικά

Ο τύπος `Option` είναι ένα enum που παρέχεται από την πρότυπη βιβλιοθήκη. Είναι χρήσιμος για να εκφράζεις μια τιμή που μπορεί να μην υπάρχει.
Ενώ μπορεί να ακούγεται σαν `null` ή `nil`, είναι αρκετά διαφορετικός και ξεχωριστός.

Το `Option<T>` περιέχει άλλους τύπους και έχει δύο παραλλαγές: `Some(T)` και `None`.

Για παράδειγμα, το `Option<u32>` περιέχει τον τύπο `u32`.

## Χρήση

### Χρήση του `T` μέσα σε `Option<T>`

Υπάρχουν αρκετοί συνηθισμένοι ιδιωματισμοί για τη χρήση της τιμής που μπορεί να υπάρχει σε ένα `Option`:

- `if let Some(t) = optional { ... }`.

    Ο ιδιωματισμός `if let` εξάγει την τιμή από ένα `Option<T>` και τη δεσμεύει στη μεταβλητή `t`. Έτσι μπορείς να τη χρησιμοποιήσεις απευθείας σε αυτό το πεδίο του μπλοκ.

- `match optional { Some(t) => {...}, None => {...}}`

    Ο τελεστής `match` σου επιτρέπει επίσης να αποσυσκευάσεις και να χειριστείς περιπτώσεις `None` σε μία εντολή ή έκφραση. Αποτελεί εναλλακτική λύση σε μια αλυσίδα από εντολές if και else. Η χρήση του `match` μπορεί να αυξήσει την αναγνωσιμότητα ορισμένων τμημάτων κώδικα.
- `optional.map(|t| ...)`
   Το `Option::map` ενημερώνει ένα Option επί τόπου, ενδεχομένως με νέο τύπο, από τη συνάρτηση που παρέχεται.

   **Σημείωση**: λειτουργεί στην τιμή που περιέχεται, αν υπάρχει. Η δέσμευση γίνεται ένα `Option<U>`, όπου το closure που δίνεται είναι `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Το ξετύλιγμα ενός `Option<T>` εξάγει το `T` αλλά θα κάνει panic αν το `T` δεν υπάρχει. Είναι βολικό σε ορισμένες περιπτώσεις.

   **Σημαντικό**: Το ξετύλιγμα μπορεί να διευκολύνει την ανάπτυξη βραχυπρόθεσμα ή σε κώδικα δοκιμών, αλλά εισάγει την πιθανότητα εμφάνισης panic κατά την εκτέλεση. Πρέπει να αποφεύγεται όταν είναι δυνατόν.

- `optional.expect("Unexpected None found! Aborting program.)`.
   Η μέθοδος `expect` στο `Option<T>` είναι αρκετά παρόμοια με την `unwrap()` αλλά θα κάνει panic χρησιμοποιώντας το μήνυμα που παρέχεται αν είναι `None`.

## Παραδείγματα

Όταν μια τιμή υπάρχει σε ένα `Option<u32>`:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Όταν μια τιμή *δεν* υπάρχει σε ένα `Option<u32>`:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
