# Εισαγωγή

Τα περισσότερα δεδομένα στη Factor βρίσκονται μέσα σε *ακολουθίες*. Οι πίνακες (`{ … }`), τα διανύσματα (`V{ … }`) και οι συμβολοσειρές μοιράζονται το ίδιο [πρωτόκολλο][sequence-protocol] από το [`sequences`][sequences].

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

Οι συναθροίσεις (`sum`, `count`, `any?`, `all?`) και τα κατηγορήματα όπως `empty?` και `member?` λειτουργούν ομοιόμορφα σε κάθε τύπο ακολουθίας. Δημιουργία νέων ακολουθιών χωρίς μετάλλαξη: `prefix`, `suffix`, `append`, `unclip`, `unclip-last`.

Τα `>array`, `>vector` και `>string` (στο [`arrays`][arrays] και στα αντίστοιχα λεξιλόγια) μετατρέπουν από τον έναν τύπο ακολουθίας στον άλλο όταν χρειάζεσαι να πάρεις πίσω έναν συγκεκριμένο τύπο από μια γενική πράξη.

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
