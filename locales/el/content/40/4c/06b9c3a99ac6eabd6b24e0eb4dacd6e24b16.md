# Εισαγωγή

## Περισσότερα για τα μοτίβα

Θυμήσου από την έννοια Θεμελιώδη ότι ένα πρόγραμμα AWK αποτελείται από **ζεύγη μοτίβου-ενέργειας**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

### Τι εννοούμε με τον όρο "μοτίβο";

Το "μοτίβο" είναι οποιαδήποτε έκφραση AWK.
Το κατά πόσο το αποτέλεσμα της έκφρασης είναι αληθές καθορίζει αν θα εκτελεστεί η ενέργεια.

### Το κενό μοτίβο

Το μοτίβο μπορεί να παραλειφθεί.
Σε αυτή την περίπτωση, η ενέργεια εκτελείται για κάθε εγγραφή.

Μπορούμε να εκτυπώσουμε όλα τα ονόματα χρηστών στο αρχείο passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

### Κανονικές εκφράσεις

Η AWK μπορεί να συγκρίνει συμβολοσειρές με κανονικές εκφράσεις για να πάρει ένα Boolean αποτέλεσμα.

Χρησιμοποίησε τον τελεστή αντιστοίχισης κανονικών εκφράσεων `~` για να αντιστοιχίσεις ένα συγκεκριμένο πεδίο.
Αυτός ο τελεστής παίρνει μια συμβολοσειρά ως αριστερό τελεστέο και μια κανονική έκφραση ως δεξιό τελεστέο.
Ένα κυριολεκτικό κανονικής έκφρασης περικλείεται σε κάθετες `/`.

Για να βρεις τους χρήστες στο αρχείο passwd που συνδέονται με bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

Το `!~` είναι ο τελεστής "η κανονική έκφραση **δεν** ταιριάζει".

Για να αντιστοιχίσεις μια κανονική έκφραση με την τρέχουσα εγγραφή, μπορείς να γράψεις `$0 ~ /regex/`.
Αυτό είναι τόσο συνηθισμένο που υπάρχει συντομογραφία: μπορείς να παραλείψεις το `$0` και το `~` και να γράψεις απλώς `/regex/`

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Σύγκρινε αυτή τη μονόγραμμη εντολή AWK με την αντίστοιχη εντολή grep

```sh
grep 'regex' data.txt
```

Η AWK σου δίνει μια ολόκληρη γλώσσα προγραμματισμού χωρίς να θυσιάζει τη συνοπτικότητα.
~~~~

Θα δούμε περισσότερα για την παραλλαγή κανονικών εκφράσεων της GNU AWK σε επόμενη ενότητα.

### Εκφράσεις

Οι εκφράσεις της AWK (αριθμητικές, λογικές ή άλλες) μπορούν να χρησιμοποιηθούν ως μοτίβα.

Για να εξαγάγεις όλους τους χρήστες με UID 1000 ή μεγαλύτερο:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Θυμήσου ότι οι ψευδείς τιμές της AWK είναι ο αριθμός μηδέν και η κενή συμβολοσειρά, ενώ όλοι οι άλλοι αριθμοί ή συμβολοσειρές είναι αληθείς.
Οποιαδήποτε έκφραση που αξιολογείται σε έναν αριθμό ή μια συμβολοσειρά μπορεί να χρησιμοποιηθεί ως μοτίβο.

### Συναρτήσεις

Οποιαδήποτε [ενσωματωμένη][builtins] ή [οριζόμενη από τον χρήστη][user-defined] συνάρτηση μπορεί να χρησιμοποιηθεί σε μια έκφραση, άρα και στο μοτίβο.
Μερικά παραδείγματα:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

### Σταθερά μοτίβα

Ένα συνηθισμένο ιδίωμα της AWK είναι:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

Το `1` είναι ένα αληθές μοτίβο χωρίς σχετιζόμενη ενέργεια.
Αυτό σημαίνει "εκτύπωσε την τρέχουσα εγγραφή".
