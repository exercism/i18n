# Σχετικά

Οι τύποι που υλοποιούν τη διεπαφή [`IEnumerable<T>`][IEnumerable] είναι γνωστοί ως _enumerable_.
Όλοι οι ενσωματωμένοι τύποι συλλογών υλοποιούν αυτή τη διεπαφή.

Ένας enumerable τύπος μπορεί να διατραβηχθεί με έναν βρόχο `foreach`:

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

Για να υλοποιήσει το `IEnumerable<T>`, ένας τύπος πρέπει να υλοποιήσει μία μέθοδο: `IEnumerator<T> GetEnumerator()`.
Όπως φαίνεται, ένας enumerable τύπος αναθέτει την πραγματική διάσχιση μιας συλλογής σε έναν τύπο `IEnumerator<T>`.
Αυτή η διεπαφή έχει μία ιδιότητα και τρεις μεθόδους προς υλοποίηση:

- `public T Current { get; }`: επιστρέφει το τρέχον στοιχείο.
- `public bool MoveNext ();`: μετακινείται στο επόμενο στοιχείο, επιστρέφοντας `true` αν η μετακίνηση στο επόμενο στοιχείο ήταν επιτυχής, και `false` αν όχι (δεν υπάρχουν άλλα στοιχεία).
- `public void Reset ();`: επαναφέρει τον απαριθμητή στην αρχική του κατάσταση (πριν από το πρώτο στοιχείο).

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
