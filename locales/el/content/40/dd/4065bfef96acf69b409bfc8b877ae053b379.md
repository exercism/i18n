# Οδηγίες

Δύο βιολονίστες κάνουν πρόβα ένα ντουέτο. Κάθε μέρος είναι ένας πίνακας που περιέχει τον αριθμό των νότων σε κάθε μέτρο, και τα μέρη δεν έχουν πάντα το ίδιο μήκος.

Και οι τέσσερις εργασίες ανήκουν στην κλάση `DUET_PRACTICE`.

## 1. Πόσα μέτρα παίζουν μαζί;

Παίζουν μαζί για όσο και τα δύο μέρη έχουν ακόμα κάποιο μέτρο.

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. Πόσα μέτρα ταιριάζουν;

Μέτρησε τα μέτρα όπου και τα δύο μέρη έχουν τον ίδιο αριθμό νότων. Μόνο τα μέτρα που έχουν και τα δύο μέρη μπορούν να ταιριάξουν.

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. Ποιος παίζει περισσότερο;

Μέτρησε τα μέτρα όπου το πρώτο μέρος έχει περισσότερες νότες από το δεύτερο.

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. Δώσε βάρος στα μέτρα

Τα επόμενα μέτρα είναι πιο δύσκολα, οπότε ένα μέτρο μετράει όσο και η θέση του: το πρώτο μέτρο μετράει μία φορά, το δεύτερο δύο φορές, το τρίτο τρεις φορές. Πολλαπλασίασε τις νότες κάθε μέτρου με τον αριθμό του και πρόσθεσέ τις όλες μαζί.

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

Δηλαδή 1×4 + 2×4 + 3×8. Τα μέτρα αριθμούνται από το ένα, όχι από το μηδέν.
