# Προσθήκη οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Για απλότητα και αναγνωσιμότητα: Σκέψου να χρησιμοποιήσεις τις συναρτήσεις συλλογών της Scala αντί για τις μεθόδους `String` της Java.
Θυμήσου ότι στη Scala ένα `String` είναι επίσης σιωπηρά ένα `Seq[Char]`, οπότε μπορείς να τις καλέσεις εξίσου εύκολα με τις μεθόδους `String`.

Μερικά παραδείγματα:
- `filter` αντί για `replaceAll`
- `take`, `takeRight`, `drop`, `head`, `tail` αντί για `substring`

Μια άλλη ιδέα που αξίζει να εξερευνήσεις είναι να μετατρέψεις το `String` σε `List[Char]` και μετά να χρησιμοποιήσεις [αντιστοίχιση προτύπων][pattern matching] με τον τελεστή `::`.

[pattern matching]: http://alvinalexander.com/scala/how-to-use-lists-nil-cons-scala-match-case-expressions
