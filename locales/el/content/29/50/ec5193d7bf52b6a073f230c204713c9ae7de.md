# Δεσμευμένες ρουτίνες

Όλα όσα έχουμε δει μέχρι τώρα διακινούσαν *τιμές*: αριθμούς, συμβολοσειρές, αντικείμενα. Μια **δεσμευμένη ρουτίνα** σου επιτρέπει να διακινείς την ίδια τη ρουτίνα: κάτι που θα κληθεί αργότερα, από κώδικα που δεν ξέρει τι είναι.

Ο αναπληρωτής ηθοποιός είναι ακριβώς αυτή η ιδέα: ο διευθυντής σκηνής κρατά έναν τρόπο να παιχτεί ο ρόλος, χωρίς να ξέρει ποιος είναι ή τι θα κάνει.

## Δημιουργώντας μία

Το `bind` παίρνει μια κλήση που έχει κενά, γραμμένα `_`:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

Το `part` είναι τώρα μια τιμή σαν οποιαδήποτε άλλη. Η κλήση του γίνεται αργότερα:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## Ο τύπος

Ο τύπος μιας δεσμευμένης ρουτίνας είναι `ROUT`, με τους τύπους των ορισμάτων σε άγκιστρα και τον τύπο επιστροφής μετά από άνω κάτω τελεία:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

Διάβασε το `ROUT{STR}:STR` ως "μια ρουτίνα που παίρνει ένα `STR` και επιστρέφει ένα `STR`".

| Γράφεται | Σημαίνει |
| --- | --- |
| `ROUT{STR}:STR` | παίρνει ένα `STR`, επιστρέφει ένα `STR` |
| `ROUT{INT,INT}:BOOL` | παίρνει δύο `INT`, επιστρέφει ένα `BOOL` |
| `ROUT{STR}` | παίρνει ένα `STR`, δεν επιστρέφει τίποτα |
| `ROUT:INT` | δεν παίρνει τίποτα, επιστρέφει ένα `INT` |

Εφόσον είναι τύπος, μπορεί να είναι όρισμα:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

Το `rehearse` δεν έχει ιδέα τι κάνει το `part`. Αυτό είναι το νόημα: μπορείς να του δώσεις το `shout`, ή το `whisper`, ή οτιδήποτε άλλο αυτής της μορφής.

## Συμπληρώνοντας μερικά από τα ορίσματα

Δε χρειάζεται κάθε όρισμα να είναι κενό. Ό,τι γράφεται ολόκληρο καθορίζεται τη στιγμή που γίνεται το bind:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

Το `twice` παίρνει μόνο τη γραμμή, γιατί το `2` έχει ήδη αποφασιστεί. Η τιμή υπολογίζεται τη στιγμή του binding και διατηρείται, οπότε αν αλλάξεις μετά τη μεταβλητή από την οποία προήλθε, αυτό δεν έχει καμία διαφορά.

Έτσι μια γενική ρουτίνα γίνεται πολλές συγκεκριμένες.

## Δένοντας και το αντικείμενο

Για μια ρουτίνα πάνω σε ένα αντικείμενο, το αντικείμενο είναι το πρώτο πράγμα στην κλήση και μπορεί να καθοριστεί ή να αφεθεί ως κενό:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
