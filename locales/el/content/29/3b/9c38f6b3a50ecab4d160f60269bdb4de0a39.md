# Σχετικά με τους βρόχους for-each

Ο [βρόχος for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) παρέχει έναν μηχανισμό για την εκτέλεση ενός μπλοκ κώδικα για κάθε στοιχείο σε μια συλλογή.
Κάποια τεκμηρίωση (π.χ. η τεκμηρίωση της Oracle) τους αναφέρει ως ενισχυμένους βρόχους for.

Ακολουθεί η γενική σύνταξη:

```java
for(declaration: collection) {
    body;
}
```

Η `declaration` δηλώνει τη μεταβλητή που χρησιμοποιείται για να κρατά τις τιμές που ανατίθενται από τη συλλογή.

Η `collection` είναι ένας πίνακας ή μια συλλογή που κρατά τις τιμές που θα ανατεθούν στη μεταβλητή του βρόχου.

Το `body` περιέχει τις εντολές που θα εκτελεστούν μία φορά για κάθε τιμή στη συλλογή.

Για παράδειγμα:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

που τυπώνει:

```text
a
e
i
o
u
```

Γενικά, ένας βρόχος `for-each` προτιμάται από έναν βρόχο `for` για τους παρακάτω λόγους:

- Ένας βρόχος `for-each` εγγυάται ότι θα διατρέξει _όλες_ τις τιμές.
- Ένας βρόχος `for-each` είναι πιο _δηλωτικός_, που σημαίνει ότι ο κώδικας επικοινωνεί _τι_ κάνει, αντί για _πώς_ το κάνει.
- Ένας βρόχος `for-each` είναι αλάνθαστος, ενώ με τους βρόχους `for` είναι εύκολο να έχεις ένα σφάλμα off-by-one (σκέψου τη χρήση του `<` εναντίον του `<=`).
- Ένας βρόχος `for-each` λειτουργεί με όλους τους τύπους συλλογών, συμπεριλαμβανομένων εκείνων που δεν υποστηρίζουν τη χρήση θέσης για πρόσβαση σε στοιχεία (π.χ. ένα `Set`).
