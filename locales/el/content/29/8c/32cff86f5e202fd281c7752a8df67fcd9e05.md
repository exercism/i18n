# Κλάσεις

Οι κλάσεις είναι μια μονάδα οργάνωσης κώδικα στην PHP.
Ο κώδικας που περιγράφει τη συμπεριφορά ενός στοιχείου ή τη συμπεριφορά μιας διαδικασίας μπορεί να ομαδοποιηθεί σε μια κλάση.
Οι συναρτήσεις που ανήκουν σε μια κλάση ονομάζονται `methods` κατά σύμβαση.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Οι κλάσεις δημιουργούνται με τη λέξη-κλειδί `new`, η οποία δεσμεύει μνήμη για το στιγμιότυπο της κλάσης και καλεί τη μέθοδο κατασκευαστή της κλάσης.
Ένα στιγμιότυπο κλάσης μπορεί να εκχωρηθεί σε μια μεταβλητή.
Για να καλέσουμε τις μεθόδους ενός στιγμιότυπου κλάσης, μπορούμε να χρησιμοποιήσουμε τον τελεστή πρόσβασης `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Ένα στιγμιότυπο κλάσης μπορεί να αναφερθεί στον εαυτό του χρησιμοποιώντας την ειδική μεταβλητή `$this`.
Οι κλάσεις μπορούν επίσης να έχουν ιδιότητες, οι οποίες λειτουργούν σαν μεταβλητές δεμένες με το στιγμιότυπο του αντικειμένου της κλάσης.
Στις ιδιότητες αυτές μπορεί να γίνει αναφορά είτε εσωτερικά είτε εξωτερικά.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
