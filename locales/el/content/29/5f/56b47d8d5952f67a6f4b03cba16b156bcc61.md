# Σχετικά

Οι συμβολοσειρές στη F# είναι αμετάβλητα αντικείμενα που αναπαριστούν κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.). Τα διπλά εισαγωγικά χρησιμοποιούνται για να οριστεί ένα στιγμιότυπο `string`:

```fsharp
let fruit = "Apple"
```

Μπορείς να επεξεργαστείς μια συμβολοσειρά καλώντας μία από τις [μεθόδους][methods] ή τις [ιδιότητες][properties] της, ή χρησιμοποιώντας μία από τις συναρτήσεις του [module `String`][string-module]. Επειδή οι τιμές συμβολοσειρών δεν μπορούν ποτέ να αλλάξουν αφού οριστούν, όλες οι μέθοδοι/συναρτήσεις χειρισμού συμβολοσειρών θα επιστρέψουν μια νέα συμβολοσειρά.

Μια συμβολοσειρά οριοθετείται από χαρακτήρες διπλού εισαγωγικού (`"`). Κάποιοι ειδικοί χαρακτήρες χρειάζονται [διαφυγή][escaping] χρησιμοποιώντας τον χαρακτήρα της ανάστροφης καθέτου (`\`). Οι συμβολοσειρές μπορούν επίσης να έχουν ως πρόθεμα το σύμβολο at (`@`), που τις κάνει [verbatim συμβολοσειρά][verbatim] η οποία θα αγνοήσει τυχόν χαρακτήρες διαφυγής.

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

Εναλλακτικά, οι συμβολοσειρές μπορούν να οριστούν χρησιμοποιώντας [τριπλά εισαγωγικά][triple-quoted] (`"""`), που επιτρέπουν να χρησιμοποιήσεις ένα διπλό εισαγωγικό μέσα στη συμβολοσειρά χωρίς να το κάνεις διαφυγή.

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

Τέλος, η συνένωση συμβολοσειρών μπορεί να γίνει μέσω του [τελεστή `+`][plus-operator]:

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
