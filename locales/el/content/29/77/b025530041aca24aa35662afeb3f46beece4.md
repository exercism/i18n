# Προσθήκη στις οδηγίες

## Υποδείξεις

Πρέπει να υλοποιήσεις τη συνάρτηση `convert` που επιστρέφει τον αριθμό μετατραμμένο σε ήχο σταγόνας βροχής. Μπορείς να χρησιμοποιήσεις την υπογραφή που δίνεται αν δεν είσαι σίγουρος για τους τύπους, αλλά μην την αφήσεις να περιορίσει τη δημιουργικότητά σου:

```haskell
convert :: Int -> String
```

Αυτή η άσκηση δουλεύει με κειμενικά δεδομένα. Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων. Για πιο αποδοτικό χειρισμό κειμενικών δεδομένων, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να

- Διαβάσεις για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη Haskell.
- Προσθέσεις `- text` στη λίστα με τις εξαρτήσεις σου στο package.yaml.
- Κάνεις import το `Data.Text` με [τον ακόλουθο τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- Τώρα μπορείς να γράψεις π.χ. `convert :: Int -> Text` και να αναφερθείς σε συνδυαστές του `Data.Text` ως π.χ. `T.pack`.
- Κοίταξε την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html),
- Έπειτα μπορείς να αντικαταστήσεις όλες τις εμφανίσεις του `String` με `Text` στο Raindrops.hs:

```haskell
convert :: Int -> Text
```

Αυτό το μέρος είναι εντελώς προαιρετικό.
