# Τεστ

## Εκτέλεση των τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την παρακάτω εντολή:

```bash
bats test-<exercise-slug>.bats
```

### Το bats είναι υλοποιημένο σε bash

Το αρχείο bats είναι ένα σενάριο bash, με κάποιες ειδικές συναρτήσεις που αναγνωρίζει η εντολή `bats`.
Θα δεις κάποια τεστ που μοιάζουν με το παρακάτω:

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Αυτή η σύνταξη `<<<` είναι ένα *Here String* της bash.
Στέλνει τη συμβολοσειρά που βρίσκεται στα δεξιά στην τυπική είσοδο του προγράμματος που βρίσκεται στα αριστερά.
Είναι περίπου το ίδιο με

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Παραλειπόμενα τεστ

Το να λύσεις μια άσκηση σημαίνει να περάσουν όλα τα τεστ της.
Από προεπιλογή, όταν τρέχεις τα τεστ εκτελείται μόνο ένα τεστ (το πρώτο).
Αυτό γίνεται σκόπιμα, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσει μόνο αυτό το ένα τεστ.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ σχολιάζοντας ή αφαιρώντας τις

    [[ $BATS_RUN_SKIPPED == true ]] || skip

σημειώσεις που προηγούνται των άλλων τεστ.

## Παράκαμψη των παραλείψεων

Για να τρέξεις όλα τα τεστ, συμπεριλαμβανομένων και αυτών με τις σημειώσεις `skip`, μπορείς να εκτελέσεις:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

ή μπορείς να σχολιάσεις ή να διαγράψεις τη γραμμή:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

από το αρχείο τεστ.
