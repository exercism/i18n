# Επανάληψη

Στον προγραμματισμό, η [επανάληψη][iteration] αναφέρεται στη διαδικασία επανάληψης ενός μπλοκ κώδικα πολλές φορές.
Αυτό μπορεί να γίνει χρησιμοποιώντας έννοιες όπως οι `while` βρόχοι και οι `until` βρόχοι.
Μπορεί επίσης να γίνει με αναδρομή, δηλαδή μια συνάρτηση που καλεί τον εαυτό της.

Ωστόσο, τις περισσότερες φορές θέλεις να επαναλάβεις πάνω σε μια συλλογή στοιχείων, όπως έναν `Array`, ένα `Range` ή μια `String`.
Τόσο η κλάση `Array` όσο και η κλάση `Range` στη Crystal περιλαμβάνουν το module [`Enumerable`][enumerable], το οποίο παρέχει έναν αριθμό μεθόδων για επανάληψη πάνω στα στοιχεία.
Εν τω μεταξύ, η κλάση `String` έχει το δικό της σύνολο μεθόδων για επανάληψη πάνω στους χαρακτήρες.

Η Crystal επίσης δεν έχει καμία εντολή `for` όπως οι άλλες γλώσσες.
Αντ' αυτού, έχει αρκετές μεθόδους που μπορούν να χρησιμοποιηθούν για επανάληψη.

## Επανάληψη

Ο πιο συνηθισμένος τρόπος για να επαναλάβεις πάνω σε μια συλλογή είναι να χρησιμοποιήσεις τη μέθοδο [`each`][each], η οποία περνάει κάθε στοιχείο της συλλογής σε ένα μπλοκ.
Αυτό μπορεί να γίνει εύκολα με ένα `Range`.
Ας πούμε ότι θέλεις να κάνεις βρόχο από το 1 έως το 3, μπορείς να χρησιμοποιήσεις τη μέθοδο `each` για να επαναλάβεις πάνω στο `Range`.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ακόμα πιο απλά, αν θέλεις απλώς να επαναλάβεις έναν αριθμό φορών, μπορείς να χρησιμοποιήσεις τη μέθοδο [`times`][times], η οποία υπάρχει στην κλάση `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Επανάληψη πάνω σε μια `String`

Μια `String` είναι μια ακολουθία χαρακτήρων και δεν ανήκει στο module `Enumerable`, που σημαίνει ότι έχει το δικό της σύνολο μεθόδων για επανάληψη πάνω στους χαρακτήρες.
Ο πιο συνηθισμένος τρόπος για να επαναλάβεις πάνω σε μια `String` είναι να χρησιμοποιήσεις τη μέθοδο [`each_char`][each_char], η οποία περνάει κάθε χαρακτήρα της `String` σε ένα μπλοκ.

~~~~exercism/note
Η μέθοδος `each_char` περνάει ένα αντικείμενο `Char` και όχι ένα αντικείμενο `String` στο μπλοκ.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Ένας άλλος τρόπος για να επαναλάβεις πάνω σε μια `String` είναι να χρησιμοποιήσεις τη μέθοδο [`each_line`][each_line].
Αυτή η μέθοδος χρησιμοποιείται κυρίως όταν διαβάζεις ένα αρχείο γραμμή προς γραμμή.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Επανάληψη πάνω σε ένα αντικείμενο που περιλαμβάνει το module `Enumerable`

Το module [`Enumerable`][enumerable] παρέχει έναν αριθμό μεθόδων για επανάληψη πάνω στα στοιχεία μιας συλλογής.
Οι συλλογές που περιλαμβάνουν το module `Enumerable` είναι οι `Array`, `Range`, `Hash`, `Set` και άλλες, οι οποίες θα καλυφθούν σε επόμενες έννοιες.

Ο πιο συνηθισμένος τρόπος για να επαναλάβεις πάνω σε έναν `Array` είναι να χρησιμοποιήσεις τη μέθοδο [`each`][each], η οποία περνάει κάθε στοιχείο του `Array` σε ένα μπλοκ.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Η μέθοδος [`map`][map] είναι ένας άλλος τρόπος για να επαναλάβεις πάνω σε έναν `Array`, επιστρέφει έναν νέο `Array` που περιέχει τα αποτελέσματα της εφαρμογής του μπλοκ σε κάθε στοιχείο.
Είναι παρόμοια με τη μέθοδο `each`, αλλά επιστρέφει έναν νέο `Array` με τα μετασχηματισμένα στοιχεία.
Ο μετασχηματισμός είναι πολύ χρήσιμος όταν θέλεις να εφαρμόσεις μια συνάρτηση σε κάθε στοιχείο της συλλογής, κάτι που είναι μια συνηθισμένη λειτουργία.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Με μια ροή ελέγχου όπως η `if` μπορείς επίσης να φιλτράρεις ποια στοιχεία θα μετασχηματίσεις.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### Με θέση

Μερικές φορές χρειάζεται να ξέρεις τη θέση του στοιχείου πάνω στο οποίο επαναλαμβάνεις, μπορείς να χρησιμοποιήσεις τη μέθοδο [`each_with_index`][each_with_index] ή τη μέθοδο [`map_with_index`][map_with_index] γι' αυτό.
Περνάει κάθε στοιχείο και τη θέση του σε ένα μπλοκ, η μέθοδος δέχεται επίσης ένα προαιρετικό όρισμα για να ορίσεις τη θέση από την οποία ξεκινά.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Σημείωσε ότι η μέθοδος [`each_char_with_index`][each_char_with_index] είναι επίσης διαθέσιμη για αντικείμενα `String`.

### sum

Η μέθοδος [`sum`][sum] επιστρέφει το άθροισμα όλων των στοιχείων της συλλογής, δέχεται επίσης ένα προαιρετικό μπλοκ για να μετασχηματίσεις τα στοιχεία πριν τα αθροίσεις.
Δέχεται επίσης ένα προαιρετικό όρισμα για να ορίσεις την αρχική τιμή του αθροίσματος.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

Η [`reduce`][reduce], ή fold όπως είναι γνωστή σε άλλες γλώσσες, είναι μια μέθοδος που, με μια μέθοδο συνδυασμού και μια αρχική τιμή, θα συνδυάσει όλα τα στοιχεία της συλλογής.
Η μέθοδος `reduce` έχει έναν συσσωρευτή που περνάεται στο μπλοκ, ο συσσωρευτής είναι το αποτέλεσμα της προηγούμενης επανάληψης.
Αυτό γίνεται μια αναδρομική διαδικασία που θα συνδυάσει όλα τα στοιχεία της συλλογής.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

Η `reduce` μπορεί να φαίνεται παρόμοια με τη `sum`, αλλά η `reduce` είναι πιο ευέλικτη γιατί σου επιτρέπει να ορίσεις την αρχική τιμή του συσσωρευτή και τη μέθοδο συνδυασμού.
Η `reduce` μπορεί να χρησιμοποιηθεί για να υλοποιήσεις τη `sum`, τη `count` και άλλες μεθόδους.
