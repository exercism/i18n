# Υποδείξεις

## Γενικά

Η γλώσσα SGF έχει έναν αναδρομικό ορισμό:

```none
GameTree = "(" Sequence { GameTree } ")"
```

Δηλαδή, ένα GameTree είναι ένα κομμάτι κειμένου που ξεκινά με μια `(`, ακολουθείται από κάποιο κείμενο που ονομάζεται "Sequence" (μια λίστα από κόμβους παιχνιδιού), _ακολουθούμενο από **μηδέν ή περισσότερα** θυγατρικά GameTrees_, και τελειώνει με μια `)`.

Ίσως θελήσεις να χρησιμοποιήσεις κανονικές εκφράσεις για να αναλύσεις ένα κείμενο SGF.
Ωστόσο, επειδή τα δέντρα παιχνιδιού μπορούν να είναι εμφωλευμένα μέσα σε άλλα δέντρα παιχνιδιού σε οποιοδήποτε βάθος, οι συνηθισμένες κανονικές εκφράσεις δεν είναι αρκετά ισχυρές για να παρακολουθούν τα επίπεδα εμφώλευσης.

Υπάρχουν μερικές προσεγγίσεις για να λύσεις αυτή την άσκηση:

### Μηχανή καταστάσεων

Θα μπορούσες να διατρέξεις τη συμβολοσειρά εισόδου χαρακτήρα προς χαρακτήρα, κρατώντας μια μεταβλητή που να κρατά την τρέχουσα θέση σου.
Μπορείς να παρακολουθείς την τρέχουσα κατάσταση του κειμένου που έχεις αναλύσει με βάση τον χαρακτήρα στην τρέχουσα θέση.
Η "τρέχουσα κατάσταση" μπορεί να είναι κάτι σαν "διαβάζω ένα όνομα ιδιότητας" ή "μέσα σε μια τιμή ιδιότητας".
Με αυτή την προσέγγιση υπάρχουν πολλές τιμές που πρέπει να παρακολουθείς.

### Αναλυτής

Ένας [αναλυτής βασισμένος σε PEG][PEG-parser] είναι ένας πολύ καλός τρόπος για να αναλύσεις μια γλώσσα που έχει καθορισμένη γραμματική.
Το [LPeg][LPeg] είναι ένας αναλυτής PEG και αποτελεί μία από τις απαιτούμενες εξαρτήσεις του MoonScript, οπότε θα έχεις ήδη πρόσβαση σε αυτό.
Ένας αναλυτής σου επιτρέπει να γράψεις κανόνες για το πώς πρέπει να είναι το κείμενο.
Για παράδειγμα, "ένα όνομα ιδιότητας αποτελείται μόνο από κεφαλαία γράμματα" ή "μια τιμή ιδιότητας περικλείεται σε αγκύλες".
Στη συνέχεια, ο αναλυτής αναλαμβάνει τη δύσκολη δουλειά του ταιριάσματος του κειμένου εισόδου με τους κανόνες σου.

Μερικές πηγές εκμάθησης για το LPeg:

* [Οδηγός για το LPeg][tutorial] στο wiki του lua-users.
* Το [Mastering LPeg][mastering-lpeg] είναι γραμμένο από έναν από τους δημιουργούς του LPeg και της ίδιας της Lua. 
  Είναι καθηγητής πανεπιστημίου και ερευνητής, οπότε αυτό το κείμενο διαβάζεται σαν ακαδημαϊκή εργασία.
