# Σχετικά

Οι ακέραιοι είναι αριθμοί χωρίς υποδιαστολή (όπως `-6`, `0`, `25`, `1234`, κ.λπ.)

Ο τύπος ακεραίων χωρίζεται σε δύο υποτύπους, τους `fixnum` και `bignum`.
* Ο `fixnum` ορίζεται ως ένας προσημασμένος ακέραιος με τουλάχιστον 16 bits, αλλά είναι πιθανότατα μεγαλύτερος ανάλογα με την υλοποίηση.
* Ο `bignum` είναι ένας τύπος που περιέχει οποιονδήποτε ακέραιο μεγαλύτερο από έναν `fixnum`.

Στην Common Lisp, οι ακέραιοι μπορούν να είναι αυθαίρετα μεγάλοι ή μικροί, οπότε δεν χρειάζεται να ανησυχείς για "υπερχείλιση" όταν δουλεύεις μαζί τους.
Ενώ κάποιες άλλες γλώσσες μπορεί να εμφανίσουν απώλεια ακρίβειας ή να αναδιπλώσουν μεγάλους αριθμούς, το μέγεθος των ακεραίων στην Common Lisp περιορίζεται μόνο από τη διαθέσιμη μνήμη.

```lisp
;; Big integers are no problem
(expt 2 200) ; => 1606938044258990275541962092341162602522202993782792835301376
```
