# Υποδείξεις

## 1. Δημιούργησε έναν νέο πίνακα υψηλών σκορ

- Δημιούργησε ένα νέο αντικείμενο χρησιμοποιώντας άγκιστρα.
- Γράψε το κλειδί ως συμβολοσειρά, ώστε το κλειδί να μπορεί να περιέχει κενά.
- Χώρισε το κλειδί από την τιμή με άνω και κάτω τελεία.

## 2. Πρόσθεσε παίκτες σε έναν πίνακα σκορ

- Χρησιμοποίησε σημειογραφία με αγκύλες για να προσθέσεις ένα κλειδί με όνομα που είναι αποθηκευμένο σε μια μεταβλητή (το όρισμα).
- Χρησιμοποίησε τον τελεστή ανάθεσης (`=`) για να ορίσεις μια τιμή για το νέο κλειδί.
- Επίστρεψε την παράμετρο του πίνακα σκορ αφού προσθέσεις τον παίκτη.

## 3. Αφαίρεσε παίκτες από έναν πίνακα σκορ

- Χρησιμοποίησε τον [τελεστή delete][mdn-delete].
- Αναφέρσου στο κλειδί όπως έκανες στην προηγούμενη εργασία (σημειογραφία με αγκύλες).

## 4. Αύξησε το σκορ ενός παίκτη

- Πρώτα σκέψου πώς να εκφράσεις τη νέα τιμή που θέλεις να αναθέσεις.
- Στη συνέχεια χρησιμοποίησε τον τελεστή ανάθεσης, όπως στην εργασία 2, για να ορίσεις αυτή τη νέα τιμή.
- Αν δεν το έχεις κάνει ήδη, μπορείς να αξιοποιήσεις τον [συντομευμένο τελεστή ανάθεσης][mdn-shorthand-assignment] `+=`.

## 5. Εφάρμοσε τους πόντους μπόνους της Δευτέρας

- Χρησιμοποίησε έναν `for...in` βρόχο για να διατρέξεις όλα τα κλειδιά του αντικειμένου.
- Για κάθε κλειδί, όρισε τη νέα τιμή όπως έκανες στην εργασία 4.

[mdn-shorthand-assignment]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Addition_assignment
