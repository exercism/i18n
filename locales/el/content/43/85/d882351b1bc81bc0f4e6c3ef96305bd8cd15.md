# Εισαγωγή

Οι μέθοδοι επέκτασης επιτρέπουν την προσθήκη μεθόδων σε υπάρχοντες τύπους χωρίς να δημιουργήσεις νέο παράγωγο τύπο, χωρίς επαναμεταγλώττιση ή άλλη τροποποίηση του αρχικού τύπου. Ορίζονται ως στατικές μέθοδοι αλλά καλούνται χρησιμοποιώντας σύνταξη μεθόδου στιγμιοτύπου. Η πρώτη τους παράμετρος προηγείται από τον τροποποιητή `this` και καθορίζει σε ποιον τύπο ενεργεί η μέθοδος, και εισάγονται στο πεδίο εφαρμογής σε επίπεδο χώρου ονομάτων.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
