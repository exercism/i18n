# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος    | Περιγραφή                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος      | διεύθυνση | συμβολοσειρά ονόματος με τερματισμό null |
| `$a1`    | είσοδος      | ακέραιος | αριθμός                       |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος με τερματισμό null |
| `$t0-9`  | προσωρινός   | οτιδήποτε | για προσωρινή αποθήκευση      |
