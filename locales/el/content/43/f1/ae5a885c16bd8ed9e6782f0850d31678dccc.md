# Οδηγίες

Σε αυτή την άσκηση, υλοποιείς έναν τρόπο για να παρακολουθείς τις υψηλές βαθμολογίες του πιο δημοφιλούς παιχνιδιού στην τοπική αίθουσα με ηλεκτρονικά παιχνίδια.

Έχεις 7 συναρτήσεις να υλοποιήσεις, όλες σχετικές με την επιστροφή και τον χειρισμό ενός λεξικού με δεδομένα υψηλών βαθμολογιών.

## 1. Ορισμός νέου λεξικού υψηλών βαθμολογιών

Δημιούργησε μια συνάρτηση `newScoreBoard()` που δεν παίρνει παραμέτρους και επιστρέφει ένα νέο λεξικό υψηλών βαθμολογιών, το οποίο χρησιμοποιεί τιμές τύπου `String` για τα κλειδιά και τιμές τύπου `Int` για τις τιμές.

## 2. Προσθήκη παικτών στο λεξικό υψηλών βαθμολογιών

Για να προσθέσεις έναν παίκτη στο λεξικό υψηλών βαθμολογιών, όρισε τη συνάρτηση `addPlayer(_:_:_:)`, η οποία παίρνει 3 παραμέτρους:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες. 
    Θα πρέπει να είναι παράμετρος in-out.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά.
- Η τρίτη παράμετρος είναι η βαθμολογία ως ακέραιος. 
    Η παράμετρος είναι προαιρετική, υλοποίησε την τρίτη παράμετρο με προεπιλεγμένη τιμή 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Αφαίρεση παικτών από το λεξικό βαθμολογιών

Για να αφαιρέσεις έναν παίκτη από το λεξικό υψηλών βαθμολογιών, όρισε τη συνάρτηση `removePlayer(_:_:)`, η οποία παίρνει 2 παραμέτρους:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες. 
    Θα πρέπει να είναι παράμετρος in-out.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά.

Αυτή η συνάρτηση θα πρέπει να αφαιρεί τον παίκτη από το λεξικό αν βρίσκεται σε αυτό και να μην κάνει τίποτα σε αντίθετη περίπτωση.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Επαναφορά της βαθμολογίας ενός παίκτη

Για να κάνεις επαναφορά στη βαθμολογία ενός παίκτη, όρισε τη συνάρτηση `resetPlayer(_:_:)`, η οποία παίρνει 2 παραμέτρους:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες.
    Θα πρέπει να είναι παράμετρος in-out.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου τη βαθμολογία θέλεις να επαναφέρεις.

Η συνάρτηση θα θέσει τη βαθμολογία του παίκτη σε 0. 
Αν ο παίκτης δεν βρίσκεται στο λεξικό, τότε δεν θα πρέπει να συμβεί τίποτα.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Ενημέρωση της βαθμολογίας ενός παίκτη

Για να ενημερώσεις τη βαθμολογία ενός παίκτη προσθέτοντας στην προηγούμενη βαθμολογία, όρισε τη συνάρτηση `updateScore`, η οποία παίρνει 3 παραμέτρους:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες. Θα πρέπει να είναι παράμετρος in-out.
- Η δεύτερη παράμετρος είναι το όνομα του παίκτη ως συμβολοσειρά, του οποίου τη βαθμολογία θέλεις να ενημερώσεις.
- Η τρίτη παράμετρος είναι η βαθμολογία που θέλεις να **προσθέσεις** στην αποθηκευμένη υψηλή βαθμολογία.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Λήψη λίστας παικτών με βαθμολογίες ταξινομημένες κατά όνομα παίκτη

Όρισε τη συνάρτηση `orderByPlayers`, η οποία παίρνει 1 παράμετρο:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες.

Η συνάρτηση θα επιστρέφει έναν πίνακα από πλειάδες `(String, Int)` που είναι οι παίκτες και οι υψηλές βαθμολογίες τους, ταξινομημένες σε αύξουσα σειρά κατά το όνομα του παίκτη.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Λήψη λίστας παικτών σε φθίνουσα σειρά κατά βαθμολογία

Για να πάρεις μια λίστα παικτών ταξινομημένη κατά βαθμολογία σε φθίνουσα σειρά, όρισε τη συνάρτηση `orderByScores`, η οποία παίρνει 1 παράμετρο:

- Η πρώτη παράμετρος είναι το λεξικό με τις βαθμολογίες.

Η συνάρτηση θα επιστρέφει έναν πίνακα από πλειάδες `(String, Int)` που είναι οι παίκτες και οι υψηλές βαθμολογίες τους, ταξινομημένες σε φθίνουσα σειρά κατά τη βαθμολογία του παίκτη.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
