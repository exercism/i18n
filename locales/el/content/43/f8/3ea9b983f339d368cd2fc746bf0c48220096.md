## Νέες έννοιες της awk

Ανατρέξε στις [οδηγίες της άσκησης `matrix`][ex-matrix] για να θυμηθείς μερικά ενδιαφέροντα χαρακτηριστικά της γλώσσας GNU awk.

### Δυναμική κλήση συνάρτησης

Οι συναρτήσεις της awk δεν είναι αντικείμενα πρώτης τάξης: δεν μπορείς να τις περνάς από εδώ και από εκεί, όπως σου επιτρέπουν κάποιες άλλες γλώσσες.
Ωστόσο, μια μεταβλητή μπορεί να κρατά το _όνομα_ μιας συνάρτησης (μια συμβολοσειρά) και η συνάρτηση καλείται με μια ειδική σημειογραφία `@varname(args)`.
Ένα παράδειγμα:

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
Αυτό περιγράφεται στις [έμμεσες κλήσεις συναρτήσεων][indirect].
Αυτή είναι μια επέκταση της `gawk`.
