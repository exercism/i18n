# Οδηγίες

Ένα τοπικό σχολείο κοντά σου έχει έναν πολύ δραστήριο μαθητικό σύλλογο.
Ο μαθητικός σύλλογος διοικείται από έναν πρόεδρο και κάθε 2 χρόνια γίνονται εκλογές για την ανάδειξη νέου προέδρου.
Στις φετινές εκλογές, αποφασίστηκε ότι χρειαζόταν ένα νέο ψηφιακό σύστημα για την καταμέτρηση των ψήφων.

Το σχολείο χρειάζεται τη βοήθειά σου για να φτιάξεις αυτό το νέο σύστημα.

## 1. Δημιούργησε έναν μετρητή ψήφων

Ένα από τα πρώτα πράγματα που χρειάζεται το νέο σύστημα ψηφοφορίας είναι ένας μετρητής ψήφων.
Αυτός ο μετρητής είναι ένας τρόπος να παρακολουθείς τις ψήφους που έχει ένας συγκεκριμένος υποψήφιος.

Δημιούργησε μια συνάρτηση `new_vote_counter` που δέχεται τον αριθμό των αρχικών ψήφων για έναν υποψήφιο και επιστρέφει ένα στιγμιότυπο μιας δομής `VoteCounter`, αρχικοποιημένο με τον δεδομένο αριθμό αρχικών ψήφων.

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. Πάρε τον αριθμό των ψήφων από έναν μετρητή

Τώρα έχεις έναν τρόπο να δημιουργείς νέους μετρητές!
Αλλά τώρα συνειδητοποιείς ότι το νέο σύστημα θα χρειαστεί και έναν τρόπο να παίρνει τον αριθμό των ψήφων από έναν μετρητή.

Δημιούργησε μια συνάρτηση `vote_count` που θα δέχεται έναν μετρητή (`@VoteCounter`) ως όρισμα και θα επιστρέφει τον αριθμό των ψήφων στον μετρητή.

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. Αύξησε τις ψήφους ενός μετρητή

Επιτέλους, ήρθε η ώρα να μετρήσεις τις ψήφους!
Τώρα χρειάζεσαι έναν τρόπο να αυξάνεις τις ψήφους σε έναν μετρητή.

Δημιούργησε μια συνάρτηση `increment_vote_count` που θα δέχεται έναν μετρητή (`@VoteCounter`) ως όρισμα και έναν αριθμό ψήφων, και θα αυξάνει τον μετρητή κατά αυτόν τον αριθμό ψήφων.

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. Δημιούργησε τα αποτελέσματα των εκλογών

Με όλες τις ψήφους πλέον καταμετρημένες, ήρθε η ώρα να ετοιμάσεις την ανακοίνωση των αποτελεσμάτων σε όλο το σχολείο.
Για αυτό, παρατηρείς ότι το να έχεις μόνο μετρητές για τις ψήφους δεν αρκεί.
Χρειάζεται ένας τρόπος να συνδέσεις τον αριθμό των ψήφων με έναν συγκεκριμένο υποψήφιο.

Δημιούργησε μια συνάρτηση `new_election_result` που δέχεται το όνομα ενός υποψηφίου και τον αριθμό των ψήφων του και επιστρέφει ένα νέο εκλογικό αποτέλεσμα.

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

Η δομή του εκλογικού αποτελέσματος έχει ήδη δημιουργηθεί για εσένα και ορίζεται ως εξής:

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. Ανακοίνωσε τα αποτελέσματα

Ήρθε η ώρα να ανακοινώσεις τον νέο πρόεδρο στο σχολείο!
Ο πρόεδρος θα ανακοινωθεί στους μικρούς ψηφιακούς πίνακες ανακοινώσεων που έχει το σχολείο.

Το μήνυμα θα πρέπει να δείχνει το όνομα του νέου προέδρου και τις ψήφους που πήρε, στην ακόλουθη μορφή: `<candidate_name> (<votes>)`.
Αυτό είναι ένα παράδειγμα τέτοιου μηνύματος: `"Peter (51)"`.

Δημιούργησε μια συνάρτηση `display_result` που θα δέχεται ένα `@ElectionResult` ως όρισμα και θα επιστρέφει ένα `ByteArray` με το μήνυμα προς εμφάνιση.

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. Επανακαταμέτρηση των ψήφων

Για να βεβαιωθούμε ότι τα τελικά αποτελέσματα ήταν ακριβή, οι ψήφοι επανακαταμετρήθηκαν.
Στην επανακαταμέτρηση, βρέθηκε ότι ο αριθμός των ψήφων για κάποιους από τους υποψηφίους διέφερε κατά ένα.

Δημιούργησε μια συνάρτηση `decrement_votes_of_candidate` που δέχεται τα τελικά αποτελέσματα και το όνομα ενός υποψηφίου του οποίου τον αριθμό ψήφων θα πρέπει να μειώσεις.
Τα τελικά αποτελέσματα δίνονται με τη μορφή ενός `Felt252Dict<u32>`, όπου τα κλειδιά είναι τα ονόματα των υποψηφίων και οι τιμές είναι το σύνολο των ψήφων τους.

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
