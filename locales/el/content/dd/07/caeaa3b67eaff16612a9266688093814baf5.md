# Σχετικά

## Εισαγωγή

Οι γενικευμένοι τύποι είναι ένα χαρακτηριστικό της γλώσσας που επιτρέπει την επαναχρησιμοποίηση κώδικα.
Για παράδειγμα, δεν θα έπρεπε να έχει σημασία τι τύπο περιέχει μια λίστα για να υπολογίσουμε το μήκος της.
Γι' αυτό η συνάρτηση `length` χρησιμοποιεί μια γενικευμένη παράμετρο τύπου `a` στην υπογραφή τύπου της.

```elm
length : List a -> Int
```

## Παράμετροι στους τύπους

Όταν ένας τύπος είναι γενικευμένος ως προς κάποιον άλλο τύπο, χρησιμοποιούμε ένα πεζό όνομα γι' αυτόν τον άλλο τύπο και το ονομάζουμε παράμετρο τύπου.
Συνήθη παραδείγματα είναι οι προσαρμοσμένοι τύποι `List`, `Maybe` και `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Μια σημαντική παρατήρηση για τα ονόματα των παραμέτρων τύπου είναι ότι μπορούν να έχουν πολλούς χαρακτήρες.
Ο μόνος περιορισμός είναι να είναι πεζά ονόματα.
Έτσι, όταν είναι χρήσιμο, τείνουμε να τους δίνουμε περιγραφικά ονόματα.

Ένας τύπος μπορεί να είναι γενικευμένος ως προς πολλούς άλλους τύπους και επομένως να έχει πολλαπλές παραμέτρους τύπου.
Σε αυτή την περίπτωση, κάθε ανεξάρτητος τύπος παίρνει διαφορετικό πεζό όνομα.
Το ότι είναι ανεξάρτητοι δεν τους εμποδίζει να γίνουν ο ίδιος τύπος, απλώς τους επιτρέπει να είναι διαφορετικοί.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Τα ψευδώνυμα τύπων καταγραφής μπορούν επίσης να έχουν παραμέτρους τύπου, αν και αυτό είναι λιγότερο συνηθισμένο.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> Γι' αυτό το πακέτο `Html` ορίζει τον τύπο `Html msg`, με μία παράμετρο τύπου που ονομάζεται `msg`.
> Η αρχιτεκτονική Elm σε καθοδηγεί στη δημιουργία ενός προσαρμοσμένου τύπου `Msg` που περιγράφει όλα τα μηνύματα που μπορεί να προκαλέσει η ιστοσελίδα σου.
> Ως αποτέλεσμα, ο κώδικάς σου θα χτίζει όψεις του τύπου `Html Msg`, όπου `Msg` είναι ο συγκεκριμένος τύπος που όρισες.
> Οι αρχάριοι μερικές φορές μπερδεύονται ανάμεσα σε σφάλματα που αναφέρουν `Html msg` (πεζό) και σε σφάλματα με `Html Msg`.
> Τώρα το ξέρεις!
> Η διαφορά είναι ότι το πρώτο είναι γενικευμένο ως προς οποιονδήποτε τύπο `msg`, ενώ το δεύτερο είναι ειδικό για τον δικό σου τύπο `Msg`.

## Παράμετροι τύπου σε συναρτήσεις

Εφόσον οι τύποι μπορούν να είναι γενικευμένοι, το ίδιο μπορούν και οι συναρτήσεις.
Μπορούν να γραφτούν συναρτήσεις που χειρίζονται γενικευμένους τύπους, όπως η `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Οι συναρτήσεις που δέχονται άλλες συναρτήσεις ως παραμέτρους ονομάζονται συναρτήσεις υψηλότερης τάξης και μπορούν κι αυτές να είναι γενικευμένες.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

Οι παράμετροι τύπου μπορούν να εμφανίζονται και στις εισόδους και στην έξοδο μιας συνάρτησης, και η γενικότητα που προσφέρουν οι παράμετροι τύπου ονομάζεται συνήθως **παραμετρικός πολυμορφισμός**.
Αυτό έρχεται σε αντίθεση με τον ad hoc πολυμορφισμό, γνωστό και ως υπερφόρτωση συναρτήσεων, όπου το ίδιο όνομα συνάρτησης μπορεί να χρησιμοποιηθεί σε πολλαπλές υλοποιήσεις όπου οι τύποι διαφέρουν.
Έρχεται επίσης σε αντίθεση με τον πολυμορφισμό υποτύπων, όπου οι τύποι μπορούν να οριστούν σε ιεραρχία, και συναρτήσεις που έχουν οριστεί για έναν τύπο μπορούν να κληθούν και με ορίσματα των υποτύπων του.
Στην Elm, ο μόνος διαθέσιμος μηχανισμός για γενικότητα είναι ο παραμετρικός πολυμορφισμός.
