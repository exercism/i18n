# Σύνολα


Ένα [σύνολο][type-set] είναι μια _μεταβλητή_ και _μη διατεταγμένη_ συλλογή από [_κατακερματίσιμα_][hashable] αντικείμενα.
Τα μέλη ενός συνόλου πρέπει να είναι διακριτά, δηλαδή δεν επιτρέπονται διπλότυπα στοιχεία.
Μπορούν να περιέχουν πολλαπλούς διαφορετικούς τύπους δεδομένων ακόμα και εμφωλευμένες δομές, όπως μια `tuple` από `tuples`, αρκεί όλα τα στοιχεία να μπορούν να _κατακερματιστούν_.
Τα σύνολα διατίθενται και σε αμετάβλητη εκδοχή, τα [`frozensets`][type-frozenset].

Τα σύνολα χρησιμοποιούνται πιο συχνά για να αφαιρείς γρήγορα τα διπλότυπα από άλλες δομές δεδομένων ή ομαδοποιήσεις στοιχείων.
Χρησιμοποιούνται επίσης για αποδοτικές συγκρίσεις, όταν δεν χρειάζεται η σειρά ούτε η παρακολούθηση διπλοτύπων.

Όπως και οι άλλοι τύποι συλλογών (_λεξικά, λίστες, πλειάδες_), τα `sets` υποστηρίζουν:
- Επανάληψη μέσω `for item in <set>`
- Έλεγχο συμμετοχής μέσω `in` και `not in`,
- Υπολογισμό μήκους μέσω `len()`, και
- Ρηχά αντίγραφα μέσω `copy()`

Τα `sets` δεν υποστηρίζουν:
- Πρόσβαση με θέση οποιουδήποτε είδους
- Διάταξη μέσω ταξινόμησης ή εισαγωγής
- Τεμαχισμό
- Συνένωση μέσω `+`


Ο έλεγχος συμμετοχής σε ένα `set` έχει σταθερή χρονική πολυπλοκότητα (κατά μέσο όρο) εναντίον του ελέγχου συμμετοχής σε μια `list` ή ένα `string`, όπου η χρονική πολυπλοκότητα αυξάνεται όσο μεγαλώνει το μήκος των δεδομένων.
Μέθοδοι όπως οι `<set>.union()`, `<set>.intersection()` ή `<set>.difference()` έχουν επίσης σταθερή χρονική πολυπλοκότητα (κατά μέσο όρο).


## Κυριολεκτικά συνόλων

Ένα `set` μπορεί να γραφτεί απευθείας ως _κυριολεκτικό συνόλου_ με άγκιστρα `{}` και κόμμα ανάμεσα στα στοιχεία.
Τα διπλότυπα παραλείπονται σιωπηρά:

```python
>>> one_element = {'➕'}
{'➕'}

>>> multiple_elements = {'➕', '🔻', '🔹', '🔆'}
{'➕', '🔻', '🔹', '🔆'}

>>> multiple_duplicates =  {'Hello!', 'Hello!', 'Hello!', 
                            '¡Hola!','Привіт!', 'こんにちは！', 
                            '¡Hola!','Привіт!', 'こんにちは！'}
{'こんにちは！', '¡Hola!', 'Hello!', 'Привіт!'}
```

Τα κυριολεκτικά συνόλου χρησιμοποιούν τα ίδια άγκιστρα με τα κυριολεκτικά `dict`, που σημαίνει ότι χρειάζεται να χρησιμοποιήσεις τη `set()` για να δημιουργήσεις ένα κενό `set`.


## Ο κατασκευαστής συνόλου

Η `set()` (_ο κατασκευαστής της κλάσης `set`_) μπορεί να χρησιμοποιηθεί με οποιοδήποτε `iterable` που περνάς ως όρισμα.
Τα στοιχεία του `iterable` διατρέχονται ένα ένα και προστίθενται μεμονωμένα στο `set`.
Η σειρά των στοιχείων δεν διατηρείται και τα διπλότυπα παραλείπονται σιωπηρά:

```python
# To create an empty set, the constructor must be used.
>>> no_elements = set()
set()

# The tuple is unpacked & each element is added.  
# Duplicates are removed.
>>> elements_from_tuple = set(("Parrot", "Bird", 
                               334782, "Bird", "Parrot"))
{334782, 'Bird', 'Parrot'}

# The list is unpacked & each element is added.
# Duplicates are removed.
>>> elements_from_list = set([2, 3, 2, 3, 3, 3, 5, 
                              7, 11, 7, 11, 13, 13])
{2, 3, 5, 7, 11, 13}
```

### Παγίδες κατά τη δημιουργία συνόλων

Εξαιτίας της συμπεριφοράς "αποσυσκευασίας" που έχει, η χρήση της `set()` με μια συμβολοσειρά μπορεί να σε εκπλήξει:

```python
# String elements (Unicode code points) are 
# iterated through and added *individually*.
>>> elements_string = set("Timbuktu")
{'T', 'b', 'i', 'k', 'm', 't', 'u'}

# Unicode separators and positioning code points 
# are also added *individually*.
>>> multiple_code_points_string = set('अभ्यास')
{'अ', 'भ', 'य', 'स', 'ा', '्'}
```

Τα σύνολα μπορούν να περιέχουν διαφορετικούς τύπους δεδομένων και _εμφωλευμένους_ τύπους δεδομένων, αλλά όλα τα στοιχεία ενός `set` πρέπει να είναι _κατακερματίσιμα_:

```python
# Attempting to use a list for a set member throws a TypeError
>>> lists_as_elements = {['🌈','💦'], 
                        ['☁️','⭐️','🌍'], 
                        ['⛵️', '🚲', '🚀']}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'list'


# Standard sets are mutable, so they cannot be hashed.
>>> sets_as_elements = {{'🌈','💦'}, 
                        {'☁️','⭐️','🌍'}, 
                        {'⛵️', '🚲', '🚀'}}

Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: unhashable type: 'set'
```


## Εργασία με σύνολα

Τα σύνολα έχουν μεθόδους που γενικά μιμούνται τις [μαθηματικές πράξεις συνόλων][mathematical-sets].
Οι περισσότερες (_όχι όλες_) από αυτές τις μεθόδους έχουν ισοδύναμο [τελεστή][operator].
Οι μέθοδοι γενικά δέχονται οποιοδήποτε `iterable` ως όρισμα, ενώ οι τελεστές απαιτούν και οι δύο πλευρές της πράξης να είναι `sets` ή `frozensets`.


### Ξένα σύνολα

Η μέθοδος `<set>.isdisjoint(<other_collection>)` χρησιμοποιείται για να ελέγξεις αν τα στοιχεία ενός `set` έχουν κάποια επικάλυψη με τα στοιχεία ενός άλλου `set`.
Η μέθοδος δέχεται οποιοδήποτε `iterable` ή `set` ως όρισμα.
Επιστρέφει `True` αν τα δύο σύνολα **δεν έχουν κοινά στοιχεία**, `False` αν **μοιράζονται** στοιχεία.
Δεν υπάρχει ισοδύναμος τελεστής:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}
               
# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Mammals and birds don't share any elements.
>>> birds.isdisjoint(mammals)
True

# There are also no shared elements between 
# additional_animals and birds.
>>> birds.isdisjoint(additional_animals)
True

# Animals and mammals have shared elements.
# **Note** The first object needs to be a set or converted to a set
# since .isdisjoint() is a set method.
>>> set(animals).isdisjoint(mammals)
False
```


### Υποσύνολα και υπερσύνολα

Η `<set>.issubset(<other_collection>)` χρησιμοποιείται για να ελέγξεις αν κάθε στοιχείο του `<set>` βρίσκεται και στο `<other_collection>`.
Η μορφή με τελεστή είναι `<set> <= <other_set>`:


```python
# Both mammals and additional_animals are lists.
>>> mammals = ['squirrel','dog','cat','cow', 'tiger', 'elephant']
>>> additional_animals = ['pangolin', 'panda', 'parrot', 
                          'lemur', 'tiger', 'pangolin']

# Animals is a dict.
>>> animals = {'chicken': 'white',
               'sparrow': 'grey',
               'eagle': 'brown and white',
               'albatross': 'grey and white',
               'crow': 'black',
               'elephant': 'grey', 
               'dog': 'rust',
               'cow': 'black and white',
               'tiger': 'orange and black',
               'cat': 'grey',
               'squirrel': 'black'}

# Birds is a set.
>>> birds = {'crow','sparrow','eagle','chicken', 'albatross'}

# Set methods will take any iterable as an argument.
# All members of birds are also members of animals.
>>> birds.issubset(animals)
True

# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issubset() is a set method.
>>> set(mammals).issubset(animals)
True

# Both objects need to be sets to use a set operator
>>> birds <= set(mammals)
False

# A set is always a loose subset of itself.
>>> set(additional_animals) <= set(additional_animals)
True
```

Η `<set>.issuperset(<other_collection>)` είναι το αντίστροφο της `.issubset()`.
Χρησιμοποιείται για να ελέγξεις αν κάθε στοιχείο του `<other_collection>` βρίσκεται και στο `<set>`.
Η μορφή με τελεστή είναι `<set> >= <other_set>`:


```python
# All members of mammals also appear in animals.
# **Note** The first object needs to be a set or converted to a set
# since .issuperset() is a set method.
>>> set(animals).issuperset(mammals)
True

# All members of animals do not show up as members of birds.
>>> birds.issuperset(animals)
False

# Both objects need to be sets to use a set operator
>>> birds >= set(mammals)
False

# A set is always a loose superset of itself.
>>> set(animals) >= set(animals)
True
```


### Τομές συνόλων

Η `<set>.intersection(*<other iterables>)` επιστρέφει ένα νέο `set` με τα στοιχεία που είναι κοινά στο αρχικό `set` και σε όλα τα `<others>` (_με άλλα λόγια, το `set` όπου όλα [τέμνονται][intersection]_).
Η μορφή αυτής της μεθόδου με τελεστή είναι `<set> & <other set> & <other set 2> & ... <other set n>`:


```python
>>> perennials = {'Annatto','Asafetida','Asparagus','Azalea',
                 'Winter Savory', 'Broccoli','Curry Leaf','Fennel', 
                 'Kaffir Lime','Kale','Lavender','Mint','Oranges',
                 'Oregano', 'Tarragon', 'Wild Bergamot'}

>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Marjoram', 
              'Summer Squash', 'Okra','Shallots', 'Basil', 
              'Cilantro', 'Cumin', 'Sunflower', 'Chervil', 
              'Summer Savory'}

>>> herbs = ['Annatto','Asafetida','Basil','Chervil','Cilantro',
            'Curry Leaf','Fennel','Kaffir Lime','Lavender',
            'Marjoram','Mint','Oregano','Summer Savory', 
            'Tarragon','Wild Bergamot','Wild Celery',
            'Winter Savory']


# Methods will take any iterable as an argument.
>>> perennial_herbs = perennials.intersection(herbs)
{'Annatto', 'Asafetida', 'Curry Leaf', 'Fennel', 'Kaffir Lime',
 'Lavender', 'Mint', 'Oregano', 'Wild Bergamot','Winter Savory'}

# Operators require both groups be sets.
>>> annuals & set(herbs)
 {'Basil', 'Chervil', 'Marjoram', 'Cilantro'}
```


### Ενώσεις συνόλων

Η `<set>.union(*<other iterables>)` επιστρέφει ένα νέο `set` με στοιχεία από το `<set>` και από όλα τα `<other iterables>`.
Η μορφή αυτής της μεθόδου με τελεστή είναι `<set> | <other set 1> | <other set 2> | ... | <other set n>`:


```python
>>> perennials = {'Asparagus', 'Broccoli', 'Sweet Potato', 'Kale'}
>>> annuals = {'Corn', 'Zucchini', 'Sweet Peas', 'Summer Squash'}
>>> more_perennials = ['Radicchio', 'Rhubarb', 
                      'Spinach', 'Watercress']

# Methods will take any iterable as an argument.
>>> perennials.union(more_perennials)
{'Asparagus','Broccoli','Kale','Radicchio','Rhubarb',
'Spinach','Sweet Potato','Watercress'}

# Operators require sets.
>>> set(more_perennials) | perennials
{'Asparagus',
 'Broccoli',
 'Kale',
 'Radicchio',
 'Rhubarb',
 'Spinach',
 'Sweet Potato',
 'Watercress'}
```


### Διαφορές συνόλων

Η `<set>.difference(*<other iterables>)` επιστρέφει ένα νέο `set` με στοιχεία του αρχικού `<set>` που δεν βρίσκονται στα `<others>`.
Η μορφή αυτής της μεθόδου με τελεστή είναι `<set> - <other set 1> - <other set 2> - ...<other set n>`.

```python
>>> berries_and_veggies = {'Asparagus', 
                          'Broccoli', 
                          'Watercress', 
                          'Goji Berries', 
                          'Goose Berries', 
                          'Ramps', 
                          'Walking Onions', 
                          'Blackberries', 
                          'Strawberries', 
                          'Rhubarb', 
                          'Kale', 
                          'Artichokes', 
                          'Currants'}

>>> veggies = ('Asparagus', 'Broccoli', 'Watercress', 'Ramps',
               'Walking Onions', 'Rhubarb', 'Kale', 'Artichokes')

# Methods will take any iterable as an argument.
>>> berries = berries_and_veggies.difference(veggies)
{'Blackberries','Currants','Goji Berries',
 'Goose Berries', 'Strawberries'}

# Operators require sets.
>>> berries_and_veggies - berries
{'Artichokes','Asparagus','Broccoli','Kale',
'Ramps','Rhubarb','Walking Onions','Watercress'}
```


# Συμμετρική διαφορά συνόλων

Η `<set>.symmetric_difference(<other iterable>)` επιστρέφει ένα νέο `set` που περιέχει τα στοιχεία που βρίσκονται στο `<set>` Ή στο `<other>`, **αλλά όχι και στα δύο**.
Η μορφή αυτής της μεθόδου με τελεστή είναι  `<set> ^ <other set>`:


```python
>>> plants_1 = {'🌲','🍈','🌵', '🥑','🌴', '🥭'}
>>> plants_2 = ('🌸','🌴', '🌺', '🌲', '🌻', '🌵')


# Methods will take any iterable as an argument.
>>> fruit_and_flowers = plants_1.symmetric_difference(plants_2)
>>> fruit_and_flowers
{'🌸', '🌺', '🍈', '🥑', '🥭','🌻' }


# Operators require both groups be sets.
>>> fruit_and_flowers ^ plants_1
{'🌲',  '🌸', '🌴', '🌵','🌺', '🌻'}

>>> fruit_and_flowers ^ set(plants_2)
{'🥭', '🌴', '🌵', '🍈', '🌲', '🥑'}
```

~~~~exercism/note

Η συμμετρική διαφορά περισσότερων από δύο συνόλων θα δώσει ένα `set` που περιλαμβάνει και τα στοιχεία που είναι μοναδικά σε κάθε `set` ΚΑΙ τα στοιχεία που μοιράζονται περισσότερα από δύο σύνολα της σειράς (_λεπτομέρειες στο άρθρο της Wikipedia για τη [συμμετρική διαφορά][symmetric_difference]_).  

Για να πάρεις μόνο τα στοιχεία που είναι μοναδικά σε κάθε `set` της σειράς, πρέπει να συγκεντρώσεις σε ένα ξεχωριστό βήμα τις τομές όλων των συνδυασμών ανά δύο συνόλων και μετά να τις αφαιρέσεις:  


```python
>>> one = {'black pepper','breadcrumbs','celeriac','chickpea flour',
           'flour','lemon','parsley','salt','soy sauce',
           'sunflower oil','water'}

>>> two = {'black pepper','cornstarch','garlic','ginger',
           'lemon juice','lemon zest','salt','soy sauce','sugar',
           'tofu','vegetable oil','vegetable stock','water'}

>>> three = {'black pepper','garlic','lemon juice','mixed herbs',
             'nutritional yeast', 'olive oil','salt','silken tofu',
             'smoked tofu','soy sauce','spaghetti','turmeric'}

>>> four = {'barley malt','bell pepper','cashews','flour',
            'fresh basil','garlic','garlic powder', 'honey',
            'mushrooms','nutritional yeast','olive oil','oregano',
            'red onion', 'red pepper flakes','rosemary','salt',
            'sugar','tomatoes','water','yeast'}

>>> intersections = (one & two | one & three | one & four | 
                     two & three | two & four | three & four)
...
{'black pepper','flour','garlic','lemon juice','nutritional yeast', 
'olive oil','salt','soy sauce', 'sugar','water'}

# The ^ operation will include some of the items in intersections, 
# which means it is not a "clean" symmetric difference - there
# are overlapping members.
>>> (one ^ two ^ three ^ four) & intersections
{'black pepper', 'garlic', 'soy sauce', 'water'}

# Overlapping members need to be removed in a separate step
# when there are more than two sets that need symmetric difference.
>>> (one ^ two ^ three ^ four) - intersections
...
{'barley malt','bell pepper','breadcrumbs', 'cashews','celeriac',
  'chickpea flour','cornstarch','fresh basil', 'garlic powder',
  'ginger','honey','lemon','lemon zest','mixed herbs','mushrooms',
  'oregano','parsley','red onion','red pepper flakes','rosemary',
  'silken tofu','smoked tofu','spaghetti','sunflower oil', 'tofu', 
  'tomatoes','turmeric','vegetable oil','vegetable stock','yeast'}
```
