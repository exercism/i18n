# Προσθήκη οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Στην άσκηση "Yacht", θα δημιουργήσεις ένα ρήμα που υπολογίζει το σκορ για μία μόνο ρίψη πέντε ζαριών στο παιχνίδι Yacht, με βάση την επιλεγμένη κατηγορία.

Για αυτή την άσκηση, το ρήμα σου θα δέχεται δύο ορίσματα:

- **Αριστερό όρισμα**: Μια συμβολοσειρά που αντιπροσωπεύει την κατηγορία βαθμολόγησης που θα εφαρμοστεί στη ρίψη των ζαριών.
- **Δεξί όρισμα**: Μια λίστα ακεραίων που αντιπροσωπεύει τα πέντε ζάρια που ρίχτηκαν.

Το ρήμα σου θα πρέπει να οριστεί ώστε να χειρίζεται αυτές τις εισόδους ως εξής:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
