# Οδηγίες

Σε αυτή την άσκηση πρέπει να υλοποιήσεις μερικές συναρτήσεις για να χειριστείς μια λίστα γλωσσών προγραμματισμού.

## 1. Όρισε μια συνάρτηση που επιστρέφει μια κενή λίστα γλωσσών

Όρισε τη συνάρτηση `new` που δεν δέχεται ορίσματα και επιστρέφει μια κενή λίστα.

```haskell
new
-- -> []
```

## 2. Όρισε μια συνάρτηση που προσθέτει μια γλώσσα στη λίστα

Όρισε τη συνάρτηση `add/2` που δέχεται 2 ορίσματα (μια _λίστα γλωσσών_ και μια συμβολοσειρά που αντιπροσωπεύει μια _γλώσσα_).
Θα πρέπει να επιστρέφει τη λίστα που προκύπτει, με τη νέα γλώσσα να μπαίνει στην αρχή της λίστας που δίνεται.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Όρισε μια συνάρτηση που αφαιρεί μια γλώσσα από τη λίστα

Όρισε τη συνάρτηση `remove` που δέχεται 1 όρισμα (μια _λίστα γλωσσών_).
Θα πρέπει να επιστρέφει τη λίστα χωρίς το πρώτο στοιχείο. Υπέθεσε ότι η λίστα θα έχει πάντα τουλάχιστον ένα στοιχείο.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Όρισε μια συνάρτηση που επιστρέφει το πρώτο στοιχείο της λίστας

Όρισε τη συνάρτηση `first` που δέχεται 1 όρισμα (μια _λίστα γλωσσών_).
Θα πρέπει να επιστρέφει την πρώτη γλώσσα της λίστας.
Υπέθεσε ότι η λίστα θα έχει πάντα τουλάχιστον ένα στοιχείο.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Όρισε μια συνάρτηση που επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

Όρισε τη συνάρτηση `count` που δέχεται 1 όρισμα (μια _λίστα γλωσσών_). 
Θα πρέπει να επιστρέφει τον αριθμό των γλωσσών της λίστας.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Όρισε μια συνάρτηση που καθορίζει αν η λίστα περιέχει μια συναρτησιακή γλώσσα

Όρισε τη συνάρτηση `isFunctionalList` που δέχεται 1 όρισμα (μια _λίστα γλωσσών_). 
Θα πρέπει να επιστρέφει μια Boolean τιμή. 
Θα πρέπει να επιστρέφει `True` αν η _"Haskell"_ είναι μία από τις γλώσσες της λίστας.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
