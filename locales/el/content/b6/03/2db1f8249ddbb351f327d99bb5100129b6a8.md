# Προσθήκη οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά ψηφίων με τερματισμό null |
| `$a1`    | είσοδος        | ακέραιος | εύρος                          |
| `$v0`    | έξοδος       | ακέραιος | γινόμενο της μεγαλύτερης σειράς        |
| `$t0-9`  | προσωρινός    | οποιοδήποτε     | για προσωρινή αποθήκευση         |
