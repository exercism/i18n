# Workflow συγχρονισμού ετικετών

Το workflow συγχρονισμού ετικετών συγχρονίζει τις [ετικέτες GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) ενός αποθετηρίου με τα περιεχόμενα του αρχείου `.github/labels.yml`.
Κάθε φορά που αλλάζει το αρχείο `.github/labels.yml`, το workflow συγχρονισμού ετικετών ενημερώνει αυτόματα τις ετικέτες του αποθετηρίου.

## Προσαρμογή των ετικετών

Οι ετικέτες που ορίζονται στο `.github/labels.yml` έχουν δύο μορφές:

- Κοινόχρηστες ετικέτες: αυτές είναι ετικέτες που χρησιμοποιούνται από _όλα_ τα αποθετήρια του Exercism, και ορίζονται στο [αποθετήριο org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Ετικέτες ειδικές για κάθε track: αυτές ορίζονται σε ένα αρχείο `.appends/.github/labels.yml`

Για να προσθέσεις ετικέτες ειδικές για κάθε track, θα πρέπει να τις προσθέσεις στο αρχείο `.appends/.github/labels.yml` (δες [αυτό το παράδειγμα](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Μόλις κάνεις merge τις αλλαγές στο `main`, θα ανοίξει αυτόματα ένα pull request για να αλλάξει το αρχείο `.github/labels.yml`.
Αφού κάνεις merge αυτό το PR, οι ετικέτες θα ενημερωθούν αυτόματα (δες την παραπάνω περιγραφή).

```exercism/caution
Μην επεξεργάζεσαι ποτέ χειροκίνητα το αρχείο `.github/labels.yml`, γιατί αυτές οι αλλαγές θα αντικατασταθούν την επόμενη φορά που θα συγχρονιστούν οι ετικέτες.
```

## Πηγή

Το workflow ορίζεται στο αρχείο `.github/workflows/sync-labels.yml`.
