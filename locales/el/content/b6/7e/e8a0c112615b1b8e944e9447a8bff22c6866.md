# Εισαγωγή

## Βασικά

Η C# είναι μια στατικά τυποποιημένη γλώσσα, που σημαίνει ότι τα πάντα έχουν έναν τύπο κατά τη μεταγλώττιση. Η ανάθεση μιας τιμής σε ένα όνομα ονομάζεται ορισμός μεταβλητής. Μια μεταβλητή μπορεί να οριστεί είτε δηλώνοντας ρητά τον τύπο της, είτε αφήνοντας τον μεταγλωττιστή της C# να συμπεράνει τον τύπο της με βάση την τιμή που της ανατίθεται (κάτι που είναι γνωστό ως _εξαγωγή τύπου_). Επομένως, οι παρακάτω δύο ορισμοί μεταβλητών είναι ισοδύναμοι:

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

Η ενημέρωση της τιμής μιας μεταβλητής γίνεται μέσω του τελεστή `=`. Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Η C# είναι μια [αντικειμενοστρεφής γλώσσα][object-oriented-programming] και απαιτεί όλες οι συναρτήσεις να ορίζονται μέσα σε μια _κλάση_. Η λέξη-κλειδί `class` χρησιμοποιείται για τον ορισμό μιας κλάσης. Τα αντικείμενα (ή _στιγμιότυπα_) δημιουργούνται με τη χρήση της λέξης-κλειδιού `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Μια συνάρτηση μέσα σε μια κλάση ονομάζεται _μέθοδος_. Κάθε μέθοδος μπορεί να έχει μηδέν ή περισσότερες παραμέτρους. Όλες οι παράμετροι πρέπει να έχουν ρητά δηλωμένο τύπο, δεν υπάρχει εξαγωγή τύπου για τις παραμέτρους. Παρομοίως, ο τύπος επιστροφής πρέπει επίσης να δηλώνεται ρητά. Οι τιμές επιστρέφονται από τις μεθόδους με τη λέξη-κλειδί `return`. Για να μπορεί μια μέθοδος να καλείται από κώδικα σε άλλα αρχεία, πρέπει να προστεθεί ο τροποποιητής πρόσβασης `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Οι μέθοδοι καλούνται χρησιμοποιώντας τη σύνταξη με τελεία (`.`) πάνω σε ένα στιγμιότυπο, καθορίζοντας το όνομα της μεθόδου που θέλεις να καλέσεις και περνώντας ορίσματα για κάθε παράμετρο της μεθόδου. Τα ορίσματα μπορούν προαιρετικά να καθορίζουν το όνομα της αντίστοιχης παραμέτρου.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Η εμβέλεια στη C# ορίζεται ανάμεσα στους χαρακτήρες `{` και `}`.

Η C# υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μονής γραμμής προηγούνται από `//` και τα σχόλια πολλαπλών γραμμών τοποθετούνται ανάμεσα στα `/*` και `*/`.
