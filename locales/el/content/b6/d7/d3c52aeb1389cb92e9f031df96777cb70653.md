# Υποδείξεις

## Γενικά

- [Εισαγωγή στους αριθμητικούς τύπους κινητής υποδιαστολής][docs.microsoft.com-floating_point_numeric_types].

## 1. Υπολόγισε το επιτόκιο

- Από προεπιλογή, κάθε αριθμός κινητής υποδιαστολής που ορίζεται σε κώδικα C# αντιμετωπίζεται ως `double`. Για να χρησιμοποιήσεις διαφορετικό τύπο κινητής υποδιαστολής (όπως `float` ή `decimal`), πρέπει να προσθέσεις το κατάλληλο [επίθημα][docs.microsoft.com-real_literals] στον αριθμό.

## 2. Υπολόγισε τον τόκο

- Όταν υπολογίζεις τον τόκο, μπορεί να σου φανεί χρήσιμο να προσέξεις ότι το `InterestRate` επιστρέφει ποσοστό.

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

- Όταν υπολογίζεις την ετήσια ενημέρωση του υπολοίπου, μπορείς να χρησιμοποιήσεις μεθόδους που έχουμε ορίσει σε προηγούμενα βήματα.

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

- Για να υπολογίσεις τα χρόνια, μπορείς να χρησιμοποιήσεις έναν βρόχο που συνεχίζει μέχρι να φτάσεις στο επιθυμητό υπόλοιπο. Η C# έχει αρκετές [δομές βρόχων][docs.microsoft.com-loops].
- Υπάρχει ένας ειδικός [τελεστής][increment-operator] για να αυξάνεις τις τιμές κατά 1.
