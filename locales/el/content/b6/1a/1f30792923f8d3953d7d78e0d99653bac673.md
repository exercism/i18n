# Οδηγίες

Ένα νέο κλαμπ ποίησης άνοιξε στην πόλη και σκέφτεσαι να το επισκεφτείς.
Επειδή έχουν συμβεί περιστατικά στο παρελθόν, το κλαμπ έχει μια πολύ συγκεκριμένη πολιτική εισόδου, την οποία θα πρέπει να μάθεις καλά πριν επιχειρήσεις να μπεις.

Το κλαμπ ποίησης έχει δύο πόρτες, μια μπροστινή και μια πίσω, και οι δύο φυλάσσονται.
Για να μπεις, θα χρειαστεί να βρεις τον κωδικό της ημέρας.

Ο κωδικός βασίζεται πάντα σε ένα ποίημα και μπορεί να προκύψει με μια διαδικασία δύο βημάτων.

1. Ο φύλακας θα απαγγείλει το ποίημα, έναν στίχο τη φορά, και εσύ θα πρέπει να απαντήσεις με το κατάλληλο γράμμα αυτού του στίχου.
2. Έπειτα ο φύλακας θα σου πει όλα τα γράμματα που απάντησες μαζεμένα, και εσύ πρέπει να τα γράψεις σε ένα χαρτί σε συγκεκριμένη μορφή.

Οι λεπτομέρειες της διαδικασίας εξαρτώνται από την πόρτα από την οποία προσπαθείς να μπεις.

## 1. Βρες το πρώτο γράμμα μιας πρότασης

Για να βρεις τα γράμματα του κωδικού της μπροστινής πόρτας, πρέπει να απαντήσεις με το πρώτο γράμμα του στίχου του ποιήματος που σου απαγγέλλει ο φύλακας.

Για να προκύπτει ένας ωραίος κωδικός, τα μέλη του κλαμπ ποίησης συνηθίζουν να χρησιμοποιούν _ακροστιχίδες_.
Αυτό σημαίνει ότι το πρώτο γράμμα κάθε πρότασης σχηματίζει μια λέξη.
Ορίστε ένα παράδειγμα από έναν από τους αγαπημένους τους συγγραφείς, τον Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Έτσι, όταν ο φύλακας απαγγείλει **Stands so high**, θα απαντήσεις **S**, και όταν απαγγείλει **Huge hooves too**, θα απαντήσεις **H**.

Υλοποίησε τη συνάρτηση `frontDoorResponse`, η οποία δέχεται ως όρισμα έναν στίχο του ποιήματος και επιστρέφει το πρώτο γράμμα αυτού του στίχου.

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. Γράψε μια λέξη με κεφαλαίο

Τώρα που έχεις όλα τα σωστά γράμματα, το μόνο που χρειάζεται για να πάρεις τον κωδικό της μπροστινής πόρτας είναι να γράψεις σωστά τη λέξη με κεφαλαίο το πρώτο γράμμα.

Υλοποίησε τη συνάρτηση `frontDoorPassword`, η οποία δέχεται μια συμβολοσειρά (τα γράμματα που συγκέντρωσες στο βήμα 1) και την επιστρέφει με σωστά κεφαλαία.

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. Βρες το τελευταίο γράμμα μιας πρότασης

Για να βρεις τα γράμματα του κωδικού της πίσω πόρτας, πρέπει να απαντήσεις με το τελευταίο γράμμα του στίχου του ποιήματος που σου απαγγέλλει ο φύλακας.

Τα μέλη του κλαμπ ποίησης είναι πραγματικά έξυπνα.
Το ποίημα που αναφέραμε πριν είναι και _τελεστιχίδα_, που σημαίνει ότι το τελευταίο γράμμα κάθε πρότασης σχηματίζει επίσης μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φύλακας απαγγείλει **Stands so high**, θα απαντήσεις **h**, και όταν απαγγείλει **Huge hooves too**, θα απαντήσεις **o**.

Σημείωσε ότι μερικές φορές ο φύλακας κάνει στιλιστικές παύσεις (με τη μορφή κενού διαστήματος) στην αρχή ή στο τέλος ενός στίχου.
Θα χρειαστεί να αγνοήσεις αυτές τις παύσεις για να βρεις το σωστό γράμμα.

Υλοποίησε τη συνάρτηση `backDoorResponse`, η οποία δέχεται ως όρισμα έναν στίχο του ποιήματος και επιστρέφει το τελευταίο γράμμα αυτού του στίχου που δεν είναι κενό διάστημα.

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. Να είσαι ευγενικός

Για να μπεις στο κλαμπ ποίησης από την πίσω πόρτα, πρέπει να είσαι ιδιαίτερα ευγενικός.
Έτσι, για να βρεις τον κωδικό, αυτή τη φορά πρέπει να γράψεις σωστά τη λέξη με κεφαλαίο το πρώτο γράμμα και να προσθέσεις `', please'` στο τέλος.

Υλοποίησε τη συνάρτηση `backDoorPassword`, η οποία δέχεται μια συμβολοσειρά (τα γράμματα που συγκέντρωσες στο βήμα 3) και επιστρέφει την ευγενική εκδοχή του κωδικού με τα σωστά κεφαλαία.

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
