# Υποδείξεις

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να εκχωρήσεις τη σωστή τιμή στη μεταβλητή `$ExpectedMinutesInOven`.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Μπορείς να αφαιρέσεις αριθμούς μεταξύ τους χρησιμοποιώντας τον τελεστή `-`.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Μπορείς να πολλαπλασιάσεις αριθμούς χρησιμοποιώντας τον τελεστή `*`.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Μπορείς να καλέσεις άλλες συναρτήσεις που έχεις ορίσει και μπορεί να σου φανούν χρήσιμες, π.χ. `function($arg)`.
- Μπορείς να προσθέσεις αριθμούς μεταξύ τους χρησιμοποιώντας τον τελεστή `+`.

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

- Μπορείς να δημιουργήσεις μια συμβολοσειρά περικλείοντας κείμενο σε μονά `'` ή σε διπλά `"` εισαγωγικά.
