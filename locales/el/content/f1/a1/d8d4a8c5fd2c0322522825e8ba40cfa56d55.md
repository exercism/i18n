# Εισαγωγή

Στην Cairo, ένα trait είναι μια σειρά μεθόδων που μπορούν να υλοποιηθούν από έναν τύπο δεδομένων.
Όταν ένα trait υλοποιηθεί για έναν τύπο, οι μέθοδοι που ορίζονται σε αυτό το trait μπορούν να κληθούν σε στιγμιότυπα αυτού του τύπου.
Ένα trait μπορεί να οριστεί με γενικούς τύπους, ορίζοντας συμπεριφορά που μοιράζονται πολλοί τύποι δεδομένων.
