# προτίμησε εξαγωγή σταθεράς στο ανώτατο επίπεδο

Σκέψου να εξαγάγεις τη σταθερά στο ανώτατο επίπεδο:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Μόνο οι συναρτήσεις, οι κλάσεις και οι σταθερές που έχουν δηλωθεί με `export` είναι ορατές και προσβάσιμες από έξω.
Αυτές οι σταθερές μπορούν να ζουν στο ίδιο αρχείο χωρίς να εκτίθενται σε άλλον κώδικα.
Επίσης, η εξαγωγή σταθερών εξοικονομεί μνήμη, αποφεύγοντας επαναλαμβανόμενες δεσμεύσεις μέσα σε συναρτήσεις όταν οι ίδιες σταθερές χρησιμοποιούνται ξανά.
