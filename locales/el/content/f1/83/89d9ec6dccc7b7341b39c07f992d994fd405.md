# Οδηγίες

Μια πολυάσχολη τράπεζα εξυπηρετεί τους πελάτες που περιμένουν με βάση την *προτεραιότητα* και όχι με τη σειρά που έφτασαν. Κάθε πελάτης παίρνει έναν αριθμό προτεραιότητας όταν παίρνει το νούμερό του, και ο ταμίας εξυπηρετεί πάντα επόμενο τον μικρότερο αριθμό (`1` είναι ο πιο επείγων). Ένας min-heap είναι η ιδανική ουρά αναμονής.

## 1. Άνοιξε την ουρά

Όρισε τη `new-queue`, που δεν παίρνει τίποτα και επιστρέφει μια καινούρια, κενή ουρά προτεραιότητας.

```factor
new-queue
! => an empty priority queue
```

## 2. Πρόσθεσε έναν πελάτη

Όρισε τη `join-queue`, που παίρνει ένα όνομα πελάτη, έναν αριθμό προτεραιότητας και μια ουρά. Προσθέτει τον πελάτη στην ουρά και επιστρέφει την ουρά, ώστε οι πελάτες να προστίθενται ο ένας μετά τον άλλον.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. Ποιος είναι ο επόμενος;

Όρισε τη `next-name`, που παίρνει μια ουρά και επιστρέφει το όνομα του πελάτη που πρέπει να εξυπηρετηθεί επόμενος, δηλαδή αυτού με τον μικρότερο αριθμό προτεραιότητας, *χωρίς* να τον αφαιρέσει.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Εξυπηρέτησε όλους

Όρισε τη `serve-all`, που παίρνει μια ουρά και επιστρέφει τα ονόματα όλων των πελατών που περιμένουν, με τη σειρά που θα εξυπηρετούνταν.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
