# Υποδείξεις

## Γενικά

- Δήλωσε τα τέσσερα σύμβολα των βασικών κατευθύνσεων και τα τέσσερα σύμβολα σχετικής διόπτευσης με μία γραμμή `SYMBOLS:`:
  `SYMBOLS: north east south west ahead starboard behind port ;`
- Κάθε πλειάδα δηλώνεται με `TUPLE: <class> <slot1> <slot2> ;`.
- Μια γραμμή `GENERIC:` δηλώνει τη λέξη· κάθε γραμμή `M:` προσθέτει μια μέθοδο για μία κλάση. Χρησιμοποίησε `M::` αν θέλεις ονομασμένες τοπικές μεταβλητές στο σώμα της μεθόδου.

## 1. `>cartesian` για τις βασικές κατευθύνσεις

- Αρκεί ένα μικρό `case` πάνω στα τέσσερα σύμβολα κατεύθυνσης.
- `{ north [ 0 1 ] }`: το σώμα απλώς βάζει τις δύο τιμές· το τεστ περιμένει το `x` κάτω από το `y` στη στοίβα.

## 2. `>cartesian` για τις πολικές συντεταγμένες

- Μετέτρεψε τις μοίρες σε ακτίνια: `bearing pi * 180 /`.
- Τα `sin` και `cos` βρίσκονται στο `math.functions`.
- Βάλε `magnitude * sin(rad)` και μετά `magnitude * cos(rad)`.

## 3. `>cartesian` για τις σχετικές διοπτεύσεις

- Δήλωσε μια δυναμική μεταβλητή: `SYMBOL: heading`.
- Διάβασέ τη στη μέθοδό σου με `heading get`.
- Αντιστοίχισε τα `ahead/starboard/behind/port` σε μια μετατόπιση `0/90/180/270` με ένα `case` και μετά πρόσθεσε τη διόπτευση. Από εκεί και πέρα, είναι η ίδια πολική μετατροπή όπως στην εργασία 2· σκέψου να εξαγάγεις μια βοηθητική λέξη `: deg>cartesian ( magnitude bearing -- x y ) ... ;`.

## 4. `flip`

- Το `change-direction` σε ένα `cardinal` και το `change-bearing` σε ένα `polar` ή `relative` δημιουργούν μια νέα πλειάδα με ένα πεδίο τροποποιημένο, αφήνοντας τα υπόλοιπα όπως είναι:
  `[ <transformation-quotation> ] change-bearing`.
- Για την περιστροφή του `polar`: `[ 180 + 360 mod ] change-bearing`.

## 5. `add-bearings`

- Κάλεσε το `>cartesian` σε κάθε είσοδο και μετά πρόσθεσε τις συνιστώσες x και τις συνιστώσες y. Οι τοπικές μεταβλητές το κάνουν πιο ευανάγνωστο:
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
