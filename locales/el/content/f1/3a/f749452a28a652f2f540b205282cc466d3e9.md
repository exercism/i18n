# Εισαγωγή

## Σύγκριση

### Σύγκριση αριθμών

Στην `jq`, οι αριθμοί μπορούν να συγκριθούν χρησιμοποιώντας τους παρακάτω τελεστές σύγκρισης και ισότητας.

| Σύγκριση               | Τελεστής |
| ---------------------- | -------- |
| Μεγαλύτερο από         | `a > b`  |
| Μεγαλύτερο ή ίσο με    | `a >= b` |
| Μικρότερο από          | `a < b`  |
| Μικρότερο ή ίσο με     | `a <= b` |
| Ίσο με                 | `a == b` |
| Διάφορο από            | `a != b` |

Το αποτέλεσμα της σύγκρισης είναι πάντα μια τιμή boolean, δηλαδή είτε `true` είτε `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Σύγκριση συμβολοσειρών

Οι παραπάνω τελεστές σύγκρισης μπορούν επίσης να χρησιμοποιηθούν για τη σύγκριση συμβολοσειρών.
Σε αυτή την περίπτωση, εφαρμόζεται σειρά λεξικού (λεξικογραφική).
Η σειρά είναι _βάσει της τιμής του κωδικού σημείου Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Πρέπει να είσαι προσεκτικός όταν συγκρίνεις δύο μεταβλητές που φαίνεται να περιέχουν αριθμητικές τιμές αλλά είναι τύπου συμβολοσειράς.
Λόγω της σειράς λεξικού, το αποτέλεσμα δεν θα είναι το ίδιο με τη σύγκριση τιμών τύπου αριθμού.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### "Αυστηρή" ισότητα

Ο τελεστής `==` της `jq` είναι σαν το `===` της JavaScript, με την έννοια ότι πράγματα που "μοιάζουν" ίδια, αλλά είναι διαφορετικών τύπων, δεν είναι ίσα.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Σύγκριση πινάκων

Δύο πίνακες είναι ίσοι αν όλα τα αντίστοιχα στοιχεία είναι ίσα.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Σύγκριση αντικειμένων

Δύο αντικείμενα είναι ίσα αν έχουν τα ίδια ζεύγη κλειδιού-τιμής.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Συνθήκες

### Έκφραση if

Η **έκφραση υπό συνθήκη** της `jq` είναι `if A then B else C end`.

Το `if-then-else` είναι ένα φίλτρο όπως όλα τα ενσωματωμένα της `jq`: παίρνει μια είσοδο και παράγει μια έξοδο.

Αν η έκφραση `A` παράγει μια "αληθοφανή" τιμή, τότε το φίλτρο `if` αξιολογεί το `B`.
Διαφορετικά αξιολογεί το `C`.
Η είσοδος του φίλτρου `if` θα περαστεί στο `B` ή στο `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
Η ρήτρα `else` είναι **προαιρετική**; οι παρακάτω δύο εντολές είναι ισοδύναμες.

```jq
if A then B else . end
if A then B end
```
~~~~

### Εμφωλευμένες εντολές if

Περαιτέρω συνθήκες μπορούν να προστεθούν με το `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Χρησιμοποίησε όσες ρήτρες `elif` χρειάζεσαι.

### Αληθοφάνεια

Οι μόνες "ψευδείς" τιμές στην `jq` είναι: `false` και `null`.
Όλα τα άλλα είναι "αληθή", ακόμα και ο αριθμός μηδέν και η κενή συμβολοσειρά, ο κενός πίνακας και το κενό αντικείμενο.

### Τελεστές boolean

Οι **τελεστές boolean** `and` και `or` μπορούν να χρησιμοποιηθούν για τη δημιουργία σύνθετων ερωτημάτων.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Για άρνηση, χρησιμοποίησε το `not`. Αυτό είναι ένα **φίλτρο**, όχι τελεστής.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Εναλλακτικός τελεστής

Ο **εναλλακτικός τελεστής** σου επιτρέπει να ορίσεις μια "προεπιλεγμένη" τιμή αν μια έκφραση είναι ψευδής ή null.

```jq
A // B

# This is identical to
if A then A else B end
```

Για παράδειγμα

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
