# Τα βασικά της Unison

## Όροι και συναρτήσεις

Οι όροι και οι συναρτήσεις είναι οι βασικές μονάδες για να γράψεις ένα πρόγραμμα σε Unison.

Ένας "όρος" είναι αυτό που ονομάζουμε στατική τιμή. Ορίζεται με `name = expression`, προαιρετικά με προηγούμενη υπογραφή τύπου της μορφής `name : MyType`. Η Unison υποστηρίζει εξαγωγή τύπου, οπότε μπορεί να δεις την υπογραφή τύπου να παραλείπεται για απλούς ορισμούς.

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

Οι συναρτήσεις στη Unison έχουν τη μορφή `myFunctionName argument1 argument2 = myImplementation`; ξεκινούν με το όνομα της συνάρτησης και ακολουθούν ορίσματα χωρισμένα με κενά.

```
getMax a b = Nat.max a b
```

Οι συναρτήσεις μπορούν προαιρετικά να περιλαμβάνουν μια υπογραφή τύπου. Ο τελευταίος τύπος στα δεξιά είναι πάντα ο τελικός τύπος επιστροφής της συνάρτησης, και κάθε όρισμα χωρίζεται με το βέλος συνάρτησης `->`.

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

Για να καλέσεις μια συνάρτηση, χρησιμοποίησε το όνομά της ακολουθούμενο από τα ορίσματά της, χωρισμένα μόνο με κενά.

```
maximum = getMax 1 10
```

Όταν καλείς μια συνάρτηση, η Unison θα προσπαθήσει να αντιμετωπίσει ό,τι βρίσκεται ακριβώς στα δεξιά ως όρισμά της, κάτι που μπορεί να μη δίνει πάντα την επιθυμητή σειρά αξιολόγησης της συνάρτησης.

Ας υποθέσουμε ότι θέλουμε να πάρουμε την τιμή `1` από την παρακάτω παράσταση

```
shouldBe1 = getMax 1 10 - 10
```

Όπως είναι γραμμένο, το `shouldBe1` αξιολογείται σε `0`, επειδή η υπονοούμενη σειρά εφαρμογής συνάρτησης είναι `getMax 1 10`, που δίνει `10`, και έπειτα `10 - 10`, που δίνει `0`.

Μπορείς να χρησιμοποιήσεις παρενθέσεις για να ανασχηματίσεις την παράσταση στην επιθυμητή σειρά πράξεων.

```
shouldBe1 = getMax 1 (10 - 10)
```

## Συναρτήσεις πολλών γραμμών

Οι συναρτήσεις πολλών γραμμών στη Unison χρησιμοποιούν εσοχή ή μπλοκ `let` για να καθορίσουν τα όρια του κώδικα, γνωστά και ως "λεξιλογική εμβέλεια".

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

Όλα όσα βρίσκονται στο ίδιο επίπεδο εσοχής μοιράζονται την ίδια εμβέλεια, γι' αυτό μπορούμε να αναφερθούμε στη μεταβλητή `newBeginning` στην τελευταία γραμμή.

## Χώροι ονομάτων και εντολές `use`

Οι χώροι ονομάτων είναι ο τρόπος με τον οποίο ομαδοποιούμε και οργανώνουμε τις συναρτήσεις στη Unison. Μπορείς να τους σκεφτείς ως κάτι ανάλογο με τους "καταλόγους". Παρέχουν δομή και λογική ομαδοποίηση.

Μπορείς να φέρεις τις συναρτήσεις ενός χώρου ονομάτων στο πεδίο εμβέλειας με μια εντολή `use`.

Ας πούμε ότι έγραφες μια συνάρτηση που κάνει χρήση τιμών `List` της Unison. Ξέρεις ότι θα χρειαστείς συναρτήσεις όπως οι `List.map` και `List.flatMap`, όπου το `List` είναι ο χώρος ονομάτων και τα `map` και `flatMap` είναι συναρτήσεις. Για να μην επαναλαμβάνεσαι, μπορείς να επιλέξεις να φέρεις τα πάντα από τον χώρο ονομάτων `List` στη λεξιλογική εμβέλεια μέσα στη συνάρτησή σου ως εξής:

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

Η γραμμή `use List` αποσαφηνίζει τις αναφορές στα `map` και `flatMap`. Μπορείς να διαβάσεις περισσότερα για [τις εντολές `use` εδώ][use-statements].

## Η πρότυπη βιβλιοθήκη της Unison

Η πρότυπη βιβλιοθήκη της Unison ονομάζεται `base`. Αν ακολούθησες τον οδηγό γρήγορης εκκίνησης και έχεις δημιουργήσει τοπικά μια βάση κώδικα, η πρότυπη βιβλιοθήκη θα πρέπει να έχει ληφθεί αυτόματα. Μπορείς να περιηγηθείς στην τεκμηρίωση της πρότυπης βιβλιοθήκης στο διαδίκτυο, στο [Unison Share][unison-share-base].

## Σχόλια και κυριολεκτικά τεκμηρίωσης

Τα σχόλια στη Unison είναι ένα κάπως ασυνήθιστο χαρακτηριστικό. Όταν γράφεις κώδικα Unison, μπορείς να δημιουργήσεις κείμενο στο αρχείο σου με κατάληξη `.u` που δεν ερμηνεύεται, με την εξής σύνταξη:

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

_Ωστόσο_, επειδή ο κώδικας Unison αποθηκεύεται ως hash του αφηρημένου συντακτικού δέντρου του και όχι ως αρχεία βασισμένα σε κείμενο στο σύστημα αρχείων, τα σχόλια που είναι διακοσμήσεις κειμένου μιας δεδομένης συνάρτησης ή ενός όρου Unison στο αρχείο δεν μπορούν πραγματικά να αποθηκευτούν και να αποδοθούν ξανά για κοινή χρήση. Αν θέλεις να προσθέσεις πληροφορίες στον όρο σου στη Unison με τρόπο που θα αποθηκεύεται ώστε να μπορούν άλλοι να τον διαβάσουν και να τον κατανοήσουν, μπορείς να χρησιμοποιήσεις ένα κυριολεκτικό τεκμηρίωσης.

Η τεκμηρίωση είναι τιμή πρώτης τάξης στη γλώσσα προγραμματισμού Unison. Αυτό σημαίνει ότι ένα στοιχείο `Doc` μπορεί να ανατεθεί σε μια τιμή, να περαστεί ως τιμή σε μια συνάρτηση ή να επιστραφεί ως τιμή μιας συνάρτησης. Τα στοιχεία κυριολεκτικών τεκμηρίωσης ανοίγουν και κλείνουν με διπλά άγκιστρα. Να πώς θα μπορούσαμε να χρησιμοποιήσουμε το στοιχείο `Doc` ως σχόλιο.

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
