# Εισαγωγή

Σε αντίθεση με πολλές άλλες γλώσσες, υπάρχουν δύο διαφορετικές οντότητες στη JavaScript που αντιπροσωπεύουν την απουσία μιας (ουσιαστικής) τιμής.
Υπάρχουν το `null` και το `undefined`.

## Null

Η πρωτογενής τιμή `null` χρησιμοποιείται ως σκόπιμη "κενή τιμή" για μεταβλητές οποιουδήποτε τύπου.

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

Μπορείς να ελέγξεις αν μια μεταβλητή είναι `null` χρησιμοποιώντας τον [αυστηρό τελεστή ισότητας][mdn-strict-equality] `===`.

```javascript
let name = null;

name === null;
// => true
```

## Undefined

> Μια μεταβλητή στην οποία δεν έχει ανατεθεί τιμή είναι τύπου `undefined`.[^1]

Αυτό σημαίνει ότι ενώ το `null` αντιπροσωπεύει μια κενή τιμή (αλλά και πάλι μια τιμή), το `undefined` αντιπροσωπεύει την πλήρη απουσία τιμής. 🤯

Το `undefined` εμφανίζεται σε διαφορετικά πλαίσια.

- Αν μια μεταβλητή δηλωθεί χωρίς τιμή (αρχικοποίηση), είναι `undefined`.

  ```js
  let name;
  console.log(name); // => undefined
  ```

- Αν προσπαθήσεις να προσπελάσεις την τιμή για ένα ανύπαρκτο κλειδί σε ένα αντικείμενο, παίρνεις `undefined`.

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- Αν μια συνάρτηση δεν επιστρέφει τιμή, το αποτέλεσμα είναι `undefined`.

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- Αν ένα όρισμα δεν περαστεί σε μια συνάρτηση, είναι `undefined`, εκτός αν αυτό το όρισμα έχει προεπιλεγμένη τιμή.

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

Μπορείς να ελέγξεις αν μια μεταβλητή είναι `undefined` χρησιμοποιώντας τον αυστηρό τελεστή ισότητας `===`.

```javascript
let name;

name === undefined;
// => true
```

## Προαιρετική αλυσίδωση

Αν προσπαθήσεις να ανακτήσεις μια εμφωλευμένη τιμή σε ένα αντικείμενο αλλά το γονικό κλειδί δεν υπάρχει, η JavaScript θα πετάξει ένα σφάλμα.
Για να αποφευχθεί εύκολα αυτό, η προαιρετική αλυσίδωση προστέθηκε στην προδιαγραφή της γλώσσας το 2020.
Με τον τελεστή προαιρετικής αλυσίδωσης `?.` μπορείς να διασφαλίσεις ότι η JavaScript θα προσπαθήσει να προσπελάσει το εμφωλευμένο κλειδί μόνο αν το γονικό δεν ήταν `null` ή `undefined`.
Διαφορετικά επιστρέφεται το `undefined`.

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## Συνένωση Nullish

Υπάρχουν περιπτώσεις όπου θέλεις να εφαρμόσεις μια προεπιλεγμένη τιμή σε περίπτωση που μια μεταβλητή είναι `null` ή `undefined` (αλλά μόνο τότε).
Για να καλυφθεί αυτό, ο τελεστής συνένωσης Nullish `??` εισήχθη το 2020.
Επιστρέφει τον τελεστέο της δεξιάς πλευράς μόνο όταν ο τελεστέος της αριστερής πλευράς είναι `null` ή `undefined`.
Διαφορετικά, επιστρέφεται ο τελεστέος της αριστερής πλευράς.

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
