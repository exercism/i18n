# Υποδείξεις

## Γενικά

- Ένα [struct][structs] μπορεί να περιέχει πολλά πεδία διαφορετικών τύπων.
- Ο [τύπος Option][option] αντιπροσωπεύει μια τιμή που μπορεί να είναι είτε `Some(value)` είτε `None`.
- [Η δομή `match`][match]: πώς να κάνεις αντιστοίχιση προτύπων στη Cairo.

## 1. Υλοποίησε τη μέθοδο `revive`

- Χρησιμοποίησε [εντολές υπό συνθήκη][if-else] για να ελέγξεις αν η υγεία του παίκτη είναι 0.
- Μπορείς να δημιουργήσεις ένα νέο στιγμιότυπο `Player` χρησιμοποιώντας [σύνταξη αρχικοποίησης struct][structs].
- Χρησιμοποίησε [αντιστοίχιση προτύπων][match] ή λογική υπό συνθήκη για να προσδιορίσεις την τιμή μάνας με βάση το επίπεδο του παίκτη.
- Επίστρεψε `Option::Some(player)` για επιτυχημένη αναβίωση ή `Option::None` όταν η αναβίωση αποτύχει.

## 2. Υλοποίησε τη μέθοδο `cast_spell`

- Χρησιμοποίησε [αντιστοίχιση προτύπων][match] στον τύπο `Option` για να χειριστείς τις περιπτώσεις `Some` και `None` για τη μάνα.
- Μπορείς να χρησιμοποιήσεις [τελεστές σύγκρισης][operators] για να ελέγξεις αν υπάρχει αρκετή μάνα.
- Μπορείς να χρησιμοποιήσεις τους [μαθηματικούς τελεστές][operators] για αφαίρεση και πολλαπλασιασμό, ώστε να υπολογίσεις τιμές.
- Θυμήσου να τροποποιήσεις την κατάσταση του παίκτη (υγεία ή μάνα) χρησιμοποιώντας μεταβλητές αναφορές.
