# Εισαγωγή

Στη C++, μπορείς να συγκρίνεις τιμές χρησιμοποιώντας τους τελεστές σύγκρισης.

| Σύγκριση        | Τελεστής  |
| ------------------| --------- |
| ίσο             | `==`      |
| άνισο             | `!=`      |
| μικρότερο              | `<`       |
| μικρότερο ή ίσο     | `<=`      |
| μεγαλύτερο           | `>`       |
| μεγαλύτερο ή ίσο  | `>=`      |

Το αποτέλεσμα αυτών των συγκρίσεων είναι πάντα μια boolean τιμή:

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

Οι τελεστές `==` και `!=` ελέγχουν αν μια τιμή είναι ίση με μια άλλη ή όχι, αντίστοιχα.
Ακολουθούν μερικά συνηθισμένα παραδείγματα:

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

Οι άλλοι τελεστές ελέγχουν αν μια τιμή είναι μεγαλύτερη από (`>`), μεγαλύτερη ή ίση με (`>=`), μικρότερη από (`<`) και μικρότερη ή ίση με (`<=`) μια άλλη τιμή.
Αυτό το είδος σύγκρισης είναι διαθέσιμο για αριθμούς και συμβολοσειρές.
Κατά τη σύγκριση συμβολοσειρών, ακολουθείται η σειρά του λεξικού (γνωστή και ως λεξικογραφική σειρά).

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```
