# Οδηγίες

Μια φορά κι έναν καιρό, υπήρχε μια πολύβουη πόλη που ονομαζόταν Cyberspace.
Το Cyberspace ήταν μια ψηφιακή μητρόπολη, με εκατομμύρια κατοίκους να συνδέονται και να αποσυνδέονται κάθε μέρα.
Για να παρακολουθεί όλους αυτούς τους χρήστες, το Cyberspace είχε ένα ειδικό αρχείο που ονομαζόταν /etc/passwd.

Το αρχείο /etc/passwd ήταν σαν τηλεφωνικός κατάλογος για την πόλη.
Κατέγραφε κάθε χρήστη που είχε λογαριασμό στο σύστημα, μαζί με μερικές σημαντικές πληροφορίες για τον καθένα:

| n   | πεδίο |
| --- | --- |
| 1   | όνομα χρήστη |
| 2   | κωδικός πρόσβασης (το "x" δείχνει ότι ο πραγματικός κωδικός πρόσβασης είναι αποθηκευμένος αλλού, για λόγους ασφάλειας) |
| 3   | UID, ένα μοναδικό αριθμητικό αναγνωριστικό χρήστη |
| 4   | GID, ένα μοναδικό αριθμητικό αναγνωριστικό ομάδας (συνήθως ίδιο με το UID) |
| 5   | πληροφορίες χρήστη (συνήθως το πλήρες όνομα του χρήστη, αλλά μπορεί να περιλαμβάνουν και άλλες πληροφορίες) |
| 6   | κατάλογος home |
| 7   | κέλυφος σύνδεσης |

Τα πεδία χωρίζονται με τον χαρακτήρα άνω τελεία.
Αυτή είναι μια τυπική καταχώριση:

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

Το αρχείο το διαχειριζόταν μια ομάδα διαχειριστών συστήματος, που ήταν υπεύθυνη για τη δημιουργία νέων λογαριασμών, την ενημέρωση των υπαρχόντων λογαριασμών και τη διαγραφή παλιών λογαριασμών.
Οι διαχειριστές συστήματος ήταν οι φύλακες του Cyberspace, φροντίζοντας ώστε μόνο εξουσιοδοτημένοι χρήστες να μπορούν να έχουν πρόσβαση στο σύστημα.

Μια μέρα, ένας νέος διαχειριστής συστήματος, ο Alex, προσλήφθηκε για να μπει στην ομάδα.
Ο Alex ανυπομονούσε να αναλάβει τη δουλειά και έμαθε γρήγορα όλα τα μυστικά του αρχείου /etc/passwd.
Έμαθε πώς να προσθέτει νέους χρήστες στο σύστημα, πώς να ενημερώνει τις πληροφορίες των χρηστών και πώς να αφαιρεί παλιούς χρήστες.

Καθώς ο Alex δούλευε στο αρχείο /etc/passwd, παρατήρησε κάτι περίεργο.
Μερικοί χρήστες είχαν περίεργους ή ασυνήθιστους καταλόγους home.
Κάποιοι χρήστες είχαν τον κατάλογο home τους ορισμένο σε /dev/null, ενώ άλλοι τον είχαν ορισμένο σε περίεργες διαδρομές που δεν υπήρχαν.

Ο Alex κατάλαβε ότι αυτοί οι χρήστες δεν ήταν πραγματικοί άνθρωποι, αλλά ψεύτικοι λογαριασμοί που είχαν δημιουργηθεί από χάκερ.
Οι χάκερ είχαν βρει τρόπο να εκμεταλλευτούν μια ευπάθεια του συστήματος και είχαν δημιουργήσει αυτούς τους ψεύτικους λογαριασμούς για να αποκτήσουν πρόσβαση στο Cyberspace.

Ο Alex ήξερε ότι έπρεπε να δράσει.
Χρησιμοποίησε το awk για να αναλύσει το αρχείο /etc/passwd και έγραψε ένα σενάριο για να εντοπίσει όλους τους ψεύτικους λογαριασμούς.
Στη συνέχεια συνεργάστηκε με την υπόλοιπη ομάδα για να αφαιρέσει αυτούς τους λογαριασμούς και να διορθώσει την ευπάθεια που είχε επιτρέψει στους χάκερ να τους δημιουργήσουν εξαρχής.

Χάρη στη χρήση του awk από τον Alex, η ομάδα μπόρεσε να εντοπίσει και να αφαιρέσει τους ψεύτικους λογαριασμούς και να κάνει το Cyberspace ένα ασφαλέστερο μέρος για όλους.
Οι διαχειριστές συστήματος συνέχισαν να διαχειρίζονται το αρχείο /etc/passwd, κρατώντας το ενημερωμένο και ασφαλές, και διασφαλίζοντας ότι μόνο εξουσιοδοτημένοι χρήστες θα έχουν πρόσβαση στο σύστημα.

Τώρα είναι η σειρά σου να γίνεις διαχειριστής συστήματος σαν τον Alex.

~~~~exercism/note
Ορίστε λίγη επιπλέον σύνταξη της AWK που θα χρειαστείς για να λύσεις αυτή την άσκηση.

* Οι τελεστές Boolean είναι παρόμοιοι με άλλες γλώσσες:

    | πράξη | παράδειγμα            |
    | --------- | ------------------ |
    | AND       | `expr1 && expr2`   |
    | OR        | `expr1 \|\| expr2` |
    | NOT       | `! expr`           |

* Η κλήση μιας συνάρτησης έχει οικεία σύνταξη:

    ```awk
    function greet(name) {
        print "Hello", name
    }
    BEGIN {
        greet("Mary")   # prints "Hello Mary"
    }
    ```

~~~~

## 1. Εμφάνισε τα ονόματα χρήστη

Γράψε ένα πρόγραμμα awk που να εμφανίζει το πρώτο πεδίο, χωρισμένο με άνω τελεία, για κάθε γραμμή του αρχείου passwd.

## 2. Εμφάνισε τους αριθμούς γραμμής

Γράψε μια εντολή awk που εμφανίζει τον αριθμό γραμμής κάθε καταγραφής στο αρχείο εισόδου.
Εμφάνισε μόνο τον αριθμό γραμμής, όχι άλλες πληροφορίες.

## 3. Εμφάνισε τις καταγραφές με μη έγκυρους καταλόγους home.

Στο Cyberspace, ένας "έγκυρος" κατάλογος home ξεκινά με `/home` ή `/root`.
Εμφάνισε τις καταγραφές του αρχείου εισόδου με **μη έγκυρους** καταλόγους home.

## 4. Εμφάνισε τους έγκυρους χρήστες που χρησιμοποιούν bash

Εμφάνισε τις καταγραφές όπου ο κατάλογος home είναι έγκυρος **και** το κέλυφος σύνδεσης είναι `bash`.
