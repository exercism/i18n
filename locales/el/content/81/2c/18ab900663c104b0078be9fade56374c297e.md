# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                     |
| -------- | ------------ | ------- | ----------------------- |
| `$a0`    | είσοδος        | ακέραιος | αριθμός γραμμών του τριγώνου |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | πίνακας λέξεων          |
| `$v0`    | έξοδος       | ακέραιος | αριθμός λέξεων εξόδου  |
| `$t0-9`  | προσωρινός    | οποιοδήποτε     | για προσωρινή αποθήκευση   |
