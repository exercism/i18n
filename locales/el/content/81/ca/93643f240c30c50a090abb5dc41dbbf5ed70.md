# Σχετικά

Ο τύπος `Bool` είναι ένα από τα δομικά στοιχεία της γλώσσας.
Σκοπός του είναι να περιγράφει αν κάτι είναι αληθές ή ψευδές, με τις αντίστοιχες τιμές `True` και `False`.
Το όνομα `Bool` είναι σύντμηση του Boolean (λογική τιμή), ενός κλάδου των μαθηματικών που σχετίζεται με τη λογική σκέψη και πήρε το όνομά του από το έργο του George Boole.

## Τελεστές Boolean

Υπάρχουν δύο συναρτήσεις και δύο τελεστές για να χειρίζεσαι τιμές του τύπου `Bool`.

- `not : Bool -> Bool`
  Αυτή η συνάρτηση μετατρέπει το `True` σε `False` και το `False` σε `True`.
- `(&&) : Bool -> Bool -> Bool`
  Αυτός ο τελεστής, που ονομάζεται "AND", παίρνει δύο τιμές Boolean και επιστρέφει `True` αν είναι και οι δύο `True`.
  Για παράδειγμα, το `True && True` επιστρέφει `True`, αλλά το `True && False` επιστρέφει `False`.
- `(||) : Bool -> Bool -> Bool`
  Αυτός ο τελεστής, που ονομάζεται "OR", παίρνει δύο τιμές Boolean και επιστρέφει `True` αν τουλάχιστον μία από αυτές είναι `True`.
  Για παράδειγμα, το `False || False` επιστρέφει `False`, αλλά το `True || False` επιστρέφει `True`.
- `xor : Bool -> Bool -> Bool`
  Αυτή η συνάρτηση (όχι τελεστής), που ονομάζεται "XOR", παίρνει δύο τιμές Boolean και επιστρέφει `True` αν και μόνο αν η μία είναι `True` και η άλλη `False`.

Οι τελεστές `&&` και `||` δεν έχουν την ίδια προτεραιότητα.
Η προτεραιότητα του `&&` είναι μεγαλύτερη από αυτήν του `||`, ακριβώς όπως συμβαίνει με τον πολλαπλασιασμό `*` και την πρόσθεση `+`.
Κατά συνέπεια, η έκφραση `True || False && False` είναι ισοδύναμη με την `True || (False && False)`, η οποία είναι διαφορετική από την `(True || False) && False`.
Η πρώτη επιστρέφει `True`, ενώ η δεύτερη επιστρέφει `False`.

## Διακλάδωση υπό συνθήκη

Οι τιμές Boolean είναι εξαιρετικά χρήσιμες για να δημιουργείς διακλαδώσεις στον κώδικά σου που εκτελούνται μόνο όταν πληρούνται ορισμένες συνθήκες.
Στην Elm, αυτό γίνεται με μια έκφραση `if-then-else`, η οποία χρησιμοποιείται ως εξής.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

Η τιμή `someCondition` μπορεί να είναι οποιαδήποτε έκφραση που επιστρέφει `Bool`.
Αν αυτή η τιμή Boolean είναι `True`, ο κώδικας θα εκτελέσει το `doSomething`.
Διαφορετικά, είναι `False` και ο κώδικας θα εκτελέσει το `doSomethingElse`.
Ο κλάδος `else` είναι υποχρεωτικός, σε αντίθεση με κάποιες άλλες γλώσσες προγραμματισμού.

Αν χρειάζεται να αλυσιδώσεις συνθήκες, μπορείς απλώς να αλυσιδώσεις τις εκφράσεις `if-then-else`.

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
