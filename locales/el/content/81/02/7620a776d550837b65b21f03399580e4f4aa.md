# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά επισκέφτηκαν τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις έξι εργασίες, όλες σχετικές με τους αριθμούς των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Για λόγους σύγκρισης, κρατάς πάντα ένα αντίγραφο των μετρήσεων της προηγούμενης εβδομάδας δίπλα σου, που ήταν: 0, 2, 5, 3, 7, 8 και 4. Υλοποίησε τη μέθοδο (_static_) `BirdCount.LastWeek()` που επιστρέφει τις μετρήσεις της προηγούμενης εβδομάδας:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

Υλοποίησε τη μέθοδο `BirdCount.Today()` για να επιστρέψει πόσα πουλιά επισκέφτηκαν τον κήπο σου σήμερα. Οι μετρήσεις των πουλιών είναι ταξινομημένες κατά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο να είναι η σημερινή μέτρηση.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Αύξησε τη σημερινή μέτρηση

Υλοποίησε τη μέθοδο `BirdCount.IncrementTodaysCount()` για να αυξήσεις τη σημερινή μέτρηση:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Έλεγξε αν υπήρξε ημέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη μέθοδο `BirdCount.HasDayWithoutBirds()` που επιστρέφει `true` αν υπήρξε ημέρα κατά την οποία μηδέν πουλιά επισκέφτηκαν τον κήπο· αλλιώς, επέστρεψε `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν για τον πρώτο αριθμό ημερών

Υλοποίησε τη μέθοδο `BirdCount.CountForFirstDays()` που επιστρέφει τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου από την αρχή της εβδομάδας, αλλά περιόρισε τη μέτρηση στον καθορισμένο αριθμό ημερών από την αρχή της εβδομάδας.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Κάποιες ημέρες είναι πιο πολυάσχολες από άλλες. Πολυάσχολη ημέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά επισκέφτηκαν τον κήπο σου.
Υλοποίησε τη μέθοδο `BirdCount.BusyDays()` για να επιστρέψει τον αριθμό των πολυάσχολων ημερών:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
