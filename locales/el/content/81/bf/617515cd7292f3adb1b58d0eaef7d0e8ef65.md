# Σχετικά

Μπορείς να χρησιμοποιείς τα [άτομα][atom] όποτε έχεις ένα σύνολο από σταθερές να εκφράσεις. Τα άτομα προσφέρουν έναν ασφαλή ως προς τον τύπο τρόπο σύγκρισης τιμών. Ένα άτομο ορίζεται από το όνομά του, με μία άνω και κάτω τελεία μπροστά:

```elixir
# Atoms start with a ':',
# followed by alphanumeric snake_cased characters
:an_atom
```

Πολλές συναρτήσεις στην πρότυπη βιβλιοθήκη της Elixir επιστρέφουν ένα άτομο για να επισημάνουν το αποτέλεσμα:

```elixir
Enum.fetch([1], 0)
# => {:ok, 1}
Enum.fetch([1], 2)
# => :error
```

Τα [_άτομα_][atom] αναπαρίστανται εσωτερικά από έναν ακέραιο σε έναν πίνακα αναζήτησης, ο οποίος συμπληρώνεται αυτόματα. Έτσι, η σύγκριση ατόμων είναι ταχύτερη από τη σύγκριση συμβολοσειρών. Δεν είναι δυνατό να αλλάξεις αυτήν την εσωτερική τιμή. Γενικά θεωρείται [αντιπρότυπο][anti-pattern] να δημιουργείς άτομα δυναμικά από δεδομένα που παρέχει ο χρήστης. Το περιβάλλον εκτέλεσης έχει χώρο μόνο για έναν περιορισμένο αριθμό ατόμων, και η δημιουργία νέων ατόμων κατά την εκτέλεση μπορεί να αποτύχει αν ο πίνακας ατόμων είναι γεμάτος.

[atom]: https://hexdocs.pm/elixir/basic-types.html#atoms
[anti-pattern]: https://en.wikipedia.org/wiki/Anti-pattern
