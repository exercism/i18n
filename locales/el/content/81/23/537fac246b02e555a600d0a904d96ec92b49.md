# Σχετικά

Καθώς όλοι οι βασικοί τύποι δεδομένων της Clojure είναι αμετάβλητοι, προσφέρει *τύπους αναφοράς* που παρέχουν ελεγχόμενη μεταβολή. Οι απλούστεροι και πιο συχνά χρησιμοποιούμενοι από αυτούς ονομάζονται Atoms.

Τα Atoms δημιουργούνται με τη συνάρτηση `atom`, η οποία παίρνει μια αρχική τιμή:

```clojure
(def players (atom ()))
```

Η τρέχουσα τιμή του Atom αποκτάται με αποαναφορά, χρησιμοποιώντας είτε το `deref` είτε τη συντομογραφία `@`:

```clojure
@players
;;=> ()
```

Η τρέχουσα τιμή του Atom `players` μπορεί να τροποποιηθεί χρησιμοποιώντας το `swap!`, το οποίο ενημερώνει την τιμή εφαρμόζοντας μια συνάρτηση:

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

Η συνάρτηση `reset!` αντικαθιστά την τιμή ενός Atom χωρίς να λαμβάνει υπόψη την τρέχουσα τιμή του:

```clojure
(reset! players ())
```
