# Εργαλεία του track

Υπάρχουν δύο τύποι εργαλείων track:

- Παραγωγή: παρέχουν βασική λειτουργία στη μαθησιακή εμπειρία της συγκεκριμένης γλώσσας
- Συντήρηση: βοηθούν στη συντήρηση του track

Τα εργαλεία είναι (κατά κανόνα) γραμμένα στη γλώσσα του συγκεκριμένου track και τα κατασκευάζουν και τα συντηρούν οι maintainers.

## Εργαλεία παραγωγής

Αυτά τα εργαλεία τρέχουν στους διακομιστές παραγωγής του Exercism.

### Εργαλεία παραγωγής ειδικά για το track

Υπάρχουν τρία εργαλεία παραγωγής ειδικά για το track:

- **[Test Runners](/docs/building/tooling/test-runners)** (απαραίτητο)
- **[Representers](/docs/building/tooling/representers)** (προαιρετικό)
- **[Analyzers](/docs/building/tooling/analyzers)** (προαιρετικό)

### Γενικά εργαλεία παραγωγής

Υπάρχουν δύο γενικά εργαλεία παραγωγής που μπορούν να ρυθμιστούν για το track σου:

- **[Lines of Code Counter](/docs/building/tooling/lines-of-code-counter)** (προαιρετικό)
- **[Snippet Extractor](/docs/building/tooling/snippet-extractor)** (προαιρετικό)

### Ανάπτυξη

Τα εργαλεία παραγωγής χτίζονται ως Docker images.
Αναπτύσσονται αυτόματα στους διακομιστές παραγωγής του Exercism μέσω CI workflows.

## Εργαλεία συντήρησης

Τα εργαλεία συντήρησης είναι σχεδιασμένα να βοηθούν στη συντήρηση του track.
Συνήθως τρέχουν τοπικά (στον υπολογιστή του maintainer/contributor) και μερικές φορές στο CI, αλλά ποτέ σε παραγωγή.

Ορίστε μερικά παραδείγματα εργαλείων συντήρησης:

- **[Test Generators](/docs/building/tooling/test-generators)**

## Υλοποίηση

Τα εργαλεία του track είναι συνήθως (κατά κύριο λόγο) γραμμένα στη γλώσσα του track.

```exercism/caution
Ενώ είσαι ελεύθερος να χρησιμοποιήσεις άλλες γλώσσες, κάθε επιπλέον γλώσσα θα κάνει τη συντήρηση ή τη συνεισφορά στο track πιο δύσκολη.
Γι' αυτό, σου προτείνουμε να χρησιμοποιείς τη γλώσσα του track όπου είναι δυνατόν, γιατί κάνει τη συντήρηση ή τη συνεισφορά ευκολότερη.
```
