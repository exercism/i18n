Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσεις να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για να μαγειρέψεις τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη συνάρτηση `expected_minutes_in_oven()`, η οποία δεν παίρνει καμία παράμετρο και επιστρέφει πόσα λεπτά πρέπει να μείνουν τα λαζάνια στον φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι 60.

```r
> expected_minutes_in_oven()
[1] 60
```

## 2. Υπολόγισε τον χρόνο που απομένει στον φούρνο σε λεπτά

Όρισε τη συνάρτηση `remaining_time_in_minutes`, η οποία παίρνει ως παράμετρο τα πραγματικά λεπτά που έχουν περάσει τα λαζάνια στον φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνουν τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο ψησίματος σε λεπτά από την προηγούμενη εργασία.

```r
> remaining_time_in_minutes(50)
[1] 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `prep_time_in_minutes()`, η οποία παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά.

```r
> prep_time_in_minutes(2)
[1] 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsed_time_in_minutes`, η οποία παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που έχουν περάσει τα λαζάνια στον φούρνο. Η συνάρτηση θα πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα των λαζάνια, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχουν περάσει τα λαζάνια στον φούρνο αυτή τη στιγμή.

```r
> elapsed_time_in_minutes(3, 20)
[1] 26
```
