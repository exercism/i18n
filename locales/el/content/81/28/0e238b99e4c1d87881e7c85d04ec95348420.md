# Σχετικά

Στη Rust, οι μέθοδοι είναι συναρτήσεις που ορίζονται για ένα struct (ή ένα `enum` ή ένα αντικείμενο `trait`).
Αυτό αλλάζει τον τρόπο κλήσης: αντί για `frobnicate(foo)`, μια μέθοδος καλείται ως `foo.frobnicate()`.

Οι μέθοδοι είναι παρόμοιες με τις συναρτήσεις: δηλώνονται με τη λέξη-κλειδί `fn`,
έχουν όνομα και μπορούν να έχουν παραμέτρους και τιμές επιστροφής.

Σε αντίθεση με τις συναρτήσεις, η πρώτη παράμετρος μιας μεθόδου είναι πάντα το `self` (ή μια παραλλαγή του),
το οποίο αντιπροσωπεύει το στιγμιότυπο του struct στο οποίο καλείται η μέθοδος (περισσότερες λεπτομέρειες παρακάτω).

Ας δημιουργήσουμε ένα `enum` για τους οίκους του Χόγκουαρτς και ένα `struct` που περιγράφει το `age` και το `house` ενός μάγου:

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## Ορισμός μεθόδων

Για να ορίσουμε μεθόδους για το struct `Wizard`, ξεκινάμε ένα μπλοκ `impl` (συντομογραφία του implementation) για το `Wizard`.

```rust
impl Wizard { }
```

Ό,τι βρίσκεται μέσα σε αυτό το μπλοκ `impl` θα συσχετίζεται με τον τύπο `Wizard`.
Σημείωσε ότι ένα struct επιτρέπεται να έχει πολλαπλά μπλοκ `impl`.

### Χρήση του `self`

Μια μέθοδος πρέπει να έχει ως πρώτη παράμετρο μια παράμετρο με όνομα `self` τύπου `Self`.
Ο τύπος `Self` είναι ένα ψευδώνυμο για τον τύπο για τον οποίο προορίζεται το μπλοκ `impl`.
Στο παράδειγμά μας, το `Self` αντιπροσωπεύει το `Wizard`.

Η Rust μάς επιτρέπει, για ευκολία, να το συντομεύσουμε γράφοντας μόνο το όνομα `self` στη θέση της πρώτης παραμέτρου.
Συνήθεις τύποι του `self` για μεθόδους περιλαμβάνουν:

- `self`: Συντομογραφία του `self: Self`. Η γυμνή υπογραφή `self` καταναλώνει το στιγμιότυπο.
- `&self`: Συντομογραφία του `self: &Self`. Δανείζεται το στιγμιότυπο αμετάβλητα.
- `&mut self`: Συντομογραφία του `self: &mut Self`. Δανείζεται το στιγμιότυπο μεταβλητά.

Σε πιο προχωρημένο κώδικα μπορεί επίσης να δεις υπογραφές όπως `self: Pin<&self>`, `self: Rc<Self>` κ.λπ.
Αυτό όμως ξεφεύγει από το πεδίο αυτού του οδηγού.

### Ορισμός μεθόδου με `&self`

Αν θέλουμε να υλοποιήσουμε μια μέθοδο `info` που εμφανίζει τις βασικές πληροφορίες του μάγου,
θα μπορούσαμε να ορίσουμε αυτή τη μέθοδο μέσα σε ένα μπλοκ `impl` για το `Wizard`:

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

Σημείωσε ότι στην υπογραφή της `info` δανειζόμαστε το στιγμιότυπο αμετάβλητα με το `&self`.
Έτσι, θα μπορούσαμε να διαβάσουμε τα πεδία `age` και `house` ενός στιγμιότυπου `Wizard` χωρίς να τα αλλάξουμε.
Αν είχαμε χρησιμοποιήσει ένα `self` που καταναλώνει αντί να δανειστούμε, το στιγμιότυπο θα ήταν απροσπέλαστο μετά την κλήση της μεθόδου.

Με τη μέθοδο `info` υλοποιημένη, θα μπορούσαμε να εκτυπώσουμε τις βασικές πληροφορίες ενός μάγου:

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### Ορισμός μεθόδου με `&mut self`

Αν θέλουμε να υλοποιήσουμε μια μέθοδο που μεταβάλλει τα πεδία ενός στιγμιότυπου struct,
δανειζόμαστε το στιγμιότυπο μεταβλητά με το `&mut self` στην υπογραφή της μεθόδου.

Ας πούμε ότι θέλουμε να θεσπίσουμε έναν νέο κανόνα στο Χόγκουαρτς που να επιτρέπει στους μαθητές να αλλάζουν οίκο.
Θα μπορούσαμε να υλοποιήσουμε μια μέθοδο `switch_house` ως εξής:

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

Τώρα μπορούμε να αλλάξουμε οίκο για έναν μάγο που σπουδάζει στο Χόγκουαρτς:

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## Πολλαπλά 'impl' blocks

Στη Rust, κάθε στοιχείο επιτρέπεται να έχει πολλαπλά μπλοκ `impl`.
Μπορούμε λοιπόν να ομαδοποιήσουμε όλες τις μεθόδους στο ίδιο μπλοκ `impl` ή να έχουμε πολλαπλά μπλοκ `impl` για διαφορετικές ομάδες μεθόδων.
Και οι δύο προσεγγίσεις είναι έγκυρη σύνταξη, αλλά η τυπική οργάνωση ενός έργου χρησιμοποιεί ένα μόνο μπλοκ `impl` ανά μοναδικό σύνολο ορίων `where` σε επίπεδο `impl`.

## Συσχετισμένες Συναρτήσεις

Είναι δυνατό να ορίσουμε συναρτήσεις μέσα σε ένα μπλοκ `impl` που δεν περιέχουν παράμετρο `self`.
Επειδή τους λείπει η παράμετρος `self`, δεν είναι μέθοδοι.
Ωστόσο, εξακολουθούν να συσχετίζονται με τον τύπο για τον οποίο υλοποιούνται και καλούνται ονομάζοντας αυτόν τον τύπο.
Γι' αυτόν τον λόγο ονομάζονται συσχετισμένες συναρτήσεις (ή συναρτήσεις συσχετισμένες με τύπο).

Έχεις ήδη δει μερικές συσχετισμένες συναρτήσεις, όπως τη `String::from()`:

```rust
let some_string = String::from("This is an associated function but not a method");
```

Οι κατασκευαστές συχνά υλοποιούνται ως συσχετισμένες συναρτήσεις.
Ας δημιουργήσουμε μια συνάρτηση `new` συσχετισμένη με τον τύπο `Wizard`:

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

Σημείωσε ότι μπορούμε να χρησιμοποιήσουμε το `Self` αντί για το `Wizard` για να δηλώσουμε τον τύπο που θα επιστραφεί από τη συνάρτηση.
Δεν είναι υποχρεωτικό να χρησιμοποιήσουμε με αυτόν τον τρόπο το ψευδώνυμο τύπου `Self`, αλλά μπορεί να απλοποιήσει την υλοποίηση για τύπους με περίπλοκα ή μακροσκελή ονόματα.
Τώρα μπορούμε να τρέξουμε τα εξής:

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
