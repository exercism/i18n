# Σχετικά

Ο `do-while` βρόχος είναι μια εναλλακτική του `while` βρόχου, με τη μόνη διαφορά ότι ένας βρόχος `do-while` εκτελείται τουλάχιστον μία φορά:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Οι περιπτώσεις χρήσης ενός `do-while` βρόχου είναι πολύ σπάνιες, οπότε χρησιμοποιείται αντ' αυτού ο κανονικός `while` βρόχος.
