# Σχετικά

Ο βρόχος `do-while` είναι μια εναλλακτική του βρόχου `while`, με τη μόνη διαφορά ότι ένας βρόχος `do-while` εκτελείται τουλάχιστον μία φορά:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Οι περιπτώσεις χρήσης ενός βρόχου `do-while` είναι πολύ σπάνιες, οπότε χρησιμοποιείται αντ' αυτού ο κανονικός βρόχος `while`.
