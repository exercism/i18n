# Υποδείξεις

## Γενικά

- [Μη ανακτήσιμα σφάλματα][unrecoverable]: προκάλεσε ένα panic με μήνυμα σφάλματος.
- [Μακροεντολή `panic!`][panic-excl-macro]: προκάλεσε ένα panic με μήνυμα `ByteArray`.
- [Μακροεντολή `assert!`][assert]: προκάλεσε ένα panic αν μια συνθήκη αξιολογείται ως `false`.
- [Απαρίθμηση Result][result]: πώς να χρησιμοποιείς την απαρίθμηση `Result`.

## 2. Χειρίσου τις παράνομες πράξεις

- Εδώ πρέπει να [επιστρέψεις ένα σφάλμα][result].

## 3. Χειρίσου την απουσία πράξης

- Εδώ πρέπει να [προκαλέσεις panic][panic-excl-macro] με ένα μήνυμα `ByteArray` για να χειριστείς τις κενές συμβολοσειρές στις πράξεις.

## 4. Χειρίσου τα σφάλματα κατά τη διαίρεση με το μηδέν

- Εδώ πρέπει να προκαλέσεις panic για να χειριστείς τη διαίρεση με το μηδέν.
