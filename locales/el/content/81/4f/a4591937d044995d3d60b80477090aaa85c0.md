# Εισαγωγή

## Ακέραιοι

Στην Elixir υπάρχουν δύο διαφορετικά είδη αριθμών: οι ακέραιοι και τα float.

```elixir
integer = 3
# => 3
```

## Αριθμοί κινητής υποδιαστολής

Τα float είναι αριθμοί με ένα ή περισσότερα ψηφία μετά την υποδιαστολή. Χρησιμοποιούν τη μορφή κινητής υποδιαστολής διπλής ακρίβειας 64-bit.

```elixir
float = 3.45
# => 3.45
```

### Εργασία με αριθμούς

Στα module [`Integer`][integer-functions] και [`Float`][float-functions] μπορείς να βρεις μερικές χρήσιμες συναρτήσεις για να δουλέψεις με αυτούς τους τύπους. Οι βασικοί αριθμητικοί τελεστές ορίζονται στο module [`Kernel`][kernel-arithmetic-operators].

### Μετατροπή

Οι ακέραιοι και τα float μπορούν να αναμειχθούν σε μια αριθμητική παράσταση. Η χρήση ενός float σε μια παράσταση εξασφαλίζει ότι το αποτέλεσμα θα είναι κι αυτό float.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Ωστόσο, όταν κάνεις διαίρεση, το αποτέλεσμα θα είναι πάντα float, ακόμα κι αν χρησιμοποιείς μόνο ακέραιους.

```elixir
6 / 2
# => 3.0
```

Για να μετατρέψεις ένα float σε ακέραιο, μπορείς να απορρίψεις το δεκαδικό μέρος με [`trunc/1`][trunc-1].
