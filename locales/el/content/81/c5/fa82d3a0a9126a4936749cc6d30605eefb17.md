# Οδηγίες

Μια νέα λέσχη ποίησης άνοιξε στην πόλη και σκέφτεσαι να πας.
Επειδή έχουν συμβεί περιστατικά στο παρελθόν, η λέσχη έχει έναν πολύ συγκεκριμένο κανονισμό για την είσοδο, τον οποίο θα πρέπει να μάθεις καλά πριν επιχειρήσεις να μπεις.

Στη λέσχη ποίησης υπάρχουν δύο πόρτες, μια μπροστινή και μια πίσω, και οι δύο φυλάσσονται.
Για να μπεις, θα πρέπει να βρεις τον κωδικό της ημέρας.

Ο κωδικός βασίζεται πάντα σε ένα ποίημα και μπορεί να προκύψει με μια διαδικασία δύο βημάτων.

1. Ο φρουρός θα απαγγείλει το ποίημα, έναν στίχο τη φορά, και εσύ πρέπει να απαντήσεις με το κατάλληλο γράμμα αυτού του στίχου.
2. Στη συνέχεια, ο φρουρός θα σου πει όλα τα γράμματα που απάντησες μαζεμένα, και πρέπει να τα γράψεις σε ένα χαρτί σε συγκεκριμένη μορφή.

Οι λεπτομέρειες της διαδικασίας εξαρτώνται από την πόρτα από την οποία προσπαθείς να μπεις.

~~~~exercism/note
Όλες οι συμβολοσειρές σε αυτή την άσκηση θα είναι κωδικοποιημένες σε ASCII και τερματισμένες με NUL.
Αυτό σημαίνει ότι όλοι οι χαρακτήρες χρησιμοποιούν κωδικοποίηση ASCII και κάθε συμβολοσειρά τελειώνει όταν βρεθεί το '\0' (ο χαρακτήρας NUL, με τιμή `0`).
~~~~

~~~~exercism/note
Αυτές είναι οι εντολές συμβολοσειρών που αναφέρονται σε αυτή την έννοια:

| instruction  | what it does                                                                                                      |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | loads a value from a memory location indicated by `rsi` into `rax`                                                |
| `stos`       | stores a value from `rax` into a memory location indicated by `rdi`                                               |
| `movs`       | copies a value from a memory location indicated by `rsi` and stores it in a memory location indicated by `rdi`    |

Όλες τους πρέπει να έχουν ένα επίθεμα που να δηλώνει το μέγεθος της πράξης:

| suffix | size             |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

Όλες οι εντολές συμβολοσειρών τροποποιούν επίσης τις διευθύνσεις στους `rsi` και/ή `rdi` (μόνο στους καταχωρητές που χρησιμοποιεί η εντολή).
Από προεπιλογή, αυξάνουν τις διευθύνσεις κατά το μέγεθος της πράξης.

Το πρόθεμα `rep` μπορεί να προστεθεί σε οποιαδήποτε από τις παραπάνω εντολές συμβολοσειρών για να την επαναλάβει τόσες φορές όσες ορίζει ο `rcx`.
~~~~

## 1. Πάρε το πρώτο γράμμα μιας πρότασης

Για να προσδιορίσεις τα γράμματα του κωδικού της μπροστινής πόρτας, πρέπει να απαντήσεις με το πρώτο γράμμα του στίχου του ποιήματος που σου απαγγέλλει ο φρουρός.

Για να προκύψει ένας ωραίος κωδικός, τα μέλη της λέσχης ποίησης συνηθίζουν να χρησιμοποιούν _ακροστιχίδες_.
Αυτό σημαίνει ότι το πρώτο γράμμα κάθε πρότασης σχηματίζει μια λέξη.
Ορίστε ένα παράδειγμα από έναν από τους αγαπημένους τους συγγραφείς, τον Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Έτσι, όταν ο φρουρός απαγγέλλει **Stands so high**, απαντάς **S**, και όταν απαγγέλλει **Huge hooves too**, απαντάς **H**.

Υλοποίησε τη συνάρτηση `front_door_response` που παίρνει ως όρισμα τη διεύθυνση στη μνήμη για έναν στίχο του ποιήματος και επιστρέφει το πρώτο γράμμα αυτού του στίχου.
Αυτό το γράμμα πρέπει να επιστραφεί ως χαρακτήρας κωδικοποιημένος σε ASCII, που καταλαμβάνει 1 byte.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Κεφαλαιοποίησε μια λέξη

Τώρα που έχεις όλα τα σωστά γράμματα, το μόνο που χρειάζεται να κάνεις για να πάρεις τον κωδικό της μπροστινής πόρτας είναι να κεφαλαιοποιήσεις σωστά τη λέξη.

Υλοποίησε τη συνάρτηση `front_door_password` που παίρνει ως όρισμα τη διεύθυνση στη μνήμη για μια συμβολοσειρά που περιέχει μόνο τα συνδυασμένα γράμματα που βρήκες στην εργασία 1.
Θα πρέπει να τροποποιεί τη συμβολοσειρά εισόδου [in-place][in-place], ώστε να είναι σωστά κεφαλαιοποιημένη.
Αυτό σημαίνει ότι η σωστή συμβολοσειρά θα πρέπει να αποθηκευτεί στην ίδια θέση μνήμης με την είσοδο.

Η συνάρτηση δεν έχει τιμή επιστροφής.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Πάρε το τελευταίο γράμμα μιας πρότασης

Για να προσδιορίσεις τα γράμματα του κωδικού της πίσω πόρτας, πρέπει να απαντήσεις με το τελευταίο γράμμα του στίχου του ποιήματος που σου απαγγέλλει ο φρουρός.

Τα μέλη της λέσχης ποίησης είναι πραγματικά έξυπνα.
Το ποίημα που αναφέρθηκε προηγουμένως είναι επίσης _τελεστιχίδα_, που σημαίνει ότι το τελευταίο γράμμα κάθε πρότασης σχηματίζει επίσης μια λέξη:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Όταν ο φρουρός απαγγέλλει **Stands so high**, απαντάς **h**, και όταν απαγγέλλει **Huge hooves too**, απαντάς **o**.

Σημείωσε ότι μερικές φορές ο φρουρός κάνει στιλιστικές παύσεις (με τη μορφή σημείων στίξης ή κενού διαστήματος) όταν απαγγέλλει το ποίημα.
Θα πρέπει να αγνοήσεις αυτές τις παύσεις για να βγάλεις το σωστό γράμμα.

Υλοποίησε τη συνάρτηση `back_door_response` που παίρνει ως όρισμα τη διεύθυνση στη μνήμη για έναν στίχο του ποιήματος και επιστρέφει το τελευταίο γράμμα αυτού του στίχου.
Αυτό το γράμμα πρέπει να επιστραφεί ως χαρακτήρας κωδικοποιημένος σε ASCII, που καταλαμβάνει 1 byte.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Να είσαι ευγενικός

Για να μπεις στη λέσχη ποίησης από την πίσω πόρτα, πρέπει να είσαι υπερβολικά ευγενικός.
Έτσι, για να βγάλεις τον κωδικό, αυτή τη φορά πρέπει να κεφαλαιοποιήσεις σωστά τη λέξη και να προσθέσεις στο τέλος το `", please."`.

Υλοποίησε τη συνάρτηση `back_door_password` που δέχεται ως ορίσματα, με αυτή τη σειρά:

1. Τη διεύθυνση στη μνήμη για ένα buffer όπου θα αποθηκευτεί η συμβολοσειρά που προκύπτει.
2. Τη διεύθυνση στη μνήμη για μια συμβολοσειρά που περιέχει τα συνδυασμένα γράμματα που βρήκες στην εργασία 3.

Η συνάρτηση θα πρέπει να αποθηκεύσει την ευγενική εκδοχή του κεφαλαιοποιημένου κωδικού στο [buffer][buffer].
Ένα _buffer_ είναι ένας πίνακας που μπορεί να χρησιμοποιηθεί για την αποθήκευση τιμών στη μνήμη, ώστε να μεταφέρονται μεταξύ διαφορετικών συναρτήσεων.

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής.

```c
back_door_password("horse");
// => "Horse, please."
```
