# Σχετικά

Η Nim είναι μια γλώσσα γενικού σκοπού, σχεδιασμένη και αναπτυγμένη από τον Andreas Rumpf, που εμφανίστηκε για πρώτη φορά το 2008.
Σχεδιασμένη να είναι αποδοτική, εκφραστική και κομψή.
Η Nim είναι στατικά τυποποιημένη και μεταγλωττιζόμενη, αλλά σου επιτρέπει να γράψεις κομψό κώδικα που εκτελείται αποδοτικά.
Η Nim σου επιτρέπει να στοχεύσεις πολλές πλατφόρμες, μεταγλωττίζοντας τον κώδικα σε C, C++, JavaScript ή Objective-C.
Η σύνταξη της Nim είναι παρόμοια με της Python και μοιράζεται πολλά από τα χαρακτηριστικά της, αλλά αντλεί έμπνευση από αρκετές γλώσσες, όπως C, C++, C#, Lisp, Ada, Go, Oberon και άλλες.

Καθώς η Nim είναι μια γλώσσα γενικού σκοπού, μπορεί να χρησιμοποιηθεί σε πολλά διαφορετικά πεδία, αλλά έχει βρει μια πραγματική θέση στον χώρο της ανάπτυξης παιχνιδιών και του προγραμματισμού συστημάτων, συμπεριλαμβανομένων των ενσωματωμένων συστημάτων.

Η Nim σου προσφέρει μεγάλο μέρος της ευκολίας που συναντάς στην Python και σε άλλες γλώσσες, όπως ευανάγνωστη σύνταξη, ένα σύστημα διαχείρισης πακέτων για να χρησιμοποιείς νέες βιβλιοθήκες στα έργα σου και φιλικά προς τον χρήστη tracebacks για τον εντοπισμό σφαλμάτων.

Η Nim σου δίνει την ταχύτητα και τη φορητότητα της C, αλλά με έναν συλλέκτη απορριμμάτων υψηλών επιδόσεων και κομψή σύνταξη που κάνει τη γλώσσα πολύ προσιτή σε όσους ξεκινούν τώρα.
Η Nim επίσης σου δίνει τον έλεγχο, αφήνοντάς σε να αλλάξεις τον συλλέκτη απορριμμάτων ή να τον απενεργοποιήσεις εντελώς, δίνοντάς σου την επιλογή να διαχειριστείς μόνος σου τη μνήμη.
Με τη Nim έχεις στη διάθεσή σου μια ποικιλία προγραμματιστικών παραδειγμάτων και επιπέδων αφαίρεσης.
