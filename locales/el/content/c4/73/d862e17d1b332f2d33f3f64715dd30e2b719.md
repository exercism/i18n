# Σχετικά

Όταν οι τύποι δεν μπορούν να μετατραπούν έμμεσα, πρέπει να χρησιμοποιήσεις τον τελεστή ρητής μετατροπής [τελεστής][cast-operator]. Ο τελεστής μετατροπής δεν είναι τίποτα περισσότερο από τον τύπο-στόχο μέσα σε παρενθέσεις, πριν από την τιμή που θέλεις να μετατρέψεις:

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

Η χρήση της ρητής μετατροπής είναι δυνητικά επικίνδυνη. Τα δύο πιο συνηθισμένα λάθη είναι:

- Η μετατροπή σε μη συμβατό τύπο. Αυτό θα πετάξει μια εξαίρεση κατά την εκτέλεση.
- Η μετατροπή σε μια αριθμητική τιμή που δεν είναι αρκετά "πλατιά". Αυτό μπορεί να οδηγήσει σε σύγκρουση προσήμου ή, στην περίπτωση των ακεραίων, στην εκτίναξη μιας εξαίρεσης υπερχείλισης

Σημείωση: μια παράσταση τύπου `int` μπορεί να μετατραπεί ρητά σε `char`. Αυτό μπορεί να έχει ως αποτέλεσμα ένα μη έγκυρο `char`.

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
