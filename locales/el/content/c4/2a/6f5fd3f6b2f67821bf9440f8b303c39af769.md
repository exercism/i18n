# Οδηγίες

Δεδομένων των ονομάτων των μαθητών και της τάξης στην οποία βρίσκονται, δημιούργησε έναν κατάλογο για το σχολείο.

Στο τέλος, θα πρέπει να μπορείς να:

- Προσθέτεις το όνομα ενός μαθητή στον κατάλογο μιας τάξης
  - "Πρόσθεσε τον Jim στην τάξη 2."
  - "Εντάξει."
- Παίρνεις μια λίστα με όλους τους μαθητές που είναι εγγεγραμμένοι σε μια τάξη
  - "Ποιοι μαθητές είναι στην τάξη 2;"
  - "Προς το παρόν έχουμε μόνο τον Jim."
- Παίρνεις μια ταξινομημένη λίστα με όλους τους μαθητές σε όλες τις τάξεις. Οι τάξεις πρέπει να ταξινομούνται ως 1, 2, 3, κ.λπ., και οι μαθητές μέσα σε μια τάξη πρέπει να ταξινομούνται αλφαβητικά κατά όνομα.
  - "Ποιοι είναι εγγεγραμμένοι στο σχολείο αυτή τη στιγμή;"
  - "Για να σκεφτώ. Έχουμε
  την Anna, τη Barb και τον Charlie στην τάξη 1,
  τον Alex, τον Peter και τη Zoe στην τάξη 2
  και τον Jim στην τάξη 5.
  Άρα η απάντηση είναι: Anna, Barb, Charlie, Alex, Peter, Zoe και Jim"

Σημείωσε ότι όλοι οι μαθητές μας έχουν μόνο ένα όνομα. (Είναι μια μικρή πόλη, τι θέλεις;)

## Για επιπλέον πόντους

Κατάφερες να περάσεις τα τεστ και να έχεις καθαρό κώδικα; Αν θέλεις, αυτά είναι μερικά επιπλέον πράγματα που θα μπορούσες να δοκιμάσεις:

- Αν δουλεύεις σε μια γλώσσα με μεταβλητές δομές δεδομένων και η υλοποίησή σου επιτρέπει σε εξωτερικό κώδικα να μεταβάλλει απευθείας την εσωτερική βάση δεδομένων του σχολείου, δες αν μπορείς να το αποτρέψεις. Μη διστάσεις να προσθέσεις επιπλέον τεστ.

Έπειτα, μοιράσου τις σκέψεις σου σε ένα σχόλιο στην υποβολή. Έκανε αυτό το πείραμα τον κώδικα καλύτερο; Χειρότερο; Έμαθες κάτι από αυτό;
