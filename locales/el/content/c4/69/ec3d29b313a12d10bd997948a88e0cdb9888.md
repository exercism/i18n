# Σχετικά

Η Gleam δεν χρησιμοποιεί εξαιρέσεις για τη διαχείριση σφαλμάτων· αντίθετα, οι συναρτήσεις που μπορούν είτε να πετύχουν είτε να αποτύχουν επιστρέφουν τον γενικό τύπο `Result`.

Ο τύπος `Result` είναι ενσωματωμένος στη γλώσσα, οπότε δεν χρειάζεται να τον ορίσεις ή να τον εισάγεις, αλλά αν τον όριζες μόνος σου θα έμοιαζε κάπως έτσι:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Όταν μια συνάρτηση πετύχει, επιστρέφεται η παραλλαγή `Ok`, και όταν μια συνάρτηση αποτύχει, επιστρέφεται η παραλλαγή `Error`.

Τα αποτελέσματα είναι πολύ συνηθισμένα στη Gleam, και όσοι προγραμματίζουν σε Gleam συνήθως χρησιμοποιούν το [`gleam/result` module](https://hexdocs.pm/gleam_stdlib/gleam/result.html) για να κάνουν πιο εύκολη τη δουλειά μαζί τους.

Η συνάρτηση `result.map` μπορεί να χρησιμοποιηθεί για να καλέσεις μια συνάρτηση στην τιμή που περιέχει ένα `Result`, αν αυτό είναι `Ok`, ή για να αφήσεις ένα `Error` να περάσει αμετάβλητο.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

Η συνάρτηση `result.try` είναι παρόμοια, αλλά η συνάρτηση callback πρέπει να επιστρέψει ένα αποτέλεσμα. Αυτό είναι χρήσιμο για να συνδέσεις σε αλυσίδα πολλές συναρτήσεις που επιστρέφουν αποτελέσματα.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
