# Εισαγωγή

Έχεις μπει στη LinkLine, μια κορυφαία εταιρεία επικοινωνιών που εργάζεται για να διασφαλίζει αξιόπιστες συνδέσεις για όλους.
Η ομάδα αντιμετωπίζει μια μεγάλη πρόκληση: οι χρήστες υποβάλλουν αριθμούς τηλεφώνου σε κάθε λογής μορφή, με παύλες, κενά, τελείες, παρενθέσεις και ακόμη και προθέματα.
Κάποιοι αριθμοί είναι έγκυροι, ενώ άλλοι είναι αδύνατο να χρησιμοποιηθούν.

Η αποστολή σου είναι να μετατρέψεις αυτό το χάος σε τάξη.
Θα καθαρίζεις τους έγκυρους αριθμούς και θα τους μορφοποιείς κατάλληλα για χρήση στο σύστημα.
Παράλληλα, θα εντοπίζεις και θα φιλτράρεις όποιες μη έγκυρες καταχωρήσεις.

Η επιτυχία των λειτουργιών της LinkLine εξαρτάται από την ικανότητά σου να ξεχωρίζεις τα χρήσιμα από τα άχρηστα.
Είσαι έτοιμος να αναλάβεις την πρόκληση και να κρατήσεις τις συνδέσεις να λειτουργούν ομαλά;
