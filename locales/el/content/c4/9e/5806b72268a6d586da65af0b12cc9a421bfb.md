# Υποδείξεις

## Συνήθεις παγίδες που καλό είναι να αποφεύγεις
- Συνήθως δεν χρειάζεται να χρησιμοποιείς το `return` στη Scala. Για τη σχετική συζήτηση δες [εδώ](http://stackoverflow.com/questions/24856106/return-in-a-scala-function-literal). Ή, όπως λέει ένα σχόλιο από εκείνη τη συζήτηση: *Μη χρησιμοποιείς το return, κάνει τη Scala να κλαίει.*
