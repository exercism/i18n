# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος     | Περιγραφή                                                |
| ----------- | -------------- | --------- | -------------------------------------------------------- |
| `$a0`       | είσοδος        | ακέραιος  | πλήθος ψηφίων εισόδου                                    |
| `$a1`       | είσοδος        | ακέραιος  | βάση για τα ψηφία εισόδου                                |
| `$a2`       | είσοδος        | ακέραιος  | βάση για τα ψηφία εξόδου                                 |
| `$a3`       | είσοδος/έξοδος | διεύθυνση | πίνακας από λέξεις ψηφίων που μπορεί να αντικατασταθεί   |
| `$v0`       | έξοδος         | ακέραιος  | πλήθος ψηφίων εξόδου, -1 αν η είσοδος δεν είναι έγκυρη   |
| `$t0-9`     | προσωρινός     | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση                 |
