# Εισαγωγή

## Αριθμοί

Το ABAP έχει αρκετούς αριθμητικούς τύπους. Σε αυτή την άσκηση, θα χρησιμοποιήσεις δύο από αυτούς:

- `i` για ακέραιες τιμές, όπως ένας αριθμός ημερών.
- `p` για συσκευασμένες δεκαδικές τιμές, όπως μια ωριαία χρέωση ή μια έκπτωση.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Οι συσκευασμένοι αριθμοί ορίζουν το μέγιστο μήκος τους και τον αριθμό των δεκαδικών ψηφίων τους.
Τα δεκαδικά κυριολεκτικά γράφονται συνήθως ως τιμές κειμένου και μετατρέπονται στον ζητούμενο δεκαδικό τύπο από τον μεταγλωττιστή ή με το `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

### Στρογγυλοποίηση

Το ABAP παρέχει ενσωματωμένες αριθμητικές συναρτήσεις για στρογγυλοποίηση.
Η συνάρτηση `floor` στρογγυλοποιεί προς τα κάτω στον πλησιέστερο ακέραιο αριθμό, και η `ceil` στρογγυλοποιεί προς τα πάνω στον πλησιέστερο ακέραιο αριθμό.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```

## Αριθμητικοί τελεστές

Το ABAP υποστηρίζει αριθμητικούς τελεστές για υπολογισμούς με αριθμητικές τιμές.

```abap
DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = rate_per_hour * 8.
```

Οι βασικοί τελεστές είναι:

- `+` για πρόσθεση.
- `-` για αφαίρεση.
- `*` για πολλαπλασιασμό.
- `/` για διαίρεση.
- `MOD` για το υπόλοιπο μιας ακέραιης διαίρεσης.

```abap
DATA remaining_days TYPE i.
remaining_days = num_days MOD 22.
```

Το ABAP υπολογίζει τον πολλαπλασιασμό και τη διαίρεση πριν από την πρόσθεση και την αφαίρεση.
Οι παρενθέσεις μπορούν να χρησιμοποιηθούν για να γίνει σαφής η επιθυμητή σειρά.

```abap
DATA discounted_rate TYPE p LENGTH 8 DECIMALS 2.
discounted_rate = monthly_rate * ( 1 - discount ).
```
