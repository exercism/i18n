# Προσθήκη οδηγιών

## Υποδείξεις

- [Σχεδιασμός με τύπους](http://fsharpforfunandprofit.com/series/designing-with-types.html) Για να καταλήξεις σε μια καθαρή λύση που διαβάζεται εύκολα, φρόντισε να διαλέξεις τους σωστούς τύπους που θα αναπαραστήσουν τα διάφορα μέρη του προβλήματος (σκέψου τα χρώματα, τις τιμές, τα φύλλα κ.λπ.)
