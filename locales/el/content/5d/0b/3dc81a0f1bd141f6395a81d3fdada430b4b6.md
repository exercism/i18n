# Υποδείξεις

## Γενικά

- Η κλάση `string` έχει πολλές χρήσιμες [ενσωματωμένες μεθόδους][methods].

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

- Υπάρχουν [αρκετές μέθοδοι][index-of] για να βρεις τη θέση στην οποία εμφανίζεται κάποιο κείμενο μέσα σε μια `string`.
- Η αφαίρεση των κενών διαστημάτων είναι [ενσωματωμένη][trim].

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

- Μια `string` μπορεί να μετατραπεί σε πεζά χρησιμοποιώντας μια [ενσωματωμένη μέθοδο][to-lower].

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

- Υπάρχει ένας [ενσωματωμένος τελεστής][plus-operator] για τη συνένωση συμβολοσειρών.
