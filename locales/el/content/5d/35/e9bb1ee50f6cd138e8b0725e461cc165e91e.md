# Υποδείξεις

## 1. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

- Η σημερινή καταμέτρηση είναι η τελευταία καταχώρηση.

## 2. Αύξησε τη σημερινή καταμέτρηση

- Τροποποίησε την τελευταία καταχώρηση επιτόπου.
- Η Julia έχει τον τελεστή `+=` αλλά όχι τον `++`.
- Πρέπει να επιστρέψεις το τροποποιημένο διάνυσμα.

## 3. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

- Ο τελεστής `.==` ελέγχει την ισότητα στοιχείο προς στοιχείο.
- Η συνάρτηση `any()` μπορεί να είναι χρήσιμη.


## 4. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν για τις πρώτες ημέρες

- Χρησιμοποίησε θέσεις από ένα διάστημα για να πάρεις ένα υποσύνολο ενός διανύσματος.
- Η συνάρτηση `sum()` δέχεται ως είσοδο ένα διάνυσμα και επιστρέφει έναν μόνο αριθμό.


## 5. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

- Η λογική ευρετηρίαση θα δώσει ένα υποσύνολο ενός διανύσματος, με καταχωρήσεις που ικανοποιούν τη δεδομένη συνθήκη.
- Η συνθήκη πρέπει να λειτουργεί στοιχείο προς στοιχείο.
- Βρες το μήκος ενός διανύσματος με τη `length()`.


## 6. Υπολόγισε τους μέσους όρους ανά ημέρα της εβδομάδας

- Οι αριθμητικοί (ενθετικοί) τελεστές μπορούν να έχουν μια τελεία μπροστά από τον τελεστή για να μετατραπούν σε λειτουργία στοιχείο προς στοιχείο.
