# Εισαγωγή

## Χρόνος

Το module `Time` χρησιμοποιείται για την εμφάνιση ημερομηνιών και ωρών σε μορφή που διαβάζει ο άνθρωπος.
Αν και είναι τεχνικά δυνατό να χειριστείς χρόνους με το `Time`, υπάρχουν πακέτα της κοινότητας του Elm που ταιριάζουν πολύ καλύτερα σε αυτή τη δουλειά, όπως το [`justinmimbs/date`][date] ή το [`CoderDennis/elm-time-format`][elm-time-format].

### Posix

Οι χρόνοι αναπαρίστανται από τον αδιαφανή τύπο `Posix`, ο οποίος περιτυλίγει τον χρόνο εποχής Unix, δηλαδή τον αριθμό των χιλιοστών του δευτερολέπτου που έχουν περάσει από την 1η Ιανουαρίου 1970 τα μεσάνυχτα UTC.
Ένα `Posix` είναι μια μονοσήμαντη τιμή που δεν αλλάζει από ζώνη ώρας σε ζώνη ώρας, γι' αυτό και είναι καλή επιλογή για να κρατάς τον χρόνο.
Σε μια εφαρμογή Elm, οι χρόνοι `Posix` συνήθως παρέχονται από εξωτερικές πηγές, όπως ο browser.

Μπορείς να μετατρέψεις ένα `Posix` σε έναν αριθμό από χιλιοστά του δευτερολέπτου και το αντίστροφο με τις παρακάτω συναρτήσεις:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### Ζώνες ώρας

Στην καθημερινή μας ζωή, συνήθως δε διαβάζουμε `Posix` και προτιμάμε την τοπική ώρα, η οποία εξαρτάται από τη θέση μας στη Γη και από τους τοπικούς κανόνες θερινής ώρας.
Στο Elm, αυτή η πληροφορία κωδικοποιείται στον αδιαφανή τύπο `Zone`, ο οποίος συνήθως παρέχεται από τον browser.

Υπάρχει μια ειδική `Zone` που είναι πάντα προσβάσιμη:

```elm
utc : Zone
```

### Χρόνοι σε ανθρώπινη μορφή

Με ένα `Posix` και μια `Zone`, έχουμε αρκετές πληροφορίες για να δείξουμε την τοπική ώρα σε όποιο επίπεδο λεπτομέρειας θέλουμε.
Ακολουθεί μια λίστα με τις συναρτήσεις που μπορούν να χρησιμοποιηθούν γι' αυτό:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Θα έχεις προσέξει δύο ακόμη προσαρμοσμένους τύπους του `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Μένει στους χρήστες να μετατρέψουν αυτούς τους προσαρμοσμένους τύπους σε τιμές με μορφή που διαβάζει ο άνθρωπος.
