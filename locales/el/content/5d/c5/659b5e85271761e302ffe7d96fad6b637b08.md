# Εισαγωγή

Μερικές φορές, όταν μια συνάρτηση δέχεται πολλά ορίσματα, μπορεί να είναι δύσκολο να θυμάσαι τη σειρά με την οποία πρέπει να δοθούν. Για να βοηθήσει την αναγνωσιμότητα, η Gleam επιτρέπει να επισημαίνονται τα ορίσματα με ένα όνομα.

Για να επισημάνεις ένα όρισμα, γράψε το όνομα της ετικέτας πριν από το όνομα του ορίσματος, χωρισμένα με ένα κενό.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Όταν καλείς μια συνάρτηση με επισημασμένα ορίσματα, τα ορίσματα μπορούν να δοθούν με οποιαδήποτε σειρά. Καθεμία από αυτές τις κλήσεις στη `replace` είναι ισοδύναμη:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Οι ετικέτες είναι πάντα προαιρετικές. Ακόμα κι αν μια συνάρτηση έχει επισημασμένα ορίσματα, μπορείς ακόμα να την καλέσεις χωρίς ετικέτες.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
