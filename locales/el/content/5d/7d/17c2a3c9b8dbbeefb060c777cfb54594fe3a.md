# Χρήσιμοι πόροι για τη Raku

[Η ιστοσελίδα Raku](https://raku.org/) έχει μια σελίδα [εκμάθησης](https://raku.org/learn) και μια σελίδα [εργαλείων](https://raku.org/tools) με ποικιλία πληροφοριών για τη γλώσσα, όπως οδηγούς για αρχάριους, τεκμηρίωση και screencasts.

Η [τεκμηρίωση](https://docs.raku.org/) περιέχει [εισαγωγικό υλικό](https://docs.raku.org/introduction), μαθήματα και οδηγούς μετάβασης για χρήστες που είναι εξοικειωμένοι με άλλες γλώσσες, και πολλά άλλα.
