# Εισαγωγή

Μια παράμετρος μεθόδου μπορεί να γίνει προαιρετική αν της αναθέσεις μια προεπιλεγμένη τιμή. Όταν καλείς μια μέθοδο με προαιρετικές παραμέτρους, δεν χρειάζεται να περάσεις τιμή γι' αυτές. Αν δεν περαστεί τιμή για μια προαιρετική παράμετρο, θα χρησιμοποιηθεί η προεπιλεγμένη τιμή της.

Οι προαιρετικές παράμετροι _πρέπει_ να βρίσκονται στο τέλος της λίστας παραμέτρων. Δεν μπορούν να ακολουθούνται από υποχρεωτικές παραμέτρους.

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
