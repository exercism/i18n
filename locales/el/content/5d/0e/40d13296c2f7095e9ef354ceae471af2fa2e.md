# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος    | Περιγραφή                              |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | φράση που τερματίζεται με null        |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος που τερματίζεται με null |
| `$t0-9`  | προσωρινός    | οποιοσδήποτε     | για προσωρινή αποθήκευση         |
