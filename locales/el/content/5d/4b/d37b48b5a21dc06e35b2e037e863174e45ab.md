# Εισαγωγή

Η σύνταξη αποδόμησης πίνακα της JavaScript είναι ένας σύντομος τρόπος για να εξάγεις τιμές από έναν πίνακα και να τις εκχωρήσεις σε διακριτές μεταβλητές.

Σε αυτό το παράδειγμα, κάθε τιμή του πίνακα `numberOfMoons` εκχωρείται στον αντίστοιχο πλανήτη της:

```javascript
const numberOfMoons = [0, 2, 14];
const [venus, mars, neptune] = numberOfMoons;

neptune;
// => 14
```
