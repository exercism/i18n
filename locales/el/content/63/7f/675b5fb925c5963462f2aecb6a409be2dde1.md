# Οδηγίες

Σε αυτή την άσκηση, θα βοηθήσεις έναν κρυπτογράφο να διαχειρίζεται και να επαληθεύει ένα ασφαλές σύστημα επικοινωνίας.
Το σύστημα βασίζεται σε μεγάλο βαθμό σε στοιχεία σώματος, συγκεκριμένα στον τύπο `felt252` της Cairo, ώστε να διασφαλίζεται ότι όλες οι αριθμητικές πράξεις παραμένουν μέσα σε ένα καθορισμένο εύρος.

## 1. Υπολόγισε το άθροισμα δύο μηνυμάτων

Δύο κρυπτογραφημένα μηνύματα, το καθένα από τα οποία παριστάνεται ως `felt252`, πρέπει να προστεθούν μεταξύ τους για να δημιουργηθεί ένα ενιαίο μήνυμα.
Ωστόσο, λόγω της κρυπτογράφησης, κάθε αποτέλεσμα που ξεπερνά τη μέγιστη τιμή $P - 1$ πρέπει να αναδιπλώνεται χρησιμοποιώντας το modulo $P$.

Υλοποίησε μια συνάρτηση που δέχεται δύο τιμές `felt252` και επιστρέφει το άθροισμά τους, διασφαλίζοντας ότι το αποτέλεσμα παραμένει μέσα στο έγκυρο εύρος:

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **Σημείωση:** Η τιμή επιστροφής πρέπει να είναι `felt252`.

## 2. Υπολόγισε τη διαφορά δύο μηνυμάτων

Μερικές φορές, τα μηνύματα πρέπει να αφαιρεθούν για να ανακτηθούν τα αρχικά δεδομένα.
Αν το αποτέλεσμα της αφαίρεσης είναι αρνητικό, το σύστημα προσαρμόζει αυτόματα το αποτέλεσμα προσθέτοντας $P$, ώστε να το επαναφέρει μέσα στο εύρος μιας έγκυρης τιμής `felt252`.

Υλοποίησε μια συνάρτηση που δέχεται δύο τιμές `felt252` και επιστρέφει τη διαφορά τους, διασφαλίζοντας ότι το αποτέλεσμα παραμένει μέσα στο έγκυρο εύρος:

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **Σημείωση:** Η τιμή επιστροφής πρέπει να είναι `felt252`.

## 3. Υπολόγισε ένα έγκυρο γινόμενο δύο μηνυμάτων

Για να διασφαλίζεται η ακεραιότητα των κρυπτογραφημένων δεδομένων, το κρυπτογραφικό σύστημα συχνά πολλαπλασιάζει δύο μηνύματα (`felt252`) για να βεβαιωθεί ότι το γινόμενό τους παραμένει μέσα σε ένα έγκυρο εύρος.
Το αποτέλεσμα πρέπει να υπολογίζεται με modulo $P$, ώστε να παραμένει μέσα στο έγκυρο εύρος.

Υλοποίησε μια συνάρτηση που δέχεται δύο τιμές `felt252` και επιστρέφει το γινόμενό τους, διασφαλίζοντας ότι το αποτέλεσμα παραμένει μέσα στο έγκυρο εύρος:

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **Σημείωση:** Η τιμή επιστροφής πρέπει να είναι `felt252`.
