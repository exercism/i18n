# Οδηγίες

Κρατάς έναν οδηγό πεδίου: έναν χάρτη που αντιστοιχίζει το όνομα ενός ζώου στον βιότοπο όπου ζει.

Και οι πέντε εργασίες μπαίνουν στην κλάση `FIELD_GUIDE`.

## 1. Είναι μέσα στον οδηγό;

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. Πού ζει;

Επέστρεψε τον βιότοπο που έχει καταγραφεί για ένα ζώο. Αν ο οδηγός δεν το έχει ακούσει ποτέ, επέστρεψε `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Πρόσθεσε μια καταγραφή

Επέστρεψε τον οδηγό με ένα ακόμη ζώο μέσα του. Αν ένα ζώο είναι ήδη καταγεγραμμένο, ο βιότοπός του αντικαθίσταται.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Ό,τι επιστρέψει αυτό είναι ο οδηγός που θα χρησιμοποιήσεις από εκεί και πέρα. Η προσθήκη σε έναν οδηγό που είναι εντελώς κενός λειτουργεί και δίνει έναν οδηγό με ένα ζώο μέσα του.

## 4. Πόσα ζώα;

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. Ποιοι βιότοποι;

Επέστρεψε το σύνολο των βιοτόπων που αναφέρει ο οδηγός. Πολλά ζώα μπορεί να μοιράζονται έναν βιότοπο, και αυτός πρέπει να εμφανίζεται μία φορά.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
