# Booleans (λογικές τιμές)

Κάποιες ερωτήσεις έχουν μόνο δύο απαντήσεις: ναι ή όχι. Στη Sather, ο τύπος για μια τέτοια απάντηση είναι `BOOL`, και οι δύο απαντήσεις γράφονται `true` και `false`.

```sather
   ready : BOOL is
      return true;
   end;
```

## Σύγκριση

Η σύγκριση δύο αριθμών δίνει ένα `BOOL`.

| Τελεστής | Ρωτάει |
| --- | --- |
| `=` | είναι ίσοι; |
| `/=` | είναι διαφορετικοί; |
| `<` | ο αριστερός είναι μικρότερος; |
| `<=` | μικρότερος, ή ίσος; |
| `>` | ο αριστερός είναι μεγαλύτερος; |
| `>=` | μεγαλύτερος, ή ίσος; |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

Πρόσεξε ότι το `=` θέτει μια ερώτηση. Η τοποθέτηση μιας τιμής *μέσα* σε κάτι είναι το `:=`, που το έχεις δει ήδη, και τα δύο δεν είναι το ίδιο πράγμα.

## Συνδυασμός

Τρεις τελεστές χτίζουν μεγαλύτερες ερωτήσεις από μικρότερες.

Το `and` είναι αληθές όταν **και οι δύο** πλευρές είναι αληθείς.

```sather
harness_on and rope_checked
```

Το `or` είναι αληθές όταν **τουλάχιστον μία** πλευρά είναι αληθής, ή και οι δύο.

```sather
mat_below or net_below
```

Το `~` αντιστρέφει μια απάντηση: μετατρέπει το αληθές σε ψευδές και το ψευδές σε αληθές.

```sather
~ready       -- true exactly when ready is false
```

Τα `and` και `or` μπαίνουν ανάμεσα σε δύο απαντήσεις, ενώ το `~` μπαίνει μπροστά από μία.
