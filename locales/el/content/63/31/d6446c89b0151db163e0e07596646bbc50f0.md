# Πόροι

## Πού να βρεις βοήθεια

1. Το [The Emacs Wiki](http://emacswiki.org/) είναι ανεκτίμητο. Πέρασε πολύ χρόνο εδώ.
2. Το [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) είναι το επίσημο εγχειρίδιο του GNU Emacs.
3. IRC - υπάρχουν κανάλια στο [Libera.Chat](https://libera.chat/) για `#emacs`, `#org-mode` και πολλά πακέτα Emacs, με πολύ εξυπηρετικό κόσμο. Και με το Emacs, το IRC βρίσκεται μόλις ένα `M-x erc` μακριά.
4. Matrix - στο [Matrix](https://matrix.org/) υπάρχουν δωμάτια για [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) και άλλα πακέτα Emacs.
   Μπορείς να [μπεις στον χώρο του Emacs στο Matrix](https://matrix.to/#/#emacs-space:matrix.org) για να πάρεις μια εικόνα των διαθέσιμων καναλιών.
   Για να μπεις στο Matrix μέσα από το Emacs, μπορείς να χρησιμοποιήσεις το πακέτο [Ement.el](https://github.com/alphapapa/ement.el).
5. Στο [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) και στο [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) μπορείς να αναζητήσεις το πρόβλημά σου και να δεις αν έχει ήδη απαντηθεί. Μπορείς επίσης να κάνεις και να απαντήσεις σε ερωτήσεις.
