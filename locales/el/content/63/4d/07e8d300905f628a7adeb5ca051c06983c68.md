# Οδηγίες

Ο φίλος σου μόλις σου έστειλε ένα μήνυμα με ένα σημαντικό μυστικό. Μη θέλοντας να κάνει εύκολο για τους άλλους να το διαβάσουν, το μήνυμα κρυπτογραφήθηκε πραγματοποιώντας μια σειρά από χειρισμούς bit. Θα χρειαστεί να γράψεις τις λέξεις που θα βοηθήσουν στην αποκρυπτογράφηση του μηνύματος.

## 1. Μετατόπισε τα bit πίσω

Το πρώτο βήμα για την αποκρυπτογράφηση του μηνύματος είναι να αναιρέσεις τη μετατόπιση της διαδικασίας κρυπτογράφησης, μετατοπίζοντας τα bit πίσω προς τα δεξιά. Τα επόμενα βήματα προϋποθέτουν ότι από τα αριστερά εισάγονται μηδενικά.

Όρισε τη `shift-back` που παίρνει μια τιμή 32 bit και ένα πλήθος, και επιστρέφει την τιμή μετατοπισμένη δεξιά κατά αυτό το πλήθος, με συμπλήρωση μηδενικών.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Θέσε κάποια bit

Έπειτα, υπάρχουν κάποια bit που πρέπει να τεθούν σε 1.

Όρισε τη `set-bits` που παίρνει μια τιμή και μια μάσκα. Κάθε bit του `value` όπου το αντίστοιχο bit του `mask` είναι 1 θα πρέπει να τίθεται σε 1· κάθε άλλο bit μένει αμετάβλητο.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Αντιστρέψε συγκεκριμένα bit

Κάποια bit αντιστρέφονται κατά την κρυπτογράφηση. Θα χρειαστεί να αντιστραφούν ξανά για να αποκρυπτογραφηθεί το μήνυμα.

Όρισε τη `flip-bits` που παίρνει μια τιμή και μια μάσκα. Κάθε bit του `value` όπου το αντίστοιχο bit του `mask` είναι 1 θα πρέπει να αντιστρέφεται· κάθε άλλο bit μένει αμετάβλητο.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Μηδένισε συγκεκριμένα bit

Τέλος, υπάρχουν και συγκεκριμένα bit που αποκρυπτογραφούνται πάντα σε 0.

Όρισε τη `clear-bits` που παίρνει μια τιμή και μια μάσκα. Κάθε bit του `value` όπου το αντίστοιχο bit του `mask` είναι 1 θα πρέπει να μηδενίζεται· κάθε άλλο bit μένει αμετάβλητο.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
