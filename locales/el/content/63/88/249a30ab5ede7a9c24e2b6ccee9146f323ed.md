# Εισαγωγή

Διαθέσιμες από την `PHP 8.0.0`, οι **Δηλώσεις τύπων ένωσης** δέχονται τιμές πολλαπλών διαφορετικών τύπων, αντί για έναν μόνο τύπο. Οι ορισμοί τύπων ένωσης γίνονται με τη χρήση της κάθετης γραμμής (`|`) για τον διαχωρισμό τύπων.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

Η PHP θα πετάξει ένα `TypeError` σε αυστηρή λειτουργία αν οι εισερχόμενες παράμετροι δεν είναι ούτε `float` ούτε `int`. Σε μη αυστηρή λειτουργία, η PHP θα πετάξει ένα σφάλμα τύπου αν οι εισερχόμενες παράμετροι δε μπορούν να εξαναγκαστούν σε `float` ή `int`.

Παρομοίως, αν η συνάρτηση δεν επιστρέψει έναν από τους δηλωμένους τύπους, η PHP θα πετάξει ένα `TypeError` κατά την εκτέλεση.
