# Οδηγίες

Σε αυτή την άσκηση, πρέπει να μεταφράσεις μερικούς κανόνες από το κλασικό παιχνίδι Pac-Man σε συναρτήσεις Haskell.

Έχεις τέσσερις κανόνες να μεταφράσεις, όλοι σχετικοί με τις καταστάσεις του παιχνιδιού.

> Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, συγκεντρώσου μόνο στο να συνδυάσεις τα ορίσματα ώστε να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `eatsGhost` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή `Bool` όταν ο Pac-Man μπορεί να φάει το φάντασμα.
Η συνάρτηση θα πρέπει να επιστρέφει `True` μόνο όταν ο Pac-Man έχει ενεργό power pellet και αγγίζει ένα φάντασμα.

```haskell
eatsGhost False True
-- -> False
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `scores` που παίρνει δύο ορίσματα (_αν ο Pac-Man αγγίζει ένα power pellet_ και _αν ο Pac-Man αγγίζει μια κουκκίδα_) και επιστρέφει μια τιμή `Bool` αν ο Pac-Man σκόραρε.
Η συνάρτηση θα πρέπει να επιστρέφει `True` όταν ο Pac-Man αγγίζει ένα power pellet ή μια κουκκίδα.

```haskell
scores True True
-- -> True
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `loses` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή `Bool` αν ο Pac-Man χάνει.
Η συνάρτηση θα πρέπει να επιστρέφει `True` όταν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό power pellet.

```haskell
loses False True
-- -> True
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `wins` που παίρνει τρία ορίσματα (_αν ο Pac-Man έχει φάει όλες τις κουκκίδες_, _αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή `Bool` αν ο Pac-Man κερδίζει.
Η συνάρτηση θα πρέπει να επιστρέφει `True` όταν ο Pac-Man έχει φάει όλες τις κουκκίδες _και_ δεν έχει χάσει με βάση τα ορίσματα που ορίστηκαν στο μέρος 3.

```haskell
wins False True False
-- -> False
```
