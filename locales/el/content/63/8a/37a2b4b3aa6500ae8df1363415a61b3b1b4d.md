# Οδηγίες

Τα τραμ της Μελβούρνης χρεώνουν ανά ζώνη και το κέντρο της πόλης είναι δωρεάν. Γράφεις τους κανόνες κομίστρου για το μηχάνημα έκδοσης εισιτηρίων. Όλα τα κόμιστρα είναι σε σεντ.

Και οι τέσσερις εργασίες μπαίνουν στην κλάση `TRAM_FARES`.

## 1. Το κόμιστρο για μια ζώνη

Η ζώνη 0 είναι η δωρεάν ζώνη των τραμ και δεν κοστίζει τίποτα. Η ζώνη 1 είναι 550. Η ζώνη 2 είναι 370. Οποιοσδήποτε άλλος αριθμός δεν είναι ζώνη τραμ καθόλου και δεν κοστίζει τίποτα.

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. Τι είδους εισιτήριο;

Τα εισιτήρια φέρουν ένα γράμμα. Το `'f'` είναι πλήρες κόμιστρο. Τόσο το `'c'` όσο και το `'s'` είναι μειωμένα κόμιστρα: το ένα για παιδιά, το άλλο για φοιτητές. Το `'x'` είναι δωρεάν κάρτα. Οτιδήποτε άλλο είναι άγνωστο.

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

Οι τέσσερις απαντήσεις είναι `"Full fare"`, `"Concession"`, `"Free pass"` και `"Unknown"`.

## 3. Τι είδους μέρα;

Τα `"Sat"` και `"Sun"` είναι σαββατοκύριακο. Τα `"Mon"` έως `"Fri"` είναι καθημερινή. Οτιδήποτε άλλο είναι άγνωστο.

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

Οι τρεις απαντήσεις είναι `"Weekend"`, `"Weekday"` και `"Unknown"`.

## 4. Το ημερήσιο όριο

Όσα τραμ κι αν πάρεις, δεν πληρώνεις ποτέ περισσότερο από το όριο για εκείνη την ημέρα: 1100 τις καθημερινές και 700 το σαββατοκύριακο. Μια μέρα που δεν αναγνωρίζει κανείς δεν έχει όριο, που είναι μηδέν.

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
