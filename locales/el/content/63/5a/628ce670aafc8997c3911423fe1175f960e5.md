# Οδηγίες

Η κοπέλα του Lucian είναι καθ' οδόν για το σπίτι και εκείνος δεν έχει μαγειρέψει το δείπνο της επετείου τους!

Σε αυτή την άσκηση, θα γράψεις λίγο κώδικα για να βοηθήσεις τον Lucian να μαγειρέψει εξαίσια λαζάνια από το αγαπημένο του βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που χρειάζεται για το μαγείρεμα των λαζανιών.

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο σε λεπτά

Όρισε τη μέθοδο `Lasagna.ExpectedMinutesInOven()` που δεν παίρνει καμία παράμετρο και επιστρέφει πόσα λεπτά πρέπει να είναι τα λαζάνια στο φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο σε λεπτά είναι 40:

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στο φούρνο σε λεπτά

Όρισε τη μέθοδο `Lasagna.RemainingMinutesInOven()` που παίρνει ως παράμετρο τα πραγματικά λεπτά που τα λαζάνια βρίσκονται στο φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμη να παραμείνουν τα λαζάνια στο φούρνο, με βάση τον αναμενόμενο χρόνο στο φούρνο σε λεπτά από την προηγούμενη εργασία.

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη μέθοδο `Lasagna.PreparationTimeInMinutes()` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για την προετοιμασία των λαζανιών, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να την ετοιμάσεις.

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη μέθοδο `Lasagna.ElapsedTimeInMinutes()` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια, και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στο φούρνο. Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα των λαζανιών, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στο φούρνο αυτή τη στιγμή.

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
