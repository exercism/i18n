# Εισαγωγή

Ο τύπος `Result` δίνει τη δυνατότητα σε μια συνάρτηση να επιστρέφει μία μόνο τιμή που δηλώνει όλα τα παρακάτω:
- Αν η πράξη πέτυχε ή απέτυχε
- Σε περίπτωση επιτυχίας, την τιμή που προκύπτει από την πράξη
- Σε περίπτωση αποτυχίας, τον λόγο της αποτυχίας

## Χρήση

Ο τύπος `Result` είναι ένας γενικός τύπος που περιέχει δύο υποκείμενους τύπους:
- Τον τύπο της τιμής που προκύπτει από μια επιτυχημένη πράξη
- Τον τύπο του σφάλματος σε περίπτωση αποτυχίας

Ο τύπος `Result` είναι επίσης μια [discriminated union][discriminated-union] με τις εξής δυνατές περιπτώσεις:
* `Ok <value>` που αντιπροσωπεύει ένα επιτυχημένο αποτέλεσμα
* `Error <reason>` που αντιπροσωπεύει μια αποτυχία

Η παρακάτω συνάρτηση δείχνει πώς να δημιουργήσεις μια τιμή `Result`:

```fsharp
let validateName (name: string) : Result<string, string> = 
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

Σε αυτό το παράδειγμα, η τιμή `Ok` είναι μια συμβολοσειρά (το όνομα που δόθηκε), και η τιμή `Error` είναι επίσης μια συμβολοσειρά (η αιτία του σφάλματος, σε μορφή κατανοητή από τον άνθρωπο).

## Διαβάζοντας το περιεχόμενο μιας τιμής `Result`

Θεώρησε τον παρακάτω ορισμό τύπου και την υπογραφή της συνάρτησης:

```
type FileOpenError = 
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

Ο κώδικας που καλεί τη συνάρτηση `openFile` μπορεί να χρησιμοποιήσει αντιστοίχιση προτύπων για να χειριστεί τις περιπτώσεις επιτυχίας και αποτυχίας, όπως στο παρακάτω παράδειγμα:

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
