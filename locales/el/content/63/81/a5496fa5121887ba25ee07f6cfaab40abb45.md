# Προσθήκη οδηγιών

Οι φακοί δεν χρησιμοποιούνται πολύ στη Roc, επειδή η σύνταξη ενημέρωσης καταγραφών καλύπτει ωραία τις περισσότερες περιπτώσεις χρήσης. Για παράδειγμα, σκέψου αυτή την εμφωλευμένη καταγραφή:

```roc
bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
```

Ας κάνουμε τώρα ένα κούρεμα στον Bob:

```roc
new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
```

Δεν χρειάζονται φακοί! Παρ' όλα αυτά, αν και οι φακοί είναι σπάνιοι στη Roc, είναι συνηθισμένοι σε άλλες γλώσσες όπως η Haskell και η Scala, οπότε ίσως αναρωτιέσαι πώς μπορεί κανείς να τους υλοποιήσει στη Roc. Είναι επίσης ένας καλός τρόπος να εξασκηθείς σε μερικές προχωρημένες δυνατότητες της Roc, όπως οι παραμετροποιημένοι τύποι και οι καταγραφές που περιέχουν συναρτήσεις. Πράγματι, να ένας τρόπος να αναπαραστήσεις έναν φακό στη Roc:

```roc
Lens(whole, part) := {
	get : whole -> part,
	set : whole, part -> whole,
}
```

Πρόκειται για έναν παραμετροποιημένο τύπο: το `whole` και το `part` μπορούν να είναι οποιοιδήποτε τύποι. Το `whole` είναι συνήθως μια καταγραφή, ενώ το `part` μπορεί να είναι οποιοσδήποτε τύπος πεδίου. Το πεδίο `get` περιέχει μια συνάρτηση που επιστρέφει ένα συγκεκριμένο `part` του δοσμένου `whole`, ενώ το πεδίο `set` περιέχει μια συνάρτηση που επιστρέφει ένα αντίγραφο του δοσμένου `whole`, με ένα συγκεκριμένο `part` να έχει αντικατασταθεί από το δοσμένο `part`.

Για παράδειγμα, να ένας φακός για να πάρεις ή να θέσεις τα μαλλιά ενός ατόμου:

```roc
hair_lens = {
	get: |person| person.hair,
	set: |person, hair| { ..person, hair },
}
```

Μπορούμε να χρησιμοποιήσουμε αυτόν τον φακό για να εστιάσουμε στα μαλλιά του Bob, έτσι:

```roc
bob_hair = bob |> hair_lens.get
```

Και μπορούμε να αλλάξουμε τα μαλλιά του έτσι:

```roc
new_hair = { ..bob.hair, length: Short }
new_bob = bob |> (hair_lens.set)(new_hair)
```

Σημείωση: οι παρενθέσεις γύρω από το `hair_lens.set` είναι απαραίτητες: χωρίς αυτές, η Roc θα έψαχνε για μια συνάρτηση με το όνομα `set` στον τύπο του `hair_lens`.

Οι φακοί γίνονται ιδιαίτερα χρήσιμοι όταν αρχίζεις να τους συνθέτεις, επιτρέποντάς σου να παίρνεις και να θέτεις βαθιά εμφωλευμένα μέρη. Αυτό μπορεί να γίνει υλοποιώντας μια συνάρτηση σαν αυτή:

```roc
compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
```

Μόλις υλοποιηθεί αυτή η συνάρτηση, μπορείς να τη χρησιμοποιήσεις για να δημιουργήσεις έναν φακό μήκους μαλλιών σαν αυτόν:

```roc
length_lens = {
	get: |hair| hair.length,
	set: |hair, length| { ..hair, length },
}
hair_length_lens = compose(hair_lens, length_lens)

```

Τώρα μπορείς να κάνεις στον Bob άλλο ένα κούρεμα:

```roc
set_hair_length = hair_length_lens.set
new_bob = bob |> set_hair_length(Short)
```

Μπορεί επίσης να θέλεις να υλοποιήσεις μια συνάρτηση που σου επιτρέπει να εφαρμόζεις οποιονδήποτε μετασχηματισμό σε ένα εμφωλευμένο μέρος:

```roc
over : Lens(whole, part), whole, (part -> part) -> whole
```

Μόλις την υλοποιήσεις, μπορείς να χρησιμοποιήσεις το `over` έτσι:

```roc
cut_hair = |current_length| match current_length {
	Long => Short
	Short => Bald
	Bald => Bald
}
new_bob = hair_length_lens |> over(bob, cut_hair)
```

Σε αυτή την άσκηση, τα τεστ θα ελέγξουν ότι ο κώδικάς σου μπορεί να τροποποιήσει διάφορα εμφωλευμένα μέρη της παρακάτω εμφωλευμένης καταγραφής:

```roc
test_person : Person
test_person = {
	name: { forenames: "Jane Joanna", surname: "Doe" },
	birth: {
		born_at: { street: "Longway", house_number: 1024, place: "Springfield", country: "United States" },
		born_on: { year: 1984, month: 4, day: 12 },
	},
	address: { street: "Shortlane", house_number: 2, place: "Fallmeadow", country: "Canada" },
}
```

Σου προτείνουμε να περάσεις πρώτα τα τεστ χρησιμοποιώντας τη σύνταξη ενημέρωσης καταγραφών της Roc και μετά να δοκιμάσεις αντ' αυτού να χρησιμοποιήσεις φακούς.
