# Υποδείξεις

## Γενικά

- Οι διευθύνσεις στη μνήμη σε x86-64 είναι αριθμοί 64 bit (8 byte).
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.

## 1. Πάρε την τιμή RGB ενός χρώματος

- Οι διευθύνσεις στη μνήμη σε x86-64 είναι αριθμοί 64 bit (8 byte).
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Για να προσπελάσεις τα περιεχόμενα που είναι αποθηκευμένα σε μια διεύθυνση στη μνήμη, πρέπει να κάνεις αποαναφορά σε αυτήν χρησιμοποιώντας `[]`.
- Οι ακέραιοι 32 bit (4 byte) επιστρέφονται στον `eax`.

## 2. Πρόσθεσε το βασικό χρώμα

- Οι διευθύνσεις στη μνήμη σε x86-64 είναι αριθμοί 64 bit (8 byte).
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Οι αρχικοποιημένες μεταβλητές ορίζονται στο _τμήμα .data_.
- Μια μεταβλητή πρέπει να δηλωθεί `global` για να είναι ορατή σε άλλα αρχεία πηγαίου κώδικα.
- Μπορείς να επαναχρησιμοποιήσεις τη συνάρτηση `get_color_value` που έχει ήδη υλοποιηθεί.

## 3. Όρισε σταθερές για τα πρωτεύοντα χρώματα

- Οι διευθύνσεις στη μνήμη σε x86-64 είναι αριθμοί 64 bit (8 byte).
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Οι αρχικοποιημένες σταθερές ορίζονται στο _τμήμα .rodata_.
- Μια σταθερά πρέπει να δηλωθεί `global` για να είναι ορατή σε άλλα αρχεία πηγαίου κώδικα.

## 4. Συνδύασε τα χρώματα

- Οι διευθύνσεις στη μνήμη σε x86-64 είναι αριθμοί 64 bit (8 byte).
- Θα πρέπει να χρησιμοποιήσεις το `rel` για να σχηματίσεις έγκυρες σχετικές διευθύνσεις στη μνήμη.
- Για να προσπελάσεις τα περιεχόμενα που είναι αποθηκευμένα σε μια διεύθυνση στη μνήμη, πρέπει να κάνεις αποαναφορά σε αυτήν χρησιμοποιώντας `[]`.
- Μια εξωτερική συνάρτηση ή δεδομένα πρέπει να δηλωθούν `extern` στο αντίστοιχο τμήμα.
- Μια εξωτερική συνάρτηση μπορεί να τροποποιήσει οποιονδήποτε από τους συνηθισμένους καταχωρητές που χρησιμοποιείς, οπότε πρέπει να αποθηκεύσεις τις μεταβλητές στη μνήμη πριν την καλέσεις.
- Η `combining_function` δέχεται την τιμή 32 bit (όχι τη διεύθυνση) για το βασικό χρώμα στον `rdi` και την τιμή 32 bit (όχι τη διεύθυνση) για το δευτερεύον χρώμα στον `rsi`.
