# Εισαγωγή

## Σχόλια

Στην Common Lisp μπορείς να γράψεις "σχόλια" που ο υπολογιστής αγνοεί.
Τα σχόλια μονής γραμμής αρχίζουν με μία ή περισσότερες άνω τελείες (`;`) και, περιστασιακά, μπορεί να δεις το εξής:

```lisp
(code...) ; => value
```

Όπου το σχόλιο χρησιμοποιείται για να δείξει ποια τιμή επιστρέφει η Common Lisp αφού εκτελέσει τον κώδικα σε αυτή τη γραμμή.

Είναι ιδιωματικό να χρησιμοποιείς μία μόνο άνω τελεία για ένα σύντομο σχόλιο στο τέλος μιας γραμμής, δύο για ένα μεγαλύτερο σχόλιο πάνω από ένα τμήμα κώδικα, τρεις για ένα μεγάλο σχόλιο που περιγράφει κάτι όπως μια συνάρτηση και τέσσερις για ένα σχόλιο όπως μια κεφαλίδα στην αρχή ενός αρχείου πηγαίου κώδικα.

## Cons

Όλα τα αντικείμενα της Common Lisp είναι είτε "άτομα" (απλές, αδιαίρετες τιμές) είτε "conses" (κατασκευασμένα από τη συνάρτηση κατασκευής "cons").
Ένα cons αποτελείται από δύο μέρη: το πρώτο στοιχείο και τα υπόλοιπα στοιχεία.
Για ιστορικούς λόγους, αυτά τα δύο μέρη ονομάζονται `car` και `cdr`.
Όταν αυτά τα cons αξιολογούνται ως κώδικας, το πρώτο στοιχείο (`car`) αντιπροσωπεύει τη συνάρτηση που καλείται, ενώ τα υπόλοιπα στοιχεία
(`cdr`) αντιπροσωπεύουν τα ορίσματα αυτής της συνάρτησης:

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## Εκφράσεις

Όλος ο κώδικας της Common Lisp αποτελείται από S-Expressions (Symbolic Expressions). Για συντομία ονομάζονται sexprs. Κάθε sexpr είναι είτε ένα άτομο είτε ένα cons. Όταν οι S-Expressions αξιολογούνται, επιστρέφουν αυτόματα κάποια τιμή που παίρνει τη θέση της έκφρασης. Όταν γράφεις τις δικές σου συναρτήσεις (χρησιμοποιώντας `defun`), η τελευταία τιμή μέσα στο σώμα της `defun` επιστρέφεται αυτόματα:

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## Σύμβολα

Τα σύμβολα στη Common Lisp είναι ειδικές τιμές που μπορούν να δείχνουν σε άλλες τιμές ή, στην περίπτωση των _λέξεων-κλειδιών_, στον εαυτό τους.
Όταν τα σύμβολα αξιολογούνται από τη Lisp, αντικαθίστανται με τις τιμές στις οποίες δείχνουν:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Σημείωσε ότι οι λέξεις-κλειδιά συμβολίζονται με μία άνω και κάτω τελεία στην αρχή (`:`).

Η παράθεση, δηλαδή η προσθήκη του `'` πριν από μια S-expression, λέει στη Lisp να μην αξιολογήσει αυτή την έκφραση.
Παραθέτοντας το `'foo` στο παράδειγμά μας με `defun`, αποφύγαμε η Lisp να προσπαθήσει να αναζητήσει (και να αποτύχει να βρει) αυτό στο οποίο υποτίθεται ότι έδειχνε το `FOO`, και αντ' αυτού να επιστρέψει την ίδια την τιμή `FOO`.
Αν το `FOO` δεν έχει οριστεί πουθενά στο πρόγραμμά μας:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Για την ώρα, μπορείς να το θεωρήσεις απλώς έναν τρόπο για να επιστρέφεις σύμβολα από μια συνάρτηση, αλλά θα ξαναδούμε την παράθεση και θα εξερευνήσουμε περαιτέρω τις επιπτώσεις της σε μελλοντικές ασκήσεις εννοιών.
