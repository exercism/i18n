# Οδηγίες

Κάνεις πεζοπορία στη Νέα Ζηλανδία και παίρνεις διόπτευσεις με μια πυξίδα. Μια
διόπτευση είναι ακέραιος αριθμός μοιρών και είναι μια τιμή: το στρίψιμο κατά 20
μοίρες δεν αλλάζει τη διόπτευση που πήρες, σου δίνει μια διαφορετική.

Γράψε μια `immutable class BEARING`. Ο σκελετός σου δίνει την κεφαλίδα της κλάσης
και το χαρακτηριστικό της.

## 1. Πάρε μια διόπτευση

Η `create` παίρνει έναν αριθμό μοιρών και δίνει μια διόπτευση. Οι μοίρες
κυμαίνονται από 0 έως 359, οπότε ό,τι είναι έξω γυρίζει πίσω: το 370 είναι 10 και
το -10 είναι 350.

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. Στρίψε

Η `turned` παίρνει έναν αριθμό μοιρών κατά τον οποίο θα στρίψεις και απαντά με τη
νέα διόπτευση. Το στρίψιμο κατά αρνητικό αριθμό στρίβει προς την άλλη κατεύθυνση.
Η διόπτευση στην οποία κλήθηκε μένει αμετάβλητη.

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. Σύγκρινε

Η `is_eq` παίρνει μια άλλη διόπτευση και απαντά αν είναι ίδιες. Μόλις υπάρξει, το
`=` δουλεύει με τις διόπτευσεις.

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. Ονόμασε το σημείο

Η `point` απαντά με το σημείο του ορίζοντα που βρίσκεται πιο κοντά στη διόπτευση,
ως ένα από τα `"N"`, `"NE"`, `"E"`, `"SE"`, `"S"`, `"SW"`, `"W"`, `"NW"`.

Κάθε σημείο καλύπτει 45 μοίρες, με κέντρο την ακριβή του διόπτευση: ο βορράς πάει
από 337.5, περνά από το 0 και φτάνει στο 22.5, ο βορειοανατολικός από 22.5 έως
67.5, και ούτω καθεξής. Επειδή εδώ οι διόπτευσεις είναι ακέραιοι αριθμοί, μια
διόπτευση 22 είναι `"N"` και η 23 είναι `"NE"`.

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. Γράψ' το

Η `str` απαντά με τις μοίρες και το σημείο, όπως `"90 degrees (E)"`.

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
