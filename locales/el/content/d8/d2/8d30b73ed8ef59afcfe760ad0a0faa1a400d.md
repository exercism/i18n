# Υποδείξεις

## 1. Προσανατόλισε το ρομπότ
- Η σειρά με την οποία εκτελείς τις πράξεις έχει σημασία.
- Υπάρχουν αρκετοί τρόποι για να μετατρέψεις ένα διάνυσμα από διανύσματα σε πίνακα.
- Μερικές ιδέες που μπορούν να βοηθήσουν στη δημιουργία του πίνακα: κατανοήσεις λιστών, βρόχοι for, [`hcat`][hcat-ref], [`reshape`][reshape-ref], [`stack`][stack-ref], κ.λπ...

## 2. Περιστρέψε το ρομπότ
- Δες την Εισαγωγή για το πώς να περιστρέψεις έναν πίνακα.
- Αρκεί απλός πολλαπλασιασμός πινάκων.

## 3. Έλεγξε αν ο προσανατολισμός είναι σωστός
- Θυμήσου, είναι η *δεύτερη* στήλη του πίνακα που δείχνει τον προσανατολισμό.
- Αυτό μπορεί να ελεγχθεί με ένα εσωτερικό γινόμενο.
- Μπορεί να σε βοηθήσει να κανονικοποιήσεις τα διανύσματα.
- Σε περίπτωση αποκλίσεων κινητής υποδιαστολής, ο προσανατολισμός χρειάζεται να είναι μόνο [κατά προσέγγιση][isapprox-ref] ίσος με περίπου `~1e-7`.
- Η παρακάτω ταυτότητα μπορεί να βοηθήσει: `x⋅y = ||x||*||y||cos(θ)` όπου [`||x|| = norm(x)`][norm-ref]

## 4. Συντεταγμένες του σώματος του ρομπότ
- Αυτό είναι πολύ απλό, αλλά οι πράξεις στοιχείο προς στοιχείο είναι σημαντικές.
- Θυμήσου ότι ο πίνακας προσανατολισμού μπορεί να ιδωθεί ως τρία διανύσματα θέσης από την αρχή των αξόνων.
