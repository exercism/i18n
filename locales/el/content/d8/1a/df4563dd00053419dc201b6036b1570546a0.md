# Εισαγωγή

Η Common Lisp παρέχει αρκετές διαφορετικές υπό συνθήκη εκφράσεις, με κύρια διαφορά τον αριθμό των κλάδων που υποστηρίζουν.

- Οι `when` και `unless` επιτρέπουν έναν μόνο κλάδο:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Το τμήμα μετά την έκφραση ελέγχου μπορεί να περιέχει περισσότερες από μία εκφράσεις.

- Το `if` παρέχει την κλασική δομή if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Σημείωσε ότι τόσο ο κλάδος then όσο και ο κλάδος else μπορούν να περιέχουν μόνο μία έκφραση.

- Το `cond` παρέχει έναν τρόπο να έχεις πολλούς κλάδους χωρίς εμφωλευμένες εκφράσεις `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Σημείωσε ότι δεν υπάρχει όριο στον αριθμό των εκφράσεων μετά την έκφραση ελέγχου.

- Το `case` παρέχει μια κλασική δομή τύπου "switch": ελέγχει μία μόνο τιμή απέναντι σε έναν αριθμό κλάδων:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Σημείωσε ότι, όπως και με το `cond`, δεν υπάρχει όριο στον αριθμό των εκφράσεων μετά την έκφραση ελέγχου.
