# Οδηγίες

Θα γράψεις κώδικα για να διαχειρίζεσαι έναν πίνακα βαθμολογίας για ένα παιχνίδι.
Ο πίνακας βαθμολογίας θα είναι ένα hash με το όνομα `%HighScoreBoard::Scores`.
Τα κλειδιά του hash θα είναι τα ονόματα των παικτών και οι τιμές θα είναι οι βαθμολογίες τους.

## 1. Όρισε τη βαθμολογία ενός παίκτη στο hash %Scores

Τροποποίησε την υπορουτίνα `HighScoreBoard::set_player_scores`, η οποία παίρνει ονόματα παικτών και βαθμολογίες ως ορίσματα, ώστε να ορίζει τις βαθμολογίες των παικτών στο hash `%HighScoreBoard::Scores`.

## 2. Πάρε τη βαθμολογία ενός παίκτη από το hash %Scores

Τροποποίησε την υπορουτίνα `HighScoreBoard::get_player_score`, η οποία παίρνει το όνομα ενός παίκτη ως όρισμα, ώστε να επιστρέφει τη βαθμολογία του παίκτη από το hash `%HighScoreBoard::Scores`.

## 3. Αύξησε τη βαθμολογία ενός παίκτη στο hash %Scores

Τροποποίησε την υπορουτίνα `HighScoreBoard::increase_player_scores`, η οποία παίρνει ονόματα παικτών και βαθμολογίες ως ορίσματα, ώστε να αυξάνει τις βαθμολογίες των παικτών στο hash `%HighScoreBoard::Scores` κατά τη βαθμολογία που δίνεται.

## 4. Ταξινόμησε τους παίκτες στο hash %Scores με βάση το όνομά τους

Τροποποίησε την υπορουτίνα `HighScoreBoard::sort_players_by_name` ώστε να επιστρέφει τα ονόματα των παικτών στο hash `%HighScoreBoard::Scores` ταξινομημένα με βάση το όνομά τους.

## 5. Ταξινόμησε τους παίκτες στο hash %Scores με βάση τη βαθμολογία τους

Τροποποίησε την υπορουτίνα `HighScoreBoard::sort_players_by_score` ώστε να επιστρέφει τα ονόματα των παικτών στο hash `%HighScoreBoard::Scores` ταξινομημένα με βάση τη βαθμολογία τους.

## 6. Διάγραψε έναν παίκτη από το hash %Scores

Τροποποίησε την υπορουτίνα `HighScoreBoard::delete_player`, η οποία παίρνει το όνομα ενός παίκτη ως όρισμα, ώστε να διαγράφει τον παίκτη από το hash `%HighScoreBoard::Scores`.
