# Οδηγίες

Σε αυτή την άσκηση παίζεις ένα παιχνίδι ρόλων όπου διαφορετικοί τύποι μαχητών μπορούν να μονομαχήσουν μεταξύ τους.
Το παιχνίδι έχει διαφορετικούς κανόνες για κάθε τύπο μαχητή.
Θα επικεντρωθούμε σε δύο συγκεκριμένους τύπους: Wizards και Warriors.

Για έναν Warrior, οι κανόνες είναι οι εξής:

- Ένας Warrior δεν είναι ποτέ ευάλωτος.
- Ένας Warrior προκαλεί `6` πόντους ζημιάς αν ο μαχητής που επιτίθεται δεν είναι ευάλωτος.
- Ένας Warrior προκαλεί `10` πόντους ζημιάς αν ο μαχητής που επιτίθεται είναι ευάλωτος.

Για έναν Wizard, οι κανόνες είναι οι εξής:

- Ένας Wizard μπορεί να προετοιμάσει ένα ξόρκι εκ των προτέρων.
- Ένας Wizard είναι ευάλωτος εκτός αν έχει προετοιμάσει ένα ξόρκι εκ των προτέρων.
- Ένας Wizard προκαλεί `12` πόντους ζημιάς αν έχει προετοιμάσει ένα ξόρκι εκ των προτέρων.
- Ένας Wizard προκαλεί `3` πόντους ζημιάς αν δεν έχει προετοιμάσει ένα ξόρκι εκ των προτέρων.

## 1. Δημιούργησε την κλάση Warrior

Δημιούργησε μια νέα κλάση που ονομάζεται `Warrior`.
Αυτή η κλάση θα πρέπει να κληρονομεί από την υπάρχουσα κλάση `Fighter`.

## 2. Περιέγραψε έναν Warrior

Ενημέρωσε την κλάση `Warrior` ώστε η μέθοδος `toString()` της να περιγράφει τι είδους μαχητής είναι.
Η μέθοδος θα πρέπει να επιστρέφει τη συμβολοσειρά `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Κάνε τους Warriors άτρωτους

Ενημέρωσε την κλάση `Warrior` ώστε η μέθοδος `isVulnerable()` της να επιστρέφει πάντα `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Υπολόγισε τους πόντους ζημιάς για έναν Warrior

Ενημέρωσε την κλάση `Warrior` ώστε η μέθοδος `getDamagePoints(Fighter)` της να υπολογίζει τη ζημιά που προκαλεί ένας Warrior σύμφωνα με τους παραπάνω κανόνες.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Δημιούργησε την κλάση Wizard

Δημιούργησε άλλη μια νέα κλάση που ονομάζεται `Wizard`.
Αυτή η κλάση θα πρέπει επίσης να κληρονομεί από την υπάρχουσα κλάση `Fighter`.

## 6. Περιέγραψε έναν Wizard

Ενημέρωσε την κλάση `Wizard` ώστε η μέθοδος `toString()` της να περιγράφει τι είδους μαχητής είναι.
Η μέθοδος θα πρέπει να επιστρέφει τη συμβολοσειρά `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Επίτρεψε στους Wizards να προετοιμάζουν ένα ξόρκι και κάνε τους ευάλωτους όταν δεν έχουν προετοιμάσει ξόρκι

Ενημέρωσε την κλάση `Wizard` ώστε να προσθέσεις μια μέθοδο που ονομάζεται `prepareSpell()`.
Η κλάση θα πρέπει να θυμάται πότε καλείται αυτή η μέθοδος και να διασφαλίζει ότι η μέθοδος `isVulnerable()` της επιστρέφει `false` μόνο όταν έχει προετοιμαστεί ένα ξόρκι.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Υπολόγισε τους πόντους ζημιάς για έναν Wizard

Ενημέρωσε την κλάση `Wizard` ώστε η μέθοδος `getDamagePoints(Fighter)` της να υπολογίζει τη ζημιά που προκαλεί ένας Wizard σύμφωνα με τους παραπάνω κανόνες.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
