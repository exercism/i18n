# Σχετικά

Η Rust είναι μια γλώσσα προγραμματισμού συστημάτων που τρέχει αστραπιαία γρήγορα, αποτρέπει τα σφάλματα κατάτμησης και εγγυάται την ασφάλεια νημάτων.
Στόχος της είναι να φέρει τον σύγχρονο σχεδιασμό γλωσσών και ένα προηγμένο σύστημα τύπων στον προγραμματισμό συστημάτων.
Η Rust δεν χρησιμοποιεί συλλογέα απορριμμάτων. Αντ' αυτού, χρησιμοποιεί προηγμένη στατική ανάλυση για να παρέχει ντετερμινιστική αποδέσμευση.
Το πετυχαίνει αυτό μέσω της έννοιας της [ιδιοκτησίας](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html).

Ο πυρήνας της Rust και η πρότυπη βιβλιοθήκη της είναι σκόπιμα μινιμαλιστικά. Οι μπαταρίες δεν περιλαμβάνονται.
Οι Rustaceans αντίθετα ενθαρρύνονται να προσθέτουν βιβλιοθήκες, τις λεγόμενες _crates_, στη γλώσσα, μοιράζοντάς τες στο [crates.io](https://crates.io/).

Η Rust χρησιμοποιείται συνήθως σε εφαρμογές όπου η ταχύτητα, η απόδοση και η σταθερότητα είναι απαραίτητες.
Η λίστα [Awesome Rust](https://github.com/kud1ing/awesome-rust) συγκεντρώνει παραδείγματα έργων σε Rust, που περιλαμβάνουν εργαλεία γραμμής εντολών, ORMs, λειτουργικά συστήματα και παιχνίδια.
Ό,τι κι αν φτιάξεις με τη Rust, θα είναι γρήγορο και ασφαλές ως προς τη μνήμη!

Η αρχική σελίδα της Rust είναι το [rust-lang.org](https://www.rust-lang.org/).
Η Rust έχει εξαιρετική τεκμηρίωση στο [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html).
Όσοι κάνουν τώρα την αρχή καλό θα ήταν να ξεκινήσουν με το "The Book", που βρίσκεται στο [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/).
