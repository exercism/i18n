# Οδηγίες

Σου έχουν ζητήσει να δουλέψεις λίγο ακόμα πάνω στο σύστημα αυθεντικοποίησης δικτύου.

Εκτός από την ταυτότητα του διαχειριστή που έχει μπει ως καρφωτή τιμή στο σύστημα κατά την ανάπτυξη, οι ιθύνοντες θέλουν να έχουν την ίδια μεταχείριση και οι έμπειροι προγραμματιστές.

## 1. Αποθήκευσε τα στοιχεία του διαχειριστή του συστήματος ως καρφωτή τιμή στο σύστημα και κάν' τα διαθέσιμα σε όποιον τα καλεί.

Τα στοιχεία του διαχειριστή είναι τα εξής:

| Email        | Χρώμα ματιών | Πλάτος φίλτρου | Όνομα    | Διεύθυνση 1 | Διεύθυνση 2 |
| ------------ | ------------ | -------------- | -------- | ----------- | ----------- |
| admin@ex.ism | green        | 0.9            | Chanakya | Mumbai      | India       |

Υλοποίησε την ιδιότητα `Authenticator.Admin` ώστε να επιστρέφει τα στοιχεία ταυτότητας του διαχειριστή του συστήματος. Το όνομα και κάθε μέρος της διεύθυνσης θα πρέπει να βρίσκονται σε ξεχωριστό στοιχείο της λίστας `NameAndAddress`.

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. Αποθήκευσε τα στοιχεία των προγραμματιστών ως καρφωτή τιμή στο σύστημα και κάν' τα διαθέσιμα με τη μορφή λεξικού

Τα στοιχεία των προγραμματιστών είναι τα εξής:

| Email         | Χρώμα ματιών | Πλάτος φίλτρου | Όνομα    | Διεύθυνση 1 | Διεύθυνση 2 |
| ------------- | ------------ | -------------- | -------- | ----------- | ----------- |
| bert@ex.ism   | blue         | 0.8            | Bertrand | Paris       | France      |
| anders@ex.ism | brown        | 0.85           | Anders   | Redmond     | USA         |

Υλοποίησε την ιδιότητα `Authenticator.Developers` ώστε να επιστρέφει τα στοιχεία ταυτότητας των προγραμματιστών. Το κλειδί του λεξικού είναι το όνομα του προγραμματιστή.

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
