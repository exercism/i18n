# Εικονική επικεφαλίδα ανώτατου επιπέδου

## Αριθμοί στην Euphoria

Στην Euphoria ένα `atom` μπορεί να περιέχει οποιοδήποτε είδος αριθμού, με τον υποτύπο `integer` να προορίζεται για ακέραιους αριθμούς.
Είναι δυνατόν να λύσεις αυτή την άσκηση σε γλώσσες τύπου C επιστρέφοντας έναν ακέραιο 64 bit χωρίς πρόσημο.

Ωστόσο, οι ακέραιοι στην Euphoria έχουν πρόσημο και είναι _ένα bit μικρότεροι από τη λέξη της μηχανής_, άρα πολύ μικροί για αυτή την άσκηση, ενώ τα atom μπορούν να περιέχουν μεγαλύτερους ακεραίους με την απαιτούμενη ακρίβεια των 64 bit.

### 32-bit

Υπάρχει μια έκδοση 32-bit της Euphoria, που υπάρχει ακόμα ώστε οι παλαιές εφαρμογές να μπορούν να συνεχίσουν να χρησιμοποιούν προμεταγλωττισμένα 32-bit dll/so όταν δεν υπάρχει διαθέσιμη έκδοση 64-bit, ή το wrapper για κάτι τέτοιο είναι γεμάτο καρφωτές μετατοπίσεις 32-bit.
Αυτή η έκδοση είναι εντελώς ανεπαρκής για να λύσεις αυτή την εργασία, αφού αυτά τα atom έχουν ακρίβεια μόνο 53 bit.
Αν δυσκολεύεσαι να λύσεις αυτή την άσκηση τοπικά, βεβαιώσου ότι χρησιμοποιείς μια έκδοση 64-bit της Euphoria.
