# Σχετικά

Οι βασικές κλάσεις του `java.time`, όπως οι `LocalDate` και `LocalDateTime`, παρέχουν απλές μεθόδους για πρόσθεση ή αφαίρεση χρονικών μονάδων, όμως οι πιο σύνθετες προσαρμογές ημερομηνιών απαιτούν συχνά πιο εξελιγμένη λογική (π.χ. την εύρεση της "δεύτερης Τρίτης του μήνα" ή της "τελευταίας ημέρας του έτους").

Το πακέτο `java.time.temporal` παρέχει τη συναρτησιακή διεπαφή [`TemporalAdjuster`][temporaladjuster-docs] για αυτόν τον σκοπό.
Αντιπροσωπεύει μια στρατηγική για την προσαρμογή ενός χρονικού αντικειμένου (όπως ένα `LocalDate`).
Η βοηθητική κλάση [`TemporalAdjusters`][temporaladjusters-docs] (πρόσεξε το πληθυντικό 's') περιέχει στατικές μεθόδους εργοστασίου που παρέχουν πολλές κοινές, προκαθορισμένες υλοποιήσεις προσαρμογέων.

## Χρήση των TemporalAdjusters

Τα χρονικά αντικείμενα όπως τα `LocalDate` και `LocalDateTime` έχουν μια μέθοδο `with()` που δέχεται ένα `TemporalAdjuster`.
Αυτή η μέθοδος επιστρέφει ένα *νέο* χρονικό αντικείμενο με την προσαρμογή εφαρμοσμένη.

```exercism/note
Η χρήση του `with(TemporalAdjuster)` επιστρέφει ένα _νέο_ στιγμιότυπο και δεν ενημερώνει το υπάρχον στιγμιότυπο, καθώς όλες οι χρονικές κλάσεις του `java.time` είναι αμετάβλητες.
```

```java
import java.time.LocalDate;
import java.time.Month;
import java.time.DayOfWeek;
import java.time.temporal.TemporalAdjusters;

LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15 (a Thursday)

// Use a predefined adjuster from TemporalAdjusters
LocalDate firstDayOfNextMonth = date.with(TemporalAdjusters.firstDayOfNextMonth());
// => 2024-09-01

LocalDate nextSunday = date.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18
```

## Συνήθεις προκαθορισμένοι προσαρμογείς

Η κλάση `TemporalAdjusters` παρέχει πολλές χρήσιμες στατικές μεθόδους.
Ακολουθούν μερικά συνηθισμένα παραδείγματα:

### Εύρεση της νιοστής ημέρας της εβδομάδας

Ο προσαρμογέας `dayOfWeekInMonth(int ordinal, DayOfWeek dayOfWeek)` βρίσκει την n-οστή εμφάνιση μιας συγκεκριμένης ημέρας της εβδομάδας μέσα στον μήνα.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the second Tuesday of August 2024
LocalDate secondTuesday = date.with(TemporalAdjusters.dayOfWeekInMonth(2, DayOfWeek.TUESDAY));
// => 2024-08-13

// Find the fourth Friday of August 2024
LocalDate fourthFriday = date.with(TemporalAdjusters.dayOfWeekInMonth(4, DayOfWeek.FRIDAY));
// => 2024-08-23
```

### Εύρεση της πρώτης/τελευταίας ημέρας της εβδομάδας στον μήνα

Οι προσαρμογείς `firstInMonth(DayOfWeek dayOfWeek)` και `lastInMonth(DayOfWeek dayOfWeek)` βρίσκουν την πρώτη ή την τελευταία εμφάνιση μιας ημέρας της εβδομάδας μέσα στον μήνα.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

// Find the first Sunday of August 2024
LocalDate firstSunday = date.with(TemporalAdjusters.firstInMonth(DayOfWeek.SUNDAY));
// => 2024-08-04

// Find the last Monday of August 2024
LocalDate lastMonday = date.with(TemporalAdjusters.lastInMonth(DayOfWeek.MONDAY));
// => 2024-08-26
```

### Εύρεση της πρώτης/τελευταίας ημέρας του μήνα/έτους

Πιο απλοί προσαρμογείς βρίσκουν την πρώτη ή την τελευταία ημέρα του τρέχοντος μήνα ή έτους.

```java
LocalDate date = LocalDate.of(2024, Month.AUGUST, 15); // 2024-08-15

LocalDate firstDay = date.with(TemporalAdjusters.firstDayOfMonth());
// => 2024-08-01

LocalDate lastDay = date.with(TemporalAdjusters.lastDayOfMonth());
// => 2024-08-31

LocalDate lastDayOfYear = date.with(TemporalAdjusters.lastDayOfYear());
// => 2024-12-31
```

### Σχετικές προσαρμογές (επόμενη/προηγούμενη)

Προσαρμογείς όπως οι `next()`, `previous()`, `nextOrSame()` και `previousOrSame()` βρίσκουν την επόμενη ή την προηγούμενη εμφάνιση μιας δεδομένης ημέρας της εβδομάδας, σε σχέση με την τρέχουσα ημερομηνία.

- `next()`/`previous()`: Αποκλείουν την τρέχουσα ημερομηνία αν ταιριάζει.
- `nextOrSame()`/`previousOrSame()`: Περιλαμβάνουν την τρέχουσα ημερομηνία αν ταιριάζει.

```java
LocalDate thursday = LocalDate.of(2024, Month.AUGUST, 15); // A Thursday

// Find the next Sunday (exclusive)
LocalDate nextSunday = thursday.with(TemporalAdjusters.next(DayOfWeek.SUNDAY));
// => 2024-08-18

// Find the next Thursday (exclusive)
LocalDate nextThursday = thursday.with(TemporalAdjusters.next(DayOfWeek.THURSDAY));
// => 2024-08-22

// Find the next Thursday (inclusive) - returns the same date
LocalDate nextOrSameThursday = thursday.with(TemporalAdjusters.nextOrSame(DayOfWeek.THURSDAY));
// => 2024-08-15

// Find the previous Monday (exclusive)
LocalDate previousMonday = thursday.with(TemporalAdjusters.previous(DayOfWeek.MONDAY));
// => 2024-08-12
```

## Προσαρμοσμένοι προσαρμογείς

Εφόσον το `TemporalAdjuster` είναι [`@FunctionalInterface`][functionalinterface-docs], μπορείς να δημιουργήσεις τους δικούς σου προσαρμοσμένους προσαρμογείς χρησιμοποιώντας εκφράσεις λάμδα για λογική που δεν καλύπτεται από τις προκαθορισμένες μεθόδους.
Η διεπαφή απαιτεί την υλοποίηση μιας μόνο μεθόδου: `Temporal adjustInto(Temporal temporal)`.

```java
// Example: An adjuster that finds the next workday (Mon-Fri), skipping weekends.
TemporalAdjuster nextWorkday = temporal -> {
    LocalDate result = (LocalDate) temporal; // Assuming input is LocalDate
    do {
        result = result.plusDays(1);
    } while (result.getDayOfWeek() == DayOfWeek.SATURDAY || result.getDayOfWeek() == DayOfWeek.SUNDAY);
    return result;
};

LocalDate friday = LocalDate.of(2024, Month.AUGUST, 16);
LocalDate nextWorkdayDate = friday.with(nextWorkday);
// => 2024-08-19 (Monday)

LocalDate sunday = LocalDate.of(2024, Month.AUGUST, 18);
LocalDate nextWorkdayFromSunday = sunday.with(nextWorkday);
// => 2024-08-19 (Monday)
```

Αν και οι προσαρμοσμένοι προσαρμογείς είναι ισχυροί, οι προκαθορισμένοι προσαρμογείς της κλάσης `TemporalAdjusters` καλύπτουν ένα ευρύ φάσμα συνηθισμένων περιπτώσεων χρήσης.
