# Οδηγίες

Ο φίλος σου βαρέθηκε να πληρώνει για λογισμικό επεξεργασίας φωτογραφιών και αποφάσισε να γράψει το δικό του.
Ο φίλος σου αποφάσισε να ονομάσει το νέο λογισμικό Foto Fusionist.

Το Foto Fusionist είναι ένα λογισμικό επεξεργασίας φωτογραφιών που μπορεί να κάνει πολλά πράγματα, αλλά μέχρι στιγμής έχεις υλοποιήσει μόνο μερικά από αυτά.
Ωστόσο, ο φίλος σου είναι πολύ ευχαριστημένος με την πρόοδο και σου ζήτησε να υλοποιήσεις μερικές ακόμα λειτουργίες.

## 1. Μετέτρεψε τη δυαδική αναπαράσταση σε ακέραιο

Για την πρώτη λειτουργία, ο φίλος σου θέλει να μπορεί να μετατρέπει τη δυαδική αναπαράσταση ενός αριθμού σε ακέραιο.
Αυτό γίνεται γιατί το λογισμικό θα μπορεί να διαβάζει τη δυαδική αναπαράσταση ενός καναλιού χρώματος και να τη μετατρέπει σε ακέραιο.

Υλοποίησε τη μέθοδο `FotoFusionist.binary_to_int` που δέχεται ένα όρισμα `binary` τύπου `String`.
Η μέθοδος θα πρέπει να επιστρέφει την ακέραια αναπαράσταση του δυαδικού αριθμού.

```crystal
FotoFusionist.binary_to_int("10011")
# => 19
```

## 2. Πάρε το λιγότερο σημαντικό bit από έναν ακέραιο

Η δεύτερη λειτουργία που θέλει ο φίλος σου είναι να μπορεί να παίρνει το [λιγότερο σημαντικό bit][least-significant-bit] από έναν ακέραιο.
Το λιγότερο σημαντικό bit είναι το bit που βρίσκεται πιο δεξιά.
Ονομάζεται λιγότερο σημαντικό bit επειδή έχει τη μικρότερη τιμή.

Το λιγότερο σημαντικό bit χρειάζεται για να αξιολογηθεί αν μια εικόνα μπορεί να βελτιστοποιηθεί μειώνοντας τον αριθμό των bit που χρησιμοποιούνται για την αναπαράσταση του καναλιού χρώματος.

Υλοποίησε τη μέθοδο `FotoFusionist.least_significant_bit` που δέχεται ένα όρισμα `number` τύπου `Int32`.
Η μέθοδος θα πρέπει να επιστρέφει το λιγότερο σημαντικό bit του αριθμού.

```crystal
FotoFusionist.least_significant_bit(0b10011)
# => 1

FotoFusionist.least_significant_bit(0b10010)
# => 0
```

## 3. Πάρε τη δεκαεξαδική τιμή από ένα κανάλι χρώματος

Η τρίτη λειτουργία που θέλει ο φίλος σου είναι να μπορεί να παίρνει τη δεκαεξαδική τιμή από ένα κανάλι χρώματος.
Η δεκαεξαδική τιμή χρειάζεται για να μπορεί το κανάλι χρώματος να μετατραπεί σε δεκαεξαδική αναπαράσταση, και η συγκεκριμένη δεκαεξαδική αναπαράσταση πρέπει να αποτελείται από δύο ψηφία.

Υλοποίησε τη μέθοδο `FotoFusionist.hex_value` που δέχεται ένα όρισμα `number` τύπου `Int32`.
Η μέθοδος θα πρέπει να επιστρέφει τη δεκαεξαδική τιμή του αριθμού ως `String`.

```crystal
FotoFusionist.hex_value(19)
# => "13"
```

## 4. Πάρε τη δεκαεξαδική τιμή από ένα χρώμα RGB

Η τέταρτη λειτουργία που θέλει ο φίλος σου είναι να μπορεί να παίρνει τη δεκαεξαδική τιμή από ένα χρώμα RGB.
Αυτό χρειάζεται ώστε ένας χρήστης να μπορεί να πάρει μια ενιαία αναπαράσταση συμβολοσειράς ενός χρώματος.
Ένα χρώμα RGB είναι ένα χρώμα που αναπαρίσταται από τρία κανάλια χρώματος: κόκκινο, πράσινο και μπλε.
Κάθε κανάλι χρώματος αναπαρίσταται από έναν αριθμό μεταξύ 0 και 255.

Η δεκαεξαδική τιμή ενός χρώματος RGB είναι μια αναπαράσταση συμβολοσειράς του χρώματος σε δεκαεξαδικό, με πρώτο το κόκκινο κανάλι χρώματος, μετά το πράσινο κανάλι χρώματος και τέλος το μπλε κανάλι χρώματος.

Υλοποίησε τη μέθοδο `FotoFusionist.hex_value_from_rgb` που δέχεται τρία ορίσματα: `red`, `green` και `blue` τύπου `Int32`.
Η μέθοδος θα πρέπει να επιστρέφει τη δεκαεξαδική τιμή του χρώματος RGB ως `String`.

```crystal
FotoFusionist.hex_value_from_rgb(255, 0, 0)
# => "ff0000"
```

[least-significant-bit]: https://en.wikipedia.org/wiki/Least_significant_bit
