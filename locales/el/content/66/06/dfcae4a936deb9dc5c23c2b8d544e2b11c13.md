# Tuples

Ένα [tuple][tuple] είναι μια πεπερασμένη διατεταγμένη λίστα στοιχείων που είναι αμετάβλητη.
Τα tuples απαιτούν όλες οι θέσεις να έχουν σταθερό τύπο.
Αυτό με τη σειρά του σημαίνει ότι ο μεταγλωττιστής γνωρίζει τι τύπος βρίσκεται σε κάθε θέση.
Οι τύποι που χρησιμοποιούνται σε ένα tuple μπορούν να διαφέρουν σε κάθε θέση, αλλά οι τύποι πρέπει να είναι γνωστοί σε χρόνο μεταγλώττισης.

## Δημιουργία ενός tuple

Ανάλογα με το αν οι τύποι των τιμών του tuple μπορούν να προσδιοριστούν σε χρόνο μεταγλώττισης, το tuple μπορεί να δημιουργηθεί με διαφορετικούς τρόπους.
Αν οι τιμές είναι γνωστές σε χρόνο μεταγλώττισης, το tuple μπορεί να δημιουργηθεί χρησιμοποιώντας τη σύνταξη literal του tuple, αλλιώς πρέπει να δηλωθούν ρητά.
Είναι επίσης σημαντικό οι τύποι των τιμών να ταιριάζουν με τους τύπους που καθορίζονται στο tuple και ο αριθμός των τιμών να ταιριάζει με τον αριθμό των τύπων που καθορίζονται.
Ακολουθεί ένα παράδειγμα ορισμού μέσω της σύνταξης literal του tuple:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

Υπάρχει επίσης η δυνατότητα να δημιουργήσεις ένα tuple χρησιμοποιώντας την κλάση `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Εναλλακτικά, μπορείς να καθορίσεις ρητά τον τύπο της μεταβλητής που ανατίθεται στο tuple.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Ο ρητός καθορισμός του τύπου του tuple μπορεί να είναι χρήσιμος, καθώς επιτρέπει να ορίσεις ότι μια θέση πρέπει να περιέχει τύπο ένωσης.
Αυτό σημαίνει ότι μια θέση μπορεί να περιέχει πολλαπλούς τύπους.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Μετατροπή

### Δημιουργία tuple από πίνακα

Μπορείς να δημιουργήσεις ένα tuple από έναν πίνακα χρησιμοποιώντας τη μέθοδο `from` της κλάσης `Tuple`.
Αυτό απαιτεί να έχει καθοριστεί ο τύπος του tuple.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Μετατροπή σε πίνακα

Μπορείς να μετατρέψεις ένα tuple σε πίνακα χρησιμοποιώντας τη μέθοδο `to_a`.
Ο τύπος των στοιχείων του πίνακα που προκύπτει είναι η ένωση των τύπων κάθε πεδίου του tuple.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

### Συντομογραφία ορισμού tuple

Υπάρχει μια συντομογραφία για τον ορισμό ρητών τύπων tuple.
Αυτή είναι να γράψεις τους τύπους μέσα στο literal του tuple.

```crystal
tuple : {Int32, String, Char} = {1, "foo", 'c'}
```

## Πρόσβαση σε στοιχεία

Όπως και οι πίνακες, τα tuples αριθμούνται από το μηδέν, που σημαίνει ότι το πρώτο στοιχείο βρίσκεται στη θέση 0.
Ωστόσο, σε αντίθεση με τους πίνακες, ο τύπος κάθε στοιχείου είναι σταθερός και γνωστός σε χρόνο μεταγλώττισης, επομένως όταν προσπελαύνεις ένα tuple με θέση, ο τύπος του στοιχείου είναι ο τύπος της συγκεκριμένης θέσης.
Για να προσπελάσεις ένα στοιχείο σε ένα tuple, μπορείς να χρησιμοποιήσεις τον τελεστή `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Μια άλλη διαφορά όσον αφορά την πρόσβαση σε στοιχεία από πίνακες είναι ότι αν η θέση καθορίζεται ρητά, τότε ο μεταγλωττιστής θα ελέγξει ότι η θέση βρίσκεται εντός των ορίων του tuple.
Αυτό σημαίνει ότι θα πάρεις ένα σφάλμα σε χρόνο μεταγλώττισης αντί για ένα σφάλμα σε χρόνο εκτέλεσης.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Ωστόσο, αν η θέση είναι αποθηκευμένη σε μια μεταβλητή, τότε ο μεταγλωττιστής δεν θα μπορεί να ελέγξει σε χρόνο μεταγλώττισης αν η θέση βρίσκεται εντός των ορίων του tuple και αντ' αυτού θα δώσει ένα σφάλμα σε χρόνο εκτέλεσης.

## Υπο-tuple

Μπορείς να πάρεις ένα υπο-tuple ενός tuple χρησιμοποιώντας τον τελεστή `[]` με ένα εύρος.
Αυτό που επιστρέφεται είναι ένα νέο tuple με τα στοιχεία του καθορισμένου εύρους.
Το εύρος πρέπει να δοθεί σε χρόνο μεταγλώττισης, αλλιώς ο μεταγλωττιστής δεν θα μπορεί να γνωρίζει τους τύπους των στοιχείων στο υπο-tuple.
Αυτό σημαίνει ότι το εύρος πρέπει να είναι ένα literal εύρους και όχι να έχει ανατεθεί σε μια μεταβλητή.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Πότε να χρησιμοποιείς ένα tuple

Τα tuples είναι χρήσιμα όταν θέλεις να ομαδοποιήσεις έναν σταθερό αριθμό τιμών μαζί, όπου οι τύποι των τιμών είναι γνωστοί σε χρόνο μεταγλώττισης.
Αυτό συμβαίνει επειδή τα tuples απαιτούν λιγότερη μνήμη και είναι ταχύτερα από τους πίνακες, λόγω της αμεταβλητότητας των tuples.
Μια άλλη περίπτωση χρήσης είναι η επιστροφή πολλαπλών τιμών από μια μέθοδο.
Αυτό είναι ιδιαίτερα χρήσιμο αν οι τιμές έχουν διαφορετικούς τύπους, καθώς κάθε θέση στο tuple μπορεί να έχει διαφορετικό τύπο.

Τα tuples δεν θα πρέπει να χρησιμοποιούνται όταν χρειάζεται μια δομή δεδομένων που μπορεί να μεγαλώσει ή να μικρύνει σε μέγεθος ή που χρειάζεται συχνά τροποποίηση.
