# Υποδείξεις

## Γενικά

- Διάβασε για τους συνδέσμους και τις εργασίες στον επίσημο [οδηγό Getting Started][getting-started-links].
- Ρίξε μια ματιά στην [τεκμηρίωση της μονάδας `Task`][task].
- Διάβασε το ["Demystifying processes in Elixir" στο blog.appsignal.com][appsignal-processes].
- Διάβασε το ["Understanding Exit Signals in Erlang/Elixir" στο crypt.codemancers.com][codemancers-exit-signals].

## 1. Ξεκίνα έναν έλεγχο αξιοπιστίας για μία μόνο είσοδο

- Δεν χρειάζεσαι εργασία για αυτό το βήμα, αρκεί μια κανονική συνδεδεμένη διεργασία.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][spawn-link] που εκτελεί μια δεδομένη ανώνυμη συνάρτηση σε μια νέα διεργασία και τη συνδέει με την τρέχουσα διεργασία.

## 2. Ερμήνευσε τα αποτελέσματα ενός ελέγχου αξιοπιστίας

- Για να λάβεις ένα μόνο μήνυμα, κάλεσε μία φορά το [`receive`][receive]. Θα διαβάσει το πρώτο μήνυμα που ταιριάζει με οποιοδήποτε από τα μοτίβα που δίνονται, αφήνοντας τα υπόλοιπα μηνύματα στο γραμματοκιβώτιο της διεργασίας.
- Μπορείς να χρησιμοποιήσεις είτε ένα guard είτε [τον τελεστή pin][pin-operator] για να διασφαλίσεις ότι θα ληφθούν μόνο μηνύματα από μια διεργασία της οποίας το PID ταιριάζει με το PID που δίνεται ως όρισμα στο `await_reliability_check_result/2`.
- Το [`receive`][receive] δέχεται μια ρήτρα `after` για να χειρίζεται τα timeouts.

## 3. Τρέξε έναν ταυτόχρονο έλεγχο αξιοπιστίας για πολλές εισόδους

- Η τρέχουσα διεργασία πρέπει να αρχίσει να παγιδεύει τις εξόδους πριν δημιουργηθεί οποιαδήποτε νέα συνδεδεμένη διεργασία.
- Η παγίδευση εξόδων σε μια διεργασία επιτυγχάνεται με τον ορισμό μιας σημαίας σε αυτή τη διεργασία.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][process-flag] που ορίζει μια σημαία σε μια διεργασία και επιστρέφει την παλιά τιμή αυτής της σημαίας.
- Η σημαία για την παγίδευση εξόδων ονομάζεται `:trap_exit` και δέχεται μια τιμή Boolean.
- Χρησιμοποίησε συναρτήσεις του `Enum` για να ξεκινήσεις πρώτα μια διεργασία για κάθε είσοδο και μετά να περιμένεις μηνύματα από κάθε διεργασία. Χρησιμοποίησε τις συναρτήσεις που υλοποιήθηκαν στα δύο προηγούμενα βήματα. Σημείωσε ότι ο χάρτης που επιστρέφει το `start_reliability_check/2` ταιριάζει με τον χάρτη που περιμένει το `await_reliability_check_result/2` ως πρώτο όρισμα.

## 4. Τρέξε έναν ταυτόχρονο έλεγχο ορθότητας για πολλές εισόδους

- Χρησιμοποίησε μια ασύγχρονη εργασία για αυτό το βήμα.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][task-async] που ξεκινά μια ασύγχρονη εργασία.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][task-await] που περιμένει να ολοκληρωθεί η εκτέλεση μιας ασύγχρονης εργασίας και επιστρέφει το αποτέλεσμα της. Δέχεται ένα timeout ως δεύτερο όρισμα.
- Χρησιμοποίησε συναρτήσεις του `Enum` για να ξεκινήσεις πρώτα μια εργασία για κάθε είσοδο και μετά να περιμένεις κάθε εργασία.
