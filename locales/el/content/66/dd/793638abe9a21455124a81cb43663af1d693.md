# Σχετικά

Η Objective-C είναι ένα λεπτό στρώμα πάνω από τη C και αποτελεί ένα "αυστηρό υπερσύνολο" της C, που σημαίνει ότι μπορείς να μεταγλωττίσεις οποιοδήποτε πρόγραμμα C με έναν μεταγλωττιστή Objective-C και να συμπεριλάβεις ελεύθερα κώδικα C μέσα σε μια κλάση Objective-C.
Η Objective-C αντλεί τη σύνταξη των αντικειμένων της από τη Smalltalk.
Όλη η σύνταξη για τις μη αντικειμενοστρεφείς λειτουργίες (συμπεριλαμβανομένων των πρωτόγονων μεταβλητών, της προεπεξεργασίας, των εκφράσεων, των δηλώσεων συναρτήσεων και των κλήσεων συναρτήσεων) είναι ίδια με αυτή της C, ενώ η σύνταξη για τα αντικειμενοστρεφή χαρακτηριστικά είναι υλοποίηση της ανταλλαγής μηνυμάτων σε στυλ Smalltalk.

Μπορείς να βρεις περισσότερες πληροφορίες για τη γλώσσα και την ιστορία της [εδώ](https://en.wikipedia.org/wiki/Objective-C).
