# Οδηγίες

Κρατάς τον πίνακα αποτελεσμάτων σε έναν αγώνα νέτμπολ. Σε αντίθεση με όλα όσα έχεις δει μέχρι τώρα, ένας πίνακας αποτελεσμάτων πρέπει να θυμάται τι έχει συμβεί.

Η κλάση `SCOREBOARD` χρειάζεται τα παρακάτω. Ο σκελετός σου δίνει την κλάση και τις δύο δηλώσεις χαρακτηριστικών της· πρόσθεσε τα υπόλοιπα.

## 1. Στήσε τον πίνακα

Η `create` δέχεται το όνομα της γηπεδούχου ομάδας και το όνομα της φιλοξενούμενης ομάδας και επιστρέφει έναν πίνακα αποτελεσμάτων με τα δύο σκορ στο μηδέν.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Σημείωσε ένα γκολ

Η `home_goal` προσθέτει ένα στο σκορ της γηπεδούχου και η `away_goal` προσθέτει ένα στο σκορ της φιλοξενούμενης. Καμία από τις δύο δεν επιστρέφει κάτι.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Διάβασε τον πίνακα

Η `summary` επιστρέφει τον πίνακα όπως θα τον έγραφες: τη γηπεδούχο ομάδα, το σκορ της, μια παύλα, το σκορ της φιλοξενούμενης και μετά τη φιλοξενούμενη ομάδα.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Τα κενά είναι ακριβώς όπως φαίνονται και η παύλα είναι ένα μόνο `-`.

## 4. Ποιος κερδίζει;

Η `leader` επιστρέφει το όνομα της ομάδας που προηγείται ή `"Draw"` όταν τα σκορ είναι ίσα.

```sather
board.leader
-- => "Vixens"
```

## 5. Πόσο μπροστά;

Η `margin` επιστρέφει πόσα γκολ χωρίζουν τις ομάδες. Δεν είναι ποτέ αρνητική, όποιος κι αν προηγείται.

```sather
board.margin
-- => 1
```
