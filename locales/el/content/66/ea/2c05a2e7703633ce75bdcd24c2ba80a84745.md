# Υπερφόρτωση συναρτήσεων

Έχουμε δει στην άσκηση Λαζάνια πώς ορίζονται οι συναρτήσεις στη Swift χρησιμοποιώντας τη λέξη-κλειδί `func`, ακολουθούμενη από μια λίστα ονομάτων παραμέτρων μέσα σε παρενθέσεις, όπου αυτά τα ονόματα περιλαμβάνουν μια προαιρετική ετικέτα ορίσματος και ένα όνομα παραμέτρου, ακολουθούμενα από υπόδειξη τύπου, και το σώμα της συνάρτησης μέσα σε άγκιστρα. Π.χ.

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = x + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySix = add(6, and: 7, doubleResult: true)
// => 26
```

Δύο συναρτήσεις θεωρούνται διαφορετικές στη Swift αν έχουν διαφορετικό όνομα, _ή_ αν ισχύει οποιοδήποτε από τα παρακάτω:

- Έχουν διαφορετικό αριθμό παραμέτρων
- Οποιαδήποτε εξωτερική ετικέτα ορίσματος είναι διαφορετική
- Ο τύπος οποιασδήποτε παραμέτρου είναι διαφορετικός

Έτσι, με δεδομένο τον παραπάνω ορισμό της `add(_:and:doubleResult)`, καθεμία από τις παρακάτω συναρτήσεις θεωρείται διαφορετική και μπορεί να οριστεί και να χρησιμοποιηθεί στο ίδιο πρόγραμμα:

```swift
// Different number of parameters
func add(_ x: Int, and y: Int) -> Int {
  x + y
}

let eleven = add(5, and: 6)
// => 11

// Different parameter type
func add(_ x: Double, and y: Int, doubleResult: Bool) -> Double {
  let sum = x + Double(y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let twentySeven = add(6.5, and: 7, doubleResult: true)
// => 27.0

// Different argument label
func add(_ x: Int, and y: Int, doubleThat: Bool) -> Int {
  let sum = x + y
  if doubleThat {
    return sum * 2
  } else {
    return sum
  }
}
let thirteen = add(6, and: 7, doubleThat: false)
// => 13
```

Οι συναρτήσεις θεωρούνται επίσης διαφορετικές αν αλλάζει μόνο η τιμή επιστροφής, αν και σε πολλές περιπτώσεις είναι απαραίτητο να δώσεις στον μεταγλωττιστή μια υπόδειξη τύπου, ώστε να ξέρει ποια έκδοση της συνάρτησης να καλέσει.

```swift
func add(_ x: Int, and y: Int, doubleResult: Bool) -> Double {
  let sum = Double(x + y)
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}

let thirty = add(6, and: 9, doubleResult: true)
// Error: Ambiguous use of 'add(_:and:doubleResult:)'

let thirty: Double = add(6, and: 9, doubleResult: true)
// => 30
```

Όμως, το να αλλάξεις απλώς το όνομα μιας εσωτερικής παραμέτρου δεν ξεχωρίζει δύο συναρτήσεις.

```swift
func add(_ w: Int, and y: Int, doubleResult: Bool) -> Int {
  let sum = w + y
  if doubleResult {
    return sum * 2
  } else {
    return sum
  }
}
// Error: Invalid redeclaration of 'add(_:and:doubleResult:)'
```
