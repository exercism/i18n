# Tests

Εκτέλεσε τα tests με:

```bash
$ gradlew test
```

> Χρησιμοποίησε το `gradlew.bat` αν είσαι σε Windows

## Tests που παραλείπονται

Στις σουίτες tests, όλα τα tests εκτός από το πρώτο έχουν παραλειφθεί.

Μόλις περάσεις ένα test, μπορείς να ενεργοποιήσεις το επόμενο αφαιρώντας τη σημείωση `@Ignore`.
