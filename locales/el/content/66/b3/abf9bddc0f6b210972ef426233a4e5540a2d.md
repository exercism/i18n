# Οδηγίες

Ως μαθητευόμενη μάγισσα, η Elyse χρειάζεται να εξασκηθεί στα βασικά. Έχει μια τράπουλα που θέλει να επεξεργαστεί.

Για να γίνουν τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τα χαρτιά 1 έως 10.

## 1. Πάρε ένα χαρτί από την τράπουλα

Υλοποίησε τη συνάρτηση `getCard` που επιστρέφει το χαρτί στη θέση `index` από την τράπουλα που δίνεται. Αν η θέση δεν υπάρχει στην τράπουλα, επέστρεψε Nothing.

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. Άλλαξε ένα χαρτί στην τράπουλα

Υλοποίησε τη συνάρτηση `setCard` που επιστρέφει μια τράπουλα όπου το χαρτί στη θέση `index` έχει αλλαχθεί με το νέο χαρτί που δίνεται.
Αν η θέση `index` δεν υπάρχει στην τράπουλα, επέστρεψε την αρχική τράπουλα.

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. Πρόσθεσε ένα χαρτί στην τράπουλα

Υλοποίησε τη συνάρτηση `addCard` που επιστρέφει μια τράπουλα με το νέο χαρτί προστεμένο.

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. Αφαίρεσε ένα χαρτί από την τράπουλα

Υλοποίησε τη συνάρτηση `removeCard` που επιστρέφει μια τράπουλα όπου έχει αφαιρεθεί το χαρτί στη θέση `index`.
Αν η θέση `index` που δίνεται δεν είναι έγκυρη θέση στην τράπουλα, επέστρεψε την αρχική τράπουλα.

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. Μέτρησε τον αριθμό των ζυγών χαρτιών στην τράπουλα

Υλοποίησε τη συνάρτηση `evenCardCount` που μετράει τον αριθμό των ζυγών χαρτιών στην τράπουλα.

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
