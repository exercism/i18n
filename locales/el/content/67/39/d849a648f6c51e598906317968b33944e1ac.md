# Υποδείξεις

## 1. Προσδιόρισε πόσο χρόνο χρειάζεται για να φτιάξεις μια παραγγελία

- Μπορείς να χρησιμοποιήσεις έναν [`for-in` βρόχο][for-in-loops] για να κοιτάς ένα ποτό τη φορά.
- Μπορείς να χρησιμοποιήσεις μια εντολή `switch` για να επιστρέψεις τον χρόνο που χρειάζεται για να φτιάξεις κάθε τύπο ποτού.

## 2. Αναπλήρωσε το απόθεμά σου σε φέτες λάιμ

- [Οι πίνακες έχουν μια μέθοδο][array-docs] που αφαιρεί το πρώτο στοιχείο ενός πίνακα και στο επιστρέφει.
- Χρειάζεται να αντιγράψεις τις παραμέτρους μιας συνάρτησης σε μια μεταβλητή αν θέλεις να τις τροποποιήσεις.

## 3. Ολοκλήρωσε τη βάρδιά σου

- Αν ξέρουμε ότι μας απομένει ακόμα χρόνος στη βάρδιά μας, ξέρουμε ότι θα πρέπει να φτιάξουμε τουλάχιστον μία παραγγελία.
    Αυτό είναι μια καλή ένδειξη ότι ένας [βρόχος repeat-while][repeat-loops] θα ήταν καλή επιλογή.
- [Οι πίνακες έχουν μια μέθοδο][array-docs] που αφαιρεί το πρώτο στοιχείο ενός πίνακα και στο επιστρέφει.

## 4. Παρακολούθησε ορισμένες παραγγελίες

- Ένας [`for-in` βρόχος][for-in-loops] μπορεί να χρησιμοποιηθεί για να δουλεύεις κάθε παραγγελία μία τη φορά.
- Η αποδόμηση πλειάδας μπορεί να χρησιμοποιηθεί για να ονομάσεις τα επιμέρους στοιχεία της πλειάδας στον βρόχο `for-in`.
- Μπορείς να χρησιμοποιήσεις [εντολές μεταφοράς ελέγχου][control-transfer] για να περάσεις στην επόμενη επανάληψη του βρόχου για τα ποτά που δεν μας ενδιαφέρουν.
