# Εισαγωγή

Πολλά είδη μελών δομών και κλάσεων (με τα πεδία να αποτελούν τη βασική εξαίρεση) μπορούν να χρησιμοποιούν τη σύνταξη μέλους με σώμα έκφρασης. Ο ορισμός ενός μέλους με μια έκφραση συχνά παράγει πιο συνοπτικό και ευανάγνωστο κώδικα από τα παραδοσιακά μπλοκ/εντολές.

Οι μέθοδοι και οι ιδιότητες μόνο για ανάγνωση συγκαταλέγονται στα μέλη που μπορούν να οριστούν με σώματα έκφρασης.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
