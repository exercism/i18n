# Σχετικά

Η Crystal είναι μια μεταγλωττισμένη, αντικειμενοστρεφής γλώσσα προγραμματισμού.
Αυτοί είναι μερικοί από τους στόχους της γλώσσας:

- Σύνταξη εμπνευσμένη από τη Ruby.

- Στατικός έλεγχος τύπων, αλλά χωρίς να χρειάζεται να προσδιορίζεις τον τύπο των μεταβλητών ή των ορισμάτων των μεθόδων.

- Να μπορείς να καλείς κώδικα C γράφοντας δεσμεύσεις για αυτόν στην Crystal.

- Να έχει αξιολόγηση και παραγωγή κώδικα κατά τη μεταγλώττιση, ώστε να αποφεύγεται ο boilerplate κώδικας.

- Να μεταγλωττίζεται σε αποδοτικό εγγενή κώδικα.
