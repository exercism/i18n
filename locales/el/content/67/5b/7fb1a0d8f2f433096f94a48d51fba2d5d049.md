# Debug

Η YS έχει μια ενσωματωμένη συνάρτηση `DBG` που μπορεί να σου φανεί χρήσιμη όταν ψάχνεις σφάλματα στον κώδικα της λύσης σου.
Δέχεται οποιονδήποτε αριθμό ορισμάτων και τα εκτυπώνει στην κονσόλα στο stderr.
Επιστρέφει το τελευταίο όρισμα, ώστε να μπορείς να το χρησιμοποιήσεις και μέσα στον κώδικά σου.


Μπορείς να χρησιμοποιήσεις τον τελεστή `.>` που είναι συντομογραφία του `.DBG()`.

Ορίστε ένα παράδειγμα αρχείου κώδικα:

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

Όταν τρέξεις αυτόν τον κώδικα με το `ys`, θα δεις την παρακάτω έξοδο:

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## Μεταγλώττιση

Ένας άλλος συνηθισμένος τρόπος για να λύσεις ένα πρόβλημα είναι να δεις τον κώδικα Clojure στον οποίο μεταγλωττίζεται ο κώδικας YS σου.

Μπορείς να το κάνεις αυτό τρέχοντας τον διερμηνευτή γραμμής εντολών `ys` με τη σημαία `-c`.

Δες πώς μοιάζει το παραπάνω αρχείο `program.ys` όταν μεταγλωττιστεί:

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

Μπορείς να δεις καθαρά πώς ο τελεστής `.>` μεταγλωττίστηκε στην κλήση της συνάρτησης `DBG`.
