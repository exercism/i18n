# Οδηγίες

Η φίλη σου η Li Mei έχει ένα μαγαζί με χυμούς, όπου πουλάει νόστιμους χυμούς από ανάμεικτα φρούτα.
Είσαι τακτικός πελάτης στο μαγαζί της και συνειδητοποίησες ότι θα μπορούσες να κάνεις τη ζωή της φίλης σου πιο εύκολη.
Αποφασίζεις να χρησιμοποιήσεις τις ικανότητές σου στον προγραμματισμό για να βοηθήσεις τη Li Mei στη δουλειά της.

## 1. Υπολόγισε πόσο χρόνο χρειάζεται για να αναμείξεις έναν χυμό

Στη Li Mei αρέσει να λέει στους πελάτες της εκ των προτέρων πόσο θα περιμένουν για τον χυμό από το μενού που παρήγγειλαν.
Δυσκολεύεται να θυμάται τους ακριβείς αριθμούς, γιατί ο χρόνος ανάμειξης των χυμών ποικίλλει.
Το `"Pure Strawberry Joy"` χρειάζεται 0,5 λεπτά, το `"Energizer"` και το `"Green Garden"` χρειάζονται 1,5 λεπτά το καθένα, το `"Tropical Island"` χρειάζεται 3 λεπτά και το `"All or Nothing"` χρειάζεται 5 λεπτά.
Για όλα τα άλλα ροφήματα (π.χ. προσφορές) μπορείς να υποθέσεις χρόνο προετοιμασίας 2,5 λεπτά.

Για να βοηθήσεις τη φίλη σου, γράψε μια συνάρτηση `time_to_mix_juice` που παίρνει ως όρισμα έναν χυμό από το μενού και επιστρέφει τον αριθμό των λεπτών που χρειάζεται για να αναμειχθεί αυτό το ρόφημα.

```R
time_to_mix_juice("Tropical Island")
# => 3

time_to_mix_juice("Berries & Lime")
# => 2.5
```

## 2. Ανανέωσε το απόθεμα από φέτες λάιμ

Πολλές από τις δημιουργίες της Li Mei περιλαμβάνουν φέτες λάιμ, είτε ως συστατικό είτε ως μέρος της διακόσμησης.
Έτσι, όταν ξεκινά τη βάρδιά της το πρωί, πρέπει να βεβαιωθεί ότι το κουτί με τις φέτες λάιμ είναι γεμάτο για την ημέρα που ακολουθεί.

Υλοποίησε τη συνάρτηση `limes_to_cut`, η οποία παίρνει τον αριθμό των φετών λάιμ που χρειάζεται να κόψει η Li Mei και έναν πίνακα που αντιπροσωπεύει το απόθεμα από ολόκληρα λάιμ που έχει διαθέσιμα.
Μπορεί να πάρει 6 φέτες από ένα λάιμ `"small"`, 8 φέτες από ένα λάιμ `"medium"` και 10 από ένα λάιμ `"large"`.
Κόβει πάντα τα λάιμ με τη σειρά που εμφανίζονται στη λίστα, ξεκινώντας από το πρώτο στοιχείο.
Συνεχίζει μέχρι να φτάσει στον αριθμό των φετών που χρειάζεται ή μέχρι να τελειώσουν τα λάιμ.

Η Li Mei θα ήθελε να ξέρει εκ των προτέρων πόσα λάιμ χρειάζεται να κόψει.
Η συνάρτηση `limes_to_cut` πρέπει να επιστρέφει τον αριθμό των λάιμ που πρέπει να κοπούν.

```R
limes_to_cut(25, c("small", "small", "large", "medium", "small"))
# => 4
```

## 3. Εμφάνισε τους χρόνους ανάμειξης κάθε παραγγελίας στην ουρά

Στη Li Mei αρέσει να παρακολουθεί σε μια οθόνη πόση ώρα θα χρειαστεί για να αναμειχθούν οι παραγγελίες που περιμένουν οι πελάτες.

Υλοποίησε τη συνάρτηση `order_times`, η οποία παίρνει μια ουρά παραγγελιών και *εκτυπώνει* στο stdout τον χρόνο που χρειάζεται για να φτιαχτεί η καθεμία.

```R
order_times(c("Energizer", "Tropical Island"))
# => 1.5 
# => 3
```

## 4. Τελείωσε τη βάρδια

Η Li Mei δουλεύει πάντα μέχρι τις 3 μ.μ.
Μετά αναλαμβάνει ο υπάλληλός της, ο Dmitry.
Υπάρχουν συχνά ροφήματα που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμη όταν τελειώνει η βάρδια της Li Mei.
Τότε ο Dmitry ετοιμάζει τους υπόλοιπους χυμούς.

Για να γίνει πιο εύκολη η παράδοση της βάρδιας, υλοποίησε μια συνάρτηση `remaining_orders`, η οποία παίρνει τον αριθμό των λεπτών που απομένουν στη βάρδια της Li Mei και έναν πίνακα με χυμούς που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμη.
Η συνάρτηση πρέπει να επιστρέφει τις παραγγελίες που η Li Mei δεν μπορεί να αρχίσει να ετοιμάζει πριν από το τέλος της εργάσιμης ημέρας της.

Ο χρόνος που απομένει στη βάρδια θα είναι πάντα μεγαλύτερος από 0.
Ο πίνακας με τους χυμούς προς ετοιμασία δεν θα είναι ποτέ κενός.
Επιπλέον, οι παραγγελίες ετοιμάζονται με τη σειρά που εμφανίζονται στον πίνακα.
Αν η Li Mei αρχίσει να αναμειγνύει κάποιον χυμό, θα τον τελειώσει πάντα, ακόμη κι αν χρειαστεί να δουλέψει λίγο παραπάνω.
Αν δεν έχουν απομείνει παραγγελίες για τις οποίες πρέπει να φροντίσει ο Dmitry, πρέπει να επιστραφεί ένα κενό διάνυσμα.

```R
remaining_orders(5, c("Energizer", "All or Nothing", "Green Garden"))
# => c("Green Garden")
```
