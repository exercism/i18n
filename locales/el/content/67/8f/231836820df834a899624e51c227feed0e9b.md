# Πώς να χρησιμοποιείς το Markdown στην καθοδήγηση

Μπορείς να χρησιμοποιήσεις το Markdown στα σχόλια καθοδήγησής σου στο GitHub.
Έτσι μπορείς να ενσωματώνεις αποσπάσματα κώδικα, να προσθέτεις επικεφαλίδες, έντονη και πλάγια γραφή, λίστες κ.λπ., και να παραθέτεις προηγούμενες προτάσεις.

Στο Exercism επιτρέπουμε επίσης ορισμένα στοιχεία του "Github-flavoured Markdown", συγκεκριμένα την επισήμανση σύνταξης, τους πίνακες και τη διαγράμμιση.

Αν δεν έχεις ξαναδουλέψει με το Markdown ή με τις επιπλέον δυνατότητες του GitHub, σου προτείνουμε να διαβάσεις τον [οδηγό του GitHub για το Markdown](https://guides.github.com/features/mastering-markdown/).
