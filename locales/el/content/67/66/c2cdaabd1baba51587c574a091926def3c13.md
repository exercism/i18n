# `vec![]`

Μπορείς να χρησιμοποιήσεις μακροεντολές της Rust για να δημιουργήσεις διανύσματα.

## Σύνταξη

- Το `vec![]` χρησιμοποιεί μια μακροεντολή της std της Rust για να αρχικοποιήσει ένα κενό `Vec<T>`
- Το `vec![1; 3]` αρχικοποιεί ένα διάνυσμα με τρεις άσσους
- Το `vec![1, 2, 3]` αρχικοποιεί ένα διάνυσμα με τις κυριολεκτικές τιμές 1, 2, 3
