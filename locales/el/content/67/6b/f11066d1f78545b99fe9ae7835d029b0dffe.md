# Εισαγωγή

Ένα λεξικό (`dict`) στην Python είναι μια δομή δεδομένων που συσχετίζει [κατακερματίσιμα][term-hashable] _κλειδιά_ με _τιμές_ και είναι γνωστό σε άλλες γλώσσες προγραμματισμού ως [πίνακας κατακερματισμού][hashtable-wikipedia] μεταβλητού μεγέθους, hashmap ή [συσχετιστικός πίνακας][associative-array].
Τα λεξικά είναι ο μόνος ενσωματωμένος [τύπος αντιστοίχισης][mapping-types-dict] της Python.


Τα `keys` πρέπει να είναι κατακερματίσιμα και μοναδικά μέσα στο λεξικό.
Οι τύποι των κλειδιών μπορούν να περιλαμβάνουν `number`s, `str`s ή `tuple`s (με _αμετάβλητες_ τιμές).
Δεν μπορούν να περιέχουν _μεταβλητές_ δομές δεδομένων όπως `list`s, `dict`s ή `set`s.
Από την Python 3.7, η σειρά των κλειδιών σε ένα `dict` είναι εγγυημένη ότι είναι η σειρά με την οποία εισάγονται οι καταχωρίσεις.

Τα `values` μπορούν να είναι οποιουδήποτε τύπου δεδομένων ή δομής.
 Οι τιμές μπορούν επίσης να εμφωλεύονται _αυθαίρετα_, ώστε να περιλαμβάνουν λίστες από λίστες, υπολεξικά και άλλες προσαρμοσμένες ή σύνθετες δομές δεδομένων.

Με δεδομένο ένα `key`, τα λεξικά μπορούν να ανακτήσουν ένα `value` σε (κατά μέσο όρο) σταθερό χρόνο (_ανεξάρτητα από τον αριθμό των καταχωρίσεων_).
Σε σύγκριση με την αναζήτηση μιας τιμής μέσα σε μια `list` ή έναν `array` (_χωρίς να γνωρίζεις τη θέση `index`_), ένα `dict` χρησιμοποιεί σημαντικά περισσότερη μνήμη, αλλά έχει πολύ γρήγορη ανάκτηση.

Τα λεξικά είναι ιδιαίτερα χρήσιμα σε σενάρια όπου η συλλογή στοιχείων είναι μεγάλη και πρέπει να προσπελαύνεται και να ενημερώνεται συχνά.
