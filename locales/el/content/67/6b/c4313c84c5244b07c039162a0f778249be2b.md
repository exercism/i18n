# Οδηγίες

Ο φίλος σου ο Johannes λατρεύει το hardware DIY (do it yourself, δηλαδή φτιάξ' το μόνος σου).
Μόλις έφτιαξε μια μηχανή χυμών και είναι πολύ ενθουσιασμένος γι' αυτό.
Ο στόχος του Johannes είναι να μπορεί να φτιάχνει φρέσκο χυμό κάθε πρωί.

Η μηχανή χυμών του Johannes μπορεί να ρυθμιστεί με διαφορετικές χωρητικότητες.
Ο Johannes δεν είναι ο καλύτερος στον προγραμματισμό, αλλά θέλει να φτιάξει ένα πρόγραμμα για να ελέγχει τη μηχανή.
Έτσι, σου ζήτησε να τον βοηθήσεις.

## 1. Δημιούργησε την κλάση `JuiceMaker`

Δημιούργησε την κλάση `JuiceMaker`.
Η κλάση έχει δύο ιδιότητες που θα της δοθούν επίσης:
- τη `capacity` σε χιλιοστόλιτρα (ως `Int`)
- μια `jug` (ως αντικείμενο `Jug`) που αντιπροσωπεύει την κανάτα που θα γεμίζει με τον χυμό από τη μηχανή

## 2. Επέκτεινε την κανάτα όταν η χωρητικότητα είναι πάνω από 1.000 χιλιοστόλιτρα

Όταν η χωρητικότητα είναι μεγαλύτερη από 1.000 χιλιοστόλιτρα, η κανάτα πρέπει να επεκταθεί ώστε να μπορεί να χωρέσει τον χυμό.
Ενημέρωσε την κλάση `JuiceMaker` ώστε να επεκτείνει την κανάτα (καλώντας τη συνάρτηση `extend` της κανάτας) όταν δημιουργείται με χωρητικότητα μεγαλύτερη από 1.000 χιλιοστόλιτρα.

## 3. Εγκατέστησε τον εκκινητή

Ορισμένα μοντέλα έχουν μια πολύ περίπλοκη διαδικασία εκκίνησης που θα χρειαζόταν πολλά χρόνια για να ολοκληρωθεί.
Ευτυχώς, έχουν δημιουργηθεί ειδικοί εκκινητές για να την επιταχύνουν.

Πρόσθεσε υποστήριξη για μοντέλα με περίπλοκες διαδικασίες εκκίνησης προσθέτοντας άλλον έναν κατασκευαστή που δέχεται επίσης ένα αντικείμενο `Starter`.
Ο κατασκευαστής θα πρέπει επίσης να καλεί τη συνάρτηση `install` του εκκινητή για να εγκατασταθεί στη μηχανή χυμών.

## 4. Πρόσθεσε μια συνάρτηση `start`

Πρόσθεσε μια συνάρτηση `start` που δέχεται μια ταχύτητα.
Η μηχανή χυμών θα συνεχίσει να λειτουργεί σε αυτή την ταχύτητα.

## 5. Πρόσθεσε μια συνάρτηση `stop`

Πρόσθεσε μια συνάρτηση `stop` για να σταματάς τη μηχανή χυμών.

## 6. Πρόσθεσε μια συνάρτηση `lightColor`

Το μηχάνημα έχει μια λυχνία που δείχνει σε ποια ταχύτητα λειτουργεί.
Το χρώμα της λυχνίας εξαρτάται από την ταχύτητα λειτουργίας:

| Ταχύτητα                | Χρώμα  |
|-------------------------|--------|
| Ανενεργή                | red    |
| μικρότερη ή ίση με 3    | green  |
| πάνω από 3              | yellow |

Πρόσθεσε μια συνάρτηση `lightColor` που επιστρέφει το χρώμα.

# 7. Κατασκεύασε με κοινή χωρητικότητα

Αφού κατασκεύασε πολλές μηχανές χυμών, ο Johanne παρατήρησε ότι μια συνηθισμένη χωρητικότητα είναι τα 1.500 χιλιοστόλιτρα.
Για να απλοποιήσεις αυτή τη ρύθμιση, υλοποίησε τη βοηθητική συνάρτηση `buildWithCommonCapacity`.
Η συνάρτηση θα πρέπει να οριστεί έξω από την κλάση `JuiceMaker`.
