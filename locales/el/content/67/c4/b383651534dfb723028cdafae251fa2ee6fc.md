# Οδηγίες

Μάθε τα βασικά για τους εσωτερικούς πίνακες της ABAP.

Η κλάση σου έχει έναν εσωτερικό πίνακα με το όνομα `initial_data`. Έχει τρεις στήλες: `GROUP`, `NUMBER` και `DESCRIPTION`.

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## Βήμα 1

Η πρώτη σου εργασία είναι να ολοκληρώσεις τη μέθοδο `fill_itab` και να τοποθετήσεις 6 καταγραφές σε αυτόν τον πίνακα με τις παρακάτω τιμές:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## Βήμα 2

Στη συνέχεια, υλοποίησε τη μέθοδο `add_to_itab` για να προσθέσεις μια καταγραφή στο τέλος του εσωτερικού πίνακα με την παρακάτω τιμή:

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## Βήμα 3

Τώρα ταξινόμησε τον εσωτερικό πίνακα στη μέθοδο `sort_itab` με τη στήλη `GROUP` σε αλφαβητική σειρά και τη στήλη `NUMBER` σε φθίνουσα σειρά.

## Βήμα 4

Στη μέθοδο `search_itab`, αναζήτησε στον ταξινομημένο πίνακα και επέστρεψε τη θέση της καταγραφής που έχει τιμή 6 στη στήλη `NUMBER`.
