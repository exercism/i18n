# Σχετικά

Η Elm είναι μια πλήρως συναρτησιακή γλώσσα, οπότε δεν υπάρχουν εντολές, μόνο εκφράσεις, και οι συναρτήσεις είναι πάντα μία μόνο έκφραση.

Αυτό ενθαρρύνει μικρές, απλές συναρτήσεις και είναι γενικά καλό, αλλά μερικές φορές οι συναρτήσεις είναι αναπόφευκτα πιο σύνθετες, και χρειαζόμαστε έναν τρόπο να διασφαλίσουμε ότι αυτές οι συναρτήσεις μπορούν να γραφτούν κομψά.

Εδώ μπαίνουν οι εκφράσεις `let` (έστω). Έχουν δύο μέρη: ένα τμήμα `let`, όπου μπορείς να δημιουργήσεις όσους ορισμούς χρειάζεσαι, και μετά ένα τμήμα `in`, που είναι μία μόνο έκφραση η οποία μπορεί να χρησιμοποιήσει αυτούς τους ορισμούς.

Με υπολογιστικούς όρους, το `let` δημιουργεί μια τοπική εμβέλεια για την έκφραση στο `in`.

Η έκφραση `let` είναι χρήσιμη σε μερικές περιπτώσεις:

- Για απλοποίηση εκφράσεων
- Για ονομασία των αποτελεσμάτων ενδιάμεσων εκφράσεων
- Για χωρισμό μιας έκφρασης σε μικρότερα κομμάτια αν μεγαλώνει

Μπορείς να κάνεις τα περισσότερα μέσα σε μια έκφραση `let`, συμπεριλαμβανομένης της αποδόμησης, ωστόσο τα παρακάτω δεν επιτρέπονται:

- Προσαρμοσμένοι τύποι
- Ψευδώνυμα τύπων
- Επισκίαση ονόματος (δε μπορείς να επαναπροσδιορίσεις / να επαναχρησιμοποιήσεις ένα όνομα που είναι ήδη στο πεδίο εμβέλειας)

## Απλοποίηση εκφράσεων

Αυτή η έκφραση προσθέτει τους κύβους τριών αριθμών, αλλά είναι δύσκολη στην ανάγνωση, και η πράξη θα μπορούσε εύκολα να διαφέρει για τους διαφορετικούς αριθμούς.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Μπορούμε να ορίσουμε μια συνάρτηση `cube` μέσα σε μια έκφραση `let` για να κάνουμε την πράξη πιο απλή, πιο εκφραστική και πιο ασφαλή. Αυτή η συνάρτηση θα μπορούσε να έχει έναν σχολιασμό τύπου, αλλά στον ιδιωματικό κώδικα Elm αυτό είναι σχετικά σπάνιο.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Ονομασία των αποτελεσμάτων των ενδιάμεσων εκφράσεων

Αυτός ο κώδικας ορίζει τα sideArea και topArea για να κάνει την πράξη πιο απλή και πιο εκφραστική.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Χωρισμός μιας μεγάλης έκφρασης

Αυτός ο κώδικας δημιουργεί ένα αρχικό μοτίβο για το [Game of Life](https://playgameoflife.com/) (μια συνηθισμένη άσκηση-παράδειγμα προγραμματισμού).

Δεν είναι σημαντικό να καταλάβεις ακριβώς πώς λειτουργεί, αλλά ελπίζουμε να είναι προφανές ότι θα ήταν πολύ μεγάλο αν γραφόταν ως μία μόνο έκφραση, χωρίς `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
