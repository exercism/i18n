# Προσάρτημα οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Υπάρχει μια ενσωματωμένη συνάρτηση που κάνει σχεδόν αυτή τη δουλειά για σένα, και δεν είναι ντροπή να τη χρησιμοποιήσεις.
(Φυσικά, δεν είναι ντροπή να χρησιμοποιήσεις και πλήρη/μακροσκελή κώδικα για να το λύσεις.)
Συμβουλή: η ενσωματωμένη συνάρτηση επιστρέφει `{1}` αντί για το `{}` που απαιτεί αυτή η άσκηση, και θα πρέπει να παρακάμψεις και τις δύο προεπιλεγμένες παραμέτρους για να επιστρέψει το σωστό.
