# Προσθήκη στις οδηγίες

## Μεταβλητά δεδομένα στην Prolog

Από προεπιλογή, οι τιμές στην Prolog είναι _αμετάβλητες_, που σημαίνει ότι οι τιμές δεν αλλάζουν ποτέ (θα χρειαστεί να εισαγάγεις μια νέα μεταβλητή για κάθε νέα τιμή).
Ενώ αυτό είναι εξαιρετικό για τη συντριπτική πλειοψηφία των περιπτώσεων χρήσης, αυτή η άσκηση _απαιτεί_ τη μεταβολή τιμών.
Για να μεταβάλεις δεδομένα στην Prolog, μπορείς να χρησιμοποιήσεις το κατηγόρημα [setarg].

[setarg]: https://www.swi-prolog.org/pldoc/doc_for?object=setarg/3
