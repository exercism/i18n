# Οδηγίες

Κάνεις εθελοντική εργασία στο κοινοτικό κέντρο τεχνών, όπου στήνεται ένα μακρύ μωσαϊκό από κεραμικά πλακίδια πάνω από την κεντρική είσοδο. Η ομάδα σχεδιασμού έχει οργανώσει τη δουλειά **σειρά σειρά**: κάθε σειρά είναι ένας πίνακας με χρώματα πλακιδίων και όλο το μωσαϊκό είναι ένας πίνακας από σειρές.

Καθώς οι εθελοντές κόβουν, τοποθετούν και αναδιατάσσουν πλακίδια, εσύ γράφεις μικρές, επαναχρησιμοποιήσιμες λέξεις για να φτιάχνεις, να συνδυάζεις και να εντοπίζεις κομμάτια του σχεδίου.

## 1. Μια λωρίδα με ένα πλακίδιο

Όρισε τη `tile-strip` ώστε να παίρνει ένα χρώμα και να επιστρέφει μια σειρά με ένα στοιχείο, που περιέχει μόνο αυτό το χρώμα.

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. Μια σειρά με τρία πλακίδια

Όρισε τη `row-of-three` ώστε να παίρνει τρία χρώματα από τη στοίβα και να επιστρέφει μια σειρά με 3 στοιχεία.

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. Συνδύασε τις σειρές σε μια επίπεδη λίστα πλακιδίων

Η ομάδα σχεδιασμού θέλει να κάνει έναν γρήγορο έλεγχο στα σύνολα χρωμάτων όλων των σειρών του μωσαϊκού. Όρισε τη `combine-rows` ώστε να παίρνει έναν πίνακα από σειρές και να επιστρέφει μία μόνο ακολουθία με όλα τα πλακίδια με τη σειρά.

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. Καθρέφτισε μια σειρά

Για τα συμμετρικά πάνελ, η ομάδα καθρεφτίζει μια σειρά πριν τοποθετήσει το αντίγραφό της στην απέναντι πλευρά. Όρισε τη `mirror-row` ώστε να επιστρέφει τη σειρά αντεστραμμένη.

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. Πού βρίσκεται αυτό το χρώμα στη σειρά;

Όρισε τη `tile-position` ώστε να παίρνει μια σειρά και ένα χρώμα και να επιστρέφει τη θέση (με βάση το 0) του πρώτου πλακιδίου με αυτό το χρώμα στη σειρά. Αν το χρώμα δεν υπάρχει, επίστρεψε `f`.

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. Περιέχει αυτή η σειρά το χρώμα;

Όρισε τη `has-colour?` ώστε να παίρνει μια σειρά και ένα χρώμα και να επιστρέφει `t` αν το χρώμα εμφανίζεται οπουδήποτε στη σειρά, αλλιώς `f`.

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
