# Εισαγωγή

## Βρόχοι

Με τους βρόχους εκτελείς κάποια λογική επανειλημμένα.
Οι δύο πιο συνηθισμένοι τύποι είναι ο `while loop` (αόριστη επανάληψη) και ο `for loop` (ορισμένη ή μετρημένη επανάληψη).
Υπάρχει επίσης ο βρόχος `for each`, που θα συναντήσεις σε επόμενη έννοια.

### Γενική σύνταξη

Ο `for loop` αποτελείται από μια κεφαλίδα και ένα μπλοκ κώδικα που περιέχει το σώμα του βρόχου μέσα σε άγκιστρα.
Η κεφαλίδα αποτελείται από 3 στοιχεία που χωρίζονται με άνω τελείες `;`: τη δήλωση αρχικοποίησης, τη συνθήκη και μια ακόμη έκφραση.
Καθένα από αυτά μπορεί να είναι κενό.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- Το στοιχείο **init_statement** είναι κώδικας που εκτελείται μόνο μία φορά πριν ξεκινήσει ο βρόχος.
- Το στοιχείο **condition** πρέπει να είναι μια έκφραση που αποτιμάται σε `boolean` και ελέγχει πότε πρέπει να σταματήσει ο βρόχος.
  Ο κώδικας μέσα στον βρόχο θα εκτελείται όσο αυτή η συνθήκη αποτιμάται σε `true`.
  Μόλις αυτή η έκφραση αποτιμηθεί σε `false`, δεν θα εκτελεστεί άλλη επανάληψη του βρόχου.
- Το στοιχείο **expression** είναι κώδικας που θα εκτελείται στο τέλος κάθε επανάληψης.

Ο `while loop` εκτελεί το σώμα του όσο ο έλεγχος της **συνθήκης** του είναι `true`.
Το παρακάτω απόσπασμα κώδικα δείχνει πώς να μετατρέψεις έναν `for` σε `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Παρένθεση: Αυξήσεις και μειώσεις

Όταν δουλεύεις με βρόχους, συχνά χρειάζεται να προσθέσεις 1 ή να αφαιρέσεις 1 από μια μεταβλητή μετρητή που παρακολουθεί τις επαναλήψεις.
Αυτό είναι τόσο συνηθισμένο, που οι ενέργειες αύξησης/μείωσης έχουν ειδικούς τελεστές: `++` και `--`.

Υπάρχουν σε **προθεματική** και σε **επιθεματική** μορφή.
Η προθεματική μορφή αλλάζει τη μεταβλητή πριν από τη χρήση της στην εντολή και η επιθεματική μετά.
Τις περισσότερες φορές μάλλον θέλεις την προθεματική μορφή.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Βρόχοι for - Ένα παράδειγμα

Το _μέρος init_ συνήθως ορίζει μια μεταβλητή μετρητή, η _συνθήκη_ ελέγχει αν ο βρόχος πρέπει να συνεχιστεί ή να σταματήσει και το _μέρος post_ συνήθως αυξάνει τον μετρητή στο τέλος κάθε επανάληψης.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Αυτός ο βρόχος θα αθροίσει τους αριθμούς από το `1` έως το `9` (συμπεριλαμβανομένου του `9`).

### break και continue

Μέσα στο σώμα ενός βρόχου, μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `break` για να σταματήσεις εντελώς την εκτέλεση του βρόχου:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Αντίθετα, η λέξη-κλειδί `continue` σταματά μόνο την εκτέλεση της τρέχουσας επανάληψης και συνεχίζει με την επόμενη:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Συνήθως είναι πιο εύκολο να καταλάβεις τη λογική του βρόχου, όταν η χρήση των `break` και `continue` περιορίζεται στο ελάχιστο ή αποφεύγεται εντελώς.
Και οι δύο λέξεις-κλειδιά παρακάμπτουν ορισμένα σημεία του κώδικα και συχνά κάνουν πιο δύσκολο να παρακολουθήσεις τη ροή.
~~~~
