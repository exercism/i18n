# Οδηγίες

Σε αυτή την άσκηση θα γράφεις κώδικα για να εκτυπώνεις ετικέτες ονόματος για τους εργαζόμενους ενός εργοστασίου. 
Οι εργαζόμενοι έχουν ένα αναγνωριστικό, ένα όνομα και το όνομα του τμήματός τους. 
Οι ετικέτες των εργαζομένων έχουν την εξής μορφή: `"[id] - name - DEPARTMENT"`.

## 1. Εκτύπωσε μια ετικέτα για έναν εργαζόμενο

Υλοποίησε τη συνάρτηση `print_name_badge`. Θα πρέπει να δέχεται ένα αναγνωριστικό, ένα όνομα και ένα τμήμα.
Θα πρέπει να επιστρέφει την ετικέτα, με το όνομα του τμήματος σε κεφαλαία.

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Εκτύπωσε μια ετικέτα για έναν νέο εργαζόμενο

Λόγω μιας ιδιορρυθμίας του υπολογιστικού συστήματος, οι νέοι εργαζόμενοι μερικές φορές δεν έχουν ακόμη αναγνωριστικό όταν ξεκινούν να δουλεύουν στο εργοστάσιο. 
Επειδή οι ετικέτες είναι υποχρεωτικές, θα παίρνουν μια προσωρινή ετικέτα χωρίς το πρόθεμα του αναγνωριστικού.

Επέκτεινε τη συνάρτηση `print_name_badge`. Όταν λείπει το αναγνωριστικό, θα πρέπει να εκτυπώνει μια ετικέτα χωρίς αυτό.

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Εκτύπωσε μια ετικέτα για τον ιδιοκτήτη

Ακόμη και ο ιδιοκτήτης του εργοστασίου πρέπει να φοράει ετικέτα συνέχεια. 
Ωστόσο, ο ιδιοκτήτης δεν έχει τμήμα και ούτε πρόκειται να αποκτήσει: είναι πάνω από όλα τα τμήματα. 
Σε αυτή την περίπτωση, η ετικέτα θα πρέπει να εκτυπώνει `"OWNER"` αντί για το όνομα του τμήματος.

Επέκτεινε τη συνάρτηση `print_name_badge`. Όταν το τμήμα είναι `NULL`, υπέθεσε ότι η ετικέτα ανήκει στον ιδιοκτήτη της εταιρείας.

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

Σημείωσε ότι είναι πιθανό ο ιδιοκτήτης να είναι και νέος εργαζόμενος.

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. Υπολόγισε τον συνολικό μισθό των εργαζομένων χωρίς αναγνωριστικό

Ως έναν πρόχειρο δείκτη του πόσο καλά εκδίδονται τα αναγνωριστικά, θέλεις να δεις τον συνολικό μισθό των εργαζομένων που δεν έχουν αναγνωριστικό. 
Μια υψηλή τιμή σημαίνει ότι πολλοί περιμένουν ή ότι το πρόβλημα αγγίζει ανθρώπους με προϋπηρεσία: και τα δύο είναι άσχημα.

Υλοποίησε τη συνάρτηση `salaries_no_id` που δέχεται ένα διάνυσμα αναγνωριστικών και ένα αντίστοιχο διάνυσμα μισθών, και επιστρέφει το άθροισμα των μισθών των ανθρώπων που δεν έχουν ακόμη αναγνωριστικό. 
Και τα δύο διανύσματα έχουν το ίδιο μήκος.

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```

_Ως επιπλέον μάθηση που δεν ελέγχεται:_ Αν δεν υπάρχουν εργαζόμενοι χωρίς αναγνωριστικό, ποιο είναι το "κενό διάνυσμα" που αθροίζεις;
