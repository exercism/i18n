# Παράρτημα οδηγιών

# Είσοδος

Η είσοδος για αυτήν την άσκηση αποτελείται από:

- `target`: Μια συμβολοσειρά (π.χ., `'stone'`) που θα είναι το _αριστερό όρισμα_.
- `candidates`: Μια λίστα από συμβολοσειρές σε πλαίσια (π.χ., `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) που θα είναι το _δεξί όρισμα_.

Το ρήμα σου θα καλείται ως εξής:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Έξοδος

Το ρήμα σου θα πρέπει να επιστρέφει μια _λίστα_ από πλαίσια που περιέχουν τις συμβολοσειρές που είναι αναγράμματα του target. Αν δεν υπάρχουν αναγράμματα, το αποτέλεσμα θα πρέπει να είναι `empty`.
