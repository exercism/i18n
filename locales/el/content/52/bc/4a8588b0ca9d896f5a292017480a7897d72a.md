# Οδηγίες

Στο παιχνίδι με κάρτες Spellbound Steel, έχεις μια τράπουλα με κάρτες που έχουν είτε διαφορετικούς χαρακτήρες, όπως warriors, mages και rogues, είτε διαφορετικά ξόρκια, όπως fireball, ice storm και lightning bolt.
Στο παιχνίδι παίζουν δύο έως τέσσερις παίκτες και ο στόχος είναι να νικήσεις τους άλλους παίκτες παίζοντας κάρτες με υψηλότερα επίπεδα ισχύος.

Θέλεις να αποκτήσεις το πάνω χέρι στο παιχνίδι δημιουργώντας διάφορες μεθόδους για να υπολογίζεις, να ταξινομείς και να συγκρίνεις τα επίπεδα ισχύος των καρτών.

## 1. Βρες κάρτα στην τράπουλα

Δεν είσαι σίγουρος αν μια κάρτα βρίσκεται στην τράπουλα ή όχι.
Γι' αυτό θέλεις μια μέθοδο που να σου λέει πού μπορείς να βρεις την πρώτη κάρτα στην τράπουλα του είδους που ψάχνεις.
Ή, αν η κάρτα δεν βρίσκεται στην τράπουλα, θέλεις να το ξέρεις κι αυτό.

Υλοποίησε μια μέθοδο `SpellboundSteel.find_card?` που παίρνει έναν `Array` από `String` κάρτες και μια `String` κάρτα προς εύρεση.
Η μέθοδος πρέπει να επιστρέφει τη θέση της πρώτης κάρτας στην τράπουλα που ταιριάζει με την κάρτα προς εύρεση.
Αν η κάρτα δεν βρίσκεται στην τράπουλα, η μέθοδος πρέπει να επιστρέφει `nil`.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. Κάνε όλους τους χαρακτήρες κεφαλαίους

Για να γίνουν οι κάρτες πιο ευανάγνωστες, θέλεις να μετατρέψεις όλους τους χαρακτήρες στα ονόματα των καρτών σε κεφαλαίους.
Έτσι θα βλέπεις εύκολα τα ονόματα των καρτών όταν παίζεις τις κάρτες.

Υλοποίησε μια μέθοδο `SpellboundSteel.capitalize_cards` που παίρνει έναν `Array` από `String` κάρτες και επιστρέφει τις κάρτες με όλους τους χαρακτήρες κεφαλαίους.

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. Υπολόγισε το επίπεδο ισχύος όλων των καρτών

Στο παιχνίδι είναι σημαντικό να υπολογίζεις το επίπεδο ισχύος όλων των καρτών.
Η ισχύς όλων των καρτών φαίνεται στον παρακάτω πίνακα:

| Τύπος κάρτας   | Επίπεδο ισχύος |
|----------------|----------------|
| Warrior        | 10             |
| Mage           | 20             |
| Rogue          | 30             |
| Fireball       | 15             |
| Ice Storm      | 25             |
| Lightning Bolt | 35             |

Υλοποίησε μια μέθοδο `SpellboundSteel.calculate_power_level` που παίρνει έναν `Array` από `String` κάρτες και επιστρέφει το συνολικό επίπεδο ισχύος όλων των καρτών.

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. Αποκωδικοποίησε μια κάρτα

Στο παιχνίδι υπάρχουν οι λεγόμενες καταραμένες κάρτες.
Αυτές οι κάρτες είναι κρυφές κάρτες που μπορεί να τις αποκωδικοποιήσει μόνο ο παίκτης που τις έπαιξε.
Για να αποκωδικοποιήσεις την κάρτα, πρέπει να πάρεις κάθε δεύτερο χαρακτήρα στο όνομα της κάρτας και να τον αφαιρέσεις.
Έτσι θα πάρεις το όνομα της κάρτας.

Υλοποίησε μια μέθοδο `SpellboundSteel.decode_card` που παίρνει μια `String` κάρτα και επιστρέφει την αποκωδικοποιημένη κάρτα.

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
