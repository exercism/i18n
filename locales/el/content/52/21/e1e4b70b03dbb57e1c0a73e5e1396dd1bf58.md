# Σχετικά

Ο τύπος `Option` είναι ο μηχανισμός της γλώσσας F# για τον χειρισμό τιμών που μπορεί να υπάρχουν ή να μην υπάρχουν.
Παρέχει μια ασφαλή ως προς τον τύπο εναλλακτική στη χρήση του `null`, η οποία είναι συνηθισμένη σε άλλες γλώσσες για τον χειρισμό τέτοιων τιμών.
Χρησιμοποιείται σε πολλές συναρτήσεις της βασικής βιβλιοθήκης της F#, οπότε η κατανόησή του είναι απαραίτητη για την αποτελεσματική χρήση της βασικής βιβλιοθήκης της F#.

## Τα πλεονεκτήματα της χρήσης του τύπου `Option`

* __Ασφάλεια κατά τη μεταγλώττιση__: Κάνοντας την παρουσία ή την απουσία μιας τιμής ρητή στο σύστημα τύπων, ο μεταγλωττιστής μπορεί να εξασφαλίσει ότι χειρίζεσαι την περίπτωση της "απουσίας τιμής", αποτρέποντας μια μεγάλη κατηγορία bugs που θα μπορούσαν να προκύψουν με τα null.

* __Ασφάλεια κατά την εκτέλεση__: Αντί να χρησιμοποιεί `null`, η F# χρησιμοποιεί το `None` για να αναπαραστήσει την απουσία μιας τιμής, καθιστώντας αδύνατη την εμφάνιση μιας `NullReferenceException`.

* __Επιβάλλει ρητό χειρισμό__: Το σύστημα τύπων απαιτεί από τον κώδικα να χειρίζεται ρητά και τις δύο περιπτώσεις, του `Some value` και του `None`, κάνοντας τον κώδικά σου πιο ανθεκτικό και προβλέψιμο.

* __Λειτουργεί με την αντιστοίχιση προτύπων__: Τα `Option` λειτουργούν άψογα με το ιδίωμα αντιστοίχισης προτύπων της F#, παρέχοντας έναν καθαρό και ασφαλή τρόπο να αποδομήσεις και να χειριστείς την τιμή αν υπάρχει, ή να κάνεις κάτι άλλο αν δεν υπάρχει.

## Χρήση 

Ο τύπος `Option` είναι ένας γενικός τύπος (έχει έναν υποκείμενο τύπο).  
Οι τιμές `Option` είναι είτε `Some value`, που αναπαριστά κάποια συγκεκριμένη τιμή, είτε `None`, που αναπαριστά την απουσία τιμής.

Η παρακάτω συνάρτηση δείχνει πώς να δημιουργήσεις μια τιμή `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
Το `T option` είναι η ισοδύναμη σύνταξη με επίθεμα για το `Option<T>`; και οι δύο μορφές σύνταξης μπορούν να χρησιμοποιηθούν εναλλάξ.
Ωστόσο, σύμφωνα με τον F# Style Guide, η σύνταξη με επίθεμα προτιμάται για τους τύπους Option (δείτε [ενότητα του F# Style Guide για τη μορφοποίηση τύπων και υποδείξεων τύπων](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

Μια τυπική περίπτωση χρήσης ενός `Option` είναι οι συναρτήσεις αναζήτησης. 
Για παράδειγμα, η συνάρτηση `List.tryFind` επιστρέφει `Some index` όταν το στοιχείο βρίσκεται στη λίστα (όπου `index` είναι η θέση της ζητούμενης τιμής στη λίστα), ή `None` όταν το στοιχείο δεν βρίσκεται στη λίστα.

## Πώς να διαβάσεις το περιεχόμενο μιας τιμής Option

Ο ιδιωματικός τρόπος για να διαβάσεις μια τιμή `Option` είναι μέσω αντιστοίχισης προτύπων, όπως φαίνεται στο παρακάτω παράδειγμα:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Ξετυλίγοντας τα Option με προεπιλεγμένες τιμές

Τα `Option` μπορούν να "ξετυλιχτούν" (να μετατραπούν στον τύπο που περιέχουν) παρέχοντας προεπιλεγμένες τιμές με τη συνάρτηση `Option.defaultValue`. 
Αυτό είναι ιδιαίτερα χρήσιμο όταν θέλεις να εξασφαλίσεις ότι η τιμή δεν είναι `None`.
Για παράδειγμα:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Περισσότερες συναρτήσεις στο module `Option`

Το module `Option` περιλαμβάνει επίσης συναρτήσεις που αντιστοιχούν σε αυτές που είναι διαθέσιμες για λίστες, πίνακες, ακολουθίες και άλλους τύπους συλλογών, όπως οι `Option.map`, `Option.iter`, `Option.forall`, `Option.count`. 
Αυτές οι συναρτήσεις επιτρέπουν στα `Option` να αντιμετωπίζονται σαν συλλογή με μηδέν ή ένα στοιχείο.
