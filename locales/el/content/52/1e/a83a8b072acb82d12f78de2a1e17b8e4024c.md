# Τεστ

Τρέξε τα τεστ με `exercism test` ή `eutest`. Από προεπιλογή εκτελούνται όλα τα τεστ.

## Παράλειψη τεστ

Ένας καλός τρόπος για να ξεκινήσεις είναι να σχολιάσεις όλα τα τεστ εκτός από το πρώτο στο `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Δούλεψέ τα ένα ένα, βγάζοντας από τα σχόλια το επόμενο τεστ μόλις περάσει το τρέχον.
Όταν περνούν όλα τα τεστ, έχεις ολοκληρώσει την άσκηση.
