# Μυστικός Πράκτορας

## Ιστορία

Γεια σου, Πράκτορα Double-Null0111.

Η αποστολή σου, αν επιλέξεις να την αποδεχτείς, είναι να γράψεις ένα ζευγάρι εργαλεία που θα σε βοηθήσουν να παρεισφρήσεις στο αρχηγείο της UMBRA (Ενωμένοι Υπηρέτες που Είναι Πραγματικά Απαίσιοι) και να ανακτήσεις τα σχέδια για το τελευταίο, πραγματικά απαίσιο σχέδιό τους. Θα χρειαστείς δύο εργαλεία για να φέρεις εις πέρας αυτή την αποστολή.

## Εργασίες

Η ιστορία διευκολύνει τον ορισμό [συναρτήσεων υψηλότερης τάξης][concepts-higher_order_functions], συμπεριλαμβανομένων μιας συνάρτησης που δέχεται μια συνάρτηση ως είσοδο και μιας συνάρτησης που επιστρέφει μια συνάρτηση ως έξοδο:

- Δημιούργησε έναν συνδυασμό για να ανοίξεις το χρηματοκιβώτιό τους
- Προστάτευσε τα μυστικά σχέδια που ανέκτησες με έναν κωδικό πρόσβασης
