# Σχετικά

Το Factor χωρίζει το I/O των ροών σε δύο επίπεδα. Το κατώτερο επίπεδο είναι το API *explicit-stream*: κάθε λέξη παίρνει τη ροή ως όρισμα. Το ανώτερο επίπεδο είναι το API *ambient-stream*: σύντομες λέξεις μιας γραμμής που δρουν στη ροή που είναι δεσμευμένη εκείνη τη στιγμή. Και τα δύο επίπεδα στηρίζονται στο ίδιο [πρωτόκολλο][stream-protocol], και οι λέξεις του ανώτερου επιπέδου απλώς αναζητούν τη ροή περιβάλλοντος και προωθούν την κλήση.

## Οι λέξεις του explicit-stream

```
stream-read       ( n stream -- seq/f )
stream-read1      ( stream -- elt/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-write1     ( elt stream -- )
stream-print      ( str stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Το `stream-contents` αδειάζει τα πάντα· το `stream-lines` αδειάζει και χωρίζει στα όρια των γραμμών· το `stream-readln` επιστρέφει μία γραμμή κάθε φορά (ή `f` στο τέλος της ροής).

## Οι λέξεις του ambient-stream

```
read1   ( -- elt/f )
read    ( n -- seq/f )
readln  ( -- str/f )
write   ( seq -- )
write1  ( elt -- )
print   ( str -- )
flush   ( -- )
```

Αυτές είναι οι καθημερινές λέξεις I/O. Αναζητούν την τρέχουσα ροή εισόδου ή εξόδου στις δυναμικές μεταβλητές `input-stream` / `output-stream` και προωθούν την κλήση. Γι' αυτό η ανακατεύθυνση του `print` σε μια συμβολοσειρά είναι απλώς θέμα δέσμευσης του `output-stream` για όσο διαρκεί μια παράθεση.

## Ενσωματωμένοι κατασκευαστές ροών

| λέξη              | λεξιλόγιο            | τι κατασκευάζει                 |
|-------------------|----------------------|---------------------------------|
| `<string-reader>` | [`io.streams.string`][io.streams.string]  | διαβάζει μια κυριολεκτική συμβολοσειρά |
| `<string-writer>` | [`io.streams.string`][io.streams.string]  | συλλέγει τις εγγραφές σε μια συμβολοσειρά |
| `<file-reader>`   | [`io.files`][io.files]           | διαβάζει ένα αρχείο με κωδικοποίηση |
| `<file-writer>`   | [`io.files`][io.files]           | γράφει ένα αρχείο με κωδικοποίηση |

Και τα τέσσερα παράγουν αντικείμενα που αποδεσμεύονται: επεκτείνουν το `disposable` από το `destructors`, οπότε οι παρακάτω συνδυαστές `with-…` τα αποδεσμεύουν κατά την έξοδο.

## Δέσμευση με εμβέλεια

```
with-input-stream   ( stream quot -- )
with-output-stream  ( stream quot -- )
with-string-reader  ( str quot -- )
with-string-writer  ( quot -- str )
with-file-reader    ( path encoding quot -- )
with-file-writer    ( path encoding quot -- )
```

Κάθε ένα ανοίγει μια ροή, τη δεσμεύει ως την τρέχουσα ροή εισόδου ή εξόδου για την εσωτερική παράθεση και την αποδεσμεύει κατά την έξοδο, ακόμη και αν η παράθεση πετάξει ένα σφάλμα. Είναι οι συνδυαστές αποδέσμευσης του `boatswains-bilge`, ειδικευμένοι στις ροές.

Το `with-string-writer` είναι μια ιδιαίτερα καθαρή παραλλαγή: κατασκευάζει αυτόματα ένα καινούριο `<string-writer>`, εκτελεί την παράθεση με αυτόν τον εγγραφέα ως την τρέχουσα έξοδο και επιστρέφει τη συμβολοσειρά που συσσωρεύτηκε. Όλο το μοτίβο "καταγραφή της εξόδου μιας παράθεσης" είναι μία λέξη.

```factor
USING: io io.streams.string ;

[ "alpha" print "bravo" print ] with-string-writer .
! => "alpha\nbravo\n"
```

## Γιατί να υπάρχει το ambient;

Η δέσμευση δυναμικής μεταβλητής είναι ο λόγος που το `print` λειτουργεί σε ένα πρόγραμμα που δεν ξέρει αν εκτελείται διαδραστικά, μέσα σε ένα αρχείο καταγραφής ή μέσα σε ένα καταγεγραμμένο buffer δοκιμών. Αλλάζεις τη δέσμευση μία φορά και κάθε λέξη που καλεί το `print` κάνει το σωστό, χωρίς να χρειάζεται καμία επανασύνδεση. Αυτή είναι η αντιστροφή που σου προσφέρει το ανώτερο επίπεδο.

Για να *υλοποιήσεις* μια ροή, δηλαδή να ορίσεις τη δική σου κλάση που συνδέεται με το πρωτόκολλο, δες την έννοια `streams` (που διδάσκεται στο `telegraphers-tape`).
