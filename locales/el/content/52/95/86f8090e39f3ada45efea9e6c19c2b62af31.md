# Συνθήκες

Η Ruby έχει αυτό που ονομάζουμε εκφράσεις ελέγχου ροής. Αυτές χρησιμοποιούνται για να ελέγχουν τον τρόπο με τον οποίο θα τρέξει το πρόγραμμα και παίρνουν μια τιμή truthy ή falsey.
Υπάρχουν τελεστές που μπορούν να χρησιμοποιηθούν για να δημιουργήσουν τιμές truthy ή falsey και είναι γνωστοί ως [τελεστές σύγκρισης][comparison-operators].

Υπάρχουν δύο βασικές εκφράσεις ελέγχου που χρησιμοποιούνται για να καθορίσουν ποιος κώδικας θα εκτελεστεί και ποιος όχι.
Δηλαδή, ποιος κλάδος από αυτούς θα εκτελεστεί.

Αυτές οι δύο είναι: η έκφραση `if` και η έκφραση `unless`.

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] χρησιμοποιούνται για να συγκρίνουν τιμές και να επιστρέφουν την τιμή `true` ή `false`.
Οι παρακάτω τελεστές απαιτούν δύο τιμές του ίδιου τύπου για να συγκριθούν.
Αν οι τιμές δεν είναι του ίδιου τύπου, τότε ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Ακολουθεί μια λίστα με τους τελεστές και ένα παράδειγμα όπου δίνουν την τιμή `true`:

| Τελεστής | Περιγραφή             | Παράδειγμα |
| -------- | --------------------- | ---------- |
| <        | μικρότερο από         | 4 < 5      |
| <=       | μικρότερο ή ίσο με    | 4 <= 4     |
| >        | μεγαλύτερο από        | 3 > 1      |
| >=       | μεγαλύτερο ή ίσο με   | 2 >= 2     |

Οι τελεστές ισότητας και ανισότητας μπορούν να χρησιμοποιηθούν για τη σύγκριση οποιουδήποτε τύπου τιμής, σε αντίθεση με τους τελεστές που αναφέρθηκαν ήδη.
Ο τελεστής `==` χρησιμοποιείται για να ελέγξει αν δύο τιμές είναι ίσες, και αυτό περιλαμβάνει τον έλεγχο του τύπου της τιμής.
Ο `!=` λειτουργεί με τον ίδιο τρόπο, αλλά θα επιστρέψει `true` αν οι τιμές δεν είναι ίσες και `false` αν είναι ίσες.
Ακολουθεί μια λίστα με τους τελεστές ισότητας και ανισότητας και ένα παράδειγμα όπου δίνουν την τιμή `true`:

| Τελεστής | Περιγραφή | Παράδειγμα |
| -------- | --------- | ---------- |
| ==       | ίσο       | 4 == 4     |
| !=       | διάφορο   | 5 != 4     |

## Η εντολή `if`

Η εντολή [`if`][if] χρησιμοποιείται για να ελέγξει αν μια δεδομένη συνθήκη είναι "truthy" ή "falsey".
Αν η συνθήκη είναι truthy, τότε ο κώδικας μέσα στην εντολή `if` θα εκτελεστεί.
Μια εντολή `if` τελειώνει με τη λέξη-κλειδί `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Η εντολή `unless`

Η εντολή `unless` λειτουργεί με πολύ παρόμοιο τρόπο με την εντολή `if`, αλλά θα εκτελέσει τον κώδικα μέσα στην εντολή `unless` αν η συνθήκη είναι falsey.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Η εντολή `else`

Η εντολή `else` μπορεί να χρησιμοποιηθεί σε συνδυασμό με την εντολή `if`.
Η εντολή `else` θα εκτελεστεί αν ο κλάδος `if` δεν εκτελεστεί.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Οι εντολές "cascading-if"

Η εντολή `elsif` μπορεί να χρησιμοποιηθεί σε συνδυασμό με την εντολή `if`.
Η εντολή `elsif` θα εκτελεστεί αν ο κλάδος `if` δεν εκτελεστεί και η συνθήκη της εντολής `elsif` είναι truthy.
Οι εντολές `elsif` μπορούν να αλυσιδωθούν μεταξύ τους και θα εκτελεστεί η πρώτη συνθήκη που είναι truthy.
Μπορεί επίσης να υπάρχει μια εντολή `else` στο τέλος της εντολής `if`, η οποία θα εκτελεστεί αν καμία από τις προηγούμενες εντολές δεν ήταν αληθής.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
