# Οδηγίες

Σε αυτή την άσκηση θα γράφεις κώδικα για να βοηθήσεις έναν freelancer να συνεννοηθεί με έναν υπεύθυνο έργου.
Το καθήκον σου είναι να παρέχεις μερικά βοηθητικά εργαλεία για να υπολογίζεις γρήγορα τις ημερήσιες και τις μηνιαίες χρεώσεις, προαιρετικά με μια δεδομένη έκπτωση.

Πρώτα ορίζουμε μερικούς κανόνες ανάμεσα στον freelancer και στον υπεύθυνο έργου:

- Η ημερήσια χρέωση είναι 8 φορές η ωριαία χρέωση.
- Ένας μήνας έχει 22 τιμολογήσιμες ημέρες.

Μερικές φορές, ο freelancer προσφέρεται να εφαρμόσει έκπτωση στην ημερήσια χρέωσή του (για παράδειγμα για τους πιο πιστούς πελάτες του ή για πελάτες μη κερδοσκοπικών οργανισμών).

Οι εκπτώσεις αναπαριστώνται ως δεκαδικοί αριθμοί που αντιπροσωπεύουν ποσοστά, για παράδειγμα, `25.0` (25%).

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

Υλοποίησε μια συνάρτηση με το όνομα `dailyRateFrom` για να υπολογίσεις την ημερήσια χρέωση, με δεδομένη την ωριαία χρέωση ως παράμετρο.
Το συμβόλαιο ορίζει ότι μια ημέρα έχει 8 τιμολογήσιμες ώρες.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι `Double`.

## 2. Υπολόγισε τη μηνιαία χρέωση, με δεδομένες την ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση `monthlyRateFrom` για να υπολογίσεις τη μηνιαία χρέωση με έκπτωση.
Παίρνει δύο παραμέτρους, μια ωριαία χρέωση και την έκπτωση σε ποσοστό.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

Η μηνιαία χρέωση που επιστρέφεται πρέπει να είναι στρογγυλοποιημένη προς τα πάνω (να παίρνεις την οροφή) στον πλησιέστερο ακέραιο.

## 3. Υπολόγισε τον αριθμό των πλήρων εργάσιμων ημερών με δεδομένα έναν προϋπολογισμό, την ωριαία χρέωση και την έκπτωση

Υλοποίησε μια συνάρτηση `workdaysIn` που παίρνει έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση, και υπολογίζει πόσες πλήρεις ημέρες εργασίας καλύπτονται.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
Ο αριθμός των ημερών που επιστρέφεται πρέπει να είναι στρογγυλοποιημένος προς τα κάτω (να παίρνεις το δάπεδο) στον αμέσως μικρότερο ακέραιο.
