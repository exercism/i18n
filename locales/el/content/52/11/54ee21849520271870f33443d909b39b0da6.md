# Εισαγωγή

Χρησιμοποιούμε τους βρόχους για να εκτελούμε κάποια λογική επανειλημμένα.
Οι δύο πιο συνηθισμένοι τύποι είναι ο `while loop` (αόριστη επανάληψη) και ο `for loop` (ορισμένη ή μετρημένη επανάληψη).
Υπάρχει επίσης ο βρόχος `for each`, που θα εμφανιστεί σε επόμενη έννοια.


## Γενική σύνταξη

Ο `for loop` αποτελείται από μια κεφαλίδα και ένα μπλοκ κώδικα που περιέχει το σώμα του βρόχου, μέσα σε άγκιστρα.
Η κεφαλίδα αποτελείται από 3 συνιστώσες που χωρίζονται με το σύμβολο `;`: αρχικοποίηση, συνθήκη και μια ακόμη έκφραση.
Κάθε μία από αυτές μπορεί να είναι κενή.

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- Η συνιστώσα **αρχικοποίησης** είναι κώδικας που εκτελείται μόνο μία φορά, πριν ξεκινήσει ο βρόχος.
- Η συνιστώσα **συνθήκης** πρέπει να είναι μια έκφραση που αξιολογείται σε Boolean και ελέγχει πότε πρέπει να σταματήσει ο βρόχος.
Ο κώδικας μέσα στον βρόχο θα εκτελείται όσο αυτή η συνθήκη αξιολογείται ως αληθής.
Μόλις αυτή η έκφραση αξιολογηθεί ως ψευδής, δεν θα εκτελεστούν άλλες επαναλήψεις του βρόχου.
- Η συνιστώσα **έκφρασης** είναι κώδικας που εκτελείται στο τέλος κάθε επανάληψης.


Ο `while loop` εκτελεί το σώμα του όσο ο έλεγχος της συνθήκης του είναι αληθής.
Το παρακάτω απόσπασμα κώδικα δείχνει πώς μετατρέπεται ένας βρόχος for σε βρόχο while.

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## Ενδιάμεσο: Αυξήσεις και μειώσεις

Όταν δουλεύεις με βρόχους, χρειάζεται συχνά να προσθέσεις ή να αφαιρέσεις 1 από μια μεταβλητή μετρητή.
Αυτό είναι τόσο συνηθισμένο, που η πράξη έχει ειδικούς τελεστές: `++` και `--`.

Υπάρχουν σε μορφή προθέματος και σε μορφή επιθέματος.
Η μορφή προθέματος αλλάζει τη μεταβλητή πριν από τη χρήση της στην εντολή, και η μορφή επιθέματος μετά.
Τις περισσότερες φορές μάλλον θέλεις τη μορφή προθέματος.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## Βρόχοι for - Ένα παράδειγμα

Η συνιστώσα αρχικοποίησης συνήθως δημιουργεί μια μεταβλητή μετρητή, η συνθήκη ελέγχει αν ο βρόχος πρέπει να συνεχιστεί ή να σταματήσει, και η τελική συνιστώσα συνήθως αυξάνει τον μετρητή στο τέλος κάθε επανάληψης.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Αυτός ο βρόχος θα αθροίσει τους αριθμούς από το `1` ως το `9` (συμπεριλαμβανομένου του `9`).

## Break και Continue

Μέσα στο σώμα ενός βρόχου, μπορείς να χρησιμοποιήσεις τη λέξη-κλειδί `break` για να σταματήσεις εντελώς την εκτέλεση του βρόχου:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

Αντίθετα, η λέξη-κλειδί `continue` σταματά μόνο την εκτέλεση της τρέχουσας επανάληψης και συνεχίζει με την επόμενη:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> Σημείωση: συνήθως είναι πιο εύκολο να καταλάβεις τη λογική του βρόχου, όταν η χρήση των `break` και `continue` περιορίζεται στο ελάχιστο ή αποφεύγεται εντελώς.
