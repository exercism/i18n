# Σχετικά

Ένα [C# `Attribute`][attribute-concept] παρέχει έναν τρόπο να διακοσμήσεις μια δήλωση ώστε να της συσχετίσεις μεταδεδομένα: μια κλάση, μια μέθοδο, μια απαρίθμηση, ένα πεδίο, μια ιδιότητα ή οποιαδήποτε [άλλη υποστηριζόμενη][attribute-targets] δήλωση.

Μπορείς να εφαρμόσεις [ένα χαρακτηριστικό][attribute] σε μια δήλωση προσθέτοντάς το μέσα σε αγκύλες `[]` πριν από τη δήλωση. Το παρακάτω παράδειγμα χρησιμοποιεί και ένα `ClassAttribute` και ένα `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Τα δηλωτικά μεταδεδομένα απλώς συσχετίζουν επιπλέον δομημένες πληροφορίες με τον κώδικα και δεν τροποποιούν τη συμπεριφορά του, αλλά αυτά τα μεταδεδομένα χρησιμοποιούνται από άλλα μέρη του κώδικα για να αλλάξουν τη συμπεριφορά του στόχου τους ή για να προσθέσουν, να αλλάξουν, να αφαιρέσουν ή να περιορίσουν κάποιες από τις λειτουργίες του.

Υπάρχουν πολλά προκαθορισμένα χαρακτηριστικά, όπως τα: `Flags`, `Obsolete`, `Conditional`. Σημείωσε ότι το πλήρες όνομα του [χαρακτηριστικού `Flags`][flags-attribute] είναι `FlagsAttribute`, αλλά το επίθημα "Attribute" μπορεί να παραλειφθεί όταν το χρησιμοποιείς ως χαρακτηριστικό.

Τα παρακάτω τέσσερα προκαθορισμένα χαρακτηριστικά χρησιμοποιούνται τακτικά:

- `[Flags]`: Προκαθορισμένο στον χώρο ονομάτων System. Δηλώνει ότι η απαρίθμηση υποστηρίζει και πράξεις bitwise και τη μέθοδο `Enum.HasFlag()`. Επιπλέον, η `ToString` θα εμφάνιζε όλα τα flags: [δες το παράδειγμα][flags-example].
- `[Obsolete]`: Προκαθορισμένο στον χώρο ονομάτων System. Επιτρέπει να προσθέσεις ένα μήνυμα που εξηγεί γιατί ο κώδικας είναι παρωχημένος, και μπορεί να χρησιμοποιηθεί για να εμφανίζει προειδοποιήσεις ή σφάλματα του μεταγλωττιστή.
- `[Conditional]`: Προκαθορισμένο στον χώρο ονομάτων System.Diagnostics. Επιτρέπει να αφαιρέσεις ορισμένες κλήσεις μεθόδων κατά τη μεταγλώττιση για σκοπούς debugging (διάγνωσης).
- `[CallerMemberName]`: Προκαθορισμένο στον χώρο ονομάτων System.Runtime.CompilerServices. Επιτρέπει σε μια μέθοδο να πάρει πληροφορίες για αυτόν που την κάλεσε.
