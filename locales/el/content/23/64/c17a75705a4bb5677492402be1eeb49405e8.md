# Σχετικά

Το `jq` είναι ένα εργαλείο για την ανάλυση και τον μετασχηματισμό δεδομένων JSON.
Το `jq` είναι σαν το `sed` για δεδομένα JSON. Μπορείς να το χρησιμοποιήσεις για να κόβεις, να φιλτράρεις, να αντιστοιχίζεις και να μετασχηματίζεις δομημένα δεδομένα με την ίδια ευκολία που το `sed`, το `awk`, το `grep` και τα παρόμοια εργαλεία σου επιτρέπουν να παίζεις με κείμενο.

Το `jq` είναι μια δυναμικά τυποποιημένη συναρτησιακή γλώσσα προγραμματισμού.
Όλες οι τιμές είναι αμετάβλητες.

Τα προγράμματα `jq` αποτελούνται από αλυσίδες "φίλτρων": κάθε φίλτρο παίρνει ένα μόνο στοιχείο ως είσοδο, ενεργεί πάνω του και βγάζει μηδέν ή περισσότερα μετασχηματισμένα στοιχεία.
Ένα "φίλτρο" μπορεί επίσης να ονομαστεί "έκφραση".

Η έξοδος (ή οι έξοδοι) μιας έκφρασης μπορεί να περάσει σε μια άλλη χρησιμοποιώντας τον τελεστή `|`.
Το `expressionA | expressionB` εφαρμόζει το `expressionA` σε κάποια είσοδο και μετά το `expressionB` εκτελείται επανειλημμένα για κάθε μία από τις εξόδους του `expressionA`.

Η είσοδος μιας έκφρασης μπορεί να αναφερθεί ρητά ως `.`.
Μια έκφραση που προσθέτει `1` στην είσοδό της γράφεται ως εξής: `. + 1` (ή `1 + .`).

## `jq` (το πρόγραμμα) εναντίον `jq` (η γλώσσα)

Το `jq` είναι ένα πρόγραμμα που μπορείς να εγκαταστήσεις ως πακέτο σε διάφορα λειτουργικά συστήματα ή να το χτίσεις από τον πηγαίο κώδικα (είναι γραμμένο σε C).
Έχει αρκετές χρήσιμες [επιλογές γραμμής εντολών][cli-options] και είναι αρκετά γρήγορο.

Το πρόγραμμα `jq` υλοποιεί επίσης μια _γλώσσα_ που επιτρέπει οσοδήποτε σύνθετους χειρισμούς των δεδομένων εισόδου.

Αυτό το track του Exercism θα επικεντρωθεί στη γλώσσα.
Θα δεις τη χρήση του προγράμματος `jq` στα τεστ.

## Εκδόσεις

Αυτό το track του Exercism θα επικεντρωθεί στην αρχική υλοποίηση του `jq`, που φιλοξενείται στο [https://jqlang.org/][jq].

## JSON

Από το [json.org][json]:

> Το JSON (JavaScript Object Notation) είναι ένα ελαφρύ μορφότυπο ανταλλαγής δεδομένων.
> Είναι εύκολο για τους ανθρώπους να το διαβάζουν και να το γράφουν.
> Είναι εύκολο για τις μηχανές να το αναλύουν και να το παράγουν.
> Βασίζεται σε ένα υποσύνολο του προτύπου της γλώσσας προγραμματισμού JavaScript ECMA-262 3η Έκδοση - Δεκέμβριος 1999.
> Το JSON είναι ένα μορφότυπο κειμένου που είναι εντελώς ανεξάρτητο από τη γλώσσα, αλλά χρησιμοποιεί συμβάσεις που είναι οικείες σε προγραμματιστές της οικογένειας γλωσσών C, όπως C, C++, C#, Java, JavaScript, Perl, Python και πολλές άλλες.
> Αυτές οι ιδιότητες καθιστούν το JSON ιδανική γλώσσα ανταλλαγής δεδομένων.

Αυτό το track αφορά το `jq` και όχι το JSON.
Θα υποθέσουμε ότι είσαι εξοικειωμένος με τη [σύνταξη και τους τύπους δεδομένων του JSON][wiki-json].
