# Οδηγίες

Ένας φίλος σου έχει ένα παλιό κατάστημα χονδρικής που λέγεται **Gross Store**.
Το όνομα προέρχεται από την ποσότητα των ειδών που πουλάει το κατάστημα: όλα είναι σε [μονάδες gross][gross-unit].
Ο φίλος σου σου ζήτησε να υλοποιήσεις ένα σύστημα σημείου πώλησης (POS) για το κατάστημά του.
**Πρώτα, θέλεις να φτιάξεις ένα πρωτότυπο γι' αυτό.**
**Στο πρωτότυπό σου, το σύστημα θα καταγράφει μόνο την ποσότητα.**
Ο φίλος σου σου έδωσε μια λίστα με μονάδες μέτρησης για να σε βοηθήσει:

| Μονάδα             | Αξία  |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Αποθήκευσε τη μονάδα μέτρησης στο πρόγραμμά σου

Για να χρησιμοποιήσεις τη μονάδα μέτρησης, πρέπει να την αποθηκεύσεις στο πρόγραμμά σου.

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. Δημιούργησε έναν νέο λογαριασμό πελάτη

Πρέπει να υλοποιήσεις μια συνάρτηση που δημιουργεί έναν νέο (κενό) λογαριασμό για τον πελάτη.

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. Πρόσθεσε ένα είδος στον λογαριασμό του πελάτη

Για να το υλοποιήσεις, θα χρειαστεί να:

- Να επιστρέψεις `false` αν το `unit` που δίνεται δεν υπάρχει στο map `units`.
- Διαφορετικά, να προσθέσεις το είδος στον `bill` του πελάτη, με κλειδί το όνομα του είδους, και μετά να επιστρέψεις `true`.
- Αν το είδος υπάρχει ήδη στον λογαριασμό, να αυξήσεις την ποσότητά του κατά το ποσό που αντιστοιχεί στο `unit` που δίνεται.

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> Σημείωσε ότι η τιμή που επιστρέφεται είναι τύπου `bool`.

## 4. Αφαίρεσε ένα είδος από τον λογαριασμό του πελάτη

Για να το υλοποιήσεις, θα χρειαστεί να:

- Να επιστρέψεις `false` αν το είδος που δίνεται **δεν** υπάρχει στον λογαριασμό
- Να επιστρέψεις `false` αν το `unit` που δίνεται δεν υπάρχει στο map `units`.
- Να επιστρέψεις `false` αν η νέα ποσότητα θα ήταν μικρότερη από 0.
- Αν η νέα ποσότητα είναι 0, να αφαιρέσεις εντελώς το είδος από τον `bill` και μετά να επιστρέψεις `true`.
- Διαφορετικά, να μειώσεις την ποσότητα του είδους και να επιστρέψεις `true`.

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> Σημείωσε ότι η τιμή που επιστρέφεται είναι τύπου `bool`.

## 5. Επίστρεψε την ποσότητα ενός συγκεκριμένου είδους που υπάρχει στον λογαριασμό του πελάτη

Για να το υλοποιήσεις, θα χρειαστεί να:

- Να επιστρέψεις `0` και `false` αν το `item` δεν υπάρχει στον λογαριασμό.
- Διαφορετικά, να επιστρέψεις την ποσότητα του είδους στον `bill` και `true`.

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> Σημείωσε ότι οι τιμές που επιστρέφονται είναι τύπων `int` και `bool`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
