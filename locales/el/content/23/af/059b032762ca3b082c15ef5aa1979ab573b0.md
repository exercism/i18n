# Εισαγωγή

Η κληρονομικότητα είναι μια θεμελιώδης έννοια στον OOP (Αντικειμενοστραφή Προγραμματισμό).
Αντιπροσωπεύει μια σχέση IS-A.
Στον προγραμματισμό σημαίνει κυριολεκτικά ό,τι σημαίνει και στα αγγλικά: κληρονομείς χαρακτηριστικά από τον γονέα (στον προγραμματισμό τα χαρακτηριστικά είναι συνήθως συναρτήσεις και μεταβλητές).

Ας δούμε μια κλάση, την `Animal`, όπως φαίνεται παρακάτω,

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

Η `Animal` είναι μια γονική κλάση, γιατί οι ιδιότητες που έχει αυτή η κλάση μπορούν να επεκταθούν σε όλα τα ζώα γενικά.

Ας δούμε ένα ζώο που λέγεται `Lion`, με μια κλάση σαν την εξής,

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
Η σημείωση `Override` χρησιμοποιείται για να δείξει ότι μια μέθοδος σε μια θυγατρική κλάση υπερκαλύπτει μια μέθοδο της γονικής κλάσης.
Δεν είναι απολύτως απαραίτητη, αλλά είναι καλή πρακτική να τη χρησιμοποιείς.
~~~~

Τώρα, όποτε κάνουμε το εξής,

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Σημείωση: Αρχικοποιούμε την κλάση `Animal` με `Lion`.
Η έξοδος θα είναι κάπως έτσι

```java
Lion here!!
```

Σύμφωνα με τον OOP, υπάρχουν πολλά είδη κληρονομικότητας, αλλά η Java υποστηρίζει μόνο μερικά από αυτά (την πολλαπλών επιπέδων και την ιεραρχική).
Για να διαβάσεις περισσότερα σχετικά, διάβασε [αυτό][java-inheritance].
