# Εισαγωγή

## Boolean (λογικές τιμές)

Η Gleam αναπαριστά τις αληθείς και ψευδείς τιμές με τον τύπο `Bool`. Υπάρχουν μόνο δύο τιμές: `True` και `False`. Αυτές οι τιμές μπορούν να δεθούν σε μια μεταβλητή:

```gleam
let true_variable = True
let false_variable = False
```

Οι τελεστές `&&`, `||` και `!` μπορούν να χρησιμοποιηθούν για να χειριστούν τιμές Boolean:

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

Οι τελεστές `&&` και `||` χρησιμοποιούν αξιολόγηση βραχυκυκλώματος, που σημαίνει ότι η έκφραση στη δεξιά πλευρά του τελεστή αξιολογείται μόνο αν χρειάζεται.

Κάθε τελεστής έχει διαφορετική προτεραιότητα, όπου το `!` αξιολογείται πριν από τα `&&` και `||`. Τα άγκιστρα μπορούν να χρησιμοποιηθούν για να αξιολογηθεί ένα μέρος της έκφρασης πριν από τα άλλα:

```gleam
!True && False   // -> False
!{True && False} // -> True
```
