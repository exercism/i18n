# Δοκιμές

Υπάρχει μια ρύθμιση που γίνεται μία φορά για κάθε άσκηση και μπορεί να πάρει μερικά λεπτά:

```
npm install
```

Άνοιξε δύο τερματικά και στο πρώτο ξεκίνα τη διαδικασία build.

```
npm start
```

Στο δεύτερο, ξεκίνα να τρέχουν οι δοκιμές.

```
npm test
```

Καθώς επεξεργάζεσαι τον κώδικα, οι δύο διαδικασίες θα ξαναχτίζουν τον κώδικα και θα ξανατρέχουν τις δοκιμές συνεχώς.
