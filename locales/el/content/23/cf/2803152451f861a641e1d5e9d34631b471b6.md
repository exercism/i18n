# Σχετικά

_Τα κλεισίματα_ είναι ένα μοτίβο προγραμματισμού στη JavaScript που επιτρέπει σε μεταβλητές από ένα εξωτερικό [λεξικό πεδίο][wiki-lexical-scope] να χρησιμοποιούνται μέσα σε ένα εμφωλευμένο μπλοκ κώδικα. Η JavaScript υποστηρίζει τα κλεισίματα διαφανώς, και συχνά χρησιμοποιούνται χωρίς να ξέρει κανείς τι είναι.

```javascript
// Top-level declarations are global-scope
const dozen = 12;

// Functions create a new function-scope and block-scope.
// Referencing the outer variable here is a closure.
function nDozen(n) {
  return dozen * n;
}
```

Το όνομα _κλείσιμο_ προέρχεται ιστορικά από τον [_λ-λογισμό_][wiki-lambda-calculus] και διαδόθηκε από τη [_Scheme_][wiki-scheme] ([πηγή][wiki-closure]) για να περιγράψει τις ανοιχτές και κλειστές δεσμεύσεις μεταβλητών μιας συνάρτησης.

## Λόγοι για να χρησιμοποιείς κλεισίματα στη JavaScript

1. Ιδιωτικότητα δεδομένων / Ενθυλάκωση δεδομένων
   - Σε αντίθεση με άλλες γλώσσες, το 2020 δεν υπήρχε τρόπος να δηλώσεις _ιδιωτικές_ μεταβλητές. Έτσι, τα κλεισίματα μπορούν να χρησιμοποιηθούν για να μιμηθούν αποτελεσματικά τις _ιδιωτικές_ μεταβλητές (υπήρχε μια πρόταση να εισαχθεί συμβολισμός ιδιωτικών μεταβλητών, η οποία μπορεί να έχει γίνει πρότυπο μέχρι να το διαβάσεις αυτό).

   ```javascript
   // Consider this function:

   const saveNumber = (number) => {
     // The saved value is unaccessible by the outer lexical scope.
     const value = number;

     // We can provide access to the primitive value with a function, but the original will never change
     return () => value;
   };

   // Attempting to set the variable outside of its lexical scope results in an error
   value = 42;
   ```

2. Μερική εφαρμογή
   - Οι συναρτήσεις μπορούν να επιστρέφουν συναρτήσεις, και όταν μια συνάρτηση που επιστρέφεται χρησιμοποιεί το όρισμα της συνάρτησης που τη δημιούργησε, αυτό είναι ένα παράδειγμα χρήσης κλεισίματος για μερική εφαρμογή. Μερικές φορές αυτό ονομάζεται _currying_ μιας συνάρτησης.

   ```javascript
   // The arguments are applied one-by-one, using closures to arrive at the final result
   function partialBuildUri(scheme) {
     return function (domain) {
       return function (path) {
         return `${scheme}://${domain}/${path}`;
       };
     };
   }

   // A function could apply them all at once.
   function buildUri(scheme, domain, path) {
     return partialBuildUri(scheme)(domain)(path);
   }

   // Or apply a few to create a flexible system of functions for reuse.
   function buildHttpsExercismUri(path) {
     return partialBuildUri('https')('exercism.org');
   }
   ```

## Λεξικό πεδίο για τις μεταβλητές

Σε οποιαδήποτε γλώσσα προγραμματισμού, **Τα κλεισίματα** σχετίζονται στενά με το πεδίο των μεταβλητών. Στη JavaScript, υπάρχουν 3 τύποι λεξικού πεδίου για τις μεταβλητές:

1. **Καθολικό πεδίο**: Πρόκειται για μεταβλητές που δηλώνονται έξω από συναρτήσεις και μπλοκ.
1. **Πεδίο συνάρτησης**: Πρόκειται για μεταβλητές που δηλώνονται μέσα σε μια συνάρτηση χρησιμοποιώντας τη λέξη-κλειδί `var`.
1. **Πεδίο μπλοκ**: Πρόκειται για μεταβλητές που δηλώνονται μέσα σε ένα μπλοκ (`{...}`) χρησιμοποιώντας τις λέξεις-κλειδιά `let` (έστω) και `const`.

Στην πράξη, ένα κλείσιμο εμφανίζεται συχνά όταν μια συνάρτηση (ή ένα μπλοκ) χρησιμοποιεί μια μεταβλητή από ένα εξωτερικό πεδίο. Στη JavaScript, αυτό υποστηρίζεται διαφανώς, οπότε τα κλεισίματα χρησιμοποιούνται συχνά χωρίς συγκεκριμένη αναφορά.

### Πεδίο συνάρτησης

Η λέξη-κλειδί `var` ορίζει μια μεταβλητή με **πεδίο συνάρτησης**. Αυτό σημαίνει ότι οι μεταβλητές που ορίζονται με `var` είναι διαθέσιμες οπουδήποτε μέσα στη συνάρτηση όπου ορίζονται και σε οποιοδήποτε εμφωλευμένο λεξικό πεδίο (είτε **συνάρτησης** είτε **μπλοκ**).

```javascript
{
  var five = 5;
}

// This will succeed because 'five' exists in the same scope
var tenTimes = five * 10;
```

### Πεδίο μπλοκ

Οι λέξεις-κλειδιά `let` και `const` ορίζουν μεταβλητές με **πεδίο μπλοκ**. Το `let` ορίζει μια μεταβλητή που μπορεί να αλλάξει, της οποίας η τιμή μπορεί να οριστεί πολλές φορές και η οποία μπορεί να δηλωθεί αλλά να μην αρχικοποιηθεί. Το `const` ορίζει μια μεταβλητή η οποία πρέπει να αρχικοποιηθεί όταν δηλώνεται, και η τιμή της έπειτα δεν μπορεί να αλλάξει. Αν η μεταβλητή `const` οριστεί σε μια πρωτογενή τιμή, δεν μπορεί να τροποποιηθεί. Αν η μεταβλητή `const` οριστεί σε μια τιμή αναφοράς, όπως ένας _πίνακας_ ή ένα _αντικείμενο_, η αναφορά δεν μπορεί να αλλάξει, αλλά τα περιεχόμενα του πίνακα μπορούν να τροποποιηθούν.

Δες αυτό το μπλοκ:

```javascript
// 'two' is defined at the top-level, therefore available to the global-scope
const two = 2;

{
  // This succeeds, as 'two' is available from the outer lexical scope
  const oneLess = two - 1;
}

// This throws an error because oneLess is not defined outside of the previous inner lexical scope
console.log(oneLess);
```

Ενώ μπορούμε να χρησιμοποιήσουμε άγκιστρα (`{...}`) αυθαίρετα για να δημιουργήσουμε μπλοκ, τα συναντάμε πιο συχνά γύρω από _εντολές `if`_, _συναρτήσεις_ και _κλάσεις_.

```javascript
const PI = 3.14;

// This function uses a closure for the value of PI (π)
function areaOfCircle(radius) {
  return PI * radius * radius;
}
```
