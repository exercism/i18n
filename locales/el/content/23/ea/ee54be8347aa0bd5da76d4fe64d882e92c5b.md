# Εισαγωγή

Οι [πίνακες][arrays-concept] έχουν ενσωματωμένες μεθόδους για να αναλύουν τα περιεχόμενα του πίνακα.
Οι περισσότερες από αυτές τις μεθόδους δέχονται ως όρισμα μια συνάρτηση που επιστρέφει αληθή ή ψευδή τιμή.
Μια τέτοια συνάρτηση ονομάζεται [`predicate`][predicate_in_programming].

Οι ενσωματωμένες μέθοδοι προορίζονται να χρησιμοποιούνται _αντί για έναν `for` βρόχο_ ή για την ενσωματωμένη μέθοδο `forEach`:

Παράδειγμα ανάλυσης με έναν `for` βρόχο:

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

Παράδειγμα ανάλυσης με μια ενσωματωμένη μέθοδο:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

Μερικές ακόμη χρήσιμες ενσωματωμένες μέθοδοι που είναι διαθέσιμες για την ανάλυση ενός πίνακα φαίνονται παρακάτω. Δες το [MDN][mdn-array-methods] για μια πλήρη λίστα μεθόδων πινάκων.

## `includes`

> Η μέθοδος includes() προσδιορίζει αν ένας πίνακας περιέχει μια συγκεκριμένη τιμή μεταξύ των στοιχείων του, επιστρέφοντας αληθή ή ψευδή τιμή ανάλογα. [^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> Η μέθοδος every() ελέγχει αν όλα τα στοιχεία του πίνακα περνούν τον έλεγχο που υλοποιεί η παρεχόμενη συνάρτηση. Επιστρέφει μια τιμή Boolean. [^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> Η μέθοδος some() ελέγχει αν τουλάχιστον ένα στοιχείο του πίνακα περνά τον έλεγχο που υλοποιεί η παρεχόμενη συνάρτηση. [^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> Η μέθοδος find() επιστρέφει την τιμή του πρώτου στοιχείου του πίνακα που ικανοποιεί τη συνάρτηση ελέγχου που δίνεται. Αν καμία τιμή δεν ικανοποιεί τη συνάρτηση ελέγχου, επιστρέφεται το undefined. [^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> Η μέθοδος findIndex() επιστρέφει τη θέση του πρώτου στοιχείου του πίνακα που ικανοποιεί τη συνάρτηση ελέγχου που δίνεται. Διαφορετικά, επιστρέφει -1, υποδηλώνοντας ότι κανένα στοιχείο δεν πέρασε τον έλεγχο. [^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
