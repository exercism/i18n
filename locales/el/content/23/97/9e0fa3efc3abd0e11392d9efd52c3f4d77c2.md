# Οδηγίες

Ως επίδοξη μάγισσα, η Elyse χρειάζεται να αναλύει την τράπουλά της με πολλούς διαφορετικούς τρόπους.
Για να κρατήσει τα πράγματα απλά, χρησιμοποιεί μόνο κάρτες με τιμές 1-10.

## 1. Προσδιόρισε πόσες κάρτες ενός συγκεκριμένου τύπου υπάρχουν στην τράπουλα

Η Elyse θέλει να μάθει πόσες κάρτες ενός συγκεκριμένου τύπου έχει στην τράπουλά της.

Γράψε μια συνάρτηση `cardTypeCheck` που παίρνει δύο παραμέτρους: έναν πίνακα με κάρτες (την τράπουλα της Elyse) και τον τύπο της κάρτας που θα μετρήσεις.

<!--prettier-ignore -->
~~~exercism/note
Η συνάρτηση πρέπει να χρησιμοποιεί `forEach` και να επιστρέφει τον αριθμό των καρτών του συγκεκριμένου τύπου που υπάρχουν στην τράπουλα.
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. Προσδιόρισε πόσες μονές ή ζυγές κάρτες υπάρχουν

Για ένα άλλο κόλπο, η Elyse χρειάζεται να ξέρει πόσες μονές ή ζυγές κάρτες υπάρχουν στην τράπουλά της.

Υλοποίησε μια συνάρτηση `determineOddEvenCards` που παίρνει δύο παραμέτρους: έναν πίνακα με κάρτες (την τράπουλα της Elyse) και ένα Boolean (λογική τιμή), όπου το true αντιστοιχεί στις "ζυγές" και το false στις "μονές".

Αυτή η συνάρτηση πρέπει να επιστρέφει έναν μόνο αριθμό: τον αριθμό των μονών ή ζυγών καρτών που υπάρχουν στην τράπουλα (ανάλογα με την τιμή του δεύτερου ορίσματος).

<!--prettier-ignore -->
~~~exercism/note
Για εξάσκηση, χρησιμοποίησε αυτή τη φορά έναν βρόχο `for...of` στην υλοποίηση της συνάρτησης.
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
