# Δοκιμές

## Γραμμή εντολών

Μπορείς να χρησιμοποιήσεις την παρακάτω εντολή για να τρέξεις τις δοκιμές από τη γραμμή εντολών:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Αντικατέστησε το `<exercise>` με το όνομα της άσκησης που υλοποιείς.

## Διαδραστικά

Για να τρέξεις το Prolog διαδραστικά, πρώτα τρέξε:

```bash
swipl
```

Αφού ξεκινήσει η κονσόλα του Prolog, φόρτωσε την υλοποίησή σου και τρέξε τις δοκιμές με:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Αντικατέστησε το `<exercise>` με το όνομα της άσκησης που υλοποιείς.

### Επαναφόρτωση αλλαγών

Αφού φορτωθούν τα παραπάνω αρχεία, μπορείς να εφαρμόσεις όποιες αλλαγές έχεις κάνει τρέχοντας:

```
?- make.
```

## Δοκιμές που παραλείπονται

Όταν ξεκινάς πρώτα μια άσκηση, μόνο η πρώτη δοκιμή θα τρέξει. Οι υπόλοιπες έχουν παραλειφθεί με την προσθήκη `condition(pending)` στον στόχο `test`. Μόλις περάσει η πρώτη δοκιμή, ενεργοποίησε ξανά την επόμενη δοκιμή αλλάζοντας το `pending` στο `condition(pending)` σε `true`. Επανάλαβε για κάθε δοκιμή μέχρι να τρέχουν και να περνούν όλες.

### Γραμμή εντολών

Πρόσθεσε το όρισμα `-- --all` στο τέλος της εντολής για να τρέξεις και τυχόν εκκρεμείς δοκιμές:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
