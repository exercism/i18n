# Εισαγωγή

Στη C#, μια ιεραρχία κλάσεων μπορεί να οριστεί χρησιμοποιώντας την _κληρονομικότητα_, η οποία επιτρέπει σε μια παράγωγη κλάση (`Car`) να κληρονομήσει τη συμπεριφορά και τα δεδομένα της γονικής της κλάσης (`Vehicle`). Αν δεν καθοριστεί κάποια γονική κλάση, η κλάση κληρονομεί από την κλάση `object`.

Οι γονικές κλάσεις μπορούν να παρέχουν λειτουργικότητα στις παράγωγες κλάσεις με τρεις τρόπους:

- Ορίζουν μια κανονική μέθοδο.
- Ορίζουν μια μέθοδο `virtual`, η οποία μοιάζει με μια κανονική μέθοδο, αλλά οι παράγωγες κλάσεις _μπορούν_ να την αλλάξουν.
- Ορίζουν μια μέθοδο `abstract`, δηλαδή μια μέθοδο χωρίς υλοποίηση την οποία οι παράγωγες κλάσεις _πρέπει_ να υλοποιήσουν. Μια κλάση με μεθόδους `abstract` πρέπει να χαρακτηριστεί και αυτή ως `abstract`. Δεν μπορεί να δημιουργηθεί στιγμιότυπο μιας αφηρημένης κλάσης.

Ο τροποποιητής πρόσβασης `protected` επιτρέπει την πρόσβαση σε ένα μέλος της γονικής κλάσης από μια παράγωγη κλάση, αλλά αποκλείει την πρόσβαση από άλλες κλάσεις.

Οι παράγωγες κλάσεις μπορούν να έχουν πρόσβαση στα μέλη της γονικής κλάσης μέσω της λέξης-κλειδιού `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Ο κατασκευαστής μιας παράγωγης κλάσης θα καλέσει αυτόματα τον κατασκευαστή της γονικής της κλάσης _πριν_ εκτελέσει τη δική του λογική. Μπορούν να περαστούν ορίσματα στον κατασκευαστή της γονικής κλάσης μέσω της λέξης-κλειδιού `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Όταν από μια κλάση βάσης παράγονται περισσότερες από μία κλάσεις, αυτές οι δύο (ή περισσότερες) κλάσεις συχνά υλοποιούν διαφορετικές εκδοχές μιας μεθόδου της κλάσης βάσης. Αυτή είναι μια πολύ σημαντική αρχή που ονομάζεται πολυμορφισμός. Για παράδειγμα, σε μια παραλλαγή του παραπάνω παραδείγματος δείχνουμε πώς ο κώδικας που χρησιμοποιεί το `Vehicle` μπορεί να αλλάξει τη συμπεριφορά του ανάλογα με τον τύπο του οχήματος που έχει δημιουργηθεί ως στιγμιότυπο.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
