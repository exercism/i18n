# Εισαγωγή

Αυτή την εβδομάδα, είναι η σειρά σου να κρατήσεις σημειώσεις στη σύσκεψη σχεδιασμού του τμήματος.
Σε αυτή τη σύσκεψη, το αφεντικό σου θα ορίσει ημερομηνίες παράδοσης για όλες τις εκκρεμείς εργασίες.
Το εκνευριστικό είναι ότι, αντί να προσδιορίσει τις _πραγματικές_ ημερομηνίες παράδοσης, το αφεντικό σου θα _τις περιγράψει_ μόνο σε συντομευμένη μορφή.
Καθώς πολλοί από τους συναδέλφους σου δεν θα είναι εξοικειωμένοι με αυτή την εταιρική αργκό, θα χρειαστεί να μετατρέψεις αυτές τις περιγραφές ημερομηνιών παράδοσης σε πραγματικές ημερομηνίες παράδοσης.
