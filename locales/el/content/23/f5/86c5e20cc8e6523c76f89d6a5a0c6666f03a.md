# Προσθήκη στις οδηγίες

## Υλοποίηση

Αυτή η άσκηση απαιτεί να χρησιμοποιήσεις αντικείμενα βασισμένα σε closures. Μπορείς να διαβάσεις περισσότερα για αυτή την προσέγγιση στην αντικειμενοστρέφεια στη Lua [σε αυτό το άρθρο][oot].

Αυτή η άσκηση απαιτεί επίσης να χρησιμοποιήσεις υπερφόρτωση τελεστών μέσω μεταμεθόδων μεταπινάκων. Μπορείς να διαβάσεις περισσότερα για αυτό στο [Programming in Lua][am].

[oot]: http://lua-users.org/wiki/ObjectOrientationTutorial
[am]: https://www.lua.org/pil/13.1.html
