# Οδηγίες

Η δημιουργία μιας υπηρεσίας στη Ballerina είναι εύκολη. Τώρα μπορείς να προσθέσεις μια παράμετρο ερωτήματος και μια σχετική διαδρομή.

## Στόχοι

- Τροποποίησε τον κώδικα που σου δίνεται.
- Θα πρέπει να έχει ένα endpoint echo που επιστρέφει την τιμή της παραμέτρου ερωτήματος `sound`. Η υπηρεσία θα πρέπει να απαντά σε ένα HTTP αίτημα GET στη διαδρομή `/echo?sound=hello`.
- Θα πρέπει να έχει ένα ακόμη endpoint που ορίζει τη λέξη "echo" και επιστρέφει τη συμβολοσειρά `"A sound or series of sounds caused by the reflection of sound waves from a surface back to the listener."`. Η υπηρεσία θα πρέπει να απαντά σε ένα HTTP αίτημα GET στη διαδρομή `/echo/definition`.
