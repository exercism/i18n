# Έλεγχος πληρωμών σε βάση δεδομένων

## Περιγραφή του προβλήματος

Η ABC Corp χρειάζεται να φορτώσεις όλα τα δεδομένα από τη βάση δεδομένων SQL σε έναν [πίνακα Ballerina](https://ballerina.io/learn/by-example/table-syntax/) για περαιτέρω επεξεργασία. Στη συνέχεια, πρέπει να βρεις τα ονόματα των υπαλλήλων που έχουν εγγραφές πληρωμών μεγαλύτερες από ένα δεδομένο ποσό (π.χ. 3000.00), κάνοντας ερώτημα στον φορτωμένο πίνακα Ballerina.

**Βήμα 1:**

Δημιούργησε έναν πίνακα Ballerina με τις παρακάτω στήλες.

`payment_id` - ακέραιος

`amount` - δεκαδικός

`employee_name` - συμβολοσειρά

**Βήμα 2:**

Γέμισε τον παραπάνω πίνακα Ballerina φορτώνοντας το αντίστοιχο πλήρες σύνολο δεδομένων από τη βάση δεδομένων H2. Χρησιμοποίησε το `payment_id` ως πρωτεύον κλειδί του πίνακα.

**Βήμα 3**

Κάνε ερώτημα στον πίνακα Ballerina χρησιμοποιώντας εκφράσεις ερωτημάτων της Ballerina για να βρεις τα ονόματα των υπαλλήλων που έχουν εγγραφές πληρωμών μεγαλύτερες από το δεδομένο ποσό. Ταξινόμησε το αποτέλεσμα κατά το όνομα του υπαλλήλου σε αύξουσα σειρά. Αφαίρεσε τα διπλότυπα ονόματα από το αποτέλεσμα πριν το επιστρέψεις.

> ΣΗΜΕΙΩΣΗ: Είναι υποχρεωτικό να χρησιμοποιήσεις τον πίνακα Ballerina για να υλοποιήσεις τη λύση.

## Λεπτομέρειες βάσης δεδομένων

Χρησιμοποίησε τη βάση δεδομένων H2 που παρέχεται για αυτό το πρόβλημα.

> Το αρχείο της δειγματικής βάσης δεδομένων είναι το `gofigure.mv.db` και το όνομα της βάσης δεδομένων είναι `gofigure`. Βρίσκεται μέσα στον φάκελο `db`.

Οι παρακάτω πίνακες υπάρχουν ήδη στη δειγματική βάση δεδομένων H2 με μερικά δείγματα δεδομένων. Τα ονόματα των στηλών και οι τύποι δεδομένων δίνονται παρακάτω.

**Όνομα πίνακα**: `Employee`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `employee_id`     | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `name`            | συμβολοσειρά        |
| `city`            | συμβολοσειρά        |
| `department`      | συμβολοσειρά        |
| `age`             | ακέραιος        |

**Όνομα πίνακα**: `Payment`

| **Στήλες:**      | τύπος |
| -----------       | ----------- |
| `payment_id`      | ακέραιος, πρωτεύον κλειδί με αυτόματη αύξηση       |
| `date`            | ημερομηνία        |
| `amount`          | δεκαδικός        |
| `employee_id`     | ακέραιος        |
| `reason`          | συμβολοσειρά        |

* Το αρχείο της βάσης δεδομένων είναι το `gofigure.mv.db`. Χρησιμοποίησε το JDBC URL ως `jdbc:h2:file:/path/to/db/file`
* Όνομα χρήστη: `root`
* Κωδικός πρόσβασης: `root`

## Περιορισμοί

* Χρησιμοποίησε το αρχείο βάσης δεδομένων H2 που παρέχεται στον φάκελο `db` για να επικυρώσεις τα ερωτήματα και το δείγμα της Ballerina
* Χρησιμοποίησε την προσέγγιση maven dependency params για να προσθέσεις τον driver της βάσης δεδομένων H2 ως εξάρτηση πλατφόρμας στο Ballerina.toml

## Περιβάλλον δοκιμών

* Μπορείς να τρέξεις τις δοκιμές με `bal test` και θα εκτελέσει δοκιμές πάνω στη δειγματική βάση δεδομένων που δίνεται.

## Υποδείξεις

* Χρησιμοποίησε το module [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) για να δουλέψεις με τη βάση δεδομένων
* Ανατρέξε στην ενότητα [Προαπαιτούμενα](https://lib.ballerina.io/ballerinax/java.jdbc/latest) για τα βήματα προσθήκης του driver JDBC ως εξάρτησης
* Χρησιμοποίησε την απομακρυσμένη μέθοδο [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) για να ανακτήσεις δεδομένα από τη βάση δεδομένων
* Δες το παράδειγμα [Απλό ερώτημα](https://ballerina.io/learn/by-example/mysql-query-operation)
* Δες το παράδειγμα [Σύνταξη πίνακα](https://ballerina.io/learn/by-example/table)
* Χρησιμοποίησε το [Ερωτήματα σε πίνακες](https://ballerina.io/learn/by-example/querying-tables) για να βρεις τα απαιτούμενα δεδομένα από τον πίνακα Ballerina
