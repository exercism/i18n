# Εισαγωγή

Η Go παρέχει ένα ενσωματωμένο πακέτο που ονομάζεται `fmt` (πακέτο μορφοποίησης), το οποίο προσφέρει μια ποικιλία συναρτήσεων για τον χειρισμό της μορφής της εισόδου και της εξόδου.
Η πιο συχνά χρησιμοποιούμενη συνάρτηση είναι η `Sprintf`, η οποία χρησιμοποιεί _ρήματα_ όπως το `%s` για να παρεμβάλλει τιμές μέσα σε μια συμβολοσειρά και επιστρέφει αυτή τη συμβολοσειρά.

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

Στη Go, οι τιμές κινητής υποδιαστολής μορφοποιούνται εύκολα με τα ρήματα της Sprintf: `%g` (συμπαγής αναπαράσταση), `%e` (εκθέτης) ή `%f` (χωρίς εκθέτη).
Και τα τρία ρήματα επιτρέπουν τον έλεγχο του πλάτους και της αριθμητικής θέσης του πεδίου.

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

Μπορείς να βρεις μια πλήρη λίστα με τα διαθέσιμα ρήματα στην [τεκμηρίωση του πακέτου μορφοποίησης][fmt-docs].

Το `fmt` περιέχει και άλλες συναρτήσεις για εργασία με συμβολοσειρές, όπως η `Println`, η οποία απλώς εκτυπώνει στην κονσόλα τα ορίσματα που δέχεται, και η `Printf`, η οποία μορφοποιεί την είσοδο με τον ίδιο τρόπο όπως η `Sprintf` πριν την εκτυπώσει.

[fmt-docs]: https://pkg.go.dev/fmt
