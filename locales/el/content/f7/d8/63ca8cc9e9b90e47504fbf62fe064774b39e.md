# Υποδείξεις

## 1. Καθόρισε αν ο Pac-Man μπορεί να φάει ένα φάντασμα

* Η συνάρτηση πρέπει να επιστρέφει μια boolean τιμή.
* Μπορείς να χρησιμοποιήσεις τον λογικό τελεστή `and` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 2. Καθόρισε αν ο Pac-Man σκοράρει

* Η συνάρτηση πρέπει να επιστρέφει μια boolean τιμή.
* Μπορείς να χρησιμοποιήσεις τον boolean τελεστή `or` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 3. Καθόρισε αν ο Pac-Man χάνει

* Η συνάρτηση πρέπει να επιστρέφει μια boolean τιμή.
* Μπορείς να χρησιμοποιήσεις τους boolean τελεστές `and` και `not` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 4. Καθόρισε αν ο Pac-Man κερδίζει

* Η συνάρτηση πρέπει να επιστρέφει μια boolean τιμή.
* Μπορείς να χρησιμοποιήσεις τους boolean τελεστές `and` και `not` για να συνδυάσεις τα ορίσματα και τα αποτελέσματα μιας από τις συναρτήσεις που έχεις υλοποιήσει προηγουμένως.
