# Εισαγωγή

## JSON

Το JSON (JavaScript Object Notation) είναι μια μορφή δεδομένων και αρχείων, αναγνώσιμη από τον άνθρωπο, που χρησιμοποιείται συνήθως για την ανταλλαγή δεδομένων, ιδίως σε διαδικτυακές εφαρμογές.
Δεν αποτελεί έκπληξη, λοιπόν, ότι κατέχει ξεχωριστή θέση στη γλώσσα Elm.

Η Elm παρέχει τα βασικά αρθρώματα `Json.Decode` και `Json.Encode` για την ανάλυση και τη συγγραφή δεδομένων JSON.
Οι decoders JSON είναι ένας τρόπος να _δηλώσεις_ τι τύπο δεδομένων περιμένεις και σε ποια δομή δεδομένων πρέπει να αντιστοιχιστούν τα δεδομένα.

Ας εισαγάγουμε μερικά ψευδώνυμα και τύπους από τα αρθρώματα:

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

Χρησιμοποιώντας το `Decode.decodeString : Decoder a -> String -> Result Error a` με έναν decoder και ένα JSON string, το αποτέλεσμα είτε θα είναι επιτυχές, αν το string συμφωνεί με τις προδιαγραφές του decoder, είτε θα αποτύχει.
Δεν υπάρχει τρόπος να εξετάσεις τα ακατέργαστα δεδομένα JSON όταν ορίζεις τον decoder, κάτι που μπορεί να φαίνεται ασυνήθιστο αν έρχεσαι από προστακτικές γλώσσες.

## Decoders βασικών τύπων δεδομένων

Το JSON έχει έναν μικρό αριθμό βασικών τύπων δεδομένων:

- Συμβολοσειρά: κωδικοποιείται με διπλά εισαγωγικά `"hello world"`
- Boolean: είτε `true` είτε `false`
- Αριθμός: όπως `34` ή `0.12`
- Null: η απουσία δεδομένων `null`

Κάθε ένας από αυτούς σχετίζεται με μια συνάρτηση του `Decode`:

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

Σημείωσε ότι το `Decode.null` σου επιτρέπει να αποφασίσεις πώς θα μοντελοποιήσεις ένα `null` στο πρόγραμμά σου, απαιτώντας μια αυθαίρετη τιμή ως όρισμα (ίσως `()`, `Nothing`, ή οτιδήποτε ταιριάζει στο πρόγραμμά σου).

## Συνδυασμός decoders

Το JSON ορίζει επίσης δύο δομές δεδομένων για τη συλλογή βασικών τύπων δεδομένων:

- Πίνακας: μια συλλογή άλλων τύπων δεδομένων `[0, null, "none", []]`
- Αντικείμενο: μια συλλογή ζευγών κλειδιού-τιμής `{"id": 1, "is_admin": false, "more_info": {}}`

Το `Decode` προσφέρει επίσης συναρτήσεις για να τα αποκωδικοποιήσεις:

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

Αυτές οι συναρτήσεις `Decode.list : Decoder a -> Decoder (List a)` και `Decode.dict : Decoder a -> Decoder (Dict String a)` περιμένουν καθεμία έναν decoder ως όρισμα, ο οποίος αναμένεται να αποκωδικοποιήσει κάθε επιμέρους στοιχείο της δομής δεδομένων.
Αν ο decoder-όρισμα αποτύχει να αποκωδικοποιήσει οποιοδήποτε στοιχείο μιας τιμής πίνακα ή αντικειμένου, ολόκληρος ο decoder αποτυγχάνει, κάτι που είναι ένα συνηθισμένο μοτίβο.

Ο συνδυασμός απλών decoders σε πιο σύνθετους είναι η βασική ιδέα της τεχνικής.
Θα παρουσιάσουμε αρκετές ακόμη συναρτήσεις που μπορούν να χρησιμοποιηθούν για να φτιάξεις decoders για δεδομένα του πραγματικού κόσμου, οσοδήποτε σύνθετα, μέσα από ένα παράδειγμα.

## GeoJSON

Για να εξασκηθείς στον συνδυασμό βασικών decoders ώστε να αναλύεις σύνθετα δεδομένα JSON, ας φτιάξουμε decoders για την ανάλυση (ενός υποσυνόλου) δεδομένων GeoJSON.
Το GeoJSON είναι μια εξειδικευμένη μορφή δεδομένων βασισμένη στο JSON, που χρησιμοποιείται για την αναπαράσταση γεωγραφικών χαρακτηριστικών, όπως τοποθεσίες, διαδρομές ή περιοχές, καθορισμένων με 2D ή 3D γεωγραφικές συντεταγμένες, μαζί με άλλες ιδιότητες.

### Αντικείμενο Geometry

Ένα Αντικείμενο Geometry του GeoJSON είναι ένα αντικείμενο που περιέχει ένα πεδίο `type` με τιμή συμβολοσειράς (υπάρχουν 7 πιθανές τιμές τύπου) και ένα πεδίο `coordinates` με γεωγραφικές συντεταγμένες (συγκεντρωμένες σε μια δομή που εξαρτάται από τον τύπο).
Για παράδειγμα,

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

ή

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

Ένα Αντικείμενο Geometry θα μπορούσε να αναπαρασταθεί στην Elm με τον ακόλουθο τύπο

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

Για να εξετάσουμε την τιμή ενός συγκεκριμένου πεδίου, μπορούμε να χρησιμοποιήσουμε το `Decode.field : String -> Decoder a -> Decoder a`, το οποίο αποκωδικοποιεί την τιμή ενός συγκεκριμένου κλειδιού ενός αντικειμένου.

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

Για να μετασχηματίσουμε την τιμή που αναλύθηκε με επιτυχία από έναν decoder, μπορούμε να χρησιμοποιήσουμε το `Decode.map : (a -> value) -> Decoder a -> Decoder value`, ή οποιοδήποτε από τα αδέρφια του, από το `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value` μέχρι το `Decode.map8`.

Σε αυτή την περίπτωση, θέλουμε να αποφασίσουμε ποιον decoder συντεταγμένων θα χρησιμοποιήσουμε ανάλογα με την τιμή στο πεδίο `type`, κάτι για το οποίο το `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` είναι ιδανικό, μαζί με τους φίλους του `Decode.succeed : a -> Decoder a` και `Decode.fail : String -> Decoder a`.

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

Σημείωσε σε αυτό το σημείο ότι θα μπορούσαμε να χρησιμοποιήσουμε το `Decode.andThen` για να επικυρώσουμε τις συντεταγμένες (ελέγχοντας ότι οι συντεταγμένες έρχονται σε ζεύγη ή τριάδες και ότι οι τιμές τους έχουν γεωγραφικό νόημα).

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### Αντικείμενο Feature

Ένα Αντικείμενο Feature του GeoJSON αναπαριστά κάτι με χωρικά όρια: έχει ένα πεδίο `type` με την τιμή `"Feature"`, ένα πεδίο `geometry` με ένα Αντικείμενο Geometry ή ένα `null`, ένα πεδίο `properties` με ένα αυθαίρετο Αντικείμενο JSON ή ένα `null`, και ένα προαιρετικό πεδίο `id` με τιμή συμβολοσειράς ή αριθμού JSON.

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

ή

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

Ας ασχοληθούμε πρώτα με το πεδίο `id`.
Αν υπάρχει, πρέπει να χωράει συμβολοσειρές ή αριθμούς, οπότε θα μπορούσαμε είτε να εισαγάγουμε έναν προσαρμοσμένο τύπο για την τιμή, είτε να την αποθηκεύουμε πάντα ως συμβολοσειρά.

Για να επιλέξουμε ανάμεσα σε δύο πιθανούς decoders, μπορούμε να χρησιμοποιήσουμε το `Decode.oneOf : List (Decoder a) -> Decoder a`.

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

Για να εκφράσουμε ότι το πεδίο είναι προαιρετικό, θα μπορούσαμε να χρησιμοποιήσουμε την ίδια τεχνική

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

Αλλά θα μπορούσαμε αντ' αυτού να χρησιμοποιήσουμε το `Decode.maybe : Decoder a -> Decoder (Maybe a)`

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

Σημείωσε ότι το `decodeMaybeFeatureId` (ή οποιοσδήποτε decoder τυλιγμένος με `Decode.maybe`) θα πετύχει πάντα, αφού μπορεί πάντα να καταφύγει στο `Ok Nothing`, αν και ένας decoder που το χρησιμοποιεί μπορεί ακόμη να αποτύχει

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

Στη συνέχεια, ας επικεντρωθούμε στο πεδίο `geometry`, το οποίο μπορεί είτε να είναι ένα Αντικείμενο Geometry είτε να είναι `null`.
Θα μπορούσαμε να χρησιμοποιήσουμε το `Decode.oneOf` για άλλη μια φορά, αλλά υπάρχει καλύτερη επιλογή: `Decode.nullable : Decoder a -> Decoder (Maybe a)`.

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

Το `Decode.maybe` και το `Decode.nullable` έχουν την ίδια υπογραφή, αλλά η συμπεριφορά τους είναι διαφορετική, αφού το αποτέλεσμα `OK Nothing` ενός `Decode.nullable` θα προκύψει μόνο από τη συγκεκριμένη τιμή JSON `null`.

Τέλος, το πεδίο `properties` μπορεί να περιέχει ένα αυθαίρετο Αντικείμενο JSON ή ένα `null`, κάτι που είναι δουλειά για το `Decode.value : Decoder Value`.

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

Σημείωσε ότι το `Value` είναι ένας αδιαφανής τύπος, που σημαίνει ότι δεν μπορείς εύκολα να εξετάσεις το περιεχόμενό του.
Για να το χρησιμοποιήσεις, μπορείς είτε να γράψεις έναν decoder γι' αυτό και να τον τρέξεις με το `Decode.decodeValue : Decoder a -> Value -> Result Error a`, είτε να το στείλεις απευθείας στη JavaScript μέσω μιας θύρας.

Είμαστε έτοιμοι να αναλύσουμε Αντικείμενα Feature:

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## Encoders JSON

Οι encoders επιτρέπουν να γράψεις έγκυρο JSON από τιμές της Elm χρησιμοποιώντας τη συνάρτηση `Encode.encode : Int -> Value -> String`.
Το πρώτο όρισμα καθορίζει το πλήθος των χαρακτήρων εσοχής στο τελικό αποτέλεσμα, και το δεύτερο όρισμα είναι η τιμή JSON που θα γραφτεί.

Μια `Value` μπορεί είτε να ληφθεί από το `Decode.value` είτε να παραχθεί από έναν από τους encoders:

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

καθώς και με το `Encode.object : List ( String, Value ) -> Value`

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

Ας ορίσουμε encoders για τους decoders GeoJSON που ορίσαμε προηγουμένως

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

Γενικά, ένα καλό τεστ για τα ζεύγη decoder-encoder σου είναι να ελέγξεις ότι `elmValue |> encoder |> decoder == elmValue`.
