# Υποδείξεις

## Γενικά

- Μην ανησυχείς για συγκεκριμένους τύπους αριθμών. Χρησιμοποίησε `Int32` και `Float64` για την ώρα.
- Τα Int32 και Float64 είναι οι προεπιλεγμένοι τύποι αριθμών στην Crystal, οπότε δεν χρειάζεται να τους προσδιορίσεις.

## 1. Μετέτρεψε τη θερμοκρασία από Κελσίου σε Κέλβιν

- Μπορείς να χρησιμοποιήσεις τον αριθμητικό τελεστή (`+`) για να προσθέσεις αριθμούς.

## 2. Στρογγυλοποίησε τη θερμοκρασία

- Μπορείς να χρησιμοποιήσεις τη μέθοδο `round` για να στρογγυλοποιήσεις έναν αριθμό σε συγκεκριμένο αριθμό δεκαδικών ψηφίων.
- Η μέθοδος round δέχεται ένα όρισμα `places` που καθορίζει τον αριθμό των δεκαδικών ψηφίων για στρογγυλοποίηση.

## 3. Μετέτρεψε τη θερμοκρασία από Κελσίου σε Φαρενάιτ

- Μπορείς να χρησιμοποιήσεις τον αριθμητικό τελεστή (`*`) για να πολλαπλασιάσεις αριθμούς.
- Μπορείς να χρησιμοποιήσεις παρενθέσεις (`()`) για να ομαδοποιήσεις πράξεις.

## 4. Βρες τον αριθμό των αισθητήρων που λείπουν

- Μπορείς να χρησιμοποιήσεις τον αριθμητικό τελεστή (`-`) για να αφαιρέσεις αριθμούς.
- Μπορείς να χρησιμοποιήσεις τον αριθμητικό τελεστή (`%`) για να πάρεις το υπόλοιπο μιας διαίρεσης.
