# Οδηγίες

Διατηρείς ένα διαδικτυακό κατάστημα μόδας. Κάθε είδος στο
απόθεμά σου είναι ένας πίνακας 2 στοιχείων `{ name price }`, και ολόκληρο
το απόθεμα είναι ένας πίνακας από είδη.

Μια τιμή που λείπει καταγράφεται ως `f`.

## 1. Ταξινόμησε το απόθεμα κατά τιμή

Όρισε τη `sort-by-price` να επιστρέφει έναν νέο πίνακα με τα είδη
ταξινομημένα κατά τιμή, σε αύξουσα σειρά.

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. Βρες τα είδη χωρίς καθορισμένη τιμή

Όρισε τη `with-missing-price` να επιστρέφει έναν πίνακα με μόνο τα είδη
των οποίων η τιμή είναι `f`.

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. Μέτρησε τα ακριβά είδη

Όρισε τη `expensive-items` να παίρνει ένα απόθεμα και ένα κατώφλι
τιμής, και να επιστρέφει πόσα είδη κοστίζουν αυστηρά περισσότερο από το
κατώφλι.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. Βρες το φθηνότερο είδος

Όρισε τη `cheapest-item` να επιστρέφει το είδος με τη χαμηλότερη τιμή.
Είδη χωρίς τιμή (`f`) δεν θα εμφανίζονται στην είσοδο.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. Άθροισε όλες τις τιμές

Όρισε τη `total-price` να επιστρέφει το άθροισμα όλων των τιμών. Είδη
χωρίς τιμή (`f`) δεν θα εμφανίζονται στην είσοδο.

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. Μορφοποίησε ένα είδος ως ετικέτα τιμής

Όρισε τη `format-price-tag` να επιστρέφει μια συμβολοσειρά της μορφής
`"name: $price"` για ένα είδος. Είδη χωρίς τιμή (`f`) δεν θα εμφανίζονται εδώ.

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
