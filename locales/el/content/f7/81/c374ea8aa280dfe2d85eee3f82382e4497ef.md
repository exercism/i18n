# Υποδείξεις

## Γενικά

- Διάβασε για τα enumerables και τα streams στον [επίσημο οδηγό Getting Started][getting-started-streams].
- Διάβασε την επίσημη τεκμηρίωση για τα [streams][stream].

## 1. Κάνε μία ρίψη εξάπλευρου ζαριού

- Τα ranges υλοποιούν το _Enumerable protocol_.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-random] για την επιλογή μιας τυχαίας τιμής από ένα enumerable.

## 2. Συνέχισε να ρίχνεις όσο φέρνεις εξάρια

- Υπάρχει μια [ενσωματωμένη συνάρτηση][stream-repeatedly] που δημιουργεί ένα stream το οποίο παράγεται καλώντας μια συνάρτηση επανειλημμένα.
- Υπάρχει μια [ενσωματωμένη συνάρτηση για streams][stream-transform] που δουλεύει παρόμοια με το `Enum.reduce/3`.

## 3. Επίτρεψε τη χρήση πειραγμένου ζαριού

- Χρησιμοποίησε τον [τελεστή σύλληψης][special-forms-capture] για να συλλάβεις τη συνάρτηση `roll/0`.
