# Δοκιμές

Για να τρέξεις τις δοκιμές, ακολούθησε αυτά τα βήματα:

- Πήγαινε στον φάκελο της άσκησης (π.χ. `~/Exercism/hello-world`).
- Ξεκίνα μια συνεδρία `jconsole` (π.χ. πληκτρολογώντας `jconsole` ή `ijconsole`) σε ένα τερματικό.
- Φόρτωσε το αρχείο της λύσης σου (π.χ. `load 'hello-world.ijs'`)
- Φόρτωσε το unit test framework πληκτρολογώντας `load  'general/unittest'`
- Δοκίμασε τη λύση σου πληκτρολογώντας `unittest 'test.ijs'`.
<br></br>
- Εναλλακτικά, μπορείς να τρέξεις τις δοκιμές σε μία μόνο γραμμή, όπως αυτή: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Δοκιμές που παραλείπονται

Στην αρχή, μόνο η αρχική δοκιμή θα είναι ενεργοποιημένη.
Η προσέγγιση σε ενθαρρύνει να λύσεις την άσκηση βήμα βήμα.
Κάθε δοκιμή περιλαμβάνει ένα ουσιαστικό πάνω από τον ορισμό της, με όνομα που τελειώνει σε _'\_ignore'_.
Για να τρέξεις τη δοκιμή, άλλαξε την τιμή της σε 0.

### Παράδειγμα:

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
