# Συμβουλές

## Γενικά

- Ένα [map][maps] είναι μια συσχετιστική δομή δεδομένων από ζεύγη κλειδιού-τιμής.
- Το Elixir προσφέρει [πολλές χρήσιμες συναρτήσεις του module Map στην τυπική βιβλιοθήκη][map-module].

## 1. Όρισε ένα νέο map υψηλών σκορ

- Θα πρέπει να επιστρέφει ένα κενό [map][maps].
- Οι συναρτήσεις του [module Map][map-module] ή οι κυριολεκτικές μορφές γραφής μπορεί να σου φανούν χρήσιμες.

## 2. Πρόσθεσε παίκτες στο map των υψηλών σκορ

- Το map που προκύπτει θα πρέπει να επιστραφεί.
- Το [module Map][map-module] περιέχει συναρτήσεις χρήσιμες για τον χειρισμό maps. [Μία από αυτές][map-put] βάζει μια τιμή σε ένα map κάτω από ένα δεδομένο κλειδί.

## 3. Αφαίρεσε παίκτες από το map των σκορ

- Το map που προκύπτει θα πρέπει να επιστραφεί.
- Το [module Map][map-module] περιέχει συναρτήσεις χρήσιμες για τον χειρισμό maps. [Μία από αυτές][map-delete] διαγράφει ένα κλειδί από ένα map.

## 4. Μηδένισε το σκορ ενός παίκτη

- Το map που προκύπτει θα πρέπει να επιστραφεί με το σκορ του παίκτη μηδενισμένο σε μια αρχική τιμή.
- Το [module Map][map-module] περιέχει συναρτήσεις χρήσιμες για τον χειρισμό maps. [Μία από αυτές][map-put] βάζει μια τιμή σε ένα map κάτω από ένα δεδομένο κλειδί.

## 5. Ενημέρωσε το σκορ ενός παίκτη

- Το map που προκύπτει θα πρέπει να επιστραφεί με το ενημερωμένο σκορ του παίκτη.
- Το [module Map][map-module] περιέχει συναρτήσεις χρήσιμες για τον χειρισμό maps. [Μία από αυτές][map-update] ενημερώνει μια τιμή σε ένα map κάτω από ένα δεδομένο κλειδί.

## 6. Πάρε μια λίστα με τους παίκτες

- Το [module Map][map-module] περιέχει συναρτήσεις χρήσιμες για τον χειρισμό maps. [Μία από αυτές][map-keys] επιστρέφει μια λίστα με όλα τα κλειδιά ενός map.
