# Εισαγωγή

Ο τύπος [`enum`](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) της C# αναπαριστά ένα σταθερό σύνολο από ονομασμένες σταθερές (μια απαρίθμηση).

Κανονικά, ένα μέλος `enum` μπορεί να αναφέρεται μόνο σε μία ακριβώς από αυτές τις ονομασμένες σταθερές. Ωστόσο, μερικές φορές είναι χρήσιμο να αναφέρεσαι σε περισσότερες από μία σταθερές. Για να το κάνεις αυτό, μπορείς να σημειώσεις το `enum` με το [χαρακτηριστικό `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

Ένα `enum` με flags μπορεί να οριστεί ως εξής (χρησιμοποιώντας συμβολισμό δυαδικών ακεραίων `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Ένα στιγμιότυπο `PhoneFeatures` του οποίου η τιμή είναι `0b00000011` έχει ορισμένα και τα δύο flags, `Call` _και_ `Text`.

Από προεπιλογή, ο τύπος `int` χρησιμοποιείται για τις τιμές των μελών του `enum`. Μπορείς να χρησιμοποιήσεις έναν διαφορετικό ακέραιο τύπο καθορίζοντας τον τύπο στη δήλωση enum:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
