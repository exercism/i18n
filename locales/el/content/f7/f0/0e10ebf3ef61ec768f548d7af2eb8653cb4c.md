# Σχετικά

Το [Elixir](https://elixir-lang.org/), που κυκλοφόρησε αρχικά το 2012, επεκτείνει τα ήδη ισχυρά χαρακτηριστικά της Erlang και ταυτόχρονα είναι πιο εύκολο για αρχάριους να το προσεγγίσουν, να το διαβάσουν, να το δοκιμάσουν και να γράψουν κώδικα.

Ο José Valim, δημιουργός του Elixir, εξηγεί [στην ομιλία του σε συνέδριο το 2012](https://vimeo.com/53221562) πώς έφτιαξε τη γλώσσα ώστε οι εφαρμογές να είναι:

  1. Κατανεμημένες
  2. Ανεκτικές σε σφάλματα
  3. Μαλακού πραγματικού χρόνου
  4. Με εναλλαγή κώδικα εν θερμώ (μπορεί να εισάγει νέο κώδικα χωρίς να σταματήσει ο διακομιστής)

Το Elixir στην πραγματικότητα μεταγλωττίζεται σε [bytecode](https://en.wikipedia.org/wiki/Bytecode) και μετά εκτελείται στην [εικονική μηχανή BEAM της Erlang](https://codesync.global/media/robert-virding-co-creator-of-erlang-explains-the-beam/).

Δεν υπάρχει "κόστος μετατροπής" για την κλήση της Erlang, που σημαίνει ότι μπορείς να τρέξεις κώδικα Erlang ακριβώς δίπλα σε κώδικα Elixir.

Καθώς είναι μια συναρτησιακή γλώσσα, τα πάντα στο Elixir είναι εκφράσεις.

Το Elixir έχει "τεκμηρίωση πρώτης κατηγορίας", που σημαίνει ότι τα σχόλια μπορούν να συνδεθούν με μια συνάρτηση, κάνοντας την ανάκτησή της ευκολότερη.

Οι κανονικές εκφράσεις έχουν επίσης μεταχείριση πρώτης κατηγορίας, εξαλείφοντας την άβολη διαφυγή μέσα σε συμβολοσειρές.

Η υλοποίηση της ασύγχρονης επικοινωνίας στο Elixir επιτρέπει στον κώδικα να είναι ελαφρύς και ταυτόχρονα να ενσωματώνει μεγάλο όγκο ταυτοχρονισμού.

Οι προγραμματιστές χρησιμοποιούν το Elixir για να διαχειρίζονται χιλιάδες αιτήματα και απαντήσεις *ταυτόχρονα* σε έναν μόνο κόμβο διακομιστή.

Έχει χρησιμοποιηθεί με επιτυχία για μικροϋπηρεσίες που χρειάζεται να καταναλώνουν και να εξυπηρετούν πλήθος API γρήγορα.

Το [Phoenix framework](https://www.phoenixframework.org/) βοηθά να δομηθούν οι εφαρμογές Elixir για τον ιστό.
