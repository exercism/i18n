# Εισαγωγή

Στη JavaScript, οι _συμβολοσειρές προτύπων_ επιτρέπουν την ενσωμάτωση εκφράσεων μέσα σε συμβολοσειρές, κάτι που αναφέρεται και ως παρεμβολή συμβολοσειρών.
Αυτή η λειτουργικότητα επεκτείνει τη λειτουργικότητα του ενσωματωμένου καθολικού αντικειμένου [`String`][string-reference].

Μπορείς να δημιουργήσεις συμβολοσειρές προτύπων στη JavaScript τυλίγοντας κείμενο σε backticks (βαρείες).
Δεν επιτρέπουν μόνο στο κείμενο να περιλαμβάνει αλλαγές γραμμής και άλλους ειδικούς χαρακτήρες, αλλά μπορείς επίσης να ενσωματώσεις μεταβλητές και άλλες εκφράσεις.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Στο παραπάνω παράδειγμα, τα backticks - (<code>\`\`</code>) - χρησιμοποιούνται για να αναπαραστήσουν μια συμβολοσειρά προτύπου. Το `${...}` είναι ο υποκαταστάτης που χρησιμοποιείται για την αντικατάσταση.
Οποιοιδήποτε τύποι δεν είναι συμβολοσειρές μετατρέπονται _σιωπηρά_ σε συμβολοσειρές.
Αυτό το θέμα καλύπτεται στην έννοια της [μετατροπής τύπων][type-conversion-concept].
Με τις συμβολοσειρές προτύπων μπορούν να χρησιμοποιηθούν όλοι οι τύποι εκφράσεων.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Όταν χρειάζεται να μορφοποιήσεις συμβολοσειρές σε πολλές γραμμές:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Με τις διαθέσιμες δυνατότητες αντικατάστασης, μπορείς επίσης να εισάγεις λογική στη διαδικασία για να καθορίσεις ποια θα πρέπει να είναι η συμβολοσειρά εξόδου.

Ένα παράδειγμα αυτού είναι η ενσωμάτωση ενός [τριμερούς τελεστή][ternary-operator].
Αυτός ο τελεστής είναι μια σύντομη μορφή για τη γραφή μιας εντολής `if/else`.
Η σύνταξη είναι `condition ? consequent-expression : alternative-expression`.
Αν η συνθήκη είναι truthy, θα επιστραφεί ο τελεστέος στην αριστερή πλευρά της άνω και κάτω τελείας.
Διαφορετικά, το αποτέλεσμα της τριμερούς έκφρασης είναι ο τελεστέος στη δεξιά πλευρά της άνω και κάτω τελείας.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
