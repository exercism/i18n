# Υποδείξεις

## 1. Πάρε την πρώτη κάρτα

- [Αυτό το άρθρο][mdn-destructuring] έχει μια καλή επισκόπηση της αποδόμησης πινάκων. Μπορείς να βρεις ένα παράδειγμα βασικής ανάθεσης μεταβλητής στην ενότητα "Basic Array Destructuring".

## 2. Πάρε τη δεύτερη κάρτα

- Μπορείς να χρησιμοποιήσεις placeholders για να αγνοήσεις μία ή περισσότερες τιμές στον πίνακα.
- Μπορείς να βρεις ένα παράδειγμα [στο MDN][mdn-destructuring-ignore-value].

## 3. Αντάλλαξε τις δύο κάρτες

- Μπορείς να ανταλλάξεις δύο τιμές σε μία μόνο έκφραση αποδόμησης.
- Μπορείς να βρεις ένα παράδειγμα [στο MDN][mdn-destructuring-swapping].

## 4. Μετατόπισε τρεις κάρτες

- Μπορείς να αλλάξεις τη θέση τριών τιμών σε μία μόνο έκφραση αποδόμησης.
- Αυτό είναι το ίδιο με την ανταλλαγή δύο τιμών, απλώς με τρεις (ή περισσότερες).

## 5. Διάλεξε τη στοίβα με όνομα

- Τα αντικείμενα μπορούν να αποδομηθούν ακριβώς όπως οι πίνακες.
- Μπορείς να βρεις ένα παράδειγμα [στο MDN][mdn-object-destructuring-basic-assignment].

## 6. Αντάλλαξε τις στοίβες με όνομα

- Όταν μια ιδιότητα εξάγεται από ένα αντικείμενο, μπορεί να μετονομαστεί με ειδική σύνταξη.
- Μπορείς να βρεις ένα παράδειγμα [στο MDN][mdn-object-destructuring-object-rename].
