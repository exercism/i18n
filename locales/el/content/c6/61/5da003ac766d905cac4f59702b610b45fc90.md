# Υποδείξεις

## 1. Δημιούργησε έναν αριθμό ταυτότητας

- Η συνάρτηση θα πρέπει να επιστρέφει μια άλλη συνάρτηση.
- Η συνάρτηση που επιστρέφεται πρέπει να έχει πρόσβαση στην παράμετρο `day`.

## 2. Προστάτεψε τα ανακτημένα μυστικά σχέδια με έναν μυστικό κωδικό πρόσβασης

- Η συνάρτηση που επιστρέφεται έχει μόνο μία παράμετρο.
- Οι συμβολοσειρές μπορούν να συγκριθούν χρησιμοποιώντας την [ισότητα].

## 3. Βρες τον μυστικό κωδικό πρόσβασης

- Κάλεσε τη συνάρτηση του υπηρέτη με μια άλλη συνάρτηση που εκτελεί το δικό μας μέρος του αλγορίθμου.

[equality]: https://kotlinlang.org/docs/equality.html#structural-equality
