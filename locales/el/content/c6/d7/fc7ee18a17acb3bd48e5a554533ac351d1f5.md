# Υποδείξεις

## 1. Υπολόγισε τον χρόνο προετοιμασίας

- Χρησιμοποίησε το [`size()`][size-func] του vector για να βρεις τον αριθμό των στρώσεων (το μήκος του slice των στρώσεων).

## 2. Υπολόγισε τις ποσότητες νουντλς και σάλτσας που χρειάζονται

- Πρώτα, φτιάξε ένα αντικείμενο `amount` για να παρακολουθείς την ποσότητα νουντλς και σάλτσας.
- Χρησιμοποίησε έναν [`for` βρόχο][for-loop] για να διατρέξεις τις στρώσεις.
- Αν συναντήσεις μια στρώση `"noodles"` ή `"sauce"` μέσα στον βρόχο σου, αύξησε ανάλογα την ποσότητα που είναι αποθηκευμένη στο αντικείμενο `amount`.

## 3. Πρόσθεσε το μυστικό συστατικό

- Ξαναδές τα [vector][concept-vector] για να μάθεις πώς να ανακτήσεις ένα στοιχείο από ένα vector και πώς να αντικαταστήσεις ένα στοιχείο μέσα σε ένα vector.
- Η θέση του τελευταίου στοιχείου σε ένα vector `a` είναι `a.size() - 1` ή μπορείς να χρησιμοποιήσεις απευθείας το `a.back()`.

## 4. Πολλαπλασίασε τη συνταγή

- Πρώτα, φτιάξε ένα νέο slice ίδιου μεγέθους με το slice εισόδου
- Χρησιμοποίησε έναν [`for` βρόχο][for-loop] για να διατρέξεις το slice εισόδου και να δημιουργήσεις το slice εξόδου

## 5. Ξεκλείδωσε το οικογενειακό μυστικό

- Μπορείς να ξαναχρησιμοποιήσεις τον κώδικα από την εργασία 3.
- Αυτή η εργασία χρειάζεται [υπερφόρτωση συναρτήσεων][function overloading].
