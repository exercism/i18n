# Εισαγωγή

## Μέθοδοι επέκτασης

Οι μέθοδοι επέκτασης σου επιτρέπουν να προσθέσεις μεθόδους σε υπάρχοντες τύπους χωρίς να δημιουργήσεις νέο παράγωγο τύπο, χωρίς επαναμεταγλώττιση ή άλλη τροποποίηση του αρχικού τύπου. Ορίζονται ως στατικές μέθοδοι, αλλά καλούνται με τη σύνταξη μεθόδων στιγμιοτύπου. Πριν από την πρώτη τους παράμετρο μπαίνει ο τροποποιητής `this`, ο οποίος προσδιορίζει σε ποιον τύπο ενεργεί η μέθοδος, ενώ οι μέθοδοι αποκτούν εμβέλεια σε επίπεδο χώρου ονομάτων.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
