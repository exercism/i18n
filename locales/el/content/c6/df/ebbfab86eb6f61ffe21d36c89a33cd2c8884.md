# Εισαγωγή

Ενώ η Swift προσφέρει πλούσια λειτουργικότητα στην Standard Library της, μπορείς να αποκτήσεις πρόσβαση σε πολλά επιπλέον χαρακτηριστικά εισάγοντας εξωτερικές βιβλιοθήκες και frameworks.
Αυτά τα modules μπορεί να προέρχονται απευθείας από το έργο Swift (όπως ο [Swift Argument Parser][argument-parser]), από frameworks της πλατφόρμας της Apple (όπως το [Foundation][apple-foundation] και το [Network Framework][network-framework]), ή από βιβλιοθήκες τρίτων ανοιχτού κώδικα (όπως το [SwiftyBeaver][swifty-beaver]).

Τα βασικά modules, όπως το Foundation, μία από τις πιο ευρέως χρησιμοποιούμενες βιβλιοθήκες στη Swift, περιλαμβάνονται στην αλυσίδα εργαλείων της Swift.
Οι βιβλιοθήκες τρίτων πρέπει να προστεθούν στη διαμόρφωση του έργου σου (για παράδειγμα, χρησιμοποιώντας το Swift Package Manager) πριν μπορέσεις να τις εισαγάγεις.

Για να εισαγάγεις ένα module, γράψε τη λέξη-κλειδί `import` ακολουθούμενη από το όνομα του module:

```swift
import Foundation
```

Η εισαγωγή ενός module κάνει τους τύπους, τις μεθόδους και τις συναρτήσεις του διαθέσιμα στον κώδικά σου.
Για παράδειγμα, η εισαγωγή του Foundation επεκτείνει το `String` με χρήσιμες βοηθητικές μεθόδους, όπως τη `components(separatedBy:)`.

Κατά σύμβαση, οι εντολές `import` τοποθετούνται στην αρχή ενός αρχείου Swift, ώστε οι εξαρτήσεις να είναι αμέσως ορατές σε όποιον διαβάζει τον κώδικα.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
