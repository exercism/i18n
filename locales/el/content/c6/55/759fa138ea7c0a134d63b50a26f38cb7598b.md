# Φέτες πίτσας

## Ιστορία

Έχεις αρκετά καταστήματα στην πόλη σου που πουλάνε πίτσα σε φέτες και θέλεις να γράψεις μια διαδικτυακή εφαρμογή που θα σε αφήνει να συγκρίνεις δύο διαφορετικές διαμορφώσεις πίτσας για να ξέρεις ποιος θα σου δώσει τη μεγαλύτερη φέτα.

## Εργασίες

Η ιστορία διευκολύνει την εξερεύνηση των [προαιρετικών τύπων][types-option-types], οι οποίοι μπορούν να χρησιμοποιηθούν για να αναπαραστήσουν μια τιμή ή την απουσία μιας τιμής.

- Γράψε μια συνάρτηση που να υπολογίζει τα μεγέθη των φετών και να επιστρέφει nil για μη έγκυρη είσοδο
- Επεξεργάσου την είσοδο από τη διαδικτυακή εφαρμογή σου για να προσδιορίσεις τη μεγαλύτερη φέτα
