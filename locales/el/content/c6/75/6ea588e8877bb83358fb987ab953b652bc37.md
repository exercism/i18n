# Εισαγωγή

Το σύστημα σφαλμάτων της Factor έχει τρία μέρη: `throw` για να πετάξεις ένα σφάλμα, `recover` για να χειριστείς ένα, και `ERROR:` για να ορίσεις το δικό σου είδος σφάλματος.

## `throw`

Το `throw` (στο [`kernel`][kernel]) πετάει ένα σφάλμα. Το όρισμα μπορεί να είναι *οποιαδήποτε* τιμή, είτε συμβολοσειρά, είτε αριθμός, είτε tuple, και γίνεται το σφάλμα που μπορείς να εξετάσεις αργότερα:

```factor
! DOCTEST: SKIP
"file not found" throw
```

Το `throw` δεν επιστρέφει· η υπόλοιπη τρέχουσα λέξη παραλείπεται.

## `recover`

Το `recover` (στο [`continuations`][continuations]) είναι το try/catch της Factor. Παίρνει ένα *try* quotation και ένα *recovery* quotation:

```
recover ( try recovery -- )
```

Αν το `try` ολοκληρωθεί χωρίς να πετάξει σφάλμα, το `recovery` αγνοείται. Αν το `try` πετάξει σφάλμα, το σφάλμα ωθείται στη στοίβα και το `recovery` εκτελείται:

```factor
[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"

[ "ok" ] [ drop "never runs" ] recover .
! => "ok"
```

Το `when` από το [`kernel`][kernel] είναι ο φυσικός σύντροφός του: εκτελεί ένα quotation μόνο όταν η κορυφή της στοίβας είναι αληθής:

```factor
: check-positive ( n -- )
    0 < [ "negative!" throw ] when ;
```

## `ERROR:`

Το `ERROR:` ορίζει μια κλάση tuple *και* μια λέξη που κατασκευάζει ένα καινούριο στιγμιότυπο και το πετάει:

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

Ένα σφάλμα χωρίς slots είναι απλώς `ERROR: name ;`, και η κλήση του `name` πετάει ένα κενό στιγμιότυπο. Τα tuples που ορίζονται με το `ERROR:` φέρουν ένα predicate κλάσης, το `name?`, που μπορείς να το χρησιμοποιήσεις για να ελέγξεις αν ένα σφάλμα που έπιασες ήταν αυτού του τύπου.

## Διαβάζοντας ξανά τα slots

Ένα σφάλμα που έπιασες είναι απλώς ένα tuple, οπότε κάθε slot του `ERROR:` συνοδεύεται από τον ίδιο αυτόματα παραγόμενο reader `slot>>` όπως κάθε άλλο tuple.

```factor
! DOCTEST: SKIP
{
    T{ not-found { path "/a" } }
    T{ not-found { path "/b" } }
}
[ path>> ] map .   ! => { "/a" "/b" }
```
