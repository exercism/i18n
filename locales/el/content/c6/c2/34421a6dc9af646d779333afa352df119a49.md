# Τύποι συμβολοσειρών

Η Cairo δεν έχει εγγενή τύπο δεδομένων για συμβολοσειρές.
Ωστόσο, υπάρχουν δύο τρόποι για να αναπαραστήσεις έναν τύπο συμβολοσειράς: σύντομες συμβολοσειρές με ένα μόνο `felt252` και συμβολοσειρές αυθαίρετου μήκους με `ByteArray`.

## Σύντομες συμβολοσειρές

Μια σύντομη συμβολοσειρά σχηματίζεται με απλά εισαγωγικά, όπου κάθε χαρακτήρας που την αποτελεί κωδικοποιείται σε ένα byte σύμφωνα με το [πρότυπο ASCII][ascii-table].

Ως συμβολοσειρά ASCII, για παράδειγμα, το `'abc'` θα είναι:

- Το `'a'` ισοδυναμεί με το `0x61`
- Το `'b'` ισοδυναμεί με το `0x62`
- Το `'c'` ισοδυναμεί με το `0x63`
- Το `'abc'` ισοδυναμεί με το `0x616263`

Στη Cairo, ο τύπος δεδομένων `felt252` αποθηκεύει τις σύντομες συμβολοσειρές.
Καθώς το `felt252` περιέχει 251 bits, μια σύντομη συμβολοσειρά περιορίζεται σε 31 χαρακτήρες (31 \* 8 = 248 bits, που είναι το μεγαλύτερο πολλαπλάσιο του 8 που χωράει στα 251 bits).

Παραδείγματα δηλώσεων σύντομων συμβολοσειρών:

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

Το struct ByteArray εισήχθη στην Cairo 2.4.0.
Οι συμβολοσειρές ByteArray γράφονται με διπλά εισαγωγικά ως εξής:

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

Τεχνικά, η ενημέρωση εισήγαγε επίσης τον τύπο `bytes31`, ο οποίος χωράει 31 bytes και ταιριάζει μέσα σε ένα felt.
Το struct `ByteArray` αναπαριστά βασικά μια μεγάλη συμβολοσειρά χρησιμοποιώντας έναν πίνακα από `bytes31` που κρατούν τις "ολόκληρες λέξεις" (δηλαδή λέξεις που γεμίζουν ολόκληρο το felt) και ένα μόνο πεδίο felt που κρατά μια "ελλιπή λέξη" (ο αριθμός των bytes που περιέχει καθορίζεται σε ξεχωριστό πεδίο μήκους).

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```

[ascii-table]: https://www.asciitable.com/
