# Εισαγωγή

## Χαρακτήρες

### Χαρακτήρες

Ο πρωταρχικός τύπος `char` της Java είναι μια αναπαράσταση 16 bit ενός μεμονωμένου χαρακτήρα.
Πολλά `char` μπορούν να σχηματίσουν μια συμβολοσειρά, όπως η `"word"`, ή τα `char` μπορούν να υποστούν επεξεργασία ανεξάρτητα.
Ένα `char` literal περικλείεται από μονά εισαγωγικά (π.χ. `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Λαμβάνοντας τα `char` μιας `String`

Η μέθοδος `String.toCharArray` επιστρέφει τα char μιας String ως πίνακα.
Όπως αναφέρθηκε στους πίνακες, μπορείς να χρησιμοποιήσεις έναν `for` βρόχο για να διατρέξεις τον πίνακα.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### Η κλάση Character

Υπάρχουν πολλές έτοιμες μέθοδοι της βιβλιοθήκης για να εξετάσεις και να χειριστείς `char`.
Μπορείς να τις βρεις ως στατικές μεθόδους της κλάσης `java.lang.Character`.
Ορίστε μερικά παραδείγματα:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Προσθέτοντας ένα `char` σε μια `String`

Ο τελεστής `+` μπορεί να χρησιμοποιηθεί για να προσθέσεις ένα `char` σε μια `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
Πρόσεξε να _μην_ χρησιμοποιήσεις τον `+` για να ενώσεις δύο `char` και να σχηματίσεις μια `String`!
Το να προσθέσεις δύο `char` με αυτόν τον τρόπο δίνει ένα `int`, _όχι_ μια `String`!
Για παράδειγμα:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Αυτό συμβαίνει επειδή η Java προάγει το `char` σε `int` (βλ. [4.2 Πρωταρχικοί Τύποι και Τιμές ][jls-primitives] της [Προδιαγραφής της Γλώσσας Java][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Ωστόσο, όταν υπάρχουν πολλοί χαρακτήρες που πρέπει να προστεθούν, μπορεί να είναι πιο αποδοτικό να χρησιμοποιήσεις ένα `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
