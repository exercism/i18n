# Εισαγωγή

## Ξεκινώντας

### Μεταβλητές

Οι τιμές μπορούν να συσχετιστούν με ονόματα ορίζοντας μια [μεταβλητή][constants-variables] και αναθέτοντας μια τιμή σε αυτή τη μεταβλητή.
Το όνομα αυτό μπορεί έπειτα να χρησιμοποιηθεί για να αναφέρεται σε αυτή την τιμή σε όλο το πρόγραμμα.
Οι μεταβλητές είναι _μεταβλητές_, που σημαίνει ότι η τιμή μπορεί να αλλάξει οποιαδήποτε στιγμή.

Οι μεταβλητές ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `var`.

```swift
var variableName = 10
```

Η Swift είναι μια γλώσσα με ασφάλεια τύπων και στατικούς τύπους, που σημαίνει ότι όλες οι τιμές έχουν τύπο κατά τη μεταγλώττιση.
Μπορείς είτε να προσδιορίσεις ρητά τον τύπο μιας μεταβλητής με [σημειώσεις τύπου][type annotations] είτε να αφήσεις τον μεταγλωττιστή να [συμπεράνει τον τύπο][type-inferring].

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed
```

Η ενημέρωση της τιμής μιας μεταβλητής γίνεται με τον τελεστή `=`.

~~~~exercism/note
Ο τύπος μιας μεταβλητής είναι σταθερός από τη στιγμή που ορίζεται αρχικά.

```swift
variableName = 13 // update to new value

// compiler error when assigning a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

Οι μεταβλητές μπορούν να δηλωθούν χωρίς να τους ανατεθεί κάποια τιμή, προσδιορίζοντας το όνομα και τον τύπο, αλλά δεν μπορούν να χρησιμοποιηθούν προτού τους ανατεθεί μια τιμή.

```swift
var someInt: Int

// This would trigger a compiler error
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value to the names
someInt = 169

print(someInt) // Prints '169'
```

### Σταθερές

Οι [σταθερές][constants-variables] είναι παρόμοιες με τις μεταβλητές στο ότι συσχετίζονται με ένα όνομα και μια τιμή, αλλά η τιμή μιας σταθεράς δεν μπορεί να αλλάξει αφού ανατεθεί αρχικά και έτσι είναι _αμετάβλητη_.
Οι σταθερές ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `let` (έστω).

```swift
let constantName = 10          // constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### Πρόσθεση, αφαίρεση και πολλαπλασιασμός

Η Swift έχει [τελεστές][arithmetical-operators] για την πρόσθεση, την αφαίρεση και τον πολλαπλασιασμό.
Οι τελεστές είναι `+`, `-` και `*` αντίστοιχα.

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### Συναρτήσεις

Στη Swift, οι [συναρτήσεις][functions] είναι ένα κομμάτι κώδικα που εκτελεί μια εργασία.
Μια συνάρτηση έχει τύπο επιστροφής και επομένως μπορεί να χρησιμοποιηθεί ως τιμή και να περαστεί ως όρισμα σε άλλες συναρτήσεις.
Στη Swift, οι συναρτήσεις ορίζονται χρησιμοποιώντας τη λέξη-κλειδί `func` που ακολουθείται από το όνομα της συνάρτησης, ορίσματα χωρισμένα με κόμματα και έναν τύπο επιστροφής.

Τα ορίσματα ορίζονται από μια ετικέτα ορίσματος, ένα όνομα παραμέτρου που ακολουθείται από άνω και κάτω τελεία και έπειτα από έναν τύπο.
Ο τύπος επιστροφής ορίζεται από ένα `->` που ακολουθείται από τον τύπο της τιμής επιστροφής.

```swift
func functionName(argumentName parameterName: ArgumentType) -> ReturnType {
  // function body
}
```

Τα ορίσματα στη Swift είναι λίγο ιδιαίτερα σε σύγκριση με άλλες γλώσσες, χρησιμοποιούν [ετικέτες ορίσματος][argument-labels].
Η ετικέτα ορίσματος χρησιμοποιείται όταν καλείς τη συνάρτηση.
Το όνομα παραμέτρου χρησιμοποιείται μέσα στο σώμα της συνάρτησης για να αναφέρεται στην τιμή του ορίσματος.
Αν δώσεις μόνο ένα όνομα στο όρισμα, αυτό θα χρησιμοποιηθεί και ως ετικέτα ορίσματος και ως όνομα παραμέτρου.
Όταν δώσεις ως όνομα ετικέτας ορίσματος το `_`, το όρισμα δεν θα έχει ετικέτα όταν καλείς τη συνάρτηση, π.χ. `functionName(argumentValue)`

Για να καλέσεις μια συνάρτηση, χρησιμοποιείς το όνομα της συνάρτησης που ακολουθείται από την ετικέτα ορίσματος και την τιμή του ορίσματος, κάπως έτσι:

```swift
func functionName(argumentLabel parameterName: ArgumentType) -> ReturnType {
  // function body
}

// calling the function
functionName(argumentLabel: argumentValue)
```

Όλα τα ορίσματα είναι αμετάβλητα από προεπιλογή και δεν μπορούν να αλλάξουν μέσα στη συνάρτηση.
Όταν μια συνάρτηση έχει τύπο επιστροφής, φρόντισε να επιστρέψεις μια τιμή αυτού του τύπου.
Αυτό γίνεται χρησιμοποιώντας τη λέξη-κλειδί `return` που ακολουθείται από την τιμή που θα επιστραφεί.

```swift
func addTen(number value: Int) -> Int {
  return value + 10
}

// calling the function
addTen(number: 10) // Returns 20
```

Όταν οι συναρτήσεις δεν επιστρέφουν κάποια τιμή, έχουν τύπο επιστροφής `Void`, που είναι το ίδιο με `()`, αλλά σε αυτές τις περιπτώσεις ο τύπος επιστροφής μπορεί να παραλειφθεί.

### Σχόλια

Η Swift υποστηρίζει δύο τύπους [σχολίων][comments].
Τα σχόλια μιας γραμμής προηγούνται από `//` και τα σχόλια πολλών γραμμών εισάγονται ανάμεσα σε `/*` και `*/`.
