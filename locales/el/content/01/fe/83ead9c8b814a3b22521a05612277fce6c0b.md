# Συναρτήσεις

Οι συναρτήσεις είναι θεμελιώδεις στη Cairo.

Κατά σύμβαση, η Cairo χρησιμοποιεί **snake case** για ονόματα συναρτήσεων και μεταβλητών, όπου οι λέξεις είναι πεζές και χωρίζονται με κάτω παύλες.

Ας δούμε ένα παράδειγμα:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Οι συναρτήσεις ορίζονται με `fn`, ακολουθούμενο από ένα όνομα, παρενθέσεις για τις παραμέτρους (αν υπάρχουν) και ένα σώμα που περικλείεται σε άγκιστρα.

Μπορείς να καλέσεις μια συνάρτηση με το όνομά της, ακολουθούμενο από παρενθέσεις.

Η σειρά των συναρτήσεων δεν έχει σημασία, αρκεί να βρίσκονται στο πεδίο εφαρμογής.

## Παράμετροι

Οι συναρτήσεις μπορούν να δέχονται **παραμέτρους**, που είναι μεταβλητές ορισμένες στην υπογραφή της συνάρτησης.

Όταν καλείς τη συνάρτηση, δίνεις **ορίσματα**, τις τιμές που περνούν σε αυτές τις παραμέτρους.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Εδώ, το `x` είναι παράμετρος τύπου `felt252`.

Όταν καλείται με `5`, η συνάρτηση τυπώνει "The value of x is: 5".

Οι πολλαπλές παράμετροι χωρίζονται με κόμματα:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Αυτό τυπώνει: `The measurement is: 5h`.

## Εντολές και εκφράσεις

Οι συναρτήσεις της Cairo αποτελούνται από **εντολές** και **εκφράσεις**:

- Οι **εντολές** εκτελούν ενέργειες αλλά δεν επιστρέφουν τιμές.
Για παράδειγμα, το `let x = 3;` είναι μια εντολή.
- Οι **εκφράσεις** αποτιμώνται σε μια τιμή.
Για παράδειγμα, το `5 + 6` αποτιμάται σε `11`.

Τα μπλοκ που περικλείονται σε άγκιστρα είναι επίσης εκφράσεις και η τελική τους τιμή επιστρέφεται:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Εδώ, στο `y` ανατίθεται η τιμή `4`.

## Τιμές επιστροφής

Οι συναρτήσεις μπορούν να επιστρέφουν τιμές χρησιμοποιώντας τη σύνταξη `->` για να προσδιορίσουν τον τύπο επιστροφής.

Από προεπιλογή, μια συνάρτηση επιστρέφει την τιμή της τελευταίας έκφρασής της:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Αυτό βγάζει: `The value of x is: 5`.

Για πιο σύνθετες περιπτώσεις:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Αυτό τυπώνει: `The value of x is: 6`.

Πρόσεξε να μην προσθέσεις ερωτηματικό στο τέλος της τελικής έκφρασης, γιατί θα μετέτρεπε την έκφραση σε εντολή, με αποτέλεσμα η συνάρτηση να επιστρέφει `()` (τύπος μονάδας) αντί για την αναμενόμενη τιμή.
