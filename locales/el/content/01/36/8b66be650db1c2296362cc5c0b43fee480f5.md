# Debug

Μπορείς να χρησιμοποιήσεις το [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) για να επισυνάψεις μηνύματα σε tests που αποτυγχάνουν, όπως εδώ:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

Σε ένα test που αποτυγχάνει, το log που επισυνάπτεται θα είναι `secondsInOneHour: 3600`.

Υπάρχει μία επιφύλαξη: οι σταθερές στο ανώτερο επίπεδο αξιολογούνται μόνο μία φορά πριν αρχίσουν να τρέχουν τα tests, οπότε τα tests δεν μπορούν να πιάσουν τα μηνύματα που καταγράφουν. Για παράδειγμα:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

δεν θα καταγράψει τίποτα κατά τη διάρκεια των tests, επειδή η μεταβλητή JavaScript που σχετίζεται με το `secondsInOneHour` έχει ήδη αξιολογηθεί στην τιμή 3600.
