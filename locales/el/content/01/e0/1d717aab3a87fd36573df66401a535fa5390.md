# Προσθήκη στις οδηγίες

## Μορφή εξόδου

Δώσε τους στίχους ως συμβολοσειρά τερματισμένη με null.

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                      |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος      | ακέραιος | στίχος έναρξης                |
| `$a1`    | είσοδος      | ακέραιος | στίχος λήξης                  |
| `$a2`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματισμένη με null |
| `$t0-9`  | προσωρινός   | οτιδήποτε | για προσωρινή αποθήκευση      |
