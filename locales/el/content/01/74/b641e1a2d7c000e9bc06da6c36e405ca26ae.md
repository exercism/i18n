# Χρησιμοποίησε αναδρομή ουράς

Ο σκοπός αυτής της άσκησης είναι να διδάξει την αναδρομή ουράς. Λύσε την χωρίς να χρησιμοποιήσεις αναδρομικές συναρτήσεις που δεν κάνουν αναδρομή ουράς.

Συναρτήσεις με αναδρομή ουράς που βρέθηκαν στη λύση σου: %{tail_call_recursive_functions}. Άλλες αναδρομικές συναρτήσεις που βρέθηκαν στη λύση σου: %{non_tail_call_recursive_functions}.

Θυμήσου ότι η αναδρομή ουράς συμβαίνει όταν η _τελευταία_ έκφραση που αξιολογείται από τη συνάρτηση είναι μια κλήση στον εαυτό της.

```elixir
# this is tail call recursion,
# the last expression is a call to `do_encode`
defp do_encode([n | rest], acc) do
  do_encode(rest, <<acc::bitstring, encode_nucleotide(n)::4>>)
end

# this is not tail call recursion,
# the last expression is a call to `<<>>`
def encode([head | tail]) do
  <<encode_nucleotide(head)::4, encode(tail)::bitstring>>
end
```
