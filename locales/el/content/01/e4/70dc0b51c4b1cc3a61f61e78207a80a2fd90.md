# Εισαγωγή

## Συμβολοσειρές

Στη F#, το `string` είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.) και ορίζεται ως εξής:

```fsharp
let fruit = "Apple"
```

Οι συμβολοσειρές χειρίζονται είτε καλώντας τις μεθόδους της συμβολοσειράς είτε χρησιμοποιώντας τις συναρτήσεις που παρέχει το `String`. Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί να αλλάξει ποτέ. Οποιεσδήποτε μέθοδοι/συναρτήσεις φαίνεται να τροποποιούν μια συμβολοσειρά, στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.

Οι συμβολοσειρές μπορούν να συνενωθούν ή να μορφοποιηθούν με μερικούς διαφορετικούς τρόπους.
* Μπορείς να χρησιμοποιήσεις τον τελεστή `+` για συνένωση:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Μπορείς να χρησιμοποιήσεις τη συνάρτηση `sprintf` για μορφοποίηση κειμένου, όπου έχεις σύμβολα αντικατάστασης σε ένα κείμενο μορφοποίησης (το `%s` για μια `string`) και παρέχεις τις τιμές ως ορίσματα:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
