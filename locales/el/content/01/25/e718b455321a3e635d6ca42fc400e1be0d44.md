# Οδηγίες

Αν θέλεις να φτιάξεις κάτι με ένα Raspberry Pi, πιθανότατα θα χρειαστείς _αντιστάτες_.
Για αυτήν την άσκηση, πρέπει να ξέρεις δύο πράγματα για αυτούς:

- Κάθε αντιστάτης έχει μια τιμή αντίστασης.
- Οι αντιστάτες είναι μικροί, τόσο μικροί μάλιστα που αν τύπωνες πάνω τους την τιμή αντίστασης, θα ήταν δύσκολο να τη διαβάσεις.

Για να ξεπεραστεί αυτό το πρόβλημα, οι κατασκευαστές τυπώνουν πάνω στους αντιστάτες χρωματιστές λωρίδες που δηλώνουν την τιμή αντίστασής τους.
Κάθε λωρίδα έχει μια θέση και μια αριθμητική τιμή.

Οι δύο πρώτες λωρίδες ενός αντιστάτη έχουν ένα απλό σχήμα κωδικοποίησης: κάθε χρώμα αντιστοιχεί σε έναν μόνο αριθμό.

Σε αυτήν την άσκηση θα φτιάξεις ένα βοηθητικό πρόγραμμα, ώστε να μη χρειάζεται να θυμάσαι τις τιμές των λωρίδων.

Αυτά τα χρώματα κωδικοποιούνται ως εξής:

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

Ο στόχος αυτής της άσκησης είναι να φτιάξεις έναν τρόπο:

- να αναζητάς την αριθμητική τιμή που αντιστοιχεί σε μια συγκεκριμένη χρωματιστή λωρίδα
- να απαριθμείς τα διάφορα χρώματα των λωρίδων

Οι μνημονικοί κανόνες συνδέουν τα χρώματα με τους αριθμούς, οι οποίοι, όταν αποθηκεύονται σε έναν πίνακα, τυγχάνει να αντιστοιχούν στη θέση τους μέσα στον πίνακα:
Better Be Right Or Your Great Big Values Go Wrong.

Περισσότερες πληροφορίες για τη χρωματική κωδικοποίηση των αντιστατών μπορείς να βρεις στο [άρθρο της Wikipedia για τον ηλεκτρονικό χρωματικό κώδικα][e-color-code].
