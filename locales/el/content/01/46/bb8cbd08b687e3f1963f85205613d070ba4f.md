# Εισαγωγή

Οι εντολές υπό συνθήκη είναι εντολές που εκτελούν διαφορετικό κώδικα ανάλογα με το αν μια συνθήκη είναι `true` ή `false`.

Μια εντολή `if` εκτελεί το σώμα της μόνο όταν η συνθήκη της είναι `true`.
Η Go δεν έχει την έννοια των truthy ή falsy τιμών, οπότε η συνθήκη πρέπει να είναι τύπου `bool`.
Εκφράσεις όπως `if mySlice { ... }` ή `if 1 { ... }` είναι σφάλματα μεταγλώττισης.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Χρησιμοποίησε `else if` για να ελέγξεις επιπλέον συνθήκες και `else` ως εναλλακτική αν δεν ταιριάζει καμία.
Οι συνθήκες αξιολογούνται από πάνω προς τα κάτω και εκτελείται μόνο ο πρώτος κλάδος του οποίου η συνθήκη είναι αληθής.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Μια εντολή `if` μπορεί επίσης να περιλαμβάνει μια σύντομη εντολή αρχικοποίησης.
Οι μεταβλητές που δηλώνονται με αυτόν τον τρόπο έχουν εμβέλεια μόνο μέσα σε ολόκληρη την αλυσίδα `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
