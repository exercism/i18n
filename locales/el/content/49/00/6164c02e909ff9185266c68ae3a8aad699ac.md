# Οδηγίες

Ο Ozan ετοιμάζει μια λίστα αναπαραγωγής για ένα επερχόμενο ταξίδι με αυτοκίνητο. Δεν θέλει να ακούσει το ίδιο κομμάτι περισσότερο από μία φορά, αλλά η λίστα έχει γίνει τόσο μεγάλη που δυσκολεύεται να θυμηθεί ποια κομμάτια έχει ήδη προσθέσει.

Το API του music player του Ozan ξέρει να δουλεύει μόνο με πίνακες, οπότε προσπαθεί να γράψει κάποιον κώδικα που χρησιμοποιεί το `Array.indexOf()` για να ελέγξει αν υπάρχει ένα κομμάτι πριν το προσθέσει στη λίστα αναπαραγωγής. Δυστυχώς, το πρόγραμμά του αργεί υπερβολικά να εκτελεστεί. Χρειάζεται τη βοήθειά σου!

Σπεύδοντας να βοηθήσεις τον Ozan, εκπλήσσεσαι όταν ανακαλύπτεις ότι η λίστα του περιέχει _μισό εκατομμύριο_ κομμάτια. Μήπως ξέρεις κάποια διαφορετική δομή δεδομένων που θα σου επιτρέψει να χειριστείς τη λίστα πιο αποδοτικά;

## 1. Αφαίρεσε τα διπλότυπα κομμάτια

Υλοποίησε τη συνάρτηση `removeDuplicates`, η οποία παίρνει μια λίστα αναπαραγωγής ως _παράμετρο_ και _επιστρέφει_ μια νέα λίστα όπου όλα τα κομμάτια είναι μοναδικά.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Έλεγξε αν ένα κομμάτι έχει ήδη προστεθεί

Υλοποίησε τη συνάρτηση `hasTrack`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα κομμάτι ως _παραμέτρους_ και _επιστρέφει_ μια Boolean (λογική τιμή) που δείχνει αν η λίστα περιέχει το κομμάτι.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Πρόσθεσε ένα κομμάτι

Υλοποίησε τη συνάρτηση `addTrack`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα κομμάτι ως _παραμέτρους_ και _επιστρέφει_ μια νέα λίστα που περιλαμβάνει το κομμάτι.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Διάγραψε ένα κομμάτι

Υλοποίησε τη συνάρτηση `deleteTrack`, η οποία παίρνει μια λίστα αναπαραγωγής και ένα κομμάτι ως _παραμέτρους_ και _επιστρέφει_ μια νέα λίστα που δεν περιλαμβάνει το κομμάτι.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Κάνε λίστα με τους μοναδικούς καλλιτέχνες

Υλοποίησε τη συνάρτηση `listArtists`, η οποία παίρνει μια λίστα αναπαραγωγής ως _παράμετρο_ και _επιστρέφει_ τη λίστα με τους μοναδικούς καλλιτέχνες της λίστας αναπαραγωγής. Σημείωσε ότι τα ονόματα των κομματιών έχουν τη μορφή `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
