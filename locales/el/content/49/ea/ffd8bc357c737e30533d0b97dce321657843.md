# Εισαγωγή

Η φίλη σου η Eliud κληρονόμησε μια φάρμα από τη γιαγιά της, την Tigist.
Η γιαγιά της ήταν εφευρέτρια και είχε την τάση να φτιάχνει τα πράγματα με υπερβολικά περίπλοκο τρόπο.
Το κοτέτσι έχει μια ψηφιακή οθόνη που δείχνει έναν κωδικοποιημένο αριθμό, ο οποίος αντιπροσωπεύει τις θέσεις όλων των αυγών που θα μπορούσαν να μαζευτούν.

Ο Eliud σου ζητάει να γράψεις ένα πρόγραμμα που δείχνει τον πραγματικό αριθμό των αυγών στο κοτέτσι.

Η κωδικοποίηση των πληροφοριών θέσης υπολογίζεται ως εξής:

1. Σάρωσε τα πιθανά σημεία όπου μπορούν να γεννηθούν αυγά και σημείωσε `1` για ένα αυγό που υπάρχει ή `0` για μια κενή θέση.
2. Μετέτρεψε τον αριθμό από δυαδικό σε δεκαδικό.
3. Δείξε το αποτέλεσμα στην οθόνη.

Παράδειγμα 1:

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

Παράδειγμα 2:

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
