# Οδηγίες

Σε αυτή την άσκηση, παίζεις ένα παιχνίδι μαντεψιάς αριθμών με έναν φίλο σου. Οι κανόνες είναι απλοί: επιλέγεις κρυφά έναν αριθμό μεταξύ `1` και `100` και ο φίλος σου προσπαθεί να μαντέψει ποιον αριθμό έχεις επιλέξει. Για να βοηθήσεις τον φίλο σου, απαντάς διαφορετικά ανάλογα με το πόσο κοντά ήταν η μαντεψιά στον αριθμό που έχεις επιλέξει (`42`). Αυτοί είναι οι κανόνες για τις διαφορετικές απαντήσεις:

- Αν η μαντεψιά είναι `42`: "Correct"
- Αν η μαντεψιά είναι `41` ή `43`: "So close"
- Αν η μαντεψιά είναι μικρότερη από `41`: "Too low"
- Αν η μαντεψιά είναι μεγαλύτερη από `43`: "Too high"

Έχεις τέσσερις εργασίες για να κωδικοποιήσεις τις απαντήσεις στις μαντεψιές.

## 1. Απάντησε σε μια σωστή μαντεψιά

Υλοποίησε τη συνάρτηση `reply` ώστε να απαντά σε μια σωστή μαντεψιά:

```gleam
reply(42)
// -> "Correct"
```

## 2. Απάντησε σε μια κοντινή μαντεψιά

Τροποποίησε τη συνάρτηση `reply` ώστε να απαντά σε κοντινές μαντεψιές:

```gleam
reply(41)
// -> "So close"
```

## 3. Απάντησε σε πολύ χαμηλές μαντεψιές

Τροποποίησε τη συνάρτηση `reply` ώστε να απαντά σε πολύ χαμηλές μαντεψιές:

```gleam
reply(25)
// -> "Too low"
```

## 4. Απάντησε σε πολύ υψηλές μαντεψιές

Τροποποίησε τη συνάρτηση `reply` ώστε να απαντά σε πολύ υψηλές μαντεψιές:

```gleam
reply(88)
// -> "Too high"
```
