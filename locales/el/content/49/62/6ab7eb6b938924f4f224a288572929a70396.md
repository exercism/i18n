# Οδηγίες

Σε αυτή την άσκηση θα μοντελοποιήσεις μια ζυγαριά.

## 1. Δημιούργησε μια αρχική κατάσταση για τη ζυγαριά

Όταν αρχικοποιείται, η ζυγαριά θα πρέπει να βασίζεται στις εργοστασιακές ρυθμίσεις της, οι οποίες διαφέρουν ανάλογα με τον τόπο όπου πωλείται η μηχανή.
Έτσι, η μηχανή θα πρέπει να μπορεί να αρχικοποιηθεί με μια ακρίβεια και με το αν χρησιμοποιεί το μετρικό ή το αγγλοσαξονικό σύστημα.

Υλοποίησε τη μέθοδο `WeighingMachine#initialize` που δέχεται δύο ορίσματα, το `precision` που είναι `Int32` και το `metric` που είναι `Bool`.
Το όρισμα `metric`, όταν είναι `true`, σημαίνει ότι η μηχανή θα πρέπει να χρησιμοποιεί το μετρικό σύστημα, αλλιώς θα πρέπει να χρησιμοποιεί το αγγλοσαξονικό σύστημα.
Η μέθοδος initialize θα πρέπει επίσης να ορίζει τη μεταβλητή στιγμιοτύπου `@weight` σε `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Επίτρεψε στη ζυγαριά να έχει ακρίβεια

Για να καλύψουμε διαφορετικές απαιτήσεις, επιτρέπουμε σε κάθε ζυγαριά να προσαρμόζεται με ακρίβεια (τον αριθμό των ψηφίων μετά το δεκαδικό σύμβολο).

Υλοποίησε τη μέθοδο getter `WeighingMachine#precision` ώστε να επιστρέφει την ακρίβεια της ζυγαριάς.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Επίτρεψε να οριστεί το βάρος στη ζυγαριά

Υλοποίησε την ιδιότητα `WeighingMachine#weight` ώστε να επιτρέπεται η ανάγνωση _και_ ο ορισμός του βάρους:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Επίτρεψε στη μηχανή να εναλλάσσεται μεταξύ μετρικών και αγγλοσαξονικών μονάδων

Υλοποίησε την ιδιότητα `WeighingMachine#metric=` ώστε να επιτρέπεται ο ορισμός της μονάδας.
Θα πρέπει να δέχεται μια τιμή Boolean (λογική τιμή).

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
