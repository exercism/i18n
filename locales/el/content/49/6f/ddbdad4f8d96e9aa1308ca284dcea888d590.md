# Σχετικά

Το Factor συγκεντρώνει την τυχαιότητα στο λεξιλόγιο [`random`][random] γύρω από μια μόνο γενική λέξη:

```
random ( obj -- elt )
```

Επιλέγει με βάση το όρισμά της:

- ένας **ακέραιος** `n` δίνει έναν τυχαίο ακέραιο στο `[0, n)`;
- μια **ακολουθία** δίνει ένα τυχαίο στοιχείο;
- υποστηρίζονται επίσης assocs, hash-sets και πλειάδες `uniform-distribution`.

Πάνω της χτίζονται δύο βοηθητικές λέξεις για ακολουθίες:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

Το `randomize` μεταβάλλει και επιστρέφει την ακολουθία, οπότε κάνε πρώτα `clone` αν χρειάζεται να κρατήσεις την αρχική σειρά.

## Από πού προέρχεται η τυχαιότητα

Το `random` διαβάζει τη γεννήτρια που βρίσκεται στη δυναμική μεταβλητή `random-generator`. Από προεπιλογή, αυτή είναι ένας Mersenne Twister με σπόρο από το ρολόι του συστήματος, οπότε κάθε διεργασία διαφέρει. Μπορείς να εγκαταστήσεις μια διαφορετική γεννήτρια για όσο διαρκεί ένα quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Επειδή το `with-random` απλώς δεσμεύει τη `random-generator` για τη δυναμική έκταση του quotation, μια λέξη που την περιτυλίγει θα πρέπει να σημειώνεται ως `inline`, ώστε το quotation να μπορεί να αφήσει το αποτέλεσμα του στη στοίβα για αυτόν που το καλεί.

Πέρα από αυτά, το `random` προσφέρει τα `random-bits`, `random-unit`, `uniform-random` και `normal-random` για άλλες κατανομές, καθώς και τα `system-random-generator` και `secure-random-generator` για μη αναπαραγώγιμες και κρυπτογραφικές ανάγκες.

[random]: https://docs.factorcode.org/content/vocab-random.html
