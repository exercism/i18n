# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση      | Τύπος   | Περιγραφή                        |
| -------- | --------- | ------- | -------------------------- |
| `$a0`    | είσοδος   | ακέραιος | αριθμός εισόδου           |
| `$v0`    | έξοδος    | ακέραιος | αριθμός των αυγών         |
| `$t0-9`  | προσωρινός | οποιοδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
