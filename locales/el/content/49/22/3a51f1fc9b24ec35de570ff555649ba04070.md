# Οδηγίες

Αναπτύσσεις το δικό σου βιντεοπαιχνίδι ρόλων. Στο παιχνίδι σου υπάρχουν _χαρακτήρες_ και _αντικείμενα_. Μία από τις πολλές ενέργειες που μπορείς να κάνεις με ένα αντικείμενο είναι να κάνεις έναν χαρακτήρα να το φάει.

Δεν είναι όλα τα αντικείμενα φαγώσιμα, και δεν έχουν όλα τα φαγώσιμα αντικείμενα τα ίδια αποτελέσματα στον χαρακτήρα. Κάποια αντικείμενα, όταν καταναλώνονται, μετατρέπονται σε ένα διαφορετικό αντικείμενο (π.χ. αν φας ένα μήλο, σου μένει το κουκούτσι του μήλου).

Για να επιτρέψεις όλη αυτή την ευελιξία, αποφάσισες να δημιουργήσεις ένα πρωτόκολλο `Edible` που μερικά από τα αντικείμενα μπορούν να υλοποιήσουν.

## 1. Όρισε την έννοια του φαγώσιμου

Δημιούργησε το πρωτόκολλο `RPG.Edible`. Το πρωτόκολλο έχει μία συνάρτηση: την `eat`. Η συνάρτηση `eat` δέχεται ένα αντικείμενο και έναν χαρακτήρα και επιστρέφει ένα υποπροϊόν και έναν χαρακτήρα.

## 2. Κάνε τα καρβέλια ψωμιού φαγώσιμα

Υλοποίησε το πρωτόκολλο `RPG.Edible` για το αντικείμενο `RPG.LoafOfBread`. Όταν καταναλωθεί, ένα καρβέλι ψωμί δίνει στον χαρακτήρα 5 πόντους υγείας και δεν έχει υποπροϊόν.

```elixir
RPG.Edible.eat(%RPG.LoafOfBread{}, %RPG.Character{health: 31})
# => {nil, %RPG.Character{health: 36, mana: 0}}
```

## 3. Κάνε τα φίλτρα μάνα φαγώσιμα

Υλοποίησε το πρωτόκολλο `RPG.Edible` για το αντικείμενο `RPG.ManaPotion`. Όταν καταναλωθεί, ένα φίλτρο μάνα δίνει στον χαρακτήρα πόντους μάνα ίσους με τη δύναμη του φίλτρου, και παράγει ένα άδειο μπουκάλι.

```elixir
RPG.Edible.eat(%RPG.ManaPotion{strength: 13}, %RPG.Character{mana: 50})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 100, mana: 63}}
```

## 4. Κάνε τα δηλητήρια φαγώσιμα

Υλοποίησε το πρωτόκολλο `RPG.Edible` για το αντικείμενο `RPG.Poison`. Όταν καταναλωθεί, ένα δηλητήριο αφαιρεί όλους τους πόντους υγείας από τον χαρακτήρα, και παράγει ένα άδειο μπουκάλι.

```elixir
RPG.Edible.eat(%RPG.Poison{}, %RPG.Character{health: 3000})
# => {%RPG.EmptyBottle{}, %RPG.Character{health: 0, mana: 0}}
```
