# Συμβουλές

## Γενικά

- Θα χρειαστεί να ορίσεις [συναρτήσεις][functions] και να χρησιμοποιήσεις [αριθμητικούς τελεστές][arithmetics].

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Όρισε τη συνάρτηση χωρίς ορίσματα `expected_minutes_in_oven()`.
- Στο σώμα της συνάρτησης, μπορείς να [εκχωρήσεις][assign] αυτή την τιμή σε μια μεταβλητή και να την επιστρέψεις, ή απλώς να επιστρέψεις την τιμή.

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Όρισε τη συνάρτηση με ένα όρισμα `remaining_time_in_minutes()`.
- Χρησιμοποίησε τον [αριθμητικό τελεστή `minus`][arithmetics] για να αφαιρέσεις το όρισμα από το `60`.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Όρισε τη συνάρτηση με ένα όρισμα `prep_time_in_minutes()`.
- Χρησιμοποίησε τον [αριθμητικό τελεστή `times`][arithmetics] για να πολλαπλασιάσεις το όρισμα με το `2`.

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

- Όρισε τη συνάρτηση με δύο ορίσματα `elapsed_time_in_minutes()`.
- Μπορείς να ξαναχρησιμοποιήσεις τη συνάρτηση `prep_time_in_minutes()` που όρισες στην προηγούμενη εργασία.
- Χρησιμοποίησε τον [αριθμητικό τελεστή `plus`][arithmetics] για να προσθέσεις την τιμή επιστροφής του `prep_time_in_minutes` στο όρισμα.
