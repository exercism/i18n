# Εισαγωγή

## Συναρτήσεις

Μπορείς να ορίσεις τις δικές σου **προσαρμοσμένες συναρτήσεις** στο `jq` για να ενσωματώσεις όποια λογική χρειάζεσαι.
Οι _συναρτήσεις_ λειτουργούν ακριβώς όπως οι ενσωματωμένες: παίρνουν μια είσοδο και παράγουν μηδέν, μία ή περισσότερες εξόδους.

### Ορισμός συνάρτησης

Μπορείς να ορίσεις μια _συνάρτηση_ `jq` χρησιμοποιώντας την εξής σύνταξη:

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- ξεκινάει με τη λέξη-κλειδί `def`,
- άνω κάτω τελεία πριν από το σώμα της συνάρτησης,
- το σώμα αποτελείται από μία μόνο έκφραση,
- τελειώνει με ερωτηματικό,
- όπως και στην υπόλοιπη σύνταξη του `jq`, μπορείς να χρησιμοποιήσεις όποια κενά θέλεις για ευαναγνωσιμότητα.

### Πού να βάζεις τις συναρτήσεις

Οι _συναρτήσεις_ πρέπει να ορίζονται πριν χρησιμοποιηθούν: αυτό είναι σφάλμα:

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

Αυτό σημαίνει ότι πρέπει να τοποθετείς τις _συναρτήσεις_ στην αρχή του κώδικα `jq`, πριν από την "κύρια" έκφραση.

#### Εμφωλευμένες συναρτήσεις

Οι _συναρτήσεις_ μπορούν να είναι εμφωλευμένες:

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

Εδώ, η _συνάρτηση_ `B` είναι ορατή μόνο στο σώμα της `A`.

### Εμβέλεια

Μια _συνάρτηση_ εισάγει μια νέα **εμβέλεια** για μεταβλητές και εμφωλευμένες συναρτήσεις.

### Ορίσματα

Τα _ορίσματα_ συνάρτησης χωρίζονται με _ερωτηματικά_ και όχι με κόμματα.
Για παράδειγμα, μια _συνάρτηση_ που παίρνει έναν αριθμό, και μετά προσθέτει έναν αριθμό και πολλαπλασιάζει με έναν αριθμό:

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

#### Τα ορίσματα είναι _εκφράσεις_

Τα _ορίσματα_ συνάρτησης είναι φίλτρα, όχι τιμές.
Με αυτή την έννοια, λειτουργούν όπως αυτό που άλλες γλώσσες περιγράφουν ως callbacks:

Χρησιμοποιώντας τη συνάρτηση `add_mul` ως παράδειγμα:

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

Τι συμβαίνει εδώ;

- το όρισμα `adder` παίρνει την _έκφραση_ `. + 5`
  - όταν η συνάρτηση κάνει `. + adder`, αυτό γίνεται `. + . + 5`
  - αυτό αξιολογείται σε 25 αφού `. == 10`
- παρομοίως, το όρισμα `multiplier` είναι η έκφραση `. - 2`
  - αυτό αξιολογείται σε 8
  - μετά το αποτέλεσμα είναι `25 * 8 == 200`

#### Ορίσματα ως τιμές

Μερικές φορές θα θέλεις να "υλοποιήσεις" ένα _όρισμα_ σε μια μεταβλητή:

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

Υπάρχει μια συντομογραφία για αυτό:

```jq
def my_func($arg):
    other stuff ...
;
```

Σημείωσε ότι αυτό είναι απλώς "συντακτική ζάχαρη": το όνομα `arg` χωρίς `$` είναι ακόμα στην εμβέλεια της _συνάρτησης_.

### Πλήθος ορισμάτων

Οι _συναρτήσεις_ έχουν ένα **πλήθος ορισμάτων**: τον αριθμό των _ορισμάτων_ που δέχονται.

Οι _συναρτήσεις_ μπορούν να χρησιμοποιήσουν το ίδιο όνομα με διαφορετικά _πλήθη ορισμάτων_.
Η ενσωματωμένη συνάρτηση [`range`][man-range] το δείχνει αυτό: τα `range/1`, `range/2` και `range/3` συνυπάρχουν.

Αυτό μπορεί να είναι χρήσιμο για τον ορισμό αναδρομικών συναρτήσεων που μεταφέρουν κατάσταση μέσω ορισμάτων.
Για παράδειγμα, η `map` _θα μπορούσε_ να υλοποιηθεί ως εξής:

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

### Αναδρομή

Το `jq` θα εκτελέσει βελτιστοποίηση ουράς, αλλά μόνο για συναρτήσεις με 0 ορίσματα.

### Ενότητες

Μια ενότητα `jq` είναι ένα αρχείο που περιέχει μόνο συναρτήσεις.
Οι ενότητες συμπεριλαμβάνονται σε ένα πρόγραμμα jq με τις εντολές [`include`][man-include] ή [`import`][man-import].
