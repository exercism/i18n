# Πλειάδες

Οι πλειάδες στην Elm μπορούν να περιέχουν δύο ή τρεις τιμές, και κάθε τιμή μπορεί να έχει οποιονδήποτε τύπο.
Στην Elm, οι πλειάδες χρησιμοποιούνται κυρίως για απλούς παροδικούς τύπους.
Για αυτόν τον λόγο, οι πλειάδες έχουν το πολύ 3 τιμές, και ως ένα ακόμη κίνητρο, οι βοηθητικές συναρτήσεις παρέχονται μόνο για 2 τιμές.
Για πιο σύνθετα δεδομένα, είναι καλύτερα να περάσεις σε καταγραφές.
Μια συνηθισμένη χρήση είναι όταν χρειάζεται να επιστρέψεις περισσότερες από μία τιμές από μια συνάρτηση.
Τα πεδία των πλειάδων δεν έχουν ονόματα. Η πρόσβαση σε αυτά γίνεται μέσω αποδόμησης ή με βάση τη θέση τους.

Μπορείς να διαβάσεις μια [σύντομη εισαγωγή στις πλειάδες][tuples-concise].
Υπάρχει επίσης μια [πιο αναλυτική εισαγωγή][tuples-in-depth], και η [τεκμηρίωση API του αρθρώματος Tuple][tuple-core] περιέχει παραδείγματα κώδικα και λεπτομερή τεκμηρίωση.

## Δήλωση

Οι τύποι για τις πλειάδες δημιουργούνται με παρενθέσεις και οι τύποι των στοιχείων τους χωρίζονται με κόμματα.

```elm
type alias IntStringTuple = (Int, String)
```

### Δημιουργία

Οι πλειάδες δημιουργούνται με παρενθέσεις και τα στοιχεία τους χωρίζονται με κόμματα.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

Μπορείς επίσης να χρησιμοποιήσεις το `Tuple.pair` για να δημιουργήσεις μια πλειάδα με δύο τιμές.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Πρόσβαση

Υπάρχουν επίσης συναρτήσεις για να προσπελάσεις τις τιμές μιας πλειάδας με βάση τη θέση τους, οι `Tuple.first` και `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Οι πλειάδες μπορούν να _αποδομηθούν_ σε δεσμεύσεις χρησιμοποιώντας αντιστοίχιση προτύπων πλειάδας.
Η αποδόμηση μπορεί να γίνει σε εκφράσεις let, σε δηλώσεις συναρτήσεων και σε εντολές case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

Η αντιστοίχιση προτύπων σε μια εντολή case σου επιτρέπει επίσης να αντιστοιχίσεις με βάση το περιεχόμενο των τιμών:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
