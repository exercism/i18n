# Οδηγίες

Βρες τη διαφορά ανάμεσα στο τετράγωνο του αθροίσματος και στο άθροισμα των τετραγώνων των πρώτων N φυσικών αριθμών.

Το τετράγωνο του αθροίσματος των πρώτων δέκα φυσικών αριθμών είναι
(1 + 2 + ... + 10)² = 55² = 3025.

Το άθροισμα των τετραγώνων των πρώτων δέκα φυσικών αριθμών είναι
1² + 2² + ... + 10² = 385.

Επομένως, η διαφορά ανάμεσα στο τετράγωνο του αθροίσματος των πρώτων δέκα φυσικών αριθμών και στο άθροισμα των τετραγώνων των πρώτων δέκα φυσικών αριθμών είναι 3025 - 385 = 2640.

Δεν περιμένουμε να ανακαλύψεις μόνος σου μια αποδοτική λύση από πρώτες αρχές. Η έρευνα επιτρέπεται, μάλιστα ενθαρρύνεται.
Το να βρεις τον καλύτερο αλγόριθμο για το πρόβλημα είναι βασική δεξιότητα στη μηχανική λογισμικού.
