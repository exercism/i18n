# Εισαγωγή

Οι πίνακες κατακερματισμού στην Common Lisp είναι δομές δεδομένων για την αποθήκευση συσχετιστικών δεδομένων. 
Αντιστοιχίζουν κλειδιά (τα οποία μπορούν να είναι οποιοδήποτε αντικείμενο) σε τιμές (οι οποίες μπορούν να είναι οποιοδήποτε αντικείμενο). 
Άλλες γλώσσες μπορεί να αναφέρονται σε αυτή την έννοια ως maps, dictionaries ή hashes.

## Δημιουργία πινάκων κατακερματισμού

Οι πίνακες κατακερματισμού μπορούν να δημιουργηθούν με τη συνάρτηση `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Σημείωσε ότι η εκτυπωμένη μορφή ενός πίνακα κατακερματισμού εξαρτάται από την υλοποίηση, οπότε μπορεί να εμφανίζεται διαφορετικά στο REPL σου.)

## Ανάκτηση τιμών με κλειδιά

Για να πάρεις μια τιμή με βάση ένα κλειδί από τον πίνακα κατακερματισμού, χρησιμοποιείς τη συνάρτηση `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

Το `gethash` επιστρέφει [πολλαπλές τιμές][concept-multiple-values], κάτι που θα εξηγηθεί σε άλλη ενότητα.

## Εισαγωγή τιμών

Για να εισαγάγεις μια τιμή σε έναν πίνακα κατακερματισμού, χρησιμοποιείς το `setf` μαζί με το `gethash`, έτσι:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Αυτό θα αλλάξει την τιμή για το κλειδί `:foo` στον πίνακα κατακερματισμού `*hash-table*` ώστε να είναι `:bar`.
Επιστρέφει την τιμή.

Η χρήση του `setf` θα εξηγηθεί σε άλλη ενότητα.
