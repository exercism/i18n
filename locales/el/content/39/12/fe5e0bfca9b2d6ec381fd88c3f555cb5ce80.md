# Δοκιμές

## Εκτέλεση των Δοκιμών

Για να τρέξεις τις δοκιμές, εκτέλεσε την παρακάτω εντολή:

```bash
make
```

## Επίλυση της άσκησης

Το να λύσεις μια άσκηση σημαίνει να κάνεις όλες τις δοκιμές της να περάσουν.
Από προεπιλογή, όταν τρέχεις τις δοκιμές εκτελείται μόνο μία δοκιμή (η πρώτη).
Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει μόνο αυτή η μία δοκιμή.
Μόλις περάσει, μπορείς να ενεργοποιήσεις την επόμενη δοκιμή αφαιρώντας τη γραμμή `TEST_IGNORE()`.
Όταν ενεργοποιηθούν όλες οι δοκιμές και η υλοποίησή σου τις περάσει όλες, θα έχεις λύσει την άσκηση!
