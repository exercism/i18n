# Οδηγίες

Η κοπέλα του Lucian επιστρέφει σπίτι και εκείνος δεν έχει μαγειρέψει το επετειακό τους δείπνο!

Σε αυτή την άσκηση, θα γράψεις κώδικα για να βοηθήσεις τον Lucian να μαγειρέψει μια εξαιρετική λαζάνια από το αγαπημένο του βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες που αφορούν τον χρόνο που αφιερώνεται στο μαγείρεμα της λαζάνιας.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

Όρισε τη σταθερά `EXPECTED_MINUTES_IN_OVEN` που αντιπροσωπεύει πόσα λεπτά πρέπει να μείνει η λαζάνια στον φούρνο. Πρέπει να εξαχθεί. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος ψησίματος σε λεπτά είναι `40`.

## 2. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Υλοποίησε τη συνάρτηση `remainingMinutesInOven` που παίρνει ως _παράμετρο_ τα πραγματικά λεπτά που βρίσκεται η λαζάνια στον φούρνο και _επιστρέφει_ πόσα λεπτά πρέπει να παραμείνει ακόμη η λαζάνια στον φούρνο, με βάση τον **αναμενόμενο χρόνο ψησίματος σε λεπτά** από την προηγούμενη εργασία.

```javascript
remainingMinutesInOven(30);
// => 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Υλοποίησε τη συνάρτηση `preparationTimeInMinutes` που παίρνει ως _παράμετρο_ τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και _επιστρέφει_ πόσα λεπτά χρειάστηκες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για να ετοιμαστεί.

```javascript
preparationTimeInMinutes(2);
// => 4
```

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

Υλοποίησε τη συνάρτηση `totalTimeInMinutes` που παίρνει _δύο παραμέτρους_: η παράμετρος `numberOfLayers` είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια και η παράμετρος `actualMinutesInOven` είναι ο αριθμός των λεπτών που βρίσκεται η λαζάνια στον φούρνο. Η συνάρτηση πρέπει να _επιστρέψει_ πόσα λεπτά συνολικά έχεις δουλέψει για το μαγείρεμα της λαζάνιας, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που έχει περάσει η λαζάνια στον φούρνο τη δεδομένη στιγμή.

```javascript
totalTimeInMinutes(3, 20);
// => 26
```
