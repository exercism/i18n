# Σχετικά

Η PHP διαθέτει αρκετές ενσωματωμένες δομές ελέγχου επανάληψης, όπως ο `while`. Η βασική μορφή μιας εντολής `while` είναι:

```php
while (expr) {
  // statements
}
```

Όσο η παράσταση (_expr_) αποτιμάται σε μια _αληθή_ τιμή, θα επαναλαμβάνει τις εντολές μέσα στον βρόχο. Αν η παράσταση (_expr_) αποτιμάται σε ψευδή τιμή πριν από την πρώτη επανάληψη, οι εντολές δεν εκτελούνται ποτέ.

Εναλλακτικά, μπορείς να χρησιμοποιήσεις έναν βρόχο `do-while`, ο οποίος εκτελεί τις εντολές του βρόχου μία φορά πριν αποτιμήσει την παράσταση (_expr_).

```php
do {
  // statements
} while (expr);
```
