# Εισαγωγή

Είναι χρήσιμο να αναφέρουμε τα σφάλματα όταν κάτι πάει λάθος ή είναι απροσδόκητο σε ένα πρόγραμμα ή σε ένα κομμάτι κώδικα.

Είναι αντικείμενα JavaScript.

Η κύρια ιδιότητα αυτού του αντικειμένου είναι το `message`:

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

Με τη σύνταξη `throw`, μπορείς να πετάξεις ένα Error.

```javascript
throw new Error('Oops');
```

Όταν πετιέται ένα `Error`, η τρέχουσα εκτέλεση σταματάει και συνεχίζεται στο πρώτο μπλοκ `catch` της στοίβας κλήσεων.

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

Όπως με οποιαδήποτε κλάση στη JavaScript, οι υποκλάσεις μπορούν να κληρονομήσουν από το `Error` για να δημιουργήσουν προσαρμοσμένα σφάλματα χρησιμοποιώντας τη λέξη-κλειδί `extends`.

Η σύνταξη `instanceof` θα ελέγξει αν το σφάλμα που πιάστηκε είναι στιγμιότυπο μιας συγκεκριμένης υποκλάσης του `Error`.

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
