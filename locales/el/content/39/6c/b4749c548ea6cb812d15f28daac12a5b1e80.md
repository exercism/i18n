# Προσθήκη οδηγιών

## Συναρτήσεις και tests

Σου δίνουμε έναν αρχικό ορισμό για τη συνάρτηση `SayHi`.

```delphi
function SayHi : string;
begin
  result := 'Goodbye, Mars!';
end;
```

Ο test runner παίρνει αυτή τη συνάρτηση και την εκτελεί, συγκρίνοντας την τιμή που [returns] με την τιμή που περιμένει.
Χρησιμοποίησε αυτόν τον αρχικό ορισμό της συνάρτησης ως βάση για τη λύση σου.

[returns]: https://www.freepascal.org/docs-html/3.2.2/ref/refse94.html
