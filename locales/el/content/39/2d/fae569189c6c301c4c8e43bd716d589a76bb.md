# Οδηγίες

Ένας φίλος σου έχει ένα παλιό κατάστημα χονδρικής που λέγεται **Gross Store**.

Το όνομα προέρχεται από την ποσότητα των ειδών που πουλάει το κατάστημα: όλα είναι σε [μονάδα gross][gross-unit].

Ο φίλος σου σου ζήτησε να υλοποιήσεις ένα σύστημα σημείου πώλησης (POS) για το κατάστημά του.

**Πρώτα, θέλεις να φτιάξεις ένα πρωτότυπο γι' αυτό.**

**Στο πρωτότυπό σου, το σύστημά σου θα καταγράφει μόνο την ποσότητα.**

Ο φίλος σου σου έδωσε μια λίστα με μονάδες μέτρησης για να σε βοηθήσει:

| Μονάδα             | Ποσότητα |
| ------------------ | -------- |
| quarter_of_a_dozen | 3        |
| half_of_a_dozen    | 6        |
| dozen              | 12       |
| small_gross        | 120      |
| gross              | 144      |
| great_gross        | 1728     |

## 1. Αποθήκευσε τη μονάδα μέτρησης στο πρόγραμμά σου

Για να χρησιμοποιήσεις τη μονάδα μέτρησης, πρέπει να την αποθηκεύσεις στο πρόγραμμά σου.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Δημιούργησε έναν νέο λογαριασμό πελάτη

Πρέπει να υλοποιήσεις μια συνάρτηση που δημιουργεί έναν νέο (κενό) λογαριασμό για τον πελάτη.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Πρόσθεσε ένα είδος στον λογαριασμό του πελάτη

Για να το υλοποιήσεις, θα χρειαστεί να:

- Επιστρέψεις `false` αν το `unit` που δίνεται δεν υπάρχει στον χάρτη `units`.
- Διαφορετικά, πρόσθεσε το είδος στον `bill` του πελάτη, με κλειδί το όνομα του είδους, και μετά επέστρεψε `true`.
- Αν το είδος υπάρχει ήδη στον λογαριασμό, αύξησε την ποσότητά του κατά το ποσό που αντιστοιχεί στο `unit` που δίνεται.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Σημείωσε ότι η τιμή επιστροφής είναι τύπου `bool`.

## 4. Αφαίρεσε ένα είδος από τον λογαριασμό του πελάτη

Για να το υλοποιήσεις, θα χρειαστεί να:

- Επιστρέψεις `false` αν το είδος που δίνεται **δεν** υπάρχει στον λογαριασμό.
Ένα είδος θεωρείται ότι δεν υπάρχει στον λογαριασμό αν η ποσότητά του είναι 0.
- Επιστρέψεις `false` αν το `unit` που δίνεται δεν υπάρχει στον χάρτη `units`.
- Επιστρέψεις `false` αν η νέα ποσότητα θα ήταν μικρότερη από 0.
- Αν η νέα ποσότητα είναι 0, το είδος θεωρείται ότι αφαιρέθηκε από τον `bill`, οπότε μπορείς να επιστρέψεις `true`.
- Διαφορετικά, μείωσε την ποσότητα του είδους και επέστρεψε `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Σημείωσε ότι η τιμή επιστροφής είναι τύπου `bool`.

## 5. Επέστρεψε την ποσότητα ενός συγκεκριμένου είδους που βρίσκεται στον λογαριασμό του πελάτη

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Σημείωσε ότι η τιμή επιστροφής είναι τύπου `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
