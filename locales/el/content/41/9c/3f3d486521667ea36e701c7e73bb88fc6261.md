# Εισαγωγή

Οι `Complex numbers` δεν είναι περίπλοκοι.
Χρειάζονται απλώς ένα λιγότερο ανησυχητικό όνομα.


Είναι τόσο χρήσιμοι, ειδικά στη μηχανική και τις επιστήμες, που η Python περιλαμβάνει τον [`complex`][complex] ως τυπικό αριθμητικό τύπο, μαζί με τους ακέραιους ([`int`s][ints]) και τους αριθμούς κινητής υποδιαστολής ([`float`s][floats]).


Μια τιμή `complex` στην Python είναι ουσιαστικά ένα ζεύγος αριθμών κινητής υποδιαστολής:

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

Αυτά ονομάζονται "πραγματικό" και "φανταστικό" μέρος.
Μπορεί να έχεις ακούσει ότι "το `i` (ή το `j`) είναι η τετραγωνική ρίζα του -1".
Για την ώρα, το μόνο που σημαίνει αυτό είναι ότι το φανταστικό μέρος _εξ ορισμού_ ικανοποιεί την ισότητα `1j * 1j == -1`.
Είναι μια απλή ιδέα, αλλά οδηγεί σε ενδιαφέρουσες μαθηματικές συνέπειες.

Στην Python, το "φανταστικό" μέρος δηλώνεται με το `j` (_όχι `i`, όπως θα έβλεπες σε μαθηματικά βιβλία_), και
το `j` πρέπει να ακολουθεί αμέσως έναν αριθμό, ώστε η Python να μην το εκλάβει ως όνομα μεταβλητής:


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


Υπάρχουν δύο συνηθισμένοι τρόποι για να δημιουργήσεις μιγαδικούς αριθμούς.

1) Ο κατασκευαστής [`complex(real, imag)`][complex] δέχεται δύο παραμέτρους `float`:

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    Ο κατασκευαστής μπορεί επίσης να αναλύσει είσοδο συμβολοσειράς.
    Αυτό έχει τον παράξενο περιορισμό ότι αποτυγχάνει αν η συμβολοσειρά περιέχει κενά.

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) Ο μιγαδικός αριθμός μπορεί να γραφτεί απευθείας ως `<real part> + <complex part>j`, ή απλώς ως `<complex part>j` αν το πραγματικό μέρος είναι μηδέν:


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    Το τελικό αποτέλεσμα είναι το ίδιο με το να χρησιμοποιήσεις τον κατασκευαστή `complex()`.


## Αριθμητική

Οι περισσότεροι από τους [`operators`][operators] που χρησιμοποιούνται με αριθμούς κινητής υποδιαστολής και ακέραιους λειτουργούν και με μιγαδικούς αριθμούς.

Η ακέραια διαίρεση _**δεν**_ είναι δυνατή στους μιγαδικούς αριθμούς, οπότε οι τελεστές `//` και `%` και η συνάρτηση `divmod()` θα αποτύχουν για τον τύπο μιγαδικών αριθμών.

Η εξήγηση των κανόνων για τον πολλαπλασιασμό και τη διαίρεση μιγαδικών αριθμών είναι εκτός του πεδίου αυτής της έννοιας (_και είναι απίθανο να χρειαστεί να εκτελέσεις αυτές τις πράξεις "με το χέρι" πολύ συχνά_).

Οποιαδήποτε [μαθηματική][math-complex] ή [ηλεκτρολογική][engineering-complex] εισαγωγή στους μιγαδικούς αριθμούς θα καλύψει αυτά τα σενάρια, αν θέλεις να εμβαθύνεις στο θέμα.

Η βασική βιβλιοθήκη της Python διαθέτει το [`math`][math-module], ένα module γεμάτο χρήσιμη λειτουργικότητα για την εργασία με πραγματικούς αριθμούς, και το [`cmath`][cmath] είναι το αντίστοιχό του για την εργασία με μιγαδικούς αριθμούς.
