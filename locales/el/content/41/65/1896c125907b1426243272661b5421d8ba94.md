# Υποδείξεις

## Γενικά

- Διάβασε για το [`alias` και το `import`][getting-started] στον οδηγό Getting Started.
- Διάβασε για τη [σύνθεση modules][elixir-school-module-composition] στο elixirschool.com.

## 1. Διόρθωσε το σφάλμα μεταγλώττισης `Race.__struct__/0 is undefined`

- Ένα alias μπορεί να δημιουργηθεί με την ειδική μορφή [`alias`][alias].

## 2. Διόρθωσε το σφάλμα μεταγλώττισης `Car.__struct__/0 is undefined`

- Ένα alias μπορεί να δημιουργηθεί με την ειδική μορφή [`alias`][alias].
- Η ειδική μορφή `alias` δέχεται μια επιλογή `:as`.

## 3. Διόρθωσε το σφάλμα μεταγλώττισης `undefined function puts/1`

- Οι συναρτήσεις μπορούν να εισαχθούν με την ειδική μορφή [`import`][import].
- Η ειδική μορφή [`import`][import] δέχεται μια επιλογή `:only`. Η τιμή της πρέπει να είναι μια λίστα λέξεων-κλειδιών, με τα ονόματα των συναρτήσεων ως κλειδιά και τον αριθμό των ορισμάτων τους ως τιμές.

## 4. Διόρθωσε το σφάλμα μεταγλώττισης `undefined function default_color/0`

- Οι συναρτήσεις μπορούν να εισαχθούν με την ειδική μορφή [`import`][import].
- Η ειδική μορφή [`import`][import] δέχεται μια επιλογή `:except`. Η τιμή της πρέπει να είναι μια λίστα λέξεων-κλειδιών, με τα ονόματα των συναρτήσεων ως κλειδιά και τον αριθμό των ορισμάτων τους ως τιμές.
