# Δομές

Οι δομές συγκεντρώνουν ένα σταθερό, ετερογενές σύνολο δεδομένων σε μία μονάδα. Στη Rust, οι δομές έχουν τις εξής ιδιότητες:

- Κάθε τύπος δομής έχει ένα συγκεκριμένο όνομα.
- Κάθε μέλος μιας δομής ονομάζεται **πεδίο**.
- Κάθε πεδίο μιας δομής έχει ένα συγκεκριμένο όνομα.
- Η ορατότητα παρακολουθείται σε επίπεδο πεδίου: κάθε πεδίο μπορεί ανεξάρτητα να είναι δημόσιο, ιδιωτικό ή κάτι άλλο[^1].

# Επισκόπηση των Δομών

Οι δομές ορίζονται με τη λέξη-κλειδί `struct`, ακολουθούμενη από το όνομα του τύπου που περιγράφει η δομή.
Το όνομα μπορεί στη συνέχεια να ακολουθείται από άγκιστρα (για μια τυπική δομή), παρενθέσεις (για μια δομή πλειάδας) ή μια άνω τελεία (για μια δομή μονάδας).

```rust
struct Item {}
```

Στη συνέχεια, επιπλέον τύποι εισάγονται στο σώμα της δομής ως _πεδία_ της δομής, καθένα με τον δικό του τύπο:

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

Τέλος, μέθοδοι μπορούν να οριστούν πάνω σε δομές μέσα σε ένα μπλοκ `impl`:

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# Παραλλαγές Δομών

Οι δομές υπάρχουν σε τρεις παραλλαγές: δομές με ονομασμένα πεδία (τυπικές δομές), δομές πλειάδας και δομές μονάδας.

Οι δομές μοιάζουν πολύ με τις **πλειάδες**. Στην πραγματικότητα, η μόνη διαφορά ανάμεσα σε δομές και πλειάδες αφορά το ποιο μέρος είναι ανώνυμο. Η γενική μορφή είναι η εξής:

- Οι δομές έχουν όνομα και ονομασμένα πεδία:

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  Η πρόσβαση στα πεδία γίνεται με το όνομά τους:

  ```rust
  let bar = foo.bar;
  ```

- Οι δομές πλειάδας έχουν όνομα αλλά ανώνυμα πεδία:

  ```rust
  Foo(Bar, Bat)
  ```

  Η πρόσβαση στα πεδία γίνεται με αποδόμηση ή με βάση την αριθμητική τους θέση:

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- Οι πλειάδες είναι ανώνυμες και έχουν ανώνυμα πεδία:

  ```rust
  (Bar, Bat)
  ```

  Όπως και στις δομές πλειάδας, η πρόσβαση στα πεδία γίνεται με αποδόμηση ή με βάση την αριθμητική τους θέση.

- Οι ανώνυμες δομές είναι, όπως υποδηλώνει το όνομα, ανώνυμες, αλλά με ονομασμένα πεδία. Μπορεί να τις έχεις συναντήσει σε άλλες γλώσσες, όπως η Go ή η Java. Δεν υπάρχουν στη Rust· στη θέση τους, θεωρείται ιδιωματικό να χρησιμοποιείς μια πλειάδα.

# Τύποι Μηδενικού Μεγέθους

Οι δομές μπορούν να έχουν όσα πεδία χρειάζεται, λίγα ή πολλά. Αυτό συνεπάγεται ότι είναι νόμιμο για μια δομή να μην έχει κανένα πεδίο. Μια δομή χωρίς πεδία ονομάζεται **τύπος μηδενικού μεγέθους** και ο μεταγλωττιστής τη χειρίζεται με ειδικό τρόπο: οι τύποι μηδενικού μεγέθους (συχνά συντομεύονται ως **ZST**) δεν καταναλώνουν ποτέ χώρο στη στοίβα ή στον σωρό, ακόμη και όταν θα περίμενες να το κάνουν. Για παράδειγμα, το `Box<T>` δεν δεσμεύει καθόλου μνήμη στον σωρό αν το `T` είναι ZST.

Μπορείς να χρησιμοποιήσεις σύνταξη τυπικής δομής ή δομής πλειάδας όταν γράφεις έναν τύπο μηδενικού μεγέθους:

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

Υπάρχει επίσης μια συντομευμένη γραφή για τους τύπους μηδενικού μεγέθους:

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

Συνήθως, όταν γράφεις έναν τύπο μηδενικού μεγέθους, προτιμάται η συντομευμένη γραφή, καθώς δεν μπορείς να τα ανακατέψεις: όποιο στυλ χρησιμοποιήθηκε για να δηλώσεις έναν ZST[^2], το ίδιο στυλ απαιτείται και για να του δημιουργήσεις στιγμιότυπο.

Ύστερα από όλη αυτή τη συζήτηση για τη σύνταξη των τύπων μηδενικού μεγέθους, ας δούμε γιατί θα ήθελες ποτέ κάτι τέτοιο. Ένας τύπος μηδενικού μεγέθους δεν μπορεί να αποθηκεύσει δεδομένα, αλλά είναι ιδανικός για να υλοποιείς traits πάνω του.

---

[^1]: [Αυτά τα έγγραφα](https://doc.rust-lang.org/reference/visibility-and-privacy.html) εξηγούν μερικές επιλογές ορατότητας που χρησιμοποιούνται σπανιότερα.
[^2]: Αυτό είναι μια συγκεκριμένη περίπτωση ενός γενικού κανόνα: όποιο στυλ χρησιμοποιήθηκε για να δηλώσεις οποιονδήποτε τύπο δομής, το ίδιο στυλ απαιτείται για να του δημιουργήσεις στιγμιότυπο.
