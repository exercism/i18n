# Σχετικά

Η τυπική βιβλιοθήκη της Elixir προσφέρει 4 διαφορετικά module για εργασία με ημερομηνίες και ώρα, καθένα με το δικό του `struct`.

- Το [module `Date`][date]. Μπορείς να δημιουργήσεις ένα `struct` `Date` με το [sigil `~D`][sigil-d].
    ```elixir
    ~D[2021-01-01]
    ```

- Το [module `Time`][time]. Μπορείς να δημιουργήσεις ένα `struct` `Time` με το [sigil `~T`][sigil-t].
    ```elixir
    ~T[12:00:00]
    ```

- Το [module `NaiveDateTime`][naivedatetime] για ημερομηνίες και ώρες χωρίς ζώνη ώρας. Μπορείς να δημιουργήσεις ένα `struct` `NaiveDateTime` με το [sigil `~N`][sigil-n].
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- Το [module `DateTime`][datetime] για ημερομηνίες και ώρες με ζώνη ώρας. Η χρήση αυτού του module για ζώνες ώρας πέραν της UTC απαιτεί μια εξωτερική εξάρτηση, μια βάση δεδομένων ζωνών ώρας. Ένα `struct` `DateTime` μπορείς να το αναπαραστήσεις με το [sigil `~U`][sigil-u], αλλά καλύτερα να το δημιουργείς με συναρτήσεις του `DateTime`.
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## Συγκρίσεις

Για να συγκρίνεις ημερομηνίες ή ώρες μεταξύ τους, αναζήτησε μια συνάρτηση `compare` ή `diff` στο αντίστοιχο module. Οι τελεστές σύγκρισης όπως οι `==`, `>` και `<` _φαίνεται_ να δουλεύουν, αλλά δεν κάνουν σωστή σημασιολογική σύγκριση για αυτά τα `struct`.

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## Μετατόπιση

Μπορείς να μετατοπίσεις ημερομηνίες, ώρες και ημερομηνίες-ώρες μπροστά και πίσω στον χρόνο χρησιμοποιώντας τη συνάρτηση `add/2` του αντίστοιχου module.

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## Μετατροπές

Ένα `struct` `NaiveDateTime` μπορεί να αποδομηθεί σε ένα `struct` `Date` και ένα `struct` `Time` χρησιμοποιώντας τις [`NaiveDateTime.to_date/1`][naivedatetime-to-date] και [`NaiveDateTime.to_time/1`][naivedatetime-to-time]. Το αντίθετο μπορείς να το πετύχεις με τη [`NaiveDateTime.new!/2`][naivedatetime-new].

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
