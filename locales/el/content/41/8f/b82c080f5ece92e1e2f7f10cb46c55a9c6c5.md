# Σχετικά

Στη Clojure, οι Boolean τιμές αναπαρίστανται από `true` ή `false`.

Οι συναρτήσεις κατηγορήματος (συναρτήσεις που επιστρέφουν Boolean) συνήθως τελειώνουν με ένα ερωτηματικό (`?`), αλλά αυτό είναι μόνο κατά σύμβαση.

Η βασική βιβλιοθήκη περιλαμβάνει συναρτήσεις για λογικούς τελεστές, όπως `not`, `and` και `or`.
