# Εγκατάσταση

Πρώτα, βεβαιώσου ότι έχεις εγκατεστημένη την Erlang, ακολουθώντας τις οδηγίες στη σελίδα εγκατάστασης της [Erlang][1], όπως ταιριάζει στην περίπτωσή σου.
[1]: /languages/erlang

## Homebrew για Mac OS X

Ενημέρωσε το Homebrew στην τελευταία έκδοση:

```bash
$ brew update
```

Εγκατέστησε το LFE:

```bash
$ brew install lfe
```

## Εγκατάσταση από τον πηγαίο κώδικα
Εγκατέστησε τα "developer tools" ή τα "essential build packages" του συστήματός σου, το `git` και το `erl` της Erlang.

Για παράδειγμα, στο Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Έπειτα, μπορείς να κατεβάσεις και να χτίσεις το LFE με τα παρακάτω:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Μόλις έχεις μεταγλωττίσει το LFE, μπορείς να ξεκινήσεις το REPL (διαδραστική συνεδρία) εκτελώντας το εκτελέσιμο ``lfe``:

```bash
$ ./bin/lfe
```
