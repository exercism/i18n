# Σχετικά

Η Ruby έρχεται με μια πρότυπη βιβλιοθήκη (συχνά συντομεύεται σε "stdlib"), μια συλλογή από κλάσεις για εργασία με πράγματα όπως ημερομηνίες, JSON και δικτύωση.
Παρέχει επίσης χρήσιμες λειτουργίες που κάνουν τον κώδικά σου πιο εύκολο στη χρήση.

Το `OpenStruct` είναι μέρος της πρότυπης βιβλιοθήκης και σου επιτρέπει να δημιουργήσεις εύκολα ένα αντικείμενο από ένα `Hash`.
Αντί να χρειάζεται να έχεις πρόσβαση χρησιμοποιώντας κλειδιά του `Hash`, το `OpenStruct` μας επιτρέπει να χρησιμοποιούμε μεθόδους για πρόσβαση και ορισμό τιμών.

Όταν χρησιμοποιείς κλάσεις από την πρότυπη βιβλιοθήκη ή οποιαδήποτε άλλη βιβλιοθήκη, πρέπει να φορτώσεις αυτή την κλάση χρησιμοποιώντας τη μέθοδο `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ένα επιπλέον πλεονέκτημα είναι ότι μπορείς να εκμεταλλευτείς μια συντόμευση όταν χρησιμοποιείς σύνταξη μπλοκ.
Σε περιπτώσεις όπου ένα μπλοκ καλεί μία μόνο μέθοδο, μπορείς να αντικαταστήσεις το μπλοκ με `&:` ακολουθούμενο από το όνομα της μεθόδου.
Για παράδειγμα, αυτές οι δύο γραμμές είναι ισοδύναμες:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
