# Παράρτημα

## Μπόνους

Δύο προαιρετικά τεστ είναι απενεργοποιημένα από προεπιλογή. Για να τα ενεργοποιήσεις, πρόσθεσε `const TEST_BIG_INTEGERS = true` στο καθολικό πεδίο του αρχείου λύσης σου (ή βγάλε από τα σχόλια τη γραμμή που παρέχεται στο αρχικό αρχείο).

Αυτοί οι αριθμοί υπερβαίνουν τον προεπιλεγμένο τύπο ακέραιου, αλλά οι ακέραιοι 128 bit αρκούν για να περάσεις τα τεστ, δεν χρειάζεται το `BigInt`.
