# Οδηγίες

Σε αυτή την άσκηση θα γράψεις λίγο κώδικα για να σε βοηθήσει να μαγειρέψεις υπέροχα λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις πέντε εργασίες, όλες σχετικές με τον χρόνο που περνάς μαγειρεύοντας τα λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο σε λεπτά

Όρισε τη συνάρτηση `expectedMinutesInOven` που δεν παίρνει κανένα όρισμα και επιστρέφει πόσα λεπτά πρέπει να είναι τα λαζάνια στον φούρνο.
Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο σε λεπτά είναι 40:

```haskell
expectedMinutesInOven
-- -> 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στο φούρνο σε λεπτά

Όρισε τη συνάρτηση `remainingMinutesInOven` που παίρνει ως όρισμα τα πραγματικά λεπτά που τα λαζάνια βρίσκονται στον φούρνο και επιστρέφει πόσα λεπτά πρέπει να μείνουν ακόμα τα λαζάνια στον φούρνο, με βάση τον αναμενόμενο χρόνο στο φούρνο σε λεπτά από την προηγούμενη εργασία.

```haskell
remainingMinutesInOven 30
-- -> 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparationTimeInMinutes` που παίρνει ως όρισμα τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για προετοιμασία.

Όρισε τη συνάρτηση `preparationTimeInMinutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στα λαζάνια και επιστρέφει πόσα λεπτά χρειάστηκες για να προετοιμάσεις τα λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για προετοιμασία.

```haskell
preparationTimeInMinutes 3
-- -> 6
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `totalTimeInMinutes` που παίρνει δύο ορίσματα: το πρώτο όρισμα είναι ο αριθμός των στρώσεων που πρόσθεσες στα λαζάνια, και το δεύτερο όρισμα είναι ο αριθμός των λεπτών που τα λαζάνια βρίσκονται στον φούρνο.
Η συνάρτηση πρέπει να επιστρέφει πόσα λεπτά συνολικά έχεις αφιερώσει στο μαγείρεμα των λαζανιών, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που τα λαζάνια έχουν περάσει στον φούρνο αυτή τη στιγμή.

```haskell
elapsedTimeInMinutes 3 20
-- -> 26
```

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

Όρισε τη συνάρτηση `alarm` που δεν παίρνει κανένα όρισμα και επιστρέφει ένα μήνυμα που δείχνει ότι τα λαζάνια είναι έτοιμα να τα φας.

```haskell
alarm
-- -> "Ding!"
```
