# Προσθήκη οδηγιών

## Υποδείξεις

Πρέπει να υλοποιήσεις τη συνάρτηση

```haskell
value :: (Color, Color) -> Int
```

που δέχεται μόνο δύο χρώματα και παράγει το αριθμητικό μέρος της αντίστασης του αντιστάτη.

**Μπόνους - Δοκιμές ιδιοτήτων:**

Αυτή η άσκηση είναι μια καλή ευκαιρία να γράψεις μερικές [δοκιμές ιδιοτήτων](https://en.wikipedia.org/wiki/Property_testing). Αν δεν έχεις ξαναγράψει καμία, ορίστε μερικοί πόροι:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Έχουμε συμπεριλάβει ένα δείγμα δοκιμής ιδιότητας QuickCheck στο αρχείο δοκιμών.

Παραδείγματα ιδιοτήτων που μπορούν να ελεγχθούν:

- `value (x, y) >= 10` για κάθε `(x, y)` όπου το `x` δεν είναι `Black`

- Η κλήση της `show` στο `value (x, y)` παράγει τη συμβολοσειρά που προκύπτει εφαρμόζοντας τη `reverse` στο αποτέλεσμα της κλήσης της `show` στο `value (y, x)`.

- Όλα τα χρώματα έχουν μοναδικά ονόματα. (Για οποιαδήποτε δύο χρώματα, αν τα χρώματα είναι διαφορετικά, τότε διαφορετικά είναι και τα ονόματά τους.)
