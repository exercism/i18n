# Υποδείξεις

## Γενικά

- Οι εντολές [cmp][cmp] και [test][test] είναι χρήσιμες για να θέτεις σημαίες ανάλογα με κάποιες συνθήκες που εξετάζεις.
- Οι εντολές [jmp][jmp] και [jcc][jcc] είναι χρήσιμες για διακλάδωση ανάλογα με τις σημαίες που έχεις θέσει προηγουμένως.
- Όταν καλείς μια συνάρτηση, η συνάρτηση που καλείς μπορεί να τροποποιήσει έναν καταχωρητή που χρησιμοποιείς.

## 1. Υπολόγισε την αξία ενός φύλλου

- Οι εντολές [cmp][cmp] και [test][test] είναι χρήσιμες για να θέτεις σημαίες ανάλογα με κάποιες συνθήκες που εξετάζεις.
- Οι εντολές [jmp][jmp] και [jcc][jcc] είναι χρήσιμες για διακλάδωση ανάλογα με τις σημαίες που έχεις θέσει προηγουμένως.
- Όταν καλείς μια συνάρτηση, η συνάρτηση που καλείς μπορεί να τροποποιήσει έναν καταχωρητή που χρησιμοποιείς.
- Μπορείς να χρησιμοποιήσεις την `cmp` για να συγκρίνεις δύο φύλλα, θέτοντας τις κατάλληλες σημαίες.
- Μπορείς να χρησιμοποιήσεις την `je` ή την `jz` για να διακλαδωθείς αν ένας αριθμός είναι ίσος με τον άλλο.
- Μπορείς να χρησιμοποιήσεις την `jl` για να διακλαδωθείς αν ένας αριθμός είναι μικρότερος από τον άλλο.

## 2. Προσδιόρισε ποιο φύλλο έχει μεγαλύτερη αξία

- Οι εντολές [cmp][cmp] και [test][test] είναι χρήσιμες για να θέτεις σημαίες ανάλογα με κάποιες συνθήκες που εξετάζεις.
- Οι εντολές [jmp][jmp] και [jcc][jcc] είναι χρήσιμες για διακλάδωση ανάλογα με τις σημαίες που έχεις θέσει προηγουμένως.
- Όταν καλείς μια συνάρτηση, η συνάρτηση που καλείς μπορεί να τροποποιήσει έναν καταχωρητή που χρησιμοποιείς.
- Μόλις ορίσεις τη συνάρτηση `value_of_card`, μπορείς να την καλέσεις από άλλες συναρτήσεις.
- Μπορείς να χρησιμοποιήσεις την `cmp` για να συγκρίνεις δύο φύλλα, θέτοντας τις κατάλληλες σημαίες.
- Μπορείς να χρησιμοποιήσεις την `jg` για να διακλαδωθείς αν ένας αριθμός είναι μεγαλύτερος από τον άλλο, και την `jl` για να διακλαδωθείς αν είναι μικρότερος.
- Αν και τα δύο φύλλα έχουν την ίδια αξία, το δεύτερο επιστρέφεται στον `rdx`. Διαφορετικά, ο `rdx` πρέπει να τεθεί σε 0.
