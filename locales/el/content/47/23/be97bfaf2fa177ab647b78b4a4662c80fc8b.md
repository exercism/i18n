# Προσθήκη οδηγιών

## Υποδείξεις

Αυτή η άσκηση ασχολείται με δεδομένα κειμένου. Για ιστορικούς λόγους, ο τύπος `String` της Haskell είναι συνώνυμος με το `[Char]`, μια λίστα χαρακτήρων. Για πιο αποδοτικό χειρισμό των δεδομένων κειμένου, μπορείς να χρησιμοποιήσεις τον τύπο `Text`.

Ως προαιρετική επέκταση αυτής της άσκησης, μπορείς να κάνεις τα παρακάτω:

- Διάβασε για τους [τύπους συμβολοσειρών](https://haskell-lang.org/tutorial/string-types) στη Haskell.
- Πρόσθεσε `- text` στη λίστα εξαρτήσεών σου στο package.yaml.
- Κάνε import το `Data.Text` με [τον ακόλουθο τρόπο](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

        import qualified Data.Text as T
        import           Data.Text (Text)

- Μπορείς τώρα να γράψεις π.χ. `isIsogram :: Text -> Bool` και να αναφέρεσαι στους συνδυαστές του `Data.Text` όπως π.χ. `T.toLower`.
- Αναζήτησε την τεκμηρίωση για το [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Αυτό το μέρος είναι εντελώς προαιρετικό.
