# Εισαγωγή

Ο τελεστής `|>` ονομάζεται τελεστής σωλήνωσης. Μπορεί να χρησιμοποιηθεί για να συνδέσει κλήσεις συναρτήσεων μεταξύ τους, έτσι ώστε η τιμή που επιστρέφει η προηγούμενη κλήση συνάρτησης να περνιέται ως πρώτο όρισμα στην επόμενη κλήση συνάρτησης.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
