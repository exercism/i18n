# Εισαγωγή

## Γενικοί τύποι

### Εισαγωγή

Οι γενικοί τύποι είναι ένα χαρακτηριστικό της γλώσσας που επιτρέπει την επαναχρησιμοποίηση κώδικα.
Για παράδειγμα, δεν θα έπρεπε να έχει σημασία τι τύπο περιέχει μια λίστα για να υπολογίσουμε το μήκος της.
Γι' αυτό η συνάρτηση `length` χρησιμοποιεί μια γενική παράμετρο τύπου `a` στην υπογραφή τύπου της.

```elm
length : List a -> Int
```

### Παράμετροι στους τύπους

Όταν ένας τύπος είναι γενικός ως προς έναν άλλο τύπο, χρησιμοποιούμε ένα πεζό όνομα για αυτόν τον άλλο τύπο και το ονομάζουμε παράμετρο τύπου.
Συνήθη παραδείγματα είναι οι προσαρμοσμένοι τύποι `List`, `Maybe` και `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Μια σημαντική παρατήρηση για τα ονόματα των παραμέτρων τύπων είναι ότι μπορούν να έχουν πολλούς χαρακτήρες.
Ο μόνος περιορισμός είναι ότι πρέπει να είναι πεζά ονόματα.
Ως εκ τούτου, όταν είναι χρήσιμο, τείνουμε να τους δίνουμε περιγραφικά ονόματα.

Ένας τύπος μπορεί να είναι γενικός ως προς πολλούς άλλους τύπους και επομένως να έχει πολλαπλές παραμέτρους τύπων.
Σε αυτή την περίπτωση, κάθε ανεξάρτητος τύπος παίρνει ένα διαφορετικό πεζό όνομα.
Το να είναι ανεξάρτητοι δεν τους εμποδίζει να γίνουν ο ίδιος τύπος, απλώς τους επιτρέπει να είναι διαφορετικοί.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Τα ψευδώνυμα τύπων καταγραφών μπορούν επίσης να έχουν παραμέτρους τύπων, αν και είναι λιγότερο συνηθισμένο.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Παράμετροι τύπων σε συναρτήσεις

Εφόσον οι τύποι μπορούν να είναι γενικοί, το ίδιο μπορούν και οι συναρτήσεις.
Μπορούν να γραφτούν συναρτήσεις που χειρίζονται γενικούς τύπους, όπως η `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Οι συναρτήσεις που δέχονται άλλες συναρτήσεις ως παραμέτρους ονομάζονται συναρτήσεις ανώτερης τάξης και αυτές μπορούν επίσης να είναι γενικές.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
