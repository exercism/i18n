# χρήση κεφαλίδας συνάρτησης

[comment]: # (Αυτό το σφάλμα εμφανίζεται όταν η λύση χρησιμοποιεί κεφαλίδα συνάρτησης)

Μια κεφαλίδα συνάρτησης (ένας ορισμός συνάρτησης χωρίς σώμα) είναι απαραίτητη μόνο για συναρτήσεις με προεπιλεγμένα ορίσματα που έχουν πολλαπλές ρήτρες.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Για συναρτήσεις με προεπιλεγμένα ορίσματα που έχουν μόνο μία ρήτρα, τα προεπιλεγμένα ορίσματα μπορούν να δηλωθούν απευθείας σε αυτή τη ρήτρα.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

Η συνάρτηση `two_fer/1` χρειάζεται μόνο μία ρήτρα, οπότε δεν χρειάζεται κεφαλίδα συνάρτησης.
