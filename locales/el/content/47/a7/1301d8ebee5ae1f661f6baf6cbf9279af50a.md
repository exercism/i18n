# Υποδείξεις

## 1. Όρισε το εύρος γραμμής και στήλης

- Υπάρχει ένας [τελεστής][swift-range-docs] για τη δημιουργία εύρους, ο οποίος μπορεί να χρησιμοποιηθεί τόσο για συμβολοσειρές όσο και για ακέραιους.

## 2. Έλεγξε αν το τετράγωνο είναι έγκυρο

- Υπάρχει μια [μέθοδος][contains-docs] για να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος.

## 3. Πάρε τη γραμμή

- Κάθε γραμμή πρέπει να έχει μήκος 8.
- Για κάθε γραμμή, ξεκινώντας από το 1, θα πρέπει να μετατοπίσεις την αρχή και το τέλος κατά 8.
- Μπορείς να χρησιμοποιήσεις ένα εύρος για να πάρεις έναν υποπίνακα του πίνακα.
