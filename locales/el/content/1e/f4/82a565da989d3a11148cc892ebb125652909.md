# Εισαγωγή

## Υπερχείλιση

Η αριθμητική υπερχείλιση συμβαίνει όταν ένας υπολογισμός, όπως μια αριθμητική πράξη ή μια μετατροπή τύπου, καταλήγει σε μια τιμή μεγαλύτερη από τη χωρητικότητα του τύπου που τη λαμβάνει.

Οι εκφράσεις τύπου `int` και `long`, καθώς και οι αντίστοιχες ανυπόγραφες εκφράσεις τους, θα αναδιπλωθούν σιωπηλά σε αυτές τις περιπτώσεις.

Η συμπεριφορά των υπολογισμών ακεραίων μπορεί να τροποποιηθεί με τη χρήση της λέξης-κλειδιού `checked`. Όταν προκύψει υπερχείλιση μέσα σε ένα μπλοκ `checked`, πετιέται ένα στιγμιότυπο της `OverflowException`.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

Οι εκφράσεις τύπου `float` και `double` θα πάρουν μια ειδική τιμή, το άπειρο.

Οι εκφράσεις τύπου `decimal` θα πετάξουν ένα στιγμιότυπο της `OverflowException`.
