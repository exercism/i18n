# Αναφορές και Στιγμιότυπα

Όταν περνάς μια μεταβλητή σε μια συνάρτηση, η ιδιοκτησία της συνήθως μεταβιβάζεται, με αποτέλεσμα η αρχική μεταβλητή να μη μπορεί πια να χρησιμοποιηθεί. Αυτό μπορεί να γίνει λίγο κουραστικό όταν θέλεις να έχεις πρόσβαση σε μια κατάσταση πάνω από μία φορά.
Η Cairo έχει δύο χαρακτηριστικά για να περνάς μια τιμή χωρίς να την καταστρέφεις ή να τη μετακινείς, τις `references` και τα `snapshots`.

## Στιγμιότυπα

Τα στιγμιότυπα παρέχουν μια αμετάβλητη εικόνα μιας τιμής σε μια συγκεκριμένη χρονική στιγμή, επιτρέποντάς σου να διατηρείς την ιδιοκτησία μιας μεταβλητής ενώ έχεις πρόσβαση στην κατάστασή της.
Οποιαδήποτε τροποποίηση της μεταβλητής δημιουργεί ένα νέο κελί μνήμης, αφήνοντας την εικόνα του στιγμιότυπου αμετάβλητη.

```rust
fn get_len(arr: @Array<u128>) -> u32 { // this parameter takes in a snapshot using `@` with the data-type
    arr.len()
}

fn foo(arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];
    let snapshot = @new_arr; // using `@` to create a snapshot of a variable
    let len = get_len(snapshot); // pass the snapshot as argument, retaining ownership
    foo(new_arr); // `new_arr` is still valid up until here and no further

    // let new_len = new_arr.len(); // this would throw an error if you uncommented the code because `new_arr` has been moved when it was passed into `foo()` above
}
```

## Ο τελεστής desnap

Για να μετατρέψεις ένα στιγμιότυπο πίσω σε μια κανονική μεταβλητή, μπορείς να χρησιμοποιήσεις τον τελεστή desnap `*`, ο οποίος λειτουργεί ως το αντίθετο του τελεστή `@`.
Μόνο οι τύποι που υλοποιούν το trait `Copy` μπορούν να γίνουν desnap.

```rust
#[derive(Drop)]
struct Rectangle {
    height: u64,
    width: u64,
}

fn main() {
    let rec = Rectangle { height: 3, width: 10 };
    let area = calculate_area(@rec);
    println!("Area: {}", area);
}

fn calculate_area(rec: @Rectangle) -> u64 {
    // We need to transform the snapshots back into values using the desnap operator `*`.
    // Here we use `*` to both multiply the height and width and to desnap the snapshots.
    *rec.height * *rec.width
}
```

## Μεταβλητές αναφορές

Οι μεταβλητές αναφορές σου επιτρέπουν να περνάς μεταβλητές τιμές σε μια συνάρτηση και να επιστρέφονται σιωπηρά, διατηρώντας την ιδιοκτησία στο πλαίσιο κλήσης.
Αυτό μπορεί να επιτευχθεί με τον τροποποιητή `ref`, αρκεί η μεταβλητή να έχει δηλωθεί με τη λέξη-κλειδί `mut`.

```rust
fn foo(ref arr: Array<u128>) { // using `ref` marks the argument as a mutable reference
    arr.pop_front(); // modifies the state of arr
}

fn main() {
    let mut new_arr: Array<u128> = array![1, 2, 3, 4, 5, 6, 7, 8];

    foo(ref new_arr);  // use `ref` to pass a mutable reference to the function

    let new_len = new_arr.len();  // the current context retains ownership of `new_arr`, so we can still use it
}
```
