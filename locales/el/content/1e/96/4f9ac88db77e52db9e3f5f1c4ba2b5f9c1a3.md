# Υποδείξεις

## Γενικά

- Οι τελεστές για int και float περιγράφονται στην [περιήγηση στη γλώσσα][tour].
- Οι συναρτήσεις για χειρισμό int ορίζονται στο [άρθρωμα `gleam/int`][int].
- Οι συναρτήσεις για χειρισμό float ορίζονται στο [άρθρωμα `gleam/float`][float].
- Οι συναρτήσεις για χειρισμό συμβολοσειρών ορίζονται στο [άρθρωμα `gleam/string`][string].

[tour]: https://gleam.run/book/tour/ints-and-floats.html
[int]: https://hexdocs.pm/gleam_stdlib/gleam/int.html
[float]: https://hexdocs.pm/gleam_stdlib/gleam/float.html
[string]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
