# Παράρτημα οδηγιών

## Traits της Rust για το `.to_string()`

Θα χρειαστεί επίσης να υλοποιήσεις το `.to_string()` για το struct `Clock`.
Θα το χρησιμοποιήσουμε αυτό για να εμφανίζουμε την κατάσταση του Clock.
Μπορείς είτε να το κάνεις υλοποιώντας το απευθείας, είτε χρησιμοποιώντας το [trait `Display`][display-trait].

Αν ναι, δοκίμασε να υλοποιήσεις το [trait `Display`][display-trait] για το `Clock`.

Τα traits παρέχουν έναν κοινό τρόπο να υλοποιείς λειτουργικότητα για διάφορους τύπους.

Για επιπλέον εξάσκηση, σκέψου πώς θα μπορούσες να υλοποιήσεις το `String::from` για τον τύπο `Clock`.
Δεν χρειάζεται να το υλοποιήσεις πραγματικά, είναι περιττό σε σχέση με το `Display`, το οποίο είναι γενικά η
καλύτερη επιλογή όταν ο τύπος προορισμού είναι `String`, αλλά είναι χρήσιμο να έχεις μερικά traits
μετατροπής τύπων στην εργαλειοθήκη σου.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
