# Εισαγωγή

## Δυαδική σημειογραφία

Ένας **ακέραιος** είναι μια αφαίρεση που αναπαριστά ακέραιους αριθμούς, όπως `4`, `-2`, `0` ή `64532`.

Για να αναπαραστήσουμε έναν ακέραιο ως ακολουθία byte, χρησιμοποιείται η **δυαδική σημειογραφία**.
Σε αυτή τη σημειογραφία, κάθε bit της ακολουθίας αντιπροσωπεύει μια ξεχωριστή δύναμη του δύο, με την τιμή να αυξάνεται όσο αυξάνεται η θέση του bit από τα δεξιά προς τα αριστερά.

## Αριθμοί χωρίς πρόσημο

Αν ο αριθμός μπορεί να είναι μόνο μη αρνητικός, ονομάζεται **μη προσημασμένος** αριθμός.

Οι μη προσημασμένοι αριθμοί αναπαρίστανται απευθείας ως το άθροισμα των δυνάμεων του δύο που αντιστοιχούν σε όλα τα bit της ακολουθίας τους που έχουν τεθεί.

Το εύρος των αναπαραστάσιμων μη αρνητικών ακεραίων σε έναν καταχωρητή εκτείνεται από το `0` (κανένα bit δεν έχει τεθεί) έως το `2⁶⁴ - 1` (άθροισμα και των 64 bit που έχουν τεθεί).

Η διεύρυνση ενός μη προσημασμένου αριθμού σε μεγαλύτερο μέγεθος γίνεται γεμίζοντας όλα τα ανώτερα bit με `0`, ώστε κανένα νέο bit να μη συνεισφέρει στην τιμή.
Αυτό ονομάζεται **επέκταση με μηδενικά**.

Η εντολή `movzx` (`z` για το μηδέν) επεκτείνει με μηδενικά έναν τελεστέο προέλευσης 8 ή 16 bit σε έναν μεγαλύτερο τελεστέο προορισμού.
Ένας τελεστέος προέλευσης 32 bit επεκτείνεται πάντα με μηδενικά σε όλα τα 64 bit του τελεστέου προορισμού με ένα απλό `mov`.

## Προσημασμένοι αριθμοί

Αν ένας ακέραιος μπορεί να πάρει θετικές ή αρνητικές τιμές, ονομάζεται **προσημασμένος** αριθμός.

Για να αναπαραστήσει αρνητικούς αριθμούς, το x86-64 χρησιμοποιεί την αναπαράσταση **συμπληρώματος ως προς δύο**.

Στο συμπλήρωμα ως προς δύο, οι προσημασμένοι αριθμοί αναπαρίστανται επίσης ως το άθροισμα των δυνάμεων του δύο που αντιστοιχούν στα bit που έχουν τεθεί.
Ωστόσο, αν το ανώτατο bit έχει τεθεί, αφαιρείται αντί να προστίθεται στα υπόλοιπα.

Επειδή αυτό το bit αντιστοιχεί σε μεγαλύτερη τιμή από το άθροισμα όλων των άλλων, στην πράξη αυτό σημαίνει ότι ένας αριθμός με αυτό το bit τεθειμένο είναι πάντα αρνητικός.
Αυτό το ειδικό bit ονομάζεται **bit πρόσημου**.

Η διεύρυνση ενός προσημασμένου αριθμού σε μεγαλύτερο μέγεθος σημαίνει γέμισμα κάθε νέου ανώτερου bit με ένα αντίγραφο του bit πρόσημου, ώστε να διατηρηθεί η τιμή.
Αυτό ονομάζεται **επέκταση πρόσημου**.

Η εντολή `movsx` (`s` για το πρόσημο) επεκτείνει το πρόσημο ενός τελεστέου προέλευσης 8 ή 16 bit σε έναν μεγαλύτερο τελεστέο προορισμού.
Μια παραλλαγή της `movsx` που ονομάζεται `movsxd` κάνει το ίδιο από έναν τελεστέο προέλευσης 32 bit σε έναν τελεστέο προορισμού 64 bit.

Η εντολή `neg` μπορεί να χρησιμοποιηθεί για να αλλάξει το πρόσημο ενός αριθμού.

~~~~exercism/caution
Στην assembly, δεν υπάρχει τρόπος να καταλάβεις αν μια ακολουθία byte αναπαριστά έναν προσημασμένο ή έναν μη προσημασμένο αριθμό.
Είναι ευθύνη του προγραμματιστή να δώσει νόημα σε αυτά τα byte.

Η χρήση σχολίων μπορεί να βοηθήσει πολύ σε αυτό το έργο.
~~~~

## Άμεσα

Σε μια προηγούμενη ενότητα, αναφέρθηκε ότι ένας σταθερός αριθμός, όπως το `4` ή το `-15`, μπορεί να χρησιμοποιηθεί ως τελεστέος προέλευσης σε πολλές εντολές.
Αυτοί οι αριθμοί ονομάζονται **άμεσα**.

Ένα άμεσο δεν αποθηκεύεται σε καταχωρητή ή στη μνήμη: κωδικοποιείται μέσα στην ίδια την εντολή.
Στις περισσότερες εντολές, ο χώρος που του δεσμεύεται είναι μόνο 32 bit, ανεξάρτητα από το πόσο μεγάλος είναι ο τελεστέος προορισμού.

Όταν ο τελεστέος προορισμού είναι 64 bit, αυτά τα 32 bit υφίστανται _επέκταση πρόσημου_ για να τον γεμίσουν.
Το ανώτερο μισό του τελεστέου γεμίζει εξ ολοκλήρου με αντίγραφα του ανώτατου bit του άμεσου, οπότε μόνο ένας αριθμός στο εύρος ενός _προσημασμένου ακεραίου 32 bit_ μπορεί να γραφτεί με αυτόν τον τρόπο:

```x86asm
add rax, -1          ; the immediate is sign-extended, so all 64 bits of rax are affected
add rax, 2147483647  ; the largest immediate an instruction like this accepts
```

Ένας αριθμός εκτός αυτού του εύρους δεν μπορεί να χρησιμοποιηθεί ως άμεσο.
Η εξαίρεση σε αυτόν τον κανόνα είναι η `mov`, η οποία μπορεί να δεχτεί ένα πλήρες άμεσο 64 bit όταν ο τελεστέος προορισμού είναι καταχωρητής.
Αν χρειάζεται ένα άμεσο 64 bit, χρησιμοποίησε πρώτα την `mov` για να το φορτώσεις σε έναν καταχωρητή και μετά χρησιμοποίησε αυτόν τον καταχωρητή:

```x86asm
mov rax, 3435973837           ; this works, mov can take a 64-bit immediate
mov rdx, 18446744073709551615 ; the largest immediate mov accepts
sub rdx, rax
```

Σημείωσε ότι ένα αρνητικό άμεσο και ο μη προσημασμένος αριθμός με την ίδια αναπαράσταση bit είναι ισοδύναμα και παράγουν την ίδια ακριβώς τιμή:

```x86asm
mov rax, -1                   ; rax = 18446744073709551615
mov rax, 18446744073709551615 ; rax = -1
```

## Άθροισμα

Η πρόσθεση δύο αριθμών μπορεί να υπολογιστεί με την εντολή `add`.

Υπάρχει επίσης η εντολή `inc`, με έναν τελεστέο, που προσθέτει `1` στην τιμή του τελεστέου της:

```x86asm
inc rax ; rax = rax + 1
```

Το άθροισμα δύο ακεραίων λειτουργεί με τον ίδιο τρόπο τόσο για μη προσημασμένους όσο και για προσημασμένους αριθμούς.

## Αφαίρεση

Η αφαίρεση δύο ακεραίων εκτελείται με την εντολή `sub`.

Υπάρχει επίσης η εντολή `dec`, με έναν τελεστέο, που αφαιρεί `1` από την τιμή του τελεστέου της:

```x86asm
dec rax ; rax = rax - 1
```

Η αφαίρεση δύο ακεραίων λειτουργεί επίσης με τον ίδιο τρόπο τόσο για μη προσημασμένους όσο και για προσημασμένους αριθμούς.

## Πολλαπλασιασμός

Υπάρχουν δύο διαφορετικές εντολές για τον πολλαπλασιασμό δύο αριθμών στο x86-64.
Κατά κανόνα, ο μη προσημασμένος πολλαπλασιασμός χρησιμοποιεί την εντολή `mul`, ενώ ο προσημασμένος πολλαπλασιασμός χρησιμοποιεί την `imul`.

Η εντολή `mul` παίρνει την ακόλουθη μορφή με έναν τελεστέο, όπου το `src` είναι ο τελεστέος προέλευσης:

```x86asm
mul src
```

Η εντολή `imul` μπορεί να πάρει μορφή με έναν, δύο ή τρεις τελεστέους:

```x86asm
imul src
imul dest, src
imul dest, src1, src2
```

### Πολλαπλασιασμός με έναν τελεστέο

Δύο καταχωρητές χρησιμοποιούνται σιωπηρά για να εκτελεστεί ένας πολλαπλασιασμός στη μορφή με έναν τελεστέο: οι `rax` και `rdx`.
Αν ο πολλαπλασιασμός αφορά δύο αριθμούς 64 bit, τότε τα χαμηλότερα 64 bit του αποτελέσματος θα βρίσκονται στον `rax` και τα ανώτερα 64 bit στον `rdx`.

Αυτό συνήθως ονομάζεται `rdx:rax`, για να δηλωθεί ότι και οι δύο καταχωρητές χρησιμοποιούνται από κοινού:

```x86asm
mul rcx ; rax = lower 64 bits of rax * rcx
        ; rdx = upper 64 bits of rax * rcx
```

Το ίδιο συμβαίνει και για άλλα μεγέθη τελεστέων.
Έτσι, για παράδειγμα, αν πολλαπλασιάζονται δύο αριθμοί 32 bit, θα χρησιμοποιηθούν οι `eax` και `edx`.

Η εξαίρεση είναι ο πολλαπλασιασμός μεταξύ δύο byte.

Σε αυτή την περίπτωση, αντί για `dl:al`, θα χρησιμοποιηθεί ο `ax`.
Το χαμηλότερο τμήμα του `ax` (`al`) θα πάρει τα χαμηλότερα 8 bit του γινομένου, ενώ το ανώτερο τμήμα (`ah`) θα πάρει τα ανώτερα 8 bit.

~~~~exercism/caution
Οι καταχωρητές που χρησιμοποιούνται σιωπηρά σε έναν πολλαπλασιασμό, όπως οι `rax` και `rdx`, αντικαθίστανται πάντα.
Οι τιμές σε αυτούς τους καταχωρητές θα πρέπει να αποθηκευτούν πριν από την πράξη, αν χρειάζονται αργότερα.
~~~~

### Πολλαπλασιασμός με δύο τελεστέους

Η μορφή της `imul` με δύο τελεστέους έχει ρητό τελεστέο προορισμού και ακολουθεί τη συνήθη σύνταξη.
Ο `rdx` δεν χρησιμοποιείται.
Αντ' αυτού, το αποτέλεσμα περικόπτεται για να χωρέσει στον τελεστέο προορισμού.

```x86asm
imul r8, r9 ; r8 = lower 64 bits of r8 * r9
```

### Πολλαπλασιασμός με τρεις τελεστέους

Η μορφή της `imul` με τρεις τελεστέους έχει δύο τελεστέους προέλευσης, ο δεύτερος από τους οποίους είναι πάντα ένα άμεσο (ένας σταθερός αριθμός).
Και οι δύο τελεστέοι προέλευσης πολλαπλασιάζονται και το αποτέλεσμα περικόπτεται και τοποθετείται στον τελεστέο προορισμού:

```x86asm
imul r8, r9, 100 ; r8 = lower 64 bits of r9 * 100
```

Σημείωσε ότι ο τελεστέος προορισμού δεν χρησιμοποιείται στον πολλαπλασιασμό.
Απλώς δέχεται το αποτέλεσμα.

### Χειρισμός υπερχείλισης

Τόσο ο πολλαπλασιασμός με δύο τελεστέους όσο και αυτός με τρεις τελεστέους περικόπτουν το αποτέλεσμα για να χωρέσει στο μέγεθος του τελεστέου προορισμού.
Ο πολλαπλασιασμός με έναν τελεστέο διατηρεί το πλήρες εύρος, αλλά συνήθως μοιράζεται σε δύο καταχωρητές, τους `rdx` και `rax`.

Έτσι, μερικές φορές είναι χρήσιμο να διευρύνεις τους τελεστέους πριν από τον πολλαπλασιασμό, ώστε να χωρέσει ολόκληρο το γινόμενο σε έναν μόνο καταχωρητή.
Ένας μη προσημασμένος τελεστέος επεκτείνεται με μηδενικά, ενώ ένας προσημασμένος επεκτείνεται με πρόσημο:

```x86asm
movzx eax, di ; di and si hold unsigned 16-bit numbers
movzx ecx, si
mul ecx       ; the 32-bit product fits in eax, and edx is cleared
```

## Διαίρεση

Όπως συμβαίνει και με τον πολλαπλασιασμό, υπάρχουν επίσης δύο εντολές για τη διαίρεση δύο αριθμών.
Η μη προσημασμένη διαίρεση χρησιμοποιεί την εντολή `div`, ενώ η προσημασμένη διαίρεση χρησιμοποιεί την `idiv`.

Και οι δύο εντολές λειτουργούν με έναν μόνο τελεστέο:

```x86asm
div src
idiv src
```

Η διαίρεση 16, 32 και 64 bit χρησιμοποιεί ως διαιρετέο τους `dx:ax`, `edx:eax` και `rdx:rax`, αντίστοιχα.
Σε αυτές τις περιπτώσεις, και οι δύο καταχωρητές δρουν από κοινού για να σχηματίσουν μια τιμή 2N bit, όπου N είναι το μέγεθος της πράξης (16, 32 ή 64 bit).
Αυτή η τιμή διαιρείται στη συνέχεια με τον τελεστέο προέλευσης.
Το πηλίκο γράφεται στον `ax`, τον `eax` ή τον `rax` και το υπόλοιπο γράφεται στον `dx`, τον `edx` ή τον `rdx`, ανάλογα με το μέγεθος της πράξης.

Η διαίρεση μεταξύ byte είναι ειδική περίπτωση: αντί να χρησιμοποιείται ο `dl:al`, χρησιμοποιείται ο `ax`.
Τα χαμηλότερα 8 bit του `ax` (`al`) θα πάρουν το πηλίκο της πράξης και τα ανώτερα 8 bit (`ah`) θα πάρουν το υπόλοιπο.

Σημείωσε ότι όλα τα bit του διαιρετέου θα πρέπει να έχουν τεθεί κατάλληλα πριν από τη διαίρεση.
Κάθε bit που έχει τεθεί στον `rdx` (ή στον `ah` για τη διαίρεση 8 bit) συνεισφέρει στην τιμή που διαιρείται.

Στη μη προσημασμένη διαίρεση, όταν η τιμή που θα διαιρεθεί χωράει στο χαμηλότερο μισό, το ανώτερο μισό θα πρέπει να μηδενιστεί.
Οποιαδήποτε εντολή μηδενίζει αυτά τα bit κάνει.
Για παράδειγμα, η `mov edx, 0` μηδενίζει τα ανώτερα bit στη διαίρεση 32 bit.

Στην προσημασμένη διαίρεση, αντίθετα, η τιμή θα πρέπει να υποστεί επέκταση πρόσημου.
Υπάρχουν εντολές που αυτοματοποιούν αυτή τη διαδικασία: οι `cbw`, `cwd`, `cdq` και `cqo`.
Η πρώτη θέτει τα bit του `ah` ανάλογα με το πρόσημο του `al`.
Οι υπόλοιπες εκτελούν επέκταση πρόσημου από τον `ax` στον `dx`, από τον `eax` στον `edx` και από τον `rax` στον `rdx`, αντίστοιχα.

~~~~exercism/caution
Οι καταχωρητές που χρησιμοποιούνται σιωπηρά σε μια διαίρεση, όπως οι `rax` και `rdx`, αντικαθίστανται πάντα.
Οι τιμές σε αυτούς τους καταχωρητές θα πρέπει να αποθηκευτούν πριν από τη διαίρεση, αν χρειάζονται αργότερα.
~~~~
