# Εισαγωγή

## Τα βασικά

### Σχόλια

Το track x86-64 στο Exercism χρησιμοποιεί το **NASM** (The Netwide Assembler) ως συμβολομεταφραστή του.
Στο NASM, τα σχόλια ξεκινούν με το σύμβολο `;`.

Τα σχόλια μπορούν να τοποθετηθούν οπουδήποτε στο πρόγραμμα και ό,τι ακολουθεί μετά από ένα `;` αγνοείται από τον συμβολομεταφραστή.

### Σταθερές

Μια σταθερά χρόνου συμβολομετάφρασης μπορεί να οριστεί στο NASM με το **equ**.
Για παράδειγμα, αυτό ορίζει μια σταθερά με όνομα `UNIVERSE` και τιμή `42`:

```x86asm
UNIVERSE equ 42
```

Οι σταθερές αξιολογούνται μία φορά, όταν ορίζονται, και _δεν_ μπορούν να επαναοριστούν αργότερα.

### Καταχωρητές γενικού σκοπού (GPRs)

Στην assembly, αντί για μεταβλητές, συνήθως χρησιμοποιούμε καταχωρητές για να αποθηκεύουμε τιμές.
Ένας **καταχωρητής CPU** είναι ένα κομμάτι γρήγορης μνήμης μέσα στον επεξεργαστή ενός υπολογιστή.
Οι περισσότεροι υπολογισμοί εκτελούνται μέσα στους καταχωρητές της CPU.

Κάποιοι από τους καταχωρητές χρησιμοποιούνται για ποικίλους διαφορετικούς υπολογισμούς και ονομάζονται **καταχωρητές γενικού σκοπού (GPRs)**.
Άλλοι έχουν ειδικούς ή αποκλειστικούς σκοπούς.

Στο x86-64 υπάρχουν 16 καταχωρητές γενικού σκοπού (GPRs) των 64 bit, στους οποίους μπορεί επίσης να γίνει πρόσβαση ως 32 bit, 16 bit ή 8 bit.
Οι GPRs περιγράφονται παρακάτω, όπου το `n` στο `rn` κυμαίνεται από 8 έως 15: `r8`, `r9`, `r10`, `r11`, `r12`, `r13`, `r14` και `r15`.

| 64-bit | 32-bit | 16-bit | 8-bit |
| :----: | :----: | :----: | :---: |
|  rax   |  eax   |   ax   | ah/al |
|  rbx   |  ebx   |   bx   | bh/bl |
|  rcx   |  ecx   |   cx   | ch/cl |
|  rdx   |  edx   |   dx   | dh/dl |
|  rsi   |  esi   |   si   |  sil  |
|  rdi   |  edi   |   di   |  dil  |
|  rbp   |  ebp   |   bp   |  bpl  |
|  rsp   |  esp   |   sp   |  spl  |
|   rn   |  rnd   |  rnw   |  rnb  |

Όταν χρησιμοποιούνται λιγότερα από 64 bit, τα bit στα οποία γίνεται πρόσβαση προέρχονται συνήθως από το χαμηλότερο τμήμα του καταχωρητή.
Εξαίρεση σε αυτόν τον κανόνα αποτελούν οι `ah`, `bh`, `ch` και `dh`, που έχουν πρόσβαση στα ανώτερα 8 bit από το τμήμα των 16 bit του καταχωρητή.

Απεικόνιση του τρόπου με τον οποίο γίνεται η πρόσβαση στα bit για τον καταχωρητή `rax`:

```
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```

Κάποιοι από αυτούς τους καταχωρητές πρέπει να διατηρούνται κατά τις κλήσεις συναρτήσεων: `rbp`, `rsp`, `rbx`, `r12`, `r13`, `r14` και `r15`.
Η μη διατήρησή τους μπορεί να οδηγήσει σε σφάλμα ή σε απροσδιόριστη συμπεριφορά.

Οι υπόλοιποι δεν διατηρούνται και μπορούν να χρησιμοποιηθούν ελεύθερα: `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` και `r11`.

~~~~exercism/caution
Αργότερα στο πρόγραμμα σπουδών θα μάθεις πώς να διατηρείς τους καταχωρητές.
Για την ώρα, χρησιμοποίησε μόνο τον δεύτερο τύπο καταχωρητών: `rax`, `rcx`, `rdx`, `rdi`, `rsi`, `r8`, `r9`, `r10` και `r11`.
~~~~

### Εντολές

Οι εντολές είναι κομμάτια υπολογισμών που μπορεί να εκτελέσει μια CPU.
Συνήθως έχουν την εξής μορφή:

```x86asm
name destination, source
```

Έτσι, πρώτα τοποθετείται το όνομα της εντολής, μετά τουλάχιστον ένα κενό διάστημα, ακολουθούμενο από τον τελεστέο προορισμού, ένα κόμμα (`,`) και τέλος έναν τελεστέο πηγής.
Ο τελεστέος πηγής συνήθως δεν τροποποιείται από μια εντολή, μόνο ο τελεστέος προορισμού.

Και οι δύο τελεστέοι πρέπει να έχουν το ίδιο μέγεθος, εκτός αν αναφέρεται διαφορετικά.
Για παράδειγμα, ο τελεστέος προορισμού πρέπει να έχει κι αυτός 16 bit αν ο τελεστέος πηγής έχει 16 bit.

Για παράδειγμα, για να αποθηκεύσουμε μια τιμή σε έναν καταχωρητή, μπορούμε να χρησιμοποιήσουμε την εντολή `mov`:

```x86asm
mov rax, rdx  ; rax = rdx
              ; mov is the name, rax is the destination operand and rdx is the source operand
```

Το παραπάνω απόσπασμα αντιγράφει τα περιεχόμενα και των 64 bit του `rdx`, του τελεστέου πηγής, στα 64 bit του `rax`, που είναι ο τελεστέος προορισμού της εντολής.

Στις περισσότερες εντολές είναι δυνατό να χρησιμοποιηθούν σταθεροί ακέραιοι αριθμοί ως τελεστέοι πηγής (αλλά όχι ως τελεστέοι προορισμού):

```x86asm
mov rcx, 42 ; rcx = 42
            ; rcx is the destination operand and 42 is the source operand
```

Σημείωσε ότι η εγγραφή σε έναν καταχωρητή 32 bit καθαρίζει επίσης τα ανώτερα bit, οπότε το `mov eax, 42` είναι το ίδιο με το `mov rax, 42`.
Αυτό δεν ισχύει για καταχωρητές 16 bit και 8 bit.

Για τις αριθμητικές πράξεις της πρόσθεσης, της αφαίρεσης και του πολλαπλασιασμού, μπορούμε να χρησιμοποιήσουμε τις εντολές `add`, `sub` και `imul`:

```x86asm
add rax, rsi ; rax = rax + rsi
imul rax, rdi ; rax = rax * rdi
sub rax, r8 ; rax = rax - r8
```

### Συναρτήσεις

Οι εντολές οργανώνονται σε συναρτήσεις.
Όλες οι συναρτήσεις τοποθετούνται στη **section .text** του αρχείου πηγαίου κώδικα.

Η δήλωση μιας συνάρτησης αποτελείται από:

1. Μια ετικέτα με το όνομα της συνάρτησης, ακολουθούμενη από ένα `:`.
2. Τις εντολές που ορίζουν τη συνάρτηση.
3. Την εντολή επιστροφής, `ret`.

Αυτό το track χρησιμοποιεί τη σύμβαση κλήσης System V AMD64 ABI και τα έξι πρώτα ακέραια ορίσματα περνούν σε μια συνάρτηση μέσα σε καταχωρητές.
Περνούν με την εξής σειρά: `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.

Μια ακέραια τιμή επιστρέφεται από τη συνάρτηση στον καταχωρητή `rax`.

Για να καλέσουμε μια συνάρτηση, χρησιμοποιούμε την εντολή `call`.
Μια συνάρτηση μπορεί να κληθεί οπουδήποτε στο ίδιο αρχείο πηγαίου κώδικα.
Για να γίνει μια συνάρτηση ορατή σε άλλα αρχεία πηγαίου κώδικα, πρέπει να χρησιμοποιηθεί η οδηγία `global`.

Για παράδειγμα, αυτό δηλώνει μια συνάρτηση `sum`:

```x86asm
section .text ; functions are placed here

global sum ; sum is visible to other source files

sum:
    ; first argument is passed in rdi
    ; second argument is passed in rsi
    ; return value is placed in rax

    mov rax, rdi ; rax is now equal to rdi
    add rax, rsi ; rax = rax + rsi

    ret ; function return
```

Και αυτό καλεί τη συνάρτησή μας `sum` με ορίσματα 3 και 5:

```x86asm
mov rdi, 3  ; First argument in rdi
mov rsi, 5  ; Second argument in rsi
call sum

; The rax register now contains the value 8 (3 + 5), after sum returns
```
