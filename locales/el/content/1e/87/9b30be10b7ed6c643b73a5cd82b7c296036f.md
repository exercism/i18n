# Οδηγίες

Σε αυτή την άσκηση θα διοργανώσεις αγώνες ανάμεσα σε διάφορα είδη τηλεχειριζόμενων αυτοκινήτων. Κάθε αυτοκίνητο έχει τα δικά του χαρακτηριστικά ταχύτητας και κατανάλωσης μπαταρίας.

Τα αυτοκίνητα ξεκινούν με γεμάτη (100%) μπαταρία. Κάθε φορά που οδηγείς το αυτοκίνητο με το τηλεχειριστήριο, αυτό διανύει τόσα μέτρα όση είναι η ταχύτητα του αυτοκινήτου και μειώνει το υπόλοιπο ποσοστό της μπαταρίας κατά την κατανάλωσή του.

Αν η μπαταρία ενός αυτοκινήτου είναι κάτω από το ποσοστό κατανάλωσής του, δεν μπορείς να οδηγήσεις άλλο το αυτοκίνητο.

Κάθε πίστα αγώνων έχει τη δική της απόσταση. Τα αυτοκίνητα δοκιμάζονται ελέγχοντας αν μπορούν να τερματίσουν την πίστα χωρίς να ξεμείνουν από μπαταρία.

Έχεις έξι εργασίες, καθεμία από τις οποίες θα δουλέψει με στιγμιότυπα τηλεχειριζόμενων αυτοκινήτων.

## 1. Δημιουργία ενός τηλεχειριζόμενου αυτοκινήτου

Επίτρεψε τη δημιουργία ενός τηλεχειριζόμενου αυτοκινήτου ορίζοντας έναν κατασκευαστή για την κλάση `RemoteControlCar` που παίρνει ως δύο παραμέτρους του την ταχύτητα του αυτοκινήτου σε μέτρα και το ποσοστό κατανάλωσης της μπαταρίας (και οι δύο τύπου `int`):

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. Δημιουργία μιας πίστας αγώνων

Επίτρεψε τη δημιουργία μιας πίστας αγώνων ορίζοντας έναν κατασκευαστή για την κλάση `RaceTrack` που παίρνει ως μοναδική παράμετρό του την απόσταση της πίστας σε μέτρα (η οποία είναι τύπου `int`):

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Οδήγησε το αυτοκίνητο

Υλοποίησε τη μέθοδο `RemoteControlCar.Drive()` που ενημερώνει τον αριθμό των μέτρων που διανύθηκαν με βάση την ταχύτητα του αυτοκινήτου. Υλοποίησε επίσης τη μέθοδο `RemoteControlCar.DistanceDriven()` ώστε να επιστρέφει τον αριθμό των μέτρων που έχει διανύσει το αυτοκίνητο:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. Έλεγξε αν η μπαταρία έχει αδειάσει

Ενημέρωσε τη μέθοδο `RemoteControlCar.Drive()` ώστε να καταναλώνει μπαταρία με βάση την κατανάλωση του αυτοκινήτου. Υλοποίησε επίσης τη μέθοδο `RemoteControlCar.BatteryDrained()` που δείχνει αν η μπαταρία έχει αδειάσει:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. Δημιούργησε το τηλεχειριζόμενο αυτοκίνητο Nitro

Το τηλεχειριζόμενο αυτοκίνητο με τις περισσότερες πωλήσεις είναι το Nitro, το οποίο έχει εντυπωσιακή μέγιστη ταχύτητα 50 μέτρων με κατανάλωση μπαταρίας 4%. Υλοποίησε τη (στατική) μέθοδο `RemoteControlCar.Nitro()` ώστε να επιστρέφει αυτόν τον τύπο αυτοκινήτου:

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. Έλεγξε αν ένα τηλεχειριζόμενο αυτοκίνητο μπορεί να τερματίσει έναν αγώνα

Για να τερματίσει μια πίστα αγώνων, ένα αυτοκίνητο πρέπει να μπορεί να διανύσει την απόστασή της. Αυτό σημαίνει ότι δεν πρέπει να αδειάσει η μπαταρία του πριν περάσει τη γραμμή τερματισμού. Υλοποίησε τη μέθοδο `RaceTrack.TryFinishTrack()` που παίρνει ως παράμετρό της ένα στιγμιότυπο `RemoteControlCar` και επιστρέφει `true` αν το αυτοκίνητο μπορεί να τερματίσει την πίστα αγώνων· αλλιώς, επιστρέφει `false`:

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
