Τα `String` και `&str` είναι δύο θεμελιώδεις τρόποι για να δουλεύεις με δεδομένα κειμένου στη Rust.

Το `String` είναι ένα ιδιόκτητο, μεταβλητό διάνυσμα από bytes `u8`.
Το `&str` είναι μια δανεισμένη αναφορά σε ένα slice ενός `String` και επομένως αμετάβλητο.

Μπορείς επίσης να δημιουργήσεις και να τροποποιήσεις `String` χρησιμοποιώντας μία από τις πολλές μεθόδους τους, όπως τη `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

Μπορείς επίσης να δημιουργήσεις ένα `String` μετατρέποντας ένα `&str`:
```rust
let a_string = "hello".to_string();
```
