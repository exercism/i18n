# Σχετικά

## Πράξεις bitwise

Οι πράξεις bitwise μάς επιτρέπουν να χειριζόμαστε μεμονωμένα ψηφία μέσα σε δυαδικούς αριθμούς.
Αυτές οι πράξεις είναι θεμελιώδεις στην πληροφορική, καθώς προσφέρουν έναν αποδοτικό τρόπο για εργασίες χαμηλού επιπέδου, όπως ο έλεγχος συγκεκριμένων bit στη μνήμη, η βελτιστοποίηση μαθηματικών υπολογισμών, η κρυπτογράφηση, οι επικοινωνίες και η κωδικοποίηση/αποκωδικοποίηση δεδομένων.

### Κατανοώντας τους ακέραιους 32 bit στην Elm

Στην Elm, οι ακέραιοι αποθηκεύονται ως ακέραιοι 32 bit με πρόσημο, χρησιμοποιώντας αναπαράσταση [συμπληρώματος ως προς δύο](https://en.wikipedia.org/wiki/Two%27s_complement), δηλαδή χρησιμοποιούν 32 δυαδικά ψηφία (_bits_) για να αποθηκεύσουν κάθε ακέραια τιμή.
Αυτό το όριο bit επηρεάζει το εύρος των ακεραίων που μπορεί να αναπαραστήσει απευθείας η Elm:

Θετικό εύρος: 0 έως 2<sup>31</sup> - 1 (ή 0 έως 2,147,483,647)
Αρνητικό εύρος: -2<sup>31</sup> έως -1 (ή -2,147,483,648 έως -1).

Για παράδειγμα, ο ακέραιος `5` αναπαρίσταται σε δυαδική μορφή ως `00000000000000000000000000000101`, αν και συνήθως αγνοούμε τα μηδενικά στην αρχή και λέμε απλώς `101`.

### Τελεστές bitwise

Η Elm παρέχει αρκετούς τελεστές bitwise στο [module Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Βασικές πράξεις

Η τροποποίηση μεμονωμένων bit ενός αριθμού ονομάζεται _εφαρμογή μάσκας_.
Μια _μάσκα_ είναι ένας αριθμός όπου συγκεκριμένα bit έχουν τεθεί με έναν συγκεκριμένο τρόπο, ώστε να χειριστούμε έναν άλλον αριθμό με τελεστές bitwise όπως οι `and`, `or` και `xor`.

### and

Ο `and` συνδυάζει δύο αριθμούς κρατώντας μόνο τα bit που είναι `1` και στους δύο.
Αυτό είναι χρήσιμο για να ελέγξεις αν ένα μεμονωμένο bit έχει τεθεί σε `1`.
Για παράδειγμα, για να ελέγξεις αν το 4ο bit ενός αριθμού είναι `1`, εφάρμοσε `and` με μια μάσκα `01000` (`8` στο δεκαδικό σύστημα) και δες αν το αποτέλεσμα δεν είναι μηδέν:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

Ο `or` συνδυάζει δύο αριθμούς θέτοντας κάθε bit σε `1` αν είναι `1` στον έναν ή και στους δύο αριθμούς.
Αυτό είναι χρήσιμο για να θέσεις ένα συγκεκριμένο bit σε `1`.
Για παράδειγμα, για να θέσεις το 2ο bit στο `10101` σε `1`, εφάρμοσε `or` με τη μάσκα `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### Αποκλειστικό ή (xor)

Ο `xor` συνδυάζει δύο αριθμούς θέτοντας κάθε bit σε `1` αν είναι `1` στον έναν αριθμό αλλά `0` στον άλλον.
Αυτό είναι χρήσιμο για να αντιστρέψεις ένα bit στην αντίθετη τιμή του:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Συμπλήρωμα

Ο `complement` αντιστρέφει κάθε bit ενός αριθμού (το `0` γίνεται `1`, το `1` γίνεται `0`).

Σημείωσε ότι έτσι οι θετικοί αριθμοί γίνονται αρνητικοί και οι αρνητικοί γίνονται θετικοί.
Αυτό συμβαίνει επειδή οι αρνητικοί αριθμοί στο δυαδικό σύστημα αναπαρίστανται με `1` στην πιο αριστερή θέση.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Μετατόπιση bit

Οι παρακάτω τελεστές μετακινούν τα bit αριστερά ή δεξιά κατά έναν καθορισμένο αριθμό θέσεων, πολλαπλασιάζοντας ή διαιρώντας ουσιαστικά με δυνάμεις του 2.

Ο `shiftLeftBy` μετακινεί τα bit αριστερά, γεμίζοντας με `0` από τα δεξιά.
Για παράδειγμα, για να μετατοπίσεις το `21` αριστερά κατά 3 θέσεις:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Αυτό είναι το ίδιο με το να πεις `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

Ο `shiftRightBy`: μετακινεί τα bit δεξιά:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Η μετατόπιση δεξιά κατά 2 θέσεις είναι το ίδιο με ακέραια διαίρεση με το 4.

Σημείωσε ότι αυτή η συνάρτηση αντιγράφει όποια τιμή βρίσκεται στο πιο αριστερό bit.
Έτσι, οι αρνητικοί αριθμοί παραμένουν αρνητικοί:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Αν θέλεις να μετατοπίσεις δεξιά και να γεμίσεις με μηδενικά, χρησιμοποίησε το `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
