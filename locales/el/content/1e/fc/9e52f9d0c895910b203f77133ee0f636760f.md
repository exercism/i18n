# Εισαγωγή

Το R δεν έχει ξεχωριστό τύπο [Σύνολο][wiki-set] και αντ' αυτού χρησιμοποιεί μια ποικιλία συναρτήσεων για να εκτελεί παρόμοιες πράξεις σε διανύσματα.

Ο τελεστής [`%in%`][ref-match] ελέγχει τη συμμετοχή σε σύνολο.
Αυτός ο ενθεματικός τελεστής είναι συνώνυμος με τη συνάρτηση `is.element()`.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Οι σχετικές συναρτήσεις περιλαμβάνουν:

- [`unique()`][ref-unique] για αφαίρεση διπλοτύπων.
- [`union()`][ref-sets] για συνένωση συνόλων (μαθηματικά, `A ∪ B`).
- [`intersect()`][ref-sets] για εύρεση των κοινών στοιχείων δύο συνόλων (`A ∩ B`).
- [`setdiff()`][ref-sets] για αφαίρεση ενός συνόλου από ένα άλλο (`A - B`).
- [`setequal`][ref-sets] για έλεγχο ισότητας συνόλων, αγνοώντας διπλότυπα και σειρά.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

Σε κάθε περίπτωση, η συνάρτηση επιστρέφει ένα αντίγραφο και αφήνει τα ορίσματα αμετάβλητα.

## Πίνακες κατακερματισμού

Οι πράξεις με διανύσματα που περιγράφηκαν παραπάνω αποτελούν μέρος του βασικού R.
Είναι χρήσιμες για μικρά προβλήματα, αλλά γίνονται αργές για μεγάλα σύνολα.

Διάφορα πακέτα τρίτων υλοποιούν [πίνακες κατακερματισμού][wiki-hash], για βελτίωση της απόδοσης σε ορισμένα πλαίσια.

Για παράδειγμα, το πακέτο [`hashtable`][ref-hashtable] παρέχει υλοποιήσεις των `hashmap` και `hashset`, που κλιμακώνονται καλύτερα.
Όπως τα περισσότερα εξωτερικά πακέτα, αυτό δεν είναι διαθέσιμο στο Exercism, αλλά αξίζει να το διερευνήσεις για προβλήματα του πραγματικού κόσμου.
