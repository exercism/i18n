# Σχετικά

Γράψε κώδικα που διαβάζεται σαν απλά αγγλικά.

Το Visual Basic τρέχει στο ίδιο .NET runtime με C# και F#.
Έχεις LINQ, γενικούς τύπους και async/await, αλλά η σύνταξη είναι φτιαγμένη για να τη διαβάζεις, όχι για να την αποκωδικοποιείς.

Αν ξέρεις ήδη C# ή F#, το .NET runtime και οι βιβλιοθήκες θα σου είναι γνώριμα.
Αν ξέρεις VB6, VBA ή VBScript, αυτή η γνώριμη σύνταξη υποστηρίζεται πλέον από το .NET runtime που έχει αποδείξει την αντοχή του.

Χωρίς άγκιστρα να ισορροπείς, χωρίς semicolons να κυνηγάς.
