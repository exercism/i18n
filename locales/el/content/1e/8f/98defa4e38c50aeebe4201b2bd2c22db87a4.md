# Οδηγίες

Το τμήμα διεκδικήσεων της Isaac's Asteroid Exploration Co. σου ανέθεσε να βελτιώσεις την απόδοση του συστήματός τους για διεκδικήσεις γης.

Κάθε φορά που ένας αστεροειδής είναι έτοιμος για εκμετάλλευση, οι κερδοσκόποι καλούνται να διεκδικήσουν το κομμάτι γης τους.
Η γη του αστεροειδούς χωρίζεται σε μη επικαλυπτόμενα ορθογώνια οικόπεδα.
Οι διαστάσεις διαφέρουν, αλλά όλα έχουν πλευρές παράλληλες προς τους άξονες συντεταγμένων.
Οι κερδοσκόποι διεκδικούν ένα από τα οικόπεδα καθορίζοντας τις συντεταγμένες του.

Ο στόχος σου είναι να αναπτύξεις ένα αποδοτικό σύστημα που θα χειρίζεται τον πυρετό διεκδικήσεων γης, ο οποίος στο παρελθόν έχει προκαλέσει την κατάρρευση της ιστοσελίδας.

Η μονάδα μέτρησης είναι τα 100 μέτρα, αλλά μπορείς να την αγνοήσεις σε αυτές τις εργασίες.

## 1. Όρισε ένα σημείο

Όρισε μια `struct` που θα περιέχει τις συντεταγμένες `x` και `y`.
Είναι αρκετά μικροί μη αρνητικοί ακέραιοι, οπότε χρησιμοποίησε τον τύπο `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Όρισε ένα Plot

Επειδή όλα τα οικόπεδα πρέπει να είναι ορθογώνια, με οριζόντιες και κάθετες πλευρές, χρειάζονται μόνο δύο απέναντι γωνίες για να οριστούν.

Υλοποίησε τη `struct` `Plot`, που παίρνει δύο struct `Coord` στον κατασκευαστή της.

Η `Plot` πρέπει να είναι μια `struct` με λέξεις-κλειδιά, με πεδία `bottom_left` και `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Έλεγξε αν η διεκδίκησή σου έχει ήδη καταχωριστεί

Υπάρχει ανταγωνισμός για αυτές τις διεκδικήσεις, οπότε πριν εγκριθεί η διεκδίκησή σου, θα ελεγχθεί ως προς τις υπάρχουσες διεκδικήσεις στο μητρώο.

Υλοποίησε τη συνάρτηση `is_claim_staked()` για να διαπιστώσεις αν μια διεκδίκηση έχει ήδη κατατεθεί.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Οι κερδοσκόποι μπορούν να διεκδικήσουν οικόπεδο καθορίζοντας τις συντεταγμένες των γωνιών του

Υλοποίησε τη συνάρτηση μετάλλαξης `stake_claim!()` για να μπορεί να καταχωριστεί μια διεκδίκηση.

Αν η ίδια διεκδίκηση έχει ήδη κατατεθεί, επέστρεψε `false`.

Αν μια νέα διεκδίκηση είναι εφικτή, πρόσθεσέ την στο μητρώο και επέστρεψε `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Βρες το μήκος της μεγαλύτερης πλευράς ενός οικοπέδου.

Υλοποίησε τη συνάρτηση `get_longest_side()` για να πάρεις τη μεγαλύτερη πλευρά (οριζόντια ή κάθετη) μιας διεκδίκησης.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Βρες το οικόπεδο που διεκδικήθηκε και έχει τη μεγαλύτερη πλευρά, για ερευνητικούς σκοπούς

Υλοποίησε τη συνάρτηση `get_claim_with_longest_side()` για να εξετάσεις όλες τις καταχωρισμένες διεκδικήσεις και να επιστρέψεις τη/τις διεκδίκηση/-εις με τη μεγαλύτερη πλευρά.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Επέστρεψε το/τα Plot ως `Set`, με ένα στοιχείο αν υπάρχει ένα μόνο οικόπεδο με τη μεγαλύτερη πλευρά, ή πολλά σε περίπτωση ισοπαλίας.
