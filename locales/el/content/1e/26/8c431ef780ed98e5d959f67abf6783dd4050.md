# Υποδείξεις

## Γενικά

- Πρέπει να κάνεις τις συναρτήσεις [ορατές σε άλλα αρχεία][global].
- Η [τεκμηρίωση του NASM][interfacing] περιγράφει πώς περνιούνται τα ορίσματα των συναρτήσεων και πώς ανακτώνται οι τιμές επιστροφής.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να κάνεις τις συναρτήσεις [ορατές σε άλλα αρχεία][global].
- Η [τεκμηρίωση του NASM][interfacing] περιγράφει πώς περνιούνται τα ορίσματα των συναρτήσεων και πώς ανακτώνται οι τιμές επιστροφής.
- Υπάρχει μια [εντολή][mov] για να αποθηκεύσεις μια τιμή σε έναν καταχωρητή.
- Μπορείς να ορίσεις σταθερές σε χρόνο assembly χρησιμοποιώντας το `equ`.

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να κάνεις τις συναρτήσεις [ορατές σε άλλα αρχεία][global].
- Η [τεκμηρίωση του NASM][interfacing] περιγράφει πώς περνιούνται τα ορίσματα των συναρτήσεων και πώς ανακτώνται οι τιμές επιστροφής.
- Μπορείς να [καλέσεις][call] μία από τις άλλες συναρτήσεις που όρισες προηγουμένως.
- Υπάρχει μια [εντολή][sub] για την αφαίρεση τιμών.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να κάνεις τις συναρτήσεις [ορατές σε άλλα αρχεία][global].
- Η [τεκμηρίωση του NASM][interfacing] περιγράφει πώς περνιούνται τα ορίσματα των συναρτήσεων και πώς ανακτώνται οι τιμές επιστροφής.
- Υπάρχει μια [εντολή][imul] για τον πολλαπλασιασμό τιμών.

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

- Πρέπει να κάνεις τις συναρτήσεις [ορατές σε άλλα αρχεία][global].
- Η [τεκμηρίωση του NASM][interfacing] περιγράφει πώς περνιούνται τα ορίσματα των συναρτήσεων και πώς ανακτώνται οι τιμές επιστροφής.
- Μπορείς να [καλέσεις][call] μία από τις άλλες συναρτήσεις που όρισες προηγουμένως.
- Υπάρχει μια [εντολή][add] για την πρόσθεση τιμών.
