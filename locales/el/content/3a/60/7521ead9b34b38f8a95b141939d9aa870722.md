# Εισαγωγή

## Ο τριαδικός τελεστής

Η τριαδική συνθήκη είναι ένας πιο σύντομος τρόπος να γράψεις απλές εντολές `if/else`.
Αν μια εντολή `if/else` περιέχει μόνο δύο κλάδους, έναν για όταν η συνθήκη είναι αληθής και έναν για όταν είναι ψευδής, μπορεί να ξαναγραφτεί ως τριαδική συνθήκη.

Οι τριαδικές συνθήκες χρησιμοποιούν έναν συνδυασμό των συμβόλων `?` και `:` για να χωρίσουν μια συνθήκη:

```ruby
condition ? true_branch : false_branch
```

Ο κώδικας στην αριστερή πλευρά του `?` είναι η συνθήκη και ο κώδικας στα δεξιά του περιέχει τους δύο πιθανούς κλάδους, χωρισμένους με το `:`.
Αν η συνθήκη είναι _αληθής_, εκτελείται ο κώδικας στην _αριστερή_ πλευρά του `:`.
Αν η συνθήκη είναι _ψευδής_, τότε εκτελείται ο κώδικας στα _δεξιά_ του `:`.

Για παράδειγμα:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

μπορεί να ξαναγραφτεί ως:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
