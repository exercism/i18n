# Εισαγωγή

Αντλίες, βαλβίδες, σωλήνες, ό,τι κρατάει έναν πόρο του λειτουργικού
συστήματος (ένα ανοιχτό αρχείο, μια σύνδεση δικτύου) πρέπει να *απελευθερώνεται*
όταν τελειώσεις μαζί του. Το vocab [`destructors`][destructors] της Factor
τα τυλίγει σε ένα framework που εγγυάται τον καθαρισμό, ακόμα κι όταν ένα σφάλμα
διακόψει τον κώδικά σου στη μέση.

## Η κλάση και το generic

Μια κλάση μπαίνει στο framework επεκτείνοντας το `disposable` και
υλοποιώντας το generic `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

Το `new-disposable ( class -- obj )` δεσμεύει το tuple *και* το
καταχωρεί στο framework. Μια εξαίρεση ανάμεσα στη δέσμευση και στο
επόμενο ασφαλές σημείο δεν μπορεί να αφήσει τον πόρο να διαρρεύσει. Το
framework εγγυάται ότι το `dispose*` εκτελείται **το πολύ μία φορά** ανά
αντικείμενο. Οι επαναλαμβανόμενες κλήσεις του `dispose` δεν κάνουν τίποτα.

## Οι εξωτερικοί καλούντες χρησιμοποιούν το `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

Το `with-disposal` είναι η μορφή για έναν μόνο πόρο: βάζει το
disposable για το εσωτερικό quotation και το απελευθερώνει στην έξοδο.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Για περισσότερους από έναν πόρους, άνοιξε ένα scope `with-destructors` και
καταχώρισε κάθε απόκτηση. Το `&dispose` (ampersand) σημαίνει "πάντα
dispose στην έξοδο, είτε επιτυχία είτε αποτυχία". Το `|dispose` (pipe)
σημαίνει "dispose **μόνο** σε περίπτωση αποτυχίας". Είναι χρήσιμο όταν το
μονοπάτι της επιτυχίας παραδίδει τον πόρο σε έναν καλούντα που θα αναλάβει
την ιδιοκτησία.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Για ένα σκέτο try/finally χωρίς μητρώο, το [`cleanup`][cleanup]
(στο `continuations`) είναι ο χαμηλότερου επιπέδου μηχανισμός, αλλά
το `with-destructors` είναι ο ιδιωματικός σύγχρονος τρόπος στη Factor.

[cleanup]: https://docs.factorcode.org/content/word-cleanup%2Ccontinuations.html
