# Εισαγωγή

Σε καταστάσεις ευαίσθητες ως προς την ασφάλεια (ή ακόμα και απλώς σε μια μεγάλη βάση κώδικα, όπου οι προγραμματιστές έχουν διαφορετικές προτεραιότητες και επιδιώξεις), θα πρέπει να αποφεύγεις να επιτρέπεις να παρακαμφθεί το δημόσιο API μιας κλάσης, δεχόμενος και αποθηκεύοντας τις μεταβλητές παραμέτρους μιας μεθόδου ή εκθέτοντας ένα μεταβλητό μέλος μιας κλάσης μέσω μιας τιμής επιστροφής ή ως παράμετρο `out`.
