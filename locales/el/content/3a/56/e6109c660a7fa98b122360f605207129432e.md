# Υποδείξεις

## Γενικά

- Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, συγκεντρώσου απλώς στο να συνδυάσεις τα ορίσματα ώστε να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο pac-man μπορεί να φάει ένα φάντασμα

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή [bool][bool].
- Μπορείς να χρησιμοποιήσεις τον τελεστή [bool][bool] `&&` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 2. Όρισε αν ο pac-man σκοράρει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή [bool][bool].
- Μπορείς να χρησιμοποιήσεις τον τελεστή [bool][bool] `||` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 3. Όρισε αν ο pac-man χάνει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή [bool][bool].
- Μπορείς να χρησιμοποιήσεις τους τελεστές [bool][bool] `&&` και `!` για να συνδυάσεις τα ορίσματα και να πάρεις ένα αποτέλεσμα.

## 4. Όρισε αν ο pac-man κερδίζει

- Η συνάρτηση πρέπει να επιστρέφει μια τιμή [bool][bool].
- Μπορείς να χρησιμοποιήσεις τους τελεστές [bool][bool] `&&` και `!` για να συνδυάσεις τα ορίσματα και τα αποτελέσματα μιας από τις συναρτήσεις που έχεις υλοποιήσει προηγουμένως.

[bool]: https://gleam.run/book/tour/bools.html
