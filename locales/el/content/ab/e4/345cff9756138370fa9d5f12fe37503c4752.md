# Προσάρτημα οδηγιών

## Ειδικές οδηγίες για το track

Για κάτι λίγο διαφορετικό, μπορείς επίσης να δοκιμάσεις μια λύση με συνάρτηση `unfold`.
Πιθανότατα γνωρίζεις ήδη τις `foldLeft/Right`: "map" μια ολόκληρη συλλογή σε κάτι άλλο (συνήθως σε κάτι που δεν είναι συλλογή).
Το `unfold` είναι η "αντίστροφη" πράξη: "map" κάτι (συνήθως κάτι που δεν είναι συλλογή) σε μια συλλογή.
Έτσι, το `unfold` είναι μια λογική προσθήκη στο καθιερωμένο ρεπερτόριο του συναρτησιακού προγραμματισμού και μέρος του.

Αυτή η άσκηση μπορεί να ιδωθεί ως μια περίπτωση για `unfold`: "map" ένα `Int` σε ένα `String` (το οποίο φυσικά είναι έμμεσα ένα `Seq[Char]`).

Οι συλλογές της Scala το διαθέτουν από την έκδοση 2.13, για παράδειγμα η [`List.unfold`][list] και η `Iterator.unfold`.
Παίρνει μια αρχική κατάσταση και μια συνάρτηση που επιστρέφει το επόμενο στοιχείο και την επόμενη κατάσταση, ή `None` για να σταματήσει:

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
