Γεια σε όλους,

Η ανταπόκριση στο #12in23 μας έχει αφήσει άφωνους. Χιλιάδες άνθρωποι ξεκίνησαν την πρόκληση και κάποιοι μάλιστα την έχουν ήδη ολοκληρώσει, που είναι ένα καταπληκτικό επίτευγμα!

Ήθελα να αφιερώσω λίγα λεπτά για να σου πω τι έχουμε σχεδιάσει για την υπόλοιπη χρονιά και να σου δώσω την ευκαιρία να συμμετάσχεις ακόμα περισσότερο!

Το πρώτο πράγμα που πρέπει να ξέρεις είναι ότι θα έχουμε ένα θέμα για κάθε μήνα, όπου σε ενθαρρύνουμε να εξερευνήσεις ένα συγκεκριμένο προγραμματιστικό παράδειγμα, ένα είδος προγραμματισμού, ίσως και μια συγκεκριμένη εποχή. Για παράδειγμα, να δοκιμάσεις πολύ παλιές ή πολύ καινούριες γλώσσες.

Κατά τη διάρκεια αυτού του μήνα θα κάνουμε streams με ανθρώπους να συζητούν για το θέμα του μήνα, να λύνουν ασκήσεις σε διάφορες γλώσσες που θα προβάλλουμε, και απλώς θα προσπαθούμε να σου φέρνουμε όσο το δυνατόν περισσότερο ενδιαφέρον και χρήσιμο περιεχόμενο! Αν θέλεις να συμμετάσχεις σε αυτό, επικοινώνησε μαζί μας. Δες τον σύνδεσμο στην περιγραφή.

Επίσης, πριν μπω στο πώς θα μοιάζει η χρονιά, κάνε εγγραφή στο κανάλι για να μη χάσεις κανένα από τα περιεχόμενα που θα κυκλοφορούμε μέσα στη χρονιά!

Ωραία! Έχουμε λοιπόν φτιάξει ένα ημερολόγιο που περιέχει κάθε μία από τις διαδρομές του Exercism. Κι αυτό δεν ήταν εύκολο κατόρθωμα! Θα σου εξηγήσω τι θα κάνουμε!

## Οι μήνες

Λοιπόν, πρώτα έχουμε τον Functional February, όπου εξερευνούμε συναρτησιακές γλώσσες! Μόλις ετοιμάσαμε το εισαγωγικό βίντεο γι' αυτόν και ανυπομονώ πραγματικά να το εξερευνήσω. Οι συναρτησιακές γλώσσες είναι εξαιρετικά ενδιαφέρουσες και διασκεδαστικές και σου μαθαίνουν πάρα πολλά. Υπάρχουν πολλές συναρτησιακές γλώσσες, αλλά αν δεν ξέρεις από πού να ξεκινήσεις, προτείνουμε συγκεκριμένα να δοκιμάσεις Elixir, F# ή Gleam.

Μετά έχουμε τον Mechanical March, όπου κοιτάμε γλώσσες πιο κοντά στον προγραμματισμό συστημάτων. Αυτές είναι γλώσσες όπως C++ ή Go ή Nim. Πράγματα που συνήθως μεταγλωττίζονται σε κώδικα μηχανής, μπορεί να έχουν διαχείριση μνήμης για να σκεφτείς, ή να σε κάνουν να αναλογιστείς πώς εκτελείται ο κώδικας. Γλώσσες που σε φέρνουν λίγο πιο κοντά στα ενδότερα του τι συμβαίνει στον υπολογιστή.

Για τον Analytical April εστιάζουμε σε πιο επιστημονικές γλώσσες. Οι δύο μεγάλες εδώ είναι η Python και η Julia, αλλά έχουμε και μια εξαιρετική διαδρομή R. Προφανώς κάτι σαν την Python χωράει σε πολλές κατηγορίες, αλλά πιστεύουμε ότι οι περισσότεροι από όσους δεν είναι αρχάριοι τη μαθαίνουν αυτή τη στιγμή για την αξία της ως τεχνολογίας επιστήμης δεδομένων, γι' αυτό τη βάλαμε εδώ!

Ο Μάιος θα είναι διασκεδαστικός και τον ονομάσαμε Mindshifting May! Ξεχωρίζουμε γλώσσες που κάνουν κάτι διαφορετικό. Το αγαπημένο μας παράδειγμα είναι η Prolog, ένας αρκετά ξεχωριστός τρόπος να προγραμματίζεις, αλλά θα δούμε επίσης Rust, TCL και Unison, μια πολύ νέα γλώσσα που ακολουθεί μια διαφορετική προσέγγιση στον κατανεμημένο προγραμματισμό και για την οποία είμαστε ενθουσιασμένοι και περίεργοι.

Πάμε στον Ιούνιο, όπου υιοθετούμε την οπτική του βόρειου ημισφαιρίου στο όνομα και τον λέμε Summer of Sexps. Θα εξερευνήσουμε γλώσσες που βασίζονται σε εκφράσεις, με έμφαση ειδικά σε Common Lisp και Clojure, δύο εξαιρετικές διαδρομές του Exercism! Αν δεν έχεις δοκιμάσει ποτέ Lisp, αυτός ο μήνας θα είναι πραγματικά διασκεδαστικός για σένα. Και αντί να φοβάσαι τις παρενθέσεις, θα αρχίσεις να τις εκτιμάς!

Καθώς μπαίνουμε στον Ιούλιο, πάμε στα παλιά για τον Jurassic July. Εξερευνούμε παλιές γλώσσες, εκείνες που έθεσαν τα θεμέλια του προγραμματισμού που ξέρουμε σήμερα. Σκέψου Fortran, COBOL, VB και C. Αν είσαι σχετικά νέος στον προγραμματισμό, μπορεί να σε γοητεύσει και να σε σοκάρει το πώς ήταν κάποτε ο προγραμματισμός!

Ο Αύγουστος είναι ένας μήνας με γλώσσες οικείες σε όλους, καθώς εστιάζουμε στο χτίσιμο ιστοσελίδων και εφαρμογών. Θα δούμε γλώσσες όπως JavaScript, Kotlin και Swift, αλλά και κάποιες λιγότερο διαδεδομένες, όπως η Dart. Θα δούμε επίσης γλώσσες όπως η ABAP, που χρησιμοποιούνται για πολύ συγκεκριμένους σκοπούς.

Ο Slimline September εστιάζει σε γλώσσες στις οποίες μπορείς να κάνεις πολλά πληκτρολογώντας πολύ λίγα. Τέτοιες γλώσσες που κάποιος μπορεί να χρησιμοποιήσει για code golf! Σκέψου Perl, AWK, JQ και Bash. Αυτές οι γλώσσες μπορεί να σου φανούν κάπως δυσνόητες την πρώτη φορά που θα τις χρησιμοποιήσεις, αλλά είναι εξαιρετικά ισχυροί τρόποι για να γίνεις παραγωγικός αν βάλεις τον κόπο να τις μάθεις. Και είναι επίσης διασκεδαστικές για να τις εξερευνήσει το μυαλό σου!

Ο μήνας 10 είναι ο Object Oriented October. Εξερευνούμε γλώσσες που εστιάζουν έντονα στον αντικειμενοστρεφή προγραμματισμό, όπως Ruby και C#, αλλά και λιγότερο γνωστές όπως Crystal και Pharo. Αν πάντα ήθελες να εμβαθύνεις στην εξερεύνηση του αντικειμενοστρεφούς προγραμματισμού, αυτός είναι ο μήνας για σένα!

Ο τελευταίος μας θεματικός μήνας είναι ο Nibbly November, αφιερωμένος στις γλώσσες του χαμηλότερου επιπέδου, όπου θα χειρίζεσαι bits και bytes. Εστιάζουμε σε δύο γλώσσες: τη x86-assembly, τη γλώσσα που πιθανότατα στηρίζει το hardware στο οποίο βλέπεις αυτό το βίντεο, και τη WebAssembly, τον νεοφερμένο της παρέας που σου επιτρέπει να τρέξεις οποιαδήποτε γλώσσα προγραμματισμού στον περιηγητή σου. Δεν θα είναι ένας εύκολος μήνας, αλλά ίσως είναι ο πιο ικανοποιητικός για να τα καταφέρεις!

Και φτάνουμε τέλος στον December Diversions. Αυτές είναι οι γλώσσες που δεν χώρεσαν πουθενά αλλού! Πράγματα όπως Groovy, Lua και Wren. Σκέψου το σαν έναν μήνα-μπαλαντέρ: μπορείς να διαλέξεις ό,τι θέλεις για να κλείσεις τη χρονιά με στυλ!

Αυτά λοιπόν: ένας χρόνος με νέες γλώσσες προγραμματισμού για να εξερευνήσεις και να διασκεδάσεις. Άφησε ένα σχόλιο στο βίντεο λέγοντάς μας τι ανυπομονείς να δοκιμάσεις! Και αν θέλεις να κάνεις stream λύνοντας ασκήσεις, επικοινώνησε μαζί μας και θα προσπαθήσουμε να διαδώσουμε αυτό που κάνεις, και ίσως σε προβάλουμε σε ένα από τα επίσημα κανάλια μας!

Ευχαριστούμε που το διάβασες :)
