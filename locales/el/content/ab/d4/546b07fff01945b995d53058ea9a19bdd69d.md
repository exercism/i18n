# Σχετικά

Η εργασία με συμβολοσειρές είναι μια συνηθισμένη εργασία στον προγραμματισμό.
Γι' αυτό η Swift παρέχει μια ποικιλία μεθόδων για τον χειρισμό συμβολοσειρών.
Σε αυτό το έγγραφο θα δούμε μερικές από τις πιο συνηθισμένες μεθόδους και ιδιότητες των συμβολοσειρών. Κάποιες από αυτές απαιτούν το import του framework Foundation.

## [`components(separatedBy:)`][components]

Όταν θέλεις να χωρίσεις μια συμβολοσειρά σε έναν πίνακα από υποσυμβολοσειρές, μπορείς να χρησιμοποιήσεις τη μέθοδο `components(separatedBy:)`.
Αν, λοιπόν, θέλεις να πάρεις κάθε λέξη μιας πρότασης, μπορείς να χρησιμοποιήσεις τον χαρακτήρα του κενού ως διαχωριστικό.

```swift
let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## [`hasPrefix(_:)`][hasPrefix], [`hasSuffix(_:)`][hasSuffix]

Όταν θέλεις να ελέγξεις αν μια συμβολοσειρά αρχίζει ή τελειώνει με μια συγκεκριμένη υποσυμβολοσειρά, μπορείς να χρησιμοποιήσεις τις μεθόδους `hasPrefix(_:)` και `hasSuffix(_:)`.
Και οι δύο αυτές μέθοδοι δέχονται μια συμβολοσειρά ως όρισμα και επιστρέφουν μια τιμή Boolean (λογική τιμή) που δείχνει αν η συμβολοσειρά αρχίζει ή τελειώνει με τη συγκεκριμένη υποσυμβολοσειρά.

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## [`lowercased`][lowercased], [`uppercased`][uppercased], [`capitalized`][capitalized]

Όταν θέλεις να αλλάξεις πεζά/κεφαλαία σε μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τις ιδιότητες `lowercased`, `uppercased` και `capitalized`.
Η ιδιότητα `lowercased` επιστρέφει μια νέα συμβολοσειρά όπου όλοι οι χαρακτήρες είναι πεζοί, η ιδιότητα `uppercased` επιστρέφει μια νέα συμβολοσειρά όπου όλοι οι χαρακτήρες είναι κεφαλαίοι, και η ιδιότητα `capitalized` επιστρέφει μια νέα συμβολοσειρά όπου ο πρώτος χαρακτήρας κάθε λέξης είναι κεφαλαίος.

```swift
let greeting = "hello, world!"
print(greeting.lowercased)  // Prints "hello, world!"
print(greeting.uppercased)  // Prints "HELLO, WORLD!"
print(greeting.capitalized) // Prints "Hello, World!"
```

## [`replacingOccurrences(of:with:)`][replacingOccurrences]

Όταν θέλεις να αντικαταστήσεις όλες τις εμφανίσεις μιας υποσυμβολοσειράς μέσα σε μια συμβολοσειρά με μια άλλη υποσυμβολοσειρά, μπορείς να χρησιμοποιήσεις τη μέθοδο `replacingOccurrences(of:with:)`.
Αυτή η μέθοδος δέχεται δύο συμβολοσειρές ως ορίσματα: την υποσυμβολοσειρά που θα αντικατασταθεί και την υποσυμβολοσειρά με την οποία θα αντικατασταθεί. Επιστρέφει μια νέα συμβολοσειρά όπου όλες οι εμφανίσεις της συγκεκριμένης υποσυμβολοσειράς έχουν αντικατασταθεί.

```swift
let greeting = "Hello, world!"
let newGreeting = greeting.replacingOccurrences(of: "world", with: "Swift")
print(newGreeting) // Prints "Hello, Swift!"
```

## [`joined(separator:)`][joined]

Αυτή δεν είναι μέθοδος του τύπου String, αλλά του τύπου Array.
Όταν θέλεις να ενώσεις έναν πίνακα από συμβολοσειρές σε μία μόνο συμβολοσειρά με έναν συγκεκριμένο διαχωριστικό, μπορείς να χρησιμοποιήσεις τη μέθοδο `joined(separator:)`.
Αυτή η μέθοδος δέχεται μια συμβολοσειρά ως όρισμα και επιστρέφει μια νέα συμβολοσειρά όπου όλα τα στοιχεία του πίνακα είναι ενωμένα μεταξύ τους, χωρισμένα με τη συγκεκριμένη συμβολοσειρά.

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
