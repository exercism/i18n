# Εισαγωγή

Στην JavaScript, η κλάση `Array` έχει πολλές ισχυρές ενσωματωμένες μεθόδους για μετασχηματισμό πινάκων.
Αυτές οι μέθοδοι κάνουν πολύ πιο εύκολη τη μετατροπή ενός πίνακα σε έναν άλλον απ' ό,τι θα ήταν με έναν απλό `for` βρόχο ή με πιο άμεσο χειρισμό.

Κάποιες μέθοδοι είναι [_καθαρές_][pure-function-definition], που σημαίνει ότι δεν τροποποιούν τον αρχικό πίνακα.
Αντ' αυτού, επιστρέφουν έναν νέο πίνακα.
Άλλες μέθοδοι, ωστόσο, τροποποιούν τον πίνακα στον οποίο καλούνται και **δεν** επιστρέφουν τον τροποποιημένο πίνακα.

Μερικές από τις πιο συχνά χρησιμοποιούμενες μεθόδους για μετασχηματισμό πινάκων παρουσιάζονται παρακάτω.
Μια πλήρης λίστα των διαθέσιμων μεθόδων υπάρχει στην [τεκμηρίωση του MDN][array-methods].

### map (καθαρή)

Δημιούργησε έναν νέο πίνακα μετασχηματίζοντας κάθε στοιχείο σύμφωνα με μια συνάρτηση που περνάς ως όρισμα.
Αυτές οι συναρτήσεις επανάκλησης γράφονται συχνά ως [συναρτήσεις βέλους][concept-arrow-functions].

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

Αξίζει να σημειωθεί ότι ο πίνακας που προκύπτει θα έχει πάντα το ίδιο μήκος με τον αρχικό.

### filter (καθαρή)

Δημιουργεί έναν πίνακα φιλτράροντας τον τρέχοντα, με δεδομένη μια συνάρτηση φιλτραρίσματος (που επιστρέφει την τιμή αληθής αν το στοιχείο πρέπει να διατηρηθεί και την τιμή ψευδής αν πρέπει να αφαιρεθεί).

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce (καθαρή)

Μειώνει τον πίνακα σε μία μόνο τιμή χρησιμοποιώντας μια συνάρτηση που παίρνει έναν _συσσωρευτή_ και το τρέχον στοιχείο του πίνακα ως παραμέτρους.
Αυτή η συνάρτηση καθορίζει πώς το τρέχον στοιχείο πρέπει να συγχωνευτεί στον συσσωρευτή και επιστρέφει τον συσσωρευτή που θα χρησιμοποιηθεί στην επόμενη επανάληψη.

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

Αντιστρέφει τα στοιχεία ενός πίνακα.

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

Αυτή η μέθοδος τροποποιεί τον πίνακα στον οποίο καλείται.

### slice (καθαρή)

Με δεδομένη μια αρχική και μια τελική θέση, δημιουργεί έναν υποπίνακα από τον πίνακα στον οποίο καλείται.

Το στοιχείο στην τελική θέση δε θα συμπεριληφθεί.
Επίσης, όλες οι παράμετροι είναι προαιρετικές:
η αρχική θέση έχει προεπιλεγμένη τιμή `0`, και η τελική θέση έχει προεπιλεγμένη τιμή το μήκος του πίνακα.

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

Αφαιρεί ή αντικαθιστά ή/και προσθέτει νέα στοιχεία ενός πίνακα.

Παίρνει τις εξής παραμέτρους:

- τη θέση του στοιχείου από όπου αρχίζει η τροποποίηση του πίνακα
- τον αριθμό των στοιχείων που θα διαγραφούν
- τα στοιχεία που θα εισαχθούν στον πίνακα (προαιρετικά)

Το `splice` επιστρέφει τα στοιχεία που αφαιρέθηκαν.

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

Από προεπιλογή, το `sort` ταξινομεί τα στοιχεία ενός πίνακα μετατρέποντάς τα πρώτα σε συμβολοσειρές και εφαρμόζοντας στη συνέχεια σύγκριση συμβολοσειρών (δες τη [Σύγκριση][concept-comparison]).
Η ταξινόμηση γίνεται _επιτόπου_, που σημαίνει ότι ο αρχικός πίνακας τροποποιείται.
Το `sort` επιστρέφει επίσης αυτόν τον τροποποιημένο πίνακα, κάτι που είναι βολικό αν θέλεις να αλυσιδώσεις άλλες μεθόδους πάνω του.

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

Για να προσαρμόσεις τη συμπεριφορά της ταξινόμησης, μπορείς να περάσεις μια συνάρτηση σύγκρισης ως όρισμα.
Η ίδια η συνάρτηση σύγκρισης καλείται με δύο ορίσματα, που είναι δύο στοιχεία του πίνακα.
Στη συνέχεια, πρέπει να επιστρέψει τα εξής:

- έναν αρνητικό αριθμό αν το πρώτο όρισμα πρέπει να ταξινομηθεί πριν από το δεύτερο
- έναν θετικό αριθμό αν το πρώτο όρισμα πρέπει να ταξινομηθεί μετά από το δεύτερο
- `0` αν η σειρά των στοιχείων πρέπει να παραμείνει ίδια

Για παράδειγμα, για να ταξινομήσεις αριθμούς μπορεί να χρησιμοποιηθεί η εξής συνάρτηση σύγκρισης.

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
