# Οδηγίες

Σε αυτή την άσκηση, θα δουλέψεις με λογαριασμούς ταμιευτηρίου.
Κάθε χρόνο, το υπόλοιπο του λογαριασμού ταμιευτηρίου σου ενημερώνεται με βάση το επιτόκιό του.
Το επιτόκιο που σου δίνει η τράπεζά σου εξαρτάται από το ποσό των χρημάτων στον λογαριασμό σου (το υπόλοιπό του):

- 3.213% για υπόλοιπο μικρότερο από `0` δολάρια (το υπόλοιπο γίνεται πιο αρνητικό).
- 0.5% για υπόλοιπο μεγαλύτερο ή ίσο με `0` δολάρια και μικρότερο από `1000` δολάρια.
- 1.621% για υπόλοιπο μεγαλύτερο ή ίσο με `1000` δολάρια και μικρότερο από `5000` δολάρια.
- 2.475% για υπόλοιπο μεγαλύτερο ή ίσο με `5000` δολάρια.

Έχεις τέσσερις εργασίες, καθεμία από τις οποίες ασχολείται με το υπόλοιπο και το επιτόκιό του.

## 1. Υπολόγισε το επιτόκιο

Υλοποίησε τη συνάρτηση `interest_rate` για να υπολογίσεις το επιτόκιο με βάση το δεδομένο υπόλοιπο:

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. Υπολόγισε τον τόκο

Υλοποίησε τη συνάρτηση `yearly_interest` για να υπολογίσεις τον τόκο με βάση το δεδομένο υπόλοιπο:

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

Υλοποίησε τη συνάρτηση `annual_balance_update` για να υπολογίσεις την ετήσια ενημέρωση του υπολοίπου, λαμβάνοντας υπόψη το επιτόκιο:

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

Υλοποίησε τη συνάρτηση `years_until_desired_balance` για να υπολογίσεις τον ελάχιστο αριθμό ετών που χρειάζονται για να φτάσεις στο επιθυμητό υπόλοιπο, λαμβάνοντας υπόψη ότι κάθε χρόνο ο τόκος προστίθεται στο υπόλοιπο.
Αυτό σημαίνει ότι το υπόλοιπο μετά από ένα χρόνο είναι: αρχικό υπόλοιπο + τόκος για το αρχικό υπόλοιπο.
Το υπόλοιπο μετά τον δεύτερο χρόνο είναι το υπόλοιπο μετά τον ένα χρόνο + τόκος για το υπόλοιπο μετά τον ένα χρόνο.
Και ούτω καθεξής, μέχρι το υπόλοιπο του τρέχοντος έτους να είναι μεγαλύτερο ή ίσο με το υπόλοιπο-στόχο.

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

Σημείωσε ότι η τιμή που επιστρέφεται είναι `int`.
