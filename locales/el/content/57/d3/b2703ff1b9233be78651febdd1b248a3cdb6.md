# Παράρτημα οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να υλοποιήσεις τη συνάρτηση `numerals`,
που *ίσως* μετατρέπει έναν αριθμό σε μια *συμβολοσειρά* που αναπαριστά έναν ρωμαϊκό αριθμό.

Η συνάρτησή σου αναμένεται να μετατρέπει, τουλάχιστον, αριθμούς μέχρι το 3000,
αλλά από εσένα εξαρτάται να αποφασίσεις πόσο μακριά θέλεις να φτάσεις.
