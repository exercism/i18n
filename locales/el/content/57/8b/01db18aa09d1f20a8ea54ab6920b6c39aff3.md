# Οδηγίες

Ο Lamont είναι ένας εξωγήινος από τη Lisp που θέλει να γράψει το δικό του βιντεοπαιχνίδι. Ένα από τα πράγματα για τα οποία σου ζήτησε βοήθεια είναι να κρατάς μια λίστα με τις υψηλές βαθμολογίες.

## 1. Δημιουργία του πίνακα υψηλών βαθμολογιών

Όρισε μια συνάρτηση `make-high-score-table` που δεν παίρνει κανένα όρισμα και αποτιμάται σε έναν νέο κενό πίνακα κατακερματισμού:

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. Προσθήκη παίκτη στον πίνακα

Για να προσθέσεις έναν παίκτη στον πίνακα, όρισε μια συνάρτηση `add-player` που παίρνει δύο ορίσματα:
- τον πίνακα υψηλών βαθμολογιών
- το όνομα του παίκτη ως λέξη-κλειδί

Όρισε την αρχική βαθμολογία του παίκτη σε μηδέν.

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. Ορισμός της βαθμολογίας ενός παίκτη

Για να ορίσεις τη βαθμολογία ενός παίκτη, όρισε μια συνάρτηση `set-score` που παίρνει τρία ορίσματα:
- τον πίνακα υψηλών βαθμολογιών
- το όνομα του παίκτη ως λέξη-κλειδί
- τη βαθμολογία του παίκτη ως ακέραιο

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. Ανάκτηση βαθμολογίας από τον πίνακα

Για να πάρεις τη βαθμολογία ενός παίκτη από τον πίνακα, όρισε μια συνάρτηση `get-score` που παίρνει δύο ορίσματα:
- τον πίνακα υψηλών βαθμολογιών
- το όνομα του παίκτη ως λέξη-κλειδί

Αυτή η συνάρτηση θα πρέπει να αποτιμάται στη βαθμολογία που είναι αποθηκευμένη για τον παίκτη.
Αν δεν υπάρχει αποθηκευμένη βαθμολογία για αυτόν τον παίκτη ή ο παίκτης δε βρίσκεται ακόμα στον πίνακα, τότε να αποτιμάται σε `0`.

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. Αφαίρεση παίκτη από τον πίνακα

Για να αφαιρέσεις έναν παίκτη από τον πίνακα υψηλών βαθμολογιών, όρισε μια συνάρτηση `remove-player` που παίρνει δύο ορίσματα:
- τον πίνακα υψηλών βαθμολογιών
- το όνομα του παίκτη ως λέξη-κλειδί

Αυτή η συνάρτηση θα πρέπει να χειρίζεται ομαλά τις περιπτώσεις όπου ο παίκτης δεν έχει προστεθεί ακόμα στον πίνακα.
Προφανώς, αφού αφαιρεθεί ένας παίκτης, αν πάρεις τη βαθμολογία του από τον πίνακα, θα είναι μηδέν.

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
