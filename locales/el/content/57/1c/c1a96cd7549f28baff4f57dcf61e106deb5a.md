# απόφυγε τους βρόχους

Αντί να χρησιμοποιήσεις έναν βρόχο, σκέψου να χρησιμοποιήσεις μία μόνο έκφραση βασισμένη σε έναν από τους τελεστές σύγκρισης (δηλαδή `<=`, `>=`, `<`, `>`, κ.λπ.).
Μπορείς να ξαναχρησιμοποιήσεις τις άλλες μεθόδους που έχουν ήδη υλοποιηθεί στην κλάση ή να προσθέσεις νέες, αν χρειάζεται.
