# Εισαγωγή

Το `OpenStruct` σου επιτρέπει να δημιουργήσεις εύκολα ένα αντικείμενο από ένα `Hash`.
Αντί να χρειάζεται να έχεις πρόσβαση μέσω των κλειδιών του `Hash`, το `OpenStruct` μάς επιτρέπει να χρησιμοποιούμε μεθόδους για να προσπελαύνουμε και να ορίζουμε τιμές.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Ένα επιπλέον πλεονέκτημα αυτής της προσέγγισης είναι ότι μπορούμε να εκμεταλλευτούμε μια συντόμευση όταν χρησιμοποιούμε σύνταξη μπλοκ.
Σε περιπτώσεις όπου ένα μπλοκ καλεί μία μόνο μέθοδο, μπορείς να αντικαταστήσεις το μπλοκ με `&:` ακολουθούμενο από το όνομα της μεθόδου.
Για παράδειγμα, αυτές οι δύο γραμμές είναι συνώνυμες:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Standard Library

Όλες οι κλάσεις που έχεις δει σε προηγούμενες ασκήσεις ήταν μέρος της Core Library της Ruby.

Το OpenStruct είναι μέρος της Standard Library της Ruby (συχνά συντομεύεται σε "stdlib"), μιας συλλογής κλάσεων για την εργασία με πράγματα όπως ημερομηνίες, json και δικτύωση.
Παρέχει επίσης χρήσιμες λειτουργίες που κάνουν τον κώδικά σου πιο εύκολο στη χρήση.

Όταν χρησιμοποιείς κλάσεις που δεν προέρχονται από την Core Library (τον δικό σου κώδικα σε διαφορετικά αρχεία, κλάσεις από τη stdlib ή εξωτερικές εξαρτήσεις), πρέπει να τις εισάγουμε με τη μέθοδο `require` πριν μπορέσουμε να τις χρησιμοποιήσουμε.
Για παράδειγμα:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
