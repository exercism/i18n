# Χάρτες και Σύνολα

Ένας πίνακας κρατά τιμές σε αριθμημένες θέσεις. Μερικές φορές η χρήσιμη ετικέτα δεν είναι ένας αριθμός.

## Χάρτες

Ένας **χάρτης** συνδυάζει κάθε **κλειδί** με έναν **στόχο**. Αναζήτησε κάτι με το κλειδί του και ο χάρτης σου δίνει αυτό που έχει καταχωρηθεί κάτω από αυτό.

Το `FMAP{K,T}` είναι ένας χάρτης από κλειδιά τύπου `K` σε στόχους τύπου `T`. Ένα guide που συνδυάζει το όνομα ενός ζώου με τον τόπο όπου ζει είναι `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Πάντα να εκχωρείς την απάντηση πίσω

Κοίτα ξανά τη μεσαία γραμμή. Το `insert` απαντά με τον χάρτη που περιέχει το επιπλέον ζεύγος, και η απάντηση πρέπει να κρατηθεί:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Ισχύει ο ίδιος κανόνας όπως με το `FSTR`, και για τον ίδιο λόγο. Η απάντηση είναι συνήθως ο ίδιος ο χάρτης που μπήκε, αλλαγμένος επιτόπου. Περιστασιακά, όταν ο χάρτης έχει γεμίσει, είναι ένας μεγαλύτερος. Επειδή δεν μπορείς να ξέρεις ποιο από τα δύο ισχύει, **χρησιμοποίησε την απάντηση και σταμάτα να χρησιμοποιείς το παλιό όνομα.** Ένα όνομα που έχει απομείνει από πριν από ένα `insert` μπορεί να είναι ξεπερασμένο ή να μην περιγράφει καθόλου έναν χάρτη που μπορείς να χρησιμοποιήσεις.

Αυτό σημαίνει επίσης ότι ένας χάρτης που δίνεται σε μια υπορουτίνα δεν είναι ασφαλής από αυτήν. Αν το αρχικό πρέπει να διατηρηθεί, δες το `copy` στη σελίδα της έννοιας.

## Υπάρχει;

Το `has_ind` ρωτά αν ένα κλειδί βρίσκεται μέσα στον χάρτη. Το όνομα είναι σύντμηση του "has index": η θέση δεν είναι τίποτε άλλο από αυτό που αυτοί οι χάρτες ονομάζουν κλειδί.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Το να ζητήσεις ένα κλειδί που δεν υπάρχει **δεν** προκαλεί κανένα παράπονο. Το `get` σου δίνει πίσω την κενή τιμή για τον τύπο: μηδέν για ένα `INT` και void για ένα `STR`, το οποίο θα πάει στραβά αργότερα και κάπου αλλού. Γι' αυτό, κοίταξε πρώτα και μετά ζήτα την τιμή:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Σύνολα

Ένα **σύνολο** κρατά τιμές χωρίς διπλότυπα και χωρίς σειρά. Το `FSET{T}` είναι ένα σύνολο τιμών τύπου `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Η εισαγωγή του ίδιου στοιχείου δύο φορές αφήνει ένα μόνο αντίγραφο. Γι' αυτό υπάρχει το σύνολο: για να συλλέγεις πράγματα ξεχνώντας πόσο συχνά εμφανίστηκε το καθένα.

Το `insert` σε ένα σύνολο απαντά με το σύνολο που θα χρησιμοποιείς από εκεί και πέρα, ακριβώς όπως κάνει και για έναν χάρτη, οπότε να το εκχωρείς πίσω κάθε φορά.

## Πόσα

Το `.size` λειτουργεί και στα δύο: πόσα ζεύγη κρατά ένας χάρτης και πόσες τιμές υπάρχουν σε ένα σύνολο.
