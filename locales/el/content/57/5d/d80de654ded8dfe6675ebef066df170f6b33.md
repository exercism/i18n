# Εισαγωγή

Στη Rust, κάθε τύπος που υλοποιεί το trait [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) μπορεί να αντιμετωπιστεί ως iterator.
Οι ενσωματωμένες [`collections`](https://doc.rust-lang.org/std/collections/index.html) της Rust μπορούν να μετατραπούν σε iterators μέσω των μεθόδων `iter`, `iter_mut` και `into_iter`.
Οι iterators διαθέτουν μια μεγάλη γκάμα από [ισχυρές μεθόδους](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods), όπως οι `collect`, `map`, `filter` και `fold`, για να εκτελείς πράξεις στα δεδομένα σου.

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
