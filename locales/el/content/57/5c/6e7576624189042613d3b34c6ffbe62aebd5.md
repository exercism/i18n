# Συμβουλές

## Γενικά

- [Υπερφόρτωση μεθόδων στη C#][member-overloading].
- Η [παρεμβολή συμβολοσειρών][string-interpolation] μπορεί να χρησιμοποιηθεί για τη μορφοποίηση συμβολοσειρών περιγραφής.

## 3. Περίγραψε τον τρόπο ταξιδιού

- Μπορείς να χρησιμοποιήσεις μια [απλή εντολή `if`][if-statement] για τη λογική της συνθήκης.

## 4. Περίγραψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό

- Μπορείς να ξαναχρησιμοποιήσεις τη λειτουργικότητα περιγραφής που υπάρχει ήδη.
- Μπορείς να χρησιμοποιήσεις [εκφράσεις μέσα σε συμβολοσειρές με παρεμβολή][string-interpolation-expressions], που σημαίνει ότι μπορείς να καλέσεις μεθόδους απευθείας στα σημεία παρεμβολής μιας συμβολοσειράς με παρεμβολή.

## 5. Περίγραψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό χωρίς να ορίσεις τον τρόπο ταξιδιού

- Μπορείς να ξαναχρησιμοποιήσεις τη λειτουργικότητα που υπάρχει ήδη και που παίρνει ρητά έναν τρόπο ταξιδιού.
- Μπορείς να χρησιμοποιήσεις [προαιρετικές παραμέτρους][optional-arguments] για να μειώσεις τον κώδικα που χρειάζεσαι.
