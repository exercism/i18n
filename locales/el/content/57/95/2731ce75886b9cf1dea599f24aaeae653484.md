# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                   |
| -------- | --------- | ------- | --------------------------- |
| `$a0`    | είσοδος   | διεύθυνση | πίνακας από λέξεις βιβλίων  |
| `$a1`    | είσοδος   | ακέραιος | αριθμός βιβλίων             |
| `$v0`    | έξοδος    | ακέραιος | τιμή, σε σεντς              |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
