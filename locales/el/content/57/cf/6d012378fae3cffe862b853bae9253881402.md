# Εγκατάσταση της Java

Εκτός από το Exercism CLI και τον αγαπημένο σου επεξεργαστή κειμένου, για να κάνεις εξάσκηση με τις ασκήσεις Java του Exercism χρειάζεσαι το **Java Development Kit** (JDK).
Το JDK περιλαμβάνει τόσο ένα Java Runtime _και_ εργαλεία ανάπτυξης (κυρίως τον μεταγλωττιστή Java).

Σήμερα υπάρχουν πολλές παραλλαγές του JDK, μερικές από τις οποίες είναι ανοιχτού κώδικα.
Εδώ στο Exercism σου προτείνουμε να χρησιμοποιήσεις το [Eclipse Temurin της Adoptium][adoptium].

## Υποστηριζόμενες εκδόσεις Java

Το track Java του Exercism υποστηρίζει την Java 25 LTS και παλαιότερες εκδόσεις.

## Εγκατάσταση του Eclipse Temurin

Για να εγκαταστήσεις το Eclipse Temurin στο σύστημά σου, πήγαινε στις εξαιρετικές [οδηγίες εγκατάστασης][adoptium-installation-guide] που έχουν.
Εκεί θα βρεις οδηγίες για το πώς να εγκαταστήσεις το JDK χρησιμοποιώντας τον αγαπημένο σου διαχειριστή πακέτων,
καθώς και συνδέσμους για λήψη προγραμμάτων εγκατάστασης για όλα τα δημοφιλή λειτουργικά συστήματα.

## IDE για Java

Υπάρχουν πολλά δωρεάν IDE διαθέσιμα για Java.
Ορίστε μερικές δημοφιλείς επιλογές:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code με την επέκταση για Java][vscode-java]
