# Σχετικά

## Πολλαπλές τιμές επιστροφής

Μπορούν να επιστραφούν [πολλαπλές τιμές][multiple-return-values] από τις συναρτήσεις στη Swift, δημιουργώντας και επιστρέφοντας μια πλειάδα από τις διαφορετικές τιμές.

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  return (reverse: str.reverse, length: str.count)
}

reverseAndLength("Hello")
// => (reverse: "olleH", length: 5)
```

## Παράλειψη του `return`

```swift
func reverseAndLength(_ str: String) -> (reverse: String, length: Int) {
  (reverse: str.reverse, length: str.count)
}
```

Σε περιπτώσεις όπου ολόκληρο το σώμα μιας συνάρτησης είναι μία μόνο έκφραση, μπορεί να παραλειφθεί [η λέξη-κλειδί `return`][implicit-returns].

Σημείωσε ότι αυτό ισχύει για όλους τους τύπους επιστροφής, όχι μόνο για τις πολλαπλές τιμές επιστροφής.

[multiple-return-values]: https://docs.swift.org/swift-book/LanguageGuide/Functions.html#ID164
