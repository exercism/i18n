# Προσθήκη στις οδηγίες

## Μορφή εξόδου

Δώσε τον ρόμβο ως συμβολοσειρά τερματιζόμενη με null, με έναν χαρακτήρα αλλαγής γραμμής στο τέλος κάθε γραμμής.

Ένα παράδειγμα εξόδου θα ήταν `"  A  \n B B \nC   C\n B B \n  A  \n"`

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | είσοδος        | byte    | γράμμα                        |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος τερματιζόμενη με null |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | για προσωρινή αποθήκευση         |
