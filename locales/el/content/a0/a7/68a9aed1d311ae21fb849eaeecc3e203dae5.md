# Υποδείξεις

## 1. Χώρισε μια συμβολοσειρά σε μεμονωμένες γραμμές

- Η Swift έχει μια [μέθοδο][nsstring-components-docs] για να χωρίζεις μια συμβολοσειρά σε έναν πίνακα από συμβολοσειρές χρησιμοποιώντας έναν διαχωριστή που της δίνεις.

## 2. Μπροστινή πόρτα

- Ο φρουρός θα απαγγείλει ένα ποίημα και θα πρέπει να χωρίσεις το ποίημα σε μεμονωμένες γραμμές, οπότε μπορείς να χρησιμοποιήσεις μια συνάρτηση που υπάρχει ήδη.
- Μπορείς να χρησιμοποιήσεις έναν `for` βρόχο για να διατρέξεις τις γραμμές του ποιήματος.
- Μπορείς να χρησιμοποιήσεις την ιδιότητα `first` μιας συμβολοσειράς για να πάρεις τον πρώτο χαρακτήρα της.
- Για να αποθηκεύσεις τον πρώτο χαρακτήρα κάθε γραμμής, μπορείς να χρησιμοποιήσεις έναν πίνακα από χαρακτήρες ή μια συμβολοσειρά.

## 3. Πίσω πόρτα

- Ο φρουρός θα απαγγείλει ένα ποίημα και θα πρέπει να χωρίσεις το ποίημα σε μεμονωμένες γραμμές, οπότε μπορείς να χρησιμοποιήσεις μια συνάρτηση που υπάρχει ήδη.
- Μπορείς να χρησιμοποιήσεις έναν `for` βρόχο για να διατρέξεις τις γραμμές του ποιήματος.
- Μπορείς να χρησιμοποιήσεις την ιδιότητα `last` μιας συμβολοσειράς για να πάρεις τον τελευταίο χαρακτήρα της.
- Για να αποθηκεύσεις τον τελευταίο χαρακτήρα κάθε γραμμής, μπορείς να χρησιμοποιήσεις έναν πίνακα από χαρακτήρες ή μια συμβολοσειρά.

## 4. Μυστικό δωμάτιο

- Ο φρουρός θα απαγγείλει ένα ποίημα και θα πρέπει να χωρίσεις το ποίημα σε μεμονωμένες γραμμές, οπότε μπορείς να χρησιμοποιήσεις μια συνάρτηση που υπάρχει ήδη.
- Μπορείς να χρησιμοποιήσεις έναν `for` βρόχο που διατρέχει το μήκος των γραμμών του ποιήματος.
- Η Swift έχει μια [μέθοδο][indexing] για να παίρνεις τον χαρακτήρα σε μια συγκεκριμένη θέση μέσα σε μια συμβολοσειρά.
- Η Swift έχει μια [μέθοδο][uppercased] για να μετατρέπεις μια συμβολοσειρά σε κεφαλαία γράμματα.
