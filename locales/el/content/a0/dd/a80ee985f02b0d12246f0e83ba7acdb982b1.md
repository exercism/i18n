# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που καταγράφει πόσα πουλιά έχουν επισκεφθεί τον κήπο σου.
Συνήθως κρατάς μια καταμέτρηση σε ένα τετράδιο για να μετράς τα πουλιά, αλλά θέλεις να δουλέψεις καλύτερα με τα δεδομένα σου.
Έχεις ήδη ψηφιοποιήσει τις ημερήσιες καταγραφές πουλιών των τελευταίων εβδομάδων που κρατούσες στο τετράδιο.

Τώρα θέλεις να προσδιορίσεις τον συνολικό αριθμό των πουλιών που μέτρησες, να υπολογίσεις τον αριθμό των πουλιών για μια συγκεκριμένη εβδομάδα και να διορθώσεις ένα λάθος στην καταμέτρηση.

## 1. Προσδιόρισε τον συνολικό αριθμό των πουλιών που έχεις μετρήσει μέχρι τώρα

Ας ξεκινήσουμε την ανάλυση των δεδομένων αποκτώντας μια γενική εικόνα.
Βρες πόσα πουλιά μέτρησες συνολικά από τότε που ξεκίνησες τις καταγραφές σου.

Υλοποίησε μια συνάρτηση `totalBirdCount` που δέχεται ένα αντικείμενο τύπου πίνακα που περιέχει τον αριθμό των πουλιών ανά ημέρα.
Θα πρέπει να επιστρέφει τον συνολικό αριθμό των πουλιών που μέτρησες.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Υπολόγισε τον αριθμό των πουλιών που επισκέφθηκαν τον κήπο σε μια συγκεκριμένη εβδομάδα

Τώρα που απέκτησες μια γενική αίσθηση των αριθμών καταγραφής πουλιών σου, θέλεις να κάνεις μια πιο λεπτομερή ανάλυση.

Υλοποίησε μια συνάρτηση `birdsInWeek` που δέχεται ένα αντικείμενο τύπου πίνακα με τους αριθμούς πουλιών ανά ημέρα και έναν αριθμό εβδομάδας.
Επιστρέφει τον συνολικό αριθμό των πουλιών που μέτρησες σε αυτή τη συγκεκριμένη εβδομάδα.
Μπορείς να υποθέσεις ότι οι εβδομάδες καταγράφονται πάντα ολοκληρωμένες.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Διόρθωσε ένα λάθος στην καταμέτρηση

Συνειδητοποίησες ότι όλον αυτόν τον καιρό που προσπαθούσες να παρακολουθείς τα πουλιά, υπήρχε ένα που κρυβόταν σε μια μακρινή γωνιά του κήπου.
Κατάλαβες ότι αυτό το πουλί περνούσε πάντα κάθε δεύτερη μέρα στον κήπο σου.
Δεν ξέρεις ακριβώς πού βρισκόταν ανάμεσα σε αυτές τις μέρες, αλλά σίγουρα όχι στον κήπο σου.
Το ένστικτό σου ως παρατηρητή πουλιών σου λέει επίσης ότι το πουλί βρισκόταν στον κήπο σου την πρώτη μέρα που κατέγραψες στη λίστα σου.

Με αυτή τη νέα πληροφορία, γράψε μια συνάρτηση `fixBirdCountLog` που παίρνει ως όρισμα ένα αντικείμενο τύπου πίνακα με τα πουλιά που μετρήθηκαν ανά ημέρα. Θα πρέπει να διορθώσει το λάθος στην καταμέτρηση τροποποιώντας τον πίνακα που δίνεται.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
