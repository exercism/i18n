# Γενικά

- Η τεκμηρίωση των [regular expressions][regular-expressions] περιγράφει τις regex και την παραλλαγή που είναι ενσωματωμένη στις βιβλιοθήκες .NET.
- Η τεκμηρίωση του [Regex][regex] που περιγράφει την ενσωματωμένη κλάση της βιβλιοθήκης.

## 1. Προσδιόρισε τις παραμορφωμένες γραμμές καταγραφής

- Δες [αυτή τη συζήτηση][ismatch] για την αντιστοίχιση.

## 2. Χώρισε τη γραμμή καταγραφής

- [Αυτό][split] το άρθρο δείχνει έναν τρόπο για τον χωρισμό γραμμών.

## 3. Μέτρησε τον αριθμό των γραμμών που περιέχουν κωδικό πρόσβασης

- Δες [αυτή τη συζήτηση][multiple-matches] για πολλαπλές αντιστοιχίσεις και [αυτή][multi-line] για αναζητήσεις σε πολλαπλές γραμμές.

## 4. Αφαίρεσε τα υπολείμματα από την καταγραφή

- [Αυτό το άρθρο][replace] δείχνει πώς μπορεί να αντικατασταθεί κείμενο.

## 5. Κατέγραψε τις γραμμές με εξαιρετικά αδύναμους κωδικούς πρόσβασης, ώστε να τιμωρηθούν οι ένοχοι

- Οι ομάδες σύλληψης συζητούνται [εδώ][capture-groups].
