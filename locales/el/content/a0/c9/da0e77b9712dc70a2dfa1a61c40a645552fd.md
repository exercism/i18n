# Οδηγίες

Κοντά σου υπάρχει ένα κατάστημα ηλεκτρικών ειδών που λέγεται "Tech Palace".
Ο ιδιοκτήτης του καταστήματος εγκατέστησε πρόσφατα μια μεγάλη οθόνη, για να προβάλλει διαφημιστικά μηνύματα και να δείχνει έναν ξεχωριστό χαιρετισμό όταν οι πελάτες σκανάρουν τις κάρτες πιστότητάς τους στην είσοδο.
Η οθόνη αποτελείται από πολλά μικρά φωτάκια LED και μπορεί να δείξει πολλές γραμμές κειμένου.

Ο ιδιοκτήτης του καταστήματος χρειάζεται τη βοήθειά σου με τον κώδικα που χρησιμοποιείται για να δημιουργεί το κείμενο της νέας οθόνης.

## 1. Δημιούργησε το μήνυμα υποδοχής

<!-- markdownlint-disable-next-line MD038 -->
Για τους περισσότερους πελάτες που σκανάρουν τις κάρτες πιστότητάς τους, ο ιδιοκτήτης θέλει να βλέπει στην οθόνη το `Welcome to the Tech Palace, ` ακολουθούμενο από το όνομα του πελάτη με κεφαλαία γράμματα.

Υλοποίησε τη συνάρτηση `welcome_message` που δέχεται το όνομα του πελάτη ως όρισμα σύντομης συμβολοσειράς (`felt252`) και επιστρέφει το επιθυμητό μήνυμα ως `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Πρόσθεσε ένα φανταχτερό περίγραμμα

Για τους πιστούς πελάτες που αγοράζουν πολλά από το κατάστημα, ο ιδιοκτήτης θέλει η οθόνη υποδοχής να γίνει πιο φανταχτερή, προσθέτοντας μια γραμμή από αστέρια πριν και μετά το μήνυμα υποδοχής.
Δεν είναι ακόμη σίγουρος πόσα αστέρια πρέπει να έχει κάθε γραμμή, γι' αυτό θέλει να μπορεί να το ρυθμίζει.

Γράψε μια συνάρτηση `add_border` που δέχεται ως ορίσματα ένα μήνυμα υποδοχής (ένα `ByteArray`) και τον αριθμό των αστεριών ανά γραμμή (τύπου `u32`).
Θα πρέπει να επιστρέφει ένα `ByteArray` που αποτελείται από 3 γραμμές: μια γραμμή με τον επιθυμητό αριθμό αστεριών, μετά το μήνυμα υποδοχής όπως ακριβώς δόθηκε, και μετά άλλη μια γραμμή αστεριών.

```rust
add_border("Welcome!", 10)
```

Θα πρέπει να επιστρέψει το εξής:

```bash
**********
Welcome!
**********
```

## 3. Καθάρισε τα παλιά διαφημιστικά μηνύματα

Πριν εγκαταστήσει αυτή τη νέα οθόνη, το κατάστημα είχε μια παρόμοια οθόνη που μπορούσε να δείχνει μόνο σταθερές γραμμές, χωρίς δυνατότητα ρύθμισης.
Ο ιδιοκτήτης θα ήθελε να ξαναχρησιμοποιήσει μερικά από τα παλιά διαφημιστικά μηνύματα στη νέα οθόνη.
Ωστόσο, τα δεδομένα περιλαμβάνουν ήδη ένα περίγραμμα από αστέρια και κάποια άτυχα κενά.
Η δουλειά σου είναι να καθαρίσεις τα μηνύματα ώστε να μπορούν να ξαναχρησιμοποιηθούν.

Υλοποίησε μια συνάρτηση `clean_up_message` που δέχεται το παλιό διαφημιστικό μήνυμα ως `ByteArray`.
Η συνάρτηση θα πρέπει πρώτα να αφαιρεί όλα τα αστέρια από το κείμενο και στη συνέχεια να αφαιρεί τα κενά στην αρχή και στο τέλος του κειμένου που απομένει.
Στη συνέχεια, η συνάρτηση θα πρέπει να επιστρέφει το καθαρισμένο μήνυμα.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
