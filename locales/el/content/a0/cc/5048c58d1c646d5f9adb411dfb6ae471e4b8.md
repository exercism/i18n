# Εισαγωγή

Πολλές γλώσσες έχουν έναν τρόπο, όπως το `null` ή το `none`, να δηλώνουν μια ανύπαρκτη τιμή. Επειδή η R είναι σχεδιασμένη να χειρίζεται μεγάλους όγκους δεδομένων (συχνά ακατάστατων), έχει πολλαπλές μορφές του τίποτα.

Ο γενικός στόχος είναι να επισημαίνονται οι τιμές που λείπουν ή είναι ύποπτες όταν τις συναντάμε και μετά η εκτέλεση να συνεχίζει χωρίς να πετάει εξαίρεση.

## NULL

Αν μια τιμή πραγματικά δεν υπάρχει, αναπαρίσταται με `NULL`. Αυτό είναι πιθανώς το πιο κοντινό σε αυτό που μπορεί να κάνουν η C ή η Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Σε πολλά πλαίσια, οι τιμές `NULL` αγνοούνται απλώς:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Για περιπτώσεις όπου μια τιμή υπάρχει αλλά δεν ξέρουμε ποια είναι, χρησιμοποιείται το `NA`. Για παράδειγμα, όταν μετράμε οχήματα που κινούνται σε έναν δρόμο, οι ανθρώπινοι παρατηρητές μπορεί να πάρουν αναρρωτική άδεια ή οι αυτόματοι αισθητήρες να χαλάσουν, αλλά η κυκλοφορία συνεχίζει να κυλάει.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Έτσι, το `NA` είναι ένα σύμβολο που κρατά τη θέση μιας τιμής, προειδοποιώντας τους ανθρώπους ότι πρέπει να αποφασίσουν πώς θα το χειριστούν.

## NaN

Συντομογραφία του "Not a Number", το `NaN` επισημαίνει ένα πρόβλημα υπολογισμού σε περιπτώσεις όπου αναμενόταν ένας αριθμός.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

Αυτή δεν είναι η μόνη δυνατότητα για "μη έγκυρους" υπολογισμούς. Η διαίρεση με το μηδέν θα επιστρέψει `Inf` ή `-Inf` για μη μηδενικό αριθμητή, χωρίς να πετάξει σφάλμα.

```R
1 / 0
#> [1] Inf
```

## Κενά διανύσματα

Ίσως παραδόξως, η R δεν έχει καθιερωμένο τρόπο να ελέγχει αν ένα διάνυσμα είναι κενό.

Ακόμη και η δημιουργία ενός κενού διανύσματος δεν είναι εντελώς προφανής. Είδαμε σε προηγούμενη ενότητα ότι η `c()` χωρίς ορίσματα επιστρέφει `NULL`, όχι ένα διάνυσμα.

```R
is.vector(c())
#> [1] FALSE
```

Συναρτήσεις όπως οι `logical()` ή `integer()` δέχονται ένα όρισμα που καθορίζει το επιθυμητό μήκος, το οποίο μπορεί να είναι μηδέν.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Μπορούμε επίσης να δημιουργήσουμε ένα διάνυσμα και μετά να αφαιρέσουμε κάθε στοιχείο, όπως περιγράφεται στην [έννοια των διανυσμάτων][concept-vectors]. Αυτό οδηγεί σε ένα διάνυσμα μήκους 0 κατάλληλου τύπου.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
