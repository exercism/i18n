# Μάθηση

## Προτεινόμενοι πόροι μάθησης

Το Exercism προσφέρει ασκήσεις και ανατροφοδότηση, αλλά η ML μπορεί να είναι δύσκολη για όσους μαθαίνουν SML για πρώτη φορά.
Οι παρακάτω πόροι μπορούν να σε βοηθήσουν να ξεκινήσεις:

### Δεν έχω προγραμματίσει ξανά

Η ML μάλλον δεν είναι η καλύτερη γλώσσα για νέους προγραμματιστές.
Ίσως είναι καλύτερα να ξεκινήσεις με μια γλώσσα όπως η Ruby ή η Python, αλλά αν νιώθεις ιδιαίτερα τολμηρός, μπορείς να διαβάσεις το [Programming in Standard ML '97: An On-line Tutorial][tutorial].
Προτείνω να παραλείψεις την εισαγωγή και να πας κατευθείαν στο [Simple applicative programming][node13], γιατί η εισαγωγή είναι πολύ τεχνική.

Το Coursera προσφέρει ένα μάθημα για [γλώσσες προγραμματισμού][coursera].
Το μάθημα απευθύνεται σε κάπως έμπειρους προγραμματιστές, αλλά είναι δύσκολο να βρεις καλύτερη εισαγωγή στη γλώσσα ML.


### Έχω ακούσει για τον συναρτησιακό προγραμματισμό

Μια καλή επιλογή για διάβασμα είναι το [Programming in Standard ML '97: An On-line Tutorial][tutorial].

Μια άλλη είναι το [A Gentle Introduction to ML][gentle].

Το Coursera προσφέρει ένα μάθημα για [γλώσσες προγραμματισμού][coursera].
Είναι δύσκολο να βρεις καλύτερη εισαγωγή στη γλώσσα ML.

Η [ιστοσελίδα του SML/NJ][smlnj] παραθέτει αρκετά βιβλία.
Τα περισσότερα είναι αρκετά παλιά και μάλλον δύσκολο να τα βρεις, όμως.
Η γλώσσα δεν έχει αλλάξει πολύ, οπότε αν τα βρεις, μην νομίζεις ότι είναι τόσο ξεπερασμένα.
Ρίξε επίσης μια ματιά στις Four Lectures on Standard ML που αναφέρονται στη σελίδα.


## Είμαι έμπειρος προγραμματιστής

Αν είσαι έμπειρος προγραμματιστής και γνωρίζεις πολύ καλά τις συναρτησιακές γλώσσες, τότε μπορείς να πάρεις μια καλή επισκόπηση της σύνταξης στο [Learn X in Y minutes][learnxy].

Οι [Four Lectures on Standard ML][four-lectures] είναι μια καλή εισαγωγή.
