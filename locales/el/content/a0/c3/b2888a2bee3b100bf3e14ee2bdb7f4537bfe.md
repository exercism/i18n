# Εισαγωγή

Υπάρχουν δύο διαφορετικοί τύποι αριθμών στη C#:

- Ακέραιοι: αριθμοί χωρίς ψηφία μετά την υποδιαστολή (δηλαδή, ακέραιοι αριθμοί). Παραδείγματα είναι τα `-6`, `0`, `1`, `25`, `976` και `500000`.
- Αριθμοί κινητής υποδιαστολής: αριθμοί με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή. Παραδείγματα είναι τα `-2.4`, `0.1`, `3.14`, `16.984025` και `1024.0`.

Οι δύο πιο συνηθισμένοι αριθμητικοί τύποι στη C# είναι ο `int` και ο `double`. Ένας `int` είναι ένας ακέραιος 32 bit και ένας `double` είναι ένας αριθμός κινητής υποδιαστολής 64 bit.

Οι αριθμητικές πράξεις γίνονται με τους τυπικούς αριθμητικούς τελεστές. Οι αριθμοί μπορούν να συγκριθούν με τους τυπικούς αριθμητικούς τελεστές σύγκρισης και τους τελεστές ισότητας (`==`) και ανισότητας (`!=`).

Η C# διαθέτει δύο τύπους αριθμητικών μετατροπών:

1. Έμμεσες μετατροπές: δεν χάνονται δεδομένα και δεν απαιτείται πρόσθετη σύνταξη.
2. Ρητές μετατροπές: μπορεί να χαθούν δεδομένα και απαιτείται πρόσθετη σύνταξη με τη μορφή _μετατροπής τύπου_.

Επειδή ο `int` έχει μικρότερη ακρίβεια από τον `double`, η μετατροπή από `int` σε `double` είναι ασφαλής και επομένως αποτελεί έμμεση μετατροπή. Ωστόσο, η μετατροπή από `double` σε `int` μπορεί να σημαίνει απώλεια δεδομένων, οπότε απαιτεί ρητή μετατροπή.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
