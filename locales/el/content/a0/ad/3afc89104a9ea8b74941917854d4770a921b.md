Αφαίρεσε όλες τις ρητές κλήσεις στη `Boolean(...)`.

Στη JavaScript, το αποτέλεσμα μιας έκφρασης δεν χρειάζεται να γίνει _cast_ σε συγκεκριμένο τύπο.
Για παράδειγμα, το αποτέλεσμα μιας δυαδικής έκφρασης μπορεί να επιστραφεί ως έχει και δεν χρειάζεται άλλη κλήση για να γίνει `boolean`.

```javascript
// instead of
return Boolean(some_expression);

// ...In JavaScript, in general, values don't need to be explicitly changed
return some_expression;
```
