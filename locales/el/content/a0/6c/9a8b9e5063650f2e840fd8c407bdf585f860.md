# Σχετικά

Τα **κλεισίματα** είναι ένα μοτίβο προγραμματισμού [στην Clojure][clojure-guide-closures] που επιτρέπει να χρησιμοποιούνται μεταβλητές από μια εξωτερική [λεξική εμβέλεια][wiki-lexical-scope] μέσα σε μια συνάρτηση. Η Clojure υποστηρίζει τα κλεισίματα με διαφάνεια, και συχνά χρησιμοποιούνται χωρίς να ξέρει κανείς τι είναι.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Κλεισίματα για αποθήκευση κατάστασης και μεταβίβαση τιμών

Η χρήση ενός atom επιτρέπει να διατηρηθεί κάποια κατάσταση:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Κάθε διαδοχική κλήση της `increment` αυξάνει τον μετρητή της:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
