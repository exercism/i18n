# Εισαγωγή

Στη Haxe, ένας **πίνακας** είναι μια συλλογή στοιχείων (συνήθως) του ίδιου τύπου. Υπάρχουν τρεις τρόποι για να δημιουργήσεις έναν πίνακα στη Haxe: είτε με κατασκευαστή είτε με σύνταξη δήλωσης. Στη Haxe, το πρώτο στοιχείο ενός πίνακα έχει θέση μηδέν:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Για να δημιουργήσεις έναν πίνακα με κατασκευαστή, πρέπει να περάσεις τον τύπο των στοιχείων που θα περιληφθούν στον πίνακα:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Αν θέλουμε ένας πίνακας να περιέχει πολλαπλούς τύπους στοιχείων, προσθέτουμε τον τύπο `Dynamic` στη δήλωση τύπου:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
