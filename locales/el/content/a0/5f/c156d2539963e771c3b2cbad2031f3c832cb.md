# Εισαγωγή

## Αρθρώματα

Τα αρθρώματα είναι ένας τρόπος να ομαδοποιείς σχετικό κώδικα, για να αποφεύγεις συγκρούσεις ονομάτων, και γενικά υπάρχουν σε όλες τις βάσεις κώδικα εκτός από τις πιο απλές.

Η σύνταξη είναι η εξής:

```rust
mod my_module {
    pub struct MyStruct {}

    pub struct OtherClass {}
}
```

Έξω από το πεδίο εφαρμογής του αρθρώματος, για να αναφερθείς σε τύπους που περικλείονται σε αρθρώματα, χρησιμοποιείς τη σύνταξη με τη διπλή άνω τελεία `::` πριν από το όνομα του τύπου.
Εναλλακτικά, και πιο συχνά, μπορείς να τοποθετήσεις μια οδηγία `use` στην κορυφή του αρχείου (ή μέσα σε ένα άρθρωμα) και τότε μπορείς να χρησιμοποιήσεις τους τύπους χωρίς το πρόθεμα.
Μέσα στο ίδιο άρθρωμα δε χρειάζεται να προσδιορίσεις τα ονόματα των τύπων.

```rust
mod my_module {
    #[derive(Drop)]
    pub struct MyStruct {}

    pub struct Foo {}

    #[generate_trait]
    pub impl FooImpl of FooTrait {
        fn bar() {
            let baz = MyStruct {};
        }
    }
}

#[derive(Drop)]
pub struct Qux {}

#[generate_trait]
impl QuxImpl of QuxTrait {
    fn box() {
        let nux = my_module::MyStruct {};
    }
}

mod other_module {
    use super::my_module::*;

    #[derive(Drop)]
    pub struct Tix {}

    #[generate_trait]
    pub impl TixImpl of TixTrait {
        fn jeg() {
            let lor = MyStruct {};
        }
    }
}
```

Μπορείς να δώσεις ψευδώνυμο σε ένα άρθρωμα ή έναν τύπο με τη σύνταξη `use core::array::ArrayTrait as Arr;` και στη συνέχεια να χρησιμοποιήσεις το ψευδώνυμο οπουδήποτε θα μπορούσε να χρησιμοποιηθεί το άρθρωμα ή ο τύπος.
