# Παράρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                                  |
| ----------- | ------------ | ------- | ------------------------------------------ |
| `$a0`       | είσοδος      | διεύθυνση | συμβολοσειρά εισόδου με μηδενικό τερματισμό |
| `$a1`       | είσοδος      | ακέραιος | κλειδί μετατόπισης                          |
| `$a2`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος με μηδενικό τερματισμό |
| `$t0-9`     | προσωρινός   | οποιοσδήποτε | για προσωρινή αποθήκευση                |
