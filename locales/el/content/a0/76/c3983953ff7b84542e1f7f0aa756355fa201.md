# Σχετικά

Το `when` είναι η λέξη-κλειδί για το φιλτράρισμα εξαιρέσεων. Τοποθετείται μετά την εντολή catch και μπορεί να πάρει μια έκφραση Boolean (λογική τιμή) που περιέχει οποιεσδήποτε τιμές βρίσκονται στην εμβέλεια εκείνη τη στιγμή. Δεν χρειάζεται να είναι μόνο μέλη της ίδιας της εξαίρεσης. Αν ο τύπος της εξαίρεσης ταιριάζει και η έκφραση αποτιμάται ως αληθής, τότε εκτελείται το μπλοκ που σχετίζεται με αυτή την εντολή `catch`, αλλιώς ελέγχεται η επόμενη εντολή `catch`, αν υπάρχει.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- Αυτό το άρθρο [Φίλτρα εξαιρέσεων][exception-filters] δείχνει πώς να φιλτράρεις εξαιρέσεις.

[exception-filters]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/when
