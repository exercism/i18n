# Σχετικά

Οι [εκφράσεις `throw`][throw-expressions] είναι μια εναλλακτική των εντολών `throw` και ειδικότερα μπορούν να ενισχύσουν την ισχύ των τριμερών και άλλων σύνθετων εκφράσεων.

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

Αν το `str` είναι `null` στον παραπάνω κώδικα, πετιέται μια εξαίρεση.

[throw-expressions]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/throw#the-throw-expression
