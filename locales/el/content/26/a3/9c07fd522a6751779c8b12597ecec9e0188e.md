# Οδηγίες

Όπως σχεδόν κάθε άνθρωπος που έχει δουλειά, έτσι κι η Λέιλα, το Lisp Alien, χρειάζεται μερικές φορές να φτιάχνει αναφορές για να ενημερώνει τους άλλους. Σου ζητάει να τη βοηθήσεις να μορφοποιήσει τα δεδομένα που έχει για αυτές τις αναφορές.

## 1. Μορφοποίηση τριμηνιαίων τιμών

Το πρώτο πράγμα που χρειάζεται η Λέιλα είναι μια συνάρτηση: η `format-quarter-value`, που παίρνει δύο παραμέτρους: το ημερολογιακό τρίμηνο και την τιμή, και τη μορφοποιεί για μια αναφορά. Πρέπει να αξιολογείται σε μια συμβολοσειρά.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. Η αναφορά δύο τριμήνων

Η Λέιλα σε ευχαριστεί για τη συνάρτηση `format-quarter-value` και λέει ότι θα της φανεί πολύ χρήσιμη στην *επόμενη* συνάρτηση που χρειάζεται.

Η επόμενη αναφορά πρέπει να δείχνει το τρίμηνο και την τιμή από 2 τρίμηνα, τυπωμένα σε δύο γραμμές.

Επίσης, η έξοδος πρέπει να πηγαίνει στο stream που δίνεται ως πρώτο όρισμα.

Για παράδειγμα: το `(format-two-quarters t "last" 3.14 "this" 0)` θα παράγει τα εξής στην τυπική έξοδο:

```

The value last quarter: 3.14
The value this quarter: 0

```

Πρόσεξε τις κενές γραμμές γύρω του.

## 3. Αναγνώσιμο από άνθρωπο εναντίον αναγνώσιμο από Lisp Alien

Η Λέιλα ξέχασε να σου πει ότι στους Lisp Aliens αρέσει να βλέπουν τις τιμές με τρόπο που να είναι αναγνώσιμος ως δεδομένα Lisp. Έτσι, χρειάζονται μια νέα συνάρτηση που να μπορεί να διαβαστεί ως δεδομένα Lisp (και πάλι στο συγκεκριμένο stream):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
