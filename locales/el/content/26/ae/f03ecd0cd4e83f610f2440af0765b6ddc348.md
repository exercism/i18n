# Προσθήκη στις οδηγίες

## Λέξεις

Υλοποίησε:

- `grep ( pattern flags files -- lines )`

`pattern` είναι η συμβολοσειρά αναζήτησης, το `flags` είναι ένας πίνακας από μηδέν ή περισσότερες από τις συμβολοσειρές σημαιών `"-n"`, `"-l"`, `"-i"`, `"-v"`, και `"-x"`, και το `files` είναι ένας πίνακας από ένα ή περισσότερα ονόματα αρχείων. Επίστρεψε τις γραμμές που ταιριάζουν (μαζί με όποια προθέματα ονόματος αρχείου και αριθμού γραμμής έχουν ζητηθεί) ως πίνακα συμβολοσειρών.

Όταν δίνεται η σημαία `-l`, επίστρεψε έναν πίνακα με τα ονόματα των αρχείων που περιέχουν τουλάχιστον μία αντιστοίχιση.

## Ανάγνωση αρχείων

Διάβασε τις γραμμές ενός αρχείου με το `file-lines`, περνώντας μια κωδικοποίηση:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Τα τρία αρχεία fixture (`iliad.txt`, `midsummer-night.txt`, και `paradise-lost.txt`) συνοδεύουν την άσκηση στον κατάλογο εργασίας, οπότε μπορείς απλώς να τα διαβάσεις με το όνομά τους.
