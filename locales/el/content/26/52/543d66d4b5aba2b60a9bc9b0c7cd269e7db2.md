# Εισαγωγή

Μια μέθοδος είναι μια συνάρτηση με ένα ειδικό όρισμα, τον _δέκτη_.
Ο δέκτης εμφανίζεται στη δική του λίστα ορισμάτων, ανάμεσα στη λέξη-κλειδί `func` και το όνομα της μεθόδου.

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

Μπορείς να ορίσεις μια μέθοδο μόνο με δέκτη του οποίου ο τύπος ορίζεται στο ίδιο πακέτο με τη μέθοδο.

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

Υπάρχουν δύο τύποι δεκτών: δέκτες τιμής και δέκτες δείκτη.

Οι μέθοδοι με δέκτη τιμής λειτουργούν πάνω σε ένα αντίγραφο της τιμής που περνάς στη μέθοδο, που σημαίνει ότι οποιαδήποτε τροποποίηση γίνει στον δέκτη μέσα στη μέθοδο δεν είναι ορατή σε όποιον κάλεσε τη μέθοδο.

Μπορείς να δηλώσεις μεθόδους με δέκτες δείκτη, ώστε να τροποποιήσεις την τιμή στην οποία δείχνει ο δέκτης.
Αυτό γίνεται βάζοντας ένα `*` μπροστά από το όνομα του τύπου. Για παράδειγμα, για τον τύπο `rect`, ένας δέκτης δείκτη θα δηλωνόταν ως `*rect`.
Τέτοιες τροποποιήσεις είναι επίσης ορατές σε όποιον κάλεσε τη μέθοδο.

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
