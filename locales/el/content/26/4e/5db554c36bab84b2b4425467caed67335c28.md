# Σχετικά

Τα [closures][closures] στη Swift είναι αυτοτελή μπλοκ κώδικα στα οποία μπορούν να περαστούν παράμετροι, ώστε να ενεργοποιηθεί ο υπολογισμός τους, και να επιστρέψουν τιμές.
Τα closures συλλαμβάνουν επίσης τιμές από το περιβάλλον τους και τις χρησιμοποιούν στους υπολογισμούς τους.
Καθώς είναι αυτοτελή, μπορούν να μεταφέρονται μέσα σε ένα πρόγραμμα όπως κάθε άλλη τιμή ή να ανατίθενται σε σταθερές και μεταβλητές.

Τα closures μπορεί να ακούγονται σαν να μοιάζουν πολύ με τις συναρτήσεις της Swift. Πράγματι μοιάζουν, και για καλό λόγο.
Οι συναρτήσεις στη Swift είναι ειδικές περιπτώσεις closures, με την προϋπόθεση ότι έχουν όνομα και ορίζονται με ελαφρώς διαφορετική σύνταξη.

Αν και οι συναρτήσεις στη Swift είναι τεχνικά closures, όταν οι άνθρωποι αναφέρονται σε "closures" στη Swift, εννοούν τις [εκφράσεις closure][closure-expressions].
Οι εκφράσεις closure γράφονται ως μια λίστα παραμέτρων ακολουθούμενη από έναν τύπο επιστροφής και τη λέξη-κλειδί `in`, και μετά το σώμα του closure, όλα μέσα σε ένα ζεύγος αγκίστρων:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Αυτό ορίζει μια έκφραση closure τύπου `(Double, Double) -> Double`, και μπορεί να εκτελεστεί με τρόπο παρόμοιο με μια συνάρτηση αυτού του τύπου, εφαρμόζοντάς την σε παραμέτρους του κατάλληλου τύπου:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Επειδή δεν είναι και πολύ βολικό να γράφεις κάθε φορά ολόκληρη την έκφραση closure όταν θέλεις να την εκτελέσεις, τα closures μπορούν να ανατεθούν σε ονόματα, όπως κάθε άλλη τιμή στη Swift.
Στη συνέχεια, μπορείς να τα καλέσεις εφαρμόζοντας το όνομα στις παραμέτρους:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Όπως φαίνεται παραπάνω, τα closures, όπως και οι κανονικές συναρτήσεις, μπορούν να παραλείψουν τη λέξη-κλειδί `return` αν το σώμα του closure είναι μία μόνο έκφραση.

Τις περισσότερες φορές, τα closures χρησιμοποιούνται με συναρτήσεις ανώτερης τάξης, είτε περνώντας τα ως παραμέτρους είτε επιστρέφοντάς τα ως αποτελέσματα:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## Εξαγωγή τύπων closure

Όταν ο τύπος επιστροφής ή οι τύποι των παραμέτρων μπορούν να [εξαχθούν από τα συμφραζόμενα][inferring-closure-types], μπορούν να παραλειφθούν από την έκφραση closure.
Επιπλέον, αν οι τύποι των παραμέτρων μπορούν να παραλειφθούν, το ίδιο μπορούν και οι παρενθέσεις γύρω από τα ονόματα των παραμέτρων:

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- Στο πρώτο παράδειγμα, ο τύπος μπορεί να εξαχθεί από τη δήλωση τύπου στη σταθερά, `mean`.
- Στο δεύτερο, ο μεταγλωττιστής γνωρίζει από τον ορισμό της `makeAdder` ότι το `base` είναι int και ότι η συνάρτηση που επιστρέφεται πρέπει να είναι τύπου `(Int) -> Int`. Από εκεί, μπορεί να επαληθεύσει ότι αν το `x` είναι `Int`, τότε το closure θα έχει τύπο `(Int) -> Int`, κι έτσι μπορούμε να παραλείψουμε την υπογραφή τύπου στο closure, αφού το `(Int) -> Int` είναι η μόνη έγκυρη υπογραφή που μπορεί να έχει το closure.
- Το τρίτο παράδειγμα είναι παρόμοιο, αλλά ο μεταγλωττιστής χρειάζεται να πάρει μέρος της πληροφορίας για τους τύπους από τον πίνακα με τον οποίο χρησιμοποιείται η μέθοδος. Γνωρίζει ότι η μέθοδος `sorted(by:)` δέχεται ως παράμετρο ένα closure με δύο παραμέτρους που είναι του ίδιου τύπου με τα στοιχεία της συλλογής που ταξινομείται και το οποίο επιστρέφει `Bool`, οπότε ο μεταγλωττιστής μπορεί να συμπεράνει ότι ο τύπος επιστροφής του closure πρέπει να είναι `Bool`. Και εφόσον η μέθοδος χρησιμοποιείται με έναν πίνακα από String, μπορεί να προσδιορίσει ότι οι τύποι των παραμέτρων `s1` και `s2` πρέπει να είναι και οι δύο `String`.

## Περιορισμοί των closures

Όπως αναφέρθηκε παραπάνω, οι συναρτήσεις και τα closures μοιάζουν πολύ στη Swift, αλλά υπάρχουν κάποιες σημαντικές διαφορές:

- Τα closures δεν μπορούν να χρησιμοποιήσουν εξωτερικές ετικέτες ορισμάτων. Δεν υπάρχει τρόπος να τις ορίσεις, και το να προσπαθήσεις να χρησιμοποιήσεις το όνομα μιας παραμέτρου όταν καλείς το closure οδηγεί σε σφάλμα:

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- Οι παράμετροι στα closures δεν μπορούν να έχουν προεπιλεγμένη τιμή.
- Οι παράμετροι στα closures μπορούν να είναι μεταβλητού πλήθους, αλλά πρέπει να έχουν όνομα και δήλωση τύπου.
