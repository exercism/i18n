# Σχετικά

Τα χαρακτηριστικά της [Red](https://www.red-lang.org) προέρχονται κυρίως από το γεγονός ότι η βάση της δημιουργίας της ήταν η [Rebol](http://www.rebol.com), και η ανάπτυξη της Red ξεκίνησε ως εναλλακτική λύση της κοινότητας ανοιχτού κώδικα. Στο μεταξύ, η ανάπτυξη της Rebol έχει σταματήσει, και η Red εξελίσσεται συνεχώς.

## Η κληρονομιά της Rebol

Όπως ακριβώς η Rebol, η Red είναι μια γλώσσα προγραμματισμού **γενικού σκοπού**. Μπορείς να τη χρησιμοποιήσεις για να δημιουργήσεις οποιαδήποτε εφαρμογή θέλεις. Για να είναι όσο το δυνατόν πιο οικεία στους προγραμματιστές, υλοποιούνται **πολλαπλά παραδείγματα**: *προστακτικά*, *συναρτησιακά*, *αντικειμενοστρεφή*, *συμβολικά* και *αντιδραστικά*. Αν και ολόκληρη η αλυσίδα εργαλείων της χωράει σε λήψη 1,5 MB, διαθέτει υλοποιήσεις **γραφικού περιβάλλοντος χρήσης** για όλα τα κύρια λειτουργικά συστήματα (Windows, Linux, macOS) και δεν έχει εξαρτήσεις από εξωτερικές βιβλιοθήκες.

Η Red προσπαθεί να είναι **όσο το δυνατόν πιο απλή**. Έχει σχεδιαστεί κάνοντας τους πιο χρηστικούς συμβιβασμούς και επιλέγοντας λογικές προεπιλογές, ώστε να μπορεί να ολοκληρωθεί κάθε εργασία χωρίς να κατακλύζεται κανείς από πλήθος επιλογών. Εστιάζει στην ανθρώπινη **αναγνωσιμότητα**, γι' αυτό η συντακτική ζάχαρη περιορίζεται στο ελάχιστο και τα προγράμματα προσπαθούν να μοιάζουν με προτάσεις φυσικής γλώσσας. Ως αποτέλεσμα, η Red και η Rebol είναι [ιδιαίτερα εκφραστικές](https://redmonk.com/dberkholz/2013/03/25/programming-languages-ranked-by-expressiveness/).

Ένα ασυνήθιστο χαρακτηριστικό της Red είναι η **ομοεικονικότητά** της, οπότε ένα πρόγραμμα Red μπορεί να χειριστεί ακριβώς όπως οποιαδήποτε δομή δεδομένων Red. Επομένως, η Red και η Rebol είναι επίσης μορφές δεδομένων. Ένα διασκεδαστικό γεγονός είναι ότι το [JSON εμπνεύστηκε από τη Rebol](http://www.rebol.com/article/0522.html).

## Red

Σε σύγκριση με τη Rebol, η Red έχει βελτιωθεί σημαντικά. Μπορεί να **μεταγλωττιστεί** σε ένα μόνο εκτελέσιμο για κάθε υποστηριζόμενη πλατφόρμα, χρησιμοποιώντας οποιαδήποτε από αυτές. Έτσι, μπορείς να μεταγλωττίσεις προγράμματα Windows σε Linux ή προγράμματα macOS σε Windows. Υπάρχει επίσης διαθέσιμη μια **κονσόλα REPL**, τόσο σε γραμμή εντολών όσο και γραφική, που επιτρέπει τον άμεσο χειρισμό δεδομένων με εντολές Red πληκτρολογώντας τις μία προς μία.

Αυτό που επίσης διαφοροποιεί τη Red είναι η διάλεκτός της, η Red/System, που κάνει τη Red μια γλώσσα **full stack**, επιτρέποντας την ανάπτυξη κώδικα χαμηλού επιπέδου όπως στη C.

## Αποστολή

* Φέρε ξανά τη **διασκέδαση** στον προγραμματισμό
* Καταπολέμησε την πολυπλοκότητα του λογισμικού

## Ανάπτυξη

Η Red είναι ανοιχτού κώδικα. Η ανάπτυξή της φιλοξενείται στο [αποθετήριο GitHub](https://github.com/red/red). Αυτή τη στιγμή το έργο βρίσκεται σε **στάδιο άλφα**, οπότε περίμενε να αλλάξουν και να χαλάσουν πράγματα.
