# Οδηγίες

Ένα βιολί κουρδίζεται με το αυτί, με βάση μια νότα αναφοράς. Οι χορδές απέχουν πολύ
η μία από την άλλη σε τονικό ύψος, και οι αριθμοί που εμπλέκονται δεν είναι ακέραιοι.

Και οι πέντε εργασίες μπαίνουν στην κλάση `TUNING_THE_STRINGS`.

## 1. Μία οκτάβα ψηλότερα

Μια νότα μία οκτάβα ψηλότερα έχει διπλάσια συχνότητα.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Μία οκτάβα χαμηλότερα

Μια οκτάβα χαμηλότερα είναι η μισή συχνότητα.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. Ακριβώς στη μέση

Δεδομένων δύο συχνοτήτων, επίστρεψε αυτή που βρίσκεται ακριβώς ανάμεσά τους.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. Πόσο απέχουν;

Όταν δύο νότες είναι κοντά αλλά όχι ίδιες, ακούς ένα διακρότημα μία φορά το
δευτερόλεπτο για κάθε κύκλο διαφοράς τους. Επίστρεψε πόσο απέχουν οι συχνότητες.
Η απάντηση δεν είναι ποτέ αρνητική, όποια νότα κι αν είναι ψηλότερη.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Μοιρασιά της εξάσκησης

Με δεδομένο έναν αριθμό λεπτών και έναν αριθμό παικτών, πόσα λεπτά αναλογούν
στον καθένα; Τα λεπτά και οι παίκτες είναι ακέραιοι αριθμοί, αλλά η απάντηση
μπορεί να μην είναι.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
