# Σχετικά

## Τύποι συναρτήσεων

Έχουμε δει στο παρελθόν πώς ορίζονται οι υπογραφές συναρτήσεων: ένα όνομα συνάρτησης ακολουθούμενο από μια λίστα ετικετών παραμέτρων χωρισμένων με κόμμα μαζί με τους τύπους τους, έπειτα το `->` και τον τύπο των τιμών που επιστρέφει η συνάρτηση.

Αν αφαιρέσεις όλα τα ονόματα και τις ετικέτες από αυτή την υπογραφή, αυτό που μένει είναι ο [τύπος της συνάρτησης][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Πρόσεξε πως οι τύποι των δύο πρώτων συναρτήσεων είναι ίδιοι, `(String, Int) -> String`, ακόμα κι αν οι δύο συναρτήσεις λειτουργούν με πολύ διαφορετικό τρόπο. Και οι δύο παίρνουν ένα `String` και ένα `Int` ως είσοδο και επιστρέφουν ένα `String`. Και, όπως φαίνεται από τον τύπο της τρίτης συνάρτησης, ακόμα κι αν η συνάρτηση δεν φαίνεται να επιστρέφει κάτι, στην πραγματικότητα επιστρέφει `()`, τη μόνη τιμή του τύπου `Void`. Σημείωσε ότι τα `()` και `Void` είναι εναλλάξιμα ως ονόματα τύπων, οπότε ο τύπος της `printString` θα μπορούσε να γραφτεί και ως `String) -> Void`.

Αυτοί οι τύποι μπορούν να χρησιμοποιηθούν με τον ίδιο τρόπο όπως κάθε άλλος τύπος στη Swift, για παράδειγμα, μπορούν να χρησιμοποιηθούν στη δήλωση μεταβλητών ή σταθερών. Και επειδή οι συναρτήσεις είναι τιμές στη Swift, συναρτήσεις που υπάρχουν ήδη μπορούν να ανατεθούν σε αυτές τις σταθερές/μεταβλητές:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Όπως με τις άλλες μεταβλητές/σταθερές, η τιμή που της αναθέτεις πρέπει να είναι του σωστού τύπου:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Τύποι συναρτήσεων ως τύποι παραμέτρων

Καθώς οι τύποι συναρτήσεων μπορούν να χρησιμοποιηθούν όπου μπορεί να χρησιμοποιηθεί οποιοσδήποτε άλλος τύπος, έπεται ότι [μπορούν να χρησιμοποιηθούν ως τύποι παραμέτρων][functions-as-parameters] και να περαστούν σε άλλες συναρτήσεις και να κληθούν μέσα από αυτές.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Τύποι συναρτήσεων ως τύποι επιστροφής

Παρομοίως, [οι τύποι συναρτήσεων μπορούν να χρησιμοποιηθούν ως τύποι επιστροφής][functions-as-returns] για συναρτήσεις. Με άλλα λόγια, μπορείς να γράψεις συναρτήσεις που δημιουργούν και επιστρέφουν άλλες συναρτήσεις. Όταν δημιουργείς αυτές τις συναρτήσεις, η συνάρτηση που επιστρέφεται μπορεί να χρησιμοποιήσει τις άλλες παραμέτρους που περνούν στη συνάρτηση ή τις τοπικές μεταβλητές που δημιουργούνται μέσα στη γονική συνάρτηση.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Καταγραφή τιμών

Όπως φάνηκε με τη συνάρτηση `makeAdder(base:)` παραπάνω, οι εμφωλευμένες συναρτήσεις μπορούν να έχουν πρόσβαση στις παραμέτρους και τις μεταβλητές των συναρτήσεων που τις περιβάλλουν. Επιπλέον, μπορούν να διατηρήσουν την πρόσβαση σε αυτές τις τιμές αφού τερματίσει η συνάρτηση που τις περικλείει. Αυτή η ενέργεια της απόκτησης και της διατήρησης πρόσβασης είναι γνωστή ως [_καταγραφή_][capturing-values].

## Συναρτήσεις ανώτερης τάξης

Οι συναρτήσεις που παίρνουν συναρτήσεις ως παραμέτρους ή/και επιστρέφουν συναρτήσεις είναι γνωστές ως συναρτήσεις ανώτερης τάξης. Η Swift έχει πολλές συναρτήσεις ανώτερης τάξης στις διάφορες βιβλιοθήκες της. Για παράδειγμα, η μέθοδος `sorted(by:)` που είναι διαθέσιμη στις συλλογές της Swift, όπως ο `Array`, η οποία για έναν πίνακα με στοιχεία τύπου `T` παίρνει μια συνάρτηση τύπου `(T, T) -> Bool` που καθορίζει ποια από τις δύο τιμές πρέπει να έρθει πριν από την άλλη σε έναν ταξινομημένο πίνακα, επιστρέφοντας `true` αν η αριστερή τιμή πρέπει να εμφανιστεί πρώτη και `false` αν η δεξιά τιμή πρέπει να εμφανιστεί πρώτη.

Ένα άλλο παράδειγμα είναι η μέθοδος `contains(where:)` στις συλλογές, η οποία για μια συλλογή με στοιχεία τύπου `T` παίρνει μια συνάρτηση τύπου `(T) -> Bool` που επιστρέφει `true` αν το στοιχείο ικανοποιεί κάποια ιδιότητα και `false` διαφορετικά. Στη συνέχεια, η `contains(where:)` επιστρέφει `true` αν κάποιο στοιχείο της συλλογής ικανοποιεί αυτή την ιδιότητα.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
