# Εισαγωγή

Στη Common Lisp ο χρόνος αναπαρίσταται με τέσσερις τρόπους, δύο από τους οποίους θα δούμε εδώ.

- Ο παγκόσμιος χρόνος είναι ένας απόλυτος χρόνος, ένας ακέραιος που αντιπροσωπεύει τον αριθμό των δευτερολέπτων από το `1900-01-01T00:00:00Z` (δηλαδή τα μεσάνυχτα της 1ης Ιανουαρίου 1900 στη ζώνη UTC).
- Ο αποκωδικοποιημένος χρόνος είναι μια πλειάδα 9 τιμών, που μαζί αντιπροσωπεύουν μια συγκεκριμένη ημερολογιακή στιγμή: δευτερόλεπτα, λεπτά, ώρα, ημέρα του μήνα, μήνας, έτος, ημέρα της εβδομάδας, σημαία θερινής ώρας, ζώνη ώρας.
(Τα συζητάμε αναλυτικά παρακάτω.)

## Παγκόσμιος χρόνος

Για να πάρεις τον τρέχοντα παγκόσμιο χρόνο, χρησιμοποιείς το `get-universal-time` ή το `get-decoded-time`.
Το πρώτο επιστρέφει τα τρέχοντα δευτερόλεπτα από το `1900-01-01T00:00Z` και το δεύτερο επιστρέφει τα ίδια δεδομένα σε αποκωδικοποιημένη μορφή.

## Αποκωδικοποιημένος χρόνος

Οι `decode-universal-time` και `encode-universal-time` είναι οι κύριες συναρτήσεις για την εργασία με τον χρόνο.
Το πρώτο παίρνει έναν παγκόσμιο χρόνο και επιστρέφει μια αποκωδικοποιημένη τιμή χρόνου ως [πολλαπλές τιμές][concept-multiple-values], ενώ το δεύτερο παίρνει τις αποκωδικοποιημένες τιμές χρόνου ως ορίσματα και επιστρέφει έναν παγκόσμιο χρόνο.

Και τα δύο παίρνουν ένα προαιρετικό όρισμα ζώνης ώρας.
Δες παρακάτω τη μορφή της ζώνης ώρας.

Ένας αποκωδικοποιημένος χρόνος είναι ένα σύνολο τιμών:

- *δευτερόλεπτα*: ένας ακέραιος μεταξύ 0 και 59
- *λεπτά*: ένας ακέραιος μεταξύ 0 και 59
- *ώρα*: ένας ακέραιος μεταξύ 0 και 23
- *ημέρα του μήνα*: ένας ακέραιος μεταξύ 1 και 31 (το ανώτατο όριο εξαρτάται προφανώς από τον μήνα και το έτος)
- *μήνας*: ένας ακέραιος μεταξύ 1 και 12
- *έτος*: ένας ακέραιος που δείχνει το έτος.
- *ημέρα της εβδομάδας*: ένας ακέραιος μεταξύ 0 και 6. Το 0 σημαίνει Δευτέρα, το 1 σημαίνει Τρίτη κ.λπ. ... το 6 σημαίνει Κυριακή.
- *σημαία θερινής ώρας*: μια αληθής τιμή δείχνει ότι η θερινή ώρα είναι σε ισχύ.
- *ζώνη ώρας*: ένας αριθμός ωρών μεταξύ -24 και 24 που δηλώνει τη μετατόπιση από την UTC.
Ο αριθμός είναι ρητός και πρέπει να είναι πολλαπλάσιο του `1/3600`

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
