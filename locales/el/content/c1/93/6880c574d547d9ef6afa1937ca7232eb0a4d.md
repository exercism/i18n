# Σχετικά

Μια [συνάρτηση ανώτερης τάξης](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) είναι μια συνάρτηση που είτε:

- Δέχεται μια συνάρτηση ως όρισμα
- Επιστρέφει μια συνάρτηση

Ένα όρισμα συνάρτησης είναι απλώς ένα συνηθισμένο όρισμα, με τη διαφορά ότι μπορείς να το καλέσεις.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
