# Εισαγωγή

Η σύνδεση περιγράφει από πού στον κώδικα μπορεί να προσπελαστεί ένα αναγνωριστικό.
Οι τιμές με εμβέλεια μπλοκ, συνάρτησης ή προτύπου συνάρτησης δεν έχουν σύνδεση.
Αυτό σημαίνει ότι δεν μπορείς να τις προσπελάσεις από έξω από την εμβέλειά τους.
Για περισσότερα σχετικά με την εμβέλεια, δες την [έννοια της εμβέλειας](../scope/introduction.md#Introduction).

## Εξωτερική σύνδεση

Τα αναγνωριστικά με εμβέλεια αρχείου έχουν εξωτερική σύνδεση από προεπιλογή.
Ένα αναγνωριστικό με εξωτερική σύνδεση μπορεί να κληθεί από οποιοδήποτε αρχείο του προγράμματος.

## Εσωτερική σύνδεση

Ένα αναγνωριστικό με εμβέλεια αρχείου μπορεί να αποκτήσει εσωτερική σύνδεση χρησιμοποιώντας το προσδιοριστικό `static`.
Ένα αναγνωριστικό με εσωτερική σύνδεση μπορεί να χρησιμοποιηθεί μόνο μέσα στο αρχείο του.

Για παράδειγμα

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

Η στατική σύνδεση δεν πρέπει να συγχέεται με τη στατική διάρκεια αποθήκευσης.
Για περισσότερα σχετικά με τη στατική διάρκεια αποθήκευσης, δες την [έννοια της διάρκειας αποθήκευσης](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type).
