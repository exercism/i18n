# Παράρτημα οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να δημιουργήσεις τον τύπο δεδομένων `CustomSet`,
με στιγμιότυπα `Eq` και `Show`, και να υλοποιήσεις τις παρακάτω συναρτήσεις:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

Θα βρεις ήδη έτοιμη μια ψευδοδήλωση δεδομένων και τις υπογραφές τύπων,
αλλά σε εσένα απόκειται να ορίσεις τις συναρτήσεις και να δημιουργήσεις έναν ουσιαστικό
τύπο δεδομένων, newtype ή συνώνυμο τύπου.

Αν σε ενδιαφέρει να γράψεις μια αποδοτική υλοποίηση αλλά δεν ξέρεις και πολύ
από πού να ξεκινήσεις, το καλύτερο εισαγωγικό βιβλίο που ξέρω είναι το
"Purely Functional Data Structures" του Chris Okasaki, μια εκδοχή του οποίου μπορείς να διαβάσεις εδώ:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
