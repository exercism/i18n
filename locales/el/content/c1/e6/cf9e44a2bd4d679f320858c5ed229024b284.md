# Προσθήκη οδηγιών

## Μορφή εισόδου

Κάθε λίστα εισόδων αναπαρίσταται ως συμβολοσειρά τερματιζόμενη με null, με έναν χαρακτήρα νέας γραμμής στο τέλος κάθε εισόδου.

Ένα παράδειγμα θα ήταν `"nail\nshoe\nhorse\nrider\nmessage\nbattle\nkingdom\n"`

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος    | Περιγραφή                                                    |
| -------- | ------------ | ------- | -------------------------------------------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά εισόδου τερματιζόμενη με null, με χαρακτήρα νέας γραμμής μετά από κάθε είσοδο     |
| `$a1`    | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου τερματιζόμενη με null                                  |
| `$t0-9`  | προσωρινός     | οποιοσδήποτε     | για προσωρινή αποθήκευση                                          |
