# Κράτηση θέσης

## Τιμές ASCII

Αυτή η άσκηση απαιτεί τη μετατροπή χαρακτήρων ASCII από και προς την αριθμητική τους τιμή. Η [επέκταση ordchr][ordchr] του GNU awk παρέχει αυτή τη λειτουργία. Για να προσθέσεις τις συναρτήσεις `ord()` και `chr()`, φόρτωσε την επέκταση `ordchr` προσθέτοντας μια οδηγία `@load` στην αρχή του αρχείου σου:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
