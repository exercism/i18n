# Προσθήκη στις οδηγίες

## Υλοποίηση

Σε αυτή την άσκηση θα υλοποιήσεις μια διαδικασία που προορίζεται να δεσμεύσει τη συμβολοσειρά που επιστρέφει. Η αποδέσμευση της συμβολοσειράς είναι ευθύνη αυτού που καλεί τη διαδικασία.

```odin
// The procedure will be called like that:
converted := convert(3)
// ...
// and eventually the caller will delete the string
delete(converted)
```
