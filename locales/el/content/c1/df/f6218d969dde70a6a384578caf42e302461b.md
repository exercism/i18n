# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LVL>]: <MESSAGE>"`.

Αυτά είναι τα διαφορετικά επίπεδα καταγραφής:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Έχεις τρεις εργασίες.

## 1. Ανάλυση του επιπέδου καταγραφής

Όρισε ένα enum `LogLevel` που έχει έξι στοιχεία, τα οποία αντιστοιχούν στα παραπάνω επίπεδα καταγραφής.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

Στη συνέχεια, υλοποίησε τη μέθοδο `LogLine.getLogLevel()` που επιστρέφει το αναλυμένο επίπεδο καταγραφής μιας γραμμής καταγραφής:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Υποστήριξη άγνωστου επιπέδου καταγραφής

Δυστυχώς, κάποιες φορές μερικές γραμμές καταγραφής έχουν άγνωστο επίπεδο καταγραφής.
Για να χειριστείς ομαλά αυτές τις γραμμές καταγραφής, πρόσθεσε ένα στοιχείο `UNKNOWN` στο enum `LogLevel`, το οποίο θα πρέπει να επιστρέφεται όταν αναλύεται ένα άγνωστο επίπεδο καταγραφής:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Μετατροπή της γραμμής καταγραφής σε σύντομη μορφή

Το επίπεδο καταγραφής μιας γραμμής καταγραφής είναι αρκετά εκτενές.
Για να μειωθεί ο χώρος στον δίσκο που απαιτείται για την αποθήκευση των γραμμών καταγραφής, αναπτύχθηκε μια σύντομη μορφή: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

Το κωδικοποιημένο επίπεδο καταγραφής είναι μια απλή αντιστοίχιση ενός επιπέδου καταγραφής σε έναν αριθμό:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Υλοποίησε τη μέθοδο `LogLine.getOutputForShortLog()` που μπορεί να παράγει τη συντομευμένη μορφή της γραμμής καταγραφής:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
