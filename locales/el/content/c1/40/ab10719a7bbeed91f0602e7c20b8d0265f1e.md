# Εισαγωγή

## Αντιστοίχιση προτύπων

Μια έκφραση `if/elif/else` μπορεί να χρησιμοποιηθεί για να εκτελέσεις λογική υπό συνθήκη. Η F# έχει όμως και έναν άλλο, πιο ισχυρό τρόπο για να εκτελείς λογική υπό συνθήκη: την αντιστοίχιση προτύπων. Με την αντιστοίχιση προτύπων, μια τιμή μπορεί να ελεγχθεί ως προς ένα ή περισσότερα _πρότυπα_. Ένα παράδειγμα τέτοιου προτύπου είναι το _σταθερό πρότυπο_, το οποίο αντιστοιχίζει μια τιμή με μια σταθερά (π.χ. `1` ή `"hello"`).

Στην F#, η αντιστοίχιση προτύπων γίνεται με τη λέξη-κλειδί `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Αν και αυτό μπορεί να μοιάζει με εντολές `switch` σε άλλες γλώσσες, η αντιστοίχιση προτύπων αρχίζει να λάμπει όταν χρησιμοποιείς και άλλα πρότυπα. Ένα τέτοιο πρότυπο είναι το _πρότυπο μεταβλητής_, το οποίο σου επιτρέπει να συλλάβεις μια τιμή:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

Σε ορισμένες περιπτώσεις, μπορεί να θέλεις να προσθέσεις μια επιπλέον συνθήκη σε ένα πρότυπο. Αυτό είναι γνωστό ως _φρουρός_ (ρήτρα), ο οποίος μπορεί να προστεθεί με τη λέξη-κλειδί `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

Στο παραπάνω παράδειγμα, δεν θα αντιστοιχιστεί κάθε πιθανή είσοδος με κάποιο πρότυπο. Ο μεταγλωττιστής θα το εντοπίσει και θα εμφανίσει μια προειδοποίηση. Αυτό είναι γνωστό ως _εξαντλητικός έλεγχος_. Για να λύσεις την προειδοποίηση, πρέπει να χειριστείς όλες τις περιπτώσεις. Γι' αυτό μπορείς να χρησιμοποιήσεις το _πρότυπο μπαλαντέρ_, ένα πρότυπο που ταιριάζει με οποιαδήποτε τιμή:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

Η αντιστοίχιση προτύπων ελέγχει μια τιμή ως προς κάθε πρότυπο από πάνω προς τα κάτω, μέχρι να βρει ένα πρότυπο που ταιριάζει και να εκτελέσει τη λογική που σχετίζεται με αυτό το πρότυπο. Η σειρά των προτύπων έχει σημασία!
