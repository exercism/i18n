# Εισαγωγή

Όπως και σε άλλες γλώσσες προγραμματισμού, τα enums, που είναι συντομογραφία του `enumerations`, χρησιμοποιούνται στη Cairo για να ορίσουν προσαρμοσμένους τύπους δεδομένων που περιέχουν μια συλλογή από ένα σταθερό σύνολο ονομασμένων τιμών, που ονομάζονται _παραλλαγές_.
Κάθε παραλλαγή που αποτελεί ένα enum είναι διακριτή και έχει μια συγκεκριμένη σημασία.
