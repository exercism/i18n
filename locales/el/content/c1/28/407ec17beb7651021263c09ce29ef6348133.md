# Εισαγωγή

Ο τύπος διακριτής ένωσης αντιπροσωπεύει έναν σταθερό αριθμό ονομασμένων περιπτώσεων. Κάθε τιμή μιας διακριτής ένωσης αντιστοιχεί σε ακριβώς μία από τις ονομασμένες περιπτώσεις.

Μια διακριτή ένωση ορίζεται με τη λέξη-κλειδί `type`, με τις περιπτώσεις να χωρίζονται από χαρακτήρες κάθετης γραμμής (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Κάθε περίπτωση μιας διακριτής ένωσης μπορεί προαιρετικά να έχει δεδομένα που σχετίζονται με αυτήν, και διαφορετικές περιπτώσεις μπορούν να έχουν διαφορετικούς τύπους δεδομένων. Αν καμία από τις περιπτώσεις δεν έχει δεδομένα, η διακριτή ένωση μοιάζει με αυτό που άλλες γλώσσες συνήθως αποκαλούν _απαρίθμηση_ (ή _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Μπορείς να δημιουργήσεις μια τιμή για μια συγκεκριμένη περίπτωση αναφέροντας το όνομά της (π.χ. `Success`). Επειδή τα ονόματα των περιπτώσεων είναι απλώς συναρτήσεις κατασκευαστή, τα σχετιζόμενα δεδομένα μπορούν να περαστούν ως κανονικό όρισμα συνάρτησης. Αν μια άλλη διακριτή ένωση έχει ορίσει μια περίπτωση με το ίδιο όνομα, θα χρειαστεί να χρησιμοποιήσεις το πλήρες όνομά της (π.χ. `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Οι διακριτές ενώσεις έχουν _δομική ισότητα_, που σημαίνει ότι δύο τιμές της ίδιας περίπτωσης και με τα ίδια (προαιρετικά) δεδομένα είναι ισοδύναμες.

Αν και μπορείς να χρησιμοποιήσεις εκφράσεις `if/elif/else` για να δουλέψεις με διακριτές ενώσεις, ο συνιστώμενος τρόπος είναι η αντιστοίχιση προτύπων με το _πρότυπο αναγνωριστικού_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
