# Σχετικά

Οι [πλειάδες][tuples] συνδυάζουν πολλές τιμές σε μία σύνθετη τιμή.
Σε αντίθεση με τους πίνακες, οι τιμές σε μια πλειάδα δεν χρειάζεται να έχουν τον ίδιο τύπο και το μέγεθος μιας πλειάδας είναι σταθερό από τη στιγμή που θα δημιουργηθεί.

Δημιούργησε μια πλειάδα περικλείοντας τιμές χωρισμένες με κόμματα σε παρενθέσεις:

```swift
let order = ("biscuits", 2.99, 3)
```

Μπορείς επίσης να δηλώσεις ρητά τους τύπους:

```swift
let order: (String, Double, Int) = ("biscuits", 2.99, 3)
```

Για να εξαγάγεις μεμονωμένα στοιχεία από μια πλειάδα χωρίς ονόματα, χρησιμοποίησε τη σύνταξη θέσης με βάση το μηδέν (`.0`, `.1`, κ.λπ.):

```swift
let item = order.0     // "biscuits"
let quantity = order.2 // 3
```

## Πλειάδες με ονόματα

Μπορείς να δώσεις ονόματα σε μεμονωμένα στοιχεία της πλειάδας όταν την ορίζεις:

```swift
let order = (item: "biscuits", price: 2.99, quantity: 3)
```

Το να ονομάζεις τα στοιχεία κάνει τον κώδικα πιο ευανάγνωστο και σου επιτρέπει να έχεις πρόσβαση στα στοιχεία χρησιμοποιώντας τη σημειογραφία με τελεία και τις ετικέτες τους:

```swift
let item = order.item         // "biscuits"
let quantity = order.quantity // 3
```

Μπορείς επίσης να συμπεριλάβεις ονόματα στοιχείων στη δήλωση τύπου:

```swift
let order: (item: String, price: Double, quantity: Int) = (item: "biscuits", price: 2.99, quantity: 3)
```

## Τροποποίηση πλειάδων

Αν μια πλειάδα δηλωθεί ως μεταβλητή (`var`), μπορείς να ενημερώσεις τα στοιχεία της:

```swift
var order = ("biscuits", 2.99, 3)
order.0 = "cookies"
order.1 = 1.99
order.2 = 5

print(order)
// Prints ("cookies", 1.99, 5)
```

## Πολλαπλές τιμές επιστροφής

Ενώ οι συναρτήσεις στη Swift μπορούν να επιστρέψουν μόνο μία τιμή, επιστρέφοντας μια πλειάδα μπορείς να συσκευάσεις και να [επιστρέψεις πολλαπλές τιμές][multiple-return-values] από μια συνάρτηση:

```swift
func divide(_ dividend: Int, by divisor: Int) -> (quotient: Int, remainder: Int) {
    let quotient = dividend / divisor
    let remainder = dividend % divisor
    return (quotient, remainder)
}

let result = divide(14, by: 4)
print("Quotient: \(result.quotient), Remainder: \(result.remainder)")
// Prints "Quotient: 3, Remainder: 2"
```

## Αποδόμηση πλειάδας

Μπορείς να αποδομήσεις (να αποσυσκευάσεις) τις τιμές μιας πλειάδας σε ξεχωριστές σταθερές ή μεταβλητές:

```swift
let order = ("biscuits", 2.99, 3)
let (item, price, quantity) = order

print(item) // Prints "biscuits"
```

Η αποδόμηση πλειάδας λειτουργεί επίσης απευθείας σε βρόχους `for-in`:

```swift
let orders = [("biscuits", 2.99, 3), ("cookies", 1.99, 5)]

for (item, price, quantity) in orders {
    print("Item: \(item), Price: \(price), Quantity: \(quantity)")
}
```
