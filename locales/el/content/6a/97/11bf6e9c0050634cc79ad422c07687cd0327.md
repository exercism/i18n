# Εισαγωγή

Η αναδρομή είναι ένας τρόπος να επαναλαμβάνεις κώδικα μέσα σε μια συνάρτηση, καλώντας η συνάρτηση τον εαυτό της.
Είναι ένας ακόμη τρόπος για βρόχους και επανάληψη. Όπως και με τον βρόχο, η συνάρτηση πρέπει να ελέγχει μια έκφραση Boolean για να ξέρει πότε να σταματήσει.
Σε αντίθεση με τον βρόχο, μια αναδρομή που δεν τελειώνει ποτέ δεν θα συνεχιστεί επ' άπειρον.
Οι τιμές που χρησιμοποιούνται σε κάθε κλήση συνάρτησης μπορεί να τοποθετούνται στο δικό τους πλαίσιο στη στοίβα.
Αν ο αριθμός των κλήσεων συνάρτησης καταλαμβάνει περισσότερο χώρο από ό,τι έχει η στοίβα, θα προκληθεί σφάλμα υπερχείλισης στοίβας.

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

Αυτό θα εκτυπώσει

```
The number is 1
The number is 2
After recursion
```

Υπάρχουν περιπτώσεις που είναι πιο ευανάγνωστες ή/και πιο εύκολο να τις κατανοήσεις όταν εκφράζονται με αναδρομή παρά με βρόχο.
