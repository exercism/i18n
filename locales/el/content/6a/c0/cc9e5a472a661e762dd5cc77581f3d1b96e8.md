# Υποδείξεις

## Γενικά

- Διάβασε για τις συμβολοσειρές στον επίσημο [οδηγό Ξεκινώντας][getting-started-strings].
- Ρίξε μια ματιά στις [συναρτήσεις που είναι διαθέσιμες στη μονάδα _String_][string-module-functions] για να ανακαλύψεις ποιες λειτουργίες πάνω σε συμβολοσειρές προσφέρει η βασική βιβλιοθήκη της Elixir.

## 1. Πάρε το πρώτο γράμμα του ονόματος

- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-first] για να πάρεις τον πρώτο χαρακτήρα από μια συμβολοσειρά.
- Υπάρχουν πολλές [ενσωματωμένες συναρτήσεις][string-trim] για να αφαιρέσεις κενά διαστήματα από την αρχή, το τέλος, ή και από τα δύο σημεία μιας συμβολοσειράς.

## 2. Μορφοποίησε το πρώτο γράμμα ως αρχικό

- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-upcase] για να μετατρέψεις όλους τους χαρακτήρες μιας συμβολοσειράς στην κεφαλαία εκδοχή τους.
- Υπάρχει ένας [τελεστής][kernel-concat] που συνενώνει δύο συμβολοσειρές.

## 3. Χώρισε το πλήρες όνομα στο όνομα και το επώνυμο

- Υπάρχει μια [ενσωματωμένη συνάρτηση][string-split] που χωρίζει μια συμβολοσειρά με βάση τα κενά διαστήματα.
- Μπορείς να αναθέσεις μερικά πρώτα στοιχεία μιας λίστας σε μεταβλητές με αντιστοίχιση προτύπων πάνω στη λίστα.

## 4. Βάλε τα αρχικά μέσα στην καρδιά

- Υπάρχει ειδική σύνταξη για την [παρεμβολή][string-interpolation] μιας έκφρασης μέσα σε μια συμβολοσειρά.
- Υπάρχει ειδική σύνταξη για να γράφεις [συμβολοσειρές πολλαπλών γραμμών][heredoc-syntax] χωρίς να χρειάζεται να κάνεις escape στις αλλαγές γραμμής.
