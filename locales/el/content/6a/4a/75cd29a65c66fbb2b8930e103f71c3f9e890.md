# Βρόχοι

Οι βρόχοι στη Rust μπορούν να χρησιμοποιηθούν για να εκτελείς επανειλημμένα ένα μπλοκ κώδικα, μέχρι να τους πεις να σταματήσουν ή μέχρι να ικανοποιηθεί μια συγκεκριμένη συνθήκη.

Η πιο βασική εκδοχή ενός βρόχου χρησιμοποιεί τη λέξη-κλειδί `loop`:

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

Το παραπάνω απόσπασμα κώδικα δημιουργεί έναν άπειρο βρόχο. Για να βγεις από έναν βρόχο, χρησιμοποίησε τη λέξη-κλειδί break:

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## Βρόχοι με `for` και `while`

Εκτός από τη λέξη-κλειδί `loop`, μπορείς να φτιάξεις βρόχους και με `for` και `while`.

Ένας `for` βρόχος χρησιμοποιείται για να διατρέξεις τα στοιχεία μιας συλλογής ή ενός επαναλήπτη.

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

Και τα εύρη είναι επαναλήπτες, κάτι που κάνει την επανάληψη πάνω από αυτά με τον `for` βρόχο πολύ βολική:

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

Ένας `while` βρόχος επαναλαμβάνει κώδικα μέχρι να ικανοποιηθεί μια συνθήκη. Θα μπορούσαμε να ξαναγράψουμε το προηγούμενο παράδειγμα χρησιμοποιώντας έναν `while` βρόχο ως εξής:

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

Δες το [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops) στο βιβλίο της Rust για περισσότερες πληροφορίες σχετικά με τους βρόχους.
