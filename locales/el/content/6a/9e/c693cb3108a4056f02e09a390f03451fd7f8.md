# Δημιουργία ενός Test Runner

Πρώτα απ' όλα, σε ευχαριστούμε για το ενδιαφέρον σου να δημιουργήσεις ένα Test Runner!

Αυτά είναι τα βήματα για να ξεκινήσεις:

1. Έλεγξε τη [λίστα αποθετηρίων μας για υπάρχον `...-test-runner`](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) για να βεβαιωθείς ότι δεν υπάρχει ήδη κάποιο.
2. Ρίξε μια ματιά στα [περιεχόμενα αυτού του καταλόγου](/docs/building/tooling/test-runners) για να βεβαιωθείς ότι νιώθεις άνετα με την ιδέα να δημιουργήσεις ένα Test Runner.
3. Ξεκίνα ένα νέο θέμα στο [φόρουμ του Exercism][building-exercism] λέγοντάς μας για ποια γλώσσα θα ήθελες να δημιουργήσεις ένα Test Runner.
4. Μόλις σου δημιουργηθεί ένα αποθετήριο Test Runner, χρησιμοποίησε τα έγγραφα [Διεπαφή Test Runner](/docs/building/tooling/test-runners/interface) και [Βέλτιστες πρακτικές](/docs/building/tooling/best-practices) για να καθοδηγήσουν την υλοποίησή σου.

Έχουμε μια απίστευτα φιλική και υποστηρικτική κοινότητα που θα χαρεί να σε βοηθήσει καθώς προχωράς!
Αν κολλήσεις, ξεκίνα ένα νέο θέμα στο [φόρουμ του Exercism][building-exercism] ή δημιούργησε νέα issues στο [exercism/exercism][exercism-repo] αν χρειαστεί 🙂
