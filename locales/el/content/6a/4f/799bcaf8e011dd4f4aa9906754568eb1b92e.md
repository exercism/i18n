# Υποδείξεις

## Γενικά

- Το `movdqa` πρέπει να χρησιμοποιείται μόνο όταν είναι γνωστό ότι ένας τελεστέος μνήμης είναι ευθυγραμμισμένος.
  Είναι ασφαλές στη χρήση όταν και οι δύο τελεστέοι είναι καταχωρητές.
- Το `movdqu` λειτουργεί με οποιαδήποτε ευθυγράμμιση.
- Οι διευθύνσεις μνήμης περνιούνται ως ακέραιες τιμές.
  Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`, αντίστοιχα.

## 1. Ανάμιξε δύο κομμάτια

- Η κορεσμένη πρόσθεση με πρόσημο για λωρίδες 16 bit είναι η `paddsw`.
- Και οι τρεις διευθύνσεις μνήμης είναι ευθυγραμμισμένες στα 16 byte, οπότε η ευθυγραμμισμένη παραλλαγή μετακίνησης, η `movdqa`, είναι κατάλληλη.
  Μπορούν επίσης να χρησιμοποιηθούν απευθείας ως τελεστέος προέλευσης (αλλά όχι ως τελεστέος προορισμού).

## 2. Αφαίρεσε τη διαρροή

- Η κορεσμένη αφαίρεση με πρόσημο για λωρίδες 16 bit είναι η `psubsw`.
- Το `track` είναι ευθυγραμμισμένο, αλλά δεν είναι εγγυημένο ότι τα `result` και `bleed` είναι, οπότε χρειάζονται τη μη ευθυγραμμισμένη παραλλαγή μετακίνησης, τη `movdqu`.

## 3. Συνδύασε τους μετρητές

- Η κορεσμένη πρόσθεση χωρίς πρόσημο για λωρίδες 8 bit είναι η `paddusb`.
- Και οι τρεις διευθύνσεις μνήμης είναι ευθυγραμμισμένες στα 16 byte, οπότε η ευθυγραμμισμένη παραλλαγή μετακίνησης, η `movdqa`, είναι κατάλληλη.
  Μπορούν επίσης να χρησιμοποιηθούν απευθείας ως τελεστέος προέλευσης (αλλά όχι ως τελεστέος προορισμού).

## 4. Εφάρμοσε ένα fade

- Ο πολλαπλασιασμός που κρατά τα υψηλά 16 bit ενός γινομένου 16 bit με πρόσημο είναι η `pmulhw`.
- Και οι τρεις διευθύνσεις μνήμης είναι ευθυγραμμισμένες στα 16 byte, οπότε η `movdqa` είναι κατάλληλη.
  Μπορούν επίσης να χρησιμοποιηθούν απευθείας ως τελεστέος προέλευσης (αλλά όχι ως τελεστέος προορισμού).
- Τόσο το `track` όσο και το `gains` διαβάζονται ως τιμές με πρόσημο, κάτι που περιμένει η `pmulhw`.
- Οι εντολές με δύο τελεστέους συνήθως αντικαθιστούν τον τελεστέο προορισμού τους.
- Κάθε καταχωρητής 128 bit χωράει 8 δείγματα, και το `n` (το τέταρτο όρισμα) είναι πάντα μη μηδενικό και πολλαπλάσιο του `8`.
- Θα πρέπει να χρησιμοποιήσεις έναν βρόχο για να επεξεργαστείς όλα τα δείγματα, προχωρώντας 16 byte (8 δείγματα) σε κάθε επανάληψη.

## 5. Εξασθένησε ένα κομμάτι

- Το ακέραιο SIMD δεν έχει συσκευασμένη διαίρεση, οπότε μετέτρεψε σε συσκευασμένες τιμές κινητής υποδιαστολής, διαίρεσε και μετά μετέτρεψε πίσω.
- Τα δείγματα είναι 16 bit και πρέπει να διευρυνθούν σε 32 bit πριν τη μετατροπή σε τιμές κινητής υποδιαστολής.
  Η διεύρυνση με πρόσημο από λωρίδες 16 bit σε λωρίδες 32 bit είναι η `pmovsxwd`.
- Η `pmovsxwd` μπορεί να δεχτεί έναν τελεστέο μνήμης 64 bit, φορτώνοντας και διευρύνοντας 4 δείγματα σε ένα μόνο βήμα.
- Μετέτρεψε τους διευρυμένους ακέραιους σε συσκευασμένα float με την `cvtdq2ps`.
- Ο διαιρέτης είναι ένας ακέραιος 32 bit που παρέχεται ήδη σε 4 αντίγραφα.
  Θα πρέπει να μετατραπεί σε συσκευασμένα float πριν χρησιμοποιηθεί σε διαίρεση κινητής υποδιαστολής.
- Η συσκευασμένη διαίρεση απλής ακρίβειας είναι η `divps`.
- Μετέτρεψε το πηλίκο πίσω σε συσκευασμένους ακέραιους 32 bit με την `cvttps2dq`, η οποία πάντα αποκόπτει προς το μηδέν.
- Κάθε μπλοκ αποτελέσματος είναι 4 ακέραιοι 32 bit, και το `n` (το τέταρτο όρισμα) είναι πάντα μη μηδενικό και πολλαπλάσιο του `4`.
- Θα πρέπει να χρησιμοποιήσεις έναν βρόχο, προχωρώντας 8 byte στο `samples` (4 τιμές) και 16 byte στο `result` (4 τιμές) σε κάθε επανάληψη.
