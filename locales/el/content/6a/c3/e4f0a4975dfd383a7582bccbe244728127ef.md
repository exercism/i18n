# Οδηγίες

Η κλήση API μπορεί να είναι επιρρεπής σε σφάλματα όταν χρησιμοποιείς ακατέργαστο κείμενο ή JSON. Σε αυτή την άσκηση, θα χρησιμοποιήσεις Ballerina Records για να οργανώσεις τα payload των αιτημάτων και να εξασφαλίσεις επιτυχή επικοινωνία με εξωτερικά endpoints κρατήσεων.

## Στόχοι

- Τροποποίησε τον κώδικα που σου δίνεται.
- Κάνε κράτηση αεροπορικού εισιτηρίου για τον χρήστη καλώντας την υπηρεσία κρατήσεων αεροπορικών εισιτηρίων. Στείλε ένα αίτημα POST στο airlineReservationService με το κατάλληλο payload και λάβε μια απάντηση
- Κάνε κράτηση δωματίου ξενοδοχείου για τον χρήστη καλώντας την υπηρεσία κρατήσεων ξενοδοχείων. Στείλε ένα αίτημα POST στο hotelReservationService με το κατάλληλο payload και λάβε μια απάντηση
- Νοίκιασε ένα αυτοκίνητο για τον χρήστη καλώντας την υπηρεσία ενοικίασης αυτοκινήτων. Στείλε ένα αίτημα POST στο carRentalService με το κατάλληλο payload και έλεγξε την απάντηση
- Αν όλα πάνε καλά, επέστρεψε ένα body με χαρακτηριστικό message ίσο με "Congratulations! Your journey is ready!!"
