# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις λίγο ακόμα πάνω σε τηλεκατευθυνόμενα αυτοκίνητα.

Ένα πειραματικό αυτοκίνητο έχει αναπτυχθεί και η πίστα δοκιμών πρέπει να προσαρμοστεί ώστε να χειρίζεται τόσο τα μοντέλα παραγωγής όσο και τα πειραματικά. Οι δύο τύποι αυτοκινήτου έχουν ήδη κατασκευαστεί και πρέπει να βρεις έναν τρόπο να τους χειριστείς και τους δύο στην πίστα δοκιμών.

Επιπλέον, τα αυτοκίνητα παραγωγής αρχίζουν να έχουν κάποια επιτυχία. Το αφεντικό της ομάδας θέλει να διατηρήσει το ανταγωνιστικό πνεύμα δημοσιεύοντας μια κατάταξη των αυτοκινήτων παραγωγής.

## 1. Ενεργοποίησε την οδήγηση των αυτοκινήτων στην ίδια πίστα δοκιμών

Πρόσθεσε μια μέθοδο στη διεπαφή `IRemoteControlCar` ώστε να εκθέτει τις υλοποιήσεις της `Drive()` για τους δύο τύπους αυτοκινήτου.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Ενεργοποίησε τη σύγκριση της απόστασης που διανύουν τα διαφορετικά μοντέλα στην πίστα δοκιμών

Πρόσθεσε μια ιδιότητα στη διεπαφή `IRemoteControlCar` ώστε να εκθέτει τις υλοποιήσεις της ιδιότητας `DistanceTravelled` για τους δύο τύπους αυτοκινήτου.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Δώσε τη δυνατότητα κατάταξης των αυτοκινήτων παραγωγής

Υλοποίησε τη διεπαφή `IComparable<T>` στην κλάση `ProductionRemoteControlCar`. Η προεπιλεγμένη σειρά ταξινόμησης για τα αυτοκίνητα θα πρέπει να είναι αύξουσα σειρά νικών.

Υλοποίησε τη στατική μέθοδο `TestTrack.GetRankedCars()` ώστε να επιστρέφει τα αυτοκίνητα που της περνάς, ταξινομημένα σε αύξουσα σειρά αριθμού νικών.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
