# Υποδείξεις

## Γενικά

- Υπάρχουν τρεις βασικοί τύποι εντολών συνθήκης στη Swift: εντολές `if`, εντολές `switch` και εντολές `guard`.

## 1. Υπολόγισε αν μπορείς να ανταπεξέλθεις στις μηνιαίες πληρωμές για ένα δεδομένο αυτοκίνητο

- Φρόντισε να διαιρέσεις τη συνολική τιμή του αυτοκινήτου με τον αριθμό των μηνών για να υπολογίσεις τη μηνιαία πληρωμή.
- Μπορείς να χρησιμοποιήσεις το `+` για να συνενώσεις δύο συμβολοσειρές.

## 2. Προσδιόρισε τον τύπο άδειας οδήγησης που θα χρειαστείς

- Οι εντολές `switch` είναι κατάλληλες για τον καθαρό χειρισμό ενός μεγάλου αριθμού περιπτώσεων.
- Μπορείς να χειριστείς πολλαπλές περιπτώσεις με μία μόνο περίπτωση `switch`, αν η συμπεριφορά πρέπει να είναι ίδια για όλες τους.
- Η περίπτωση `default` χειρίζεται όλες τις περιπτώσεις που δεν αναφέρονται ρητά.

## 3. Υπολόγισε τα τέλη ταξινόμησης για το νέο σου όχημα

- Η εντολή `guard` χρησιμοποιείται σε περιπτώσεις όπου η πρόωρη έξοδος είναι επιθυμητή, επειδή δεν χρειάζεται (ή δεν είναι δυνατή) περαιτέρω επεξεργασία.
- Χρειάζεται να κάνεις υπολογισμούς με τον τύπο μόνο αν το όχημα είναι κάτω των 10 ετών.
