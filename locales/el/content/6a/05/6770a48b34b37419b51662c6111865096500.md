# NuVoc

Το [NuVoc][nuvoc-link] είναι η οριστική αναφορά για τη J.
Είναι μια εξαιρετικά περιεκτική και πυκνή σε πληροφορίες επισκόπηση των primitives και της γλώσσας J.

- [r/apljk][reddit-link] subreddit
- [discord][discord-link] κανάλι

# Rosetta Code

Πολλές εργασίες του Rosetta Code έχουν λύσεις σε `J`.
Είναι μια καλή πηγή για να βρεις προγράμματα σε J που μπορείς να μελετήσεις.
[Εδώ](https://rosettacode.org/wiki/Sudoku#J) υπάρχει ένας επιλυτής sudoku του Roger Hui.
