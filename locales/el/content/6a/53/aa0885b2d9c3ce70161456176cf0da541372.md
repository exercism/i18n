# Έννοιες της παράλληλης συχνότητας γραμμάτων

Αυτή η άσκηση προσφέρει μεγάλη ποικιλία πιθανών λύσεων, σε συνδυασμό με τη βοήθεια εξωτερικών crates. Για να κρατήσουμε τον όγκο της δουλειάς διαχειρίσιμο, αυτό το έγγραφο περιέχει μια μικρή επιλογή από δυνατότητες. Οι λύσεις με Crossbeam έχουν ένα παρόμοιο σύνολο εννοιών με όσες παρατίθενται εδώ, ενώ το Rayon απαιτεί μόνο ένα υποσύνολό τους.

## Γενικά

- Συμβολοσειρές: συγκεκριμένα, το `str` παίζει πάντα ρόλο εδώ
- Unicode: συμβιβασμοί σε επιδόσεις/χαρακτηριστικά των μεθόδων ASCII εναντίον των μεθόδων unicode. Το benchmarking βγαίνει στρεβλό όταν το benchmark χρησιμοποιεί μεθόδους unicode και η λύση χρησιμοποιεί μεθόδους ASCII.
- Επαναλήπτες: επανάληψη πάνω στην είσοδο ή σε κομμάτια της.
- Συλλογές: Επανάληψη πάνω σε ένα `HashMap` και χρήση του `Entry`. Συνήθως τα handles συλλέγονται σε ένα `Vec`.
- Αναφορές
- Αριθμοί: συγκεκριμένα το trait `Add`
- `for` βρόχος: δεν μπορείς να ενώσεις νήματα μέσα σε έναν Iterator εξαιτίας του move.
- **Opt** Ορατότητα: κράτα τις λεπτομέρειες υλοποίησης μη δημόσιες
- **Opt** slices: η `.chunks()` είναι μια μέθοδος που χρησιμοποιείται συχνά για τον διαχωρισμό της εισόδου για νήματα εργασίας. Εναλλακτικά χρησιμοποιούνται υπο-τμήματα.
- **Opt** Συναρτήσεις ανώτερης τάξης: τα HashMap μπορούν να συγχωνευτούν από μια συνάρτηση ανώτερης τάξης με έναν Iterator.
- **Opt** Τύποι: για τη διαίρεση της εισόδου μπορούμε να μετατρέψουμε ακεραίους σε τιμές κινητής υποδιαστολής ώστε να εφαρμόσουμε στρογγυλοποίηση
- **Opt** Crates

## Προσέγγιση με std, με ή χωρίς κανάλια

- Παραλληλισμός - υποενότητα: δημιουργία/ένωση νημάτων.
- Επαναλήπτες - υποενότητα: οκνηρή αποτίμηση: η δημιουργία και η ένωση νημάτων με τον ίδιο Iterator εμποδίζει τον παραλληλισμό.
- Διάρκειες ζωής - υποενότητες: `'static lifetime` και ρητή σημασιολογία `move`
- Επαναλήπτες/διάρκειες ζωής - υποενότητα: καταναλωτικοί Iterator: τα νήματα δεν μπορούν να ενωθούν χρησιμοποιώντας Iterator.
- Τύπος Option: ξετύλιγμα αποτελεσμάτων νήματος ή καναλιού
- Συναρτήσεις: Συγκεκριμένα, απαιτούνται συναρτήσεις ανώτερης τάξης για τη δημιουργία νημάτων. Τα closures είναι μια επιλογή εδώ.

## Προσέγγιση με std και κανάλια

- Παραλληλισμός - υποενότητα: κανάλια.
- Πλειάδες: το `mpsc::channel()` επιστρέφει μια πλειάδα
- Αποδόμηση: μια πλειάδα μπορεί να αποδομηθεί κατά την εκχώρηση
- Διάρκειες ζωής: `drop()`

## Εναλλακτική προσέγγιση με κοινόχρηστες μεταβλητές

- Μέτρηση αναφορών: κοινή χρήση συγκεντρωτικών δεδομένων μεταξύ νημάτων με μια συλλογή που μετρά αναφορές.
- **Τιμητική μνεία**: Παραλληλισμός - υποενότητα: Mutexes. Δεν είναι απαραίτητο/χρήσιμο για αυτή την άσκηση, αλλά παρ' όλα αυτά είναι μια κοινή έννοια. Σχετικό: `RwLock`.

### Παράδειγμα με std και κανάλια

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Παράδειγμα με crate και Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
