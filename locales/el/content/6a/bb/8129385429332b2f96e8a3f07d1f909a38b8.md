# Προσάρτημα οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Η Phix δεν έχει δείκτες, και η υλοποίηση κάτι σαν συνδεδεμένη λίστα, που είναι ήδη λίγο περίπλοκη από την αρχή, ίσως με το να προσομοιώνεις δείκτες με θέσεις, όχι μόνο θα ήταν ακόμη πιο περίπλοκη, αλλά και εντελώς άσκοπη, δεδομένου ότι μια τυπική ακολουθία, η ίδια η ραχοκοκαλιά της γλώσσας, χειρίζεται τέτοια πράγματα με πολύ πιο εύκολο και σχεδόν τετριμμένο τρόπο.
Γι' αυτό, αυτή η άσκηση είναι πολύ απλή: να προσομοιώσεις τη συμπεριφορά μιας διπλά συνδεδεμένης (/διπλού άκρου) λίστας χρησιμοποιώντας μία μόνο (επίπεδη) ακολουθία, χωρίς καθόλου δείκτες ή οτιδήποτε παρόμοιο.
Ενώ πολλαπλές λίστες θα μπορούσαν να χειριστούν με πολλαπλές επιστροφές, ή θα μπορούσε να χρησιμοποιηθεί το παρεχόμενο include για στοίβα/ουρά (και τα δύο μπορούν να λάβουν εντολή να εκτελέσουν μια πράξη στο "άλλο" άκρο τους), για να απλοποιήσουμε ακόμη περισσότερο τα πράγματα θα χρησιμοποιήσουμε απλώς τη μοναδική στατική μεταβλητή "list".
