# Εισαγωγή

Στη JavaScript, οι _πρότυπες συμβολοσειρές_ επιτρέπουν την ενσωμάτωση εκφράσεων μέσα σε συμβολοσειρές, κάτι που αναφέρεται και ως παρεμβολή συμβολοσειρών.
Αυτή η δυνατότητα επεκτείνει τη λειτουργικότητα του ενσωματωμένου καθολικού αντικειμένου [`String`][string-reference].

Μπορείς να δημιουργήσεις πρότυπες συμβολοσειρές στη JavaScript τυλίγοντας κείμενο σε backticks (βαρείες).
Δεν επιτρέπουν μόνο στο κείμενο να περιλαμβάνει νέες γραμμές και άλλους ειδικούς χαρακτήρες, αλλά μπορείς επίσης να ενσωματώσεις μεταβλητές και άλλες εκφράσεις.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

Στο παραπάνω παράδειγμα, τα backticks - (<code>\`\`</code>) - χρησιμοποιούνται για να αναπαραστήσουν μια πρότυπη συμβολοσειρά. Το `${...}` είναι το σύμβολο υποκατάστασης που χρησιμοποιείται για αντικατάσταση.
Οποιοσδήποτε τύπος που δεν είναι συμβολοσειρά μετατρέπεται _σιωπηρά_ σε συμβολοσειρά.
Αυτό το θέμα καλύπτεται στην έννοια [μετατροπή τύπων][type-conversion-concept].
Όλοι οι τύποι εκφράσεων μπορούν να χρησιμοποιηθούν με πρότυπες συμβολοσειρές.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Όταν θέλεις να μορφοποιήσεις συμβολοσειρές σε πολλές γραμμές:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Αν θέλεις να αναπαραστήσεις μια νέα γραμμή μέσα σε μια κανονική συμβολοσειρά αντί να χρησιμοποιήσεις μια πρότυπη συμβολοσειρά (δηλαδή χωρίς backticks), μπορείς να χρησιμοποιήσεις την ακολουθία διαφυγής νέας γραμμής `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Με τις διαθέσιμες δυνατότητες υποκατάστασης, μπορείς επίσης να εισαγάγεις λογική στη διαδικασία για να καθορίσεις ποια πρέπει να είναι η συμβολοσειρά εξόδου.
Ένας τρόπος να χειριστείς τη λογική θα μπορούσε να είναι να χρησιμοποιήσεις τον [τριτενάρη τελεστή][ternary-operator].
Αυτό παρέχει την ίδια λειτουργικότητα υπό συνθήκη `if/else` σε ελαφρώς διαφορετική μορφή.

Για να υλοποιήσεις λογική στη σύνταξη πρότυπων συμβολοσειρών:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
