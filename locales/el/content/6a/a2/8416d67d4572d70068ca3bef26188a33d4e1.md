# Προσθήκη στις οδηγίες

## Υλοποίηση

Στο πακέτο twobucket, υλοποίησε μια συνάρτηση Go, τη Solve, με την εξής υπογραφή:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Η Solve επιστρέφει τέσσερις τιμές: τον κάδο-στόχο που προέκυψε ("one" ή "two"), τον αριθμό των κινήσεων/βημάτων για να επιτευχθεί η ποσότητα-στόχος, τα λίτρα που απομένουν στον άλλο κάδο και μια τιμή σφάλματος.
Επέστρεψε ένα σφάλμα για οποιαδήποτε μη έγκυρη παράμετρο ή όταν δεν υπάρχει λύση.
