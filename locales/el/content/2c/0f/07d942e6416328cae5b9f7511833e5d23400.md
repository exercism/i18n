# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να επεξεργαστείς μια λίστα με γλώσσες προγραμματισμού που σκοπεύεις να εξασκήσεις από την πλατφόρμα Exercism.

Έχεις έξι εργασίες.

## 1. Δημιούργησε μια νέα λίστα

Πριν μπορέσεις να προσθέσεις γλώσσες, θα πρέπει να ξεκινήσεις δημιουργώντας μια νέα λίστα. Όρισε μια συνάρτηση που επιστρέφει μια κενή λίστα.

```clojure
(new-list)
;; => ()
```

## 2. Πρόσθεσε μια νέα γλώσσα στη λίστα

Καθώς εξερευνάς το Exercism και βρίσκεις γλώσσες που θέλεις να μάθεις, θα πρέπει να μπορείς να τις προσθέτεις στη λίστα σου. Όρισε μια συνάρτηση που προσθέτει μια νέα γλώσσα στην αρχή της λίστας σου.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Έλεγξε τη γλώσσα που προστέθηκε τελευταία

Θα θέλεις να ελέγχεις γρήγορα ποια γλώσσα μόλις πρόσθεσες. Όρισε μια συνάρτηση που επιστρέφει την πρώτη γλώσσα από τη λίστα σου.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Αφαίρεσε την πρώτη γλώσσα από τη λίστα

Μερικές φορές θα αλλάξεις γνώμη για μια γλώσσα που μόλις πρόσθεσες. Όρισε μια συνάρτηση που αφαιρεί την πρώτη γλώσσα από τη λίστα σου.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Μέτρησε τις γλώσσες στη λίστα

Το να μετράς τις γλώσσες μία προς μία δεν είναι βολικό. Όρισε μια συνάρτηση που μετράει τον αριθμό των γλωσσών στη λίστα σου.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Συνδύασέ τα όλα

Όρισε μια συνάρτηση `learning-list`, μέσα στην οποία θα χρησιμοποιήσεις μερικές από τις συναρτήσεις που όρισες παραπάνω.

- Δημιούργησε μια κενή λίστα
- Πρόσθεσε 2 νέες γλώσσες προγραμματισμού στη λίστα.

  - "Clojure"
  - "Lisp"

- Αφαίρεσε τη "Lisp" από τη λίστα, καθώς μπορεί να μην έχεις αρκετό χρόνο για τη χρονιά, και μοιάζει αρκετά με την Clojure.
- Πρόσθεσε άλλες 2 γλώσσες προγραμματισμού στη λίστα.

  - "Java"
  - "JavaScript"

- Επίστρεψε τον συνολικό αριθμό των γλωσσών. Υπόδειξη: θα πρέπει να είναι 3.

```clojure
(learning-list)
;; => 3
```
