# Διευκρινίσεις

## 1. Δημιούργησε τα γράμματα των θέσεων

- Η τιμή επιστροφής θα πρέπει να είναι _τύπου_ `generator`.
- Μπορείς να έχεις μια ακολουθία γραμμάτων από το `A` έως το `D` και να τα εναλλάσσεις κυκλικά.
- Χρησιμοποίησε το `yield` για να επιστρέψεις το επόμενο γράμμα.

## 2. Δημιούργησε τις θέσεις

- Η τιμή επιστροφής θα πρέπει να είναι _τύπου_ `generator`.
- Η σειρά `13` θα πρέπει να παραλείπεται, οπότε πήγαινε από το `12` στο `14`.
- Να θυμάσαι ότι οι τιμές που επιστρέφονται θα πρέπει να είναι ταξινομημένες από τη μικρότερη στη μεγαλύτερη. `1A, 1B, 2A, ...`
- Εδώ ίσως είναι καλό να ξαναχρησιμοποιήσεις ή να καλέσεις συναρτήσεις που έχεις ήδη ορίσει.

## 3. Ανάθεσε θέσεις στους επιβάτες

- Βεβαιώσου ότι οι αριθμοί των θέσεων δεν περιέχουν κενά.
- Εδώ ίσως είναι καλό να ξαναχρησιμοποιήσεις ή να καλέσεις συναρτήσεις που έχεις ήδη ορίσει.

## 4. Κωδικοί εισιτηρίων

- Μπορείς να χρησιμοποιήσεις το `len()` για να βρεις το μήκος μιας συμβολοσειράς.
- Μπορείς να χρησιμοποιήσεις το `"<string>" * <int>` για να επαναλάβεις μια συμβολοσειρά.
