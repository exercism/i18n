# Οδηγίες

Σε αυτή την άσκηση, πρέπει να υλοποιήσεις μερικούς κανόνες από το κλασικό παιχνίδι Pac-Man.

Έχεις τέσσερις κανόνες να υλοποιήσεις, όλοι σχετικοί με τις καταστάσεις του παιχνιδιού.

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Υλοποίησε μια συνάρτηση που δέχεται αν ο Pac-Man έχει ενεργό ένα χάπι δύναμης και αν ο Pac-Man αγγίζει ένα φάντασμα, και επιστρέφει μια τιμή Boolean που δείχνει αν ο Pac-Man μπορεί να φάει το φάντασμα. Η συνάρτηση πρέπει να επιστρέφει `true` μόνο αν ο Pac-Man έχει ενεργό ένα χάπι δύναμης και αγγίζει ένα φάντασμα.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Υλοποίησε μια συνάρτηση που δέχεται αν ο Pac-Man αγγίζει ένα χάπι δύναμης και αν ο Pac-Man αγγίζει μια τελεία, και επιστρέφει μια τιμή Boolean που δείχνει αν ο Pac-Man σκόραρε. Η συνάρτηση πρέπει να επιστρέφει `true` αν ο Pac-Man αγγίζει ένα χάπι δύναμης ή μια τελεία.

```lua
rules.score(true, true)
-- => true
```

## 3. Όρισε αν ο Pac-Man χάνει

Υλοποίησε μια συνάρτηση που δέχεται αν ο Pac-Man έχει ενεργό ένα χάπι δύναμης και αν ο Pac-Man αγγίζει ένα φάντασμα, και επιστρέφει μια τιμή Boolean που δείχνει αν ο Pac-Man χάνει. Η συνάρτηση πρέπει να επιστρέφει `true` αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό ένα χάπι δύναμης.

```lua
rules.lose(false, true)
-- => true
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Υλοποίησε μια συνάρτηση που δέχεται αν ο Pac-Man έχει φάει όλες τις τελείες, αν ο Pac-Man έχει ενεργό ένα χάπι δύναμης και αν ο Pac-Man αγγίζει ένα φάντασμα, και επιστρέφει μια τιμή Boolean που δείχνει αν ο Pac-Man κερδίζει. Η συνάρτηση πρέπει να επιστρέφει `true` αν ο Pac-Man έχει φάει όλες τις τελείες και δεν έχει χάσει, σύμφωνα με τα ορίσματα που ορίζονται στο μέρος 3.

```lua
rules.win(false, true, false)
-- => false
```
