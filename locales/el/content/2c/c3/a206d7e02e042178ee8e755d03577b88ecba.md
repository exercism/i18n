Στη JavaScript, οι φακοί είναι μια έννοια του συναρτησιακού προγραμματισμού που σου επιτρέπει να έχεις πρόσβαση σε δεδομένα και να τα τροποποιείς με αρθρωτό και αμετάβλητο τρόπο. Στην ουσία, είναι ζεύγη καθαρών συναρτήσεων getter και setter που μπορούν να συντεθούν μεταξύ τους και εστιάζουν σε ένα συγκεκριμένο πεδίο μέσα σε ένα αντικείμενο.

Μπορείς να χρησιμοποιήσεις τους φακούς για να απλοποιήσεις τον κώδικα, να τον κάνεις πιο επαναχρησιμοποιήσιμο και να αποφύγεις συνηθισμένα λάθη προγραμματισμού. Για παράδειγμα, οι φακοί μπορούν να χρησιμοποιηθούν για να:

- Αποκτάς πρόσβαση και να τροποποιείς εμφωλευμένες δομές δεδομένων χωρίς να ανησυχείς για τη συγκεκριμένη δομή των δεδομένων.
- Ενημερώνεις δεδομένα με καθαρό τρόπο, χωρίς να μεταβάλλεις το αρχικό αντικείμενο.
- Συνθέτεις πολλούς φακούς μαζί για να δημιουργείς πιο σύνθετους φακούς που μπορούν να έχουν πρόσβαση σε δεδομένα και να τα τροποποιούν με πολλούς διαφορετικούς τρόπους.
