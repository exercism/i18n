# Εισαγωγή

Η Julia ενθαρρύνει τους προγραμματιστές να βάζουν όσο περισσότερο κώδικα γίνεται μέσα σε συναρτήσεις που μπορούν να μεταγλωττιστούν JIT, και η δημιουργία πολλών μικρών συναρτήσεων είναι, εκ σχεδιασμού, αποδοτική.

Αυτό τείνει να αφήνει πολλές μικρές, απλές συναρτήσεις, οι οποίες πρέπει να συνδυαστούν για να φέρουν εις πέρας μη τετριμμένες εργασίες.

Μια προφανής προσέγγιση είναι η εμφώλευση των κλήσεων συναρτήσεων.
Το παρακάτω παράδειγμα είναι πολύ τεχνητό, αλλά δείχνει το νόημα.

```julia-repl
julia> first.(titlecase.(reverse.(["my", "test", "strings"])))
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

Το μειονέκτημα αυτής της προσέγγισης είναι ότι η αναγνωσιμότητα πέφτει γρήγορα όσο βαθαίνει η εμφώλευση.

Χρειαζόμαστε μια πιο απλή και πιο ευέλικτη προσέγγιση.

## Σύνθεση

Αυτή είναι η τεχνική που αγαπούν οι μαθηματικοί, και η Julia αντιγράφει τη μαθηματική σύνταξη.

Ένας αυθαίρετος αριθμός συναρτήσεων μπορεί να [`composed`][comp] μεταξύ τους με τελεστές `∘` (τους εισάγεις με `\circ` και μετά tab).
Το αποτέλεσμα μπορεί να χρησιμοποιηθεί ως μία μόνο συνάρτηση.

```julia-repl
julia> compfunc = first ∘ titlecase ∘ reverse
first ∘ titlecase ∘ reverse
julia> compfunc.(["my", "test", "strings"])
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
# alternative syntax, giving the same result
julia> (first ∘ titlecase ∘ reverse).(["my", "test", "strings"])
```

Δύο σημεία που αξίζει να προσέξεις:

- Οι αρχικές συναρτήσεις εμφανίζονται με την ίδια σειρά όπως στην εμφώλευση και εκτελούνται από τα δεξιά προς τα αριστερά.
- Η μετάδοση δεν είναι απλή στη χρήση όταν συνθέτεις, αλλά μπορεί να εφαρμοστεί όταν καλείς τη συντεθειμένη συνάρτηση.

## Σωλήνωση

Μια εναλλακτική θα μπορούσε να θεωρηθεί η προσέγγιση των _προγραμματιστών_ και όχι των _μαθηματικών_.

Οι [`Pipelines`][comp] χρησιμοποιούνται εδώ και πολύ καιρό σε σενάρια φλοιού του Unix, και πιο πρόσφατα έγιναν δημοφιλείς σε κυρίαρχες γλώσσες προγραμματισμού (η F# συχνά πιστώνεται ότι πρωτοστάτησε στην υιοθέτησή τους).

Η βασική ιδέα είναι να ξεκινήσεις με κάποια δεδομένα και μετά να τα διοχετεύσεις μέσα από μια σειρά συναρτήσεων για να πάρεις το αποτέλεσμα.

Ο τελεστής διοχέτευσης είναι ο `|>` (όπως στην F# και σε πρόσφατες εκδόσεις της R), αν και η Julia έχει επίσης μια παραλλαγή μετάδοσης, τον `.|>`.

```julia-repl
julia> ["my", "test", "strings"] .|> reverse .|> titlecase .|> first
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

Η εκτέλεση γίνεται τώρα αυστηρά από τα αριστερά προς τα δεξιά, με την έξοδο κάθε συνάρτησης να ρέει προς την κατεύθυνση του βέλους για να γίνει η είσοδος της επόμενης συνάρτησης.

## Περιορισμοί, παρακάμψεις και άλλες επιλογές

Δεν είναι καθόλου τυχαίο ότι οι συναρτήσεις που χρησιμοποιήθηκαν για να παρουσιάσουν τη σύνθεση και τη σωλήνωση δέχονται όλες ένα _μόνο_ όρισμα.

Κάποιες καθαρά συναρτησιακές γλώσσες διοχετεύουν το _πρώτο_ όρισμα σε μια συνάρτηση, αλλά επιτρέπουν να συμπεριληφθούν και άλλα.

Αντιθέτως, η Julia περιμένει μόνο _ονόματα_ συναρτήσεων (ή κάτι αντίστοιχο) σε μια σωλήνωση, χωρίς πρόσθετα ορίσματα.

Υπάρχουν σημαντικοί τεχνικοί λόγοι πίσω από αυτό (που σχετίζονται με το γεγονός ότι το [`currying`][currying] δεν αποτελεί βασικό μέρος του σχεδιασμού της γλώσσας).
Οι _πολλοί_ άνθρωποι που δεν καταλαβαίνουν το currying θα πρέπει απλώς να δεχτούν ότι αυτός ο περιορισμός δεν είναι αποτέλεσμα αμέλειας και δεν είναι πιθανό να αλλάξει σε μελλοντικές εκδόσεις της Julia.

### Παρακάμψεις

Χρειαζόμαστε συναρτήσεις με ένα μόνο όρισμα που κάνουν ό,τι χρειάζεται.
Ευτυχώς, ο ορισμός νέων συναρτήσεων στη Julia είναι εύκολος.

Με τον πιο απλό τρόπο, θα μπορούσαμε να χρησιμοποιήσουμε μια [`anonymous function`][anonymous-function].
Για παράδειγμα, αν έχουμε μία συμβολοσειρά εισόδου και θέλουμε να τη χωρίσουμε στις κάτω παύλες:

```julia-repl
julia> "my_test_strings" |> (s -> split(s, '_'))
3-element Vector{SubString{String}}:
 "my"
 "test"
 "strings"
```

Αυτό το διάνυσμα θα μπορούσε στη συνέχεια να διοχετευτεί σε άλλες συναρτήσεις, όπως και πριν.

Το να περικλείσεις την ανώνυμη συνάρτηση σε παρενθέσεις είναι προαιρετικό σε αυτή την περίπτωση, αλλά γενικότερα είναι ένας χρήσιμος τρόπος για να μειώσεις την ασάφεια.

Παρομοίως, θα μπορούσαμε να δημιουργήσουμε μια επώνυμη συνάρτηση, νωρίτερα στο πρόγραμμα, και να την επαναχρησιμοποιήσουμε όποτε χρειάζεται.
