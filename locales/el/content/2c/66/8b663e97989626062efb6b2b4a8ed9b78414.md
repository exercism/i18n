# Οδηγίες

Αναπτύσσεις ένα σύστημα που βοηθά το προσωπικό της ιστοσελίδας ενός ποδοσφαιρικού συλλόγου να συντάσσει αναφορές για τους αγώνες. Τα δεδομένα φτάνουν από διάφορες πηγές και, αφού καθαριστούν, διοχετεύονται σε ένα ενιαίο ρεύμα.

## 1. Εμφάνισε περιγραφές των παικτών με βάση τον αριθμό της φανέλας τους

Η ομάδα παίζει πάντα με σχηματισμό 4-3-3 και δεν αποδέχτηκε ποτέ την αλλαγή των κανόνων του 1965 που επέτρεψε τις αλλαγές παικτών, πόσο μάλλον τις διευρυμένες ομάδες.

Οι περιγραφές των παικτών είναι οι εξής:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Υλοποίησε τη στατική μέθοδο `FootballMatchReports.onField()` ώστε να εμφανίζει μια περιγραφή του παίκτη με βάση τον αριθμό της φανέλας του.

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. Εμφάνισε "invalid" αν ο αριθμός της φανέλας δεν είναι μέρος της επίσημης λίστας

Τροποποίησε τη μέθοδο `FootballMatchReports.onField()` ώστε να επιστρέφει "invalid" όταν επεξεργάζεται αριθμό φανέλας έξω από το εύρος 1-11.

```java
FootballMatchReports.onField(13);
// => "invalid"
```
