# Εντολές `case`

Όταν μία τιμή συγκρίνεται με μια λίστα από πιθανές τιμές, μια αλυσίδα από
`elsif` λέει το ίδιο πράγμα ξανά και ξανά:

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

Το `case` το λέει μία φορά:

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

Η τιμή μπαίνει μετά το `case`. Κάθε `when` δίνει μια τιμή με την οποία
συγκρίνεται, και εκτελείται το πρώτο που ταιριάζει.

## Πολλές τιμές σε ένα when

Ένα `when` μπορεί να απαριθμεί τιμές, χωρισμένες με κόμματα:

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

Αυτό δουλεύει με ακέραιους αριθμούς, χαρακτήρες και συμβολοσειρές, με
οτιδήποτε μπορεί να συγκριθεί με το `=`.

## Το else δεν είναι προαιρετικό

**Ένα `case` που δεν ταιριάζει με τίποτα και δεν έχει `else` είναι ένα
σφάλμα που σταματάει το πρόγραμμα όταν συμβεί.**

Αυτό είναι διαφορετικό από το `if`, όπου η παράλειψη του `else` σημαίνει
απλώς ότι δεν συμβαίνει τίποτα. Είναι επίσης διαφορετικό από τις
περισσότερες γλώσσες, όπου ένα `case` που δεν βρίσκει ταίριασμα δεν κάνει
τίποτα, σιωπηλά.

Έτσι, κάθε `case` χρειάζεται ένα `else`, ακόμα κι όταν είσαι σίγουρος ότι τα
`when` καλύπτουν ήδη κάθε τιμή. Αργότερα προστίθεται μια τέταρτη ζώνη, το
`case` δεν ενημερώνεται για να ταιριάζει, και το πρόγραμμα σταματάει στον
πρώτο επιβάτη που θα τη χρησιμοποιήσει.

## Μόνο ένα when εκτελείται

Όταν ένα `when` ταιριάζει, εκτελούνται οι εντολές μετά το `then` του και το
`case` τελειώνει: το πρόγραμμα συνεχίζει μετά το `end`. Τα `when` που
βρίσκονται από κάτω δεν εξετάζονται ποτέ, οπότε δεν χρειάζεται να γράψεις
τίποτα για να εμποδίσεις το επόμενο να εκτελεστεί κι αυτό.
