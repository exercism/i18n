# Υποδείξεις

## Γενικά

Θυμήσου, αυτό είναι ένα [MVP][mvp].
Αυτό σημαίνει ότι δεν χρειάζεται να το παρακάνεις με τη διαχείριση σφαλμάτων ή με διάφορα σενάρια "οριακών περιπτώσεων".
Δεν πειράζει να είσαι απλός και άμεσος στις συναρτήσεις που γράφεις.

Η ενότητα για τα λεξικά του [επίσημου οδηγού][dicts-docs] και η [επίσημη αναφορά της βιβλιοθήκης][mapping-types-dict] για τον τύπο αντιστοίχισης είναι εξαιρετικά σημεία για να βρεις περισσότερη βοήθεια με όλες αυτές τις μεθόδους.


## 1. Προσθήκη στοιχείων στο καλάθι αγορών του χρήστη

- Θα χρειαστεί να κάνεις επανάληψη σε κάθε στοιχείο του `items_to_add`.
- Μπορείς να αποφύγεις ένα `KeyError` όταν λείπει ένα κλειδί, χρησιμοποιώντας μια [μέθοδο][set-default] του `dict` που παίρνει μια _προεπιλεγμένη τιμή_ ως ένα από τα ορίσματά της.
- Μπορείς επίσης να κάνεις το ίδιο πράγμα χειροκίνητα μέσα στον `loop`, με κάποιον έλεγχο και διαχείριση σφαλμάτων, αλλά η μέθοδος του `dict` είναι πιο εύκολη.

## 2. Διάβασε τα στοιχεία που υπάρχουν στην εφαρμογή σημειώσεων του χρήστη

- Θυμήσου, η Python έχει μέθοδο για _τα πάντα_. Αυτή εδώ είναι μια _classmethod_ που αποτελεί έναν εύκολο τρόπο να [γεμίσεις ένα `dict`][fromkeys] με κλειδιά.
- Αυτή η μέθοδος του `dict` επιστρέφει ένα _νέο λεξικό_, γεμάτο με προεπιλεγμένες τιμές. Αν δεν δοθεί καμία τιμή, η προεπιλεγμένη τιμή θα γίνει `None`

## 3. Ενημέρωση της ενότητας "Ιδέες" της συνταγής

- Μην το πολυσκεφτείς!  Αυτό λύνεται με **μία** μόνο κλήση μεθόδου του `dict`.
- Η λέξη-κλειδί εδώ είναι .... [_update_][update].

## 4. Ταξινόμησε τα στοιχεία στο καλάθι του χρήστη

- Ποια μέθοδο θα καλέσεις για να πάρεις μια [προβολή των στοιχείων του λεξικού που μπορείς να διατρέξεις][items];
- Αν είχες μια `list` ή μια `tuple`, ποια συνάρτηση [`built-in`][builtins] θα μπορούσες να χρησιμοποιήσεις για να τις ταξινομήσεις;
- Η συνάρτηση `built-in` που θέλεις είναι αυτή που επιστρέφει ένα _αντίγραφο_ και δεν μεταβάλλει το αρχικό.

## 5. Στείλε το καλάθι αγορών του χρήστη στο κατάστημα για διεκπεραίωση

- Το να έχεις εδώ ένα καινούριο, άδειο λεξικό ως `fulfillment_cart` μπορεί να σου φανεί βολικό για να προσθέτεις στοιχεία.
- Το να περάσεις με `Looping` από τα μέλη του καλαθιού μπορεί να είναι ο πιο άμεσος τρόπος πρόσβασης εδώ.
- Ποια μέθοδο θα καλέσεις για να πάρεις μια [προβολή μόνο των κλειδιών του λεξικού που μπορείς να διατρέξεις][keys];
- Θυμήσου ότι μπορείς να πάρεις την `value` ενός κλειδιού χρησιμοποιώντας τη σύνταξη `<dict name>[<key_name>]`.
- Αν είχες μια `list` ή μια `tuple`, ποια συνάρτηση [`built-in`][builtins] θα μπορούσες να χρησιμοποιήσεις για να τις ταξινομήσεις;
- Θυμήσου ότι η συνάρτηση `built-in` μπορεί να πάρει ένα προαιρετικό όρισμα `reverse=True`.

## 6. Ενημέρωσε το απόθεμα του καταστήματος ώστε να αντικατοπτρίζει τι έχει παραγγείλει ο χρήστης.

- Υπάρχει μια μέθοδος που σου δίνει μια προβολή των ζευγών (`key`, `value`) του λεξικού που μπορείς να διατρέξεις.
- Μπορείς να προσπελάσεις ένα στοιχείο μέσα σε μια _εμφωλευμένη πλειάδα_ χρησιμοποιώντας _συμβολισμό αγκυλών_:  `<tuple>[<nested_tuple>][<index_of_value>]`
- Μην ξεχάσεις να ελέγξεις αν το απόθεμα πέσει στο μηδέν, θα χρειαστεί να προσθέσεις το μήνυμα "Out of Stock".
