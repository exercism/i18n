# Παράρτημα οδηγιών

## Υποδείξεις

Για να είναι η πρόκληση στο σωστό επίπεδο, καλό είναι να χρησιμοποιήσεις μόνο λειτουργικότητα που υπάρχει στο Prelude. Προσπάθησε να μη χρησιμοποιήσεις τα Data.List, Data.Char, Data.Bits ή Numeric.

Προσπάθησε να χρησιμοποιήσεις κατάλληλα τα seq, $! ή BangPatterns, ώστε η λύση να είναι αποδοτική.

Δε χρειάζεται να χειριστείς μην έγκυρα δεδομένα εισόδου.
