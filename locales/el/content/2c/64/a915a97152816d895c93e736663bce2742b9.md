# Εισαγωγή

Μια στατική επέκταση σου επιτρέπει να επεκτείνεις ψευδο-υπάρχοντες τύπους χωρίς να τροποποιείς τον πηγαίο κώδικά τους. Αυτό επιτυγχάνεται με τη χρήση της εντολής `using`. Οι στατικές επεκτάσεις μπορούν να αποτελέσουν ένα ισχυρό εργαλείο που σου επιτρέπει να εμπλουτίζεις τύπους χωρίς να τους αλλάζεις στην πραγματικότητα.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
