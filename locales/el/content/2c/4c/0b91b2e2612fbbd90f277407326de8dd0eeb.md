# Οδηγίες

Ως μελλοντική μάγισσα, η Elyse πρέπει να εξασκηθεί σε μερικά βασικά. Έχει μια στοίβα με κάρτες που θέλει να χειριστεί.

Για να τα κάνει λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10, ώστε η στοίβα με τις κάρτες της να μπορεί να αναπαρασταθεί από έναν εσωτερικό πίνακα αριθμών. Η θέση μιας συγκεκριμένης κάρτας αντιστοιχεί στη γραμμή του πίνακα. Αυτό σημαίνει ότι η γραμμή 1 αναφέρεται στην πρώτη κάρτα, η γραμμή 2 στη δεύτερη κάρτα, κ.ο.κ.

## 1. Πάρε μια κάρτα από τη στοίβα

Για να διαλέξεις μια κάρτα, επίστρεψε την κάρτα στη θέση `position` από τη στοίβα που δίνεται.

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(card) = get_Item( stack = stack
                       position = 3 ).   " card = 4
```

## 2. Άλλαξε μια κάρτα στη στοίβα

Κάνε έναν ταχυδακτυλουργικό κόλπο και αντάλλαξε την κάρτα στη θέση `position` με την κάρτα αντικατάστασης που δίνεται.
Επίστρεψε τη στοίβα που προκύπτει.

```abap
data(stack) = value #( ( 1 ) ( 2 ) ( 4 ) ( 1 ) ).
data(new_Stack) = set_Item( stack = stack
                            position = 3 
                            replacement = 6 ).   
" new_Stack = 1, 2, 6, 1
```

## 3. Βάλε μια κάρτα στην κορυφή της στοίβας

Κάνε μια κάρτα να εμφανιστεί βάζοντας μια νέα κάρτα στην κορυφή της στοίβας.
Επίστρεψε τη στοίβα που προκύπτει.

```abap
data(stack) = value #( ( 5 ) ( 9 ) ( 7 ) ( 1 ) ).
data(new_Stack) = insert_Item_at_Top( stack    = stack
                                      new_Card = 8 ).   
" new_Stack = 5, 9, 7, 1, 8
```

## 4. Αφαίρεσε μια κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας από τη στοίβα την κάρτα στη θέση `position` που δίνεται.
Επίστρεψε τη στοίβα που προκύπτει.

```abap
data(stack) = value #( ( 3 ) ( 2 ) ( 6 ) ( 4 ) ( 8 ) ).
data(new_Stack) = remove_Item( stack    = stack
                               position = 3 ).   
" new_Stack = 3, 2, 4, 8
```

## 5. Αφαίρεσε την πάνω κάρτα από τη στοίβα

Κάνε μια κάρτα να εξαφανιστεί αφαιρώντας την κάρτα στην κορυφή της στοίβας.
