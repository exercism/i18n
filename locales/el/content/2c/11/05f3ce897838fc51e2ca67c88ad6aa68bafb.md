# Σχετικά

## Boolean

Η PowerShell διαθέτει τον τύπο [`bool`][booleans] για να αναπαριστά τιμές Boolean (λογική τιμή): αληθείς και ψευδείς.
Σε αυτόν τον τύπο υπάρχουν μόνο δύο τιμές: `True` και `False`.
Μπορείς να αναθέσεις αυτές τις τιμές σε μεταβλητές με το πρόθεμα `$`:

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

Μπορούμε να χρησιμοποιήσουμε [λογικούς τελεστές][logical-operators] όπως `-and`, `-or` και `-not` για να συνδυάζουμε και να αξιολογούμε παραστάσεις Boolean.

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## Μετατροπή και ερμηνεία ως Boolean

Η PowerShell μπορεί να αντιμετωπίζει έμμεσα οποιονδήποτε τύπο ως Boolean.
Ωστόσο, μπορείς επίσης να χρησιμοποιήσεις τον επιταχυντή τύπου `[bool]` για ρητή μετατροπή.

Ακολουθούν μερικοί γενικοί κανόνες που χρησιμοποιεί η PowerShell για να μετατρέψει άλλους τύπους σε Boolean τιμές:

$false:
- Κενές συμβολοσειρές όπως `''` ή `""`
- Τιμές null όπως `$null`
- Αριθμητικός τύπος με τιμή μηδέν (0)

$true:
- Μη κενές συμβολοσειρές
- Στιγμιότυπα οποιουδήποτε άλλου τύπου που δεν είναι συλλογή

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

Για αναλυτικούς κανόνες σχετικά με τη μετατροπή Boolean τιμών από τύπους συλλογών, διάβασε [εδώ][collection-conversion].
