# Σχετικά

Η υπό συνθήκη εκτέλεση κώδικα μπορεί να γίνει με [εκφράσεις `if/elif/else`][conditional-expression]. Οι συνθήκες που χρησιμοποιούνται σε μια έκφραση `if/elif/else` πρέπει να είναι τύπου `bool`. Η F# δεν έχει την έννοια των _αληθοφανών_ τιμών.

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

Καθώς η `if/elif/else` είναι έκφραση, μπορεί να δεθεί με ένα όνομα ή να επιστραφεί από μια συνάρτηση.

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

Όλοι οι κλάδοι πρέπει να επιστρέφουν τον ίδιο τύπο. Διαφορετικά, προκύπτει σφάλμα μεταγλωττιστή:

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

Οι κλάδοι `else` και `elif` είναι προαιρετικοί, αλλά μόνο αν ο τύπος της έκφρασης που επιστρέφεται είναι [`unit`][unit-type].

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

Μια έκφραση `if/else` μπορεί επίσης να τοποθετηθεί σε μία μόνο γραμμή. Αυτό θα πρέπει να χρησιμοποιείται μόνο για απλές εκφράσεις `if`.

```fsharp
let y = if x > 5 then 10 else 20
```
