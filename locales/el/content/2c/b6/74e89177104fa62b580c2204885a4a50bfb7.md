# Προσθήκη στις οδηγίες

## Υλοποίηση

Για να γίνει πιο εύκολη η δοκιμή της, η λύση σου θα χρειαστεί να υλοποιήσει μια μέθοδο `Robot.forget` που καθαρίζει τυχόν κοινόχρηστη κατάσταση που μπορεί να υπάρχει για την παρακολούθηση διπλότυπων ονομάτων ρομπότ.

Μπόνους πόντοι αν αυτή η μέθοδος δεν χρειάζεται να κάνει τίποτα για τη λύση σου.
