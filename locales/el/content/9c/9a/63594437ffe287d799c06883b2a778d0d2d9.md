# Οδηγίες

Ο μετεωρολογικός σταθμός του Wellington θα αντικαταστήσει το χειροκίνητο σύστημα καταγραφής θερμοκρασίας με ένα νέο ψηφιακό.
Στο παλιό σύστημα, οι υπολογισμοί γίνονταν με το χέρι.
Στο νέο σύστημα, θα αυτοματοποιηθούν.
Οι υπολογισμοί περιλαμβάνουν τη μετατροπή της θερμοκρασίας από Κελσίου σε Φαρενάιτ και την εύρεση της μέσης θερμοκρασίας.
Το νέο σύστημα διαθέτει αισθητήρες για την καταγραφή δεδομένων θερμοκρασίας σε Κελσίου.

Ο μετεωρολογικός σταθμός του Wellington θέλει να τον βοηθήσεις με το νέο σύστημα.

## 1. Μετέτρεψε τη θερμοκρασία από Κελσίου σε Κέλβιν

Ο μετεωρολογικός σταθμός έχει μια ενότητα στην ιστοσελίδα του που προορίζεται για ερευνητές.
Οι ερευνητές ενδιαφέρονται για τη θερμοκρασία σε Κέλβιν.

Το Κέλβιν είναι μια μονάδα που χρησιμοποιείται για τη μέτρηση της θερμοκρασίας.
Βρίσκεται στην ίδια κλίμακα με το Κελσίου, αλλά με διαφορετικό σημείο εκκίνησης.
Το σημείο εκκίνησής του είναι το απόλυτο μηδέν, που είναι 0K (Κέλβιν) ή -273.15°C (Κελσίου).

Ακολουθεί ένας πίνακας που δείχνει τη μετατροπή μεταξύ Κελσίου και Κέλβιν:

| Κελσίου(°C) | Κέλβιν(K) |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

Ο μετεωρολογικός σταθμός θέλει να υλοποιήσεις μια μέθοδο που μετατρέπει μια θερμοκρασία από Κελσίου σε Κέλβιν.

Υλοποίησε τη μέθοδο `Temperature#to_kelvin` που δέχεται ένα όρισμα `celsius` και επιστρέφει τη θερμοκρασία σε Κέλβιν προσθέτοντας 273.15 στην τιμή του `celsius` που δίνεται.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Στρογγυλοποίησε τη θερμοκρασία

Ο αισθητήρας θερμοκρασίας του μετεωρολογικού σταθμού είναι ακριβής.
Μπορεί να μετρήσει τη θερμοκρασία με ακρίβεια 0.0001°C.
Ο μετεωρολογικός σταθμός θέλει να εμφανίζει τη θερμοκρασία στρογγυλοποιημένη στο 1 δεκαδικό ψηφίο, αφού οι περισσότεροι χρήστες δεν ενδιαφέρονται για αυτό το επίπεδο ακρίβειας.

Ο μετεωρολογικός σταθμός θέλει να υλοποιήσεις μια μέθοδο που στρογγυλοποιεί τη θερμοκρασία στο 1 δεκαδικό ψηφίο.

Υλοποίησε τη μέθοδο `Temperature#round` που δέχεται ένα όρισμα `celsius` και επιστρέφει τη θερμοκρασία στρογγυλοποιημένη στο 1 δεκαδικό ψηφίο.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Μετέτρεψε τη θερμοκρασία από Κελσίου σε Φαρενάιτ

Ο μετεωρολογικός σταθμός έχει μια ενότητα στην ιστοσελίδα του που προορίζεται για τουρίστες.
Οι τουρίστες ενδιαφέρονται για τη θερμοκρασία σε Φαρενάιτ.

Το Φαρενάιτ είναι μια μονάδα μέτρησης θερμοκρασίας.
Έχει διαφορετική κλίμακα από το Κελσίου.
Οι 0°C είναι 32°F, και 1 βαθμός Κελσίου ισούται με 1.8 βαθμούς Φαρενάιτ.

Ακολουθεί ένας πίνακας που δείχνει τη μετατροπή μεταξύ Κελσίου και Φαρενάιτ:

| Κελσίου(°C) | Φαρενάιτ(°F) |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148            |
| 0           | 32             |
| 100         | 212            |

Ο μετεωρολογικός σταθμός θέλει να υλοποιήσεις μια μέθοδο που μετατρέπει τη θερμοκρασία από Κελσίου σε Φαρενάιτ.

Υλοποίησε τη μέθοδο `Temperature#to_fahrenheit` που δέχεται ένα όρισμα `celsius` και επιστρέφει τη θερμοκρασία σε Φαρενάιτ ως ακέραιο.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Βρες πόσοι αισθητήρες λείπουν

Κατά την εγκατάσταση των αισθητήρων θερμοκρασίας, οι εργαζόμενοι συντήρησης συνειδητοποίησαν ότι έλειπαν κάποιοι αισθητήρες.
Κάθε μονάδα μέτρησης θερμοκρασίας απαιτεί τέσσερις αισθητήρες θερμοκρασίας.
Η ομάδα συντήρησης μέτρησε πόσους αισθητήρες είχε, αλλά χρειαζόταν να μάθει πόσοι έλειπαν.
Θα ήθελαν βοήθεια για να υπολογίσουν πόσους αισθητήρες πρέπει να αγοράσουν για να φτιάξουν άλλη μια πλήρη μονάδα μέτρησης θερμοκρασίας.

Υλοποίησε τη μέθοδο `Temperature#number_missing_sensors` που δέχεται ένα όρισμα `number_of_sensors` και επιστρέφει τον αριθμό των αισθητήρων που λείπουν.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
