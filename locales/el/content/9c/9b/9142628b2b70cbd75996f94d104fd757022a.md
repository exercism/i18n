# Υποδείξεις

## 1. Μετατόπισε πίσω τα bit
- Η Crystal έχει έναν [τελεστή][shifts] για μετατόπιση bit προς τα αριστερά.

## 2. Εφάρμοσε μια μάσκα bit
- Η Crystal έχει έναν [bitwise AND][binary] τελεστή. 

## 3. Θέσε μερικά bit
- Η Crystal έχει έναν [bitwise OR][binary] τελεστή.

## 4. Ανάστρεψε το XOR
- Ένα XOR μπορεί να αντιστραφεί εφαρμόζοντας XOR στην ίδια τιμή.
- Η Crystal έχει τελεστές για [bitwise NOT][not] και bitwise [XOR][xor].

[xor]: https://crystal-lang.org/reference/syntax_and_semantics/operators.html#binary
