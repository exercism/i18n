# Εισαγωγή

Ένας ορισμός τύπου δημιουργεί έναν νέο ονομασμένο τύπο, διακριτό από κάθε άλλο τύπο, ακόμη και από έναν που έχει τον ίδιο υποκείμενο τύπο.

## Ορισμός τύπων

Ένας ορισμός τύπου ξεκινά με τη λέξη-κλειδί `type`, ακολουθούμενη από το όνομα του νέου τύπου και τον υποκείμενο τύπο του:

```go
type File []bool
```

Το `File` εδώ αναφέρεται σε μία μόνο κάθετη στήλη σε μια σκακιέρα, που συνήθως σημειώνεται με τα γράμματα A έως H.
Κάθε τετράγωνο σε αυτή τη στήλη αντιπροσωπεύεται από μια τιμή Boolean που δηλώνει αν είναι κατειλημμένο ή όχι.
Τώρα που το `File` έχει οριστεί, μπορούμε να το χρησιμοποιήσουμε μέσα σε άλλους ορισμούς:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

Το `Chessboard` αντιστοιχίζει αναγνωριστικά στηλών σε τιμές `File`.
Κάθε `File` είναι ένα slice από Boolean που αντιπροσωπεύει τα τετράγωνα σε μία στήλη της σκακιέρας.
Χωρίς αυτούς τους ορισμούς τύπων, το `board` θα ήταν ένα `map[string][]bool`, που θα έκανε πιο δύσκολο να καταλάβουμε τι αντιπροσωπεύουμε.
