# Ενσωμάτωση κώδικα

Το `circus-acts` χρησιμοποιούσε το `<` για να δηλώσει ότι μια κλάση *μπορεί να κάνει* όσα περιγράφει μια αφηρημένη κλάση. Δεν έλεγε τίποτα για το πώς.

Το `include` είναι το άλλο μισό: παίρνει τον πραγματικό κώδικα από μια άλλη κλάση και βάζει ένα αντίγραφό του σε αυτήν.

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

Το `JAZZ_ROUTINE::count` είναι 8, χωρίς η `JAZZ_ROUTINE` να το αναφέρει πουθενά.

## Δύο ξεχωριστές αποφάσεις

Στις περισσότερες γλώσσες προγραμματισμού πάνε μαζί: ένα `extends` και κληροδοτεί τον κώδικα και κάνει την υποκλάση χρησιμοποιήσιμη όπου χρειάζεται η υπερκλάση. Η Sather τις κρατά χωριστά.

| Γραμμένο | Τι λέει |
| --- | --- |
| `class A < $B` | ένα `A` μπορεί να χρησιμοποιηθεί όπου χρειάζεται ένα `$B` |
| `class A is include B` | το `A` ξεκινά με ένα αντίγραφο του κώδικα του `B` |

Το ένα χωρίς το άλλο, ή και τα δύο. Η ενσωμάτωση μιας κλάσης **δεν** την κάνει υποτύπο: μετά το `include WARM_UP`, μια `JAZZ_ROUTINE` εξακολουθεί να μη μπορεί να χρησιμοποιηθεί όπου χρειάζεται μια `WARM_UP`, και τίποτα δεν προσποιείται το αντίθετο.

## Μετονομασία

Μια ρουτίνα που ενσωματώνεται μπορεί να μπει με διαφορετικό όνομα:

```sather
   include WARM_UP count -> warm_up_count;
```

Αρκετές χωρίζονται με κόμματα:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## Παράλειψη μιας ρουτίνας

Η μετονομασία σε *τίποτα* την αφήνει απ' έξω, κι έτσι την αντικαθιστάς:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

Το `count` έρχεται ως συνήθως· το `describe` όχι, οπότε το να γράψεις ένα εδώ δεν προκαλεί σύγκρουση. Χωρίς το `describe -> ;` ο μεταγλωττιστής θα αρνιόταν: δύο ρουτίνες με το ίδιο όνομα και τις ίδιες παραμέτρους σε μία κλάση είναι σφάλμα, και η Sather δεν θα μαντέψει ποια εννοούσες.

Αυτή είναι η διαφορά από την υπερκάλυψη στις περισσότερες γλώσσες: η αντικατάσταση δηλώνεται ρητά αντί να υπονοείται.
