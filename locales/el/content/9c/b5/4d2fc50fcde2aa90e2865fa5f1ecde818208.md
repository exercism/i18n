# Χρήση της τεκμηρίωσης ενότητας

[comment]: # (This error is raised when the submission lacks @moduledoc for the Module)

Συνιστάται να έχεις ένα χαρακτηριστικό [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) που να περιγράφει τον σκοπό της ενότητας.

- Η τεκμηρίωση είναι [πολίτης πρώτης κατηγορίας](https://hexdocs.pm/elixir/writing-documentation.html) στην Elixir. Η τεκμηρίωση της γλώσσας είναι σχεδιασμένη ώστε να διαβάζεται και να γράφεται εύκολα.
- Η σύνταξη Markdown υποστηρίζεται μέσα στα χαρακτηριστικά τεκμηρίωσης `@moduledoc` και `@doc`
