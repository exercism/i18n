# Εισαγωγή

Οι πίνακες είναι ο κύριος τύπος ακολουθίας σταθερού μήκους στη Factor και γράφονται
`{ … }`: μπορείς να αλλάξεις τα στοιχεία, αλλά όχι το μήκος. Τα λεξιλόγια `arrays`
και `sequences` μαζί σου δίνουν μικρούς κατασκευαστές που παίρνουν τιμές από τη
στοίβα, καθώς και καθημερινές λειτουργίες για συνένωση, αντιστροφή και
αναζήτηση στοιχείων.

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
