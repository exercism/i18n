# Εισαγωγή

Στη Go, κάθε μεταβλητή έχει μια τιμή.
Αν δηλώσεις μια μεταβλητή χωρίς να της εκχωρήσεις τιμή, αυτή παίρνει τη μηδενική τιμή του τύπου της.

Οι βασικοί τύποι, όπως το `bool`, οι αριθμητικοί τύποι και το `string`, έχουν ο καθένας μια σταθερή μηδενική τιμή:

| Τύπος                  | Μηδενική τιμή |
| ---------------------- | ------------- |
| bool                   | `false`       |
| int, int8, int64, κ.λπ. | `0`           |
| float32, float64       | `0`           |
| complex64, complex128  | `0+0i`        |
| string                 | `""`          |

Οι δείκτες, οι συναρτήσεις, οι διεπαφές, τα slice, τα κανάλια και τα map έχουν όλα μηδενική τιμή `nil`.

Οι πίνακες και τα struct δεν είναι ποτέ `nil`, επειδή κρατούν τα δεδομένα απευθείας, όχι μια αναφορά σε αυτά.
Κάθε στοιχείο ενός πίνακα και κάθε πεδίο ενός struct αρχικοποιείται στη μηδενική τιμή του δικού του τύπου.
Για παράδειγμα, το `var a [3]int` δημιουργεί τον πίνακα `[0, 0, 0]`.

## Δήλωση μηδενικών τιμών

Χρησιμοποίησε το `var` για μια δήλωση:

```go
var myBool bool   // false
var mySlice []int // nil
```

Χρησιμοποίησε ένα σύνθετο literal `T{}` για τα struct:

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
