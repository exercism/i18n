# Ξεκινώντας

Καλώς ήρθες στο Exercism!

Υπάρχουν πάρα πολλά πράγματα να κάνεις στο Exercism, με τις βασικές επιλογές να είναι:

- Να αποκτήσεις ευχέρεια σε μία από τις 50+ γλώσσες προγραμματισμού
- Να καθοδηγήσεις μαθητές και να τους βοηθήσεις να βελτιώσουν την ευχέρειά τους
- Να βοηθήσεις στο χτίσιμο του Exercism

## Μάθε μια γλώσσα προγραμματισμού

Ο βασικός στόχος του Exercism είναι να βοηθά τους ανθρώπους να αποκτήσουν ευχέρεια στη γλώσσα προγραμματισμού που επιλέγουν.
Το Exercism σε βοηθά να αποκτήσεις μεγαλύτερη ευχέρεια σε μια γλώσσα προγραμματισμού λύνοντας ασκήσεις.

Υπάρχουν πάνω από 50 γλώσσες προγραμματισμού για να διαλέξεις, με τεράστια ποικιλία.
Για να ξεκινήσεις να μαθαίνεις μια γλώσσα προγραμματισμού, βρες πρώτα τη γλώσσα που θέλεις να μάθεις στη [σελίδα των διαδρομών](/tracks).

Όταν αποφασίσεις ποια γλώσσα θέλεις, πήγαινε στη σελίδα της διαδρομής της και γράψου στη διαδρομή.
Αφού γραφτείς σε μια διαδρομή, θα μπορείς αμέσως να ξεκινήσεις να [λύνεις ασκήσεις](/docs/using/solving-exercises).

Ολοκληρώνοντας ασκήσεις (δηλαδή: γράφοντας μια υλοποίηση που περνά όλα τα τεστ) θα αποκτάς πρόσβαση σε ακόμα περισσότερες ασκήσεις, βελτιώνοντας την ευχέρειά σου στην πορεία.
Η σελίδα [ξεκλείδωμα ασκήσεων](/docs/building/product/unlocking-exercises) έχει περισσότερες πληροφορίες για το πώς ξεκλειδώνεις ασκήσεις.

Αν κολλήσεις ποτέ σε μια άσκηση, μπορείς να ζητήσεις βοήθεια από έναν μέντορα.
Ένας μέντορας θα ξεκινήσει τότε μια συζήτηση μαζί σου για να σε βοηθήσει να ξεκολλήσεις.

Καλή διασκέδαση στη μάθηση!

## Καθοδήγησε μαθητές

Θέλεις να βοηθήσεις να μοιραστείς τις γνώσεις σου με άλλους;
Τότε η [καθοδήγηση](/mentoring) είναι ό,τι πρέπει για σένα!

Η καθοδήγηση είναι ένας διασκεδαστικός και ανταποδοτικός τρόπος να ενισχύσεις τη δική σου μάθηση, βοηθώντας παράλληλα άλλους να μάθουν και να ανακαλύψουν πράγματα που δεν ξέρουν.
Η καθοδήγηση σου αποφέρει επίσης [φήμη](/docs/using/product/reputation).

Δεν είσαι σίγουρος ότι μπορείς να καθοδηγήσεις αποτελεσματικά;
Κάποιοι από τους καλύτερους μέντορές μας ανησυχούσαν κι εκείνοι.

Ενδιαφέρεσαι να γίνεις μέντορας;
Ρίξε μια ματιά στη [σελίδα καθοδήγησης](/mentoring) για οδηγίες σχετικά με το πώς να γίνεις μέντορας.

## Χτίσε το Exercism

Το Exercism είναι ένα έργο ανοιχτού κώδικα, μη κερδοσκοπικό, που το χτίζουν άνθρωποι κάθε υπόβαθρου.
Με πάνω από εκατό αφοσιωμένους συντηρητές και χιλιάδες συνεισφέροντες, ο στόχος μας είναι να φτιάξουμε την καλύτερη, δωρεάν πλατφόρμα εκμάθησης προγραμματισμού στον ιστό.

Θέλεις να βοηθήσεις στο χτίσιμο του Exercism;
Η [σελίδα συνεισφοράς](/contributing) περιέχει μια επισκόπηση των διάφορων εργασιών με τις οποίες μπορείς να ασχοληθείς.
Έχουμε μεγάλη ποικιλία εργασιών, σε μέγεθος από ασήμαντες μέχρι τεράστιες.

Δεν έχεις συνεισφέρει ποτέ σε έργο ανοιχτού κώδικα;
Θα σε βοηθήσουμε να υποβάλεις το πρώτο σου pull request.

Έγινε merge στη συνεισφορά σου; Τέλεια!
Θα αναφέρεσαι ως συνεισφέρων στον ιστότοπο.
Κάθε συνεισφορά σου αποφέρει επίσης [φήμη](/docs/using/product/reputation).
