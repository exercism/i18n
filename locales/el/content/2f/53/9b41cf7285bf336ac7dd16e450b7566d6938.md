# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                                              |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | είσοδος   | διεύθυνση | συμβολοσειρά εισόδου τερματιζόμενη με null             |
| `$v0`    | έξοδος    | boolean | εγκυρότητα της συμβολοσειράς εισόδου (`0` = `false`, `1` = `true`) |
| `$t0-9`  | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση               |
