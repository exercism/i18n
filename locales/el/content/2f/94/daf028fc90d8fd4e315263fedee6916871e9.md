# Προσθήκη στις οδηγίες

## Μορφή του ταμπλό

Το ταμπλό αναπαρίσταται ως συμβολοσειρά με τερματισμό null και με έναν χαρακτήρα αλλαγής γραμμής στο τέλος κάθε γραμμής.

Ένα παράδειγμα θα ήταν `"X  \n XO\nOX \n"`

## Καταχωρητές

| Καταχωρητής | Χρήση       | Τύπος    | Περιγραφή                                                              |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | είσοδος        | διεύθυνση | συμβολοσειρά εισόδου με τερματισμό null                                            |
| `$v0`    | έξοδος       | ακέραιος | κατάσταση παιχνιδιού (`1` = `ongoing`, `2` = `draw`, `3` = `win`, `-1` = `error`) |
| `$t0-9`  | προσωρινός    | οτιδήποτε     | για προσωρινή αποθήκευση                                                   |
