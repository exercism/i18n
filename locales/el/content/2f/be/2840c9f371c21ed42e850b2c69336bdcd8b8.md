# Εισαγωγή

## Συμβολοσειρές

Μια `string` στη C# είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.). Με τα διπλά εισαγωγικά ορίζεις ένα στιγμιότυπο `string`:

```csharp
string fruit = "Apple";
```

### Μέθοδοι

Τις συμβολοσειρές τις χειρίζεσαι καλώντας τις [ενσωματωμένες μεθόδους][docs-string-methods] τους.
Για παράδειγμα, για να αφαιρέσεις τα κενά από μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τη [μέθοδο Trim][tutorial-docs.microsoft.com-trim-white-space] έτσι:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί να αλλάξει ποτέ.
Όποια μέθοδος φαίνεται να τροποποιεί μια συμβολοσειρά, στην πραγματικότητα επιστρέφει μια νέα συμβολοσειρά.

### Συνένωση

Πολλές συμβολοσειρές μπορούν να συνενωθούν (να προστεθούν) μεταξύ τους. Ο πιο απλός τρόπος να το κάνεις αυτό είναι να χρησιμοποιήσεις τον τελεστή `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Μορφοποίηση

Για οποιαδήποτε μορφοποίηση συμβολοσειράς πιο σύνθετη από την απλή συνένωση, προτιμάται η παρεμβολή συμβολοσειρών. Για να χρησιμοποιήσεις παρεμβολή σε μια συμβολοσειρά, βάλε μπροστά της το σύμβολο του δολαρίου (`$`). Έπειτα μπορείς να χρησιμοποιήσεις άγκιστρα (`{}`) για να προσπελάσεις οποιεσδήποτε μεταβλητές μέσα στη συμβολοσειρά σου.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
