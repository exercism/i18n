# Test Runners

Ένα Test Runner είναι ένα πρόγραμμα που τρέχει τα tests μιας άσκησης πάνω στον κώδικα ενός μαθητή.

Τα Test Runners μας δίνουν δύο πλεονεκτήματα:

1. Επιτρέπουν τον προγραμματισμό μέσα στον browser, όπου ο μαθητής μπορεί να δουλεύει πάνω σε μια λύση βλέποντας αν τα tests περνούν ή αποτυγχάνουν.
2. Μας επιτρέπουν να δίνουμε στους μέντορες πληροφορίες για το αν ο κώδικας ενός μαθητή "δουλεύει" ή όχι.

## Συνεισφορά στα Test Runners

Κάθε γλώσσα έχει το δικό της Test Runner, γραμμένο σε αυτή τη γλώσσα.
Η ιστοσελίδα λειτουργεί ως ο ενορχηστρωτής ανάμεσα στα Test Runners και τις υποβολές των μαθητών.

Κάθε Test Runner βρίσκεται στον οργανισμό Exercism στο GitHub, σε ένα αποθετήριο με όνομα `<track_slug>-test-runner` (π.χ. [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Μπορείς να δεις τα υπάρχοντα Test Runners [εδώ](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Αν θέλεις να βοηθήσεις σε ένα υπάρχον Test Runner, άνοιξε ένα issue στο αποθετήριό του ρωτώντας αν υπάρχει κάπου που μπορείς να βοηθήσεις.
Αν θέλεις να δημιουργήσεις ένα Test Runner για μια γλώσσα που δεν έχει ακόμα, ακολούθησε τις οδηγίες για τη [δημιουργία ενός Test Runner](/docs/building/tooling/test-runners/creating-from-scratch).
