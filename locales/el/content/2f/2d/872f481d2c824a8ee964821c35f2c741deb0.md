# χωρίς βρόχους

Ο τελεστής βρόχου δεν χρειάζεται.
Χρησιμοποίησε [προεπιλεγμένες τιμές παραμέτρων](https://docs.scala-lang.org/tour/default-parameter-values.html) και [παρεμβολή συμβολοσειρών](https://docs.scala-lang.org/overviews/core/string-interpolation.html) για να δημιουργήσεις δυναμικά τη συμβολοσειρά επιστροφής.
