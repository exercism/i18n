# Εισαγωγή

Η C είναι μια γλώσσα με στατική τυποποίηση, που σημαίνει ότι τα πάντα έχουν τύπο κατά τον χρόνο μεταγλώττισης.
Η επιλογή ενός ονόματος για μια μεταβλητή και ο καθορισμός του τύπου της ονομάζεται δήλωση μεταβλητής.

Μια μεταβλητή δηλώνεται με τον ρητό προσδιορισμό του τύπου της.
Το όνομα μιας μεταβλητής πρέπει να ξεκινά με ένα γράμμα ή με μια κάτω παύλα.
Κάποια ονόματα δεν μπορούν να χρησιμοποιηθούν, γιατί είναι δεσμευμένα [για λέξεις-κλειδιά][reserved-keywords] ή [για άλλα αναγνωριστικά][reserved-identifiers].

Ο καθορισμός ή η ενημέρωση της μεταβλητής γίνεται μέσω εκχώρησης.
Ο καθορισμός της τιμής ορίζει αυτή τη μεταβλητή.
Ο ορισμός της μεταβλητής είναι επίσης γνωστός ως αρχικοποίηση.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

Η τιμή μιας μεταβλητής μπορεί να εκχωρηθεί και να ενημερωθεί χρησιμοποιώντας τον απλό τελεστή εκχώρησης `=`.
Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

Η C είναι μια προστακτική, διαδικαστική γλώσσα.
Όλοι οι υπολογισμοί εκτελούνται ως μέρος μιας σειράς εντολών που ανήκουν σε μια συνάρτηση ή σε πολλές συναρτήσεις.

Κάθε συνάρτηση μπορεί να έχει μηδέν ή περισσότερες παραμέτρους.
Όταν ορίζεις μια συνάρτηση, τόσο όλες οι παράμετροι όσο και η τιμή επιστροφής πρέπει να έχουν ρητά δηλωμένο τύπο.
Οι τιμές επιστρέφονται από τις συναρτήσεις χρησιμοποιώντας τη λέξη-κλειδί `return`.
Οι συναρτήσεις έχουν από προεπιλογή εξωτερική κλάση αποθήκευσης, που σημαίνει ότι υπάρχει για όλη τη διάρκεια ζωής του προγράμματος και μπορεί να είναι ορατή εξωτερικά του αρχείου.
Για να το αποτρέψεις αυτό, μπορείς να προσθέσεις τη λέξη-κλειδί `static` ώστε να προσδιορίσεις εσωτερική ορατότητα.

```c
static int add(int x, int y) {
  return x + y;
}
```

Στο παραπάνω παράδειγμα, οι μεταβλητές `x` και `y` μπορούν να χρησιμοποιηθούν μόνο μέσα στη συνάρτηση, δηλαδή έχουν εμβέλεια συνάρτησης.
Η εμβέλεια είναι η ιδέα ότι η τιμή που σχετίζεται με ένα όνομα (ενός στοιχείου προγράμματος) είναι προσβάσιμη μόνο μέσα στη "περιοχή" κώδικα όπου ορίζεται.
Οι κυριότερες περιοχές κώδικα στη C είναι:

- αρχείο
- συνάρτηση
- μπλοκ (όπως μέσα σε βρόχους και σε άλλες δομές)

Οι συναρτήσεις καλούνται προσδιορίζοντας το όνομα της συνάρτησης και περνώντας ορίσματα για κάθε παράμετρο της συνάρτησης.

```c
int sum = add(1, 2);
```

Η C υποστηρίζει δύο τύπους σχολίων.
Τα σχόλια μίας γραμμής προηγούνται από `//` (από τη C99) και τα σχόλια πολλών γραμμών εισάγονται μεταξύ `/*` και `*/`.

[reserved-keywords]: https://en.cppreference.com/w/c/keyword
[reserved-identifiers]: https://en.cppreference.com/w/c/language/identifier
