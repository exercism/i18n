# Εισαγωγή

Θυμήσου από την ενότητα Fundamentals ότι ένα πρόγραμμα AWK αποτελείται από **ζεύγη μοτίβου-ενέργειας**.

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## Τι εννοούμε με τον όρο "μοτίβο";

Το "μοτίβο" είναι οποιαδήποτε έκφραση AWK.
Το αν το αποτέλεσμα της έκφρασης είναι αληθές καθορίζει αν θα εκτελεστεί η ενέργεια.

## Το Κενό Μοτίβο

Το μοτίβο μπορεί να παραλειφθεί.
Σε αυτή την περίπτωση, η ενέργεια εκτελείται για κάθε καταγραφή.

Μπορούμε να εκτυπώσουμε όλα τα ονόματα χρηστών στο αρχείο passwd.

```sh
awk -F: '{print $1}' /etc/passwd
```

## Κανονικές Εκφράσεις

Το AWK μπορεί να συγκρίνει συμβολοσειρές με κανονικές εκφράσεις για να πάρει ένα λογικό αποτέλεσμα.

Χρησιμοποίησε τον τελεστή αντιστοίχισης κανονικών εκφράσεων `~` για να αντιστοιχίσεις ένα συγκεκριμένο πεδίο.
Αυτός ο τελεστής παίρνει μια συμβολοσειρά ως αριστερό τελεστέο και μια κανονική έκφραση ως δεξιό τελεστέο.
Το κυριολεκτικό μιας κανονικής έκφρασης περικλείεται ανάμεσα σε κάθετες `/`.

Για να βρεις τους χρήστες στο αρχείο passwd που συνδέονται με bash:

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

Το `!~` είναι ο τελεστής "η κανονική έκφραση **δεν** αντιστοιχεί".

Για να αντιστοιχίσεις μια κανονική έκφραση με την τρέχουσα καταγραφή, μπορείς να γράψεις `$0 ~ /regex/`.
Αυτό είναι τόσο συνηθισμένο που υπάρχει συντομογραφία: μπορείς να παραλείψεις το `$0` και το `~` και να γράψεις απλώς `/regex/`.

```sh
awk '/regex/' data.txt
```

~~~~exercism/note
Σύγκρινε αυτή τη μονόγραμμη εντολή AWK με την αντίστοιχη εντολή grep

```sh
grep 'regex' data.txt
```

Το AWK σου δίνει μια ολόκληρη γλώσσα προγραμματισμού χωρίς να θυσιάζεις τη συντομία.
~~~~

Θα δούμε περισσότερα για την παραλλαγή κανονικών εκφράσεων του GNU AWK σε επόμενη ενότητα.

## Εκφράσεις

Οι εκφράσεις AWK (αριθμητικές, λογικές ή άλλες) μπορούν να χρησιμοποιηθούν ως μοτίβα.

Για να εξαγάγεις όλους τους χρήστες με UID 1000 ή παραπάνω:

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

Θυμήσου ότι οι ψευδείς τιμές του AWK είναι ο αριθμός μηδέν και η κενή συμβολοσειρά, και όλοι οι άλλοι αριθμοί ή συμβολοσειρές είναι αληθείς.
Οποιαδήποτε έκφραση που αποτιμάται σε έναν αριθμό ή μια συμβολοσειρά μπορεί να χρησιμοποιηθεί ως μοτίβο.

## Συναρτήσεις

Οποιαδήποτε συνάρτηση [ενσωματωμένη][builtins] ή [ορισμένη από τον χρήστη][user-defined] μπορεί να χρησιμοποιηθεί σε μια έκφραση, άρα και στο μοτίβο.
Δύο παραδείγματα:

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## Σταθερά Μοτίβα

Ένα συνηθισμένο ιδίωμα του AWK είναι:

```sh
{
    xyz()   # some code that transforms each record
}
1
```

Το `1` είναι ένα αληθές μοτίβο χωρίς σχετιζόμενη ενέργεια.
Αυτό σημαίνει "εκτύπωσε την τρέχουσα καταγραφή".
