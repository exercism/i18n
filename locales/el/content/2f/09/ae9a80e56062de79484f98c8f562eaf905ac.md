# Σχετικά

Το κύριο αντικειμενοστρεφές δομικό στοιχείο στη C# είναι η _κλάση_, που είναι συνδυασμός δεδομένων ([_πεδίων_][fields]) και συμπεριφοράς ([_μεθόδων_][methods]). Τα πεδία και οι μέθοδοι μιας κλάσης είναι γνωστά ως _μέλη_ της.

Η πρόσβαση στα μέλη μπορεί να περιοριστεί μέσω προσδιοριστών πρόσβασης, με τους δύο πιο συνηθισμένους να είναι:

- [`public`][public]: το μέλος είναι προσβάσιμο από οποιονδήποτε κώδικα (χωρίς περιορισμούς).
- [`private`][private]: το μέλος είναι προσβάσιμο μόνο από κώδικα στην ίδια κλάση.

Είναι σύνηθες να καθορίζεται ένας προσδιοριστής πρόσβασης για όλα τα μέλη. Αν δεν καθοριστεί προσδιοριστής πρόσβασης, από προεπιλογή θα είναι `private`.

Η παραπάνω ομαδοποίηση σχετιζόμενων δεδομένων και συμπεριφοράς μαζί με τον περιορισμό της πρόσβασης στα μέλη είναι γνωστή ως [ενθυλάκωση][encapsulation], που είναι μία από τις βασικές αντικειμενοστρεφείς έννοιες.

Ο συνδυασμός των τιμών των πεδίων ενός αντικειμένου σε μια δεδομένη στιγμή είναι γνωστός ως [κατάσταση][object-state] του αντικειμένου.

Μπορείς να σκεφτείς μια κλάση ως ένα πρότυπο για τη δημιουργία στιγμιοτύπων αυτής της κλάσης. Για να [δημιουργήσεις ένα στιγμιότυπο μιας κλάσης][creating-objects] (γνωστό και ως _αντικείμενο_), χρησιμοποιείται η [`new` λέξη-κλειδί][new]:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Τα [πεδία][fields] έχουν τύπο και μπορούν να οριστούν οπουδήποτε μέσα σε μια κλάση.
Τα δημόσια πεδία ορίζονται σε [PascalCase][pascal-case] και τα ιδιωτικά πεδία ορίζονται σε [camelCase][camel-case] και έχουν πρόθεμα την κάτω παύλα `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Μπορείς προαιρετικά να αντιστοιχίσεις μια αρχική τιμή σε ένα πεδίο. Αν ένα πεδίο _δεν_ καθορίζει αρχική τιμή, θα οριστεί στην [προεπιλεγμένη τιμή][default-values] του τύπου του. Οι τιμές των πεδίων ενός στιγμιοτύπου μπορούν να προσπελαστούν και να ενημερωθούν χρησιμοποιώντας τη σημειογραφία με τελείες.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Τα ιδιωτικά πεδία συνήθως ενημερώνονται ως παρενέργεια της κλήσης μιας μεθόδου. Τέτοιες μέθοδοι συνήθως δεν επιστρέφουν κάποια τιμή, οπότε ο τύπος επιστροφής θα πρέπει να είναι [`void`][void]:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

Σημείωσε ότι δεν είναι σύνηθες να χρησιμοποιούνται δημόσια πεδία σε κλάσεις C#. Χρησιμοποιούνται είτε ιδιωτικά πεδία είτε άλλοι τύποι μελών που θα συζητηθούν σε επόμενες ασκήσεις.

Μέσα σε μια κλάση, η [`this` λέξη-κλειδί][this] αναφέρεται στην τρέχουσα κλάση. Αυτό είναι ιδιαίτερα χρήσιμο αν μια παράμετρος έχει το ίδιο όνομα με ένα πεδίο:

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

Η δομή κλάσης και μεθόδων παρέχει έναν φυσικό τρόπο να περιορίζεται η ορατότητα στοιχείων του προγράμματος όπως πεδία και μέθοδοι και να αποφεύγεται το γνωστό [πρόβλημα της καθολικής κατάστασης][so-global-state-problem]. Τα δημόσια πεδία, οι μέθοδοι και άλλα μέλη πρέπει να προσδιορίζονται με το όνομα του αντικειμένου, `object.field` ή `object.method()`, (το όνομα της κλάσης στην περίπτωση στατικών) για να είναι ορατά από κώδικα έξω από την κλάση. Οι μεταβλητές και οι παράμετροι που δηλώνονται μέσα σε μια μέθοδο είναι ορατές μόνο μέσα σε αυτή τη μέθοδο.

Κάτι για το οποίο πρέπει να είσαι προσεκτικός με αυτή την προσέγγιση είναι ότι αν το όνομα ενός πεδίου και το όνομα μιας μεταβλητής ή παραμέτρου σε μια μέθοδο είναι ίδια, τότε το όνομα του πεδίου θα αγνοηθεί από τον κώδικα μέσα στη μέθοδο, κάτι που μπορεί να μην είναι αυτό που θέλεις. Γενικά, θα πρέπει να το αποφεύγεις όπου είναι δυνατόν, αν και είναι ένα συνηθισμένο μοτίβο στους κατασκευαστές. Αν είναι κατάλληλο το όνομα του πεδίου και της μεταβλητής να είναι το ίδιο, τότε προσδιόρισε το όνομα του πεδίου με τη λέξη-κλειδί `this` μέσα στη μέθοδο.

Αυτοί οι [προσδιοριστές πρόσβασης][access-modifiers] μπορούν να χρησιμοποιηθούν για να περιορίσουν περαιτέρω την ορατότητα.
