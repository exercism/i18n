# Υποδείξεις

## Γενικά

- Διάβασε για τη συμπεριφορά [`Access`][access-behaviour] στην τεκμηρίωση.

## 1. Εξαγωγή δεδομένων από μια εμφωλευμένη δομή map

- Πρώτα κάνε tokenize τη διαδρομή της συμβολοσειράς σε μια κατάλληλη μορφή. Μπορείς να χρησιμοποιήσεις [συναρτήσεις της μονάδας `String`][string-module].
- Γράψε μια αναδρομική συνάρτηση που διατρέχει την εμφωλευμένη δομή map για να ανακτήσει την τιμή ή να επιστρέψει `nil`.

## 2. Αναδιαμόρφωση με τις ενσωματωμένες συναρτήσεις

- Διάβασε τις διάφορες [συναρτήσεις της μονάδας `Kernel`][kernel-module], για να βρεις κάποια που μπορεί να συντομεύσει ή να απλοποιήσει την προσέγγισή σου.

[kernel-module]: https://hexdocs.pm/elixir/Kernel.html#functions
[string-module]: https://hexdocs.pm/elixir/String.html#functions
[access-behaviour]: https://hexdocs.pm/elixir/Access.html
