# Επιλογή testing framework

Όλες οι ασκήσεις βασίζονται στο να παρέχεις μια σουίτα δοκιμών που αποτυγχάνει, ώστε να την τρέξει κάποιος και να την κάνει να περάσει, οπότε πρέπει να διαλέξουμε ένα testing framework.
Αν υπάρχουν πολλά διαθέσιμα testing frameworks, θα πρέπει να βρούμε ποιο ταιριάζει καλύτερα.

## Τι να λάβεις υπόψη

1. Ευκολία στο ξεκίνημα.
1. Υποστήριξη σε πολλαπλές πλατφόρμες (MacOS, Linux, Windows).

Για τους ανθρώπους που θα λύνουν τις ασκήσεις, είναι σημαντικό να μπορούν να ξεκινήσουν όσο το δυνατόν πιο γρήγορα.

Γενικά, προτιμάμε εργαλεία από τη βασική βιβλιοθήκη όταν υπάρχουν, και αν δεν υπάρχουν, στοχεύουμε σε μια βιβλιοθήκη τρίτων που χρησιμοποιείται ευρέως.
Αν έχεις να διαλέξεις ανάμεσα σε πολλές δημοφιλείς βιβλιοθήκες, σκέψου μερικούς παράγοντες:

- Είναι κάποια από αυτές πιο εύκολη στην εγκατάσταση;
- Είναι πιο εύκολο να βρεις βοήθεια ή υλικό για κάποια από αυτές;
- Είναι κάποια πιο απλή από την άλλη, είτε στη σύνταξη είτε στην έννοια;

Θυμήσου ότι όλες οι ασκήσεις του Exercism είναι από τη φύση τους πολύ μικρές, οπότε δεν χρειάζεται η πολυπλοκότητα που μερικές φορές απαιτούν τα πραγματικά έργα.

## Κατέγραψε τις αποφάσεις

Καθώς παίρνεις αυτές τις αποφάσεις, κατέγραψέ τες στο `README.md` του αποθετηρίου του track, για τους συνεισφέροντες και τους συντηρητές.
Ειδικότερα, όταν κάποιος υποβάλλει μια συνεισφορά που πάει κόντρα σε μία από αυτές τις αποφάσεις, είναι πολύ χρήσιμο να μπορείς να παραπέμψεις όχι μόνο στο συμπέρασμα, αλλά και σε λίγα λόγια για το γιατί πάρθηκε αυτή η απόφαση.
Έτσι γίνεται πιο εύκολο να αποφασίσεις αν θα κλείσεις απλώς το issue ή το pull request του συνεισφέροντα, ή αν ήρθε η ώρα να επανεκτιμήσεις την απόφαση με βάση νέες πληροφορίες.

Όσο πιο δύσκολη ήταν η απόφαση, τόσο πιο σημαντικό είναι να την καταγράψεις διεξοδικά.
(π.χ. Τι trade-offs σκέφτηκες; Τι έγειρε το ένστικτό σου προς τη μία ή την άλλη κατεύθυνση; Τι σφράγισε την απόφαση;)
