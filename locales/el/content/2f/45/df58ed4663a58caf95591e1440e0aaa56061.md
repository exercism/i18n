# Επαναχρησιμοποίησε κώδικα από την περιγραφή δύο παραμέτρων

Η μέθοδος `describe(Character, Destination)` θα πρέπει να επαναχρησιμοποιεί τη λογική που υλοποιείται στην `describe(Character, Destination, TravelMethod)` ή στις επιμέρους μεθόδους `describe(Character)`, `describe(Destination)`, `describe(TravelMethod)`.
Η επαναχρησιμοποίηση υπαρχουσών μεθόδων μπορεί να κάνει τον κώδικα πιο εύκολο στη συντήρηση.
