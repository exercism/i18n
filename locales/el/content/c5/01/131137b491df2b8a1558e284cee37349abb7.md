# Εισαγωγή

Η γλώσσα προγραμματισμού Java χρησιμοποιεί _εξαιρέσεις_ για να χειρίζεται σφάλματα και άλλα έκτακτα συμβάντα.

## Τι είναι μια εξαίρεση

Μια εξαίρεση είναι ένα συμβάν που λαμβάνει χώρα κατά την εκτέλεση ενός προγράμματος και διαταράσσει την κανονική ροή των εντολών.
Οι εξαιρέσεις πετιούνται ρητά στη Java, και η πράξη του πετάγματος μιας εξαίρεσης ονομάζεται _πέταγμα μιας εξαίρεσης_.
Η πράξη του χειρισμού μιας εξαίρεσης ονομάζεται _πιάσιμο μιας εξαίρεσης_.

Στη Java, όλες οι εξαιρέσεις είναι υποκλάσεις της κλάσης `Exception`, η οποία είναι με τη σειρά της υποκλάση του `Throwable`.

Η Java διακρίνει δύο τύπους εξαιρέσεων:

1. Ελεγχόμενες εξαιρέσεις
2. Μη ελεγχόμενες εξαιρέσεις

### Ελεγχόμενες εξαιρέσεις

Οι _ελεγχόμενες εξαιρέσεις_ είναι εξαιρετικές συνθήκες που μια εφαρμογή θα πρέπει να προβλέπει και να ανακάμπτει από αυτές.
Ένα παράδειγμα ελεγχόμενης εξαίρεσης είναι η `FileNotFoundException`, η οποία προκύπτει όταν μια μέθοδος προσπαθεί να διαβάσει ένα αρχείο που δεν υπάρχει.

Αυτός ο τύπος εξαίρεσης ελέγχεται κατά τη μεταγλώττιση: οι μέθοδοι που πετούν ελεγχόμενες εξαιρέσεις θα πρέπει να το δηλώνουν στην υπογραφή της μεθόδου τους, και ο κώδικας που καλεί μια μέθοδο που μπορεί να πετάξει μια ελεγχόμενη εξαίρεση απαιτείται να τη χειριστεί, αλλιώς ο κώδικας δεν θα μεταγλωττιστεί.

Όλες οι ελεγχόμενες εξαιρέσεις είναι υποκλάσεις της `Exception` που δεν επεκτείνουν την `RuntimeException`.

### Μη ελεγχόμενες εξαιρέσεις

Οι _μη ελεγχόμενες εξαιρέσεις_ είναι εξαιρετικές συνθήκες που μια εφαρμογή συνήθως δεν μπορεί να προβλέψει ούτε να ανακάμψει από αυτές.
Ένα παράδειγμα μη ελεγχόμενης εξαίρεσης είναι η `NullPointerException`, η οποία προκύπτει όταν μια μέθοδος περιμένει μια τιμή που δεν είναι null αλλά λαμβάνει `null`.

Αυτός ο τύπος εξαίρεσης δεν ελέγχεται κατά τη μεταγλώττιση: οι μέθοδοι που πετούν μη ελεγχόμενες εξαιρέσεις δεν απαιτείται να το δηλώνουν στην υπογραφή της μεθόδου τους, και ο κώδικας που καλεί μια μέθοδο που μπορεί να πετάξει μια μη ελεγχόμενη εξαίρεση δεν απαιτείται να τη χειριστεί.

Όλες οι μη ελεγχόμενες εξαιρέσεις κληρονομούν από την `RuntimeException`, η οποία είναι με τη σειρά της επέκταση της `Exception`.

## Πέταγμα εξαιρέσεων

Μια μέθοδος στη Java μπορεί να πετάξει μια εξαίρεση χρησιμοποιώντας την εντολή `throw`.

### Πέταγμα μιας ελεγχόμενης εξαίρεσης

Όταν πετάς μια ελεγχόμενη εξαίρεση από μια μέθοδο, απαιτείται να το δηλώσεις στην υπογραφή της μεθόδου χρησιμοποιώντας τη λέξη-κλειδί `throws`, όπως φαίνεται στο παρακάτω παράδειγμα.
Αυτό αναγκάζει τον κώδικα που καλεί να προβλέψει ότι μπορεί να πεταχτεί μια εξαίρεση και να τη χειριστεί ανάλογα.

```java
public class InsufficientBalanceException extends Exception {

}

public class BankAccount {
  public void withdraw(double amount) throws InsufficientBalanceException {
    if (balance < amount) {
      throw new InsufficientBalanceException();
    }

    // rest of the method implementation
  }
}
```

### Πέταγμα μιας μη ελεγχόμενης εξαίρεσης

Όταν πετάς μια μη ελεγχόμενη εξαίρεση από μια μέθοδο, δεν απαιτείται να το δηλώσεις στην υπογραφή της μεθόδου, αν και υποστηρίζεται.

```java
public class BankAccount {
  public void withdraw(double amount) {
    if (amount < 0) {
      throw new IllegalArgumentException("Cannot withdraw a negative amount");
    }

    // rest of the method implementation
  }
}
```

## Χειρισμός εξαιρέσεων

Ο χειρισμός εξαιρέσεων στη Java γίνεται με τις λέξεις-κλειδιά `try`, `catch` και `finally`.

- Οι εντολές κώδικα που μπορεί να πετάξουν μια εξαίρεση θα πρέπει να περικλείονται σε ένα μπλοκ `try`.
- Το μπλοκ `try` ακολουθείται από ένα ή περισσότερα μπλοκ `catch` που πιάνουν τις εξαιρέσεις που πετιούνται στο μπλοκ `try`.
- Τα μπλοκ `catch` ακολουθούνται προαιρετικά από ένα μπλοκ `finally` που εκτελείται πάντα μετά το μπλοκ `try`, ανεξάρτητα από το αν πετάχτηκε κάποια εξαίρεση ή όχι.

Το παρακάτω παράδειγμα δείχνει πώς λειτουργούν αυτές οι λέξεις-κλειδιά:

```java
public class ATM {
  public void withdraw(BankAccount bankAccount, double amount) {
    try {
      System.out.println("Withdrawing " + amount);
      bankAccount.withdraw(amount);
      System.out.println("Withdrawal succeeded");
    } catch (InsufficientBalanceException) {
      System.out.println("Withdrawal failed: insufficient balance");
    } catch (RuntimeException e) {
      System.out.println("Withdrawal failed: " + e.getMessage());
    } finally {
      System.out.println("Current balance: " + bankAccount.getBalance());
    }
  }
}
```

Σε αυτό το παράδειγμα, όταν δεν πετιέται καμία εξαίρεση, εκτυπώνεται το εξής:

```text
Withdrawing 10.0
Withdrawal succeeded
Current balance: 5.0
```

Ωστόσο, αν η εντολή `bankAccount.withdraw(amount)` πετάξει μια `InsufficientBalanceException`, εκτυπώνεται το εξής:

```text
Withdrawing 10.0
Withdrawal failed: insufficient balance
Current balance: 5.0
```

Ή, σε περίπτωση που πεταχτεί μια μη ελεγχόμενη εξαίρεση από την `bankAccount.withdraw(amount)`, εκτυπώνεται το εξής:

```text
Withdrawing -10.0
Withdrawal failed: Cannot withdraw a negative amount
Current balance: 5.0
```

## Σφάλματα

Η Java έχει επίσης μια ξεχωριστή κατηγορία που ονομάζεται _Σφάλματα_, τα οποία είναι σοβαρά προβλήματα εξωτερικά ως προς μια εφαρμογή.
Ένα παράδειγμα σφάλματος είναι το `OutOfMemoryError`, το οποίο προκύπτει όταν μια εφαρμογή προσπαθεί να χρησιμοποιήσει περισσότερη μνήμη από αυτή που είναι διαθέσιμη στο σύστημα.

Όπως οι μη ελεγχόμενες εξαιρέσεις, τα σφάλματα δεν ελέγχονται κατά τη μεταγλώττιση.
Η διαφορά είναι ότι αντιπροσωπεύουν προβλήματα σε επίπεδο συστήματος και συνήθως πετιούνται από την Εικονική Μηχανή Java ή το περιβάλλον αντί για την εφαρμογή.
Οι εφαρμογές γενικά δεν θα πρέπει να επιχειρούν να τα πιάσουν ή να τα χειριστούν.

Όλα τα σφάλματα στη Java κληρονομούν από την κλάση `Error`.
