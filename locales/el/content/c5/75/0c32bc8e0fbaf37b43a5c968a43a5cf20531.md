# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να αναλύσεις την παραγωγή μιας γραμμής συναρμολόγησης σε ένα εργοστάσιο αυτοκινήτων.
Η ταχύτητα της γραμμής συναρμολόγησης μπορεί να κυμαίνεται από `0` (εκτός λειτουργίας) έως `10` (μέγιστη).

Στην πιο αργή ταχύτητά της (`1`), παράγονται `221` αυτοκίνητα κάθε ώρα.
Η παραγωγή αυξάνεται γραμμικά με την ταχύτητα.
Έτσι, με την ταχύτητα στο `4`, θα πρέπει να παράγει `4 * 221 = 884` αυτοκίνητα την ώρα.
Ωστόσο, οι υψηλότερες ταχύτητες αυξάνουν την πιθανότητα να παραχθούν ελαττωματικά αυτοκίνητα, τα οποία μετά πρέπει να απορριφθούν.
Ο παρακάτω πίνακας δείχνει πώς η ταχύτητα επηρεάζει το ποσοστό επιτυχίας:

- Από `1` έως `4`: 100% ποσοστό επιτυχίας.
- Από `5` έως `8`: 90% ποσοστό επιτυχίας.
- `9`: 80% ποσοστό επιτυχίας.
- `10`: 77% ποσοστό επιτυχίας.

Έχεις δύο εργασίες.

## 1. Υπολόγισε τον ρυθμό παραγωγής ανά ώρα

Υλοποίησε τη μέθοδο `AssemblyLine#production_rate_per_hour` για να υπολογίσεις τον ρυθμό παραγωγής της γραμμής συναρμολόγησης ανά ώρα, λαμβάνοντας υπόψη το ποσοστό επιτυχίας της.
Σημείωσε ότι η τιμή που επιστρέφεται είναι ένα στιγμιότυπο της `Float`.

```ruby
AssemblyLine.new(6).production_rate_per_hour
#=> 1193.4
```

## 2. Υπολόγισε τον αριθμό των λειτουργικών προϊόντων που παράγονται ανά λεπτό

Υλοποίησε τη μέθοδο `AssemblyLine#working_items_per_minute` για να υπολογίσεις πόσα **ολοκληρωμένα, λειτουργικά αυτοκίνητα** παράγονται ανά λεπτό.
Σημείωσε ότι η τιμή που επιστρέφεται είναι ένα στιγμιότυπο της `Integer`.

```ruby
AssemblyLine.new(6).working_items_per_minute
#=> 19
```
