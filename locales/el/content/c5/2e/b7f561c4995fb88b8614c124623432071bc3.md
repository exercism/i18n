# Οδηγίες

Σε αυτή την άσκηση θα δημιουργείς ημιδομημένα μηνύματα καταγραφής.

## Παράγαγε ημιδομημένα μηνύματα

Θα ξεκινήσεις με μερικές κενές συναρτήσεις και το παρακάτω enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Ο στόχος σου είναι να παράγεις ένα μήνυμα καταγραφής ως εξής: `"[<LEVEL>]: <MESSAGE>"`.
Θα χρειαστεί να υλοποιήσεις συναρτήσεις που αντιστοιχούν στα επίπεδα καταγραφής.

Για παράδειγμα, το παρακάτω απόσπασμα δείχνει μια αναμενόμενη έξοδο για τη συνάρτηση `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Και για τη συνάρτηση `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

Καλή διασκέδαση!
