# Εισαγωγή

Η Common Lisp έχει πολλά διαφορετικά κατηγορήματα ισότητας.
Αυτό διαφέρει από άλλες γλώσσες προγραμματισμού που μπορεί να έχουν μόνο ένα ή δύο (για παράδειγμα, ίσως `==` και `===`).
Μερικά από αυτά τα κατηγορήματα στην Common Lisp είναι ειδικά για τύπους, ενώ άλλα είναι γενικά.
Με αυτά τα τελευταία θα ασχοληθούμε εδώ.

Υπάρχουν τέσσερα γενικά κατηγορήματα ισότητας και διαφέρουν ως προς την περιοριστικότητά τους στο τι θεωρούν "ίσο".
Είναι, με σειρά από το πιο περιοριστικό προς το λιγότερο περιοριστικό: `eq`, `eql`, `equal` και `equalp`.

Μια σύντομη σειρά ορισμών (παραλείποντας μερικές λεπτομέρειες) είναι η εξής:

- `eq`: ορίζει την ισότητα ως το ότι τα δύο αντικείμενα είναι πανομοιότυπα.
  _π.χ._:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: ορίζει την ισότητα ως εξής: δύο αριθμοί με τον ίδιο τύπο και την ίδια τιμή, δύο χαρακτήρες που είναι ίδιοι,
  ή για οτιδήποτε άλλο αν είναι `eq`.
  _π.χ._:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: ορίζει την ισότητα ως εξής: δύο λίστες είναι `equal` αν κάθε στοιχείο είναι επίσης `equal`· δύο συμβολοσειρές είναι `equal` αν κάθε στοιχείο είναι `eql`· δύο πίνακες είναι `equal` αν είναι `eq`· οτιδήποτε άλλο είναι `equal` αν είναι `eql`.
  _π.χ._:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: ορίζει την ισότητα ως εξής: οι συμβολοσειρές και οι χαρακτήρες συγκρίνονται χωρίς διάκριση πεζών-κεφαλαίων· οι αριθμοί συγκρίνονται με κάποια μετατροπή τύπου· οι λίστες και οι πίνακες είναι `equalp` αν κάθε στοιχείο είναι επίσης `equalp`, οι δομές αν είναι του ίδιου τύπου και όλα τα πεδία είναι `equalp` και οι πίνακες κατακερματισμού αν τα κλειδιά και οι τιμές τους είναι `equalp`
  _π.χ._:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
