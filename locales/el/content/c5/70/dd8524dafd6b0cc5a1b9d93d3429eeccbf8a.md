# Εισαγωγή

Οι βασικοί αριθμητικοί και συγκριτικοί τελεστές μπορούν να προσαρμοστούν για χρήση από τις δικές σου κλάσεις και δομές. Αυτό είναι γνωστό ως _υπερφόρτωση τελεστών_.

Οι περισσότεροι τελεστές έχουν τη μορφή:

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

Οι τελεστές μετατροπής έχουν τη μορφή:

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

Οι τελεστές συμπεριφέρονται με τον ίδιο τρόπο όπως οι στατικές μέθοδοι. Ένα σύμβολο τελεστή παίρνει τη θέση ενός αναγνωριστικού μεθόδου, και οι τελεστές έχουν παραμέτρους και τύπο επιστροφής. Οι κανόνες τύπων για παραμέτρους και τύπο επιστροφής ακολουθούν τη διαίσθησή σου και μπορείς να βασιστείς στον μεταγλωττιστή ότι θα παρέχει λεπτομερή καθοδήγηση.
