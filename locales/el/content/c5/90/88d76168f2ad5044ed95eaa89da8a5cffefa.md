# Οδηγίες

Ένα τοπικό σχολείο κοντά σου έχει έναν πολύ δραστήριο σύλλογο μαθητών.
Ο σύλλογος μαθητών διοικείται από έναν πρόεδρο και κάθε 2 χρόνια γίνονται εκλογές για την ανάδειξη νέου προέδρου.

Στις φετινές εκλογές, αποφασίστηκε ότι χρειαζόταν ένα νέο ψηφιακό σύστημα για την καταμέτρηση των ψήφων.
Το σχολείο χρειάζεται τη βοήθειά σου για να φτιαχτεί αυτό το νέο σύστημα.

## 1. Δημιούργησε έναν μετρητή ψήφων

Ένα από τα πρώτα πράγματα που χρειάζεται το νέο σύστημα ψηφοφορίας είναι ένας μετρητής ψήφων.
Αυτός ο μετρητής είναι ένας τρόπος να παρακολουθείς τις ψήφους που έχει ένας συγκεκριμένος υποψήφιος.

Δημιούργησε μια συνάρτηση `NewVoteCounter` που δέχεται τον αριθμό των αρχικών ψήφων ενός υποψηφίου και επιστρέφει έναν δείκτη που αναφέρεται σε ένα `int`, αρχικοποιημένο με τον δεδομένο αριθμό αρχικών ψήφων.

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. Πάρε τον αριθμό των ψήφων από έναν μετρητή

Τώρα έχεις έναν τρόπο να δημιουργείς νέους μετρητές! Αλλά τώρα συνειδητοποιείς ότι το νέο σύστημα θα χρειαστεί και έναν τρόπο να παίρνει τον αριθμό των ψήφων από έναν μετρητή.

Δημιούργησε μια συνάρτηση `VoteCount` που θα δέχεται έναν μετρητή (`*int`) ως όρισμα και θα επιστρέφει τον αριθμό των ψήφων στον μετρητή.
Αν ο μετρητής είναι `nil`, υπέθεσε ότι ο μετρητής δεν έχει ψήφους:

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. Αύξησε τις ψήφους ενός μετρητή

Επιτέλους ήρθε η ώρα να μετρήσεις τις ψήφους! Τώρα χρειάζεσαι έναν τρόπο να αυξάνεις τις ψήφους σε έναν μετρητή.

Δημιούργησε μια συνάρτηση `IncrementVoteCount` που θα δέχεται έναν μετρητή (`*int`) ως όρισμα και έναν αριθμό ψήφων, και θα αυξάνει τον μετρητή κατά αυτόν τον αριθμό ψήφων.
Μπορείς να υποθέσεις ότι ο δείκτης που περνάει δε θα είναι ποτέ `nil`.

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. Δημιούργησε τα αποτελέσματα των εκλογών

Με όλες τις ψήφους τώρα καταμετρημένες, ήρθε η ώρα να ετοιμάσεις την ανακοίνωση των αποτελεσμάτων σε όλο το σχολείο.
Για αυτό, παρατηρείς ότι το να έχεις μόνο μετρητές για τις ψήφους δεν αρκεί.
Χρειάζεται ένας τρόπος να συσχετίζεις τον αριθμό των ψήφων με έναν συγκεκριμένο υποψήφιο.

Δημιούργησε μια συνάρτηση `NewElectionResult` που δέχεται το όνομα ενός υποψηφίου και τον αριθμό των ψήφων του και
επιστρέφει ένα νέο αποτέλεσμα εκλογών.

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

Το struct του αποτελέσματος εκλογών έχει ήδη δημιουργηθεί για σένα και ορίζεται ως εξής:

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. Ανακοίνωσε τα αποτελέσματα

Ήρθε η ώρα να ανακοινώσεις τον νέο πρόεδρο στο σχολείο!
Ο πρόεδρος θα ανακοινωθεί στις μικρές ψηφιακές πινακίδες μηνυμάτων που έχει το σχολείο.
Το μήνυμα θα πρέπει να δείχνει το όνομα του νέου προέδρου και τις ψήφους που πήρε, στην εξής μορφή: `<candidate_name> (<votes>)`.
Αυτό είναι ένα παράδειγμα τέτοιου μηνύματος: `"Peter (51)"`.

Δημιούργησε μια συνάρτηση `DisplayResult` που θα δέχεται ένα `*ElectionResult` ως όρισμα και θα επιστρέφει μια συμβολοσειρά με το μήνυμα προς εμφάνιση.

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. Επανακαταμέτρηση ψήφων

Για να βεβαιωθούν ότι τα τελικά αποτελέσματα ήταν ακριβή, οι ψήφοι επανακαταμετρήθηκαν.
Στην επανακαταμέτρηση, βρέθηκε ότι ο αριθμός των ψήφων για κάποιους από τους υποψηφίους ήταν λάθος κατά ένα.

Δημιούργησε μια συνάρτηση `DecrementVotesOfCandidate` που δέχεται τα τελικά αποτελέσματα και το όνομα ενός υποψηφίου για τον οποίο θα πρέπει να μειώσεις τον αριθμό των ψήφων του.
Τα τελικά αποτελέσματα δίνονται με τη μορφή ενός `map[string]int`, όπου τα κλειδιά είναι τα ονόματα των υποψηφίων και οι τιμές είναι το σύνολο των ψήφων του καθενός.

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
