# Εισαγωγή

## Μετατροπή τύπων

Η Go απαιτεί ρητή μετατροπή μεταξύ διαφορετικών τύπων.
Η μετατροπή μεταξύ τύπων (γνωστή και ως **casting τύπων**) γίνεται μέσω μιας συνάρτησης με το όνομα του τύπου στον οποίο θέλεις να μετατρέψεις.
Για παράδειγμα, για να μετατρέψεις ένα `int` σε `float64`, θα χρειαστεί να κάνεις το εξής:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Μετατροπή μεταξύ πρωτογενών τύπων και συμβολοσειρών

Υπάρχει ένα πακέτο `strconv` για τη μετατροπή μεταξύ πρωτογενών τύπων (όπως `int`) και `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Ισχυρισμοί τύπων

Οι διεπαφές στη Go μπορούν να προκαλέσουν ασάφεια σχετικά με τον υποκείμενο τύπο.
Ένας ισχυρισμός τύπου μάς επιτρέπει να εξαγάγουμε τη συγκεκριμένη υποκείμενη τιμή μιας τιμής διεπαφής χρησιμοποιώντας αυτή τη σύνταξη: `interfaceVariable.(concreteType)`.

Για παράδειγμα:

```go
var input any = 12
number := input.(int)
```

ΣΗΜΕΙΩΣΗ: αυτό θα προκαλέσει panic αν η μεταβλητή διεπαφής δεν περιέχει τιμή του συγκεκριμένου τύπου.

Μπορούμε να ελέγξουμε αν μια τιμή διεπαφής περιέχει έναν συγκεκριμένο τύπο, αξιοποιώντας και τις δύο τιμές επιστροφής του ισχυρισμού τύπου: την υποκείμενη τιμή και μια λογική τιμή που αναφέρει αν ο ισχυρισμός πέτυχε.
Για παράδειγμα:

```go
str, ok := input.(string) // no panic if input is not a string
```

Αν το `input` περιέχει ένα `string`, τότε το `str` θα είναι η υποκείμενη τιμή και το `ok` θα είναι αληθές.
Αν το `input` δεν περιέχει ένα `string`, τότε το `str` θα είναι η μηδενική τιμή του τύπου `string` (δηλ. `""` - η κενή συμβολοσειρά) και το `ok` θα είναι ψευδές.
Δεν προκαλείται panic σε καμία περίπτωση.

## Διακόπτες τύπων

Ένας **διακόπτης τύπων** μπορεί να εκτελέσει αρκετούς ισχυρισμούς τύπων σε σειρά.
Έχει την ίδια σύνταξη με έναν ισχυρισμό τύπου (`interfaceVariable.(concreteType)`), αλλά το `concreteType` αντικαθίσταται από τη λέξη-κλειδί `type`.
Ακολουθεί ένα παράδειγμα:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
