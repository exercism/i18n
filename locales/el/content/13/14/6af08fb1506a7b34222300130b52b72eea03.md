# Οδηγίες

Όσο περισσότερο μαθαίνεις για τον προγραμματισμό, τόσο πιο πολύ αρχίζεις να σκέφτεσαι ότι αυτό μπορεί να μην είναι απλώς μια παροδική μόδα.
Μπορεί μάλιστα να υπάρχουν και επιχειρηματικές ευκαιρίες: οι άνθρωποι γράφουν κώδικα, θέλουν να τον αποθηκεύσουν, να τον μοιραστούν, να συνεργαστούν, ίσως ακόμη και να πάρουν κάποια ανατροφοδότηση.

Εντάξει, ας το κάνουμε, ας φτιάξουμε μια υπηρεσία που να ενθαρρύνει τους ανθρώπους να γράφουν κώδικα: hup, hup, κόσμε, ώρα να αρχίσει ο καθένας να χρησιμοποιεί το git!
Ας το ονομάσουμε... GitHup.

Ξεκινάς να φτιάχνεις ένα REST JSON API: χρήστες, pull requests, σχόλια, και το backend ετοιμάζεται γρήγορα.
Ορίστε ένα παράδειγμα του payload που επιστρέφεται όταν ζητάς από τον server τη λίστα με τα σχόλια σε ένα pull request:

```json
[
  {
    "id": 256,
    "pull_request_review_id": 42,
    "user": {
      "id": 101,
      "login": "octodog",
      "avatar_url": "https://githup.com/images/error/octodog_happy.gif",
      "site_admin": false
    },
    "body": "Great stuff!",
    "side": "RIGHT",
    "_links": {
      "self": {
        "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1"
      },
      "html": {
        "href": "https://githup.com/octodog/Hello-World/pull/1#discussion-diff-1"
      },
      "pull_request": {
        "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/1"
      }
    }
  },
  {
    "id": 11,
    "pull_request_review_id": null,
    "user": {
      "id": 2,
      "login": "hexacat",
      "name": "Alex Kate",
      "avatar_url": "https://githup.com/images/error/hexacat_happy.gif",
      "site_admin": true
    },
    "body": "Amazing stuff!",
    "side": "LEFT",
    "_links": {
      "self": {
        "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1"
      }
    }
  }
]
```

Φυσικά, το frontend θα γίνει σε Elm, αλλά πρώτα πρέπει να καταλάβεις περί τίνος πρόκειται αυτοί οι διαβόητοι decoders/encoders.

```exercism/note
Πέρα από το χιουμοριστικό σενάριο, οι απαιτήσεις της άσκησης προέρχονται απευθείας από τα REST API endpoints του GitHub για σχόλια σε pull request.
Κάποια πεδία αφαιρέθηκαν από τα JSON schemas για λόγους απλότητας, αλλά αυτό είναι όσο πιο κοντά γίνεται σε εφαρμογές του πραγματικού κόσμου.
```

## 1. ID, παρακαλώ!

Το αετίσιο μάτι σου παρατήρησε ότι τόσο τα σχόλια όσο και οι χρήστες έχουν ένα πεδίο `id`, ιδανικό σημείο για να ξεκινήσεις.

Όρισε τη `decodeId` ώστε να μπορεί να αποκωδικοποιεί ένα JSON αντικείμενο, με έναν ακέραιο `id`.

```elm
Decode.decodeString decodeId """{id: 10}"""
    --> Ok 10
```

## 2. Πώς με λένε, είπαμε;

Παρατηρείς στο παραπάνω παράδειγμα ότι δεν έχουν όλοι οι χρήστες όνομα.

Όρισε τη `decodeName` ώστε να μπορεί να αποκωδικοποιεί μια συμβολοσειρά στο πεδίο `name`, αν υπάρχει.
Δεν υπάρχει όνομα; Κανένα πρόβλημα, απλώς επέστρεψε `Nothing`.
Αυτός ο decoder δεν πρέπει να αποτυγχάνει ποτέ.

```elm
Decode.decodeString decodeName """{"id": 10, "name": "Otto"}"""
    --> Ok (Just Otto)

Decode.decodeString decodeName """null"""
    --> Ok Nothing
```

## 3. Χρήστης; Δεν τον ξέρω καν!

Έχουμε φτάσει σχεδόν στη μέση όσον αφορά την αποκωδικοποίηση των χρηστών, ας το τελειώσουμε.

Όρισε τη `decodeUser` ώστε να μπορεί να αποκωδικοποιεί ένα JSON αντικείμενο χρήστη.
Φρόντισε να χρησιμοποιήσεις τις `decodeId` και `decodeName` μέσα στη `decodeUser`.

```elm
Decode.decodeString decodeUser
    """
    {
      "id": 101,
      "login": "octodog",
      "avatar_url": "https://githup.com/images/error/octodog_happy.gif",
      "site_admin": false
    }
    """
    --> Ok
    -->   { id = 101
    -->   , name = Nothing
    -->   , login = "octodog"
    -->   , avatarUrl = "https://githup.com/images/error/octodog_happy.gif
    -->   , siteAdmin = False
    -->   }
```

## 4. Είμαι ένα δυνατό και ανεξάρτητο σχόλιο

Κάποια σχόλια σε ένα pull review είναι αυτόνομα και επομένως δεν έχουν `pull_request_review_id`.
Ωστόσο, οι προδιαγραφές αναφέρουν ότι σε μια τέτοια περίπτωση θα πρέπει να υπάρχει ακόμη ένα πεδίο `pull_request_review_id`, αλλά η τιμή του θα πρέπει να είναι `null`, το `Nothing` του φτωχού.

Όρισε τη `decodePullRequestReviewId` ώστε να μπορεί να αποκωδικοποιεί έναν ακέραιο στο πεδίο `pull_request_review_id`, αν υπάρχει.
Αν δεν υπάρχει ακέραιος, θα πρέπει να υπάρχει ένα `null`, και αν δεν υπάρχει `null`, ο decoder θα πρέπει να αποτυγχάνει.

```elm
Decode.decodeString decodePullRequestReviewId """{"pull_request_review_id": 3}"""
    --> Ok (Just 3)

Decode.decodeString decodePullRequestReviewId """{"pull_request_review_id": null}"""
    --> Ok Nothing

Decode.decodeString decodePullRequestReviewId """{"id": 3}"""
    --> Err ...
```

## 5. Δουλίτσα στο πλάι

Στη συνέχεια είναι αυτό το ενδιαφέρον πεδίο `side`.
Σε ένα pull review, μπορείς να σχολιάσεις κώδικα που αφαιρέθηκε (στην πλευρά `Left` της οθόνης) ή κώδικα που προστέθηκε (στην πλευρά `Right` της οθόνης).

Όρισε τη `decodeSide` ώστε να μπορεί να αποκωδικοποιεί είτε `"LEFT"` είτε `"RIGHT"` στο πεδίο `side` και να τα αντιστοιχίζει στην αντίστοιχη παραλλαγή τύπου.

```elm
Decode.decodeString decodeSide """{"side": "LEFT"}"""
    --> Ok Left

Decode.decodeString decodeSide """{"side": "middle?"}"""
    --> Err ...
```

## 6. Links awakening

Κάθε σχόλιο έχει ένα σύνολο συνδέσμων, που δεν φαίνεται να είναι το ίδιο σε όλα τα σχόλια.

Όρισε τη `decodeLinks` ώστε να μπορεί να αποκωδικοποιεί μια συλλογή από URLs στο πεδίο `_links`.
Τα ονόματα και ο αριθμός των συνδέσμων μπορεί να διαφέρουν, φρόντισε να το λάβεις υπόψη.
Οι ίδιοι οι σύνδεσμοι είναι JSON αντικείμενα που θα πρέπει να έχουν πάντα ένα πεδίο `href`.

```elm
Decode.decodeString decodeLinks """
    {
      "_links": {
        "self": { "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1" },
        "html": { "href": "https://githup.com/octodog/Hello-World/pull/1#discussion-diff-1" },
        "pull_request": { "href": "https://api.githup.com/repos/octodog/Hello-World/pulls/1" }
      }
    }
    """
    --> Ok
    -->   (Dict.fromList
    -->       [ ( "self", "https://api.githup.com/repos/octodog/Hello-World/pulls/comments/1" )
    -->       , ( "html", "https://githup.com/octodog/Hello-World/pull/1#discussion-diff-1" )
    -->       , ( "pull_request", "https://api.githup.com/repos/octodog/Hello-World/pulls/1" )
    -->       ]
    -->   )
```

## 7. Ναι, σχόλια

Σχεδόν φτάσαμε, ας το τελειώσουμε.

Όρισε τις `decodeComment` και `decodeComments` ώστε να μπορούν να αποκωδικοποιούν ένα μεμονωμένο JSON αντικείμενο σχολίου ή μια λίστα με σχόλια αντίστοιχα.
Φρόντισε να χρησιμοποιήσεις όλες τις συναρτήσεις που έχεις ορίσει μέχρι τώρα στη `decodeComment`, με εξαίρεση τη `decodeName`.
Φυσικά, η `decodeComments` θα πρέπει να χρησιμοποιεί και τη `decodeComment`.

## 8. Όλα δένουν

Λείπει ακόμη ένα χαρακτηριστικό από όλα αυτά: η δυνατότητα να στέλνεις ένα νέο σχόλιο στον server.
Γι' αυτό, πρέπει να πετύχεις το αντίθετο ενός decoder, πρέπει να μπορείς να μετατρέπεις ένα Elm `Comment` σε ένα JSON `Value`.

Όρισε τη `encodeComment` ώστε να μπορεί να κωδικοποιεί οποιοδήποτε έγκυρο `Comment`.
Η σειρά των πεδίων δεν έχει σημασία, αρκεί ο encoder να παράγει μια τιμή που μπορεί να αποκωδικοποιήσει η `decodeComment`.
