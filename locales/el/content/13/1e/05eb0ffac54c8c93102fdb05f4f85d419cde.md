# Εισαγωγή

Ενώ η Swift περιλαμβάνει πολλή λειτουργικότητα στην Standard Library της, υπάρχει ακόμη περισσότερη λειτουργικότητα διαθέσιμη με τη μορφή εξωτερικών βιβλιοθηκών.
Αυτές οι βιβλιοθήκες μπορεί να προέρχονται από το ίδιο το έργο Swift, όπως ο [Swift Argument Parser][argument-parser], βιβλιοθήκες κλειστού κώδικα από εταιρείες, όπως το [Network Framework][network-framework] της Apple, ή βιβλιοθήκες τρίτων, όπως το [Swifty Beaver][swifty-beaver].

Μερικά από αυτά τα modules, όπως το Network Framework ή το [Foundation][apple-foundation] (που είναι πιθανώς η πιο συχνά χρησιμοποιούμενη βιβλιοθήκη στη Swift), έρχονται μαζί με τη διανομή της Swift.
Οι εξωτερικές βιβλιοθήκες τρίτων πρέπει να προστεθούν στο έργο σου πριν μπορέσεις να τις εισαγάγεις, αν και αυτό είναι εκτός του πεδίου αυτής της άσκησης.

Η εισαγωγή modules γίνεται γράφοντας τη λέξη-κλειδί `import` ακολουθούμενη από το όνομα του module. Έτσι, μπορείς να εισαγάγεις το Foundation προσθέτοντας το παρακάτω στο πρόγραμμά σου.

```swift
import Foundation
```

Αυτό δίνει πρόσβαση σε όλους τους τύπους, τις τιμές και τη λειτουργικότητα μέσα σε αυτό το module· για παράδειγμα, αν θέλεις να χρησιμοποιήσεις τη μέθοδο `components(separatedBy:)` του String, η μέθοδος αυτή γίνεται διαθέσιμη στο `String` με αυτό το import.

Αν και οι εντολές import μπορούν να τοποθετηθούν στον κώδικα οπουδήποτε πριν από ένα κομμάτι κώδικα που χρησιμοποιεί κάτι από το περιεχόμενο του module, συνήθως τοποθετούνται στην αρχή του αρχείου που τις χρησιμοποιεί, για μεγαλύτερη αναγνωσιμότητα.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
