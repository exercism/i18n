# Εγκατάσταση

Η διαδρομή της γλώσσας C απαιτεί να έχεις εγκατεστημένο στο σύστημά σου το ακόλουθο λογισμικό:

* Έναν σύγχρονο μεταγλωττιστή C
* Το εργαλείο κατασκευής Make

Το Xcode IDE της Apple συνδυάζει τον μεταγλωττιστή και το εγγενές σύστημα κατασκευής σε ένα ενιαίο IDE (ολοκληρωμένο περιβάλλον ανάπτυξης).
Τα περιβάλλοντα Linux συνήθως παρέχουν τον μεταγλωττιστή και το εγγενές σύστημα κατασκευής ως ξεχωριστά εργαλεία γραμμής εντολών.

## Linux

Οι χρήστες Linux θα χρειαστούν gcc ή clang για τον μεταγλωττιστή, και το `make` θα χρειαστεί για την εγγενή κατασκευή.
Το Make είναι προεγκατεστημένο στα περισσότερα συστήματα Unix, αλλά είναι κατά πάσα πιθανότητα διαθέσιμο μέσω του διαχειριστή πακέτων σου.
Σε διανομές βασισμένες σε Debian και Ubuntu, ό,τι χρειάζεσαι μπορεί να εγκατασταθεί με `sudo apt-get install build-essential` αν δεν είναι ήδη εγκατεστημένα.

## MacOS

Οι χρήστες MacOS μπορούν να εγκαταστήσουν gcc ή clang με το [Homebrew][] μέσω `brew install gcc` ή `brew install llvm`.

## Windows

Στους χρήστες Windows 10 συνιστάται να χρησιμοποιήσουν το [Windows Subsystem for Linux][] και να προχωρήσουν στις οδηγίες για Linux παραπάνω.

Αν χρησιμοποιείς παλαιότερη έκδοση των Windows ή δεν έχεις διαθέσιμο το WSL Bash, θα μπορούσες να χρησιμοποιήσεις το [MSYS][] ή το [mingw-w64][].

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
