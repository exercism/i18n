# Εισαγωγή στις μεταβλητές

## Μεταβλητές

Οι _μεταβλητές_ είναι ένας χώρος για να κρατάς δεδομένα.
Το bash έχει δύο είδη δεδομένων: συμβολοσειρές και πίνακες.
Θα μιλήσουμε για τους πίνακες αργότερα.

Εκχωρείς μια τιμή σε μια μεταβλητή ως εξής
```bash
name="value"
```

~~~~exercism/note
**Σημαντικό** -- δεν πρέπει να υπάρχουν _κενά_ γύρω από το σύμβολο ίσον!

Όταν υπάρχουν κενά, όπως σε αυτό το παράδειγμα,

```bash
x = 10
```

το bash θα καλέσει την **εντολή** `x` με τα **δύο ορίσματα** `=` και `10`!
~~~~

Οι μεταβλητές μπορούν επίσης να ονομαστούν _παράμετροι_.
Οι δύο όροι θα χρησιμοποιούνται εναλλακτικά σε αυτό το κείμενο.

Μερικές σημαντικές παράμετροι που χρησιμοποιεί ή ορίζει το bash είναι:

* `PATH` -- μια λίστα καταλόγων χωρισμένων με άνω και κάτω τελεία, που χρησιμοποιείται για την εύρεση εξωτερικών εντολών.
* `IFS` -- ο "εσωτερικός διαχωριστής πεδίων".
   Θα δούμε πώς χρησιμοποιείται παρακάτω.
* `PWD` -- ο τρέχων κατάλογος εργασίας σου.
   Θα έχει την ίδια τιμή με την έξοδο της εντολής `pwd`.
* `RANDOM` -- ένας ψευδοτυχαίος ακέραιος μεταξύ 0 και 32767.
* `BASH_VERSION` -- η συμβολοσειρά έκδοσης της περίπτωσης του bash που εκτελείται.

## Ονόματα μεταβλητών

Ένα όνομα μεταβλητής αποτελείται από _κεφαλαία γράμματα, πεζά γράμματα, αριθμούς και κάτω παύλα_.
Δεν μπορεί να ξεκινά με αριθμό.

~~~~exercism/caution
Είναι καλή πρακτική να **αποφεύγεις ονόματα μεταβλητών που γράφονται ΟΛΑ ΚΕΦΑΛΑΙΑ**.
Το κέλυφος χρησιμοποιεί αυτή τη σύμβαση για τις παραμέτρους του, και δεν θέλεις να αντικαταστήσεις κατά λάθος παραμέτρους του κελύφους που έχουν ειδική σημασία.
Για παράδειγμα: [1][1], [2][2], [3][3]

## Επέκταση παραμέτρων

Παίρνεις την τιμή μιας παραμέτρου με τη σύνταξη `$varname`.

```bash
x=10
echo "The value of x is $x"
```

Για να μην μπερδεύεται το όνομα της μεταβλητής με το κείμενο που το περιβάλλει, μπορείς να κλείσεις το όνομα της μεταβλητής σε άγκιστρα.
Για παράδειγμα, για να εκτυπώσεις τη συμβολοσειρά `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

Κάποιοι [οδηγοί στυλ][google-style-guide] συνιστούν τη χρήση αγκίστρων στις περισσότερες περιπτώσεις για αναγνωσιμότητα ή/και συνέπεια.

## Παράμετροι θέσης

Όπως συζητήσαμε στην ενότητα [Εντολές και ορίσματα][cmds-args], οι εντολές μπορούν να δέχονται ορίσματα.
Τα σενάρια bash δεν αποτελούν εξαίρεση.
Τα ορίσματα στην τρέχουσα περίπτωση του bash ονομάζονται _παράμετροι θέσης_.
Μπορείς να τα ανακτήσεις με αυτές τις ειδικές παραμέτρους:

* `$1` -- η πρώτη παράμετρος θέσης
* `$2` ... `$9` -- οι επόμενες παράμετροι
* `${10}` ... -- τα διψήφια απαιτούν άγκιστρα.
* `$0` -- το όνομα του τρέχοντος σεναρίου.

Τα ορίσματα σε μια συνάρτηση του κελύφους είναι επίσης παράμετροι θέσης και αντιμετωπίζονται με τον ίδιο ακριβώς τρόπο.
Θα δούμε περισσότερα για τις συναρτήσεις σε επόμενη ενότητα.

### Ειδικές παράμετροι θέσης

Υπάρχουν κάποιες _ειδικές παράμετροι_ που σε βοηθούν να δουλέψεις με τις παραμέτρους θέσης.

* `$#` επεκτείνεται στον _αριθμό_ των παραμέτρων θέσης.
* `"$@"` επεκτείνεται στη λίστα όλων των παραμέτρων θέσης, καθεμιά ως ξεχωριστή λέξη.
* `"$*"` επεκτείνεται σε μία μόνο συμβολοσειρά με όλες τις παραμέτρους θέσης ενωμένες με έναν χαρακτήρα.
  * Ο χαρακτήρας ένωσης είναι _ο πρώτος χαρακτήρας_ της μεταβλητής `$IFS`, που από προεπιλογή είναι ένα κενό.

Το `"$@"` είναι ο ασφαλέστερος τρόπος να περάσεις παραμέτρους θέσης σε άλλη εντολή κρατώντας τις σωστά μέσα σε εισαγωγικά.
Είναι επίσης αυτό που θα χρησιμοποιήσεις για να διατρέξεις με βρόχο τις παραμέτρους θέσης:

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

Στην πράξη, το `"$@"` χρησιμοποιείται πιο συχνά από το `"$*"`.

## Αντικατάσταση εντολών

Μια πολύ συχνή λειτουργία που θα κάνεις σε σενάρια bash είναι να συλλάβεις την έξοδο μιας εντολής και να την αποθηκεύσεις σε μια μεταβλητή.
Για να το κάνεις αυτό, θα χρησιμοποιήσεις την _αντικατάσταση εντολών_.

```bash
var=$(command)
```

Για παράδειγμα, για να μετατρέψεις μια συμβολοσειρά σε κεφαλαία, μπορείς να κάνεις το εξής:

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## Περισσότερα για την επέκταση παραμέτρων

Το bash έχει πολλά ενσωματωμένα εργαλεία για να χειρίζεσαι μεταβλητές και συμβολοσειρές, ώστε να μην χρειάζεται να καλέσεις εξωτερικές εντολές.

* Μετατροπή κειμένου σε κεφαλαία.
  Στην προηγούμενη ενότητα έδειξα πώς να χρησιμοποιήσεις το `tr` για να μετατρέψεις κείμενο σε κεφαλαία.
  Για να το κάνεις στο bash:

  ```bash
  echo "${text^^}"
  ```

  Αντίστοιχα, το `${text,,}` μετατρέπει την τιμή σε πεζά.

* Παροχή μιας προεπιλεγμένης τιμής αν η μεταβλητή είναι κενή.

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* Αναζήτηση και αντικατάσταση.

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

Υπάρχουν πολλές άλλες ενδιαφέρουσες επεκτάσεις παραμέτρων: εξαγωγή υποσυμβολοσειράς, λήψη του μήκους μιας συμβολοσειράς, _εκχώρηση_ μιας προεπιλεγμένης τιμής, αφαίρεση κειμένου από την αρχή ή το τέλος της τιμής και άλλα.
Διάβασε γι' αυτές [στο εγχειρίδιο][param-exp].
