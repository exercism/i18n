# Οδηγίες

Ο σύλλογος νέτμπολ σου χρειάζεται να υπολογίζεις την κατάταξή του μετά από κάθε αγωνιστική.

Και οι τέσσερις εργασίες μπαίνουν στην κλάση `NETBALL_LADDER`.

## 1. Βαθμοί κατάταξης

Η νίκη αξίζει 4 βαθμούς και η ισοπαλία 2. Οι ήττες δεν αξίζουν τίποτα.

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. Διαφορά τερμάτων

Τα τέρματα που σημειώνεις μείον τα τέρματα που δέχεσαι. Μπορεί να είναι αρνητική.

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. Ολόκληρα τέταρτα που παίχτηκαν

Ένα τέταρτο είναι 15 λεπτά. Με δεδομένο έναν αριθμό λεπτών, πόσα ολόκληρα
τέταρτα είναι αυτά;

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. Λεπτά μέσα στο τέταρτο

Με τον ίδιο αριθμό λεπτών, πόσο μέσα στο τρέχον τέταρτο βρισκόμαστε;

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
