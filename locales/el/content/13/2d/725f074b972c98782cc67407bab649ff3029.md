# Εισαγωγή

## Χειρισμός bit

Η Java διαθέτει τελεστές για τον χειρισμό των bit ενός `byte`, `short`, `int`, `long` ή `char`.

### Τελεστές ολίσθησης

Χρησιμοποίησε τον `<<` για ολίσθηση των bit προς τα αριστερά και τον `>>` για ολίσθηση προς τα δεξιά.

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

Ο τελεστής `<<` εισάγει πάντα μηδενικά στη δεξιά πλευρά.
Ωστόσο, ο `>>` εισάγει το ίδιο bit με το πιο αριστερό bit (1 αν ο αριθμός είναι αρνητικός ή 0 αν είναι θετικός).

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

Χρησιμοποίησε τον `>>>` αντ' αυτού όταν κατά την ολίσθηση προς τα δεξιά πρέπει να εισαχθούν μηδενικά.

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

### Πράξεις bit

#### AND κατά bit

Ο τελεστής AND κατά bit (`&`) παίρνει δύο τιμές και εκτελεί AND σε κάθε bit.
Συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν είναι και τα δύο 1, τότε το bit του αποτελέσματος είναι 1.
Διαφορετικά, το bit του αποτελέσματος είναι 0.

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

#### OR κατά bit

Ο τελεστής OR κατά bit (`|`) παίρνει δύο τιμές και εκτελεί OR σε κάθε bit.
Συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν οποιοδήποτε από τα δύο bit είναι 1, το bit του αποτελέσματος είναι 1.
Διαφορετικά, είναι 0.

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

#### XOR κατά bit

Ο τελεστής XOR κατά bit (`^`) εκτελεί XOR κατά bit σε δύο τιμές.
Όπως οι τελεστές AND και OR κατά bit, συγκρίνει κάθε bit της πρώτης τιμής με το bit στην ίδια θέση της δεύτερης τιμής.
Αν μόνο ένα από τα δύο είναι 1, το bit του αποτελέσματος είναι 1.
Διαφορετικά, είναι 0.

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

#### NOT κατά bit (`~`)

Τέλος, ο τελεστής NOT κατά bit (`~`) αντιστρέφει κάθε bit.
Σε αντίθεση με τους προηγούμενους τελεστές, αυτός είναι μονομελής τελεστής και δρα μόνο σε μία τιμή.

```java
~0b0110_0101;
// # => 0b1001_1010
```
