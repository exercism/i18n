# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος   | Περιγραφή                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | είσοδος   | διεύθυνση | πίνακας με λέξεις παραγόντων    |
| `$a1`    | είσοδος   | ακέραιος | πλήθος παραγόντων              |
| `$a2`    | είσοδος   | ακέραιος | όριο                          |
| `$v0`    | έξοδος    | ακέραιος | άθροισμα των πολλαπλασίων εντός του ορίου |
| `$t0-9`  | προσωρινός | ό,τιδηποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
