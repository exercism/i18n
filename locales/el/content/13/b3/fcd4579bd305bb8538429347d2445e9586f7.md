# Σχετικά

Η συμβολοσειρά στη Factor είναι μια ακολουθία χαρακτήρων και μοιράζεται το πλήρες
[πρωτόκολλο `sequences`][sequence-protocol] (`length`, `nth`, `head`,
`tail`, `map`, `filter` κ.ο.κ.) μαζί με τα δικά της ξεχωριστά λεξιλόγια.

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

Οι λέξεις που αφορούν ειδικά τις συμβολοσειρές βρίσκονται κυρίως στα [`splitting`][splitting],
[`ascii`][ascii] και [`unicode`][unicode]:

| λέξη         | λεξιλόγιο     | τι κάνει                              |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | κόβει στην πρώτη εμφάνιση             |
| `split`      | [`splitting`][splitting]   | κόβει σε οποιονδήποτε χαρακτήρα ενός συνόλου |
| `harvest`    | [`sequences`][sequences]   | πετάει τα κενά κομμάτια από το αποτέλεσμα ενός διαχωρισμού |
| `replace`    | [`splitting`][splitting]   | αντικαθιστά μια υποσυμβολοσειρά        |
| `surround`   | [`sequences`][sequences]   | τυλίγει με ένα πρόθεμα και ένα επίθεμα |
| `glue`       | [`sequences`][sequences]   | ενώνει δύο συμβολοσειρές με έναν διαχωριστικό |
| `join`       | [`sequences`][sequences]   | ενώνει έναν πίνακα συμβολοσειρών με έναν διαχωριστικό |
| `>lower`     | [`ascii`][ascii]       | πεζά (ASCII)                          |
| `>upper`     | [`ascii`][ascii]       | κεφαλαία (ASCII)                      |
| `[ blank? ] trim` | [`sequences`][sequences] | αφαιρεί τα κενά στην αρχή και στο τέλος |
| `first`, `second`, `third`, `fourth` | [`sequences`][sequences] | η θέση στην αρχή |
| `first2`, `first3`         | [`sequences`][sequences]   | αποσυσκευάζει δύο ή τρεις θέσεις από την αρχή |
| `>string`    | [`strings`][strings]     | μετατρέπει μια ακολουθία χαρακτήρων σε συμβολοσειρά |
| `1string`    | [`strings`][strings]     | τυλίγει έναν μόνο χαρακτήρα σε συμβολοσειρά ενός χαρακτήρα |
| `CHAR: x`    | parser        | ένα κυριολεκτικό ενός χαρακτήρα (π.χ. `CHAR: A` → `65`) |

Για μετατροπή αριθμών σε συμβολοσειρές και αντίστροφα, το [`math.parser`][math.parser]
παρέχει τα `number>string` και `string>number`. Για έξοδο με μορφοποιημένο
κείμενο, το [`formatting`][formatting] παρέχει το `sprintf` και παρόμοια.

Για μετατροπή πεζών/κεφαλαίων ή κατηγοριοποίηση χαρακτήρων με επίγνωση του
Unicode, χρησιμοποίησε τις αντίστοιχες λέξεις στο [`unicode`][unicode].
