# Βιβλιοθήκες

Το Exercism στοχεύει να σε μάθει να έχεις [ευχέρεια](/docs/using/product/fluency) στη σύνταξη, στα ιδιώματα και στην πρότυπη βιβλιοθήκη της γλώσσας.
Αυτό ρητά _δεν_ αναφέρει εξωτερικές βιβλιοθήκες (μη ενσωματωμένες), καθώς κάτι τέτοιο εμπίπτει στην _επάρκεια_.
Οι ασκήσεις πρέπει επομένως, με λίγες εξαιρέσεις, να λύνονται χωρίς τη χρήση βιβλιοθηκών.

## Λόγοι για υποστήριξη βιβλιοθηκών

Υπάρχουν μερικοί λόγοι για τους οποίους μια διαδρομή μπορεί να θέλει παρ' όλα αυτά να υποστηρίζει βιβλιοθήκες:

1. Η γλώσσα έχει (πολύ) μικρή πρότυπη βιβλιοθήκη.
   Ένα παράδειγμα τέτοιας γλώσσας είναι η Rust.
2. Η βιβλιοθήκη προσθέτει λειτουργικότητα για δοκιμές.
   Ένα παράδειγμα είναι μια βιβλιοθήκη που προσθέτει υποστήριξη για property-based testing.
3. Η άσκηση μπορεί να λυθεί μόνο με τη χρήση βιβλιοθήκης.
   Ένα παράδειγμα τέτοιας άσκησης είναι η [άσκηση lens-person](https://exercism.org/exercises/lens-person), η οποία στις περισσότερες γλώσσες μπορεί να λυθεί μόνο με τη χρήση βιβλιοθήκης.

## Υποστήριξη βιβλιοθηκών στον εκτελεστή δοκιμών

Επειδή ο εκτελεστής δοκιμών δεν έχει πρόσβαση στο διαδίκτυο όσο εκτελείται, δεν είναι δυνατό να κατεβάσεις βιβλιοθήκες τη στιγμή της εκτέλεσης.
Η **μόνη** λύση σε αυτό το πρόβλημα είναι να εγκαταστήσεις/κατεβάσεις τις βιβλιοθήκες τη στιγμή του build, όπου _έχεις_ πρόσβαση στο διαδίκτυο.
Στην πράξη, αυτό σημαίνει ότι θα χρειαστεί να εγκαταστήσεις/κατεβάσεις βιβλιοθήκες μέσα στο Dockerfile.

Για παράδειγμα, ο [Dockerfile του εκτελεστή δοκιμών για Prolog](https://github.com/exercism/prolog-test-runner/blob/ed7447a7518ede6ee3405e649f50aaec828e318b/Dockerfile) εγκαθιστά τη βιβλιοθήκη `date_time`:

```dockerfile
RUN swipl pack install date_time -y
```

## Τεκμηρίωση

Αν η διαδρομή σου υποστηρίζει βιβλιοθήκες, αυτό θα πρέπει να τεκμηριώνεται σε ένα [έγγραφο της διαδρομής](/docs/building/tracks/docs).
Παραπέμψε επίσης σε αυτό το έγγραφο (χρησιμοποιώντας το πλήρες URL του) από το [έγγραφο `exercises/shared/.docs/help.md`](/docs/building/tracks/shared-files#file-help-md).
