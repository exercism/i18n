# Bools

Η Haskell έχει έναν τύπο γνωστό ως [`Bool`][bools] (λογική τιμή).
Είναι μια απαρίθμηση των `True` και `False`.

## Λογικοί τελεστές

Η Haskell έχει τρεις λογικούς τελεστές (`not`, `||`, `&&`), οι οποίοι συνδυάζουν Bool και σχηματίζουν εκφράσεις που παράγουν διαφορετικές τιμές.

### Και (`&&`)

Ο [τελεστής _και_][and] στη Haskell αναπαρίσταται με το `&&` και επιστρέφει `True` αν και οι δύο τιμές είναι `True`, αλλιώς επιστρέφει `False`.
Όταν χρησιμοποιείς τον τελεστή _και_, βάζεις το ένα Bool στα δεξιά του `&&` και το άλλο στα αριστερά.

```haskell
True && True
-- -> True

True && False
-- -> False
```

### Ή (`||`)

Ο [τελεστής _ή_][or] στη Haskell αναπαρίσταται με το `||` και επιστρέφει `True` αν **τουλάχιστον μία** από τις τιμές που δίνονται είναι `True`. 
Αν και οι δύο τιμές είναι `False`, τότε επιστρέφει `False`.
Όταν χρησιμοποιείς τον τελεστή _ή_, πρέπει να βάλεις το ένα Bool στα δεξιά του `||` και το άλλο στα αριστερά.

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### Όχι (`not`)

Ο τελεστής _όχι_ στη Haskell αναπαρίσταται με το `not` και επιστρέφει `True` αν το Bool που του δίνεις είναι `False`, και επιστρέφει `False` αν του δώσεις `True`.
Όταν χρησιμοποιείς τον τελεστή _όχι_, βάζεις το Bool μετά τον τελεστή (`not`).

```haskell
not True
-- -> False

not False
-- -> True
```

## Χρήση παρενθέσεων (`()`)

Όταν δουλεύεις με Bool, μπορείς να χρησιμοποιήσεις παρενθέσεις για να ορίσεις ποια Bool θα αξιολογηθούν πρώτα.
Το αποτέλεσμα μπορεί να διαφέρει ανάλογα με το πώς χρησιμοποιείς τις παρενθέσεις.
Στη Haskell, ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα.

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

Επειδή ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα, στο παρακάτω παράδειγμα ο τελεστής _όχι_ εφαρμόζεται στην έκφραση μέσα στις παρενθέσεις.

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

Να χρησιμοποιείς παρενθέσεις μόνο όταν επηρεάζουν το αποτέλεσμα, αλλιώς καλό είναι να τις παραλείπεις.
~~~~
