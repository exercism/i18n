# Οδηγίες

Μετέτρεψε μια φράση στο ακρώνυμό της.

Οι τεχνόφιλοι λατρεύουν τα TLA (ακρώνυμα τριών γραμμάτων)!

Βοήθησε να παραχθεί λίγη ορολογία γράφοντας ένα πρόγραμμα που μετατρέπει ένα μεγάλο όνομα, όπως το Portable Network Graphics, στο ακρώνυμό του (PNG).

Η στίξη αντιμετωπίζεται ως εξής: τα ενωτικά χωρίζουν τις λέξεις (όπως τα κενά); όλη η άλλη στίξη μπορεί να αφαιρεθεί από την είσοδο.

Για παράδειγμα:

| Είσοδος                  | Έξοδος |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
