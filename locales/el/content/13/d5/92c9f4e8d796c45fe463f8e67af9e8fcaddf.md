# Εισαγωγή

## Πίνακες κατακερματισμού

Οι πίνακες κατακερματισμού στην Common Lisp είναι δομές δεδομένων για την αποθήκευση συσχετιστικών δεδομένων.
Αντιστοιχίζουν κλειδιά (που μπορεί να είναι οποιοδήποτε αντικείμενο) σε τιμές (που μπορεί επίσης να είναι οποιοδήποτε αντικείμενο).
Άλλες γλώσσες μπορεί να αναφέρονται σε αυτή την έννοια ως χάρτες, λεξικά ή κατακερματισμούς.

### Δημιουργία πινάκων κατακερματισμού

Οι πίνακες κατακερματισμού μπορούν να δημιουργηθούν με τη συνάρτηση `make-hash-table`.

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

(Σημείωσε ότι η εκτυπωμένη μορφή ενός πίνακα κατακερματισμού εξαρτάται από την υλοποίηση, οπότε μπορεί να εμφανιστεί διαφορετικά στο REPL σου.)

### Ανάκτηση τιμών με βάση τα κλειδιά

Για να πάρεις μια τιμή με βάση ένα κλειδί από τον πίνακα κατακερματισμού, χρησιμοποιείς τη συνάρτηση `gethash`:

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

Το `gethash` επιστρέφει [πολλαπλές τιμές][concept-multiple-values], οι οποίες θα εξηγηθούν σε άλλη ενότητα.

### Εισαγωγή τιμών

Για να εισάγεις μια τιμή σε έναν πίνακα κατακερματισμού, χρησιμοποιείς το `setf` μαζί με το `gethash`, όπως εδώ:

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

Αυτό θα αλλάξει την τιμή για το κλειδί `:foo` στον πίνακα κατακερματισμού `*hash-table*` σε `:bar`.
Επιστρέφει την τιμή.

Η χρήση του `setf` θα εξηγηθεί σε άλλη ενότητα.
