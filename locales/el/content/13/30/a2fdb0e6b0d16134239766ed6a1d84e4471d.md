# Εισαγωγή

Το Gleam δεν χρησιμοποιεί εξαιρέσεις για τη διαχείριση σφαλμάτων. Αντίθετα, οι συναρτήσεις που μπορούν είτε να πετύχουν είτε να αποτύχουν επιστρέφουν τον γενικό τύπο `Result`.

Ο τύπος `Result` είναι ενσωματωμένος στη γλώσσα, οπότε δεν χρειάζεται να τον ορίσεις ούτε να τον εισάγεις, αλλά αν τον όριζες μόνος σου θα έμοιαζε κάπως έτσι:

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

Η παραλλαγή `Ok` επιστρέφεται όταν μια συνάρτηση πετυχαίνει, και η παραλλαγή `Error` επιστρέφεται όταν μια συνάρτηση αποτυγχάνει.

Οι τιμές `Result` είναι πολύ συνηθισμένες στο Gleam, και οι προγραμματιστές της Gleam χρησιμοποιούν συνήθως την [ενότητα `gleam/result`](https://hexdocs.pm/gleam_stdlib/gleam/result.html) για να κάνουν τη δουλειά μαζί τους πιο εύκολη.

Με τη συνάρτηση `result.map` μπορείς να καλέσεις μια συνάρτηση στην τιμή που περιέχει ένα `Result` αν αυτό είναι `Ok`, ή να αφήσεις ένα `Error` να περάσει αμετάβλητο.

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

Η συνάρτηση `result.try` είναι παρόμοια, αλλά η συνάρτηση callback πρέπει να επιστρέφει ένα `Result`. Αυτό είναι χρήσιμο για να ενώσεις σε αλυσίδα πολλές συναρτήσεις που επιστρέφουν `Result`.

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
