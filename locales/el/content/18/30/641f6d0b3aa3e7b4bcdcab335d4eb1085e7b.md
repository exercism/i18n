# Σχετικά

Οι [παράμετροι μεταβλητού πλήθους][variadic-parameters] επιτρέπουν σε μια συνάρτηση να δέχεται μηδέν ή περισσότερες τιμές ενός καθορισμένου τύπου για μία μόνο παράμετρο.
Ορίζεις μια παράμετρο μεταβλητού πλήθους προσθέτοντας τρεις τελείες (`...`) στη δήλωση τύπου της παραμέτρου.

Μέσα στο σώμα της συνάρτησης, η Swift κάνει αυτές τις τιμές διαθέσιμες ως πίνακα του καθορισμένου τύπου:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Αν μια συνάρτηση περιλαμβάνει επιπλέον παραμέτρους μετά από μια παράμετρο μεταβλητού πλήθους, η πρώτη παράμετρος που ακολουθεί την παράμετρο μεταβλητού πλήθους **πρέπει** να έχει ρητή ετικέτα ορίσματος, ώστε η Swift να ξέρει πού τελειώνει η λίστα ορισμάτων της παραμέτρου μεταβλητού πλήθους.
~~~~

[variadic-parameters]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/functions/#Variadic-Parameters
