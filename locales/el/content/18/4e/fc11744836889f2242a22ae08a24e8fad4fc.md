# Βρόχοι `while` και `until`

Ο βρόχος είναι μια δομή ελέγχου που επιτρέπει σε κώδικα να εκτελείται ξανά και ξανά, με βάση μια συνθήκη.

## Βρόχοι `while`

Ο `while` βρόχος είναι μια δομή ελέγχου που επιτρέπει σε κώδικα να εκτελείται ξανά και ξανά, με βάση μια συνθήκη.
Ο κώδικας μέσα σε έναν `while` βρόχο συνεχίζει να εκτελείται όσο η συνθήκη αποτιμάται ως truthy.
Οι `while` βρόχοι χρησιμοποιούνται συχνά όταν δεν ξέρεις από πριν πόσες επαναλήψεις θα χρειαστούν, αλλά μπορείς να τους χρησιμοποιήσεις όπου χρειάζεσαι βρόχο.

Η συνθήκη αποτιμάται πριν εκτελεστεί ο κώδικας μέσα στον βρόχο. Αυτό σημαίνει ότι, αν η συνθήκη είναι ψευδής, ο κώδικας μέσα στον βρόχο δεν θα εκτελεστεί ποτέ.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Όταν θέλεις να διατρέξεις μια συμβολοσειρά, μπορείς να κάνεις βρόχο με βάση το μήκος της.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Βρόχοι `until`

Οι `until` βρόχοι λειτουργούν όπως οι `while` βρόχοι, με τη διαφορά ότι ο κώδικας μέσα στον βρόχο συνεχίζει να εκτελείται μέχρι η συνθήκη να αποτιμηθεί ως truthy.
Είναι η ίδια διαφορά που υπάρχει ανάμεσα στο `if` και στο `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Ατέρμονοι βρόχοι

Ένα συχνό σφάλμα με τους `while` βρόχους είναι να μπεις σε έναν "ατέρμονο βρόχο", από τον οποίο δεν βγαίνεις ποτέ.
Ένας ατέρμονος βρόχος μπορεί να προκληθεί από μια συνθήκη που δεν αποτιμάται _ποτέ_ ως truthy ή falsey.
Αυτό συνήθως οφείλεται σε λάθος του προγραμματιστή, για παράδειγμα όταν ξεχνάς να αυξήσεις τη μεταβλητή του βρόχου.
Μερικές φορές όμως, ο ατέρμονος βρόχος είναι ο πιο ξεκάθαρος τρόπος να υλοποιήσεις τη λογική του προγράμματος.
Ή μπορεί να είναι απαραίτητο ο βρόχος να τρέχει για πάντα. Για παράδειγμα, ένας διακομιστής HTTP περιμένει μια εισερχόμενη σύνδεση, την εξυπηρετεί και μετά περιμένει την επόμενη.

## `break`

Με τη λέξη-κλειδί `break` μπορείς να βγεις νωρίτερα από έναν βρόχο.
Αυτό είναι βολικό όταν θέλεις να βγεις νωρίτερα από έναν βρόχο κάτω από ορισμένες συνθήκες.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

Με τη λέξη-κλειδί `next` μπορείς να προχωρήσεις κατευθείαν στην επόμενη επανάληψη ενός βρόχου.
Αυτό είναι βολικό όταν θέλεις να παραλείψεις συγκεκριμένες επαναλήψεις ενός βρόχου.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Τύποι μέσα σε βρόχο

Ο τύπος μιας μεταβλητής μπορεί να διαφέρει μέσα σε έναν βρόχο.
Στο παρακάτω παράδειγμα, ο τύπος της `a` είναι `Int32 | String`, επειδή στο πρώτο μέρος του βρόχου μπορεί να είναι `Int32` ή `String`.
Η μεταβλητή `a` έχει τον τύπο `Int32 | String` μόνο στο πρώτο μέρος του βρόχου, αφού όταν ξεκινά ο βρόχος περιέχει `Int32` και στη δεύτερη επανάληψη περιέχει `String`.
Θα εξηγήσουμε αναλυτικά αυτό το σύστημα πολλαπλών τύπων αργότερα.
Επειδή όμως είμαστε σίγουροι ότι στο δεύτερο μέρος του βρόχου θα περιέχει μόνο `String`, ο τύπος της `a' is `String` under the second part of the loop.
At runtime, it will never simultaneously hold `Int32` and `String`.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

# `return`

Στην Crystal, μια μέθοδος επιστρέφει την τιμή της τελευταίας της έκφρασης.
Μερικές φορές όμως χρειάζεται να επιστρέψεις μια τιμή πριν από την τελευταία έκφραση.
Γι' αυτό υπάρχει η λέξη-κλειδί `return`, που επιστρέφει την τιμή της έκφρασης που ακολουθεί.
Ο κώδικας που γράφεται μετά από ένα `return` δεν εκτελείται.

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
Όταν η τελευταία έκφραση μιας μεθόδου είναι η τιμή που πρέπει να επιστραφεί, παράλειψε τη λέξη-κλειδί `return`.
~~~~
