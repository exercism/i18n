# Τοπική αποσφαλμάτωση

Όταν τρέχεις τα τεστ του track Bash με το [Bats](https://github.com/bats-core/bats-core), το Bats καταγράφει και το STDOUT και το STDERR για assertions στην έξοδο.

```exercism/caution
Αυτό λειτουργεί τοπικά με το `bats`, αλλά **όχι** στον online editor του Exercism.
```

Αν θέλεις να τυπώσεις έξοδο αποσφαλμάτωσης χωρίς να επηρεάσεις το αποτέλεσμα του τεστ, γράψε την στον περιγραφέα αρχείου (fd) 3.

```bash
echo 'debug message' >&3
```

Το Bats δείχνει την έξοδο που γράφεται στο fd 3 κατά τη διάρκεια της εκτέλεσης των τεστ, αλλά δεν τη συμπεριλαμβάνει σε assertions όπως το `assert_output`.

Παράδειγμα εκτέλεσης:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Αυτό είναι χρήσιμο όταν τρέχεις τα τεστ τοπικά.
