# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να σε βοηθήσει να μαγειρέψεις μια υπέροχη λαζάνια από το αγαπημένο σου βιβλίο μαγειρικής.

Έχεις τέσσερις εργασίες, όλες σχετικές με τον χρόνο που ξοδεύεις για να μαγειρέψεις τη λαζάνια.

## 1. Όρισε τον αναμενόμενο χρόνο στο φούρνο σε λεπτά

Όρισε τη συνάρτηση `expected_minutes_in_oven` για να ελέγξεις πόσα λεπτά πρέπει να είναι η λαζάνια στο φούρνο. Σύμφωνα με το βιβλίο μαγειρικής, ο αναμενόμενος χρόνος στο φούρνο σε λεπτά είναι 40:

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. Υπολόγισε τον υπόλοιπο χρόνο στο φούρνο σε λεπτά

Όρισε τη συνάρτηση `remaining_minutes_in_oven` που παίρνει ως παράμετρο τα πραγματικά λεπτά που η λαζάνια βρίσκεται στο φούρνο και επιστρέφει πόσα λεπτά πρέπει ακόμα να μείνει η λαζάνια στο φούρνο, με βάση τον αναμενόμενο χρόνο στο φούρνο σε λεπτά από την προηγούμενη εργασία.

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Όρισε τη συνάρτηση `preparation_time_in_minutes` που παίρνει ως παράμετρο τον αριθμό των στρώσεων που πρόσθεσες στη λαζάνια και επιστρέφει πόσα λεπτά ξόδεψες για να προετοιμάσεις τη λαζάνια, υποθέτοντας ότι κάθε στρώση σου παίρνει 2 λεπτά για προετοιμασία.

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε τη συνάρτηση `elapsed_time_in_minutes` που παίρνει δύο παραμέτρους: η πρώτη παράμετρος είναι ο αριθμός των στρώσεων που πρόσθεσες στη λαζάνια, και η δεύτερη παράμετρος είναι ο αριθμός των λεπτών που η λαζάνια βρίσκεται στο φούρνο. Η συνάρτηση θα πρέπει να επιστρέφει πόσα λεπτά έχεις δουλέψει για το μαγείρεμα της λαζάνια, που είναι το άθροισμα του χρόνου προετοιμασίας σε λεπτά και του χρόνου σε λεπτά που η λαζάνια έχει περάσει στο φούρνο τη δεδομένη στιγμή.

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
