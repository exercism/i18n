# Υποδείξεις

## Γενικά

- Η [εκτύπωση τιμών][exercism-debugging] δεν είναι μέρος της λύσης, αλλά μπορείς να χρησιμοποιήσεις το [`var_dump();`][php-vardump] για να καταλάβεις τι βλέπει η PHP.
- Μια [ακέραια τιμή][php-integers] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Τα [literals συμβολοσειρών][php-string] είναι μια ακολουθία χαρακτήρων που περικλείεται από διπλά εισαγωγικά.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να [επιστρέψεις ρητά][php-return] μια τιμή από μια συνάρτηση.
- Πρέπει να επιστρέψεις έναν [ακέραιο][php-integers].

## 2. Υπολόγισε τον υπόλοιπο χρόνο ψησίματος σε λεπτά

- Πρέπει να [επιστρέψεις ρητά][php-return] μια τιμή από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][php-integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή της αφαίρεσης][php-operators] για να αφαιρέσεις τιμές.
- Μπορείς να [καλέσεις μια από τις άλλες συναρτήσεις][exercism-methods] της κλάσης.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να [επιστρέψεις ρητά][php-return] μια τιμή από μια συνάρτηση.
- Το όρισμα της συνάρτησης είναι ένας [ακέραιος][php-integers].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή του πολλαπλασιασμού][php-operators] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να [επιστρέψεις ρητά][php-return] μια τιμή από μια συνάρτηση.
- Τα ορίσματα της συνάρτησης είναι [ακέραιοι][php-integers].
- Μπορείς να [καλέσεις μια από τις άλλες συναρτήσεις][exercism-methods] της κλάσης.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή της πρόσθεσης][php-operators] για να προσθέσεις τιμές.

## 5. Δημιούργησε μια ειδοποίηση ότι η λαζάνια είναι έτοιμη

- Πρέπει να [επιστρέψεις ρητά][php-return] μια τιμή από μια συνάρτηση.
- Πρέπει να επιστρέψεις μια [συμβολοσειρά][php-string].
