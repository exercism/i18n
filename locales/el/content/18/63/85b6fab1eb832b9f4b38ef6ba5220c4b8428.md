# Boolean

Η Swift διαθέτει έναν τύπο γνωστό ως [`Bool`][bools], ο οποίος χρησιμοποιείται για να αναπαριστά τις τιμές `true` και `false`.

## Λογικοί τελεστές

Η Swift έχει 3 [λογικούς τελεστές (`!`, `||`, `&&`)][logical-operators] που χρησιμοποιούνται για να συνδυάζουν Boolean τιμές και να δημιουργούν εκφράσεις που παράγουν διαφορετικές τιμές.

### Και(`&&`)

Ο τελεστής [_και_][and] στη Swift αναπαρίσταται με `&&` και επιστρέφει `true` αν και οι δύο τιμές που δίνονται είναι `true`, αλλιώς επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _και_, μία Boolean τιμή τοποθετείται στη δεξιά πλευρά του `&&` και μία άλλη στην αριστερή πλευρά.

```Swift
true && true  // true
true && false // false
```

### Ή(`||`)

Ο τελεστής [_ή_][or] στη Swift αναπαρίσταται με `||` και επιστρέφει `true` αν **τουλάχιστον μία** από τις τιμές που δίνονται είναι `true`· αν και οι δύο τιμές είναι `false`, τότε επιστρέφει `false`.
Όταν χρησιμοποιείς τον τελεστή _ή_, μία Boolean τιμή θα πρέπει να τοποθετείται στη δεξιά πλευρά του `||` και μία άλλη στην αριστερή πλευρά.

```swift
true || true   // true
true || false  // true
false || false // false
```

### Όχι(`!`)

Ο τελεστής [_όχι_][not] στη Swift αναπαρίσταται με `!` και επιστρέφει `true` αν η Boolean τιμή που δίνεται είναι `false` και επιστρέφει `false` αν δίνεται `true`.
Όταν χρησιμοποιείς τον τελεστή _όχι_, μία Boolean τιμή θα πρέπει να τοποθετείται μετά τον τελεστή (`!`).

```swift
!true  // false
!false // true
```

## Χρήση παρενθέσεων(`()`)

Όταν δουλεύεις με Boolean τιμές, μπορείς να χρησιμοποιήσεις [ρητές παρενθέσεις][explicit-parentheses] για να αποφασίσεις ποιες Boolean τιμές θα αξιολογηθούν πρώτες.
Το αποτέλεσμα μπορεί να διαφέρει ανάλογα με το πώς χρησιμοποιούνται οι παρενθέσεις.
Στη Swift, ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα.

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

Επειδή ό,τι βρίσκεται μέσα σε παρενθέσεις αξιολογείται πρώτα, στο παρακάτω παράδειγμα ο τελεστής _όχι_ εφαρμόζεται στην έκφραση μέσα στις παρενθέσεις.

```Swift
!true && false   // false
!(true && false) // true
```

Καλό είναι να χρησιμοποιείς παρενθέσεις μόνο όταν επηρεάζουν το αποτέλεσμα, αλλιώς να τις παραλείπεις.
