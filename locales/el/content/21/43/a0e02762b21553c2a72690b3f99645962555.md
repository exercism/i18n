# Εισαγωγή

Στην Clojure, η δέσμευση μιας τιμής σε ένα όνομα ονομάζεται _var_. Οι var κορυφαίου επιπέδου (καθολικές) μοιάζουν με τις σταθερές σε άλλες γλώσσες.

Οι var κορυφαίου επιπέδου ορίζονται με το `def`:

```clojure
(def fingers 10)

fingers
;;=> 10
```

Μπορείς να χρησιμοποιήσεις το `defn` για να ορίσεις μια συνάρτηση που δέχεται μηδέν ή περισσότερα ορίσματα. Αυτή είναι μια συνάρτηση που προσθέτει 2 αριθμούς μεταξύ τους:

```clojure
(defn add [x y]
  (+ x y))
```

Αυτή η συνάρτηση δέχεται 2 ορίσματα, τα οποία τοποθετούνται στο διάνυσμα `[x y]`, και στη συνέχεια ακολουθεί το *σώμα* της συνάρτησης, το οποίο μπορεί να περιέχει οποιονδήποτε αριθμό εκφράσεων. Η τιμή επιστροφής είναι πάντα το αποτέλεσμα της αξιολόγησης της τελευταίας έκφρασης στο σώμα, `(+ x y)`. Αυτή η έκφραση είναι μια λίστα που αντιπροσωπεύει μια κλήση συνάρτησης. Το πρώτο στοιχείο της λίστας είναι η συνάρτηση `+`, η οποία αξιολογείται χρησιμοποιώντας τα επόμενα στοιχεία `x` και `y` ως ορίσματα.

Η συνάρτηση `add` που ορίστηκε παραπάνω καλείται με τον ίδιο τρόπο:

```clojure
(add 2 3)
;;=> 5
```

Οι συναρτήσεις και οι τιμές στην Clojure μπορούν να χρησιμοποιηθούν μόνο _αφού_ οριστούν, δηλαδή τα forms αξιολογούνται πάντα με τη σειρά που εμφανίζονται.

Στην Clojure, τα κενά δεν έχουν καμία σημασία πέρα από τη μορφοποίηση.

Οι συναρτήσεις και οι var της Clojure οργανώνονται σε namespaces. Ένα namespace ομαδοποιεί σχετική λειτουργικότητα και ορίζεται με τη μακροεντολή `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Η Clojure υποστηρίζει δύο τύπους σχολίων. Τα σχόλια μίας γραμμής ξεκινούν με `;` και η μορφή `comment` χρησιμοποιείται για να αποτρέψει την αξιολόγηση όλων όσων βρίσκονται ανάμεσα στο `(comment` και το `)`.
