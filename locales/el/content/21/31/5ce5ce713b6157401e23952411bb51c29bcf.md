# Οδηγίες

Είσαι πάλι στην κουζίνα και βελτιώνεις τη συνταγή για λαζάνια από το
[Leah's Luscious Lasagna][lasagna]. Οι εργασίες εδώ σου ζητούν να
χειριστείς πολλές εισόδους ταυτόχρονα, και τότε ακριβώς είναι που τα
*locals*, οι ονομασμένες δεσμεύσεις της Factor, δικαιώνουν την ύπαρξή τους.

## 1. Προσδιόρισε την κατάσταση μαγειρέματος

Όρισε τη `cooking-status` ώστε να παίρνει μια ένδειξη του χρονοδιακόπτη
από τη στοίβα και να επιστρέφει μια συμβολοσειρά κατάστασης.

- `0` → `"Lasagna is done."`
- `f` (ο χρονοδιακόπτης δεν είχε οριστεί ποτέ) → `"You forgot to set the timer."`
- οποιοσδήποτε άλλος αριθμός → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Υπολόγισε κατά προσέγγιση τον χρόνο προετοιμασίας

Όρισε τη `preparation-time` ώστε να παίρνει έναν πίνακα με ονόματα
στρώσεων και έναν μέσο αριθμό λεπτών ανά στρώση, και να επιστρέφει τον
συνολικό χρόνο προετοιμασίας.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Υπολόγισε τα ζυμαρικά και τη σάλτσα που χρειάζεσαι

Όρισε τη `quantities` ώστε να παίρνει έναν πίνακα με ονόματα στρώσεων και
να επιστρέφει *δύο* τιμές: τα γραμμάρια ζυμαρικών που χρειάζονται (50 g
ανά στρώση ζυμαρικών) και τα λίτρα σάλτσας που χρειάζονται (`1/5` λίτρου
ανά στρώση σάλτσας).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Πρόσθεσε το μυστικό συστατικό

Ο φίλος σου στέλνει μια λίστα με συστατικά· το *τελευταίο* στοιχείο είναι
το μυστικό του. Όρισε τη `add-secret-ingredient` ώστε να παίρνει τη δική
του λίστα και τη δική σου και να επιστρέφει τη λίστα σου με το μυστικό
στο τέλος.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Κλιμάκωσε τη συνταγή

Η συνταγή του βιβλίου μαγειρικής βγάζει δύο μερίδες. Όρισε τη
`scale-recipe` ώστε να παίρνει μια συνταγή (έναν hashtable από όνομα
συστατικού σε ποσότητα) και έναν αριθμό μερίδων-στόχο, και να επιστρέφει
μια νέα συνταγή κλιμακωμένη ανάλογα.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
