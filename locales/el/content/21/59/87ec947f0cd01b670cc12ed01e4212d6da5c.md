# Σχετικά

Ένα [`Option`][option] είναι ένα [enum][enum] που χρησιμοποιείται για να ελέγχει την εγκυρότητα των τιμών επιστροφής των συναρτήσεων. Ορίζεται ως εξής:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Είναι μέρος του πακέτου [`haxe.ds`][haxeDs]:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
