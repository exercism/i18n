# Οδηγίες

Η Astrid, μια τολμηρή αλχημίστρια, προσπαθεί να τυποποιήσει τις μαγικές μονάδες μέτρησης που συλλέγει από διάφορα βασίλεια.
Κάποια βασίλεια χρησιμοποιούν προσημασμένες μετρήσεις (που μπορεί να είναι αρνητικές), ενώ άλλα χρησιμοποιούν απρόσημες (που είναι πάντα θετικές).
Επιπλέον, η Astrid έχει δύο προσαρμοσμένους τύπους για ορισμένα σπάνια συστατικά και χρειάζεται έναν τρόπο να μετατρέπει εύκολα από τον έναν τύπο στον άλλο.

Η αποστολή σου είναι να βοηθήσεις την Astrid να μετατρέπει προσημασμένους και απρόσημους ακεραίους και να δημιουργήσεις μετατροπές προσαρμοσμένων τύπων για τους ειδικούς τύπους συστατικών της, χρησιμοποιώντας τα trait `Into` και `TryInto` της Cairo.

## 1. Μετατροπή μαγικών μονάδων μεταξύ προσημασμένων και απρόσημων

Η Astrid έχει μετρήσεις που μερικές φορές έχουν θετικές ή αρνητικές τιμές (προσημασμένοι ακέραιοι), αλλά για ορισμένες εργασίες χρειάζεται να διασφαλίζει ότι οι τιμές είναι πάντα θετικές (απρόσημοι ακέραιοι).

Βοήθησε την Astrid γράφοντας μια συνάρτηση που μετατρέπει:

1. Έναν προσημασμένο ακέραιο (`i32`) σε έναν απρόσημο ακέραιο (`u16`).
2. Έναν απρόσημο ακέραιο (`u16`) σε έναν προσημασμένο ακέραιο (`i32`).

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. Μετατροπή προσαρμοσμένων τύπων συστατικών

Η Astrid δουλεύει με δύο σπάνια συστατικά, **Essence** και **Elixir**, που τα αντιπροσωπεύουν προσαρμοσμένοι τύποι.
Θέλει να μπορεί να μετατρέπει **Essence** σε **Elixir**, αλλά όχι και αντίστροφα.

Βοήθησε την Astrid δημιουργώντας δύο προσαρμοσμένους τύπους, `Essence` και `Elixir`, και υλοποιώντας το trait `Into` για μετατροπή από `Essence` σε `Elixir`.

Γράψε μια συνάρτηση που δέχεται `Essence` και το μετατρέπει σε `Elixir` χρησιμοποιώντας το `.into()`.

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
