# Υποδείξεις

## 1. Προσδιόρισε πόση ώρα χρειάζεται για να αναμείξεις έναν χυμό

- Στήσε μια [εντολή `switch`][mdn-switch] για τη μεταβλητή `name`.
- Οι διαφορετικές περιπτώσεις πρέπει να αντιστοιχούν στα διαφορετικά ονόματα χυμών.
- Χρησιμοποίησε την περίπτωση `default` για να καλύψεις όλα τα υπόλοιπα ονόματα.
- Θυμήσου ότι οι περιπτώσεις [μεταβαίνουν στην επόμενη από προεπιλογή][mdn-fallthrough], οπότε φρόντισε να κάνεις κάτι για να το αποτρέψεις.

## 2. Αναπλήρωσε το απόθεμα από φέτες λάιμ

- Χρησιμοποίησε έναν [`while` βρόχο][mdn-while] για να κόψεις το ένα λάιμ μετά το άλλο.
- Ξαναδές την [έννοια των πινάκων][concept-arrays] για να βρεις έναν τρόπο να αφαιρέσεις τα λάιμ από τη λίστα με τη σωστή σειρά.
- Στήσε μια [εντολή `switch`][mdn-switch] για να βρεις τον αριθμό των φετών για ένα συγκεκριμένο μέγεθος λάιμ.
- Πρέπει να παρακολουθείς δύο πράγματα: πόσα λάιμ έχουν ήδη κοπεί και πόσες φέτες λείπουν ακόμα.
- Μπορείς να συνδυάσεις δύο συνθήκες για τον βρόχο χρησιμοποιώντας [λογικούς τελεστές][concept-booleans].

## 3. Τελείωσε τη βάρδια

- Χρησιμοποίησε έναν [`do-while` βρόχο][mdn-do-while] για να χειριστείς τη μία παραγγελία μετά την άλλη.
- Ξαναδές την [έννοια των πινάκων][concept-arrays] για να βρεις έναν τρόπο να αφαιρέσεις τα ποτά από τη λίστα με τη σωστή σειρά.
- Έχεις ήδη μια συνάρτηση που καθορίζει τον χρόνο που χρειάζεται για να ετοιμάσεις ένα ποτό, χρησιμοποίησέ την για να μειώσεις ανάλογα τον χρόνο που απομένει.
- Μπορείς να συνδυάσεις δύο συνθήκες για τον βρόχο χρησιμοποιώντας [λογικούς τελεστές][concept-booleans].
