# Λεξικά

Τα λεξικά στη Cairo είναι αποθήκες κλειδιών-τιμών, παρόμοιες με τους χάρτες ή τους πίνακες κατακερματισμού σε άλλες γλώσσες.

Ωστόσο, έχουν κάποια μοναδικά χαρακτηριστικά εξαιτίας του αμετάβλητου μοντέλου μνήμης της Cairo.

## Βασική έννοια

Ο τύπος `Felt252Dict<T>` παρέχει λειτουργικότητα λεξικού στη Cairo, με το `felt252` ως τύπο κλειδιού και οποιονδήποτε υποστηριζόμενο τύπο `T` ως τύπο τιμής.

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## Σημαντικά χαρακτηριστικά

Σε αντίθεση με τα λεξικά σε άλλες γλώσσες, τα λεξικά της Cairo έχουν κάποιες ειδικές ιδιότητες:

1. Τα κλειδιά πρέπει να είναι τιμές `felt252`.
2. Όλα τα κλειδιά ξεκινούν σιωπηρά με τιμή μηδέν.
3. Δεν μπορείς να διαγράψεις καταχωρίσεις, μπορείς μόνο να ενημερώσεις τιμές.
4. Οι τιμές πρέπει να υλοποιούν το trait `Felt252DictValue`.

## Σημείωση για την απόδοση

Εξαιτίας του αμετάβλητου μοντέλου μνήμης της Cairo, οι πράξεις στα λεξικά έχουν πολυπλοκότητα $O(n)$, όπου $n$ είναι ο αριθμός των πράξεων που εκτελούνται στο λεξικό.

Κάθε πράξη δημιουργεί μια νέα καταχώριση που καταγράφει την αλλαγή.

## Εργασία με σύνθετους τύπους

Για τύπους που δεν υλοποιούν το `Felt252DictValue` (όπως οι πίνακες ή οι δομές), μπορείς να τους τυλίξεις σε `Nullable<T>`:

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## Διαχείριση μνήμης

Τα λεξικά υλοποιούν το trait `Destruct`, που σημαίνει ότι "συμπυκνώνονται" αυτόματα (επικυρώνονται και βελτιστοποιούνται) όταν βγουν από το πεδίο εμβέλειάς τους.

Αυτό είναι μέρος του συστήματος απόδειξης της Cairo και συμβαίνει στο παρασκήνιο.

Θυμήσου: ενώ τα λεξικά μπορεί να φαίνονται λιγότερο αποδοτικά από ό,τι σε άλλες γλώσσες, έχουν σχεδιαστεί έτσι ώστε να ταιριάζουν με τις απαιτήσεις του μοναδικού μοντέλου μνήμης και του συστήματος απόδειξης της Cairo.
