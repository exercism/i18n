Ως μελλοντική μάγισσα, η Elyse πρέπει να εξασκηθεί στα βασικά.
Έχει μια τράπουλα που θέλει να χειριστεί.

Για να τα κάνει λίγο πιο εύκολα, χρησιμοποιεί μόνο τα φύλλα 1 έως 10.

## 1. Πάρε ένα φύλλο από την τράπουλα

Επίστρεψε το φύλλο στη θέση `idx` από την τράπουλα που σου δίνεται.

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. Άλλαξε ένα φύλλο στην τράπουλα

Άλλαξε το φύλλο στη θέση `idx` με το νέο φύλλο που δίνεται και επίστρεψε την τροποποιημένη τράπουλα.
Πρόσεξε ότι αυτό θα μεταβάλει (αλλάξει) το διάνυσμα εισόδου και αυτό είναι εντάξει.

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. Βάλε ένα φύλλο στην κορυφή της τράπουλας

Βάλε το νέο φύλλο στην κορυφή της τράπουλας και επίστρεψε την τράπουλα.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. Αφαίρεσε ένα φύλλο από την τράπουλα

Αφαίρεσε το φύλλο στη θέση `idx` από την τράπουλα και επίστρεψε την τράπουλα.

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. Αφαίρεσε το πάνω φύλλο της τράπουλας

Αφαίρεσε το φύλλο στην κορυφή της τράπουλας και επίστρεψε την τράπουλα.

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. Βάλε ένα φύλλο στο κάτω μέρος της τράπουλας

Βάλε ένα νέο φύλλο στο κάτω μέρος της τράπουλας και επίστρεψε την τράπουλα.

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. Αφαίρεσε ένα φύλλο από το κάτω μέρος της τράπουλας

Αφαίρεσε το φύλλο στο κάτω μέρος της τράπουλας και επίστρεψε την τράπουλα.

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. Έλεγξε το μέγεθος της τράπουλας

Έλεγξε αν το μέγεθος της τράπουλας ισούται με ένα δεδομένο `deck_size` ή όχι.

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
