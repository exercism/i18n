# Τελεστές σύγκρισης

Η PHP έχει δέκα ενσωματωμένους τελεστές σύγκρισης:

| Όνομα  | Παράδειγμα    | Αποτέλεσμα                                             |
| ----- | ---------- | -------------------------------------------------- |
| Ίσο | `$a == $b` | αληθής αν το `$a` είναι ίσο με το `$b` μετά από αυτόματη μετατροπή τύπων. |
| Πανομοιότυπο | `$a === $b` | αληθής αν το `$a` είναι ίσο με το `$b` και ίδιου τύπου. |
| Άνισο | `$a != $b` | αληθής αν το `$a` δεν είναι ίσο με το `$b` μετά από αυτόματη μετατροπή τύπων. |
| Άνισο | `$a <> $b` | αληθής αν το `$a` δεν είναι ίσο με το `$b` μετά από αυτόματη μετατροπή τύπων. |
| Μη πανομοιότυπο | `$a !== $b` | αληθής αν το `$a` δεν είναι ίσο με το `$b` ή δεν είναι ίδιου τύπου. |
| Μικρότερο από | `$a < $b` | αληθής αν το `$a` είναι αυστηρά μικρότερο από το `$b`. |
| Μεγαλύτερο από | `$a > $b` | αληθής αν το `$a` είναι αυστηρά μεγαλύτερο από το `$b`. |
| Μικρότερο ή ίσο με | `$a <= $b` | αληθής αν το `$a` είναι μικρότερο ή ίσο με το `$b`. |
| Μεγαλύτερο ή ίσο με | `$a >= $b` | αληθής αν το `$a` είναι μεγαλύτερο ή ίσο με το `$b`. |
| Διαστημόπλοιο | `$a <=> $b` | επιστρέφει έναν ακέραιο μικρότερο από, ίσο με ή μεγαλύτερο από το `0`i όταν το `$a`. |

Η PHP έχει ξεχωριστούς ορισμούς που διακρίνουν το `equal` από το `identical`.
Μερικές φορές το `identical` αναφέρεται και ως `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
