# Τεστ

Αν το εκτελέσιμο phix βρίσκεται στο path σου, πληκτρολόγησε την εντολή:

```bash
p test 
```
Αυτό θα τρέξει το αρχείο τεστ (test.exw).

Αν το εκτελέσιμο phix δε βρίσκεται στο PATH, στα Windows πληκτρολόγησε

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Τεστ που παραλείπονται

Το να λύσεις μια άσκηση σημαίνει να περάσεις όλα τα τεστ της.
Από προεπιλογή, όλα τα τεστ στο αρχείο test.exw εκτελούνται.
Για να παραλείψεις ένα τεστ, βάλε δύο παύλες (το τυπικό σημείο σχολιασμού της Phix) στην αρχή της γραμμής.

Σημείωσε ότι τα τεστ δεν λαμβάνουν υπόψη τυχόν flags include=false στο tests.toml· αντίθετα, είναι ευθύνη
του συντάκτη του test.exw να τα συντηρεί χειροκίνητα σε αυτό το αρχείο, ώστε να αντικατοπτρίζουν την
πραγματικότητα προς όφελος του ιστότοπου Exercism (π.χ. για τη συλλογή στατιστικών του track), αλλά τίποτα
στο ίδιο το track δεν τα χρησιμοποιεί καθόλου, συμπεριλαμβανομένων ειδικά της γεννήτριας τεστ και του εκτελεστή τεστ.
