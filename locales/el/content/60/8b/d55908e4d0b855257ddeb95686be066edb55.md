# Εισαγωγή

Ένα [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) παρέχει έναν τρόπο να διακοσμήσεις μια δήλωση ώστε να συσχετίσεις μεταδεδομένα με: μια κλάση, μια μέθοδο, ένα enum, ένα πεδίο, μια ιδιότητα ή οποιεσδήποτε άλλες [υποστηριζόμενες](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets) δηλώσεις.

Μπορείς να εφαρμόσεις ένα χαρακτηριστικό προσθέτοντάς το στη γραμμή πριν από τη δήλωση, χρησιμοποιώντας ένα `ClassAttribute` και ένα `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Αυτά τα δηλωτικά μεταδεδομένα συσχετίζουν μόνο πρόσθετες δομημένες πληροφορίες με τον κώδικα και δεν τροποποιούν τη συμπεριφορά του, αλλά αυτά τα μεταδεδομένα χρησιμοποιούνται από άλλα μέρη του κώδικα για να αλλάξουν το πώς θα συμπεριφέρεται ο στόχος τους ή να προσθέσουν, να αλλάξουν ή να αφαιρέσουν, να περιορίσουν ορισμένες από τις λειτουργίες του.

Υπάρχουν πολλά [προκαθορισμένα και δεσμευμένα χαρακτηριστικά](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), για παράδειγμα: `Flags`, `Obsolete`, `Conditional`, καθένα έχει μια συγκεκριμένη λειτουργία που μπορείς να αναζητήσεις στην τεκμηρίωση της C#. Σημείωσε ότι το πλήρες όνομα ενός χαρακτηριστικού όπως το [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) είναι `FlagsAttribute` κατά σύμβαση, αλλά το επίθημα _Attribute_ μπορεί να παραλειφθεί όταν εφαρμόζεται σε μια δήλωση.
