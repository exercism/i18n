# Οδηγίες

Είσαι μέλος μιας πυροσβεστικής οργάνωσης που αποτελείται από διεθνείς εθελοντές.
Λόγω της διεθνούς σύστασης της ομάδας, πολύτιμος χρόνος έχει χαθεί στις τελευταίες κλήσεις μεταφράζοντας μεταξύ Φαρενάιτ και Κελσίου, την ώρα που υπολόγιζες τη θερμοκρασία μέσα στα φλεγόμενα κτίρια.
Για να κερδίσεις χρόνο, αλλά και ανθρώπινες ζωές, αποφασίζεις να φτιάξεις ένα πρόγραμμα που να μετατρέπει αυτόματα μεταξύ Φαρενάιτ και Κελσίου για τη διεθνή ομάδα σου.

## 1. Μετατροπή από Φαρενάιτ σε Κελσίου

Υλοποίησε τη συνάρτηση `tempToC` για να μετατρέψεις μια θερμοκρασία `Integer` σε Φαρενάιτ στην αντίστοιχη `Float` σε Κελσίου, στρογγυλοποιημένη στο πλησιέστερο εκατοστό.
Η θερμοκρασία σε βαθμούς Κελσίου ορίζεται ως: T(°C) = (T(°F) - 32) / 1.8.

```haskell
> tempToC 32
0.00
```

## 2. Μετατροπή από Κελσίου σε Φαρενάιτ

Υλοποίησε τη συνάρτηση `tempToF` για να μετατρέψεις μια θερμοκρασία `Float` σε Κελσίου στην αντίστοιχη σε Φαρενάιτ.
Για λόγους ασφάλειας, **στρογγυλοποίησε προς τα πάνω** το αποτέλεσμα στον **επόμενο μεγαλύτερο** `Integer`.
Η θερμοκρασία σε βαθμούς Φαρενάιτ ορίζεται ως: T(°F) = T(°C) × 1.8 + 32.

```Haskell
> tempToF 4
40
```
