# Εισαγωγή

Ένας **Map** είναι μια δομή δεδομένων για την αποθήκευση ζευγών κλειδιού-τιμής.
Μοιάζει με τα λεξικά σε άλλες γλώσσες προγραμματισμού.
Η διεπαφή [Map][map-javadoc] ορίζει τις λειτουργίες ενός Map.

Η Java έχει αρκετές διαφορετικές υλοποιήσεις του Map.
Το [HashMap][hashmap-javadoc] είναι μία από τις πιο συχνά χρησιμοποιούμενες.

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

Πρόσθεσε καταχωρήσεις στον Map χρησιμοποιώντας τη [put][map-put-javadoc].

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

Μόνο μία τιμή μπορεί να συσχετιστεί με κάθε κλειδί.
Αν καλέσεις τη `put` με το ίδιο κλειδί, θα ενημερωθεί η τιμή του κλειδιού.

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

Χρησιμοποίησε τη [get][map-get-javadoc] για να πάρεις την τιμή ενός κλειδιού.

```java
fruitPrices.get("apple"); // => 100
```

Χρησιμοποίησε τη [containsKey][map-containskey-javadoc] για να δεις αν ο Map περιέχει ένα συγκεκριμένο κλειδί.

```java
fruitPrices.containsKey("apple");   // => true
fruitPrices.containsKey("orange");  // => false
```

Αφαίρεσε καταχωρήσεις με τη [remove][map-remove-javadoc].

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

Η μέθοδος [size][map-size-javadoc] επιστρέφει τον αριθμό των καταχωρήσεων.

```java
fruitPrices.size();  // Returns 2
```

Μπορείς να χρησιμοποιήσεις τις μεθόδους [keySet][map-keyset-javadoc] ή [values][map-values-javadoc] για να πάρεις τα κλειδιά ή τις τιμές ενός Map ως Set ή συλλογή αντίστοιχα.

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
