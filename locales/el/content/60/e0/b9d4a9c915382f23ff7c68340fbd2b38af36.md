# Στατικές λέξεις-κλειδιά κλάσης

Μια κλάση είναι μια μονάδα οργάνωσης κώδικα στην PHP και συχνά αναπαριστά ένα στιγμιότυπο ενός πράγματος, μιας υπηρεσίας ή μιας διαδικασίας.
Χρησιμοποιώντας τις λέξεις-κλειδιά `static` και `self`, οι ιδιότητες και οι μέθοδοι μπορούν να υπάρχουν με αναφορά στην κλάση για όλα τα στιγμιότυπα (ή για κανένα στιγμιότυπο).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Περιορισμός

Οι στατικές μέθοδοι μιας κλάσης μπορούν να καλέσουν μόνο άλλες στατικές ιδιότητες ή μεθόδους της δικής τους κλάσης.

```php
<?php

class Book
{
    $name = 'Treasure Island';

    static function getName()
    {
        // This static method cannot access the instance variable
        return $this->name;
    }
}
```
