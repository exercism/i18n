# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις έναν freelancer να συνεννοηθεί με τους πελάτες του σχετικά με τις τιμές ορισμένων έργων. Θα γράψεις μερικές βοηθητικές συναρτήσεις για να υπολογίζεις γρήγορα το κόστος για τους πελάτες.

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

Ένας πελάτης επικοινωνεί με τον freelancer για να ρωτήσει για τις χρεώσεις του.
Ο freelancer εξηγεί ότι **_δουλεύει 8 ώρες την ημέρα._**
Ωστόσο, ο freelancer γνωρίζει μόνο την ωριαία χρέωσή του για το έργο.
Βοήθησέ τον να υπολογίσει μια ημερήσια χρέωση με δεδομένη την ωριαία χρέωση.

Υλοποίησε τη συνάρτηση `dailyRateFrom(hourlyRate:)`, η οποία παίρνει το όρισμα `hourlyRate` που περιέχει την ωριαία χρέωση του freelancer.  
Η συνάρτηση πρέπει να επιστρέφει την ημερήσια χρέωση με βάση την ωριαία χρέωση.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι `Double`.

## 2. Υπολόγισε τη μηνιαία χρέωση, με δεδομένες την ωριαία χρέωση και μια έκπτωση

Μερικές φορές, ένας πελάτης ενδιαφέρεται να προσλάβει τον freelancer για μεγαλύτερο χρονικό διάστημα.
Ο freelancer είναι πρόθυμος να κάνει έκπτωση στον πελάτη, αλλά μόνο αν ο πελάτης τον προσλάβει για τουλάχιστον έναν μήνα.
Συνολικά υπάρχουν **_22 εργάσιμες ημέρες_**.
Βοήθησε τον freelancer να υπολογίσει τη μηνιαία χρέωσή του, με δεδομένες την ωριαία χρέωση και το ποσοστό έκπτωσης που είναι διατεθειμένος να εφαρμόσει στη σταθερή τιμή, στρογγυλοποιημένο στον πλησιέστερο ακέραιο αριθμό.

Υλοποίησε τη συνάρτηση `monthlyRateFrom(hourlyRate:withDiscount:)`, η οποία παίρνει τα ορίσματα `hourlyRate` που περιέχει την ωριαία χρέωση του freelancer, και `withDiscount` που περιέχει την έκπτωση που είναι διατεθειμένος να δώσει ο freelancer στον πελάτη.
Η συνάρτηση πρέπει να επιστρέφει τη μηνιαία χρέωση στρογγυλοποιημένη στον πλησιέστερο ακέραιο αριθμό.

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένα έναν προϋπολογισμό, την ωριαία χρέωση και την έκπτωση

Μια άλλη μέρα, ένας υπεύθυνος έργου προτείνει στον freelancer να δουλέψει σε ένα έργο με σταθερό προϋπολογισμό.
Με δεδομένο τον σταθερό προϋπολογισμό και την ωριαία χρέωση του freelancer, βοήθησέ τον να υπολογίσει πόσες ημέρες θα δουλέψει μέχρι να εξαντληθεί ο προϋπολογισμός.
Λάβε υπόψη ότι σε αυτό το σενάριο ο freelancer είναι πάντα πρόθυμος να δώσει την έκπτωση, ανεξάρτητα από τον αριθμό των ημερών πρόσληψης.
Το αποτέλεσμα _πρέπει_ να είναι **στρογγυλοποιημένο προς τα κάτω** στον πλησιέστερο ακέραιο αριθμό.

Υλοποίησε τη συνάρτηση `workdaysIn(budget:hourlyRate:withDiscount:)`, η οποία παίρνει τα ορίσματα:
- `budget` που περιέχει τον προϋπολογισμό για το έργο.
- `hourlyRate` που περιέχει την ωριαία χρέωση του freelancer.
- `withDiscount` που περιέχει την έκπτωση που είναι διατεθειμένος να δώσει ο freelancer στον πελάτη.

Η συνάρτηση πρέπει να επιστρέφει τον αριθμό των εργάσιμων ημερών που θα δουλέψει ο freelancer στο έργο, στρογγυλοποιημένο προς τα κάτω.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
