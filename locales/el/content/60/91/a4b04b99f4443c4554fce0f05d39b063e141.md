# Εισαγωγή

Οι συμβολοσειρές στη Swift είναι μια συλλογή χαρακτήρων, όπου οι χαρακτήρες είναι, λίγο πολύ, ένα μεμονωμένο εκτυπώσιμο στοιχείο. Έτσι, οι συμβολοσειρές στη Swift μπορούν να περιέχουν χαρακτήρες Unicode και emoji.

Οι συμβολοσειρές δημιουργούνται εύκολα στη Swift μέσω των κυριολεκτικών συμβολοσειρών. Τα κυριολεκτικά συμβολοσειρών μοιάζουν με αυτά που συναντάς σε πολλές άλλες γλώσσες προγραμματισμού: χαρακτήρες που περικλείονται ανάμεσα σε ένα ζεύγος διπλών εισαγωγικών (`"`). Κάποιοι χαρακτήρες χρησιμοποιούν ειδικό συμβολισμό μέσα στις συμβολοσειρές ώστε να μπορούν να αναπαρασταθούν σωστά, όπως ο χαρακτήρας αλλαγής γραμμής που γράφεται ως `\n` μέσα στις συμβολοσειρές ή ο χαρακτήρας του διπλού εισαγωγικού που γράφεται ως `\"` μέσα σε μια συμβολοσειρά, ώστε ο μεταγλωττιστής να ξέρει ότι δεν είναι το διπλό εισαγωγικό που τερματίζει τη συμβολοσειρά.

Μια κενή συμβολοσειρά αναπαρίσταται από δύο διπλά εισαγωγικά χωρίς τίποτα ανάμεσά τους.

```swift
let hello = "Hello, World!"
let sausage = "Weißwurst is a tasty sausage."
var fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶"
var empty = ""
```
