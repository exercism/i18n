# Υποδείξεις

## Γενικά

- Διάβασε για τα [σφάλματα][errors] στον οδηγό Getting Started.
- Διάβασε για το [`try`][docs-try] στην τεκμηρίωση.

## 1. Προειδοποίησε την ομάδα

- Επίτρεψε στη συνάρτηση της πράξης να πετάξει το σφάλμα της.
- Για να καλέσεις μια συνάρτηση που βρίσκεται σε μια μεταβλητή, χρησιμοποίησε τον τελεστή `.`.

## 2. Περιτύλιξε το σφάλμα

- Χρησιμοποίησε το try .. rescue για να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 3. Προώθησε το μήνυμα

- Χρησιμοποίησε το try .. rescue για να επιστρέψεις το επιθυμητό αποτέλεσμα.
- Το μπλοκ rescue σου επιτρέπει να κάνεις αντιστοίχιση προτύπων στο όνομα Module του σφάλματος και να δεσμεύσεις το σφάλμα σε μια μεταβλητή.
