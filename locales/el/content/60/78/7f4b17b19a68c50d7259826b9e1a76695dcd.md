# Υποδείξεις

## Γενικά

- Διάβασε την επίσημη τεκμηρίωση για τα [εύρη][range].

## 1. Όρισε το εύρος των γραμμών

- Υπάρχει ένας [ειδικός τελεστής][range-creation-operator] για τη δημιουργία ευρών.

## 2. Όρισε το εύρος των στηλών

- Υπάρχει ένας [ειδικός τελεστής][range-creation-operator] για τη δημιουργία ευρών.
- Υπάρχει μια [ειδική σύνταξη][unicode-code-points] για να γράψεις ένα σημείο κώδικα χαρακτήρα χωρίς να γνωρίζεις ρητά την τιμή του.

## 3. Μετέτρεψε το εύρος των γραμμών σε λίστα με γραμμές

- Τα εύρη υλοποιούν το πρωτόκολλο `Enumerable`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-to-list] για να μετατρέψεις μια απαριθμήσιμη δομή δεδομένων σε λίστα.

## 4. Μετέτρεψε το εύρος των στηλών σε λίστα με στήλες

- Τα εύρη υλοποιούν το πρωτόκολλο `Enumerable`.
- Υπάρχει μια [ενσωματωμένη συνάρτηση][enum-map] για να μετατρέψεις μια απαριθμήσιμη δομή δεδομένων σε λίστα τροποποιώντας παράλληλα τα στοιχεία της.
- Η [ειδική μορφή bitstring][bitstring-special-form] μπορεί να χρησιμοποιηθεί για να μετατρέψεις ένα σημείο κώδικα σε συμβολοσειρά.
