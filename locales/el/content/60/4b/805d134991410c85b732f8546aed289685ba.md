# Σχετικά

Η απαρίθμηση είναι η διαδικασία να διατρέχουμε μια συλλογή (`Array`, `Hash`, κ.λπ.) και να εκτελούμε κάποια ενέργεια πάνω σε κάθε αντικείμενο.

Η απαρίθμηση είναι μια βασική έννοια στη Ruby και χρησιμοποιείται για ταξινόμηση (`sort_by`), ομαδοποίηση (`group_by`), απεικόνιση (`map`), αναγωγή (`reduce`) και πολλά άλλα.
Θα τη συναντήσεις πιο συχνά ως τον ιδιωματικό τρόπο για να διατρέχεις συλλογές, αντί να χρησιμοποιείς βρόχους.

Μια απλή απαρίθμηση για να εκτυπώσουμε κάθε λέξη ενός πίνακα θα έμοιαζε κάπως έτσι:

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

Σε αυτό το παράδειγμα, έχουμε καλέσει τη μέθοδο `Array#each` και έχουμε περάσει ένα _μπλοκ_, το οποίο παίρνει μία παράμετρο (`word`) και την εκτυπώνει.

Μπορούμε επίσης να συνδέσουμε μεθόδους απαρίθμησης σε αλυσίδα.
Για παράδειγμα, μπορούμε να συνδέσουμε το `.with_index` στο `each`, για να εκτυπώσουμε και τη θέση ενός αντικειμένου, καθώς και την τιμή του:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

Η απαρίθμηση αντικειμένων `Hash` είναι ακριβώς η ίδια με την απαρίθμηση αντικειμένων `Array`, με τη διαφορά ότι το μπλοκ δέχεται δύο ορίσματα: το κλειδί και την τιμή:

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

Οι μέθοδοι που περιγράφονται παραπάνω αποτελούν μέρος του [αρθρώματος `Enumerable`][enumerable-module], το οποίο περιλαμβάνεται στον `Array`, στον `Hash` και σε άλλες κλάσεις που χρειάζονται τη δυνατότητα απαρίθμησης.

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
