# Εισαγωγή

## Σύγκριση

Στη Go οι αριθμοί μπορούν να συγκριθούν με τους παρακάτω τελεστές σύγκρισης και ισότητας.

| Σύγκριση          | Τελεστής  |
| ------------------| --------- |
| ίσο               | `==`      |
| όχι ίσο           | `!=`      |
| μικρότερο         | `<`       |
| μικρότερο ή ίσο   | `<=`      |
| μεγαλύτερο        | `>`       |
| μεγαλύτερο ή ίσο  | `>=`      |

Το αποτέλεσμα της σύγκρισης είναι πάντα μια Boolean τιμή, δηλαδή είτε `true` είτε `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Οι παραπάνω τελεστές σύγκρισης μπορούν να χρησιμοποιηθούν και για τη σύγκριση συμβολοσειρών.
Σε αυτή την περίπτωση εφαρμόζεται λεξικογραφική σειρά (όπως σε ένα λεξικό).
Για παράδειγμα:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Εντολές `if`

Οι συνθήκες στη Go είναι παρόμοιες με τις συνθήκες σε άλλες γλώσσες.
Ο υποκείμενος τύπος κάθε πράξης συνθήκης είναι ο τύπος `bool`, ο οποίος μπορεί να έχει την τιμή `true` ή `false`.
Οι συνθήκες χρησιμοποιούνται συχνά ως μηχανισμοί ελέγχου ροής, για τον έλεγχο διαφόρων περιπτώσεων.

Για να ελέγξεις μια συγκεκριμένη περίπτωση, μπορείς να χρησιμοποιήσεις μια εντολή `if`, η οποία εκτελεί τον κώδικά της αν η συνθήκη είναι `true`, όπως εδώ:

```go
var value string

if value == "val" {
    return "was val"
}
```

Σε σενάρια με περισσότερες από μία περιπτώσεις, πολλές εντολές `if` μπορούν να συνδεθούν μεταξύ τους με τις εντολές `else if` και `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Οι εντολές `if` μπορούν επίσης να περιλαμβάνουν μια σύντομη εντολή αρχικοποίησης, η οποία μπορεί να χρησιμοποιηθεί για να αρχικοποιήσει μία ή περισσότερες μεταβλητές για την εντολή `if`.
Για παράδειγμα:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Σημείωση: οποιεσδήποτε μεταβλητές δημιουργούνται στην εντολή αρχικοποίησης βγαίνουν εκτός εμβέλειας μετά το τέλος της εντολής if.
