# Οδηγίες

Δεδομένου ενός κειμένου εισόδου, βγάλε το μετατεθειμένο.

Χονδρικά εξηγημένο, η μετάθεση ενός πίνακα:

```text
ABC
DEF
```

δίνεται από:

```text
AD
BE
CF
```

Οι γραμμές γίνονται στήλες και οι στήλες γίνονται γραμμές.
Δες [μετάθεση][transpose].

Αν η είσοδος έχει γραμμές με διαφορετικά μήκη, αυτό λύνεται ως εξής:

- Συμπλήρωσε με κενά στα αριστερά.
- Μη συμπληρώνεις στα δεξιά.

Επομένως, μεταθέτοντας αυτόν τον πίνακα:

```text
ABC
DE
```

δίνει:

```text
AD
BE
C
```

Και μεταθέτοντας:

```text
AB
DEF
```

δίνει:

```text
AD
BE
 F
```

Γενικά, όλοι οι χαρακτήρες από την είσοδο θα πρέπει επίσης να υπάρχουν και στο μετατεθειμένο αποτέλεσμα.
Αυτό σημαίνει ότι αν μια στήλη στο κείμενο εισόδου περιέχει μόνο κενά στην κατώτατη γραμμή/-ές της, η αντίστοιχη γραμμή εξόδου θα πρέπει να περιέχει τα κενά στη δεξιότερη στήλη/-ές της.

[transpose]: https://en.wikipedia.org/wiki/Transpose
