# Getters και setters

Τα getters και τα setters είναι μέθοδοι που σου επιτρέπουν να διαβάζεις και να γράφεις την τιμή μιας ιδιότητας ενός αντικειμένου.
Η Crystal έχει macros, κάτι που κάνει εύκολο τον ορισμό getters και setters για μια ιδιότητα.
Τα macros είναι ένας τρόπος να παράγεις κώδικα σε χρόνο μεταγλώττισης, κάτι που θα καλυφθεί αργότερα στην έννοια των macros.

Στη Ruby αυτές οι μέθοδοι ορίζονται με τις μεθόδους `attr_reader`, `attr_writer` και `attr_accessor` και, εκ πρώτης όψεως, μοιάζουν πολύ με την υλοποίηση της Crystal.
Η Crystal τις έχει ορίσει ως τα macros `getter`, `setter` και `property`.

## Getters

Το getter είναι ένα macro που ορίζει μια μέθοδο που επιστρέφει την τιμή μιας μεταβλητής στιγμιοτύπου.
Αυτό σημαίνει ότι δεν χρειάζεται πια να γράφεις `@` μπροστά από τη μεταβλητή στιγμιοτύπου όταν θέλεις να έχεις πρόσβαση σε αυτήν (μέσα σε μεθόδους, εκτός από την initialize). Αντ' αυτού, μπορείς να καλέσεις τη μέθοδο που έχει ορίσει το macro getter.

Το macro getter μπορεί να δεχτεί πολλές μεταβλητές στιγμιοτύπου, χωρίζοντάς τες με κόμματα.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

Όπως βλέπεις, χρησιμοποιώντας το getter γράφεις λιγότερο κώδικα και ο κώδικας γίνεται πιο ευανάγνωστος.
Επίσης, η Ruby και η Crystal διαφέρουν στο ότι η Crystal δέχεται ως ορίσματα για το macro getter τόσο το όνομα της μεταβλητής όσο και το symbol.
Τα symbols θα καλυφθούν αργότερα στην έννοια των symbols.

## Setters

Το setter είναι ένα macro που ορίζει μια μέθοδο που θέτει την τιμή μιας μεταβλητής στιγμιοτύπου.
Αυτό το macro δεν συναντάται τόσο συχνά, και συνήθως χρησιμοποιείται αντ' αυτού το macro `property`.
Οι μέθοδοι που θα δημιουργηθούν θα έχουν τη μορφή `name_of_method=`. Το `=` είναι αυτό που επιτρέπει τον ορισμό της ιδιότητας.

Αυτός ο ορισμός μεθόδου είναι λίγο ιδιαίτερος, αφού το όρισμα που δέχεται η μέθοδος βρίσκεται μετά το σύμβολο `=`.
Αρκετές άλλες ιδιαίτερες μέθοδοι στην Crystal χρησιμοποιούν αυτή τη σύνταξη, όπως η μέθοδος `+`.

Όπως και με το macro getter, όταν θέλεις να ενημερώσεις την τιμή μιας μεταβλητής στιγμιοτύπου αφού ορίσεις ένα setter, μπορείς να καλέσεις τη μέθοδο που έχει ορίσει το macro setter.

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Το property είναι ένα macro που ορίζει ταυτόχρονα ένα getter και ένα setter για μια μεταβλητή στιγμιοτύπου.

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
