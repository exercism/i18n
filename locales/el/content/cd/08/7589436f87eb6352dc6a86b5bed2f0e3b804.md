# Οδηγίες

Ο καθένας από εμάς κληρονομεί από τους βιολογικούς του γονείς ένα σύνολο χημικών οδηγιών γνωστών ως DNA, που επηρεάζουν το πώς χτίζεται το σώμα μας. Όλη η γνωστή ζωή εξαρτάται από το DNA!

> Σημείωση: Δεν χρειάζεται να καταλάβεις τίποτα σχετικά με τα νουκλεοτίδια ή το DNA για να ολοκληρώσεις αυτή την άσκηση.

Το DNA είναι μια μακριά αλυσίδα από άλλες χημικές ουσίες, και οι πιο σημαντικές είναι τα τέσσερα νουκλεοτίδια: αδενίνη, κυτοσίνη, γουανίνη και θυμίνη. Μια μόνο αλυσίδα DNA μπορεί να περιέχει δισεκατομμύρια από αυτά τα τέσσερα νουκλεοτίδια, και η σειρά με την οποία εμφανίζονται είναι σημαντική!
Τη σειρά αυτών των νουκλεοτιδίων σε ένα κομμάτι DNA την ονομάζουμε "αλληλουχία DNA".

Αναπαριστούμε μια αλληλουχία DNA ως ένα διατεταγμένο σύνολο αυτών των τεσσάρων νουκλεοτιδίων, και ένας συνηθισμένος τρόπος να το κάνουμε αυτό είναι με μια συμβολοσειρά χαρακτήρων, όπως "ATTACG" για μια αλληλουχία DNA 6 νουκλεοτιδίων.
Το 'A' για την αδενίνη, το 'C' για την κυτοσίνη, το 'G' για τη γουανίνη και το 'T' για τη θυμίνη.

Δεδομένης μιας συμβολοσειράς που αναπαριστά μια αλληλουχία DNA, μέτρησε πόσα από κάθε νουκλεοτίδιο υπάρχουν.
Αν η συμβολοσειρά περιέχει χαρακτήρες που δεν είναι A, C, G ή T, τότε είναι άκυρη και πρέπει να πετάξεις ένα σφάλμα.

Για παράδειγμα:

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
