# Debug

Όταν αποτυγχάνει ένα test, εμφανίζεται ένα μήνυμα που περιγράφει τι πήγε στραβά και για ποια είσοδο. Μπορείς επίσης να εκμεταλλευτείς το γεγονός ότι θα εμφανίζεται κι ό,τι τυπώνεται στην "τυπική έξοδο". Μπορείς να γράψεις στην τυπική έξοδο χρησιμοποιώντας το `println!`:

```rust
println!("Debug message");
```

Χρησιμοποίησε άγκιστρα `{}` για να τυπώσεις την τιμή μιας μεταβλητής ή μιας έκφρασης:

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

Σημείωσε ότι δε μπορούν να τυπωθούν όλοι οι τύποι με αυτόν τον τρόπο, μόνο όσοι μπορούν να παρουσιαστούν στους χρήστες χωρίς ασάφεια. Για παράδειγμα, τα διανύσματα (λίστες) δε μπορούν να τυπωθούν έτσι, γιατί δεν είναι σαφές πώς θα έπρεπε να εμφανίζεται ένα διάνυσμα στους χρήστες! Για αυτούς τους άλλους τύπους, μπορείς να πεις στο macro `println!` να χρησιμοποιήσει _μορφοποίηση debug_ με: `{:?}`. Αυτή η αναπαράσταση προορίζεται να τη βλέπουν μόνο οι προγραμματιστές. Ένα παράδειγμα:

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

Υπάρχει ακόμη και το εύχρηστο macro `dbg!`, το οποίο μπορείς να χρησιμοποιήσεις για να κάνεις debug μεγάλες εκφράσεις επιτόπου, χωρίς να χρειάζεται να τις αναλύσεις σε ξεχωριστές δηλώσεις μεταβλητών.

Ας υποθέσουμε ότι έχουμε την παρακάτω έκφραση:

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

Τώρα θα θέλαμε να δούμε τι επιστρέφει η κλήση στο `collect`. Θα μπορούσαμε να κάνουμε το εξής:

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

Αλλά είναι κουραστικό! Δε θέλουμε να ξαναγράψουμε τις ωραίες εκφράσεις μας μόνο και μόνο για να μπορούμε να τις κάνουμε debug. Ας υποδεχτούμε στη σκηνή: `dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

Τα κενά είναι μόνο για λόγους σαφήνειας. Μπορείς να τυλίξεις οποιαδήποτε έκφραση σε `dbg!()`, το οποίο θα τυπώσει αυτή την τιμή (με μορφοποίηση debug). Στη συνέχεια μπορείς να συνεχίσεις να χρησιμοποιείς την τιμή σε μια μεγαλύτερη έκφραση, σαν να μην ήταν καν εκεί το `dbg!`.

Καλό debugging!
