# Υποδείξεις

## 1. Κατέγραψε με regex τις πληροφορίες που χρειάζονται για να δημιουργήσεις τις κάρτες

- Το `\p{L}` θα ταιριάξει με οποιοδήποτε γράμμα από οποιαδήποτε γλώσσα.
- Μπορείς να χρησιμοποιήσεις την παρακάτω έκφραση για να καταγράψεις τις πληροφορίες:
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
