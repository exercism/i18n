# Σχετικά

Ένα `DateTime` στη C# είναι ένα αμετάβλητο αντικείμενο που περιέχει πληροφορίες τόσο για την ημερομηνία _όσο και_ για την ώρα. Μπορείς να έχεις πρόσβαση στις πληροφορίες ημερομηνίας και ώρας μέσω των ενσωματωμένων [ιδιοτήτων][properties] του.

Μπορείς να χειριστείς ένα `DateTime` καλώντας μία από τις [μεθόδους][methods] του. Επειδή οι τιμές `DateTime` δεν μπορούν ποτέ να αλλάξουν αφού οριστούν, όλες οι μέθοδοι που φαίνεται να τροποποιούν ένα `DateTime` στην πραγματικότητα επιστρέφουν ένα νέο `DateTime`.

Μπορείς να συγκρίνεις στιγμιότυπα `DateTime` χρησιμοποιώντας τους προεπιλεγμένους τελεστές σύγκρισης (`<`, `>`, κ.λπ.). Μπορείς να ανακτήσεις την τρέχουσα ημερομηνία (και ώρα) μέσω της ιδιότητας `DateTime.Now`.

Μια σημαντική πτυχή των ημερομηνιών στη C# είναι ότι εξαρτώνται από την κουλτούρα. Έτσι, οποιαδήποτε μέθοδος `DateTime` που έχει να κάνει με `string`s θα εξαρτάται από την τρέχουσα κουλτούρα. Αυτό περιλαμβάνει τη μέθοδο [`DateTime.Parse()`][parse] που μετατρέπει μια `string` σε `DateTime`, καθώς και τη μέθοδο [`ToString()`][to-string] της κλάσης `DateTime` που μετατρέπει ένα `DateTime` σε `string`.
