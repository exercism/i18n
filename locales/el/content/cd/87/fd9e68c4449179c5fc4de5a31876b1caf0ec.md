# Θέση κράτησης

## Γενικά

- Η `rand` [αριθμητική συνάρτηση][rand-func] μπορεί να παράγει τυχαίους αριθμούς.
- Η `srand` [αριθμητική συνάρτηση][srand-func] θα σου φανεί χρήσιμη για να ορίσεις το seed για τη `rand`.

## Δημιουργία λαβυρίνθου

Μπορείς να χρησιμοποιήσεις οποιονδήποτε αλγόριθμο για να δημιουργήσεις έναν τέλειο λαβύρινθο. Ο [αναδρομικός αλγόριθμος οπισθοδρόμησης][recursive-backtracker] είναι καλή επιλογή.
