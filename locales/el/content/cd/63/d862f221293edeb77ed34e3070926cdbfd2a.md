# προτίμησε σταθερά στο ανώτατο επίπεδο

Αντί να ορίσεις τη σταθερά _μέσα_ στη συνάρτηση, σκέψου να τη μεταφέρεις στο ανώτατο επίπεδο. Οι σταθερές, οι συναρτήσεις και οι κλάσεις που δεν έχουν `export`, δεν είναι προσβάσιμες εκτός του αρχείου.

```javascript
const %{name} = %{value}

export const gigasecond = (...)
```
