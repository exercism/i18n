# Προσθήκη στις οδηγίες

## Υποδείξεις

Η τιμή επιστροφής της `countWords` μπορεί να είναι οποιοσδήποτε τύπος πίνακα κατακερματισμού με κλειδί `string` και τιμή `int`.

Οι πίνακες κατακερματισμού (γνωστοί και ως "dictionaries" ή "maps" σε άλλες γλώσσες προγραμματισμού) υλοποιούνται από το module `tables` - δες την [documentation]

Για παράδειγμα, η `countWords` θα μπορούσε να επιστρέψει ένα `TableRef[string, int]`

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
