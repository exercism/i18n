# Υποδείξεις

## Γενικά

- Δώσε μεγάλη προσοχή στη σύνταξη των δεικτών.
  Θα χρησιμοποιήσεις τον `*` (τελεστή αποαναφοράς) και τον `->` (πρόσβαση σε μέλος μέσω δείκτη).
- Φρόντισε να ελέγχεις για μηδενικούς δείκτες (`nullptr`) όπου χρειάζεται, ώστε να αποφύγεις την πρόσβαση σε μη έγκυρη μνήμη.
- Μπορείς να τρέξεις τα tests ακόμα κι αν ο κώδικάς σου δεν είναι ολοκληρωμένος· μια πρόχειρη δομή αρκεί για να δεις τα αποτελέσματα των tests.
- Όλες οι συναρτήσεις που χρησιμοποιούν τα tests πρέπει να δηλώνονται στο αρχείο κεφαλίδας.
- Αν το πρόγραμμά σου κρασάρει ή συμπεριφέρεται απρόβλεπτα, συχνά φταίει η αποαναφορά ενός μηδενικού δείκτη.
  Βεβαιώσου ξανά ότι χειρίζεσαι σωστά το `nullptr`.
- Όταν χρησιμοποιείς αριθμητική δεικτών, βεβαιώσου ότι μένεις μέσα στα όρια του πίνακα αισθητήρων.
  Το να ξεπεράσεις τη χωρητικότητα του πίνακα μπορεί να προκαλέσει προβλήματα μνήμης.

## 1. Έλεγξε τη σύνδεση του αισθητήρα (`connection_check`)

- Η εργασία αφορά κυρίως την επαλήθευση του αν ένας δείκτης είναι μηδενικός ή όχι.
- Χρησιμοποίησε τον τελεστή σύγκρισης `!=` για να ελέγξεις αν ένας δείκτης είναι έγκυρος.
- Αν δεν είσαι σίγουρος ότι ελέγχεις σωστά τον δείκτη, σκέψου τι αντιπροσωπεύει το `nullptr` (την απουσία μιας έγκυρης διεύθυνσης μνήμης).


## 2. Μέτρησε τη δραστηριότητα των αισθητήρων (`activity_counter`)

- Πρέπει να διατρέξεις τον πίνακα των αισθητήρων.
  Ένας πίνακας στη C++ μπορεί να αντιμετωπιστεί ως δείκτης στο πρώτο του στοιχείο.
- Χρησιμοποίησε αριθμητική δεικτών (`sensor_array + i`) για να προσπελάσεις τον αισθητήρα στη θέση `i`.
- Ο τελεστής `->` χρησιμοποιείται για να προσπελάσεις ένα μέλος της δομής μέσω ενός δείκτη.

### Παράδειγμα

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. Έλεγχος συναγερμού (`alarm_control`)

- Πρώτα, έλεγξε αν ο δείκτης είναι μηδενικός πριν προσπελάσεις τον αισθητήρα.
- Χρησιμοποίησε τον τελεστή `->` για να προσπελάσεις το μέλος `activity` της δομής `pillar_men_sensor`.
- Σκέψου προσεκτικά τι πρέπει να συμβεί αν το επίπεδο δραστηριότητας του αισθητήρα είναι `0`.
  Πρέπει να ενεργοποιηθεί ο συναγερμός;

## 4. Έλεγχος των δεδομένων για ανωμαλίες με τη συνάρτηση `uv_alarm`

- Χρησιμοποίησε τον τελεστή `&` για να περάσεις έναν δείκτη στον πίνακα δεδομένων του αισθητήρα στη συνάρτηση `uv_light_heuristic`.
- Βεβαιώσου ότι ελέγχεις σωστά για μηδενικό δείκτη πριν προσπελάσεις τα δεδομένα του αισθητήρα.
- Σύγκρινε το αποτέλεσμα της `uv_light_heuristic` με την τιμή `activity` του αισθητήρα για να καθορίσεις αν πρέπει να ενεργοποιηθεί ο συναγερμός.
