# Εισαγωγή

Το `when` της Kotlin είναι μια έκφραση υπό συνθήκη για να διαλέγεις ανάμεσα σε πολλές επιλογές.
Μοιάζει με το `switch` της Java και είναι πιο ευέλικτο από μια αλυσίδα `if` ... `else if` ... `else`.

Όπως το `if`, έτσι και το `when` μπορεί να χρησιμοποιηθεί ως έκφραση που παράγει μια τιμή.

## Αντιστοίχιση μιας τιμής

Δώσε στο `when` μια τιμή για αντιστοίχιση μέσα σε παρενθέσεις.
Κάθε κλάδος συγκρίνει αυτή την τιμή μέχρι να βρεθεί αντιστοιχία:

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- Κάθε κλάδος γράφεται ως `pattern -> result`.
- Οι κλάδοι δοκιμάζονται από πάνω προς τα κάτω μέχρι να βρεθεί αντιστοιχία.
  Εκτελείται μόνο ο πρώτος κλάδος.
- Χρησιμοποίησε `else` για κάθε τιμή που δεν αναφέρεται παραπάνω (παρόμοια με το τελικό `else` σε μια αλυσίδα `if`).

Αυτό μοιάζει με την [αντιστοίχιση μοτίβων][pattern-matching].
Το `pattern` μπορεί να είναι μια τιμή για αντιστοίχιση ή μπορείς να χρησιμοποιήσεις το `is` για αντιστοίχιση με βάση τον τύπο:

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

ή χρησιμοποίησε το `in` για να ελέγξεις αν περιέχεται σε ένα εύρος, σε μια συλλογή, σε μια συμβολοσειρά ή σε οτιδήποτε άλλο έχει μέθοδο `contains`:

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## Συνθήκες φύλαξης

Όταν αντιστοιχίζεις μια τιμή, μπορείς να βάλεις επιπλέον συνθήκες σε ένα `if` μετά το μοτίβο.
Αυτές οι συνθήκες ονομάζονται συνθήκες φύλαξης.

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

Μπορεί να χρησιμοποιηθεί ακόμη και το `else if`.

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## Αντιστοίχιση συνθηκών

Εναλλακτικά, μπορείς να παραλείψεις την τιμή και να βάλεις λογικές συνθήκες σε κάθε κλάδο:

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

Και πάλι, οι κλάδοι ελέγχονται από πάνω προς τα κάτω και εκτελείται μόνο ο πρώτος κλάδος του οποίου η συνθήκη είναι `true`.

## Χρήση του `when` ως έκφρασης

Όταν το `when` χρησιμοποιείται για το αποτέλεσμά του (ανάθεση σε μια μεταβλητή, επιστροφή από μια συνάρτηση κ.ο.κ.), πρέπει να καλύπτεται κάθε πιθανή περίπτωση.

- Όταν αντιστοιχίζεις με μια τιμή, πρόσθεσε `else` εκτός αν έχουν ήδη καλυφθεί όλες οι πιθανές τιμές (για παράδειγμα, όλες οι τιμές ενός `Boolean` ή ενός `enum`).
- Όταν αντιστοιχίζεις συνθήκες, ο κλάδος `else` είναι υποχρεωτικός, γιατί ο μεταγλωττιστής δεν μπορεί να ξέρει ότι οι συνθήκες σου καλύπτουν κάθε περίπτωση.

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
