# Τεστ

Μπορείς να χρησιμοποιήσεις τον online editor της ιστοσελίδας του Exercism για να λύσεις τις ασκήσεις.
Ή κατέβασε τις ασκήσεις στον υπολογιστή σου, λύσε τις τοπικά και μετά υπόβαλέ τις στο Exercism.

Αν θέλεις να δουλέψεις τοπικά, θα χρειαστείς το πρόγραμμα [`bats`][bats].
Ρίξε μια ματιά στη σελίδα [Τεστ στο track Bash][test-bash] για τις οδηγίες εγκατάστασης.

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
