# Οδηγίες

Σε αυτή την άσκηση, πρέπει να υλοποιήσεις μερικούς κανόνες από το [Pac-Man][Pac-Man], το κλασικό παιχνίδι arcade της δεκαετίας του 1980.

Υπάρχουν έξι εργασίες συνολικά, οι τέσσερις από αυτές είναι κανόνες που σχετίζονται με τις καταστάσεις του παιχνιδιού.

> _Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα μέσα στις συναρτήσεις, επικεντρώσου απλώς στον συνδυασμό των ορισμάτων ώστε να επιστρέψεις το επιθυμητό αποτέλεσμα._


## 0. Όρισε μια κατάσταση ισχύος

Όρισε μια μεταβλητή με το όνομα `PowerOn` με μια τιμή που να αναπαριστά ότι η ισχύς είναι πράγματι ενεργή.

```powershell
> $PowerOn
True
```

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `EatGhost` που παίρνει δύο παραμέτρους (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια τιμή Boolean (λογική τιμή) αν ο Pac-Man μπορεί να φάει το φάντασμα.
Η συνάρτηση θα πρέπει να επιστρέφει `True` μόνο αν ο Pac-Man έχει ενεργό power pellet και αγγίζει ένα φάντασμα.

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `Score` που παίρνει δύο παραμέτρους (_αν ο Pac-Man αγγίζει ένα power pellet_ και _αν ο Pac-Man αγγίζει μια τελεία_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man σκόραρε.
Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα power pellet ή μια τελεία.

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `Lose` που παίρνει δύο παραμέτρους (_αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man χάνει.
Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό power pellet.

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `Win` που παίρνει τρεις παραμέτρους (_αν ο Pac-Man έχει φάει όλες τις τελείες_, _αν ο Pac-Man έχει ενεργό power pellet_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man κερδίζει.
Η συνάρτηση θα πρέπει να επιστρέφει `True` αν ο Pac-Man έχει φάει όλες τις τελείες και δεν έχει χάσει με βάση τις παραμέτρους που ορίστηκαν στο μέρος 3.

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. Γράψε τη Σύνοψη για τη συνθήκη νίκης

Πήγαινε πίσω στην τελευταία συνάρτηση και πρόσθεσε μια ενότητα `Synopsis` στο μπλοκ σχολίων ως σύντομη περιγραφή του τρόπου με τον οποίο κερδίζεις το παιχνίδι.
Η περιγραφή θα πρέπει να έχει μήκος τουλάχιστον δέκα χαρακτήρες.

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
