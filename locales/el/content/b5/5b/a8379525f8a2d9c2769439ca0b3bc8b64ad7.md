# Σχετικά

Η Haxe υποστηρίζει ανάκλαση τύπων και πεδίων κατά τον χρόνο εκτέλεσης. Για να χρησιμοποιήσεις σωστά την ανάκλαση, πρέπει να καταλάβεις ποιου είδους πράξεις υποστηρίζονται και ποιες όχι. Δεδομένης της δυναμικής φύσης της ανάκλασης, αυτό δεν μπορεί πάντα να προσδιοριστεί κατά τη μεταγλώττιση.

Το API της ανάκλασης αποτελείται από δύο κλάσεις:

- `Reflect`: Ένα ελαφρύ API που λειτουργεί καλύτερα με ανώνυμες δομές, με περιορισμένη υποστήριξη για κλάσεις.
- `Type`: Ένα πιο ισχυρό API για εργασία με κλάσεις και enums.

Οι διαθέσιμες μέθοδοι περιγράφονται αναλυτικά στο API για τα [Reflect][reflect] και [Type][type].

Για το παρακάτω παράδειγμα, χρησιμοποιούμε τον στόχο JavaScript:

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
