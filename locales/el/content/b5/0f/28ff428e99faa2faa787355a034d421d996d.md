# Υποδείξεις

## 1. Μετονόμασε μια στήλη

- Θυμήσου, πρέπει να τροποποιήσεις το σύνολο δεδομένων `trees`, το οποίο είναι διαθέσιμο αν καλέσεις τη `library(datasets)`.
- Ίσως (ή ίσως όχι) να θέλεις να μετατρέψεις το αρχικό `data.frame` σε `tibble`.
- Δες την Εισαγωγή για το πώς να αλλάξεις το όνομα μιας στήλης.

## 2. Πρόσθεσε στήλες περιμέτρου και βάρους

- Δες την Εισαγωγή για το πώς να προσθέσεις στήλες.
- Οι νέες στήλες μπορούν να υπολογιστούν με τις υπάρχουσες στήλες.
- Μην ξεχάσεις να στρογγυλοποιήσεις στην απαιτούμενη ακρίβεια.

## 3. Αντίγραφο του συνόλου δεδομένων για τον οπωρώνα

- Πρέπει να αναδιατάξεις στήλες και να ταξινομήσεις γραμμές (δες την Εισαγωγή).

## 4. Αντίγραφο του συνόλου δεδομένων για τον πελάτη

- Θα χρειαστεί να πάρεις ένα υποσύνολο των στηλών.
- Μόνο τα δέντρα με ύψος από το ελάχιστο έως το μέγιστο *και* βάρος κάτω από το μέγιστο θα πρέπει να βρίσκονται στο αντίγραφο.
