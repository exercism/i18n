# Οδηγίες

Η μέρα που περίμενες τόσο καιρό ήρθε επιτέλους και τώρα είσαι ο περήφανος ιδιοκτήτης μιας όμορφης φάρμας στις Άλπεις.

Ακόμα δε σου αρέσει να ξυπνάς πολύ νωρίς το πρωί για να ταΐσεις τις αγελάδες σου.
Επειδή είσαι εξαιρετικός μηχανικός, κατασκευάζεις έναν ταϊστή, τον `FEED-M-ALL`.

Το τελευταίο πράγμα που απαιτείται για να ολοκληρώσεις το έργο σου είναι ένα κομμάτι κώδικα που υπολογίζει την ποσότητα ζωοτροφής που πρέπει να πάρει κάθε αγελάδα.
Είναι σημαντικό κάθε αγελάδα να παίρνει την ίδια ποσότητα, πρέπει να αποφύγεις τις συγκρούσεις.
Οι αγελάδες είναι πολύ ευαίσθητες.

Ευτυχώς, δε χρειάζεται να βγάλεις μόνος σου όλους τους τύπους για τον υπολογισμό των ποσοτήτων ζωοτροφής.
Χρησιμοποιείς κάποια μυστηριώδη εξωτερική βιβλιοθήκη που βρήκες στο διαδίκτυο.
Υποτίθεται ότι θα έχει ως αποτέλεσμα τις πιο ευτυχισμένες αγελάδες.
Η βιβλιοθήκη εκθέτει μια κλάση που υλοποιεί την παρακάτω διεπαφή.
Θα στηριχτείς σε αυτήν στον κώδικα που γράφεις ο ίδιος.

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

Καθώς δουλεύεις τον κώδικά σου, θα βελτιώσεις τον χειρισμό σφαλμάτων ώστε να γίνει πιο ανθεκτικός και πιο εύκολος στο debug αργότερα, όταν τον χρησιμοποιείς στην καθημερινή ζωή της φάρμας σου.

## 1. Μοίρασε την τροφή ομοιόμορφα

Πρώτα απ' όλα, επικεντρώνεσαι στη συγγραφή του κώδικα που χρειάζεται για να υπολογίσεις την ποσότητα ζωοτροφής ανά αγελάδα.

Υλοποίησε μια μέθοδο `TheFarm.divide_food` που δέχεται ως ορίσματα ένα αντικείμενο `FodderCalculator` και έναν αριθμό αγελάδων ως ακέραιο.
*Για αυτή την εργασία, υποθέτεις ότι ο αριθμός των αγελάδων που περνάει είναι πάντα μεγαλύτερος από το μηδέν.*
Η μέθοδος πρέπει να επιστρέφει την ποσότητα τροφής ανά αγελάδα.

Για να κάνεις τον υπολογισμό, πρώτα πρέπει να ανακτήσεις τη συνολική ποσότητα ζωοτροφής για όλες τις αγελάδες.
Αυτό γίνεται καλώντας τη μέθοδο `fodder_amount!` και περνώντας τον αριθμό των αγελάδων.
Επιπλέον, χρειάζεσαι έναν συντελεστή με τον οποίο πρέπει να πολλαπλασιαστεί αυτή η ποσότητα.
Αυτόν τον συντελεστή τον παίρνεις καλώντας τη μέθοδο `fattening_factor!`.
Με αυτές τις δύο τιμές και τον αριθμό των αγελάδων, μπορείς τώρα να υπολογίσεις την ποσότητα τροφής ανά αγελάδα (ως `float64`).

Αν μία από τις μεθόδους που καλείς επιστρέφει σφάλμα, η εκτέλεση πρέπει να σταματάει και να επιστρέφει `0`.

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. Έλεγξε τον αριθμό των αγελάδων

Ενώ δούλευες στην πρώτη εργασία παραπάνω, συνειδητοποίησες ότι η εξωτερική βιβλιοθήκη που χρησιμοποιείς δεν είναι τόσο υψηλής ποιότητας όσο νόμιζες.
Για παράδειγμα, δε μπορεί να χειριστεί σωστά μη έγκυρες εισόδους.
Θέλεις να παρακάμψεις αυτόν τον περιορισμό προσθέτοντας έναν έλεγχο για την τιμή εισόδου στον κώδικά σου.

Γράψε μια συνάρτηση `TheFarm.validate_input_and_divide_food` που έχει την ίδια υπογραφή με τη `TheFarm.divide_food` παραπάνω.

- Αν ο αριθμός των αγελάδων που περνάει είναι μεγαλύτερος από 0, η συνάρτηση πρέπει να καλεί τη `TheFarm.divide_food` και να επιστρέφει τα αποτελέσματα αυτής της κλήσης.
- Αν ο αριθμός των αγελάδων είναι 0 ή λιγότερο, η συνάρτηση πρέπει να πετάει ένα σφάλμα με μήνυμα `"Number of cows must be greater than 0"`.

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. Βελτίωσε τον χειρισμό σφαλμάτων

Ο έλεγχος του αριθμού των αγελάδων πριν τον περάσεις παρακάτω ήταν καλή κίνηση, αλλά δεν είσαι και τόσο ευχαριστημένος με το ασαφές μήνυμα σφάλματος.
Αποφασίζεις να τα κάνεις καλύτερα δημιουργώντας μια προσαρμοσμένη κλάση σφάλματος με το όνομα `InvalidCowsError`.

Το προσαρμοσμένο σφάλμα πρέπει να κρατάει τον αριθμό των αγελάδων (`Int32`) και ένα προσαρμοσμένο μήνυμα (`String`) και η μέθοδος `Expection` πρέπει να σειριοποιεί τα δεδομένα στην παρακάτω μορφή:
```txt
{number of cows} cows are invalid: {custom message}
```

Οπλισμένος με το προσαρμοσμένο σφάλμα σου, υλοποίησε μια συνάρτηση `TheFarm.validate_number_of_cows` που δέχεται τον αριθμό των αγελάδων ως ακέραιο και επιστρέφει ένα σφάλμα (ή nil).

- Αν ο αριθμός των αγελάδων είναι μικρότερος από 0, η συνάρτηση επιστρέφει ένα `InvalidCowsError` με το προσαρμοσμένο μήνυμα ορισμένο σε `"there are no negative cows"`.
- Αν ο αριθμός των αγελάδων είναι 0, η συνάρτηση επιστρέφει ένα `InvalidCowsError` με το προσαρμοσμένο μήνυμα ορισμένο σε `"no cows don't need food"`.
- Διαφορετικά, η συνάρτηση επιστρέφει `nil` για να δείξει ότι ο έλεγχος ήταν επιτυχής.

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```

Μετά τη σκληρή δουλειά της δημιουργίας αυτής της συνάρτησης ελέγχου, παρατηρείς ότι έχει ήδη βραδιάσει και αφήνεις το γραφείο σου για να απολαύσεις το ηλιοβασίλεμα πάνω από τα βουνά.
Την προσθήκη της νέας συνάρτησης ελέγχου στον κώδικά σου την αφήνεις για άλλη μέρα.
