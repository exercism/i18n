# Σχετικά

Η Julia, όπως οι περισσότερες γλώσσες προγραμματισμού, παρέχει μια πλούσια ποικιλία τύπων συλλογών.

Κάποιες έχουν εγγενή σειρά (όπως τα `Vectors` και οι `Arrays` με περισσότερες διαστάσεις), οπότε μπορούμε να προσπελάσουμε τα στοιχεία τους με βάση τη θέση.
Άλλες συλλογές δεν έχουν σειρά (`Sets`, `Dicts`), και τα στοιχεία τους πρέπει να προσπελαύνονται με κλειδί ή με τιμή.

Στην απλούστερη περίπτωση, ας υποθέσουμε ότι έχουμε ένα `Vector` από `Ints` και θέλουμε να τον [ταξινομήσουμε][ref-sorting] κατά αύξουσα σειρά.

```julia-repl
julia> v = [3, 2, 4, 1]
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v)
4-element Vector{Int64}:
 1
 2
 3
 4

# sort descending
julia> sort(v, rev=true)
4-element Vector{Int64}:
 4
 3
 2
 1
```

Απλό!
Η συνάρτηση [`sort()`][ref-sort] έχει προφανές όνομα, και προφανώς επιστρέφει τον ταξινομημένο `Vector`.

_Αστειεύομαι μόνο!_
Σε αυτό το σημείο της ύλης, ίσως υποψιάζεσαι (σωστά) ότι υπάρχουν λεπτομέρειες που πρέπει να συζητήσουμε.

## Συναρτήσεις που μεταλλάσσουν εναντίον συναρτήσεων που δεν μεταλλάσσουν

Αφού τρέξουμε το `sort(v)`, τι είναι το `v`;

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> issorted(v)
false
```

Το αρχικό διάνυσμα δεν αλλάζει.
Η `sort()` είναι μια ***μη μεταλλάσσουσα*** συνάρτηση που επιστρέφει ένα _αντίγραφο_ της εισόδου της.

Αυτός είναι καλός σχεδιασμός σε πολλά πλαίσια: έχουμε μια [καθαρή συνάρτηση][wiki-pure-func] της οποίας η συμπεριφορά είναι εύκολο να αναλυθεί, ακόμη και σε παράλληλο, κατανεμημένο κώδικα.

Από την άλλη, ας υποθέσουμε ότι είχαμε έναν πίνακα με ένα δισεκατομμύριο συμβολοσειρές και θέλαμε να τον ταξινομήσουμε.

Η ταξινόμηση μάλλον θα είναι αργή (περισσότερα γι' αυτό παρακάτω).
Επιπλέον, πρέπει να αντιγράψουμε τα πάντα (_αργά!_) και να δεσμεύσουμε αρκετή μνήμη (_αρκετά GigaBytes!_) για να αποθηκεύσουμε το αντίγραφο.

Σύγκρινε με αυτόν τον αρκετά παρόμοιο κώδικα:

```julia-repl
# v is as previously

julia> issorted(v)
false

julia> sort!(v)
4-element Vector{Int64}:
 1
 2
 3
 4

julia> v
4-element Vector{Int64}:
 1
 2
 3
 4

julia> issorted(v)
true
```

Τώρα ο `Vector` εισόδου ταξινομείται επιτόπου, χωρίς αντιγραφή, και η αρχική σειρά χάνεται οριστικά.

Αυτό μπορεί να είναι αποδοτικό, μπορεί να έχει bugs και να οδηγήσει σε απρόσμενες [παρενέργειες][wiki-side-effect], μπορεί να μπερδέψει τους άλλους που χρησιμοποιούν τον κώδικά σου.
_Διάλεξε προσεκτικά!_

Η [`sort!()`][ref-sort!] είναι μια [συνάρτηση που μεταλλάσσει][ref-mutating-func], και κατά (_πολύ ισχυρή_) σύμβαση, κάθε συνάρτηση που μεταλλάσσει τα ορίσματά της έχει ένα `!` στο τέλος του ονόματός της, ως προειδοποίηση για τους προγραμματιστές.

## Ταξινόμηση με βάση τι;

Η ταξινόμηση τιμών `Int64` είναι σχετικά απλή: ακόμη και μικρά παιδιά καταλαβαίνουν ότι το 2 είναι μεγαλύτερο από το 1 και μικρότερο από το 3.

Άλλοι τύποι μπορεί να είναι πιο περίπλοκοι, αλλά γενικά `x < y` αν `isless(x, y) == true`.
Η Julia παρέχει υλοποιήσεις της `isless()` για τους περισσότερους τυπικούς τύπους, και μπορείς να ορίσεις ισοδύναμες [μεθόδους][concept-multiple-dispatch] για να συγκρίνεις τους [δικούς σου τύπους][concept-composite-types].

Για παράδειγμα, οι χαρακτήρες Unicode (για τα ευρωπαϊκά γράμματα, τα κεφαλαία ταξινομούνται πριν από τα πεζά):

```julia-repl
julia> j = collect("Julia")
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> sort(j)
5-element Vector{Char}:
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0false069 (category Ll: Letter, lowercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)
```

Μπορούμε επίσης να εφαρμόσουμε οποιαδήποτε αυθαίρετη συνάρτηση στα στοιχεία πριν από την ταξινόμηση, όπως την [`abs`][ref-abs] για να αγνοήσουμε το πρόσημο ή την [`uppercase`][ref-uppercase] για ταξινόμηση χωρίς διάκριση πεζών-κεφαλαίων:

```julia-repl
julia> nums = [3, -2, -4, 1]
4-element Vector{Int64}:
  3
 -2
 -4
  1

julia> sort(nums)
4-element Vector{Int64}:
 -4
 -2
  1
  3

julia> sort(nums, by=abs)
4-element Vector{Int64}:
  1
 -2
  3
 -4

# j is from "Julia", as previously

julia> sort(j, by=uppercase)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'i': ASCII/Unicode U+0069 (category Ll: Letter, lowercase)
 'J': ASCII/Unicode U+004A (category Lu: Letter, uppercase)
 'l': ASCII/Unicode U+006C (category Ll: Letter, lowercase)
 'u': ASCII/Unicode U+0075 (category Ll: Letter, lowercase)

julia> vecs = [[1, 3], [4, 2], [3, 4], [2, 1]];

julia> sort(vecs)  # by default sorts by the first element of the (2-element) vectors
4-element Vector{Vector{Int64}}:
 [1, 3]
 [2, 1]
 [3, 4]
 [4, 2]

julia> sort(vecs, by=last)
4-element Vector{Vector{Int64}}:
 [2, 1]
 [4, 2]
 [1, 3]
 [3, 4]
```

Για [πολυδιάστατους πίνακες][concept-mda], μπορούμε να ορίσουμε τη λέξη-κλειδί `dims` για να ελέγξουμε την κατεύθυνση της ταξινόμησης.

```julia-repl
# create a matrix of integers in random order
julia> A = reshape(Random.shuffle(1:9), (3, 3))
3×3 Matrix{Int64}:
 8  4  9
 6  7  5
 2  1  3

julia> sort(A, dims=1)  # sort rows
3×3 Matrix{Int64}:
 2  1  3
 6  4  5
 8  7  9

julia> sort(A, dims=2)  # sort columns
3×3 Matrix{Int64}:
 4  8  9
 5  6  7
 1  2  3
```

## Ταξινόμηση μέσω πίνακα θέσεων

Αν τα στοιχεία που ταξινομούνται είναι μεγάλα αντικείμενα, μπορεί να είναι ευκολότερο να δουλέψεις με τη θέση τους.

```julia-repl
julia> langs = ["Julia", "C++", "Python", "Elixir"]
4-element Vector{String}:
 "Julia"
 "C++"
 "Python"
 "Elixir"

julia> inxs = sortperm(langs)  # => Integers
4-element Vector{Int64}:
 2
 4
 1
 3

julia> langs[inxs]  # sort the entire vector
4-element Vector{String}:
 "C++"
 "Elixir"
 "Julia"
 "Python"

julia> langs[inxs[1:2]]  # slice the indices
2-element Vector{String}:
 "C++"
 "Elixir"
```

Επειδή το `langs` είναι ένα διάνυσμα, κάθε θέση είναι ένας ακέραιος στο [διάστημα][concept-range] `1:length(langs)`.
Η έξοδος της κλήσης της [sortperm()][ref-sortperm] σε ένα διάνυσμα είναι μια [μετάθεση][wiki-permutation] αυτών των ακεραίων, που αντιστοιχεί σε μια ταξινόμηση του διανύσματος εισόδου.

## Μερική ταξινόμηση

Χρειάζεται το πρόγραμμά σου να ταξινομηθεί ολόκληρη η είσοδος;
Στις περιπτώσεις όπου ενδιαφέρουν μόνο τα πρώτα ή τα τελευταία λίγα στοιχεία, μπορεί να είναι σημαντικά ταχύτερο να κάνεις μια [μερική ταξινόμηση][wiki-partial-sort].

Η Julia παρέχει τις συναρτήσεις [`partialsort()`][ref-partialsort] και [`partialsort!()`][ref-partialsort!], που εγγυώνται ότι το συγκεκριμένο στοιχείο ή διάστημα στοιχείων είναι σωστό, αλλά δεν δίνουν καμία εγγύηση για το υπόλοιπο της εισόδου.

Το δεύτερο όρισμα μπορεί να είναι είτε ένας ακέραιος είτε ένα διάστημα, που αντιπροσωπεύει τη θέση ή τις θέσεις στην ταξινομημένη είσοδο:

```julia-repl
julia> vsq = [9, 4, 16, 1];  # would be [1, 4, 9, 16] after a full sort

julia> partialsort(vsq, 4)
16

julia> partialsort(vsq, 2:3)
2-element view(::Vector{Int64}, 2:3) with eltype Int64:
 4
 9
```

## Αλγόριθμοι ταξινόμησης

Η ταξινόμηση του `[3, 2, 4, 1]` είναι μια εύκολη πρόκληση, είτε για έναν άνθρωπο είτε για έναν υπολογιστή.

Αν η είσοδος είναι _πολύ_ μεγαλύτερη, ποιος είναι ο καλύτερος τρόπος να την ταξινομήσουμε;

Αυτό μας αναγκάζει να ορίσουμε το "καλύτερο"!

- Ο πιο γρήγορος μέσος χρόνος;
- Χρόνος στην καλύτερη ή στη χειρότερη περίπτωση; Ή ένα ενδιάμεσο όριο, όπως ο χρόνος στο 90ό εκατοστημόριο;
- Ελάχιστη χρήση μνήμης;
- Μια προσεγγιστική ή μερική ταξινόμηση, που είναι "αρκετά καλή" για την τρέχουσα εφαρμογή;

Επίσης, ποια είναι η είσοδος;
Μπορεί να είναι ουσιαστικά τυχαία, αλλά ειδικές περιπτώσεις περιλαμβάνουν πίνακες που είναι ήδη ταξινομημένοι, ή ταξινομημένοι σε αντίστροφη σειρά, ή με πολλά επαναλαμβανόμενα στοιχεία.
Διαφορετικοί αλγόριθμοι θα συμπεριφερθούν πολύ διαφορετικά σε αυτές τις καταστάσεις.

Ο σχεδιασμός νέων και καλύτερων αλγορίθμων ταξινόμησης είναι ταυτόχρονα πνευματικά συναρπαστικός (_για έναν συγκεκριμένο τύπο προσωπικότητας_) και εμπορικά πολύτιμος: _ένας ισχυρός συνδυασμός!_

Κατά συνέπεια, υπάρχει τεράστια βιβλιογραφία πάνω σε αυτό το θέμα, που ακόμη αυξάνεται σταθερά.

Η Julia προσπαθεί να επιλέγει έναν λογικό προεπιλεγμένο αλγόριθμο στις περισσότερες περιπτώσεις, αν και οι προγραμματιστές μπορούν να [ορίσουν την προτίμησή τους][ref-algorithms] αν χρειαστεί.

Το επόμενο παιχνιδιάρικο παράδειγμα είναι γελοίο, αλλά δείχνει τη σύνταξη:

```julia-repl
julia> v
4-element Vector{Int64}:
 3
 2
 4
 1

julia> sort(v, alg=InsertionSort)
4-element Vector{Int64}:
 1
 2
 3
 4
```
