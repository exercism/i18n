# Τεστ

Για να τρέξεις τα τεστ, εκτέλεσε την παρακάτω εντολή στον κατάλογο της άσκησης:

```shell
make
```

## Παραλειπόμενα τεστ

Για να λύσεις μια άσκηση, πρέπει να περνούν όλα τα τεστ της.
Από προεπιλογή, όταν τρέχεις τα τεστ εκτελείται μόνο ένα τεστ (το πρώτο).
Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει μόνο αυτό το ένα τεστ.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ αφαιρώντας τη γραμμή `TEST_IGNORE();`.
Όταν ενεργοποιηθούν όλα τα τεστ και η υλοποίησή σου τα περνάει όλα, τότε έχεις λύσει την άσκηση!
