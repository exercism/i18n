# Εισαγωγή

Στην Common Lisp, η λίστα ορισμάτων μιας συνάρτησης είναι γνωστή ως ["lambda list"][lambda-list].
Μια lambda list μπορεί να έχει ορίσματα διαφορετικών τύπων.
Αυτοί οι διαφορετικοί τύποι δηλώνονται με τη χρήση των ["lambda list keywords"][lambda-list-keyword], οι οποίες ξεκινούν όλες με `&`.
Οι πιο συχνά χρησιμοποιούμενοι τύποι είναι τα προαιρετικά ορίσματα, τα ορίσματα με λέξεις-κλειδιά και τα υπόλοιπα ορίσματα.
Κάθε παράμετρος στη lambda list μετά από ένα συγκεκριμένο lambda list keyword θα είναι αυτού του τύπου.
Μια lambda list keyword μπορεί να χρησιμοποιηθεί μόνο μία φορά σε μια lambda list.

Οι lambda lists χρησιμοποιούνται επίσης σε άλλες δομές που θα συζητήσουμε αργότερα, όπως η αποδόμηση και οι μακροεντολές.
