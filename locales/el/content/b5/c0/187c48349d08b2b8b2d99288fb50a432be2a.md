# Οδηγίες

Η αποστολή σου είναι να πάρεις μια λίστα με τους σκόρερ ενός αγώνα και να μετρήσεις πόσα γκολ έχει βάλει κάθε παίκτης.

Το `PlayerName` είναι ένα ψευδώνυμο τύπου για το `String`, ώστε ο κώδικας να διαβάζεται πιο εύκολα και να ξεχωρίζει αυτή η χρήση του `String` από άλλες χρήσεις του `String`.

## 1. Συγκέντρωσε τους σκόρερ

Πρώτα υλοποίησε την `updateGoalCountForPlayer`, ώστε να αρχικοποιεί ή να αυξάνει τον αριθμό γκολ ενός παίκτη.
Έπειτα υλοποίησε τη συνάρτηση `aggregateScorers`, ώστε να μετράς πόσα γκολ έχει βάλει κάθε παίκτης, χρησιμοποιώντας την `updateGoalCountForPlayer`.
Αυτή η συνάρτηση δέχεται μια `List PlayerName` (τα ονόματα των παικτών που έβαλαν τα γκολ, που μπορεί να περιέχει διπλότυπα ονόματα παικτών) και επιστρέφει ένα `Dict PlayerName Int` που περιέχει όλους τους παίκτες της λίστας μαζί με το πόσα γκολ έχουν βάλει.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Αφαίρεσε τους ασήμαντους παίκτες

Υλοποίησε τη συνάρτηση `removeInsignificantPlayers`, για να φιλτράρεις όσους παίκτες έχουν βάλει λιγότερα γκολ από το όριο.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Μηδένισε τον αριθμό γκολ ενός παίκτη

Υλοποίησε τη συνάρτηση `resetPlayerGoalCount`, ώστε να μηδενίζει τα γκολ που έχει βάλει ένας παίκτης.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Μορφοποίησε τον αριθμό γκολ για έναν παίκτη

Υλοποίησε τη συνάρτηση `formatPlayer`, ώστε να μορφοποιείς τον αριθμό γκολ ενός παίκτη ως συμβολοσειρά. Αν ο παίκτης δεν υπάρχει στο λεξικό, θεώρησε ότι ο αριθμός γκολ του είναι μηδέν.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Μορφοποίησε τον αριθμό γκολ για όλους τους παίκτες

Υλοποίησε τη συνάρτηση `formatPlayers`, ώστε να μορφοποιείς τον αριθμό γκολ όλων των παικτών ως συμβολοσειρά. Οι παίκτες πρέπει να είναι ταξινομημένοι κατά όνομα παίκτη.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Συνδύασε τους αγώνες

Υλοποίησε τη συνάρτηση `combineGames`, μετρώντας τον συνολικό αριθμό γκολ που έχει βάλει κάθε παίκτης και στους δύο αγώνες.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
