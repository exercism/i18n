# Οδηγίες

Το έργο του τηλεκατευθυνόμενου αυτοκινήτου που ξεκίνησες στην άσκηση `classes` πήγε καλά (συγχαρητήρια!) και, λόγω μιας σειράς πρόσφατων συμφωνιών χορηγίας, υπάρχουν χρήματα στον προϋπολογισμό για βελτιώσεις.

Μέρος του προϋπολογισμού χρησιμοποιείται για την παροχή κάποιας τηλεμετρίας.

Για να κρατήσουμε τους χορηγούς ευχαριστημένους, έχει τοποθετηθεί ένα πάνελ στο αυτοκίνητο που εμφανίζει τα ονόματα των χορηγών καθώς κάνει τους γύρους στην πίστα.

Θα παρατηρήσεις ότι η εισαγωγή αυτών των φανταχτερών νέων τεχνολογιών μείωσε δραματικά τη διάρκεια ζωής της μπαταρίας του αυτοκινήτου.

## 1. Κάνε το τηλεκατευθυνόμενο αυτοκίνητο να εμφανίζει τα ονόματα των χορηγών

Υλοποίησε τη `SetSponsors()` ώστε να δέχεται ένα ή περισσότερα ονόματα χορηγών και να τα αποθηκεύει στο αυτοκίνητο.

Σημείωσε ότι το όρισμα της μεθόδου `SetSponsors()` είναι εγγυημένο ότι δεν είναι `null`.

Υλοποίησε τη `DisplaySponsor()` για να εμφανίζει τον επιλεγμένο χορηγό. Ο πρώτος χορηγός που περνάς έχει `sponsorNum` 0, ο δεύτερος 1 κ.ο.κ.

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. Πάρε τα δεδομένα τηλεμετρίας του αυτοκινήτου

Υλοποίησε τη μέθοδο `RemoteControlCar.GetTelemetryData()`.

Η `GetTelemetryData()` θα πρέπει να κάνει διαθέσιμα το ποσοστό μπαταρίας και την απόσταση που διανύθηκε σε μέτρα μέσω παραμέτρων `out`.

Η `GetTelemetryData()` θα πρέπει να επιστρέφει `false` αν το όρισμα `serialNum` είναι μικρότερο από την προηγούμενη τιμή που δέχτηκε. (Υπάρχει κάποιο ζήτημα με πολλαπλούς κόμβους τηλεμετρίας που εμπλέκονται). Σε αυτή την περίπτωση το `serialNum` θα οριστεί στο υψηλότερο προηγούμενο `serialNum` και τόσο το ποσοστό μπαταρίας όσο και τα μέτρα που διανύθηκαν θα οριστούν σε `-1`. Όταν η κλήση είναι επιτυχής, το `serialNum` παραμένει αμετάβλητο.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. Πρόσθεσε λειτουργικότητα ώστε το σύστημα τηλεμετρίας να μπορεί να λαμβάνει τη χρήση μπαταρίας ανά μέτρο

Υλοποίησε τη μέθοδο `TelemetryClient.GetBatteryUsagePerMeter()`.

Αυτή θα καλέσει τη `RemoteControlCar.GetTelemetryData()`. Αν η `GetTelemetryData()` επιστρέψει `false` ή το αυτοκίνητο δεν έχει κινηθεί, τότε αυτή η ρουτίνα θα πρέπει να επιστρέψει "no data". Αν η `GetTelemetryData()` επιστρέψει `true`, τότε θα πρέπει να επιστραφεί ένα μήνυμα με την εξής μορφή "usage-per-meter=BATTERY-USAGE-PER-METER". Όπου ο υπολογισμός είναι (100 - το τρέχον ποσοστό μπαταρίας) διαιρεμένο με την απόσταση σε μέτρα που έχει διανυθεί μέχρι στιγμής.

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
