# Προσθήκη στις οδηγίες

## Χρήση παραλληλισμού

Ο στόχος αυτής της άσκησης είναι να εξασκηθείς στον παραλληλισμό με Emacs Lisp.

Στην Emacs Lisp, αυτό μπορεί να γίνει χρησιμοποιώντας [`asynchronous processes`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Asynchronous-Processes.html#:~:text=An%20asynchronous%20process%20is%20controlled,%2Dtype%20(see%20below)).

Ίσως θελήσεις επίσης να ρίξεις μια ματιά στην τεκμηρίωση για [`batch mode`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Batch-Mode.html), [`sentinels`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Sentinels.html) και [`receiving output from processes`](https://www.gnu.org/software/emacs/manual/html_node/elisp/Output-from-Processes.html).
