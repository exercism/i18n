# Εγκατάσταση

Το Exercism σου επιτρέπει να γράφεις και να δοκιμάζεις τον κώδικα ABAP απευθείας στον browser σου. Δεν απαιτείται πρόσθετη εγκατάσταση. Ωστόσο, αν προτιμάς να γράφεις και να δοκιμάζεις κώδικα στο δικό σου σύστημα, μπορείς να αποκτήσεις ένα δοκιμαστικό σύστημα ABAP.

Φυσικά, ο εργοδότης σου μπορεί να χρησιμοποιεί SAP. Ρώτησε το τμήμα πληροφορικής σου αν και πώς μπορείς να αποκτήσεις πρόσβαση σε ένα sandbox ανάπτυξης ABAP.

## Ποια έκδοση να διαλέξεις;

Σου προτείνουμε να χρησιμοποιήσεις μια τρέχουσα έκδοση της πλατφόρμας ABAP με ενεργή υποστήριξη. Αυτή τη στιγμή είναι η **ABAP 7.5 και νεότερες**. Λεπτομέρειες για τις τρέχουσες εκδόσεις και το χρονοδιάγραμμά τους υπάρχουν στο [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## Τι να εγκαταστήσεις;

Σου προτείνουμε να χρησιμοποιήσεις το πιο πρόσφατο [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial). Βασίζεται στο ABAP 7.58. Μπορείς να εγκαταστήσεις το σύστημα SAP ABAP ως εικόνα Docker ή φιλοξενημένο στο SAP Cloud Appliance Library. Επιπλέον, χρειάζεται να εγκαταστήσεις το SAP GUI είτε για Windows είτε για Java, ανάλογα με το λειτουργικό σύστημα του υπολογιστή σου. Μπορείς να κατεβάσεις το SAP GUI από [εδώ](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Για περισσότερες λεπτομέρειες, δες αυτό το blog του [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
