# Οδηγίες

Δίνεις τα σινιάλα για τη σχολική σας παράσταση. Ο διευθυντής σκηνής θέλει τις καθιερωμένες ατάκες γραμμένες κάτω, ώστε να μπορεί οποιοσδήποτε να χειριστεί το πόστο.

Έχεις τέσσερις εργασίες, όλες στην κλάση `STAGE_DIRECTIONS`.

## 1. Αναγγελία της έναρξης

Επίστρεψε την ατάκα που ανοίγει την παράσταση.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Αναγγελία του διαλείμματος

Επίστρεψε την ατάκα που λέγεται στο διάλειμμα.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Αναγγελία του τέλους

Επίστρεψε την ατάκα που κλείνει την παράσταση.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Δώσε το τελευταίο σινιάλο

Το τελευταίο σινιάλο είναι η ίδια ατάκα με αυτή που κλείνει την παράσταση. Αντί να ξαναγράψεις το κείμενο δεύτερη φορά, κάλεσε τη ρουτίνα που έχεις ήδη γράψει.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
