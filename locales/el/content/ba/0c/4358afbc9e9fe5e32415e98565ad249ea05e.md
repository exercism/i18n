# Εισαγωγή

## Τελεστής σωλήνωσης

Ο τελεστής `|>` ονομάζεται τελεστής σωλήνωσης. Μπορεί να χρησιμοποιηθεί για να συνδέσει αλυσιδωτά κλήσεις συναρτήσεων, με τέτοιο τρόπο ώστε η τιμή που επιστρέφει η προηγούμενη κλήση συνάρτησης να περνά στην επόμενη κλήση συνάρτησης.

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

Ο παραπάνω κώδικας είναι ισοδύναμος με τον παρακάτω:

```gleam
string.append(string.uppercase("hello"), "?!")
```

Ο τελεστής σωλήνωσης θα περάσει την τιμή είτε ως πρώτο όρισμα στην κλήση συνάρτησης είτε ως μοναδικό όρισμα σε μια νέα κλήση, επιλέγοντας όποια περίπτωση θα είχε τον σωστό τύπο.

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

Μερικές φορές θέλουμε να περάσουμε την τιμή σε άλλη θέση. Σε αυτή την περίπτωση, το σύμβολο υποκατάστασης `_` μπορεί να χρησιμοποιηθεί για να δείξει πού πρέπει να εισαχθεί η τιμή.

```gleam
100
|> some_function(1, _, 2)
```
