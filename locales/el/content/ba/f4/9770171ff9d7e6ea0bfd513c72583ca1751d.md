# Υποδείξεις

## 1. Εκτύπωσε ένα σήμα για έναν υπάλληλο

- Η [παρεμβολή συμβολοσειρών][string-interpolation] μπορεί να χρησιμοποιηθεί για να μορφοποιήσεις το σήμα με συνοπτικό τρόπο.
- Υπάρχει μια [ενσωματωμένη μέθοδος για τη μετατροπή μιας συμβολοσειράς σε κεφαλαία][toupper].

## 2. Εκτύπωσε ένα σήμα για έναν νέο υπάλληλο

- Θα πρέπει να ελέγξεις αν το ID είναι `null` πριν το χρησιμοποιήσεις.
- [Αυτό το σεμινάριο εξηγεί λεπτομερώς πώς να δουλέψεις με τύπους τιμών που δέχονται null][nullable-types-tutorial].

## 3. Εκτύπωσε ένα σήμα για τον ιδιοκτήτη

- Θα πρέπει να ελέγξεις αν το τμήμα είναι `null` πριν το χρησιμοποιήσεις.
- [Αυτό το σεμινάριο εξηγεί λεπτομερώς πώς να δουλέψεις με τύπους αναφοράς που δέχονται null][nullable-reference-types-tutorial].
- Ο [τελεστής null-conditional][null-conditional-operator] μπορεί να χρησιμοποιηθεί για να απλοποιήσεις την κλήση ενός μέλους σε μια τιμή που δέχεται null.
- Ο [τελεστής null-coalescing][null-coalescing-operator] μπορεί να χρησιμοποιηθεί για να απλοποιήσεις την επιστροφή μιας διαφορετικής τιμής αν μια τιμή που δέχεται null είναι `null`.
