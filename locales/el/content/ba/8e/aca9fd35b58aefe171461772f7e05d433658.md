# Εκτέλεση των tests

Για να τρέξεις το test για μια συγκεκριμένη άσκηση, κάνε `cd` στον φάκελο και τρέξε το παρακάτω:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Τα tests χρησιμοποιούν μια βιβλιοθήκη που ονομάζεται TestBox, η οποία υποστηρίζει xUnit και το στυλ δοκιμών BDD. Όλα τα test suites θα είναι γραμμένα στο [στυλ BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) το οποίο χρησιμοποιεί closures για να ορίσει test specs. Δεν χρειάζεται να ανησυχήσεις για την εγκατάσταση του TestBox. Ο test runner της γραμμής εντολών θα το αναλάβει για σένα. Το μόνο που χρειάζεται είναι να είσαι συνδεδεμένος στο διαδίκτυο την πρώτη φορά που θα το τρέξεις. Μπορείς να διαβάσεις περισσότερα για αυτό εδώ:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
