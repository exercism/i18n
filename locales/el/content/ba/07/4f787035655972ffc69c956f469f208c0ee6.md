# Εισαγωγή

Θυμήσου ότι ένα πρόγραμμα `jq` είναι μια _σωλήνωση εκφράσεων_.
**Η ανάθεση μεταβλητής** ακολουθεί αυτόν τον κανόνα: μια _ανάθεση μεταβλητής_ είναι μια έκφραση που μοιάζει με:

```jq
... | expr as $varname | ...
```

## Το φίλτρο έχει ως έξοδο την είσοδο

Όπως η _έκφραση ταυτότητας_ `.`, έτσι και η έξοδος της _ανάθεσης μεταβλητής_ είναι ίδια με την είσοδό της.
Ο ορισμός της τιμής της μεταβλητής είναι μια παρενέργεια.

Παράδειγμα, που δείχνει ότι το `.` μετά την ανάθεση είναι ίδιο με την αρχική είσοδο:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## Εμβέλεια μεταβλητής

Η εμβέλεια της μεταβλητής είναι "λεξιλογική": η μεταβλητή θα παραμένει στην εμβέλεια μέχρι το τέλος της σωλήνωσης.
Οι μεταβλητές που ορίζονται μέσα σε συναρτήσεις (θα ασχοληθούμε με τις συναρτήσεις αργότερα) είναι "τοπικές" στη συνάρτηση.

## Ονόματα μεταβλητών

Η μεταβλητή πρέπει να αρχίζει με `$`.
Το υπόλοιπο του ονόματος της μεταβλητής είναι ένα **αναγνωριστικό**: ξεκινά με ένα γράμμα ή μια κάτω παύλα και ακολουθείται από γράμματα, αριθμούς ή κάτω παύλες.

## Ανάθεση με αποδόμηση

Από το εγχειρίδιο:

> Πολλαπλές μεταβλητές μπορούν να δηλωθούν με μία μόνο έκφραση `as`, δίνοντας ένα μοτίβο που _ταιριάζει με τη δομή της εισόδου_ (αυτό είναι γνωστό ως "αποδόμηση").

Παραδείγματα:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Το ταίριασμα του ονόματος της μεταβλητής με το _κλειδί του αντικειμένου_ προσφέρει μια συντόμευση:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Σταθερές

Όπως φαίνεται στο παραπάνω παράδειγμα, οι μεταβλητές είναι βολικές για την αποθήκευση σταθερών.
Είναι καλύτερα να δίνεις ένα όνομα στις σταθερές, αντί να εμφανίζονται "μαγικοί αριθμοί" μέσα στον κώδικα.

## Συχνά οι μεταβλητές δεν χρειάζονται

Συχνά είναι πιο ευανάγνωστο να παραλείπεις τις μεταβλητές.

Σκέψου τον υπολογισμό του μέσου όρου μιας λίστας αριθμών

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

σε σύγκριση με

```jq
[2, 4, 8, 7] | add / length
```

Αυτό αναδεικνύει μια από τις πιο ισχυρές πτυχές του `jq`: η είσοδος σε ένα φίλτρο παρέχεται σε _κάθε_ υπο-έκφραση:

- ο πίνακας εισόδου `[2,4,8,7]` περνά στο `add` (το οποίο αθροίζει τους αριθμούς εφαρμόζοντας τον τελεστή `+` σε όλα τα στοιχεία)
- _παράλληλα_, το `[2,4,8,7]` περνά και στο `length`
- όταν ολοκληρωθούν αυτές οι υπο-εκφράσεις, τα αποτελέσματά τους διαιρούνται και επιστρέφουν τη μέση τιμή των αριθμών του πίνακα εισόδου.

## Τελεστές του `jq` που θα χρειαστείς για τη μαθησιακή άσκηση

### Εναλλακτικός τελεστής: `//`

Η έκφραση `a // b` δίνει ως έξοδο το `b` αν το `a` είναι ψευδής ή null, αλλιώς δίνει ως έξοδο το `a`.
Στο πλαίσιο του ορισμού μιας μεταβλητής, αυτό είναι πολύ βολικό για να παρέχεις μια προεπιλεγμένη τιμή:

```jq
(.input.theAnswer // 42) as $answer | ...
```

### Αριθμητικοί τελεστές

- `+`, `-`, `*` είναι οι συνήθεις αριθμητικοί τελεστές πρόσθεσης, αφαίρεσης και πολλαπλασιασμού.
