# Εισαγωγή

## Κλάσεις

Το κύριο αντικειμενοστραφές δομικό στοιχείο στη C# είναι η _κλάση_, που συνδυάζει δεδομένα (_πεδία_) και συμπεριφορά (_μεθόδους_). Τα πεδία και οι μέθοδοι μιας κλάσης είναι γνωστά ως _μέλη_ της.

Η πρόσβαση στα μέλη μπορεί να περιοριστεί μέσω τροποποιητών πρόσβασης, με τους δύο πιο συνηθισμένους να είναι:

- `public`: το μέλος είναι προσβάσιμο από οποιονδήποτε κώδικα (χωρίς περιορισμούς).
- `private`: το μέλος είναι προσβάσιμο μόνο από κώδικα της ίδιας κλάσης.

Μπορείς να σκεφτείς μια κλάση σαν ένα πρότυπο για τη δημιουργία στιγμιοτύπων της. Για να δημιουργήσεις ένα στιγμιότυπο μιας κλάσης (γνωστό και ως _αντικείμενο_), χρησιμοποιείται η λέξη-κλειδί `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Τα πεδία έχουν τύπο και μπορούν να οριστούν οπουδήποτε μέσα σε μια κλάση.
Τα δημόσια πεδία ορίζονται σε PascalCase και τα ιδιωτικά πεδία ορίζονται σε camelCase και παίρνουν ως πρόθεμα την κάτω παύλα `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Μπορείς προαιρετικά να εκχωρήσεις μια αρχική τιμή σε ένα πεδίο. Αν ένα πεδίο _δεν_ καθορίζει αρχική τιμή, θα οριστεί στην προεπιλεγμένη τιμή του τύπου του. Μπορείς να έχεις πρόσβαση στις τιμές των πεδίων ενός στιγμιοτύπου και να τις ενημερώσεις χρησιμοποιώντας τη σημειογραφία με τελείες.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Τα ιδιωτικά πεδία συνήθως ενημερώνονται ως παρενέργεια της κλήσης μιας μεθόδου. Τέτοιες μέθοδοι συνήθως δεν επιστρέφουν καμία τιμή, οπότε ο τύπος επιστροφής θα πρέπει να είναι `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
