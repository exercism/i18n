# Εισαγωγή

Πολλές γλώσσες έχουν έναν τρόπο, όπως το `null` ή το `none`, για να δηλώσουν μια τιμή που δεν υπάρχει. Επειδή η R είναι σχεδιασμένη να χειρίζεται μεγάλους όγκους (συχνά ακατάστατων) δεδομένων, έχει πολλαπλές μορφές του τίποτα.

Ο γενικός στόχος είναι να επισημαίνονται οι ελλιπείς ή ύποπτες τιμές τη στιγμή που τις συναντάς, και μετά να συνεχίζει χωρίς να πετάει εξαίρεση.

## NULL

Αν μια τιμή πραγματικά δεν υπάρχει, αναπαρίσταται από το `NULL`. Αυτό είναι μάλλον το πιο κοντινό σε αυτό που κάνουν η C ή η Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

Σε πολλά πλαίσια, οι τιμές `NULL` απλώς αγνοούνται:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Για καταστάσεις όπου μια τιμή υπάρχει αλλά δεν ξέρουμε ποια είναι, χρησιμοποιείται το `NA`. Για παράδειγμα, όταν μετράμε οχήματα που κινούνται σε έναν δρόμο, οι άνθρωποι που παρατηρούν μπορεί να αρρωστήσουν ή οι αυτόματοι αισθητήρες μπορεί να χαλάσουν, αλλά η κυκλοφορία συνεχίζει να ρέει.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Έτσι, το `NA` είναι ένα σύμβολο θέσης, που προειδοποιεί τους ανθρώπους ότι πρέπει να αποφασίσουν πώς θα το χειριστούν.

## Κενά διανύσματα

Ίσως προκαλεί έκπληξη το γεγονός ότι η R δεν έχει τυπικό τρόπο να ελέγχει αν κάτι είναι κενό, αν και ορισμένα πακέτα τρίτων υλοποιούν δικές τους συναρτήσεις, όπως η `is.empty()`.

Ακόμα και η δημιουργία ενός κενού διανύσματος δεν είναι εντελώς προφανής.
Είδαμε σε προηγούμενη ενότητα ότι η `c()` χωρίς ορίσματα επιστρέφει `NULL`, όχι ένα διάνυσμα.

```R
is.vector(c())
#> [1] FALSE
```

Συναρτήσεις όπως η `logical()` ή η `integer()` δέχονται ένα όρισμα που καθορίζει το επιθυμητό μήκος, το οποίο μπορεί να είναι μηδέν.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

Μπορούμε επίσης να δημιουργήσουμε ένα διάνυσμα και μετά να αφαιρέσουμε κάθε στοιχείο του, όπως περιγράφεται στην [έννοια Διανύσματα][concept-vectors].
Αυτό έχει ως αποτέλεσμα ένα διάνυσμα μήκους 0 του κατάλληλου τύπου.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
