# μη χρησιμοποιήσεις τη λίστα

Αυτή η άσκηση εννοιών έχει σκοπό να εξασκηθείς στη χρήση της αναδρομής.
Στις πραγματικές εφαρμογές, καλό είναι να βασίζεσαι σε ενσωματωμένα modules όποτε αυτό είναι εφικτό, αλλά σε αυτή την άσκηση μη χρησιμοποιήσεις καμία από τις συναρτήσεις που παρέχει το module `List`.
