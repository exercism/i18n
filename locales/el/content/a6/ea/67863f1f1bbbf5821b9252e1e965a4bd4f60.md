# Συντηρητές

## Εισαγωγή

Οι Συντηρητές του Exercism είναι εθελοντές που διαχειρίζονται τα διάφορα μέρη του οικοσυστήματός μας.
Είναι έμπειρα μέλη της κοινότητάς μας που έχουν δείξει ότι συμπορεύονται με τις αξίες του Exercism, την ποιότητα της δουλειάς τους και μια διάθεση να αφιερώνουν χρόνο δουλεύοντας στο Exercism.

Αυτό το έγγραφο περιγράφει μια επίσημη διαδικασία για να γίνεις Συντηρητής και να παραμείνεις ένας, σχεδιασμένη ώστε να είναι εφικτή και δίκαιη για όλους.
Αν θέλεις κάποια μέρα να γίνεις Συντηρητής (γιούπι!!), τότε συνέχισε να διαβάζεις!
Αλλά θυμήσου: οι περισσότεροι άνθρωποι που βοηθούν να χτιστεί το Exercism δεν είναι Συντηρητές, είναι [Συνεισφέροντες](/docs/community/contributors).
**Δεν υπάρχει κανένα εμπόδιο στη συνεισφορά στο Exercism** και κάθε βοήθεια είναι ευπρόσδεκτη με ευγνωμοσύνη.

Στοχεύουμε να έχουμε τουλάχιστον δύο ενεργούς Συντηρητές για κάθε Track και τουλάχιστον έναν ενεργό συντηρητή για όλα τα μέρη της πλατφόρμας.

_Σημείωση: οι παρακάτω ενότητες αφορούν γενικά τους Συντηρητές Track.
Η διαδικασία για να γίνεις Συντηρητής σε άλλα μέρη του οικοσυστήματος διαφέρει._

## Αρμοδιότητες

Οι Συντηρητές είναι υπεύθυνοι να διασφαλίζουν ότι ένα Track λειτουργεί καλά μέσα στο Exercism και συνεχίζει να αναπτύσσεται και να εξελίσσεται.
Συγκεκριμένα, αυτό σημαίνει ότι οι Συντηρητές:

- **Καθορίζουν την τεχνική κατεύθυνση ενός Track:** Επιλέγουν τις σωστές εκδόσεις γλώσσας, τα εργαλεία κ.λπ.
- **Διαχειρίζονται το πρόγραμμα σπουδών ενός Track:** Σχεδιάζουν, επιλέγουν και ορίζουν τις σωστές Έννοιες και Ασκήσεις για ένα Track και φροντίζουν να είναι σωστά συνδεδεμένες και οργανωμένες.
- **Φροντίζουν ένα Track να λειτουργεί καλά:** Διασφαλίζουν ότι το Track είναι ενημερωμένο, ότι ο test runner του είναι γρήγορος κ.λπ.
- **Διασφαλίζουν ότι το Track συμμορφώνεται με τα πρότυπα του Exercism:** Το Exercism έχει προδιαγραφές και πρότυπα για κάθε γλωσσικό Track, ώστε να διασφαλίζεται ένας βαθμός συνέπειας μέσα στην πλατφόρμα. Αν και οι Συντηρητές έχουν πλήρη ελευθερία σε μεγάλο μέρος του Track, όλα τα Track πρέπει να συμμορφώνονται με τα πρότυπα του Exercism.

Οι Συντηρητές είναι επίσης υπεύθυνοι για την αλληλεπίδραση με την κοινότητα των συνεισφερόντων μας.
Αξιολογούν PR από την κοινότητα, λειτουργώντας ως φύλακες, καθοδηγητές και ενθουσιώδεις υποστηρικτές του Exercism.
Είναι υπεύθυνοι να κρατούν την τεκμηρίωση και τις οδηγίες συνεισφοράς ενημερωμένες και να φροντίζουν να υπάρχουν σχετικά ανοιχτά ζητήματα που μπορούν να αναλάβουν πιθανοί συνεισφέροντες.

Οι Συντηρητές πρέπει και να ενσαρκώνουν τις αξίες του Exercism, την ενσυναίσθηση και την καλοσύνη, και να διατηρούν τα υψηλά πρότυπα που θέλουμε να έχει η εκπαιδευτική μας πλατφόρμα.

## Εξουσίες

Ο βασικός τρόπος με τον οποίο οι Συντηρητές μπορούν να ασκήσουν τις αρμοδιότητές τους είναι μέσω πρόσβασης εγγραφής στα αποθετήρια.
Έτσι, οι Συντηρητές ελέγχουν ποιος κώδικας μπαίνει στα αποθετήριά τους.

## Ανταμοιβές

Τα κύρια κίνητρα για να γίνεις Συντηρητής του Exercism είναι συνήθως εσωτερικά: π.χ. η χαρά να χτίζεις κάτι ουσιαστικό και χρήσιμο μαζί με άλλους ανθρώπους με κοινές αντιλήψεις.
Υπάρχουν επίσης οφέλη για την καριέρα σου, όπως η διεύρυνση του προσωπικού σου δικτύου, η ανάπτυξη τεχνικών και ήπιων δεξιοτήτων και μια ουσιαστική καταχώριση στο βιογραφικό σου που δεν προέρχεται από τη δουλειά σου.

Παρέχουμε επίσης κάποια επιπλέον προνόμια:

- Ένα σήμα "Συντηρητής" στα προφίλ και σε όλη την ιστοσελίδα.
- Αναρτήσεις στο blog και συνεντεύξεις με Συντηρητές.
- Αποκλειστικό swag για Συντηρητές.

## Προϋποθέσεις για να γίνεις Συντηρητής

Οι Συντηρητές δεσμεύονται να αφιερώνουν κατά μέσο όρο ~4 ώρες την εβδομάδα στη συντήρηση των Track τους.

### Η πορεία για να γίνεις Συντηρητής

Στα Track που συντηρούνται ενεργά, θα προσκληθείς να γίνεις Συντηρητής όταν συγκεντρώσεις 150 βαθμούς φήμης από building ή/και authoring σε αυτό το Track μέσα σε διάστημα 6 μηνών.

Στα Track χωρίς Συντηρητές, οι περιορισμοί είναι λιγότερο αυστηροί.
Αφού γίνουν merge μερικές μικρές συνεισφορές σου, μπορείς να ανοίξεις ένα ζήτημα στο Track ζητώντας να γίνεις Συντηρητής.
Μπορεί επίσης να σε προσκαλέσουμε να γίνεις Συντηρητής αν παρατηρήσουμε ότι συνεισφέρεις τακτικά σε αυτά τα λιγότερο συντηρούμενα Track.

### Πώς παραμένεις Συντηρητής

Κάθε έξι μήνες ελέγχουμε αν οι Συντηρητές μας είναι ακόμα ενεργοί.
Σε αυτούς τους ελέγχους, όποιος έχει συγκεντρώσει 100 βαθμούς φήμης από building/authoring/maintaining σε ένα Track τους προηγούμενους 6 μήνες καλείται να συνεχίσει ως συντηρητής.
Γενικά, όσοι έχουν κάνει ελάχιστα ή τίποτα σε αυτό το διάστημα παύουν να είναι Συντηρητές.
Αυτό είναι μια κατευθυντήρια αρχή και όχι απόλυτος κανόνας, και λαμβάνουμε υπόψη τις προσωπικές συνθήκες του καθενός και την κατάσταση του Track πριν επιβεβαιώσουμε αυτές τις αποφάσεις.

### Ανώτεροι Συντηρητές Track

Όταν ένας Συντηρητής δείξει ότι αναλαμβάνει ενεργό ηγετικό ρόλο μέσα σε ένα Track και είναι Συντηρητής σε αυτό το Track για τουλάχιστον 6 μήνες, μπορεί να τον ορίσουμε Ανώτερο Συντηρητή.
Τα γενικά κριτήρια που χρησιμοποιούμε είναι ένας Συντηρητής να έχει κερδίσει τουλάχιστον 1.000 βαθμούς φήμης από building/maintenance σε ένα Track και τουλάχιστον 200 βαθμούς φήμης από building/maintaining σε ένα Track τους τελευταίους 6 μήνες, αλλά εξετάζουμε κάθε περίπτωση ξεχωριστά.

Οι Ανώτεροι Συντηρητές αναλαμβάνουν πρόσθετες ευθύνες μέσα σε ένα Track: καθοδηγούν νέους Συντηρητές και παίρνουν πιο ισχυρή ηγετική θέση μέσα στο Track.
Σε αποφάσεις όπου υπάρχουν διαφορετικές απόψεις που χρειάζονται διαιτησία από την Ομάδα Διαχειριστών, οι απόψεις των Ανώτερων Συντηρητών έχουν εξ ορισμού μεγαλύτερο βάρος.

Οι Ανώτεροι Συντηρητές χαρακτηρίζονται στο Track με ένα σήμα "Ανώτερος Συντηρητής".

### Συντηρητές Αξιολογητές

Η τελευταία κατηγορία Συντηρητών είναι οι Συντηρητές Αξιολογητές: Συντηρητές που δουλεύουν σε πολλά Track, αξιολογώντας και κάνοντας merge PR, χωρίς να αναλαμβάνουν πρωτοβουλίες ή ηγετικές θέσεις σε κάποιο Track.
Οι Συντηρητές Αξιολογητές είναι μέλη της ομάδας του Exercism με υψηλή εμπιστοσύνη, που συμμετέχουν στο Exercism τουλάχιστον ένα χρόνο και έχουν υπάρξει Συντηρητές σε τουλάχιστον ένα Track.
Τους προσκαλούν να γίνουν Συντηρητές Αξιολογητές οι Διαχειριστές του Exercism.
Η ιδιότητα μέλους επανεξετάζεται κάθε έξι μήνες, χωρίς επίσημες προϋποθέσεις.

Για Track που έχουν λιγότερους από δύο Συντηρητές, η ομάδα των Αξιολογητών προστίθεται αυτόματα στο αποθετήριο του Track, όπου αποκτά πρόσβαση εγγραφής.
Έτσι διασφαλίζεται ότι οι απαιτήσεις αξιολόγησης καλύπτονται πάντα.
