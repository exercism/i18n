# Εισαγωγή

Μια ιδιότητα στη Haxe είναι ένα μέλος μιας κλάσης που παρέχει πρόσβαση σε δεδομένα μέσα σε αυτή την κλάση. Όσοι καλούν μπορούν να θέσουν ή να ανακτήσουν (get) τα δεδομένα. Περιλαμβάνουν μια μέθοδο πρόσβασης set ή/και μια μέθοδο πρόσβασης get.

Οι ιδιότητες έχουν τροποποιητές πρόσβασης (public, private κ.λπ.) με τον ίδιο τρόπο όπως τα άλλα μέλη της κλάσης, αλλά η μέθοδος πρόσβασης set μπορεί να έχει επίπεδο πρόσβασης ανεξάρτητο από τη μέθοδο πρόσβασης get (ανάκτησης) και αντίστροφα. Μια ιδιότητα δεν χρειάζεται να έχει και τις δύο μεθόδους πρόσβασης, μπορεί να έχει μόνο μία (είτε get είτε set).

Η πρόσβαση ανάγνωσης και η πρόσβαση εγγραφής αντικατοπτρίζονται άμεσα στη σύνταξη, όπως δείχνει το παρακάτω παράδειγμα:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Τόσο το `default` όσο και το `null` είναι ειδικά **αναγνωριστικά πρόσβασης**. Τα αναγνωριστικά πρόσβασης καθορίζουν τη συμπεριφορά όταν το πεδίο διαβάζεται (πρώτο αναγνωριστικό) και όταν το πεδίο εγγράφεται (δεύτερο αναγνωριστικό). Οι αποδεκτές τιμές είναι:

- `default`: Επιτρέπει κανονική πρόσβαση στο πεδίο αν το πεδίο είναι public.
- `null`: Επιτρέπει πρόσβαση μόνο μέσα από την κλάση που το ορίζει.
- `get/set`: Η πρόσβαση παράγεται ως κλήση σε μια μέθοδο πρόσβασης (`get_x()`).
- `dynamic`: Ίδιο με `get/set` αλλά η ύπαρξη μιας μεθόδου πρόσβασης δεν μπορεί να επαληθευτεί.
- `never`: Δεν επιτρέπει καμία απολύτως πρόσβαση.

Ακολουθεί ένα πλήρες παράδειγμα:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
