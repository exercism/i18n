# Εισαγωγή

Ο πιο συνηθισμένος τρόπος για να εκτελέσεις κώδικα υπό συνθήκη στη F# είναι με μια έκφραση `if/elif/else`:

```fsharp
if x = 5 then
    printfn "Expression to evaluate when x equals 5"
elif x > 7 then
    printfn "Expression to evaluate when x greater than 7"
else
    printfn "Expression to evaluate in all other cases"
```

Η συνθήκη (ή οι συνθήκες) που χρησιμοποιείται σε μια έκφραση `if/elif/else` πρέπει να είναι τύπου `bool`. Η F# δεν έχει την έννοια των _truthy_ τιμών.
