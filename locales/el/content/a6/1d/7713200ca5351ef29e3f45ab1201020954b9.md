# Επανάληψη

Στον προγραμματισμό, η [επανάληψη][iteration] αναφέρεται στη διαδικασία επανάληψης ενός μπλοκ κώδικα πολλές φορές.
Αυτό μπορεί να γίνει χρησιμοποιώντας έννοιες όπως οι `while` βρόχοι και οι `until` βρόχοι.
Μπορεί επίσης να γίνει με αναδρομή, η οποία είναι μια συνάρτηση που καλεί τον εαυτό της.

Ωστόσο, τις περισσότερες φορές θέλεις να κάνεις επανάληψη πάνω από μια συλλογή στοιχείων, όπως έναν `Array`, ένα `Range` ή ένα `String`.
Τόσο η κλάση `Array` όσο και η κλάση `Range` στην Crystal περιλαμβάνουν το module [`Enumerable`][enumerable], το οποίο παρέχει έναν αριθμό μεθόδων για επανάληψη πάνω από τα στοιχεία.
Εν τω μεταξύ, η κλάση `String` έχει το δικό της σύνολο μεθόδων για επανάληψη πάνω από τους χαρακτήρες.

Η Crystal επίσης δεν έχει κάποια εντολή `for` όπως άλλες γλώσσες.
Αντ' αυτού, έχει αρκετές μεθόδους που μπορούν να χρησιμοποιηθούν για επανάληψη.

## Πώς κάνουμε επανάληψη

Ο πιο συνηθισμένος τρόπος για να κάνεις επανάληψη πάνω από μια συλλογή είναι να χρησιμοποιήσεις τη μέθοδο [`each`][each], η οποία δίνει κάθε στοιχείο της συλλογής σε ένα μπλοκ.
Αυτό μπορεί να γίνει εύκολα με ένα `Range`.
Ας πούμε ότι θέλεις να κάνεις βρόχο από το 1 έως το 3· μπορείς να χρησιμοποιήσεις τη μέθοδο `each` για να κάνεις επανάληψη πάνω σε αυτό.

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

Ακόμα πιο απλά, αν θέλεις απλώς να κάνεις επανάληψη έναν αριθμό φορών, μπορείς να χρησιμοποιήσεις τη μέθοδο [`times`][times], η οποία υπάρχει στην κλάση `Int`.

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## Επανάληψη πάνω από ένα `String`

Ένα `String` είναι μια ακολουθία χαρακτήρων και δεν ανήκει στο module `Enumerable`, που σημαίνει ότι έχει το δικό του σύνολο μεθόδων για επανάληψη πάνω από τους χαρακτήρες.
Ο πιο συνηθισμένος τρόπος για να κάνεις επανάληψη πάνω από ένα `String` είναι να χρησιμοποιήσεις τη μέθοδο [`each_char`][each_char], η οποία δίνει κάθε χαρακτήρα του `String` σε ένα μπλοκ.

~~~~exercism/note
Η μέθοδος `each_char` περνάει ένα αντικείμενο `Char` και όχι ένα αντικείμενο `String` στο μπλοκ.
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

Ένας άλλος τρόπος για να κάνεις επανάληψη πάνω από ένα `String` είναι να χρησιμοποιήσεις τη μέθοδο [`each_line`][each_line].
Αυτή η μέθοδος χρησιμοποιείται κυρίως κατά την ανάγνωση ενός αρχείου γραμμή προς γραμμή.

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## Επανάληψη πάνω από ένα αντικείμενο που περιλαμβάνει το module `Enumerable`

Το module [`Enumerable`][enumerable] παρέχει έναν αριθμό μεθόδων για επανάληψη πάνω από τα στοιχεία μιας συλλογής.
Συλλογές που περιλαμβάνουν το module `Enumerable` είναι οι `Array`, `Range`, `Hash`, `Set` και άλλες· οι τελευταίες θα καλυφθούν σε επόμενες έννοιες.

Ο πιο συνηθισμένος τρόπος για να κάνεις επανάληψη πάνω από έναν `Array` είναι να χρησιμοποιήσεις τη μέθοδο [`each`][each], η οποία δίνει κάθε στοιχείο του `Array` σε ένα μπλοκ.

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

Η μέθοδος [`map`][map] είναι ένας άλλος τρόπος για να κάνεις επανάληψη πάνω από έναν `Array`· επιστρέφει έναν νέο `Array` που περιέχει τα αποτελέσματα της εφαρμογής του μπλοκ σε κάθε στοιχείο.
Είναι παρόμοια με τη μέθοδο `each`, αλλά επιστρέφει έναν νέο `Array` με τα μετασχηματισμένα στοιχεία.
Ο μετασχηματισμός είναι πολύ χρήσιμος όταν θέλεις να εφαρμόσεις μια συνάρτηση σε κάθε στοιχείο της συλλογής, κάτι που είναι συνηθισμένη λειτουργία.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

Με μια ροή ελέγχου όπως το `if`, μπορείς να φιλτράρεις ποια στοιχεία θα μετασχηματιστούν.

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## Συντομογραφία

Στην Crystal, υπάρχει μια συντομογραφία σύνταξης για επανάληψη και εφαρμογή μιας μεθόδου σε κάθε στοιχείο μιας συλλογής.
Αυτό είναι χρήσιμο όταν δουλεύεις με απλή λογική που χρειάζεται να μετασχηματιστεί μόνο με μία μέθοδο.
Αυτό γίνεται χρησιμοποιώντας τη σύνταξη `&.` ακολουθούμενη από το όνομα της μεθόδου.

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### Με θέση

Μερικές φορές χρειάζεται να ξέρεις τη θέση του στοιχείου πάνω στο οποίο κάνεις επανάληψη· γι' αυτό μπορείς να χρησιμοποιήσεις τη μέθοδο [`each_with_index`][each_with_index] ή [`map_with_index`][map_with_index].
Δίνει κάθε στοιχείο και τη θέση του σε ένα μπλοκ· η μέθοδος δέχεται επίσης ένα προαιρετικό όρισμα για να ορίσεις τη θέση εκκίνησης.

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

Σημείωσε ότι η μέθοδος [`each_char_with_index`][each_char_with_index] είναι επίσης διαθέσιμη για αντικείμενα `String`.

### sum

Η μέθοδος [`sum`][sum] επιστρέφει το άθροισμα όλων των στοιχείων της συλλογής· δέχεται επίσης ένα προαιρετικό μπλοκ για να μετασχηματίσεις τα στοιχεία πριν τα αθροίσεις.
Δέχεται επίσης ένα προαιρετικό όρισμα για να ορίσεις την αρχική τιμή του αθροίσματος.

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

Η [`reduce`][reduce], ή fold όπως είναι γνωστή σε άλλες γλώσσες, είναι μια μέθοδος που, με μια μέθοδο συνδυασμού και μια αρχική τιμή, συνδυάζει όλα τα στοιχεία της συλλογής.
Η μέθοδος `reduce` έχει έναν συσσωρευτή που περνάει στο μπλοκ· ο συσσωρευτής είναι το αποτέλεσμα της προηγούμενης επανάληψης.
Αυτό γίνεται μια αναδρομική διαδικασία που συνδυάζει όλα τα στοιχεία της συλλογής.

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

Η `reduce` μπορεί να φαίνεται παρόμοια με τη `sum`, αλλά η `reduce` είναι πιο ευέλικτη, γιατί σου επιτρέπει να ορίσεις την αρχική τιμή του συσσωρευτή και τη μέθοδο συνδυασμού.
Η `reduce` μπορεί να χρησιμοποιηθεί για να υλοποιήσεις τη `sum`, τη `count` και άλλες μεθόδους.
