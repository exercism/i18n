# Εισαγωγή

## Αληθείς και ψευδείς τιμές

Στη Common Lisp όλες οι τιμές είναι "αληθείς" εκτός από το `()`, που είναι "ψευδές".
Υπάρχουν δύο ειδικά σταθερά σύμβολα, τα `t` και `nil`, των οποίων οι τιμές είναι αληθείς και ψευδείς αντίστοιχα.

## Συνθήκες

Η Common Lisp παρέχει αρκετές διαφορετικές εκφράσεις υπό συνθήκη, με κύρια διαφορά τον αριθμό των διακλαδώσεων που υποστηρίζουν.

- Τα `when` και `unless` επιτρέπουν μία μόνο διακλάδωση:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

Το τμήμα μετά την έκφραση ελέγχου μπορεί να περιέχει περισσότερες από μία εκφράσεις.

- Το `if` παρέχει την κλασική μορφή if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Σημείωσε ότι τόσο ο κλάδος then όσο και ο κλάδος else μπορούν να περιέχουν μόνο μία έκφραση.

- Το `cond` δίνει έναν τρόπο να έχεις πολλαπλές διακλαδώσεις χωρίς εμφωλευμένες εκφράσεις `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Σημείωσε ότι δεν υπάρχει όριο στον αριθμό των εκφράσεων μετά την έκφραση ελέγχου. 

- Το `case` παρέχει μια κλασική μορφή τύπου 'switch': Ελέγχει μία μόνο τιμή απέναντι σε έναν αριθμό διακλαδώσεων:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Σημείωσε ότι, όπως και στο `cond`, δεν υπάρχει όριο στον αριθμό των εκφράσεων μετά την έκφραση ελέγχου.
