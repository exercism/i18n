# Υποδείξεις

Για όλες αυτές τις εργασίες, θα χρειαστείς την εντολή `print`:
```awk
{print "something", "something else"}
```

## 1. Κάνε λίστα με τα ονόματα χρηστών

* Χρησιμοποίησε [τη μεταβλητή `FS`][var-fs] για να ορίσεις τον διαχωριστικό πεδίων.

## 2. Εμφάνισε τους αριθμούς γραμμής

* Χρησιμοποίησε την [ενσωματωμένη μεταβλητή `NR`][var-nr] για να πάρεις τον αριθμό γραμμής.

## 3. Εμφάνισε τις καταγραφές με μη έγκυρους αρχικούς καταλόγους.

* Ο αρχικός κατάλογος είναι το 6ο πεδίο.
* Χρησιμοποίησε τη δοσμένη συνάρτηση `startsWith`.
* Χρησιμοποίησε [Boolean τελεστές][boolean-ops]: `&&`, `||`, `!`.

## 4. Εμφάνισε τον αριθμό των έγκυρων χρηστών που χρησιμοποιούν bash

* Το login shell είναι το τελευταίο πεδίο, μπορείς να χρησιμοποιήσεις [τη μεταβλητή `NF`][var-nf].
