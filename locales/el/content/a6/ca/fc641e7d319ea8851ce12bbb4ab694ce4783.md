# Εισαγωγή

Τα σύμβολα στη Common Lisp είναι ειδικές τιμές που μπορούν να δείχνουν σε άλλες τιμές ή, στην περίπτωση των _λέξεων-κλειδιών_, στον εαυτό τους.
Όταν η Lisp αξιολογεί τα σύμβολα, τα αντικαθιστά με τις τιμές στις οποίες δείχνουν:

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

Πρόσεξε ότι οι λέξεις-κλειδιά δηλώνονται με μια άνω και κάτω τελεία (`:`) στην αρχή.

Η παράθεση, δηλαδή η προσθήκη του `'` πριν από μια S-expression, λέει στη Lisp να μην αξιολογήσει αυτή την έκφραση.
Παραθέτοντας το `'foo` στο παράδειγμά μας με τη `defun`, αποφύγαμε να προσπαθήσει η Lisp να αναζητήσει (και να μην καταφέρει να βρει) αυτό στο οποίο υποτίθεται ότι έδειχνε το `FOO`, και αντ' αυτού το αποτέλεσμα ήταν η ίδια η τιμή `FOO`.
Αν το `FOO` δεν έχει οριστεί πουθενά στο πρόγραμμά μας:

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

Για την ώρα, μπορείς να το δεις απλώς ως έναν τρόπο να επιστρέφεις σύμβολα από μια συνάρτηση, αλλά θα ξαναδούμε την παράθεση και θα εξερευνήσουμε πιο βαθιά τις συνέπειές της σε μελλοντικές ασκήσεις εννοιών.
