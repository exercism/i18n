# Σχετικά

Η Ruby είναι μια δυναμική γλώσσα με ισχυρή τυποποίηση.
Στις δυναμικές γλώσσες, ο τύπος μιας μεταβλητής ή ενός αντικειμένου καθορίζεται κατά την εκτέλεση, που σημαίνει ότι η τιμή ή ο τύπος της μπορεί να αλλάξει μέχρι και την τελευταία στιγμή (όταν τον αναλύει ο διερμηνευτής).
Και τι εννοούμε με τον όρο ισχυρή τυποποίηση;
Μόλις μάθουμε τον τύπο μιας μεταβλητής ή ενός αντικειμένου, η Ruby είναι αυστηρή ως προς το τι μπορείς να κάνεις με αυτό, για παράδειγμα:

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**Όμως**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

Θυμήσου, στη Ruby τα πάντα είναι αντικείμενα.
Ακόμη και οι κλάσεις είναι στιγμιότυπα της κλάσης `Class`.

Για παράδειγμα:

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

Αυτό σημαίνει ότι μπορούμε επίσης να ορίσουμε κλάσεις ως εξής:

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

Τέλος, να έχεις υπόψη σου ότι το αντικείμενο `Integer` περιέχει τιμές που μπορούν να οριστούν ως ένα ή περισσότερα (συνεχόμενα) ψηφία και οι μέθοδοί του υποστηρίζουν πολλούς από τους [μαθηματικούς τελεστές][integers-docs].

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
Στην τεκμηρίωση συχνά γίνεται αναφορά σε μεθόδους στιγμιότυπων με σύνταξη όπως `Class#method_name`, ενώ οι μέθοδοι σε επίπεδο κλάσης ή module αναφέρονται ως `Class::method_name`.
Το `::` ονομάζεται _Scope Resolution Operator_, δηλαδή η σταθερά ή η μέθοδος σε επίπεδο κλάσης ή module στην οποία γίνεται αναφορά.
Θα το συναντήσεις στην τεκμηρίωση της Ruby, καθώς και σε λίστες αλληλογραφίας και άλλους χώρους υποστήριξης.
Θα διαπιστώσεις ότι εμείς στα κείμενά μας αναφερόμαστε στις μεθόδους κλάσεων και module ως `ClassName.method_name` ή `ModuleName.method_name`.
~~~~
