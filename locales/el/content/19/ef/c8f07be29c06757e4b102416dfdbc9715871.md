# Οδηγίες

Σε αυτή την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες, καθεμία από τις οποίες παίρνει μια γραμμή καταγραφής και σου ζητά να κάνεις κάτι με αυτήν. Υπάρχουν πολλοί τρόποι να λύσεις αυτές τις εργασίες. Διάλεξε τις αγαπημένες σου μεθόδους από τα παραπάνω παραδείγματα και δες τι μπορείς να φτιάξεις.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `LogLineParser#message` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Τυχόν κενά στην αρχή ή στο τέλος πρέπει να αφαιρούνται:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `LogLineParser#log_level` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο πρέπει να επιστρέφεται με πεζά γράμματα:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη μέθοδο `LogLineParser#reformat` που αναδιαμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής σε παρενθέσεις:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
