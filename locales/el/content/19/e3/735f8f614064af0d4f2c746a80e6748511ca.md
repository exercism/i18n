# παρεμβολή συμβολοσειρών

Εκτός από την παρεμβολή συμβολοσειρών, ένας άλλος συνηθισμένος τρόπος για να δημιουργήσεις συμβολοσειρές στη Ruby είναι να χρησιμοποιήσεις το [String#%%](https://www.rubyguides.com/2012/01/ruby-string-formatting/) (που διαβάζεται ίσως ως "String format").
Για παράδειγμα:

```ruby
"One for %%s, one for me." %% %{name_variable}
```
