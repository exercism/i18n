# Εισαγωγή

Το [Zen of Python][zen-of-python] υποστηρίζει ότι θα πρέπει να υπάρχει "ένας _προφανής_ τρόπος" για να κάνεις κάτι στην Python.
Για την Python 3.6 και μετά, η [**κυριολεκτική παρεμβολή συμβολοσειρών**][string-interpolation] (τα [**`f-string`s**][f-string]) είναι συχνά ο προφανής και προτιμώμενος τρόπος για να μορφοποιείς συμβολοσειρές:

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

Ωστόσο, δεδομένης της μακράς ιστορίας της Python και των διαφορετικών περιπτώσεων χρήσης, δεν είναι παράξενο που υπάρχουν **τρεις** άλλοι συνηθισμένοι τρόποι για να κάνεις μορφοποίηση συμβολοσειρών στην Python:

1. Η [`str.format()`][str-format] είναι ευέλικτη, πολύ ισχυρή και συμβατή τόσο με το [`gnu gettext`][gettext] όσο και με τις περισσότερες εκδόσεις της Python.
2. Αν αυτό που χρειάζεσαι είναι απλότητα, ασφάλεια ή/και έντονη διεθνοποίηση, η [`string.Template()`][string-template] μπορεί να χρησιμοποιηθεί για να μετριάσεις τους κινδύνους όταν πρέπει να χειριστείς εισόδους και για να τυλίξεις συμβολοσειρές μετάφρασης.
3. Ο τελεστής `%` θεωρείται γενικά παρωχημένος για νέο κώδικα, αν και λειτουργεί ακόμη στη σύγχρονη Python.
  Θα πρέπει κυρίως να χρησιμοποιείται για συμβατότητα με παλαιότερο κώδικα.
  Η μορφοποίηση με `%` μπορεί να οδηγήσει σε προβλήματα στην εμφάνιση χαρακτήρων που δεν είναι ASCII και χαρακτήρων Unicode, και έχει περισσότερα σφάλματα και λιγότερες λειτουργίες από τις άλλες μεθόδους.
  Έλεγξε τη συγκεκριμένη διανομή Python που χρησιμοποιείς για λεπτομέρειες υποστήριξης, αν σκοπεύεις να τη χρησιμοποιήσεις.

Αν θέλεις να προχωρήσεις παραπέρα, το [all about formatting][all-about-formatting] και το [Python String Formatting Best Practices][formatting-best-practices] είναι καλά σημεία για να ξεκινήσεις.
