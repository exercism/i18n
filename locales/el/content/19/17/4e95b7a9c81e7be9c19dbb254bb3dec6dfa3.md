# Υποδείξεις

## Γενικά

- Μια [ακέραια τιμή][ints] μπορεί να οριστεί ως ένα ή περισσότερα συνεχόμενα ψηφία.
- Τα κυριολεκτικά [συμβολοσειράς][string] είναι μια ακολουθία χαρακτήρων που περικλείεται από διπλά εισαγωγικά.

## 1. Όρισε τον αναμενόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς παραμέτρους.
- Πρέπει να επιστρέψεις έναν [ακέραιο][ints].

## 2. Υπολόγισε τον υπολειπόμενο χρόνο ψησίματος σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Πρέπει να επιστρέψεις έναν ακέραιο από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι ένας [ακέραιος][ints].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για αφαίρεση][ints] για να αφαιρέσεις τιμές.

## 3. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με μία παράμετρο.
- Πρέπει να επιστρέψεις έναν ακέραιο από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι ένας [ακέραιος][ints].
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πολλαπλασιασμό][ints] για να πολλαπλασιάσεις τιμές.

## 4. Υπολόγισε τον συνολικό χρόνο εργασίας σε λεπτά

- Πρέπει να ορίσεις μια [συνάρτηση][functions] με δύο παραμέτρους.
- Πρέπει να επιστρέψεις έναν ακέραιο από μια συνάρτηση.
- Η παράμετρος της συνάρτησης είναι ένας [ακέραιος][ints].
- Μπορείς να καλέσεις μία από τις άλλες συναρτήσεις που έχεις ορίσει προηγουμένως.
- Μπορείς να χρησιμοποιήσεις τον [μαθηματικό τελεστή για πρόσθεση][ints] για να προσθέσεις τιμές.

## 5. Δημιούργησε μια ειδοποίηση ότι τα λαζάνια είναι έτοιμα

- Πρέπει να ορίσεις μια [συνάρτηση][functions] χωρίς παραμέτρους.
- Πρέπει να επιστρέψεις μια [συμβολοσειρά][string].

[functions]: https://gleam.run/book/tour/functions.html
[ints]: https://gleam.run/book/tour/ints-and-floats.html
[string]: https://gleam.run/book/tour/strings.html
