# Προσθήκη οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                     |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | είσοδος   | διεύθυνση | πρώτη συμβολοσειρά τερματισμένη με null  |
| `$a1`    | είσοδος   | διεύθυνση | δεύτερη συμβολοσειρά τερματισμένη με null |
| `$v0`    | έξοδος    | ακέραιος | απόσταση Hamming                |
| `$t0-9`  | προσωρινός | οτιδήποτε | για προσωρινή αποθήκευση           |
