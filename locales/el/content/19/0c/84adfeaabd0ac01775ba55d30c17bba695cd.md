# Προσάρτημα οδηγιών

## Καταχωρητές

| Καταχωρητής | Χρήση      | Τύπος   | Περιγραφή                                                  |
| ----------- | ---------- | ------- | ---------------------------------------------------------- |
| `$a0`       | είσοδος    | διεύθυνση | τα στοιχεία του πίνακα ένα                                |
| `$a1`       | είσοδος    | ακέραιος  | μέγεθος του πίνακα ένα, σε λέξεις                          |
| `$a2`       | είσοδος    | διεύθυνση | τα στοιχεία του πίνακα δύο                                |
| `$a3`       | είσοδος    | ακέραιος  | μέγεθος του πίνακα δύο, σε λέξεις                          |
| `$v0`       | έξοδος     | ακέραιος  | `0` = ίσος, `1` = άνισος, `2` = υπολίστα, `3` = υπερλίστα  |
| `$t0-9`     | προσωρινός | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση                   |
