# Εισαγωγή

Τον τροποποιητή `const` μπορείς (και γενικά πρέπει) να τον εφαρμόσεις σε οποιοδήποτε πεδίο του οποίου η τιμή είναι γνωστή κατά τη μεταγλώττιση και δεν θα αλλάξει κατά τη διάρκεια ζωής του προγράμματος.

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

Τον τροποποιητή `readonly` μπορείς (και γενικά πρέπει) να τον εφαρμόσεις σε οποιοδήποτε πεδίο που δεν μπορεί να γίνει `const`, όταν η τιμή του δεν θα αλλάξει κατά τη διάρκεια ζωής του προγράμματος και ορίζεται είτε από έναν inline αρχικοποιητή είτε κατά τη δημιουργία στιγμιοτύπου (από τον κατασκευαστή ή από μια μέθοδο που καλεί ο κατασκευαστής).

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
