# Εισαγωγή

## Αναφορές null

Αν έχεις χρησιμοποιήσει ποτέ κάποια άλλη γλώσσα προγραμματισμού (C/C++, Python, Java, Ruby, Lisp κ.λπ.), είναι πιθανό να έχεις συναντήσει στο παρελθόν το `null` ή το `nil`.
Με το `null` ή το `nil` αυτές οι γλώσσες δηλώνουν ότι μια συγκεκριμένη μεταβλητή δεν έχει τιμή.
Ωστόσο, έτσι είναι εύκολο (και συχνό) να χρησιμοποιήσεις κατά λάθος μια μεταβλητή που είναι `null`.
Όπως μπορεί να φανταστείς, το να προσπαθήσεις να καλέσεις μια συνάρτηση που δεν υπάρχει ή να προσπελάσεις μια τιμή που δεν υπάρχει μπορεί να οδηγήσει σε κάθε λογής bugs και καταρρεύσεις.
Ο δημιουργός του `null` έφτασε μάλιστα στο σημείο να το αποκαλέσει ["λάθος του δισεκατομμυρίου"][billion-dollar-mistake].

[billion-dollar-mistake]: https://www.infoq.com/presentations/Null-References-The-Billion-Dollar-Mistake-Tony-Hoare/

## Ο τύπος `Option`

Για να αποφευχθούν αυτά τα προβλήματα, οι μεταβλητές στη Cairo μπορούν να χρησιμοποιούν το enum `Option` για να αναπαριστούν με ασφάλεια την απουσία τιμής.
Αυτό το enum έχει δύο παραλλαγές: το `None`, που ισοδυναμεί με το null της Cairo, και το `Some(T)`, όπου το `T` είναι μια τιμή οποιουδήποτε τύπου.

Μοιάζει κάπως έτσι:

```rust
enum Option<T> {
    None,
    Some(T),
}
```

Μπορείς να σκεφτείς το `Option` ως ένα στρώμα ασφάλειας ανάμεσα σε εσένα και στα προβλήματα που μπορούν να προκαλέσουν οι αναφορές null, ενώ ταυτόχρονα διατηρείς τη χρησιμότητά τους σε εννοιολογικό επίπεδο.

## Χρήση του `Option`

Το να θέσεις μια μεταβλητή σε `None` είναι αρκετά απλό:

```rust
let nothing: Option<u32> = Option::None;  // Variable nothing is set to None
```

Ωστόσο, αν θέλεις ο τύπος `Option` να μεταφέρει μια τιμή, δεν μπορείς να εκχωρήσεις απευθείας αυτή την τιμή.
Μια μεταβλητή τύπου `Option` και, ας πούμε, μια μεταβλητή τύπου `i32` δεν είναι ισοδύναμες.
Πρέπει να χρησιμοποιήσεις το `Some`:

```rust
let wrong_way: Option<i32> = -4; // This will not work

let right_way: Option<i32> = Option::Some(-4); // This will work
let another_right_way = Option::Some(-4); // Compiler infers that this is Option<i32>
```

Για τον ίδιο λόγο, το παρακάτω δεν θα δουλέψει:

```rust
let number = 47;
let option_number = Option::Some(15);

let compile_error = number + option_number; // Cannot add an i32 and an Option<i32> - they are of different types
```

Για να πάρεις την τιμή που περιέχει το `Some`, πρέπει πρώτα να ελέγξεις ότι υπάρχει:

```rust
let mut some_words = Option::Some("choose something to say"); // some_words set to something

match some_words {
    Option::Some(str) => println!("Here, we will {}", str),
    Option::None => println!("I've got nothing to say"),
} // Prints, "Here, we will choose something to say"

some_words = Option::None; // some_words now set to None

// Exactly the same match block as above
match some_words {
    Option::Some(str) => println!("Here, we will {}", str),
    Option::None => println!("I've got nothing to say"),
} // Prints, "I've got nothing to say"
```

Η Cairo έχει κι άλλα εργαλεία εκτός από το `match` για τον έλεγχο και την πρόσβαση σε τιμές που περιέχονται σε ένα `Option`, αλλά το `match` θα σου είναι πλέον οικείο.

Θεώρησέ το αυτό ως μια επίδειξη του γιατί η Cairo χρησιμοποιεί το `Option` αντί για μια αναφορά null.
Το νόημα είναι ότι **πρέπει οπωσδήποτε να ελέγχεις** αν η μεταβλητή `Option` είναι `Some` (οπότε μπορείς να προχωρήσεις και να εξαγάγεις και να χρησιμοποιήσεις την τιμή που περιέχει) ή `None`.
Διαφορετικά, το πρόγραμμα δε θα μεταγλωττιστεί. Ο μεταγλωττιστής σε κρατά ασφαλή από το `null`.
