# Δήλωση τύπου

Οι δηλώσεις τύπου στην PHP παρέχουν ελέγχους τύπου κατά τον χρόνο εκτέλεσης για ορίσματα συναρτήσεων, τιμές επιστροφής και ιδιότητες κλάσης.
Στις συναρτήσεις, μπορεί να προστεθεί τύπος επιστροφής `void` για να δηλώσει ότι δεν επιστρέφεται καμία τιμή από τη συνάρτηση.
Οι δηλωμένοι τύποι χρησιμεύουν επίσης ως έλεγχοι κατά τον χρόνο εκτέλεσης ότι οι συναρτήσεις επιστρέφουν μια απάντηση με λογικό τύπο.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## Ενώσεις τύπων

Αν ένα όρισμα συνάρτησης, μια τιμή επιστροφής ή μια ιδιότητα κλάσης μπορεί να έχει περισσότερους από έναν τύπους, μπορεί να δηλωθεί μια ένωση τύπων.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## Μικτοί τύποι

Όταν δουλεύουμε με κώδικα, μπορεί να μην μπορούμε να προσδιορίσουμε έναν τύπο.
Ξεκινώντας από την PHP 8.0, παρέχεται ένας τύπος διαφυγής με το όνομα `mixed`.
Ο `mixed` ισοδυναμεί με μια ένωση τύπων `object|resource|array|string|float|int|bool|null`.
