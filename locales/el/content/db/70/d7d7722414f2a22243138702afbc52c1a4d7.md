# Οδηγίες

Σε αυτή την άσκηση θα μοντελοποιήσεις μια ζυγαριά με μονάδα το χιλιόγραμμο.

Έχεις 6 εργασίες, καθεμία από τις οποίες απαιτεί να υλοποιήσεις μία ή περισσότερες ιδιότητες:

## 1. Επίτρεψε στη ζυγαριά να έχει ακρίβεια

Για να καλύψουμε διαφορετικές ανάγκες, κάθε ζυγαριά μπορεί να προσαρμόζεται με μια ακρίβεια (τον αριθμό των ψηφίων μετά το δεκαδικό σύμβολο).
Υλοποίησε την κλάση `WeighingMachine` ώστε να έχει μια ιδιότητα `Precision` μόνο για ανάγνωση, ορισμένη στο όρισμα `precision` του κατασκευαστή:

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. Επίτρεψε να ορίζεται το βάρος στη ζυγαριά

Υλοποίησε την ιδιότητα `WeighingMachine.Weight` ώστε το βάρος να μπορεί να διαβαστεί _και_ να οριστεί:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. Βεβαιώσου ότι απορρίπτεται ένα αρνητικό βάρος εισόδου

Προφανώς, κάποιος δεν μπορεί να έχει αρνητικό βάρος.
Πρόσθεσε επικύρωση στην ιδιότητα `WeighingMachine.Weight` ώστε να πετάει μια εξαίρεση `ArgumentOutOfRangeException` όταν προσπαθείς να την ορίσεις σε αρνητικό βάρος:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. Επίτρεψε να εφαρμόζεται μια ρύθμιση απόβαρου στη ζυγαριά

Η ρύθμιση απόβαρου μπορεί να είναι οποιαδήποτε τιμή (ακόμη και αρνητική ή μια τιμή που κάνει το εμφανιζόμενο βάρος αρνητικό)
Υλοποίησε την ιδιότητα `WeighingMachine.TareAdjustment` ώστε να μπορεί να οριστεί η ρύθμιση απόβαρου:

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. Βεβαιώσου ότι η ζυγαριά έχει προεπιλεγμένη ρύθμιση απόβαρου

Μετά από διεξοδικές δοκιμές, φαίνεται ότι εξαιτίας ενός κατασκευαστικού προβλήματος όλες οι ζυγαριές έχουν την τάση να υπερεκτιμούν το βάρος κατά `5`.
Άλλαξε την ιδιότητα `WeighingMachine.TareAdjustment` ώστε η προεπιλεγμένη τιμή της να είναι `5`.

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. Επίτρεψε την ανάκτηση του βάρους

Υλοποίησε την ιδιότητα `WeighingMachine.DisplayWeight`, η οποία πρέπει να επιστρέφει μια συμβολοσειρά που δείχνει το βάρος μετά τη ρύθμιση απόβαρου, με την εφαρμογή της σωστής ακρίβειας και με τη μονάδα στο τέλος.
Σημείωσε ότι:
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
