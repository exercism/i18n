# Εισαγωγή

Οι Boolean (λογικές τιμές) στη Rust αντιπροσωπεύονται από τον τύπο `bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η Rust υποστηρίζει έξι τελεστές σύγκρισης: `==` (ίσο), `!=` (όχι ίσο), `>` (μεγαλύτερο από), `<` (μικρότερο από), `>=`
(μεγαλύτερο ή ίσο με), `<=` (μικρότερο ή ίσο με). Μπορούν να χρησιμοποιηθούν για να αξιολογήσουν τη σχέση τιμών που δεν είναι Boolean
σε μια τιμή Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

Σε αντίθεση με κάποιες άλλες γλώσσες, το `0` δεν είναι `false` και μια μη μηδενική τιμή δεν είναι `true`.

Η Rust υποστηρίζει δύο τελεστές Boolean: `||` (ή), `&&` (και). Αξιολογούνται μόνο όταν ο αριστερός τελεστέος δεν καθορίζει ήδη
το αποτέλεσμα της παράστασης. Δηλαδή, το `||` αξιολογεί τον δεξιό τελεστέο του μόνο όταν ο αριστερός τελεστέος αξιολογείται
σε `false`, και το `&&` μόνο όταν αξιολογείται σε `true`.
