# Μάθηση

## Μαθαίνοντας C++ από το μηδέν

Η C++ είναι μια γλώσσα προγραμματισμού με ευρεία και εκφραστική σύνταξη που
υποστηρίζει αρκετά διαφορετικά στυλ προγραμματισμού: διαδικαστικό,
αντικειμενοστρεφές, συναρτησιακό και γενικό, αλλά και συνδυασμούς όλων αυτών
μαζί στο ίδιο πρόγραμμα.  Αυτή η διαδρομή της γλώσσας προσπαθεί να παρουσιάσει
προβλήματα με βαθμιαία αυξανόμενη δυσκολία.  Ωστόσο, ορισμένα στοιχεία της
σύνταξης της γλώσσας παρουσιάζονται καλύτερα με άλλη μορφή, όχι ως μια σειρά
ασκήσεων.

Γενικά, το Exercism υποθέτει ότι γνωρίζεις ήδη τη σύνταξη και τους μηχανισμούς
μιας γλώσσας σε μια συγκεκριμένη διαδρομή.  Ωστόσο, το να γνωρίζεις τη σύνταξη
μιας γλώσσας είναι μόνο το πρώτο βήμα για να αποκτήσεις εξειδίκευση σε αυτήν.
Το Exercism σου επιτρέπει να εξασκηθείς στη λύση προβλημάτων και να συζητήσεις
με άλλους προγραμματιστές που έχουν λύσει το ίδιο πρόβλημα.  Μέσα από την κοινή
συζήτηση αποκτάμε εξειδίκευση και διορατικότητα ώστε να γίνουμε καλύτεροι
προγραμματιστές.

Αν είσαι εντελώς νέος στη γλώσσα C++, καλό είναι να αφιερώσεις πρώτα χρόνο για
να μάθεις τα βασικά της.  Ορίστε μερικοί πόροι που μπορούν να σε βοηθήσουν να
ξεκινήσεις:

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

Το [Coliru](http://coliru.stacked-crooked.com/) είναι μια απλή διαδικτυακή
φόρμα προς έναν μεταγλωττιστή C++ που θα σου επιτρέψει να δοκιμάσεις μικρά
προγράμματα.  Μερικές φορές αυτός μπορεί να είναι ένας πιο εύκολος τρόπος για
ένα γρήγορο πείραμα από το να χτίσεις κάτι τοπικά σε ένα ολοκληρωμένο
περιβάλλον ανάπτυξης.

## Ανάπτυξη καθοδηγούμενη από δοκιμές σε C++

Το Exercism υποθέτει ότι είσαι εξοικειωμένος με την έννοια της ανάπτυξης
καθοδηγούμενης από δοκιμές.  Κάθε άσκηση συνοδεύεται από μια σειρά δοκιμών που
είναι ήδη γραμμένες για σένα.  Προχωράς στην άσκηση μία δοκιμή τη φορά,
γράφοντας σταδιακά μια υλοποίηση που να ικανοποιεί τις δοκιμές.

Αν είσαι νέος στην ανάπτυξη καθοδηγούμενη από δοκιμές, συνιστάται ανεπιφύλακτα
να περάσεις πρώτα από το εργαστήριο [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven)
του [C++ Now! 2014](http://cppnow.org/).  Τα ίδια εργαλεία που
χρησιμοποιούνται σε αυτό το εργαστήριο χρησιμοποιούνται και στη διαδρομή της
C++ στο Exercism.
