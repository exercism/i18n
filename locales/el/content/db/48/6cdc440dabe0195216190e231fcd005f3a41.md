# Σχετικά

Κλάσεις όπως οι `LocalDate` και `LocalDateTime` περιγράφουν μια _στιγμή_ στον χρόνο.
Το πακέτο `java.time` έχει επίσης δύο κλάσεις που περιγράφουν ένα _χρονικό διάστημα_:

- Το [`Period`][period-docs] είναι ένα χρονικό διάστημα βασισμένο σε ημερομηνία, σε χρόνια, μήνες και ημέρες, όπως "2 μήνες και 5 ημέρες".
- Το [`Duration`][duration-docs] είναι ένα χρονικό διάστημα βασισμένο στον χρόνο, σε ώρες, λεπτά, δευτερόλεπτα, χιλιοστά του δευτερολέπτου και νανοδευτερόλεπτα, όπως "1 ώρα και 30 λεπτά".

Η διαφορά έχει σημασία, γιατί οι μονάδες του ημερολογίου δεν έχουν σταθερό μήκος.
Ένας μήνας μπορεί να έχει 28, 29, 30 ή 31 ημέρες, οπότε ο "ένας μήνας" δεν είναι σταθερός αριθμός δευτερολέπτων.
Ένα `Period` ακολουθεί το ημερολόγιο, ενώ ένα `Duration` μετρά ακριβή χρόνο.

| | `Period` | `Duration` |
| --- | --- | --- |
| Αποθηκεύει | χρόνια, μήνες και ημέρες | δευτερόλεπτα και νανοδευτερόλεπτα |
| Χρησιμοποιείται με | `LocalDate`, `LocalDateTime` | `LocalTime`, `LocalDateTime`, `Instant` |

Και οι δύο κλάσεις είναι αμετάβλητες.
Μέθοδοι όπως οι `plusDays()` ή `multipliedBy()` επιστρέφουν ένα _νέο_ στιγμιότυπο και αφήνουν το αρχικό αναλλοίωτο.

## `Period`

### Δημιουργία περιόδου

```java
Period.ofDays(10);
// => P10D

Period.ofWeeks(2);
// => P14D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

Το αποτέλεσμα του `toString()` χρησιμοποιεί τη [μορφή διάρκειας ISO-8601][iso-8601-durations]: `P` ακολουθούμενο από τον αριθμό των ετών (`Y`), των μηνών (`M`) και των ημερών (`D`).
Δεν υπάρχουν εβδομάδες σε ένα `Period`: το `Period.ofWeeks(2)` αποθηκεύεται ως 14 ημέρες.
Η ίδια σημειογραφία μπορεί να αναλυθεί ξανά με το `Period.parse()`:

```java
Period.parse("P1Y2M15D");
// => P1Y2M15D
```

### Προσθήκη περιόδου σε μια ημερομηνία

Μια περίοδος προστίθεται ή αφαιρείται από μια ημερομηνία με τις `plus()` και `minus()`:

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

Μια περίοδος μπορεί να προστεθεί σε ένα `LocalDateTime` με τον ίδιο τρόπο, και η ώρα της ημέρας μένει ίδια:

```java
LocalDateTime.of(2024, 3, 10, 9, 30).plus(Period.ofMonths(1));
// => 2024-04-10T09:30
```

Ένα `Instant` δεν έχει ημερολόγιο, οπότε μπορεί να του προστεθεί μόνο περίοδος σε ημέρες.
Μια περίοδος με χρόνια ή μήνες πετάει μια εξαίρεση:

```java
Instant instant = Instant.parse("2024-03-10T09:30:00Z");

instant.plus(Period.ofDays(2));
// => 2024-03-12T09:30:00Z

instant.plus(Period.ofMonths(1));
// => throws UnsupportedTemporalTypeException
```

Πρώτα προστίθενται τα χρόνια, μετά οι μήνες και μετά οι ημέρες.
Όταν η προσθήκη ετών ή μηνών πέφτει σε μια ημέρα που δεν υπάρχει, το αποτέλεσμα μεταφέρεται στην τελευταία έγκυρη ημέρα εκείνου του μήνα:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28

LocalDate.of(2024, 2, 29).plus(Period.ofYears(1));
// => 2025-02-28
```

Αυτό σημαίνει επίσης ότι η προσθήκη μιας περιόδου και μετά η αφαίρεσή της δεν δίνει πάντα πίσω την αρχική ημερομηνία:

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1)).minus(Period.ofMonths(1));
// => 2025-01-28
```

### Η περίοδος μεταξύ δύο ημερομηνιών

Το `Period.between()` επιστρέφει την περίοδο από τη μία ημερομηνία (συμπεριλαμβανομένης) έως την άλλη (μη συμπεριλαμβανομένης).
Το ίδιο αποτέλεσμα είναι διαθέσιμο και ως `LocalDate.until()`:

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period.between(start, end);
// => P1Y2M15D

start.until(end);
// => P1Y2M15D
```

Τα μέρη μιας περιόδου είναι διαθέσιμα μέσω των `getYears()`, `getMonths()` και `getDays()`.
Αυτά τα μέρη είναι ανεξάρτητα μεταξύ τους: το `getDays()` επιστρέφει μόνο το μέρος των ημερών, όχι τον συνολικό αριθμό ημερών.
Το `toTotalMonths()` επιστρέφει τα χρόνια και τους μήνες μαζί ως αριθμό μηνών, αλλά δεν υπάρχει μέθοδος για τον συνολικό αριθμό ημερών, γιατί αυτός εξαρτάται από τους μήνες που εμπλέκονται.

```java
Period period = Period.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => P2M5D

period.getDays();
// => 5

period.toTotalMonths();
// => 2
```

### Κανονικοποίηση μιας περιόδου

Μια περίοδος που δημιουργείται με μια μέθοδο κατασκευής κρατά τις μονάδες της ακριβώς όπως δόθηκαν, και το `equals()` συγκρίνει τις μονάδες μία προς μία.
Το `normalized()` μετατρέπει τους μήνες σε χρόνια, αλλά αφήνει τις ημέρες όπως είναι:

```java
Period.ofMonths(14);
// => P14M

Period.ofMonths(14).equals(Period.of(1, 2, 0));
// => false

Period.ofMonths(14).normalized();
// => P1Y2M

Period.ofDays(45).normalized();
// => P45D
```

## Μέτρηση μονάδων με το `ChronoUnit`

Για να πάρεις τον συνολικό αριθμό μιας μεμονωμένης μονάδας ανάμεσα σε δύο χρονικές στιγμές, χρησιμοποίησε τη μέθοδο `between()` σε μία από τις σταθερές του [`ChronoUnit`][chronounit-docs]:

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

ChronoUnit.DAYS.between(start, end);
// => 65

ChronoUnit.WEEKS.between(start, end);
// => 9

ChronoUnit.MONTHS.between(start, end);
// => 2
```

Μετριούνται μόνο πλήρεις μονάδες, και το αποτέλεσμα είναι αρνητικό όταν το δεύτερο όρισμα είναι πριν από το πρώτο:

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

Το `ChronoUnit` λειτουργεί επίσης με μονάδες που βασίζονται στον χρόνο και με ημερομηνίες-ώρες:

```java
ChronoUnit.MINUTES.between(
    LocalDateTime.of(2024, 3, 10, 18, 5),
    LocalDateTime.of(2024, 3, 10, 19, 40));
// => 95
```

## `Duration`

### Δημιουργία διάρκειας

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofSeconds(3725);
// => PT1H2M5S

Duration.ofDays(2);
// => PT48H

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

Στη σημειογραφία ISO-8601, το `T` χωρίζει το τμήμα της ημερομηνίας από το τμήμα της ώρας.
Ένα `Duration` δεν έχει τμήμα ημερομηνίας, οπότε το `toString()` του ξεκινά πάντα με `PT`.
Το `Duration.ofDays()` θεωρεί μια ημέρα ακριβώς 24 ώρες.

Μια διάρκεια μπορεί επίσης να αναλυθεί με το `Duration.parse()`:

```java
Duration.parse("PT1H30M");
// => PT1H30M
```

### Προσθήκη διάρκειας σε μια ώρα

Μια διάρκεια προστίθεται ή αφαιρείται από ένα `LocalTime`, ένα `LocalDateTime` ή ένα `Instant` με τις `plus()` και `minus()`:

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00

LocalTime.of(23, 0).plus(Duration.ofHours(2));
// => 01:00
```

Ένα `LocalTime` κάνει κύκλο γύρω από τα μεσάνυχτα, όπως δείχνει το τελευταίο παράδειγμα.

Ένα `LocalDate` δεν έχει ώρα, οπότε δεν μπορεί να συνδυαστεί με ένα `Duration`:

```java
LocalDate.of(2024, 3, 10).plus(Duration.ofHours(1));
// => throws UnsupportedTemporalTypeException
```

### Η διάρκεια μεταξύ δύο χρονικών στιγμών

Το `Duration.between()` επιστρέφει το ακριβές χρονικό διάστημα μεταξύ δύο ωρών ή ημερομηνιών-ωρών:

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M

Duration.between(checkOut, checkIn);
// => PT-1H-35M
```

Το `Duration.between()` δεν δέχεται δύο τιμές `LocalDate`, γιατί μια ημερομηνία δεν έχει δευτερόλεπτα για να μετρηθούν:

```java
Duration.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => throws UnsupportedTemporalTypeException
```

Για ημερομηνίες, χρησιμοποίησε αντ' αυτού το `Period.between()` ή το `ChronoUnit.DAYS.between()`.

### Μετατροπή μιας διάρκειας

Οι μέθοδοι `toXxx()` μετατρέπουν μια διάρκεια σε _συνολική_ ποσότητα μιας μεμονωμένης μονάδας, στρογγυλοποιημένη προς τα κάτω:

```java
Duration duration = Duration.ofSeconds(5730); // 1 hour, 35 minutes and 30 seconds

duration.toHours();
// => 1

duration.toMinutes();
// => 95

duration.toSeconds();
// => 5730
```

Οι μέθοδοι `toXxxPart()` χωρίζουν μια διάρκεια στα μέρη της, όπως σε ένα ρολόι:

```java
Duration duration = Duration.ofSeconds(5730);

duration.toHoursPart();
// => 1

duration.toMinutesPart();
// => 35

duration.toSecondsPart();
// => 30
```

Το `toHoursPart()` σταματά στο 23, γιατί οι ώρες πάνω από αυτό μετριούνται από το `toDaysPart()`.

### Σύγκριση και υπολογισμοί με διάρκειες

Οι διάρκειες μπορούν να συγκριθούν με το `compareTo()` και να ελεγχθούν με τα `isZero()` και `isNegative()`:

```java
Duration visit = Duration.ofMinutes(95);
Duration limit = Duration.ofHours(2);

visit.compareTo(limit) > 0;
// => false

Duration.between(LocalTime.of(10, 0), LocalTime.of(9, 0)).isNegative();
// => true
```

Υποστηρίζουν επίσης αριθμητικές πράξεις, όπως `plus()`, `minus()`, `multipliedBy()` και `dividedBy()`:

```java
Duration.ofMinutes(20).multipliedBy(3);
// => PT1H

Duration.ofHours(2).dividedBy(Duration.ofMinutes(15));
// => 8
```

## `Period` ή `Duration`;

Για ένα `LocalDate` ή ένα `LocalTime`, η επιλογή γίνεται για σένα: μια ημερομηνία δεν έχει ώρα για να μετρηθεί, και μια ώρα δεν έχει ημερολόγιο.
Ένα `LocalDateTime` έχει και τα δύο, αλλά όχι ζώνη ώρας, οπότε η προσθήκη `Period.ofDays(1)` ή `Duration.ofDays(1)` σε αυτό δίνει το ίδιο αποτέλεσμα.
Η διαφορά γίνεται ορατή με τις ζώνες ώρας.
Όταν τα ρολόγια πηγαίνουν μπροστά για τη θερινή ώρα, μια ημερολογιακή ημέρα διαρκεί μόνο 23 ώρες:

```java
ZonedDateTime noon = ZonedDateTime.of(2025, 3, 29, 12, 0, 0, 0, ZoneId.of("Europe/Amsterdam"));

noon.plus(Period.ofDays(1));
// => 2025-03-30T12:00+02:00[Europe/Amsterdam]

noon.plus(Duration.ofDays(1));
// => 2025-03-30T13:00+02:00[Europe/Amsterdam]
```

Η προσθήκη ενός `Period` μιας ημέρας κρατά την ώρα της ημέρας, ενώ η προσθήκη ενός `Duration` μιας ημέρας προσθέτει ακριβώς 24 ώρες.
Χρησιμοποίησε `Period` για ποσά που τα σκεφτόμαστε με όρους ημερολογίου ("την ίδια ώρα τον επόμενο μήνα") και `Duration` για χρόνο που έχει περάσει ("το εισιτήριο στάθμευσης ισχύει για 2 ώρες").
