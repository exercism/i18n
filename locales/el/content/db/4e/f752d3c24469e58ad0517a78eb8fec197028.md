# Εισαγωγή

## Ψευδώνυμα τύπων

### Ψευδώνυμα τύπων

Ένα ψευδώνυμο τύπου μπορεί να χρησιμοποιηθεί στη Gleam για να δώσει ένα βολικό όνομα σε έναν υπάρχοντα τύπο που διαφορετικά θα ήταν δύσκολο να γραφτεί.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Όταν γράφεται με `pub type`, το ψευδώνυμο μπορεί να χρησιμοποιηθεί εκτός του αρθρώματος στο οποίο ορίζεται. Αν παραλειφθεί το `pub`, τότε το ψευδώνυμο είναι ιδιωτικό και δεν μπορεί να γίνει αναφορά σε αυτό από άλλα αρθρώματα.

## Λεξικά

Τα λεξικά στη Gleam είναι η δομή δεδομένων για την αποθήκευση πληροφοριών σε ζεύγη κλειδιού-τιμής. Σε άλλες γλώσσες, αυτά μπορεί επίσης να είναι γνωστά ως συνειρμικοί πίνακες, κατακερματισμοί ή λεξικά.

Οποιοσδήποτε τύπος μπορεί να χρησιμοποιηθεί για τα κλειδιά και τις τιμές σε ένα λεξικό, και δεν εγγυώνται τη σειρά των καταχωρήσεών τους όταν προσπελαύνονται ή επιστρέφονται.

### Εργασία με λεξικά

Τα λεξικά δημιουργούνται και χειρίζονται χρησιμοποιώντας συναρτήσεις από το άρθρωμα `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
