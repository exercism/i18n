# Προσθήκη στις οδηγίες

## Λέξεις

Όρισε μια πλειάδα `stopwatch` και έναν κατασκευαστή `<stopwatch> ( -- stopwatch )` που επιστρέφει ένα νέο χρονόμετρο στην κατάσταση `"ready"`, χωρίς χρόνο που έχει περάσει και χωρίς προηγούμενους γύρους.

Δώσε αυτές τις λέξεις που λειτουργούν πάνω σε ένα χρονόμετρο:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` ή `"stopped"`.
- `current-lap ( stopwatch -- str )`: ο χρόνος που έχει περάσει στον τρέχοντα γύρο, ως συμβολοσειρά `"HH:MM:SS"`.
- `total ( stopwatch -- str )`: ο συνολικός χρόνος που έχει περάσει στον τρέχοντα γύρο και σε όλους τους προηγούμενους γύρους, ως συμβολοσειρά `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )`: ένας πίνακας με τους γύρους που έχουν καταγραφεί προηγουμένως, ο καθένας ως συμβολοσειρά `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )` και `lap ( stopwatch -- )`: οι τέσσερις εντολές από τον παραπάνω πίνακα. Αν καλέσεις μία από αυτές από μια κατάσταση που δεν την επιτρέπει, θα πρέπει να `throw` ένα σφάλμα.

Ο χρόνος προωθείται με:

- `advance-time ( str stopwatch -- )`: πρόσθεσε τη διάρκεια `"HH:MM:SS"` στον τρέχοντα γύρο. Αυτό έχει αποτέλεσμα μόνο όσο το χρονόμετρο βρίσκεται σε λειτουργία.
