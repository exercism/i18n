# Εισαγωγή

## Πίνακες

Η βασική βιβλιοθήκη της Cairo υλοποιεί έναν τύπο `Array`.

Μοιάζει με τους συνηθισμένους τύπους πίνακα που συναντάς σε άλλες γλώσσες προγραμματισμού, αλλά έχει μερικές βασικές διαφορές:

- Τα στοιχεία μπορούν να προστεθούν αποδοτικά μόνο στο πίσω μέρος του τύπου `Array`, και μπορούν να αφαιρεθούν αποδοτικά μόνο από το μπροστινό μέρος.
- Είναι αδύνατο να ορίσεις χειροκίνητα ένα στοιχείο χρησιμοποιώντας τη θέση του πίνακα.

Οι πίνακες μπορούν να δημιουργηθούν χρησιμοποιώντας τη συνάρτηση `ArrayTrait::new` καθώς και το μάκρο `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Τα στοιχεία μπορούν να προστεθούν στον πίνακα χρησιμοποιώντας τη συνάρτηση `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Τα στοιχεία μπορούν να αφαιρεθούν από τον πίνακα χρησιμοποιώντας τη συνάρτηση `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Η Cairo εισάγει επίσης έναν τύπο `Span` που λειτουργεί σαν ένα "στιγμιότυπο" του `Array`.

Κάθε `Array` μπορεί να μετατραπεί σε `Span` με τη συνάρτηση `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Η μετατροπή ενός πίνακα σε `Span` είναι πολύ αποδοτική, καθώς το `Span` είναι απλώς μια δομή δεδομένων που επιτρέπει στην Cairo να "δει" ένα τμήμα του πίνακα, χωρίς να το τροποποιεί με κανέναν τρόπο.

Μετατρέποντας έναν πίνακα σε `Span`, η Cairo επιτρέπει να εκτελεστούν περισσότερες λειτουργίες από όσες θα επιτρέπονταν απευθείας σε ένα `Array`, όπως η αφαίρεση ενός στοιχείου από το μπροστινό μέρος του span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Σημείωσε ότι έπρεπε να κάνουμε το `one_to_four_span` μεταβλητό με τη λέξη-κλειδί `mut` για να καλέσουμε το `pop_back`, το οποίο μεταβάλλει το span συντομεύοντας το τμήμα του πίνακα που "βλέπει" το span.
