# Υποδείξεις

## 1. Συστήσου

Η συνάρτηση `introduce` πρέπει να "ξετυλίξει" την τιμή που περιέχεται στο `player.Name`.
Σκέψου να χρησιμοποιήσεις τη συνάρτηση [`Options.defaultValue`][defaultvalue] για να μετατρέψεις το `player.Name` στη "τυλιγμένη" τιμή του όταν είναι `Some` ή στην απαιτούμενη προεπιλεγμένη τιμή όταν είναι `None`.

## 2. Υλοποίησε τον μηχανισμό αναβίωσης

Η συνάρτηση `revive` πρέπει να επιστρέψει είτε `Some <player>` είτε `None`, όπου το `<player>` είναι μια καταγραφή `Player`, ενδεχομένως με κάποια τροποποιημένα πεδία.

## 3. Υλοποίησε τον μηχανισμό ρίψης ξορκιών

Σκέψου να χρησιμοποιήσεις μια έκφραση match για να καλύψεις και τις δύο περιπτώσεις, `Some` και `None`, όπως στο παρακάτω παράδειγμα:

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
