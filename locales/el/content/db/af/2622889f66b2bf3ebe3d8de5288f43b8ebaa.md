# Οδηγίες

Σε δελέασαν να γυρίσεις στη Hyperia (με τον υψηλό πληθωρισμό) για μια ημερήσια αμοιβή που κόβει την ανάσα.

Η Κεντρική Τράπεζα σκέφτεται να εισαγάγει το δολάριο ΗΠΑ ως δεύτερο νόμισμα, οπότε όλα τα λογιστικά συστήματα πρέπει να προσαρμοστούν ώστε να χειρίζονται πολλαπλά νομίσματα.

Σου ζητήθηκε να υλοποιήσεις το αντικείμενο ποσού νομίσματος.

## 1. Ενεργοποίησε τον έλεγχο ισότητας του ποσού νομίσματος

Τροποποίησε το struct `CurrencyAmount` ώστε να χειρίζεται την ισότητα. Αν τα δύο struct ποσού νομίσματος δεν έχουν το ίδιο νόμισμα ("USD" ή "HD"), τότε θα πρέπει να πεταχτεί ένα στιγμιότυπο της `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Σύγκρινε ποσά νομίσματος

Τροποποίησε το struct `CurrencyAmount` ώστε να χειρίζεται συγκρίσεις (μόνο `>` και `<`). Αν τα δύο struct ποσού νομίσματος δεν έχουν το ίδιο νόμισμα ("USD" ή "HD"), τότε θα πρέπει να πεταχτεί ένα στιγμιότυπο της `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Πρόσθεσε και αφαίρεσε ποσά νομίσματος

Τροποποίησε το struct `CurrencyAmount` ώστε να χειρίζεται αριθμητική πρόσθεση και αφαίρεση (μόνο `+` και `-`). Αν τα δύο struct ποσού νομίσματος δεν έχουν το ίδιο νόμισμα ("USD" ή "HD"), τότε θα πρέπει να πεταχτεί ένα στιγμιότυπο της `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Πολλαπλασίασε και διαίρεσε ποσά νομίσματος

Τροποποίησε το struct `CurrencyAmount` ώστε να χειρίζεται αριθμητικό πολλαπλασιασμό και διαίρεση (μόνο `*` και `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Μετέτρεψε το ποσό νομίσματος σε `double`

Τροποποίησε το struct `CurrencyAmount` ώστε ένα στιγμιότυπό του να μπορεί να μετατραπεί ρητά σε `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Μετέτρεψε το ποσό νομίσματος σε `decimal`

Τροποποίησε το struct `CurrencyAmount` ώστε ένα στιγμιότυπό του να μπορεί να μετατραπεί έμμεσα σε `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
