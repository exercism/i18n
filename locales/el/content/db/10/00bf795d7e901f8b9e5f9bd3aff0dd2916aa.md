# Υποδείξεις

## Γενικά

- Διάβασε για τα [σφάλματα][getting-started-errors] στον οδηγό Ξεκινώντας.
- Διάβασε για το [IO][getting-started-io] στον οδηγό Ξεκινώντας.

## 1. Άνοιξε ένα αρχείο

- Χρησιμοποίησε τη _δυναμική αποστολή_ για να καλέσεις τη συνάρτηση open. Δες ξανά το απόσπασμα κώδικα της εισαγωγής.

## 2. Προσπάθησε να γράψεις στο αρχείο

- Αξιοποίησε τη δομή try-rescue.
- Υπάρχει μια [συνάρτηση][io-write] στο module `IO` που σου επιτρέπει να γράψεις σε μια συσκευή IO.
- Μπορείς να χρησιμοποιήσεις το μπλοκ `rescue` για να κάνεις αντιστοίχιση προτύπων στο σφάλμα και να επιστρέψεις την πλειάδα σφάλματος.
- Μπορείς να χρησιμοποιήσεις το μπλοκ `else` για να κάνεις αντιστοίχιση προτύπων στην τιμή επιστροφής μιας επιτυχημένης εγγραφής.

## 3. Κλείσε το αρχείο

- Μπορείς να χρησιμοποιήσεις το μπλοκ `after` για να εκτελέσεις μια συνάρτηση ανεξάρτητα από το αν το μπλοκ `try` πετύχει ή πιαστεί από το `rescue`.
