# Βασικά

Η Haskell είναι μια συναρτησιακή γλώσσα προγραμματισμού, όπου οι συναρτήσεις θεωρούνται πολίτες πρώτης κατηγορίας.
Αυτό σημαίνει ότι οι συναρτήσεις μπορούν να περαστούν ως ορίσματα σε άλλες συναρτήσεις, να επιστραφούν ως τιμές από άλλες συναρτήσεις και να ανατεθούν σε μεταβλητές.

## Συναρτήσεις

Οι συναρτήσεις στη Haskell ορίζονται με τον τελεστή `=`.
Το όνομα της συνάρτησης ακολουθείται από τα ορίσματά της, χωρισμένα με κενά.
Αυτό διαφέρει αρκετά από τις περισσότερες άλλες γλώσσες, όπου το όνομα της συνάρτησης ακολουθείται από παρενθέσεις που περιέχουν τα ορίσματα χωρισμένα με κόμματα.

```haskell
add number1 number2 = number1 + number2
```

Η Haskell είναι μια στατικά τυποποιημένη γλώσσα, και ο μεταγλωττιστής ghc μπορεί να συμπεράνει τους τύπους των ορισμάτων και της τιμής επιστροφής.
Ωστόσο, είναι καλή πρακτική να καθορίζεις τους τύπους των ορισμάτων και της τιμής επιστροφής.
Για να καθορίσουμε τον τύπο μιας συνάρτησης, χρησιμοποιούμε τον τελεστή `::`.
Το όνομα της συνάρτησης ακολουθείται από τον τελεστή `::`, και μετά έρχονται οι τύποι των ορισμάτων χωρισμένοι με `->`, ενώ ο τελευταίος τύπος είναι η τιμή επιστροφής.

```haskell
justNumber :: Int
justNumber = 42

add :: Int -> Int -> Int
add number1 number2 = number1 + number2
```

## Κλήση συναρτήσεων

Για να καλέσουμε μια συνάρτηση, γράφουμε το όνομα της συνάρτησης και μετά τα ορίσματα, χωρισμένα με κενά.

```haskell
add 1 2
```

Όταν περνάμε μια συνάρτηση ως όρισμα σε άλλη συνάρτηση, ίσως χρειαστεί να χρησιμοποιήσουμε παρενθέσεις για να καθορίσουμε τη σειρά αξιολόγησης.

```haskell
add (add 1 2) 3
```

Εδώ πρώτα αξιολογείται το 1 2, μετά το αποτέλεσμα περνά στην εξωτερική συνάρτηση add, οπότε η εξωτερική add λαμβάνει δύο ορίσματα.

## Εσοχή / σημαντικά κενά

Η Haskell χρησιμοποιεί κενά και εσοχή για να καθορίσει τα όρια του κώδικα.
***Ο κώδικας που αποτελεί μέρος κάποιας έκφρασης θα πρέπει να έχει μεγαλύτερη εσοχή από την αρχή αυτής της έκφρασης.***

- Οι ορισμοί module, import και συναρτήσεων ανώτατου επιπέδου πρέπει να ξεκινούν στην πιο αριστερή στήλη.
- Αν μια έκφραση χωριστεί σε πολλές γραμμές, ο κώδικας που αποτελεί μέρος αυτής της έκφρασης πρέπει να έχει εσοχή κάτω από αυτήν την έκφραση με τουλάχιστον ένα κενό.
- Τα μέρη της έκφρασης που ομαδοποιούνται μαζί θα πρέπει να έχουν εσοχή με ίσο αριθμό κενών.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

## Modules

Τα modules εξάγουν συναρτήσεις.
Αυτό σημαίνει ότι μπορείς να χρησιμοποιήσεις τις συναρτήσεις που το module καθιστά διαθέσιμες στη δήλωση εξαγωγής του.
Ένα module μπορεί επίσης να ορίσει συναρτήσεις μόνο για εσωτερική χρήση.
Από προεπιλογή, οι συναρτήσεις που δεν έχουν εξαχθεί ρητά δεν μπορούν να χρησιμοποιηθούν από έξω από το module.

Στην αρχή ενός module, καθορίζουμε το όνομα του module.
Αν έχουμε ένα αρχείο που ονομάζεται Calculator.hs, τότε θα πρέπει να ονομάσουμε το module μας Calculator.
Στη συνέχεια, καθορίζουμε τις συναρτήσεις που εξάγει και μετά από αυτό, μπορούμε να αρχίσουμε να γράφουμε τις συναρτήσεις.
Ας ξεκινήσουμε λοιπόν με αυτό.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Σχόλια

Ένα σχόλιο είναι κάποιο κείμενο μέσα στο αρχείο Haskell που δεν διερμηνεύεται ως κώδικας.
Προορίζεται κυρίως για να το διαβάζεις εσύ και άλλοι προγραμματιστές.
Υπάρχει μια ελαφριά σύνταξη για σχόλια μίας γραμμής, βασισμένη σε διπλές παύλες.
Τα σχόλια πολλών γραμμών είναι επίσης δυνατά με το ζεύγος `{-` και `-}` ως οριοθέτες ανοίγματος και κλεισίματος.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
