# Οδηγίες

Σε αυτή την άσκηση, σου έχει ανατεθεί να γράψεις το λογισμικό για μια συσκευή κρυπτογράφησης που λειτουργεί εκτελώντας μετασχηματισμούς σε δεδομένα. Χρειάζεσαι έναν τρόπο να δημιουργείς πολύπλοκες συναρτήσεις με ευελιξία, συνδυάζοντας απλούστερες συναρτήσεις μεταξύ τους.

Για κάθε εργασία, επέστρεψε μια ανώνυμη συνάρτηση που μπορεί να κληθεί από το πλαίσιο κλήσης.

Όλες οι συναρτήσεις πρέπει να δέχονται ακέραια ορίσματα. Οι ακέραιοι είναι επίσης κατάλληλοι για την εκτέλεση πράξεων bitwise στην Elixir.

## 1. Δημιούργησε έναν αθροιστή

Υλοποίησε τη `Secrets.secret_add/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και προσθέτει σε αυτό το όρισμα που πέρασες στη `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Δημιούργησε έναν αφαιρέτη

Υλοποίησε τη `Secrets.secret_subtract/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και αφαιρεί από αυτό το όρισμα το μυστικό που πέρασες στη `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Δημιούργησε έναν πολλαπλασιαστή

Υλοποίησε τη `Secrets.secret_multiply/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και το πολλαπλασιάζει με το μυστικό που πέρασες στη `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Δημιούργησε έναν διαιρέτη

Υλοποίησε τη `Secrets.secret_divide/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και το διαιρεί με το μυστικό που πέρασες στη `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Χρησιμοποίησε ακέραια διαίρεση ώστε η έξοδος να είναι συμβατή με την αναμενόμενη είσοδο των άλλων συναρτήσεων.

## 5. Δημιούργησε μια συνάρτηση "and"

Υλοποίησε τη `Secrets.secret_and/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και εκτελεί μια bitwise πράξη _and_ σε αυτό και στο μυστικό που πέρασες στη `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Δημιούργησε μια συνάρτηση "xor"

Υλοποίησε τη `Secrets.secret_xor/1`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και εκτελεί μια bitwise πράξη _xor_ σε αυτό και στο μυστικό που πέρασες στη `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Δημιούργησε έναν συνδυαστή συναρτήσεων

Υλοποίησε τη `Secrets.secret_combine/2`. Θα πρέπει να επιστρέφει μια συνάρτηση που δέχεται ένα όρισμα και εφαρμόζει σε αυτό τις δύο συναρτήσεις που πέρασες στη `secret_combine` με τη σειρά.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
