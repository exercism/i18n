# Εισαγωγή

Τα `Integer` κρατούν οποιονδήποτε αριθμό, όσο μεγάλος κι αν είναι, μέχρι το όριο της μνήμης του υπολογιστή σου, ενώ το `Int` αντιστοιχεί στο σύνολο των θετικών και αρνητικών ακεραίων που μπορούν να παρασταθούν σε 32 ή 64 bits (εγγυημένα τουλάχιστον από -2^29 έως 2^29).

Το `Float` αντιστοιχεί στο σύνολο των πραγματικών αριθμών, περιορισμένο από την ακρίβεια του υπολογιστή.
Οι πράξεις που ορίζονται στους αριθμούς συνήθως λειτουργούν στον έναν τύπο ή στον άλλον, αλλά όχι και στους δύο.

Οι συναρτήσεις για τη μετατροπή μεταξύ `Float` και `Integer` περιλαμβάνουν, μεταξύ άλλων, τη `toFloat`, που μετατρέπει `Int`/`Integer` σε `Float`, και τη `ceiling`, που μετατρέπει ένα `Float` σε `Int`.

Η μετατροπή από έναν ακέραιο τύπο (`Int` ή `Integer`) σε οποιονδήποτε άλλον αριθμητικό τύπο γίνεται με τη συνάρτηση `fromIntegral`.
Ο τύπος-στόχος συνάγεται αυτόματα.
Για παράδειγμα:

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
