# Εισαγωγή

## Κληρονομικότητα

Στη C#, μια ιεραρχία _κλάσεων_ μπορεί να οριστεί με _κληρονομικότητα_, η οποία επιτρέπει σε μια παράγωγη κλάση (`Car`) να κληρονομήσει τη συμπεριφορά και τα δεδομένα της γονικής της κλάσης (`Vehicle`). Αν δεν καθοριστεί γονική κλάση, η κλάση κληρονομεί από την κλάση `object`.

Οι γονικές κλάσεις μπορούν να παρέχουν λειτουργικότητα στις παράγωγες κλάσεις με τρεις τρόπους:

- Ορίζοντας μια συνηθισμένη μέθοδο.
- Ορίζοντας μια μέθοδο `virtual`, που είναι σαν μια συνηθισμένη μέθοδος, με τη διαφορά ότι οι παράγωγες κλάσεις _μπορούν_ να την αλλάξουν.
- Ορίζοντας μια μέθοδο `abstract`, που είναι μια μέθοδος χωρίς υλοποίηση την οποία οι παράγωγες κλάσεις _πρέπει_ να υλοποιήσουν. Μια κλάση με μεθόδους `abstract` πρέπει να έχει και η ίδια τη σήμανση `abstract`. Οι αφηρημένες κλάσεις δεν μπορούν να δημιουργηθούν ως στιγμιότυπα.

Ο τροποποιητής πρόσβασης `protected` επιτρέπει την πρόσβαση σε ένα μέλος της γονικής κλάσης μέσα από μια παράγωγη κλάση, αλλά εμποδίζει την πρόσβαση από άλλες κλάσεις.

Οι παράγωγες κλάσεις μπορούν να έχουν πρόσβαση στα μέλη της γονικής κλάσης μέσω της λέξης-κλειδιού `base`.

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

Ο κατασκευαστής μιας παράγωγης κλάσης καλεί αυτόματα τον κατασκευαστή της γονικής κλάσης _πριν_ εκτελέσει τη λογική του δικού του κατασκευαστή. Ορίσματα μπορούν να περαστούν στον κατασκευαστή μιας γονικής κλάσης χρησιμοποιώντας τη λέξη-κλειδί `base`:

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

Όταν από μια βασική κλάση παράγονται περισσότερες από μία κλάσεις, οι δύο (ή περισσότερες) κλάσεις συχνά υλοποιούν διαφορετικές εκδοχές μιας μεθόδου της βασικής κλάσης. Αυτή είναι μια πολύ σημαντική αρχή που ονομάζεται πολυμορφισμός. Για παράδειγμα, σε μια παραλλαγή του παραπάνω παραδείγματος, δείχνουμε πώς ο κώδικας που χρησιμοποιεί `Vehicle` μπορεί να αλλάξει τη συμπεριφορά του ανάλογα με το ποιος τύπος οχήματος έχει δημιουργηθεί ως στιγμιότυπο.

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
