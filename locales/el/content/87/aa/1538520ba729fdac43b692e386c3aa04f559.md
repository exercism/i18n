# Εισαγωγή

Η αποδόμηση είναι ένας τρόπος να διασπάσεις σύνθετες τιμές στη Rust. Χρησιμοποιείται συχνά για να εξάγεις πεδία από πλειάδες ή struct.

Για παράδειγμα, το παρακάτω απόσπασμα εξάγει δύο τιμές από μια πλειάδα:

```rust
let (first, second) = (1, 2);
```

Η τιμή `1` δεσμεύεται στη μεταβλητή `first`.
Η τιμή `2` δεσμεύεται στη μεταβλητή `second`.
