# Εισαγωγή

Αυτό είναι δυνητικά ένα _μεγάλο_ θέμα!
Μπορεί κανείς να γράψει ένα ολόκληρο βιβλίο γι' αυτό, και αρκετοί άνθρωποι το έχουν κάνει (ψάξε στο Amazon για "unicode book" για να δεις μερικά παραδείγματα).

## Μια πολύ σύντομη ιστορία

Ο χειρισμός χαρακτήρων στους υπολογιστές ήταν πολύ πιο απλός τις προηγούμενες δεκαετίες, όταν οι προγραμματιστές θεωρούσαν ότι τα αγγλικά ήταν η μόνη σημαντική γλώσσα.
Λοιπόν: 26 γράμματα, κεφαλαία και πεζά, 10 ψηφία, μερικά σημεία στίξης, συν έναν κωδικό (0x07) για να χτυπάει ένα κουδούνι, και όλα χωρούσαν σε 7 bits: το σύνολο χαρακτήρων [ASCII][wiki-ascii].

Φυσικά, οι άνθρωποι άρχισαν να ρωτούν τι γίνεται με τα à, ä και Ł, μετά άλλοι άρχισαν να ρωτούν για τα ऄ, ஹ και ญ, και οι νέοι ήθελαν emoji 😱.
Τι να κάνουμε;

Για να μην τα πολυλογούμε, πολλοί έξυπνοι και υπομονετικοί άνθρωποι χρειάστηκε να συμμετάσχουν σε επιτροπές για χρόνια, επεξεργαζόμενοι τις λεπτομέρειες του συνόλου χαρακτήρων [Unicode][web-unicode] και κωδικοποιήσεων όπως το [UTF-8][wiki-utf-8], και πολλά προγράμματα χρειάστηκαν μια _πολύ_ περίπλοκη επανεγγραφή.
Επίσης, εισήχθησαν πολλά νέα bugs.

Για να μην καταρρεύσουν _τα πάντα_, ο σχεδιασμός των Unicode/UTF-8 διασφαλίζει ότι οι πρώτοι 127 κωδικοί είναι ίδιοι με το ASCII _(ακόμα και το κουδούνι)_.

## Οι χαρακτήρες στην Kotlin

Οι γλώσσες προγραμματισμού που σχεδιάστηκαν μετά το 2005 περίπου έχουν το τεράστιο πλεονέκτημα ότι υπήρχε ήδη ένα αρκετά σταθερό πρότυπο Unicode.

Η Kotlin (κυκλοφόρησε για πρώτη φορά το 2011) μπόρεσε να υποθέσει ότι οι χρήστες θα χρησιμοποιούσαν διάφορες (ανθρώπινες) γλώσσες και θα χρειάζονταν το Unicode για να τις εκφράσουν.

Τα κυριολεκτικά χαρακτήρων γράφονται με μονά εισαγωγικά και διαφέρουν από τις συμβολοσειρές που γράφονται με διπλά εισαγωγικά.
Αυτό είναι πιθανώς προφανές σε όσους προέρχονται από τον κόσμο της C/C++ αλλά μπορεί να μπερδέψει όσους προγραμματίζουν σε Python και JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Η μετατροπή μεταξύ `Char` και `Int` είναι απλή:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

Ο μεταγλωττιστής επιτρέπει _μερικές_ μορφές ακέραιης αριθμητικής σε `Char`:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Μερικές συναρτήσεις για `Char`

Όπως πάντα, υπάρχουν πάρα [πολλές συναρτήσεις][ref-char-lib] για να τις συζητήσουμε εδώ, οπότε αυτή είναι απλώς μια επιλογή.

- Για τα κατάλληλα αλφάβητα, άλλαξε πεζά/κεφαλαία με τις [`uppercase()`][ref-uppercase] και [`lowercase()`][ref-lowercase].
- Έλεγξε αν είναι πεζά ή κεφαλαία με τις [`isUpperCase()`][ref-isuppercase] και [`isLowerCase()`][ref-islowercase].
- Έλεγξε τον τύπο του χαρακτήρα με:
    - [`isLetter()`][ref-isletter], καλύπτει πολλά αλφάβητα
    - [`isDigit()`][ref-isdigit], στο εύρος 0..9
    - `isLetterOrDigit()`, συνδυάζει τις δύο προηγούμενες
    - [`isWhitespace()`][ref-iswhitespace], οποιονδήποτε χαρακτήρα κενού

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Μετατροπές μεταξύ λίστας `Char` και συμβολοσειράς

Για μετατροπή από συμβολοσειρά σε λίστα `Char`, μπορούμε να χρησιμοποιήσουμε τη `toList()`.

Για μετατροπή από λίστα `Char` σε συμβολοσειρά, υπάρχει η συνάρτηση [`joinToString()`][ref-jointostring], η οποία δέχεται έναν διαχωριστικό (συχνά τη συμβολοσειρά κενό) ως όρισμα.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Σημείωσε ότι η `joinToString()` λειτουργεί σε λίστα ή πίνακα.
Για να _μετατρέψεις_ έναν μεμονωμένο `Char` σε συμβολοσειρά ενός χαρακτήρα, χρησιμοποίησε τη `toString()`.

```kotlin
'a'.toString() // => "a"
```

Για να ελέγξεις αν ένας χαρακτήρας υπάρχει σε μια `String`, ή σε μια λίστα ή πίνακα `Char`, έχουμε το `in`, που αντιστοιχεί στη συνάρτηση [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
