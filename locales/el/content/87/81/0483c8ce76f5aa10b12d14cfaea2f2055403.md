# Προσθήκη στις οδηγίες

## Λέξεις

Η λέξη `find-fewest-coins ( coins target -- result )` επιστρέφει έναν πίνακα
με ονομαστικές αξίες κερμάτων, το άθροισμα των οποίων είναι `target`. Το
`coins` είναι ένα hash set (π.χ. `HS{ 1 5 10 25 }`)· χρησιμοποίησε τις λέξεις
του λεξιλογίου `sets` (`members`, `in?`, …) για να δουλέψεις μαζί του.

Όταν κανένας συνδυασμός από `coins` δεν μπορεί να σχηματίσει το `target`,
πέταξε ένα σφάλμα `cannot-make-change`.
