# Οδηγίες

Σε αυτήν την άσκηση θα επεξεργάζεσαι γραμμές καταγραφής.

Κάθε γραμμή καταγραφής είναι μια συμβολοσειρά με την εξής μορφή: `"[<LEVEL>]: <MESSAGE>"`.

Υπάρχουν τρία διαφορετικά επίπεδα καταγραφής:

- `INFO`
- `WARNING`
- `ERROR`

Έχεις τρεις εργασίες, καθεμία από τις οποίες θα παίρνει μια γραμμή καταγραφής και θα σου ζητάει να κάνεις κάτι με αυτήν.

## 1. Πάρε το μήνυμα από μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLine.Message()` ώστε να επιστρέφει το μήνυμα μιας γραμμής καταγραφής:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Οποιοδήποτε κενό διάστημα στην αρχή ή στο τέλος πρέπει να αφαιρείται:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Πάρε το επίπεδο καταγραφής από μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLine.LogLevel()` ώστε να επιστρέφει το επίπεδο καταγραφής μιας γραμμής καταγραφής, το οποίο θα πρέπει να επιστρέφεται με πεζά γράμματα:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Αναδιαμόρφωσε μια γραμμή καταγραφής

Υλοποίησε τη (_static_) μέθοδο `LogLine.Reformat()` που αναδιαμορφώνει τη γραμμή καταγραφής, βάζοντας πρώτα το μήνυμα και μετά το επίπεδο καταγραφής σε παρενθέσεις:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
