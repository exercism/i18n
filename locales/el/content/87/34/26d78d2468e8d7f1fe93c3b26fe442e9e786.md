# Ρύθμισε τα εργαλεία

Υπάρχουν τρία εργαλεία που αξίζει να προσαρμόσεις για το track σου:

- Ο **[Μετρητής Γραμμών Κώδικα](/docs/building/tooling/lines-of-code-counter)**: αυτό το εργαλείο έχει αναλάβει να μετράει τις γραμμές κώδικα για κάθε επανάληψη που υποβάλλεται.
- Ο **[Εξαγωγέας Αποσπασμάτων](/docs/building/tooling/snippet-extractor)**: αυτό το εργαλείο εξάγει ένα απόσπασμα για κάθε επανάληψη, το οποίο εμφανίζεται στον ιστότοπο.
- Το **[Exercism CLI](/docs/building/tooling/cli)**: αυτό το εργαλείο το χρησιμοποιούν οι μαθητές για να δουλέψουν σε ένα track τοπικά, στον δικό τους υπολογιστή.

```exercism/note
Ακόμα κι αν η προσαρμογή αυτών των εργαλείων είναι προαιρετική, θα κάνει την ενσωμάτωση του track σου στον ιστότοπο _πολύ_ καλύτερη.
Γι' αυτό σου συνιστούμε ανεπιφύλακτα να προσαρμόσεις και τα τρία εργαλεία.
```
