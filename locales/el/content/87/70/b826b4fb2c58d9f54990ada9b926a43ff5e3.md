# Οδηγίες

Είναι άλλη μια πολυάσχολη νύχτα στον σταθμό διαλογής της Αμβέρσας. Είσαι ο υπεύθυνος διαλογής της βάρδιας: τα εισερχόμενα φορτηγά βαγόνια πρέπει να ομαδοποιηθούν ξανά σε εξερχόμενα τρένα, οι συζεύξεις να επιθεωρηθούν, οι διαδρομές να χωριστούν στις διακλαδώσεις και τα πανομοιότυπα φορτία να ενωθούν για την τιμολόγηση.

Κάθε *βαγόνι* είναι μια συμβολοσειρά που ονομάζει αυτό που μεταφέρει: `"coal"`, `"timber"`, `"crates"` κτλ.

## 1. Σύζευξε βαγόνια σε τρένα

Όρισε τη συνάρτηση `couple` ώστε να παίρνει έναν πίνακα από βαγόνια και ένα μήκος `n`, και να επιστρέφει μη επικαλυπτόμενα τρένα των `n` βαγονιών το καθένα. Το τελευταίο τρένο μπορεί να είναι μικρότερο αν ο αριθμός δεν διαιρείται ακριβώς.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Ρίξε μια ματιά στις συζεύξεις

Όρισε τη συνάρτηση `peek-couplings` ώστε να παίρνει έναν πίνακα από βαγόνια και να επιστρέφει κάθε γειτονικό ζεύγος, ώστε ο επιθεωρητής να μπορεί να εξετάσει κάθε σύζευξη.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Χώρισε την αλυσίδα στις διακλαδώσεις

Όρισε τη συνάρτηση `split-at-junctions` ώστε να παίρνει έναν πίνακα από βαγόνια και έναν πίνακα από `junctions` (βαγόνια που σηματοδοτούν ένα σημείο διακοπής), και να επιστρέφει τα τμήματα ανάμεσα στα βαγόνια-διακλαδώσεις. Τα ίδια τα βαγόνια-διακλαδώσεις δεν διατηρούνται.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Ένωσε τα πανομοιότυπα φορτία

Όρισε τη συνάρτηση `coalesce-cargo` ώστε να παίρνει έναν πίνακα από βαγόνια και να ομαδοποιεί σε συνεχόμενες σειρές τα *διαδοχικά* βαγόνια που μεταφέρουν το ίδιο φορτίο.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
