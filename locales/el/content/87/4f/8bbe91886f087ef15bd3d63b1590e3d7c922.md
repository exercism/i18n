# Σχετικά με τις συμβολοσειρές

Μια [`string`][ref-string] στην Kotlin είναι μια αμετάβλητη ακολουθία χαρακτήρων Unicode.

Το [`Immutable`][wiki-immutable] σημαίνει ότι οποιαδήποτε πράξη σε μια συμβολοσειρά πρέπει να επιστρέφει μια νέα συμβολοσειρά: η αρχική συμβολοσειρά δεν μπορεί ποτέ να αλλάξει.

Το [`Unicode`][wiki-unicode] σημαίνει ότι τα περισσότερα συστήματα γραφής του κόσμου μπορούν να αναπαρασταθούν, αλλά (σε αντίθεση με παλαιότερες γλώσσες όπως η C) δεν υπάρχει αντιστοιχία 1:1 ανάμεσα σε χαρακτήρες και byte.
Αυτό θα το συζητήσουμε περαιτέρω στην έννοια [`Chars`][concept-chars].

Μια συμβολοσειρά περικλείεται από διπλά εισαγωγικά `" "`.

Κάποιοι χαρακτήρες χρειάζονται διαφυγή: `\\`, καθώς και οι συνήθεις μη εκτυπώσιμοι χαρακτήρες, όπως `\t` (στηλοθέτης) και `\n` (αλλαγή γραμμής).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Οι συμβολοσειρές πολλαπλών γραμμών περικλείονται από 3 διπλά εισαγωγικά και μπορούν να περιέχουν οποιοδήποτε κείμενο (χωρίς να χρειάζεται διαφυγή).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Χρησιμοποίησε το [trimIndent][trimIndent-doc] για να αφαιρέσεις την κοινή στοίχιση από τις γραμμές.
Αυτό είναι χρήσιμο για τη μορφοποίηση της συμβολοσειράς:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Εναλλακτικά, το [trimMargin][trimMargin-doc] σου επιτρέπει να ορίσεις έναν διαχωριστή.
Κάθε γραμμή στο `String` τότε ξεκινά μετά τον διαχωριστή.
Ο προεπιλεγμένος διαχωριστής είναι το `|`, αλλά μπορείς να ορίσεις διαφορετικό διαχωριστή ως παράμετρο.
Για παράδειγμα:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Οι συμβολοσειρές μπορούν να συνενωθούν με `+`, αλλά αυτό είναι καλύτερο να περιορίζεται σε σύντομες και απλές περιπτώσεις.
Υπάρχουν κι άλλες, συχνά καλύτερες επιλογές.

## Πρότυπα συμβολοσειρών

Τα [`Templates`][ref-templates] αναφέρονται σε αυτό που κάποιες άλλες γλώσσες ονομάζουν "παρεμβολή".

Αν μια συμβολοσειρά περιέχει ένα σύμβολο δολαρίου `$` που ακολουθείται από ένα αναγνωριστικό, ή περιέχει άγκιστρα (`{expression}`) γύρω από μια έκφραση, αυτά αντικαθίστανται από την τιμή ή το αποτέλεσμα της έκφρασης, αντίστοιχα.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Μορφοποίηση συμβολοσειρών

Στην πλατφόρμα JVM (μόνο εκεί), η `String.format()` επιτρέπει πιο ακριβή μορφοποίηση από τα πρότυπα συμβολοσειρών, με [σύνταξη][web-formats] παρόμοια με τις (_πανάρχαιες!_) συναρτήσεις [`printf`][wiki-printf].

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

~~~~exercism/advanced
Η Kotlin μπορεί να μεταγλωττιστεί για διάφορους διαφορετικούς στόχους: την Java Virtual Machine, τη JavaScript, εγγενή δυαδικά αρχεία για Linux, Windows, Android και Apple, καθώς και δύο παραλλαγές του WebAssembly.

Ουσιαστικά ο ίδιος κώδικας μπορεί να χρησιμοποιηθεί για τον καθένα, αλλά οι διαφορετικές δυνατότητες των πλατφορμών-στόχων σημαίνουν κάποιες διαφορές στο ποιες συναρτήσεις της πρότυπης βιβλιοθήκης υποστηρίζονται.

Το Exercism χρησιμοποιεί αυτή τη στιγμή την JVM για τις δοκιμές.

## Συναρτήσεις συμβολοσειρών

Η Kotlin παρέχει _πολλές_ [`functions`][ref-string-functions] για τον χειρισμό συμβολοσειρών.

Ως επί το πλείστον, αυτές είναι [`extensions functions`][ref-extensions] και όχι μέλη της κλάσης `String`, αν και αυτό έχει μικρή επίπτωση στον τρόπο που τις χρησιμοποιούμε.

~~~~exercism/note
Οι μάλλον περίπλοκες σελίδες [τεκμηρίωσης][ref-string-functions] της Kotlin κρύβουν τις συναρτήσεις επέκτασης στην προεπιλεγμένη προβολή.
Τη στιγμή που γράφεται αυτό, το πιο πολύτιμο περιεχόμενο είναι κρυμμένο σε μια καρτέλα με το όνομα `Members & Extensions`.
Κάνε κλικ πάνω της για να αναπτύξεις αυτή την ενότητα και να δεις όλα τα μέλη και τις επεκτάσεις που είναι διαθέσιμα στην κλάση `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Το παρακάτω παράδειγμα δείχνει μόνο μια μικρή επιλογή από όσα είναι διαθέσιμα:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Δημιουργία συμβολοσειράς

Μερικές φορές μια μεγάλη συμβολοσειρά πρέπει να χτιστεί σε στάδια, για παράδειγμα μέσα σε έναν βρόχο.

Η συνένωση συμβολοσειρών με `+` παύει γρήγορα να είναι κομψή ή αποδοτική: η αμεταβλητότητα σημαίνει ότι απαιτείται _πολλή_ αντιγραφή.

Η Kotlin έχει διάφορους πιο αποδοτικούς τρόπους για να συνδυάσεις πολλές συμβολοσειρές:

- Τα πρότυπα συμβολοσειρών, που περιγράφηκαν παραπάνω.
- [`joinToString()][ref-jointostring], που θα καλυφθεί στην έννοια [Λίστες][concept-lists].
- Το [`StringBuilder`][ref-stringbuilder] της Java, που δεν θεωρείται ιδιαίτερα ιδιωματικό για την Kotlin.
- Το [`buildString()`][ref-buildstring] της Kotlin, που τυλίγει το `StringBuilder` σε μια πιο συνοπτική και ιδιωματική σύνταξη.
Αυτό παίρνει τη λογική δημιουργίας συμβολοσειράς ως όρισμα lambda, που θα συζητηθεί σε μια επόμενη έννοια.

Στην ουσία, ένα `StringBuilder` είναι μια δομή σαν λίστα, με πολλές βολικές μεθόδους.
Μια μικρή επιλογή:

- [`append()`][ref-sb-append] για προσθήκη στο τέλος.
- [`insert()`][ref-sb-insert] για προσθήκη σε συγκεκριμένη θέση.
- [`deleteAt()`][ref-sb-deleteat] και [`deleteRange()`][ref-sb-deleterange] για αφαίρεση από συγκεκριμένες θέσεις.
- `toString()` για μετατροπή σε κανονική συμβολοσειρά στο τέλος: συνενώνει τα πάντα σε μία, αποδοτική πράξη.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Ένα παράδειγμα με `buildString()`, που χρησιμοποιεί σύνταξη από επόμενες έννοιες:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
