# Υποδείξεις

## 1. Όρισε τον εξωτερικό τύπο `GbTree`

- Οι εξωτερικοί τύποι μπορούν να οριστούν χρησιμοποιώντας τη σύνταξη `pub type TypeName(a, b, c)`.

## 2. Όρισε τη συνάρτηση `new_gb_tree`

- Οι εξωτερικές συναρτήσεις μπορούν να οριστούν χρησιμοποιώντας τη σύνταξη `@external(erlang, "module", "function")`.
- Η συνάρτηση θα πρέπει να χρησιμοποιεί το `gb_trees:empty/0`.

## 3. Όρισε τη συνάρτηση `insert`

- Έλεγξε την τεκμηρίωση του `gb_trees:insert/3` για να επιβεβαιώσεις τη σωστή σειρά των ορισμάτων.
- Η εξωτερική συνάρτηση μπορεί να είναι μια ιδιωτική συνάρτηση που καλείται από τη συνάρτηση `insert`, προκειμένου να αλλάξει η σειρά των ορισμάτων.
- Η συνάρτηση θα πρέπει να χρησιμοποιεί το `gb_trees:insert/3`.

## 4. Όρισε τη συνάρτηση `delete`

- Έλεγξε την τεκμηρίωση του `gb_trees:delete_any/2` για να επιβεβαιώσεις τη σωστή σειρά των ορισμάτων.
- Η εξωτερική συνάρτηση μπορεί να είναι μια ιδιωτική συνάρτηση που καλείται από τη συνάρτηση `delete`, προκειμένου να αλλάξει η σειρά των ορισμάτων.
- Η συνάρτηση θα πρέπει να χρησιμοποιεί το `gb_trees:delete_any/2`.
- Η συνάρτηση `gb_trees:delete/2` θα κρασάρει αν το κλειδί δεν βρεθεί, οπότε δεν θα πρέπει να χρησιμοποιηθεί.
