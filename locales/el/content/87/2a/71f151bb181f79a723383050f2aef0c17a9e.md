# Οδηγίες

Η νοσταλγία σου για τις κάρτες Blorkemon™️ δε λέει να κοπάσει, άρχισες μάλιστα να τις συλλέγεις ξανά και παροτρύνεις κιόλας τους φίλους σου να συμμετάσχουν.

Σε αυτή την άσκηση, μια συλλογή καρτών αναπαρίσταται με `Set(String)`, καθώς οι διπλότυπες κάρτες δεν έχουν σημασία όταν ο στόχος σου είναι να αποκτήσεις όλες τις υπάρχουσες κάρτες.

## 1. Ξεκίνα μια συλλογή

Θέλεις πραγματικά να μπουν και οι φίλοι σου στην τρέλα σου με τα Blorkemon™️, και ο καλύτερος τρόπος είναι να ξεκινήσεις τη συλλογή τους χαρίζοντάς τους μία κάρτα.

Υλοποίησε τη συνάρτηση `new_collection`, που μετατρέπει μια κάρτα σε συλλογή.

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. Μεγάλωσε τη συλλογή

Μόλις αποκτήσεις μια συλλογή, αποκτά δική της ζωή και πρέπει να μεγαλώσει.

Υλοποίησε τη συνάρτηση `add_card`, που παίρνει μια κάρτα και μια συλλογή και επιστρέφει μια πλειάδα με δύο τιμές: ένα `Bool` που δείχνει αν η κάρτα ήταν ήδη στη συλλογή, και τη συλλογή με την κάρτα να έχει προστεθεί.

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. Ξεκίνα τις ανταλλαγές

Τώρα που οι φίλοι σου έχουν ξανατρελαθεί με τα Blorkemon™️, μπορείς να το χρησιμοποιήσεις αυτό για να μεγαλώσεις τη δική σου συλλογή ανταλλάσσοντας κάρτες.

Δεν αξίζει να κάνεις κάθε ανταλλαγή, ούτε μπορούν να γίνουν όλες.
Δε μπορείς να ανταλλάξεις μια κάρτα που δεν έχεις, και δεν πρέπει να ανταλλάξεις μια κάρτα με μια που έχεις ήδη.

Υλοποίησε τη συνάρτηση `trade_card`, που παίρνει δύο κάρτες προς ανταλλαγή (τη δική σου και τη δική τους) και την τρέχουσα συλλογή σου.
Η τιμή επιστροφής είναι μια πλειάδα με δύο τιμές: ένα `Bool` που δηλώνει αν η ανταλλαγή είναι εφικτή και αξίζει να γίνει, και η συλλογή στην οποία θα κατέληγες αν έκανες την ανταλλαγή (ακόμα κι αν δεν είναι στην πραγματικότητα εφικτή).

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. Κάρτες που τις έχουν όλοι

Εσύ και οι φίλοι σου που λατρεύουν τα Blorkemon™️ μαζεύεστε και αναρωτιέστε ποιες κάρτες είναι οι πιο συνηθισμένες.

Υλοποίησε τη συνάρτηση `boring_cards`, που παίρνει μια λίστα με συλλογές και επιστρέφει μια λίστα με ταξινομημένες κάρτες που τις έχουν όλες οι συλλογές.

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. Όλες οι κάρτες

Έχετε εσύ και οι φίλοι σου μαζί όλες τις κάρτες Blorkemon™️;

Υλοποίησε τη συνάρτηση `total_cards`, που παίρνει μια λίστα με συλλογές και επιστρέφει τον συνολικό αριθμό διαφορετικών καρτών σε όλες τις συλλογές.

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. Shiny για τη νίκη

Ο ανιψιός σου έρχεται να σε επισκεφτεί σύντομα και θέλεις να τον εντυπωσιάσεις.
Στα παιδιά αρέσουν τα λαμπερά πράγματα, έτσι δεν είναι;
Οι κάρτες Blorkemon™️ μπορούν να είναι shiny!

Υλοποίησε τη συνάρτηση `shiny_cards`, που παίρνει μια συλλογή και επιστρέφει ένα σύνολο που περιέχει όλες τις κάρτες που αρχίζουν με `"Shiny "`.

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
