# Προσάρτημα οδηγιών

## Πλεονεκτήματα και μειονεκτήματα του `from_quote`
Αυτή η άσκηση ορίζει μια συνάρτηση `from_quote` στον τύπο `Time`. Έτσι μπορείς να γράψεις κώδικα σαν κι αυτόν:

```roc
time : Time
time = "00:01:23"
```

Αυτός ο κώδικας καλεί σιωπηρά το `Time.from_quote("00:01:23")` τη στιγμή της μεταγλώττισης. Αυτό μπορεί δυνητικά να επιταχύνει το πρόγραμμα, αφού δεν χρειάζεται να χειρίζεται την ανάλυση κατά την εκτέλεση, και διασφαλίζει ότι οι ώρες που απορρίπτονται από το `from_quote` πιάνονται τη στιγμή της μεταγλώττισης και όχι κατά την εκτέλεση. Επιπλέον, κάνει τον κώδικα ωραίο και ευανάγνωστο. Για παράδειγμα, να ένα από τα τεστ αυτής της άσκησης:

```roc
## start initiates time tracking for current lap
expect {
	result = Stopwatch.create()
		.start()?
		.advance_time("00:00:05")
		|> expect_current_lap("00:00:05")

	result.is_ok()
}
```

Ωστόσο, κάποιος που διαβάζει αυτόν τον κώδικα μπορεί να υποθέσει ότι η συνάρτηση `advance_time` δέχεται ένα `Str`, ενώ στην πραγματικότητα δέχεται ένα `Time`. Αυτό μπορεί να οδηγήσει σε σύγχυση και σφάλματα. Για αυτόν τον λόγο, μπορεί να προτιμήσεις τη λίγο μεγαλύτερη αλλά πιο ρητή μορφή: `"00:00:05".Time`, η οποία επίσης καλεί το `from_quote` τη στιγμή της μεταγλώττισης.

Στα δικά σου προγράμματα, μπορεί να προτιμήσεις να χρησιμοποιήσεις αντ' αυτού το `from_str`:

```roc
Time := { ... }.{
    from_str : time_str -> Try(Time, [InvalidTime])
    from_str = |time_str| ...
}
```

Μπορείς επίσης να καλέσεις το `from_str` (ή οποιαδήποτε άλλη καθαρή συνάρτηση) τη στιγμή της μεταγλώττισης, όπως εδώ:

```roc
Ok(time) = Time.from_str("00:01:23")
```

Σημείωση: Αν τοποθετήσεις αυτόν τον ορισμό στο ανώτατο επίπεδο, εκτελείται τη στιγμή της μεταγλώττισης (καθώς η συνάρτηση είναι καθαρή και η είσοδός της είναι γνωστή τη στιγμή της μεταγλώττισης). Μέσα σε μια συνάρτηση, μπορείς να χρησιμοποιήσεις το `from_str` κατά την εκτέλεση.
