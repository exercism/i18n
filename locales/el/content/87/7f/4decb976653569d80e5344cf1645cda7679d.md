# Υποδείξεις

## Γενικά

- Μια συνάρτηση μπορεί να οριστεί έτσι ώστε να δέχεται πολλά ορίσματα συσκευασμένα μαζί, χρησιμοποιώντας την παράμετρο `*args` για ορίσματα `list` και `tuple`, ή την παράμετρο `**kwargs` για ορίσματα λεξικού ή με λέξεις-κλειδιά.
- Για να συσκευάσεις ή να αποσυσκευάσεις, χρησιμοποίησε τον τελεστή `*` ή `**`.

## 1. Δημιούργησε μια λίστα με όλα τα βαγόνια

- Πολλά ορίσματα στις παραμέτρους μιας συνάρτησης μπορούν να συσκευαστούν με τον τελεστή `*args`.

## 2. Διόρθωσε τη λίστα με τα βαγόνια

- Χρησιμοποιώντας αποσυσκευασία με τον τελεστή `*`, μπορείς να εξαγάγεις τα δύο πρώτα στοιχεία μιας `list` κρατώντας τα υπόλοιπα άθικτα.
- Για να προσθέσεις μια άλλη `list` μέσα σε μια υπάρχουσα `list`, μπορείς να χρησιμοποιήσεις τον τελεστή `*` για να "απλώσεις" τη `list`.

## 3. Πρόσθεσε τις στάσεις που λείπουν

- Χρησιμοποιώντας το `**kwargs` ως παράμετρο συνάρτησης, μπορείς να περάσεις οποιονδήποτε αριθμό ορισμάτων με λέξεις-κλειδιά.
- Χρησιμοποιώντας το `**<dict>` ως όρισμα, αποσυσκευάζεις ένα λεξικό σε ορίσματα με λέξεις-κλειδιά.
- Μπορείς να βάλεις ορίσματα με λέξεις-κλειδιά μέσα σε `{}` ή `dict()`.
- Για να βγάλεις τις τιμές από ένα λεξικό, μπορείς να χρησιμοποιήσεις τη μέθοδο `<dict>.values()`.

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

- Χρησιμοποιώντας το `**<dict>` ως όρισμα, αποσυσκευάζεις ένα λεξικό σε ορίσματα με λέξεις-κλειδιά.
- Μπορείς να βάλεις ορίσματα με λέξεις-κλειδιά μέσα σε `{}` ή `dict()`.

## 5. Διόρθωσε το αμαξοστάσιο

- Το `zip(*iterators)` μπορεί να χρησιμοποιηθεί για να μεταθέσεις μια εμφωλευμένη `list`.
- Για να εξαγάγεις δεδομένα από επαναλήπτες που έχουν περάσει από `zip()`, μπορείς να χρησιμοποιήσεις έναν `for` βρόχο.
- Μπορείς επίσης να αποσυσκευάσεις επαναλήπτες που έχουν περάσει από `zip()` χρησιμοποιώντας το `*`.
  Το `[*content] = zip(iterator_1, iterator_2)` θα αποσυσκευάσει το `tuple` που παράγει το `zip()` σε μια `list`.
