# Εισαγωγή

Η `List` μοιάζει πολύ με τον `Array`. Ωστόσο, υπάρχουν σημαντικές διαφορές που δεν θέλεις να προσπεράσεις:

1. Δεν μπορείς να προσπελάσεις μια λίστα με θέση χρησιμοποιώντας αγκύλες, δηλαδή `[0]`.
2. Δεν μπορείς να αρχικοποιήσεις μια λίστα.
3. Δεν υπάρχουν list comprehensions.
4. Μια λίστα μπορεί να τροποποιεί ελεύθερα τα στοιχεία της ενώ τα διατρέχεις.

Η `List` είναι μέλος του πακέτου `haxe.ds`, οπότε κάθε φορά που θέλεις να χρησιμοποιήσεις λίστες, πρέπει να εισάγεις το πακέτο της:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
