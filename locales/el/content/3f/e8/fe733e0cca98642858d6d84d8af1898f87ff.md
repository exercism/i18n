# Υποδείξεις

## 1. Περιγραφή απλών αριθμών

- χρησιμοποίησε τη `fmt.Sprintf` για μορφοποίηση

## 2. Περιγραφή ενός κουτιού αριθμού

- πάρε το αποτέλεσμα από τη μέθοδο `Number()`
- χρησιμοποίησε τη `fmt.Sprintf` για μορφοποίηση

## 3. Υλοποίηση μιας μεθόδου που εξάγει τον αριθμό από ένα φανταχτερό κουτί αριθμού

- χρησιμοποίησε ένα type assertion για να ελέγξεις αν αυτό είναι ένα `FancyNumber`
- πάρε το `string` από τη μέθοδο `Value()`
- χρησιμοποίησε τη `strconv.Atoi` για να μετατρέψεις το `string` σε `int` (μπορούμε να αγνοήσουμε το σφάλμα, αφού θέλουμε 0 αν δεν μπορεί να μετατραπεί σε `int`)

## 4. Περιγραφή ενός φανταχτερού κουτιού αριθμού

- χρησιμοποίησε τη `ExtractFancyNumber` για να πάρεις την τιμή `int`
- μετέτρεψε το `int` σε `float64`
- χρησιμοποίησε τη `fmt.Sprintf` για μορφοποίηση

## 5. Υλοποίηση της `DescribeAnything` που τις χρησιμοποιεί όλες

- χρησιμοποίησε είτε type assertions (π.χ. `i.(someType)`) είτε ένα type switch (`switch v := i.(type)`)
- θυμήσου να μετατρέψεις το `int` σε `float64`
