# Εισαγωγή

Όπως πολλές άλλες γλώσσες προγραμματισμού, έτσι και η Go έχει δείκτες.
Αν έρχεσαι πρώτη φορά σε επαφή με τους δείκτες, μπορεί να σου φανούν λίγο μυστηριώδεις, αλλά μόλις τους συνηθίσεις είναι αρκετά απλοί.
Είναι κρίσιμο κομμάτι της Go, οπότε αφιέρωσε λίγο χρόνο για να τους καταλάβεις πραγματικά.

Πριν μπούμε στις λεπτομέρειες, αξίζει να καταλάβεις τη χρήση των δεικτών.
Οι δείκτες είναι ένας τρόπος να μοιραζόμαστε μνήμη με άλλα μέρη του προγράμματός μας, κάτι που είναι χρήσιμο για δύο βασικούς λόγους:

1. Όταν έχουμε μεγάλο όγκο δεδομένων, το να φτιάχνουμε αντίγραφα για να τα περνάμε από συνάρτηση σε συνάρτηση είναι πολύ αναποτελεσματικό.
   Περνώντας αντ' αυτού τη διεύθυνση μνήμης όπου είναι αποθηκευμένα τα δεδομένα, μπορούμε να μειώσουμε δραστικά το αποτύπωμα πόρων των προγραμμάτων μας.
2. Περνώντας δείκτες από συνάρτηση σε συνάρτηση, μπορούμε να έχουμε πρόσβαση και να τροποποιούμε απευθείας το μοναδικό αντίγραφο των δεδομένων, που σημαίνει ότι οποιαδήποτε αλλαγή κάνει μια συνάρτηση είναι αμέσως ορατή στα υπόλοιπα μέρη του προγράμματος μόλις τελειώσει η συνάρτηση.

## Μεταβλητές και μνήμη

Ας πούμε ότι έχουμε μια συνηθισμένη ακέραια μεταβλητή `a`:

```go
var a int
```

Όταν δηλώνουμε μια μεταβλητή, η Go πρέπει να βρει ένα μέρος στη μνήμη για να αποθηκεύσει την τιμή της.
Αυτό είναι σε μεγάλο βαθμό αφηρημένο για εμάς. Όταν χρειάζεται να πάρουμε την τιμή που είναι αποθηκευμένη σε εκείνο το κομμάτι μνήμης, αρκεί να αναφερθούμε σε αυτήν με το όνομα της μεταβλητής.

Για παράδειγμα, όταν γράφουμε `a + 2`, στην ουσία παίρνουμε την τιμή που είναι αποθηκευμένη στη μνήμη που αντιστοιχεί στη μεταβλητή `a` και προσθέτουμε 2 σε αυτή.

Παρομοίως, όταν χρειάζεται να αλλάξουμε την τιμή στο κομμάτι μνήμης του `a`, μπορούμε να χρησιμοποιήσουμε το όνομα της μεταβλητής για να κάνουμε μια εκχώρηση:

```go
a = 3
```

Το κομμάτι μνήμης που αντιστοιχεί στο `a` θα αποθηκεύει πλέον την τιμή `3`.

## Δείκτες

Ενώ οι μεταβλητές μάς επιτρέπουν να αναφερόμαστε σε τιμές στη μνήμη, μερικές φορές είναι χρήσιμο να ξέρουμε τη **διεύθυνση μνήμης** στην οποία δείχνει η μεταβλητή.
Οι **δείκτες** κρατούν τις διευθύνσεις μνήμης αυτών των τιμών.
Δηλώνεις μια μεταβλητή με τύπο δείκτη βάζοντας έναν αστερίσκο μπροστά από τον υποκείμενο τύπο:

```go
var p *int // 'p' contains the memory address of an integer
```

Εδώ δηλώνουμε μια μεταβλητή `p` τύπου "δείκτης σε int" (`*int`).
Αυτό σημαίνει ότι το `p` θα κρατά τη διεύθυνση μνήμης ενός ακέραιου.
Η μηδενική τιμή των δεικτών είναι `nil`, γιατί ένας δείκτης `nil` δεν κρατά καμία διεύθυνση μνήμης.

### Πώς παίρνεις έναν δείκτη σε μια μεταβλητή

Για να βρεις τη διεύθυνση μνήμης της τιμής μιας μεταβλητής, μπορείς να χρησιμοποιήσεις τον τελεστή `&`.
Για παράδειγμα, αν θέλουμε να βρούμε και να αποθηκεύσουμε τη διεύθυνση μνήμης της μεταβλητής `a` στον δείκτη `p`, μπορούμε να κάνουμε το εξής:

```go
var a int
a = 2

var p *int
p = &a // the variable 'p' contains the memory address of 'a'
```

### Πρόσβαση στην τιμή μέσω δείκτη (αποαναφορά)

Όταν έχουμε έναν δείκτη, μπορεί να θέλουμε να μάθουμε την τιμή που είναι αποθηκευμένη στη διεύθυνση μνήμης που αντιπροσωπεύει ο δείκτης.
Μπορούμε να το κάνουμε αυτό με τον τελεστή `*`:

```go
var a int
a = 2

var p *int
p = &a // the variable 'p' contains the memory address of 'a'

var b int
b = *p // b == 2
```

Η πράξη `*p` παίρνει την τιμή που είναι αποθηκευμένη στη διεύθυνση μνήμης που κρατά το `p`.
Αυτή η πράξη ονομάζεται συχνά "αποαναφορά".

Μπορούμε επίσης να χρησιμοποιήσουμε τον τελεστή αποαναφοράς για να εκχωρήσουμε μια νέα τιμή στη διεύθυνση μνήμης στην οποία αναφέρεται ο δείκτης:

```go
var a int        // declare int variable 'a'
a = 2            // assign 'a' the value of 2

var pa *int
pa = &a          // 'pa' now contains to the memory address of 'a'
*pa = *pa + 2    // increment by 2 the value at memory address 'pa'

fmt.Println(a)   // Output: 4
                 // 'a' will have the new value that was changed via the pointer!
```

Η εκχώρηση στο `*pa` θα αλλάξει την τιμή που είναι αποθηκευμένη στη διεύθυνση μνήμης που κρατά το `pa`.
Εφόσον το `pa` κρατά τη διεύθυνση μνήμης του `a`, εκχωρώντας στο `*pa` αλλάζουμε στην ουσία την τιμή του `a`!

Μια προειδοποίηση όμως: να ελέγχεις πάντα αν ένας δείκτης δεν είναι `nil` πριν κάνεις αποαναφορά.
Η αποαναφορά ενός δείκτη `nil` θα κάνει το πρόγραμμα να καταρρεύσει κατά την εκτέλεση!

```go
var p *int // p is nil initially
fmt.Println(*p)
// panic: runtime error: invalid memory address or nil pointer dereference
```

### Δείκτες σε struct

Μέχρι τώρα έχουμε δει μόνο δείκτες σε πρωτογενείς τιμές.
Μπορούμε επίσης να δημιουργήσουμε δείκτες για struct:

```go
type Person struct {
    Name string
    Age  int
}

var peter Person
peter = Person{Name: "Peter", Age: 22}

var p *Person
p = &peter
```

Θα μπορούσαμε επίσης να δημιουργήσουμε ένα νέο `Person` και να αποθηκεύσουμε αμέσως έναν δείκτη σε αυτό:

```go
var p *Person
p = &Person{Name: "Peter", Age: 22}
```

Όταν έχουμε έναν δείκτη σε struct, δε χρειάζεται να κάνουμε αποαναφορά του δείκτη πριν αποκτήσουμε πρόσβαση σε ένα από τα πεδία του:

```go
var p *Person
p = &Person{Name: "Peter", Age: 22}

fmt.Println(p.Name) // Output: "Peter"
                    // Go automatically dereferences 'p' to allow
                    // access to the 'Name' field
```

## Τα slices και τα maps είναι ήδη δείκτες

Τα slices και τα maps είναι ειδικοί τύποι, γιατί στην υλοποίησή τους έχουν ήδη δείκτες.
Αυτό σημαίνει ότι τις περισσότερες φορές δε χρειάζεται να δημιουργήσουμε δείκτες για αυτούς τους τύπους προκειμένου να μοιραστούμε τη διεύθυνση μνήμης των τιμών τους.
Φαντάσου ότι έχουμε μια συνάρτηση που αυξάνει την τιμή ενός κλειδιού σε ένα map:

```go
func incrementPeterAge(m map[string]int) {
	m["Peter"] += 1
}
```

Αν δημιουργήσουμε ένα map και καλέσουμε αυτή τη συνάρτηση, οι αλλαγές που έκανε η συνάρτηση στο map παραμένουν και αφού τελειώσει η συνάρτηση.
Αυτή είναι μια συμπεριφορά παρόμοια με αυτή που θα είχαμε αν χρησιμοποιούσαμε δείκτη, αλλά πρόσεξε ότι σε αυτό το παράδειγμα δε χρησιμοποιούμε καμία αναφορά ή αποαναφορά ούτε καθόλου σύνταξη δεικτών:

```go
ages := map[string]int{
  "Peter": 21
}
incrementPeterAge(ages)
fmt.Println(ages)
// Output: map[Peter:22]
// The changes the function 'incrementPeterAge' made to the map are visible after the function ends!
```

Το ίδιο ισχύει όταν αλλάζουμε ένα υπάρχον στοιχείο σε ένα slice.

Ωστόσο, πράξεις που επιστρέφουν ένα νέο slice, όπως η `append`, αποτελούν ειδική περίπτωση και **μπορεί να μην** τροποποιήσουν το slice έξω από τη συνάρτηση.
Αυτό οφείλεται στον τρόπο με τον οποίο λειτουργούν εσωτερικά τα slices, αλλά δε θα το καλύψουμε αναλυτικά, καθώς είναι ένα πιο προχωρημένο θέμα.
Αν είσαι πραγματικά περίεργος, μπορείς να διαβάσεις περισσότερα για αυτό στο [Go Blog: Mechanics of 'append'][mechanics-of-append]

[mechanics-of-append]: https://go.dev/blog/slices
