# Οδηγίες

Η ιδιοκτήτρια της τοπικής σου πιτσαρίας ζήτησε τη βοήθειά σου για να υπολογίσει τους χρόνους ψησίματος για διάφορες πίτσες. Σε αυτή την άσκηση θα γράψεις μερικές συναρτήσεις για να τους υπολογίσεις.

Έχεις τρεις εργασίες.

## 1. Υπολόγισε τον χρόνο ψησίματος που απομένει σε λεπτά

Όρισε και υλοποίησε τη συνάρτηση `remainingMinutesInOven()` που θα υπολογίζει πόσα ακόμα λεπτά χρειάζεται να κρατήσεις την πίτσα στον φούρνο.

Η συνάρτηση θα πρέπει να δέχεται μία **προαιρετική** παράμετρο (με προεπιλεγμένη τιμή) για τον αριθμό των λεπτών που πέρασαν από τότε που ξεκίνησες να ψήνεις την πίτσα. Αν η παράμετρος λείπει, υπέθεσε ότι μόλις έβαλες την πίτσα στον φούρνο και ότι έχουν περάσει ήδη **0 (μηδέν)** λεπτά.

Για απλότητα, ας υποθέσουμε ότι όλα τα είδη πίτσας χρειάζονται ακριβώς 40 λεπτά στον φούρνο για να είναι έτοιμα.

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. Υπολόγισε τον χρόνο προετοιμασίας σε λεπτά

Πριν ψήσεις την πίτσα, πρέπει να ετοιμάσεις τη ζύμη, να την ανοίξεις και να βάλεις τα υλικά από πάνω.

Όρισε και υλοποίησε τη συνάρτηση `preparationTimeInMinutes()` που θα υπολογίζει πόσα λεπτά χρειάζονται για να ετοιμαστεί η πίτσα πριν μπει στον φούρνο.

Η συνάρτηση θα πρέπει να δέχεται μία **υποχρεωτική** παράμετρο (`numberOfIngredientTypes`) για τον αριθμό των ειδών υλικών επικάλυψης που θα χρησιμοποιηθούν.

Υπέθεσε ότι χρειάζεσαι 5 λεπτά για να φτιάξεις και να ανοίξεις τη ζύμη και 2 λεπτά για **κάθε** είδος υλικού επικάλυψης.

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. Υπολόγισε τον χρόνο που έχει περάσει σε λεπτά

Όρισε και υλοποίησε τη συνάρτηση `elapsedCookingTimeInMinutes()` που θα υπολογίζει πόσα λεπτά χρειάζονται για να ετοιμαστεί, να ψηθεί και να σερβιριστεί η πίτσα. Χρησιμοποίησε τις συναρτήσεις από τα προηγούμενα βήματα για τους υπολογισμούς.

Η συνάρτηση θα πρέπει να δέχεται δύο παραμέτρους. Η πρώτη είναι **υποχρεωτική** και είναι ο αριθμός των ειδών υλικών επικάλυψης. Η δεύτερη είναι **προαιρετική** και είναι ο χρόνος σερβιρίσματος σε λεπτά (υπέθεσε ότι είναι 0 αν δεν δοθεί).

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
