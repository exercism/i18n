# Εισαγωγή

## Ανώνυμες συναρτήσεις

Οι συναρτήσεις αντιμετωπίζονται ως πολίτες πρώτης κατηγορίας στην Elixir. Αυτό σημαίνει ότι:

- Οι επώνυμες και ανώνυμες συναρτήσεις μπορούν να ανατεθούν σε μεταβλητές.
- Οι επώνυμες και ανώνυμες συναρτήσεις μπορούν να περνούν σαν δεδομένα, ως ορίσματα και τιμές επιστροφής.
- Οι ανώνυμες συναρτήσεις μπορούν να δημιουργηθούν δυναμικά.

Οι ανώνυμες συναρτήσεις, σε αντίθεση με τις επώνυμες, δεν έχουν κάποια στατική αναφορά διαθέσιμη σε αυτές, είναι διαθέσιμες μόνο αν ανατεθούν σε μια μεταβλητή ή κληθούν άμεσα.

Μπορεί να χρησιμοποιήσουμε ανώνυμες συναρτήσεις για να:

- Κρύψουμε δεδομένα χρησιμοποιώντας λεξιλογικό πεδίο (γνωστό και ως closure).
- Δημιουργήσουμε δυναμικά συναρτήσεις κατά την εκτέλεση.

Οι ανώνυμες συναρτήσεις ξεκινούν με τη δεσμευμένη λέξη `fn`, τα ορίσματα χωρίζονται από το σώμα της συνάρτησης με το σύμβολο `->` και τελειώνουν με ένα `end`. Όπως και με τις επώνυμες συναρτήσεις, η τελευταία έκφραση μέσα στη συνάρτηση _επιστρέφεται έμμεσα_ στη συνάρτηση που την κάλεσε.

Για να καλέσεις μια αναφορά συνάρτησης, πρέπει να βάλεις μια `.` ανάμεσα στη μεταβλητή αναφοράς και τη λίστα των ορισμάτων:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Μπορείς μάλιστα να χρησιμοποιήσεις τη συντομευμένη σημειογραφία σύλληψης για να γίνει ακόμη πιο σύντομο:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```

## Χειρισμός bit

Η Elixir υποστηρίζει πολλές συναρτήσεις για εργασία με bit, που βρίσκονται στο _άρθρωμα Bitwise_.

- `band/2`: bitwise AND
- `bsl/2`: bitwise SHIFT LEFT
- `bsr/2`: bitwise SHIFT RIGHT
- `bxor/2`: bitwise XOR
- `bor/2`: bitwise OR
- `bnot/1`: bitwise NOT

Ορίστε ένα παράδειγμα για το πώς να χρησιμοποιήσεις μια συνάρτηση bitwise:

```elixir
Bitwise.bsl(1, 3)
# => 8
```

Όλες οι συναρτήσεις bitwise λειτουργούν μόνο με ακέραιους αριθμούς.

Αν τρέχεις την έκδοση 1.9 της Elixir ή παλαιότερη, θα χρειαστεί να καλέσεις το `require Bitwise` στην αρχή του ορισμού του αρθρώματος για να μπορείς να χρησιμοποιήσεις το _άρθρωμα Bitwise_.
