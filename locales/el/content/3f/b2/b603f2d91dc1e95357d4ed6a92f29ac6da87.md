# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, χρειάζεται να υλοποιήσεις τη συνάρτηση `slices`, που παίρνει ένα *κείμενο* και επιστρέφει τις υπακολουθίες ψηφίων με συγκεκριμένο μέγεθος:

Αν λύνεις αυτή την άσκηση για πρώτη φορά, καλό είναι να μείνεις στην υπογραφή που σου δίνεται:

```haskell
slices :: Int -> String -> [[Int]]
```

Αργότερα, μπορεί να είναι καλή ιδέα να ξαναδείς αυτό το πρόβλημα και να πειραματιστείς με άλλους τύπους δεδομένων και βιβλιοθήκες:

- `ByteString`, από το πακέτο *bytestring*.
- `Sequence`, από το πακέτο *containers*.
- `Text`, από το πακέτο *text*.
- `Vector`, από το πακέτο *vector*.

Η σουίτα δοκιμών σχεδιάστηκε επίτηδες ώστε να δέχεται σχεδόν οποιαδήποτε υπογραφή τύπου έχει νόημα, οπότε σε ενθαρρύνουμε να βρεις αυτή που πιστεύεις ότι είναι η καλύτερη.
