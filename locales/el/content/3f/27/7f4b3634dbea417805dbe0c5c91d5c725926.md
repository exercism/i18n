# Προσθήκη οδηγιών

## Υποδείξεις

Αυτή η άσκηση απαιτεί να επεξεργαστείς μια συλλογή δεδομένων.
Μπορείς να απλοποιήσεις τον κώδικά σου χρησιμοποιώντας LINQ (ενσωματωμένο ερώτημα γλώσσας).
Για περισσότερες πληροφορίες, δες [χρήση του LINQ][using linq].
