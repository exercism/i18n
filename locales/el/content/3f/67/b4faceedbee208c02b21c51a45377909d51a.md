# Υποδείξεις

## Γενικά

- [Υπερφόρτωση μεθόδων στη Java][method-overloading].
- Η [συνένωση συμβολοσειρών][string-concatenation] μπορεί να χρησιμοποιηθεί για τη δημιουργία συμβολοσειρών περιγραφής.

## 3. Περιέγραψε τη μέθοδο ταξιδιού

- Μια [απλή συνθήκη][if-statement] μπορεί να χρησιμοποιηθεί για τη λογική με συνθήκες.

## 4. Περιέγραψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό

- Μπορείς να ξαναχρησιμοποιήσεις την υπάρχουσα λειτουργικότητα περιγραφής.
- Μπορείς να καλέσεις μεθόδους απευθείας στα μέρη μιας συνένωσης συμβολοσειρών ή μιας μορφοποίησης συμβολοσειρών.

## 5. Περιέγραψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό χωρίς να προσδιορίζεις τη μέθοδο ταξιδιού

- Μπορείς να ξαναχρησιμοποιήσεις την υπάρχουσα λειτουργικότητα που δέχεται ρητά μια μέθοδο ταξιδιού.
