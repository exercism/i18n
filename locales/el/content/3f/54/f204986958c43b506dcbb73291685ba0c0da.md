# Εισαγωγή

## Παράμετροι

Αυτή η άσκηση πραγματεύεται μερικές λεπτομέρειες των παραμέτρων μεθόδου και τη χρήση τους στη C#.

Οι παράμετροι μεταφέρουν πληροφορίες από τη μέθοδο που καλεί στη μέθοδο που καλείται.

- Η συμπεριφορά των παραμέτρων μπορεί να τροποποιηθεί με τη χρήση τροποποιητών όπως `ref` και `out`.

- Μια παράμετρος με τον τροποποιητή `out` μεταφέρει μια τιμή πίσω από την καλούμενη μέθοδο στον καλούντα. Η παράμετρος μπορεί να περαστεί στην καλούμενη μέθοδο χωρίς να έχει αρχικοποιηθεί, και σε κάθε περίπτωση αντιμετωπίζεται μέσα στην καλούμενη μέθοδο σαν να μην είχε αρχικοποιηθεί κατά την είσοδο. Η κατανόηση της συμπεριφοράς και των κανόνων που αφορούν τους τροποποιητές παραμέτρων αποκτάται πιο εύκολα μέσα από παραδείγματα (δες παρακάτω) και μηνύματα του μεταγλωττιστή.

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- Στις παραμέτρους `out` πρέπει να εκχωρηθεί τιμή μέσα στην καλούμενη μέθοδο.

- Μια παράμετρος με τον τροποποιητή `ref` περνά μια τιμή μέσα σε μια καλούμενη μέθοδο. Όταν η μέθοδος επιστρέψει, ο καλών θα βρει στην παράμετρο αυτή όποιες αλλαγές έχει κάνει η καλούμενη μέθοδος.

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- Οι παράμετροι `ref` πρέπει να είναι μεταβλητές, καθώς η καλούμενη μέθοδος θα λειτουργεί απευθείας πάνω στην παράμετρο όπως τη βλέπει ο καλών.
- Οι τροποποιητές `out` και `ref` απαιτούνται και στην υπογραφή της καλούμενης μεθόδου και στο σημείο κλήσης.
