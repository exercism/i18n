# Υποδείξεις

## Γενικά

- Το [πακέτο strings][strings-package] περιέχει πολλές χρήσιμες συναρτήσεις για `string`.
- Το πακέτο `strings` πρέπει να εισαχθεί πριν χρησιμοποιηθεί.
- Για να καλέσεις συναρτήσεις του πακέτου `strings`, γράψε μπροστά τους το πρόθεμα `strings.`.

## 1. Δημιούργησε το μήνυμα καλωσορίσματος

- Οι συμβολοσειρές μπορούν να συνενωθούν με τον τελεστή `+`.
- Υπάρχει μια συνάρτηση για να [μετατρέψεις μια `string` σε κεφαλαία][to-upper].

## 2. Πρόσθεσε ένα διακοσμητικό περίγραμμα

- Υπάρχει μια συνάρτηση για να [δημιουργήσεις μια `string` όπου ένας συγκεκριμένος χαρακτήρας επαναλαμβάνεται έναν αριθμό φορών][repeat].
- Ο χαρακτήρας αλλαγής γραμμής είναι ένας ειδικός [χαρακτήρας διαφυγής][escape-characters].

## 3. Καθάρισε τα παλιά διαφημιστικά μηνύματα

- Υπάρχει μια συνάρτηση για να [αντικαταστήσεις συμβολοσειρές μέσα σε μια `string`][replace-all].
- Υπάρχει μια συνάρτηση για να [αφαιρέσεις τα κενά στην αρχή και στο τέλος μιας `string`][trim-space].
