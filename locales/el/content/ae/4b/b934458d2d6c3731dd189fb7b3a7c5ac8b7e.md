# Εισαγωγή

Οι εντολές υπό συνθήκη στη C++ μοιάζουν με τις αντίστοιχες εντολές σε άλλες γλώσσες.
Ο υποκείμενος τύπος οποιασδήποτε πράξης υπό συνθήκη είναι ο τύπος `bool`, ο οποίος μπορεί να έχει την τιμή `true` ή `false`.
Οι εντολές υπό συνθήκη χρησιμοποιούνται συχνά ως μηχανισμοί ελέγχου ροής για τον έλεγχο διαφόρων συνθηκών.

Μπορείς να χρησιμοποιήσεις μια εντολή `if`, η οποία εκτελεί τον κώδικά της αν η συνθήκη είναι `true`, όπως εδώ:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

Σε περιπτώσεις με περισσότερες από μία συνθήκες, πολλές εντολές `if` μπορούν να συνδεθούν μεταξύ τους σε αλυσίδα χρησιμοποιώντας τις εντολές `else if` και `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Από τη C++17 και μετά, οι εντολές if μπορούν να περιλαμβάνουν και μια σύντομη εντολή αρχικοποίησης, η οποία μπορεί να χρησιμοποιηθεί για την αρχικοποίηση μίας ή περισσότερων μεταβλητών για την εντολή if.
Για παράδειγμα:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Σημείωση: οι μεταβλητές που δημιουργούνται στην αρχικοποίηση δεν είναι προσβάσιμες μετά το τέλος της εντολής if.
