# Οδηγίες

Σε αυτή την άσκηση, θα διαχειριστείς ένα σύστημα αποθέματος.

Το απόθεμα θα πρέπει να είναι οργανωμένο με βάση το όνομα του αντικειμένου και να παρακολουθεί τον αριθμό των διαθέσιμων αντικειμένων.

Θα χρειαστεί να χειριστείς την προσθήκη αντικειμένων σε ένα απόθεμα.
Κάθε φορά που ένα αντικείμενο εμφανίζεται σε ένα δεδομένο διάνυσμα, η ποσότητα του αντικειμένου θα πρέπει να αυξάνεται κατά `1` στο απόθεμα.
Θα χρειαστεί επίσης να χειριστείς τη διαγραφή αντικειμένων από ένα απόθεμα μειώνοντας τις ποσότητες κατά `1` όταν σου ζητείται.

Τέλος, θα χρειαστεί να υλοποιήσεις μια συνάρτηση που θα επιστρέφει όλα τα ζεύγη κλειδιού-τιμής σε ένα δεδομένο απόθεμα ως `vector` από `pair`s.

~~~~exercism/note
Οι δοκιμές σε αυτή την άσκηση είναι ανεξάρτητες από τη μετάλλαξη, αλλά τα ονόματα των συναρτήσεων υποδεικνύουν ότι δεν θα πρέπει να μεταλλάσσουν.
Αν θέλεις να χρησιμοποιήσεις συναρτήσεις από την εισαγωγή χωρίς να μεταλλάσσεις την είσοδο, η συνάρτηση `copy()` θα σου φανεί χρήσιμη.
~~~~

## 1. Δημιούργησε ένα απόθεμα με βάση ένα διάνυσμα

Υλοποίησε τη συνάρτηση `create_inventory(<input vector>)` που δημιουργεί ένα "απόθεμα" από ένα διάνυσμα εισόδου με αντικείμενα.
Θα πρέπει να επιστρέφει ένα `dict` που περιέχει κάθε όνομα αντικειμένου μαζί με την αντίστοιχη ποσότητά του.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Πρόσθεσε αντικείμενα από ένα διάνυσμα σε ένα υπάρχον λεξικό

Υλοποίησε τη συνάρτηση `add_items(<inventory dict>, <item vector>)` που προσθέτει ένα διάνυσμα αντικειμένων στο απόθεμα που της περνάς:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Μείωσε τις ποσότητες των αντικειμένων στο απόθεμα

Υλοποίησε τη συνάρτηση `decrement_items(<inventory dict>, <items vector>)` που παίρνει ένα `vector` από αντικείμενα.
Η συνάρτησή σου θα πρέπει να αφαιρεί `1` από τον αριθμό ενός αντικειμένου για κάθε φορά που αυτό το αντικείμενο εμφανίζεται στο `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

Οι ποσότητες των αντικειμένων στο απόθεμα δεν θα πρέπει να επιτρέπεται να πέσουν κάτω από το 0.
Αν ο αριθμός των φορών που ένα αντικείμενο εμφανίζεται στο `vector` εισόδου υπερβαίνει τη διαθέσιμη ποσότητα, η ποσότητα που καταγράφεται για αυτό το αντικείμενο θα πρέπει να παραμένει στο 0.
Επιπλέον αιτήματα αφαίρεσης ποσοτήτων θα πρέπει να αγνοούνται μόλις η ποσότητα πέσει στο μηδέν.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Αφαίρεσε εντελώς μια καταχώριση από το απόθεμα

Υλοποίησε τη συνάρτηση `remove_item(<inventory dict>, <item>)` που αφαιρεί ένα αντικείμενο και την ποσότητά του εντελώς από ένα απόθεμα:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Αν το αντικείμενο δεν βρεθεί στο απόθεμα, η συνάρτηση θα πρέπει να επιστρέφει το αρχικό απόθεμα αμετάβλητο.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Επίστρεψε ολόκληρο το περιεχόμενο του αποθέματος

Υλοποίησε τη συνάρτηση `list_inventory(<inventory dict>)` που παίρνει ένα απόθεμα και επιστρέφει ένα διάνυσμα από ζεύγη `(item, quantity)`.

Το διάνυσμα θα πρέπει να περιλαμβάνει μόνο τα _διαθέσιμα_ αντικείμενα (_με ποσότητα μεγαλύτερη από το μηδέν_) και θα πρέπει να είναι ταξινομημένο σε αλφαβητική σειρά των αντικειμένων:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
