[Τα Boolean (λογική τιμή)][booleans] στη Haxe αναπαρίστανται από τον τύπο `Bool`, του οποίου οι τιμές μπορούν να είναι είτε `true` είτε `false`.

Η Haxe υποστηρίζει τρεις [λογικούς τελεστές][operators]: `!` (μοναδιαίο NOT), `&&` (δυαδικό AND) και `||` (δυαδικό OR)

Οι σύνθετες λογικές εκφράσεις (`&&` και `||`) χρησιμοποιούν αξιολόγηση _βραχυκυκλώματος_, όπου οι εκφράσεις αξιολογούνται από αριστερά προς τα δεξιά, αλλά μόνο όσο χρειάζεται. Αυτό έχει σημασία σε περιπτώσεις όπως η παρακάτω:

```haxe
object != null && object.field == x
```

Ο πρώτος λογικός έλεγχος διασφαλίζει ότι το `object.field` προσπελάζεται μόνο αν το `object` δεν είναι `null`, προστατεύοντας από ένα σφάλμα χρόνου εκτέλεσης.

Οι τρεις λογικοί τελεστές έχουν διαφορετική [προτεραιότητα][precedence] και αξιολογούνται με αυτή τη σειρά: `!` -> `&&` -> `||`.

Η περικύκλωση εκφράσεων σε παρενθέσεις `()` επιτρέπει την παράκαμψη αυτών των κανόνων προτεραιότητας, καθώς οι παρενθέσεις έχουν μεγαλύτερη προτεραιότητα.

```haxe
!true && false   // => false
!(true && false) // => true
```
