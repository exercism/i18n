# Εισαγωγή

Στη Haxe, οι επαναλήπτες χρησιμοποιούνται για να διατρέχουν μια τιμή μέσω ενός `for` βρόχου. Υπάρχουν δύο τύποι επαναληπτών:

- `Iterator` που διατρέχει μια τιμή.
- Δεδομένα `Iterable` που καθιστούν δυνατό να διατρέξεις έναν τύπο δεδομένων.

Και οι δύο αυτές οι έννοιες αντιπροσωπεύονται από τα `Iterator<T>` και `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Οποιαδήποτε κλάση ενοποιείται με έναν από αυτούς τους τύπους μπορεί να διατρεχθεί χρησιμοποιώντας έναν `for` βρόχο. Αν μια κλάση ορίζει τις μεθόδους `hasNext` και `next`, θεωρείται επαναλήπτης, αλλιώς αν ορίζει μια μέθοδο `iterator`, θεωρείται επαναλήψιμος τύπος.
