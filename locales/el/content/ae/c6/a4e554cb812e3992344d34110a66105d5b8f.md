# Εισαγωγή στην Επανάληψη

Η Bash έχει δύο μορφές επανάληψης:

* Επανάλαβε κάποιες εντολές _για κάθε στοιχείο μιας λίστας στοιχείων_,
* Επανάλαβε κάποιες εντολές _όσο κάποια συνθήκη είναι αληθής (ή ψευδής)_.

## `for` βρόχοι

Για να διατρέξουμε μια λίστα στοιχείων, χρησιμοποιούμε τον `for` βρόχο.

```bash
for varname in words; do COMMANDS; done
```

Το `words` επεκτείνεται με τον διαχωρισμό λέξεων και την επέκταση ονομάτων αρχείων (τα μάθαμε στην [έννοια Quoting][quoting]).
Κάθε λέξη ανατίθεται με τη σειρά στη `varname` και οι COMMANDS εκτελούνται.

Ακολουθούν μερικά παραδείγματα που δείχνουν πότε μπορεί να φανεί χρήσιμος ο `for` βρόχος

* Εκτέλεσε κάποιες εντολές σε μια ομάδα αρχείων.

    ```bash
    # source all the bash library files in the current directory
    for file in ./*.bash; do
        source "$file"
    done
    ```

* Εκτέλεσε κάποια εντολή σε κάθε μία από τις παραμέτρους ενός σεναρίου ή μιας συνάρτησης.

    ```bash
    for arg in "$@"; do
        echo "argument: ${arg}"
    done
    ```

* Εκτέλεσε κάποια εντολή για κάθε λέξη, χωρισμένη με κενό διάστημα, στην έξοδο μιας εντολής.

    ```bash
    for i in $(seq 10); do
        echo "${i} squared is $((i * i))"
    done
    ```

    Θα δούμε κάποιες προειδοποιήσεις γι' αυτό το στυλ παρακάτω.

### Αριθμητικός `for` βρόχος

Η Bash έχει όντως έναν αριθμητικό βρόχο.
Αυτό θα σου φανεί κάπως γνώριμο από άλλες γλώσσες προγραμματισμού.

```bash
for ((INITIALIZATION; CONDITION; INCREMENT)); do COMMANDS; done
```

Οι διπλές παρενθέσεις στη bash αντιπροσωπεύουν ένα αριθμητικό περιβάλλον (θα δούμε περισσότερα για την αριθμητική της bash σε επόμενη έννοια).
Το παραπάνω παράδειγμα με το `seq` μπορεί να γραφτεί έτσι

```bash
for ((i = 1; i <= 10; i++)); do
    echo "${i} squared is $((i * i))"
done
```

### Πότε να μην χρησιμοποιείς τον `for`

[Μη διαβάζεις γραμμές με τον `for`][bashfaq1].

Αυτό είναι ένα anti-pattern που θα δεις συχνά: να διατρέχεις την έξοδο του `cat`.

```bash
for line in $(cat some.file); do 
    do_something_with "$line"
done
```

Αυτό είναι λάθος για δύο λόγους.

1. Η αντικατάσταση εντολής δεν είναι μέσα σε εισαγωγικά, οπότε υπόκειται σε διαχωρισμό λέξεων.
   Ο διαχωρισμός λέξεων, από προεπιλογή, γίνεται με βάση τα _κενά διαστήματα_, όχι μόνο τις αλλαγές γραμμής.
   Αυτός ο `for` βρόχος διατρέχει τις **λέξεις** του αρχείου, όχι τις γραμμές.
2. Η αντικατάσταση εντολής δεν είναι μέσα σε εισαγωγικά, οπότε υπόκειται σε επέκταση ονομάτων αρχείων.
   Κάθε λέξη του αρχείου θα αντιστοιχιστεί ως μοτίβο glob.

Όπως μάθαμε στην [έννοια Quoting][quoting], ο διαχωρισμός λέξεων μπορεί να ελεγχθεί με τη μεταβλητή `IFS` και η επέκταση ονομάτων αρχείων μπορεί να απενεργοποιηθεί.
Αλλά αυτή τείνει να είναι μια εύθραυστη λύση.
Ο `for` είναι ο λάθος τρόπος για να διατρέξεις τις γραμμές ενός αρχείου.
Ο ιδιωματικός τρόπος για να διαβάσεις ένα αρχείο είναι με έναν `while` βρόχο.

## `while` βρόχοι

Χρησιμοποίησε το `while` για να επαναλάβεις μια ακολουθία εντολών _όσο_ κάποια συνθήκη είναι αληθής.

```bash
while CONDITION_COMMANDS; do COMMANDS; done
```

Όπως και με το `if` (όπως μάθαμε στην [έννοια Conditionals][conditionals]), δεν υπάρχει ειδική σύνταξη για τις CONDITION_COMMANDS.
Η κατάσταση εξόδου της λίστας εντολών θα καθορίσει το "αληθής" ή το "ψευδής".

## Έλεγχος των βρόχων

Η εντολή `break` βγαίνει από τον βρόχο.
Η εκτέλεση συνεχίζεται με την εντολή που ακολουθεί τον τερματισμό `done` του βρόχου.

Η εντολή `continue` πηγαίνει στην επόμενη επανάληψη του βρόχου.

## Διαβάζοντας τις γραμμές ενός αρχείου

Όπως αναφέρθηκε, ένας `while` βρόχος είναι ο ιδιωματικός τρόπος για να διαβάσεις ένα αρχείο. 

```bash
while IFS= read -r line; do
    do_something_with "$line"
done < some.file
```

* Το περιεχόμενο του αρχείου παρέχεται ως είσοδος στον βρόχο με την ανακατεύθυνση `<`.
* Η εντολή `read` επιστρέφει "αληθής" αν μπορεί να διαβάσει μια ολόκληρη γραμμή από την είσοδό της.
  Όταν η είσοδος εξαντληθεί, ή αν η τελευταία γραμμή τελειώνει χωρίς χαρακτήρα αλλαγής γραμμής στο τέλος, τότε η read επιστρέφει "ψευδής".
  * Ο _πραγματικά_ ιδιωματικός τρόπος για να διαβάσεις τις γραμμές ενός αρχείου, ακόμα κι αν η τελευταία γραμμή δεν τελειώνει με αλλαγή γραμμής, είναι

    ```bash
    while IFS= read -r line || [[ -n "$line" ]]; do ...
    ```

* Η επιλογή `-r` λέει στη `read` να μην αντικαθιστά ακολουθίες ανάστροφης κάθετου: η ανάστροφη κάθετος είναι απλώς ένας συνηθισμένος χαρακτήρας.
* Το `IFS=` αναθέτει την κενή συμβολοσειρά στο IFS μόνο για τη διάρκεια της εντολής read.
  Αυτό απενεργοποιεί προσωρινά τον διαχωρισμό λέξεων, ώστε να διατηρείται τυχόν κενό στην αρχή ή στο τέλος της εισερχόμενης γραμμής κειμένου.

## Until

Η δομή `until` επαναλαμβάνει μια ακολουθία εντολών όσο κάποια συνθήκη είναι **ψευδής**.
Ο βρόχος επαναλαμβάνεται _μέχρι_ η συνθήκη να γίνει αληθής.

```bash
until CONDITION_COMMANDS; do COMMANDS; done
```

Είναι σπάνιο να χρησιμοποιείς το `until`.
Είναι πιο συνηθισμένο να χρησιμοποιείς έναν βρόχο "while not".

```bash
while ! CONDITION_COMANDS; do ...
```

## Ατέρμονοι βρόχοι

Μερικές φορές θέλεις να επαναλαμβάνεις για πάντα.
Ορίστε δύο τρόποι για να το κάνεις.

1. ένας `while` βρόχος με συνθήκη που έχει πάντα κατάσταση εξόδου επιτυχίας

    ```bash
    while true; do ...
    ```

2.  ένας αριθμητικός `for` βρόχος με κενές εκφράσεις

    ```bash
    for ((;;)); do ...
    ```

## Do-While

Δεν υπάρχει ρητή δομή do-while, αλλά μπορείς να πετύχεις το ίδιο αποτέλεσμα:

```bash
while true; do
    COMMANDS

    if END_CONDITION; then
        break
    fi
done
```
