# Υποδείξεις

## 1. Μετατροπή από Φαρενάιτ σε Κελσίου

- Η θερμοκρασία σε βαθμούς Κελσίου ορίζεται ως: T(°C) = (T(°F) - 32) / 1.8
- Η θερμοκρασία σε Φαρενάιτ δίνεται ως `Integer` και πρέπει να επιστρέψεις τη θερμοκρασία σε Κελσίου ως `Float`.
  Η συνάρτηση `fromInteger` θα σου φανεί χρήσιμη.

## 2. Μετατροπή από Κελσίου σε Φαρενάιτ

- Η θερμοκρασία σε βαθμούς Φαρενάιτ ορίζεται ως: T(°F) = T(°C) × 1.8 + 32
- Η θερμοκρασία σε Κελσίου δίνεται ως `Float` και πρέπει να επιστρέψεις τη θερμοκρασία σε Φαρενάιτ στρογγυλοποιημένη προς τα πάνω στον πλησιέστερο `Integer`.
  Η συνάρτηση `ceiling` θα σου φανεί χρήσιμη.
