# Λίστες

Ο `ARRAY` είναι σταθερός. Φτιάχνεται σε ένα μέγεθος και μένει σε αυτό το μέγεθος: δεν μπορείς να προσθέσεις σε αυτόν ούτε να αφαιρέσεις από αυτόν.

Το σημειωματάριο ενός ντετέκτιβ δεν είναι έτσι. Τα ίχνη εμφανίζονται ένα ένα και διαγράφονται όταν αποκλείονται. Για αυτό χρειάζεσαι μια **λίστα**.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes.append("broken window");
   notes.size                   -- 2
```

Το `LIST{T}` κρατά τιμές τύπου `T` με σειρά, όπως ένας πίνακας, και μεγαλώνει και μικραίνει όποτε του το ζητήσεις.

## Αλλάζει επιτόπου

Η `append` αλλάζει τη λίστα στην οποία καλείται και δεν επιστρέφει τίποτα:

```sather
   notes.append("muddy boots");        -- yes
   notes := notes.append("muddy boots");   -- no: append answers nothing
```

Αυτό είναι διαφορετικό από τα `FMAP` και `FSET`, όπου κάθε αλλαγή έπρεπε να την αναθέσεις πίσω. Μια `LIST` είναι ένα συνηθισμένο αντικείμενο, όπως ένα `SCOREBOARD`: δώσ' την σε μια ρουτίνα και η ρουτίνα μπορεί να αλλάξει τη δική σου.

## Ανάγνωση και εγγραφή

Αγκύλες, με τη μέτρηση να ξεκινά από το μηδέν, ακριβώς όπως σε έναν πίνακα:

```sather
   notes[0]                     -- "muddy boots"
   notes[1] := "smashed window";
   notes.size                   -- how many
   notes.is_empty               -- true when there are none
```

## Αφαίρεση

Η `remove_index` βγάζει μια θέση και όλα όσα ακολουθούν μετακινούνται μια θέση πιο πάνω:

```sather
   notes.remove_index(0);       -- the first clue is struck out
```

Έτσι, οι θέσεις δεν είναι μόνιμες. Η θέση ενός ίχνους αλλάζει όταν αφαιρεθεί ένα προηγούμενο, κάτι που αξίζει να το θυμάσαι πριν αποθηκεύσεις μια θέση.

## Διάσχιση

Το `elt!` δουλεύει, όπως και σε έναν πίνακα:

```sather
   loop
      #OUT + notes.elt! + "\n";
   end;
```

## Τα άγκιστρα

Το `LIST{STR}` είναι μια λίστα συμβολοσειρών, το `LIST{INT}` μια λίστα αριθμών. Είναι μια γενική κλάση, ακριβώς σαν αυτή που έγραψες στο `lost-property`, και τώρα μπορείς να διαβάσεις με τον ίδιο τρόπο και αυτήν της βιβλιοθήκης.
