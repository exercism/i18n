# Οδηγίες

Σε αυτή την άσκηση πρέπει να υλοποιήσεις μερικές συναρτήσεις για να χειρίζεσαι μια λίστα γλωσσών προγραμματισμού.

## 1. Όρισε μια συνάρτηση που επιστρέφει μια κενή λίστα γλωσσών

Όρισε τη συνάρτηση `language_list` που δεν παίρνει ορίσματα και επιστρέφει μια κενή λίστα.

```php
<?php

language_list();
// => []
```

## 2. Τροποποίησε τη συνάρτηση ώστε να δημιουργεί μια λίστα από οποιονδήποτε αριθμό γλωσσών

Τροποποίησε τη συνάρτηση `language_list`, ώστε να παίρνει ένα όρισμα μεταβλητού πλήθους γλωσσών (συμβολοσειρών).
Πρέπει να επιστρέφει τη λίστα που προκύπτει με τις γλώσσες μέσα της.

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. Όρισε μια συνάρτηση που προσθέτει μια γλώσσα στη λίστα

Όρισε τη συνάρτηση `add_to_language_list` που παίρνει 2 ορίσματα, έναν πίνακα γλωσσών και τη νέα γλώσσα.

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. Όρισε μια συνάρτηση που αφαιρεί ένα στοιχείο από τη λίστα γλωσσών

Όρισε τη συνάρτηση `prune_language_list` που αφαιρεί την πρώτη γλώσσα από τον πίνακα γλωσσών.

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. Όρισε μια συνάρτηση που παίρνει το πρώτο στοιχείο της λίστας

Όρισε τη συνάρτηση `current_language` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_).
Πρέπει να επιστρέφει την πρώτη γλώσσα της λίστας.
Θεώρησε ότι η λίστα θα έχει πάντα τουλάχιστον ένα στοιχείο.

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. Όρισε μια συνάρτηση που επιστρέφει πόσες γλώσσες υπάρχουν στη λίστα

Όρισε τη συνάρτηση `language_list_length` που παίρνει 1 όρισμα (μια _λίστα γλωσσών_).
Πρέπει να επιστρέφει τον αριθμό των γλωσσών στη λίστα.

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
