# Εισαγωγή

Υπάρχουν βασικά δύο τύποι βρόχων:

1. Επανάληψη μέχρι να ικανοποιηθεί μια συνθήκη.
2. Επανάληψη πάνω από τα στοιχεία μιας συλλογής.

Και οι δύο είναι εφικτοί στη Julia, αν και ο δεύτερος μπορεί να είναι πιο συνηθισμένος.

## Ο `while` βρόχος

Για προβλήματα ανοιχτού τύπου, όπου ο αριθμός των περασμάτων από τον βρόχο δεν είναι γνωστός εκ των προτέρων, η Julia έχει τον `while` βρόχο.

Η βασική μορφή είναι αρκετά απλή:

```julia
while condition
    do_something()
end
```

Σε αυτή την περίπτωση, το πρόγραμμα θα συνεχίσει να γυρίζει τον βρόχο μέχρι το `condition` να μην είναι πλέον `true`.

Υπάρχουν δύο τρόποι για να βγεις νωρίς από τον βρόχο:

- Ένα `break` προκαλεί την έξοδο από τον βρόχο, με την εκτέλεση να συνεχίζεται στην επόμενη γραμμή μετά το `end` του βρόχου.
- Ένα `return x` σταματά την εκτέλεση της τρέχουσας συνάρτησης, περνώντας την τιμή επιστροφής `x` πίσω στον καλούντα.

Με αυτές τις επιλογές διαθέσιμες, μερικές φορές μπορεί να είναι βολικό να δημιουργήσεις έναν "άπειρο" βρόχο με `while true ... end` και μετά να βασιστείς στο ότι θα βρεις μια συνθήκη τερματισμού μέσα στο σώμα του βρόχου, ώστε να προκαλέσεις ένα `break` ή ένα `return`.

## Επανάληψη πάνω από μια συλλογή

Το πιο απλό παράδειγμα είναι η επανάληψη πάνω από ένα εύρος.

Αν θέλεις να κάνεις κάτι 10 φορές:

```julia
for n in 1:10
    do_something(n)
end
```

Αν η τρέχουσα επανάληψη δεν ικανοποιεί κάποια συνθήκη, μπορείς να περάσεις αμέσως στην επόμενη επανάληψη με ένα `continue`:

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

Σε συντομότερη μορφή, το μπλοκ `if` θα μπορούσε να αντικατασταθεί από `is_useless(n) && continue`.

Μπορείς να κάνεις επανάληψη πάνω από πολλούς άλλους τύπους συλλογών: στοιχεία ενός πίνακα, χαρακτήρες μιας συμβολοσειράς, κλειδιά ενός λεξικού...

Τα παραδείγματα μέχρι τώρα κάνουν επανάληψη πάνω από το εύρος `1:10`, όπου η τιμή είναι ταυτόχρονα και η θέση του βρόχου.

Γενικότερα, μπορεί να χρειάζεσαι τη θέση και όχι μόνο την τιμή.
Γι' αυτό χρησιμοποιείς τη συνάρτηση `eachindex()`, για παράδειγμα `for i in eachindex(my_array) ... end`.
