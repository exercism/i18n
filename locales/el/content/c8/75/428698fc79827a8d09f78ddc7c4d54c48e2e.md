# Εισαγωγή

Ένα διάνυσμα είναι ένας μονοδιάστατος πίνακας.
Μπορούν να περιέχουν στοιχεία διαφορετικών τύπων.

## Δημιουργία διανυσμάτων

Τα διανύσματα μπορούν να δημιουργηθούν μέσω της συνάρτησης `vector` ή χρησιμοποιώντας τη μορφή αναγνώστη `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 t "foo" B)
#(2 nil "bar" a)      ; => #(2 nil "bar" A)
```

## Πρόσβαση σε στοιχεία

Για να προσπελάσεις τα στοιχεία ενός διανύσματος, χρησιμοποίησε το `aref`. Οι θέσεις ξεκινούν από το μηδέν:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
