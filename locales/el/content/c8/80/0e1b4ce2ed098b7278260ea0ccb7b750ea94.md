# Μέθοδοι συμβολοσειρών

Η `String` διαθέτει αρκετές μεθόδους που μπορούν να χρησιμοποιηθούν για τον χειρισμό συμβολοσειρών.  
Αυτές οι μέθοδοι καλούνται πάνω στην ίδια τη συμβολοσειρά και συχνά συνδυάζονται αλυσιδωτά για να εκτελέσουν πολλαπλές πράξεις σε μια συμβολοσειρά.

Ακολουθεί μια λίστα με μερικές από τις πιο συνηθισμένες μεθόδους.
Δες την [τεκμηρίωση του API της `String`][string-api] για μια πλήρη λίστα μεθόδων.

## String#upcase & String#downcase

Η μέθοδος [`upcase`][upcase] επιστρέφει μια νέα συμβολοσειρά όπου όλοι οι χαρακτήρες έχουν μετατραπεί σε κεφαλαία.

```crystal
"hello".upcase
# => "HELLO"
```

Η μέθοδος [`downcase`][downcase] επιστρέφει μια νέα συμβολοσειρά όπου όλοι οι χαρακτήρες έχουν μετατραπεί σε πεζά.

```crystal
"HELLO".downcase
# => "hello"
```

## String#sub & String#gsub

Η Crystal διαθέτει μεθόδους για την αντικατάσταση τμημάτων μιας συμβολοσειράς.
Αυτές είναι οι [`sub`][sub] (_υποκατάσταση_) και [`gsub`][gsub] (_καθολική υποκατάσταση_).

Αυτές οι μέθοδοι δέχονται ως πρώτο όρισμα μια συμβολοσειρά, έναν χαρακτήρα ή μια κανονική έκφραση και ως δεύτερο όρισμα μια συμβολοσειρά ή έναν χαρακτήρα.
Το πρώτο όρισμα είναι το τμήμα της συμβολοσειράς που θα αντικατασταθεί, και το δεύτερο όρισμα είναι η αντικατάσταση.
Το `Char` και οι κανονικές εκφράσεις θα εξηγηθούν σε επόμενες έννοιες.

Η μέθοδος `sub` αντικαθιστά την πρώτη εμφάνιση του πρώτου ορίσματος με το δεύτερο όρισμα.

```crystal
"hello".sub("l", "r")
# => "herlo"
```

Η μέθοδος `gsub` λειτουργεί όπως η `sub`, αλλά αντικαθιστά όλες τις εμφανίσεις του πρώτου ορίσματος με το δεύτερο όρισμα.

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp & String#strip

Οι chomp και strip μπορούν να χρησιμοποιηθούν για να αφαιρέσεις ανεπιθύμητους χαρακτήρες από μια συμβολοσειρά.

Η μέθοδος [`chomp`][chomp] αφαιρεί από προεπιλογή τους τελευταίους χαρακτήρες `\r`, `\n` ή `\r\n` από μια συμβολοσειρά.
Αν η μέθοδος κληθεί με ένα όρισμα, θα αφαιρέσει τη συγκεκριμένη τιμή από το τέλος της συμβολοσειράς, εφόσον αυτή υπάρχει εκεί.

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

Από προεπιλογή, η μέθοδος [`strip`][strip] αφαιρεί όλα τα κενά διαστήματα από την αρχή και το τέλος μιας συμβολοσειράς.
Αν η μέθοδος κληθεί με ένα όρισμα, θα αφαιρέσει αυτό το όρισμα από την αρχή και το τέλος της συμβολοσειράς, εφόσον υπάρχει στην αρχή ή στο τέλος της.

```crystal
" hello ".strip
# => "hello"
```

## String#index

Η μέθοδος [`index`][index] μπορεί να χρησιμοποιηθεί για να βρεις τη θέση ενός χαρακτήρα σε μια συμβολοσειρά.
Η μέθοδος `index` δέχεται ως όρισμα μια `String`, ένα `Char` ή μια κανονική έκφραση.
Μπορεί να δεχτεί ένα προαιρετικό δεύτερο όρισμα που καθορίζει τη θέση από την οποία θα ξεκινήσει η αναζήτηση.
Η μέθοδος `index` επιστρέφει τη θέση της πρώτης εμφάνισης του ορίσματος.

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

Μπορείς να χρησιμοποιήσεις τη μέθοδο [`delete_at`][delete_at] για να αφαιρέσεις έναν χαρακτήρα από μια συμβολοσειρά.
Η μέθοδος `delete_at` δέχεται ως όρισμα μια θέση και αφαιρεί τον χαρακτήρα που βρίσκεται σε αυτή τη θέση.

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

Η μέθοδος [`insert`][insert] μπορεί να χρησιμοποιηθεί για να εισάγεις μια συμβολοσειρά σε μια συγκεκριμένη θέση.
Η μέθοδος `insert` δέχεται ως πρώτο όρισμα μια θέση και ως δεύτερο όρισμα μια συμβολοσειρά.
Η μέθοδος `insert` επιστρέφει μια νέα συμβολοσειρά όπου το δεύτερο όρισμα έχει εισαχθεί στη θέση αυτή.

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
