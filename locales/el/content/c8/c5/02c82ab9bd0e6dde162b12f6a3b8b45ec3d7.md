# If, Elseif, Else

Οι εντολές υπό συνθήκη με `if`, `elseif` και `else` αποτελούν θεμελιώδη στοιχεία του ελέγχου ροής ενός προγράμματος.
Η εντολή `if` αξιολογεί μια έκφραση και, αν είναι `true`, εκτελεί τον κλάδο κώδικα.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Αν η έκφραση δεν είναι τιμή boolean, η αξιολόγηση καθορίζει την "αληθότητα" ή τη "μη ψευδότητα" της τιμής.
Στην PHP, οι παρακάτω τιμές θεωρούνται ίσες με την ψευδή τιμή:

- boolean `false`
- ακέραιος `0`
- δεκαδικός `0.0` και `-0.0`
- ένας κενός πίνακας `[]`
- μια κενή συμβολοσειρά `""` ή μια αριθμητική συμβολοσειρά `"0"`
- `null`

Όλες οι άλλες τιμές θεωρούνται αληθείς.

## Ανταπόκριση σε πολλαπλές συνθήκες

Μετά από μια εντολή `if`, μπορείς να συνδυάσεις πολλαπλές συνθήκες χρησιμοποιώντας `elseif` και `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Μόνο μία εντολή υπό συνθήκη που αξιολογείται ως αληθής θα εκτελεστεί.
Έτσι, αν πολλαπλές συνθήκες μπορούν να αξιολογηθούν ως αληθείς, η σειρά με την οποία είναι γραμμένες έχει σημασία.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
