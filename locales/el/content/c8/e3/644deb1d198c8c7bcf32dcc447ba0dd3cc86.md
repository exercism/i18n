# Σχετικά

Ένα crate είναι μια μονάδα μεταγλώττισης στη Rust. Ένα crate μπορεί να μεταγλωττιστεί σε ένα εκτελέσιμο αρχείο ή σε μια βιβλιοθήκη. Τις περισσότερες φορές, θα χρησιμοποιείς το `cargo` για να διαχειρίζεσαι εξωτερικές εξαρτήσεις. Η προσθήκη μιας εξάρτησης μπορεί να είναι τόσο απλή όσο το να προσθέσεις μία γραμμή στο αρχείο `Cargo.toml` σου.

- [εισαγωγή στα πακέτα και στο Cargo στο βιβλίο της Rust](https://doc.rust-lang.org/book/ch07-00-managing-growing-projects-with-packages-crates-and-modules.html)
