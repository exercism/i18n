# Προσθήκη οδηγιών

## Υποδείξεις

- Για να αναλύσεις το κείμενο, θα μπορούσες να δοκιμάσεις να χρησιμοποιήσεις τη βιβλιοθήκη [FParsec](http://www.quanttec.com/fparsec/tutorial.html).
- Ως άσκηση, θα μπορούσες να δοκιμάσεις να αναπαραστήσεις μια ερώτηση ως [Αφηρημένο Συντακτικό Δέντρο](https://en.wikipedia.org/wiki/Abstract_syntax_tree).
