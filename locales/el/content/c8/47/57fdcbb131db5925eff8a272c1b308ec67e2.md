# Οδηγίες

Η φίλη σου η Li Mei έχει ένα μπαρ με χυμούς, όπου πουλάει νόστιμους χυμούς από ανάμεικτα φρούτα. Είσαι τακτικός πελάτης στο μαγαζί της και κατάλαβες ότι θα μπορούσες να της κάνεις τη ζωή λίγο πιο εύκολη με λίγο κώδικα Factor.

## 1. Προσδιόρισε πόση ώρα χρειάζεται για να φτιαχτεί ένας χυμός

Στη Li Mei αρέσει να λέει στους πελάτες της από πριν πόση ώρα θα περιμένουν για έναν χυμό από το μενού. Της είναι δύσκολο να θυμάται τους ακριβείς αριθμούς, γιατί ο χρόνος που χρειάζεται για να φτιαχτεί ο κάθε χυμός ποικίλλει:

- Ο `"Pure Strawberry Joy"` θέλει `0.5` λεπτά.
- Ο `"Energizer"` και ο `"Green Garden"` θέλουν `1.5` λεπτά ο καθένας.
- Ο `"Tropical Island"` θέλει `3` λεπτά.
- Ο `"All or Nothing"` θέλει `5` λεπτά.
- Όλα τα άλλα ποτά (π.χ. ειδικές προσφορές) θέλουν `2.5` λεπτά.

Όρισε τη `time-to-mix-juice` ώστε να παίρνει ένα όνομα χυμού από τη στοίβα και να επιστρέφει τον αριθμό των λεπτών που χρειάζονται για να φτιαχτεί αυτό το ποτό.

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. Ανανέωσε το απόθεμα σε φέτες λάιμ

Πολλές από τις δημιουργίες της Li Mei περιλαμβάνουν φέτες λάιμ, είτε ως συστατικό είτε ως μέρος της διακόσμησης. Έτσι, όταν ξεκινάει τη βάρδιά της το πρωί, πρέπει να βεβαιωθεί ότι το δοχείο με τις φέτες λάιμ είναι γεμάτο για την ημέρα που έρχεται.

Όρισε τη `wedges-from-lime` ώστε να παίρνει ένα μέγεθος λάιμ και να επιστρέφει τον αριθμό των φετών που βγάζει: `6` από ένα `"small"` λάιμ, `8` από ένα `"medium"`, `10` από ένα `"large"`.

Έπειτα, όρισε τη `limes-to-cut` ώστε να παίρνει τον αριθμό των `needed` φετών και έναν πίνακα με `limes` (μεγέθη λάιμ με τη σειρά κοψίματος). Κόβει τα λάιμ ένα ένα, με τη σειρά, και σταματάει μόλις είτε μαζέψει αρκετές φέτες είτε τελειώσουν τα λάιμ. Επίστρεψε τον αριθμό των λάιμ που χρειάστηκε να κόψει.

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. Κατέγραψε τους χρόνους για να φτιαχτεί κάθε παραγγελία στην ουρά

Στη Li Mei αρέσει να παρακολουθεί πόση ώρα θα πάρει να φτιαχτούν οι παραγγελίες που περιμένουν οι πελάτες.

Όρισε τη `order-times` ώστε να παίρνει έναν πίνακα με παραγγελίες και να επιστρέφει έναν πίνακα με τον χρόνο για να φτιαχτεί κάθε παραγγελία, με την ίδια σειρά.

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. Τελείωσε τη βάρδια

Η Li Mei δουλεύει πάντα μέχρι τις 3 μ.μ. Τότε αναλαμβάνει ο υπάλληλός της, ο Dmitry. Συχνά υπάρχουν ποτά που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμη όταν τελειώνει η βάρδια της Li Mei. Τότε ο Dmitry ετοιμάζει τους υπόλοιπους χυμούς.

Για να γίνει πιο εύκολη η παράδοση της βάρδιας, όρισε τη `remaining-orders` ώστε να παίρνει τον αριθμό των λεπτών `time-left` που απομένουν στη βάρδια της Li Mei και έναν πίνακα με `orders` (χυμούς που έχουν παραγγελθεί αλλά δεν έχουν ετοιμαστεί ακόμη). Επίστρεψε τις παραγγελίες που θα χρειαστεί να αναλάβει ο Dmitry, δηλαδή αυτές που δεν προλαβαίνει να ξεκινήσει η Li Mei πριν τελειώσει η βάρδιά της.

Το `time-left` είναι πάντα μεγαλύτερο από `0`. Οι παραγγελίες ετοιμάζονται με τη σειρά που εμφανίζονται στον πίνακα. Μόλις η Li Mei ξεκινήσει έναν χυμό, τον τελειώνει πάντα, ακόμη κι αν χρειαστεί να δουλέψει λίγο παραπάνω. Αν προλαβαίνει να ξεκινήσει κάθε παραγγελία, επίστρεψε έναν κενό πίνακα.

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
