# Σχετικά

Ένα από τα βασικά σημεία όταν δουλεύεις με αριθμούς στην F# είναι η διάκριση ανάμεσα στους ακέραιους (αριθμούς χωρίς ψηφία μετά το διαχωριστικό δεκαδικών) και τους αριθμούς κινητής υποδιαστολής (αριθμούς με μηδέν ή περισσότερα ψηφία μετά το διαχωριστικό δεκαδικών).

Οι δύο πιο συχνά χρησιμοποιούμενοι αριθμητικοί τύποι στην F# είναι ο `int` (ένας ακέραιος 32 bit) και ο `float` (ένας αριθμός κινητής υποδιαστολής 64 bit).

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

Τόσο οι ακέραιοι όσο και οι αριθμοί κινητής υποδιαστολής μπορούν να χρησιμοποιήσουν τον χαρακτήρα `_` ως _διαχωριστικό ψηφίων_, κάτι που βοηθάει όταν ορίζεις μεγάλους αριθμούς:

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

Η αριθμητική γίνεται με τους τυπικούς [αριθμητικούς τελεστές][arithmetic-operators] (`+`, `-`, `*`, κ.λπ.). Οι αριθμοί μπορούν να συγκριθούν με τους [τυπικούς τελεστές σύγκρισης][comparison-operators] (`<`, `>=`, κ.λπ.) και με τους τελεστές ισότητας (`=`) και ανισότητας (`<>`).

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

Για να μετατρέψεις αριθμητικούς τύπους μεταξύ τους, πρέπει να χρησιμοποιήσεις τον ενσωματωμένο [τελεστή μετατροπής][conversion-operators]. Αυτοί οι τελεστές παίρνουν το όνομά τους από τον τύπο στον οποίο μετατρέπουν.

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

Όταν μετατρέπεις τύπους, να είσαι πάντα προσεκτικός. Αν μια τιμή δεν μπορεί να αναπαρασταθεί από τον τύπο προορισμού, η τιμή θα _υπερχειλίσει_.
