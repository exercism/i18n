# Υποδείξεις

## 1. Εξαγωγή σφαλμάτων

- Μπορείς να κάνεις αντιστοίχιση μοτίβου στα σφάλματα χρησιμοποιώντας τη σύνταξη μοτίβου `Error(value)`.

## 2. Αφαίρεση προθέματος ομάδας

- Μπορείς να κάνεις αντιστοίχιση μοτίβου στα προθέματα συμβολοσειρών χρησιμοποιώντας τη σύνταξη μοτίβου `"prefix" <> rest`.

## 3. Διαχωρισμός περιοχής και ομάδας

- Μπορείς να χωρίσεις τις συμβολοσειρές σε έναν χαρακτήρα χρησιμοποιώντας τη [συνάρτηση `string.split`][split].
- Μπορείς να κάνεις αντιστοίχιση μοτίβου στις λίστες χρησιμοποιώντας τη σύνταξη μοτίβου `[a, b, c]`.

[split]: https://hexdocs.pm/gleam_stdlib/gleam/string.html#split
