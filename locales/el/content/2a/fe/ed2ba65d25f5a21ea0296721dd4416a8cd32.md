# Υποδείξεις

## 1. Μετέτρεψε τη δυαδική αναπαράσταση σε ακέραιο

- Υπάρχει μια [ενσωματωμένη μέθοδος][string-to_i] για να μετατρέψεις μια συμβολοσειρά με δυαδική αναπαράσταση σε ακέραιο, δίνοντας τη βάση.

## 2. Πάρε το λιγότερο σημαντικό bit από έναν ακέραιο

- Υπάρχει μια [ενσωματωμένη μέθοδος][integer-bit] για να πάρεις ένα bit από έναν ακέραιο, δίνοντας μια θέση.
- Το λιγότερο σημαντικό bit είναι το bit που βρίσκεται πιο δεξιά.
  Βρίσκεται στη θέση 0.

## 3. Πάρε τη δεκαεξαδική τιμή από ένα κανάλι χρώματος

- Υπάρχει μια [ενσωματωμένη μέθοδος][integer-to_s] για να μετατρέψεις έναν ακέραιο σε συμβολοσειρά με δεκαεξαδική αναπαράσταση, δίνοντας τη βάση.
- Η μέθοδος μπορεί να δεχτεί ένα προαιρετικό όρισμα που καθορίζει την ακρίβεια του αριθμού των ψηφίων που παράγονται.

## 4. Πάρε τη δεκαεξαδική τιμή από το RGB

- Μπορείς να χρησιμοποιήσεις ήδη ορισμένες μεθόδους για να πάρεις τη δεκαεξαδική τιμή από ένα κανάλι χρώματος.
