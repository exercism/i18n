# Σχετικά

Οι πόροι που κρατούν κατάσταση του λειτουργικού συστήματος (λαβές αρχείων, sockets, κλειδώματα)
χρειάζονται *εγγυημένο* καθαρισμό, ακόμη και όταν μια εξαίρεση ξετυλίγει τη
στοίβα. Το vocab [`destructors`][destructors] του Factor παρέχει ένα
μικρό framework για αυτό, και οι περισσότεροι ενσωματωμένοι πόροι
(`<file-reader>`, `<file-writer>`, sockets, …) συνδέονται ήδη με
αυτό.

## Η κλάση και το generic

Μια κλάση συμμετέχει επεκτείνοντας το `disposable` και υλοποιώντας
το `dispose*`:

```factor
TUPLE: my-handle < disposable underlying ;

: <my-handle> ( underlying -- handle )
    my-handle new-disposable swap >>underlying ;

M: my-handle dispose* underlying>> dispose ;
```

Το `new-disposable ( class -- obj )` δεσμεύει το tuple *και* το
καταχωρεί στην τρέχουσα εμβέλεια destructor, ώστε μια εξαίρεση
ανάμεσα στη δέσμευση και το επόμενο ασφαλές σημείο να μην μπορεί να
προκαλέσει διαρροή του πόρου. Το framework εγγυάται ότι το `dispose*`
εκτελείται **το πολύ μία φορά** ανά αντικείμενο: οι επαναλαμβανόμενες
κλήσεις του `dispose` δεν κάνουν τίποτα.

## Οι δημόσιοι καλούντες χρησιμοποιούν το `dispose`

| λέξη              | αποτέλεσμα                                    |
|-------------------|-----------------------------------------------|
| `dispose`         | `( obj -- )`: απελευθερώνει τον πόρο, ασφαλές να κληθεί δύο φορές |
| `with-disposal`   | `( disposable quot -- )`: βάζει έναν πόρο σε εμβέλεια |
| `with-destructors`| `( quot -- )`: ανοίγει μια εμβέλεια καταχωρητή |
| `&dispose`        | `( obj -- obj )`: κάνει dispose στην κανονική *ή* στην αποτυχημένη έξοδο |
| `|dispose`        | `( obj -- obj )`: κάνει dispose μόνο αν η εμβέλεια ξετυλιχθεί |

Το `with-disposal` είναι η μορφή για έναν μόνο πόρο. Για περισσότερους
από έναν πόρους, άνοιξε μια εμβέλεια `with-destructors` και καταχώρισε
κάθε απόκτηση με `&dispose` (θέλεις πάντα να τον απελευθερώσεις) ή
`|dispose` (απελευθέρωση μόνο σε αποτυχία, η επιτυχημένη διαδρομή τον
κρατά).

```factor
[
    "in.txt"  utf8 <file-reader> &dispose
    "out.txt" utf8 <file-writer> &dispose
    [ read1 ] [ write1 ] bi
] with-destructors
```

## Το `cleanup` είναι η γυμνή, πρωτογενής λέξη

Για ένα μεμονωμένο try/finally χωρίς καταχωρητή, το [`cleanup`][cleanup]
(από το `continuations`) είναι η λέξη χαμηλότερου επιπέδου:

```
cleanup ( try cleanup-always cleanup-error -- )
```

Το `with-destructors` είναι αυστηρά πιο ισχυρό (ο καταχωρητής μπορεί
να μεγαλώσει κατά την εκτέλεση), αλλά το `cleanup` ταιριάζει πιο φυσικά
όταν το ζεύγος απόκτησης/απελευθέρωσης είναι σταθερό και τοπικό.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
[cleanup]: https://docs.factorcode.org/content/word-cleanup%2Ccontinuations.html
