# Tests

Υπάρχουν δύο διαφορετικοί τρόποι για να προετοιμάσεις το περιβάλλον σου ώστε να τρέξεις τα tests με Objective-C:

- Δημιούργησε ένα project στο Xcode με ένα test target που θα τρέχει τα tests.
- Χρησιμοποίησε το ruby gem `objc` ως βοηθητικό πρόγραμμα για να τρέχεις τα tests.

Και οι δύο περιγράφονται με περισσότερες λεπτομέρειες εδώ: https://exercism.org/tracks/objective-c/tests
