# Εισαγωγή

Οι ακέραιοι είναι αριθμοί χωρίς δεκαδικό μέρος.

Οι τύποι ακεραίων μπορούν είτε να αποθηκεύουν μόνο θετικούς αριθμούς (μη προσημασμένοι) είτε να αποθηκεύουν θετικούς και αρνητικούς αριθμούς (προσημασμένοι).

Για παράδειγμα, -6, 0, 1, 25 και 976.

Σημείωσε ότι μπορείς να χρησιμοποιήσεις κάτω παύλες για να βελτιώσεις την αναγνωσιμότητα των μεγαλύτερων αριθμών: `1_000_000`.
