Νέος χρόνος, νέα πρόκληση!

Είναι 2024 και είμαι πραγματικά ενθουσιασμένος που ανακοινώνω ότι ξεκινάμε μια ολοκαίνουργια, ετήσια πρόκληση για να σε κρατάμε σε φόρμα στο ταξίδι σου στον προγραμματισμό: [#48in24](https://exercism.org/challenges/48in24)!

Λοιπόν, μην πανικοβάλλεσαι, δεν ανεβάζουμε τον πήχη ζητώντας σου να μάθεις 48 γλώσσες προγραμματισμού φέτος, για να αντιγράψεις αυτό που κάναμε με το #12in23. Αυτό θα ήταν παράλογο ακόμα και για τα δικά μας δεδομένα. Αντ' αυτού, σε προκαλούμε να λύσεις και να εμβαθύνεις σε 48 διαφορετικές ασκήσεις μέσα στη χρονιά.

Κάθε εβδομάδα θα αποκαλύπτουμε μια νέα επιλεγμένη άσκηση για να δοκιμάσεις. Και για κάθε άσκηση μπορείς να κερδίσεις τρία βραβεία:
Χάλκινο: Ολοκληρώνεις την άσκηση σε οποιαδήποτε γλώσσα.
Ασημένιο: Ολοκληρώνεις την άσκηση σε οποιεσδήποτε τρεις γλώσσες.
Χρυσό: Παίρνεις το ασημένιο και επιπλέον έχεις ολοκληρώσει (είτε στο παρελθόν είτε φέτος) την άσκηση στις τρεις επιλεγμένες γλώσσες. 

Μπορείς να ολοκληρώσεις τις ασκήσεις οποιαδήποτε στιγμή μέσα στη χρονιά. Ωστόσο, θα προσπαθήσουμε να ποικίλλουμε τις δυσκολίες και τα είδη των εργασιών μέσα στη χρονιά, οπότε αν τις ολοκληρώσεις με τη σειρά, θα νιώσεις μια πιο ενδιαφέρουσα και ποικίλη εμπειρία!

Ο στόχος δεν είναι απλώς να λύσεις την άσκηση, αλλά να αξιοποιήσεις την ευκαιρία για να εμβαθύνεις πραγματικά στους διαφορετικούς τρόπους με τους οποίους μπορεί να λυθεί: να ζυγίσεις διαφορετικούς συμβιβασμούς και προσεγγίσεις και, ιδανικά, να τη δοκιμάσεις σε διαφορετικές γλώσσες (π.χ. να δοκιμάσεις μια αντικειμενοστρεφή προσέγγιση, μια συναρτησιακή προσέγγιση, μια προσέγγιση βασισμένη στη λογική κ.λπ.). Θα ενθαρρύνουμε τον κόσμο να ζητάει καθοδήγηση πάνω στην άσκηση και να τη συζητάει στο φόρουμ και στο Discord.

Θα αξιοποιήσουμε επίσης αυτή την ευκαιρία για να προσανατολίσουμε την κοινότητά μας που συνεισφέρει στη δημιουργία περιεχομένου γύρω από κάθε επιλεγμένη άσκηση. Πριν από την εβδομαδιαία αποκάλυψη, θα ζητάμε από την κοινότητα να γράψει νέες Προσεγγίσεις και Άρθρα, να καταγράψει αναλυτικά βίντεο και να διασφαλίσει ότι η άσκηση είναι ενημερωμένη για εκείνη τη διαδρομή. Ως βασική ομάδα, θα ελέγχουμε και θα βελτιώνουμε επίσης τις οδηγίες των ασκήσεων και θα καταγράφουμε τις δικές μας εξερευνήσεις των ασκήσεων, ανεξάρτητες από τη γλώσσα, κοιτάζοντας μερικούς από τους ενδιαφέροντες διαφορετικούς τρόπους με τους οποίους μπορούν να λυθούν.

Οι ασκήσεις θα κυκλοφορούν κάθε Τρίτη και η πρώτη θα είναι στις 16 Ιανουαρίου. Θα συνεχίσουμε να κυκλοφορούμε μία την εβδομάδα μέχρι να φτάσουμε τις 48 τον Δεκέμβριο, δίνοντας στον κόσμο τις τελευταίες δύο εβδομάδες της χρονιάς για να τακτοποιήσει ό,τι έμεινε (και να κάνει διακοπές!) 

Μπορείς να δηλώσεις συμμετοχή στην πρόκληση στο [https://exercism.org/challenges/48in24](https://exercism.org/challenges/48in24). Τα λέμε μέσα!
