# Εισαγωγή

Οι αριθμοί κινητής υποδιαστολής είναι αριθμοί με ένα ή περισσότερα ψηφία μετά την υποδιαστολή. Χρησιμοποιούν τη μορφή κινητής υποδιαστολής διπλής ακρίβειας 64 bit.

```elixir
float = 3.45
# => 3.45
```

## Εργασία με αριθμούς

Στα module [`Integer`][integer-functions] και [`Float`][float-functions] μπορείς να βρεις μερικές χρήσιμες συναρτήσεις για να δουλεύεις με αυτούς τους τύπους. Οι βασικοί αριθμητικοί τελεστές ορίζονται στο module [`Kernel`][kernel-arithmetic-operators].

## Μετατροπή

Οι ακέραιοι και οι αριθμοί κινητής υποδιαστολής μπορούν να αναμειχθούν σε μία μόνο αριθμητική παράσταση. Η χρήση ενός αριθμού κινητής υποδιαστολής σε μια παράσταση εξασφαλίζει ότι το αποτέλεσμα θα είναι επίσης αριθμός κινητής υποδιαστολής.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Ωστόσο, όταν κάνεις διαίρεση, το αποτέλεσμα θα είναι πάντα αριθμός κινητής υποδιαστολής, ακόμα κι αν χρησιμοποιείς μόνο ακέραιους.

```elixir
6 / 2
# => 3.0
```

Για να μετατρέψεις έναν αριθμό κινητής υποδιαστολής σε ακέραιο, μπορείς να απορρίψεις το δεκαδικό μέρος με τη [`trunc/1`][trunc-1].
