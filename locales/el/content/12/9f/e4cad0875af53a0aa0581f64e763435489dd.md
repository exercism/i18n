# Σχετικά

Μπορείς να κάνεις επανάληψη πάνω στο [concept:csharp/enumerables]() χρησιμοποιώντας έναν [`foreach` βρόχο][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Ένας `foreach` βρόχος αποτελείται από τρία μέρη:

1. Τη δήλωση: ορίζεις τη μεταβλητή που θα περιέχει την τιμή της επανάληψης. Αυτή η μεταβλητή μπορεί να χρησιμοποιηθεί (μόνο) μέσα στον βρόχο.
2. Το αντικείμενο προς επανάληψη: το αντικείμενο πάνω στο οποίο μπορεί να γίνει επανάληψη.
3. Το σώμα του βρόχου.

## Βρόχος `for` εναντίον βρόχου `foreach`

Ωστόσο, γενικά ένας `foreach` βρόχος είναι προτιμότερος από έναν `for` βρόχο για τους παρακάτω λόγους:

- Ένας `foreach` βρόχος εγγυάται ότι θα κάνει επανάληψη πάνω σε _όλες_ τις τιμές. Με έναν `for` βρόχο, είναι εύκολο να παραλείψεις στοιχεία, για παράδειγμα εξαιτίας ενός σφάλματος κατά ένα.
- Ένας `foreach` βρόχος είναι πιο _δηλωτικός_: ο κώδικάς σου δηλώνει _τι_ θέλεις να κάνει, αντί ενός `for` βρόχου που δηλώνει _πώς_ θέλεις να το κάνεις.
- Ένας `foreach` βρόχος δεν αφήνει περιθώριο για λάθη, ενώ με τους `for` βρόχους είναι εύκολο να κάνεις σφάλμα κατά ένα.
- Ένας `foreach` βρόχος λειτουργεί με όλους τους τύπους συλλογών, συμπεριλαμβανομένων εκείνων που δεν υποστηρίζουν τη χρήση θέσης για την πρόσβαση στα στοιχεία.

Για να εγγυηθεί ότι ένας `foreach` βρόχος θα κάνει επανάληψη πάνω σε _όλες_ τις τιμές, ο μεταγλωττιστής δεν επιτρέπει την ενημέρωση μιας συλλογής μέσα σε έναν `foreach` βρόχο:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Ένας `for` βρόχος έχει πράγματι κάποια πλεονεκτήματα έναντι ενός `foreach` βρόχου:

- Μπορείς να ξεκινήσεις ή να σταματήσεις στη θέση που θέλεις.
- Μπορείς να χρησιμοποιήσεις οποιαδήποτε συνθήκη τερματισμού (Boolean) θέλεις.
- Μπορείς να παραλείψεις στοιχεία προσαρμόζοντας την αύξηση της μεταβλητής του βρόχου.
- Μπορείς να επεξεργαστείς συλλογές από το τέλος προς την αρχή μετρώντας αντίστροφα.
- Μπορείς να χρησιμοποιήσεις `for` βρόχους σε σενάρια που δεν περιλαμβάνουν συλλογές.

Σχετικά θέματα:

- Να έχεις υπόψη σου ότι η C# υποστηρίζει [πολυδιάστατους πίνακες][multi-dimensional-arrays] όπως `int[,] arr = new int[10, 5]`, οι οποίοι μπορεί να είναι πολύ χρήσιμοι.
- Να έχεις επίσης υπόψη σου ότι μπορείς να δημιουργήσεις στιγμιότυπα αντικειμένων τύπου [`System.Array`][system-array-object] με το `Array.CreateInstance`. Τέτοια αντικείμενα έχουν μικρή χρησιμότητα, κυρίως για διαλειτουργικότητα με κώδικα VB.NET. Δεν είναι εναλλάξιμα με τους τυπικούς πίνακες (`T[]`). Μπορούν να έχουν μη μηδενικό κατώτερο όριο.

Και τα δύο παραπάνω θέματα συζητούνται πιο αναλυτικά σε επόμενη άσκηση.
