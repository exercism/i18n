# Ο τύπος πλειάδας

Η πλειάδα είναι ένας ευέλικτος και αποδοτικός σύνθετος τύπος δεδομένων στη Cairo, που σου επιτρέπει να ομαδοποιείς πολλαπλές τιμές διαφορετικών τύπων σε μία οντότητα.
Οι πλειάδες έχουν σταθερό μήκος: μόλις δηλωθούν, το μέγεθός τους δεν μπορεί να αλλάξει.

## Δημιουργία πλειάδων

Για να δημιουργήσεις μια πλειάδα, γράφεις μια λίστα τιμών χωρισμένων με κόμμα μέσα σε παρενθέσεις.
Κάθε θέση στην πλειάδα έχει έναν συγκεκριμένο τύπο, και αυτοί οι τύποι μπορούν να διαφέρουν μεταξύ τους.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

Μια πλειάδα μπορεί να περιέχει πολλαπλές τιμές διαφορετικών τύπων δεδομένων, ακόμη και άλλες πλειάδες.
Για παράδειγμα:

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

Εδώ, η μεταβλητή `nested_tup` είναι μια πλειάδα που περιέχει δύο πλειάδες, δείχνοντας ότι οι πλειάδες μπορούν να έχουν άλλες πλειάδες ως στοιχεία.

## Αποδόμηση πλειάδων

Για να αποκτήσεις πρόσβαση στις επιμέρους τιμές μιας πλειάδας, μπορείς να χρησιμοποιήσεις αντιστοίχιση προτύπων για να την αποδομήσεις.
Έτσι η πλειάδα σπάει στα συστατικά της μέρη.

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## Ταυτόχρονη δήλωση και αποδόμηση

Μπορείς επίσης να δηλώσεις και να αποδομήσεις μια πλειάδα ταυτόχρονα.

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## Ο τύπος μονάδας `()`

Ο τύπος μονάδας είναι ένας ειδικός τύπος στη Cairo που έχει μόνο μία τιμή: `()`.
Αντιπροσωπεύεται από μια πλειάδα χωρίς στοιχεία.
Το μέγεθος του τύπου μονάδας είναι πάντα μηδέν και είναι εγγυημένο ότι δεν υπάρχει στον μεταγλωττισμένο κώδικα.

Στη Cairo, κάθε έκφραση επιστρέφει μια τιμή, και όταν μια έκφραση δεν επιστρέφει τίποτα, επιστρέφει σιωπηρά `()`.
Αυτό μπορεί να είναι χρήσιμο για συναρτήσεις που πρέπει να επιστρέψουν μια τιμή αλλά δεν έχουν κάποια ουσιαστική τιμή να επιστρέψουν.

## Δήλωση ονομασμένου τύπου πλειάδας

Μια ονομασμένη πλειάδα σου επιτρέπει να δημιουργήσεις ένα πιο περιγραφικό ψευδώνυμο τύπου για μια πλειάδα, βελτιώνοντας την αναγνωσιμότητα του κώδικα.

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

Σε αυτό το παράδειγμα, το `Point` είναι ένας ονομασμένος τύπος πλειάδας που αντιπροσωπεύει ένα ζεύγος ανυπόγραφων ακέραιων 32 bit, κάνοντας τον κώδικα πιο εκφραστικό.
