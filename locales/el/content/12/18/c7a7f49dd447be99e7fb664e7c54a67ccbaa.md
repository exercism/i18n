# Συνθήκες

Μια **συνθήκη** διαλέγει ανάμεσα σε δύο πορείες δράσης ανάλογα με το αν κάτι είναι αληθές.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Διαβάζοντάς το: `if`, μετά μια ερώτηση που απαντά `true` ή `false`, μετά `then`. Οι γραμμές μετά το `then` εκτελούνται όταν η απάντηση είναι αληθής, και οι γραμμές μετά το `else` εκτελούνται όταν είναι ψευδής. Το `end;` κλείνει όλο το κομμάτι.

## Περισσότεροι από δύο τρόποι

Το `elsif` προσθέτει άλλη μια ερώτηση, που τίθεται μόνο όταν οι πιο πάνω βγήκαν ψευδείς.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Η σειρά έχει σημασία. Μια βαθμολογία `9` πιάνεται από την πρώτη ερώτηση και δεν φτάνει ποτέ στη δεύτερη, παρόλο που το `9 >= 5` είναι επίσης αληθές. Το συνηθισμένο λάθος είναι να γράψεις τους ελέγχους με λάθος σειρά.

Γράφεται `elsif`, όχι `elseif`, και όχι `else if`.

## Παραλείποντας το else

Το `else` μπορεί να παραλειφθεί όταν δεν υπάρχει τίποτα να κάνεις σε αυτή την περίπτωση.

```sather
   if late then
      apologise;
   end;
```

Μια ρουτίνα που πρέπει να επιστρέφει κάτι χρειάζεται κάθε διαδρομή να επιστρέφει, οπότε σε αυτή την άσκηση κάθε `if` κρατάει το `else` του.
