# Χρήση του `||` αντί για if-else

Όταν θέλεις να αλλάξεις μια τιμή αν αυτή περιέχει `nil` ή οποιαδήποτε άλλη ψευδή τιμή, χρησιμοποίησε τον τελεστή `||` αντί για μια εντολή if-else.
Αυτό είναι πιο ιδιωματικό και πιο συνοπτικό, αλλά και πιο αποδοτικό.

Ο τελεστής `||` επιστρέφει την τιμή στα αριστερά του τελεστή αν αυτή είναι αληθής, αλλιώς επιστρέφει την τιμή στα δεξιά του τελεστή.

Για παράδειγμα:

```crystal
# Rather than:
value.nil? ? "default" : value

# Consider:
value || "default"
```
