# Υποδείξεις

## Γενικά

- Οι [πλειάδες][tuple-module] είναι δομές δεδομένων που είναι διατεταγμένες σε συνεχόμενη μνήμη και μπορούν να περιέχουν οποιονδήποτε τύπο δεδομένων.
- Τα άτομα μπορούν να χρησιμοποιηθούν για να δηλώσουν πεπερασμένες καταστάσεις, όπως σε αυτή την άσκηση χρησιμοποιούνται τα `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter` για να δηλώσουν τις μονάδες που χρησιμοποιούνται.
- Μπορείς να χρησιμοποιήσεις συναρτήσεις του [`Kernel`][elem] ή του [`Tuple`][tuple-module] ή αντιστοίχιση προτύπων για να χειριστείς τις πλειάδες.

## 1. Πάρε το αριθμητικό στοιχείο από ένα ζεύγος όγκου

- Σκέψου να χρησιμοποιήσεις [μια συνάρτηση του αρθρώματος `Kernel`][elem] για να επιστρέψεις το αριθμητικό στοιχείο του ζεύγους όγκου.

## 2. Μετέτρεψε το ζεύγος όγκου σε χιλιοστόλιτρα

- Χρησιμοποίησε [συναρτήσεις με πολλαπλές ρήτρες][multi-clause] και [αντιστοίχιση προτύπων][pattern-matching] για να μειώσεις τη λογική ροής ελέγχου με συνθήκες.
- Υλοποίησε τη συνάρτηση για όλες τις μονάδες προς χιλιοστόλιτρα, συμπεριλαμβανομένων των χιλιοστολίτρων προς χιλιοστόλιτρα.

## 3. Μετέτρεψε το ζεύγος όγκου με χιλιοστόλιτρα σε άλλη μονάδα

- Χρησιμοποίησε [συναρτήσεις με πολλαπλές ρήτρες][multi-clause] και [αντιστοίχιση προτύπων][pattern-matching] για να μειώσεις τη λογική ροής ελέγχου με συνθήκες.
- Υλοποίησε τη συνάρτηση για χιλιοστόλιτρα προς όλες τις μονάδες, συμπεριλαμβανομένων των χιλιοστολίτρων προς χιλιοστόλιτρα.

## 4. Μετέτρεψε από οποιαδήποτε μονάδα σε οποιαδήποτε μονάδα

- Επανάχρησιμοποίησε τις συναρτήσεις που έχεις ήδη δημιουργήσει για να κάνεις τη μετατροπή στη συνάρτηση `convert/2`.
