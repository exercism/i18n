# Εισαγωγή

Ένα `String` στη Java είναι ένα αντικείμενο που αναπαριστά αμετάβλητο κείμενο ως ακολουθία χαρακτήρων Unicode (γράμματα, ψηφία, σημεία στίξης κ.λπ.).
Χρησιμοποιείς διπλά εισαγωγικά για να ορίσεις ένα στιγμιότυπο `String`:

```java
String fruit = "Apple";
```

Χειρίζεσαι τις συμβολοσειρές καλώντας τις μεθόδους τους.
Μόλις δημιουργηθεί μια συμβολοσειρά, η τιμή της δεν μπορεί να αλλάξει ποτέ.
Όποιες μέθοδοι φαίνεται να τροποποιούν μια συμβολοσειρά, στην πραγματικότητα επιστρέφουν μια νέα συμβολοσειρά.
Η κλάση `String` παρέχει μερικές _static_ μεθόδους για να μετασχηματίσεις τις συμβολοσειρές.
