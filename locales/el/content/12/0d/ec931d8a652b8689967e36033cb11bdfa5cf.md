# Εισαγωγή

Θα υποθέσουμε ότι γνωρίζεις τη σύνταξη και τους τύπους δεδομένων της JSON.

Το jq λειτουργεί περνώντας τα εισερχόμενα δεδομένα JSON μέσα από μία _μεμονωμένη έκφραση_ (γραμμένη ως _σωλήνωση φίλτρων_) για να πετύχεις τα επιθυμητά μετασχηματισμένα δεδομένα.

<!-- prettier-ignore -->
~~~~exercism/note
Η γλώσσα `jq` υλοποιείται από το _πρόγραμμα_ `jq`.
Αυτό το πρόγραμμα παρέχει αρκετές βολικές επιλογές γραμμής εντολών για να ελέγχεις πώς καταναλώνεται η είσοδος και πώς παρουσιάζεται η έξοδος.

Στα παρακάτω παραδείγματα θα συναντήσεις:

- `-n` ή `--null-input`

    Κανονικά στο πρόγραμμα `jq` δίνεται ένα αρχείο για ανάγνωση ή στέλνεις δεδομένα στην είσοδό του.
    Η επιλογή `--null-input` σου επιτρέπει να παράγεις δεδομένα JSON χωρίς καμία είσοδο.

- `-c` ή `--compact-output`

    Το `jq` από προεπιλογή εκτυπώνει την έξοδό του με ωραία μορφοποίηση.
    Είναι εξαιρετικά χρήσιμο για τους ανθρώπους να βλέπουν τα δεδομένα όταν είναι όμορφα μορφοποιημένα.
    Ωστόσο αυτό δεν είναι απαραίτητο για τις μηχανές: η επιλογή `--compact-output` αφαιρεί τα κενά μορφοποίησης για να ελαχιστοποιήσει το μέγεθος του JSON που προκύπτει.

- `-f filename` ή `--from-file filename`

    Διάβασε το πρόγραμμα `jq` από το `filename` αντί να το δίνεις στη γραμμή εντολών.
    Τα `sed` και `awk` χρησιμοποιούν και τα δύο την επιλογή `-f` για τον ίδιο σκοπό.
    Θα το δεις να χρησιμοποιείται στα σενάρια δοκιμών για τις ασκήσεις πρακτικής.

Το υπόλοιπο αυτής της ενότητας θα επικεντρωθεί στη _γλώσσα_ `jq`.
~~~~

## Φίλτρα και σωλήνες

Τα **φίλτρα** είναι επίσης γνωστά ως **εκφράσεις**.

Ένα _φίλτρο_ παίρνει μια είσοδο και παράγει μια έξοδο.
Όπως όταν δουλεύεις σε ένα unix shell, μπορείς να ενώσεις _φίλτρα_ με έναν σωλήνα `|` για να συνδέσεις την έξοδο ενός _φίλτρου_ με την είσοδο ενός άλλου.

## Το φίλτρο ταυτότητας: `.`

Αυτό είναι το πιο απλό _φίλτρο_.
Απλώς περνά την είσοδό του στην έξοδό του.

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## Πίνακες

Αυτή θα είναι μια γρήγορη εισαγωγή στην εργασία με **πίνακες**.
Θα καλύψουμε αυτό το θέμα με περισσότερες λεπτομέρειες αργότερα.

Τα στοιχεία του _πίνακα_ προσπελαύνονται με αγκύλες και οι θέσεις τους ξεκινούν από το μηδέν.

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

Ένα _φίλτρο_ μπορεί να φτιάξει έναν _πίνακα_ τυλίγοντας μια έκφραση σε `[` και `]`

- με μια γνωστή λίστα στοιχείων:

  ```sh
  jq -n '[1, 2, 3]'
  ```

- για να συγκεντρώσεις μια ροή στοιχείων: για παράδειγμα,
  η `range` είναι μια συνάρτηση που παράγει μια ροή αριθμών

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  Χρησιμοποιώντας το `[]` συγκεντρώνεις τα αποτελέσματα της έκφρασης σε έναν πίνακα

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## Το κόμμα είναι τελεστής

Το _κόμμα_ δεν είναι απλώς σύνταξη που χωρίζει στοιχεία _πίνακα_.
Το **κόμμα** είναι ένας **τελεστής** που ενώνει ροές.

Για παράδειγμα το `[1, 2, 3]` είναι ένα _φίλτρο_ που χρησιμοποιεί τον κατασκευαστή _πίνακα_ `[]` για να συγκεντρώσει το αποτέλεσμα της ένωσης των τριών εκφράσεων `1`, `2` και `3`.

Πρόσεξες τα semicolons στο `range(10; 70; 15)` παραπάνω;
Επειδή τα _κόμματα_ έχουν συγκεκριμένο σκοπό στη γλώσσα `jq`, οι συναρτήσεις που παίρνουν πολλά ορίσματα χρησιμοποιούν semicolons για να χωρίσουν τα ορίσματα.

## Αντικείμενα

Μια γρήγορη εισαγωγή στα **αντικείμενα**.

Όπως σε πολλές γλώσσες προγραμματισμού, χρησιμοποίησε τελείες για να προσπελάσεις τις ιδιότητες ενός _αντικειμένου_

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
Οι αγκύλες μπορούν να χρησιμοποιηθούν και για _αντικείμενα_, αλλά τότε χρειάζονται εισαγωγικά για τις κυριολεκτικές συμβολοσειρές.
Αυτή είναι μια μέθοδος για να δουλεύεις με κλειδιά που περιέχουν κενά.

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

Μπορείς να κατασκευάσεις ένα _αντικείμενο_ με `{}` και ζεύγη `key: value`.
Δεν απαιτούνται εισαγωγικά γύρω από _κλειδιά_ που είναι "απλές" συμβολοσειρές.

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

παράγει

```none
{
  "question": 54,
  "answer": 42
}
```

Για να χειριστείς το _κλειδί_ ως _έκφραση_, πρέπει να το τυλίξεις σε παρενθέσεις (το παρακάτω παράγει επίσης το ίδιο αποτέλεσμα όπως παραπάνω).

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## Σωληνώσεις

Για παράδειγμα, με δεδομένο το `file.json` που περιέχει

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

Ας υπολογίσουμε το μήκος του _πίνακα_ key2:

```sh
$ jq '.key2 | length' file.json
3
```

Διοχετεύουμε την έξοδο της έκφρασης `.key2` ως είσοδο στη `length`, η οποία όπως είναι αναμενόμενο παράγει τον αριθμό των στοιχείων του _πίνακα_.

## Τα φίλτρα μπορούν να αγνοούν την είσοδό τους

Σε αυτό το παράδειγμα, τα δεδομένα JSON εισόδου αγνοούνται και δεν επηρεάζουν την έξοδο:

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## Τα φίλτρα μπορούν να παράγουν ροές δεδομένων

Ένα _φίλτρο_ μπορεί να παράγει περισσότερες από μία τιμές.
Για παράδειγμα, το _φίλτρο_ `.[]` παράγει κάθε στοιχείο ενός _πίνακα_ ως ξεχωριστή τιμή:

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

Η διοχέτευση ενός τέτοιου _φίλτρου_ σε ένα άλλο θα εκτελέσει το δεύτερο _φίλτρο_ **_για κάθε τιμή_**:

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

Αυτό μοιάζει με έμμεση επανάληψη.
Μόλις κατανοήσεις αυτή την τεχνική, θα συνειδητοποιήσεις ότι τα πολύ ισχυρά _φίλτρα_ `jq` μπορούν να είναι πολύ συνοπτικά.

## Παρενθέσεις

Οι **παρενθέσεις** χρησιμοποιούνται για να ομαδοποιούν υποεκφράσεις μαζί και να επιβάλλουν τη σειρά των πράξεων, όπως ακριβώς σε άλλες γλώσσες.
Στο `jq`, η ανάγκη για αυτές μπορεί να φαίνεται κάπως απρόσμενη.

Για παράδειγμα, ας πούμε ότι θέλουμε να κατασκευάσουμε έναν _πίνακα_ με 2 στοιχεία: την τετραγωνική ρίζα του 9 και το _e_ υψωμένο στη δύναμη 1.
Οι δύο ξεχωριστές εκφράσεις είναι `9 | sqrt` και `1 | exp`.
Περιμένουμε η έξοδος να είναι ο _πίνακας_ `[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

Γιατί δεν πήραμε αυτό που περιμέναμε; Το `jq` το ερμηνεύει ως εξής:

```jq
[ ((9|sqrt), 1) | exp ]
```

Το `jq` φτιάχνει μια ροή δύο στοιχείων (`3` και `1`) που το καθένα δίνεται στο `exp`.

Πρέπει να διασφαλίσουμε ότι το `exp` παίρνει μόνο έναν αριθμό ως είσοδο.
Με άλλα λόγια, πρέπει να επιβάλουμε ο σωλήνας να αξιολογείται πριν από το κόμμα.

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## Συναρτήσεις και τελεστές

Χωρίς να μπούμε σε μεγάλο βάθος (οι συναρτήσεις θα είναι θέμα για άλλη άσκηση), να μερικές χρήσιμες ενσωματωμένες συναρτήσεις:

- `length`

  Δεδομένου ενός πίνακα ως είσοδο, παράγει τον αριθμό των στοιχείων του πίνακα.

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  Αυτός ο τελεστής κάνει διαφορετικά πράγματα ανάλογα με τον τύπο των τελεστέων του:
  προσθέτει αριθμούς,
  συνενώνει συμβολοσειρές,
  προσθέτει πίνακες,
  συγχωνεύει αντικείμενα.

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  Η `add` είναι μια συνάρτηση που παίρνει έναν πίνακα και επιστρέφει ένα στοιχείο με όλα τα στοιχεία αθροισμένα χρησιμοποιώντας τους κανόνες του `+`.
  Το `[1, 2, 3] | add` παράγει `6`.

- `map`

  Δεδομένου ενός πίνακα ως είσοδο και ενός φίλτρου ως όρισμα, παράγει έναν πίνακα όπου το φίλτρο εφαρμόζεται σε κάθε στοιχείο

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  Δεδομένης _κάποιας_ εισόδου και ενός φίλτρου ως όρισμα:
  - αν το φίλτρο που εφαρμόζεται στην είσοδο έχει ως αποτέλεσμα μια _αληθή_ τιμή, παράγει την είσοδο αμετάβλητη
  - διαφορετικά, δεν παράγει _τίποτα_ (όχι την τιμή `null`, πραγματικά καμία έξοδο)

  Για παράδειγμα, δεδομένων κάποιων αριθμών, επίλεξε εκείνους που διαιρούνται με το 3

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  Θυμήσου ότι η `range` παράγει μια _ροή_ αριθμών.
  Η `select` θα καλείται μία φορά για κάθε αριθμό.
  Μόνο οι αριθμοί που "περνούν" την έκφραση παράγονται.

  Συχνά χρειάζεται να επιλέξεις στοιχεία ενός πίνακα.
  Υπάρχουν μερικοί τρόποι να το κάνεις.

  Με είσοδο `["Anne", "Bob", "Cathy", "Dave"]`, επίλεξε τα ονόματα που έχουν μήκος 4.
  - χρησιμοποίησε `map` και `select` μαζί

    ```jq
    map(select(length == 4))
    ```

  - σπάσε τον πίνακα σε στοιχεία, εφάρμοσε `select` σε αυτή τη ροή και συγκέντρωσε τα αποτελέσματα

    ```jq
    [ .[] | select(length == 4) ]
    ```

## Σχόλια

Τα σχόλια ξεκινούν με τον χαρακτήρα `#` και συνεχίζουν μέχρι το τέλος της γραμμής.
