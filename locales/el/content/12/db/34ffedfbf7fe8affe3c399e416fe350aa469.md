# Οδηγίες

Σε αυτή την άσκηση θα φτιάξεις τη διαχείριση σφαλμάτων για μια απλή αριθμομηχανή ακεραίων. Για να απλοποιήσουμε τα πράγματα, παρέχονται μέθοδοι για τον υπολογισμό της πρόσθεσης, του πολλαπλασιασμού και της διαίρεσης.

Ο στόχος είναι να έχεις μια αριθμομηχανή που λειτουργεί και επιστρέφει μια συμβολοσειρά με το εξής μοτίβο: `16 + 51 = 67`, όταν της δίνονται τα ορίσματα `16`, `51` και `+`.

```csharp
SimpleCalculator.Calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator.Calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator.Calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. Υλοποίησε τις πράξεις της αριθμομηχανής

Η κύρια μέθοδος που θα υλοποιήσεις σε αυτή την εργασία θα είναι η (_στατική_) μέθοδος `SimpleCalculator.Calculate()`. Δέχεται τρία ορίσματα. Τα δύο πρώτα ορίσματα είναι ακέραιοι αριθμοί πάνω στους οποίους θα εκτελεστεί μια πράξη. Το τρίτο όρισμα είναι τύπου συμβολοσειράς και για αυτή την άσκηση χρειάζεται να υλοποιήσεις τις εξής πράξεις:

- η πρόσθεση χρησιμοποιώντας τη συμβολοσειρά `+`
- ο πολλαπλασιασμός χρησιμοποιώντας τη συμβολοσειρά `*`
- η διαίρεση χρησιμοποιώντας τη συμβολοσειρά `/`

## 2. Χειρίσου τις μη έγκυρες πράξεις

Οποιοδήποτε άλλο σύμβολο πράξης θα πρέπει να πετάει την εξαίρεση `ArgumentOutOfRangeException`. Αν το όρισμα της πράξης είναι κενή συμβολοσειρά, τότε η μέθοδος θα πρέπει να πετάει την εξαίρεση `ArgumentException`. Όταν δίνεται `null` ως όρισμα πράξης, τότε η μέθοδος θα πρέπει να πετάει την εξαίρεση `ArgumentNullException`.

```csharp
SimpleCalculator.Calculate(100, 10, "-"); // => throws ArgumentOutOfRangeException

SimpleCalculator.Calculate(8, 2, ""); // => throws ArgumentException

SimpleCalculator.Calculate(58, 6, null); // => throws ArgumentNullException
```

## 3. Χειρίσου τα σφάλματα όταν διαιρείς με το μηδέν

Όταν προσπαθείς να διαιρέσεις με το `0`, η αριθμομηχανή θα πρέπει να επιστρέφει μια συμβολοσειρά με περιεχόμενο `Division by zero is not allowed.`. Καμία άλλη εξαίρεση δεν θα πρέπει να χειρίζεται η μέθοδος `SimpleCalculator.Calculate()`.

```csharp
SimpleCalculator.Calculate(512, 0, "/"); // => returns "Division by zero is not allowed."
```
