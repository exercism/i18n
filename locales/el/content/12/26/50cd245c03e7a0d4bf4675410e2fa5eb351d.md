# Συνένωση συμβολοσειρών

Η συνένωση συμβολοσειρών είναι απολύτως αποδεκτή στη Ruby, αλλά ένας πιο συνηθισμένος τρόπος για να συνθέσεις μια συμβολοσειρά είναι η [παρεμβολή συμβολοσειρών](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Για παράδειγμα:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
