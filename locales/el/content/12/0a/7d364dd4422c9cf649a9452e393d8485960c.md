# Προσθήκη στις οδηγίες

## Καταχωρητές

| Καταχωρητής | Χρήση          | Τύπος     | Περιγραφή                              |
| ----------- | -------------- | --------- | -------------------------------------- |
| `$a0`       | είσοδος        | ακέραιος  | όριο                                   |
| `$a1`       | είσοδος/έξοδος | διεύθυνση | πίνακας προορισμού για πρώτους αριθμούς |
| `$v0`       | έξοδος         | ακέραιος  | πλήθος πρώτων αριθμών                  |
| `$t0-9`     | προσωρινός     | οτιδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
