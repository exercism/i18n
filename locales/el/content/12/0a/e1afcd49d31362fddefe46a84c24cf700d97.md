# Εισαγωγή

Η Perl είναι μια γλώσσα προγραμματισμού που δημιούργησε ο Larry Wall και κυκλοφόρησε για πρώτη φορά το 1987.

## Packages και Modules

Ένα package είναι μια συλλογή κώδικα, που συχνά περιέχεται σε ένα αρχείο module με το ίδιο όνομα και την επέκταση `.pm`.
Στη συνέχεια, το module μπορεί να εισαχθεί σε ένα άλλο αρχείο, συνήθως με τη λέξη-κλειδί `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Μεταβλητές

Υπάρχουν μεταβλητές τριών τύπων: scalar (`$foo`), πίνακες (`@bar`) και hash (`%baz`).
Για να κρατήσουμε τα πράγματα απλά, εδώ θα χρησιμοποιήσουμε μόνο μεταβλητές scalar.
Μια τιμή scalar μπορεί να είναι ένα από τα εξής: μια συμβολοσειρά, ένας αριθμός, ένα Boolean (λογική τιμή) ή μια [αναφορά][perlreftut] σε κάτι.
Η απουσία τιμής είναι `undef`.


Οι λέξεις-κλειδιά `my` και `our` δηλώνουν μια μεταβλητή στο λεκτικό πεδίο, π.χ. `my $foo;`.
Με το `our`, η μεταβλητή αποκτά επίσης ψευδώνυμο προς μια μεταβλητή package με το ίδιο όνομα.
Υπάρχουν κι άλλοι τρόποι δήλωσης μεταβλητών, που δεν θα καλύψουμε εδώ.

Μπορείς να αναθέσεις τιμή σε μια μεταβλητή με τον τελεστή `=`, π.χ. `$foo = 1;`, κάτι που μπορείς να κάνεις ταυτόχρονα με τη δήλωση της μεταβλητής, π.χ. `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Υπορουτίνες

Η λέξη-κλειδί `sub` δηλώνει μια [υπορουτίνα][perlsub].
Η λέξη-κλειδί `return` τερματίζει την υπορουτίνα, δίνοντας τις καθορισμένες τιμές ή μια κενή λίστα αν δεν δοθεί τίποτα.
Χωρίς ρητό `return`, η τιμή που επιστρέφεται καθορίζεται από το πλαίσιο (scalar, λίστα ή void) της υπορουτίνας που χρησιμοποιείται και από την τελευταία της εντολή.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Οι πρόσφατες εκδόσεις της Perl σου επιτρέπουν να ορίσεις τυπικές παραμέτρους σε μια [υπογραφή][perlsubsig].
Η λίστα παραμέτρων μπορεί να περιέχει μεταβλητές τύπου scalar, πίνακα ή hash.
Μια κενή λίστα παραμέτρων σημαίνει ότι η υπορουτίνα δέχεται μηδέν ορίσματα.
Οι παλαιότερες εκδόσεις της Perl απαιτούσαν να πάρεις τα ορίσματα από την ειδική μεταβλητή `@_`, κάτι που δεν θα καλύψουμε εδώ.
