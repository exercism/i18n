# Σχετικά

Στην Common Lisp, μια λίστα παραμέτρων (όπως αυτή για τον ορισμό μιας συνάρτησης) είναι επίσης γνωστή ως [λίστα λάμδα][lambda-list].
Οι λίστες λάμδα χρησιμοποιούνται επίσης για τον ορισμό μακροεντολών και για την αποδόμηση.

Οι λίστες λάμδα μπορούν να περιέχουν [λέξεις-κλειδιά λίστας λάμδα][lambda-list-keyword] όπως `&rest`, `&optional`, `&key` και άλλα.

Ενώ πολλαπλοί τύποι παραμέτρων μπορούν να συνδυαστούν με άλλους τύπους παραμέτρων (προαιρετικές παραμέτρους και παραμέτρους με λέξεις-κλειδιά), αυτό μπορεί να είναι προβληματικό και θα πρέπει να γίνεται προσεκτικά.
Δες την ενότητα ["Ανάμειξη διαφορετικών τύπων παραμέτρων"][pcl-function] στο Practical Common Lisp.
