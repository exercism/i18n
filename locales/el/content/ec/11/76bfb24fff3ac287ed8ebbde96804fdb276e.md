# Εισαγωγή

Οι `Complex numbers` δεν είναι περίπλοκοι.
Απλώς χρειάζονται ένα λιγότερο ανησυχητικό όνομα.

Είναι τόσο χρήσιμοι, ειδικά στη μηχανική και στις επιστήμες, που η R συμπεριλαμβάνει τους [μιγαδικούς αριθμούς][web-complex] ως βασικούς [ατομικούς τύπους][ref-atomic], δίπλα στους integer, double, logical, character και raw.

## Τα βασικά

Ένας αριθμός `complex` στην R είναι μία μεμονωμένη τιμή.
Στην πράξη, ωστόσο, μπορεί να θεωρηθεί ως ένα ζεύγος αριθμών.
Αυτά ονομάζονται "πραγματικό" και "φανταστικό" μέρος, για ατυχείς ιστορικούς λόγους.
Και πάλι, το καλύτερο είναι να εστιάσεις στην υποκείμενη απλότητα και όχι στα παράξενα ονόματα.

Για να δημιουργήσεις μιγαδικούς αριθμούς από δύο πραγματικούς αριθμούς, απλώς πρόσθεσε το επίθημα `i` στο φανταστικό μέρος.

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

Για να δημιουργήσεις έναν μιγαδικό αριθμό από πραγματικές μεταβλητές, η παραπάνω σύνταξη δεν θα δουλέψει.
Γράφοντας `r + imi` μπερδεύεις τον συντακτικό αναλυτή, που νομίζει ότι το `imi` είναι ένα όνομα μεταβλητής (που δεν υπάρχει).

Είτε πολλαπλασίασε το φανταστικό μέρος με `1i`, είτε χρησιμοποίησε τη συνάρτηση [`complex()`][ref-complex]:

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

Μπορεί να αναρωτιέσαι, γιατί `i` και όχι `j`;

Οι περισσότεροι μηχανικοί προτιμούν το `j`.
Οι περισσότεροι επιστήμονες και μαθηματικοί προτιμούν τον μαθηματικό συμβολισμό `i` για το _φανταστικό_, αλλά αυτός ο συμβολισμός συγκρούεται με τη χρήση του `i` για το _ρεύμα_ στην Ηλεκτρολογία.

Η R διάλεξε το `i`, η Python διάλεξε το `j` και η Julia απέφυγε τη διαμάχη διαλέγοντας το `im`.
Πρόσεχε όταν αλλάζεις μεταξύ [STEM][wiki-STEM] γλωσσών προγραμματισμού.

Για να προσπελάσεις τα μέρη ενός μιγαδικού αριθμού ξεχωριστά:

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

Οποιοδήποτε από τα δύο μέρη μπορεί να είναι μηδέν, και οι μαθηματικοί μπορεί τότε να λένε ότι ο αριθμός είναι "καθαρά πραγματικός" ή "καθαρά φανταστικός".
Ωστόσο, στην R παραμένει ένας μιγαδικός αριθμός.

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

Μπορεί να έχεις ακούσει ότι "το `i` (ή το `j`) είναι η τετραγωνική ρίζα του -1".

Για την ώρα, αυτό σημαίνει μόνο ότι το φανταστικό μέρος _εξ ορισμού_ ικανοποιεί την παρακάτω ισότητα:

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

Είναι μια απλή ιδέα, αλλά οδηγεί σε ενδιαφέρουσες συνέπειες.

## Αριθμητική

Οι περισσότεροι από τους [`operators`][ref-operators] που χρησιμοποιούνται με δεκαδικούς και ακέραιους λειτουργούν και με μιγαδικούς αριθμούς:

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

Η εξήγηση των κανόνων για τον πολλαπλασιασμό και τη διαίρεση μιγαδικών αριθμών είναι έξω από τα όρια αυτής της έννοιας (_και είναι απίθανο να χρειαστεί να κάνεις αυτές τις πράξεις "με το χέρι" πολύ συχνά_).

Οποιαδήποτε [μαθηματική][web-math-complex] ή [ηλεκτρολογική][web-engineering-complex] εισαγωγή στους μιγαδικούς αριθμούς θα το καλύπτει, αν θέλεις να εμβαθύνεις στο θέμα.

Εναλλακτικά, το Exercism έχει μια άσκηση εξάσκησης [`Complex Numbers`][exercise-complex-numbers], όπου μπορείς να υλοποιήσεις μια κλάση μιγαδικών αριθμών με αυτές τις πράξεις από τα βασικά.

Η ακέραια διαίρεση γενικά ___δεν___ είναι δυνατή στους μιγαδικούς αριθμούς, οπότε οι τελεστές `%/%` και `%%` θα αποτύχουν για τον τύπο μιγαδικών αριθμών.

## Συναρτήσεις

Οι περισσότερες μαθηματικές συναρτήσεις λειτουργούν με μιγαδικές εισόδους.

Ωστόσο, το να δίνεις πραγματικές εισόδους και να περιμένεις μιγαδική έξοδο συνήθως δεν θα δουλέψει.

```r
sqrt(z1)
#> [1] 1.414214+0.707107i

sqrt(-1)  # fails!
#> Warning in sqrt(-1) : NaNs produced
#> [1] NaN

sqrt(-1 + 0i)  # succeeds with complex input
#> [1] 0+1i

sin(z1)
#> [1] 3.752771+0.256554i
```

Υπάρχουν αρκετές συναρτήσεις, πέρα από τις `Re()` και `Im()`, με ιδιαίτερη σημασία για τους μιγαδικούς αριθμούς.

- Η `Conj()` απλώς αντιστρέφει το πρόσημο του φανταστικού μέρους ενός μιγαδικού αριθμού (_από + σε - ή αντίστροφα_).
  - Λόγω του τρόπου που λειτουργεί ο πολλαπλασιασμός μιγαδικών, αυτό είναι πιο χρήσιμο απ' όσο νομίζεις.
- Η `abs(<complex number>)` είναι εγγυημένο ότι επιστρέφει έναν πραγματικό αριθμό χωρίς φανταστικό μέρος (το "μέτρο" της), και η `Mod(<complex number>)` είναι συνώνυμη.
- Η `Arg(<complex number>)` επιστρέφει τη γωνία φάσης σε ακτίνια.

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
