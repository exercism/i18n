# Εισαγωγή

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] συγκρίνουν δύο τιμές του ίδιου τύπου και επιστρέφουν μια τιμή `Bool` (`true` ή `false`).
Αν προσπαθήσεις να συγκρίνεις τιμές διαφορετικών τύπων, ο μεταγλωττιστής θα πετάξει ένα σφάλμα.

Οι τυπικοί τελεστές σύγκρισης στη Swift είναι:

| Τελεστής | Περιγραφή              | Παράδειγμα         |
| -------- | ------------------------ | --------------- |
| `==`     | Ίσο με                 | `1 == 1` (αληθής) |
| `!=`     | Όχι ίσο με             | `1 != 2` (αληθής) |
| `<`      | Μικρότερο από                | `4 < 5`  (αληθής) |
| `<=`     | Μικρότερο ή ίσο με    | `4 <= 4` (αληθής) |
| `>`      | Μεγαλύτερο από             | `3 > 1`  (αληθής) |
| `>=`     | Μεγαλύτερο ή ίσο με | `2 >= 2` (αληθής) |

## Εντολές if και else

Μια [εντολή υπό συνθήκη][conditional-statement] εκτελεί κώδικα ανάλογα με το αν μια συνθήκη αξιολογείται σε `true` ή `false`.
Η πιο συνηθισμένη εντολή υπό συνθήκη είναι η [εντολή `if`][if], η οποία εκτελεί ένα μπλοκ κώδικα μόνο όταν η συνθήκη της είναι `true`.
Για να γράψεις μια εντολή `if`, χρησιμοποίησε τη λέξη-κλειδί `if`, ακολουθούμενη από τη συνθήκη και το μπλοκ κώδικα μέσα σε άγκιστρα:

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

Μπορείς να συνδυάσεις την `if` με μια ρήτρα `else` για να εκτελέσεις εναλλακτικό κώδικα όταν η συνθήκη είναι `false`:

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

Για να ελέγξεις πολλαπλές συνθήκες στη σειρά, σύνδεσε τις εντολές μεταξύ τους με `else if`.
Μια εντολή `if` δεν απαιτεί κλάδο `else`, αλλά μπορείς να συμπεριλάβεις έναν για να χειριστείς περιπτώσεις όπου καμία από τις συνθήκες δεν ταιριάζει:

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## Εκφράσεις if

Στη σύγχρονη Swift, οι εντολές `if` μπορούν επίσης να χρησιμοποιηθούν ως εκφράσεις που παράγουν μια τιμή.
Κάθε κλάδος αξιολογείται σε μια τιμή, οπότε μπορείς εύκολα να αναθέσεις αποτελέσματα με βάση μια συνθήκη:

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
