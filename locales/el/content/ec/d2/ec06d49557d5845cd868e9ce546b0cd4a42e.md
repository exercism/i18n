# Σχετικά

Το I/O της Factor είναι χτισμένο πάνω σε ένα μόνο [πρωτόκολλο][stream-protocol], το οποίο μπορεί να υλοποιήσει οποιαδήποτε πηγή ή αποδέκτης δεδομένων. Οι ενσωματωμένες ροές (`<file-reader>`, `<file-writer>`, `<string-reader>`, `<string-writer>`, υποδοχείς δικτύου, πίνακες byte, tty) είναι όλες κλάσεις που υλοποιούν τον ίδιο μικρό αριθμό generics από το [`io`][io] και επεκτείνουν το `disposable` από το [`destructors`][destructors].

```factor
USING: io ;

GENERIC: stream-read1        ( stream -- elt/f )
GENERIC: stream-read-unsafe  ( n buf stream -- count )
GENERIC: stream-write1       ( elt stream -- )
GENERIC: stream-write        ( seq stream -- )
GENERIC: stream-flush        ( stream -- )
GENERIC: stream-element-type ( stream -- type )
```

Το `stream-read-unsafe` είναι η μαζική ανάγνωση χαμηλού επιπέδου: γεμίζει ένα buffer που παρέχει ο καλών και επιστρέφει πόσα στοιχεία γράφτηκαν. Τα δημόσια `stream-read` και `stream-read-partial` είναι χτισμένα πάνω του και χειρίζονται την κατανομή μνήμης. Οι περισσότερες ροές που ορίζει ο χρήστης υλοποιούν είτε το `stream-read1` (όταν οι αναγνώσεις γίνονται ένα στοιχείο τη φορά) είτε το `stream-read-unsafe` (όταν οι αναγνώσεις μπορούν να γίνουν μαζικά).

Το `stream-element-type` επιστρέφει ένα από δύο μοναδικά tokens: `+byte+` για ροές byte (αναγνώστες αρχείων, υποδοχείς) και `+character+` για ροές χαρακτήρων (αναγνώστες συμβολοσειρών, tty). Μια ροή-περιτύλιγμα συνήθως απλώς αναθέτει στην υποκείμενη ροή της.

## Ένταξη στα mixins

```factor
INSTANCE: my-stream input-stream
INSTANCE: my-stream output-stream
```

Μια κλάση μπορεί να είναι το ένα, το άλλο ή και τα δύο. Η ένταξη στο mixin κάνει τις προεπιλεγμένες μεθόδους των `input-stream` / `output-stream` να δρομολογούνται στην κλάση σου. Είναι το ίδιο μοτίβο ανοιχτού mixin με το `set` από το vocab `sets`.

## Το framework του disposable

Το `new-disposable ( class -- disposable )` καταχωρίζει ένα νέο στιγμιότυπο στο τρέχον πεδίο των destructors, ώστε μια εξαίρεση στη μέση της προετοιμασίας πόρων να ξετυλίγεται καθαρά:

```factor
USING: destructors ;

[
    "log.txt" utf8 <file-writer>   ! registered automatically
    "log.txt" utf8 <file-reader>   ! and so is this one
    ! ... use them ...
] with-destructors
! both files closed even if an error is thrown above
```

Το `dispose` είναι η δημόσια λέξη· το `dispose*` είναι το generic που υλοποιεί η κλάση. Μια παράκαμψη σε υποκλάση του `dispose*` θα πρέπει να καθαρίζει τη δική της κατάσταση και μετά να κάνει dispose σε όποιους πόρους κατέχει:

```factor
M: my-stream dispose* underlying>> dispose ;
```

Το framework εγγυάται ότι το `dispose*` εκτελείται το πολύ μία φορά ανά αντικείμενο. Οι επανειλημμένες κλήσεις της `dispose` δεν κάνουν τίποτα.

## Προσπελαστές με εμβέλεια

Τρεις συνδυαστές ορίζουν την καθολική "τρέχουσα ροή εισόδου/εξόδου" που χρησιμοποιούν τα `print`, `read1` κ.λπ.:

```
with-input-stream   ( stream quot -- )    ! reads in quot use stream
with-output-stream  ( stream quot -- )    ! writes in quot use stream
with-disposal       ( disposable quot -- )! generic — any disposable
```

Ο καθένας κάνει dispose στον πόρο κατά την έξοδο, ακόμα κι αν το quotation πετάξει ένα σφάλμα. Έτσι χρησιμοποιεί ο περισσότερος κώδικας μια προσαρμοσμένη ροή, αντί να τη μεταβιβάζει σε κάθε κλήση.
