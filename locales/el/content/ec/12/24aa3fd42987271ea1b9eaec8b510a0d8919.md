# Εισαγωγή

Θυμήσου ότι το `jq` υποστηρίζει τους ίδιους τύπους δεδομένων με το JSON.
Το JSON περιγράφει τις **συμβολοσειρές** ως εξής:

> Μια συμβολοσειρά είναι μια ακολουθία από μηδέν ή περισσότερους χαρακτήρες Unicode, κλεισμένη σε διπλά εισαγωγικά, με χρήση διαφυγών backslash.

## Ακολουθίες διαφυγής

Μέσα σε μια συμβολοσειρά, χρησιμοποίησε τον χαρακτήρα backslash για να ενσωματώσεις "ειδικούς" χαρακτήρες:

- `\"` ένα κυριολεκτικό εισαγωγικό,
- `\\` ένα κυριολεκτικό backslash,
- χαρακτήρες κενού `\n`, `\t`, `\r`, `\f`, `\b`
- χαρακτήρες unicode `\uAAAA`, όπου το `A` είναι ένα δεκαεξαδικό ψηφίο

## Μήκος συμβολοσειράς

Για να βρεις τον αριθμό των χαρακτήρων, χρησιμοποίησε τη συνάρτηση `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Υποσυμβολοσειρές

Ο συμβολισμός **slice** μπορεί να χρησιμοποιηθεί για την εξαγωγή υποσυμβολοσειρών.
Η σύνταξη είναι `.[i:j]`.
Η υποσυμβολοσειρά που επιστρέφεται έχει μήκος `j - i` και περιέχει χαρακτήρες από τη θέση `i` (συμπεριλαμβανομένης) έως τη θέση `j` (μη συμπεριλαμβανομένης).
Κάθε θέση μπορεί να είναι αρνητική, οπότε μετράει ανάποδα από το τέλος της συμβολοσειράς.
Κάθε θέση μπορεί να παραλειφθεί, οπότε αναφέρεται στην αρχή ή στο τέλος της συμβολοσειράς.
Οι θέσεις ξεκινούν από το μηδέν.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Συνένωση

Χρησιμοποίησε το `+` για να ενώσεις συμβολοσειρές:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Χρησιμοποίησε το `add` όταν έχεις έναν πίνακα από συμβολοσειρές:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Διαχωρισμός και ένωση

Ο διαχωρισμός χρησιμοποιεί τη συνάρτηση `split/1` ή τον τελεστή `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

Το αντίστροφο του `split/1` είναι το `join/1`.

Η μετατροπή μιας συμβολοσειράς σε πίνακα χαρακτήρων χρειάζεται συχνά.
Υπάρχουν δύο τρόποι για να το κάνεις αυτό:

1. διαχωρισμός σε κενή συμβολοσειρά

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` σε πίνακα από _σημεία κώδικα_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   Το `implode` είναι το αντίστροφο του `explode`.

## Βρες τη θέση μιας υποσυμβολοσειράς

Χρησιμοποίησε τη συνάρτηση `index/1`· η θέση ξεκινά από το μηδέν.

```jq
"hello" | index("el")'   # => 1
```

Αν η υποσυμβολοσειρά δεν υπάρχει στη συμβολοσειρά, το αποτέλεσμα είναι `null`

```jq
"hello" | index("elk")   # => null
```

## Παρεμβολή συμβολοσειρών

Μέσα σε μια συμβολοσειρά, η ακολουθία `\(expression)` ενσωματώνει το _αποτέλεσμα_ αυτής της έκφρασης [στη συμβολοσειρά][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Μετατροπή πεζών/κεφαλαίων

Χρησιμοποίησε τις συναρτήσεις `ascii_downcase` και `ascii_upcase`.

## Κανονικές εκφράσεις

Το `jq` έχει πλούσια υποστήριξη για κανονικές εκφράσεις: αυτό θα είναι το θέμα μιας επόμενης ενότητας.
