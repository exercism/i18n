# Εισαγωγή

Ένα λεξικό είναι μια συλλογή στοιχείων όπου κάθε στοιχείο αποτελείται από ένα κλειδί και μια τιμή, έτσι ώστε αν ένα κλειδί περαστεί σε μια μέθοδο του λεξικού, να επιστρέφεται η τιμή που του αντιστοιχεί. Παίζει τον ίδιο ρόλο με τους χάρτες ή τους συσχετιστικούς πίνακες σε άλλες γλώσσες.

Ένα λεξικό μπορεί να δημιουργηθεί ως εξής:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

Ή

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Σημείωσε ότι οι τύποι του κλειδιού και της τιμής αποτελούν μέρος του ορισμού του λεξικού.

Μόλις δημιουργηθεί, μπορείς να προσθέσεις ή να αφαιρέσεις καταχωρήσεις από ένα λεξικό χρησιμοποιώντας τις ενσωματωμένες μεθόδους του `Add` και `Remove`.

Η ανάκτηση ή η ενημέρωση τιμών σε ένα λεξικό γίνεται με πρόσβαση στο λεξικό μέσω ενός κλειδιού:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Μπορείς να ελέγξεις αν υπάρχει ένα κλειδί στο λεξικό με:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Η απαρίθμηση σε ένα λεξικό θα απαριθμήσει τα ζεύγη κλειδιού/τιμής του. Τα λεξικά έχουν επίσης ιδιότητες που επιτρέπουν την απαρίθμηση των κλειδιών ή των τιμών τους.
