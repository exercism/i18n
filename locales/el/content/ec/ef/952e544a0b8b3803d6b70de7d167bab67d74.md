# Προσθήκη στις οδηγίες

## Μορφή εξόδου

Δώσε ως έξοδο την ηλικία σε εκατοστά του έτους.

Για παράδειγμα, 100 × 1.000.000.000 ÷ 31.557.600 ≈ 3.169, οπότε κάποιος που είναι 1.000.000.000 δευτερολέπτων έχει ηλικία `3169` εκατοστών του γήινου έτους.

## Καταχωρητές

| Καταχωρητής | Χρήση     | Τύπος    | Περιγραφή                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | είσοδος   | ακέραιος | πλανήτης (`0` = Ερμής, `1` = Αφροδίτη, `2` = Γη, `3` = Άρης, `4` = Δίας, `5` = Κρόνος, `6` = Ουρανός, `7` = Ποσειδώνας) |
| `$a1`    | είσοδος   | ακέραιος | δευτερόλεπτα                |
| `$v0`    | έξοδος    | ακέραιος | ηλικία σε εκατοστά του έτους |
| `$t0-9`  | προσωρινός | οποιοσδήποτε | χρησιμοποιείται για προσωρινή αποθήκευση |
