# Εισαγωγή

Στην Global Verification Authority, μόλις σου ανατέθηκε μια κρίσιμη αποστολή.
Σε όλη την πόλη, από τις ηλεκτρονικές αγορές μέχρι τις ασφαλείς συνδέσεις, αμέτρητες λειτουργίες βασίζονται στην ακρίβεια αριθμητικών αναγνωριστικών, όπως αριθμοί πιστωτικών καρτών, αριθμοί τραπεζικών λογαριασμών, κωδικοί συναλλαγών και αναγνωριστικά παρακολούθησης.
Ο αλγόριθμος Luhn είναι ένας απλός τύπος αθροίσματος ελέγχου που χρησιμοποιείται για να διασφαλίζει ότι αυτοί οι αριθμοί είναι έγκυροι και χωρίς λάθη.

Μια παρτίδα αναγνωριστικών μόλις έφτασε στο γραφείο σου.
Όλα πρέπει να περάσουν τη δοκιμή Luhn για να επιβεβαιωθεί ότι είναι νόμιμα.
Αν κάποιο αποτύχει, θα σημανθεί ως μη έγκυρο, αποτρέποντας έτσι λάθη ή απάτες, όπως λανθασμένες συναλλαγές ή μη εξουσιοδοτημένη πρόσβαση.

Μπορείς να φροντίσεις να γίνει σωστά; Η ακεραιότητα πολλών υπηρεσιών εξαρτάται από εσένα.
