# Break, Continue

Όταν χρησιμοποιείς μια δομή ελέγχου βρόχου ή επανάληψης, οι λέξεις-κλειδιά `break` και `continue` μπορούν να βοηθήσουν στον έλεγχο της ροής ενός προγράμματος.
Η λέξη-κλειδί `break` εξέρχεται από το περιβάλλον του βρόχου στο εξωτερικό πεδίο, τερματίζοντας έτσι τον βρόχο.
Η λέξη-κλειδί `continue` παραλείπει το υπόλοιπο της τρέχουσας επανάληψης και επανεκκινεί το περιβάλλον του βρόχου από την αρχή της επόμενης επανάληψης.
Αν και σπάνιο, μπορεί να δοθεί ένας αριθμός μαζί με τη λέξη-κλειδί για να καθορίσεις από πόσα περιβάλλοντα θα βγεις ή σε ποιο περιβάλλον θα συνεχίσεις στην επόμενη επανάληψη.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

Στο προηγούμενο παράδειγμα, το `continue` εκτελείται πέντε (5) φορές, αλλά στην έκτη (6) επανάληψη εκτελείται το `break`, με αποτέλεσμα ο κώδικας να βγει από τον βρόχο.
