Τα πράγματα όμως είναι λίγο ακατάστατα: οι συντεταγμένες της Aazra φαίνεται να είναι μορφοποιημένες και ταξινομημένες διαφορετικά από της Rui, και πρέπει να κοιτούν συνεχώς από τη μία λίστα στην άλλη για να καταλάβουν ποιοι θησαυροί πάνε με ποιες θέσεις. Καθώς είναι επίδοξοι Gleamlins, ήρθαν σε σένα για βοήθεια, για να γράψεις ένα μικρό πρόγραμμα (ουσιαστικά, ένα σύνολο συναρτήσεων) που θα οργανώσει καλύτερα τις πληροφορίες του κυνηγιού τους.

## 1. Μετέτρεψε τις θέσεις

Υλοποίησε τη συνάρτηση `place_location_to_treasure_location`, η οποία παίρνει μια θέση τοποθεσίας (όπως την `#("C", 1)`) και τη μετατρέπει σε θέση θησαυρού (όπως την `#(1, "C")`).

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. Σύγκρινε θέσεις θησαυρών και τοποθεσιών

Υλοποίησε τη συνάρτηση `treasure_location_matches_place_location`, η οποία παίρνει μια θέση τοποθεσίας (όπως την `#("C", 1)`) και επιστρέφει `True` αν ταιριάζει με μια θέση θησαυρού (όπως την `#(1, "C")`).

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. Μέτρησε τις θέσεις των θησαυρών

Υλοποίησε τη συνάρτηση `count_place_treasures`, η οποία παίρνει μια τοποθεσία (όπως την `#("Aqua Lagoon (Island of Mystery)", #("F", 1))`) και τη λίστα με τους θησαυρούς, και επιστρέφει τον αριθμό των θησαυρών που μπορούν να βρεθούν εκεί.

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. Ειδικές τοποθεσίες

Υλοποίησε τη συνάρτηση `special_case_swap_possible`, η οποία παίρνει έναν θησαυρό (όπως τον `#("Amethyst Octopus", #(1, "F"))`), μια τοποθεσία (όπως την `#("Seaside Cottages", #("C", 1))`) και έναν επιθυμητό θησαυρό (όπως τον `#("Crystal Crab", #(6, "A"))`), και επιστρέφει `True` για τους παρακάτω συνδυασμούς:

- Το Brass Spyglass μπορεί να ανταλλαχθεί με οποιονδήποτε άλλο θησαυρό στο Abandoned Lighthouse.
- Το Amethyst Octopus μπορεί να ανταλλαχθεί με το Crystal Crab ή το Glass Starfish στο Stormy Breakwater.
- Το Vintage Pirate Hat μπορεί να ανταλλαχθεί με το Model Ship in Large Bottle ή το Antique Glass Fishnet Float στο Harbor Managers Office.
