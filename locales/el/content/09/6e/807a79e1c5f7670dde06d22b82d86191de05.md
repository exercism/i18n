# μη γράφεις στην κονσόλα

Αφαίρεσε τις συναρτήσεις που γράφουν στην κονσόλα, καθώς οι δοκιμές δεν τις χρειάζονται και κάνουν τον κώδικα λίγο πιο δύσκολο να διαβαστεί.

Συνήθως, αυτές οι εντολές προστίθενται για να βοηθήσουν στο debug του κώδικα. Ωστόσο, μια καλύτερη προσέγγιση είναι να κάνεις debug στον κώδικα ενώ τρέχεις μία ή περισσότερες δοκιμές μονάδας. Αυτό έχει το πρόσθετο πλεονέκτημα ότι μπορείς να επικεντρωθείς στο debug μιας συγκεκριμένης περίπτωσης δοκιμής. Ορίστε μερικοί σύνδεσμοι που εξηγούν πώς να κάνεις debug σε κώδικα Scala ενώ τρέχεις δοκιμές μονάδας σε διάφορα IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
