# Υποδείξεις

## Γενικά

- Για να μπορεί ένα όνομα να έχει πολλαπλούς διαφορετικούς τύπους, πρέπει να χρησιμοποιήσεις έναν [τύπο ένωσης][union-type].
- Για να μπορέσεις να χρησιμοποιήσεις μια μεταβλητή στιγμιοτύπου σε μια έκφραση ελέγχου [`if var.is_a?(Type)`][if-is-a], πρέπει πρώτα να την εκχωρήσεις σε μια τοπική μεταβλητή.

## 1. Όρισε έναν κωδικό πρόσβασης

- Πρέπει να ορίσεις μια κλάση με το όνομα `PasswordLock`.
- Πρέπει να ορίσεις μια μέθοδο αρχικοποίησης που δέχεται ως όρισμα είτε `String`, είτε `Int32`, είτε `Float64`.
- Πρέπει να ορίσεις μια [μεταβλητή στιγμιοτύπου][instance-variable] `@password` που ορίζεται στο όρισμα που περνάς στον κατασκευαστή.

## 2. Κρυπτογράφησε τον κωδικό πρόσβασης

- Όρισε μια μέθοδο στιγμιοτύπου με το όνομα `encrypt`.
- Η μέθοδος πρέπει να τροποποιεί τη [μεταβλητή στιγμιοτύπου][instance-variable] `@password` ώστε να είναι κρυπτογραφημένη.
- Για να μπορεί ένας συγκεκριμένος κλάδος να εκτελεστεί μόνο αν η μεταβλητή είναι συγκεκριμένου τύπου, πρέπει να χρησιμοποιήσεις τη μέθοδο [`is_a?`][is-a] σε μια έκφραση ελέγχου.

## 3. Έλεγξε αν ένας κωδικός πρόσβασης είναι σωστός

- Μπορείς να χρησιμοποιήσεις μεθόδους που έχουν ήδη οριστεί για να κρυπτογραφήσεις την προσπάθεια κωδικού που σου δίνεται.
