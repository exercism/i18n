# Εισαγωγή

Το λεξιλόγιο [`random`][random] της Factor παρέχει μία γενική λέξη, τη `random`, που προσαρμόζεται στο όρισμά της, μαζί με βοηθητικές λέξεις για την ανακάτεψη και τη δειγματοληψία ακολουθιών.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

Η `random` για έναν ακέραιο `n` επιστρέφει μια τιμή στο `[0, n)`· για μια ακολουθία επιστρέφει ένα τυχαίο στοιχείο. Η `randomize` ανακατεύει τα στοιχεία επιτόπου, και η `sample` επιλέγει διακριτά στοιχεία.

Από προεπιλογή, αυτές αντλούν από μια καθολική γεννήτρια με σπόρο από το ρολόι του συστήματος. Για να γίνουν τα αποτελέσματα αναπαραγώγιμα, εγκατέστησε μια γεννήτρια με σπόρο με το `<mersenne-twister>` (από το [`random.mersenne-twister`][mt]) και το `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```

[mt]: https://docs.factorcode.org/content/vocab-random.mersenne-twister.html
