# Εισαγωγή

## Πακέτα και Ενότητες

### Εισαγωγή

Μια ενότητα συνήθως φορτώνεται με τη λέξη-κλειδί `use`.
Αυτό θα τη φορτώσει και θα καλέσει τη μέθοδο `import` πάνω της, εισάγοντας τυχόν εξαγόμενα σύμβολα.

Τα σύμβολα στον πίνακα `@EXPORT` του πακέτου θα εισάγονται από προεπιλογή.
Τα σύμβολα στον πίνακα `@EXPORT_OK` του πακέτου πρέπει να εισάγονται ρητά.

### Εξαγωγή

Για να εισαχθεί ένα σύμβολο, πρέπει πρώτα να εξαχθεί.
Η ενότητα [Exporter][Exporter] παρέχεται μαζί με την Perl και είναι μία από τις πιο βολικές επιλογές για εξαγωγή.

Ορισμός της ενότητας:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Χρήση της ενότητας:
```perl
use Foo ('bar');

bar();
```

### Βασικές Ενότητες

Μαζί με την [Exporter][Exporter], η Perl έχει μεγάλη ποικιλία από [βασικές ενότητες][perl-core-modules] διαθέσιμες για χρήση.
Μερικά παραδείγματα χρήσιμα για ασκήσεις που μπορεί να συναντήσεις εδώ περιλαμβάνουν τα [List::Util][List::Util], [Time::Piece][Time::Piece] και [Math::BigRat][Math::BigRat].

### CPAN

Εκτός από τις βασικές ενότητες, το [CPAN][metacpan] έχει χιλιάδες επιπλέον ενότητες που έχουν δημιουργηθεί από την κοινότητα της Perl και είναι διαθέσιμες για εγκατάσταση.
Η διαδρομή Perl χρησιμοποιεί ένα [cpanfile][test-runner-cpanfile] για να εγκαταστήσει μια επιλογή ενοτήτων που μπορούν να χρησιμοποιηθούν με τον Perl test runner του Exercism.
