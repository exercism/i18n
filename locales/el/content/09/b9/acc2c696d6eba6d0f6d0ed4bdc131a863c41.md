# Σχετικά

Όταν θέλεις να έχεις κώδικα με διακλαδώσεις, μπορείς να χρησιμοποιήσεις το [`cond/1`][cond]:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Το `cond` ακολουθεί το πρώτο μονοπάτι που αξιολογείται σε `true`. Τουλάχιστον μία ρήτρα πρέπει να αξιολογείται σε `true`, αλλιώς θα πεταχτεί ένα σφάλμα κατά την εκτέλεση.

Η συνθήκη `cond` χρησιμοποιείται συνήθως όταν υπάρχουν περισσότερες από δύο λογικές διακλαδώσεις και κάθε διακλάδωση έχει μια συνθήκη που βασίζεται σε διαφορετικές μεταβλητές. Αν όλες οι συνθήκες βασίζονται στις ίδιες μεταβλητές, τότε η συνθήκη [`case`][case] ταιριάζει καλύτερα. Αν υπάρχουν μόνο δύο λογικές διακλαδώσεις, χρησιμοποίησε τη συνθήκη [`if`][if].

[cond]: https://hexdocs.pm/elixir/case-cond-and-if.html#cond
[case]: https://hexdocs.pm/elixir/case-cond-and-if.html#case
[if]: https://hexdocs.pm/elixir/case-cond-and-if.html#if
