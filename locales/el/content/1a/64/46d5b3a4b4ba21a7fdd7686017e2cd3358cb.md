# Αποσφαλμάτωση

Για να διευκολύνεις την αποσφαλμάτωση, μπορείς να εκμεταλλευτείς το γεγονός ότι όλη η έξοδος της κονσόλας καταγράφεται και εμφανίζεται στο παράθυρο με τα αποτελέσματα των τεστ.
Μπορείς να εμφανίσεις οποιαδήποτε τιμή περνώντας την στο `@show`.

Το `@show` εμφανίζει μια έκφραση και το αποτέλεσμά της και ταυτόχρονα επιστρέφει το αποτέλεσμά της.

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

Μπορείς επίσης να χρησιμοποιήσεις τη [`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println) ή οποιαδήποτε άλλη μέθοδο που γράφει έξοδο στο [`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout)).
