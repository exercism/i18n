# Σχετικά

Η δημιουργία ενός στιγμιότυπου μιας _κλάσης_ γίνεται καλώντας τον [_κατασκευαστή_][constructors] της μέσω του [τελεστή `new`][new]. Ο κατασκευαστής είναι ένας ειδικός τύπος μεθόδου, με σκοπό να αρχικοποιήσει ένα στιγμιότυπο που μόλις δημιουργήθηκε. [Οι κατασκευαστές μοιάζουν με τις συνηθισμένες μεθόδους][constructor-syntax], αλλά χωρίς τύπο επιστροφής και με όνομα που ταιριάζει με το όνομα της κλάσης.

```csharp
class Library
{
    private books;

    public Library()
    {
        this.books = 10;
    }
}

// This will call the constructor
var library = new Library();
```

Όπως οι συνηθισμένες μέθοδοι, έτσι και οι κατασκευαστές μπορούν να έχουν παραμέτρους. Οι παράμετροι του κατασκευαστή συνήθως αποθηκεύονται σε (ιδιωτικά) [πεδία][fields] για να προσπελαστούν αργότερα, ή αλλιώς χρησιμοποιούνται σε κάποιον υπολογισμό που γίνεται μία φορά. Μπορούν να περαστούν ορίσματα στους κατασκευαστές, ακριβώς όπως περνάς ορίσματα σε συνηθισμένες μεθόδους.

```csharp
class Building
{
    private int numberOfStories;
    private int totalHeight;

    public Building(int numberOfStories, double storyHeight)
    {
        this.numberOfStories = numberOfStories;
        this.totalHeight = numberOfStories * storyHeight;
    }
}

// Call a constructor with two arguments
var largeBuilding = new Building(55, 6.2);
```

Ο καθορισμός ενός κατασκευαστή είναι προαιρετικός. Αν δεν καθοριστεί κανένας κατασκευαστής, ο μεταγλωττιστής δημιουργεί έναν [κατασκευαστή χωρίς παραμέτρους][parameterless-constructors]:

```csharp
class Elevator
{
}

// This will call the (empty) generated constructor
var elevator = new Elevator();
```

Αν στα πεδία έχει ανατεθεί μια αρχική τιμή, ο μεταγλωττιστής θα παράγει κώδικα στον οποίο η ανάθεση γίνεται στην πραγματικότητα μέσα στον κατασκευαστή. Οι παρακάτω δηλώσεις κλάσης είναι επομένως ισοδύναμες (ως προς τη λειτουργικότητα):

```csharp
class UsingFieldInitialization
{
    private int players = 5;
}

class UsingConstructorInitialization
{
    private int players;

    public UsingConstructorInitialization()
    {
        players = 5;
    }
}
```
