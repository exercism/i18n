# Υποδείξεις

## Γενικά

- Το `MACRO:` βρίσκεται στο [`macros`][macros]. Τα δομικά στοιχεία βρίσκονται στο
  `kernel` (`dup`, `curry`), στο `sequences` (`append`, `concat`,
  `<repetition>`, `map`) και στο `quotations` (`>quotation`).
- Ένα σώμα μακροεντολής πρέπει να αφήνει **μία παράθεση** στη στοίβα. Αν το
  σώμα σου παράγει έναν πίνακα με κώδικα, τελείωσε με `>quotation`.
- Για να ελέγξεις τη σκέψη σου, εκτέλεσε τις λέξεις του σώματος πάνω σε μια
  κυριολεκτική τιμή στον listener και δες την παράθεση που θα πάρεις πίσω. Θα
  πρέπει να είναι ο γραμμικός κώδικας από τη γραμμή «μεταγλωττίζεται σε» της
  εργασίας.

## 1. Δύο φορές

- Παίρνεις `[ A ]` και θέλεις `[ A A ]`. Κάνε ένα αντίγραφο και ένωσέ τα:
  `dup append`.

## 2. N επαναλήψεις

- Παίρνεις `[ A ] n` και θέλεις `n` αντίγραφα ενωμένα μεταξύ τους.
- Το `<repetition>` φτιάχνει τα αντίγραφα, αλλά το αποτέλεσμά του στη στοίβα είναι
  `( length elt -- repetition )`. Το πλήθος πρέπει να είναι στην κορυφή, οπότε
  πρώτα `swap`.
- Μετά επιπεδοποίησε και μετέτρεψε: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Σύνθεση πολλών

- Παίρνεις ήδη τον πίνακα με τις παραθέσεις. Το μόνο που χρειάζεται είναι να τον
  επιπεδοποιήσεις σε μία. Το `concat >quotation` είναι όλο το σώμα.

## 4. Αποδιπλωμένη επανάληψη

Παίρνεις μια ακολουθία και μια παράθεση, π.χ. `{ 10 20 30 } [ + ]`, και θέλεις
`[ 10 + 20 + 30 + ]`. Χτίσε την σε τρία βήματα.

**Ένα στοιχείο.** Το να ενσωματώσεις ένα στοιχείο μέσα στην παράθεση είναι ακριβώς
αυτό που κάνει το `curry`:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Κάθε στοιχείο.** Θέλεις να το περάσεις με `map` πάνω από την ακολουθία, αλλά το
`map` δίνει μόνο μία είσοδο στην παράθεση αντιστοίχισης (το στοιχείο), ενώ
χρειάζεσαι και το `[ + ]` διαθέσιμο κάθε φορά. Έτσι, ενσωμάτωσε πρώτα το `[ + ]`
στην παράθεση αντιστοίχισης, πάλι με `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

Το `[ curry ] curry` διαβάζεται ως «βάλε τη μικρή παράθεση `[ curry ]` και μετά
κάνε curry το `[ + ]` μέσα της», δίνοντας `[ [ + ] curry ]`. Η αντιστοίχιση αυτού
πάνω από ένα στοιχείο `e` εκτελεί `e [ + ] curry`, που είναι `[ e + ]`.

**Ένωσέ τα.** Ίδιο τελείωμα με τις άλλες εργασίες:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- Όλο το σώμα: `[ curry ] curry map concat >quotation`.
