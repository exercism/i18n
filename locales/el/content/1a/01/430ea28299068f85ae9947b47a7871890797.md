# Μην συγκρίνεις τιμές Boolean με αληθή ή ψευδή

Το να συγκρίνεις τιμές Boolean με αληθή ή ψευδή είναι περιττό.
Η χρήση του `==` παράγει μια τιμή Boolean, οπότε δεν χρειάζεται να τη συγκρίνεις με μια άλλη καρφωτή τιμή Boolean.
Αν θέλεις να αντιστρέψεις την τιμή Boolean, χρησιμοποίησε τον τελεστή `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
