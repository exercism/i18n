## 2. Γράψε έναν προσαρμογέα επαναλήπτη `evens` που επιστρέφει τα άρτια στοιχεία από έναν αυθαίρετο επαναλήπτη

- Απλώς σύνδεσε μεταξύ τους τις προτεινόμενες μεθόδους και όλα θα δουλέψουν
- Ένας αριθμός `n` είναι άρτιος αν `n % 2 == 0`
- Ένα closure είναι μια συνάρτηση με συντομευμένη σύνταξη: το όνομα (ή τα ονόματα) του ορίσματος μπαίνουν μέσα σε ένα ζεύγος συμβόλων `|` και ακολουθεί η έκφραση.
  Σε αντίθεση με τις κανονικές συναρτήσεις, δεν είναι πάντα απαραίτητο να δηλώσεις ρητά τον τύπο κάθε ορίσματος, μόνο το όνομα.
  Για παράδειγμα, έτσι μπορείς να κατασκευάσεις έναν επαναλήπτη με τα τετράγωνα των περιττών αριθμών: `(0..).map(|n| 2 * n + 1).map(|n| n * n)`.

## 3. Υλοποίησε μια μέθοδο `manhattan` σε μια δομή-πλειάδα `Position`

- Μην ανησυχείς για τη σύνταξη των μεθόδων· αρκεί να αντικαταστήσεις το τμήμα `todo` μέσα στο μπλοκ `impl Position` και θα γίνει το σωστό.
- Σκέψου ότι κάποιες τιμές μέσα σε μια `Position` μπορεί να είναι αρνητικές, αλλά μια απόσταση δεν είναι ποτέ αρνητική.
- Ο υπολογισμός της απόλυτης τιμής θα υποστηρίζεται εγγενώς στην Cairo κάποια στιγμή· στο μεταξύ, σου παρέχουμε ένα βοηθητικό trait που μπορείς να χρησιμοποιήσεις
