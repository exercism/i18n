# Εισαγωγή

Η Factor έχει δύο Boolean (λογική τιμή) τιμές: `t` (αληθής) και `f` (ψευδής). Όπου
χρειάζεται μια απάντηση "ναι/όχι", οι λέξεις σπρώχνουν μία από αυτές στη
στοίβα.

Οι Boolean τελεστές βρίσκονται στο [`kernel`][kernel]:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

Το `f` είναι επίσης η μόνη *ψευδής* τιμή του Factor. Κάθε άλλη τιμή (κενές
συμβολοσειρές, μηδέν, κενοί πίνακες) αντιμετωπίζεται ως *αληθής*.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
