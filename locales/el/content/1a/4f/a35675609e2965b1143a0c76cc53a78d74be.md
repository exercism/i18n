# Introduction
## `switch`

Μια [εντολή `switch`][switch] σου επιτρέπει να συγκρίνεις μια τιμή με πολλαπλές πιθανές τιμές που μπορούν να ταιριάξουν. Σου επιτρέπει να γράψεις πιο συνοπτικό κώδικα από το να χρησιμοποιείς πολλαπλές εντολές `else-if`. Μια εντολή `switch` ξεκινά με τη λέξη-κλειδί `switch` ακολουθούμενη από την τιμή που θα συγκριθεί. Στη συνέχεια, μπορείς να ορίσεις τις περιπτώσεις χρησιμοποιώντας τη λέξη-κλειδί `case` ακολουθούμενη από την τιμή με την οποία θα συγκριθεί. Η λέξη-κλειδί `default` χρησιμοποιείται για να ορίσει την προεπιλεγμένη περίπτωση όταν καμία από τις περιπτώσεις δεν ταιριάζει. Όπως και οι εντολές `else-if`, οι εντολές `switch` εκτελούν μόνο το μπλοκ κώδικα που σχετίζεται με την πρώτη περίπτωση που ταιριάζει.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Δες το ακόλουθο παράδειγμα:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

Αυτό θα μπορούσε να γραφτεί εναλλακτικά ως:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while` βρόχοι

Ένας [`while` βρόχος][while-loops] είναι μια εντολή ροής ελέγχου που επιτρέπει την εκτέλεση κώδικα όσο μια συγκεκριμένη συνθήκη είναι αληθής. Η Swift παρέχει δύο είδη βρόχων `while`: τους βρόχους `while` και `repeat-while`. Η συνθήκη του βρόχου `while` αξιολογείται πριν εκτελεστεί το σώμα του βρόχου· αν η συνθήκη είναι ψευδής, το σώμα του βρόχου δεν θα εκτελεστεί καθόλου. Οι βρόχοι `while` στη Swift έχουν την ακόλουθη δομή:

```swift
while <#condition#> {
  <#code#>
}
```

Εδώ ο βρόχος θα εκτελεστεί όσο το count είναι μεγαλύτερο από 0 και θα τυπώσει έτσι τους αριθμούς 2, 1 και το "Liftoff!".

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Ένας [`repeat-while` βρόχος][while-loops] είναι παρόμοιος με έναν βρόχο `while`, αλλά η συνθήκη αξιολογείται αφού εκτελεστεί το σώμα του βρόχου. Αυτό σημαίνει ότι το σώμα του βρόχου θα εκτελεστεί πάντα τουλάχιστον μία φορά, ακόμη και αν η συνθήκη είναι ψευδής. Οι βρόχοι `repeat-while` στη Swift έχουν την ακόλουθη δομή:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Εδώ ο βρόχος θα εκτελεστεί μόνο μία φορά, αφού η συνθήκη είναι ψευδής. Επειδή είναι βρόχος `repeat-while`, το σώμα του βρόχου θα εκτελεστεί μία φορά πριν αξιολογηθεί η συνθήκη.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Μεταφορά Ελέγχου

Η Swift έχει ένα σύνολο εντολών που μπορούν να χρησιμοποιηθούν για να αλλάξουν την κανονική ροή ελέγχου των βρόχων. Αυτές είναι γνωστές ως εντολές μεταφοράς ελέγχου. Έχεις ήδη δει το `return`· αυτή η έννοια θα παρουσιάσει άλλες, που περιλαμβάνουν τα `continue`, `break` και τις ετικέτες. Δεν θα καλύψουμε το `fallthrough` σε αυτή την έννοια, αλλά μπορείς να διαβάσεις γι' αυτό στο [βιβλίο της Swift][fallthrough].

### Συνέχεια

Μερικές φορές χρειάζεται να μεταβείς νωρίς στην επόμενη επανάληψη ενός βρόχου, χωρίς να ολοκληρώσεις τις υπόλοιπες εντολές της τρέχουσας επανάληψης. Η λέξη-κλειδί `continue` μπορεί να χρησιμοποιηθεί γι' αυτό. Όταν εκτελεστεί το `continue`, ο βρόχος μεταπηδά στον επόμενο έλεγχο για να δει αν μπορεί να εκτελεστεί η επόμενη επανάληψη, δηλαδή το `while` στους βρόχους `while` και `repeat-while` ή ο έλεγχος αν υπάρχει άλλο στοιχείο στην ακολουθία στους βρόχους `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Διακοπή

Το `break` χρησιμοποιείται για να βγεις νωρίς από έναν βρόχο. Όταν εκτελεστεί το `break`, ο βρόχος θα τερματιστεί αμέσως και το πρόγραμμα θα συνεχίσει με την πρώτη εντολή μετά τον βρόχο.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Ετικέτες

Όταν οι βρόχοι είναι εμφωλευμένοι, υπάρχουν στιγμές που μπορεί να θέλεις να χρησιμοποιήσεις το `break` ή το `continue` για να βγεις ή να επανεκκινήσεις τους εξωτερικούς βρόχους που περιέχουν τον βρόχο στον οποίο χρησιμοποιούνται το `break` ή το `continue`. Σε τέτοιες περιπτώσεις, μπορούν να χρησιμοποιηθούν ετικέτες για να προσδιορίσουν τον βρόχο που θα τερματιστεί ή θα επανεκκινηθεί. Μπορείς να βάλεις ετικέτα σε έναν βρόχο βάζοντας ένα όνομα ακολουθούμενο από άνω και κάτω τελεία πριν από το `while`, το `repeat` ή το `for` που ξεκινά τον βρόχο.

Για να δεις το αποτέλεσμα της χρήσης ετικετών με αυτόν τον τρόπο, δες τον ακόλουθο βρόχο.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
