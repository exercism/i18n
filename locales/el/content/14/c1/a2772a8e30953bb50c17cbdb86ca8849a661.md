# Οδηγίες

Η Izzy είναι μια φανατική παρατηρήτρια πουλιών και καταγράφει πόσα πουλιά έχουν επισκεφτεί τον κήπο της κάθε μέρα.

Σου ζήτησε να τη βοηθήσεις να πάει την παρατήρηση πουλιών σε ένα νέο επίπεδο και να υλοποιήσεις μερικά εργαλεία που θα τη βοηθήσουν να παρακολουθεί και να επεξεργάζεται τα δεδομένα.

Έχεις επιλέξει να αποθηκεύεις τα δεδομένα ως λίστα από ακέραιους αριθμούς. Ο πρώτος αριθμός στη λίστα είναι ο αριθμός των πουλιών που επισκέφτηκαν τον κήπο σου σήμερα, ο δεύτερος χθες, και ούτω καθεξής.

## 1. Έλεγξε πόσα πουλιά επισκέφτηκαν τον κήπο σήμερα

Υλοποίησε τη συνάρτηση `today`. Πρέπει να παίρνει μια λίστα με τους καθημερινούς αριθμούς πουλιών και να επιστρέφει τον σημερινό αριθμό. Αν η λίστα είναι κενή, πρέπει να επιστρέφει `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Αύξησε τον σημερινό αριθμό κατά ένα

Υλοποίησε τη συνάρτηση `increment_day_count`. Πρέπει να παίρνει μια λίστα με τους καθημερινούς αριθμούς πουλιών και να αυξάνει τον σημερινό αριθμό κατά 1. Αν η λίστα είναι κενή, να επιστρέφει `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Έλεγξε αν υπήρξε μέρα χωρίς πουλιά

Υλοποίησε τη συνάρτηση `has_day_without_birds`. Πρέπει να παίρνει μια λίστα με τους καθημερινούς αριθμούς πουλιών. Πρέπει να επιστρέφει `True` αν υπήρξε τουλάχιστον μία μέρα που κανένα πουλί δεν επισκέφτηκε τον κήπο, και `False` διαφορετικά. Αν η λίστα είναι κενή, αυτό μετράει ως κανένα πουλί καταγεγραμμένο _ακόμη_. Να επιστρέφει `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Υπολόγισε τον συνολικό αριθμό των πουλιών που επισκέφτηκαν τον κήπο

Υλοποίησε τη συνάρτηση `total`. Πρέπει να παίρνει μια λίστα με τους καθημερινούς αριθμούς πουλιών και να επιστρέφει τον συνολικό αριθμό πουλιών που επισκέφτηκαν τον κήπο σου από τότε που άρχισες να συλλέγεις τα δεδομένα.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Υπολόγισε τον αριθμό των φορτωμένων ημερών

Κάποιες μέρες είναι πιο φορτωμένες από άλλες. Φορτωμένη μέρα είναι εκείνη κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.

Υλοποίησε τη συνάρτηση `busy_days`. Πρέπει να παίρνει μια λίστα με τους καθημερινούς αριθμούς πουλιών και να επιστρέφει τον αριθμό των φορτωμένων ημερών.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
