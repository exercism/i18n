# Εισαγωγή

## Λίστες

Οι λίστες είναι ενσωματωμένες στη γλώσσα Elixir. Θεωρούνται βασικός τύπος και συμβολίζονται με αγκύλες. Οι λίστες μπορεί να είναι κενές ή να περιέχουν οποιονδήποτε αριθμό στοιχείων οποιουδήποτε τύπου. Για παράδειγμα:

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Η Elixir υλοποιεί τις λίστες ως συνδεδεμένη λίστα, όπου κάθε κόμβος αποθηκεύει δύο τιμές: το πρώτο στοιχείο και μια άλλη λίστα με όλα τα υπόλοιπα στοιχεία. Το πρώτο στοιχείο της λίστας ονομάζεται _κεφαλή_ και η λίστα με τα υπόλοιπα στοιχεία ονομάζεται _ουρά_. Μπορούμε να χρησιμοποιήσουμε αυτόν τον συμβολισμό στον κώδικα:

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

Μπορούμε να χρησιμοποιήσουμε τον συμβολισμό _`[head | tail]`_ για να προσθέσουμε στοιχεία στην αρχή μιας λίστας:

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

Υπάρχουν αρκετές συναρτήσεις στο module `Kernel` για να δουλέψεις με λίστες, καθώς και ολόκληρο το module `List`.

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
