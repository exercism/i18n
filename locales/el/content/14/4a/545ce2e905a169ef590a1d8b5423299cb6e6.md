# Σχετικά

Μια συμβολοσειρά αναπαριστά δεδομένα κειμένου.
Στη Swift, ένα [`String`][strings-and-characters] είναι μια διατεταγμένη συλλογή από τιμές `Character`, όπου κάθε χαρακτήρας αναπαριστά έναν χαρακτήρα Unicode.

Μπορείς να δημιουργήσεις μια συμβολοσειρά μέσα από ένα κυριολεκτικό συμβολοσειράς, που είναι μια σειρά χαρακτήρων κλεισμένη σε διπλά εισαγωγικά (`"`).
Για συμβολοσειρές πολλών γραμμών, χρησιμοποίησε τρία διπλά εισαγωγικά (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Οι συμβολοσειρές της Swift συνδέονται απρόσκοπτα με την κλάση [`NSString`][nsstring-docs] του framework Foundation, παρέχοντας πρόσβαση σε εκτεταμένες δυνατότητες επεξεργασίας κειμένου.

## Χαρακτήρες

Ένα `Character` αναπαριστά ένα μόνο εκτεταμένο σύμπλεγμα γραφημάτων, δηλαδή έναν χαρακτήρα αναγνώσιμο από τον άνθρωπο, ο οποίος αποτελείται από μία ή περισσότερες [τιμές βαθμωτού Unicode][unicode-scalar-values].
Μια τιμή βαθμωτού Unicode είναι ένα κωδικό σημείο 21 bit στην περιοχή από `U+0000` έως `U+D7FF` συμπεριλαμβανομένων ή από `U+E000` έως `U+10FFFF` συμπεριλαμβανομένων.

```swift
let aChar: Character = "A"
```

## Εξαγωγή τύπου

Όταν γράφεις ένα κυριολεκτικό συμβολοσειράς, η Swift συμπεραίνει αυτόματα τον τύπο του ως `String`.
Για να αποθηκεύσεις έναν μόνο χαρακτήρα ως `Character`, πρέπει να δώσεις έναν ρητό σχολιασμό τύπου:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Συνένωση

Μπορείς να ενώσεις συμβολοσειρές μεταξύ τους χρησιμοποιώντας τον τελεστή πρόσθεσης (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

Δεν μπορείς να συνενώσεις απευθείας ένα `Character` με ένα `String` χρησιμοποιώντας το `+` χωρίς πρώτα να μετατρέψεις τον χαρακτήρα σε συμβολοσειρά.
Ωστόσο, μπορείς να χρησιμοποιήσεις τη μέθοδο [`append(_:)`][append] για να προσθέσεις στο τέλος είτε μια συμβολοσειρά είτε έναν χαρακτήρα απευθείας σε μια συμβολοσειρά που μπορεί να μεταβληθεί:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Παρεμβολή συμβολοσειρών

Η [παρεμβολή συμβολοσειρών][string-interpolation] σου επιτρέπει να κατασκευάσεις μια συμβολοσειρά ενσωματώνοντας σταθερές, μεταβλητές, κυριολεκτικά και εκφράσεις μέσα σε κυριολεκτικά συμβολοσειρών.
Τύλιξε κάθε έκφραση σε παρενθέσεις, με μια ανάστροφη κάθετο μπροστά (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Ιδιότητες συμβολοσειρών και χαρακτήρων

Οι συμβολοσειρές και οι χαρακτήρες προσφέρουν αρκετές ιδιότητες για να εξετάσεις το περιεχόμενό τους.

### Ιδιότητες συμβολοσειράς

Οι πιο συνηθισμένες ιδιότητες συμβολοσειράς είναι:

| Ιδιότητα | Περιγραφή                                      | Παράδειγμα                       |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | Επιστρέφει `true` αν η συμβολοσειρά δεν έχει χαρακτήρες | `"Hello".isEmpty` αξιολογείται σε `false` |
| `count`   | Επιστρέφει τον αριθμό των χαρακτήρων στη συμβολοσειρά | `"Hello".count` αξιολογείται σε `5`       |

Για μια πλήρη λίστα ιδιοτήτων, δες την [τεκμηρίωση του String της Apple][string-docs].

### Ιδιότητες χαρακτήρα

Οι πιο συνηθισμένες ιδιότητες χαρακτήρα είναι:

| Ιδιότητα       | Περιγραφή                                     | Παράδειγμα                           |
| -------------- | --------------------------------------------- | ------------------------------------ |
| `isLowercase`  | Επιστρέφει `true` αν ο χαρακτήρας είναι πεζός | `"a".isLowercase` αξιολογείται σε `true` |
| `isUppercase`  | Επιστρέφει `true` αν ο χαρακτήρας είναι κεφαλαίος | `"A".isUppercase` αξιολογείται σε `true` |
| `isNumber`     | Επιστρέφει `true` αν ο χαρακτήρας είναι ψηφίο | `"1".isNumber` αξιολογείται σε `true`    |
| `isWhitespace` | Επιστρέφει `true` αν ο χαρακτήρας είναι κενό διάστημα | `" ".isWhitespace` αξιολογείται σε `true`|

Για μια πλήρη λίστα ιδιοτήτων, δες την [τεκμηρίωση του Character της Apple][character-docs].

## Μετατροπή τύπου

Μπορείς να μετατρέψεις άλλους τύπους σε συμβολοσειρές χρησιμοποιώντας τον αρχικοποιητή `String(_:)`, ο οποίος υποστηρίζει βασικούς τύπους όπως `Int`, `Double` και `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Ειδικοί χαρακτήρες

Τα κυριολεκτικά συμβολοσειρών της Swift υποστηρίζουν αρκετές [ακολουθίες διαφυγής][special-characters] για ειδικούς χαρακτήρες:

| Ακολουθία  | Περιγραφή                     |
| ---------- | ----------------------------- |
| `\0`       | Χαρακτήρας null               |
| `\\`       | Ανάστροφη κάθετος             |
| `\t`       | Οριζόντιος στηλοθέτης         |
| `\n`       | Αλλαγή γραμμής (νέα γραμμή)   |
| `\r`       | Επιστροφή φορείου             |
| `\'`       | Μονό εισαγωγικό               |
| `\"`       | Διπλό εισαγωγικό              |
| `\u{n}`    | Οποιαδήποτε τιμή βαθμωτού Unicode (δεκαεξαδική) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
