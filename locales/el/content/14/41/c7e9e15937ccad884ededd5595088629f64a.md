# Οδηγίες

Ένας τροχός κρυπτογράφησης είναι δύο δίσκοι, ο ένας μέσα στον άλλο, που περιστρέφουν το αλφάβητο: βάλε τον στο 3 και κάθε γράμμα γίνεται αυτό που βρίσκεται τρεις θέσεις παρακάτω, με το `z` να γυρίζει πίσω στο `a`. Οι ντετέκτιβ τους χρησιμοποιούν εδώ και αιώνες. Εσύ φτιάχνεις έναν.

Και οι πέντε εργασίες μπαίνουν στην κλάση `CIPHER_WHEEL`.

## 1. Είναι γράμμα;

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. Φώναξέ το

Επίστρεψε το κεφαλαίο ενός χαρακτήρα. Ό,τι δεν είναι γράμμα επιστρέφεται ως έχει.

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. Τι αριθμός είναι;

Επίστρεψε τον αριθμό που αντιστοιχεί σε έναν χαρακτήρα.

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. Ο πρώτος χαρακτήρας

Επίστρεψε τον πρώτο χαρακτήρα μιας συμβολοσειράς.

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. Γύρισε τον τροχό

Δεδομένου ενός πεζού γράμματος και ενός αριθμού θέσεων, επίστρεψε το γράμμα που βρίσκεται τόσες θέσεις παρακάτω στο αλφάβητο. Πέρα από το `z` γυρίζει πίσω στο `a`.

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

Το γύρισμα προς τα πίσω λειτουργεί επίσης, με αρνητικό αριθμό θέσεων.

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

Μπορείς να υποθέσεις ότι ο χαρακτήρας που δίνεται είναι πεζό γράμμα.
