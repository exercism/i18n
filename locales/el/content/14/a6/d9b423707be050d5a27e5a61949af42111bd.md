# Υποδείξεις

## 1. Αντικατέστησε όποια κενά συναντήσεις με κάτω παύλες

- Η [τεκμηρίωση αναφοράς][char-docs] για τα `Char` βρίσκεται εδώ.
- Οι τιμές `Char` περικλείονται σε μονά εισαγωγικά, ενώ οι τιμές `String` σε διπλά εισαγωγικά.

## 2. Αφαίρεσε όλα τα κενά διαστήματα

- Δες [αυτή τη μέθοδο][isspace] για τον εντοπισμό χαρακτήρων κενού διαστήματος και [αυτή τη μέθοδο][isdigit] για τα ψηφία.

## 3. Μετέτρεψε το camel-case σε kebab-case

- Δες [αυτή τη μέθοδο][isuppercase] για να ελέγξεις αν ένας χαρακτήρας είναι κεφαλαίος.
- Δες [αυτή τη μέθοδο][lowercase] για να μετατρέψεις έναν χαρακτήρα σε πεζό.

## 5. Παράλειψε τα ελληνικά πεζά γράμματα

- Τα `Char` υποστηρίζουν τους προεπιλεγμένους τελεστές ισότητας και σύγκρισης.

## 6. Συνδύασε αυτές τις πράξεις για να δουλέψεις με μια συμβολοσειρά

- Μπορείς να διατρέξεις μια συμβολοσειρά με τον ίδιο τρόπο όπως έναν πίνακα.
- Για να κάνεις όλους τους μετασχηματισμούς, σκέψου να χρησιμοποιήσεις μια comprehension.
- Πολλές συμβολοσειρές μπορούν να [ενωθούν][join] σε μία.
