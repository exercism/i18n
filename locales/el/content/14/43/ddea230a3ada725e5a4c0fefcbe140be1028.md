# Προσθήκη οδηγιών

## Θέματα

Μερικά θέματα της Rust για τα οποία μπορεί να θέλεις να διαβάσεις καθώς λύνεις αυτό το πρόβλημα:

- Traits, τόσο το trait From όσο και [η υλοποίηση των δικών σου traits](https://doc.rust-lang.org/book/ch10-02-traits.html)
- [Προεπιλεγμένες υλοποιήσεις μεθόδων](https://doc.rust-lang.org/book/ch10-02-traits.html#default-implementations) για traits
- Macros, η χρήση μιας macro θα μπορούσε να μειώσει τον επαναλαμβανόμενο κώδικα και να αυξήσει την αναγνωσιμότητα
  για αυτή την άσκηση. Για παράδειγμα,
  [μια macro μπορεί να υλοποιήσει ένα trait για πολλούς τύπους ταυτόχρονα](https://stackoverflow.com/questions/39150216/implementing-a-trait-for-multiple-types-at-once),
  αν και δεν πειράζει να υλοποιήσεις το `years_during` μέσα στο ίδιο το trait Planet. Μια macro θα μπορούσε
  να ορίσει και τα structs και τις υλοποιήσεις τους. Πληροφορίες για να ξεκινήσεις με τις macros
  μπορείς να βρεις εδώ:

  - [The Macros chapter in The Rust Programming Language](https://doc.rust-lang.org/stable/book/ch19-06-macros.html)
  - [an older version of the Macros chapter with helpful detail](https://doc.rust-lang.org/1.30.0/book/first-edition/macros.html)
  - [Rust By Example](https://doc.rust-lang.org/stable/rust-by-example/macros.html)
