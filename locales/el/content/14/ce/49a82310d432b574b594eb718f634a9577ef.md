# Επίδομα Καυσίμων

## Διατύπωση προβλήματος

Κάθε υπάλληλος της ABC Corp λαμβάνει απεριόριστο επίδομα καυσίμων. Οι υπάλληλοι πρέπει να στέλνουν μια καταγραφή κάθε φορά που ανεφοδιάζουν το όχημά τους. Αυτές οι καταγραφές προστίθενται στο ίδιο αρχείο CSV και επεξεργάζονται στο τέλος του μήνα.

Ως μέλος της ομάδας ψηφιακών λειτουργιών, η αποστολή σου είναι να διαβάσεις αυτό το αρχείο CSV και να γράψεις τα αποτελέσματα σε ένα άλλο αρχείο CSV. Το αρχείο εξόδου θα πρέπει να περιέχει μία καταχώριση για κάθε υπάλληλο με τις ακόλουθες λεπτομέρειες:

- Αριθμός υπαλλήλου
- Αριθμός ανεφοδιασμών καυσίμου
- Συνολικό κόστος καυσίμου
- Σύνολο γαλονιών
- Σύνολο μιλίων που διανύθηκαν

Σου δίνονται δύο ορίσματα `string`.

1. Διαδρομή του αρχείου CSV εισόδου
1. Διαδρομή του αρχείου CSV εξόδου

Το αρχείο CSV εισόδου έχει `n` γραμμές και κάθε γραμμή έχει την ακόλουθη μορφή.

| Όνομα στήλης      | Τύπος στη Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

Το αρχείο εξόδου θα πρέπει να περιέχει μία καταχώριση για κάθε υπάλληλο, ταξινομημένη κατά αύξουσα σειρά με βάση το `employee_id`. Κάθε γραμμή έχει την ακόλουθη μορφή:

| Όνομα στήλης      | Τύπος στη Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Περιορισμοί

- Αριθμός γραμμών `n` στο αρχείο CSV εισόδου:  2 <= n <= 1000
- Αριθμός υπαλλήλων στην εταιρεία: 97
- Η τιμή του καυσίμου είναι ανά γαλόνι
- Δε λείπουν καταγραφές ανεφοδιασμού

## Παράδειγμα 1

- Είσοδος: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Έξοδος: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
