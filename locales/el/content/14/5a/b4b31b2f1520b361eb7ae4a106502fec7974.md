# Εισαγωγή

Στη Haxe, η `class` είναι η κύρια δομή δεδομένων, η οποία ενθυλακώνει δεδομένα (πεδία) και συμπεριφορά (μεθόδους). Τα πεδία και οι μέθοδοι ονομάζονται επίσης μέλη μιας κλάσης.

Η πρόσβαση στα μέλη μπορεί να περιοριστεί με τροποποιητές πρόσβασης, οι οποίοι είναι:

- `public`: το μέλος είναι προσβάσιμο από οπουδήποτε.
- `private`: το μέλος είναι προσβάσιμο μόνο από την ίδια κλάση.

Οι κλάσεις μπορούν να θεωρηθούν πρότυπα για τη δημιουργία στιγμιότυπων. Για να δημιουργήσεις ένα στιγμιότυπο, χρησιμοποίησε απλώς τη λέξη-κλειδί `new`:

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

Για να ορίσεις ένα πεδίο, χρησιμοποίησε έναν τροποποιητή πρόσβασης ακολουθούμενο από το όνομα και τον τύπο της μεταβλητής:

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

Μπορείς επίσης να ορίσεις μια αρχική τιμή όταν ορίζεις ένα πεδίο. Αν ένα πεδίο δεν καθορίζει αρχική τιμή, θα πάρει την τιμή `null`. Μπορείς να έχεις πρόσβαση σε ένα πεδίο χρησιμοποιώντας τον συμβολισμό με τελεία:

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
