# Προειδοποίηση pylint

**Η γραμμή %{lineno} [_%{code}_]** αναφέρθηκε από το Pylint:

%{message}.

Υπάρχει ένα ζήτημα στον κώδικα που θα μπορούσε να οδηγήσει σε ένα bug ή ένα σφάλμα στο πρόγραμμα.
Αν και αυτό το σφάλμα μπορεί να μην είναι _σοβαρό_, θα μπορούσε να οδηγήσει σε πιο σοβαρά ζητήματα στο μέλλον.
Συνιστάται να διορθώσεις το πρόβλημα πριν συνεχίσεις.

%{bad_code}
%{good_code}
%{related_info}
%{details}
