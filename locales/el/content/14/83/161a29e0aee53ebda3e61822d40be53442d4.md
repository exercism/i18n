# Εισαγωγή

Η δήλωση `MACRO:` είναι σαν τη `:`, μόνο που το σώμα εκτελείται σε *χρόνο μεταγλώττισης* και πρέπει να επιστρέφει μια παράθεση. Ο μεταγλωττιστής αντικαθιστά την κλήση του macro με την παράθεση που επιστράφηκε. Επειδή το σώμα είναι συνηθισμένος κώδικας Factor, το χτίσιμο της τελικής παράθεσης είναι απλώς χειρισμός ακολουθιών από λέξεις.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Οι είσοδοι ενός macro είναι *κυριολεκτικές τιμές στη θέση κλήσης*. Αν περάσεις μια τιμή που δεν είναι κυριολεκτική, ο μεταγλωττιστής θα αρνηθεί την εξειδίκευση, επειδή το σώμα του macro χρειάζεται την τιμή σε χρόνο μεταγλώττισης, όχι σε χρόνο εκτέλεσης.

Στενός συγγενής είναι το μπλοκ αξιολόγησης σε χρόνο ανάλυσης `<< … >>`, το οποίο εκτελεί αυθαίρετο κώδικα Factor σε χρόνο μεταγλώττισης χωρίς τη σύμβαση επιστροφής παράθεσης. Και τα δύο ανήκουν στον μηχανισμό [`macros`][macros] της Factor.
