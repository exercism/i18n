# Εισαγωγή

Ο buffer συμβολοσειρών είναι ένας αποδοτικός τρόπος για να φτιάξεις μια μεγάλη συμβολοσειρά προσθέτοντας μικρά στοιχεία το ένα μετά το άλλο. Σε αντίθεση με το String, ένα στιγμιότυπο του StringBuf δεν είναι αμετάβλητο, με την έννοια ότι μπορεί να περαστεί ως όρισμα σε συναρτήσεις που το τροποποιούν προσθέτοντας περισσότερες τιμές.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
