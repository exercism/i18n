# Σχετικά

Η "στατιστική" είναι ένα μεγάλο και σύνθετο αντικείμενο με πολλές πτυχές.

Κάποιες πτυχές θίγονται στην έννοια [`Randomness`][randomness], η οποία είναι ένα ξεχωριστό αλλά σχετικό αντικείμενο.

Στην απλούστερη μορφή της, η στατιστική μπορεί να περιλαμβάνει τρόπους σύνοψης μιας επαναλήψιμης συλλογής δεδομένων σε μία μόνο τιμή.
Όσοι έρχονται για πρώτη φορά στη Julia μπορεί να εκπλαγούν με το πόσο λίγες συναρτήσεις είναι ενσωματωμένες στη γλώσσα από προεπιλογή:

- [`sum`][sum], για να αθροίζεις αριθμούς.
- [`min`][min] και [`max`][max], για να παίρνεις τις ακραίες τιμές των παραμέτρων που δίνονται.
- [`extrema`][extrema], για να παίρνεις την πλειάδα (min, max) μιας επαναλήψιμης συλλογής.
- [`length`][length], για να μετράς όλες τις τιμές.
- [`count`][count], για να μετράς μόνο τις τιμές που πληρούν κάποιο κριτήριο.

```julia-repl
julia> v = collect(1:0.2:3)
11-element Vector{Float64}:
 1.0
 1.2
 ... # display truncated
 3.0

julia> mean(v)
2.0

julia> extrema(v)
(1.0, 3.0)

julia> length(v)
11

julia> min('g', 'a', 'c')
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> count(isodd, 1:5)  # 1, 3, and 5 are odd
3
```

Αυτό το περιορισμένο σύνολο συναρτήσεων είναι μια σκόπιμη απόφαση για να ελαχιστοποιηθεί το φούσκωμα στη βασική Julia, μεταφέροντας άλλες συναρτήσεις σε μια αλληλουχία από άλλες ενότητες και πακέτα.

## Η ενότητα `Statistics`

Ως μέρος της τυπικής βιβλιοθήκης, η [`Statistics`][statistics] πιθανότατα είναι προεγκατεστημένη, οπότε αρκεί να προσθέσεις το `using Statistics` στην αρχή του προγράμματος για να την φέρεις στον χώρο ονομάτων.

Αυτή η ενότητα περιέχει την επόμενη βαθμίδα συνηθισμένων συναρτήσεων, οι οποίες είναι πιθανό να χρησιμοποιούνται ευρέως από ένα υποσύνολο προγραμματιστών.

Πολλές από τις συναρτήσεις στην `Statistics` προϋποθέτουν κάποιες βασικές γνώσεις του αντικειμένου.
Τα πιο απλά παραδείγματα περιλαμβάνουν:

- [`mean`][mean], που πολλοί θα το έλεγαν μέσο όρο (ίδιο αποτέλεσμα με `sum / length`).
- [`median`][median], η μεσαία τιμή μετά την ταξινόμηση.
- [`std`][std], [τυπική απόκλιση][stddev]: ένα μέτρο του πόσο απλωμένες είναι οι τιμές.
- [`var`][var], διακύμανση: το τετράγωνο του `std`, που γενικά υπολογίζεται πιο γρήγορα.

Κάθε συνάρτηση συνήθως έχει διάφορες επιλογές, και υπάρχουν _πολλές_ ακόμα συναρτήσεις, οπότε ρίξε μια ματιά στην [τεκμηρίωση][statistics] αν ενδιαφέρεσαι.

## Άλλα πακέτα

Όπως ίσως περιμένεις, η στατιστική είναι ένας μεγάλος τομέας χρήσης για τη Julia, και υπάρχουν πολλά διαθέσιμα πακέτα που υποστηρίζουν πιο εξειδικευμένη εργασία.

Η ομάδα JuliaStats διατηρεί εξυπηρετικά μια [διαδικτυακή λίστα][juliastats].
