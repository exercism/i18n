# Παράρτημα οδηγιών

## Υλοποίηση

Πρέπει να ορίσεις έναν προσαρμοσμένο τύπο 'DNA' με μια συνάρτηση 'Counts' που επιστρέφει δύο τιμές:

- μια καταμέτρηση συχνότητας για τον δεδομένο κλώνο DNA
- ένα σφάλμα (αν υπάρχουν μη έγκυρα νουκλεοτίδια)

Ποιος τύπος είναι κατάλληλος για έναν κλώνο DNA;

Ποιοι είναι οι καλύτεροι τύποι Go για να αναπαραστήσουν τις τιμές εξόδου;

Ρίξε μια ματιά στις περιπτώσεις δοκιμών για να πάρεις μια ιδέα για το ποιες μπορεί να είναι οι πιθανές είσοδοι.
