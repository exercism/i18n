# Υποδείξεις

## Γενικά

- Διάβασε για τα [optionals][optionals] και για τις [εντολές υπό συνθήκη][conditionals] στο _A Tour of Swift_ της Apple.

## 1. Γράψε μια συνάρτηση που να υπολογίζει τα μεγέθη των φετών και να επιστρέφει nil για μη έγκυρη είσοδο.

- Το εμβαδόν ενός κύκλου είναι _pi_ \* _r_<sup>2</sup>, όπου _r_ είναι το μισό της διαμέτρου.
- Μπορείς να χρησιμοποιήσεις μετατροπή τύπων για να μετατρέψεις ένα `Int` σε `Double`.
- Μπορείς να χρησιμοποιήσεις μια συνθήκη τύπου guard για να βγεις νωρίς αν κάποια από τις δύο παραμέτρους δεν είναι έγκυρη.

## 2. Επεξεργάσου την είσοδο από τη διαδικτυακή εφαρμογή σου για να προσδιορίσεις τη μεγαλύτερη φέτα.

- Μπορείς να χρησιμοποιήσεις optional binding για να διαπιστώσεις αν ένα optional έχει τιμή και να εξαγάγεις αυτή την τιμή αν υπάρχει.
- Μπορείς να βγεις νωρίς από τη συνάρτηση αν ξέρεις ποια πρέπει να είναι η τιμή επιστροφής χωρίς περαιτέρω επεξεργασία.
- Δεν μπορείς να συγκρίνεις απευθείας το `nil` με τιμές που δεν είναι `nil`.
- Μπορείς να χρησιμοποιήσεις εντολές switch και μοτίβα optional για να συγκρίνεις τιμές optional.
