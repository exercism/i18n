# Υποδείξεις

## Γενικά

- [Το σεμινάριο για τα λεξικά της Python][dict-tutorial] μπορεί να είναι ένα εξαιρετικό σημείο για να ξεκινήσεις.
- Η τεκμηρίωση της Python για τους [Τύπους αντιστοίχισης - λεξικά][dict docs] είναι επίσης αρκετά χρήσιμη.

## 1. Δημιούργησε ένα απόθεμα με βάση μια λίστα

- Χρειάζεσαι έναν [`for` βρόχο][for-loop] για να διατρέξεις τη λίστα με τα στοιχεία, και μετά να εισάγεις κάθε στοιχείο στο λεξικό αν λείπει και να αυξήσεις τον αριθμό των στοιχείων χρησιμοποιώντας την πρόσβαση στο λεξικό.
- Μπορείς να χρησιμοποιήσεις το [`dict.setdefault`][dict setdefault] για να βεβαιωθείς ότι η τιμή έχει οριστεί πριν αυξήσεις τον αριθμό των στοιχείων.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return-keyword] ένα λεξικό.

## 2. Πρόσθεσε στοιχεία από μια λίστα σε ένα υπάρχον λεξικό

- Χρειάζεσαι έναν [`for` βρόχο][for-loop] για να διατρέξεις τη λίστα με τα στοιχεία, και μετά να εισάγεις κάθε στοιχείο αν δεν υπάρχει ήδη στο λεξικό και να [αυξήσεις][increment] τον αριθμό των στοιχείων χρησιμοποιώντας την πρόσβαση στο λεξικό.
- Μπορείς να χρησιμοποιήσεις το [`dict.setdefault`][dict setdefault] για να βεβαιωθείς ότι η τιμή έχει οριστεί πριν αυξήσεις τον αριθμό των στοιχείων.
- Η συνάρτηση `add_items` μπορεί να χρησιμοποιηθεί από τη συνάρτηση `create_inventory` με ένα άδειο λεξικό ως παράμετρο.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return-keyword] ένα λεξικό.

## 3. Μείωσε τα στοιχεία του αποθέματος

- Χρειάζεσαι έναν [`for` βρόχο][for-loop] για να διατρέξεις τη λίστα με τα στοιχεία· αν ο αριθμός των στοιχείων δεν είναι `0`, τότε να [μειώσεις][decrement] τον τρέχοντα αριθμό των στοιχείων.
- Μπορείς να χρησιμοποιήσεις τον έλεγχο `key in dict`, που επιστρέφει `True` αν το κλειδί υπάρχει, για να βεβαιωθείς ότι η τιμή βρίσκεται στο λεξικό πριν μειώσεις τον αριθμό των στοιχείων.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return-keyword] ένα λεξικό.

## 4. Αφαίρεσε εντελώς ένα στοιχείο από το απόθεμα

- Αν το στοιχείο βρίσκεται στο λεξικό, [αφαίρεσέ το][dict-pop].
- Αν το στοιχείο δε βρίσκεται στο λεξικό, μην κάνεις τίποτα.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return-keyword] ένα λεξικό.

## 5. Επίστρεψε το περιεχόμενο του αποθέματος

- Χρειάζεται να χρησιμοποιήσεις έναν [`for` βρόχο][for-loop] στο απόθεμα και αν ο αριθμός των στοιχείων είναι μεγαλύτερος του `0`, τότε να προσθέσεις την `tuple` σε μια `list`.
- Μπορείς να χρησιμοποιήσεις το [`dict.items()`][dict items] για να διατρέξεις ταυτόχρονα και το στοιχείο και την τιμή· το `items()` επιστρέφει μια `tuple` που μπορείς να χρησιμοποιήσεις ή να αποδομήσεις, αν χρειαστεί.
- Αυτή η συνάρτηση πρέπει να [επιστρέφει][return-keyword] μια [λίστα][list] από [πλειάδες][tuples].
