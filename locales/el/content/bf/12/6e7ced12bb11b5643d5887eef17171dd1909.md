# Οδηγίες

Ως μέλλουσα μάγισσα, η Elyse χρειάζεται να εξασκηθεί σε μερικά βασικά. Έχει μια στοίβα από κάρτες που θέλει να χειριστεί.

Για να γίνουν τα πράγματα λίγο πιο εύκολα, χρησιμοποιεί μόνο τις κάρτες 1 έως 10.

Η στοίβα από κάρτες αναπαρίσταται από μια `queue`, με το κάτω μέρος της στοίβας στο μπροστινό μέρος της ουράς και το πάνω μέρος της στοίβας στο πίσω μέρος.

## 1. Εισαγωγή κάρτας στην κορυφή της στοίβας

Υλοποίησε τη συνάρτηση `insert_top` που επιστρέφει ένα αντίγραφο της στοίβας με τη νέα κάρτα που δίνεται να προστίθεται στην κορυφή της στοίβας.

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. Αφαίρεση της πάνω κάρτας από τη στοίβα

Υλοποίησε τη συνάρτηση `remove_top_card` που επιστρέφει ένα αντίγραφο της στοίβας αφού της αφαιρεθεί η πάνω κάρτα. Αν η στοίβα που δίνεται είναι κενή, επέστρεψε την αρχική στοίβα, χωρίς αλλαγές.

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. Εισαγωγή κάρτας στο κάτω μέρος της στοίβας

Υλοποίησε τη συνάρτηση `insert_bottom` που επιστρέφει ένα αντίγραφο της στοίβας με τη νέα κάρτα που δίνεται να προστίθεται στο κάτω μέρος της στοίβας.

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. Αφαίρεση κάρτας από το κάτω μέρος της στοίβας

Υλοποίησε τη συνάρτηση `remove_bottom_card` που επιστρέφει ένα αντίγραφο της στοίβας αφού της αφαιρεθεί η κάτω κάρτα. Αν η στοίβα που δίνεται είναι κενή, επέστρεψε την αρχική στοίβα, χωρίς αλλαγές.

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. Έλεγχος του μεγέθους της στοίβας

Υλοποίησε τη συνάρτηση `check_size_of_stack` που ελέγχει αν το μέγεθος της στοίβας είναι ίσο με ένα δεδομένο `stack_size` ή όχι.

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
