# Εισαγωγή

Μέχρι τώρα έχουμε δει ότι τα ορίσματα που περνιούνται σε μια μέθοδο αντιστοιχίζονται με τις δηλωμένες παραμέτρους της μεθόδου με βάση τη θέση. Μια εναλλακτική προσέγγιση, ιδιαίτερα όταν μια ρουτίνα δέχεται μεγάλο αριθμό ορισμάτων, είναι ο καλών να αντιστοιχίζει τα ορίσματα καθορίζοντας το αναγνωριστικό της δηλωμένης παραμέτρου.

Το παρακάτω δείχνει τη σύνταξη:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
