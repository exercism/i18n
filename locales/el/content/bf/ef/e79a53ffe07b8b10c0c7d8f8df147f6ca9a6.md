# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να βοηθήσεις έναν freelancer να συνεννοηθεί με έναν project manager, παρέχοντας μερικά βοηθητικά εργαλεία για να υπολογίζει γρήγορα ημερήσιες και μηνιαίες χρεώσεις, προαιρετικά με μια δεδομένη έκπτωση.

Πρώτα ορίζουμε μερικούς κανόνες ανάμεσα στον freelancer και στον project manager:

- Η ημερήσια χρέωση είναι 8 φορές την ωριαία χρέωση.
- Ένας μήνας έχει 22 χρεώσιμες ημέρες.

Κάποιες φορές, ο freelancer προσφέρει έκπτωση στην ημερήσια χρέωσή του (για παράδειγμα, για τους πιο πιστούς πελάτες του ή για μη κερδοσκοπικούς πελάτες).

Οι εκπτώσεις μοντελοποιούνται ως δεκαδικοί αριθμοί που αντιπροσωπεύουν ποσοστό, για παράδειγμα `25.0` (25%).

## 1. Υπολόγισε την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση

Υλοποίησε μια συνάρτηση που υπολογίζει την ημερήσια χρέωση με δεδομένη την ωριαία χρέωση:

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

Η ημερήσια χρέωση που επιστρέφεται πρέπει να είναι float.

## 2. Υπολόγισε μια τιμή με έκπτωση

Υλοποίησε μια συνάρτηση που υπολογίζει την τιμή μετά από έκπτωση.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

Η τιμή που επιστρέφεται πρέπει να είναι πάντα float, χωρίς καμία στρογγυλοποίηση.

## 3. Υπολόγισε τη μηνιαία χρέωση, με δεδομένη την ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση που υπολογίζει τη μηνιαία χρέωση και εφαρμόζει μια έκπτωση:

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

Η μηνιαία χρέωση που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα πάνω (να παίρνεις την οροφή) στον πλησιέστερο ακέραιο.

## 4. Υπολόγισε τον αριθμό των εργάσιμων ημερών με δεδομένο έναν προϋπολογισμό, την ωριαία χρέωση και μια έκπτωση

Υλοποίησε μια συνάρτηση που παίρνει έναν προϋπολογισμό, μια ωριαία χρέωση και μια έκπτωση, και υπολογίζει πόσες εργάσιμες ημέρες καλύπτει.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

Ο αριθμός των εργάσιμων ημερών που επιστρέφεται πρέπει να στρογγυλοποιείται προς τα κάτω (να παίρνεις το δάπεδο) σε ένα δεκαδικό ψηφίο.
