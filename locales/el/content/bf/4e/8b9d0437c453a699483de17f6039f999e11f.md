# Εισαγωγή

Στην Python, [ένα `enum`][enum-docs] είναι ένα σύνολο ονομάτων που είναι δεσμευμένα σε μοναδικές τιμές `literal` ή `constant`.
Τα `Enums` ορίζονται με κληρονομικότητα από μια κλάση `Enum` ή με τη δημιουργία υποκλάσης της.
Οι ενσωματωμένοι τύποι `enum` είναι διαθέσιμοι στο module `enum` και η κλάση `Enum` μπορεί να εισαχθεί με `from enum import Enum`.


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

Σημείωσε ότι οι τιμές των μελών του `enum` μπορούν να είναι οποιοσδήποτε τύπος δεδομένων, όπως `str`, `tuple`, `float`, κ.λπ.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Όταν αντιστοιχίζεται η ίδια τιμή σε δύο μέλη ενός `enum`, το μέλος που αντιστοιχίζεται τελευταίο γίνεται ψευδώνυμο του πρώτου. Δεν επιτρέπεται να χρησιμοποιήσεις το ίδιο όνομα για δύο διαφορετικά μέλη ενός `enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Η επανάληψη μέσα από τα μέλη του `enum` μπορεί να γίνει με τη στάνταρ σύνταξη `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Τα μέλη του `Enum` μπορούν να συγκριθούν με τον [`is` (_τελεστή ταυτότητας_)][identity-keyword] ή τον `is not`. Οι `==` ή `!=` (_τελεστές ισότητας_) λειτουργούν επίσης με τον ίδιο τρόπο:

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Για να προσπελάσεις ένα μέλος του `enum` για μια δεδομένη τιμή, μπορείς να χρησιμοποιήσεις το `<EnumName>(<value>)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
