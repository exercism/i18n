# Υποδείξεις

## Γενικά

- Οι συναρτήσεις callback είναι συναρτήσεις που περνιούνται ως όρισμα σε μια συνάρτηση που τις καλεί.
- Οι συναρτήσεις callback πρέπει να πληρούν τις προδιαγραφές της συνάρτησης που τις καλεί.

## 1. Ειδοποίησε με μήνυμα επιτυχίας

- Χρησιμοποίησε την εισαγόμενη συνάρτηση API `notify` στη συνάρτησή σου.
- Πέρασε ένα αντικείμενο στο `notify`. Θα πρέπει να έχει μια ιδιότητα `message`. Σκέψου ποια θα πρέπει να είναι η τιμή του μηνύματος.
- Πρόσεξε την υπόδειξη τύπου του JSDoc: η συνάρτηση δε θα πρέπει να επιστρέφει τιμή.

## 2. Ειδοποίησε με μήνυμα σφάλματος

- Χρησιμοποίησε την εισαγόμενη συνάρτηση API `notify` στη συνάρτησή σου.
- Πέρασε ένα άλλο αντικείμενο στο `notify`. Θα πρέπει να έχει μια ιδιότητα `message`. Η τιμή του μηνύματος θα πρέπει να διαφέρει από το προηγούμενο μέρος.
- Πρόσεξε τα σχόλια [JSDoc] πάνω από τον ορισμό της συνάρτησης:
  - Η συνάρτηση δε θα πρέπει να επιστρέφει τιμή.

## 3. Κάνε παραγγελία για αγορά φρούτων

- Χρησιμοποίησε τη συνάρτηση `order` που έχεις ήδη εισαγάγει.
- Πρόσεξε τις υποδείξεις τύπου του JSDoc: η συνάρτηση θα πρέπει να δέχεται 3 ορίσματα και να μην επιστρέφει τιμή.
- Χρησιμοποίησε ξανά τις συναρτήσεις callback που δημιούργησες προηγουμένως ως ορίσματα στη συνάρτηση order.

## 4. Αναδιαμόρφωσε τη δουλειά σου σε μια πιο συνοπτική συνάρτηση

- Χρησιμοποίησε ξανά τις συναρτήσεις από τις προηγούμενες εργασίες.
- Πρόσεξε τις υποδείξεις τύπου του JSDoc: η συνάρτηση θα πρέπει να δέχεται 2 ορίσματα και να μην επιστρέφει τιμή.
- Συνδύασε τα ορίσματα σε ένα αντικείμενο που αντιπροσωπεύει το αίτημα προς τον μανάβη για να κάνεις παραγγελία.
