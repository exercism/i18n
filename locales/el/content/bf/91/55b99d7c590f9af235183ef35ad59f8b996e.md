# Εκτέλεση των tests

Οι ασκήσεις που τις κατεβάζεις με τον [πελάτη γραμμής εντολών του Exercism](https://exercism.io/cli) έρχονται με τουλάχιστον τρία αρχεία: ένα αρχείο `readme.md`, ένα αρχείο `.dpr` και ένα αρχείο `.pas`. Το αρχείο `.dpr` είναι το αρχείο project της Delphi και το αρχείο `.pas` είναι αυτό που εκτελεί τα tests. Φόρτωσε το project της Delphi είτε κάνοντας διπλό κλικ στο αρχείο `.dpr` είτε ανοίγοντας το project μέσα από τη Delphi. Θα πρέπει να δημιουργήσεις ένα νέο αρχείο `.pas` που θα περιέχει τον κώδικα της λύσης σου, πάνω στον οποίο θα εκτελεστούν τα tests. Δες το αρχείο `readme.md` για οδηγίες σχετικά με το πώς να μεταγλωττίσεις και να εκτελέσεις τον κώδικά σου.

Όλα τα tests έχουν αγνοηθεί εκτός από το πρώτο, πάνω στο οποίο θα δουλέψεις. Για να συνεχίσεις, σχολίασε το χαρακτηριστικό `[Ignore]` του test και ξεκίνα να δουλεύεις πάνω του.

Βεβαιώσου ότι το [DUnitX](https://github.com/VSoftTechnologies/DUnitX) είναι εγκατεστημένο, αν δεν το έχεις ήδη εγκαταστήσει με τα βήματα παραπάνω.
