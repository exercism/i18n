# Εισαγωγή

## Εξήγηση

Εκτός από πρωτόγονους τύπους δεδομένων όπως το `number` και το `string`, υπάρχει στη JavaScript ένας άλλος σημαντικός τύπος δεδομένων που ονομάζεται `object`.
Τα αντικείμενα είναι συλλογές από ζεύγη κλειδιού-τιμής.
Ως τέτοια, μπορούν να χρησιμοποιηθούν ως αυτό που σε άλλες γλώσσες συχνά αποκαλείται χάρτες ή λεξικά.

Σε άλλες γλώσσες, όλες οι τιμές σε έναν χάρτη πρέπει συχνά να έχουν τον ίδιο τύπο δεδομένων.
Στη JavaScript, περιορίζεται μόνο ο τύπος του κλειδιού: πρέπει να είναι συμβολοσειρά.
Οι τιμές μέσα σε ένα αντικείμενο μπορούν να έχουν διαφορετικούς τύπους.
Μπορούν να είναι πρωτόγονοι τύποι όπως αριθμοί, αλλά και πίνακες, άλλα αντικείμενα ή ακόμη και συναρτήσεις.
Αυτό κάνει τα αντικείμενα εξαιρετικά ευέλικτα, ώστε να αποτελούν και βασικές οντότητες για τον [αντικειμενοστρεφή προγραμματισμό][oop] (OOP) στη JavaScript.

Στη συνέχεια, θα επικεντρωθούμε στα αντικείμενα ως συλλογές ή χάρτες. Άλλες περιπτώσεις χρήσης των αντικειμένων καλύπτονται σε άλλες έννοιες, δες π.χ. τις [Κλάσεις][concept-classes].

## Δημιουργία Αντικειμένου

Δημιουργείς ένα αντικείμενο χρησιμοποιώντας άγκιστρα.
Μπορείς επίσης να συμπεριλάβεις απευθείας μερικές καταχωρήσεις.
Γι' αυτό, δήλωσε πρώτα το κλειδί, μετά μία άνω και κάτω τελεία και μετά την τιμή.

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

Το κόμμα μετά την τελευταία καταχώρηση είναι προαιρετικό στη JavaScript.

Ίσως αναρωτιέσαι γιατί τα κλειδιά δεν περικλείονται σε εισαγωγικά, αν και υποτίθεται ότι είναι συμβολοσειρές.
Αυτή είναι μια συντομευμένη σημειογραφία.
Αν το κλειδί ακολουθεί τους κανόνες ονοματοδοσίας για ένα [αναγνωριστικό][mdn-identifier] της JavaScript, μπορείς να παραλείψεις τα εισαγωγικά.
Για κλειδιά με ειδικούς χαρακτήρες στο όνομα, χρειάζεται να χρησιμοποιήσεις τη συνήθη σημειογραφία συμβολοσειράς.

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## Ανάκτηση Τιμής

Υπάρχουν δύο τρόποι για να ανακτήσεις την τιμή για ένα δεδομένο κλειδί: η σημειογραφία με τελεία και η σημειογραφία με αγκύλες.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

Η χρήση της σημειογραφίας με τελεία ως σύντμηση έχει τον ίδιο περιορισμό με την παράλειψη των εισαγωγικών.
Λειτουργεί μόνο αν το κλειδί ακολουθεί τους κανόνες ονοματοδοσίας των αναγνωριστικών.
Με άλλα λόγια, αν το κλειδί σου δεν είναι μία μόνο λέξη που χρησιμοποιεί μόνο γράμματα, πρέπει να χρησιμοποιήσεις τη σημειογραφία με αγκύλες.

## Προσθήκη ή Αλλαγή Τιμής

Μπορείς να προσθέσεις ή να αλλάξεις μια τιμή χρησιμοποιώντας τον τελεστή ανάθεσης `=`.
Και πάλι, υπάρχουν διαθέσιμες η σημειογραφία με τελεία και η σημειογραφία με αγκύλες.

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## Διαγραφή Καταχώρησης

Μπορείς να διαγράψεις ένα ζεύγος κλειδιού-τιμής από ένα αντικείμενο χρησιμοποιώντας τη λέξη-κλειδί `delete`.

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## Έλεγχος Αν Υπάρχει ένα Κλειδί

Μπορείς να ελέγξεις αν ένα συγκεκριμένο κλειδί υπάρχει σε ένα αντικείμενο με τη μέθοδο `hasOwnProperty`.

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## Διάσχιση ενός Αντικειμένου με Βρόχο

Υπάρχει ένας ειδικός βρόχος `for...in` για να διατρέξεις όλα τα κλειδιά ενός αντικειμένου.

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

Για να αποφύγεις λεπτά λάθη, θα πρέπει πάντα να υποθέτεις ότι ο βρόχος `for...in` επισκέπτεται τα κλειδιά με αυθαίρετη σειρά.
Επίσης, να έχεις υπόψη σου ότι το `for...in` συμπεριλαμβάνει [κληρονομημένα κλειδιά][concept-inheritance] στην επανάληψή του.
