# Φύλλο Χαρακτήρα RPG

## Ιστορία

Εσύ και οι φίλοι σου λατρεύετε να παίζετε παιχνίδια ρόλων με χαρτί και μολύβι, αλλά παρατήρησες ότι είναι δύσκολο να πείσεις νέα άτομα να μπουν στην ομάδα σου. Συχνά δυσκολεύονται με τη δημιουργία χαρακτήρα. Δεν ξέρουν από πού να ξεκινήσουν. Για να βοηθήσεις τους νέους παίκτες, αποφάσισες να γράψεις ένα μικρό πρόγραμμα που θα τους καθοδηγεί στη διαδικασία.

## Εργασίες

- Εκτύπωσε ένα μήνυμα καλωσορίσματος
- Ρώτησε για το όνομα, την κλάση και το επίπεδο του χαρακτήρα
- Συνδύασε τις πληροφορίες που δίνονται σε μια κανονικά μη εκτυπώσιμη δομή δεδομένων, π.χ. έναν χάρτη ή ένα struct, και εκτύπωσε και αυτό.
