# Απόφυγε καρφωτές περιπτώσεις δοκιμών

Αυτή η λύση έχει βάλει καρφωτές τιμές σε μερικά από τα δεδομένα δοκιμών.

Γενικά, οι λύσεις δεν θα πρέπει να βασίζονται στα συγκεκριμένα δεδομένα που δοκιμάζονται.
Αντ' αυτού, οι λύσεις θα πρέπει να λύνουν το πρόβλημα γενικά, για οποιαδήποτε είσοδο.

Αφαίρεσε τα καρφωτά δεδομένα δοκιμών.
