# Οδηγίες

Σε αυτή την άσκηση θα γράψεις κώδικα για να κρατάς μια λίστα με τις γλώσσες προγραμματισμού που θέλεις να μάθεις στο Exercism.

Έχεις έξι εργασίες, που όλες τους έχουν να κάνουν με λίστες.

## 1. Δημιούργησε μια νέα λίστα

Για να κρατάς λίστα με τις γλώσσες που θέλεις να μάθεις, θα χρειαστεί να δημιουργήσεις μια νέα λίστα. Όρισε τη συνάρτηση `new_list` που επιστρέφει μια νέα, κενή λίστα.

```gleam
new_list()
// -> []
```

## 2. Όρισε μια υπάρχουσα λίστα

Αυτή τη στιγμή, έχεις ένα χαρτί όπου είναι γραμμένες οι γλώσσες που θέλεις να μάθεις: Gleam, Go και TypeScript. Όρισε τη συνάρτηση `existing_list` ώστε να επιστρέφει αυτή τη λίστα.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Πρόσθεσε μια νέα γλώσσα σε μια λίστα

Καθώς εξερευνάς το Exercism και βρίσκεις πιο ενδιαφέρουσες γλώσσες, θέλεις να τις προσθέτεις στη λίστα σου. Υλοποίησε τη συνάρτηση `add_language` για να προσθέτεις μια νέα γλώσσα στην αρχή της λίστας σου.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Μέτρησε τις γλώσσες στη λίστα

Το να μετράς τις γλώσσες μία προς μία δεν είναι βολικό. Υλοποίησε τη συνάρτηση `count_languages` για να μετράς το πλήθος των γλωσσών στη λίστα σου.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Αντιστρέψε τη λίστα

Κάποια στιγμή, συνειδητοποιείς ότι η λίστα σου είναι στην πραγματικότητα με αντίστροφη σειρά! Υλοποίησε τη συνάρτηση `reverse_list` για να αντιστρέψεις τη λίστα σου.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Έλεγξε αν η λίστα είναι συναρπαστική

Αν και αγαπάς όλες τις γλώσσες, η Gleam έχει ξεχωριστή θέση στην καρδιά σου. Έτσι, ενθουσιάζεσαι πραγματικά με μια λίστα γλωσσών αν:

- Το πρώτο στη λίστα είναι η Gleam.
- Το δεύτερο στοιχείο της λίστας είναι η Gleam και η λίστα περιέχει είτε δύο είτε τρεις γλώσσες.

Υλοποίησε τη συνάρτηση `exciting_list` για να ελέγχεις αν μια λίστα γλωσσών είναι συναρπαστική:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
