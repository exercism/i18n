# workflow του configlet

Το workflow του configlet χρησιμοποιεί το [εργαλείο configlet](/docs/building/configlet) για να ελέγχει αν τα αρχεία (διαμόρφωσης) ενός track είναι σωστά δομημένα, και συντακτικά και σημασιολογικά.
Αυτό το κάνει τρέχοντας το [`configlet lint`](/docs/building/configlet/lint).

## Ενεργοποίηση του ελέγχου της μορφοποίησης αρχείων

Τα track μπορούν να χρησιμοποιήσουν το [`configlet fmt`](/docs/building/configlet/format) για να μορφοποιήσουν τα διάφορα αρχεία διαμόρφωσης του track.
Με την ίδια εντολή μπορείς επίσης να ελέγξεις αν όλα τα αρχεία διαμόρφωσης είναι σωστά μορφοποιημένα.

Το workflow του `configlet` υποστηρίζει τον έλεγχο του αν τα αρχεία διαμόρφωσης είναι σωστά μορφοποιημένα, αλλά αυτό είναι προαιρετικό και απενεργοποιημένο από προεπιλογή.
Για να ενεργοποιήσεις τον έλεγχο της μορφοποίησης των αρχείων διαμόρφωσης, ακολούθησε αυτά τα βήματα:

1. Δημιούργησε ένα αρχείο `.github/org-wide-files-config.toml` με το παρακάτω περιεχόμενο

```toml
[configlet]
fmt = true
```

2. Αφού συγχωνευτεί αυτό το αρχείο στο `main`, θα ανοίξει αυτόματα ένα PR που τροποποιεί το workflow `configlet.yml` ως εξής:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Μόλις συγχωνευτεί αυτό το PR, το workflow του `configlet` θα ελέγχει επίσης τη μορφοποίηση των αρχείων διαμόρφωσης του track.

## Πηγή

Το workflow ορίζεται στο αρχείο `.github/workflows/configlet.yml`.
