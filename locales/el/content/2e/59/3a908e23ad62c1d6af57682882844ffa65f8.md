# Εισαγωγή

Ενώ ο τροποποιητής `readonly` εμποδίζει την αντικατάσταση της τιμής ή της αναφοράς σε ένα πεδίο, δεν προσφέρει καμία προστασία για τα μέλη ενός τύπου αναφοράς.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Για να διασφαλίσεις ότι όλα τα μέλη ενός τύπου αναφοράς προστατεύονται, μπορείς να δηλώσεις τα πεδία ως `readonly` και να ορίσεις αυτόματες ιδιότητες χωρίς προσπελαστή `set`.

Η Βασική Βιβλιοθήκη Κλάσεων (BCL) παρέχει κάποιες εκδόσεις συλλογών μόνο για ανάγνωση, όταν χρειάζεται να εμποδιστεί η ενημέρωση των μελών μιας συλλογής. Αυτές έρχονται με τη μορφή περιτυλιγμάτων:

- Το `ReadOnlyDictionary<T>` εκθέτει ένα `Dictionary<T>` ως μόνο για ανάγνωση.
- Το `ReadOnlyCollection<T>` εκθέτει ένα `List<T>` ως μόνο για ανάγνωση.
