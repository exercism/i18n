# Εισαγωγή

Η χρήση της αντιστοίχισης προτύπων κυριαρχεί στον κατηγορηματικό, ιδιωματικό κώδικα Elixir. Μπορεί να θυμάσαι ότι το `=/2` περιγράφεται ως τελεστής αντιστοίχισης και όχι ως τελεστής ανάθεσης. Όταν χρησιμοποιείς τον τελεστή αντιστοίχισης, αν το πρότυπο στην αριστερή πλευρά ταιριάζει με τη δεξιά, τυχόν μεταβλητές στα αριστερά δεσμεύονται και επιστρέφεται η τιμή της δεξιάς πλευράς. Πετάγεται ένα `MatchError` αν δεν υπάρχει αντιστοίχιση.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Θυμήσου, οι αντιστοιχίσεις γίνονται από τη δεξιά πλευρά προς την αριστερή.

Στο τελευταίο παράδειγμα, αν δεν χρειαζόμαστε μια μεταβλητή σε μια αντιστοίχιση προτύπων, μπορούμε να την απορρίψουμε αναφέροντας το `_`. Οποιαδήποτε μεταβλητή ξεκινά με `_` δεν παρακολουθείται από το runtime.

## Αντιστοίχιση προτύπων σε ονομασμένες συναρτήσεις

Η αντιστοίχιση προτύπων είναι επίσης ένα χρήσιμο εργαλείο όταν δημιουργείς πολλαπλές ρήτρες συνάρτησης. Η αντιστοίχιση προτύπων μπορεί να χρησιμοποιηθεί στα ορίσματα των συναρτήσεων, τα οποία στη συνέχεια καθορίζουν ποια ρήτρα συνάρτησης θα κληθεί, ξεκινώντας από την κορυφή του αρχείου και προχωρώντας προς τα κάτω μέχρι την πρώτη αντιστοίχιση. Οι μεταβλητές μπορούν να δεσμευτούν σε μια κεφαλή συνάρτησης και να χρησιμοποιηθούν στο σώμα της συνάρτησης.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
