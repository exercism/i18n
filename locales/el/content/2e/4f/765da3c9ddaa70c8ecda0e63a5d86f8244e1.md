# Σχετικά

## Σύγκριση αριθμών

Στη `jq` οι αριθμοί μπορούν να συγκριθούν χρησιμοποιώντας τους παρακάτω τελεστές σχέσεων και ισότητας.

| Σύγκριση               | Τελεστής |
| ---------------------- | -------- |
| Μεγαλύτερο από         | `a > b`  |
| Μεγαλύτερο ή ίσο με    | `a >= b` |
| Μικρότερο από          | `a < b`  |
| Μικρότερο ή ίσο με     | `a <= b` |
| Ίσο με                 | `a == b` |
| Όχι ίσο με             | `a != b` |

Το αποτέλεσμα της σύγκρισης είναι πάντα μια Boolean τιμή (λογική τιμή), δηλαδή είτε `true` είτε `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

## Σύγκριση συμβολοσειρών

Οι παραπάνω τελεστές σύγκρισης μπορούν να χρησιμοποιηθούν και για τη σύγκριση συμβολοσειρών.
Σε αυτή την περίπτωση εφαρμόζεται λεξικογραφική σειρά.
Η σειρά καθορίζεται [από την τιμή του σημείου κώδικα Unicode][sort].

[sort]: https://jqlang.org/manual/#sort-sort_by

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Χρειάζεται να προσέχεις όταν συγκρίνεις δύο μεταβλητές που φαίνεται να περιέχουν αριθμητικές τιμές αλλά είναι τύπου συμβολοσειράς.
Λόγω της λεξικογραφικής σειράς, το αποτέλεσμα δεν θα είναι το ίδιο με τη σύγκριση τιμών τύπου αριθμού.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

## "Αυστηρή" ισότητα

Ο τελεστής `==` της `jq` είναι σαν τον `===` της Javascript, με την έννοια ότι πράγματα που "μοιάζουν" ίδια, αλλά είναι διαφορετικού τύπου, δεν είναι ίσα.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

## Σύγκριση πινάκων

Δύο πίνακες είναι ίσοι αν όλα τα αντίστοιχα στοιχεία τους είναι ίσα.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

## Σύγκριση αντικειμένων

Δύο αντικείμενα είναι ίσα αν έχουν τα ίδια ζεύγη κλειδιού-τιμής.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```
