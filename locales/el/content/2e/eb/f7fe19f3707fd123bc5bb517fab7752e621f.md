# Υποδείξεις

## Γενικά

- Για να δουλέψεις με την κλάση `DateTime`, πρέπει να _ανοίξεις_ τον χώρο ονομάτων `System`.

## 1. Ανάλυσε την ημερομηνία του ραντεβού

- Η κλάση `DateTime` έχει μια μέθοδο για την [ανάλυση][parsing] μιας `string` σε `DateTime`.

## 2. Έλεγξε αν ένα ραντεβού έχει ήδη περάσει

- Τα αντικείμενα `DateTime` μπορούν να συγκριθούν χρησιμοποιώντας τους προεπιλεγμένους [τελεστές σύγκρισης][operators].
- Υπάρχει μια [ιδιότητα][properties] για να ανακτήσεις την τρέχουσα ημερομηνία και ώρα.

## 3. Έλεγξε αν το ραντεβού είναι το απόγευμα

- Η πρόσβαση στο τμήμα της ώρας ενός αντικειμένου `DateTime` μπορεί να γίνει μέσω μιας από τις [ιδιότητές][properties] του.

## 4. Περιέγραψε την ώρα και την ημερομηνία του ραντεβού

- Τα tests τρέχουν σαν να βρίσκονται σε μηχάνημα στις Ηνωμένες Πολιτείες, που σημαίνει ότι όταν μετατρέπεις ένα `DateTime` σε `string` θα πάρεις ημερομηνίες και ώρα σε μορφή ΗΠΑ.
- Υπάρχει μια [ενσωματωμένη μέθοδος][to-string] για να μετατρέψεις ένα στιγμιότυπο `DateTime` σε `string`. Αν χρησιμοποιείς `sprintf`, αντί να χρησιμοποιήσεις το σύμβολο μορφοποίησης `%s` για συμβολοσειρές, υπάρχει [ένα άλλο σύμβολο μορφοποίησης][object-placeholder] που θα καλέσει αυτόματα τη μέθοδο που αναφέρθηκε παραπάνω.

## 5. Επίστρεψε την ημερομηνία επετείου

- Χρησιμοποίησε έναν από τους διάφορους [κατασκευαστές][constructors] της `DateTime` για να δημιουργήσεις ένα νέο στιγμιότυπο `DateTime`.
- Μπορείς να χρησιμοποιήσεις μία από τις [ιδιότητες][properties] της τρέχουσας ημερομηνίας και ώρας για να πάρεις το τρέχον έτος.
