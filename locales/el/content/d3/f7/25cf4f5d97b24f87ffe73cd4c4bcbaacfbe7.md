# Σχετικά

Η ColdFusion (CFML) είναι μια γλώσσα σεναρίων για την JVM, με σύνταξη παρόμοια με αυτή της C ή της JavaScript.
Μεταγλωττίζεται JIT σε byte code που εκτελείται στην JVM, αλλά είναι δυναμική και χαλαρά τυποποιημένη, κάτι που την κάνει γρήγορη και εύκολη στην ανάπτυξη.
Η CF είναι μια πολυπαραδειγματική γλώσσα, που υποστηρίζει κλασικό αντικειμενοστρεφή αλλά και συναρτησιακό προγραμματισμό.

Η CFML διαθέτει επίσης μια ενσωματωμένη γλώσσα προτύπων βασισμένη σε ετικέτες, που την κάνει ιδανική για εφαρμογές ιστού.
Εκτελείται σε περιβάλλον J2EE με πολλές βιβλιοθήκες που περιλαμβάνονται μαζί της, οι οποίες την κάνουν ιδιαίτερα παραγωγική χωρίς να χρειάζεται να εγκαταστήσεις πολλά πακέτα.
Η CFML έχει εγγενή υποστήριξη για αρχεία zip, δημιουργία PDF και Excel, email, FTP, HTTP, συστήματα αρχείων S3, βιβλιοθήκες ασφαλείας ESAPI, οδηγούς JDBC, καθώς και JSON και REST APIs.

Η CFML μπορεί επίσης να αξιοποιήσει οποιοδήποτε έργο Java, ρίχνοντας τα jars στο έργο και δημιουργώντας απευθείας αντικείμενα Java στον κώδικα σου.
