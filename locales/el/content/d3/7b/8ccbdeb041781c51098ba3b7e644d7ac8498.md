# Συμβουλές

## 1. Παρακολούθηση γύρων πόκερ

- Η συνάρτηση [`list`][list] επιστρέφει μια λίστα που αποτελείται από τα ορίσματα που της περνάς.

## 2. Διατήρηση όλων των γύρων στο ίδιο σημείο

- Η συνάρτηση [`concat`][concat] μπορεί να χρησιμοποιηθεί για να συνενώσεις δύο λίστες.

## 3. Εύρεση προηγούμενων γύρων

- Η συνάρτηση [`some`][some] επιστρέφει την πρώτη λογικά αληθή τιμή σε μια συλλογή.
- Η συνάρτηση [`boolean`][boolean] είναι χρήσιμη σε περιπτώσεις όπου μια συνάρτηση επιστρέφει μια τιμή αλλά τα tests περιμένουν Boolean.

## 4. Υπολογισμός μέσου όρου τιμών καρτών

- Θυμήσου τους βασικούς αριθμητικούς τελεστές, όπως [`/`][division] και [`+`][addition].
- Μια συλλογή αριθμών μπορεί να αθροιστεί χρησιμοποιώντας είτε [`apply`][apply] είτε [`reduce`][reduce].
- Η συνάρτηση [`count`][count] επιστρέφει τον αριθμό των στοιχείων σε μια συλλογή.
- Η συνάρτηση [`/`][division] επιστρέφει τύπο ratio όταν εφαρμόζεται σε ακέραιους. Μπορείς να χρησιμοποιήσεις τη [`double`][double] για να μετατρέψεις ένα ratio σε δεκαδικό.

## 5. Εναλλακτικοί μέσοι όροι

- Υπάρχουν συναρτήσεις ακολουθίας που επιστρέφουν το [`first`][first] ή το [`last`][last] στοιχείο μιας ακολουθιακής συλλογής.
- Για να βρεις τη μεσαία κάρτα, μπορείς να διαιρέσεις τον αριθμό των καρτών με το 2, να στρογγυλοποιήσεις προς τα κάτω στον μικρότερο ακέραιο με τη [`int`][int] και να ανακτήσεις την κάρτα σε αυτή τη θέση χρησιμοποιώντας τη [`nth`][nth].
- Χρησιμοποίησε το [`or`][or] για να προσδιορίσεις αν οποιαδήποτε από τις δύο συνθήκες είναι αληθής.

## 6. Περισσότερες τεχνικές υπολογισμού μέσου όρου

- Ένας τρόπος για να ανακτήσεις τις κάρτες σε άρτιες/περιττές θέσεις θα ήταν να κάνεις [`map`][map] μια συνάρτηση που χρησιμοποιεί τη [`nth`][nth] πάνω σε ένα [`range`][range], το οποίο δέχεται ένα προαιρετικό όρισμα `step`.

## 7. Κανόνες του γύρου μπόνους

- Θυμήσου πώς χρησιμοποιείται το [`if`][if] από την άσκηση για τις συνθήκες.
- Μπορείς να επιστρέψεις όλα τα στοιχεία μιας συλλογής εκτός από το τελευταίο χρησιμοποιώντας τη [`butlast`][butlast].
