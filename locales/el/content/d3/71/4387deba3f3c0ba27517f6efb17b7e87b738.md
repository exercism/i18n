# Εισαγωγή

Η Pyret έχει δύο ξεχωριστές Boolean αρχέγονες τιμές, το `true` και το `false`.
Αυτές οι δύο τιμές δηλώνουν αν μια πρόταση ή μια συνθήκη ισχύει ή όχι.

```pyret
"a" == "a" # true
"a" == "b" # false
```

Η Pyret παρέχει τους τελεστές `and` και `or`, οι οποίοι μπορούν να συνδυάσουν Boolean τιμές.

Ο τελεστής and επιστρέφει αληθή τιμή αν και οι δύο πλευρές είναι αληθείς και ψευδή σε όλους τους άλλους συνδυασμούς.

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

Ο τελεστής or επιστρέφει αληθή τιμή αν τουλάχιστον η μία πλευρά είναι αληθής και ψευδή αν και οι δύο πλευρές είναι ψευδείς.

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

Η `not()` είναι μια ενσωματωμένη συνάρτηση που μετατρέπει μια αληθή τιμή σε ψευδή ή μια ψευδή τιμή σε αληθή.

```pyret
not(true) # false
not(false) # true
```
