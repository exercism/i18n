# Σχετικά

Ο τύπος Boolean (λογική τιμή) στη Lua έχει τις δύο παραδοσιακές Boolean τιμές: `true` και `false`. Αυτές οι τιμές μπορούν να ανατεθούν σε μια μεταβλητή, να συνδυαστούν με λογικούς τελεστές (`and`, `or`, `not`) και να χρησιμοποιηθούν σε ελέγχους συνθηκών (π.χ. σε δομές ελέγχου).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Οι έλεγχοι συνθηκών και οι λογικοί τελεστές θεωρούν ψευδή τόσο το Boolean `false` όσο και το `nil`, και αληθές οτιδήποτε άλλο.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Τόσο το `and` όσο και το `or` χρησιμοποιούν *αξιολόγηση βραχυκυκλώματος*, που σημαίνει ότι αξιολογούν τον δεύτερο τελεστέο τους μόνο όταν είναι απαραίτητο. Όλες οι πράξεις αξιολογούνται σύμφωνα με την [προτεραιότητα τελεστών](https://www.lua.org/manual/5.4/manual.html#3.4.8), όπου το `not` αξιολογείται πριν από το `and` και το `or`.

Δεδομένου ότι μόνο το `false` και το `nil` θεωρούνται ψευδή και οτιδήποτε άλλο αληθές, ένα συνηθισμένο ιδίωμα στη Lua είναι το εξής:
```lua
x = x or y
```

Αυτό είναι ισοδύναμο με:
```lua
if not x then
  x = y
end
```

Είναι αρκετά συνηθισμένο να το χρησιμοποιείς αυτό σε συναρτήσεις, για να ορίσεις μια προεπιλεγμένη τιμή αν μια παράμετρος δεν έχει τιμή (είναι `nil`):
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
