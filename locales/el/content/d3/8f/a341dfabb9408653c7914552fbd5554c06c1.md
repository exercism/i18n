# Εισαγωγή

Εργάζεσαι σε μια εταιρεία που πουλάει γραμματοσειρές μέσω της ιστοσελίδας της.
Θα ήθελαν να δείχνουν μια διαφορετική πρόταση κάθε φορά που κάποιος βλέπει μια γραμματοσειρά στην ιστοσελίδα τους.
Για να δίνουν μια ολοκληρωμένη εικόνα της γραμματοσειράς, οι τυχαίες προτάσεις θα πρέπει να χρησιμοποιούν **όλα** τα γράμματα του αγγλικού αλφαβήτου.

Διοργανώνουν έναν διαγωνισμό για να μαζέψουν προτάσεις που θα μπορούν να χρησιμοποιήσουν.
Εσύ έχεις αναλάβει να ελέγχεις τις συμμετοχές για να δεις αν είναι έγκυρες.

```exercism/note
Το Pangram προέρχεται από τα ελληνικά, παν γράμμα, pan gramma, που σημαίνει "κάθε γράμμα".

Το πιο γνωστό αγγλικό pangram είναι:

> The quick brown fox jumps over the lazy dog.
```
