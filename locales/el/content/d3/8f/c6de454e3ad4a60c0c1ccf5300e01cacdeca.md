# Σχετικά

Το Coq είναι ταυτόχρονα μια γλώσσα προγραμματισμού και ένα λογικό σύστημα, βασισμένο στην [αντιστοιχία Curry-Howard](https://en.wikipedia.org/wiki/Curry%E2%80%93Howard_correspondence).
Για να είναι ένα λογικό σύστημα με νόημα, η γλώσσα έχει σχεδιαστεί έτσι ώστε κάθε πρόγραμμα γραμμένο σε Coq να τερματίζει εγγυημένα.
Εξαιτίας αυτού, το Coq χρησιμοποιείται σπάνια για γενικούς σκοπούς· αντ' αυτού, επιτρέπει να αναπτύσσεις *θεωρίες στα μαθηματικά* και να γράφεις *πιστοποιημένα προγράμματα*.

Το Coq είναι επίσης ένας διαδραστικός βοηθός αποδείξεων.
Δεν λύνει αυτόματα θεωρήματα, αλλά βοηθά τον χρήστη να χτίσει αποδείξεις μέσω τακτικών.
Η γλώσσα τακτικών (Ltac) είναι μια γλώσσα από μόνη της, που επιτρέπει να αυτοματοποιείς μέρη των αποδείξεων.
Ένα καλογραμμένο σενάριο απόδειξης μοιάζει με μια άτυπη απόδειξη γραμμένη σε πεζό λόγο.

Οι κύριοι τομείς εφαρμογής και έρευνας που χρησιμοποιούν το Coq περιλαμβάνουν:

* Μαθηματικά (θεωρία αριθμών, θεωρία συνόλων, θεωρία λογικής, θεωρία υπολογισιμότητας, άλγεβρα, γεωμετρία, ...)
* Γλώσσες προγραμματισμού (μεταγλωττιστές, μοντέλα εκτέλεσης, βελτιστοποιήσεις μεταγλωττιστών, σύστημα τύπων, ...)
* Πιστοποιημένοι αλγόριθμοι (ορθότητα και τερματισμός αλγορίθμων) και εξαγωγή σε μια γλώσσα γενικού σκοπού (συνήθως Ocaml ή Haskell)

Μερικά αξιοσημείωτα έργα σε Coq περιλαμβάνουν:

* Απόδειξη του [Προβλήματος των Τεσσάρων Χρωμάτων](https://madiot.fr/coq100/#32) που έχει ελεγχθεί από υπολογιστή
* Το [CompCert](http://compcert.inria.fr/compcert-C.html), ένας πιστοποιημένος μεταγλωττιστής C

Αν σε ενδιαφέρει το Coq αλλά δεν το έχεις μάθει ακόμα, συνήθως προτείνεται να ξεκινήσεις με τη σειρά [Software Foundations](https://softwarefoundations.cis.upenn.edu/).
Ειδικά τα πρώτα κεφάλαια (μέχρι το "IndProp") θα σου δώσουν τα βασικά που χρειάζεσαι πριν αρχίσεις να δουλεύεις με πιο ενδιαφέρουσες έννοιες και θεωρίες.
Ίσως βρεις ενδιαφέρουσες και [άλλες πηγές](https://coq.inria.fr/documentation).
