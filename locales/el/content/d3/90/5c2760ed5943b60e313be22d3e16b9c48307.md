# Προσθήκη οδηγιών

## Ειδικές οδηγίες για τη διαδρομή

Βεβαιώσου ότι η λύση σου είναι αρκετά γενική ώστε να επεκτείνεται εύκολα σε μεγαλύτερα ονόματα που περιέχουν περισσότερα γράμματα και ψηφία.
Αυτό συνήθως οδηγεί και σε καλύτερη ποιότητα κώδικα.

Πρόταση (αυτό δεν ελέγχεται ρητά):
Για να έχεις πάντα ένα μοναδικό όνομα, θα μπορούσες να υλοποιήσεις τη δική σου cache ή να χρησιμοποιήσεις ένα `Stream` με την ενσωματωμένη cache του.
