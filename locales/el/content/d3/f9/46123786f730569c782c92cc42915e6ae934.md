# Οδηγίες

Ενώ ετοιμάζεσαι να ψήσεις μπισκότα για τους φίλους σου, ανακάλυψες ότι πρέπει να μετατρέψεις κάποιες από τις μονάδες μέτρησης που χρησιμοποιεί η συνταγή. Γνωρίζοντας μόνο το μετρικό σύστημα, πρέπει να βρεις έναν τρόπο να μετατρέπεις τις συνηθισμένες αμερικανικές μονάδες μέτρησης για ψήσιμο σε χιλιοστόλιτρα (mL) για ευκολία σου.

Χρησιμοποίησε αυτόν τον πίνακα μετατροπών για τη λύση σου:

| Μονάδα προς μετατροπή | όγκος | σε χιλιοστόλιτρα (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| αμερικανική κούπα | 1      | 240                 |
| αμερικανική υγρή ουγγιά | 1      | 30                  |
| αμερικανικό κουταλάκι του γλυκού | 1      | 5                   |
| αμερικανική κουταλιά της σούπας | 1      | 15                  |

Καθώς είσαι ένας ταλαντούχος εκπαιδευόμενος προγραμματιστής, αποφασίζεις να χρησιμοποιήσεις τα χιλιοστόλιτρα ως ενδιάμεση μονάδα για να διευκολύνεις τη μετατροπή από οποιαδήποτε μονάδα του πίνακα σε οποιαδήποτε άλλη (ακόμα και στην ίδια).

## 1. Πάρε το αριθμητικό μέρος από ένα ζεύγος όγκου

Υλοποίησε τη συνάρτηση `KitchenCalculator.get_volume/1`. Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να επιστρέφει μόνο το αριθμητικό μέρος.

```elixir
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Μετέτρεψε το ζεύγος όγκου σε χιλιοστόλιτρα

Υλοποίησε τη συνάρτηση `KitchenCalculator.to_milliliter/1`. Δεδομένης μιας πλειάδας ζεύγους όγκου, θα πρέπει να μετατρέπει τον όγκο σε χιλιοστόλιτρα χρησιμοποιώντας τον πίνακα μετατροπών.

Χρησιμοποίησε πολλαπλές ρήτρες συνάρτησης και αντιστοίχιση προτύπων για να δημιουργήσεις τις συναρτήσεις για κάθε μονάδα. Τα άτομα που χρησιμοποιούνται για να δηλώσουν κάθε μονάδα είναι: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`. Επίστρεψε το αποτέλεσμα της μετατροπής τυλιγμένο σε μια πλειάδα.

```elixir
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Μετέτρεψε το ζεύγος όγκου από χιλιοστόλιτρα σε άλλη μονάδα

Υλοποίησε τη συνάρτηση `KitchenCalculator.from_milliliter/2`. Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον όγκο στην επιθυμητή μονάδα χρησιμοποιώντας τον πίνακα μετατροπών.

Χρησιμοποίησε πολλαπλές ρήτρες συνάρτησης και αντιστοίχιση προτύπων για να δημιουργήσεις τις συναρτήσεις για κάθε μονάδα. Τα άτομα που χρησιμοποιούνται για να δηλώσουν κάθε μονάδα είναι: `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon`, `:milliliter`

```elixir
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Μετέτρεψε από οποιαδήποτε μονάδα σε οποιαδήποτε μονάδα

Υλοποίησε τη συνάρτηση `KitchenCalculator.convert/2`. Δεδομένης μιας πλειάδας ζεύγους όγκου και της επιθυμητής μονάδας, θα πρέπει να μετατρέπει τον δεδομένο όγκο στην επιθυμητή μονάδα.

```elixir
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
