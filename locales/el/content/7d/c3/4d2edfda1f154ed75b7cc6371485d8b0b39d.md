# Οδηγίες

Μετάφρασε αλληλουχίες RNA σε πρωτεΐνες.

Το RNA μπορεί να χωριστεί σε αλληλουχίες τριών νουκλεοτιδίων, που ονομάζονται κωδικόνια, και μετά να μεταφραστεί σε ένα πολυπεπτίδιο, κάπως έτσι:

RNA: `"AUGUUUUCU"` => μεταφράζεται σε

Κωδικόνια: `"AUG", "UUU", "UCU"`
=> τα οποία γίνονται ένα πολυπεπτίδιο με την εξής αλληλουχία =>

Πρωτεΐνη: `"Methionine", "Phenylalanine", "Serine"`

Υπάρχουν 64 κωδικόνια, τα οποία με τη σειρά τους αντιστοιχούν σε 20 αμινοξέα. Ωστόσο, στην άσκηση αυτή δεν έχουν σημασία όλες οι αλληλουχίες κωδικονίων και τα αμινοξέα που προκύπτουν.
Αν δουλεύει για ένα κωδικόνιο, το πρόγραμμα θα πρέπει να δουλεύει για όλα.
Ωστόσο, μη διστάσεις να επεκτείνεις τη λίστα στο σύνολο δοκιμών, ώστε να τα περιλαμβάνει όλα.

Υπάρχουν επίσης τρία κωδικόνια τερματισμού (γνωστά και ως κωδικόνια 'STOP'). Αν το ριβόσωμα συναντήσει κάποιο από αυτά, η μετάφραση σταματά και η πρωτεΐνη τερματίζεται.

Όλα τα επόμενα κωδικόνια αγνοούνται, κάπως έτσι:

RNA: `"AUGUUUUCUUAAAUG"` =>

Κωδικόνια: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Πρωτεΐνη: `"Methionine", "Phenylalanine", "Serine"`

Πρόσεξε ότι το κωδικόνιο τερματισμού `"UAA"` τερματίζει τη μετάφραση και η τελευταία μεθειονίνη δεν μεταφράζεται στην αλληλουχία της πρωτεΐνης.

Παρακάτω βρίσκονται τα κωδικόνια και τα αμινοξέα που προκύπτουν και χρειάζονται για την άσκηση.

| Codon              | Protein       |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Μάθε περισσότερα για τη [μετάφραση πρωτεΐνης στη Wikipedia][protein-translation].

[protein-translation]: https://en.wikipedia.org/wiki/Translation_(biology)
