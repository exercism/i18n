# Υποδείξεις

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

- Τα [διανύσματα][vectors] αναπαρίστανται στη Clojure με αγκύλες (`[ ]`)

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν σήμερα

- Η συνάρτηση [`peek`][peek] μπορεί να χρησιμοποιηθεί για να επιστρέψει το τελευταίο στοιχείο ενός διανύσματος.

## 3. Αύξησε τη σημερινή μέτρηση

- Η συνάρτηση [`update`][update] μπορεί να χρησιμοποιηθεί για να επιστρέψει ένα νέο διάνυσμα με διαφορετικό στοιχείο σε μια δεδομένη θέση.

- Η συνάρτηση [`count`][count] μπορεί να χρησιμοποιηθεί για να βρεις το μήκος του διανύσματος.

- Οι συναρτήσεις [`inc`][inc] και [`dec`][dec] μπορούν να χρησιμοποιηθούν για να αυξήσεις και να μειώσεις ακέραιες τιμές.

## 4. Έλεγξε αν υπήρξε μέρα χωρίς επισκέψεις πουλιών

- Η συνάρτηση [`every?`][every?] μπορεί να χρησιμοποιηθεί για να ελέγξεις αν όλα τα στοιχεία μιας συλλογής ικανοποιούν ένα δεδομένο κατηγόρημα.

- Το κατηγόρημα [`pos?`][pos?] επιστρέφει `true` αν ένας αριθμός είναι μεγαλύτερος του μηδενός.

- Η συνάρτηση [`not`][not] επιστρέφει `true` αν μια έκφραση αξιολογείται ως λογικά ψευδής.

## 5. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τις πρώτες μέρες

- Η συνάρτηση [`take`][take] μπορεί να χρησιμοποιηθεί για να επιστρέψει μια ακολουθία με τα πρώτα n στοιχεία μιας συλλογής.

- Η συνάρτηση [`reduce`][reduce] μπορεί να χρησιμοποιηθεί για να αθροίσεις τις τιμές μιας συλλογής.

## 6. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

- Η συνάρτηση υψηλότερης τάξης [`filter`][filter] μπορεί να χρησιμοποιηθεί για να επιστρέψει μια ακολουθία στοιχείων μιας συλλογής που ικανοποιούν ένα δεδομένο κατηγόρημα.

## 7.  Έλεγξε αν η εβδομάδα είναι μονή

- Η συνάρτηση [`=`][equality] μπορεί να χρησιμοποιηθεί για να ελέγξεις την ισότητα.
