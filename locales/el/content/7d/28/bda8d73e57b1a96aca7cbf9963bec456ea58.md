# Άρθρα

Κάθε άσκηση μπορεί να έχει άρθρα συνδεδεμένα μαζί της, τα οποία εξερευνούν κάποια ενδιαφέρουσα πτυχή της άσκησης.

## Θέματα

Πιθανά θέματα που θα μπορούσε να εξερευνήσει ένα άρθρο:

- Σύγκριση των επιδόσεων διαφορετικών προσεγγίσεων
- Ό,τι ενδιαφέρον μπορείς να σκεφτείς!

## Γενικές σκέψεις

- Αν το άρθρο σου βασίζεται σε κώδικα που έχεις γράψει, σκέψου να κάνεις commit αυτόν τον κώδικα (μέσα στον κατάλογο του άρθρου)
  - Ένα παράδειγμα είναι ένα άρθρο για τις επιδόσεις, για το οποίο γράφτηκε κώδικας μέτρησης επιδόσεων

## Για ποιες ασκήσεις να γράψεις άρθρα;

Για οποιαδήποτε άσκηση, αρκεί να υπάρχει κάτι ενδιαφέρον να εξερευνήσεις.

## Αρχεία

Για κάθε άρθρο πρέπει να προσθέσεις τα εξής δύο αρχεία:

- `.articles/<article-slug>/content.md`: περιγραφή του άρθρου (δες [την τεκμηρίωση](/docs/building/tracks/practice-exercises#file-articles-article-slug-content-md))
- `.articles/<article-slug>/snippet.md`: snippet που παρουσιάζει το άρθρο (δες [την τεκμηρίωση](/docs/building/tracks/practice-exercises#file-articles-article-slug-snippet-txt))

Στη συνέχεια θα χρειαστεί να προσθέσεις ή να ενημερώσεις:

- `.articles/config.json`: μεταδεδομένα για τα άρθρα (δες [την τεκμηρίωση](/docs/building/tracks/practice-exercises#file-article-config-json))
