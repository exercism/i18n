# Εισαγωγή

Οι εξαιρέσεις είναι μια μορφή χειρισμού σφαλμάτων.
Ονομάζονται εξαιρέσεις, επειδή εμφανίζονται συνήθως όταν έχουμε να κάνουμε με κάποιο απρόσμενο γεγονός.

Σε οποιοδήποτε σημείο του κώδικά μας, μπορούμε να "πετάξουμε" μια εξαίρεση.
Αυτό το κάνουμε χρησιμοποιώντας τη μέθοδο `raise`, περνώντας ένα αντικείμενο, συνήθως ένα αντικείμενο Exception, αν και μπορούμε επίσης να χρησιμοποιήσουμε απλές συμβολοσειρές.
Για παράδειγμα, θα δεις στα stubs των ασκήσεων ότι χρησιμοποιούμε το ενσωματωμένο `RuntimeError` για να πούμε στη Ruby ότι μια μέθοδος δεν έχει υλοποιηθεί.
Μπορείς επίσης να χρησιμοποιήσεις τη συντομευμένη σύνταξη `raise(ExceptionObject, params)`.
Αν παραλειφθεί η κλάση της εξαίρεσης, χρησιμοποιείται το `RuntimeError` από προεπιλογή.
Για παράδειγμα:

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

Όταν η Ruby το δει αυτό, μεταφέρει το σφάλμα στην κορυφή του προγράμματος και στη συνέχεια τερματίζει.
Για παράδειγμα, αν προσπαθήσεις να διαιρέσεις κάτι με το μηδέν, θα δεις κάτι σαν αυτό:
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
