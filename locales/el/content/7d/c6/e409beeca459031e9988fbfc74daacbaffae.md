# Οδηγίες

Σε αυτή την άσκηση, πρέπει να μεταφράσεις μερικούς κανόνες από το κλασικό παιχνίδι Pac-Man σε συναρτήσεις Elixir.

Έχεις τέσσερις κανόνες να μεταφράσεις, όλοι σχετικοί με τις καταστάσεις του παιχνιδιού.

> Μην ανησυχείς για το πώς προκύπτουν τα ορίσματα, απλώς επικεντρώσου στον συνδυασμό τους για να επιστρέψεις το επιθυμητό αποτέλεσμα.

## 1. Όρισε αν ο Pac-Man τρώει ένα φάντασμα

Όρισε τη συνάρτηση `Rules.eat_ghost?/2` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ένα ενεργό χάπι ενέργειας_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή (λογική τιμή) αν ο Pac-Man μπορεί να φάει το φάντασμα. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής μόνο αν ο Pac-Man έχει ένα ενεργό χάπι ενέργειας και αγγίζει ένα φάντασμα.

```elixir
Rules.eat_ghost?(false, true)
# => false
```

## 2. Όρισε αν ο Pac-Man σκοράρει

Όρισε τη συνάρτηση `Rules.score?/2` που παίρνει δύο ορίσματα (_αν ο Pac-Man αγγίζει ένα χάπι ενέργειας_ και _αν ο Pac-Man αγγίζει μια κουκκίδα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man σκόραρε. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man αγγίζει ένα χάπι ενέργειας ή μια κουκκίδα.

```elixir
Rules.score?(true, true)
# => true
```

## 3. Όρισε αν ο Pac-Man χάνει

Όρισε τη συνάρτηση `Rules.lose?/2` που παίρνει δύο ορίσματα (_αν ο Pac-Man έχει ένα ενεργό χάπι ενέργειας_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man χάνει. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man αγγίζει ένα φάντασμα και δεν έχει ενεργό χάπι ενέργειας.

```elixir
Rules.lose?(false, true)
# => true
```

## 4. Όρισε αν ο Pac-Man κερδίζει

Όρισε τη συνάρτηση `Rules.win?/3` που παίρνει τρία ορίσματα (_αν ο Pac-Man έχει φάει όλες τις κουκκίδες_, _αν ο Pac-Man έχει ένα ενεργό χάπι ενέργειας_ και _αν ο Pac-Man αγγίζει ένα φάντασμα_) και επιστρέφει μια Boolean τιμή αν ο Pac-Man κερδίζει. Η συνάρτηση θα πρέπει να επιστρέφει την τιμή αληθής αν ο Pac-Man έχει φάει όλες τις κουκκίδες και δεν έχει χάσει με βάση τα ορίσματα που ορίζονται στο μέρος 3.

```elixir
Rules.win?(false, true, false)
# => false
```
