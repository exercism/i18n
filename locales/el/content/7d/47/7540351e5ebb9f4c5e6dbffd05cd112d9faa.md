# Προσάρτημα οδηγιών

## Μορφή κήπου

Ο κήπος αναπαρίσταται ως μια συμβολοσειρά με τερματισμό μηδενικού, με έναν χαρακτήρα νέας γραμμής στο τέλος κάθε σειράς.

Ένα παράδειγμα θα ήταν `"   \n * \n   \n"`

## Καταχωρητές

| Καταχωρητής | Χρήση        | Τύπος   | Περιγραφή                                      |
| ----------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`       | είσοδος      | διεύθυνση | συμβολοσειρά εισόδου με τερματισμό μηδενικού   |
| `$a1`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά εξόδου με τερματισμό μηδενικού    |
| `$t0-9`     | προσωρινή    | οποιοσδήποτε | για προσωρινή αποθήκευση                       |
