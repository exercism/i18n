# Σχετικά

Μια παράθεση, γραμμένη μέσα σε `[ ]`, είναι το ανάλογο του Factor για μια ανώνυμη συνάρτηση ή ένα μπλοκ κώδικα. Είναι μια τιμή πρώτης τάξης που μπορείς να την ωθήσεις στη στοίβα, να την αποθηκεύσεις ή να τη μεταβιβάσεις, και που εκτελείται μόνο όταν κάτι την *καλεί*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Οι παραθέσεις είναι ακολουθίες λέξεων, και ο Factor τις χρησιμοποιεί παντού όπου ένα κομμάτι συμπεριφοράς πρέπει να αναβληθεί ή να παραμετροποιηθεί:

- οι κλάδοι των `if` / `when` / `unless` / `cond`
- το κατηγόρημα των `filter`, `count`, `any?`, `all?`
- ο μετασχηματισμός των `map`, `each`, `reduce`
- το σώμα των `times`, `while`, `loop`

Η επίδραση μιας παράθεσης στη στοίβα μπορεί συνήθως να συναχθεί. Όταν δεν μπορεί, συνήθως όταν την αποθηκεύσεις και την καλέσεις με `call` αργότερα, δήλωσε την επίδραση ρητά: `call( a b -- c )`.

## Συνδυασμός παραθέσεων

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

Το `compose` συνενώνει δύο παραθέσεις από άκρη σε άκρη σε μια νέα παράθεση που εκτελεί πρώτα την πρώτη και μετά τη δεύτερη. Το `curry` προσθέτει μπροστά μια σταθερή τιμή και επιστρέφει μια παράθεση που θα ωθήσει αυτή την τιμή πριν καλέσει την αρχική. Και τα δύο παράγουν συνηθισμένες παραθέσεις που μπορείς να `call`, να αποθηκεύσεις ή να περάσεις σε combinators.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
