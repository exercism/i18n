# Οδηγίες

Σε αυτή την άσκηση θα χρειαστεί να υλοποιήσεις κάποιες μεθόδους για να χειριστείς έναν πίνακα γλωσσών προγραμματισμού.

## 1. Όρισε μια μέθοδο που να επιστρέφει έναν κενό πίνακα γλωσσών

Όρισε τη μέθοδο `LanguageList.list` που δεν παίρνει ορίσματα και επιστρέφει έναν κενό πίνακα του τύπου `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Όρισε μια μέθοδο που να προσθέτει μια γλώσσα στον πίνακα

Όρισε τη μέθοδο `LanguageList.add` που παίρνει 2 ορίσματα (έναν _πίνακα γλωσσών_ και μια συμβολοσειρά που περιέχει μια _γλώσσα_).
Η μέθοδος θα πρέπει να επιστρέφει τον πίνακα με τη νέα γλώσσα προστιθέμενη στο τέλος του πίνακα.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Όρισε μια μέθοδο που να αφαιρεί μια γλώσσα από τον πίνακα

Όρισε τη μέθοδο `LanguageList.remove` που παίρνει 1 όρισμα (έναν _πίνακα γλωσσών_).
Η μέθοδος θα πρέπει να επιστρέφει τον πίνακα χωρίς το τελευταίο στοιχείο.
Υπέθεσε ότι ο πίνακας θα έχει πάντα τουλάχιστον ένα στοιχείο.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Όρισε μια μέθοδο που να επιστρέφει το ν-οστό στοιχείο του πίνακα

Όρισε τη συνάρτηση `LanguageList.at` που παίρνει 2 ορίσματα (έναν _πίνακα γλωσσών_ και μια θέση).
Η μέθοδος θα πρέπει να επιστρέφει τη γλώσσα στη θέση ν του πίνακα.
Υπέθεσε ότι στη θέση αυτή θα υπάρχει πάντα μια γλώσσα.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Όρισε μια μέθοδο που να αναλύει μια συμβολοσειρά γλωσσών

Όρισε τη μέθοδο `LanguageList.parse` που παίρνει 1 όρισμα (μια συμβολοσειρά που περιέχει γλώσσες χωρισμένες με κόμμα).
Η μέθοδος θα πρέπει να επιστρέφει έναν πίνακα γλωσσών.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
