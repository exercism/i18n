# Γενικά

- Τεκμηρίωση API: [πακέτο regexp][package-regexp]
- Σύνταξη κανονικών εκφράσεων: [regexp/syntax][regexp-syntax]
- Η ιστοσελίδα [regex101.com][regex101] έχει έναν διαδικτυακό ελεγκτή κανονικών εκφράσεων.
- Συνιστάται να γράφεις τις κανονικές εκφράσεις ως [κυριολεκτικά συμβολοσειρών][raw-string-literals] μέσα σε backticks (βαρείες).

## 1. Προσδιόρισε τις αλλοιωμένες γραμμές καταγραφής

- Η συνάρτηση [regexp.MatchString][fun-re-match-string] ή η μέθοδος [MatchString][method-match-string] μπορεί να σου φανεί χρήσιμη εδώ.
- Σε μια κανονική έκφραση, ο χαρακτήρας `^` ταιριάζει με την αρχή μιας γραμμής/συμβολοσειράς.

## 2. Χώρισε τη γραμμή καταγραφής

- Η μέθοδος [Split][regexp-split] μπορεί να σου φανεί χρήσιμη εδώ.

## 3. Μέτρησε τον αριθμό των γραμμών που περιέχουν `password` μέσα σε εισαγωγικά

- Μπορείς να κάνεις την αντιστοίχιση της έκφρασης να ξεχωρίζει πεζά και κεφαλαία, βάζοντας το `(?i)` στην αρχή της κανονικής έκφρασης.
  Αυτό θα ορίσει το flag `i`.
  Δες [αυτό το σεμινάριο][yourbasic-i-flag].

## 4. Αφαίρεσε τα κατάλοιπα από την καταγραφή

- Η μέθοδος [ReplaceAllString][replace-all-string] μπορεί να σου φανεί χρήσιμη εδώ.

## 5. Σημείωσε τις γραμμές με ονόματα χρηστών

- Η μέθοδος [FindStringSubmatch][find-string-submatch] μπορεί να σου φανεί χρήσιμη εδώ.
