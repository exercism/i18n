# Οδηγίες

Ο φίλος σου ο Chandler σχεδιάζει να επισκεφτεί εξωτικά μέρη σε όλο τον κόσμο.
Δυστυχώς, ο Chandler δεν τα πάει καλά με τα μαθηματικά.
Ανησυχεί αρκετά μήπως τον εξαπατήσουν τα ανταλλακτήρια συναλλάγματος στο ταξίδι του, και θέλει να του φτιάξεις έναν υπολογιστή συναλλάγματος.

Αυτές είναι οι προδιαγραφές του για την εφαρμογή.

~~~~exercism/note
Οι συναρτήσεις αυτής της άσκησης δηλώνονται σε ένα αρχείο πηγαίου κώδικα C με τις υπογραφές που δίνονται.
Ο κώδικας σου σε assembly x86-64 πρέπει να ακολουθεί αυτές τις προδιαγραφές.
~~~~

## 1. Παρακολούθησε τα διαφορετικά νομίσματα

Έχεις δημιουργήσει ένα `enum currency_t` για να παρακολουθείς τα διαφορετικά νομίσματα που χρησιμοποιεί ο Chandler στα ταξίδια του:

```c
enum currency_t {
    GBP,
    EUR,
    JPY,
    AUD,
    BRL,
    CNY,
    CAD,
    INR
};
```

Κάποιες φορές χρειάζεται να εκτυπώσεις αυτά τα νομίσματα στην οθόνη για να ελέγξεις αν είναι σωστά.

Δημιούργησε τη συνάρτηση `stringify_currency`:

```c
void stringify_currency(char *buffer, enum currency_t currency);
```

Αυτή η συνάρτηση δεν έχει τιμή επιστροφής και πρέπει να αποθηκεύει μια συμβολοσειρά τύπου C στη θέση που δείχνει το `buffer`.
Η συμβολοσειρά πρέπει να αναπαριστά οπτικά το είδος του νομίσματος που πέρασε στη συνάρτηση:

```c
char buffer[4];
stringify_currency(buffer, CAD);
// => "CAD"
```

## 2. Έλεγξε την ισοτιμία

Δημιούργησε τη συνάρτηση `exchange_rate`:

```c
double exchange_rate(enum currency_t domestic_currency, enum currency_t foreign_currency, const double *value_in_US_dollars);
```

Το όρισμα `domestic_currency` αντιπροσωπεύει το τοπικό νόμισμα του Chandler που θα ανταλλαχθεί με ένα `foreign_currency`.

Το `value_in_US_dollars` είναι ένας δείκτης σε έναν πίνακα από `double` που περιέχει την τιμή μιας μονάδας κάθε νομίσματος σε δολάρια ΗΠΑ.
Τα νομίσματα είναι θέσεις σε αυτόν τον πίνακα.
Έτσι, αν το `EUR` είναι έγκυρο στοιχείο για το `enum currency_t`, τότε το `value_in_US_dollars[EUR]` δίνει την τιμή του `1 EUR` σε δολάρια ΗΠΑ.

Αυτή η συνάρτηση πρέπει να επιστρέφει την τιμή μιας μονάδας του ξένου νομίσματος στο εγχώριο νόμισμα.

```c
const double value_in_US_dollars[8] = {
    1.33329, 1.16443, 0.00654374, 0.650888,
    0.185577, 0.140420, 0.714142, 0.0113863
};

exchange_rate(JPY, GBP, value_in_US_dollars);
// => 203.750454633
```

## 3. Υπολόγισε την αξία των χαρτονομισμάτων

Δημιούργησε τη συνάρτηση `get_value_of_bills`:

```c
uint64_t get_value_of_bills(unsigned long long denomination, unsigned short number_of_bills);
```

Το όρισμα `denomination` είναι η ονομαστική αξία ενός μεμονωμένου χαρτονομίσματος, ενώ το `number_of_bills` είναι ο συνολικός αριθμός των χαρτονομισμάτων.

Αυτό το ανταλλακτήριο συναλλάσσει μόνο μετρητά σε συγκεκριμένες υποδιαιρέσεις.
Το συνολικό ποσό που λαμβάνεις πρέπει να διαιρείται με την αξία ενός "χαρτονομίσματος" ή μιας μονάδας, κάτι που μπορεί να αφήσει κλάσμα ή υπόλοιπο.
Η συνάρτηση σου πρέπει να επιστρέφει μόνο τη συνολική αξία των χαρτονομισμάτων (_χωρίς τα κλασματικά ποσά_) που θα σου έδινε το ανταλλακτήριο.
Δυστυχώς, το ανταλλακτήριο κρατάει το υπόλοιπο/τα ρέστα ως επιπλέον μπόνους.

```c
get_value_of_bills(5, 128);
// => 640
```

## 4. Υπολόγισε τον αριθμό των χαρτονομισμάτων

Δημιούργησε τη συνάρτηση `get_number_of_bills`:

```c
unsigned int get_number_of_bills(float amount, unsigned long long denomination);
```

Αυτή η συνάρτηση πρέπει να επιστρέφει τον _αριθμό των χαρτονομισμάτων_ που μπορείς να λάβεις μέσα στο δεδομένο _ποσό_.
Με άλλα λόγια: πόσα _ολόκληρα χαρτονομίσματα_ χωράνε στο αρχικό ποσό;
Θυμήσου, μπορείς να λάβεις μόνο _ολόκληρα χαρτονομίσματα_, όχι κλάσματα χαρτονομισμάτων, οπότε θυμήσου να διαιρέσεις αναλόγως.
Στην πράξη, στρογγυλοποιείς _προς τα κάτω_ στο πλησιέστερο ολόκληρο χαρτονόμισμα/ονομαστική αξία.

```c
get_number_of_bills(127.5, 5);
// => 25
```

## 5. Υπολόγισε την αξία μετά την ανταλλαγή

Δημιούργησε τη συνάρτηση `exchangeable_value`:

```c
uint32_t exchangeable_value(float budget, double exchange_rate, uint8_t spread, unsigned long long denomination);
```

Η παράμετρος `spread` είναι το _ποσοστό που κρατείται_ ως προμήθεια ανταλλαγής, γραμμένο ως ακέραιος.
Πρέπει να μετατραπεί σε δεκαδικό διαιρώντας το με το 100.
Σημείωσε ότι το spread προστίθεται στην ισοτιμία, έτσι ώστε ένα spread `10` να δίνει ισοτιμία 10% υψηλότερη.

Αυτή η συνάρτηση πρέπει να επιστρέφει τη μέγιστη αξία του νέου νομίσματος αφού υπολογίσεις την *ισοτιμία* προσαρμοσμένη με το *spread*.
Θυμήσου ότι η *ονομαστική αξία* του νομίσματος είναι ακέραιος αριθμός και δεν μπορεί να διαιρεθεί περαιτέρω.

```c
exchangeable_value(127.25, 0,873350884, 10, 20);
// => 120
exchangeable_value(127.25, 0,873350884, 10, 5);
// => 130
```
