# Εισαγωγή

## Αριθμοί

Από [το εγχειρίδιο][man-types]

> Το jq υποστηρίζει το ίδιο σύνολο τύπων δεδομένων με το JSON: αριθμούς, συμβολοσειρές, Boolean, πίνακες, αντικείμενα (που στη γλώσσα του JSON είναι hashes με κλειδιά μόνο συμβολοσειρών) και "null".

Ας επικεντρωθούμε στους **αριθμούς**.

### Αριθμοί και αριθμητικοί τελεστές

Όλοι οι αριθμοί, είτε είναι ακέραιοι είτε όχι, είναι αριθμοί κινητής υποδιαστολής διπλής ακρίβειας IEEE754.
Αυτό μας περιορίζει σε 53 bit ακρίβειας.

Οι συνήθεις τελεστές είναι διαθέσιμοι για χρήση με αριθμούς:

- αριθμητικές πράξεις: `+`, `-`, `*`, `/`, `%`
- συγκρίσεις: `==`, `!=`, `<`, `<=`, `>=`, `>`
- τυπικές [μαθηματικές συναρτήσεις][man-math]

  Για συναρτήσεις με ένα όρισμα, διοχέτευσε την τιμή στη συνάρτηση

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Για συναρτήσεις με δύο ορίσματα, οι συναρτήσεις αγνοούν την είσοδο και περιμένουν
  τα ορίσματα ως παραμέτρους (θυμήσου ότι οι παράμετροι χωρίζονται με ερωτηματικό)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  Ο διαχωριστής των ορισμάτων των συναρτήσεων είναι το ερωτηματικό, όχι το κόμμα.

### Άλλες εκφράσεις `jq`

Για να λύσεις την άσκηση, θα χρειαστεί να μάθεις για τις εκφράσεις υπό συνθήκη.

#### Εκφράσεις υπό συνθήκη

Το `jq` χρησιμοποιεί μια [έκφραση `if-then-else`][if-then-else] για τις **εκφράσεις υπό συνθήκη**.
Ως _έκφραση_, τοποθετείται μέσα σε ένα pipeline.

Η σύνταξη είναι: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

Η ρήτρα `else` είναι προαιρετική.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Για επιπλέον συνθήκες, χρησιμοποίησε το `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
