# Εισαγωγή

## Αριθμοί

Στην Python υπάρχουν τρία διαφορετικά είδη ενσωματωμένων αριθμών: `ints`, `floats` και `complex`. Ωστόσο, σε αυτή την άσκηση θα έχεις να κάνεις μόνο με `ints` και `floats`.

### ints

Τα `ints` είναι ακέραιοι αριθμοί. π.χ. `1234`, `-10`, `20201278`.

Οι ακέραιοι στην Python έχουν [αυθαίρετη ακρίβεια][arbitrary-precision], το πλήθος των ψηφίων περιορίζεται μόνο από τη διαθέσιμη μνήμη του συστήματος που φιλοξενεί το πρόγραμμα.

### floats

Τα `floats` είναι αριθμοί που περιέχουν δεκαδικό σημείο. π.χ. `0.0`,`3.14`,`-9.01`.

Οι αριθμοί κινητής υποδιαστολής υλοποιούνται συνήθως στην Python με ένα `double` στη C (_15 δεκαδικά ψηφία ακρίβειας_), αλλά η αναπαράστασή τους ποικίλλει ανάλογα με το σύστημα υποδοχής και άλλες λεπτομέρειες υλοποίησης. Αυτό μπορεί να δημιουργήσει εκπλήξεις όταν δουλεύεις με floats, αλλά είναι "αρκετά καλό" για τις περισσότερες περιπτώσεις.

## Αριθμητική

Η Python υποστηρίζει πλήρως αριθμητικές πράξεις μεταξύ `ints` και `floats`. Μετατρέπει τους στενότερους αριθμούς ώστε να ταιριάζουν με τους λιγότερο στενούς ομολόγους τους όταν χρησιμοποιούνται με τους δυαδικούς αριθμητικούς τελεστές (`+`, `-`, `*`, `/`, `//` και `%`).

Η Python θεωρεί τα `ints` στενότερα από τα `floats`. Έτσι, η χρήση ενός float σε μια παράσταση εξασφαλίζει ότι το αποτέλεσμα θα είναι κι αυτό float. Ωστόσο, στη διαίρεση το αποτέλεσμα θα είναι πάντα float, ακόμα κι αν χρησιμοποιούνται μόνο ακέραιοι.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Αν χρειάζεσαι ακέραιο αποτέλεσμα, μπορείς να χρησιμοποιήσεις το `//` για να περικόψεις το αποτέλεσμα.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Για να μετατρέψεις ένα float σε ακέραιο, μπορείς να χρησιμοποιήσεις την `int()`. Για να μετατρέψεις έναν ακέραιο σε float, μπορείς να χρησιμοποιήσεις την `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
