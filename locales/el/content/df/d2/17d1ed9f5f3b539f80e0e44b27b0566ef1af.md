# Σχετικά

[`case`][case] είναι μια δομή ελέγχου ροής που μας επιτρέπει να συγκρίνουμε μια δεδομένη τιμή με πολλά πρότυπα. Οι ρήτρες σε μια έκφραση `case` αξιολογούνται από πάνω προς τα κάτω, μέχρι να βρεθεί μια αντιστοίχιση.

Σε πολλές περιπτώσεις, η χρήση του `case` είναι εναλλάξιμη με τον ορισμό πολλαπλών ρητρών συνάρτησης. Η αντιστοίχιση προτύπων και οι φρουροί μπορούν να χρησιμοποιηθούν σε ρήτρες `case`.

```elixir
# one function clause, multiple case clauses
def age_group(age) do
  case age do
    0 -> ~c"infant"
    age when age < 4 -> ~c"baby"
    age when age < 13 -> ~c"child"
    age when age < 18 -> ~c"teenager"
    _ -> ~c"adult"
  end
end

# multiple function clauses, no case
def age_group(0), do: ~c"infant"
def age_group(age) when age < 4, do: ~c"baby"
def age_group(age) when age < 13, do: ~c"child"
def age_group(age) when age < 18, do: ~c"teenager"
def age_group(_), do: ~c"adult"
```

Δεν υπάρχουν αυστηροί κανόνες για την επιλογή του ενός έναντι του άλλου. Είναι θέμα προσωπικής προτίμησης που συνήθως εξαρτάται από τα συμφραζόμενα.
