# Εξαίρεση

Στον ιδανικό κόσμο, όλα λειτουργούν τέλεια.
Αλλά στον πραγματικό κόσμο, τα πράγματα μπορεί να πάνε στραβά, και ο τρόπος που χειριζόμαστε αυτές τις καταστάσεις έχει σημασία, ώστε το λογισμικό μας να είναι ανθεκτικό και αξιόπιστο.
Οι εξαιρέσεις είναι μια κρίσιμη έννοια στον προγραμματισμό που μας επιτρέπει να χειριζόμαστε σφάλματα και απρόβλεπτες καταστάσεις με κομψό τρόπο.

Το πέταγμα ενός σφάλματος, αν δεν αντιμετωπιστεί, σταματάει το πρόγραμμα και εμφανίζει ένα μήνυμα σφάλματος.
Στις περισσότερες περιπτώσεις, δεν θέλεις το πρόγραμμά σου να σταματήσει όταν προκύψει ένα σφάλμα, αλλά θέλεις να χειριστείς το σφάλμα και να συνεχίσεις την εκτέλεση του προγράμματος.

## Το πέταγμα μιας εξαίρεσης

Στην Crystal, πετάς εξαιρέσεις με τη λέξη-κλειδί `raise`, και μπορείς να της δώσεις είτε μια `String` είτε ένα αντικείμενο `Exception`.
Αν δεν αντιμετωπιστεί, το πρόγραμμα θα σταματήσει και θα εκτυπώσει το μήνυμα σφάλματος.

```crystal
raise "This is an error"
```

Υπάρχουν αρκετές ενσωματωμένες εξαιρέσεις στην Crystal, όπως οι `ArgumentError`, `IndexError`, `KeyError`, `IOError`, `SystemCallError`, `TypeError`, `ZeroDivisionError` και πολλές άλλες.
Αυτές απαιτούν να περάσεις ένα μήνυμα στην εξαίρεση.

```crystal
raise ArgumentError.new("This is an argument error")
```

## [Χειρισμός εξαιρέσεων][exception-handling]

Δεν θα θέλαμε το πρόγραμμά μας να καταρρεύσει όταν πετάγεται μια εξαίρεση.
Επομένως, όταν γνωρίζουμε ότι ένα κομμάτι κώδικα είναι επιρρεπές σε σφάλματα, μπορούμε να το τυλίξουμε σε ένα μπλοκ `begin` και να πιάσουμε την εξαίρεση με ένα μπλοκ `rescue`.
Το μπλοκ `begin` σηματοδοτεί την αρχή του κώδικα που μπορεί να πετάξει μια εξαίρεση, και το μπλοκ `rescue` χειρίζεται την εξαίρεση.

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
end
```

Το μπλοκ `rescue` μπορεί επίσης να καθοριστεί με μια μεταβλητή, για να πάρεις το αντικείμενο της εξαίρεσης.

```crystal
begin
 raise "This is an error"
rescue ex
 puts "An error occurred: #{ex.message}"
end
```

Το μπλοκ `rescue` μπορεί επίσης να καθοριστεί με έναν συγκεκριμένο τύπο εξαίρεσης, ώστε να πιάνει μόνο αυτή την εξαίρεση.

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
end

# or

begin
 raise ArgumentError.new("This is an argument error")
rescue ex : ArgumentError
 puts "An argument error occurred: #{ex.message}"
end
```

Μπορείς να χρησιμοποιήσεις πολλά μπλοκ `rescue` για να χειριστείς διαφορετικούς τύπους εξαιρέσεων.
Στο παρακάτω παράδειγμα, το πρώτο μπλοκ `rescue` θα πιάσει ένα `ArgumentError`, και το δεύτερο μπλοκ `rescue` θα πιάσει οποιαδήποτε άλλη εξαίρεση.

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
rescue
 puts "An error occurred!"
end
```

Το μπλοκ `begin` μπορεί επίσης να έχει ένα μπλοκ `else`, το οποίο εκτελείται αν δεν πεταχτεί καμία εξαίρεση.

```crystal
begin
 puts "No error occurred"
rescue
 puts "An error occurred!"
else
 puts "No error occurred"
end
```

Τέλος, υπάρχει ένα μπλοκ `ensure` που εκτελείται πάντα, ανεξάρτητα από το αν πετάχτηκε μια εξαίρεση.

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
ensure
 puts "This is always executed"
end
```

## Σύμβαση μεθόδων

Κάποιες μέθοδοι έχουν δύο εκδοχές, μία με `!` και μία χωρίς.
Αυτό μπορεί να σημαίνει δύο διαφορετικά πράγματα.
Το ένα είναι ότι η μέθοδος μεταλλάσσει το αντικείμενο, και το άλλο είναι ότι η μέθοδος μπορεί να πετάξει μια εξαίρεση.

Αλλά υπάρχει και μια άλλη σύμβαση σχετικά με το να τελειώνει μια μέθοδος με `?`, που αναφέρεται στην έννοια Boolean.
Κάποιες μέθοδοι πετούν μια εξαίρεση από προεπιλογή, αλλά έχουν και μια εκδοχή που τελειώνει με `?`, η οποία επιστρέφει `nil` αντί να πετάξει μια εξαίρεση.

Αυτό είναι ιδανικό όταν θέλεις να αποφύγεις το πέταγμα ενός σφάλματος.
Αυτό μπορεί να ωφελήσει την απόδοση, αφού δεν χρειάζεται να δημιουργήσει ένα ίχνος στοίβας, και, αν στηθεί σωστά, θα μπορούσε να κάνει τον κώδικα πιο ασφαλή.

## Προσαρμοσμένες εξαιρέσεις

Μπορείς επίσης να δημιουργήσεις τις δικές σου εξαιρέσεις, κληρονομώντας από την κλάση [`Exception`][exception].
Κάνοντάς το, μπορείς προαιρετικά να παρακάμψεις τη μέθοδο `initialize` για να ορίσεις το μήνυμα της εξαίρεσης.
Αυτό μπορεί να γίνει ορίζοντας σε μια μεταβλητή στιγμιοτύπου με το όνομα `@message` το μήνυμα.

```crystal
class MyException < Exception
 def initialize
   @message = "This is my exception"
 end
end

raise MyException.new
```
