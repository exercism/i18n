# Σχετικά

Τα [structs και οι κλάσεις][structs-and-classes] είναι τα βασικά δομικά στοιχεία για τη δημιουργία προσαρμοσμένων τύπων στη Swift.
Και τα δύο σου επιτρέπουν να ομαδοποιείς σχετικές ιδιότητες (δεδομένα) και μεθόδους (συμπεριφορά) σε επαναχρησιμοποιήσιμες μονάδες.
Οι περισσότεροι βασικοί τύποι στη Swift, όπως οι `Int`, `Double`, `String`, καθώς και οι τύποι συλλογών όπως οι `Array` και `Dictionary`, είναι υλοποιημένοι ως structs.

Για λεπτομερείς οδηγούς για κάθε τύπο, δες:

- [concept:swift/structs]()
- [concept:swift/classes]()

## Επιλογή ανάμεσα σε structs και κλάσεις

Ενώ και τα structs και οι κλάσεις σου επιτρέπουν να ορίζεις προσαρμοσμένους τύπους, διαφέρουν θεμελιωδώς ως προς τον τρόπο που μεταβιβάζονται στη μνήμη:

- **Τα structs είναι τύποι τιμής**: Όταν αντιγράφεις ή περνάς ένα struct, η Swift δημιουργεί ένα ανεξάρτητο αντίγραφο των δεδομένων του.
Οι αλλαγές που γίνονται σε ένα αντίγραφο δεν επηρεάζουν τα άλλα αντίγραφα.
- **Οι κλάσεις είναι τύποι αναφοράς**: Όταν αντιγράφεις ή περνάς ένα στιγμιότυπο κλάσης, η Swift μοιράζεται μια αναφορά στο υπάρχον στιγμιότυπο.
Οι αλλαγές που γίνονται μέσω μιας αναφοράς επηρεάζουν αμέσως όλες τις άλλες αναφορές που δείχνουν στο ίδιο στιγμιότυπο.

Η Swift δίνει έμφαση στην ασφάλεια και στην προβλέψιμη συμπεριφορά, κάτι που κάνει τα structs την προεπιλεγμένη σύσταση για τους περισσότερους προσαρμοσμένους τύπους.
Η χρήση τύπων τιμής διασφαλίζει ότι η τροποποίηση δεδομένων σε ένα σημείο του προγράμματός σου δεν παράγει απρόβλεπτες παρενέργειες αλλού.

Γενικά:

- **Χρησιμοποίησε struct** όταν μοντελοποιείς δεδομένα που αντιπροσωπεύουν ανεξάρτητες τιμές (όπως συντεταγμένες, σχήματα, γεωμετρικές διαστάσεις ή μορφοποιημένες καταγραφές).
- **Χρησιμοποίησε κλάση** όταν μοντελοποιείς οντότητες που έχουν ξεχωριστές ταυτότητες ή απαιτήσεις κοινής διάρκειας ζωής (όπως στοιχεία ελέγχου UI, συνδέσεις βάσεων δεδομένων ή λαβές αρχείων).
