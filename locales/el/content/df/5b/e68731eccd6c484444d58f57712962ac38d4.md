# Προετοιμασία για την εκκίνηση

Πριν είσαι έτοιμος να εκκινήσεις τη διαδρομή σου, βεβαιώσου ότι έχουν ολοκληρωθεί οι παρακάτω εργασίες.

## Ζήτησε εικονίδιο για τη διαδρομή

Για να σχεδιαστεί ένα εικονίδιο για τον ιστότοπο, άνοιξε ένα issue στο αποθετήριο [exercism/website-icons](https://github.com/exercism/website-icons/issues), απαντώντας στις παρακάτω ερωτήσεις:

- Έχει η γλώσσα επίσημο λογότυπο; Αν ναι
  - συμπερίλαβε έναν σύνδεσμο προς ένα παράδειγμα
  - ανάφερε τις απαιτήσεις αναφοράς και τα δικαιώματα που παρέχονται για τη χρήση αυτού του λογοτύπου
- Έχει η γλώσσα ανεπίσημο λογότυπο; Αν ναι
  - εξήγησε με ποιους τρόπους χρησιμοποιούν οι άνθρωποι το ανεπίσημο λογότυπο
  - συμπερίλαβε έναν σύνδεσμο προς ένα παράδειγμα
  - ανάφερε τις απαιτήσεις αναφοράς αυτού του λογοτύπου

## Πρόσθεσε τεκμηρίωση της διαδρομής

Πρόσθεσε τα παρακάτω έγγραφα της διαδρομής:

- `docs/ABOUT.md`: μια σύντομη εισαγωγή στη γλώσσα.
- `docs/INSTALLATION.md`: περιγράφει τι χρειάζεται να εγκαταστήσει ο μαθητής για να μπορεί να δουλεύει τη διαδρομή στο τοπικό του σύστημα χρησιμοποιώντας τη γραμμή εντολών.
- `docs/LEARNING.md`: σύνδεσμοι προς πόρους μάθησης.
- `docs/RESOURCES.md`: σύνδεσμοι προς χρήσιμους πόρους.
- `docs/TESTS.md`: περιγράφει όλα όσα σχετίζονται με την εκτέλεση των δοκιμών στη διαδρομή.

Αυτά τα έγγραφα θα βοηθήσουν τον μαθητή να ξεκινήσει με τη διαδρομή και να μάθει για τη διαδρομή και τη γλώσσα της.
Δες την [τεκμηρίωση για τα docs](/docs/building/tracks/docs) για περισσότερες πληροφορίες.

## Πρόσθεσε τεκμηρίωση ασκήσεων

Πρόσθεσε τα παρακάτω έγγραφα ασκήσεων:

- `exercises/shared/.docs/help.md`: περιέχει οδηγίες ειδικές για τη διαδρομή σχετικά με το πώς να ζητήσεις βοήθεια
- `exercises/shared/.docs/tests.md`: περιέχει οδηγίες ειδικές για τη διαδρομή σχετικά με το πώς να εκτελέσεις τις δοκιμές

## Πρόσθεσε απόσπασμα κώδικα

Πρόσθεσε ένα απόσπασμα κώδικα στο αρχείο `docs/SNIPPET.txt`.
Αυτό το απόσπασμα δίνει μια οπτική εικόνα του πώς μοιάζει η σύνταξη της γλώσσας.
Δες την [τεκμηρίωση για τα docs](/docs/building/tracks/docs) για περισσότερες πληροφορίες.

## Ενημέρωσε τα μεταδεδομένα

Τα μεταδεδομένα της διαδρομής ορίζονται στο [αρχείο config.json](/docs/building/tracks/config-json).
Οι παρακάτω ιδιότητες θα πρέπει να ενημερωθούν:

- `language`: η γλώσσα της διαδρομής (π.χ. `"C#"`). Το μήκος της πρέπει να είναι <= 255
- `slug`: η γλώσσα της διαδρομής ως συμβολοσειρά σε kebab-case με πεζά γράμματα (π.χ. `"csharp"`). Το μήκος της πρέπει να είναι <= 255
- `blurb`: μια σύντομη περιγραφή της γλώσσας. Το μήκος της πρέπει να είναι <= 400
- `online_editor`: ένα αντικείμενο που περιγράφει τις ρυθμίσεις που χρησιμοποιεί ο διαδικτυακός επεξεργαστής:
  - `indent_style`: είτε `"space"` είτε `"tab"`
  - `indent_size`: το μέγεθος της εσοχής ως ακέραιος αριθμός (π.χ. `4`)
  - `highlightjs_language`: το αναγνωριστικό γλώσσας για το Highlight.js (δες την [πλήρη λίστα αναγνωριστικών](https://github.com/highlightjs/highlight.js/blob/main/SUPPORTED_LANGUAGES.md)). Αν δεν υπάρχει υποστήριξη του Highlight.js, αυτό το πεδίο μπορεί να παραλειφθεί.
- `key_features`: τα βασικά χαρακτηριστικά της γλώσσας, που περιγράφουν συνοπτικά τα σημαντικότερα χαρακτηριστικά της. Για περισσότερες πληροφορίες, δες την [τεκμηρίωση για τα βασικά χαρακτηριστικά](/docs/building/tracks/config-json#h-key-features).
- `tags`: όρισε τις ετικέτες που ισχύουν για αυτή τη διαδρομή, κάτι που επιτρέπει την αναζήτησή της στον ιστότοπο. Για περισσότερες πληροφορίες και τη λίστα των υποστηριζόμενων ετικετών, δες την [τεκμηρίωση για τις ετικέτες](/docs/building/tracks/config-json#h-tags).
