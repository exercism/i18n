# Οδηγίες

Είσαι ένας φανατικός παρατηρητής πουλιών που παρακολουθεί πόσα πουλιά έχουν επισκεφτεί τον κήπο σου τις τελευταίες επτά ημέρες.

Έχεις έξι εργασίες, όλες σχετικές με τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου.

## 1. Έλεγξε ποιες ήταν οι μετρήσεις την προηγούμενη εβδομάδα

Για λόγους σύγκρισης, κρατάς πάντα κοντά σου ένα αντίγραφο των μετρήσεων της προηγούμενης εβδομάδας, οι οποίες ήταν: 0, 2, 5, 3, 7, 8 και 4. Υλοποίησε τη μέθοδο `BirdWatcher.getLastWeek()` που επιστρέφει τις μετρήσεις της προηγούμενης εβδομάδας:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν τον κήπο σήμερα

Υλοποίησε τη μέθοδο `BirdWatcher.getToday()` ώστε να επιστρέφει πόσα πουλιά επισκέφτηκαν τον κήπο σου σήμερα. Οι μετρήσεις των πουλιών είναι ταξινομημένες ανά ημέρα, με το πρώτο στοιχείο να είναι η μέτρηση της παλαιότερης ημέρας και το τελευταίο στοιχείο τη σημερινή μέτρηση.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Αύξησε τη σημερινή μέτρηση

Υλοποίησε τη μέθοδο `BirdWatcher.incrementTodaysCount()` για να αυξήσεις τη σημερινή μέτρηση:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Έλεγξε αν υπήρξε ημέρα χωρίς επισκέψεις πουλιών

Υλοποίησε τη μέθοδο `BirdWatcher.hasDayWithoutBirds()` που επιστρέφει `true` αν υπήρξε ημέρα κατά την οποία δεν επισκέφτηκε κανένα πουλί τον κήπο· διαφορετικά, επέστρεψε `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Υπολόγισε τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο για τις πρώτες ημέρες

Υλοποίησε τη μέθοδο `BirdWatcher.getCountForFirstDays()` που επιστρέφει τον αριθμό των πουλιών που επισκέφτηκαν τον κήπο σου από την αρχή της εβδομάδας, αλλά περιορίζει τη μέτρηση στον καθορισμένο αριθμό ημερών από την αρχή της εβδομάδας.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Υπολόγισε τον αριθμό των πολυάσχολων ημερών

Κάποιες ημέρες είναι πιο πολυάσχολες από άλλες. Πολυάσχολη ημέρα είναι μία κατά την οποία πέντε ή περισσότερα πουλιά έχουν επισκεφτεί τον κήπο σου.
Υλοποίησε τη μέθοδο `BirdWatcher.getBusyDays()` για να επιστρέψεις τον αριθμό των πολυάσχολων ημερών:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
