# Οδηγίες

Στο εργαστήριο όπου κάνεις έρευνα πάνω στο DNA, έχεις δοκιμάσει διάφορους τρόπους συμπίεσης των ερευνητικών σου δεδομένων για να εξοικονομήσεις χώρο αποθήκευσης. Ένας συνεργάτης σου προτείνει να μετατρέψεις τα δεδομένα DNA σε δυαδική αναπαράσταση:

| Νουκλεϊκό οξύ | Κωδικός |
| ------------ | ----- |
| Adenine      |  `00` |
| Cytosine     |  `01` |
| Guanine      |  `10` |
| Thymine      |  `11` |

Το σκέφτεσαι. Ενδέχεται να μειώσει το κόστος αποθήκευσης που απαιτείται, αλλά με κόστος την αναγνωσιμότητα από τον άνθρωπο. Αποφασίζεις να γράψεις ένα άρθρωμα που να κωδικοποιεί και να αποκωδικοποιεί τα δεδομένα σου, ώστε να μετρήσεις τι εξοικονομάς.

## 1. Κωδικοποίησε το νουκλεϊκό οξύ σε δυαδική τιμή

Υλοποίησε τη συνάρτηση `encode_nucleotide` ώστε να δέχεται ένα νουκλεοτίδιο και να επιστρέφει την ακέραια τιμή του κωδικοποιημένου κωδικού.

```gleam
encode_nucleotide(Cytosine)
// -> 1
// (which is equal to 0b01)
```

## 2. Αποκωδικοποίησε τη δυαδική τιμή σε νουκλεϊκό οξύ

Υλοποίησε τη συνάρτηση `decode_nucleotide` ώστε να δέχεται την ακέραια τιμή του κωδικοποιημένου κωδικού και να επιστρέφει το νουκλεοτίδιο.

```gleam
decode_nucleotide(0b01)
// -> Ok(Cytosine)
```

## 3. Κωδικοποίησε μια λίστα DNA

Υλοποίησε τη συνάρτηση `encode` ώστε να δέχεται μια λίστα με νουκλεοτίδια και να επιστρέφει έναν πίνακα bit με τα κωδικοποιημένα δεδομένα.

```gleam
encode([Adenine, Cytosine, Guanine, Thymine])
// -> <<27>>
```

## 4. Αποκωδικοποίησε έναν πίνακα bit DNA

Υλοποίησε τη συνάρτηση `decode` ώστε να δέχεται έναν πίνακα bit που αναπαριστά νουκλεϊκό οξύ και να επιστρέφει τα αποκωδικοποιημένα δεδομένα ως λίστα νουκλεοτιδίων.

```gleam
decode(<<27>>)
// -> Ok([Adenine, Cytosine, Guanine, Thymine])
```
