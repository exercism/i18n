# Εισαγωγή

Στο Toyland, τα τρένα είναι πάντα απασχολημένα, μεταφέροντας θησαυρούς σε όλη την πόλη, από γυαλιστερές μπίλιες μέχρι σπάνια τουβλάκια.
Οι ράγες πάνω στις οποίες κινούνται είναι φτιαγμένες από πολύχρωμα κομμάτια σε σχήμα ντόμινο, καθένα σημαδεμένο με δύο αριθμούς.
Για να κινηθούν τα τρένα, τα ντόμινο πρέπει να σχηματίσουν μια τέλεια αλυσίδα όπου τα νούμερα ταιριάζουν.

Σήμερα, μια επείγουσα παράδοση σπάνιων παιχνιδιών περιμένει.
Σου έχουν δώσει ένα σετ κομματιών ράγας για να εξετάσεις.
Αν μπορούν να σχηματίσουν μια συνεχή αλυσίδα, το τρένο θα ξεκινήσει, φέρνοντας χαμόγελα σε όλο το Toyland.
Αν όχι, το σετ θα πεταχτεί και θα δοκιμαστεί ένα άλλο.

Τα παιχνίδια υπολογίζουν σε σένα για να λύσεις αυτό το παζλ.
Θα ενώσουν τα ντόμινο τις ράγες και θα βάλουν το τρένο να κυλήσει, ή θα μείνει το σετ πίσω;
