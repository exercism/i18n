# Οδηγίες

Είσαι δάσκαλος.
Στο τέλος της χρονιάς, έχεις υπολογίσει έναν αριθμητικό βαθμό για κάθε μαθητή σου.
Τώρα πρέπει να τον μετατρέψεις σε βαθμό με γράμμα και να μετρήσεις πόσοι μαθητές πήραν κάθε βαθμό με γράμμα

## 1. Μετέτρεψε έναν αριθμητικό βαθμό σε βαθμό με γράμμα

Η συνάρτηση `letter_grade` παίρνει ως είσοδο έναν αριθμητικό βαθμό και επιστρέφει το γράμμα.
Χρησιμοποίησε αυτά τα διαστήματα:

| Γράμμα |      Βαθμός |
| :----: | ----------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

Παράδειγμα:

```jq
75 | letter_grade   # => "C"
```

## 2. Μέτρησε τον αριθμό των μαθητών για κάθε βαθμό με γράμμα

Η συνάρτηση `count_letter_grades` παίρνει ένα αντικείμενο που αντιστοιχίζει ονόματα μαθητών στους βαθμούς τους.
Η έξοδος θα είναι ένα αντικείμενο που αντιστοιχίζει κάθε βαθμό με γράμμα στον αριθμό των μαθητών που πήραν αυτόν τον βαθμό.

Παράδειγμα:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Υπάρχουν μερικοί διαφορετικοί τρόποι να το λύσεις.
Χρησιμοποίησε το φίλτρο `reduce` για εξάσκηση.
