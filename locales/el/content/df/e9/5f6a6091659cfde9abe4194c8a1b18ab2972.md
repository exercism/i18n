# Εισαγωγή

Οι χαρακτήρες και οι συμβολοσειρές αποτελούν τη βάση για την αναπαράσταση κειμένου στην Elm.
Μπορείς να σκεφτείς τις συμβολοσειρές ως λίστες χαρακτήρων, και οι περισσότερες συναρτήσεις του `List` έχουν το αντίστοιχό τους στο module `String`.

## Χαρακτήρες

Ο τύπος `Char` αναπαριστά έναν μόνο χαρακτήρα Unicode με απλά εισαγωγικά, π.χ. `'a'`.
Το module `Char` παρέχει συναρτήσεις κατηγορήματος (`Char -> Bool`) για να ελέγχεις ιδιότητες ενός χαρακτήρα: `isUpper`, `isLower`, `isAlpha` και `isAlphaNum`.
Το module παρέχει επίσης συναρτήσεις για τη μετατροπή ενός χαρακτήρα, `toUpper`, `toLower`, `toLocaleUpper`, `toLocaleLower`, καθώς και για τη μετατροπή από και προς την αριθμητική τιμή του σε Unicode (`Int`) με τις `toCode` και `fromCode`.

## Συμβολοσειρές

Ο τύπος `String` παρέχει μια ενσωματωμένη αναπαράσταση για αποδοτικό χειρισμό συμβολοσειρών και μπορεί να αναπαραστήσει οποιαδήποτε ακολουθία χαρακτήρων Unicode.
Οι συμβολοσειρές αναπαρίστανται με διπλά εισαγωγικά: `"this is a string"`.
Οι συμβολοσειρές πολλών γραμμών αναπαρίστανται με τρία διπλά εισαγωγικά και μπορούν να περιέχουν εισαγωγικά και αλλαγές γραμμής χωρίς χαρακτήρες διαφυγής.

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## Χειρισμός συμβολοσειρών

Η `reverse : String -> String` αντιστρέφει τη συμβολοσειρά.
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

Η `repeat : Int -> String -> String` επαναλαμβάνει μια συμβολοσειρά n φορές.
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

Η `replace : String -> String -> String -> String` αντικαθιστά όλες τις εμφανίσεις μιας δεδομένης υποσυμβολοσειράς.
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

Η `append : String -> String -> String` συνενώνει δύο συμβολοσειρές.
Μπορείς επίσης να χρησιμοποιήσεις τον τελεστή `++` για να το κάνεις αυτό.
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

Η `concat : List String -> String` συνενώνει μια λίστα συμβολοσειρών σε μία συμβολοσειρά.
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

Η `split : String -> String -> List String` χωρίζει μια συμβολοσειρά σε λίστα συμβολοσειρών στο δεδομένο διαχωριστικό.
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

Η `join : String -> List String -> String` συνενώνει μια λίστα συμβολοσειρών με ένα δεδομένο διαχωριστικό.
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

Η `words : String -> List String` σπάει μια συμβολοσειρά σε συμβολοσειρές, χωρίζοντάς την με βάση τμήματα κενών διαστημάτων.
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

Η `lines : String -> List String` σπάει μια συμβολοσειρά σε γραμμές, χωρίζοντας στις αλλαγές γραμμής.
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

Η `cons : Char -> String -> String` προσθέτει έναν χαρακτήρα στην αρχή μιας συμβολοσειράς.
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

Η `uncons : String -> Maybe ( Char, String )` χωρίζει μια μη κενή συμβολοσειρά στην κεφαλή και την ουρά της.
Αυτό σου επιτρέπει να κάνεις αντιστοίχιση προτύπων σε συμβολοσειρές ακριβώς όπως θα έκανες με λίστες.
Οι κενές συμβολοσειρές επιστρέφουν `Nothing`.
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## Λήψη υποσυμβολοσειρών

Η `slice : Int -> Int -> String -> String` παίρνει μια υποσυμβολοσειρά με δεδομένη θέση αρχής και τέλους.
Οι αρνητικές θέσεις μετρώνται ξεκινώντας από το τέλος της λίστας.
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

Οι `left : Int -> String -> String` και `right : Int -> String -> String` παίρνουν n χαρακτήρες από την αριστερή ή τη δεξιά πλευρά μιας συμβολοσειράς αντίστοιχα.

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

Οι `dropLeft : Int -> String -> String` και `dropRight : Int -> String -> String` αφαιρούν n χαρακτήρες από την αριστερή ή τη δεξιά πλευρά μιας συμβολοσειράς αντίστοιχα.
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## Έλεγχος ιδιοτήτων συμβολοσειρών

Η `length : String -> Int` επιστρέφει τον αριθμό των χαρακτήρων σε μια συμβολοσειρά.
```elm 
length "Hello world." 
    --> 12
```

Η `isEmpty : String -> Bool` προσδιορίζει αν μια συμβολοσειρά είναι κενή.
```elm 
isEmpty "Hello world." 
    --> False
```

Η `contains : String -> String -> Bool` ελέγχει αν η δεύτερη συμβολοσειρά περιέχει την πρώτη.
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

Οι `startsWith : String -> String -> Bool` και `endsWith : String -> String -> Bool` ελέγχουν αν η δεύτερη συμβολοσειρά αρχίζει/τελειώνει με μια δεδομένη υποσυμβολοσειρά.
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

Η `indexes : String -> String -> List Int` παίρνει μια λίστα με όλες τις θέσεις έναρξης μιας υποσυμβολοσειράς μέσα σε μια άλλη συμβολοσειρά.
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## Μετατροπή συμβολοσειρών
Η `toInt : String -> Maybe Int` προσπαθεί να μετατρέψει μια συμβολοσειρά σε `Just Int` και επιστρέφει `Nothing` για συμβολοσειρές με λανθασμένη μορφή.
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

Η `fromInt : Int -> String` μετατρέπει έναν ακέραιο σε συμβολοσειρά.
```elm
fromInt -42 
    --> "-42"
```

Η `toFloat : String -> Maybe Float` προσπαθεί να μετατρέψει μια συμβολοσειρά σε float, αποτυγχάνοντας για συμβολοσειρές με λανθασμένη μορφή.
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

Η `fromFloat : Float -> String` μετατρέπει ένα float σε συμβολοσειρά.
```elm
fromFloat 3.9 
    --> "3.9"
```

Οι `toList : String -> List Char` και `fromList : List Char -> String` μετατρέπουν μια συμβολοσειρά σε λίστα χαρακτήρων και αντίστροφα, αντίστοιχα.
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

Η `fromChar : Char -> String` μετατρέπει έναν χαρακτήρα σε συμβολοσειρά.
```elm
fromChar 'a' 
    --> "a"
```

## Μορφοποίηση συμβολοσειρών

Οι `toUpper : String -> String` και `toLower : String -> String` μετατρέπουν συμβολοσειρές σε όλα κεφαλαία ή όλα πεζά, αντίστοιχα.
Χρήσιμες για συγκρίσεις που δεν διακρίνουν πεζά και κεφαλαία.
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

Η `pad : Int -> Char -> String -> String` γεμίζει μια συμβολοσειρά και από τις δύο πλευρές με το `Char` που δίνεις, μέχρι να αποκτήσει το δεδομένο μήκος.
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
Παρομοίως, οι `padLeft` και `padRight` γεμίζουν μια συμβολοσειρά από τη μία ή την άλλη πλευρά μέχρι να αποκτήσει ένα δεδομένο μήκος.

Η `trim : String -> String` αφαιρεί τα κενά διαστήματα και από τις δύο πλευρές μιας συμβολοσειράς.
```elm
trim "  hats  \n" 
    --> "hats"
```
Οι `trimLeft` και `trimRight` αφαιρούν τα κενά διαστήματα από τη μία ή την άλλη πλευρά μιας συμβολοσειράς.

## Συναρτήσεις υψηλότερης τάξης

Η `map : (Char -> Char) -> String -> String` μετασχηματίζει κάθε χαρακτήρα μιας συμβολοσειράς με τη δεδομένη συνάρτηση.
Πρόσεξε ότι η συνάρτηση που δίνεις πρέπει να είναι μια αντιστοίχιση από και προς `Char`.
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

Η `filter : (Char -> Bool) -> String -> String` κρατάει μόνο τους χαρακτήρες που περνούν τον έλεγχο.
```elm
filter isDigit "R2-D2" 
    --> "22"
```

Η `foldl : (Char -> b -> b) -> b -> String -> b` ανάγει μια συμβολοσειρά ξεκινώντας από τα αριστερά.
Η συνάρτηση εφαρμόζεται με τον πρώτο χαρακτήρα ως πρώτη παράμετρο και μια αρχική τιμή που δίνεις ως δεύτερη παράμετρο.
Το αποτέλεσμα της συνάρτησης πρέπει να έχει τον ίδιο τύπο με την αρχική τιμή που δίνεις και εφαρμόζεται σε κάθε χαρακτήρα με τη σειρά.
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
Η `foldr` κάνει το ίδιο, αλλά ξεκινώντας από τη δεξιά πλευρά της συμβολοσειράς.

Η `any : (Char -> Bool) -> String -> Bool` προσδιορίζει αν κάποιος χαρακτήρας επιστρέφει `True` στο κατηγόρημα που δίνεις.
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
Η `all : (Char -> Bool) -> String -> Bool` προσδιορίζει αν όλοι οι χαρακτήρες μιας συμβολοσειράς επιστρέφουν `True` στο κατηγόρημα που δίνεις.
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
