# Σχετικά

Ο Printer της Common Lisp είναι ο μηχανισμός για την έξοδο δεδομένων σε ροές. Μια συνηθισμένη συνάρτηση σε αυτόν τον μηχανισμό είναι η `format`.

Η `format` δέχεται δύο υποχρεωτικές παραμέτρους: μια ροή στην οποία γράφει και μια συμβολοσειρά ελέγχου. Τα περιεχόμενα της συμβολοσειράς ελέγχου καθορίζουν πώς χρησιμοποιούνται τυχόν περαιτέρω ορίσματα.

Η πρώτη παράμετρος έχει δύο ειδικές τιμές: `t` και `nil`. Το `t` δηλώνει ότι θα χρησιμοποιηθεί η ροή που είναι δεσμευμένη στο `*standard-output*` και το `nil` δηλώνει ότι θα δημιουργηθεί και θα επιστραφεί μια συμβολοσειρά. Το `format` αξιολογείται σε `nil` εκτός αν η παράμετρος ροής είναι `nil`.

Η συμβολοσειρά ελέγχου μπορεί να περιέχει οδηγίες μορφοποίησης, οι οποίες δηλώνονται από ένα `~` που ακολουθείται από έναν χαρακτήρα (το αν ο χαρακτήρας είναι κεφαλαίος ή πεζός δεν έχει σημασία). Η οδηγία μορφοποίησης καθορίζει αν καταναλώνονται ορίσματα και πώς μορφοποιούνται στη ροή.

Οι σημαντικές βασικές οδηγίες μορφοποίησης είναι:

* `~A` - _αισθητικά_ μορφοποίηση με τρόπο "αναγνώσιμο από τον άνθρωπο".
* `~S` - μορφοποίηση στην _τυποποιημένη_ μορφή ώστε να είναι "αναγνώσιμο από μηχανή".
* `~%` - εκπέμπει μια νέα γραμμή
* `~&` - εκπέμπει μια νέα γραμμή, εκτός αν βρίσκεται ήδη στην αρχή μιας γραμμής.
* `~~` - εκπέμπει μια περισπωμένη.

Παραδείγματα:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
