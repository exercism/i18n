# Υποδείξεις

## 1. Έλεγξε αν μπορεί να γίνει μια γρήγορη επίθεση

Πρέπει να ελέγξουμε αν ο ιππότης είναι ξύπνιος και να _αντιστρέψουμε_ τη λογική τιμή που αντιπροσωπεύει την κατάστασή του. Αυτό μπορεί να γίνει με τη συνάρτηση [`not`][not].

## 2. Έλεγξε αν μπορείς να κατασκοπεύσεις την ομάδα

Θέλουμε η συνάρτηση να επιστρέφει `true` αν _οποιοδήποτε_ από τα κατηγορήματα που δίνονται είναι `true`. Αυτό μπορεί να γίνει με τη συνάρτηση [`or`][or].

## 3. Έλεγξε αν μπορείς να δώσεις σήμα στον φυλακισμένο

Θέλουμε να επιστρέφουμε `true` αν και μόνο αν _όλα_ τα κατηγορήματα που δίνονται είναι `true`. Αυτό μπορεί να γίνει με τη συνάρτηση [`and`][and].

## 4. Έλεγξε αν μπορείς να ελευθερώσεις τον φυλακισμένο

Εδώ, πρέπει να συνδυάσουμε τους τρεις βασικούς λογικούς τελεστές, [`and`][and], [`or`][or] και [`not`][not].

[not]: https://clojuredocs.org/clojure.core/not
[or]: https://clojuredocs.org/clojure.core/or
[and]: https://clojuredocs.org/clojure.core/and
