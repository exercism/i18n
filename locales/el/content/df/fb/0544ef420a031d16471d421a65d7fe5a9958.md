# Συμβουλές

## Γενικά

- Το αρχείο της λύσης σου συμπεριλαμβάνεται σε ένα άλλο, το οποίο καλεί τις μακροεντολές σου.
  Κράτησε το όνομα κάθε μακροεντολής και τη σειρά των ορισμάτων της ακριβώς όπως τα δίνει η εργασία, αλλιώς το αρχείο δε θα συναρμολογηθεί.
- Τα ορίσματα μιας μακροεντολής είναι διακριτικά, που αντικαθίστανται ως `%1`, `%2`, `%3` όπου κι αν εμφανίζονται στο σώμα.
  Μπορούν να είναι καταχωρητές, εκφράσεις διεύθυνσης ή κυριολεκτικά, αρκεί κάθε επέκταση να είναι έγκυρη εντολή.
- Κάθε μακροεντολή ελέγχεται για τους καταχωρητές που αφήνει ανέπαφους, όχι μόνο για το τι γράφει.
  Διάβασε τη σημείωση κάθε εργασίας για τους καταχωρητές που καταστρέφονται και άλλαξε μόνο τους καταχωρητές που επιτρέπει.

## 1. Ονόμασε τις σταθερές της μορφής

- Ένα `%define` μιας γραμμής δίνει ένα όνομα σε μια τιμή, ώστε ο υπόλοιπος κώδικας να διαβάζει το όνομα αντί για έναν σκέτο αριθμό.
  Για έναν σταθερό αριθμό, το `equ` κάνει το ίδιο και είναι η συνηθισμένη επιλογή για μια σταθερά.
- Οι σταθερές byte μπορούν να γραφτούν είτε ως δεκαεξαδικές (`0x20`) είτε ως κυριολεκτικός χαρακτήρας (`' '`).
  Και οι δύο συναρμολογούνται στην ίδια τιμή.

## 2. Γράψε τη μακροεντολή `fill_run`

- Πρέπει να δώσεις στο `rcx` το ευανάγνωστο όνομα `COUNTER`.
- Η `fill_run` είναι μια μακροεντολή πολλών γραμμών που παίρνει 3 ορίσματα.
  Οι μακροεντολές πολλών γραμμών ορίζονται με `%macro ... %endmacro`.
- Το πρώτο όρισμα της `fill_run` είναι μια διεύθυνση μνήμης σε έναν καταχωρητή γενικού σκοπού 64 bit.
  Το δεύτερο είναι το πλήθος, που μπορεί να περαστεί σε έναν καταχωρητή γενικού σκοπού 64 bit ή ως άμεση τιμή.
  Το τρίτο είναι ένα byte προς εγγραφή, ως άμεση τιμή.
  Θα πρέπει να σχεδιάσεις τον κώδικα μέσα στη μακροεντολή ώστε να λαμβάνει υπόψη αυτές τις προδιαγραφές.
- Ο μόνος καταχωρητής που επιτρέπεται να τροποποιήσει η `fill_run` είναι ο `COUNTER`.
- Ένας βρόχος μέσα σε μια μακροεντολή χρειάζεται συνήθως μια ετικέτα με πρόθεμα `%%`.
  Χωρίς αυτό το πρόθεμα, δημιουργείται η ίδια ετικέτα κάθε φορά που καλείται η μακροεντολή, κάτι που μπορεί να προκαλέσει σφάλμα αν η μακροεντολή κληθεί πάνω από μία φορά.

## 3. Γράψε τη μακροεντολή `lay_columns`

- Η `lay_columns` είναι μια μακροεντολή πολλών γραμμών που παίρνει 2 ορίσματα.
  Οι μακροεντολές πολλών γραμμών ορίζονται με `%macro ... %endmacro`.
- Και τα δύο ορίσματα της `lay_columns` περνιούνται σε καταχωρητές γενικού σκοπού 64 bit.
  Το πρώτο είναι μια διεύθυνση μνήμης, το δεύτερο είναι ένας ακέραιος.
  Θα πρέπει να σχεδιάσεις τον κώδικα μέσα στη μακροεντολή ώστε να λαμβάνει υπόψη αυτές τις προδιαγραφές.
- Οι μόνοι καταχωρητές που επιτρέπεται να τροποποιήσει η `lay_columns` είναι οι δύο που περνιούνται ως ορίσματα.
- Το πλήθος των μετατοπίσεων που πρέπει να γράψει η μακροεντολή είναι σταθερό κατά τη συναρμολόγηση.
  Μπορείς να χρησιμοποιήσεις `%rep ... %endrep` για να επαναλάβεις τον κώδικα.
- Ο υπολογισμός της μετατόπισης γίνεται με `offset[i] = margin + i * COLUMN_STRIDE`.
  Το `margin` είναι το δεύτερο όρισμα της μακροεντολής.
  Το `i` είναι ένας μετρητής βρόχου που μπορεί να οριστεί ως μεταβλητή `%assign`.

## 4. Γράψε τη μακροεντολή `set_header`

- Η `set_header` είναι μια μακροεντολή πολλών γραμμών που παίρνει 2 ορίσματα.
  Οι μακροεντολές πολλών γραμμών ορίζονται με `%macro ... %endmacro`.
- Το πρώτο όρισμα της `set_header` είναι η έκφραση μιας ενεργού διεύθυνσης μνήμης.
  Παίρνει έναν καταχωρητή βάσης, που μπορεί να αθροιστεί με έναν καταχωρητή θέσης κλιμακωμένο κατά `1`, `2`, `4` ή `8`, και μια άμεση τιμή.
  Αυτό σημαίνει ότι ένα σκέτο `rdi` είναι έγκυρο, όπως και το `rdi+rax*4+2`.
- Το δεύτερο όρισμα της `set_header` είναι μια άμεση τιμή που μπορεί να έχει τις τιμές `0`, `1` ή `2`.
- Η `set_header` δεν πρέπει να τροποποιεί κανέναν καταχωρητή.
- Θα πρέπει να αντιγράψεις υπό συνθήκη ένα byte στη διεύθυνση προορισμού κατά τη συναρμολόγηση, ανάλογα με το δεύτερο όρισμα.
  Η τιμή `0` πρέπει να αντιγράφει το `PLAIN`, η τιμή `1` πρέπει να αντιγράφει το `RULED` και η τιμή `2` πρέπει να αντιγράφει το `BOXED`.
