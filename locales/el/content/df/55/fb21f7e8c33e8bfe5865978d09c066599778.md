# Σχετικά

Οι συνδυαστές μετατρέπουν τα μοτίβα αναδιάταξης της στοίβας σε ονομασμένες, συνθέσιμες λέξεις. Όταν έχεις γράψει αρκετό Factor, σταματάς να σκέφτεσαι "πρέπει να κάνω `dup`, μετά να τρέξω το F και μετά να κρατήσω το αρχικό" και απλώς γράφεις `[ F ] keep`.

| μοτίβο | αναδιατάξεις | συνδυαστής |
|------------------------------------|-------------------------------|-----------------|
| εφαρμογή του F, διατήρηση της εισόδου | `dup F swap` | `[ F ] keep` |
| δύο συναρτήσεις πάνω στην ίδια είσοδο | `dup F swap G` | `[ F ] [ G ] bi` |
| τρεις συναρτήσεις πάνω στην ίδια είσοδο | μπερδεμένες | `[ F ] [ G ] [ H ] tri` |
| πολλές συναρτήσεις πάνω στην ίδια είσοδο | πολύ μπερδεμένες | `{ Fs … } cleave` |
| λειτουργία σε τιμές *κάτω* από την κορυφή | `swap F swap` | `[ F ] dip` |
| ίδια πράξη σε δύο τιμές | `swap F swap F` | `[ F ] bi@` |
| διαφορετικές πράξεις σε δύο τιμές | `swap F swap G` | `[ F ] [ G ] bi*` |

Η οικογένεια με πρόθεμα `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) κάνει το ίδιο όταν κάθε πράξη χρειάζεται *δύο* εισόδους· τα `3dup` και `4dup` επεκτείνουν το ιδίωμα της αντιγραφής σε τρεις ή τέσσερις τιμές στην κορυφή της στοίβας.

Πέρα από την οικογένεια cleave/dip/bi, το [`kernel`][kernel] προσφέρει επίσης παραλλαγές ροής ελέγχου που μεταδίδουν το `f` καθαρά:

| λέξη | αποτέλεσμα |
|-------------|-----------------------------------------------------|
| `if*` | ο αληθής κλάδος βλέπει την τιμή· ο ψευδής κλάδος όχι |
| `?last` | το τελευταίο στοιχείο μιας ακολουθίας ή `f` αν είναι κενή |
| `pop*` | παραλλαγή του `pop` που απορρίπτει την τιμή (μεταβάλλει το διάνυσμα) |
| `dupd` | αντιγράφει το *δεύτερο* από την κορυφή |
| `pick` | αντιγράφει το *τρίτο* από την κορυφή στην κορυφή |
| `swapd` | ανταλλάσσει το δεύτερο και το τρίτο από την κορυφή |
| `rotd` | περιστρέφει τα τρία κάτω στοιχεία μιας στοίβας βάθους τεσσάρων |
| `tuck` | αντιγράφει την κορυφή κάτω από το δεύτερο στοιχείο |
| `with` | ενσωματώνει μια σταθερή τιμή σε ένα quotation για HOS |
| `while` | επαναλαμβάνει όσο ισχύει ένα κατηγόρημα |
| `until` | επαναλαμβάνει μέχρι να ισχύσει ένα κατηγόρημα |

Η επιλογή του σωστού συνδυαστή είναι από μόνη της δεξιότητα. Ο γενικός κανόνας: όταν το σώμα ενός ορισμού έχει πάνω από μία λέξη αναδιάταξης στη σειρά, συνήθως υπάρχει ένας συνδυαστής που αποτυπώνει καλύτερα την πρόθεση.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
