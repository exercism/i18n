# Γενικές Κλάσεις

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## Τι είναι η παράμετρος

Το `T` αντιπροσωπεύει έναν τύπο που παρέχεται στο σημείο χρήσης. Ο Sather
δημιουργεί μια ξεχωριστή κλάση για κάθε συνδυασμό που χρησιμοποιείται
πραγματικά, όταν το πρόγραμμα μεταγλωττίζεται. Επομένως:

- τα `LOST_BOX{STR}` και `LOST_BOX{INT}` είναι άσχετοι μεταξύ τους τύποι·
- δεν υπάρχει έλεγχος κατά τον χρόνο εκτέλεσης, ούτε boxing ούτε μετατροπή·
- ένα σφάλμα στην κλάση εμφανίζεται για κάθε τύπο με τον οποίο χρησιμοποιείται.

Αυτή είναι η ίδια προσέγγιση με τα templates της C++ ή τα generics της Rust,
και όχι με τα generics της Java, όπου ο τύπος διαγράφεται και στην
πραγματικότητα τα πάντα είναι ένα αντικείμενο.

## Περιορισμένες παράμετροι

Ένα σκέτο `T` μπορεί να ανατεθεί, να περαστεί και να επιστραφεί, τίποτε άλλο,
γιατί τίποτε άλλο δεν είναι γνωστό γι' αυτό. Για να καλέσεις ρουτίνες πάνω
του, δήλωσε σε τι πρέπει να συμμορφώνεται:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

Το `T < $STR` απαιτεί το `T` να συμμορφώνεται με το `$STR` και, σε αντάλλαγμα,
επιτρέπει να κληθεί το `item.str`. Ό,τι δεν μπορεί να κάνει ένα σκέτο `T`, ένας
περιορισμός είναι ο τρόπος να το επιτρέψεις.

Χωρίς τον περιορισμό, το `item.str` δεν θα μεταγλωττιστεί, και το μήνυμα θα
δείξει τη γραμμή μέσα στη γενική κλάση, όχι τη γραμμή που τη χρησιμοποίησε.

## Γενικές ρουτίνες;

Δεν υπάρχουν. Μόνο οι κλάσεις παίρνουν παραμέτρους. Μια ρουτίνα που πρέπει να
δουλέψει με πολλούς τύπους είτε ζει μέσα σε μια γενική κλάση είτε παίρνει έναν
αφηρημένο τύπο, όπως το `$STR`.

## Πώς να διαλέξεις ανάμεσά τους

| | γενική κλάση | αφηρημένη κλάση |
| --- | --- | --- |
| αποφασίζεται | κατά τη μεταγλώττιση | κατά την εκτέλεση |
| κρατά | έναν τύπο ανά στιγμιοποίηση | οποιονδήποτε συμμορφούμενο τύπο |
| κόστος | κανένα | μια δυναμική ανάθεση |

Το `ARRAY{$ACT}` χρησιμοποιεί και τα δύο: γενικό ως προς τον τύπο των στοιχείων,
αφηρημένο ως προς το τι μπορεί να είναι αυτό το στοιχείο.

Προτίμησε μια γενική κλάση όταν ο τύπος είναι ίδιος σε όλη τη διάρκεια και ο
χρήστης της κλάσης το γνωρίζει. Προτίμησε μια αφηρημένη κλάση όταν πολλοί τύποι
πρέπει να συνυπάρχουν σε μία συλλογή.
