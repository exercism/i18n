# Τεστ

Κάθε άσκηση περιέχει ένα αρχείο τεστ.
Τρέξε τα τεστ χρησιμοποιώντας το πρόγραμμα `bats`.

```bash
bats test-hello-world.bats
```

Το `bats` θα χρειαστεί να εγκατασταθεί.
Δες τη σελίδα [Τεστ για το Bash][bash] για οδηγίες σχετικά με την εγκατάσταση του `bats` για το σύστημά σου.

### Το bats είναι υλοποιημένο σε bash

Το αρχείο bats είναι ένα σενάριο bash, με κάποιες ειδικές συναρτήσεις που αναγνωρίζει η εντολή `bats`.
Θα δεις κάποια τεστ που μοιάζουν κάπως έτσι:

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

Αυτή η σύνταξη `<<<` είναι ένα bash [Here String][here-string].
Στέλνει τη συμβολοσειρά στη δεξιά πλευρά στο standard input του προγράμματος στην αριστερή πλευρά.
Είναι ([περίπου][so]) το ίδιο με

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## Βοήθεια για τις συναρτήσεις assert

Τα τεστ χρησιμοποιούν συναρτήσεις από τη βιβλιοθήκη [bats-assert][bats-assert].
Εκεί θα βρεις βοήθεια για τις διάφορες συναρτήσεις `assert*`.

## Τεστ που παραλείπονται

Η επίλυση μιας άσκησης σημαίνει να περάσεις όλα τα τεστ της.
Από προεπιλογή, μόνο ένα τεστ (το πρώτο) εκτελείται όταν τρέχεις τα τεστ.
Αυτό γίνεται σκόπιμα, γιατί σου επιτρέπει να επικεντρωθείς στο να περάσεις μόνο αυτό το ένα τεστ.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο τεστ σχολιάζοντας ή αφαιρώντας τη

    [[ $BATS_RUN_SKIPPED == true ]] || skip

σημείωση που προηγείται των άλλων τεστ.

## Παράκαμψη των παραλείψεων

Για να τρέξεις όλα τα τεστ, μαζί και αυτά με σημειώσεις `skip`, μπορείς να τρέξεις:

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

Μπορεί να σου φανεί βολικό να χρησιμοποιήσεις μια συνάρτηση-περιτύλιγμα για να γλιτώσεις πληκτρολόγηση: στο `bash` μπορείς να κάνεις:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Έπειτα τρέξε τα τεστ με ένα απλό:

```bash
bats
```

## Αποσφαλμάτωση στο `jq`

Το `jq` έρχεται με ένα βολικό φίλτρο [`debug`][debug].
Χρησιμοποίησέ το όσο αναπτύσσεις τις λύσεις των ασκήσεών σου για να εξετάσεις τα δεδομένα που βρίσκονται αυτή τη στιγμή στη ροή του jq.
Δες το [έγγραφο για την αποσφαλμάτωση][debugging] για περισσότερες λεπτομέρειες.
