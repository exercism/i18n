# Εισαγωγή

Στην Common Lisp, μια συνάρτηση δεν επιστρέφει μόνο μία τιμή, αλλά μπορεί να επιστρέψει πολλαπλές τιμές.
Για παράδειγμα η `floor`, που στρογγυλοποιεί προς τα κάτω, με φορά προς το μηδέν, επιστρέφει δύο τιμές: η πρώτη είναι η στρογγυλοποιημένη τιμή και η δεύτερη είναι το υπόλοιπο.

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
(Θα δείχνουμε τις πολλαπλές τιμές που επιστρέφονται σε ξεχωριστές γραμμές της εξόδου.)

## Επιστροφή πολλαπλών τιμών

Αν θέλεις μια συνάρτηση να επιστρέφει πολλαπλές τιμές, χρησιμοποιείς το `values`:

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## Χειρισμός πολλαπλών τιμών

Αν σε ενδιαφέρει μόνο η πρώτη τιμή, τότε δεν χρειάζεται να κάνεις κάτι το ιδιαίτερο: η γλώσσα αναλαμβάνει τα υπόλοιπα:

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

Ωστόσο, αν θέλεις να προσπελάσεις και τις άλλες τιμές, υπάρχουν αρκετές συναρτήσεις που θα χρειαστεί να χρησιμοποιήσεις.
Δύο βασικά μάκρο είναι τα `multiple-value-list` και `multiple-value-bind`.
Αυτά χρησιμοποιούνται για να τυλίξουν κάτι που επιστρέφει πολλαπλές τιμές και να πιάσουν όλες τις τιμές.
Το πρώτο δημιουργεί μια λίστα με όλες τις τιμές.
Το δεύτερο σου επιτρέπει να δεσμεύσεις μεταβλητές σε κάθε επιμέρους τιμή.

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

Μια άλλη χρήσιμη συνάρτηση είναι η `nth-value`
