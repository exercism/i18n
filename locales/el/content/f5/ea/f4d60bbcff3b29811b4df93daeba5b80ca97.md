# Προσθήκη οδηγιών

## Μορφή εισόδου

Κάθε ντόμινο αποθηκεύεται ως δύο συνεχόμενα byte στη γραμμική μνήμη, ένα byte για κάθε μισό.

Για παράδειγμα, οι πέτρες `[2|1]`, `[2|3]` και `[1|3]` αναπαρίστανται ως ο πίνακας byte `[ 0x02, 0x01, 0x02, 0x03, 0x01, 0x03 ]`

## Δεσμευμένη μνήμη

Ο buffer για τα ντόμινα εισόδου χρησιμοποιεί τα byte 256-511 της γραμμικής μνήμης.
