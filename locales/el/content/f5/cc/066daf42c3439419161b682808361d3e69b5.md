# Γράφοντας τον κώδικα

Γράψε τον κώδικά σου στο αρχείο `<exercise_name>.zig`.
Κάποιες ασκήσεις έρχονται με έτοιμες υπογραφές για συγκεκριμένες δομές της Zig, όπως [σταθερές][constants], [συναρτήσεις][functions], [εισαγωγές][imports], [δομές][structs] και [πολλά άλλα ακόμα][et-cetera]!

Αυτές οι έτοιμες υπογραφές έχουν σκοπό να σε βοηθήσουν να ολοκληρώσεις τις ασκήσεις, δίνοντάς σου ένα ξεκάθαρο σημείο εκκίνησης.
Ωστόσο, δεν είναι απαραίτητο να ξεκινήσεις από αυτές τις υπογραφές.
Ειδικά όταν οποιοσδήποτε κώδικας περνάει τα τεστ τους είναι μια απολύτως αποδεκτή λύση.

## Εκτέλεση των τεστ

Για να τρέξεις τα τεστ, το μόνο που χρειάζεται να κάνεις είναι να εκτελέσεις την παρακάτω εντολή:

```bash
zig test test_exercise_name.zig
```

αντικαθιστώντας το `exercise_name` με το όνομα της άσκησης.
Η παραπάνω εντολή πρέπει να εκτελεστεί στον ριζικό κατάλογο της άσκησης, αφού το αρχείο τεστ της βρίσκεται στο ίδιο σημείο.
Επιπλέον, όλα τα τεστ κάθε άσκησης είναι ενεργοποιημένα από προεπιλογή και κανένα τεστ δεν μπορεί να παραλειφθεί.

Εφόσον όλα τα τεστ έχουν αυτούς τους περιορισμούς, θα πρέπει να [σχολιάσεις][comments] τα τεστ που δεν περνάνε, αν θέλεις να τα περάσεις ένα ένα.
Το σχόλιασμα ενός τεστ είναι τόσο απλό όσο να ξεκινήσεις κάθε γραμμή με `//`.
Διαφορετικά, όταν είσαι σίγουρος ότι η λύση σου μπορεί να περάσει τα τεστ, μπορείς να αφαιρέσεις τα σχόλια από αυτά τα τεστ για να δεις αν περνάει.
