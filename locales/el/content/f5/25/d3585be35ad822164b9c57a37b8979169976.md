# Οδηγίες

Σε αυτή την άσκηση, θα υλοποιήσεις ένα πρόγραμμα που καθορίζει την κατάσταση ενός παιχνιδιού [τρίλιζας][tic-tac-toe].
(_Ίσως το ξέρεις και ως "noughts and crosses" ή "Xs and Os"._)

Το παιχνίδι παίζεται σε ένα πλέγμα 3×3.
Οι παίκτες τοποθετούν εναλλάξ `X` και `O` στο πλέγμα.
Το παιχνίδι τελειώνει όταν ένας παίκτης κερδίσει βάζοντας τρία σημάδια στη σειρά, σε μια στήλη ή κατά μήκος μιας διαγωνίου του πλέγματος, ή όταν γεμίσει ολόκληρο το πλέγμα.

Σε αυτή την άσκηση, θα υποθέσουμε ότι ξεκινάει το `X`.

Δική σου δουλειά είναι να καθορίσεις σε ποια κατάσταση βρίσκεται ένα δεδομένο παιχνίδι.

Υπάρχουν 3 πιθανές καταστάσεις του παιχνιδιού:

- Το παιχνίδι βρίσκεται σε εξέλιξη (**ongoing**).
- Το παιχνίδι έληξε με ισοπαλία (**draw**).
- Το παιχνίδι έληξε με νίκη (**win**).

Αν το δεδομένο ταμπλό είναι άκυρο, πέτα ένα κατάλληλο σφάλμα.

Ένα ταμπλό είναι άκυρο αν πληροί τις παρακάτω προϋποθέσεις:

- Το δεδομένο ταμπλό δεν μπορεί να προκύψει όταν οι κινήσεις γίνονται με τη σωστή σειρά (θυμήσου ότι ξεκινάει το `X`).
- Το παιχνίδι συνεχίστηκε αφού είχε ήδη τελειώσει.

## Παραδείγματα

### Παιχνίδι σε εξέλιξη

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Ισοπαλία

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Νίκη

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### Άκυρο

#### Λάθος σειρά κινήσεων

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Το παιχνίδι συνεχίστηκε μετά τη νίκη

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
