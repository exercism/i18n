# Προτεινόμενη ανάγνωση

Καθώς η Smalltalk χρησιμοποιείται ευρέως, υπάρχει μεγάλη ποικιλία υλικού για διάβασμα.

## Ξεκινώντας

* [Pharo Main Site](https://pharo.org/documentation):
έχει πλήθος άρθρων και βοήθειας
* [Pharo Syntax Cheatsheet](https://files.pharo.org/media/pharoCheatSheet.pdf):
χωράει σε μια καρτ ποστάλ
* [I Can Read C but not Smalltalk](https://www.eli.sdsu.edu/courses/spring01/cs635/readingSmalltalk.pdf): μερικά εύκολα βήματα για να καταλάβεις τη Smalltalk
* [Pharo By Example (9.0)](https://books.pharo.org/pharo-by-example9/):
ένα ολόκληρο βιβλίο σε pdf με παραδείγματα βήμα προς βήμα
* [Learning OOP and TDD in Pharo](https://books.pharo.org/learning-oop/):
παρουσιάζει περισσότερες τεχνικές και έννοιες προγραμματισμού
* Το [Discord](https://discord.gg/QewZMZa) έχει ένα
ενεργό διαδικτυακό φόρουμ συζητήσεων για τη Pharo (χρησιμοποίησε τον σύνδεσμο πρόσκλησης στο πάνω μέρος της [Σελίδας Κοινότητας](https://pharo.org/community))
* [Pharo Mooc](https://mooc.pharo.org/):
προσφέρει μια σειρά από ολοκληρωμένα μαθήματα προγραμματισμού και βίντεο

## Πιο προχωρημένα

* [Deep Into Pharo](https://books.pharo.org/deep-into-pharo/):
σε περνάει από πιο προχωρημένα θέματα όπως τα γραφικά και η συντακτική ανάλυση
* [Pharo with style](https://github.com/SquareBracketAssociates/Booklet-PharoWithStyle):
είναι ο οδηγός για μορφοποίηση και σχεδιασμό με τον τρόπο της Pharo
* [Smalltalk with style](http://sdmeta.gforge.inria.fr/FreeBooks/WithStyle/SmalltalkWithStyle.pdf):
είναι ένας ευρύτερος οδηγός για μορφοποίηση και σχεδιασμό στη Smalltalk
* [Enterprise Pharo - Web Perspective](http://books.pharo.org/enterprise-pharo/):
καλύπτει διαδικτυακές εφαρμογές, http και δεδομένα
