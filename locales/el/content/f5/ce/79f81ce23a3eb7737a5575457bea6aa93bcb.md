# Εισαγωγή

Ο τύπος `char` της C# είναι ένα μέγεθος 16 bit που αναπαριστά τα μικρότερα διευθυνσιοδοτούμενα συστατικά του κειμένου.
Πολλοί χαρακτήρες `char` μπορούν να σχηματίσουν μια συμβολοσειρά όπως η `"word"` ή οι χαρακτήρες `char` μπορούν να
επεξεργαστούν ανεξάρτητα. Τα literal τους γράφονται με απλά εισαγωγικά, π.χ. `'A'`.

Οι χαρακτήρες `char` της C# υποστηρίζουν κωδικοποίηση UTF-16 Unicode, οπότε, εκτός από το λατινικό σύνολο χαρακτήρων,
μπορούν να αναπαρασταθούν σχεδόν όλα τα συστήματα γραφής που χρησιμοποιούνται παγκοσμίως,
π.χ. το ελληνικό γράμμα `'β'`.

Υπάρχουν πολλές ενσωματωμένες μέθοδοι βιβλιοθήκης για την επιθεώρηση και τον χειρισμό χαρακτήρων `char`. Αυτές
μπορούν να βρεθούν ως στατικές μέθοδοι της κλάσης `System.Char`.
