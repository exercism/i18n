# 24 Pull Requests για το Exercism - Έκδοση Ruby!

Καλωσορίζουμε όσους θέλουν να συνεισφέρουν στο έργο.

Κοίτα τις παρακάτω ετικέτες στη λίστα ζητημάτων μας:

* first-timers only
* good first patch
* bug
* enhancement

Ή παρατήρησες κάτι που αξίζει να συνεισφέρεις;  Η τεκμηρίωση δεν είναι αρκετά καλή;
Κάτι λείπει;  Υποβάλλεις και ελέγχεις ασκήσεις στο Exercism και
βλέπεις κάτι που δεν σου αρέσει;  Δημιούργησε ένα pull request!

Ρίξε μια ματιά στην τεκμηρίωση [Συμμετοχή σε ένα track](https://github.com/exercism/docs/blob/master/contributing-to-language-tracks/README.md#getting-involved-in-an-exercism-language-track), καθώς και σε μερικές [ιδέες για πράγματα που ψάχνουμε](http://exercism.io/languages/ruby/todo) για ασκήσεις που χρειάζεται να υλοποιηθούν.

Είμαστε διαθέσιμοι να απαντήσουμε σε ερωτήσεις στο φόρουμ μας [building-exercism].

[building-exercism]: https://forum.exercism.org/c/general/building-exercism/125
