# Προσάρτημα οδηγιών

## Μορφή πλέγματος

Το πλέγμα αναπαρίσταται ως συμβολοσειρά τερματιζόμενη με null, με έναν χαρακτήρα νέας γραμμής στο τέλος κάθε γραμμής.

## Καταχωρητές

| Καταχωρητής | Χρήση         | Τύπος    | Περιγραφή                                                                 |
| ----------- | ------------- | -------- | ------------------------------------------------------------------------- |
| `$a0`       | είσοδος       | διεύθυνση | συμβολοσειρά εισόδου τερματιζόμενη με null                                |
| `$a1`       | είσοδος/έξοδος | διεύθυνση | συμβολοσειρά αποτελέσματος τερματιζόμενη με null, κενή αν οι διαστάσεις του πλέγματος είναι άκυρες |
| `$v0`       | έξοδος        | ακέραιος | κατάσταση πλέγματος (`0` = `ok`, `-1` = `invalid columns`, `-2` = `invalid rows`) |
| `$t0-9`     | προσωρινός    | οποιοσδήποτε | για προσωρινή αποθήκευση                                                  |
