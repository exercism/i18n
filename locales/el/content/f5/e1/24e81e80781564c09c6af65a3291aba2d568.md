# Οδηγίες

Μάθε πώς να συνδυάζεις δεδομένα από δύο διαφορετικούς εσωτερικούς πίνακες σε έναν εσωτερικό πίνακα αποτελέσματος.

Η κλάση σου θα λάβει δύο εσωτερικούς πίνακες που περιέχουν δύο εντελώς διαφορετικά σύνολα δεδομένων, τα ALPHAS και NUMS.

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

Τα δεδομένα στον πίνακα ALPHA είναι όπως φαίνονται παρακάτω.

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

Τα δεδομένα στον πίνακα NUMS είναι όπως φαίνονται παρακάτω.

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

Η εργασία σου είναι να επιστρέψεις έναν εσωτερικό πίνακα με καταγραφές που συνδυάζουν τις τιμές κάθε κελιού του εσωτερικού πίνακα ALPHAS και του εσωτερικού πίνακα NUMS μαζί. Για παράδειγμα, η τιμή της πρώτης στήλης της πρώτης γραμμής του εσωτερικού πίνακα COMBINED_DATA θα πρέπει να είναι "A1".

Ο αναμενόμενος πίνακας επιστροφής έχει τον ακόλουθο ορισμό:

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
