# Οδηγίες

Σε αυτή την άσκηση θα υλοποιήσεις ένα μερικό σύνολο βοηθητικών συναρτήσεων για να βοηθήσεις έναν προγραμματιστή να καθαρίσει ονόματα αναγνωριστικών.

Στις 5 εργασίες θα χτίσεις σταδιακά τη συνάρτηση `clean`.
Ένα έγκυρο αναγνωριστικό αποτελείται από μηδέν ή περισσότερα γράμματα και κάτω παύλες.

Αν δοθεί μια κενή συμβολοσειρά στη συνάρτηση `clean`, θα πρέπει να επιστραφεί μια κενή συμβολοσειρά.

## 1. Αντικατέστησε τα κενά με κάτω παύλες

Υλοποίησε τη συνάρτηση `clean1` ώστε να αντικαθιστά κάθε κενό με κάτω παύλα. Αυτό ισχύει και για κενά στην αρχή και στο τέλος.

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. Αντικατέστησε τους χαρακτήρες ελέγχου με τη συμβολοσειρά με κεφαλαία γράμματα "[CTRL]"

Υλοποίησε τη συνάρτηση `clean2` ώστε να κάνει ό,τι κάνει η προηγούμενη συνάρτηση και να αντικαθιστά τους συνηθισμένους χαρακτήρες ελέγχου (\n, \t και \r ) με τη συμβολοσειρά `"[CTRL]"`.

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. Μετέτρεψε το kebab-case σε camelCase

Υλοποίησε τη συνάρτηση `clean3` ώστε να κάνει ό,τι κάνει η προηγούμενη συνάρτηση και να μετατρέπει το kebab-case σε camelCase.

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. Παράλειψε τα ψηφία

Υλοποίησε τη συνάρτηση `clean4` ώστε να κάνει ό,τι κάνει η προηγούμενη συνάρτηση και να παραλείπει όλα τα ψηφία.

```elm
clean4 "123"
    --> ""
```

## 5. Παράλειψε τα ελληνικά πεζά γράμματα

Τέλος, υλοποίησε τη συνάρτηση `clean` ώστε να κάνει ό,τι κάνει η προηγούμενη συνάρτηση και να παραλείπει οποιοδήποτε ελληνικό γράμμα στο εύρος από 'α' έως 'ω'.

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
