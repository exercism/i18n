# Σχετικά

Ένας *σωρός* είναι μια συλλογή που ξέρει πάντα το μικρότερο (ή το μεγαλύτερο) στοιχείο της και σου επιτρέπει να το αφαιρέσεις γρήγορα: είναι η φυσική υλοποίηση μιας *ουράς προτεραιότητας*. Οι σωροί βρίσκονται στο λεξιλόγιο [`heaps`][heaps].

Το `<min-heap>` φτιάχνει έναν κενό σωρό του οποίου το μικρότερο κλειδί βγαίνει πρώτο· το `<max-heap>` εξυπηρετεί πρώτα το μεγαλύτερο. Κάθε στοιχείο είναι μια *τιμή* που αποθηκεύεται κάτω από ένα *κλειδί*, και το κλειδί είναι η προτεραιότητα με βάση την οποία βάζει σε σειρά η Factor:

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Ο σωρός είναι *μεταβλητός*: το `heap-push` και το `heap-pop` τον αλλάζουν επί τόπου.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

Το `heap-peek` διαβάζει το πρώτο στοιχείο χωρίς να το αφαιρέσει· το `heap-pop` το αφαιρεί και το επιστρέφει· το `heap-pop-all` αδειάζει τον σωρό σε μια λίστα συσχετίσεων με ζεύγη `{ key value }` με σειρά προτεραιότητας.

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

Η εισαγωγή είναι `O(log n)` και η ανάγνωση του πρώτου στοιχείου είναι `O(1)`, οπότε το μοτίβο "πάρ' το πιο επείγον στοιχείο και μετά πρόσθεσε κι άλλα", όταν το επαναλαμβάνεις, παραμένει γρήγορο ακόμη και για μια μεγάλη ουρά. Η υλοποίηση είναι ένας δυαδικός σωρός αποθηκευμένος σε έναν πίνακα που μπορεί να μεγαλώσει· το κλειδί μπορεί να είναι οποιαδήποτε τιμή που μπορεί να διαταχθεί (αριθμοί, συμβολοσειρές, …).

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
