# Σχετικά

Οι `for` βρόχοι είναι ο πιο σύνθετος τύπος βρόχου στην PHP. Συμπεριφέρονται όπως οι `for` βρόχοι σε `C`, `Java` και `JavaScript`. Η βασική του μορφή είναι:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

Η πρώτη έκφραση (_expr1_) αξιολογείται πριν ξεκινήσει ο βρόχος. Η δεύτερη έκφραση (_expr2_) αξιολογείται πριν από κάθε επανάληψη, και αν αξιολογείται σε μια _truthy_ τιμή, εκτελούνται οι εντολές. Αφού εκτελεστούν οι εντολές, αξιολογείται η τρίτη έκφραση (_expr3_).
