# Εισαγωγή

## Αναδρομή ουράς

Όταν κάνεις [αναδρομή][exercism-recursion] μέσα από απαριθμήσιμα (λίστες, bitstrings, συμβολοσειρές), υπάρχουν συχνά δύο ζητήματα:

- πόση μνήμη χρειάζεται για να αποθηκευτεί το ίχνος των αναδρομικών κλήσεων συναρτήσεων
- πώς να χτίσεις τη λύση αποδοτικά

Για να αντιμετωπίσεις αυτά τα ζητήματα, μπορείς να χρησιμοποιήσεις έναν _συσσωρευτή_.

Ο συσσωρευτής είναι μια μεταβλητή που περνιέται μαζί με τα δεδομένα. Χρησιμοποιείται για να μεταφέρει την τρέχουσα κατάσταση της εκτέλεσης της συνάρτησης, από κλήση σε κλήση, μέχρι να φτάσουμε στη _βασική περίπτωση_. Στη βασική περίπτωση, ο συσσωρευτής χρησιμοποιείται για να επιστραφεί η τελική τιμή της αναδρομικής κλήσης της συνάρτησης.

Οι συσσωρευτές πρέπει να αρχικοποιούνται από τον συγγραφέα της συνάρτησης, όχι από τον χρήστη της. Για να το πετύχεις αυτό, δήλωσε δύο συναρτήσεις: μια δημόσια συνάρτηση που παίρνει ως ορίσματα μόνο τα απαραίτητα δεδομένα και αρχικοποιεί τον συσσωρευτή, και μια ιδιωτική συνάρτηση που παίρνει κι αυτή έναν συσσωρευτή. Στην Elixir, είναι συνηθισμένο μοτίβο να βάζεις το πρόθεμα `do_` στο όνομα της ιδιωτικής συνάρτησης.

```elixir
# Count the length of a list without an accumulator
def count([]), do: 0
def count([_head | tail]), do: 1 + count(tail)

# Count the length of a list with an accumulator
def count(list), do: do_count(list, 0)

defp do_count([], count), do: count
defp do_count([_head | tail], count), do: do_count(tail, count + 1)
```

Η χρήση ενός συσσωρευτή μάς επιτρέπει να μετατρέψουμε αναδρομικές συναρτήσεις σε _συναρτήσεις αναδρομής ουράς_. Μια συνάρτηση είναι _αναδρομική ουράς_ αν το _τελευταίο_ πράγμα που εκτελείται μέσα της είναι μια κλήση στον εαυτό της.
