# Εγκατάσταση του Swift

Ο Swift είναι διαθέσιμος σε macOS, Linux και Windows.
Η διαδικασία εγκατάστασης διαφέρει ανάλογα με το λειτουργικό σύστημα που χρησιμοποιείς.
Αξίζει να σημειώσεις ότι, όσον αφορά την υποστήριξη στο Linux, ο Swift υποστηρίζεται (επίσημα) μόνο στις εξής διανομές:
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

Αν χρησιμοποιείς κάποια άλλη διανομή Linux, θα χρειαστεί να βρεις τον δικό σου τρόπο να εγκαταστήσεις τον Swift.

## Xcode (macOS)

Ο Swift περιλαμβάνεται στο Xcode, το IDE (Ολοκληρωμένο Περιβάλλον Ανάπτυξης) της Apple για ανάπτυξη σε macOS και iOS.
Για το track του Exercism θα χρειαστεί να έχεις εγκατεστημένη την έκδοση 16.0 του Xcode ή νεότερη.
Το Xcode διατίθεται δωρεάν στο [Mac App Store][xcode].
Επιπλέον εκδόσεις του Xcode (συμπεριλαμβανομένης της πιο πρόσφατης beta) είναι διαθέσιμες στο [κέντρο προγραμματιστών της Apple][apple-developer-center].

## macOS & Linux

Για macOS και Linux, υπάρχει ένας διαχειριστής εγκατάστασης του Swift που λέγεται [swiftly][swiftly].
Είναι ένα εργαλείο γραμμής εντολών που σου επιτρέπει να εγκαταστήσεις και να διαχειριστείς πολλές εκδόσεις του Swift στο σύστημά σου.
Την εντολή για να εγκαταστήσεις το swiftly σε macOS θα τη βρεις [εδώ][swiftly-macos], και για Linux [εδώ][swiftly-linux].

Μια άλλη μέθοδος εγκατάστασης για macOS είναι το [Homebrew][homebrew].
Για Linux, μπορείς να εγκαταστήσεις χρησιμοποιώντας το tarball από την επίσημη [ιστοσελίδα του Swift][tarball].

## Windows

Ο συνιστώμενος τρόπος για να εγκαταστήσεις τον Swift στα Windows είναι να χρησιμοποιήσεις τον [εγκαταστάτη WinGet][winget-windows].
Μπορείς επίσης να εγκαταστήσεις τον Swift χρησιμοποιώντας τον διαχειριστή πακέτων Scoop ή κάνοντας χειροκίνητη εγκατάσταση.
Για όλες τις επιλογές, δες τη σελίδα [Εγκατάσταση του Swift στα Windows][swift-windows].
