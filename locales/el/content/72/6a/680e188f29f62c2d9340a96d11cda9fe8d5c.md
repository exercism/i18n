# Εκτέλεση των tests

Για να τρέξεις τα tests μιας άσκησης, τρέξε το script `<exercise>.test` στον κατάλογο της άσκησης:

```bash
tclsh <exercise>.test
```

Στις περισσότερες ασκήσεις, όλα τα tests εκτός από το πρώτο θα εμφανίζονται ως "skipped".
Αυτό σου επιτρέπει, ως προγραμματιστή, να εφαρμόσεις την Ανάπτυξη Καθοδηγούμενη από Tests: να προγραμματίζεις μόνο όσο χρειάζεται για να περάσεις κάθε test ένα ένα.
Για να παρακάμψεις τις εντολές skip, όρισε τη μεταβλητή περιβάλλοντος `RUN_ALL` σε μια έγκυρη αληθή τιμή της Tcl \[1\] πριν τρέξεις τη σουίτα των tests:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Οι αληθείς/ψευδείς τιμές της Tcl τεκμηριώνονται στη man page της συνάρτησης της βιβλιοθήκης C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
