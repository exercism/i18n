# Εισαγωγή

Στην Python, το `None` χρησιμοποιείται συχνά για να αναπαραστήσει την απουσία μιας τιμής: ένα σύμβολο κράτησης θέσης για να ορίσεις μια `null` (κενή) μεταβλητή, αντικείμενο ή όρισμα.

Αν έχεις ακούσει ή έχεις χρησιμοποιήσει έναν τύπο `NULL` ή `nil` σε κάποια άλλη γλώσσα προγραμματισμού, τότε αυτή η χρήση του `None` στην Python θα σου είναι γνώριμη. Το `None` σε βοηθάει να δηλώσεις μεταβλητές ή ορίσματα συνάρτησης για τα οποία δεν έχεις ακόμη τιμές. Αυτά μπορούν στη συνέχεια να εκχωρηθούν ξανά σε συγκεκριμένες τιμές, όποτε χρειαστεί.

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

Το `None` αξιολογείται ως `False` όταν χρησιμοποιείται σε έναν έλεγχο συνθήκης, οπότε είναι χρήσιμο για να επαληθεύσεις την "παρουσία" ή την "απουσία" μιας τιμής, *οποιασδήποτε* τιμής. Πρόκειται για ένα μοτίβο που χρησιμοποιείται συχνά όταν μια συνάρτηση ή μια διεργασία μπορεί να επιστρέψει ένα αντικείμενο σφάλματος ή ένα μήνυμα σφάλματος.

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
