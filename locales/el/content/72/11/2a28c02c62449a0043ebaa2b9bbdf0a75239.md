# Εισαγωγή

## RFLAGs

Υπάρχει ένας ειδικός καταχωρητής με το όνομα `rflags`.
Τα bits του λειτουργούν σαν σημαίες για διάφορες συνθήκες.

Μερικές από αυτές παρατίθενται παρακάτω:

| όνομα    | σύμβολο | bit |
| :------- | :----: | :-: |
| μεταφορά |   CF   |  0  |
| μηδέν    |   ZF   |  6  |
| πρόσημο  |   SF   |  7  |
| υπερχείλιση |   OF   | 11  |

## Εντολές σύγκρισης

Οι σημαίες στο `rflags` _δεν_ τροποποιούνται απευθείας.
Αντίθετα, ορίζονται από πολλές διαφορετικές εντολές.

Για παράδειγμα, το `ZF` ορίζεται από πολλές αριθμητικές πράξεις ή πράξεις bitwise όταν το αποτέλεσμα είναι μηδέν.

Μία από τις πιο συνηθισμένες εντολές που χρησιμοποιούνται για τον έλεγχο συνθηκών είναι η `cmp`.
Δέχεται δύο τελεστέους και ενημερώνει τις σημαίες, αλλά **δεν τροποποιεί τους τελεστέους της**.

### Η εντολή CMP

Η εντολή `cmp` αφαιρεί τον δεύτερο τελεστέο από τον πρώτο και ορίζει τις σημαίες ανάλογα με το αποτέλεσμα.

Αν το A είναι ο πρώτος τελεστέος και το B ο δεύτερος:

| σημαία | ορίζεται όταν                       |
| :--: | :----------------------------- |
|  CF  | A < B (χωρίς πρόσημο)               |
|  ZF  | A == B                         |
|  SF  | A < B (με πρόσημο, χωρίς υπερχείλιση)    |
|  OF  | υπερχείλιση σε αφαίρεση με πρόσημο |

## Διακλάδωση

Από προεπιλογή, ο κώδικας σε x86-64 εκτελείται διαδοχικά από πάνω προς τα κάτω.

Υπάρχουν όμως πολλές περιπτώσεις όπου είναι απαραίτητο να αλλάξεις αυτή τη συμπεριφορά.
Για παράδειγμα, για να εκτελέσεις ένα διαφορετικό σύνολο εντολών ως απάντηση σε μια συνθήκη.

Στις γλώσσες υψηλότερου επιπέδου, αυτό γίνεται συνήθως με αφαιρέσεις όπως οι συνθήκες `if...else`.
Ωστόσο, αυτές δεν υπάρχουν σε x86-64.

Αντ' αυτού, το x86-64 παρέχει εντολές που μεταφέρουν αποτελεσματικά την εκτέλεση σε άλλο σημείο του κώδικα.
Αυτό ονομάζεται `branching`.

~~~~exercism/note
Έχουμε ήδη δει δύο τέτοιες εντολές: τις `call` και `ret`.

Όταν καλείται μια συνάρτηση, η εκτέλεση μεταφέρεται από τον καλούντα στη συνάρτηση που καλείται.
Και, κατά την επιστροφή, η εκτέλεση μεταφέρεται πίσω στον καλούντα.

Αν δεν βρεθεί κάποιο `ret`, η εκτέλεση περνά απευθείας από τη μία συνάρτηση στην επόμενη.
Αυτό μπορεί μερικές φορές να χρησιμοποιηθεί για να βελτιστοποιηθεί η ροή του κώδικα.
~~~~

### Άλμα χωρίς συνθήκη

Η εντολή **jmp** μεταφέρει την εκτέλεση του προγράμματος σε άλλο σημείο του κώδικα χωρίς καμία συνθήκη.
Ο μοναδικός της τελεστέος είναι μια ετικέτα που περιέχει τη διεύθυνση του σημείου από το οποίο θα συνεχιστεί η εκτέλεση.

Ας δούμε, για παράδειγμα, την παρακάτω συνάρτηση:

```x86asm
fn:
    mov rax, 5
    jmp end

    add rax, 10
end:
    ret
```

Όταν καλείται η `fn`, η εκτέλεση ξεκινά από το `mov rax, 5`.
Αυτό θέτει την τιμή του `rax` σε 5 στο σημείο εκείνο.

Η επόμενη εντολή είναι η `jmp end`, που μεταφέρει την εκτέλεση στην ετικέτα `end`.

Μετά το `end`, η επόμενη εντολή είναι η `ret`, που μεταφέρει την εκτέλεση πίσω στη συνάρτηση που κάλεσε.

Πρόσεξε ότι, καθώς το `add rax, 10` βρίσκεται μετά το `jmp end` και πριν το `end`, δεν εκτελείται ποτέ.
Η τιμή του `rax` όταν επιστρέφει η `fn` είναι 5.

### Άλμα υπό συνθήκη

Η οικογένεια εντολών **jcc** μεταφέρει την εκτέλεση του προγράμματος σε άλλο σημείο μόνο αν ικανοποιείται μια συγκεκριμένη συνθήκη.
Διαφορετικά, η εκτέλεση συνεχίζεται διαδοχικά.

Κάθε συνθήκη αντιστοιχεί σε μία ή περισσότερες σημαίες του `rflags`.
Κάποιες παραλλαγές της `jcc` ελέγχουν αν μια σημαία είναι ορισμένη, άλλες ελέγχουν αν είναι μηδενισμένη.

Το `cc` στο `jcc` δεν είναι κυριολεκτικό, αλλά αναφέρεται στο συγκεκριμένο επίθημα που σχετίζεται με τη σημαία που ελέγχεται.

Υπάρχουν πολλά επιθήματα και πολλά από αυτά ελέγχουν την ίδια συνθήκη με κάποιο άλλο.
Κάποια από αυτά αναφέρονται απευθείας σε μια σημαία, ώστε η εντολή να μεταβαίνει σε μια ετικέτα αν η συγκεκριμένη σημαία είναι ορισμένη:

| επίθημα | μεταβαίνει αν |
| :----: | :------: |
|   z    | ZF == 1  |
|   c    | CF == 1  |
|   s    | SF == 1  |
|   o    | OF == 1  |

Πολλά άλλα επιλέγονται ώστε να παραπέμπουν στο νόημά τους σε μια εντολή `cmp`.
Για παράδειγμα:

| εντολή | επίθημα | μεταβαίνει αν         |
| ----------- | :----: | :--------------- |
| cmp A, B    |   e    | A == B           |
| cmp A, B    |   l    | A < B (με πρόσημο)   |
| cmp A, B    |   b    | A < B (χωρίς πρόσημο) |
| cmp A, B    |   g    | A > B (με πρόσημο)   |
| cmp A, B    |   a    | A > B (χωρίς πρόσημο) |

Μπορείς να προσθέσεις το `e` μετά το `l`, το `b`, το `g` ή το `a` για να συμπεριλάβεις την ισότητα στη συνθήκη:

```x86asm
cmp rcx, r8
jge two      ; this jumps to 'two' if rcx is greater than, or equal to, r8 in a signed comparison
jbe two      ; this jumps to 'two' if rcx is lesser than, or equal to, r8 in an unsigned comparison
```

Για όλα τα επιθήματα υπάρχουν παραλλαγές που ελέγχουν την αντίθετη συμπεριφορά.
Έχουν την ίδια σύνταξη, αλλά με ένα `n` πριν από το επίθημα.

Για παράδειγμα, η `jnz` μεταβαίνει όταν το `ZF` **δεν** είναι ορισμένο.
Παρομοίως, η `jnae` μεταβαίνει όταν το A **δεν** είναι >= το B (τα A και B ερμηνεύονται ως ακέραιοι χωρίς πρόσημο).

~~~~exercism/note
Κάποια επιθήματα είναι ψευδώνυμα για τις ίδιες συνθήκες.
Για παράδειγμα, οι `jz` (επίθημα `z`, για το `ZF`) και `je` (επίθημα `e`, για την ισότητα) μεταβαίνουν και οι δύο όταν το `ZF` είναι ορισμένο.
Αυτό συμβαίνει επειδή, με την `cmp`, το `ZF` ορίζεται όταν η αφαίρεση δίνει μηδέν, που σημαίνει ότι οι δύο τελεστέοι είναι ίσοι.

Άλλα επιθήματα, ωστόσο, ελέγχουν συνδυασμό σημαιών και δεν μπορούν να αντικατασταθούν άμεσα από ένα μεμονωμένο επίθημα σημαίας.

Προτίμησε το επίθημα που περιγράφει καλύτερα τη σημασιολογία της σύγκρισής σου.
~~~~

## Τοπικές ετικέτες

Οι ετικέτες είναι ορατές σε ολόκληρο το αρχείο πηγαίου κώδικα, δεν είναι τοπικές σε μια συνάρτηση.
Έτσι, είναι αδύνατο να ξαναχρησιμοποιήσεις το όνομα μιας ετικέτας.

Για να μιμηθεί τη συμπεριφορά μιας τοπικής ετικέτας, το NASM έχει έναν ειδικό συμβολισμό για μια ετικέτα που δηλώνεται με τελεία (`.`) μπροστά της.
Ο συμβολισμός αυτός ορίζει μια ετικέτα που περιλαμβάνει σιωπηρά το όνομα της προηγούμενης ετικέτας χωρίς τελεία:

```x86asm
section .text
fn1:
    ...
.example: ; this is fn1.example
    ...
    ret

fn2:
    ...
.example: ; this is fn2.example
    ...
    ret
```

Είναι ακόμα δυνατό να μεταβείς σε αυτή την ετικέτα από οπουδήποτε στον κώδικα χρησιμοποιώντας το πλήρες όνομα της ετικέτας, για παράδειγμα `jmp fn1.example`.

Ωστόσο, ένα άλμα που χρησιμοποιεί το μέρος της ετικέτας που αρχίζει από την τελεία θα γίνει προς την ετικέτα _μέσα_ στην εξωτερική συνάρτηση.
Για παράδειγμα, το `.example` συμπεριφέρεται σαν να ήταν τοπικό στη συνάρτηση:

```x86asm
section .text
fn1:
    ...
.example:
    ...
    jmp .example ; this jumps to fn1.example

fn2:
    ...
.example:
    ...
    jmp .example ; this jumps to fn2.example
```
