# Προσθήκη οδηγιών

## Υποδείξεις

Για να ολοκληρώσεις αυτή την άσκηση, πρέπει να υλοποιήσεις τη συνάρτηση `anagramsFor`,
η οποία παίρνει μια *λέξη* και μια ομάδα *λέξεων* και επιστρέφει εκείνες που είναι
αναγραμματισμοί της δοσμένης *λέξης*.

Πρέπει να επιστρέψεις τους αναγραμματισμούς με την ίδια σειρά με την οποία
εμφανίζονται στις υποψήφιες λέξεις.


Αν λύνεις αυτή την άσκηση για πρώτη φορά, καλό είναι να μείνεις στην υπογραφή
που σου δίνεται:

```haskell
anagramsFor :: String -> [String] -> [String]
```

Αργότερα, ίσως είναι καλή ιδέα να ξαναπιάσεις αυτό το πρόβλημα και να παίξεις με
άλλους τύπους δεδομένων και βιβλιοθήκες:

- `Text`, από το πακέτο *text*.
- `Sequence` και `Set`, από το πακέτο *containers*.
- `MultiSet`, από το πακέτο *multiset*

Η σουίτα δοκιμών σχεδιάστηκε σκόπιμα ώστε να δέχεται σχεδόν οποιαδήποτε υπογραφή
τύπου έχει νόημα, οπότε σε ενθαρρύνουμε να βρεις αυτή που πιστεύεις ότι είναι η
καλύτερη.
