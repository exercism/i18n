# Προσάρτημα οδηγιών

## Σημείωση

Μπορεί να σου φανούν χρήσιμα τα λεξικά της Pharo για να ολοκληρώσεις αυτή την άσκηση.
Η Pharo προσφέρει αρκετούς τρόπους για να κατασκευάσεις λεξικά, όπως το `Dictionary new: at:put:` και μια κυριολεκτική σύνταξη με `Association`s.
Ένα `Association` μοιάζει με `key -> value` και μπορεί να μετατραπεί σε λεξικό έτσι: `{ 'key' -> 'value' } asDictionary`.
Θυμήσου ότι στη Smalltalk όλοι οι ενθηματικοί τελεστές είναι δεξιά προσεταιριστικοί και ότι μπορείς να περιηγηθείς ζωντανά σε οποιαδήποτε από τις κλάσεις που αναφέρονται παραπάνω.
