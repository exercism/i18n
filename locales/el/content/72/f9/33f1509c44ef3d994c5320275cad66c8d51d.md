# Υποδείξεις


## 1. Μετατροπή από Φαρενάιτ σε Κελσίου

- Μπορείς να μετατρέψεις τους βαθμούς Φαρενάιτ σε Κελσίου αφαιρώντας 32 και μετά διαιρώντας με το 1.8.
- Η διαίρεση έχει μεγαλύτερη προτεραιότητα από την αφαίρεση, οπότε η αφαίρεση πρέπει να μπει μέσα σε ένα μπλοκ ή να ανατεθεί σε μια μεταβλητή, ώστε να εκτελεστεί πρώτη.

## 2. Σύγκριση δύο θερμοκρασιών

- Μπορείς να χρησιμοποιήσεις αντιστοίχιση προτύπων στον τύπο `Temperature` για να εξάγεις την τιμή από τις παραλλαγές `Celsius` και `Fahrenheit`.
- Μπορείς να χρησιμοποιήσεις τη συνάρτηση `float.compare` για να συγκρίνεις δύο θερμοκρασίες αφού μετατραπούν στην ίδια μονάδα.

## 3. Ταξινόμηση πόλεων κατά θερμοκρασία

- Μπορείς να χρησιμοποιήσεις τη συνάρτηση [`list.sort`][list-sort] για να ταξινομήσεις μια λίστα χρησιμοποιώντας μια δεδομένη συνάρτηση σύγκρισης.

[list-sort]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#sort
