# Προσάρτηση

## Σημειώσεις Υλοποίησης

Θα γράψεις μια υλοποίηση μιας διπλά συνδεδεμένης λίστας.

Υλοποίησε ένα Node που να κρατά μια τιμή και δείκτες προς τον επόμενο και τον προηγούμενο κόμβο.

Στη συνέχεια, υλοποίησε μια LinkedList που κρατά αναφορές στον πρώτο και τον τελευταίο κόμβο και προσφέρει μια διεπαφή τύπου πίνακα για την προσθήκη και αφαίρεση στοιχείων:

- `push` (*εισαγωγή τιμής στο πίσω μέρος*);
- `pop` (*αφαίρεση τιμής από το πίσω μέρος*);
- `shift` (*αφαίρεση τιμής από το μπροστινό μέρος*);
- `unshift` (*εισαγωγή τιμής στο μπροστινό μέρος*);
- `delete` (*αφαίρεση του πρώτου κόμβου που ταιριάζει*)

Για να κρατήσεις την υλοποίησή σου απλή, τα tests δεν θα καλύπτουν συνθήκες σφάλματος.
Συγκεκριμένα: ποτέ δεν θα κληθεί η `pop` ή η `shift` σε μια κενή λίστα.
