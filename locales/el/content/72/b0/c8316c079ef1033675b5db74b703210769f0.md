# Οδηγίες

Σε αυτή την άσκηση θα δουλέψεις με λογαριασμούς ταμιευτηρίου.
Κάθε χρόνο, το υπόλοιπο του λογαριασμού ταμιευτηρίου σου ενημερώνεται με βάση το επιτόκιό του.
Το επιτόκιο που σου δίνει η τράπεζά σου εξαρτάται από το ποσό των χρημάτων στον λογαριασμό σου (το υπόλοιπό του):

- 3,213% για υπόλοιπο μικρότερο από `0` δολάρια (το υπόλοιπο γίνεται πιο αρνητικό).
- 0,5% για υπόλοιπο μεγαλύτερο ή ίσο με `0` δολάρια και μικρότερο από `1000` δολάρια.
- 1,621% για υπόλοιπο μεγαλύτερο ή ίσο με `1000` δολάρια και μικρότερο από `5000` δολάρια.
- 2,475% για υπόλοιπο μεγαλύτερο ή ίσο με `5000` δολάρια.

Έχεις τέσσερις εργασίες, καθεμία από τις οποίες ασχολείται με το υπόλοιπό σου και το επιτόκιό του.

## 1. Υπολόγισε το επιτόκιο

Υλοποίησε τη συνάρτηση `InterestRate()` για να υπολογίσεις το επιτόκιο με βάση το καθορισμένο υπόλοιπο:

```go
InterestRate(200.75)
// => 0.5
```

Σημείωσε ότι η τιμή επιστροφής είναι `float32`.

## 2. Υπολόγισε τον τόκο

Υλοποίησε τη συνάρτηση `Interest()` για να υπολογίσεις τον τόκο με βάση το καθορισμένο υπόλοιπο:

```go
Interest(200.75)
// => 1.003750
```

Σημείωσε ότι η τιμή επιστροφής είναι `float64`.

## 3. Υπολόγισε την ετήσια ενημέρωση του υπολοίπου

Υλοποίησε τη συνάρτηση `AnnualBalanceUpdate()` για να υπολογίσεις την ετήσια ενημέρωση του υπολοίπου, λαμβάνοντας υπόψη το επιτόκιο:

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

Σημείωσε ότι η τιμή επιστροφής είναι `float64`.

## 4. Υπολόγισε τα χρόνια μέχρι να φτάσεις στο επιθυμητό υπόλοιπο

Υλοποίησε τη συνάρτηση `YearsBeforeDesiredBalance()` για να υπολογίσεις τον ελάχιστο αριθμό ετών που απαιτούνται για να φτάσεις στο επιθυμητό υπόλοιπο, λαμβάνοντας υπόψη ότι κάθε χρόνο ο τόκος προστίθεται στο υπόλοιπο.
Αυτό σημαίνει ότι το υπόλοιπο μετά από ένα χρόνο είναι: αρχικό υπόλοιπο + τόκος για το αρχικό υπόλοιπο.
Το υπόλοιπο μετά από δύο χρόνια είναι: υπόλοιπο μετά από ένα χρόνο + τόκος για το υπόλοιπο μετά από ένα χρόνο.
Και ούτω καθεξής, μέχρι το υπόλοιπο του τρέχοντος έτους να είναι μεγαλύτερο ή ίσο με το υπόλοιπο-στόχο.

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

Σημείωσε ότι η τιμή επιστροφής είναι `int`.
