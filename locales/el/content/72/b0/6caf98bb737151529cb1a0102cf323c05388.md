# Tests

Για να τρέξεις το test της άσκησης από τη γραμμή εντολών, εκτέλεσε την παρακάτω εντολή από τον κατάλογο της άσκησης:

```bash
clojure -M:test
```

## REPL

Για να τρέξεις το test της άσκησης μέσω του REPL, εκτέλεσε την παρακάτω εντολή από τον κατάλογο της άσκησης:

```bash
$ clojure -m cljs.main -re node
```

Στη συνέχεια, κάνε `require` στο test namespace της άσκησης και στο test namespace της Clojure):

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Άλλαξε το ns στο test namespace:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Στη συνέχεια, κάλεσε το `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
