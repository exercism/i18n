# Υποδείξεις

## Γενικά

- Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.
- Οι διευθύνσεις στη μνήμη είναι τιμές 64-bit (8-byte).

## 1. Δημιούργησε μια καταχώριση για κάθε αντικείμενο

- Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.
- Οι διευθύνσεις στη μνήμη είναι τιμές 64-bit (8-byte).
- Όλα τα ακέραια ορίσματα μετά το έκτο περνιούνται στη στοίβα, με το πρώτο να βρίσκεται στο `rsp + 8`.
- Ο αριθμός των επιπλέον ορισμάτων είναι ίσος με τον αριθμό των κατηγοριών, ο οποίος περνιέται στο `r9`.
- Μπορείς να χρησιμοποιήσεις έναν βρόχο για να προσθέσεις τα επιπλέον ορίσματα ένα ένα, ή μπορείς να χρησιμοποιήσεις [movsq][movs] σε συνδυασμό με [rep][rep].

## 2. Δέσμευσε χώρο για μια μηνιαία λίστα αντικειμένων

- Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.
- Οι διευθύνσεις στη μνήμη είναι τιμές 64-bit (8-byte).
- Πρέπει να γνωρίζεις το μέγεθος του πίνακα για να καθαρίσεις τα byte του αφού καλέσεις τη συνάρτηση δέσμευσης μνήμης.
- Όταν καλείς μια εξωτερική συνάρτηση, μπορεί να τροποποιήσει την τιμή σε οποιονδήποτε _καταχωρητή caller-saved_.
- Μπορείς να διατηρήσεις την τιμή ενός καταχωρητή στη στοίβα χρησιμοποιώντας [push][push] ή τροποποιώντας απευθείας το `rsp`.
- Οποιαδήποτε τροποποίηση του `rsp`, ακόμα και με `push`, πρέπει να αντιστραφεί πριν επιστρέψει η συνάρτηση, είτε με [pop][pop] είτε αλλάζοντας απευθείας το `rsp`.

## 3. Εισήγαγε ένα αντικείμενο στη μηνιαία λίστα

- Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.
- Οι διευθύνσεις στη μνήμη είναι τιμές 64-bit (8-byte).
- Μια τιμή που δεν χωράει σε έναν καταχωρητή περνιέται σε μια συνάρτηση στη στοίβα.
- Κάθε καταχώριση για ένα αντικείμενο καταλαμβάνει 120 byte χώρου, κάτι που είναι πολύ μεγαλύτερο από το μέγιστο μέγεθος ενός καταχωρητή (8 byte).
- Τα ορίσματα που περνιούνται στη στοίβα βρίσκονται σε διευθύνσεις που ξεκινούν από το `rsp + 8`.
- Μπορείς να χρησιμοποιήσεις έναν βρόχο για να προσθέσεις τις τιμές στη θέση μνήμης προορισμού, ή μπορείς να χρησιμοποιήσεις [movsb][movs] σε συνδυασμό με [rep][rep].

## 4. Εκτύπωσε ένα αντικείμενο

- Τα πρώτα έξι ακέραια ορίσματα περνιούνται σε μια συνάρτηση στα `rdi`, `rsi`, `rdx`, `rcx`, `r8` και `r9`.
- Οι διευθύνσεις στη μνήμη είναι τιμές 64-bit (8-byte).
- Η εισαγωγική συμβολοσειρά είναι προαιρετική, μπορείς να καλέσεις τη συνάρτηση εκτύπωσης με `0` αντ' αυτής.
- Αν η εισαγωγική συμβολοσειρά περαστεί στη συνάρτηση εκτύπωσης, πρέπει να έχει το πολύ 50 χαρακτήρες ASCII, συμπεριλαμβανομένου ήδη του τερματικού NUL (τιμή `0`).
- Κάθε φορά που καλείς μια συνάρτηση, πρέπει να δεσμεύεις χώρο στη στοίβα για οποιοδήποτε όρισμα μετά το έκτο.
- Το System V ABI ορίζει ότι η στοίβα πρέπει να είναι ευθυγραμμισμένη στα 16 byte πριν από την κλήση μιας συνάρτησης, κάτι που είναι ιδιαίτερα σημαντικό για εξωτερικές συναρτήσεις.
- Κάθε καταχώριση για ένα αντικείμενο στη λίστα καταλαμβάνει 120 byte χώρου.
