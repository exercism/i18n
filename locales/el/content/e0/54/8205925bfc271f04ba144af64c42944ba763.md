# Σημειώσεις για τις αγκύλες

Η Tcl είναι μια [πολύ απλή γλώσσα](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm),
αλλά ο τρόπος με τον οποίο ο διερμηνευτής αναλύει τον κώδικα έχει μερικές
δύσκολες οριακές περιπτώσεις.

## Άγκιστρα

Τα άγκιστρα στην Tcl είναι απλώς ένας τρόπος να περικλείεις ένα μπλοκ κειμένου. Το κείμενο αυτό μπορεί να ερμηνευτεί ως κώδικας ή ως δεδομένα. Μέσα στα άγκιστρα μπορούν να εμφανιστούν εμφωλευμένα άγκιστρα, αλλά τα εμφωλευμένα άγκιστρα πρέπει να είναι ισορροπημένα. Η σελίδα man της Tcl λέει το εξής:

> Τα άγκιστρα εμφωλεύονται μέσα στη λέξη: για κάθε επιπλέον άγκιστρο ανοίγματος πρέπει να υπάρχει ένα επιπλέον άγκιστρο κλεισίματος (ωστόσο, αν ένα άγκιστρο ανοίγματος ή κλεισίματος μέσα στη λέξη _έχει διαφύγει με backslash_, τότε δε μετριέται στον εντοπισμό του αντίστοιχου άγκιστρου κλεισίματος).

Η διατύπωση εκεί είναι αρκετά συγκεκριμένη: αν θέλεις να έχεις ένα άγκιστρο ανοίγματος ή κλεισίματος χωρίς ταίρι, πρέπει να το διαφύγεις με backslash. Οπότε μην κάνεις αυτό:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
Πρέπει να κάνεις το εξής:
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

Αυτό μπορεί να είναι προβληματικό εξαιτίας του τρόπου με τον οποίο η Tcl αναλύει τα σχόλια, ο οποίος διαφέρει από αυτόν των περισσότερων γλωσσών. Υπάρχει περισσότερη συζήτηση στο [wiki της Tcl](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments).

## Αγκύλες

Παρομοίως, επειδή η Tcl χρησιμοποιεί αγκύλες για [υποκατάσταση εντολών.](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11), ακόμα και μέσα σε συμβολοσειρές με διπλά εισαγωγικά, πρέπει να προσέχεις τη διαφυγή των αγκυλών ανοίγματος.

## Παρενθέσεις

Με εξαίρεση τις [μεταβλητές συσχετιστικών πινάκων](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12), οι παρενθέσεις είναι απλώς συνηθισμένοι χαρακτήρες.
