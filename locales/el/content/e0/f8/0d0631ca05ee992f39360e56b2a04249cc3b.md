# Παράδειγμα

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Οι γραμμές που ξεκινούν με τελεία είναι _οδηγίες_: εντολές για τον συμβολομεταφραστή και όχι για τον επεξεργαστή.
Το `.equ` δίνει το όνομα `FRAME_SIZE` στον αριθμό 16.
Το `.text` λέει ότι ό,τι ακολουθεί είναι κώδικας.
Το `.global` κάνει την ετικέτα `is_triple` ορατή έξω από αυτό το αρχείο, ώστε άλλος κώδικας να μπορεί να την καλέσει.
Μπορεί επίσης να δεις `.globl`, που σημαίνει το ίδιο πράγμα.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

Το `is_triple` ελέγχει αν `a² + b² = c²`, επιστρέφοντας 1 αν ισχύει και 0 αλλιώς.
Για παράδειγμα, το `(6, 8, 10)` δίνει 1, επειδή `36 + 64 = 100`.
Η ετικέτα `is_triple` σηματοδοτεί το σημείο όπου ξεκινά η συνάρτηση.
Καλείται με τα `a`, `b` και `c` στους καταχωρητές `a0`, `a1` και `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

Ο καταχωρητής `ra` κρατά τη _διεύθυνση επιστροφής_, το σημείο του καλούντος στο οποίο θα επιστρέψουμε όταν τελειώσουμε.
Κάθε `call` αντικαθιστά το `ra`, οπότε πρώτα το αποθηκεύουμε στη _στοίβα_.
Η στοίβα μεγαλώνει προς τα κάτω, προς μικρότερες διευθύνσεις, οπότε αφαιρώντας 16 από τον δείκτη στοίβας `sp` δεσμεύουμε 16 byte για εμάς.
(Το `sp` πρέπει πάντα να είναι πολλαπλάσιο του 16.)
Αποθηκεύουμε επίσης τα `b` και `c`, επειδή μια συνάρτηση που καλούμε επιτρέπεται να αλλάξει τους καταχωρητές `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

Το `a` βρίσκεται ήδη στο `a0`, εκεί όπου το `square` περιμένει την είσοδό του.
Το `call` θέτει το `ra` στην επόμενη εντολή και μεταπηδά στο `square`, το οποίο επιστρέφει το αποτέλεσμά του στο `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Φορτώνουμε το `b` πίσω από τη στοίβα, το υψώνουμε στο τετράγωνο και το προσθέτουμε στο `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

Η διαφορά είναι μηδέν ακριβώς όταν `a² + b² = c²`.
Το `seqz` («ορισμός στο 1 αν είναι ίσο με μηδέν») το μετατρέπει σε 1 ή 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Επαναφέρουμε το `ra` και επιστρέφουμε τα 16 byte της στοίβας.
Το `ret` μεταπηδά στη διεύθυνση που περιέχει το `ra`, πίσω στον καλούντα.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

Το `square` δεν καλεί καμία άλλη συνάρτηση, οπότε το `ra` παραμένει άθικτο και δεν υπάρχει τίποτα να αποθηκεύσουμε.
Δεν έχει σημειωθεί ως `.global`, επειδή μόνο το `is_triple` το χρησιμοποιεί.
