# Παράρτημα οδηγιών

## Δομή του έργου

* Το `src` περιέχει τη λύση σου για την άσκηση
* Το `spec` περιέχει τα τεστ που θα εκτελέσεις για την άσκηση

## Εκτέλεση τεστ

Αν βρίσκεσαι στον σωστό φάκελο (δηλαδή σε αυτόν που περιέχει τα `src` και `spec`), μπορείς να εκτελέσεις τα τεστ για αυτή την άσκηση τρέχοντας `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Αυτό θα εκτελέσει όλα τα αρχεία τεστ στον φάκελο `spec`.

Σε κάθε αρχείο τεστ, όλα τα τεστ εκτός από το πρώτο έχουν παραλειφθεί.

Μόλις περάσεις ένα τεστ, μπορείς να ενεργοποιήσεις το επόμενο αλλάζοντας το `pending` σε `it`.

## Υποβολή της λύσης σου

Φρόντισε να υποβάλεις το αρχείο πηγαίου κώδικα στον φάκελο `src` όταν υποβάλλεις τη λύση σου:

```bash
$ exercism submit src/hello_world.cr
```
