# Εισαγωγή

Στη Java, το κυριολεκτικό `null` χρησιμοποιείται για να δηλώσει την απουσία μιας τιμής.

Οι πρωτόγονοι τύποι δεδομένων στη Java έχουν όλοι μια προεπιλεγμένη τιμή και επομένως δεν μπορούν ποτέ να είναι `null`. Κατά σύμβαση, ξεκινούν με πεζό γράμμα, π.χ. `int`.

Οι τύποι αναφοράς περιέχουν τη διεύθυνση μνήμης ενός αντικειμένου και μπορούν να έχουν τιμή `null`. Γενικά ξεκινούν με κεφαλαίο γράμμα, π.χ. `String`.

Η προσπάθεια εκχώρησης της τιμής `null` σε μια μεταβλητή πρωτόγονου τύπου θα έχει ως αποτέλεσμα ένα σφάλμα χρόνου μεταγλώττισης, καθώς η μεταβλητή περιέχει πάντα μια πρωτόγονη τιμή του τύπου που της έχει εκχωρηθεί.

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

Η εκχώρηση της τιμής `null` σε μια μεταβλητή αναφοράς δεν θα έχει ως αποτέλεσμα σφάλμα χρόνου μεταγλώττισης, καθώς οι μεταβλητές αναφοράς μπορούν να έχουν την τιμή `null`.

```java
//No error will occur as the String variable str is nullable
String str = null;
```
