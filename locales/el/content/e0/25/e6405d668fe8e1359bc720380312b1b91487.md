# Εισαγωγή

Ο τύπος `Bool` είναι ένα από τα δομικά στοιχεία της γλώσσας.
Στόχος του είναι να περιγράφει αν κάτι είναι αληθές ή ψευδές, με τις αντίστοιχες τιμές `True` και `False`.

Οι Boolean (λογική τιμή) μπορούν να συνδυαστούν με τους τελεστές `&&` "AND" και `||` "OR" και να αντιστραφούν με τη συνάρτηση `not`.

Οι Boolean είναι επίσης εξαιρετικά χρήσιμες για να δημιουργείς διακλαδώσεις στον κώδικά σου που εκτελούνται μόνο όταν πληρούνται ορισμένες συνθήκες.
Στην Elm, αυτό γίνεται με μια έκφραση `if-then-else`, η οποία χρησιμοποιείται ως εξής.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
