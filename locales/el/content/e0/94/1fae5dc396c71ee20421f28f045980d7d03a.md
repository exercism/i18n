# Εγκατάσταση

Πήγαινε στο [wiki του `jq`][jq-wiki-install] για τις οδηγίες εγκατάστασης.

## Πληροφορίες έκδοσης

Από τον Ιούνιο του 2025, η τρέχουσα έκδοση του jq είναι η **1.8**.
Αυτή είναι η έκδοση που χρησιμοποιεί ο διαδικτυακός test runner του jq.

Πολλοί διαχειριστές πακέτων στο Linux θα εγκαταστήσουν μια παλαιότερη έκδοση, την 1.6.
Καλύτερα να εγκαταστήσεις χειροκίνητα μια νεότερη έκδοση· έχουν γίνει πολλές ωφέλιμες αλλαγές από τότε που κυκλοφόρησε η v1.6 το 2018.

[jq-wiki-install]: https://github.com/jqlang/jq/wiki/Installation
