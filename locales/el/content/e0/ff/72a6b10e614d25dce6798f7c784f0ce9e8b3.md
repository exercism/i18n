# Εισαγωγή

Ένας `for` βρόχος σου επιτρέπει να εκτελείς κώδικα επανειλημμένα μέχρι να ικανοποιηθεί μια συνθήκη.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Ένας `for` βρόχος αποτελείται από τέσσερα μέρη:

1. Η αρχικοποίηση: εκτελείται μία φορά πριν μπεις στον βρόχο. Συνήθως χρησιμοποιείται για να ορίσεις τις μεταβλητές που χρησιμοποιούνται μέσα στον βρόχο.
2. Η συνθήκη: εκτελείται πριν από κάθε επανάληψη του βρόχου. Ο βρόχος συνεχίζει να εκτελείται όσο αυτή αξιολογείται σε `true`.
3. Η ανανέωση: εκτελείται μετά από κάθε επανάληψη του βρόχου. Συνήθως χρησιμοποιείται για να τροποποιείς (συχνά: να αυξάνεις ή να μειώνεις) τη μεταβλητή ή τις μεταβλητές του βρόχου.
4. Το σώμα: ο κώδικας που εκτελείται σε κάθε επανάληψη του βρόχου.
