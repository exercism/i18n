# Εισαγωγή

## Η διεπαφή ως σύνολο μεθόδων

Στην απλούστερη μορφή της, ένας **τύπος διεπαφής** είναι ένα σύνολο υπογραφών μεθόδων.
Ακολουθεί ένα παράδειγμα ορισμού διεπαφής που περιλαμβάνει δύο μεθόδους `Add` και `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Τα ονόματα παραμέτρων όπως το `increment` μπορούν να παραλειφθούν από τον ορισμό της διεπαφής, αλλά συχνά αυξάνουν την αναγνωσιμότητα.

Τα ονόματα διεπαφών στη Go δεν περιέχουν τη λέξη `Interface` ή `I`.
Αντ' αυτού, συχνά τελειώνουν σε `er`, π.χ. `Reader`, `Stringer`.

## Υλοποίηση μιας διεπαφής

Κάθε τύπος που ορίζει τις μεθόδους της διεπαφής την "υλοποιεί" αυτόματα και σιωπηρά.
Δεν υπάρχει λέξη-κλειδί `implements` στη Go.

Ο παρακάτω τύπος υλοποιεί τη διεπαφή `Counter` που είδαμε παραπάνω.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Για την υλοποίηση της διεπαφής, δεν έχει σημασία αν η μέθοδος έχει δέκτη τιμής ή δέκτη δείκτη.
(Ρίξε μια ματιά στις [έννοιες των μεθόδων][concept-methods] αν δεν είσαι σίγουρος γι' αυτούς.)

> Μια τιμή τύπου διεπαφής μπορεί να περιέχει οποιαδήποτε τιμή που υλοποιεί αυτές τις μεθόδους. [^1]

Αυτό σημαίνει ότι το `Stats` μπορεί τώρα να χρησιμοποιηθεί σε όλα τα σημεία που περιμένουν τη διεπαφή `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Επειδή οι διεπαφές υλοποιούνται σιωπηρά, ένας τύπος μπορεί εύκολα να υλοποιήσει πολλαπλές διεπαφές.
Αρκεί να έχει ορίσει όλες τις απαραίτητες μεθόδους.

## Κενή διεπαφή

Υπάρχει ένας πολύ ξεχωριστός τύπος διεπαφής στη Go, ο **κενός τύπος διεπαφής** που δεν περιέχει καμία μέθοδο.
Ο κενός τύπος διεπαφής γράφεται ως εξής: `interface{}`.
Το `any` είναι ψευδώνυμο για το `interface{}` και χρησιμοποιείται συχνότερα.

Επειδή η κενή διεπαφή δεν έχει μεθόδους, κάθε τύπος την υλοποιεί σιωπηρά.
Αυτό είναι χρήσιμο για τον ορισμό μιας συνάρτησης που μπορεί γενικά να δέχεται οποιαδήποτε τιμή.
Σε αυτή την περίπτωση, η παράμετρος της συνάρτησης χρησιμοποιεί τον κενό τύπο διεπαφής.
