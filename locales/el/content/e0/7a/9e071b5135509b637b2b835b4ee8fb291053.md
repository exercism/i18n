# Οδηγίες

Σε αυτή την άσκηση θα ελέγχεις τα δικαιώματα των λογαριασμών χρηστών σε ένα διαδικτυακό φόρουμ. Το φόρουμ υποστηρίζει τρία διαφορετικά δικαιώματα:

- Read
- Write
- Delete

Υπάρχουν τρεις τύποι λογαριασμών, ο καθένας με διαφορετικά προεπιλεγμένα δικαιώματα:

- Επισκέπτες: μπορούν να διαβάζουν αναρτήσεις.
- Χρήστες: μπορούν να διαβάζουν και να γράφουν αναρτήσεις.
- Συντονιστές: μπορούν να διαβάζουν, να γράφουν και να διαγράφουν αναρτήσεις, έχουν όλα τα δικαιώματα.

Μερικές φορές, μεμονωμένα δικαιώματα μπορούν να τροποποιηθούν. Για παράδειγμα, είναι δυνατό να δοθεί σε έναν λογαριασμό επισκέπτη το δικαίωμα να γράφει κι αυτός αναρτήσεις, ή η ανάκληση όλων των δικαιωμάτων από έναν λογαριασμό θα είχε ως αποτέλεσμα να μην έχει κανένα από τα δικαιώματα.

## 1. Πάρε τα προεπιλεγμένα δικαιώματα για έναν τύπο λογαριασμού

Πρώτα, όρισε ένα enum `AccountType` που να αντιπροσωπεύει τους τρεις τύπους λογαριασμών: `Guest`, `User` και `Moderator`.

Στη συνέχεια, όρισε ένα enum `Permission` που να αντιπροσωπεύει τους τρεις τύπους δικαιωμάτων: `Read`, `Write`, `Delete`, και δύο επιπλέον: `All` για να έχει όλα τα δικαιώματα και `None` για να μην έχει κανένα από τα δικαιώματα.

Έπειτα, υλοποίησε τη (_static_) μέθοδο `Permissions.Default()` για να επιστρέφει τα προεπιλεγμένα δικαιώματα για έναν συγκεκριμένο τύπο λογαριασμού:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Χορήγησε ένα δικαίωμα

Υλοποίησε τη (_static_) μέθοδο `Permissions.Grant()` που χορηγεί (προσθέτει) ένα δικαίωμα:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Ανακάλεσε ένα δικαίωμα

Υλοποίησε τη (_static_) μέθοδο `Permissions.Revoke()` που ανακαλεί (αφαιρεί) ένα δικαίωμα:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Έλεγξε ένα δικαίωμα

Υλοποίησε τη (_static_) μέθοδο `Permissions.Check()` που παίρνει τα τρέχοντα δικαιώματα του λογαριασμού και ελέγχει αν ο λογαριασμός είναι εξουσιοδοτημένος για ένα δεδομένο δικαίωμα:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
