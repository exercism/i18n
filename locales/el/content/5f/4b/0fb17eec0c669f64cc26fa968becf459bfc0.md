# Προσάρτημα οδηγιών

## Υλοποίηση

Αυτή η άσκηση απαιτεί να καλέσεις μια συνάρτηση που περνιέται ως όρισμα.
Στην Uiua, μπορείς να το κάνεις αυτό μέσω [μακροεντολών](https://www.uiua.org/tutorial/macros), που είναι ο τρόπος με τον οποίο περιμένει αυτή η άσκηση να τη λύσεις.

```exercism/note
Μπορείς να δεις αμέσως ότι μια δέσμευση είναι μακροεντολή λόγω του επιθήματος `!`.
```
