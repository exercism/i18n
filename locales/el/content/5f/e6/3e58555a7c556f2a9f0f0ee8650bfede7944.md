# Συνεχής ενσωμάτωση

Στο Exercism, χρησιμοποιούμε [GitHub Actions](https://github.com/features/actions) για να καλύψουμε τις ανάγκες μας σε [συνεχή ενσωμάτωση](https://en.wikipedia.org/wiki/Continuous_integration) (CI) και [συνεχή ανάπτυξη](https://en.wikipedia.org/wiki/Continuous_deployment) (CD).
Αυτό περιλαμβάνει την εκτέλεση tests, τη μορφοποίηση διαφόρων πραγμάτων και την ανάπτυξη.

Για περισσότερες πληροφορίες, δες:

- [Ροές εργασιών](/docs/building/tracks/ci/workflows)
- [Ρύθμιση CI για νέα tracks](/docs/building/tracks/new/setup-continuous-integration)
