# Εισαγωγή

## Καταγραφές

Μια καταγραφή είναι μια συλλογή από πεδία (τα οποία μπορούν να είναι διαφορετικών τύπων) που ανήκουν μαζί. Για να ορίσεις μια καταγραφή χρησιμοποιείται η λέξη-κλειδί `type`. Τα πεδία μιας καταγραφής ορίζονται ανάμεσα στους χαρακτήρες `{` και `}`, και κάθε πεδίο έχει ένα όνομα _και_ έναν τύπο. Για να δημιουργήσεις μια καταγραφή, όρισε τα ονόματα των πεδίων και ανάθεσε μια τιμή σε αυτά ανάμεσα στους χαρακτήρες `{` και `}`. Κατά τη δημιουργία μιας καταγραφής, όλα τα πεδία πρέπει να πάρουν μια τιμή. Οι τιμές των πεδίων ενός στιγμιοτύπου καταγραφής μπορούν να προσπελαστούν χρησιμοποιώντας σημειογραφία με τελεία.

Όταν ορίζεις/δημιουργείς μια καταγραφή, κάθε πεδίο πρέπει είτε να βρίσκεται σε ξεχωριστή γραμμή είτε να χωρίζεται με το σύμβολο `;` όταν βρίσκεται σε μία γραμμή.

```fsharp
// Define a record
type Address =
    { Street: string
      HouseNumber: int }

// Create a record
let oldAddress: Address =
    { Street = "Main Street"
      HouseNumber = 17 }

// Single-line alternative
type ConciseAddress = { Street: string; HouseNumber: int }
let conciseAddress: ConciseAddress = { Street = "Main Street"; HouseNumber = 17 }
```

Καθώς οι καταγραφές είναι αμετάβλητες, μόλις δημιουργηθεί μια καταγραφή, οι τιμές των πεδίων της δεν μπορούν ποτέ να αλλάξουν. Αν θέλεις να αλλάξεις τις τιμές μιας καταγραφής, η λέξη-κλειδί `with` σου επιτρέπει να δημιουργήσεις ένα αντίγραφο μιας υπάρχουσας καταγραφής, αλλά με νέες τιμές για ένα ή περισσότερα πεδία.

```fsharp
// Copy the old address but change the house number
let newAddress: Address = { oldAddress with HouseNumber = 86 }
newAddress.Street      // => "Main Street"
newAddress.HouseNumber // => 86
```

Οι καταγραφές έχουν _δομική ισότητα_, που σημαίνει ότι δύο στιγμιότυπα της ίδιας καταγραφής με ίδιες τιμές είναι ισοδύναμα.

Εκτός από τη δυνατότητα χρήσης σημειογραφίας με τελεία για πρόσβαση στα πεδία μιας καταγραφής, οι καταγραφές μπορούν επίσης να αποδομηθούν σε δεσμεύσεις και σε αντιστοίχιση προτύπων:

```fsharp
let myAddress: Address = { Street = "Broadway"; HouseNumber = 123 }
let { Street = myStreet; HouseNumber = myHouseNumber } = myAddress

match myAddress with
| { HouseNumber = 1 } -> printfn "First house"
| { HouseNumber = houseNumber; Street = street } -> printfn "House number %d on %s" houseNumber street
// => "House number 123 on Broadway
```
