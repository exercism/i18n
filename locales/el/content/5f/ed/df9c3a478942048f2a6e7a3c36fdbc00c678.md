# Σχετικά

Οι [τριμερείς τελεστές][ternary-operators] επιτρέπουν να ορίζονται συνθήκες if σε εκφράσεις αντί για μπλοκ εντολών. Αυτό θυμίζει προσεγγίσεις του συναρτησιακού προγραμματισμού και συχνά μπορεί να κάνει τον κώδικα πιο εκφραστικό και λιγότερο επιρρεπή σε σφάλματα.

Ο τριμερής τελεστής συνδυάζει 3 εκφράσεις: μια συνθήκη, ακολουθούμενη από μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι αληθής (το τμήμα `if`, που εισάγεται από το `?`) και μια έκφραση που αξιολογείται και επιστρέφεται αν η συνθήκη είναι ψευδής (το τμήμα `else`, που εισάγεται από το `:`).

```csharp
int a = 3, b = 4;
int max = a > b ? a : b;
// => 4
```

[ternary-operators]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/conditional-operator
