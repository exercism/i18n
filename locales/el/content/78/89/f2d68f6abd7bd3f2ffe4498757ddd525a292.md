# Υποδείξεις

## Γενικά

- Ένα δέντρο είναι μια αναδρομική δομή δεδομένων που έχει δύο περιπτώσεις:
  - `nil`: ένας κόμβος-φύλλο, που δεν έχει τιμή
  - `node(Left, Value, Right)`: ένας κανονικός κόμβος, που έχει τιμή και έναν αριστερό και έναν δεξιό κόμβο
- Και για την προδιατεταγμένη και για την ενδοδιατεταγμένη διάσχιση, θα χρειαστεί να ορίσεις κανόνες που χειρίζονται τις δύο περιπτώσεις για τα δέντρα.
