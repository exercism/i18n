# χρήση της σημείωσης override

Αν και δεν είναι απολύτως απαραίτητο, είναι καλή πρακτική να χρησιμοποιείς τη σημείωση `@Override` όταν κάνεις override σε μεθόδους από μια υπερκλάση.

Κάτι τέτοιο μπορεί να βοηθήσει στην αποφυγή σφαλμάτων· αν μια μέθοδος που φέρει τη σημείωση `@Override` δεν κάνει σωστά override σε μια μέθοδο κάποιας από τις υπερκλάσεις της, ο μεταγλωττιστής θα εμφανίσει ένα σφάλμα.
