# Introduction

## AST

Το Abstract Syntax Tree (AST), που λέγεται και _παρατιθέμενη έκφραση_, είναι ένας τρόπος να αναπαραστήσεις τον κώδικα ως δεδομένα.

Κάθε κόμβος στο AST είναι μια πλειάδα τριών στοιχείων.

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

Το πρώτο στοιχείο, ένα άτομο, είναι η πράξη. Το δεύτερο στοιχείο, μια λίστα λέξεων-κλειδιών, είναι τα μεταδεδομένα. Το τρίτο στοιχείο είναι μια λίστα ορισμάτων, που περιέχει άλλους κόμβους. Οι κυριολεκτικές τιμές, όπως οι ακέραιοι, τα άτομα και οι συμβολοσειρές, αναπαρίστανται στο AST ως οι ίδιες αντί για πλειάδες τριών στοιχείων.

### Μετατροπή κώδικα σε AST

Η μετατροπή κώδικα Elixir σε AST και η μετατροπή AST πίσω σε κώδικα είναι μέρος της βασικής βιβλιοθήκης. Μπορείς να βρεις συναρτήσεις για να δουλέψεις με AST στα αρθρώματα `Code` (π.χ. για να μετατρέψεις μια συμβολοσειρά με κώδικα σε AST) και `Macro` (π.χ. για να διατρέξεις το AST ή να το μετατρέψεις σε συμβολοσειρά).

Σημείωσε ότι όλες οι συναρτήσεις της βασικής βιβλιοθήκης χρησιμοποιούν το όνομα "quoted" για να δηλώσουν το AST (συντομογραφία της _παρατιθέμενης έκφρασης_).

Η ειδική μορφή για τη μετατροπή κώδικα σε AST ονομάζεται `quote`. Δέχεται ένα μπλοκ κώδικα και επιστρέφει το AST του.

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

### Περιπτώσεις χρήσης

Η δυνατότητα να αναπαραστήσεις τον κώδικα ως AST βρίσκεται στην καρδιά του μεταπρογραμματισμού στην Elixir. Οι _μακροεντολές_, που είναι ένας τρόπος να γράφεις κώδικα Elixir ο οποίος παράγει κώδικα Elixir, λειτουργούν επιστρέφοντας AST ως έξοδο.

Μια άλλη περίπτωση χρήσης των AST είναι η στατική ανάλυση κώδικα, όπως το εργαλείο της ίδιας της Exercism, το Analyzer, που ίσως το ξέρεις ήδη ως το μικρό bot που αφήνει σχόλια στις λύσεις σου.
