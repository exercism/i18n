# Εισαγωγή

## Συμβολοσειρές

Οι συμβολοσειρές στη Gleam είναι αμετάβλητο κείμενο που περικλείεται από διπλά εισαγωγικά. Υποστηρίζουν χαρακτήρες unicode και μπορούν να εκτείνονται σε πολλές γραμμές.

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

Μπορείς να ενώσεις συμβολοσειρές με τον τελεστή `<>`:

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

Το module [`gleam/string`][stdlib] της πρότυπης βιβλιοθήκης παρέχει συναρτήσεις για την εργασία με συμβολοσειρές.

Οι συμβολοσειρές μπορούν να χρησιμοποιηθούν σε αντιστοίχιση προτύπων μέσα σε εκφράσεις `case`:

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

Αν θέλεις να κάνεις αντιστοίχιση στην αρχή μιας συμβολοσειράς και να αναθέσεις το υπόλοιπο σε μια μεταβλητή, μπορείς να χρησιμοποιήσεις το πρότυπο με τον τελεστή `<>`:

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
