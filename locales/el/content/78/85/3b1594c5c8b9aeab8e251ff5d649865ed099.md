# Προσθήκη οδηγιών

## Callable

Στην PHP υπάρχει η έννοια του [callable](https://www.php.net/manual/en/language.types.callable.php).

Αυτά μπορούν να πάρουν πολλές μορφές, αλλά εμείς θα επικεντρωθούμε στις [ανώνυμες συναρτήσεις](https://www.php.net/manual/en/functions.anonymous.php).

Μπορείς να δημιουργήσεις μια ανώνυμη συνάρτηση μέσα σε μια μεταβλητή και να την καλέσεις με παραμέτρους:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
