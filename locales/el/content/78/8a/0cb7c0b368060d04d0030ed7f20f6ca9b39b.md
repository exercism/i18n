# Προσθήκη στις οδηγίες

## Υλοποίηση

Τα αντικείμενα αναπαρίστανται με [καταγραφές](https://lfe.gitbooks.io/reference-guide/content/16.html), που ορίζονται στο `item.lfe`.
Χρησιμοποίησε το `item-weight` για να πάρεις το βάρος και το `item-value` για να πάρεις την τιμή.

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
