# Εισαγωγή

Η ABAP έχει αρκετούς αριθμητικούς τύπους. Σε αυτή την άσκηση, θα χρησιμοποιήσεις δύο από αυτούς:

- `i` για ακέραιες τιμές, όπως έναν αριθμό ημερών.
- `p` για πακεταρισμένες δεκαδικές τιμές, όπως μια ωριαία χρέωση ή μια έκπτωση.

```abap
DATA billable_days TYPE i VALUE 22.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.
```

Οι πακεταρισμένοι αριθμοί ορίζουν το μέγιστο μήκος τους και τον αριθμό των δεκαδικών ψηφίων. Τα δεκαδικά literals γράφονται συνήθως ως τιμές κειμένου και μετατρέπονται στον δεκαδικό τύπο προορισμού από τον μεταγλωττιστή ή με τη `CONV`.

```abap
TYPES discount_rate TYPE p LENGTH 8 DECIMALS 6.

DATA discount TYPE discount_rate.
discount = CONV discount_rate( '0.15' ).
```

Η ABAP παρέχει ενσωματωμένες αριθμητικές συναρτήσεις για στρογγυλοποίηση. Η συνάρτηση `floor` στρογγυλοποιεί προς τα κάτω στον πλησιέστερο ακέραιο αριθμό και η `ceil` στρογγυλοποιεί προς τα πάνω στον πλησιέστερο ακέραιο αριθμό.

```abap
DATA full_months TYPE i.
full_months = floor( 70 / 22 ).

DATA rounded_cost TYPE i.
rounded_cost = ceil( '14527.2' ).
```
