# Οδηγίες

Σε αυτή την άσκηση θα γράφεις κώδικα για να παρακολουθείς μια λίστα με γλώσσες προγραμματισμού που θέλεις να μάθεις στο Exercism.

Έχεις έξι εργασίες, οι οποίες όλες θα περιλαμβάνουν χειρισμό λιστών.

## 1. Δημιούργησε μια νέα λίστα

Για να παρακολουθείς τις γλώσσες που θέλεις να μάθεις, θα χρειαστεί να δημιουργήσεις μια νέα λίστα. Όρισε τη δέσμευση `newList` που περιέχει μια νέα, κενή λίστα.

```fsharp
newList
// => []
```

## 2. Όρισε μια υπάρχουσα λίστα

Αυτή τη στιγμή, έχεις ένα χαρτί που απαριθμεί τις γλώσσες που θέλεις να μάθεις: F#, Clojure και Haskell. Όρισε τη δέσμευση `existingList` για να αναπαραστήσεις αυτή τη λίστα.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Πρόσθεσε μια νέα γλώσσα σε μια λίστα

Καθώς εξερευνάς το Exercism και βρίσκεις πιο ενδιαφέρουσες γλώσσες, θέλεις να τις προσθέσεις στη λίστα σου. Υλοποίησε τη συνάρτηση `addLanguage` για να προσθέτεις μια νέα γλώσσα στην αρχή της λίστας σου.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Μέτρησε τις γλώσσες στη λίστα

Η καταμέτρηση των γλωσσών μία προς μία είναι άβολη. Υλοποίησε τη συνάρτηση `countLanguages` για να μετράς τον αριθμό των γλωσσών στη λίστα σου.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Αντιστρέψε τη λίστα

Κάποια στιγμή, συνειδητοποιείς ότι η λίστα σου είναι στην πραγματικότητα σε αντίστροφη σειρά! Υλοποίησε τη συνάρτηση `reverseList` για να αντιστρέψεις τη λίστα σου.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Έλεγξε αν η λίστα είναι συναρπαστική

Ενώ αγαπάς όλες τις γλώσσες, η F# έχει μια ξεχωριστή θέση στην καρδιά σου. Γι' αυτό, ενθουσιάζεσαι πραγματικά με μια λίστα γλωσσών αν:

- Το πρώτο στη λίστα είναι F#.
- Το δεύτερο στοιχείο στη λίστα είναι F# και η λίστα περιέχει είτε δύο είτε τρεις γλώσσες.

Υλοποίησε τη συνάρτηση `excitingList` για να ελέγχεις αν μια λίστα γλωσσών είναι συναρπαστική:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
