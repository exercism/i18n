# Υποδείξεις

## Γενικά

- Οι πίνακες με τις καταμετρήσεις πουλιών περιέχουν πάντα ακριβώς 7 ακέραιους.

## 1. Έλεγξε ποιες ήταν οι καταμετρήσεις την προηγούμενη εβδομάδα

- Υπάρχουν [αρκετοί τρόποι να ορίσεις έναν πίνακα][creating-arrays].

## 2. Έλεγξε πόσα πουλιά επισκέφτηκαν χθες

- Θυμήσου ότι οι καταμετρήσεις είναι ταξινομημένες κατά ημέρα, από την παλαιότερη στην πιο πρόσφατη, με το τελευταίο στοιχείο να αντιπροσωπεύει τη σημερινή ημέρα.
- Μπορείς να προσπελάσεις το προτελευταίο στοιχείο είτε χρησιμοποιώντας τη (σταθερή) θέση του (θυμήσου να αρχίζεις να μετράς από το μηδέν) είτε υπολογίζοντας τη θέση του με το μήκος του πίνακα, είτε μέσω μιας [συνάρτησης στο `Array`][length-function] είτε μέσω μιας από τις [ιδιότητες][length-property] του πίνακα.

## 3. Υπολόγισε τον συνολικό αριθμό των πουλιών που επισκέφτηκαν

- Στο `Array` υπάρχει μια [συνάρτηση για το άθροισμα των τιμών ενός πίνακα][sum-function].

## 4. Έλεγξε αν υπήρξε ημέρα χωρίς κανένα πουλί

- Στο `Array` υπάρχει μια [συνάρτηση για να ελέγξεις αν ένας πίνακας περιέχει μια συγκεκριμένη τιμή][contains-function].

## 5. Αύξησε τη σημερινή καταμέτρηση

- Υπάρχουν δύο τρόποι να ενημερώσεις μια τιμή σε έναν πίνακα:
  - Ο τελεστής `<-` επιτρέπει την ενημέρωση μιας τιμής σε έναν πίνακα.
  - Στο `Array` υπάρχει μια [συνάρτηση για την ενημέρωση μιας τιμής σε έναν πίνακα][set-function].
- Η παραπάνω συνάρτηση για την ενημέρωση μιας τιμής σε έναν πίνακα δεν επιστρέφει τιμή. Θα πρέπει λοιπόν να επιστρέψεις χειροκίνητα τον ενημερωμένο πίνακα αφού ορίσεις την τιμή του.

## 6. Έλεγξε για ασυνήθιστη εβδομάδα

- Αντί να ελέγχεις όλες τις επιμέρους τιμές, χρησιμοποίησε [αντιστοίχιση προτύπων][pattern-matching-array].
