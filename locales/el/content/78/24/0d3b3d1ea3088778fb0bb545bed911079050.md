# Εισαγωγή

Ένας συνηθισμένος τρόπος να χρησιμοποιήσεις μια διακριτή ένωση στο F# είναι για να αναπαραστήσεις ένα σταθερό σύνολο από ονομασμένες σταθερές, μια δομή που σε άλλες γλώσσες ονομάζεται "enum".

Συνήθως, σε μια τέτοια διακριτή ένωση, κάθε περίπτωση μπορεί να αναφέρεται σε μία μόνο από αυτές τις ονομασμένες σταθερές.
Ωστόσο, μερικές φορές είναι χρήσιμο να αναφέρεσαι σε περισσότερες από μία σταθερές.
Για να το κάνεις αυτό, μπορείς να επισημάνεις τη διακριτή ένωση με το χαρακτηριστικό Flags.

Μια διακριτή ένωση με το χαρακτηριστικό Flags μπορεί να οριστεί ως εξής (χρησιμοποιώντας συμβολισμό δυαδικών ακεραίων 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Ένα στιγμιότυπο `PhoneFeatures` με τιμή `0b00000011` έχει ενεργοποιημένες και τις δύο σημαίες `Call` και `Text`.
