# Εισαγωγή

## Αριθμοί

Υπάρχουν δύο διαφορετικοί τύποι αριθμών στη C#:

- Ακέραιοι: αριθμοί χωρίς ψηφία μετά την υποδιαστολή (ακέραιοι αριθμοί). Παραδείγματα: `-6`, `0`, `1`, `25`, `976` και `500000`.
- Αριθμοί κινητής υποδιαστολής: αριθμοί με μηδέν ή περισσότερα ψηφία μετά την υποδιαστολή. Παραδείγματα: `-2.4`, `0.1`, `3.14`, `16.984025` και `1024.0`.

Οι δύο πιο συνηθισμένοι αριθμητικοί τύποι στη C# είναι οι `int` και `double`. Ένα `int` είναι ένας ακέραιος 32 bit και ένα `double` είναι ένας αριθμός κινητής υποδιαστολής 64 bit.

Οι αριθμητικές πράξεις γίνονται με τους τυπικούς αριθμητικούς τελεστές. Οι αριθμοί μπορούν να συγκριθούν με τους τυπικούς τελεστές σύγκρισης αριθμών και τους τελεστές ισότητας (`==`) και ανισότητας (`!=`).

Η C# έχει δύο τύπους αριθμητικών μετατροπών:

1. Έμμεσες μετατροπές: δεν θα χαθούν δεδομένα και δεν απαιτείται πρόσθετη σύνταξη.
2. Ρητές μετατροπές: μπορεί να χαθούν δεδομένα και απαιτείται πρόσθετη σύνταξη με τη μορφή ενός _cast_.

Επειδή ένα `int` έχει μικρότερη ακρίβεια από ένα `double`, η μετατροπή από `int` σε `double` είναι ασφαλής και επομένως είναι έμμεση μετατροπή. Ωστόσο, η μετατροπή από `double` σε `int` μπορεί να σημαίνει απώλεια δεδομένων, οπότε απαιτεί ρητή μετατροπή.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Εντολές `if`

Σε αυτή την άσκηση πρέπει να εκτελέσεις λογική υπό συνθήκη. Ο πιο συνηθισμένος τρόπος να το κάνεις αυτό στη C# είναι με μια εντολή `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

Η συνθήκη μιας εντολής `if` πρέπει να είναι τύπου `bool`. Η C# δεν έχει την έννοια των _truthy_ τιμών.
