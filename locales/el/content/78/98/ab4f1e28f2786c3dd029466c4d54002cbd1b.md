# Εισαγωγή

Πολλά προγράμματα χρειάζονται (ψευδο)τυχαίες τιμές για να προσομοιώσουν γεγονότα του πραγματικού κόσμου.

Συνηθισμένα, οικεία παραδείγματα περιλαμβάνουν:

- Ρίψη νομίσματος: μια τυχαία τιμή από ('H', 'T').
- Ρίψη ζαριού: ένας τυχαίος ακέραιος από το 1 έως το 6.
- Ανακάτεμα μιας τράπουλας: μια τυχαία διάταξη μιας λίστας φύλλων.
- Τη δημιουργία δέντρων και θάμνων σε μια τρισδιάστατη προσομοίωση γραφικών.

Η παραγωγή πραγματικά τυχαίων τιμών με έναν υπολογιστή είναι μια [τεχνική πρόκληση που εκπλήσσει με τη δυσκολία της][why-randomness-is-hard], γι' αυτό υπάρχουν και οι "ψευδοτυχαίοι" γεννήτορες.

~~~exercism/advanced
Οι [προδιαγραφές της γλώσσας][spec] για τη JavaScript δεν επιβάλλουν τον τρόπο υλοποίησης της παραγωγής τυχαίων αριθμών.
Όλοι οι μεγάλοι περιηγητές και τα περιβάλλοντα εκτέλεσης JavaScript υλοποιούν έναν PRNG (γεννήτορα ψευδοτυχαίων αριθμών).
Επειδή οι αριθμοί δεν είναι κρυπτογραφικά ασφαλείς, δεν θα πρέπει να χρησιμοποιούνται ποτέ για οτιδήποτε απαιτεί πραγματικά τυχαίους ή τουλάχιστον κρυπτογραφικά ασφαλείς τυχαίους αριθμούς, όπως η δημιουργία πιστοποιητικών ή κωδικών πρόσβασης ή σχετικές λειτουργίες.

Υπάρχει ένα πρότυπο που ονομάζεται [Web Cryptography][rfc], το οποίο τυποποιεί μια διεπαφή για κρυπτογραφικές λειτουργίες στη JavaScript.
Υλοποιείται [από τους περιηγητές][crypto-web] καθώς και από περιβάλλοντα εκτέλεσης όπως το [Node.JS][crypto-node] και το [Deno][crypto-deno].

Αυτή η έννοια δεν αφορά το Web Crypto και θα περιοριστεί στην παραγωγή ψευδοτυχαίων αριθμών.

## Παραγωγή τυχαίων αριθμών

Στη JavaScript, μπορείς να παράγεις ψευδοτυχαίους αριθμούς χρησιμοποιώντας τη συνάρτηση [`Math.random()`][Math.random].
Επιστρέφει έναν ψευδοτυχαίο αριθμό κινητής υποδιαστολής μεταξύ του 0 (συμπεριλαμβανομένου) και του 1 (μη συμπεριλαμβανομένου).

Για να πάρεις έναν τυχαίο αριθμό μεταξύ του _min_ (συμπεριλαμβανομένου) και του _max_ (μη συμπεριλαμβανομένου), μπορείς να χρησιμοποιήσεις μια συνάρτηση κάπως έτσι:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

~~~exercism/advanced
Οι περισσότερες απλές τεχνικές για την παραγωγή ενός εύρους αριθμών με βάση τον τυχαία παραγόμενο αριθμό [εισάγουν μεροληψία][bias].
Αυτό σημαίνει ότι κάποιοι αριθμοί είναι πιο πιθανό να προκύψουν από άλλους.
Η χρήση της τεχνικής του πολλαπλασιασμού κατανέμει τη μεροληψία σε ολόκληρο το εύρος, οπότε είναι λιγότερο εμφανής και στις περισσότερες περιπτώσεις δεν αποτελεί μεγάλο πρόβλημα, αλλά καλό είναι να το γνωρίζεις.

[bias]: https://adammil.net/blog/v134_Efficiently_generating_random_numbers_without_bias.html

## Παραγωγή τυχαίων ακεραίων

Για να παράγεις έναν τυχαίο ακέραιο, μπορείς να χρησιμοποιήσεις τη `Math.floor()` ή τη `Math.ceil()` για να μετατρέψεις έναν τυχαία παραγόμενο αριθμό σε ακέραιο.

[why-randomness-is-hard]: https://www.malwarebytes.com/blog/news/2013/09/in-computers-are-random-numbers-really-random
[Math.random]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Math/random
