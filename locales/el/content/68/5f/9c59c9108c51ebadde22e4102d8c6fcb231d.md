# Οδηγίες

Ο φίλος σου ο Linus είναι μηχανοδηγός και οδηγεί εμπορευματικά τρένα ανάμεσα σε πόλεις.
Αν και είναι καταπληκτικός στο χειρισμό των τρένων, δεν τα καταφέρνει εξίσου καλά με τα logistics ή με τους υπολογιστές.
Θα ήθελε να ζητήσει τη βοήθειά σου στον προγραμματισμό για να οργανώσει τις λεπτομέρειες των τρένων και να διορθώσει λάθη στα δεδομένα των διαδρομών.

~~~~exercism/note
Αυτή η άσκηση θα μπορούσε εύκολα να λυθεί με τεμαχισμό, ευρετηρίαση και διάφορες μεθόδους `hash`.
Ωστόσο, θα θέλαμε να εξασκηθείς στο πακετάρισμα, το ξεπακετάρισμα και την πολλαπλή εκχώρηση λύνοντας καθεμία από τις παρακάτω εργασίες.
~~~~

## 1. Δημιούργησε μια λίστα με όλα τα βαγόνια

Ο φίλος σου κρατά αρχείο με το αναγνωριστικό (ID) κάθε βαγονιού, αλλά δεν είναι ποτέ σίγουρος πόσα βαγόνια θα χρειαστεί να επεξεργαστεί το σύστημα κάθε δεδομένη στιγμή. Θα ήταν πολύ πιο εύκολο για το υπόλοιπο πρόγραμμα logistics να έχει αυτά τα δεδομένα συσκευασμένα σε έναν ενιαίο **πίνακα**.

Υλοποίησε μια μέθοδο `generate_list_of_wagons()` που δέχεται οποιονδήποτε αριθμό αναγνωριστικών βαγονιών.
Κάθε αναγνωριστικό θα είναι ένας θετικός ακέραιος.
Στη συνέχεια, η μέθοδος θα πρέπει να `return` τα δοσμένα αναγνωριστικά ως έναν μόνο **πίνακα**.

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. Διόρθωσε τη λίστα με τα βαγόνια

Σε αυτό το σημείο, αρχίζεις να εξοικειώνεσαι με τα δεδομένα και με τον τρόπο που χρησιμοποιούνται στο πρόγραμμα logistics.
Το σύστημα αναγνωριστικών δίνει πάντα στη μηχανή το αναγνωριστικό **1**, ενώ στα υπόλοιπα βαγόνια του τρένου αναθέτει ένα τυχαία επιλεγμένο αναγνωριστικό μεγαλύτερο του **1**.

Ο φίλος σου έπρεπε να συνδέσει δύο νέα βαγόνια στο τρένο και ξέχασε να ενημερώσει το σύστημα!
Τώρα, τα δύο πρώτα βαγόνια του **πίνακα** του τρένου πρέπει να μετακινηθούν στο τέλος, αλλιώς τα πάντα θα είναι σε λάθος σειρά.

Για να γίνουν τα πράγματα πιο περίπλοκα, ο φίλος σου μόλις ανακάλυψε έναν δεύτερο **πίνακα** που φαίνεται να περιέχει αναγνωριστικά βαγονιών που λείπουν.
Το μόνο που θυμάται είναι ότι, αφού μετακινηθούν τα νέα βαγόνια, τα αναγνωριστικά από αυτόν τον δεύτερο **πίνακα** πρέπει να τοποθετηθούν αμέσως μετά τη μηχανή που έχει οριστεί.

Ο Linus θα σου είναι πολύ ευγνώμων που διόρθωσες τα λάθη του και ενοποίησες τα δεδομένα.

Υλοποίησε μια μέθοδο `fix_list_of_wagons()` που παίρνει δύο **πίνακες** με αναγνωριστικά βαγονιών.
Θα πρέπει να μετακινήσει τα δύο πρώτα στοιχεία του πρώτου **πίνακα** στο τέλος και να εισαγάγει τις τιμές από τον δεύτερο **πίνακα** πίσω (_στη δεξιά πλευρά του_) από το αναγνωριστικό της μηχανής (**1**).
Στη συνέχεια, η μέθοδος θα πρέπει να `return` έναν **πίνακα** με τις τροποποιήσεις.

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. Πρόσθεσε τις στάσεις που λείπουν

Τώρα που όλα τα δεδομένα των βαγονιών είναι σωστά, ο Linus θα ήθελε να ενημερώσεις τις πληροφορίες δρομολόγησης του συστήματος.
Κατά μήκος μιας διαδρομής μεταφοράς, ένα τρένο μπορεί να κάνει στάσεις σε μερικούς διαφορετικούς σταθμούς για να παραλάβει ή/και να αφήσει φορτίο.
Κάθε ταξίδι μπορεί να έχει διαφορετικό αριθμό από αυτά τα ενδιάμεσα σημεία παράδοσης.
Ο φίλος σου θα ήθελε να ενημερώσεις το **hash** δρομολόγησης του συστήματος με οποιαδήποτε πληροφορία παράδοσης λείπει ή είναι επιπλέον.

Υλοποίησε μια μέθοδο `add_missing_stops()` που δέχεται ένα **hash** δρομολόγησης ακολουθούμενο από μεταβλητό αριθμό ορισμάτων με λέξεις-κλειδιά.
Αυτά τα ορίσματα μπορεί να έχουν τη μορφή ενός **hash** που περιέχει μία ή περισσότερες στάσεις, ή οποιουδήποτε αριθμού ζευγών λέξεων-κλειδιών `stop_<number>: "city"`.
Στη συνέχεια, η μέθοδος θα πρέπει να επιστρέψει το **hash** δρομολόγησης ενημερωμένο με ένα επιπλέον **κλειδί** που περιέχει έναν **πίνακα** με όλες τις στάσεις που προστέθηκαν, με τη σειρά τους.

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
Οι στάσεις θα περνιούνται πάντα με τη σωστή σειρά, οπότε δε χρειάζεται να ανησυχείς για την ταξινόμησή τους.
~~~~

## 4. Επέκτεινε τις πληροφορίες δρομολόγησης

Ο Linus δουλεύει πάνω στο πρόγραμμα δρομολόγησης και έχει παρατηρήσει ότι ορισμένες διαδρομές λείπουν κάποιες σημαντικές λεπτομέρειες.
Οι αρχικές πληροφορίες της διαδρομής έχουν κατασκευαστεί ως ένα **hash** και ο φίλος σου θα ήθελε να ενημερώσεις αυτό το **hash** με ό,τι μπορεί να λείπει.
Κάθε διαδρομή στο σύστημα απαιτεί ελαφρώς διαφορετικές λεπτομέρειες, οπότε ο Linus θα προτιμούσε πραγματικά μια γενική λύση.

Υλοποίησε μια μέθοδο που ονομάζεται `extend_route_information()` και δέχεται δύο **hash**.
Το πρώτο **hash** περιέχει τις πόλεις αναχώρησης και προορισμού ανάμεσα στις οποίες εκτελείται η διαδρομή του τρένου.

Το δεύτερο **hash** περιέχει άλλες λεπτομέρειες της διαδρομής, όπως την ταχύτητα, το μήκος ή τη θερμοκρασία του τρένου.
Η μέθοδος θα πρέπει να επιστρέψει ένα ενοποιημένο **hash** με όλες τις πληροφορίες της διαδρομής.

~~~~exercism/note
Το δεύτερο **hash** μπορεί να περιέχει διαφορετικές ή περισσότερες ιδιότητες από αυτές που φαίνονται στο παράδειγμα.
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
