# Προσθήκη στις οδηγίες

## Ειδικές σημειώσεις για το assembly x86-64

Οι συναρτήσεις σε αυτή την άσκηση δέχονται έναν πίνακα που περιέχει έναν ή περισσότερους αριθμούς, καθένας από τους οποίους αντιπροσωπεύει μία "βαθμολογία παιχνιδιού".

Στο assembly x86-64, τα στοιχεία ενός πίνακα προσπελαύνονται ως μετατόπιση σε bytes από έναν δείκτη βάσης.

Αυτός ο δείκτης βάσης περνιέται σε έναν καταχωρητή, σύμφωνα με τη [Σύμβαση Κλήσης System V AMD64 ABI](https://www.uclibc.org/docs/psABI-x86_64.pdf).

Τα 3 πρώτα ορίσματα περνιούνται στους rdi, rsi, rdx, με αυτή τη σειρά.

Καθώς οι βαθμολογίες του παίκτη αναπαρίστανται ως ακέραιοι 32 bit, που καταλαμβάνουν 4 bytes, μπορούν να διαβαστούν από

| `rsi`   |
|---|
| `dword [rsi]` |
| `dword [rsi + 4]` |
| ... |
| `dword [rsi + 4*scores_count - 4]` |

Η `personal_top_three()` θα πρέπει να γράφει τις κορυφαίες βαθμολογίες του παίκτη σε ένα buffer, το οποίο επίσης περνιέται σε έναν καταχωρητή και προσπελαύνεται με τον ίδιο τρόπο.

| `rdi`   |
|---|
| `dword [rdi]` |
| `dword [rdi + 4]` |
| ... |

Οι ακέραιες τιμές, κατά σύμβαση, επιστρέφονται στον καταχωρητή rax.
