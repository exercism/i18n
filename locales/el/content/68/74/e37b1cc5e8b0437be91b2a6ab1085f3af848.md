# Σχετικά

Το [concept:csharp/resource-cleanup]() χρησιμοποιεί τη διεπαφή `IDispose` για να δηλώσει σε όσους καλούν μια κλάση ότι υπάρχουν πόροι ή κατάσταση του προγράμματος που πρέπει να απελευθερωθούν ή να επαναφερθούν εγκαίρως, όταν το αντικείμενο στο οποίο αναφέρονται δεν χρειάζεται πια. Σε αυτή την άσκηση έχουμε εισαγάγει λίγη συντακτική ζάχαρη, με τη λέξη-κλειδί `using`, που κάνει τον κώδικα λιγότερο φλύαρο και μειώνει την πιθανότητα να παραλειφθούν σημαντικές κλήσεις.

Το `using` μπορεί να θεωρηθεί ότι αντικαθιστά το [`try/finally`][try-finally] σε ορισμένες περιπτώσεις χρήσης.

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

Αυτή η σύνταξη αντικαθίσταται από την πιο συμπαγή και αλάνθαστη:

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

Σημείωσε ότι πολλοί πόροι μπορούν να συνδυαστούν εύκολα ακολουθώντας τους συνήθεις κανόνες για μπλοκ μιας γραμμής:

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

Στη C# 8 εισήχθη η εξής παραλλαγή, όπου η εντολή `using` βρίσκεται στην αρχή ενός μπλοκ:

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

Αυτό σου επιτρέπει να έχεις πολλά αντικείμενα disposable στο ίδιο μπλοκ και να χειρίζεσαι πιο φυσικά το [`try/catch`][try-catch]:

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

Οι κανόνες που σχετίζονται με το πώς μπορεί να χρησιμοποιηθεί η λέξη-κλειδί `using` και με στιγμιότυπα ποιων τύπων, περιγράφονται λεπτομερώς [εδώ][using-statement].

## Σημείωση για προγραμματιστές Java

Οι προγραμματιστές Java ίσως αναγνωρίσουν σε αυτό ένα ανάλογο του μηχανισμού [_αυτόματης διαχείρισης πόρων_][automatic-resource-management] που εισήχθη στη Java 7. Μοιάζουν πολύ. Η σύνταξη της Java, η οποία επαναχρησιμοποιεί το `try`, έχει το πλεονέκτημα ότι ενσωματώνει τα μπλοκ `catch` πιο φυσικά απ' ό,τι το `using` της C#.

## Εκδόσεις

Σημείωσε ότι η πιο ευέλικτη εκδοχή του `using`, όπου δεν έχει το δικό της συντακτικό μπλοκ, εισήχθη στη C# 8, οπότε ίσως χρειαστεί να ελέγξεις αν η βάση κώδικα στην οποία εργάζεσαι χρησιμοποιεί C# 8 ή νεότερη.

## Αναφορά

Η τεκμηρίωση της [εντολής using][using-statement] περιγράφει πώς και πότε να χρησιμοποιείς τη λέξη-κλειδί `using`.
