# Σχετικά

Το `call` είναι το καθολικό βασικό στοιχείο για "τρέξε αυτό το απόσπασμα τώρα". Όταν ο μεταγλωττιστής μπορεί να δει το απόσπασμα κυριολεκτικά, μπορεί να συμπεράνει και την επίδραση στη στοίβα. Όταν όμως το απόσπασμα προέρχεται από μια μεταβλητή, έναν πίνακα ή μια παράμετρο, πρέπει να δηλώσεις την επίδραση:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

Η δήλωση `call( a b -- c )` μεταγλωττίζεται σε έναν έλεγχο κατά την εκτέλεση ότι το απόσπασμα έχει πράγματι τη δηλωμένη επίδραση: μια ασυμφωνία γίνεται ένα σαφές σφάλμα αντί για κατεστραμμένη κατάσταση της στοίβας.

Το να μεταχειρίζεσαι τα αποσπάσματα ως δεδομένα, να τα σπρώχνεις στη στοίβα, να τα βάζεις σε πίνακες, να τα επιστρέφεις από λέξεις, είναι ένα από τα πράγματα που κάνουν τον συνενωτικό κώδικα τόσο συμπαγή. Ένα "πρόγραμμα" μπορεί να είναι μια απλή ακολουθία, και το `each` μαζί με το `call` αρκεί για να την ερμηνεύσεις.
