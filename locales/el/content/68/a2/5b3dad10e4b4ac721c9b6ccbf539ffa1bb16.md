# Tests

Σε MacOS/Linux, τρέξε:

```sh
$ chmod +x gradlew
```

Εκτέλεσε τα tests με:

```sh
$ ./gradlew test
```

> Χρησιμοποίησε το `gradlew.bat` αν χρησιμοποιείς Windows

## Παραλειπόμενα tests

Μόλις περάσει το πρώτο test (ή τα πρώτα tests), συνέχισε σχολιάζοντας ή αφαιρώντας τους σχολιασμούς `@Ignore` που προηγούνται των υπόλοιπων tests.
