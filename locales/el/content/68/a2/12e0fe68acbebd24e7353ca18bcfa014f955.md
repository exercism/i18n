# Οδηγίες

Η εταιρεία σχεδιασμού σου έχει δουλέψει κυρίως με μετασχηματισμούς CSS για να φτιάχνει ιστοσελίδες. Μετά από κάποια συζήτηση, αποφασίζεται να αρχίσει η ομάδα να χρησιμοποιεί Clojure για κάποιους δυναμικούς υπολογισμούς. Κάποιοι από τους συναδέλφους σου έχουν λιγότερη εμπειρία με την Clojure, οπότε αποφασίζεις να χρησιμοποιήσεις ένα closure συνάρτησης για να δημιουργήσεις επαναχρησιμοποιήσιμους μετασχηματισμούς για ζεύγη συντεταγμένων `{x, y}`.

## 1. Μετατόπισε τις συντεταγμένες

Υλοποίησε τη συνάρτηση `translate2d`, η οποία επιστρέφει μια συνάρτηση που χρησιμοποιεί ένα closure για να εκτελεί μια επαναλαμβανόμενη διδιάστατη μετατόπιση ενός ζεύγους συντεταγμένων.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def result (move-coordinates-right-2px 4 8))
;; result => [6 8]
```

## 2. Κλιμάκωσε τις συντεταγμένες

Υλοποίησε τη συνάρτηση `scale2d`, η οποία επιστρέφει μια συνάρτηση που χρησιμοποιεί ένα closure για να εκτελεί επαναλαμβανόμενη διδιάστατη κλιμάκωση ενός ζεύγους συντεταγμένων.

> Για αυτή την άσκηση, θεώρησε ότι οι τιμές κλιμάκωσης είναι μόνο θετικές.

```clojure
(def double-scale (scale2d 2 2))
(def result (double-scale 6 -3))
;; result => [12 -6]
```

## 3. Σύνθεσε συναρτήσεις μετασχηματισμού

Συνδύασε δύο συναρτήσεις μετασχηματισμού για να εκτελέσεις έναν επαναλαμβανόμενο μετασχηματισμό. Αυτό συχνά ονομάζεται _σύνθεση συναρτήσεων_, όπου το αποτέλεσμα της πρώτης συνάρτησης _'f(x)'_ χρησιμοποιείται ως είσοδος στη δεύτερη συνάρτηση _'g(x)'_.

```clojure
(def move-coordinates-right-2px (translate2d 2 0))
(def double-coordinates (scale2d 2 2))
(def composed-transformations 
  (compose-transform move-coordinates-right-2px 
                     double-coordinates))
(def result (composed-transformations 0 1))
;; result => [4 2]
```

## 4. Αποθήκευσε τα αποτελέσματα των συναρτήσεων

Υλοποίησε τη συνάρτηση `memoize-transform`. Παίρνει μια συνάρτηση προς _απομνημόνευση_ και μετά επιστρέφει μια νέα συνάρτηση που θυμάται τις εισόδους της συνάρτησης που της δίνεται, ώστε η τελευταία τιμή επιστροφής να μπορεί να "θυμάται" και να υπολογίζεται μόνο μία φορά αν κληθεί ξανά με τα ίδια ορίσματα.

> Η απομνημόνευση μερικές φορές ονομάζεται _δυναμικός προγραμματισμός_ και επιτρέπει να γίνονται οι δαπανηρές λειτουργίες μόνο μία φορά, αφού το αποτέλεσμά τους θυμάται.

```clojure
(def triple-scale (scale2d 3 3))
(def memoized-scale (memoize-transform triple-scale))

(memoized-scale 4 3)
;; => [12, 9], this is computed since it hasn't been computed before for the arguments

(memoized-scale 4 3)
;; => [12, 9], this is remembered, since it was computed already
```
