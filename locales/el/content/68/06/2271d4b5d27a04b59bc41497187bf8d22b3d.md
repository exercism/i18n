# Υποδείξεις

## 1. Όρισε το εύρος γραμμών και στηλών

- Πρέπει να ορίσεις δύο [σταθερές][constants] που θα περιέχουν ένα [`Range`][range] γραμμών και στηλών.
- Οι γραμμές πρέπει να είναι ένα `range` με τιμές [`Integer`][integers] από το 1 έως το 8.
- Οι στήλες πρέπει να είναι ένα `Range` με τιμές [`String`][string] από το 'A' έως το 'H'.
- Η σταθερά πρέπει να οριστεί στο [module][module] `Chess`.

## 2. Έλεγξε αν το τετράγωνο είναι έγκυρο

- Πρέπει να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος.
- Υπάρχει [μια μέθοδος][include] που μπορείς να χρησιμοποιήσεις για να ελέγξεις αν μια τιμή βρίσκεται μέσα σε ένα εύρος.

## 3. Πάρε το ψευδώνυμο του παίκτη

- Μπορείς να πάρεις ένα slice χρησιμοποιώντας ένα `Range` ως είσοδο.
- Υπάρχει μια [μέθοδος][upcase] που μπορείς να χρησιμοποιήσεις για να μετατρέψεις μια συμβολοσειρά σε κεφαλαία.

## 4. Δημιούργησε το μήνυμα της κίνησης

- Μπορείς να χρησιμοποιήσεις τη θέση στη συμβολοσειρά του τετραγώνου για να πάρεις τη γραμμή και τη στήλη.
- Μπορείς να χρησιμοποιήσεις μεθόδους που έχεις ήδη ορίσει για να πάρεις το ψευδώνυμο του παίκτη και να ελέγξεις αν η κίνηση είναι έγκυρη.
