# Σχετικά

Γράψε ReScript, κυκλοφόρησε JavaScript.
Χτισμένη πάνω στο ισχυρό σύστημα τύπων της OCaml και στον σύγχρονο διάδοχο των BuckleScript και ReasonML, η ReScript προσφέρει εξαντλητική αντιστοίχιση προτύπων και εγγυήσεις κατά τη μεταγλώττιση μέσα στο οικοσύστημα της JavaScript.
Η ενσωμάτωση της React ως πολίτη πρώτης κατηγορίας την καθιστά πειστική εναλλακτική απέναντι στη TypeScript για προγραμματιστές που θέλουν πραγματική ασφάλεια τύπων αντί για JavaScript με επισημειώσεις.
Χωρίς `any`, χωρίς εκπλήξεις από `undefined`.

[rescript-lang]: https://rescript-lang.org
