# Προσθήκη στις οδηγίες

## Διαδικασία IO

Σε αντίθεση με άλλες ασκήσεις, το `grep` απαιτεί να αλληλεπιδράσεις με τον "εξωτερικό κόσμο": να διαβάζεις αρχεία, να χειρίζεσαι σφάλματα του συστήματος και να εκτυπώνεις στο `stdout`.

Στη Lean, η αλληλεπίδραση με το σύστημα γίνεται συνήθως στη μονάδα [IO][io], η οποία επιτρέπει να συμβαίνουν παρενέργειες σε ένα ελεγχόμενο περιβάλλον χωρίς να επηρεάζεται η καθαρή κατάσταση των περισσότερων άλλων συναρτήσεων.

## Ανάγνωση ορισμάτων

Η Lean επιτρέπει να καλέσεις ένα αρχείο ως script, είτε απευθείας ως αυτόνομο script μέσω `lean --run` είτε με τη χρήση του `lake`.

Ένα project σε Lean έχει ένα σημείο εισόδου, μια συνάρτηση που ονομάζεται `main`, η οποία παίρνει μια `List String` με όλα τα ορίσματα που της περνιούνται.
Για να προσομοιωθεί η εκτέλεση του `Grep.lean` ως εκτελέσιμου, τα ορίσματα περνιούνται με τον ίδιο τρόπο σε αυτή την άσκηση.

## Ανάγνωση αρχείων

Η Lean προσφέρει [συναρτήσεις][files] για τον χειρισμό αρχείων στη μονάδα `IO.FS`.
Για παράδειγμα, η `IO.FS.readFile` μπορεί να χρησιμοποιηθεί για να διαβάσεις τα περιεχόμενα ενός αρχείου σε μια δεδομένη διαδρομή, ως `String`.

## Εγγραφή εξόδου

Αντί να επιστρέφει μια τιμή, αυτή η άσκηση απαιτεί τα αποτελέσματα να γράφονται στην τυπική έξοδο ή στο τυπικό σφάλμα.
Υπάρχουν [συναρτήσεις][console] στη Lean για αυτόν τον σκοπό.

## Χειρισμός σφαλμάτων συστήματος

Σε αντίθεση με τα σφάλματα στο `Except`, οι εξαιρέσεις του `IO` είναι στην πραγματικότητα εξαιρέσεις χρόνου εκτέλεσης.
Μπορείς να χρησιμοποιήσεις `try`/`catch` για να τις χειριστείς:

```
try
    /- 
        code that may possibly raise an exception 
    -/
catch msg =>
    /-
        code that is executed only if an exception was thrown
    -/
```
