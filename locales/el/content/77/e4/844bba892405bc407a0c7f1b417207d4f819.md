# Εισαγωγή

Οι σταθερές στη Gleam είναι ένας τρόπος να δίνεις ονόματα σε τιμές. Ορίζονται με τη λέξη-κλειδί `const`.

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

Όταν μια σταθερά ορίζεται με τη λέξη-κλειδί `pub`, μπορείς να έχεις πρόσβαση σε αυτήν από άλλα αρθρώματα. Αλλιώς, μπορείς να έχεις πρόσβαση σε αυτήν μόνο μέσα από το άρθρωμα στο οποίο ορίζεται.
