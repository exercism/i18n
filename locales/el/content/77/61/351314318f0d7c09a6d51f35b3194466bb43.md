# Οδηγίες

Σε αυτή την άσκηση βοηθάς τη μικρότερη αδερφή σου να επιμεληθεί την έκθεσή της για το σχολείο. Ο δάσκαλος ψάχνει για σωστή στίξη, γραμματική και εξαιρετική επιλογή λέξεων.

Έχεις τέσσερις εργασίες για να καθαρίσεις και να τροποποιήσεις συμβολοσειρές.

## 1. Κεφαλαιοποίησε τον τίτλο της έκθεσης

Κάθε καλή έκθεση χρειάζεται έναν σωστά μορφοποιημένο τίτλο.
Υλοποίησε τη συνάρτηση `capitalize_title(<title>)`, η οποία παίρνει ως παράμετρο έναν τίτλο `str` και κάνει κεφαλαίο το πρώτο γράμμα κάθε λέξης.
Η συνάρτηση θα πρέπει να επιστρέφει μια `str` σε μορφή τίτλου.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Έλεγξε αν κάθε πρόταση τελειώνει με τελεία

Θέλεις να σιγουρευτείς ότι η στίξη στην έκθεση είναι άψογη.
Υλοποίησε τη συνάρτηση `check_sentence_ending()`, η οποία παίρνει ως παράμετρο το `sentence`. Η συνάρτηση θα πρέπει να επιστρέφει ένα `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Καθάρισε τα κενά

Για να δείχνει η έκθεση επαγγελματική, πρέπει να αφαιρεθούν τα περιττά κενά.
Υλοποίησε τη συνάρτηση `clean_up_spacing()`, η οποία παίρνει ως παράμετρο το `sentence`.
Η συνάρτηση θα πρέπει να αφαιρεί τα επιπλέον κενά τόσο στην αρχή όσο και στο τέλος της πρότασης και να επιστρέφει μια νέα, ενημερωμένη πρόταση `str`.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Αντικατέστησε λέξεις με συνώνυμα

Για να κάνεις την έκθεση _ακόμη καλύτερη_, μπορείς να αντικαταστήσεις μερικά από τα επίθετα με συνώνυμά τους.
Γράψε τη συνάρτηση `replace_word_choice()`, η οποία παίρνει ως παραμέτρους τα `sentence`, `old_word` και `new_word`.
Η συνάρτηση θα πρέπει να αντικαθιστά κάθε εμφάνιση του `old_word` με το `new_word` και να επιστρέφει μια νέα `str` με την ενημερωμένη πρόταση.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
