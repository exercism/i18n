# Εισαγωγή

## Συναρτήσεις

Στη Gleam οι συναρτήσεις ορίζονται με τη σύνταξη `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Αυτή η συνάρτηση παίρνει δύο ορίσματα, και τα δύο τύπου `Int`, και επιστρέφει μια τιμή τύπου `Int`. Δεν υπάρχει λέξη-κλειδί `return` στη Gleam: η τιμή της τελευταίας έκφρασης σε μια συνάρτηση _επιστρέφεται πάντα σιωπηρά_.

Οι σχολιασμοί τύπου για τα ορίσματα και ο τύπος επιστροφής είναι προαιρετικοί, και η Gleam θα ελέγξει πάντα πλήρως τους τύπους του κώδικά σου. Συνήθως οι προγραμματιστές Gleam δίνουν σχολιασμούς τύπου στις συναρτήσεις τους για σαφήνεια, αλλά μπορείς να τους παραλείψεις αν θέλεις.

```gleam
pub fn add(x, y) {
  x + y
}
```

Μια συνάρτηση μπορεί να κληθεί με τη σύνταξη `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Μεταβλητές

Στη Gleam οι μεταβλητές ορίζονται με τη σύνταξη `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Οι μεταβλητές μπορούν να δηλωθούν με σχολιασμούς τύπου. Όπως και στα ορίσματα συναρτήσεων, αυτοί είναι προαιρετικοί, αν και οι περισσότεροι προγραμματιστές Gleam παραλείπουν τους σχολιασμούς τύπου στις μεταβλητές για συντομία.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Κυριολεκτικές συμβολοσειρές

Στη Gleam οι συμβολοσειρές γράφονται με διπλά εισαγωγικά.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Σχόλια κώδικα

Τα σχόλια μπορούν να χρησιμοποιηθούν για να αφήσεις σημειώσεις σε άλλους προγραμματιστές που διαβάζουν τον πηγαίο κώδικα. Τα σχόλια στη Gleam είναι μεμονωμένες γραμμές, πριν από τις οποίες μπαίνει το `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
