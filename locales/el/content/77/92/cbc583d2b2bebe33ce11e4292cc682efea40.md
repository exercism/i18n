# Οδηγίες

Διαχειρίζεσαι ένα διαδικτυακό κατάστημα μόδας. Η μεγάλη ετήσια έκπτωση πλησιάζει, οπότε θέλεις να φτιάξεις κάποιες λειτουργίες που θα σε βοηθήσουν να κάνεις απογραφή του αποθέματός σου και να βεβαιωθείς ότι είσαι έτοιμος.

Κάθε μεμονωμένο είδος του αποθέματος αναπαρίσταται από ένα hash, και ολόκληρο το απόθεμα είναι ένας πίνακας από αυτά τα hash.

```ruby
[
  {
    name: "White Shirt",
    price: 40,
    quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}
  },
  { ... }
]
```

## 1. Επίστρεψε μια λίστα με τα ονόματα των ειδών

Υλοποίησε τη μέθοδο `BoutiqueInventory.item_names`, η οποία πρέπει να επιστρέφει μια λίστα με τα ονόματα των ειδών σε αλφαβητική σειρά.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).item_names

#=> ["Bamboo Socks Cats", "Black Short Skirt", "Maxi Brown Dress", "Red Short Skirt"]
```

## 2. Επίστρεψε τα είδη που είναι φθηνά

Υλοποίησε τη μέθοδο `BoutiqueInventory.cheap` που πρέπει να επιστρέφει όποια είδη κοστίζουν λιγότερο από $30.

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).cheap

# => [
#      {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
#      {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
#    ]
```

## 3. Επίστρεψε τα είδη που έχουν εξαντληθεί

Υλοποίησε τη μέθοδο `BoutiqueInventory.out_of_stock` που πρέπει να επιστρέφει όποια είδη δεν έχουν απόθεμα (όπου το `quantity_by_size` είναι κενό).

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).out_of_stock

#=> [{price: 50.00, name: "Red Short Skirt", quantity_by_size: {}}]
```

## 4. Επίστρεψε το απόθεμα ενός μεμονωμένου είδους

Υλοποίησε τη μέθοδο `BoutiqueInventory.stock_for_item(name)` για να επιστρέφει το απόθεμα ενός είδους με βάση το όνομά του:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).stock_for_item("Black Short Skirt")

#=> {s: 1, xl: 4}
```

## 5. Επίστρεψε το συνολικό απόθεμα

Υλοποίησε τη μέθοδο `BoutiqueInventory.total_stock` για να υπολογίσεις το συνολικό πλήθος των ειδών στην αποθήκη σου:

```ruby
BoutiqueInventory.new([
  {price: 65.00, name: "Maxi Brown Dress", quantity_by_size: {s: 3, m: 7, l: 8, xl: 4}},
  {price: 50.00, name: "Red Short Skirt", quantity_by_size: {}},
  {price: 29.99, name: "Black Short Skirt", quantity_by_size: {s: 1, xl: 4}},
  {price: 20.00, name: "Bamboo Socks Cats", quantity_by_size: {s: 7, m: 2}}
]).total_stock

#=> 36
```
