# Προσθήκη στις οδηγίες

## Υλοποίηση

Μπορείς να χρησιμοποιήσεις το `collect(1:10)` ως έναν γρήγορο τρόπο για να δημιουργήσεις μια συλλογή, αλλά θυμήσου ότι κάτω από το καπό η συλλογή επιστρέφει έναν πίνακα, οπότε μπορείς απλώς να δημιουργήσεις έναν πίνακα ρητά κάνοντας `my_array = [1, 2, 3, 4, 5]`.
