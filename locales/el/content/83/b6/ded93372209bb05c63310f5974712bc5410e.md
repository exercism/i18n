# Παράρτημα οδηγιών

## Λέξεις

Όρισε μια πλειάδα `school` για να κρατάς τη λίστα μαθητών. Πώς θα αποθηκεύσεις τους μαθητές μέσα της είναι δικό σου θέμα. Στη συνέχεια, υλοποίησε τις παρακάτω λέξεις.

- `<school> ( -- school )`: δημιουργεί ένα κενό school.
- `add-student ( school name grade -- ? )`: προσθέτει `name` σε `grade`. Επιστρέφει `t` σε περίπτωση επιτυχίας, ή `f` αν το `name` έχει ήδη προστεθεί (σε αυτήν ή σε οποιαδήποτε άλλη τάξη), οπότε η λίστα μαθητών παραμένει αμετάβλητη.
- `roster ( school -- names )`: όλοι οι μαθητές, ταξινομημένοι κατά τάξη και έπειτα αλφαβητικά κατά όνομα.
- `grade ( school n -- names )`: οι μαθητές της τάξης `n`, ταξινομημένοι αλφαβητικά κατά όνομα.
