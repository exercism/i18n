# Σχετικά

Ο κλιμακωτός κώδικας βασίζεται σε σημαίες που θέτουν διάφορες εντολές για να διακλαδωθεί ανάλογα με μια συγκεκριμένη συνθήκη.
Οι συσκευασμένες τιμές, ωστόσο, αντιπροσωπεύουν όχι μία αλλά πολλές τιμές παράλληλα.
Μια μεμονωμένη συνθήκη μπορεί να αποτύχει για μία λωρίδα και να ισχύσει για μια άλλη.

Γι' αυτό ο κώδικας SIMD είναι [χωρίς διακλαδώσεις][branchless-code] εξ ορισμού.

Αντί να βασίζονται σε σημαίες, οι συσκευασμένες συγκρίσεις συνήθως παράγουν μια **μάσκα** στον τελεστέο προορισμού.
Για κάθε λωρίδα, η σύγκριση γεμίζει ολόκληρη τη λωρίδα με άσσους όταν είναι αληθής και με μηδενικά όταν είναι ψευδής.
Αν τη διαβάσεις ως προσημασμένο ακέραιο, μια αληθής λωρίδα είναι `-1` και μια ψευδής λωρίδα είναι `0`.

Αυτή η μάσκα μπορεί στη συνέχεια να συνδυαστεί με [πράξεις bitwise][simd-bitwise] για να φιλτράρει συγκεκριμένες λωρίδες.

## Συσκευασμένες συγκρίσεις

Μια κλιμακωτή `cmp` είναι γενική με την έννοια ότι χρησιμοποιείται για να θέσει διάφορες σημαίες ταυτόχρονα.
Μια άλλη εντολή μπορεί στη συνέχεια να καταναλώσει αυτές τις σημαίες είτε για να διακλαδωθεί είτε για να εκτελέσει υπολογισμούς.

Ωστόσο, επειδή μια συσκευασμένη σύγκριση και ελέγχει μια συνθήκη και υπολογίζει μια μάσκα, δεν είναι γενική.
Η σύγκριση πρέπει να δεχθεί την ακριβή συνθήκη που ελέγχεται.

Υπάρχουν δύο τρόποι να γίνει αυτό:

- Οι συγκρίσεις ακεραίων δέχονται τη συνθήκη ως επίθημα: `eq` για ισότητα και `gt` για "μεγαλύτερο από".
  Άλλες παραλλαγές κατασκευάζονται συνδυάζοντας το αποτέλεσμα μιας από αυτές.
- Οι συγκρίσεις κινητής υποδιαστολής δέχονται τη συνθήκη κωδικοποιημένη σε έναν άμεσο τελεστέο.
  Διαφορετικές τιμές αυτού του άμεσου τελεστέου αντιστοιχούν σε διαφορετικές συνθήκες που ελέγχονται.

Εκτός από τη χρήση ενός συγκεκριμένου επιθήματος συνθήκης στις συγκρίσεις ακεραίων, η σύνταξη ακολουθεί την ίδια δομή που έχουμε ήδη δει:

- Για ακεραίους, `p` + `cmp` + συνθήκη + μέγεθος (`b`, `w`, `d` ή `q`).
- Για αριθμούς κινητής υποδιαστολής, `cmp` + `p` + μέγεθος (`s` ή `d`).
  Η συνθήκη περνιέται σε έναν άμεσο τελεστέο ως επιπλέον τελεστέος.

### Συγκρίσεις ακεραίων

Όπως αναφέρθηκε, υπάρχουν συγκρίσεις ακεραίων μόνο για ισότητα και για "μεγαλύτερο από":

| εντολή                                     | περιγραφή                                          |
|--------------------------------------------|----------------------------------------------------|
| `pcmpeqb`, `pcmpeqw`, `pcmpeqd`, `pcmpeqq` | ισότητα ανά λωρίδα                                 |
| `pcmpgtb`, `pcmpgtw`, `pcmpgtd`, `pcmpgtq` | **προσημασμένο** "μεγαλύτερο από" ανά λωρίδα       |

```x86asm
movdqa  xmm0, [rel scores]
pcmpgtd xmm0, [rel threshold] ; lane i = 0xFFFFFFFF (-1) if scores[i] > threshold[i], else 0
```

Για να δημιουργήσεις μια σύγκριση "μικρότερο από", χρησιμοποίησε την `gt` με τους τελεστέους αντεστραμμένους: `a < b` == `b > a`.

Σημείωσε ότι η σύγκριση είναι **προσημασμένη**.
Για να εκτελέσεις μια σύγκριση χωρίς πρόσημο, αντιστρέψε το υψηλότερο bit και των δύο τελεστέων.
Αυτό μπορεί να γίνει με ένα XOR με μια μάσκα όπου μόνο το υψηλότερο bit είναι τεθειμένο.

~~~~exercism/note
Δύο βολικά ιδιώματα είναι:

1. Το XOR ενός καταχωρητή με τον εαυτό του για να παραχθούν όλα μηδενικά.
2. Η σύγκριση ενός καταχωρητή με τον εαυτό του για να παραχθούν όλοι άσσοι.

Για παράδειγμα:

```x86asm
pxor    xmm4, xmm4 ; xmm4 = all zeros
pcmpeqd xmm7, xmm7 ; xmm7 = all ones
```

Τα όλα-μηδενικά και τα όλα-άσσοι είναι συνηθισμένες μάσκες που κωδικοποιούν το "ψευδές παντού" και το "αληθές παντού", αντίστοιχα.
Μπορούν επίσης να χρησιμοποιηθούν για να αναπαραστήσουν συσκευασμένο `0` ή συσκευασμένο `-1`, που είναι συνηθισμένες τιμές-φρουροί.
Για παράδειγμα, το NUL που σηματοδοτεί το τέλος μιας συμβολοσειράς είναι ένα `0`.
~~~~

### Συγκρίσεις κινητής υποδιαστολής

Οι λωρίδες κινητής υποδιαστολής χρησιμοποιούν διαφορετική μορφή: μία εντολή, την `cmpps` (και την `cmppd` για λωρίδες 64 bit), με τη συνθήκη ως άμεσο τελεστέο:

```x86asm
movaps xmm0, [rel readings]
cmpps  xmm0, [rel limits], 1 ; condition 1 is "less than": lane i = all ones if readings[i] < limits[i]
```

Το NASM έχει επίσης ψευδοεντολές που αντιστοιχούν στον σωστό άμεσο τελεστέο και είναι πιο εύκολες στην απομνημόνευση.
Σε όλα τα παρακάτω, το `x` στο `px` μπορεί να είναι `s` (αριθμοί κινητής υποδιαστολής 32 bit) ή `d` (64 bit):

| ψευδοεντολή  | άμεσος τελεστέος | σύγκριση                 |
|--------------|------------------|--------------------------|
| `cmpeqpx`    | 0                | a == b                   |
| `cmpltpx`    | 1                | a <  b                   |
| `cmplepx`    | 2                | a <= b                   |
| `cmpunordpx` | 3                | το a είναι NaN ή το b είναι NaN |
| `cmpneqpx`   | 4                | a != b                   |
| `cmpnltpx`   | 5                | a >= b                   |
| `cmpnlepx`   | 6                | a >  b                   |
| `cmpordpx`   | 7                | ούτε το a ούτε το b είναι NaN |

~~~~exercism/caution
Το NaN συγκρίνεται ως μη διατεταγμένο: δεν είναι ούτε μικρότερο ούτε ίσο ούτε μεγαλύτερο από τίποτα, ούτε από τον εαυτό του.
Τα διατεταγμένα κατηγορήματα, όπως η `cmpltps`, δίνουν ψευδές όταν οποιοσδήποτε από τους τελεστέους είναι NaN, ενώ τα μη διατεταγμένα κατηγορήματα δίνουν αληθές.
Γι' αυτό υπάρχουν οι `cmpordps` και `cmpunordps`, για να ελέγχουν ρητά για NaN.
~~~~

## Επιλογή με μάσκα

Μια μάσκα κωδικοποιεί το αποτέλεσμα μιας συνθήκης.
Μπορεί στη συνέχεια να χρησιμοποιηθεί για να επιλέγει, λωρίδα προς λωρίδα, ανάμεσα σε δύο σύνολα τιμών σύμφωνα με αυτή τη συνθήκη.
Παίρνουμε τη λωρίδα από τη μία τιμή όπου η μάσκα είναι αληθής και από την άλλη όπου είναι ψευδής:

```x86asm
; result = (a AND mask) OR (b AND NOT mask)
movdqa xmm2, xmm0  ; xmm0 holds the mask, keep a copy
pand   xmm2, xmm3  ; xmm2 = a AND mask: lanes of a where mask is true
pandn  xmm0, xmm4  ; xmm0 = NOT mask AND b: lanes of b where mask is false
por    xmm2, xmm0  ; combine the two halves
```

Αυτό το μοτίβο είναι η συσκευασμένη μορφή της επιλογής χωρίς διακλαδώσεις.
Κάθε λωρίδα υπολογίζεται και μόνο η μάσκα αποφασίζει ποια τιμή επιβιώνει, χωρίς καμία `jcc` πουθενά.

## Ειδικές εντολές blend

Υπάρχουν εντολές που εκτελούν απευθείας αυτή την ίδια επιλογή, διαβάζοντας ένα bit ανά στοιχείο από έναν καταχωρητή μάσκας.
Ονομάζονται εντολές **blend**:

| εντολή      | στοιχείο    | πηγή μάσκας     |
|-------------|-------------|-----------------|
| `pblendvb`  | byte        | σιωπηρός `xmm0` |
| `blendvps`  | λωρίδα 32 bit | σιωπηρός `xmm0` |
| `blendvpd`  | λωρίδα 64 bit | σιωπηρός `xmm0` |

Σημείωσε ότι η πρώτη εντολή ακολουθεί τη σύνταξη των ακεραίων, ενώ οι άλλες δύο ακολουθούν τη σύνταξη των αριθμών κινητής υποδιαστολής.
Ωστόσο, επειδή αυτές οι εντολές απλώς επιλέγουν ακατέργαστα byte, οποιαδήποτε από αυτές μπορεί να χρησιμοποιηθεί και με ακεραίους και με αριθμούς κινητής υποδιαστολής.

Για κάθε στοιχείο, η εντολή blend κρατά τον προορισμό όταν το υψηλότερο bit του αντίστοιχου στοιχείου της μάσκας είναι μηδενισμένο, και παίρνει την πηγή όταν είναι τεθειμένο.
Μόνο αυτό το **υψηλότερο bit** εξετάζεται, κάτι που μια μάσκα σύγκρισης ικανοποιεί, αφού οι λωρίδες της είναι όλες άσσοι ή όλα μηδενικά.
Ο καταχωρητής μάσκας είναι πάντα ο `xmm0`, ο οποίος είναι σιωπηρός:

```x86asm
movaps   xmm0, [rel mask]  ; the selecting mask must be in xmm0
movaps   xmm1, [rel b]     ; destination: kept where the mask bit is clear
blendvps xmm1, [rel a]     ; source: taken where the mask bit is set
```

Είναι επίσης δυνατό να χρησιμοποιήσεις την `pblendvb` για να επιλέξεις λωρίδες από μια μάσκα σύγκρισης για οποιοδήποτε άλλο μέγεθος.
Επειδή όλα τα byte σε μια αληθή λωρίδα είναι άσσοι, η `pblendvb` τα επιλέγει όλα.

~~~~exercism/note
Αυτές οι εντολές προσθέτουν όλες ένα `v` μετά την πράξη που εκτελείται (`blend`).
Αυτό το `v` σημαίνει _variable_, επειδή η επιλογή δεν είναι στατική: εξαρτάται από έναν καταχωρητή.

Υπάρχουν επίσης παραλλαγές χωρίς `v`, που επιλέγουν σύμφωνα με έναν άμεσο τελεστέο.
Ακολουθούν το ίδιο μοτίβο, επιλέγοντας τη λωρίδα `i` αν το bit `i` του άμεσου τελεστέου είναι τεθειμένο.
~~~~

## Από μια μάσκα πίσω στον κλιμακωτό κώδικα

Αν και ισχυρός, ο κώδικας SIMD στερείται μεγάλου μέρους της ευελιξίας του κλιμακωτού κώδικα.
Σε πολλές περιπτώσεις, είναι απαραίτητο να μεταβείς από έναν συσκευασμένο καταχωρητή πίσω στον κόσμο των κλιμακωτών εντολών.

Η οικογένεια εντολών `movmsk` λειτουργεί ως γέφυρα ανάμεσα στους δύο κόσμους.
Αυτές οι εντολές εξάγουν το **υψηλότερο bit** κάθε λωρίδας σε έναν καταχωρητή γενικού σκοπού:

| εντολή      | συλλέγει                          | πλάτος αποτελέσματος |
|-------------|-----------------------------------|----------------------|
| `pmovmskb`  | το υψηλότερο bit καθενός από 16 byte | 16 bit             |
| `movmskps`  | το υψηλότερο bit καθενός από 4 dwords | 4 bit             |
| `movmskpd`  | το υψηλότερο bit καθενός από 2 qwords | 2 bit             |

Αν χρησιμοποιηθεί μετά από μια σύγκριση, κάθε τεθειμένο bit αντιπροσωπεύει μια "αληθή" λωρίδα και κάθε μηδενισμένο bit, μια "ψευδή" λωρίδα.
Αυτό το αποτέλεσμα μπορεί στη συνέχεια να υποστεί επεξεργασία όπως συνήθως με κλιμακωτές εντολές.
Για παράδειγμα, μια `popcnt` μετρά τον αριθμό των αντιστοιχιών και η `tzcnt` βρίσκει την πρώτη.

Ο καταχωρητής γενικού σκοπού μπορεί να έχει πλάτος 32 ή 64 bit.

## Έλεγχος ολόκληρου διανύσματος

Υπάρχει επίσης μια συσκευασμένη παραλλαγή της κλιμακωτής εντολής `test`: η `ptest`.

Μοιάζει με το κλιμακωτό αντίστοιχό της στο ότι εκτελεί μια πράξη AND ανάμεσα σε δύο τελεστέους, χωρίς να τους τροποποιεί.
Σε αντίθεση με την `test`, η `ptest` εκτελεί επίσης μια πράξη ANDN, κάνοντας άρνηση στον πρώτο τελεστέο.

Έτσι, η `ptest` μπορεί να θεωρηθεί ως μια μη καταστρεπτική εκδοχή των `pand` και `pandn` που θέτει σημαίες ανάλογα με το αποτέλεσμα.
Με τρόπο παρόμοιο με αυτές τις δύο εντολές, η `ptest` αντιμετωπίζει ολόκληρο τον καταχωρητή SIMD ως μία μόνο λωρίδα και έτσι δεν παίρνει πρόθεμα μεγέθους.

Αν το αποτέλεσμα μιας πράξης AND είναι `0`, τίθεται το `ZF`, και αν η πράξη ANDN έχει αποτέλεσμα `0`, αυτό που τίθεται είναι το `CF`.
Αυτό σημαίνει ότι η `ptest` μπορεί να χρησιμοποιηθεί για να ελέγξεις και μια μάσκα όλων-άσσων και μια μάσκα όλων-μηδενικών:

1. Χρησιμοποιώντας την `ptest` σε έναν καταχωρητή με τον εαυτό του, το `ZF` τίθεται μόνο αν ο καταχωρητής είναι όλα μηδενικά.
   Αυτό μιμείται το συνηθισμένο κλιμακωτό ιδίωμα της χρήσης της `test` σε έναν καταχωρητή με τον εαυτό του για έλεγχο του `0`.
2. Χρησιμοποιώντας την `ptest` σε έναν καταχωρητή με μια μάσκα όλων-άσσων, το `CF` τίθεται μόνο αν ο καταχωρητής είναι όλοι άσσοι.
   Επίσης, θέτει το `ZF` μόνο αν ο καταχωρητής είναι όλα μηδενικά, καθιστώντας δυνατό τον έλεγχο και των δύο μασκών ταυτόχρονα.

```x86asm
pxor  xmm0, xmm0   ; xmm0 = all zeros
ptest xmm0, xmm0   ; xmm0 AND xmm0 == 0 => ZF is set
                   ; (NOT xmm0) AND xmm0 == 0 => CF is set

; Using ptest on a register with itself makes ZF set only if the register is all zeros

pcmpeqb xmm1, xmm1 ; xmm1 = all ones
ptest   xmm0, xmm1 ; xmm0 AND xmm1 == 0 => ZF is set
                   ; (NOT xmm0) AND xmm1 != 0 => CF is cleared

pcmpeqb xmm3, xmm3 ; xmm3 = all ones
ptest   xmm3, xmm1 ; xmm3 AND xmm1 != 0 => ZF is cleared
                   ; (NOT xmm3) AND xmm1 == 0 => CF is set

mov eax, -1
movd  xmm2, eax    ; xmm2 = {-1, 0, 0, 0}
ptest xmm2, xmm1   ; xmm2 AND xmm1 != 0 => ZF is cleared
                   ; (NOT xmm2) AND xmm1 != 0 => CF is cleared

; After using ptest on a register with an all-ones mask, ZF is only set if the register is all zeros.
; CF may be:
; 1. cleared, if the register is all zeros or is partially set
; 2. set, if the register is all ones
```

Το αποτέλεσμα μιας `ptest` μπορεί να χρησιμοποιηθεί για διακλάδωση ή σε εντολές χωρίς διακλαδώσεις, όπως οι `setcc` ή `cmovcc`, όπως συνήθως.

## AVX και πέρα από αυτά

Το AVX δίνει στις συγκρίσεις, στις εντολές blend και στην `ptest` μια μορφή με πρόθεμα `v` σε φαρδύτερους καταχωρητές.

Η εντολή blend με μεταβλητή μάσκα αλλάζει μορφή.
Η μάσκα δεν είναι πλέον ο σιωπηρός `xmm0` αλλά ένας ρητός τέταρτος τελεστέος:

```x86asm
vpcmpgtd  ymm0, ymm1, ymm2       ; eight 32-bit lanes compared at once
vblendvps ymm0, ymm1, ymm2, ymm3 ; ymm3 is the mask, named explicitly
vptest    ymm0, ymm0
```

Οι επεκτάσεις AVX-512 αλλάζουν το μοντέλο πιο βαθιά.

Πρώτον, προσθέτουν μια νέα κλάση καταχωρητών SIMD των 64 byte, που ονομάζονται `zmm`.
Επεκτείνουν τους αντίστοιχους καταχωρητές `ymm`, με τον ίδιο τρόπο που οι καταχωρητές `ymm` επεκτείνουν τους καταχωρητές `xmm`.

Δεύτερον, αυτές οι επεκτάσεις δημιουργούν επίσης μια ολόκληρη νέα κλάση **καταχωρητών opmask**, από `k0` έως `k7`, των οποίων ο κύριος σκοπός είναι να χρησιμεύουν ως μάσκες για εντολές SIMD.
Οι συγκρίσεις δε γράφουν πλέον σε διανύσματα, αλλά σε έναν από αυτούς τους νέους καταχωρητές.
Μπορούν επίσης να χρησιμοποιηθούν απευθείας σε πολλές εντολές ως κατηγορήματα με μάσκα εγγραφής `{k}`, επιλέγοντας λωρίδες _απευθείας_:

```x86asm
vpcmpgtd  k1, zmm0, zmm1         ; k1 gets one bit per lane
vmovdqa32 zmm2{k1}, zmm3         ; copy only the lanes whose bits are set in k1
```

Τέλος, υπάρχουν νέες εντολές για να λειτουργούν σε αυτούς τους νέους καταχωρητές, συμπεριλαμβανομένης της αντιγραφής τους σε καταχωρητές γενικού σκοπού.
Αυτό καθιστά τις εντολές `movmsk` περιττές και δεν υπάρχει υποστήριξη για εντολές `movmsk` σε καταχωρητές `zmm`.

Αυτές οι επεκτάσεις αναφέρονται για λόγους πληρότητας.
Οι ασκήσεις σε αυτό το track χρησιμοποιούν τις μορφές SSE.
