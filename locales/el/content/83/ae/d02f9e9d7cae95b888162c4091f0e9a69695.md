# Σχετικά

Τα [symbols][symbols] είναι ονομασμένα αναγνωριστικά που μπορούν να χρησιμοποιηθούν για να αναφέρονται σε μια τιμή.
Τα symbols δημιουργούνται μέσω ενός κυριολεκτικού symbol, βάζοντας δηλαδή μπροστά από ένα όνομα τον χαρακτήρα `:`, π.χ. `:foo`.
Μπορούν επίσης να γραφτούν και με εισαγωγικά, π.χ. `:"foo"`, κάτι που επιτρέπει, για παράδειγμα, κενά μέσα στο όνομα.

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

Τα symbols χρησιμοποιούνται σε πολλά σημεία της γλώσσας, μεταξύ άλλων ως κλειδιά σε hashes, για να αναπαριστούν ονόματα μεθόδων και ονόματα μεταβλητών.

## Αναγνωριστικό

Αυτό που κάνει τα symbols διαφορετικά από τις συμβολοσειρές είναι ότι είναι αναγνωριστικά και δεν αναπαριστούν δεδομένα ή κείμενο.
Αυτό σημαίνει ότι δύο symbols με το ίδιο όνομα είναι πάντα το ίδιο αντικείμενο.

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## Τροποποίηση symbols

Τα symbols είναι αμετάβλητα, που σημαίνει ότι δε μπορούν να τροποποιηθούν.
Αυτό σημαίνει ότι όταν "τροποποιείς" ένα symbol, στην πραγματικότητα δημιουργείς ένα νέο symbol.
Υπάρχουν μερικές μέθοδοι που μπορούν να χρησιμοποιηθούν για τον χειρισμό symbols και όλες επιστρέφουν νέα symbols.
Όλες οι μέθοδοι βρίσκονται στο [Symbol API][symbols-api].

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

Το πλεονέκτημα του ότι τα symbols είναι αμετάβλητα είναι ότι είναι πιο αποδοτικά ως προς τη μνήμη από τις συμβολοσειρές, αλλά και ασφαλέστερα στη χρήση ως αναγνωριστικά.

## Μετατροπή

Τα symbols μπορούν να μετατραπούν σε συμβολοσειρές και αντίστροφα.
Αυτό μπορεί να φανεί χρήσιμο όταν θέλεις να τροποποιήσεις ένα symbol ή όταν θέλεις να χρησιμοποιήσεις ένα symbol ως συμβολοσειρά.
Για να παρουσιάσεις μια συμβολοσειρά ως symbol, μπορείς να χρησιμοποιήσεις τη μέθοδο `String#to_sym` και για το αντίθετο, τη μέθοδο `Symbol#to_s`.
Επειδή τα symbols έχουν περιορισμένο σύνολο μεθόδων, μπορεί να φανεί χρήσιμο να μετατρέψεις ένα symbol σε συμβολοσειρά για να χρησιμοποιήσεις πάνω του μεθόδους συμβολοσειρών, αν χρειάζεσαι ένα νέο symbol.

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
