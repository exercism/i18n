# Εισαγωγή στις συνθήκες

## Τι θεωρείται αληθές στη Bash

Η Bash δεν έχει την έννοια των τιμών Boolean (λογική τιμή).
Υπάρχουν συμβολοσειρές και αριθμοί, καθώς και πίνακες συμβολοσειρών ή αριθμών.
Πώς λοιπόν οι εντολές συνθηκών χειρίζονται το αληθές και το ψευδές;

## Κατάσταση εξόδου

Οι εντολές παράγουν μια _κατάσταση εξόδου_ όταν τερματίζουν.
Η κατάσταση εξόδου είναι ένας ακέραιος από το 0 έως το 255, συμπεριλαμβανομένων των άκρων.
Η Bash θεωρεί ότι μια κατάσταση εξόδου με τιμή **μηδέν** αντιπροσωπεύει _επιτυχία_.
Κάθε άλλη κατάσταση εξόδου αντιπροσωπεύει _αποτυχία_.

Αυτό ισχύει για όλες τις εντολές, συμπεριλαμβανομένων των ενσωματωμένων εντολών της Bash, των λέξεων-κλειδιών και των συναρτήσεων.

## Η εντολή "if"

Η βασική σύνταξη της εντολής `if` είναι

```bash
if CONDITIONAL_COMMANDS; then TRUE_COMMANDS; else FALSE_COMMANDS; fi
```

Ξεκινά με `if`· οι εντολές συνθήκης χωρίζονται από τις εντολές "επιτυχίας" με το `then`· και τερματίζεται με το `fi`.
Η ρήτρα `else` είναι προαιρετική.

Οι CONDITIONAL_COMMANDS μπορεί να είναι μία μόνο εντολή ή μια [λίστα εντολών][command-list].

Οι CONDITIONAL_COMMANDS εκτελούνται και

* αν η κατάσταση εξόδου είναι μηδέν (επιτυχία), τότε εκτελούνται οι TRUE_COMMANDS.
* αν η κατάσταση εξόδου είναι μη μηδενική (αποτυχία), τότε εκτελούνται οι FALSE_COMMANDS, εφόσον υπάρχουν.

Διαδοχικές διακλαδώσεις μπορούν να δοθούν με το `elif`
```bash
if CONDITIONAL_COMMANDS
then TRUE_COMMANDS
elif CONDITIONAL_COMMANDS_2
then TRUE_COMMANDS_2
# more elif branches ...
else FALSE_COMMANDS
fi
```

Πρέπει να υπάρχει ένα ερωτηματικό ή μια αλλαγή γραμμής πριν από τις λέξεις `then`, `elif`, `else` και `fi`.

Για να το τονίσουμε: αυτό που ελέγχει τη ροή είναι η **κατάσταση εξόδου** των εντολών συνθήκης.
Για παράδειγμα, η `grep` επιστρέφει 0 αν βρεθεί αντιστοιχία και 1 αν δεν βρεθεί.
Η επιλογή `-q` καταστέλλει την έξοδο, παράγοντας μόνο την κατάσταση εξόδου.

```bash
if grep -q "my pattern" my_file; then echo "the pattern is found in the file"; fi
```

## Οι εντολές "[" και "test"

Δεν υπάρχει ειδική σύνταξη γύρω από τις CONDITIONAL_COMMANDS.
Ίσως έχεις συνηθίσει να βλέπεις εντολές `if` που μοιάζουν κάπως έτσι:

```if
if [ "$password" = "secure" ]; then
    echo "Welcome!"
fi
```

Το `[` δεν είναι ειδική σύνταξη.
Είναι μια _εντολή_ που αξιολογεί την έκφραση συνθήκης και τερματίζει με κατάσταση επιτυχίας/αποτυχίας.
Όπως με όλες τις εντολές, το κενό διάστημα είναι **απαραίτητο** μεταξύ αυτής και των ορισμάτων της.

Το `[` είναι στην πραγματικότητα συνώνυμο της εντολής `test`.
Είναι ακριβώς το ίδιο, με τη διαφορά ότι το τελευταίο όρισμα του `[` _πρέπει_ να είναι `]`.

### Εκφράσεις συνθηκών

Μέσα στα `[` και `]` γράφεις μια έκφραση συνθήκης.
Μερικές τυπικές εκφράσεις συνθηκών είναι οι εξής:

```bash
[ -f "$filename" ]             # file operations
[ "$string1" = "$string2" ]    # string comparisons
[ "$num1" -eq "$num2" ]        # arithmetic comparisons
```

Υπάρχουν πολλές ακόμη διαθέσιμες πράξεις· αναφέρονται στην ενότητα [Bash Conditional Expressions][cond-expr] του εγχειριδίου.

~~~~exercism/note
Στα παραπάνω παραδείγματα, πρόσεξε ότι όλες οι μεταβλητές είναι μέσα σε εισαγωγικά.
Οι εντολές `test` και `[` είναι απλές εντολές, όπου τα ορίσματα υπόκεινται σε διαχωρισμό λέξεων και επέκταση ονομάτων αρχείων όπως σε κάθε άλλη εντολή.

Αυτό αξίζει να το επισημάνουμε, γιατί οι εκφράσεις συνθηκών αξιολογούνται διαφορετικά ανάλογα με το _πόσα ορίσματα_ δίνεις:

* 0 ορίσματα: η κατάσταση εξόδου είναι μη μηδενική (αποτυχία)
* 1 όρισμα: η κατάσταση εξόδου είναι μηδέν (επιτυχία) αν το όρισμα δεν είναι κενό, μη μηδενική αν είναι κενό.
* 2 ορίσματα: το πρώτο όρισμα πρέπει να είναι μοναδιαίος τελεστής (όπως `[ -z "$name" ]`), ή ένα `!` (που αντιστρέφει την κατάσταση του ελέγχου με 1 όρισμα)
* και [περισσότερα][test].

Μπορεί να πάρεις απροσδόκητα αποτελέσματα αν ξεχάσεις τα εισαγωγικά:

```bash
str=""

# this prints "empty"
if [ -n "$str" ]; then echo "not empty"; else echo "empty"; fi

# leaving the variable unquoted results in incorrect "not empty" output
if [ -n $str ]; then echo "not empty"; else echo "empty"; fi
```

[test]: https://www.gnu.org/software/bash/manual/bash.html#index-test
~~~~

## Η λέξη-κλειδί "[["

Η [`[[...]]` κατασκευή συνθήκης][cond-construct] δεν είναι _εντολή_, είναι **λέξη-κλειδί**.
Αυτό σημαίνει ότι, αν και αντιμετωπίζεται όπως κάθε άλλη εντολή, έχει ειδικούς κανόνες ανάλυσης.
Το ιδιαίτερο με το `[[` είναι ότι οι μεταβλητές που επεκτείνονται μέσα του **δεν** υπόκεινται σε διαχωρισμό λέξεων ή επέκταση ονομάτων αρχείων.
Αυτό σημαίνει ότι αυτή η εντολή συμπεριφέρεται όπως περιμένεις, ακόμη και χωρίς εισαγωγικά.

```bash
if [[ -n $str ]]; then echo "not empty"; else echo "empty"; fi
```

Το `[[` υποστηρίζει όλες τις εκφράσεις συνθηκών που μπορούν να χειριστούν τα `test` και `[`.
Επιπλέον, το `[[` παρέχει

* τον τελεστή αντιστοίχισης κανονικών εκφράσεων `=~`,
* τα `==` και `!=` ως τελεστή αντιστοίχισης μοτίβων glob,
* τα `&&` και `||` ως λογικούς τελεστές (ειδικός κανόνας ανάλυσης),
* τα `<` και `>` ως "γυμνούς" τελεστές σύγκρισης συμβολοσειρών (ειδικός κανόνας ανάλυσης: επειδή είναι σύμβολα ανακατεύθυνσης, στο `[` πρέπει να προστατευτούν με χαρακτήρα διαφυγής).

Επικρατεί η άποψη ότι αυτά τα ειδικά χαρακτηριστικά προσφέρουν τόσα πολλά που το `[[` θα έπρεπε να χρησιμοποιείται αποκλειστικά.
(Για παράδειγμα, ο [Google Shell Style Guide][goog-test].)

## Η εντολή "case"

Το [`case`][case] είναι μια ακόμη εντολή ελέγχου ροής.
Μοιάζει με την εντολή "switch" σε άλλες γλώσσες.

```bash
case WORD in [PATTERN [| PATTERN]...) COMMANDS ;;]... esac
```

Το WORD αντιστοιχίζεται με κάθε PATTERN.
Όταν ένα ταιριάζει, εκτελούνται οι COMMANDS.

```bash
read -p "Guess the secret word: " word
case "$word" in
    secret) echo "Yes, you guessed it!" ;;
    ??????) echo "That's the right number of letters." ;;
    s*)     echo "You guessed the first letter." ;;
    *)      echo "Not even close! Try again." ;;
esac
```

Κάθε ρήτρα COMMANDS πρέπει να τελειώνει με **δύο** ερωτηματικά, `;;`.

   Δες [το εγχειρίδιο][case] για λεπτομέρειες.
