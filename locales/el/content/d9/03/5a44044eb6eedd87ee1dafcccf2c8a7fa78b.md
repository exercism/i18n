# Οδηγίες

Ο σύλλογος της γειτονιάς σου σου ζητά να διαχειριστείς τις εγγραφές στα παρτέρια του κήπου. Η κατάσταση αποθηκεύεται σε δύο δυναμικές μεταβλητές:

- `registrations` — ένα διάνυσμα από πλειάδες `plot` που είναι αυτή τη στιγμή ανατεθειμένες σε κάποιο άτομο.
- `next-id` — ο ακέραιος που θα χρησιμοποιηθεί για την επόμενη εγγραφή.

Η πλειάδα `plot` έχει δύο θέσεις:

| θέση            | τύπος     |
| --------------- | -------- |
| `id`            | ακέραιος |
| `registered-to` | συμβολοσειρά |

## 1. Άνοιξε τον κήπο και εμφάνισε τις εγγραφές του

Όρισε τη συνάρτηση `open-garden` ώστε να αρχικοποιεί τις δυναμικές μεταβλητές: ένα κενό διάνυσμα για το `registrations` και `1` για το `next-id`. Στη συνέχεια, όρισε τη συνάρτηση `list-registrations` ώστε να επιστρέφει το τρέχον διάνυσμα με τις πλειάδες `plot`.

```factor
open-garden
list-registrations .
! => V{ }
```

## 2. Καταχώρισε ένα παρτέρι

Όρισε τη συνάρτηση `register` ώστε να παίρνει ένα όνομα από τη στοίβα, να δημιουργεί μια νέα πλειάδα `plot` με το επόμενο διαθέσιμο id, να την προσθέτει στο διάνυσμα `registrations`, να αυξάνει το `next-id` κατά ένα και να επιστρέφει τη νέα πλειάδα `plot`.

```factor
open-garden
"Emma Balan" register .
! => T{ plot { id 1 } { registered-to "Emma Balan" } }

list-registrations .
! => V{ T{ plot { id 1 } { registered-to "Emma Balan" } } }
```

Τα id των παρτεριών πρέπει να είναι μοναδικά και να αυξάνονται ακόμη και μετά από μια ελευθέρωση. Το `next-id` δεν πρέπει ποτέ να ξαναχρησιμοποιεί μια τιμή.

## 3. Ελευθέρωσε ένα παρτέρι

Όρισε τη συνάρτηση `release` ώστε να παίρνει ένα id και να αφαιρεί την αντίστοιχη καταχώριση από το `registrations`. Η ελευθέρωση ενός άγνωστου id δεν κάνει τίποτα.

```factor
open-garden
"Emma" register drop
1 release
list-registrations .
! => V{ }
```

## 4. Πάρε ένα καταχωρισμένο παρτέρι

Όρισε τη συνάρτηση `get-registration` ώστε να παίρνει ένα id και να επιστρέφει την αντίστοιχη πλειάδα `plot` ή το σύμβολο `not-found` αν κανένα παρτέρι δεν έχει αυτό το id.

```factor
open-garden
"Emma" register drop
1 get-registration .
! => T{ plot { id 1 } { registered-to "Emma" } }

7 get-registration .
! => not-found
```

## 5. Βρες παρτέρια με βάση το όνομα

Όρισε τη συνάρτηση `find-by-name` ώστε να παίρνει ένα όνομα και να επιστρέφει ένα διάνυσμα με όλες τις πλειάδες `plot` που είναι αυτή τη στιγμή καταχωρισμένες σε αυτό το άτομο.

```factor
open-garden
"Emma" register drop
"Bob" register drop
"Emma" register drop
"Emma" find-by-name .
! => V{ T{ plot { id 1 } { registered-to "Emma" } }
        T{ plot { id 3 } { registered-to "Emma" } } }
```
