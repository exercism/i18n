# Υποδείξεις

## 1. Όρισε το ψευδώνυμο τύπου

- [Αυτή η σελίδα][record-types] δείχνει πώς να δημιουργήσεις ένα ψευδώνυμο τύπου για μια καταγραφή.

## 2. Δημιούργησε τον προπονητή μιας ομάδας

- [Αυτή η σελίδα][create] δείχνει πώς να δημιουργήσεις ένα στιγμιότυπο μιας καταγραφής.

## 3. Δημιούργησε τα στατιστικά μιας ομάδας

- [Αυτή η σελίδα][create] δείχνει πώς να δημιουργήσεις ένα στιγμιότυπο μιας καταγραφής.

## 4. Δημιούργησε μια ομάδα

- [Αυτή η σελίδα][create] δείχνει πώς να δημιουργήσεις ένα στιγμιότυπο μιας καταγραφής.

## 5. Αντικατέστησε τον προπονητή

- Υπάρχει [ειδική σύνταξη][update] για να επιστρέψεις ένα αντίγραφο μιας καταγραφής, αλλά με ένα ή περισσότερα πεδία να έχουν νέα τιμή.

## 6. Έλεγξε αν είναι η ίδια ομάδα

- Η Elm χρησιμοποιεί δομική ισότητα, που σημαίνει ότι καταγραφές με τις ίδιες τιμές είναι ίσες.

## 7. Έλεγξε αν πρέπει να υποστηρίξεις μια ομάδα

- Ο καλύτερος τρόπος να εκτελέσεις λογική με βάση την τιμή της ομάδας είναι να χρησιμοποιήσεις [αντιστοίχιση προτύπων][pattern-matching].
