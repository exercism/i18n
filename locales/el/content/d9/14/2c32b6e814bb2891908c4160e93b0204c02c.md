# Οδηγίες

Είσαι ένας έμπειρος mixologist και φτιάχνεις νόστιμα ποτά για τον κόσμο να τα απολαμβάνει στις βραδινές του εξόδους. Σκέφτηκες όμως ότι θα μπορούσες να κάνεις τη ζωή σου πιο εύκολη γράφοντας λίγο κώδικα που θα σε βοηθάει στη δουλειά σου.

## 1. Υπολόγισε πόσο χρόνο χρειάζεται για να φτιάξεις μια παραγγελία

Τα διάφορα ποτά θέλουν διαφορετικό χρόνο για να ετοιμαστούν:

- Τα `"beer"`, `"soda"` και `"water"` θέλουν 0,5 λεπτά το καθένα.
- Τα `"shot"` θέλουν 1,0 λεπτά, τα `"mixed drink"` θέλουν 1,5 λεπτά,
- Τα `"fancy drink"` θέλουν 2,5 λεπτά,
- Τα `"frozen drink"` θέλουν 3,0 λεπτά.

Υλοποίησε τη συνάρτηση `timeToPrepare(drinks:)`, η οποία δέχεται το όρισμα `drinks`, έναν πίνακα από συμβολοσειρές που αντιπροσωπεύουν τα ποτά που πρέπει να ετοιμαστούν.
Η συνάρτηση πρέπει να επιστρέφει τον συνολικό χρόνο που θα χρειαστεί για να ετοιμαστούν όλα τα ποτά του πίνακα.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Ανανέωσε το απόθεμά σου σε φέτες λάιμ

Ένα από τα πρώτα πράγματα που πρέπει να κάνεις όταν ξεκινάς τη βάρδιά σου είναι να σιγουρευτείς ότι το μικρό δοχείο σου με τις φέτες λάιμ είναι γεμάτο για τη βάρδια που έχεις μπροστά σου.
Θα έχεις λάιμ διαφορετικών μεγεθών, που δίνουν διαφορετικό αριθμό φετών: από ένα λάιμ "small" παίρνεις 6 φέτες, από ένα λάιμ "medium" 8 φέτες και από ένα λάιμ "large" 10 φέτες.

Όσο χρειάζεσαι ακόμα φέτες και σου απομένουν λάιμ για κόψιμο, πάρε το πρώτο λάιμ από τον πίνακα και αφαίρεσε τον αντίστοιχο αριθμό φετών από όσες χρειάζεσαι.
Συνέχισε μέχρι να μη χρειάζεσαι άλλες φέτες ή μέχρι να τελειώσουν τα λάιμ.

Υλοποίησε τη συνάρτηση `makeWedges(needed:limes:)`, η οποία δέχεται τα ορίσματα `needed`, που περιέχει τον αριθμό των φετών που πρέπει να κόψεις, και `limes`, που περιέχει έναν πίνακα από συμβολοσειρές με τα μεγέθη των λάιμ που έχεις διαθέσιμα για κόψιμο.
Η συνάρτηση πρέπει να επιστρέφει τον αριθμό των λάιμ που έκοψες.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Τελείωσε τη βάρδιά σου

Συγχαρητήρια! Η μεγάλη σου μέρα στη δουλειά φτάνει σχεδόν στο τέλος της και σε λίγο θα πας σπίτι για να δουλέψεις τη νέα σου εφαρμογή.
Έχεις όμως ακόμα μια σειρά από παραγγελίες ποτών να ετοιμάσεις πριν παραδώσεις τις παραγγελίες στην επόμενη βάρδια και φύγεις.

Όσο σου απομένει χρόνος στη βάρδια σου, ετοίμασε την πρώτη παραγγελία του πίνακα και μετά αφαίρεσέ την από τον πίνακα.
Έπειτα μπορείς να αφαιρέσεις τον χρόνο που χρειάστηκε για να ετοιμαστεί αυτή η παραγγελία, σύμφωνα με τη συνάρτηση `timeToPrepare(drinks:)`, από τον χρόνο που σου απομένει στη βάρδια.

Υλοποίησε τη συνάρτηση `finishShift(minutesLeft:remainingOrders:)`, η οποία δέχεται τον αριθμό των λεπτών που απομένουν στη βάρδια σου (με εγγύηση ότι είναι μεγαλύτερος από 0) και έναν μη κενό πίνακα παραγγελιών ποτών.
Η συνάρτηση πρέπει να επιστρέφει τον πίνακα με τις παραγγελίες που δεν πρόλαβες πριν από το τέλος της βάρδιάς σου.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Παρακολούθησε συγκεκριμένες παραγγελίες

Για να σιγουρευτείς ότι η μπύρα και η σόδα μένουν φρέσκες, πρέπει να παρακολουθείς τις παραγγελίες τους μαζί με τις ώρες που δόθηκαν αυτές οι παραγγελίες.

Υλοποίησε τη συνάρτηση `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)` η οποία, όταν της δίνεται μια λίστα με παραγγελίες και ώρες, επιστρέφει ένα ζεύγος προαιρετικών πλειάδων που περιέχουν τις ώρες της πρώτης και της τελευταίας παραγγελίας μπύρας και σόδας, μαζί με τον συνολικό αριθμό παραγγελιών για την καθεμία, και `nil` αν δεν έγινε καμία παραγγελία από αυτά τα ποτά. Δεν χρειάζεται να παρακολουθείς κανένα άλλο ποτό.

Υλοποίησε τη συνάρτηση `orderTracker(orders:)`, η οποία δέχεται έναν πίνακα από πλειάδες, όπου κάθε πλειάδα περιέχει το ποτό που παραγγέλθηκε και την ώρα που δόθηκε η παραγγελία.
Η συνάρτηση πρέπει να επιστρέφει μια πλειάδα που περιέχει την ώρα της πρώτης και της τελευταίας παραγγελίας μπύρας, τον συνολικό αριθμό παραγγελιών μπύρας, την ώρα της πρώτης και της τελευταίας παραγγελίας σόδας και τον συνολικό αριθμό παραγγελιών σόδας.
Πρέπει να επιστρέφεται ως πλειάδα με τη μορφή: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
