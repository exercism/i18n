# Υποδείξεις

## 1. Κατηγοριοποίησε τους πελάτες

- Η χρήση της [`every()`][ref-every] με μια ανώνυμη συνάρτηση μπορεί να σου φανεί βολική.

## 2. Ονόμασε τους πελάτες

- Επεξεργάζεσαι δύο εισόδους παράλληλα: σκέψου τη [`map2()`][ref-map2] ως πιθανή προσέγγιση.

## 3. Ξεχώρισε τους πελάτες με έμφαση

- Οι προηγούμενες εργασίες θα σε βοηθήσουν.
- Ποιους πελάτες θέλεις να [`keep`][ref-keep] στη λίστα εξόδου;

## 4. Μετέτρεψε τις αξιολογήσεις σε δυαδικές

- Υπάρχουν αρκετοί τρόποι να το λύσεις, αλλά η [`if_else()`][ref-if_else] από τη βιβλιοθήκη `dplyr` μπορεί να είναι ο πιο απλός. Αυτό συζητήθηκε στην [έννοια Switch][concept-switch].
- Μέσα στο `purrr`, μια άλλη δυνατότητα είναι η [`map_int()`][ref-map_int].

## 5. Μέσος όρος αξιολογήσεων στον χρόνο

- Είναι ένας αθροιστικός μέσος όρος, που σου δίνει ένα στοιχείο για το όνομα μιας χρήσιμης συνάρτησης.
- Ένας μέσος όρος είναι ένα άθροισμα διαιρεμένο με ένα μήκος, οπότε θα μπορούσαμε να το υλοποιήσουμε χρησιμοποιώντας συναρτήσεις του `purrr`.
  - Στην Εισαγωγή είδαμε πώς να συσσωρεύουμε ένα άθροισμα.
  - Θα μπορούσαμε να χρησιμοποιήσουμε τη [`map2_dbl()`][ref-map2] για να διαιρέσουμε αθροίσματα με μήκη.
