# Εισαγωγή

Ένα διάνυσμα είναι ένας μονοδιάστατος πίνακας.
Μπορεί να περιέχει στοιχεία διαφορετικών τύπων.

## Δημιουργία διανυσμάτων

Τα διανύσματα μπορούν να δημιουργηθούν μέσω της συνάρτησης `vector` ή χρησιμοποιώντας τη μορφή ανάγνωσης `#()`

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

Επειδή είναι πίνακες, μπορούν να δημιουργηθούν και με τη `make-array`:

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## Κατηγόρημα διανύσματος

Για να ελέγξεις αν ένα αντικείμενο είναι διάνυσμα, χρησιμοποίησε απλώς το κατηγόρημα `vectorp`.

## Πρόσβαση σε στοιχεία

Για να έχεις πρόσβαση στα στοιχεία ενός διανύσματος, χρησιμοποίησε το `aref`. Οι θέσεις ξεκινούν από το μηδέν:

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
