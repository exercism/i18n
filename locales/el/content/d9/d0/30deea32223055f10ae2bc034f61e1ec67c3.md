# Εισαγωγή

## Boolean

Ο τύπος `Bool` είναι ένα από τα δομικά στοιχεία της γλώσσας.
Σκοπός του είναι να περιγράφει αν κάτι είναι αληθές ή ψευδές, με τις αντίστοιχες τιμές `True` και `False`.

Τα Boolean (λογικές τιμές) μπορούν να συνδυαστούν με τους τελεστές `&&` "AND" και `||` "OR", και να αντιστραφούν με τη συνάρτηση `not`.

Τα Boolean είναι επίσης εξαιρετικά χρήσιμα για να δημιουργείς διακλαδώσεις στον κώδικά σου που εκτελούνται μόνο αν πληρούνται ορισμένες συνθήκες.
Στην Elm, αυτό γίνεται με μια έκφραση `if-then-else`, όπως φαίνεται παρακάτω.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
