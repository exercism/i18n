# Εισαγωγή

Μια *γενική λέξη* δηλώνει μια πράξη που μπορεί να έχει διαφορετικές
υλοποιήσεις ανάλογα με την κλάση του ορίσματός της. Οι μέθοδοι
προστίθενται με `M:`.

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

Το `GENERIC:` δηλώνει τη λέξη και την επίδρασή της στη στοίβα. Το `M:`
ορίζει μια μέθοδο σε μια συγκεκριμένη κλάση: ο Factor επιλέγει τη μέθοδο
με βάση την κλάση του ορίσματος που βρίσκεται στην κορυφή της στοίβας, τη
στιγμή της εκτέλεσης.

Μπορείς να ρωτήσεις τη γενική λέξη για ποιες κλάσεις έχει μεθόδους, και
να προσθέσεις ή να αφαιρέσεις μεθόδους εκ των υστέρων. Δεν υπάρχει ειδική
σύνταξη κληρονομικότητας: κάθε κλάση tuple μπορεί αυτόματα να δεχτεί
ορισμούς μεθόδων.
