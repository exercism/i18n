# Υποδείξεις

## 1. Προσδιόρισε τον συνολικό αριθμό των πουλιών που έχεις μετρήσει μέχρι τώρα

- Ανατρέξε στην εισαγωγή της άσκησης για ένα παράδειγμα χρήσης ενός `for` βρόχου για να διατρέξεις έναν πίνακα.
- Χρησιμοποίησε μια βοηθητική μεταβλητή για να αποθηκεύσεις τον συνολικό αριθμό και αύξησέ την καθώς διατρέχεις τον πίνακα.
- Σκέψου τη σωστή αρχική τιμή για αυτή τη βοηθητική μεταβλητή.
- Ανατρέξε ξανά στην [έννοια του πίνακα][concept-arrays] για να θυμηθείς πώς να ανακτάς τιμές από έναν πίνακα.

## 2. Υπολόγισε τον αριθμό των πουλιών που επισκέπτονται σε μια συγκεκριμένη εβδομάδα

- Αυτή η εργασία είναι παρόμοια με την πρώτη.
  Μπορείς να αντιγράψεις τον κώδικά σου ως σημείο εκκίνησης.
- Σκέψου ποιες θέσεις στον πίνακα θα χρειαστεί να λάβεις υπόψη για την εβδομάδα 1 και 2, αντίστοιχα.
- Τώρα, βρες έναν γενικό τρόπο να υπολογίζεις την πρώτη και την τελευταία θέση που πρέπει να λάβεις υπόψη.
- Έτσι, μπορείς να στήσεις τον `for` βρόχο ώστε να διατρέχει μόνο το σχετικό τμήμα του πίνακα.

## 3. Διόρθωσε ένα λάθος στη μέτρηση

- Και πάλι, χρειάζεται να στήσεις έναν `for` βρόχο για να διατρέξεις ολόκληρο τον πίνακα καταμέτρησης πουλιών.
- Αυτή τη φορά χρειάζεται να επισκεφτείς μόνο κάθε δεύτερη καταχώριση στον πίνακα.
- Άλλαξε το βήμα ώστε η μεταβλητή μετρητή να αυξάνεται ανάλογα μετά από κάθε επανάληψη.
- Στο σώμα του `for` βρόχου μπορείς να χρησιμοποιήσεις τον τελεστή αύξησης για να αλλάξεις την τιμή ενός στοιχείου σε έναν πίνακα επιτόπου.
