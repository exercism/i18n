# Σχετικά

## Οδηγίες include

Για να συμπεριλάβει το περιεχόμενο άλλων αρχείων, η C++ χρησιμοποιεί την οδηγία `include`.
Αυτές οι οδηγίες include πρέπει να δηλώνονται στην αρχή του αρχείου.
Κατά τη μεταγλώττιση, η γραμμή με την οδηγία αντικαθίσταται από το περιεχόμενο του αντίστοιχου αρχείου.
Μετά τις συμπεριλήψεις, οι χώροι ονομάτων διατηρούνται όπως είναι στο αρχικό αρχείο.

## Η τυπική βιβλιοθήκη

Η τυπική βιβλιοθήκη προσφέρει πολλές κοινές συναρτήσεις, αλγορίθμους και δομές δεδομένων.
Η τυπική βιβλιοθήκη χρησιμοποιεί τον χώρο ονομάτων `std`.

Ένα παράδειγμα είναι η βιβλιοθήκη αριθμητικών υπολογισμών της C, `cmath`.
Παρέχει πολλές κοινές μαθηματικές πράξεις.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Οι τυπικές βιβλιοθήκες συμπεριλαμβάνονται με γωνιακές αγκύλες `<>` αντί για διπλά εισαγωγικά `"`.
Η διαφορά είναι η τοποθεσία στην οποία ο μεταγλωττιστής αναζητά τα αντίστοιχα αρχεία.
Η αναζήτηση στο τρέχον έργο παραλείπεται για την έκδοση με τις γωνιακές αγκύλες, και ξεκινά απευθείας στους καταλόγους include του συστήματος.
Αν θέλεις να συμπεριλάβεις τοπικά αρχεία, θα χρησιμοποιούσες διπλά εισαγωγικά: `#include "myfile"`
~~~~
