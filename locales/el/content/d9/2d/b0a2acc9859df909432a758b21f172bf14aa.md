# Εισαγωγή

Στην PHP, μπορείς να καλέσεις μια μεταβλητή ως συνάρτηση εφαρμόζοντας παρενθέσεις [`()`] σε αυτήν. Όταν η PHP προσπαθεί να καλέσει τη συνάρτηση, θα αναζητήσει μια συνάρτηση με το ίδιο όνομα με την τιμή της μεταβλητής.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
