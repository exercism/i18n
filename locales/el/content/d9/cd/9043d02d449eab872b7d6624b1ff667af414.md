# Εισαγωγή στους Γενικούς Τύπους

Ένας **γενικός τύπος** είναι μια γενική κλάση ή διεπαφή που παραμετροποιείται ως προς τύπους.
Αυτό επιτρέπει στον μεταγλωττιστή να επιβάλλει την ασφάλεια τύπων στην κλάση ή τη διεπαφή.

Ας δούμε αυτή τη μη γενική διεπαφή `Container`:

```java
class Container {
    private Object object;

    public void set(Object object) { this.object = object; }
    public Object get() { return object; }
}
```

Επειδή δέχεται και επιστρέφει τύπους `Object`, δουλεύει με οποιονδήποτε μη πρωτόγονο τύπο.
Ωστόσο, αυτό έχει κόστος, γιατί κάποιος κώδικας μπορεί να καλέσει τη `get` περιμένοντας `Integer`, ενώ άλλος κώδικας καλεί τη `set` προσθέτοντας `String`, με αποτέλεσμα μια εξαίρεση κατά την εκτέλεση.

Μια **γενική κλάση** και μια **γενική διεπαφή** έχουν την εξής μορφή:

```java
class ClassName<T1, T2, ..., Tn> { ... }
interface InterfaceName<T1, T2, ..., Tn> { ... }
```

Το τμήμα των παραμέτρων τύπου, που οριοθετείται από γωνιακές αγκύλες (`<>`) και ακολουθεί το όνομα της κλάσης ή της διεπαφής, καθορίζει τις παραμέτρους τύπου (που ονομάζονται και μεταβλητές τύπου) `T1`, `T2`, ..., και `Tn`.
Αυτές μπορούν να χρησιμοποιηθούν μέσα στο σώμα της κλάσης ή της διεπαφής για να έχεις ασφάλεια τύπων.

Ορίστε η γενική έκδοση του `Container`:

```java
class Container<E> {
    private E object;

    public void set(E object) { this.object = object; }
    public E get() { return object; }
}
```

Όταν τη δημιουργείς, πρέπει πλέον να δηλώσεις τι τύπο κρατάει και ο μεταγλωττιστής θα επιβάλλει αυτόν τον περιορισμό:

```java
// empty <> can infer from context
Container<String> stringContainer = new Container<>();
// compiler knows this is a String, so it is allowed
stringContainer.set("Some string");
// no cast needed, compiler knows it is a String
String result = stringContainer.get();
// this causes a compiler error:
stringContainer.set(42);
```
