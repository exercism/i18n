# Εισαγωγή

## Αριθμοί

Οι δύο πιο συνηθισμένοι τύποι αριθμών στη Ruby είναι:

- **Ακέραιοι:** αριθμοί χωρίς ψηφία μετά το δεκαδικό διαχωριστικό (ακέραιοι αριθμοί). Παραδείγματα είναι τα `-6`, `0`, `1`, `25`, `976` και `500000`.
- **Αριθμοί κινητής υποδιαστολής:** αριθμοί με ένα ή περισσότερα ψηφία μετά το δεκαδικό διαχωριστικό. Παραδείγματα είναι τα `-2.4`, `0.1`, `3.14`, `16.984025` και `1024.0`.

Υλοποιούνται μέσω των κλάσεων `Integer` και `Float`.

Αυτές οι κλάσεις έχουν μεθόδους που μετατρέπουν τιμές από τη μία στην άλλη. Οι αριθμοί `Integer` είναι ακριβείς ως προς την ακέραια μονάδα, ενώ το `Float` έχει ακρίβεια κλασματική ως προς έναν ακέραιο αριθμό:
- `Integer#to_f`: Μετατρέπει σε νέο float
- `Float#ceil`: Στρογγυλοποιεί προς τα πάνω στον πλησιέστερο ακέραιο
- `Float#floor`: Στρογγυλοποιεί προς τα κάτω στον πλησιέστερο ακέραιο
- `Float#round`: Στρογγυλοποιεί στον πλησιέστερο ακέραιο
- `Float#to_i`: Αποκόπτει στον πλησιέστερο ακέραιο

## Συνθήκες

Η Ruby έχει αυτό που ονομάζεται εκφράσεις ελέγχου ροής. Χρησιμοποιούνται για να ελέγχουν τον τρόπο με τον οποίο θα εκτελεστεί το πρόγραμμα και παίρνουν μια τιμή αληθή ή ψευδή.
Υπάρχουν τελεστές που μπορούν να χρησιμοποιηθούν για να δημιουργήσουν αληθείς ή ψευδείς τιμές, γνωστοί ως [τελεστές σύγκρισης][comparison-operators].

Υπάρχουν δύο βασικές εκφράσεις ελέγχου που καθορίζουν ποιος κώδικας θα εκτελεστεί και ποιος όχι.
Δηλαδή, ποιος συγκεκριμένος κλάδος θα εκτελεστεί.

Αυτές οι δύο είναι: η έκφραση `if` και η έκφραση `unless`.

## Τελεστές σύγκρισης

Οι [τελεστές σύγκρισης][comparison-operators] χρησιμοποιούνται για να συγκρίνουν τιμές και να επιστρέφουν μια τιμή `true` ή `false`.
Οι παρακάτω τελεστές απαιτούν οι δύο τιμές που συγκρίνονται να είναι του ίδιου τύπου.
Αν οι τιμές δεν είναι του ίδιου τύπου, τότε ο μεταγλωττιστής θα πετάξει ένα σφάλμα.
Ακολουθεί μια λίστα με τους τελεστές και ένα παράδειγμα για το πότε δίνουν τιμή `true`:

| Μέθοδος | Περιγραφή           | Παράδειγμα |
| ------ | --------------------- | ------- |
| <      | μικρότερο από             | 4 < 5   |
| <=     | μικρότερο ή ίσο με    | 4 <= 4  |
| >      | μεγαλύτερο από          | 3 > 1   |
| >=     | μεγαλύτερο ή ίσο με | 2 >= 2  |

Οι τελεστές ισότητας και ανισότητας μπορούν να χρησιμοποιηθούν για τη σύγκριση οποιουδήποτε τύπου τιμής, σε αντίθεση με τους τελεστές που αναφέρθηκαν ήδη.
Ο τελεστής `==` χρησιμοποιείται για να ελέγξει αν δύο τιμές είναι ίσες, και αυτό περιλαμβάνει τον έλεγχο του τύπου της τιμής.
Ο `!=` λειτουργεί με τον ίδιο τρόπο, αλλά θα επιστρέψει `true` αν οι τιμές δεν είναι ίσες και `false` αν είναι ίσες.
Ακολουθεί μια λίστα με τους τελεστές ισότητας και ανισότητας και ένα παράδειγμα για το πότε δίνουν τιμή `true`:

| Μέθοδος | Περιγραφή  | Παράδειγμα |
| ------ | ------------ | ------- |
| ==     | ίσο        | 4 == 4  |
| !=     | άνισο    | 5 != 4  |

## Η εντολή `if`

Η εντολή [`if`][if] χρησιμοποιείται για να ελέγξει αν μια δεδομένη συνθήκη είναι "αληθής" ή "ψευδής".
Αν η συνθήκη είναι αληθής, τότε ο κώδικας μέσα στην εντολή `if` θα εκτελεστεί.
Μια εντολή `if` τελειώνει με τη λέξη-κλειδί `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Η εντολή `unless`

Η εντολή `unless` λειτουργεί πολύ παρόμοια με την εντολή `if`, αλλά θα εκτελέσει τον κώδικα μέσα στην εντολή `unless` αν η συνθήκη είναι ψευδής.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Η εντολή `else`

Η εντολή `else` μπορεί να χρησιμοποιηθεί σε συνδυασμό με την εντολή `if`.
Η εντολή `else` θα εκτελεστεί αν ο κλάδος `if` δεν εκτελεστεί.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"
```

## Εντολές "διαδοχικών if"

Η εντολή `elsif` μπορεί να χρησιμοποιηθεί σε συνδυασμό με την εντολή `if`.
Η εντολή `elsif` θα εκτελεστεί αν ο κλάδος `if` δεν εκτελεστεί και η συνθήκη της εντολής `elsif` είναι αληθής.
Οι εντολές `elsif` μπορούν να αλυσιδωθούν μεταξύ τους και θα εκτελεστεί η πρώτη αληθής συνθήκη.
Μπορεί επίσης να υπάρχει μια εντολή `else` στο τέλος της εντολής `if`, η οποία θα εκτελεστεί αν καμία από τις προηγούμενες εντολές δεν ήταν αληθής.

```ruby
value = 1
if value != 1
  "1 is not equal to 1"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 1 and 1 is not greater than 2"
end
# => "1 is not equal to 1 and 1 is not greater than 2"
```
