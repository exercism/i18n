# Εισαγωγή

Μια [`string`][ref-string] στην Kotlin είναι μια αμετάβλητη ακολουθία χαρακτήρων Unicode.

[`Immutable`][wiki-immutable] σημαίνει ότι οποιαδήποτε πράξη πάνω σε μια συμβολοσειρά πρέπει να επιστρέφει μια νέα συμβολοσειρά: η αρχική συμβολοσειρά δεν μπορεί να αλλάξει ποτέ.

[`Unicode`][wiki-unicode] σημαίνει ότι τα περισσότερα συστήματα γραφής του κόσμου μπορούν να αναπαρασταθούν, αλλά (σε αντίθεση με παλαιότερες γλώσσες όπως η C) δεν υπάρχει αντιστοιχία 1:1 μεταξύ χαρακτήρων και bytes.

Μια συμβολοσειρά συνήθως περικλείεται από διπλά εισαγωγικά `" "`.

Μερικοί χαρακτήρες χρειάζονται διαφυγή: `\'`, `\\`, καθώς και οι συνήθεις μη εκτυπώσιμοι χαρακτήρες όπως `\t` (στηλοθέτης) και `\n` (νέα γραμμή).

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

Οι συμβολοσειρές πολλών γραμμών περικλείονται από 3 διπλά εισαγωγικά και μπορούν να περιέχουν οποιοδήποτε κείμενο (χωρίς να χρειάζεται διαφυγή).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Χρησιμοποίησε το [trimIndent][trimIndent-doc] για να αφαιρέσεις την κοινή εσοχή από τις γραμμές.
Αυτό είναι χρήσιμο για τη μορφοποίηση της συμβολοσειράς:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Εναλλακτικά, το [trimMargin][trimMargin-doc] σου επιτρέπει να ορίσεις έναν διαχωριστή.
Τότε, κάθε γραμμή στη `String` ξεκινά μετά τον διαχωριστή.
Ο προεπιλεγμένος διαχωριστής είναι το `|`, αλλά μπορείς να ορίσεις έναν διαφορετικό διαχωριστή ως παράμετρο.
Για παράδειγμα:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Οι συμβολοσειρές μπορούν να συνενωθούν με `+`, αλλά είναι καλύτερα να το περιορίζεις σε σύντομες και απλές περιπτώσεις.
Υπάρχουν άλλες, και συχνά καλύτερες, επιλογές.

## Πρότυπα συμβολοσειρών

Αυτό αναφέρεται σε αυτό που μερικές άλλες γλώσσες ονομάζουν "παρεμβολή".

Αν μια συμβολοσειρά περιέχει ένα σύμβολο δολαρίου `$`, ακολουθούμενο από ένα αναγνωριστικό, ή περιέχει άγκιστρα (`{expression}`) γύρω από μια έκφραση, τότε αυτά αντικαθίστανται από την τιμή ή το αποτέλεσμα της έκφρασης, αντίστοιχα.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

Τα άγκιστρα `{ }` χρειάζονται γύρω από εκφράσεις όταν, σε διαφορετική περίπτωση, η ανάλυση θα ήταν αμφίσημη.

Γενικά, η χρήση προτύπων συμβολοσειρών είναι ένας πιο αποδοτικός και πιο ιδιωματικός τρόπος να συνδυάζεις συμβολοσειρές από τη χρήση του `+`.

## Συναρτήσεις συμβολοσειρών

Η Kotlin παρέχει _πολλές_ [`functions`][ref-string-functions] για τον χειρισμό συμβολοσειρών.

Ως επί το πλείστον, αυτές είναι [`extensions functions`][ref-extensions] και όχι μέλη της κλάσης `String`, αν και αυτό έχει μικρή επίδραση στον τρόπο που τις χρησιμοποιούμε.

~~~~exercism/note
Οι αρκετά περίπλοκες [σελίδες τεκμηρίωσης][ref-string-functions] της Kotlin κρύβουν τις συναρτήσεις επέκτασης στην προεπιλεγμένη προβολή.
Φρόντισε να κάνεις κλικ στο `Members & Extensions` για να αναπτύξεις αυτήν την ενότητα.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

Τα παρακάτω παραδείγματα δείχνουν μόνο ένα μικρό δείγμα από ό,τι είναι διαθέσιμο:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
