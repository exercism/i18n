# Οδηγίες

Υλοποίησε την πράξη `accumulate`, η οποία, δεδομένης μιας συλλογής και μιας πράξης που εκτελείται σε κάθε στοιχείο της συλλογής, επιστρέφει μια νέα συλλογή που περιέχει το αποτέλεσμα της εφαρμογής αυτής της πράξης σε κάθε στοιχείο της συλλογής εισόδου.

Δίνεται η συλλογή αριθμών:

- 1, 2, 3, 4, 5

Και η πράξη:

- ύψωση ενός αριθμού στο τετράγωνο (`x => x * x`)

Ο κώδικάς σου θα πρέπει να μπορεί να παράγει τη συλλογή των τετραγώνων:

- 1, 4, 9, 16, 25

Ρίξε μια ματιά στη σουίτα δοκιμών για να δεις την αναμενόμενη υπογραφή της συνάρτησης.
