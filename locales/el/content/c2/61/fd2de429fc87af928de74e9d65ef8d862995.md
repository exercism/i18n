# Τεστ

Κάνε το πρώτο τεστ να μεταγλωττιστεί, να συνδεθεί και να περάσει, ακολουθώντας τους [τρεις κανόνες της ανάπτυξης καθοδηγούμενης από τεστ][3-tdd-rules].

Με το makefile που περιλαμβάνεται μπορείς να δημιουργήσεις και να τρέξεις τα τεστ, χρησιμοποιώντας την εργασία `test`.

```console
$ make test
```

Δημιούργησε μόνο τις συναρτήσεις που χρειάζεσαι για να αντιμετωπίσεις τυχόν σφάλματα του μεταγλωττιστή και κάνε το τεστ να αποτύχει.
Έπειτα, γράψε μόνο τον κώδικα που αρκεί για να περάσει το τεστ.
Μόλις το κάνεις αυτό, προχώρησε στο επόμενο τεστ.

Καθώς προχωράς μέσα από τα τεστ, αφιέρωσε χρόνο για να αναδιαμορφώσεις την υλοποίησή σου ώστε να είναι πιο ευανάγνωστη και εκφραστική, και μετά προχώρησε στο επόμενο τεστ.

Προσπάθησε να χρησιμοποιείς τις δυνατότητες του προτύπου C99, αντί να γράφεις με το χέρι τους δικούς σου αλγορίθμους ή μηχανισμούς χαμηλού επιπέδου.

## Έλεγχος για διαρροές μνήμης

Το makefile περιλαμβάνει επίσης ένα build που ελέγχει κάποια συνηθισμένα λάθη σχετικά με διαρροές μνήμης και προσβάσεις σε πίνακες εκτός ορίων.
Για να τρέξεις αυτούς τους ελέγχους, χρησιμοποίησε το παρακάτω στη γραμμή εντολών:

```console
$ make memcheck
```
