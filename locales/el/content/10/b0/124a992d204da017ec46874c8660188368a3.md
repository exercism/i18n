# Εισαγωγή

Στη Go, οι συμβολοσειρές είναι αμετάβλητες.
Η συνένωση συμβολοσειρών με `+` μέσα σε έναν βρόχο προκαλεί συχνές δεσμεύσεις μνήμης και αντιγράφει τα δεδομένα πολλές φορές.
Το πακέτο [`strings`](https://pkg.go.dev/strings) παρέχει το [`Builder`](https://pkg.go.dev/strings#Builder) για να ελαχιστοποιεί την επιβάρυνση μνήμης, συνθέτοντας συμβολοσειρές με αποδοτικό τρόπο.

## Κατασκευή συμβολοσειρών

Η μηδενική τιμή ενός `strings.Builder` είναι έτοιμη για χρήση αμέσως, χωρίς καμία ρητή αρχικοποίηση ή δέσμευση μνήμης.
Μπορείς να προσθέτεις νέα δεδομένα στον builder με συγκεκριμένες μεθόδους εγγραφής.
Κάθε μέθοδος εγγραφής επιστρέφει μια τιμή σφάλματος για να ικανοποιεί τις τυπικές διεπαφές της Go, αλλά είναι εγγυημένο ότι θα είναι πάντα `nil` και συνήθως αγνοείται στον καθημερινό κώδικα.

Οι μέθοδοι που χρησιμοποιούνται πιο συχνά είναι:

- `WriteString(s string) (int, error)`: Προσαρτά μια συμβολοσειρά στο buffer.
- `WriteRune(r rune) (int, error)`: Προσαρτά την κωδικοποίηση UTF-8 ενός rune.
- `WriteByte(c byte) error`: Προσαρτά ένα μόνο byte.

```go
var sb strings.Builder

sb.WriteString("Hello")
var r rune = ' '
sb.WriteRune(r)
var b byte = '.'
sb.WriteByte(b)
```

## Ανάκτηση και επαναφορά

Όταν τελειώσεις τη σύνθεση του κειμένου σου, μπορείς να πάρεις το συσσωρευμένο περιεχόμενο ως μια κανονική συμβολοσειρά της Go καλώντας τη μέθοδο `String()`.
Η κλήση της `String()` είναι μια πολύ φθηνή πράξη, γιατί επιστρέφει απευθείας ως συμβολοσειρά το υποκείμενο slice των byte, χωρίς να αντιγράψει τα συσσωρευμένα δεδομένα.

Αν χρειάζεται να ξαναχρησιμοποιήσεις το ίδιο στιγμιότυπο του builder για να συνθέσεις μια νέα συμβολοσειρά (για παράδειγμα, μέσα σε έναν βρόχο), μπορείς να καλέσεις τη μέθοδο `Reset()`.
Αυτή αδειάζει τον εσωτερικό buffer, ώστε να ξεκινήσεις από την αρχή και να φτιάξεις την επόμενη συμβολοσειρά, διατηρώντας στο παρασκήνιο τη χωρητικότητα μνήμης που έχει ήδη δεσμευτεί.

```go
var sb strings.Builder

sb.WriteString("Task One")
fmt.Println(sb.String()) // Output: Task One

// Clear the buffer for resource reuse
sb.Reset()

sb.WriteString("Task Two")
fmt.Println(sb.String()) // Output: Task Two
```
