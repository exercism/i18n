# Οδηγίες

Στον Λόγκαν, τον εξωγήινο της Lisp, αρέσουν οι αριθμοί και του αρέσει επίσης να οργανώνει.

Σου ζητάει να τον βοηθήσεις να γράψει μια συνάρτηση που θα παίρνει μια λίστα με αριθμούς και θα παράγει ένα ζεύγος από δύο λίστες: η πρώτη περιέχει όλους τους περιττούς αριθμούς, η δεύτερη όλους τους άρτιους.

## 1. Κατηγοριοποίηση ενός αριθμού

Πρώτα θα χρειαστεί να δημιουργήσεις μια συνάρτηση που παίρνει ένα ζεύγος από δύο λίστες και έναν αριθμό, και τοποθετεί αυτόν τον αριθμό στη σωστή υπολίστα ανάλογα με το αν είναι περιττός ή άρτιος:

```lisp
(categorize-number '((1) . (2)) 23) ; => ((23 1) . (2))
(categorize-number '((1) . (2)) 42) ; => ((1) . (42 2))
```

## 2. Κατηγοριοποίηση πολλών αριθμών

Τώρα, χρησιμοποιώντας τη συνάρτηση που μόλις δημιούργησες, μπορείς να γράψεις μια άλλη συνάρτηση που παίρνει μια λίστα με αριθμούς και τους κατηγοριοποιεί όπως έκανες παραπάνω:

```lisp
(partition-numbers '(1 2 3 4))     ; => ((3 1) . (4 2))
(partition-numbers '(42 31 24 13)) ; => ((13 31) . (24 42))
```
