# Υποδείξεις

## Γενικά

- Διάβασε για τις συμβολοσειρές στον επίσημο [οδηγό συμβολοσειρών][string-guide].
- Ρίξε μια ματιά στις [μεθόδους που είναι διαθέσιμες για τις _συμβολοσειρές_][string-methods].

## 1. Καθάρισε το όνομα

- Υπάρχει μια [ενσωματωμένη μέθοδος][string-replace] για να αντικαταστήσεις όλες τις εμφανίσεις μιας υποσυμβολοσειράς μέσα σε μια συμβολοσειρά.
- Υπάρχει μια [ενσωματωμένη μέθοδος][string-strip] για να αφαιρέσεις τα κενά στην αρχή και στο τέλος μιας συμβολοσειράς.

## 2. Πάρε το πρώτο γράμμα του ονόματος

- Για να πάρεις έναν συγκεκριμένο χαρακτήρα από μια συμβολοσειρά, μπορείς να χρησιμοποιήσεις τον [τελεστή θέσης][string-indexing].

## 3. Μορφοποίησε το πρώτο γράμμα ως αρχικό

- Υπάρχει μια [ενσωματωμένη μέθοδος][string-upcase] για να μετατρέψεις όλους τους χαρακτήρες μιας συμβολοσειράς στη μορφή τους με κεφαλαία.

## 4. Βάλε τα αρχικά μέσα στην καρδιά

- Υπάρχει ειδική σύνταξη για την [παρεμβολή][string-interpolation] μιας έκφρασης μέσα σε μια συμβολοσειρά.
- Μπορείς να βάλεις ένα emoji καρδιάς σε μια συμβολοσειρά χρησιμοποιώντας διαφυγή: `\u<id>`, το id για το emoji καρδιάς είναι `2764`.
