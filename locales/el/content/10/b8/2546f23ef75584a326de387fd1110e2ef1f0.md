# Οδηγίες

Σε αυτή την άσκηση θα γράφεις κώδικα για να διαχειρίζεσαι ένα λεξικό με διεθνείς κωδικούς κλήσης χρησιμοποιώντας ένα `Map`.

Το λεξικό επιτρέπει την αναζήτηση του ονόματος μιας χώρας (της τιμής του Map, ως `String`) μέσω του διεθνούς κωδικού κλήσης (του κλειδιού του Map, ως `Integer`).

## 1. Επίστρεψε τους κωδικούς σε ένα Map

Υλοποίησε τη μέθοδο `getCodes` που δε δέχεται παραμέτρους και επιστρέφει ένα Map με τους κωδικούς κλήσης και τις αντίστοιχες χώρες που βρίσκονται αυτή τη στιγμή στο λεξικό.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Πρόσθεσε καταχωρίσεις στο λεξικό

Το λεξικό πρέπει να γεμίσει με δεδομένα.
Υλοποίησε τη μέθοδο `setDialingCode` που δέχεται έναν κωδικό κλήσης και την αντίστοιχη χώρα και προσθέτει τον κωδικό κλήσης και τη χώρα.
Αν ο κωδικός κλήσης υπάρχει ήδη στο Map, ενημέρωσε το Map με τον κωδικό και τη χώρα που δίνονται.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Βρες τη χώρα ενός κωδικού κλήσης

Υλοποίησε τη μέθοδο `getCountry` που δέχεται έναν κωδικό κλήσης και επιστρέφει το όνομα της χώρας με αυτόν τον κωδικό κλήσης.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. Μην επιτρέπεις διπλότυπα

Όταν προσθέτεις έναν κωδικό κλήσης, πρέπει να προσέξεις ώστε να μην προστεθεί δύο φορές ένας κωδικός ή μια χώρα.
Σε τέτοιες περιπτώσεις, μπορείς να υποθέσεις ότι η πρώτη καταχώριση είναι η σωστή.
Υλοποίησε τη μέθοδο `addNewDialingCode` που προσθέτει μια καταχώριση για τον δεδομένο κωδικό κλήσης και τη χώρα.
Ωστόσο, σε αντίθεση με τη `setDialingCode`, δε κάνει τίποτα αν ο κωδικός κλήσης ή η χώρα υπάρχουν ήδη στο Map.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Βρες τον κωδικό κλήσης μιας χώρας

Είναι σπάνιο, αλλά μπορούν να γίνουν λάθη.
Για να διορθώσουμε το λάθος, θα χρειαστεί να ξέρουμε σε ποιον κωδικό κλήσης αντιστοιχίζεται αυτή τη στιγμή η χώρα.
Για να βρεις ποιος κωδικός κλήσης πρέπει να διορθωθεί, υλοποίησε τη μέθοδο `findDialingCode` που δέχεται μια χώρα και επιστρέφει τον κωδικό κλήσης της χώρας.
Επίστρεψε `null` αν η χώρα _δεν_ βρίσκεται στο Map.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Ενημέρωσε τον κωδικό κλήσης της χώρας

Τώρα που ξέρουμε ποιος κωδικός κλήσης πρέπει να διορθωθεί, προχωράμε στην ενημέρωση του κωδικού.
Υλοποίησε τη μέθοδο `updateCountryDialingCode` που δέχεται τον νέο κωδικό κλήσης της χώρας και το όνομα της χώρας και ενημερώνει ανάλογα.
Μην κάνεις τίποτα αν η χώρα _δεν_ βρίσκεται στο Map (καθώς αυτή η μέθοδος προορίζεται μόνο για τη διόρθωση λαθών).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
