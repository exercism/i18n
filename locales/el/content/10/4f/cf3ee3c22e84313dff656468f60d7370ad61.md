# Case

[Case][case] (συχνά αναφέρεται ως switch σε άλλες γλώσσες) είναι μια μορφή έκφρασης ελέγχου ροής, όπως η if-else.
Το case επιτρέπει τη σύνδεση πολλαπλών εντολών if-else-if και μπορεί να είναι πιο ευανάγνωστο, ενώ παράλληλα παρέχει έλεγχο ροής.

Ένα case ορίζεται από τη λέξη-κλειδί `case` που ακολουθείται από μια προαιρετική έκφραση.
Έπειτα, για κάθε περίπτωση, χρησιμοποιείται η λέξη-κλειδί `when` ακολουθούμενη από μια έκφραση που συγκρίνεται με την έκφραση του case.
Η λέξη-κλειδί `when` δεν πρέπει να έχει εσοχή σε σχέση με τη λέξη-κλειδί `case`.
Μετά τη λέξη-κλειδί `when` ακολουθεί ο κώδικας που πρέπει να εκτελεστεί αν η έκφραση του case ταιριάζει με την έκφραση του when.
Το case επιτρέπει μια προαιρετική εντολή `else` που εκτελείται αν δεν ταιριάζει καμία άλλη περίπτωση.

Η έκφραση του case αξιολογείται και στη συνέχεια συγκρίνεται με κάθε έκφραση `when`.
Οι εκφράσεις συγκρίνονται με τον τελεστή ισότητας case (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Ο τελεστής ισότητας case (`===`)

Ο τελεστής ισότητας case (`===`) διαφέρει λίγο από τον τελεστή ισότητας (`==`).
Ο τελεστής ελέγχει αν η δεξιά πλευρά είναι μέλος του συνόλου που περιγράφει η αριστερή πλευρά.
Αυτό σημαίνει ότι έχει σημασία πού τοποθετείται κάθε τελεστέος.
Το πώς λειτουργεί εξαρτάται από τον τύπο της αριστερής πλευράς· για παράδειγμα, ένα `Range` θα έλεγχε αν η δεξιά πλευρά βρίσκεται μέσα στο εύρος, ενώ ένα `Object` θα έλεγχε αν η δεξιά πλευρά είναι στιγμιότυπο του `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case με πολλαπλές εκφράσεις

Τα cases επιτρέπουν το ταίριασμα πολλαπλών εκφράσεων σε ένα μόνο case, με κάθε πιθανή τιμή να χωρίζεται με κόμμα.
Ο κώδικας εκτελείται αν ταιριάζει οποιαδήποτε από τις εκφράσεις.
Αυτό είναι χρήσιμο όταν θέλεις ένα case να έχει πολλαπλές πιθανές τιμές.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Case με εύρη

Τα cases μπορούν επίσης να ελέγχουν αν μια τιμή βρίσκεται μέσα σε ένα εύρος.
Αυτό γίνεται έχοντας ένα εύρος ως έκφραση when.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case χωρίς έκφραση case

Όταν δεν χρειάζεται έκφραση case, μπορείς να την παραλείψεις.
Έτσι, κάθε έκφραση when αξιολογείται ως προς την αληθότητά της.
Και έτσι συμπεριφέρονται σαν εντολές if-else-if.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## when σε μία γραμμή

Η Ruby επιτρέπει εντολές case σε μία γραμμή.
Αυτό μπορεί να χρησιμοποιηθεί όταν έχεις μια απλή εντολή μίας γραμμής.
Η εντολή when μίας γραμμής γράφεται ως `when <expression> then <statement>`.
Και όταν χρησιμοποιείται στην εντολή else, γράφεται ως `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case με τύπους

Το case επιτρέπει το ταίριασμα με τύπους.
Αυτό είναι χρήσιμο όταν θέλεις διαφορετική συμπεριφορά ανάλογα με τον τύπο μιας μεταβλητής.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
