# Σχετικά

Οι τοπικές μεταβλητές δεν αντικαθιστούν τον κώδικα της στοίβας, συνυπάρχουν μαζί του. Καταφεύγεις σε αυτές όταν:

- Η ίδια είσοδος αναφέρεται περισσότερες από μία φορές.
- Η φυσική σειρά των πράξεων δεν ταιριάζει με τη σειρά της στοίβας.
- Βρίσκεσαι μέσα σε μια λέξη ανώτερης τάξης που δίνει στο λάμδα πολλές τιμές ταυτόχρονα (το `( key value -- newkey newvalue )` της `assoc-map`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

Το `[let code :> name code :> name ... body ]` εισάγει τοπικές δεσμεύσεις μέσα σε ένα quotation ή στον listener, όπου αλλιώς το `:>` δεν θα είχε λεκτικό πεδίο για να δεσμεύσει:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

Το επίθημα μεταβολής `:>` σού επιτρέπει να επαναδεσμεύσεις μια τοπική μεταβλητή, κάτι χρήσιμο σε βρόχους που έχουν προστακτική αίσθηση:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
