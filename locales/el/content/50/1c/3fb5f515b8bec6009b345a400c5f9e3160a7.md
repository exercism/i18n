# Σχετικά

Τα λάμδα είναι συναρτήσεις χωρίς όνομα. Είναι βασικά ένας συντομευμένος συμβολισμός για συναρτήσεις.

Τα λάμδα μπορούν να είναι είτε [λάμδα έκφρασης](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions) είτε [λάμδα εντολών](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/lambda-expressions#statement-lambdas):

```
(input_parameters) => expression
(input_parameters) => { <statements> }
```

## Δήλωση λάμδα

Τα λάμδα που δεν επιστρέφουν τιμή (`void`) μπορούν να μετατραπούν σε τύπο delegate `Action<T>`.

```csharp
// Statement lambda
Action = () =>
{
    Console.WriteLine("No parameters");
    Console.WriteLine("Still nice, right?");
}

// Expression lambda
Action<int> = (x) => Console.WriteLine(x);
```

Τα λάμδα με τιμή επιστροφής που δεν είναι `void` μπορούν να μετατραπούν σε τύπο delegate `Func<T>`.

```csharp
// Expression lambda
Func<int, int> = (x) => x * x;

// Statement lambda
Func<string, string, bool> = (left, right) =>
{
    var equal = left == right;
    return equal;
}
```

Αν ένα λάμδα έχει μόνο μία παράμετρο, οι παρενθέσεις γύρω από την παράμετρο μπορούν να παραλειφθούν:

```csharp
// Equivalent definitions
Action<int> = (x) => Console.WriteLine(x);
Action<int> = x => Console.WriteLine(x);
```

## Ορίσματα λάμδα

Η κύρια χρήση των λάμδα είναι να τα περνάς ως ορίσματα σε άλλες μεθόδους, όπως οι περισσότερες μέθοδοι LINQ:

```csharp
var numbers = new[] { 1, 2, 3, 4 };
var doubled = numbers.Select(n => n * 2);
foreach (var number in doubled)
{
    Console.Write(number)
}
// => 2468
```
