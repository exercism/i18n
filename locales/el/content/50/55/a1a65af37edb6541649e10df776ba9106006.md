# Tests

Για να τρέξεις τα tests, εκτέλεσε την παρακάτω εντολή:

```bash
make
```

## Παραλειπόμενα tests

Το να λύσεις μια άσκηση σημαίνει να κάνεις όλα τα tests της να περάσουν.
Από προεπιλογή, όταν τρέχεις τα tests εκτελείται μόνο ένα test (το πρώτο).
Αυτό γίνεται σκόπιμα, ώστε να μπορείς να επικεντρωθείς στο να περάσει μόνο αυτό το ένα test.
Μόλις περάσει, μπορείς να ενεργοποιήσεις το επόμενο test αφαιρώντας τη γραμμή `TEST_IGNORE()`.
Όταν ενεργοποιηθούν όλα τα tests και η υλοποίησή σου τα περάσει όλα, θα έχεις λύσει την άσκηση!

## Debugging

Για να σε βοηθήσουν στο debugging, έχουν οριστεί διάφορες μακροεντολές στο αρχείο `debug.mac`.
Μπορείς να τις καλέσεις με ένα ή περισσότερα ορίσματα του κατάλληλου μεγέθους.
Για παράδειγμα:

```x86asm
debugf32 xmm0, xmm1 ; prints the value of two 32-bit floating-point numbers
debugd16 ax, cx, dx ; prints the value of three signed 16-bit integers
debugx64 [rax]      ; prints the value of a 64-bit integer in hexadecimal format
debugs rsi          ; prints a NUL-terminated string whose address is stored in `rsi`
debugu8_xmm xmm1    ; prints 16 packed 8-bit unsigned integers
```

Για να χρησιμοποιήσεις οποιαδήποτε από αυτές τις μακροεντολές, πρέπει να συμπεριλάβεις το `debug.mac` στην αρχή του αρχείου της λύσης σου:

```x86asm
%include "debug.mac"
```
