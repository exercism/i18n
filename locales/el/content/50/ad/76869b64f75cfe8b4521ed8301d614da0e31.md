# Εισαγωγή

Όπως είδαμε στην έννοια `Nothingness`, η R έχει διάφορους τρόπους να αναπαραστήσει δεδομένα που απουσιάζουν (`NULL`), είναι άγνωστα (`NA`) ή είναι μαθηματικά μη έγκυρα (`NaN`, `Inf`).
Γενικά, η R θα προσπαθήσει να τα χρησιμοποιήσει για να επισημάνει προβλήματα επί τόπου και να συνεχίσει χωρίς να πετάξει κάποια εξαίρεση.

## `stop()`

Κάποια προβλήματα είναι πολύ θεμελιώδη για να αφήσουν το πρόγραμμα να συνεχίσει.
Σε αυτή την περίπτωση, χρησιμοποίησε το `stop(msg)` για να σταματήσεις αμέσως το πρόγραμμα με ένα `Error` και να εκτυπώσεις το `msg`.

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

Παρόμοια με το `assert` σε άλλες γλώσσες, αυτή είναι ένας βολικός περιτυλιγμός για το `stop()`.
Οι παράμετροι είναι ένας οποιοσδήποτε αριθμός συνθηκών Boolean χωρισμένων με κόμμα, και το πρόγραμμα θα συνεχίσει μόνο αν είναι όλες `TRUE`.

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()` και `message()`

Αυτές είναι αποκρίσεις σε μη θανατηφόρες καταστάσεις, για παράδειγμα:

- Για να προειδοποιήσεις για ένα πρόβλημα από το οποίο το πρόγραμμα θα μπορούσε τουλάχιστον εν μέρει να ανακάμψει.
- Για να ενημερώσεις τον χρήστη για την πρόοδο ενός προγράμματος που εκτελείται για πολλή ώρα.

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

Η συνάρτηση `suppressWarnings()` μπορεί περιστασιακά να είναι χρήσιμη μέσα στο Exercism, για να αποφύγεις να μπερδέψεις τον test runner με ανεπιθύμητη έξοδο.
