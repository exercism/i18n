# Σχετικά

Οι μεταβλητές που δηλώνονται με τη λέξη-κλειδί `final` αντί για `var` μπορούν να πάρουν τιμή μόνο μία φορά.

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

Είναι σημαντικό να σημειώσεις ότι το `final` μπορεί να μην έχει το επιθυμητό αποτέλεσμα με τύπους που δεν είναι αμετάβλητοι, όπως οι πίνακες ή τα αντικείμενα:

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
