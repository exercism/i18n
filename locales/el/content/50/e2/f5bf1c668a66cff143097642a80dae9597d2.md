# Εισαγωγή

Η αποστολή σου είναι να μετατρέψεις έναν αριθμό από αραβικούς αριθμούς σε ρωμαϊκούς αριθμούς.

Σε αυτή την άσκηση μας ενδιαφέρουν μόνο οι παραδοσιακοί ρωμαϊκοί αριθμοί, στους οποίους ο μεγαλύτερος αριθμός είναι το MMMCMXCIX (ή 3.999).

~~~~exercism/note
Υπάρχουν πολλοί διαφορετικοί τρόποι για να μετατρέψεις αραβικούς αριθμούς σε ρωμαϊκούς και αντίστροφα.
Σου προτείνουμε να ακολουθήσεις πρώτα μια αφελή προσέγγιση, για να εξοικειωθείς με την έννοια των ρωμαϊκών αριθμών, και ύστερα να αναζητήσεις πιο αποδοτικούς τρόπους.

Φρόντισε να δεις το βίντεο Deep Dive στο τέλος, για να εξερευνήσεις τις διαφορετικές προσεγγίσεις που μπορείς να ακολουθήσεις!
~~~~
