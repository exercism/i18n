# Οδηγίες

Σε αυτή την άσκηση παίζεις ένα παιχνίδι ρόλων με τίτλο "Wizard and Warriors" με τους κολλητούς σου. Είσαι ο Game Master, το άτομο που έχει αναλάβει να ζωντανέψει τον κόσμο του παιχνιδιού για τους παίκτες. Ένα βασικό κομμάτι αυτού είναι να περιγράφεις το παιχνίδι στους παίκτες: ποια είναι η κατάσταση ενός χαρακτήρα, πώς μοιάζει η πόλη που επισκέπτονται κ.λπ.

Έχεις πέντε εργασίες στις οποίες περιγράφεις στους παίκτες διάφορα μέρη του παιχνιδιού.

## 1. Περιγράψε έναν χαρακτήρα

Κάθε χαρακτήρας έχει κλάση, επίπεδο και αριθμό πόντων ζωής και περιγράφεται ως: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Υλοποίησε τη (στατική) μέθοδο `GameMaster.Describe` που δέχεται ένα `Character` ως μοναδική παράμετρο και επιστρέφει την περιγραφή του.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Περιγράψε έναν προορισμό

Κάθε προορισμός έχει όνομα και αριθμό κατοίκων και περιγράφεται ως: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Υλοποίησε τη (στατική) μέθοδο `GameMaster.Describe` που δέχεται ένα `Destination` ως μοναδική παράμετρο και επιστρέφει την περιγραφή του.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Περιγράψε τη μέθοδο μετακίνησης

Οι χαρακτήρες μπορούν να ταξιδέψουν σε έναν προορισμό με μία από δύο επιλογές:

- Περπατώντας, που περιγράφεται ως: `"You're traveling to your destination by walking."`
- Έφιππος, που περιγράφεται ως: `"You're traveling to your destination on horseback."`

Υλοποίησε τη (στατική) μέθοδο `GameMaster.Describe` που δέχεται ένα `TravelMethod` ως μοναδική παράμετρο και επιστρέφει την περιγραφή του.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Περιγράψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό

Όταν ένας χαρακτήρας ταξιδεύει σε έναν προορισμό, αυτό περιγράφεται ως συνδυασμός των επιμέρους περιγραφών: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Υλοποίησε τη (στατική) μέθοδο `GameMaster.Describe` που δέχεται ένα `Character`, ένα `Destination` και ένα `TravelMethod` ως παραμέτρους και επιστρέφει την περιγραφή του.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Περιγράψε έναν χαρακτήρα που ταξιδεύει σε έναν προορισμό χωρίς να προσδιορίσεις τη μέθοδο μετακίνησης

Στις περισσότερες περιπτώσεις, οι χαρακτήρες ταξιδεύουν σε έναν προορισμό περπατώντας. Για ευκολία, οι παίκτες μπορούν να παραλείψουν να αναφέρουν τη μέθοδο μετακίνησής τους, οπότε θεωρείται ότι ταξιδεύουν περπατώντας. Υλοποίησε τη (στατική) μέθοδο `GameMaster.Describe` που δέχεται ένα `Character` και ένα `Destination` ως παραμέτρους και επιστρέφει την περιγραφή του.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
