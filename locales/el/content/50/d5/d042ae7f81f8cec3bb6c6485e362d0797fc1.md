# Tests

Απλώς πληκτρολόγησε `make chez` αν χρησιμοποιείς το ChezScheme ή `make guile` αν χρησιμοποιείς το GNU Guile.

## Χρήση του REPL

- Πληκτρολόγησε `test.scm` στο prompt του REPL.
- Ανάπτυξε τη λύση σου στο αρχείο `problem.scm`, κάνοντας επαναφόρτωση όσο προχωράς.
- Τρέξε `(test)` για να ελέγξεις τη λύση σου.
