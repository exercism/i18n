# Σχετικά

Η Java είναι μια γλώσσα στατικής τυποποίησης, που σημαίνει ότι τα πάντα έχουν τύπο κατά τη μεταγλώττιση.
Η εκχώρηση μιας τιμής σε ένα όνομα ονομάζεται ορισμός μεταβλητής.

```java
int explicitVar = 10; // Explicitly typed
```

Η τιμή μιας μεταβλητής μπορεί να εκχωρηθεί και να ενημερωθεί χρησιμοποιώντας τον [τελεστή `=`][assignment].
Μόλις οριστεί, ο τύπος μιας μεταβλητής δεν μπορεί ποτέ να αλλάξει.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Η Java είναι μια αντικειμενοστρεφής γλώσσα και απαιτεί όλες οι συναρτήσεις να ορίζονται μέσα σε μια _κλάση_, η οποία ορίζεται με τη [`class` λέξη-κλειδί][classes].
Μια συνάρτηση μέσα σε μια κλάση ονομάζεται _μέθοδος_.
Κάθε [μέθοδος][methods] μπορεί να έχει μηδέν ή περισσότερες παραμέτρους.
Όλες οι παράμετροι πρέπει να έχουν ρητά δηλωμένο τύπο, δεν υπάρχει συμπερασμός τύπου για τις παραμέτρους.
Παρομοίως, ο τύπος επιστροφής πρέπει επίσης να δηλώνεται ρητά.
Οι τιμές επιστρέφονται από τις συναρτήσεις με τη [`return` λέξη-κλειδί][return].
Για να μπορεί μια μέθοδος να καλείται από άλλες κλάσεις, πρέπει να προστεθεί ο τροποποιητής πρόσβασης `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Η κλήση μιας μεθόδου γίνεται καθορίζοντας το όνομα της κλάσης και της μεθόδου της και περνώντας ορίσματα για κάθε παράμετρο της μεθόδου.

```java
int sum = new Calculator().add(1, 2);
```

Αν μια μέθοδος δεν χρησιμοποιεί καθόλου _κατάσταση_ της κλάσης (όπως συμβαίνει σε αυτή την άσκηση), η μέθοδος μπορεί να γίνει _static_ χρησιμοποιώντας τον τροποποιητή `static`.
Παρομοίως, αν μια κλάση έχει μόνο static μεθόδους, μπορεί κι αυτή να γίνει static χρησιμοποιώντας τον τροποποιητή `static`.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Η εμβέλεια στη Java ορίζεται ανάμεσα στους χαρακτήρες `{` και `}`.

Η Java υποστηρίζει δύο τύπους [σχολίων][comments].
Τα σχόλια μονής γραμμής ξεκινούν με `//` και τα σχόλια πολλαπλών γραμμών τοποθετούνται μεταξύ `/*` και `*/`.

Οι ακέραιες τιμές ορίζονται ως ένα ή περισσότερα (συνεχόμενα) ψηφία και υποστηρίζουν τους [προεπιλεγμένους μαθηματικούς τελεστές][operators].
