# Προσθήκη οδηγιών

## Υποδείξεις

Για αυτή την άσκηση, το ακόλουθο χαρακτηριστικό που προσφέρει η F# θα σου φανεί χρήσιμο:

- [Αναδρομή ουράς](https://blogs.msdn.microsoft.com/fsharpteam/2011/07/08/tail-calls-in-f/) Απόφυγε τις υπερχειλίσεις στοίβας με μεγάλη είσοδο χρησιμοποιώντας αναδρομή ουράς. Ενώ δεν υπάρχουν περιπτώσεις δοκιμών που να το ελέγχουν ρητά, η χρήση αναδρομής ουράς οδηγεί σε πιο αποδοτική λύση. Μια άλλη καλή πηγή για την αναδρομή ουράς είναι [αυτή η ανάρτηση ιστολογίου](http://blog.ploeh.dk/2015/12/22/tail-recurse/).
- [Εξαγωγή τύπων](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/generics/#implicitly-generic-constructs) Ο μεταγλωττιστής της F# μπορεί να εξάγει αυτόματα τύπους, που σημαίνει ότι συχνά δεν χρειάζεται να προσθέσεις καθόλου τύπους. Για περισσότερες πληροφορίες σχετικά με το πώς λειτουργεί αυτό και τα πλεονεκτήματά του, δες [αυτή τη σελίδα](https://fsharpforfunandprofit.com/posts/type-inference/).
