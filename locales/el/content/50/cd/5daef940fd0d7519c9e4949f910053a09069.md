# Εσωτερικοί σύνδεσμοι

Οι σύνδεσμοι που αποδίδονται μέσω του Markdown parser του Exercism ελέγχονται για το αν είναι εσωτερικοί και, αν είναι, μπορεί να διακοσμηθούν με tooltips.

Ένα tooltip για μια έννοια μπορεί να μοιάζει κάπως έτσι:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Χρήση

Δεν υπάρχει ειδική σύνταξη για να διακοσμούνται οι σύνδεσμοι με αυτόν τον τρόπο.
Αντ' αυτού, ελέγχουμε αν το href του συνδέσμου ακολουθεί μία από τις δύο παρακάτω μορφές:

- Ένα URL, π.χ. https://exercism.org/tracks/ruby/concepts/basics
- Μια απόλυτη διαδρομή, π.χ. /tracks/ruby/concepts/basics

Προς το παρόν δεν υποστηρίζουμε σχετικά URLs (π.χ. αυτά που ξεκινούν με `./` ή `../`), γιατί ο Markdown parser δεν γνωρίζει το πλαίσιο του εγγράφου που αποδίδει, το πλαίσιο στο οποίο αποδίδει, ούτε τη δομή ενός αποθετηρίου git.

## Εναλλακτικές

Αντί να χρησιμοποιείς κανονικούς συνδέσμους, μπορείς να αποδώσεις Widgets.
Αυτά χρησιμοποιούνται συνήθως στο τέλος ενός εγγράφου για να προτείνουν επιπλέον ανάγνωση ή καλές ασκήσεις για να μάθεις κάτι από αυτές.

Δες [την τεκμηρίωση των Widgets](/docs/building/markdown/widgets) για περισσότερες λεπτομέρειες.
