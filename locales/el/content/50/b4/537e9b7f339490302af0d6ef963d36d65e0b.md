# Επανάληψη πάνω σε ένα map

Η χρήση ενός map είναι μια απόλυτα φυσική ιδέα σε αυτή την περίπτωση. Ωστόσο, πρόσεξε: επειδή τα map υλοποιούνται ως πίνακες κατακερματισμού, η σειρά των κλειδιών τους δεν είναι εγγυημένη. Μάλιστα, όταν κάνεις επανάληψη πάνω στα κλειδιά ενός map, αυτά θα βρίσκονται κάθε φορά σε διαφορετική, τυχαία σειρά. Δες την ενότητα `Iteration order` στο [Go maps in action](https://blog.golang.org/go-maps-in-action). Αν η σειρά επανάληψης έχει σημασία, ένα slice είναι καλύτερη επιλογή.
