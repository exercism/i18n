# Οδηγίες

Σε αυτήν την άσκηση θα γράψεις κώδικα για να παρακολουθείς κωδικούς διεθνούς κλήσης μέσω ενός λεξικού κωδικών κλήσης.

Το λεξικό χρησιμοποιεί έναν ακέραιο για τα κλειδιά του (τον κωδικό κλήσης) και μια συμβολοσειρά (όνομα χώρας) για τις τιμές του.

Έχεις 9 εργασίες που αφορούν τη στατική κλάση `DialingCodes`.

## 1. Δημιούργησε ένα νέο λεξικό

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.GetEmptyDictionary()` που επιστρέφει ένα κενό λεξικό.

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. Δημιούργησε ένα προσυμπληρωμένο λεξικό

Υπάρχει ένα προσυμπληρωμένο λεξικό που περιέχει τους εξής 3 κωδικούς κλήσης: "United States of America" με κωδικό 1, "Brazil" με κωδικό 55 και "India" με κωδικό 91. Υλοποίησε τη (στατική) μέθοδο `DialingCodes.GetExistingDictionary()` ώστε να επιστρέφει το προσυμπληρωμένο λεξικό:

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. Πρόσθεσε μια χώρα σε ένα κενό λεξικό

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.AddCountryToEmptyDictionary()` που δημιουργεί ένα λεξικό και προσθέτει σε αυτό έναν κωδικό κλήσης και το σχετικό όνομα χώρας.

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. Πρόσθεσε μια χώρα σε ένα υπάρχον λεξικό

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.AddCountryToExistingDictionary()` που προσθέτει έναν κωδικό κλήσης και το σχετικό όνομα χώρας σε ένα μη κενό λεξικό.

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. Βρες το όνομα χώρας που αντιστοιχεί σε έναν κωδικό κλήσης

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.GetCountryNameFromDictionary()` που παίρνει έναν κωδικό κλήσης και επιστρέφει το αντίστοιχο όνομα χώρας. Αν ο κωδικός κλήσης δεν περιέχεται στο λεξικό, τότε επιστρέφεται μια κενή συμβολοσειρά.

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. Έλεγξε ότι μια χώρα υπάρχει στο λεξικό

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.CheckCodeExists()` για να ελέγξεις αν ένας κωδικός κλήσης υπάρχει στο λεξικό.

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. Ενημέρωσε το όνομα μιας χώρας

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.UpdateDictionary()` που παίρνει έναν κωδικό κλήσης και αντικαθιστά το αντίστοιχο όνομα χώρας στο λεξικό με το όνομα χώρας που περνιέται ως παράμετρος. Αν ο κωδικός κλήσης δεν υπάρχει στο λεξικό, τότε το λεξικό παραμένει ως έχει.

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. Αφαίρεσε μια χώρα από το λεξικό

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.RemoveCountryFromDictionary()` που παίρνει έναν κωδικό κλήσης και αφαιρεί την αντίστοιχη καταγραφή, κωδικό κλήσης + όνομα χώρας, από το λεξικό.

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. Βρες τη χώρα με το μεγαλύτερο όνομα

Υλοποίησε τη (στατική) μέθοδο `DialingCodes.FindLongestCountryName()` που θα επιστρέψει το όνομα της χώρας με το μεγαλύτερο όνομα από αυτές που είναι αποθηκευμένες στο λεξικό.

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
