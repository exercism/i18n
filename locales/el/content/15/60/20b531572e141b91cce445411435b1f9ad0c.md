# Εισαγωγή

Η απαρίθμηση είναι η διαδικασία κατά την οποία διασχίζεις μια συλλογή (`Array`, `Hash` κ.λπ.) και εκτελείς κάποια ενέργεια σε κάθε αντικείμενο.

Η απαρίθμηση είναι μια βασική έννοια στη Ruby και χρησιμοποιείται για ταξινόμηση (`sort_by`), ομαδοποίηση (`group_by`), αντιστοίχιση (`map`), αναγωγή (`reduce`) και πολλά άλλα.
Πιο συχνά θα συναντήσεις την απαρίθμηση ως τον ιδιωματικό τρόπο για να διασχίζεις συλλογές, αντί να χρησιμοποιείς βρόχους.

Μια απλή απαρίθμηση που κάνει χρήση των `map` και `with_index` μοιάζει κάπως έτσι:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
