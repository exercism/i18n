# Εισαγωγή

Η Python έχει τρεις διαφορετικούς τύπους ενσωματωμένων αριθμών: ακέραιους ([`int`][int]), κινητής υποδιαστολής ([`float`][float]) και μιγαδικούς ([`complex`][complex]).
Τα κλάσματα ([`fractions.Fraction`][fractions]) και οι δεκαδικοί ([`decimal.Decimal`][decimals]) είναι επίσης διαθέσιμα μέσω εισαγωγής από την τυπική βιβλιοθήκη.

Οι ακέραιοι αριθμοί, στους οποίους περιλαμβάνονται οι δεκαεξαδικοί ([_`hex()`_][hex]), οι οκταδικοί ([_`oct()`_][oct]) και οι δυαδικοί ([_`bin()`_][bin]) αριθμοί **χωρίς** δεκαδικά ψηφία, χαρακτηρίζονται επίσης ως `ints`:

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

Οι αριθμοί που περιέχουν υποδιαστολή (με ή χωρίς κλασματικά μέρη) χαρακτηρίζονται ως `floats`:

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## Αριθμητικές πράξεις

Η Python υποστηρίζει πλήρως αριθμητικές πράξεις μεταξύ αυτών των διαφορετικών τύπων αριθμών και θα μετατρέψει τους στενότερους αριθμούς ώστε να ταιριάζουν με τους λιγότερο στενούς ομολόγους τους όταν χρησιμοποιούνται με τους δυαδικούς αριθμητικούς τελεστές (`+`, `-`, `*`, `/`, `//` και `%`).

### Πρόσθεση και αφαίρεση

Οι τελεστές πρόσθεσης και αφαίρεσης συμπεριφέρονται όπως στα συνηθισμένα μαθηματικά.
Αν ένας ή περισσότεροι από τους τελεστέους είναι `float`, οι υπόλοιποι `int` θα μετατραπούν επίσης σε `float`:

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### Πολλαπλασιασμός

Όπως με την πρόσθεση και την αφαίρεση, ο πολλαπλασιασμός θα μετατρέψει τους στενότερους αριθμούς ώστε να ταιριάζουν με τους λιγότερο στενούς ομολόγους τους:

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### Διαίρεση

Η διαίρεση επιστρέφει πάντα ένα `float`, ακόμα και αν το αποτέλεσμα είναι ακέραιος αριθμός:

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### Ακέραια διαίρεση

Αν χρειάζεται αποτέλεσμα `int`, μπορείς να χρησιμοποιήσεις την ακέραια διαίρεση για να περικόψεις το αποτέλεσμα.
Η ακέραια διαίρεση εκτελείται με τον τελεστή `//`:

```python
>>> 6//5
1

>>> 6//2
3
```

### Υπόλοιπο

Ο τελεστής υπολοίπου (`%`) επιστρέφει το υπόλοιπο της διαίρεσης των δύο τελεστέων:

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

Ένας άλλος τρόπος να δεις το 5 % 3:

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## Στρογγύλευση

Η Python παρέχει μια ενσωματωμένη συνάρτηση [`round(number, <decimal_places>)`][round] για να στρογγυλοποιήσεις έναν αριθμό κινητής υποδιαστολής σε έναν δεδομένο αριθμό δεκαδικών ψηφίων.
Αν δεν καθοριστεί αριθμός δεκαδικών ψηφίων, ο αριθμός στρογγυλοποιείται στον πλησιέστερο ακέραιο και επιστρέφει ένα `int`:

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## Προτεραιότητα και παρενθέσεις

Η Python σου επιτρέπει να χρησιμοποιείς παρενθέσεις για να ομαδοποιήσεις εκφράσεις.
Αυτό είναι χρήσιμο όταν θέλεις να παρακάμψεις την προεπιλεγμένη σειρά των πράξεων.

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Η Python ακολουθεί τον κανόνα [PEMDAS][pemdas] για την προτεραιότητα των τελεστών.
Αυτό σημαίνει ότι οι υπολογισμοί μέσα σε `()` έχουν την υψηλότερη προτεραιότητα, ακολουθούμενοι από `**`, μετά `*`, `/`, `//`, `%`, `+` και `-`:

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## Ακρίβεια και αναπαράσταση

Οι ακέραιοι στην Python έχουν [αυθαίρετη ακρίβεια][arbitrary-precision]. Ο αριθμός των ψηφίων περιορίζεται μόνο από τη διαθέσιμη μνήμη του συστήματος υποδοχής.

Οι αριθμοί κινητής υποδιαστολής συνήθως υλοποιούνται χρησιμοποιώντας έναν `double` στη C (_15 δεκαδικά ψηφία ακρίβειας_), αλλά η αναπαράστασή τους ποικίλλει ανάλογα με το σύστημα υποδοχής.
Οι μιγαδικοί αριθμοί έχουν ένα `real` και ένα `imaginary` μέρος, τα οποία αναπαρίστανται και τα δύο από αριθμούς κινητής υποδιαστολής.

Για πιο λεπτομερείς συζητήσεις των ζητημάτων και των περιορισμών της αριθμητικής κινητής υποδιαστολής σε διάφορες γλώσσες προγραμματισμού, ρίξε μια ματιά στο [0.30000000000000004.com][0.30000000000000004.com] και στο [The Python Tutorial][floating point math].
