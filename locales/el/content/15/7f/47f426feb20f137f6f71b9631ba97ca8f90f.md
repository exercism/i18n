# Υποδείξεις

## Γενικά

- Για να έχεις πρόσβαση σε μεταβλητές στιγμιοτύπου και να τις ορίσεις, γράφεις `@` και μετά το όνομα της μεταβλητής.

## 1. Αρχικοποίησε το `TaskHandler`

- Για να δημιουργήσεις ένα `Proc`, χρησιμοποίησε τη σύνταξη `-> (args) { block }`.
- Όταν ένα `Proc` ορίζεται για μια μεταβλητή στιγμιοτύπου, ο τύπος του πρέπει να δηλώνεται ρητά.
  Αυτό μπορεί να γίνει προσθέτοντας `: Proc(<arg_type>, <return_type>)` μετά το όνομα της μεταβλητής.
  Ή με τη σύνταξη `-> (arg_1 : <arg_type>) : <return_type> { block }`.
- Το `Proc` θα πρέπει να συγκρίνει αν το όρισμα είναι μεγαλύτερο ή ίσο με το 0.

## 2. Ενημέρωσε τη λογική της συνθήκης της εργασίας

- Η μέθοδος θα πρέπει να δέχεται ένα μπλοκ ως όρισμα και να το εκχωρεί στη μεταβλητή στιγμιοτύπου `@task_condition_logic`.

## 3. Εκτέλεσε την επόμενη εργασία

- Για να εκτελέσεις ένα `Proc`, μπορείς να χρησιμοποιήσεις τη μέθοδο `call`, η οποία δέχεται τα ορίσματα του Proc.
