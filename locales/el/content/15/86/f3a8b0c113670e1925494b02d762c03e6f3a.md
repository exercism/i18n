# Σχετικά

Η άσκηση δείχνει τη συμπεριφορά διάφορων αριθμητικών τύπων όταν υπερχειλίζουν, δηλαδή όταν η χωρητικότητά τους δεν επαρκεί για να περιέχει την τιμή που προκύπτει από έναν υπολογισμό, όπως μια αριθμητική πράξη ή μια μετατροπή τύπου.

- Οι ακέραιοι [χωρίς πρόσημο][integral-numeric-types] (`byte`, `ushort`, `uint`, `ulong`) θα επιστρέψουν κυκλικά στο μηδέν (η μέγιστη τιμή του τύπου + 1 λειτουργεί ως μέτρο), εκτός αν, [γενικά μιλώντας][checked-compiler-setting], βρίσκονται μέσα σε ένα μπλοκ [`checked`][checked-and-unchecked], οπότε πετιέται ένα στιγμιότυπο της `OverflowException`. Οι `int` και `long` θα συμπεριφερθούν παρόμοια, μόνο που θα επιστρέψουν κυκλικά στο `int.MinValue` και στο `long.minValue` αντίστοιχα.

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;  // overflow exception is thrown
}

// or

int expr2 = checked(int.MaxValue + one);  // overflow exception is thrown
```

- Αν μια παράσταση literal πρόκειται να προκαλέσει υπερχείλιση στη μεταβλητή στην οποία ανατίθεται, τότε προκύπτει σφάλμα κατά τη μεταγλώττιση.
- Η κατάσταση `checked` ισχύει μόνο για εκφράσεις που βρίσκονται απευθείας μέσα στο μπλοκ. Οι καταστάσεις υπερχείλισης σε συναρτήσεις που καλούνται δεν πιάνονται.
- Οι τύποι [`float` και `double`][floating-point-numeric-types] θα υιοθετήσουν μια κατάσταση _άπειρου_, η οποία μπορεί να ελεγχθεί με `float.IsInfinity()` κ.λπ.

```csharp
double d = double.MaxValue;
d *= 2d;
Double.IsFinite(d)
// => false
```

- Οι αριθμοί τύπου [`decimal`][floating-point-numeric-types] θα έχουν ως αποτέλεσμα να πεταχτεί ένα στιγμιότυπο της `OverflowException`.
- Υπάρχει μια αντίστοιχη λέξη-κλειδί `unchecked` για περιπτώσεις όπου θέλεις να αντιστρέψεις το αποτέλεσμα του `unchecked` μέσα σε ένα μπλοκ `checked` ή όταν έχει χρησιμοποιηθεί η ρύθμιση του μεταγλωττιστή.

Οι υπερχειλίσεις που συμβαίνουν χωρίς να πεταχτεί κάποια εξαίρεση μπορούν να αποδειχτούν προβληματικές, γιατί γενικά ισχύει ότι όσο νωρίτερα μπορεί να αναφερθεί μια κατάσταση σφάλματος, τόσο το καλύτερο.

Τα προβλήματα με τις υπερχειλίσεις για τους `int` και `float` μπορούν να μετριαστούν αν αναθέσεις το αποτέλεσμα σε μια μεταβλητή τύπου `long`, `decimal` ή `double`.

Αν οι μεγάλοι ακέραιοι είναι απαραίτητοι στον κώδικά σου, τότε η χρήση του τύπου [`BigInteger`][big-integer] είναι μια επιλογή.

Φυσικά υπάρχουν περιπτώσεις στις οποίες είναι θεμιτό να αφήσεις έναν ακέραιο να επιστρέψει κυκλικά, ειδικά στην περίπτωση των τιμών χωρίς πρόσημο. Κλασική περίπτωση είναι οι κωδικοί κατακερματισμού που χρησιμοποιούν το πλάτος του ακέραιου ως ένα είδος μέτρου.

Συνήθως θα διαπιστώσεις ότι σε κώδικες δεν γίνεται συχνά έλεγχος όταν ένα `uint` ή ένα `ulong` χρησιμοποιείται ως αναγνωριστικό, γιατί θεωρείται ότι δημιουργεί περισσότερα προβλήματα από όσα αξίζει.
