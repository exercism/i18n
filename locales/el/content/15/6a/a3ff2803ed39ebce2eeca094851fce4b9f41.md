# Εισαγωγή

Το module [`fractions`][fractions] μάς επιτρέπει να δημιουργούμε και να δουλεύουμε με [`rational numbers`][rational]: κλάσματα με έναν ακέραιο αριθμητή διαιρεμένο με έναν ακέραιο παρονομαστή.
Για παράδειγμα, μπορούμε να αποθηκεύσουμε το `2/3` ως ακριβές κλάσμα αντί για την προσεγγιστική τιμή `float` `0.6666...`.

Σε αντίθεση με τους αριθμούς `int`, `float` και `complex`, τα κλάσματα δεν έχουν κυριολεκτική μορφή.
Ωστόσο, ο κατασκευαστής κλασμάτων είναι αρκετά ευέλικτος.

Το πιο προφανές είναι ότι μπορεί να πάρει δύο ακέραιους ως ορίσματα.
Οι κοινοί παράγοντες αφαιρούνται αυτόματα, μετατρέποντας το κλάσμα στην "ανάγωγη μορφή" του (_τους μικρότερους ακέραιους που αντιπροσωπεύουν με ακρίβεια το κλάσμα_):

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

Ο κατασκευαστής κλασμάτων μπορεί επίσης να αναλύσει μια αναπαράσταση συμβολοσειράς:

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

Τα κλάσματα μπορούν επίσης να λειτουργήσουν με παραμέτρους `float`, αλλά αυτό μπορεί να προκαλέσει προβλήματα με την προσεγγιστική φύση της αναπαράστασης της δεκαδικής τιμής εσωτερικά ως δυαδικό.
Για περισσότερα σχετικά με αυτό το ζήτημα αναπαράστασης, δες τον ιστότοπο [0.30000000000000004][0.30000000000000004] και το [Αριθμητική Κινητής Υποδιαστολής: Ζητήματα και Περιορισμοί][fp-issues] στην τεκμηρίωση της Python.

Για ένα πιο αξιόπιστο αποτέλεσμα όταν χρησιμοποιείς αριθμούς κινητής υποδιαστολής με κλάσματα, υπάρχει η μέθοδος `<fraction>.limit_denominator()`.


## Αριθμητική με κλάσματα

Οι συνήθεις [`arithmetic operators`][operators] `+ - * / **` θα λειτουργούν με κλάσματα, όπως και με άλλους αριθμητικούς τύπους.

Ακέραιοι και άλλα κλάσματα `Fraction` μπορούν να συμπεριληφθούν στην εξίσωση και να δώσουν αποτέλεσμα `Fraction`.
Η συμπερίληψη ενός `float` στην παράσταση δίνει αποτέλεσμα `float`, με επακόλουθη (πιθανή) απώλεια ακρίβειας:

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

Διάφορες τυπικές αριθμητικές συναρτήσεις της Python δίνουν επίσης το αποτέλεσμα που θα περίμενες δουλεύοντας με τύπους `int` και `float`:

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
