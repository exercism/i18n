# 提示

## 通用

- 特别注意指针语法。你会用到`*`（解引用运算符）和`->`（通过指针访问成员）。
- 必要时务必检查空指针（`nullptr`），避免访问无效内存。
- 即使代码还没写完，也可以运行测试；有个大致的结构就足以看到测试结果。
- 测试用到的所有函数都必须在头文件中声明。
- 如果程序崩溃或行为异常，通常是因为解引用了空指针。仔细检查你是否正确处理了`nullptr`。
- 使用指针运算时，确保不要超出传感器数组的边界。超出数组容量可能导致内存问题。

## 1. 检查传感器连接（`connection_check`）

- 这个任务主要是判断指针是否为空。
- 用比较运算符`!=`检查指针是否有效。
- 如果不确定自己检查指针的方式对不对，就想一想`nullptr`代表什么（没有有效的内存地址）。


## 2. 统计传感器的活动（`activity_counter`）

- 你需要遍历传感器数组。在 C++ 中，数组可以看作指向其第一个元素的指针。
- 用指针运算（`sensor_array + i`）访问下标为`i`的传感器。
- `->`运算符用于通过指针访问结构体的成员。

### 示例

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```

## 3. 警报控制（`alarm_control`）

- 首先，在访问传感器之前先检查指针是否为空。
- 用`->`运算符访问`pillar_men_sensor`结构体的`activity`成员。
- 仔细想一想，如果传感器的活动值为`0`，应该发生什么。警报应该被触发吗？

## 4. 用`uv_alarm`函数检查数据异常

- 用`&`运算符把指向传感器数据数组的指针传给`uv_light_heuristic`函数。
- 确保在访问传感器数据之前正确检查空指针。
- 把`uv_light_heuristic`的返回值与传感器的`activity`值比较，判断警报是否应该触发。
