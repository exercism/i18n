# 简介

Kotlin 的`when`是一个条件表达式，用于在多个选项中做选择。
它类似于 Java 中的`switch`，但比一串`if` ... `else if` ... `else`更灵活。

和`if`一样，`when`也可以用作产生值的表达式。

## 匹配值

在括号中给`when`一个要匹配的值。
每个分支都会拿这个值来比较，直到有一个分支匹配成功：

```kotlin
val animal = "chicken"
val type = when (animal) {
    "chicken" -> "bird"
    "poodle" -> "dog"
    else -> "unknown"
}
// type => "bird"
```

- 每个分支的写法是`pattern -> result`。
- 分支从上到下依次尝试，直到找到匹配项。
  只有第一个匹配的分支会执行。
- 对于上面没有列出的值，用`else`处理（类似于`if`链中最后的`else`）。

这类似于[模式匹配][pattern-matching]。
`pattern`可以是要匹配的值，也可以用`is`按类型匹配：

```kotlin
fun typeText(subject: Any): String {
    return when(subject) {
        is Animal -> "Animal"
        is Fruit -> "Fruit"
        is String -> "Text"
        else -> "Unknown"
    }
}
```

也可以用`in`检查它是否包含在区间、集合、字符串或其他任何带有`contains`方法的对象中：

```kotlin
fun describe(number: Int, position: String) {
    // Range
    when(number) {
        in 1..10 -> println("From 1 to 10")
        in 11..20 -> println("From 11 to 20")
    }

    // Collection
    when(number) {
        in listOf(2, 4, 6) -> println("small even")
        in listOf(3, 5, 7) -> println("small odd")
    }

    // String
    when(position) {
        in "center middle" -> println("inner")
        in "left right boundary" -> println("outer")
    }
}
```

## 守卫条件

在匹配值时，可以在模式后面加一个`if`，写上额外的条件。
这些条件叫做守卫条件。

```kotlin
val x = 5
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else -> "other"
}
// description => "x is 5, y is even"
```

甚至可以写`else if`。

```kotlin
val x = 7
val y = 10
val description = when (x) {
    5 if y % 2 == 0 -> "x is 5, y is even"
    else if y % 2 == 0 -> "y is an even number"
    else -> "other"
}
// description => "y is an even number"
```


## 匹配条件

另一种写法是省略值，在每个分支上写布尔条件：

```kotlin
val x = 5
val y = 8
val description = when {
    x % 2 != 0 -> "x is odd"
    y % 2 == 0 -> "y is even"
    else -> "neither condition matched first"
}
// description => "x is odd"
```

同样，分支从上到下依次检查，只有第一个条件为`true`的分支会执行。

## 把`when`用作表达式

当使用`when`的结果时（把它赋给变量、从函数中返回，等等），必须覆盖所有可能的情况。

- 按值匹配时，要加上`else`，除非所有可能的值都已经处理（例如`Boolean`或`enum`的所有值）。
- 按条件匹配时，`else`分支是必需的，因为编译器无法知道你的条件是否覆盖了所有情况。

```kotlin
fun label(n: Int): String = when (n) {
    0 -> "zero"
    1 -> "one"
    else -> "other"
}
```
