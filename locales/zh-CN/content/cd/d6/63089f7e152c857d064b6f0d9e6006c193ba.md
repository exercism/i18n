# Debug

测试失败时，会显示一条消息，说明哪里出了问题，以及对应的输入是什么。另外，凡是你打印到“标准输出”的内容也都会显示出来，这一点你可以加以利用。你可以用`println!`向标准输出写入内容：

```rust
println!("Debug message");
```

使用大括号`{}`可以打印变量或表达式的值：

```rust
let secret_number = 4321;
println!("My banking password is {}, which is better than {}.", secret_number, 1200 + 34);
```

注意，并不是所有类型都能这样打印，只有那些能毫无歧义地呈现给用户的类型才可以。例如，向量（列表）就不能这样打印，因为不清楚一个向量应该怎样展示给用户！对于这些其他类型，你可以用`{:?}`让`println!`宏使用_调试格式化_：

```rust
let words = vec!["hello", "world"];
println!("words that are often combined: {:?}", words);
```

这种表示形式只打算给开发者看。举个例子：

还有一个很方便的`dbg!`宏，可以用它在原处调试大型表达式，而不必把它拆成一个个单独的变量声明。

假设我们有下面这个表达式：

```rust
"hello world".split(' ').collect::<Vec<_>>().join("-")
```

现在我们想看看调用`collect`返回了什么。我们可以这样做：

```rust
let my_temporary_debug_variable = "hello world".split(' ').collect::<Vec<_>>();
println!("{:?}", my_temporary_debug_variable);
my_temporary_debug_variable.join("-")
```

但这很麻烦！我们不想仅仅为了能调试，就把精心写好的表达式重写一遍。下面隆重请出：`dbg!`

```rust
dbg!(
    "hello world".split(' ').collect::<Vec<_>>()
).join("-")
```

这里的空白只是为了看得更清楚。你可以把任何表达式包进`dbg!()`里，它会打印该值（使用调试格式化）。之后你仍然可以在更大的表达式里继续使用这个值，就好像`dbg!`根本不存在一样。

调试愉快！
