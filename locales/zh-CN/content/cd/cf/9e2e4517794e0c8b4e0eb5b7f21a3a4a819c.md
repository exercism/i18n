# 简介

Gleam 中的正则表达式遵循**PCRE**规范（**P**erl **C**ompatible **R**egular **E**xpressions），与 Java、JavaScript、Ruby 等其他流行语言类似。

`gleam/regex`模块提供了处理正则表达式的函数。

~~~~exercism/note
本练习假定你已经了解正则表达式语法，包括字符类、量词、分组和捕获。

如果你需要复习正则表达式方面的知识，可以参考以下资料：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

创建正则表达式最常见的方式是使用`regex.from_string`函数。

```gleam
let assert Ok(re) = regex.from_string("test")
```

如果正则表达式语法无效，`regex.from_string`函数会返回一个`Error`，所以这里使用了 let 断言来确保正则表达式有效。

可以用`regex.check`函数检查某个正则表达式是否匹配一个字符串。

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## 捕获

如果你想用正则表达式捕获子字符串，可以使用`regex.scan`函数，它会返回一个匹配结果的数组。

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## 修饰符

通过`regex.compile`函数创建正则表达式并传入选项，可以改变它的行为。

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
