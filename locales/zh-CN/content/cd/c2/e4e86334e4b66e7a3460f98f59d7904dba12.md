# 提示

## 1. 用正则表达式捕获生成卡片所需的信息

- `\p{L}`会匹配任何语言中的任意字母。
- 你可以使用下面的表达式来捕获这些信息：
  ```julia
  re = r"""»(.*)«                     # title
           \ –\ (.*?)                 # name
           (?:\ \((.*?)\)|)           # optional pronouns
           (?:,\ from\ (.*?)|).       # optional organisation
           \ Start:\ (.*?),\          # start time
           (?:Q&A:\ (.*?),\ |)        # optional Q&A time
           End:\ (.*)                 # end time
        """x
  ```
