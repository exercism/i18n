# 说明

在这个练习中，你需要实现经典 20 世纪 80 年代街机游戏 [Pac-Man][Pac-Man] 的一些规则。

一共有六个任务，其中四个是与游戏状态相关的规则。

> _不用担心函数中的实参是如何得来的，只需专注于组合这些实参，返回预期的结果。_


## 0. 定义一个能量状态

定义一个名为 `PowerOn` 的变量，并赋予它一个值，表示能量确实处于开启状态。

```powershell
> $PowerOn
True
```

## 1. 定义 Pac-Man 能否吃掉幽灵

定义 `EatGhost` 函数，它接收两个形参（_Pac-Man 是否有生效的能量豆_ 和 _Pac-Man 是否正碰到幽灵_），并返回一个布尔值，表示 Pac-Man 是否能吃掉幽灵。
只有当 Pac-Man 有生效的能量豆并且正碰到幽灵时，该函数才应返回 `True`。

```powershell
> EatGhost -ActivePower $false -TouchingGhost $true
False
```

## 2. 定义 Pac-Man 是否得分

定义 `Score` 函数，它接收两个形参（_Pac-Man 是否正碰到能量豆_ 和 _Pac-Man 是否正碰到豆子_），并返回一个布尔值，表示 Pac-Man 是否得分。
如果 Pac-Man 正碰到能量豆或豆子，该函数应返回 `True`。

```powershell
> Score -TouchDot $true -TouchPowerPellet $true
4
```

## 3. 定义 Pac-Man 是否失败

定义 `Lose` 函数，它接收两个形参（_Pac-Man 是否有生效的能量豆_ 和 _Pac-Man 是否正碰到幽灵_），并返回一个布尔值，表示 Pac-Man 是否失败。
如果 Pac-Man 正碰到幽灵，并且没有生效的能量豆，该函数应返回 `True`。

```powershell
> Lose -ActivePower $false -TouchingGhost $true
True
```

## 4. 定义 Pac-Man 是否获胜

定义 `Win` 函数，它接收三个形参（_Pac-Man 是否已经吃掉了所有豆子_、_Pac-Man 是否有生效的能量豆_ 和 _Pac-Man 是否正碰到幽灵_），并返回一个布尔值，表示 Pac-Man 是否获胜。
如果 Pac-Man 已经吃掉了所有豆子，并且没有根据第 3 部分中定义的形参判定为失败，该函数应返回 `True`。

```powershell
> Win -EatenAllDots $false -ActivePower $true -TouchingGhost $false
False
```

## 5. 为获胜条件编写 Synopsis

回到上一个函数，在注释块中添加一个 `Synopsis` 部分，简要描述如何赢得游戏。
描述至少要有十个字符长。

```powershell
function MyFunc($Arg) {
    <#
    .DESCRIPTION
    This is a demonstration of the comment-based help with the description keyword.
    #>
}
```
