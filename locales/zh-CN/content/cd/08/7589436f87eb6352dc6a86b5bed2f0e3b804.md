# 说明

我们每个人都从亲生父母那里继承了一套被称为 DNA 的化学指令，它们影响着我们身体如何构建。已知的一切生命都离不开 DNA！

> 注意：完成这个练习并不需要了解任何关于核苷酸或 DNA 的知识。

DNA 是由其他化学物质构成的长链，其中最重要的是四种核苷酸：腺嘌呤、胞嘧啶、鸟嘌呤和胸腺嘧啶。一条 DNA 链可以包含数十亿个这四种核苷酸，它们出现的顺序非常重要！
我们把一段 DNA 中这些核苷酸的排列顺序称为“DNA 序列”。

我们用这四种核苷酸的有序集合来表示 DNA 序列，常见的做法是使用一串字符，例如用“ATTACG”表示由 6 个核苷酸组成的 DNA 序列。
'A' 代表腺嘌呤，'C' 代表胞嘧啶，'G' 代表鸟嘌呤，'T' 代表胸腺嘧啶。

给定一个表示 DNA 序列的字符串，统计每种核苷酸各有多少个。
如果字符串中包含 A、C、G、T 以外的字符，那么它就是无效的，你应该报错。

例如：

```
"GATTACA" -> 'A': 3, 'C': 1, 'G': 1, 'T': 2
"INVALID" -> error
```
