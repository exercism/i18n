# 补充说明

## 棋盘格式

棋盘用一个以 null 结尾的字符串表示，每一行末尾都有一个换行符。

例如：`"X  \n XO\nOX \n"`

## 寄存器

| 寄存器  | 用途   | 类型 | 说明                                                          |
| -------- | ------------ | ------- | ----------------------------------------------------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的输入字符串                                            |
| `$v0`    | 输出       | 整数 | 游戏状态（`1` = `ongoing`，`2` = `draw`，`3` = `win`，`-1` = `error`） |
| `$t0-9`  | 临时    | 任意     | 用于临时存储                                                   |
