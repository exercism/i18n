## 可选实参

```julia-repl
julia> f(a, b=1) = a + b
f (generic function with 2 methods)
```

等价于

```julia-repl
julia> f(a, b) = a + b
f (generic function with 1 method)

julia> f(a) = f(a, 1)
f (generic function with 2 methods)
```

在 REPL 的响应中，你可以看到第一个定义同时定义了两个方法。
