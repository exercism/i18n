# 简介

回顾基础概念中的内容：一个 AWK 程序由**模式-动作对**组成。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## “模式”指的是什么？

“模式”就是任意一个 AWK 表达式。
表达式结果的真假，决定了动作是否执行。

## 空模式

模式可以省略。
这种情况下，每条记录都会执行动作。

我们可以打印 passwd 文件中所有的用户名。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正则表达式

AWK 可以把字符串与正则表达式进行比较，得到一个布尔结果。

使用`~`正则匹配运算符来匹配某个字段。
这个运算符的左侧操作数是一个字符串，右侧操作数是一个正则表达式。
正则表达式字面量用一对`/`括起来。

要找出 passwd 文件中使用 bash 登录的用户：

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~`是“正则表达式**不**匹配”运算符。

要让正则表达式与当前记录匹配，可以写`$0 ~ /regex/`。
这种写法太常见了，所以有一个简写：可以省略`$0`和`~`，直接写`/regex/`。

```sh
awk '/regex/' data.txt
```

我们会在后面的概念中进一步了解 GNU AWK 的正则表达式风格。

## 表达式

AWK 表达式（算术表达式、逻辑表达式或其他表达式）都可以用作模式。

要提取所有 UID 大于等于 1000 的用户：

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

回顾一下，AWK 中的假值是数字零和空字符串，其他所有数字或字符串都为真。
任何求值结果为数字或字符串的表达式都可以用作模式。

## 函数

任何[内置][builtins]或[自定义][user-defined]函数都可以用在表达式里，因而也可以用在模式中。
下面举两个例子：

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 常量模式

AWK 中一个常见的惯用写法是：

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1`是一个值为真的模式，没有关联的动作。
意思是“打印当前记录”。
