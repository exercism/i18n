# 关于

C# 中主要的面向对象构造是_类_，它把数据（[_字段_][fields]）和行为（[_方法_][methods]）结合在一起。类的字段和方法称为它的_成员_。

可以通过访问修饰符来限制对成员的访问，最常见的两个是：

- [`public`][public]：任何代码都可以访问该成员（没有限制）。
- [`private`][private]：只有同一个类中的代码才能访问该成员。

习惯上会为所有成员指定访问修饰符。如果没有指定访问修饰符，默认就是`private`。

上面这种把相关数据和行为组合在一起，并限制对成员访问的做法称为[封装][encapsulation]，它是面向对象的核心概念之一。

对象在某一时刻的字段值组合称为对象的[状态][object-state]。

可以把类看作创建该类实例的模板。要[创建类的实例][creating-objects]（也称为_对象_），需要使用[`new`关键字][new]：

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

[字段][fields]有类型，可以在类中的任何位置定义。
公有字段使用 [PascalCase][pascal-case] 命名，私有字段使用 [camelCase][camel-case] 命名，并加上下划线前缀`_`：

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

可以选择给字段赋一个初始值。如果字段_没有_指定初始值，它会被设为其类型的[默认值][default-values]。可以使用点表示法访问和更新实例的字段值。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

私有字段通常作为调用方法的副作用被更新。这类方法通常不返回任何值，此时返回类型应该是[`void`][void]：

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field
        _carsImported = _carsImported + numberOfCars;
    }
}
```

注意，在 C# 类中使用公有字段并不常见。要么使用私有字段，要么使用其他类型的成员，这些将在后续练习中讨论。

在类内部，[`this`关键字][this]指向当前类。如果某个形参与字段同名，这就特别有用：

```csharp
class CarImporter
{
    private int carsImported;

    public void SetImportedCars(int carsImported)
    {
        // Update private field from public method
        this.carsImported = carsImported;
    }
}
```

类和方法的这种结构提供了一种自然的方式，来限制字段和方法等程序元素的可见性，并避免众所周知的[全局状态问题][so-global-state-problem]。公有字段、方法和其他成员必须用对象名限定，即`object.field`或`object.method()`（静态成员则用类名），类外部的代码才能访问它们。在方法内部声明的变量和形参只能在该方法内访问。

使用这种方式时要注意一点：如果字段名与方法中某个变量或形参的名字相同，那么方法内的代码会忽略该字段，这可能并不是你想要的结果。一般来说，应尽可能避免这种情况，尽管它在构造函数中是一种常见的模式。如果字段和变量确实适合同名，那么在方法内用`this`关键字限定字段名。

还可以使用这些[访问修饰符][access-modifiers]来进一步限制可见性。
