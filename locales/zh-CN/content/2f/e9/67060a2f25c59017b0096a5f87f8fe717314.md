# 安装

## 安装 tclsh

你唯一需要的工具就是 TCL 翻译`tclsh`。

在 Windows 上，获取 Tcl 的最佳途径是[Magicsplat 提供的 Tcl 安装程序][magicsplat]。

在 MacOS 和类 Unix 操作系统上，`tclsh`通常已经安装好了。通常，安装的版本是 8.6.*某个版本*。要安装当前稳定的 9.0 版本：
 - 在 MacOS 上，使用 [Homebrew][brew]。
 - 在 Linux 上，查看你的包管理器。
 - 或者[下载源代码][download]并[自行编译][build]。

使用 Exercism 网页界面做练习时，测试运行器（截至 2023 年 2 月）使用的是 Tcl 8.7a4 版本。

## 使用交互式 tclsh shell

写代码时，大家常常会启动一个交互式的[`tclsh`][tclsh]会话来测试各种命令。不过，tclsh 只提供一个非常基础的 REPL 翻译，既没有命令行编辑，也没有命令历史。想要更好的体验，可以使用一个叫`rlwrap`的程序，它为 tclsh 添加了 readline 功能：

```bash
rlwrap tclsh
```

安装 rlwrap：
 - 在 MacOS 上，使用 [Homebrew][brew]。
 - 在 Linux 上，查看你的包管理器。
 - 或者[下载源代码][rlwrap-download]并[自行编译][rlwrap-build]。

它实在太方便了，你会想一直用它：把下面这行加到你的 ~/.bashrc 里

```bash
command -v rlwrap && alias tclsh='rlwrap tclsh'
```

## 该用哪个版本？

当前稳定版本是 9.0。如上所述，8.6 版本仍然被广泛使用。

运行下面这条命令，可以查看你安装的`tclsh`是哪个版本：

```bash
echo 'puts [info patchlevel]' | tclsh
```
