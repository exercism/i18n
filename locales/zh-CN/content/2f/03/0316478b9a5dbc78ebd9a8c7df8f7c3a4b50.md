# 关于

- Pony 是静态类型的。这意味着你*必须*事先为程序中的数据定义好类型。如果你告诉 Pony 变量`x`是整数，就不能把字符串赋给它。
- Pony 的类型系统是 Pony 各项保证的基础。
  - 只要程序能编译通过，它就不会崩溃。
  - 永远不会出现未处理的异常。
  - 不存在`null`这种东西，所以你的程序永远不会试图解引用`null`。
  - 永远不会出现数据竞争。
  - 永远不会出现死锁。
  - 你的代码始终是能力安全的（可抵御供应链攻击）。
- Pony 不允许进行类型转换。所有类型变更都必须通过一个函数来完成，由该函数创建新类型的实例。
- Pony 的类型系统与几乎所有其他语言都不一样，所以我们会把它分成小块来讲。

## Primitives

- primitive 是 Pony 中最简单的代码组织单位。
  - 你可以把它看作函数的容器或命名空间。
  - 它没有字段（字段要靠类来实现）。
  - 它用`primitive`关键字定义。

## Functions

- 函数用`fun`关键字定义。
  - 函数必须放在`primitive`中（`class`和`actor`也同理，不过它们稍后才会讲到）。
  - 函数可以有传入的实参和返回值，而且都必须标明类型。
  - 如果你定义了返回类型，函数就*必须*返回该类型的值。Pony 没有 Null 这个概念。

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## 注释

注释可以用来留便签、记提醒，或者只是暂时把代码从源码里移走。正如你上面所见，单行注释用`//`。多行注释用 C 风格的`/*`和`*/`。

## 变量

- 变量名总是以小写字母开头。
  - 我们用`var`声明变量。（`let`和`embed`稍后再讲）。
  - 如果 Pony 能推断出变量类型，它会替你完成。
  - 变量的类型在编译期检查，之后永远不能改变。
  - 刚开始学 Pony 时，我们建议把类型写明确。

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
