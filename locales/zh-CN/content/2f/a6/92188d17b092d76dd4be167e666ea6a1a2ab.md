# 简介

C 是一种静态类型语言，这意味着所有东西在编译时都有类型。
为变量取一个名字并设定它的类型，称为声明变量。

声明变量时需要显式地指定它的类型。
变量名必须以字母或下划线开头。
有些名字不能使用，因为它们被保留给[关键字][reserved-keywords]或[其他标识符][reserved-identifiers]。

设置或更新变量是通过变量赋值完成的。
设置值即定义了该变量。
定义变量也称为初始化。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

可以使用`=`简单赋值运算符来赋值和更新变量的值。
变量一旦定义，它的类型就永远不能改变。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C 是一种命令式过程式语言。
所有计算都是通过一系列语句完成的，这些语句属于一个或多个函数。

每个函数可以有零个或多个形参。
定义函数时，所有形参以及返回值都必须显式地标注类型。
使用`return`关键字从函数返回值。
函数默认具有外部存储类，这意味着它在程序的整个生命周期内都存在，并且可以在文件外部可见。
要阻止这一点，可以加上`static`关键字来指定内部可见性。

```c
static int add(int x, int y) {
  return x + y;
}
```

在上面的例子中，变量`x`和`y`只能在函数内部使用，也就是说，它们具有函数作用域。
作用域指的是这样一个概念：与某个名字（某个程序元素的名字）相关联的值，只能在定义它的代码“区域”内访问。
C 中的主要代码区域有：

- 文件
- 函数
- 代码块（例如循环和其他结构内部）

调用函数时，需要指定函数名，并为每个形参传入实参。

```c
int sum = add(1, 2);
```

C 支持两种注释。
单行注释以`//`开头（自 C99 起），多行注释则写在`/*`和`*/`之间。
