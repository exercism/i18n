# 测试运行器

测试运行器是一种软件，用来在学生写的代码上运行练习的测试。

测试运行器为我们带来两个好处：

1. 它们让浏览器内编程成为可能：学生可以反复迭代自己的解答，并看到测试是通过还是失败。
2. 它们让我们能向导师提供信息，说明学生的代码是否能“正常工作”。

## 为测试运行器做贡献

每种语言都有自己的测试运行器，用该语言编写。
网站充当测试运行器与学生提交内容之间的协调者。

每个测试运行器都放在 Exercism GitHub 组织里一个名为`<track_slug>-test-runner`的代码仓库中（例如 [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)）。
你可以在[这里](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories)查看现有的测试运行器。

如果你想参与帮助一个现有的测试运行器，请在该仓库中开一个 issue，问问有什么地方你可以帮忙。
如果你想为目前还没有测试运行器的语言创建一个，请按照[从头创建测试运行器](/docs/building/tooling/test-runners/creating-from-scratch)的说明操作。
