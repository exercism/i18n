# 简介

## 字符串

C# 中的`string`是一种对象，它表示不可变文本，由一系列 Unicode 字符（字母、数字、标点等）组成。双引号用于定义`string`实例：

```csharp
string fruit = "Apple";
```

### 方法

通过调用字符串的内置[方法][docs-string-methods]来操作字符串。
例如，要去除字符串中的空白字符，可以像这样使用 [Trim 方法][tutorial-docs.microsoft.com-trim-white-space]：

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

字符串一旦创建，它的值就永远无法改变。
任何看似会修改字符串的方法，实际上都会返回一个新的字符串。

### 拼接

多个字符串可以拼接（相加）在一起。实现这一点的最简单方法就是使用`+`运算符。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### 格式化

如果字符串格式化比简单拼接更复杂，更推荐使用字符串插值。要在字符串中使用插值，请在它前面加上美元（`$`）符号。然后可以使用大括号（`{}`）来访问字符串中的任何变量。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
