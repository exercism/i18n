# 关于

C 是一门静态类型语言，这意味着所有东西在编译时都有类型。
为[变量][variable]取一个名字并设置其类型，这一过程称为声明变量。

声明变量时，需要显式指定它的类型。
变量名[必须遵循一些规则][name-rules]，例如以字母或下划线开头。
有些名字不能使用，因为它们被保留给[关键字][reserved-keywords]或[其他标识符][reserved-identifiers]。

设置或更新变量通过变量赋值完成。
赋予值就定义了这个变量。
定义变量也称为初始化。

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

可以使用 [`=`简单赋值运算符][assignment-operator]来赋值和更新变量的值。
变量一旦定义，其类型就永远不能改变。

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C 是一门[命令式][imperative][过程式][procedural]语言。
所有计算都作为一系列[语句][statements]来执行，这些语句属于一个[函数][function]或多个函数。

每个函数可以有零个或多个[形参][parameters]。
定义函数时，所有形参以及返回值都必须显式指定类型。
函数使用 [`return`关键字][return-keyword]来返回值。
函数默认具有外部[存储类][storage_class]，这意味着它在程序的整个生命周期内都存在，并且可以在文件外部可见。
要避免这一点，可以加上 `static` 关键字来指定内部可见性。

```c
static int add(int x, int y) {
  return x + y;
}
```

在上面的例子中，变量`x`和`y`只能在函数内部使用，也就是说，它们具有函数作用域。
[作用域][scope]指的是与某个名字（某个程序元素的名字）关联的值只能在其定义的代码“区域”内访问。
C 中主要的代码区域有：

- 文件
- 函数
- 块（例如循环以及其他结构内部）

调用函数时，需要指定函数名，并为每个形参传入实参。

```c
int sum = add(1, 2);
```

C 支持两种[注释][comments]。
单行注释以`//`开头（自 C99 起），多行注释则插入在`/*`和`*/`之间。
