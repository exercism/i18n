# 在命令行中测试

用以下命令运行测试：

```bash
scarb cairo-test
```

除了第一个测试，其余测试都已被忽略。让第一个测试通过后，打开位于`tests`目录中的测试源文件，去掉下一个测试的`#[ignore]`标记，再让它通过。每个独立的测试都是一个函数，其上方带有`#[test]`标记。就这样继续下去，直到通过所有测试。

如果你想在不修改测试源文件的情况下运行_所有_测试，可以使用：

```bash
scarb cairo-test --include-ignored
```

要运行某个特定测试，无论它是否被忽略，例如`some_test`，可以使用：

```bash
scarb cairo-test -f some_test
```

想进一步了解 Cairo 测试，请参阅在线[测试文档][cairo-tests]。

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
