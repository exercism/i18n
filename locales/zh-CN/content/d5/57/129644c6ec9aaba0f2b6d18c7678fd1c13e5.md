# 说明

在这个练习中，你要为纽约一家美容院开发预约调度程序。这家美容院于 2012 年 9 月 15 日开业。

一共有四个任务，都会涉及预约日期。日期和时间会使用下面三种格式之一：

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00:00"`

~~~~exercism/caution
测试会自动把区域文化设置为 `en-US`，你不需要自己设置或指定它。
~~~~

## 1. 解析预约日期

实现 `schedule` 函数，它能把预约日期的文本表示解析成对应的 `DateTime` 格式：

```fsharp
schedule "7/25/2019 13:45:00"
// => DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 检查预约是否已经过去

实现 `hasPassed` 函数，它接收一个预约日期，检查这个预约是否在过去：

```fsharp
hasPassed (DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 检查预约是否在下午

实现 `isAfternoonAppointment` 函数，它接收一个预约日期，检查这个预约是否在下午（大于等于 12:00 且小于 18:00）：

```fsharp
isAfternoonAppointment (DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述预约的时间和日期

实现 `description` 函数，它接收一个预约日期，返回该日期和时间的描述：

```fsharp
description (DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 返回周年纪念日

实现 `anniversaryDate` 函数，它返回今年的周年纪念日，也就是 9 月 15 日：

```fsharp
anniversaryDate()
// => DateTime(2019, 9, 15, 0, 0, 0)
```
