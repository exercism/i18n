# 简介

`use`宏允许我们快速用另一个模块提供的功能来扩展我们的模块。当你`use`一个模块时，那个模块可以把代码注入到我们的模块中，比如它可以定义函数、`import`或`alias`其他模块，或者设置模块属性。

如果你看过 Exercism 上一些 Elixir 练习的测试文件，你很可能已经注意到它们都以`use ExUnit.Case`开头。正是这一行代码让宏`test`和`assert`在测试模块中可用。

```elixir
defmodule LasagnaTest do
  use ExUnit.Case

  test "expected minutes in oven" do
    assert Lasagna.expected_minutes_in_oven() === 40
  end
end
```

## `__using__/1`宏

当你`use`一个模块时，具体会发生什么由该模块的`__using__/1`宏决定。它接收一个实参，即包含选项的关键字列表，并返回一个[引用表达式][concept-ast]。调用`use`时，这个引用表达式中的代码会插入到我们的模块中。

```elixir
defmodule ExUnit.Case do
  defmacro __using__(opts) do
    # some real-life ExUnit code omitted here
    quote do
      import ExUnit.Assertions
      import ExUnit.Case, only: [describe: 2, test: 1, test: 2, test: 3]
    end
  end
end
```

调用`use`时，选项可以作为第二个实参传入，例如`use ExUnit.Case, async: true`。如果没有显式给出，这些选项默认为空数组。

[concept-ast]: https://exercism.org/tracks/elixir/concepts/ast
