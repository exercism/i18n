# 简介

按位运算让我们可以操作二进制数中的单个位。

Elm 在 [Bitwise 模块](https://package.elm-lang.org/packages/elm/core/latest/Bitwise) 中提供了几个按位运算符。

## 基本运算

修改一个数字的单个位称为_掩码操作_。
_掩码_是一个数字，其中特定的位按某种方式设置好，用来通过按位运算符（如`and`、`or`和`xor`）操作另一个数字。

### and

`and`通过只保留两个数字中同为`1`的位来合并它们。
这在检查单个位是否被设置时很有用。
例如，要检查一个数字的第 4 位是否被设为`1`，可以将它与掩码`01000`（十进制的`8`）做`and`运算，然后看结果是否为非零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`合并两个数字时，只要某一位在其中一个或两个数字中为`1`，就把结果中的这一位设为`1`。
这在把某个特定位设为`1`时很有用。
例如，要把`10101`中的第 2 位设为`1`，可以将它与掩码`00010`做`or`运算：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 异或（xor）

`xor`合并两个数字时，如果某一位在一个数字中为`1`、在另一个数字中为`0`，就把结果中的这一位设为`1`。
这在把某一位翻转为其相反值时很有用：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 取反

`complement`会把一个数字的每一位取反（`0`变成`1`，`1`变成`0`）。

注意，这会让正数变成负数，负数变成正数。
这是因为二进制中的负数用最左边的`1`来表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### 移位

下面的运算符会把位向左或向右移动指定的位数，相当于乘以或除以 2 的幂。

`shiftLeftBy`把位向左移动，从右侧补入`0`。
例如，把`21`左移 3 位：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

这等同于`21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`：把位向右移动：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

右移 2 位等同于整数除以 4。

注意，这个函数会用最左边位上原有的值来填充移入的位。
因此，负数会保持为负数：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你希望右移并补入 0，请使用`shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
