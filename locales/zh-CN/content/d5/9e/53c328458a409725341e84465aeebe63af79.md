# 关于

映射指的是把一个函数应用到序列的每个元素上，从而得到一个新的序列。

可以用`mapcar`把一个函数映射到一个对象列表上：

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

注意，第一个实参是要调用的函数。
`#'`是一种特殊的引用语法，用来指定一个函数。
（这里也可以用`'double`，但使用`#'`更符合习惯，而且可以说“更正确”。）

## 多个列表

映射并不局限于把函数应用到一个序列上，也可以作用于多个序列。
如果提供了`N`个序列，那么函数必须接受`N`个实参。

```lisp
(mapcar #'list '(1 2) '(a b) '("foo" "bar")) ; => ((1 a "foo") (2 b "bar"))
```

## 其他映射函数

除了`mapcar`，还有其他用于在列表上映射的函数。
`mapcar`无疑是最常用的，不过了解一下其他函数也很有好处。

`maplist`的用法与`mapcar`类似，但它作用的是依次递进的子列表，而不是元素。
先是整个列表，然后是它的`cdr`，再然后是那个`cdr`的`cdr`，依此类推：

```lisp
(maplist #'identity '(a b c)) ; => ((A B C) (B C) (C))
```

`mapc`和`mapl`分别类似于`mapcar`和`maplist`，但它们不收集结果，而是返回第一个列表。
这类函数用于产生副作用的操作。

`mapcan`和`mapcon`类似于`mapcar`和`maplist`，但结果会借助`nconc`展平。`nconc`类似于`append`，但它对除最后一个实参以外的所有实参都具有破坏性。

## 在其他序列上映射

映射并不局限于[列表][concept-lists]。任何序列（在另一个概念中介绍）都可以被映射。
对于非列表的序列，则使用`map`函数。

`map`接受 3 个或更多实参：
- 第一个是结果序列的类型
- 第二个是要应用的函数
- 第三个及之后的实参是要操作的序列。

```lisp
(map 'list #'double '(1 2 3))        ; => (2 4 6)
(map 'string #'char-upcase "foobar") ; => "FOOBAR"
```

作为一种特殊情况，如果把`nil`作为结果序列的类型，那么返回的就是`nil`。
这种用法（和上面的`mapc`、`mapl`一样）是为了产生副作用。
