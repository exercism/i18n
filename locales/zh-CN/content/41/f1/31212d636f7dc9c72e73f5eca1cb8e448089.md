# 结构体

结构体把一组固定且类型各异的数据收集到一个单元中。Rust 中的结构体有以下特点：

- 每个结构体类型都有一个特定的名字。
- 结构体的每个成员都叫做**字段**。
- 结构体的每个字段都有一个特定的名字。
- 可见性按字段来跟踪：每个字段都可以独立地设为公开、私有或其他[^1]。

# 结构体概览

结构体使用`struct`关键字定义，后面跟着这个结构体所描述的类型的名字。
名字后面可以跟花括号（标准结构体）、圆括号（元组结构体）或分号（单元结构体）。

```rust
struct Item {}
```

然后把其他类型作为结构体的_字段_引入结构体内部，每个字段都有自己的类型：

```rust
struct Item {
    name: String,
    weight: f32,
    worth: u32,
}
```

最后，可以在`impl`块中为结构体定义方法：

```rust
impl Item {
    // initializes and returns a new instance of our Item struct
    fn new() -> Self {
        todo!()
    }
}
```

# 结构体的种类

结构体有三种形式：带命名字段的结构体（标准结构体）、元组结构体和单元结构体。

结构体和**元组**非常相似。事实上，结构体和元组唯一的区别在于什么是匿名的。一般形式是这样的：

- 结构体有名字，字段也有名字：

  ```rust
  struct Foo {
      bar: Bar,
      bat: Bat,
  }
  ```

  字段通过名字访问：

  ```rust
  let bar = foo.bar;
  ```

- 元组结构体有名字，但字段是匿名的：

  ```rust
  Foo(Bar, Bat)
  ```

  字段通过解构或数字下标访问：

  ```rust
  // unpacking
  let (bar, bat) = foo;
  ```

  ```rust
  // numeric index
  let bar = foo.0;
  let bat = foo.1;
  ```

- 元组是匿名的，字段也是匿名的：

  ```rust
  (Bar, Bat)
  ```

  和元组结构体一样，字段通过解构或数字下标访问。

- 匿名结构体，顾名思义，是匿名的，但字段有名字。你可能在 Go 或 Java 等其他语言中见过它们。Rust 中没有匿名结构体；惯常的做法是改用元组。

# 零大小类型

结构体可以有任意多或任意少的字段，视需要而定。这意味着一个结构体拥有零个字段是合法的。没有字段的结构体叫做**零大小类型**，编译器对它有一些特殊处理：零大小类型（常缩写为 **ZST**）从不占用栈或堆空间，即使你可能以为它们会占用。例如，如果`T`是一个 ZST，`Box<T>`不会分配任何堆内存。

写 ZST 时，你可以使用标准结构体或元组结构体的语法：

```rust
// declaration
struct Foo {}
// instantiation
let foo = Foo {}
```

```rust
// declaration
struct Foo();
// instantiation
let foo = Foo();
```

ZST 还有一种简写形式：

```rust
// declaration
struct Foo;
// instantiation
let foo = Foo;
```

一般来说，写 ZST 时更推荐用简写，因为两者不能混用：声明一个 ZST[^2]时用的是哪种写法，实例化它时就必须用同一种写法。
