# 说明

在这个练习中，你将编写一些代码，帮你照着最喜欢的烹饪书做出一份美味的千层面。

你有五个任务，它们都和烹饪千层面所花的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义`expectedMinutesInOven`函数，它不接受任何实参，并返回千层面应该在烤箱里烤多少分钟。根据烹饪书，预期的烤箱时间是 40 分钟：

```haskell
expectedMinutesInOven
-- -> 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`remainingMinutesInOven`函数，它接受千层面实际已在烤箱中烤的分钟数作为实参，并根据上一个任务中的预期烤箱时间，返回千层面还需要在烤箱里烤多少分钟。

```haskell
remainingMinutesInOven 30
-- -> 10
```

## 3. 计算准备时间（分钟）

定义`preparationTimeInMinutes`函数，它接受你加到千层面里的层数作为实参，并返回你准备这份千层面所花的分钟数。假设每铺一层需要 2 分钟。

```haskell
preparationTimeInMinutes 3
-- -> 6
```

## 4. 计算已用时间（分钟）

定义`totalTimeInMinutes`函数，它接受两个实参：第一个实参是你加到千层面里的层数，第二个实参是千层面已经在烤箱里烤了多少分钟。该函数应返回你在烹饪这份千层面上总共花掉的分钟数，也就是准备时间加上千层面此刻在烤箱里已用的时间。

```haskell
elapsedTimeInMinutes 3 20
-- -> 26
```

## 5. 创建千层面已烤好的通知

定义`alarm`函数，它不接受任何实参，并返回一条表示千层面可以吃了的消息。

```haskell
alarm
-- -> "Ding!"
```
