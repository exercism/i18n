# 关于

Ruby 自带一个标准库（常简称为“stdlib”），它是处理日期、json、网络等内容的类的集合。它还提供了一些实用的功能，让你的代码更易于使用。

`OpenStruct`是标准库的一部分，能让你轻松地由`Hash`创建对象。不同于必须用`Hash`的键来访问，`OpenStruct`允许我们改用方法来访问和设置值。

使用标准库或其他任何库中的类时，你需要用`require`方法引入该类。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

这样做还有一个额外的好处：使用块语法时，可以利用一个简写。当块只调用一个方法时，你可以用`&:`加上方法名来替代整个块。例如，下面这两行是等价的：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
