# 提示

## 通用

- 在[入门指南][getting-started]中了解 `alias` 和 `import`。
- 在 elixirschool.com 上了解[模块组合][elixir-school-module-composition]。

## 1. 修复编译错误 `Race.__struct__/0 is undefined`

- 可以使用`alias`特殊形式创建别名。

## 2. 修复编译错误 `Car.__struct__/0 is undefined`

- 可以使用`alias`特殊形式创建别名。
- `alias`特殊形式接受一个`:as`选项。

## 3. 修复编译错误 `undefined function puts/1`

- 可以使用`import`特殊形式导入函数。
- `import`特殊形式接受一个`:only`选项。它的值应该是一个关键字列表，以函数名为键，以函数的参数个数为值。

## 4. 修复编译错误 `undefined function default_color/0`

- 可以使用`import`特殊形式导入函数。
- `import`特殊形式接受一个`:except`选项。它的值应该是一个关键字列表，以函数名为键，以函数的参数个数为值。
