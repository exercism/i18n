# 说明

实现编写秘密消息的经典方法，即所谓的方阵密码。

给定一段英文文本，输出这段文本的编码版本。

首先要对输入进行规范化：去掉英文文本中的空格和标点符号，并把消息中的所有字母转为小写。

然后，把规范化后的字符分成若干行。打印时加上换行，这些行就构成一个矩形。

例如，句子

```text
"If man was meant to stay on the ground, god would have given us roots."
```

规范化后是：

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

明文应当排列成一个矩形。矩形的大小（`r x c`）要根据消息的长度来确定，使得 `c >= r` 且 `c - r <= 1`，其中 `c` 是列数，`r` 是行数。

我们规范化后的文本长度是 54 个字符，对应的矩形为 `c = 8`、`r = 7`：

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

编码后的消息通过从上到下逐列读取得到，读取顺序是从最左边一列到最右边一列。

上面的消息编码后为：

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

输出编码后的文本时，要把它分成若干块，每块都正好填满一个矩形（`(r X c)`），也就是 `c` 块长度为 `r` 的内容，块与块之间用空格分隔。对于比完整矩形短 `n` 个字符的短语，给最后`n`块各补一个尾随空格。

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

注意，如果把这些内容堆叠起来，我们就能直观地把密文解码回原始消息：

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
