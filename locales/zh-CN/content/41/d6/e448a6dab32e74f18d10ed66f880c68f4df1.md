# 关于

Elixir 的标准库提供了 4 个处理日期和时间的模块，每个模块都有自己的结构体。

- [`Date`模块][date]。`Date`结构体可以用[`~D`符号][sigil-d]创建。
    ```elixir
    ~D[2021-01-01]
    ```

- [`Time`模块][time]。`Time`结构体可以用[`~T`符号][sigil-t]创建。
    ```elixir
    ~T[12:00:00]
    ```

- [`NaiveDateTime`模块][naivedatetime]，用于不带时区的日期时间。`NaiveDateTime`结构体可以用[`~N`符号][sigil-n]创建。
    ```elixir
    ~N[2021-01-01 12:00:00]
    ```

- [`DateTime`模块][datetime]，用于带时区的日期时间。要用这个模块处理 UTC 以外的时区，需要一个外部依赖：时区数据库。`DateTime`结构体可以用[`~U`符号][sigil-u]表示，但应该改用`DateTime`函数来创建。
    ```elixir
    DateTime.new!(~D[2021-01-01], ~T[12:00:00], "Etc/UTC")
    # => ~U[2021-01-01 12:00:00Z]
    ```

## 比较

要把日期或时间相互比较，请在对应的模块中寻找`compare`或`diff`函数。像`==`、`>`和`<`这样的比较运算符*似乎*能用，但它们并不会为这些结构体做正确的语义比较。

```elixir
Date.compare(~D[2020-11-30], ~D[2020-12-01])
# => :lt

Time.diff(~T[13:45:00], ~T[13:46:30])
# => -90
```

## 偏移

使用对应模块的`add/2`函数，可以把日期、时间和日期时间在时间轴上向前或向后偏移。

```elixir
# add 4 days
Date.add(~D[2021-01-01], 4)
# => ~D[2021-01-05]

# subtract 1 second
Time.add(~T[12:00:00], -1)
# => ~T[11:59:59.000000]

# add 4 days and 30 seconds
NaiveDateTime.add(~N[2021-01-01 12:00:00], 4 * 24 * 60 * 60 + 30)
# => ~N[2021-01-05 12:00:30]
```

## 转换

可以用[`NaiveDateTime.to_date/1`][naivedatetime-to-date]和[`NaiveDateTime.to_time/1`][naivedatetime-to-time]把一个`NaiveDateTime`结构体拆解成`Date`结构体和`Time`结构体。反过来，可以用[`NaiveDateTime.new!/2`][naivedatetime-new]实现。

```elixir
NaiveDateTime.to_date(~N[2021-01-01 12:00:00])
# => ~D[2021-01-01]

NaiveDateTime.to_time(~N[2021-01-01 12:00:00])
# => ~T[12:00:00]

NaiveDateTime.new!(~D[2021-01-01], ~T[12:00:00])
# => ~N[2021-01-01 12:00:00]
```
