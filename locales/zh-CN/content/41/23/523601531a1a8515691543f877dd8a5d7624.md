# 安装

你需要 [NodeJS LTS](https://nodejs.org/en)。

> 💡 这条 track 通常也能在更早的稳定版本以及“Current”版本上运行。
> 不过，[按照设计](https://github.com/nodejs/release#release-schedule)，奇数版本从来都不稳定。
> 请务必安装偶数版本的 NodeJS。

使用 Node.JS `corepack` 安装 [Yarn 4+](https://yarnpkg.com/getting-started/install)：

```shell
corepack enable yarn
```

## 检查安装

通常需要打开一个新的终端，才能使用刚刚安装的可执行文件。

```shell
$ node -v
v20.15.0

$ corepack -v
0.28.1

$ corepack yarn -v
v4.3.1
```

_注意：你的版本很可能与此不同。_

## 练习安装

**每个练习**都需要一些工具才能运行测试：

在每个练习目录中运行下面的命令即可安装：

```bash
$ corepack yarn install
```

取决于你使用的编辑器，为了配合 Plug'n'Play 安装，还需要在每个练习中安装 [Editor SDK](https://yarnpkg.com/getting-started/editor-sdks)。
撰写本文时，支持以下编辑器：

- [CoC nvim](https://yarnpkg.com/getting-started/editor-sdks#coc-nvim)
- [Emacs](https://yarnpkg.com/getting-started/editor-sdks#emacs)
- [Neovim Native LSP](https://yarnpkg.com/getting-started/editor-sdks#neovim-native-lsp)
- [VSCode](https://yarnpkg.com/getting-started/editor-sdks#vscode)
