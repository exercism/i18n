# 安装

首先，参照 [Erlang][1] 安装页面上的说明，确保已安装 Erlang。
[1]: /languages/erlang

## Mac OS X 上的 Homebrew

把 Homebrew 更新到最新版本：

```bash
$ brew update
```

安装 LFE：

```bash
$ brew install lfe
```

## 从源码安装

安装系统的“开发者工具”或“基础构建包”、`git`，以及 Erlang 的 `erl`。

例如，在 Ubuntu 18.04 上：

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

之后，你可以用下面的命令下载并构建 LFE：

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

LFE 编译完成后，你可以执行 ``lfe`` 二进制文件来启动 REPL（交互式会话）：

```bash
$ ./bin/lfe
```
