# 简介

`Complex numbers`并不复杂。
只是需要一个没那么吓人的名字。


它们在工程和科学领域特别有用，所以 Python 把[`complex`][complex]也作为一种标准数值类型，与整数（[`int`s][ints]）和浮点数（[`float`s][floats]）并列。


Python 中的`complex`值本质上就是一对浮点数：

```python
>>> my_complex = 5.443+6.77j
(5.443+6.77j)
```

这两部分分别叫作“实部”和“虚部”。
你可能听过“`i`（或`j`）是 -1 的平方根”这种说法。
就目前而言，这只说明虚部_按定义_满足等式`1j * 1j == -1`。
这是个简单的想法，却能引出有趣的数学结果。

在 Python 中，虚部用`j`表示（_不像数学课本里那样写成`i`_），而且
`j`必须紧跟在数字后面，这样 Python 才不会把它当成变量名：


```python
>>> j
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'j' is not defined

>>> 1j
1j

>>> type(1j)
<class 'complex'>
```


创建复数有两种常见方式。

1) [`complex(real, imag)`][complex]构造函数接受两个`float`参数：

    ```python
    >>> z1 = complex(1.5, 2.0)
    >>> z1
    (1.5+2j)
    ```

    构造函数也能解析字符串输入。
    它有个奇怪的限制：字符串里含空格时就会失败。

    ```python
    >>> complex('4+2j')
    (4+2j)
    
    >>> complex('4 + 2j')
    Traceback (most recent call last):
      File "<stdin>", line 1, in <module>
    ValueError: complex() arg is a malformed string
    ```


2) 复数可以写成`<real part> + <complex part>j`这样的字面量；如果实部为零，也可以只写`<complex part>j`：


    ```python
    >>> z2 = 2.0 + 1.5j
    >>> z2
    (2+1.5j)
    ```
    最终结果和使用`complex()`构造函数完全相同。


## 算术运算

浮点数和整数使用的大部分[`operators`][operators]也适用于复数。

复数_**不能**_进行整数除法，所以`//`和`%`运算符以及`divmod()`函数对复数类型都会失败。

解释复数乘法和除法的规则超出了本概念的范围（_而且你不太需要经常“手算”这些运算_）。

任何一篇关于复数的[数学][math-complex]或[电气工程][engineering-complex]入门介绍都会讲到这些内容，如果你想深入了解这个话题的话。

Python 标准库中的[`math`][math-module]模块提供了大量处理实数的实用功能，而[`cmath`][cmath]模块则是它处理复数时的对应版本。
