# 指令补充

## 自定义与抛出异常

有时，你需要在代码里既[自定义](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)异常，又[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)异常。这样做时，你应该始终包含一条**有意义的错误消息**，说明错误的来源是什么。这能让你的代码更易读，对调试也有很大帮助。

自定义异常可以通过新的异常类来创建（详情请见[`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)），这些类通常是[`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)的子类。

如果你知道错误的来源属于某种异常类型的派生类型，可以选择继承 _Exception_ 类下的某个[`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)。抛出错误时，你仍然应该包含一条有意义的消息。

这道练习要求你创建一个_自定义异常_，在栈填充不充分时[抛出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/“throw”它。只有当你自定义了合适的异常、`raise`了这个异常，并包含了合适的错误消息，测试才会通过。


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

此外，这道练习还要求你抛出几个带错误消息的`built-in exceptions`。
要用消息抛出一个`built-in exception`，请把该消息写成`exception`类型的实参：

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
