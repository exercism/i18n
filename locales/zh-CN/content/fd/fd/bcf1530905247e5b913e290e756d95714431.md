# 简介

*堆*是一种集合，它始终知道自己最小的元素，并且能让你快速把它移除，这正是*优先队列*最自然的实现方式。堆位于[`heaps`][heaps]词表里。

`<min-heap>`构造一个空堆，最小的键最先取出；`<max-heap>`则正好相反。每个元素都是一个*值*，存放在某个*键*之下，而键就是优先级：

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

堆是*可变的*，`heap-push`会就地修改它。`heap-peek`返回堆顶的值和键，但不移除它们；`heap-pop`会移除堆顶并返回它；`heap-pop-all`则会把堆清空，按优先级顺序得到一个由`{ key value }`键值对组成的关联列表：

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
