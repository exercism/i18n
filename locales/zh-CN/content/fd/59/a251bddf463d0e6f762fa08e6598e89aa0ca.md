# 说明

在本练习中，你将编写代码来分析汽车工厂装配线的生产情况。装配线的速度范围从`0`（关闭）到`10`（最大）。

在最低速度（`1`）下，每小时生产`221`辆汽车。产量随速度线性增长。因此，当速度设为`4`时，每小时应生产`4 * 221 = 884`辆汽车。不过，速度越高，越有可能生产出有缺陷的汽车，这些汽车随后只能报废。

你有三个任务。

## 1. 计算成功率

实现`success_rate()`方法，计算在给定速度下生产出无错误产品的比率。下表展示了速度如何影响成功率：

- `0`：成功率 0%。
- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

```R
success_rate(10)
# => 0.77
```

## 2. 计算每小时的产量

实现`production_rate_per_hour()`方法，计算装配线每小时的产量，并考虑其成功率：

```R
production_rate_per_hour(6)
# => 1193.4
```

注意，返回的值是`double`类型。

## 3. 计算每分钟生产的合格品数量

实现`working_items_per_minute()`方法，计算每分钟生产多少辆合格汽车：

```R
working_items_per_minute(6)
# => 19
```

注意，返回的值是整数：不完整的产品不计入。
