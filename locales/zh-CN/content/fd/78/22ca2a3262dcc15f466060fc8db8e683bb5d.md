# 简介

Swift 提供了一组语句，可以用来改变循环的正常控制流。这些语句被称为控制转移语句。你已经见过`return`；本概念会介绍其他几种，包括`continue`、`break`和标签。本概念不会涉及`fallthrough`，但你可以在 [Swift 编程语言][fallthrough] 中了解它。

## Continue

有时需要提前跳到循环的下一次迭代，而不执行本次迭代中剩余的语句。这时可以用`continue`关键字。执行`continue`时，循环会跳到下一次检查，看看能否进入下一轮迭代：也就是 while 循环和 repeat-while 循环中的`while`条件，或者 for-in 循环中判断序列里是否还有下一个元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

break 用于提前退出循环。执行`break`时，循环会立即退出，程序接着执行循环之后的第一个语句。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 标签

循环嵌套时，有时需要用`break`或`continue`来退出或重新开始外层循环，也就是包含当前循环的那层循环。这种情况下，可以用标签来指明要退出或重新开始的是哪个循环。在循环开头的`while`、`repeat`或`for`之前写上一个名字加冒号，就为这个循环加上了标签。

想看看这样使用标签的效果，请看下面这个循环。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
