# 说明

你已经在市政办公室工作了一段时间，也开发了一套工具来提高日常工作的效率，比如填写表格。

现在，一位新同事要加入你们，你意识到自己做的工具可能不够一目了然。
你们办公室有很多奇怪的习惯，比如填表时总要用大写字母，还不能让字段留空。

作为第一步，你决定加上 PHP 类型声明，好让新同事能迅速上手，开始使用你的工具。

## 1. 声明 Address 类的类型

为 `Address` 类中声明的每个属性添加属性类型声明。
每个类属性都应声明为字符串。

## 2. 声明用空白值填写表单时的类型

为 `Form` 类中的 `blanks` 方法添加形参类型声明和返回类型声明。
该方法应接收一个整数长度，并返回空白行的字符串表示。

## 3. 声明把值拆分成单个字母时的类型

为 `Form` 类中的 `letters` 方法添加形参类型声明和返回类型声明。
该方法应接收一个表示单词的字符串，并返回一个由字母组成的数组。

## 4. 声明检查值是否能放进表单时的类型

为 `Form` 类中的 `checkLength` 方法添加形参类型声明和返回类型声明。
该方法应接收一个字符串单词和一个整数最大长度，并返回 true 或 false 值。

## 5. 声明在表单中格式化地址时的类型

为 `Form` 类中的 `formatAddress` 方法添加形参类型声明和返回类型声明，其中形参类型要用到前面更新过的 `Address` 类。
该方法应接收一个 `Address`，并返回一个格式化后的字符串。
