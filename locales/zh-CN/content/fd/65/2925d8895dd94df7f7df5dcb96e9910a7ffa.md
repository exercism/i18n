# 简介

最实用的序列词会把一个*引用*作为输入之一，并用它来驱动操作：

```
each   ( seq quot -- )
map    ( seq quot -- newseq )
filter ( seq quot -- newseq )
reject ( seq quot -- newseq )
count  ( seq quot -- n )
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
```

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ 2 > ] count .      ! => 3
```

`map-sum`（也在`sequences`中）会把一个引用映射到序列上，并在一次遍历中把结果相加。同样的模式也驱动着`sort-by`（在[`sorting`][sorting]中）以及`minimum-by`/`maximum-by`（在`sequences`中）。

[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
