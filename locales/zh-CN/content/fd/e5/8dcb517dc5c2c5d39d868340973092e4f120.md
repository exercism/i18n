# 简介

在 Go 中，常量是一个简单、不变的值，通过`const`关键字赋给一个名字：

```go
const myWebsite = "Exercism"
```

这类常量是无类型的，但当需要类型时，Go 会根据它们的写法为它们指定一个默认类型，比如把它们传给某个方法时就是如此。
显式地加上类型，就可以创建有类型的常量：

```go
const myWebsite string = "Exercism"
```

Go 不像某些其他语言那样有枚举，但它有一个预声明的标识符`iota`，用于创建枚举常量。
代码块中的常量会被隐式重复：

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
