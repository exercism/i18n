# 简介

C++ 中的布尔值用`bool`类型表示。
一个`bool`要么是`true`，要么是`false`。

## 逻辑运算符

C++ 支持三种布尔运算符：`!`（NOT）、`&&`（AND）和`||`（OR）。
你也可以使用它们的替代写法`not`、`and`和`or`。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 优先级

这三种布尔运算符各有不同的_运算符优先级_。
因此，它们的求值顺序是：`!`最先，`&&`其次，最后是`||`。
如果你想强制改变顺序，可以把一个布尔表达式放在括号里（即`()`），因为括号的运算符优先级还要更高。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 转换

如果在需要数字的地方使用`true`或`false`，它们会分别被转换成`1`和`0`。
如果在布尔运算中使用数字，除了`0`以外的所有值都会被当作`true`，即使是负数。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
