# 说明

附近有一家叫“Tech Palace”的电器商店。店主最近装了一块大显示屏，用来显示营销信息，并在顾客在入口处扫描他们所谓的会员卡时显示一句特别的问候。显示屏由许多小 LED 灯组成，可以显示多行文字。

店主需要你帮忙编写用于为新显示屏生成文字的代码。

## 1. 创建欢迎消息

对于大多数扫描会员卡的顾客，店主希望显示屏上显示`Welcome to the Tech Palace, `后面跟上顾客姓名的大写形式。

实现`welcome`函数，它接受顾客的姓名，并以字符串形式返回所需的消息。

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. 添加华丽边框

对于在店里大量购买的忠实顾客，店主希望欢迎显示更华丽一些，在欢迎消息前后各加一行星号。他们还不确定每行星号应该有多少个，所以希望能配置。

编写`add_border`函数，接受欢迎消息和每行的星号数量作为实参。它应返回一个由 3 行组成的字符串：一行是所需数量的星号，然后是原样传入的欢迎消息，最后又是一行星号。

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. 清理旧的营销信息

在安装这块新显示屏之前，店里有一块类似的显示屏，只能显示无法配置的静态行。店主想在新显示屏上重复使用一些旧的营销信息。然而，这些数据里已经包含了一些多余的空白字符，那是以前用来在上下堆叠的多块显示屏之间对齐文字用的。你的任务是清理这些信息，好让它们可以重复使用。

实现`clean`函数，它接受旧的营销信息。该函数应首先移除文本开头和结尾的所有空白字符，然后返回它。

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
