# 学习

Exercism 提供练习和反馈，但对于第一次学习 Common Lisp 的人来说，可能不太容易上手。
以下这些资源可以帮助你入门：

* [A Road to Common Lisp][road-to-cl]，一篇博客文章，讲述一个人学习 Common Lisp 的历程，以及他对如何入门的看法
* [Practical Common Lisp][practical-cl]，一本完整的学习 Common Lisp 的书，可在线免费阅读（也有纸质版）
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  由多位贡献者编写
* [Awesome Common Lisp Learning][awesome-cl]

另请参阅本 Exercism Common Lisp 学习路径中的：[重要资源][track-resources]。
