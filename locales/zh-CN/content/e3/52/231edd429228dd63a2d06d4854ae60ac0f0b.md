# 安装

## 目标版本

本 track 的测试使用`alpine:3.24.1` Docker 镜像，截至 2026 年 9 月，该镜像使用`sqlite3 version 3.53.4`。
我们力求确保本 track 提供的工具能在最新的 Ubuntu LTS 版本上正常运行。
虽然用户可能安装了更新的版本，但请注意，某些功能可能无法与我们的测试运行器配合使用。
各版本的功能对比请参见 [SQLite 版本历史][version-history]。

## Windows

要在 Windows 上安装 SQLite，请按以下步骤操作：

1. 从[官方下载页面][sqlite-download]下载预编译的 Windows 二进制文件。
2. 将下载的 ZIP 文件解压到你选择的目录。
   例如`C:\Program Files\sqlite3`。
3. 把包含`sqlite3.exe`的目录添加到系统的 PATH 环境变量中。
   不同 Windows 版本的操作步骤略有不同，但相关信息应该很容易搜到。
   例如 [Windows 11][windows-11-install] 和 [Windows 10][windows-10-install] 的安装说明。

## macOS

在 macOS 上，SQLite 是预装的。
不过，如果你需要更新的版本，可以使用 [Homebrew][homebrew]：

```bash
brew install sqlite
```

## Ubuntu / Debian

在 Ubuntu 和基于 Debian 的系统上，你可以用 apt 安装 SQLite：

```bash
sudo apt install sqlite3
```

## CentOS / Fedora / RHEL

在 CentOS、Fedora 和基于 Red Hat 的系统上，你可以用 yum 或 dnf 安装 SQLite：

```bash
sudo yum install sqlite3
# OR
sudo dnf install sqlite3
```

## Arch Linux

在 Arch Linux 上，你可以用 pacman 安装 SQLite：

```bash
sudo pacman -S sqlite
```

## 其他安装途径和旧版本

更多信息和替代安装方法请参见 [SQLite 下载页面][sqlite-download]。
`Build Product Names and Info` 一节给出了不同 SQLite 版本的命名模板，因此你应该能用自己喜欢的搜索引擎搜到想要的版本。
