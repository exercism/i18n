# 提示

前三个任务都会调用同一个 `print_name_badge()` 函数。它的实现可以逐步搭建，在做的过程中为任务 2 和任务 3 添加逻辑。

## 1. 为员工创建姓名牌

- 这是默认情况，只需把这 3 个实参拼成一个合适的字符串。
- [字符串插值][interpolation]大概是最简单的做法。

## 2. 为新员工创建姓名牌

- 现在 ID 是 `missing,`，所以目标字符串的格式不一样。
- [`ismissing()][ismissing] 在这里很有用。
- Julia 有语法简洁的[三元运算符][ternary]。

## 3. 为老板创建姓名牌

- 现在部门是 `nothing`。
- 有一个 [`isnothing()`][isnothing] 函数。

## 4. 计算没有 ID 的员工的工资总额

- 有[任何][any] ID 缺失吗？如果没有，返回值就是零。
- 要挑出 ID 缺失的条目，可以先[打包][zip] `ids` 和 `salaries` 这两个向量。
- 有几种方法可以遍历得到的元组向量，而不用写显式的循环。
  - 用 Python 式的写法，通过向量[推导式][comprehension]。
  - 用函数式的写法，通过 [`map()`][map] 和[匿名函数][anonymous]。
  - 用向量化的写法，通过对[匿名函数][anonymous]进行[广播][broadcasting]。
- 最后，会对修改后的工资向量调用 [`sum()`][sum]。
   - 有 ID 的员工的工资可以省略，也可以设为零。
