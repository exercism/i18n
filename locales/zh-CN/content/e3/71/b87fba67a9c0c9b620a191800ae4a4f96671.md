# 提示

## 通用

- 阅读[官方入门指南][getting-started-erlang-libraries]中关于使用 Erlang 库的内容，尤其是其中关于[格式化字符串][getting-started-formatted-text-output]的部分。

## 1. 生成一个随机的行星

- 使用提供的模块属性，它是一个包含行星等级字母的列表。
- 有一个[内置函数][enum-random]可以从列表中随机选取一个元素。

## 2. 生成一个随机的星舰注册编号

- 有一个[内置函数][enum-random]可以从范围中随机选取一个元素。

## 3. 生成一个随机的星历

- Elixir 没有可以返回随机浮点数的函数。
- 有一个[内置的 Erlang 函数][erl-rand-uniform]，它返回一个随机浮点数 x，其中 `0.0 <= x < 1.0`。
- 如果 `x` 属于范围 `0.0 <= x < 1.0`，但你需要的数字来自另一个范围 `a <= x < b`，你可以把 x 的范围平移：乘以范围的宽度（`b - a`），再加上范围的起点（`a`）。也就是：`x * (b - a) + a`。

## 4. 格式化星历

- Elixir 没有能一步就把浮点数按指定精度格式化成字符串的函数。
- 有一个[内置的 Erlang 函数][erl-io-lib-format]，它接受一个格式字符串和一个数据列表，并返回一个字符列表。
- 有一个[内置函数][to-string]可以把字符列表转换成字符串。
- 那个函数的格式字符串中包含控制序列。
- 控制序列以 `~` 开头，形式为 `~F.P.PadModC`，其中 `F` 表示输出的宽度，`P` 表示精度，`Pad` 表示填充字符，`Mod` 表示控制序列修饰符，`C` 是控制序列的类型。
- 要按指定的精度格式化浮点数，形式为 `~.PC` 的控制序列就足够了。
- 浮点数对应的控制序列类型是 `f`。
- 你需要的格式字符串正是 `~.1f`。
