# 成为一名优秀的 Exercism 社区成员

我们希望 Exercism 成为一个人人都愿意花时间待着的好地方，无论你是谁。
为了确保 Exercism 做到这一点，我们非常看重做一名优秀的社区成员。

这一点已经正式写进了我们的[行为准则](https://exercism.org/code-of-conduct)，但用一句话就能概括：**友善待人。**

在你为 Exercism 做贡献的过程中，有几条原则值得记住。无论你是在做指导、在学习、在聊天空间里闲逛，还是在 GitHub 上帮忙构建项目，只要遵循这些理念，你就会发现 Exercism 是一个极其有趣、也极有收获的地方：

- 先假设对方心怀善意
- 犯错是件大好事
- 你不知道自己不知道什么
- 建设性地表达分歧
- 谨慎选择措辞

## 先假设对方心怀善意

参与 Exercism 的绝大多数人，都是因为_想帮助他人_才加入的。他们可能对科技充满热情，也许还对教育感兴趣，但最根本的，是想待在一个能和别人一起做点积极事情的空间里。

这意味着，大多数讨论都发生在两个既希望对方好、也希望 Exercism 好的人之间。

有时候，一旦出现分歧，我们很容易就认定对方在故意刁难、没有在听，或者根本没理解你的观点。我们很容易想象对方正暗自得意、自我陶醉，一边用他们那些“错误”的观点把你激怒。但现实中，对方更可能只是想表达一件他们觉得重要的事，只是一时找不到能让别人听懂的说法或方式。

当我们退一步，先假设每个参与者都在**努力**保持友善、努力做正确的事、努力把话说清楚时，我们就更容易放下自己的自尊，去**主动**倾听对方的观点。

这就引出了下面这一点……

## 犯错是件大好事

发现自己错了，是_你能遇到的最好的事_，因为你现在比以前**错得更少**了。如果你在意用科学的方式思考、追求知识、把事情弄对，那么发现自己错了就是最令人兴奋的事。

所以当你在 Exercism 上参与讨论时，把它看成一个发现自己可能错在哪里的机会，而不是证明自己对的机会。这样一来，你可能会比以前更正确。

Adam Grant 就这个主题写过[一整本书](https://www.adamgrant.net/book/think-again/)。书中他引用了 [Ray Dalio](https://en.wikipedia.org/wiki/Ray_Dalio) 的话：“如果你回头看自己，不会想‘哇，一年前的我真蠢’，那说明你过去一年没学到多少东西。”

## 你不知道自己不知道什么

Exercism 建立在这样一个信条之上：**我们不知道自己不知道什么**。整个平台都围绕着一个思路运转：由导师指出你自己都没意识到的知识盲区。当双方都对新的信息保持开放时，这会是一种非常棒的体验（很多时候，反而是_导师_在看到学生写出的新代码和新思路后，发现自己也有不知道的东西！）

在指导环节里当学生时，这种感受很容易记住，但这种开放的精神在 Exercism 的其他任何地方同样重要。当你觉得网站上某件事很糟糕时，先问问自己有哪些事情你_可能_不知道：从你的角度看很荒唐的决定，可能说明你的知识有盲区，也同样可能说明这个决定**确实**荒唐。

想看看这条原则的具体应用实例，可以读一读我们关于[切斯特顿的栅栏](/docs/community/being-a-good-community-member/chestertons-fence)的文章。

## 建设性地表达分歧

打造一款成功的产品和建立一个成功的社区，很大程度上都取决于人们带着不同的意见和视角走到一起，并为了找到共识而展开讨论。有时甚至需要对公认的结论提出异议，才能抵达更好的结论。因此，彼此之间的分歧是 Exercism 至关重要的一部分。而建设性地表达分歧是一种技能，一种很难掌握的技能。

以下几条要点，讲的是在我们的社区里如何_建设性地_表达分歧：

### 1. 先问自己要不要介入

你发现了一个问题，觉得得让人知道。首先要问自己的是：别人真的需要知道吗？告诉别人哪里不对，会_让事情变得更好_吗？你是在制造噪音，还是在提供有价值的信号？

多数情况下，告诉别人他们错了是件好事。你帮他们补上了一个知识盲区，也让 Exercism 变得更好。但有时候，这点噪音或这份精力并不值得，纠正别人反而只会让对方感觉更糟。所以在插话之前，先确认对其他贡献者来说，这么做是对的。

### 2. 不要一哄而上

这一点和上一条紧密相关：看到有人表达了常见（或与自己相冲突）的观点时，我们那种从众的本能常常觉得非得说点什么。在 GitHub 上这种事很常见：有人给每条评论都加上 👍 和 👎 表情，或者用一句“我也是！”刷屏。很多人看到公开的分歧，就觉得自己得“声援”那些和自己观点一致的人。

如果你说不出什么新东西、也没什么用，那就问问自己，到底_有没有必要_开口。

- 那个 👎 是不是只会让某个人觉得自己一无是处？
- 它是不是只会让对方更死守自己的立场，变得更防备？
- 加上一个 👍 是不是会让另一个人觉得自己就是对的、助长他的自负，反而更难去体谅对方的观点？
- 加一句“我这也有这个问题！”的评论，是给维护者提供了一个_有用的_信息，还是只是又添了一份压力和催促？

每种情况都不一样，但点击或打字之前，先想一想。

### 3. 不要针对个人

好了，你卷入了一场分歧。**太好了！** 🎉 现在，_让它有价值_。

记住，你反对的不是一个人，而是他**当前**对某件事的看法。一定要给对方留出改变这个看法的空间，让他们_不用_觉得改变就是丢面子。让他们看到你观点的价值，同时又不觉得自己很蠢。**不要针对个人。**

一个很明显的危险信号，就是非要引用对方说过的话，来指出他们哪儿错了或哪儿自相矛盾。人自相矛盾，往往是**思想在演进**的表现。这并不证明他们_错了_，只证明他们愿意让自己的思维保持创造性。  
他们在探索不同的路径，用不同的方式把东西组合起来。要鼓励这一点！

也别忘了做你自己。你_不必_指明自己同意 X，或者 Y 显然是对的。这不是关于人的问题，而是_找到最佳方案_的问题。提供信号，而不是噪音。

### 4. 接受决定

很多时候，分歧并不会得出所有人都赞同的结论。事实上，在 Exercism，几乎每件事都是一种妥协。所以你几乎总会对结果有点不满意。

想成为优秀的社区成员，关键就在于接受并拥抱这些决定，即使你并不赞同。

决定必须兼顾很多视角，最终也必然包含很多取舍。对某个语言轨道有利的事，对另一个可能就差一点。某些架构或组织方向上的安排，可能给你带来的工作量比给别人带来的更多。某项全站或全社区的考虑，可能被认为比你这个语言轨道特有的考虑更重要。

如果你觉得自己不明白某个决定为什么做出，随时可以问。但一旦决定被解释清楚，即使你不喜欢，接受它也是你的责任。如果每个人都努力这样做，那么下次某个决定**真的**如你所愿、却是以牺牲别人的意愿为代价时，你就不会感受到他们的愧疚或怨恨，也能把自己的精力放在更有成效的事情上。

并且要相信，这些决定都是出于_**善意**_做出的：每个人都在努力为社区、为平台、为我们的学生做到最好。

## 谨慎选择措辞

在 Exercism 里，践行友善的方式有很多，但最有力量的，是去考虑你的话会如何影响他人。

在一个充满来自不同背景的人、跨越文化的空间里（他们有着不同的信念、价值体系和母语），把话说清楚就是一种超能力。你很容易知道自己的话_想传达什么效果_，却很难知道别人_是怎样理解你的话的_。

读一读[我们使用的词语](/docs/community/being-a-good-community-member/the-words-that-we-use)，了解更多关于这件事为何如此重要的内容。
