# 关于

Factor 唯一的数据传递约定是*数据栈*：词弹出自己的输入，压入自己的输出。每个词的定义都会声明一个*栈效果*，用来记录这项约定。

```factor
: restow ( a b -- b a ) swap ;
: discard-top ( a b -- a ) drop ;
```

`( … -- … )`里的名字是给读者看的；编译器检查的是输入和输出的*个数*。不匹配就是编译期错误，这能抓住一类 bug；在缺少这种声明的动态类型语言里，这类 bug 会变成运行期错误。

因为栈是按位置排的，所以在下一个词运行之前，你总要重新安排栈顶的内容。`kernel`里的**重排词**正是干这个的：

```
dup   ( x   -- x x   )    ! duplicate the top
drop  ( x   --       )    ! discard the top
swap  ( x y -- y x   )    ! flip the top two
over  ( x y -- x y x )    ! copy the second item onto the top
nip   ( x y -- y     )    ! discard the second item
rot   ( x y z -- y z x )  ! roll the third item up to the top
```

完整的那一大家子重排词还做了这些扩展：`-rot`（朝相反方向滚动）、带`d`后缀、作用深一层的近亲（`dupd`、`swapd`）、带`2`前缀、作用于成对元素的近亲（`2dup`、`2drop`、`2nip`），以及`pick`、`tuck`这样其他的词。它们会在后面的练习需要时再介绍；一次用太多重排词，通常说明这里改用*局部变量*（有名字的值）会更好读。

按照惯例，词的命名使用`lowercase-kebab-case`，谓词以`?`结尾并返回布尔值（`even?`、`empty?`），设值词写作`>>name`，取值词写作`name>>`；一个词和它的可变版本常常共用一个名字，只能靠上下文区分。
