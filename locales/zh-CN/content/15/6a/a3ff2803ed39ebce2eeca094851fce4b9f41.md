# 简介

[`fractions`][fractions] 模块让我们能够创建和操作 [`rational numbers`][rational]：分子为整数、分母为整数的分数。
例如，我们可以把 `2/3` 存为精确的分数，而不是近似的 `float` 值 `0.6666...`。

与 `int`、`float` 和 `complex` 这些数字类型不同，分数没有字面量形式。
不过，分数的构造函数相当灵活。

最明显的是，它可以接受两个整数作为实参。
公因数会被自动约去，将分数化为“最简形式”（_能准确表示该分数的最小整数_）：

```python
>>> from fractions import Fraction

>>> f1 = Fraction(2, 3) # 2/3
>>> f1
Fraction(2, 3)

>>> f2 = Fraction(6, 9)
>>> f2
Fraction(2, 3)  # automatically simplified

>>> f1 == f2
True
```

分数的构造函数也可以解析字符串形式的表示：

```python
>>> f3 = Fraction('2/3')
>>> f3
Fraction(2, 3)
```

分数也可以接受 `float` 形参，但这可能会遇到问题，因为小数值在内部是用二进制近似表示的。
关于这个表示问题的更多内容，请参阅 [0.30000000000000004][0.30000000000000004] 网站，以及 Python 文档中的[浮点运算：问题与局限][fp-issues]。

使用浮点数处理分数时，如果想得到更可靠的结果，可以用 `<fraction>.limit_denominator()` 方法。


## 分数的算术运算

常用的 [`arithmetic operators`][operators] `+ - * / **` 和其他数字类型一样，也能用于分数。

整数和其他 `Fraction` 都可以放进算式里，结果仍是 `Fraction`。
如果表达式中包含 `float`，结果就是 `float`，因此可能（但不一定）带来精度损失：

```python
>>> Fraction(2, 3) + Fraction(1, 4) # addition
Fraction(11, 12)

>>> Fraction(2, 3) * Fraction(6, 5) # multiply fractions
Fraction(4, 5)

>>> Fraction(2, 3) * 6 / 5 # fraction with integers
Fraction(4, 5)

>>> Fraction(2, 3) * 1.2  # fraction with float -> float
0.7999999999999999

>>> Fraction(2, 3) ** 2  # exponentiation with integer
Fraction(4, 9)
```

各种标准的 Python 数字函数也能给出与处理 `int` 和 `float` 类型时一样的结果：

```python
>>> round(Fraction(11, 3))
4

>>> from math import floor, ceil
>>> floor(Fraction(11, 3))
3
>>> ceil(Fraction(11, 3))
4

>>> float(Fraction(11, 3))
3.6666666666666665
```
