# 简介

Python 有三种不同的内置数字类型：整数（[`int`][int]）、浮点数（[`float`][float]）和复数（[`complex`][complex]）。
分数（[`fractions.Fraction`][fractions]）和小数（[`decimal.Decimal`][decimals]）也可以通过从标准库导入来使用。

整数，包括十六进制（[_`hex()`_][hex]）、八进制（[_`oct()`_][oct]）和二进制（[_`bin()`_][bin]）写法的数字，只要**不带**小数部分，也都被视为 `ints`：

```python
# Ints are whole numbers.
>>> 1234
1234
>>> type(1234)
<class 'int'>

>>> -12
-12
```

含有小数点的数字（无论是否带小数部分）都被视为 `floats`：

```python
>>> 3.45
3.45
>>> type(3.45)
<class 'float'>
```

## 算术运算

Python 完全支持这些不同数字类型之间的算术运算。当把它们与二元算术运算符（`+`、`-`、`*`、`/`、`//` 和 `%`）一起使用时，Python 会把较窄的数字类型转换成与之对应的较宽类型。

### 加法与减法

加法和减法运算符的行为与普通数学中一样。
如果有一个或多个操作数是 `float`，其余的 `int` 也会被转换成 `float`：

```python
>>> 5 - 3
2
# The int is widened to a float here, and a float is returned.
>>> 3 + 4.0
7.0
```

### 乘法

与加法和减法一样，乘法也会把较窄的数字类型转换成与之对应的较宽类型：

```python
>>> 3 * 2
6

>>> 3 * 2.0
6.0
```

### 除法

除法总是返回 `float`，即使结果正好是整数：

```python
>>> 6/5
1.2

>>> 6/2
3.0
```

### 向下取整除法

如果需要 `int` 结果，可以用向下取整除法截断结果。
向下取整除法使用 `//` 运算符：

```python
>>> 6//5
1

>>> 6//2
3
```

### 求模

求模运算符（`%`）返回两个操作数相除的余数：

```python
# The result of % is zero here, because dividing 8 by 2 leaves no remainder
>>> 8 % 2
0

# The result of % is 2 here, because 3 only goes into 5 once, with 2 leftover
>>> 5 % 3
2
```

换个角度看 5 % 3：

```python
>>> whole_part = int(5/3)
1

>>> decimal_part = 5/3 - whole_part
0.6666666666666667

>>> whole_remainder = decimal_part * 3
2.0
```

## 四舍五入

Python 提供了一个内置函数 [`round(number, <decimal_places>)`][round]，可以把浮点数四舍五入到指定的小数位数。
如果没有指定小数位数，数字会被四舍五入到最接近的整数，并返回 `int`：

```python
>>> round(3.1415926535, 2)
3.14

>>> round(3.1415926535)
3
```

## 优先级与括号

Python 允许你用括号把表达式分组。
当你想改变默认的运算顺序时，这很有用。

```python
>>> 2 + 3 * 4
14

>>> (2 + 3) * 4
20
```

Python 遵循 [PEMDAS][pemdas] 规则来确定运算符的优先级。
也就是说，`()` 内的计算优先级最高，然后是 `**`，接着是 `*`、`/`、`//`、`%`、`+` 和 `-`：

```python
>>> 2 + 3 - 4 * 4
-11

>>> (2 + 3 - 4) * 4
4

# In the following example, the `**` operator has the highest priority, then `*`, then `+`
# Meaning we first do 4 ** 4, then 3 * 64, then 2 + 192
>>> 2 + 3 * 4 ** 4
770
```

## 精度与表示

Python 中的整数具有[任意精度][arbitrary-precision]，位数只受宿主系统可用内存的限制。

浮点数在 C 中通常用 `double` 实现（_精度为 15 位小数_），但具体表示方式会因宿主系统而异。
复数有 `real` 和 `imaginary` 两部分，两者都由浮点数表示。

如果想更详细地了解各种编程语言中浮点运算存在的问题和局限，可以看看 [0.30000000000000004.com][0.30000000000000004.com] 和 [The Python Tutorial][floating point math]。
