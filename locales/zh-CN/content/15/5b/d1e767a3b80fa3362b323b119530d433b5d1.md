# 简介

回顾一下“基础”概念里的内容，AWK 程序由**模式-动作对**组成。

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

## 我们说的“模式”是什么意思？

“模式”就是任意一个 AWK 表达式。
表达式结果的真假，决定了动作是否会被执行。

## 空模式

模式可以省略。
这时，动作会针对每一条记录执行。

我们可以打印 passwd 文件中所有的用户名。

```sh
awk -F: '{print $1}' /etc/passwd
```

## 正则表达式

AWK 可以把字符串和正则表达式进行比较，得到一个布尔结果。

使用 `~` 正则匹配运算符来匹配某个字段。
这个运算符左边是字符串，右边是正则表达式。
正则表达式字面量用 `/` 斜杠括起来。

要找出 passwd 文件中使用 bash 登录的用户：

```sh
awk -F: '$7 ~ /bash/ {print $1}' /etc/passwd
```

`!~` 是“正则表达式**不**匹配”运算符。

要让正则表达式匹配当前的记录，可以写 `$0 ~ /regex/`。
这种写法太常见了，所以有个简写：可以省掉 `$0` 和 `~`，直接写 `/regex/`

```sh
awk '/regex/' data.txt
```

我们会在后面的概念中进一步介绍 GNU AWK 的正则表达式风格。

## 表达式

AWK 表达式（算术的、逻辑的，或者其他任何形式）都可以用作模式。

要提取所有 UID 为 1000 及以上的用户：

```sh
awk -F: '$3 >= 1000' /etc/passwd
```

回想一下，AWK 的 false 值就是数字 0 和空字符串，其他任何数字或字符串都是 true。
任何求值结果为数字或字符串的表达式，都可以用作模式。

## 函数

任何[内置][builtins]函数或[用户定义][user-defined]函数都可以用在表达式里，因此也能用在模式里。
举两个例子：

```awk
length($1) {print "first field is not empty"}
```
```awk
toupper(substr($1, 1, 1)) ~ /[AEIOU]/ {print "starts with a vowel"}
```

## 常量模式

一个常见的 AWK 惯用法是：

```sh
{
    xyz()   # some code that transforms each record
}
1
```

`1` 是一个恒为真的模式，它没有关联的动作。
它的意思是“打印当前的记录”。
