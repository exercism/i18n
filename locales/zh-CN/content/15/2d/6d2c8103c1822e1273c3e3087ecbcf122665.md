# 表示器规范化

[JavaScript 表示器][github-javascript-representer]会进行以下规范化：

## 移除注释

所有注释都会被移除。
以下示例是等价的：

### 带注释的示例

```javascript
/**
 * Returns the string literal 'hi there' just to say hello
 * @return [String]
 */
function hello(/* nothing*/) {
  // just return it
  return 'hi there';
}
```

### 不带注释的示例

```javascript
function hello() {
  return 'hi there';
}
```

## 规范化空白字符

代码被表示时，它的_顺序_很重要，而它的物理位置并不重要。
这意味着空白字符会被规范化。
以下示例是等价的：

### 使用两个空格缩进的示例

```javascript
function hello() {
  return 'hello world';
}
```

### 使用四个空格缩进的示例

```javascript
function hello() {
  return 'hello world';
}
```

### 使用有趣缩进的示例

```javascript
function hello() {
  return 'hello world';
}
```

## 规范化标识符

标识符会被规范化为占位符值。

### 规范化前

```javascript
const MY_CONSTANT = 42;

function answer(multiplier, addition = 1) {
  return MY_CONSTANT * multiplier + addition;
}
```

### 规范化后

```javascript
const PLACEHOLDER_1 = 42;

function PLACEHOLDER_2(PLACEHOLDER_3, PLACEHOLDER_4 = 1) {
  return PLACEHOLDER_1 * PLACEHOLDER_3 + PLACEHOLDER_4;
}
```
