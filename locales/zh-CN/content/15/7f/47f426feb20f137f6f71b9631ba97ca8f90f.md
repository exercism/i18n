# 提示

## 概述

- 要访问和定义实例变量，需要写`@`，后面跟上变量名。

## 1. 初始化 `TaskHandler`

- 要创建 `Proc`，可以使用 `-> (args) { block }` 语法。
- 当为实例变量定义 `Proc` 时，需要显式声明它的类型。
  可以在变量名后面加上 `: Proc(<arg_type>, <return_type>)` 来做到这一点。
  也可以使用 `-> (arg_1 : <arg_type>) : <return_type> { block }` 语法。
- `Proc` 应该比较实参是否大于或等于 0。

## 2. 更新任务条件逻辑

- 该方法应该接收一个块作为实参，并把它赋值给实例变量 `@task_condition_logic`。

## 3. 执行下一个任务

- 要执行 `Proc`，可以使用 `call` 方法，它接收传给该 proc 的实参。
