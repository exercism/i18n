# 数组方法

数组是一种常见的数据结构。
因此，有许多方法可以用来处理数组。
包括排序、反转、插入等等。

其中一些方法具有破坏性，也就是说，它们会修改原数组。
另一些则是非破坏性的，意思是它们返回一个新数组，不会修改原数组。

下面介绍处理数组时最常用的一些方法：

## insert

要在数组中插入元素，可以使用[`insert`][insert]方法，它接受一个下标和一个元素作为实参。
元素会被插入到指定的下标处，数组的其余部分会向右移动。
如果下标越界，就会抛出`IndexError`。

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

要从数组中删除某个特定元素时，可以使用[`delete`][delete]方法，它接受一个元素作为实参。
该方法返回被移除的那个元素。
如果数组中不存在该元素，则返回`nil`。

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

要获取数组的第一个或最后一个元素时，可以使用[`first`][first]和[`last`][last]方法。
这些方法接受一个可选实参，用来指定要返回多少个元素。
与使用下标`0`或`-1`，或者使用区间相比，这样可读性更好。
如果数组为空，就会抛出`Enumerable::EmptyError`。

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

要反转数组时，可以使用[`reverse`][reverse]方法，它返回一个元素顺序相反的新数组。
需要注意的是，`reverse`返回的是新数组，不会修改原数组。
如果你想修改原数组，就在方法名末尾加上`!`。

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## flatten & compact & transpose & uniq

以下方法在进行把数组变成一维、移除`nil`元素、去除重复项，或转置由数组组成的数组等操作时很有用。
与`reverse`一样，这些方法返回新数组，不会修改原数组。

| 方法 | 说明 | 示例 |
| ------ | ----------- | ------- |
| [`flatten`][flatten] | 返回一个新数组，它是对该数组进行一维扁平化（递归）的结果。也就是说，对每个数组元素，把它的元素提取到新数组中。 | `[[1, 2], [3, 4]].flatten # => [1, 2, 3, 4]` |
| [`compact`][compact] | 返回自身的一个副本，并移除所有 nil 元素。 | `[1, nil, 2, nil, 3].compact # => [1, 2, 3]` |
| [`transpose`][transpose] | 假定自身是由数组组成的数组，并[转置][transpose]其行和列。 | `[[1, 2], [3, 4]].transpose # => [[1, 3], [2, 4]]` |
| [`uniq`][uniq] | 通过移除自身中的重复值返回一个新数组。 | `[1, 2, 1, 3, 1].uniq # => [1, 2, 3]` |

## Concat(`+`)

想把对象添加到数组时，append 方法（`<<`）很有用。
不过，要合并两个数组时，可以使用[`+`][concat]运算符，它返回一个包含两个数组元素的新数组。

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

如果你把一个数组追加到另一个数组，该数组会作为一个单独的元素添加进去。

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

要检查数组是否为空时，可以使用[`empty?`][empty?]方法，它在数组为空时返回`true`，否则返回`false`。
与把数组的长度和`0`作比较相比，这样可读性更好。

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

要获取数组中某个元素的下标时，可以使用[`index`][index]方法，它接受一个元素作为实参。
如果数组中不存在该元素，则返回`nil`。

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

想知道数组中元素的数量时，可以使用[`size`][size]方法。

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

想统计某个元素在数组中出现了多少次时，可以使用[`count`][count]方法。

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

要对数组排序时，可以使用[`sort`][sort]方法，它返回一个元素已排序的新数组。
与`reverse`一样，该方法返回新数组，不会修改原数组。

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
