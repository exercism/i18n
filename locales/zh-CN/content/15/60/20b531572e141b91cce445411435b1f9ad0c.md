# 简介

枚举就是遍历一个集合（`Array`、`Hash` 等），并对其中每个对象执行某种操作。

枚举是 Ruby 中的一个核心概念，可用于排序（`sort_by`）、分组（`group_by`）、映射（`map`）、归约（`reduce`）等等。
遍历集合时，最常见的是用枚举这种惯用写法，而不是用循环。

下面是一个使用 `map` 和 `with_index` 的简单枚举示例：

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
