# 说明

在这个练习中，你将编写代码，借助一个国际拨号代码字典来跟踪国际拨号代码。

这个字典的键是整数（拨号代码），值是字符串（国家名称）。

你有 9 个任务，它们都涉及`DialingCodes`静态类。

## 1. 创建一个新字典

实现（静态）方法`DialingCodes.GetEmptyDictionary()`，它返回一个空字典。

```csharp
DialingCodes.GetEmptyDictionary();
// => empty dictionary
```

## 2. 创建一个预先填充好的字典

有一个预先填充好的字典，其中包含以下 3 个拨号代码：代码为 1 的 “United States of America”、代码为 55 的 “Brazil”，以及代码为 91 的 “India”。实现（静态）方法`DialingCodes.GetExistingDictionary()`来返回这个预先填充好的字典：

```csharp
DialingCodes.GetExistingDictionary();
// => 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 3. 向空字典中添加一个国家

实现（静态）方法`DialingCodes.AddCountryToEmptyDictionary()`，它会创建一个字典，并向其中添加一个拨号代码和对应的国家名称。

```csharp
DialingCodes.AddCountryToEmptyDictionary(44, "United Kingdom");
// => 44 => "United Kingdom"
```

## 4. 向已有字典中添加一个国家

实现（静态）方法`DialingCodes.AddCountryToExistingDictionary()`，它会把一个拨号代码和对应的国家名称添加到一个非空字典中。

```csharp
DialingCodes.AddCountryToExistingDictionary(DialingCodes.GetExistingDictionary(),
  44, "United Kingdom");
// => 1 => "United States of America", 44 => "United Kingdom", 55 => "Brazil", 91 => "India"
```

## 5. 获取与某个拨号代码匹配的国家名称

实现（静态）方法`DialingCodes.GetCountryNameFromDictionary()`，它接收一个拨号代码，并返回对应的国家名称。如果字典中不包含该拨号代码，则返回空字符串。

```csharp
DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 55);
// => "Brazil"

DialingCodes.GetCountryNameFromDictionary(
  DialingCodes.GetExistingDictionary(), 999);
// => string.Empty
```

## 6. 检查字典中是否存在某个国家

实现（静态）方法`DialingCodes.CheckCodeExists()`，用于检查某个拨号代码是否存在于字典中。

```csharp
DialingCodes.CheckCodeExists(DialingCodes.GetExistingDictionary(), 55);
// => true
```

## 7. 更新国家名称

实现（静态）方法`DialingCodes.UpdateDictionary()`，它接收一个拨号代码，并把字典中对应的国家名称替换为作为形参传入的国家名称。如果字典中不存在该拨号代码，则字典保持不变。

```csharp
DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 1, "Les États-Unis");
// => 1 => "Les États-Unis", 55 => "Brazil", 91 => "India"

DialingCodes.UpdateDictionary(
  DialingCodes.GetExistingDictionary(), 999, "Newlands");
// 1 => "United States of America", 55 => "Brazil", 91 => "India"
```

## 8. 从字典中删除一个国家

实现（静态）方法`DialingCodes.RemoveCountryFromDictionary()`，它接收一个拨号代码，并从字典中删除对应的记录，也就是拨号代码和国家名称。

```csharp
DialingCodes.RemoveCountryFromDictionary(
  DialingCodes.GetExistingDictionary(), 91);
// => 1 => "United States of America", 55 => "Brazil"
```

## 9. 找出名称最长的国家

实现（静态）方法`DialingCodes.FindLongestCountryName()`，它会返回字典中名称最长的那个国家的名称。

```csharp
DialingCodes.FindLongestCountryName(
  DialingCodes.GetExistingDictionary());
// => "United States of America"
```
