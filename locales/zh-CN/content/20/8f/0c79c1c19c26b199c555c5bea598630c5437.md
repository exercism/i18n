# 构造函数属性提升

在声明了许多属性的类中，如果分别声明类、它的属性，以及用来设置这些属性的构造函数，就会产生大量重复。
使用构造函数属性提升，可以减少这种重复。

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
