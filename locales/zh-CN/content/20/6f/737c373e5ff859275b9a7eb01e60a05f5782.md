# Instructions

舞团排成几排，你要记录谁站在哪里。

五个任务都写在`DANCE_FORMATION`类里。

## 1. 这一排有多少人？

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. 谁领队？

谁站在第一个，谁就是领队。

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. 谁在队尾？

队尾就是站在最后的那个人，不管这一排有多长。

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. 开场队形

舞团每次开场都按同样的顺序站位：Mia、Ana、Ben。返回这一排。

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

这个例程不接受任何实参。

## 5. 数一数舞步

每位舞者都有若干舞步要做。把它们加起来。

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

空的一排步数为 0。
