# 说明

在这个练习中，你将处理日志条目。

每条日志行都是一个格式如下的字符串：`"[<LEVEL>]: <MESSAGE>"`。

日志级别有三种：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会给你一条日志行，让你对它做点什么。解决这些任务的方法有很多，从上文的示例中挑一个你最喜欢的技术，看看能想出什么办法。

## 1. 从日志行中获取消息

实现`message`函数，返回日志行的消息：

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

开头和结尾的空白字符都应去掉：

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现`log_level`函数，返回日志行的日志级别，返回值应为小写：

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. 重新格式化日志行

实现`reformat`函数，重新格式化日志行，把消息放在前面，日志级别用括号放在它后面：

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
