# 简介

有些循环没法写成“对序列里的每个元素都这样做一次”，你得一直重复下去，直到某个条件发生变化。Factor 的 `while` 组合子就是干这个的：一个谓词 quotation 说“还要继续吗？”，一个循环体 quotation 完成一步的工作，`while` 会不断重复，直到谓词返回 `f`。

## `while` 和 `until`

```
while ( pred body -- )
until ( pred body -- )
```

`pred` 和 `body` 都是操作数据栈的 quotation。只要 `pred` 留下一个真值，`while` 就一直循环；`until` 则相反：它会一直循环，*直到* `pred` 变为真（也就是说，只要 `pred` 留下的是 `f`）。

同一个状态值可以在谓词和循环体之间沿着栈流动：

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

追踪一下：谓词 `dup 0 >` 看一眼当前计数器；循环体 `dup . 1 -` 把它打印出来并减 1；计数器到 `0` 时循环停止。结尾的 `drop` 把最后那个 `0` 从栈上丢掉。

## `while*`：保留谓词的值

```
while* ( pred body -- )
```

`while` 只关心它的谓词是否留下了一个真值，它会在运行循环体之前把这个值本身丢掉。`while*` 则相反，会*把这个值交给循环体*。只要测试和循环体需要同一个刚算出来的东西，比如一次查找、一次匹配、一个解析出来的 token，就该用它。

这里每个名字都指向链中的下一个名字。谓词查找当前的名字；只要还有下一个名字，`while*` 就把它交给循环体，循环体把它打印出来，再从那里继续：

```factor
USING: assocs kernel locals prettyprint ;

:: print-chain ( start links -- )
    start [ links at ] [ dup . ] while* ;

"a" H{ { "a" "b" } { "b" "c" } } print-chain
! prints "b" then "c"
```

`links at` 会返回下一个名字，某个名字没有对应条目时就返回 `f`。只要它返回的是一个名字，`while*` 就把这个名字交给 `dup .`，后者把它打印出来，并留在栈上作为下一次查找的键。第一个 `f` 会让循环停止，`while*` 把它丢掉，所以不会留下任何多余的东西。

## 用局部变量承载多个状态值

当循环要携带不止一个值，比如一个剩余的列表和一个累计的总和，在栈上倒腾来倒腾去就很乱。最干净的做法是用 `::` 声明*局部变量*：

```
:: word ( inputs -- outputs ) ... ;
```

在循环体内部，`:> name!` 会添加一个可变的局部变量；读取时用 `name`，写入时用 `name!`（它会把新值从栈上取走并赋给它）。

```factor
USING: kernel locals math sequences ;

! Walk a sequence from the front, summing as we go
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0   :> running!
    [ rest empty? ] [
        rest unclip [ rest! ] dip
        running + running!
    ] until
    running ;
```

这里的两个局部变量（`rest` 和 `running`）覆盖了整个循环的状态：谓词检查它们，循环体更新它们，最后返回最终的值。

`unclip ( seq -- rest first )` 会把序列的第一个元素剥下来，当循环想每次迭代消耗列表里的一个元素时很方便。`[ rest! ] dip` 这种写法把 `rest` 更新成剩余的尾巴，同时把刚弹出的元素留在栈上供循环体使用。
