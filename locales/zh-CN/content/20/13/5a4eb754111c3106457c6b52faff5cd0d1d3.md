# 简介

当你要根据多个离散的可能值进行分派时，`case`（位于[`combinators`][combinators]中）比一连串`if`更简洁。

## `case`

```
case ( obj assoc -- )
```

`case`会从栈顶取下值，以及一个由子句组成的*assoc*。每个子句都是`{ value [ body ] }`。第一个其值`=`输入值的子句胜出；它的主体运行时，输入值已经被消耗掉。末尾只有一个`[ body ]`的条目是默认分支，它运行时输入*仍在栈上*。

```factor
USING: combinators ;

: name-of ( n -- s )
    {
        { 1 [ "one" ] }
        { 2 [ "two" ] }
        [ drop "many" ]
    } case ;
```

相等性通过`=`判断，因此任何比较相等的值都可以作为键，数字、字符串和符号都可以。

## `cond`用于带守卫的分支

当选择取决于*谓词*而不是相等性时（例如`x > 11`），`cond`就是对应的工具。你已经在[汽车，组装！][cars-assemble]中见过`cond`。

## 符号

`SYMBOL:`声明一个会将自身压入栈的词，一个自求值的标签值。`SYMBOLS:`可以一次声明多个词：

```factor
SYMBOLS: yes no maybe ;
```

现在`yes`是一个值，可以用`=`比较，也可以用作 case 的键：

```factor
: invert ( ? -- ?' )
    { { yes [ no ] } { no [ yes ] } [ ] } case ;
```
