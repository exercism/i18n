# 关于

Perl v5 是一门高级通用编程语言，由 Larry Wall 发明，于 1987 年首次发布。
它是一门兼收并蓄的解释型、过程式、弱类型语言。
随着万维网的兴起，它的流行度达到顶峰；不过，它在质量保证、IT 基础设施自动化、文本处理、生物信息学和 Web 应用开发等领域至今仍被广泛使用，这里只列举了其中几个。
它非常灵活，但这种灵活性可能带来后续的维护成本。

Perl 还具备：

- 内置的对象支持很少，但第三方面向对象方案很有意思
- 一等函数
- 闭包
- 强大的内置正则表达式引擎
- [Comprehensive Perl Archive Network (CPAN)](http://www.cpan.org)，一个由用户贡献的庞大模块库

所有知名的 Unix 和类 Unix 操作系统都随附 Perl。
