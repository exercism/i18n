# 关于

`bit`是计算中最细粒度的值。
`bit`一词是“二进制数字”的缩写。
它是执行环境中的一种数据存储单位，大到足以容纳一个只能取两个值之一的对象。
因此，它的二进制值只能是`1`或`0`。
所有其他数据类型都由多个`bits`组成。
例如，一个`byte`通常由八个`bits`组成。

## 如何书写 bit 值

`Bits`构成了以 2 为基数的数制。
`2`的每一个倍数都会被放进我们通常所说的十位、百位、千位等位置，只不过这里的“十位”是“二”，“百位”是“四”，“千位”是“八”，依此类推。
所以，十进制值`2`对应的二进制值是`10`，`4`对应`100`，`8`对应`1000`。
和十进制数一样，越往左，各数位的权值越高。
我们可以把十进制值`5`看作二进制中的`101`：个位上有一个`1`，四位上也有一个`1`。
不过，二进制字面量并不属于 C 语言标准的一部分。
C 语言标准支持的二进制值只有单个的`1`或`0`。
二进制字面量_确实_被一些非标准的编译器扩展所支持，比如 gnu 编译器，只要在字面量前面加上`0b`即可。

```c
#include <stdio.h>

int main() {
    int binary_five = 0b101;
    printf("%d", binary_five);
    return 0;
}
```

要记住，这种写法并非所有编译器都支持，可能会成为代码在不同编译器之间移植的障碍。

编写二进制值的一种常见方式是使用十六进制表示法，也就是以 16 为基数的数制。
C 语言的十六进制表示法会在字面量前加上`0x`或`0X`。
由于十进制值`16`表示为十位上的`1`，因此十进制值`10`在十六进制中表示为`0xA`，`11`表示为`0xB`，`12`表示为`0xC`，`13`表示为`0xD`，`14`表示为`0xE`，`15`表示为`0xF`。
例如，十进制值`42`会写成`0x2A`：`2`乘以`16`（等于`32`）再加`10`（等于`42`）。

在二进制中，我们可以把`42`看作`00101010`：`32`加`8`再加`2`。
我们会说，从右数第二、第四和第六位是“置位”的，也就是说它们是`1`而不是`0`。
第二位是`2`，第四位是`8`，第六位是`32`。
把这三位置位就确定了一个值`42`。

## 位掩码

位掩码可以是任何用来设置各个位的值。
例如，英文字母表中有 26 个字母。
一个至少有 26 位的值，比如无符号 32 位整数，可以用作位掩码，为每个英文字母设置一个`true`或`false`的条件。
只要有足够的位来处理所需的一组`true`或`false`条件，任何值都可以充当位掩码。
设置和读取各个位都要通过位运算符来完成。

## 位运算符

假设我们要记录`string`中出现了哪些字母。
在示例中，我们只用英文字母表中的 26 个字母。
我们的位掩码将是一个无符号 32 位整数。
`0`表示该字母没有出现。
`1`表示该字母出现了一次或多次。
一开始，位掩码的位表示是连续 32 个`0s`：`00000000000000000000000000000000`。
最右边的位置对应`A`。
从右数第二位对应`B`，依此类推。
假设我们在循环中处理字符串里的所有字母，因此我们希望有一行代码能对设置任意字母都适用。

### 按位左移运算符：定位某一位的方法

`<<`是左移的位运算符。

如果字母是`A`，我们不需要左移；如果字母是`B`，我们想左移一位；如果字母是`C`，我们想左移两位，依此类推。
尽管我们可以把`chars`看作`A`或`B`这样的字母，但`char`在内存中是以整数类型实现的，所以我们可以用`char`做简单的数学运算。
假设有一个名为`letter`的变量，它代表我们正在处理的`char`，那么只要把`1`左移`letter`与`A`这个`char`的差值这么多位，就能完成所需的左移，就像这样：`1 << letter - 'A'`。
`A`减`A`等于`0`，所以如果`letter`是`A`，就左移`0`位。
`B`减`A`等于`1`，所以如果`letter`是`B`，就左移`1`位，依此类推。

### 按位或运算符：设置某一位的方法

一旦知道了想要设置的是_哪一位_，就可以用按位或运算符`|`来真正设置它。
只要左侧或右侧操作数在某一位上有置位，`|`运算符在该位的结果就是`1`。
所以，`0010 | 0001`的结果是`0011`。
（要记住，这个值在二进制中是`11`，在十进制中却是`3`。）
要把结果赋给某个值，可以把`|`运算符与赋值运算符组合起来设置位，就像这样：`|=`。
为了简单起见，下面的例子没有使用循环，但它演示了如何用位掩码处理字母`ABA`。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

我们为`A`把掩码最右边设为`0001`，然后为`B`把掩码设为`0011`。
再设置一个`A`不会改变现有的掩码。
我们可以先看看`A`是否已经置位，从而避免重复设置这一位。

### 按位与运算符：读取某一位的方法

`&`是按位与运算符。
只有当左侧和右侧操作数在某一位上都有置位时，`&`运算符在该位的结果才是`1`。
所以，`0011 & 0001`的结果是`0001`。
下面的例子展示了它的实际效果。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 按位异或运算符：翻转某一位的方法

`^`是按位异或运算符。
_包含_或运算符的存在，意味着还有一种行为不同的_异或_运算符。
只有当左侧或右侧操作数中_只有一个_在某一位上有置位时，`^`运算符在该位的结果才是`1`。
所以，`0001 ^ 0011`的结果是`0010`。
最右边的一位不会被置位，因为两个操作数在最右边位置上的都是`1`。
异或运算有时也写作 XOR。
如果对一个值做异或，再把得到的结果做一次异或，就会返回原来的值。
这可以用于一种非常简单的加密方式：同一个密钥既用来加密，也用来解密数据。
例如

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

### 按位右移运算符：将值减半的方法

`>>`是右移的位运算符。
通常，一个值的位每右移一位，结果就是该值除以二。
例如

```c
#include <stdio.h>

int main() {
    int number = 16;
    number >>= 2;
    // prints 4, or 16 / 2 = 8 / 2 = 4
    printf("%d\n", number);
}
```

如果右操作数的值为负，或者大于等于提升后的左操作数的宽度，那么行为是未定义的。
这同样适用于左移运算符。
如果用有符号整数代替无符号整数，那么符号性也可能起作用。
下面的例子展示了在有符号整数上左移或右移过多时，某个系统上的行为。

```c
#include <stdio.h>

int main() {
    int number = 16;
    number <<= 250;
    // prints 1073741824
    printf("%d\n", number);
    number <<= 1;
    // prints -2147483648
    printf("%d\n", number);
    number <<= 1;
    // prints 0
    printf("%d\n", number);
    // total shifts are now 256, done incrementally
    number <<= 4;
    // prints 0
    printf("%d\n", number);
    number = 16;
    // prints 16 when 256 total shifts done at once
    printf("%d\n", number << 256);
    // prints 0 when bits shifted right far enough
    printf("%d\n", number >> 5);    
    // still prints 0
    printf("%d\n", number >> 255);
    // prints 16 when shifted right far enough to "wrap around"
    printf("%d\n", number >> 256);
}
```

由于行为是未定义的，不同的系统可能会得到不同的结果。
移位时，了解所用数据类型的界限很重要。

## 位域

我们已经看到，打包进简单数据类型的位可以按位置来寻址。
打包进`struct`的位则可以按名称来寻址。
这样的数据类型称为`bit field`。
需要一组开/关标志，同时希望尽量减少内存占用时，就是`bit fields`的一个使用场景。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`这样的语法会在结构体内创建一个位于`unsigned int`中的`1`位字段。
除了`unsigned int`，也可以使用`signed int`；或者从 C99 起，还可以使用`bool`类型。
包含位字段的结构体也可以包含其他数据类型的字段，比如上面例子中的`number_of_lights`。
