# 简介

泛型让你可以编写适用于多种类型、而无需重复的代码。
使用尖括号`<T>`来定义泛型类型，其中`T`是任意类型的占位符。

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

Cairo 要求使用 trait 约束来指明泛型类型必须支持哪些操作。
你可以使用`+`语法来添加约束：

```rust
fn process_data<T, +Drop<T>, +Copy<T>>(value: T) -> T {
    // Function body
}
```

结构体也可以是泛型的：

```rust
#[derive(Drop)]
struct Container<T> {
    value: T,
}
```

trait 本身也可以是泛型的，这样它们就能与不同的类型一起工作：

```rust
trait Processor<T> {
    fn process(self: @T) -> ByteArray;
}

impl MyProcessor<T, +Drop<T>> of Processor<T> {
    fn process(self: @T) -> ByteArray {
        "processed"
    }
}
```

函数可以接受带 trait 约束的泛型参数，从而适用于任何实现了所需 trait 的类型：

```rust
fn use_processor<T, +Processor<T>, +Drop<T>>(item: T) -> ByteArray {
    item.process()
}
```
