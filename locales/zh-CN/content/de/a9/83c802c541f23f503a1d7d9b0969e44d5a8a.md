# 指令附录

## 实现

在国际象棋中，行叫做“rank”，列叫做“file”。rank 的取值范围是 1 到 8，file 的取值范围是 A 到 H。

在本练习中，`Square` 是一种不透明类型，表示棋盘上的一个格子。它的内部使用从 0 开始计数的`row`和`column`字段，并保证这两个字段始终有效（即从 0 到 7）。

`create` 函数接收一个`Str`作为输入，用官方记谱法表示棋盘上一个有效的格子，例如 `"C5"`。`create` 函数必须解析这个`Str`，验证它确实表示一个有效的格子；如果是，就返回一个`Square`值，其中包含相应的`row`和`column`字段。rank 1 对应 row 0，rank 8 对应 row 7。例如，`create("C5")` 必须返回一个 row 为 4、column 为 2 的格子。

`Square` 类型还提供了便捷的`rank`和`file`方法。在上面的例子中，`rank` 必须返回整数 `5`，`file` 必须返回字符 `'C'`。

最后，`queen_can_attack` 函数接收两个不同的`Square`值，检查放在这两个格子上的皇后能否互相攻击。

要点：当你想要提供一些保证时，比如`row`和`column`始终在 0 到 7 之间，像`Square`这样的不透明类型就非常合适。不透明类型还会对使用者隐藏实现细节，让 API 更简洁。
