# 简介

处理输入和输出的函数由`IO`模块提供。

## 输出

要把字符串写到标准输出，可以用`IO.puts`。`IO.puts`总是会在字符串末尾加上一个换行。如果你不想要这种行为，可以改用`IO.write`。如果执行成功，这两个函数都会返回原子`:ok`。

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts`很适合写字符串，但也仅此而已。如果你需要一个调试工具，把任意值写到标准输出，可以改用`IO.inspect`。`IO.inspect`会原样返回传给它的值，因此可以插到代码中的任何位置。它还接受许多选项，比如`:label`，让你能把它和其他`IO.inspect`调用区分开。

## 输入

要从标准输入读取一行，可以用`IO.gets`。`IO.gets`接受一个实参：一个字符串，它会把这个字符串作为输入提示打印出来。`IO.gets`不会在提示后面加换行，有需要的话自己加上。

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
