# 安装

## PowerShell 语言 track 的要求

Exercism 的 PowerShell 语言 track 要求你的系统上安装有：

- PowerShell 或 Windows PowerShell Core
- 已安装 Pester 测试与 mock 框架模块

（注：PowerShell 的支持仅限于关键修复。PowerShell Core 持续维护，跨平台支持更好）

### 安装 PowerShell

从 Windows 7 SP1 起，所有 Windows 操作系统都预装了 PowerShell。

你可以在[这里][installation]找到最新版本的 PowerShell，以及适用于所有平台（Linux、macOS 和 Windows）的安装说明。

也可以获取 [PowerShell][source-code] 的源代码和手动安装方式。

### 安装和更新 Pester 框架

[Pester][pester] 是 PowerShell 的测试框架。
从 4.0.9 版本起，它兼容 Windows、Linux 和 MacOS 上的 PowerShell Core（有一些限制）。

它在 Windows 10 上已预装，不过建议你运行下面的 PowerShell 命令来更新：

```PowerShell
Install-Module -Name Pester -Force -SkipPublisherCheck
```

之后的更新，运行：

```PowerShell
Update-Module -Name Pester
```

如有需要，更多安装说明请见：[https://github.com/pester/Pester/wiki/Installation-and-Update]()

## 使用 IDE

如果你想要功能更完整的编辑体验，可能需要用 IDE。
下面这些是支持构建 PowerShell 项目的最流行的 IDE：

### 所有平台

- [PowerShell ISE（集成脚本环境）][ise]，随 PowerShell 一起提供的内置图形化 IDE（仅限 Windows）。
  要启动 PowerShell ISE，在 PowerShell 控制台中输入`powershell_ise.exe`。
- [Visual Studio Code][vsc] 加上 [PowerShell 扩展][vsc-extension]。
  用 Visual Studio Code 还能运行测试，也能调试代码。
- [Sublime Text 3][sublime] 加上 [PowerShell 包][sublime-package]。
