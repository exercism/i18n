# 字符串方法

`String`有多个方法可以用来操作字符串。  
这些方法在字符串本身上调用，而且经常会串联使用，对字符串执行多种操作。

下面列出一些最常用的方法。
完整的方法列表请参阅 [`String` API 文档][string-api]。

## String#upcase、String#downcase

[`upcase`][upcase]方法会返回一个新字符串，其中所有字符都转换为大写。

```crystal
"hello".upcase
# => "HELLO"
```

[`downcase`][downcase]方法会返回一个新字符串，其中所有字符都转换为小写。

```crystal
"HELLO".downcase
# => "hello"
```

## String#capitalize、String#camelcase、String#underscore、String#titleize

还有一些方法可以完成更具体的大小写转换。
在把字符串转换成特定格式时，这会很有用。
下面列出其中一些最常用的方法：

| 方法                              | 说明                                                                                                               | 示例                                                 |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- |
| [`String#capitalize`][capitalize] | 把第一个字母转换为大写，其余字母转换为小写                                                   | `"hEllO" # => "Hello"`                               |
| [`String#camelcase`][camel-case]  | 把下划线转换为驼峰式                                                                                   | `"eiffel_tower" # => "EiffelTower"`                  |
| `String#camelcase(lower: true)`   | 与 String#camelcase 相同，但第一个字符保持小写                                                 | `"empire_state_building" # => "empireStateBuilding"` |
| [`String#underscore`][underscore] | 把所有字符转换为小写，并在小写字母和大写字母之间插入下划线 | `"PartyInTheUSA" # => "party_in_the_usa"`            |
| [`String#titleize`][titleize]     | 把每个单词的首字母大写，其余字母小写                                                   | `"the great gatsBY" # => "The Great Gatsby"`         |

## String#sub、String#gsub

Crystal 提供了用于替换字符串中部分内容的方法。
它们分别是 [`sub`][sub]（_替换_）和 [`gsub`][gsub]（_全局替换_）。

这两个方法的第一个参数可以是字符串、`Char`或正则表达式，第二个参数可以是字符串或`Char`。
第一个参数是字符串中要被替换的部分，第二个参数是替换后的内容。
`Char`和正则表达式会在后面的概念中讲解。

`sub`方法会把第一个参数第一次出现的内容替换为第二个参数。

```crystal
"hello".sub("l", "r")
# => "herlo"
```

`gsub`方法的用法与`sub`相同，但会把第一个参数出现的所有位置都替换为第二个参数。

```crystal
"hello".gsub("l", "r")
# => "herro"
```

## String#chomp、String#strip

chomp 和 strip 可以用来删除字符串中不需要的字符。

默认情况下，[`chomp`][chomp]方法会删除字符串末尾的`\r`、`\n`或`\r\n`字符。
如果调用时传入了参数，它会从字符串末尾删除给定的值。
前提是字符串末尾确实有这个值。

```crystal
"hello\n".chomp
# => "hello"

"hello".chomp("llo")
# => "he"
```

默认情况下，[`strip`][strip]方法会删除字符串开头和末尾的所有空白字符。
如果调用时传入了参数，它会从字符串的开头和末尾删除该参数。
前提是字符串的开头或末尾确实有这个值。

```crystal
" hello ".strip
# => "hello"
```

## String#reverse

可以用[`reverse`][reverse]方法反转字符串。
该方法会返回一个新字符串，其中的字符顺序被反转。

```crystal
"hello".reverse
# => "olleh"
```

## String#index

可以用[`index`][index]方法查找某个字符在字符串中的下标。
`index`方法接受`String`、`Char`或正则表达式作为参数。
它还可以接受一个可选的第二个参数，用来指定从哪个下标开始搜索。
`index`方法会返回参数第一次出现的下标。

```crystal
"hello".index("l")
# => 2

"hello".index("l", 3)
# => 3
```

## String#delete_at

可以用[`delete_at`][delete_at]方法删除字符串中的一个字符。
`delete_at`方法接受一个下标作为参数，并删除该下标处的字符。

```crystal
"hello".delete_at(0)
# => "ello"

"hello".delete_at(3)
# => "helo"
```

## String#insert

可以用[`insert`][insert]方法在指定的下标处插入一个字符串。
`insert`方法的第一个参数是下标，第二个参数是字符串。
`insert`方法会返回一个新字符串，第二个参数会被插入到该下标处。

```crystal
"hello".insert(0, "h")
# => "hhello"

"hello".insert(3, "l")
# => "helllo"
```
