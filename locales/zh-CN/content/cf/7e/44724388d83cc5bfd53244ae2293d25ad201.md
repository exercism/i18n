# 简介

函数让你可以把代码组织成一个可复用的单元。
它由 `func`关键字、函数名，以及圆括号中用逗号分隔的零个或多个形参和类型组成。

## 函数形参

所有形参都必须显式指定类型；形参没有类型推断。
形参没有默认值，因此函数的每个形参都是必需的。

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

类型相同的形参可以写在一起，后面跟一个类型声明。

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## 形参与实参

我们先快速讲一下两个经常被弄混的术语：`parameters`和`arguments`。
函数形参是函数签名中定义的名称，比如上面 `PrintGreetingName`函数里的 `greeting`和`name`。
函数实参则是我们调用函数时，传给形参的具体值。
例如在下面的例子里，`"Hello"`和`"Katrina"`就是传给 `greeting`和`name`这两个形参的实参：

```go
PrintGreetingName("Hello", "Katrina")
```

## 返回值

形参之后是零个或多个返回值，它们同样必须显式指定类型。
单个返回值直接写出来，多个返回值则用括号括起来。
函数使用 `return`关键字把值返回给调用方。
一个函数里可以有多个 `return`语句。
一旦执行到其中某个 `return`语句，函数就会立即结束。
如果函数要返回多个值，它们之间用逗号分隔。

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## 调用函数

调用函数时，要写出函数名，并在括号里为函数的每个形参传入实参。

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## 命名返回值与裸返回

和形参一样，返回值也可以选择命名。
如果使用了命名返回值，那么不带参数的 `return`语句就会返回这些值。
这被称为“裸”返回。

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
