# 简介

Julia 的一个核心目标，就是能够快速、高效地对数值数据进行计算。
_海量_的数值数据。

通常，这些数据会存放在数组（或某种相关的类型）中，所以完全可以说，数组是 Julia 语言的核心。

数组可以有任意大小（仅受硬件内存的限制），也可以有任意多的维度。

这篇入门概念聚焦于一维数组的基础知识，在 Julia 中，一维数组称为 Vector。

## 创建 Vector

在 Julia 中，Vector 是一个有序的值序列，可以通过下标访问其中的值。

创建 Vector 最简单的方法，就是把各个值写进方括号里：

```julia-repl
julia> num_vec = [1, 4, 9]
3-element Vector{Int64}:
 1
 4
 9

julia> str_vec = ["arrays", "are", "important"]
3-element Vector{String}:
 "arrays"
 "are"
 "important"
```

Vector 的类型与每个元素的类型一致。

_那么 Vector 必须是同质的（所有元素类型相同）吗？_

从某种意义上说，是的，而且如果你追求最佳性能，建议尽量做到这一点。
不过，在必要时，Julia 可以借助`Any`类型绕过这一限制：

```julia-repl
julia> mixed_vector = [1, "str", 'c']
3-element Vector{Any}:
 1
  "str"
  'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
```

创建空 Vector 时，Julia 默认的元素类型是`Any`，不过只要给空数组标注上想要的元素类型，就能把它指定得更具体。

```julia-repl
julia> empty_vec = []
Any[]

julia> empty_int_vec = Int64[]
Int64[]
```

# 下标

请阅读并记住这条规则：

- ***默认情况下，Julia 的下标从 1 开始，而不是 0***。

用过其他数据科学语言（R、Matlab、Fortran 等）的人对此很熟悉，但对有类 C 语言背景的计算机科学家来说，可能会觉得难以置信。

除此之外，下标的用法和你想的一样：把它们写在方括号里就行：

```julia
squares = [0, 1, 4, 9, 16]
squares[1]  # 0
squares[3]  # 4
squares[begin]  # 0 ("begin" is synonym for 1)
squares[end]  # 16 ("end" is synonym for length(squares))
```

注意用`end`（非常有用）和`begin`（大概没什么用）做下标有多方便。

Python 程序员可能会好奇负下标的情况。
别想了：Julia 没有负下标，用它会抛出`BoundsError`；任何小于 1 或大于`length(squares)`的下标也一样。

## Vector 的操作

Julia 中的 Vector 是_可变的_：我们可以修改单个格子里的内容。

```julia-repl
julia> vals = [1, 3, 5, 7]
4-element Vector{Int64}:
 1
 3
 5
 7

julia> vals[2] = 4  # reassign the value of this element
4

# Only the value at position 2 changes:
julia> vals
4-element Vector{Int64}:
 1
 4
 5
 7
```

有很多函数可以用来操作 Vector，不过 Julia 文档把它们泛化成了“集合”，而不只是 Vector。

注意，按照惯例，会修改输入的函数，名字里都带一个`!`。
编译器不会强制这一点，但这是 Julia 世界里一条非常_强_的惯例。

这里列出几个有用的函数：

- 要在 Vector 末尾添加值，使用`push!()`。
- 要移除最后一个值，使用`pop!()`。
- 要对 Vector 的开头进行操作，对应的函数是`pushfirst!()`和`popfirst!()`。
- 要在任意位置插入或移除元素，可以使用`insert!()`和`deleteat!()`。

```julia-repl
julia> vals = [1, 3]
2-element Vector{Int64}:
 1
 3

julia> push!(vals, 5, 6)  # can add multiple values
4-element Vector{Int64}:
 1
 3
 5
 6

julia> pop!(vals)  # mutates vals, return popped value
6

julia> vals
3-element Vector{Int64}:
 1
 3
 5
```
