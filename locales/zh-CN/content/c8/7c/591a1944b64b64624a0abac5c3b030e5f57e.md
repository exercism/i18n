# 简介

循环基本上分两种：

1. 一直循环，直到某个条件得到满足。
2. 遍历集合中的元素。

在 Julia 中这两种都可行，不过第二种可能更常见。

## `while`循环

对于循环次数事先未知的开放式问题，Julia 提供了`while`循环。

基本形式相当简单：

```julia
while condition
    do_something()
end
```

在这种情况下，程序会不断循环，直到`condition`不再是`true`。

有两种提前退出循环的方式：

- `break`会让循环退出，程序从循环`end`之后的那一行继续执行。
- `return x`会停止当前函数的执行，并把返回值`x`传回给调用方。

有了这些手段，有时可以先创建一个“无限”循环`while true ... end`，再依靠在循环体内部找到停止条件来触发`break`或`return`，这样会很方便。

## 遍历集合

最简单的例子是遍历一个范围。

如果我们想把某件事做 10 次：

```julia
for n in 1:10
    do_something(n)
end
```

如果当前迭代不满足某个条件，可以用`continue`立即跳到下一次迭代：

```julia
for n in 1:10
    if is_useless(n)
        continue
    end
    
    # we decided this iteration could be useful
    do_something_slow(n)
end
```

更简短的形式是，把`if`块替换成`is_useless(n) && continue`。

还可以遍历许多其他集合类型：数组中的元素、字符串中的字符、字典中的键……

到目前为止的例子都在遍历范围`1:10`，其中的值同时也是循环下标。

更一般地说，需要的可能不只是值，还有下标。
为此可以使用`eachindex()`函数，例如`for i in eachindex(my_array) ... end`。
