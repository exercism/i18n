# 说明

你受聘成为一家为乌龟生产被子的公司的助理生产工程师。

订单会在一天中陆续送来，内容包括客户姓名或编号以及订购数量。
这些订单会在早上、当天的生产开始之前处理完毕。

只要当天的订单全部完成，你就可以拿全额工资回家，所以你有动力尽可能缩短工作时间。
由于每个订单都由单台机器处理，先安排最大的订单可以把启动一项任务的额外开销转嫁到较小的订单上，从而缩短总的生产时间。
因此，你决定提供一些排序函数来帮助加快排程，这样你就能回家给你的乌龟织毛衣了。

## 1. 对数量排序！

如前所述，数量数组需要按从大到小排序。
由于这些数组可能很大，应当*原地*排序。
为了正确地跟踪所有内容，你还需要能够对客户数组排序，使其与数量一一对应，因此需要数量数组的排序置换。

编写一个函数 `sortquantity!(qty)`，它接收一个由`Integer`数量组成的`Vector`。
该函数会原地按降序对输入的`qty`排序，并返回这一顺序的排序置换。

```julia-repl
julia> qty = [8, 9, 5, 6]
4-element Vector{Int64}:
 8
 9
 5
 6

julia> sortquantity!(qty)
4-element Vector{Int64}:
 2
 1
 4
 3

julia> qty # original vector is sorted in-place
4-element Vector{Int64}:
 9
 8
 6
 5
```

## 2. 对客户排序

如上所述，你需要按照确定的顺序跟踪客户。

编写一个函数 `sortcustomer(cust, srtperm)`，它接收一个客户`Vector`（`cust`）和一个排序置换`Vector`（`srtperm`）。
该函数返回一个新数组，其中的客户按照排序置换指定的顺序排列。

```julia-repl
julia> cust = ["a", "b", "c"]
3-element Vector{String}:
 "a"
 "b"
 "c"

julia> sortcustomer(cust, [2, 3, 1])
3-element Vector{String}:
 "b"
 "c"
 "a"

julia> cust # original vector remains unsorted
3-element Vector{String}:
 "a"
 "b"
 "c"
```

## 3. 生产计划！

现在你可以把它们组合起来，帮助那些乌龟保持温暖了！
你现在可以正确地排序数量和客户了，但为了发货，你还需要能够恢复原来的顺序。
这可以通过逆排序置换来实现。

编写一个函数 `production_schedule!(cust, qty)`，它接收一个客户`Vector`和一个数量`Vector`。
该函数会原地按降序对数量排序。
它返回一个新的客户`Vector`，其中的客户与数量顺序相同，以及一个*逆*排序置换，可用于把排序后的向量恢复为原来的顺序。

```julia-repl
julia> cust, qty = ["a", "b", "c"], [2, 3, 1]
(["a", "b", "c"], [2, 3, 1])

julia> orderedcust, invperm = production_schedule!(cust, qty)
(["b", "a", "c"], [2, 1, 3])

julia> qty # has been sorted in-place
3-element Vector{Int64}:
 3
 2
 1

julia> orderedcust[invperm], qty[invperm] # inverse permutation gives original ordering
(["a", "b", "c"], [2, 3, 1])
```
