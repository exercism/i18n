# 关于

在 F# 中处理数字时，一个关键点是区分整数（小数点后没有数字的数）和浮点数（小数点后有零个或多个数字的数）。

F# 中最常用的两种数值类型是 `int`（32 位整数）和 `float`（64 位浮点数）。

```fsharp
let i = 123   // Type is `int`
let d = 54.29 // Type is `float`
```

整数和浮点数都可以使用 `_` 字符作为*数字分隔符*，这在定义较大的数字时会很有帮助：

```fsharp
let largeInt = 1_000_000
// => 1000000

let largeFloat = 9_876_543.21
// => 9876543.21
```

算术运算使用标准的[算术运算符][arithmetic-operators]（`+`、`-`、`*` 等）完成。数字可以使用[标准比较运算符][comparison-operators]（`<`、`>=` 等）以及相等（`=`）和不等（`<>`）运算符进行比较。

```fsharp
5 * 6
// => 30

1.2 > 0.8
// => true

2 <> 4
// => true
```

要在数值类型之间转换，必须使用内置的[转换运算符][conversion-operators]。这些运算符以它们要转换到的类型命名。

```fsharp
let floatFromInt = float 2
let intFromFloat = int 3.39
```

在类型之间转换时，一定要小心。如果某个值无法用目标类型表示，该值就会*溢出*。
