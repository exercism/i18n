# If、Elseif 和 Else

使用`if`、`elseif`和`else`的分支语句是程序控制流的基础组成部分。`if`语句会对一个表达式求值，如果结果为`true`，就执行对应的代码分支。

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

如果表达式不是布尔值，那么判断的依据就是这个值的“真值性”，也就是它是否“不为假”。在 PHP 中，以下值都被认为等于 false：

- 布尔值`false`
- 整数`0`
- 浮点数`0.0`和`-0.0`
- 空数组`[]`
- 空字符串`""`或数字字符串`"0"`
- `null`

其他所有值都被认为是 true。

## 处理多个条件

在`if`语句之后，你可以用`elseif`和`else`串联多个条件。

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

只有一个求值为真的分支会被执行。所以，如果多个条件都可能为真，它们的书写顺序就很重要。

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
