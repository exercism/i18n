# 说明

Josh 正在开发一款新的角色扮演游戏，需要你帮忙实现其中的一些机制。

## 1. 定义联合类型

定义一个`String`和`Missing`的联合类型，命名为`StringOrMissing`，以便在后面的代码中使用。
定义一个`Int64`和`Nothing`的联合类型，命名为`IntOrNothing`，以便在后面的代码中使用。

## 2. 实现 Player 复合类型

Player 复合类型应包含四个字段，每个字段都有类型标注和一个默认值：
- `name`的类型是`StringOrMissing`，默认值为`missing`
- `level`的类型是`Int64`，默认值为`0`
- `health`的类型是`Int64`，默认值为`100`
- `mana`的类型是`IntOrNothing`，默认值为`nothing`

```julia-repl
julia> defaultplayer = Player()
Player(missing, 0, 100, nothing)

julia> wealthyplayer = Player(mana=100)
Player(missing, 0, 100, 100)

julia> namedplayer = Player(name="Guilian", level=10)
Player("Guilian", 10, 100, nothing)
```

## 3. 自我介绍

实现`introduce`函数。

潜行的玩家可能会隐藏自己的名字，这时会用`"Mighty Magician"`来介绍他们。
否则，直接用玩家的名字来介绍他们。

```julia-repl
julia> introduce(Player(level=2, health=8))
"Mighty Magician"

julia> introduce(Player(name="Merlin", level=2, health=8))
"Merlin"
```

## 4. 实现 increment 方法

`increment`辅助函数有两个方法，每个方法都有不同的函数签名。
每个方法的实参都需要类型标注，以明确签名。

用于名字的`increment`方法应接收玩家的`name`。
- 如果名字是`missing`，返回称号“The Great”。
- 否则，把称号“ the Great”添加到名字上。

这个`increment`方法返回新的名字。

```julia-repl
julia> player1 = Player(name="Ogre", level=5, health=49, mana=26)
Player("Ogre", 5, 49, 26)

julia> increment(player1.name)
"Ogre the Great"

julia> player2 = Player(level=32, mana=57)
Player(missing, 32, 100, 57)

julia> increment(player2.name)
"The Great"
```

用于法力的`increment`方法应接收玩家的`mana`。
- 如果玩家的法力是`missing`，返回值`50`。
- 否则，法力增加`100`。

这个`increment`方法返回更新后的法力。

```julia-repl
julia> player3 = Player(level=3)
Player(missing, 3, 100, nothing)

julia> increment(player3.mana)
50

julia> player4 = Player("Goblin", level=15, health=49, mana=26)
Player("Goblin", 5, 49, 26)

julia> increment(player4.mana)
126
```

## 5. 实现 title 函数

游戏中的最高等级是`42`。为了表彰达到这一等级的玩家，会在他们的名字上附加一个称号。`title!`函数会按以下方式更新玩家的名字。

- 如果玩家的等级是 42，就用`increment`函数更新名字。
- 否则，名字保持不变。

无论哪种情况，`title!`函数都会返回玩家的名字。

```julia-repl
julia> player1 = Player(level=42, health=12)
Player(missing, 42, 12, nothing)

julia> title!(player1)
"The Great"

julia> player1.name
"The Great"

julia> player2 = Player(name="Svengali", level=42, health=36, mana=54)
Player("Svengali", 42, 36, 54)

julia> title!(player2)
"Svengali the Great"

julia> player2.name
"Svengali the Great"

julia> player3 = Player(name="Rasputin", level=21, health=100, mana=54)
Player("Rasputin", 21, 100, 54)

julia> title!(player3)
"Rasputin"

julia> player3.name
"Rasputin"
```

## 6. 实现 revive 函数

`revive!`函数应检查玩家的角色是否确实已经死亡（生命值降到了`0`）。

如果玩家已经死亡：
- 应该以`100`点生命值让玩家复活。
- 用`increment`函数增加玩家的法力。

如果玩家还活着，则玩家不会有任何变化。

`revive!`函数应返回玩家。

```julia-repl
julia> deadplayer1 = Player(level=2, health=0)
Player(missing, 2, 0, nothing)

julia> revive!(deadplayer1)
Player(missing, 2, 100, 50)

julia> deadplayer2 = Player(level=12, health=0, mana=5)
Player(missing, 12, 0, 5)

julia> revive!(deadplayer2)
Player(missing, 12, 100, 105)

julia> aliveplayer = Player(level=23, health=1)
Player(missing, 23, 1, nothing)

julia> revive!(aliveplayer)
Player(missing, 23, 1, nothing)
```
