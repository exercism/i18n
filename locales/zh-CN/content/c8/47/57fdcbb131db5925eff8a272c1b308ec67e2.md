# 说明

你的朋友 Li Mei 经营着一家果汁店，卖各种美味的混合果汁。你是她店里的常客，发现可以用一些 Factor 代码让她的生活轻松一点。

## 1. 确定调制一杯果汁需要多长时间

Li Mei 喜欢提前告诉顾客，点菜单上的一杯果汁要等多久。她很难记住确切的数字，因为调制不同果汁所需的时间各不相同：

- `"Pure Strawberry Joy"`需要`0.5`分钟。
- `"Energizer"`和`"Green Garden"`各需要`1.5`分钟。
- `"Tropical Island"`需要`3`分钟。
- `"All or Nothing"`需要`5`分钟。
- 所有其他饮品（例如特价饮品）都需要`2.5`分钟。

定义`time-to-mix-juice`，从栈上取下一个果汁名称，返回调制这杯饮品所需的分钟数。

```factor
"Tropical Island" time-to-mix-juice .
! => 3

"Berries & Lime" time-to-mix-juice .
! => 2.5
```

## 2. 补充青柠角

Li Mei 的很多作品都会用到青柠角，无论是作为配料还是作为装饰的一部分。所以早上开始上班时，她要确保装青柠角的盒子是满的，够应付接下来这一天。

定义`wedges-from-lime`，它接收一个青柠大小，返回这个青柠能切出的青柠角数量：`"small"`的青柠是`6`个，`"medium"`是`8`个，`"large"`是`10`个。

然后定义`limes-to-cut`，它接收`needed`（所需的青柠角数量）和一个`limes`数组（按切开顺序排列的青柠大小）。它会按顺序逐个切开青柠，一旦青柠角的数量够了，或者青柠用完了，就立即停下。返回它必须切开的青柠数量。

```factor
25 { "small" "small" "large" "medium" "small" } limes-to-cut .
! => 4
```

## 3. 列出队列中每笔订单的调制时间

Li Mei 喜欢记录调制顾客正在等待的订单需要多长时间。

定义`order-times`，它接收一个订单数组，返回一个数组，按相同的顺序给出每笔订单的调制时间。

```factor
{ "Energizer" "Tropical Island" } order-times .
! => { 1.5 3 }
```

## 4. 结束这一班

Li Mei 总是工作到下午 3 点。之后由她的员工 Dmitry 接手。Li Mei 的班结束时，常常还有已经下单但还没调制的饮品；Dmitry 会接着调制剩下的果汁。

为了让交接更顺利，定义`remaining-orders`，它接收`time-left`（Li Mei 班次剩余的分钟数）和一个`orders`数组（已经下单但还没调制的果汁）。返回 Dmitry 需要接手的订单，也就是 Li Mei 在下班前没时间开始的那些。

`time-left`总是大于`0`。订单按它们在数组中出现的顺序调制。Li Mei 一旦开始调制一杯果汁，就一定会把它做完，哪怕要多工作一会儿。如果她有足够时间开始每一笔订单，就返回空数组。

```factor
5 { "Energizer" "All or Nothing" "Green Garden" } remaining-orders .
! => { "Green Garden" }
```
