# 基础

一个 Sather 程序由**类**构成，**类**里装着**例程**。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

## 类

类名用大写字母书写，单词之间用下划线连接：`GREETER`、`STAGE_DIRECTIONS`。文件名通常与之对应，只是改用小写：`stage_directions.sa`。

每个例程都写在某个类里面。类外面没有任何代码。

## 例程

会返回结果的例程，要在冒号后面声明结果的类型：

```sather
   hello : STR is
      return "Hello!";
   end;
```

`STR`是文本的类型。不接受形参的例程，定义和调用时都不写括号。

例程也可以接受形参，写在名字后面的括号里：

```sather
   louder(word : STR) : STR is
      return word;
   end;
```

`return`把结果交回去，并立刻结束例程，所以它下面的所有行都会被跳过。

## 调用

从类外面调用时，先写类名，再写`::`，最后写例程名：

```sather
GREETER::hello
```

在同一个类里面，可以省略类名。这是让一个例程使用另一个例程的常见做法：

```sather
   greeting_again : STR is
      return hello;
   end;
```

## 注释

两个连字符开始一段注释，一直延续到行尾。

```sather
   -- Explain why, not what: the code already says what.
   hello : STR is
      return "Hello!";   -- a trailing comment is fine too
   end;
```

按照惯例，类的结尾会写一条注释说明类的名字。例程、循环和类都以`end;`结束，所以这条注释用来指明这个`end;`属于哪一个：

```sather
end; -- class GREETER
```

## 分号

语句以分号结尾。例程中最后一条语句后面的分号可以省略，不过每次都写上，就少了一件需要操心的事。
