# 说明

在本练习中，你需要实现一些函数来操作一个编程语言列表。

## 1. 定义一个返回空语言列表的函数

定义`language_list`函数，它不接受任何形参，返回一个空数组。

```php
<?php

language_list();
// => []
```

## 2. 修改函数，使其能根据任意数量的语言创建列表

修改`language_list`函数，让它接受可变数量的语言形参（字符串）。
它应返回包含这些语言的结果列表。

```php
<?php

$language_list = language_list();
// => []
$language_list = language_list("Clojure", "PHP");
// => ["Clojure", "PHP"]
$language_list = language_list("PHP", "Haskell", "Java", "C++", "Rust")
// => ["PHP", "Haskell", "Java", "C++", "Rust"]
```

## 3. 定义一个向列表中添加语言的函数

定义`add_to_language_list`函数，它接受 2 个形参：一个语言数组，以及要添加的新语言。

```php
<?php

$language_list = language_list();
// => []
$language_list = add_to_language_list($language_list, "Clojure");
// => ["Clojure"]
```

## 4. 定义一个从语言列表中移除元素的函数

定义`prune_language_list`函数，用于从语言数组中移除第一个语言。

```php
<?php

$language_list = language_list("PHP");
// => ["PHP"]
$language_list = prune_language_list($language_list);
// => []
```

## 5. 定义一个获取列表中第一个元素的函数

定义`current_language`函数，它接受 1 个形参（一个_语言列表_）。
它应返回列表中的第一个语言。
假定该列表至少有一个元素。

```php
<?php

$language_list = language_list("PHP", "Prolog");
// => ["PHP", "Prolog"]
$first = current_language($language_list);
// => "PHP"
```

## 6. 定义一个返回列表中有多少种语言的函数

定义`language_list_length`函数，它接受 1 个形参（一个_语言列表_）。
它应返回列表中语言的数量。

```php
<?php

$language_list = language_list("PHP", "Prolog", "Wren");
// => ["PHP", "Prolog", "Wren"]
language_list_length($language_list);
// => 3
```
