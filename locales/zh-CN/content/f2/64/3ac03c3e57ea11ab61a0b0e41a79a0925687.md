# 简介

强制转换和类型转换是两种不同的方式，都能把表达式从一种数据类型变成另一种。

可以用强制转换运算符`(<type>)`把表达式强制转换成另一种类型。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

如果类型不兼容，就会抛出`InvalidCastException`的实例。对数字来说，这意味着接收类型无法表示被转换的值。对类来说，其中一个类型必须派生自另一个类型（对结构体来说，这一点显然也同样适用）。

除了强制转换，另一种选择是使用`is`运算符进行类型转换。这通常用于引用类型和可空类型。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

如果需要检测对象的精确类型，`is`可能就有点过于宽松了，因为对于一个类以及它直接或间接派生的任何类和接口，它都会返回 true。这种情况下，`typeof`和`Object.GetType()`才是解决办法。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
