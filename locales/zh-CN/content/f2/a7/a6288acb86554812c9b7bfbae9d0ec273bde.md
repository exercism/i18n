# 简介

当循环的迭代次数事先无法确定时（“一直持续到某个谓词不再为真”），Factor 会用到 [`kernel`][kernel] 中的 `while` 组合子：

```
while ( pred body -- )
```

`pred` 和 `body` 都是操作数据栈的 quotation。`while` 会先调用 `pred`；如果 `pred` 在栈顶留下一个真值，`while` 就运行 `body` 然后重复；否则就停止。一次迭代到下一次迭代之间流动的状态，保存在两次调用之间的栈上（如果状态不止一份，则保存在具名局部变量里）。

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` 是对称的形式：它会持续运行，*直到*谓词变成真值。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
