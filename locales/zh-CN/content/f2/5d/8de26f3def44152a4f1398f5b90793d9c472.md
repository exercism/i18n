# 简介

代数数据类型（ADT）表示固定数量的具名情况，ADT 的每个值都恰好对应其中一个情况。

ADT 用`data`关键字定义，各个情况之间用竖线（`|`）分隔。如果所有情况都没有关联数据，这种 ADT 就类似其他语言通常所说的_枚举_（或 _enum_）。

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

ADT 的每个情况都可以选择性地关联数据，不同情况关联的数据类型也可以不同。情况关联了数据时，就必须使用构造函数。

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

要为某个特定情况创建值，只需引用它的名字（例如 `NInt 22`）。情况名本身就是构造函数，因此关联的数据可以像普通的函数实参一样传入。

ADT 具有_结构相等性_，也就是说，属于同一情况、且（可选的）数据也相同的两个值彼此等价。

虽然可以用`if/else`表达式来处理 ADT，但推荐的做法是使用模式匹配，也就是 _case_ 语句：

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
