# 关于

C++ 中的条件语句与其他语言中的条件语句类似。
任何条件运算的底层类型都是 `bool` 类型，其值可以是 `true` 或 `false`。
条件语句常被用作流程控制机制，用来检查各种条件。

可以使用 `if` 语句，当底层条件为 `true` 时执行它的代码，如下所示：

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

当涉及多种情况时，可以用 `else if` 和 `else` 语句把多个 `if` 语句串联起来。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

从 C++17 起，`if` 语句还可以包含一个简短的初始化语句，用来为 `if` 语句初始化一个或多个变量。
例如：

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：在初始化中创建的变量，在 if 语句结束后无法访问。
