# 忽略

## 额外的 jq 命令行选项

你会注意到，测试里为 `jq` 传入了额外的选项。

```sh
run jq -s -R -c -f minesweeper.jq << 'END_INPUT'
```

它们分别是什么意思？

- `-s`

  这是“slurp”模式。
  它不会把输入当作一串 JSON 对象来处理，
  而是把全部输入整个读进一个数组。

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  你可能已经见过 `-r`，它用来输出“原始”字符串（不带引号）。
  `-R` 正好相反。
  输入的每一行都会被当作一个字符串。

  两个例子：

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

把这两个选项放在一起时，你得到的**并不是**字符串数组，而是把整个输入当作一个字符串，末尾的换行也包含在内。

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

如何处理这一点，正是这道练习的挑战之一。
