# 说明补充

## 限制

Rust 的标准库中已经提供了[二分查找函数](https://doc.rust-lang.org/std/primitive.slice.html#method.binary_search)。这道练习中请不要使用这个函数，只用其他基本工具来实现。

## 加分项

测试都通过了吗？代码也写得足够干净吗？如果愿意，你还可以再尝试一些额外的内容。

- 目前你的 find 函数可能只适用于数字切片，但 Rust 的类型系统足够灵活，可以写出一个对所有切片都能用的 find 函数，只要切片里的元素可以排序。
- 此外，这个 find 函数不仅可以用在切片上，还能同时用在 Vec 或数组上。

要运行加分测试，请移除`#[ignore]`标记，并使用`generic` feature 来执行测试，就像这样：

```bash
$ cargo test --features generic
```
