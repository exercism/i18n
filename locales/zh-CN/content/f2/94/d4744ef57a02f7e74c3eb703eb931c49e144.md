# 说明

在本练习中，你将实现[二十一点][blackjack]的一些规则，比如游戏的玩法和计分方式。

**注意**：在本练习中，_`A`_ 表示 ace，_`J`_ 表示 jack，_`Q`_ 表示 queen，_`K`_ 表示 king。
大小王都被去掉。
这里假定使用的是一副[标准的 52 张法式扑克牌][standard_deck]，不过大多数玩法会把好几副牌洗在一起使用。

## 1. 计算一张牌的点数

在二十一点里，A 算 1 点还是 11 点，由每位玩家自己决定（_稍后会详细说明_）。
人头牌（`J`、`Q`、`K`）记 10 点，其他牌则按其“牌面点数”（_数值_）计分。

定义一个 `value_of_card(<card>)` 函数，参数为 `card`。
函数应返回传入的牌面字符串的_数值_。
由于 A 可以取多个值（1 **或** 11），这个函数暂时先把 A 的点数固定为 1。
稍后，你会实现一个函数，在已知现有手牌的情况下判断 A 的点数。

```python
>>> value_of_card('K')
10

>>> value_of_card('4')
4

>>> value_of_card('A')
1
```

## 2. 判断哪张牌的点数更高

定义一个 `higher_card(<card_one>, <card_two>)` 函数，参数为 `card_one` 和 `card_two`。
就计分而言，`J`、`Q` 或 `K` 的点数都是 10。
函数应返回到计分时点数更高的那张牌。
如果两张牌点数相同，就把两张都返回。
在 `return` 语句里用逗号，就可以同时返回两张牌：

```python
# Using a comma in a return creates a Tuple.  Tuples will be covered in a later exercise.
>>> def returning_two_values(value_one, value_two):
        return value_one, value_two

>>> returning_two_values('K', '3')
('K', '3')
```

A 可以取多个值，所以这个任务里我们把`A`的点数固定为 1。

```python
>>> higher_card('K', '10')
('K', '10')

>>> higher_card('4', '6')
'6'

>>> higher_card('K', 'A')
'K'
```

## 3. 计算 A 的点数

如前所述，A 可以算 1 点，_也可以_算 11 点。
玩家会尽量接近 21 点，但不能_超过_ 21 点（超过就叫“爆牌”）。

定义一个 `value_of_ace(<card_one>, <card_two>)` 函数，参数 `card_one` 和 `card_two` 是在拿到 A _之前_手里已有的一组牌。
你的函数要判断即将拿到的这张 A 算 1 点还是 11 点，并返回该值。
记住：加上这张 A 后，手牌的点数要尽可能高，但_不能_超过 21。

**提示**：如果手里已经有 A，那么即将拿到的这张 A 只能算 1 点。

```python
>>> value_of_ace('6', 'K')
1

>>> value_of_ace('7', '3')
11
```

## 4. 判断是否为“天生”或“二十一点”手牌

如果玩家最初拿到的两张牌是一张 A（`A`）和一张十点牌（10、`K`、`Q` 或 `J`），那么他的点数就是 21。
这就叫**二十一点**手牌。


定义一个 `is_blackjack(<card_one>, <card_two>)` 函数，参数 `card_one` 和 `card_two` 是一组牌。
判断这两张牌是不是**二十一点**，是就返回布尔值 `True`，否则返回 `False`。

**注意**：点数的_计算_可以有很多种做法。
但如果可以的话，我们希望你去检查手牌**_中_**（_或者某个特定位置上_）是否有一张 A 和一张十点牌，而不是去_累加_手牌的点数。

```python
>>> is_blackjack('A', 'K')
True

>>> is_blackjack('10', '9')
False
```

## 5. 分牌

如果手牌的前两张点数相同（_比如两张 6，或者一张 `Q` 和一张 `K`_），玩家可以选择把它们当成两手牌来打。
这就叫“分牌”。

定义一个 `can_split_pairs(<card_one>, <card_two>)` 函数，参数 `card_one` 和 `card_two` 是一组牌。
判断这手两张牌能否拆分成两对。
如果可以分牌，返回布尔值 `True`，否则返回 `False`

```python
>>> can_split_pairs('Q', 'K')
True

>>> can_split_pairs('10', 'A')
False
```

## 6. 加倍

当最初发到的两张牌总共 9、10 或 11 点时，玩家可以再下一次和原注相同的赌注。
这就叫“加倍”。

定义一个 `can_double_down(<card_one>, <card_two>)` 函数，参数 `card_one` 和 `card_two` 是一组牌。
判断这手两张牌能否“加倍”，可以就返回布尔值 `True`，否则返回 `False`。

```python
>>> can_double_down('A', '9')
True

>>> can_double_down('10', '2')
False
```
