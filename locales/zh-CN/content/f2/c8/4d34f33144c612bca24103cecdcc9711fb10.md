# 简介

Clojure 中的`vector`是一种有序、带索引、不可变的集合，可以包含零个或多个值。也就是说，向量一旦创建，就不能再修改。对向量进行操作的函数会返回一个新的向量，而原来的向量保持不变。向量中的值可以有不同的类型。向量可以这样定义：

```clojure
(def empty [])
(def single-value 5)
(def single-value-alternative (vector 5))
(def three-values [a b c]
```

可以使用下标从向量中取出元素。Clojure 的向量下标从零开始，也就是说第一个元素的下标始终是 0：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原来的向量保持不变：

```clojure
numbers
;;=> [2 3 5]
```

要记住更新后的值，需要把它传递下去，或者用一个 var 把它保存起来：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
