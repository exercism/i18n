# 关于

_字符串_是 JavaScript 中用来存储文本数据的数据类型。
单个字符并没有单独的数据类型。

## 创建字符串

把文本用单引号或双引号括起来，就创建了一个字符串[字面量][literal]。
在 Exercism 上，使用单引号。

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

文本中的某些特殊字符需要以反斜杠`\`作为前缀，参见 [MDN 上的转义序列][mdn-escape-sequences]。

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

除了单引号和双引号，你还可以用反引号把文本括起来创建字符串。
这种语法允许包含单引号、双引号，甚至换行，而不需要转义。
它还允许嵌入表达式，更多细节见[模板字符串][mdn-template-strings]。

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## 字符串是字符的数组

字符串可以看作字符的数组，其中第一个字符的下标是`0`。
用方括号加上你想获取的字符的下标，就能访问字符串中的单个字符。
此外，还有`charAt`方法。

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

访问`length`属性可以确定字符串中字符的个数。

```javascript
'cat'.length;
// => 3
```

## 拼接与方法

拼接字符串最简单的方式是使用加法运算符`+`。

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

字符串提供了很多辅助方法，完整列表见 [MDN 的字符串方法文档][mdn-string-methods]。
下面列出了一些常用的辅助方法。

- [`toUpperCase`][mdn-to-upper-case] 和 [`toLowerCase`][mdn-to-lower-case]：改变所有字符的大小写
- [`trim`][mdn-trim]：去掉开头和结尾的空白字符
- [`includes`][mdn-includes]、[`startsWith`][mdn-starts-with] 和 [`endsWith`][mdn-ends-with]：判断另一个字符串是否是给定字符串的一部分
- [`slice`][mdn-slice]：截取字符串的一部分

## 字符串不可变

调用上面的方法永远不会改变原始字符串，而是会创建并返回一个新的字符串。
在 JavaScript 中，字符串（以及其他原始数据类型）是不可变的。
这也意味着，你不能用上面展示的方括号语法给某个下标处的字符赋不同的值（就像在数组中那样）。

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
