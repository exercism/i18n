# 简介

[`Set`][set-docs]是一种无序集合，与`List`不同，它保证不包含任何重复的值。

`Set`接口的泛型类型参数表示`Set`中元素的类型：

```java
Set<Integer> ints = Set.of(1, 2, 3);
Set<String> strings = Set.of("alpha", "beta", "gamma");
Set<Object> mixed = Set.of(1, false, "foo");
```

注意，`Set.of()`方法创建的是一个[_不可修改_][unmodifiable-set-docs]的`Set`实例。
在这个实例上调用`add`、`remove`这样的方法，会在运行时导致异常。

要创建可修改的`Set`，需要实例化一个实现`Set`接口的类。
实现这个接口最常用的内置类是[`HashSet`][hashset-docs]类。

```java
Set<Integer> ints = new HashSet<>();
```

`Set`接口继承自[`Collection`][collection-docs]和[`Iterable`][iterable-docs]接口，因此与其他类型的集合共享很多方法。
但它与`Collection`接口有一个明显的不同：`add`、`remove`这样的方法返回`boolean`（而不是`void`），用来表示调用该方法时集合中是否包含该项：

```java
Set<Integer> set = new HashSet<>();
set.add(1);
// => true
set.add(2);
// => true
set.add(1);
// => false
set.size();
// => 2
set.contains(1);
// => true
set.contains(3);
// => false
set.remove(3);
// => false
set.remove(2);
// => true
set.size();
// => 1
```
