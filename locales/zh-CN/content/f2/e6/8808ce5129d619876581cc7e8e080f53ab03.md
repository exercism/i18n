# 说明

在本练习中，你将处理储蓄账户。每年，你的储蓄账户余额都会根据利率更新。银行给你的利率取决于你账户里的金额（也就是余额）：

- 余额为负数时，为 -3.213%。
- 余额为正且小于`1000`美元时，为 0.5%。
- 余额为正，且大于等于`1000`美元、小于`5000`美元时，为 1.621%。
- 余额为正且大于等于`5000`美元时，为 2.475%。

每年，政府允许你免税地把一定比例的钱捐给慈善机构。因为你是个好人，如果年底时你的余额为正，你会向慈善机构捐出这个金额的两倍，并向下取整到最接近的整数美元。

本练习有三个任务，每个任务都涉及你的余额和利率。

## 1. 计算利率

实现`interest-rate`函数，根据给定的余额计算利率：

```clojure
(interest-rate 200.75M)
;;=> 0.5
```

注意，返回的值是`Double`。

## 2. 计算年度余额更新

实现`annual-balance-update`函数，计算年度余额更新，其中要考虑利率：

```clojure
(annual-balance-update 200.75M)
;;=> 201.75375M
```

注意，返回的值是`BigDecimal`。

## 3. 计算捐款金额

实现`amount-to-donate`函数，根据余额以及政府允许的免税比例，计算要捐给慈善机构的金额：

```clojure
(def balance 550.5M)
(def tax-free-percentage 2.5)

(amount-to-donate balance tax-free-percentage)
;;=> 27
```

注意，返回的值是`int`。
