# 说明

你是一位狂热的观鸟爱好者，会记录有多少只鸟来过你的花园。
通常你会用笔记本上的计数表来数鸟，但为了更好地处理数据，你已经把过去几周的鸟类计数数字化了。

## 1. 确定到目前为止你数过的鸟的总数

我们先从整体上了解一下这些数据。
弄清楚自从开始记录以来，你一共数了多少只鸟。

实现一个函数`totalBirdCount`，它接受一个`Int`数组，其中包含每天的鸟的数量。
它应该返回你数过的鸟的总数。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. 计算某一周来访的鸟的数量

既然你对鸟的数量已经有了大致的了解，接下来你想做更细致的分析。

实现一个函数`birdsInWeek`，它接受一个每天的鸟的数量数组以及一个周数。

它返回你在那一周数到的鸟的总数。
你可以假定每一周都被完整记录。

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. 修正计数错误

你意识到，在你一直努力记录鸟的这段时间里，有一只鸟一直躲在花园远处的一个角落里。

你发现这只鸟每隔一天就会在你的花园里待上一天。

你不知道它在间隔的那些天里究竟在哪里，但肯定不在你的花园里。

你的观鸟直觉还告诉你，这只鸟在你列表里记录的第一天就在你的花园里。

根据这些新信息，编写一个函数`fixBirdCountLog`，它接收一个每天数到的鸟的数量的数组作为实参，并返回修正计数错误后的数组。

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
