# 说明

在这个练习中，你将编写代码，来记录一个你想在 Exercism 上学习的编程语言数组。

你有六个任务，它们都涉及处理数组。

## 1. 创建一个新数组

为了记录你想学习的编程语言，你需要创建一个新数组。定义`new_list`函数，让它返回一个新的空数组。

```gleam
new_list()
// -> []
```

## 2. 定义一个已有的数组

目前，你有一张纸，上面列出了你想学习的编程语言：Gleam、Go 和 TypeScript。定义`existing_list`函数来返回这个数组。

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. 向数组添加一门新语言

当你在 Exercism 上探索并发现更多有趣的编程语言时，你会想把它们添加到数组中。实现`add_language`函数，把一门新语言添加到数组的开头。

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. 统计数组中的语言数量

逐个统计语言很不方便。实现`count_languages`函数，统计数组中语言的数量。

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. 反转数组

某个时刻，你会发现数组的顺序其实是反的！实现`reverse_list`函数来反转数组。

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. 检查数组是否令人兴奋

虽然你喜欢所有语言，但 Gleam 在你心中有特殊的位置。因此，如果满足以下条件，你就会对一个语言数组感到非常兴奋：

- 数组的第一项是 Gleam。
- 数组的第二项是 Gleam，并且数组中包含两门或三门语言。

实现`exciting_list`函数，检查一个语言数组是否令人兴奋：

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
