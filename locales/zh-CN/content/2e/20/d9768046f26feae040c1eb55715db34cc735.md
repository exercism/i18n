# 说明补充

## 异常信息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，应该始终附上**有意义的错误信息**，说明错误的来源是什么。这能让代码更易读，也能大大帮助调试。如果你已经明确知道错误来源属于某种类型，可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍应附上有意义的信息。

本练习要求你在`board()`函数收到格式错误的输入时，使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)“抛出”`ValueError`。只有既`raise`该`exception`，又为它附上信息，测试才会通过。

要抛出带信息的`ValueError`，把信息写成`exception`类型的实参：

```python
# when the board receives malformed input
raise ValueError("The board is invalid with current input.")
```
