# 介绍

## 说明

除了 `number` 和 `string` 这样的原始数据类型，JavaScript 中还有一种重要的数据类型叫做`object`。
对象是键值对的集合。
因此，它们可以当作其他语言中常说的映射或字典来使用。

在其他语言中，映射里的所有值通常必须具有相同的数据类型。
而在 JavaScript 中，只有键的类型受限：它必须是字符串。
同一个对象中的值可以有不同的类型。
它们可以是数字这样的原始类型，也可以是数组、其他对象，甚至函数。
这让对象变得非常灵活，它们也因此成为 JavaScript 中[面向对象编程][oop]（OOP）的关键实体。

下面，我们将重点关注作为集合或映射的对象。对象的其他用法会在其他概念中介绍，例如[类][concept-classes]。

## 创建对象

使用大括号创建对象。
也可以直接写入一些条目。
为此，先写键，然后是一个冒号和值。

```javascript
const emptyObject = {};

const obj = {
  favoriteNumber: 42,
  greeting: 'Hello World',
  useGreeting: true,
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
  fruits: ['melon', 'papaya'],
  addNumbers: function (a, b) {
    return a + b;
  },
};
```

在 JavaScript 中，最后一个条目后面的末尾逗号是可选的。

你可能会好奇，既然键本应是字符串，为什么没有用引号把它们括起来。
这是一种简写形式。
如果键符合 JavaScript 的[标识符][mdn-identifier]命名规则，就可以省略引号。
如果键的名字中含有特殊字符，就需要使用通常的字符串写法。

```javascript
const obj = {
  '1keyStartsWithNumber': '...',
  'key/with/slashes': '...',
  'key-with-dashes': '...',
  'key with spaces': '...',
  '#&()[]{}èä樹keyWithSpecialChars': '...',
};
```

## 读取值

有两种方式可以根据给定的键读取值：点表示法和方括号表示法。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting;
// => hello world

obj['greeting'];
// => hello world

// Bracket notation also works with variables.
const key = 'greeting';
obj[key];
// => hello world
```

把点表示法当作简写来用，和省略引号有同样的限制。
只有当键符合标识符命名规则时才有效。
换句话说，如果你的键不是只由字母组成的单个词，就必须使用方括号表示法。

## 添加或修改值

可以使用赋值运算符`=`来添加或修改值。
同样，点表示法和方括号表示法都可以用。

```javascript
const obj = { greeting: 'hello world' };

obj.greeting = 'Hi there!';
obj['greeting'] = 'Welcome.';

obj.newKey1 = 'new value 1';
obj['new key 2'] = 'new value 2';

const key = 'new key 3';
obj[key] = 'new value 3';
```

## 删除条目

可以使用`delete`关键字从对象中删除一个键值对。

```javascript
const obj = {
  key1: 'value1',
  key2: 'value2',
};

delete obj.key1;
delete obj['key2'];
```

## 检查键是否存在

可以用`hasOwnProperty`方法检查对象中是否存在某个键。

```javascript
const obj = { greeting: 'hello world' };

obj.hasOwnProperty('greeting');
// => true

obj.hasOwnProperty('age');
// => false
```

## 遍历对象

有一种特殊的`for...in`循环，可以迭代对象的所有键。

```javascript
const obj = {
  name: 'Ali',
  age: 65,
};

for (let key in obj) {
  console.log(key, obj[key]);
}
// name Ali
// age 65
```

为避免难以察觉的错误，你应该始终假设`for...in`循环以任意顺序访问键。
另外要注意，`for...in`在迭代时也会包含[继承的键][concept-inheritance]。
