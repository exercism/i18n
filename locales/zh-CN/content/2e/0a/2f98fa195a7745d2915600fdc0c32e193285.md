# 关于

在 Rust 中，迭代器是任何实现了 [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) trait 的值。
调用迭代器上的 `next` 方法，可以手动推进迭代器中的值。

```rust
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;
    // many built-in methods implemented
}
```

Rust 的许多 [`collections`](https://doc.rust-lang.org/std/collections/index.html) 都实现了
[`IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html)，
它能从集合的值中产出一个 `Iterator`。

```rust
trait IntoIterator where Self::IntoIter: Iterator<Item=Self::Item> {
    type Item;
    type IntoIter: Iterator;
    fn into_iter(self) -> Self::IntoIter;
}
```

注意，虽然 `IntoIterator::into_iter` 会消耗它的 `self` 类型，但这个类型不一定得是拥有所有权的值。
因此，[`Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-2)、
[`&'a Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator) 和
[`&'a mut Vec`](https://doc.rust-lang.org/std/vec/struct.Vec.html#impl-IntoIterator-1) 都有对应的 `IntoIterator` 实现。
这些针对不同所有权程度的实现提供了很有用的灵活性。

理解 `traits` 并不是学习本概念所必需的，我们会用一整个练习帮你掌握 `traits`。
现在，你只要记住：

- 任何实现了 `IntoIterator` 的类型都称为_可迭代的_，因为它可以被转换成一个迭代器。
- 任何实现了 `Iterator` 的类型都是迭代器；迭代器会_产出_值，并且可以被_迭代_。
- 对于任何实现了 `IntoIterator` 的类型，你都可以通过调用它的 `into_iter` 方法得到一个迭代器。
- 每个迭代器都[实现了 `IntoIterator`](https://doc.rust-lang.org/std/iter/trait.IntoIterator.html#impl-IntoIterator-25)，并产出它自己。
- `for`循环总是作用于迭代器，并对其范围参数隐式调用 `IntoIterator`。

## `into_iter`与`for`循环

你可能已经熟悉用 `for`循环遍历向量：

```rust
// lor is a `Vec`, which implements `IntoIterator`
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
for people in &lor {
    println!("{people}");
}
```

从根本上说，`for`循环只是这样一个简写：先调用其参数的 `into_iter` 方法，然后不断调用 `next()`，直到它不再产出元素。换句话说，前面的循环会被脱糖成：

```rust
{
    let mut iterator = (&lor).into_iter();
    while let Some(people) = iterator.next() {
        println!("{people}");
    }
}
```

## `iter`和`iter_mut`方法

大多数 Rust 集合类型都提供 `iter` 和 `iter_mut` 方法。
对于类型为 `T` 的集合，按照约定，这两个方法的行为如下：

- `iter`返回的迭代器会产出不可变借用的 `&T`。
- `iter_mut`返回的迭代器会产出可变借用的 `&mut T`。

```rust
let mut v = vec![1, 2, 3];

// Using `iter` method
let mut iterator = v.iter();
assert_eq!(iterator.next(), Some(&1));
assert_eq!(iterator.next(), Some(&2));
assert_eq!(iterator.next(), Some(&3));
assert_eq!(iterator.next(), None);

// Using `iter_mut` method
for value in v.iter_mut() {
     *value *= *value;
}
println!("{v:?}");
// => [1, 4, 9]
```

## `iter`、`iter_mut`和`into_iter`的区别

如果`iter`、`iter_mut`和`into_iter`都会产生迭代器，那它们之间有什么区别？

- `iter`返回的迭代器按约定会产出不可变借用的 `&T`。
- `iter_mut`返回的迭代器按约定会产出可变借用的 `&mut T`。
- `into_iter`返回的迭代器可能产出 `T`、`&T`或`&mut T`，取决于它的上下文。

`into_iter`调用的上下文是什么？
是它的 `self`类型。
回想一下，`Vec`、`&'a Vec`和`&'a mut Vec`都有 `IntoIterator` 实现。
因此：

- `(&v).into_iter()`等于`v.iter()` => 返回`&T`
- `(&mut v).into_iter()`等于`v.iter_mut()` => 返回`&mut T`
- `v.into_iter()` => 返回`T`，并移动这些值

这一点在 `for`循环中体现得最清楚：

- `for num in &v {...}` => 绑定`&T`
- `for num in &mut v {...}` => 绑定`&mut T`
- `for num in v {...}` => 绑定`T`，并移动这些值

写`v.iter()`通常比写`(&v).into_iter()`更清楚。
因此，从人体工学的角度来说，也更有理由优先使用 `iter` 和 `iter_mut`，而不是 `into_iter`。

## 使用迭代器的内置方法

迭代器提供了许多内置方法，例如 `map`、`filter`、`collect`。
这些方法有时会和闭包一起使用。

`map`使用闭包来转换迭代器中的值。
`take`把一个（可能是无限的）迭代器截断成一个最多在指定数量的元素之后就终止的迭代器。

```rust
for even_number in (0..).into_iter().map(|x| x * 2).take(4) {
    let odd_number = even_number + 1;
    println!("{even_number} => {odd_number}");
}
// 0 => 1
// 2 => 3
// 4 => 5
// 6 => 7
```

`filter`把迭代器转换成只返回那些使闭包求值为 `true` 的值的迭代器。
`count`会消耗迭代器，返回它产出的元素个数。

```rust
let lor = vec!["Ainur", "Elves", "Men", "Dwarves", "Hobbits", "Orcs", "Dragons"];
let short_people = ["Dwarves", "Hobbits"];
let num_tall_people = lor.iter().filter(|people| !short_people.contains(people)).count();
assert_eq!(num_tall_people, 5);
```

`flat_map`通过提供的闭包把每个元素转换成一个新的迭代器，从而转换一个迭代器，然后再把所有产生的新迭代器串联起来、展平它们。
只要集合类型实现了 [`FromIterator`](https://doc.rust-lang.org/std/iter/trait.FromIterator.html)，`collect`就会产生一个新的集合。

```rust
let words = ["alpha", "beta", "gamma"];
// chars() returns an iterator
let merged: String = words.iter()
                          .flat_map(|s| s.chars())
                          .collect();
assert_eq!(merged, "alphabetagamma");
```

[`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html) 提供了_许多_这样有用的迭代器转换方法，值得读一读文档，熟悉它们。

## 惰性

有一点很重要：Rust 的迭代器是惰性的，在我们消耗迭代器之前，它们不会产出任何值。
如果你编写并运行下面的代码：

```rust
(0..5).map(|x| x * x);
```

你会得到下面这个编译器错误：

```rust
 --> src/main.rs:2:5
  |
2 |     (0..5).map(|x| x * x);
  |     ^^^^^^^^^^^^^^^^^^^^^^
  |
  = note: `#[warn(unused_must_use)]` on by default
  = note: iterators are lazy and do nothing unless consumed
```

这是因为 `map` 是一个适配器方法，它会返回另一个迭代器。

要消耗一个迭代器，要么使用 `for`循环，要么使用某个会产生本身不是迭代器的值的迭代器方法。

例如，`collect`是一个消费者方法（它的函数签名返回的不是迭代器，而是一个泛型类型）：

```rust
//         Iterator   Adaptor        Consumer
//                |      |               |
let v: Vec<_> = (0..5).map(|x| x * x).collect();
```
