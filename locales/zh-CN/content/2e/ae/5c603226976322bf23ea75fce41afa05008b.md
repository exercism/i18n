# 补充说明

## 提示

你需要实现`decode`和`encode`两个函数，这两个函数使用 Atbash 密码对`String`进行解码和编码。
如果你不确定类型，可以使用给出的签名，但不要让它限制你的创造力。

本练习处理的是文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是一个字符列表。若要更高效地处理文本数据，可以使用`Text`类型。

作为本练习的可选延伸，你可以

- 阅读 Haskell 中关于[字符串类型](https://haskell-lang.org/tutorial/string-types)的内容。
- 在 package.yaml 的依赖列表中添加`- text`。
- 按照[下面的方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 使用`Text`类型，例如`decode :: Text -> Text`；并像`T.pack`那样引用`Data.Text`的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档。
- 把 Atbash.hs 中出现的所有`String`都替换成`Text`，即：

```haskell
decode :: Text -> Text
decode cipherText = ...

encode :: Text -> Text
encode plainText = ...
```

这部分完全是可选的。
