# 简介

在 F# 中，把一个值赋给一个名字称为_绑定_。绑定是不可变的，因此它们类似于其他语言中的常量。由于 F# 是静态类型语言，每个绑定在编译期都有类型。

绑定使用`let`关键字定义。对大多数绑定来说，指定类型是可选的，因为 F# 的_类型推断_通常能根据值推断出类型。一个绑定看起来像这样：

```fsharp
// Automatically inferred type
let fingers = 10
```

函数也是普通的绑定，只不过带有一个或多个形参。函数会自动返回它的最后一个表达式。类型推断对大多数函数也适用：它会分析函数被调用时传入了哪些值，以及函数返回什么值。

```fsharp
// Automatically inferred types for parameters and return type
let add x y = x + y
```

调用函数时，需要写上函数名，并为函数的每个形参传入实参。

```fsharp
let five = add 2 3
```

如果无法推断出绑定的类型，编译器会报错。要解决这个问题，给绑定加上显式的类型标注。

```fsharp
// Explicit type annotation
let fingers: int = 10

// Explicit type annotation (also for parameters)
let add (x: int) (y: int): int = x + y
```

F# 中的绑定只能在定义_之后_使用。在定义之前就使用绑定，会导致编译错误。

```fsharp
// Compile error as the add binding has not yet been defined
// let seven = add 3 4

let add x y = x + y
```

F# 使用有意义的空白来定义作用域。也就是说，作用域是通过用空格缩进代码来定义的，缩进相对于声明绑定的那一行。默认约定是使用 4 个空格缩进：

```fsharp
let toes =
    let left = 5
    let right = 5
    left + right

let multiplyPlusTwo x y =
    let product = x * y
    product + 2

// Trying to access the left, right or product bindings
// here would result in a compile error
```

F# 的绑定（包括函数）通常组织在模块中。模块把相关的功能归到一起，使用`module`关键字定义。模块定义必须位于它的绑定之前：

```fsharp
module Calculator

let pi = 3.14

let add x y = x + y
```

F# 支持两种注释。单行注释以`//`开头，多行注释则插在`(*`和`*)`之间。
