# 简介

`readonly`修饰符能防止字段中的值或引用被覆盖，但它无法保护引用类型的成员。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

若要确保引用类型的所有成员都受到保护，可以把字段声明为`readonly`，并在定义自动属性时省略`set`访问器。

基类库（BCL）提供了一些集合的只读版本，用来满足阻止集合成员被更新的需求。它们以包装器的形式出现：

- `ReadOnlyDictionary<T>`以只读方式公开`Dictionary<T>`。
- `ReadOnlyCollection<T>`以只读方式公开`List<T>`。
