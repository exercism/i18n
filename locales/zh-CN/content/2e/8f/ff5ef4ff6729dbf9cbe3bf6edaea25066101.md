# 关于

[Emacs Lisp](https://www.gnu.org/software/emacs/manual/) 是 Emacs 的核心语言。Emacs 是一款标志性的文本编辑器，也是自由软件运动的起点。
Emacs 由 100 多万行 Emacs Lisp 代码构成，所有在 Emacs 里运行的应用都是用 Emacs Lisp 写的，包括各种编程语言的 IDE（集成开发环境）、游戏、日程规划工具等。
用户的偏好设置同样是由一条条 Emacs Lisp 表达式组成的列表。

了解 Emacs Lisp 是走进 Lisp 的第一步。Lisp 是仍在使用的编程语言中第二古老的（2018 年刚满 60 岁），至今也依然影响着众多其他编程语言。

[引用 Emacs 的创造者](https://www.gnu.org/gnu/rms-lisp.html)：
“Multics Emacs 取得了巨大的成功：编写新的编辑命令非常方便，以至于连他办公室里的秘书都开始学着用它。她们用了一本别人写的手册，那本手册演示了如何扩展 Emacs，却没说明这就是在编程。于是，那些自认为不会编程的秘书没有被吓退。她们读了手册，发现自己能做出有用的东西，然后就学会了编程。”
