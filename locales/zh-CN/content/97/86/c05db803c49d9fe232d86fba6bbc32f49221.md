# 学习 PowerShell

开始学习 PowerShell 的一个好方法是，去 PowerShell 网站上的[学习资源区][learning section]挑一份学习资料。
那里有大量信息，还有通往各种 PowerShell 主题的链接。

PowerShell 还自带一套非常完善的自文档帮助系统。
使用 `Get-Help` cmdlet，就能探索 PowerShell 提供的许多功能。
在 PowerShell 里，试试：

```PowerShell
Get-Help about
```

你会看到大约 3 页可供探索的主题。
另外两个非常有用的函数是：

- Get-Command
- Get-Member

想知道它们是做什么的？当然可以试试 `Get-Help Get-Command` 和 `Get-Help Get-Member`。

## PowerShell 的动词与名词

PowerShell 给 cmdlet 命名时，遵循相当严格的“动词-名词”格式。
一开始，这可能会让经验丰富的程序员感到很不适应。
虽然你可以随意命名自己的函数，但熟悉并采用标准动词，会提升你编写 PowerShell 代码的水平。

想查看所有已批准动词的列表，只需运行：

```PowerShell
Get-Verb
```
