# 说明

在这个练习中，你要组织各种遥控车之间的比赛。每辆车的速度和耗电特性都各不相同。

赛车出发时电池都是满的（100%）。每用遥控器驾驶一次，赛车就会前进与车速相等的距离（单位为米），同时剩余电量百分比会减去它的耗电量。

如果赛车的电量低于它的耗电量，就不能再驾驶它了。

每条赛道都有自己的长度。测试的方法是看赛车能否在电量耗尽前跑完整条赛道。

## 1. 创建一辆遥控车

定义一个`car`数组，包含以下元素：

- speed
- battery_drain
- battery
- distance_traveled

定义`new_car`函数即可创建一辆遥控车：它接收车速（单位为米）和耗电百分比这两个形参，并返回一个`car`数组。

对于新车，电量为 100%，已行驶距离为零。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. 创建一条赛道

再定义一个名为`track`的数组，它只包含`track_length`这一个元素。
定义`new_track`函数即可创建一条赛道，它接收赛道的长度（单位为米）：

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. 检查电量是否耗尽

实现`battery_drained()`函数，用来判断电量是否耗尽。如果剩余电量不足以再行驶一次，就认为电量已耗尽。

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. 驾驶赛车

实现`drive`函数：根据车速更新已行驶的米数，并按耗电量减少电量。如果电量不足以再行驶一次，赛车就不会移动。

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. 检查遥控车能否跑完一场比赛

要跑完一场比赛，赛车必须能够行驶赛道的长度。也就是说，它不能在冲过终点线之前耗尽电量。

实现`can_finish`函数：它接收一个`car`和一个`track`作为形参，如果赛车能跑完比赛就返回`TRUE`，否则返回`FALSE`。

假设你现在位于比赛的起跑线上，正在为比赛启动赛车引擎。请注意，比赛开始时赛车不一定处于满电状态。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. 记录赛车满电时能否跑完某条赛道

你已经创建了若干条长度不同的赛道，现在需要记录赛车在满电时能否跑完它们。

实现`store_track`函数：它接收一辆车、一条赛道和一个赛道名称，返回一辆多带一个元素的更新后的车。这个元素的名称是赛道的`name`，对应的值是一个子数组，其中包含`track_length`以及赛车能否`complete`它。

实参传入的车可能不是满电的，所以在使用它之前，一定要重置电量和已行驶距离。

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
