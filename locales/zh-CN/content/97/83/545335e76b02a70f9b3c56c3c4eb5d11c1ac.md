# 说明

在本练习中，你将编写一些代码，为购买车辆做准备。

你有三个任务：判断自己是否需要驾驶证，在两种车辆之间做出选择，以及估算一辆二手车的合理价格。

## 1. 判断你是否需要驾驶证

有些类型的车辆需要驾驶证才能驾驶。
假设只有 `"car"` 和 `"truck"` 这两种类型需要驾驶证，其他类型无需驾驶证即可驾驶。

实现 `needs_license(kind)` 函数，它接收车辆类型（字符串），返回一个布尔值，表示这种类型的车辆是否需要驾驶证。

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. 在两种备选车辆之间做选择

你评估了可选的车辆。
你成功把范围缩小到两种选择，但需要有人帮你做最终决定。
为此，实现 `choose_vehicle(option1, option2)` 函数，它接收两种车辆作为实参，返回的决定中包含字典序更靠前的那种。

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

返回的字符串应当符合“<CHOSEN_VEHICLE> is clearly the better choice.”这一模式，其中 `<CHOSEN_VEHICLE>` 是传入实参中所选中的那种车辆。

## 3. 估算二手车的价格

既然你已经做出决定，你希望确保在经销商那里拿到公道的价格。
既然你打算买二手车，价格就取决于车龄。
粗略估算的话，假设车龄不到 3 年，价格为全新时原价的 80%。
如果车龄达到 10 年，价格为原价的 50%。
如果车龄在 3 年及以上但不到 10 年，价格为原价的 70%。

实现 `calculate_resell_price(original_price, age)` 函数，用 `if`、`else if` 和 `else` 来实现这套逻辑（如果你想练练手，也有其他写法）。
它接收原价和车龄作为实参，返回经销商处的估价。

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> 注意：返回值的类型是 `double`。
