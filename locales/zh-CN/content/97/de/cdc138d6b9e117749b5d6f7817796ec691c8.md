# 简介

除了字符类和量词，正则表达式还能描述*结构*和*上下文*。这些特性都属于同一个[`regexp`][regexp]词汇表，也使用同一个`R/ /`字面量。

圆括号`( )`可以把模式的一部分分组，这样量词或`|`（“这个或那个”）就会作用于整个分组；分组后面的`?`会让它变成可选的：

```factor
USING: regexp ;

"abab"    R/ (ab)+/ matches? .             ! => t
"$100"    R/ \$\d+(\.\d{2})?/ matches? .   ! => t   (optional group)
```

锚点把模式固定到某个位置：`^`（开头）、`$`（结尾）和`\b`（单词边界）。

*环视*根据某个位置周围的内容来匹配，但并不消耗它：

```
(?=...)    ! lookahead — ... must follow
(?!...)    ! negative lookahead — ... must not follow
(?<=...)   ! lookbehind — ... must come before
```

```factor
USING: regexp ;

"spent $100 and $25" R/ (?<=\$)\d+/ all-matching-subseqs .
! => { "100" "25" }

"up 5% then 12%" R/ \d+(?=%)/ all-matching-subseqs .
! => { "5" "12" }
```

在结尾的`/`后面加一个选项字母，会改变整个模式；`i`会让模式不区分大小写：

```factor
USING: regexp ;

"REFUND" R/ refund/i matches? .   ! => t
```

Factor 用环视代替捕获组：它没有捕获组提取、反向引用或惰性量词。
