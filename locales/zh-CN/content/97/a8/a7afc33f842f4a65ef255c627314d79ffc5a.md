# 补充说明

## 关于 Arturo 的特定信息

在这个练习中，你需要使用带有自定义单位的[物理量][physical-quantities]来返回年龄，该单位表示那颗行星上一年的长度。
在 Arturo 中，一个量由数值和关联的[计量单位][unit-of-measurement]组成。

```arturo
length: 10`m
units length ; `m
scalar length ; 10

10`m * 10`m ; 100 m²
```

~~~~exercism/caution
Arturo 内置的`yr unit 会转换为 31556952 秒。
因此，你需要根据前面说明中提到的秒数，定义并使用你自己的“年”单位。
~~~~

量可以被[转换][convert]为另一个兼容的单位。
```arturo
convert 1`m `ft ; 1250/381 ft
convert 100`m2 `ft2 ; 156250000/145161 ft²

property `m  ; length
property `m2 ; area

convert 1`m `m2 ; conversion error results
```

~~~~exercism/note
由于浮点数的精度限制，Arturo 有时会把标量存储为有理数。
可以使用 [`to` 函数][to] 改为获取近似的浮点数形式的数值。

```arturo
length: convert 1`m `ft ; 1250/381 ft
to :floating length ; 3.280839895013123
```

[to]: https://arturo-lang.io/documentation/library/types/to/
~~~~

Arturo 还允许我们为量[指定][specify]自己的单位。

```arturo
specify 'nauMile 1.151`mi
property `nauMile length
specify 'lea 3.00579`nauMile
property `lea ; length
depth: 20000`lea
convert depth `km ; 111355.7993425152 km
```
