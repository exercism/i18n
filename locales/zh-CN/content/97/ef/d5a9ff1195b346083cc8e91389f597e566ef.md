## 交互式 jq 工具

输入一些内容，试用各种 jq 过滤器，看看能得到什么结果。

- [jq playground][jqplay]，一种“在线试用”体验。
- [ijq][ijq]，交互式 jq 工具，相当于命令行版的 jqplay。
- [jqp][jqp] 是另一个命令行工具，它使用 gojq 作为后端，与原始 jq 并非 100% 兼容。

## 其他 JSON 处理工具

- [gron][gron]：将 JSON“扁平化”为一连串单独的赋值，这样就可以用面向行的工具（grep 等）来处理它。
- [jo][jo]：一个小工具，可以从 shell 变量创建 JSON 对象。
- [jello][jello]：jello 与 jq 类似，区别在于 jello 使用标准的 python dict 和 list 语法。
