# 简介

## 浮点数

浮点数是指小数点后有零位或多位数字的数字。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

不同的浮点数类型能存储的小数点后位数不同，这称为它的精度。

C# 有三种浮点数类型：

- `float`：4 字节（约 6-9 位精度）。写作`2.45f`。
- `double`：8 字节（约 15-17 位精度）。这是最常见的类型。写作`2.45`或`2.45d`。
- `decimal`：16 字节（28-29 位精度）。通常用于处理货币数据，因为它的精度能降低出现舍入误差的可能性。写作`2.45m`。

可以看出，每种类型能存储的位数各不相同。例如，尝试把 PI 存入`float`时，只会存储前 6 位小数（最后存储的一位会四舍五入）。

## `while` 循环

在本练习中，你可能需要使用循环。在 C# 中写循环有好几种方式，但这里`while`循环最合适：

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## `do`/`while` 循环

如果循环中的代码需要至少执行一次，可以使用`do`/`while`循环：

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
