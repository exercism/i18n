# 说明

一家忙碌的银行按*优先级*为等候的顾客办理业务，而不是按他们到达的顺序。每位顾客取号时都会得到一个优先级数字，柜员接下来总是服务数字最小的那位（`1`最紧急）。最小堆正是最理想的等待队列。

## 1. 打开队列

定义 `new-queue`，它不接受任何输入，返回一个新的空优先队列。

```factor
new-queue
! => an empty priority queue
```

## 2. 添加顾客

定义 `join-queue`，它接受顾客姓名、优先级数字和队列。它把顾客加入队列并返回该队列，这样就可以一个接一个地加入顾客。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. 下一位是谁？

定义 `next-name`，它接受一个队列，返回下一位应该被服务的顾客姓名，也就是优先级数字最小的那位，并且*不会*将其移除。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. 服务所有顾客

定义 `serve-all`，它接受一个队列，返回所有等候顾客的姓名，按他们应被服务的顺序排列。

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
