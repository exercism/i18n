# 提示

## 通用

- 名字组成的数组，类型是`ARRAY{STR}`；数字组成的数组，类型是`ARRAY{INT}`。实参需要说明是哪一种，任务 4 里的答案也一样。

## 1. 这一行有多少人？

- 用`.size`，后面不加括号。

## 2. 谁站在最前面？

- 第一个位置是`0`。

## 3. 谁站在最后面？

- 最后一个位置比大小少 1，因为计数从 0 开始。
- 要根据`.size`算出来，而不是直接写`2`。测试用的行有好几种不同的长度。

## 4. 开场队形

- 答案是字符串数组，所以函数的声明要写成`: ARRAY{STR}`。
- 返回一个数组字面量：把三个名字写在两个`|`之间。

## 5. 数步子

- 用一个累计值和一个循环，和上一个练习一样。
- 用位置变量从`0`开始往上数，循环以`until!(i >= steps.size)`结束。
- 把累计值从 0 开始，这样空行不用任何特殊处理就能得到 0。
