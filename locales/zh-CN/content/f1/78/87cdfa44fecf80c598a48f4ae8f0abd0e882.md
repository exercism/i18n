# Unison 基础

## 项和函数

项和函数是编写 Unison 程序的基本单位。

“项”就是我们所说的静态值。它通过`name = expression`定义，前面可以带一个类型签名，形式为`name : MyType`。Unison 支持类型推断，所以在简单的定义中，类型签名可能会被省略。

```
myTerm = 42

helloThere : Text
helloThere = "Hello, World!"
```

Unison 函数的写法是`myFunctionName argument1 argument2 = myImplementation`：先是函数的名字，后面跟着用空格分隔的实参。

```
getMax a b = Nat.max a b
```

函数可以带一个可选的类型签名。最右边最后一个类型始终是函数的最终返回类型，各个类型之间用函数箭头`->`分隔。

```
getMax : Nat -> Nat -> Nat
getMax a b = Nat.max a b
```

要调用一个函数，就写出它的名字，后面跟上实参，实参之间只用空格分隔。

```
maximum = getMax 1 10
```

调用函数时，Unison 会尝试把紧跟在右边的内容当作实参，而这并不总能带来你想要的函数求值顺序。

假设我们想从下面这个表达式中得到值`1`

```
shouldBe1 = getMax 1 10 - 10
```

按照现在的写法，`shouldBe1`的求值结果是`0`，因为隐含的函数应用顺序是`getMax 1 10`，得到`10`，然后`10 - 10`得到`0`。

你可以用括号重新组合表达式，得到你想要的运算顺序。

```
shouldBe1 = getMax 1 (10 - 10)
```

## 多行函数

Unison 的多行函数用缩进或`let`块来界定代码边界，也就是“词法作用域”。

```
swapOrder : Text -> Text -> Text -> Text
swapOrder beg middle end =
  newBeginning = end ++ middle
  newBeginning ++ beg
```

处于同一缩进层级的内容共享同一个作用域，所以我们才能在最后一行引用变量`newBeginning`。

## 命名空间和`use`语句

命名空间是我们分组、组织 Unison 函数的方式。你可以把它们类比为“目录”。它们提供了结构和逻辑分组。

你可以用`use`语句把命名空间里的函数引入作用域。

假设你在写一个函数，要用到 Unison 的`List`值。你知道自己需要`List.map`和`List.flatMap`这样的函数，其中`List`是命名空间，`map`和`flatMap`是函数。为了避免重复，你可以像下面这样，把`List`命名空间里的所有内容引入函数的词法作用域：

```
listProcessing: [Nat] -> [Text]
listProcessing nats =
  use List
  map Nat.toText nats |>
  flatMap (fill 2)
```

`use List`这一行消除了对`map`和`flatMap`的引用的歧义。你可以阅读[关于 `use` 语句的更多内容][use-statements]。

## 注释和文档字面量

Unison 里的注释算是个有点特别的功能。在写 Unison 代码时，你可以在以`.u`结尾的文件里写下不会被解释执行的文本，语法如下：

```
-- a single line comment
-- another single line comment

{-
  a multiline comment
  spanning multiple lines
-}
```

不过，因为 Unison 代码是以其抽象语法树的哈希形式保存的，而不是以文件系统里基于文本的文件保存的，所以文件中某个 Unison 函数或项的基于文本的注释“装饰”其实无法保存下来，也无法重新渲染用于分享。如果你想以某种能被保存下来、供他人阅读和理解的方式，为你的 Unison 项添加信息，可以使用文档字面量。

文档在 Unison 编程语言里是一等值。这意味着`Doc`元素可以赋值，可以作为值传给函数，也可以作为函数的值返回。文档字面量元素用双层花括号开启和关闭。下面是我们把`Doc`元素当作注释使用的一个例子。

```
myFunction: Nat -> Boolean
myFunction n =

  {{ when n is `4` we have a special important business logic exception}}

  if n === 4 then true
  else
    if isEven n then false
    else true
```
