# 简介

## 比较

### 比较数字

在`jq`中，可以使用以下关系运算符和相等运算符来比较数字。

| 比较             | 运算符 |
| ---------------------- | -------- |
| 大于           | `a > b`  |
| 大于等于 | `a >= b` |
| 小于              | `a < b`  |
| 小于等于 | `a <= b` |
| 等于               | `a == b` |
| 不等于           | `a != b` |

比较的结果始终是布尔值，要么是`true`，要么是`false`。

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### 比较字符串

上面的比较运算符也可以用来比较字符串。此时会按字典（字典序）顺序比较，也就是_按 Unicode 码点值_排序。

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

比较两个看起来像数字、但类型是字符串的变量时要格外小心。由于采用字典顺序，得到的结果与比较数字类型的值并不相同。

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### “严格”相等

`jq`的`==`运算符类似于 Javascript 的`===`：那些看起来相同、但类型不同的值并不相等。

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### 比较数组

如果两个数组中所有对应的元素都相等，这两个数组就相等。

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### 比较对象

如果两个对象拥有相同的键值对，它们就相等。

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## 条件语句

### if 表达式

`jq`的**条件表达式**是`if A then B else C end`。

`if-then-else`和所有`jq`内置函数一样，是一个过滤器：它接受一个输入，产生一个输出。

如果表达式`A`产生一个“真值”，`if`过滤器就会对`B`求值；否则对`C`求值。传给`if`过滤器的输入会传递给`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**可选的**；下面两条语句是等价的。

```jq
if A then B else . end
if A then B end
```
~~~~

### 嵌套的 if 语句

可以用`elif`添加更多条件。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

需要多少个`elif`子句就用多少个。

### 真值性

`jq`中只有两个“假”值：`false`和`null`。其他一切都是“真”，连数字 0、空字符串、空数组和空对象也不例外。

### 布尔运算符

可以用**布尔运算符**`and`和`or`构建复杂的查询。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

要取反，用`not`。这是一个**过滤器**，不是运算符。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### 替代运算符

**替代运算符**可以让你在表达式为假或 null 时指定一个“默认”值。

```jq
A // B

# This is identical to
if A then A else B end
```

演示一下：

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
