# 简介

与许多其他语言不同，JavaScript 中有两种不同的实体用来表示（有意义的）值不存在：`null`和`undefined`。

## null

原始值`null`用作任意类型变量有意设置的“空值”。

```javascript
let name = null;
// name is intentionally set to "empty" because it is not
// available
```

你可以使用[严格相等运算符][mdn-strict-equality]`===`来检查一个变量是否为 null。

```javascript
let name = null;

name === null;
// => true
```

## undefined

> 没有被赋值的变量，类型为`undefined`。[^1]

也就是说，`null`表示一个空值（但仍然是一个值），而`undefined`表示值完全不存在。🤯

`undefined`会出现在不同的场景中。

- 如果声明变量时没有赋值（初始化），它就是`undefined`。

  ```js
  let name;
  console.log(name); // => undefined
  ```

- 如果你访问对象中不存在的键对应的值，会得到`undefined`。

  ```js
  let obj = {
    name: 'John',
  };
  console.log(obj.age); // => undefined
  ```

- 如果函数没有返回值，结果就是`undefined`。

  ```js
  function printName(name) {
    'My name is ' + name;
  }
  console.log(printName('John')); // => undefined
  ```

- 如果没有给函数传入实参，该实参就是`undefined`，除非它有默认值。

  ```js
  function printName(name) {
    return name;
  }
  console.log(printName()); // => undefined
  ```

你可以使用严格相等运算符`===`来检查一个变量是否为 undefined。

```javascript
let name;

name === undefined;
// => true
```

## 可选链

如果你尝试获取对象中嵌套的值，但父级键不存在，JavaScript 会抛出错误。
为了轻松避免这种情况，语言规范在 2020 年加入了可选链。
使用可选链运算符`?.`，你可以确保 JavaScript 只在父级不是`null`或`undefined`时才尝试访问嵌套的键。
否则会返回`undefined`。

```javascript
const obj = {
  address: {
    street: 'Trincomalee Highway',
    city: 'Batticaloa',
  },
};

obj.address.zipCode;
// => undefined

obj.residence.street;
// => TypeError: Cannot read property 'street' of undefined

obj.residence?.street;
// => undefined
```

## 空值合并

有些情况下，你希望在变量为 null 或 undefined 时应用一个默认值（而且只在这种情况下）。
为此，2020 年引入了空值合并运算符`??`。
只有当左侧操作数是`null`或`undefined`时，它才返回右侧操作数。
否则返回左侧操作数。

```javascript
let amount = null;
amount = amount ?? 1;
// => 1

amount = 0;
amount = amount ?? 1;
// => 0
```
