# 说明

从前，有一座繁华的城市，名叫 Cyberspace。
Cyberspace 是一座数字大都市，每天都有数百万居民登录和退出。
为了记录所有这些用户，Cyberspace 有一个特殊的文件，叫作 /etc/passwd。

/etc/passwd 文件就像这座城市的电话簿。
它列出了系统上所有拥有账号的用户，以及每位用户的一些重要信息：

| n   | 字段 |
| --- | --- |
| 1   | 用户名 |
| 2   | 密码（"x" 表示出于安全考虑，真正的密码存放在别处） |
| 3   | UID，一个唯一的数字用户 ID |
| 4   | GID，一个唯一的数字组 ID（通常与 UID 相同） |
| 5   | 用户信息（通常是用户的全名，但也可以包含其他信息） |
| 6   | 主目录 |
| 7   | 登录 shell |

各字段之间用冒号分隔。
下面是一个典型的条目：

```none
glennj:x:1010:1010:Glenn Jackman:/home/glennj:/usr/local/bin/fish
```

这个文件由一个系统管理员团队管理，他们负责创建新账号、更新已有账号以及删除旧账号。
系统管理员是 Cyberspace 的守门人，确保只有经过授权的用户才能访问系统。

有一天，团队新招了一位叫 Alex 的系统管理员。
Alex 很高兴能接下这份工作，很快就摸清了 /etc/passwd 文件的门道。
他们学会了如何向系统添加新用户、如何更新用户信息，以及如何删除旧用户。

在处理 /etc/passwd 文件的过程中，Alex 注意到了一些奇怪的地方。
有些用户的主目录很奇怪，很不寻常。
有些用户的主目录被设成了 /dev/null，还有一些用户的主目录被设成了根本不存在、莫名其妙的路径。

Alex 意识到，这些用户并不是真人，而是黑客创建的虚假账号。
黑客找到了一种利用系统漏洞的方法，创建这些虚假账号来入侵 Cyberspace。

Alex 知道自己必须采取行动。
他们用 awk 分析 /etc/passwd 文件，并写了一个脚本来找出所有虚假账号。
然后他们和团队其他成员一起删除了这些账号，并修补了让黑客得以创建这些账号的漏洞。

多亏 Alex 用上了 awk，团队才得以找出并删除这些虚假账号，让 Cyberspace 对每个人都更安全。
系统管理员继续管理着 /etc/passwd 文件，让它保持最新、安全，并确保只有经过授权的用户才能访问系统。

现在，轮到你来做一名像 Alex 一样的系统管理员了。

## 1. 列出用户名

写一个 awk 程序，打印 passwd 文件中每一行里以冒号分隔的第一个字段。

## 2. 打印行号

写一条 awk 命令，打印输入文件中每条记录的行号。
只打印行号，不要打印其他任何信息。

## 3. 打印主目录无效的记录。

在 Cyberspace 中，“有效”的主目录以 `/home` 或 `/root` 开头。
打印输入文件中主目录**无效**的记录。

## 4. 打印使用 bash 的有效用户

打印主目录有效**并且**登录 shell 是 `bash` 的记录。
