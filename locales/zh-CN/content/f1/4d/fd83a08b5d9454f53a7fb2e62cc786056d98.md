# 提示

## 通用

- 用一行`SYMBOLS:`声明四个基本方向符号和四个相对方位符号：
  `SYMBOLS: north east south west ahead starboard behind port ;`
- 每个元组都用`TUPLE: <class> <slot1> <slot2> ;`声明。
- 一行`GENERIC:`声明该词；每个`M:`行会为一个类添加方法。如果希望在方法体中使用具名局部变量，请使用`M::`。

## 1. `>cartesian`用于基本方向

- 对四个方向符号用一个小的`case`就够了。
- `{ north [ 0 1 ] }`：函数体只是压入这两个值；测试期望栈上`x`在`y`下方。

## 2. `>cartesian`用于极坐标

- 将角度转换为弧度：`bearing pi * 180 /`。
- `sin`和`cos`在`math.functions`中。
- 先压入`magnitude * sin(rad)`，再压入`magnitude * cos(rad)`。

## 3. `>cartesian`用于相对方位

- 声明一个动态变量：`SYMBOL: heading`。
- 在方法中用`heading get`读取它。
- 用`case`把`ahead/starboard/behind/port`映射到`0/90/180/270`偏移量，然后加上 heading。接下来就和任务 2 一样是极坐标转换了，考虑抽出一个辅助词：`: deg>cartesian ( magnitude bearing -- x y ) ... ;`。

## 4. `flip`

- 对`cardinal`调用`change-direction`，对`polar`或`relative`调用`change-bearing`，会构建一个新元组，只修改一个槽位，其余保持不变：
  `[ <transformation-quotation> ] change-bearing`。
- 对于`polar`的旋转：`[ 180 + 360 mod ] change-bearing`。

## 5. `add-bearings`

- 对每个输入调用`>cartesian`，然后把 x 分量和 y 分量相加。使用局部变量可以让这段代码更易读：
  ```factor
  :: add-bearings ( a b -- x y )
      a >cartesian :> ay :> ax
      b >cartesian :> by :> bx
      ax bx +
      ay by + ;
  ```
