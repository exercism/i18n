### 简介

欢迎来到 Java 赛道的第一个练习！

本文档是一份循序渐进的指南，带你一步步完成这个练习。其中的步骤在 Windows、macOS 和 Linux 上同样适用。

即使你已经熟悉 Java 基础，跟着本指南走一遍也可能有帮助：它能帮你理解我们用来编译和测试代码的工具 Gradle 的输出，也会介绍本赛道所有练习共有的一些模式。

### 练习结构

当你获取一个新的 Java 练习时，你会得到：

- __一个或多个测试文件__（总是如此）。
它们位于`src/test/java`目录中，定义了一组测试；我们的解答必须通过这组测试，才能确认它确实能正常工作。
- __一个或多个起始文件__（初始状态下）。
如果提供了起始文件，它们位于`src/main/java`目录中，定义了解决当前问题所需的类的骨架。

### 第 1 步：修正解答

无论你是在本地工作，还是使用在线编辑器，都应该能看到下面这段代码：

```java
String getGreeting() {
    return "Goodbye, Mars!";
}
```

目标就是修改给出的代码，让它生成`"Hello, World!"`这段文本，而不是`"Goodbye, Mars!"`。

### 第 2 步：运行测试

完成修改并实现解答后，再次运行测试。你可以使用在线编辑器运行测试，也可以在自己的机器上本地运行：

- 要在在线编辑器中运行测试，请点击“Run Tests”按钮。
- 要在本地运行测试，请查看[在 Java 赛道测试][Testing locally on the java track]。如果测试失败，也没关系！看看错误信息在告诉你什么，修改代码后重新测试；测试通过后，就进入下一步。

### 第 3 步：提交你的第一次迭代

有了可以正常工作、我们也检查过的解答，就可以把它提交到 exercism.org 了。你可以用在线编辑器提交，也可以在本地通过 [Exercism CLI][Working Locally] 提交：

- 要在本地提交练习，如果还没有安装 CLI，请先[安装 Exercism CLI][Working Locally]，然后提交你解答的文件，例如：

  ```sh
  exercism submit <file location>
  ```

- 把`<file location>`替换成你的`Greeter.java`文件的相对路径。例如，如果你在`C:\exercism\java\hello-world`目录下工作，那么命令就是

  ```sh
  exercism submit .\src\main\java\Greeter.java
  ```

- 如果你想用在线编辑器提交解答，直接点击“Submit”按钮即可！

想更详细地了解如何在本地提交解答：

### 成为导师

Exercism 的核心，就是围绕编程实践的交流。埋头练习固然有趣，但只有与他人互动，无论是看别人的尝试还是看自己的解答，才能得到反馈。这些反馈能帮你看出自己哪些地方做得好、哪些地方还需要改进。

有些提交会和你的几乎一模一样，有些则完全不同。两种都看看，既长见识，也有意思。

导师会审阅他们选择指导的赛道中提交的解答，帮助学习者尽可能多地学到东西。

想了解更多关于指导的内容，请查看 [Exercism 文档][Mentoring]。
