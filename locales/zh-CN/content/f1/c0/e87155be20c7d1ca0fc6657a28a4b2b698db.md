# 关于

[Java](https://go.java/index.html) 是目前最流行的编程语言之一，这要归功于它的通用性和兼容性。它广泛用于软件开发、移动应用以及大型系统的构建。

Java 诞生于 1995 年，目前由 [Oracle](https://www.oracle.com/index.html) 维护。尽管它不像如今的一些新语言那样年轻，Java 依然非常受欢迎。它的设计目标是快速、安全、可靠、对初学者友好，并且具有高度的可移植性。之所以有这样的可移植性优势，是因为 Java 运行在跨平台兼容的 [Java 虚拟机（JVM）](https://en.wikipedia.org/wiki/Java_virtual_machine) 上。Android 应用也使用 Java 开发，因为 [Android 操作系统](<https://en.wikipedia.org/wiki/Android_(operating_system)>) 运行在 Java 语言环境之上。

Java 社区非常庞大！例如，GitHub 上有超过 150 万个 Java 项目。另外值得一提的是，Java 在 [StackOverflow](https://stackoverflow.com/questions/tagged/java) 上拥有规模第二大的社区！这一点很重要，因为编程语言的社区越大，你能获得的帮助就越多。

Java 还拥有一套强大且设计良好的内置 [API（应用程序接口）](https://docs.oracle.com/en/java/javase/11/docs/api/index.html)，可用于数据库连接、网络、I/O、XML 解析、实用工具等各种用途。

从笔记本电脑到数据中心，从游戏主机到科学超级计算机，从手机到互联网，[Java 无处不在](https://en.wikipedia.org/wiki/Write_once,_run_anywhere)！
