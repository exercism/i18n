# 提示

## 1. 说一句台词的两种方式

- `.upper` 和 `.lower` 作用于整个字符串，而不只是单个字符。
- `whisper` 会在转为小写的那句台词两端各拼接一个 `"..."`。

## 2. 排练一句台词

- 实参类型写成 `ROUT{STR}:STR`，也就是花括号里写各个实参的类型，冒号后面写返回值。
- 函数体只有一行：`return part.call(line);`
- `rehearse` 里不能出现 `shout` 或 `whisper`。正因为不知道具体是哪一个，才要接收一个绑定好的例程。

## 3. 整场戏

- 用一个循环和一个 `FSTR`，就像 `rehearsal-script` 那样。
- 对每一句台词调用 `part.call(...)`，并在除第一句之外的每一句前面加上 `" "`。

## 4. 返回一种表达方式

- 返回类型是 `ROUT{STR}:STR`，和任务 2 中的实参类型完全一样。
- 在类里写 `bind(shout(_))`，不需要写类名，就像从自己所属的类里调用任何例程一样。
- `return bind(...)` 无法通过解析。`bind` 必须先放在赋值语句的右边：

  ```sather
     part : ROUT{STR}:STR;
     if ... then part := bind(shout(_)); else ... end;
     return part;
  ```

- 有两种情况，所以用一个 `if`，或者用一个带 `else` 的 `case`。

## 5. 固定一个实参

- `repeat` 本身就是一个普通的例程：一个循环、一个 `FSTR`，以及 `1.upto!(times)`。
- `doubler` 在绑定它时把数字写死，把台词留成一个空位：`bind(repeat(2, _))`。和任务 4 一样，先把它赋给一个变量，再返回这个变量。
- 只有 `_` 会成为绑定后例程的实参，所以 `bind(repeat(2, _))` 的类型是 `ROUT{STR}:STR`，而不是 `ROUT{INT,STR}:STR`。
