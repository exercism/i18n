# 说明

在这个练习中，你将要实现一种方式来记录本地街机厅里最热门游戏的高分。

你需要实现 6 个函数，它们大多与操作一个保存高分的对象有关。

## 1. 创建一个新的高分榜

编写一个函数`create_score_board`，它创建一个用作高分榜的对象。
这个对象的键将是玩家姓名，值将是他们的分数。
为了便于测试，你需要在这个对象中直接包含一个条目。
这个初始条目应包含`"The Best Ever"`作为玩家姓名，`1000000`作为分数。

```jq
create_score_board
# returns an object with one initial entry
```

## 2. 向记分板添加玩家

要向高分榜添加玩家，请实现函数`add_player`。
它接收一个记分板作为输入，并需要两个形参：玩家姓名和玩家的分数。
该函数输出添加了新玩家后的记分板对象。

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

如果该玩家已经在记分板上，则原样输出记分板。

## 3. 从记分板移除玩家

如果玩家违反了街机厅的规则，他们会被手动从高分榜中移除。
实现`remove_player`，它接收一个记分板作为输入，以及一个形参：要移除的玩家姓名。
该函数应从记分板中移除指定玩家的条目，并输出新的记分板。
如果该玩家原本就不在记分板上，记分板不应发生任何变化，应原样返回。

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. 增加玩家的分数

如果玩家在街机厅又完成了一局游戏，一定数量的分数会加到记分板上之前的分数上。
实现`update_score`，它接收一个记分板作为输入，并需要两个形参：玩家姓名和要增加的分数。
该函数应返回更新完成后的记分板。

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

如果玩家还不在记分板上，该函数应将其添加到记分板上。

## 5. 应用周一奖励分

街机厅在每周一使用一个单独的记分板。
一天结束时，该记分板上的每位玩家都会获得 100 分额外分数。

实现函数`apply_monday_bonus`。
该函数为记分板上列出的每位玩家加上奖励分数。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. 计算总分

不同的街机厅会相互竞争，以决出谁的玩家最厉害。
总分最高的街机厅赢得这份荣誉。

编写一个函数`total_score`。
它接收一个记分板作为输入，并输出所有玩家分数的总和。

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
