# 简介

## 变量

回想一下，`jq`程序是一条_表达式管道_。
**变量赋值**遵循这条规则：_变量赋值_是一个像这样的表达式：

```jq
... | expr as $varname | ...
```

### 过滤器的输出就是输入

和_恒等表达式_`.`一样，_变量赋值_的输出与它的输入相同。
设置变量的值是一种副作用。

下面这个例子说明，赋值之后的`.`与最初的输入相同：

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

### 变量的作用域

变量的作用域是“词法”的，也就是说，变量在管道剩余的部分中都在作用域内。
在函数中定义的变量（我们稍后会讲到函数）是函数的“局部”变量。

### 变量名

变量必须以`$`开头。
变量名的其余部分是一个**标识符**：以字母或下划线开头，后面跟着字母、数字或下划线。

### 解构赋值

手册中是这么写的：

> 通过提供一个_与输入的结构相匹配_的模式，可以使用单个`as`表达式声明多个变量（这称为“解构”）。

示例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

让变量名与_对象的键_匹配，可以获得一种简写：

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

### 常量

如上面的例子所示，用变量来存储常量很方便。
与其让“魔法数字”出现在代码中，不如给常量起个名字。

### 往往并不需要变量

省略变量通常会让代码更易读。

以计算一组数字的平均值为例：

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

与下面这种写法相比：

```jq
[2, 4, 8, 7] | add / length
```

这体现了`jq`最强大的特性之一：过滤器的输入会提供给_每一个_子表达式：

- 输入数组`[2,4,8,7]`被传给`add`（它把`+`运算符应用到所有元素上，从而求出这些数字的和）
- _同时_，`[2,4,8,7]`也会被传给`length`
- 当这些子表达式完成后，它们的结果会被相除，返回输入数组中所有数字的平均值。

### 学习练习会用到的`jq`运算符

#### 替代运算符：`//`

表达式`a // b`在`a`为 false 或 null 时输出`b`，否则输出`a`。
在给变量赋值的场景中，它非常适合用来提供默认值：

```jq
(.input.theAnswer // 42) as $answer | ...
```

#### 算术运算符

- `+`、`-`、`*` 就是常见的数值加法、减法和乘法运算符。
