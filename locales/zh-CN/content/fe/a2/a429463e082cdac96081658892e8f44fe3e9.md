# 说明

在本练习中，你将编写一些代码，帮你按照最喜欢的菜谱做出一份美味的千层面。

你有四个任务，全都与烹饪千层面所花的时间有关。

## 1. 把预期的烘焙时间存到一个常量里

定义常量 `expected-bake-time`，它应该返回千层面需要在烤箱里烘焙多少分钟。

根据菜谱，千层面需要在烤箱里总共烤 40 分钟。

```factor
expected-bake-time .
! => 40
```

## 2. 计算准备时间（分钟）

定义 `preparation-time` 这个单词。它从栈上取出你给千层面加的层数，留下你花在准备上的分钟数，假设每层需要准备 2 分钟。

```factor
4 preparation-time .
! => 8
```

## 3. 计算剩余的烘焙时间（分钟）

定义 `remaining-time` 这个单词。它接收千层面已经在烤箱里烤过的分钟数，留下它还需要在里面待多少分钟。

```factor
25 remaining-time .
! => 15
```

## 4. 计算总工作时间（分钟）

定义 `total-working-time` 这个单词。它从栈上取出两个实参：先是千层面的层数，然后是千层面已经在烤箱里的分钟数；然后留下目前为止烹饪所花的总时间：准备时间加上已经在烤箱里度过的时间。

```factor
3 20 total-working-time .
! => 26
```
