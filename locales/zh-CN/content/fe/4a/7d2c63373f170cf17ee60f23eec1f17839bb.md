# 介绍

## 部分应用与函数组合

### 部分应用

Elm 中的所有函数都是[柯里化][currying]的，也就是说，如果你调用一个函数时没有传入全部实参，它会返回一个新函数。

这样做的结果叫做[部分应用][partial-application]（你没有把全部实参传给函数，而是只应用了其中一部分）。

```elm
add: Int -> Int -> Int
add a b = a + b

add2: Int -> Int
add2 = add 2

eight: Int
eight = add2 6
--> 8
```

部分应用总是按顺序应用实参。

```elm
contains: String -> String -> Bool
contains first second =
--> This function is in the standard library, and returns True if the second string contains the first one

containsCedd: String -> Bool
containsCedd = contains "Cedd"
--> (partial application always applies the arguments in order, so "Cedd" becomes the first argument to contains
--> This is a function that takes a string, and returns True if that string contains Cedd)

ceddBurgeContainsCedd: Bool
ceddBurgeContainsCedd = containsCedd "Cedd Burge"
--> True
--> ("Cedd Burge" ends up being the second argument to contains, and it does include "Cedd", the first argument)
```

### 管道运算符（`|>`）

写`x |> f`和写`f x`完全等价。举一个具体的例子，`"5" |> String.toInt`和`String.toInt "5"`是一样的。

乍一看这似乎没什么用，但它之所以叫[管道运算符][pipe-operator]，是因为它能让你写出“管道式”的代码。

举个例子，假设我们有一个`sanitize`函数，用来把用户输入转换成整数：

```elm
sanitize : String -> Maybe Int
sanitize input =
    String.toInt (String.trim input)
```

我们可以把它改写成这样：

```elm
sanitize : String -> Maybe Int
sanitize input =
    input
    |> String.trim
    |> String.toInt
```

这样就避免了使用括号，并且按照函数被应用的顺序来展示它们（先是`String.trim`，然后是`String.toInt`），读起来更清楚。

还有一个[反向管道运算符 `(<|)`][reverse-pipe-operator]。
写`f <| x`和写`f x`完全等价。
乍一看这个似乎也没什么用，而且用得肯定没有管道运算符多，但在某些情况下它能帮你省掉括号。

### 函数组合 / 无点风格

[`(>>)`][forward-composition]运算符的类型是`(a -> b) -> (b -> c) -> (a -> c)`，它通过组合两个类型分别为`a -> b `和`b -> c`的兼容函数，创建出一个类型为`a -> c`的函数。
具体做法是：取出第一个函数的输出（类型为`b`），把它作为第二个函数的第一个实参（第二个函数的类型必须也是`b`）。
创建出来的函数接受的输入与第一个函数相同（类型为`a`），返回的则是第二个函数返回的那个`c`。

一个具体的例子是`String.trim >> String.toInt`。
`String.trim`只接受一个字符串作为形参，所以创建出来的函数也只接受一个字符串。
`String.toInt`返回`Maybe Int`，所以创建出来的函数也返回`Maybe Int`。
`String.trim`返回`String`，而`String.toInt`正好能把它作为形参接收，所以这个例子能通过编译。

现在我们可以把`sanitize`函数改写成下面这样：

```elm
sanitize : String -> Maybe Int
sanitize =
    String.trim >> String.toInt
```

注意，虽然功能完全相同，但我们不再使用原始示例中那个`input`形参了。
这种不引用形参来创建函数的方式叫做“无点风格”。
这种风格的优点是代码更简洁，缺点是可能更难理解，对初学者尤其如此。

值得一提的是，Elm 中所有函数都是柯里化的，所以`String.length >> max`能通过编译。

- [`(>>)`][forward-composition]运算符的类型是`(a -> b) -> (b -> c) -> (a -> c)`。
- `String.length`的类型是`String -> Int`，对应`(a -> b)`那一部分，所以`a`是`String`，`b`是`Int`。
- `max`的类型是`Int -> Int -> Int`，对应`b -> c`那一部分。
- `b`是`Int`，所以`max`被部分应用，于是`c`就是这次部分应用的结果（`Int -> Int`）。
- 所以`String.length >> max`的类型是`String -> (Int -> Int)`。
- 所以`((String.length >> max) "123") 2`返回`3`，因为`"123"`的长度是 3，大于`Int`实参传入的 2。

### 函数设计

为了在 Elm 中轻松写出优雅的代码，你应该把主要数据结构放在函数的最后一个形参位置。
标准库中所有常用函数都遵循这一点，比如`List.map`（类型签名见下）。

```elm
map : (a -> b) -> List a -> List b
```

可以看到，`map`函数的最后一个形参是`List a`，返回值是`List b`，所以主要数据结构（`List`）就是最后一个形参。

这样就能写出优雅的管道式代码，比如下面这样。

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase names =
    names
    |> List.map String.trim
    |> List.map String.toUpper
```

它也让你可以方便地使用函数组合和无点风格，作为管道写法的替代方案。

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map String.trim
    >> List.map String.toUpper
```

函数组合还能把这个例子简化成对`List.map`的一次调用。

```elm
trimAndUpperCase : List String -> List String
trimAndUpperCase =
    List.map (String.trim >> String.toUpper)
```
