# 提示

## 通用

- [Python 教程][the python tutorial]是不错的入门材料。
- [PEP 8][pep8] 是 Python 的代码风格指南。
- [PEP 257][PEP257]详细介绍了 Python 文档字符串的约定。
- Python 中的[数字][numbers]可以是整数、浮点数或复数。


## 1. 定义预期的烘焙时间（分钟）

- 你需要[命名][naming]一个[常量][constants]，并给它[赋值][assignment]一个[整数][numbers]值。
  这个常量应该是文件顶部文档字符串之后的第一项内容。
  记得在定义常量之后删除 #TODO 注释。

## 2. 计算剩余的烘焙时间（分钟）

- 你需要定义一个带单个形参的[函数][defining functions]，该形参表示到目前为止已经过去的时间。
- 用[减法运算符][numbers]来做减法。
- 这个函数应该[返回一个值][return]。

## 3. 计算准备时间（分钟）

- 你需要定义一个带单个形参的[函数][defining functions]，该形参表示层数。
- 用[乘法运算符][numbers]来做乘法。
- 你可以在代码中定义一个 PREPARATION_TIME _常量_，表示每层所需的分钟数，而不是使用["魔法数字"][magic-numbers]。
- 这个函数应该[返回一个值][return]。

## 4. 计算总共耗费的烹饪时间（准备 + 烘焙，分钟）

- 你需要定义一个带两个形参的[函数][defining functions]。
- 记住：你总是可以_调用_之前定义过的函数。
- 你可以使用[加法运算符][python as a calculator]来求和。
- 这个函数应该[返回一个值][return]。

## 5. 用注释更新菜谱

- 始终建议按照 [PEP257][pep257] 清晰地[注释][comments]和[编写文档][docstrings]你的代码。
- Google 风格的文档字符串示例可以在 Sphinx 文档的 [napoleon 模块][napoleon]中找到。
