# 说明

Elaine 正在开发一款新的儿童游戏，游戏的主角是动物和魔法棒。
现在该动手编写几个函数了：掷骰子、生成随机的魔法棒能量，以及打乱切片。

## 1. 掷骰子

实现一个`RollADie`函数。

这就是传统的二十面骰子，点数从 1 到 20。

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. 生成魔法棒能量

实现一个`GenerateWandEnergy`函数。
魔法棒能量应该是一个随机浮点数，大于等于 0.0 且小于 12.0。

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. 打乱切片

游戏中出现了八种不同的动物：

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

编写一个`ShuffleAnimals`函数，返回一个切片，其中包含这八种动物，顺序随机。
