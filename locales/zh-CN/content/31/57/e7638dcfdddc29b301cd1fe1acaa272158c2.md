# 提示

## 通用

- 阅读[Elm 创始人写的递归介绍][recursion]。
- 使用 `case` 表达式进行模式匹配。
- 试着把问题拆成一个基准情况和一个递归情况。比如，假设你想用递归的方式数清饼干罐里有多少块饼干。基准情况是空罐子，里面有零块饼干。如果罐子不空，那么罐子里的饼干数等于一块饼干加上拿走一块饼干后罐子里的饼干数。

## 1. 检查今天有多少只鸟来过

- 这个任务不需要递归。
- 可以用 `case` 表达式做模式匹配来访问数组的第一个元素。
- 返回一个值的时候，记得用 `Just` 把结果包起来。

## 2. 让今天的计数自增

- 这个任务不需要递归。
- 可以用 `case` 表达式做模式匹配来访问数组的第一个元素。
- 使用 [`::` 运算符][list-cons]来拆解并重建新的数组。

## 3. 检查是否存在没有鸟来访的一天

- 用递归迭代数组中的元素，直到找到没有鸟来访的一天。
- 基准情况是空数组，或者一只鸟也没有的一天。
- 用模式匹配检查数组中是否有 `0`。

## 4. 计算来访鸟的总数

- 用递归迭代数组中的每一个元素。
- 基准情况是空数组。
- 用 `+` 运算符把当前元素加到其余元素的总和上。

## 5. 计算忙碌天的数量

- 用递归迭代数组中的每一个元素。
- 基准情况是空数组。
- 用 `if` 表达式检查当天是否忙碌（5 只或更多的鸟）。
- 找到忙碌的一天时，把剩余数组里忙碌天的计数加 1。
