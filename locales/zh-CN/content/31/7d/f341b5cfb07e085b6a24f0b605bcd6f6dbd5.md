# 安装

## 安装 Node.js

**Windows 和 OS X 用户**：通过[包管理器][node-download]安装 [Node.js][node]。

**Linux 用户**：按照 [Node.js 包管理器][linstall]上针对你的发行版给出的说明安装 [Node.js][node]。

## 安装`jasmine-node`和`coffeescript`

对大多数用户来说，只需要运行下面这条命令：

```bash
$ npm install -g jasmine-node coffeescript
```

根据你的环境不同，全局安装 `npm` 模块可能需要超级用户权限。如果你使用的是上面链接的官方安装程序，就会遇到这种情况。如果 NPM 报错说你没有访问权限，就在上面的命令中加上 `sudo`：

```bash
$ sudo npm install -g jasmine-node coffeescript
```

如果你使用的是官方安装程序，`PATH` 应该已经自动配置好了。但如果你的 shell 找不到全局安装的模块，或者你是从源码构建的 Node.js，那就更新 `PATH`，让它包含 `npm` 的可执行文件。把下面这一行加到 `~/.bash_profile` 或 `~/.zshrc` 中即可：

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
