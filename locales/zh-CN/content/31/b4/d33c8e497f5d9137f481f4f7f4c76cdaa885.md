# 简介

## 异常筛选

`when`是异常筛选中使用的关键字。它放在 catch 语句之后，可以接受一个布尔表达式，该表达式可以包含当时处于作用域内的任何值。如果表达式的值为 true，就会执行与该`catch`语句关联的代码块，否则会检查下一个`catch`语句（如果有的话）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## 用户自定义异常

用户自定义异常指的是你在代码中定义的、派生自 `System.Exception` 的任何类。它遵循类继承的所有规则，但除此之外，编译器和语言运行时还会对这类类做特殊处理，允许其实例在正常控制流之外被抛出和捕获，就像`exceptions`练习中讨论的那样。

用户自定义异常通常用于携带额外的信息，例如一条消息和其他相关数据，以便捕获它的例程能够获取这些信息。
