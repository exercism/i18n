# 简介

在 Go 中，应用程序通过包来组织。
一个包就是位于同一个文件夹下的一组源文件。
同一个文件夹里的所有源文件，在文件顶部都必须使用相同的包名。
按照惯例，包的名称与它所在的文件夹同名。

```go
package greeting
```

Go 提供了内容丰富的标准库，你可以使用`import`关键字在程序中引入其中的包。
标准库中的包直接用它们的名字导入。

```go
package greeting

import "fmt"
```

导入包之后，通过包名来使用它：

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go 根据声明方式决定某个条目能否被其他包中的代码调用。
要让函数、类型、变量、常量或结构体字段对外可见（称为_导出_），名称必须以大写字母开头。
这类似于 Java 等编程语言使用`public`、`private`这类访问修饰符的做法。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
