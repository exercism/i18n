# 比较运算符

PHP 内置了 10 个比较运算符：

| 名称 | 示例 | 结果 |
| ---- | ---- | ---- |
| 等于 | `$a == $b` | 经过类型转换后`$a`等于`$b`，则为 true。 |
| 全等 | `$a === $b` | `$a`等于`$b`，且类型相同，则为 true。 |
| 不等于 | `$a != $b` | 经过类型转换后`$a`不等于`$b`，则为 true。 |
| 不等于 | `$a <> $b` | 经过类型转换后`$a`不等于`$b`，则为 true。 |
| 不全等 | `$a !== $b` | `$a`不等于`$b`，或类型不相同，则为 true。 |
| 小于 | `$a < $b` | `$a`严格小于`$b`，则为 true。 |
| 大于 | `$a > $b` | `$a`严格大于`$b`，则为 true。 |
| 小于等于 | `$a <= $b` | `$a`小于或等于`$b`，则为 true。 |
| 大于等于 | `$a >= $b` | `$a`大于或等于`$b`，则为 true。 |
| 太空船 | `$a <=> $b` | 当`$a`时，返回一个小于、等于或大于`0`i 的整数。 |

PHP 对`equal`和`identical`做了明确的区分。有时`identical`也被称为`strictly equal`。

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
