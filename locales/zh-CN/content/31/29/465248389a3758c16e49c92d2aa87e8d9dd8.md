# 避免使用打印语句

试着从代码中删掉像 `System.out.println()` 这样的语句。
练习的测试要求提交的解答从方法中_返回_值，而不是把它们打印出来。

通常，这类语句是为了帮助调试代码而加上的。
不过，更好的做法是在运行一个或多个单元测试的同时调试代码。
这样做还有一个好处：可以专注于调试某个具体的测试用例。

下面这些链接介绍了如何在各种 IDE 中一边运行单元测试一边调试 Java 代码：

- [在 Visual Studio Code 中运行和调试 Java 测试](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [在 IntelliJ IDEA 中调试测试](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
