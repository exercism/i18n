# 说明

在这个练习中，你将处理日志行。

每一行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志级别一共有三种：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会给出一行日志，要求你对它做点什么。

你可以自由选用 base R 中的旧式函数，也可以使用`stringr`库，两者都能给出简短可行的解法。

## 1. 从日志行中提取消息

实现`message`函数，返回日志行中的消息：

```R
message("[ERROR]: Invalid operation")
#> "Invalid operation"
```

开头和结尾的空白字符都应去掉：

```R
message("[WARNING]:  Disk almost full\r\n")
#> "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现`log_level`函数，返回日志行的日志级别，并且要用小写形式返回：

```R
log_level("[ERROR]: Invalid operation")
#> "error"
```

## 3. 重新格式化日志行

实现`reformat`函数，重新格式化日志行：把消息放在前面，日志级别放在后面并加上括号：

```R
reformat("[INFO]: Operation completed")
#> "Operation completed (info)"
```
