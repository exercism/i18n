# 关于

[类](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/classes)是 F# 中进行面向对象编程的主要构造。

F# 中的类由字段和方法组成。类的字段和方法统称为它的_成员_。

F# 中的类使用`type`关键字定义。方法使用`member`关键字定义，并且始终是公开的。要定义（私有）字段，可以使用`let`绑定。

```fsharp
type Shoe() =
    let size = 8

    member this.Describe() = $"This is a size {size} shoe"
```

类是用于创建对象的模板。要创建类的实例，把类名当作函数调用即可。类的实例也称为_对象_。

可以使用点号表示法访问对象的成员。

```fsharp
let myShoe = Shoe()
myShoe.Describe()
// => "This is a size 8 shoe"
```
