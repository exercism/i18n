# 说明

了解如何把两个不同内表的数据合并到一个结果内表中。

你的类会收到两个内表，它们包含两组完全不同的数据集：ALPHAS 和 NUMS。

```abap
TYPES: BEGIN OF alphatab_type,
         cola TYPE string,
         colb TYPE string,
         colc TYPE string,
       END OF alphatab_type.
TYPES: alphas TYPE STANDARD TABLE OF alphatab_type.
TYPES: BEGIN OF numtab_type,
         col1 TYPE string,
         col2 TYPE string,
         col3 TYPE string,
       END OF numtab_type.
TYPES: nums TYPE STANDARD TABLE OF numtab_type.
```

ALPHA 表中的数据如下所示。

| COLA | COLB | COLC |
| --- | --- | --- |
| A | B | C | 
| D | E | F |
| G | H | I |

NUMS 表中的数据如下所示。

| COL1 | COL2 | COL3 |
| --- | --- | --- |
| 1 | 2 | 3 | 
| 4 | 5 | 6 |
| 7 | 8 | 9 |

你的任务是返回一个内表，其中的记录把内表 ALPHAS 和内表 NUMS 中每个单元格的值组合在一起。例如，内表 COMBINED_DATA 第一行第一列的值应该是 “A1”。

期望返回的表定义如下：

```abap
TYPES: BEGIN OF combined_data_type,
         colx TYPE string,
         coly TYPE string,
         colz TYPE string,
       END OF combined_data_type.
TYPES: combined_data TYPE STANDARD TABLE OF combined_data_type WITH EMPTY KEY.
```
