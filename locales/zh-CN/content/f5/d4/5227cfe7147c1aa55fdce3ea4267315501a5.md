# 测试

每个练习都包含一个测试文件。
使用 `bats` 程序运行测试。

```bash
bats test-hello-world.bats
```

你需要先安装 `bats`。
请查看 [Bash 赛道的测试][bash] 页面，了解如何在你的系统上安装 `bats`。

### bats 是用 bash 实现的

bats 文件是一个 bash 脚本，其中包含一些由 `bats` 命令识别的特殊函数。
你会看到一些像这样的测试：

```sh
jq -f some-exercise.jq <<< "{some,json,here}"
```

那个 `<<<` 语法是 bash 的 [Here String][here-string]。
它把右侧的字符串送入左侧程序的标准输入。
它（[大致][so]）等同于：

```sh
echo "{some,json,here}" | jq -f some-exercise.jq
```

## assert 函数的帮助

测试使用了 [bats-assert][bats-assert] 库中的函数。
各种 `assert*` 函数的帮助都能在那里找到。

## 跳过的测试

解出一道练习，意味着让它所有的测试都通过。
默认情况下，运行测试时只会执行一个测试（也就是第一个）。
这是有意为之的，这样你就能专注于让那一个测试通过。
一旦它通过，你就可以把其他测试前面的

    [[ $BATS_RUN_SKIPPED == true ]] || skip

标注注释掉或删除，从而启用下一个测试。

## 覆盖跳过设置

要运行所有测试，包括带有 `skip` 标注的测试，可以运行：

```bash
BATS_RUN_SKIPPED=true bats test-some-exercise.bats
```

用包装函数来省去重复输入会很方便：在 `bash` 里可以这样做：

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

然后运行测试只需：

```bash
bats
```

## 在 `jq` 中调试

`jq` 自带一个很方便的 [`debug`][debug] 过滤器。
在开发练习解答时用它来查看当前位于 jq 管道中的数据。
更多细节请参见[调试文档][debugging]。
