# 说明

在这个练习中，你将实现一部分辅助函数，帮助开发者清理标识符名称。

在这 5 个任务中，你将逐步构建出 `clean` 函数。
合法的标识符由零个或多个字母和下划线组成。

如果向 `clean` 函数传入空字符串，则应返回空字符串。

## 1. 将空格替换为下划线

实现一个 `clean1` 函数，将所有空格替换为下划线。开头和结尾的空格也不例外。

```elm
clean1 "my   Id"
    --> "my___Id"
```

## 2. 将控制字符替换为大写字符串 "[CTRL]"

实现 `clean2`，完成上一个函数的所有功能，并将常见的控制字符（\n、\t 和 \r）替换为字符串 `"[CTRL]"`。

```elm
clean2 "my\nId"
    --> "my[CTRL]Id",
```

## 3. 将 kebab-case 转换为 camelCase

实现 `clean3`，完成上一个函数的所有功能，并将 kebab-case 转换为 camelCase。

```elm
clean3 "à-ḃç"
    --> "àḂç"
```

## 4. 省略数字

实现 `clean4`，完成上一个函数的所有功能，并省略所有数字。

```elm
clean4 "123"
    --> ""
```

## 5. 省略小写希腊字母

最后，实现 `clean`，完成上一个函数的所有功能，并省略 'α' 到 'ω' 范围内的所有希腊字母。

```elm
clean "My Οβιεγτ Finder"
    --> "My_Ο_Finder"
```
