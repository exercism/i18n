# 面向 Exercism 的 24 Pull Requests：Ruby 版！

我们欢迎各位贡献者参与这个项目。

在我们的 issue 列表里，留意下面这些标签：

* first-timers only
* good first patch
* bug
* enhancement

或者，你发现了可以贡献的地方？觉得文档还不够完善？少了点什么？在 Exercism 上提交或评审练习时遇到了你不喜欢的地方？那就创建一个 pull request 吧！

看看[参与语言轨道](https://github.com/exercism/docs/blob/master/contributing-to-language-tracks/README.md#getting-involved-in-an-exercism-language-track)的文档，以及一些[我们正在寻找的点子](http://exercism.io/languages/ruby/todo)，那里列出了还需要有人实现的练习。

我们会在论坛的 [building-exercism] 里回答大家的问题。

[building-exercism]: https://forum.exercism.org/c/general/building-exercism/125
