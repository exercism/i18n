# 关于

*堆* 是一种集合，它始终知道自己最小（或最大）的那一项，并且能让你快速把它取出来，也就是*优先队列*最自然的实现方式。堆位于 [`heaps`][heaps] 词汇表中。

`<min-heap>` 会构建一个空堆，其中最小的键最先出来；`<max-heap>` 则让最大的键最先出来。每一项都是一个*值*，存放在某个*键*之下，而键就是 Factor 用来排序的优先级：

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
heap-push  ( value key heap -- )
heap-push-all ( assoc heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

堆是*可变的*：`heap-push` 和 `heap-pop` 会就地修改它。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
heap-empty?  ( heap -- ? )
heap-size    ( heap -- n )
```

`heap-peek` 只读取最前面的一项，不把它移除；`heap-pop` 会移除并返回它；`heap-pop-all` 会把堆排空，按优先级顺序转成一个由 `{ key value }` 对组成的关联列表。

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
"carol" 9 pick heap-push
dup heap-pop .           ! => 2 "bob"   (removed; value then key)
heap-pop-all values .    ! => { "alice" "carol" }
```

入堆的复杂度是 `O(log n)`，读取最前面一项的复杂度是 `O(1)`，所以即使队列很大，反复“取出最紧急的一项，再加入新的项”也依然很快。它的实现是用一个可增长的数组存储的二叉堆；键可以是任何可排序的值（数字、字符串等）。

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
