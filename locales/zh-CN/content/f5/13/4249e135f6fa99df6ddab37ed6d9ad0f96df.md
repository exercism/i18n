# 简介

在 Common Lisp 中，函数不仅能返回一个值，还能返回多个值。
例如，`floor`会朝零的方向向下取整，并返回 2 个值：第一个是取整后的值，第二个是余数。

```lisp
(floor 3.5) ; => 3
            ;    0.5
```
（在输出中，我们会把返回的多个值分行显示。）

## 返回多个值

如果你想让函数返回多个值，就要使用`values`访问器：

```lisp
(defun three-numbers () (values 1 2 3))
(three-numbers) ; => 1
                ;    2
                ;    3
```

## 处理多个值

如果你只关心第一个值，那就不需要做任何特别的事：语言会帮你处理好：

```lisp
(+ (values 1 2 3) (values 10 20 30)) ; => 11
```

不过，如果你想访问那些其他的值，就需要用到好几个函数。
两个主要的宏是`multiple-value-list`和`multiple-value-bind`。
它们用来包裹返回多个值的表达式，并捕获所有的值。
第一个会创建一个包含所有值的列表。
第二个则让你把变量绑定到各个值上。

```lisp
(multiple-value-list (values 1 2 3))                   ; => (1 2 3)
(multiple-value-bind (a b c) (values 1 2 3) 
   (+ a b c)) ; => 6
```

另一个有用的函数是`nth-value`
