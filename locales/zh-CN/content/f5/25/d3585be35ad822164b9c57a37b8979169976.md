# 说明

在本练习中，你将实现一个程序，用来判断一局[井字棋][tic-tac-toe]的状态。
（_你可能还知道这个游戏叫“noughts and crosses”或“Xs and Os”。_）

游戏在 3×3 的棋盘上进行。
玩家轮流在棋盘上放置`X`和`O`。
当一名玩家在棋盘的一行、一列或一条对角线上放满三个标记而获胜，或者整个棋盘被填满时，游戏结束。

在本练习中，我们假设`X`先走。

你的任务是判断给定的棋局处于哪种状态。

游戏可能有 3 种状态：

- 游戏处于**ongoing**状态。
- 游戏以**draw**结束。
- 游戏以**win**结束。

如果给定的棋盘无效，就抛出相应的错误。

如果棋盘满足以下条件，它就是无效的：

- 在按正确顺序轮流落子的情况下，这样的棋盘不可能出现（记住，`X`先走）。
- 游戏在已经结束后仍在继续。

## 示例

### 进行中的游戏

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 平局

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 获胜

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 无效

#### 落子顺序错误

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 获胜后继续落子

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
