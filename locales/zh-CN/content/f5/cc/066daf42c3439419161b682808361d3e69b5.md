# 编写代码

在`<exercise_name>.zig`中编写代码。
有些练习会附带为特定 Zig 构造预先写好的签名，比如[常量][constants]、[函数][functions]、[导入][imports]、[结构体][structs]，以及[可能还有更多][et-cetera]！

这些预先写好的签名旨在为你提供一个清晰的起点，帮助你完成练习。
不过，并不一定要从这些签名开始。
尤其是，任何能通过测试的代码都是完全可以接受的解答。

## 运行测试

要运行测试，只需运行以下命令：

```bash
zig test test_exercise_name.zig
```

把`exercise_name`替换成练习的名称。
上述命令必须在练习的根目录中运行，因为它的测试文件应该就在同一个位置。
此外，任何练习的所有测试默认都是启用的，而且没有任何测试可以跳过。

由于所有测试都有这些规定，如果你想逐个通过每个测试，就必须把未通过的测试[注释掉][comments]。
注释掉一个测试很简单，只需在每一行开头加上`//`。
否则，当你确信自己的解答能通过测试时，可以取消注释这些测试，看看是否能通过。
