# 简介

## 特性

[C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/)提供了一种修饰声明的方式，可以把元数据关联到类、方法、枚举、字段、属性，或任何[其他受支持](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)的声明上。

你可以把特性写在声明的前一行来应用它，例如用`ClassAttribute`和`FieldAttribute`：

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

这种声明式元数据只是给代码附加了额外的结构化信息，并不会改变代码的行为。但代码的其他部分会用到这些元数据，从而改变目标的行为，或者为目标增加、修改、移除、限制某些功能。

有许多[预定义和保留的特性](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)，例如`Flags`、`Obsolete`、`Conditional`和`Experimental`。每个特性都有特定的语义，可以在 C# 文档中查阅。注意，像[`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)这样的特性，其完整名称采用`<Name>Attribute`的形式（例如`FlagsAttribute`）。

## 标志枚举

C# 的[`enum`类型](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)表示一组固定的命名常量（也就是枚举）。

通常，一个`enum`成员只能指向其中一个命名常量。但有时指向多个常量会很有用。这时，可以在`enum`上加上[`Flags`特性](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)

标志枚举可以这样定义（使用二进制整数表示法`0b`）：

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

一个`PhoneFeatures`实例，如果它的值是`0b00000011`，就同时设置了`Call`和`Text`两个标志。

默认情况下，枚举成员的值使用`int`类型。你也可以在枚举声明中指定其他整数类型：

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
