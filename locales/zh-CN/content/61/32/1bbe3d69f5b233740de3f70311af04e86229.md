# 说明

玛丽是电视剧 _Star Trek: The Next Generation_ 的忠实粉丝。
她经常玩纸上角色扮演游戏，在游戏里她和朋友们假扮 _Starship Enterprise_ 的船员。
玛丽扮演的角色是 Captain Picard，这意味着她得负责记舰长日志。
她很喜欢游戏中富有创造力的部分，但不喜欢临场随机编造数据。

帮帮玛丽，为舰长日志里常见的数据写一些随机生成器吧。

~~~~exercism/note
本练习的起始实现接收一个`java.util.Random`实例作为构造参数。
这样，练习的测试就能传入一个带预定义种子的实例，从而让测试结果可预测。

因此，你应当在实现中使用提供的`java.util.Random`实例。
~~~~

## 1. 生成随机星球

_Starship Enterprise_ 在航行中会遇到许多星球。
在 Star Trek 宇宙中，星球会按各自的性质划分成不同类别。
比如，地球是一颗`M`级星球。
所有可能的星球等级有：`D`、`H`、`J`、`K`、`L`、`M`、`N`、`R`、`T`和`Y`。

实现`randomPlanetClass()`方法。
它应该随机返回其中一个星球等级。

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. 生成随机星舰注册号

Enterprise（注册号`NCC-1701`）并不是唯一一艘在宇宙中飞行的星舰！
当它和另一艘星舰会合时，玛丽需要记下那艘星舰的注册号。

注册号以 "NCC-" 开头，后面是一个从`1000`到`9999`（含两端）的数字。

实现`randomShipRegistryNumber()`方法，它返回一个随机的星舰注册号。

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. 生成随机星历

日志里要是不写日期，那还有什么用呢？

星历是一个浮点数。
_Starship Enterprise_ 在 _The Next Generation_ 第一季里的冒险，发生在星历`41000.0`和`42000.0`之间。
其中的 "4" 代表 24 世纪，"1" 代表第一季。

实现`randomStardate()`方法，返回一个介于`41000.0`（含）和`42000.0`（不含）之间的浮点数。

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
