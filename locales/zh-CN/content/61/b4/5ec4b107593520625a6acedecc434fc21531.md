# 说明

在这个练习中，你要和朋友玩一个猜数字游戏。
规则很简单：你悄悄想一个`1`到`100`之间的数字，朋友来猜你选的是哪个数。
为了帮朋友，你要根据猜测与你选的数字（`42`）的接近程度给出不同的回答。
下面是不同输入对应的规则：

- 猜的是`42`："Correct"
- 猜的是`41`或`43`："So close"
- 猜的数小于`41`："Too low"
- 猜的数大于`43`："Too high"

你要用四个任务来实现对这些猜测的回答。

## 1. 回复猜对的答案

实现`reply`函数，对猜对的答案作出回复：

```haskell
reply 42
-- -> "Correct"
```

## 2. 回复接近的答案

修改`reply`函数，让它对接近的答案作出回复：

```haskell
reply 41
-- -> "So close"
```

## 3. 回复猜得太小的答案

修改`reply`函数，让它对猜得太小的答案作出回复：

```haskell
reply 25
-- -> "Too low"
```

## 4. 回复猜得太大的答案

修改`reply`函数，让它对猜得太大的答案作出回复：

```haskell
reply 88
-- -> "Too high"
```
