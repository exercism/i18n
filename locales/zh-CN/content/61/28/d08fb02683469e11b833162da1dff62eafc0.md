# 说明

在 _Instruments of Texas_ 工作期间，你的任务是开发一台用 C# 编写的实验性计算器。你要构建一个测试框架，用来验证一系列计算器功能，先从乘法开始。你会发现，当乘法的两个操作数都为负数时，需要特别留意。

我们已经为你提供了`Calculator`类，请不要修改它。

## 1. 完善用户定义的异常`CalculationException`的定义

请完善`CalculationException`的构造函数，它需要存储（包装）计算器抛出的任何异常，以及在异常抛出时正在处理的操作数。

## 2. 处理计算器中的溢出情况，并向调用方提供更详细的信息

实现`CalculatorTestHarness.Multiply()`方法：它应当调用传给构造函数的`Calculator`实例的`Calculator.Multiply()`方法，并传入整数 x 和 y。如果`Calculator.Multiply()`方法中发生溢出，就会抛出`OverflowException`。这个异常应当在`CalculatorTestHarness.Multiply()`方法中被捕获，包装成`CalculationException`，并把传递的 x 和 y 值存储为该异常的操作数。然后抛出新建的`CalculationException`对象。如果调用成功，可以忽略`Calculator.Multiply()`方法返回的值。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.Multiply(Int32.MaxValue, Int32.MaxValue);
// => throws an instance of CalculationException

var cth2 = new CalculatorTestHarness(new Calculator());
cth2.Multiply(3, 2);
// => silently exits
```

## 3. 用有效输入测试乘法运算

实现`CalculatorTestHarness.TestMultiplication()`方法，它接收两个整数并调用`CalculatorTestHarness.Multiply()`方法。此时返回`"Multiply succeeded"`。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(6, 7);
// => "Multiply succeeded"
```

## 4. 用负数输入测试乘法运算

修改`CalculatorTestHarness.TestMultiplication()`方法，使两个整数实参都为负数（小于零）时返回`"Multiply failed for negative operands. <INNER_EXCEPTION_MESSAGE>"`。

其中`<INNER_EXCEPTION_MESSAGE>`占位符应替换为`CalculationException`内部异常的消息。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(-2, -Int32.MaxValue);
// => "Multiply failed for negative operands. " + innerException.Message
```

## 5. 用正数输入测试乘法运算

修改`CalculatorTestHarness.TestMultiplication()`方法，使至少有一个整数实参不是负数时返回`"Multiply failed for mixed or positive operands. <INNER_EXCEPTION_MESSAGE>"`。

其中`<INNER_EXCEPTION_MESSAGE>`占位符应替换为`CalculationException`内部异常的消息。

```csharp
var cth = new CalculatorTestHarness(new Calculator());
cth.TestMultiplication(Int32.MaxValue, Int32.MaxValue);
// => "Multiply failed for mixed or positive operands. " + innerException.Message
```
