# Alias

[特殊形式 `alias`][alias]可以让你缩短或更改引用外部模块时使用的名称。你可以通过 `:as` 选项指定自定义名称。

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

不带任何参数使用时，它会把模块名缩减为最后一部分，例如：

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

多个别名可以用`{}`合并在一起：

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

别名通常写在模块定义的开头，但也可以写在任何位置。它们具有词法作用域，也就是说，在某个函数定义内部添加的别名，在另一个函数中无法使用。

未使用的别名会导致编译器警告。

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
