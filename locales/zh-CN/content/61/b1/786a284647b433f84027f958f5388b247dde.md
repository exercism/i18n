# 简介

_枚举类型_是一种特殊的数据类型，它让变量的值只能是一组预定义的常量。变量的值必须等于为它预先定义好的某个值。常见的例子包括指南针方向（`NORTH`、`SOUTH`、`EAST` 和 `WEST`）以及一周中的各天。

由于它们是常量，枚举类型中字段的名称使用大写字母。

## 定义枚举类型

在 Java 编程语言中，使用 `enum` 关键字来定义枚举类型。例如，把一周中的各天定义成枚举类型可以这样写：

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

只要需要表示一组固定的常量，就应该使用枚举类型。这包括像太阳系中的行星这样天然的枚举类型，也包括在编译时就能知道所有可能取值的数据集合，例如菜单上的选项、命令行标志等。

## 使用枚举类型

下面的代码展示了如何使用上面定义的 `DayOfWeek` 枚举：

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

## 添加方法和字段

Java 编程语言的枚举类型比其他语言中的对应类型强大得多。`enum` 声明定义了一个_类_（称为_枚举类型_）。枚举类的主体可以包含方法和其他字段：

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

在 `Rating` 枚举类型的某个成员上调用 `getNumberOfStars` 方法：

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
