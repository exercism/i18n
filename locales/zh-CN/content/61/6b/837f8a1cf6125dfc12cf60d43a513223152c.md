# 关于

结构体和类的许多种成员（字段是主要的例外）都可以使用[表达式主体成员][expression-bodied-members]语法。用表达式定义成员，往往比传统的块或语句写出的代码更简洁、更易读。

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```

表达式主体成员不能包含由多条语句组成的块，但有函数式编程背景的人要记住：传统成员能做到的任何事情，都可以用这类成员实现。这里的“表达式”可以是产生副作用的赋值运算，也可以是方法调用，也就是说，什么都可能发生。

[expression-bodied-members]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/statements-expressions-operators/expression-bodied-members
