# 提示

## 概述

- 每天的鸟的数量存储在名为`birdsPerDay`的字段中。
- 每天的鸟的数量是一个数组，其中恰好包含 7 个整数。

## 1. 检查上周的计数

- 由于我们保留了过去一周的数据，只需要返回上周的值。

## 2. 检查今天有多少只鸟来访

- 记住，计数按天从最早到最近排列，最后一个元素表示今天。
- 访问最后一个元素，既可以使用它（固定）的下标（记得从 0 开始计数），也可以通过数组的大小来计算它的下标。

## 3. 自增今天的计数

- 把表示今天计数的元素设置为今天的计数加 1。

## 4. 检查是否有某一天没有鸟来访

- 可以用 `for` 循环遍历数组。
- 另一种解法是使用 Java Stream API。

## 5. 计算前若干天来访的鸟的数量

- 可以用一个变量来保存来访的鸟的数量。
- 可以用 `for` 循环遍历数组。
- 可以在循环中更新这个变量。
- 记住：数组的下标从`0`开始。

## 6. 计算忙碌的天数

- 可以用一个变量来保存忙碌的天数。
- 可以用 `foreach` 循环遍历数组。
- 可以在循环中更新这个变量。
- 可以在循环中使用分支语句。
