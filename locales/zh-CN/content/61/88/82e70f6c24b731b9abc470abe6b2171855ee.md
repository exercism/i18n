# 安装

安装 Ceylon 最简单的方法就是**别**安装它。
大多数练习用我们的[网页版 IDE](http://try.ceylon-lang.org/) 就能解决。

不过如果你更想自己动手，也可以安装命令行发行版，最简便的方式是通过 [SDKMAN](http://sdkman.io/)。
如果还没装，先装上它，然后在终端输入 `sdk install ceylon` 即可。

OSX 用户还可以通过 [Homebrew 包管理器](http://mxcl.github.com/homebrew/) 安装。

其他平台以及 Ceylon IDE（Eclipse 的一个插件）的安装说明，都可以在[官方网站](http://ceylon-lang.org/download/) 找到。
