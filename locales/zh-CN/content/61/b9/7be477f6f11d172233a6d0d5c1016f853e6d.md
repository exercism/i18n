# Haskell 内置数值类型

## 数字

Haskell 的标准库称为 ***Prelude***，其中定义了大多数基本数值类型：固定大小的整数（`Int`）、任意精度整数（`Integer`）、单精度浮点数（`Float`）和双精度浮点数（`Double`）。有理数、复数等其他数值类型则定义在其他库中。

`Integer`能保存任意大小的数字，上限只取决于机器的内存；而`Int`对应的是能用 32 位或 64 位表示的整数集合（保证至少能表示 -2^29 到 2^29）。

`Float`对应实数集合，精度受计算机限制。定义在数字上的运算通常只适用于其中一种类型，而不是两者都适用。

在`Float`和`Integer`之间进行转换的函数有很多，其中包括把`Int`/`Integer`转换成`Float`的`toFloat`，以及把`Float`转换成`Int`的`ceiling`。

## 算术运算符

Haskell 有三个“求幂”运算符，它们的工作方式不同，接受的实参类型也不同。

- `**`接受两个**浮点数**，用对数计算幂。
- `^^`接受一个**浮点数**，把它提升到**整数**次幂，指数可正可负。
- `^`接受**任意数值类型**，把它提升到**正整数**次幂。

从整数类型（`Int`或`Integer`）转换到其他任何数值类型，使用函数`fromIntegral`完成。目标类型会被自动推断。例如：

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```

整数的除法有点复杂。如果对整数使用普通的`/`运算符，就会收到错误信息（不过表达式`4/3`确实能工作，因为 Haskell 会在必要时把字面量整数提升为浮点数）。整数的除法要改用一组有名字的运算符来完成。

Haskell 对运算符有个巧妙的小技巧：任何接受两个实参的函数，只要把名字用反引号括起来，就能像运算符一样使用。所以下面两行代码的意思完全相同：

```haskell
 d = 7 `div` 3
 d = div 7 3
```

记住这一点，下面就是整数除法的运算符：

- `quot`：返回两个数字的商。也就是除法结果向零截断后的值。
- `rem`：返回相除后的余数。
- `div`：与`quot`类似，但向负无穷方向取整。
- `mod`：返回两个数字的模。它与`rem`类似，但当`div`返回负数时，规则不同。

正如可以把接受两个实参的函数转换成一个运算符，你也可以把运算符放进括号里，把它转换成接受两个实参的函数。所以下面两行代码意思相同：

```haskell
(+) 3 4
3 + 4
```
