# 简介

Haxe 内置支持正则表达式。你可以用它们来验证字符串的格式、转换字符串，或者从给定文本中提取某些有规律的数据。

要创建正则表达式，在`~/`和`/`之间输入即可：

```haxe
var r = ~/haxe/i;
```

另一种做法是使用`EReg()`实例：

```haxe
var r = new EReg("haxe", "i");
```

这里的`i`是一个标志，让模式不区分大小写。还有其他标志，包括：

- `g`：全局替换。
- `m`：多行匹配

在`~/`和`/`之间，输入正则表达式的模式。例如，你想查找一个包含 A 到 Z 字母的字符串。这里可以使用范围模式`[A-Z]`。表达式模式有很多，包括：

- `.`：任意字符
- `*`：重复零次或多次
- `+`：重复一次或多次
- `[A-Z0-9]`：字符范围
