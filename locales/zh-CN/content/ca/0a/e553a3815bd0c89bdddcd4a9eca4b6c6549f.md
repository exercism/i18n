# 引言

Go 的函数和方法可以返回多个值：

```go
func GetCard() (Card, error) { ... }
```

每个返回值都必须按顺序赋值，并用逗号分隔：

```go
card, err := GetCard()
```

赋值语句中的每个位置都会声明一个变量。
如果某个声明过的变量从未被使用，Go 就无法编译通过。
空白标识符`_`可以代替变量名，用来跳过对应的那个返回值：

```go
card, _ := GetCard()
```

`error`是内置接口。
当`error`为`nil`时，说明没有发生错误；只要它不是`nil`，就说明出了问题。
按照惯例，可能失败的函数应该把`error`作为最后一个返回值。
调用方在使用其他返回值之前，必须先检查它：

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
