# 关于

条件表达式用于根据 **if** 条件为**true**或**false**来执行代码。这些表达式写成：

```haxe
if (condition) {
  expressions
};
```

条件的输出为`Bool`类型，因此当输出为`true`时，就会执行这些表达式。

有时，当条件实际上是`false`时，我们希望执行另一段代码。这时`else`表达式就派上用场了。`else`会在初始条件为`false`时执行表达式。但如果我们想针对多种可能情况检查条件呢？这时就可以使用`else if (condition)`。下面是一个完整的示例：

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
