# 指令附录

## 在 Prolog 中处理日期

Prolog 内置的日期支持[相当基础][built-in-dates-support]。只用 Prolog 内置的功能也能解出这道练习，但处理日期更舒服的方式是使用 [date_time 包][date-time-package]。

### 安装 date_time 包

如果你安装的 Swipl 版本比较新，可以通过运行以下命令来安装这个包：

```bash
swipl pack install date_time
```

如果这样不行，可以运行：

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
如果你使用的是在线编辑器，就不需要手动安装任何东西。
~~~~

### 使用 date_time 包

将以下代码添加到解答文件的开头，即可使用 `date_time` 包：

```prolog
:- use_module(library(date_time)).
```
