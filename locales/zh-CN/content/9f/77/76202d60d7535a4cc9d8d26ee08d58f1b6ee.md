# 关于

Lambda 类是一组函数式方法，让我们能在 Haxe 中使用函数式编程风格。它让我们可以一次性操作整个 Iterable。相比循环式的写法，这通常更可取，因为它更不容易出错，也更易读。为了方便，Array 和 List 类也包含了 Lambda 类里一些常用的方法。

`Lambda` 类的一些函数包括：

- `Lambda.array`、`Lambda.list` 将 Iterable 转换为 Array 或 List。它总是返回一个新的实例。
- `Lambda.count` 统计元素的数量。如果 Iterable 是 Array 或 List，使用它的 length 属性会更快。
- `Lambda.has` 判断指定元素是否在 Iterable 中。
- `Lambda.indexOf` 找出指定元素的下标。
- `Lambda.find` 找出符合给定查找函数的第一个元素。
- `Lambda.concat` 合并两个 Iterable，返回一个新的 List。
- `Lambda.filter` 找出满足条件的元素，返回一个新的 List。

下面的例子演示了其中一些函数：

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
