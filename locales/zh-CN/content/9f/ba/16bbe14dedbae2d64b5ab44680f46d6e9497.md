# 关于

Factor 的序列库大量依赖 *quotations*，也就是 `[ ]` 括号里的代码，来参数化迭代。形式始终不变：传入一个序列和一个 quotation，高阶词就会把 quotation 作用到每个元素上。

```factor
{ 1 2 3 4 5 } [ even? ] filter .   ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .   ! => { 1 3 5 }
{ 1 2 3 4 5 } [ 3 > ] find .s      ! => 3 / 4 (index, element)
{ 1 2 3 4 5 } [ sq ] map .         ! => { 1 4 9 16 25 }
{ 1 2 3 4 5 } [ . ] each           ! prints each element
0 { 1 2 3 4 5 } [ + ] reduce .     ! => 15
```

常用的高阶词一览：

| 词         | 形式                                      |
|--------------|--------------------------------------------|
| `each`       | `( seq quot -- )`                          |
| `map`        | `( seq quot -- newseq )`                   |
| `filter`     | `( seq quot -- newseq )`                   |
| `reject`     | `( seq quot -- newseq )`                   |
| `find`       | `( seq quot -- i/f elt/f )`                |
| `find-last`  | `( seq quot -- i/f elt/f )`                |
| `reduce`     | `( seq init quot -- result )`              |
| `map-sum`    | `( seq quot -- n )`                        |
| `count`      | `( seq quot -- n )`                        |
| `any?`       | `( seq quot -- ? )`                        |
| `all?`       | `( seq quot -- ? )`                        |
| `with`       | `( value seq quot -- seq curry )`          |
| `without`    | `( seq exclude -- newseq )`                |
| `sort`       | `( seq -- sortedseq )`                     |
| `sum`        | `( seq -- n )`                             |
| `minimum`    | `( seq -- elt )`                           |
| `maximum`    | `( seq -- elt )`                           |
| `minimum-by` | `( seq quot -- elt )`                      |
| `maximum-by` | `( seq quot -- elt )`                      |

当*你*定义的词要把运行时的 quotation 传给这些组合子时，就用`; inline`声明它，这样组合子在调用处做效果推断时才能看清 quotation 的形式。只用字面 quotation 构建的词则不需要。

除了核心的序列操作之外：

| 词汇              | 提供                                      |
|--------------------|-----------------------------------------------|
| [`sorting`][sorting]          | `sort`、`sort-by`                             |
| [`math.statistics`][math.statistics]  | `cum-sum`、`cum-product`、`cum-min`、`cum-max` |
| [`grouping`][grouping]         | `group`、`clump`、`monotonic-split`           |
| [`sets`][sets]             | `members`、`all-unique?`                      |

成对组合子（`bi`、`tri`）和“n 元”组合子（`2map`、`2each`、`zip`）在 quotation 需要多个输入时，也沿用同样的模式。
