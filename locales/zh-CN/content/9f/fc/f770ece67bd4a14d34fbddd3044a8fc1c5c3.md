# 关于字符

这可能是_一个很大_的话题！
完全可以为它写一本厚书，而且确实有好几个人这么做了（在亚马逊上搜索 “unicode book” 就能看到一些例子）。

## 极简历史

在早些年，计算机处理字符要简单得多，那时程序员认为英语是唯一重要的语言。
于是：26 个字母（含大小写）、10 个数字、若干标点符号，再加上一个让铃声响起的编码（0x07），全部都能塞进 7 个比特里：这就是 [ASCII][wiki-ascii] 字符集。

很自然地，有人开始问：那 à、ä 和 Ł 怎么办？接着又有人问起 ऄ、ஹ 和 ญ，而年轻人想要 emoji 😱。
该怎么办呢？

长话短说，许多聪明又有耐心的人在委员会里工作了好几年，才敲定 [Unicode][web-unicode] 字符集以及 [UTF-8][wiki-utf-8] 等编码的细节，大量软件也需要进行_极其_复杂的重写。
此外，还引入了大量新的 bug。

为了避免_所有东西_都坏掉，Unicode/UTF-8 的设计确保前 127 个编码与 ASCII 完全相同_（连那个铃声也不例外）_。

## Kotlin 中的字符

大约在 2005 年之后设计的语言有一个巨大的优势：那时已经存在一个相当稳定的 Unicode 标准。

Kotlin（2011 年首次发布）可以假定用户会使用各种（人类）语言，并且需要用 Unicode 来表达它们。

~~~~exercism/advanced
Kotlin 中的[字符][ref-char]是 16 位的（UTF-16）[`codepoints`][wiki-codepoint]，与 JVM 的 `char` 相同。
这足以表达大多数书写字母表，但不足以涵盖全部 emoji。

完整的 Unicode 标准每个字符最多使用六个字节（48 位），称为 [`grapheme`][wiki-grapheme]。

必要时，Kotlin 的 `Strings` 会通过为每个字符使用多个码点来支持这套完整标准。
例如，😱 由 `\uD83D` 和 `\uDE31` 组成。

遗憾的是，Java 没有内置的 grapheme 支持，为了保持兼容，Kotlin 也没有。

[wiki-codepoint]: https://en.wikipedia.org/wiki/Code_point
[wiki-grapheme]: https://en.wikipedia.org/wiki/Grapheme
[ref-char]: https://kotlinlang.org/docs/characters.html
~~~~


字符字面量用单引号书写，而字符串用双引号书写，两者是不同的。
对来自 C/C++ 世界的人来说这大概显而易见，但对 Python 和 JavaScript 程序员来说可能有点令人困惑。

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code // => 65535 (64k, the largest code point allowed)

val not_char = 'abc' // => Too many characters in a character literal.
```

在 `Char` 和 `Int` 之间转换很简单：

```kotlin
a.code  // => 97
Char(97) // => 'a'
```

编译器允许对 `Char` 进行_某些_形式的整数运算：

```kotlin
'a' + 5     // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## 一些用于`Char`的函数

一如既往，可用的[函数][ref-char-lib]实在太多，没法在这里一一讨论，所以下面只挑了几个。

- 对适用的字母表，用 [`uppercase()`][ref-uppercase] 和 [`lowercase()`][ref-lowercase] 改变大小写。
- 用 [`isUpperCase()`][ref-isuppercase] 和 [`isLowerCase()`][ref-islowercase] 检测字母的大小写。
- 用以下函数检测字符类型：
  - [`isLetter()`][ref-isletter]，覆盖许多字母表（Unicode 中的 Lu、Ll、Lt、Lm 和 Lo 类别）
  - [`isDigit()`][ref-isdigit]，范围是 0..9（Unicode 中的 Nd 类别）
  - `isLetterOrDigit()`，结合了前两个
  - [`isWhitespace()`][ref-iswhitespace]，任意空白字符（Unicode 中的 Cc、Zp、Zl 和 Zs 类别）

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

此外，[正则表达式][ref-regex]（这会在后面的某个概念里专门讲解）可以实现强大的搜索和操作。

## Char、List 与 String 之间的相互转换

要把 `String` 转换成 `Char` 的 `List`，可以用 `toList()`。

要把 `Char` 的 `List` 转换成 `String`，可以用 [`joinToString()`][ref-jointostring] 函数，它接收一个分隔符（通常是空字符串）作为实参。

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

注意，`joinToString()` 作用于 List 或数组。
要把单个 `Char`_转换_成长度为 1 的字符串，用 `toString()`。

```kotlin
'a'.toString() // => "a"
```

要检查某个字符是否出现在 `String`、`Char` 列表或数组中，可以用 `in`，它对应 [`contains()`][ref-contains] 函数。

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
