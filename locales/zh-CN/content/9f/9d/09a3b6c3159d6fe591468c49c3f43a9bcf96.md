# 结构体

结构体是一种自定义数据类型，你可以用它把多个相关的值组合在一起，并给它们命名。
结构体和元组类似，但更灵活，还能给每一项数据命名，让代码更清晰。
Cairo 中的结构体有以下几个特点：

- 每个结构体类型都有自己的名字。
- 结构体的每个成员都称为**字段**。
- 结构体的每个字段都有自己的名字。
- 可见性按字段来管理：每个字段都可以独立地设为公开或私有。

## 定义和实例化结构体

要定义结构体，使用`struct`关键字，后面跟上名字以及一对花括号，花括号中写明各个字段的名字和类型：

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

要创建`struct`的实例，先写出`struct`的名字，再用一对花括号写上各个字段的键值对。
注意，创建实例时字段的顺序可以任意：

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## 与结构体实例交互

使用点号记法访问或修改`struct`实例的字段。
注意，要修改字段，实例必须是可变的：

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

和任何表达式一样，我们可以把新构造的`struct`实例作为函数体中的最后一个表达式，从而隐式返回这个新实例：

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## 字段初始化简写

在上一个例子中，把`email`和`username`这两个函数形参命名为与`struct`中字段相同的名字是合理的，但在给结构体字段赋值时还要把它们重复写一遍就有点繁琐了。
好在有一种便捷的简写方式，可以用同名的变量来初始化结构体字段：

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## 使用结构体更新语法从其他实例创建实例

使用结构体更新语法可以基于已有的实例创建新实例，只改动其中一些字段，其余字段保持不变。
这通过`..`运算符来实现。

不使用更新语法时：

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

使用更新语法时：

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

`..user1`语法会把`user1`中剩余的字段复制到`user2`。
注意，这会把数据从`user1`移动到`user2`，所以如果`user1`含有不可复制的类型，之后就不能再使用它了。
