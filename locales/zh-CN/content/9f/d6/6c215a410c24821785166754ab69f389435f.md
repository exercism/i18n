# 关于

[F#](https://try.fsharp.org/) 是一种强类型函数式语言，也是微软 .NET 语言体系的一部分。

虽然 F# 非常适合解决数据科学问题，但它也能优雅地处理你抛给它的几乎所有问题。

由于 F# 运行在 .NET 运行时之上，你可以使用整个 .NET 生态系统，包括 [nuget.org](https://www.nuget.org/) 上的所有包。

F# 还允许你编写面向对象的代码，因此与现有 .NET 代码的集成也变得更加简单。

F# 的主页是 [fsharp.org](http://fsharp.org/)，在 [F# for fun and profit](http://fsharpforfunandprofit.com/) 网站上可以找到很棒的 F# 入门介绍。
