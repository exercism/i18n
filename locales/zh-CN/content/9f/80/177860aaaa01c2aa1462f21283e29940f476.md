# 说明

你正在帮一位朋友根据他在花园各个角落记录的读数生成一份报告。
遗憾的是，你的朋友把数据存成了一种奇怪的格式。
每条读数都是一组用逗号分隔的字段。
不过，他把两位数拆到了两列中。

| 字段编号 | 含义 |
| --- | --- |
| 1 | ID 编号 |
| 2 | 位置 |
| 3 | 第一条读数，十位 |
| 4 | 第一条读数，个位 |
| 5 | 第二条读数，十位 |
| 6 | 第二条读数，个位 |

对于像`101,house,4,2,5,4`这样的输入行：
- 第一条读数是`42`，
- 第二条读数是`54`。

## 任务 1：生成报告

你的任务是求出这两条读数的平均值，并按以下格式输出每一行的结果

```none
#<id>, <label> = <average>
```

由于 42 和 54 的平均值是 48，示例行的输出应该是：

```none
#101, house = 48
```
