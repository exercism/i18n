# 说明

附近有一家叫“Tech Palace”的电器商店。
店主最近安装了一块大显示屏，用来播放营销消息，并在顾客在入口处扫描会员卡时显示一句特别问候。
这块显示屏由许多小 LED 灯组成，可以显示多行文字。

店主需要你帮忙编写用来为新显示屏生成文字的代码。

## 1. 创建欢迎消息

对于大多数扫描会员卡的顾客，店主希望在显示屏上看到`"Welcome to the Tech Palace,"`，后面跟着顾客姓名的大写形式。

实现函数`WelcomeMessage`，它接受顾客姓名作为`string`实参，并返回所需的消息，类型为`string`。

```go
WelcomeMessage("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 添加花哨的边框

对于在店里消费很多的忠实顾客，店主希望通过在欢迎消息前后各加一行星星，让欢迎消息的显示更花哨。
店主还不确定每行应该有多少颗星星，所以希望这个数量可以配置。

编写函数`AddBorder`，它接受一条欢迎消息（`string`）和每行星星的数量（类型`int`）作为实参。
它应返回一个`string`，由 3 行组成：一行包含所需数量的星星，接着是传入的欢迎消息，最后是另一行星星。

```go
AddBorder("Welcome!", 10)
```

应返回以下内容：

```text
**********
Welcome!
**********
```

## 3. 清理旧的营销消息

在安装这块新显示屏之前，店里有一块类似的显示屏，只能显示不可配置的静态文字行。
店主想在新显示屏上重复使用一些旧的营销消息。
不过，这些数据中已经包含了一圈星星边框和一些多余的空白字符。
你的任务是清理这些消息，让它们可以重新使用。

实现函数`CleanUpMessage`，它接受旧的营销消息作为字符串。
该函数应首先从文本中移除所有星星，然后从剩余的文本中移除开头和结尾的空白字符。
然后，该函数应返回清理后的消息。

```go
message := `
**************************
*    BUY NOW, SAVE 10%   *
**************************
`

CleanUpMessage(message)
// => BUY NOW, SAVE 10%
```
