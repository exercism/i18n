# 说明

在这个练习中，你将处理日志行。

每一行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志级别共有三种：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会给出一行日志，要求你对它做点什么。

## 1. 从日志行中获取消息

实现（_static_）`LogLevels.message()`方法，返回日志行中的消息：

```java
LogLevels.message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

首尾的空白字符都应该去掉：

```java
LogLevels.message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现（_static_）`LogLevels.logLevel()`方法，返回日志行的日志级别，并且要用小写字母返回：

```java
LogLevels.logLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 重新格式化日志行

实现（_static_）`LogLevels.reformat()`方法，重新格式化日志行：把消息放在前面，日志级别放在它后面的括号里：

```java
LogLevels.reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
