# 关于

有时一个函数要接受很多实参，很难记住它们应该按什么顺序传入。为了提高可读性，Gleam 允许给实参加上标签名。

要给实参加标签，把标签名写在实参名前面，中间用空格隔开。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

调用带标签实参的函数时，实参可以按任意顺序传入。下面这些对`replace`的调用都是等价的：

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

标签始终是可选的。即使一个函数有带标签实参，也仍然可以在调用时不加标签。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

定义带标签实参的函数时，第一个带标签实参之后的所有实参也都必须带标签。

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
