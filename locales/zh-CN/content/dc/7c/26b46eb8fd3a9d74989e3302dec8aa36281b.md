# 说明补充

## 测试

测试会并发执行一些操作。
你应该尽量确保对`Account`的操作始终让它保持一致的状态。
例如：多个 goroutine 可能同时存款和取款，而两笔同时进行的取款不应让余额变成负数。

在本地开发时，你可以用`-race`标志运行测试，来检验代码是否正确处理了并发、没有引入数据竞争。

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
