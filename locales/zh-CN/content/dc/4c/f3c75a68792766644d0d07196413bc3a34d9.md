# 简介

维基百科把`switch`语句描述为“一种选择控制机制，用来让变量或表达式的值改变程序的控制流”。

该机制涉及以下关键字：`switch`、`case`、`break`和`default`。

最简单的用法是检查一个基元类型或字符串表达式，并根据它的值做出判断。例如：

```csharp
string direction = GetDirection();
switch (direction)
{
    case "left":
        GoLeft();
        break;
    case "right":
        GoRight();
        break;
    default:
        MarkTime();
        break;
}
```

而在最复杂的用法中，会引入向下类型转换`case <Type> <variable>:`以及守卫条件（`when`）。

```csharp
Animal animal = GetAnimal();

switch (animal)
{
    case Dog canine:
    case Coyote canine:
        canine.Bark();
        break;
    case Cat cat when cat.HasOnly8Lives():
        cat.IsCareful();
        cat.Meow();
        break;
    case Cat cat:
        cat.Meow();
        break;
}
```
