# 安装

与许多其他语言不同，Pyret 不要求你在全局安装这门语言。Pyret 的开发者把编译器发布成了一个 [npm 包][pyret-npm]。你需要为每个练习使用`npm`安装 Pyret：[测试][tests]页面会有更多细节。

你需要安装 Node.js，一个 JavaScript 运行环境。在 [Node.js 下载][download] 页面上，请确保把包管理器选为`npm`。

~~~~exercism/note
目前，pyret-npm 包只兼容 Linux 和 MacOS。Windows 用户需要使用 WSL 或虚拟机来安装 pyret-npm。
~~~~

[pyret-npm]: https://www.npmjs.com/package/pyret-npm
