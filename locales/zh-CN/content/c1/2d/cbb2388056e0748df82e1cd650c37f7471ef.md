# 简介

## Random

在 Elm 这样的纯函数式语言中，用相同的实参调用同一个函数，必须始终返回相同的值。
因此，类型签名为`rand : Int`的函数只能实现为`rand = 4`，这对生成随机整数来说可不是个好兆头。

那么在 Elm 中，我们该如何生成随机的值呢？
把问题拆成两步：先用`Random.Generator a`描述想要生成的值，再生成一个值。

生成值的第一种方式，是用`initialSeed : Int -> Seed`创建一个`Random.Seed`，再使用`step : Generator a -> Seed -> ( a, Seed )`，它会返回一个值和一个新的种子。
注意，这两个函数都是纯函数，所以用相同的实参调用两次，会得到相同的值。

生成值的第二种方式是使用`generate : (a -> msg) -> Generator a -> Cmd msg`，但这只能在 Elm 应用内部进行。
这种情况下，Elm 运行时既可以使用`step`，也可以使用外部的、非纯的资源来生成种子。

接下来，我们只关注生成器。

为了演示示例，我们不妨假设：已经用`initialSeed`和`step`定义了一个函数`generate : Int -> Generator a -> List a`，它能从一个生成器生成若干个值。

`Random`模块提供了两个基础生成器，用于在特定范围内生成整数和浮点数：

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

这些值可以组合成元组，也可以组合成由值组成的数组：

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

`elm-community/random-extra`包提供了更多生成器，可用于各种数据结构：字符串、日期、字典、数组、集合等。

用`Random.constant`可以创建只返回单个值的生成器：

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

用`Random.uniform`可以从给定的元素中以相等的概率随机挑选：

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`接收两个实参（`Red`和`[Green, Blue]`），以保证至少有一个值可供挑选，因为单个数组有可能是空的。

还可以用`Random.weighted`调整概率：

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

这些值不需要加总为 100，它们反正会被重新归一化。

用`Random.map`可以触及生成器的内部：

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

还可以使用`Random.map2`一直到`Random.map5`来组合更多的生成器：

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

对于更复杂的用法，我们有`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，它可以用一个生成器生成的值来创建另一个生成器：

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

有时，把生成器定义为自递归的会很有用。
这种情况下，你可能需要用`Random.lazy`来防止编译器无限展开这个生成器。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

这个例子稍微有点复杂，我们来拆解一下。

`Peano`是一种表示正整数的类型：`Zero`是 0，`Next(Zero)`是 1，`Next(Next(Zero))`是 2，依此类推。
我们定义`peano`，用它得到一个随机的`Peano`数。

首先，注意`Random.lazy`并没有给逻辑增加任何东西，它只是防止编译器无限地把`peano`写进`peano`里。

我们用`Random.uniform`在零（概率 50%）和另一个`Peano`数加一（概率 50%）之间做选择。
不过，与前面的例子不同，这里`Random.uniform`挑选的不是值（比如`Zero`），而是生成器（比如`Random.constant Zero`），因为我们想用到`peano`本身。
这意味着`Random.uniform`会返回一个类型为`Generator (Generator Peano)`的值，而这并不是我们需要的。

要把这个生成器“压平”，我们把它通过管道传给`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，这里我们希望`b`是`Peano`。
由于`Generator a`就是`Generator (Generator Peano)`，`a`必须是`Generator Peano`，而函数`(a -> Generator b)`的类型必须是`(Generator Peano -> Generator Peano)`。
我们不想修改任何东西，所以`identity`是合适的选择。

最后，`peano`会生成什么样的数呢？
我们知道，它有 50% 的时间会生成 0，另外 50% 的时间会生成自身的又一次迭代加一。
也就是说，生成的数会是 0（50% 的时间）、1（25% 的时间）、2（12% 的时间）、3（6% 的时间），等等。
`peano`可以生成任意大的数，只是概率会呈指数级下降。
