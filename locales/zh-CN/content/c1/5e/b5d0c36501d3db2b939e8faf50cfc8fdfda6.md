# 简介

在 Common Lisp 中，时间有四种表示方式，本页会介绍其中两种。

- 通用时间是一种绝对时间，用一个整数表示自`1900-01-01T00:00:00Z`起经过的秒数（即 UTC 时间 1900 年 1 月 1 日的午夜）。
- 解码时间是由 9 个值组成的元组，它们共同表示一个具体的日历时间：秒、分钟、小时、日、月、年、星期、夏令时标志、时区。
（下文会详细讨论。）

## 通用时间

要获取当前的通用时间，可以使用`get-universal-time`或`get-decoded-time`。
前者返回自`1900-01-01T00:00Z`以来当前的秒数，后者则以解码格式返回同样的数据。

## 解码时间

`decode-universal-time`和`encode-universal-time`是处理时间的主要函数。
前者接收一个通用时间，并以[multiple-values][concept-multiple-values]的形式返回解码时间值；后者接收各个解码时间值作为实参，返回一个通用时间。

两者都接受一个可选的时区实参。
时区的格式见下文。

解码时间是一组值：

- *秒*：0 到 59 之间的整数
- *分钟*：0 到 59 之间的整数
- *小时*：0 到 23 之间的整数
- *日*：1 到 31 之间的整数（上限显然取决于月份和年份）
- *月*：1 到 12 之间的整数
- *年*：表示年份的整数。
- *星期*：0 到 6 之间的整数。0 表示星期一，1 表示星期二，依此类推……6 表示星期日。
- *夏令时标志*：值为 true 表示当前处于夏令时。
- *时区*：-24 到 24 之间的小时数，表示相对 UTC 的偏移量。
这个数是有理数，并且必须是`1/3600`的倍数。

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121)       ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800) ; => 0
                                   ;    0
                                   ;    0
                                   ;    1
                                   ;    1
                                   ;    1970
                                   ;    3
                                   ;    NIL
                                   ;    0
```
