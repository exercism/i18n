# 说明补充

## 排序包

这道练习要求你对数组排序，但标准库并没有内置排序功能。你当然可以自己写一个排序库，不过更好的做法是使用 [sorts 包](https://github.com/diku-dk/sorts)。

你可以在解答目录中运行以下命令，从而在自己的解答里使用这个包：

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

然后，通过下面的语句导入你[需要的排序算法](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts)：

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
