# 简介

可区分联合类型表示固定数量的具名案例。可区分联合的每个值都恰好对应其中一个具名案例。

可区分联合使用`type`关键字定义，各个案例之间用管道符（`|`）分隔：

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

可区分联合的每个案例都可以选择性地关联数据，而且不同案例可以关联不同类型的数据。如果所有案例都没有关联数据，那么这种可区分联合就类似于其他语言通常所说的_枚举_（或 _enum_）。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

要创建某个特定案例的值，可以引用它的名字（例如`Success`）。由于案例名本身就是构造函数，所以关联的数据可以像普通实参一样传入。如果另一个可区分联合已经定义了同名的案例，你就需要使用它的完整名称（例如`Result.Success`）。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

可区分联合具有_结构相等_，也就是说，同一案例、且（可选的）数据相同的两个值彼此等价。

虽然可以用`if/elif/else`表达式来处理可区分联合，但推荐的方式是使用_标识符模式_进行模式匹配：

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
