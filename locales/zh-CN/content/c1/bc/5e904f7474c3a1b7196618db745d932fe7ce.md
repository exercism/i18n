## 函数类型

前面我们已经见过函数签名是怎么定义的：先是一个函数名，接着是逗号分隔的形参标签及其类型，然后是`->`，最后是函数返回的值的类型。

如果把这个签名中的所有名字和标签都去掉，剩下的就是[函数的类型][function-types]。

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

注意前两个函数的类型是相同的，都是`(String, Int) -> String`，尽管这两个函数的工作方式差别很大。它们都接受一个`String`和一个`Int`作为输入，并返回一个`String`。从第三个函数的类型可以看出，虽然这个函数看起来什么都不返回，实际上它返回的是`()`，也就是类型`Void`唯一的值。注意`()`和`Void`作为类型名可以互换，所以`printString`的类型也可以写成`String) -> Void`。

这些类型可以像 Swift 中的其他任何类型一样使用，比如可以用在变量或常量的声明中。而且，由于函数在 Swift 中也是值，可以把已有的函数赋值给这些常量或变量：

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

与其他变量或常量一样，赋给它的值必须是正确的类型：

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## 函数类型作为形参类型

既然函数类型可以用在任何其他类型可以使用的地方，那么[它们也可以用作形参类型][functions-as-parameters]，传入其他函数，并在这些函数内部被调用。

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## 函数类型作为返回类型

同样地，[函数类型也可以用作函数的返回类型][functions-as-returns]。换句话说，你可以编写创建并返回其他函数的函数。在创建这类函数时，被返回的函数可以使用传入该函数的其他形参，也可以使用在父函数内部创建的局部变量。

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## 捕获值

如上面的`makeAdder(base:)`函数所示，嵌套函数可以访问外层函数的形参和变量。此外，在外层函数结束后，它们仍然能保持对这些值的访问。这种获取并保持访问的行为称为[_捕获_][capturing-values]。

## 高阶函数

接受函数作为形参和/或返回函数作为结果的函数称为高阶函数。Swift 的各个库中有许多高阶函数。例如，Swift 集合（如`Array`）上可用的`sorted(by:)`方法：对于一个元素类型为`T`的数组，它接受一个类型为`(T, T) -> Bool`的函数，这个函数决定在排序后的数组中两个值哪一个应该排在前面，如果左边的值应该排在前面就返回`true`，如果右边的值应该排在前面就返回`false`。

另一个例子是集合上的`contains(where:)`方法：对于一个元素类型为`T`的集合，它接受一个类型为`(T) -> Bool`的函数，如果元素满足某个属性该函数就返回`true`，否则返回`false`。如果集合中某个元素满足这个属性，`contains(where:)`就返回`true`。

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
