# 说明

在本练习中，你将处理日志行。

每一行日志都是一个字符串，格式如下：`"[<LVL>]: <MESSAGE>"`。

以下是各种日志级别：

- `TRC`（跟踪）
- `DBG`（调试）
- `INF`（信息）
- `WRN`（警告）
- `ERR`（错误）
- `FTL`（致命）

你有三个任务。

## 1. 解析日志级别

定义一个 `LogLevel` 枚举，其中包含六个元素，分别对应上面的日志级别。

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

接下来，实现 `LogLine.getLogLevel()` 方法，返回一行日志解析后的日志级别：

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. 支持未知日志级别

遗憾的是，有时某些日志行会带有未知的日志级别。
为了妥善处理这些日志行，请向 `LogLevel` 枚举中添加一个 `UNKNOWN` 元素，在解析到未知日志级别时应当返回它：

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. 将日志行转换为短格式

一行日志的日志级别相当冗长。
为减少存储日志行所需的磁盘空间，我们设计了一种短格式：`"[<ENCODED_LEVEL>]:<MESSAGE>"`。

编码后的日志级别就是日志级别到数字的简单映射：

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

实现 `LogLine.getOutputForShortLog()` 方法，它能够输出缩短后的日志行格式：

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
