# 简介

链接性描述的是代码中的某个标识符可以从哪里被访问。具有块作用域、函数作用域或函数原型作用域的值没有链接性，也就是说，无法从它们的作用域之外访问。关于作用域的更多内容，请参见[作用域概念](../scope/introduction.md#Introduction)。

## 外部链接性

具有文件作用域的标识符默认具有外部链接性。具有外部链接性的标识符可以在程序的任何文件中被调用。

## 内部链接性

使用`static`说明符，可以让具有文件作用域的标识符具有内部链接性。具有内部链接性的标识符只能在其所在的文件中使用。

例如

```c
int public_count = 0; // file scope, external linkage by default
static int private_count = 0;  // file scope, internal linkage 

// file scope, internal linkage
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
int main()
{
    // code snipped
}
```

静态链接性不应与静态存储期混淆。关于静态存储期的更多内容，请参见[存储期概念](https://github.com/exercism/c/blob/main/concepts/storage-class-specifiers/about.md#static-the-storage-specifier-not-to-be-confused-with-the-static-linkage-type)。
