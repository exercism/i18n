# 简介

## 模式匹配

`if/elif/else` 表达式可用于有条件地执行逻辑。F# 还有一种更强大的有条件执行逻辑的方式：模式匹配。通过模式匹配，可以用一个或多个*模式*来检验一个值。这种模式的一个例子是*常量模式*，它把值与一个常量进行匹配（例如`1`或`"hello"`）。

在 F# 中，模式匹配通过`match`关键字完成：

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

虽然这看起来像其他语言中的`switch`语句，但当同时使用其他模式时，模式匹配才开始大放异彩。其中一种模式是*变量模式*，它允许捕获一个值：

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

有时，你可能想给模式添加一个附加条件。这被称为*守卫*（子句），可以用`when`关键字添加：

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

在上面的例子中，并非所有可能的输入都有匹配的模式。编译器会检测到这一点并输出警告。这被称为*穷尽性检查*。要消除这个警告，就必须处理所有情况。为此，可以使用*通配符模式*，它能匹配任意值：

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

模式匹配会从上到下用每个模式检验一个值，直到找到匹配的模式，并执行与该模式关联的逻辑。模式的顺序很重要！
