# 简介

F# 的 `char` 类型是一个 16 位值，用来表示文本中最小的可寻址单位，默认不可变。

`char`可以用单引号定义为字面量：

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

字符串就是一串字符。

通过从 0 开始的下标，可以从字符串中取出单个`char`：

```fsharp
"Exercism"[4] //  =>  'c'
```

遍历字符串时，每一步都会返回一个`char`。

下一个例子为了简便，用到了高阶函数和匿名函数。
教学大纲后面会详细介绍它们，现在你只需要知道，它们本质上是一种简洁的写法，用来遍历字符串中的字符。

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

如上所示，`char`可以转换成它的`int`值。
这对其他文字（*至少在有些情况下*）也成立：

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

比较字符时，用的是底层的 Int16：

```fsharp
'A' < 'D'  // =>  true
```

反过来，`int`也可以转换成`char`：

```fsharp
char 77  // => 'M'
```

`System.Char` 库包含了 .NET 语言应有的全套方法，比如大小写转换：

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
