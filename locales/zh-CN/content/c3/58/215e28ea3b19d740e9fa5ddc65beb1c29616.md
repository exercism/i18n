# 测试

## 运行测试

1. 获取一个练习：

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. 进入练习所在目录：

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. 运行测试：

    ```bash
    $ ./gradlew test
    ```

大多数练习默认只运行第一个测试。  
其余测试都标注了`@Ignore`，会被跳过。  
每通过一个测试，就删掉下一个测试上的`@Ignore`，继续往下做。

这是测试驱动开发（简称 TDD）中的常见做法。这样做是为了确保你一次只专注解决一个问题。
