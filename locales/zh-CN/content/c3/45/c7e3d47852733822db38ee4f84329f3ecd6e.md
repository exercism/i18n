# 简介

大多数情况下，Factor 通过像`each`、`map`和`count`这样的组合子来处理迭代。不过，有时描述一个计算最简洁的方式是**递归**，也就是一个调用自身的词。

## 定义递归词

一个 `:` 定义可以直接调用自身：

```factor
: count-down ( n -- )
    dup 0 = [ drop ] [ dup . 1 - count-down ] if ;

5 count-down
! prints 5 4 3 2 1
```

## 空与非空分支

`if-empty`（位于[`sequences`][sequences]中）是天然的递归基准情形：

```
if-empty ( seq emptyquot nonemptyquot -- )
```

```factor
{ 4 0 9 } [ "empty" ] [ "got data" ] if-empty .
! => "got data"
```

`emptyquot` 运行时，序列（此时为空）已经被消耗掉；`nonemptyquot` 运行时，序列仍在栈上。

## `cond`：一串带守卫的分支

当递归有两个以上的情形时，`cond`（位于[`combinators`][combinators]中）能让代码保持易读：

```factor
: classify ( n -- label )
    {
        { [ dup 0 < ] [ drop "negative" ] }
        { [ dup 0 = ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```

## 用 `DEFER:` 进行前向引用

一个 `:` 定义可以直接调用自身，但当两个词*互相*调用时，解析器会在第二个词存在之前先看到第一个词。`DEFER:` 会预留一个名字，好让第一个定义能够编译：

```factor
DEFER: even?

: odd? ( n -- ? ) dup 0 = [ drop f ] [ 1 - even? ] if ;
: even? ( n -- ? ) dup 0 = [ drop t ] [ 1 - odd? ] if ;
```

当某个辅助词更自然地在使用它的词*之后*阅读时，`DEFER:` 也很有用。
