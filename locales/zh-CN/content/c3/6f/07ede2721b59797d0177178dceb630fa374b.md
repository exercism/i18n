# 安装

## 安装 Clojure CLI
Clojure 提供了一些命令行工具，可以用来启动 Clojure REPL、使用 Clojure 和 Java 库，以及启动 Clojure 程序。

如果你需要安装 Java，我们推荐 [Adoptium Temurin 17](https://adoptium.net/)。

### Linux
请确保已安装以下依赖：`bash`、`curl`、`rlwrap` 和 `Java`。
你可以通过以下两种方式安装 Clojure：

1. LinuxBrew，需要 [Homebrew](https://brew.sh/)

```bash
brew install clojure/tools/clojure
```

2. 脚本安装程序

```bash
curl -O https://download.clojure.org/install/linux-install-1.11.1.1347.sh
chmod +x linux-install-1.11.1.1347.sh
sudo ./linux-install-1.11.1.1347.sh
```

### 在 Mac OS X 上使用 Homebrew
通过 [clojure/tools](https://github.com/clojure/homebrew-tools) tap，用 brew 安装命令行工具：

```bash
brew install clojure/tools/clojure
```

#### Java

任何 Java 发行版都可以。如有需要，你可以用 brew 安装 Temurin：

```bash
brew tap homebrew/cask-versions
brew install --cask temurin17
```

### Windows

最近，Windows 上的 Clojure 有了显著改进。我们过去推荐使用 WSL2，它工作得很好，
但现在已经有了 PowerShell 安装程序。Windows 上的 Clojure 目前处于 alpha 阶段，已知问题请参阅 [clj-on-windows](https://github.com/clojure/tools.deps.alpha/wiki/clj-on-Windows#known-issues)。

请确保已安装 Java，并已设置 `JAVA_HOME` 环境变量，然后运行：

```powershell
iwr -useb download.clojure.org/install/win-install-1.11.1.1165.ps1 | iex
```

在 Windows 上安装 Clojure 的另一种方式是使用 [Scoop](https://scoop.sh/) 包管理器。要安装 Scoop，请打开 PowerShell，依次运行以下两条命令：

 ```sh
 iwr -useb get.scoop.sh | iex
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force
```

要用 Scoop 安装 Clojure，你需要先添加两个重要的 bucket：

```sh
# if you don't have git version control system installed
# it is required for adding new external buckets to your scoop installer
# you can skip this step otherwise
scoop install git

# add scoop bucket for Java 
scoop bucket add java

# add scoop bucket for clojure build
scoop bucket add scoop-clojure https://github.com/littleli/scoop-clojure
```

现在可以运行以下命令来安装 Java 和 Clojure 了：

```sh
# install Java runtime and compiler
scoop install adoptopenjdk-lts-hotspot

# install official clojure tools
scoop install clojure

# update to the newest version
scoop update clojure
```

成功执行以上步骤后，你应该可以通过以下命令运行 Clojure：

```sh
clj
```

## 安装 Leiningen（可选）

虽然已不再是必需的，但我们仍然支持功能齐全的项目管理工具 [Leiningen](https://leiningen.org/)。
它提供了各种实用的任务，例如便捷的测试、构建，以及更好的 REPL。

1. 下载 [lein 脚本](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein) 或 [lein.bat](https://raw.githubusercontent.com/technomancy/leiningen/stable/bin/lein.bat)（Windows）
2. 把它放到你的 `$PATH` 中，让 shell 能找到它（例如 `/usr/local/bin/`）
3. 将其设置为可执行（`sudo chmod a+x /usr/local/bin/lein`）
4. 运行 `lein`。
