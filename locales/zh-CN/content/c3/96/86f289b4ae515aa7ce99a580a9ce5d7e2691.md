# 说明

将一个用某一进制的一串数字表示的数，转换为任意其他进制。

实现通用的进制转换。给定一个**a**进制的数，用一串数字表示，把它转换为**b**进制。

## 注意

- 试着自己实现这个转换，不要借助其他东西替你完成。

## 关于[位值制](https://en.wikipedia.org/wiki/Positional_notation)

在位值制中，一个**b**进制的数可以理解为**b**的各次幂的线性组合。

数字 42，*在十进制中*，表示：

(4 * 10^1) + (2 * 10^0)

数字 101010，*在二进制中*，表示：

(1 * 2^5) + (0 * 2^4) + (1 * 2^3) + (0 * 2^2) + (1 * 2^1) + (0 * 2^0)

数字 1120，*在三进制中*，表示：

(1 * 3^3) + (1 * 3^2) + (2 * 3^1) + (0 * 3^0)

我想你已经明白是怎么回事了！

*没错。上面这三个数完全相等。恭喜！*
