# 简介

Lambda 类汇集了一组函数式方法，让你可以在 Haxe 中使用函数式风格的编程。有了它，我们可以一次性操作整个 Iterable。相比循环，这种做法通常更可取，因为不容易出错，也更易读。为了方便，Array 和 List 类也包含了一些 Lambda 类中常用的方法。

`Lambda` 类的一些函数包括：

- `Lambda.array`、`Lambda.list`将 Iterable 转换为 Array 或 List。它总是返回一个新实例。
- `Lambda.count`统计元素的数量。如果 Iterable 是 Array 或 List，使用它的 length 属性会更快。
- `Lambda.has`判断指定的元素是否在 Iterable 中。
- `Lambda.indexOf`查找指定元素的下标。
- `Lambda.find`根据给定的搜索函数找到第一个元素。
- `Lambda.concat`合并两个 Iterable，返回一个新的 List。
- `Lambda.filter`找出满足条件的元素，并返回一个新的 List。

下面这个例子演示了其中一些函数：

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
