# 整数

整数是不带小数部分的数，属于集合`{..., -2, -1, 0, 1, 2, ...}`。
整数的最大值和最小值由 PHP 运行所在的系统决定。
在大多数现代系统上，整数通常是 64 位值，也就是说它能表示从 `-9_223_372_036_854_775_808` 到 `9_223_372_036_854_775_807`（含两端）的值。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

除了十进制，你还可以用进制前缀来写整数字面量：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
