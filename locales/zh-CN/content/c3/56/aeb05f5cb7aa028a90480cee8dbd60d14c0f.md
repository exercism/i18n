# 测试

## 快速上手

- 进入题目所在的目录（例如`~/Exercism/hello-world`）。
- 在终端中启动一个`jconsole`会话。
- 加载你的解答文件（例如`load 'hello-world.ijs'`）。
- 输入`load  'general/unittest'`，加载单元测试框架。
- 输入`unittest 'test.ijs'`，测试你的解答。
<br></br>
- 也可以像这样用一行命令运行测试：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## jconsole 会话

我们希望这些测试的搭建方式尽可能简单。
如果你正在做一道练习，比如`hamming.ijs`，整个流程大致如下。
编辑`hamming.ijs`，写出你的解答。
先输入下面的命令，以交互方式逐步构建。

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

然后在 J 控制台中输入以下命令重新加载。

```j
load 'hamming.ijs'
```

接下来，输入以下命令加载单元测试框架。

```j
load 'general/unittest'
```

加载完解答后，输入以下命令即可运行测试。

```j
unittest 'test.ijs'
```

然后观察测试结果。

## 命令行

你也可以在终端里用 -js 标志，以一行命令运行测试：

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
其中每个参数代表一条将按顺序执行的命令。
