# 说明

你即将编写一些代码，用来管理一份要学习的编程语言清单。这份清单会存放在名为`@LanguageList::Languages`的数组中。

## 1. 向 @Languages 数组添加一门语言

修改 `LanguageList::add_language` 子程序，它接收一个语言名称作为实参，把该语言添加到`@LanguageList::Languages`数组的末尾。

## 2. 从 @Languages 数组中移除一门语言

修改 `LanguageList::remove_language` 子程序，把最后一门语言从`@LanguageList::Languages`数组中移除。

## 3. 获取 @Languages 数组中的第一门语言

修改 `LanguageList::first_language` 子程序，让它返回`@LanguageList::Languages`数组中的第一门语言。

## 4. 获取 @Languages 数组中的最后一门语言

修改 `LanguageList::last_language` 子程序，让它返回`@LanguageList::Languages`数组中的最后一门语言。

## 5. 从 @Languages 数组中获取一段切片

修改 `LanguageList::get_languages` 子程序，它接收一个数字数组，表示想要获取的元素，返回`@LanguageList::Languages`数组的一个切片。

## 6. 检查 @Languages 数组中是否存在某门语言

修改 `LanguageList::has_language` 子程序，它接收一个语言名称作为实参，返回 true 或 false，表示该语言是否存在于`@LanguageList::Languages`数组中。
