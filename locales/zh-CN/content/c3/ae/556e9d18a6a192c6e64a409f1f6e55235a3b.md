# 说明

一家制造商可以生产两种不同类型的电机；下文把这两种电机分别称为电机 A 和电机 B。两种电机的生产都需要 3 个环节：绕线、钻孔和装配。每种电机在每个环节所需的时间各不相同。一般来说，生产一台电机 A 需要 t_a_1 小时绕线、t_a_2 小时钻孔、t_a_3 小时装配。而生产一台电机 B 需要 t_b_1 小时绕线、t_b_2 小时钻孔、t_b_3 小时装配。实现一个函数：给定每个生产环节分配的总小时数（t_1 小时用于绕线、t_2 小时用于钻孔、t_3 小时用于装配）以及每种电机的价格（p_a、p_b），计算出能让利润最大化的电机 A 和电机 B 的最优产量。

该函数共有 4 个输入参数，具体如下：

1. a_hours：(t_a_1, t_a_2, t_a_3) 三元组，单位为小时
2. b_hours：(t_b_1, t_b_2, t_b_3) 三元组，单位为小时
3. total_hours：(t_1, t_2, t_3) 三元组，单位为小时
4. prices：(p_a, p_b) 二元组，单位为美元

输出应该是一个三元组 (q_a, q_b, profit)，其中：

1. q_a：电机 A 的最优产量
2. q_b：电机 B 的最优产量
3. profit：最大化的利润值，单位为美元

其他需要注意的重要事项：

q_a 和 q_b 不能是浮点数，因为电机无法只生产一部分。在输出之前，需要把 Z3 模型对变量给出的结果转换为整数。如果 Z3 模型结果的类型是`IntNumRef`，可以使用`as_long()`类方法将其转换为整数。如果由于输入无效而导致问题无解，则抛出 Python 内置异常`ArithmeticError()`。
