# 数组

**数组**按顺序存放一排值，这些值的类型都相同。

类型写作 `ARRAY{T}`，其中 `T` 表示数组存放的内容。字符串数组是 `ARRAY{STR}`，整数数组是 `ARRAY{INT}`。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

两个 `|` 之间的值就是**数组字面量**。Sather 会根据值的个数算出数组的大小。

## 取出一个值

方括号里写的是位置：

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

计数从**零**开始，而不是从一。所以第一个值在 `0`，3 个值里最后一个在 `2`。

## 有多少个？

`.size` 表示数组里有多少个值。

```sather
row.size    -- 3
```

因为计数从零开始，最后一个位置总是 `.size - 1`：

```sather
row[row.size - 1]     -- "Ben"
```

要取一个不存在的位置，比如 `row[3]` 或 `row[-1]`，Sather 不会替你发现这是错的，所以最好写 `.size - 1`，而不是用眼睛去数。

## 遍历数组

数组和循环总是一起用。用一个变量逐个走过每个位置，再用它取到对应的值：

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
