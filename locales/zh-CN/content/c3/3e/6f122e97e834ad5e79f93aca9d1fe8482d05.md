# 占位符

## `jq`技巧

这道练习要做的是接收一个输入对象，再把它转换成一个新的对象。
下面这几个内置函数可能会帮上忙：

- [`to_entries`][x_entries]
  - 这个函数接收一个对象作为输入
  - 它输出的是一个_数组_，每个数组元素都是一个对象`{"key": "K", "value": V}`
    - 每个`K`都是输入对象中的一个键
    - 每个`V`都是`K`对应的值。
- [`from_entries`][x_entries]
  - 相反的操作
  - 接收一个由`{"key": K, "value": V}`对象组成的数组，构造出一个对象

举个例子：

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

输出为

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
