# 介绍

当自定义类型的变体保存数据时，该变体就称为记录，其中包含的每个值都存放在一个_字段_中。

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

为了方便阅读，Gleam 允许给字段标注名称。

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

使用标签，可以按任意顺序向记录的构造函数传入实参。

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

当自定义类型只有一个变体时，可以用`.label`访问器语法来获取记录的字段。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

当自定义类型只有一个变体时，可以用记录更新语法从已有的记录创建一条新记录，只是其中部分字段会被替换成新的值。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

在模式匹配时，也可以用标签来从记录中提取值。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h > 20.0 -> True
    _ -> False
  }
}
```

如果我们只想匹配部分字段，可以用展开运算符`..`来忽略剩余的字段。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
