# 说明

在这个练习中，你将处理储蓄账户。每年，你的储蓄账户余额都会根据其利率进行更新。银行给你的利率取决于你账户里的金额（也就是余额）：

- 余额为负时是 3.213%（会产生负利息）。
- 余额为正且小于`1000`美元时是 0.5%。
- 余额为正、大于或等于`1000`美元且小于`5000`美元时是 1.621%。
- 余额为正且大于或等于`5000`美元时是 2.475%。

每年，政府允许你把一定比例的钱免税捐给慈善机构。因为你是个好人，如果年底时你的余额为正，你会把免税比例翻倍，并向下取整到最接近的整数美元。你不介意就捐款的后一半缴税。

你有三个任务，每个任务都涉及你的余额和它的利率。

## 1. 计算利率

实现`interestRate`函数，根据指定的余额计算利率：

```fsharp
interestRate 200.75m
// => 0.5f
```

注意，返回的值是 `single`。

## 2. 计算利息

实现`interest`方法，根据指定的余额计算利息：

```fsharp
interest 200.75m
// => 1.00375m
```

注意，返回的值是 `decimal`。

## 3. 计算年度余额更新

实现`annualBalanceUpdate`函数，计算年度余额更新，并考虑利率：

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

注意，返回的值是 `decimal`。

## 4. 计算捐款金额

实现`amountToDonate`函数，根据余额和政府允许的免税比例，计算向慈善机构捐款的金额：

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

注意，返回的值是 `int`。
