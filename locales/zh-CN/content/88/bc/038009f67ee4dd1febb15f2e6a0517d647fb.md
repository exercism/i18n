# 排序

把东西排好序是再常见不过的需求，库会替你完成。

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort`能处理任何已经知道如何比较自身的东西。数字和字符串都可以，因为它们有`is_lt`。

## 按自己的规则排序

大多数排序规则都不是内置的那一种。无板篮球的积分榜既不是按字母顺序，也不是按名字长短排的：它先按积分，积分相同的队伍再按净胜分。`ARRAY`没法猜到这一点。

所以你要把排序规则作为绑定例程传进去：

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by`接收一个`ROUT{T,T}:BOOL`，也就是一个例程：它接收两个待排序的元素，回答第一个是否应排在第二个前面。它会按需调用这个例程，然后按照这些回答所暗示的顺序排列数组。

这正是`understudy`的用途。库只知道如何排序，对你的排序规则一无所知；绑定例程就是两者交汇的地方。

## 编写比较

当第一个实参应排在前面时，例程回答 **true**。

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

如果规则不止一个部分，就按重要程度依次处理：

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

只要积分不同，第一个`if`就能定下来。只有当积分相同时，第二行才有发言权。如果把打破平局的判断放在前面，积分就永远不起作用了。

## 排序会改变数组

`insertion_sort_by`会就地把数组排好序，不返回任何东西：

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

如果原始顺序很重要，就对副本排序：

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
