# 简介

C# 中最主要的面向对象结构是_类_，它由数据（_字段_）和行为（_方法_）组合而成。类的字段和方法统称为它的_成员_。

可以通过访问修饰符限制对成员的访问，最常见的两种是：

- `public`：任何代码都能访问该成员（没有限制）。
- `private`：只有同一个类中的代码才能访问该成员。

可以把类看作创建该类实例的模板。创建类的实例（也叫_对象_）要使用`new`关键字：

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

字段有类型，可以定义在类中的任何位置。公共字段使用 PascalCase 命名，私有字段使用 camelCase 命名，并以`_`作为前缀：

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

你可以选择给字段赋一个初始值。如果字段_没有_指定初始值，就会被设置为其类型的默认值。实例的字段值可以通过点号表示法读取和更新。

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

私有字段通常作为调用方法的副作用被更新。这类方法一般不会返回任何值，此时返回类型应当写成`void`：

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
