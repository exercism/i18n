# 简介

Factor 中的字符是整数，也就是 Unicode 码点，因此 `<`、`>`、`=` 这些数值比较可以直接给出区分大小写的顺序。[`unicode`][unicode] 词汇表则加入了能识别 Unicode 的谓词，以及单个字符的大小写转换。

## 字符谓词

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## 大小写转换

`ch>upper`和`ch>lower`用来转换单个字符的大小写。字符串层面的`>upper`和`>lower`则会把它们应用到字符串中的每一个字符上。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
