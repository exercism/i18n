# 简介

## 正则表达式

Gleam 中的正则表达式遵循 **PCRE** 规范（**P**erl **C**ompatible **R**egular **E**xpressions），与 Java、JavaScript 或 Ruby 等其他常用语言类似。

`gleam_regexp` 包中的`gleam/regexp`模块提供了处理正则表达式的函数。

~~~~exercism/note
本练习假设你已经了解正则表达式的语法，包括字符类、量词、分组和捕获。

如果你需要复习正则表达式的知识，可以看看下面这些资料：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

创建正则表达式最常见的方式是使用`regexp.from_string`函数。

```gleam
let assert Ok(re) = regexp.from_string("test")
```

如果正则表达式的语法无效，创建正则表达式的函数会返回一个错误，所以这里使用了 let assert 断言来确保正则表达式是有效的。

`regexp.check`函数可以用来检查正则表达式是否匹配一个字符串。

```gleam
let assert Ok(re) = regexp.from_string("test")

regexp.check(re, "this is a test")
// -> True

regexp.check(re, "this is too")
// -> False
```


### 捕获

如果你想用正则表达式捕获子字符串，可以使用`regexp.scan`函数返回一个匹配结果的数组。

```gleam
let assert Ok(re) = regexp.from_string("[oi]n a (\\w+)")
regexp.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

### 修饰符

使用`regexp.compile`函数创建正则表达式并传入选项，就可以修改它的行为。

```gleam
let options = regexp.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regexp.compile("[A-Z]", with: options)
regexp.check(re, "abc123")
// -> True
```
