# 简介

## 包与模块

### 导入

模块通常使用`use`关键字加载。
这会加载该模块，并调用它的`import`方法，导入所有已导出的符号。

包的`@EXPORT`数组中的符号默认会被导入。
包的`@EXPORT_OK`数组中的符号必须显式导入。

### 导出

一个符号要被导入，必须先被导出。
[Exporter][Exporter] 模块随 Perl 一起提供，是最方便的导出方案之一。

定义模块：
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

使用模块：
```perl
use Foo ('bar');

bar();
```

### 核心模块

除了 [Exporter][Exporter]，Perl 还提供了大量可用的[核心模块][perl-core-modules]。
其中一些例子对你在这里可能遇到的练习很有用，包括 [List::Util][List::Util]、[Time::Piece][Time::Piece] 和 [Math::BigRat][Math::BigRat]。

### CPAN

除了核心模块，[CPAN][metacpan] 还拥有数以千计由 Perl 社区创建的额外模块，可供安装。
Perl 轨道使用 [cpanfile][test-runner-cpanfile] 来安装一组模块，这些模块可与 Exercism 的 Perl 测试运行器配合使用。
