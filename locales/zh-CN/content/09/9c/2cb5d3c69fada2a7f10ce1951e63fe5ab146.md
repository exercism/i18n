不过事情有点乱：Aazra 的坐标格式和排序方式似乎与 Rui 的不一样，他们得不停地从一份清单看到另一份清单，才能弄清哪些宝物对应哪些地点。作为初出茅庐的 Gleamlin，他们来找你帮忙写一个小程序（其实是一组函数），好把寻宝信息整理得更清楚。

## 1. 转换位置

实现`place_location_to_treasure_location`函数，它接收一个地点位置（例如`#("C", 1)`），并把它转换成宝物位置（例如`#(1, "C")`）。

```gleam
place_location_to_treasure_location(#("C", 1))
// -> #(1, "C")
```

## 2. 比较宝物位置和地点位置

实现`treasure_location_matches_place_location`函数，它接收一个地点位置（例如`#("C", 1)`），如果它与某个宝物位置（例如`#(1, "C")`）匹配，就返回`True`。

```gleam
treasure_location_matches_place_location(#("C", 1), #(1, "C"))
// -> True

treasure_location_matches_place_location(#("C", 1), #(2, "C"))
// -> False
```

## 3. 统计宝物位置

实现`count_place_treasures`函数，它接收一个地点（例如`#("Aqua Lagoon (Island of Mystery)", #("F", 1))`）和宝物数组，并返回在该地点能找到的宝物数量。

```gleam
let place = #("Aqua Lagoon (Island of Mystery)", #("F", 1))

count_place_treasures(place, treasures)
// -> 2
```

## 4. 特殊地点

实现`special_case_swap_possible`函数，它接收一个宝物（例如`#("Amethyst Octopus", #(1, "F"))`）、一个地点（例如`#("Seaside Cottages", #("C", 1))`）和一个想要的宝物（例如`#("Crystal Crab", #(6, "A"))`），并对以下组合返回`True`：

- Brass Spyglass 可以在 Abandoned Lighthouse 换成任何其他宝物。
- Amethyst Octopus 可以在 Stormy Breakwater 换成 Crystal Crab 或 Glass Starfish。
- Vintage Pirate Hat 可以在 Harbor Managers Office 换成 Model Ship in Large Bottle 或 Antique Glass Fishnet Float。
