# 提示

## 通用

- `plot`元组、`registrations`和`next-id`符号，以及`not-found`符号都已在练习文件中声明。
- 对于模块级状态，使用`set-global`、`get-global`和`change-global`。

## 1. 打开花园并列出其中的注册信息

- `V{ } clone`是`registrations`合适的初始值（始终要`clone`，这样字面量不会在多次调用之间共享）。
- `1 next-id set-global`设置计数器。
- 对于`list-registrations`，一次`registrations get-global`就够了。

## 2. 注册地块

- 先读取`next-id`，然后用`plot boa`根据`id`和`name`构建地块。
- 用`next-id [ 1 + ] change-global`增加计数器的值。
- `push`（在[`sequences`][sequences]中）会就地追加到向量，非常适合用于`registrations get-global`。

## 3. 释放地块

- `:: release ( id -- )`会让`id`在筛选谓词内部可用。
- `[ id>> id = ] reject`会保留所有`id`槽位与局部`id`*不*匹配的地块。把它用作`change-global`的主体。

## 4. 获取已注册的地块

- `find`返回`( index elt/f )`。`nip`会丢弃下标。
- 当没有找到任何内容时，`[ not-found ] unless*`会代入该符号。

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
