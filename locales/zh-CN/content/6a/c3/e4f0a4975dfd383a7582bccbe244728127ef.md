# 说明

调用 API 时，如果使用原始文本或 JSON，很容易出错。在本练习中，你将使用 Ballerina 记录来组织请求负载，并确保与外部预订端点成功通信。

## 目标

- 修改提供的代码。
- 通过调用航空预订服务为用户预订机票。向 airlineReservationService 发送带有合适负载的 POST 请求，并获取响应。
- 通过调用酒店预订服务为用户预订酒店房间。向 hotelReservationService 发送带有合适负载的 POST 请求，并获取响应。
- 通过调用租车服务为用户租车。向 carRentalService 发送带有合适负载的 POST 请求，并检查响应。
- 如果一切顺利，返回一个响应体，其中 message 属性的值为 “Congratulations! Your journey is ready!!”。
