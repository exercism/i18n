# 说明附录

## 实现

在 twobucket 包中，实现一个名为 Solve 的 Go func，签名如下：

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve 返回四个值：存放目标水量的那个桶（“one”或“two”）、达到目标水量所需的移动步数、另一个桶中剩余的水量，以及一个错误值。
只要有任何参数无效，或者无法求出解，就返回一个错误。
