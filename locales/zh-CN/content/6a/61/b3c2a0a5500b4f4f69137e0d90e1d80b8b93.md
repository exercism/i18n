安装
====

要用 YAMLScript 编写程序，你需要安装 YAMLScript 命令行解释器。这是一个名为`ys`的二进制可执行文件。它目前支持以下平台：

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> 注意：Windows 支持已在计划中，但目前尚不可用。

发行版[可在 GitHub 上获取](http://github.com/yaml/yamlscript/releases)。


## 自动安装

要完成 Exercism 的 YAMLScript 练习，你需要反复修改你的解答程序，并运行`make test`，直到所有测试都通过。

就这样！

第一次运行`make test`时，它会尝试在`/path/to/exercism/yamlscript/.local/`目录中，安装该练习所需的特定版本的`ys`解释器。

如果你已经在`PATH`中的某个位置安装了该版本的`ys`，它会静默地把`ys`解释器复制到正确的位置。

如果没有，它会提示你进行二进制发行版安装，这通常只需要几秒钟。

如果这一步失败（很少见，但偶尔会发生），它会提示你从源码进行自动构建，这可能需要几分钟（但非常可靠，而且不需要任何交互）。

只有在第一次运行`make test`时，你才会遇到这种情况。所有设定为使用同一版本`ys`的练习，都会共用同一份安装。

> 注意：你也可以在`make test`之外，单独使用`make install-ys`命令。它会执行与`make test`完全相同的安装过程，只是之后不会运行测试。


有关安装 YAMLScript 的更多信息，尤其是在 Exercism 之外使用它时，请参阅 [YAMLScript 安装文档](https://yamlscript.org/doc/install/)。
