# 说明

在这个练习中，你将进一步研究遥控车。

一款实验车已经开发出来，测试赛道也需要改造，以便同时容纳量产车和实验车型。这两种车都已经造好，你需要找到一种方法，让它们都能在同一条测试赛道上运行。

此外，量产车开始取得一些成绩。车队老板希望通过公布量产车的排名来保持竞争氛围。

## 1. 让小车能在同一条测试赛道上行驶

请为`IRemoteControlCar`接口添加一个方法，用来暴露两种车型的`Drive()`实现。

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. 让测试赛道上不同车型行驶的距离可以相互比较

请为`IRemoteControlCar`接口添加一个属性，用来暴露两种车型的`DistanceTravelled`属性的实现。

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. 让量产车可以参与排名

请在`ProductionRemoteControlCar`类中实现`IComparable<T>`接口。小车的默认排序顺序应当是按获胜次数升序排列。

实现静态方法`TestTrack.GetRankedCars()`，返回传入的小车，并按获胜次数升序排列。

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
