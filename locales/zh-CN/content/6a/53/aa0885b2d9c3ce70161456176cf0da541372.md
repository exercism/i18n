# 并行字母频率的概念

这个练习有非常多的可能解法，还可以配合外部 crate 来完成。为了让工作量保持在可控范围内，本文只选取了其中一小部分可能方案。Crossbeam 的解法涉及的概念与这里列出的类似，而 Rayon 只需要其中的一个子集。

## 通用说明

- 字符串：具体来说，这里始终会涉及 `str`
- Unicode：ASCII 方法与 Unicode 方法在性能/功能上的取舍。如果基准测试使用 Unicode 方法，而解法使用 ASCII 方法，基准结果就会有偏差。
- 迭代器：遍历输入，或遍历其中的分块。
- 集合：遍历 `HashMap` 并使用 `Entry`。通常会把句柄收集到 `Vec` 中。
- 引用
- 数字：具体指 `Add` trait
- `for`循环：由于 `move`，无法在迭代器中汇合线程。
- **可选**可见性：让实现细节保持非公开
- **可选**切片：`.chunks()`是拆分输入、分给工作线程的常用方法。也可以改用子切片。
- **可选**高阶函数：可以借助迭代器，用高阶函数把这些 HashMap 合并起来。
- **可选**类型：在拆分输入时，可以把整数转换为浮点值，以便取整
- **可选** crate

## 标准库方案（带或不带通道）

- 并行：子话题是创建/汇合线程。
- 迭代器：子话题是惰性求值：用同一个迭代器创建并汇合线程，就无法并行。
- 生命周期：子话题是`'static lifetime`和显式的`move`语义
- 迭代器/生命周期：子话题是消耗型迭代器：无法用迭代器汇合线程。
- `Option`类型：对线程或通道的结果做解包
- 函数：具体来说，创建线程需要用到高阶函数。闭包在这里也可以。

## 标准库方案（带通道）

- 并行：子话题是通道。
- 元组：`mpsc::channel()`返回一个元组
- 解构：元组可以在赋值时解构
- 生命周期：`drop()`

## 使用共享变量的另一种方案

- 引用计数：用带引用计数的集合在线程之间共享聚合数据。
- **值得一提**：并行，子话题是 Mutex。对本练习来说并非必需，也没什么用处，但仍是一个常见概念。相关：`RwLock`。

### 使用通道的标准库示例

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### 使用 Arc 的 crate 示例

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
