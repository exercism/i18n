# 循环

Rust 中的循环可以用来反复执行一个代码块，直到你让它停止，或者满足某个条件。

最基本的循环使用`loop`关键字：

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

上面的代码片段会构成一个无限循环。要退出循环，可以使用 break 关键字：

```rust
fn main() {
    let mut count = 0;
    loop {
        println!("again!");
        count += 1;
        if count > 10 { break; }
    }
}
```

## 使用`for`和`while`的循环

除了`loop`关键字，你还可以用`for`和`while`来创建循环。

`for`循环用于迭代集合或迭代器中的元素。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];

    for x in a {
        println!("the value is: {x}");
    }
}
```

范围本身也是迭代器，因此用`for`循环遍历它们非常方便：

```rust
fn main() {
    for x in 0..10 {
        println!("the value is: {x}");
    }
}
```

`while`循环会不断重复代码，直到满足某个条件。我们可以用`while`循环把前面的例子改写成这样：

```rust
fn main() {
    let a = [10, 20, 30, 40, 50];
    let mut index = 0;

    while index < 5 {
        println!("the value is: {}", a[index]);

        index += 1;
    }
}
```

关于循环的更多信息，请参见 Rust 书籍中的 [https://doc.rust-lang.org/book/ch03-05-control-flow.html#repetition-with-loops](repetition with loops)。
