# 行为准则

## 引言

Exercism 是一个围绕共情式交流构建的平台。我们对任何让人感到不受欢迎、得不到支持、受到侮辱或遭到歧视的交流，容忍度都极低。

## 看到或遇到了让你不舒服的事？

如果你看到或遭遇虐待、骚扰、歧视，或者感到不安全、感到不安，请发送邮件至 abuse@exercism.org。我们会认真对待你的举报。

## 执行

我们主动监督违反行为准则（CoC）的行为，并极其严肃地对待所有违规举报。我们曾因违规而封禁贡献者、导师和用户。

收到违反行为准则的举报后，我们会查看当事人在 Exercism 及相关沟通渠道上的对话记录，并尝试判断此人是故意违反行为准则，还是无意越界。我们通常会联系被举报人，讨论我们有哪些顾虑，并警告其重复违规将导致封禁。有时我们会认定并未发生违规、无需采取任何行动，有时我们也会在首次违规时就封禁账号。我们力求公平，但在涉及保护社区文化时，宁可从严。

Exercism 的管理团队保留针对违反行为准则的行为采取其认为适当的一切措施的权利。

## 简单版

- 有共情心
- 待人热情
- 友善
- 诚实
- 乐于支持
- 有礼貌

## 详细说明

Exercism 应当是每个人的安全之地，不论其：

- 性别、性别认同或性别表达
- 性取向
- 残障
- 外貌（包括但不限于体型）
- 种族
- 年龄
- 宗教
- 以及你能想到的任何其他方面。

作为这个社区的一员，你同意：

- 我们集体和个人都致力于营造安全、包容的环境。
- 我们对虐待、骚扰或歧视零容忍。
- 我们尊重他人的边界和身份。
- 我们不使用可能被视为冒犯或压迫性的语言（无论是系统性的还是其他形式的），例如性别歧视、种族歧视、恐同、恐跨、残障歧视、阶级歧视等。这包括（但不限于）各类侮辱性称呼。
- 我们避免拿冒犯性的话题开玩笑。

我们积极致力于：

- 成为一个安全的社区
- 培育一个彼此支持与鼓励的网络
- 鼓励负责任且多样化的表达方式

我们谴责：

- 跟踪骚扰、人肉搜索或公开他人隐私信息
- 暴力、暴力威胁或暴力语言
- 任何危害他人安全的行为
- 可能被视为性别歧视、种族歧视、恐同、恐跨、残障歧视或其他具有歧视性或冒犯性的行为或言论。
- 使用不受欢迎的、带有暗示性的、贬损性的或不恰当的绰号或称呼。
- 对他人不尊重（开玩笑、含沙射影、轻蔑态度），以及对不同意见的不尊重。
- 恐吓或骚扰（线上或线下）。关于我们如何界定骚扰，请阅读[《公民行为准则》](https://github.com/stumpsyn/policies/blob/master/citizen_code_of_conduct.md)。
- 不恰当的关注或接触。
- 分不清建设性批评与贬低之间的区别。

以上这些行为都是不可接受的。

留意你的行为如何影响他人。如果让别人感到不舒服，就停下来。

如果你说了什么让人感到被冒犯的话，并因此被指出来，请试着：

- 不打断地倾听。
- 相信对方所说的话，不要试图否定他们所说的内容。
- 请教对方，寻求避免今后再冒犯他人的建议或帮助。
- 道歉并请求原谅。

## 历史

该政策最初采用自 Front-end London Slack 社区，此后经过多次修改。版本历史可在 [GitHub](https://github.com/exercism/docs/commits/main/using/legal/code-of-conduct.md) 上查看。

_本政策是一份“活文档”，将来会不断细化和扩充。本政策适用于 Exercism 网站、Exercism GitHub 组织、任何其他与 Exercism 相关的沟通渠道（例如论坛、Slack、Twitter、电子邮件）以及任何其他 Exercism 实体或活动。_
