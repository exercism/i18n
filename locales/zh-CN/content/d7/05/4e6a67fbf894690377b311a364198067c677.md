# 简介

用其他语言的术语来说，JSON 的**对象**就是一个“哈希”、“映射”或“字典”。

JSON 把_对象_定义为：

> 对象是一组无序的**名称**/**值**对。
> 对象以 `{` 左大括号开始，以 `}` 右大括号结束。
> 每个_名称_后面跟一个 `:` 冒号，各个_名称/值_对之间用 `,` 逗号分隔。

_名称_**必须是字符串**。
_名称_的另一个说法是_键_。

_值_可以是任何 JSON 类型。
同一个对象中不同的_值_可以是不同的类型，就像下面这个例子。

<!-- prettier-ignore -->
```json
{
  "name": "Jane",
  "age": 42,
  "pets": ["cat", "fish"],
  "address": {"street": "123 Main St", "city": "Springfield"}
}
```

<!-- prettier-ignore-end -->

注意，_最后一个_键值对后面**不能**有逗号。

## 创建对象

用大括号来收集名称/值对。
虽然名称必须是字符串，但如果名称**类似标识符**（由字母数字字符和下划线组成，并且不以数字开头），就不需要用引号括起来。

```jq
{name: "Jane", age: 42}
```

使用**不类似标识符**的键也是可以的。
只要给它们加上引号就行。

```jq
{"first name": "Jane", "last name": "Lopez", age: 42}
```

如果名称是某个表达式的结果，那么这个表达式**必须**放在括号里。

```sh
$ echo "Jane" | jq -Rc '{.: 42}'
# verbose error message ...

$ echo "Jane" | jq -Rc '{(.): 42}'
{"Jane":42}
```

## 索引

可以用**点号表示法**从对象中取值。

```jq
{name: "Jane", age: 42} | .age    # => 42
```

如果无法把键当作标识符来引用，就用**方括号表示法**。

```jq
"name" as $key | {name: "Jane", age: 42} | .$key    # => error
"name" as $key | {name: "Jane", age: 42} | .[$key]  # => "Jane"
```

## 添加或修改键值对

要向数组添加新的键值对，或者更新已有键的值，可以使用 `=` 赋值运算符，并在左边写一个索引表达式。

```jq
{name: "Jane", age: 42} | .sport = "tennis" | .age = 21
# => {
#      "name": "Jane",
#      "age": 21,
#      "sport": "tennis"
#    }
```

`+` 运算符会_合并_对象。

```jq
{Richard: 54} + {Jane: 42}
# => {
#      "Richard": 54,
#      "Jane": 42
#    }
```

## 删除键

用 `del` 函数可以删除一个键。
它会返回更新后的对象。

```jq
{name: "Jane", age: 42} | del(.age)   # => {"name": "Jane"}
```

`del` 的形参是一个**索引表达式**（使用点号表示法或方括号表示法），它解析为对象中的某个键。
`jq` 把它称为**路径表达式**。
只给一个字符串是不够的。

```jq
{name: "Jane", age: 42} | del(name)        # error: name/0 is not defined
{name: "Jane", age: 42} | del("name")      # error: Invalid path expression with result "name"
{name: "Jane", age: 42} | del(.name)       # OK
{name: "Jane", age: 42} | del(.["name"])   # OK
```

## 成员判断

- 要判断对象是否有某个键，可以用 `has` 函数。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ($example | has("name")),    # => true
    ($example | has("sport"))    # => false
  ```

- 用 `in` 判断某个键是否在对象中。

  ```jq
  {name: "Jane", age: 42} as $example
  |
    ("name"  | in($example)),    # => true
    ("sport" | in($example))     # => false
  ```

## 列出所有键

用 `keys` 函数可以输出所有键的列表。

```jq
{name: "Jane", age: 42} | keys   # => ["age", "name"]
```

注意，`keys` 会对键_排序_。
如果想按原来的顺序获取键，用 `keys_unsorted`。

没有用来列出所有_值_的对应函数。
不过 `.[]` 过滤器会把对象的值作为一个_流_输出，而这个流可以用 `[...]` 数组构造器捕获。

```jq
[{first: "Jane", last: "Lopez", status: "awesome!"} | .[]]
# => ["Jane", "Lopez", "awesome!"]
```

## 迭代

- `map_values(filter)` 函数会把过滤器应用到对象中的每个_值_上。

  ```jq
  {first: "Jane", last: "Lopez", status: "awesome!"}
  | map_values(ascii_upcase)
  # => {"first": "JANE", "last": "LOPEZ", "status": "AWESOME!"}
  ```

- 要对对象进行迭代，必须先把它转换成一个由键值对象组成的数组。
  `to_entries` 函数可以做到这一点。

  ```jq
  {name: "Jane", age: 42} | to_entries'
  # => [
  #      {
  #        "key": "name",
  #        "value": "Jane"
  #      },
  #      {
  #        "key": "age",
  #        "value": 42
  #      }
  #    ]
  ```

  这时，我们就可以使用数组迭代函数，比如 `map`。

- `from_entries` 函数的作用相反：把由键值对象组成的数组转换成一个对象。

  ```jq
  [
    {"key":"name", "value":"Jane"},
    {"key":"age", "value":42}
  ] | from_entries                  # =>{"name": "Jane", "age": 42}
  ```

- 要把过滤器应用到对象中的_每个_键值对，可以用 `with_entries(filter)` 函数。

  例如，给定一个把名称映射到年龄的对象，可以像下面这样交换键和值。

  ```jq
  {"Jane": 42, "Richard": 54}
  | with_entries({key: (.value | tostring), value: .key})
  ```

  输出

  ```json
  {
    "42": "Jane",
    "54": "Richard"
  }
  ```

  `with_entries(filter)` 等同于

  ```jq
  to_entries | map(filter) | from_entries
  ```
