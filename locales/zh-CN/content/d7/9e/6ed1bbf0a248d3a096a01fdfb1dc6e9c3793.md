# 说明

在本练习中，你需要实现 1980 年代经典街机游戏 [Pac-Man][Pac-Man] 的一些规则。

你需要实现四条规则，它们都与游戏状态有关。

> _不用担心参数是怎么来的，只需专注于组合这些参数，返回预期的结果。_

## 1. 定义吃豆人是否能吃掉幽灵

定义 `eat_ghost()` 函数，它接收两个参数（_吃豆人是否有能量丸生效_ 和 _吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否能吃掉幽灵。
只有在吃豆人有能量丸生效且碰到幽灵时，该函数才应返回 `True`。

```python
>>> eat_ghost(False, True)
...
False
```

## 2. 定义吃豆人是否得分

定义 `score()` 函数，它接收两个参数（_吃豆人是否碰到能量丸_ 和 _吃豆人是否碰到豆子_），并返回一个布尔值，表示吃豆人是否得分。
只要吃豆人碰到能量丸或豆子，该函数就应返回 `True`。

```python
>>> score(True, True)
...
True
```

## 3. 定义吃豆人是否失败

定义 `lose()` 函数，它接收两个参数（_吃豆人是否有能量丸生效_ 和 _吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否失败。
如果吃豆人碰到幽灵且没有能量丸生效，该函数就应返回 `True`。

```python
>>> lose(False, True)
...
True
```

## 4. 定义吃豆人是否获胜

定义 `win()` 函数，它接收三个参数（_吃豆人是否吃掉了所有豆子_、_吃豆人是否有能量丸生效_，以及 _吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否获胜。
如果吃豆人吃掉了所有豆子，并且根据第 3 部分定义的规则判断没有失败，该函数就应返回 `True`。

```python
>>> win(False, True, False)
...
False
```
