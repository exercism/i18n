# 简介

在 Cairo 中，类型转换能让你把数据从一种类型变成另一种类型，从而灵活、安全地操作数据。

## 基础

Cairo 提供了多种类型转换机制：

### 直接类型转换

对于相互兼容的数字类型，可以使用直接类型转换：

```rust
let small_number: u8 = 42;
let big_number: u32 = small_number.into();
```

### `Into`特征

`Into`特征可以把一种类型转换成另一种类型：

```rust
let value: u16 = 100;
let converted: u32 = value.into();
```

### `TryInto`特征

对于可能失败的转换，可以使用`TryInto`，它会返回一个`Option`：

```rust
let large_value: u32 = 70000;
let small_value: Option<u16> = large_value.try_into();

match small_value {
    Option::Some(v) => println!("Converted: {}", v),
    Option::None => println!("Conversion failed"),
}
```

## 自定义类型转换

你可以为自己的类型实现`Into`：

```rust
#[derive(Drop)]
struct Celsius {
    value: i32,
}

#[derive(Drop)]
struct Fahrenheit {
    value: i32,
}

impl CelsiusIntoFahrenheit of Into<Celsius, Fahrenheit> {
    fn into(self: Celsius) -> Fahrenheit {
        Fahrenheit { value: (self.value * 9) / 5 + 32 }
    }
}
```

## 安全注意事项

- 当转换可能失败时（例如从大类型转成小类型），使用`TryInto`
- 当转换总能成功时，使用`Into`
- 一定要处理`TryInto`返回的`Option::None`情况
- 在有符号类型和无符号类型之间转换时，要考虑溢出和下溢
