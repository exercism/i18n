# 分析器标签

分析器标签用于标识某个解答是_如何_解出的。

这些标签随后可以用来：

- 把解答关联到解题方法
- 把解答关联到概念
- 搜索带有特定标签的解答

## 格式

标签是一个字符串，格式为：`<category>:<thing>`。

我们支持四种不同的类别，层级从高到低：

| Category    | Description                                     | Specificity                              | Examples                              |
| ----------- | ----------------------------------------------- | ---------------------------------------- | ------------------------------------- |
| `paradigm`  | 一种[编程范式][programming-paradigms]            | 层级很高，不特定于某个轨道                  | `imperative`、`functional`             |
| `technique` | 所使用的一种技巧                                  | 层级较高，大多数不特定于某个轨道             | `recursion`、`immutability`            |
| `construct` | 一种语言构造                                      | 很多不特定于某个轨道                        | `bitwise-and`、`for-loop`              |
| `uses`      | 特定于某门语言的用法，比如类型或方法                 | 层级较低，特定于某个轨道                     | `DateTime.add_seconds`、`IEnumerable`  |

一些示例标签：

- `paradigm:functional`
- `technique:recursion`
- `construct:bitwise-and`
- `uses:DateTime.add_seconds`

## 常用标签

虽然各个轨道可以按自己的方式给解答打标签，但我们建议尽可能使用下面这份常用标签列表。
使用一套通用的标签，能让我们实现一些巧妙的功能，比如跨轨道关联解答。

| `construct:yield`                            | 在循环中惰性地产出值                                                            |
