# 关于

Elixir 用布尔类型来表示 true 和 false 这两个值。这样的值只有两个：`true` 和 `false`。它们可以用布尔运算符（[`and/2`][strict-and]、[`or/2`][strict-or]和[`not/1`][strict-not]）组合起来：

```elixir
true_variable = true and true
false_variable = true and false

true_variable = false or true
false_variable = false or false

true_variable = not false
false_variable = not true
```

[`and/2`][strict-and]、[`or/2`][strict-or]和[`not/1`][strict-not]都是严格布尔运算符，也就是说它们要求_第一个_实参必须是布尔值。此外还有一些等效的布尔运算符，它们可以接受任意类型的实参：[`&&/2`][and]、[`||/2`][or]和[`!/1`][not]。

布尔运算符使用_短路求值_，也就是说，只有当需要时才会对运算符右侧的表达式求值。

每个运算符的优先级都不同，`not/1`会先于`and/2`和`or/2`求值。可以用括号让表达式的某一部分先于其他部分求值：

```elixir
not true and false
# => false

not (true and false)
# => true
```

在编写返回布尔值的函数时，[习惯上会在函数名末尾][naming]加上`?`。存储布尔值的变量也可以使用同样的约定。

```elixir
def either_true?(a?, b?) do
  a? or b?
end
```
