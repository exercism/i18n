# 说明

Sarah 正在制作一款新的角色扮演游戏，需要你帮忙处理玩家机制。

## 1. 定义`player`元组

定义一个包含四个槽位和默认值的元组类`player`：

| 槽位     | 默认值 |
| -------- | ------- |
| `name`   | `f`     |
| `level`  | `0`     |
| `health` | `100`   |
| `mana`   | `f`     |

定义好之后，你可以用字面量创建一个玩家：

```factor
T{ player { name "Merlin" } { level 5 } } .
! => T{ player { name "Merlin" } { level 5 } }
```

## 2. 介绍玩家

定义`introduce`来返回玩家的名字。潜行的玩家会隐藏自己的名字（`name`为`f`），介绍时应该返回`"Mighty Magician"`。

```factor
T{ player { name "Merlin" } } introduce .
! => "Merlin"

T{ player { health 8 } } introduce .
! => "Mighty Magician"
```

## 3. 复活倒下的玩家

定义`revive`来返回一个*新的*玩家，其`health`设为 100，`mana`设为 100，但仅当玩家的`health`为`0`时如此。如果玩家还活着，则返回`f`。

```factor
T{ player { name "Merlin" } { health 0 } } revive .
! => T{ player { name "Merlin" } { health 100 } { mana 100 } }

T{ player { health 50 } } revive .
! => f
```

## 4. 承受伤害

定义`take-damage`来返回一个*新的*玩家，其`health`减少给定的数值，但绝不会低于`0`。

```factor
T{ player { health 100 } } 30 take-damage .
! => T{ player { health 70 } }

T{ player { health 5 } } 30 take-damage .
! => T{ player { health 0 } }
```
