# 简介

`LocalDate`、`LocalDateTime` 这样的类描述的是时间上的一个*点*。
`java.time` 包中还有两个类，它们描述的是*一段*时间：

- `java.time.Period` 表示以年、月、日计的一段时间，例如“2 个月零 5 天”。
- `java.time.Duration` 表示以时、分、秒、毫秒和纳秒计的一段时间，例如“1 小时 30 分钟”。

`Period` 遵循日历，因此与日期和日期时间一起使用。
`Duration` 衡量的是精确的时间，因此与时间和日期时间一起使用，但不能用于日期。

```exercism/note
和其他 `java.time` 类一样，`Period` 和 `Duration` 也是不可变的。
那些看起来会修改它们的方法，实际上返回的是一个*新*实例。
```

## `Period`

`Period` 通过它的某个静态工厂方法创建：

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()` 的结果使用 [ISO-8601][iso-8601-durations] 记法：先是 `P`（代表“period”），后面依次是年（`Y`）、月（`M`）和日（`D`）的数量。

可以把一个周期加到一个日期上，也可以从日期中减去一个周期：

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

由于每个月的天数不同，加上月数后可能落到一个并不存在的日期上。这种情况下，结果会回退到该月的最后一个有效日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()` 返回从一个日期（包含在内）到另一个日期（不包含）之间的周期：

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

## 用 `ChronoUnit` 计算单位数量

`Period` 把年、月、日分开保存。
因此 `getDays()` 只返回周期中日的*那一部分*，而不是总天数。
要计算两个日期之间某个单位的总数，请使用 [`java.time.temporal.ChronoUnit`][chronounit-docs] 的 `between()` 方法：

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

如果第二个日期早于第一个日期，结果为负数：

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

## `Duration`

`Duration` 同样通过静态工厂方法创建：

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

在 ISO-8601 记法中，`T` 用来分隔日期部分和时间部分，所以时长的写法是 `PT...`。

可以把一个时长加到一个日期时间上，也可以从日期时间中减去一个时长：

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()` 返回两个日期时间之间的精确时长：

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

可以用 `toHours()`、`toMinutes()` 和 `toSeconds()` 之类的方法把时长换算成单一单位。
这些方法返回该单位下的*总量*，向下取整：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

如果想像看钟表那样把时长拆成各个部分，就改用 `toXxxPart()` 方法：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
