# 安装 Python

如果你的系统上还没有 Python，可以在官方文档的 [Python 安装与使用][using python] 部分找到按平台划分的详细说明。Real Python 也提供了一份[不错的指南][helpful guide]，介绍如何在各种平台上安装 Python，包括 iOS 和 Android。

最后，Brett Cannon 的这两篇文章 [A quick-and-dirty guide][quick-and-dirty] 和 [Why you should use `python -m pip`][python-m-pip] 就如何管理 Python 的安装和软件包给出了非常有用的建议。

**MacOS 用户请注意：**在 MacOS Monterey（12.3）之前，`Python 2.7` 是随操作系统预装的。在 Exercism 或大多数其他程序中使用 `Python 2.7` 都不受支持。你应该改用下面详述的某种方法安装 [Python 3][Python-three downloads]。从 MacOS Monterey（12.3）起，MacOS 不再预装任何版本的 Python。

以下是按操作系统划分的文档快速链接：

-  [Windows][windows] 此外，微软的这篇关于[在 Windows 上安装 Python][python-on-windows]的文章也很有帮助。
-  [Unix 和 Linux 系统][unix-and-linux]（_这些方法大多也适用于 MacOS_）
-  [MacOS][macos]

   我们还建议你回顾一下 Real Python 的[安装 Python][installing-python]文章中列出的一些方法，或者上面链接的 Brett Cannon 的文章。


Exercism 的测试和工具目前支持 `3.10` - `3.13.5`（_测试_）以及 [`Python 3.13.5`][313-new-features]（_工具_）。这一支持范围的例外情况会在出现的地方加以说明。大多数练习在 `Python 3.6+` 甚至更早的版本上也能运行。但我们不保证支持 [当前活跃的 Python 版本][active-python-releases] 中未列出的版本。


关于目前支持的内容，请参阅 [Python 3.13.x 文档][3.13 docs]。
