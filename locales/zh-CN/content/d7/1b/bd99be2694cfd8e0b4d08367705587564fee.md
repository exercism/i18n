# 说明

你的朋友 Kojo 是个超级数字迷。
他有一个小网站，叫“fun-with-numbers”。
Kojo 的编程水平不算好，所以他来找你帮忙。

你要为 Kojo 网站上的新数字游戏写两个辅助函数，再加第三个，用来校验用户可能输入的某些内容。

## 1. 计算老虎机上数字的和

Kojo 网站上的其中一个游戏看起来像一台老虎机，上面显示着两组带数字的转轮。
每组数字代表一个数。
为了实现游戏机制，Kojo 需要知道这两个数的和。

写一个函数`twoSum`，接受两个数组作为形参。
每个数组由一个或多个 0 到 9 之间的数字组成。
函数应把每个数组解释成一个数，并返回这两个数的和。

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. 判断一个数是否为回文数

网站上的另一个游戏是一个叫“幸运数字”的小测验。
用户可以输入一个数，然后看到这个数是否属于某个秘密数列或模式。
“幸运数字”的数列或模式每个月都会变，而每个用户只有有限的几次机会猜出它。

本月的幸运数字应该是回文数。
回文数把各位数字反转后仍然相同。

实现新的`luckyNumber`函数，它接受一个数作为形参。
如果这个数是回文数，函数应返回`true`，否则返回`false`。
输入的数永远是正整数。

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. 为无效的用户输入生成错误消息

网站上有多处输入框，用户可以输入数字并点击按钮来触发某个操作。
Kojo 想改善他网站的用户体验。
如果用户点击了按钮，但输入框里是一个无效的输入值，他希望显示一条错误消息。

下面再补充一些关于输入框的值是如何提供的说明。

- 如果用户在输入框里输入了内容，那么对应的值永远是字符串，即使用户只输入了数字。
- 如果用户输入了内容又把它删掉，这个变量会是一个空字符串。
- 在用户开始输入之前，这个变量可能是`undefined`或`null`。

写一个函数`errorMessage`，它接受用户输入作为形参。
如果用户没有提供任何输入，`errorMessage`应返回`'Required field'`。
如果输入不能表示一个非零的数（按照 JavaScript 的转换规则），则应返回`'Must be a number besides 0'`。
其他所有情况下，你可以假定输入是有效的，返回值应为空字符串。

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
