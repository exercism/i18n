# 简介

## 导出函数

导出函数在第一个概念中已经讲过，这里快速回顾一下。

Elm 中的每个文件都是一个模块，并且必须在所有其他代码之前包含一条 `module` 语句。

模块名必须与文件名一致，因此模块 `Calculator` 必须放在文件 Calculator.elm 中，模块 `Parser.Utils` 必须放在文件 Parser/Utils.elm 中。

模块内定义的任何内容默认都只在该模块内部可见，除非在 `exposing` 中列出，否则无法从这个模块外部访问。

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 从其他模块导入函数

要访问其他模块中定义的函数，需要通过导入来实现。
导入某个模块时，该模块中所有被它公开的函数都会变为可访问。
但访问它们的方式取决于导入该模块的方式。

限定导入是默认方式，访问这类模块中的函数（例如 `List` 模块里的 `map` 函数）时，需要加上模块名作为前缀（`List.map`）。

开放导入让你可以直接访问该模块中公开的函数，无需加前缀。它使用 `exposing` 关键字，与导出时所用的那个关键字正好对应。你可以公开所有可用的函数（用 `..`），也可以只公开特定的函数（例如 `map`）。

你还可以从其他模块导入类型及其构造器，这会在后面的概念中介绍。

推荐使用限定导入，这样更清晰，也能避免命名冲突。

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

## 类型注解

类型注解的定义形式为 `name : parameter types -> return type`，多个形参类型之间也用 `->` 分隔。

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

括号可用于定义函数形参（形参本身也用同样的语法定义，因此需要用到括号）。

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

## 数字

Elm 中有两种数字类型，分别由 `Int` 和 `Float` 类型定义。
`Int` 对应正整数和负整数的集合。
`Float` 对应实数的集合，受计算机精度的限制。
定义在数字上的运算通常只适用于其中一种类型，不能把两者混用。
有一些函数可以在两种类型之间转换，例如 `toFloat` 把 `Int` 转换为 `Float`，而 `round`、`floor`、`ceiling` 或 `truncate` 则以不同的语义把 `Float` 转换为 `Int`。

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

## 字符串操作

为了在代码中表示单词和句子，Elm 提供了原生的 `String` 类型。
字符串字面量写在双引号之间，例如 `"Hello World!"`。
默认可以使用字符串拼接运算符 `++` 和相等运算符 `==`。

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

其他大多数字符串函数都在 `String` 模块中，需要先导入该模块。

https://package.elm-lang.org/packages/elm/core/latest/String
