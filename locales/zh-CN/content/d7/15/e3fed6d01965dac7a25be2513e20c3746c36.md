# 安装

Crystal 可在 Linux、macOS 和 Windows 上使用。

需要注意的是，Crystal 对 Windows 的支持仍处于实验阶段。这意味着某些边界情况可能无法正常工作，也可能不太适合用于生产环境。不过，对于 Exercism 和基本使用来说，原生 Windows 大体上是可用的。

如果你希望在 Windows 上进行开发时获得非预览版体验，建议使用 [WSL（Windows Subsystem for Linux）][wsl]。这是 Windows 10（1903 及以上版本）和 11 的一项**免费**功能，让开发者无需虚拟机就能运行 Linux 环境。

安装 Crystal 的步骤请参考某篇[安装指南][installation guides]。

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
