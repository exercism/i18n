# 不要使用嵌套`if`语句

试着改写这些`if`语句，避免过深的嵌套，因为嵌套过深会让代码更难理解。看看下面两段代码：

```csharp
void PrintName(Person p)
{
    if (p != null)
    {
        if (p.Name != null)
        {
            if (p.Age >= 21)
            {
                Console.WriteLine(p.Name);
            }
        }
    }
}
```

再对比下面这段代码：

```csharp
void PrintName(Person p)
{
  if (p == null || p.Name == null || p.Age < 21)
  {
      return;
  }

  Console.WriteLine(p.Name);
}
```

第二个例子有一个很明确的结构：所有处理错误的路径都放在缩进的代码块里，而“正常路径”始终靠最左边对齐。这样读起来非常轻松，因为一眼就能看出代码里最常见、没有错误的那条路径。
