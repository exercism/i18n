# 安装

Racket 发行版可以从 https://download.racket-lang.org 下载。

官方为以下平台提供了安装程序：

* Windows
* Linux
* macOS

入门材料请参考 Racket 的 [Getting Started](http://docs.racket-lang.org/getting-started/) 页面。

[Racket Guide](https://docs.racket-lang.org/guide/intro.html) 会向你介绍如何与 Racket 交互。

有关使用 DrRacket IDE 的指引，请参阅 [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html)。

想了解 Racket 命令行工具以及如何使用其他编辑器，请参阅 [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html)。


## 关于 Linux 安装程序：

Linux 版构建足够通用，在大多数发行版上都能运行，包括比较旧的发行版。

下载安装程序文件后，用以下命令运行它：
```
sh racket-8.10-x86_64-linux-cs.sh
```

如果要安装到需要管理员权限的位置，可能需要在命令开头加上 `sudo`。

**警告：Racket 也可能通过你的发行版的包管理器获得，不过它可能比最新的 Racket 版本要旧。**
虽然你可以以后再这样做，但作为学习者，如果坚持使用 https://download.racket-lang.org 上提供的最新版本，体验会好得多。


## 关于 macOS 安装程序：

如果你的机器使用 M1 或 M2 系列处理器，请在下载前在平台下拉菜单中选择**Apple Silicon**。
