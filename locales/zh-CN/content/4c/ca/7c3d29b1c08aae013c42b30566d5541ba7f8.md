# 关于

[cons][hyper-conses] 是 Common Lisp 中的一种基本数据类型。它由头部和尾部组成（出于历史原因，分别称为 `car` 和 `cdr`）。
对 cons 的头部和尾部的数据类型没有任何限制。

cons 由 [`cons`][hyper-cons] 函数创建，该函数接收两个对象，并求值得到一个 cons（有时也称为“cons cell”）。

访问 cons 的各个部分可以使用 [`car`][hyper-car] 和 [`cdr`][hyper-cdr] 函数。

## 参考

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
