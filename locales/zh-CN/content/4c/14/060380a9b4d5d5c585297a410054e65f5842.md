# 简介

遍历序列时，你需要的不仅是元素本身，还有它的*位置*。[`sequences`][sequences]里的 `*-index` 系列会把两者都交给处理每个元素的 quotation。`times` 则是普通计数迭代的近亲，当你只需要一个计数、不需要序列时，它很有用。

## `each-index` 和 `map-index`：quotation 中的下标

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

传给 quotation 的是位于下标下方的元素，`index` 位于栈的**顶部**：

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index`运行 quotation 只是为了它的副作用，不返回任何东西。`map-index`则把每个元素的结果收集成一个与输入相同类型的新序列。

## `times`：计数迭代

`times`（位于 [`math`][math] 中）会把它的 quotation 运行 `n` 次。

```
times ( n quot: ( -- ) -- )
```

公布的 `( -- )` 形态只是*最低要求*：因为 `times` 是 `inline`，像 `( str -- str )` 这样效果平衡的 quotation 也完全没问题，栈会在各次迭代之间依次传递。这样你就能在没有可变状态的情况下得到一个计数累加器：

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

每次迭代的循环体都能看到当前的字符串，把内容追加进去，然后把新字符串留在栈上，供下一次迭代使用。当你想让一个累加器贯穿整个迭代过程时，`each-index` 和 `map-index` 也可以用同样的技巧。
