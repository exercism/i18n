# 简介

许多程序需要（伪）随机值来模拟现实世界中的事件。

常见而熟悉的例子包括：

- 抛硬币：从 ('H', 'T') 中随机取一个值。
- 掷骰子：从 1 到 6 中随机取一个整数。
- 洗牌：把一副牌的列表随机排序。
- 在三维图形模拟中生成树木和灌木。

用计算机生成真正随机的值是一个[出奇困难的技术挑战][why-randomness-is-hard]，这也是为什么还有“伪随机”生成器。

## 生成随机数

在 Javascript 中，你可以使用[`Math.random()`][Math.random]函数生成伪随机数。
它会返回一个介于 0（包含）和 1（不包含）之间的伪随机浮点数。

要获得介于 _min_（包含）和 _max_（不包含）之间的随机数，可以使用类似下面这样的函数：

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

## 生成随机整数

要生成随机整数，你可以使用 `Math.floor()`或`Math.ceil()`把一个随机生成的数变成整数。
