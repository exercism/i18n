# 说明

你刚开始在一家攀岩馆的前台工作。会员会购买若干个月的会员资格，每次来馆时都要签到和签退。经理让你写一个辅助工具，用来回答会员们最常问的问题。

## 1. 计算会员资格的到期日期

从某一天开始的会员资格，会在若干个月后的同一天结束。如果结束的那个月里没有这一天，会员资格就在该月的最后一天结束。

实现`FrontDesk.membershipEnd()`方法，它接收会员资格的开始日期和月数，返回会员资格的结束日期：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. 显示会员资格的时长

攀岩馆会在会员卡上印出会员资格的时长，以年、月、日表示。

实现`FrontDesk.membershipLength()`方法，它接收会员资格的开始日期和结束日期，返回会员资格的时长，类型为`Period`：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. 统计会员资格剩余的天数

会员经常问，自己的会员资格到期之前还剩多少天。

实现`FrontDesk.daysLeft()`方法，它接收今天的日期和会员资格的结束日期，返回从今天到结束日期的总天数。如果结束日期就是今天，或者已经过去，就没有剩余天数了，此时该方法返回`0`：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. 计算一次到访的时长

攀岩馆全天开放，闸机会记录会员签到和签退的日期与时间。

实现`FrontDesk.visitDuration()`方法，它接收一次到访的签到和签退日期时间，返回这次到访的时长，类型为`Duration`：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. 在收据上打印一次到访

收据上会以小时和分钟显示一次到访的时长，例如`1h 35m`。分钟总是写成两位数，秒数一律舍去，小时数也不限于一天以内。

实现`FrontDesk.formatVisit()`方法，它接收到访的时长，并按这种格式返回：

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
