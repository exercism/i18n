# 简介

## 列表

F# 中的`list`是一个不可变集合，可以包含零个或多个值。列表中的所有值都必须具有相同的类型。由于列表是不可变的，一旦列表被构建出来，它的值就永远不会改变。任何看起来会修改列表的函数或运算符（例如添加一个元素），实际上都会返回一个新的列表。

列表可以这样定义：

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

向列表中添加元素最常见的方式是使用`::`（cons）运算符：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

F# 列表有一个_头部_（第一个元素）和一个_尾部_（第一个元素之后的所有内容）。列表的尾部本身也是一个列表。

列表既可以通过`List`模块中定义的函数和运算符来操作，也可以使用模式匹配，借助 _list_ 和 _cons_ 模式手动操作：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

在模式匹配时，你也可以_丢弃_一个值；当你在某个特定分支中_不_关心某个值（也就是说，你不打算_使用_它）时，可以用下划线（`'_'`）来表示这一点：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

在模式匹配时，单个`'_'`应始终放在_最后_；所有不匹配其他分支的值都会由这一分支来处理。
