# 关于

C# 中的数组是基元值或结构、类实例的集合。它们在基类库中实现为 [`List<T>`][lists-docs]，其中 `T` 是数组中元素的类型。API 提供了丰富的方法，用于创建和操作数组。

```csharp
var listOfStrings = new List<string>();
var listOfIntegers = new List<int>();
var listOfRandoms = new List<Random>();
var listOfBigIntegers = new List<BigInteger>();
```

集合的定义通常会在尖括号里留一个占位符，按惯例常写作 `T`。这样集合的使用者就能指定要在这个集合里存放什么类型的元素。

与 [concept:csharp/arrays]() 不同，数组可以动态调整自身大小。

## LINQ

尽管 `List<T>` 的内置 API 很丰富（包括 `ConvertAll`、`FindAll` 和 `Foreach` 等映射和筛选功能），它的[循环语法][for-each]也非常清晰，你确实需要熟悉这套 API，不过在许多任务中还可以使用语言集成查询（[LINQ][linq]）。它更强大，使用也更广泛，优势在于能为库集合、第三方集合和你自己的类提供一致的接口。
