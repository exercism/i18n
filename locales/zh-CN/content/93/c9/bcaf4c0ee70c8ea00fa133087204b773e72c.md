# 提示

## 概述

- [`combinators`][combinators] 里的 `cond` 是把速度映射为成功率最简洁的方式。
- 算术相关的词都在 [`math`][math] 里；浮点数转整数的辅助词 `floor` 和 `>integer` 则分别位于 [`math.functions`][math.functions] 和 [`math`][math] 中。

## 1. 报告生产线是否在运行

- [`math`][math] 里的 `zero?` 用来检测速度是不是 `0`。
- `if` 接收一个布尔值和两个引用 `[ "stopped" ] [ "running" ]`，然后运行匹配的那一个。这里速度会被测试消耗掉，所以两个引用都不需要 `drop`。

## 2. 计算成功率

- 一个 `cond` 子句是 `{ [ predicate ] [ body ] }`。每个谓词都会检查速度，但应让栈保持原样（用 `dup` … `<test>` 就能做到）。子句主体通常以 `drop` 开头。
- 顺序很重要：先检查 `zero?`，再检查 `4 <=`，因为 `0 4 <=` 的结果是 `t`。
- 用一个不带谓词的最后分支作为速度 `10` 的默认值。

## 3. 计算每小时的产量

- 在文件靠上的位置用 `CONSTANT:` 定义 `base-speed`（就像 `lasagna` 里的 `expected-bake-time` 那样）。
- 计算 `base-speed * speed * success-rate`。一种方式是使用 `kernel` 里的 `bi`：它会在同一个输入上运行两个引用，并把两个结果都留在栈上。

## 4. 计算每分钟生产的合格产品数量

- 把每小时的产量除以 60。
- 用 `floor` 去掉小数部分，再用 `>integer` 把浮点数结果转成整数。
