# 类型断言简介

Go 中的接口可能会让底层类型变得不明确。
类型断言让我们可以用下面的语法取出接口值底层的具体值：`interfaceVariable.(concreteType)`。

例如：

```go
var input interface{} = 12
number := input.(int)
```

注意：如果接口变量没有持有该具体类型的值，就会引发 panic。

我们可以利用类型断言的两个返回值来判断接口值是否持有某个具体类型：一个是底层值，另一个是布尔值，用来表明断言是否成功。
例如：

```go
str, ok := input.(string) // no panic if input is not a string
```

如果 `input` 持有 `string`，那么 `str` 就是那个底层值，`ok` 为 true。
如果 `input` 没有持有 `string`，那么 `str` 会是 `string` 类型的零值（即 `""`，空字符串），`ok` 为 false。
无论哪种情况都不会发生 panic。

## 类型 switch

**类型 switch**可以依次执行多个类型断言。
它的语法和类型断言（`interfaceVariable.(concreteType)`）相同，只是把 `concreteType` 换成了关键字 `type`。
下面是一个例子：

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
