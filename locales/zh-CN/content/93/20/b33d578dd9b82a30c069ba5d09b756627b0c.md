# 安装

要在你的系统上安装 Julia，请按照 [Julia 语言下载页面](https://julialang.org/downloads/)上的说明操作。

~~~~exercism/caution
不建议通过操作系统的包管理器安装 Julia。这些软件包并非官方维护，可能会引发问题。
~~~~

如果想在本地安装，目前有适用于大量编辑器/IDE 的插件。[VS Code 扩展](https://github.com/julia-vscode/julia-vscode)是最受欢迎的一个。你可以在 GitHub 上的 [JuliaEditorSupport](https://github.com/JuliaEditorSupport) 组织中找到其他编辑器的集成方案。

如果你更喜欢交互式的环境，可以配合 [IJulia](https://github.com/JuliaLang/IJulia.jl) 使用 Jupyter 笔记本，或者用 [Pluto.jl](https://github.com/fonsp/Pluto.jl) 来写 Julia 中简洁的响应式笔记本。

无需本地安装就能轻松上手 Julia 的一种方式是 [Nextjournal](https://nextjournal.com/)，一个基于笔记本的在线 IDE。你可以从浏览器访问它，登录后就能开始做练习。如果你只想要一个在线 REPL，可以使用 [Repl.it](https://repl.it/languages/julia)。
