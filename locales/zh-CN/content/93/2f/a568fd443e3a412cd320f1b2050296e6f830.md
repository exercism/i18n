# 简介

Perl 是由 Larry Wall 创建的编程语言，于 1987 年首次发布。

## 包与模块

包是一组代码，通常放在一个同名、扩展名为`.pm`的模块文件中。
之后可以用`use`关键字把这个模块导入另一个文件。

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 变量

变量分为标量变量（`$foo`）、数组变量（`@bar`）和哈希变量（`%baz`）。
为简单起见，这里只使用标量变量。
标量值可以是以下几种：字符串、数字、布尔值，或对某个东西的[引用][perlreftut]。
值不存在时用`undef`表示。


`my`和`our`关键字会在词法作用域中声明变量，例如`my $foo;`。
使用`our`时，该变量还会作为别名关联到同名的包变量。
还有其他的变量声明方式，这里不再介绍。

可以用`=`运算符给变量赋值，例如`$foo = 1;`；这也可以和声明变量同时进行，例如`my $foo = 1;`。

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## 子程序

`sub`关键字用于声明[子程序][perlsub]。
`return`关键字会退出子程序，并返回指定的值；如果没有给出任何值，则返回空列表。
如果没有显式写出`return`，返回值就由调用子程序时的上下文（标量、列表或空上下文）以及最后一条语句决定。

```perl
sub hello () {
    return 'Hello, World!';
}
```

较新版本的 Perl 允许在[签名][perlsubsig]中指定形参。
参数列表可以包含标量、数组或哈希变量。
空的参数列表表示该子程序不接受任何实参。
较旧版本的 Perl 需要从特殊变量`@_`中获取实参，这里不再介绍。
