# 类型转换

类型转换有时也被称为类型强制转换。
类型转换是指，在运算时把两个不同类型的值转换为同一种类型。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15 // int
```

表达式求值时，字符串值会被隐式转换为`int`，以符合`*`运算符的预期。
至于该转换哪一种类型，由 PHP 根据运算自身的规则来决定，而这些规则千差万别。

调用函数和方法时也会发生类型强制转换：

```php
strlen(12321);
# => 5
```

## 强制类型转换

除了依赖隐式类型强制转换，我们还可以使用 `C` 语言风格的强制类型转换，显式地强制一个值按某种类型来求值：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

这会把值转换为括号`(...)`中指定的类型。
所有基本类型都可以作为目标类型：`bool`、`int`、`float`、`string`、`array`、`object`。

## 转换只是暂时的

类型转换或强制类型转换**不会改变**变量中存储的值的类型。
被转换的只是参与运算的输入。

```php
$apples_per_basket = "3" // string
5 * $apples_per_basket
# $apples_per_basket => "3" // string

$my_number = (int) $apples_per_basket // cast string to int
# $apples_per_basket => "3" // string
```

## 信息丢失

把一个值转换为另一种类型时，这个过程中可能会丢失信息：

```php
$exact_distance = 15.5
$rough_distance = (int) $exact_distance
// => 15

$is_distant = (bool) $exact_distance
// => true

$erroneous_distance = (float) $is_distant
// => 1.0
```

在较大的系统中，无论显式还是隐式，依赖类型转换都可能引发错误。

## 显式转换为`array`和`object`

值也可以强制转换为`array`和`object`类型。
如果把一个既不是数组也不是对象的值转换为`array`，它会被转换为数组中的单个元素：

```php
$day_of_the_week = 'Monday';
(array) $day_of_the_week
// => array(1) {
//      [0]=>
//        string(6) "Monday"
//    }
```

转换为`object`时，该值会被设为一个名为`scalar`的公有属性：

```php
$car = "Honda"
(object) $car
// => object(stdClass)#1 (1) {
//      ["scalar"]=>
//        string(5) "Honda"
//    }
```

> `stdClass`是 PHP 内置的匿名类的类型。
