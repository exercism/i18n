# 关于

Clojure 的所有标准数据类型都是不可变的，因此它提供了*引用类型*，用来实现受控的修改。其中最简单、也最常用的一种叫做 Atom。

Atom 通过`atom`函数创建，该函数接受一个初始值：

```clojure
(def players (atom ()))
```

Atom 的当前值可以用`deref`或`@`简写来解引用：

```clojure
@players
;;=> ()
```

使用`swap!`可以修改`players`这个 Atom 的当前值，它通过应用一个函数来更新该值：

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!`函数会替换 Atom 的值，而不管它当前的值是什么：

```clojure
(reset! players ())
```
