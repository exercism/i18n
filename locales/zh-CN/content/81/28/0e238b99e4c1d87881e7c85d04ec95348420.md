# 关于

在 Rust 中，方法是定义在结构体（或`enum`、`trait`对象）上的函数。这也改变了调用方式：不再写成`frobnicate(foo)`，而是写成`foo.frobnicate()`来调用方法。

方法和函数很像：都用`fn`关键字声明，都有名字，也都可以有形参和返回值。

与函数不同的是，方法的第一个形参总是`self`（或它的某个变体），它代表调用该方法时所针对的结构体实例（详见下文）。

我们为霍格沃茨的学院定义一个`enum`，再定义一个`struct`，用来描述巫师的`age`和`house`：

```rust
#[derive(Debug)]
enum House {
    Gryffindor,
    Hufflepuff,
    Ravenclaw,
    Slytherin,
}

struct Wizard {
    age: u32,
    house: House,
}
```

## 定义方法

要为结构体`Wizard`定义方法，我们先为`Wizard`开一个`impl`块（implementation 的缩写）。

```rust
impl Wizard { }
```

这个`impl`块里的所有内容都会与`Wizard`类型关联。注意，一个结构体可以拥有多个`impl`块。

### 使用`self`

方法必须把名为`self`、类型为`Self`的形参作为第一个形参。
类型`Self`是`impl`块所针对的类型的别名。
在我们的例子里，`Self`代表`Wizard`。

为方便起见，Rust 允许我们做个简写，在第一个形参的位置只写`self`这个名字。
方法中常见的`self`类型有：

- `self`：是`self: Self`的缩写。单独写`self`的签名会消耗实例。
- `&self`：是`self: &Self`的缩写。这会以不可变的方式借用实例。
- `&mut self`：是`self: &mut Self`的缩写。这会以可变的方式借用实例。

在更高级的代码里，你可能还会看到`self: Pin<&self>`、`self: Rc<Self>`等签名。
不过，这超出了本教程的范围。

### 用`&self`定义方法

如果我们想实现一个`info`方法来显示巫师的基本信息，可以在`Wizard`的`impl`块里定义这个方法：

```rust
impl Wizard {
    fn info(&self) {
        println!(
            "A wizard of age {} who studies in House {:?} at Hogwarts",
            self.age,
            self.house,
        );
    }
}
```

注意，在`info`的签名里，我们用`&self`以不可变的方式借用实例。
这样，我们就能读取`Wizard`实例的`age`和`house`字段，而不改变它们。
如果改用会消耗实例的`self`而不是借用，那么方法调用之后，这个实例就无法访问了。

实现了`info`方法之后，我们就能打印巫师的基本信息：

```rust
let harry = Wizard { age: 11, house: House::Gryffindor };
harry.info();
// => A wizard of age 11 who studies in House Gryffindor at Hogwarts
```

### 用`&mut self`定义方法

如果我们想实现一个会修改结构体实例字段的方法，就要在方法的签名里用`&mut self`以可变的方式借用实例。

假设我们想在霍格沃茨定一条新规矩，允许学生更换学院。
我们可以这样实现`switch_house`方法：

```rust
impl Wizard {
    fn switch_house(&mut self, new_house: House) {
        self.house = new_house;
    }
}
```

现在，我们就可以给在霍格沃茨就读的巫师更换学院了：

```rust
// Note that the variable must be mutable
let mut cedric = Wizard {age: 14, house: House::Hufflepuff};
cedric.info();
// => A wizard of age 14 who studies in House Hufflepuff at Hogwarts
cedric.switch_house(House::Slytherin);
cedric.info()
// => A wizard of age 14 who studies in House Slytherin at Hogwarts
```

## 多个`impl`块

在 Rust 中，每个条目都可以有多个`impl`块。
因此，我们可以把所有方法都放在同一个`impl`块里，也可以按方法分组写成多个`impl`块。
两种写法在语法上都合法，不过典型的项目组织方式是：每一组不同的`impl`级别的`where`约束，只用一个`impl`块。

## 关联函数

在一个`impl`块里，可以定义不含`self`形参的函数。
由于没有`self`形参，它们不是方法。
但它们仍然与`impl`所针对的类型关联，调用时要写出那个类型的名字。
正因如此，它们被称为关联函数（也叫类型关联函数）。

你已经见过一些关联函数，比如`String::from()`：

```rust
let some_string = String::from("This is an associated function but not a method");
```

构造函数通常就实现为关联函数。
我们来创建一个与`Wizard`类型关联的`new`函数：

```rust
impl Wizard {
    fn new(age: u32, house: House) -> Self {
        Self {
            age,
            house,
        }
    }
}
```

注意，我们可以用`Self`代替`Wizard`来表示函数将要返回的类型。
以这种方式使用`Self`类型别名并不是必须的，但对于名字复杂或冗长的类型，它能简化实现。
现在我们可以运行下面的代码：

```rust
let myrtle = Wizard::new(14, House::Ravenclaw);

myrtle.info();
// => A wizard of age 14 who studies in House Ravenclaw at Hogwarts
```
