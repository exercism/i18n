# 关于

`Bool`类型是这门语言的基本构件之一。它用来描述某个东西是真还是假，分别对应`True`和`False`这两个值。`Bool`这个名字是“布尔”的缩写，布尔是数学中与逻辑思维有关的一个领域，得名于 George Boole 的研究。

## 布尔运算符

有两个函数和两个运算符可以用来操作`Bool`类型的值。

- `not : Bool -> Bool`
  这个函数把`True`变成`False`，把`False`变成`True`。
- `(&&) : Bool -> Bool -> Bool`
  这个叫做“AND”的运算符接受两个布尔值，如果它们都是`True`就返回`True`。
  例如，`True && True`返回`True`，而`True && False`返回`False`。
- `(||) : Bool -> Bool -> Bool`
  这个叫做“OR”的运算符接受两个布尔值，只要其中至少有一个是`True`就返回`True`。
  例如，`False || False`返回`False`，而`True || False`返回`True`。
- `xor : Bool -> Bool -> Bool`
  这个函数（不是运算符）叫做“XOR”，它接受两个布尔值，当且仅当一个为`True`、另一个为`False`时返回`True`。

`&&`和`||`运算符的优先级并不相同。`&&`的优先级高于`||`，就像乘法`*`和加法`+`一样。因此，表达式`True || False && False`等价于`True || (False && False)`，这与`(True || False) && False`不同。前者返回`True`，后者返回`False`。

## 条件分支

布尔值非常适合用来在代码中创建分支，这些分支只有在满足特定条件时才会执行。在 Elm 中，这通过`if-then-else`表达式实现，用法如下。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```

`someCondition`可以是任何返回`Bool`的表达式。如果这个布尔值是`True`，代码就会执行`doSomething`。否则它就是`False`，代码会执行`doSomethingElse`。和其他一些编程语言不同，`else`分支是必需的。

如果你需要串联多个条件，直接把`if-then-else`表达式串联起来即可。

```elm
if someCondition then
    doSomething
else if someOtherCondition then
    doAnotherThing
else
    doSomethingElse
```
