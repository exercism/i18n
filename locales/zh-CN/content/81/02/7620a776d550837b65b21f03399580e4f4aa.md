# 说明

你是一位热心的观鸟爱好者，一直在记录过去 7 天里有多少只鸟来过你的花园。

你有 6 个任务，它们都和来你花园的鸟的数量有关。

## 1. 查看上周的计数是多少

为了便于比较，你总是把上周计数的副本放在手边，上周的计数是：0、2、5、3、7、8 和 4。实现（_静态_）`BirdCount.LastWeek()` 方法，让它返回上周的计数：

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看今天有多少只鸟来过

实现 `BirdCount.Today()` 方法，返回今天有多少只鸟来过你的花园。这些计数按天排序，第一个元素是最早那天的计数，最后一个元素是今天的计数。

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. 自增今天的计数

实现 `BirdCount.IncrementTodaysCount()` 方法，把今天的计数自增：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. 检查是否有某一天没有鸟来过

实现 `BirdCount.HasDayWithoutBirds()` 方法：如果有某一天没有鸟来过花园，就返回 `true`；否则返回 `false`：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. 计算前若干天来过的鸟的数量

实现 `BirdCount.CountForFirstDays()` 方法，返回从这周开始起有多少只鸟来过你的花园，但只统计从这周开始算起的指定天数。

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. 计算忙碌的天数

有些日子比其他日子更忙碌。如果某一天有 5 只或更多的鸟来过你的花园，那这一天就是忙碌的一天。
实现 `BirdCount.BusyDays()` 方法，返回忙碌的天数：

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
