在这个练习中，你要写一些代码，帮你照着最喜欢的菜谱做出一份美味的千层面。

一共有四个任务，都与烹饪千层面所花的时间有关。

## 1. 定义千层面在烤箱中的预期时间（分钟）

定义函数`expected_minutes_in_oven()`，它不接受任何形参，返回千层面应该在烤箱里待多少分钟。按照菜谱，预期的烤箱时间是 60 分钟。

```r
> expected_minutes_in_oven()
[1] 60
```

## 2. 计算剩余的烤箱时间（分钟）

定义函数`remaining_time_in_minutes`，它把千层面实际已经在烤箱里待的分钟数作为形参，并根据上一个任务中得出的预期烤箱时间，返回千层面还需要在烤箱里继续待多少分钟。

```r
> remaining_time_in_minutes(50)
[1] 10
```

## 3. 计算准备时间（分钟）

定义函数`prep_time_in_minutes()`，它把你在千层面里加的层数作为形参，返回你准备千层面花了多少分钟，假设每一层需要 2 分钟来准备。

```r
> prep_time_in_minutes(2)
[1] 4
```

## 4. 计算已用时间（分钟）

定义函数`elapsed_time_in_minutes`，它接收两个实参：第一个实参是你在千层面里加的层数，第二个形参是千层面已经在烤箱里待的分钟数。这个函数应该返回你烹饪千层面总共花了多少分钟，也就是准备时间（分钟）与千层面此刻已经在烤箱里所花时间的总和。

```r
> elapsed_time_in_minutes(3, 20)
[1] 26
```
