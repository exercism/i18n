# 说明

镇上开了一家新的诗歌俱乐部，你正打算去参加。
因为过去发生过一些状况，俱乐部有一套非常具体的入场规定，你得先掌握它，才能尝试进入。

诗歌俱乐部有两扇门，一扇前门、一扇后门，两扇门都有人把守。
想进去，你需要推算出当天的口令。

口令总是基于一首诗，可以通过两个步骤推出来。

1. 守卫会一次一行地念出这首诗，而你需要用该行中对应的字母来回应。
2. 接着守卫会一次说出你刚才回应过的所有字母，你需要按特定格式把它们写在一张纸上。

具体流程取决于你想进的是哪扇门。

~~~~exercism/note
本练习中的所有字符串都采用 ASCII 编码，并以 NUL 结尾。
也就是说，所有字符都使用 ASCII 编码，每个字符串在遇到 '\0'（NUL 字符，值为 `0`）时结束。
~~~~

~~~~exercism/note
以下是本概念中提到的字符串指令：

| 指令   | 作用                                                                                          |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | 将`rsi`指向的内存位置中的值加载到`rax`                                                |
| `stos`       | 将`rax`中的值存储到`rdi`指向的内存位置                                               |
| `movs`       | 从`rsi`指向的内存位置复制一个值，并存储到`rdi`指向的内存位置    |

它们都必须带一个后缀，用来指明操作的大小：

| 后缀 | 大小             |
|--------|------------------|
| `b`    | 字节             |
| `w`    | 字（2 字节）   |
| `d`    | 双字（4 字节）  |
| `q`    | 四字（8 字节）  |

所有字符串指令还会修改`rsi`和/或`rdi`中的地址（仅限于该指令用到的那些寄存器）。
默认情况下，它们会按操作的大小递增这些地址。

可以在上述任意字符串指令前加上`rep`前缀，让它重复执行，重复次数等于`rcx`。
~~~~

## 1. 获取一句话的第一个字母

要确定前门口令所需的字母，你需要用守卫念给你的那行诗的第一个字母来回应。

为了得到漂亮的口令，诗歌俱乐部的成员喜欢使用_藏头诗_。
也就是说，每句话的第一个字母能拼成一个单词。
下面是他们最喜欢的作家之一 Michael Lockwood 写的一个例子。

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

所以当守卫念出**Stands so high**时，你要回应**S**；当守卫念出**Huge hooves too**时，你要回应**H**。

实现函数`front_door_response`，它以诗句在内存中的地址作为形参，并返回该行的第一个字母。
这个字母必须以 ASCII 编码的字符形式返回，占 1 个字节。

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. 把单词首字母大写

现在你已经拿到了所有正确的字母，接下来只要把单词的首字母正确大写，就能得到前门口令。

实现函数`front_door_password`，它以任务 1 中找到的那些字母拼成的字符串在内存中的地址作为形参。
它应该[原地][in-place]修改输入字符串，使首字母正确大写。
也就是说，正确的字符串应该存储在与输入相同的内存位置。

这个函数没有返回值。

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. 获取一句话的最后一个字母

要确定后门口令所需的字母，你需要用守卫念给你的那行诗的最后一个字母来回应。

诗歌俱乐部的成员真的很聪明。
前面提到的那首诗同时也是_藏尾诗_，也就是说，每句话的最后一个字母也能拼成一个单词：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

当守卫念出**Stands so high**时，你要回应**h**；当守卫念出**Huge hooves too**时，你要回应**o**。

注意，守卫念诗时有时会做一些风格上的停顿（用标点或空白表示）。
你需要忽略这些停顿，才能推出正确的字母。

实现函数`back_door_response`，它以诗句在内存中的地址作为形参，并返回该行的最后一个字母。
这个字母必须以 ASCII 编码的字符形式返回，占 1 个字节。

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. 保持礼貌

想从后门进入诗歌俱乐部，你需要格外有礼貌。
所以这一次，要推出后门口令，你需要把单词的首字母正确大写，并在末尾加上`", please."`。

实现函数`back_door_password`，它按以下顺序接受形参：

1. 用于存放结果字符串的缓冲区在内存中的地址。
2. 任务 3 中找到的那些字母拼成的字符串在内存中的地址。

这个函数应该把大写后的口令的礼貌版本存到[缓冲区][buffer]中。
_缓冲区_是一个数组，可以用来在内存中存储值，以便在不同函数之间传递它们。

这个函数没有返回值。

```c
back_door_password("horse");
// => "Horse, please."
```

[in-place]: https://en.wikipedia.org/wiki/In-place_algorithm
[buffer]: https://en.wikipedia.org/wiki/Data_buffer
