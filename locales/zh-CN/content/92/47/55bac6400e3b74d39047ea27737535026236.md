# 说明

镇上新开了一家诗歌俱乐部，你正想着要不要去。
因为以前出过一些事，俱乐部有一套非常特别的进门规定，你得先掌握它，才能尝试入场。

诗歌俱乐部有两扇门，都有人把守。
想进去，你得破解出当天的密码：

## 1. 把字符串拆分成单独的行

你要做的第一件事，是把这首诗拆分成单独的行。
守卫会念出一首诗，你要把它拆成若干行。

实现函数`splitOnNewlines`，它接收一个字符串，以换行符为分隔符，把它拆分成一个字符串数组。
函数应返回一个字符串数组，其中每个字符串都是诗中的一行。

```swift
splitOnNewlines("Hello.\nHow are you?\n\nI'm doing fine.")
// returns ["Hello." ,"How are you?", "", "I'm doing fine"].
```

## 2. 前门

1. 守卫会念出一首诗
2. 你要把这首诗拆分成单独的行。
3. 你要取出每一行的首字母。
   - 如果这一行是空的，就用`_`代替。
4. 你要把这些字母拼起来，组成一个单词。

比如，他们最喜欢的作家之一是 Michael Lockwood，他写过下面这首_藏头诗_，也就是说每句的首字母能拼成一个单词：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

守卫念出这首诗时，你要把它拆分成单独的行，然后回答每一行的首字母，也就是`["S", "H", "I", "R", "E"]`。

然后守卫会把你回答的字母数组所拼成的单词给你，让你把它变成首字母大写的单词形式。
最后你返回的密码是`"SHIRE"`，你就能进去了。

实现函数`frontDoorPassword`，它接收一个表示这首诗的字符串。
函数应返回你要告诉守卫的密码。

```swift
frontDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "SHIRE"
```

## 3. 后门

在俱乐部后面，你能见到最著名的诗人，那里就像 VIP 专区。
因为不是谁都能进，后门的流程要绕一些。

1. 守卫会念出一首诗。
2. 你要把这首诗拆成若干行。
3. 你要取出每一行的末字母。
   - 有的行末尾会带空格，所以你需要把它们去掉。
4. 你要把这些字母拼起来，然后在拼成的单词末尾加上`", please"`。

比如，前面提到的那首诗也是_藏尾诗_，也就是说每句的末字母能拼成一个单词：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

守卫念出这首诗时，你要把它拆分成单独的行，去掉末尾的空格，然后回答每一行的首字母，也就是`["h", "o", "r", "s", "e"]`。

然后守卫会把你回答的字母数组所拼成的单词给你，让你把它变成首字母大写的单词形式，并加上`", please"`。
最后你返回的密码是`"horse, please"`，你就能进去了。

实现函数`backDoorPassword`，它接收一个表示这首诗的字符串。
函数应返回你要告诉守卫的密码。

```swift
backDoorPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nReins and harness\nEager to leave")
// returns "horse, please"
```

## 4. 密室

俱乐部后室里还有一扇门，通向密室，只有最顶尖的诗人才能进入。

1. 守卫会念出一首诗。
2. 你要把这首诗拆成若干行。
3. 你要取出第 i<sup>th</sup> 行的第 i<sup>th</sup> 个字母。 
4. 你要把这些字母拼起来，然后在拼成的单词末尾加上`"!"`。
5. 你要把这个单词变成大写形式。

比如，前面提到的那首诗稍作修改后，就符合这个规律：

```text
Stands so high
Huge hooves too
Impatiently waits for
Rider with harness
Eager to leave
```

守卫念出这首诗时，你要把它拆分成单独的行，去掉末尾的空格，然后回答每一行的第 i<sup>th</sup> 个字母，也就是 ["S", "u", "p", "e", "r"]。

然后守卫会把你回答的字母数组所拼成的单词给你，让你把它变成大写形式，并加上`"!"`。
最后你返回的密码是`SUPER!`，你就能进去了。

实现函数`secretRoomPassword`，它接收一个表示这首诗的字符串。
函数应返回你要告诉守卫的密码。

```swift
secretRoomPassword("Stands so high\nHuge hooves too\nImpatiently waits for\nRider with harness\nEager to leave")
// returns "SUPER!"
```
