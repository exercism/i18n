# 说明

在这个练习中，你将使用 Cairo 的控制流结构，帮助管理一家小面包店的日常运营。

## 1. 计算订单总价

实现 `calculate_total`，根据糕点类型和数量计算订单的费用：

- 羊角面包：每个 3 枚金币
- 松饼：每个 2 枚金币
- 曲奇：每个 1 枚金币

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. 应用批量折扣

实现 `apply_discount`，根据订单总额应用折扣。
先把百分比折扣应用到总额上，再向下取整到最接近的整数金币（floor）。

- 订单 ≥ 20 金币：10% 折扣
- 订单 ≥ 10 金币：5% 折扣
- 订单 < 10 金币：无折扣

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. 创建烘焙计划

实现 `baking_schedule`，创建一份每日烘焙计划。
面包店每小时按 5 个订单为一批进行烘焙：

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

请使用合适的控制流结构（`if`/`else`、`loop`），高效地解决每个问题。
