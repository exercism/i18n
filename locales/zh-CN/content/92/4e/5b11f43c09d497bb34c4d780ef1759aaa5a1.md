# 说明补充

## Roc 与宿主的职责

在 Roc 代码中，我们通常只关注业务逻辑，而由平台负责并发和共享状态。因此，在本练习中你只需要在`BankAccount.roc`中实现账户操作，不必操心并发。账户初始状态为关闭，重新开启会重置余额，存款和取款金额都必须是正数。

## 可选的服务器演示

附带的`bank-account-demo.roc`展示了如何把你的实现用在一个小型 Web 服务里。你可以在编辑器中阅读它，但它与测试无关，也不属于你要提交的解答。

要运行演示程序，你需要先在机器上[安装 Roc](https://www.roc-lang.org/install/)、安装 [Exercism CLI](https://exercism.org/cli-walkthrough)，然后在终端中运行这条命令：

```sh
exercism download --exercise=bank-account --track=roc
```

接下来，实现`BankAccount.roc`，并用下面的命令测试它（如果 CLI 打印的下载位置与下面的路径不同，请相应替换）：

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

等所有测试都通过后，就可以用下面的命令启动演示服务器：

```sh
roc bank-account-demo.roc
```

服务器使用 [basic-webserver 平台](https://github.com/roc-lang/basic-webserver)及其内置的 SQLite 支持（Roc 会在第一次运行时下载该平台）。不需要单独的数据库服务器。服务器监听`http://127.0.0.1:8000`，并在当前目录下创建`bank-account-demo.db`（把`DB_PATH`设为别的值即可使用不同的数据库文件）。按 Ctrl-C 停止服务器。数据在重启后仍然存在。

在另一个终端里，你可以用`curl`调用这个 Web 服务（在 Windows 上请一律使用`curl.exe`，以避开 PowerShell 的`curl`别名）。例如，下面演示如何开启 123 号账户、存入 50、取出 10，并查询其余额：

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

余额是`40`。账户 ID 和金额必须是无符号整数。更新成功时返回`OK`，失败时返回你的账户实现给出的错误。要关闭 123 号账户：

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

想在 Linux/macOS 上试试并发请求，可以用一个新的账户 ID，从 8 个客户端发送 100 笔存款：

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

在 Windows 上，请使用 [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows)来运行这个并行示例：

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

这些存款应该全部成功，余额应该是`100`。

## 演示程序如何处理并发

每个请求都会读取账户、调用你的 Roc 函数，并在一个 SQLite `Immediate`事务中保存结果。失败的操作会回滚，不会改动账户。SQLite 一次只允许一个写入者，因此并发请求不会互相覆盖更新（即使涉及不同的账户）。

注意：本练习使用`U64`，但演示程序把余额存为 SQLite 整数，并会拒绝超过`I64`最大值（`9223372036854775807`）的更新。

想看并行运行相互独立的计算的例子，可以试试[并行字母频率练习](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency)。
