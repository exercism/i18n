# 布尔类型

在 Cairo 中，布尔类型对于逻辑运算和条件语句来说必不可少。Cairo 中的布尔值大小为 1 个`felt252`，既能高效利用空间，又保持了 true/false 逻辑的简洁性。

Cairo 中的布尔类型使用关键字 `bool` 来指定。这样就可以在语言中声明和操作布尔变量。例如：

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

在这个例子中，声明了 2 个布尔变量。变量 `t` 被赋值为 `true`，并隐式声明为布尔类型；变量 `f` 则显式标注了 `bool` 类型，并被赋值为 `false`。

有一点很重要：在 Cairo 中声明布尔变量时，必须使用 `true` 或 `false` 字面量作为值。这意味着整数子面量，例如 `0` 或 `1`，不能用来代替 `false` 或 `true`。严格执行这条规则能保证类型安全，避免智能合约开发中出现潜在的逻辑错误。

## Cairo 中的布尔运算符

- `||`（逻辑或）：只要有一个操作数是 `true`，就返回 `true`。
- `&&`（逻辑与）：两个操作数都为 `true` 时才返回 `true`。
- `!`（逻辑非）：返回与操作数相反的布尔值。

## 示例代码

下面的代码片段演示了如何在 Cairo 中使用布尔类型。它展示了布尔变量的声明、布尔表达式的赋值，以及如何使用断言来验证布尔逻辑的正确性：

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
