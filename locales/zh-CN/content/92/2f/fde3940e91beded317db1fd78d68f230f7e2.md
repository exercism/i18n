# 说明

你在海岸边的无线电小屋值守，监听着频道里的通话：消息顺着线路传来，你把它们记录下来，再把回复发出去。一班岗的活儿，五个小词就能搞定。

测试会传给你`<string-reader>`作为输入（进来的消息），发出去的部分则用`<string-writer>`，不过这里的每个词，换成真正的`<file-reader>`或套接字，用法也一样。

## 1. 全部听完

定义`hear-out`，把输入流里的内容全部读出来，汇成一个字符串。

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. 统计消息条数

定义`count-messages`，从输入流中读取每一行，返回一共有多少行。

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. 回传最后一次呼叫

定义`echo-back`，读取每一行，返回**转为大写的那最后一行**，也就是无线电里标准的“你刚才说的是 X”式回复。

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. 广播一条消息

定义`broadcast`，把消息写入给定的写入器，并刷新流，让它立刻发出去。没有返回值。

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. 捕获引用的输出

定义`capture`，用一个全新的 string-writer 作为环境输出流来运行一个引用，并返回该引用打印出来的内容。引用不接收任何参数，只是照常写入环境流。

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
