# 说明

你又回来继续开发在[exercise:csharp/object-relational-mapping]()中介绍过的 ORM（对象关系映射）系统了。

我们对 ORM 的使用情况分析显示，95% 的事务都是在同一个调用方法内部执行的，因此我们决定，改用单个 ORM 方法来开启、写入并提交事务会更合适。

该数据库有以下实例方法：

- `Database.BeginTransaction()`开启数据库上的一个事务。
- `Database.Write(string data)`在事务中把数据写入数据库。如果收到无效数据，就会抛出异常。如果在尚未调用`BeginTransaction()`的情况下尝试调用这个方法，也会抛出异常。如果成功，数据库的内部状态会变为`DataWritten`。
- `Database.EndTransaction()`把事务提交到数据库。如果无法关闭事务，或者之前没有调用过`Database.BeginTransaction()`，它可能会抛出异常。
- 如果事务期间抛出异常，调用`Database.Dispose()`会清理数据库。这会把数据库的状态变为`Closed`。

## 1. 写入数据库

实现`Orm.Write()`方法，开启一个数据库事务，写入传入的数据，然后提交事务。所有异常，包括`InvalidOperationException`，都应原样传递给调用方，不要记录日志，也不要进行任何其他干预。

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.Write("good write");
// => database has an internal state of State.Closed
orm.Write("bad write");
// => an exception is thrown but database is left with an internal state of State.Closed
orm.Write("bad commit");
// => an exception is thrown but database is left with an internal state of State.Closed
```

## 2. 写入数据库，并告知调用方写入是否成功

`Orm.Write()`推出已经几个月了，团队内部出现了分歧。许多开发者希望 _ORM_ 在抛出异常时处理错误，并直接向调用方返回一个成功与否的指示。

请实现`Orm.WriteSafely()`方法，开启一个数据库事务，写入传入的数据并提交事务（同上）。如果*写入*成功，它应返回`true`，否则返回`false`。不要尝试记录异常日志。

```csharp
Database db = new Database();
Orm orm = new Orm(db);
orm.WriteSafely("good write");
// => true
orm.WriteSafely("bad write");
// => false
orm.WriteSafely("bad commit");
// => false
```
