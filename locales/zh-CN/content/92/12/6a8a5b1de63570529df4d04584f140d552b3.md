# 补充说明

## 初始代码

`src/TreeBuilding.hs`里已经包含一个能通过所有测试的可用实现。它运行缓慢，而且难以阅读；你的任务是在不让测试失败的前提下改进它。

当记录无法构成一棵有效的树时，`buildTree`返回`Nothing`。

## 更改表示方式

测试从不直接使用`Tree`的构造器。相反，它们用下面这个函数构建预期的树：

```haskell
node :: Int -> [Tree] -> Tree
```

其中，`node i children`是 id 为`i`、子节点为给定列表的节点，子节点按 id 升序排列。

这意味着你可以自由更改`Tree`的表示方式，例如改成：

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

只要`Tree`仍然有`Eq`和`Show`实例，并且`node`保持其含义即可。如果你使用`containers`之类的库，记得把它添加到`package.yaml`的`dependencies`中。
