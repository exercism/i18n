# 说明

在这个练习中，你需要把经典游戏 Pac-Man 中的一些规则翻译成 Gleam 函数。

你有 4 条规则要翻译，它们都与游戏状态有关。

> 不用担心实参是怎么来的，只需专注于把实参组合起来，返回预期的结果。

## 1. 定义吃豆人是否能吃掉幽灵

定义 `eat_ghost` 函数，它接收 2 个实参（_吃豆人是否有能量丸处于生效状态_和_吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否能吃掉幽灵。只有当吃豆人能量丸处于生效状态且碰到幽灵时，函数才应返回 `True`。

```gleam
eat_ghost(False, True)
// -> False
```

## 2. 定义吃豆人是否得分

定义 `score` 函数，它接收 2 个实参（_吃豆人是否碰到能量丸_和_吃豆人是否碰到豆子_），并返回一个布尔值，表示吃豆人是否得分。只要吃豆人碰到能量丸或豆子，函数就应返回 `True`。

```gleam
score(True, True)
// -> True
```

## 3. 定义吃豆人是否失败

定义 `lose` 函数，它接收 2 个实参（_吃豆人是否有能量丸处于生效状态_和_吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否失败。如果吃豆人碰到幽灵，并且没有能量丸处于生效状态，函数应返回 `True`。

```gleam
lose(False, True)
// -> True
```

## 4. 定义吃豆人是否获胜

定义 `win` 函数，它接收 3 个实参（_吃豆人是否吃掉了所有的豆子_、_吃豆人是否有能量丸处于生效状态_和_吃豆人是否碰到幽灵_），并返回一个布尔值，表示吃豆人是否获胜。如果吃豆人吃掉了所有的豆子，并且根据第 3 部分中定义的实参判断没有失败，函数应返回 `True`。

```gleam
win(False, True, False)
// -> False
```
