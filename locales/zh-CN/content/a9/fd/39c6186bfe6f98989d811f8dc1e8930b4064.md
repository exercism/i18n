# 提示

## 通用

- [结构体和类][structs-and-classes]的定义语法很相似。

## 1. 定义 Size 结构体

- 如果属性可以被修改，就必须用`var`定义。
- height 和 width 属性应分别设置默认值为 80 和 60。
- 如果方法会修改结构体的属性，就必须标记为`mutating`。

## 2. 定义 Position 结构体

- 如果属性可以被修改，就必须用`var`定义。
- x 和 y 属性应设置默认值为 0。
- 如果方法会修改结构体的属性，就必须标记为`mutating`。

## 3. 定义 Window 类

- 使用[逐一成员初始化器][memberwise-initializers]，可以用不同的属性值初始化结构体。
- 常量属性应该用`let`定义。
- `contents`属性应该是可选的，因为它可能没有值。
- 你必须为这个类定义一个空的初始化器（`init() {}`）。

## 4. 添加一个调整窗口大小的方法

- 这个方法应该接收一个类型为`Size`的形参`to`。
- 可以用点语法从`to`形参中取出 width 和 height。

## 5. 添加一个移动窗口的方法

- 这个方法应该接收一个类型为`Position`的形参`to`。
- 可以用点语法从`to`形参中取出 x 和 y。

## 6. 添加一个设置窗口内容的方法

- 在 Swift 中，可以有两个同名但形参不同的方法。
- 定义一个带形参`title`的方法，用来设置`title`属性。
- 定义一个带形参`text`的方法，用来设置`contents`属性。
- 定义一个显示方法，用来打印窗口的 title 和 contents。

## 7. 为 Window 类创建初始化器

- 这个类应该有两个初始化器，一个不接收任何形参，一个接收形参。
- 新的初始化器应该有形参`title`和`contents`，还应该允许可选形参`size`和`position`
    如果没有提供形参，就使用默认值。
- 可选形参可以通过[默认形参值][default-parameters-vales]来实现。
