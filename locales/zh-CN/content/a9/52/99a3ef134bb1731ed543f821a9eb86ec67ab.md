# 引言

`|>`运算符称为管道运算符。它可以把多个函数调用串联起来，让上一个函数调用返回的值传给下一个函数调用。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上面的代码等价于下面这段：

```gleam
string.append(string.uppercase("hello"), "?!")
```

管道运算符会把值作为函数调用的第一个实参传入，或者作为新调用的唯一实参传入，具体取决于哪种方式能得到正确的类型。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

有时我们想把值传到另一个位置，这时可以用`_`占位符来指明值应该插入到哪里。

```gleam
100
|> some_function(1, _, 2)
```
