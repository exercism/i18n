# 简介

`switch()`函数可以简洁地取代一长串`if`……`else if`判断。用作`switch`判断的变量通常是字符串，这时选择器中的引号可以省略。

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

注意，只有在值留空时，选项才会向下贯穿，就像上面例子中的`M`一样。不需要像其他一些语言那样写`break`语句。

当对`character`类型进行切换时，最后一个值是默认值，就像这里这样。而对于整数类型，则不能指定默认值。

## `dplyr`中的函数

基础 R 中的`switch`相当有限：它只能对单个输入进行精确匹配。这在 1993 年 R 首次发布时看似合理，但对现代使用来说需要改进。

只要在代码开头加上`library(dplyr)`（加载单个包）或`library(tidyverse)`（加载整个包集合），就可以把`dplyr`包引入作用域。

`dplyr`包提供了两个与`switch`相关的额外函数。

### `recode_values`和`replace_values`函数

这两个相关的函数支持以向量化的、类似 switch 的方式将旧值映射到新值。

两者的主要区别在于：`recode_values()`会创建一个全新的向量，而`replace_values()`允许对已有向量进行部分更新。

匹配仍然是精确匹配，但是：

- 左侧的选项可以是向量，只要其中任一元素匹配，输入就算匹配。
- 左侧的选项和右侧的结果用波浪号`~`连接，而不是用`=`。
- 在所有情况下都可以指定默认值。

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when`函数

`case_when`把`case_match`语法又推进了一步，允许在`~`左侧使用任何逻辑表达式。

输入向量（下面例子中的`x`）不作为实参传入，它只需要已经定义好即可。

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()`函数也是`dplyr`的一部分。
