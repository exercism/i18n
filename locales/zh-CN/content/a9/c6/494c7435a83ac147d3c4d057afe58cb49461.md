# 说明

玛丽是电视剧 _Star Trek: The Next Generation_ 的超级粉丝。她经常玩纸笔角色扮演游戏，在游戏里，她和朋友们会假扮成 _Starship Enterprise_ 的船员。

玛丽扮演的是皮卡德舰长，所以她得负责记录舰长日志。她很喜欢游戏里需要发挥创意的部分，却不喜欢临场编造随机数据。

来帮帮玛丽吧，为舰长日志里常见的数据写几个随机生成器。

## 1. 随机生成行星

_Starship Enterprise_ 在航行途中会遇到许多行星。在 Star Trek 的世界里，行星会根据自身的属性被划分成不同的类别。比如，地球就是一颗 M 级行星。所有可能的行星等级有：D、H、J、K、L、M、N、R、T 和 Y。

实现`random_planet_class`函数。它应该以向量的形式，随机返回所需数量的行星等级。允许出现重复的等级，而且向量较长时可能就需要重复。

```R
random_planet_class(number_needed)
#> "K"
```

### 2. 随机生成星舰注册号

Enterprise（注册号 NCC-1701）并不是唯一在飞的星舰！当它与其他星舰会合时，玛丽需要记录那艘星舰的注册号。

注册号以“NCC-”前缀开头，后面跟一个 1000 到 9999（含）之间的数字。

实现`random_ship_registry_number`函数，让它返回一个随机的星舰注册号。

```R
random_ship_registry_number()
#> "NCC-1947"
```

## 3. 随机打乱一支星舰舰队

游戏有一个版本需要与其他星舰互动，玛丽得从中挑选一些。

可能出现的星舰有一整份清单，但每局游戏只需要其中几艘，而且应该随机挑选。

实现`shuffle_starships(starships)`函数，它接收一个由互不重复的星舰注册号组成的向量，返回一个长度相同、但星舰顺序被打乱的向量。这样玛丽就能轻松地从向量开头随机取出任意数量的星舰。

结果中的值都应取自`starships`，且不能有重复。

```R
shuffle_starships(c("NCC-5011", "NCC-1228", "NCC-7039", "NCC-3978", "NCC-1476"))
#> [1] "NCC-1476" "NCC-7039" "NCC-3978" "NCC-5011" "NCC-1228"
```

## 4. 随机生成星历

日志里要是没有日期，那还有什么用？

星历是一个浮点数。_The Next Generation_ 第一季中 _Starship Enterprise_ 的冒险发生在星历 41000.0 到 42000.0 之间。“4”代表 24 世纪，“1”代表第一季。

实现`random_stardate`函数，返回一个介于 41000.0 和 42000.0 之间的浮点数。

```R
random_stardate()
#> 41037.6
```
