# 关于

你可以让自己定义的类和结构体使用主要的算术运算符和比较运算符。这称为*运算符重载*。

这篇[文章][operator-overloading]详细讨论了相关语法，以及哪些运算符可以重载、哪些不可以。

大多数运算符的形式如下：

```csharp
static <return type> operaator <operator symbols>(<parameters>);
```

[强制转换运算符][ud-conversion-operators]的形式如下：

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

运算符的行为与静态方法相同。

- 运算符符号代替方法标识符，并且同样有形参和返回类型。形参和返回类型的类型规则符合你的直觉，你也可以依靠编译器给出详细的提示。
- 对于二元运算，第一个形参接收运算左侧的实参。
- 运算符的签名包含两个形参（二元运算符的情况）和一个返回类型，一元运算符则包含一个形参和一个返回类型。
- 对于二元运算符，其中一个形参的类型必须是声明该运算符的类的类型。
- 对于类型转换，形参或返回类型中必须有一个是声明类的类型。
- 对于自增和自减运算符，形参和返回类型都必须是声明类的类型。

语法示例：

```csharp
struct Point
{
    decimal x;
    decimal y;

    public static bool operator ==(Point pt, Point ptOther)
    {
        return pt.x == ptOther.x && pt.y == ptOther.y;
    }

    public static bool operator !=(Point pt, Point ptOther)
    {
        return !(pt == ptOther);
    }

    public static Point operator *(Point pt, decimal scale)
    {
        var ptNew = new Point();
        ptNew.x = pt.x * scale;
        ptNew.y = pt.y * scale;
        return ptNew;
    }

    public static implicit operator Point((decimal x, decimal y) xy)
    {
        var pt = new Point();
        pt.x = xy.x;
        pt.y = xy.y;
        return pt;
    }

    public static explicit operator (decimal x, decimal y)(Point pt)
    {
        return (pt.x, pt.y);
    }
}
```

通常，实现一个 [`Equals()`][equals] 方法并在 `==`运算符中调用它很有用。同样，对于比较，你可以实现 [`IComparable`][icomparable]接口。这两种情况下，你都能用略超过一块的石头打下两只鸟。

请注意，不能用不属于标准运算符集合的符号创建运算符。只有文档说明可以重载的运算，你才能用已有的符号来实现。可以重载的运算符列在[这里][overloadable-operators]。

注意，当形参类型不同时，形参的顺序很重要。在上面的示例代码中，`pt * 10m`是合法的表达式，而 `10m * pt`将无法编译。
