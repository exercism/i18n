# 简介

Factor 中的字符串是字符序列。[`sequences`][sequences]词汇表中的大多数单词都能作用于字符串，此外还有 [`splitting`][splitting]、[`ascii`][ascii]等词汇表中专门处理字符串的单词。

## 字符串字面量

字符串用双引号书写。常见的转义都支持：`\n`、`\t`、`\r`、`\\`、`\"`：

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## 长度与下标

因为字符串是序列，[`sequences`][sequences]词汇表中的`length`和`nth`等单词可以直接作用于它。

`length`返回字符的数量：

```factor
"hello" length .    ! => 5
```

`nth`接受一个从 0 开始的下标和序列，返回该位置上的元素。对于字符串来说，元素是一个*字符*，也就是一个码点（一个整数），而不是长度为 1 的子字符串：

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## 从字符回到字符串

要把单个码点变成只含一个字符的字符串，可以使用 [`strings`][strings]词汇表中的`1string ( char -- str )`。`CHAR:`是字面量码点在解析期的写法：

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## 拆分

[`splitting`][splitting]词汇表能把字符串切成若干片段。

`split1`在分隔符*第一次*出现的位置切开，返回前后两部分：

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split`按分隔符集合中*任意*一个字符切开，可能产生空片段：

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest`（位于[`sequences`][sequences]中）会丢弃空片段：

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## 取出某个片段

字符串被拆分成由片段组成的数组后，`first`、`second`、`third`和`fourth`（位于[`sequences`][sequences]中）会返回对应位置上的片段：

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

如果想一次把所有开头的片段都放到栈上，`first2`和`first3`可以一步取出两个或三个：

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

直接对字符串使用时，`first`返回的是第一个**字符**，也就是一个码点，而不是子字符串：

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## 去除空白

`[ blank? ] trim`（来自[`sequences`][sequences]，其中的`blank?`来自[`ascii`][ascii]词汇表）会去除首尾空白：

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## 大小写转换

`>lower`和`>upper`（来自[`ascii`][ascii]）会返回一个改变了大小写的新字符串：

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## 连接

[`sequences`][sequences]词汇表中的两个单词可以拼装字符串：

`surround`用前缀和后缀把字符串包起来：

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue`用分隔符把两个字符串连起来：

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
