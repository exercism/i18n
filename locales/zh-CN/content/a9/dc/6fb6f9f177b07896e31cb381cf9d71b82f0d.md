# 说明补充

## 项目结构

Exercism 上的 Clojure 练习使用 [leiningen](http://leiningen.org/) 来配置和运行你的代码，并采用 [leiningen 标准目录结构](https://github.com/technomancy/leiningen/blob/master/doc/TUTORIAL.md#directory-layout)。

你会在 `test` 目录里找到一个名为 `hello_world_test.clj` 的测试文件。
把代码写在 `src/hello_world.clj` 中。它需要使用命名空间 `hello-world`，这样测试才能找到它。

## 运行测试

用 `lein test` 命令运行测试，并让它们通过：

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

然后用下面的命令提交练习：

```
$ exercism submit src/hello_world.clj
```

更详细的说明和学习资源请参考 [Exercism 的 Clojure 语言页面](http://exercism.io/languages/clojure)。
