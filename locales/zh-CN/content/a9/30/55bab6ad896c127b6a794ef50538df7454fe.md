# 关于

Haxe 中的迭代器用于配合`for`循环遍历一个值。迭代器分为两种：

- `Iterator`：用于遍历一个值。
- `Iterable`数据：让某种数据类型可以被遍历。

这两个概念分别由`Iterator<T>`和`Iterable<T>`表示：

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

任何能与这两种类型之一统一的类，都可以用`for`循环遍历。如果一个类定义了`hasNext`和`next`方法，它就被视为迭代器；否则，如果它定义了`iterator`方法，就被视为可迭代类型：

```haxe
class MyStringIterator {
  var str:String;
  var i:Int;

  public function new(str:String) {
    this.str = str;
    i = 0;
  }

  public function hasNext():Bool {
    return i < str.length;
  }

  public function next():String {
    return str.charAt(i++);
  }
}
```

在上面的例子中，`MyStringIterator`类同时实现了`hasNext`和`next`方法，因此被视为迭代器，可以和`Iterator<String>`兼容。

```haxe
class MyArrayWrap<T> {
  var arr:Array<T>;

  public function new(a:Array<T>) {
    this.a = a;
  }

  public function iterator() {
    return a.iterator();
  }
}
```

这里，`MyArrayWrap`类与`Iterable<Array<T>>`兼容，因此被视为可迭代数据类型。
