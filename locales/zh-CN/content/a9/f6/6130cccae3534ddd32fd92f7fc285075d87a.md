# 关于

Elm 是一门令人愉悦的语言，用来构建可靠的 Web 应用。
它有友好的错误信息、出色的性能、很小的打包体积，不会出现运行时异常。

Elm 最出名、被借鉴最多的部分，大概要数 The Elm Architecture。它是一种组织 Web 应用结构的简单模式，所有 Elm Web 应用都是按照它来写的。

核心思想是，你的代码围绕这么几样东西构建：表示应用状态的`Model`、更新模型的`update`，以及展示模型的`view`。

`Model`包含应用的状态，也就是应用需要的所有数据。
想象一个简单的应用：它有一个文本框，还有一段文字显示这段文本的反转结果。它的模型就像下面这样。
你也可以在 [Elm 指南][elm-guide-text-fields] 里看到这个例子。

```elm
type alias Model =
  { text : String
  }
```

`update`是一个函数，当发生变化（比如用户点击按钮）时，它会被调用，并接收一个`Msg`。
它接收`Msg`和当前的`Model`，然后返回一个新的`Model`。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view`是一个函数，返回在浏览器中展示给用户的 HTML。
它接收当前的`Model`，返回一个`Html Msg`（Elm 用来表示 HTML 的类型）。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
