# 简介

## 数组

在 Ruby 中，**数组**是有序的、以整数为下标的集合，可以存放任意对象。
数组下标从`0`开始。
负下标相对于数组末尾计数，例如下标`-1`表示数组的最后一个元素，`-2`表示倒数第二个元素，以此类推。

### 创建数组

数组通常使用`[]`表示法创建。
数组可以包含各种不同类型的对象。

```ruby
array = [1, "two", 3.0]
```

### 元素引用

数组中的元素可以通过下标用`#[]`方法获取。
它会返回该下标处的元素，或者返回一个子数组：从起始下标开始，持续指定的长度。
负下标从数组末尾向前计数。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]       #=> "c"
a[6]       #=> nil
a[1, 3]    #=> [ "b", "c", "d" ]

a[-1]      #=> "e"
a[-2]      #=> "d"
a[-3, 2]   #=> ["c", "d"]
```

### 辅助方法

数组上有很多好用的辅助方法。
以下是一些比较常见的：

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.size      #=> 8
fibonacci.sum       #=> 33
fibonacci.reverse   #=> [13, 8, 5, 3, 2, 1, 1, 0]
```

## 枚举

在 Ruby 中，我们不用循环来遍历集合，而是使用枚举。

枚举是指遍历一个集合（这里是数组），并对其中每个对象执行某种操作。枚举是 Ruby 中的核心概念，排序、分组、映射、归约等操作都要用到它。

一个打印数组中每个单词的枚举如下所示：

```ruby
words = ["the", "cat", "sat"]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
```

在这个例子中，我们在数组上调用了`.each`方法，并传入一个_块_，它接收一个形参（`word`）并把它打印出来。

在后续的学习中，我们会更深入地学习_块_，现在你可以把它们看作可以接收零个或多个实参的匿名函数。
它们可以用`do...end`语法（如上）或`{}`语法（如下）来定义。

下面是另外一些使用块的数组方法示例：

```ruby
fibonacci = [0, 1, 1, 2, 3, 5, 8, 13]

fibonacci.count  { |number| number == 1 }   #=> 2
fibonacci.any?   { |number| number == 6 }   #=> false
fibonacci.select { |number| number.odd? }   #=> [1, 1, 3, 5, 13]
fibonacci.all?   { |number| number < 20 }   #=> true
fibonacci.map    { |number| number * 2  }   #=> [0, 2, 2, 4, 6, 10, 16, 26]
```
