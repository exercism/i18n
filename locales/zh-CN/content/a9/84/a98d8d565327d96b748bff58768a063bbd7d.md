# 学习

与 Perl、Tcl、Python 等类似语言相比，Rexx 编程语言非常容易学习。这得益于它简单的语法、类英语的指令和极简的本质。

Rexx 的学习资源非常丰富，但大多针对大型机上的 Rexx，而且通常更侧重于与平台功能对接，而非深入探讨 Rexx 语言本身的特性。一个典型的例子是：[REXX Tutorial - IBM Mainframer](https://www.ibmmainframer.com/rexx-tutorial/#main)。它很有趣，但对不在大型机上学习的 Rexx 学习者来说，可能并不是理想的资源。

一个更有用、对初学者更友好的 Rexx 学习资源是 [Rexx Tutorial - Tutorials Point](https://www.tutorialspoint.com/rexx/index.htm)。它可以作为快速参考，比如如何执行循环，或查询内置函数的用法。不过它可能会让人困惑，因为它涵盖了一些并不适用的特性，以及各种不同的 Rexx 实现。

## 推荐教程

在作者看来，最有用、也最有趣的 Rexx 教程是 Jeff Glatt 的 [Learn REXX Programming in 56,479 Easy Steps](http://nokix.sourceforge.net/help/learn_rexx/language.htm)。它不仅概述了这门语言，还直观且颇有深度地探讨了各种特性。作为参考工具也很有用。强烈推荐给各种水平的学习者。

## 推荐参考

由于本轨道使用 [Regina](https://regina-rexx.sourceforge.io/index.html) 这一 Rexx 实现，最合适的参考就是随附的文档。它可以在 Regina 发行版的 `docs` 文件夹中找到，也可以直接从 [Regina Documentation](https://sourceforge.net/projects/regina-rexx/files/regina-documentation/3.9.5/regina.pdf) 下载。
