# 关于

[结构体][structs-and-classes]（通常简称为 *struct*）是 Swift 程序的主要构建块之一。结构体让你可以创建自定义类型，把相关的属性（数据）和方法（行为）组合在一起。事实上，Swift 的标准类型，包括`Int`、`Double`、`Bool`、`String`、`Array`和`Dictionary`，都是用结构体实现的。

## 定义结构体

用`struct`关键字定义结构体，后面跟上类型名和包含其定义的一对大括号。按照 Swift 的约定，结构体名采用`UpperCamelCase`命名：

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## 创建实例

结构体定义相当于一张蓝图。要创建结构体的*实例*，就调用它的初始化器，也就是先写类型名，后面加一对括号：

```swift
var someStats = CharacterStats()
```

这会创建一个实例，它的属性值就是定义里设定的默认值。

Swift 还会自动为结构体生成一个**逐成员初始化器**，让你可以按名称初始化各个属性：

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## 访问和修改属性

你可以用*点语法*来访问和修改实例的属性：

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

因为结构体是值类型，所以要修改实例的属性，这个实例本身必须用`var`声明。如果用`let`声明实例，它的所有属性也会变成不可变的。
