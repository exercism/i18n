# 关于

循环是一种成批重复调用一条或多条语句的方式。
每运行一批语句一次，称为一次迭代。

## `while`循环

`while`循环在循环顶部的布尔表达式为真时，成批执行语句。
当布尔表达式为假时，循环停止运行，执行继续到循环之后的下一行代码。

如果布尔表达式一开始就求值为假，`while`循环根本不会运行，执行会直接继续到循环之后的下一行代码。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

循环必须有一个结束条件，这一点很重要；否则它就成了无限循环，代码会因此无法继续推进。
如果把上面的代码中`i`的`++`去掉，它就会变成无限循环。

## `do`循环

`do`循环的布尔表达式在循环底部进行测试。
`do`循环至少会运行一次，如下例所示

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

用`while`循环来写会更加冗长

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for`循环

循环常常会更新一个变量，并在变量达到某个值时结束。
`for`循环是一种在一行括号内初始化、更新和测试一个或多个变量的方式。
第一部分用于初始化变量，第二部分用于测试变量，第三部分用于更新变量的值。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

这比等价的`while`循环更简洁，而且依然易读。

`for`循环的初始化和更新部分可以处理多个变量，方法是使用逗号运算符分隔条件中的各个表达式。

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

这会输出

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

`for`循环的各个部分都不是必须定义的。
空的测试表达式会求值为真，因此可以像下面这样用`for`循环定义一个无限循环

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

这与`while`循环类似：`i`在循环之前初始化，在循环内部自增。
另外，`i`在循环内部接受测试，循环以`break`语句结束。

## `break`语句

有时循环可能需要在一个布尔表达式里没有测试的特殊条件下结束。
`break`语句会结束循环，执行将继续到循环之后的下一行代码。

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

这会输出

```
i is 0
j is 5
After the loop
```

## `continue`语句

有时循环可能需要在没有完成当前迭代的情况下开始下一次迭代。
`continue`语句会停止当前迭代的执行，并在下一次迭代开始时继续执行。

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

这会输出

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

当`i`和`j`都等于`2`时，它不会输出它们的值。
