# 简介

Java 中的数字有两种不同的类型：

- 整数：小数点后没有数字的数（即整数）。
  例如`-6`、`0`、`1`、`25`、`976`和`-500000`。
- 浮点数：小数点后可以有零个或多个数字的数。
  例如`-20.4`、`0.1`、`2.72`、`16.984025`和`1024.0`。

Java 中最常见的两种数值类型是`int`和`double`。
`int`是 32 位整数，`double`是 64 位浮点数。

算术运算使用标准算术运算符完成。
可以使用标准数值比较运算符（例如`5 > 4`和`4 <= 5`）以及相等（`==`）和不等（`!=`）运算符来比较数字。

Java 有两种数值转换：

1. 隐式转换：不会丢失数据，也不需要额外的语法。
2. 显式转换：数据可能会丢失，并且需要额外的语法，即 _强制类型转换_。

由于`int`的精度低于`double`，因此从`int`转换为`double`是安全的，所以属于隐式转换。
不过，从`double`转换为`int`可能会导致数据丢失，因此需要显式转换。
