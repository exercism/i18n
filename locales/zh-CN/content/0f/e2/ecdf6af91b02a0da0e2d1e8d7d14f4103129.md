# 介绍

回想一下，一个`jq`程序就是一条_表达式管线_。
**变量赋值**遵循这样的规则：_变量赋值_是一种表达式，形如：

```jq
... | expr as $varname | ...
```

## 过滤器的输出就是它的输入

和_恒等表达式_`.`一样，_变量赋值_的输出与它的输入相同。
设置变量的值只是一个副作用。

下面的例子表明，赋值之后的`.`与最初的输入相同：

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## 变量的作用域

变量的作用域是“词法”的。在管线的其余部分中，该变量都处于作用域内。
在函数中定义的变量（稍后我们会讲到函数）对函数来说是“局部”的。

## 变量名

变量名必须以`$`开头。
变量名的其余部分是一个**标识符**：以字母或下划线开头，后面跟字母、数字或下划线。

## 解构赋值

手册中写道：

> 只用一个`as`表达式，通过提供一个_与输入结构相匹配_的模式，就可以声明多个变量（这叫做“解构”）。

示例：

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

让变量名与_对象的键_相匹配，可以少写一些代码：

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## 常量

如上面的例子所示，变量很适合用来存放常量。
与其让“魔法数字”出现在代码里，不如给常量起个名字。

## 很多时候并不需要变量

省略变量往往可读性更好。

比如计算一个数字数组的平均值：

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

与下面这种写法相比：

```jq
[2, 4, 8, 7] | add / length
```

这体现了`jq`最强大的特点之一：过滤器的输入会被提供给_每一个_子表达式：

- 输入数组`[2,4,8,7]`被传给`add`（它把`+`运算符应用到所有元素上，从而求出这些数字的和）
- _同时_，`[2,4,8,7]`也被传给`length`
- 这些子表达式完成后，它们的结果再相除，得到输入数组中所有数字的平均值。
