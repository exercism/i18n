使用`+`运算符进行字符串拼接是一种可行的做法，但它可能带来维护和可读性方面的问题。
使用[str.format()][str.format()]方法或[f-strings][f-strings]（_又称“格式化字符串字面量”或“插值字符串”_）可以提供一些选项，既能提高可维护性，也能让字符串中的变量替换更清晰。

博客文章[String Formatting in Python][string formatting in python]是了解 Python 全部字符串格式化选项的一个很好的起点，[Newer Python String Format Techniques][newer python string format techniques]也提供了一些使用`str.format()`和`f-strings`的实用技巧和窍门。
