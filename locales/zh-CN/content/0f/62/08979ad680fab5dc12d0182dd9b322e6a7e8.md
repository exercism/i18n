# 说明补充

## 输入格式

`board`形参代表棋盘，格式为字符串数组。

```javascript
['  B  ', ' B B ', 'B W B', ' W W ', '  W  '];
```

字符串中的每个字符代表一个格子。
格子的有效取值有：

- ` ` 代表空格子的空白字符
- `B` 黑方拥有的格子
- `W` 白方拥有的格子

## 输出格式

`getTerritory`函数应返回一个包含 2 个属性的对象：

- `owner`：领地的所有者（`NONE`、`BLACK` 或 `WHITE`）
- `territory`：由坐标组成的数组，表示领地中的每个格子。

```javascript
{
    owner: 'BLACK',
    territory: [
        [0, 0],
        [0, 1],
        [1, 0],
    ],
}
```

`getTerritories`函数应返回一个包含 3 个属性的对象：

- `territoryBlack`：由坐标组成的数组，表示 `BLACK` 方拥有的领地
- `territoryWhite`：由坐标组成的数组，表示 `WHITE` 方拥有的领地
- `territoryNone`：由坐标组成的数组，表示双方玩家都不拥有的领地

```javascript
{
    territoryBlack: [
        [0, 0],
        [0, 1],
    ],
    territoryWhite: [
        [3, 0],
        [3, 1],
    ],
    territoryNone: [],
}
```
