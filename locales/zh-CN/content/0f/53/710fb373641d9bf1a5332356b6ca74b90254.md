# 说明

你将编写一些代码，帮你照着最喜欢的食谱做一份千层面。

一共有五个任务，都与制作这份食谱的过程有关。

## 1. 定义预期的烘焙时间（分钟）

定义一个`ExpectedBakeTime`常量，返回千层面需要在烤箱里烘焙多少分钟。
根据你的食谱，千层面需要在烤箱里烤 40 分钟：

```powershell
> $ExpectedBakeTime
> 40
```

## 2. 计算剩余的烘焙时间（分钟）

实现`RemainingTime`函数，它接收千层面已经在烤箱里的实际分钟数作为实参，并根据`ExpectedBakeTime`返回千层面还需要烘焙多少分钟。

```powershell
> RemainingTime -Minutes 30
> 10
```

## 3. 计算准备时间（分钟）

实现`PreparationTime`函数，它接收你想往千层面里加的层数作为实参，并返回制作这些层需要多少分钟。
假设每层需要 2 分钟来准备。

```powershell
> PreparationTime -Layers 2
> 4
```

## 4. 计算总共花费的烹饪时间（准备 + 烘焙），单位为分钟

实现`ElapsedTime`函数，它有两个形参：`Layers`（_添加到千层面中的层数_）和`Minutes`（_千层面在烤箱里已经烘焙的分钟数_）。
这个函数应返回你烹饪的总分钟数，也就是准备时间与千层面已经在烤箱中烘焙的时间之和。

```powershell
> ElapsedTime -Layers 3 -Minutes 20
> 26
```

## 5. 创建一条千层面已做好的通知

定义`Notification`函数，它不接收任何实参，并返回一条表示千层面已经可以享用的消息。

```powershell
> Notification
> "Lasagna's ready!"
```
