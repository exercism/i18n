# 补充说明

## 关于`smallest`和`largest`实现的说明：

这两个函数都必须接收两个关键字参数：
- `max_factor`: int
- `min_factor`: int，默认值为 0

它们的返回值必须是一个`tuple -- (value, factors)`，其中`value`是回文数本身，`factors`是一个`iterable`，按任意顺序包含该回文数的两个因数。


## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，你应该始终加上一条**有意义的错误消息**，说明错误的来源。这会让代码更易读，也大大有助于调试。如果你已经知道错误的来源属于某个特定类型，可以选择抛出某个[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍然要加上一条有意义的错误消息。

这道练习要求你在`largest()`或`smallest()`函数收到一对不在正确范围内的因数时，使用[raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)“抛出”一个`ValueError`。只有当你既`raise`了这个`exception`，又为它附上一条消息时，测试才会通过。

要想在抛出`ValueError`时附带消息，把这条消息写成`exception`类型的一个实参：

```python
# if the max_factor is less than the min_factor
raise ValueError("min must be <= max")
```
