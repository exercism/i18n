# 介绍

可以使用`if/elif/else`表达式来根据条件执行逻辑。F# 还提供了另一种更强大的条件执行方式：模式匹配。有了模式匹配，就可以把一个值与一个或多个_模式_进行匹配。其中一种模式叫做_常量模式_，它把值与常量（例如`1`或`"hello"`）进行匹配。

在 F# 中，模式匹配通过`match`关键字完成：

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

这看起来可能像其他语言里的`switch`语句，但当你同时使用其他模式时，模式匹配才真正开始大放异彩。其中一种模式叫做_变量模式_，它可以把一个值捕获下来：

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

有时，你可能想给模式再加上一个条件。这叫做_守卫_（子句），可以用`when`关键字添加：

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

在上面的例子里，并非所有可能的输入都有匹配的模式。编译器会检测到这一点并给出警告。这叫做_穷尽性检查_。要消除这个警告，就必须处理所有情况。为此，可以使用_通配符模式_，它能匹配任何值：

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

模式匹配会自上而下地把一个值依次与每个模式进行匹配，直到找到匹配的模式，然后执行该模式对应的逻辑。模式的顺序很重要！
