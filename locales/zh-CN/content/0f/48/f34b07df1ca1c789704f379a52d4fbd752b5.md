# 安装

## 我用的是哪个 awk？

Exercism 的 AWK track 使用`gawk`，也就是 GNU 的 AWK。
你的系统可能已经装了；想确认的话，执行这条命令：
```sh
awk --version
```

如果它返回的是：

* 类似 `GNU Awk 5.1.0 ...` 这样的输出
    - 你已经装了 GNU awk，可以直接开始做练习了。

* 类似 `awk version 20200816` 这样的输出
    - 这是 `nawk`，也叫 BWK awk（以 Brian Kernighan 命名），或者“one true awk”。
    - 这是 MacOS 和 BSD 系统自带的版本。
    - 安装说明见下文。

* 报错 `awk: not an option: --version`
    - 你很可能装的是`mawk`。
    - 用 `awk -W version` 确认一下，它可能返回 `mawk 1.3.4 20200120`。
    - mawk 是一款非常优秀、速度很快的 awk 实现，但它缺少一些我们会在 track 中用到的 gawk 特有功能。
    - 安装说明见下文。

* 报错 `awk: unrecognized option: version`，后面还跟着 `BusyBox v1.35.0 ...`
    - 你可能用的是 Alpine Linux。
    - 安装说明见下文。

* 出现“command not found”错误
    - 那要么是你的 PATH 出了问题，要么你根本没装 awk。
    - 安装说明见下文。

### Linux

视你的发行版所用的包管理器而定。通常是：
```sh
apt install gawk
yum install gawk
apk add gawk
# and so on
```
执行相应的命令时，你可能需要用到`sudo`。

### MacOS

[Homebrew][brew] 是你的好帮手。点进链接把它装上，然后运行：
```sh
brew install gawk
```

### Windows

用 [WSL][wsl] 的话，参见上面的 Linux 说明。
用 cygwin 的话，安装`gawk`包。

### 从源码编译

给敢于尝试的人：[`gawk` 手册中有说明][build]。
