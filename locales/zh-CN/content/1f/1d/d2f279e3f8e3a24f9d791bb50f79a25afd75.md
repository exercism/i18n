# 关于

PHP 是一门面向 Web 开发的服务器端语言。这个缩写是递归的，代表 _PHP: Hypertext Preprocessor_。

PHP 比 CGI 脚本灵活得多，常用来为普通 HTML 增添交互功能，并强化 Web 框架。

这门语言可以在任何操作系统上使用。PHP 得到大多数常见 Web 服务器的支持，通常通过翻译模块来处理。这样就把静态网页代码和动态内容结合了起来。

PHP 不只是一个 Web 服务器框架。它还适用于编写命令行脚本（无头解析）以及开发图形用户界面（GUI）。

你应该学习 PHP，因为：

- 它是一门开源语言
- 文档完善，支持充分
- 兼容大多数常见 Web 服务器
- 容易上手，学习门槛低
- 可伸缩性强，易于扩展
