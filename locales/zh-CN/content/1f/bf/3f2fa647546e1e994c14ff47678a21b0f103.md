# 补充说明

## 异常信息

有时你需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。抛出异常时，应该始终附上一条**有意义的错误信息**，说明错误来自哪里。这样能让代码更易读，也大大方便调试。如果你确定错误来源属于某个类型，可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍然要附上有意义的信息。

这个练习要求你在数组中找不到给定值时，用[`raise`语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)来“抛出”一个`ValueError`。只有同时`raise`这个`exception`并附上信息，测试才会通过。

要用一条信息抛出`ValueError`，就把这条信息作为实参写在该`exception`类型后面：

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
