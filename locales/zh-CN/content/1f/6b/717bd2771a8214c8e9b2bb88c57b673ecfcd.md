# 说明

卢顿图书馆是一座大型图书馆，馆藏文献十分丰富，从书籍到艺术作品应有尽有。图书馆设有一个区域，供人们研究文献并把书籍录入计算机系统。

其中某些环节希望能实现自动化，于是图书馆请你来帮忙。这包括把题写流程的表单自动化，以及协助解密文本。

## 1. 获取标题的首字母

图书应当便于查找，因此图书馆按标题的首字母排序。

实现 `Library.first_letter` 方法，它接受一个参数 `title`，该参数保存书籍的标题。方法应返回标题的首字母。

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. 获取作者姓名的首字母缩写

图书馆有很多由不同作者撰写的书籍。作者通常以姓名首字母缩写被提及，因此图书馆要求开发一个系统，通过输入作者的名字和姓氏来给出作者的姓名首字母缩写。首字母缩写应这样格式化：`{first_letter_of_first_name}.{first_letter_of_last_name}`

实现 `Library.initials` 方法，它接受两个参数 `first_name` 和 `last_name`，分别保存作者的名字和姓氏。方法应返回作者的姓名首字母缩写。

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. 解密字母

有些文献是加密的，图书馆有大量加密文本。图书馆希望有一套针对这种特殊加密的新解密系统。

加密的方式是：取出一个字母，用字母表中排在它前面的那个字母替换它。例如 `a` 会变成 `z`，`b` 会变成 `a`，`c` 会变成 `b`，依此类推。

图书馆希望它既能解密大写字母，也能解密小写字母，并保持与原始字母相同的大小写。

实现 `Library.decrypt_character` 方法，它接受一个参数 `character`，该参数保存要解密的字母。方法应返回解密后的字母。

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. 解密文本

图书馆还希望用上述加密方式解密整段文本，也就是取字母表中排在每个字母前面的那个字母。

解密程序应只解密字母，其他所有字符都保持原样。

实现 `Library.decrypt_text` 方法，它接受一个参数 `text`，该参数保存要解密的文本。方法应返回解密后的文本。

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
