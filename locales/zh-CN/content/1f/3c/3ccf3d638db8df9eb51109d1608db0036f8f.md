# 引言

在 Python 中，`None`经常用来表示没有值，它是一个占位符，用来定义`null`（空）变量、对象或实参。

如果你在其他编程语言中听说过或使用过`NULL`或`nil`类型，那么 Python 里`None`的这种用法你会很熟悉。
`None`可以帮助你声明暂时还没有值的变量或函数实参。
之后可以根据需要把它们重新赋值为具体的值：


```python
a = None
print(a)
#=> None

type(a)
#=> <class 'NoneType'>

# Adding a default argument with `None`
def add_to_todos(new_task, todo_list=None):
    if todo_list is None:
        todo_list = []  
    todo_list.append(new_task)
     
  return todo_list
```

在条件判断中使用时，`None`会求值为`False`，因此它很适合用来验证某个值是“存在”还是“不存在”，_任何_值都可以。当函数或过程可能返回`error`、`object`或消息时，经常会用到这种写法。

```python
a = None
if a: #<-- a will be evaluated to False when it is used in a conditional check.
    print("This will not be printed")
```
