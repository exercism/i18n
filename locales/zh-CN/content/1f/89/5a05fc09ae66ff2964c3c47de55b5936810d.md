## 制作你的第一个 Coffee 模块

要创建一个可以用 `Bob = require './bob'` 加载的模块，把这段代码放进 `bob.coffee`：

```coffeescript
class Bob

module.exports = Bob
```

关于模块的更多信息，可以查看 [Node 文档](http://nodejs.org/api/modules.html#modules_module_exports)。

## 在 Windows 上使用 Visual Studio

如果你有 Visual Studio 的付费版本，可以下载一个已经配置好的 Visual Studio 解决方案，它可以直接配合 CoffeeScript 以及 Visual Studio 支持的其他语言使用。

![Solution Explorer](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/SolutionExplorer.png)

1. 在 GitHub 上点击页面中的 Download Zip 按钮，下载 [Exercism.io Visual Studio Template](https://github.com/rprouse/Exercism.VisualStudio)。
2. 把模板解压到你的练习目录，例如 `C:\src\exercises`
2. 安装 [Exercism CLI](http://exercism.io/cli)
3. 在练习目录下打开命令提示符
4. 把你的 API 密钥添加到 exercism：`exercism configure --key=YOUR_API_KEY`
5. 在 exercism 中配置你的源码目录：`exercism configure --dir=C:\src\exercises`
6. [获取你的第一个练习](http://exercism.io/languages/coffeescript)：`exercism fetch coffeescript`
7. 在 Visual Studio 中打开这个 Exercism 解答
8. 展开 Exercism.coffeescript 项目
9. 在 Solution Explorer 中点击 **Show All Files**（见下文）
10. 你刚刚获取的练习会显示为灰色。右键点击该文件夹，然后选择 **Include In Project**
11. 开始写代码吧……

![添加文件](https://raw.githubusercontent.com/exercism/coffeescript/main/docs/img/AddFiles.png)

要在 Visual Studio 中使用 CoffeeScript，应该安装 [Web Essentials](http://vswebessentials.com/) 扩展。它也会让 Javascript 的使用方便得多。

你可以用项目中的批处理文件，从 node.js 命令行运行单元测试。

```bash
C:\Src\exercises\coffeescript> test example\bob_test.spec.coffee
.................

Finished in 0.02 seconds
17 tests, 17 assertions, 0 failures, 0 skipped
```

如果运行测试后看不到任何输出，你很可能是没有在 Node.js 命令提示符中运行。
