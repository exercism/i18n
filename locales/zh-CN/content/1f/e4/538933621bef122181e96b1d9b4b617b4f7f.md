# 简介

## 字典

字典是一种元素的集合，其中每个元素都由一个键和一个值组成：如果把某个键传给字典的方法，就会返回与它关联的值。它和其他语言里的映射或关联数组所起的作用相同。

可以这样创建字典：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

或者

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

注意，键和值的类型也是字典定义的一部分。

字典创建好之后，可以用它内置的`Add`和`Remove`方法来添加或删除条目。

要获取或更新字典中的值，可以用键对字典进行索引：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

可以用下面的方式判断字典中是否存在某个键：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

遍历字典会遍历它的键值对。字典还有一些属性，可以让你单独遍历它的键或值。
