# Null

Null 是一种原始值类型，它只有一个值：`null`。
Null 常用来表示空值。
它被认为是“falsey”，但与 `false` 和其他 falsey 值并不相同。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## 处理 null 值

在 PHP 中，null 值经常是引发错误的原因，因为函数常常返回 null 来代替错误状态，或者用它表示空。
要避免这类错误，通常需要在操作之前做“null 检查”，确认值不是 null。

反复进行 null 检查很容易出错，因此 PHP 提供了两个用于处理 null 值的运算符：null 安全访问运算符 `?->` 和 null 合并运算符 `??`。
