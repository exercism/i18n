# 百分号格式化或“旧式”格式化

这个解答对字符串使用了 `%%-formatting`，也就是[旧式格式化][old-style formatting]。

虽然 `%%-formatting` 完全可行，但它可能在表示或可读性上带来问题。使用 [str.format()][str.format()] 方法或 [f-strings][f-strings]（_又称“格式化字符串字面量”或“插值字符串”_），可以获得一些选项，让代码更易读，也让字符串中的变量替换更清晰。

博客文章 [String Formatting in Python][string formatting in python] 是了解 Python 所有字符串格式化选项的不错起点，而 [Newer Python String Format Techniques][newer python string format techniques] 也提供了一些使用 `str.format()` 和 `f-strings` 的实用技巧。
