玩家会在地图上四处移动，沿途收集宝藏。
宝藏位置和地点位置采用了不同的格式，以此增加额外的挑战。
此外还有一些特殊地点，在那里某些宝藏可以换成另一些宝藏，给游戏增添额外的转折。
你的任务是编写函数，帮助他们完成这个游戏。

## 1. 转换位置

实现 `placeLocationToTreasureLocation` 函数，它接收一个地点位置（例如 `('C', 1)`），并把它转换成宝藏位置（例如 `(1, 'C')`）。

```elm
placeLocationToTreasureLocation ('C', 1)
--> (1,'C')
```

## 2. 比较宝藏位置和地点位置

实现 `treasureLocationMatchesPlaceLocation` 函数，它接收一个 `PlaceLocation`（例如 `('C', 1)`），如果它与某个 `TreasureLocation`（例如 `(1, 'C')`）匹配就返回 true。

```elm
treasureLocationMatchesPlaceLocation ('C', 1) (1, 'C')
--> true

treasureLocationMatchesPlaceLocation ('C', 1) (2, 'C')
--> false
```

## 3. 统计宝藏位置

实现 `countPlaceTreasures` 函数，它接收一个地点（例如 `("Aqua Lagoon (Island of Mystery)", ('F', 1))`）和宝藏清单，并返回在那里能找到的宝藏数量。

```elm
place = ("Aqua Lagoon (Island of Mystery)", ('F', 1))

countPlaceTreasures place treasures =
--> 2
```

## 4. 特殊地点

实现 `specialCaseSwapPossible` 函数，它接收一个宝藏（例如 `("Amethyst Octopus", (1, 'F'))`）和一个地点（例如 `("Seaside Cottages ", ('C', 1))`），并在以下组合中返回 true：

- 在 Abandoned Lighthouse，Brass Spyglass 可以换成任何其他宝藏
- 在 Stormy Breakwater，Amethyst Octopus 可以换成 Crystal Crab 或 Glass Starfish
- 在 Harbor Managers Office，Vintage Pirate Hat 可以换成 Model Ship in Large Bottle 或 Antique Glass Fishnet Float

试着把这个函数写成一个带有临时元组的 case 语句，而不是使用 if 语句（这是 Elm 中常见的惯用法）。
