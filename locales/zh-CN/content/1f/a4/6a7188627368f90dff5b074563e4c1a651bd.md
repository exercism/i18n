# Haskell 语法基础

## 常量与函数

Haskell 程序由定义和表达式组成。

常量用`name = expression`定义。

```haskell
five = 5

six = 3 + 3
```

函数用`name parameters... = expression`定义，各个形参之间只用空格分隔。

```haskell
add number1 number2 = number1 + number2
```

调用函数本身也是一个表达式：写出函数名，再为函数的每个形参传入实参，之间用空格分隔，和定义函数时一样。

```haskell
five = add 2 3
```

可以用括号来指定表达式的求值顺序。

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 缩进 / 有意义的空白

Haskell 用空白字符和缩进来划分代码的边界。
***属于某个表达式的代码，缩进要比该表达式的开头更深。***

- 模块、导入语句和顶层函数定义必须从最左边一列开始。
- 如果一个表达式被拆成多行，属于该表达式的代码必须缩进到该表达式之下，至少缩进一个空格。
- 表达式中归为一组的各个部分，应该用相同数量的空格缩进。

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## 模块

模块会导出函数。
也就是说，你可以使用模块在导出语句中公开的那些函数。
模块也可以只定义供内部使用的函数。
默认情况下，没有显式导出的函数无法从模块外部使用。

在模块的开头，我们要指定模块名。
如果有一个名为 Calculator.hs 的文件，那我们就应该把模块命名为 Calculator。
接着指定它导出的函数，之后就可以开始写函数了。
那么我们先从这个开始。

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## 注释

注释是 Haskell 文件中不会被当作代码解释的一段文本，主要是写给你自己和其他程序员看的。
单行注释有一种基于双连字符的轻量语法。
多行注释则用`{-`和`-}`这一对起止分隔符来写。

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
