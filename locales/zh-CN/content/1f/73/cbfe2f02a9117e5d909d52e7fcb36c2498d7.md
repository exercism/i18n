# 关于

`while` 和 `until`（位于 [`kernel`][kernel] 中）是以 quotation 驱动的循环组合子，适用于你事先并不知道迭代次数的情况：

```
while ( pred: ( -- ? ) body: ( -- ) -- )
until ( pred: ( -- ? ) body: ( -- ) -- )
```

只要 `pred` 留下一个真值，`while` 就会一直循环下去；只要 `pred` 留下 `f`，`until` 就会一直循环下去。当它们的谓词翻转时，两者都会停止并返回。

```factor
USING: kernel math ;

! Halve down to 1
16 [ dup 1 > ] [ 2 / ] while .   ! => 1

! Double up to 100
1 [ dup 100 >= ] [ 2 * ] until .   ! => 128
```

当栈上流动的单个值不足以承载全部状态时，比如同时需要一个剩余数组、一个累计总和和一个计数器，最清晰的做法是使用具名的*局部变量*以保证清晰。课程体系后面会更深入地介绍局部变量；这里只需知道，`:: word ( a b -- c )` 会把输入声明为具名的局部变量，而 `:> name!` 会添加一个可变的局部变量，循环体可以用 `value name!` 来更新它。

```factor
USING: kernel locals math sequences ;

! Sum a sequence by hand
:: sum-by-hand ( seq -- total )
    seq :> rest!
    0 :> running!
    [ rest length 0 > ] [
        rest unclip [ rest! ] dip
        running + running!
    ] while
    running ;
```
