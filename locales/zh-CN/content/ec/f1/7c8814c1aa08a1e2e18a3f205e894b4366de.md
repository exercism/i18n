# Break, Continue

使用循环或迭代控制结构时，`break`和`continue`这两个关键字可以帮助控制程序的流程。
`break`关键字会跳出循环上下文，进入外层作用域，从而终止循环。
`continue`关键字会跳过当前迭代的剩余部分，并让循环上下文在下一轮迭代开始时重新开始。
虽然不常见，但可以在关键字后面提供一个数字，用来控制要跳出多少层上下文，或者跳过多少层上下文进入下一轮迭代。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

在前面的示例中，`continue`执行了 5 次，但在第 6 次迭代时执行了`break`，使代码退出循环。
