# 简介

字典是一种由元素组成的集合，每个元素都包含一个键和一个值。如果向字典的某个方法传入一个键，就会返回与之关联的值。它在其他语言中的作用相当于映射或关联数组。

字典可以这样创建：

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

或者

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

注意，键和值的类型是字典定义的一部分。

创建之后，可以使用字典内置的方法`Add`和`Remove`来添加或删除条目。

要获取或更新字典中的值，可以用一个键来索引字典：

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

可以用下面的代码测试字典中是否存在某个值：

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

对字典进行枚举时，枚举的是它的键值对。字典还有一些属性，可以枚举它的键或值。
