# 关于

## struct 类型

我们已经见过 struct 类型了。再回顾一下：`struct`是一系列有名字的元素，称为_字段_，每个字段都有自己的名字和类型。字段的名字在同一个 struct 内必须唯一。`Structs`可以类比面向对象编程范式中的_类_。

使用 `type` 和 `struct` 关键字可以创建新的 struct，然后按照下面的示例显式定义字段的名字和类型。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 非 struct 类型

也可以定义非 struct 类型，作为内置类型声明的别名。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你还可以定义由数组和映射组成的非 struct 类型。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
