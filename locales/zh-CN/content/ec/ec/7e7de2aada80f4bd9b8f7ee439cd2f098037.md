# 浮点数

`INT`只保存整数，两个整数相除会丢掉余数：

```sather
7 / 2        -- 3, not 3.5
```

当小数部分有意义时，类型就是`FLTD`，即**浮点数**，它能保存整数之间的值。

## 写一个浮点数

浮点字面量的末尾有一个小数点和一个小小的`d`。

```sather
   concert_a : FLTD is
      return 440.0d;
   end;
```

`d`不是可有可无的。单独的`440.0`属于另一种类型，精度更低；而`d`要求的是本学习路径处处都在用的那一种。

要写`2.0d`，不能写`2d`，小数点也是必须有的。

## 算术运算

`+`、`-`、`*`和`/`都能用，而且`/`现在会保留小数部分：

```sather
7.0d / 2.0d      -- 3.5
```

两边都必须是`FLTD`。Sather 不会悄悄把两种类型混在一起，所以`7 / 2.0d`会直接报错，而不是给你一个意外结果。

## 从整数转换

`.fltd`把`INT`变成`FLTD`：

```sather
   halve(n : INT) : FLTD is
      return n.fltd / 2.0d;
   end;
```

`halve(7)`的结果是`3.5`。注意转换放在哪里：`(7 / 2).fltd`会得到`3.0`，因为那次除法早就把一半丢掉了。要在做除法**之前**转换，而不是之后。

## 相差多少？

`.abs`会去掉负号，用它可以求两个值相差多少，而不必关心哪个更大：

```sather
(440.0d - 442.0d).abs      -- 2.0
```
