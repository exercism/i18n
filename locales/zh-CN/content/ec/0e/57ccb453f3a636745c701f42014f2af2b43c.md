# 提示

## 1. 从牌堆中取出一张牌

- `Vector`的下标从`1`开始。
- 你可以用`v[n]`取出向量`v`中的第`n`个值。

## 2. 交换牌堆中的一张牌

- `Vector`是可变的，你可以随时修改其中的内容。
- 这个方法接收一个 [Pair](https://docs.julialang.org/en/v1/base/collections/#Base.Pair) 作为实参。
- 你可以用`p.first`和`p.second`访问 pair `p` 的字段。

## 3. 在牌堆顶部插入一张牌

- Base 中有一个方法 [`push!`](https://docs.julialang.org/en/v1/base/collections/#Base.push!)，可以把新值添加到集合末尾。

## 4. 从牌堆中移除一张牌

- Base 中有一个方法 [`deleteat!`](https://docs.julialang.org/en/v1/base/collections/#Base.deleteat!)，可以删除`Vector`中指定下标处的元素。

## 5. 移除牌堆顶部的一张牌

- Base 中有一个方法 [`pop!`](https://docs.julialang.org/en/v1/base/collections/#Base.pop!)，可以移除集合末尾的元素。

## 6. 在牌堆底部插入一张牌

- Base 中有一个方法 [`pushfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.pushfirst!)，可以把新值插入集合的开头。

## 7. 从牌堆底部移除一张牌

- Base 中有一个方法 [`popfirst!`](https://docs.julialang.org/en/v1/base/collections/#Base.popfirst!)，可以移除集合开头的元素。

## 8. 检查牌堆的大小

- Base 中有一个方法 [`length`](https://docs.julialang.org/en/v1/base/collections/#Base.length)，可以获取集合的长度。
