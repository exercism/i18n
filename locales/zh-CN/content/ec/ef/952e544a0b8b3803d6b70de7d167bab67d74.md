# 补充说明

## 输出格式

以百分之一年为单位输出年龄。

例如，100 × 1,000,000,000 ÷ 31,557,600 ≈ 3,169，所以一个年龄为 1,000,000,000 秒的人，其年龄为`3169`个百分之一地球年。

## 寄存器

| 寄存器 | 用途     | 类型 | 说明                                                          |
| ------ | -------- | ---- | ------------------------------------------------------------- |
| `$a0`  | 输入     | 整数 | 行星（`0` = Mercury、`1` = Venus、`2` = Earth、`3` = Mars、`4` = Jupiter、`5` = Saturn、`6` = Uranus、`7` = Neptune） |
| `$a1`  | 输入     | 整数 | 秒数                                                          |
| `$v0`  | 输出     | 整数 | 以百分之一年为单位的年龄                                      |
| `$t0-9`| 临时     | 任意 | 用于临时存储                                                  |
