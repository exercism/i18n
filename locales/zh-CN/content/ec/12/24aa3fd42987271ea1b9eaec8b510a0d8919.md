# 简介

回想一下，`jq`支持与 JSON 相同的数据类型。
JSON 对**字符串**的描述是：

> 字符串是由零个或多个 Unicode 字符组成的序列，用双引号包裹，并使用反斜杠转义。

## 转义序列

在字符串中，用反斜杠来嵌入“特殊”字符：

- `\"` 字面意义上的引号，
- `\\` 字面的反斜杠，
- 空白字符 `\n`、`\t`、`\r`、`\f`、`\b`
- Unicode 字符 `\uAAAA`，其中 `A` 是一个十六进制数字

## 字符串长度

要得到字符的数量，使用 `length` 函数。

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## 子字符串

可以用**切片**表示法来提取子字符串。
语法是 `.[i:j]`。
返回的子字符串长度为 `j - i`，包含从下标 `i`（含）到下标 `j`（不含）之间的字符。
任一下标都可以为负数，这时它从字符串末尾向前数。
任一下标也都可以省略，省略时就表示字符串的开头或结尾。
下标从 0 开始。

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## 拼接

用 `+` 把字符串连接起来：

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

面对一个字符串数组时，用 `add`：

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## 拆分与合并

拆分使用 `split/1` 函数或 `/` 运算符：

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1` 的逆操作是 `join/1`。

经常需要把字符串转换成一个字符数组。
有两种做法：

1. 按空字符串拆分

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. 用 `explode` 拆成 _码点_ 数组

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` 是 `explode` 的逆操作。

## 查找子字符串的下标

使用 `index/1` 函数；下标从 0 开始。

```jq
"hello" | index("el")'   # => 1
```

如果字符串中不存在该子字符串，结果就是 `null`

```jq
"hello" | index("elk")   # => null
```

## 字符串插值

在字符串中，`\(expression)` 这个写法会把该表达式的_结果_ [嵌入字符串][interpolate]：

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## 大小写转换

使用 `ascii_downcase` 和 `ascii_upcase` 函数。
