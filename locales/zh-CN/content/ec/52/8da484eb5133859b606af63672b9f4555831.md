# 简介

## 比较运算符

[比较运算符][comparison-operators]会比较两个相同类型的值，并返回一个`Bool`值（`true`或`false`）。
如果尝试比较不同类型的值，编译器会产生一个错误。

Swift 中的标准比较运算符有：

| 运算符 | 描述 | 示例 |
| -------- | ------------------------ | --------------- |
| `==`     | 等于                 | `1 == 1` (true) |
| `!=`     | 不等于                 | `1 != 2` (true) |
| `<`      | 小于                | `4 < 5`  (true) |
| `<=`     | 小于等于    | `4 <= 4` (true) |
| `>`      | 大于                 | `3 > 1`  (true) |
| `>=`     | 大于等于 | `2 >= 2` (true) |

## if 和 else 语句

[条件语句][conditional-statement]会根据条件求值为`true`还是`false`来执行代码。
最常见的条件语句是 [if 语句][if]，仅当其条件为`true`时才运行代码块。
使用`if`关键字编写`if`语句，后跟条件以及用花括号括起来的代码块：

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

你可以将`if`与`else`子句配对，以便在条件为`false`时运行替代代码：

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

要按顺序测试多个条件，可以使用`else if`将语句串联起来。
`if`语句不要求有`else`分支，但你可以添加一个分支来处理所有条件都不匹配的情况：

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## if 表达式

在现代 Swift 中，`if`语句也可以用作产生值的表达式。
每个分支都会求值为一个值，从而可以轻松地按条件赋值：

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```
