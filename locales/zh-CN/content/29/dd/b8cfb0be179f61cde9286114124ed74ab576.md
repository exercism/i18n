# 说明

在这个练习中，你要为一个朋友正在开发的新角色扮演游戏（RPG）实现任务逻辑。
游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛又忠诚的宠物狗。
不幸的是，灾难降临了：她最好的朋友在森林里寻找浆果时被绑架了。
Annalyn 会设法找到并救出她最好的朋友，也可以在这次冒险中带上她的狗。

沿着好朋友的踪迹追踪了一段时间后，她找到了关押着好朋友的营地。
原来有两个绑架者：一位强大的骑士和一个狡猾的弓箭手。

找到绑架者后，Annalyn 开始考虑自己能采取以下哪些行动：

- _快速攻击_：只要**骑士**处于**_睡着_**状态，就可以发动快速攻击，因为他穿上盔甲需要时间，这时他会很脆弱。
- _侦察_：只要他们中**至少有一个**是**_醒着的_**，就可以对这群人进行侦察。否则，侦察就是浪费时间。
- _向囚犯发信号_：如果**囚犯**是**_醒着的_**，而**弓箭手**是**_睡着的_**，就可以用鸟叫声向囚犯发信号，因为弓箭手受过鸟鸣信号的训练，可能会截获这条信息。
- _解救囚犯_：Annalyn 可以试着潜入营地，把囚犯救出来。
  这件事风险很大，只有两种方式能成功：
  - 如果 Annalyn 带上了她的宠物狗，那么只要**弓箭手**是**_睡着的_**，她就能救出囚犯。
    骑士怕狗，而弓箭手来不及准备好，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没有带上她的狗，那她和囚犯就必须非常悄悄地行动！
    只要**囚犯**是**_醒着的_**，并且**骑士**和**弓箭手**都**_睡着_**，Annalyn 就能救出囚犯；但如果**囚犯**是**_睡着的_**，就没法救出他们：Annalyn 突然出现会吓到囚犯，从而吵醒骑士和弓箭手。

你有四个任务：根据森林里这三个角色的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可用的逻辑。

## 1. 检查是否可以发动“快速攻击”行动

实现一个名为`canFastAttack`的函数，它接收一个布尔值，表示骑士是否醒着。
如果根据该角色的状态，“快速攻击”行动可用，这个函数就返回`true`；否则返回`false`：

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. 检查是否可以采取“侦察”行动

实现一个名为`canSpy`的函数，它接收三个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。
如果根据这些角色的状态，“侦察”行动可用，这个函数就返回`true`；否则返回`false`：

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. 检查是否可以采取“向囚犯发信号”行动

实现一个名为`canSignal`的函数，它接收两个布尔值，分别表示弓箭手和囚犯是否醒着。
如果根据这些角色的状态，“向囚犯发信号”行动可用，这个函数就返回`true`；否则返回`false`：

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. 检查是否可以采取“解救囚犯”行动

实现一个名为`canLiberate`的函数，它接收四个布尔值。
前三个形参分别表示骑士、弓箭手和囚犯是否醒着。
最后一个形参表示 Annalyn 的宠物狗是否在场。
如果根据这些角色的状态以及 Annalyn 的宠物狗是否在场，“解救囚犯”行动可用，这个函数就返回`true`；否则返回`false`：

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
