# 提示

## 通用

- 试着把一个问题拆分成基本情况和递归情况。例如，假设你想用递归的方法数一数饼干罐里有多少块饼干。基本情况就是空罐子，里面没有饼干。如果罐子不是空的，那么罐子里的饼干数就等于一块饼干，加上取出这块饼干后罐子里剩下的饼干数。

## 1. 检查今天有多少只鸟来过

- 这个任务不需要递归。
- 使用 case 表达式就可以取出数组中的第一个元素。

## 2. 增加今天的计数

- 这个任务不需要递归。
- 使用 case 表达式可以取出数组中的第一个元素以及数组的其余部分。

## 3. 检查是否存在没有鸟来过的日子

- 用递归遍历数组中的元素，直到找到没有鸟来过的那一天。
- 基本情况是空数组。

## 4. 计算来访鸟的总数

- 用递归遍历数组中的每一个元素。
- 基本情况是空数组。

## 5. 计算忙碌日子的数量

- 用递归遍历数组中的每一个元素。
- 基本情况是空数组。
- 为 case 表达式其中一个子句加上守卫。
