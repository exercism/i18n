# 说明附录

## 本赛道专属说明

为了简洁易读，不妨考虑使用 Scala 的集合函数，而不是 Java 的`String`方法。
记住，在 Scala 中，`String`其实也隐式地是一个`Seq[Char]`，所以你可以像调用`String`方法那样轻松地调用它们。

一些例子：
- 用`filter`代替`replaceAll`
- 用`take`、`takeRight`、`drop`、`head`、`tail`代替`substring`

另一个值得探索的思路是，把`String`转换成`List[Char]`，然后用`::`运算符做[模式匹配]。

[模式匹配]: http://alvinalexander.com/scala/how-to-use-lists-nil-cons-scala-match-case-expressions
