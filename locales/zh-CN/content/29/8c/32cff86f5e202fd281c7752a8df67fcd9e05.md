# 类

类是 PHP 中组织代码的一个单位。
表示某个事物的行为或某个过程的行为的代码，可以归为一个类。
归属于类的函数，按惯例称为`methods`。

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

类通过`new`关键字实例化，这会为类的实例分配内存，并调用类的构造函数。
实例化后的类可以赋值给变量。
要调用类实例的方法，可以使用`->`访问运算符。

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

实例化的类可以使用特殊的`$this`变量引用它自己的实例。
类还可以有属性，这些属性的作用相当于绑定在类对象实例上的变量。
这些属性既可以在内部引用，也可以在外部引用。

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
