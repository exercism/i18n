# 提示

## 通用

SGF 语言有一个递归定义：

```none
GameTree = "(" Sequence { GameTree } ")"
```

也就是说，GameTree 是一段以`(`开头的文本，后面跟着一段称为“Sequence”的文本（一串对局节点），_再后面是**零个或多个**子 GameTree_，最后以`)`结束。

你或许想用正则表达式来解析 SGF 文本。
不过，由于对局树可以嵌套在其他对局树里，深度不限，标准正则表达式的能力不足以跟踪嵌套的层级。

解决这道练习有几种思路：

### 状态机

你可以逐字符扫描输入字符串，同时用一个变量保存当前位置。
根据当前位置上的字符，你可以跟踪已解析文本的当前状态。
“当前状态”可能是“正在读取属性名”，或者“位于属性值内部”之类。
用这种方式，你需要跟踪很多值。

### 解析器

对于有明确文法的语言，[基于 PEG 的解析器][PEG-parser]是很好的解析办法。
[LPeg][LPeg] 是一个 PEG 解析器，也是 MoonScript 的必需依赖之一，所以你已经能直接用它了。
解析器让你可以为文本应该长什么样编写规则。
比如，“属性名全是大写字母”，或者“属性值用方括号括起来”。
然后，把输入文本与你的规则进行匹配这件重活，就交给解析器了。
