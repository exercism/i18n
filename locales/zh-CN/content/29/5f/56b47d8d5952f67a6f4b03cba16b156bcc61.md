# 关于

F# 的字符串是不可变对象，它把文本表示为一系列 Unicode 字符（字母、数字、标点符号等）。定义一个`string`实例要使用双引号：

```fsharp
let fruit = "Apple"
```

要操作字符串，可以调用它的某个[方法][methods]或[属性][properties]，也可以使用 [`String`模块][string-module]里的某个函数。字符串值一经定义就无法再更改，因此所有字符串操作方法/函数都会返回一个新的字符串。

字符串由双引号（`"`）括起来。有些特殊字符需要用反斜杠（`\`）来[转义][escaping]。字符串也可以加上 at 符号（`@`）作为前缀，这样它就变成了[逐字字符串][verbatim]，会忽略其中的任何转义字符。

```fsharp
let escaped = "c:\\test.txt"
let verbatim = @"c:\test.txt"
escaped = verbatim
// => true
```

另外，也可以用[三引号][triple-quoted]（`"""`）来定义字符串，这样就能在字符串中使用双引号而不必转义。

```fsharp
let tripledQuoted = """<movie title="Se7en" />"""
// => "<movie title="Se7en" />
```

最后，可以通过 [`+`运算符][plus-operator]来拼接字符串：

```fsharp
let name = "Jane"
"Hello " + name + "!"
// => "Hello Jane!"
```
