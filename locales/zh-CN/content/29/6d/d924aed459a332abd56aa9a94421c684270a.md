# 测试

## 运行测试

要运行测试，请执行以下命令：

```bash
bats test-<exercise-slug>.bats
```

### bats 是用 bash 实现的

bats 文件是一个 bash 脚本，其中包含一些由 `bats` 命令识别的特殊函数。
你会看到一些类似这样的测试：

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

那个 `<<<` 语法是 bash 的一种 *Here String*。
它把右侧的字符串送入左侧程序的标准输入。
它大致等同于

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## 跳过的测试

解出一道练习意味着让它所有的测试都通过。
默认情况下，运行测试时只会执行一个测试（第一个）。
这是有意为之，这样你就能专注于让那一个测试通过。
一旦它通过，你就可以通过注释掉或删除下面这行来启用下一个测试：

    [[ $BATS_RUN_SKIPPED == true ]] || skip

这些注解附加在其他测试的前面。

## 取消跳过

要运行所有测试，包括带有 `skip` 注解的测试，可以运行：

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

或者，你也可以从测试文件中注释掉或删除这一行：

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```
