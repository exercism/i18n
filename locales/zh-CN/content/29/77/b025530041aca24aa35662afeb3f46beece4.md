# 说明附录

## 提示

你需要实现 `convert`函数，将数字转换为雨滴声并返回。如果不确定类型，可以使用给出的签名，但不要让它限制你的创造力：

```haskell
convert :: Int -> String
```

这个练习处理的是文本数据。出于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是字符数组。为了更高效地处理文本数据，可以使用`Text`类型。

作为这个练习的可选扩展，你可以

- 阅读 Haskell 中的[字符串类型](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的依赖列表中添加 `- text`。
- 按[下面的方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 现在你可以写例如`convert :: Int -> Text`，并用例如`T.pack`来引用`Data.Text`的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档，
- 然后你可以在 Raindrops.hs 中把所有`String`替换为`Text`：

```haskell
convert :: Int -> Text
```

这部分完全是可选的。
