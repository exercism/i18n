# 迭代

在编程中，[迭代][iteration]指的是重复执行一段代码块的过程。这可以通过`while`循环、`until`循环等概念来实现，也可以通过递归来实现，也就是一个调用自身的函数。

不过，大多数情况下你要迭代的是一个元素集合，比如`Array`、`Range`或`String`。Crystal 中的`Array`和`Range`类都包含了[`Enumerable`][enumerable]模块，它提供了许多用于迭代元素的方法。而`String`类则有自己的一套用于迭代字符的方法。

Crystal 也没有其他语言那样的`for`语句，而是提供了若干可用于迭代的方法。

## 迭代

迭代集合最常见的方式是使用[`each`][each]方法，它会把集合中的每个元素传给块。用`Range`就能轻松做到这一点。假设你想在 1 到 3 之间循环，就可以用`each`方法迭代这个范围。

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

更简单的是，如果你只是想重复执行若干次，可以使用[`times`][times]方法，它定义在`Int`类上。

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## 迭代`String`

`String`是字符的序列，不属于`Enumerable`模块，也就是说它有一套自己的方法来迭代字符。迭代`String`最常见的方式是使用[`each_char`][each_char]方法，它会把`String`中的每个字符传给块。

~~~~exercism/note
`each_char`方法传给块的是`Char`对象，而不是`String`对象。
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

迭代`String`的另一种方式是使用[`each_line`][each_line]方法。这个方法主要用于逐行读取文件。

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## 迭代包含`Enumerable`模块的对象

[`Enumerable`][enumerable]模块提供了许多用于迭代集合中元素的方法。包含`Enumerable`模块的集合有`Array`、`Range`、`Hash`、`Set`等，后面这几种会在后续概念中介绍。

迭代`Array`最常见的方式是使用[`each`][each]方法，它会把`Array`中的每个元素传给块。

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map]方法是迭代`Array`的另一种方式，它返回一个新的`Array`，其中包含把块应用到每个元素后得到的结果。它和`each`方法类似，但返回的是一个包含转换后元素的新`Array`。当你想把某个函数应用到集合的每个元素上时，转换非常有用，这是一种很常见的操作。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

借助`if`这样的控制流，你还可以筛选要转换哪些元素。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

### 带下标

有时你需要知道正在迭代的元素的下标，这时可以使用[`each_with_index`][each_with_index]或[`map_with_index`][map_with_index]方法。它会把每个元素及其下标传给块，该方法还接受一个可选实参来指定起始下标。

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

注意，`String`对象也可以使用[`each_char_with_index`][each_char_with_index]方法。

### sum

[`sum`][sum]方法返回集合中所有元素的和，它还接受一个可选的块，用来在求和之前转换元素。它还接受一个可选实参来指定求和的初始值。

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce]（在其他语言中也叫 fold）是这样的一个方法：给定一个合并方法和一个初始值，它会把集合中的所有元素合并起来。`reduce`方法有一个累加器会传给块，累加器是上一次迭代的结果。这样就形成了一个递归的过程，把集合中的所有元素合并起来。

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce`看起来可能和`sum`类似，但`reduce`更灵活，因为你可以指定累加器的初始值和合并方法。`reduce`可以用来实现`sum`、`count`等方法。
