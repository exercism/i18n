# 绑定例程

到目前为止，我们传递的都是*值*：数字、字符串、对象。**绑定例程**让你可以传递例程本身，也就是一段稍后才会被调用的东西，而调用它的代码并不知道它是什么。

替补演员说的正是这个道理：舞台监督手里握着一种演这个角色的方式，却不知道这个人是谁，也不知道他会怎么演。

## 创建一个

`bind`接受一个带空位的调用，空位写成`_`：

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

现在`part`已经是一个普通的值了，和其他值一样。调用它则发生在稍后：

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## 类型

绑定例程的类型是`ROUT`，实参类型写在花括号里，返回类型写在冒号后面：

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

把`ROUT{STR}:STR`读作“一个接受`STR`、返回`STR`的例程”。

| 写法 | 含义 |
| --- | --- |
| `ROUT{STR}:STR` | 接受一个`STR`，返回一个`STR` |
| `ROUT{INT,INT}:BOOL` | 接受两个`INT`，返回一个`BOOL` |
| `ROUT{STR}` | 接受一个`STR`，没有返回值 |
| `ROUT:INT` | 不接受实参，返回一个`INT` |

既然它是一种类型，就可以作为实参：

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse`完全不知道`part`是做什么的。这正是关键所在：它可以传入`shout`，也可以传入`whisper`，或者任何形状相同的其他例程。

## 填入部分实参

并不是每个实参都必须是空位。写出来的内容在绑定时就已经固定：

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice`只接受那一行文本，因为`2`已经定下来了。这个值在绑定那一刻就算好并保留下来，所以之后再改动它来自的那个变量也没有影响。

一个通用例程就是这样变成许多个具体例程的。

## 把对象也绑定进去

对于对象上的例程，对象是调用里的第一项，它可以固定下来，也可以留作空位：

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
