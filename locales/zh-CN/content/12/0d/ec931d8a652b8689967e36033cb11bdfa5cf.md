# 简介

我们假定你已经熟悉 JSON 的语法和数据类型。

jq 通过一个*单一表达式*（写成一个*过滤器管道*）来传递传进来的 JSON 数据，从而得到想要的转换结果。

<!-- prettier-ignore -->
~~~~exercism/note
`jq`语言由`jq`*程序*实现。
这个程序提供了几个方便的命令行选项，用来控制输入如何被读取、输出如何呈现。

在下面的示例里，你会遇到：

- `-n`或`--null-input`

    通常`jq`程序会拿到一个要读取的文件，或者你把数据发送到它的输入。
    `--null-input`选项让你可以在没有任何输入的情况下生成 JSON 数据。

- `-c`或`--compact-output`

    `jq`默认会对输出做美化排版。
    当数据排版整齐时，人类查看起来非常方便。
    不过机器并不需要这样：`--compact-output`选项会去掉格式化用的空白，以尽可能减小生成的 JSON 的大小。

- `-f filename`或`--from-file filename`

    从`filename`读取`jq`程序，而不是在命令行上提供它。
    `sed`和`awk`都出于同样的目的使用`-f`选项。
    你会在练习的测试脚本里看到这种用法。

本课剩下的内容将聚焦于`jq`*语言*。
~~~~

<!-- prettier-ignore-end -->

## 过滤器与管道

**过滤器**也称为**表达式**。

一个*过滤器*接收一个输入，产生一个输出。
就像在 unix shell 里工作时那样，你可以用管道`|`把*过滤器*连接起来，将一个*过滤器*的输出接到另一个*过滤器*的输入。

## 恒等过滤器：`.`

这是最简单的*过滤器*。
它只是把输入原样传到输出。

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

## 数组

下面快速介绍一下如何使用**数组**。
这个话题我们稍后会更详细地展开。

*数组*的元素用方括号访问，下标从 0 开始。

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

*过滤器*可以把一个表达式包在`[`和`]`里来构建*数组*

- 元素列表已知时：

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 收集元素流时：例如，`range`是一个输出数字流的函数

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  用`[]`可以把表达式的结果收集到一个数组里

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

## 逗号是运算符

*逗号*不只是用来分隔*数组*元素的语法。
**逗号**是一个连接流的**运算符**。

例如，`[1, 2, 3]`是一个*过滤器*，它用*数组*构造器`[]`把三个表达式`1`、`2`和`3`连接的结果收集起来。

你注意到上面`range(10; 70; 15)`里的分号了吗？
因为在`jq`语言里*逗号*有专门的用途，所以接受多个实参的函数用分号来分隔实参。

## 对象

快速介绍一下**对象**。

和许多编程语言类似，用点号访问*对象*的属性

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
方括号也可以用于*对象*，但这样一来字符串字面量就需要加引号。
这是处理含空格的键的一种方法。

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

你可以用`{}`和`key: value`键值对来构造*对象*。
对于“简单”字符串的*键*，引号不是必需的。

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

输出

```none
{
  "question": 54,
  "answer": 42
}
```

要把*键*当作*表达式*处理，必须用括号把它包起来（下面的代码输出也和上面相同）。

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

## 管道

例如，给定内容如下的`file.json`

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

我们来计算一下 key2 这个*数组*的长度：

```sh
$ jq '.key2 | length' file.json
3
```

我们把`.key2`这个表达式的输出*用管道传给*`length`作为输入，它不出所料地输出了*数组*中的元素个数。

## 过滤器可以忽略输入

在这个例子中，输入的 JSON 数据被忽略，对输出没有任何影响：

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

## 过滤器可以输出数据流

一个*过滤器*可以输出多个值。
例如，`.[]`这个*过滤器*把*数组*的每个元素作为单独的值输出：

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

把这样的*过滤器*用管道接到另一个*过滤器*上时，第二个*过滤器*会**_对每个值_**执行一次：

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

这有点像隐式迭代。
一旦你掌握了这种技巧，就会发现非常强大的`jq`*过滤器*可以写得非常简洁。

## 括号

**括号**用于把子表达式组合在一起，以确定运算顺序，和其他语言一样。
在`jq`中，需要用到它们的地方有时会显得有些意外。

例如，假设我们要构造一个含 2 个元素的*数组*：9 的平方根，以及 _e_ 的 1 次幂。
这两个单独的表达式是`9 | sqrt`和`1 | exp`。
我们期望输出的是*数组*`[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

为什么没有得到我们期望的结果？`jq`把它理解成了这样：

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`会构建一个由两个元素（`3`和`1`）组成的流，这两个元素会分别被传给`exp`。

我们需要确保`exp`只接收一个数字作为输入。
换句话说，我们要确保管道在逗号之前求值。

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

## 函数与运算符

这里不做深入展开（函数会是另一个练习的主题），下面是一些有用的内置函数：

- `length`

  给定一个数组作为输入，输出数组中元素的个数。

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  这个运算符会根据操作数的类型做不同的事：
  它把数字相加，
  把字符串拼接，
  把数组追加，
  把对象合并。

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`是一个函数，它接收一个数组，并返回一个按照`+`的规则把所有元素加在一起的结果项。
  `[1, 2, 3] | add`输出`6`。

- `map`

  给定一个数组作为输入、一个过滤器作为实参，输出一个把该过滤器应用到每个元素上的数组

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  给定*某个*输入和一个过滤器作为实参：
  - 如果应用到该实参上的过滤器得到 _true_ 值，就原样输出输入
  - 否则，输出*什么都没有*（不是`null`值，而是真的没有任何输出）

  例如，给定一些数字，选出能被 3 整除的那些

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  回想一下，`range`输出的是一个数字*流*。
  `select`会针对每个数字各调用一次。
  只有“通过”该表达式的数字才会被输出。

  你经常需要选出数组中的元素。
  有几种方法可以做到。

  输入为`["Anne", "Bob", "Cathy", "Dave"]`时，选出长度为 4 的名字。
  - 把`map`和`select`一起用

    ```jq
    map(select(length == 4))
    ```

  - 把数组拆开成一个个元素，在那个流上做`select`，再收集结果

    ```jq
    [ .[] | select(length == 4) ]
    ```
