# 元组类型

元组是 Cairo 中一种灵活高效的复合数据类型，可以把多个不同类型的值组合成一个整体。
元组的长度固定，也就是说，一旦声明，它的大小就无法改变。

## 创建元组

要创建元组，只需在括号里写一组用逗号分隔的值。
元组中每个位置都有特定的类型，而且这些类型可以互不相同。

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}
```

元组可以容纳多个不同数据类型的值，甚至可以容纳其他元组。
例如：

```rust
fn main() {
    let nested_tup: ((i32, u64), (u8, bool)) = ((10, 3), (5, false));
}
```

这里的`nested_tup`变量是一个包含两个元组的元组，说明元组可以把其他元组当作元素。

## 解构元组

要访问元组中的各个值，可以使用模式匹配来解构元组，把它拆分成一个个组成部分。

```rust
fn main() {
    let tup = (500, 6, true);

    let (x, y, z) = tup;

    println!("x is: {x}"); // prints "x is: 500"
    println!("y is: {y}"); // prints "x is: 6"
    println!("z is: {z}"); // prints "z is: true"
}
```

## 同时声明和解构

你也可以同时声明并解构一个元组。

```rust
fn main() {
    let (x, y): (felt252, felt252) = (2, 3);
}
```

## 单元类型 `()`

单元类型是 Cairo 中一种特殊的类型，它只有一个值：`()`。
它用一个不含任何元素的元组表示。
单元类型的大小始终为零，并且保证不会出现在编译后的代码中。

在 Cairo 中，每个表达式都会返回一个值；当表达式什么都不返回时，它会隐式返回`()`。
对于那些需要返回值、却没有实际内容可返回的函数来说，这很有用。

## 命名元组类型声明

命名元组让你可以为元组创建一个更具描述性的类型别名，从而提高代码的可读性。

```rust
type Point = (u32, u32);

fn main() {
    let point: Point = (10, 8);
    println!("{point:?}"); // prints "(10, 8)"
}
```

在这个例子中，`Point`是一个命名元组类型，表示一对无符号 32 位整数，让代码更有表现力。
