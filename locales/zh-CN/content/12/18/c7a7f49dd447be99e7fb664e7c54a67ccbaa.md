# 条件判断

**条件判断**会根据某件事是否为真，在两种做法之间做出选择。

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

读法是这样的：先写 `if`，接着是一个答案为 `true` 或 `false` 的判断，然后是 `then`。答案为 true 时，运行 `then` 后面的几行；答案为 false 时，运行 `else` 后面的几行。`end;` 把整段收尾。

## 不止两种分支

`elsif` 可以再加一个判断，只有在上面的判断都为 false 时才会轮到它。

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

顺序很重要。分数为 `9` 时会被第一个判断截住，永远到不了第二个，尽管 `9 >= 5` 同样为 true。把判断的顺序写反，是出错最常见的原因。

它的拼写是 `elsif`，不是 `elseif`，也不是 `else if`。

## 省略 `else`

那种情况下无事可做时，可以不写 `else`。

```sather
   if late then
      apologise;
   end;
```

必须返回值的例程，要求每条路径都能返回，所以在这个练习里，每个 `if` 都会保留 `else`。
