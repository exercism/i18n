# Introduction

Elixir 中所有的错误都实现了_异常行为_。就像_访问行为_一样，_异常行为_定义了回调函数，模块必须实现这些回调函数，才能满足该行为的软件契约。错误一旦定义好，就具备以下特性：

- 模块的名称决定了错误的名称。
- 模块会定义一个错误结构体。
- 该结构体带有一个`:message`字段。
- 模块可以和`raise/1`、`raise/2`一起使用，抛出想要的错误

_异常行为_还规定了两个回调函数：`message/1`和`exception/1`。如果没有实现它们，就会使用默认实现。通过`raise`调用时，`message/1`会把错误结构体转换成一条可读的消息。通过`raise/2`调用时，`exception/1`允许向消息中添加额外的上下文。

## Defining an exception

要从错误模块定义异常，我们使用`defexception`宏：

```elixir
# Defines a minimal error, with the name `MyError`
defmodule MyError do
  defexception message: "error"
end

# Defines an error with a customized exception/1 function
defmodule MyCustomizedError do
  defexception message: "custom error"

  @impl true
  def exception(value) do
    case value do
      [] ->
        %MyCustomizedError{}

      _ ->
        %MyCustomizedError{message: "Alert: " <> value}
    end
  end
end
```

## Using exceptions

定义好的错误可以像内置错误那样使用，通过`raise/1`或`raise/2`即可。

- `raise/1`根据模块名抛出特定的错误；如果参数是字符串，则会抛出一个`RuntimeError`，并把该字符串作为消息。
- `raise/2`根据模块名抛出特定的错误，并且接受一个属性参数，用来获取带有相应消息的错误。
