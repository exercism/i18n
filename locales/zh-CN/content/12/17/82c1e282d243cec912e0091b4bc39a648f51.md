# 说明

你是一位热衷观鸟的爱好者，会记录过去七天里有多少只鸟来过你的花园。

你有六个任务，全都与来过你花园的鸟的数量有关。

## 1. 查看上周的计数是多少

为了方便比较，你总是把上周的计数副本放在手边，上周的计数是：0、2、5、3、7、8 和 4。创建一个包含上周计数的向量：

```clojure
last-week
;;=> [0 2 5 3 7 8 4]
```

## 2. 查看今天有多少只鸟来访

实现`today`函数，返回今天有多少只鸟来过你的花园。鸟的计数按天排序，第一个元素是最早那天的计数，最后一个元素是今天的计数。

```clojure
(def birds-per-day [2 5 0 7 4 1])
(today birds-per-day)
;;=> 1
```

## 3. 让今天的计数自增

实现`inc-bird`函数，让今天的计数自增：

```clojure
(inc-bird birds-per-day)
;;=> [2 5 0 7 4 2]
```

## 4. 检查是否有哪天没有鸟来访

实现`day-without-birds?`谓词函数：如果有一天没有任何鸟来过花园，就返回`true`；否则返回`false`：

```clojure
(day-without-birds? birds-per-day)
;;=> true
```

## 5. 计算前若干天来访鸟的数量

实现`n-days-count`函数，返回从这周开始起来过你花园的鸟的数量，但把计数限制在从这周开始算起的指定天数内。

```clojure
(n-days-count birds-per-day 4)
;;=> 14
```

## 6. 计算忙碌天数的数量

有些日子比其他日子更忙。忙碌的一天是指有 5 只或更多鸟来过你花园的日子。
实现`busy-days`函数，返回忙碌天数的数量：

```clojure
(busy-days birds-per-day)
;;=> 2
```

## 7. 检查是否为奇特的一周

过去一年里，你发现有些星期都呈现出同样奇特的规律：鸟的数量在 1 和 0 之间交替。实现`odd-week?`函数：如果这周的鸟数量规律符合这个奇特规律，就返回`true`：

```clojure
(odd-week? [1 0 1 0 1 0 1])
;;=> true
```
