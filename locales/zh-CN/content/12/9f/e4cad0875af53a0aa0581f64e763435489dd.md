# 关于

[concept:csharp/enumerables]() 可以用 [`foreach`循环][foreach-statement]来迭代：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

`foreach`循环由三部分组成：

1. 声明：定义用来保存被迭代值的变量。这个变量（只能）在循环内部使用。
2. 可迭代对象：可以被迭代的对象。
3. 循环体。

## for 循环与 foreach 循环

不过，一般来说 `foreach`循环比 `for`循环更可取，原因如下：

- `foreach`循环保证会迭代到*所有*值。而使用 `for`循环时，很容易漏掉元素，例如因为差一错误。
- `foreach`循环更具*声明式*风格，你的代码表达的是你*想做什么*，而 `for`循环表达的是你*想怎么做*。
- `foreach`循环绝不会出错，而 `for`循环很容易出现差一错误。
- `foreach`循环适用于所有集合类型，包括那些不支持用索引器访问元素的类型。

为了保证 `foreach`循环会迭代到*所有*值，编译器不允许在 `foreach`循环内部修改集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

`for`循环确实比 `foreach`循环有一些优势：

- 你可以在想要的下标处开始或结束。
- 你可以使用任何（布尔）终止条件。
- 你可以通过自定义循环变量的自增方式来跳过元素。
- 你可以通过倒着计数，从后往前处理集合。
- 你可以在不涉及集合的场景中使用 `for`循环。
