# 说明补充

## 寄存器

| 寄存器 | 用途 | 类型 | 描述 |
| -------- | ------------ | ------- | ----------------------------------- |
| `$a0`    | 输入        | 整数 | 上限                               |
| `$a1`    | 输入/输出 | 地址 | 存放质数的目标数组 |
| `$v0`    | 输出       | 整数 | 质数的个数                    |
| `$t0-9`  | 临时    | 任意     | 用于临时存储          |
