# 简介

Perl 是一门由 Larry Wall 创造的编程语言，于 1987 年首次发布。

## 包与模块

包是代码的集合，通常放在一个同名、扩展名为`.pm`的模块文件里。
之后可以把模块导入到另一个文件中，通常使用`use`关键字。

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## 变量

变量分为标量（`$foo`）、数组（`@bar`）和哈希（`%baz`）三种。
为了简单起见，这里只使用标量变量。
标量值可以是以下这些：字符串、数字、布尔值，或者指向某个东西的[引用][perlreftut]。
值不存在时就是`undef`。


`my`和`our`这两个关键字会在词法作用域中声明一个变量，例如`my $foo;`。
使用`our`时，该变量还会被别名到同名的包变量。
还有其他声明变量的方式，这里不做介绍。

可以用`=`运算符给变量赋值，例如`$foo = 1;`，也可以在声明变量的同时进行，例如`my $foo = 1;`。

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## 子程序

`sub`关键字用于声明一个[子程序][perlsub]。
`return`关键字会退出子程序，返回指定的值；如果没有给出任何值，则返回空列表。
如果没有明确指定`return`，返回值将由使用该子程序的上下文（标量、列表还是空上下文）以及它的最后一条语句决定。

```perl
sub hello () {
    return 'Hello, World!';
}
```

较新的 Perl 版本允许你在[签名][perlsubsig]中指定形参。
形参列表可以包含标量、数组或哈希变量。
空的形参列表表示该子程序接受零个实参。
较老版本的 Perl 需要从特殊变量`@_`中取出实参，这里不做介绍。
