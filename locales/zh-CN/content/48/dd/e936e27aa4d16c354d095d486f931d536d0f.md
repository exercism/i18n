# 说明

你负责维护地震仪阵列的处理站，这是一个记录地面如何移动的传感器网络。

读数以数据块的形式到达。
有些是存储为 32 位浮点数的地面位移，另一些是存储为 32 位整数的原始计数和状态字。
处理站一次性处理整个数据块，对每个值应用相同的操作。

你有 6 个任务，每个任务都作用于内存中保存的一个数据块。
你通过内存地址接收操作数，并通过结果地址写出答案。
本练习中的所有内存地址都是 16 字节对齐的。

~~~~exercism/note
本练习中的计算应使用 SIMD 按位运算和移位来完成，而不是标量运算。
~~~~

## 1. 整流迹线

对于震级分析而言，重要的只是每个地面位移的大小，而不是它的方向。
第一个处理步骤把每个读数折算为非负值。

实现 `rectify_trace` 函数，它计算每个读数的绝对值。
一个数据块包含 4 个读数，每个都是一个 32 位浮点数。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个整流后的读数会被写入其中。
- `trace`：录得的读数的内存地址，包含 4 个值，每个都是一个 32 位浮点数。

```c
trace  = {1.5, -2.25, 0.0, -135.75}
result = {1.5,  2.25, 0.0,  135.75}
```

这个函数没有返回值。

## 2. 读取震动的尺度

分析人员按 2 的幂为震动分级：接近 `8.0` 的读数处于尺度 `3`，接近 `0.25` 的读数处于尺度 `-2`。
这个尺度已经作为指数域存储在每一个浮点数内部。

一个 32 位浮点数的布局是：第 31 位是符号位，第 30 到 23 位是 8 位指数，第 22 到 0 位是 23 位尾数。
存储的指数带 127 的偏置，因此该数的值为 `(-1)^sign * 1.fraction * 2^(exponent - 127)`。

实现 `reading_scale` 函数，它把每个读数的无偏指数提取为有符号 32 位整数。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个尺度会被写入其中，每个都是一个有符号 32 位整数。
- `trace`：整流后的读数的内存地址，包含 4 个值，每个都是一个 32 位浮点数。

```c
trace  = {8.0, 0.25, 1.0, 13.5}
result = {  3,   -2,   0,   3}
```

这个函数没有返回值。
所有读数都是规格化的非零浮点数。

## 3. 降低分辨率

为了长期存储，原始位移计数以更粗的分辨率保存：每个计数都除以 2 的某个幂。

位移计数是有符号的：地面可以向两个方向移动。
要正确地除以它们，需要用能保留符号的移位。

实现 `coarsen_displacements` 函数，它把每个有符号计数除以 `2^shift`，并向负无穷方向取整。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个粗化后的计数会被写入其中，每个都是一个有符号 32 位整数。
- `counts`：原始计数的内存地址，包含 4 个有符号 32 位整数。
- `shift`：要除的 2 的幂，是一个介于 `0` 和 `31` 之间的 64 位无符号整数。

```c
counts = {1024, -1024, 25, -25}
shift  = 3
result = { 128,  -128,  3,  -4}
```

~~~~exercism/note
可以使用指令 `movq` 把一个 64 位整数从通用寄存器复制到 `xmm` 寄存器，而不改变其底层的位表示。
~~~~

这个函数没有返回值。

## 4. 门控通道

每个处理站会合并两次记录活动，然后静默硬件报告标记为故障的通道。
每个数据块包含 4 个通道掩码，每个都是一个无符号 32 位整数，其中每一位代表一个通道：`1` 表示启用，`0` 表示禁用。

实现 `gate_channels` 函数，它合并任一次活动中启用的通道，然后清除每一个被标记为故障的通道。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个门控后的掩码会被写入其中，每个都是一个无符号 32 位整数。
- `enable_a`：第一次活动的启用掩码的内存地址，包含 4 个无符号 32 位整数。
- `enable_b`：第二次活动的启用掩码的内存地址，包含 4 个无符号 32 位整数。
- `faulty`：故障通道掩码的内存地址，包含 4 个无符号 32 位整数。

```c
enable_a = {0b1100, 0b0001, 0b1111, 0b0000}
enable_b = {0b0110, 0b0001, 0b0000, 0b0000}
faulty   = {0b0100, 0b0011, 0b1001, 0b1111}
result   = {0b1010, 0b0000, 0b0110, 0b0000}
```

这个函数没有返回值。

## 5. 切换校准位

处理站每天运行一次校准流程，翻转每个状态字中一组选定的配置位，并保持其他所有位不变。
但有些位被硬件锁定，无论校准流程请求什么，都绝不能改变。
把同一个流程运行两次即可恢复原来的配置。

实现 `toggle_calibration` 函数，它在每个状态字中恰好翻转那些在对应的切换掩码中置位、而在对应的锁定掩码中未置位的位。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个更新后的状态字会被写入其中，每个都是一个无符号 32 位整数。
- `status`：当前状态字的内存地址，包含 4 个无符号 32 位整数。
- `toggle`：切换掩码的内存地址，包含 4 个无符号 32 位整数。
- `locked`：锁定掩码的内存地址，包含 4 个无符号 32 位整数。

```c
status = {0b1100, 0b0001, 0b1111, 0b1010}
toggle = {0b0110, 0b0011, 0b1111, 0b1010}
locked = {0b0010, 0b0001, 0b1100, 0b0000}
result = {0b1000, 0b0011, 0b1100, 0b0000}
```

这个函数没有返回值。

## 6. 放大迹线

阵列的每个通道都有自己的增益微调，以 2 的幂表示：增益 `3` 把该通道的读数乘以 `8`，增益 `-5` 把它除以 `32`。

处理站不做任何一次乘法，而是通过操作每个浮点数的指数域来应用这些增益。

实现 `amplify_trace` 函数，它把每个读数乘以 `2` 的该通道增益次幂，且只对原始位进行操作。

这个函数按以下顺序接收实参：

- `result`：一个缓冲区的内存地址，4 个放大后的读数会被写入其中。
- `trace`：读数的内存地址，包含 4 个值，每个都是一个 32 位浮点数。
- `gains`：各通道增益的内存地址，包含 4 个有符号 32 位整数。

```c
trace  = {1.5, -2.0, 0.25, 96.0}
gains  = {  2,    1,    3,   -5}
result = {6.0, -4.0,  2.0,  3.0}
```

这个函数没有返回值。
所有读数都是规格化的非零浮点数，并且每一个放大后的结果也都是规格化的。
