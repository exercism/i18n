# 提示

## 通用

- [`Set` API 文档][set-docs]中列出了 `Set` 接口可用的所有方法。

## 1. 开始收集

- [`HashSet` 类][hashset-docs]有一个接收 `Collection` 的构造函数。

## 2. 扩充收集

- 看一下 `Set` 接口上[`add` 方法][set-add-docs]的签名。

## 3. 开始交易

- 把`Set`包在`new HashSet<>()`里，就能创建它的副本。
- [`Set` 接口][set-docs]有一个方法，可以移除另一个 `Collection` 中包含的所有元素。

## 4. 找出共有的卡牌

- 把`Set`包在`new HashSet<>()`里，就能创建它的副本。
- [`Set` 接口][set-docs]有一个方法，可以只保留另一个 `Collection` 中包含的所有元素。

## 5. 所有的卡牌

- 把`Set`包在`new HashSet<>()`里，就能创建它的副本。
- [`Set` 接口][set-docs]有一个方法，可以添加另一个 `Collection` 中包含的所有元素。

[set-docs]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Set.html
