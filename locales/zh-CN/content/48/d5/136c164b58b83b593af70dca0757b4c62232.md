# 测试

安装依赖。

```sh
dart pub get
```

运行测试。

```sh
dart test
```

如果想查看每个测试更详细的输出，可以使用 expanded 报告器。

```sh
dart test -r expanded
```

大多数练习都包含多个测试，默认情况下除第一个之外，其余测试都会被跳过。
如果想逐个完成测试，可以在每完成一个测试后，把它的`skip: true`改成`skip: false`。

另一种做法是不修改文件，直接一次运行所有测试。

```sh
dart test --run-skipped
```

提交时，在线测试运行器会运行所有测试，包括被跳过的测试。
