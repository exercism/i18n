# 简介

[`Rational numbers`][rational]是用整数分子除以整数分母得到的分式。

例如，我们可以把`2//3`精确地存为一个分式，而不是`Float64`的近似值`0.6666...`。

好处在于（除非出现[integer overflow][integer-overflow]这种极端情况），有理数始终是精确的，从而避免浮点数常常无法避免的舍入误差。

更多细节请参阅 Julia 的[手册页面][julia-rational]。

有理数是一种相当简单的数值类型，其行为基本符合你的预期。
由于从早期版本起，有理数就一直是 Julia 的标准类型，大多数函数都像接受整数和浮点数那样接受它们作为输入。

## 创建有理数

创建非常简单，只需在两个整数之间使用`//`。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

公因数会被自动约去，把分数化为其[“最简形式”][lowest-terms]：能够准确表示该分数的最小整数，且分母非负。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

无穷大的结果可以接受，但[`NaN`][NaN]不行。

```julia-repl
julia> 1//0
1//0

julia> float(1//0)
Inf

julia> 0//0
ERROR: ArgumentError: invalid rational: zero(Int64)//zero(Int64)
```

## 有理数的算术运算

常见的[`arithmetic operators`][operators]`+ - * / ^ %`同样适用于有理数，与其他数值类型基本相同。

整数和其他`Rational`都可以参与运算，结果是`Rational`。
如果表达式中包含`float`，输出就是`float`，精度可能会有所损失。

如果需要`float`，只需用`float()`函数把有理数转换一下。
用有理数在漫长的计算过程中保持精度，最后再转换成浮点数，这是很常见的做法。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

有理数还可以和[复数][complex]结合使用。
复数会在[单独的概念][complex-concept]中讨论。

## 其他运算

在 Julia 中，有理数就是普通的数字。
编译器通常会按需要自动转换类型。

不过要注意，只有当分数具有有限小数表示时，比较运算才能得到预期结果：

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

否则，比较前应该先把`Rational`转换成`Float`：

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

数学函数可以接受有理数作为输入，但可能返回浮点数结果：

```julia-repl
julia> sqrt(9//16)
0.75
```
