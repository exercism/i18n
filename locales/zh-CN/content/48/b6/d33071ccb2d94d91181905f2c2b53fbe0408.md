# 简介

Elixir 允许函数拥有多个子句，从而有助于践行**开闭原则**。这样就不必编写冗长且硬编码的控制逻辑，而是可以编写针对性强的函数，轻松地添加或移除行为。

Elixir 提供了 _多个函数子句_ 和 _守卫_ 来编写：

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

在运行时，Elixir 会从源文件的顶部到底部依次测试，以决定该调用哪个函数子句。

未使用的变量应以下划线开头。
