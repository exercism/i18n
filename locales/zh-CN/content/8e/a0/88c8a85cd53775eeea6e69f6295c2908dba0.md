# 说明

在本次练习中，你将编写代码，帮助一位自由职业者与客户沟通某些项目的报价。你将编写几个实用方法，用来快速计算客户的费用。

```exercism/note
`rate_per_hour`形参和`day_rate`方法都与金额有关。它们的计量单位是单位时间对应的金额，分别以小时和天计。
```

## 1. 根据小时费率计算日费率

一位客户联系自由职业者，询问收费标准。自由职业者解释说，他们**_每天工作 8 小时_**。不过，自由职业者只知道自己在项目中的小时费率。请根据小时费率，帮他们估算日费率。

```abap
DATA(freelancer_rates) = NEW zcl_freelancer_rates( ).

freelancer_rates->day_rate( 89 ).
// => 712
```

日费率不需要四舍五入，也不需要改成“固定”精度。

## 2. 根据固定预算计算工作天数

又有一天，一位项目经理邀请自由职业者参与一个预算固定的项目。请根据固定预算和自由职业者的小时费率，帮他们计算在预算用完之前能工作多少天。结果_必须_**向下取整**为最接近的整数。

```abap
freelancer_rates->days_in_budget(
  budget        = 20000
  rate_per_hour = 89 ).
// => 28
```

## 3. 计算大型项目的折扣费率

自由职业者的客户经常会聘请他们承接持续数月的项目。这种情况下，自由职业者决定对每一个完整的月份给予折扣，剩余的天数按日费率计费。你出色的工作与生活平衡意味着你每个自然月只工作 22 天，所以**_每个月有 22 个可计费天数_**。请根据小时费率、项目包含的可计费天数以及月度折扣率，帮他们估算这类项目的费用。折扣总是以数字传入，`42%`会变成`0.42`。结果_必须_**向上取整**为最接近的整数。

```abap
freelancer_rates->price_with_monthly_discount(
  rate_per_hour = 89
  num_days      = 230
  discount      = '0.42' ).
// => 97972
```
