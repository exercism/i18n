# C 风格指南

本指南介绍的是 C 语言学习轨道中练习的示例文件和测试文件应当遵循的风格。

本指南中的规则，是对 [.clang-format][] 文件所设规则的补充，或是对这些规则的明确说明。

## C 标准

代码应符合 C99 标准，其正式名称是 ISO/IEC 9899:1999。
不应使用 POSIX，也不应使用非标准的库函数、类型，以及实现之外的其他引用。

## 命名

一般来说，类型、变量、结构和文件的名称应使用蛇形命名法，所有字母都小写，并用下划线`_`分隔名称的各个组成部分。

```c
void some_foo_function(char * input_string, int input_string_length);
```

### 枚举

枚举名通常应使用单数，而不是复数。

枚举标签应使用全大写的蛇形命名法。

```c
enum heading {
    HEADING_NORTH,
    HEADING_EAST,
    HEADING_SOUTH,
    HEADING_WEST
}
```

### 宏

定义常量的宏使用全大写的蛇形命名法。

```c
#define CONSTANT 0x4000
```

宏名使用全大写蛇形命名法值得提倡，但类似函数的宏也可以用小写蛇形命名法来命名。

### 类型

应优先使用标准的定宽类型（`stdint.h`中定义的那些），而不是基本整数类型。

类型`bool`（来自`stdbool.h`）优先于`_Bool`。

同样，表示与内存相关的数量时，优先使用`size_t`和`ptrdiff_t`（来自`stddef.h`）。

程序使用`typedef`定义的类型，命名时都应加上`_t`后缀。
我们清楚 POSIX 保留了`_t`后缀，但本轨道目前并未使用 POSIX。

## 包含防护

所有头文件都应使用包含防护。

通常，一组包含防护应包住头文件的全部内容。

示例实现（`.meta/example.h`）和练习桩（`exercise_name.h`）中的防护，应使用与练习名一致的宏名。
防护宏的名称，其大小写应遵循上文关于宏的规则。

例如，对于`hello-world`练习，可以这样写：

```c
#ifndef HELLO_WORLD_H
#define HELLO_WORLD_H

//...

#endif
```

## 参数

所有函数的声明和定义中，都应给函数参数命名。
这一点对`.c`和`.h`文件都适用。
各处使用的名称应保持一致。
也就是说，下面这个函数原型虽然是合法的 C 代码，但风格不正确，因为参数没有名字：`void foo(int);`。
如果其他所有声明和定义也都使用参数名`bar`，那么正确的原型就是`void foo(int bar);`。

在更简单或更合适的情况下，应优先选择按值而不是按指针传递实参的参数。
尤其要注意，这也包括`struct`类型的参数。

如果学习者不需要在自己的实现中修改某个指针类型参数的值，这个参数就应该用`const`修饰。

## 测试文件布局

每个练习的测试文件都遵循一种特定的布局。
这种布局既能帮助贡献者识别文件的各个部分，也能帮助学习者理解测试是如何工作的。

和大多数 C 源文件一样，测试文件以包含指令开头。

```c
#include "vendor/unity.h"
#include "../src/file_under_test.h"
// any other includes here
```

包含指令之后是`setUp()`和`tearDown()`函数。
到目前为止，还没有练习用到它们（函数体是空的），但必须把它们保留在原处，这样测试文件才能在所有平台上都正确编译。

```c
void setUp(void)
{
}

void tearDown(void)
{
}
```

接下来是测试函数会用到的辅助函数。
这类辅助函数的名称不应使用`test_`前缀。

然后是测试函数本身。
这些函数的名称带`test_`前缀。
除第一个之外，每个测试函数的第一条语句都应该是`TEST_IGNORE();`。
第一次出现它时，后面应跟上行注释`// delete this line to run test`。

例如：

```c
static void test_the_first(void)
{
   test_first_foo();
}

static void test_the_second(void)
{
   TEST_IGNORE();               // delete this line to run test
   test_second_foo();
}

static void test_the_third(void)
{
   TEST_IGNORE();
   char grade = 'A';
   test_third_foo(grade);
}
```

文件最后是`main()`函数。
`main()`的函数体本身也遵循一种特定的布局。
首先调用`UNITY_BEGIN()`，接着是一个空行，然后是各个测试。
最后一个测试后面再跟一个空行，然后返回`UNITY_END()`的结果。

```c
int main(void)
{
    UNITY_BEGIN();

    RUN_TEST(test_foo);
    RUN_TEST(test_bar);

    return UNITY_END();
}
```
