# 介绍

Haxe 是一门强类型语言，不过在需要时可以绕过类型系统。给一个名字赋值称为定义变量。定义变量时，既可以显式指定它的类型，也可以让 Haxe 编译器推断类型。因此，下面两种变量定义是等价的：

```haxe
var explicitVariable:Int = 10; // Explicitly typed
var implicitVariable = 10; // Implicit typed
```

使用 `=` 运算符可以更新变量：

```haxe
var number = 0; // Initial value
number = 1; // Updated value
```

如果尝试赋给变量的值类型与变量不同，编译器会报错：

```haxe
var number = 1; // Variable number is of integer type
number = "Hello" // Error trying to assign a string to an integer variable
```

类里面的函数称为_方法_。方法可以有零个或多个形参。所有形参都必须显式指定类型。与形参一样，方法的返回类型也无法推断，必须显式写出。方法使用 `return` 关键字返回值：

```haxe
function add(x:Int, y:Int):Int {
  return x + y;
}
```

调用方法时，需要指定它所在的类和方法的名称，并传入实参：

```haxe
var sum = add(1, 2) // sum = 3
```

Haxe 中的作用域定义在`{`和`}`字符之间。

Haxe 支持两种注释。单行注释以 `//` 开头，多行注释写在 `/*` 和 `*/` 之间。
