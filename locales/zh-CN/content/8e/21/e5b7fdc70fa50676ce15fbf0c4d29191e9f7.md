# 运算符重载

运算符重载是某些编程语言中的一种特性，它允许重新定义标准运算符（加法`+`、减法`-`、乘法`*`和除法`/`），让它们能够作用于自定义类型。

这样能让代码的语法更直观：对自定义类型的运算，可以和基本类型的运算用同一种方式来表达。

在 Cairo 中，运算符重载是通过实现特定的 trait 来完成的。

每个运算符都有一个与之关联的 trait，重载某个运算符，就是为自定义类型实现这个 trait。
不过，一定要审慎地使用运算符重载。

滥用会导致困惑，让代码更难维护，比如被重载的运算符本身并没有什么语义的时候。

来看一个例子：需要把两个`Potions`合并。

`Potions`有两个数据字段：mana 和 health。

合并两个`Potions`时，应该把各自对应的字段相加。

```rust
struct Potion {
    health: felt252,
    mana: felt252,
}

impl PotionAdd of Add<Potion> {
    fn add(lhs: Potion, rhs: Potion) -> Potion {
        Potion { health: lhs.health + rhs.health, mana: lhs.mana + rhs.mana }
    }
}

fn main() {
    let health_potion: Potion = Potion { health: 100, mana: 0 };
    let mana_potion: Potion = Potion { health: 0, mana: 100 };
    let super_potion: Potion = health_potion + mana_potion;
    // Both potions were combined with the `+` operator.
    assert(super_potion.health == 100, '');
    assert(super_potion.mana == 100, '');
}
```

在上面的代码中，我们为`Potion`类型实现了`Add` trait。

`add`函数接收两个实参：`lhs`和`rhs`（分别指左侧和右侧的操作数）。

函数体返回一个新的`Potion`实例，它的字段值是`lhs`和`rhs`的组合。

如示例所示，重载运算符需要指明被重载的具体类型。

被重载的泛型 trait 是`Add<T>`，而我们通过`Add<Potion>`为`Potion`类型定义了具体的实现。
