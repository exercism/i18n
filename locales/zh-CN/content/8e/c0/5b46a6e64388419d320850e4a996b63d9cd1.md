# 说明补充

## 实现

机器人名字是可能用完的。一旦所有可能的机器人名字都已分配出去，就应当返回一个错误。

## 附加测试

当你让 `go test` 通过之后，你会发现测试套件里有一个名为 `TestCollisions` 的测试，它默认会被跳过，因为可能要花很长时间。
这个测试会不断创建新的机器人，直到再也不能给机器人分配新的名字为止。

要让这个测试运行起来，请删掉这一行：

```go
t.Skip("skipping test as it can take a long time to run if solution is sub-optimal.")
```

要让这个测试通过，你必须确保机器人的名字之前没有被用过，并且名字能够被高效地分配。
