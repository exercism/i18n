# 测试

## Clojure CLI

Exercism 上的 Clojure 练习都自带一个 `deps.edn` 文件，其中有一个 `:test` 别名，用来调用 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)：

``` bash
$ clj -X:test
```

## Leiningen

也可以用 Leiningen 运行练习的测试，只需在练习目录下执行以下命令：

```bash
lein test
```

## REPL

要用 REPL 运行练习的测试，请在练习目录下执行以下命令：

```bash
$ clj
```

或

```bash
$ lein repl
```

然后用`require`引入练习的测试命名空间和 Clojure 测试命名空间）：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
```

接着在 `<exercise>-test` 上调用 `run-tests`：

```clojure
;; replace <exercise> with the exercise's name
=> (clojure.test/run-tests '<exercise>-test)
```
