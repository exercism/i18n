# 介绍

Swift 有一组语句，可以用来改变循环的正常控制流。这些语句被称为控制转移语句。你已经见过`return`，本概念会介绍另外几个，包括`continue`、`break`和标签。

## Continue

有时需要提前跳到循环的下一次迭代，而不执行当前迭代中剩余的语句。可以使用`continue`关键字来实现这一点。执行`continue`时，循环会跳到下一次检查，看看循环的下一次迭代能否运行，也就是 while 循环和 repeat-while 循环中的`while`，或者 for-in 循环中判断序列里是否还有另一个元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

break 用于提前退出循环。执行`break`时，循环会立即退出，程序继续执行循环之后的第一个语句。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## 标签

循环嵌套时，有时可能需要用`break`或`continue`来退出或重新开始外层循环，而这些外层循环包含着使用`break`或`continue`的那个循环。在这种情况下，可以用标签来指定要退出或重新开始的循环。在启动循环的`while`、`repeat`或`for`前面写上名字加冒号，就能给循环加标签。

想看看这样使用标签的效果，请看下面的循环。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```

## Fallthrough

`fallthrough`关键字用于在 switch 语句中贯穿到下一个 case。也就是说，下一个 case 中的代码会被执行，而不会检查它的条件。这会让 switch 语句的行为像其他编程语言那样：在那些语言里，匹配到某个 case 之后，不需要用`break`语句来退出 switch 语句。你可以在[《Swift 编程语言》][fallthrough]中了解更多关于`fallthrough`的内容。

```swift
let value = 1
switch value {
case 1:
  print("One")
  fallthrough
case 2:
  print("Two")
}

// prints:
// One
// Two
```
