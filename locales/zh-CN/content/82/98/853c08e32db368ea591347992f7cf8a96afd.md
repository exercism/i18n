# 说明

作为一名准魔术师，Elyse 需要练习一些基本功。她有一叠牌，想要对它们进行各种操作。

为了方便起见，她只用 1 到 10 的牌，因此这叠牌可以用一个数字数组来表示。某张牌的位置对应数组中的下标。也就是说，位置 0 指的是第一张牌，位置 1 是第二张牌，依此类推。

<!-- prettier-ignore-start -->
~~~~exercism/note
除了两个函数之外，其他函数都应该先更新牌堆数组，然后返回修改后的数组。这种常见的工作方式叫作 Builder 模式，它让你能够优雅地把函数像链子一样串起来。

两个例外是 `getItem`，它应该返回指定位置上的牌；以及 `checkSizeOfStack`，如果给定的大小相符，它应该返回 `true`。
~~~~
<!-- prettier-ignore-end -->

## 1. 从牌堆中取出牌

要取出一张牌，请返回给定牌堆中下标为 `position` 的那张牌。

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. 交换牌堆中的一张牌

施展一点手法，把下标为 `position` 的那张牌换成提供的替换牌。
返回调整后的牌堆。

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. 在牌堆顶部插入一张牌

在牌堆顶部插入一张新牌，让一张牌出现。
返回调整后的牌堆。

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. 从牌堆中移除一张牌

从牌堆中移除给定 `position` 上的那张牌，让一张牌消失。
返回调整后的牌堆。

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. 移除牌堆顶部的牌

移除牌堆顶部的那张牌，让一张牌消失。
返回调整后的牌堆。

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. 在牌堆底部插入一张牌

在牌堆底部插入一张新牌，让一张牌出现。
返回调整后的牌堆。

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. 从牌堆底部移除一张牌

移除牌堆底部的那张牌，让一张牌消失。
返回调整后的牌堆。

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. 检查牌堆的大小

检查牌堆的大小是否等于 `stackSize`。

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
