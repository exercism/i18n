# 简介

模式匹配是指根据值是否匹配给定的（可能嵌套得很深的）模式来选择分支的过程。在 Haxe 中，**模式匹配**通过`switch`表达式和各个`case`表达式实现。

看看下面这个数据结构：

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- 模式总是从上到下依次匹配。
- 与输入值匹配的最靠上的那个模式，会执行它对应的表达式。
- `_`模式可以匹配任何值，所以`case _:`等同于`default:`

## 枚举匹配

枚举可以自然地通过其构造函数进行匹配：

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
