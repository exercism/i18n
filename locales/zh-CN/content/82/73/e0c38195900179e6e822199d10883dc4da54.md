## 格式

Common Lisp 并不在意代码的缩进和排版，也不在意你用的是空格还是制表符，但这一点对提交到 exercism 的解答来说却很重要。
Exercism.org 的代码组件不太能处理好制表符和空格混用的情况，所以建议只使用空格，这样代码对人工审阅者来说也更易读。
请查看你的编辑器设置，了解如何做到这一点。
下面是针对一些常用编辑器的说明。

### VIM

使用以下命令，确保 VIM 只使用空格进行缩进：

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

（也可以写成一行`:set tabstop=2 shiftwidth=2 expandtab`）。把它加到你的`~/.vimrc`文件里，就能一直使用这套设置。

### Emacs

Emacs 非常适合编辑 Common Lisp，并且有许多强大的附加包可用。要让原版 Emacs 与 exercism.org 良好配合，你只需要对下面这段代码求值：

`(setq-default indent-tabs-mode nil)`

把它放进你的`~/.emacs`（或`~/.emacs.d/init.el`）里，就能在每次启动 Emacs 时自动生效。

Emacs 和 Common Lisp 的一个推荐附加包是 [SLIME][slime]，它与 REPL 紧密集成，让迭代式编码和测试变得非常轻松。
