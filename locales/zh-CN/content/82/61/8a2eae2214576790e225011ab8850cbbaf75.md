# 向量作为栈

栈是一种线性数据结构，专为从一端访问而优化。一个合适的比喻是一叠穿在轴上的纸：新的纸片总是从同一端放入，而取出的顺序与放入的顺序相反。最先放入的纸最后取出，最后放入的纸最先取出。

Rust 的`Vec`数据结构适合用作栈。[`push`方法](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.push)会把元素添加到向量的尾部。[`pop`方法](https://doc.rust-lang.org/std/vec/struct.Vec.html#method.pop)会从向量中移除最后一个元素。`push`和`pop`都只需要均摊`O(1)`时间。

## 示例

在这个示例中，我们用一个向量作为栈，来实现一个简单的[逆波兰表示法](https://en.wikipedia.org/wiki/Reverse_Polish_notation)计算器。完整源码可以在[演练场](https://play.rust-lang.org/?version=stable&mode=debug&edition=2018&gist=b40514e282cb753d0c3272778f92d736)中找到。

```rust
#[derive(Default)]
pub struct RpnCalculator {
    stack: Vec<Value>,
}

impl RpnCalculator {
    pub fn evaluate(&mut self, argument: Argument) -> Result<(), Error> {
        match argument {
            Argument::Value(value) => self.stack.push(value),
            Argument::Operator(operator) => {
                let b = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let a = self.stack.pop().ok_or(Error::StackUnderflow)?;
                let output = operator.execute()(a, b);
                self.stack.push(output);
            }
        }
        Ok(())
    }

    pub fn conclude(self) -> Result<Value, Error> {
        if self.stack.len() == 1 {
            Ok(self.stack[0])
        } else {
            Err(Error::IncompleteCalculation)
        }
    }
}
```
