# 关于

Scala 是一门随你成长的编程语言：从简单的小脚本到大型多平台应用，都能胜任。

Scala 将面向对象编程和函数式编程融合在一门简洁的高级语言之中。Scala 的静态类型有助于在复杂应用中避开 bug，它的 JVM、JavaScript 和 Native 运行时让你既能构建高性能系统，又能轻松接入庞大的库生态系统。

* 特性
    * JVM 互操作性：Scala 运行在 JVM 上，因此 Java 和 Scala 的技术栈可以混合使用，实现无缝集成。
    * JS 和 Native 互操作性：得益于 [Scala.js](https://www.scala-js.org/) 和 [Scala Native](https://github.com/scala-native/scala-native)，Scala 可以运行在浏览器和原生设备上。
    * 类型推断：Scala 是静态类型语言。不过，Scala 提供了类型推断，以减轻高级类型系统带来的负担。
    * 面向对象：Scala 是一门纯面向对象的语言，因为每个值都是对象。对象的数据类型和行为由类和特质描述。类的抽象通过子类化，以及灵活的、基于混入的组合机制来扩展，从而避免多重继承的问题。
    * 函数式：Scala 也是一门函数式语言，因为每个函数都是一个值。Scala 提供了定义匿名函数的轻量级语法，支持高阶函数，允许函数嵌套，还支持柯里化。Scala 的 case class 以及对模式匹配的内置支持，为许多函数式编程语言中使用的代数类型提供了建模能力。单例对象提供了一种便捷的方式，把不属于某个类的函数组织在一起。
    * 并发与分布式：对集合使用数据并行操作，用 actor 实现并发和分布式，或者用 future 进行异步编程。
