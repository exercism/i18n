# 说明

活动策划人 Mika 升职了，作为新职责的一部分，她现在负责活动数据库。她很快发现，很多数据的存储方式都很难处理，于是你们组队，用一个一次性脚本把这些数据整理干净。

由于这个脚本只会运行一次，而且你对数据的结构很有把握，你觉得这里很适合使用 Gleam 的 _let 断言_。

## 1. 提取错误

每场过去的活动都有一个数组，记录着活动期间发生的问题。它们以结果的形式存储，但始终是`Error`变体。

实现`extract_error`函数，它接收一个预期始终为`Error`的结果，并返回其中包含的错误值。

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. 移除团队前缀

团队名称前面都加上了“Team ”这个前缀，但这并不需要。实现`remove_team_prefix`函数，从团队名称中移除这个前缀。

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. 拆分地区和团队

每场活动都由一个团队负责，每个团队都属于一个地区。在数据库中，它们存储在一个字符串里，用逗号分隔。

实现`split_region_and_team`函数，把这个字符串拆分成一个包含两个字符串的元组，一个表示地区，一个表示团队。团队名称中的“Team ”前缀应该被移除。

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
