# 关于

[C++](https://en.wikipedia.org/wiki/C%2B%2B)（读作 cee plus plus）是一门通用编程语言，由 [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) 于 1979 年在贝尔实验室开始开发。它非常流行，尤其是在那些需要速度，或者需要访问某些底层功能的应用程序中。它通常被视为一门中级语言，因为它同时涵盖高级和底层语言的特性。

C++ 支持[过程式](https://en.wikipedia.org/wiki/Procedural_programming)、[面向对象](https://en.wikipedia.org/wiki/Object-oriented_programming)、[函数式](https://en.wikipedia.org/wiki/Functional_programming)和[泛型](https://en.wikipedia.org/wiki/Generic_programming)编程。C++ 的编译器几乎可用于所有平台，包括 Windows、Mac OS 和 Linux。

主要优势：
- **类型安全：** 封装必要的不安全操作
- **资源安全：** 并非所有资源管理都是在管理内存
- **性能：** 对几乎所有系统的部分场景来说，它都很重要
- **可预测性：** 适用于硬实时和软实时系统
- **可教学性：** 代码的复杂度应当与任务的复杂度成正比
- **可读性：** 人和机器（“可分析性”）
- **直接映射到硬件：** 指令和基本数据类型
- **零开销抽象：** 带有构造函数和析构函数的类、继承、泛型编程、函数式编程技巧

C++ 的标准由国际标准化组织（ISO）维护，截至 2018 年 6 月，C++ 的当前版本是 C++17（它并不是说 C++ 的第 17 个版本，而是表示该标准于 2017 年获得批准）。

C++ 最棒的一点是，它能运行在各种设备上，从资源极其有限的嵌入式处理器，到最大的大型机超级计算机，以及介于两者之间的每一台个人电脑。
