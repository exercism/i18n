# 关于

[推导式][for]提供了一种以简单、声明式的方式转换_可枚举对象_的机制。它是 Elixir 中遍历可枚举对象的_语法糖_。

[//]: # (elixir-formatter-disable-next-block)

```elixir
for s <- ["a", "b", "hello", "c"], # 1. generator
  String.length(s) == 1,           # 2. filter
  into: "",                        # 3. collectable
  do: String.upcase(s)

# => "ABC"
```

推导式由三个部分组成：

1. _生成器_：
   - 从实现了 [_Enumerable_][enumerable] 协议的结构中枚举出的值。
   - 用于解构枚举值的模式匹配表达式。
2. _过滤器_：布尔条件，用来选择在创建新值时使用哪些枚举值。
3. _可收集对象_：实现了 [_Collectable_][collectable] 协议的结构，用来收集新值。

推导式有单行和多行两种写法。当使用多个生成器时，会枚举出所生成值的[笛卡尔积][cartesian-product]。也就是说，第一个生成器生成的每个值，都会与第二个生成器生成的每个值各配对一次。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]

for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```

对于_可枚举对象_中**生成的每一个值**，`do`块中的值都会被插入到_可收集对象_中。

```elixir
for _ <- [1, 2, 3], do: :a
# => [:a, :a, :a]
```

推导式中也可以出现模式匹配：既可以写在`<-`的左侧，也可以单独成行。

```elixir
for {atom, str} <- [a: "string"], do: str
# => ["string"]

for pair <- [a: "string"],
    {atom, str} = pair do
  str
end

# => ["string"]
```
