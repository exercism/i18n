# 说明

给定任意两个数组`A`和`B`，判断以下哪种情况成立：

- 数组`A`与数组`B`相等；或
- 数组`A`包含数组`B`（`A`是`B`的超数组）；或
- 数组`A`被数组`B`包含（`A`是`B`的子数组）；或
- 以上都不成立，因此数组`A`和`B`不相等

具体来说，如果两个数组的值相同且顺序一致，那么数组`A`与数组`B`相等。
如果数组`A`包含一段与`B`相等的连续子序列，那么`A`是`B`的超数组。
如果数组`B`包含一段与`A`相等的连续子序列，那么`A`是`B`的子数组。

例如：

- 如果`A = []`且`B = []`（两个数组都为空），那么`A`和`B`相等
- 如果`A = [1, 2, 3]`且`B = []`，那么`A`是`B`的超数组
- 如果`A = []`且`B = [1, 2, 3]`，那么`A`是`B`的子数组
- 如果`A = [1, 2, 3]`且`B = [1, 2, 3, 4, 5]`，那么`A`是`B`的子数组
- 如果`A = [3, 4, 5]`且`B = [1, 2, 3, 4, 5]`，那么`A`是`B`的子数组
- 如果`A = [3, 4]`且`B = [1, 2, 3, 4, 5]`，那么`A`是`B`的子数组
- 如果`A = [1, 2, 3]`且`B = [1, 2, 3]`，那么`A`和`B`相等
- 如果`A = [1, 2, 3, 4, 5]`且`B = [2, 3, 4]`，那么`A`是`B`的超数组
- 如果`A = [1, 2, 4]`且`B = [1, 2, 3, 4, 5]`，那么`A`和`B`不相等
- 如果`A = [1, 2, 3]`且`B = [1, 3, 2]`，那么`A`和`B`不相等
