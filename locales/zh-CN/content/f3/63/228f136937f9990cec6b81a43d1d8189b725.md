# 说明

在这个练习中，你将为一个简单的整数计算器实现错误处理。
这个计算器需要支持加法、乘法和除法运算，并把结果以格式化字符串的形式返回。
你还要实现错误处理，来应对非法运算和除以零的情况。

目标是做出一个能正常工作的计算器，按下面的格式返回字符串：

```rust
SimpleCalculator::calculate(16, 51, "+"); // => returns "16 + 51 = 67"

SimpleCalculator::calculate(32, 6, "*"); // => returns "32 * 6 = 192"

SimpleCalculator::calculate(512, 4, "/"); // => returns "512 / 4 = 128"
```

## 1. 实现计算器运算

这个任务的主要函数是`SimpleCalculator::calculate`，它接收三个实参：两个整数，以及一个表示运算的`ByteArray`。
请实现以下运算：

- 使用`+`符号的**加法**
- 使用`*`符号的**乘法**
- 使用`/`符号的**除法**

## 2. 处理非法运算

如果运算符号不是`+`、`*`或`/`，计算器应当 panic，或者返回错误：

- 如果运算是一个空字符串，就以`ByteArray`错误消息`"Operation cannot be an empty string"`触发 panic。
- 对于其他任何无效运算，返回`Result::Err("Operation is out of range")`。

```rust
SimpleCalculator::calculate(100, 10, "-"); // => returns Result::Err("Operation is out of range")

SimpleCalculator::calculate(8, 2, ""); // => panics with "Operation cannot be an empty string"
```

## 3. 处理除以零时的错误

当试图除以`0`时，计算器应当 panic，并给出错误消息，说明不允许除以零。
返回的结果应当是值为`'Division by zero is not allowed'`的`felt252`。

```rust
SimpleCalculator::calculate(512, 0, "/"); // => panics with 'Division by zero is not allowed'
```
