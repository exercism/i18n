# 简介

## 列表

考虑到我们使用的语言 Lisp 的名字是 _LIST Processing_（列表处理）的缩写，你可能会以为它具备处理元素列表的功能，而你想得没错！

虽然 Common Lisp 还有列表以外的其他数据结构，但列表的使用仍然非常普遍。

Common Lisp 中的列表是元素的序列。它也被称为**cons**（主要是出于历史原因）。
元素本身的类型不必相同。
例如，你可以有一个包含`1`、`two`、`"III"`的列表。

### 创建列表

你可以直接输入一个带引号的列表，像这样：`'(1 two "III")`，这样就会创建并求值一个列表（求值结果为`(1 two "III")`）。

另外还有两个用于创建列表的主要函数：`list`和`cons`。

`list`接受零个或多个实参，求值结果是一个由这些值创建的列表：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`接受两个元素，创建一个列表，第一个元素作为它的`car`（列表的头部），第二个元素作为它的`cdr`（列表的剩余部分）：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

函数`car`和`cdr`可以用来访问列表的`car`和`cdr`。

（`first`和`rest`是`car`和`cdr`的同义词，作用完全相同。）

### 长度与随机访问

列表的长度可以用`length`求得。
空列表的长度为零。

可以用`nth`访问任意一个元素（注意，列表的下标从 0 开始）。

请求一个大于列表长度的下标并_不_是错误，它反而会求值为`nil`：

```lisp
(nth 23 '(short list)) ; => nil
```

此外还有几个辅助方法可以访问列表的前几个元素：`first`、`second`、`third`，一直到`tenth`。很妙吧？

### 合并列表

两个或多个列表可以用`append`合并：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

传给`append`的每个实参都必须是列表。
