# 关于

Rust 实现了 [char][char type] 类型，用来表示单个字符。`char`字面量写在单引号里，例如`'a'`。
每个`char`占 4 个字节，表示一个 [Unicode 标量值][unicode scalar]。

然而，[`char`][character type]并不总是我们心目中的字母。有些语言（例如印地语）会使用[变音符号][diacritics]，它们是一些特殊符号，用来修饰所附着的字符。虽然在 Rust 中变音符号是一个单独的`char`，但我们通常当作一个字母来看的，其实是变音符号和它所修饰的那个字符。

字符连同它的变音符号，合起来称为[字形簇][grapheme cluster]。有一些外部 crate 可以用来处理字形簇，例如 [unicode-segmentation][unicode-segmentation]。

示例

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

输出

```rust
2
'u'
'\u{308}'
```

'\u{308}' 是`char`字面量的另一种写法。`\u`表示它是一个 Unicode `char`，而`{308}`是该字符或变音符号唯一的 Unicode 编号。
