# 说明

Karl 想在 Exercism 网站上跟踪记录一份他要学习的语言列表。
Karl 需要能够添加新语言、移除旧语言，并检查某些语言是否在列表中。
如果 Karl 想学 Java 或 Kotlin，那就太令人兴奋了！

## 1. 定义一个函数来检查语言列表是否为空

Karl 需要知道他这份语言列表是否有一天会变成空的，这样他就能去找更多语言来学习！
定义一个名为`isEmpty`的方法，如果列表中没有语言就返回`true`。

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. 定义一个函数向列表中添加语言

Karl 很期待学习 Kotlin 和 Python！
帮 Karl 开个头吧：定义一个名为`addLanguage`的方法，它接收他想学习的语言，并把它添加到列表中。

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. 定义一个函数从列表中移除语言

Karl 决定他现在不想学 Scala 了。
帮 Karl 把它从列表中移除：定义一个名为`removeLanguage`的方法，它接收他要移除的语言，并把它从列表中删除。

```java
languageList.removeLanguage("Scala");
```

## 4. 定义一个函数返回列表中的第一项

Karl 想记住他添加到列表中的第一种语言（它仍在列表中）。
定义一个名为`firstLanguage`的方法，返回列表中的第一种语言。

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. 定义一个函数返回列表中有多少种语言

Karl 需要知道他打算学多少种语言。
帮 Karl 找到答案：定义一个名为`count`的方法，返回列表中语言的数量。

```java
int two = languageList.count(); // 2
```

## 6. 定义一个函数判断某种语言是否在列表中

Karl 想回忆起他究竟是想学 Python 还是 Ruby。
定义一个名为`containsLanguage`的方法，它接收他询问的语言，这样 Karl 就能弄清楚了！

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. 定义一个函数判断这个列表是否令人兴奋

如果 Karl 想学 Java 或 Kotlin，那就太令人兴奋了！
定义一个名为`isExciting`的方法，如果 Karl 想学 Java 或 Kotlin 就返回 true。

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
