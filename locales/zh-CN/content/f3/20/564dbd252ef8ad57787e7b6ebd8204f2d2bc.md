# 说明

在这个练习中，你将处理日志行。

每行日志都是一个格式如下的字符串："[<LEVEL>]: <MESSAGE>*"。

## 1. 从日志行中获取消息

实现`LogLevels.message()`函数，返回日志行中的消息，并去掉开头和结尾的空白字符。

## 2. 从日志行中获取日志级别

实现`LogLevels.logLevel()`函数，返回日志行中的日志级别，并转换为小写。

## 3. 重新格式化日志行

实现`LogLevels.reformat()`方法，它接收一个日志行和一个位置字符串，将其重新格式化为包含两行的消息。
第一行的格式为`<LEVEL>@<LOCATIOON>:`，其中：

* `<LEVEL>`是小写的日志级别（参见第 2 步“从日志行中获取日志级别”）。
* `<LOCATION>`是作为第二个参数传入的位置。

第二行包含恰好两个空格，后面是日志消息（参见第 1 步“从日志行中获取消息”）：

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
