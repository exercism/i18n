# 类的静态关键字

类是 PHP 中代码组织的一个单位，通常表示某个事物、服务或过程的实例。
借助`static`和`self`关键字，属性和方法可以关联到类本身，供所有实例使用（也可以不依赖任何实例）。

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## 限制

类的静态方法只能调用本类中的其他静态属性或静态方法。
