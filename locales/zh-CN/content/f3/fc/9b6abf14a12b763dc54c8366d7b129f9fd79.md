# 安装 Delphi 和 DUnitX 测试框架 #
## Windows ###

可以免费使用[社区版](https://www.embarcadero.com/products/delphi/starter)。请按照产品自带的安装说明操作。

## 基于非 Windows 的操作系统 ###

Delphi 只能在基于 Windows 的操作系统中运行。你也可以在装有 Windows 的虚拟机里运行 Delphi。

## 安装 DUnitX 测试框架 ###
在安装 Delphi XE8 及更高版本时，可以选择一并安装 DUnitX。不过，我建议按照下面的说明，直接从作者的 GitHub 仓库手动获取一份 DUnitX，因为那里的更新更频繁。

成功安装 Delphi 之后，如果你发现自己的 Delphi 缺少这个测试框架，请按照以下步骤获取并安装 DUnitX。

- DUnitX 是 [VSoftTechnologies](https://www.github.com/VSoftTechnologies) 的开源项目。DUnitX 的 GitHub 仓库在[这里](https://github.com/VSoftTechnologies/DUnitX)。
- 最好先 fork 这个仓库，然后把 fork 克隆或以其他方式下载到本地。
- Vincent Parrett 在一篇博客文章里给出了把 DUnitX 安装到 Delphi 的分步说明，文章在[这里](https://www.finalbuilder.com/resources/blogs/postid/702/dunitx-has-a-wizard)。

## 为 DUnitX 配置 Delphi ###

如果你的 Delphi 安装中本来没有 DUnitX，因此你手动安装了它，请按照下面这些带图步骤，对 Delphi 做必要的配置更改，好让它能找到你安装的 DUnitX。

*注意：这里假定此时你已经完成了 Delphi 的安装。*

- 启动 Delphi。如果是全新安装，你很可能看到一个类似下图的`Welcome Page`。

[![欢迎页面](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepageLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/00delphiwelcomepage.png)

- 在顶部菜单中找到并点击`Tools`。
 
![Tools](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/01delphiclicktools.png)

- 点击`Options`。

![Options](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/02delphiclickoptions.png)

- 在 Options 界面左侧找到并点击`Environment Variables`。

[![Options 界面上的 Environment Variables](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariablesLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/03delphioptionsenvironmentvariables.png)

- 点击 `User overrides` 分组中的`New`按钮

![点击 New](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/04delphioptionsenvironmentvariablesclicknew.png)

- 这时应该会弹出一个 New User Variable 窗口，里面有两个字段。在上面的字段中，把变量名填为`DUNITX`。在下面的字段中，填入你的 DUnitX 副本的完整路径，例如我的是 `C:\Program Files\Embarcadero\Studio\19.0\source\DUnitX`。*你不一定有 19.0 这个文件夹，这取决于你安装的 Delphi 版本。*然后点击`Ok`按钮关闭这个窗口。

![New User Variable](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/05delphinewuservariable.png)

- 在 Options 界面左侧找到并点击`Library`。

[![Library](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibraryLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/06delphioptionslibrary.png)

- 点击 Directories 分组中 Library 路径旁边的`...`按钮

[![... 按钮](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbuttonLogo.png)](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/07delphiclicklibrarypathbutton.png)

- 在 Directories 窗口中填入你前几步创建的变量名。输入后应该显示成这样`$(DUNITX)` 

![Directories](https://raw.githubusercontent.com/exercism/delphi/master/docs/img/08delphidirectoriesinputvarnameclickadd.png)

- 点击`Add`按钮，把这一新项添加到列表中。

- 点击`Ok`按钮保存这项更改。


- 最后，点击 Options 窗口上的`Ok`按钮，保存所有更改。

现在 Delphi 就能找到与 DUnitX 测试框架库相关的单元了。

*注意：这里假定学员使用的是 Delphi XE 或更高版本。*
