# 说明

在这个练习中，你的任务是为一台加密设备编写软件，它通过对数据执行变换来工作。你需要一种方法，把简单的函数组合起来，灵活地创建复杂的函数。

对于每个任务，返回一个可以从调用方作用域中调用的匿名函数。

## 1. 创建一个加法函数

实现 `secret_add`。它应该返回一个函数，这个函数接受一个实参，并把传给 `secret_add` 的实参加到它上面。

```gleam
let adder = secret_add(2)
adder(2)
// -> 4
```

## 2. 创建一个减法函数

实现 `secret_subtract`。它应该返回一个函数，这个函数接受一个实参，并从该实参中减去传给 `secret_subtract` 的秘密值。

```gleam
let subtractor = secret_subtract(2)
subtractor(3)
// -> 1
```

## 3. 创建一个乘法函数

实现 `secret_multiply`。它应该返回一个函数，这个函数接受一个实参，并把它乘以传给 `secret_multiply` 的秘密值。

```gleam
let multiplier = secret_multiply(7)
multiplier(3)
// -> 21
```

## 4. 创建一个除法函数

实现 `secret_divide`。它应该返回一个函数，这个函数接受一个实参，并用它除以传给 `secret_divide` 的秘密值。

```gleam
let divider = secret_divide(3)
divider(32)
// -> 10
```

## 5. 创建一个函数组合器

实现 `secret_combine`。它应该返回一个函数，这个函数接受一个实参，并按顺序把传给 `secret_combine` 的两个函数应用到它上面。

```gleam
let multiply = secret_multiply(7)
let divide = secret_divide(3)
let combined = secret_combine(multiply, divide)

combined(6)
// -> 14
```
