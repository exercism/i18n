# 简介

## `if`表达式

`jq`的**条件表达式**是`if A then B else C end`。

`if-then-else`和所有`jq`内置过滤器一样，也是一个过滤器：它接收一个输入，并产生一个输出。

如果表达式`A`产生一个“真”值，`if`过滤器就会对`B`求值。
否则，它会对`C`求值。
`if`过滤器的输入会传给`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**可选的**；下面两条语句是等价的。

```jq
if A then B else . end
if A then B end
```
~~~~

## 嵌套`if`语句

可以用`elif`添加更多条件。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

需要多少`elif`子句，就写多少。

## 真值性

`jq`中唯一的“假”值只有`false`和`null`。
其他一切都是“真”的，连数字 0、空字符串、空数组和空对象也不例外。

## 布尔运算符

用**布尔运算符**`and`和`or`可以构建复杂的查询。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

要取反，可以用`not`。它是一个**过滤器**，不是运算符。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## 替代运算符

用**替代运算符**可以在表达式为 false 或 null 时指定一个“默认”值。

```jq
A // B

# This is identical to
if A then A else B end
```

例如：

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
