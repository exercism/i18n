# 简介

我们将这门_语言_称为 **AWK**，把解释 AWK 程序的_可执行文件_称为 **`awk`** 或 **`gawk`**。

## 模式与动作

AWK 程序由**模式-动作对**组成

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**模式**可以是用来匹配输入的正则表达式，也可以是任何结果为 true/false 值的表达式。

**动作**是一条或多条 AWK 命令，外面那对花括号不能省略。

如果模式的结果为 _true_，就执行对应的动作。

## 记录与字段

AWK 把输入解析成一系列**记录**，每条记录又会被拆分成零个或多个**字段**。

默认行为是：

- 用换行符作为“记录分隔符”把输入拆分成记录，因此每一_行_就是一条记录。
- 用空白字符作为“字段分隔符”把记录拆分成字段，因此每一个_词_就是一个字段。

## 模式与动作（续）

模式可以省略，这时动作会_对每一条输入记录_执行。

动作也可以省略，这时的默认动作是打印当前记录。

### 特殊模式

有两个特殊模式经常会用到。

- `BEGIN` 会在读取任何输入之前执行关联的动作。
- `END` 会在所有输入读取完毕之后执行关联的动作。

## 字段变量

字段用 `$1`、`$2`、`$3` 等表示，当前记录则是 `$0`。

下面还有一些其他常用的内置变量。

### 控制输入解析的内置变量

- `RS` 是输入记录分隔符。如前所述，它的默认值是换行符。
- `FS` 是输入字段分隔符。

这些变量通常在 `BEGIN` 动作块中设置。

### 传递信息的内置变量

这些变量由 AWK 在程序执行过程中自动设置。

- `NF` 保存当前记录中的字段数。
  - 要获取最后一个字段的值，可以使用 `$NF`。
- `NR` 保存当前记录号。
  - 处理多个输入文件时，`NR` 保存的是到目前为止已处理的记录总数。
- `FNR` 保存当前输入文件中的当前记录号。
  - 为了说明 NR 和 FNR 的区别，这里给出一个常见的 AWK 惯用法。
    ```awk
    NR == FNR {action}
    ```
    意思是“如果累计的记录号等于当前文件的记录号”，这只对_第一个输入文件_中的记录才可能成立。

## 真假值

AWK 对真假值的判断与 C 相同。

- 数字 `0` 是 false。
- 其他任何数字都是 true。

由于 AWK 是文本处理语言，真假值的概念也扩展到了字符串。

- 空字符串 `""` 是 false。
- 任何非空字符串都是 true。

## 注释

注释以 `#` 字符开头，一直延伸到行尾。

## 示例

在类 Unix 系统上，`/etc/passwd` 包含用户信息。每个用户占一行，各字段之间用冒号分隔。

要列出用户名：

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

注意 `{print $1}` 这个动作没有模式，所以会对每条记录执行。

如果我们想只输出把 bash 作为登录 shell 的用户，可以这样做：

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
