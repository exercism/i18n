# 数组

`ARRAY{T}`是一行长度固定、类型为`T`的值。

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
   sizes : ARRAY{INT} := |3, 1, 2|;
```

## 大括号

`ARRAY{STR}`读作“由`STR`组成的数组”。大括号里放的是**类型参数**：单独的`ARRAY`不是一个类型，因为数组总得是某种东西的数组。Sather 库的很大一部分就是这样构建的，自己写这样一个类则是以后的事。

## 位置

```sather
row[0]                 -- the first
row[row.size - 1]      -- the last
row.size               -- how many
```

位置从`0`一直到`.size - 1`。数组知道自己有多大，而且从不改变：不能往`ARRAY`里追加元素。

## 不用字面量创建数组

`#ARRAY{INT}(n)`创建一个包含`n`个值的数组，每个值都是零：

```sather
   counts ::= #ARRAY{INT}(5);      -- five noughts
   counts[0] := 7;
```

给某个位置赋值，也是在`:=`左边用同一对方括号。

## 越界

在普通构建中，读写一个不存在的位置是不会被检查的。它不会给出有用的提示让程序停下来，而是会读写内存中紧随其后的内容，不管那里是什么。两个习惯就能避开这种情况：用`.size - 1`，而不要用靠目测数出来的数字；用`until!(i >= a.size)`结束循环，而不要用字面量。

## 打印数组

`.str`会以大括号的形式给出内容，在理清思路时很方便：

```sather
   #OUT + row.str;      -- {Mia,Ana,Ben}
```
