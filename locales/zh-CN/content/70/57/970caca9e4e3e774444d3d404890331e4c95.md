# 学习

Odin 是一门系统编程语言。
和 C 一样，程序员必须手动管理内存。
不过它是一门相当简单的语言。

以下资源可以帮助你学习 Odin：

先从这里初步体验这门语言：

* 观看 [Odin 简介][video]，由 Odin 的创造者主讲。
* 阅读 [Odin 简介][intro] 文章，作者是[《Understanding the Odin Programming Language》][book]一书的作者。
* 研究 [演示文件][demo]，它用代码展示了 Odin 的各种概念。

想深入了解，可以看看：

* [Odin 语言概览][overview]。
* [官方软件包][packages]的文档。
* [《Understanding the Odin Programming Language》][book] 这本书（付费）。
* 官方的 [“Odin Examples”][examples] 示例集。
