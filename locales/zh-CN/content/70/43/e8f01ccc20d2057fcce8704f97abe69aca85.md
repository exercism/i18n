# 测试

大多数测试会检查你是否通过给 [result] 赋值，或向 [exit] 传值，返回了预期的值。

有些测试会检查你是否 [raise] 了预期的异常。

## 运行测试

运行测试需要依赖`make`工具。

在练习目录中，在控制台/终端里输入：

```sh
make
```

如果你连练习的解答文件都没碰过，就会看到类似这样的提示：

```
Please implement your solution.
```

所以，在开始编写解答之前，把这一行删掉。

默认情况下，只会执行第一个测试。

```text
TAP version 14
1..10
ok 1 - ...
```

要运行所有测试，输入：

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

所有测试都通过后，这个练习就完成了，你可以提交解答了。

你也可以传入对应的编号，只运行某一个测试，例如：

```sh
make test=2
```

就只会执行第二个测试。
