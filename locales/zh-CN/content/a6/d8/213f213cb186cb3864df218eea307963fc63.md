# 简介

在 Haxe 中，属性是类的一种成员，它提供对该类内部数据的访问。调用者可以设置或读取（get）这些数据。属性由 set 访问器和/或 get 访问器组成。

属性与其他类成员一样有访问修饰符（public、private 等），但 set 访问器可以拥有独立于 get 访问器的访问级别，反之亦然。属性不必同时具备两个访问器，它可以只有其中一个（get 或 set）。

读访问和写访问会直接体现在语法中，如下例所示：

```haxe
class Main {
  public var x(default, null):Int;
}
```

`default`和`null`都是特殊的**访问标识符**。访问标识符规定了字段被读取时（第一个标识符）和字段被写入时（第二个标识符）的行为。可接受的值有：

- `default`：如果字段是 public，就允许正常的字段访问。
- `null`：只允许从定义该字段的类内部访问。
- `get/set`：访问会以调用访问器方法的形式生成（`get_x()`）。
- `dynamic`：与`get/set`相同，但无法验证访问器方法是否存在。
- `never`：完全不允许访问。

下面是一个完整的示例：

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
