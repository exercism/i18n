# 简介

## 真值与假值

在 Common Lisp 中，除了 `()` 是“false”之外，其他所有值都是“true”。
有两个特殊的常量符号`t`和`nil`，它们的值分别是 true 和 false。

## 条件表达式

Common Lisp 提供了几种不同的条件表达式，它们的主要区别在于支持的分支数量。

- `when` 和 `unless` 只支持一个分支：

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

测试表达式之后的部分可以包含多个表达式。

- `if` 提供经典的 if-then-else 结构：

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

注意，then 和 else 子句都只能是一个表达式。

- `cond` 提供了一种不用嵌套 `if` 表达式就能拥有多个分支的方式：

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

注意，测试表达式之后的表达式数量没有限制。

- `case` 提供经典的“switch”风格结构：它会把一个值与多个分支逐一比较：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

注意，和 `cond` 一样，测试表达式之后的表达式数量没有限制。
