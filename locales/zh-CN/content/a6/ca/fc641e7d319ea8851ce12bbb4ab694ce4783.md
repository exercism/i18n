# 简介

Common Lisp 中的符号是一种特殊的值，可以指向其他值；对于_关键字_来说，则指向它们自身。
当 Lisp 对符号求值时，会用符号所指向的值来替换它：

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

注意，关键字由开头的冒号（`:`）表示。

引用，也就是在 S-表达式前面加上一个 `'`，它告诉 Lisp 不要对该表达式求值。
在我们的 `defun` 示例中，通过引用 `'foo`，我们避免了 Lisp 去查找（并且查不到）`FOO` 本该指向的东西，而是返回 `FOO` 这个值本身。
如果我们的程序里从未在任何地方定义过 `FOO`：

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

目前，你可以把它仅仅看作从函数中返回符号的一种方式，不过之后我们会再次讨论引用，并在未来的概念练习中进一步探究它的影响。
