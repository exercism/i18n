# 关于

Ruby 是一门动态的强类型语言。
在动态语言中，变量或对象的类型在运行时才确定，也就是说，它的值或类型一直到最后一刻（被翻译解析时）都还能改变。
那“强类型”又是什么意思呢？
一旦我们知道了一个变量或对象的类型，Ruby 就会严格要求你能拿它做什么，例如：

```ruby
x = '2'
y = x + 'n'
# => '2n'
```

**但是**

```ruby
x = '2'
y = x + 2
# => TypeError (no implicit conversion of Integer into String)
```

记住，在 Ruby 中一切皆对象。
连类本身也是`Class`类的实例。

例如：

```ruby
1.class
# => Integer

Integer.is_a?(Object)
# => true

Class.is_a?(Object)
# => true
```

这意味着我们也可以这样定义类：

```ruby
Car = Class.new do
  def run
    'running'
  end
end

Car.new.run
# => 'running'
```

最后，请记住，`Integer`对象保存的值可以由一个或多个（连续的）数字定义，它的方法支持许多[数学运算符][integers-docs]。

[integers-docs]: https://docs.ruby-lang.org/en/master/Integer.html

~~~~exercism/note
文档中经常用 `Class#method_name` 这样的语法来引用实例方法，而类或模块级别的方法则写成 `Class::method_name`。
`::`叫作_作用域解析运算符_，用来引用类或模块级别的常量或方法。
你会在 Ruby 文档、邮件列表和其他支持渠道中遇到这种写法。
不过你会发现，在我们的内容里，引用类方法和模块方法时用的是 `ClassName.method_name` 或 `ModuleName.method_name`。
~~~~
