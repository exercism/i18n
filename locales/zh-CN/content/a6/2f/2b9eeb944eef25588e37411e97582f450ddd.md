# 关于

Gleam 可以运行在 Erlang 虚拟机（BEAM）上，也可以运行在 JavaScript 运行时上。还有很多其他语言也使用这些运行时，而从 Gleam 调用用这些语言写成的代码，往往很有用。

Gleam 的*外部函数*功能可以把其他语言中的函数导入 Gleam，并且调用时没有任何运行时开销。

如果你的 Gleam 项目运行在 Erlang 虚拟机上，而你想调用 Erlang `lists`模块里的`reverse`函数，可以给 Gleam 函数头部加上`@external`属性，像这样：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

之后就可以像普通的 Gleam 函数那样调用它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果尝试为 JavaScript 运行时编译这段代码，编译会失败并给出错误信息，因为没有对应的 JavaScript 实现。这时可以为 JavaScript 运行时另外指定一个实现：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

还可以写一个 Gleam 实现，在当前编译目标没有外部实现时使用：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
