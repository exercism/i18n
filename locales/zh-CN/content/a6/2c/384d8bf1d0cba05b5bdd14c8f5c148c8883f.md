# 提示

所有这些任务都需要用到`print`命令：
```awk
{print "something", "something else"}
```

## 1. 列出用户名

* 使用[`FS`变量][var-fs]来定义字段分隔符。

## 2. 打印行号

* 使用[内置变量`NR`][var-nr]获取行号。

## 3. 打印主目录无效的记录。

* 主目录是第 6 个字段。
* 使用给定的`startsWith`函数。
* 使用[布尔运算符][boolean-ops]：`&&`、`||`、`!`。

## 4. 打印使用 bash 的有效用户数

* 登录 shell 是最后一个字段，你可以使用[`NF`变量][var-nf]。
