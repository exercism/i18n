# 介绍

## 带标签的字段

当自定义类型的变体包含数据时，它被称为记录，其中包含的每个值都位于一个_字段_中。

```gleam
pub type Rectangle {
  Rectangle(
    Float, // The first field
    Float, // The second field
  )
}
```

为了提高可读性，Gleam 允许用名称给字段加上标签。

```gleam
pub type Rectangle {
  Rectangle(
    width: Float,
    height: Float,
  )
}
```

使用标签可以以任意顺序向记录的构造函数提供实参。

```gleam
let a = Rectangle(height: 10.0, width: 20.0)
let b = Rectangle(width: 20.0, height: 10.0)

a == b
// -> True
```

当自定义类型只有一个变体时，可以使用`.label`访问器语法来获取记录中的字段。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)

rect.height // -> 10.0
rect.width  // -> 20.0
```

当自定义类型只有一个变体时，还可以使用记录更新语法，在现有记录的基础上创建一个新记录，并将其中的部分字段替换为新值。

```gleam
let rect = Rectangle(height: 10.0, width: 20.0)
let tall_rect = Rectangle(..rect, height: 50.0)

tall_rect.height // -> 50.0
tall_rect.width  // -> 20.0
```

在模式匹配中提取记录的值时，也可以使用标签。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, width: _) if h >. 20.0 -> True
    _ -> False
  }
}
```

如果我们只想匹配其中一部分字段，可以使用展开运算符`..`来忽略其余字段。

```gleam
pub fn is_tall(rect: Rectangle) {
  case rect {
    Rectangle(height: h, ..) if h >. 20.0 -> True
    _ -> False
  }
}
```
