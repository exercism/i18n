# 迭代

在编程中，[迭代][iteration]指的是把一段代码重复执行多次的过程。这可以借助 `while` 循环、`until` 循环等方式实现，也可以借助递归来实现，也就是函数调用自身。

不过，大多数时候你想遍历的是一个元素集合，比如 `Array`、`Range` 或 `String`。Crystal 中的 `Array` 类和 `Range` 类都包含 [`Enumerable`][enumerable] 模块，它提供了许多用于遍历元素的方法。而 `String` 类则有一套自己的方法用来遍历字符。

Crystal 也不像其他语言那样有 `for` 语句，取而代之的是几个可以用来遍历的方法。

## 遍历

遍历集合最常见的方式是使用 [`each`][each] 方法，它会把集合中的每个元素依次传给块。用 `Range` 就能轻松做到这一点。假设你想在 1 和 3 之间循环，就可以用 `each` 方法遍历这个区间。

```crystal
(1..3).each do |n|
  puts n
end

# Output:
# 1
# 2
# 3
```

更简单的是，如果你只想重复执行固定次数，可以使用 [`times`][times] 方法，它定义在 `Int` 类上。

```crystal
3.times do |n|
  puts n
end

# Output:
# 0
# 1
# 2
```

## 遍历 `String`

`String` 是一串字符，不属于 `Enumerable` 模块，也就是说它有一套自己的方法用来遍历字符。遍历 `String` 最常见的方式是使用 [`each_char`][each_char] 方法，它会把 `String` 中的每个字符依次传给块。

~~~~exercism/note
`each_char` 方法传给块的是 `Char` 对象，而不是 `String` 对象。
~~~~

```crystal
str = "hello"
str.each_char { |char| puts char }

# Output:
# h
# e
# l
# l
# o
```

遍历 `String` 的另一种方式是使用 [`each_line`][each_line] 方法。这个方法主要在逐行读取文件时使用。

```crystal
str = "hello\nworld"
str.each_line do |line|
  puts line
end

# Output:
# hello
# world
```

## 遍历包含 `Enumerable` 模块的对象

[`Enumerable`][enumerable] 模块提供了许多用于遍历集合元素的方法。包含 `Enumerable` 模块的集合有 `Array`、`Range`、`Hash`、`Set` 等，后面的几个会在后续概念中介绍。

遍历 `Array` 最常见的方式是使用 [`each`][each] 方法，它会把 `Array` 中的每个元素依次传给块。

```crystal
arr = [5, 2, 3]
arr.each do |element|
  puts element
end

# Output:
# 5
# 2
# 3
```

### Map

[`map`][map] 方法是遍历 `Array` 的另一种方式，它返回一个新 `Array`，其中包含把块应用到每个元素后得到的结果。它和 `each` 方法类似，但会返回一个包含转换后元素的新 `Array`。当你想把某个函数应用到集合的每个元素上时，转换就非常有用，这是一种很常见的操作。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  element * 2
end

new_arr
# => [2, 4, 6]
```

配合 `if` 这样的控制流，你还可以筛选出要转换的元素。

```crystal
arr = [1, 2, 3]
new_arr = arr.map do |element|
  if element.odd?
    element * 2
  else
    element
  end
end

new_arr
# => [2, 2, 6]
```

## 简写

在 Crystal 中，有一种简写语法，可以在遍历集合并把某个方法应用到每个元素上时使用。当逻辑很简单、只需用一个方法转换时，它就很方便。写法是使用 `&.` 语法，后面跟上方法名。

```crystal
arr = [1, 2, 3]
arr.map(&.to_s)
# => ["1", "2", "3"]
```

### 带下标

有时你需要知道正在遍历的元素的下标，这时可以使用 [`each_with_index`][each_with_index] 或 [`map_with_index`][map_with_index] 方法。它会把每个元素及其下标传给块；该方法还接受一个可选参数，用来指定起始下标。

```crystal
arr = [1, 2, 3]
arr.each_with_index(4) do |element, index|
  puts "Element: #{element}, Index: #{index}"
end

# Output:
# Element: 1, Index: 4
# Element: 2, Index: 5
# Element: 3, Index: 6
```

注意，`String` 对象也可以使用 [`each_char_with_index`][each_char_with_index] 方法。

### sum

[`sum`][sum] 方法返回集合中所有元素的总和，它还接受一个可选的块，用于在求和前转换元素。它还接受一个可选参数，用来指定总和的初始值。

```crystal
arr = [1, 2, 3]
arr.sum
# => 6

arr.sum(2) { |n| n * 2 }
# => 14
```

### reduce

[`reduce`][reduce]（在其他语言中称为 fold）是一个方法，它通过一个合并操作和一个初始值，把集合中的所有元素合并起来。`reduce` 方法有一个累加器，它会被传给块，累加器是上一次迭代的结果。这样就形成了一个递归过程，把集合中的所有元素合并起来。

```crystal
arr = [1, 2, 3]
arr.reduce(0) do |acc, n|
  acc + n
end
# => 6
```

`reduce` 看起来可能和 `sum` 类似，但 `reduce` 更灵活，因为它允许你指定累加器的初始值和合并方式。`reduce` 可以用来实现 `sum`、`count` 等方法。
