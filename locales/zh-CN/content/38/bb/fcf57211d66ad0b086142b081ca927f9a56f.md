# 简介

## 方法重载

在 Java 中，方法重载是一项允许一个类拥有多个同名方法的特性，只要它们的形参列表不同即可。
它与编译时（或静态）多态有关。
这一概念对于编写功能相似但输入不同的方法至关重要。

### 为什么要重载方法？

方法重载可以提高程序的可读性。
不同的方法可以使用相同的名字，但形参不同。
具体调用哪个方法，取决于形参的数量或类型。

### 如何重载方法？

方法重载的关键在于方法的签名。
如果两个方法的签名不同，它们就被视为不同的方法。
重载方法有两种方式：

1. **形参数量不同**：方法可以同名，但形参数量不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(int x, int y) {
           System.out.println("Show with two ints: " + x + ", " + y);
       }
   }
   ```

2. **形参类型不同**：方法可以同名、形参数量也相同，但类型不同。

   ```java
   public class Display {

       public void show(int x) {
           System.out.println("Show with int: " + x);
       }

       public void show(String s) {
           System.out.println("Show with String: " + s);
       }
   }
   ```

### 需要注意的几点

- 重载的方法必须改变实参列表。
- 重载的方法也可以改变返回类型，但仅仅改变返回类型并不构成方法重载。
- 方法可以在同一个类中重载，也可以在子类中重载。
