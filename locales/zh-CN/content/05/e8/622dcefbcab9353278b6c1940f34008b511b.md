# 说明

在这个练习中，你将编写一些代码，帮助你按照最喜欢的烹饪书做出一份美味的千层面。

你有四个任务，全都与烹饪千层面所花的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义一个名为`$expected_minutes_in_oven`的常量。
根据烹饪书，烤箱的预期时间是 40 分钟：

```sh
$ jq -n -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  ...
```

## 2. 计算烤箱的剩余时间（分钟）

这个值接收千层面在烤箱中实际已经烤制的分钟数作为输入，并根据上一个任务中得出的烤箱预期时间，返回千层面还需要在烤箱中继续烤制多少分钟：

```sh
$ echo '{"actual_minutes_in_oven": 18}' | jq -f lasagna.jq
{
  "expected_minutes_in_oven": 40,
  "remaining_minutes_in_oven": 22,
  ...
```

## 3. 计算准备时间（分钟）

准备时间是指把千层面放进烤箱之前，准备好它所需要的时长。
每一层需要 2 分钟来准备。

```sh
$ echo '{"number_of_layers": 3}' | jq -f lasagna.jq
{
  ...
  "preparation_time": 6,
  ...
```

## 4. 计算总工作时间（分钟）

计算你烹饪千层面总共花了多少分钟。
它等于准备时间的分钟数，加上千层面此刻已经在烤箱中烤制的分钟数。

```sh
$ echo '{"actual_minutes_in_oven": 10, "number_of_layers": 2}' | jq -f lasagna.jq
{
  ...
  "total_time": 14,
  ...
```
