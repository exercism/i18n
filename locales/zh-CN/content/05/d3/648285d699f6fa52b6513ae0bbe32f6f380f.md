# 补充

## GNU awk 与任意精度算术

默认情况下，`awk`中的数字以双精度浮点数表示。这能提供 53 位的精度（参见手册中的[表 16.3][table-16.3]）。遗憾的是，这不足以完成本练习（剧透一下，有一个测试需要 63 位的精度）。

“精度不足”看起来是这样的：
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

如果相关库已经编译进`awk`可执行文件，GNU `awk`就能使用任意精度的数字。检查一下你的 awk 版本，看看有没有 “GNU MPFR”：
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

如果存在，就用`-M`选项启用这项功能：
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

如果我的`awk`没有`-M`怎么办？那就得调用一个能做任意精度算术的外部程序，比如`bc`。具体做法参见[从管道使用 getline 读入变量][getline-pipe]一节。
