# 说明补充

## 提示

在 Java 中，一般认为使用实例方法比类方法更好。不过，在某些情况下，把函数写成 `static` 是完全合适的。由于 Java 中的类对修改是封闭的（也就是说，不能像在 Ruby 或 JavaScript 等语言中那样，在类定义之外给它添加成员），所以无法直接为这个类添加新行为。如果你仍然想为某个类型定义行为，该怎么办？这种情况下，惯用的做法是写一个工具方法。

这类方法的集合通常被称为“工具类”。JRE 中就有这样的类，比如 [Arrays](https://docs.oracle.com/javase/9/docs/api/java/util/Arrays.html) 和 [Collections](https://docs.oracle.com/javase/9/docs/api/java/util/Collections.html)。

在这个练习中，我们希望 List 拥有 `map()`、`reduce()`、`filter()` 等方法。但 List 并没有这些方法，所以我们改用静态方法。

`foldLeft` 和 `foldRight` 方法属于“fold”函数，这个概念在函数式编程领域广为人知，但在面向对象领域就没那么常见了。参见维基百科上关于折叠的页面：[总体背景](https://en.wikipedia.org/wiki/Fold_(higher-order_function))和[签名与实现提示](https://en.wikipedia.org/wiki/Fold_(higher-order_function)#Linear_folds)。
