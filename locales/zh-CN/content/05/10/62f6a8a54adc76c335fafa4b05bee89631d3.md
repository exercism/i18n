# 基础简介

[Go](https://golang.org) 是一门静态类型的编译型编程语言。
Go 的语法与 C 相似。
由于它以前的域名 golang.org，这门语言常被称为 Golang，但它的正式名称是 Go。

基础概念将介绍三个主要的语言特性：包、函数和变量。

## 包

Go 应用以包的形式组织起来。
一个包是位于同一目录下的一组源文件。
同一目录下的所有源文件必须使用相同的包名。
按照惯例，包名就是导入路径中的最后一级目录名。
例如，[“math/rand” 包](https://golang.org/src/math/rand/)中的文件都以 `package rand` 这条语句开头。
导入一个包之后，只有名称以大写字母开头的实体（函数、类型、变量、常量）才能被使用或访问。
Go 推荐的命名风格是：标识符使用 `camelCase` 命名，而那些需要跨包访问的标识符则应该使用 `PascalCase`。

```go
package lasagna
```

## 变量

Go 是静态类型的，这意味着所有变量在编译时[都必须有确定的类型](https://en.wikipedia.org/wiki/Type_system)。

变量可以通过显式指定类型来定义：

```go
var explicit int // Explicitly typed
```

你也可以使用初始化值，编译器会把变量的类型设定为与初始化值的类型一致。

```go
implicit := 10   // Implicitly typed as an int
```

变量声明之后，可以用 `=` 运算符给它赋值。
变量一旦声明，它的类型就再也不能改变。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 常量

常量和变量一样保存着一份数据，但它的值在程序运行期间不能改变。

常量用 `const` 关键字定义，可以是数字、字符、字符串或布尔值：

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 函数

Go 函数接受零个或多个形参。
形参必须显式标明类型，不存在类型推断。

函数使用 `return` 关键字返回值。

调用一个函数时，需要写出函数名，并为函数的每个形参传入实参。

注意，Go 支持两种注释。
单行注释以 `//` 开头，多行注释则写在 `/*` 和 `*/` 之间。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
