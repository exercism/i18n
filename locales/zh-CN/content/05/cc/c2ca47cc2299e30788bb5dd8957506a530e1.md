# 测试

## 交互式测试

在你下载练习的目录中启动 REPL。

把测试文件加载到 REPL 中就能运行测试，命令是 `(load "exercise-test")`（把“exercise”换成相应的名称）。然后对 `(exercise-test:run-tests)` 求值，即可运行所有测试。

如果你直接在 REPL 中编写代码，那么只需对 `(exercise-test:run-tests)` 求值即可。

如果你把代码写在练习的 lisp 文件中，那么先用 `(load "exercise")` 加载它，再对 `(exercise-test:run-tests)` 求值即可。

## 从命令行测试

你可以用下面这行命令来启动测试（同样，把两处“exercise”换成相应的名称）

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
