# 简介

抽象语法树（AST），也叫_引用表达式_，是一种把代码表示为数据的方式。

AST 中的每个节点都是一个三元组。

```elixir
# AST representation of:
# 2 + 3
{:+, [], [2, 3]}
```

第一个元素是一个原子，代表要执行的操作。第二个元素是一个关键字列表，是元数据。第三个元素是实参列表，里面包含其他节点。像整数、原子和字符串这类字面量，在 AST 中直接用它们本身表示，而不是表示成三元组。

## 把代码转换成 AST

把 Elixir 代码转换成 AST，再把 AST 转换回代码，都是标准库的一部分。你可以在`Code`模块（例如把一段代码字符串转换成 AST）和`Macro`模块（例如遍历 AST，或把 AST 转换成字符串）里找到处理 AST 的函数。

注意，标准库里的所有函数都用“quoted”来指代 AST（它是_引用表达式_的缩写）。

把代码转换成 AST 的特殊形式叫做`quote`。它接受一个代码块，并返回它的 AST。

```elixir
quote do
  2 + 3 - 1
end

# => {:-, [], [
#      {:+, [], [2, 3]},
#      1
#    ]}
```

## 应用场景

把代码表示为 AST 的能力，是 Elixir 元编程的核心。_宏_是一种编写能生成 Elixir 代码的 Elixir 代码的方式，它的原理就是返回 AST 作为输出。

AST 的另一个应用场景是静态代码分析，比如 Exercism 自己的工具 Analyzer，你可能已经认识它了，就是那个会在你提交的解答下留言的小机器人。
