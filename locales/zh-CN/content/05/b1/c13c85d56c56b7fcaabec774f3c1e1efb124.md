# 简介

`bit`是计算中粒度最小的值。
`bit`一词代表“二进制位”。
它是执行环境中的一种数据存储单位，大到足以容纳一个可能取两个值之一的对象。
因此，它的二进制值要么是`1`，要么是`0`。
所有其他数据类型都由多个`bits`组成。
例如，一个`byte`通常由 8 个`bits`组成。

## 位掩码

位掩码可以是任何用来设置单个位的值。
例如，英文字母表中有 26 个字母。
至少 26 位的值（例如一个无符号 32 位整数）可以用作位掩码，为每个英文字母设置一个`true`或`false`条件。
任何位数足够、足以处理所需的一组`true`或`false`条件的值，都可以充当位掩码。
设置和读取单个位都要通过按位运算符来实现。

## 按位运算符

假设我们想记录一个`string`中出现了哪些字母。
在本例中，我们只用英文字母表中的 26 个字母。
我们的位掩码将是一个无符号 32 位整数。
`0`表示该字母没有出现。
`1`表示该字母出现一次或多次。
一开始，位掩码的位表示是 32 个连续的`0s`：`00000000000000000000000000000000`。
最右边的位置对应`A`。
左起第二个位置对应`B`，以此类推。
假设我们在一个循环中处理字符串里的所有字母，那么我们需要一行对任何字母都能用的代码来设置对应的位。

### 按位左移运算符：定位某一位的方法

`<<`是用于左移的按位运算符。

如果字母是`A`，我们不想左移；但如果字母是`B`，我们要左移 1 位；如果字母是`C`，我们要左移 2 位，以此类推。
虽然我们可以把`chars`看作`A`或`B`这样的字母，但在内存中`char`是以整数类型实现的，所以我们可以对`char`做简单的数学运算。
假设有一个名为`letter`的变量，代表我们正在处理的`char`，我们可以把`1`左移`letter`与`A`这个`char`之差那么多位，从而左移所需的位数，像这样：`1 << letter - 'A'`。
`A` - `A`等于`0`，所以如果`letter`是`A`，就左移`0`位。
`B` - `A`等于`1`，所以如果`letter`是`B`，就左移 1 位，以此类推。

### 按位或运算符：设置某一位的方法

一旦知道想要设置*哪一位*，就可以用按位或运算符（即`|`）来真正设置它。
`|`运算符的结果在左操作数或右操作数某一位被置位的每个位置上都为`1`。
所以，`0010 | 0001`的结果是`0011`。
（记住，这个值用二进制表示是`11`，用十进制表示是`3`。）
要把结果赋值给某个值，可以把`|`运算符和赋值运算符组合起来，像这样设置位：`|=`。
为简单起见，下面的示例没有使用循环，但它演示了如何在一个位掩码中处理字母`ABA`。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

我们为`A`把掩码最右边的部分设为`0001`，然后为`B`把掩码设为`0011`。
再设置一次`A`不会改变现有的掩码。
我们本可以先检查`A`是否已经设置，从而避免再次设置这一位。

### 按位与运算符：读取某一位的方法

`&`是按位与运算符。
`&`运算符的结果在左操作数和右操作数某一位都被置位的每个位置上都为`1`。
所以，`0011 & 0001`的结果是`0001`。
下面的示例演示了这一点。

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### 按位异或运算符：翻转某一位的方法

`^`是按位异或运算符。
既然有*或*运算符，就意味着还存在一种行为不同的*异或*运算符。
`^`运算符的结果在左操作数或右操作数*只有一个*在某一位被置位的位置上为`1`。
所以，`0001 ^ 0011`的结果是`0010`。
最右边的一位不会被置位，因为两个操作数在最右边的位置上*都*有`1`。
异或运算有时也记作 XOR。
如果对一个值做异或运算的结果再做一次异或运算，就会得到原来的值。
这可以用于一种非常简单的加密：用同一个密钥既加密又解密数据。
例如

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## 位域

我们已经看到，打包进简单数据类型的位可以按位置来访问。
打包进`struct`的位可以按名称来访问。
这样的数据类型称为`bit field`。
`bit fields`的一个使用场景是：需要一组开/关标志，并且希望尽量少占用内存。

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

`unsigned int variable_name : 1;`这种语法会在结构体内的`unsigned int`中创建一个`1`位的字段。
除了`unsigned int`，也可以使用`signed int`；或者从 C99 及以后开始，还可以使用`bool`类型。
包含位域的结构体也可以包含其他数据类型的字段，例如上面示例中的`number_of_lights`。
