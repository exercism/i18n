# 简介

类型定义会创建一个新的具名类型，它与其他任何类型都不相同，即使底层类型一样。

## 定义类型

类型定义以`type`关键字开头，后面跟着新类型的名字和它的底层类型：

```go
type File []bool
```

这里的`File`指的是棋盘上的一条竖列，通常用 A 到 H 标记。
这一列中的每个格子都用一个布尔值表示，标记它是否被占据。
现在`File`已经定义好了，我们可以在其他定义中使用它：

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`把列标识符映射到`File`值。
每个`File`都是一个布尔值切片，表示一条棋盘列上的各个格子。
如果没有这些类型定义，`board`就会是`map[string][]bool`，这会让我们更难理解所表示的内容。
