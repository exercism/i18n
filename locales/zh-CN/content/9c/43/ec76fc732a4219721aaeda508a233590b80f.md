# 简介

数组是 Factor 主要的定长序列类型，写作`{ … }`：你可以修改其中的元素，但不能改变长度。`arrays`和`sequences`两个词汇表共同提供了从栈上取值的小型构造函数，以及用于拼接、反转、查找元素的日常操作。

```factor
USING: arrays sequences ;

42 1array .                ! => { 42 }
"a" "b" "c" 3array .       ! => { "a" "b" "c" }
{ { 1 2 } { 3 4 } } concat .   ! => { 1 2 3 4 }
{ 1 2 3 } reverse .            ! => { 3 2 1 }
```

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
