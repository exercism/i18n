# 简介

在 Go 中，每个变量都有一个值。
声明变量而不给它赋值，它就会被设为该类型的零值。

基本类型，包括`bool`、数值类型和`string`，都有固定的零值：

| 类型                   | 零值 |
| ---------------------- | ---------- |
| bool                   | `false`    |
| int, int8, int64, etc. | `0`        |
| float32, float64       | `0`        |
| complex64, complex128  | `0+0i`     |
| string                 | `""`       |

指针、函数、接口、切片、通道和映射的零值都是`nil`。

数组和结构体永远不为`nil`，因为它们直接持有数据，而不是对数据的引用。
数组的每个元素和结构体的每个字段都会被初始化为其各自类型的零值。
例如，`var a [3]int`会创建数组`[0, 0, 0]`。

## 声明零值

声明变量时使用`var`：

```go
var myBool bool   // false
var mySlice []int // nil
```

结构体使用复合字面量`T{}`：

```go
type Person struct {
    Name string
    Age  int
}

myPerson := Person{} // Person{Name: "", Age: 0}
```
