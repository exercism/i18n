# 说明

惠灵顿的气象站将用新的数字系统取代手动温度记录系统。
在旧系统中，计算是手动进行的。
在新系统中，这些计算将实现自动化。
这些计算包括将温度从摄氏度转换为华氏度，以及求平均温度。
新系统配有传感器，以摄氏度记录温度数据。

惠灵顿气象站希望你能帮助他们完成新系统。

## 1. 将温度从摄氏度转换为开尔文

气象站网站上有一个专为研究人员设置的版块。
研究人员关心的是以开尔文表示的温度。

开尔文是用于测量温度的单位。
它与摄氏度采用相同的温标，但起点不同。
它的起点是绝对零度，即 0K（开尔文）或 -273.15°C（摄氏度）。

下表展示了摄氏度与开尔文之间的换算：

| 摄氏度（°C） | 开尔文（K） |
| ----------- | --------- |
| -273.15     | 0         |
| -100        | 173.15    |
| 0           | 273.15    |
| 100         | 373.15    |

气象站希望你能实现一个将温度从摄氏度转换为开尔文的方法。

实现`Temperature#to_kelvin`方法，它接受一个实参`celsius`，并在给定的`celsius`值上加 273.15，返回以开尔文表示的温度。

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. 将温度四舍五入

气象站的温度传感器非常精确。
它可以精确到 0.0001°C。
气象站只想显示四舍五入到 1 位小数的温度，因为大多数用户对这种精度不感兴趣。

气象站希望你能实现一个将温度四舍五入到 1 位小数的方法。

实现`Temperature#round`方法，它接受一个实参`celsius`，并返回四舍五入到 1 位小数的温度。

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. 将温度从摄氏度转换为华氏度

气象站网站上有一个专为游客设置的版块。
游客关心的是以华氏度表示的温度。

华氏度是一种温度测量单位。
它与摄氏度采用不同的温标。
0°C 等于 32°F，1 摄氏度等于 1.8 华氏度。

下表展示了摄氏度与华氏度之间的换算：

| 摄氏度（°C） | 华氏度（°F） |
| ----------- | -------------- |
| -273.15     | -459.8         |
| -100        | -148            |
| 0           | 32             |
| 100         | 212            |

气象站希望你能实现一个将温度从摄氏度转换为华氏度的方法。

实现`Temperature#to_fahrenheit`方法，它接受一个实参`celsius`，并以整数形式返回华氏温度。

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. 获取缺少的传感器数量

在安装温度传感器期间，维护人员发现有些传感器缺失。
每个温度测量单元需要四个温度传感器。
维护团队数了数他们有多少传感器，但还需要知道缺少多少。
他们希望有人能帮忙计算，为了再搭建一个完整的温度测量单元，他们需要购买多少个传感器。

实现`Temperature#number_missing_sensors`方法，它接受一个实参`number_of_sensors`，返回缺少的传感器数量。

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
