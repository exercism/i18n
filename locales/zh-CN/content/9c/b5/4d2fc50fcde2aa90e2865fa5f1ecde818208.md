# 使用模块文档

[comment]: # (当提交的解答中缺少模块的 @moduledoc 时，会触发这个错误)

建议使用 [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) 属性来描述这个模块的用途。

- 在 Elixir 中，文档是[一等公民](https://hexdocs.pm/elixir/writing-documentation.html)，Elixir 的文档在设计上就易于阅读和编写。
- 文档属性`@moduledoc`和`@doc`内部支持 Markdown 语法
