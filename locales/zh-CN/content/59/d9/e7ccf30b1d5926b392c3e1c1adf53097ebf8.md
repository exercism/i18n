# 说明

在这个练习中，你要玩一款名为“Wizard and Warriors”的角色扮演游戏，可以扮演巫师，也可以扮演战士。

战士和巫师造成多少伤害点数，各有各的规则。

战士的规则如下：

- 如果被攻击的角色不脆弱，造成 6 点伤害
- 如果被攻击的角色脆弱，造成 10 点伤害

巫师的规则如下：

- 如果巫师事先准备了法术，造成 12 点伤害
- 如果巫师没有事先准备法术，造成 3 点伤害

一般来说，角色永远不会脆弱。不过，巫师如果还没有准备法术，就_是_脆弱的。

你有六个任务，需要用到战士和巫师角色。

## 1. 描述角色

重写 `Character` 类上的 `ToString()` 方法，返回角色的描述，格式为 `"Character is a <CHARACTER_TYPE>"`。

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. 让角色默认不脆弱

确保 `Character.Vulnerable()` 方法始终返回 `false`。

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. 让巫师能够准备法术

实现 `Wizard.PrepareSpell()` 方法，让巫师能够事先准备法术。

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. 让巫师在没有准备法术时变得脆弱

确保巫师没有准备法术时，`Vulnerable()` 方法返回 `true`；否则返回 `false`。

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. 计算巫师的伤害点数

实现 `Wizard.DamagePoints()` 方法，返回造成的伤害点数：准备过法术时是 12 点伤害，没有准备时是 3 点伤害。

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. 计算战士的伤害点数

实现 `Warrior.DamagePoints()` 方法，返回造成的伤害点数：目标脆弱时是 10 点伤害，否则是 6 点伤害。

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
