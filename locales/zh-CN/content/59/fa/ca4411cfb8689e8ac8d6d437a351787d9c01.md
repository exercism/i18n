# 循环

```sather
   loop
      ...
   end;
```

Sather 只有一种循环语句。没有 `while`，也没有 `for`；它们都是用 `loop` 和某个能结束它的东西搭建出来的。

## 变量

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` 声明变量，并从所给的值推断出类型。如果某个变量必须先存在、之后才会有值，那就改用类型来声明：

```sather
   total : INT;
   total := 0;
```

声明时没有给定值的变量，`INT` 从 0 开始，`BOOL` 从 `false` 开始，字符串或对象则是 void。

## 结束循环

| 写法 | 结束循环的时机 |
| --- | --- |
| `until!(q)` | `q` 为 true 时 |
| `while!(q)` | `q` 为 false 时 |
| `break!` | 立即结束 |

这三种都可以出现在循环体的任何位置，一个循环也可以同时使用多个。

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## 感叹号

`until!`、`while!` 和 `break!` 都以 `!` 结尾，因为它们是**迭代器**：只能出现在循环内部，并且能够结束循环。在循环外面写一个是错误，而不是警告。后面的练习会用到库里的其他迭代器，最终还会自己编写新的迭代器。

## 无限循环

没有任何东西来结束它的循环会一直运行下去。偶尔这正是我们想要的，但更多时候，它意味着条件所问及的那个值始终没有改变。如果程序卡住了，首先要检查的就是循环内部是否有东西在推动它走向结束。
