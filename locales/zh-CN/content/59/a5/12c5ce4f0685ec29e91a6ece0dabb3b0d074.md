# 简介

[switch 语句][switch]把一个值与多个可能的匹配模式进行比较。相比串联多个`if-else`语句，它提供了一种更简洁、更易读的写法。

`switch`语句以`switch`关键字开头，后面是要测试的值。每个可能的匹配都用`case`关键字引入。`default`关键字定义一个兜底分支，在所有显式分支都不匹配时执行。和`if-else`链一样，`switch`语句只会执行第一个匹配分支对应的代码块。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

来看下面这条`if-else`链：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

用`switch`语句可以让它更清晰：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
