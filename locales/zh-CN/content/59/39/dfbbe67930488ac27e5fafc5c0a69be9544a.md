# 提示

## 通用

- 结构体实例的创建方式是：先写结构体名，后面跟上用大括号括起来的字段值。
- 可以用`@T`来声明某个类型`T`的快照，例如`let i: @u32 = @1;`声明了一个变量`i`，它是`u32`值`1`的快照；
- 可以用`*`（desnap）运算符从快照中取出值，例如`let int = *an_int_snapshot;`。
- 可以用`mut`关键字把值声明为可变的，例如`let mut i = 1;`。

## 1. 创建一个投票计数器

- 你需要创建一个指向`VoteCounter`结构体的指针，也就是一个`@VoteCounter`。
- 创建结构体实例时，可以直接给`value`形参赋值。

## 2. 从计数器中获取票数

- 你可以在快照上使用`*`运算符，对它进行 desnap 并获取其值，例如`*my_snapshot`

## 3. 让计数器的票数自增

- 不要修改`@VoteCounter`快照，而要返回一个票数自增后的新`VoteCounter`实例。
- 你可以用`*`运算符对底层的投票计数器值进行 desnap，也可以调用你在上一个任务中创建的函数。

## 4. 创建选举结果

- 创建一个新的`ElectionResult`结构体或变量，把它的`name`和`vote_counter`字段填成函数实参里的值。
- 你可以在变量名或结构体声明前加上`@`运算符来创建一个`VoteCounter`快照，也可以调用你在前面某个任务中写的`new_vote_counter`函数。

## 5. 公布结果

- 虽然你拿到的是指向`ElectionResult`的快照，但仍然可以用点`.`号来访问它的字段，就好像它根本不是快照一样！
- 通过访问结构体上的`name`和`vote_counter`字段来拼出这条消息。
- 对嵌套的快照进行 desnap 时，有多少层快照需要 desnap，就要用多少个`*`运算符：

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. 重新计票

- 由于[字典的实现方式][dictionaries underneath]，字典必须是可变的，才能既修改它又读取它；也就是说，你在函数内部对字典所做的修改，在函数外部也能看到。
- 要让`let mut m: Felt252Dict<u32>`中某个键的值自增，可以把它的`get`和`insert`函数组合起来：`m.insert('mykey', m.get('mykey') + 1);`

[dictionaries underneath]: https://book.cairo-lang.org/ch03-02-dictionaries.html#dictionaries-underneath
