# 关于

[记录][records]是一种数据结构，把相关的信息连同标签组织在一起。它们类似 JavaScript 或 Java 里的对象，或 C 或 Rust 里的 struct，但有一些关键区别。

## 创建记录

记录用[花括号创建][create]，各个元素之间用逗号分隔。

```elm
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

记录的类型也用类似的语法定义，只是等号`=`换成了冒号`:`。

```elm
firefly : { name : String, creator : String, episodes : Int }
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

重复写这些类型定义很麻烦，因此常见的做法是用[类型别名][record-types]来共享定义。

```elm
type alias TvSeries =
    { name : String
    , creator : String
    , episodes : Int
    }

firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }
```

类型别名还会自动为记录提供一个构造函数。这一点有时会让人意外，因为 Elm 里的函数必须以小写字母开头，而类型构造函数是一个例外。

```elm
firefly : TvSeries
firefly = TvSeries "Firefly" "Joss Whedon" 14
```

## 访问记录字段

[访问记录实例的字段值][access]的主要方式是使用点号写法，例如`firefly.creator`。Elm 编译器还支持以点号`.`开头的特殊访问函数，例如`.creator`，它们对任何含有该名字字段的记录都有效。这是“函数必须以小写字母开头”这条规则的第二个例外。其实，用户自定义的函数必须以小写字母开头，但我们刚才看到的这两个例子是由编译器生成的，而不是程序员编写的。

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

firefly.name
    --> "Firefly"

.creator firefly
    --> "Joss Whedon"
```

记录还可以在绑定中使用[记录模式匹配][pattern-matching]进行_解构_。解构对任何含有相关名字字段的记录都适用。

```elm
episodesCount : TvSeries -> Int
episodesCount { episodes } =
    episodes

complicatedCopy : TvSeries -> TvSeries
complicatedCopy show =
    let
        { name, creator } = show
    in
    { name = name
    , creator = creator
    , episodes = episodesCount show
    }
```

## 更新记录

和 Elm 里的一切一样，记录是不可变的，所以一旦定义了记录，它的字段值就永远不能改变。[有一种特殊语法可以创建现有记录的副本，同时修改一个或多个字段][update]。这种语法用竖线符号`|`来区分原始记录和将要修改的字段，例如`{ oldRecord | field1 = newValue }`。

```elm
firefly : TvSeries
firefly =
    { name = "Firefly"
    , creator = "Joss Whedon"
    , episodes = 14
    }

updatedFirefly : TvSeries
updatedFirefly =
    { firefly | creator = "J Whedon", episodes = 15 }
```

## 比较记录

Elm 使用[结构相等][equality]，也就是说，同一种记录的两个实例只要值相同就相等。

```elm
firefly1 = TvSeries "Firefly" "Joss Whedon" 14
firefly2 = TvSeries "Firefly" "Joss Whedon" 14

firefly1 == firefly2
    --> True
```

## 可扩展记录

Elm 还支持[结构类型][structural-typing]，也就是说，如果一个函数要求传入带有 x 和 y 字段的记录，那么任何含有这些字段的记录都能用，比如二维点、三维点、飞船等等。这类记录类型的定义里有一个竖线`|`，例如`{ a | x : Float, y : Float }`，在 Elm 的术语中称为“可扩展记录”。要注意类型定义中的竖线`|`（那是在定义可扩展记录，如`{ a | x : Int }`）和实际记录实例中的竖线`|`（表示我们要更新该记录的部分字段）之间的区别。

```elm
point2d = { x = 1, y = 2 }
point3d = { x = 3, y = 4, z = 7 }

.x point2d --> 1
.x point3d --> 3

length : { a | x : Float, y : Float } -> Float
length vector =
    sqrt (vector.x * vector.x + vector.y * vector.y)

length point2d --> 2.236068
length point3d --> 5

translateX : { a | x : Float } -> { a | x : Float }
translateX vector =
    { vector | x = vector.x + 1 }

translateX point2d --> { x = 2, y = 2 }
translateX point3d --> { x = 4, y = 4, z = 7 }
```
