# 关于

在前面的概念中，我们看到 Julia 的类型构成一个层级结构，最顶层是`Any`。

像`Number`这样的抽象类型有自己的子类型，但它们本身不能被实例化。
把一个变量声明为抽象类型，会_约束_这个变量的值必须是该抽象类型的任意子类型。
例如：

```julia-repl
julia> x::Number = 3
3

julia> typeof(x)  # one subtype of Number
Int64

julia> x = 4.2
4.2

julia> typeof(x) # another subtype of Number
Float64

julia> x = "fail" # not a number type!
ERROR: MethodError: Cannot `convert` an object of type String to an object of type Number
```

这为我们约束哪些输入有效提供了一种灵活性。

不过，假设我们希望一个变量既能接受整数值，又能接受字符串值呢？
这两种类型在层级结构中并不属于同一分支。

我们可以把类型设为[`Any`][any]，或者就让它默认使用`Any`，但这样一来，就完全无法控制允许的类型了。

更好的做法是使用[`Union{ }`][union]语法，在大括号里列出 2 个或更多类型。

```julia-repl
julia> y::Union{Integer, String} = 4
4

julia> typeof(y)
Int64

julia> y = "works"
"works"

julia> typeof(y)
String

julia> y = 5.3
ERROR: MethodError: Cannot `convert` an object of type 
  Float64 to an object of type 
  Union{Integer, String}
```

另一个例子在函数签名中使用了同样的类型联合：

```julia-repl
julia> IntOrString = Union{Integer, String}
Union{Integer, String}

julia> f(z::IntOrString) = z^3
f (generic function with 1 method)

julia> f(2) # integers are cubed
8

julia> f("ab") # strings are repeated 3 times
"ababab"
```

这里我们给这个类型起了个名字，写起来很方便，但并不是必须的。
函数`g(z::Union{Integer, String}) = z^3`的行为完全一样。

关于函数签名，我们在“多重分派”概念中会有更多讨论。

## 与 nothing 的联合

其他一些语言有可以包含值、也可以不包含值的类型，名字类似`Option`、`Nullable`或`Maybe`。

Julia 没有专门的语法来做这件事，不过类型联合是同一思路的推广。

在[`Nothingness`][nothingness]概念中，我们看到 Julia 有多种表示无值的方式，包括[`nothing`][nothing]和[`missing`][missing]。
这两者都可以放进类型联合里。

例如，在定义某种[链表][linked]时，我们需要一种方式，在没有后续节点时终止这个链表。
`Nothing`是只含单例值`nothing`的类型，下面这个 Node 的定义就能用来标记链的末尾：

```julia-repl
julia> struct Node
           value::Any
           next::Union{Node, Nothing}
       end
```

类似地，`missing`可以作为缺失值的占位符，尤其是在向量这样的集合里。
下面这个例子很牵强，但缺失值在真实数据集中很常见。

```julia-repl
julia> q(x::Real) = x >= 0 ? sqrt(x) : missing  # skip negative values
q (generic function with 1 method)

julia> vals::Vector{Union{Real, Missing}} = q.([4, 3.1, -1, 0])
4-element Vector{Union{Missing, Float64}}:
 2.0
 1.760681686165901
  missing
 0.0
```
