# 简介

在 Python 中，[`enum`][enum-docs] 是一组名称，这些名称绑定到唯一的 `literal` 或 `constant` 值。
`Enums` 通过继承 `Enum` 类或对其派生子类来定义。
内置的 `enum` 类型位于 `enum` 模块中，而 `Enum` 类可以通过 `from enum import Enum` 导入。


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

注意，`enum` 成员的值可以是任何数据类型，例如 `str`、`tuple`、`float` 等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

当为 `enum` 中的两个成员赋相同的值时，后赋值的成员会成为前一个成员的别名。不允许为 `enum` 中的两个不同成员使用相同的名称。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

可以使用标准的 `for member in` 语法遍历 `enum` 的成员：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

`Enum` 成员可以使用 [`is`][identity-keyword]（_身份运算符_）或 `is not` 进行比较。`==` 或 `!=`（_相等运算符_）的作用也一样：

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

要获取给定值对应的 `enum` 成员，可以使用 `<EnumName>(<value>)`：

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
