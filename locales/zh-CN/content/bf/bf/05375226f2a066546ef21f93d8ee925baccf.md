# 简介

[`list`][list]是一种按_顺序_排列的可变元素集合。
 像大多数集合一样（_参见内置的[`tuple`][tuple]、[`dict`][dict]和[`set`][set]_），数组可以持有任意（或多种）数据类型的引用，包括其他数组。
 数组可以通过[切片语法][slice notation]整体或部分复制，也可以使用`<list>.copy()`来复制。
 与任何[序列][sequence type]一样，`lists`中的元素可以从左边按`0-based index`编号引用，也可以从右边按`-1-based index`编号引用。

数组既支持[通用][common sequence operations]序列操作，也支持[可变][mutable sequence operations]序列操作，例如`min(<list>)`/`max(<list>)`、`<list>.index()`、`<list>.append()`和`<list>.reverse()`。
 可以使用`for item in <list>`结构遍历`list`中的元素。
 当同时需要元素的下标和值时，可以使用`for index, item in enumerate(<list>)`。

Python 还提供了许多处理数组的实用[数组方法][list-methods]。
 下面会介绍其中一部分`list methods`。


注意，当你用`list-method`操作一个`list`时，**你改变的是传入的那个数组**对象。
 如果你不想修改原来的`list`，至少需要通过切片或`<list>.copy()`对它做一个`shallow copy`。


## 添加元素

要把元素添加到已有数组的末尾，也就是“右侧”，可以使用`<list>.append(<item>)`：

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

与_追加_不同，`<list>.insert()`让你可以把元素添加到数组中的_指定下标_。
它接收 2 个形参：

1. 你希望插入元素的`<index>`。
2. 要插入的`<item>`。

**注意**：如果给定的`index`是 0，元素会被添加到`list`的开头（“左侧”）。
 如果传入的`index`大于`list`上最后一个`index`，元素会被添加到最后一个位置，效果等同于使用`<list>.append(<item>)`。


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


可以用`<list>.extend(<item>)`把一个已有的数组与另一个可迭代对象（例如`set`、`tuple`、`str`或`list`）中的元素合并起来。
 这个可迭代对象会被_解包_，其中的元素会按顺序追加（_在这种情况下使用`<list>.append(<item>)`会把整个可迭代对象作为**单个元素**添加进去。_）。


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## 删除元素

要从数组中删除元素，使用`<list>.remove(<item>)`，把要删除的元素作为实参传入。
 如果要删除的元素不在`list`中，`<list>.remove(<item>)`会抛出`ValueError`。


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


另一种做法是使用`<list>.pop(<index>)`方法，它既能移除元素，**也**能把该元素`return`出来供使用。


`<list>.pop(<index>)`接受一个可选的形参：要移除并返回的元素的`index`。
 如果没有指定（可选的）`index`实参，`list`的最后一个元素会被移除并返回。
 如果指定的`index`大于最后一个元素的`index`，则会引发`IndexError`。


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

可以用`list.clear()`移除`list`中的所有元素。它不接收任何形参。

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## 反转与重排

`<list>.reverse()`方法会**就地**反转元素的顺序。


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


借助[`<list>.sort()`][sort]，数组可以_**就地**_重新排序。
默认的排序顺序是从左起的_升序_。
Python 文档提供了[更多排序技巧和方法][sorting how to]。

~~~~exercism/note
 从 2002 年到 2022 年，Python 内部使用一种名为[`Timsort`][timsort]的算法来排列数组，但从`Python 3.11`起改用了[`Powersort`][powersort]。

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

如果需要_降序_，就传入`reverse=True`实参：

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

如果不想修改原数组，可以使用内置的[`sorted(<iterable>)`][sorted]函数返回一个排好序的**副本**。


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## 元素在数组中出现的次数

可以用`list.count(<item>)`计算某个元素在数组中出现的次数。
 它把要统计的`item`作为实参，并返回该元素在`list`中出现的总次数。


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## 查找元素的下标

`<list>.index(<item>)`会返回传入元素_第一次出现_的`index`编号。
 如果没有出现，则会引发`ValueError`。
 如果不需要元素的确切位置，用内置的`in`运算符检查数组是否包含某个给定的值会更高效。


下标从左边开始，以 0 为基准，所以“第一个”元素的位置是`0`。
下标也可以从右边开始，从`-1`起算。


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

还可以提供`start`和`end`下标，把搜索范围缩小到`list`的某个特定区段：

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
