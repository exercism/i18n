# 操作说明

作为一名准魔术师，Elyse 需要练习一些基本功。她有一叠牌，想要摆弄一下。

为了简单起见，她只用 1 到 10 这些牌。

这叠牌用一个`queue`表示，牌堆的底部在队列的前端，牌堆的顶部在队列的后端。

## 1. 把一张牌插入牌堆顶部

实现函数`insert_top`，返回这叠牌的一个副本，并把新给出的牌放在牌堆顶部。

```gleam
insert_top(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([5, 9, 7, 1, 8])
```

## 2. 从牌堆顶部移除一张牌

实现函数`remove_top_card`，返回移除了顶部那张牌之后的牌堆副本。如果给定的牌堆为空，则返回原来的牌堆，保持不变。

```gleam
remove_top_card(queue.from_list([3, 2, 6, 4, 8]))
// -> queue.from_list([3, 2, 6, 4])
```

## 3. 把一张牌插入牌堆底部

实现函数`insert_bottom`，返回这叠牌的一个副本，并把新给出的牌放在牌堆底部。

```gleam
insert_bottom(queue.from_list([5, 9, 7, 1]), 8)
// -> queue.from_list([8, 5, 9, 7, 1])
```

## 4. 从牌堆底部移除一张牌

实现函数`remove_bottom_card`，返回移除了底部那张牌之后的牌堆副本。如果给定的牌堆为空，则返回原来的牌堆，保持不变。

```gleam
remove_bottom_card(queue.from_list([8, 5, 9, 7, 1]))
// -> queue.from_list([5, 9, 7, 1])
```

## 5. 检查牌堆的大小

实现函数`check_size_of_stack`，检查牌堆的大小是否等于给定的`stack_size`。

```gleam
check_size_of_stack(queue.from_list([3, 2, 6, 4, 8]), 4)
// -> False
```
