# 简介

## 注释

Exercism 的 x86-64 track 使用 **NASM**（The Netwide Assembler）作为汇编器。
在 NASM 中，注释以分号（`;`）开头。

注释可以放在程序中的任何位置，汇编器会忽略 `;`之后的所有内容。

## 常量

在 NASM 中，可以用 **equ** 定义汇编期常量。
例如，下面定义了一个名为`UNIVERSE`、值为`42`的常量：

```x86asm
UNIVERSE equ 42
```

常量在定义时只求值一次，之后_不能_重新定义。

## 通用寄存器（GPRs）

在汇编中，我们通常不用变量，而是用寄存器来存储值。
**CPU 寄存器**是处理器内部的一小块高速存储器。
大多数运算都在 CPU 的寄存器中进行。

其中一些寄存器用于各种不同的运算，称为**通用寄存器（GPRs）**。
其他寄存器则有特殊或专门的用途。

在 x86-64 中，共有 16 个 64 位通用寄存器（GPRs），它们也可以按 32 位、16 位或 8 位来访问。
下面介绍这些通用寄存器，其中`rn`里的`n`取 8 到 15：`r8`、`r9`、`r10`、`r11`、`r12`、`r13`、`r14` 和`r15`。

| 64-bit | 32-bit | 16-bit | 8-bit |
| :----: | :----: | :----: | :---: |
|  rax   |  eax   |   ax   | ah/al |
|  rbx   |  ebx   |   bx   | bh/bl |
|  rcx   |  ecx   |   cx   | ch/cl |
|  rdx   |  edx   |   dx   | dh/dl |
|  rsi   |  esi   |   si   |  sil  |
|  rdi   |  edi   |   di   |  dil  |
|  rbp   |  ebp   |   bp   |  bpl  |
|  rsp   |  esp   |   sp   |  spl  |
|   rn   |  rnd   |  rnw   |  rnb  |

当使用的位数少于 64 位时，访问的通常是寄存器的低位部分。
这条规则的例外是`ah`、`bh`、`ch` 和`dh`，它们访问的是寄存器 16 位部分中的高 8 位。

下面以 `rax` 寄存器为例，说明这些位是如何访问的：

```
+--------+---------------------------------------+
| 64-bit |                  rax                  |
+--------+-------------------+-------------------+
| 32-bit |                   |        eax        |
+--------+-------------------+---------+---------+
| 16-bit |                             |    ax   |
+--------+-----------------------------+----+----+
| 8-bit  |                             | ah | al |
+--------+-----------------------------+----+----+
```

其中一些寄存器必须在函数调用之间保持不变：`rbp`、`rsp`、`rbx`、`r12`、`r13`、`r14` 和`r15`。
如果没有保持它们，可能会导致错误或未定义行为。

其余寄存器不需要保持，可以自由使用：`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10` 和`r11`。

~~~~exercism/caution
在学习大纲后面的内容中，你会学到如何保持寄存器。
现在，只使用第二类寄存器：`rax`、`rcx`、`rdx`、`rdi`、`rsi`、`r8`、`r9`、`r10` 和`r11`。
~~~~

## 指令

指令是 CPU 能够执行的一段运算。
它们通常具有以下形式：

```x86asm
name destination, source
```

也就是说，指令名放在最前面，然后是至少一个空白字符，接着是目标操作数、一个逗号（`,`），最后是源操作数。
通常，指令只修改目标操作数，不修改源操作数。

除非另有说明，两个操作数的大小必须相同。
例如，如果源操作数是 16 位，那么目标操作数也必须是 16 位。

例如，要把一个值存入寄存器，可以使用 `mov` 指令：

```x86asm
mov rax, rdx  ; rax = rdx
              ; mov is the name, rax is the destination operand and rdx is the source operand
```

上面的代码片段把源操作数 `rdx` 的全部 64 位内容复制到目标操作数 `rax` 的全部 64 位中。

在大多数指令中，可以把整数常量用作源操作数（但不能用作目标操作数）：

```x86asm
mov rcx, 42 ; rcx = 42
            ; rcx is the destination operand and 42 is the source operand
```

注意，写入 32 位寄存器还会清空高 32 位，所以 `mov eax, 42` 与 `mov rax, 42` 效果相同。
但 16 位和 8 位寄存器不是这样。

对于加法、减法和乘法运算，可以使用 `add`、`sub` 和`imul` 指令：

```x86asm
add rax, rsi ; rax = rax + rsi
imul rax, rdi ; rax = rax * rdi
sub rax, r8 ; rax = rax - r8
```

## 函数

指令组织在函数中。
所有函数都放在源文件的 **section .text** 中。

一个函数声明由以下部分组成：

1. 以函数名命名的标签，后面跟一个 `:`。
2. 构成这个函数的指令。
3. 返回指令 `ret`。

这个 track 使用 System V AMD64 ABI 调用约定，前六个整数实参通过寄存器传给函数。
它们按以下顺序传递：`rdi`、`rsi`、`rdx`、`rcx`、`r8` 和`r9`。

整数值通过 `rax` 寄存器从函数返回。

要调用一个函数，我们使用 `call` 指令。
函数可以在同一个源文件中的任何位置调用。
要让函数对其他源文件可见，必须使用 `global` 指示符。

例如，下面声明了一个函数 `sum`：

```x86asm
section .text ; functions are placed here

global sum ; sum is visible to other source files

sum:
    ; first argument is passed in rdi
    ; second argument is passed in rsi
    ; return value is placed in rax

    mov rax, rdi ; rax is now equal to rdi
    add rax, rsi ; rax = rax + rsi

    ret ; function return
```

下面的代码用实参 3 和 5 调用我们的 `sum` 函数：

```x86asm
mov rdi, 3  ; First argument in rdi
mov rsi, 5  ; Second argument in rsi
call sum

; The rax register now contains the value 8 (3 + 5), after sum returns
```
