# CLI

## 安装

安装 PureScript 最简单的方式是使用 Node.js 和 NPM。

如果你的电脑上还没有安装 Node.js，可以从 [Node.js 官方网站][nodejs-website] 下载。Node.js 装好之后，在终端里输入下面这条命令，就能安装 PureScript 编译器和 Spago 包管理器/构建工具。

```shell
npm install -g purescript spago
```

更多信息请查看 [PureScript 仓库][purescript-repository]。

## 依赖项

安装练习所需的依赖：

```shell
spago install
spago build
```

## 让测试套件通过

用下面的命令运行测试：

```shell
spago test
```

测试套件里除了第一个测试之外，其余测试都被跳过了。这样做是为了鼓励你一步一步地解决练习。

当某个测试通过后，把`xit`改成`it`，就能启用下一个测试。

## 提交解答

当所有测试都不再被跳过、并且全部通过后，就可以这样提交你的解答：

```shell
exercism submit src/<NAME>.purs
```

## 编写自定义测试

如果你想编写额外的自定义测试，新建一个文件`test/Custom.purs`，然后把它和你的解答一起提交：

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
