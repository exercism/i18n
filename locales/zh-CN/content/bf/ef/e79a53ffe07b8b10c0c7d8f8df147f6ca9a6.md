# 说明

在这个练习中，你将编写代码，帮助自由职业者与项目经理沟通：提供几个实用工具函数，用来快速计算日费率和月费率，也可以按给定的折扣计算。

我们先约定自由职业者和项目经理之间的几条规则：

- 日费率是小时费率的 8 倍。
- 一个月有 22 个可计费工作日。

有时，自由职业者会对日费率提供折扣（例如给最忠实的客户或非营利客户）。

折扣用表示百分比的小数来建模，例如 `25.0`（25%）。

## 1. 根据小时费率计算日费率

实现一个函数，根据小时费率计算日费率：

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

返回的日费率应为浮点数。

## 2. 计算折扣后的价格

实现一个函数，计算应用折扣后的价格。

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

返回的值应始终是浮点数，不做任何舍入。

## 3. 根据小时费率和折扣计算月费率

实现一个函数，计算月费率并应用折扣：

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

返回的月费率应向上取整（取上限）为最接近的整数。

## 4. 根据预算、小时费率和折扣计算工作日数

实现一个函数，接收预算、小时费率和折扣，计算这些预算能覆盖多少天的工作。

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

返回的天数应向下取整（取下限）到一位小数。
