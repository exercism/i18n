# 提示

## 概述

- 回调函数是作为实参传给调用函数的函数。
- 回调函数必须符合调用函数的规范。

## 1. 用成功消息通知

- 在你的函数中使用已导入的 API 函数`notify`。
- 向`notify`传入一个对象。它应该有一个`message`属性。想一想 message 的值应该是什么。
- 注意 JSDoc 类型提示：该函数不应该返回任何值。

## 2. 用错误消息通知

- 在你的函数中使用已导入的 API 函数`notify`。
- 向`notify`传入另一个对象。它应该有一个`message`属性。message 的值应该与上一部分不同。
- 注意函数定义上方的 [JSDoc] 注释：
  - 该函数不应该返回任何值。

## 3. 下单购买水果

- 使用已经导入的`order`函数。
- 注意 JSDoc 类型提示：该函数应该接收 3 个实参，并且不返回任何值。
- 复用之前创建的回调函数，把它们作为 order 函数的实参。

## 4. 把代码重构成更简洁的函数

- 复用前面任务中的函数。
- 注意 JSDoc 类型提示：该函数应该接收 2 个实参，并且不返回任何值。
- 把这些实参合并成一个对象，表示向果蔬商下单的请求。
