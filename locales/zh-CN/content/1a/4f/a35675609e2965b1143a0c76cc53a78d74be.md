# 介绍

## `switch`语句

[`switch`语句][switch]让你可以把一个值与多个可能的匹配值进行比较，从而写出比使用多个`else-if`语句更简洁的代码。`switch`语句以`switch`关键字开头，后面跟着要比较的值。然后你可以用`case`关键字定义各个分支，后面跟着要与之比较的值。当所有分支都不匹配时，用`default`关键字定义默认分支。和`else-if`语句一样，`switch`语句只会执行第一个匹配分支所对应的代码块。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

看看下面这个例子：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

也可以改写成这样：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## `while`循环

[`while`循环][while-loops]是一种控制流语句，它让代码在某个条件为真时反复执行。Swift 提供了两种 while 循环：`while`循环和`repeat-while`循环。`while`循环会先对条件求值，再执行循环体；如果条件为假，循环体根本不会执行。Swift 中`while`循环的结构如下：

```swift
while <#condition#> {
  <#code#>
}
```

这里的循环会在 count 大于 0 时一直执行，因此会依次打印出数字 2、1 和“Liftoff!”。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`循环][while-loops]与`while`循环类似，但它的条件是在循环体执行之后才求值。这意味着即使条件为假，循环体也至少会执行一次。Swift 中`repeat-while`循环的结构如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

这里的循环只会执行一次，因为条件为假。由于它是`repeat-while`循环，循环体会先执行一次，然后才对条件求值。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 控制转移

Swift 提供了一组语句，可以用来改变循环正常的控制流。这些语句称为控制转移语句。你已经见过`return`了；本概念会介绍其他几种，包括`continue`、`break`和标签。本概念不会讲解`fallthrough`，但你可以在 [Swift 官方书籍][fallthrough]中了解它。

### `continue`

有时需要提前跳到循环的下一次迭代，而不执行本次迭代中剩下的语句。这时可以使用`continue`关键字。执行`continue`时，循环会跳到下一次检查，判断下一次迭代能否执行，也就是`while`循环和`repeat-while`循环中的那个`while`，或者`for-in`循环中判断序列里是否还有下一个元素。

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### `break`

`break`用于提前退出循环。执行`break`时，循环会立即退出，程序接着执行循环之后的第一条语句。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### 标签

当循环嵌套时，有时你会想用`break`或`continue`退出或重新开始外层循环，也就是包含`break`或`continue`所在循环的那些循环。在这种情况下，可以用标签来指定要退出或重新开始的循环。在循环开头的`while`、`repeat`或`for`前面写上一个名字加冒号，就可以给循环加上标签。

想看看这样使用标签的效果，请看下面这个循环。

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
