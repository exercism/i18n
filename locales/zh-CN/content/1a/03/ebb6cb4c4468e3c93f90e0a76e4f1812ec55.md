# 说明

在这个练习中，你要实现一个程序，判断一局[井字棋][tic-tac-toe]的状态。
（*这个游戏也叫“noughts and crosses”或“Xs and Os”。*）

游戏在一个 3×3 的网格上进行。
玩家轮流在网格上放置`X`和`O`。
当一方玩家在网格的一行、一列或一条对角线上连放三个标记而获胜时，或者整个网格被填满时，游戏结束。

在这个练习中，我们假设`X`先手。

你的任务是判断给定的棋局处于哪种状态。

游戏可能有 3 种状态：

- 游戏处于**ongoing**状态。
- 游戏以**draw**结束。
- 游戏以**win**结束。

如果给定的棋盘无效，就抛出适当的错误。

如果棋盘满足以下条件，就是无效的：

- 当双方按正确顺序轮流落子时，无法得到给定的棋盘（记住`X`先手）。
- 游戏在结束后仍继续落子。

## 示例

### 进行中的游戏

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### 平局

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### 获胜

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### 无效

#### 轮流顺序错误

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### 获胜后继续落子

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
