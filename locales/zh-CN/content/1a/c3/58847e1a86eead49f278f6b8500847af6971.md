# 提示

## 通用

- `MACRO:` 位于 [`macros`][macros] 中。各个基本构件分布在 `kernel`（`dup`、`curry`）、`sequences`（`append`、`concat`、`<repetition>`、`map`）和 `quotations`（`>quotation`）里。
- 宏体必须在栈上留下**一个 quotation**。如果你的宏体生成的是代码数组，就用 `>quotation` 收尾。
- 想验证自己的思路，可以在 listener 里把宏体的各个词作用到一个字面量上，看看返回的 quotation 是什么，它应该正是任务“编译为”那一行里的直线代码。

## 1. 重复两次

- 你拿到的是 `[ A ]`，想要 `[ A A ]`。复制一份再把它们拼接起来：`dup append`。

## 2. 重复 N 次

- 你拿到的是 `[ A ] n`，想要把 `n` 个副本拼接在一起。
- `<repetition>` 负责生成这些副本，但它的效果是 `( length elt -- repetition )`，计数必须在栈顶，所以要先 `swap`。
- 然后展平并转换：`swap <repetition> concat >quotation`。

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. 组合多个

- 你拿到的已经是 quotation 组成的数组，只需要把它展平成一个。整个宏体就是 `concat >quotation`。

## 4. 展开的迭代

你拿到一个序列和一个 quotation，例如 `{ 10 20 30 } [ + ]`，想要得到 `[ 10 + 20 + 30 + ]`。分三步搭建出来。

**一个元素。** 把一个元素嵌入 quotation 中，正是 `curry` 做的事：

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**每个元素。** 你想对序列做 `map`，但 `map` 只把一个输入（元素）交给映射 quotation，而你每次还需要手边有 `[ + ]`。所以先用 `curry` 把 `[ + ]` 嵌入映射 quotation：

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` 读作“把那个小 quotation `[ curry ]` 压栈，再把 `[ + ]` curry 进去”，得到 `[ [ + ] curry ]`。把它映射到元素 `e` 上，就是运行 `e [ + ] curry`，也就是 `[ e + ]`。

**把它们拼接起来。** 和其他任务一样收尾：

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- 整个宏体：`[ curry ] curry map concat >quotation`。
