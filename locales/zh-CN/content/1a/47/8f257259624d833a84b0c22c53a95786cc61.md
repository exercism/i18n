# 关于

Factor 的[`calendar`][calendar]词汇表围绕两个元组构建：

- `timestamp`，表示一个时间点（`year`、`month`、`day`、`hour`、`minute`、`second`，以及 GMT 偏移量）。
- `duration`，表示一段时间（字段相同，只是用作数量）。

## 时间戳

`<date>` 会构建一个午夜时间戳；`>date<` 则把它拆开：

```
<date> ( year month day -- timestamp )
>date< ( timestamp -- year month day )
```

```factor
USING: calendar ;

2024 7 14 <date> >date< .   ! => 14   (2024 and 7 below it)
```

常用查询：

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1   (0 = Sunday .. 6 = Saturday)
2024 1 8 <date> day-of-week day-names nth .   ! => "Monday"
2024 leap-year? .                      ! => t
2024 2 1 <date> days-in-month .        ! => 29
```

`day-names`（以及 `month-names`）定义在[`calendar.english`][english]中。

## 时间段与运算

`days`、`weeks`、`hours`、`minutes` 这样的词会构建出一个 `duration`，而 `time+` / `time-` 则把时间戳平移一个时间段：

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .   ! => 29   (2024-02-29)
```

运算会跨越月份和年份的边界，而表示同一时刻的两个时间戳用 `=` 比较时相等。

除此之外，`calendar` 还提供了一天中的时刻（`set-time`、`+hour`）、时区转换（`>gmt`、`>local-time`）、当前时间（`now`），以及通过 `calendar.format` 实现的解析与格式化。
