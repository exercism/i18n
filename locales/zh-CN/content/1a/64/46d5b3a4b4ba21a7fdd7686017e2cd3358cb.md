# 调试

为了方便调试，你可以利用这一点：所有控制台输出都会被捕获并显示在测试结果窗口中。
把任何值传给`@show`，就能输出它。

`@show`会显示表达式及其结果，同时返回该结果。

```julia
@show uppercase("hello") # HELLO will be shown as debug output
```

```julia-repl
julia> function f(a, b)
           @show a b
           return (@show a^b) / 1000
       end
f (generic function with 1 method)

julia> f(3, 5)
a = 3
b = 5
a ^ b = 243
0.243
```

你也可以使用[`println`](https://docs.julialang.org/en/v1/base/io-network/#Base.println)，或任何其他向[`stdout`](https://en.wikipedia.org/wiki/Standard_streams#Standard_output_(stdout))写入输出的方法。
