# 说明

在这个练习中，你将编写代码，记录你想在 Exercism 上学习的编程语言数组。
本练习共有六个任务，每个任务都涉及数组。

## 1. 创建一个新数组

为了记录你想学习的编程语言，你需要创建一个新数组。
定义 `newList` 常量，让它包含一个新的空数组。

```elm
newList
    --> []
```

## 2. 定义一个已有的数组

目前，你手上有一张纸，上面列出了你想学习的编程语言：Elm、Clojure 和 Haskell。
定义 `existingList` 常量来表示这个数组。

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. 往数组里添加一门新语言

当你在 Exercism 上探索、发现更多有趣的语言时，你会想把它们加到数组里。
实现 `addLanguage` 函数，把一门新语言添加到数组的开头。

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. 数一数数组里有几门语言

手动数语言的数量很不方便。
实现 `countLanguages` 函数，统计数组中语言的数量。

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. 反转数组

某一天你会发现，数组的顺序其实是反的！
实现 `reverseList` 函数，把数组反转过来。

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. 检查数组是否令人兴奋

虽然你热爱所有语言，但 Elm 在你心中有特殊的地位。
因此，只要满足以下条件，你就会对一份编程语言数组感到非常兴奋：

- 数组的第一项是 Elm。
- 或者数组的第二项是 Elm，且数组中至多包含三种语言。

实现 `excitingList` 函数，检查一个编程语言数组是否令人兴奋：

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
