# 简介

## 背景

字符串是用引号括起来的一段文本。
R 目前所有受支持的版本都用 UTF-8 编码字符串，因此世界上大多数语言都能得到支持。

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

遗憾的是，对于熟悉其他语言的程序员来说，这套术语可能会让人困惑。

尽管 `type` 是 `character`，R 并不区分单个字母（在其他几种语言里叫 `char`，但在 R 里不是）和一整串长文本。
两者都只是一个单独的元素，而且用单引号 `' '` 或双引号 `" "` 括起来都可以。

风格指南建议使用双引号，除非你想在字符串内部使用双引号而又不想转义它们。

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

因此，`character vector` 就是一个由字符串组成的向量，其中每个字符串各占一个元素。

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

在上面的例子里，`length(s[1])` 等价于 `length("some")`：它给出的是_向量元素_的个数，而不是_字符串长度_。

当然可以单独操作某一个字符串，就像上面例子里的 `nchar()` 那样，但这需要一些专门的函数，下面会讨论。

### 字符串函数

在基础 R 里，大多数事情都_能_做到，但许多程序员觉得它对字符串操作的支持相当有限，而且令人困惑。

好在有一些 `tidyverse` 软件包，它们更直观、更灵活，也更自洽。

### 基础 R

仍然有大量遗留代码在使用旧式的字符串函数。
Exercism 上的大多数社区解答就属于这一类。

另外，对于小任务来说，使用内置函数而不是引入一个大型库往往更有用。
R 赛道的维护者在编写范例解答来验证练习时，倾向于采用这种做法。

因此，了解一些旧方法仍然值得。

#### `nchar`

返回字符串中字符的个数。

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

"字符"到底是什么意思，这个（_相当复杂！_）的话题超出了本文的范围。
只需注意上面例子里的几点：

- 字符串在 R 内部虽然是用 C 实现的，但并不以 `\0` 结尾（那样会让长度加 1）。
- 多字节 Unicode 字符的处理方式和你预期/希望的一样。"Hrōðgār" 有 7 个字符（也称 "rune" 或 "码点"），但存储时需要 10 个字节。

#### `paste` 和 `paste0`

把任意数量的字符串合并成一个字符串。

`paste` 可以选择指定分隔符：默认是一个空格。

`paste0(v)` 等价于 `paste(v, sep = "")`。

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

为了更精细地控制字符串的组装，R 从 C 中复制了 `sprintf` 函数（以及后来的一些语言：维基百科[列出了][wiki-printf-ports]大约 30 种）。

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

可以用 `trimws()` 去掉开头和/或结尾的空白字符：

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

还有一个 `which = "left"`（或 `"right"`）形参，用来避免同时修剪两端。

#### `substr`

作用于单个字符串，返回两个（含端点）界限之间的子字符串。

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

根据一个分隔符字符串，把字符串拆分成一个 R 列表。
分隔符是必需的（没有默认值），但可以是空字符串。

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

列表会在另一个[概念][concept-lists]中介绍。
如果你还没学到教学大纲的那一部分，现在只需知道 `unlist()` 函数（在这个例子里）会把列表转换成向量。

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

宽容一点说，我们可以认为旧式字符串函数算不上 R 能提供的最好的东西（_当然也有不那么宽容的看法_）。

为了改善这种状况，`stringr` 库从 2009 年起就在开发，如今已是 Tidyverse 集合的重要组成部分。

用 `library(stringr)` 或 `library(tidyverse)` 把它导入到你的命名空间中。

一些主要特点包括：

- 所有函数名都带有 `str_` 前缀，并尽量让用途一目了然。
- 实参的顺序尽量保持自洽，把输入数据作为第一个实参。
- 输入可以是从单个字符串到复杂数据结构的各种形式。函数会尽量适应，并做出最合理的处理。

和所有 Tidyverse 软件包一样，`stringr` 有很好的文档，通常由软件包作者撰写。

- 一个[参考网站][ref-stringr]
- 一份[速查表][cheat-stringr]
- 《R for Data Science》中的[一章][book-strings]

#### 岔开一下：管道的快速入门

用管道 `|>` 连接函数的做法，会在教学大纲的其他部分详细讨论。

现在只需知道以下几点：

- 管道左边的结果会成为右边函数的第一个实参（这里的"右边"会忽略可选的换行）。
- 其余的实参都可以写在函数调用里。
- 在 R 里，管道必须接到函数_调用_，而不只是函数_名_，所以括号总是必需的（_这一点和其他一些语言不同_）。

下面的例子演示了这种语法。
各个函数会在后面讨论。

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### 管理长度

`str_length` 统计码点（类似于 `nchars`）。

还有其他一些函数处理空白字符，包括 `str_trim()` 和 `str_squish()`。
在任何数据科学项目开始时，这往往是一项至关重要的清理工作。

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### 截取字符串

函数 `str_sub(string, start, end)` 会返回从 `start` 到 `end`（含端点）的子字符串，而 `str_sub_all()` 可以作用于多个字符串。

这里有很大的灵活性。
`start` 和 `end` 分别默认指向第一个和最后一个字符。
它们可以是下标向量。
与向量下标不同，负值会像 Python 那样从字符串末尾往前数，这一点很受欢迎。

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### 连接字符串

`str_flatten` 把字符向量转换成一个字符串。
`collapse` 实参会被插入到每个元素之间，默认是 `""`。

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c` 把多个字符向量转换成一个字符向量，必要时会循环使用。

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue` 把简单的字符串插值带到 R 里。
大括号 `{ }` 内的表达式会被求值，并替换为它的文本表示。

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### 拆分字符串

R 的一个非常常见的用途，是把杂乱的数据整理成一致的格式以便分析。
为了帮助做到这一点，有几种把文本拆分成子字符串的方法。
大多数都超出了本文的范围。

`str_split_1` 最简单，它把单个字符串转换成一个片段向量，按某个指定的模式拆分（没有默认模式）。

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### 修改字符串

一些语言（主要是欧洲语言）区分大写字母和小写字母。
`stringr` 提供了一组函数，用符合各区域习惯的方式在两者之间转换：

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()`：把每个单词的首字母变成大写
- `str_to_sentence()`：把句子的首字母变成大写

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

对于基于模式匹配的子字符串替换，`str_replace()` 会替换模式的第一次出现，`str_replace_all()` 会替换所有出现。

对于基于字符下标的子字符串替换，str_sub() 还有一种赋值写法。

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
