# 提示

## 1. 生成 SELECT 查询

- 记住，你不需要用构造函数或字面量来初始化 builder。一个简单的`var sb strings.Builder`就已经可以使用了。
- 确保处理好`columns`切片为空或为`nil`的情况，这时要追加通配符`*`。
- 注意，这里既不需要也不要求处理任何元字符或做 SQL 清洗。你可以放心地用`sb.WriteString(col)`直接追加列名。

## 2. 生成批量 INSERT 语句

- 在`for`循环里新建一个`strings.Builder`会抵消性能上的好处。应该在循环开始*之前*声明一个 builder。
- 每次循环迭代开始时，调用 builder 实例的`Reset()`方法。这会清空缓冲区，让你能开始一条全新的查询，同时保留底层已经分配好的内存容量。
- 别忘了，SQL 的`VALUES`子句里的字符串值需要用单引号`'`显式括起来。你可以用`WriteByte('\'')`干净地把它们加上。
- 和 SELECT 查询一样，不用担心列值里的特殊字符转义，也不用操心 SQL 注入。直接把这些输入字符串当作安全的来用即可。
