# 范围

[范围][range]表示两个值之间的区间。
支持范围的最常见类型是`Integer`和`String`。
它们有很多用途，比如快速创建集合、截取字符串、检查某个值是否在范围内，以及迭代。
范围用范围运算符`..`或`...`创建（分别表示包含和不包含结束值）。

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

之所以要有两个范围运算符，是为了能够创建包含或不包含结束值的范围。例如在处理从 0 开始的下标时，这会很有用。

范围也可以用`Range`初始化方法创建。

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Ruby 中用范围运算符`..`或`...`创建范围后，如果想在范围上调用方法，需要用括号把范围括起来。
否则，该方法会在范围运算符的第 2 个参数上被调用。

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## 获取子字符串

想截取字符串时，可以用范围运算符来获取子字符串，也就是用子字符串的起始下标和结束下标创建一个范围。

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

也可以用负数下标从字符串末尾获取子字符串。

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 范围方法

范围确实有一组可以用来操作它们的方法。
例如，这些方法可以获取范围内所有值的总和，或者检查范围是否包含某个值。

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | 返回范围内所有值的总和                                                  | `(1..5).sum # => 15`            |
| [`size`][size]          | 返回范围的大小                                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | 如果范围包含给定的值则返回`true`，否则返回`false`                       | `(1..5).include?(3) # => true` |

## 无终点范围与无起点范围

范围可以没有终点，也可以没有起点。
无终点或无起点范围的起始值或结束值为`nil`，但在定义范围时可以省略这个`nil`。

想从开头或到末尾截取字符串时，使用无起点和无终点范围会很有用。

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
如果不用于集合，无终点范围在不加注意的情况下可能会形成无限序列。
~~~~

## 字符串范围

字符串也可以用在范围中，用来获取两个字符串之间的字符串区间。
使用某些字符串时，它的行为可能有点出乎意料，所以要谨慎使用。

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
