# 测试

要测试你提交的解答，只需运行：

```bash
make test
```

这会运行测试文件 `<exercise-name>-test.ys`，其中包含你的解答要达到正确所必须通过的全部测试。
你应该仔细研究这个测试文件，弄清楚你的解答具体需要做什么。

> 注意：第一次运行 `make test` 时，它还会确保正确版本的 `ys` YAMLScript 解释器被安装到正确的位置。

如果在改动任何文件之前就运行 `make test`，所有测试都会失败。
这是正常且符合预期的行为。
练习开发的正常流程是不断改进你的解答，每次改动后都运行 `make test`，直到所有测试全部通过。

如果你只想运行某个特定的测试（比如正集中精力处理解答的某一部分），可以给这个测试加上这样一个键值对：

```yaml
  ONLY: true
```

如果你想跳过某些测试（比如正在处理解答的其他部分），可以给这些测试加上这样一个键值对：

```yaml
  SKIP: true
```


## 测试前提条件

YAMLScript 目前可在 MacOS 和 Linux 上运行。

你的电脑需要安装以下这些非常常见的命令：

* `bash`：你可以在任意 shell 下运行测试，但必须能使用 `bash`。
* `make`：必须用 GNU `make` 来运行测试。
  在某些环境中，它的名字可能不叫 `make`，而可能是 `gmake`。
* `prove`：任何正常的 Perl 安装都自带这个程序。
* `curl`：在尚未安装 ys 时用它来安装 ys。

你极有可能已经安装了以上所有程序。
