# 安装

## 安装 Clojure CLI

Clojure 提供了一些命令行工具，用于：运行交互式 REPL（读取-求值-输出循环）、运行 Clojure 程序、求值 Clojure 表达式。
我们建议你在做练习时使用 Clojure CLI。要安装 [Clojure CLI](https://clojure.org/guides/deps_and_cli)：

### Windows
Windows 上的安装说明见：[Clojure CLI 安装](https://clojure.org/guides/getting_started#_installation_on_windows)。

### Linux
大多数平台的安装说明见：[Clojure CLI 安装](https://clojure.org/guides/getting_started#_installation_on_linux)。

### Mac OS X 上的 Homebrew
更新 Homebrew：

``` bash
$ brew update
```

安装 Clojure CLI：
``` bash
$ brew install node clojure/tools/clojure
```

使用 node 环境需要`Node`。

## 测试安装

要测试安装是否正确，请运行`clojure --help`，如果一切正常，它会显示版本号。

```bash
$ clojure --help
Version: 1.10.1.547
...
```
