# 简介

每当有一组固定的常量值时，就可以使用[枚举类型][enumeration types]。使用`enum`可以让你以类型安全的方式与常量值交互。定义枚举通过`enum`关键字完成。引用枚举成员时，需要在它前面加上枚举名和一个点（例如`Status.Active`）。

每个枚举成员都是一个名称与一个`int`值的关联。如果第一个成员没有显式值，它的值会被设为`0`。如果没有为某个枚举成员显式定义值，它的值会自动设为前一个成员的值加`1`。

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

枚举非常具有声明性。比较下面两个方法调用：

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

对于阅读代码的人来说，第二个版本（带枚举）更容易理解。

## 数值类型枚举

虽然值的默认数值类型是`int`，但可以通过显式指定任何其他[整型数值][integral numeric]类型来更改。

下面的枚举使用`byte`数值类型作为其值：

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## 转换为枚举成员

每当你想建模类似布尔值的东西时，都应该考虑使用枚举。除了前面提到的可读性优势之外，枚举相比布尔值还有另一个优点：新值总可以添加到枚举中，而布尔值永远只能是`true`或`false`。因此，使用枚举更具前瞻性。

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

注意，虽然_可以_将整数值强制转换为枚举，但当整数值没有映射到某个枚举值时，这样做可能会导致意外结果：

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## 解析枚举

有时根据名称将字符串转换为枚举成员会很有用，这时可以使用[`Enum.Parse`][enum parse]：

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

要检查名称或值是否存在于枚举中，可以使用[`Enum.TryParse`][enum tryparse]或[`Enum.IsDefined`][enum isdefined]，它们都会返回一个布尔值，指示该枚举成员是否存在：

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
