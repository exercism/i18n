# 求模

在 Crystal 中，用求模做比较完全没问题。不过，要比较除法的余数，还有一种更易读的写法：使用[`divisible_by?`][divisible_by]方法。如果你想判断一个数字是奇数还是偶数，那还有更好的办法，直接用[`odd?`][odd?]和[`even?`][even?]方法就可以了。

例如：

```crystal
# Rather than:
number %% 2 == 0

# Consider:
number.even?
```
