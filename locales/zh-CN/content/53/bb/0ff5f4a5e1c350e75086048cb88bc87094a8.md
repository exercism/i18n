# 介绍

## 变量与赋值

R 是一门动态类型语言，因此通常不需要指定变量的类型。首选的赋值运算符是`<-`。

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

用`=`代替`<-`通常也能用，但并非总是如此，而且这种写法风格不佳，不推荐使用。
如果在 RStudio 中工作，可以用快捷键`Alt-minus`输入。

运算符大多是常规的，但请注意`%/%`和`%%`：

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

在 R 中，`#`开始一段单行注释。
多行注释没有单独的语法。

## 函数

定义函数的写法如下：

```R
squareit <- function(x) {
    x * x
}
```

函数可以有零个或多个实参，用逗号分隔。
即使没有形参，`function()`后面也必须带上括号`()`。

可以为函数的实参指定默认值，不过这些带默认值的实参必须放在所有没有默认值的实参之后，并且要用`=`而不是`<-`来指定默认值。
下面是一个相当没有意义的例子：

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

对于单行函数体，大括号`{ }`并非严格必需，但加上它们被认为是一种良好的风格。

如上面的例子所示，R 会自动返回函数的最后一个值。

`return()`可以用在函数体中的任何位置，让返回值变得明确。

调用函数的方式和许多其他语言相同：

```R
squareit(3)
#> [1] 9
```
