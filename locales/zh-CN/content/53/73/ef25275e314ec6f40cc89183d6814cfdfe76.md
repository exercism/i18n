# 关于

遍历序列时，有时光有元素还不够，你还需要它的位置。Factor 的*带下标*迭代词会把元素和下标一起传给作用于每个元素的引述，下标位于栈顶。`times` 则是相关的一个词，用于在没有底层序列的情况下进行计数迭代。

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| 词           | 栈效果                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`，但请看下文                                  |

`times` 有一点微妙：它的引述在文档里写作 `( -- )`，但这个词是 `inline` 的，所以像 `( str -- str )` 这样栈效果平衡的引述完全可用，并且会在各次迭代之间传递栈。这样就能在没有可变状态的情况下得到一个计数累加器：

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

同样的技巧也适用于 `each-index` 和 `map-index`：声明中每个元素的栈效果是*下限*，而不是*上限*。
