# 字符串

字符串是一系列字符，两边用引号包起来。
单引号和双引号都支持。

```php
<?php

$where = "Spain";
$what = 'rain';
```

## 字符串变量展开

在双引号字符串中，如果引用的变量处于作用域内，它的值会被插入到字符串里。

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## 字符编码支持

一直以来，PHP 的字符串函数只支持 ASCII 字符，不支持现代的 Unicode 编码。
每个 ASCII 字符占 1 个字节，而 Unicode 字符的长度可能是 1 到 4 个字节。
如果需要安全地处理 Unicode 字符串，请参考这些旧函数对应的[多字节版本][multi-byte-fns]。

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
