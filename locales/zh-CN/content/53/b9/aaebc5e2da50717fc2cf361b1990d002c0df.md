# 安装

## 安装 .NET 10

Visual Basic 课程使用 .NET 10。
要在本地构建和测试练习，请安装[适用于你的操作系统的 .NET 10 SDK][install-sdk]：
安装 SDK，而不只是运行时。

## 检查你的安装

打开一个新终端，然后运行：

```bash
dotnet --version
```

命令应该输出`10.0.0`或更高版本。

## 编辑器支持

完成这些练习，只需要 .NET SDK 和一个简单的文本编辑器。
如果想要代码补全、调试等更高级的功能，可以考虑以下编辑器之一：

- Windows 上的 [Visual Studio 2026][visual-studio]
- Windows、Linux 或 macOS 上的 [Visual Studio Code][visual-studio-code]
- Windows、Linux 或 macOS 上的 [JetBrains Rider][rider]
