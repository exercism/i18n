# 简介

## 模块

Gleam 代码按模块组织，每个文件就是一个 Gleam 模块。

到目前为止，我们一直用`pub fn`语法编写函数，它定义的函数可以公开供其他模块使用。用`fn`定义的函数对定义它的模块是私有的，其他模块无法使用。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 模块有名称，名称基于它们在`src`或`test`目录中的文件路径。

例如，定义在`src\geometry\rectangle.gleam`（在 Windows 上）或`src/geometry/rectangle.gleam`（在类 UNIX 操作系统上）的模块，名称会是`geometry/rectangle`。

## 从其他模块导入函数

访问其他模块中定义的函数要通过导入来实现。导入某个模块时，该模块公开的所有函数都会变为可访问。但访问它们的方式取决于模块的导入方式。

默认使用限定导入，访问这类模块中的函数（例如`gleam/list`模块中的`map`函数）时，要在模块名前加前缀（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

默认情况下，用来指代模块的名称是模块名的最后一部分，这里是`int`，但可以通过`as`关键字更改。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非限定导入可以直接访问该模块中公开的函数，无需加前缀。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

更推荐使用限定导入，因为它能让读者更清楚地知道函数来自哪里，并避免名称冲突。


## 标准库

Gleam 有一个丰富且文档齐全的标准库。文档可在线访问：[hexdocs.pm/gleam_stdlib][docs]。把这个链接保存到某处，你会经常用到它！

大多数内置数据类型都有对应的模块，提供用于处理该数据类型的函数。例如，`gleam/int`模块用于整数，`gleam/string`模块用于字符串，`gleam/list`模块用于数组，等等。

[docs]: https://hexdocs.pm/gleam_stdlib/
