# 关于

Gleam 有一等函数，也就是说，函数就是普通的值，可以赋给变量、作为实参传入，也可以从其他函数中返回。

在模块中定义的具名函数，可以通过它的名字来引用。

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam 也有匿名函数，它们在其他函数内部定义。

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

函数类型的写法与匿名函数类似。一个接收`Int`和`Float`、并返回`Int`的函数，它的类型是这样写的：

```gleam
fn(Int, Float) -> Int
```

匿名函数可以引用定义它们时处于作用域内的变量，因此它们也被称为_闭包_。

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_函数捕获_语法提供了一种便捷的简写形式，用来创建匿名函数，把单个实参传给某个函数。下面这两个表达式是等价的：

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
