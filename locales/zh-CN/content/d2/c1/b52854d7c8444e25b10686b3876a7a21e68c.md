# 简介

## 整数

整数是不带小数部分的数，属于集合 `{..., -2, -1, 0, 1, 2, ...}`。
整数的最大值和最小值取决于 PHP 运行所在的系统。
在大多数现代系统上，整数通常是 64 位的值，也就是说它能表示从 `-9_223_372_036_854_775_808` 到 `9_223_372_036_854_775_807`（含两端）的值。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

你可以用进制前缀来书写 10 进制以外的整数字面量：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```

> 摘自 PHP 的[文档][syntax]

## 浮点数

在 PHP 中，浮点数用来表示实数的一个子集。
浮点数以一个或多个数字开头，数字之间用小数点分隔。

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

### 常见的坑

并非所有数字和算术运算都能用浮点数进行。
用浮点数表示美元和美分可能会导致舍入误差。

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```

## 算术运算符

PHP 提供了多种用于执行算术运算的运算符。PHP 的算术运算符遵循标准的数学运算顺序。PHP 提供的运算符有：

* 取正 (+)
* 取负 (-)
* 加法 (+)
* 减法 (-)
* 乘法 (*)
* 除法 (/)
* 求模 (%)
* 幂运算 (**)

```php
$moles = +'10';
$aLotOfMoles = 6.022 * 10**23 * $moles;
```
