# 三元运算符

三元运算符提供了另一种语法，用来执行 `if..else..` 比较并返回一个值。

## 语法

PHP 提供了 `if` 语句，可以根据条件的“真值”来决定要执行的操作。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

三元运算符也可以表示同样的操作：

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

这种写法的语法很短，形如 `(condition) ? (evaluate if true) : (evaluate if false);`。

## 优点

使用三元运算符最明显的好处是简洁：与 `if..else..` 语句相比，条件表达式写起来要短得多。不过它还有另外几个优点：

- 它是一个表达式，可以嵌在另一个表达式里使用。
- 它便于对每个分支进行惰性求值。

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  在这个例子中，如果不需要精确答案，就不会调用那个开销很大的计算。

## 缺点

三元运算符也有几个缺点，所以使用前需要斟酌：

- 三元运算符可能更难阅读，因为它依赖对符号的解读，而不是使用关键字。
- 三元运算符可能会无意中导致 bug，因为 PHP 中的三元运算符是左结合的，而大多数现代语言（如 C、Java、JavaScript）并非如此。
- 真分支或假分支中被求值的表达式必须返回一个值。

## 更短的写法

三元语法还能进一步缩短为 `(condition) ?: (evaluate if falsey)`。
其中一种用法是在表达式中提供回退值：

```php
$fruit = null;
eat($fruit ?: 'apple');
```

它有时也被称为*Elvis 运算符*（`?:`）
