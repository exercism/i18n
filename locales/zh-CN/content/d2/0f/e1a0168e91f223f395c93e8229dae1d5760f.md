# 简介

Gleam 里的`Iterator`和数组类似，都是按顺序排列的值的集合，并且所有值的类型都相同。它和数组的区别在于它是惰性的，也就是说，它不会一次性把所有值都存进内存，而是在需要时才计算出来。

在处理非常大、甚至长度无限的序列时，这一点很有用：即使没有足够的空闲内存把它们全部存下来，我们也能处理它们。

`gleam/iterator`模块定义了`Iterator`类型，以及一系列用于处理迭代器的函数。

数组的很多函数在迭代器上也有，比如`map`、`filter`和`take`。这些函数返回的都是迭代器，因此在迭代器被消耗之前，它们实际上并不会做任何工作。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

用`unfold`函数可以通过一个会被反复调用的函数来创建迭代器，这个函数负责生成序列中的下一个值。

下面用`unfold`函数创建了一个生成斐波那契数列的迭代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

这里的序列是无限的，所以先用`take`函数把它变成有限的，再把值收集成一个数组。如果对无限迭代器调用`to_list`，程序会一直运行，直到内存耗尽而崩溃。
