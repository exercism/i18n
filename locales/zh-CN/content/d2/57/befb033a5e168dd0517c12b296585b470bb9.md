# 说明

在这个练习中，你将编写一些代码，帮你照着最喜欢的食谱做出一份美味的千层面。

一共有五个任务，都与烤千层面所花的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义`expected_minutes_in_oven`函数，它不接受任何实参，返回千层面应该在烤箱里烤多少分钟。根据食谱，预期的烤箱时间是 40 分钟：

```gleam
expected_minutes_in_oven()
// -> 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`remaining_minutes_in_oven`函数，它接受千层面已经在烤箱里烤了多少分钟作为实参，并基于上一个任务中得出的预期烤箱时间，返回千层面还需要在烤箱里烤多少分钟。

```gleam
remaining_minutes_in_oven(30)
// -> 10
```

## 3. 计算准备时间（分钟）

定义`preparation_time_in_minutes`函数，它接受你往千层面里加了几层作为实参，返回你准备千层面花了多少分钟，假设每准备一层需要 2 分钟。

```gleam
preparation_time_in_minutes(2)
// -> 4
```

## 4. 计算总的工作时间（分钟）

定义`total_time_in_minutes`函数，它接受两个实参：第一个实参是你往千层面里加的层数，第二个实参是千层面已经在烤箱里烤了多少分钟。该函数应返回你烹饪千层面总共花了多少分钟，也就是准备时间加上千层面此刻已经在烤箱里烤的时间。

```gleam
total_time_in_minutes(3, 10)
// -> 16
```

## 5. 创建千层面烤好的通知

定义`alarm`函数，它不接受任何实参，返回一条表示千层面可以吃了的消息。

```gleam
alarm()
// -> "Ding!"
```
