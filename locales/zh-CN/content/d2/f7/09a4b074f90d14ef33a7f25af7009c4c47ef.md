# 提示

## 通用

- 观看 Jeroen Engels 关于幻影构建器模式的[精彩演讲][phantom-builder-pattern]

## 1. 为宝箱提供一个占位符

- `Chest`可以和`TreasureChest`相同，也就是一个加上幻影类型的单一变体
- 占位符`Chest todo`的类型参数不够，缺少幻影类型
- 幻影类型应该是一个记录，这样才能扩展
- 起始类型是不受约束的`Chest treasure {}`，最终类型是经过完整校验的`Chest treasure { conditions | securePassword : (), uniqueTreasure : () }`
- 要从起始类型变成另一个，条件`securePassword : ()`和`uniqueTreasure : ()`会分别由`secureChest`和`uniqueTreasures`添加

## 2. 选择安全的宝箱

- 你可以对函数实参中的`Chest`进行模式匹配
- 你可以使用函数[`String.length`][string-length]来验证密码
- `securePassword : ()`条件来自类型签名，而不是函数体
- 你不能把一个不受约束的`Chest`放进`Just`里，还指望类型会改变。你需要用`Chest`构造器创建一个新值

## 3. 选择唯一的宝物

- 没有可以使用的`List.unique`函数，你需要自己写一个
- 一种可行的做法是配合一个类型与`secureChest`相似的辅助函数来使用`List.filterMap`
- `uniqueTreasure : ()`条件来自类型签名，而不是函数体
- 你不能把一个不受约束的`Chest`放进`Just`里，还指望类型会改变。你需要用`Chest`构造器创建一个新值

## 4. 享受最终成品

- `makeTreasureChest`应该使用`TreasureChest`类型构造器
