# 厨房计算器

## 故事

这个练习帮助学习者探索某门编程语言中的[元组][type-tuple]。

基本设定是：厨房里的食材常常用一些不常见的方式来计量，并且需要根据用量或手头可用的工具进行不同的换算。元组用于为测量值中的数值部分提供[鸭子类型][concept-duck-typing]。

因此，这个练习探索了使用浮点数进行值的基本换算。

### 换算

| From               | To      |
| ------------------ | ------- |
| 1 mL               | 1mL     |
| 1 杯               | 240mL   |
| 1 液量盎司（美制） | 29.57mL |
| 1 茶匙             | 5 mL    |
| 1 汤匙             | 15 mL   |

## 任务

这会引导学生学习如何使用：

- 元组
- 作为分组信息的元组
- 通过元素下标从元组中取值
- 使用模式匹配从元组中取值
- 创建新元组
