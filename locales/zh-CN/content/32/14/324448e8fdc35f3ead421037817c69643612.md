# 说明

在和朋友们筹划游戏之夜时，大家决定重温一下童年的最爱。你的德国朋友提议玩 _Mensch ärgere Dich nicht_（意为“老兄，别生气”），这是许多欧洲国家的经典游戏（类似英国的 _Ludo_ 或北美的 _Parcheesi_）。

为了准备这场游戏，你决定用 Elixir 实现掷骰子的函数。

在 _Mensch ärgere Dich nicht_ 中，玩家掷一颗六面骰子来决定下一步怎么走。如果运气好掷出 6，就可以再掷一次，再走一步。

## 1. 掷一次六面骰子

实现`d6/0`函数，每次调用时随机返回 1 到 6 之间的一个整数。

```elixir
MenschAergereDichNicht.d6()
# => 1
MenschAergereDichNicht.d6()
# => 5
```

## 2. 只要掷出 6 就继续掷

实现`roll/0`函数，返回一个掷骰结果的流。掷骰要遵循游戏规则：掷出 6 就再掷一次；否则就停下来。请使用上一步定义的`d6/0`函数。

```elixir
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [5]
MenschAergereDichNicht.roll() |> Enum.to_list()
# => [6, 3]
```

## 3. 允许使用灌铅骰子

为了方便测试你的代码，允许使用灌铅骰子。

扩展`roll/0`函数，让它接受一个可选的实参：一个函数。如果传入了这个实参，就用它来掷骰子；否则就退回使用`MenschAergereDichNicht.d6/0`。

```elixir
MenschAergereDichNicht.roll(fn -> 3 end) |> Enum.to_list()
# => [3]
```
