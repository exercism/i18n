# 说明补充

有理数与实数之间的幂运算需要计算一个数的非整数次幂，而 WebAssembly 原生并不支持这一功能。

不过，你也可以把 `x ^ y` 表示为 `x ^ y = exp(y * ln(x))`。

幸运的是，我们可以用不同的级数来计算指数函数和自然对数。

## 指数函数

计算指数函数最好的方法是用[泰勒级数](https://en.wikipedia.org/wiki/Taylor_series)：

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## 对数函数（x 为正数时）

高效计算自然对数有多种方法。其中一种是基于[反双曲正切](https://en.wikipedia.org/wiki/Logarithm#Inverse_hyperbolic_tangent)的级数：

```
ln(x) / 2 ≃ y + y ^ 3 / 3 + y ^ 5 / 5 + ... + y ^ n / n where y = (x - 1) / (x + 1)
```

还有另一种计算自然对数的泰勒级数：

```
ln(x) = (x - 1) - (x - 1) ^ 2 / 2 + (x  - 1) ^ 3 / 3 - (x - 1) ^ 4 / 4 ... + (x - 1) ^ n / n
```

它只在 `x` 介于 0 和 2 之间时准确。不过我们也可以用 `ln(x) = - ln(1 / x)`。

## 整数幂

整数幂运算最好用乘法和循环或递归来实现，这既是出于性能考虑，也是出于精度考虑。为了进一步提升性能，可以用[霍纳法则](https://en.wikipedia.org/wiki/Horner%27s_method)来减少乘法的次数。
