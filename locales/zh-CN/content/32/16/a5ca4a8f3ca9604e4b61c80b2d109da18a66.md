# 提示

## 通用

- 契约写在返回类型之后、`is`之前：

  ```sather
     spare_capacity(load : INT) : INT
        pre load >= 0
     is
        ...
     end;
  ```

- 在契约里，你可以使用实参和对象的属性，所以`limit`是可用的。
- 测试在构建时没有加`-chk`，所以错误的契约不会让测试失败。契约是写给读者看的。

## 1. 搭建安全装置

- 在`create`上写`pre kg > 0`。
- 函数体就是平常的`new`：设置属性，再返回它。

## 2. 还有多少余量？

- 用`and`连接两个条件：`pre load >= 0 and load <= limit`。
- `post result >= 0`。它由`pre`推导而来，这也正是它值得写出来的原因：它记录了为什么这个答案可信。

## 3. 有多满？

- `pre load >= 0`和`post result >= 0`。
- `load * 100 / limit`，要按这个顺序。先做除法会把一切都丢掉，在`tuning-the-strings`里也是如此。

## 4. 安全吗？

- 完全不需要`pre`：重点就在于任何负载都可能被查询。
- `post`重述了这个问题：`post result = (load <= limit)`。这里要用括号，因为`=`被用于两件不同的事。
