# 简介

除了`if`语句，JavaScript 还有`switch`语句，用来有条件地执行逻辑。当需要把单个变量与多个可能值进行比较时，就会用到它。比较通过检查严格相等（`===`）来完成，参见[比较概念][concept-comparison]。对于某个变量`x`，JavaScript 中的`switch`语句具有以下语法。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default`分支是可选的，当其他选项都不匹配该变量时，可以用它来执行一些代码。

上面的`break`语句是必需的，因为在 JavaScript 中，默认情况下所有分支都会“贯穿”。这意味着，如果没有`break`语句，即使`x`与那些选项不匹配，第一个匹配选项下面的所有分支代码也会被执行。在 JavaScript 中使用`switch`时，这种默认的“贯穿”行为是常见的坑。在函数内部，也可以用`return`代替`break`来避免这个问题。
