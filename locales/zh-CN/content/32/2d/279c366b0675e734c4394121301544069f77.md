# 简介

有时，你并不需要为了创建一个带状态的对象而付出那些额外的开销。这种情况下，可以使用`module`。

模块和类非常相似（事实上，在对象继承体系中，`Module`是`Class`的祖先），主要区别在于：我们用的不是实例方法，而是类方法。类方法以`self.`开头，并且直接在模块上调用。

例如：

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
