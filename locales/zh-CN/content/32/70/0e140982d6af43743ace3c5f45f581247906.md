# 关于

在编写 Haskell 函数时，我们可以使用[模式匹配][pattern-matching]。模式匹配是 Haskell 一个非常强大的特性，它让你可以匹配数据构造器，并把变量绑定到其中包含的值上。顾名思义，我们要做的就是把值和模式进行匹配：如果值匹配上了模式，就可以把变量绑定到模式里的值上。模式匹配主要由这几个概念构成：识别值、绑定变量，以及拆解值。

~~~~exercism/note
在 Elixir 等语言中，模式匹配与 Haskell 中的模式匹配略有不同。例如，Elixir 允许同一个模式里出现多个同名的绑定，而 Haskell 不允许。
~~~~


以这个函数为例：

```haskell
lucky :: Int -> String
lucky 7 = "Lucky number seven!"
lucky x = "Sorry, you're out of luck, pal!"
```

这里有一个函数`lucky`，它接受一个`Int`，返回一个`String`。我们为这个函数定义了两个模式：一个匹配数字`7`，另一个匹配其他任何数字。名字可以随便取（只要符合 Haskell 的命名约定），不过这里用的是`x`。如果数字是`7`，函数就会返回`"Lucky number seven!"`，否则返回`"Sorry, you're out of luck, pal!"`。这里要注意的是，模式是从上到下依次检查的，所以如果把两个模式的顺序调换一下，函数就会始终返回`"Lucky number seven!"`。

## 数组模式

一种很常见的模式是匹配数组，也就是取出数组的头部和尾部。这是因为数组本质上是由链表实现的。下面这个函数返回数组的头部和尾部：

```haskell
headAndTail :: [Int] -> (Int, [Int])
headAndTail [] = error "Can't call head on an empty list"
headAndTail (x:xs) = (x, xs)
```

这里有两个模式：一个匹配空数组，另一个匹配至少含有一个元素的数组。这是因为如果数组为空，就必须单独处理这种情况，否则就会遇到运行时错误。如果数组不为空，我们就可以让`x`匹配数组的头部，让`xs`匹配数组的尾部。这是通过`:`（cons）运算符完成的，它用于在数组前面添加一个元素。但在模式匹配中，它让我们可以把数组拆分成头部和尾部，某种程度上算是做了相反的事。

`xs`是数组尾部常见的命名，它强调这是一个数组；如果你处理的是嵌套数组，可以用`xss`来表明它是由数组组成的数组。

## 元组模式

和数组一样，我们也可以匹配元组。下面这个函数接受一个元组，返回其中的第一个和第二个元素：

```haskell
sumTuple :: (Int, Int) -> Int
sumTuple (x, y) = x + y
```

这里的模式匹配一个包含两个元素的元组，第一个元素绑定到`x`，第二个元素绑定到`y`。

## 通配符模式

有时我们并不关心某个变量的值，只想匹配模式本身。这时就该通配符模式出场了，它用下划线`_`表示。

下面这个函数返回数组的第一个元素：

```haskell
head' :: [Int] -> Int
head' [] = error "Can't call head on an empty list"
head' (x:_) = x
```

这里我们表示不需要数组的尾部，于是用通配符模式把它忽略掉。

## 类型模式

我们也可以匹配类型，这要通过使用该类型的构造器来实现。同样可以像处理元组那样，把类型里的值提取出来。

```haskell
data AccountType = Guest | User String 

greet :: AccountType -> String
greet Guest = "Welcome, guest!"
greet (User name) = "Welcome, " ++ name ++ "!"
```

第一个模式匹配`Guest`构造器，第二个模式匹配`User`构造器，并把其中的值绑定到`name`。
