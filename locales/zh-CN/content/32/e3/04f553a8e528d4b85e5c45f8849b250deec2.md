# 说明补充

## 异常信息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，一定要附带一条**有意义的错误信息**，说明错误的来源。这能让代码更易读，对调试也有很大帮助。如果你知道错误的来源属于某种类型，可以选择抛出某个[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但同样要附带一条有意义的信息。

这道练习要求你在传入的实参不是合法的二进制字面量时，使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)“抛出”一个 `ValueError`。只有既`raise`了`exception`，又附带了信息，测试才会通过。

要抛出带信息的 `ValueError`，请把信息作为实参传给 `exception` 类型：

```python
# example when the argument passed is not a valid binary literal
raise ValueError("Invalid binary literal: " + digits)
```
