# 二进制、八进制和十六进制

二进制、八进制和十六进制（_又称 hex_）是基数的不同的[记数系统][numeral-systems]。
二进制的基数是 2，八进制是 8，十六进制是 16。
在 Crystal 中，普通整数都以 10 为基数。
二进制、八进制和十六进制都是整数的表示形式。
这意味着它们表示正数和负数（_包括 0_）时不带分数或小数，并且支持所有能对整数进行的运算。

## 二进制

[二进制][binary]是一种基数为 2 的记数系统，只使用数字 0 和 1。
它通常表示计算机中电流通过晶体管和开关时的 0（“关”）和 1（“开”）两种状态，也用来表示磁性存储介质中的正负电荷。
二进制可以表示十进制中使用的所有整数。

截取二进制系统的一段如下所示，不过它会无限延伸，并不会在 128 处停下：

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

所以如果要表示数字 6，用二进制就是：110

| 位权     | 4   | 2   | 1   |
| -------- | --- | --- | --- |
| 二进制数 | 1   | 1   | 0   |

运算过程是：`4 + 2 + 0 = 6`

再看一个例子：19

| 位权     | 16  | 8   | 4   | 2   | 1   |
| -------- | --- | --- | --- | --- | --- |
| 二进制数 | 1   | 0   | 0   | 1   | 1   |

这个二进制数是：10011
运算过程是：`16 + 0 + 0 + 2 + 1 = 19`

## Crystal 中的二进制

在 Crystal 中，我们可以用`0b`前缀表示二进制字面量。
如果写成`0b10011`，Crystal 会把它解释为二进制数并转换为十进制。

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

如果用一个`0b`前缀写出不属于二进制的数字，会引发编译错误。

```crystal
0b10211
# => Error: unexpected token: "211"
```

### 二进制数的运算

由于二进制数就是整数，我们可以对它们执行所有能对整数执行的运算。

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### 二进制表示与整数之间的转换

Crystal 会自动把二进制字面量转换为`Int32`。
要把`Int32`转换为二进制表示，使用 [`<int>.to_s(base)`][to_s] 方法，并把 base 实参设为 2。
该方法会返回二进制数的字符串表示：

```crystal
19.to_s(2)
# => "10011"
```

要把二进制的字符串表示转换为整数，可以使用 [`<int>.to_i(base)`][to_i] 方法，并把基数（2）作为实参传入：

```crystal
"10011".to_i(2)
# => 19
```

如果传入错误的基数（_或无效的二进制表示_），会引发`ArgumentError`：

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### 二进制相关方法

有些方法可以用在整数上，用来获取该数字二进制表示的信息。

[`<int>.bit_length`][bit_length] 会返回表示该数字所需的位数：

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] 会返回给定下标处的位，从右边（_最低有效位_）开始计数：

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## 八进制

[八进制][octal]是一种基数为 8 的记数系统。
它使用数字 0、1、2、3、4、5、6 和 7。

在 Crystal 中，我们可以用`0o`前缀表示八进制数字。
与二进制一样，Crystal 会自动把八进制表示转换为`Int32`。

```crystal
0o123
# => 83
```

如果给不属于八进制的数字加上`0o`前缀，会引发编译错误。

### 八进制表示与整数之间的转换

与二进制一样，我们可以使用 [`<int>.to_s(base)`][to_s] 方法把`Int32`转换为八进制表示。
也可以用 [`<int>.to_i(base)`][to_s] 方法把八进制表示转换为`Int32`。

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

与二进制一样，传入错误的基数会引发`ArgumentError`。

## 十六进制

[十六进制][hexadecimal]是一种基数为 16 的记数系统。
它使用 0 到 9 的数字以及字母 A、B、C、D、E 和 F。
A 表示 10，B 表示 11，C 表示 12，D 表示 13，E 表示 14，F 表示 15。

在 Crystal 中，我们可以用`0x`前缀表示十六进制数字。
与二进制和八进制一样，Crystal 会自动把十六进制字面量转换为`Int32`。

```crystal
#=> 0x123
291
```
 
如果给非十六进制的数字加上`0x`前缀，会引发编译错误。

###  十六进制表示与整数之间的转换

与二进制一样，我们可以使用 [`<int>.to_s(base)`][to_i] 方法把`Int32`转换为十六进制表示。
也可以用 [`<int>.to_i(base)`][to_s] 方法把十六进制表示转换为`Int32`。

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

与二进制和八进制一样，传入错误的基数会引发`ArgumentError`。

## 精度

把数字转换为字符串表示时，我们可以指定数字的精度。
也就是表示该数字时使用的**最少**位数。
如果该数字的位数少于精度，字符串表示中会补上前导零。
做法是给 [`<int>.to_s(<base>, precision: <value>)`][to_s] 方法传入`precision`实参。

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## 大写

把数字转换为字符串表示时，我们可以指定是否要把字符串中的字母变为大写。
做法是给 [`<int>.to_s(<base>, upcase: <value>)`][to_s] 方法传入`upcase`实参。

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
