# 说明

你的朋友 Chandler 计划去世界各地游玩，看看那些充满异国情调的国家。遗憾的是，Chandler 的数学不太好。他非常担心在旅途中被货币兑换处骗，于是想让你帮他做一个货币计算器。以下是他为这个应用提出的要求：

## 1. 估算兑换后的价值

创建`exchange_money()`函数，它接收 2 个形参：

1. `budget`：你计划兑换的金额。
2. `exchange_rate`：与一单位外币等值的本币金额。

这个函数应该返回兑换后货币的值。

**注意：** 如果你的货币是 USD，想按`1.20`的汇率把 USD 兑换成 EUR，那么`1.20 USD == 1 EUR`。

```python
>>> exchange_money(127.5, 1.2)
106.25
```

## 2. 计算兑换后剩余的金额

创建`get_change()`函数，它接收 2 个形参：

1. `budget`：兑换前的金额。
2. `exchanging_value`：从预算中*扣除*用于兑换的金额。

这个函数应该返回预算中*剩余*的金额。

```python
>>> get_change(127.5, 120)
7.5
```

## 3. 计算纸币的价值

创建`get_value_of_bills()`函数，它接收 2 个形参：

1. `denomination`：单张纸币的面值。
2. `number_of_bills`：纸币的总张数。

这个兑换处只处理以特定面额单位计量的现金。你收到的总额必须能被一张“纸币”（即一个单位）的面值整除，除不尽时会留下小数或余数。你的函数应该只返回兑换处返还的纸币总价值（_不含小数部分_）。遗憾的是，兑换处会把余数或零头当作额外的好处留下。

```python
>>> get_value_of_bills(5, 128)
640
```

## 4. 计算纸币的张数

创建`get_number_of_bills()`函数，它接收`amount`和`denomination`。

这个函数应该返回在给定的 _金额_ 内你能收到的 _纸币张数_。换句话说：起始金额能容纳多少张 _整张纸币_？记住，你只能收到 _整张纸币_，而不能收到纸币的零头，所以要相应地做除法。实际上，你是在向最接近的整张纸币/面值 _向下_ 取整。

```python
>>> get_number_of_bills(127.5, 5)
25
```

## 5. 计算兑换成纸币后的余额

创建`get_leftover_of_bills()`函数，它接收`amount`和`denomination`。

这个函数应该返回在给定纸币面值的情况下，从起始 _金额_ 中无法返还的 _余额_。准确知道兑换处会留下多少钱非常重要。

```python
>>> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 计算兑换后的价值

创建`exchangeable_value()`函数，它接收`budget`、`exchange_rate`、`spread`和`denomination`。

形参`spread`是作为兑换手续费*收取的百分比*，用整数表示。需要把它除以 100，转换为小数。如果`1.00 EUR == 1.20 USD`，而*点差*为`10`，那么实际汇率将是：`1.00 EUR == 1.32 USD`，因为 1.20 的 10% 是 0.12，这笔额外费用会计入兑换。

这个函数应该返回在计算了*汇率*加上*点差*之后，新货币的最大价值。记住，货币的*面值*是整数，不能再细分。

**注意：** 返回值应该是`int`类型。

```python
>>> exchangeable_value(127.25, 1.20, 10, 20)
80
>>> exchangeable_value(127.25, 1.20, 10, 5)
95
```
