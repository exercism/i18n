# 简介

在 R 中，`list`是一种有序的元素集合，它与`vectors`有几点不同：

- 元素可以是不同的类型（例如把`numeric`和`character`混在一起）。
- 元素可以是复杂的结构（例如向量、其他列表等）。
- 访问元素时所用的语法也有所不同。

与其他语言类比并不精确。
R 的`list`和 Python 的字典有些相似，但`list`是有序的，可以用数值下标访问。
它和 C 的`struct`也有些相似，只不过`list`可以在运行时方便地扩展。

## 创建列表

给元素起名字（通常称为“标签”）在列表中比在向量中更常见：

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

不过，标签是可选的，此时 R 会直接使用下标编号：

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## 访问列表元素

有三种方法可以实现，各自适用于不同的场景。

### 1. 使用 `$tag` 表示法

如果标签名事先已知，这种方式非常常用。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. 使用 `[[tag]]` 表示法

它的优势在于标签名可以在运行时决定。
注意这里是双层方括号。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 使用位置下标

无论列表有没有标签，这种方式都能用。
同样，括号是双层的。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 添加和删除元素

很简单：对元素赋值时，如果它已存在就会修改它，如果是新元素就会插入它。

```R
point$color <- "red"
point$trust <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

要删除元素，把`NULL`赋值给不需要的那个元素。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
