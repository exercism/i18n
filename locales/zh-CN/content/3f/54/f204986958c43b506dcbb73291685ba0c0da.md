# 简介

## 参数

本练习讨论方法形参的一些细节，以及它们在 C# 中的用法。

形参把信息从调用方法传递给被调用的方法。

- 形参的行为可以通过`ref`和`out`等修饰符来改变。

- 带有`out`修饰符的形参会把一个值从被调用的方法回传给调用方。这样的形参可以在未初始化的情况下传递给被调用的方法，而且在被调用的方法内部，无论怎样都会被当作进入时尚未初始化来处理。要理解形参修饰符的行为和规则，最容易的办法是通过示例（见下文）和编译器消息。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- `out`形参必须在被调用的方法内部被赋值。

- 带有`ref`修饰符的形参把值传入被调用的方法。方法返回时，调用方会在该形参中看到被调用的方法所做的任何更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`形参必须是变量，因为被调用的方法会直接操作调用方所看到的那个形参。
- `out`和`ref`修饰符在被调用的方法签名中和调用处都必须写出。
