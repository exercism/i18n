# 说明

你当地披萨店的老板请你帮她计算不同披萨的烘烤时间。在这个练习中，你将编写几个函数来完成这些计算。

本练习包含三个任务。

## 1. 计算剩余的烘烤时间（分钟）

定义并实现`remainingMinutesInOven()`函数，计算你还需要把披萨继续放在烤箱里多少分钟。

该函数应接受一个**可选**形参（带默认值），表示你开始烘烤披萨后已经过去的分钟数。如果省略该形参，就假设你刚刚把披萨放进烤箱，已经过去了**0（零）**分钟。

为简单起见，假设所有类型的披萨都需要在烤箱里烤整整 40 分钟才能做好。

```kotlin
remainingMinutesInOven()   // => 40

remainingMinutesInOven(10)   // => 30
```

## 2. 计算准备时间（分钟）

在烘烤披萨之前，你需要准备面团，把它擀开，再放上配料。

定义并实现`preparationTimeInMinutes()`函数，计算把披萨放进烤箱之前需要多少分钟来准备。

该函数应接受一个**必需**的形参（`numberOfIngredientTypes`），表示将要使用的配料种类数。

假设制作并擀开面团需要 5 分钟，而使用**每种**配料需要 2 分钟。

```kotlin
preparationTimeInMinutes(0) // => 5

preparationTimeInMinutes(1) // => 7
```

## 3. 计算总共花费的时间（分钟）

定义并实现`elapsedCookingTimeInMinutes()`函数，计算准备、烘烤和上桌披萨一共需要多少分钟。计算时请使用前面步骤中定义的函数。

该函数应接受两个形参。第一个是**必需**的，表示配料种类数。第二个是**可选**的，表示上桌时间，单位为分钟（如果没有提供，就假设为 0）。

```kotlin
elapsedCookingTimeInMinutes(1)  // => 47

elapsedCookingTimeInMinutes(2, 3)  // => 52
```
