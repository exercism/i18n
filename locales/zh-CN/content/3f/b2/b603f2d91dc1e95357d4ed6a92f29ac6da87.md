# 说明补充

## 提示

要完成这个练习，你需要实现 `slices` 函数：它接收一段*文本*，返回指定长度的数字子序列。

如果这是你第一次做这个练习，建议你先沿用给出的签名：

```haskell
slices :: Int -> String -> [[Int]]
```

之后，你可以回过头来重新看看这个问题，试着用一用其他的数据类型和库：

- `ByteString`，来自 *bytestring* 包。
- `Sequence`，来自 *containers* 包。
- `Text`，来自 *text* 包。
- `Vector`，来自 *vector* 包。

测试套件特意设计成能接受几乎所有合理的类型签名，所以我们鼓励你找出自己认为最好的那一种。
