# 简介

## 类

Java 中最主要的面向对象构造是_类_，它是数据（_字段_）与行为（_方法_）的组合。
类的字段和方法称为它的_成员_。

对成员的访问可以通过访问修饰符来控制，最常见的两种是：

- `public`：任何代码都可以访问该成员（没有限制）。
- `private`：只有同一个类中的代码可以访问该成员。

可以把类看作创建该类实例的模板。
要创建类的实例（也称为_对象_），需要使用 `new` 关键字：

```java
class Car {
}

// Create two car instances
Car myCar = new Car();
Car yourCar = new Car();
```

字段有类型和名称（用 camelCase 定义），可以在类中的任何位置定义（按惯例用 PascalCase 命名）：

```java
class Car {
    // Accessible by anyone
    public int weight;

    // Only accessible by code in this class
    private String color;
}
```

可以选择给字段赋一个初始值。
如果字段_没有_指定初始值，它会被设为该类型的默认值。
可以使用点表示法访问和更新实例的字段值。

```java
class Car {
    // Will be set to specified value
    public int weight = 2500;

    // Will be set to default value (0)
    public int year;
}

Car newCar = new Car();
newCar.weight; // => 2500
newCar.year;   // => 0

// Update value of the field
newCar.year = 2018;
```

私有字段通常作为调用方法时的副作用被更新。
这类方法通常不返回任何值，此时返回类型应为 `void`：

```java
class CarImporter {
    private int carsImported;

    public void importCars(int numberOfCars)
    {
        // Update private field from public method
        carsImported = carsImported + numberOfCars;
    }
}
```
