# 关于

`TUPLE:`声明一个带有具名槽位的类。Factor 会自动生成一个构造词（类名后缀 `new`）、一个 `boa`（即“按参数顺序”）构造器、一种字面量语法 `T{ class … }`，以及每个槽位各自的访问器词。

```factor
TUPLE: player
    { name initial: f }
    { level initial: 0 }
    { health initial: 100 } ;

player new .                                    ! T{ player }
3 100 "Merlin" player boa .                     ! by-order construction
T{ player { name "Merlin" } { health 50 } } .   ! literal syntax
```

[`accessors`][accessors] 中的访问器系统为每个槽位提供四种形式：`name>>`、`>>name`、`change-name`，以及成对使用的修改形式 `[ … ] change-name`。`>>name` 和 `change-name` 会修改元组本身；如果你需要让原元组保持不变，先用 `clone` 复制一份。

元组支持按结构相等性进行 `=` 比较，打印时会显示那些与默认值不同的槽位值。

[accessors]: https://docs.factorcode.org/content/vocab-accessors.html
