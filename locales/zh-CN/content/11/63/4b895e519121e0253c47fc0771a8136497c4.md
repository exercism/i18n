# 附加说明

## 异常信息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，一定要附上**有意义的错误信息**，说明错误的来源。这能让你的代码更易读，也对调试大有帮助。如果你知道错误来源属于某一特定类型，可以选择抛出某一种[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但同样要附上有意义的信息。

这道练习要求你在违反计分规则或比赛规则时，使用[raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)来“抛出”错误。只有既`raise`了`exception`，又附上一条信息，测试才会通过。

要用一条信息抛出`ValueError`，就把这条信息写成`exception`类型的实参：

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
