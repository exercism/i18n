# 说明

你是一艘正在穿越白令海峡的巡逻艇上的值更官。有三个来源在报告视野中每一块浮冰和每一处海角的位置：

- **海图台**用的是罗盘方位，也就是`north`、`east`、`south`、`west`。只有方向，没有距离。
- **领航员**用的是从巡逻艇最近一次定位算起的*极坐标*：大小以海里计，方位角是从正北顺时针量起的度数（所以`0`是北，`90`是东，`180`是南，`270`是西）。
- **桅顶瞭望员**用的是*相对坐标*：向前的距离，再加上`ahead`、`starboard`、`behind`、`port`中的一个。相对方位是相对于*本船当前航向*来测量的，每次值更前，船长都会在舰桥上宣布这个航向。

你的任务是把这三种坐标都转换到一个统一的笛卡尔`(x, y)`坐标系里，这样才能绘图。方位用度表示；`(0, 1)`表示正北一海里，`(1, 0)`表示正东一海里。

## 1. 数据模型，以及基本方位的笛卡尔坐标

首先搭好整个练习共用的几个部件：

- 定义三个元组：`cardinal`（一个槽位`direction`）、`polar`（槽位`magnitude`和`bearing`），以及`relative`（槽位`distance`和`bearing`）。
- 用`SYMBOLS:`声明航向符号：`north`、`east`、`south`、`west`、`ahead`、`starboard`、`behind`、`port`。
- 用`SYMBOL:`声明一个动态变量`heading`（任务 3 会用到它）。
- 声明两个泛型词：`GENERIC: >cartesian ( direction -- x y )`和`GENERIC: flip ( direction -- direction' )`。它们的方法你在后面几个任务里补上。

然后为`>cartesian`添加`M: cardinal`方法，返回指定方向的单位向量。

```factor
T{ cardinal { direction north } } >cartesian . .
! => 1
! => 0
! (top of stack is `y`, just below it is `x`)
```

## 2. 极坐标的笛卡尔坐标

为`>cartesian`添加`M: polar`方法，把极坐标形式转换成`(x, y)`：

```
x = magnitude * sin(bearing-in-radians)
y = magnitude * cos(bearing-in-radians)
```

```factor
T{ polar { magnitude 10 } { bearing 90 } } >cartesian . .
! => 0   (close to zero — the cosine of π/2 isn't exactly 0 in floats)
! => 10
```

## 3. 相对坐标的笛卡尔坐标

为`>cartesian`添加`M: relative`方法。难点在于：相对方位是相对于*本船当前航向*测量的，而这个航向并不在元组里。用`heading get`读取`heading`变量（任务 1 中声明的），加上方位偏移（`ahead = 0`、`starboard = 90`、`behind = 180`、`port = 270`），再算出笛卡尔坐标点。调用方会在`with-variable`块里设置`heading`。

```factor
0 heading [
    T{ relative { distance 5 } { bearing starboard } } >cartesian
] with-variable . .
! => 0   (heading 0 is north; starboard is east; (5, 0))
! => 5
```

## 4. 翻转

为`flip`泛型（在任务 1 中声明）添加方法，让它返回相反的方向。

- 对于`cardinal`：north ↔ south，east ↔ west。
- 对于`polar`：给方位角加上 180°（对 360 取模）。
- 对于`relative`：ahead ↔ behind，starboard ↔ port。

```factor
T{ cardinal { direction north } } flip .
! => T{ cardinal { direction south } }

T{ polar { magnitude 10 } { bearing 90 } } flip .
! => T{ polar { magnitude 10 } { bearing 270 } }

T{ relative { distance 5 } { bearing ahead } } flip .
! => T{ relative { distance 5 } { bearing behind } }
```

## 5. 方位相加

定义`add-bearings ( a b -- x y )`，把两个方向都转换成笛卡尔坐标并返回它们的和。它对`cardinal`、`polar`和`relative`的任意组合都适用，这正是把`>cartesian`做成泛型的好处。

```factor
T{ cardinal { direction north } } T{ cardinal { direction east } } add-bearings . .
! => 1
! => 1
```
