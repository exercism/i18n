# 提示

## 通用

- `struct` 是一系列具名元素的序列，这些元素称为字段，每个字段都有一个名称和一个类型。

## 1. 创建一辆遥控车

- 实例化一个新的 [struct][struct]，并填充除 `distance` 之外的所有字段。
- 创建一个函数，返回新建的 struct 类型，并相应地更新各个字段

## 2. 创建一条赛道

- 定义一个新的 [struct][struct]，其中包含 1 个字段
- 创建一个函数，返回新建的 struct 类型，并相应地更新各个字段

## 3. 驾驶汽车

- 新增一个字段来记录已行驶的距离
- 你需要检查电量是否足够驱动汽车

## 4. 检查遥控车能否完成比赛

- 假设汽车刚刚开始比赛
- 你需要计算汽车在当前电池电量下最多能行驶的距离
- 汽车可以行驶的次数可以通过 `battery / batteryDrain` 计算得出。
- 汽车能行驶的最大距离是汽车速度与可行驶次数的乘积。
- 知道了汽车能行驶的最大距离之后，将其与赛道的距离进行比较
