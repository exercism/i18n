# 说明

为一个已完成的扫雷棋盘添加地雷计数。

扫雷是一款流行的游戏，玩家需要借助数字提示来找出地雷。这些提示表示有多少颗地雷与某个方格直接相邻（水平、垂直或对角）。

在这个练习中，你需要编写一些代码，统计与给定空白方格相邻的地雷数量，并用这个数量替换该方格。

棋盘是一个由空白字符（' '）组成的矩形。地雷用星号（'\*'）字符表示。

如果某个方格周围完全没有相邻的地雷，就把该方格留空。

## 示例

例如，你可能会收到一个像这样的 5 x 4 棋盘（这里用 '·' 字符来表示空白格，以便在屏幕上显示）：

```
·*·*·
··*··
··*··
·····
```

你的代码会把它转换成这样：

```
1*3*1
13*31
·2*2·
·111·
```
