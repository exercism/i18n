# 帮助

## 安装 Cairo

关于 Cairo 的安装和学习资源，请参阅 [Exercism 帮助页面][help-page]。

## 提交解答

通常，你应该提交所有用来实现解答的文件（大多数情况下是`src/lib.cairo`）。如果你使用了任何外部 crate，请考虑一并提交`Scarb.toml`文件。这会让审核流程更快、更清晰。

## 反馈、Issue 和 Pull Request

GitHub 上的 [track 仓库][github]是所有 Cairo 练习的大本营。如果你对某个练习有反馈，或者想帮忙实现新练习，就去那里创建一个 issue。Cairo track 团队的成员很乐意帮忙！

如果你想进一步了解 Exercism，可以看看[贡献指南][contribution guide]。

## 提交不完整的解答

你也可以提交不完整的解答，这样就能看到别人是如何完成这个练习的。
