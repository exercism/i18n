# 指令补充

复数的乘方需要用到指数函数、正弦函数和余弦函数，而这些在 WebAssembly 中都没有提供。好在可以用[泰勒级数](https://en.wikipedia.org/wiki/Taylor_series)来计算它们。为了与预期的值一致，你的精度至少需要达到`1/26!`。

## 指数函数

```
exp(x) ≃ 1 + x + x ^ 2 / 2! + x ^ 3 / 3! + x ^ 4 / 4! + ... + x ^ n / n!
```

## 正弦函数

```
sin(x) ≃ x - x ^ 3 / 3! + x ^ 5 / 5! - x ^ 7 / 7! + ... - x ^ n / n!
```

## 余弦函数

```
cos(x) ≃ 1 - x ^ 2 / 2! + x ^ 4 / 4! - x ^ 6 / 6! + ... - x ^ n / n!
```
