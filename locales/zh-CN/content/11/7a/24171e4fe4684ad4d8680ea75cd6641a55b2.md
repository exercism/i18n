## 说明

你被一家回收中心录用了。
由于空间不足，所有产品都被放在同一条传送带上，但这导致不同的材料混在一起，变得无法使用。
为了解决这个问题，你的任务是编写一些函数，用来识别产品的类型。

### 1. 检查一个值是否为布尔值

实现`isBoolean`函数，检查一个值是否为布尔值。

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. 检查一个值是否为数字。

实现`isNumber`函数，检查一个值是否为_有限_的`number`或`bigint`，即不是`NaN`或`Infinity`。

有时，读取 ID 的设备会出现故障，把非数值读成`NaN`（Not a Number）或`Infinity`。
你的函数也应该能正确处理这种情况。

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. 检查一个值是否为对象

实现`isObject`函数，检查一个值是否为对象。
在传送带上，`null`什么都不是，也不被视作对象。

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. 检查一个字符串是否为数字字符串

实现`isNumericString`函数，检查一个值是否为只由数字组成的字符串，或者由一个减号后跟数字组成、表示负数的字符串。
只有整数才会被考虑；在回收机器人的这项检查中，小数不算数值。

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. 检查一个对象是否为电子设备

实现`isElectronic`函数，检查一个对象是否为所提供的`ElectronicDevice`类的实例，或者是它的某个子类的实例。

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. 检查一个值是否为非空数组

实现`isNonEmptyArray`函数，检查一个值是否为非空数组。

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. 检查一个值是否为空数组

实现`isEmptyArray`函数，检查一个值是否为空数组。

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. 检查一个对象是否具有`type`属性或方法

实现`hasType`函数，检查一个对象是否具有`type`属性或方法。

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. 如果一个对象没有`id`属性或方法，就抛出错误

实现`assertHasId`函数，如果对象缺少`id`属性，就抛出一个`Error`。

如果对象确实有`id`属性，则不应返回任何内容。

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. 检查一个对象是否具有`id`属性

实现`hasIdProperty`函数，检查一个对象是否具有`id`属性。

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. 检查一个对象是否具有已定义的`type`属性

实现`hasDefinedType`函数，检查一个对象是否具有不为`undefined`的`type`属性。

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
