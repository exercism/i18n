# 说明

有了类型检查，HTTP 端点会更好用。为 POST 请求加上 Record 类型，就能确保每次都发送正确的数据。

## 目标

- 修改提供的代码。
- 为这个 Record 类型添加必要的属性，让它能接受两个操作数和一个运算符。
- 添加一个 HTTP 资源函数，在路径 '/calc' 上接受 POST 请求。
- 该函数应接受 Calculation record 类型作为载荷，并返回一个通用的 JSON 对象。

### 接收

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### 返回

```json
{ "expression": "4+10.2", "result": 14.2 }
```
