# 关于

## 数组迭代

`for` 循环可以用来迭代数组，并对每个元素重复执行代码：

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

在上面的例子中，`fruit` 是保存数组 `fruitList` 中单个元素的值的变量。编译器会确保 `fruitList` 可以被迭代，否则就会停止执行。

## 范围迭代

你可以使用范围运算符来迭代数字。这个运算符接受两个 `Int` 操作数，写法是 `min...max`。`min` 是包含的，`max` 是不包含的（`min` <= i 并且 `max` > i）

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## 键值对迭代

你也可以迭代由键值对组成的集合。语法上的唯一区别是：这里不写单个变量，而是先写一个键的变量标识符，接着写 `=>`，再写值的变量标识符：

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
