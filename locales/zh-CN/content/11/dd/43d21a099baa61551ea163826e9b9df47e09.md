# 说明

你在布拉格伏尔塔瓦河畔照看一个小小的气象站，每个班次都会把温度读数随手记进一个纯文本日志里，每行一条读数。五个小词就能打理好一个班次的全部账目。

每个词都会收到日志文件的路径。

## 1. 读取每一条读数

定义`read-readings`，让它把日志里所有的读数作为一个字符串数组返回，每行一个。

```factor
"weather.log" read-readings .
! => { "21.5" "19.0" "22.3" }
```

## 2. 找出最新的一条读数

定义`latest-reading`，返回最近的一条读数，也就是日志的最后一行。

```factor
"weather.log" latest-reading .
! => "22.3"
```

## 3. 读取原始日志

定义`log-text`，把整个日志文件作为一个字符串返回，与存储时完全一致。

```factor
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n"
```

## 4. 记录一条读数

定义`record-reading`，把一条新读数作为单独一行追加到日志末尾，先前的读数保持不变。没有返回值。

```factor
"23.1" "weather.log" record-reading
"weather.log" log-text .
! => "21.5\n19.0\n22.3\n23.1\n"
```

## 5. 重写日志

定义`rewrite-log`，用一组全新的读数替换整个日志，每行一条。

```factor
{ "10.0" "11.0" } "weather.log" rewrite-log
"weather.log" log-text .
! => "10.0\n11.0\n"
```
