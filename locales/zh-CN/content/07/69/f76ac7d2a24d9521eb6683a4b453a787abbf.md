# 如何写出好的支持请求

在 Exercism 上遇到问题，需要帮助吗？
学会如何写好一份支持请求，并鼓励我们的社区来支持你，能大大增加你得到有用回复的机会。

下面是一些关键建议。

## 用代码块，而不是图片

想分享代码（无论是你写的代码，还是操作说明）时，请使用代码块，而不是图片。

作为开发者，我们读代码远比把图片放大去看要快得多。
而且我们的很多用户使用屏幕阅读器，而屏幕阅读器无法读出图片内容。
所以，如果你想做一个好社区成员、想鼓励我们的志愿者来帮助你、想显得专业，就把代码作为文本分享，而不是图片！

例如，你可以输入以下内容：

````
```
for number in range(10):
  total += number;
```
````

渲染出来是这样的：

```
for number in range(10):
  total += number;
```

在代码块的开头加上语言名，还能获得语法高亮：

````
```python
for number in range(10):
  total += number;
```
````

就变成了：

```python
for number in range(10):
  total += number;
```

## 使用包容性语言

Exercism 的成员有着不同的性别。
如果你在我们的 Discord 里冒出来就说“嘿，兄弟们”之类的话，就立刻把社区里一半的人排除在外了。
这意味着他们不太可能帮助你。而且，社区里的其他人也不太可能帮你，因为 Exercism 非常重视包容性。

所以，如果你想获得帮助，也想做一个友善的人，就不要使用带性别指向的语言。
试试“嘿，大家好”“各位好”，或者大胆一点，用“嘿，各位 Exercist！”

想了解更多，请阅读我们的文章[我们使用的措辞](./the-words-that-we-use)。
