# 简介

在硬件底层，[晶体管只能处于开或关状态][how-transistors-work]：传统上用`1`和`0`表示的两种状态。
它们就是[`binary digits`][binary-digits]，简称[`bits`][bits]。
对使用低级语言的系统程序员来说，了解`bits`和`binary`尤为重要。
然而，在计算的大部分历史中，编程的重点一直是寻找越来越复杂的方法来_抽象掉_这种二进制现实。


在 Python 中（以及许多其他[高级编程语言][high-level-language]中），我们使用`int`、`float`、`string`以及其他已定义的_类型_，甚至包括音频和视频格式。
Python 内部会（_最终_）负责把所有更高层的数据转换成比特。


不过，使用[位运算符][python-bitwise-operators]和[位运算][python-bitwise-operations]有时能在速度和内存效率方面带来显著优势，即使在像 Python 这样的高级语言中也是如此。
