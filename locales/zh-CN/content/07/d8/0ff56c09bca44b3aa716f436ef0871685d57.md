# 关于

`Complex numbers`并不复杂。
它们只是需要一个不那么吓人的名字。

复数非常有用，尤其在工程和科学领域，因此 Julia 把[复数][complex]作为标准数值类型，与整数和浮点数并列。

## 基础

Julia 中的 `complex` 值本质上是一对数：通常是浮点数，但也不总是。
由于一些不太走运的历史原因，它们被称为“实部”和“虚部”。
同样，最好把注意力放在它内在的简洁性上，而不是这些奇怪的名字上。

要从两个实数创建复数，只需给虚部加上后缀 `im`。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> typeof(z)
ComplexF64 (alias for Complex{Float64})

julia> zi = 1 + 2im
1 + 2im

julia> typeof(zi)
Complex{Int64}
```

因此有多种 `Complex` 类型，它们由对应的整数或浮点数类型派生而来。

如果想用实数变量创建复数，上面的写法行不通。
写成 `a + bim` 会让解析器误以为 `bim` 是一个（并不存在的）变量名。

写成 `b*im` 也可以，但更推荐的做法是使用 `complex()` 函数。

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

你可能会想，为什么用 `im`，而不是 `i` 或 `j`？

大多数工程师习惯用 `j`。
大多数科学家和数学家更喜欢用数学符号 `i` 表示_虚数_，但在电气工程中，`i` 已经用来表示_电流_，两者会冲突。

[手册][complex]中说：“使用数学家的 i 或工程师的 j 作为这个全局常量被否决了，因为它们是非常常见的索引变量名。”

幸运的是，这也避免了工程师与其他所有人之间的长期争论。
至于这有没有影响当时的决定，你可以自行判断。

要单独访问复数的各个部分：

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im

julia> real(z)
1.2

julia> imag(z)
3.4
```

任一部分都可以为零，此时数学家可能会说这个数“纯实”或“纯虚”。
但在 Julia 中，它仍然是一个复数。

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im

julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})

julia> zi = 3.4im
0.0 + 3.4im

julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

你可能听说过“`i`（或 `j`）是 -1 的平方根”。

目前，这只说明虚部_按定义_满足下面这个等式：

```julia-repl
julia> 1im * 1im == -1
true
```

这个想法很简单，却会带来有趣的结论。

## 运算

用于浮点数和整数的所有标准数学 `operators` 和初等函数，也都能用于复数。下面举几个例子：

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im

julia> z2 = 2 + 1.5im
2.0 + 1.5im

julia> z1 + z2  # addition
3.5 + 3.5im

julia> z1 * z2  # multiplication
0.0 + 6.25im

julia> z1 / z2  # division
0.96 + 0.28im

julia> z1^2  # exponentiation
-1.75 + 6.0im

julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

解释复数乘法和除法的规则超出了本概念的范围（_而且你也多半不常需要“手工”进行这些运算_）。

如果你想深入了解这个主题，任何关于复数的[数学][math-complex]或[电气工程][engineering-complex]入门材料都会讲到这些。

另外，Exercism 有一个 `Complex Numbers` 练习，你可以在其中从基本原理出发，实现一个支持这些运算的复数类。

复数（基本）___不能___做整数除法，因此 `//`、`÷` 和 `%` 运算符对复数类型都会失败。
唯一的例外是用 `//` 对复数_整数_运算，得到复有理数，但这大概并不常用。

## 函数

大多数数学函数都能接受复数输入。

不过，传入实数输入却期望得到复数结果，通常行不通。
这是一种性能优化，看过“多重分派”概念后就更容易理解了。

```julia-repl
julia> sin(1.5 + 2.0im)
3.752771340479298 + 0.25655395609048176im

julia> sqrt(-1)
ERROR: DomainError with -1.0:
sqrt was called with a negative real argument but will only return a complex result if called with a complex argument. Try sqrt(Complex(x)).

julia> sqrt(-1 + 0im)
0.0 + 1.0im
```

除了 `real()` 和 `imag()`，还有几个函数与复数尤其相关。
如果这些内容你看不懂，跳过也没关系！

- `conj()` 只是把复数虚部的符号取反（_从 + 变 -，或反过来_）。
    - 由于复数乘法的运作方式，它比你想象的更有用。
- `abs(<complex number>)` 保证返回一个没有虚部的实数。
- `abs2(<complex number>)` 返回 `abs(<complex number>)` 的平方：计算比 `abs()` 更快，而且常常正是计算所需要的。
- `angle(<complex number>)` 返回以弧度为单位的相位角。

```julia-repl
julia> z1
1.5 + 2.0im

julia> conj(z1)
1.5 - 2.0im

julia> abs(z1)
2.5

julia> abs2(z1)
6.25

julia> angle(z1)
0.9272952180016122
```
给喜欢数学的读者一个粗略的解释（_同样，不看也没关系_）：

- `z1` 的 `(real, imag)` 表示实际上就是在复平面上使用笛卡尔坐标。
- 同一个复数也可以用极坐标写成 `(r, θ)` 的形式。
- 这里，`r` 和 `θ` 分别由 `abs(z1)` 和 `angle(z1)` 给出。

下面用几个常量举个例子：

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im

julia> real(euler)
-1.0

julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

于是，一个包含自然界最重要的三个常量 `e`、`i`（或 `j`）和 `pi` 的简单表达式，得到的结果是 `-1`。
有些人认为这是整个数学中最美的结果。
它最早可以追溯到 1740 年左右。

极坐标 `(r, θ)` 形式非常有用，因此 Julia 内置了 `cis`（`cos(x) + isin(x)` 的缩写）和 `cispi`（`cos(πx) + isin(πx)` 的缩写）这两个函数，它们可以更高效地构造这种形式。

极坐标形式的好处在欧拉那个优美的公式中体现出来：`ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`，其中 `|x + iy| = 1`。
当 `|x + iy| = r` 时，就得到更一般的极坐标形式 `r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`。
尤其要注意，指数形式简洁，也易于运算。

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

上面用的是近似相等，因为 [`cis`][cis] 和 [`cispi`][cispi] 这两个函数能给出更漂亮的数值结果，尤其是 `cispi`，在处理 π 的任意倍数参数时更是如此（比如弧度！）。

```julia-repl
julia> cis(π)
-1.0 + 0.0im

julia> cispi(1)
-1.0 + 0.0im

julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im

julia> cis(θ)
6.123233995736766e-17 + 1.0im

julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

顺带一提，这也让复数非常适合在二维中进行旋转和径向位移。

以旋转为例，复数 `z = x + iy` 绕原点旋转角度 `θ`，只需做一次简单的乘法：`z * ℯ^(iθ)`。
注意，这里的 `x` 和 `y` 就是实二维笛卡尔平面上通常的坐标，正角度会得到*逆时针*旋转，负角度则得到*顺时针*旋转。

同样简单的是，径向位移 `Δr` 可以通过把它加到极坐标形式下复数的模 `r` 上来得到（例如 `z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`）。
可以看到角度部分保持不变，只有模 `r` 发生变化，正如预期。

## 选读：复数常见问题

除非你感兴趣，否则这部分可以跳过。

### 这是不是某种奇怪的纯数学新东西？

在 16 世纪，它确实既奇怪又新鲜。

500 年后的今天，它已成为大多数工程学科和物理科学的核心。

### 为什么会有人用复数？

事实证明，要描述任何旋转的东西或任何具有波动性质的东西，复数都是最简单的方式。
因此它们被广泛用于电气工程、音频处理、物理、电子游戏和导航等领域，这里只举了几个例子。

你能看到东西在旋转。
复数也许不能让世界转动，但它们非常擅长解释世界转动所_带来的结果_：看看任何一张大型风暴的卫星图像。

没那么明显的是，声音、光、无线电信号都具有波动性，甚至连你所在国家的经济也至少有一部分具有波动性。

许多这类波动处理都可以用三角函数（`sin()` 和 `cos()`）完成，但很快就会变得很乱。

而复指数运算起来___容易得多___。

### 可我并不需要复数！

除非你住在山洞里，靠采集食物为生，否则这话并不成立。

如果你正在某种屏幕上读这段话，那你就完全依赖于 20 世纪借助复数取得的一些有用进展。

1. __半导体芯片__。
    - 它们在经典物理学中说不通，只能用量子力学（QM）来解释（并设计）。
    - 在 QM 中，一切都按定义取复值。（_一路往下都是波形_）

2. __快速傅里叶变换（FFT）算法__。
    - FFT 是复数的一种应用，凡是与声音传输、音频处理、照片和视频有关的_一切_，都有它的身影。

    - MP3 和其他音频格式使用 FFT 来压缩，让更多音频能装进更小的存储空间。
    - JPEG 压缩和 MP4 视频，以及许多其他图像和视频格式，也使用 FFT 来压缩。

    - FFT 还用于数字滤波器，让手机基站能把你的个人手机信号与其他人的信号分离开。

所以，你正在使用的技术，很可能每秒都要进行成千上万次依赖复数的计算。
