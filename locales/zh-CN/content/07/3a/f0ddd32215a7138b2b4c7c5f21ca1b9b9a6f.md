# 关于

循环基本上可以分为两类：

1. 循环直到满足某个条件。
2. 遍历集合中的元素。

这两种在 R 中[都可以实现][web-loops]，不过第一种可能更常见。

## `while` 和 `repeat` 循环

对于那些事先不知道要循环多少次的开放式问题，R 提供了带条件的[`while`][ref-control]循环，以及不带条件的[`repeat`][ref-control]循环（等价于 `while (TRUE)`）。

基本形式相当简单：

```R
while (condition) {
  do_something()
}
```

此时，程序会一直在循环里转下去，直到 `condition` 不再是 `TRUE`。

有两种方法可以提前退出循环：

- `break` 会让循环退出，程序从循环的右大括号 `}` 之后的那一行继续运行。
- `return(x)` 会停止当前函数的执行，把返回值 `x` 传回给调用方。

有了这些手段，有时用 `repeat { ... }` 创建一个“无限”循环会很方便，然后在循环体里找到一个停止条件来触发 `break` 或 `return`。

下面三种写法是等价的，最终都会得到 `x == 0.4444...`。

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 遍历向量（或其他集合）

在 R 中，这通常是不必要的。
正如其他概念中所讨论的，许多函数会直接作用于整个向量。

不过，显式循环有时还是无法避免。
尤其是在以下情况：

- 循环体带有副作用，比如打印输出或文件 I/O。
- 循环要一直持续到满足某个标准为止，而在此之前要经过多少次迭代无法预知。

循环条件必须放在括号里。
和函数体一样，对于单行循环体，大括号是可选的（但通常还是会写上）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

如果当前这次迭代不满足某个条件，可以用 `next` 直接跳到下一次迭代：

```R
for (n in 1:5) {
  if (n %% 2 == 0) next
  print(n)
}
#> [1] 1
#> [1] 3
#> [1] 5
```

如果需要数字下标，请使用 [`seq_along()`][ref-seq_along]。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

并不推荐使用 `i in 1:length(v)`，因为当 `length(v)` 为零时会出问题。
范围 `1:0` 等价于 `c(1, 0)`，所以循环体会运行，而且很可能会出错。
`seq_along()` 函数就是为了正确处理这种情况而设计的。
