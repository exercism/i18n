# 提示

## 通用

- 不可变类里没有 `new`。`create` 的起点是一个已经存在的该类变量：

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` 不会改变 `b`。它返回一个新的方位，所以被返回的正是它。

## 1. 测量方位

- `%` 可以把数字限定到范围内，但 `-10 % 360` 等于 `350`，只是因为当右边的操作数为正时，Sather 的 `%` 不会返回负数。所以只用 `d % 360` 就够了。

## 2. 转向

- 把转过的量加到原有的度数上，再用总和构造一个新的方位：`#BEARING(degrees + by)`。
- `create` 已经会把结果重新限定到范围内，所以越过正北不用做任何处理。

## 3. 比较

- 一行就够了：比较两个 `degrees`。
- 实参的类型是 `SAME`，按常规方式读取它的属性即可：`other.degrees`。

## 4. 给方位点命名

- 诀窍是在相除之前先平移半个区间，这样每个方位点都是以自己的*中心*作为度量起点：`((degrees + 22) / 45) % 8` 对正北得 0，对东北得 1，依此类推。
- 然后对这个数字写一个 `case`，列出八个名称，再加上一个 `else`：即便八个分支已经覆盖了所有可能的值，`case` 也总是需要 `else`。

## 5. 写下来

- `+` 可以把各个片段连起来，但只有字符串才能被加东西。这里数字在前面，所以要用 `degrees.str` 来开始拼接。`"a" + 1` 没问题，`1 + "a"` 则通不过编译。
- 直接调用 `point`，不要重新算一遍名称。
