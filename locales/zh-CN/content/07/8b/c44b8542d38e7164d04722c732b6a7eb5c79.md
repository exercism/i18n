# 练习测试

按照下面的步骤，为练习开发解答并在本地测试。

## 下载练习

打开 Command Prompt，用你想要的那个练习的名称执行下面的命令来下载它。

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## 开发你的解答

1. 执行下面的命令，进入刚下载的练习目录。

     >**提示：** 下面命令中的目录位置取决于你的操作系统和你配置的 Exercism 工作区。你可以通过执行`exercism configure`命令查看工作区的位置。

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. 按照提供的说明，为这个练习开发一个解答。

## 测试你的解答

有些 Ballerina 练习只有一个测试，有些则有多个测试。测试位于练习根目录下`/tests`目录中相应的测试文件里。

### 测试只有一个测试的练习

执行下面的命令来运行练习的测试。

默认只启用第一个测试。这是有意设计的，让你可以专注于只让那一个测试通过。

```sh
bal test
```

### 测试有多个测试的练习

按照下面的步骤测试有多个测试的练习。

1. 第一个测试通过后，移除`@test:Config`注解的`enable: false`属性，以启用下一个测试。

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  执行下面的命令，运行已启用的测试。

   ```sh
     bal test
   ```

3. 重复上面两个步骤，启用其余的测试。

当所有测试都已启用，并且你的实现能通过每一个测试时，你就成功完成了这个练习。
