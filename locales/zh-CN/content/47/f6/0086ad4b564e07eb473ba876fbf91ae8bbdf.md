# 简介

函数最早是在 [基础][concept-basics] 概念中介绍的，比如下面这个例子：

```R
squareit <- function(x) {
    x * x
}

squareit(3)
#> [1] 9

# shorter form
squareit_short <- function(x) x ^ 2
```

再仔细看看 `squareit` 的定义，可以分辨出几个部分：

- 这个函数有一个形参 `x`。
- 有一个函数体，通常放在大括号`{ }`里。
- 函数对象创建好之后，会被赋值给变量`squareit`。

在 R 里，函数是一等对象，和数字、字符串一样。
因此，`squareit <- function...`这个赋值在语法上和`x <- 42`完全一样。

## 实参

R 不像 Python、Julia 等其他脚本语言那样，明确区分位置实参和关键字实参。

函数调用既可以按位置传值，也可以按名称传值。
后者对于实参很多、顺序又难记的复杂函数很有用。

```R
f <- function(x, y) x / y

# call positionally
f(4, 2)
#> [1] 2

# call by name
f(y = 2, x = 4)
#> [1] 2
```

### 可选实参

默认实参值可以在函数定义中指定，但必须放在所有没有默认值的形参之后。

之后我们可以选择接受默认值，还是覆盖它。

```R
g <- function(x, y = 2) x / y

# default y value
g(6)
#> [1] 3

# explicit y value
g(6, 3)
#> [1] 2
```

### 额外实参

要接受任意数量的额外实参，可以在定义中使用`...`（省略号）。
可以把函数调用中任何额外的值转换成一个向量，不过请继续往下读，看看使用这些“点参数”的另一种方式（在其他一些语言中称为“varargs”）。

```R
var_f <- function(x, y, ...) {
  print(c(...))
}

var_f(2, 3, "opt1", "opt2")
#> [1] "opt1" "opt2"
```

## 函数环境

前面我们说过，形参和函数体都是函数的组成部分。

事实上还有第三个组成部分：定义函数时所处的*环境*。

嵌套函数就是一个很好的例子：

```R
outer_func <- function(x) {
  inner_func <- function(y) {
    x * y
  }
  
  inner_func(3)
}

outer_func(5)
#> [1] 15
```

这次函数调用把`x = 5`传给外层函数，这个值在该函数体内可以使用。

内层函数是外层函数体的*一部分*，可以访问`x`的值。
换个说法，`x = 5`位于内层函数的*环境*中。

从技术上讲，这叫作[闭包][wiki-closure]。

环境在点参数这里尤其重要，因为用这种方式提供的任何值都可以传递给函数体中的函数调用。
外层函数不需要知道、也不用关心这些点参数是什么意思。

```R
f_var <- function(x, ...) {
  sum(x, ...)
}

x <- c(1, 2, NA, 6)

# for sum(), na.rm defaults to FALSE
f_var(x)
#> [1] NA

# pass through the na.rm value
f_var(x, na.rm = TRUE)
#> [1] 9
```

这种技巧被 Tidyverse 系列库大量使用，比如[`stringr`][ref-stringr]。
很多`stringr`函数都是对`stringi`和 base R 中底层函数的友好封装。

传给`str_*()`函数的额外实参，会直接透传给那些底层函数。

## 函数作为返回值

外层函数可以定义内层函数（可以是有名字的，也可以是下面要讲到的匿名函数），并把它用作返回值。

返回的函数会包含定义它时所处的环境。

```R
times_y <- function(x) {
  # anonymous function - see next section
  \(y) x * y
}

f <- times_y(3)
class(f)
#> [1] "function"

f(4)
#> [1] 12
```

## 匿名函数

定义函数时，我们通常会把得到的函数对象绑定到一个变量上：

```R
x <- 2

# function definition captures x from the environment
doubleit_short <- function(y) x * y
```

这样方便在脚本后面使用这个函数，但这种绑定并不是必需的。
一个简短、只用一次的函数，可能在当前场景下就很有用。
如果不绑定名字，它就被称为*匿名函数*。

匿名函数用得太多了，以至于（从 R v4.1.0 起）有了一种定义它们的简写语法：把`function`这个词换成一个反斜杠`\`。

上一节讲返回值时就用了一个例子。

## 修改时复制

R 允许给向量的单个元素赋值。
如果我们把向量作为函数实参传进去，在函数体里修改它之后再返回，得到的就是修改过的向量。

但原来的向量怎么样了呢？

```R
f <- function(vec) {
  vec[1] <- 42
  vec
}

vals <- c(1, 3, 4)

# f() returns a modified vector
f(vals)
#> [1] 42  3  4  

# the original vector is unchanged.
vals
#> [1] 1 3 4
```

R 是一门为数据科学设计的语言。
收集这些数据可能要花很多时间、精力，还可能花掉一笔高得令人咋舌的钱：*千万别把它弄坏！*

总体原则（也有少数例外）是*修改时复制*。
如果一个对象（比如向量）以可能引发后续问题的方式被改动，R 会返回*修改后的副本*，并保持原对象不变。

复制大型数据结构在计算上可能很昂贵，但和数据被破坏相比，这通常是两害相权取其轻。
