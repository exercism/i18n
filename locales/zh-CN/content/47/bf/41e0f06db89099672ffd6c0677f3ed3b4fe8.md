# 安装

elm 当前版本是 0.19.1。
安装说明会随着语言的发展而变化。
最新的安装说明请参阅 [elm 指南的安装说明][elm-install]。

[elm-install]: https://guide.elm-lang.org/install/elm.html

## 其他工具

**elm-test**

用来从命令行运行测试的工具叫做 elm-test。
目前 elm-test 需要 Node.js 和 npm，如果你还没有安装，请先[安装 Node.js 和 npm][npm-install]。
装好 npm 之后，就可以用下面的命令安装 elm-test：

```shell
npm install --global elm-test@latest-0.19.1
```

更多信息请见 [elm-test 的 npm 主页][elm-test]。

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

大多数 elm 程序员都用 elm-format 来格式化自己的 elm 代码。
它是一个零配置的代码格式化工具。
如果你不习惯自动格式化工具，一开始可能会觉得有点别扭，但一旦用习惯了，你就会想不通以前没有它的时候是怎么写代码的。
它同样可以用 npm 安装：

```shell
npm install --global elm-format@latest-0.19.1
```

更多信息请见 [GitHub 上的 elm-format 主页][elm-format]。

[elm-format]: https://github.com/avh4/elm-format

**文本编辑器**

至少对 [IntelliJ][intellij]，以及兼容 [elm language server][els] 的文本编辑器（比如 VS Code、Sublime Text 或 Vim），Elm 都有不错的支持。

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## npm 的权限错误

在安装 elm-test 或 elm-format 时，你可能会遇到 npm 的 EACCESS 权限错误。
如果是这样，请按照 npm 网站上的说明操作。
[全局安装软件包时解决 EACCES 权限错误][eaccess]。

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
