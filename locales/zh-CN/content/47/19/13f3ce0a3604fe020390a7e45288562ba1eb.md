# 帮助

## 安装 Rust

Rust 的安装方法和学习资源请参见 [Exercism 帮助页面][help-page]。

## 提交解答

一般来说，你应该提交所有实现了你的解答的文件（大多数情况下是`src/lib.rs`）。如果你使用了任何外部 crate，请考虑一并提交`Cargo.toml`文件。这能让审核流程更快、更清晰。

## 反馈、问题与 Pull Request

请前往[论坛](https://forum.exercism.org/c/programming/rust/)发帖，对某个练习提出反馈，或者告诉大家你想帮忙编写新练习。Rust 轨道团队的成员很乐意帮忙！

GitHub 上的[轨道仓库][github]收录了所有的 Rust 练习。

如果你想进一步了解 Exercism，可以看看[贡献指南]。

## 提交未完成的解答

你也可以提交未完成的解答，这样就能看到其他人是如何完成这个练习的。
