# 补充说明

## 提示

你需要实现下面这个函数

```haskell
value :: (Color, Color) -> Int
```

它只接受两种颜色，并给出该电阻阻值的数值部分。

**加分项：属性测试**

这个练习是编写[属性测试](https://en.wikipedia.org/wiki/Property_testing)的好机会。如果你以前没写过，这里有一些资源：

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

我们在测试文件里提供了一个 QuickCheck 属性测试示例。

可以测试的属性示例：

- 对于所有`x`不为`Black`的`(x, y)`，都有`value (x, y) >= 10`

- 对`value (x, y)`调用`show`得到的字符串，等于对`value (y, x)`调用`show`得到的字符串再调用`reverse`的结果。

- 所有颜色的名称都唯一。（任意两种颜色，只要颜色不同，它们的名称也就不同。）
