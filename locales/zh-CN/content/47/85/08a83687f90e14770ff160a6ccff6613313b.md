# 元组

元组是一种轻量的方式，用于把数量固定、类型可以各不相同的一组数据组合在一起。元组没有特定的名字；一旦给一个数据结构命名，它就变成了 `struct`。元组的字段也没有名字；访问它们要靠解构，或者按位置访问。

## 语法

元组是用括号括起来的一串字段：

- `()` 是 `unit type`（单元类型），属于一种[特殊情况](https://doc.rust-lang.org/std/primitive.unit.html)
- **(** _表达式_ **,)** 是单元素元组表达式
- **(** _类型_ **,)** 是单元素元组类型
- **(** _表达式_ **,** ... **)** 是通用元组表达式
- **(** _类型_ **,** ... **)** 是通用元组类型

### 创建

元组总是用元组表达式创建：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元组可以有任意数量的元素。

### 通过解构访问

可以通过解构来访问元组的元素。这其实就是把变量名赋给元组中的各个元素，同时消耗掉这个元组。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 按位置访问

也可以用数字位置下标来访问元组的元素。和往常一样，下标从 0 开始。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 元组结构体

你也会被要求处理元组结构体。和普通结构体一样，它们是有名字的类型；但与普通结构体不同的是，它们的字段是匿名的。它们的语法与普通元组的语法非常相似。既可以解构，也可以按位置访问。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let borrowed_neg = &my_tuple_struct.1;
let TupleStruct(borrowed_byte, _) = &my_tuple_struct;
assert_eq!(borrowed_neg, &-321);
assert_eq!(borrowed_byte, &123);
```

### 字段可见性

匿名元组的所有字段始终是公开的。不过，元组结构体的每个字段各自有可见性，默认是私有的，就像标准结构体的字段一样。你可以像在标准结构体中那样，用 `pub` 修饰符把字段设为公开。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
