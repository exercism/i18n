# 说明

在这个练习中，你要为一位朋友正在开发的新角色扮演游戏扩展任务逻辑。为了让游戏更有趣，朋友希望你加入一些能改变局势的随机事件。

整体背景和上一个练习相比没有变化。下面这段文字中用粗体标出了新增的随机事件。

游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛又忠诚的宠物狗。不幸的是，灾难降临了：她最好的人类朋友在森林里寻找浆果时被绑架了。Annalyn 将设法找到并救出她最好的朋友，这次冒险中她可以选择带上她的狗。

沿着最好的朋友留下的踪迹追踪了一段时间后，她找到了关押着好友的营地。原来有两个绑匪：一个强大的骑士和一个狡猾的弓箭手。

找到绑匪后，Annalyn 考虑自己可以采取以下哪些行动：

- _快速攻击_：如果骑士正在睡觉，就可以发动快速攻击，因为他需要时间穿上盔甲，此时他会很脆弱。<!-- **Annalyn 在接近骑士时有 5% 的概率绊倒。这会惊醒骑士，给他足够的时间穿上盔甲，于是快速攻击就无法再发动了。** [将来可能的测试用例] -->
- _侦察_：只要他们中至少有一个人醒着，就可以对这群人进行侦察。否则，侦察只是浪费时间。**有 _一半_ 的游戏过程中会起雾，因此无法进行侦察。**
- _给囚犯发信号_：如果囚犯醒着而弓箭手在睡觉，就可以用鸟叫声向囚犯发送信号，因为弓箭手受过鸟叫信号的训练，可能会截获消息。
- _解救囚犯_：Annalyn 可以试着潜入营地解救囚犯，但这个战术只有在囚犯醒着、另外两个人都睡着时才有效。如果囚犯正在睡觉，会被 Annalyn 突然出现吓到，从而惊醒另外两个人。如果弓箭手在睡觉，而 Annalyn 带着她的宠物狗，也可以解救囚犯，因为骑士会被狗吓到而退却，弓箭手也来不及拿起弓阻止囚犯被救走。**可惜的是，Annalyn 的狗喜欢追兔子。在去营地的路上，狗有 25% 的概率遇到兔子。这种情况下，狗就无法再去吓退骑士了。**

**救出朋友后，Annalyn 还有一些时间快速搜刮营地。她可以找到 3 到 13 枚金币。她还会遇到一个宝箱，里面装着一件随机物品。**

你的任务是实现这些函数：判断这些随机事件是否发生，以及确定 Annalyn 搜刮到的物品。

### 1. 添加一个判断是否有雾的函数

实现一个名为`is_foggy`的函数。这个函数有一半的时间返回`true`，否则返回`false`。

```julia-repl
julia> is_foggy()
true

julia> is_foggy()
false
```

### 2. 添加一个判断狗是否被分心的函数

实现一个名为`is_dog_distracted`的函数。这个函数有 25% 的时间返回`true`，否则返回`false`。

```julia-repl
julia> is_dog_distracted()
false

julia> is_dog_distracted()
true

julia> is_dog_distracted()
false
```

### 3. 添加一个搜刮金币的操作

实现一个名为`loot`的函数，返回 Annalyn 在营地中找到的金币数量。例如：

```julia-repl
julia> loot()
4

julia> loot()
7

julia> loot()
3
```

### 4. 添加一个搜刮宝箱的操作

实现一个名为`loot`的函数，它接受一个物品集合作为实参，并返回 Annalyn 在宝箱中找到的物品。例如：

```julia-repl
julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Cabbage"

julia> loot(["Cabbage", "Daring Dagger", "Sneaky Shoes"])
"Sneaky Shoes"
```
