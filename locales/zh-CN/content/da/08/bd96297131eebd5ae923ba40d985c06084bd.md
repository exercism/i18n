# 资源

## 推荐学习资源

Clojurescript 是 Clojure 的一个精心设计的方言。你对 Clojure 的了解（是这门语言本身，而不是 JVM 这个宿主平台）也能用在 Clojurescript 中。

- [ClojureScript API](http://cljs.github.io/api/)，官方的 API 文档。
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)，一份官方速查表。
- [Learn Clojurescript Syntax in 15 minutes](https://github.com/shaunlebron/ClojureScript-Syntax-in-15-minutes)，一个 GitHub 代码仓库，带你学习这门语言的语法。
