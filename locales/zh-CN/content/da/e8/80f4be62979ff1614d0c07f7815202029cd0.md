# 简介

常量是在编译时确定的值，不能重新赋值。使用 `const` 关键字声明单个常量：

```go
const greeting = "hello"
```

可以在一个块中声明多个常量。在块内，没有显式设置值的常量会重复上一个表达式：

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

常量通常在包级别声明，也可以在函数内部声明。

## 有类型常量和无类型常量

声明常量时不指定类型，它就成为了无类型常量。无类型常量没有固定的类型，它的值决定了它能与哪些类型兼容。只要底层值兼容，编译器就会在每次使用时把它转换成所需的类型：

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

有类型的常量在声明时就确定了类型：

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## 什么可以成为常量

常量只能保存布尔值、数字、字符串和 rune。由于值是在编译时确定的，函数调用的结果不能用作常量。

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## iota

在一个常量块中，`iota` 表示常量在块中的位置：

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

块中第一个常量之后的每个常量都继承同一个表达式，同时 `iota` 每次递增 1。

`iota` 在表达式中同样有效。

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
