# 简介

Cairo 中的函数让你可以把代码组织成可复用的单元，让程序更模块化、也更容易理解。
Cairo 的函数由`fn`关键字、函数名、括号中的形参列表，以及定义函数行为的代码块组成。

## 函数的形参

在 Cairo 中，所有函数形参都必须显式标注类型。
与一些语言不同，Cairo 不会推断类型，也没有默认的形参值，因此所有形参都是必需的。

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## 形参与实参

区分`parameters`和`arguments`很重要：

- **形参**是函数定义中使用的变量名，例如函数`print_greeting_name`中的`greeting`和`name`。
- **实参**是调用函数时实际传入的值。

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## 语句与表达式

函数体由一系列语句组成，末尾可以有一个表达式。

- 语句是执行某些操作、但不返回值的指令。
- 表达式会求值得到一个结果值。

用`let`关键字创建变量并给它赋值，这是一条语句。

```rust
let y = 6;
```

但上面这条语句中的`6`是一个表达式，它的求值结果是值`6`。

调用函数也是一个表达式，因为它总会求值得到一个值：如果指定了，就是函数的显式返回值；否则就是“unit”类型`()`。

## 返回值

Cairo 函数可以把值返回给调用它的代码。
返回值列在形参之后，用箭头`->`分隔。
在 Cairo 中，函数的返回值等同于函数体代码块中最后一个表达式的值。
你可以使用`return`关键字并指定一个值，从而提前从函数返回。

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## 调用函数

要在 Cairo 中调用函数，只需写出函数名，后面跟上括号里的实参。

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
