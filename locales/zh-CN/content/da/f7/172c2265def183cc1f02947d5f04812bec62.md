# 关于

Factor 的 `<iota>` 会生成一个*虚拟*的整数序列 `0, 1, …, n-1`。用 `map` 遍历它，就能得到一个制表序列，其中每个元素都是它所在位置的函数：

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

有两个部分可以帮你把整数编码序列转换成字符串：

| word      | role                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | 解析期字面量，会把一个字符的码点压入栈                  |
| `>string` | 把码点序列转换成字符串                                  |

两者组合起来，就是按位置构建字符行的标准惯用法：

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

在 quotation 内用 `if`（或 `?`）来选择字符，能让每个位置上的判断贴近它所依赖的下标。
