# 关于

在 Python 中，[枚举][enum-docs]是一组唯一的名称，这些名称绑定到唯一且**常量**的值。
`Enums`通过继承`Enum`类来定义。
内置枚举类型位于`enum`模块中，而`Enum`类可以通过`from enum import Enum`导入。


```python
from enum import Enum

class Color(Enum):
    RED = 1
    GREEN = 2
```

请注意，`enum`成员的值可以是任何数据类型，例如`str`、`tuple`、`float`等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

`Enums`也可以使用[函数调用语法][enum-functional-example]来创建。

```python
from enum import Enum

Animal = Enum('Animal', 'ANT BEE CAT DOG')
list(Animal)
#=> [<Animal.ANT: 1>, <Animal.BEE: 2>, <Animal.CAT: 3>, <Animal.DOG: 4>]

Animal.ANT.value
#=> 1
```

当把相同的值赋给`enum`中的两个成员时，后赋值的成员会成为前一个成员的别名。不允许为`enum`的两个不同成员使用相同的名称。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>
```

可以使用标准的`for member in`语法遍历枚举的成员：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)

# __members__.items() helps you to loop through alias as well
for member in Color.__members__.items():
    print(member)
#=> ('RED', <Color.RED: 1>)
#=> ('GREEN', <Color.GREEN: 2>)
#=> ('ALIAS_OF_RED', <Color.RED: 1>)
```

`Enum`成员可以使用[`is`（身份运算符）][identity-keyword]或`is not`进行比较。`==`或`!=`（相等运算符）的作用相同：


```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

要分配整数值，[`auto()`函数][enum-auto-docs]从`1`开始，并自动设置后续值。

```python
class Shape(Enum):
    CIRCLE = auto()
    SQUARE = auto()
    OVAL = auto()
```

要禁止别名（_防止不同名称具有重复值_），可以使用[类装饰器][class-decorator][`@enum.unique`][enum-unique-decorator]装饰器。

```python
@enum.unique
class Shape(Enum):
    CIRCLE = 1
    SQUARE = 2
    TRIANGLE = 1
#=> ValueError: duplicate values found in <enum 'Shape'>: TRIANGLE -> CIRCLE
```

要使用给定值访问`enum`成员，可以使用这样的写法：`<EnumName>(<value>)`。

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```

通过使用任意混入类或数据类型对`Enum`类进行子类化，可以编写自定义的[受限`Enum`][restricted-enums]。例如：


```python
class StrEnum(str, Enum):
    pass
```

仅当`enum`**不**定义任何成员时，才允许对`Enum`进行子类化。
