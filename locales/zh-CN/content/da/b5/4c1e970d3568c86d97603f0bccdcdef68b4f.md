# Break, Continue

在使用循环或迭代控制结构时，`break` 和 `continue` 关键字可以帮助控制程序的流程。
`break` 关键字会跳出循环所在的上下文，进入外层作用域，从而终止循环。
`continue` 关键字会跳过当前迭代中剩下的部分，让循环上下文从下一次迭代的开头重新开始。
虽然并不常见，但也可以在关键字后面加上一个数字，用来控制要跳出几层上下文，或者跳过几层继续下一次迭代。

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

在上面的例子中，`continue` 执行了五（5）次，但在第六（6）次迭代时执行了 `break`，使代码退出了循环。
