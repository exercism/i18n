# 说明

你所在的公司想减少碳足迹，因此希望你写一个程序，来计算他们各种电器的功率和运行成本。

## 1. 获取额外小时数

你的雇主有一个程序，用来计算运行不同电器所需的时间。
目前，时间以小时为单位存储。
你的雇主在累加这些小时数时，发现时间长度不正确。
他们希望你在时间数据上再加上 3 个额外的小时。
他们还想知道，把数据换算成“整天”（一天是 24 小时）之后，还剩多少“额外”小时。
需要换算的时间不一定是整天数。

实现一个函数 `get_extra_hours()`，它接受一个表示小时数的整数。
这个函数应做出相应的“额外小时”调整，然后 `return` 一个整数，表示需要从总数中减去多少小时，才能得到以“整天”为单位的时间。

```python
>>> get_extra_hours(25)
4
```

## 2. 获取 kW 值

你的雇主想以 kW 为单位了解不同电器的功率。
kW 代表千瓦（kilowatt），瓦特是功率的单位。
单位名称中的 kilo 是公制里的一个前缀，意思是 1000。
1 千瓦 == 1000 瓦。

实现一个函数 `get_kW_value()`，它接受一个表示瓦特数的整数。
这个函数应把瓦特数转换为千瓦，并 `return` 四舍五入到 1 位小数的结果。

```python
>>> get_kW_value(1150)
1.2
```

## 3. 获取 kWh 值

为了能计算电器的运行成本，你的雇主需要知道以 kWh 为单位的功率。
kWh 代表千瓦时（kilowatt-hour），其中小时是时间单位。
1 千瓦时 == 1000 瓦使用 1 小时。
1 小时由 60 分钟组成，1 分钟由 60 秒组成。
1 小时等于 3600 秒。
要计算 kWh 值，你必须先把瓦特换算成 kW，然后把结果除以 3600 并向下取整。

实现一个函数 `get_kWh_value()`，它接受一个表示瓦特数的整数。
这个函数应 `return` 一个整数形式的千瓦时值。

```python
>>> get_kWh_value(5000000)
1
```

## 4. 获取效率

电器并非 100% 高效。
因此，你的雇主希望你计算电器的_效率_。
要得到效率，你必须把功率因数（_一个 0 到 100 之间的浮点数_）除以 100。

实现一个函数 `get_efficiency()`，它接受一个表示功率因数的浮点数。
这个函数应把计算出的效率作为浮点数 `return`。

```python
>>> get_efficiency(80)
0.8
```

## 5. 获取成本

你的雇主想知道电器的运行成本。
电器的运行成本就是用掉的功率乘以每 kWh 的成本。
用掉的功率是给定功率除以计算出的效率。

实现一个函数 `get_cost(<watts>,<power_factor>,<price>)`，它接受一个表示瓦特数的整数、一个表示功率因数的浮点数，以及一个表示每 kWh 成本的浮点数。
这个函数应把电器的运行成本作为浮点数 `return`。

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
