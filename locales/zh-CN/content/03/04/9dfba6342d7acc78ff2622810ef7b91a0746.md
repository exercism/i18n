# 说明

在这个练习中，你将编写一些代码来帮助 Betty's Bike Shop，一家销售自行车和配件的网店。
你有三个任务，目标是在网站上正确显示自行车和配件的价格。

## 1. 导出`pence_to_pounds`函数

你的同事已经写好了这个模块的骨架，也就是尚未完成的函数`pence_to_pounds`和`pounds_to_string`。
不过，他们忘记导出`pence_to_pounds`函数，所以目前其他模块和测试套件都看不到它。

导出`pence_to_pounds`函数。

## 2. 把便士换算成英镑

目前，价格以整数个*便士*存储（这家自行车店位于英国）。
在网站上，我们希望以*英镑*显示价格，其中 1.00 英镑等于 100 便士。
你的第一个任务是实现`pence_to_pounds`函数，它接收一个以`Int`表示的便士金额，并把它转换成等值的英镑，结果为`Float`。
你还应该为这个函数添加类型注解。

```gleam
pence_to_pounds(106)
// -> 1.06
```

## 3. 把价格格式化，以便在网站上显示

由于 Betty's 的自行车以英镑出售，价格显示时应该带上符号“£”。
因此，你的第二个任务是实现`pounds_to_string`函数，它接收一个以`Float`表示的英镑金额，并返回显示为`String`的价格，前面加上英镑符号。

在使用`gleam/float`和`gleam/string`模块之前，你应该先导入它们。

你还应该为`pounds_to_string`定义类型注解。

```gleam
pounds_to_string(1.06)
// -> "£1.06"
```
