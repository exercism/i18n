# 简介

在 Go 中，函数是一等值。
这意味着你能对函数做的事情，和你能对其他所有值做的事情一样：把函数赋值给变量、把它作为实参传给其他函数，甚至从其他函数中返回函数。

下面我们创建了两个函数`engGreeting`和`espGreeting`，并把它们赋值给变量`greeting`：

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

函数值让我们不仅能用数据、还能用行为来参数化函数。
在下面的例子中，我们通过`greetingFunc`形参把行为传给`dialog`函数：

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// =>
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

函数类型的变量如果未初始化，它的值就是`nil`。
因此，调用值为`nil`的函数会引发 panic。

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

函数值可以与`nil`比较。
这有助于避免程序发生不必要的 panic。

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 函数类型

之所以能够使用函数值，要归功于 Go 中的函数类型。
函数类型表示这样一组函数：它们具有相同的形参类型序列和相同的返回值类型序列。
可以在函数类型之上声明用户定义的类型。
例如，前面例子中的`dialog`函数可以这样修改：

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 匿名函数

一等函数支持带来的另一个强大工具是匿名函数。
匿名函数在使用处定义，`func`关键字后面不跟名字。
这类函数可以访问外层函数中的变量。

例如：

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := range N {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

调用`fib`会声明变量`n1`和`n2`，并返回一个匿名函数，而这个匿名函数每次被调用时，又会改变这些变量的值。
匿名函数的第 N 次调用返回斐波那契数列中从 0 开始的第 N 个数。这个匿名内部函数可以访问外层函数`fib`的局部变量（`n1`和`n2`）。
这是让函数值在多次调用之间保持状态的好方法。
我们称这个匿名函数是变量`n1`和`n2`的闭包。[闭包][closure]在编程中被广泛使用，你可能也会看到其他语言支持它。

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
