# 范围

[范围][range]表示两个值之间的区间。
支持范围的最常见类型是`Int`、`Char`和`String`。
它们可以用于许多事情，例如快速创建集合、截取字符串、检查某个值是否在范围内，以及迭代。
它们使用范围运算符`..`或`...`创建（分别表示包含和不包含）。

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

有两个范围运算符的原因是为了创建包含或不包含末尾值的范围，例如在处理从零开始的下标时，这会很有用。

范围也可以使用`Range`初始化方法创建。

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Crystal 中使用范围运算符`..`或`...`创建范围，并且想要在范围上调用方法时，需要用括号把范围括起来。
这是因为如果不加括号，方法就会在范围运算符的第二个参数上被调用。

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 获取子字符串

想要截取字符串时，可以使用范围运算符获取子字符串。
也就是说，用子字符串的起始下标和结束下标创建一个范围。

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

也可以使用负数下标从字符串末尾获取子字符串。

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 范围方法

范围确实有一组可用于操作它们的方法。
例如，这些方法可以用来求范围中所有值的和，或者检查范围是否包含某个值。

| 方法 | 描述 | 示例 |
|------|------|------|
| [`sum`][sum] | 返回范围中所有值的和 | `(1..5).sum # => 15` |
| [`size`][size] | 返回范围的大小 | `(1..5).size # => 5` |
| [`includes?`][indludes] | 如果范围包含给定值则返回`true`，否则返回`false` | `(1..5).includes?(3) # => true` |

## 无终点和无起点范围

范围可以没有终点，也可以没有起点。
无终点范围或无起点范围的起点或终点值为`nil`，但在定义范围时可以省略`nil`。

例如，当你想要从开头或到末尾截取字符串时，使用无起点范围和无终点范围会很有用。

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
如果没有用在集合上，又不谨慎使用，无终点范围可能会导致无限序列。
~~~~

## 字符范围

字符可以用于范围，让你获取两个字符之间的字符区间。
例如，当你想要获取字母表时，这会很方便。

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## 字符串范围

字符串也可以用于范围，让你获取两个字符串之间的字符串区间。
但是，当字符串范围中使用多个字符时，它的行为与`Char`略有不同。
在进行更复杂的字符串范围操作时，它的行为可能会变得令人困惑，所以要谨慎。

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```

## 范围中的自定义对象

~~~~exercism/advanced
Crystal 允许你在范围中使用自定义对象。
要求是该对象实现以下内容：

- 包含`Comparable`模块
- `succ`方法
- `<=>`方法

这些方法使得范围可以迭代该对象并比较范围内的对象。

```crystal
class Foo
  include Comparable(Foo)

  getter value

  def initialize(@value : Int32)
  end

  def succ
    Foo.new(value + 1)
  end

  def <=>(other : Foo)
 value <=> other.value
  end
end

Foo.new(1)..Foo.new(5)
# => #<Foo:0x7f3552bebe70 @value=1>, #<Foo:0x7f3552bebe50 @value=2>, #<Foo:0x7f3552bebe40 @value=3>, #<Foo:0x7f3552bebe30 @value=4>, #<Foo:0x7f3552bebe20 @value=5>
```
