# 说明

艾伦正在做一款游戏，玩家要在游戏里和外星人作战。
她刚刚学习了面向对象编程（OOP），迫不及待地想利用`classes`为她的程序带来的好处。

令艾伦高兴的是，你主动提出帮忙，于是她交给你一项任务：编写玩家要对抗的那些外星人。


## 1. 创建`Alien`类

定义`Alien`类，它的构造函数接受两个`int`参数`x`和`y`，并把它们分别存入成员变量`x_coordinate`和`y_coordinate`。
每个外星人一开始的生命值都是`3`，所以成员变量`health`也要初始化。

`health`应该是一个私有成员变量。
为了让程序的其他部分能读取生命值信息，艾伦希望有一个`public`的`get_health()`方法，返回`int`。

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

现在，每个外星人都应该能在内部记录自己的位置和生命值。

## 2. `hit`函数

艾伦希望 Alien 的`class`有一个`hit`方法，调用时把外星人对象的生命值减少`1`。
这样，她只要调用`some_alien_instance.hit()`就行了，不必手动修改外星人的生命值。
确保生命值不会降到零以下。
该函数应返回`true`。
艾伦想在之后加入护盾，届时如果护盾开着，就会报告`false`。

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. `is_alive`函数

你意识到，如果生命值不断下降，迟早会降到`0`。
最好加一个`is_alive`方法，让艾伦能快速调用，检查外星人是不是……嗯……还活着。😉
`some_alien_instance.is_alive()`应返回布尔值。

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. `teleport`函数

在艾伦的游戏里，外星人能够传送！
你需要写一个`teleport`方法，接受`x_new`和`y_new`两个值，并相应地改变外星人的坐标。
目前，该函数应返回`true`。
艾伦想在之后的关卡里加入能阻止传送的炸弹，届时传送失败就会报告`false`。

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. `collision_detection`函数

既然外星人可能被什么东西撞到，它们就得能检测出这种碰撞何时可能发生。
艾伦需要知道两个外星人是否占据相同的坐标。
`collision_detection()`函数接受另一个外星人对象作为实参，并返回`bool`。

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
