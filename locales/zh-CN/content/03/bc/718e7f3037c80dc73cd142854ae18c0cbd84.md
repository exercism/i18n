# 简介

我们在`Vectors`概念中看到，向量可以用在条件表达式里，得到一个逻辑向量。这样的结果又能传给`all()`和`any()`这类函数。

```R
v <- c(4, 7, 10)
v >= 6
#> [1] FALSE  TRUE  TRUE
all(v > 6)
#> [1] FALSE    # not all elements match this condition
any(v > 6)
#> [1] TRUE     # at least one element matches
```

这项技术的威力远不止于此。

## 向量的子集

可以用一个下标，或者一个下标向量，取出向量中选定的元素：

```R
v <- 5:10
v
#> [1]  5  6  7  8  9 10
v[3] 
#> [1] 7
v[c(2, 4)]
#> [1] 6 8
```

也可以用一个逻辑向量过滤原向量，返回与`TRUE`相对应的那部分元素：

```R
v <- 1:3
bools <- c(FALSE, TRUE, TRUE)
v[bools]
#> [1] 2 3
```

在此基础上，再用条件表达式生成这个布尔向量，只是往前迈了一小步：

```R
bools <- v >= 2
bools
#> [1] FALSE  TRUE  TRUE

v[bools]
#> [1] 2 3

# simpler form
v[v >= 2]
#> [1] 2 3
```

## 查找下标

`which()`函数接收一个布尔实参，返回结果为`TRUE`的下标向量。

```R
v
#> [1] 2 7 9

v[v > 5]  # returns values
#> [1]  7  9

which(v > 5) # returns indices
#> [1] 2 3
```

## 检查某个元素是否存在

前面的几节讲的都是如何找出符合某个条件的元素。

如果你只是想知道向量里是否包含某个特定的元素，可以用`%in%`运算符。

```R
3 %in% 1:5
#> [1] TRUE
7 %in% 1:5
#> [1] FALSE
```

它的功能和下面这段代码完全一样，但用起来方便得多：

```R
v <- 1:5
length(v[v == 3]) > 0
#> [1] TRUE
```
