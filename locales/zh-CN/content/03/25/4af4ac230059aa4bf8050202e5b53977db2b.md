# 简介

## 基础

[Lua](https://lua.org) 是一门简单却强大、高效、轻量的可嵌入脚本语言。它由 Roberto Ierusalimschy、Waldemar Celes 和 Luiz Henrique de Figueiredo 组成的团队在巴西的 [PUC-RIO](https://www.puc-rio.br/) 设计、实现并维护，从 1993 年一直延续至今。

### 注释

Lua 中的单行注释以 `--` 开头，多行注释以 `--[[` 开头，以 `]]` 结尾。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

### 变量

Lua 中有三种变量：全局变量、局部变量和表字段。为了简单起见，这里只介绍局部变量。默认情况下所有变量都是全局的，所以我们必须用关键字`local`把变量声明为局部变量。
```lua
local x
```

使用`=`运算符可以把值赋给变量。
```lua
local x = 1
```

`local`变量的作用域仅限于声明它的代码块。代码块可以是控制结构的体、函数的体，也可以是声明该变量的文件或字符串。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

### 函数

函数使用关键字`function`声明，而且和变量一样，默认是全局的。一个函数定义包含名称、形参列表和函数体。遇到关键字`return`时函数就会结束，并返回其后列出的所有值。如果没有写`return`，函数会返回`nil`。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

### 表

表是 Lua 中唯一的数据结构机制，功能非常强大。它们用来表示数组、集合、对象、模块等等。本质上，Lua 中的表就是关联数组。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

这只是下一节需要的一点点背景知识。后面我们会详细地回到这个话题。

### 模块

模块是存放在 `.lua` 源文件中的一组代码。模块导出的所有内容都存放在一个表中，并在文件末尾返回这个表。所以这个表基本上起到了一种命名空间的作用。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

然后可以通过函数`require`把这个模块加载到另一个文件中，它会返回那个表。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

看到`say.hello`时，我们会想到“模块`say`中的函数`hello`”。但是，如果我们知道`say-hello.lua`返回的是一个表，再回头看表那一节，就会发现在 Lua 中这个表达式表示“以字符串`hello`为键对表`say`做索引”。

虽然模块返回表是一种好做法，但返回其他任何类型也同样可行，比如函数。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
