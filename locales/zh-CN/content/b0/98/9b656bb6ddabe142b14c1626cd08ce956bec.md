# 简介

Julia 中的`String`是有序的字符序列。正如手册所指出的：“当然，真正的麻烦在于追问什么是字符。”

这些复杂之处大部分会在`Chars`概念里更详细地展开，这里先简要看看：

- Julia 中的所有字符串都是 Unicode。
- 恰好也是 ASCII 的字符串（英文的 A 到 Z 大小写字母、数字以及少量标点符号）处理起来_很简单_。
- 世界上大多数其他文字系统_也可以_处理，但需要更小心。

## 字符串字面量

一般来说，字符串用双引号`" "`括起来。
单引号`' '`只用于`Chars`。

也可以使用三引号`""" """`，这样字符串里就能直接使用`"`，无需转义。
更重要的是，多行字符串里不需要的额外缩进会被去掉。

```julia-repl
julia> """
       Multiline
       String
       """
"Multiline\nString\n"
```

### 转义字符

和从 C 开始的多数语言一样，Julia 使用反斜杠`\`进行转义：

1. 输入不可打印的字符，例如上例中的换行符`\n`。
2. 保护那些本来会有特殊含义的字符，例如`\$`（见下文）。

## 下标

原则上，字符串可以完全像向量一样用下标访问：

```julia-repl
julia> s[1], s[5]
('J', 'a')
```

对于像 "Julia" 这样的 ASCII 字符串，这显然行得通，但这样一来就忽略了世界上大多数语言。

来看看《贝奥武夫》里的一个字符，这部作品用古英语写成，距今约 1500 年。

"Hrōðgār" 显然是 7 个字符，但并非全都是 ASCII。

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> isascii(king)
false

# collect() converts to a Char vector:
julia> collect(king)
7-element Vector{Char}:
 'H': ASCII/Unicode U+0048 (category Lu: Letter, uppercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
 'ō': Unicode U+014D (category Ll: Letter, lowercase)
 'ð': Unicode U+00F0 (category Ll: Letter, lowercase)
 'g': ASCII/Unicode U+0067 (category Ll: Letter, lowercase)
 'ā': Unicode U+0101 (category Ll: Letter, lowercase)
 'r': ASCII/Unicode U+0072 (category Ll: Letter, lowercase)
```

这样给字符串做下标，一开始很顺利，但到某个地方就会出问题：

```julia-repl
julia> king[3]
'ō': Unicode U+014D (category Ll: Letter, lowercase)

julia> king[4]
ERROR: StringIndexError: invalid index [4], valid nearby indices [3]=>'ō', [5]=>'ð'
```

问题在于，这种下标方式数的是_字节_，而对非 ASCII 字符串来说，字节和字符并不是 1:1 的关系。
一个 Unicode/UTF-8 字符最多可能需要 4 个字节来表示，`Chars`概念会进一步探讨这一点。

## 构建字符串

### 拼接

很多语言用`+`作为字符串拼接运算符，但 Julia 不是。
至少它的错误信息很有帮助。

```julia-repl
julia> "s1 " + "s2"
ERROR: MethodError: no method matching +(::String, ::String)
The function `+` exists, but no method is defined for this combination of argument types.
String concatenation is performed with * 

julia> "s1 " * "s2"
"s1 s2"
```

`string()`函数可以拼接任意数量的字符串。

```julia-repl
julia> string("lots ", "of ", "bits")
"lots of bits"
```

`join()`函数也能做到，而且它还能接收一个字符串向量，用给定的分隔符把它们拼接起来（默认为`""`）。

```julia-repl
julia> join(["lots", "of", "bits"], "_")
"lots_of_bits"
```

注意，字符串是不可变的，拼接过程涉及复制。
因此，在循环里反复拼接效率很低，更好的做法是把片段收集到一个向量里，最后再全部拼接起来。

### 重复

很简单：

```julia-repl
julia> repeat("Abc", 5)
"AbcAbcAbcAbcAbc"
```

### 插值

很多语言都有把计算出的值插入字符串的方法，不过对于哪种语法最好，分歧极大。

在 Julia 中，插值的值前面要加`$`。

```julia-repl
julia> myvar = 42
42

julia> "myvar evaluates to $myvar"
"myvar evaluates to 42"

julia> r = 5.3
5.3

julia> "A circle of radius $r has area $(π * r^2)"
"A circle of radius 5.3 has area 88.24733763933729"
```

省略括号会产生歧义时，括号是必须的；而对于后面紧跟空白字符的单个标识符，括号则可有可无。

要在字符串里包含 $，就把它转义为`\$`。

注意一个局限：目前插值不支持格式化，比如指定显示几位小数。

### `@sprintf()`

为了更精细地控制字符串的组装，Julia 从 C（以及后来的一些语言，维基百科列出了大约 30 种）借鉴了`sprintf`函数。

在 Julia 中，它是在`Printf`模块里以`macro`的形式实现的，因此有`@`前缀。

```julia-repl
julia> using Printf

julia> r = 5.3
5.3

julia> @sprintf("A circle of radius %.1f has area %.2f", r, π * r^2)
"A circle of radius 5.3 has area 88.25"
```

## 字符串函数

为简单起见，本节主要介绍返回新字符串、不改变输入的函数。
许多函数都有一个带`!`后缀的对应版本，会就地修改输入。

### 长度

一个字符串有多长？
有时这取决于你怎么数。

最简单的情况是 ASCII 字符串，每个字符占 1 个字节。

```julia-repl
julia> string_asc = "Julia"
"Julia"

julia> length(string_asc)
5

julia> sizeof(string_asc)
5
```

`length()`函数返回_字符_的数量，`sizeof()`函数返回_字节_的数量。

换成其他字符集时，这个区别就变得重要了：

```julia-repl
julia> king = "Hrōðgār"
"Hrōðgār"

julia> length(king)
7

julia> sizeof(king)
10
```

### 拆分

编程中常见的操作，是把一个长字符串按一个或多个字符组成的分隔符拆成若干部分。

最通用的做法是用`split()`函数。
分隔符默认为（任意）空白字符，也可以指定别的分隔符。

```julia-repl
julia> split("my little string")
3-element Vector{SubString{String}}:
 "my"
 "little"
 "string"

julia> split("My_snake_case_string", "_")
4-element Vector{SubString{String}}:
 "My"
 "snake"
 "case"
 "string"
```

这些例子把字符串拆成更小的_字符串_。
而把字符串拆成_字符_是另一种操作。

### 查找与替换

字符串里是否包含指定的子串？
奇怪的是，有两个函数可以测试这一点：`occursin()`和`contains()`的区别只在于实参的顺序。

```julia-repl
julia> needle = "Julia"
"Julia"

julia> haystack = "Python, Julia and R"
"Python, Julia and R"

julia> occursin(needle, haystack)
true

julia> contains(haystack, needle)
true
```

要更具体地知道位置：

```julia-repl
julia> startswith(haystack, "Python")
true

julia> endswith(haystack, "Python")
false
```

要得到子串的起始和结束下标，我们有几个函数：

- `findfirst()`
- `findlast()`
- `findprev()`
- `findnext()`

```julia-repl
julia> findfirst(needle, haystack)
9:13
```

要替换子串，就用`x => y`语法列出各项改动。

```julia-repl
julia> replace("abc", "a"=>"b", "b"=>"c", "c"=>"a")
"bca"
```

从 Julia 1.7 起，`replace`函数可以接受任意数量的改动，并保证在替换过程中没有任何字符会被改动两次。

`x => y`语法叫做`pair`，这是 Julia 中一种重要的类型，`Dicts and Pairs`概念里有更详细的介绍。

### 空白字符

我们经常需要去掉字符串开头和（或）结尾的空白字符。

用于此目的的函数有`lstrip()`（左）、`rstrip()`（右）、`strip()`（两端）。

```julia-repl
julia> strip("\n\t  useful_bit\n\n")
"useful_bit"
```

### 更改大小写

这些函数的名字基本上一看就懂：

```julia-repl
julia> s = repeat("aBcD ", 5)
"aBcD aBcD aBcD aBcD aBcD "

julia> uppercase(s)
"ABCD ABCD ABCD ABCD ABCD "

julia> lowercase(s)
"abcd abcd abcd abcd abcd "

julia> titlecase(s)  # Initial letter of each word uppercase
"Abcd Abcd Abcd Abcd Abcd "
```
