# 说明

在这个练习中，你将编写一些代码，帮助你为购买一辆车做好准备。

你需要完成三项任务：一项是判断你是否需要驾照，一项是帮你在两辆车之间做选择，还有一项是估算一辆二手车的合理价格。

## 1. 判断你是否需要驾照

有些类型的车辆需要驾照才能驾驶。
假设只有 `'car'` 和 `'truck'` 这两种类型需要驾照，其他所有类型都可以在没有驾照的情况下驾驶。

实现 `needsLicense(kind)` 函数，它接受车辆的类型，并返回一个布尔值，表示这种车辆是否需要驾照。

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. 在两辆备选车辆之间做选择

你评估了当前可选的车辆。
你把范围缩小到了两个选项，但需要有人帮你做最终决定。
为此，请实现 `chooseVehicle(option1, option2)` 函数，它接受两辆车作为实参，并返回一个决定，其中包含按字典顺序排在前面的那个选项。

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. 估算一辆二手车的价格

既然你已经做出了决定，你想确保在经销商那里能以公道的价格买到车。
由于你打算买一辆二手车，价格就取决于这辆车的车龄。
做个粗略估算：如果车龄不到 3 年，价格就是它全新时原价的 80%。
如果车龄超过 10 年，价格就是原价的 50%。
如果车龄至少 3 年但不超过 10 年，价格就是原价的 70%。

实现 `calculateResellPrice(originalPrice, age)` 函数，用 `if`、`else if` 和 `else` 来应用这套逻辑（如果你想多加练习，也可以用别的方式）。
它接受原价和车龄作为实参，并返回该车在经销商处的估算价格。

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
