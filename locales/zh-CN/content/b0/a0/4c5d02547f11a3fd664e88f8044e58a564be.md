# 关于

## JSON

[JSON][json]（JavaScript Object Notation）是一种人类可读的数据与文件格式，常用于交换数据，尤其是 Web 应用。因此，它在 Elm 语言中占有特殊地位也就不足为奇了。

Elm 提供了核心模块 [`Json.Decode`][decode] 和 [`Json.Encode`][encode]，用来解析和写入 JSON 数据。JSON 解码器是一种*声明*预期数据类型以及数据应映射到哪种数据结构的方式。

如果你来自动态类型语言，解码器乍看之下往往显得繁琐或过于死板。虽然它们确实冗长，至少在 Elm 中是这样，但它们是一个很有价值的工具，能明确描述程序对传入数据的预期，而且[并不比动态类型表达力更差][dynamic-types-not-more-open]。

让我们从这些模块中导入一些别名和类型：

```elm
import Json.Decode as Decode exposing (Decoder, Error)
import Json.Encode as Encode exposing (Value)
```

使用 `Decode.decodeString : Decoder a -> String -> Result Error a`，传入一个解码器和一个 JSON 字符串，如果字符串符合解码器的规范，就会成功，否则失败。定义解码器时无法查看原始 JSON 数据，如果来自命令式语言，可能会觉得不太习惯。

## 基本数据类型解码器

JSON 只有少数几种核心数据类型：

- 字符串：用双引号编码，如 `"hello world"`
- 布尔值：`true` 或 `false`
- 数字：例如 `34` 或 `0.12`
- 空值：表示没有数据，即 `null`

这些类型各自对应一个 `Decode` 函数：

```elm
Decode.decodeString Decode.string """\"hello\""""
    --> Ok "hello"

Decode.decodeString Decode.string """null"""
    --> Err ...

Decode.decodeString Decode.bool """true"""
    --> Ok True

Decode.decodeString Decode.bool """0"""
    --> Err ...

Decode.decodeString Decode.int """12"""
    --> Ok 12

Decode.decodeString Decode.float """3.14"""
    --> Ok 3.14

Decode.decodeString (Decode.null AnyValue) """null"""
    --> Ok AnyValue

Decode.decodeString (Decode.null AnyValue) """true"""
    --> Err ...
```

注意，`Decode.null` 要求传入一个任意值作为参数（可以是 `()`、`Nothing`，或任何适合你的程序的值），让你自行决定如何在程序中表示 `null`。

## 组合解码器

JSON 还定义了两种用于收集核心数据类型的数据结构：

- 数组：其他数据类型的集合 `[0, null, "none", []]`
- 对象：键值对的集合 `{"id": 1, "is_admin": false, "more_info": {}}`

`Decode` 也提供了解码这些结构的函数：

```elm
Decode.decodeString (Decode.list Decode.int) """[1, 2, 3]"""
    --> Ok [1, 2, 3]

Decode.decodeString (Decode.list Decode.int) """[1, 2, 3, "not an int"]"""
    --> Err ...

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": 71 }"""
    --> Ok (Dict.fromList [("key1", 17), ("key2", 71)])

Decode.decodeString (Decode.dict Decode.int) """{ "key1": 17, "key2": "seventy-one" }"""
    --> Err ...
```

这两个函数 `Decode.list : Decoder a -> Decoder (List a)` 和 `Decode.dict : Decoder a -> Decoder (Dict String a)` 都期待一个解码器作为参数，该解码器预期会解码数据结构中的每一个元素。如果作为参数的解码器无法解码数组或对象值中的任何一个元素，整个解码器就会失败，这是一种常见模式。

把简单的解码器组合成更复杂的解码器，是这项技术的核心思想。我们将通过一个示例，介绍另外几个函数，用它们可以构建任意复杂的真实数据解码器。

## GeoJSON

为了练习组合基本解码器来解析复杂的 JSON 数据，让我们构建一些解码器，用来解析（一部分）GeoJSON 数据。[GeoJSON][geojson] 是一种专门的、基于 JSON 的数据格式，用于表示地理要素，比如位置、路径或区域，它们由 2D 或 3D 地理坐标以及其他属性来指定。

### 几何对象

GeoJSON 几何对象是一个包含 `type` 字段（值为字符串，有 7 种可能的取值）和 `coordinates` 字段（包含地理坐标，其结构取决于类型）的对象。例如，

```json
{
  "type": "Point",
  "coordinates": [127.831, 26.461]
}
```

或者

```json
{
  "type": "LineString",
  "coordinates": [
    [127.831, 26.461],
    [127.829, 26.465],
    [127.829, 26.469],
    [127.83, 26.47]
  ]
}
```

在 Elm 中，几何对象可以用以下类型表示：

```elm
type Geometry
  = Point (List Float)
  | LineString (List (List Float))
  | ...
```

要获取某个字段的值，可以使用 `Decode.field : String -> Decoder a -> Decoder a`，它会解码对象中指定键的值。

```elm
decodePointCoordinates : Decoder (List Float)
decodePointCoordinates =
    Decode.field "coordinates" (Decode.list Decode.float)

decodeLineStringCoordinates : Decoder (List (List Float))
decodeLineStringCoordinates =
    Decode.field "coordinates" (Decode.list (Decode.list Decode.float))
```

要转换解码器成功解析出的值，可以使用 `Decode.map : (a -> value) -> Decoder a -> Decoder value`，或它的任意一个同类函数，从 `Decode.map2  (a -> b -> value) -> Decoder a -> Decoder b -> Decoder value` 到 `Decode.map8`。

在这个例子中，我们想根据 `type` 字段的值决定使用哪个坐标解码器，这正是 `Decode.andThen : (a -> Decoder b) -> Decoder a -> Decoder b` 及其伙伴 `Decode.succeed : a -> Decoder a` 和 `Decode.fail : String -> Decoder a` 的用武之地。

```elm
decodeGeometry : Decoder Geometry
decodeGeometry =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                case value of
                    "Point" ->
                        decodePointCoordinates |> Decode.map Point

                    "LineString" ->
                        decodeLineStringCoordinates |> Decode.map LineString

                    _ ->
                        Decode.fail "Geometry not implemented yet, or invalid type value"
            )
```

这里要注意，我们本可以用 `Decode.andThen` 来校验坐标（检查坐标是否成对或成三元组出现，并检查坐标值在地理上是否合理）。

```elm
Decode.decodeString decodeGeometry """{"type": "Point", "coordinates": [127.831, 26.461]}"""
    --> Ok (Point [127.831, 26.461])

Decode.decodeString decodeGeometry """{"type": "LineString", "coordinates": [127.831, 26.461]}"""
    --> Err ...
```

### 要素对象

GeoJSON 要素对象表示某个在空间上有界的东西：它有一个 `type` 字段，值为 `"Feature"`；一个 `geometry` 字段，值为几何对象或 `null`；一个 `properties` 字段，值为任意 JSON 对象或 `null`；以及一个可选的 `id` 字段，值为 JSON 字符串或数字。

```json
{
  "type": "Feature",
  "geometry": null,
  "properties": null
}
```

或者

```json
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
```

我们先来处理 `id` 字段。如果它存在，就必须同时容纳字符串或数字，所以我们可以为这个值引入一个自定义类型，或者总是把它保存为字符串。

要在两个可能的解码器之间做出选择，可以使用 `Decode.oneOf : List (Decoder a) -> Decoder a`。

```elm
decodeFeatureId : Decoder String
decodeFeatureId =
    Decode.oneOf
        [ Decode.string
        , Decode.int |> Decode.map String.fromInt
        , Decode.float |> Decode.map String.fromFloat
        ]
        |> Decode.field "id"

Decode.decodeString decodeFeatureId """{"id": "seventeen"}"""
    --> Ok "seventeen"

Decode.decodeString decodeFeatureId """{"id": 17}"""
    --> Ok "17"

Decode.decodeString decodeFeatureId """{"type": "Point"}"""
    --> Er ...
```

要表示该字段是可选的，我们可以使用同样的技巧

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.oneOf
        [ decodeFeatureId |> Decode.map Just
        , Decode.succeed Nothing
        ]
```

但我们也可以改用 `Decode.maybe : Decoder a -> Decoder (Maybe a)`

```elm
decodeMaybeFeatureId : Decoder (Maybe String)
decodeMaybeFeatureId =
    Decode.maybe decodeFeatureId

Decode.decodeString decodeMaybeFeatureId """{"id": 17}"""
    --> Ok (Just "17")

Decode.decodeString decodeMaybeFeatureId """{"type": "Point"}"""
    --> Ok Nothing
```

注意，`decodeMaybeFeatureId`（或任何用 `Decode.maybe` 包装的解码器）总会成功，因为它总能回退到 `Ok Nothing`，不过使用它的解码器仍可能失败

```elm
Decode.decodeString (Decode.list decodeMaybeFeatureId) """{"id": 17}"""
    --> Err ...
```

接下来，我们把注意力放在 `geometry` 字段上，它可以是几何对象，也可以是 `null`。我们本可以再次使用 `Decode.oneOf`，但有一个更好的选择：`Decode.nullable : Decoder a -> Decoder (Maybe a)`。

```elm
decodeFeatureGeometry : Decoder (Maybe Geometry)
decodeFeatureGeometry =
    Decode.nullable decodeGeometry
        |> Decode.field "geometry"

Decode.decodeString decodeFeatureGeometry """{"geometry": {"type": "Point", "coordinates": [127.831, 26.461]}}"""
    --> Ok (Just (Point [127.831, 26.461]))

Decode.decodeString decodeFeatureGeometry """{"geometry": null}"""
    --> Ok Nothing

Decode.decodeString decodeFeatureGeometry """{"geometry": {}}"""
    --> Err ...
```

`Decode.maybe` 和 `Decode.nullable` 的签名相同，但行为不同，因为 `Decode.nullable` 只有在遇到特定的 JSON 值 `null` 时才会得到 `OK Nothing` 的结果。

最后，`properties` 字段可以包含任意 JSON 对象或 `null`，这正适合用 `Decode.value : Decoder Value` 来处理。

```elm
decodeProperties : Decoder (Maybe (Dict String Value))
decodeProperties =
    Decode.nullable (Decode.dict Decode.value)
        |> Decode.field "properties"


Decode.decodeString decodeProperties """{"properties": null}"""
    --> Ok Nothing

Decode.decodeString decodeProperties """{"properties": {"country": "Japan"}}"""
    --> Ok (Just (Dict.fromList [("country", <internals>)]))

Decode.decodeString decodeProperties """{"properties": 17}"""
    --> Err ...
```

注意，`Value` 是一种不透明类型，这意味着你无法轻松查看它的内容。要使用它，你可以为它写一个解码器，再用 `Decode.decodeValue : Decoder a -> Value -> Result Error a` 运行它；或者通过端口直接把它发送给 JavaScript。

现在我们可以解析要素对象了：

```elm
type alias Feature =
    { id : Maybe String
    , geometry : Maybe Geometry
    , properties : Maybe (Dict String Value)
    }

decodeFeature : Decoder Feature
decodeFeature =
    Decode.field "type" Decode.string
        |> Decode.andThen
            (\value ->
                if value /= "Feature" then
                    Decode.fail "not a Feature"

                else
                    Decode.map3 Feature
                        decodeMaybeFeatureId
                        decodeFeatureGeometry
                        decodeProperties
            )

Decode.decodeString decodeFeature """{"type": "Feature", "geometry": null, "properties": null}"""
    --> Ok { geometry = Nothing, id = Nothing, properties = Nothing }

"""
{
  "type": "Feature",
  "id": "0157",
  "geometry": {
    "type": "Point",
    "coordinates": [127.831, 26.461]
  },
  "properties": {
    "country": "Japan"
  }
}
"""
  |> Decode.decodeString decodeFeature
    --> Ok { geometry = Just (Point [127.831,26.461]), id = Just "0157", properties = Just (Dict.fromList [("country",<internals>)]) }
```

## JSON 编码器

编码器让你可以使用 `Encode.encode : Int -> Value -> String` 函数，把 Elm 值写成合法的 JSON。第一个参数指定最终结果中的缩进量，第二个参数是要写入的 JSON 值。

`Value` 既可以从 `Decode.value` 获得，也可以由某个编码器生成：

```elm
Encode.encode 0 (Encode.string "hello")
    --> "hello"

Encode.encode 0 (Encode.bool True)
    --> "true"

Encode.encode 0 (Encode.int 12)
    --> "12"

Encode.encode 0 (Encode.float 3.14)
    --> "3.14"

Encode.encode 0 Encode.null
    --> "null"

Encode.encode 0 (Encode.list Encode.int [1, 2, 3])
    --> "[1,2,3]"

Encode.encode 4 (Encode.list Encode.int [1, 2, 3])
    --> "[\n    1,\n    2,\n    3\n]"

Encode.encode 0 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\"key1\":17,\"key2\":71}"

Encode.encode 4 (Encode.dict String.toLower Encode.int (Dict.fromList [("KEY1", 17), ("KEY2", 71)]))
    --> "{\n    \"key1\": 17,\n    \"key2\": 71\n}"
```

也可以用 `Encode.object : List ( String, Value ) -> Value`

```elm
Encode.object
    [ ( "key1", Encode.int 17 )
    , ( "key2", Encode.int 71 )
    ]
    |> Encode.encode 0
    --> "{\"key1\":17,\"key2\":71}"
```

让我们为前面定义的 GeoJSON 解码器定义编码器

```elm
encodeGeometry : Geometry -> Value
encodeGeometry geometry =
    case geometry of
        Point coord ->
            Encode.object
                [ ( "type", Encode.string "Point" )
                , ( "coordinates", Encode.list Encode.float coord )
                ]

        LineString coord ->
            Encode.object
                [ ( "type", Encode.string "LineString" )
                , ( "coordinates", Encode.list (Encode.list Encode.float) coord )
                ]

encodeFeature : Feature -> Value
encodeFeature feature =
    let
        maybeId =
            case feature.id of
                Nothing ->
                    []

                Just id ->
                    [ ( "id", Encode.string id ) ]
    in
    Encode.object
        (maybeId
            ++ [ ( "type", Encode.string "Feature" )
               , ( "geometry"
                 , case feature.geometry of
                    Nothing ->
                        Encode.null

                    Just geometry ->
                        encodeGeometry geometry
                 )
               , ( "properties"
                 , case feature.properties of
                    Nothing ->
                        Encode.null

                    Just dict ->
                        Encode.dict identity identity dict
                 )
               ]
        )
```

一般来说，检验解码器与编码器是否配对的一个好办法，是检查 `elmValue |> encoder |> decoder == elmValue` 是否成立。

## 还有什么？

我们并没有覆盖 `Json` 模块中的每一个函数。没有提到的内容还包括：把数组转成 `Array`、把对象转成 `List (String, a)` 的解码器，用于含一个或多个元素的数组的解码器，用于嵌套 JSON 对象中特定字段或数组中特定元素的解码器，如何解码递归结构，以及 `Error` 的各种变体及如何显示它们。

其他常用的包还有 [`Json.Decode.Pipeline`][pipeline]，它为复杂的 JSON 结构引入了便捷的流程；以及 [`Json.Decode.Extra`][extra]，它提供了更多的解码器、编码器和辅助函数。
