# 简介

## `while`循环

只要满足某个条件，`while`循环就能重复执行代码。
它的写法是：先写 `while`关键字，后面跟一个用圆括号括起来的条件，再跟一个用大括号括起来的代码块，里面是循环的*循环体*。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript 也有 `do-while`循环。
这种循环在执行完循环体之后才检查条件。
当条件取决于循环体中算出的结果时，这很有用。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

在循环体内部，你可以用 `break`关键字完全终止循环的执行。
与之相对，`continue`关键字只终止当前这一次迭代，然后继续下一次迭代。
借助 `continue`，你常常可以避免把循环体的大部分内容都包进一个 `if`语句里。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## `switch`语句

除了 `if`语句，JavaScript 还有 `switch`语句，用来按条件执行不同的逻辑。
当需要把一个变量与多个可能值做比较时，就用它。
比较时检查的是严格相等（`===`），参见[比较][concept-comparison]。
对于某个变量 `x`，JavaScript 中 `switch`语句的语法如下。

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

`default`分支是可选的，用来在其他选项都与变量不匹配时执行一些代码。

上面这些 `break`语句是必需的，因为在 JavaScript 中所有分支默认都会“贯穿”。
也就是说，如果没有 `break`语句，第一个匹配选项下面所有分支里的代码都会被执行，即使 `x` 并不匹配那些选项。
这种“默认贯穿”的行为是使用 `switch`时常见的一个坑。
在函数内部，你也可以用 `return`代替 `break`，从而避免这个问题。
