# 优先使用顶层常量

可以考虑把 `GIGASECOND` 这个数字提取成一个常量：

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

只有被`export`的函数、类和常量，才能从外部看到和访问。给[魔数](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29)起个名字通常是有意义的，这样可以提高可维护性。这些常量可以放在同一个文件里，而不会暴露给其他代码。
