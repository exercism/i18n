# 关于

Go 提供了基本的数字类型，可以用来表示整数或浮点数的集合。具体有哪些类型，取决于你需要多大的值，以及应用程序所运行的计算机架构（例如 32 位和 64 位）。

本概念将重点介绍两种数字类型：

- `int`：例如 `0`、`255`、`2147483647`。
  一个大小至少为 32 位的有符号整数（取值范围：-2147483648 到 2147483647）。
  但这取决于系统的架构。
  大多数现代计算机都是 64 位的，因此 `int` 的大小为 64 位（取值范围：-9223372036854775808 到 9223372036854775807）。

- `float64`：例如 `0.0`、`3.14`。
  包含所有 64 位浮点数组成的集合。

Go 支持标准的一组算术运算符：`+`、`-`、`*`、`/` 和 `%`（求余而非求模）。

在 Go 中，在不同类型之间赋值需要显式转换。
例如，要把 `int` 转换成 `float64`，需要这样做：

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
