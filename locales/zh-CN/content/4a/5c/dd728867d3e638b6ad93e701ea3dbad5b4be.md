# 解决问题的策略


正如这里的第一篇文章所说，**_解决问题是一项元技能_**。
我们常常发现，编程语言的语法或结构并不是解决挑战时最难的部分，真正难的是想清楚_要写什么代码_，或者_从哪里开始_。
培养一套策略和体系，把问题拆解成可以写成代码的步骤，是一项**非常值得**养成的技能。
下面是一些来自社区的文章、视频和书籍，可以帮你练就这项超级技能。


- Free Code Camp 有一篇不错的概览文章：[How to Think Like a Programmer - Lessons in Problem-Solving][free-code-camp-think-like-a-programmer]。
- fast.ai 的创始人 Jeremy Howard 对 [G. Polya's Problem Solving Techniques][g-polya-how-to-solve-it-summary] 做了很好的总结。
- [G. Polya's How To Solve It][g-polya-how-to-solve-it]（全书）最初写于 1945 年，用来指导如何攻克复杂的数学问题，如今对于一般意义上的解决问题，它依然是_绝佳_的建议。
- Kurtis Pykes 在 Towards Data Science 上写了一篇不错的[解决问题的实战教程][Kurtis Pykes: Hands-on Tutorial - How to Improve Your Problem-Solving Skills as A Programmer]。
- Free Code Camp 那篇文章里提到的 V. Anton Spraul 的 [Think Like a Programmer: An Introduction to Creative Problem Solving][v-anton-spraul-think-like-a-programmer]，对 Polya 为数学勾勒出的那些通用方法，给出了更现代、更贴近编程的阐释。
- [Felienne Hermans][felienne-hermans] 更关注人们是_如何_学会编程这门手艺的，以及这与一般意义上的学习有什么对应关系。
  她写了 [The Programmer's Brian][programmers-brain-free-online]，里面讲了更好地阅读代码、清晰地思考代码、写更好的代码，以及成为更好的代码协作者等策略。
  - 你可以[在这里][programmers-brain-manning]订购她这本书的纸质版。
  - 她在同一主题下还有两个有趣的视频：[How to Teach Programming (and other things)?][felienne-hermans-how-to-teach-programming] 和 [Programming is Writing is Programming ][felienne-hermans-programming-is-writing-is-programming]。
- No Starch Press 出版的 [Algorithmic Thinking (Daniel Zingaro)][daniel-zingaro-algorithmic-thinking] 和 [How to think like a programmer (Paul Vickers)][paul-vickers-how-to-think-like-a-programmer] 也讲了编程时如何解决问题。
- [Computational Thinking: A beginner's guide to problem-solving and programming (Karl Beecher)][beecher-computational-thinking] 和 [Computational Thinking for the Modern Problem-Solver (Riley and Hunt)][riley-and-hunt-computational-thinking] 也提供了思考问题、并把问题拆解成编程解法的策略。
- [From Computing to Computational Thinking (Paul S. Wang)][wang-computational-thinking] 稍偏通用和学术一些，但它提供的解决问题策略和结构不只适用于编程，而且不需要事先具备编程知识。

其中一些书也可以通过美国计算机协会（Association of Computing Machinery，ACM）的图书馆阅读。
会员（付费）相关信息见 [acm(dot)org][association-for-computing-machinery]。
