# 说明

你受雇于一家正在开发聊天机器人的公司，担任正则表达式专家。

它正处于非常初级的开发阶段。
你的任务是使用正则表达式来提升聊天机器人理解和生成自然语言的能力。

## 1. 检查有效的命令

聊天机器人不仅聪明，还是一位忠诚的助手。
要向聊天机器人提问，用户必须在命令的第一个位置说出“**Chatbot**”这个词。
关键字是大写还是小写都没有关系。
重要的是这个词出现的位置。

实现函数 `is_valid_command`，它帮助聊天机器人识别用户何时在发出命令。

```jq
"Chatbot, play a song from the 80's." | is_valid_command
# => true
"Hey Chatbot, where is the closest pharmacy?" | is_valid_command
# => false
"CHATBOT, do you have a solution for this challenge?" | is_valid_command
# => true
```

## 2. 移除加密的表情符号

聊天机器人很难理解人类如何用表情符号来表达情绪。
当聊天机器人收到用户消息时，每个表情符号都表示为字符串“emoji”后跟一个 _id 编号_。

实现 `remove_emoji` 方法，它接收一个字符串，并移除消息中所有的表情符号。

不含表情符号的行应当原样返回。
只需移除 emoji 字符串。
不要调整空白字符。

```jq
"I love playing videogames emoji3465 it's one of my hobbies" | remove_emoji
# => "I love playing videogames  it's one of my hobbies"
```

## 3. 检查有效的电话号码

在与聊天机器人交互的某个时刻，用户会提供一个电话号码。
聊天机器人只能拨打特定格式的号码。

实现 `check_phone_number` 函数。

如果号码有效，聊天机器人会回复一条消息，感谢用户并确认号码。
如果号码无效，聊天机器人会告知用户该电话号码无效。

期望的格式是`(+NN) NNN-NNN-NNN`，其中 N 是数字。

```jq
"chatbot my phone number is (+34) 659-771-594" | check_phone_number
# => "Thanks! Your phone number is OK."
"chatbot, call me at 659-771-594" | check_phone_number
# => "Oops, it seems like I can't reach out to 659-771-594."
```

## 4. 获取网站链接

聊天机器人是一款非常好奇的软件。
尽管它能上网搜索某个特定主题，但它还是喜欢问用户有哪些值得访问的网站，以便找到相关信息。

示例对话：

> **聊天机器人**：嘿，用户，我想学习用 JavaScript 编程。你知道有什么不错的网站可以让我学习吗？

> **用户**：我从 exercism.org 学到了很多，那里有很多很棒的内容。

实现函数 `get_domains`，它返回一个网站域名数组。

```jq
"I learned a lot from exercism.org and google.com" | get_domains
# => ["exercism.org", "google.com"]
```

## 5. 问候用户

有礼貌的聊天机器人会用名字称呼用户。
当用户自我介绍时，我们的聊天机器人会识别出他们的名字，并友好地打招呼。

编写函数 `nice_to_meet_you`。

如果输入字符串包含“My name is Someone.”，就捕获其中的名字，并返回字符串“Nice to meet you, Someone.”。

```jq
"My name is Jean-Luc" | nice_to_meet_you
# => "Nice to meet you, Jean-Luc"
```

## 6. 非常简单的 CSV 解析

抵挡不住“功能蔓延”的诱惑，我们要给聊天机器人添加一个 CSV 解析函数。

实现 `parse_csv` 函数，它接收一个字符串，并返回由解析结果字段组成的数组。
字段分隔符应该是“逗号加可选的空白”。

我们不必担心 CSV 格式的任何边界情况（例如字段中包含逗号）。

```jq
"first, second,third,   fourth" | parse_csv
# => ["first", "second", "third", "fourth"]
```
