# 简介

Kotlin 中的函数是一等公民。
这意味着函数可以存储在变量里、作为实参传递，甚至还能由其他函数返回。
例如，把一个函数赋值给变量`addOne`：

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

函数也可以返回另一个函数：

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

函数一旦完成赋值，就可以通过这个变量来调用它，就像调用普通的函数一样：
```kotlin
addOne(3)
// => 4
```

## 声明函数类型

可以使用`(parameter types) -> return type`这样的语法来声明变量或形参的类型。
例如，声明一个变量：

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

声明形参也是如此：

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Lambda 表达式

lambda 表达式是定义函数的一种更简短的方式。
它的写法形如`{ parameters -> body }`。
表达式会返回函数体中最后一条语句的值。
例如：

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

只要信息足够，Kotlin 就能推断出类型。
例如，上面的例子也可以写成：

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## 单形参 lambda 使用`it`

当表达式只有一个形参时，可以省略这个形参。
Kotlin 会在函数体中提供一个名为`it`的形参。
例如：

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 传递尾随 lambda

当函数的最后一个实参是 lambda 时，lambda 表达式直接写在括号的_后面_。
例如：

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
