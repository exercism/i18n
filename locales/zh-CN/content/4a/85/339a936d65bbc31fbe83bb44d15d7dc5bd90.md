# 学习

## 从零开始学习 Python

Python 是（*正如 [Wikipedia 所说][wikipython]*）一门*通用、高级的编程语言*。你可以用它编写各种各样的软件，从电子游戏到 HTTP 服务器，再到命令行工具，还有许许多多其他东西。它尤其擅长把不同的系统和程序“粘”在一起。

我们认为，最好的学习方式就是*玩*、就是*练*，动手做或大或小的编程项目，或者做些小题目，就像 exercism 上这些一样！
