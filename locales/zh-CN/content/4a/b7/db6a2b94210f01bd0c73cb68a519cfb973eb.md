# 简介

## 可区分联合

可区分联合类型表示固定数量的具名事例。可区分联合的每个值都恰好对应其中一个具名事例。

可区分联合使用 `type` 关键字定义，各个事例之间用竖线（`|`）分隔：

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

可区分联合的每个事例都可以选择性地关联数据，不同事例可以关联不同类型的数据。如果所有事例都没有关联数据，那么这种可区分联合就类似于其他语言通常所说的*枚举*（或 *enum*）。

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

要创建某个特定事例的值，可以引用它的名字（例如 `Success`）。由于事例名本质上就是构造函数，关联的数据可以像普通函数实参一样传入。如果另一个可区分联合定义了同名的事例，就需要使用它的完整名称（例如 `Result.Success`）。

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

可区分联合具有*结构相等性*，也就是说，同一事例且（可选）数据相同的两个值彼此等价。

虽然可以用 `if/elif/else` 表达式处理可区分联合，但推荐的做法是通过模式匹配，使用*标识符模式*：

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
