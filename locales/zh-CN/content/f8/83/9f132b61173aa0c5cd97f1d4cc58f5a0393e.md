# 简介

## 带标签的实参

有时一个函数接收很多实参，很难记住它们的先后顺序。为了提高可读性，Gleam 允许给实参加上标签。

要给一个实参加上标签，把标签名写在实参名前面，中间用一个空格隔开。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

调用带标签实参的函数时，实参可以按任意顺序给出。下面这几处对`replace`的调用都是等价的：

```gleam
replace(in: "🍔🍔🍔", each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

标签始终是可选的。即使一个函数的实参带有标签，调用时也仍然可以不写标签。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
