# Luhn 的概念

Luhn 是一种验证算法，它结合了文本和数值两方面的判定。Rust 的解答更偏好函数式方法。

## 概述

### 基本类型

- `&str` 和 `char`
  - 学生必须理解单个 `char` 与 `&str` 的区别，才能正确地排除或包含给定输入中的某些部分
- 整数
  - 要完成所需的数值验证，理解整数很重要
- 布尔值
  - 对于同一性判定和最终比较必不可少

### 迭代器特性

- 链式调用
  - 要以有序的方式解决这个问题，理解迭代器链在这里很重要。
- `map`、`filter`、turbofish，也可能用 `fold`
  - 把 map 和 filter 结合起来，为这类验证问题提供了一种基础的设计模式。用 `fold` 的解答也更加简洁。
  - 有些解答需要用 turbofish 告诉 Rust，你正在从链式表达式中创建哪种类型

## 示例解答 1

york 的[解答](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d)

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## 示例解答 2

规范解答

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
