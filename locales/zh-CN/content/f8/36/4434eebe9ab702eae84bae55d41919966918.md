# 说明

作为一名准魔术师，Elyse 需要练习一些基本功。她有一叠想要摆弄的牌。

为了让事情简单一点，她只使用数字 1 到 10 的牌，这样她的牌堆就可以用一个数字向量来表示。
某张牌的位置对应向量中的下标。

## 1. 从牌堆中取出一张牌

要取一张牌，请从给定的牌堆中返回下标`position`处的牌。

```R
stack <- c(1, 2, 4, 1)
position <- 3
get_item(stack, position)
# => 4
```

## 2. 交换牌堆中的一张牌

耍个花招，把下标`position`处的牌与提供的替换牌交换。返回调整后的牌堆。

```R
stack <- c(1, 2, 4, 1)
position <- 3
replacement_card <- 6
set_item(stack, position, replacement_card)
# => c(1, 2, 6, 1)
```

## 3. 在牌堆顶部插入一张牌

通过在牌堆顶部插入一张新牌，让一张牌出现。返回调整后的牌堆。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_top(stack, new_card)
# => c(5, 9, 7, 1, 8)
```

## 4. 从牌堆中移除一张牌

通过从牌堆中移除给定`position`处的牌，让一张牌消失。返回调整后的牌堆。

```R
stack <- c(3, 2, 6, 4, 8)
position <- 3
remove_item(stack, position)
# => c(3, 2, 4, 8)
```

## 5. 检查牌堆的大小

检查牌堆的大小是否等于`stack_size`。

```R
stack <- c(3, 2, 6, 4, 8)
stack_size <- 4
check_size_of_stack(stack, stack_size)
# => FALSE
```

## 6. 从牌堆顶部移除一张牌

通过移除牌堆顶部的牌，让一张牌消失。返回调整后的牌堆。

```R
stack <- c(3, 2, 6, 4, 8)
remove_item_from_top(stack)
# => c(3, 2, 6, 4)
```

## 7. 在牌堆底部插入一张牌

通过在牌堆底部插入一张新牌，让一张牌出现。返回调整后的牌堆。

```R
stack <- c(5, 9, 7, 1)
new_card <- 8
insert_item_at_bottom(stack, new_card)
# => c(8, 5, 9, 7, 1)
```

## 8. 从牌堆底部移除一张牌

通过移除牌堆底部的牌，让一张牌消失。返回调整后的牌堆。

```R
stack <- c(8, 5, 9, 7, 1)
remove_item_at_bottom(stack)
# => c(5, 9, 7, 1)
```
