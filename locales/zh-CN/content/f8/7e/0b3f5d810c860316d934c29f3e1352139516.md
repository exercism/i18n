# 简介

## 类

类是 PHP 中组织代码的基本单位。
表示某个事物或某个过程的行为的代码，可以归组为一个类。
按照约定，定义在类中的函数称为`methods`。

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

类使用`new`关键字来实例化，这会为类的实例分配内存，并调用该类的构造函数。
实例化后的类可以赋值给一个变量。
要调用类实例的方法，可以使用`->`访问运算符。

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

实例化的类可以使用特殊的`$this`变量来引用自身的实例。
类也可以有属性，它们相当于绑定在类对象实例上的变量。
这些属性既可以在内部引用，也可以在外部引用。

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
