# 说明

你的朋友 Li Mei 经营着一家果汁吧，售卖美味的混合果汁。
你是她店里的常客，发现自己可以让朋友的工作轻松一些。
你决定用自己的编程技能帮 Li Mei 分担工作。

## 1. 确定制作一杯果汁需要多长时间

Li Mei 喜欢提前告诉顾客，他们点的那杯果汁需要等多久。
但她很难记住确切的数字，因为不同果汁的制作时间各不相同：

| ID  | 饮品                | 时间 |
| --- | ------------------- | ---- |
| 1   | 纯草莓之悦          | 1    |
| 2   | 能量补充            | 3    |
| 3   | 绿色花园            | 3    |
| 4   | 热带岛屿            | 4    |
| 5   | 全有或全无          | 5    |
| 6   | 好心情              | 4    |
| 7   | 今日特饮            | 7    |
| 8   | 顾客之选            | 10   |

写一个函数 `time_to_make_juice`，它接收一个果汁的 ID（一个 32 位数字），并返回制作该果汁所需的时间，同样是一个 32 位数字。

```c
time_to_make_juice(2);
// => 3
```

## 2. 确定制作所有已点果汁需要多长时间

Li Mei 需要定期补充原料，所以她得提前知道，把当前所有订单都准备好需要多长时间。

为了帮你的朋友，写一个函数 `time_to_prepare`，它接收一个数组，里面是每个已点果汁的 ID，以及数组中果汁的数量。
这个函数应返回准备好数组中所有饮品所需的总时间。

你可以认为每个 ID、数组中 ID 的数量以及返回值都是 32 位数字。
结果始终能放进一个 32 位数字中。

```c
time_to_prepare({2, 3, 8}, 3);
// => 16
```

## 3. 补充青柠角库存

Li Mei 的很多作品里都有青柠角，要么作为配料，要么作为装饰的一部分。
所以每天早上开始上班时，她都要确保青柠角盒子是满的，够接下来一天使用。

实现函数 `limes_to_cut`，它接收 Li Mei 需要切出的青柠角数量、一个表示她手头整颗青柠储备的数组，以及数组中青柠的数量。

数组中的每颗青柠用一个字符来表示它的大小。
不同大小的青柠能给 Li Mei 带来数量不同的青柠角：

| 大小 | 青柠角 |
| ---- | ------ |
| 'S'  | 6      |
| 'M'  | 8      |
| 'L'  | 10     |

~~~~exercism/note
字符是一个 8 位数字，可以像任何 8 位数字那样使用：

| 字符 | 数值 |
|------|------|
| 'S'  | 83   |
| 'M'  | 77   |
| 'L'  | 76   |

它也可以直接用在指令中，效果等同于它的数值：

```x86asm
mov dl, 'S'
cmp cl, 'M'
```
~~~~

Li Mei 总是按照青柠在数组中出现的顺序来切，从第一颗开始。
她一直切到凑够所需的青柠角数量，或者切完所有青柠为止。

Li Mei 想提前知道她需要切多少颗青柠。

你可以认为所需的青柠角数量、数组中青柠的数量以及返回值都是 32 位数字。
结果始终能放进一个 32 位数字中。

```c
limes_to_cut(25, {'S', 'S', 'L', 'M', 'S'}, 5);
// => 4
```

## 4. 结束当班

Li Mei 总是工作到下午 3 点。
之后由她的员工 Dmitry 接班。
Li Mei 下班时，常常还有已点但尚未制作的饮品。
Dmitry 会接着制作剩下的果汁。

为了让交接更顺利，实现一个函数 `remaining_orders`，它接收：

- Li Mei 当班剩余的分钟数。
- 一个数组，里面是每个已点但尚未制作的果汁的 ID。

该函数应返回 Li Mei 在下班前制作完成的订单数量。

当班剩余时间始终大于 0。
待制作的果汁数组永远不会为空，而当班总会在数组结束之前结束。
另外，订单按它们在数组中出现的顺序制作。
如果 Li Mei 开始制作某杯果汁，她一定会把它做完，即使要多工作一会儿。

你可以认为剩余的分钟数、数组中的每个 ID 以及返回值都是 32 位数字。
结果始终能放进一个 32 位数字中。

```c
remaining_orders(5, {5, 5, 3});
// => 1
```
