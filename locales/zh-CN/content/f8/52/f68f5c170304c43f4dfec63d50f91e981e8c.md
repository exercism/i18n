# 介绍

JavaScript 是一门动态语言，支持面向对象、命令式和声明式（例如函数式编程）等多种风格。

## 变量

在 JavaScript 中，给名字赋值主要有几种方式，可以用变量，也可以用常量。
在 Exercism 上，变量始终使用 [camelCase][wiki-camel-case] 写法，常量使用 [SCREAMING_SNAKE_CASE][wiki-snake-case] 写法。
这方面没有官方规定可循，不同的公司和组织也各有自己的风格指南。
_你完全可以按自己喜欢的方式命名变量_。
按照练习中准备好的方式书写，好处是它们在网页界面和大多数 IDE 中会有不同的高亮显示。

JavaScript 中的变量可以使用 [`const`][mdn-const]、[`let`][mdn-let] 或 [`var`][mdn-var] 关键字来定义。

使用 `let` 或 `var` 时，变量在其生命周期内可以引用不同的值。
例如，用赋值运算符`=`可以多次定义和重新赋值 `myFirstVariable`：

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

与 `let` 和 `var` 不同，用 `const` 定义的变量只能赋值一次。
在 JavaScript 中，常量就是这样定义的。

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

## 函数声明

在 JavaScript 中，功能单元被封装在_函数_里，属于同一组的函数通常放在同一个文件中。
这些函数有形参（因此可以接收实参），并且可以用 `return` 关键字来_返回_一个值。
函数通过 `()` 语法来调用。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

在这个例子中，函数名是 `add`。
它有两个形参，`num1` 和 `num2`。
它返回一个值，也就是表达式 `num1 + num2` 的结果。

接着，函数 `add` 用两个实参来_调用_：`1` 和 `3`。
函数的结果，也就是返回值，是 `4`。

## 供其他文件使用

要让一个`function`、常量或变量在_其他文件_中可用，需要用 `export` 关键字将它们[导出][mdn-export]。
然后另一个文件可以用 `import` 关键字来[导入][mdn-import]这些内容。
这也被称为模块系统。

所有测试的工作方式就是一个很好的例子。
每个练习都至少有一个文件，例如 `lasagna.js`，其中包含_实现_。
_实现_会从该文件里 `export` 出去，从而可以在另一个文件中导入。
此外至少还有一个其他文件，例如 `lasagna.spec.js`，其中包含_测试_。
这个文件会 `import` 那些公开的（即被 `export` 的）实体，以便测试实现：

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
