# 关于

C# 中有三种浮点类型：`double`、`float` 和 `decimal`。最常用的类型是`double`，而`decimal`通常用于处理货币数据。`double` 写作 `2.45` 或 `2.45d`，`float` 写作 `2.45f`，而 decimal 写作 `2.45m`。

每种浮点类型都有自己的[精度、近似范围和大小][docs-microsoft.com-characteristics-of-the-floating-point-types]。

浮点类型之间的某些转换是[自动（隐式）][docs-microsoft.com-implicit-numeric-conversion]的，而另一些则是[手动（显式）][docs-microsoft.com-explicit-numeric-conversion]的。

```csharp
decimal account = 125m * (decimal)1.2f;
```

检查浮点类型的值是否相等时一定要小心，因为看起来相等的值实际上可能并不相同。更多信息请参阅[这篇文章][docs.microsoft.com_precision-in-comparisons]。

你可以在 [0.30000000000000004.com][0.30000000000000004.com] 找到关于浮点数的简短介绍。[Float Toy 页面][evanw.github.io-float-toy]用图形直观地展示了浮点数的各个比特位是如何转换成实际的浮点值的。
