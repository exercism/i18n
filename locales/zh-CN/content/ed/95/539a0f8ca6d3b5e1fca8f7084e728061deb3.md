# 说明

在这个练习中，你将编写一个泛型（还带点魔法！）的 TreasureChest，用来存放一些宝藏。

## 1. 定义 TreasureChest 类型

定义一个带两个字段的参数化类型`TreasureChest{T}`。

- `password`字段，类型为`String`，用于存储宝箱的密码。
- `treasure`字段，类型为`T`，用于存储宝藏。
这个值是泛型的，所以宝藏可以是任何东西。

```julia-repl
julia> chest = TreasureChest{String}("password", "gold")
TreasureChest{String}("password", "gold")
```



## 2. 定义 get_treasure() 函数

这个函数应该接受两个实参。

- 一个`String`（用于尝试密码）
- 一个`TreasureChest`类型

这个函数应该检查提供的密码尝试是否与`TreasureChest`中的`password`一致。

- 如果密码匹配，则返回宝藏。
- 如果密码不匹配，则返回`nothing`。

```julia-repl
julia> get_treasure("password", chest)
"gold"

julia> get_treasure("wrong", chest)
# no output

julia> isnothing(get_treasure("wrong", chest))
true
```

## 3. 定义 multiply_treasure() 函数

这个函数应该接受两个实参。

- 一个整数乘数`n`。
- 一个`TreasureChest{T}`类型。

该函数应该返回一个新的`TreasureChest{Vector{T}}`，其中：
- 密码与原宝箱相同
- 倍增后的宝藏为长度为`n`的`Vector{T}`，并且原宝藏重复`n`次。

```julia-repl
julia> multiply_treasure(3, chest)
TreasureChest{Vector{String}}("password", ["gold", "gold", "gold"])
```
