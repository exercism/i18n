# 说明补充

## Odin 专属说明

### 二叉树上的 zipper

上面的说明用多叉树（每个节点有多个子节点）来讲解 zipper，但 zipper 这个概念可以应用到任何类型的树，甚至列表。
在本次练习中，我们将使用二叉树（每个节点有两个子节点），这样就能专注于 zipper 的操作，而不必操心如何管理数量不固定的子节点。

说明中列出的操作已经更新，以匹配二叉树：

| 操作            | 说明                                                                       |
| --------------- | -------------------------------------------------------------------------- |
|`zip_from_tree`  | 从树中取出一个 zipper，焦点位于根节点。                                    |
|`zip_to_tree`    | 从 zipper 中取回树。                                                       |
| `zip_value`     | 获取焦点节点的值。                                                         |
| `zip_left`      | 把焦点移到焦点节点的左子节点，返回一个新的 zipper。                        |
| `zip_right`     | 把焦点移到焦点节点的右子节点，返回一个新的 zipper。                        |
| `zip_up`        | 把焦点移到焦点节点的父节点，返回一个新的 zipper。                          |
| `zip_set_value` | 设置焦点节点的值，返回一个新的 zipper。                                    |
| `zip_set_left`  | 设置焦点节点的左子树，返回一个新的 zipper。                                |
| `zip_set_right` | 设置焦点节点的右子树，返回一个新的 zipper。                                |

### 内存管理

在 Odin 中，你需要手动管理内存。
为了简化练习、让你专注于 zipper 的操作，分配给树节点和轨迹的内存会通过 arena 分配器自动管理。
你只需要按需用`new(Node)`和`new(Step)`分配内存；操作完树之后，测试会自动对 arena 调用`free_all()`。
在 Odin 中，对于任何周期性过程（比如游戏循环，或者一组请求与回复），这都是处理内存分配的惯用做法。

如果你想进一步了解 Odin 中的分配器，尤其是 arena 分配器，下面这些文档可能会让你感兴趣：[Odin 概览中的分配器章节][allocators-overview]、[理解临时分配器；理解 arena，作者 Karl Zylinski][allocators-zylinksi]，以及[线性/arena 分配器，作者 gingerBill][allocators-gingerbill]。
