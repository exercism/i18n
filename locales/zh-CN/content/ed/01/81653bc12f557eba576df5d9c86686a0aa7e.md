# 说明

你正在丛林里标出一条徒步路线。距离和观察记录都以序列的形式给出，所以两者都是迭代器。

这四个都放在`BUSH_WALK`类里。它们每一个都是迭代器，所以每个名字都以`!`结尾。

## 1. 标记

`markers!`接收一个以米为单位的间距和一个数量，给出每个标记点到起点的距离。

```sather
loop
   #OUT + BUSH_WALK::markers!(100, 3) + " ";
end;
-- 100 200 300
```

数量为零时，什么也不给出。

## 2. 直到路线结束

`until_end!`接收沿途的观察记录，一次给出一个，遇到`"end"`时停下。`"end"`本身不会被给出。

```sather
loop
   #OUT + BUSH_WALK::until_end!(|"gum", "wattle", "end", "banksia"|) + " ";
end;
-- gum wattle
```

如果没有`"end"`，就给出全部内容。

## 3. 只挑鸟类

`birds!`接收观察记录，只给出那些以大写字母开头的，这次调查就是这样记录鸟类的。

```sather
loop
   #OUT + BUSH_WALK::birds!(|"gum", "Emu", "wattle", "Galah"|) + " ";
end;
-- Emu Galah
```

## 4. 编号

`numbered!`接收观察记录，给出每一项，并在前面加上它的位置，从 1 开始计数。

```sather
loop
   #OUT + BUSH_WALK::numbered!(|"gum", "Emu"|) + " ";
end;
-- 1. gum 2. Emu
```
