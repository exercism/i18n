# 关于

[Clojure](http://clojure.org) 是一门面向 Java 虚拟机（JVM）的动态编程语言。作为一门通用语言来设计，Clojure 既有脚本语言那样平易近人的上手体验，又为多线程编程提供了健壮的基础设施。

Clojure 主要是一门函数式编程语言，拥有丰富的不可变、持久化[数据结构](http://clojure.org/data_structures)。

Clojure 是开源的，关于如何为这门语言做贡献的[信息可以在这里找到](http://clojure.org/contributing)。

Clojure 的创造者 Rich Hickey 想要一门用于函数式编程的现代 Lisp，它与成熟的 Java 平台共生，并为并发而设计；Clojure 由此诞生。

下面两句话很好地体现了 Clojure 的目标：

* _好的设计不在于制定宏大的计划，而在于把东西拆解开来。_
* _编程不在于敲键盘……而在于思考。_
