# 说明

在本练习中，你将编写代码来分析汽车工厂里装配线的生产情况。装配线的速度范围从 `0`（关闭）到 `10`（最大）。

在最低速度（`1`）下，每小时生产 `221` 辆汽车。产量随速度线性增长。因此当速度设为 `4` 时，每小时应生产 `4 * 221 = 884` 辆汽车。不过，速度越高，生产出故障汽车的可能性就越大，这些故障汽车随后必须报废。下表展示了速度如何影响成功率：

- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`和`10`：成功率 77%。

你有两个任务。

## 1. 计算每小时的生产率

实现一个方法，计算装配线每小时的生产率，并考虑它的成功率：

```rust
assembly_line::production_rate_per_hour(6)
// Returns: 1193.4
```

注意，返回的值是`f64`。

## 2. 计算每分钟生产的合格品数量

实现一个方法，计算每分钟生产多少辆合格汽车：

```rust
assembly_line::working_items_per_minute(6)
// Returns: 19
```

注意，返回的值是`u32`。
