# 说明

你的弦乐小组要举办一场演奏会，得有人来写节目单。

五个任务都写在 `PROGRAMME_NOTES` 类里。

## 1. 写出曲名和作曲者

先放曲名，然后是` by `，最后是作曲者。

```sather
PROGRAMME_NOTES::full_title("Nocturne", "Chopin")
-- => "Nocturne by Chopin"
```

## 2. 测量一行的长度

印刷工需要知道一行有多长。

```sather
PROGRAMME_NOTES::title_length("Nocturne")
-- => 8
```

## 3. 开头的几个字母

给定一个标题和一个数字，返回从开头数起的这么多个字母。

```sather
PROGRAMME_NOTES::opening_letters("Nocturne", 3)
-- => "Noc"
```

## 4. 结尾的几个字母

做法一样，只是从末尾开始数。

```sather
PROGRAMME_NOTES::closing_letters("Nocturne", 4)
-- => "urne"
```

## 5. 缩短过长的标题

放不下的标题会被截取前六个字母，后面再加上三个句点。

```sather
PROGRAMME_NOTES::short_title("Nocturne in E flat")
-- => "Noctur..."
```
