# 简介

在 Elixir 中，函数是一等公民。这意味着：

- 具名函数和匿名函数都可以赋值给变量。
- 具名函数和匿名函数可以像数据一样作为实参传递，也可以作为返回值传递。
- 匿名函数可以动态创建。

与具名函数不同，匿名函数没有可供使用的静态引用，只有赋值给变量或立即调用时才可用。

我们可能会用匿名函数来：

- 借助词法作用域（也称为闭包）隐藏数据。
- 在运行时动态创建函数。

匿名函数以保留字`fn`开头，实参与函数体之间用`->`分隔，并以`end`结尾。与具名函数一样，函数中的最后一个表达式会_隐式返回_给调用它的函数。

要调用函数引用，必须在引用变量和实参列表之间加上`.`：

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

你甚至可以使用简写捕获语法，让写法更简洁：

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
