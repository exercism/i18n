# 指令补充

## 提示

你需要实现`label`和`ohms`两个函数。你可以使用为`label`提供的签名，但别让它束缚你的创意。

这个练习处理的是文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，即一个字符数组。若要更高效地处理文本数据，可以使用`Text`类型。

作为本练习的可选扩展，你可以

- 阅读 Haskell 中的[字符串类型](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的依赖列表中添加`- text`。
- 以[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- 现在你可以编写`label :: Resistor -> Text`这样的代码，并以`T.pack`等形式引用`Data.Text`中的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档，

这部分完全可选。
