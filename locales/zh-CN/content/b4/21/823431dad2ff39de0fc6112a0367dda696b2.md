# 说明

你为一家小公司记账，每天的交易记录都是一行行杂乱无章的文本。你将使用正则表达式来验证金额、按标记符号提取数字，并标记出需要进一步查看的行。

## 1. 验证金额

格式正确的金额由一个`$`、一个或多个数字，以及*可选*的小数部分组成：小数部分是一个小数点加上恰好两位数字，例如`$100`或`$100.50`，但不是`$100.5`。定义`valid-amount?`，当*整个*字符串都是格式正确的金额时返回`t`。

```factor
"$100.50" valid-amount? .   ! => t
"$100"    valid-amount? .   ! => t
"$100.5"  valid-amount? .   ! => f
```

## 2. 提取美元金额

定义`dollar-amounts`，返回该行中紧跟在`$`后面的每一个数字（只包含数字，不含`$`），并保持原有顺序。

```factor
"spent $100 and $25 today" dollar-amounts .
! => { "100" "25" }
```

## 3. 提取百分比

定义`percentages`，返回每一个紧跟`%`的数字。

```factor
"up 5% then down 12%" percentages .
! => { "5" "12" }
```

## 4. 标记一行

定义`flagged?`，当一行中出现任意大小写组合的`refund`或`chargeback`时返回`t`。

```factor
"Issued a REFUND today" flagged? .   ! => t
"a normal sale"         flagged? .   ! => f
```
