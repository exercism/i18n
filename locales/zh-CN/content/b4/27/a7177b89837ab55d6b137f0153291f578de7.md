## 变量

变量是符号化的名字，指向值或容器。
变量名可以以一个叫做 sigil 的特殊字符开头，也可以不带它，后面再跟一个标识符。
sigil 后面还可以再跟一个 [twigil][twigils]。

带不同 sigil 的变量存放不同类型的数据结构。

```raku
my $scalar; # Assigned value will be stored as-is
my @array;  # Assigned value will be coerced into an array
my %hash;   # Assigned value will be coerced into a hash
my &code;   # Assigned value must be a code object
```

常见的 twigil 有 `^` 和 `:`，它们是代码块签名的简写形式。
`^` 用于位置参数。
`:` 用于命名参数。

```raku
{ $^a + $^b }; #`[same as] ->  $a,  $b { $a + $b }; # Called with (1, 2)
{ $:a + $:b }; #`[same as] -> :$a, :$b { $a + $b }; # Called with (a => 1, b => 2)
```

## 容器

容器让变量可以被修改。

用 `constant` 声明的变量，以及无 sigil 变量（在标识符前加 `\` 声明），都没有容器，而是直接指向值。

```raku
my $foo = 1;
$foo = 2;

constant $bar = 3;
my \baz = 4;

# The following will fail
$bar = 5;
baz  = 6;
```

## 类型

声明变量时可以加上类型约束。
类型约束还可以带强制转换：把可接受的类型作为参数传给想要的类型。

```raku
my Bool   $foo = True; # Booleans only.
my Bool() $bar = 0;    # Accepts type `Any`. Coerced to False.

my Str(Bool(Int)) $baz;
$baz = 1;   # "True"
$baz = "1"; # "1"
```

使用类型约束，是利用多重分派例程的一种方式。

```raku
multi foo (Int $bar) { say 'Type of arg to $bar is Int!' }
multi foo (Str $bar) { say 'Type of arg to $bar is Str!' }
```

Raku 中的类型也只是另一种对象。
声明`class`、`role`或`enum`都是创建自己的类型对象的方式。
例如，内置类型`Bool`就是用 enum 构建的：`enum Bool <False True>`。

你还可以借助`subset`关键字，基于其他类型创建简单的类型约束。
使用`where`子句可以进一步限制这个新类型。
`where`子句也可以用在签名中。

```raku
subset PositiveInt of Int where * > 0;

sub is-even (PositiveInt $n where  %% 2) { say "$n is even!" }
```
