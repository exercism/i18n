# 说明补充

## 寄存器

| 寄存器 | 用途     | 类型    | 描述                                                                                  |
| -------- | --------- | ------- | ------------------------------------------------------------------------------------- |
| `$a0`    | 输入     | 整数 | 数字                                                                                |
| `$v0`    | 输出     | 整数 | 分类（`1` = `perfect`，`2` = `abundant`，`3` = `deficient`，`-1` = `error`） |
| `$t0-9`  | 临时 | 任意     | 用于临时存储                                                            |
