# 简介

## 属性

C# 中的属性是类的一个成员，用于访问该类内部的数据。调用方可以设置或获取（get）数据。属性既可以是自动实现的，也可以带有后备字段。属性由一个 set 访问器和一个/或一个 get 访问器组成。在其他一些语言中，“修改器”大致相当于 set 访问器，“访问器”大致相当于 get 访问器，不过语法的构成完全不同。

设置属性时，可以对输入值进行验证、格式化或以其他方式处理，实际上，只要类中的代码能够访问，任何程序化操作都可以执行。

同样，获取属性时，也可以对数据进行计算或格式化，同样可以执行类所能使用的任何程序化操作。

属性和其他类成员一样拥有访问修饰符（`public`、`private` 等），但 set 访问器可以拥有独立于获取（get）访问器的访问级别，反之亦然。属性不必同时拥有两个访问器，它可以只有一个（get 或 set）。

表达属性的基本语法有两种形式：

### 基于字段或表达式的属性：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

### 自动实现的属性

```
public int MyProperty { get; private set; } = 42;
```

初始化是可选的。
