# 说明

你是船上的事务长，负责管理食品储藏室的库存。库存是一个哈希表，其中每个键是物品名称，值是该物品的库存数量。

## 1. 根据列表构建库存

定义`create-inventory`，接收一个物品名称序列，返回一个哈希表，将每个不重复的名称与其计数配对。

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. 添加更多物品

定义`add-items`，接收一个库存和一个物品序列，返回一个新的库存，其中每个列出的物品的计数都加了一。原有的库存不应被修改。

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. 减少计数

定义`decrement-items`，接收一个库存和一个物品序列，返回一个新的库存，其中每个列出的物品的计数都减了一。计数绝不能降到零以下，库存中原本没有的物品应被略过（不会插入负数条目）。

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. 完全移除一个物品

定义`remove-item`，接收一个库存和一个物品，返回一个移除了该物品的新库存。如果该物品不存在，返回一个未改动的副本。

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. 列出可用的物品

定义`list-inventory`，接收一个库存，返回一个由`{ name quantity }`对组成的数组，其中只包含数量大于零的物品，并按名称的字母顺序排序。

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
