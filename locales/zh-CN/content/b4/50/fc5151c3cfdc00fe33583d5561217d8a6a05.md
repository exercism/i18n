# Phix 中的数字

Phix 中有两种用来存放数字的数据类型：整数和 atom。
整数是有符号的，并且比机器字长少一位，因此在 64 位机器上（剧透警告）也不足以完成这个练习。
atom 能存放精度更高的整数，至少在 64 位下够用。你在 exercism.org 网站上在线运行时用的肯定是 64 位，在 CLI 里很可能也是，只要你装的就是这个版本。只要在终端控制台里运行 'p' 就知道了。

## 32 位机器

不过，即使在 32 位下，atom 的精度和大小仍然不足以完成这个练习。要绕过这一点，你可以改为返回一个字符串，它必须/可以精确无误，不含任何逗号或下划线，但在 64 位下你并不一定要这么做。你可以手动构造这样的字符串，也可以使用任意精度库，比如 [mpfr][mpfr]。

在使用 p2js 之前，桌面版 Phix 的 32 位版本对于充分测试仍然至关重要，因为 JavaScript 天生就是 32 位（或者更准确地说，53 位）的，即便在 64 位机器上运行的 64 位浏览器里也是如此。

Phix 的整数和 atom 能表示的精确范围，当然在[手册][manual]中有更详细的说明。
