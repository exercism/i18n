# 简介

AWK 是一门非常小的语言，只有少数几种基本数据类型。
这一课我们来看看数字和字符串。

## 数字

AWK 中的数字以双精度浮点数实现。
整数、浮点数与双精度数之间没有区别。

AWK 能识别八进制数字常量（以`0`开头）和十六进制数字常量（以`0x`或`0X`开头）。

### 数字运算

你可以使用[标准算术运算符][ops-arith]`+`、`-`、`*`、`/`、`%`。
幂运算符是`^`（由 POSIX 规定），不过也可以使用`**`。
还有一些[内置数字函数][funcs-numeric]，包括三角函数、随机数生成，以及把数字截断为 _x_ 与零之间最接近整数的`int(x)`。

没有按位_运算符_。
gawk 以函数的方式实现它们。
实参必须是非负数。

| 函数                | 运算                                      |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | 对实参按位与                   |
| `or(a, b [, ...])`  | 对实参按位或                   |
| `xor(a, b [, ...])` | 对实参按位异或                   |
| `lshift(v, count)`  | 将 _v_ 的值左移 _count_ 位  |
| `rshift(v, count)`  | 将 _v_ 的值右移 _count_ 位 |
| `compl(v, count)`   | 对 _v_ 按位取反                      |

## 字符串

AWK 字符串是字符序列。
用双引号指定字符串常量。

~~~~exercism/caution
GNU awk 允许字符串中包含 Unicode 字符，其他 awk 实现可能不允许。
比较`gawk`和`mawk`（另一个流行的 AWK 实现）：

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### 字符串运算

字符串运算只有一种：拼接。
拼接没有专门的运算符；
只要把两个字符串放在一起，就完成了拼接：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` 是**语句**，不是函数。
`print` 不需要括号。
~~~~

AWK 有大量[字符串操作函数][funcs-string]。
随着我们继续学习，会逐步深入了解它们。

## 在数字和字符串之间转换

数字和字符串之间没有显式的转换运算符。
AWK 会根据程序的上下文隐式完成转换。
这使得处理输入字段的值变得非常简单：AWK 通常会做你想要它做的事。

* `print x + y`会借助`+`的数值运算，把变量`x`和`y`的值转换为数字。
* `print x y`会借助拼接运算，把变量`x`和`y`的值转换为字符串。

如果你想显式地转换，`0 + x`会给出 _x_ 的数字表示，`"" x`会给出 _x_ 的字符串表示。

### 从字符串到数字

AWK 将字符串转换为数字的方式可能会让人困惑。
一个简单的理解方式是：AWK 从字符串开头开始读取“数字字符”，直到遇到“非数字”字符为止。
一些例子：

* `"2.5"`转换为数字`2.5`；
* `"1e3"`转换为数字`1000`（科学计数法）；
* `"456abc"`转换为数字`456`（因为`a`不是“数字”，转换就此停止）。
* `"abc789"`转换为数字`0`（字符串的**开头**没有数字）。

完整细节见[手册][str-to-num]。

## 判断变量的类型

[`typeof(var)`函数][func-typeof]以字符串形式返回类型。

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
输出
```none
42 string
43 number
```
