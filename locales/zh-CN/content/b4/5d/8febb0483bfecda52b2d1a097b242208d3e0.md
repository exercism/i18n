# 关于

集合是一种不可变且无序的、包含唯一值的数据结构。集合中的所有元素必须是同一类型。

`gleam/set`模块定义了`Set`类型，并提供了用于操作集合的函数。

你可以使用`set.to_list`和`set.from_list`在数组和集合之间相互转换。集合中元素的顺序是不保证的。

```gleam
set.from_list([2, 3, 3, 3, 1, 1, 2])
// -> set.from_list([1, 2, 3])

set.to_list(set.from_list([2, 3, 3, 3, 1, 1, 2]))
// -> [1, 2, 3]
```

你可以使用`set.new`、`set.insert`和`set.delete`创建和填充集合。

```gleam
set.new()
// -> set.from_list([])

let eighty_eight = set.from_list([88])

set.insert(eighty_eight, 88)
// -> set.from_list([88])

set.insert(eighty_eight, 89)
// -> set.from_list([88, 89])

set.delete(eighty_eight, 88)
// -> set.from_list([])

set.delete(eighty_eight, 89)
// -> set.from_list([88])
```

你可以使用`set.contains`和`set.size`函数查询集合的内容。

```gleam
set.contains(eighty_eight, 88)
// -> True

set.size(eighty_eight)
// -> 1
```

集合可以使用`set.union`和`set.intersect`进行合并。

```gleam
let a = set.from_list([1, 5, 10])
let b = set.from_list([1, 2, 3, 4, 5])

set.union(a, b)
// -> set.from_list([1, 2, 3, 4, 5, 10])

set.intersection(a, b)
// -> set.from_list([1, 5])
```

你可以过滤集合。

```gleam
let is_small = fn(n) { x <= 3 }

set.filter(b, is_small)
// -> set.from_list([1, 2, 3])
```
