# 补充说明

## 输出格式

把歌词输出为一个以空字符结尾的字符串。

## 寄存器

| 寄存器   | 用途         | 类型    | 说明                          |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入         | 整数    | 起始诗节                      |
| `$a1`    | 输入         | 整数    | 结束诗节                      |
| `$a2`    | 输入/输出    | 地址    | 以空字符结尾的输出字符串      |
| `$t0-9`  | 临时         | 任意    | 用于临时存储                  |
