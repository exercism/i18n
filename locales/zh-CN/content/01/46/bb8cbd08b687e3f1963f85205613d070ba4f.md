# 简介

条件分支是一种语句，它根据条件是`true`还是`false`，执行不同的代码。

`if`语句只有在条件为`true`时才会执行其中的代码。
Go 没有 truthy 或 falsy 的概念，所以条件必须是`bool`类型。
像`if mySlice { ... }`或`if 1 { ... }`这样的表达式会导致编译错误。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

用`else if`检查更多条件，如果都不匹配，就用`else`兜底。
条件会从上到下依次判断，只有第一个条件为 true 的分支才会运行。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if`语句还可以带一条简短的初始化语句。
这样声明的变量，其作用域仅限于整个`if`/`else`链内。

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
