# 函数

函数是 Cairo 的基础。

按照惯例，Cairo 的函数名和变量名使用**蛇形命名法**，也就是单词全部小写，并用下划线分隔。

下面是一个例子：

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

函数用`fn`定义，`fn`后面依次是函数名、用来放参数的括号（如果有参数的话），以及用大括号括起来的函数体。

调用函数时，写下函数名，后面加上那对括号。

只要都在作用域内，函数的定义顺序无关紧要。

## 形参

函数可以接收**形参**，也就是在函数签名中定义的变量。

调用函数时，你提供的是**实参**，也就是传给这些形参的值。

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

这里，`x`是一个类型为`felt252`的形参。

用`5`调用时，函数会打印“The value of x is: 5”。

多个参数之间用逗号分隔：

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

输出结果为：`The measurement is: 5h`。

## 语句和表达式

Cairo 函数由**语句**和**表达式**组成：

- **语句**执行操作，但不返回值。
例如，`let x = 3;`就是一条语句。
- **表达式**会求出一个值。
例如，`5 + 6`的求值结果是`11`。

用大括号括起来的代码块也是表达式，它的最后一个值会被返回：

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

这里，`y`被赋值为`4`。

## 返回值

函数可以返回值，用`->`语法指定返回类型。

默认情况下，函数返回最后一个表达式的值：

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

输出结果为：`The value of x is: 5`。

更复杂一些的情况：

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

输出结果为：`The value of x is: 6`。

注意不要在最后一个表达式的末尾加分号，否则这个表达式就变成了语句，函数返回的会是`()`（单元类型），而不是期望的值。
