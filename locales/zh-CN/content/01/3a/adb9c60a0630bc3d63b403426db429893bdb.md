# 关于

接口可以理解为类的签名，因为它描述了一个类的公有字段。类通过`implments`关键字_实现_一个`interface`。

它的语法与类非常相似，只是方法以签名的形式出现，没有方法体：

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

从接口实现的字段**必须**始终使用相同的可见性修饰符。例如，如果变量`a`在接口中是`public`，那么它的实现也必须是`public`。
