# 调试

你可以用 [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) 把消息附加到失败的测试上，就像这样：

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

测试失败时，附加的日志会是 `secondsInOneHour: 3600`。

有一点需要注意：顶层常量只会在测试开始运行之前求值一次，因此测试无法捕获它们的日志消息。例如：

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

在测试期间不会输出任何日志，因为与`secondsInOneHour`关联的 JavaScript 变量已经被求值为 3600。
