# 简介

## 字符串

F# 中的`string`是一个对象，它将不可变的文本表示为一系列 Unicode 字符（字母、数字、标点等），定义方式如下：

```fsharp
let fruit = "Apple"
```

要操作字符串，可以调用字符串的方法，也可以使用`String`模块的函数。字符串一旦创建，其值就永远无法改变。任何看似会修改字符串的方法或函数，实际上都会返回一个新的字符串。

拼接或格式化字符串有几种不同的方式。
* 可以使用`+`运算符进行拼接：
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* 可以使用`sprintf`函数来格式化文本：在格式文本中放置占位符（`%s`表示一个`string`），并将值作为实参传入：
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
