## 各个月份

首先登场的是 Functional February，我们在这个月探索函数式语言！我们刚把这个月的介绍视频做好，我非常期待深入其中。函数式语言非常有趣、好玩，还能让你学到很多东西。函数式语言有很多，但如果你不知道从哪里开始，我们特别推荐试试 Elixir、F# 或 Gleam。

接下来是 Mechanical March，我们要看看更偏系统编程的语言，比如 C++、Go 或 Nim。这类语言通常会编译成机器码，可能需要你操心内存管理，或者让你思考代码是怎么执行的。它们能让你更贴近计算机内部正在发生的事情。

Analytical April 我们聚焦更偏科学的语言。这里的两大主角是 Python 和 Julia，不过我们还有很棒的 R 轨道。显然，像 Python 这样的语言可以归入很多类别，但我们觉得，现在大多数非初学者学它，是看中了它作为数据科学技术的价值，所以把它放在这个月！

五月会很有意思，我们给它起名叫 Mindshifting May！我们重点介绍那些做法与众不同的语言。我们最喜欢的例子是 Prolog，它是一种相当独特的编程方式；此外我们还会看 Rust、TCL 和 Unison。Unison 是一门非常新的语言，它在分布式编程上另辟蹊径，让我们既兴奋又好奇。

进入六月，我们按照北半球的习惯来命名，叫它 Summer of Sexps。我们要探索基于表达式的语言，重点关注 Common Lisp 和 Clojure 这两条很棒的 Exercism 轨道！如果你从没试过 Lisp，这个月会让你觉得非常好玩。你不但不会害怕那些括号，反而会慢慢欣赏它们！

进入七月，我们来点老派的，叫 Jurassic July。我们探索古老的语言，那些为今天的编程打下基础的语言。想想 Fortran、COBOL、VB 和 C。如果你在编程方面算是新手，看到当年的编程是什么样子，可能会觉得既新奇又震惊！

八月里会有你们每个人都熟悉的语言，因为我们聚焦网站和 App 的开发。我们会看 JavaScript、Kotlin 和 Swift 这样的语言，也会看 Dart 这类用得没那么多的语言。我们还会看看 ABAP 这类用于非常特定用途的语言。

Slimline September 聚焦那些打字很少、却能做很多事的语言。就是那种人们可能用来玩代码高尔夫的语言！想想 Perl、AWK、JQ 和 Bash。这些语言第一次用的时候可能感觉有点高深，但只要你肯下功夫去学，它们就是提升生产力的超级利器，而且探索起来对大脑也很有趣！

第 10 个月是 Object Oriented October。我们探索那些高度重视面向对象编程的语言，比如 Ruby 和 C#，以及 Crystal、Pharo 这类不那么知名的语言。如果你一直想深入探索 OOP，这个月就是为你准备的！

最后一个主题月是 Nibbly November，专门献给最底层的语言，你会在其中操作比特和字节。我们重点关注两门语言：x86-assembly，你正在看这个视频所用硬件背后的语言；以及 WebAssembly，这个新秀能让你在任何网页浏览器里运行任何编程语言。这个月不会轻松，但达成时的满足感很可能是最大的！

最后就是 December Diversions。这些是我们没法归到别处的语言！比如 Groovy、Lua 和 Wren。把它当成一个自由发挥的月份，你可以任选一门语言，漂漂亮亮地给这一年收尾！
