# 说明

作为一名准魔术师，Elyse 需要练习一些基本功。她有一个牌堆，想要对它做些操作。

为了方便一些，她只用 1 到 10 这些牌，所以她的牌堆可以用一个数字向量表示。某张牌的位置对应向量中的下标。

## 1. 从牌堆中取出一张牌

要取出某张牌，就从给定的牌堆中返回下标为`position`的那张牌。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> get_item(stack, position)
4
```

## 2. 交换牌堆中的一张牌

施展一点手法，把下标为`position`的牌换成提供的替换牌。返回调整后的牌堆。

```julia-repl
julia> stack = [1, 2, 4, 1];
julia> position = 3;
julia> replacement_card = 6;
julia> set_item!(stack, position, replacement_card)
[1, 2, 6, 1]
```

## 3. 在牌堆顶部插入一张牌

通过在牌堆顶部插入一张新牌来变出一张牌。返回调整后的牌堆。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_top!(stack, new_card)
[5, 9, 7, 1, 8]
```

## 4. 从牌堆中移除一张牌

通过从牌堆中移除给定`position`处的牌来让一张牌消失。返回调整后的牌堆。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> position = 3;
julia> remove_item!(stack, position)
[3, 2, 4, 8]
```

## 5. 移除牌堆顶部的牌

通过移除牌堆顶部的牌来让一张牌消失。返回调整后的牌堆。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> remove_item_from_top!(stack)
[3, 2, 6, 4]
```

## 6. 在牌堆底部插入一张牌

通过在牌堆底部插入一张新牌来变出一张牌。返回调整后的牌堆。

```julia-repl
julia> stack = [5, 9, 7, 1];
julia> new_card = 8;
julia> insert_item_at_bottom!(stack, new_card)
[8, 5, 9, 7, 1]
```

## 7. 从牌堆底部移除一张牌

通过移除牌堆底部的牌来让一张牌消失。返回调整后的牌堆。

```julia-repl
julia> stack = [8, 5, 9, 7, 1];
julia> remove_item_at_bottom!(stack)
[5, 9, 7, 1]
```

## 8. 检查牌堆的大小

检查牌堆的大小是否等于`stack_size`。

```julia-repl
julia> stack = [3, 2, 6, 4, 8];
julia> stack_size = 4;
julia> check_size_of_stack(stack, stack_size)
false
```
