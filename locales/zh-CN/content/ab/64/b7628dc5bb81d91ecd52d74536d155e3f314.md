# 简介

在 JavaScript 中，`Array`类有很多强大的内置方法，可以用来转换数组。
相比用简单的 `for`循环或更直接的操作方式，这些方法能把一个数组转换成另一个数组，容易得多。

有些方法是[_纯函数_][pure-function-definition]，也就是说它们不会修改原数组，而是返回一个新数组。
但另一些方法会修改调用它们的那个数组，并且**不会**返回修改后的数组。

下面介绍一些最常用的数组转换方法。
可用方法的完整列表可以在[MDN 文档][array-methods]中找到。

### map（纯函数）

用一个作为实参传入的函数来转换每个元素，从而创建一个新数组。
这些回调函数通常写成[箭头函数][concept-arrow-functions]。

```javascript
let arr = [1, 2, 3, 4];

const newArr = arr.map((value) => value - 1);
console.log(newArr);
// => [0, 1, 2, 3]
console.log(arr);
// => [1, 2, 3, 4]
```

值得注意的是，结果数组的长度始终与原数组相同。

### filter（纯函数）

给定一个过滤函数（元素应保留时返回 true，应移除时返回 false），对当前数组进行过滤，创建一个新数组。

```javascript
let arr = [1, 2, 3, 4];

arr.filter((value) => value % 2 === 0);
// => [2, 4]
```

### reduce（纯函数）

用一个函数把数组归约为单个值，这个函数以_累加器_和数组的当前元素作为形参。
这个函数说明当前元素应该如何合并进累加器，并返回将在下一次迭代中使用的累加器。

```javascript
let arr = [1, 2, 3, 4];

// Get the sum of elements
arr.reduce((accumulator, currentValue) => accumulator + currentValue, 0);
// => 10

// Classify the numbers by whether they are odd or not
arr.reduce(
  (accumulator, currentValue) => {
    if (currentValue % 2 === 0) {
      accumulator.even.push(currentValue);
    } else {
      accumulator.odd.push(currentValue);
    }

    return accumulator;
  },
  { even: [], odd: [] },
);
// => { even: [2, 4], odd: [1, 3] }
```

### reverse

反转数组中的元素。

```javascript
const arr = [1, 2, 3, 4];

arr.reverse();
// => [4, 3, 2, 1]
```

这个方法会修改调用它的那个数组。

### slice（纯函数）

给定起始下标和结束下标，从调用它的数组中创建一个子数组。

结束下标处的元素不会被包含在内。
另外，所有形参都是可选的：
起始下标默认为`0`，结束下标默认为数组长度。

```javascript
const arr = [1, 2, 3, 4];

arr.slice(1, 2); // [2]
arr.slice(1); // [2, 3, 4]
// You can also use negative numbers, that represent the indexes
// starting from the end of the array
arr.slice(-2); // [3, 4]
```

### splice

移除、替换和/或添加数组元素。

它接收以下形参：

- 开始修改数组的那个元素的下标
- 要删除的元素个数
- 要插入数组的元素（可选）

`splice`返回被移除的元素。

```javascript
const arr = ['1', '2', '5', '6'];

// Insert an element at index 2
arr.splice(2, 0, '3');
console.log(arr);
// => ['1', '2', '3', '5', '6']

// Remove 2 elements, starting at index 3 and insert 2 elements
const removed = arr.splice(3, 2, '4', '5');
console.log(removed);
// => ['5', '6']
console.log(arr);
// => ['1', '2', '3', '4', '5']

// Remove 1 element at index 1
arr.splice(1, 1);
console.log(arr);
// => ['1', '3', '4', '5']
```

### sort

默认情况下，`sort`会先把数组元素转换成字符串，再按字符串比较（参见[比较概念][concept-comparison]）来排序。
排序是_原地_进行的，也就是说原数组会被修改。
`sort`还会返回这个被修改的数组，如果你想在它后面链式调用其他方法，这很方便。

```javascript
const arr = ['c', 'a', 'z', 'b'];
const result = arr.sort();
console.log(result);
// => ['a', 'b', 'c', 'z']
console.log(arr);
// => ['a', 'b', 'c', 'z']
```

要自定义排序行为，可以传入一个比较函数作为实参。
这个比较函数本身会以数组的两个元素作为实参被调用。
它需要返回以下内容：

- 如果第一个实参应排在第二个之前，返回一个负数
- 如果第一个实参应排在第二个之后，返回一个正数
- 如果两个元素的顺序应保持不变，返回`0`

例如，要对数字排序，可以使用下面的比较函数。

```javascript
const arr = [3, 1, 2, 10];
arr.sort((a, b) => a - b);
// => [1, 2, 3, 10]
// "a - b" is negative when b is greater than a, positive when
// a is greater than b and 0 when they are equal.
```
