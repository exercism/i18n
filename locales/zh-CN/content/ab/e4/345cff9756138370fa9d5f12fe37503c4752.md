# 附加说明

## 本 Track 专属说明

如果你想尝试点不一样的，也可以试试用`unfold`函数写一个解法。
你可能已经熟悉`foldLeft/Right`：把一个集合“映射”成其他东西（通常不是集合）。
`unfold`则是“反向”操作：把某个东西（通常不是集合）“映射”成集合。
所以`unfold`是函数式编程标准技能库中顺理成章的补充，也是其中的一部分。

这道练习可以看作适合`unfold`的一个场景：把一个`Int`“映射”成一个`String`（当然，它隐式地就是一个`Seq[Char]`）。

Scala 的集合库从 2.13 起就有了，例如[`List.unfold`][list]和`Iterator.unfold`。
它接收一个初始状态和一个函数，该函数返回下一个元素和下一个状态，或者返回`None`表示停止：

```scala
List.unfold(1234)(n => Option.when(n > 0)((n % 10, n / 10)))
// List(4, 3, 2, 1)
```

[list]: https://www.scala-lang.org/api/current/scala/collection/immutable/List$.html
