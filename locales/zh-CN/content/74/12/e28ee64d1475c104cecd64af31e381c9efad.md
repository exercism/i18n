# `for`循环简介

[for 循环](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)提供了一种机制，可以重复执行一组语句，直到满足某个条件为止。循环由四个部分组成：

```java
for (initialization; test; update) {
    body;
}
```

`initialization`为循环设置初始状态，并且在循环开始时只执行一次。通常它会声明并赋值一个变量，供测试表达式和更新语句使用。例如：

```java
int i = 1
```

`test`表达式用来判断循环是否应该结束。如果它的求值结果为 `true`，就会先执行循环体，再执行更新表达式。如果求值结果为 `false`，循环体和更新语句都不会执行，程序会从循环结束的括号之后继续往下执行。通常它会检查在初始化部分里赋值的那个变量。例如：

```java
i <= 10
```

执行完循环体之后，就会执行 `update`表达式。通常它会把循环变量自增或自减某个值。例如：

```java
i++
```

下面这个 `for`循环会打印出前四个平方数：

```java
for (int i = 1; i <= 4; i++) {
    System.out.println("square of " + i + " is " + i * i);
}
```

输出结果会是：

```text
square of 1 is 1
square of 2 is 4
square of 3 is 9
square of 4 is 16
```

如果要遍历集合中的每个元素，最好使用 `for-each`循环，不过用 `for`循环也可以做到：

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

相比 `for-each`循环，`for`循环确实有一些优势：

- 可以从你想要的下标开始或结束。
- 可以使用任何（布尔）终止条件。
- 可以通过自定义循环变量的自增方式来跳过某些元素。
- 可以通过倒着计数，从后往前处理集合。
- 可以在不涉及集合的场景中使用 `for`循环。
