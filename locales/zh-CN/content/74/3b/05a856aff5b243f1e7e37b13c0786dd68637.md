# 线程

## Tcl 特有的线程信息

你将用线程实现并行：把输入分成若干块，让运行在线程中的代码可以异步地检查这些块。

以下是一些关于 Tcl 线程的阅读材料：

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf)，
  选自 _Practical Programming in Tcl and Tk, 4th Ed._ 中的一章，
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * 注意，本章中写道“Most binary distributions of Tcl are not thread-enabled”。现在情况已经不同了：Tcl 发行版如今都带有线程支持（参考 [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md)）
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)，来自 Tcl 文档。
