# PaySwitch - 薪资转换器

## 问题陈述

一家名为 **Insure Everyone** 的公司用外币向员工支付工资。但由于法律规定，工资必须换算成当地货币。它的员工遍布世界各地。
Insure Everyone 的人力资源部门正在寻求一位有才华的开发者的帮助，来构建一个把每位员工的工资换算成其对应当地货币的程序。Insure Everyone 依赖外部 API 提供的汇率。

给定这个外部汇率 API，你需要编写一个函数，它接收 `source currency`、`salary`（以源货币计）以及员工的 `local currency`，并返回以本地货币计的工资。

## 约束

* 500 <= `salary` <= 10000
* `sourceCurrency`和`targetCurrency`是 [ISO 货币代码（字母）](https://en.wikipedia.org/wiki/ISO_4217#Active_codes)。测试输入中可能包含无效的货币代码。
* 返回汇率的精度测量到小数点后`5`位。
