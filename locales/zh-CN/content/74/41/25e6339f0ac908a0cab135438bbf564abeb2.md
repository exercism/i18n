# 说明

在本练习中，你将运用[围棋的规则](https://matmoore.github.io/learngo/)。规则本身已经写好，你只需应用它们，来更新 Game 并处理各种错误或违反规则的情况。

游戏的数据结构如下：

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

游戏中有 4 条规则：

- 每个点只能放一颗棋子（`oneStonePerPointRule`）
- 对方的棋子可以被吃掉！（`captureRule`）
- 不能把棋子下在会吃掉自己的位置（`libertyRule`）
- 同一个点不能下两次（`koRule`）

## 1. 应用规则

编写 `applyRules` 函数的内容。它接收一个初始的 `Game` 和一组规则，并在应用这些规则之后返回新的 `Game`。

`oneStonePerPointRule`、`libertyRule` 和 `koRule` 都会检查是否违反规则，可能会返回错误，因此它们的返回类型是 `Result String Game`。如果其中任何一条规则失败，就应返回原来的游戏，但要把 `error` 字段更新为相应的错误。

`captureRule` 不检查是否违反规则，因此不会失败（不过它可以返回一个改变了的 `Game`），所以它的返回类型是 `Game`。

如果所有规则都通过，就应保留各条规则对 `Game` 所做的更改，并切换玩家。我们提供了 `changePlayer` 函数来完成这件事。

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
