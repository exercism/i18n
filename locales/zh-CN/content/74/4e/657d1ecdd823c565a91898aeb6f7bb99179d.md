# 说明

在本练习中，你需要把经典游戏 Pac-Man 中的一些规则转化成 C++ 函数。

你要转化的有四条规则，它们都与游戏状态有关。

> 不用担心这些实参是怎么来的，只需专注于把实参组合起来，返回预期的结果。

## 1. 判断 Pac-Man 能否吃掉幽灵

定义`can_eat_ghost`函数，它接收两个实参（_Pac-Man 是否有处于激活状态的能量豆_和 _Pac-Man 是否碰到了幽灵_），并返回一个布尔值，表示 Pac-Man 能否吃掉幽灵。只有当 Pac-Man 有处于激活状态的能量豆并且碰到了幽灵时，函数才应返回 true。

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. 判断 Pac-Man 是否得分

定义`scored`函数，它接收两个实参（_Pac-Man 是否碰到了能量豆_和 _Pac-Man 是否碰到了豆子_），并返回一个布尔值，表示 Pac-Man 是否得分。如果 Pac-Man 碰到了能量豆或豆子，函数应返回 true。

```cpp
scored(true, true);
// => true
```

## 3. 判断 Pac-Man 是否输掉

定义`lost`函数，它接收两个实参（_Pac-Man 是否有处于激活状态的能量豆_和 _Pac-Man 是否碰到了幽灵_），并返回一个布尔值，表示 Pac-Man 是否输掉。如果 Pac-Man 碰到了幽灵并且没有处于激活状态的能量豆，函数应返回 true。

```cpp
lost(false, true);
// => true
```

## 4. 判断 Pac-Man 是否获胜

定义`won`函数，它接收三个实参（_Pac-Man 是否吃掉了所有豆子_、_Pac-Man 是否有处于激活状态的能量豆_，以及 _Pac-Man 是否碰到了幽灵_），并返回一个布尔值，表示 Pac-Man 是否获胜。如果 Pac-Man 吃掉了所有豆子，并且根据第 3 部分中定义的实参判断它没有输掉，函数应返回 true。

```cpp
won(false, true, false);
// => false
```
