# 关于

能够容纳零个或多个元素的数据结构叫做_集合_。**数组**是一种集合，它的大小/长度固定，而且所有元素都必须是同一类型。可以用下标把元素赋给数组，也可以用它从数组中取出元素。C# 数组从零开始计数，也就是说第一个元素的下标始终是 0：

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

数组也可以用一种简写方式来定义，这种写法既能创建数组，又能设置它的值。由于编译器此时能够判断数组会有多少个元素，所以可以省略长度：

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

可以调用数组实例的[方法][array-methods]或[属性][array-properties]来操作数组，也可以使用 [`Array`类][array-class]中定义的静态方法。

## 迭代

数组也是一种_集合_，这意味着你可以用 [`foreach`循环][foreach-statement]遍历它的_所有_值：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

也可以用 [`for`循环][for-statement]遍历数组：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

不过一般来说，`foreach`循环比 `for`循环更可取，原因如下：

- `foreach`循环保证会遍历_所有_值。而用 `for`循环时，很容易漏掉元素，比如因为差一错误。
- `foreach`循环更具_声明式_风格：代码传达的是你_想做什么_，而 `for`循环传达的则是你_想怎么做_。
- `foreach`循环万无一失，而 `for`循环很容易出现差一错误。
- `foreach`循环适用于所有集合类型，包括那些不支持用索引器访问元素的类型。

为了保证 `foreach`循环会遍历_所有_值，编译器不允许在 `foreach`循环内更新集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

相比 `foreach`循环，`for`循环确实有一些优势：

- 你可以从想要的下标开始，也可以在那里停止。
- 你可以使用任何（布尔）终止条件。
- 你可以通过自定义循环变量的自增方式来跳过元素。
- 你可以倒着计数，从后往前处理集合。
- 你也可以在不涉及集合的场景中使用 `for`循环。

相关内容：

- 你需要知道，C# 支持[多维数组][multi-dimensional-arrays]，比如 `int[,] arr = new int[10, 5]`，这非常有用。
- 你也应该知道，可以用 `Array.CreateInstance` 实例化 [`System.Array`][system-array-object] 类型的对象。这类对象用处不大，主要用于与 VB.NET 代码互操作。它们不能与标准数组（`T[]`）互换使用。它们可以有非零的下界。
