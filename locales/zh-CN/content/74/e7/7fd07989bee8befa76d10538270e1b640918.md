# HTTP 十亿美元之问

## 问题描述

你需要在一组给定的国家（国家数量为`N`）中，按净资产找出排名前`x`的亿万富翁。为此，你可以访问一个 API，它会按国家返回亿万富翁的详细信息。

## 限制条件

* 1 <= N <= 5
* 1 <= x <= 10

## 示例 1

输入

```
Countries: ["United States"]
Limit: 3
```

输出

```
["Elon Musk", "Jeff Bezos", "Bill Gates"]
```

## 示例 2

输入

```
Countries: ["China", "India"]
Limit: 5
```

输出

```
["Mukesh Ambani", "Gautam Adani & family", "Zhong Shanshan", "Zhang Yiming", "Ma Huateng"]
```

## 测试环境

* 连接亿万富翁 API 所需的 Client ID 和 Client Secret 已经在`tests/Config.toml`中提供给你。你可以用它们来初始化客户端。
* 使用`bal test`来运行并测试你的实现。
