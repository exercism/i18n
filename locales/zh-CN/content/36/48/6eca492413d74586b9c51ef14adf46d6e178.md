# 关于

`Maybe`类型是 Elm 语言中处理可选值的方案。因此，它出现在大量 Elm 核心函数的类型签名中，理解它至关重要。

## 定义与类型变量

`Maybe`类型的定义如下：

```elm
type Maybe a = Nothing | Just a
```

这在 Elm 术语中称为“自定义类型”定义。自定义类型会在本轨道的另一个概念中详细介绍，不过要专门理解`Maybe`并不需要它。`Maybe a`和`Just a`中的`a`表示一个类型变量，也就是说它可以是任意类型，比如`Int`、`Bool`或`String`。因此，`Maybe String`是一个可选地保存`String`的变量，而`Maybe Int`则可选地保存一个`Int`。

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

`Maybe`类型定义中的竖线`|`表示“或”。它表明该类型的一个值要么是`Nothing`，要么是类型为`a`的`Just`某个值。那么，假设那个人的姓名和年龄没有被填写，就会得到下面的结果。

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## 读取 Maybe 值的内容

读取`Maybe`值的内容通过“模式匹配”完成。模式匹配也会在另一个概念中详细介绍，所以这里我们只关注对`Maybe`进行模式匹配是如何工作的。

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

每次使用`Maybe`值时，Elm 编译器都会检查你的代码是否处理了所有可能情况，所以你绝不会写出只处理了`Just someValue`这一种情况的模式匹配。这起初可能有些烦人，但它正是 Elm 语言最强大的优势之一。它能避免数百个 bug，也让由编译器引导的重构成为一次无所畏惧、充满成就感的体验。

## 更多操作`Maybe`的函数

`Maybe`模块中还有许多有用的函数，可以用来操作`Maybe`类型。

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
