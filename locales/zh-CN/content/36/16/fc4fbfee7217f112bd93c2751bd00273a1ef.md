# 通用

- 确保你已经很好地掌握了如何创建和更新数组。
- Python 的[`lists`文档][python lists]会很有帮助。
- Python [教程中关于`lists`的部分][more on lists]也是个不错的资源。

## 1. 把我加进队列

- 用`if-else`语句可以帮你判断手上的是哪种票。
- 然后你就可以根据票的类型，用`append()`把这个人加到队列里。

## 2. 我的朋友们在哪儿

- 你需要在队列中找到这位朋友名字的`index()`。

## 3. 我能加入他们吗？

- 既然你已经知道了`index()`，就可以用`insert()`把这位朋友插到队列的那个位置。

## 4. 队列里的坏人

- 你已经知道了这个坏人的名字，所以可以用`remove()`把他从队列里删掉。

## 5. 同名的人

- 在这里，用`count()`统计`name`在队列中出现的次数，可能是个不错的思路。

## 6. 移除最后一个人

- 虽然你可以按名字用`remove()`移除那个人，但用`pop()`把他弹出可能会更快。

## 7. 给队列排序

- 别忘了，你需要避免改动队列而丢失它原有的顺序。
- 有了`copy()`之后，再用`sort()`排序应该就很直接了。
- 我们要的是_升序_排序，也就是_按 a 到 z 的字母顺序_。
