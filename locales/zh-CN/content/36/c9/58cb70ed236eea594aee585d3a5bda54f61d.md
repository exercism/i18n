# 简介

## 映射

映射指的是把函数应用到序列的每个元素上，从而产生一个新序列。

用 `mapcar` 函数可以轻松地对列表完成这件事。
假设有一个函数 `double`，它把实参乘以 `2`：

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

注意，第一个实参是要调用的函数。`#'` 是一种特殊的引用语法，用于指定函数。

`double` 先以第一个元素调用，然后以第二个元素调用，依此类推。
结果被收集到一个列表中，这个列表就是该表达式求值得到的值。

## 过滤

过滤是指从另一个序列创建新序列的过程：复制原序列中的元素，但排除其中某些元素。
至于把哪些元素纳入新序列，可以由谓词函数（求值为布尔值的函数）来决定，也可以由是否与某个特定对象相等来决定。

### 按谓词移除

`remove-if` 接受一个谓词函数和一个序列作为实参，返回一个序列，其中只包含那些谓词求值为假值的元素。
换句话说，它会“移除”序列中所有令谓词求值为真的元素。不过要注意，这个函数不会修改原序列！
它返回的是一个去掉了相应元素的新序列。如果谓词对所有值都为真，则返回一个空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### 移除特定元素

如果想从序列中移除某个特定的元素，可以使用 `remove`，它接受要移除的元素和一个序列。
序列中所有不等于该元素的值都会被返回。
注意：默认使用`eql`[通用相等谓词][concept-equality]来检查是否相等。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
