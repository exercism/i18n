# 说明

在这个练习里，你将和最好的朋友们一起玩一款名叫“Wizard and Warriors”的角色扮演游戏。
你是游戏主持人，负责让游戏世界在玩家面前鲜活起来。
其中一个关键环节，就是向玩家描述游戏内容：角色的状态是什么样，他们正在造访的城镇是什么样，等等。

你有五个任务，需要你向玩家描述游戏的各个部分。

## 1. 描述一个角色

每个角色都有自己的职业、等级和生命值，描述格式为：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`。
实现`GameMaster.describe`方法，它接受一个`Character`作为唯一的形参，并返回对该角色的描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

new GameMaster().describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 描述一个目的地

每个目的地都有一个名称和一定数量的居民，描述格式为：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`。
实现`GameMaster.describe`方法，它接受一个`Destination`作为唯一的形参，并返回对该目的地的描述。

```java
Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 描述出行方式

角色可以选用以下两种方式之一前往目的地：

- 步行，描述为：`"You're traveling to your destination by walking."`
- 骑马，描述为：`"You're traveling to your destination on horseback."`

实现`GameMaster.describe`方法，它接受一个`TravelMethod`作为唯一的形参，并返回对该出行方式的描述。

```java
new GameMaster().describe(TravelMethod.HORSEBACK);
// => "You're traveling to your destination on horseback."
```

## 4. 描述角色前往目的地的情形

当角色前往目的地时，这段描述由前面各条单独的描述组合而成：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`。
实现`GameMaster.describe`方法，它接受`Character`、`Destination`和`TravelMethod`作为形参，并返回相应的描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination, TravelMethod.HORSEBACK);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 描述角色在未指定出行方式时前往目的地的情形

大多数情况下，角色都是步行前往目的地的。
为了方便，玩家可以省略出行方式，这时就默认使用步行。
实现`GameMaster.describe`方法，它接受`Character`和`Destination`作为形参，并返回相应的描述。

```java
Character character = new Character();
character.setCharacterClass("Wizard");
character.setLevel(4);
character.setHitPoints(28);

Destination destination = new Destination();
destination.setName("Muros");
destination.setInhabitants(732);

new GameMaster().describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
