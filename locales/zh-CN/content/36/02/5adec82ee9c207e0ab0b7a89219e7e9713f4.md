# 说明补充

## 输出格式

把动作序列输出为以 null 结尾的字符串，用逗号和空格作为分隔符。

## 寄存器

| 寄存器 | 用途     | 类型 | 说明                          |
| ------ | -------- | ---- | ----------------------------- |
| `$a0`  | 输入     | 整数 | 1 到 31 之间的数字            |
| `$a1`  | 输入/输出 | 地址 | 以 null 结尾的输出字符串      |
| `$t0-9` | 临时    | 任意 | 用于临时存储                  |
