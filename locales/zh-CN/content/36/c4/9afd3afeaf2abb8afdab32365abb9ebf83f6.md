# 迭代器

迭代器是一种名字以`!`结尾的例程，只能在`loop`内部调用。循环每转一圈，它就产生下一个值；一旦它耗尽，循环便立即结束。

```sather
   loop
      total := total + counts.elt!;
   end;
```

Sather 没有 `for` 语句。迭代器就是用来替代它的，也是这门语言最出名的特性。

## 值得先记住的几个

| 迭代器 | 产生的值 |
| --- | --- |
| `a.elt!` | `a` 的每个元素，按顺序 |
| `a.ind!` | `a` 的每个下标：0、1、2 … |
| `n.upto!(m)` | `n`、`n+1` … `m` |
| `n.downto!(m)` | `n`、`n-1` … `m` |
| `n.times!` | 运行 `n` 次，不产生任何值 |
| `n.up!` | `n`、`n+1`、…，永不结束 |
| `s.elt!` | 字符串的每个字符 |

`until!`、`while!`和`break!`也是迭代器。这就是它们都以`!`结尾、且只能在循环里使用的原因。

## 调用写在哪儿

迭代器调用可以出现在任何能写表达式的地方，包括条件中间：

```sather
   loop
      if counts.elt! > 10 then busy := busy + 1; end;
   end;
```

程序中每一处写下迭代器的*位置*，都各自维护自己的进度。在一个循环体里写两次`counts.elt!`，就等于对数组做两次独立的遍历，这几乎从来不是你想要的结果：

```sather
   loop
      #OUT + counts.elt! + " and " + counts.elt!;   -- two separate walks
   end;
```

只调用一次，把值存进变量里就行。

## 循环如何结束

只要循环里*任意*一个迭代器耗尽，循环就立即结束，而不是等所有迭代器都耗尽。只有一个迭代器时，这一点显而易见。有多个时，这条规则最容易让所有人栽跟头，也正是下一道练习要讲的。

## 该选哪一个

需要值时优先用`elt!`，需要下标时优先用`ind!`。只有当两者同时需要，或者答案本身是下标而不是值时，才退而使用`upto!`去遍历`0 .. a.size - 1`。
