# 说明

请使用基本原理，把一个用字符串表示的三进制数（例如“102012”）转换为等价的十进制数。

对于指定无效三进制数的字符串，程序应将其视为值 0。

三进制数包含三个符号：0、1 和 2。

三进制数中最后一位代表 1，倒数第二位代表 3，倒数第三位代表 9，依此类推。

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

如果你的编程语言的标准库中提供了完成这一转换的方法，请假装它不存在，自己动手实现。
