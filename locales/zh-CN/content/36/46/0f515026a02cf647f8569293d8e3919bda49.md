# 关于

ABAP 有多种数字类型。在小型的入门练习中，最常用的是用于整数值的 `i` 和用于压缩十进制值的 `p`。

当某个值必须是整数时，使用 `i`，比如天数的计数。当某个值可以包含小数位时，使用十进制类型，比如每小时的费率。

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

需要固定小数位数时，商业应用中经常使用压缩十进制数。ABAP 还有十进制浮点数（`decfloat16` 和 `decfloat34`）和二进制浮点数（`f`）。二进制浮点数在科学计算中很有用，但对于与金钱有关的例子来说并不是一个好的默认选择，因为许多十进制小数无法被精确表示。
