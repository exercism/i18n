# 关于

`case`是 Factor 中基于相等性的多路分支结构。当选择取决于*单个*值是否等于若干备选值之一时，它就是合适的工具；而当每个分支需要不同的判断时，它就不合适（那种情况请用`cond`）。

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

有几点需要分清：

- 相等判断用的是`=`。凡是能用于`=`的东西都可以作为键，数字、字符串、字符、符号，甚至元组都行。
- *匹配*的分支看到的栈中不含输入值。*默认*分支看到的栈中，输入值仍在栈顶。
- 没有默认分支、又没有任何匹配子句的`case`会抛出错误。

在可能的情况下，`case`会编译成跳转表，所以它不只是`if`链的语法糖，速度也很快。
