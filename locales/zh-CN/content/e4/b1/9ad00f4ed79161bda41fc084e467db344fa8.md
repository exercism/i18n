# 资源

## 模块

Perl 自带一组核心模块，你可以在 [perldoc](https://perldoc.perl.org/modules) 上找到它们的完整列表。通常，你可以立即使用其中任何一个模块。（某些发行版可能需要你单独安装核心模块。）

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) 是一份经过精选的实用模块列表，同时也提到了一些其他的推荐列表。

Perl 有好几种可用的模块安装器，让你能安装 [CPAN](https://metacpan.org/) 上种类繁多的模块。

### App::cpm
一个非常快速、简单直接的模块安装器。
[CPAN](https://metacpan.org/pod/App::cpm::Tutorial) 上有教程。

如果你按照[安装文档](https://exercism.org/tracks/perl5/installation)中的`local::lib`说明操作，那么你应该已经装好它了。

只要运行`cpm install`，就能从`cpanfile`安装所需的模块；使用`--with-recommends`或`--with-suggested`则可以分别安装推荐模块和建议模块。

运行`cpm install Module::Name`可以在本地安装某个模块，运行`cpm install -g Module::Name`则可以全局安装。

### App::cpanminus
最知名、最常用的模块安装器。
安装说明可以在 [CPAN](https://metacpan.org/pod/App::cpanminus) 上找到。

运行`cpanm -L local --installdeps .`可以从`cpanfile`安装所需的模块。
运行`cpanm -L local Module::Name`可以在本地安装某个模块，运行`cpanm Module::Name`则可以全局安装。

## 代码风格与代码检查

如果你想找关于 Perl 编程的通用好建议，Damian Conway 的 [Perl Best Practices][PBP] 是个不错的参考。

要给代码做格式化美化，可以使用 [Perl::Tidy][PerlTidy] 模块。

然后你可以用随附的`perltidy`实用程序来重新格式化代码。

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy`有*非常多的*配置选项，可以迎合各种口味。它们记录在[这里][perltidyDocs]。

还有 [tidyview]，一个可视化界面，可以让你调整各种选项，并立即看到结果。

如果你想强制推行编码规范，还有 [Perl::Critic][perlcritic]。它自带前面提到的 *Perl Best Practices* 一书中描述的规则，但也有大量可用的插件，并且可以自定义来适配任何内部编码规范。

使用：

    $ perlcritic some_script.pl

这个工具有很多很多的配置调整项，完整内容见它的[文档][perlcriticdocs]。
