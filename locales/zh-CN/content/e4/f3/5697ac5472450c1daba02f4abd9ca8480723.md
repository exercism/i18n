# 介绍

当你需要一行`n`个值，而每个值都取决于它的位置时，Factor 的`<iota>`和`map`可以配合完成这件事，不必写循环计数器。

## `<iota>`与`map`

`<iota>`（位于 [`sequences`][sequences]）接受一个非负整数`n`，返回一个*虚拟*的整数序列`0, 1, …, n-1`。接下来`map`会遍历它，把你的引文应用到每个元素上：

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

引文接收一个整数（也就是下标），并在栈上留下该位置对应的值。

## 按次数迭代与重复

当你只需要访问每个下标的*副作用*，而不需要新序列时，`each-integer`（位于 [`math`][math]）会在`0, 1, …, n-1`上运行一段引文：

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate`（位于 [`sequences`][sequences]）会调用一段引文`n`次并收集结果，忽略下标，非常适合构造`n`个相互独立的值：

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## 有界区间

当下标范围不从`0`开始时，或者你希望两端都包含时，[`ranges`][ranges]词汇表提供了括号记法的字面量。方括号包含端点，圆括号不包含。

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

几个常见的一参简写：

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>`是最常见的形式；当下标范围不从`0`开始，或者需要包含上界时，`[a..b]`及其同类就是合适的工具。

## 开下界与可能为空的区间

方括号*包含*端点，圆括号则不包含。同样的技巧用在左边就得到`(a..b]`和`(a..b)`：

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]`在`n > 0`时给出`{ 1 … n }`，在`n = 0`时给出`{ }`，这正是遍历“从 1 到`n`（含`n`）的每个正整数”时最自然的形态。

## 递减区间

所有四种括号形式，即`[a..b]`、`[a..b)`、`(a..b]`、`(a..b)`，在`a > b`时都会*向下*计数，而不是趋向空结果：

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## 按位置构造字符串

`map`产出的形态取决于其引文返回的内容。如果引文在栈上留下一个字符编码，`>string`（位于 [`strings`][strings]）就会把结果变成字符串：

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A`会解析为整数`65`。这里的引文把下标翻倍再加上这个基数，于是落在每隔一个的大写字母上。你在这个下标之上叠加的任何运算，都决定了最终落在该位置上的是哪个字符。

## 按位置做选择

当字符取决于关于下标的某个*条件*时，就在引文内部做选择：

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

前三个位置把`i 3 <`判定为`t`，于是得到`a`；其余位置得到`b`。同样的形态，即`[ <test> [ <yes> ] [ <no> ] if ]`，可以覆盖用`even?` / `odd?`（位于 [`math`][math]）做的奇偶判断，以及用`mod`和`zero?`做的“每隔 k 个位置”判断。
