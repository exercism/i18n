# 关于

Haxe 有两种数字类型：整数和浮点数。

- `Int`：表示一个整数。
- `Float`：表示双精度 64 位浮点数。

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

虽然凡是`Int`都能用在期望`Float`的地方（也就是说，`Int`**可以赋值给**`Float`，也可以**与**`Float`**统一**），但反过来不成立：把`Float`赋值给`Int`可能会丢失精度，因此不允许隐式进行。

## 比较

如果两个数字的值相同，它们就相等。

```haxe
1 == 1; // true

1.2 == 1.2; // true

1 == 1.0; // true

0.2 + 0.1 == 0.3 // false
```

至于最后一种情况，参见 [0.30000000000000004.com][0.30000000000000004.com] 的简要说明。
