# 介绍

在 Python 中，[元组][tuple] 是一个_不可变_的集合，其中的元素按_顺序_排列。
和大多数集合一样，`tuples`可以存放任何（或多种）数据类型，包括其他的`tuples`。
元组支持所有[通用序列操作][common sequence operations]，但**不**支持[可变序列操作][mutable sequence operations]。

元组的元素可以使用`for item in <tuple>`结构进行迭代。
如果同时需要元素的下标和值，可以使用`for index, item in enumerate(<tuple>)`。
和任何序列一样，`tuples`中的元素可以通过_方括号表示法_访问，使用从左数起的`0-based index`编号，或者从右数起的`-1-based index`编号。
元组也可以完整或部分地复制，使用切片表示法（_`<tuple>[<start>:<stop>:<step>]`_）。


## 元组的构造

元组可以通过多种方式创建，既可以使用`tuple(<iterable>)`类构造函数，也可以使用`tuple`字面量声明。

### 以空参数或_可迭代对象_使用`tuple()`构造函数：

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

字符串是可迭代的，所以把单个`str`作为参数传给`tuple()`构造函数，可能会得到意想不到的结果：

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

传入单个可迭代对象时，它的元素会逐个被添加进去：

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### 将元组声明为_字面量_：

由于`tuple(<iterable>)`构造函数只接受_可迭代对象_（或不接受任何参数）作为参数，用字面量方法创建单元素元组要容易得多。

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

嵌套的数据结构也可以作为`tuple`的元素，包括其他的`tuples`：

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## 元组的拼接

可以使用加号`+`运算符拼接元组，它会解包每个`tuple`，创建一个新的、合并后的`tuple`。

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## 访问元组中的元素

`tuple`中的元素可以通过_方括号表示法_访问，使用从左数起的`0-based index`编号，或者从右数起的`-1-based index`编号。

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## 迭代元组中的元素

`tuple`中的元素可以使用`for item in <tuple>`语法在循环中_迭代_。
如果同时需要下标和值，可以使用`for index, item in enumerate(<tuple>)`。

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## 检查元组成员资格

可以使用`in`运算符检查某个元素是否在`tuple`中。

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
