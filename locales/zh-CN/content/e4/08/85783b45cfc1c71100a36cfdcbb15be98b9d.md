# 关于

自定义类型是 Gleam 中定义新数据类型的方式。它们可以有多个_变体_，每个变体都有自己的名字。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自定义类型的每个变体都可以携带数据，也可以不携带；不同的变体携带的数据类型可以不同。变体携带数据时，就称为_记录_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

要为一个特定变体创建值，如果它不包含额外数据（`Spring`），直接引用它的名字即可；如果包含额外数据（`SomeInt(2)`），就要像调用函数一样调用它。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

自定义类型和 Gleam 中的其他一切一样，具有_结构化相等性_，也就是说，同一个变体且数据相同的两个值是相等的。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

自定义类型的变体可以用 case 表达式进行模式匹配。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
