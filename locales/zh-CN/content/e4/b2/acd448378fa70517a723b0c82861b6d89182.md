# 简介

Kotlin 是一门由 JetBrains 开发的**静态类型**编程语言。这意味着变量的类型在编译时就已经确定。

## 变量

与其他静态类型编程语言类似，每个变量的类型都应该在编译时确定。只要编译器能根据上下文推断出类型，就可以省略显式的类型声明。

Kotlin 有不可变变量（`val`）和可变变量（`var`）。不可变变量在被赋予初始值之后，它的值就不能再改变。大多数时候你都会使用这种变量。

```kotlin
val robotName = "HAL-9000"
userId = "T-1000"  // This will not compile
```

可变变量的值可以改变一次或多次：

```kotlin
var index = 12
print(index)  // 12

index = 100
print(index)  // 100
```

Kotlin 中的分号是可选的，只有少数特殊情况例外，这些情况会在后面讲到。

## 函数

Kotlin 中的函数用 `fun` 关键字定义，是_一等公民_（与面向对象编程无关）。也就是说，你可以直接在文件中声明它们（即所谓的`top-level functions`），比如在 Java 中，方法只能在类里定义，而不能在文件中定义：

```kotlin
// This is content of the Hello.kt file

fun hello() {}
```

函数可以接收实参。每个实参都有名字和类型。与变量不同，实参的类型无法推断。函数可以有零个或多个实参：

```kotlin
fun hello() {}

fun hello(name: String) {}

fun hello(name: String, age: Int) {}
```

Kotlin 函数可以返回一个值，也可以不返回：

```kotlin
fun min(a: Int, b: Int): Int

fun countBonuses(user: User): Bonuses

fun run() {}
```

要从函数中返回一个值，需要使用 `return` 关键字：

```kotlin
fun getName(): String {
    return "Alice"
}
```

函数可以有带默认值的形参。如果在调用函数时省略了这些形参，就会使用它们的默认值：

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

## 注释

使用`//`定义单行注释：

```kotlin
foo() // Everything after `//` will be ignored by compiler

// I will be ignored too
```

或者用`/*`和`*/`定义多行注释：

```kotlin
/*
   This this an example
   for a multiline comment
*/
```
