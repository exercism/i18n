# 关于

JavaScript 是一种动态的、基于原型的语言。它有一些[原始类型][mdn-primitive]，除此之外的一切都被视为对象。

虽然它最为人熟知的身份是网页的脚本语言，但许多非浏览器环境也在使用它，比如 Node.js。这门语言一直在积极开发中；得益于它的多范式特性，它支持多种编程风格。JavaScript 是一门动态语言，支持面向对象、命令式和声明式（例如函数式编程）等风格。

## 赋值与重新赋值

在 JavaScript 中，给名称赋值主要有几种方式：使用变量或常量。在 Exercism 上，变量一律用 [camelCase][wiki-camel-case] 书写，常量则用 [SCREAMING_SNAKE_CASE][wiki-snake-case] 书写。并没有官方指南可循，不同的公司和组织也有各自的风格指南。_你可以按自己喜欢的任何方式书写变量_。按练习中准备好的方式书写，好处是它们在网页界面和大多数 IDE 中会有不同的高亮显示。

JavaScript 中的变量可以用[`const`][mdn-const]、[`let`][mdn-let]或[`var`][mdn-var]关键字来定义。

使用`let`或`var`时，一个变量在其生命周期内可以引用不同的值。例如，`myFirstVariable`可以用赋值运算符`=`定义和重新定义很多次：

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

与`let`和`var`不同，用`const`定义的变量只能赋值一次。这正是 JavaScript 中定义常量的方式。

```javascript
const MY_FIRST_CONSTANT = 10;

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

### 常量赋值

`const`关键字在变量和常量中_都_会被提到。围绕常量经常提到的另一个概念是[(不)可变性][wiki-mutability]。

`const`关键字只让_绑定_不可变，也就是说，你只能给一个`const`变量赋值一次。在 JavaScript 中，只有[原始值][mdn-primitive]是不可变的。不过，[非原始值][mdn-primitive]仍然可以被修改。

```javascript
const MY_MUTABLE_VALUE_CONSTANT = { food: 'apple' };

// This is possible
MY_MUTABLE_VALUE_CONSTANT.food = 'pear';

MY_MUTABLE_VALUE_CONSTANT;
// => { food: "pear" }
```

### 常量值（不可变性）

按照惯例，在 Exercism 以及许多其他组织和项目的风格指南中，不要修改看起来像`const SCREAMING_SNAKE_CASE`的值。从技术上说，这些值_可以_被修改，但为了清晰，也为了在 Exercism 上做好预期管理，我们不鼓励这样做。当_必须_强制这一点时，使用[`Object.freeze(value)`][mdn-object-freeze]。

```javascript
const MY_VALUE_CONSTANT = Object.freeze({ food: 'apple' });

// This silently fails
MY_VALUE_CONSTANT.food = 'pear';

MY_VALUE_CONSTANT;
// => { food: "apple" }
```

在实际项目中，不太可能整个代码库里到处都看到`Object.freeze`，但永远不修改`SCREAMING_SNAKE_CASE`值是个好规则；它通常由 linter 之类的自动化分析工具来强制执行。

## 函数声明

在 JavaScript 中，功能单元被封装在_函数_里，如果几个函数属于同一类东西，通常会把它们放在同一个文件中。这些函数可以接收形参（实参），并可以用`return`关键字_返回_一个值。函数通过`()`语法调用。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 在 JavaScript 中，声明函数有_很多_不同的方式。这些方式看起来与使用`function`关键字不同。该 track 会尝试逐步介绍它们，但如果你已经了解，可以随意使用任何一种。大多数情况下，用其中哪一种都谈不上更好或更差。

## 导出与导入

`export`和`import`关键字是把普通 JavaScript 文件变成[JavaScript 模块][mdn-module]的强大工具。除了让代码可以选择性地暴露组件（例如函数、类、变量和常量）之外，它还带来了一整套其他特性，比如：

- [重命名导出和导入][mdn-renaming-modules]，可以帮你避免命名冲突，
- [动态导入][mdn-dynamic-imports]，可以按需加载代码，
- [摇树优化][blog-tree-shaking]，通过剔除无副作用的模块、甚至模块中_未被使用_的内容，来减小最终代码的体积，
- 导出[_实时绑定_][blog-live-bindings]，当原始值发生变化时，可以让你导出的值在所有导入它的地方一起变化。

一个具体的例子是 Exercism 的 JavaScript track 上测试的工作方式。每个练习至少有一个实现文件，例如`lasagna.js`，也至少有一个测试文件，例如`lasagna.spec.js`。实现文件用`export`暴露公开的 API，测试文件用`import`访问它们，测试就是这样检验实现的结果的。

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
