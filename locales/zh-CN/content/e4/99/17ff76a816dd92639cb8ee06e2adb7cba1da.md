# 简介

数组是 Factor 的定长序列：元素可以修改，长度不能改变。你已经知道如何写数组字面量`{ … }`，以及如何对它进行切片和聚合。本练习涵盖一套小工具，当你从栈上的值构建数组，然后查找或重新排列其中的内容时就会用到它们。

## 从栈上构建

`1array`、`2array`、`3array` 和 `4array`（位于[`arrays`][arrays]中）从栈顶取出 1、2、3 或 4 个值，把它们打包起来：

```
1array ( a       -- { a }       )
2array ( a b     -- { a b }     )
3array ( a b c   -- { a b c }   )
4array ( a b c d -- { a b c d } )
```

```factor
42 1array .                ! => { 42 }
3 4 2array .               ! => { 3 4 }
"x" "y" "z" 3array .       ! => { "x" "y" "z" }
1 2 3 4 4array .           ! => { 1 2 3 4 }
```

## 拼接

`concat`（位于[`sequences`][sequences]中）接收一个序列，其元素本身也是序列，并将它们展平一层。`join` 做的事情相同，只是在每一对之间插入一个分隔符：

```
concat ( seqs     -- seq )
join   ( seqs sep -- seq )
```

```factor
{ { 1 2 } { 3 4 } { 5 } } concat .
! => { 1 2 3 4 5 }

{ "alpha" "beta" "gamma" } ", " join .
! => "alpha, beta, gamma"
```

## 反转

`reverse` 返回一个新序列，其中元素的顺序相反：

```
reverse ( seq -- newseq )
```

```factor
{ 1 2 3 4 } reverse .   ! => { 4 3 2 1 }
```

## 它是不是数组？

`array?`（位于[`arrays`][arrays]中）是类型判定。对于由 `<array>`、`1array`/`2array`/……或数组字面量 `{ … }` 构建的任何值，它都返回 true，对其他所有值（包括向量、字符串和其他序列）都返回 false：

```
array? ( obj -- ? )
```

```factor
{ 1 2 3 } array? .         ! => t
"hello" array? .           ! => f
V{ 1 2 3 } array? .        ! => f
```

## 查找

`index` 返回第一个等于输入值的元素的下标，如果该值不存在则返回 `f`。`member?` 只返回一个布尔值。两者都是**元素在前**，**序列在后**。`members`（位于[`sets`][sets]中）返回序列中*唯一*的元素，也就是去重操作；而 `all-unique?`（同样位于[`sets`][sets]中）测试序列是否已经没有重复项：

```
index       ( elt seq -- i/f )
member?     ( elt seq -- ? )
members     ( seq     -- uniques )
all-unique? ( seq     -- ? )
```

```factor
"b" { "a" "b" "c" } index .       ! => 1
"z" { "a" "b" "c" } index .       ! => f
"b" { "a" "b" "c" } member? .     ! => t
"z" { "a" "b" "c" } member? .     ! => f
{ 1 2 3 2 1 } members .           ! => { 1 2 3 }
{ 1 2 3 } all-unique? .           ! => t
{ 1 2 1 } all-unique? .           ! => f
```
