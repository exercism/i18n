# `for` 循环

循环是编程中的基本概念，它让你可以多次执行一个代码块。
在 Swift 中，循环分为两种：[`for-in` 循环][for-loops]和`while`循环。
本章将介绍`for-in`循环。

`for`循环让你可以遍历一系列值，依次取出每个元素，并把它绑定到你选择的变量上。
在 Swift 中，你可以遍历多种序列，比如区间、数组和字符串（后面还会介绍更多类型）。
当序列中的每个元素都被遍历过后，循环就会结束。

声明`for`循环时要用到`for`关键字，后面跟一个变量名、`in`关键字，以及要遍历的值序列。
`for-in`循环中声明的变量是不可变的，也就是说，你不能在循环内部修改它的值。
下面是一个遍历数字数组的`for-in`循环示例：

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`变量是在`for-in`循环中声明的，只能在循环的作用域内使用。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 遍历区间

你也可以用`for-in`循环遍历一个数字区间。
这样可以让你把一个代码块执行指定的次数。例如，区间`1...5`会依次遍历数字 1、2、3、4、5，所以循环会执行 5 次。
有时你可能想遍历数组这类数据结构中的下标，这时可以使用`0..<array.count`区间。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 遍历字符串

你也可以用`for-in`循环遍历字符串。
这样可以遍历字符串中的每个字符。请特别注意，循环变量的类型是`Character`。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift 还提供了`stride`函数，让你可以在一个区间上按指定步长创建序列。
然后可以用`for-in`循环遍历它。
`stride`有两种形式：[`stride(from:to:by:)`][stride-to]和[`stride(from:through:by:)`][stride-through]。前者的区间不包含终点，后者的区间包含终点。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

注意，`to`形参不包含终点，因此循环会一直迭代到`to`形参之前的那个数；而`through`形参包含终点，所以在这个例子里它也会包括`10`。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
