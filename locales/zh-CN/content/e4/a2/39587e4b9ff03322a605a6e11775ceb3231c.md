# 简介

假设你想要 1000 以内的所有非负整数。
如果要把它们一个个敲进数组里，那就太荒唐了。

为此，我们有`range`类型：

```julia-repl
julia> 0:1000
0:1000

julia> typeof(0:1000)
UnitRange{Int64}
```

区间非常常见：不仅是为了省去你手动输入的麻烦，也常常作为函数的返回类型。

注意，区间并不是向量。
它们只是一组用来生成序列的指令（也就是“惰性”求值，或者说“迭代器”）。

如果你需要把区间当作向量使用，就用`collect()`函数来转换：

```julia-repl
julia> collect(0:5)
6-element Vector{Int64}:
 0
 1
 2
 3
 4
 5
```

还可以指定步长，这里是 0.3：

```julia-repl
julia>  collect(1.0:0.3:2.0)
4-element Vector{Float64}:
 1.0
 1.3
 1.6
 1.9
```

所以语法是`start:stepsize:stop`。
正如整数示例中所见，两个端点都是_包含_的。
如果步长不能整除`stop - start`，最后一个元素就不会超过`stop`。

## 字母区间

区间中也可以使用非数字序列。
最简单的例子是 ASCII 字母：

```julia-repl
julia> 'a':'d'
'a':1:'d'

julia> typeof('a':'d')
StepRange{Char, Int64}

julia> collect('a':'d')
4-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
```

`Char`类型会在另一个概念中更详细地讲解。
现在，只需把它们当作单引号里的单个字符即可。

## 区间相关的函数和运算符

用`first()`和`last()`查看区间的端点。

```julia
 r = 1:10  # => 1:10
 first(r)  # => 1
 last(r)   # => 10
```

## 关于向量下标的更多内容

整数区间和向量都可以用在向量下标中：

```julia
nums = collect(10.0:50.0)
nums[3:2:7]  # gives [12.0, 14.0, 16.0]
nums[ [3, 5, 7] ] # also gives [12.0, 14.0, 16.0]
```
