# 介绍

## 比较

在 JavaScript 中，可以使用下面的关系运算符和相等运算符来比较数字。

| 比较               | 运算符    |
| ---------------------- | --------- |
| 大于                   | `a > b`   |
| 大于或等于             | `a >= b`  |
| 小于                   | `a < b`   |
| 小于或等于             | `a <= b`  |
| 严格相等               | `a === b` |
| 非严格相等             | `a !== b` |

比较的结果始终是一个布尔值：`true`或`false`。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

在 JavaScript 中，上面的比较运算符也可以用来比较字符串。这时会按照字典顺序进行比较。你可以在[这里][utf-16-list]找到所有字符确切顺序的列表。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 条件判断

在 JavaScript 中，有条件地执行逻辑的常见方式是`if`语句。它由`if`关键字、用圆括号括起来的条件，以及用大括号括起来的代码块组成。只有当条件的求值结果为`true`时，才会执行这个代码块。

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

它既可以单独使用，也可以和`else`关键字结合使用。

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

要在`else`语句中嵌套另一个条件，可以使用`else if`。

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
