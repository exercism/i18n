# 说明

在本练习中，你将编写代码，帮助一家标牌公司为他们的标牌制作自定义信息。

## 1. 制作一块活动标牌

实现函数 `buildSign(occasion, name)`，它接受一个字符串作为 `occasion` 形参，并接受一个存放某人姓名的字符串作为 `name` 形参。
这两个形参会嵌入到一个模板字符串中，输出标牌上的信息。

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. 制作一块生日标牌

实现函数 `buildBirthdaySign(age)`，它接受一个年龄，并根据年龄决定标牌上信息的一部分。
如果年龄为 50 或更大，标牌会称用户为 _mature_；否则称其为 _young_。
确切期望的输出如下所示：

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. 制作一块毕业标牌

实现函数 `graduationFor(name, year)`，它接受一个字符串形参作为姓名，接受一个数字形参作为年份，并使用字符串插值生成标牌上的短语，其中用换行符分隔信息的两行。

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. 计算标牌的费用

实现函数 `costOf(sign, currency)`，它接受一个存放标牌内容的字符串和一个表示货币的字符串。
标牌的基础价格是给定货币的 20。此外，每个字母花费 2。（空格也计入计算。）
返回的短语包含制作标牌的费用，费用写成小数点后两位，后面跟着货币字符串。

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
