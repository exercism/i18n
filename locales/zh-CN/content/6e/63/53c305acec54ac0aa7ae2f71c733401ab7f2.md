# 说明

在本练习中，你将实现一部分实用工具函数，帮助开发者清理标识符名称。

在 6 个任务里，你将逐步构建两个函数：`transform`用来转换单个字符，`clean`用来转换字符串。

合法的标识符由零个或多个字母、下划线、连字符、问号和表情符号组成。

如果把空字符串传给`clean`函数，就应该返回空字符串。

## 1. 把遇到的连字符替换为下划线

实现`transform`函数，把连字符替换为下划线。

```fsharp
transform '-'  // => "_"
```

## 2. 移除所有空白字符

移除所有空白字符。
这包括开头和结尾的空白。

```fsharp
transform ' '  // => ""
```

## 3. 把 camelCase 转换为 kebab-case

修改`transform`函数，把 camelCase 转换为 kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. 省略数字字符

修改`transform`函数，省略所有数字字符。

```fsharp
transform '7'  // => ""
```

## 5. 把希腊小写字母替换为问号

修改`transform`函数，把 'α' 到 'ω' 范围内的希腊字母替换掉。

```fsharp
transform 'β' // => "?"
```

## 6. 组合这些操作来处理一个字符串

实现`clean`函数，对整个字符串应用这些操作。

不符合这些规则的字符应原样保留。

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## 把字符拼接成字符串

这个主题会在教学大纲的后面详细讲解。

不过现在，知道有一个叫 [`String.collect`][string-collect] 的[高阶函数][higher-order-function]可能会很有用，它会用你提供的函数，把 `char` 的集合转换成字符串。

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```

[higher-order-function]: https://exercism.org/tracks/fsharp/concepts/higher-order-functions
[string-collect]: https://fsharp.github.io/fsharp-core-docs/reference/fsharp-core-stringmodule.html#collect
