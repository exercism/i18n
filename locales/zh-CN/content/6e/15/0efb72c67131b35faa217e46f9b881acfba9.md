# 简介

在 JavaScript 中，值可以有多种不同的类型。要改变一个变量的类型，可以通过显式的**类型转换**来实现。除此之外，当上下文需要时，JavaScript 也会执行**类型强制转换**（隐式类型转换）。

## 类型转换

JavaScript 不像许多其他语言那样，有专门用于把值转换成另一种类型的语法结构，但可以用一些内置的辅助工具代替。最常用的是，`Boolean`、`Number`和`String`可以作为函数使用，把值转换成对应的类型。

### 转换成布尔值（真值/假值）

用`Boolean(value)`可以把任何值转换成布尔值。有一组固定的值，称为**假值**，它们会转换成`false`。最重要的是，`false`、`0`、空字符串、`null`、`undefined`和`NaN`都是假值。

对于其他所有值，`Boolean`都返回`true`。这些值称为**真值**。

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

请注意，根据上述规则，`'0'`、`'false'`、`[]`和`{}`在 JavaScript 中都是**真值**。

### 转换成数字

可以用`Number(value)`把值转换成数字。字符串开头和结尾的空白字符会被忽略，空字符串会转换成`0`。如果尝试转换非原始值，或者转换不表示数字的字符串，结果就是`NaN`（[非数字][mdn-nan]）。

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### 转换成字符串

用`String(value)`可以把值转换成字符串。对于原始值，结果和你预期的一样。

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

对于数组，`String`函数会对每个元素应用字符串转换，并用逗号把结果拼接起来。你也可以自己调用[`join`方法][mdn-join]，例如自定义分隔符。请注意，在这些情况下，`null`和`undefined`会被转换成空字符串。

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

对于对象，`String`默认会返回一段没什么用的文本。

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## 类型强制转换

在某些上下文中，JavaScript 会在求值某个语句之前，自动把值转换成另一种数据类型。这种隐式转换称为**类型强制转换**。

### 布尔上下文

当非布尔值用在布尔上下文中时，JavaScript 会应用和`Boolean`函数相同的规则，来隐式转换该值。

到布尔值的强制转换常见于以下位置：

- [if 语句][concept-conditionals]的条件
- [三元运算符][mdn-ternary]`?`的第一个操作数
- 逻辑非运算符`!`的操作数
- 逻辑与`&&`和逻辑或`||`运算符的操作数（表达式的结果是其中一个操作数，不一定是布尔值）

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### 字符串上下文

如果加法运算符`+`用于原始值，并且其中一个操作数是字符串，那么另一个操作数也会被强制转换成字符串。转换逻辑和`String`函数相同。然后，两个字符串会被拼接起来。

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### 数字上下文

许多运算符会按照上面讲解的`Number`函数的逻辑，把操作数强制转换成数字（如果需要的话）。

- 算术运算符：`+`（如果不涉及字符串）、`-`、`*`、`/`、`%`、`**`
- 一元加号运算符和一元取负运算符：`+`、`-`
- 关系运算符（操作数不是字符串时）：`>`、`>=`、`<`、`<=`
- 位运算符：`|`、`&`、`^`、`~`

关于这些运算符的更多细节，请参阅 [MDN 运算符列表][mdn-operators]。

为了避免出错，最好在应用这些运算符之前，总是显式调用`Number`。
