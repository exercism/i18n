# 介绍

Elixir 提供了一种优雅的语法来处理二进制数据，正如我们在用于处理[位串][exercism-bitstrings]的`<<>>`特殊形式中看到的那样。

二进制类型是位串类型的一种特化。位串长度可以任意（任意数量的[位][wiki-bit]），而二进制则要求位数能被 8 整除。也就是说，处理二进制数据时，我们通常以[字节][wiki-byte]（8 位）为单位来思考。一个字节可以表示从`0`到`255`的整数。处理字节值时常用[十六进制][wiki-hexadecimal]，即`0x00 - 0xFF`。

二进制字面量使用位串特殊形式`<<>>`定义。定义二进制字面量时，可以使用整数字面量和字符串字面量。大于 255 的整数值会溢出，只使用该整数的最后 8 位。默认情况下，会对值应用`::binary`修饰符。我们可以使用`<>/2`运算符拼接二进制数据。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<2, 4, 6, 8, 10, 12, 14, 16>> == <<0x02, 0x04, 0x06, 0x08, 0x0A, 0x0C, 0x0E, 0x10>>
```

_空字节_是`<<0>>`的另一个名称。

## 对二进制数据进行模式匹配

[模式匹配][exercism-pattern-matching]甚至扩展到了二进制数据，我们可以像对数组那样，对二进制数据的一部分进行模式匹配。

```elixir
# Ignore the first 8 bytes, match and bind the remaining to `body`
<<_::binary-size(8), body::binary>>
```

与其他类型的模式匹配一样，我们可以在函数签名中使用它，以便在多个函数子句中选择时进行匹配。
