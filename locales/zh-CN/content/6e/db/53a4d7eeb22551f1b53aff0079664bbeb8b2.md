# 关于

Haskell 有一个类型`Num`，它是所有数值类型的基础类型。
数字类型下有四个主要子类型：[`Int`][int]、[`Integer`][integer]、[`Double`][double] 和 [`Float`][float]。

Haskell 中有两种整数类型，用来表示整数。
`Int`是固定大小的整数，而`Integer`是任意精度的整数。
`Integer`能保存任意大小的数字，上限只取决于机器的内存；而`Int`对应的是能用 32 位或 64 位表示的整数集合（保证至少能表示 -2^29 到 2^29 - 1）。

注意，在写负数时，应该使用括号来避免歧义。

```haskell
1

(-1)
```

`Float`对应实数集合，精度受计算机限制。
定义在数字上的运算通常只适用于其中一种类型，而不是两者都适用。
`Double`是双精度浮点数。

```haskell
10.5
```

## 整数与浮点数之间的转换

使用`toFloat`函数，可以把`Int`或`Integer`转换成`Float`。

```haskell
toFloat 1
-- -> 1.0
```

还有`fromIntegral`，它可以把任意数值类型转换成推断出的所需类型。

```haskell
fromIntegral 1
-- -> 1.0
```

要把`Float`转换成`Int`，可以使用[`round`][round]、[`floor`][floor]或[`ceiling`][ceiling]函数。
`round`函数会舍入到最接近的整数，`floor`向下取整，`ceiling`向上取整。

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

## 算术运算符

可以在数值类型上使用[基本算术运算符][math]。
这些运算符是`+`、`-`、`*`、`/`和`%`。
使用这些运算符时，数字的类型必须一致。
`fromIntegral`函数会进行转换，让类型保持一致。

### 加法、减法与乘法

`+`运算符用于加法，`-`运算符用于减法，`*`运算符用于乘法。

| 运算符 | 示例        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

### 除法

除法用于数字相除。
`/`运算符用于除法。
结果始终是浮点数。

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
在某些编程语言中，除以零会得到错误。

在 Haskell 中，除以零的结果是`Infinity`或`-Infinity`。
唯一的例外是零除以零，结果是`NaN`（非数字）。

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

## 整数除法

整数除法用于对整数做除法，并取得结果的整数部分。
Haskell 有两个整数除法函数，它们在结果为负数时的取整方式不同：

- `div`向下取整，朝负无穷方向。
- `quot`向零取整。

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
使用整数除法时除以零会导致异常。
这与普通除法不同。
~~~~

### 余数

整数除法的余数可以用`mod`或`rem`求得。
当其中一个数字为负数时，它们的结果符号不同：

- `mod`与`div`配套使用，其结果与除数同号。
- `rem`与`quot`配套使用，其结果与被除数同号。

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

对于任意`x`和`y`（其中`y`不为零），以下等式成立：

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
当两个数字都为正数时，`div`和`quot`的结果相同，`mod`和`rem`也是如此。
在这种情况下，`quot`和`rem`可能稍微更高效，因为`div`和`mod`需要额外的步骤来处理负数。
~~~~

~~~~exercism/caution
使用`mod`或`rem`时除以零会导致异常。
这与普通除法不同。

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

## 求幂

Haskell 有三个“求幂”运算符，它们的工作方式不同，接受的实参类型也不同。

- `**`接受两个**浮点数**，用对数计算幂。
- `^^`接受一个**浮点数**，把它提升到**整数**次幂，指数可正可负。
- `^`接受**任意数值类型**，把它提升到**正整数**次幂。

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

## 优先级与括号

Haskell 允许使用括号（`()`），可以用它们把表达式分组。
当你想改变运算顺序时，这很有用。

使用多个算术运算符时，运算顺序与数学中相同，也称为[PEMDAS][pemdas]。
它遵循括号（`()`）、指数（`**`）、乘法（`*`）与除法（`/`）、加法（`+`）与减法（`-`）的顺序。

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
