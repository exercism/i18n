# 说明

实现一个函数：给定 2D 坐标平面上的两个点，求出第三个点，使这些点连接起来构成一个等边三角形。函数会输出两个点，因为给定最初的两个点，有两种可能的“第三个”点可以构成等边三角形。值得注意的是，等边三角形是指三条边长度都相等的三边形。

这个函数接收两个 Python 元组作为输入，每个元组用浮点数给出一个点的 x 和 y 坐标。例如，(0.0, 0.0) 和 (1.0, 1.0) 都可以作为输入。

函数应当输出一个元组，其中包含两个元组，每个元组用浮点数给出一个点的 x 和 y 坐标。例如，((0.0, 0.0), (1.0, 1.0)) 就是一种可能的输出。

如果 Z3 求解器得出的结果不可满足，函数应当抛出 Python 内置异常 ArithmeticError。如果两个输入点相同，也应当抛出 ArithmeticError。

函数不应使用 z3 库中的 "set_option()" 函数来设置全局参数。这一步在测试用例中完成，以确保浮点数具有预期的精度（小数点后的位数）。

由于 Z3 Real 变量的模型解释是 AlgebraicNumRef、IntNumRef 或 RatNumRef 的实例，因此另外提供了一个函数，用于把这个实例转换为浮点数。
