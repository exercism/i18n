# 附加说明

## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。抛出异常时，一定要附上一段**有意义的错误消息**，说明错误的来源。这样代码更易读，也能大大方便调试。如果已经确定错误来源属于某种类型，你可以选择抛出某个[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但同样要附上有意义的消息。

本练习要求你在传给`classify()`函数的数字不是_正整数_时，使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)来“抛出”`ValueError`。只有既用`raise`抛出该`exception`，又附上消息，测试才会通过。

要给`ValueError`附上消息，就把消息作为实参传给该`exception`类型：

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
