# 简介

## 继承

继承是 OOP（面向对象编程）中的核心概念。
它表示一种 IS-A 关系。
它在编程中的字面含义和英语中一样，都是从父级继承特性（在编程中，特性通常指函数和变量）。

看看下面这个`Animal`类：

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal`是父类，因为这个类具有的属性可以扩展给所有动物。

再看一个名叫`Lion`的动物，它的类是这样的：

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override`注解用于表示子类中的方法重写了其父类的方法。
它不是严格必需的，但使用它是一种最佳实践。
~~~~

现在，当我们这样写：

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

注意：用`Lion`初始化`Animal`类。
输出会是这样：

```java
Lion here!!
```

按照 OOP 的说法，继承有很多种类型，但 Java 只支持其中一部分（多级继承和层次继承）。
想了解更多，请阅读[这篇文章][java-inheritance]。
