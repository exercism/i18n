# Linux 黑客安装（仅限高级 Linux 用法）

我们还在摸索这里最合适的说明，但我们知道（也很感激）很多 Linux 开发者对安装什么、东西放在哪里非常讲究。

_如果你确实想走标准安装流程，直接返回并按照[常规安装步骤](https://exercism.io/tracks/pharo-smalltalk/installation)操作即可。_

以下说明还很粗糙，基于 ArchLinux，但也可能适用于你的发行版（如果不管用，欢迎帮我们一起想办法改进，说不定还能给 Pharo 上游提些需求）。_注意：这些说明目前还不能确定是否可靠，所以欢迎你帮忙完善。_

- 把一个 Pharo VM 装到你想要的位置。如果 AUR 或类似的仓库里列出了 Pharo 7，你也许可以直接用它；否则可以从这里下载：[https://files.pharo.org/vm/pharo-spur64/linux/]（挑一个 stable-timer 的 vm）
- 接下来，你需要解压出一个 Pharo.image 文件，放到你的 exercism 目录里。可以从这里获取：[https://files.pharo.org/image/70/]，选最新的 64 位 zip 文件。
- 现在用一条简单的命令行测试来确认 VM 和 Image 是否正常工作：`pharo Pharo.image eval "100 factorial"`。如果一切正常，你应该能得到一个结果。
- 接着试试 OSX 一节里讲的“加载脚本”。你可能会遇到提到 `libgit2` 的错误，如果是这样，把它也装上再试一次。我们也收到反馈说安装 `libcurl-gnutls` 会有帮助（不过这一点还没被证实）
- 我们还收到反馈说，某些 libgit2 失败的情况跟一个内部 loadModule 改动有关，我们可能会从开发版 Pharo 把它移植回来。这种情况下，你需要把 `LGitLibrary` 类里的 `unixModuleName` 方法替换成下面这样：
  1. 输入 `pharo-ui Pharo.image` 启动带界面的 Pharo
  1. 按 Ctrl-Space，输入 `unixModuleName`
  1. 选中 `LGitLibrary >> unixModuleName` 这一项，按回车
  1. 在打开的浏览器里，把 `unixModuleName` 的方法源码替换成下面这段（复制粘贴过去），按保存（ctrl-s），最后保存并退出 Pharo。
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

现在再重试前面提到的 OSX exercism “加载脚本”。如果一切正常，你应该能看到加载进度条在屏幕上一闪而过，然后弹出一个 System Browser 窗口。如果没有，请到 Pharo Discord 求助（见上文）。

现在你应该返回，继续按照剩下的[入门说明](https://exercism.io/tracks/pharo-smalltalk/installation)操作。
