# 提示

## 通用

- `case`（在[`combinators`][combinators]中）是做相等值匹配的正确工具；`cond` 则是做带守卫的谓词匹配的正确工具。
- 符号（`yes`、`no`、`maybe`、`korean` 等）已经在练习文件中通过 `SYMBOLS:` 声明好了。

## 1. 给菜系评分

- 用一个两分支的 `case`，把 `korean` 和 `turkish` 分别映射到各自的认可值。

## 2. 给电影类型评分

- 匹配 `romance`，为其余情况放一个 `[ drop no ]` 作为默认分支。记住，默认分支在栈顶看到的仍是原始值，所以在压入结果前要先把它 `drop` 掉。

## 3. 给散步评分

- 使用 `cond`（也在 `combinators` 中），每个守卫都是 `[ dup N > ]`。主体需要先 `drop` 掉公里数，再压入认可值。

## 4. 给活动评分

- 活动是 `{ tag value }`。用 `first2` 把两者都压入栈，再 `swap`，让 tag 位于栈顶，这正是 `case` 用来匹配的对象。
- `board-game` 和 `chill` 的分支在栈上仍能看到（`f`）值；在压入认可值前先把它 `drop` 掉。
- `movie`、`restaurant` 和 `walk` 的分支在栈上仍能看到对应的值，所以你可以直接调用你在第 2/1/3 题中定义的那个单词。
