# 说明

Lisp 外星人 Lucy 喜欢数字，认为其中一些数字“很了不起”。

Lucy 请你帮忙写一些函数，让数字变得更了不起。

Lucy 觉得一个数字怎样才算了不起，这一点是会变的，所以这些函数需要足够灵活。

## 1. 让数字变得了不起

要把一个数字数组变成更了不起的数字数组，你需要写一个函数`make-magnificent-maybe`，它接受一个要应用于这些数字的函数，以及一个数字数组。
它应该求值为一个数字数组，其中的数字更了不起（根据所提供的函数）。

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. 只保留最好的

在（希望如此）让数字变得更了不起之后，Lucy 只想看到真正了不起的数字。

Lucy 很清楚 1 *永远* 都算不上了不起，所以你只需要把它去掉。

但除此之外，Lucy 有时会改变主意，所以还会再给你一个函数，用来判断一个数字是否了不起。

你需要写一个函数`only-the-best`，它接受一个函数和一个数字数组，并且只返回最好的数字（不包括`1`，也不包括函数对其求值为 true 的数字）。

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
