# 关于

JavaScript 有一个自增运算符和一个自减运算符。
它们会直接修改变量本身。
`++`给数字加一，`--`给数字减一。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

上面的例子展示的是后缀自增/自减运算符。
这种情况下，运算符放在变量之后，表达式的返回值是变量自增/自减_之前_的值。

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

还有前缀形式，运算符放在变量之前。
这时返回值是变量自增/自减_之后_的值。

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
