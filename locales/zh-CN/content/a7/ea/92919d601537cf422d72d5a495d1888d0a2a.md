# 说明

在这个练习中，你将处理日志行。

每一行日志都是一个格式如下的字符串：`"[<LEVEL>]: <MESSAGE>"`。

一共有三种不同的日志级别：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会接收一行日志，并要求你对它做点什么。

## 1. 从日志行中获取消息

实现 `message` 函数，返回日志行中的消息：

```fsharp
message "[ERROR]: Invalid operation"
// => "Invalid operation"
```

任何开头或结尾的空白字符都应被移除：

```fsharp
message "[WARNING]:  Disk almost full\r\n"
// => "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现 `logLevel` 函数，返回日志行的日志级别，返回值应小写：

```fsharp
logLevel "[ERROR]: Invalid operation"
// => "error"
```

## 3. 重新格式化日志行

实现 `reformat` 函数，重新格式化日志行，把消息放在前面，日志级别放在它后面的括号中：

```fsharp
reformat "[INFO]: Operation completed"
// => "Operation completed (info)"
```
