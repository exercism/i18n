# 关于

CoffeeScript 是一门可转译为 JavaScript 的语言，用于制作动态网站（既可在网页浏览器中运行，也可在服务器端运行）。
在运行之前，代码会先经过转译，把 CoffeeScript 转换成 JavaScript，这样既能保持与 JavaScript 的兼容性和同样的性能，又能带来许多新特性！

CoffeeScript 的诞生，是为了提供一种更简单的编写 JavaScript 的方式，它融合了 Ruby 和 Python 两种语言的特点。
其中一个不同之处，是用缩进和箭头取代 JavaScript 中冗长的函数写法，并引入了函数式语言中一些实用的特性，比如模式匹配。

CoffeeScript 是众多转译为 JavaScript 的新语言之一，TypeScript 和 Flow 也是其中一员。这个社区正在不断壮大，这类语言也非常受欢迎。
