# 安装

## 快速开始

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

默认情况下，脚本会安装到`/usr/local/bin`。要改变安装位置，请提供目录名：

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Linux 和 macOS 的二进制文件通过 brew 提供。

安装：

    brew install borkdude/brew/babashka

升级：

    brew upgrade babashka

## Arch (Linux)

`babashka`在 [Arch User Repository](https://aur.archlinux.org) 中[可用](https://aur.archlinux.org/packages/babashka-bin/)。你可以用自己喜欢的 [AUR](https://aur.archlinux.org) 助手来安装，比如 [yay](https://github.com/Jguer/yay)、[yaourt](https://github.com/archlinuxfr/yaourt)、[apacman](https://github.com/oshazard/apacman) 和 [pacaur](https://github.com/rmarquis/pacaur)。下面是一个使用`yay`的例子：

    yay -S babashka-bin

## Windows

在 Windows 上，你可以使用 [scoop](https://scoop.sh/) 和 [scoop-clojure](https://github.com/littleli/scoop-clojure) bucket 来安装。

## 下载

你也可以从 [Github](https://github.com/borkdude/babashka/releases) 下载二进制文件。Linux 上还提供了一款可以在 Alpine 上使用的静态二进制文件。
