# 简介

当一段引用需要*记住*周围环境中的值时，Factor 提供了两种工具：来自 [`kernel`][kernel] 的 `curry` 和 `compose`，以及来自 [`fry`][fry] 的 fry 语法 `'[ … ]`。

`curry` 会把一个值固定到引用的开头：

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` 会把两个引用粘合在一起：

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

当需要捕获的值不止一两个时，用 fry 会更简洁。每个 `_` 占位符都会按顺序填入一个从栈上取下的值：

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

fry 还能深入嵌套的引用。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[fry]: https://docs.factorcode.org/content/vocab-fry.html
