# 说明

在这个练习中，你将为一个朋友正在开发的新 RPG 游戏实现冒险逻辑。

游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛又忠诚的宠物狗。不幸的是，灾难降临了：她最好的朋友在森林里寻找浆果时被绑架了。

Annalyn 会试着找到并救出她最好的朋友，这次冒险她可以选择带上她的狗。

沿着最好朋友的踪迹走了一段时间后，她找到了关押她最好朋友的营地。原来有两个绑匪：一位强大的骑士和一个狡猾的弓箭手。

找到绑匪后，Annalyn 考虑自己能采取以下哪些行动：

- _快速攻击_：如果骑士在睡觉，就可以发动快速攻击，因为他穿上盔甲需要时间，所以会处于脆弱状态。
- _侦查_：只要三人中至少有一个人醒着，就可以侦查他们。否则，侦查只是浪费时间。
- _给囚犯发信号_：如果囚犯醒着而弓箭手在睡觉，就可以用鸟叫声给囚犯发信号；因为弓箭手受过鸟语信号的训练，他们可能会截获消息。
- _救出囚犯_：Annalyn 可以试着潜入营地救出囚犯。
  这样做风险很大，只有两种方式之一能成功：
  - 如果 Annalyn 带着她的宠物狗，那么只要弓箭手睡着了，她就能救出囚犯。
    骑士怕狗，而弓箭手来不及准备好，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没带狗，那她和囚犯就必须非常小心！
    如果囚犯醒着，而骑士和弓箭手都在睡觉，Annalyn 就能救出囚犯；但如果囚犯在睡觉，就没法救他：囚犯会被 Annalyn 突然出现吓到，然后吵醒骑士和弓箭手。

你有四个任务：根据在森林里遇到的三个人物的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可行的逻辑。

## 1. 检查能否发动快速攻击

实现`can_fast_attack()`方法，它接受一个布尔值，表示骑士是否醒着。如果根据骑士的状态可以发动快速攻击，该方法就返回`TRUE`；否则返回`FALSE`：

```R
knight_is_awake <- TRUE
can_fast_attack(knight_is_awake)
# => FALSE
```

## 2. 检查能否侦查这群人

实现`can_spy()`方法，它接受三个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。如果根据这三个人物的状态可以侦查他们，该方法就返回`TRUE`；否则返回`FALSE`：

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
can_spy(knight_is_awake, archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 3. 检查能否给囚犯发信号

实现`can_signal_prisoner()`方法，它接受两个布尔值，分别表示弓箭手和囚犯是否醒着。如果根据这两个人物的状态可以给囚犯发信号，该方法就返回`TRUE`；否则返回`FALSE`：

```R
archer_is_awake <- FALSE
prisoner_is_awake <- TRUE
can_signal_prisoner(archer_is_awake, prisoner_is_awake)
# => TRUE
```

## 4. 检查能否救出囚犯

实现`can_free_prisoner()`方法，它接受四个布尔值。前三个形参分别表示骑士、弓箭手和囚犯是否醒着。最后一个形参表示 Annalyn 的宠物狗是否在场。如果根据这三个人物的状态以及 Annalyn 是否带着宠物狗可以救出囚犯，该方法就返回`TRUE`；否则返回`FALSE`：

```R
knight_is_awake <- FALSE
archer_is_awake <- TRUE
prisoner_is_awake <- FALSE
pet_dog_is_present <- FALSE
can_free_prisoner(knight_is_awake, archer_is_awake, prisoner_is_awake, pet_dog_is_present)
# => FALSE
```
