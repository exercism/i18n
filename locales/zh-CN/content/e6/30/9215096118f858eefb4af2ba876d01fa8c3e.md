# 简介

[区间][range]表示两个值之间的间隔。
区间常与`Int`、`String`、`Character`等类型搭配使用，用来遍历序列、对集合进行切片，或者检查某个值是否落在区间内。

Swift 提供了两种主要的区间运算符：

- **闭合区间运算符（`...`）：**同时包含起始值和结束值（`1...5` 包含 1、2、3、4 和 5）。
- **半开区间运算符（`..<`）：**包含起始值，但不包含结束值（`1..<5` 包含 1、2、3 和 4）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

~~~~exercism/note
直接在区间字面量上调用方法时，要把区间表达式用括号括起来，这样编译器会先计算区间：

```swift
(1...5).contains(3) // Returns true
// 1...5.contains(3) // Error: value of type 'Int' has no member 'contains'
```
~~~~

## 将区间转换为数组

你可以使用`Array(_:)`构造器，把一段数字区间转换成`Array`：

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 用区间对数组进行切片

你可以用区间切出数组的某个子片段：

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 区间的属性和方法

区间上常见的操作包括：

| 成员                  | 说明                                                | 示例                              |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 返回区间中元素的数量                | `(1...5).count` 返回`5`          |
| [`contains(_:)`][contains] | 如果区间包含指定的值，就返回`true` | `(1...5).contains(3)` 返回`true` |

## 单侧区间

Swift 还支持单侧（部分）区间，也就是省略起始值或结束值：

- `array[2...]`：从下标 2 到集合末尾。
- `array[...2]`：从集合开头一直到下标 2，包含下标 2。
- `array[..<2]`：从集合开头一直到下标 2，但不包含下标 2。

## 字符串区间和字符区间

也可以在符合`Comparable`的字符或字符串之间创建区间：

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
