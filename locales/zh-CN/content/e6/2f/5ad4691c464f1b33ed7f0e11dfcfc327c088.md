## 数组

Elm 中的`List`是一种不可变的集合，包含零个或多个同一类型的值。

数组可以这样定义：

```elm
empty = []
singleValue = [ 5 ]
threeValues = [ "a", "b", "c" ]
```

向数组中添加元素最常见的方式，是使用`::`（cons）运算符：

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [ 1, 2, 3, 4 ]
```

数组通过定义在 [`List` 模块][list-module] 中的函数和运算符来操作，也可以通过[模式匹配][list-destructuring]来操作：

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
