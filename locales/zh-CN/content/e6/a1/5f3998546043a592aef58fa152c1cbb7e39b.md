# 说明

学校话剧的试镜已经结束，导演需要把决定写下来。

四项任务都写在 `CASTING_CALL` 类里。

## 1. 判定结果

每位表演者都按十分制打分。八分及以上就录取；五到七分进入复试；低于五分则向他们致谢。

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. 属于哪个组？

13 岁以下的表演者是 Juniors。13 到 15 岁是 Middles。16 岁及以上是 Seniors。

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. 什么时候回来

Juniors 在四点复试，Middles 在五点，其他人都在六点。

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

参数是组的名称，拼写必须与任务 2 完全一致。

## 4. 表格上写什么

得分八分及以上、并且会唱歌的人是`"Lead"`。八分及以上但不会唱歌是`"Speaking part"`。其他所有人都算`"Chorus"`。

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
