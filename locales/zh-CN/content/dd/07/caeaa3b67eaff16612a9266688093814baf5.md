# 关于

## 简介

泛型是一种支持代码复用的语言特性。
例如，计算一个数组的长度时，数组中存放的是哪种类型并不重要。
所以 `length` 函数的类型签名中使用了泛型类型参数 `a`。

```elm
length : List a -> Int
```

## 类型中的参数

当一个类型对另一个类型泛型时，我们用小写名称来表示那另一个类型，并称之为类型参数。
常见的例子是 `List`、`Maybe` 和 `Result` 这些自定义类型。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

关于类型参数的名称，有一点很重要：它们可以由多个字符组成。
唯一的约束是必须使用小写名称。
因此，在有用的时候，我们倾向于给它们起描述性的名称。

一个类型可以同时对多个其他类型泛型，因此可以有多个类型参数。
在这种情况下，每个相互独立的类型都会获得一个不同的小写名称。
相互独立并不妨碍它们最终成为同一个类型，只是允许它们可以不同。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

记录类型别名也可以有类型参数，虽然不太常见。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

> 这就是 `Html` 包定义 `Html msg` 类型的原因，它有一个名为 `msg` 的类型参数。
> Elm 架构会引导你创建一个自定义类型 `Msg`，用来描述你的网页可以触发的所有消息。
> 于是，你的代码构建出的视图类型是 `Html Msg`，其中 `Msg` 是你定义的具体类型。
> 初学者有时会分不清提到 `Html msg`（小写）的错误和出现 `Html Msg` 的错误。
> 现在你明白了！
> 区别在于，前者对任意 `msg` 类型泛型，而后者则专属于你定义的 `Msg` 类型。

## 函数中的类型参数

既然类型可以是泛型的，函数也可以。
可以编写处理泛型类型的函数，例如 `Maybe.withDefault`。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

把其他函数作为参数的函数称为高阶函数，它们也可以是泛型的。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```

类型参数既可以出现在函数的输入中，也可以出现在输出中，由类型参数实现的泛型通常称为**参数化多态**。
这与特设多态（也称为函数重载）形成对比，后者中同一个函数名可以用于多个类型不同的实现。
这与子类型多态也形成对比，在后者的体系中类型可以定义在一个层级结构中，定义在某个类型上的函数也可以用它子类型的实参来调用。
在 Elm 中，唯一可用的泛型机制就是参数化多态。
