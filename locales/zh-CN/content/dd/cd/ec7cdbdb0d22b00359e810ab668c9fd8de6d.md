# 说明

在这个练习中，你需要实现一些函数，用来操作一个编程语言数组。

## 1. 定义一个返回空语言数组的函数

定义`new`函数，它不接受任何实参，并返回一个空数组。

```haskell
new
-- -> []
```

## 2. 定义一个向数组中添加语言的函数

定义`add/2`函数，它接受 2 个实参（一个_语言数组_和一个_语言_的字符串字面量）。
它应该返回一个新数组，把新语言添加到给定数组的最前面。

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. 定义一个从数组中删除语言的函数

定义`remove`函数，它接受 1 个实参（一个_语言数组_）。
它应该返回去掉第一个元素后的数组。假设数组中至少有一个元素。

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. 定义一个返回数组中第一个元素的函数

定义`first`函数，它接受 1 个实参（一个_语言数组_）。
它应该返回数组中的第一个语言。
假设数组中至少有一个元素。

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. 定义一个返回数组中有多少种语言的函数

定义`count`函数，它接受 1 个实参（一个_语言数组_）。
它应该返回数组中语言的数量。

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. 定义一个判断数组是否包含函数式语言的函数

定义`isFunctionalList`函数，它接受 1 个实参（一个_语言数组_）。
它应该返回一个布尔值。
如果_"Haskell"_是数组中的语言之一，它应该返回`True`。

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
