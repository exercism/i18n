# 关于

Go 提供了一个名为 `fmt`（格式化包）的内置包，其中包含各种用于处理输入输出格式的函数。
最常用的函数是 `Sprintf`，它使用像 `%s` 这样的*动词*把值插入字符串，并返回这个字符串。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

在 Go 中，浮点数可以方便地用 Sprintf 的动词来格式化：`%g`（紧凑表示）、`%e`（指数）或 `%f`（非指数）。这三个动词都允许控制字段的宽度和数值位数。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

你可以在[格式化包文档][fmt-docs]中找到所有可用动词的完整列表。

`fmt` 还包含其他处理字符串的函数，比如 `Println` 只是把接收到的实参打印到控制台，而 `Printf` 会先按照 `Sprintf` 的方式格式化输入，然后再打印出来。

[fmt-docs]: https://pkg.go.dev/fmt
