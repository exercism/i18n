# 指令补充

## 实现说明

Cipher 接口的定义位于`cipher.go`中。

你的实现必须符合 Cipher 接口。

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

`Encode` 应忽略字符串中所有不属于 A-Za-z 的字符，它们不会出现在输出中。
输出也会被统一转换为小写。

用于获取密码器的函数如下：

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

`NewShift` 的参数必须在 1 到 25 或 -1 到 -25 的范围内。
不允许为 0。
参数无效时，`NewShift` 返回 nil。

`NewVigenere` 的参数只能由小写字母 a-z 组成。
完全由字母 'a' 组成的值是不允许的。
参数无效时，`NewVigenere` 返回 `nil`。
