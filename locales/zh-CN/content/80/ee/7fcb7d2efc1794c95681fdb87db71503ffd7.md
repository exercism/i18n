# Bash 花田练习的提示

这个练习看起来需要用到二维数组。
Bash 只提供一维的索引数组或关联[数组][array]。

多维数组可以通过关联数组来模拟：把各个下标编码成一个用逗号分隔的字符串，作为数组的键。

```bash
# store this matrix:
#   a b
#   c d
declare -A array2d
array2d["0,0"]="a"
array2d["0,1"]="b"
array2d["1,0"]="c"
array2d["1,1"]="d"
```

[array]: https://www.gnu.org/software/bash/manual/bash.html#Arrays
