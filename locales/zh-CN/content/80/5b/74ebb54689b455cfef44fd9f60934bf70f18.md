# 字符

`CHAR`是一个字符，写在单引号之间。

```sather
   c : CHAR := 'M';
```

## 特殊字符

有些字符无法直接输入，需要用反斜杠表示：

| 写法 | 表示 |
| --- | --- |
| `'\n'` | 换行符 |
| `'\t'` | 制表符 |
| `'\''` | 单引号 |
| `'\\'` | 反斜杠 |

## 判断

```sather
'M'.is_alpha      -- true
'7'.is_digit      -- true
'M'.is_upper      -- true
' '.is_space      -- true
'M'.is_alphanum   -- true, a letter or a digit
```

## 大小写

`.upper`和`.lower`会改变字母的大小写，其他字符保持不变，所以可以放心地用在尚未检查过的字符上。

## 数字

```sather
'a'.int           -- 97
97.char           -- 'a'
```

`.int`和`.char`正好相反。关于编号，有用的事实是：`'a'`到`'z'`依次连续，`'A'`到`'Z'`依次连续，`'0'`到`'9'`也依次连续。因此：

```sather
   c.int - 'a'.int          -- how far c is along the alphabet
   ('a'.int + n).char       -- the letter n places along
   d.int - '0'.int          -- the value of a digit character
```

## 回绕

密码轮转过`z`后会绕回`a`。`%`正是这样做的：

```sather
   ('a'.int + (c.int - 'a'.int + places) % 26).char
```

Sather 的`%`在右侧为正数时从不会返回负数，因此无论是向前还是向后转动密码轮，这都适用。

## 字符和字符串

`STR`是一串字节，而`CHAR`是一个字节。对于英文文本，一个字节就是一个字母，所以`"Marlowe".size`为 7，而`"Marlowe"[0]`是`'M'`。对于带重音符号或其他字母表的文本，一个字母可能占多个字节，上面两种情况都不成立。
