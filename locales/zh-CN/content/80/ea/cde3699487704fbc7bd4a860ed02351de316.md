# 简介

`Rational numbers`是分数，由一个整数分子除以一个整数分母构成。

例如，我们可以把`2//3`存成精确的分数，而不是近似的`Float64`值`0.6666...`。

这样做的好处是，除了*整数溢出*这种极端情况，有理数都能保持精确，避免浮点数常常无法避免的舍入误差。

有理数是一种相当简单的数值类型，用法基本符合你的预期。由于从早期版本开始它就是 Julia 的标准类型，大多数函数都会像接受整数和浮点数那样，接受它作为输入。

## 创建有理数

创建很简单，只要在两个整数之间使用`//`即可。

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

公因数会自动约去，把分数化成“最简形式”：能准确表示该分数的最小整数，并且分母非负。

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## 有理数的算术运算

常用的`arithmetic operators` `+ - * / ^ %`都能用于有理数，效果与其他数值类型基本相同。

表达式中可以包含整数和其他`Rational`，结果仍是`Rational`。如果表达式中含有`float`，结果就是`float`，精度也会随之（可能）损失。

如果需要`float`，用`float()`函数把有理数转换一下即可。通常的做法是：用有理数在漫长的计算过程中保持精度，最后再转换成浮点数。

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## 其他运算

在 Julia 中，有理数就是数字。编译器通常会按需转换类型。

不过要注意，比较只在分数具有有限小数表示时才成立：

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

除此之外，比较时应先把`Rational`转换成`Float`：

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

数学函数可以接受有理数作为输入，但可能返回浮点数结果：

```julia-repl
julia> sqrt(9//16)
0.75
```
