# 简介

## R 中的布尔值

`logical`类型表示真或假的值。它只包含两个值：`TRUE`和`FALSE`。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 布尔运算符

R 中共有五个布尔运算符，但教学大纲的这个阶段只会用到其中三个。另外两个在处理向量时很重要，会在后面的几个概念中讲到。

`&&`是布尔“与”。如果`&&`*两侧*的表达式都是`TRUE`，整个表达式的值就是`TRUE`。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||`是布尔“或”。如果`||`*任意一侧*的表达式是`TRUE`，整个表达式的值就是`TRUE`。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!`是布尔“非”。它会把`TRUE`和`FALSE`互换。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

对于更长、更复杂的表达式，最好用括号把意图表达清楚。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
