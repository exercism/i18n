# 提示

为了帮助理解：这个练习用复数来表示网格上的交叉口。由于复数可以看成由两个数组成的一对，所以也可以把它想象成二维的 x-y 平面，其中 x 轴 = 实轴，y 轴 = 虚轴。

## 1. 简单的复数

- 这是一个简单的包装函数。
- 关于如何使用变量创建复数，参见“简介”。
- 注意，如果不使用关键字参数，`complex()` 的位置参数可能和你想的不一样。

## 2. 获取司机的行驶方向

- 这个函数只需要一次数学运算。
- 运算的顺序很重要（也就是说，它不是对称的）。

## 3. 计算曼哈顿距离

- 记住，这是出租车沿着网格线行驶时经过的交叉口总数（不包括起始交叉口）。
- 你的`driver_directions`函数会很有帮助。
- 其他可能有帮助的函数还有 [`Re()`和`Im()`][complex-ref]。

## 4. 计算“乌鸦直线飞行”距离

- 这是两个交叉口之间的直线距离。
- 你可以把它看成一段只拐一次弯的曼哈顿路径所构成的斜边。
- 它也叫做[欧几里得距离][euclid-ref]，或者 L2 范数。
- 你的`driver_directions`函数也会很有帮助。
- 关于另一个可以用来求模的复数函数，参见“简介”。

## 5. 获取乌鸦的飞行方向

- 你的`driver_directions`函数会很有用。
- 这个函数会把司机行驶方向中的南北方向翻转过来。
- 这样就会把感知到的位置沿“x 轴”翻转。
- 关于另一个可以选择使用的函数，参见“简介”。

[complex-ref]: https://www.rdocumentation.org/packages/base/versions/3.5.3/topics/complex
[euclid-ref]: https://en.wikipedia.org/wiki/Euclidean_distance
