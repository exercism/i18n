# 只读类和属性

只读属性和类让类可以声明公开属性，方便外部访问，同时又能防止被修改。
要把某个属性声明为只读，需要在类型声明前加上`readonly`。
该属性只允许被赋值一次，此后任何重新赋值或修改值的尝试都会导致错误。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length;
        public readonly int $width;
    ) {
    }
}
```

只读类在此基础上更进一步：如果类被声明为`readonly`，每个属性都会自动应用只读声明。
此外，它还会禁止添加动态属性。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length;
        public int $width;
    ) {
    }
}
```
