# 介绍

继承是面向对象编程（OOP）中的一个核心概念，表示一种 IS-A（是一个）关系。它在编程中的含义和在英语中字面上一样：从父级那里继承特性（在编程中，特性通常指函数和变量）。

考虑下面这个 `Animal` 类：

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` 是一个父类，因为这个类拥有的属性可以扩展到所有动物。

考虑一种名叫 `Lion` 的动物，它的类是这样：

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
`Override` 注解用于表示子类中的某个方法正在重写其超类的方法。
它并非严格必需，但使用它是一种最佳实践。
~~~~

现在，每当我们这样写：

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

注意：用 `Lion` 初始化 `Animal` 类。
输出将会是

```java
Lion here!!
```

按照面向对象编程的说法，继承有很多种类型，但 Java 只支持其中一部分（多级继承和层次继承）。
想了解更多，请阅读[这篇文章][java-inheritance]。
