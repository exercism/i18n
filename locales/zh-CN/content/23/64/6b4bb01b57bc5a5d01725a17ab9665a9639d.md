# 关于

C# 的 [`Attribute`][attribute-concept]提供了一种修饰声明的方式，可以把元数据关联到类、方法、枚举、字段、属性或任何[其他受支持的][attribute-targets]声明上。

你可以把[特性][attribute]放在声明前的方括号`[]`里，把它应用到该声明上。下面这个例子同时用到了 `ClassAttribute` 和 `FieldAttribute`：

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

这种声明式元数据只是把额外的结构化信息关联到代码上，并不会改变代码的行为。但代码的其他部分会利用这些元数据来改变目标的行为，或者增加、修改、删除、限制它的某些功能。

预定义特性有很多，例如：`Flags`、`Obsolete`、`Conditional`。注意，[`Flags`特性][flags-attribute]的全名是 `FlagsAttribute`，不过使用时可以省略“Attribute”后缀。

以下四个预定义特性经常会被用到：

- `[Flags]`：在 System 命名空间中预定义。表示该枚举既支持按位运算，也支持方法`Enum.HasFlag()`，此外，`ToString`会显示所有标志：[见示例][flags-example]。
- `[Obsolete]`：在 System 命名空间中预定义。可以添加一条说明代码为何过时的消息，用来显示编译器警告或错误。
- `[Conditional]`：在 System.Diagnostics 命名空间中预定义。可以在编译时移除某些方法调用，用于调试（诊断）。
- `[CallerMemberName]`：在 System.Runtime.CompilerServices 命名空间中预定义。可以让方法获取其调用方的信息。
