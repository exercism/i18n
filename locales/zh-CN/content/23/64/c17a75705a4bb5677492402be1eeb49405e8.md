# 关于

`jq` 是一个用于解析和转换 JSON 数据的工具。
`jq` 之于 JSON 数据，就像 `sed` 之于文本：你可以像用`sed`、`awk`、`grep`等工具处理文本那样，轻松地对结构化数据进行切片、过滤、映射和转换。

`jq` 是一门动态类型的函数式编程语言。
所有值都是不可变的。

`jq` 程序由一条条“过滤器”组成的管道构成：每个过滤器接收单个项作为输入，对它进行处理，并输出零个或多个转换后的元素。
“过滤器”也可以称为“表达式”。

一个表达式的输出可以通过`|`运算符传递给另一个表达式。
`expressionA | expressionB` 会先把`expressionA`应用到某个输入上，然后针对`expressionA`的每个输出反复执行`expressionB`。

表达式的输入可以用`.`显式引用。
一个把输入加上`1`的表达式是这样写的：`. + 1`（也可以写成`1 + .`）。

## `jq`（程序）与`jq`（语言）

`jq` 是一个程序，你可以在各种操作系统上把它作为软件包安装，也可以从源代码构建（它是用 C 写的）。
它有不少实用的[命令行选项][cli-options]，而且速度相当快。

`jq` 这个程序还实现了一门_语言_，让你能对输入数据进行任意复杂的操作。

这条 Exercism 学习路径聚焦的是这门语言。
你会在测试中看到`jq`程序的用法。

## JSON

摘自 [json.org][json]：

> JSON（JavaScript Object Notation）是一种轻量级的数据交换格式。
> 它易于人类阅读和编写。
> 它易于机器解析和生成。
> 它基于 JavaScript 编程语言标准 ECMA-262 第 3 版（1999 年 12 月）的一个子集。
> JSON 是一种完全与语言无关的文本格式，但它使用的约定对 C 语言家族的开发者来说很熟悉，包括 C、C++、C#、Java、JavaScript、Perl、Python 等众多语言。
> 这些特性使 JSON 成为理想的数据交换语言。

这条学习路径讲的是`jq`，而不是 JSON。
我们假定你已经熟悉 [JSON 语法和数据类型][wiki-json]。
