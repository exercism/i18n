# 说明

你的一位朋友经营着一家叫**Gross Store**的老式批发店。
店名来自店里售卖商品的计量单位：全都以 [gross 单位][gross-unit] 计。
你的朋友请你为他的店实现一套销售点（POS）系统。
**首先，你要为它做一个原型。**
**在原型中，你的系统只记录数量。**
你的朋友给了你一份计量单位列表来帮你：

| 单位               | 数值 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 在程序中存储计量单位

要使用这些计量单位，你需要把它们存到程序中。

```go
units := Units()
fmt.Println(units)
// Output: map[...] with entries like ("dozen": 12)
```

## 2. 为顾客新建一份账单

你需要实现一个函数，为顾客创建一份新的（空）账单。

```go
bill := NewBill()
fmt.Println(bill)
// Output: map[]
```

## 3. 向顾客账单中添加商品

为此，你需要：

- 如果给定的`unit`不在`units`映射中，返回`false`。
- 否则把商品加入顾客的`bill`，以商品名作为键，然后返回`true`。
- 如果该商品已经在账单中，就按给定`unit`对应的数量增加它的数量。

```go
bill := NewBill()
units := Units()
ok := AddItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: true (since dozen is a valid unit)
```

> 注意，返回值的类型是`bool`。

## 4. 从顾客账单中移除商品

为此，你需要：

- 如果给定的商品**不在**账单中，返回`false`。
- 如果给定的`unit`不在`units`映射中，返回`false`。
- 如果新的数量会小于 0，返回`false`。
- 如果新的数量是 0，就把该商品从`bill`中彻底移除，然后返回`true`。
- 否则，减少该商品的数量并返回`true`。

```go
bill := NewBill()
units := Units()
ok := RemoveItem(bill, units, "carrot", "dozen")
fmt.Println(ok)
// Output: false (because there are no carrots in the bill)
```

> 注意，返回值的类型是`bool`。

## 5. 返回顾客账单中某个商品的数量

为此，你需要：

- 如果`item`不在账单中，返回`0`和`false`。
- 否则，返回该商品在`bill`中的数量和`true`。

```go
bill := map[string]int{"carrot": 12, "grapes": 3}
qty, ok := GetItem(bill, "carrot")
fmt.Println(qty)
// Output: 12
fmt.Println(ok)
// Output: true
```

> 注意，返回值的类型是`int`和`bool`。

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
