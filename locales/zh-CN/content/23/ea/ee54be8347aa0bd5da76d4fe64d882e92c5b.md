# 介绍

[数组][arrays-concept]内置了一些方法，可以用来分析数组的内容。
这些方法大多接受一个返回 true 或 false 的函数作为实参。
这样的函数被称为[`predicate`][predicate_in_programming]。

这些内置方法的用途，是_用来替代`for`循环_或内置的`forEach`方法：

使用 for 循环进行分析的示例：

```javascript
const numbers = [1, 'two', 3, 'four'];
for (var i = 0; i < numbers.length; i++) {
  if (numbers[i] === 'two') {
    return i;
  }
}
// => 1
```

使用内置方法进行分析的示例：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.indexOf('two');
// => 1
```

下面还列出了一些可用于分析数组的内置方法。完整的数组方法列表请参见 [MDN][mdn-array-methods]。

## `includes`

> includes() 方法用来判断数组是否包含某个值，并根据情况返回 true 或 false。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.includes(1);
// => true
numbers.includes('one');
// => false
```

## `every`

> every() 方法用来检测数组中的所有元素是否都能通过所提供函数的测试。它返回一个布尔值。[^2]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.every((num) => num % 2 !== 0);
// => true
```

## `some`

> some() 方法用来检测数组中是否至少有一个元素能通过所提供函数的测试。[^3]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.some((num) => num % 2 !== 0);
// => true
```

## `find`

> find() 方法返回所提供数组中第一个满足所提供测试函数的元素的值。如果没有值满足该测试函数，则返回 undefined。[^4]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.find((num) => num < 5);
// => 1
```

## `findIndex`

> findIndex() 方法返回数组中第一个满足所提供测试函数的元素的下标。否则返回 -1，表示没有元素通过测试。[^5]

```javascript
const numbers = [1, 3, 5, 7, 9];
numbers.findIndex((num) => num > 7);
// => 4
numbers.findIndex((num) => num > 9);
// => -1
```
