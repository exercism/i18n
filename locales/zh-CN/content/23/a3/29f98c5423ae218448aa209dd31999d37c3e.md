# 数据库支付审计

## 问题描述

ABC Corp 需要你把 SQL 数据库中的所有数据加载到 [Ballerina 表](https://ballerina.io/learn/by-example/table-syntax/)中，以便进一步处理。然后，你需要通过查询加载好的 Ballerina 表，找出支付金额大于给定金额（例如 3000.00）的员工姓名。

**第 1 步：**

创建一个包含以下列的 Ballerina 表。

`payment_id` - 整数

`amount` - 浮点数

`employee_name` - 字符串

**第 2 步：**

通过加载 H2 数据库中对应的完整数据集，向上述 Ballerina 表中填充数据。使用`payment_id`作为该表的主键。

**第 3 步**

使用 Ballerina 查询表达式查询 Ballerina 表，找出支付金额大于给定金额的员工姓名。按员工姓名升序排列结果。返回之前去掉结果中重复的姓名。

> 注意：实现提交的解答时，必须使用 Ballerina 表。

## 数据库详情

本题请使用提供的 H2 数据库。

> 示例数据库文件是`gofigure.mv.db`，数据库名是`gofigure`。它位于`db`文件夹中。

示例 H2 数据库中已经有以下表，其中包含一些示例数据。列名和数据类型如下。

**表名**：`Employee`

| **列：**      | 类型 |
| -----------       | ----------- |
| `employee_id`     | 整数，自增主键       |
| `name`            | 字符串        |
| `city`            | 字符串        |
| `department`      | 字符串        |
| `age`             | 整数        |

**表名**：`Payment`

| **列：**      | 类型 |
| -----------       | ----------- |
| `payment_id`      | 整数，自增主键       |
| `date`            | 日期        |
| `amount`          | 浮点数        |
| `employee_id`     | 整数        |
| `reason`          | 字符串        |

* 数据库文件是`gofigure.mv.db`。JDBC URL 使用`jdbc:h2:file:/path/to/db/file`
* 用户名：`root`
* 密码：`root`

## 限制条件

* 使用`db`文件夹中提供的 H2 数据库文件来验证查询和 Ballerina 示例
* 使用 maven 依赖参数的方式，在 Ballerina.toml 中添加 H2 数据库驱动作为平台依赖

## 测试环境

* 你可以用`bal test`运行测试，它会针对给定的示例数据库运行测试。

## 示例

### 示例 1

**输入：**dbFilePath：`“/Path/to/file/gofigure”`，amount：`3000`

**输出：**`["Amanda Hug", "Anita Bath"]`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模块来操作数据库
* 关于如何添加 JDBC 驱动作为依赖，请参阅[先决条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)一节
* 使用 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 远程方法从数据库中查询数据
* 参考[简单查询](https://ballerina.io/learn/by-example/mysql-query-operation)示例
* 参考[表语法](https://ballerina.io/learn/by-example/table)示例
* 使用[查询表](https://ballerina.io/learn/by-example/querying-tables)从 Ballerina 表中找出所需的数据
