# 提示

## 1. 创建服装单品

- 有些函数可以用推导式语法来构造。
- `Dict`就是这样一种函数，复习简介中的**生成器表达式**。
- 下标为`i`的类别与下标为`i`的品质相匹配（[eachindex()][index] 可能会有用）

## 2. 推荐组合

- 有一种简洁的语法可以从推导式创建多维数组。
- 复习简介中的**多变量、多维输出**。
- 确保迭代器（`tops` / `bottoms`）的顺序正确。

## 3. 计算服装搭配总价

- 你需要获取两件衣物的价格，然后把它们相加。
- 确保输出数组的形状与输入数组的形状相同。
- 复习简介中的**单变量**。

## 4. 过滤掉冲突的服装搭配

- 你需要比较两件衣物的`base_color`，并丢弃`base_color`相同的服装搭配。
- 当输入为`Matrix`时，确保输出采用最高效的顺序（即列主序）。
- 复习简介中的**单变量**。
