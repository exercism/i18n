# 简介

在 C# 中，可以使用_继承_来定义_类_的层次结构，它允许派生类（`Car`）继承父类（`Vehicle`）的行为和数据。如果没有指定父类，该类就继承自`object`类。

父类可以通过三种方式为派生类提供功能：

- 定义一个普通方法。
- 定义一个`virtual`方法，它类似普通方法，但派生类_可以_修改它。
- 定义一个`abstract`方法，它是一种没有实现的方法，派生类_必须_实现它。含有`abstract`方法的类也必须标记为`abstract`。抽象类不能被实例化。

`protected`访问修饰符允许在派生类中访问父类成员，但会阻止其他类访问。

派生类可以通过`base`关键字访问父类成员。

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

派生类的构造函数会在执行自身构造函数的逻辑_之前_自动调用父类的构造函数。使用`base`关键字，可以把实参传给父类的构造函数：

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

当一个基类派生出多个类时，这两个（或更多）类往往会以不同方式实现基类的同一个方法。这就是一个非常重要的原则，叫做多态。例如，在上例的一个变体中，我们展示使用`Vehicle`的代码如何根据实例化的是哪种交通工具而改变自己的行为。

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
