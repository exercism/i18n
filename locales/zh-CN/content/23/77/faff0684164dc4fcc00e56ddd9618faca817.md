# Introduction

## Default parameter values

通过在形参列表中该形参的类型标注后面给它赋值，就可以为函数的任意形参提供[默认形参值][default-parameter-values]。指定了默认形参值后，调用方在调用函数时就可以省略该形参，此时会改用默认值。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Variadic parameters

Swift 中的[_可变参数_][variadic-parameters]允许把零个或多个同类型的值传入函数中的单个形参。做法是在该形参的类型标注后面加上`...`。

这些值会自动归组为一个数组，其中的元素类型与可变参数的类型相同。

```swift
func geometricMean(_ numbers: Double...) -> Double {
  var total = 1.0
  for number in numbers {
      total *= number
  }
  return pow(total, 1.0 / Double(numbers.count))
}

geometricMean(1, 2, 3, 4, 5)
// => 2.605171084697352
```

注意，使用可变参数时，Swift 有一项限制。如果函数定义中在可变参数之后还有形参，那么紧随可变参数之后的第一个形参_必须_带有实参标签。

## In-out parameters

在函数体内，形参被视为常量而非变量；试图修改某个形参的值会引发编译期错误。如果函数想要修改某个形参的值，就必须使用[_输入输出参数_][in-out-parameters]，把这种可变性明确表达出来。

要使用输入输出参数，程序员必须确保三件事：

1. 函数定义必须显式标记输入输出参数：在该形参的类型标注中，把关键字`inout`写在`:`和类型名之间。
2. 传入输入输出参数的值必须声明为变量，而不能是常量。同样，它也不能是字面量。
3. 在调用函数时，变量名前面必须加上`&`，明确表示它可被修改。

做到这些之后，函数会在内部复制一份该输入输出参数，按函数体中的指示修改这份副本，然后在函数返回时把修改后的值复制回传入的那个变量。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
关于输入输出参数，还有几条额外的规则需要注意。

1. 在带有输入输出参数的函数内部，不允许引用作为输入输出参数传入的那个变量。
2. 在同一个函数中，不能把同一个变量作为多个输入输出参数传入。
   例如，`inoutFunc(&mutVar, &mutVar)`会引发编译错误。
~~~~

## Nested functions

在 Swift 中，你可以在其他函数内部[定义函数][nested-functions]。这类函数称为**嵌套函数**。

嵌套函数通常用作私有辅助函数，为外层函数完成特定任务，同时不会让外层作用域变得杂乱：

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

嵌套函数的行为和标准函数一样，但它的可见范围仅限于外层函数体。
