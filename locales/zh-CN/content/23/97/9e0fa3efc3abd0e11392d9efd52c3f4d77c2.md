# 说明

作为一名初出茅庐的魔术师，Elyse 需要以许多不同的方式分析自己的牌组。
为了简单起见，她只用点数为 1-10 的牌。

## 1. 确定牌组中有多少张某种类型的牌

Elyse 想知道自己的牌组里有多少张特定类型的牌。

编写一个函数 `cardTypeCheck`，它接收两个形参：一个牌的数组（Elyse 的牌组）和要统计的牌的类型。

<!--prettier-ignore -->
~~~exercism/note
该函数应使用 `forEach`，并返回牌组中指定类型的牌的数量。
~~~

```javascript
const cardType = 3;
cardTypeCheck([1, 2, 3, 4], cardType);
// => 1
```

## 2. 确定有多少张奇数牌或偶数牌

为了表演另一个魔术，Elyse 需要知道自己的牌组里有多少张奇数牌或偶数牌。

实现一个函数 `determineOddEvenCards`，它接收两个形参：一个牌的数组（Elyse 的牌组）和一个布尔值（true 相当于“偶数”，false 相当于“奇数”）。

这个函数应返回一个数字：牌组中奇数牌或偶数牌的数量（取决于第二个实参的值）。

<!--prettier-ignore -->
~~~exercism/note
为了练习，这次的函数实现请使用 `for...of` 循环。
~~~

```javascript
determineOddEvenCards([1, 2, 3, 1, 5, 6], true);
// => 2

determineOddEvenCards([1, 2, 3, 1, 5, 6], false);
// => 4
```
