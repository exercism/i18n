# 关于 Odin

[Odin 语言][odin-website]是一门静态类型的命令式语言，旨在成为 C 语言实用而现代的后继者。
[GingerBill][gb]是 Odin 的创造者，他想要一门实用的语言，既能解决 C 语言的大部分烦人之处，又能提供同样贴近底层、面向性能的体验。

Odin 的设计原则：

- 简单：一致、安全、易用的语法。
- 高性能：对内存和数据布局的显式控制
- 为现代系统而设计
- 找回编程的乐趣

Odin 是一门系统编程语言，与 C、Go、Nim 和 Zig 属于同一类别。
与 Go 和 Nim 不同，Odin 采用手动内存管理：程序员必须分配内存，然后自行释放。
Odin 的内置机制让这一点变得相当简单。

Odin 的编译器套件“自带电池”：既有规模可观的标准库，也有一系列面向游戏和图形的库，例如 OpenGL、SDL、Direct-X 和 Raylib。

来学习 Odin 吧：它承诺让你以比传统系统语言更清晰、更少摩擦的方式，构建高性能应用。
