# 简介

## 布尔值

Gleam 用`Bool`类型表示 true 和 false 值。只有两个值：`True`和`False`。这些值可以绑定到变量：

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`和`!`运算符可用于操作布尔值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`运算符采用短路求值，也就是说，只有当需要时，才会对运算符右侧的表达式求值。

每个运算符的优先级都不同，其中`!`会先于`&&`和`||`求值。可以使用大括号让表达式的某一部分先于其他部分求值：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
