# 简介

数组是 Elixir 语言内置的类型。它属于基本类型，用方括号表示。数组可以是空的，也可以包含任意数量、任意类型的元素。例如：

```elixir
empty_list = []
one_item_list = [1]
two_item_list = [1, 2]
multiple_type_list = [1, :pi, 3.14, "four"]
```

Elixir 用链表来实现数组：每个节点存储两个值，第一个元素，以及一个包含其余所有元素的数组。数组中的第一个元素称为_头_，其余元素组成的数组称为_尾_。我们可以在代码里使用这种写法：

```elixir
# [1] represented in [head | tail] notation
[1 | []]

# [1, 2, 3] represented in [head | tail] notation
[1 | [2 | [3 | []]]]
```

我们可以用_`[head | tail]`_这种写法把元素添加到数组的开头：

```elixir
# Suppose
list = [2, 1]

[3, 2, 1] == [3 | list]
# => true
```

`Kernel` 模块里有多个处理数组的函数，此外还有完整的 `List` 模块。

```elixir
# Check if 1 is a member of the list
1 in [1, 2, 3, 4]
# => true
```
