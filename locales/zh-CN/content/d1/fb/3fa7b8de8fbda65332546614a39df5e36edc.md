# 补充说明

## 提示

你需要实现`responseFor`函数，它根据给定的输入返回 Bob 的回应。如果不确定类型，可以参考给出的签名，但不要让它限制你的创造力：

```haskell
responseFor :: String -> String
```

要解决这个练习，你可以先了解：

- [守卫][guards]

[guards]: https://www.futurelearn.com/courses/functional-programming-haskell/0/steps/27226

本练习处理文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是一个字符数组。为了更高效地处理文本数据，可以使用`Text`类型。

作为本练习的可选扩展，你可以

- 阅读 Haskell 中关于[字符串类型](https://haskell-lang.org/tutorial/string-types)的内容。
- 在 package.yaml 的依赖列表中添加`- text`。
- 按[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

    ```haskell
    import qualified Data.Text as T
    import           Data.Text (Text)
    ```

- 现在你可以写`responseFor :: Text -> Text`这样的代码，也可以用`T.isSuffixOf`这样的方式引用`Data.Text`的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档，
- 然后你可以在 Bob.hs 中把所有出现的`String`替换为`Text`：

    ```haskell
    responseFor :: Text -> Text
    ```

这部分完全可选。
