# 运行测试

安装好`sbt`后，就可以在命令行中运行测试：

```bash
$ sbt test
```

注意，每次都执行`sbt test`会很慢，因为每次调用都会重新初始化`sbt`。

`sbt`用起来就像一个 shell：启动之后，你就可以在里面运行各种命令。

例如，源代码文件一有改动，你就可以用`sbt`重新运行测试：
```bash
$ sbt
>~ test
```

注意，除第一个测试外，其余测试都已禁用，供你先从第一个开始。要继续下去，只需把每个测试用例开头的`pending`关键字删掉即可。

想进一步了解`sbt`，请[点这里](https://www.scala-sbt.org/)。


测试也可以在以下 IDE 中运行

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA with Scala Plugin](https://www.jetbrains.com/idea/)
