# 简介

很多语言都有类似`null`或`none`这样的方式来表示不存在的值。由于 Julia 的设计目标是处理海量（而且往往很杂乱的）数据，所以它有多重表示“无”的形式。

总的目标是，在遇到缺失或可疑的值时把它们标记出来，然后继续运行，而不抛出异常。

## `nothing`

如果一个值确实不存在，就用`nothing`表示。这大概最接近 C（`NULL`）或 Python（`None`）的做法。

```julia-repl
julia> n = nothing

julia> isnothing(n)
true

julia> typeof(n)
Nothing
```

所以`nothing`是类型为`Nothing`的单例值，我们可以对它进行测试。

`nothing`的一个常见用途，是作为那些只为副作用（打印、网络配置之类）而调用的函数的返回值，换句话说，就是“没有返回值”。

## `missing`

对于值理论上存在、但我们不知道它究竟是什么的情况，就使用`missing`。例如，在统计公路上行驶的车辆时，人工观察员可能需要休息，自动传感器也可能失灵，但车流仍在继续。

因此`missing`是一个占位符，提醒人们需要就如何处理数据中的这段空缺做出决定。

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> typeof(mv)
Vector{Union{Missing, Int64}} (alias for Array{Union{Missing, Int64}, 1})

julia> ismissing.(mv)  # broadcast function, displays as 1 for true, 0 for false
3-element BitVector:
 0
 0
 1
```

很少有其他语言内置这一特性，但 R 里的`NA`和 SQL 里的`NULL`是与之相近的类似物。

如果存在`missing`值，表达式通常默认返回`missing`。如果你希望忽略这些值，就用`skipmissing()`函数把这一点明确表示出来：

```julia-repl
julia> mv = [1, 2, missing]
3-element Vector{Union{Missing, Int64}}:
 1
 2
  missing

julia> sum(mv)  # missing in, missing out
missing

julia> skipmissing(mv)
skipmissing(Union{Missing, Int64}[1, 2, missing])

julia> collect(skipmissing(mv))
2-element Vector{Int64}:
 1
 2

julia> sum(skipmissing(mv))  # functions like sum() can work with iterators
3
```

由于`skipmissing`创建的是迭代器，如果你需要一个向量，就用`collect()`把它包起来。

有时把`missing`值替换成某个默认值很有用。`@coalesce()`宏在这方面很有用，它会返回第一个不是`missing`的值（如果除此之外没有别的，就返回`missing`）。

```julia-repl
julia> str = ["I", "exist", missing]
3-element Vector{Union{Missing, String}}:
 "I"
 "exist"
 missing

julia> [@coalesce(s, "-") for  s in str]
3-element Vector{String}:
 "I"
 "exist"
 "-"
```

## `NaN`

NaN 是“Not a Number”的缩写，用来在期望出现数字的情况下标记出计算问题。

```julia-repl
julia> v = [0, 1, -1]
3-element Vector{Int64}:
  0
  1
 -1

julia> v / 0
3-element Vector{Float64}:
 NaN
  Inf
 -Inf
 
julia> sum(v / 0)
NaN
```

只要数据里包含 NaN，对它做任何计算，结果都会是`NaN`。

目前没有专门用来移除`NaN`值的函数，不过标准的`filter()`函数就能很轻松地做到。只有那些让给定条件为`true`的值，才会被复制到结果数组中：

```julia-repl
julia> filter(!isnan, [1, 2, NaN])
2-element Vector{Float64}:
 1.0
 2.0
```
