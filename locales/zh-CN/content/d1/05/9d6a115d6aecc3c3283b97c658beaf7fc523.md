# 简介

## 队列

Gleam 标准库在 `gleam/queue` 模块中实现了 `Queue` 类型。它和 `List` 类型很像，但有几个关键区别：

- `Queue` 类型没有字面量语法，无法用它来构造队列，也无法对它进行模式匹配。
- 元素可以高效地从 `Queue` 类型的前端和后端添加和移除，而 `List` 类型只能高效地从前端添加和移除元素。

大多数时候你会想用 `List` 类型，但当你需要从集合的末尾添加和移除元素时，`Queue` 类型是个不错的选择。

可以用 `queue.new` 和 `queue.from_list` 函数来创建队列：

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

可以用 `queue.push_front` 和 `queue.push_back` 函数向队列中添加元素：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

可以用 `queue.pop_front` 和 `queue.pop_back` 函数从队列中移除元素：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

可以用 `queue.to_list` 函数把队列转换成列表：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

### 队列相等性

由于队列的实现方式，两个包含相同元素、且顺序也相同的队列，按照比较值结构的 `==` 运算符来判断，可能并不相等。例如：

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

如果你需要比较两个队列是否相等，可以使用 `queue.is_logically_equal` 函数。

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
