# 关于

Gleam 标准库中的`gleam/order`模块包含`Order`类型，用于比较值。

`Order`的定义如下：

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

该类型有三个变体，每个变体用于表示一个值与另一个值之间的关系：

- `Gt`：该值_大于_另一个值。
- `Eq`：该值_等于_另一个值。
- `Lt`：该值_小于_另一个值。

如果一种数据类型可以按大小比较，那么模块通常会定义`compare`函数，该函数返回一个`Order`值。例如，`gleam/float`和`gleam/int`分别定义了操作浮点数和整数的`compare`函数。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

诸如`list.sort`这样的排序函数通常接受一个返回`Order`值的函数，让调用方定义列表应如何排序。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
