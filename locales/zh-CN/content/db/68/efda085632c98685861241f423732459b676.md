# 学习

## 从零开始学习 C++

C++ 是一门语法丰富、表达力强的语言，支持多种不同的编程风格：过程式、面向对象、函数式、泛型，甚至可以在同一个程序里把它们组合起来使用。本语言轨道会尽量让题目的难度逐步递增。不过，语言的语法细节，与其用一连串练习来介绍，不如换一种形式引入。

一般来说，Exercism 假定你已经了解某个轨道中语言的语法和机制。但掌握一门语言的语法，只是精通这门语言的第一步。Exercism 让你练习解题，并与其他解出同一道题的程序员交流讨论。正是在这样的共同讨论中，我们积累经验、拓宽思路，成为更好的程序员。

如果你完全是 C++ 新手，应该先花时间学习语言基础。下面这些资源可以帮你入门：

* [Learn C++](http://www.learncpp.com/)
* [C++ Koans](https://github.com/torbjoernk/CppKoans)

[Coliru](http://coliru.stacked-crooked.com/) 是一个简单的网页表单界面，背后连着 C++ 编译器，可以让你试跑小程序。有时候，想快速做个小实验，用它比在本地的集成开发环境里搭一个项目更方便。

## C++ 中的测试驱动开发

Exercism 假定你熟悉测试驱动开发的概念。每道练习都附有一系列已经写好的测试。你要一次一个测试地推进，逐步写出能通过测试的实现。

如果你刚接触测试驱动开发，强烈建议你先做完 [C++ Now! 2014](http://cppnow.org/) 的 [Test-Driven Development in C++](https://github.com/boostcon/cppnow_presentations_2014/tree/master/files/test_driven) 工作坊。该工作坊使用的工具，和 Exercism 上 C++ 轨道使用的是同一套。
