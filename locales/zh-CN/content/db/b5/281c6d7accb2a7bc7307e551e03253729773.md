# 测试

运行测试有多种方式。

## 在 Emacs 里交互式运行

1. 打开测试文件，执行`M-x eval-buffer RET`
2. 用`M-x ert RET test-name RET`逐个交互式运行
3. 用`M-x ert RET t RET`一次交互式运行全部测试
   注意，这会运行当前已加载到 Emacs 中的所有测试！
4. 每次修改代码后，测试前都要重新执行`M-x eval-buffer RET`

如果只想执行当前缓冲区里的测试，可以把下面的代码加到你的`.emacs`或`init.el`中：

```elisp
(defun my-eval-and-run-all-tests-in-buffer ()
  "Deletes all loaded tests from the runtime, evaluates the current buffer and runs all loaded tests with ert."
  (interactive)
  (ert-delete-all-tests)
  (eval-buffer)
  (ert 't))
```

重启 Emacs 之后：

1. 打开测试文件
2. 执行`M-x my-eval-and-run-all-tests-in-buffer RET`

## 在终端里运行

要在终端里以批处理模式运行所有测试，执行`emacs -batch -l ert -l *-test.el -f ert-run-tests-batch-and-exit`

上面的命令有点长，如果你愿意，可以这样做：

1. 在`$PATH`（通常是`~/bin`）里创建一个名为`ert-run`的文件
2. 文件内容如下：
   ```sh
   #!/usr/bin/env sh
   emacs -batch -l ert -l $1 -f ert-run-tests-batch-and-exit
   ```
3. 用`chmod +x ert-run`给文件加上可执行权限

之后只要调用`ert-run *-test.el`，就能以批处理模式运行测试了。

## 其他方式

其他方式可以在文档里找到，`C-h i m ert RET`。
