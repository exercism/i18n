# 简介

## 数组

Cairo 核心库实现了一个`Array`类型。

它与其他编程语言中常见的数组类型相似，但有几个关键区别：

- 元素只能高效地添加到`Array`类型的尾部，也只能高效地从头部移除。
- 无法通过数组下标手动设置某个元素。

可以使用`ArrayTrait::new`函数创建数组，也可以使用`array!`宏：

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

可以使用`ArrayTrait::append`函数向数组中添加元素：

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

可以使用`ArrayTrait::pop_front`函数从数组中移除元素：

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo 还引入了`Span`类型，它就像是`Array`的“快照”。

每个`Array`都可以通过`ToSpanTrait::span`函数转换为`Span`：

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

把数组转换为`Span`非常高效，因为`Span`只是一种数据结构，让 Cairo 能够“查看”数组的一段内容，它不会以任何方式修改数组。

通过把数组转换为`Span`，Cairo 可以执行比直接在`Array`上更多的操作，比如从 span 的前端移除元素。

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

注意，我们必须用`mut`关键字把`one_to_four_span`设为可变的，才能调用`pop_back`，它会通过缩短 span 所“查看”的数组片段来改变这个 span。
