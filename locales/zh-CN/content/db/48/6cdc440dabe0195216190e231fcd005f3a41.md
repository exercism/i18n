# 简介

像`LocalDate`和`LocalDateTime`这样的类描述的是时间中的一个_点_。`java.time`包中还有两个类，用来描述一段_时间量_：

- `Period`表示基于日期的时长，以年、月、日为单位，例如“2 个月零 5 天”。
- `Duration`表示基于时间的时长，以小时、分钟、秒、毫秒和纳秒为单位，例如“1 小时 30 分钟”。

这个区别很重要，因为日历单位的长度并不固定。一个月可能有 28、29、30 或 31 天，所以“一个月”并不是固定的秒数。`Period`遵循日历，而`Duration`度量的是精确的时间。

| | `Period` | `Duration` |
| --- | --- | --- |
| 存储内容 | 年、月、日 | 秒和纳秒 |
| 配合使用 | `LocalDate`、`LocalDateTime` | `LocalTime`、`LocalDateTime`、`Instant` |

这两个类都是不可变的。像`plusDays()`或`multipliedBy()`这样的方法会返回一个_新_实例，原实例保持不变。

## `Period`

### 创建`Period`

```java
Period.ofDays(10);
// => P10D

Period.ofWeeks(2);
// => P14D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`的结果使用 [ISO-8601 时长格式][iso-8601-durations]：`P`后面依次是年数（`Y`）、月数（`M`）和天数（`D`）。`Period`中没有周：`Period.ofWeeks(2)`会存成 14 天。同样的表示法可以用`Period.parse()`解析回来：

```java
Period.parse("P1Y2M15D");
// => P1Y2M15D
```

### 把`Period`加到日期上

用`plus()`和`minus()`可以给日期加上或减去一个`Period`：

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

也可以用同样的方式把`Period`加到`LocalDateTime`上，并且一天中的时间保持不变：

```java
LocalDateTime.of(2024, 3, 10, 9, 30).plus(Period.ofMonths(1));
// => 2024-04-10T09:30
```

`Instant`没有日历，所以只能给它加上以天为单位的`Period`。如果`Period`带有年或月，就会抛出异常：

```java
Instant instant = Instant.parse("2024-03-10T09:30:00Z");

instant.plus(Period.ofDays(2));
// => 2024-03-12T09:30:00Z

instant.plus(Period.ofMonths(1));
// => throws UnsupportedTemporalTypeException
```

先加年，再加月，最后加天。如果加上年或月后落到一个不存在的日期，结果会回退到该月的最后一个有效日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28

LocalDate.of(2024, 2, 29).plus(Period.ofYears(1));
// => 2025-02-28
```

这也意味着，先加上一个`Period`再减去它，并不总能回到原来的日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1)).minus(Period.ofMonths(1));
// => 2025-01-28
```

### 两个日期之间的`Period`

`Period.between()`返回从一个日期（包含）到另一个日期（不包含）之间的`Period`。用`LocalDate.until()`也能得到同样的结果：

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period.between(start, end);
// => P1Y2M15D

start.until(end);
// => P1Y2M15D
```

`Period`的各个部分可以通过`getYears()`、`getMonths()`和`getDays()`获取。这些部分彼此独立：`getDays()`只返回天数部分，而不是总天数。`toTotalMonths()`把年和月合起来折算成月数返回，但没有方法能返回总天数，因为这取决于涉及哪些月份。

```java
Period period = Period.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => P2M5D

period.getDays();
// => 5

period.toTotalMonths();
// => 2
```

### 规范化`Period`

用工厂方法创建的`Period`会原样保留各个单位，而`equals()`会逐个比较单位。`normalized()`会把满 12 个月进位成年，但不会动天数：

```java
Period.ofMonths(14);
// => P14M

Period.ofMonths(14).equals(Period.of(1, 2, 0));
// => false

Period.ofMonths(14).normalized();
// => P1Y2M

Period.ofDays(45).normalized();
// => P45D
```

## 用`ChronoUnit`计数单位

要得到两个时间点之间某个单位的总数，可以使用[`ChronoUnit`][chronounit-docs]中某个常量的`between()`方法：

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

ChronoUnit.DAYS.between(start, end);
// => 65

ChronoUnit.WEEKS.between(start, end);
// => 9

ChronoUnit.MONTHS.between(start, end);
// => 2
```

只计算完整的单位，并且当第二个实参早于第一个实参时，结果为负数：

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

`ChronoUnit`也适用于基于时间的单位和日期时间：

```java
ChronoUnit.MINUTES.between(
    LocalDateTime.of(2024, 3, 10, 18, 5),
    LocalDateTime.of(2024, 3, 10, 19, 40));
// => 95
```

## `Duration`

### 创建`Duration`

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofSeconds(3725);
// => PT1H2M5S

Duration.ofDays(2);
// => PT48H

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

在 ISO-8601 表示法中，`T`把日期部分和时间部分分隔开。`Duration`没有日期部分，所以它的`toString()`总是以`PT`开头。`Duration.ofDays()`把一天恰好当作 24 小时。

`Duration`也可以用`Duration.parse()`解析：

```java
Duration.parse("PT1H30M");
// => PT1H30M
```

### 把`Duration`加到时间上

用`plus()`和`minus()`可以给`LocalTime`、`LocalDateTime`或`Instant`加上或减去一个`Duration`：

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00

LocalTime.of(23, 0).plus(Duration.ofHours(2));
// => 01:00
```

正如最后一个例子所示，`LocalTime`会跨过午夜回到起点。

`LocalDate`没有时间，所以不能与`Duration`一起使用：

```java
LocalDate.of(2024, 3, 10).plus(Duration.ofHours(1));
// => throws UnsupportedTemporalTypeException
```

### 两个时间之间的`Duration`

`Duration.between()`返回两个时间或日期时间之间的精确时间量：

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M

Duration.between(checkOut, checkIn);
// => PT-1H-35M
```

`Duration.between()`不接受两个`LocalDate`值，因为日期没有可以度量的秒：

```java
Duration.between(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => throws UnsupportedTemporalTypeException
```

对日期请改用`Period.between()`或`ChronoUnit.DAYS.between()`。

### 转换`Duration`

`toXxx()`系列方法会把`Duration`转换成某个单位的_总量_，并向下取整：

```java
Duration duration = Duration.ofSeconds(5730); // 1 hour, 35 minutes and 30 seconds

duration.toHours();
// => 1

duration.toMinutes();
// => 95

duration.toSeconds();
// => 5730
```

`toXxxPart()`系列方法则像看钟表一样，把`Duration`拆成各个部分：

```java
Duration duration = Duration.ofSeconds(5730);

duration.toHoursPart();
// => 1

duration.toMinutesPart();
// => 35

duration.toSecondsPart();
// => 30
```

`toHoursPart()`最大到 23，超过的小时数由`toDaysPart()`计算。

### 比较和计算`Duration`

`Duration`可以用`compareTo()`比较，也可以用`isZero()`和`isNegative()`检查：

```java
Duration visit = Duration.ofMinutes(95);
Duration limit = Duration.ofHours(2);

visit.compareTo(limit) > 0;
// => false

Duration.between(LocalTime.of(10, 0), LocalTime.of(9, 0)).isNegative();
// => true
```

它们还支持算术运算，例如`plus()`、`minus()`、`multipliedBy()`和`dividedBy()`：

```java
Duration.ofMinutes(20).multipliedBy(3);
// => PT1H

Duration.ofHours(2).dividedBy(Duration.ofMinutes(15));
// => 8
```

## 用`Period`还是`Duration`？

对于`LocalDate`或`LocalTime`，选择已经替你做好了：日期没有可以度量的时间，而时间没有日历。`LocalDateTime`两者都有，但没有时区，所以给它加上`Period.ofDays(1)`或`Duration.ofDays(1)`，结果是一样的。有了时区，区别就显现出来了。当因为夏令时把时钟拨快时，一个日历日只有 23 个小时：

```java
ZonedDateTime noon = ZonedDateTime.of(2025, 3, 29, 12, 0, 0, 0, ZoneId.of("Europe/Amsterdam"));

noon.plus(Period.ofDays(1));
// => 2025-03-30T12:00+02:00[Europe/Amsterdam]

noon.plus(Duration.ofDays(1));
// => 2025-03-30T13:00+02:00[Europe/Amsterdam]
```

加上一天的`Period`会保持一天中的时间不变，而加上一天的`Duration`则恰好增加 24 小时。人们用日历方式思考的时间量（例如“下个月的同一时间”）用`Period`，而经过的时间（例如“停车票有效期为 2 小时”）用`Duration`。
