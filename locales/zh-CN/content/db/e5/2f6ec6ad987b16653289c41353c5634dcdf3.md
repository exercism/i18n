# 提示

## 1. 自我介绍

`introduce`函数必须“解包”`player.Name`中包含的值。
可以考虑使用[`Options.defaultValue`函数][defaultvalue]，在值为`Some`时把`player.Name`转换成它“包装”后的值，在值为`None`时转换成所需的默认值。

## 2. 实现复活机制

`revive`函数必须返回`Some <player>`或`None`，其中`<player>`是一个`Player`记录，其部分字段可能已被修改。

## 3. 实现施法机制

可以考虑使用 match 表达式同时覆盖`Some`和`None`两种情况，如下例所示：

```fsharp
let exists (x: int option) =
    match x with
    | Some n -> true
    | None -> false
```

[defaultvalue]: https://learn.microsoft.com/en-us/dotnet/fsharp/language-reference/options#converting-options-with-default-values
