# 简介

在 Rust 中，布尔值由`bool`类型表示，其值可以是`true`或`false`。

Rust 支持六个比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于等于）、`<=`（小于等于）。它们可以用来将非布尔值之间的关系求值为一个布尔值。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

与其他一些语言不同，`0`不是`false`，非零也不是`true`。

Rust 支持两个布尔运算符：`||`（或）、`&&`（与）。这两个运算符只有在左侧操作数尚未确定表达式的结果时，才会对右侧操作数求值。也就是说，`||`只有在左侧操作数求值为`false`时，才会对右侧操作数求值；而`&&`只有在左侧操作数求值为`true`时，才会这样做。
