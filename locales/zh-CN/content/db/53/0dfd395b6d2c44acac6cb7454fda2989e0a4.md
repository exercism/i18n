# 关于

[位串][bitstring]让程序员可以高效地处理二进制数据。

- 你可以使用[`<<>>` 特殊形式][bitstring-form]优雅地构造位串。

  ```elixir
  <<0b101::3>> == <<5::3>> and <<5::3>> == <<5::size(3)>>
  # => true

  first = <<0b110::3>>
  second = <<0b001::3>>
  combined = <<first::bitstring, second::bitstring>>
  # => <<49::size(6)>>
  ```

- 你可以使用`<<>>`形式进行匹配，并用该匹配进一步[分解二进制数据][bitstring-matching]。

  ```elixir
  <<data_size::32, count::size(data_size)>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  data_size
  # => 8
  count
  # => 3
  ```

- 你可以使用`::bitstring`匹配位串的剩余部分。

  ```elixir
  <<_::32, remainder::bitstring>> = <<8::32, 3::8>>
  # => <<0, 0, 0, 8, 3>>
  remainder
  # => <<3>>
  ```

- 二进制数据*类型*是一种特殊的位串，它的位数能被 8 整除。
  - 所有二进制都是位串，但并非所有位串都是二进制。
- Elixir 为以不同形式使用[整数字面量][integer-literal]提供了语法糖：
  - `0b1000001 = ?A = 65`
