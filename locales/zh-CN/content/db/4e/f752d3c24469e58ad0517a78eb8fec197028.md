# 简介

## 类型别名

### 类型别名

在 Gleam 中，类型别名可以为已有的类型取一个方便的名字，否则这个类型写起来会很繁琐。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

用`pub type`书写时，该别名可以在定义它的模块之外使用。如果省略`pub`，这个别名就是私有的，无法在其他模块中引用。

## 字典

Gleam 中的字典是用于以键值对存储信息的数据结构。在其他语言中，这类结构也被称为关联数组、哈希或字典。

字典中的键和值可以是任意类型，而且在访问或返回时，它们不保证条目的顺序。

### 使用字典

字典通过`gleam/dict`模块中的函数来创建和操作。

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
