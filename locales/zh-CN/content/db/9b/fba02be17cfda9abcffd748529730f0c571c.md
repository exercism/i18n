# 说明附录

## 词

定义一个`stopwatch`元组，以及一个构造器`<stopwatch> ( -- stopwatch )`；该构造器返回一个新的秒表，它处于`"ready"`状态，没有已用时间，也没有之前的计次。

提供以下用于操作秒表的词：

- `state ( stopwatch -- str )`：`"ready"`、`"running"` 或`"stopped"`。
- `current-lap ( stopwatch -- str )`：当前计次的已用时间，以`"HH:MM:SS"`字符串的形式表示。
- `total ( stopwatch -- str )`：当前计次与之前所有计次加在一起的总已用时间，以`"HH:MM:SS"`字符串的形式表示。
- `previous-laps ( stopwatch -- seq )`：由之前记录的各个计次组成的数组，每个计次都以`"HH:MM:SS"`字符串的形式表示。
- `start ( stopwatch -- )`、`stop ( stopwatch -- )`、`reset ( stopwatch -- )`和`lap ( stopwatch -- )`：上面表格中的四条命令。从不允许该操作的状态调用其中一条，应该`throw`一个错误。

时间通过以下方式推进：

- `advance-time ( str stopwatch -- )`：把`"HH:MM:SS"`的时长加到当前计次上。只有在秒表运行时，它才会生效。
