# 说明

为了那高得令人咋舌的日薪，你被吸引回了 Hyperia（那里的通货膨胀率很高）。

中央银行正在考虑引入美元作为第二种货币，这样一来，所有会计系统都必须改造，以支持多种货币。

你被要求实现货币金额对象。

## 1. 让货币金额能够进行相等性判断

请修改 `CurrencyAmount` 结构体，使其支持相等性判断。如果两个货币金额结构体的货币不同（"USD" 或 "HD"），则应抛出一个 `ArgumentException` 实例。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. 比较货币金额

请修改 `CurrencyAmount` 结构体，使其支持比较运算（仅限 `>` 和 `<`）。如果两个货币金额结构体的货币不同（"USD" 或 "HD"），则应抛出一个 `ArgumentException` 实例。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. 对货币金额进行加法和减法

请修改 `CurrencyAmount` 结构体，使其支持加法运算和减法运算（仅限 `+` 和 `-`）。如果两个货币金额结构体的货币不同（"USD" 或 "HD"），则应抛出一个 `ArgumentException` 实例。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. 对货币金额进行乘法和除法

请修改 `CurrencyAmount` 结构体，使其支持乘法运算和除法运算（仅限 `*` 和 `/`）。

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. 将货币金额转换为 double

请修改 `CurrencyAmount` 结构体，使其实例可以显式转换为 `double`。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. 将货币金额转换为 decimal

请修改 `CurrencyAmount` 结构体，使其实例可以隐式转换为 `decimal`。

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
