# 类型声明

PHP 中的类型声明会在运行时对函数实参、返回值和类属性进行类型断言。
在函数上，可以加上`void`返回类型，表示该函数不返回任何值。
声明的类型同时也是一种运行时断言，确保函数返回的响应具有合理的类型。

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

## 联合类型

如果函数实参、返回值或类属性可以属于多种类型，就可以声明联合类型。

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## 混合类型

写代码时，我们可能无法指定某个类型。
从 PHP 8.0 开始，PHP 提供了一个名为`mixed`的逃生舱类型。
`mixed`等同于`object|resource|array|string|float|int|bool|null`的联合类型。
