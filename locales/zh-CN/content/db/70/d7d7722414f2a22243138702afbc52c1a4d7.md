# 说明

在本练习中，你将为一台以千克为单位的称重机建模。

共有 6 个任务，每个任务都需要实现一个或多个属性：

## 1. 让称重机可以设置精度

为了满足不同的需求，我们允许每台称重机自定义精度（小数点后的位数）。
实现`WeighingMachine`类，使其具有一个只读的`Precision`属性，该属性由构造函数的`precision`参数设定：

```csharp
var wm = new WeighingMachine(precision: 3);

//  => wm.Precision == 3
```

## 2. 让称重机可以设置重量

实现`WeighingMachine.Weight`属性，让重量可以被读取和设置：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.5;

//  => wm.Weight == 60.5
```

## 3. 确保拒绝负的输入重量

显然，一个人的重量不可能是负数。
为`WeighingMachine.Weight`属性添加校验，在尝试将其设为负数时抛出`ArgumentOutOfRangeException`：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = -10; // Throws an ArgumentOutOfRangeException
```

## 4. 允许对称重机进行皮重调整

皮重调整可以是任意值（甚至是负数，或是会让显示重量变成负数的值）
实现`WeighingMachine.TareAdjustment`属性，以便可以设置皮重调整：

```csharp
var wm = new WeighingMachine(precision: 3);
wm.TareAdjustment = -10.6;

// => wm.TareAdjustment == -10.6
```

## 5. 确保称重机有默认的皮重调整

经过一番仔细测试后发现，由于制造问题，所有称重机都倾向于把重量高估`5`。
将`WeighingMachine.TareAdjustment`属性的默认值改为`5`。

```csharp
var wm = new WeighingMachine(precision: 3);

// => wm.TareAdjustment == 5.0
```

## 6. 让重量可以被获取

实现`WeighingMachine.DisplayWeight`属性，它应返回一个字符串，显示应用皮重调整后的重量，同时保留正确的精度，并加上单位。
注意：
``` display-weight = input-weight - tare-adjustment ```

```csharp
var wm = new WeighingMachine(precision: 3);
wm.Weight = 60.567;
wm.TareAdjustment = 10;

// => wm.DisplayWeight == "50.567 kg"
```
