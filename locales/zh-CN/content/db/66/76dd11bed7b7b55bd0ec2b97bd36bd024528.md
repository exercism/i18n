# 精确数字

| 类型 | 存放内容 | 上限 |
| --- | --- | --- |
| `INT` | 整数 | 恰好 32 位 |
| `FLTD` | 分数 | 近似 |
| `INTI` | 整数 | 内存 |
| `RAT` | 分数 | 精确 |

## INTI

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
   a + b, a - b, a * b, a / b
   a < b, a = b
   #INTI(25).factorial
   #INTI(48).gcd(#INTI(18))       -- 6
   #INTI(2).pow(100)
   big.str
   small.int                      -- back to an INT, if it fits
```

对两个`INTI`做`/`运算得到的是整数除法，余数会被丢弃，跟`INT`完全一样。

对一个超出`INT`范围的数值调用`.int`并不会报告问题。如果这有影响，先自行检查。

## RAT

```sather
   #RAT(1, 3)
   #RAT(6)                        -- from a whole number
   a + b, a - b, a * b, a / b
   a < b, a = b
   r.is_int                       -- is it a whole number?
   r.is_zero, r.is_pos, r.is_neg
   r.abs, r.negate
   r.floor                        -- an INTI, rounded down
   r.str
```

`RAT`总是约到最简形式，符号也总是放在分子上：`#RAT(1, -2)`就是`-1/2`。两个`RAT`只有在表示同一个分数时才相等，所以`=`的行为正是你想要的，这也正是它和`FLTD`的全部区别。

`RAT`建立在`INTI`之上，所以它的分子和分母同样没有大小限制。把很多分母不同的分数相加会让它们不断变大，因为每次相加都会先把分母乘开，然后再约分。

`ceiling`虽然已经声明，但一调用就会抛出 "not implemented"。改用`floor`，再自行调整。

## 如何选择

当数量可能超过 20 亿时，选用`INTI`：阶乘、幂、组合数，以及长时间累积的合计值。

当分数必须精确、分母又比较小时，选用`RAT`：份额、概率、音符时值，以及任何否则会累积舍入误差的计算。

默认情况下两者都不用。`INT`和`FLTD`要快得多，大多数运算也用不上它们。

处理金额时，通常两者也都不是答案：用`INT`来数整分。
