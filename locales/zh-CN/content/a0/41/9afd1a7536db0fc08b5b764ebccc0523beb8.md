# 学习

## 推荐学习资源

Exercism 提供练习和反馈，但对初次学习 SML 的人来说，ML 可能比较难上手。以下资源可以帮助你入门：

### 我从未编过程序

对新程序员来说，ML 可能不是最好的语言。你最好从 Ruby 或 Python 这样的语言开始。不过，如果你胆子特别大，可以去读 [Programming in Standard ML '97: An On-line Tutorial][tutorial]。我建议跳过引言，直接看 [Simple applicative programming][node13]，因为引言非常技术化。

Coursera 上有一门关于[编程语言][coursera]的课程。这门课面向有一定经验的程序员，不过要找到比它更好的 ML 语言入门资料并不容易。


### 我听说过函数式编程

值得一读的是 [Programming in Standard ML '97: An On-line Tutorial][tutorial]。

还有 [A Gentle Introduction to ML][gentle]。

Coursera 上有一门关于[编程语言][coursera]的课程。要找到比它更好的 ML 语言入门资料并不容易。

[SML/NJ 网站][smlnj]列出了一批书。不过大多数书年代相当久远，可能很难找到。这门语言变化不大，所以如果你能找到它们，不要觉得它们有多过时。也请看看该页面上列出的 Four Lectures on Standard ML。


## 我是一名有经验的程序员

如果你是一名有经验的程序员，并且非常熟悉函数式语言，那么你可以在 [Learn X in Y minutes][learnxy] 上快速了解这门语言的语法。

[Four Lectures on Standard ML][four-lectures] 是很好的入门材料。
