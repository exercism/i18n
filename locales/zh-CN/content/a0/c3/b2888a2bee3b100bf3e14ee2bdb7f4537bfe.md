# 简介

C# 中有两种不同的数字类型：

- 整数：小数点后没有数字的数（即整数）。例如`-6`、`0`、`1`、`25`、`976`和`500000`。
- 浮点数：小数点后可以有零个或多个数字的数。例如`-2.4`、`0.1`、`3.14`、`16.984025`和`1024.0`。

C# 中最常见的两种数值类型是`int`和`double`。`int`是 32 位整数，`double`是 64 位浮点数。

算术运算使用标准算术运算符完成。数字可以使用标准数值比较运算符以及相等（`==`）和不等（`!=`）运算符进行比较。

C# 中的数值转换有两种：

1. 隐式转换：不会丢失数据，也不需要额外的语法。
2. 显式转换：可能会丢失数据，并且需要一种*强制转换*形式的额外语法。

由于`int`的精度比`double`低，从`int`转换为`double`是安全的，因此属于隐式转换。然而，从`double`转换为`int`可能会丢失数据，所以需要显式转换。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
