# 关于

**闭包**是[在 Clojure 中][clojure-guide-closures]的一种编程模式，它允许在函数内部使用来自外层[词法作用域][wiki-lexical-scope]的变量。Clojure 透明地支持闭包，人们常常在不知道闭包是什么的情况下使用它们。

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## 用闭包保存状态和传递值

使用 atom 可以保存一些状态：

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

每次连续调用`increment`都会使其计数器自增：

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
