# 补充说明

## 寄存器

| 寄存器 | 用途   | 类型 | 说明                |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的输入字符串  |
| `$a1`    | 输入        | 整数 | 移位量                     |
| `$a2`    | 输入/输出 | 地址 | 以 null 结尾的结果字符串 |
| `$t0-9`  | 临时        | 任意 | 用于临时存储         |
