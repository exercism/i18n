# 引言

在 Haxe 中，**数组**是（通常情况下）同一类型元素的集合。在 Haxe 中创建数组有三种方式，可以借助构造函数，也可以借助声明语法。在 Haxe 中，数组第一个元素的下标是 0：

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

要使用构造函数创建数组，需要传入将包含在数组中的元素类型：

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

如果我们想让数组包含多种类型的元素，就在类型指示符里加上`Dynamic`类型：

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
