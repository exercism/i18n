# 说明

附近有一家叫“Tech Palace”的家电店。店老板最近安装了一块大显示屏，用来播放营销信息，还能在顾客于入口扫描会员卡时显示一句特别的问候语。这块显示屏由许多小 LED 灯组成，可以显示多行文字。

店老板需要你帮忙处理为新显示屏生成文字的代码。

## 1. 创建欢迎消息

<!-- markdownlint-disable-next-line MD038 -->
对于大多数扫描会员卡的顾客，店老板希望显示屏上显示`Welcome to the Tech Palace, `，后面跟上用大写字母写成的顾客姓名。

实现`welcome_message`函数，它接收顾客姓名作为短字符串（`felt252`）实参，并以`ByteArray`返回所需的欢迎消息。

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. 添加花哨的边框

对于在店里大量购买的忠实顾客，店老板想让欢迎显示屏更花哨一些，在欢迎消息前后各加一行星号。他们还不确定每行应该有多少颗星号，所以希望这个数量可以配置。

编写一个`add_border`函数，接收一条欢迎消息（`ByteArray`）和每行星号的数量（类型为`u32`）作为实参。它应返回一个由 3 行组成的`ByteArray`：第一行是指定数量的星号，然后是原样传入的欢迎消息，最后又是一行星号。

```rust
add_border("Welcome!", 10)
```

应返回：

```bash
**********
Welcome!
**********
```

## 3. 清理旧的营销信息

在安装这块新显示屏之前，店里有一块类似的显示屏，只能显示无法配置的固定文字行。店老板想在新显示屏上重复使用一些旧的营销信息。不过，这些数据里已经包含了星号边框和一些多余的空白字符。你的任务是清理这些信息，让它们可以重复使用。

实现一个`clean_up_message`函数，接收旧的营销信息，类型为`ByteArray`。该函数应首先从文本中移除所有星号，然后去掉剩余文本开头和结尾的空白字符。然后返回清理后的消息。

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
