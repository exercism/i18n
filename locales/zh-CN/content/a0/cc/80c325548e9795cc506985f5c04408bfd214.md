# 说明

在这个练习中，你将编写一些代码，帮助你按照最喜欢的烹饪书做出一份美味的千层面。

一共有四个任务，都与烹饪千层面所用的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义`expectedMinutesInOven()`方法，它不接受任何形参，返回千层面应该在烤箱中烤多少分钟。根据烹饪书，烤箱的预期时间是 40 分钟：

```java
Lasagna lasagna = new Lasagna();
lasagna.expectedMinutesInOven();
// => 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`remainingMinutesInOven()`方法，它接收千层面已经在烤箱中度过的实际分钟数作为形参，并根据上一个任务中得出的烤箱预期时间，返回千层面还需要在烤箱中烤多少分钟。

```java
Lasagna lasagna = new Lasagna();
lasagna.remainingMinutesInOven(30);
// => 10
```

## 3. 计算准备时间（分钟）

定义`preparationTimeInMinutes()`方法，它接收你为千层面添加的层数作为形参，并返回你准备千层面花了多少分钟，假设准备每一层需要 2 分钟。

```java
Lasagna lasagna = new Lasagna();
lasagna.preparationTimeInMinutes(2);
// => 4
```

## 4. 计算总工作时间（分钟）

定义`totalTimeInMinutes()`方法，它接收两个形参：第一个形参是你为千层面添加的层数，第二个形参是千层面已经在烤箱中度过的分钟数。这个函数应返回你烹饪千层面总共花了多少分钟，也就是准备时间的分钟数与此刻千层面在烤箱中度过的分钟数之和。

```java
Lasagna lasagna = new Lasagna();
lasagna.totalTimeInMinutes(3, 20);
// => 26
```
