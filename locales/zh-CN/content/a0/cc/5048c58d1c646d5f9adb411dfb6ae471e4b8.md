# 简介

很多语言都有`null`或`none`这样的方式来表示一个不存在的值。
由于 R 的设计目标是处理大量（往往杂乱）的数据，所以它有多种表示“不存在”的形式。

总体目标是在遇到缺失或可疑的值时把它们标记出来，然后继续执行，而不抛出异常。

## NULL

如果某个值确实不存在，就用`NULL`表示。这可能最接近 C 或 Python 的做法。

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

在很多场景下，`NULL`值会被直接忽略：

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

如果某个值存在，但我们不知道它具体是什么，就用`NA`。例如，统计一条路上通过的车辆时，人工观察员可能会请病假，自动传感器也可能出故障，但车流依然不断。

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

因此`NA`是一个占位符，提醒人们需要决定如何处理它。

## NaN

`NaN`是“Not a Number”的缩写，用来标记在本该得到数字的地方出现的计算问题。

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

这并非“无效”计算的唯一可能。
当分子不为 0 时，除以 0 会返回`Inf`或`-Inf`，而不报错。

```R
1 / 0
#> [1] Inf
```

## 空向量

也许出乎意料，R 并没有检查“空”的标准方法。

就连生成一个空向量也并不那么直观。
我们在前面的小节看到，不带实参的`c()`返回的是`NULL`，而不是向量。

```R
is.vector(c())
#> [1] FALSE
```

`logical()`或`integer()`这样的函数接收一个指定所需长度的实参，这个长度可以是 0。

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

我们也可以先生成一个向量，再去掉其中的每一个元素，如[向量概念][concept-vectors]中所述。
这样得到的就是一个长度为 0、类型合适的向量。

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
