# 补充说明

## 在 Prolog 中使用日期

Prolog 内置的日期支持[相当简陋][built-in-dates-support]。用 [date_time 包][date_time-package] 来处理日期要方便得多。

### 安装 date_time 包

如果你安装的 Swipl 版本比较新，可以运行下面的命令来安装这个包：

```bash
swipl pack install date_time
```

如果这样不行，可以运行：

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
如果你使用的是在线编辑器，就不需要手动安装任何东西。
~~~~

### 使用 date_time 包

要在解答文件的顶部使用 `date_time` 包，请添加以下代码：

```prolog
:- use_module(library(date_time)).
```

~~~~exercism/note
提示：[date_time 包的源码][https://www.swi-prolog.org/pack/file_details/date_time/prolog/date_time.pl?show=src]文档很完善，会很有帮助！
~~~~
