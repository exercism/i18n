# 关于

`when` 是筛选异常时使用的关键字。它放在 `catch` 语句之后，可以接受一个布尔表达式，其中可以包含当时作用域内的任意值。这些值不必非得是异常本身的成员。如果异常的类型匹配，并且该表达式的结果为 true，那么就会执行与该 `catch` 语句关联的代码块；否则就检查下一个 `catch` 语句（如果存在的话）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

- 这篇[异常筛选][exception-filters]文章介绍了如何筛选异常。
