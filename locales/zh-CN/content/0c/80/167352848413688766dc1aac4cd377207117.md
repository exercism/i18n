# 关于

递归是一种让函数通过调用自身来重复执行代码的方式。
它也是循环或迭代的另一种做法。和循环一样，函数需要判断一个布尔表达式，才能知道何时结束。
与循环不同的是，永不终止的递归不会一直运行下去。
每次函数调用用到的值，可能被放在栈上独立的栈帧里。
如果函数调用占用的空间超过了栈的容量，就会导致栈溢出错误。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return i;
    printf("The number is %i\n", i++);
    printIncrement(i, maxValue);
}

int main() {
    printIncrement(1, 2);
    printf("After recursion");
    return 0;
}
```

会输出

```
The number is 1
The number is 2
After recursion
```

有些情况下，用递归表达会比用循环表达更易读，也更容易理清思路。


## 尾调用

尾调用是指函数的最后一条语句只调用自身，不再做别的事情。

尾调用是一种特殊的递归形式，它可能让编译器在编译后的代码中把递归优化成循环。
这样就能两全其美：既有递归的可读性，又有循环的性能。
把递归编译成循环称为`tail call elimination`或`tail call optimization.`

当尾调用被编译成循环时，每次函数调用都不会创建新的栈帧。
函数最初被调用时的地址会收到更新后的值，从而节省栈空间、提升性能。

下面这个例子不是尾调用，因为函数会在调用自身的结果上加 1。

```c
int printIncrement (int i, int maxValue){
    if (i > maxValue) return 1;
    printf("The number is %i\n", i++);
    return 1 + printIncrement(i, maxValue);
}

int main() {
    int j = printIncrement(1, 2);
    printf("j is %i after recursion", j);
    return 0;
}
```

会输出

```
The number is 1
The number is 2
j is 3 after recursion
```

要把它重构成尾调用，需要把`j`变成`printIncrement`的形参。

```c
int printIncrement (int i, int maxValue, int j){
    if (i > maxValue) return j;
    printf("The number is %i\n", i++);
    return printIncrement(i, maxValue, ++j);
}

int main() {
    int j = printIncrement(1, 2, 1);
    printf("j is %i after recursion", j);
    return 0;
}
```

你可能会发现，尾调用比非尾调用的递归调用更容易理清思路。
不过，编译器通常并不保证所有尾调用都会被优化。
使用递归时，始终要清楚迭代次数不会多到让栈溢出。
