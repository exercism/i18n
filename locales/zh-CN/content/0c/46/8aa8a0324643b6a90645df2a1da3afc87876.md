# 说明

你经营着一家会员制电影院。
要想看电影，人们必须先购买年票，之后就可以免费观影了。

你的影院维护着一份入场记录。
你想用这份记录来追踪本月哪些会员使用了年票。
你还想了解顾客的年龄分布信息。
你发现可以用集合来实现这些目标。

## 集合

集合是存储这类数据的理想数据类型。

集合是一种用于存储互不相同、唯一的值的数据类型，这些值没有特定的顺序。
“互不相同、唯一”意味着一个元素要么在集合中，要么不在集合中；与数组不同，它不能在集合中出现多次。
集合通常是无序的；如果你列出集合中的元素，得到的顺序可能与添加时的顺序不同，甚至可能与上一次列出的顺序也不同！

集合的一个基本特性是成员检查：能够检查集合是否包含某个元素。
成员检查几乎是所有集合用途的核心。

Go 不提供内置的集合数据类型。
通常用`map[<type>]struct{}`或`map[<type>]bool`来代替集合；与集合类似，`map`允许添加互不相同、唯一的元素，并支持成员检查。

## 1. 存放参会者信息的地方

为了追踪入场情况和年龄分布，你想使用集合。

你不想为姓名和年龄分别写一个集合；相反，你可以用一个泛型集合同时处理两者。
定义一个`Set`类型为`map[T comparable]struct{}`，用来存储参会者。
写一个`NewSet[T comparable]()`函数，返回一个空的`Set[T]`。

```go
names := NewSet[string]()
```

## 2. 追踪参会者

现在你可以记录参会者信息了。

写一个`Add[T]()`方法，用于向集合中添加元素。

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. 检查参会者

现在你有了一个参会者集合，可以检查特定会员和年龄分布是否出现过。
写一个`Contains[T](element)`方法，返回某个会员或年龄分布是否在`Set`中。

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. 比较参会者

又过了一个月，你有了一组新的年龄分布`Set`。
你的市场经理想知道本月的新片是否改变了出现的年龄分布。
写一个`Equals[T](other)`方法，判断两个集合是否含有相同的元素。

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
