# 简介

在 Go 中，`struct` 是一系列被称为_字段_的具名元素，每个字段都有一个名称和类型。
字段的名称在 struct 内必须唯一。
struct 可以类比为面向对象编程范式中的_类_。

## 定义 struct

你可以使用 `type` 和 `struct` 关键字来创建新的 struct，并显式定义各字段的名称和类型。
例如，这里我们定义了 `Shape` struct，它保存形状的名称和大小：

```go
type Shape struct {
    name string
    size int
}
```

struct 中的字段名遵循 Go 的约定：以小写字母开头的字段只对同一个包中的代码可见，而以大写字母开头的字段对其他包也可见。

## 创建 struct 实例

定义好 `struct` 之后，就需要创建新的实例了。创建时用字段名指定各字段的值，顺序任意：

```go
s := Shape {
    name: "Square",
    size: 25,
}
```

要读取或修改实例的字段，可以使用 `.` 表示法：

```go
// Update the name and the size
s.name = "Circle"
s.size = 35
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 35
```

没有赋予初始值的字段会取零值。
例如：

```go
s := Shape{name: "Circle"}
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name: Circle size: 0
```

只要_按顺序_定义字段，就可以不使用字段名来创建 `struct` 实例：

```go
s := Shape {
	"Oval",
	20,
}
```

不过，这种语法被认为是_脆弱代码_，因为一旦新增字段，它就可能会失效，尤其是新字段的类型不同时。
在下面这个例子中，我们给 `Shape` 添加了一个额外的字段：

```go
type Shape struct {
	name        string
	description string // new field 'description' added
	size        int
}

s := Shape{
    "Circle",
    20,
}
// Since the second field of the struct is now a string and not an int,
// the compiler will throw an error when compiling the program:
// Output: cannot use 20 (type untyped int) as type string in field value
// Output: too few values in Shape{...}
```

## “New” 函数

有时候，有一些能帮我们创建 struct 实例的函数会很不错。
按照约定，这类函数通常命名为 `New`，或者名称以 `New` 开头；不过它们只是普通函数，你可以随意命名。
它们可能会让你想起其他语言中的构造函数，但在 Go 里它们只是普通函数。

在下面的例子中，我们用其中一个 `New` 函数来创建 `Shape` 的新实例，并自动为形状的 `size` 设置默认值：

```go
func NewShape(name string) Shape {
	return Shape{
		name: name,
		size: 100, //default-value for size is 100
	}
}

NewShape("Triangle")
// => Shape { name: "Triangle", size: 100 }

```

使用 `New` 函数有以下优点：

* 可以对传入的值进行校验
* 可以处理默认值
* 由于 `New` 函数通常与它们所初始化的 struct 声明在同一个包中，因此它们甚至可以初始化 struct 的私有字段

如果想深入了解这个类型，可以看看这些资源：[Go by Example: Structs][go-by-example-structs]、[A Tour of Go: Structs][tour-of-go-structs] 或 [Structures in Go (structs)][medium-structures-in-go]

## `new` 内置函数

创建 struct 新实例的另一种方式是使用 `new` 内置函数：

```go
s := new(Shape) // s will be of type *Shape (pointer to shape)
fmt.Printf("name: %s size: %d\n", s.name, s.size)
// Output: name:  size: 0
```

在这个例子中，`new` 创建了 struct `Shape` 的一个实例，所有值都初始化为其类型的零值，并返回一个指向它的指针。

~~~~exercism/note
大多数情况下，你不会看到用 `new` 内置函数创建 struct 新实例的写法。
应该优先使用 struct 字面量、自定义的 `New` 函数，或者包中提供的其他能帮你构建 struct 的函数。
只有在万不得已时，才用 `new` 内置函数来创建 struct 的新实例。
~~~~
