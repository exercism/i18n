# 指令

Tori 是一名气候记者，她想写一篇关于不同城市天气的文章。她手上有不同城市的天气数据，想根据气温给这些城市排名，但有些气温是华氏度，有些是摄氏度。她需要你帮忙把气温换算成同一单位，再给它们排名。

## 1. 将华氏度转换为摄氏度

定义`fahrenheit_to_celsius`函数，它接收一个华氏温度作为实参，返回对应的摄氏温度。

要把华氏度换算成摄氏度，先用华氏温度减去 32，再把结果除以 1.8。

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. 比较两个温度

定义`compare_temperature`函数，它接收两个温度，返回一个`Order`值，表示第一个温度是小于、等于还是大于第二个温度。

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. 按气温给城市排序

定义`sort_cities_by_temperature`函数，它接收一个城市数组，并按照从最冷到最暖的顺序返回这些城市。

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
