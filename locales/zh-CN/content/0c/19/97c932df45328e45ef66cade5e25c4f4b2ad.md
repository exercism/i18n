Raku 是一门极其丰富、灵活且强大的编程语言。它的灵活性让程序员能够写出富有表现力、契合自身风格的代码。

Raku 是一门体量庞大、值得学习、探索和实验的语言，其中蕴藏着丰富的深度。本教学大纲旨在覆盖让你入门所需的基础知识。

面向对象编程是 Raku 的核心，但它并不强加面向对象的编程实践。由于 Raku 本身面向对象的特性，本教学大纲会经常提到[对象、类和方法][object-orientation]。

## 变量

为了保持简单，我们在基础部分只使用标量[变量][variables]。

标量变量是以`$`符号为前缀的[标识符][identifiers]。

标量变量几乎可以容纳任何东西，默认类型为 [`Any`][Any]。

你使用的大多数变量都需要[声明][variable-declarator]。目前请先使用 [`my`][my] 和 [`constant`][constant]。

```raku
my $foo;
constant $BAR;
```

## 子例程

子例程通过 [`sub`][sub-declarator] 声明符来声明。

`sub`声明后面依次跟着一个可选的[标识符][identifiers]、一个可选的[签名][signatures]，以及一个[代码块][blocks]。

子例程（以及其他内容）可以通过添加 [`is export`][exporting] 特性来导出。

子例程可以在标识符上用[后环缀 `( )`][postcircumfix-()]运算符来调用。

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## 运算符

Raku 有各种各样的[运算符][operators]。在基础概念的练习中，我们会用到 Raku 的一些基本数学运算符，比如`+`和`-`。

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

如果你愿意，可以在 Raku 中轻松定义自己的运算符。大多数内置运算符也可以作为子例程使用。

## 包和模块

Raku 中有多种[包][package-declarator]。在基础部分我们只用`module`。

要把整个文件声明为`module`，需要在模块声明前加上`unit`。

```raku
unit module Foo;

sub bar () { ... }
```

## 注释

Raku 有[单行][single-line-comments]和[多行/内嵌][multi-line-comments]注释。

单行注释以`#`开头，一直延续到行尾。

多行/内嵌注释以井号开头，后面跟一个反引号和一个 Unicode 开标点字符，并以一个与之配对的闭标点字符结尾。

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## 风格约定

Raku 中变量和子例程的[标识符][identifiers]采用`kebab-case`风格。常量采用`ALL-CAPS`风格。包名采用`PascalCase`风格。
