# 关于

除了 `cond`，Elixir 还提供了宏 [`if/2`][getting-started-if]，当你只需要检查一个条件时，它很有用。

[`if/2`][kernel-if] 接受一个条件和两个选项。条件为 _truthy_ 时，它返回第一个选项；条件为 _falsy_ 时，返回第二个选项。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

如果没有给出第二个选项，就会返回 `nil`。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
end

# => nil
```

也可以把 `if` 表达式写在一行里。注意条件后面的逗号。

```elixir
if age >= 16, do: "beer", else: "no beer"
```

这种语法适合非常短的表达式，但如果表达式放不下一行，就应该避免使用它。

## _truthy_ 和 _falsy_

在 Elixir 中，所有数据类型出现在布尔上下文里时（例如 `if` 表达式），都会求值为 _truthy_ 或 _falsy_。除了 `false` 和 `nil`，所有数据都被视为 _truthy_。尤其是空字符串、整数 `0` 和空列表，在 Elixir 中都算作 _truthy_。在这一点上，[Elixir 与 Ruby 相似，但与 JavaScript、Python 或 PHP 不同][falsy-various-langs]。

```elixir
truthy? = fn x -> if x, do: "truthy", else: "falsy" end

truthy?.(true)
# => "truthy"
truthy?.(0)
# => "truthy"
truthy?.([])
# => "truthy"

truthy?.(false)
# => "falsy"
truthy?.(nil)
# => "falsy"
```

[`&&/2`][kernel-and]、[`||/2`][kernel-or] 和 [`!/1`][kernel-not] 是 _truthy_ 布尔运算符，可以用于任何值，它们与_严格_布尔运算符 [`and/2`][kernel-boolean-and]、[`or/2`][kernel-boolean-or] 和 [`not/1`][kernel-boolean-not] 相互补充。

```elixir
0 and true
# => ** (BadBooleanError) expected a boolean on left-side of "and", got: 0

0 && true
# => true
```
