# 关于

ClojureScript 是一个面向 JavaScript 的 Clojure 编译器。它生成的 JavaScript 代码与 Google Closure 优化编译器的高级编译模式兼容。

## 为什么选择 Clojure？

Clojure 是一门动态的通用编程语言，支持交互式开发。Clojure 是一门函数式编程语言，拥有丰富的不可变持久化数据结构。作为 Lisp 的一种方言，它秉持代码即数据的理念，并具备强大的宏系统。

## 为什么选择 JavaScript？

浏览器和基于 Web 的应用的普及，让 JavaScript 获得了其他任何语言都无法比拟的广泛覆盖。正因如此重要，JavaScript 引擎也在接受大量的研究与优化，使 JavaScript 在性能上能与 JVM 等许多更成熟的平台一较高下。

## 为什么选择 Google Closure？

作为当今一些最复杂的客户端服务 Web 应用背后的提供者，Google 投入了大量精力来创建 Closure 库和 Closure 编译器。二者协同工作，使全程序优化成为可能，从而让即使使用了许多库的程序也能把加载时间降到最低。

## 机会

ClojureScript 将 JavaScript 平台的广泛覆盖、Clojure 的灵活性与交互式开发，以及 Google Closure 的全程序优化结合在一起，为 Web 编程提供了最强大的语言。
