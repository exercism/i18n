# 说明

作为一名国际象棋爱好者，你想写出属于自己的那款棋。
没错，网上可能已经有不少现成的国际象棋实现，但你的版本会是独一无二的！

你首先要为棋子实现一套基本的移动系统。

这局国际象棋在一个宽 8 格、长 8 格的棋盘上进行。
每个格子用字母和数字来标识。

## 1. 定义 rank 和 file 的范围

程序需要存储棋盘的 rank。
rank 是棋盘的行，编号从 1 到 8。

程序还需要存储棋盘的 file。
file 是棋盘的列，用字母 A 到 H 表示。

定义`Chess::RANKS`和`Chess::FILES`常量，分别存储 rank 和 file 的范围。

```ruby
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 检查格子是否有效

程序需要检查一个格子是否有效。
如果 rank 和 file 都在各自的范围之内，这个格子就是有效的。

定义`Chess.valid_square?`方法，它接受两个实参：`rank`存放表示 rank 的整数，`file`存放表示 file 的字符。
如果 rank 和 file 都在各自的范围之内，方法应返回`true`，否则返回`false`。

```ruby
Chess.valid_square?(1, 'A')
# => true
```

## 3. 获取玩家的昵称

程序需要获取玩家的昵称。
昵称由玩家名字的前 2 个字符加上姓氏的后 2 个字符组成。
昵称应当大写。

定义`Chess.nickname`方法，它接受两个实参：`first_name`存放玩家名字的字符串，`last_name`存放玩家姓氏的字符串。
方法应返回玩家大写的昵称字符串。

```ruby
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 创建走棋消息

程序需要为一步走棋创建消息，说明哪位玩家移动到了哪个格子。
消息要用到玩家的昵称和他们移动到的格子。
程序还要判断这步棋是否有效，方法是检查该格子的 file 和 rank 是否在各自的范围之内。

如果这步棋有效，消息应当是：`"{nickname} moved to {square}"`
如果这步棋无效，消息应当是：`"{nickname} attempted to move to {square}, but that is not a valid square"`

定义`Chess.move_message`方法，它接受三个实参：`first_name`存放玩家名字的字符串，`last_name`存放玩家姓氏的字符串，`square`存放玩家移动到的格子的字符串。
方法应以字符串的形式返回这步棋的消息。

```ruby
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
