# 学习

* [The Rust Programming Language](https://doc.rust-lang.org/book/) 是入门 Rust、以及深入了解 Rust 各项具体特性的绝佳资源。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) 用示例展示你在 Rust 中最常写到的那些内容。
* [Into_rust()](http://intorust.com/)：“学习 Rust 的视频教程。”
* [Rustlings](https://github.com/carols10cents/rustlings)：“帮助你熟悉阅读和编写 Rust 代码的小练习。”
* [Rust User Forum](http://users.rust-lang.org) 会解答各个水平的问题
