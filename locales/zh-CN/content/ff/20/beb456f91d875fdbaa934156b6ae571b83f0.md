# 简介

## switch 语句

和 _if/else_ 语句一样，`switch` 语句也能让你通过有条件地执行代码来改变程序的执行流程。
区别在于，`switch` 语句只能把一个基本类型或字符串表达式的值与预先定义的常量值进行比较。

使用`switch`语句时，有几个关键字很有用。

- `switch`：这个关键字用来声明`switch`的结构。
  它后面跟着会改变结果的表达式或变量。
- `case`：你会用这个关键字来声明结果可能出现的各种情况。
- `break`：`break`关键字非常有用，它能在想要的流程结束时停止`switch`的执行。
  如果忘了写它，程序会继续执行下去，可能产生意想不到的结果。
- `default`：顾名思义，当没有其他`case`匹配表达式的结果时，用它作为默认结果。

最简单的`switch`语句会测试一个基本类型或字符串表达式，并根据它的值做出判断。
例如：

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
