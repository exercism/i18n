# 运行测试

要运行某个练习的测试，`cd`进入该文件夹，然后运行以下命令：

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

测试使用了一个叫 TestBox 的库，它同时支持 xUnit 和 BDD 两种测试风格。所有测试套件都以 [BDD 风格](https://testbox.ortusbooks.com/content/primers/bdd/specs.html) 编写，这种风格用闭包来定义测试规格。你不需要操心安装 TestBox 的事，CLI 测试运行器会替你处理好。第一次运行时，你只要联网就行。你可以在这里了解更多信息：

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
