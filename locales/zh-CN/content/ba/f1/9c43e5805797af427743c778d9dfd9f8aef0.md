# 说明

你正在为学校的演出喊提示词。舞台监督希望把这些标准台词都写下来，好让任何人都能接手控制台。

一共四个任务，全部在`STAGE_DIRECTIONS`类中完成。

## 1. 播报开场

返回开场时的那句台词。

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. 播报中场休息

返回中场休息时报出的那句台词。

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. 播报落幕

返回谢幕时的那句台词。

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. 喊出最后一条提示

最后一条提示和谢幕那句台词完全相同。不要再把这段文字写一遍，直接调用你已经写好的那个例程。

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
