# 简介

许多语言都有 `null` 或 `none` 之类的方式来表示不存在的值。
因为 R 的设计目标就是处理大量（往往很杂乱）的数据，所以它有多种表示“无”的形式。

总体目标是，在遇到缺失或可疑的值时把它们标记出来，然后继续运行，而不是抛出异常。

## NULL

如果一个值确实不存在，就用 `NULL` 表示。这大概最接近 C 或 Python 的做法。

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

在很多场景下，`NULL` 值会被直接忽略：

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

对于值存在、但我们不知道它是多少的情况，就用 `NA`。例如，在统计一条路上通行的车辆时，人工观察员可能会请病假，自动传感器也可能会出故障，但车流仍在继续。

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

因此 `NA` 是一个占位符，提醒人们需要决定如何处理它。

## 空向量

也许出乎意料的是，R 并没有检查“空”的标准方法，不过一些第三方包实现了自己的函数，比如 `is.empty()`。

就连生成一个空向量也不是那么显而易见。
我们在前面的小节看到，不带实参的 `c()` 返回的是 `NULL`，而不是向量。

```R
is.vector(c())
#> [1] FALSE
```

像 `logical()` 或 `integer()` 这样的函数会接收一个实参来指定所需的长度，这个长度可以是零。

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

我们也可以先生成一个向量，再删掉其中每个元素，具体做法见[向量概念][concept-vectors]。
这样得到的是一个长度为 0、类型合适的向量。

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```

[concept-vectors]: https://exercism.org/tracks/r/concepts/vectors
