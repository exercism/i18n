# 简介

在 Python 中，可以用 [`if`][if statement]、`elif`（_“else and if”的缩写_）和 `else` 语句来[控制执行流程][control flow tools]，并在程序中做出判断。
与许多其他编程语言不同，Python 3.9 及更早的版本没有提供正式的分支选择语句，而是通过多个 `elif` 语句来实现类似的功能。

Python 3.10 引入了一种名为`pattern matching`的分支选择语句变体，它将在另一个概念中单独介绍。

条件语句使用的表达式必须求值为`True`或`False`，要么直接返回一个`bool`，要么通过求值得到[“truthy”或“falsy”][truth value testing]。


```python
x = 10
y = 5

# The comparison '>' returns the bool 'True',
# so the statement is printed.
if x > y:
    print("x is greater than y")
...
>>> x is greater than y
```

与`if`搭配使用时，当原来的`if`条件求值为`False`，可选的`else`代码块就会执行：

```python
x = 5
y = 10

# The comparison '>' here returns the bool False,
# so the 'else' block is executed instead of the 'if' block.
if x > y:
    print("x is greater than y")
else:
    print("y is greater than x")
...
>>> y is greater than x
```

`elif`允许进行多次求值、走多个分支。

```python
x = 5
y = 10
z = 20

# The elif statement allows for the checking of more conditions.
if x > y > z:
    print("x is greater than y and z")
elif y > x > z:
    print("y is greater than x and z")
else:
    print("z is greater than x and y")
...
>>> z is greater than x and y
```

[布尔运算][boolean operations]和[比较][comparisons]可以与条件语句结合，实现更复杂的判断：

```python
>>> def classic_fizzbuzz(number):
...     if number % 3 == 0 and number % 5 == 0:
...         say = 'FizzBuzz!'
...     elif number % 5 == 0:
...         say = 'Buzz!'
...     elif number % 3 == 0:
...         say = 'Fizz!'
...     else:
...         say = str(number)
...     return say

>>> classic_fizzbuzz(15)
'FizzBuzz!'

>>> classic_fizzbuzz(13)
'13'
```
