# 提示

## 1. 为员工打印工作牌

- [字符串内插][string-interpolation]可以简洁地格式化工作牌。
- 有一个[把字符串转换成大写的内置方法][toupper]。

## 2. 为新员工打印工作牌

- 使用 ID 之前，应该先检查它是不是`null`。
- [这篇教程详细介绍了如何使用可空值类型][nullable-types-tutorial]。

## 3. 为所有者打印工作牌

- 使用部门之前，应该先检查它是不是`null`。
- [这篇教程详细介绍了如何使用可空引用类型][nullable-reference-types-tutorial]。
- 可以用[null 条件运算符][null-conditional-operator]简化对可空值调用成员的操作。
- 如果可空值是`null`，可以用[null 合并运算符][null-coalescing-operator]简化返回另一个值的操作。
