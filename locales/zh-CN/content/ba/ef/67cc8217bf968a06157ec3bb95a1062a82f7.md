# 提示

## 1. 创建一个新数组

- Common Lisp 有一个[名字起得相当直白的函数][hyper-list]，用来创建 _LIST_。

## 2. 向数组中添加元素

- 要把一个元素加到数组开头，惯用的做法是用 *CONS* 构造一个新数组：把该元素作为 `car`，把原来的数组作为 `cdr`。在 Hyperspec 中可以找到[一页][hyper-cons]，其中介绍了这个函数。

## 3. 数组中的下一个元素是什么？

- Common Lisp 有一个通用函数，可以[从数组的任意下标处取出元素][hyper-nth]。
- 它还有[几个辅助函数][hyper-first-tenth]，用于访问 11 以下的下标。
- 数组的下标从 0 开始。

## 4. 从数组中删除元素

- 删除数组第一个元素的惯用做法，是使用一个能把数组的`cdr`和`car`分开的函数。在 Hyperspec 中可以找到[一页][hyper-rest]，介绍了其中一个能做到这一点的函数。

## 5. 用小的数组拼出大的数组

- Common Lisp 有一个函数，[专门用来把一个数组添加到另一个数组的前面][hyper-append]。

## 6. 数组有多长？

- Common Lisp 有一个[名字一目了然的函数][hyper-length]，用来获取数组的长度。
