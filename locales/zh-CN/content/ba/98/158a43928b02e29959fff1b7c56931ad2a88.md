# 简介

## 结构体

C# 的`struct`和`class`关系密切。它们有状态和行为。它们有接收实参的构造函数，实例可以被赋值、进行相等性测试，也可以存储在集合中。

```csharp
enum Unit
{
    Kg,
    Lb
}
struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```
