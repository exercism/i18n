# 安装

Exercism 让你可以直接在浏览器里编写和测试 ABAP 代码，无需额外安装。不过，如果你更想在自己的系统上编写和测试代码，也可以获取一套 ABAP 试用系统。

当然，你所在的公司可能正在运行 SAP。请联系 IT 部门，确认能否以及如何获得 ABAP 开发沙箱的访问权限。

## 该选择哪个版本？

我们建议使用仍处于支持期的 ABAP 平台当前版本。目前即 **ABAP 7.5 及以上版本**。关于当前版本及其支持时间线的详细信息，请见 [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise)。

## 需要安装什么？

我们推荐使用最新的 [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial)，它基于 ABAP 7.58。你可以把 SAP ABAP 系统安装为 Docker 镜像，也可以使用托管在 SAP Cloud Appliance Library 中的版本。此外，你还需要根据本机操作系统安装 SAP GUI，Windows 版或 Java 版均可。你可以从[这里](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui)下载 SAP GUI。

更多细节请见这篇 [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183) 博客。
