# 简介

## 管道运算符

`|>`运算符称为管道运算符。它可以用来把函数调用串联起来，使前一次函数调用返回的值传给下一次函数调用。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上面的代码等价于下面这段：

```gleam
string.append(string.uppercase("hello"), "?!")
```

管道运算符要么把值作为第一个实参传给函数调用，要么把它作为唯一实参传给新的调用，具体取决于哪种做法能得到正确的类型。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

有时我们想把值传入另一个位置，这时可以使用`_`占位符来指明该值应插入的位置。

```gleam
100
|> some_function(1, _, 2)
```
