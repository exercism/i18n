# 函数

在 JavaScript 中，函数是_一等对象_，这意味着它们可以赋值给变量和属性，可以传给其他函数，也可以从函数中返回。它们和任何其他_对象_一样，可以拥有属性和方法。

## 输入：传入实参

JavaScript 函数允许你在调用它们时传入实参。实参总是[按值传递](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7)的。换句话说，如果在函数内部给形参重新赋值，函数外部的值不会改变。但这并不意味着传入的对象不能被修改。

> [!TIP]
> 传入对象时，该对象的引用是按值传入的。这让人_觉得_传入对象的处理方式有所不同，但事实并非如此。

一个接收两个实参并将它们相乘的函数示例如下：

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 输出：返回值

JavaScript 可以通过`return`关键字从函数中返回一个值，后面跟一个表达式。当函数没有返回任何内容时，返回的值是`undefined`。

一个返回值的函数示例如下：

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## 定义函数

JavaScript 中的函数有四种形式：

1. 普通函数：可以返回任何内容，并且总是运行到结束；
2. 异步函数：总是返回一个`Promise`，可以用`await`运算符暂停和恢复；
3. 生成器函数：总是返回一个`Generator`对象，可以用`yield`运算符暂停和恢复；
4. 异步生成器函数：总是返回一个`AsyncGenerator`对象，可以同时用`yield`和`await`两个运算符暂停和恢复。

对这四种形式中的每一种，都有三种定义方式：

1. 使用声明
2. 使用表达式
3. 使用构造函数

最后，还有一些用于定义_箭头函数和方法_的特殊语法。
