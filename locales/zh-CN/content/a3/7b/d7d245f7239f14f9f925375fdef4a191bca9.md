# 简介

`for`循环可以遍历数组，并对每个元素重复执行代码：

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

在上面的例子中，`fruit`这个变量保存了数组`fruitList`中单个元素的值。编译器会确保`fruitList`可以被遍历，否则就会停止执行。

你也可以使用范围运算符来遍历数字。这个运算符接受两个`Int`操作数，写法是`min...max`：

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```
