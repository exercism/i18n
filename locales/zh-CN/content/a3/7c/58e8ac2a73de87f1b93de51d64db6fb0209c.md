# 简介

## 字符串

Elixir 中的字符串用双引号包围，采用 UTF-8 编码：

```elixir
"Hi!"
```

字符串可以用`<>/2`运算符拼接：

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir 的字符串支持使用`#{}`语法进行插值：

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

要在字符串里放入一个换行符，使用`\n`转义符：

```elixir
"1\n2\n3\n"
```

如果文本里有很多换行，用起来更方便的是三引号 heredoc 语法：

```elixir
"""
1
2
3
"""
```

Elixir 在`String`模块中提供了许多处理字符串的函数。

## 管道运算符

`|>`运算符叫做管道运算符。它可以把多个函数调用串联起来：前一个函数调用的返回值，会作为第一个实参传给下一个函数调用。

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
