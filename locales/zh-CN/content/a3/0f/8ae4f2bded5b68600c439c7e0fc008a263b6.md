# 简介

## 结构体类型

之前我们已经见过结构体类型。回顾一下，`struct`是由一系列叫做_字段_的具名元素组成的序列，每个字段都有自己的名字和类型。字段名在同一个结构体内必须唯一。结构体可以类比面向对象编程范式中的_类_。

你可以使用`type`和`struct`关键字创建一个新的结构体，然后像下面的示例那样显式定义各个字段的名字和类型。

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## 非结构体类型

你也可以定义非结构体类型，把它们用作内置类型声明的别名。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你还可以定义由数组和映射组成的非结构体类型。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
