# 关于

字典与其他语言中的映射或关联数组等类似结构一样，用来存储键值对：只要把键传给字典的索引器属性，就能直接获取或修改对应的值。

此外，还可以向字典中添加键值对，也可以从中删除键值对。键、值以及键值对都可以枚举。

值可以是任意 C# 类型的对象，包括基元类型、结构体_和_类。

Dictionary 对象允许键为任意类型的对象。不过，要确保运行时的行为正确，键必须具有由 [GetHashCode][gethashcode] 返回的合适的哈希码。

一个字典实例不能由多个线程安全地访问（非线程安全）。多线程场景可以使用 [ConcurrentDictionary][concurrent-dictionary]。

另请参阅 [HashSet][hashset]、[ConcurrentDictionary][concurrent-dictionary]、[SortedDictionary][sorted-dictionary]。

虽然 Dictionary 没有非泛型版本，但库中仍保留了一些类来支持非泛型的映射。你需要了解非泛型的 IDictionary 和 Hashtable，主要是为了在见到它们时能认出来。除了维护旧的代码库之外，你不太可能用到它们。

你通常会希望通过[`IDictionary<TKey, TValue>`][idictionary]接口来公开和访问字典。

注意，由于[索引器属性][indexer-properties]的特性，基元类型的值可以就地修改，例如：

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
