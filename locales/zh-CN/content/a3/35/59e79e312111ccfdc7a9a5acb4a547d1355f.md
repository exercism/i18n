# 说明

在这个练习中，你将实现一款角色扮演游戏的各项机制。
玩家的角色由以下类型表示：

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

这个游戏中的玩家必须先达到 10 级，才能解锁法力池，从而开始施放法术。
你将在这个游戏中实现两个功能：复活机制和施放法术的机制。

## 1. 介绍你自己

编写`introduce`函数的内容。
注意，`Player`记录的`Name`字段是一个`Option`。
有些潜行的玩家可能想把名字设为`None`来隐藏身份，这类玩家自我介绍时会用`"Mighty Magician"`。
否则，直接用你的名字介绍自己就好。

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. 实现复活机制

`revive`函数应当检查玩家的角色确实已经死亡（生命值降到了 0）。
如果已经死亡，就返回一个生命值为 100 的新`Player`实例。
否则，如果玩家的角色没有死亡，`revive`函数就返回`None`。

如果玩家的等级达到 10 级或更高，复活时还应当带有 100 点法力值。
如果玩家的等级低于 10 级，法力值应当为`None`。
`revive`函数应当保留玩家的等级。

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

如果对生命值为 1 或更高的玩家调用`revive`方法，函数应当返回`None`。

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. 实现施放法术的机制

`castSpell`函数接收一个表示法术消耗多少法力值的`int`和一个`Player`作为实参。
它返回更新后的玩家，以及施放的法术造成的伤害值。
成功施放法术造成的伤害等于法术法力消耗的两倍。
不过，如果玩家的法力值不足，就什么也不会发生：玩家保持不变，也不造成伤害。
如果玩家连法力池都没有，那么尝试施放法术时，玩家的生命值会减少相当于法术法力消耗的量，并且不造成伤害。

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
