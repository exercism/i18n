# 关于

Elixir 中的[字符串][getting-started-strings]用双引号界定，并以 UTF-8 编码：

```elixir
"Hi!"
```

可以使用[`<>/2`][kernel-concat]运算符拼接字符串：

```elixir
"Welcome to" <> " " <> "New York"
# => "Welcome to New York"
```

Elixir 中的字符串支持[插值][string-interpolation]，使用的语法是`#{}`：

```elixir
"6 * 7 = #{6 * 7}"
# => "6 * 7 = 42"
```

插值内部可以是任意合法的 Elixir 表达式。如果插入的是一个字符串，就按原样插进去。如果插入的是其他值，Elixir 会尝试把它转换成字符串。

```elixir
"Elixir can convert booleans to strings: #{true}"
# => "Elixir can convert booleans to strings: true"

"And #{["lists", ", ", "too!"]}"
# => "And lists, too!"

"But not functions: #{fn x -> x end}"

# => ** (Protocol.UndefinedError) protocol String.Chars not implemented for #Function<7.126501267/1 in :erl_eval.expr/5> of type Function
#        (elixir 1.10.1) lib/string/chars.ex:3: String.Chars.impl_for!/1
#        (elixir 1.10.1) lib/string/chars.ex:22: String.Chars.to_string/1
```

Elixir 在`String`模块中提供了许多处理字符串的函数。如果你不确定该怎样按自己的需要处理字符串，不妨浏览一下[`String`模块中可用的函数][string-module-functions]，你很可能会找到自己需要的东西。

```elixir
String.downcase("PLEASE NO SHOUTING")
# => "please no shouting"

String.split("hello", "", trim: true)
# => ["h", "e", "l", "l", "o"]

String.replace("Do I enjoy Elixir? Maybe...", "Maybe...", "Definitely!")
# => "Do I enjoy Elixir? Definitely!"

String.at("12345", 2)
# => "3"
```

使用其中一些函数时，请记住字符串中第一个字符的下标是`0`。

有些字符需要[转义][escape-characters]才能放进字符串，比如换行符、双引号，或者`#`字符：

```elixir
"\"A\" is the \#1st letter of the alphabet.\n"
```

如果想轻松处理包含大量换行的文本，改用[三引号 heredoc 语法][heredoc-syntax]会更方便：

```elixir
"""
1
2
3
"""
```

你经常会看到这种语法被用来为代码写文档：

```elixir
defmodule MyApp.Hello do
  @moduledoc """
  This is the Hello module.
  """

  @doc """
  Says hello to the given `name`.

  Returns `:ok`.

  ## Examples

      iex> MyApp.Hello.world(:john)
      :ok

  """
  def world(name) do
    IO.puts("hello #{name}")
  end
end
```
