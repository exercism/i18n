# 简介

Elixir 代码运行在 BEAM 虚拟机中。BEAM 是 Erlang 运行时系统的一部分。Elixir 受 Erlang 启发，并与其共享运行环境，因此能与 Erlang 库很好地互操作。这意味着 Elixir 开发者可以在自己的 Elixir 代码中使用 Erlang 库。事实上，对于 Erlang 库已经提供的功能，Elixir 社区不鼓励再编写 Elixir 库来实现。

因此，某些功能，比如数学运算或定时器函数，在 Elixir 中只能通过 Erlang 使用。

Erlang 的标准库可以直接在我们的 Elixir 代码中使用，无需任何额外步骤。

调用 Erlang 函数的方式与调用 Elixir 函数相同，只有一个小区别：Erlang 的模块名是`snake_case`原子。例如，要调用`math`模块中的 Erlang `pi/0`函数，可以这样写：

```elixir
:math.pi()
# => 3.141592653589793
```

最常用的、在 Elixir 中没有对应实现的 Erlang 函数有：

- `:timer.sleep/1`，将进程暂停指定的毫秒数。
- `:rand.uniform/0`，生成一个随机浮点数`x`，其中`0.0 <= x < 1.0`。
- `:io_lib.format/2`，提供 C 风格的字符串格式化（使用控制序列）。例如，可以用它把整数按 2 到 36 之间的任意进制打印出来，或者按所需精度格式化浮点数。注意，这个函数和许多 Erlang 函数一样，返回的是 charlist。
- `math`模块，提供诸如`sin/1`、`cos/1`、`log2/1`、`log10/1`、`pow/2`等数学函数，以及更多。

要了解 Erlang 的标准库，可以查阅 [STDLIB 参考手册][erl-stdlib-ref]。

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
