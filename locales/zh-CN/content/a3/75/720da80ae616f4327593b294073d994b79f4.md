# 关于

你运行过的每一个程序，无论是游戏、网页浏览器还是手机应用，最终都会变成一长串微小的指令，由处理器一条一条地执行。
汇编语言就是你自己来编写这些指令的方式。
这里没有变量、数组和 `for` 循环，你操作的是处理器自己的基本构件：一小部分寄存器、内存地址，以及指令之间的跳转。

RISC-V（读作“risk five”）是一种处理器设计，2010 年起源于加州大学伯克利分校。
与大多数处理器设计不同，它是一个开放标准：任何人都不需要付费或申请许可就能制造 RISC-V 芯片，规范也免费供所有人阅读。
RISC-V 芯片出现在微控制器、单板计算机、存储设备等许多地方。

RISC-V 是一种很好的入门汇编语言，因为它从设计上就追求简洁。
它的指令遵循少量固定的模式，32 个寄存器职责清晰一致，所以需要记住的内容远少于大多数笔记本电脑里的处理器。
也正是因为这种简洁，如今许多大学都用 RISC-V 来讲授计算机的工作原理。

下面是一个小小的示例，一个把两个数字相加的函数：

```riscv
add_numbers:
        add     a0, a0, a1      /* a0 = a0 + a1 */
        ret                     /* return to the caller, with the answer in a0 */
```

在这个学习路径中，你编写的是 32 位的 RISC-V 汇编。
你不需要任何 RISC-V 硬件：程序会在模拟器上测试，模拟器会模拟一颗 RISC-V 处理器。
你既可以在在线编辑器中完成练习，也可以用免费工具在自己的电脑上完成。

学习汇编需要耐心，但这份付出是值得的。
一旦你看到循环或函数调用在处理器看来是什么样子，其他编程语言就会变得更容易理解一些。
