# 运行 Ceylon 测试

在运行测试之前，你的代码必须先通过[`ceylon compile`](https://ceylon-lang.org/documentation/current/reference/tool/ceylon/subcommands/ceylon-compile.html)编译。

我们使用[`ceylon test`](https://ceylon-lang.org/documentation/reference/tool/ceylon/subcommands/ceylon-test.html)命令运行测试。

`ceylon test`需要一个模块名，用来指定要运行测试的模块。
在 Ceylon 学习路径中，每个练习只有一个模块。

因此，你可以用以下命令运行测试：

```bash
ceylon compile && ceylon test $(basename source/*)
```
