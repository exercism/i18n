# 说明

你是货轮上的无线电报务员。信号通过一条嘈杂的线路传来：船上的机械声、天气静电、偶尔传来的外语通话，全都和你真正要收听的摩尔斯电码混在一起。为了捕捉这条消息，你把线路接到一台*磁带*设备上，它会滤掉除了有效摩尔斯符号之外的一切（`.`、`-`，以及分隔字母的空格）。

你的任务就是把这个磁带做成一款自定义 Factor 输入流。

## 1. 定义 tape

定义一个 `tape` 元组，让它继承 `disposable`，并包含一个槽位 `wire`，用来存放底层的输入流。

```factor
TUPLE: tape < disposable wire ;
```

然后编写构造函数 `<tape> ( wire -- tape )`。使用 `new-disposable`（而不是 `new`），这样析构框架就会把磁带登记进去；再把底层流存进 `wire` 槽位。

## 2. 混入 input-stream

把 `tape` 声明为一个 `input-stream`：

```factor
INSTANCE: tape input-stream
```

这样，协议默认的组合子就会分派到你的类上。

## 3. 读取一个摩尔斯符号

实现 `M: tape stream-read1 ( tape -- elt/f )`。从底层线路读取字节，直到遇到 `CHAR: .`、`CHAR: -` 或 `CHAR: \s`（空格）中的一个。返回那个字节。如果线路返回 `f`（流已结束），你也返回 `f`，磁带的事就到此为止。

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. 委托元素类型

实现 `M: tape stream-element-type ( tape -- type )`，把工作委托给线路。磁带不会改变所读元素的类型。

## 5. 清理

实现 `M: tape dispose* ( tape -- )`。框架每次 `dispose` 只会调用你这个方法一次；你只需要释放底层的线路。

这五部分就位后，磁带就能像普通的输入流一样工作：`with-input-stream`、`stream-read` 以及其他协议词都会自动分派到你的方法上。
