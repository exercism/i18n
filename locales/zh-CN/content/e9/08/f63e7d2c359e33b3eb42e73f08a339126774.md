# 关于

- [binary][binary] 类型是 [bitstring][bitstring] 类型的一种特化。
- binary 由[字节][wiki-byte]组成。
  - 一个字节是 8 [位][wiki-bit]。
  - 字节可以表示从 `0` 到 `255` 的数字。
  - 处理字节时，[十六进制][wiki-hexadecimal]整数值很常见：`0x00` 到 `0xFF`。
- binary 字面量使用 [`<<>>` 特殊形式][special-form]定义。
  - 如果你给一个字节使用大于 `255` 的整数，那么只会使用最后 8 位，除非你使用 [`::`][type-operator] 运算符指定[要使用的单位和/或大小][bin-size]。
- 可以使用 [`<>/2`][bin-concat] 来拼接 bitstring、binary 和字符串。

```elixir
<<255>> == <<0xFF>>
# Overflowing bits are truncated
<<256>> == <<0>>
<<256::size(16)>> == <<1, 0>>

<<"Hello">> == <<72, 101, 108, 108, 111>>
```

_空字节_ 是 `<<0>>` 的另一个名字。

## 字符串是编码后的二进制数据

- 字符串是以 [UTF-8][wiki-utf8] 格式编码的二进制数据。
  - 它们以 8 位（一个字节）为单位进行编码，最多使用 4 个字节来表示 255 以外的字符。
  - 字符串的[长度][string-length]可能与它的[字节大小][byte-size]不同。

```elixir
# This string has a string length of 5, but is made up of 7 bytes
string = "cześć"
String.length(string) != byte_size(string)

# Even emoji strings are encoded binaries
"👍" == <<240, 159, 145, 141>>
```

## 对二进制数据进行模式匹配

- 可以[把 binary 作为整体进行模式匹配，也可以使用特殊形式][special-form]只匹配其中一部分。
  - 模式匹配中只有最后一部分可以具有可变大小。

```elixir
# Ignore the first 8 bytes, bind the remaining variable sized binary to `body`
<<_::binary-size(8), body::binary>>
```

字符串也可以这样做：

```elixir
# bind the first 5 bytes to `name`,
# match the string literal " the ",
# bind remaining bytes to `species`
<<name::binary-size(5), " the ", species::binary>> = <<"Frank the Walrus">>
{name, species}
# => {"Frank", "Walrus"}
```
