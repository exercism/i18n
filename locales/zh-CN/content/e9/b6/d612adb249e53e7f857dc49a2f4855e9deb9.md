# 线程

本练习引入线程，用来测试你的银行账户在并发操作下有多健壮。下面是一些 Tcl 线程的阅读材料：

* [Tcl Threading Model](https://www.tcl.tk/doc/howto/thread_model.html)
* [Threads Done Right… with Tcl](https://www.activestate.com/blog/threads-done-right-tcl/)
* [Multi-Threaded Tcl Scripts](http://www.beedub.com/book/4th/Threads.pdf)，
  摘自 _Practical Programming in Tcl and Tk, 4th Ed._ 的一章，
copyright 2003 © Brent Welch, Ken Jones
[http://www.beedub.com/book/](http://www.beedub.com/book/)
    * 注意，这一章写道 “Most binary distributions of Tcl are not thread-enabled”。现在情况已经不是这样了：如今的 Tcl 发行版都带线程支持（参见 [TIP 364](https://core.tcl-lang.org/tips/doc/trunk/tip/364.md)）
* [Thread Package Commands](https://tcl.tk/man/tcl8.6/ThreadCmd/contents.htm)，出自 Tcl 文档。

## 安装

有些 Tcl 发行版默认不包含 Tcl 的 Thread 包：它可能需要单独安装。
用下面的命令验证
```bash
$ echo 'package require Thread' | tclsh
```
如果它_没有输出_，说明 Thread 包已经安装好了。

按需执行 `apt install tcl-thread`（或 `dnf install tcl-thread`）。
