# 简介

[`Basics`][basics]概念介绍了两种定义函数的方式。

最一般的形式是多行写法：

```julia
function muladd(x, y, z)
    x * y + z
end
```

对于简短的定义，还有“赋值”形式，也叫“单行”形式：
```julia
muladd(x, y, z) = x * y + z
```

还有第三种更简短的形式：可以创建没有名字的、简短且只用一次的函数：

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

在这种情况下，`x -> 2x`是一个“匿名函数”。
这相当于其他一些语言中所说的“lambda 函数”。

注意，多个实参需要用括号括起来，比如 `(x, y) -> x * y`。

匿名函数在 Julia 代码中很常见，尤其是与`map()`和`filter()`这类高阶函数结合使用时。

## 函数的实参

到目前为止，在本教学大纲中，我们只看了那些实参数量固定、且要求函数调用按正确顺序提供全部实参的函数。
这样会很有局限，也不方便，所以还有几种其他选择。

### 可选实参

和许多语言一样，Julia 允许在函数定义中为单个实参提供默认值。

函数调用时，既可以给该实参提供一个值，也可以省略它，使用默认值。

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

所有_没有_默认值的实参都必须排在任何_有_默认值的实参前面，也就是说`f(x=2, y)`是无效的。

### 关键字实参

到目前为止的所有示例都用的是 `positional arguments`，也就是说函数调用中提供的值必须与函数定义中对应实参的顺序一致。

和许多语言一样，Julia 也支持 `keyword arguments`。
函数调用时必须指定实参名，但多个关键字实参可以按任意顺序给出。

Julia 的一个独特之处是，函数定义中的关键字实参（如果有）前面必须加一个分号 `;`，以便和位置实参分开。
函数调用时，在最后一个位置实参和第一个关键字实参之间，可以用 `;` 或 `,`。

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

和位置实参一样，也可以选择性地指定默认值。

当某个与形参同名的变量已经预先算好时，函数调用里常常会出现`myarg=myarg`这样的写法。
这种情况下可以使用简写语法：

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat 和 slurp

如果你好奇的话，这两个名字是 Julia 语法中一个实用特性的标准叫法。
两者都指 `...` 运算符。

#### Splat

Splat 用在函数的_调用_中，把集合展开成函数所需要的各个独立的值。

这个用示例演示比用语言解释更容易：

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

有些“函数调用”被语法糖隐藏了起来，所以 splat 也可以用在不那么明显的地方。

例如，多重赋值内部使用了一个元组构造函数：

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

关键字实参也可以通过 splat 提供，通常使用 `named tuple`。 
用`Dict`也可以，但键必须是符号（字符串不行）。

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Slurp 用在函数的_定义_中，把任意数量的单个值打包进一个集合。

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

被 slurp 的实参的名字（这里是 `more`）并不重要。
这个变量的类型由编译器决定，但对于位置实参来说，很可能是 `tuple` 或类似的类型。

关键字实参也可以被 slurp，得到一个 `Dict`（或类似的东西）。

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

调用时可以使用任意关键字实参。
由函数定义来决定响应哪些关键字、忽略哪些关键字。
