# 提示

## 1. 定义`Usd`、`Eur`和`Jpy`类型

- `Usd`、`Eur`和`Jpy`类型无需构造器，使用`pub type TypeName`语法即可定义。

## 2. 定义`Money`类型

- `Money`类型应有一个用于货币的幻影类型参数。

## 3. 定义`dollar`、`euro`和`yen`函数

- `dollar`、`euro`和`yen`函数的返回类型标注应为`Money(currency)`，其中`currency`是`Money`类型对应的类型参数。

## 4. 定义`total`函数

- `total`函数的返回类型标注应使用与实参相同的类型参数。
