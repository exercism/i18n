# 资源

## 参考资料

- [RISC-V 参考卡片][reference-card]列出了指令、伪指令和寄存器。
- [RISC-V 调用约定][psabi]说明了函数的输入和结果存放在哪些寄存器中，以及函数必须保留哪些寄存器。
- [RISC-V 规范][isa-manual]详细说明了每条指令的具体作用。
- [GNU 汇编器手册][gas-directives]介绍了`.section`、`.string`、`.word`和`.global`等指示符。

## 工具

- [Compiler Explorer][godbolt]可以显示编译器为一段 C 代码生成的汇编。
  该链接会以 32 位 RISC-V 编译器打开它，这样你就可以把自己写的解答与编译器生成的汇编进行对比。

## 社区

- [RISC-V International][riscv-org]是负责维护 RISC-V 标准的组织。
- [r/RISCV][reddit]是一个分享 RISC-V 芯片、开发板和软件相关资讯的 Reddit 社区。
- [Stack Overflow][stack-overflow]上有关于 RISC-V 汇编的问题和解答。
