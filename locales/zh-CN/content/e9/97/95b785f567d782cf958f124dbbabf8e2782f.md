# 测试

要运行提供的测试，你需要 Minitest gem。打开终端窗口，运行以下命令安装 minitest：

```
gem install minitest
```


在练习目录中运行以下命令来运行测试：

```
ruby <snake-case-exercise>_test.rb
```

请把`<snake-case-exercise>`替换为你的练习名称（snake_case 格式）。

## 彩色输出

你可以`require 'minitest/pride'`，或者运行以下命令来获得彩色输出：

```
ruby -r minitest/pride <snake-case-exercise>_test.rb
```
