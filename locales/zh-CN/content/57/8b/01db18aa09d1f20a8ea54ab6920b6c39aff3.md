# 说明

Lamont 是一个 Lisp 外星人，想自己写一款电子游戏。他请你帮忙做的一件事，就是记录一份高分榜。

## 1. 创建高分表

定义一个函数`make-high-score-table`，它不接受任何实参，求值结果是一个新的空哈希表：

```lisp
(make-high-score-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {1005A90103}>
```

## 2. 向表中添加玩家

要向表中添加玩家，请定义一个函数`add-player`，它接受两个实参：
- 高分表
- 玩家的名字，以关键字表示

把玩家的初始分数设为 0。

```lisp
(add-player hash-table :louis) ; => 0
(add-player hash-table :lilly) ; => 0
```

## 3. 设置玩家的分数

要为玩家设置分数，请定义一个函数`set-score`，它接受三个实参：
- 高分表
- 玩家的名字，以关键字表示
- 玩家的分数，以整数表示

```lisp
(set-score hash-table :louis 1234) ; => 1234
```

## 4. 从表中获取分数

要从表中获取某位玩家的分数，请定义一个函数`get-score`，它接受两个实参：
- 高分表
- 玩家的名字，以关键字表示

这个函数的求值结果应该是为该玩家存储的分数。
如果该玩家没有存储分数，或者该玩家还不在表中，则求值为`0`。

```lisp
(get-score hash-table :louis)                         ; => 1234
(get-score hash-table :lilly)                         ; => 0
(get-score hash-table :not-a-character-in-this-story) ; => 0
```

## 5. 从表中移除玩家

要从高分表中移除玩家，请定义一个函数`remove-player`，它接受两个实参：
- 高分表
- 玩家的名字，以关键字表示

对于玩家尚未添加到表中的情况，这个函数也应该能妥善处理。
显然，移除玩家之后再从表中获取他的分数，得到的就是 0。

```lisp
(set-score hash-table :louis 1234)           ; => 1234
(remove-player hash-table :louis)            ; => T
(get-score hash-table :louis)                ; => 0

(remove-player hash-table :not-in-the-table) ; => NIL
```
