# 简介

在 Rust 中，任何实现了 [`Iterator`](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html) trait 的类型，都可以当作迭代器来使用。
Rust 内置的 [`collections`](https://doc.rust-lang.org/std/collections/index.html) 可以通过 `iter`、`iter_mut` 和 `into_iter` 方法转换成迭代器。
迭代器有一整套[强大的方法](https://doc.rust-lang.org/stable/std/iter/trait.Iterator.html#provided-methods)，比如 `collect`、`map`、`filter` 和 `fold`，你可以用它们对数据执行各种操作。

```rust
use std::collections::HashMap;

let v = vec![0, 1, 2];

let mut iter = v.iter();

// Call next() to return the next value
assert_eq!(Some(&0), iter.next());
assert_eq!(Some(&1), iter.next());
assert_eq!(Some(&2), iter.next());
// Ahen None once it's over
assert_eq!(None, iter.next());

// Loop over iterators with built-in methods, such as `map` and `collect`
let w: HashMap<_, _> = v.into_iter().map(|x| (x, x + 1)).collect();
println!("{w:?}");
// => {1: 2, 0: 1, 2: 3}
```
