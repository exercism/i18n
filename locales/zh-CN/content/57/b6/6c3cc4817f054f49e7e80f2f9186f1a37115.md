# 说明

Elyse 是未来的魔术师，正在继续她的训练。
她有一副牌想要摆弄。

为了让事情简单些，她通常只用数字 2 到 10 的牌开始，不过有些戏法可能会用到额外的（人头）牌。

<!-- prettier-ignore-start -->
~~~~exercism/note
洗牌有**很多**种方式，但为了维持魔术的假象，关键在于*任何一种方法都不能使用*，例如 Elyse 不使用`splice`、`slice`、`shift`、`unshift`、`push`、`at`。
数组访问器`array[index]`和对象访问器（`object[key]`和`object.key`）也绝不能使用。
~~~~
<!-- prettier-ignore-end -->

想帮 Elyse 提升她的魔法等级吗？

<!-- prettier-ignore-start -->
~~~~exercism/advanced
每个函数都可以使用形参和一个只有单个`return expression`的函数体来实现。
~~~~
<!-- prettier-ignore-end -->

## 1. 取出第一张牌

Elyse 会召唤牌堆中的第一张牌，而不使用`array[index]`、`.at(index)`或`.shift()`。
就像变魔术一样。

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. 取出第二张牌

Elyse 施展手法，不使用`array[index]`或`.shift()`，就召唤出牌堆中的第二张牌。

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. 交换两张牌

Elyse 会让牌堆中的两张牌互换位置。
她不需要调用任何函数。

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. 轮换三张牌

为了再施展一些手法，Elyse 拿起三张牌，迅速把最上面的牌移到后面，让中间的牌成为第一张牌，原来的最下面的牌成为中间的牌。
她不需要调用任何函数。

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. 选出指定的一堆

Elyse 会把牌堆分成两堆。
接着她请观察者从两堆中挑出一堆，我们把它命名为`chosen`。
`disregarded`这一堆不再有用，她让它消失了。
她不需要调用任何函数。

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. 交换挑出的那一堆

不幸的是，观察者总是挑到“错误”的那一堆，但靠着一些巧妙迅速的手法，Elyse 把`chosen`这一堆改名为`disregarded`，把`disregarded`这一堆改名为`chosen`。
她不需要调用任何函数。

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
