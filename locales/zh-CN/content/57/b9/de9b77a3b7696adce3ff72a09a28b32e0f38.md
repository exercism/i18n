# 指令补充

## 输出格式

将菱形输出为一个以 null 结尾的字符串，每行末尾带一个换行符。

一个示例输出是 `"  A  \n B B \nC   C\n B B \n  A  \n"`

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 字节    | 字母                        |
| `$a1`    | 输入/输出 | 地址 | 以 null 结尾的结果字符串 |
| `$t0-9`  | 临时    | 任意     | 用于临时存储         |
