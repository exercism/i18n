# 说明

在本练习中，你将处理储蓄账户。
每年，你的储蓄账户余额都会根据利率进行更新。
银行给你的利率取决于你账户中的金额（即余额）：

- 余额小于`0`美元时，利率为 3.213%（余额会变得更负）。
- 余额大于或等于`0`美元且小于`1000`美元时，利率为 0.5%。
- 余额大于或等于`1000`美元且小于`5000`美元时，利率为 1.621%。
- 余额大于或等于`5000`美元时，利率为 2.475%。

本练习共有四个任务，每个任务都涉及余额及其利率。

## 1. 计算利率

实现`interest_rate`函数，根据给定的余额计算利率：

```cpp
interest_rate(200.75);
// => 0.5
```

## 2. 计算利息

实现`yearly_interest`函数，根据给定的余额计算利息：

```cpp
yearly_interest(200.75):
// => 1.003750
```

## 3. 计算年度余额更新

实现`annual_balance_update`函数，在考虑利率的情况下计算年度余额更新：

```cpp
annual_balance_update(200.75);
// => 201.75375
```

## 4. 计算达到目标余额所需的年数

实现`years_until_desired_balance`函数，计算达到目标余额所需的最少年数。注意每年都会把利息加到余额上。
也就是说，一年后的余额等于：初始余额 + 初始余额产生的利息。
第二年的余额等于一年后的余额 + 一年后的余额产生的利息。
依此类推，直到当年的余额大于或等于目标余额。

```cpp
double balance {200.75};
double targetBalance {214.88};
years_until_desired_balance(balance, targetBalance)
// => 14
```

注意，返回的值是`int`类型。
