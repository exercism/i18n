# 简介

`GENERIC:` 声明会创建一个单词，它的行为取决于某个实参的*类*。具体的行为来自*方法*，用 `M:` 定义。

```factor
GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area
    side>> dup * ;
M: circle area
    radius>> dup * pi * ;
```

调用 `area` 时，Factor 会检查栈顶，在类匹配的方法中找出最具体的那个，然后运行它。使用局部变量时，可以用 `M::`：

```factor
TUPLE: rectangle width height ;

M:: rectangle area ( r -- n )
    r width>> r height>> * ;

T{ rectangle { width 3 } { height 4 } } area .   ! => 12
```

有了泛型，你以后可以添加新的表示形式，而无需修改调用代码：`area` 本来就已经能处理 `square` 和 `circle`，而且无论在哪里调用 `area`，`rectangle` 方法都会被自动选中。

## 什么时候该用泛型

在以下情况使用 `GENERIC:`：

- 同一个操作对不同输入有*真正不同*的实现。
- 你预期以后会有代码添加新的类型。
- 你希望类型系统强制每个类都给出定义。

如果变化只是少量标签的枚举，那么用 `case` 更简单。

## 用 `INSTANCE:` 加入混入

*混入*是一种*开放*的泛型类，任何人都可以注册一个新类作为它的成员。Factor 的许多内置协议（序列、集合、流等）都以混入的形式提供，因此自定义元组可以通过声明自己是实例，来接入协议的默认方法：

```factor
MIXIN: shape
M: shape area                   ! a default area for any shape
    drop 0 ;

TUPLE: my-shape ;
INSTANCE: my-shape shape         ! my-shape is now a `shape`

T{ my-shape } area .   ! => 0
```

使用 `INSTANCE:` 之后，每个默认方法 `M: shape …` 都会自动对 `my-shape` 分派，任何要求 `shape` 的代码也都接受 `my-shape`。`M:` 用于给泛型添加方法；`INSTANCE:` 用于把一个类加入混入。

## `TYPED::`：为普通单词提供带检查的输入

`GENERIC:`/`M:` 会根据实参的类来选择方法。有时你并不需要分派，只想要*一个*单词，它坚持要求自己的输入属于某个给定的类。`TYPED::`（位于 `typed` 模块中）就是 `::`，只不过在每个输入名后面写上了类：

```factor
TYPED:: triple ( n: integer -- m )
    n 3 * ;

14 triple .   ! => 42
```

`n: integer` 读起来和你已经用过的局部变量一样，只是在冒号后面写上了类。这里没有分派，只有一份定义、一种行为，但现在每个实参都会根据它的类接受检查：像 `"x" triple` 这样的类型不匹配会被拒绝（*expected input value of type integer but got string*），而不会悄无声息地通过。

输出也可以用同样的方式标注。`yes?` 会同时标注输入和结果的类型：

```factor
TYPED:: yes? ( word: string -- answer: boolean )
    word "yes" = ;

"yes" yes? .   ! => t
"no" yes? .    ! => f
```

## 数学函数与常量

本练习还会用到 `math.constants` 和 `math.functions` 中的几个单词，你在这里会第一次见到它们：

- `pi`：常量 π，来自 `math.constants`。
- `sin ( x -- y )`、`cos ( x -- y )`：弧度制下角度的正弦和余弦。
- `e^ ( x -- y )`：`e` 的 `x` 次方。（任意底数请用 `^`。）

```factor
pi 2 / sin   ! → 1.0
0 cos        ! → 1.0
1 e^         ! → 2.718281828459045
```
