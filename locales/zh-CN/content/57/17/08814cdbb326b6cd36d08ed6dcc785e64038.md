# 说明

你的任务是用以下规则把英文文本翻译成 Pig Latin：

- **规则 1**：如果单词以元音开头，就在单词末尾加上 “ay” 音（例如 “apple” -> “appleay”）。
  请注意，位于单词开头的 “xr” 和 “yt” 发元音（例如 “xray” -> “xrayay”，“yttria” -> “yttriaay”）。
- **规则 2**：如果单词以辅音开头，就把它移到单词末尾，然后在单词末尾加上 “ay” 音（例如 “pig” -> “igpay”）。
  辅音可以由多个辅音字母组成，比如 “chair” 中的 “ch” 或 “stand” 中的 “st”（例如 “chair” -> “airchay”）。
- **规则 3**：如果单词以辅音开头，并且后面紧跟着 “qu”，就把它们一起移到单词末尾，然后在单词末尾加上 “ay” 音（例如 “square” -> “aresquay”）。
- **规则 4**：如果单词在辅音连缀之后含有 “y”，或者 “y” 是两个字母的单词中的第二个字母，那么它发元音（例如 “rhythm” -> “ythmrhay”，“my” -> “ymay”）。
