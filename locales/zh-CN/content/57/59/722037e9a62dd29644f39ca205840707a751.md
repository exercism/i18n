# 映射与集合

数组把值放在编号的位置里。有时候，真正有用的标签并不是数字。

## 映射

一个**映射**把每个**键**与一个**目标**配成一对。用键去查，映射就会把登记在这个键下的东西给你。

`FMAP{K,T}`是从类型`K`的键到类型`T`的目标的映射。把动物名字和它栖息地配对的一份指南，就是`FMAP{STR,STR}`。

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## 一定要把返回值赋回去

再看中间那一行。`insert`会返回一个多了一对数据的映射，这个返回值必须保存下来：

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

这和`FSTR`的规则一样，原因也一样。返回值通常就是传进去的那个映射，只是被就地修改了；偶尔映射已经装满了，返回值就是一个更大的新映射。既然你分不清是哪种情况，就**使用返回值，并且不要再使用旧名字**。一次`insert`之前留下的名字可能已经过时，甚至可能根本不再指向一个可用的映射。

这也意味着，传给例程的映射并不安全。如果原来的映射必须保留下来，请参见概念页面里的`copy`。

## 它在不在？

`has_ind`问的是某个键在不在映射里。这个名字是“has index”的缩写，而 index 就是这些映射对键的叫法。

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

查询一个不存在的键**不会**报错。`get`会返回该类型的空值：对`INT`来说是 0，对`STR`来说是 void，而 void 以后会在别的地方出问题。所以取之前先查一查：

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## 集合

一个**集合**存放不重复、也没有顺序的值。`FSET{T}`是类型`T`的值的集合。

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

同一个值插入两次，留下的还是一份。这正是集合的用途：收集值，同时不必记住每个值出现了多少次。

对集合调用`insert`，返回的是今后要用的那个集合，和映射完全一样，所以每次都要把它赋回去。

## 有多少

`.size`对两者都管用：映射里有多少对，集合里有多少个值。
