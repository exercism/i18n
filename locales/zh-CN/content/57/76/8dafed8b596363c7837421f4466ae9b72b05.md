# 简介

## 日期时间

Java 8 引入的`java.time`包包含多个用于处理日期和时间的类。

### `LocalDate`

`java.time.LocalDate`类表示 [ISO-8601 日历系统][iso-8601] 中不带时区的日期，例如`2007-12-03`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
```

日期可以与其他日期进行比较：

```java
LocalDate date1 = LocalDate.of(2007, 12, 3);
LocalDate date2 = LocalDate.of(2007, 12, 4);

date1.isBefore(date2);
// => true

date1.isAfter(date2);
// => false
```

`LocalDate`实例提供了一些方法，用来获取其中的时间部分：

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.getDayOfMonth();
// => 3
```

`LocalDate`实例提供了一些方法，可以向其中添加时间单位：

```exercism/note
这些方法返回一个_新_的`LocalDate`实例，不会更新现有的实例，因为`LocalDate`类是不可变的。
```

```java
LocalDate date = LocalDate.of(2007, 12, 3);

date.plusDays(3);
// => 2007-12-06
```

### `LocalDateTime`

`java.time.LocalDateTime`类表示 [ISO-8601 日历系统][iso-8601] 中不带时区的日期时间，例如`2007-12-03T10:15:30`：

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
```

可以把`LocalDate`实例转换成`LocalDateTime`：

```java
LocalDate date = LocalDate.of(2007, 12, 3);
LocalDateTime datetime = date.atTime(10, 15, 30);
datetime.toString();
// => "2007-12-03T10:15:30"
```

### 格式化日期时间

`LocalDate`和`LocalDateTime`在与`String`相互转换时，都使用 [ISO-8601][iso-8601] 标准记法。

```java
LocalDateTime datetime = LocalDateTime.of(2007, 12, 3, 10, 15, 30);
LocalDateTime parsed = LocalDateTime.parse("2007-12-03T10:15:30");

datetime.isEqual(parsed);
// => true
```

用其他格式像这样从`String`中解析`LocalDate`或`LocalDateTime`是行不通的。
要使用自定义格式来格式化日期，应该改用`java.time.format.DateTimeFormatter`：

```java
DateTimeFormatter parser = DateTimeFormatter.ofPattern("dd/MM/yyyy");
LocalDate date = LocalDate.parse("03/12/2007", parser);

DateTimeFormatter printer = DateTimeFormatter.ofPattern("MMMM d, yyyy");
printer.format(date);
// => "December 3, 2007"
```

创建自定义格式时还可以指定区域设置，以便针对不同地区进行格式化和解析：

```java
DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.FRENCH).format(date);
// => décembre 3, 2007

DateTimeFormatter.ofPattern("MMMM d, yyyy", Locale.of("pt")).format(date);
// => dezembro 3, 2007
```

[iso-8601]: https://en.wikipedia.org/wiki/ISO_8601
