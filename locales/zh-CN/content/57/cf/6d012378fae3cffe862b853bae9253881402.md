# 安装 Java

除了 Exercism CLI 和你最喜欢的文本编辑器，用 Exercism 练习 Java 还需要 **Java 开发工具包**（JDK）。JDK 既包含 Java 运行时，_也_包含开发工具（最值得一提的是 Java 编译器）。

如今 JDK 有许多发行版，其中一些是开源的。在 Exercism，我们推荐使用 [Adoptium 的 Eclipse Temurin][adoptium]。

## 支持的 Java 版本

Exercism 的 Java 轨道支持 Java 25 LTS 及更早版本。

## 安装 Eclipse Temurin

要在你的系统上安装 Eclipse Temurin，请前往他们出色的[安装说明][adoptium-installation-guide]。那里有使用你最喜欢的包管理器安装 JDK 的说明，还包含适用于所有主流操作系统的可下载安装程序的链接。

## Java IDE

Java 有很多免费的 IDE。以下是一些热门选择：

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [装有 Java 扩展的 Visual Studio Code][vscode-java]

## 下一步

现在你已经准备好开始学习 Exercism 的 Java 轨道了！

开始之前，请参阅“[运行测试][exercism-java-tests-docs]”。
