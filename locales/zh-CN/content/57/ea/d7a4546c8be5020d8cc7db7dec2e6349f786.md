# 简介

`OpenStruct`让你可以轻松地从一个`Hash`创建对象。不必使用`Hash`的键来访问，`OpenStruct`允许我们改用方法来读取和设置值。


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

这种写法还有一个好处：使用块语法时，我们可以利用一个快捷写法。当块只调用一个方法时，你可以用`&:`加上方法名来代替整个块。例如，下面两行是等价的：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## 标准库

你在之前的练习中见过的所有类，都属于 Ruby 的核心库。

OpenStruct 是 Ruby 标准库（常简称为“stdlib”）的一部分，标准库是一组类的集合，用来处理日期、json、网络之类的内容。它还提供了一些实用的功能，让你的代码更易于使用。

在使用不属于核心库的类时，比如你自己写在其他文件里的代码、来自标准库的类，或者外部的依赖，我们需要先用`require`方法导入它们，然后才能使用。例如：

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
