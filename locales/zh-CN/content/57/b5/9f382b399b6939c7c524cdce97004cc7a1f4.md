# 说明

Boris 是个狂热的火车模型爱好者，决定通过创办一份邮件通讯来与世界分享这份热情。他打算先把邮件通讯的第一期发送给有同样爱好的朋友和熟人，这些人的电子邮件地址存储在一个文本文件中。

提示：使用 [simplifile](https://hexdocs.pm/simplifile/simplifile.html) 模块进行文件操作。

## 1. 从文件中读取电子邮件地址

实现`read_emails`函数。它接收一个指向文本文件的路径字符串，该文件包含以换行符分隔的电子邮件地址，并返回由文件中的电子邮件地址组成的数组。

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. 创建一个用于写入的日志文件

发送电子邮件这项任务可能会因为许多无法预料的原因而失败，比如电子邮件地址拼写错误，或者临时出现网络问题。为了确保你可以重新向所有朋友发送邮件而不会重复发送，你需要记录已经收到过邮件的电子邮件地址。为此，你需要一个日志文件。

实现`create_log_file`函数。它接收一个文件路径，并在该位置创建一个新的空文件。

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. 记录已发送的电子邮件

实现`log_sent_email`函数。它接收日志文件的路径和一个包含电子邮件地址的字符串。它把电子邮件地址写入文件，并在后面加上一个换行符。

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. 发送邮件通讯

现在你已经有了发送电子邮件流程的全部基本组成部分，需要把它们组合到一个函数中。

实现`send_newsletter`函数。它接收包含电子邮件地址的文件的路径、日志文件的路径，以及一个向给定电子邮件地址发送邮件的匿名函数。

它应该从给定文件中读取所有电子邮件地址，并尝试向其中每一个地址发送电子邮件。如果发送邮件的匿名函数返回`Ok`值，就把该电子邮件地址写入日志文件。确保邮件一发送就立刻执行这一步。

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
