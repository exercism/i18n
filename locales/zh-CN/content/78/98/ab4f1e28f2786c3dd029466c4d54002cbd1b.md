# 简介

许多程序需要用（伪）随机值来模拟现实世界中发生的事件。

常见的例子包括：

- 抛硬币：从 ('H', 'T') 中随机取一个值。
- 掷骰子：从 1 到 6 中随机取一个整数。
- 洗牌：把一副牌随机打乱顺序。
- 在三维图形模拟中生成树木和灌木。

用计算机生成真正随机的值是一项[出奇困难的技术挑战][why-randomness-is-hard]，这也是为什么还有“伪随机”生成器。

~~~exercism/advanced
JavaScript 的[语言规范][spec]并没有强制规定随机数生成的具体实现方式。
所有主流浏览器和 JavaScript 运行时都实现了 PRNG（伪随机数生成器）。
由于这些数字在密码学上并不安全，所以绝不能把它们用于任何需要真正随机、或至少需要具备密码学安全性的随机数的场合，比如生成证书、密码，或进行相关操作。

有一项名为 [Web Cryptography][rfc] 的标准，它为在 JavaScript 中进行密码学操作定义了统一的接口。
[浏览器][crypto-web]以及 [Node.JS][crypto-node]、[Deno][crypto-deno] 等运行时都实现了它。

本概念不涉及 Web Crypto，只讨论伪随机数生成。

## 生成随机数

在 JavaScript 中，你可以使用 [`Math.random()`][Math.random] 函数生成伪随机数。
它会返回一个介于 0（包含）和 1（不包含）之间的伪随机浮点数。

要获得一个介于 _min_（包含）和 _max_（不包含）之间的随机数，你可以使用类似下面这样的函数：

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

~~~exercism/advanced
大多数基于随机生成的数字来返回某个范围内数值的简单做法，都[会引入偏差][bias]。
也就是说，有些数字会比其他的更容易被抽到。
使用乘法技术可以把偏差分散到整个区间，因此不那么明显，在大多数情况下也不是大问题，但你应该意识到这一点。

## 生成随机整数

要生成随机整数，你可以用`Math.floor()`或`Math.ceil()`把随机生成的数字转成整数。
