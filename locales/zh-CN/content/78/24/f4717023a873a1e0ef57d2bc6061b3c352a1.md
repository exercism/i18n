# 说明

把用字符串表示的八进制数（例如 '1735263'）从基本原理出发转换为其十进制等价值（也就是说，不可以，你不能使用内置或外部库来完成转换）。

实现八进制到十进制的转换。给定一个八进制输入字符串，你的程序应产生一个十进制输出。

## 注意

- 自己实现转换。
  不要用其他东西替你完成转换。
- 把无效输入当作八进制 0 处理。

## 关于八进制（Base-8）

十进制是 base-10 系统。

以 base 10 记法表示的数字 233 可以理解为 10 的各次幂的线性组合：

- 最右边的数字乘以 10^0 = 1
- 下一个数字乘以 10^1 = 10
- ……
- 第 _n_ 个数字乘以 10^_(n-1)_。
- 所有这些值相加。

所以：

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

八进制与之类似，但用的是 8 的幂而不是 10 的幂。

所以：

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
