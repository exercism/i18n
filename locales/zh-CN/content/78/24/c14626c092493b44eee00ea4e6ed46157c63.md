# 简介

我们使用的这门语言叫 Lisp，它的名字来自 _LIST Processing_，所以你可能会以为它天生就能处理由多个元素组成的数组，没错，确实如此！

虽然 Common Lisp 除了数组之外还有别的数据结构，但数组仍然被大量使用。

在 Common Lisp 里，数组是一系列元素。它也被称为 **cons**（主要是出于历史原因）。元素本身不必是同一类型。例如，你可以有一个由`1`、`two`和`"III"`组成的数组。

## 创建数组

你可以直接输入一个带引号的数组，像这样：`'(1 two "III")`，这样就会创建并求值一个数组（求值结果为`(1 two "III")`）。

创建数组还有两个主要函数：`list`和`cons`。

`list`接受零个或多个实参，求值结果是用这些值创建的数组：

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons`接受两个元素，创建一个数组，其中第一个元素是它的`car`（数组的头部），第二个元素是它的`cdr`（数组的其余部分）：

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

函数`car`和`cdr`可以用来访问数组的`car`和`cdr`。

（`first`和`rest`是`car`和`cdr`的同义词，作用完全相同。）

## 长度与随机访问

可以用`length`得到数组的长度。空数组的长度为零。

可以用`nth`访问任意一个元素（注意，数组的下标从 0 开始）。

即使请求的下标比数组的长度还大，也_不算错误_，而是求值为`nil`：

```lisp
(nth 23 '(short list)) ; => nil
```

还有一些辅助方法可以访问数组开头的几个元素：`first`、`second`、`third`，一直到`tenth`。很方便吧？

## 合并数组

可以用`append`把两个或多个数组合并起来：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

传给`append`的每个实参都必须是数组。
