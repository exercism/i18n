# 补充说明

## 实现

物品由[记录](https://lfe.gitbooks.io/reference-guide/content/16.html)表示，定义在`item.lfe`中。
用`item-weight`获取重量，用`item-value`获取价值。

```
;; Create an item with weight=5, value=50
(set item (make-item weight 5 value 50))

;; Get the weight. Returns 5.
(item-weight item)

;; Get the value. Returns 50.
(item-value item)
```
