# 简介

## 数字

C# 中有两种不同类型的数字：

- 整数：小数点后没有数字的数字（也就是整数）。例如 `-6`、`0`、`1`、`25`、`976` 和 `500000`。
- 浮点数：小数点后可以有零位或多位数字的数字。例如 `-2.4`、`0.1`、`3.14`、`16.984025` 和 `1024.0`。

C# 中最常见的两种数值类型是 `int` 和 `double`。`int` 是 32 位整数，`double` 是 64 位浮点数。

算术运算使用标准的算术运算符。数字可以使用标准的数值比较运算符，以及相等（`==`）和不等（`!=`）运算符来进行比较。

C# 有两种数值转换：

1. 隐式转换：不会丢失任何数据，也不需要额外的语法。
2. 显式转换：可能会丢失数据，并且需要额外的语法，也就是_强制转换_。

由于 `int` 的精度低于 `double`，从 `int` 转换到 `double` 是安全的，因此属于隐式转换。不过，从 `double` 转换到 `int` 可能会丢失数据，所以需要进行显式转换。

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## `if` 语句

在本练习中，你需要按条件执行逻辑。在 C# 中最常见的做法是使用 `if/else` 语句：

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

`if` 语句的条件必须是 `bool` 类型。C# 中没有_真值_的概念。
