# 帮助

如果你遇到了问题需要帮助，可以使用以下资源：

- [The Emacs Wiki](http://emacswiki.org/)非常有价值，值得在这里花上大量时间。
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html)是 GNU Emacs 的官方手册。
- IRC：[Libera.Chat](https://libera.chat/) 上有 `#emacs`、`#org-mode` 以及许多 Emacs 软件包的频道，还有不少热心人。而在 Emacs 里，上 IRC 就像 `M-x erc` 一样近在咫尺。
- Matrix：在 [Matrix](https://matrix.org/) 上有 [emacs](https://matrix.to/#/#emacs:matrix.org)、[org-mode](https://matrix.to/#/#org-mode:matrix.org) 以及其他 Emacs 软件包的聊天室。你可以[加入 Emacs Matrix 空间](https://matrix.to/#/#emacs-space:matrix.org)，了解有哪些可用的频道。要在 Emacs 里加入 Matrix，可以使用 [Ement.el](https://github.com/alphapapa/ement.el) 包。
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) 和 [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) 可以用来搜索你的问题，看看是否已经有人解答过。你也可以提问和回答问题。
