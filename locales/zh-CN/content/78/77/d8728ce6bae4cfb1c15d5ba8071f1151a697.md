# 说明

在这个练习中，你将编写代码来记录你想在 Exercism 上学习的编程语言列表。

一共有六个任务，它们都涉及对列表的处理。

## 1. 创建一个新列表

为了记录你想学习的语言，你需要创建一个新列表。定义 `newList` 绑定，让它包含一个新的空列表。

```fsharp
newList
// => []
```

## 2. 定义一个已有的列表

目前，你有一张纸，上面列出了你想学习的语言：F#、Clojure 和 Haskell。定义 `existingList` 绑定来表示这个列表。

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. 向列表中添加一门新语言

当你在 Exercism 上探索并发现更多有趣的语言时，你会想把它们加进列表。实现 `addLanguage` 函数，把一门新语言添加到列表的开头。

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. 统计列表中的语言数量

一门一门地清点语言很不方便。实现 `countLanguages` 函数，统计列表中有多少门语言。

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. 反转列表

某天你发现，自己的列表顺序其实是反的！实现 `reverseList` 函数，把列表反转过来。

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. 检查列表是否令人兴奋

虽然你喜欢所有语言，但 F# 在你心中有特殊的位置。因此，只要满足以下条件，你就会对一个语言列表感到兴奋：

- 列表的第一项是 F#。
- 列表的第二项是 F#，并且列表包含两门或三门语言。

实现 `excitingList` 函数，检查一个语言列表是否令人兴奋：

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
