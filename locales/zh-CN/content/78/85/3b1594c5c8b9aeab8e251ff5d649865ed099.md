# 练习说明补充

## callable

PHP 里有 callable 这个概念，详见 [callable](https://www.php.net/manual/en/language.types.callable.php)。

它有多种形式，不过我们只关注[匿名函数](https://www.php.net/manual/en/functions.anonymous.php)。

可以把匿名函数赋给一个变量，然后用实参调用它：

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
