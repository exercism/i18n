# 安装

要动手做这些练习，你需要下面这些软件：

1. [`OPAM`，OCaml 包管理器](https://opam.ocaml.org/)

   关于如何针对你的操作系统安装并配置 `OPAM`，请参阅 [Real World Ocaml, 2nd Ed.: Installation Instructions](https://dev.realworldocaml.org/install.html)。

2. OCaml 编译器

   查看可用版本列表：

   ```bash
   opam switch
   ```

   如果你已经有 OCaml 5.1 的 switch，可以运行 `opam switch <switch-name>` 来加载它，也可以运行下面的命令新建一个 switch：

   ```bash
   opam switch create exercism 5.4.0
   ```

   这里的名字 `exercism` 是可选的，但给 switch 起个名字是个好习惯。

3. 安装扩展标准库和测试库

   运行下面的命令，安装本 track 所需的依赖：

   ```bash
   opam install base core_kernel ounit qcheck
   ```

   有些练习只用到 OCaml 标准库，另一些则用到 Jane Street 的扩展库 Base 和 Core_kernel。
   测试库叫 OUnit，还有一些练习额外使用 QCheck 库来做基于属性的测试。
   运行上面的命令就会安装这些库。

4. 安装并使用交互式 shell（可选）

   以下是 [Setting up and using `utop`](https://dev.realworldocaml.org/install.html) 的摘要：

   ```bash
   opam install utop
   ```

   在你的主目录下新建一个名为 `.ocamlinit` 的文件，并在其中加入下面几行：

   ```ocaml
   #use "topfind";;
   #require "base";;
   open Base
   ```

5. 在 VS Code 中安装工具（可选）

   如果你使用 VS Code：
   - 从[这里](https://github.com/ocaml/ocaml-lsp)安装 OCaml 语言服务器。
   - 从[这里](https://marketplace.visualstudio.com/items?itemName=ocamllabs.ocaml-platform)安装 OCaml VS Code 扩展，或者搜索 Ocaml Labs 的`OCaml Platform`。
