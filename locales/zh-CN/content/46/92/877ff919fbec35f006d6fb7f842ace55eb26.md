# 说明

社区艺术中心的马赛克上个月才装好，现在被 Magpie Marg 盯上了。大多数日子里，她会从附近的**宝藏**里拿更闪亮的瓷砖换走一两块，或者抠下一块瓷砖，然后消失一个小时。

你是负责记录每次变动的志愿者。马赛克本身是一个**固定大小的数组**，每个瓷砖位置对应一个槽位，里面存放一个颜色字符串，或者用`f`表示“缺失”。Magpie Marg 的宝藏是一个**向量**，里面装着她偷来的散落瓷砖。

## 1. 铺出一行新瓷砖

定义`fresh-mosaic`，它接受一个长度`n`，返回一个包含`n`个空槽位的数组（每个槽位都是`f`）。

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. 放置一块瓷砖

定义`place-tile`，它接受一行、一个位置和一个颜色，就地更新这一行，让指定的位置存放该颜色。这个词不返回任何值。

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. 抠出一块瓷砖

定义`chip-tile`，它接受一行和一个位置，就地更新这一行，让指定的位置重新变成`f`。

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. 给瓷砖重新上色

定义`recolour-tile`，它接受一行、一个位置和一个单参数的引述，对该位置上的瓷砖应用这个引述，从而就地更新这一行。

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. 趁 Marg 还没来，先拍个快照

定义`snapshot-mosaic`，它接受一行，返回一个独立的副本，之后对原始行的改动不会影响到它。

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg 把一块瓷砖揣进兜里

定义`stash-tile`，它接受 Marg 的宝藏（一个向量）和一个颜色，把这个颜色追加到宝藏里。不返回任何值。

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg 归还一块瓷砖

定义`return-tile`，它接受 Marg 的宝藏，移除并返回最近存放进去的那块瓷砖（也就是最上面那一块）。

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
