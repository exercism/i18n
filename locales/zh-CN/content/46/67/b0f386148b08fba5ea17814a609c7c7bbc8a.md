# 补充说明

## 寄存器

| 寄存器 | 用途     | 类型    | 说明                                                |
| -------- | --------- | ------- | ---------------------------------------------------------- |
| `$a0`    | 输入     | 整数 | 类别：`0` 表示 choice、`1` 表示 ones、`2` 表示 twos、`3` 表示 threes、`4` 表示 fours、`5` 表示 fives、`6` 表示 sixes、`7` 表示 little_straight、`8` 表示 big_straight、`9` 表示 full_house、`10` 表示 four_of_a_kind、`11` 表示 yacht |
| `$a2`    | 输入     | 地址 | 骰子（字数组）                                          |
| `$v0`    | 输出     | 整数 | 最终得分                                            |
| `$t0-9`  | 临时 | 任意     | 用于临时存储                                 |
