# 简介

Python 中的`dict`是一种数据结构，它把[可哈希][term-hashable]的_键_与_值_关联起来；在其他编程语言里，它也被称为可动态调整大小的[哈希表][hashtable-wikipedia]、哈希映射或[关联数组][associative-array]。
字典是 Python 唯一的内置[映射类型][mapping-types-dict]。


`Keys`必须可哈希，并且在同一个字典中唯一。
键的类型可以是`numbers`、`str`或`tuples`（由_不可变_的值组成）。
键不能包含`lists`、`dict`s或`set`s这类_可变_的数据结构。
从 Python 3.7 起，`dict`中键的顺序保证与条目插入的顺序一致。

`values`可以是任何数据类型或结构。
值还可以_任意_嵌套，因此可以包含列表的列表、子字典，以及其他自定义或复合的数据结构。

给定一个`key`，字典可以在（平均）常数时间内取出对应的`value`（_与条目数量无关_）。
与在`list`或`array`中查找某个值（_在不知道`index`位置的情况下_）相比，`dict`占用的内存明显更多，但检索速度非常快。
当条目集合很大，而且需要频繁访问和更新时，字典尤其有用。


## 字典的构造

创建字典的方法有很多种。
最直接的两种是使用`dict()`构造函数，或者声明一个`dict`_字面量_。

### `dict()`类构造函数

`dict()`（_字典类的构造函数_）可以配合任意由`key`、`value`对组成的可迭代对象使用，也可以配合一系列`<name>=<value>`_实参_使用：

```python
#Passing a list of key,value tuples.
>>> wombat = dict([('name', 'Wombat'),('speed', 23),('land_animal', True)])
{'name': 'Wombat', 'speed': 23, 'land_animal': True}


#Using key=value arguments.
>>> bear = dict(name="Black Bear", speed=40, land_animal=True)
{'name': 'Black Bear', 'speed': 40, 'land_animal': True}
```

### 字典字面量

`dict`也可以直接写成_字典字面量_，即用花括号（`{}`）把`key : value`对括起来：

```python
>>> whale = {"name": "Blue Whale", "speed": 35, "land_animal": False}
{'name': 'Blue Whale', 'speed': 35, 'land_animal': False}
```

## 访问字典中的值

可以用方括号（`[]`）里的_键_来访问字典中的条目。
如果`dict`里不存在某个`key`，就会抛出`KeyError`：

```python
>>> bear["speed"]
40

>>> bear["color"]
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'color'
```

通过`.get(<key>, <default value>)`方法访问条目，则可以避开`KeyError`：

```python
>>> bear.get("color", 'not found')
'not found'
```

## 修改或添加字典的值

可以通过给条目的_键_赋值来修改它的`value`：

```python
#Assigning the value "Grizzly Bear" to the name key.
>>> bear["name"] = "Grizzly Bear"
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True}

>>> whale["speed"] = 25
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False}
```

新的`key`:`value`对也可以用同样的方式_添加_进去：

```python
# Adding a new "color" key with a new "tawney" value.
>>> bear["color"] = 'tawney'
{'name': 'Grizzly Bear', 'speed': 40, 'land_animal': True, 'color': 'tawney'}

>>> whale["blowholes"] = 1
{'name': 'Blue Whale', 'speed': 25, 'land_animal': False, 'blowholes': 1}
```

## 移除（弹出）字典条目

可以使用`.pop(<key>)`方法删除字典条目。
`.pop()`会移除这一对（`key`、`value`），并把其中的`value`返回出来供你使用。
和`.get()`一样，`.pop(<key>)`也接受第二个参数（_`dict.pop(<key>, <default value>)`_），当找不到该`key`时就返回它。
这样可以避免抛出`KeyError`：

```python
#Using .pop() removes both the key and value, returning the value.
>>> bear.pop("name")
'Grizzly Bear'


#The "name" key is now removed from the dictionary.
#Attempting .pop() a second time will throw a KeyError.
>>> bear.pop("name")
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
KeyError: 'name'


#Using a default argument with .pop() will prevent a KeyError from a missing key.
>>> bear.pop("name", "Unknown")
'Unknown'
```

## 遍历与迭代字典

用`for item in dict`或`while item`遍历字典时，默认只会迭代_键_。
在同一个循环里，可以用_方括号_访问_值_：

```python
>>> for key in bear:
>>>     print((key, bear[key])) #this forms a tuple of (key, value) and prints it.
('name', 'Black Bear')
('speed', 40)
('land_animal', True)
```

也可以使用`.items()`方法，它会自动返回（`key`、`value`）元组：

```python
#dict.items() forms (key, value tuples) that can be unpacked and iterated over.
>>> for key, value in whale.items():
>>>     print(key, ":", value)
name : Blue Whale
speed : 25
land_animal : False
blowholes : 1
```

同样，`.keys()`方法会返回`keys`，`.values()`方法会返回`values`。
