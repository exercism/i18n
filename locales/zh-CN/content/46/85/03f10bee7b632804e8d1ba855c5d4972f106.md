# 说明

你负责保管一艘小岛渡轮的航行时刻表。航班都用日期记录，你需要几个辅助函数来处理它们。

## 1. 记录航班日期

定义`make-date`，接收年、月、日，返回对应的时间戳。

```factor
2024 7 14 make-date .
! => T{ timestamp { year 2024 } { month 7 } { day 14 } ... }
```

## 2. 得出星期几的名称

定义`weekday-name`，接收一次航班的时间戳，返回它落在星期几的名称。

```factor
2024 1 8 make-date weekday-name .
! => "Monday"
```

## 3. 闰年

定义`leap?`，接收一个年份，返回它是否为闰年。

```factor
2024 leap? .   ! => t
2023 leap? .   ! => f
```

## 4. 一个月的天数

定义`month-length`，接收一个年份和一个月，返回这个月的天数（别忘了二月）。

```factor
2024 2 month-length .   ! => 29
2023 2 month-length .   ! => 28
```

## 5. 几天之后

定义`add-days`，接收一个时间戳和天数，返回往后推这么多天后的时间戳。

```factor
2024 2 28 make-date 1 add-days >date< .
! => 29   (2024-02-29)
```
