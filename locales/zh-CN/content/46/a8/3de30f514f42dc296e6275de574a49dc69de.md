# Cairo 中的模块与路径

Cairo 使用**模块**来组织代码。

模块有助于组织项目结构，并控制函数、结构体和 trait 等项的可见性。

## 定义模块

模块用 `mod` 定义，并且可以嵌套：

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

函数、结构体和 trait **默认都是私有的**。

使用 `pub` 可以让它们在模块外部被访问。

## 路径：绝对路径与相对路径

要引用另一个模块中的项，可以使用：

- **绝对路径**（从 `crate::` 开始）：

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **相对路径**（从当前模块开始）：

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  如果 `front_of_house` 在同一个模块中，这样写是可行的。

## 用 `use` 将模块引入作用域

反复写完整路径很麻烦。

`use` 关键字可以让你使用更短的引用：

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` **只在它出现的作用域内生效**；如果其他地方也需要，就必须重复写。

### `use` 的惯用写法

- 把**模块**引入作用域，而不是把函数引入作用域：

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  而不是这样写：

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- 对于 **trait、结构体和枚举**，使用完整路径：

  ```rust
  use core::num::traits::BitSize;
  ```

### 用 `as` 起别名

必要时可以重命名导入：

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### 一次导入多个项

与其写多条 `use` 语句，不如把导入合并起来：

```rust
use shapes::{Square, Circle, Triangle};
```

## 用 `pub use` 重新导出

如果想以一种不同的结构对外暴露某个模块，可以使用 `pub use`：

```rust
pub use crate::front_of_house::hosting;
```

这样一来，外部代码就可以用 `restaurant::hosting::add_to_waitlist()`，而不必写 `restaurant::front_of_house::hosting::add_to_waitlist()`。

## 用 Scarb 使用外部包

要添加依赖，请修改 `Scarb.toml`：

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

用 `scarb add <package>` 添加依赖，用 `scarb rm <package>` 移除依赖。

## 通配符运算符（`*`）

要从一个模块中导入所有内容：

```rust
use core::num::traits::*;
```

这个运算符要谨慎使用，因为它会让代码更难读。
