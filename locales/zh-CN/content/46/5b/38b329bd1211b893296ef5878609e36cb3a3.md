# 简介

Kotlin 中的[`string`][ref-string]是由 Unicode 字符组成的不可变序列。

[`Immutable`][wiki-immutable]的意思是，对字符串的任何操作都必须返回一个新的字符串：原字符串永远不会改变。

[`Unicode`][wiki-unicode]意味着世界上大多数书写系统都能被表示出来，但是（与 C 这类更早的语言不同）字符和字节之间并不存在一对一的映射。

字符串用双引号`" "`括起来。

有些字符需要转义：`\\`，以及常见的非打印字符，比如`\t`（制表符）和`\n`（换行符）。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

多行字符串由 3 个双引号括起来，可以包含任意文本（无需转义）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

用[trimIndent][trimIndent-doc]可以去掉各行共同的缩进。
这在格式化字符串时很有用：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

另一种方式是使用[trimMargin][trimMargin-doc]，它可以让你指定一个分隔符。
`String`中的每一行都从这个分隔符之后开始。
分隔符默认为`|`，不过你也可以把别的分隔符作为形参传入。
例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字符串可以用`+`拼接，但这最好只用于简短简单的情况。
还有其他往往更好的选择。

## 字符串模板

这指的是其他一些语言中所说的“插值”。

如果字符串中包含一个美元符号`$`，后面跟一个标识符，或者包含一对包裹表达式的大括号（`{expression}`），那么它们会分别被替换为该标识符的值或该表达式的结果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

当解析会产生歧义时，就需要用大括号`{ }`把表达式括起来。

一般来说，使用字符串模板比用`+`拼接字符串更高效，也更符合惯用法。

## 字符串函数

Kotlin 提供了_许多_[`functions`][ref-string-functions]来操作字符串。

它们大多是[`extensions functions`][ref-extensions]，而不是`String`类的成员，不过这对我们如何使用它们几乎没有影响。

~~~~exercism/note
Kotlin 相当复杂的[documentation][ref-string-functions]页面在默认视图中会隐藏扩展函数。
请务必点击`Members & Extensions`来展开这一部分。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

下面的例子只展示了可用功能中的一小部分：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
