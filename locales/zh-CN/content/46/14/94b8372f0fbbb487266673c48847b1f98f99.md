# 三元运算符

_三元运算符_可以看作是 _if-else_ 的紧凑版本。它通常用在返回语句中（但不仅限于此），只需一行就能做出判断：如果表达式为`true`，就返回左边的值；如果为`false`，就返回右边的值。

很多简单的 _if/else_ 表达式都可以用 _三元运算符_ 来简化。

```java
// this ternary statement
return 5 > 4 ? true : false;

// is equivalent to this if/else
if ( 5 > 4 ) {
    return true;
} else {
    return false;
}
```

那么，如何在 _if-else_ 和 _三元运算符_ 之间做选择？_三元运算符_适合简单的场景：只需根据条件返回一个值，不需要额外的计算。其他情况就用 _if-else_，比如嵌套条件、复杂的表达式，或者需要多行才能确定返回值的时候。

虽然 _三元运算符_ 可以嵌套，但代码往往变得难以阅读。这种情况下，最好使用嵌套的 if。

```java
// hard to read
int value = expr1 ? expr2 && expr3 ? val1 : (val2 + val3) : expr4;

// easier to read
if (expr1){

    if (expr2 && expr3){

        return val1;
    }

    return val2 + val3;
}
return val4;


```

_三元运算符_和 _if/else_ 语句就是一个很好的例子，说明在编程中可以用不同的方式达到相同的结果。
