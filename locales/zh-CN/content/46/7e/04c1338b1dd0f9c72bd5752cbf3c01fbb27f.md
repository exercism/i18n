# 介绍

## 关键字列表

关键字列表是一种键值对数据结构。

```elixir
[month: "April", year: 2018]
```

关键字列表是由`{key, value}`元组组成的列表，也可以写成这种形式，但更短的语法使用得更广泛。

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

关键字列表中的键必须是[原子][exercism-atoms]，但值可以是任何东西。每个键可以使用多次。关键字列表中的键值对是有序的。

你可以用处理列表的相同方法来处理关键字列表，也可以使用`Keyword`模块。

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
