# 关于

Swift 是一门编译型的多范式编程语言，设计时以三个主要目标为核心：

- **安全**：内置的语言特性有助于在代码投入生产环境之前捕获并预防 bug。
- **速度**：性能经过优化，可与基于 C 的语言相媲美。
- **表达力**：简洁现代的语法，易读易写，用起来很愉快。

苹果在 2014 年推出 Swift，作为 Objective-C 的现代替代品；Objective-C 是此前用于 iOS 和 macOS 开发的语言。
如今，Swift 已经开源，可运行在 Apple 平台、Linux 和 Windows 上。

## 入门

### 变量

通过定义[变量][constants-variables]，你可以存储值并为其命名。
定义变量之后，你可以在代码中用它的名字来引用那个值。
变量是_可变的_，这意味着它们的值在定义之后可以改变。

使用`var`关键字定义变量：

```swift
var variableName = 10
```

Swift 是一门静态类型语言，也就是说每个值在编译时都有已知的类型。
你可以用[类型注解][type annotations]显式声明类型，也可以让 Swift 编译器根据所赋的值[推断类型][type-inferring]：

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

你可以用赋值运算符（`=`）更新变量的值：

~~~~exercism/note
变量一旦声明，其类型就不能再改变。

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

你可以通过指定类型来声明一个没有初始值的变量，但在使用它之前必须先赋值：

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 常量

[常量][constants-variables]同样把一个名字和一个值关联起来，但它们的值在赋值之后不能改变。
它们是_不可变的_。
使用`let`关键字定义常量：

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 算术运算符

Swift 提供了标准的[算术运算符][arithmetical-operators]，用于基本的数学运算：

- 加法：`+`
- 减法：`-`
- 乘法：`*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 函数

在 Swift 中，[函数][functions]是执行特定任务的独立代码块。
函数可以接收输入、返回值，还可以作为值传递给其他函数。
使用`func`关键字定义函数，后面依次是函数名、括号里的参数列表，以及可选的返回类型：

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift 函数使用[实参标签][argument-labels]，让代码读起来像自然的句子：

- **实参标签**在调用函数时使用。
- **形参名称**在函数体内部用于访问该值。

如果只写一个名字，Swift 会把它同时用作实参标签和形参名称：

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

如果调用函数时不想要实参标签，就在形参名称前写一个下划线（`_`）：

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

默认情况下，函数的所有形参都是常量（`let`），也就是说它们的值不能在函数体内被修改。

要让函数返回一个值，在`->`之后指定返回类型，并使用`return`关键字：

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

当函数不返回值时，它的返回类型是`Void`（等价于空元组`()`）。
这类函数可以同时省略`-> Void`返回类型和`return`语句。

### 注释

Swift 支持两种形式的[注释][comments]：

- **单行注释**以`//`开头，一直延续到该行末尾。
- **多行注释**写在`/*`和`*/`之间。

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
