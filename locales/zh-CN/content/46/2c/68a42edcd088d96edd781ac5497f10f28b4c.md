# 说明

在这个练习中，你要帮助高中情侣在社交媒体上表白：用他们名字的缩写生成一个 ASCII 爱心：

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 获取名字的首字母

实现`first_letter`函数。它接收一个名字并返回其首字母。它应当清理名字中任何多余的空白字符。

```gleam
first_letter("Jane")
// -> "J"
```

## 2. 把首字母格式化为缩写

实现`initial`函数。它接收一个名字，返回其首字母的大写形式，后面再跟一个点。记得复用上一步中定义的`first_letter`。

```gleam
initial("Robert")
// -> "R."
```

## 3. 把全名拆分为名和姓

实现`initials`函数。它接收一个全名，由名和姓组成，两者之间用一个空格分隔，并返回姓名缩写。记得复用上一步中定义的`initial`。

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. 把缩写放进爱心里

实现`pair`函数。它接收两个全名，返回放在 ASCII 爱心中的姓名缩写。记得复用上一步中定义的`initials`。

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
