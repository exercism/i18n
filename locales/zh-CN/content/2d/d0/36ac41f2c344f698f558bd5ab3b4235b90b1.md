# 说明

你正在帮忙做一项鸟类调查。每天有人坐在观鸟屋里，数一数飞过的鸟，当天的计数会以数组的形式返回。

五个任务都放在`BIRD_SURVEY`类里。

## 1. 总数

把每天的计数加起来。

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

一天也没有的调查，数到的鸟是 0 只。

## 2. 最好的一天

返回最大的计数。如果一天也没有，答案就是 0。

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. 鸟类多的日子

有多少天的计数高于某个数字？

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

高于就是高于：计数正好等于 2 不算。

## 4. 需要查看的观鸟屋

调查的第一天你查看 1 个观鸟屋，第二天查看 2 个，以此类推。这样总共要查看多少个观鸟屋？

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

也就是 1 + 2 + 3 + 4。

## 5. 第一个繁忙的日子

哪一天是第一个计数高于某个数字的日子？天的编号从 0 开始，和数组下标一样。如果没有哪一天那么繁忙，答案就是 `-1`。

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
