# 简介

## 基础

我们把**_语言_**称为**AWK**，把负责解释 AWK 程序的**_可执行文件_**称为**`awk`**或**`gawk`**。

### 模式与动作

一个 AWK 程序由**模式-动作对**组成

```awk
pattern1 { action1 }
pattern2 { action2 }
...
```

**模式**可以是用来匹配输入的正则表达式模式。
它也可以是任何结果为 true/false 值的表达式。

**动作**是一条或多条 AWK 命令。
包裹它的大括号不能省略。

如果模式的结果为 *true*，就会执行对应的动作。

### 记录与字段

AWK 会把输入解析成一系列**记录**。
每条记录都会被拆分成零个或多个**字段**。

默认行为是：

- 用换行符作为“记录分隔符”把输入拆分成记录，所以每一*行*就是一条记录。
- 用空白字符作为“字段分隔符”把记录拆分成字段，所以每一个*词*就是一个字段。

### 模式与动作（续）

模式可以省略，此时动作会*针对每一条输入记录*执行。

动作也可以省略，此时默认动作是打印当前记录。

#### 特殊模式

有两个经常用到的特殊模式。

- `BEGIN`会在读取任何输入之前执行对应的动作。
- `END`会在所有输入读取完毕之后执行对应的动作。

### 字段变量

可以用`$1`、`$2`、`$3`等来引用字段。

当前记录是`$0`。

下面是其他一些常用的内置变量。

#### 控制输入解析的内置变量

- `RS`是输入记录分隔符。
  如前所述，它的默认值是换行符。
- `FS`是输入字段分隔符。

这些变量通常会在`BEGIN`动作块中设置。

#### 传递信息的内置变量

这些变量由 AWK 在程序执行期间自动设置。

- `NF`保存当前记录中字段的数量。
  - 想获取最后一个字段的值，可以使用`$NF`。
- `NR`保存当前的记录编号。
  - 处理多个输入文件时，`NR`保存的是到目前为止已处理记录的总数。
- `FNR`保存当前输入文件中的当前记录编号。
  - 为了说明 NR 与 FNR 的区别，下面是一个常见的 AWK 惯用法。
    ```awk
    NR == FNR {action}
    ```
    它的意思是“累计记录编号等于当前文件的记录编号”。
    只有*第一个输入文件*中的记录才可能满足这个条件。

### 真值性

AWK 使用与 C 相同的真值性概念。

- 数字`0`为 false。
- 其他任何数字都为 true。

由于 AWK 是一门文本处理语言，真值也扩展到了字符串。

- 空字符串`""`为 false。
- 任何非空字符串都为 true。

### 注释

注释以`#`字符开头，一直延伸到行尾。

### 示例

在类 Unix 系统上，`/etc/passwd`包含用户的信息。
每个用户单独占一行，字段之间用冒号分隔。

要列出用户名：

```sh
awk '
    BEGIN { FS = ":" }
    { print $1 }
' /etc/passwd
```

注意`{print $1}`这个动作没有模式，所以它会对每一条记录执行。

如果我们想把输出限制为只用 bash 作为登录 shell 的用户，可以这样做：

```sh
awk '
    BEGIN { FS = ":" }
    $7 == "/bin/bash" { print $1 }
' /etc/passwd
```
