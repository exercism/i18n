# 关于

Swift 提供控制转移语句，用来改变循环和 switch 语句的执行流程。除了`return`，Swift 还包括`continue`、`break`、循环标签和`fallthrough`。

## Continue

`continue`语句告诉循环停止执行当前迭代，立即开始下一次迭代。在`while`或`repeat-while`循环中，它会直接跳到条件检查。在`for-in`循环中，它会移到序列中的下一个元素。

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

`break`语句会立即退出整个循环或 switch 语句。程序会从循环或 switch 后面的第一行代码继续执行。

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## 带标签的语句

在嵌套循环中，你可能希望`break`或`continue`作用于外层循环，而不是最内层循环。在循环前面加上名字和冒号（`labelName:`），就能给循环加标签。然后就可以把这个标签传给`break`或`continue`：

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

在 Swift 中，`switch`语句默认不会贯穿到下一个 case；执行会在匹配到的 case 末尾自动停止。如果你明确希望执行继续进入下一个 case，而不判断它的模式，就使用`fallthrough`关键字：

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
