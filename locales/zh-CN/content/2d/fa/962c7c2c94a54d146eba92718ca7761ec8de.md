# 没有具名导出

未找到 [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)。没有它，测试就无法通过。

确保`%{export.name}`存在，并在它前面加上`export`：
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
