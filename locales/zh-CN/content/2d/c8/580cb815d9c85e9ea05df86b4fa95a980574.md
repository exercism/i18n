# 关于基础

Kotlin 是一门静态类型语言，设计上能与 Java 完全互操作。

与 Java 相比，Kotlin：

- 语法更干净、更简洁；
- 融合了许多函数式语言的特性；
- 对可空值提供了广泛的支持。

## 变量

因为 Kotlin 是静态类型语言，所以必须在编译期就_知道_每个值的类型。

不过，Kotlin 的[类型推断][inference]非常强大，因此通常可以不_指定_类型。

声明变量有两种方式。

1. `val`创建不可变变量，试图修改它会引发编译期错误。

```kotlin
val x = 42  // => 42
x = 43      // => 'val' cannot be reasssigned
```

2. `var`创建可变变量。

```Kotlin
var x = 42  // => 42
x = 43      // => 43
```

由于不可变变量能消除一类常见的 bug，因此只要有可能，就鼓励使用`val`。

另外，即使是`var`，也不能改变类型：

```kotlin
var x = 42
x = "foobar" // => Type mismatch: inferred type is String but Int was expected
```

为了减少视觉上的干扰，本教学大纲大多会省略显式类型。
不过，至少建议在下面这些地方写明类型：

- 公开的 API
- 函数签名
- 需要文档说明的地方

有些公司和组织要求严格的类型安全，不允许使用类型推断；另一些则只把它限制在“简单”类型上，还有一些则完全拥抱类型推断。

```kotlin
val x: Int = 42  // => 42
```

一般来说，变量和函数的命名应当使用`camelCase`，而不是`snake_case`

## 函数

用`fun`关键字声明函数。
与 Java 不同，函数不必是某个类的一部分。

```Kotlin
fun hello(): String {
    return "Hello, World!"
}

fun add(x: Int, y: Int): Int {
    return x + y
}
```

有几点需要注意：

- 即使函数不接受任何实参，函数名后面也需要那对括号`()`。
- 函数的实参必须写明类型：这里没有类型推断（与变量不同）。
- 函数体用大括号`{ }`括起来（不过请看下文）。
- 如果要返回值，就必须使用`return`关键字。
- 行尾的分号`;`是可选的，通常都会省略。
- 算术运算符`+`、`-`、`*`、`/`与大多数主流语言类似。

不过，对于这类非常简单的“单表达式”函数，有一种简写语法：

```Kotlin
// return type is usually omitted for single-expression functions
fun add(x: Int, y: Int) = x + y  
```
函数可以有带默认值的形参。
如果在调用函数时省略了这些形参，就会使用它们的默认值：

```kotlin
fun ping(host: String = "localhost") {
    println("PING --> $host")
}

ping("exercism.io")  // PING --> exercism.io
ping()               // PING --> localhost
```

Exercism 中的函数通常都会返回值（这与测试运行器的结构有关）。
如果想更广泛地使用 Kotlin，知道下面这一点会很有用：不返回值的函数可以省略返回类型和`return`关键字。

这时就说它的返回类型是`Unit`：相当于 Java 和另外几种语言中的`void`。

## 注释

单行注释以`//`开头，该行后面的内容都会被忽略。

多行注释以`/*`开头，以`*/`结尾

```Kotlin
fun hello(): String {
    /*
     * Failing to run this program on a new installation 
     * is considered bad luck
    */
    return "Hello, World!" // the compiler pixies are now happy
}
```

这与 Java 相同。
