# 说明

你正在开发一个面向低功耗嵌入式系统的游戏，需要编写几个便捷函数，供游戏的其他部分使用。

## 1. 计算除法的商和余数

商是除法运算的输出。

```rust
fn divmod(dividend: i16, divisor: i16) -> (i16, i16)
```

示例：

```rust
assert_eq!(divmod(10, 3), (3, 1));
```

## 2. 从迭代器中选取偶数位置的元素

你的老板保证，这有助于实现屏幕缓冲区优化。

迭代器是暴露了由[`Iterator` trait](https://doc.rust-lang.org/std/iter/trait.Iterator.html)所定义的方法的元素。那份文档相当详尽，因为迭代器提供了很多方法；下面是最相关的几个特性：

- 迭代器是一个任意长度的元素流
- 它有[`enumerate`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.enumerate)，会为每个值返回一个元组`(i, val)`
- 它有[`filter`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.filter)，使用闭包来决定是否产出迭代器中的某个元素
- 它有[`map`方法](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.map)，使用闭包来修改迭代器中的元素

由于你的函数可以作用于任何类型的迭代器，因此用`impl`来表示这是一个 trait 实例，而不是一个具体的条目。同样，`<Item=T>`这种写法只是表示迭代器产出什么类型的元素都无所谓；你的函数可以产出任何迭代器的偶数位置元素。

```rust
fn evens<T>(iter: impl Iterator<Item=T>) -> impl Iterator<Item=T>
```

示例：

```rust
let mut even_ints = evens(0_u8..);
assert_eq!(even_ints.next(), Some(0));
assert_eq!(even_ints.next(), Some(2));
assert_eq!(even_ints.next(), Some(4));
assert_eq!(even_ints.next(), Some(6));
```

```rust
let mut evens_from_odds = evens(1_i16..);
assert_eq!(evens_from_odds.next(), Some(1));
assert_eq!(evens_from_odds.next(), Some(3));
assert_eq!(evens_from_odds.next(), Some(5));
assert_eq!(evens_from_odds.next(), Some(7));
```

## 3. 计算某个位置到原点的曼哈顿距离

为了方便映射，这里为你提供了一个元组结构体`Position`：

```rust
struct Position(i16, i16);
```

你需要在`Position`上实现一个`manhattan`方法，返回该位置到原点（`Position(0, 0)`）的[曼哈顿距离](https://en.wikipedia.org/wiki/Taxicab_geometry)。

```rust
impl Position {
    fn manhattan(&self) -> i16
}
```

示例：

```rust
assert_eq!(Position(3, 4).manhattan(), 7);
```
