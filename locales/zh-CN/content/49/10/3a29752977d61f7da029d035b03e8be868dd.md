# 简介

## 异常

Java 编程语言使用_异常_来处理错误和其他异常事件。

### 什么是异常

异常是程序执行期间发生的事件，它会打断指令的正常执行流程。
在 Java 中，异常是显式抛出的，抛出异常的动作叫作_抛出异常_。
处理异常的动作叫作_捕获异常_。

在 Java 中，所有异常都是 `Exception`类的子类，而 `Exception`类本身又是 `Throwable`类的子类。

Java 区分两种类型的异常：

1. 受检异常
2. 非受检异常

#### 受检异常

_受检异常_是应用程序应当预料到并从中恢复的异常情况。
受检异常的一个例子是 `FileNotFoundException`，当方法试图读取一个不存在的文件时，就会出现这种异常。

这类异常会在编译时检查：抛出受检异常的方法应当在其方法签名中注明这一点，而调用可能抛出受检异常的方法的代码必须处理它，否则代码将无法编译。

所有受检异常都是 `Exception`的子类，且不继承 `RuntimeException`。

#### 非受检异常

_非受检异常_是应用程序通常无法预料、也无法从中恢复的异常情况。
非受检异常的一个例子是 `NullPointerException`，当方法期望得到非空值、却收到`null`时，就会出现这种异常。

这类异常不会在编译时检查：抛出非受检异常的方法不要求在方法签名中注明这一点，调用可能抛出非受检异常的方法的代码也不要求处理它。

所有非受检异常都继承自 `RuntimeException`，而 `RuntimeException`本身又是 `Exception`的扩展。

### 抛出异常

Java 中的方法可以使用 `throw`语句来抛出异常。

#### 抛出受检异常

从方法中抛出受检异常时，必须使用 `throws`关键字在方法签名中注明这一点，如下面的示例所示。
这会强制调用该方法的代码预料到可能抛出异常，并相应地处理它。

```java
public class InsufficientBalanceException extends Exception {

}

public class BankAccount {
  public void withdraw(double amount) throws InsufficientBalanceException {
    if (balance < amount) {
      throw new InsufficientBalanceException();
    }

    // rest of the method implementation
  }
}
```

#### 抛出非受检异常

从方法中抛出非受检异常时，不要求在方法签名中注明这一点，不过这样做也是支持的。

```java
public class BankAccount {
  public void withdraw(double amount) {
    if (amount < 0) {
      throw new IllegalArgumentException("Cannot withdraw a negative amount");
    }

    // rest of the method implementation
  }
}
```

### 处理异常

在 Java 中，处理异常是通过 `try`、`catch`和`finally`关键字完成的。

- 可能抛出异常的代码语句应当用 `try`代码块包裹起来。
- `try`代码块后面跟着一个或多个 `catch`代码块，用来捕获 `try`代码块中抛出的异常。
- `catch`代码块后面可以选择性地跟一个 `finally`代码块，无论是否抛出了异常，它都会在 `try`代码块之后执行。

下面的示例展示了这些关键字的工作方式：

```java
public class ATM {
  public void withdraw(BankAccount bankAccount, double amount) {
    try {
      System.out.println("Withdrawing " + amount);
      bankAccount.withdraw(amount);
      System.out.println("Withdrawal succeeded");
    } catch (InsufficientBalanceException) {
      System.out.println("Withdrawal failed: insufficient balance");
    } catch (RuntimeException e) {
      System.out.println("Withdrawal failed: " + e.getMessage());
    } finally {
      System.out.println("Current balance: " + bankAccount.getBalance());
    }
  }
}
```

在这个示例中，没有抛出异常时，打印的内容如下：

```text
Withdrawing 10.0
Withdrawal succeeded
Current balance: 5.0
```

不过，如果 `bankAccount.withdraw(amount)`语句抛出了 `InsufficientBalanceException`，打印的内容则如下：

```text
Withdrawing 10.0
Withdrawal failed: insufficient balance
Current balance: 5.0
```

或者，如果 `bankAccount.withdraw(amount)`抛出了非受检异常，打印的内容如下：

```text
Withdrawing -10.0
Withdrawal failed: Cannot withdraw a negative amount
Current balance: 5.0
```

### 错误

Java 还有一个单独的类别，叫作_错误_，它指的是应用程序外部的严重问题。
错误的一个例子是 `OutOfMemoryError`，当应用程序试图使用的内存超过系统可用内存时，就会出现这种错误。

和非受检异常一样，错误也不会在编译时检查。
区别在于，它们代表的是系统层面的问题，通常由 Java 虚拟机或环境抛出，而不是由应用程序抛出。
应用程序通常不应尝试捕获或处理它们。

Java 中的所有错误都继承自 `Error`类。
