# 关于

Factor 在 [`random`][random] 词汇表中把随机性集中到一个泛型词上：

```
random ( obj -- elt )
```

它会根据实参进行分派：

- **整数** `n`会返回 `[0, n)`范围内的随机整数；
- **序列**会产生一个随机元素；
- 也支持 assoc、hash-set 和 `uniform-distribution`元组。

有两个序列辅助词建立在这个词之上：

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize`会就地修改并返回该序列，所以如果需要保留原来的顺序，先用`clone`复制一份。

## 随机性从何而来

`random`读取的是`random-generator`动态变量中保存的生成器。默认情况下，它是一个 Mersenne Twister 生成器，种子来自系统时钟，所以每个进程都不一样。你可以在一段 quotation 的持续时间内换用另一个生成器：

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

由于`with-random`只是在 quotation 的动态作用范围内绑定`random-generator`，包装它的词应该标记为`inline`，这样 quotation 才能把结果留在数据栈上交给调用方。

除此之外，`random`还提供了用于其他分布的`random-bits`、`random-unit`、`uniform-random`和`normal-random`，以及用于不可复现需求和加密需求的`system-random-generator`和`secure-random-generator`。
