# 说明

在这个练习中，你要和朋友玩一个猜数字游戏。规则很简单：你秘密选一个`1`到`100`之间的数字，然后由朋友来猜你选的是哪个数。为了帮助朋友，你要根据猜测与你所选数字（`42`）的接近程度给出不同的回应。不同回应遵循以下规则：

- 如果猜的是`42`：“Correct”
- 如果猜的是`41`或`43`：“So close”
- 如果猜的数小于`41`：“Too low”
- 如果猜的数大于`43`：“Too high”

你需要完成四个任务，分别实现对不同猜测的回应。

## 1. 回应猜中的情况

实现`reply`函数，让它能回应猜中的情况：

```gleam
reply(42)
// -> "Correct"
```

## 2. 回应接近的猜测

修改`reply`函数，让它能回应接近的猜测：

```gleam
reply(41)
// -> "So close"
```

## 3. 回应过低的猜测

修改`reply`函数，让它能回应过低的猜测：

```gleam
reply(25)
// -> "Too low"
```

## 4. 回应过高的猜测

修改`reply`函数，让它能回应过高的猜测：

```gleam
reply(88)
// -> "Too high"
```
