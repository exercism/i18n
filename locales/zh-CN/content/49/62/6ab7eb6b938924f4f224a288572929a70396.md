# 说明

在这个练习中，你将对一台称重机建模。

## 1. 为称重机创建初始状态

初始化时，称重机应参考其出厂设置，而出厂设置会因机器的销售地区而异。因此，机器在初始化时应能指定一个精度，以及它使用的是公制还是英制。

实现 `WeighingMachine#initialize` 方法，它接收两个实参：`precision`（一个 `Int32`）和 `metric`（一个 `Bool`）。`metric` 实参为 `true` 时表示机器应使用公制，否则应使用英制。这个初始化方法还应将实例变量 `@weight` 设为 `0.0`。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. 让称重机具有精度

为了满足不同的需求，我们允许每台称重机自定义精度（小数点后的位数）。

实现 `WeighingMachine#precision` getter 方法，返回称重机的精度。

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. 允许在称重机上设置重量

实现 `WeighingMachine#weight` 属性，使重量既能被读取，_也_能被设置：

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. 允许机器在公制和英制单位之间切换

实现 `WeighingMachine#metric=` 属性来设置单位。它应接受一个布尔值。

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
