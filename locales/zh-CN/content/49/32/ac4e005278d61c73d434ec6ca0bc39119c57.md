# 输入输出参数

在函数体内，形参被当作常量而不是变量；试图修改形参的值会引发编译时错误。
如果函数希望修改某个形参的值，就必须使用[_输入输出参数_][in-out-parameters]，把这种可变性明确表达出来。

要使用输入输出参数，程序员必须确认三件事：

1. 函数定义必须显式标记输入输出参数：在形参类型标注的`:`和类型名之间写上关键字`inout`。
2. 传给输入输出参数的值必须声明为变量，而不是常量。同样，它也不能是字面量。
3. 调用函数时，变量名前面必须加上`&`，显式标明它是可修改的。

完成这些之后，函数会在内部复制一份输入输出参数，按函数体中的指示修改这份副本，然后在函数返回时把修改后的值复制回传入的那个变量。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
关于输入输出参数，还有几条额外的规则需要留意。

1. 在带有输入输出参数的函数内部，不能引用作为输入输出参数传入的那个变量。
2. 同一个变量不能在同一次函数调用中作为多个输入输出参数传入。
   例如，`inoutFunc(&mutVar, &mutVar)`会引发编译器错误。
~~~~
