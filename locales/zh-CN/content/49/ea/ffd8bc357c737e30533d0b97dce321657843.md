# 简介

你的朋友 Eliud 从奶奶 Tigist 那里继承了一座农场。她的奶奶是个发明家，总喜欢把东西造得过分复杂。鸡舍里有一块数字显示屏，上面显示一个经过编码的数字，表示所有可以捡到的鸡蛋的位置。

Eliud 想请你写一个程序，显示鸡舍里鸡蛋的实际数量。

位置信息的编码方式如下：

1. 扫描所有可能下蛋的位置，有鸡蛋的标记 `1`，空位置的标记 `0`。
2. 把这个数从二进制转换成十进制。
3. 把结果显示在屏幕上。

示例 1：

```text
Chicken Coop:
 _ _ _ _ _ _ _
|E| |E|E| | |E|

Resulting Binary:
 1 0 1 1 0 0 1

Decimal number on the display:
89

Actual eggs in the coop:
4
```

示例 2：

```text
Chicken Coop:
 _ _ _ _ _ _ _ _
| | | |E| | | | |

Resulting Binary:
 0 0 0 1 0 0 0 0

Decimal number on the display:
16

Actual eggs in the coop:
1
```
