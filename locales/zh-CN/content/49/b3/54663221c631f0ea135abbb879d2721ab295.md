# 说明

从前，有一位古怪的程序员，住在一栋窗户装着铁栅栏的奇怪房子里。有一天，他从一个在线招聘网站上接了一份工作，要造一个派对机器人。这个机器人负责迎接客人，并把他们带到座位上。第一版非常技术化，暴露出这位程序员缺乏与人打交道的经验。其中一些问题也被带进了下一版。

## 1. 欢迎新客人来参加派对

实现`welcome`方法，用给定的名字返回一条欢迎消息：

```crystal
PartyRobot.welcome("Christiane")
# => Welcome to my party, Christiane!
```

## 2. 欢迎今天过生日的新客人来参加派对

实现`happy_birthday`方法，用这个人的名字和年龄返回一条生日祝福。可惜这位程序员有点爱炫耀，所以机器人必须展示它知道每位客人的生日。

```crystal
PartyRobot.happy_birthday("Frank", 58)
# => Happy birthday Frank! You are now 58 years old!
```

## 3. 指路

实现`assign_table`函数来指路。它应该接受 5 个形参。

- 要迎接的新客人的名字（`String`）
- 桌号（`Int`）
- 同桌的名字（`String`）
- 找到桌子的方向（`String`）
- 到桌子的距离（`Float64`）

确切的结果格式见下面的示例。

同桌的名字应缩写为这个名字的首字母和末字母。Frank 会变成 Fk，Christian 会变成 Cn，依此类推。

机器人会说出桌号。机器人还会提到桌子的距离。幸好精度只保留 1 位小数。

```crystal
PartyRobot.assign_table("Christiane", "on the left", 27, 23.7834298, "Frank")
# =>
# Welcome to my party, Christiane!
# You have been assigned to table 27. Your table is on the left, exactly 23.8 meters from here.
# You will be sitting next to Fk.
```
