# 说明

Ozan 正在为即将到来的一次公路旅行准备播放列表。他不想把同一首曲目听两遍，但播放列表已经变得太长，他记不清哪些曲目已经加进去了。

Ozan 音乐播放器的 API 只会处理数组，于是他试着写了一些代码，用`Array.indexOf()`在把曲目加入播放列表之前检查它是否已经存在。可惜的是，他的程序运行起来太慢了。他需要你的帮助！

赶来帮助 Ozan 的你惊讶地发现，他的播放列表里居然有_五十万_首曲目。也许你知道另一种数据结构，能让你更高效地操作这个播放列表？

## 1. 移除重复的曲目

实现`removeDuplicates`函数：它接收一个播放列表作为_形参_，并_返回_一个新的播放列表，其中所有曲目都不重复。

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. 检查某首曲目是否已经添加过

实现`hasTrack`函数：它接收一个播放列表和一首曲目作为_形参_，并_返回_一个布尔值，表示该播放列表中是否包含这首曲目。

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. 添加一首曲目

实现`addTrack`函数：它接收一个播放列表和一首曲目作为_形参_，并_返回_一个包含该曲目的新播放列表。

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. 删除一首曲目

实现`deleteTrack`函数：它接收一个播放列表和一首曲目作为_形参_，并_返回_一个不包含该曲目的新播放列表。

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. 列出不重复的艺术家

实现`listArtists`函数：它接收一个播放列表作为_形参_，并_返回_播放列表中所有不重复的艺术家列表。注意，曲目的名称格式为`<SONG> - <ARTIST>`。

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
