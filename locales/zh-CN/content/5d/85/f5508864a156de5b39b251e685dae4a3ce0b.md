# 简介

给方法形参指定一个默认值，就能把它变成可选形参。调用带可选形参的方法时，调用方不必为这些形参传入值。如果没有为某个可选形参传入值，就会使用它的默认值。

可选形参_必须_放在形参列表的末尾；它们后面不能再有非可选形参。

```csharp
class Card
{
    static string NewYear(int year = 2020)
    {
        return $"Happy {year}!";
    }
}

Card.NewYear();     // => "Happy 2020!"
Card.NewYear(1999); // => "Happy 1999!"
```
