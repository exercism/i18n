# 运行测试

## 下载练习

使用 [Exercism CLI][cli] 下载你想做的练习。

```sh
exercism download --track=dart --exercise=hello-world
```

然后进入练习目录。

```sh
cd /path/to/exercism/dart/hello-world
```

## 安装依赖

运行测试之前，先下载练习的依赖。

```sh
dart pub get
```

## 运行测试

```sh
dart test
```

## 看懂测试结果

## 逐个完成测试

大多数练习都有多个测试，默认情况下除第一个之外全部跳过。

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

想一次只做一个测试，可以边做边把每个测试的`skip: true`改成`skip: false`。
或者，不修改文件，一次性运行所有测试。

```sh
dart test --run-skipped
```

提交时，在线测试运行器会运行所有测试，包括被跳过的那些。

## 处理错误 “Could not find a command named frontend_server.dart.snapshot”

假设你有一个已经解决并提交过的练习，过了一段时间又回来做。
测试时可能会遇到下面这个错误：

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

[解决办法][solution]是删除 `pubspec.lock` 文件。
然后重新运行 dart 命令。
