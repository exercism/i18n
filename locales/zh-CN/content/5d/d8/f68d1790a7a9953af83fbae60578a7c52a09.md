# 指令

在一局[龙与地下城][DND]（DND）游戏中，每位玩家首先要生成一个可以扮演的角色。
这个角色拥有六项能力：

- strength,
- dexterity,
- constitution,
- intelligence,
- wisdom,
- charisma.

这六项能力的分值由随机方式确定。
具体做法是投掷四颗六面骰子，记录其中最大的三颗骰子的点数之和。
这样进行六次，每次对应一项能力。

角色的初始生命值是 10 + 角色的 constitution 修正值。
要得到角色的 constitution 修正值，用角色的 constitution 减去 10，除以 2，再向下取整。

~~~~exercism/advanced
如果你更喜欢数学记号，修正值的定义如下

$$

\operatorname{modifier}\left(\text{constitution}\right) = \left\lfloor\frac{\text{constitution} - 10}{2}\right\rfloor

$$

生命值的定义如下

$$

\operatorname{HP}\left(\text{constitution}\right) = 10 + \operatorname{modifier}\left(\text{constitution}\right)

$$
~~~~

例如，六次投掷四颗骰子的结果可能如下：

* 5, 3, 1, 6：舍去 1，把 5 + 3 + 6 = 14 相加，将结果赋给 strength。
* 3, 2, 5, 3：舍去 2，把 3 + 5 + 3 = 11 相加，将结果赋给 dexterity。
* 1, 1, 1, 1：舍去 1，把 1 + 1 + 1 = 3 相加，将结果赋给 constitution。
* 2, 1, 6, 6：舍去 1，把 2 + 6 + 6 = 14 相加，将结果赋给 intelligence。
* 3, 5, 3, 4：舍去 3，把 5 + 3 + 4 = 12 相加，将结果赋给 wisdom。
* 6, 6, 6, 6：舍去 6，把 6 + 6 + 6 = 18 相加，将结果赋给 charisma。

因为 constitution 是 3，constitution 修正值是 -4，生命值是 10 - 4 = 6。

## 1. 生成有效的能力值

实现一个函数`ability()`，根据上述规则返回一项能力的值。

```julia-repl
julia> ability()
14
```

~~~~exercism/note
本练习不涉及随机分布，因此你无需模拟四次骰子投掷。
无论分布如何，你都可以用 3 到 18（含）之间的随机值作为能力值。
~~~~

## 2. 计算 constitution 修正值

实现一个函数`modifier(ability)`，根据上述规则，基于`ability`的值返回该项能力的修正值。
返回值必须是整数。

```julia-repl
julia> modifier(17)
3
``` 

## 3. 编写一个遵循上述规则的随机角色生成器

实现一个`DNDCharacter`结构体，包含三个构造函数：

| 构造函数                                                                                    | 说明                                                                       |
| ---------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `DNDCharacter()`                                                                               | 创建一个能力随机生成的角色。                             |
| `DNDCharacter(strength, dexterity, constitution, intelligence, wisdom, charisma, hitpoints)`   | 用给定的能力创建一个角色，使用**位置参数**。 |
| `DNDCharacter(; strength, dexterity, constitution, intelligence, wisdom, charisma, hitpoints)` | 用给定的能力创建一个角色，使用**关键字参数**。    |

```julia-repl
julia> DNDCharacter()
DNDCharacter(18, 17, 18, 17, 5, 10, 14)

julia> DNDCharacter(4, 12, 13, 18, 13, 7, 11)
DNDCharacter(4, 12, 13, 18, 13, 7, 11)

julia> DNDCharacter(
           strength = 4,
           dexterity = 12,
           constitution = 13,
           intelligence = 18,
           wisdom = 13,
           charisma = 7,
           hitpoints = 11
       )
DNDCharacter(4, 12, 13, 18, 13, 7, 11)
```
