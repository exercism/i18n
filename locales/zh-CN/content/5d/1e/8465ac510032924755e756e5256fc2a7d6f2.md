# 简介

PHP 中的协变和逆变概念很重要，因为 PHP 在继承类或接口时会强制遵循这些规则。

协变会保持两种类型之间的关系，而逆变则会反转这种关系。简而言之，在继承类并重写函数时，方法的形参可以允许更具体或更宽泛的类型，方法也可以返回更少或更具体的类型。

## 示例

看看下面的类：

```php
class Calculator 
{
    public function add(int $x, int $y): int 
    {
        return $x + $y;
    }
}
```

如果我们继承这个类，就可以让形参类型比原来声明的更多，但不能返回原来返回类型之外的任何类型。

```php
class Floatulator extends Calculator
{
    // This is valid
    public function add(int|float $x, int|float $y): int 
    {
        return (int)($x + $y);
    }
}
```

下面这个扩展类无效，因为不允许返回额外或更宽泛的类型：

```php
class BrokenCalculator extends Calculator 
{
    // This is invalid and will not compile
    public function add(int|float $x, int|float $y): int|float{
        return $x + $y;
    }
}
```
