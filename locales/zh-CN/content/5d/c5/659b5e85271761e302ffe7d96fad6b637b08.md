# 简介

有时一个函数会接收很多实参，这时很难记住它们的先后顺序。为了提高可读性，Gleam 允许给实参加上名称标签。

要给实参加标签，就把标签名写在实参名前面，中间用一个空格分隔。

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

用带标签的实参调用函数时，实参可以按任意顺序给出。下面这几次对 `replace` 的调用都是等价的：

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

标签始终是可选的。即使一个函数带有标签实参，调用时也依然可以不写标签。

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```
