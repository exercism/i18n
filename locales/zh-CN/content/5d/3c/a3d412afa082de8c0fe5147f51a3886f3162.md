# 简介

Ruby 是一门动态的[面向对象语言][object-oriented-programming]。
Ruby 中一切皆[对象][object]。

在 Ruby 中，将对象赋值给名称主要有两种方式：使用变量或常量。
变量始终采用[蛇形命名法][snake-case]。
变量在其生命周期内可以引用不同的对象。
例如，可以使用`=`运算符多次定义和重新定义`my_first_variable`：

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

不过，常量只应赋值一次。
常量必须以大写字母开头，通常写作全大写形式，单词之间用下划线分隔。

例如：

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby 中的代码以类来组织。
类使用`class`关键字定义，后面跟类名。
对象通常通过使用`.new`方法实例化类来创建。

例如：

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

功能单元封装在方法中，类似于其他语言中的_函数_。
方法可以选择性地定义位置实参，和/或使用`:`语法定义和调用的关键字实参。
方法要么隐式返回最后一条被求值语句的结果，要么可以通过`return`关键字显式返回对象。
方法通过`.`语法调用。

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
