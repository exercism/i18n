# 介绍

## 时间

使用`Time`模块来显示人类可读的日期/时间。
虽然从技术上讲，可以用`Time`来操作时间，但 Elm 社区有一些更适合这项任务的包，例如[`justinmimbs/date`][date]或[`CoderDennis/elm-time-format`][elm-time-format]。

### Posix

时间由不透明类型`Posix`表示，它包装了 Unix 纪元时间，即自 1970 年 1 月 1 日午夜 UTC 以来经过的毫秒数。
`Posix`是一个无歧义的值，不会因时区而变化，因此很适合用来记录时间。
在 Elm 应用程序中，`Posix`时间通常由外部来源（例如浏览器）提供。

可以用以下函数将`Posix`转换为毫秒数，反之亦然：

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

### 时区

在日常生活中，我们人类通常不直接读取`Posix`，而是更喜欢本地时间，本地时间取决于我们在地球上的位置以及当地的夏令时规则。
在 Elm 中，这类信息编码在不透明类型`Zone`中，通常由浏览器提供。

有一个始终可访问的特殊`Zone`：

```elm
utc : Zone
```

### 人类可读时间

有了`Posix`和`Zone`，我们就有足够的信息来以任意详细程度显示本地时间。
以下是可用于此目的的函数列表：

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

你可能已经注意到`Time`中还有两个自定义类型：

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

将这些自定义类型转换为人类可读的值，就留给用户了。
