# 简介

在 SQL 中，`SELECT` 语句可以用来从数据库中检索数据。`SELECT` 语句的结果是一个结果集。结果集包含按行和列排列的值。每一列都是数据的一个特定属性，每一行则包含每一列对应的一个值。

一种理解方式是：一组列代表一种数据结构，其中每一列代表该数据结构的一个字段，每一行代表该数据结构的一个实例。

使用 `SELECT` 语句，你可以指定想要检索的数据。此外，你还可以选择对输出的数据进行转换、筛选，以及（或）修改其结构。

## 基础知识

一条基本的 `SELECT` 语句的结构如下：

```sql
SELECT <columns>
FROM <source>
WHERE <criteria>;
```

~~~~exercism/note
`FROM` 和 `WHERE` 子句都是可选的。例如，`SELECT "Hello, world.";` 这样的语句完全有效。

还要注意，换行并不是必需的；任何空白都足以分隔 `SELECT` 语句的不同子句（也就是各个部分）。
~~~~

紧跟在 `SELECT` 关键字后面的，是你希望出现在结果中的列名列表。`FROM` 子句指明数据的来源，通常就是数据库中的一张表。`WHERE` 子句则按照一个或多个条件筛选输出的数据。

## 用 WHERE 子句筛选数据

`WHERE` 子句让你可以筛选 `SELECT` 语句检索到的数据。例如，如果我们只要 Appliances 这一类数据，可以这样做：

```sql
SELECT * FROM inventory
WHERE category = "Appliances";
```

结果：
```
upc           category    supplier        brand      product_name                 weight  stock
------------  ----------  --------------  ---------  ---------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker    4.2     18   
880012349876  Appliances  Culinary Depot  HeatWave   Compact Toaster Oven         7.5     14   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender  3.1     16   
```

又或者，我们只要重量在 2.0 到 6.0 之间的数据：

```sql
SELECT * FROM inventory
WHERE weight BETWEEN 2.0 AND 6.0;
```

结果：
```
upc           category    supplier        brand      product_name                  weight  stock
------------  ----------  --------------  ---------  ----------------------------  ------  -----
899001234556  Appliances  Culinary Depot  QuickBrew  Single-Serve Coffee Maker     4.2     18   
823450987112  Cookware    KitchenCo       FreshKeep  12-Piece Glass Container Set  6       33   
899998877665  Cookware    KitchenCo       IronCraft  Cast-Iron Grill Pan           5.3     21   
844110220987  Appliances  Culinary Depot  BlendPro   High-Speed Personal Blender   3.1     16   
```
