# 关于

函数默认具有外部链接，可以被项目中的任何其他文件调用。
关于链接的更多内容，请参阅[链接概念](../linkage/introduction.md#Introduction)。
`static`函数只能在定义它的源文件内被调用。

例如

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```

即使一个函数在头文件中声明，如果它被定义为`static`，也无法从它的源文件之外调用。
源文件可以包含该头文件，调用头文件中声明的`static`函数，并通过编译，但链接器会找不到该`static`函数的定义。
在源文件中标记为`static`的函数不应在其头文件中声明。
