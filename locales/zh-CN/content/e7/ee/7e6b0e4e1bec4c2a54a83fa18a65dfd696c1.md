# 简介

Julia 中主要有三种条件语句：

- `if`表达式
- 三元运算符
- 短路求值

## `if`表达式

Julia 中的 `if`表达式与其他语言中的类似：

```julia-repl
julia> function say_if_positive(n)
           if n > 0
               println("n is positive!")
           else
               println("n is not positive!")
           end
       end
say_if_positive (generic function with 1 method)

julia> say_if_positive(10)
n is positive!

julia> say_if_positive(-10)
n is not positive!
```

如果 `if`后面的布尔表达式求值为`true`，就会运行第一个代码块，跳过第二个代码块。
如果 `if`后面的布尔表达式求值为`false`，就会跳过第一个代码块，运行第二个代码块。
程序从 `end`关键字之后的第一行代码继续运行。

~~~~exercism/note
在 Julia 中，`end`关键字表示所有块表达式的结束。
这个语法并不专属于 `if`表达式或函数定义。
~~~~

如果第二个代码块本身就是另一个 `if`表达式，那么用 `elseif`就可以避免在代码块里嵌套 `if`表达式：

```julia-repl
julia> function dessert(fruit)
           if fruit == "apple"
               return "Apple Crumble"
           elseif fruit == "lemon"
               return "Lemon Meringue Pie"
           else
               return "Fruit Salad"
           end
       end
dessert (generic function with 1 method)

julia> dessert("apple")
"Apple Crumble"

julia> dessert("lemon")
"Lemon Meringue Pie"

julia> dessert("peach")
"Fruit Salad"
```

如果 `if`表达式只需要处理其中一种情况，就不必写出 `else`分支。

## 三元运算符

简单的 `if-else`语句也可以用三元运算符 `a ? b : c` 来写。
如果`a`为`true`，就求值`b`。
否则求值`c`。

例如下面这个函数

```julia-repl
julia> function diagnose(heartrate)
           if heartrate > 100
               println("Elevated heart rate.")
           else
               println("Nominal heart rate or dead.")
           end
       end
diagnose (generic function with 1 method)
```

也可以写成

```julia-repl
julia> diagnose(heartrate) = heartrate > 100 ? println("Elevated heart rate.") : println("Nominal heart rate or dead.")
diagnose (generic function with 1 method)
```

如果你想根据条件给变量赋不同的值，这一写法尤其有用。
如果`a`为`true`，`x = a ? b : c` 会把`b`赋给`x`，否则把`c`赋给`x`。
例如：

```julia-repl
julia> function patient_status(heartrate)
           status = heartrate > 0 ? "alive" : "dead"

           println("The patient is ", status)
       end

julia> patient_status(100)
The patient is alive

julia> patient_status(0)
The patient is dead
```

## 短路求值

如果用 `&&` 和 `||` 运算符把多个布尔表达式串联起来，Julia 只会求值确定整条链的值所必需的最少数量的表达式。

例如，看这条表达式链 `n > 0 && k > 10`。
如果`n`等于`5`，链的第一部分`n > 0`为`true`，这时必须求值第二个表达式 `k > 10`，才能确定整个表达式是否为`true`。
但如果`n`等于`-5`，我们就知道整条链**不可能**为`true`，因为它的第一个表达式为`false`。

如果换成 `n > 0 || k > 10`，情况正好相反。
如果`n`等于`5`，链的第一部分`n > 0`为`true`，我们就知道无论第二个表达式是什么，整条链都为`true`。
但如果`n`等于`-5`，就必须求值第二个表达式。

利用这一行为可以写出很短的 `if`语句：

```julia
if a
    b
end
```

等价于

```julia
a && b
```

`&&` 和 `||` 链中的最后一个表达式不必是布尔表达式。
你经常会看到这个特性被用于提前报错或提前返回。
例如，用上面那个 `dessert(fruit)`函数：

```julia-repl
julia> function whats_for_dessert(fruit, allergic_to)
           fruit == allergic_to && return "I can't eat that, guess I'll not have dessert tonight!"

           return dessert(fruit)
       end
whats_for_dinner (generic function with 1 method)

julia> whats_for_dinner("apple", "peach")
"Apple Crumble"

julia> whats_for_dinner("apple", "apple")
"I can't eat that, guess I'll not have dessert tonight!"
```
