# 简介

## 模式匹配字面量

`if/else`表达式可以用来实现条件逻辑，但 Haskell 还有一种更强大的方式：[模式匹配][pattern-matching]。
有了模式匹配，就可以把一个值和一个或多个_模式_进行匹配。
这类模式的一个例子是_常量模式_，它把一个值和常量（比如`1`或`"hello"`）进行匹配。

定义函数时，可以为不同的模式定义不同的函数体。
这样写出的代码干净利落，简单易读。
你可以对任何数据类型进行模式匹配：数字、字符、数组、元组等。

比如，有一个简单的函数，它接收一个整数（`Int`），并让它向 _0_ 靠近 _1_，可以这样写：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

模式匹配和其他模式一起使用时才真正显出威力，比如_变量模式_：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

上面的例子把所有非 _0_ 的输入都同等对待，对负数会产生错误的结果。
这可以用条件模式来解决，这种模式叫作_守卫_，用`|`符号表示：

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

上面的例子里，并非所有可能的输入都有匹配的模式。
编译器会发现这一点，并给出警告。
这是 Haskell 一个非常有用的特性，它能帮助确保覆盖所有可能的路径，避免运行时错误。
这叫作_穷尽性检查_。
要消除这个警告，你必须处理所有情况。
在_守卫_里，你可以用表达式`otherwise`作为`True`的语法糖，来兜住所有剩下的模式。

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

模式匹配会从上到下依次把值和每个模式进行匹配，直到找到匹配的模式，然后执行与该模式关联的逻辑。
**模式的顺序很重要！**
