# 说明

在这个练习中，你将再写一些代码，帮助你按照最喜欢的烹饪书做出美味的千层面。

你共有五个任务，它们都与烹饪千层面所花的时间有关。

## 1. 允许修改预期的烘烤时间

你想写一个改进版的`remainingMinutesInOven`函数，它接受千层面已经在烤箱里度过的分钟数作为形参，并根据上一个任务中给出的预期烘烤时间（分钟），返回千层面还需要在烤箱里待多久。
之前，你依赖的是来自`remainingMinutesInOven`函数外部的常量`expectedMinutesInOven`。
这样的写法对你来说既有点杂乱，又不够灵活，因为它不允许你修改预期的烘烤时间。

为了理清这些，请定义`remainingMinutesInOven`函数，它接受千层面已经在烤箱里度过的分钟数作为形参，还接受一个默认值为 40 的`expectedMinutesInOven`形参。
你的函数应根据上一个任务中给出的预期烘烤时间（分钟），返回千层面还需要在烤箱里待多久。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. 允许层数不同

你之前写过`preparationTimeInMinutes`函数，它接受加入千层面的层数作为形参，返回准备千层面所花的分钟数，并假定每层需要 2 分钟准备。
不过，你对这个函数并不太满意，因为在调用它之前，你得自己数千层面有多少层。谁有那么多时间？

为了让自己省点事，请写一个`preparationTimeInMinutes`函数，它接受一个可变参数的`String`形参`layers`，在其中列出千层面的各种层。
该函数随后会数出千层面有多少层，并返回所需的准备时间。

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. 计算面条和酱料的用量

在开始组装千层面之前，你想确认自己是否有足够的酱料和面条，来做出梦想中的千层面。
千层面中每有一层，就需要 3 片面条。
千层面中每有一层酱料，就需要 0.2 升酱料。

定义`quantities`函数，它接受一个可变参数的`String`形参`layers`，在其中列出千层面的各种层。
该函数会算出这道菜所需的面条和酱料用量。结果应以`(noodles: Int, sauce: Double)`类型的元组返回。

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. 原地将升转换为液量盎司

不巧的是，你手头这瓶酱料的体积标注的是液量盎司，而不是升。
为了方便判断手头的酱料是否够用，请写一个`toOz`函数，它接受一个输入输出元组形参`(noodles: Int, sauce: Double)`，并把酱料的用量转换为液量盎司。
注意，每升等于 33.814 液量盎司。

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. 确定最适合搭配的葡萄酒

最后，你想知道吃千层面时该搭配哪种葡萄酒。
你听说，如果千层面里的马苏里拉奶酪、里科塔奶酪和白酱比肉和酱料多，就应该配白葡萄酒，否则配红葡萄酒。
请写一个`redWine`函数，它接受一个可变参数的`String`形参`layers`，在其中列出千层面的各种层。
该函数会使用五个嵌套函数，分别数出千层面中马苏里拉奶酪、里科塔奶酪、白酱、酱料和肉的层数，再比较这些层数，判断是否应该配红葡萄酒：应该时返回`true`，否则返回`false`。

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
