# 没有具名导出

没有找到名为 `%{export.name}` 的 [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export)。少了它，测试就无法通过。

确保 `%{export.name}` 存在，并在它前面加上 `export`：
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
