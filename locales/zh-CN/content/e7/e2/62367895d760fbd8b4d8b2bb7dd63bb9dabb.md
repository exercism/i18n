# 说明

在本练习中，你将实现一组实用函数，帮助开发者清理标识符名称。

在 4 个任务中，你将逐步构建`clean`函数。有效的标识符由零个或多个字母和下划线组成。

在所有情况下，输入字符串都保证不是 nil。如果向`clean`函数传入空字符串，则应返回空字符串。

注意，调用方应避免用空标识符调用`clean`函数，因为这类标识符没有实际作用。

## 1. 把遇到的空格替换成下划线

实现`clean`函数，把空格替换成下划线。开头和结尾的空格也不例外。

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. 把控制字符替换成大写字符串 `"CTRL"`

修改`clean`函数，把控制字符替换成大写字符串`"CTRL"`。

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. 把 kebab-case 转换为 camelCase

修改`clean`函数，把 kebab-case 转换为 camelCase。

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. 省略小写希腊字母

修改`clean`函数，省略 'α' 到 'ω' 范围内的所有希腊字母。

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
