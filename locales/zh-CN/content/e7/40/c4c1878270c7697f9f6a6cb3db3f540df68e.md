# `jq`中的函数

你可以在`jq`中定义自己的**自定义函数**，用来封装你需要的任何逻辑。
_函数_的行为和内置函数一样：接收一个输入，产生零个、一个或多个输出。

## 定义函数

你可以使用下面的语法定义`jq`的_函数_：

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- 以`def`关键字开头，
- 函数体前面有一个冒号，
- 函数体由单个表达式组成，
- 以分号结尾，
- 和`jq`语法的其他部分一样，你可以随意使用空白来提升可读性。

## 函数放在哪里

_函数_必须先定义后使用：下面这样是错误的：

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

这意味着你必须把_函数_放在`jq`代码的开头，也就是“主”表达式之前。

### 嵌套函数

_函数_可以嵌套：

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

这里，`B`_函数_只在`A`的函数体里可见。

## 作用域

一个_函数_会为变量和嵌套函数引入一个新的**作用域**。

## 实参

_函数_的**实参**之间用_分号_分隔，而不是逗号。
例如，下面这个_函数_接收一个数，再给它加上一个数，然后乘以一个数：

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

<!-- prettier-ignore -->
~~~~exercism/note
之所以需要分号，是因为逗号在`jq`中已经有用途了：它是一个合并流的运算符。

用逗号代替分号，会试图对一个只有_一个实参_的`add_mul`函数发起两次调用，而这个函数并不存在，因此第一次调用就会失败：

```jq
10 | add_mul(5, 4)
# error: add_mul/1 is not defined
```

`5, 4`中的逗号把数字 5 和 4 拼接成一个流。
当我们用一个流作为实参调用函数时，`jq`会多次调用该函数，流中的每个值各调用一次。
这就是`jq`流中固有的“隐式迭代”的一个例子。
`10 | add_mul(5, 4)`等价于下面这样。

```jq
(10 | add_mul(5)), (10 | add_mul(4))
```
现在我们就能看出`add_mul/1 is not defined`这个错误是怎么冒出来的了。
~~~~

<!-- prettier-ignore-end -->

### 实参是_表达式_

函数的_实参_是过滤器，而不是值。
从这个意义上说，它们的作用类似于其他语言中所说的回调：

以`add_mul`函数为例：

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

这里发生了什么？

- `adder`实参得到的是_表达式_`. + 5`
  - 当函数执行`. + adder`时，这就变成了`. + . + 5`
  - 因为`. == 10`，所以结果是 25
- 类似地，`multiplier`实参是表达式`. - 2`
  - 结果是 8
  - 最终结果就是`25 * 8 == 200`

### 实参作为值

有时你会想把一个_实参_“具象化”为一个变量：

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

这有一种简写形式：

```jq
def my_func($arg):
    other stuff ...
;
```

注意，这只是“语法糖”：不带`$`的名字`arg`在_函数_中仍然处于作用域内。

<!-- prettier-ignore -->
~~~~exercism/caution
例如，为了解一道练习，我写了类似这样的代码：

```jq
# function that encodes the input value
def code:
    # expression here
    ;

def equals($code):
    (. | code) as $this_code
    | $code == $this_code
    ;

("some key value" | code) as $key
| ["array", "of", "values"]
| map(select(equals($key)))
```

结果我惊讶地发现，数组中的每个值都等于那个键。

这是因为 jq 把`equals`函数看成了

```jq
def equals(code):
    code as $code
    | (. | code) as $this_code
    | $code == $this_code
    ;
```

**实参**`code`_覆盖_了先前定义的**函数**`code`。
这意味着`(. | code)`只是输出这个**实参**，而不是根据输入值计算出一个新的 code。
因此`$this_code`和`$code`总是相同的。
~~~~

## 元数

_函数_有**元数**，也就是它所接收的_实参_个数。

_函数_可以同名，但_元数_不同。
内置函数[`range`][man-range]就是一个例子：`range/1`、`range/2`和`range/3`可以共存。

这对于定义通过实参携带状态的递归函数很有用。
例如`map`_可以_这样实现：

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## 递归

`jq`会进行尾调用优化，但只对元数为 0 的函数。

## 模块

`jq`模块是只包含函数的文件。
可以用[`include`][man-include]或[`import`][man-import]命令把模块引入 jq 程序。
