# 异常

在理想情况下，一切都能正常运行。但在现实世界里，事情难免出错，而如何处理这些情况，直接决定了我们的软件是否健壮可靠。异常是编程中的一个关键概念，它让我们能够从容地处理错误和意外情况。

抛出错误后，如果不加处理，程序就会中止并输出一条错误信息。大多数情况下，你不希望程序一出错就中止，而是希望处理这个错误，让程序继续运行。

## 抛出异常

在 Crystal 中，异常通过`raise`关键字抛出，它既可以接收一个`String`，也可以接收一个`Exception`对象。如果没有处理，程序会中止并打印错误信息。

```crystal
raise "This is an error"
```

Crystal 内置了多种异常，例如`ArgumentError`、`IndexError`、`KeyError`、`IOError`、`SystemCallError`、`TypeError`、`ZeroDivisionError`等等。这些异常要求你为它传入一条消息。

```crystal
raise ArgumentError.new("This is an argument error")
```

## [处理异常][exception-handling]

我们不希望程序在抛出异常时崩溃。因此，当我们知道某段代码容易出错时，可以把它包在`begin`块里，再用`rescue`块捕获异常。`begin`块标记了可能抛出异常的代码的起点，`rescue`块则负责处理异常。

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
end
```

`rescue`块还可以指定一个变量，用来获取异常对象。

```crystal
begin
 raise "This is an error"
rescue ex
 puts "An error occurred: #{ex.message}"
end
```

`rescue`块也可以只指定某种具体的异常类型，从而只捕获该类型的异常。

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
end

# or

begin
 raise ArgumentError.new("This is an argument error")
rescue ex : ArgumentError
 puts "An argument error occurred: #{ex.message}"
end
```

可以用多个`rescue`块来处理不同类型的异常。在下面的例子中，第一个`rescue`块会捕获`ArgumentError`，第二个`rescue`块则会捕获其他任何异常。

```crystal
begin
 raise ArgumentError.new("This is an argument error")
rescue ArgumentError
 puts "An argument error occurred!"
rescue
 puts "An error occurred!"
end
```

`begin`块还可以带一个`else`块，当没有异常抛出时就会执行它。

```crystal
begin
 puts "No error occurred"
rescue
 puts "An error occurred!"
else
 puts "No error occurred"
end
```

最后还有一个`ensure`块，无论是否抛出异常，它都一定会执行。

```crystal
begin
 raise "This is an error"
rescue
 puts "An error occurred!"
ensure
 puts "This is always executed"
end
```

## 方法约定

有些方法有两个版本，一个带`!`，另一个不带。这可能表示两种不同的含义：一是该方法会修改对象，二是该方法可能抛出异常。

不过，布尔概念中还提到了另一个约定，即以`?`结尾的方法。有些方法默认会抛出异常，但也提供一个以`?`结尾的版本，它不抛出异常，而是返回`nil`。

当你希望避免抛出错误时，这种方式很理想。它还有利于性能，因为不必生成堆栈跟踪，而且如果使用得当，还能让代码更安全。

## 自定义异常

你也可以通过继承 [`Exception`][exception] 类来创建自己的异常。这样做时，你可以选择重写`initialize`方法，以设置异常消息。具体做法是给名为`@message`的实例变量赋上该消息。

```crystal
class MyException < Exception
 def initialize
   @message = "This is my exception"
 end
end

raise MyException.new
```
