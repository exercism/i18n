# 说明

你是一位热心的观鸟爱好者，一直在记录过去七天里有多少只鸟造访过你的花园。

你有六个任务，全都与造访你花园的鸟的数量有关。

## 1. 查看上周的鸟数量

为了方便比较，你总是随身保留一份上周的数量记录，分别是：0、2、5、3、7、8 和 4。实现`BirdWatcher.getLastWeek()`方法，返回上周的数量：

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看今天有多少只鸟来访

实现`BirdWatcher.getToday()`方法，返回今天有多少只鸟造访过你的花园。鸟的数量按天排序，第一个元素是最早那天的数量，最后一个元素是今天的数量。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. 让今天的数量自增

实现`BirdWatcher.incrementTodaysCount()`方法，让今天的数量自增：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. 检查是否有某天没有鸟来访

实现`BirdWatcher.hasDayWithoutBirds()`方法，如果某天没有鸟造访花园就返回`true`；否则返回`false`：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. 计算前几天的来访鸟数量

实现`BirdWatcher.getCountForFirstDays()`方法，返回从本周开始造访过你的花园的鸟的数量，但把统计范围限制在从本周起始算起的指定天数内。

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. 计算繁忙日子的数量

有些日子比其他日子更繁忙。繁忙的一天是指有 5 只或更多鸟造访过你的花园。
实现`BirdWatcher.getBusyDays()`方法，返回繁忙日子的数量：

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
