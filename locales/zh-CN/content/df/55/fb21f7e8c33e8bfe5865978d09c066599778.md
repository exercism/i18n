# 关于

组合子把栈上重排的模式变成有名字、可组合的词。等你写够了 Factor，就不会再想着“我得先 `dup`，再运行 F，然后保留原来的值”，而是直接写 `[ F ] keep`。

| 模式                            | 栈重排                        | 组合子      |
|------------------------------------|-------------------------------|-----------------|
| 对输入应用 F，并保留输入           | `dup F swap`                  | `[ F ] keep`    |
| 同一个输入上应用两个函数           | `dup F swap G`                | `[ F ] [ G ] bi`|
| 同一个输入上应用三个函数           | 很繁琐                        | `[ F ] [ G ] [ H ] tri` |
| 同一个输入上应用多个函数           | 极其繁琐                      | `{ Fs … } cleave`|
| 对栈顶*下方*的值进行操作           | `swap F swap`                 | `[ F ] dip`     |
| 对两个值做同样的操作               | `swap F swap F`               | `[ F ] bi@`     |
| 对两个值做不同的操作               | `swap F swap G`               | `[ F ] [ G ] bi*`|

以`2`开头的系列（`2bi`、`2dip`、`2tri`、`2dup`、`2drop`、`2nip`、`2swap`）会在每个操作需要*两个*输入时做同样的事；`3dup` 和 `4dup` 则把复制的用法扩展到栈顶的三个或四个值。

除了 cleave/dip/bi 这一族之外，[`kernel`][kernel] 还提供了一些控制流变体，它们能干净地传递 `f`：

| 词          | 作用                                                |
|-------------|-----------------------------------------------------|
| `if*`       | 真分支能看到该值；假分支看不到                      |
| `?last`     | 序列的最后一个元素，为空时返回 `f`                  |
| `pop*`      | `pop` 的丢弃版（会修改向量）                        |
| `dupd`      | 复制栈顶*第二个*值                                  |
| `pick`      | 把栈顶*第三个*值复制到栈顶                          |
| `swapd`     | 交换栈顶第二和第三个值                              |
| `rotd`      | 旋转四层栈中最底下的三个值                          |
| `tuck`      | 把栈顶值复制到栈顶第二个值的下面                    |
| `with`      | 把一个固定值烘焙进引文，供 HOS 使用                 |
| `while`     | 在谓词成立时循环                                    |
| `until`     | 循环直到谓词成立                                    |

选对组合子本身就是一门技能。一般规律是：一个定义的函数体里只要连续出现了不止一个重排词，通常就有一个组合子能更好地表达这个意图。

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
