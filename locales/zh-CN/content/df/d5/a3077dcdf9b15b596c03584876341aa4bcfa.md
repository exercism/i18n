# 简介

几乎每个 Factor 程序都是一系列在*数据栈*上消耗和产生值的词。当输入和输出恰好对齐时，代码读起来从左到右，毫不费力；一旦对不上，就得搬出*重排词*，代码很快就会变得杂乱。

这个练习会带你认识 Factor 的标准解法：组合子。

## 重排词

最常见的重排词都在[`kernel`][kernel]里：

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

你应该已经用过`dup`和`swap`。`over`会复制从栈顶数起的*第 2 个*元素，当同一个输入需要送给 2 个计算时很方便：

```factor
! Sum a number with twice itself: x + 2*x
: triple ( x -- 3x ) dup 2 * + ;
```

只用 1 次还好。但把`dup`、`swap`、`over`、`rot`串在一起，很快就变得难以阅读。

## `keep`：保留输入

`keep`（位于[`kernel`][kernel]）会把一个引用作用在栈顶，但把原值留在结果的上面：

```
keep ( x quot: ( x -- y ) -- y x )
```

```factor
5 [ 2 * ] keep .s
! => 10
! => 5
```

这就替代了先`dup`、再做点什么、然后重排的写法：凡是原来要写`dup something swap`的地方，现在只要写`[ something ] keep`就行。

## `bi`：1 个输入，2 个函数

`bi`（位于[`kernel`][kernel]）会把*2 个*引用作用在同一个值上，并把 2 个结果都留在栈上：

```
bi ( x q1 q2 -- r1 r2 )
```

```factor
4 [ sq ] [ neg ] bi .s
! => 16
! => -4
```

没有`bi`的话，你得写`dup sq swap neg`，2 个操作还算读得懂，3 个就头疼了。

## `tri`和`cleave`：1 个输入，多个函数

`tri`把`bi`扩展到 3 个引用：

```
tri ( x q1 q2 q3 -- r1 r2 r3 )
```

`cleave`（位于[`combinators`][combinators]）是同样的思路，只不过作用在由任意数量引用组成的*数组*上：

```factor
4 { [ ] [ sq ] [ neg ] } cleave .s
! => 4
! => 16
! => -4
```

空的引用`[ ]`起恒等作用，当切割出来的某一格恰好要是输入本身时很有用。

## `dip`和`2dip`：在下方操作

`dip`（位于[`kernel`][kernel]）会把一个引用作用在栈顶*下方*的值上，栈顶保持不变。`2dip`做同样的事，但保护最上面的*2 个*值：

```
dip  ( x   quot -- x   )
2dip ( x y quot -- x y )
```

```factor
9 10 11 [ + ] dip .s
! => 19      (9 + 10)
! => 11      (the protected top, restored)

9 10 11 12 [ + ] 2dip .s
! => 19      (9 + 10)
! => 11      (the protected y, originally 11)
! => 12      (the protected x, originally 12)
```

这里`dip`先把`11`藏起来，运行`9 10 +`，再把`11`放回栈顶。`2dip`把`11 12`藏起来，在下方运行`9 10 +`，然后恢复`11 12`。

当自然的实参顺序把那个“透传”的值留在栈顶时，`dip`就是合适的工具。用它来代替`swap … swap`这种“夹心”写法。

## `bi@`：对 2 个值做同样的操作

`bi@`（位于[`kernel`][kernel]）会把 1 个引用作用在 2 个栈值上：

```
bi@ ( x y quot -- r1 r2 )
```

```factor
3 4 [ sq ] bi@ .s
! => 9
! => 16
```

## `bi*`：对 2 个值做不同的操作

`bi*`（位于[`kernel`][kernel]）会把*不同的*引用作用在这 2 个栈值上：第 1 个引用作用于下面那个值，第 2 个作用于栈顶：

```
bi* ( x y q1 q2 -- r1 r2 )
```

```factor
3 4 [ sq ] [ neg ] bi* .s
! => 9
! => -4
```

需要同样处理时用`bi@`，各自需要不同处理时用`bi*`。

## `tri*`：对 3 个值做不同的操作

`tri*`（位于[`combinators`][combinators]）把`bi*`扩展到 3 个值和 3 个引用，按顺序把每个引用作用在 1 个值上：

```
tri* ( x y z q1 q2 q3 -- r1 r2 r3 )
```

```factor
1 2 3 [ sq ] [ neg ] [ 10 * ] tri* .s
! => 1
! => -2
! => 30
```
