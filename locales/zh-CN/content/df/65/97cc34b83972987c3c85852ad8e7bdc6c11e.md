# 说明补充

## WebAssembly 专用说明

WebAssembly 导出函数`convert`的签名如下：

```wasm
(func (export "convert")
    (param $arrOffset i32)
    (param $arrLength i32)
    (param $inputBase i32)
    (param $outputBase i32)
    (result i32 i32 i32)
)
```

前两个参数`$arrOffset`和`$arrLength`表示一个 32 位有符号整数数组的起始偏移量和长度。长度参数以数组中的元素个数为单位，而不是字节数。在调用这个函数之前，调用方要把这个数组写入 WebAssembly 线性内存中，起始位置为偏移量`$arrOffset`。WebAssembly 线性内存始终采用小端序表示。

因此，调用方会把数组`[1,2]`编码成下面这 8 个字节的序列。

```
| 64 | 65 | 66 | 67 | 68 | 69 | 70 | 71 |
| ---- arr[0] ----- | ---- arr[1] ----- |
,0x01,0x00,0x00,0x00,0x02,0x00,0x00,0x00,
```

参数`$inputBase`和`$outputBase`与线性内存无关。

结果类型是`(i32 i32 i32)`。前两个值是你的输出在线性内存中的`offset`和`length`。如果你愿意，可以覆盖用于输入的线性内存地址。第三个返回值是一个用于错误处理的 i32 状态码。

如果第三个返回值表示错误状态，单元测试不会读取前两个返回值。
