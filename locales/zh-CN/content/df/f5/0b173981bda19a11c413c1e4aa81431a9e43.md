# 简介

## 数字

Python 中的内置数字类型有三种：`ints`、`floats` 和 `complex`。不过在本练习中，你只会用到 `ints` 和 `floats`。

### ints

`ints` 是整数，例如 `1234`、`-10`、`20201278`。

Python 中的整数具有[任意精度][arbitrary-precision]，位数只受宿主系统可用内存的限制。

### floats

`floats` 是带小数点的数字，例如 `0.0`、`3.14`、`-9.01`。

浮点数在 Python 中通常用 C 里的 `double` 实现（精度为 15 位小数），但其表示方式会因宿主系统和其他实现细节而有所不同。这在使用浮点数时可能带来一些意外，但对大多数场景来说已经“足够好”了。

## 算术运算

Python 完全支持 `ints` 和 `floats` 之间的算术运算。在使用二元算术运算符（`+`、`-`、`*`、`/`、`//` 和 `%`）时，它会把范围较窄的数字转换成与之对应的较宽类型。

Python 认为 `ints` 比 `floats` 窄。因此，在表达式中使用浮点数，结果也一定是浮点数。不过在做除法时，即使只涉及整数，结果也始终是浮点数。

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

如果需要得到整数结果，可以用 `//` 截断结果。

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

要把浮点数转换成整数，可以用 `int()`；要把整数转换成浮点数，可以用 `float()`。

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
