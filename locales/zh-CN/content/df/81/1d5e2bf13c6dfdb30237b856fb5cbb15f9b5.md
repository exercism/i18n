# 关于

Common Lisp 的 Printer 是向流输出数据的机制。这个机制中最常用的函数之一是`format`。

`format`接受两个必需的形参：一个是要写入的流，另一个是控制字符串。控制字符串的内容决定后续的实参如何使用。

第一个形参有两个特殊值：`t`和`nil`。`t`表示应使用绑定到`*standard-output*`的流，`nil`表示应创建一个字符串并将其返回。除非该流形参为`nil`，否则`format`的求值结果为`nil`。

控制字符串可以包含格式指令，格式指令通过一个`~`后面跟一个字符来表示（该字符不区分大小写）。格式指令会指明是否会消耗实参，以及这些实参以何种方式格式化到流中。

几个重要的基本格式指令如下：

* `~A`：以“人类可读”的方式_美观_地格式化。
* `~S`：以“机器可读”的_标准_形式来格式化。
* `~%`：输出一个换行
* `~&`：输出一个换行，除非已经位于行首。
* `~~`：输出一个波浪号。

示例：

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
