# 简介

在 Elm 中，字符和字符串是文本表示的基础。
可以把字符串看成由字符组成的数组，`List`中的大多数函数在`String`模块里都有对应版本。

## 字符

`Char`类型表示单个 Unicode 字符，用单引号括起来，例如`'a'`。
`Char`模块提供了一些谓词函数（`Char -> Bool`），用来判断字符的性质：`isUpper`、`isLower`、`isAlpha`和`isAlphaNum`。
该模块还提供了一些用于转换字符的函数：`toUpper`、`toLower`、`toLocaleUpper`和`toLocaleLower`，以及借助`toCode`和`fromCode`在字符与它的 Unicode 数值（`Int`）之间来回转换。

## 字符串

`String`类型为高效的字符串操作提供了内置表示，可以表示任意 Unicode 字符序列。
字符串用双引号表示：`"this is a string"`。
多行字符串用三个双引号表示，其中的引号和换行符无需转义。

```elm 
haiku = 
"""
    Code's strings entwine
    , In binary, thoughts combine
    , Logic's elegant line.
"""
```

## 字符串操作

`reverse : String -> String`反转字符串。
```elm 
reverse "Hello world." 
    --> ".dlrow olleH"
```

`repeat : Int -> String -> String`把字符串重复 n 次。
```elm 
repeat 2 "Hello world." 
    --> "Hello world.Hello world."
```

`replace : String -> String -> String -> String`把给定子串的所有出现全部替换掉。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`append : String -> String -> String`把两个字符串拼接起来。
也可以用`++`运算符来完成。
```elm
append "butter" "fly" 
    --> "butterfly"
"butter" ++ "fly" 
    --> "butterfly"
```

`concat : List String -> String`把一个字符串数组拼接成单个字符串。
```elm
concat ["never", "the", "less"] 
    --> "nevertheless"
```

`split : String -> String -> List String`按给定的分隔符把字符串拆分成字符串数组。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`用给定的分隔符把一个字符串数组拼接起来。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```

`words : String -> List String`按空白字符块把字符串拆分成字符串数组。
```elm
words "How are \t you? \n Good?" 
    --> ["How", "are", "you?", "Good?"]
```

`lines : String -> List String`按换行符把字符串拆分成若干行。
```elm
lines "How are you?\nGood?" 
    --> ["How are you?", "Good?"]
```

`cons : Char -> String -> String`在字符串的开头添加一个字符。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`uncons : String -> Maybe ( Char, String )`把非空字符串拆分成头部和尾部。
这样就能像对数组一样对字符串进行模式匹配。
空字符串返回`Nothing`。
```elm
uncons "abc" 
    --> Just ('a', "bc")
uncons ""
    --> Nothing
```

## 获取子串

`slice : Int -> Int -> String -> String`根据给定的起始下标和结束下标取出子串。
负下标从数组末尾开始计数。
```elm
slice 0 6 "snakes on a plane!" 
    --> "snakes"
slice 0 -7 "snakes on a plane!"
    --> "snakes on a"
```

`left : Int -> String -> String`和`right : Int -> String -> String`分别从字符串的左侧或右侧取 n 个字符。

```elm
left 2 "Mulder" 
    --> "Mu"
right 2 "Scully" 
    --> "ly"
```

`dropLeft : Int -> String -> String`和`dropRight : Int -> String -> String`分别从字符串的左侧或右侧去掉 n 个字符。
```elm
dropRight 6 "Hello world." 
    --> "Hello"
dropLeft 6 "Hello world." 
    --> "world"
```

## 检查字符串的性质

`length : String -> Int`返回字符串中字符的数量。
```elm 
length "Hello world." 
    --> 12
```

`isEmpty : String -> Bool`判断字符串是否为空。
```elm 
isEmpty "Hello world." 
    --> False
```

`contains : String -> String -> Bool`检查第二个字符串是否包含第一个字符串。
```elm
contains "the" "theory" 
    --> True
contains "THE" "theory" 
    --> False
```

`startsWith : String -> String -> Bool`和`endsWith : String -> String -> Bool`检查第二个字符串是否以给定子串开头或结尾。
```elm
startsWith "the" "theory" 
    --> True
endsWith "ory" "theory" 
    --> True
```

`indexes : String -> String -> List Int`返回子串在另一个字符串中所有出现的起始下标组成的数组。
```elm
indexes "ss" "Mississippi"  
    --> [2, 5]
```

## 字符串转换
`toInt : String -> Maybe Int`尝试把字符串转换成`Just Int`，对于格式不正确的字符串返回`Nothing`。
```elm
toInt "-42" 
    --> Just -42
toInt "3.1" 
    --> Nothing
toInt "two" 
    --> Nothing
```

`fromInt : Int -> String`把整数转换成字符串。
```elm
fromInt -42 
    --> "-42"
```

`toFloat : String -> Maybe Float`尝试把字符串转换成浮点数，格式不正确时失败。
```elm
toFloat "-42" 
    --> Just -42.0
toFloat "3.1" 
    --> Just 3.1
toFloat "two" 
    --> Nothing
```

`fromFloat : Float -> String`把浮点数转换成字符串。
```elm
fromFloat 3.9 
    --> "3.9"
```

`toList : String -> List Char`和`fromList : List Char -> String`分别把字符串转换成字符数组，以及把字符数组转换成字符串。
```elm 
toList "abc" 
    --> ['a', 'b', 'c']
fromList ['a', 'b', 'c'] 
    --> "abc"
```

`fromChar : Char -> String`把字符转换成字符串。
```elm
fromChar 'a' 
    --> "a"
```

## 格式化字符串

`toUpper : String -> String`和`toLower : String -> String`分别把字符串全部转换成大写或小写。
这在不区分大小写的比较中很有用。
```elm
toUpper "skinner" 
    --> "SKINNER"
toLower "X-FILES" 
    --> "x-files"
```

`pad : Int -> Char -> String -> String`用给定的`Char`在字符串两侧填充，直到达到指定长度。
```elm
pad 5 ' ' "11"  
    --> "  11 "
```
类似地，`padLeft`和`padRight`在字符串的某一侧填充，直到达到指定长度。

`trim : String -> String`去掉字符串两侧的空白字符。
```elm
trim "  hats  \n" 
    --> "hats"
```
`trimLeft`和`trimRight`去掉字符串某一侧的空白字符。

## 高阶函数

`map : (Char -> Char) -> String -> String`用给定的函数转换字符串中的每个字符。
注意，提供的函数必须是从`Char`到`Char`的映射。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```

`filter : (Char -> Bool) -> String -> String`只保留通过测试的字符。
```elm
filter isDigit "R2-D2" 
    --> "22"
```

`foldl : (Char -> b -> b) -> b -> String -> b`从左侧开始对字符串进行归约。
调用该函数时，第一个参数是当前字符，第二个参数是提供的初始值。
函数的结果必须与提供的初始值类型相同，并且会依次应用到每个字符上。
```elm
foldl (\c acc -> Char.toCode c + acc) 0 "the sum of my unicode is " 
    --> 2260
```
`foldr`的作用相同，只是从字符串的右侧开始。

`any : (Char -> Bool) -> String -> Bool`判断是否有任意一个字符对给定的谓词返回`True`。
```elm
any isDigit "R2-D2" 
    --> True
any isDigit "heart" 
    --> False
```
`all : (Char -> Bool) -> String -> Bool`判断字符串中的所有字符是否都对给定的谓词返回`True`。
```elm
all isDigit "R2-D2" 
    --> False
all isAlpha "heart" 
    --> True
```
