# 说明

你是一名老师。
到了年底，你为每位学生打出了一个数字成绩。
现在你需要把它转换成字母等级，并统计有多少学生拿到了各个字母等级

## 1. 把数字成绩转换成字母等级

`letter_grade`函数接收一个数字成绩作为输入，输出对应的字母。
使用以下范围：

| 字母 |      成绩 |
| :----: | ---------: |
|   A    | 90% - 100% |
|   B    |  80% - 89% |
|   C    |  70% - 79% |
|   D    |  60% - 69% |
|   F    |   0% - 59% |

示例：

```jq
75 | letter_grade   # => "C"
```

## 2. 统计每个字母等级的学生人数

`count_letter_grades`函数接收一个对象，把学生姓名映射到他们的成绩。
输出是一个对象，把每个字母等级映射到拿到该等级的学生人数。

示例：

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

这道题有几种不同的解法。
为了练习，请使用`reduce`过滤器。
