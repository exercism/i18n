# 说明附录

## 输出格式

将蛋白质序列输出为以 null 结尾的字符串，每个蛋白质后面都跟一个换行符。

一个示例输出是 `"Methionine\nPhenylalanine\nSerine\n"`

如果输入无效，输出一个空字符串。

## 寄存器

| 寄存器 | 用途        | 类型    | 描述                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的输入字符串  |
| `$a1`    | 输入/输出 | 地址 | 以 null 结尾的输出字符串 |
| `$t0-9`  | 临时    | 任意 | 用于临时存储    |
