# 抽象类

马戏演出就是一串节目。抛接、空中飞人和翻滚是各不相同的东西，内部构造也不一样，但负责编排演出顺序的人只需要从每个节目那里知道两件事：它叫什么，以及它要演多久。

一个**抽象类**描述的就只有这些，不多也不少。

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

它的名字以 `$` 开头。它列出没有方法体的例程：只有签名，每个签名以分号结尾。它无法被用来创建任何东西：既没有 `create`，也没有 `new`。

## 遵从

一个真实的类在 `<` 后面写上它的名字，以此承诺自己是一个 `$ACT`：

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` 读作“是一个”。这个类必须提供抽象类列出的每一个例程，实参相同，返回类型也相同。漏掉一个会直接导致编译错误，而不是等到运行时才出问题。

类可以随意添加别的东西。`TRAPEZE` 可以保存一个其他节目都没有的高度；抽象类既不知道，也不关心。

## 使用这个类型

`$ACT` 是一种类型，所以任何东西都可以用它来声明：

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

这个数组同时保存着三个不同类的对象，而 `ARRAY{JUGGLING}` 做不到这一点。

## 分派

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` 是一个 `$ACT`。运行到这一行时，由对象实际是什么来决定运行哪一个 `minutes`：抛接节目运行 `JUGGLING::minutes`，空中飞人运行 `TRAPEZE::minutes`。这种选择就叫**分派**。

负责相加的那段例程从不过问自己拿到的是哪种节目。要加入第四种节目，只需写一个新类，其他什么都不用改，这正是要这样做的全部理由。
