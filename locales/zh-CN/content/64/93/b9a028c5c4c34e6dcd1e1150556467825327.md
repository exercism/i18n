# 遗留文件

```exercism/note
如果你在开始使用 v3 之后，在 Elixir 或 Elm 上看到了这个提示，那很可能是因为这些学习路径改变了它们的文件结构。
如何处理这种变化，请看本文档底部的几节。
```

## 什么是遗留文件？

如果你在使用 Exercism 的在线编辑器，有时可能会看到关于遗留文件的警告。
出现这种情况有两种原因。

### 通过 CLI 错误上传的文件

使用 CLI 时，你可以上传任意你选的文件。
但在线编辑器只允许你编辑它认识的文件。
所以，如果你上传了一个编辑器不认识的文件，它就不会让你编辑，还会显示一条警告，方便你把它删掉。

### 因练习变化而产生的文件

有时候，练习的结构会发生变化。
文件可能被重命名，甚至整个练习的结构都可能改变。
我们尽量避这种情况，但有时从实际角度出发，这么做才是对的。
比如，某个学习路径可能会更换构建系统，Elixir 就是从`exs`文件迁移到了`ex`文件。
又或者，某种语言惯用的目录结构会发生变化，Elm 就把所有内容都移到了子目录里。

这种情况下，我们没法替你自动移动文件，所以需要你手动处理一下。
编辑器里会显示旧的提交的解答文件（带有遗留文件标记），以及新提交的解答文件的存根。
把旧文件里的代码复制到新文件里，再调整需要改动的地方。
等测试通过以后，你就可以删掉旧的提交的解答文件，然后当这一切都没发生过 🙂

## 删除遗留文件

删除遗留文件**不会**影响之前的迭代。
那个文件在这些迭代里依然存在。
删除文件只是把它从你**下一次**通过编辑器提交的迭代中移除。

## 学习路径结构的变化

### Elixir

2019 年 7 月，Elixir 把练习结构从使用 Elixir 脚本（`*.exs`文件）改成了每个练习都是一个完整的 [Mix 项目](https://elixir-lang.org/getting-started/mix-otp/introduction-to-mix.html)。
要使用 v3 的功能，请把你的提交的解答复制到位于`lib/<exercise_stub>.ex`的存根文件里。
你不需要移动测试文件，更新后的版本已经放在正确的位置了。

### Elm

在 v3 发布时，Elm 修改了它的练习。
