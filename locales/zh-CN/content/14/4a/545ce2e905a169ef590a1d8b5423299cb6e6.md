# 关于

字符串用于表示文本数据。
在 Swift 中，[`String`][strings-and-characters] 是 `Character` 值的有序集合，其中每个字符都代表一个 Unicode 字符。

可以使用字符串字面量创建字符串，它是由双引号（`"`）包围的字符序列。
对于多行字符串，使用三个双引号（`"""`）：

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift 字符串与 Foundation 框架的 [`NSString`][nsstring-docs] 类无缝衔接，可以访问丰富的文本处理能力。

## 字符

一个 `Character` 表示一个扩展字形簇，即由一到多个 [Unicode 标量值][unicode-scalar-values] 组成的人类可读字符。
Unicode 标量值是一个 21 位的码点，范围从 `U+0000` 到 `U+D7FF`（含），或从 `U+E000` 到 `U+10FFFF`（含）。

```swift
let aChar: Character = "A"
```

## 类型推断

写下字符串字面量时，Swift 会自动推断其类型为 `String`。
若要把单个字符存储为 `Character`，必须显式标注类型：

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## 拼接

可以用加法运算符（`+`）把字符串连接起来：

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

如果不先把字符转换成字符串，就无法直接用 `+` 把 `Character` 拼接到 `String` 上。
不过，可以使用 [`append(_:)`][append] 方法，把字符串或字符直接追加到可变字符串上：

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## 字符串插值

[字符串插值][string-interpolation] 让你可以在字符串字面量中嵌入常量、变量、字面量和表达式，从而构造出字符串。
把每个表达式放到以反斜杠开头的括号中（`\(` ... `)`）：

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## 字符串和字符的属性

字符串和字符提供了若干属性，用来查看它们的内容。

### 字符串属性

常用的字符串属性包括：

| 属性      | 说明                                           | 示例                                   |
| --------- | ---------------------------------------------- | -------------------------------------- |
| `isEmpty` | 如果字符串没有字符，则返回 `true`              | `"Hello".isEmpty` 的求值结果为 `false` |
| `count`   | 返回字符串中字符的数量                         | `"Hello".count` 的求值结果为 `5`       |

完整的属性列表请参阅 [Apple 的 String 文档][string-docs]。

### 字符属性

常用的字符属性包括：

| 属性           | 说明                                       | 示例                                       |
| -------------- | ------------------------------------------ | ------------------------------------------ |
| `isLowercase`  | 如果字符是小写，则返回 `true`              | `"a".isLowercase` 的求值结果为 `true`      |
| `isUppercase`  | 如果字符是大写，则返回 `true`              | `"A".isUppercase` 的求值结果为 `true`      |
| `isNumber`     | 如果字符是数字，则返回 `true`              | `"1".isNumber` 的求值结果为 `true`         |
| `isWhitespace` | 如果字符是空白字符，则返回 `true`          | `" ".isWhitespace` 的求值结果为 `true`     |

完整的属性列表请参阅 [Apple 的 Character 文档][character-docs]。

## 类型转换

可以使用 `String(_:)` 初始化器把其他类型转换成字符串，它支持 `Int`、`Double`、`Character` 等标准类型：

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## 特殊字符

Swift 字符串字面量支持若干用于特殊字符的[转义序列][special-characters]：

| 序列    | 说明                        |
| ------- | --------------------------- |
| `\0`    | 空字符                      |
| `\\`    | 反斜杠                      |
| `\t`    | 水平制表符                  |
| `\n`    | 换行符                      |
| `\r`    | 回车符                      |
| `\'`    | 单引号                      |
| `\"`    | 双引号                      |
| `\u{n}` | 任意 Unicode 标量（十六进制） |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
