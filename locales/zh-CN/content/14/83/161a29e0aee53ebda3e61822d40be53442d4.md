# 简介

`MACRO:`声明与`:`类似，但它的主体在*编译时*运行，并且必须返回一个 quotation。编译器会用返回的 quotation 替换宏调用。因为主体是普通的 Factor 代码，所以构建结果 quotation 不过是在操作 word 序列。

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

宏的输入是*调用点处的字面量*。传入非字面量值，编译器就会拒绝特化，因为宏主体需要在编译时而不是运行时获得该值。

与之密切相关的是`<< … >>`解析时求值块，它会在编译时运行任意 Factor 代码，而不需要返回 quotation 的约定。两者都属于 Factor 的[`macros`][macros]机制。

[macros]: https://docs.factorcode.org/content/vocab-macros.html
