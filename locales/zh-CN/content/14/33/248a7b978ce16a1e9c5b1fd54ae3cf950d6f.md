# 安装

本 track 使用 ReScript 12，并要求 [Node.js][nodejs] 22 或更高版本。
很多系统已经预装了它，或者你可能在学其他 track 时已经装过。

打开终端，运行：

```sh
node -v
```

如果没有安装 Node，或者显示的版本较旧，请按照适合你平台的 [Node.js 官方安装][nodejs-install]说明操作。

## 安装依赖

每个 ReScript 练习都是一个独立的 npm 项目。
用 [Exercism CLI][exercism-cli] 下载练习后，安装项目依赖（其中包含 ReScript），就可以开始了：

```sh
cd /path/to/exercise
npm install
```

## 编辑器支持
