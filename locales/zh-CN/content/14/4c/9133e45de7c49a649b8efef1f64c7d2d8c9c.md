# 说明

根据尼科马库斯（公元 60 - 120 年）为正整数制定的分类体系，判断一个数属于 perfect、abundant 还是 deficient。

希腊数学家[尼科马库斯](https://en.wikipedia.org/wiki/Nicomachus)为正整数设计了一套分类体系，根据每个数的[真因数和](https://en.wikipedia.org/wiki/Aliquot_sum)，把每个正整数唯一地归入 **perfect**、**abundant** 或 **deficient** 这三类。真因数和是指一个数的所有因数（不包括这个数本身）之和。例如，15 的真因数和是 (1 + 3 + 5) = 9。

- **Perfect**：真因数和 = 该数本身
  - 6 属于 perfect 类，因为 (1 + 2 + 3) = 6
  - 28 属于 perfect 类，因为 (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**：真因数和 > 该数
  - 12 属于 abundant 类，因为 (1 + 2 + 3 + 4 + 6) = 16
  - 24 属于 abundant 类，因为 (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**：真因数和 < 该数
  - 8 属于 deficient 类，因为 (1 + 2 + 4) = 7
  - 质数都属于 deficient 类

实现一个方法，判断给定的数是否为 **perfect**。视你所使用的编程语言而定，你可能还需要实现判断给定的数是否为 **abundant** 或 **deficient** 的方法。
