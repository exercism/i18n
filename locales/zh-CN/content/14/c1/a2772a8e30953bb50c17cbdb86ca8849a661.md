# 说明

伊兹是一位热心的观鸟爱好者，她会记录每天有多少只鸟来到她的花园。

她请你帮忙把她的观鸟爱好提升到一个新水平，并实现几个工具，帮她跟踪和处理这些数据。

你选择把数据存成一个整数数组。数组中的第一个数字是今天来到你花园的鸟的数量，第二个是昨天的，以此类推。

## 1. 检查今天有多少只鸟来访

实现 `today` 函数。它接收一个每日鸟数量的数组，并返回今天的数量。如果数组为空，应该返回 `0`。

```gleam
today([2, 5, 1])
// -> 2
```

## 2. 增加今天的数量

实现 `increment_day_count` 函数。它接收一个每日鸟数量的数组，并把今天的数量加 1。如果数组为空，返回 `[1]`。

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. 检查是否存在没有鸟来访的日子

实现 `has_day_without_birds` 函数。它接收一个每日鸟数量的数组。如果至少有一天没有鸟来花园，它应该返回 `True`，否则返回 `False`。如果数组为空，这算作_还_没有记录到任何鸟，返回 `False`。

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. 计算来访鸟的总数

实现 `total` 函数。它接收一个每日鸟数量的数组，并返回自你开始收集数据以来到访你花园的鸟的总数。

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. 计算忙碌的天数

有些日子比其他日子更忙。忙碌的一天是指有 5 只或更多鸟来访你花园的一天。

实现 `busy_days` 函数。它接收一个每日鸟数量的数组，并返回忙碌的天数。

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
