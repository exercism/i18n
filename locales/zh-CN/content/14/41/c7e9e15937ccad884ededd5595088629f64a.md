# 说明

密码轮由两个圆盘组成，一个套在另一个里面，可以让字母表转圈：把它调到 3，每个字母就变成往后数三位的那个字母，`z` 则会绕回到 `a`。侦探们用它已经有好几百年了。现在，你要亲手做一个。

五个任务都写在 `CIPHER_WHEEL` 类里。

## 1. 它是字母吗？

```sather
CIPHER_WHEEL::is_letter('m')
-- => true
CIPHER_WHEEL::is_letter('7')
-- => false
```

## 2. 喊出来

返回字符的大写形式。不是字母的字符原样返回。

```sather
CIPHER_WHEEL::shout('m')
-- => 'M'
```

## 3. 它是哪个数字？

返回代表某个字符的数字。

```sather
CIPHER_WHEEL::code('a')
-- => 97
```

## 4. 第一个字符

返回字符串的第一个字符。

```sather
CIPHER_WHEEL::first_character("Marlowe")
-- => 'M'
```

## 5. 转动轮盘

给定一个小写字母和要移动的位数，返回字母表中往后数那么多位的字母。越过 `z` 后会绕回到 `a`。

```sather
CIPHER_WHEEL::turn('a', 3)
-- => 'd'
CIPHER_WHEEL::turn('z', 1)
-- => 'a'
```

往回转也可以，只要位数是负数。

```sather
CIPHER_WHEEL::turn('a', -1)
-- => 'z'
```

你可以假设传入的字符是小写字母。
