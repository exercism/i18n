# 介绍

在 Haxe 中，`class`是最主要的数据结构，它把数据（字段）和行为（方法）封装在一起。字段和方法也叫做类的成员。

可以使用访问修饰符来限制对成员的访问，访问修饰符有以下几种：

- `public`：成员可以从任何地方访问。
- `private`：成员只能被同一个类访问。

可以把类看作创建实例的模板。要创建一个实例，只需使用`new`关键字：

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

要定义一个字段，请使用访问修饰符，后面跟上变量名和类型：

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

定义字段时还可以设置初始值。如果字段没有指定初始值，它就会取值为`null`。可以使用点号表示法访问字段：

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
