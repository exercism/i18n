# 燃油补贴

## 问题陈述

ABC 公司的每位员工都享有不限量的燃油补贴。员工每次给车加油后都需要提交一条记录。这些记录会被追加到同一个 CSV 文件里，并在月末统一处理。

作为数字运营团队的一员，你的任务是读取这个 CSV 文件，并把结果写入另一个 CSV 文件。输出文件应为每位员工包含一条记录，包含以下信息：

- 员工编号
- 加油次数
- 燃油总费用
- 总加仑数
- 累计总里程

你会收到两个 `string` 参数。

1. 输入 CSV 文件的路径
1. 输出 CSV 文件的路径

输入 CSV 文件有 `n` 行，每行的格式如下。

| 列名      | Ballerina 类型 |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

输出文件应为每位员工包含一条记录，并按 `employee_id` 升序排列。每行的格式如下：

| 列名      | Ballerina 类型 |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## 约束条件

- 输入 CSV 文件的行数 `n`：2 <= n <= 1000
- 公司员工人数：97
- 油价为每加仑的价格
- 没有缺失的加油记录

## 示例 1

- 输入：`example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- 输出：`example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```

## 提示

- 使用 [`ballerina/io` 模块](https://lib.ballerina.io/ballerina/io/latest)读写 csv 文件
- 输入和输出文件不会/不应包含表头
