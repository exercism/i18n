# 说明

Elyse 是一位准魔术师，她还在继续自己的训练。她会拿到好几叠牌，用来表演她的魔术。
为了让事情简单一些，她只用数字 1 到 10 的牌。

在这个练习中，请使用内置方法来分析向量的内容。

## 1. 判断某张牌是否在牌堆中

Elyse 想判断某张牌是否在牌堆中，换句话说，就是牌堆里是否包含某个特定的数字。

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. 找出某张牌的位置

Elyse 想知道某张牌在牌堆中的位置（下标）。
如果这张牌不在牌堆中，就返回 `-1`。

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. 判断每张牌是否都是偶数

Elyse 想知道每张牌是否都是偶数，换句话说，就是牌堆中的每个数字是否都是偶数。

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. 检查牌堆中是否有奇数牌

Elyse 想知道牌堆中是否有奇数。

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. 取出牌堆中的第一张奇数牌

Elyse 想知道第一张奇数牌的值。  
如果牌堆中没有奇数牌，就返回 `-1`。

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. 判断第一张偶数牌的位置

Elyse 想知道第一张偶数牌的位置。
如果牌堆中没有偶数牌，就返回 `-1`。

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
