# Instructions

你是一位热衷于观鸟的人，会记录过去 7 天里有多少只鸟来到你的花园。

你有 6 个任务，全都围绕来到你花园的鸟的数量展开。

## 1. 查看今天有多少只鸟来访

实现`today()`函数，返回今天有多少只鸟来到你的花园。鸟的数量按天排列，第一个元素是最早那天的数量，最后一个元素是今天的数量。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. 增加今天的数量

实现`increment_todays_count()`函数，把今天的数量加一：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. 检查是否有某天没有鸟来访

实现`has_day_without_birds()`函数，如果存在某一天到花园来访的鸟为零，则返回`TRUE`；否则返回`FALSE`：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. 计算开头若干天来访鸟的数量

实现`count_for_first_days()`函数，返回从这周开始起有多少只鸟来到你的花园，但把统计范围限制为从这周开始起的指定天数。

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. 计算繁忙日子的数量

有些日子比其他日子更忙。繁忙的一天，是指有 5 只或更多鸟来到你的花园的日子。
实现`busy_days()`函数，返回繁忙日子的数量：

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. 计算过去一周鸟来访次数的累计总数

你很好奇这周到目前为止一共有多少只鸟来访。
计算每一天的累计总数。

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. 按繁忙程度对星期名称排序

你怀疑鸟的来访受到附近道路交通规律的影响，所以周末和工作日会有所不同。

按照来访鸟的数量，对星期缩写进行_降序_排序。

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
