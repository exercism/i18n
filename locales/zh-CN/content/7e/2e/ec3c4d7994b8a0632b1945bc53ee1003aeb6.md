# for-each 循环简介

[for-each 循环](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)提供了一种机制，可以对集合中的每个元素执行一段代码块。
有些文档（例如 Oracle 的文档）把这种循环称为增强 for 循环。

以下是通用语法：

```java
for(declaration: collection) {
    body;
}
```

`declaration` 声明一个变量，用来保存从集合中赋给它的值。

`collection` 是一个数组或集合，其中保存着将要赋给循环变量的值。

`body` 包含一些语句，集合中的每个值都会让它们执行一次。

例如：

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

输出结果为：

```text
a
e
i
o
u
```

一般来说，`for-each` 循环比 `for` 循环更可取，原因如下：

- `for-each` 循环保证会遍历 _所有_ 值。
- `for-each` 循环更具_声明式_风格，也就是说，代码表达的是它_在做什么_，而不是_怎么做_。
- `for-each` 循环不易出错，而使用 `for` 循环则很容易出现差一错误（想想用`<`还是`<=`）。
- `for-each` 循环适用于所有集合类型，包括不支持用下标访问元素的类型（例如 `Set`）。
