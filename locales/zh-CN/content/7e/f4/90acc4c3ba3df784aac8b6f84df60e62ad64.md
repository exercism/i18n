# 关于

GDScript 是一门渐进类型、面向对象、命令式的脚本语言，专为[Godot 引擎][godot-engine]而创建（并且一般只与它搭配使用）。Godot 引擎是一款开源的 2D 和 3D 游戏引擎兼 IDE。
因此，它围绕 Godot 基于场景的架构做了大量优化，并原生支持诸如此类的数据类型。

由于 GDScript 与许多流行语言有不少相似之处（比如它的语法就与 Python 相似），学习 GDScript 是一个有趣的入口，既能走进 Godot 游戏编程，也能帮你学习其他编程语言。
如果你已经对 Godot 感兴趣，却还不确定该学它支持的哪门语言，不妨读一读[什么是 GDScript，我为什么要用它？][why-use-gdscript]。

如果你好奇 Godot 为什么要创造一门自己的语言，可以在[创造 GDScript 背后的动机是什么？][why-create-gdscript]中读到更多内容。
