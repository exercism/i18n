# 说明

你是码头上负责重新堆装货箱的甲板水手。每个任务都是一个单独的
词，它的定义体只用重排词，不做任何算术。

## 1. 交换最上面两个货箱

定义 `swap-crates` 词。它从栈上取走两个货箱，再以相反的顺序把它们留在栈上。

```factor
1 2 swap-crates .s
! 2
! 1
```

## 2. 清掉洒出来的货箱

定义 `clear-spill` 词。它从栈上取走三个货箱，把下面两个留下，丢弃最上面那个。

```factor
1 2 3 clear-spill .s
! 1
! 2
```

## 3. 保留下面货箱的一份副本

定义 `peek-under` 词。它从栈上取走两个货箱，把它们留在栈上，并在最上面放一份下面那个货箱的副本。

```factor
1 2 peek-under .s
! 1
! 2
! 1
```

## 4. 整理甲板

定义 `tidy-deck` 词。它从栈上取走三个货箱（顺序为 `x y z`），然后留下 `z z y`：丢弃最下面的货箱，再让最上面货箱的两份副本位于中间那个货箱的下方。

```factor
1 2 3 tidy-deck .s
! 3
! 3
! 2
```
