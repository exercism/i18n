# 简介

Ruby 自带一个标准库（通常简称为“stdlib”），其中包含一组用于处理日期、json、网络等内容的类。
它还提供了一些实用的功能，让你的代码更易于使用。

`OpenStruct`是标准库的一部分，可以让你轻松地根据`Hash`创建对象。
不用通过`Hash`的键来访问，`OpenStruct`允许我们用方法来访问和设置值。

使用标准库或任何其他库中的类时，需要用`require`方法引入该类。

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

这样还有一个额外的好处：使用块语法时，你可以用上一个简写。
当块只调用一个方法时，你可以用`&:`加上方法名来代替这个块。
例如，下面两行是等价的：

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
