# 三元运算符

三元运算符是编写简单`if/else`语句的一种更简短的方式。如果`if/else`语句只包含两个分支，一个在条件为 true 时执行，另一个在条件为 false 时执行，那么它就可以改写成三元运算符。

三元运算符使用`?`和`:`符号的组合来拆分条件：
```ruby
condition ? true_branch : false_branch
```

`?`左侧的代码是条件，右侧的代码包含两个可能的分支，二者用`:`分隔。
如果条件为 _true_，就执行`:`_左边_的代码。
如果条件为 _false_，则执行`:`_右边_的代码。

例如：

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

可以改写成：

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
