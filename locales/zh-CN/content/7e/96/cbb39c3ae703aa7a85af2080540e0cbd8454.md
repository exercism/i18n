# 简介

## 数组和向量

C++ 提供了多种容器，可以按顺序存储相同类型的元素。
固定大小的容器可以使用`std::array`，而`std::vector`支持动态调整大小。

### 构造

声明数组或向量时，你需要指定容器将要存储的元素类型。
数组还需要指定大小。
下面这两个例子展示了这两种容器的初始化方式：

```cpp
#include <array>
#include <string>

// std::array<element_type, size> variable_name {list of elements}
std::array<std::string, 3> indie_rock {"yeah", "yeah", "yeah"};
// indie_rock contains the elements "yeah" three times
```

向量通常需要更多空间，因为它们会为后续的增长分配内存。
你不需要指定大小：

```cpp
#include <vector>

// std::vector<element_type> variable_name {list of elements}
std::vector<int> countdown {3, 2, 1};
// countdown contains the elements 3, 2 and 1
```

> 注意：你现在还不需要了解模板这一概念背后的具体机制，在教学大纲中更靠后的位置，它会拥有自己的概念。

### 元素访问

向量和数组使用相同的函数来访问元素。
你可以使用成员函数`front`和`back`来获取容器的第一个和最后一个元素。
此外还有`at`和`[]`运算符，用于访问特定的元素。

```cpp
countdown[0];
// => 3
countdown.at(2);
// => 1
countdown[1] = 4;
// countdown now contains 3, 4 and 1
indie_rock.back() = "yeahs";
// indie_rock is now "yeah", "yeah", "yeahs"
```

> 注意：如果你选的位置不在容器的范围内，`[]`可能会导致未定义行为。
> `at`函数则会抛出异常，从长远来看，这可能会让你的日子更好过一些。

### 向量修改器

由于`vector`的大小并不固定，因此可以添加或删除元素。
用于此目的的两个常用函数是`emplace_back`和`pop_back`。

```cpp
std::vector<std::string> witches {"Holly", "Alyssa", "Shannen"};
witches.pop_back();
// Shannen is no longer with the witches
witches.emplace_back("Rose");
// Rose has joined the team
```

### 容量

你可以用成员函数`empty`检查容器是否为空。
如果你想知道元素的数量，可以使用`size`。
