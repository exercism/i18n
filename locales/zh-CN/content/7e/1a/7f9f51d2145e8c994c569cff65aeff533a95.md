# 学习

Exercism 提供练习和反馈，但对第一次学习 Racket 的人来说，直接上手可能并不容易。
以下资源可以帮助你入门：

* [Quick: An Introduction to Racket with Pictures](http://docs.racket-lang.org/quick/)
* [Continue: Web Applications in Racket](http://docs.racket-lang.org/continue/index.html)
* [More: Systems Programming with Racket](http://docs.racket-lang.org/more/index.html)
* [How to Design Programs](http://htdp.org/)，作者 Matthias Felleisen、Robert Bruce Findler、Matthew Flatt 和 Shiriam Krishnamurthi
* [The Little Schemer](http://mitpress.mit.edu/books/little-schemer-fourth-edition)，作者 Daniel P. Friedman 和 Matthias Felleisen
