# `jq`中的函数

你可以在`jq`中定义自己的**自定义函数**，用来封装你需要的任何逻辑。
_函数_的行为和内置函数完全一样：接收一个输入，并产生零个、一个或多个输出。

## 定义函数

你可以用下面的语法定义一个`jq`_函数_：

```jq
# no arguments
def funcname: expression;

# or with arguments
def funcname(args): expression;
```

- 以`def`关键字开头，
- 函数体之前有一个冒号，
- 函数体由单个表达式构成，
- 以分号结尾，
- 与`jq`语法的其他部分一样，你可以用任意空白字符来提高可读性。

## 函数放在哪里

_函数_必须先定义再使用，下面这样会报错：

```jq
def A: B(10);
def B(n): n + 1;
A
# => error: B/1 is not defined
```

这意味着你必须把_函数_放在`jq`代码的开头，即“主”表达式之前。

### 嵌套函数

_函数_可以嵌套：

```jq
def A:
    def B(n): n + 1;
    B(10)
    ;
A
# => 11
```

在这里，`B`这个_函数_只在`A`的函数体内可见。

## 作用域

_函数_会为变量和嵌套函数引入一个新的**作用域**。

## 实参

_函数_的**实参**之间用_分号_分隔，而不是逗号。
例如，一个_函数_接收一个数字，先加上一个数字，再乘以一个数字：

```jq
def add_mul(adder; multiplier): (. + adder) * multiplier;

10 | add_mul(5; 4)    # => 60
```

10 | add_mul(5, 4)

### 实参是_表达式_

函数的_实参_是过滤器，而不是值。
从这个意义上说，它们的作用类似其他语言所说的回调：

以`add_mul`函数为例：

```jq
10 | add_mul(. + 5; . - 2)    # => 200
```

这里发生了什么？

- `adder`实参拿到的是_表达式_`. + 5`
  - 当函数执行`. + adder`时，它就变成了`. + . + 5`
  - 由于`. == 10`，它求值为 25
- 同样，`multiplier`实参是表达式`. - 2`
  - 它求值为 8
  - 于是结果是`25 * 8 == 200`

### 实参作为值

有时你会想把_实参_“实体化”成一个变量：

```jq
def my_func(arg):
    arg as $arg
    | other stuff ...
;
```

这有一种简写形式：

```jq
def my_func($arg):
    other stuff ...
;
```

注意，这只是“语法糖”：不带`$`的名字`arg`在_函数_中仍然处于作用域内。

## 元数

_函数_有**元数**，也就是它所接收的_实参_个数。

_函数_可以在不同元数下使用相同的名字。
内置函数[`range`][man-range]就说明了这一点：`range/1`、`range/2`和`range/3`可以共存。

这对于定义通过实参携带状态的递归函数很有用。
例如，`map`_可以_这样实现：

```jq
def my_map($accumulator; func):
    if length == 0
        then $accumulator
        else first as $elem | .[1:] | my_map($accumulator + [$elem | func]; func)
    end
    ;

def my_map(func):
    my_map([]; func)
    ;

[1, 2, 3, 4] | my_map(. * 10)   # => [10, 20, 30, 40]
```

## 递归

`jq`会执行尾调用优化，但只对零元函数有效。

## 模块

`jq`模块是一个只包含函数的文件。
模块通过[`include`][man-include]或[`import`][man-import]命令引入 jq 程序。
