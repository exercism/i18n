# 说明

在本练习中，你将处理日志行。

每个日志行都是一个格式为 `"[<LEVEL>]: <MESSAGE>"` 的字符串。

日志共有三个级别：`INFO`、`WARNING` 和 `ERROR`。

你有三个任务。每个任务从栈中取出一条日志行。

## 1. 从日志行中获取消息

定义 `message`，让它返回日志行中的消息。开头和结尾的所有空白字符都应去掉。

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. 从日志行中获取日志级别

定义 `log-level`，返回日志行的级别，并转换为小写。

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. 重新格式化日志行

定义 `reformat`，把消息放在最前面，并在后面用括号加上小写的日志级别。

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***注意：*** 本练习中的所有字符串都是 ASCII。后续练习会处理支持 Unicode 的字符串。
