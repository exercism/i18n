# 测试

如果 PATH 中有 phix 可执行文件，请输入以下命令：

```bash
p test 
```
这会运行测试文件（test.exw）。

如果 PATH 中没有 phix 可执行文件，在 Windows 中请输入

```cmd
\path\to\p.exe test
```

Linux：

```bash
/path/to/p test
```

## 跳过的测试

完成一道练习，意味着让它所有的测试都通过。
默认情况下，test.exw 文件中的所有测试都会执行。
要跳过某个测试，在那一行的开头加上两个短横线（Phix 的标准注释标记）。

注意，测试并不会遵循 tests.toml 中的 include=false 标志。这些标志需要由 test.exw 的作者手动在该文件中维护，以反映实际情况，方便 Exercism 网站使用（例如收集赛道统计数据）。不过赛道本身完全不会用到它们，特别是测试生成器和测试运行器。
