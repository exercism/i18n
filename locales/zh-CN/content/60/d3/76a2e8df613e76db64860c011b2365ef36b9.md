# 说明

在本练习中，你将编写代码，帮助一位自由职业者就某些项目的价格与客户沟通。你将编写几个实用函数，用来快速计算客户的费用。

## 1. 根据时薪计算日薪

一位客户联系这位自由职业者，想询问报价。
自由职业者解释说，他们**_每天工作 8 小时。_**
不过，这位自由职业者只知道这个项目的时薪。
请帮助他们根据时薪估算出日薪。

实现函数`dailyRateFrom(hourlyRate:)`，它接收实参`hourlyRate`，其中保存着这位自由职业者的时薪。  
该函数应返回根据时薪计算出的日薪。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

返回的日薪应该是`Double`类型。

## 2. 根据时薪和折扣计算月薪

有时，客户想更长期地雇佣这位自由职业者。
自由职业者愿意给客户折扣，但前提是客户至少雇佣他们一个月。
总共有**_22 个工作日_**。
请根据时薪，以及他们愿意在标准价基础上给出的折扣百分比，帮助这位自由职业者计算月薪，并四舍五入到最接近的整数。

实现函数`monthlyRateFrom(hourlyRate:withDiscount:)`，它接收实参`hourlyRate`（保存自由职业者的时薪）和`withDiscount`（保存自由职业者愿意给客户的折扣）。
该函数应返回四舍五入到最接近整数的月薪。

```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

## 3. 根据预算、时薪和折扣计算工作日数量

又有一天，一位项目经理提出让这位自由职业者参与一个预算固定的项目。
给定固定预算和这位自由职业者的时薪，请帮助他们计算在预算用完之前可以工作多少天。
请注意，在这种情况下，无论雇佣多少天，这位自由职业者都愿意给出折扣。
结果_必须_**向下取整**到最接近的整数。

实现函数`workdaysIn(budget:hourlyRate:withDiscount:)`，它接收以下实参：
- `budget`，保存项目的预算。
- `hourlyRate`，保存自由职业者的时薪。
- `withDiscount`，保存自由职业者愿意给客户的折扣。

该函数应返回这位自由职业者在这个项目上工作的天数，向下取整。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
