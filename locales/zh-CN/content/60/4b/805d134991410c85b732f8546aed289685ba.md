# 关于

枚举就是遍历集合（`Array`、`Hash`等），并对每个对象执行某个操作的过程。

枚举是 Ruby 中的关键概念，用于排序（`sort_by`）、分组（`group_by`）、映射（`map`）、归约（`reduce`）等等。
你最常看到的枚举用法，是遍历集合的惯用写法，而不是使用循环。

下面是一个简单的枚举示例，用于打印数组中的每个单词：

```ruby
words = %w[the cat sat on the mat]
words.each do |word|
  puts word
end

# Output:
# the
# cat
# sat
# on
# the
# mat
```

在这个例子中，我们调用了`Array#each`方法，并传入一个 _代码块_，它接收一个形参（`word`）并打印它。

我们还可以链式调用可枚举方法。
例如，我们可以把`.with_index`链式接到`each`上，从而同时打印出对象的下标和它的值：

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index { |word, index| "#{index}. #{word}" }
puts list

# Output:
# 0. the
# 1. cat
# ...
# 5. mat
```

枚举`Hash`对象与枚举`Array`对象完全相同，区别在于代码块接收两个实参：键和值：

```ruby
pet_names = {cat: "bob", horse: "caris", mouse: "arya"}
words.each { |animal, name| ... }

# The two arguments should be put in brackets when chaining
words.each.with_index { |(animal, name), index| ... }
```

上面描述的方法属于[`Enumerable`模块][enumerable-module]，它被包含在`Array`、`Hash`以及其他需要具备枚举能力的类中。

[enumerable-module]: https://docs.ruby-lang.org/en/master/Enumerable.html
