# 提示

## 概述

- 这里的每个循环都由迭代器驱动，所以它们都不需要计数器变量或 `until!`。
- 答案总是存放在循环之前声明的变量里，因为在循环内部声明的任何内容都会在循环结束时消失。

## 1. 总数

- `counts.elt!` 每轮给出一个计数。
- 总数从 `0` 开始，对于没有任何天数的调查，这也会给出正确的答案。

## 2. 最好的一天

- 用一个变量保存目前为止最好的一天，初始值为 `0`。
- 每轮都比较一下，如果这一天比它更好就替换掉。`.max` 一步就能完成比较：`best := best.max(counts.elt!)`。

## 3. 忙碌的日子

- 计数而不是求和：`if counts.elt! > n then found := found + 1; end;`
- 在 `if` 条件里只向迭代器取一次值。在一个循环体里写两次 `counts.elt!` 会把数组遍历两遍。

## 4. 要检查的观鸟屋

- 这里没有遍历任何东西，所以 `elt!` 派不上用场。`1.upto!(days)` 会替你计数。
- `1.upto!(0)` 什么也不会给出，对于零天来说，这正是正确的答案。

## 5. 第一个忙碌的日子

- 答案是位置而不是值，所以遍历位置：`i ::= 0.upto!(counts.size - 1)`。
- 答案从 `-1` 开始。如果什么都没找到，这本来就是应该返回的结果。
- 一旦找到某一天，就用 `break!` 跳出循环，否则后面某个忙碌的日子会覆盖掉第一个。
