# 简介

Elm 中的[自定义类型][custom-types]代表固定数量的具名分支。每个值都恰好对应其中一个具名分支。

自定义类型使用 `type`关键字定义，需要的语法很少。它是 Elm 编程中最重要的技术之一，用来让代码中可能出现的值与现实生活中合法的值完全对应，从而不给非法数据留出空间，也让[不可能的状态无法在代码中表示][impossible-states]。

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

自定义类型的每个分支都可以附带数据，不同分支也可以附带不同类型的数据。如果所有分支都不附带数据，这种可辨识联合就类似于其他语言通常所说的_枚举_（或 _enum_）。

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

要创建某个分支的值，可以引用它的名字（`Spring`），前提是它定义在同一个模块中，或者通过 `import SeasonModule exposing (Season(..))`这种语法导入；也可以引用它的完全限定名（`Season.Spring`），前提是通过 `import SeasonModule exposing (Season)`这种语法导入。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

自定义类型和 Elm 中的一切一样，都具有_结构相等性_，也就是说，同一个分支、带有相同（可选）数据的两个值彼此等价。

处理自定义类型的首选方式是[模式匹配][pattern-matching]：

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
