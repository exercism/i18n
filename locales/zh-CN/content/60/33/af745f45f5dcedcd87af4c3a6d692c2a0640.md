# 说明

给定一段输入文本，输出它的转置。

粗略地说，矩阵的转置：

```text
ABC
DEF
```

是这样得到的：

```text
AD
BE
CF
```

行变成列，列变成行。
参见[转置][transpose]。

如果输入的各行长度不同，按下面的方式处理：

- 在左侧用空格补齐。
- 不要在右侧补齐。

因此，对下面这个矩阵做转置：

```text
ABC
DE
```

会得到：

```text
AD
BE
C
```

而对下面这个矩阵做转置：

```text
AB
DEF
```

会得到：

```text
AD
BE
 F
```

一般来说，输入中的所有字符也都应该出现在转置后的输出里。
也就是说，如果输入文本中某一列只在最底部的若干行上是空格，那么对应的输出行也应该在最右侧的若干列上保留这些空格。

[transpose]: https://en.wikipedia.org/wiki/Transpose
