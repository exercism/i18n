# 说明

你所在的消防队由来自世界各地的志愿者组成。
由于团队成员来自不同国家，在最近几次出警中，大家为了估算着火建筑内部的温度，不得不在华氏度和摄氏度之间来回换算，白白浪费了宝贵的时间。
为了节省时间，也为了救人，你决定写一个程序，为你的国际团队自动完成华氏度和摄氏度之间的换算。

## 1. 将华氏度转换为摄氏度

实现`tempToC`函数，把以`Integer`表示的华氏温度转换成等价的摄氏温度`Float`，并四舍五入到小数点后两位。
摄氏温度的定义是：T(°C) = (T(°F) - 32) / 1.8。

```haskell
> tempToC 32
0.00
```

## 2. 将摄氏度转换为华氏度

实现`tempToF`函数，把以`Float`表示的摄氏温度转换成等价的华氏温度。
出于安全考虑，请将结果**向上取整**为**大于等于它的最小**`Integer`。
华氏温度的定义是：T(°F) = T(°C) × 1.8 + 32。

```Haskell
> tempToF 4
40
```
