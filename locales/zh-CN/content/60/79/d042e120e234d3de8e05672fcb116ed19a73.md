# 提示

## 通用

- `set-nth ( elt n seq -- )`、`change-nth ( i seq quot -- )`、`push ( elt seq -- )` 和 `pop ( seq -- elt )` 都会*修改*自己的序列参数，并且不会把关于它的任何东西返回到栈上，改动本身就是效果。

## 1. 新建马赛克

- `<array>`（在 [`arrays`][arrays] 中）接受一个长度和一个填充值，返回一个新数组。

## 2. 放置一块瓷砖

- `set-nth` 负责赋值，但它期望的顺序是 `( elt n seq -- )`，而传进来的输入顺序是 `( row position colour -- )`。`kernel` 中的 `spin ( x y z -- z y x )` 能在单个词里重新排列栈上的三个值，让它们按照 `set-nth` 要求的顺序落位。

## 3. 敲掉一块瓷砖

- “把该位置设为 `f`”：形式和任务 2 一样，但你需要先把 `f` 压入栈中。

## 4. 给瓷砖重新上色

- `change-nth` 会对给定位置上的元素运行一个引用，并把结果存回原处。

## 5. 快照

- `clone`（在 [`kernel`][kernel] 中）返回一份独立的副本。

## 6. 暂存

- `push` 会把一个元素就地追加到向量末尾。

## 7. 返回

- `pop` 会移除并返回向量的最后一个元素。
