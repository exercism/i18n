# 简介

一个值一旦离开你的程序，不管是发到线路上、写进日志文件，还是经过套接字，它都必须是*文本*。在为传输打包值时，有三个 Factor 惯用法会反复出现：序列化器`unparse`、在不复制的情况下查看序列的 slice 变体，以及多输入的 cleave 组合子，后者让你能用一条短语从栈上取出多个字段。

```factor
USING: combinators kernel prettyprint sequences strings ;

123 unparse .                          ! => "123"
"NS-1024" 2 head-slice >string .       ! => "NS"
1 2 [ + ] [ - ] 2bi . .
! => -1
! => 3
```

`unparse`是 Factor 解析器的逆操作，`dup unparse parse`可以原样往返。`head-slice`返回的是一个*视图*（`slice`对象），而不是像`head`那样分配一个全新的序列。当你只是需要查看某个区域时，这一点很有用。`2bi`、`3bi`、`2tri`和`3tri`把 cleave 组合子家族扩展到了两个或三个栈输入。
