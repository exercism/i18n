# 简介

一个 [C# `Attribute`](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) 提供了一种修饰声明的方式，可以把元数据关联到类、方法、枚举、字段、属性，或者任何其他[受支持的](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets)声明上。

要把特性应用到声明上，只需把它写在声明的前一行，例如`ClassAttribute`和`FieldAttribute`：

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

这种声明式元数据只是把额外的结构化信息关联到代码上，并不会改变代码的行为。不过，代码的其他部分会利用这些元数据来改变目标的行为，或者增加、修改、删除、限制目标的某些功能。

C# 中有许多[预定义和保留的特性](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute)，例如`Flags`、`Obsolete`、`Conditional`，它们各有特定的用途，可以在 C# 文档中查到。注意，按约定，像 [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) 这样的特性，完整名称是`FlagsAttribute`，但在声明上应用时可以省略 _Attribute_ 后缀。
