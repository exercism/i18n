# 简介

## 比较

在 Go 中，可以使用以下关系运算符和相等运算符来比较数字。

| 比较              | 运算符    |
| ------------------| --------- |
| 相等              | `==`      |
| 不相等            | `!=`      |
| 小于              | `<`       |
| 小于或等于        | `<=`      |
| 大于              | `>`       |
| 大于或等于        | `>=`      |

比较的结果始终是布尔值，也就是 `true` 或 `false`。

```go
a := 3

a != 4 // true
a > 5  // false
```

上面的比较运算符也可以用来比较字符串。
这时会按字典序（即字典顺序）进行比较。
例如：

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## `if` 语句

Go 中的条件判断与其他语言相似。
任何条件运算的底层类型都是 `bool` 类型，其值为 `true` 或 `false`。
条件判断常用于控制流程，以检查各种条件。

要检查某个特定情况，可以使用 `if` 语句。当底层条件为 `true` 时，它就会执行其中的代码，如下所示：

```go
var value string

if value == "val" {
    return "was val"
}
```

当涉及不止一种情况时，可以用 `else if` 和 `else` 语句把多个 `if` 语句串联起来。

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

`if` 语句还可以包含一条简短的初始化语句，用来为 `if` 语句初始化一个或多个变量。
例如：

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> 注意：在初始化语句中创建的任何变量，都会在 `if` 语句结束后离开作用域。
