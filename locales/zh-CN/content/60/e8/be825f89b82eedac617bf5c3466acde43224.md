# 提示

## 通用

- 读取相关的词都放在[`io`][io]里；字符串流的构造函数和`with-string-writer`则放在[`io.streams.string`][io.streams.string]里。
- 在刷新写入器的任务里，如果同一个流需要操作两次，用局部变量（`::` 和 `:>`）可以让函数体保持易读。

## 1. 全部读出来

- 只需一个词：`stream-contents`。

## 2. 统计消息数量

- `stream-lines`把流按行拆分成数组；`length`返回数量。

## 3. 回显最后一次呼叫

- 和上面一样先用`stream-lines`，然后`last`，再`>upper`（来自`ascii`）。

## 4. 广播一条消息

- `stream-write`写入消息，`stream-flush`把它推出去。写入器会被用到两次，所以要用`::`局部变量：
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`。

## 5. 捕获引用的输出

- 只需一个词：`with-string-writer`。在结尾的`;`后面加上`inline`，这样编译器就能看穿引用参数：
  `: capture ( quot -- captured ) with-string-writer ; inline`。
