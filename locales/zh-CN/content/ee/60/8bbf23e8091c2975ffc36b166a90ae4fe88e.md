# 简介

Elixir 使用代码中的 _Behaviour_ 来提供通用的公共接口，同时让每个实现它的模块都能给出各自的实现。_Access Behaviour_ 就是这样一个常见的例子。

_Access Behaviour_ 为从基于键的数据结构中获取数据提供了公共接口。_Access Behaviour_ 已经为映射和关键字列表实现，不过我们来看看它在映射上的用法，先找找感觉。_Access Behaviour_ 规定，当你有一个映射时，可以在它后面跟上_方括号_，然后用键取出与该键关联的值。

```elixir
# Suppose we have these two maps defined (note the difference in the key type)
my_map = %{key: "my value"}
your_map = %{"key" => "your value"}

# Obtain the value using the Access Behaviour
my_map[:key] == "my value"
your_map[:key] == nil
your_map["key"] == "your value"
```

如果键在数据结构中不存在，就会返回`nil`。这可能会带来意料之外的行为，因为它不会抛出错误。注意，`nil`本身也实现了 Access Behaviour，对任何键都返回`nil`。
