# 提示

## 1. 向 @Languages 数组添加一门语言

- 你需要修改`@Languages`数组，在末尾添加一门新语言。

## 2. 从 @Languages 数组中移除一门语言

- 你需要修改`@Languages`数组，移除最后一门语言。

## 3. 从 @Languages 数组中获取第一门语言

- 你需要`return` `@Languages`数组的第一个元素。

## 4. 从 @Languages 数组中获取最后一门语言

- 你需要`return` `@Languages`数组的最后一个元素。

## 5. 从 @Languages 数组中获取一段语言切片

- 你需要`@Languages`数组的一个切片。
- 记住，下标从 0 开始。元素`1`的下标是`0`。

## 6. 检查某门语言是否存在于 @Languages 数组中

- 如果给定的语言能在`@Languages`数组中找到，你需要返回 true（例如`1`）或 false（例如`0`）这样的值。
