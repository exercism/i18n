# 简介

在[`Vectors`][vectors]概念中，我们说过“数组是 Julia 语言的核心”，而向量是一维数组。

既然如此，我们可以合理地期待这门语言提供了许多灵活而强大的方式，来对向量_做点什么_，不管那具体是什么。

## 接受向量输入的函数

有些非常简单的函数接受向量输入，返回标量输出。

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## 算术运算

假设你有一个数值向量，想从每个值中减去 0.5。

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

这样不行，那减去另一个向量呢？

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

成功了，但随着向量变长，这种做法相当繁琐，也很耗内存。

幸运的是，Julia 有一个“魔法”点号，可以非常简单地解决这个问题：你需要的只是`v .- 0.5`。

下一节会解释其中的原因。

## 广播

那么，`v - 0.5`会失败，而`v .- 0.5`会成功，我们需要理解这个点号到底做了什么。

它做了两件事，二者结合起来才能得到想要的结果。

### 1. 逐元素应用

首先，在任何中缀运算符_前面_加点号，表示“把这个运算分别应用到每个元素上”。

同样，在函数名_后面_加点号会将其“向量化”，即使这个函数原本是为标量输入写的。

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. 单例扩展

在前面某个例子中我们看到，可以相减长度相等的向量，不过请理解，`.-`比`-`更_安全_，因为它清楚地表明了逐元素的意图。

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

那么长度不相等的向量呢？

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

一般来说，长度不相等会报错，_除非_其中一个的长度为 1（从技术上讲，是一个“单例”维度）。

像`[0.5,]`这样的单例，或者干脆就是`0.5`，会通过重复自动扩展到所需的长度。
这正是`broadcasting`的核心。

### 原地广播

如果担心内存占用，原地操作是减少内存分配的常见做法。

不过，上面例子中的广播运算会创建一个新的`Vector`，而不是修改原来的向量。

要原地修改原来的`Vector`，这个修改本身也需要被广播。

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## 下标

通过下标来选取向量元素，前面的概念中已有讨论。

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### 逻辑下标

也可以选取满足某个逻辑表达式（从技术上讲，是一个“谓词”）的元素。
这通常需要用到广播。

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

表达式越复杂，点号就用得越多（不过它们很小，也很容易输入）。

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

提醒一下，“向量”实际上可以是任何合适的有序可迭代对象，比如区间：

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
