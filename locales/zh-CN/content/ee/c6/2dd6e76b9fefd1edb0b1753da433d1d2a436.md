# `for` 循环

循环是编程中的一个基础概念，它让你可以多次执行同一段代码。
在 Swift 里，循环有两种：[`for-in` 循环][for-loops]和`while`循环。
本章将介绍`for-in`循环。

`for`循环让你可以迭代一个值序列，依次取出每个元素，并把它绑定到你选定的变量上。
Swift 允许你迭代多种序列，比如范围、数组和字符串（还有更多类型，稍后会讲到）。
当序列中的每个元素都被迭代过后，循环就会结束。

`for`循环使用`for`关键字声明，后面跟一个变量名、`in`关键字，以及要迭代的值序列。
`for-in`循环中给出的变量是不可变的，也就是说你无法在循环内部改变它的值。
下面是一个`for-in`循环的例子，它迭代一个数字数组：

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`变量是在`for-in`循环中声明的，只在循环的作用域内可用。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 迭代一个范围

你也可以用`for-in`循环迭代一个数字范围。
这样你就能把一段代码执行指定的次数。比如范围`1...5`会迭代数字 1、2、3、4 和 5，所以循环会执行 5 次。
有时你可能想迭代数组这类数据结构中的下标，这时可以用`0..<array.count`范围。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 迭代字符串

你也可以用`for-in`循环迭代字符串。
这样你就能迭代字符串中的每个字符。要特别注意，循环中给出的类型是`Character`。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## 未使用的变量

如果你不需要循环中变量的值，可以用下划线`_`来忽略它。

```swift
let numbers = [3, 10, 7, 11]

for _ in numbers {
  print("Hello!")
}
```

## stride

Swift 还提供了`stride`函数，让你可以按指定的步长在一个范围上创建序列。
然后可以用`for-in`循环来迭代它。
`stride`有两种定义：[`stride(from:to:by:)`][stride-to]和[`stride(from:through:by:)`][stride-through]，前者不包含边界，后者包含边界。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

注意，`to`形参不包含边界，所以循环会迭代到`to`形参之前的那个数字；而`through`形参包含边界，因此在这个例子中它也会包括`10`。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
