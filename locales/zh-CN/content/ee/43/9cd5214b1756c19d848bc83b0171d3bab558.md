# 数字类型

Crystal 提供了多种不同的数字类型，各有各的用途。
例如，有些类型运算速度更快，但能表示的取值范围比其他的小；有些类型的取值范围更大，但速度更慢。

在 Crystal 中，整数类型既有有符号的，也有无符号的。
有符号整数可以表示正数，也可以表示负数。
无符号整数只能表示正数。

## 有符号整数类型

Crystal 中的[有符号整数类型][int]如下：

| Type     | Size (bits) | Range                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 至 127                                                                                                 |
| `Int16`  | 16          | -32_768 至 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 至 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 至 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 至 170_141_183_460_469_231_731_687_303_715_884_105_727 |

较小的类型占用的内存更少，速度也更快，但能表示的取值范围更小。

如果你确定数值会落在某个范围内，最好使用尽可能小的类型，以节省内存并提升性能。

默认的整数类型是 `Int32`。
要声明一个指定类型的整数，可以把类型名作为后缀，写成 `<number>_I <bit>`。

```crystal
1_i8.class
# => Int8
```

你可以用 `to_i<bit>` 方法在不同整数类型之间转换。
`to_i` 方法会转换成默认的整数类型 `Int32`。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 无符号整数类型

Crystal 中的[无符号整数][uint]类型如下：

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

有符号整数和无符号整数唯一的区别在于，无符号整数只能是正数。
要声明一个指定类型的无符号整数，可以把类型名作为后缀，写成 `<number>_u<bit>`。
你可以用 `to_u<bit>` 方法在不同无符号整数类型之间转换。
`to_u` 方法会转换成默认的无符号整数类型 `UInt32`。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮点数类型

Crystal 中的浮点数类型如下：

| Type      | Size (bits) | Range                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 to 3.4E+38   |
| `Float64` | 64          | 2.3E-308 to 1.7E+308 |

[浮点数类型][float]有两种，其中一种比另一种精度更高。

默认的浮点数类型是 `Float64`。

你可以用 `to_f<bit>` 方法在不同浮点数类型之间转换。
`to_f` 方法会转换成默认的浮点数类型 `Float64`。

[float]: https://crystal-lang.org/api/latest/Float.html
[int]: https://crystal-lang.org/api/latest/Int.html
[uint]: https://crystal-lang.org/api/latest/UInt32.html
