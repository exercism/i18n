# 学习

如果你是 SQLite 新手，想学习 SQL 语法和数据库管理的基础知识，下面这些资源都很适合初学者：

- **YouTube 上的 SQL 入门**：来看看 [What is SQL?][sql-youtube]，这是 Danielle Thé 为初学者制作的 4 分钟视频。

- **SQLite Tutorials**：[SQLite Tutorials][sqlite-tutorial] 提供了适合初学者的 SQLite 入门介绍，涵盖数据库创建、查询和数据操作等基础概念。

- **SQLZoo**：在 [SQLZoo][sqlzoo] 上通过交互式练习和教程来练习你的 SQL 技能，其中还包含适合初学者的 SQLite 专属内容。

这些资源为学习 SQLite 和 SQL 语法打下了基础，能帮助初学者理解数据库概念，并在使用 SQLite 数据库的过程中积累实践经验。

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
