# 说明

Lucian 的女朋友正在回家的路上，而他们的周年纪念晚餐他还没做！

在这个练习中，你要写一些代码，帮 Lucian 按照他最喜欢的食谱做一份精致的千层面。

本练习有四个任务，都与做千层面花费的时间有关。

## 1. 定义预期的烤箱时间（分钟）

定义`EXPECTED_MINUTES_IN_OVEN`常量，它表示千层面应该在烤箱里烤多少分钟。这个常量必须被导出。根据这本食谱，预期的烤箱时间是`40`分钟。

## 2. 计算剩余的烤箱时间（分钟）

实现`remainingMinutesInOven`函数，它接收千层面已经在烤箱里烤的实际分钟数作为_形参_，并根据上一个任务中的**预期的烤箱时间（分钟）**，_返回_千层面还需要在烤箱里烤多少分钟。

```javascript
remainingMinutesInOven(30)
// => 10
```

## 3. 计算准备时间（分钟）

实现`preparationTimeInMinutes`函数，它接收你给千层面加的层数作为_形参_，并_返回_你准备千层面花了多少分钟，假设每一层需要 2 分钟来准备。

```javascript
preparationTimeInMinutes(2)
// => 4
```

## 4. 计算总工作时间（分钟）

实现`totalTimeInMinutes`函数，它接收_两个形参_：`numberOfLayers`形参是你给千层面加的层数，`actualMinutesInOven`形参是千层面已经在烤箱里烤的分钟数。这个函数应该_返回_你总共花了多少分钟来做千层面，也就是准备时间的分钟数与千层面此刻在烤箱里已经烤的分钟数之和。

```javascript
totalTimeInMinutes(3, 20)
// => 26
```
