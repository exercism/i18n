# 说明

在这个练习中，你正在玩一款角色扮演游戏，不同类型的战士可以互相战斗。游戏为每种类型的战士制定了不同的规则。我们将重点关注两种特定类型：巫师和战士。

对于 Warrior，规则如下：

- Warrior 永远不会处于易伤状态。
- 如果 Warrior 攻击的战士没有处于易伤状态，Warrior 造成`6`点伤害。
- 如果 Warrior 攻击的战士处于易伤状态，Warrior 造成`10`点伤害。

对于 Wizard，规则如下：

- Wizard 可以提前准备法术。
- 除非 Wizard 提前准备了法术，否则会处于易伤状态。
- 如果 Wizard 提前准备了法术，则造成`12`点伤害。
- 如果 Wizard 没有提前准备法术，则造成`3`点伤害。

## 1. 创建 Warrior 类

创建一个名为`Warrior`的新类。该类应继承现有的`Fighter`类。

## 2. 描述 Warrior

更新`Warrior`类，使其`toString()`方法描述它属于哪种战士。该方法应返回字符串`"Fighter is a Warrior"`。

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. 让 Warrior 免疫易伤

更新`Warrior`类，使其`isVulnerable()`方法始终返回`false`。

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. 计算 Warrior 的伤害点数

更新`Warrior`类，使其`getDamagePoints(Fighter)`方法根据上述规则计算 Warrior 造成的伤害点数。

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. 创建 Wizard 类

再创建一个名为`Wizard`的新类。该类也应继承现有的`Fighter`类。

## 6. 描述 Wizard

更新`Wizard`类，使其`toString()`方法描述它属于哪种战士。该方法应返回字符串`"Fighter is a Wizard"`。

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. 允许 Wizard 准备法术，并在未准备法术时使其处于易伤状态

更新`Wizard`类，添加一个名为`prepareSpell()`的方法。该类应记住此方法何时被调用，并确保其`isVulnerable()`方法仅在法术已准备时返回`false`。

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. 计算 Wizard 的伤害点数

更新`Wizard`类，使其`getDamagePoints(Fighter)`方法根据上述规则计算 Wizard 造成的伤害点数。

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
