# 关于

Rust 是一门系统编程语言，运行速度极快，能避免段错误，并保证线程安全。
它旨在把现代语言设计和先进的类型系统带入系统编程。
Rust 不使用垃圾回收器，而是借助高级静态分析来实现确定性的释放。
做到这一点靠的是[所有权](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html)这一概念。

Rust 的核心与标准库都刻意保持精简，并不自带电池。
相反，Rust 用户（Rustaceans）被鼓励把库分享到 [crates.io](https://crates.io/) 上，为这门语言增添内容，这类库称为 _crates_。

Rust 最常用于对速度、性能和稳定性有极高要求的应用。
[Awesome Rust](https://github.com/kud1ing/awesome-rust) 列表收集了许多 Rust 项目示例，其中包括 CLI 工具、ORM、操作系统和游戏。
不论你用 Rust 构建什么，它都会又快又内存安全！

Rust 的主页是 [rust-lang.org](https://www.rust-lang.org/)。
Rust 在 [rust-lang.org/documentation.html](https://www.rust-lang.org/documentation.html) 上有非常出色的文档。
初学者应该从 [doc.rust-lang.org/book/](https://doc.rust-lang.org/book/) 上的“The Book”开始。
