# 说明

你正在新西兰徒步，用指南针测方位角。方位角是一个整数度数，而且它是一个值：转过 20 度并不会改变你测得的方位角，而是会得到另一个方位角。

写一个`immutable class BEARING`。代码桩已经给出了类头和它的属性。

## 1. 测方位角

`create`接收一个度数，返回一个方位角。度数的范围是 0 到 359，所以超出范围的数会绕回来：370 对应 10，-10 对应 350。

```sather
#BEARING(370).degrees
-- => 10
#BEARING(-10).degrees
-- => 350
```

## 2. 转动

`turned`接收一个要转动的度数，返回转动后的新方位角。用负数转动则会朝相反的方向转。调用它的那个方位角本身不变。

```sather
#BEARING(350).turned(20).degrees
-- => 10
```

## 3. 比较

`is_eq`接收另一个方位角，返回它们是否相同。一旦它存在，`=`就可以用于方位角。

```sather
#BEARING(10) = #BEARING(370)
-- => true
```

## 4. 命名方位点

`point`返回方位角最接近的方位点，取值是`"N"`、`"NE"`、`"E"`、`"SE"`、`"S"`、`"SW"`、`"W"`、`"NW"`之一。

每个方位点覆盖 45 度，以它精确的方位角为中心：正北从 337.5 经过 0 到 22.5，东北从 22.5 到 67.5，以此类推。由于这里的方位角都是整数，方位角 22 是`"N"`，方位角 23 是`"NE"`。

```sather
#BEARING(0).point
-- => "N"
#BEARING(90).point
-- => "E"
#BEARING(225).point
-- => "SW"
```

## 5. 写成文本

`str`返回度数和方位点，形如`"90 degrees (E)"`。

```sather
#BEARING(90).str
-- => "90 degrees (E)"
```
