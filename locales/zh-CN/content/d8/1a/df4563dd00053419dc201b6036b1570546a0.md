# 简介

Common lisp 提供了几种不同的条件表达式，它们的主要区别在于支持的分支数量。

- `when`和`unless`只支持单个分支：

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

测试表达式之后的部分可以包含不止一个表达式。

- `if`提供经典的 if-then-else 结构：

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

注意，then 和 else 分支都只能是单个表达式。

- `cond`提供了一种无需嵌套`if`表达式就能拥有多个分支的方式：

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

注意，测试表达式之后的表达式数量没有限制。

- `case`提供经典的“switch”风格结构：它把单个值与若干分支逐一比对：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

注意，和`cond`一样，测试表达式之后的表达式数量也没有限制。
