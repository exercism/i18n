# 简介

## 注释

Common Lisp 允许程序员编写会被计算机忽略的“注释”。
单行注释以一个或多个分号（`;`）开头，偶尔你还会看到下面这种写法：

```lisp
(code...) ; => value
```

这里的注释用来指出 Common Lisp 运行该行代码后返回的值。

按照惯用风格，行末的简短注释用一个分号，代码段上方的较长注释用两个，描述函数之类内容的注释用三个，而源文件顶部的文件头之类的注释则用四个。

## Cons

Common Lisp 中的所有对象要么是“原子”（单个、不可分割的值），要么是“cons”（由构造函数 "cons" 生成）。
一个 cons 由两部分组成：第一个元素和其余的元素。
出于历史原因，这两部分分别叫做`car`和`cdr`。
当这些 cons 作为代码被求值时，第一个元素（`car`）表示被调用的函数，而其余的元素（`cdr`）则表示传给该函数的实参：

```lisp
(<function> <arg1> <arg2> ... <argN>)
; ^ car ^  |        ^ cdr ^
```

## 表达式

所有 Common Lisp 代码都由 S-表达式（Symbolic Expression，符号表达式）构成，简称 sexpr。每个 sexpr 要么是原子，要么是 cons。当 S-表达式被求值时，会自动返回某个值，这个值会取代该表达式。当你自己编写函数时（使用`defun`），`defun`函数体中的最后一个值会被自动返回：

```lisp
;; Defining a new function
(defun gimme-foo () 'foo)
;; Calling the function as an S-Expression
(gimme-foo) ; => FOO
```

## 符号

Common Lisp 中的符号是一种特殊的值，可以指向其他值；而对于_关键字_来说，则指向自身。
当 Lisp 对符号求值时，会用它们所指向的值来替换它们：

```lisp
foo  ; => <whatever-foo-points-to>
:foo ; => :FOO
```

注意，关键字以开头的冒号（`:`）表示。

引用，也就是在 S-表达式前面加上`'`，会告诉 Lisp 不要对该表达式求值。
在我们的`defun`示例中引用`'foo`，就避免了让 Lisp 去查找（并且查找不到）`FOO`本应指向的东西，而是直接返回`FOO`这个值本身。
如果`FOO`在我们的程序中没有在任何地方定义：

```lisp
foo  ; => <ERROR! Lisp doesn't know what foo points to!>
'foo ; => FOO
```

目前，你可以先把它当作一种从函数中返回符号的方式，但之后我们会重新回顾引用，并在今后的概念练习中进一步探讨它的影响。
