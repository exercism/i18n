# 说明

你被要求继续在网络身份验证系统上做一些工作。

开发期间，系统已经硬编码了管理员的身份。除此之外，高层还希望资深开发者也能享受同等的待遇。

## 1. 把系统管理员的详细信息硬编码到系统中，并让调用方可以获取。

管理员的详细信息如下：

| 电子邮件 | 眼睛颜色 | 人中宽度 | 姓名 | 地址 1 | 地址 2 |
| ------------ | --------- | -------------- | -------- | --------- | --------- |
| admin@ex.ism | green     | 0.9            | Chanakya | Mumbai    | India     |

实现 `Authenticator.Admin` 属性，返回系统管理员的身份信息。姓名和地址的每一部分都应放在 `NameAndAddress` 列表的独立元素中。

```csharp
var authenticator = new Authenticator();
authenticator.Admin;
// => {"admin@ex.ism", {"green", 0.9m}, ["Chanakya", "Mumbai", "India"]}
```

## 2. 把开发者的详细信息硬编码到系统中，并以字典的形式提供给调用方

开发者的详细信息如下：

| 电子邮件 | 眼睛颜色 | 人中宽度 | 姓名 | 地址 1 | 地址 2 |
| ------------- | --------- | -------------- | -------- | --------- | --------- |
| bert@ex.ism   | blue      | 0.8            | Bertrand | Paris     | France    |
| anders@ex.ism | brown     | 0.85           | Anders   | Redmond   | USA       |

实现 `Authenticator.Developers` 属性，返回开发者的身份信息。字典的键是开发者的姓名。

```csharp
var authenticator = new Authenticator();
authenticator.Developers;
// => ["Bertrand"] = {"bert@ex.ism", {"blue", 0.8m}, ["Bertrand", "Paris", "France"]},
// ["Anders"] = {"anders@ex.ism", {"brown", 0.85m}, ["Anders", "Redmond", "USA"]},

```
