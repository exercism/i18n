# 说明

你认识的 Erin 要为好几场活动打印数千份传单，他们需要你的帮助！他们请你设计一张传单的版式，其中包含一个标题、一个可选的日期，以及一份艺术家列表：每位艺术家都对应一个 _unicode 图标_。目标是用`print`输出并分发你这张超酷的新传单设计，为此你需要用上全部 Python 字符串格式化技巧才能成功。

## 1. 创建类，并让标题首字母大写

`capitalize_header`函数应接收一个活动名称，并返回该活动名称首字母大写后的形式。

```python
>>> capitalize_header("fan meetup")
"Fan meetup"
```

## 2. 格式化日期

新建一个方法`format_date`，它接收一个数组，数组中包含日、月和年。它会按`<month_name> <date>, <year>`的格式显示格式化后的日期。

```python
>>> convert_date([9, 4, 2020])
>>> leaflet.date
"April 9, 2020"
>>> leaflet.set_date([13, 5, 2030])
>>> leaflet.date
"May 13, 2030"
```

## 3. 把 unicode 码点渲染成图标

调用`display_icons`方法时，传入的 unicode 码点数组应当被渲染，并以 _图标_ 组成的`list`形式返回。

```python
>>> leaflet.display_icons(['\U00000040', '\U0001D70B'])
['@', '𝜋']
```

## 4. 展示做好的传单

现在，你要用上前面所有的函数，把它们组合到`print_leaflet`函数里。
它应接收一个`event_name`、一个`icons`数组、一个`authors`数组，以及一个`event_date`数组。

海报应遵循下面的版式。

传单遵循一种特定的矩形版式：

- 第一行和最后一行包含 20 个星号。`"*"`
- 每个部分的上方和下方各用一个空行隔开。
- 空行只在开头和结尾各有一个星号。
- 第一部分是传单的标题，这个标题首字母大写。
- 第二部分是可选的日期；如果没有传入日期，这一部分应是一个空行。
- 第三部分也是最后一部分，是艺术家列表，每位艺术家都对应着相应的图标。

* Benjamin     🎤  *
