# match 表达式

match 表达式会对一个值和条件进行求值，并返回一个待求值的表达式。它很像三元表达式：如果条件不匹配，返回的表达式就不会被求值。匹配条件时，执行的是恒等（严格相等或`===`）检查。

```php
<?php
$some_value = 42;

$return_value = match($some_value) {
    0 => 'number is 0',
    1 => 'number is 1',
    default => 'number is something else'
}
```

要进行相等（`==`）检查，可以调整条件：

```php
<?php
$some_value = 42;

$return_value = match(true) {
    $some_value < 100 => 'number is less than 100',
    $some_value > 100 => 'number is greater than 100',
    $some_value == 100 => 'number is 100',
}
```

在 match 表达式中，如果没有条件匹配，就会抛出`UnhandledMatchError`。
