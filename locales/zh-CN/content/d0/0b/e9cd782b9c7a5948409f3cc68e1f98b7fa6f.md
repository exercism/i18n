# 安装

## Mac

使用 homebrew 安装，命令是`brew install swi-prolog`。
也可以从 [SWI Prolog Website](http://www.swi-prolog.org/download/devel) 下载适合你所用机器的源代码。

## Windows

从 [SWI Prolog Website](http://www.swi-prolog.org/download/devel) 下载适合你所用机器的源代码。

## Linux

根据你的发行版，按照[这里](http://www.swi-prolog.org/build/unix.html)的说明操作。
