# 占位符

## 如何用 bash 解题

`bash`没有任何内置的方式来**解析**日期时间字符串。这道练习需要你调用外部工具。

* GNU `date`命令的`-d`选项可以解析[各种各样的格式][gnu-date]。
* Mac 用户请参阅 [BSD `date` 命令][bsd-date]及其`-f`选项。
* Perl 使用广泛，而且可以用 [`Time::Piece` 模块][time-piece]来解析时间戳。

bash 无需任何外部工具就能**格式化**日期。给定一个整数时间值（自纪元以来的秒数），[`printf`的`%()T`格式化写法][bash-printf]就能按“strftime”风格进行格式化。

```bash
epoch=1234567890

printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-13 18:31:30

# bash uses the `TZ` environment variable for the timezone.

TZ=Asia/Kolkata printf '%(%Y-%m-%d %H:%M:%S)T\n' "$epoch"
# ==> 2009-02-14 05:01:30
```

[bsd-date]: https://manpage.me/index.cgi?apropos=0&q=date&sektion=0&manpath=FreeBSD+12-CURRENT+and+Ports&arch=default&format=html
