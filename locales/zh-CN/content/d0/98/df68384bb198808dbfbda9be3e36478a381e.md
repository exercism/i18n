# 提示

## 通用

- [The Cairo Book - Type Conversions][tcb-conversions]
- [The Cairo Book - Custom Type Conversion][tcb-ctc]

## 1. 将有符号数转换为无符号数

- 检查有符号值是否为负数，如果是，就返回`Option::None`
- 检查有符号值是否超过`u16::MAX`（65535），如果是，就返回`Option::None`
- 对于有效的值，使用`.try_into()`进行转换，或者直接转换
- 记住，`u16`能保存 0 到 65535 之间的值

## 2. 将无符号数转换为有符号数

- 由于`u16::MAX`（65535）可以轻松放入`i32`，所以这个转换总能成功
- 使用`.into()`把`u16`安全转换为`i32`

## 3. 自定义类型转换

- 用这样的语法实现`Into` trait：`impl IntoImplName of Into<SourceType, TargetType>`
- 在`into`方法中，创建目标类型的新实例
- 把`potency`字段从`Essence`映射到`Elixir`的`strength`字段
- 实现该 trait 后，就可以对`Essence`实例使用`.into()`

## 4. 使用 Into trait

- 实现`Into` trait 后，对`Essence`参数调用`.into()`
- 编译器会自动使用你的 trait 实现
- 返回类型标注能帮助 Cairo 知道该使用哪种转换
