# 说明

在本练习中，你将编写一些代码，帮助自由职业者与项目经理沟通：提供几个实用工具，快速计算日费率和月费率，并可按需应用给定的折扣。

我们首先在自由职业者和项目经理之间约定几条规则：

日费率是小时费率的 8 倍。
一个月有 22 个计费日。
如果项目经理选择让自由职业者按月结算，自由职业者可以给出折扣。当项目经理需要控制一定的预算时，这会很有用。

折扣用表示百分比的小数来建模，例如 25.0（25%）。

## 1. 根据小时费率计算日费率

实现一个函数，根据小时费率计算日费率：

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

返回的日费率应当是一个浮点数。

## 2. 计算折扣后的价格

实现一个函数，计算折扣后的价格。

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

返回的值始终应当是浮点数，不要以任何方式取整。

## 3. 根据小时费率和折扣计算月费率

实现一个函数来计算月费率，并应用折扣：

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

返回的月费率应当向上取整（取上限）到最接近的整数。

## 4. 根据预算、小时费率和折扣计算工作天数

实现一个函数，接收预算、小时费率和折扣，计算这些预算能覆盖多少天的工作。

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

返回的天数应当向下取整（取下限），保留一位小数。
