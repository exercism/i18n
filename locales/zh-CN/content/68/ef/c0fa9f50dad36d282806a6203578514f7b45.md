# 关于

Julia 的创造者想鱼与熊掌兼得。正如他们在博文[“Why We Created Julia”](http://julialang.org/blog/2012/02/why-we-created-julia)中所描述的，他们想要 C 的速度、Ruby 的动态性，以及 Matlab 那种熟悉的数学记法。他们希望 Julia 是自己最喜欢的各种语言中最喜欢的特性的集合。像 Perl 那样的字符串处理。像 shell 那样的粘合能力。强大，但不会复杂到让人难以理解。

Julia 拥有一套强大、清晰而直观的动态[类型系统](http://docs.julialang.org/en/v1/manual/types/)。它既允许你编写动态代码，也允许你在需要额外表达力来简化代码或提升性能时指定类型。这门语言支持[多重分派](https://youtu.be/kc9HwsxE1OY?t=66)，也就是说，它会根据每个实参的类型来决定调用哪个方法。这样你就能为特定类型编写专门的方法，同时提供通用的回退方案；这在数学代码里尤其有用，因为在这类代码中，很难说清一个运算为什么应该归属于某个特定的实参。

在 Julia 中，[元编程](http://docs.julialang.org/en/v1/manual/metaprogramming/)很容易。代码可以表示为 Julia 自身的数据结构，因此程序能够像 Lisp 那样转换并生成自己的代码。[Julia 的基础库和标准库](https://github.com/julialang/julia)有很大一部分也是用 Julia 写的，理解和修改它们不需要你懂另一门语言。如果你需要用到的库是用其他语言写的，比如 [C、Fortran](http://docs.julialang.org/en/v1/manual/calling-c-and-fortran-code/) 或 [Python](https://github.com/JuliaPy/PyCall.jl)，你可以用简单的接口直接在自己的代码中调用它们。

尽管问世不久，Julia 已经在各个领域的实际应用中崭露头角，包括但不限于金融、数据科学和科学计算。你可以在 [Julia Blog Aggregator](https://www.juliabloggers.com/) 上找到许多展示性应用，在 [juliacomputing.com](https://juliacomputing.com/case-studies/) 上看到商业应用的案例研究，还可以在[这里](https://julialang.org/research/)找到有关这门语言及其研究应用的出版物列表。
