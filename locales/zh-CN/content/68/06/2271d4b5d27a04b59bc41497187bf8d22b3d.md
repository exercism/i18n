# 提示

## 1. 定义 rank 和 file 的范围

- 你需要定义两个[常量][constants]，分别用来存放 rank 和 file 的[`Range`][range]。
- rank 应该是一个从 1 到 8 的 [`Integer`][integers] `range`。
- file 应该是一个从 'A' 到 'H' 的 [`String`][string] `Range`。
- 这个常量需要定义在`Chess`[模块][module]中。

## 2. 检查格子是否有效

- 你需要检查一个值是否在某个范围之内。
- 有一个[方法][include]可以用来检查某个值是否在范围之内。

## 3. 获取玩家的昵称

- 你可以把`Range`作为输入来获取一个切片。
- 有一个[方法][upcase]可以把字符串转换为大写。

## 4. 创建走子消息

- 你可以对表示格子的字符串取下标，从而获取 rank 和 file。
- 你可以使用已经定义好的方法，获取玩家的昵称，并检查这步走子是否有效。
