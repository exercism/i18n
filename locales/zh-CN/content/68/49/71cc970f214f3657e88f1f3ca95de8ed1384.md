# 说明补充

## 输入/输出格式

每一组单词都表示为一个以 null 结尾的字符串，每个单词末尾都有一个换行符。

你必须按照候选单词中列出的顺序返回这些变位词。

例如`"tones\nnotes\nSeton\n"`

## 寄存器

| 寄存器  | 用途   | 类型 | 说明                                       |
| ------- | ------ | ---- | ------------------------------------------ |
| `$a0`   | 输入   | 地址 | 以 null 结尾的目标字符串，末尾没有换行符   |
| `$a1`   | 输入   | 地址 | 以 null 结尾的候选字符串，每个单词后有换行符 |
| `$a2`   | 输入/输出 | 地址 | 以 null 结尾的输出字符串，每个单词后有换行符 |
| `$t0-9` | 临时   | 任意 | 用于临时存储                               |
