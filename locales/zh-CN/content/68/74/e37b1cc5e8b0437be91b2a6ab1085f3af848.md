# 关于

[concept:csharp/resource-cleanup]() 使用 `IDispose`接口，向类的调用方表明：当该对象不再需要时，有资源或程序状态需要及时释放或重置。在本练习中，我们借助 `using`关键字引入了一些语法糖，让代码更简洁，也更不容易漏掉重要的调用。

在某些用例中，可以把`using`看作[`try/finally`][try-finally]的替代品。

```csharp
File file = null;
try
{
    file = new File("myStuff.txt");
    file.Write("more stuff");
}
finally
{
    file.Dispose();
}
```

这种写法可以换成下面这种更紧凑、也更不容易出错的形式：

```csharp
using (var file = new File("myStuff.txt")
{
    file.Write("more stuff");
}
```

注意，多个资源可以按照单行块的标准规则方便地组合在一起：

```csharp
using (var file = new File("mystuff.txt")
using (var fileWriter = new StreamWriter(file)
{
     ...
}
```

C# 8 引入了下面这种变体，把`using`语句放在块的开头：

```csharp
using var file = new File("myStuff.txt");
file.Write("more stuff");
```

这样你就能在同一个块里使用多个可释放对象，也能更自然地处理[`try/catch`][try-catch]：

```csharp
using var fileIn = new File("myStuff.txt");
using var fileOut = new File("yourStuff.txt");
try
{
    var stuff = fileIn.Read();
    fileOut.Write(stuff);
}
catch (Exception)
{
    LogStuff();
}
```

关于`using`关键字可以使用哪些写法，以及它可以用于哪些类型的实例，[这里][using-statement]有详细说明。

## 给 Java 开发者的提示

Java 开发者可能会认出，这类似于 Java 7 引入的[_自动资源管理_][automatic-resource-management]机制。两者非常相似。Java 的语法重新利用了 `try`，在融合`catch`块方面比 C# 的`using`更自然。

## 版本

注意，那种不带自己语法块的、更灵活的`using`形式是在 C# 8 中引入的，因此你可能需要确认自己正在处理的代码库是否使用 C# 8 或更高版本。
