# 关于

`call` 是通用的“立即运行这段引用”原语。当编译器能直接看到引用本身时，就能推断出它的效果；如果引用来自变量、数组或参数，就必须声明效果：

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

声明 `call( a b -- c )` 会编译成一次运行时检查，用来确认这段引用确实具有所声明的效果。一旦不匹配，得到的是一个清晰的错误，而不是损坏的栈状态。

把引用当作数据来用（压入它们、放进数组、从单词中返回它们），正是拼接式代码如此紧凑的原因之一。一个“程序”可以只是一段普通的序列，用 `each` 配合 `call` 就足以解释它。
