# 说明

你的朋友 Linus 是一名火车司机，驾驶货运列车往返于城市之间。
他开火车很在行，但在物流和电脑方面就不太行了。
他想请你用编程帮他整理列车信息，并修正路线数据中的错误。

~~~~exercism/note
这道练习用切片、下标和各种 `hash` 方法就能轻松解决。
不过，我们希望你在完成下面每个任务时，练习打包、解包和多重赋值。
~~~~

## 1. 创建所有车厢的数组

你的朋友一直在记录每节车厢的标识符（ID），但他从来不确定系统在任意时刻需要处理多少节车厢。
如果把这些数据打包成一个统一的**数组**，物流程序的其他部分处理起来会轻松得多。

实现一个方法`generate_list_of_wagons()`，它接受任意数量的车厢 ID。
每个 ID 都是一个正整数。
然后，该方法应当把这些 ID 作为单个**数组**`return` 出去。

```ruby
LocomotiveEngineer.generate_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
# => [1, 7, 12, 3, 14, 8, 5]
```

## 2. 修正车厢数组

到这里，你已经对数据以及它在物流程序中的用法有了初步感觉。
ID 系统总是把火车头的 ID 分配为**1**，列车中其余车厢则随机分配一个大于**1**的 ID。

你的朋友需要给列车接上两节新车厢，却忘了更新系统！
现在，列车**数组**中前两节车厢必须移到末尾，否则所有顺序都会乱掉。

更麻烦的是，你的朋友刚刚又发现了一个**数组**，里面似乎装着缺失的车厢 ID。
他只记得，新车厢移好之后，第二个**数组**里的 ID 应当直接放在指定火车头的后面。

如果你能帮他改正这些错误并整合数据，Linus 会非常感激。

实现一个方法`fix_list_of_wagons()`，它接受两个装有车厢 ID 的**数组**。
它应当把第一个**数组**的前两项移到末尾，并把第二个**数组**中的值插入到火车头 ID（**1**）的后面（_即它的右侧_）。
然后，该方法应当 `return` 修改后的**数组**。

```ruby
LocomotiveEngineer.fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
# => [1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 补充缺失的停靠站

现在车厢数据都正确了，Linus 希望你更新系统的路线信息。
在一段运输路线上，列车可能会在几个不同的车站停靠，装货或卸货。
每趟行程的中间配送点数量可能各不相同。
你的朋友希望你用缺失或额外的配送信息更新系统的路线**哈希**。

实现一个方法`add_missing_stops()`，它接受一个路线**哈希**，后面跟可变数量的关键字参数。
这些参数可以是一个包含一个或多个停靠站的**哈希**，也可以是任意数量的 `stop_<number>: "city"` 关键字对。
然后，你的方法应当返回更新后的路线**哈希**，其中新增一个**键**，它的值是一个按顺序包含所有新增停靠站的**数组**。

```ruby
LocomotiveEngineer.add_missing_stops({from: "New York", to: "Miami"},
                    stop_1: "Washington, DC", stop_2: "Charlotte", stop_3: "Atlanta",
                    stop_4: "Jacksonville", stop_5: "Orlando")
# => {from: "New York", to: "Miami", stops: ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

~~~~exercism/note
停靠站总是会按正确的顺序传入，所以你不必操心排序。
~~~~

## 4. 扩展路线信息

Linus 一直在开发这个路线程序，他发现某些路线缺少一些重要的细节。
初始路线信息已经构造成一个**哈希**，你的朋友希望你把这个**哈希**更新，补上所有可能缺失的内容。
系统中每条路线所需的细节都略有不同，所以 Linus 很希望有一个通用的解决方案。

实现一个名为`extend_route_information()`的方法，它接受两个**哈希**。
第一个**哈希**包含这条列车路线往返的起点城市和终点城市。

第二个**哈希**包含其他路线细节，比如列车速度、长度或温度。
该方法应当返回一个包含所有路线信息的整合**哈希**。

~~~~exercism/note
第二个**哈希**可以包含与示例中不同的或更多的属性。
~~~~

```ruby
LocomotiveEngineer.extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
# => {"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```
