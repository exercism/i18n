# 说明

作为一名准魔术师，Elyse 需要练习一些基本功。

她有一摞牌，想摆弄摆弄。

为了省点事，她只用 1 到 10 这些牌。

这摞牌用一个`Array`表示，牌堆的底部在数组的前端，顶部在数组的后端。

## 1. 在牌堆顶部插入一张牌

实现函数 `insert_top`，它返回牌堆的一个副本，并把给定的新牌加到牌堆顶部。

```rust
let stack = array![5, 9, 7, 1];
insert_top(stack, 8);
// -> [5, 9, 7, 1, 8]
```

## 2. 从牌堆顶部移除一张牌

实现函数 `remove_top_card`，它返回移除了顶部一张牌后的牌堆副本。

如果给定的牌堆是空的，就原样返回原来的牌堆，不做任何改动。

```rust
let stack = array![3, 2, 6, 4, 8];
remove_top_card(stack);
// -> [3, 2, 6, 4]
```

## 3. 在牌堆底部插入一张牌

实现函数 `insert_bottom`，它返回牌堆的一个副本，并把给定的新牌加到牌堆底部。

```rust
let stack = array![5, 9, 7, 1];
insert_bottom(stack, 8);
// -> [8, 5, 9, 7, 1]
```

## 4. 从牌堆底部移除一张牌

实现函数 `remove_bottom_card`，它返回移除了底部一张牌后的牌堆副本。

如果给定的牌堆是空的，就原样返回原来的牌堆，不做任何改动。

```rust
let stack = array![8, 5, 9, 7, 1];
remove_bottom_card(stack);
// -> [5, 9, 7, 1]
```

## 5. 检查牌堆的大小

实现函数 `check_size_of_stack`，它检查牌堆的大小是否等于给定的 `stack_size`。

```rust
let stack = array![3, 2, 6, 4, 8];
check_size_of_stack(stack, 4);
// -> false
```
