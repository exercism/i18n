# 说明

在这个练习中，我们将模拟[二十一点](https://en.wikipedia.org/wiki/Blackjack)游戏的第一个回合。

你会拿到两张牌，并且能看到庄家亮出的那张明牌。所有的牌都用字符串表示，比如 “ace”、“king”、“three”、“two” 等等。每张牌的值如下：

| 牌 | 值 | 牌 | 值 |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**注意**：通常情况下，ace 可以算作 1 或 11，但为了简单起见，我们假设它只能算作 11。

根据你的两张牌和庄家的那张牌，游戏的第一回合有一套策略，你可以选择：

    - Stand (S)
    - Hit (H)
    - Split (P)
    - Automatically win (W)

虽然这套策略还不是最优的，但你要按照你的朋友 Alex 一直在完善的策略来做，具体如下：

类别：大牌

- 如果你有一对 ace，就必须总是分牌。
- 如果你拿到二十一点（两张牌之和为 21），而庄家没有 ace、人头牌或 ten，那么你就自动获胜。如果庄家确实有这些牌中的任何一张，你就必须停牌，等待另一张牌翻开。

类别：小牌

- 如果你的牌点数之和达到 17 或更高，就应该总是停牌。
- 如果你的牌点数之和为 11 或更低，就应该总是要牌。
- 如果你的牌点数之和的取值在 [12, 16] 范围内，就应该总是停牌，除非庄家的牌是 7 或更高，这时就应该总是要牌。

整体逻辑已经实现好了。你有四个任务：

## 1. 计算任意一张给定牌的点数。

实现一个函数，用分支语句根据牌的名字计算出它的数值。

```java
parseCard("ace")
// returns 11
```

## 2. 判断两张牌是否构成二十一点。

实现一个函数，如果两张牌构成二十一点就返回 `true`，否则返回 `false`。

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. 实现手牌点数大于 20 时的决策逻辑。

实现一个函数，它根据你的牌返回表示决策的字符串。只有当 `handScore` 大于 20 时才会调用这个函数。它会接收 2 个实参：`isBlackJack` 和 `dealerScore`。它应当实现上面“大牌”类别中的各个要点。

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. 实现手牌点数小于 21 时的决策逻辑。

实现一个函数，它根据你的牌返回表示决策的字符串。只有当 `handScore` 小于 21 时才会调用这个函数。它会接收 2 个实参：`handScore` 和 `dealerScore`。它应当实现上面“小牌”类别中的各个要点。

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
