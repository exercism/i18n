# 关于

在 C# 中处理数字时，一个关键点是要区分整数（小数点后没有数字的数）和浮点数（小数点后有零个或多个数字的数）。

C# 中最常用的两种数值类型是`int`（32 位整数）和`double`（64 位浮点数）。

```csharp
int i = 123;
double d = 54.29;
```

整数和浮点数都可以使用`_`字符作为数字分隔符，这在定义较大的数字时会很有帮助：

```csharp
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

算术运算使用标准的[算术运算符][arithmetic-operators]（`+`、`-`、`*`等）。数字可以使用标准的[比较运算符][comparison-operators]（`<`、`>=`等）以及[相等运算符][equality-operators]（`==`）和[不等运算符][equality-operators]（`!=`）进行比较。

```csharp
5 * 6;
// => 30

1.2 > 0.8
// => true

2 != 4
// => true
```

在数值类型之间转换时，有两种数值转换：

1. 隐式转换：不会丢失数据，也不需要额外的语法。
2. 显式转换：可能会丢失数据，并且需要以强制转换的形式写出额外的语法。

由于`int`的精度低于`double`，从`int`转换为`double`是安全的，因此属于隐式转换。而从`double`转换为`int`可能会丢失数据，所以需要显式转换。

```csharp
int i = 9;
double d = 2.66;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
