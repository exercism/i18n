# 说明

你的朋友刚刚给你发来一条带有重要秘密的消息。
为了不让别人轻易读到它，这条消息经过一系列位操作进行了加密。
你需要编写一些函数来帮助解密这条消息。

## 1. 将位向右移回去

解密这条消息的第一步，是把加密过程中的移位还原，也就是把位向右移回去。
解密过程中后续的一些步骤会假定 0 是从左侧插入的。

实现`shift_back()`函数，它接收一个值和要移位的位数，并执行移位。

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. 设置一些位

接下来，有一些位需要设为 1。

实现`set_bits()`函数，它接收一个值和一个掩码，返回把值中的相应位设为 1 之后的结果。
如果`mask`中的某一位是 1，那么`value`中对应的位也应设为 1。
其余所有位保持不变。

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. 翻转特定位

加密过程中有一些位被翻转了。
要解密这条消息，就需要把它们翻转回来。

实现`flip_bits()`函数，它接收一个值和掩码。
掩码指明值中哪些位需要翻转。
如果`mask`中的某一位是 1，`value`中对应的位就会被翻转。
其余所有位保持不变。

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. 清除特定位

最后，还有一些位解密后总是 0。

实现`clear_bits()`函数，它接收一个值和掩码。
掩码中为 1 的位，在`value`中对应的位应设为 0。
其余所有位保持不变。

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
