# 可变性

Cairo 的设计面向区块链，因此默认采用不可变的内存模型。这意味着值一旦写入内存，就无法被覆盖，只能读取。不过，Cairo 提供了一种机制，可以用 `mut` 关键字创建可变变量。当变量被声明为可变，并且它的值被改变时，新值会写入一个新的内存单元，变量则被更新为指向这个新单元。这种机制在保留不可变性好处的同时，也带来了灵活性。

在下面的例子中，`x`被声明为不可变变量。如果改变`x`的值，编译器就会抛出错误。

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

我们可以用`mut`关键字把`x`声明为可变变量。这样一来，`x`在声明之后仍然可以改变它的值。

```rust
let mut x = 5;
x = 10;
```

说到底，用不用可变性由你自己决定，要看在具体情况下怎样写最清晰。

## 常量

和不可变变量一样，常量也是绑定到某个名字的值，不允许改变，但常量和变量之间有一些区别：

- 常量用 `const` 关键字声明
- 常量不允许使用 `mut`
- 值的类型必须始终显式指定
- 常量只能在全局作用域中声明
- 常量只能被赋值为常量表达式，而不能是运行时计算出来的结果

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

也可以用`consteval_int!`宏来创建一个`const`变量，它的值是某种计算的结果。

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## 遮蔽

当某个值发生变换时，通过多次`let`重新声明来复用同一个变量名是可行的，而且往往是惯用做法。这称为_遮蔽_。实际上，第二个变量会盖过第一个变量，此后对该变量名的所有使用都指向第二个变量，直到它自己也被遮蔽，或者作用域结束。

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

借助遮蔽，我们甚至可以在复用同一个变量名的同时改变变量的类型。

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
