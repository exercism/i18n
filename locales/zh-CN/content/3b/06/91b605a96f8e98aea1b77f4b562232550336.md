# case 语句

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## 如何匹配

`case`后面的值会自上而下与每个`when`值用`=`比较。第一个匹配的分支会运行，而且只有它运行。其余的`when`分支会被跳过，执行在`end`之后继续。

任何支持`=`的类型都可以使用：`INT`、`CHAR`、`STR`、`BOOL`。

## else 分支

如果`case`没有`else`，又匹配不上任何值，运行时就会引发致命错误。一定要写一个`else`。当剩下的情况确实不该发生时，就在`else`里说明，而不是省略它：

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise`后面才会讲到；在那之前，返回一个合理的默认值就可以。

## 何时该优先用 if

`case`是把一个值和常量比较。其他任何情况都该用`if`：

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

硬要把范围比较塞进`case`，写出来的代码会比它替换掉的`if`更长、更糟。

## case 作为表达式

`case`是语句，不是表达式，所以下面这样写不是 Sather：

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

在每个分支内部直接返回，或者在每个分支内部给变量赋值。
