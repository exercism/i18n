# 关于

[列表][hyper-cons-as-list] 是 Common Lisp 中非常常见的一种数据类型。
它们由一串 [cons][concept-cons] 单元组成。
每个`car`都是列表中的一个元素，每个`cdr`要么是下一个 cons 单元，要么是一个作为结尾的原子。

以空列表结尾的列表称为“正规列表”。

以不是空列表的原子结尾的列表称为“点对列表”（这是根据它的打印方式命名的：`(cons 'a 'b) ;=> (a . b)`）。

如果列表中的某个 cons 单元是更靠后的某个 cons 单元的`cdr`，那么这个列表也可能是循环的，也就是循环列表。
例如：`(let ((x (list 1))) (setf (cdr x) x) (write x :stream t :circle t) :done)`。
处理循环列表时要小心：如果在打印时没有把 [`*print-circle*`][hyper-print-circle] 绑定为`t`，就会导致无限循环，并锁死 REPL（在这个例子里，由于给`write`指定了`:circle t`，`*print-circle`会被绑定为`t`）。

## 合并列表

你可以用任意数量的列表调用`append`，包括 1 个或 0 个：

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '()))     ; => (A B C)
(append '(a b c))          ; => (A B C)
(append)                   ; => ()
```

除了`append`，还可以用`nconc`，它的结果相同，但副作用是会修改原来的列表。使用`nconc`时要小心，因为它可能带来出人意料的效果。
