# 说明

Daphne 一直在开发一个系统，用来运行并记录她的实验结果。有些代码变得有点冗长、重复，所以她请你写一些`use`表达式来帮忙精简一下。

## 1. 定义`with_retry`函数

有时实验会因为一次性的失误而失败，所以如果实验失败了，Daphne 想再重试一次，看看第二次能不能成功。

定义`with_retry`函数，它接受一个返回结果的函数作为实参。

如果这个函数返回`Ok`值，那么`with_retry`应该返回该值。

如果这个函数返回`Error`值，那么`with_retry`应该再次调用这个函数，并返回那次调用的结果。

Daphne 会这样使用这个函数：

```gleam
pub fn main() {
  use <- with_retry
  // Perform the experiment here
}
```

## 2. 定义`record_timing`函数

Daphne 通过在每次实验前后调用一个记录时间的函数，来记录每个实验运行了多久。

定义`record_timing`函数，它接受两个实参：
- 一个记录时间的函数，它不接受任何实参，并返回`Nil`。
- 一个实验函数，它不接受任何实参，并返回一个结果。

`record_timing`应该先调用记录时间的函数，然后调用实验函数，接着再次调用记录时间的函数，最后返回实验函数的结果。

Daphne 会这样使用这个函数：

```gleam
pub fn main() {
  use <- record_timing(time_logger)
  // Perform the experiment here
}
```

## 3. 定义`run_experiment`函数

实验由三个阶段组成：设置、操作和记录。三个阶段都会返回结果，而且每个阶段都需要上一个阶段的成功结果才能运行。

定义`run_experiment`函数，它接受四个实参：
- 实验的名称，类型为`String`。
- 一个设置函数，它不接受任何实参，并返回一个结果。
- 一个操作函数，它以设置函数返回的`Ok`值作为实参，并返回一个结果。
- 一个记录函数，它以设置函数和操作函数返回的`Ok`值作为实参，并返回一个结果。

如果这三个函数都成功，那么`run_experiment`应该返回`Ok(#(experiment_name, recording_data))`。

如果其中任何一个函数返回`Error`值，那么`run_experiment`应该返回该值。

Daphne 会这样使用这个函数：

```gleam
pub fn main() {
  use setup_data, action_data <- run_experiment("Test 1", setup, action)
  // Record the results here
}
```
