# 简介

## 字符串

回想一下，`jq`支持与 JSON 相同的数据类型。
JSON 把**字符串**描述为：

> 字符串是由零个或多个 Unicode 字符组成的序列，用双引号括起来，并使用反斜杠转义。

### 转义序列

在字符串中，可以使用反斜杠字符来嵌入“特殊”字符：

- `\"`表示一个字面量双引号，
- `\\`表示一个字面量反斜杠，
- 空白字符`\n`、`\t`、`\r`、`\f`、`\b`
- Unicode 字符`\uAAAA`，其中`A`是十六进制数字

### 字符串长度

要查找字符的数量，可以使用`length`函数。

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

### 子字符串

可以用**切片**表示法来提取子字符串。
语法是`.[i:j]`。
返回的子字符串长度为`j - i`，返回从下标`i`（包含）到下标`j`（不包含）的字符。
任何一个下标都可以为负数，此时会从字符串末尾向前计数。
任何一个下标都可以省略，此时它分别指向字符串的开头或末尾。
下标从 0 开始计数。

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

### 拼接

使用`+`来拼接字符串：

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

给定一个字符串数组时，使用`add`：

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

### 拆分与合并

拆分使用`split/1`函数或`/`运算符：

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

`split/1`的逆操作是`join/1`。

经常需要把字符串转换成字符数组。
有两种方法：

1. 按空字符串拆分

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. 用`explode`拆分成由_码点_组成的数组

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode`是`explode`的逆操作。

### 查找子字符串的下标

使用`index/1`函数；下标从 0 开始。

```jq
"hello" | index("el")'   # => 1
```

如果子字符串不在字符串中，结果为`null`。

```jq
"hello" | index("elk")   # => null
```

### 字符串插值

在字符串中，序列`\(expression)`会把该表达式的_结果_插入[到字符串中][interpolate]：

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

### 大小写转换

使用`ascii_downcase`和`ascii_upcase`函数。

### 正则表达式
