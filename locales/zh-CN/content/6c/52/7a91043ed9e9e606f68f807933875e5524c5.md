# 介绍

## 枚举

C# 的 `enum` 类型表示一组固定的具名常量（也就是枚举）。它的主要用途是提供一种类型安全的方式来处理数字常量，把可用的取值限制在一个预先定义好的集合内。一个简单的枚举可以这样定义：

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

如果没有显式赋值，枚举成员会自动获得递增的整数值，其中第一个值为 0。也可以显式赋值：

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
