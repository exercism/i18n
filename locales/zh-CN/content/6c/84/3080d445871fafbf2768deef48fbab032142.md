# 说明

你的任务是把文本从英语翻译成 Pig Latin。
翻译由四条规则定义，这些规则考察单词开头元音和辅音的排列模式。
这些规则考察每个单词对元音和辅音的使用情况：

- 元音：字母`a`、`e`、`i`、`o`和`u`
- 辅音：英语字母表中其余 21 个字母

## 规则 1

如果一个单词以元音开头，或者以`"xr"`或`"yt"`开头，就在单词末尾加上一个`"ay"`音。

例如：

- `"apple"` -> `"appleay"`（以元音开头）
- `"xray"` -> `"xrayay"`（以`"xr"`开头）
- `"yttria"` -> `"yttriaay"`（以`"yt"`开头）

## 规则 2

如果一个单词以一个或多个辅音开头，先把这些辅音移到单词末尾，然后在单词末尾加上一个`"ay"`音。

例如：

- `"pig"` -> `"igp"` -> `"igpay"`（以单个辅音开头）
- `"chair"` -> `"airch"` -> `"airchay"`（以多个辅音开头）
- `"thrush"` -> `"ushthr"` -> `"ushthray"`（以多个辅音开头）

## 规则 3

如果一个单词以零个或多个辅音后接`"qu"`开头，先把这些辅音（如果有的话）和`"qu"`部分移到单词末尾，然后在单词末尾加上一个`"ay"`音。

例如：

- `"quick"` -> `"ickqu"` -> `"ay"`（以`"qu"`开头，前面没有辅音）
- `"square"` -> `"aresqu"` -> `"aresquay"`（以一个辅音后接`"qu`"开头）

## 规则 4

如果一个单词以一个或多个辅音后接`"y"`开头，先把`"y"`前面的辅音移到单词末尾，然后在单词末尾加上一个`"ay"`音。

一些例子：

- `"my"` -> `"ym"` -> `"ymay"`（以单个辅音后接`"y"`开头）
- `"rhythm"` -> `"ythmrh"` -> `"ythmrhay"`（以多个辅音后接`"y"`开头）
