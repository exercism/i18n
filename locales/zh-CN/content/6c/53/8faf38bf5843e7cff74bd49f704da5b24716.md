# 说明

在这个练习中，你将帮助高中情侣在社交媒体上表达爱意，方法是生成一个用两人首字母组成的 Unicode 心形：

```
❤ J.  +  M. ❤
```

## 1. 清理名字

实现`cleanupname`方法。
它应接受一个名字，把其中所有的`-`字符替换为空格。
还应该去掉名字开头和结尾的空白。

```julia-repl
julia> cleanupname("Jane-Ann")
"Jane Ann"
```

## 2. 获取名字的首字母

实现`firstletter`方法。
它应接受一个名字，并以字符串的形式返回其首字母。
记得复用你在上一步定义的`cleanupname`，并把它与其他函数组合起来。

```julia-repl
julia> firstletter("Jane")
"J"
```

## 3. 把首字母格式化为缩写

实现`initial`方法。
它应接受一个名字，返回其首字母的大写形式，后面跟一个点。
记得复用你在上一步定义的`firstletter`。

```julia-repl
initial("Robert")
"R."
```

## 4. 把缩写放进心形里

实现`couple`方法。
它应接受两个名字，返回两边带有爱心表情的缩写。
记得复用你在上一步定义的`initial`。

```julia-repl
couple("Blake Miller", "Riley Lewis")
"❤ B.  +  R. ❤"
```
