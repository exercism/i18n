# 区间

[区间][range]表示两个值之间的一段范围。
最常见的支持区间的类型是`Integer`和`String`。
它们的用途很多，比如快速创建集合、截取字符串、检查某个值是否在区间内，以及迭代。
创建区间要使用区间运算符`..`或`...`（分别表示包含和不包含末尾值）。

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

之所以有两个区间运算符，是为了让你能创建包含或不包含末尾值的区间。比如，在处理从零开始的下标时，这就很有用。

也可以用`Range`的构造函数`new`来创建区间。

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Ruby 中用区间运算符`..`或`...`创建区间后，如果想在区间上调用方法，就需要把区间用括号括起来。
否则，方法会被调用在区间运算符的第二个参数上。

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## 获取子字符串

想截取字符串时，可以使用区间运算符来获取子字符串。
也就是创建一个由子字符串的起始下标和结束下标构成的区间。

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

也可以用负数下标从字符串末尾开始截取子字符串。

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 区间的方法

区间确实有一组可以用来操作它们的方法。
例如，可以用这些方法求区间中所有值的和，或者检查区间是否包含某个值。

| Method                  | Description                                                             | Example                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | 返回区间中所有值的和                                                    | `(1..5).sum # => 15`            |
| [`size`][size]          | 返回区间的大小                                                          | `(1..5).size # => 5`            |
| [`include?`][indlude]   | 如果区间包含给定的值则返回`true`，否则返回`false`                       | `(1..5).include?(3) # => true`  |

## 无终点与无起点区间

区间可以没有终点，也可以没有起点。
无终点或无起点的区间，其起点或终点值是`nil`，但在定义区间时可以省略这个`nil`。

当你想从字符串开头截取，或者一直截取到末尾时，无起点区间和无终点区间就很有用。

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello "
```

~~~~exercism/caution
如果不是用在集合上，无终点区间可能会造成无限序列，使用时需要小心。
~~~~

## 字符串区间

字符串也可以用在区间中，让你得到两个字符串之间的一段字符串区间。
使用某些字符串时，它的行为可能有点出人意料，所以要谨慎使用。

```ruby
("aa".."az").to_a # => ["aa", "ab", "ac", ..., "az"]
```
