# 字符串方法

`str` 是由 [Unicode 码点][unicode code points] 组成的[不可变序列][text sequence]。其中可以包括字母、变音符号、定位字符、数字、货币符号、emoji、标点、空格和换行符等等。

字符串实现了所有[通用序列操作][common sequence operations]，并且可以用 `for item in <str>` 或 `for index, item in enumerate(<str>)` 语法进行迭代。单个码点（_长度为 1 的字符串_）可以用从左数起的 `0-based index` 编号引用，也可以用从右数起的 `-1-based index` 编号引用。

字符串可以用 `<str> + <other str>` 或 `<str>.join(<iterable>)` 拼接，也可以用 `<str>.split(<separator>)` 拆分。它们还提供了许多其他的格式化和组装选项。

为了进一步处理字符串，Python 提供了一套丰富的[字符串方法][str-methods]，用于搜索、清理、转换、翻译以及许多其他操作。

一些比较常用的 `str` 方法包括：

- 用 `<str>.startswith(<substr>)` 和 `<str>.endswith(<substr>)` 检查前缀或后缀
- 用 `<str>.title()`、`<str>.upper()`/`<str>.lower()` 和 `<str>.swapcase()` 等方法改变字符串的大小写
- 用 `<str>.strip(<chars>)`、`<str>.lstrip(<chars>)` 或 `<str>.rstrip(<chars>)` 删除字符串开头或结尾的字符
- 用 `<str>.replace(<old>, <new>)` 方法替换子字符串

由于字符串是_不可变_的，`str` 对象在内存中的值无法改变；那些看起来会修改字符串的方法，返回的是该 `str` 对象的一个新副本或新实例。


[`<str>.endswith(<suffix>)`][str-endswith] 在字符串以 `<suffix>` 结尾时返回 `True`，否则返回 `False`。

```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.title()`][str-title] 会解析字符串，并把找到的每个“单词”的第一个“字符”大写。
在 Python 中，这很大程度上取决于所使用的[语言编解码器][codecs]，以及具体语言如何表示单词和字符。
某种语言或字符集可能还有[区域设置][locale]规则。


```python
>>> man_in_hat_th = 'ผู้ชายใส่หมวก'
>>> man_in_hat_ru = 'мужчина в шляпе'
>>> man_in_hat_ko = '모자를 쓴 남자'
>>> man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```


[`<str>.strip(<chars>)`][str-strip] 返回 `str` 的一个副本，并删除开头和结尾的 `<chars>`。
`<chars>` 中指定的码点并不是前缀或后缀，从字符串的**两端**开始，这些码点的**所有组合**都会被删除。
如果没有为 `<chars>` 指定任何内容，则会删除空白码点的所有组合。
如果只想删除左侧或右侧，可以使用 `<str>.lstrip(<chars>)` 和 `<str>.rstrip(<chars>)`。


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
 ```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] 返回字符串的一个副本，其中所有出现的 `<substring>` 都被替换为 `<replacement substring>`。


下面引用的诗句出自 [Lewis Carroll][Lewis Carroll] 的 [The Hunting of the Snark][The Hunting of the Snark]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```

🌟**Python `3.9` 新增内容**

Python `3.9` 引入了两个新的字符串方法，让删除前缀和后缀变得容易得多。

[`<str>.removeprefix(<substring>)`][removeprefix] 返回去掉前缀后的字符串（`string[len(<substring>):]`）。如果 `<substring>` 不存在，则返回原字符串的副本。

```python
# removing a prefix
>>> 'TestHook'.removeprefix('Test')
'Hook'
>>> 'bookkeeper'.removeprefix('book')
'keeper'
```

[`<str>.removesuffix(<substring>)`][removesuffix] 返回去掉后缀后的字符串（`string[:-len(substring)]`）。如果 `<substring>` 不存在，则返回原字符串的副本。

```python
# removing a suffix
>>> 'TestHook'.removesuffix('Hook')
'Test'
>>> 'bookkeeper'.removesuffix('keeper')
'book'
```
