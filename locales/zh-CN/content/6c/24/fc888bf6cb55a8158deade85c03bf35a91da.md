# 简介

## 结构体和类

结构体和类是 Swift 编程中两种主要的构建单元。它们都能把相关的数据和函数组合成自成一体的功能单元。当你定义一个结构体或类时，你就是在定义一种新的类型，供你在 Swift 中使用，就像你已经用过的`Int`和`String`这些类型一样。

Swift 中的结构体和类有很多相似之处。除了其他方面，两者都能把值存储在_属性_中，并通过_方法_来提供功能。

它们各自还提供一些额外的功能，这不在本练习的讨论范围内。

### 定义结构体和类

结构体和类的定义方式大致相同：先写对应的关键字，接着要定义的类型名，然后是结构体或类的主体，放在大括号之间。

主体可以由存储属性组成，它们的定义方式和行为都与普通常量或变量一样。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id = makeRandomID()
}
```

### 实例

如上所述，定义结构体或类只是定义了一种新的_类型_。它只是这种类型的值长什么样的蓝图，并不会真正创建出可供你使用的该类型的值。

要创建这种类型的_实例_，你需要写出类型名，后面加上一对括号。

```swift
let someStats = CharacterStats()
let someCharacter = GameCharacter()
```

这会创建这些类型的值，其中的属性会用定义中提供的默认值填充。注意，在像 GameCharacter 的`name`属性这样的可选情况下，除非提供值，否则该属性会默认为 nil，就像定义普通的可选类型时，如果没立刻提供值一样。

对于结构体，Swift 会自动提供一种叫做_逐成员初始化器_的东西，你可以在括号里为结构体的属性提供值，这些值会覆盖定义中的默认值。

```swift
let differentStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

### 访问属性

结构体和类的属性可以用_点语法_访问：先写值的名称，再写一个点（`.`），然后是属性名。如果结构体或类的某个属性自身也有属性，也可以用这种点语法来访问这些嵌套属性。

这种语法既可以用来读取属性的值，在允许的情况下也可以修改它。

```swift
someStats.health
// => 0
someCharacter.name
// => nil

someStats.health = 87.3
someStats.health
// => 87.3
someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id  = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 方法

属性在结构体和类中存储数据，与之类似，你也可以定义_方法_，在结构体或类中存放函数。

方法的定义方式和普通函数一样，只是写在结构体或类的主体内部。注意，如果某个函数会改变结构体中某个属性的值，它前面必须加上`mutating`关键字。另外，如果某个属性可以被方法改变，那么它必须用`var`而不是`let`来定义，就像普通变量一样。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}

class GameCharacter {
  var stats = CharacterStats()
  var characterClass: String?
  var name: String?
  var active = false
  let id: String = makeRandomID()

  func takesDamage(_ damage: Double) {
    stats.takeHit(damage)
    if stats.health <= 0 {
      active = false
    }
  }
  func sayName() -> String {
    return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
  }
  func lift(_ weight: Int) -> String {
    if stats.canLift(weight) {
      return "No problem!"
    } else {
      return "Ooof! No way."
    }
  }
}
```

这些方法可以像属性一样用点语法调用。

```swift
var myChar = GameCharacter()
myChar.stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
myChar.active = true

myChar.lift(750)
// => "Ooof! No way."
myChar.takesDamage(80)
myChar.active
// => false
```

### Self

结构体或类的每个实例都有一个名为`self`的隐式属性，它指向实例本身。
`self`最常见的用途是区分同名的实例属性和参数：

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Swift 类型还提供了一个大写的`Self`关键字，它指向实例的*类型*，而不是实例本身。
