# 说明

在这个练习中，你将编写代码，为工厂员工打印工牌。

## 1. 为员工打印工牌

员工有 ID、姓名和部门名称。员工工牌标签的格式如下：`"[id] - name - DEPARTMENT"`。实现（_static_）`Badge.Print()`方法，返回员工的工牌标签：

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

注意，标签上的部门名称应大写。

## 2. 为新员工打印工牌

由于计算机系统的一个小问题，新员工开始到工厂工作时偶尔还没有 ID。由于必须佩戴工牌，他们会收到一个不带 ID 前缀的临时工牌。修改（_static_）`Badge.Print()`方法，使其支持还没有 ID 的新员工：

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. 为老板打印工牌

即使是工厂老板，也必须始终佩戴工牌。但是，老板没有部门。这种情况下，标签应打印 `"OWNER"`，而不是部门名称。修改（_static_）`Badge.Print()`方法，为老板打印标签：

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

注意，老板也可能同时是新员工：

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
