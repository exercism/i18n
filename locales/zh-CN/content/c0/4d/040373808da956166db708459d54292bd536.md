# 简介

除了 `if` 语句，还可以用 `switch` 语句来有条件地执行逻辑。当需要把同一个变量与多个不同的值进行比较时，就会用到它。对于某个变量 x，Haxe 中`switch`语句的语法如下。

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

当没有其他情况匹配时，就会执行 `default`。
