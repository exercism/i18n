# 测试

## Clojure CLI

Exercism 上的 Clojure 练习自带一个 `deps.edn` 文件，其中的 `:test` 别名用于调用 [cognitect-labs test-runner](https://github.com/cognitect-labs/test-runner)：

``` bash
$ clj -X:test
```

它会扫描项目的 `test` 目录，找到用 `clojure.test` 定义的所有测试并运行。

## Leiningen

要用 Leiningen 运行练习的测试，只需调用：

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
