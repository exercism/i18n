# 说明

在这道练习中，你将编写一些代码，帮助你照着最喜欢的菜谱做出一份美味的千层面。

一共有四个任务，都与烹饪千层面所花的时间有关。

## 1. 定义预期的烤箱用时（分钟）

定义`expected_minutes_in_oven`绑定，用来表示千层面应该在烤箱里烤多少分钟。
根据菜谱，预期的烤箱用时是 40 分钟：

```rust
expected_minutes_in_oven()
// Returns: 40
```

## 2. 计算剩余的烤箱用时（分钟）

定义`remaining_minutes_in_oven`函数，它接收千层面实际已经在烤箱里烤的分钟数作为形参，并返回千层面还需要在烤箱里烤多少分钟，依据是上一个任务中得出的预期烤箱用时（分钟）。

```rust
remaining_minutes_in_oven(30)
// Returns: 10
```

## 3. 计算准备时间（分钟）

定义`preparation_time_in_minutes`函数，它接收你往千层面里加的层数作为形参，并返回你准备千层面所用的分钟数，假设每加一层需要 2 分钟。

```rust
preparation_time_in_minutes(2)
// Returns: 4
```

## 4. 计算已用时间（分钟）

定义`elapsed_time_in_minutes`函数，它接收两个形参：第一个形参是你往千层面里加的层数，第二个形参是千层面已经在烤箱里烤的分钟数。该函数应返回你烹饪千层面所用的分钟数，也就是准备时间的分钟数，加上千层面此刻已经在烤箱里烤的分钟数。

```rust
elapsed_time_in_minutes(3, 20)
// Returns: 26
```
