# 关于

Ceylon 是一门通用编程语言，语法与 Java 和 C# 相似。它是命令式的、静态类型的、块结构的、面向对象的，并且支持高阶特性。所谓_静态类型_，是指编译器会在代码中出现的类型标注的帮助下执行大量的类型检查。所谓_面向对象_，是指这门语言支持用户自定义类型，并具有名义类型系统：类型是一组具名属性和操作的集合，同时它还支持继承和子类型多态。所谓_高阶_，是指每一个可引用的程序元素（每一个属性、每一个操作、每一个类型）本身也是一个值。所谓_块结构_，是指这门语言具有词法作用域，以及一套用于声明和语句的、极其规整的递归语法。

Ceylon 改进了 Java 的语言和类型系统，与 Java 和 C# 相比，它减少了冗长程度，提高了类型安全性。Ceylon 鼓励更偏向函数式、命令式色彩稍弱的编程风格，由此得到的代码更容易推理，也更容易重构。
