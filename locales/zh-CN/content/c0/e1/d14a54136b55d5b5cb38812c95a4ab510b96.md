# 说明

给定一段输入文本，输出其转置后的结果。

大致来说，矩阵的转置：

```text
ABC
DEF
```

由以下内容给出：

```text
AD
BE
CF
```

行变成列，列变成行。参见 <https://en.wikipedia.org/wiki/Transpose>。

如果输入的各行长度不同，则按以下方式处理：

- 在左侧用空格补齐。
- 不要在右侧补齐。

因此，转置这个矩阵：

```text
ABC
DE
```

会得到：

```text
AD
BE
C
```

而转置：

```text
AB
DEF
```

会得到：

```text
AD
BE
 F
```

一般来说，输入中的所有字符也都应该出现在转置后的输出中。这意味着，如果输入文本的某一列在其最下面的若干行中只包含空格，那么对应的输出行就应该在其最右边的若干列中包含这些空格。
