# 提示

## 通用

- 这个挑战是用[单链表][singly linked list]来实现一个[_栈_][Baeldung: The Stack Data Structure]。
- 与用`lists`、`collections.deque`或`queue.LifoQueue`支撑的栈不同，我们要求你自定义 `Node` 和 `LinkedList` 这两个[`classes`][classes tutorial]，用来存储和连接元素。

![表示用链表实现的栈的示意图。最左侧是一个带虚线边框的圆圈，名为 New_Node，有两条点线箭头指向右侧。New_Node 上写着“(becomes head) - New_Node - next = node_6”。上方那条点线箭头标注为“push”，指向右上方 Node_6。Node_6 上写着“(current) head - Node_6 - next = node_5”。下方那条点线箭头标注为“pop”，指向一个写着“gets removed on pop()”的方框。Node_6 有一条实线箭头指向右侧的 Node_5，Node_5 上写着“Node_5 - next = node_4”。Node_5 有一条实线箭头指向右侧的 Node_4，Node_4 上写着“Node_4 - next = node_3”。这个模式一直延续到 Node_1，Node_1 上写着“(current) tail - Node_1 - next = None”。Node_1 有一条点线箭头指向右侧一个写着“None”的节点。](https://assets.exercism.org/images/tracks/python/simple-linked-list/linked-list.svg)

- 可以参考 [Real Python: Linked Lists][Real Python Linked Lists]、[Towards Data Science: Demystifying the Linked List][towards data science demystifying the linked list] 和 [ADS Stack in Python][Koder Dojo Coding an ADS Stack in Python]，了解实现细节。
- 你的 `LinkedList` 应当在其_构造函数_中接受一个 `list` 参数，但不应该用 `list` 来存储节点或元素。
- `len()` 是大多数 Python 对象都有的内置函数。
要让_自定义对象_支持 `len()`，需要定义特殊方法 [`__len__`][__len__]。
- Python 中大多数序列、容器或集合类型的对象都支持迭代。
要让_自定义_对象支持循环或重新排序，需要定义特殊方法 `__iter__`。
[Implementing an iterator for a class][implementing iterators] 可以向你展示具体做法。
