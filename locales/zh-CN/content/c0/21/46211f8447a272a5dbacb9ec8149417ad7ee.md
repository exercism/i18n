# 简介

Cairo 在其核心库中提供了字典，由`Felt252Dict<T>`类型表示。

Cairo 中字典的键类型被限制为`felt252`，这与其他语言不同，在其他语言中可以定义键的类型。

要创建字典，可以使用`Default` trait 的`default`方法，如下所示：

```rust
let mut foo: Felt252Dict<u32> = Default::default();
```

最常用的基本操作有：

1. `insert(felt252, T) -> ()`，用于向字典实例写入值；
2. `get(felt252) -> T`，用于从中读取值。

下面演示如何使用这些操作：

```rust
let mut foo: Felt252Dict<u32> = Default::default();
// Add a value to the dictionariy
foo.insert('bar', 42);
// Here we update the element of 'bar'
foo.insert('bar', 73);
// To retrieve a dictionary value, you can use
baz = foo.get('bar');
```

如果你尝试获取字典中不存在的键的值，它将返回值类型的零值。

这可能会让你困惑，尤其是当你的值类型的默认值（例如整数的 0）本身就是一个有效值时。

这也意味着无法从字典中删除数据。

在将这个结构融入代码时，需要考虑这一点。
