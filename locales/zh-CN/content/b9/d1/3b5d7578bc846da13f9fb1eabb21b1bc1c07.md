# 关于

JavaScript 中有两种不同的数字：数字和“bigints”。

数字最常用，表示双精度 64 位浮点格式的数值数据类型。

- `number`：双精度 64 位浮点格式（IEEE 754）的数值数据类型。例如 `-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0` 和 `500000`。
- `bigint`：能以任意精度格式表示_整数_的数值数据类型。例如 `-12n`、`0n`、`4n` 和 `9007199254740991n`。

```javascript
let numericValue = 42;
// => 42
```

JavaScript 代码中像 `42` 这样的数字字面量是浮点值，不是整数。日常使用中并没有单独的整数类型。`bigint`类型的设计目的不是在日常使用中取代`number`类型。`42`仍然是`Number`，不是`BigInt`。

数字也可以用 `0b101`、`0o13`、`0x0A` 这样的字面量形式表示。要了解更多关于数字词法语法的内容，请参见[这里][lexical-grammar]。

## 特殊表示法

### 指数表示法

E 表示法表示一个需要乘以 10 的指定次幂的数字。E 表示法的格式是：先写一个数字，后面跟 `e` 或 `E`，再跟上要乘的 10 的次幂。

```javascript
const num = 3.125e7;
// => 31250000
// The notation essentially says, "Take 3.125 and multiply it by 10^7".
```

E 表示法也可以用来表示非常小的数字：

```javascript
const num = 325987e-6; // Equals 0.325987
// The notation essentially says, "Take 325987 and multiply it by 10^-6.
```

### 下划线表示法

下划线可以让大数字更容易阅读。编译器会完全忽略这些下划线。

```javascript
const num = 1_000_000; // You can read this as 1,000,000
console.log(num);
// => 1000000
```

## 内置对象

处理数字时，有两个内置对象很有用：

- [`Number`][built-in-number]：用于常见/有用值的静态属性，用于[类型检查][concept-type-checking]和[类型转换][concept-type-conversion]的静态方法，以及用于[类型转换][concept-type-conversion]和[把数字格式化为字符串][string-formatting]的实例方法。
- [`Math`][built-in-math]：用于数学常量和数学函数的属性和方法，**不能**用于 `BigInt`。

`Math`还包含对数字取整的方法。关于可用的取整选项，可以阅读这篇 [javascript.info 上关于取整的文章][ref-math-object-rounding]。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

内置的全局`object` `Number` 同时也是一个全局`function`，可以用来把_几乎任何_类似数字的东西转换成`number`。它不像把`string`_解析_成`number`那样宽容。

```javascript
const date = new Date('December 17, 1995 03:24:00');
const unix = Number(date);

unix;
// => 819199440000
```

JavaScript 中的数字有三类最大值（以及最小值 / 最大负值）：

- `VALUE`：由`Number.MAX_VALUE`和`Number.MIN_VALUE`给出
- `INFINITY`：由`Number.POSITIVE_INFINITY`和`Number.NEGATIVE_INFINITY`给出
- `SAFE_INTEGER`：由`Number.MAX_SAFE_INTEGER`和`Number.MIN_SAFE_INTEGER`给出

由于 JavaScript 中数字的实现方式，`Number.MIN_VALUE`和`Number.MAX_VALUE`之间的数字**并非**全都能表示。不过，`Number.MIN_SAFE_INTEGER - 1`和`Number.MAX_SAFE_INTEGER + 1`之间的_每一个_数字都**能**表示。

## 特殊数字值

JavaScript 有几个特殊的数字值：

- 两个错误值：`NaN`和`Infinity`。
- 两个零值：`+0`和`-0`。

### NaN：非数字

错误值`NaN`（也叫“非数字”）会在以下情况中产生。

- 数字无法解析：
  ```javascript
  Number('123'); // => 123
  Number('Hello, World!'); // => NaN
  ```
- 操作失败：
  ```javascript
  Math.sqrt(-64); // => NaN
  ```
- 其中一个操作数是 NaN：
  ```javascript
  NaN + 69; // => NaN
  ```

`NaN`是唯一不等于自身的值：

```javascript
NaN === NaN; // => false
```

如果想检查某个值是否为`NaN`，就必须使用全局函数`isNaN()`：

```javascript
isNaN(NaN); // => true
isNaN(123); // => false
```

### Infinity

`Infinity`是一个错误值，表示以下两种问题之一：

- 数字因为量级过大而无法表示。
  ```javascript
  Math.pow(2, 1024); // => Infinity
  ```
- 发生了除以零。
  ```javascript
  6 / 0; // => Infinity
  -6 / 0; // => -Infinity
  ```

`Infinity`比任何其他数字都大（`NaN`除外）。同样，`-Infinity`比任何其他数字都小（`NaN`除外）。

全局函数`isFinite()`可以检查某个值是否是真正的数字（既不是无穷大，也不是`NaN`）：

```javascript
isFinite(80085); // => true
isFinite(Infinity); // => false
isFinite(NaN); // => false
```

### 两个零

`+0`和`-0`在 JavaScript 中是两个不同的数字。当你表示的数字小到与 0 无法区分时，就可能产生它们。带符号的零让你可以记录自己是从“哪个方向”趋近零的，也就是这个数字在被视为零之前带什么符号。最佳实践是假装只有一个零。

## 比较

如果两个数字的值相同，就认为它们相等。

```javascript
1 == 1.0;
// => true

1 === 1.0;
// => true
// Remember, all numbers are floating-points, so this is
// different syntax for the exact same value.

1 === 1n;
// => false
// Strictly checking a number against a bigint will always result
// in false.
```

关于一般的比较以及在 JavaScript 中比较数值的更多信息，请参见[比较][concept-comparison]。

## 坑

由于 JavaScript 中的数字是浮点数，对这些值进行的所有数学运算都是浮点运算。因此，在 JavaScript 中：

```javascript
0.1 + 0.2 === 0.3;
// => false
```

简要说明请参见 [0.30000000000000004.com](https://0.30000000000000004.com/)，深入说明请参见 Oracle Numerical Computation Guide 的[附录 D](https://docs.oracle.com/cd/E19957-01/806-3568/ncg_goldberg.html)：“What Every Computer Scientist Should Know About Floating-Point Arithmetic”。
