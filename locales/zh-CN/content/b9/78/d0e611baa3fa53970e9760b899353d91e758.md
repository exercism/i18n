# 字符串

`STR`存储文本。字符串写在双引号之间。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

`STR`一旦存在就不会改变。下面的一切都以一个*新*字符串作答，而不是修改被问及的那个字符串。

## 拼接

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+`也可以把数字拼接到字符串上，这就是数字进入句子的方式：

```sather
"Opus " + 27           -- "Opus 27"
```

## 长度

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size`统计字符数，结果是`INT`。

## 片段

| 调用 | 结果 |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

请求的字符比实际拥有的多时，会返回实际拥有的部分，而不是失败。

## 比较

`=`询问两个字符串是否是同一段文本，`/=`询问它们是否不同。

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

大小写是有区别的。`.upper`和`.lower`会返回转换为相应大小写的副本，这是不区分大小写进行比较的常用方式：

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## 关于大小

`STR`是一行字节，`.size`统计的是字节数。对于英文文本，这与统计字母数相同。对于带重音符号或其他字母表的文本则不然，因为这些字母每个都占用一个以上的字节。
