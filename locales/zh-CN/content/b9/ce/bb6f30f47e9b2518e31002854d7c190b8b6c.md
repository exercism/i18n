# 说明

Turndit Inc. 正在生产一款新型唱机，它可以在唱片的曲目之间跳转。没人知道这有什么好处，但他们坚持要做，那就随他们去吧。目前他们需要有人帮忙弄清楚，怎样才能在需要时把唱针引到唱片上正确的位置。

这套装置由两部分组成：

唱针悬挂在唱机上方，可以在唱片上方左右和前后移动（想想抓娃娃机！）。
由于控制唱针的机构做线性运动，它用一对坐标`(x, y)`来记录自己的位置，原点位于唱片中心。

还有一套光学装置，用来追踪唱针所在的位置，以及上一首或下一首歌曲的起始位置。
由于唱片在旋转，追踪两点之间的径向差和角度间隔会更方便，即`(r, θ)`，原点同样位于唱片中心。

Turndit 需要知道，当选中另一首曲目时，如何求出唱针将要移动到的新坐标`(x', y')`。

~~~~exercism/note
这些运算可以通过三角函数和/或旋转矩阵来完成，但如果借助复数，通过旋转和径向位移来实现，就能变得更简单（我保证，也更有趣！）。
事实上，如果你愿意，本练习中的每个函数都可以用复数以及 Julia 内置的方法/功能写成赋值形式（也就是一行代码）。
~~~~

## 1. 从笛卡尔坐标构造复数

实现`z(x, y)`函数，它接收复平面上的`x`坐标和`y`坐标，并返回对应的复数。

```julia-repl
julia> z(1, 1)
1.0 + 1.0im

julia> z(4.5, -7.3)
4.5 - 7.3im
```

## 2. 从极坐标构造复数

实现`euler(r, θ)`函数，它接收径向坐标`r`、角度`θ`（单位为弧度），并以直角坐标形式返回对应的复数。

```julia-repl
julia> euler(1, π)
-1.0 + 0.0im

julia> euler(3, π/2)
0.0 + 3.0im

julia> euler(2, -π/4)
1.4142135623730951 - 1.414213562373095im  # √2 - √2im
```

## 3. 执行二维向量旋转

实现`rotate(x, y, θ)`函数，它接收`x`坐标、`y`坐标和角位移`θ`（单位为弧度）。
该函数应将点绕原点旋转给定角度`θ`，并以元组形式返回新坐标：`(x', y')`。

```julia-repl
julia> rotate(0, 1, π)
(0, -1)

julia> rotate(1, 1, -π/2)
(1, -1)
```
## 4. 执行径向位移

实现`rdisplace(x, y, r)`函数，它接收`x`坐标、`y`坐标和径向位移`r`。
该函数应沿半径方向把 x-y 坐标移动`r`的距离，并以元组形式返回新坐标：`(x', y')`。

```julia-repl
julia> rdisplace(0, 1, 1)
(0, 2)

julia> rdisplace(1, 1, √2)
(2, 2)
```
## 5. 找到目标歌曲

实现`findsong(x, y, r, θ)`函数，它接收唱针的`x`和`y`坐标，以及唱针与目标歌曲起始位置之间的`r`和`θ`位移。应以元组形式返回唱针的新坐标：`(x', y')`。

```julia-repl
julia> findsong(0, 1, 3, -π/2)
(4, 0)

julia> findsong(√2, √2, 0, 3π/4)
(-2, 0)
```
