# 测试

## 运行测试

进入某个练习的目录后，你会看到两个子目录：

* `src` 包含你为这个练习提交的解答

Wait — spacing. Per the guide, no space when the Latin run is set off by inline code. Let me correct: `src`包含你为这个练习提交的解答

* `spec`包含要为这个练习运行的测试

如果你在正确的目录里（也就是包含`src`和`spec`的那个目录），就可以通过运行`crystal spec`来执行该练习的测试：

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

这会运行`spec`目录中的所有测试文件。

在每个测试文件里，除了第一个测试，其余的都已被跳过。

一旦某个测试通过了，你就可以把`pending`改成`it`，从而取消跳过下一个测试。

## Crystal 格式

提交之前，建议你先对自己提交的解答运行`crystal tool format`。

你可以用下面的命令格式化当前目录中的所有内容：

```bash
$ crystal tool format ./
```

或者，你也可以有选择地格式化某些文件：

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## 提交你的解答

提交解答时，务必提交`src`目录中的源文件：

```bash
$ exercism submit src/<exercise>.cr
```
