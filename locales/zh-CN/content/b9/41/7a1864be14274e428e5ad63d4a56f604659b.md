# 介绍

Common Lisp 对大多数运算都使用标准的算术运算符，但它有一点很独特：用的是“前缀表示法”，而不是我们更熟悉的中缀表示法。

更直观地看：

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

前缀表示法虽然会把 `2 + 2` 这样的运算变成有点陌生的 `(+ 2 2)` 形式，却让同时处理多个数字变得容易得多。

## 基本数学运算

Common Lisp 拥有所有常见的函数：用于加、减、乘、除的 `+`、`-`、`*`、`/`。

说到除法，有时你可能想知道除法得到的余数。`mod`（求模）函数就能做到这一点，它接受一个数字和一个除数作为实参：

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## 比较数字

最后，你可能会发现用 `=`（等于）、`/=`（不等于）和 `>=`（大于或等于）这类函数来比较不同的数字会很有用。
当这些比较成立时（例如 `(= 1 1)`），它们返回 `T`；不成立时（例如 `(> 0 1)`），它们返回 `NIL`。
