# 关于

布尔值表示某个条件为`true`还是`false`。
在 Go 中，`bool` 类型只能是这两个值之一。

```go
isDoorLocked := true
hasKey := true
knowsCode := false
```

## 逻辑运算符

逻辑运算符作用于一个或两个布尔值，并产生一个布尔结果。

| Operator | Name | Behavior                                       |
| -------- | ---- | ---------------------------------------------- |
| `!`      | NOT  | 返回单个布尔值的相反值 |
| `&&`     | AND  | 只有当两边都为`true`时才返回`true` |
| `\|\|`   | OR   | 只要有一边是`true`就返回`true` |

当你需要一个布尔值的相反值时，使用 `!`（NOT）：

```go
!isDoorLocked // false
```

当两个条件都必须为`true`时，使用 `&&`（AND）：

```go
canUnlockDoor := isDoorLocked && hasKey // true
```

当至少有一个条件必须为`true`时，使用 `||`（OR）：

```go
canOpenDoor := canUnlockDoor || knowsCode // true
```

逻辑运算符的求值顺序是：先 `!`，再 `&&`，最后 `||`。
用括号把代码分组，控制哪些运算先执行：

```go
!true && false   // false because !true is evaluated first
!(true && false) // true because true && false is evaluated first
```
