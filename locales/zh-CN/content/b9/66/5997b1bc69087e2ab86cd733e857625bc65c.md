# 测试

## 环境配置

按照 [WebAssembly 的安装说明][docs-exercism-wasm] 完成环境配置，安装所需的依赖。

## 要求

安装练习的依赖：

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## 让测试套件通过

所有练习都自带测试套件，帮你在提交前验证自己的解答。
在练习目录下打开命令行，然后运行以下命令，就能执行这些测试：

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

有些测试套件会跳过除第一个之外的所有测试。

当一个测试通过后，把`xtest`改成`test`，就能启用下一个测试。

## 编写自定义测试

如果你想额外编写自定义测试，新建一个`custom.spec.js`文件，然后把它和你的解答一起提交：

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
