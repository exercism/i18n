# 说明补充

## 本练习在 Python 学习路径中的结构

本练习的测试要求你用 Python 将解答实现为一个`RelativeDistance` `class`。
如果你不熟悉 Python 中的`class`，可以从 [concept:python/classes]() 和 [Python 官方文档中的`classes`][classes in python] 入手。


`RelativeDistance`应该使用`family_tree`来初始化（_详见[`__init__()`][init]_），`family_tree`是一个字典，其中`keys`是个体，`values`是该个体所有子代的`list`。
你还需要实现一个`degree_of_separation`[方法][methods]，用来返回`person_a`和`person_b`之间的亲疏程度，他们都是传入的家族树中的个体。


我们为你提供了一个`__init__`[特殊方法][special-methods]的桩实现，用于创建`RelativeDistance`类的实例，同时也提供了`degree_of_separation`方法的桩。
首先，你需要在`__init__`中为`self`（_即实例_）添加一个合适的属性，用来表示`family_tree`数据。
然后，你就可以在`degree_of_separation`方法中加入自己的逻辑，计算出`person_a`和`person_b`之间的亲疏程度。


## 异常消息

有时需要[抛出异常][raising-exceptions]。
抛出异常时，你应该始终附上**有意义的错误消息**，指出错误的来源。
这能让代码更易读，对调试也有很大帮助。
如果你已经知道错误来源属于某种类型，可以选择抛出[内置错误类型][base-error-classes]中的一种，但同样应该附上有意义的消息。

本练习要求你使用 [raise 语句][raise-statement]来“抛出”多个`ValueError`。
在第一种情况下，当传给`RelativeDistance.degree_of_separation`方法的人中有一个或两个不在家族树里时，你需要抛出一个`ValueError`。

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

如果两个人都在家族树中，但按规则他们之间不存在有效的连接，你需要抛出一个`ValueError`。

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

只有当你既`raise`了预期的`exception`类型，又附上了预期的消息，测试才会通过。
请仔细查看测试及其预期结果，因为本说明并不全面。
