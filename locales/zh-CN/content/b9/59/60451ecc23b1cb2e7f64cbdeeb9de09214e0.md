# 简介

## 时长与周期

`LocalDate`和`LocalDateTime`这样的类描述的是时间上的一个_点_。`java.time`包中还有两个类，用来描述一段_时间量_：

- `java.time.Period`表示一段以年、月、日计的时间量，比如“2 个月零 5 天”。
- `java.time.Duration`表示一段以小时、分钟、秒、毫秒和纳秒计的时间量，比如“1 小时 30 分钟”。

`Period`遵循日历，所以用来配合日期和日期时间。`Duration`度量的是精确时间，所以配合时间和日期时间使用，但不能用于日期。

```exercism/note
和其他`java.time`类一样，`Period`和`Duration`都是不可变的。
那些看起来会修改它们的方法，实际上返回的是一个_新_实例。
```

### `Period`

`Period`用它的某个静态工厂方法创建：

```java
Period.ofDays(10);
// => P10D

Period.ofMonths(3);
// => P3M

Period.of(1, 2, 15);
// => P1Y2M15D
```

`toString()`的结果采用 [ISO-8601][iso-8601-durations] 记法：`P`（代表“period”）后面跟着年数（`Y`）、月数（`M`）和天数（`D`）。

可以给日期加上或减去一个周期：

```java
LocalDate date = LocalDate.of(2024, 3, 10);

date.plus(Period.ofMonths(2));
// => 2024-05-10

date.minus(Period.ofDays(10));
// => 2024-02-29
```

因为每个月的长度不同，加上几个月后可能落到一个并不存在的日期上。这时结果会回退到该月最后一个有效日期：

```java
LocalDate.of(2025, 1, 31).plus(Period.ofMonths(1));
// => 2025-02-28
```

`Period.between()`返回从一个日期（含）到另一个日期（不含）之间的周期：

```java
LocalDate start = LocalDate.of(2023, 3, 10);
LocalDate end = LocalDate.of(2024, 5, 25);

Period period = Period.between(start, end);
// => P1Y2M15D

period.getYears();
// => 1
period.getMonths();
// => 2
period.getDays();
// => 15
```

### 用`ChronoUnit`按单位计数

`Period`会把年、月、日分开保存。所以`getDays()`返回的只是周期中“日”的那_一部分_，而不是总天数。要按某一个单位计算两个日期之间的总数，请使用[`java.time.temporal.ChronoUnit`][chronounit-docs]的`between()`方法：

```java
LocalDate start = LocalDate.of(2024, 1, 15);
LocalDate end = LocalDate.of(2024, 3, 20);

Period.between(start, end);
// => P2M5D

Period.between(start, end).getDays();
// => 5

ChronoUnit.DAYS.between(start, end);
// => 65
```

当第二个日期早于第一个日期时，结果为负数：

```java
ChronoUnit.DAYS.between(end, start);
// => -65
```

### `Duration`

`Duration`同样用静态工厂方法创建：

```java
Duration.ofMinutes(90);
// => PT1H30M

Duration.ofHours(2).plusMinutes(15);
// => PT2H15M
```

在 ISO-8601 记法中，`T`把日期部分和时间部分隔开，所以时长的写法是`PT...`。

可以给日期时间加上或减去一个时长：

```java
LocalDateTime start = LocalDateTime.of(2024, 3, 10, 22, 30);

start.plus(Duration.ofMinutes(90));
// => 2024-03-11T00:00
```

`Duration.between()`返回两个日期时间之间的精确时间量：

```java
LocalDateTime checkIn = LocalDateTime.of(2024, 3, 10, 18, 5);
LocalDateTime checkOut = LocalDateTime.of(2024, 3, 10, 19, 40);

Duration.between(checkIn, checkOut);
// => PT1H35M
```

可以用`toHours()`、`toMinutes()`和`toSeconds()`这样的方法把时长换算成单一单位。这些方法返回该单位的_总量_，向下取整：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHours();
// => 1
duration.toMinutes();
// => 95
```

如果想按时钟那样把时长拆成各部分，改用`toXxxPart()`系列方法：

```java
Duration duration = Duration.ofMinutes(95);

duration.toHoursPart();
// => 1
duration.toMinutesPart();
// => 35
```
