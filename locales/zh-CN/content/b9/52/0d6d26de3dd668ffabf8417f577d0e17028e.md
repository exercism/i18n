## 概述

不要把 `SimpleLinkedList` 结构体实现为对 `Vec` 的封装。应该在堆上分配节点。

可以这样实现：

```
pub struct SimpleLinkedList<T> {
    head: Option<Box<Node<T>>>,
}
```

`head` 字段指向这个链表的第一个元素（Node）。

这个实现还需要一个 `Node` 结构体，包含以下字段：

```
struct Node<T> {
    data: T,
    next: Option<Box<Node<T>>>,
}
```

`data` 保存存储的数据，`next` 指向下一个节点（如果存在），否则为 None。

## 为什么用 `Option<Box<Node<T>>>`，而不是只用 `Option<Node<T>>`？

自己动手试试看。你会得到下面这个错误。

```
| struct Node<T>
| ^^^^^^^^^^^^^^ recursive type has infinite size
...
|     next: Option<Node<T>>,
|     --------------------- recursive without indirection
```

问题在于，编译时必须知道 next 的大小。由于 `next` 是递归的（“一个节点里有节点，节点里还有节点……”），编译器不知道该分配多少内存。相比之下，[Box](https://doc.rust-lang.org/std/boxed/) 是一个大小确定的堆指针。
