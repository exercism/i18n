## 1. 提取坐标

实现`get_coordinate()`函数，它接收 Azara 清单中的一个`(treasure, coordinate)`对，只返回提取出来的地图坐标。


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. 格式化坐标

实现`convert_coordinate()`函数，它接收“2A”这种格式的坐标，返回`("2", "A")`这种格式的元组。


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. 匹配坐标

实现`compare_records()`函数，它接收一个`(treasure, coordinate)`对和一个`(location, coordinate, quadrant)`记录，并比较两者的坐标。
如果坐标“匹配”，返回 **`True`**；如果不匹配，返回 **`False`**。
为了准确比较，按需重新格式化坐标。


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. 合并匹配的记录

实现`create_record()`函数，它接收 Azara 清单中的一个`(treasure, coordinate)`对和 Rui 清单中的一个`(location, coordinate, quadrant)`记录，**如果坐标匹配**，就返回`(treasure, coordinate, location, coordinate, quadrant)`。
如果坐标_不_匹配，返回字符串 **"not a match"**。
为了准确比较，按需重新格式化坐标。


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
