# 简介

Factor 通过 [`io`][io] 流进行读写。大多数代码面向的是*环境*输入输出。`read`、`readln`、`print` 和 `write` 这些词操作的都是当前绑定的那个流，而一小部分的`with-…`组合子可以在一个 quotation 执行期间，把这个环境流换进换出。

```factor
USING: io io.streams.string ;

"hello\nworld" <string-reader> [ readln . readln . ] with-input-stream
! prints "hello"
! prints "world"

[ "captured" print ] with-string-writer .
! prints (returns) "captured\n"
```

`<string-reader>`和`<string-writer>`是本次练习中用到的内存流。`<file-reader>`和`<file-writer>`是它们在磁盘上的对应版本，接口完全相同。把它们与`with-file-reader`/`with-file-writer`搭配使用，就能实现有作用域的文件访问。

[io]: https://docs.factorcode.org/content/vocab-io.html
