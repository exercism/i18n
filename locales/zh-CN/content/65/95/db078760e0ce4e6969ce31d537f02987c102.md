# 补充说明

## 实现

定义两个函数：（两个？没错，有时候我们对 Go 的要求就是会多一些。）

`All`返回一个数组，包含 s 中所有长度为 n 的子字符串。

`All(n int, s string) []string`

`UnsafeFirst`返回 s 中第一个长度为 n 的子字符串。

`UnsafeFirst(n int, s string) string`

到这里，你可以认为这个练习已经完成，接着往下走了。

不过等一下，你可能会问一个很合理的问题：为什么这个函数叫 **Unsafe** First？如果你感兴趣，就继续往下读，看看附加练习。

## 附加练习

当`go test`通过后，试试`go test -tags asktoomuch`。
这里用了一个_构建标签_来启用之前没有启用的测试。
构建标签可以用来选择包要使用哪些文件。
在我们的例子里，它会控制使用哪些测试文件。
你可以在 [Go 文档](https://golang.org/pkg/go/build/#hdr-Build_Constraints) 中了解更多。

你可能会发现，你没法让这个 _asktoomuch_ 测试通过。
我们需要一种方式来表示：在某些情况下，你无法取字符串的前 N 个字符。
`UnsafeFirst`做不到这一点，因为它只返回一个字符串。

为了解决这个问题，我们给函数再加一个返回值吧。
定义`First(int, string) (first string, ok bool)`，并用`go test -tags first`来测试。

`ok bool`这个第二个返回值是 Go 里常见且地道的写法。
例如，你在 [Map 查询](https://blog.golang.org/go-maps-in-action) 和 [类型断言](https://tour.golang.org/methods/15) 里都能看到它。
