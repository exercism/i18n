# 简介

`:`定义可以直接调用自身。Factor 的编译器会像推断其他任何词一样，推断递归词的栈效果，普通的递归不需要特殊的声明。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

这两部分就是递归的*基本情况*（这里，空序列的和为`0`）和*递归步骤*（剥掉一个元素，对剩余部分递归，再合并结果）。

`if-empty`和`unclip`是序列递归的标准搭档。`if-empty ( seq emptyquot nonemptyquot -- )`会根据序列运行两个引用之一；`unclip`会剥掉第一个元素，好让递归步骤处理的序列更简单。
