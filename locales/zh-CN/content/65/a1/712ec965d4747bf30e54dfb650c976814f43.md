# 只读类和属性

只读类和属性允许类声明公开属性以便访问，同时阻止修改。
要将属性声明为只读，需要在类型声明前加上`readonly`。
属性只允许被赋值一次，任何重新赋值或修改变量的尝试都会导致 Error。

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

只读类在只读属性的基础上更进一步：把类声明为`readonly`以后，`readonly`声明会应用到它的每个属性上。
此外，它还会阻止添加动态属性。

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
