# 通过 GitHub 贡献

对 Exercism 代码库的贡献都是通过 [GitHub][github] 完成的。

顾名思义，GitHub 使用 [git][git] 作为版本控制系统。如果你不熟悉 Git，最好的在线资源是 [Pro Git][pro-git]。

如果你还不熟悉 GitHub 和贡献工作流，下面这些资源可以帮你入门：

- [GitHub 入门 - 互动课程][github-course]
- [如何在 GitHub 上创建 Pull Request - 教程][pr-tutorial]
- [如何创建一个简单的 GitHub PR - anthonywritescode 的视频][anthonywritescode]

## 指南

想了解如何让你的贡献更受欢迎，可以阅读[如何写出优秀的 Pull Request][great-pr]指南。

我们还有几篇专门针对 Exercism 的 Pull Request 指南：
