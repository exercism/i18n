# 关于

很难找到一门比 Raku 更具表现力的编程语言。[Raku](https://raku.org/) 是一门现代的、多范式编程语言。Raku 提供[过程式](https://docs.raku.org/language/functions)、[面向对象](https://docs.raku.org/language/objects)和[函数式编程](https://docs.raku.org/language/functions#Functions_are_first-class_objects)方法。

[好奇吗？](https://raku.org/) 到[文档](https://docs.raku.org/)或模块[仓库](https://raku.land/)（类似 pypi 或 CPAN）里深入探索吧。

它是一门极其[灵活](https://docs.raku.org/language/operators)的语言，能[适应](https://docs.raku.org/language/glossary#gradual_typing)你的编程风格：无论是系统管理员用的快速[单行脚本](https://docs.raku.org/language/create-cli)，还是管理数据库导入的脚本，抑或是搭建[整个网站](https://cro.services/)所需的完整模块栈，都能胜任。

Raku 从其他语言中学习：

* 它用一套像样的对象系统提升了 Perl 的长期吸引力，其中包含[角色](https://docs.raku.org/language/typesystem#role)、[线程](https://docs.raku.org/language/concurrency)和[多重方法](https://docs.raku.org/language/glossary#Multi-dispatch)分派。
* 它把 Java 的线程机制拿了过来，并[简化](https://docs.raku.org/language/concurrency)成几个方法。
* 沿用 Lisp 的[外部函数](https://docs.raku.org/language/nativecall)接口，让访问库简单到只需一行代码。
* [正则表达式](https://docs.raku.org/language/regexes)如今被调到最高档：随着语法分析表达式[语法](https://docs.raku.org/language/grammars)（Parser Expression Grammars）的引入，再庞大的解析任务也能应对。
* 严格检查与警告现在都自动开启，消除了大量潜在错误。
* ……而且它还会做[数学](https://docs.raku.org/language/math)：```1/10 * 3 == 0.3 ``` 换你最喜欢的语言试试看！

Raku 的座右铭：
* “Raku 的设计目标是让简单的事变简单，同时不让困难的事变得不可能。”
* “做同一件事的方法不止一种，而且现在还有更多：加上了 -Ofun（为乐趣而优化）。”
