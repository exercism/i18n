# 关于

类型定义会创建一个新的命名类型。它与任何其他类型都不同，即使另一个类型的底层类型和它一样。

## 定义类型

类型定义以`type`关键字开头，后面跟着新类型的名字和它的底层类型：

```go
type File []bool
```

这里的`File`指的是棋盘上的一条竖列，通常用 A 到 H 来标记。这一列中的每个格子都用一个布尔值来表示，标明它是否被占用。既然`File`已经定义好了，我们就可以在其他定义中使用它：

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`把纵列标识符映射到`File`值。每个`File`都是一个布尔切片，表示一条纵列上的各个格子。如果没有这些类型定义，`board`就会是一个`map[string][]bool`，这会让人更难理解我们到底在表示什么。

## 定义的类型各不相同

虽然`Score`和`int`都保存整数值，但在它们之间转换需要显式转换：

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42`是一个无类型常量，所以可以直接赋值给`Score`变量。

定义的类型还可以有方法，这在方法概念中有介绍。

## struct 类型

struct 定义使用同样的`type`关键字：

```go
type Player struct {
    Name  string
    Score Score
}
```

struct 类型在 struct 概念中有介绍。

## 类型别名

类型别名是为已有类型另起一个名字，而不是创建一个新类型。因为别名和它原来的类型完全相同，它们的值可以互换使用。声明别名要使用`type`关键字、别名、等号（`=`）以及已有的类型。

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
