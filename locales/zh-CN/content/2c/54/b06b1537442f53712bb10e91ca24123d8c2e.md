# 说明

在这个练习中，你需要实现经典游戏 Pac-Man 中的一些规则。

你要实现四条规则，它们都与游戏状态有关。

## 1. 定义 Pac-Man 是否吃掉幽灵

实现一个函数，它接收 Pac-Man 是否有能量豆生效、Pac-Man 是否碰到幽灵这两个输入，并返回一个布尔值，表示 Pac-Man 能否吃掉幽灵。只有当 Pac-Man 有能量豆生效并且碰到幽灵时，这个函数才应返回`true`。

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. 定义 Pac-Man 是否得分

实现一个函数，它接收 Pac-Man 是否碰到能量豆、Pac-Man 是否碰到豆子这两个输入，并返回一个布尔值，表示 Pac-Man 是否得分。只要 Pac-Man 碰到能量豆或豆子，这个函数就应返回`true`。

```lua
rules.score(true, true)
-- => true
```

## 3. 定义 Pac-Man 是否输掉

实现一个函数，它接收 Pac-Man 是否有能量豆生效、Pac-Man 是否碰到幽灵这两个输入，并返回一个布尔值，表示 Pac-Man 是否输掉。如果 Pac-Man 碰到幽灵且没有能量豆生效，这个函数就应返回`true`。

```lua
rules.lose(false, true)
-- => true
```

## 4. 定义 Pac-Man 是否获胜

实现一个函数，它接收 Pac-Man 是否已经吃光所有豆子、Pac-Man 是否有能量豆生效、Pac-Man 是否碰到幽灵这三个输入，并返回一个布尔值，表示 Pac-Man 是否获胜。如果 Pac-Man 已经吃光所有豆子，并且根据第 3 部分定义的参数判断没有输掉，这个函数就应返回`true`。

```lua
rules.win(false, true, false)
-- => false
```
