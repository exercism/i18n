# 说明

你正在开发一个系统，帮助某家足球俱乐部网站的工作人员报道比赛。数据来自各种来源，经过清洗后被汇入同一条数据流。

## 1. 根据球衣号码输出球员的描述

这支球队一直只踢 4-3-3 阵型，也从未认可 1965 年那项允许换人的规则修改，更别说扩大阵容了。

球员的描述如下：

```text
1 -> "goalie"
2 -> "left back"
3 & 4 "center back"
5 -> "right back"
6, 7, & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

实现静态方法`FootballMatchReports.onField()`，根据球衣号码输出球员的描述。

```java
FootballMatchReports.onField(10);
// => "striker"
```

## 2. 如果球衣号码不在官方名单中，输出“invalid”

修改`FootballMatchReports.onField()`方法，当处理到超出 1 到 11 这个范围的球衣号码时，返回“invalid”。

```java
FootballMatchReports.onField(13);
// => "invalid"
```
