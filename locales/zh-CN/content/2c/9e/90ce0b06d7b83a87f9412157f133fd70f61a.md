# `case` 语句

当一个值需要和一组可能的值逐一比较时，一长串 `elsif` 只是在反复说同一件事：

```sather
   if zone = 0 then
      return 0;
   elsif zone = 1 then
      return 550;
   elsif zone = 2 then
      return 370;
   else
      return 920;
   end;
```

`case` 只需说一次：

```sather
   case zone
   when 0 then return 0;
   when 1 then return 550;
   when 2 then return 370;
   else return 920;
   end;
```

值写在 `case` 后面。每个 `when` 给出一个用来与它比较的值，第一个匹配的 `when` 会执行。

## 一个 when 里放多个值

`when` 可以列出一组值，用逗号分隔：

```sather
   case day
   when "Sat", "Sun" then return "Weekend";
   when "Mon", "Tue", "Wed", "Thu", "Fri" then return "Weekday";
   else return "Unknown";
   end;
```

整数、字符和字符串都可以这样用，凡是能用 `=` 比较的值都行。

## else 不是可选的

**一个没有匹配到任何值、又没有 `else` 的 `case` 是一个错误，一旦发生就会让程序中止。**

这与 `if` 不同：在 `if` 中省略 `else` 只是表示什么都不做。这也与大多数语言不同，在那些语言里，没有匹配的 `case` 会悄无声息地什么都不做。

所以每个 `case` 都需要一个 `else`，即使你确信 `when` 部分已经覆盖了所有值。以后新增了第四个区域，而 `case` 没有相应更新，程序就会在第一个使用该区域的乘客身上中止。

## 只有一个 when 会执行

当某个 `when` 匹配时，它 `then` 后面的语句会执行，整个 `case` 就结束了，程序会从 `end` 之后继续。下面的 `when` 部分根本不会被查看，所以你不必写任何东西来阻止下一个 `when` 也执行。
