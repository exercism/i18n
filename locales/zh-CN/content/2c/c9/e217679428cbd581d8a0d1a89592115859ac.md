# 关于

使用 [`if/elif/else`表达式][conditional-expression]可以按条件执行代码。`if/elif/else`表达式中使用的条件必须是`bool`类型。F# 没有“truthy”值的概念。

```fsharp
if x = 5 then
    printfn "x equals 5"
elif x > 7 then
    printfn "x is not 5 and greater than 7"
else
    printfn "x is not 5 and not greater than 7"
```

由于`if/elif/else`是一个表达式，因此可以绑定到名称，也可以从函数返回。

```fsharp
let message =
    if x = 5 then
        "x equals 5"
    elif x > 7 then
        "x is not 5 and greater than 7"
    else
        "x is not 5 and not greater than 7"
```

所有分支都必须返回相同的类型。否则会导致编译器错误：

```fsharp
if x = 5 then
    true
elif x > 7 then
    5.6

// Results in compiler error
```

`else`和`elif`分支是可选的，但只有当返回的表达式的类型为[`unit`][unit-type]时，它们才是可选的。

```fsharp
// Valid if expression
if x > 2 then
    printfn "x is greater than two"

// Invalid if expression, results in compiler warning
if x > 2 then
    true
```

`if/else`表达式也可以放在一行中。这应仅用于简单的`if`表达式。

```fsharp
let y = if x > 5 then 10 else 20
```
