# 说明

在这个练习中，你将编写代码来处理一个编程语言数组，这些语言是你打算在 Exercism 平台上练习的。

你需要完成六个任务。

## 1. 创建一个新数组

在添加语言之前，你需要先创建一个新数组。定义一个返回空数组的函数。

```clojure
(new-list)
;; => ()
```

## 2. 向数组中添加一门新语言

当你在 Exercism 上浏览并发现自己想学的语言时，你需要能把它们添加到数组中。定义一个函数，把一门新语言添加到数组的开头。

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. 查看最后添加的语言

你会想快速查看自己刚刚添加的是哪门语言。定义一个函数，返回数组中的第一门语言。

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. 从数组中移除第一门语言

有时你会对刚添加的语言改变主意。定义一个函数，从数组中移除第一门语言。

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. 统计数组中的语言数量

逐个统计语言很不方便。定义一个函数，统计数组中语言的数量。

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. 把所有内容组合起来

定义一个 `learning-list` 函数，并在其中使用上面定义的部分函数。

- 创建一个空数组
- 向数组中添加 2 门新的编程语言。

  - “Clojure”
  - “Lisp”

- 从数组中移除 “Lisp”，因为你可能这一年没有足够的时间，而且它与 Clojure 非常相似。
- 再向数组中添加 2 门编程语言。

  - “Java”
  - “JavaScript”

- 返回语言的总数。提示：应该是 3。

```clojure
(learning-list)
;; => 3
```
