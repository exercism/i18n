# 关于

## 布尔值

PowerShell 提供了 [`bool`][booleans] 类型，用来表示 true 和 false 这两种值。
这个类型只有两个值：`True` 和 `False`。
你可以用前缀 `$` 把这些值绑定到变量上：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我们可以使用 [逻辑运算符][logical-operators]，比如 `-and`、`-or` 和 `-not`，来组合和求值布尔表达式。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```

## 转换与真值性

PowerShell 可以隐式地把任何类型都当作布尔值来对待。
不过，你也可以使用布尔类型加速器 `[bool]` 来进行显式转换。

下面是 PowerShell 把其他类型转换成布尔值的一些通用规则：

$false：
- 空字符串，比如 `''` 或 `""`
- 空值，比如 `$null`
- 值为零（0）的数值类型

$true：
- 非空字符串
- 其他任何非集合类型的实例

```powershell
> [bool] 0
False

> [bool] 0.0
False

> [bool] ""
False

> [bool] "Hello"
True

> [bool] 1234
True
```

关于从集合类型转换布尔值的详细规则，请阅读[这里][collection-conversion]。
