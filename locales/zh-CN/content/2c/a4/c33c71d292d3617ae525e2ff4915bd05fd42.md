# 安装

我们提供了[预编译的 Uiua 二进制文件][releases]，因此你无需自行编译。最新的安装说明（包括 IDE 集成和字体）请参见[官方安装指南][install-guide]。

```exercism/note
目前我们的在线测试运行器使用的是`0.18.1`版本。Uiua 的开发节奏很快，这个版本可能会发生变化，所以如果你无法复现网站上的测试结果，请留意这一点。
```

下载到目标位置后，你还需要把 Uiua 添加到系统的 PATH 中。

- **macOS：**用 Finder 打开`Applications > Utilities > Terminal`。输入`export PATH="/path/to/uiua:$PATH"`，即可从任意位置运行 Uiua。

- **Windows：**从开始菜单打开“Edit Environment Variables”。在“Path”中添加你的 Uiua 文件夹。

- **Linux：**打开终端，把`export PATH="/path/to/uiua:$PATH"`添加到`~/.bashrc` 或`~/.profile` 中，方便随时使用。

[releases]: https://github.com/uiua-lang/uiua/releases
[install-guide]: https://www.uiua.org/docs/install#basic
