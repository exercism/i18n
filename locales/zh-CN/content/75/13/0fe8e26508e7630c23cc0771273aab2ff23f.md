# 提示

## 1. 定义 Coord 类型。

- `Coord`是一个`struct`。
- 字段是`x`和`y`。
- 两者的类型都是`UInt16`。

## 2. 定义 Plot 类型。

- `Plot`是一个关键字`struct`。
- 字段是`bottom_left`和`top_right`。
- 两者的类型都是`Coord`。

## 3. 检查你的主张是否已经被登记。

- 这个主张是否已经是`register`中的一个元素？
- 如有需要，复习一下[`Sets`][sets]的知识。

## 4. 投机者可以通过指定一个由其角坐标确定的地块来提出主张。

- 如果同一主张已经被登记，就返回`false`，表示你的主张失败了。
- 如果允许，就把你的主张加入 register。[`push!()`][push]函数可能会有用。
- 因为`stake_claim!()`是一个会修改状态的函数，`register`里的改动对调用者可见。
- 允许使用链式点号表示法，例如`claim.bottom_left.x`。
- 返回`true`表示成功。

## 5. 求地块较长边的长度。

- 记住这些矩形地块的朝向。你可以推断出`top_left`和`bottom_right`坐标。
- 计算各边的长度只是简单的算术。
- 注意[`max()`][max]和[`maximum()`][maximum]的区别。`max`接受任意数量的参数进行比较，`maximum`接受单个可迭代对象。

```julia-repl
julia> max(1, 2, 3)
3

julia> v = [1, 2, 3];
julia> maximum(v)
3
```

## 6. 出于研究目的，找出边长最长的已主张地块。

- register 是一个 Set，无序但可迭代。
  - 把 register 转成有序的结构可能会方便一些，例如用`collect()`。
  - 你已经写过一个计算地块最长边的函数，可以把它应用到这个集合上。
- 关于`max`与`maximum`的对比说明，参见任务 5。
- 找出一个或多个长度最大的地块。
- 以`Set{Plot}`的形式返回结果。
