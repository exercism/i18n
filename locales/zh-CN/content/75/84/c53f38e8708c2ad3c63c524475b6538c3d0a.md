# 说明

Conda Airlines 是编程界最大的航空公司，每天有超过 10,000 个航班！

他们目前还在靠人工为乘客分配所有座位，这需要实现自动化。

他们请_你_来编写软件，自动完成乘客座位分配。
他们要求你的软件既节省内存，又性能出色。

## 1. 生成座位字母

Conda 想为他们的飞机生成座位字母。
一架飞机由一排排座位组成。
每排都有 _4 个座位_。
每排的座位总是命名为 `A`、`B`、`C` 和 `D`。
一排中的第一个座位是 `A`，第二个座位是 `B`，依此类推。
到达 `D` 之后，再重新从 `A` 开始。

实现一个函数 `generate_seat_letters(<number>)`，它接受一个 `int`，表示要生成多少个座位字母。
该函数应返回一个座位字母的_可迭代对象_。

```python
>>> letters = generate_seat_letters(4)
>>> next(letters)
"A"
>>> next(letters)
"B"
```

## 2. 生成座位

Conda 想要一个系统，能为他们的飞机生成指定数量的座位。
每架飞机的每一排都有 _4 个座位_。
排号用数字表示，从 `1` 开始递增。
座位应按这样的顺序排列：`1A`、`1B`、`1C`、`1D`、`2A`、`2B`、`2C`、`2D`、`3A`、`3B`、`3C`、`3D`、……

下面是一个例子：

|      x      |  1  |  2  |
| :---------: | :-: | :-: |
|      排     |  5  | 21  |
|   座位字母  |  A  |  D  |
|     结果    | 5A  | 21D |

由于乘客的迷信，很多航空公司的航班都没有第 13 排。
Conda Airlines 也遵循这一惯例，所以请务必_不要_生成第 13 排的座位。

实现一个函数 `generate_seats(<number>)`，它接受一个 `int`，表示要生成多少个座位。
该函数应返回一个包含所生成座位的_可迭代对象_。

```python
>>> seats = generate_seats(10)
>>> next(seats)
"1A"
>>> next(seats)
"1B"
```

## 3. 为乘客分配座位

现在你已经有了生成座位的函数，可以用它为乘客分配座位了。

实现一个函数 `assign_seats(<passengers>)`，它接受一个由乘客姓名组成的 `list`。
该函数应返回一个_字典_，以 `passenger` 为_键_，以 `seat_number` 为_值_。

```python
>>> passengers = ['Jerimiah', 'Eric', 'Bethany', 'Byte', 'SqueekyBoots', 'Bob']

>>> assign_seats(passengers)
{'Jerimiah': '1A', 'Eric': '1B', 'Bethany': '1C', 'Byte': '1D', 'SqueekyBoots': '2A', 'Bob': '2B'}
```

## 4. 机票代码

Conda Airlines 希望每张机票都有一个唯一的代码。
由于他们是一家大型航空公司，航班非常多。
这意味着会有多个航班的座位号相同。
他们希望你创建一个系统，生成一个长度为 _12_ 个字符的唯一机票字符串。

该代码以 `assigned_seat` 开头，后面跟 `flight_id`。
代码的其余部分用 `0s` 填充。

实现一个函数 `generate_codes(<seat_numbers>, <flight_id>)`，它接受一个由 `seat_numbers` 组成的 `list` 和一个包含航班号的 `string`。
该函数应返回一个 `generator`，它会产出 `ticket_number`。

```python
>>> seat_numbers = ['1A', '17D']
>>> flight_id = 'CO1234'
>>> ticket_ids = generate_codes(seat_numbers, flight_id)

>>> next(ticket_ids)
'1ACO12340000'
>>> next(ticket_ids)
'17DCO1234000'
```
