# 简介

`Option`是一个枚举，用来检查函数返回值是否有效。它的定义如下：

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

它属于`haxe.ds`包：

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
