# Entry API

entry API 通常是操作映射结构内容最惯用的方式。不过，对 Rust 来说不太寻常的是，它并没有被形式化为一个 trait：它只是一组类型和方法，实现在标准库的映射类型上。

从根本上说，`map.entry()`方法会提供一个`enum`：

```rust
enum Entry {
    Occupied(_),
    Vacant(_),
}
```

它的实用价值来自在这个枚举上进一步实现的方法。例如，如果你想获取某个键对应的值，并可能修改它，而该值类型的默认值又恰好合适，那么直接这样写即可：

```rust
// `entry` has type `&mut Value` for the value type of the map
let entry = map.entry(key).or_default();
```

对于计数器这类应用来说，这会让事情变得非常简单：

```rust
let counts: HashMap<_, usize> = HashMap::new();
for item in sequence {
    *counts.entry(item).or_default() += 1;
}
```

如果该类型的默认值不适合你的应用，你可以用`or_insert`提供一个自己的常量默认值，或者用`or_insert_with`计算出一个。

在某些情况下，你可能希望在真正插入之前先对已有的值做一次计算。这时`and_modify`可以做到这点。不过这种用法比较少见。`and_modify`更常见的用途是省去解引用的麻烦：

```rust
map.entry(key).and_modify(|v| *v += 1).or_default();
```

偶尔，直接对 entry 进行匹配会更方便。这样做是允许的：

```rust
match map.entry(key) {
    Entry::Occupied(occupied) => println!("removed from the map: {:?}", occupied.remove_entry()),
    Entry::Vacant(vacant) => println!("key not present in map: {:?}", vacant.key()),
}
```

想了解更多，请参阅[`std::collections::hash_map::Entry`](https://doc.rust-lang.org/std/collections/hash_map/enum.Entry.html)和[`std::collections::btree_map::Entry`](https://doc.rust-lang.org/std/collections/btree_map/enum.Entry.html)。
