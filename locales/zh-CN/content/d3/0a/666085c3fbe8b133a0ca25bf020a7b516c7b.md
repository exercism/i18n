# 关于

Lua 中的布尔类型有两个传统的布尔值：`true`和`false`。这些值可以赋给变量，与逻辑运算符（`and`、`or`、`not`）组合，也可以用在条件判断中（例如控制结构里）。

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```
条件判断和逻辑运算符都把布尔值`false`和`nil`视为 false，其他任何值都视为 true。
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```
`and`和`or`都使用*短路求值*，也就是说，只有在必要时才会对第二个操作数求值。所有运算都按照[运算符优先级](https://www.lua.org/manual/5.4/manual.html#3.4.8)求值，其中`not`先于`and`和`or`求值。

由于只有`false`和`nil`被视为 false，其他一切都是 true，Lua 中一个常见的惯用法是：
```lua
x = x or y
```

这等价于：
```lua
if not x then
  x = y
end
```

在函数中这样用很常见：如果形参没有值（即`nil`），就为它赋一个默认值：
```lua
local function hello(name)
  name = name or "World"
  print("Hello " .. name)
end

hello()       --> "Hello World"
hello('Mars') --> "Hello Mars"
```
