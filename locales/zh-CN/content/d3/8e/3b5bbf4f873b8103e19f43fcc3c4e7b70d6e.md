# 说明

从基本原理出发，将用字符串表示的三进制数（例如 '102012'）转换为等价的十进制数。

程序应将表示无效三进制数的字符串视为值 0。

三进制数包含三个符号：0、1 和 2。

三进制数中最后一位的位值是 1。
倒数第二位的位值是 3，倒数第三位的位值是 9，依此类推。

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

如果你的编程语言的标准库中提供了进行此转换的方法，请假装它不存在，自己动手实现。
