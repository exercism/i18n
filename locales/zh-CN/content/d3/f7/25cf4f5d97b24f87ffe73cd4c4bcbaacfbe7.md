# 关于

ColdFusion（CFML）是一门 JVM 脚本语言，语法与 C 或 JavaScript 相似。它通过 JIT 编译成运行在 JVM 上的字节码，但本身是动态、弱类型的，因此开发起来又快又轻松。CF 是一门多范式语言，同时支持经典的面向对象编程和函数式编程。

CFML 还内置了基于标签的模板语言，非常适合开发 Web 应用。它运行在 J2EE 容器中，自带大量库，无需安装许多包就能高效开发。CFML 原生支持 zip 文件、PDF 和 Excel 生成、电子邮件、FTP、HTTP、S3 文件系统、ESAPI 安全库、JDBC 驱动，以及 JSON 和 REST API。

CFML 还能利用任何 Java 项目：把 jar 包放进项目里，就能在代码中直接实例化 Java 对象。想了解基本语法和一等数据类型，可以阅读这份指南：[Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
