# 简介

## Maybe

`Maybe`类型是 Elm 语言中处理可选值的方案。Elm 的很多核心函数的类型签名里都会出现它，因此理解它至关重要。
`Maybe`类型的定义如下：

```elm
type Maybe a = Nothing | Just a
```

在 Elm 的术语里，这叫作“自定义类型”定义。它表示这种类型的值要么是`Nothing`，要么是`Just`某个类型为`a`的值。
要创建`Maybe`值，可以用它的两个构造函数`Nothing`和`Just`中的一个。
要读取`Maybe`里的内容，则要通过模式匹配。

```elm
matthieu : Maybe String
matthieu = Just "Matthieu"

anon : Maybe String
anon = Nothing

sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello matthieu
    --> "Hello, Matthieu!"

sayHello anon
    --> "Hello, World!"
```

`Maybe`模块里还有许多有用的函数，可以用来操作`Maybe`类型。

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
