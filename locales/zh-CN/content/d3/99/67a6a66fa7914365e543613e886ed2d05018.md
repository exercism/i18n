# 简介

## use 表达式

在 Gleam 中，编写和使用高阶函数很常见，也就是把其他函数作为实参的函数。有时同时使用多个高阶函数，代码会变得难以阅读，出现一层又一层的缩进。

例如，下面这个函数调用了几个返回 `Result(Int, Nil)` 的函数，并在四个都成功时把它们的值相加。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  result.try(function1(), fn(a) {
    result.try(function2(), fn(b) {
      result.try(function3(), fn(c) {
        result.try(function4(), fn(d) {
          Ok(a + b + c + d)
        })
      })
    })
  })
}
```

Gleam 的 `use` 表达式让我们不用缩进就能写出这段代码，通常也更容易阅读。

```gleam
import gleam/result

pub fn main() -> Result(Int, Nil) {
  use a <- result.try(function1())
  use b <- result.try(function2())
  use c <- result.try(function3())
  use d <- result.try(function4())
  Ok(a + b + c + d)
}
```

`use` 表达式会把代码块中随后的所有语句收集起来，作为一个回调函数，作为最后一个实参传给这次函数调用。`use` 关键字和 `<-` 符号之间的变量，就是将要传给回调函数的实参的名字。

```gleam
// This use expression
use a <- function(1, 2)
io.println("Hello!")
a

// Is equivalent to this normal function call
function(1, 2, fn(a) {
  io.println("Hello!")
  a
})
```

回调函数可以接收任意数量的实参，也可以一个都不接收。

```gleam
use a, b, c, d <- call_4_function()

use <- call_0_function()
```

要想创建能用 `use` 表达式调用的函数，除了把回调函数作为最后一个实参之外，没有其他特殊要求。

```gleam
pub fn call_twice(function: fn() -> t) -> #(t, t) {
  let first = function()
  let second = function()
  #(first, second)
}
```

Gleam 的 `use` 表达式是一个非常强大的功能，可以用于解决很多问题，但用得过多反而会让代码难以阅读。通常更推荐使用普通的函数调用语法，只有当 `use` 表达式能让代码更易读时才去使用它。
