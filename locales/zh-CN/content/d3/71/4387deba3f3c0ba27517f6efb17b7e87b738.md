# 简介

Pyret 有两个不同的布尔原始值：`true` 和 `false`。
这两个值表示一个判定或条件是否成立。

```pyret
"a" == "a" # true
"a" == "b" # false
```

Pyret 提供了`and`和`or`这两个运算符，可以把布尔值组合起来。

and 运算符在两边的值都为 true 时返回 true，其他组合都返回 false。

```pyret
true and true # true
true and false # true
false and true # false
false and false # false
```

or 运算符在至少一边为 true 时返回 true，两边都为 false 时返回 false。

```pyret
true or true # true
true or false # true
false or true # true
false or false # false
```

`not()`是一个内置函数，可以把 true 变成 false，也可以把 false 变成 true。

```pyret
not(true) # false
not(false) # true
```
