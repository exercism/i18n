# 说明

在这个练习中，你要帮妹妹修改她的学校论文。老师希望标点正确、语法无误，用词也要出色。

你有四个任务，需要整理和修改字符串。

## 1. 把论文标题首字母大写

一篇好论文需要一个格式规范的标题。
实现函数`capitalize_title(<title>)`，它接受一个标题`str`作为形参，并把每个单词的首字母大写。
这个函数应返回一个采用标题式大写格式的`str`。


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. 检查每个句子是否以句号结尾

你想确保论文里的标点完全正确。
实现函数`check_sentence_ending()`，它接受`sentence`作为形参。这个函数应返回一个`bool`。


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. 清理空格

为了让论文看起来更专业，需要去掉多余的空格。
实现函数`clean_up_spacing()`，它接受`sentence`作为形参。
这个函数应去掉句子开头和结尾的多余空白，并返回更新后的新句子`str`。


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. 用同义词替换单词

为了让论文_更出色_，你可以把一些形容词换成它们的同义词。
编写函数`replace_word_choice()`，它接受`sentence`、`old_word`和`new_word`作为形参。
这个函数应把所有出现的`old_word`替换为`new_word`，并返回一个包含更新后句子的新`str`。


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
