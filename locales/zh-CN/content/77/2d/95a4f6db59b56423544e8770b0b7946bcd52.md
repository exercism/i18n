# 简介

## 函数

在 Gleam 中，函数用`pub fn`语法定义。

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

这个函数接收两个实参，类型都是 `Int`，并返回一个 `Int` 类型的值。Gleam 中没有 `return` 关键字，函数中最后一个表达式的值总是会被_隐式返回_。

实参的类型标注和返回类型都是可选的，而且 Gleam 始终会对你的代码做完整的类型检查。通常，Gleam 程序员会为了清晰而给函数加上类型标注，不过如果你愿意，也可以省略。

```gleam
pub fn add(x, y) {
  x + y
}
```

函数可以用`function_name(argument1, argument2)`这种语法来调用。

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## 变量

在 Gleam 中，变量用`let name = expression`语法定义。

```gleam
pub fn main() {
  let count = 1
}
```

变量可以带类型标注来声明。和函数实参一样，这些标注是可选的，不过大多数 Gleam 程序员为了简洁会省略变量的类型标注。

```gleam
pub fn main() {
  let count: Int = 1
}
```

## 字符串字面量

在 Gleam 中，字符串使用双引号书写。

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## 代码注释

注释可以用来给阅读源代码的其他开发者留下说明。Gleam 中的注释是单行的，以`//`开头。

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
