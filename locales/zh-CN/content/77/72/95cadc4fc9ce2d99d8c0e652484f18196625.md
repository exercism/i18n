# 说明

你的朋友 Chandler 打算去世界各地充满异国情调的国家旅行。可惜的是，Chandler 的数学不太好。他很担心在旅途中被货币兑换处骗，所以想让你帮他做一个货币计算器。

## 1. 估算兑换后的价值

定义`exchange-money`，它接收`budget`和`exchange-rate`，并返回兑换后货币的价值。

**注意：**如果你的货币是 USD，想按`1.20`的汇率把 USD 兑换成 EUR，那么`1.20 USD == 1 EUR`。

```factor
127.5 1.2 exchange-money .
! => 106.25
```

## 2. 计算兑换后剩余的货币

定义`get-change`，它接收`budget`（兑换前的预算）和`exchanging-value`（从预算中取出用于兑换的金额）。返回剩余的钱数。

```factor
127.5 120 get-change .
! => 7.5
```

## 3. 计算纸币的价值

定义`value-of-bills`，它接收`denomination`（单张纸币的价值）和`number-of-bills`。返回这些纸币的总价值。

```factor
5 128 value-of-bills .
! => 640
```

## 4. 计算纸币的数量

定义`number-of-bills`，它接收`amount`和`denomination`。返回该金额中能容纳多少张给定面额的*整张纸币*。向下取整，因为不存在零碎的纸币。

```factor
127.5 5 number-of-bills .
! => 25
```

## 5. 计算兑换成纸币后的余额

定义`leftover-of-bills`，它接收`amount`和`denomination`。返回无法以整张纸币形式换回的那部分剩余金额。

```factor
127.5 20 leftover-of-bills .
! => 7.5
```

## 6. 计算兑换后的价值

定义`exchangeable-value`，它接收`denomination`、`budget`、`spread`和`exchange-rate`。

`spread`是以整数形式表示的*百分比*兑换手续费。它需要以分数的形式加到汇率上。如果`1.00 EUR == 1.20 USD`，且`spread`为`10`，那么总汇率就是`1.00 EUR == 1.32 USD`（1.20 的 10% 是 0.12，加到 1.20 上）。

返回在汇率加上 spread 之后新货币的最大价值，向下取整为给定`denomination`的整张纸币。返回的值是一个整数。

```factor
20 127.25 10 1.20 exchangeable-value .
! => 80

5 127.25 10 1.20 exchangeable-value .
! => 95
```

## 7. 安全找零

和`get-change`类似，但如果 Chandler 不小心输入的兑换金额大于他的预算，就返回`0`，而不是负数。定义`safe-change`，它接收`budget`和`exchanging-value`。

```factor
127.5 120 safe-change .
! => 7.5

50 100 safe-change .
! => 0
```

## 8. 按预算封顶

Chandler 正在为一件纪念品讨价还价。定义`cap-spend`，它接收`budget`和`price`，并返回两者中较小的那个，也就是他实际能支付的最高金额。

```factor
100 30 cap-spend .
! => 30

20 30 cap-spend .
! => 20
```
