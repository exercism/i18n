# 推荐学习资源

## 博客

- 微软的 [CommandLine 博客](https://devblogs.microsoft.com/commandline/)是了解 Windows 命令行最新功能的优质资源。

## 社交媒体

- [StackOverflow](https://stackoverflow.com/questions/tagged/batch-file)可用于搜索你的问题，看看它是否已经被解答过。你也可以提问和回答问题。
- [/r/Batch](https://www.reddit.com/r/Batch/)是 Batch 的 subreddit。

## 视频

- [John Hammond 的 Batch 教程](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4)讲解清晰，很适合初学者。
- [Batch-Man](https://www.youtube.com/@batch-man/videos)频道也会定期制作内容，展示各种技巧。

## 课程

- `Free: `[The Ultimate Guide for CMD / DOS / BATCH Programming](https://batch-man.com/courses/batch-from-scratch/)
