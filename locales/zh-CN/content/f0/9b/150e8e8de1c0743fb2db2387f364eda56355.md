# 调试

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] 是一个会返回值的表达式。
Pyret 在一个代码块中只允许有一个表达式，除非外层代码块用`block`标记。
在第二个示例中，给函数声明加上`block`，就可以先打印 42，再返回它。

## `spy` 语句

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

`spy` 语句可以接受一个可选的标签和一个或多个变量，并报告每个变量及其值。
因为`spy`不是表达式，所以可以把它用在代码块中，而不需要用`block`标记外层代码块。
