# 关于

## 可选类型

Swift 使用[可选类型][optionals]，让程序员能够表示某个值可能不存在。可选类型是一种类型，它要么持有一个值，要么是`nil`，后者表示值不存在。使用可选类型时，程序需要先检查值是否存在，解包后才能使用。

在任何类型名末尾加上`?`，就能把它变成可选类型。因此，可选整数的类型是`Int?`，可选字符串的类型是`String?`。定义可选类型的常量或变量并给它们赋值，与处理非可选类型的值完全一样。

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

只要把一个特殊值`nil`赋给可选类型的变量，就表示这个值不存在。`nil`可以用于所有可选类型，但赋给两个不同可选类型的`nil`类型并不相同，既不能互换，甚至不能比较。

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

另外要注意，虽然`nil`可以赋给任何可选类型，却不能赋给非可选类型（即使它实际上并不持有`nil`）。同样，期望非可选类型的方法，如果不先解包，就不能传入可选类型。

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## 使用可选类型

由于可选类型和它的基础类型并不是同一种类型，两者不能以相同的方式使用。例如：`Int("123") + 1`会产生一个编译错误“Value of optional type 'Int?' must be unwrapped to a value of type 'Int'”。这是因为`Int("123")`返回的是可选类型`Int?`，而不是`Int`类型；如果字符串无法转换成整数，结果就是`nil`。要想从转换结果中取出`Int`，必须先对它进行“解包”。

在 Swift 中，最常见的做法是使用[_可选绑定_][optional-binding]的`if-let`和`guard-let`结构：如果值存在，就把解包后的值绑定到给定的名字上，走一条代码路径；如果发现是`nil`，就走另一条代码路径。

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

值得注意的是，`safeNum`变量的类型是`Int`，不是`Int?`。在下面的例子里，`num`的类型是`Int?`，`safeNum`的类型是`Int`。

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

这种_可选绑定_很重要，因为它把可选类型从值上解包（也就是“去掉”）了，让这个值可以当作非可选值使用。如果只是做一个条件判断，检查这个值是不是`nil`，那么它的类型仍然是可选类型：

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

在需要提前返回的场景下，也可以使用`guard-let`：

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## 比较可选类型

注意，即使一对可选类型的基础类型可以用标准比较运算符比较，这些可选类型本身也不能比较。只能检查它们是否相等。如果两个可选类型都是`nil`，或者它们包裹的值在各自的基础类型下相等，那么这两个可选类型就相等。

不过，也可以编写代码，对两个可选值做自定义的比较。下面是一个`switch`语句的例子：只有当两个可选值都非 nil、并且第一个值小于第二个值时，它才会返回`true`。为此，它使用了_可选模式_`varName?`，这种模式只匹配非 nil 的可选值，并把可选值里面的值绑定到名字`varName`上。

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```

## nil 合并

还有一种解包方式：当遇到`nil`时，可以使用一个[备用值][fallback]。这可以通过_nil 合并运算符_`??`来实现。假设`x`是`Int?`，如果写`let y = x ?? 0`，Swift 就会检查 x 是不是`nil`。如果不是，它就会解包`x`，把解包后的值赋给`y`；而如果`x`_确实_是`nil`，它就会把 0 赋给`y`。

因为`x ?? y`只是`x != nil ? x! : y`的简写，所以如果`x`不是 nil，表达式`y`根本不会被求值。

最后要注意，nil 合并运算符是右结合的，不了解这一点的人可能会对结果感到意外。

```swift
let k = 42 ?? 0 + 1    // returns 42
let j = nil ?? 0 + 1   // returns 1
```

想进一步了解 nil 合并运算符，可以阅读 [A Tour of Swift: Nil-Coalescing Operator][nil-coalescing]。
