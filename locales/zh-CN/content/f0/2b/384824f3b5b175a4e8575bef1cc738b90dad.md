# 提示

## 通用

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。

## 1. 记录不同的货币

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。
- 你可以把相关的字符串放在 .rodata 段或 .data 段中，再根据枚举的值来分派它们。
- 枚举会被隐式转换成一个整数，通常是 32 位大小。

## 2. 检查汇率

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。
- 每个枚举元素的值，就是它在 `value_in_US_dollars` 所引用的 C 数组中的下标。
- 在 C 中，下标从偏移量 0 开始，而且是针对元素而非字节大小来计数的，所以下标 `2` 总是指向第三个元素。
- 每个 `double` 占用 8 字节空间。
- 用外币的美元价值除以内币的美元价值，就能算出汇率。

## 3. 计算钞票的价值

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。
- 钞票的价值可以用 `denomination` 乘以 `number_of_bills` 来计算。
- `unsigned long long` 是一种无符号 64 位整数。
- `unsigned short` 是一种无符号 16 位整数。
- `uint64_t` 是一种无符号 64 位整数。

## 4. 计算钞票的数量

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。
- 在把 `amount` 转换成整数之前，你需要先把它向下取整。
- `float` 是一种 32 位浮点数。
- 你可以使用 [roundss][round]，把 `1` 作为第三个操作数，对一个 32 位浮点数向下取整。
- `unsigned int` 是一种无符号 32 位整数。

## 5. 计算兑换后的价值

- 大多数双操作数或三操作数指令都要求所有操作数大小相同。
- 在把 `spread` 除以 `100` 得到百分比之前，你需要先把它转换成浮点数。
- 得到百分比之后，把它乘以 `exchange_rate`，就得到了点差的_费用_。
- _实际汇率_等于汇率加上点差费用。
- 用预算除以实际汇率，就能得到最多可以兑换的金额。
- 你可以复用之前实现的 `get_number_of_bills` 函数，来得到你需要使用的钞票数量。
- `uint32_t` 是一种无符号 32 位整数。

[round]: https://www.felixcloutier.com/x86/roundss
