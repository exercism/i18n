# 分析器

Exercism 的分析器会自动评估学生提交的内容，并给出导师式的点评。

## 为分析器做贡献

每种语言都有自己的分析器，用该语言编写。
网站负责在分析器与学生提交的内容之间做协调。

每个分析器都位于 Exercism 的 GitHub 组织下，仓库名为 `<track_slug>-analyzer`（例如 [`exercism/ruby-analyzer`](https://github.com/exercism/ruby-analyzer)）。
现有的分析器可以在[这里](https://github.com/search?q=topic%3Aexercism-analyzer&type=repositories)查看。

如果你想参与协助某个现有的分析器，可以在它的仓库里提一个 issue，问问有哪些地方需要帮忙。
如果你想为目前还没有分析器的语言创建一个，请按照[创建分析器](/docs/building/tooling/analyzers/creating-from-scratch)的说明操作。
