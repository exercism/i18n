# 返回

在 Crystal 中，方法里的最后一个表达式会返回它的值。
不过，有时你需要在最后一个表达式之前返回一个值。
为此，你可以使用`return`关键字，它会返回紧随其后的表达式的值。
写在`return`关键字之后的代码不会被执行。

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
当方法中的最后一个表达式就是要返回的值时，应省略`return`关键字。
~~~~
