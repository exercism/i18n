# 说明

在这个练习中，你将编写代码来分析汽车工厂装配线的生产情况。 
装配线的速度范围从 `0`（关闭）到 `10`（最大）。

在最低速度（`1`）时，每小时生产 `221` 辆汽车。 
产量随速度线性增长。 
因此速度设为 `4` 时，每小时应生产 `4 * 221 = 884` 辆汽车。 
不过，速度越高，生产出有缺陷汽车的可能性就越大，而这些次品只能被丢弃。 

你一共有三个任务。
每个需要实现的函数都接收一个整数形参，即装配线的速度。

## 1. 计算成功率

实现 `success_rate()` 方法，计算给定速度下生产出无错误产品的概率。 
下表展示了速度如何影响成功率：

- `0`：0% 成功率。
- `1`到`4`：100% 成功率。
- `5`到`8`：90% 成功率。
- `9`：80% 成功率。
- `10`：77% 成功率。

```julia-repl
julia> success_rate(10)
0.77
```

## 2. 计算每小时的生产率

实现 `production_rate_per_hour()` 方法，计算装配线每小时的生产率，并考虑其成功率。

```julia-repl
julia> production_rate_per_hour(6)
1193.4
```

注意，返回的值是浮点数。

## 3. 计算每分钟生产的合格产品数量

实现 `working_items_per_minute()` 方法，计算每分钟生产多少辆合格汽车：

```julia-repl
julia> working_items_per_minute(6)
19
```

注意，返回的值是整数：不完整的产品不计入其中。
