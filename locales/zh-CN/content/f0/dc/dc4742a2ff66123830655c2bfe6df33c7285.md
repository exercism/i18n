# 简介

在 Factor 中，用`: name ( stack-effect ) body ;`定义一个新的单词。主体是一串单词；调用你新建的这个单词，就会按顺序运行它们。

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

当一个例程越写越大，你可以（也应该）把它*分解*：把一组单词抽成更小的具名单词，每个只做一件事。这门语言的名字就来源于此。

## 词汇

每个`.factor`文件都用`IN:`声明一个词汇。一个词汇里的单词可以调用另一个词汇里的单词，只要在`USING:`中把那个词汇列出来。

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

目录结构遵循带点的词汇名：词汇`my-vocab`位于`my-vocab/my-vocab.factor`；词汇`my-vocab.helpers`位于`my-vocab/helpers/helpers.factor`。Factor 的加载器会沿着`USING:`声明递归跟进，按需加载每个词汇。
