## 数字与数字运算符

所有**数字**，无论是否为整数，都是 IEEE754 双精度浮点数。`jq`的实现使用的是 C 的 `double` 类型。这把我们限制在 53 位的精度内。

数字可以使用常见的运算符：

- 算术：`+`、`-`、`*`、`/`、`%`
- 比较：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 标准[数学函数][man-math]

  对于单输入函数，把值通过管道传给该函数

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  对于双输入函数，函数会忽略输入，而期望把这两个输入作为实参传入

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  函数实参的分隔符是分号，不是逗号。

~~~~exercism/caution
说“这把我们限制在 53 位的精度内”是什么意思？

来看一个示例：

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

看起来没问题。那如果我们把指数调大呢？

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

这两个数字不应该相等。
这就是“精度丢失”的样子。
这意味着 `jq` 无法处理任意大的数字。
~~~~

## 条件表达式

`jq`使用 [`if-then-else` 表达式][if-then-else]来表示**条件表达式**。作为一个_表达式_，它被放在管道中。

它的语法是：`if CONDTITION then TRUE_EXPR else FALSE_EXPR end`。

`else` 子句是可选的。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

额外的条件使用 `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
