# 运行测试

在终端里，切换到练习的根目录，然后运行测试：

```bash
$ mix test
```

这会执行 `test` 子文件夹里的测试文件，也就是以 `_test.exs` 结尾的文件。

文档：

* [`mix test`：Elixir 的测试执行工具](https://hexdocs.pm/mix/Mix.Tasks.Test.html)
* [`ExUnit`：Elixir 的单元测试库](https://hexdocs.pm/ex_unit/ExUnit.html)

## 待处理的测试

在练习的测试套件中，除了第一个测试之外，其余测试都被标记为跳过。

当一个测试通过后，你可以用 `#` 号注释掉对应的 `@tag :pending`，从而不再跳过下一个测试。

例如：

```elixir
# @tag :pending
test "shouting" do
  assert Bob.hey("WATCH OUT!") == "Whoa, chill out!"
end
```

如果你想一次运行所有测试，可以在 `mix test` 命令上使用 `--include` 标志，把所有被跳过的测试也包含进来：

```bash
$ mix test --include pending
```

或者，你也可以注释掉 `test/test_helper.exs` 文件中的 `ExUnit.configure` 那一行，从而启用所有测试。

```elixir
# ExUnit.configure(exclude: :pending, trace: true)
```

## 实用的 `mix test` 选项

* `test/<FILE>.exs:LINENUM`：只运行单个测试，即 `<FILE>.exs` 中定义在第 `LINENUM` 行的那个测试
* `--failed`：只运行上一次运行时失败的测试
* `--max-failures`：当测试失败数达到这个数量时，测试套件就停止执行测试
* `--seed 0`：关闭随机化，这样一个文件中的测试总是按照它们定义的顺序运行
