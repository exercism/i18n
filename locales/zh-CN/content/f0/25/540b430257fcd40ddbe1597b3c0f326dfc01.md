# 关于

在 Elm 中，[`List`][lists]是一个不可变的集合，包含零个或多个相同类型的值。由于数组是不可变的，一旦数组被创建，它的值就永远不会改变。Elm 中的数组有一个_头部_（第一个元素）和一个_尾部_（第一个元素之后的所有内容）。数组的尾部本身也是一个数组。

数组的类型注解可以如下定义：

```elm
List String --> a list of String
List Int --> a list of Int
```

数组可以如下定义：

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

向数组添加元素最常见的方式是使用 `::`（cons）运算符：

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

数组可以使用 `++` 运算符或 `List.append` 追加：

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

数组的操作通过 [`List`模块][list-module]中定义的函数和运算符完成。

```elm
List.length [ 7, 8 ] --> 2
```

任何看似会修改数组的函数或运算符（例如添加元素），实际上都会返回一个新的数组。不过性能通常不是问题，因为数组的实现会避免不必要的分配或复制。

数组也可以使用[模式匹配][list-destructuring]来处理。

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
