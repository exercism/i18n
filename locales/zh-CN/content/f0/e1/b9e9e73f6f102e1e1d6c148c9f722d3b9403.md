# 说明

在为朋友们准备烤饼干时，你发现食谱中有些计量单位需要换算。由于你只熟悉公制，你需要想个办法，把常见的美国烘焙计量单位换算成毫升（mL），方便自己使用。

解答时请使用这张换算表：

| 要换算的单位 | 体积 | 毫升（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| US cup          | 1      | 240                 |
| US fluid ounce  | 1      | 30                  |
| US teaspoon     | 1      | 5                   |
| US tablespoon   | 1      | 15                  |

作为一名正在成长、有天赋的程序员，你决定用毫升作为中间单位，这样就能方便地把表中任意一种单位换算成任意另一种（哪怕是换算成它自己）。

## 1. 从体积对中取出数值部分

实现`getVolume`函数。给定一个体积对元组，它应该只返回其中的数值部分。

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. 把体积对换算成毫升

实现`toMilliliter`函数。给定一个体积对元组，它应该使用换算表把体积换算成毫升。

使用多个函数子句和模式匹配，为每一种单位分别创建函数。用来表示各种单位的原子是：`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`。
把换算结果包在元组里返回。

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. 把毫升体积对换算成其他单位

实现`fromMilliliter`函数。给定一个体积对元组和目标单位，它应该使用换算表把体积换算成目标单位。

使用多个函数子句和模式匹配，为每一种单位分别创建函数。用来表示各种单位的原子是：`Cup`、`FluidOunce`、`Teaspoon`、`Tablespoon`、`Milliliter`。

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. 在任意单位之间换算

实现`convert`函数。给定一个体积对元组和目标单位，它应该把给定的体积换算成目标单位。

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
