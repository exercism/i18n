# 简介

## 数组

在 Common Lisp 中，和其他语言一样，数组是一组通过整数下标访问的元素。
元素的类型可以各不相同。
数组可以是多维的（不只是 1 维）。

### 创建

`make-array` 可以用来创建数组。
它有很多选项，但较简单的用法既可以把 N 维数组的所有元素都初始化为同一个值，也可以用另一个序列（比如列表）中的值来初始化数组。
它的第一个参数是一个列表，描述每个维度的大小。

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

（注意 N 维数组在打印时会带上维数。）

也可以用数组打印时所用的格式来创建数组：

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### 访问元素

要访问向量的元素，用`aref`，下标从 0 开始。
提供的下标数量必须与数组的秩一致。

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
