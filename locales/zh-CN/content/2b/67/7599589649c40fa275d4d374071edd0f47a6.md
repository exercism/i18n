# 说明

Elena 是一家报纸工厂新来的质量经理，她请你写一小段软件，用来监控生产车间。

## 1. 定义一个自定义错误

使用`ERROR:`解析词定义一个错误元组类`machine-error`。它不需要任何槽位。

```factor
machine-error   ! throws a fresh machine-error
```

## 2. 检查湿度

定义`check-humidity`。它从栈上取一个湿度读数，如果该读数严格大于`70`，就`throw`s字符串`"humidity too high"`。否则，不返回任何值。

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. 检查温度

定义`check-temperature`。它取一个温度读数，如果该读数严格大于`500`，就`throw`s字符串`"temperature too high"`。否则，不返回任何值。

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. 监控机器

定义`monitor`，让它从栈上取一个湿度和一个温度，并运行这两项检查。如果任意一项检查`throw`s，`monitor`应该改为抛出一个新的`machine-error`。如果两项都通过，`monitor`不返回任何值。

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. 监控一批读数

定义`monitor-batch`，让它取一个由`{ humidity temperature }`读数组成的数组，并返回其中有多少个会失败（即有多少个会让`monitor`抛出异常）。

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
