# 关于

哈希集合在底层借助哈希实现了 [`sets`][sets] [协议][set-protocol]，其平均插入、查找和删除的复杂度都是 O(1)。它们可以原地修改，这让它们非常适合图遍历中的*已访问集合*模式。

```factor
USING: hash-sets kernel sets ;

HS{ } clone                   ! fresh empty mutable set
"NS-1024" over adjoin         ! insert (no-op if already present)
"NS-1024" over in? .          ! => t  (membership test)
"WB-203" over adjoin
over cardinality .            ! => 2
"NS-1024" over delete         ! remove
over cardinality .            ! => 1
```

| 单词          | 效果                                    |
|---------------|-------------------------------------------|
| `HS{ }`       | 空的哈希集合字面量（共享的，要 `clone` 它！） |
| `>hash-set`   | `( seq -- set )`，从序列构建一个新集合（会去重） |
| `adjoin`      | `( elt set -- )`，破坏性插入     |
| `in?`         | `( elt set -- ? )`，成员判断           |
| `delete`      | `( elt set -- )`，破坏性删除     |
| `cardinality` | `( set -- n )`，元素个数       |
| `null?`       | `( set -- ? )`，集合为空时为 true |
| `members`     | `( set -- seq )`，以序列形式枚举  |
| `union`       | `( set1 set2 -- set )`                    |
| `intersect`   | `( set1 set2 -- set )`                    |
| `diff`        | `( set1 set2 -- set )`                    |
| `set-like`    | `( set exemplar -- set' )`，把 `set` 强制转换为 `exemplar` 所属的类 |

要用已有的数据构建集合，`>hash-set` 能一步把任意序列转换过来，同时丢弃重复项，`{ 2 3 2 5 } >hash-set` 会得到 `HS{ 2 3 5 }`。它相当于用反复调用 `adjoin` 来扩张集合的批量版本。

关于 `in?` 与 `member?`（来自 `sequences`）还有一个微妙之处：两者都判断成员关系，但 `member?` 会对序列做线性扫描，而 `in?` 则会分派到集合类型对应的协议方法，对 `HS{ }` 而言就是一次哈希查找。当你的“已访问”容器里的条目多于几个时，就该改用 `in?`。

`null?` 不必计算完整的 `cardinality` 就能回答“这个集合为空吗？”，它是判断“还有东西要处理吗？”的自然守卫。对于用集合保存的工作列表，`[ set null? ] [ … ] until` 会将它一直排空到空为止。

## 与哈希表搭配使用

用 `HS{ }` 表示“X 访问过了吗？”，与用 `H{ }` 表示“X 的邻居是谁？”，两者是天然的一对。一个教科书式的深度优先搜索就是：

```factor
visited adjoin
stack push
[ stack empty? ] [
    stack pop dup neighbours-quot call [
        dup visited in? [ drop ] [
            [ visited adjoin ] [ stack push ] bi
        ] if
    ] each
] until
```

已访问集合负责去重；栈串起边界节点（通过 `push`/`pop` 实现后进先出）；邻居映射（一个哈希表）提供图的数据。对于可达性问题，访问顺序并不重要，这正是用向量充当栈就足够的原因，而同样形状的真正广度优先搜索则会把向量换成 [`<dlist>`][dlist]，并改为从队首出队。
