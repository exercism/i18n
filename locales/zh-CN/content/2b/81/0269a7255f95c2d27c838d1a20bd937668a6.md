# 关于

Lua 用两种方式表示数字：64 位整数和双精度浮点数。

~~~exercism/note
在 5.3 版之前，Lua 用双精度浮点数格式表示所有数字。
~~~

数字可以带可选的小数部分，也可以带可选的十进制指数。
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

带小数点或指数的数字会被视为浮点数，不带这两种东西的则被视为整数，但两者的类型都是 'number'。
```lua
type(1)         --> number
type(2.0)       --> number
```

如果要区分浮点数和整数，可以使用`math`模块的`type`函数。
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## 比较

值相同的整数和浮点数比较时相等：
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## 算术运算

Lua 支持常见的一组算术运算符：加法、减法、乘法、除法和取负。此外还支持向下取整除法、求模和求幂。

### 加法、减法、乘法和取负

如果两个操作数都是整数，运算结果就是整数。浮点数也是如此。
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

如果一个操作数是浮点数，其余整数也会被转换成浮点数，运算结果就是浮点数。
```lua
1.0 + 2   --> 3.0
```

### 除法

除法始终以浮点数进行，结果也是浮点数。
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

除以零会得到`inf`或`-inf`。零除以零会得到`-nan`。
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### 向下取整除法

如果需要整数结果，可以使用向下取整除法。向下取整除法总是把商向负无穷方向取整，从而保证对所有操作数都得到整数结果。

~~~exercism/note
在 5.3 版之前，Lua 没有用于向下取整除法的算术运算符。
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

向下取整除法遵循与加法、减法、乘法和取负运算符相同的规则：如果两个操作数都是整数，运算结果就是整数，否则结果是浮点数。

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

使用向下取整除法除以零时，Lua 会抛出错误。
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### 求模

求模用于得到两个操作数相除的余数。
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### 求幂

和除法一样，求幂也以浮点数进行，结果也是浮点数。
```lua
10 ^ 2    --> 100.0
```

## 优先级

所有运算都按照[运算符优先级](https://www.lua.org/manual/5.4/manual.html#3.4.8)求值。可以使用括号改变表达式的优先级。

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## 取整

`math`模块提供三个取整函数：`floor`向负无穷方向“向下”取整，`ceil`向正无穷方向“向上”取整，`modf`向零取整。

### `math.floor`

`floor`向负无穷方向取整。
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil`向正无穷方向取整。
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf`向零取整。该函数返回取整后的值以及数字的小数部分，小数部分始终是浮点数。
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## 转换

如果要把整数转换成浮点数，可以给它加上`0.0`。
```lua
1 + 0.0         --> 1.0
```

如果要把浮点数转换成整数，可以把它与零做按位或，或者使用`math`模块的`tointeger`函数。
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

如果数字无法转换成整数，或运算符会抛出错误，而`tointeger`函数会返回`nil`。
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## 十六进制

和许多其他编程语言一样，Lua 支持十六进制数字，只需在它们前面加上`0x`；但和许多其他编程语言不同的是，Lua 还支持浮点十六进制数。这类数字可以带小数部分和二进制指数，以 'p' 或 'P' 为前缀。
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
