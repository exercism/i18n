# 说明

在这道练习中，你要帮助高中情侣在社交媒体上表白：用他们姓名缩写生成一个 ASCII 爱心：

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. 获取名字的首字母

实现`HighSchoolSweetheart::firstLetter`函数。
它接收一个名字，返回这个名字的首字母。
它应该清理掉名字中多余的空白字符。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->firstLetter("Jane");
# => "J"
```

## 2. 把首字母格式化为缩写

实现`HighSchoolSweetheart::initial`函数。
它接收一个名字，返回它的大写首字母，后面加一个点。
记得复用你在上一步定义的`HighSchoolSweetheart::first_letter`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initial("jane");
# => "J."
```

## 3. 把全名拆分成名字和姓氏

实现`HighSchoolSweetheart::initials`函数。
它接收一个全名，全名由名字和姓氏组成，中间用空格分隔，然后返回姓名缩写。
记得复用你在上一步定义的`HighSchoolSweetheart::initial`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->initials("Jane Doe");
# => "J. D."
```

## 4. 把姓名缩写放进爱心里

实现`HighSchoolSweetheart::pair`函数。
它接收两个全名，返回放在 ASCII 爱心里的姓名缩写。
记得复用你在上一步定义的`HighSchoolSweetheart::initials`。

```php
<?php

$sweetheart = new HighSchoolSweetheart();
$sweetheart->pair("Blake Miller", "Riley Lewis")
# => """
#      ******       ******
#    **      **   **      **
#  **         ** **         **
# **            *            **
# **                         **
# **     B. M.  +  R. L.     **
#  **                       **
#    **                   **
#      **               **
#        **           **
#          **       **
#            **   **
#              ***
#               *
# """
```
