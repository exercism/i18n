# 安装

运行这些练习，你只需要安装 [CommandBox CLI](https://commandbox.ortusbooks.com/getting-started-guide) 和 [Java 8](https://java.com/en/download/)。CommandBox CLI 在 Mac、Linux 和 Windows 上都可以使用，安装指南可以在这里找到：

[https://commandbox.ortusbooks.com/setup/installation](https://commandbox.ortusbooks.com/setup/installation)

如果你是 Mac 上的 Homebrew 用户，安装 CommandBox CLI 的一个例子是：

```bash
brew install commandbox
```

安装好 CLI 之后，你就可以在 REPL 里试试了：

```bash
box repl
```

你也可以直接执行 .cfm 页面：

```bash
box exec myTest.cfm
```

甚至可以在硬盘的任意目录中启动一个 Web 服务器：

```bash
box server start
```

CommandBox 还有一个交互式 shell，具备增强的 Tab 补全功能，运行速度也更快。只要不带任何参数运行`box`可执行文件，就能进入。

```bash
box
```
