# 运行测试

在终端中先切换到练习的基础目录，然后运行测试：

```bash
$ gleam test
```

这会执行`test`子文件夹中的测试文件，即文件名以`_test.gleam`结尾的文件。

## 测试函数

测试使用[自定义测试框架](https://github.com/exercism/gleam-test-runner/tree/main/runner)。`test`目录中任何以`_test`结尾的公开函数都会被测试框架视为一个测试。

例如：

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
