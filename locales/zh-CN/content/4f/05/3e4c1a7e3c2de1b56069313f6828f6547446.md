在 Haxe 中手动拼接字符串虽然可行，但 Haxe 支持[字符串插值][string-interpolation]，它提供了一种更简短、更便捷的语法：

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

如上所示，插值字符串用单引号字符（`'`）括起来，这一点与普通的[字符串][strings]不同；此外，插值字符串还可以包含以美元符号（`$`）标示的特殊标识符，这些标识符会触发插值。

使用 `${expr}` 可以嵌入完整的表达式，其中 `expr` 是任何合法的 Haxe 表达式：

```haxe
trace('the next number is ${x + 1}');
```

如果确实想输出美元符号本身，可以用 `$$` 来抑制插值：

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

最后要注意，字符串插值是一项编译期特性，对运行时性能没有任何影响。在内部，Haxe 编译器生成的代码与手动拼接等价。

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
