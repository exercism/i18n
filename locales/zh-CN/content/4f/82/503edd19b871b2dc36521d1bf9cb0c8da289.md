# 简介

Python 有两种循环结构。
`while`循环用于_不确定的_（不计数的）迭代，`for`循环用于_确定的_（计数的）迭代。
关键字`break`、`continue`和`else`有助于自定义循环的行为。
`range(<length of sequence>)`和`enumerate(<iterable>)`函数有助于循环计数和下标处理。


`while`循环并没有指定要执行的循环次数，只要`loop`表达式或“测试”求值为`True`，循环就会一直继续下去。
当循环表达式求值为`False`时，循环就会终止。

```python
while expression:
    set_of_statements
```

`for`循环会遍历任意序列中的值，当没有更多值返回时便终止。
当没有数据结构或其他可迭代对象可供循环时，`range(<length of sequence>)`函数会提供一个`loop`计数器或序列。

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
