# 提示

## 1. 三个节目

- 类的头部在`<`后面给出抽象类的名字：
  `class JUGGLING < $ACT is`。
- 每个节目都必须同时定义`name`和`minutes`，而且要和抽象类里声明的一模一样。少定义其中一个，编译器就会报错并指出是哪个例程。
- 每个节目还需要一个`create`，否则`#JUGGLING`就没有东西可以调用。对其中两个来说，`create : SAME is return new; end;`就是全部内容。
- `TRAPEZE`需要一个表示高度的属性，还需要一个接收该属性的`create`。
- `+`会把数字拼接到字符串上，所以`"Trapeze at " + height + "m"`不需要做任何转换。

## 2. 演出

- 实参类型是`ARRAY{$ACT}`。正因如此，一个数组才能装下全部三种节目。
- `acts.elt!`会返回一个`$ACT`。在它上面调用`.minutes`，就会自动运行正确的那个。这就是分派，也是这道练习的重点。不需要做任何检查，也不用写`typecase`。
- `billing`在循环里构建字符串，所以要用`FSTR`；而`", "`要放在除第一个名字之外的每个名字前面。
- `longest`会记录到目前为止最好的节目。把最佳分钟数从`-1`开始，第一个节目就总能胜过它，这样即使演出是空的也无需特殊处理：名字会保持为`""`。
