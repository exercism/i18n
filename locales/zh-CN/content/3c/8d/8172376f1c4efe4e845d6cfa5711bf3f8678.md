# 简介

方法是一种带有特殊_接收者_实参的函数。
接收者出现在它自己的实参列表中，位于`func`关键字和方法名之间。

```go
func (receiver type) MethodName(parameters) (returnTypes) {
}
```

只有当接收者的类型与方法定义在同一个包里时，你才能为它定义方法。

```go
package person 

type Person struct {
	Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}
```

结构体上的方法可以通过点号表示法调用。

```go
p := Person{Name: "Bronson"}
fmt.Println(p.Greetings())
// Output: Welcome Bronson!
```

注意我们在`Person`实例`p`上调用方法`Greetings()`的方式。
这和在面向对象编程语言中调用方法的方式完全一样。

记住：方法只是一个带接收者实参的函数。
方法有助于避免命名冲突：因为方法绑定到特定的接收者类型，所以你可以在不同的类型上使用相同的方法名。

```go
import "math"

type rect struct {
	width, height int
}
func (r rect) area() int {
	return r.width * r.height
}

type circle struct {
	radius int
}
func (c circle) area() float64 {
	return math.Pow(float64(c.radius), 2) * math.Pi
}
```

接收者有两种：值接收者和指针接收者。

到目前为止我们看到的所有方法都使用值接收者，这意味着它们收到的是传给方法的值的副本，也就是说，在方法内部对接收者所做的任何修改对调用方都不可见。

你可以用指针接收者来声明方法，以便修改接收者所指向的值。
做法是在类型名前面加一个`*`。
例如，对于`rect`类型，指针接收者会声明为`*rect`。
这类修改对方法的调用方也是可见的。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10
```
