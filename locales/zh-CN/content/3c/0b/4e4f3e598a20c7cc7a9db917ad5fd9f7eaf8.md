# 简介

对象可以通过设置_实例变量_来保存自己的状态：在变量名前加上`@`，就创建了一个实例变量。

```ruby
@name = 2
```

对象通常在`initialize`方法中设置初始状态，当对类调用`new`时，这个方法会被自动调用。

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

`initialize`方法也可以接收实参，这样每个实例都能以自定义的状态开始：

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

请把_实例变量_视为私有的，外部不能对它进行读取和写入。获取和设置实例变量应该使用_实例方法_：

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
