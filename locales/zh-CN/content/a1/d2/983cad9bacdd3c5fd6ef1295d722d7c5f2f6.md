# 简介

## 定义变量

定义变量就是把一个值赋给一个名字。在 Scala 中，变量分为两种：val 和 var。

`val` 是不可变的，因此第一次赋值之后，它的值就不能再改变了：

```scala
val numberTen = 10

numberTen = 11
// --> raises a compile error "reassignment to val"
```

相比之下，`var` 可以重新赋值为同类型的新值：

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala 是一门静态类型语言，这意味着所有东西在编译时都有类型。定义变量时，既可以显式指定它的类型，也可以让 Scala 编译器根据赋给它的值来推断类型（这称为类型推断）。因此，下面两种变量定义是等价的：

```scala
val explicitNumber: Int = 10; // Explicitly typed
val implicitNumber = 10; // Implicitly typed
```

变量一旦定义，它的类型就永远不能改变。

```scala
var count = 1; // Assigning an initial value of type Int
count = 2;     // Updating to new value is possible, because it is defined as var

count = false;
// --> raises a compile error "type mismatch"
```

## 在类中定义方法

Scala 是一门_面向对象语言_，所有方法都必须定义在_类_中。使用 `class` 关键字来定义类。

```scala
class Calculator {
  // ...
}
```

在类中，定义方法要以关键字 `def` 开头，后面跟一个名字。每个方法可以有零个或多个形参，它们用逗号分隔，列在圆括号内。所有形参都必须显式标注类型，形参没有类型推断。在形参列表之后，再用一个冒号分隔，定义方法的返回类型。

方法定义后面跟一个 `=` 号，开始方法体。在下面的例子中，方法体包含两条语句，它们用花括号包围。

方法会返回最后一个表达式的值，在这里，`add` 方法返回变量 `sum` 的值：

```scala
class Calculator {
  // long form
  def add(x: Int, y: Int): Int = {
    val sum = x + y
    sum
  }
}
```

为了提高可读性，可以做一些改进来缩短这个方法：

- 由于变量 `sum` 只在返回值时被访问一次，可以省略它
- 只包含一条语句的方法不需要花括号
- 方法的返回类型可以像变量类型那样被推断出来

这样就得到了下面这个功能相同的一行方法：

```scala
class Calculator {
  // shortened form
  def add(x: Int, y: Int) = x + y
}
```

## 实例化类和调用方法

调用方法分两步：先创建一个类的实例，然后在该实例上用实参调用这个方法：

```scala
val calculator = new Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## 注释

Scala 支持两种注释：单行注释和多行注释：

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
