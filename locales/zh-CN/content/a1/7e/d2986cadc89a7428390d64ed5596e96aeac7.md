# 测试

我们使用标准库中的 [PonyTest](https://stdlib.ponylang.io/pony_test--index/) 来编写测试，检验你提交的解答。要测试你提交的解答，需要编译并运行你的代码。

例如，你测试 “Hello World” 时的会话可能像这样：

```text
[red@apophenia:~/exercism/pony/hello-world]$ ponyc
Generating
 Reachability
 Selector painting
 Data prototypes
 Data types
 Function prototypes
 Functions
 Descriptors
Optimising
Writing ./hello-world.o
Linking ./hello-world

[red@apophenia:~/exercism/pony/hello-world]$ ./hello-world 
1 test started, 0 complete: hello-world/HelloWorld started
1 test started, 1 complete: hello-world/HelloWorld complete
---- Passed: hello-world/HelloWorld
----
---- 1 test ran.
---- Passed: 1
```
