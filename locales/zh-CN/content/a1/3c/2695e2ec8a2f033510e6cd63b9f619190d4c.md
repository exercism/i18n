# 补充说明

## 示例输入

```j
  INPUTS=: 2 ; 1 0 0 1 0 1 ; 10
```

这意味着你的输入是：
```
  0{INPUTS NB. is the input base.
  1{INPUTS NB. is the digits.
  2{INPUTS NB. is the output base.
```
## 处理无效输入

如果任何一个输入值无效，你的动词应返回一个`empty`（例如`0$0`或`''`）。

### 示例

- 如果*输入进制*小于 2：
    ```j
      '' -: rebase 10 ; 0 0 0 0 ; 1
    ```

- 如果*输出进制*小于 2：
    ```j
      '' -: rebase 1 ; 0 0 0 0 ; _7
    ```

- 如果*数字*包含大于或等于输入进制的值：
    ```j
      '' -: rebase 10 ; 1 0 2 0 ; 2
    ```
