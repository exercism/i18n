# 说明

你要帮助高中情侣在社交媒体上表达爱意：用他们的名字首字母生成一个 unicode 爱心：

```
❤ J.  +  M. ❤
```

## 1. 清理名字

定义 `cleanupname`，它从栈上取出一个名字。把每个 `-` 替换成空格，然后去掉开头和结尾的空白字符。

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. 取出名字的第一个字母

定义 `firstletter`，它从栈上取出一个名字。复用上一个任务中的 `cleanupname`，然后取出结果的第一个字符，并以只含这一个字符的字符串返回。

```factor
"Jane" firstletter .
! => "J"
```

## 3. 把第一个字母格式化为缩写

定义 `initial`，它从栈上取出一个名字。复用上一个任务中的 `firstletter`，把它转换成大写，然后追加一个 `.`。

```factor
"Robert" initial .
! => "R."
```

## 4. 把缩写放进爱心里

定义 `couple`，它从栈上取出两个名字。对每个名字都复用上一个任务中的 `initial`，然后拼出结果：

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
