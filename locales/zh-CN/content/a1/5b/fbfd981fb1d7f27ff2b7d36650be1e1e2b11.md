# 测试

## 运行测试

完成[安装步骤][test-installation-steps]后，你就可以从任意练习目录（例如 `~/exercism/gdscript/two-fer`）开始，运行脚本（脚本在上一级目录，即 `../`）来在本地测试你对该练习提交的解答：

```sh
../test-local-gdscript-solution.sh
```

## 解答练习

解答练习意味着让它的所有测试都通过。

为了帮你上手，每个练习都附带一个以该练习命名的 GDScript 文件（例如 `exercism/gdscript/two-fer/two_fer.gd`）。
你可以把这个文件作为构建提交的解答的起点。
你可以按需随意修改它，但测试要求函数名保持最初提供的样子。

[test-installation-steps]: https://exercism.org/docs/tracks/gdscript/tests
