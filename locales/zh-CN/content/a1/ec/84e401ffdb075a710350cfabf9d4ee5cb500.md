# 介绍

Gleam 标准库在`gleam/queue`模块中实现了一个`Queue`类型。它与`List`类型类似，但有几个关键区别：

- `Queue`类型没有可以用来构造队列或对队列进行模式匹配的字面量语法。
- 队列的前面和后面都可以高效地添加和移除元素，而`List`类型只能在前面高效地添加和移除元素。

大多数情况下，你会想用`List`类型，但当你需要从集合的末尾添加和移除元素时，`Queue`类型是个不错的选择。

队列可以用`queue.new`和`queue.from_list`函数来创建：

```gleam
let empty = queue.new()
let one_to_four = queue.from_list([1, 2, 3, 4])
```

元素可以用`queue.push_front`和`queue.push_back`函数添加到队列中：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
let one_to_five = queue.push_back(one_to_four, 5)
let zero_to_five = queue.push_front(one_to_five, 0)
```

元素可以用`queue.pop_front`和`queue.pop_back`函数从队列中移除：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])

queue.pop_back(one_to_four)
// -> Ok(#(4, queue.from_list([1, 2, 3])))

queue.pop_front(one_to_four)
// -> Ok(#(1, queue.from_list([2, 3, 4])))

queue.pop_front(queue.new())
// -> Error(Nil)
```

可以用`queue.to_list`函数把队列转换为列表：

```gleam
let one_to_four = queue.from_list([1, 2, 3, 4])
queue.to_list(one_to_four)
// -> [1, 2, 3, 4]
```

## 队列相等性

由于队列的实现方式，两个元素相同、顺序也相同的队列，用`==`运算符比较时可能并不相等，因为该运算符是按结构比较值的。例如：

```gleam
let empty = queue.new()
let a = queue.push_front(empty, 1)
let b = queue.push_back(empty, 1)
a == b
// -> False
```

如果需要比较两个队列是否相等，可以用`queue.is_logically_equal`函数。

```gleam
queue.is_logically_equal(a, b, fn(x, y) { x == y })))
// -> True
```
