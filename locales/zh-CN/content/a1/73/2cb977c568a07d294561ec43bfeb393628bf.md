# 测试

## 运行测试

使用以下命令运行测试规范：

```bash
$ gradle test
```

## 启用更多测试

当你的代码通过所有已启用的测试后，就可以启用另一个测试：删掉你感兴趣的下一个测试前面的`@Ignore`。具体做法是删除`@Ignore`这一行，或者在这一行开头加上两个斜杠，把它注释掉。

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
