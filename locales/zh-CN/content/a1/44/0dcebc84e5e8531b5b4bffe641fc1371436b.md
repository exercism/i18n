# 补充说明

## 异常信息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，你应当始终附上一句**有意义的错误信息**，说明错误的来源。这会让你的代码更易读，对调试也大有帮助。如果你知道错误来源会是某种特定类型，可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍然要附上有意义的信息。

本练习要求你在待解码或编码的序列不完整时，使用 [`raise` 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)“抛出”一个 `ValueError`。只有既 `raise` 了 `exception`，又为它附上信息，测试才会通过。

要以带信息的方式抛出 `ValueError`，就把这条信息作为实参传给 `exception` 类型：

```python
# if the sequence is incomplete
raise ValueError("incomplete sequence")
```
