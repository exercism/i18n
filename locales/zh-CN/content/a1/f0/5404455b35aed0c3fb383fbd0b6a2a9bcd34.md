# 关于

Go 的 [regexp][package-regexp] 包提供了对正则表达式的支持。

## 语法

所接受的正则表达式[语法][regexp-syntax]与 Perl、Python 及其他语言使用的通用语法相同。

搜索模式和输入文本都按 UTF-8 解释。

使用反引号（\`）创建字符串时，反斜杠（`\`）没有任何特殊含义，也不会标记特殊字符的开头，比如制表符`\t`或换行符`\n`：

```go
"\t\n" // regular string literal with 2 characters: a tab and a newline
`\t\n`// raw string literal with 4 characters: two backslashes, a 't', and an 'n'
```

因此，创建正则表达式时最好使用反引号，因为这样就不需要转义反斜杠：

```go
"\\" // string with a single backslash
`\\` // string with 2 backslashes
```

## 编译模式：`RegExp`类型

要使用正则表达式，我们必须先编译字符串模式。
这里的编译指的是，把正则表达式的字符串模式转换成一种更易于处理的内部表示。
每个模式只需要编译一次，之后就可以多次使用编译后的正则表达式。
类型`regexp.Regexp`表示编译后的正则表达式。
我们可以使用函数`regexp.Compile`把字符串模式编译成`regexp.Regexp`。
如果编译失败，这个函数会返回`nil`和一个错误：

```go
re, err := regexp.Compile(`(a|b)+`)
fmt.Println(re, err) // => (a|b)+ <nil>
re, err = regexp.Compile(`a|b)+`)
fmt.Println(re, err) // => <nil> error parsing regexp: unexpected ): `a|b)+`
```

函数`MustCompile`是`Compile`的一个方便的替代品：

```go
re = regexp.MustCompile(`[a-z]+\d*`)
```

使用这个函数就不需要处理错误。

~~~~exercism/caution
 `MustCompile` should only be used when we know for sure the pattern does compile, as otherwise the program will panic.
 ~~~~

## 正则表达式的方法

`Regexp`有 16 个方法可以匹配正则表达式并识别匹配到的文本。
这些方法的名称都能被下面这个正则表达式匹配：

```text
Find(All)?(String)?(Submatch)?(Index)?
```

* 如果含有`All`，该例程会依次匹配整个表达式的各个不重叠的匹配项。
* 如果含有`String`，实参是字符串；否则是字节切片；返回值也会相应地调整。
* 如果含有`Submatch`，返回值是一个切片，用来标识表达式中各个连续的子匹配。
* 如果含有`Index`，匹配和子匹配用输入字符串中的字节下标对来标识。

此外还有用于以下操作的方法：

* 用替换字符串替换正则表达式的匹配项，以及
* 拆分由正则表达式分隔的字符串。

总的来说，`regexp`包定义了 40 多个函数和方法。
下面我们会演示其中几个方法的用法。
这些函数以及其他函数的详细信息，请参阅 [API 文档][package-regexp]。

### `MatchString`示例

方法`MatchString`报告字符串中是否包含正则表达式的任何匹配项。

```go
re = regexp.MustCompile(`[a-z]+\d*`)
b = re.MatchString("[a12]")       // => true
b = re.MatchString("12abc34(ef)") // => true
b = re.MatchString(" abc!")       // => true
b = re.MatchString("123 456")     // => false
```

### `FindString`示例

方法`FindString`返回一个字符串，其中包含正则表达式最左边那个匹配项的文本。

```go
re = regexp.MustCompile(`[a-z]+\d*`)
s = re.FindString("[a12]")       // => "a12"
s = re.FindString("12abc34(ef)") // => "abc34"
s = re.FindString(" abc!")       // => "abc"
s = re.FindString("123 456")     // => ""
```

### `FindStringSubmatch`示例

方法`FindStringSubmatch`返回一个字符串切片，其中包含正则表达式最左边那个匹配项的文本，以及它的各个子表达式（如果有）的匹配文本。
可以用它来找出匹配捕获组的字符串。
返回值为`nil`表示没有匹配。

```go
re = regexp.MustCompile(`[a-z]+(\d*)`)
sl = re.FindStringSubmatch("[a12]")       // => []string{"a12","12"}
sl = re.FindStringSubmatch("12abc34(ef)") // => []string{"abc34","34"}
sl = re.FindStringSubmatch(" abc!")       // => []string{"abc",""}
sl = re.FindStringSubmatch("123 456")     // => <nil>
```

### `ReplaceAllString`示例

方法`re.ReplaceAllString(src,repl)`返回`src`的一个副本，并把正则表达式`re`的匹配项替换为替换字符串`repl`。

```go
re = regexp.MustCompile(`[a-z]+\d*`)
s = re.ReplaceAllString("[a12]", "X")       // => "[X]"
s = re.ReplaceAllString("12abc34(ef)", "X") // => "12X(X)"
s = re.ReplaceAllString(" abc!", "X")       // => " X!"
s = re.ReplaceAllString("123 456", "X")     // => "123 456"
```

### `Split`示例

方法`re.Split(s,n)`把文本`s`按该表达式切分成若干子串，并返回这些表达式匹配项之间的子串切片。
数量`n`决定最多返回多少个子串。
如果`n<0`，该方法返回所有子串。

```go
re = regexp.MustCompile(`[a-z]+\d*`)
sl = re.Split("[a12]", -1)      // => []string{"[","]"}
sl = re.Split("12abc34(ef)", 2) // => []string{"12","(ef)"}
sl = re.Split(" abc!", -1)      // => []string{" ","!"}
sl = re.Split("123 456", -1)    // => []string{"123 456"}
```

本包提供的 regexp 实现保证[运行时间与输入大小成线性关系][re2-performance]。

## 注意事项

`regexp`包实现的是 [RE2 正则表达式][re2-syntax]（`\C` 除外）。
其语法与 PCRE（“Perl 兼容正则表达式”）大体兼容，但也有一些差异。
详情请参阅[这篇文章][reg-exp-wild]中的“注意事项”部分。
