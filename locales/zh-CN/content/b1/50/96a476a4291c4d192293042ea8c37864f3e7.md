# 说明

在这个练习中，你将编写代码来分析汽车工厂的装配线。

## 1. 计算每小时生产的合格汽车数量

实现一个函数，它接收每小时生产的汽车数量和成功率，并计算每小时成功生产的汽车数量。成功率以百分比给出，范围是`0`到`100`：

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**注意：**返回值应该是浮点数。

## 2. 计算每分钟生产的合格汽车数量

实现一个函数，它接收每小时生产的汽车数量和成功率，并计算每分钟成功生产多少辆汽车：

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**注意：**返回值应该是整数。

## 3. 计算生产成本 

每辆汽车单独生产的成本通常是 $10.000，无论它是否成功生产。但只要稍微规划一下，10 辆汽车就可以一起生产，成本为 $95.000。例如，37 辆汽车可以这样生产：
37 = 3 组十辆 + 7 辆单独生产

所以 37 辆汽车的成本是：
3 \* 95.000 + 7 \* 10.000 = 355.000

实现一个函数，计算生产一定数量汽车的成本，无论这些汽车是否成功生产：

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**注意：**返回值应该是整数。
