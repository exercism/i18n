# Instructions

Alizé 经营着一家线上时装精品店。一年一度的大促销就要到了，她想做点功能来帮忙盘点库存。

库存中的单件商品用一个自定义类型表示。

```gleam
Item(
  name: "White Shirt",
  price: 40,
  quantity: 6,
)
```

## 1. 返回商品名称的列表

实现`item_names`函数，它接收一个商品迭代器，并返回一个名称迭代器，顺序保持不变。

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> item_names
|> iterator.to_list

// -> ["Maxi Brown Dress", "Red Short Skirt", "Black Short Skirt", "Bamboo Socks Cats"]
```

## 2. 返回所有便宜的商品

实现`cheap`函数，它接收一个商品迭代器，并返回一个价格低于 30 的商品迭代器。

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> cheap
|> iterator.to_list

// -> [
//   Item(price: 29, name: "Black Short Skirt", quantity: 4),
//   Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
// ]
```

## 3. 返回所有缺货的商品

实现`out_of_stock`函数，它返回所有没有库存的商品。

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> out_of_stock
|> iterator.to_list

// -> [
//   Item(price: 50, name: "Red Short Skirt", quantity: 0),
// ]
```

## 4. 返回库存总量

实现`total_stock`函数，它计算你仓库中商品的总数量：

```gleam
[
  Item(price: 65, name: "Maxi Brown Dress", quantity: 8),
  Item(price: 50, name: "Red Short Skirt", quantity: 0),
  Item(price: 29, name: "Black Short Skirt", quantity: 4),
  Item(price: 20, name: "Bamboo Socks Cats", quantity: 7),
]
|> iterator.from_list
|> total_stock

// -> 19
```
