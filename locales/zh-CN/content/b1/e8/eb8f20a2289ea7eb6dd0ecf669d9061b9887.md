# Python 中的字典方法

Python 中的`dict`类提供了许多有用的[方法][dict-methods]，其中一些已经在讲解字典的概念练习中介绍过了。

这个概念还介绍了以下几个：

- `<dict>.setdefault()`可以自动添加键，而不会抛出 KeyError。
- `<dict>.fromkeys(<iterable>, <default value>)`可以从任意数量的可迭代对象创建一个新的`dict`。
- `<dict>.keys()`、`<dict>.values()`和`<dict>.items()`提供了便捷的迭代器。
- `sorted(<dict>.items())`可以轻松重新排列`dict`中的条目。
- `<dict_one>.update(<dict_two>)`用另一个`dict`中重叠的值更新一个`dict`。
- `<dict> | <other_dict>`和`<dict> |= <other_dict>`通过运算符合并或更新两个`dict`。
- `reversed(<dict>.keys())`、`reversed(<dict>.values())`或`reversed(<dict>.items())`会生成_反转的_视图。
- `<dict>.popitem()`移除并返回一个`key`、`value`对。

[dict-methods]: https://docs.python.org/3/library/stdtypes.html#dict
