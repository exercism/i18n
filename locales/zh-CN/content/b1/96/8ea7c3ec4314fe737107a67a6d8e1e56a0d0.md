# 介绍

本练习延续你在[后院观鸟者][backyard-birdwatcher]里学到的内容，介绍那些接收*引用*的高阶词。引用就是写在`[ ]`括号里的一小段代码，高阶词靠它来驱动操作。

## 引用作为值

引用本身只是一段字面量形式的代码。你可以把它作为数据传给另一个词：

```factor
{ 1 2 3 4 5 } [ 2 > ] count .   ! => 3
```

这里，`[ 2 > ]`是一个引用，它接收一个数字，留下一个布尔值。`count`会对每个元素运行它，并统计结果为真的次数。

## 筛选与剔除

```
find      ( seq quot    -- i/f elt/f ) ! first match: index and element, or f f
find-last ( seq quot    -- i/f elt/f ) ! same, but searches from the end
filter    ( seq quot    -- newseq )    ! keep elements where quot is truthy
reject    ( seq quot    -- newseq )    ! drop them instead
without   ( seq exclude -- newseq )    ! drop every element that's in `exclude`
sift      ( seq         -- newseq )    ! drop every `f`, keep the rest
```

```factor
{ 1 2 3 4 5 } [ 3 > ] find .s
! => 3            (index)
! => 4            (element)
{ 1 2 3 4 5 } [ 3 > ] find-last .s
! => 4            (index)
! => 5            (element)
{ 1 2 3 4 5 } [ even? ] filter .    ! => { 2 4 }
{ 1 2 3 4 5 } [ even? ] reject .    ! => { 1 3 5 }
"hello world" " ld" without .       ! => "heowor"
{ 1 f 2 f 3 } sift .                ! => { 1 2 3 }
```

`without`把它的第二个参数当作一个集合：只要`seq`里的某个元素`=`等于`exclude`中的*任意*一个元素，它就会被丢弃。`sift`是`reject`在不用引用时的特例：它保留除`f`以外的每个元素，很适合清理上一次`map`留下的空缺。

### 保留测试的结果

`find`返回的是匹配到的*元素*。当测试本身就已经*算出*了你真正想要的值时，`map-find`能省去再遍历一遍：它对每个元素运行引用，返回第一个不是`f`的结果**以及**产生它的那个元素。

```
map-find ( seq quot: ( elt -- result/f ) -- result elt )
```

```factor
USING: kernel math sequences ;

! First multiple of 3, paired with that multiple divided by 3.
{ 11 13 15 17 } [ dup 3 mod 0 = [ 3 /i ] [ drop f ] if ] map-find .s
! => 5            (result: 15/3)
! => 15           (element)
```

引用对不符合条件的元素返回`f`，对符合条件的那个元素返回你想保留的结果。如果没有任何元素符合条件，`map-find`会留下`f f`，和`find`一样。

### 按槽位筛选记录

当元素是*元组*时，谓词通常会通过自动生成的读取器`slot>>`取出某个槽位，再对它进行测试：

```factor
USING: accessors sequences ;

TUPLE: customer name vip? ;

{
    T{ customer { name "Alice" } { vip? t } }
    T{ customer { name "Bob"   } { vip? f } }
    T{ customer { name "Carol" } { vip? t } }
}
[ vip?>> ] filter [ name>> ] map .
! => { "Alice" "Carol" }
```

## 用`with`传入一个固定值

有时候，谓词需要一个在每次调用中都不变的值：可能是一个阈值、一个除数或一个目标字符串。`with`（位于[`kernel`][kernel]中）会把那个固定值嵌入引用里，把接收两个参数的引用`( value elt -- ? )`变成`filter`、`count`、`map`和`each`所期望的那种单参数引用：

```
with ( value seq quot -- seq curry )
```

每次针对单个元素的调用都会在栈上看到`( value elt )`：固定值在前，当前元素在后：

```factor
USING: kernel sequences ;

! Count elements greater than 5 — value=5 is threaded in
5 { 2 7 4 9 1 8 } [ < ] with count .   ! => 3
```

## 映射与遍历

`map`（位于[`sequences`][sequences]中）把引用应用到每个元素上，并返回结果组成的数组。`each`走同样的遍历，但会丢弃结果，当引用纯粹是为了产生副作用而运行时很有用。`2map`以同步的方式遍历*两个*序列，并合并对应的元素；`2each`和`2reduce`分别是它只管副作用和负责折叠的近亲；`zip`是“只配对、不合并”的简写：

```
map     ( seq       quot           -- newseq )
map-as  ( seq       quot exemplar  -- newseq )
each    ( seq       quot           -- )
2map    ( seq1 seq2 quot           -- newseq )
2each   ( seq1 seq2 quot           -- )
2reduce ( seq1 seq2 identity quot  -- result )
zip     ( seq1 seq2                -- pairs )
```

`2reduce`会同时把一个累加器穿过两个序列，它的引用接收`( accumulator elt1 elt2 -- accumulator' )`。这里它累加的是点积：每一对元素相乘，再把乘积相加（`1*10 + 2*20 + 3*30`）：

```factor
{ 1 2 3 } { 10 20 30 } 0 [ * + ] 2reduce .   ! => 140
```

`map-as`是`map`的近亲，它会强制指定输出序列的类型：传入一个空的`{ }`或`V{ }`作为样板，就能覆盖默认沿用输入类型的做法（否则，把字符串映射为非字符时，Factor 在试图把结果重新打包回字符串时会报错）。

```factor
USING: formatting math sequences ;

{ 1 2 3 } [ sq ] map .                         ! => { 1 4 9 }
{ 1 2 3 } [ . ] each                           ! prints 1, then 2, then 3
{ 1 2 3 } { 10 20 30 } [ + ] 2map .            ! => { 11 22 33 }
{ "x" "y" } { 1 2 } [ "%s%d" sprintf ] 2map .  ! => { "x1" "y2" }
{ 1 2 3 } { 10 20 30 } [ + . ] 2each           ! prints 11, then 22, then 33
{ "a" "b" "c" } { 1 2 3 } zip .                ! => { { "a" 1 } { "b" 2 } { "c" 3 } }
```

两种双序列形式都在较短的输入结束时就停止。`zip`等同于`[ 2array ] 2map`，它会保留配对，而不是把配对合并起来。

## 排序

`sort`返回按自然顺序排好序的副本；`sort-by`（位于[`sorting`][sorting]中）则按从每个元素中提取出的键来排序：

```
sort    ( seq      -- sortedseq )
sort-by ( seq quot -- sortedseq )
```

```factor
{ 3 1 4 1 5 9 2 6 } sort .
! => { 1 1 2 3 4 5 6 9 }

{ -3 5 -1 4 } [ abs ] sort-by .
! => { -1 -3 4 5 }
```

## 聚合

`map-sum`（位于[`sequences`][sequences]中）把引用映射到整个序列上，并在一趟遍历中把结果相加：

```
map-sum ( seq quot -- n )
```

```factor
{ 1 2 3 4 } [ sq ] map-sum .   ! => 30
```

## 最小值和最大值

`minimum`和`maximum`直接返回序列中最小或最大的元素。`minimum-by`和`maximum-by`（都在[`sequences`][sequences]中）则返回提取出的键最小或最大的那个元素：

```
minimum     ( seq      -- elt )
maximum     ( seq      -- elt )
minimum-by  ( seq quot -- elt )
maximum-by  ( seq quot -- elt )
```

```factor
{ 3 1 4 1 5 9 2 6 } minimum .       ! => 1
{ 3 1 4 1 5 9 2 6 } maximum .       ! => 9

{ -3 5 -1 4 } [ abs ] minimum-by .
! => -1
```

## 编写自己的高阶词

当*你的*词把引用作为运行时参数接收，并把它转发给`map`、`filter`、`each`等时，要用`; inline`声明它。这会让编译器在每个调用点把你的词内联展开，因为在那里引用是已知的字面量。没有它，编译器就无从知道引用的栈效果。

```factor
USING: math sequences ;

: tax-on ( inventory quot -- total )
    map-sum ; inline

{ { "shirt" 20 } { "hat" 15 } } [ second 1/10 * ] tax-on .
! => 3+1/2
```

只用字面量引用写成的词不需要`inline`，只有把*传入的*引用继续传递下去的词才需要。

如果这样的`inline`词还会调用*它自己*（也就是递归组合子），那就改用`; inline recursive`来声明。少了这个额外的词，编译器会停下并报出*“The inline recursive word ... must be declared recursive”*，这句话正好告诉你该补上什么。

## 取出第二个元素

对于包含 2 个元素的数组，`second`返回它的第二个元素，`first`返回第一个。两者都在[`sequences`][sequences]中。

## 把数字变成字符串

`number>string ( n -- str )`（位于[`math.parser`][math.parser]中）把数字变成它的十进制字符串形式：

```factor
42 number>string .     ! => "42"
3.5 number>string .    ! => "3.5"
```
