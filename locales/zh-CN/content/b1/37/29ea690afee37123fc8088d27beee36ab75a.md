# 泛型类

你从很早的时候就开始使用`ARRAY{STR}`、`FMAP{STR,INT}`和`FSET{STR}`了。大括号里一直放着一个类型。现在，你要自己写一个带大括号的类。

## 问题

失物招领处需要一个盒子，里面装一样东西，并且记住是谁交上来的。一个装毛衣的盒子：

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

然后为水瓶再写一遍同样的类，再为手机写一遍。三份副本只差一个词。

## 类型参数

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

类名后面的`{T}`是**类型参数**。`T`不是类型，它是一个占位符，代表使用这个类时实际提供的那个类型。在类内部，`T`的用法和任何类型名完全一样。

## 使用它

在大括号里提供类型：

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}`和`LOST_BOX{INT}`是两个不同的类型。把其中一个用在需要另一个的地方，是编译器会捕获的错误，就和你手写两个类一样。实际上发生的就是这件事：Sather 会为实际用到的每个类型，根据这个模式生成一个单独的类。

所以这在运行时没有任何开销，也不会丢失类型信息：`jumper.item`确实是`STR`，不需要检查或转换。

## 不止一个

一个类可以接受多个参数，用逗号分隔。`FMAP{K,T}`就是你已经见过的例子。

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## 命名

按照惯例用单个大写字母：`T`表示一个东西，`K`表示键，`E`表示元素。库中从头到尾都是这么用的。
