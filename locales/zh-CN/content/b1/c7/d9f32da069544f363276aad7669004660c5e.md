# 提示

## 通用

- 所有读写相关的词都在[`io.files`][io.files]里；它们都要用的`utf8`编码来自[`io.encodings.utf8`][utf8]。

## 1. 读取每一条读数

- `file-lines`返回一个数组，里面是去掉换行符后的各行内容。

## 2. 找出最新的一条读数

- 用`file-lines`读取这些行，然后取`last`那一个（来自`sequences`）。

## 3. 读取原始日志

- `file-contents`把整个文件作为一个字符串返回，换行符也一并包含在内。

## 4. 记录一条读数

- 以追加方式打开文件，在引述里`print`这条读数：
  `with-file-appender ( path encoding quot -- )`。这条读数在引述内部被使用，
  而路径在它之前就已被消耗，所以用`::`局部变量能让函数体保持可读：
  `:: record-reading ( reading path -- ) path utf8 [ reading print ]
  with-file-appender ;`。

## 5. 重写日志

- `set-file-lines`把序列中的每个元素写到自己的一行上，换行符会自动帮你加上。

[io.files]: https://docs.factorcode.org/content/vocab-io.files.html
[utf8]: https://docs.factorcode.org/content/vocab-io.encodings.utf8.html
