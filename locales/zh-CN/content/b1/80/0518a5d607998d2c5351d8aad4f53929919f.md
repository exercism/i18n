# 说明

在你的帮助下，Lisp 外星人 Lilly 肯定已经做了很多千层面。他们想送你一些剩菜表示感谢。不过在此之前，他们对你帮忙写的其中一个函数有些反馈。

在这个练习中，你要再写几个函数，帮助 Lilly 烹制千层面，并帮他们把剩菜和你分掉。

一共有 6 个任务：3 个是改进现有的千层面烹饪函数，3 个是关于分配剩菜的。

## 1. 让`preparation-time-in-minutes`更易使用

Lilly 说，用你写的`preparation-time-in-minutes`有点别扭，因为调用函数之前得先把所有层都数一遍。Lilly 想知道，你能不能做一个这样的函数版本：把层（数量不限）作为实参传进去，然后根据有多少层来算出准备时间？提醒一下，准备一层需要 19 分钟。

```lisp
(preparation-time 'sauce 'cheese 'right-handed-macaroni 'cheese 'sauce
                  'left-handed-macaroni 'sauce 'sauce 'cheese 'cheese)
                  ;; => 190 (because there are 10 layers.)
```

## 2. 允许更改预期的烤箱时间

虽然 Lilly 的家长总是把千层面烤 337 分钟，但 Lilly 也承认，其他 Lisp 外星人喜欢把千层面烤得久一点或短一点。

所以，如果`remaining-minutes-in-oven`不再使用`expected-minutes-in-oven`，而是可以接收一个_可选_形参，用来指定时间是更长、非常长、更短还是非常短，那就好了。更长或更短，是指在默认的 337 基础上加或减 100；非常长或非常短，就是加或减 200。如果没有提供形参，或者实参是 'normal'，就应返回默认值 337。

```lisp
(remaining-minutes-in-oven)             ;; => 337
(remaining-minutes-in-oven :normal)     ;; => 337
(remaining-minutes-in-oven :shorter)    ;; => 237
(remaining-minutes-in-oven :very-short) ;; => 137
(remaining-minutes-in-oven :longer)     ;; => 437
(remaining-minutes-in-oven :very-long)  ;; => 537
```

## 3. Lilly 又想起一种偏好的烹饪方式

你刚做完那处修改，Lilly 就想起有些 Lisp 外星人喜欢_特别短_的烹饪时间。实际上，他们想要的就是生的。所以现在，如果实参是`NIL`，函数应返回 0，其他情况的返回值和上一个任务相同。

```lisp
(remaining-minutes-in-oven)     ;; => 337
(remaining-minutes-in-oven nil) ;; => 0
```

## 4. 分配剩菜

既然你已经帮忙改进了千层面的烹饪函数，现在可是_有好多千层面_了！Lilly 想和你分掉这些剩菜，来报答你所有的帮助。你需要写一个函数，接收 3 个形参：剩菜总量、Lilly 在柜子里找到的装剩菜的容器数量，以及你找到的容器数量。因为寻找装剩菜的容器可能要花不同的时间，而剩菜的确切数量可能在你和 Lilly 翻柜子的时候才能确定，所以你俩一致同意：这个函数应该允许以任意顺序传入实参，这样每确定一个数字，你就可以先把它写下来。等 3 个数字都齐了，只要把函数调用的括号补上，求值就行了。

函数应返回剩下的剩菜量，也就是剩菜重量与你俩找到的容器总数之差。

```lisp
(split-leftovers :weight 20 :human 10 :alien 5) ;; => 5
(split-leftovers :weight 20 :alien 10 :human 2) ;; => 8
(split-leftovers :alien 12 :weight 20 :human 4) ;; => 4
```

## 5. 做出假设

在各自往返柜子几趟之后，你俩一致认为，如果函数能在没有指定时直接_假定_你或 Lilly 有……比如说 10 个容器，那就太好了。

```lisp
(split-leftovers :weight 20 :human 5) ;; => 5
(split-leftovers :weight 20 :alien 5) ;; => 5
(split-leftovers :weight 20)          ;; => 0
```

## 6. 标准剩菜量

更好的是，函数可以_假定_剩菜足够装进容器里。因此，如果没有提供重量，函数应返回`:just-split-it`。_不过_，如果提供了重量，而它是`nil`，则应返回`:looks-like-someone-was-hungry`。

```lisp
(split-leftovers :human 5 :alien 5) ;; => :JUST-SPLIT-IT
(split-leftovers :weight NIL :human 5 :alien 5) ;; => :LOOKS-LIKE-SOMEONE-WAS-HUNGRY
```
