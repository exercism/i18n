# 简介

在任何语言中，处理二进制数据都是一个重要的概念，Elixir 提供了优雅的语法来编写、匹配和构造二进制数据。

在 Elixir 中，二进制数据被称为位串类型。二进制数据_类型_（不要与一般意义上的二进制数据混淆）是位串的一种特殊形式，我们会在后面的练习中讨论。

位串字面量使用位串特殊形式`<<>>`来定义。定义位串字面量时，是按段来定义的。每个段都有一个值和类型，二者由`::`运算符分隔。类型指定用多少位来编码这个值。类型可以完全省略，此时默认是 8 位整数值。

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

把类型写成`::1`是`::size(1)`的简写。如果位数来自变量，就需要使用较长的写法。

## 二进制

在编写二进制整数字面量时，我们可以直接在字面量前加上`0b`，用二进制记法来书写。注意，在测试结果中打印它们，或者使用 iex 时，它们仍然会以十进制数字显示。

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## 截断

如果段的值超出该段类型的容量，它就会从左侧被截断。

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## 前置与追加

使用特殊形式，你既可以在现有位串的前面添加，也可以在其后面追加。如果现有位串的大小未知，就必须对其使用`::bitstring`类型。

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## 拼接

我们可以使用特殊形式拼接存储在变量中的位串。拼接两个大小未知的位串时，必须使用`::bitstring`类型。

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## 模式匹配

也可以用模式匹配从特殊形式中获取值。对于想要捕获的每个片段，你都必须知道它的位数，只有一个例外：可以用`::bitstring`类型对大小未知的位串进行模式匹配，但它只能用于最后一个片段。

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## 查看位串

~~~~exercism/note
测试运行器或 iex 可能会以不同于创建它们时所用格式的格式打印位串。这在学习位串时常常会造成困惑。
~~~~

默认情况下，位串以 8 位（一个字节）为片段来显示，即使你创建它时用的是不同大小的片段。

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

如果你创建的位串表示一个可打印的 UTF-8 编码字符串，它就会以字符串的形式显示。

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
