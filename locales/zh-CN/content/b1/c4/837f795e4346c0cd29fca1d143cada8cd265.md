# 简介

## 整数

Gleam 中有两种不同的数字：整数和浮点数。

整数是不带小数的数。

```gleam
let integer = 3
// -> 3
```

Gleam 提供了多个可用于整数的运算符。

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```

## 浮点数

浮点数的小数点后有一位或多位数字。

```gleam
let float = 3.45
// -> 3.45
```

浮点数也有自己的一套运算符。

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

## 模块

### 模块

Gleam 代码按模块来组织，每个文件就是一个 Gleam 模块。

到目前为止，我们一直用 `pub fn` 语法来写函数，它定义的函数对其他模块公开可用。用 `fn` 定义的函数则只对它所在的模块私有，其他模块无法使用。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 模块有名称，名称取决于它在 `src` 或 `test` 目录下的文件路径。

例如，定义在 `src\geometry\rectangle.gleam`（Windows）或 `src/geometry/rectangle.gleam`（类 UNIX 操作系统）中的模块，名称为`geometry/rectangle`。

### 从其他模块导入函数

要访问其他模块中定义的函数，需要通过导入来完成。导入某个模块时，该模块公开的所有函数都会变得可以访问。但访问它们的方式取决于模块是怎么导入的。

限定导入是默认方式，访问这类模块中的函数（例如`gleam/list`模块中的`map`函数）时，要在前面加上模块名（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

默认情况下，用来指代模块的名称是模块名的最后一部分，在这里是`int`，不过可以用 `as` 关键字来改变。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非限定导入可以直接访问模块里公开的函数，无需添加前缀。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

推荐使用限定导入，因为它能让读者更清楚地看出函数来自哪里，也能避免名称冲突。


### 标准库

Gleam 有一个丰富且文档完善的标准库。文档可以在线查阅：[hexdocs.pm/gleam_stdlib][docs]。把这个链接保存好，你会经常用到它！

大多数内置数据类型都有对应的模块，提供处理该数据类型的函数，例如整数有 `gleam/int` 模块，字符串有 `gleam/string` 模块，数组有 `gleam/list` 模块，等等。

[docs]: https://hexdocs.pm/gleam_stdlib/
