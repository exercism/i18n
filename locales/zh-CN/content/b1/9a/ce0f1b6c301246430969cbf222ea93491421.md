# 关于

Haxe 中的[字符串][strings]是不可变的对象，表示由 Unicode 字符（字母、数字、标点等）组成的序列。定义 `string` 实例时使用双引号：

```haxe
var fruit:String = "Apple";
```

操作字符串可以通过调用它的某个[方法或属性][string-api]来完成。由于字符串的值一旦定义就永远不能改变，所有字符串操作方法都会返回一个新的字符串。

字符串由双引号（`"`）字符界定。有些特殊字符需要用反斜杠（`\`）进行[转义][escaping]。此外，Haxe 字符串支持多行，可以轻松构造很长的字符串字面量：

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

拼接字符串最简单的方式是使用 [`+`运算符][plus-operator]。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

对于更复杂的字符串格式化，推荐使用[字符串插值][interpolation]。做法是用单引号（`'`）把字符串括起来，并用美元符号（`$`）触发变量插值。也可以用`${expr}`求值整个表达式，其中`expr`是任意合法的 Haxe 表达式：

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
