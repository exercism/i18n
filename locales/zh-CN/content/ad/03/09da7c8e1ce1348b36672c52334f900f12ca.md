# 说明

Lilly 喜欢烹饪。
她想和朋友们办一场披萨派对。
为了充分利用食材，她需要在开始前知道每种食材需要多少。

为了解决这个问题，Lilly 已经草拟了一个程序来自动完成部分规划，但需要你帮忙完成它。
你愿意帮 Lilly 办一场比例完美的披萨派对吗？

## 1. 面团比例

Lilly 喜欢薄脆的披萨，饼底也更薄。
中间部分所需的面团最少为 200 克，但每多供应一个人，就需要再加 20 克面团。

`grams = pizzas * ((persons * 20) + 200)`

Lilly 需要一个函数，它可以：

- 接收披萨的数量
- 每张披萨供应的人数
- 并返回所需的面团量，精确到克。

例如，制作 4 张可供 8 人食用的披萨：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateDoughRequirement(4, 8);
// => 1440
```

## 2. 来点酱汁

Lilly 涂酱汁时很讲究，但她的披萨大小可能不一致。
根据经验，她知道每张披萨需要 125 毫升酱汁。
Lilly 需要一个函数，来计算需要买多少罐酱汁。

`cans of sauce = pizzas * sauce per pizza / sauce can volume`

例如，假设 Lilly 需要做 8 张披萨，每罐有 250 毫升：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateSauceRequirement(8, 250);
// => 4
```

## 3. 来点奶酪吧

奶酪以标准立方体出售，按大小定价。

Lilly 使用的公式不是披萨面积的公式，因为她_不_希望奶酪覆盖整个表面。
她决定用下面的公式来确定，用一块边长为（`cheese_dimension`）的奶酪立方体，可以做出多少张直径为（`diameter`）的披萨：

`pizzas = (cheese_dimension³) / (thickness * PI * diameter)`

创建一个函数，它可以：

- 接收奶酪立方体的边长
- 接收奶酪层的期望厚度
- 接收披萨的直径
- 并使用 Lilly 的公式返回可以制作的披萨数量，向下取整。

例如，已知一块 25x25x25 厘米的奶酪立方体、0.5 厘米厚的奶酪层，以及直径为 30 厘米的披萨：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateCheeseCubeCoverage(25, 0.5, 30);
// => 331
```

## 4. 公平分配

最后，Lilly 希望每张披萨都切成 8 片，并平均分给她的朋友们。

创建一个函数，它可以：

- 接收披萨的数量和朋友的数量
- 并返回当每个人分到相同片数时，会剩下多少片。

例如：

```php
<?php

$pizza_pi = new PizzaPi();
$pizza_pi->calculateLeftOverSlices(2, 4);
// => 0
$pizza_pi->calculateLeftOverSlices(4, 3);
// => 2
```
