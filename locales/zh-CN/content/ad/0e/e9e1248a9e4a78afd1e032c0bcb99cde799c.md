# 简介

C++ 中的布尔值用`bool`类型表示。
`bool`的取值要么是`true`，要么是`false`。

## 逻辑运算符

C++ 支持三种布尔运算符：`!`（NOT）、`&&`（AND）和`||`（OR）。
你也可以使用替代形式`not`、`and`和`or`。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 优先级

这三种布尔运算符各有不同的_运算符优先级_。
因此，它们的求值顺序是：先`!`，再`&&`，最后`||`。
如果你想强制改变求值顺序，可以把布尔表达式放在括号中（即`()`），因为括号的运算符优先级更高。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 转换

如果在需要数字的地方使用`true`或`false`，它们会分别被转换为`1`和`0`。
如果在布尔运算中使用数字，除`0`以外的所有值都被视为`true`，负数也一样。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
