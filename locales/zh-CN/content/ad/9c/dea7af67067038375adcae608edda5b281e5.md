# 简介

当你需要一个由 `n` 个值组成的序列，而每个值又取决于它的下标时，Factor 提供了 `<iota>` 和 `map`。其中 `<iota>` 是一个虚拟序列，由整数 `0, 1, …, n-1` 组成。

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` 不会预先分配这些整数，`map` 会按顺序遍历它们，对每个整数应用这个 quotation。

如果每个位置得到的结果是一个字符编码，`>string` 可以把结果变成字符串。这是根据下标逐位决定字符、最终拼成一串字符的最自然做法：

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
