# 前置条件

要学习 D 语言，你的系统上需要安装以下软件：

* D 语言第 2 版编译器
* （可选，但推荐）DUB

## 前置条件：D 语言第 2 版编译器

在 D 语言官网 [dlang.org](https://dlang.org) 上，可以下载并安装参考编译器 DMD（Digital Mars D）的最新版本，它支持多种平台。
更多信息请参阅[官方下载页面](https://dlang.org/download.html)。
在 Windows 上，另一种方案是[使用 Chocolatey](https://chocolatey.org/packages/dmd)。
在基于 Intel 的 Mac 上，另一种方案是[使用 Homebrew](https://formulae.brew.sh/formula/dmd)。

### 其他编译器
除了使用自家后端的 DMD 参考编译器之外，还有两个编译器可以从 dlang.org 的下载页面获取：

* [GDC](http://gdcproject.org/downloads)，它使用 GCC 后端
* [LDC](https://github.com/ldc-developers/ldc#installation)，基于 LLVM 后端

GDC 和 LDC 并不总是采用最新的 DMD 前端版本，但它们能提供更好的优化级别，并支持 ARM 等其他平台。

请到维基查看[更多信息](https://wiki.dlang.org/Compilers)。

### IDE（集成开发环境）支持

各种 IDE 也支持 D 语言，例如用于 Visual Studio 的 [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html)，以及用于 IntelliJ CLion 的 [D 插件](https://plugins.jetbrains.com/plugin/7727?pr=clion)。
请到维基查看[更多信息](https://wiki.dlang.org/IDEs)。

### 前置条件：DUB

[DUB](https://github.com/dlang/dub) 是 D 语言的构建管理器。

我们推荐用它来简化运行测试的流程，不过，如果你无法安装或不想安装它，也仍然可以在没有 DUB 的情况下运行测试。

#### Windows

[DUB 官网的下载页面](https://code.dlang.org/download)提供了 Windows 安装程序。

#### MacOS

* [DUB 官网的下载页面](https://code.dlang.org/download)提供了 macOS 二进制文件。
* 对于基于 Intel 和 Apple Silicon 的 Mac，还有[可用的 Homebrew 软件包](https://formulae.brew.sh/formula/dub)：

#### Linux

* [DUB 官网的下载页面](https://code.dlang.org/download)提供了 Linux 二进制文件。
* 还提供了适用于各种发行版的软件包：
    * [ArchLinux](https://www.archlinux.org/packages/community/x86_64/dub/)
