# 简介

## 数学函数

单靠`+`、`-`、`*`和`/`，很难算出平方根、角度和增长曲线。[`math.functions`][math.functions]词汇表里有能替你算出这些的单词，[`math.constants`][math.constants]里则有 π。和其他每个单词一样，每个单词都从栈上取输入，把答案留在栈上。

## 平方根

```
sqrt ( x -- y )
```

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .     ! => 3.0
2 sqrt .     ! => 1.4142135623730951
```

一架 5 米长的梯子，底部离墙 3 米，能沿墙向上够到 4 米高：

```factor
5 sq 3 sq - sqrt .   ! => 4.0
```

## 圆周率

`pi`（来自`math.constants`）会把 π 压入栈，π 就是一个圆的周长与直径的比值：

```factor
: wheel-edge ( diameter -- edge ) pi * ;

2 wheel-edge .   ! => 6.283185307179586
```

## 角度以弧度为单位

```
sin ( x -- y )
cos ( x -- y )
tan ( x -- y )
```

`sin`、`cos`和`tan`接收一个角度，但不是度数。它们使用的是**弧度**，其中半圈是 π 而不是 180。传给它们度数并不会报错：它会悄悄给出错误的答案。

`deg>rad`把度数转换成弧度，`rad>deg`则转换回来。它们等同于乘以 π 再除以 180，或者反过来：

```
deg>rad ( x -- y )
rad>deg ( x -- y )
```

```factor
30 deg>rad .       ! => 0.5235987755982988
30 pi * 180 / .    ! => 0.5235987755982988
pi rad>deg .       ! => 180.0
```

调用`sin`之前，先把度数转换成弧度：

```factor
: ramp-rise ( length degrees -- rise ) deg>rad sin * ;

10 30 ramp-rise .   ! => 4.999999999999999
```

一条 10 米长、坡度为 30 度的斜坡会升高 5 米。答案打印为`4.999999999999999`，因为数学函数给出的是最接近的浮点数，而不是精确值。如果不做转换，`30 sin`就会把 30 当成弧度（接近整整五圈），这条斜坡就会“上升”`-9.88`米。

## 求角度

`fatan2`则反过来：给定向上多远和横向多远，它会用弧度给出角度。它位于[`math.libm`][math.libm]中。*向上*的距离先入栈，然后才是*横向*的距离：

```
fatan2 ( y x -- radians )
```

```factor
1.0 1.0 fatan2 .              ! => 0.7853981633974483
1.0 1.0 fatan2 rad>deg .      ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
0.0 -1.0 fatan2 rad>deg .     ! => 180.0
```

角度是从正的*横向*方向开始测量的。`fatan2`会看两个距离的符号，因此能给出从 −180 到 180 度之间的任何角度。

## 10 的幂：10^ 和 log10

`10^`把 10 提升到某个幂：

```factor
5 10^ .     ! => 100000
2 10^ .     ! => 100
0.5 10^ .   ! => 3.1622776601683795
```

`log10`则反过来。它回答的问题是“10 的多少次方等于这个数？”这个答案就是这个数的**对数**：

```factor
100000 log10 .   ! => 5.0
100 log10 .      ! => 2.0
1 log10 .        ! => 0.0
0.001 log10 .    ! => -3.0
```

## e^ 和 log

`e^`和`log`是同样的一对，只不过用 *e*（约 2.718）代替 10。`e^`把 *e* 提升到某个幂，`log`则回答“*e* 的多少次方等于这个数？”

```
e^  ( x -- y )
log ( x -- y )
```

数学家会用 *e* 来描述任何每一步都按相同比例增长或缩小的东西。钱生利息是一个例子，一杯茶变凉是另一个例子：

```factor
! 80 degrees hotter than the room, the gap shrinking by 5% a minute
: tea-gap ( minutes -- gap ) -0.05 * e^ 80 * ;

0 tea-gap .    ! => 80.0
10 tea-gap .   ! => 48.52245277701067
```

`log`是`e^`的逆运算。这反过来回答了这个问题：要过多少分钟，温差才会降到 40 度？

```factor
80 40 / log 0.05 / .   ! => 13.862943611198904
```
