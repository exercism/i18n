# 安装

## 需要什么

用 Common Lisp 开发，最基本需要这几样东西：

- 一个 Lisp“实现”，让你能够编译并运行代码，还会提供一个 REPL。
- 一个适合编写 Lisp 代码的文本编辑器。
- （可选但推荐）Common Lisp 语言常用的参考资料：["Common Lisp Hyperspec"][hyperspec]。

## Roswell

[Roswell][roswell] 是一个用于安装和管理 Common Lisp 实现的命令行工具，它还提供许多功能，让开发和分发 Lisp 应用变得轻松。
我们用它来简化安装和测试步骤。

### 安装 Roswell

请查看[安装指南][ros-inst]，并按照适用于你所使用平台的说明操作。
对大多数用户来说，下面的方法就足够了：

* 在 MacOS 和 Linux 上，用 [Homebrew][brew] 就能轻松搞定：
  ```sh
  brew install roswell
  ```
* 在 Windows 上，用 [Scoop][scoop]：
  ```powershell
  scoop install roswell
  ```

第一次使用 Roswell 时，它会下载并安装 SBCL 和 Quicklisp。
只需要运行：
```sh
ros help
```

用下面的命令进入 REPL：
```sh
ros run
```

## 配置你的文本编辑器

如果你是 Common Lisp 新手，尤其是以前用过 Emacs，那么安装 [Portacle, the Portable Common Lisp Environment][portacle] 可以让你轻松快速地上手。
它免费且功能齐全，支持所有主流平台，开箱即用，已经预先配置好了。它会提供：

- 一个 Lisp 实现：SBCL，其中包含 Quicklisp 和 ASDF。
- 一个文本编辑器：Emacs

……还附带大量用于编写 Lisp 代码的扩展：
- SLIME，即“Superior Lisp Interaction Mode for Emacs”，它把 Emacs 变成一个 Common Lisp IDE
- ParEdit，让你轻松处理括号。

所有内容都已经预先配置好，开箱即用。从[首页][portacle]下载即可安装 Portacle。

注意：如果你不习惯 Emacs（文本编辑器），一开始可能会觉得有点晕。好在网上有很多关于 Emacs 和 SLIME 的入门资料。

## 传统方式开始

如果你更愿意分别安装所需的工具，就需要安装并配置好：

- 一个懂 Lisp 的文本编辑器：[Emacs][emacs] 搭配 [Slime][slime] 或 [Sly][sly] 是常见选择，不过 [VIM][vim] 搭配 [SLIMV][slimv]、[Atom][atom] 搭配 [SLIMA][slima]，或者 [VSCode][vscode] 搭配 [Common Lisp 插件][vscode-plugin] 也很不错。
- 一个 Common Lisp 实现：[SBCL][sbcl] 是一个“稳妥”的选择，在 Linux、MacOS 和 Windows 上都能用。由于这门语言基于一个标准，其他[符合标准的实现][awesome-cl-implementations]同样可以使用。
- [Quicklisp][quicklisp]，用于管理库。下载后，按照[说明][quicklisp-install]操作，确保它与你的 Common Lisp 实现正确集成。
