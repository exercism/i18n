# 简介

## 自定义类型

在 Gleam 中，自定义类型用来定义新的数据类型。一个自定义类型可以有多个_变体_，每个变体都有自己的名字。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自定义类型的每个变体都可以选择性地携带一些数据，而且不同变体携带的数据类型可以不同。当变体携带数据时，它就被称为_记录_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

如果要为某个变体创建值，当它不包含额外数据时（`Spring`），直接引用它的名字即可；当它包含额外数据时（`SomeInt(2)`），则把它当作函数来调用。

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

自定义类型和 Gleam 中的其他所有东西一样，都具有_结构相等性_：也就是说，两个值只要属于同一个变体、携带的数据相同，就彼此等价。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

使用 case 表达式，可以对自定义类型的变体进行模式匹配。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
