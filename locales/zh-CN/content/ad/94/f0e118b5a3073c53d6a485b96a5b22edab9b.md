# 说明补充

## 最大整数值

根据 [Vim 文档][number]：

> 假设使用 64 位数字（参见 v:numbersize），无符号数会被截断为 0x7fffffffffffffff 或 9223372036854775807。

换句话说，Vim script 无法把 `2^63` 或更大的数字表示为整数。

本练习的一些测试需要 64 位整数，这超出了 Vim script 的整数大小限制。
由于这一限制，计算结果是针对一个表示该整数值的字符串进行测试的，而不是把答案表示为 Integer。
你能通过避免使用超出该语言直接允许范围的数字来解决这个问题吗？

[number]: https://vimhelp.org/eval.txt.html#expr-number
