# 测试

每道练习都需要完成以下常规步骤。

首先，切换到你想练习的那道练习所在的目录，本例中是 `bob`。

```bash
$ cd </path/to/exercism>/lfe/bob
```

接下来运行测试。`test`这个 make 目标依赖 `compile`，所以运行 `make test` 会先编译你的源代码，然后再运行测试。


```bash
$ make test
```

恭喜！你收获了一堆失败的测试！！！

现在读一读 `README.md`，弄清楚要让所有测试通过还需要做些什么。


修复测试报告的第一个错误，然后再次运行测试。

```bash
$ make test
```

接着修复源代码中下一个失败的测试，并反复运行测试，直到所有测试都通过。

所有测试都通过之后，最后再检查一遍 `src` 目录里的代码，确认自己对它满意，然后提交评审。

获取反馈，修改提交的解答，重新提交，再尝试下一道练习，如此循环，直到领悟 LFE 的真谛。
