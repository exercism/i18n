# 简介

*正则表达式*（regex）是一种很小的模式，用来描述一段文本应该长什么样。你不必自己一个字符一个字符地去检查字符串，而是把你想要的形状写一次，然后让 Factor 去做匹配。Factor 的正则表达式工具位于 [`regexp`][regexp] 词汇表中。

## 编写模式

在 Factor 中，正则表达式写在 `R/ `和`/`之间：

```factor
R/ cat/      ! the pattern that matches the letters c, a, t
```

模式中的大多数字符只表示它们自身，`R/ cat/`匹配的就是文本`cat`。真正的威力来自几个特殊片段，它们代表某*一类*字符，或者某个片段要出现*多少次*。

### 字符类：“集合中的一个字符”

```
\d        ! any digit, 0–9
\D        ! any NON-digit (the opposite of \d)
\s        ! any space, tab, or newline
\S        ! any NON-space character (the opposite of \s)
\w        ! a "word" character: a letter, a digit, or an underscore
\W        ! any NON-word character (the opposite of \w)
[A-Z]     ! any one capital letter A to Z
[a-z]     ! any one lowercase letter
[0-9]     ! any one digit (same as \d)
.         ! any single character at all
```

一个字符类恰好匹配*一个*字符。`[A-Z]`能匹配`Q`，但不能匹配`QQ`。

### 量词：“多少个”

把下面某个符号放在一个片段*后面*，说明它可以重复多少次：

```
{4}       ! exactly 4 times
{2,5}     ! between 2 and 5 times
+         ! one or more
*         ! zero or more
?         ! zero or one (optional)
```

所以`\d{4}`表示连续四个数字，而`[A-Z]+`表示一个或多个大写字母。合在一起，`R/ [A-Z]+-\d+/`描述的是“一个或多个大写字母、一个短横线，然后是一个或多个数字”，也就是像`SALE-2024`这样的文本。这里的`-`是普通字符：在`[ ]`之外，短横线只匹配短横线（在字符类内部，比如`[A-Z]`，它表示一个范围）。

## 匹配整个字符串

`matches?`回答的是“这个*完整的*字符串是否符合该模式？”，模式必须涵盖每一个字符，从头到尾：

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"SALE-2024"     R/ [A-Z]+-\d+/ matches? .   ! => t
"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text before)
"SALE-2024 NOW" R/ [A-Z]+-\d+/ matches? .   ! => f   (extra text after)
"sale-2024"     R/ [A-Z]+-\d+/ matches? .   ! => f   (lowercase letters)
```

即使`SALE-2024`出现在`"GET SALE-2024"`里面，`matches?`依然返回`f`：多出来的字符也是字符串的一部分，它们不符合该模式。当你只关心模式是否出现在*某处*时，就该用`re-contains?`，它在`matches?`返回`f`的地方恰好返回`t`：

```
re-contains? ( string regexp -- ? )
```

```factor
USING: regexp ;

"GET SALE-2024" R/ [A-Z]+-\d+/ matches? .      ! => f
"GET SALE-2024" R/ [A-Z]+-\d+/ re-contains? .  ! => t
```

## 在更长的文本中查找匹配

`re-contains?`只告诉你模式*是否*在里面。接下来这几个词会往里面看，并报告*匹配到了什么*：`all-matching-subseqs`返回模式匹配的每一处，结果是一个字符串序列，而`count-matches`只负责数出它们的数量：

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
```

```factor
USING: regexp ;

"3 cats, 12 dogs, 1 fish" R/ \d+/ all-matching-subseqs .
! => { "3" "12" "1" }            (every run of digits)

"the quick fox" R/ \S+/ all-matching-subseqs .
! => { "the" "quick" "fox" }     (every run of non-space characters)

"id_7!" R/ \w/ count-matches .   ! => 4   (i, d, _ and 7 count; ! does not)
```

## 替换匹配

`re-replace`会把每一处匹配换成一段替换文本，并返回新的字符串：

```
re-replace ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"page 7 of 12" R/ \d+/ "N" re-replace .
! => "page N of N"
```

`regexp`词汇表里还有更多值得了解的词，点开链接看详情：[`first-match`][first-match]（只匹配第一处）和[`re-split`][re-split]（在模式匹配的每一处拆分字符串）。
