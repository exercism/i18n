# 测试

用以下命令运行测试：

```shell
npm run test
```

你也可以让 Jest 以“watch”模式运行，这样当你保存对代码或测试模块的改动时，它会自动重新运行测试：

```shell
npm run watch
```

## 了解跳过测试

`skip` 方法会让测试套件不运行某个测试。这个函数也可以使用以下别名：`it.skip(name, fn)`、`xit(name, fn)` 或 `xtest(name, fn)`

- 为什么要跳过它们？

这样用户可以一次专注于一个测试，并在完善解答的过程中逐个启用。

- 如何启用它们？

把 `xtest` 改成 `test`。

```javascript
test("title cased phrases", () => {
  expect(Acronyms.parse("Portable Network Graphics")).toEqual("PNG");
});
```
