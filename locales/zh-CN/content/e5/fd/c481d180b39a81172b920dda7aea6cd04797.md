# 说明

在这个练习中，你将为一个朋友正在开发的新 RPG 游戏实现任务逻辑。游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛而忠诚的宠物狗。不幸的是，灾难降临了：她最好的朋友在森林里寻找浆果时被绑架了。Annalyn 会尝试找到并解救她最好的朋友，在这次冒险中可以带上她的狗。

沿着最好朋友的踪迹追踪了一段时间后，她找到了关押着最好朋友的营地。原来有两个绑匪：一个强大的骑士和一个狡猾的弓箭手。

找到绑匪后，Annalyn 在考虑她可以采取以下哪些行动：

- 快速攻击：如果骑士正在睡觉，就可以发动快速攻击，因为他穿上盔甲需要时间，所以他会很脆弱。
- 侦察：只要他们中至少有一个人醒着，就可以对这群人进行侦察。否则，侦察就是浪费时间。
- 向囚犯发信号：如果囚犯醒着而弓箭手在睡觉，就可以用鸟叫声向囚犯发信号，因为弓箭手受过鸟鸣信号的训练，可能会拦截信息。
- _解救囚犯_：Annalyn 可以尝试潜入营地来解救囚犯。
  这件事很冒险，只有两种方式之一才能成功：
  - 如果 Annalyn 带着她的宠物狗，那么只要弓箭手在睡觉，她就能救出囚犯。
    骑士怕狗，而弓箭手来不及准备好，Annalyn 和囚犯就已经逃走了。
  - 如果 Annalyn 没有带狗，那她和囚犯就必须非常小心！
    如果囚犯醒着，而骑士和弓箭手都在睡觉，Annalyn 就能救出囚犯；但如果囚犯在睡觉，就没法救他：囚犯会被 Annalyn 的突然出现吓到，从而惊醒骑士和弓箭手。

你有四个任务：根据在森林里遇到的三个人物的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可用的逻辑。

## 1. 检查是否可以发动快速攻击

实现`canFastAttack()`方法，它接收一个布尔值，表示骑士是否醒着。如果根据骑士的状态可以发动快速攻击，该方法返回`true`。否则返回`false`：

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. 检查是否可以侦察这群人

实现`canSpy()`方法，它接收三个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。如果根据这三个人物的状态可以侦察这群人，该方法返回`true`。否则返回`false`：

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. 检查是否可以给囚犯发信号

实现`canSignalPrisoner()`方法，它接收两个布尔值，分别表示弓箭手和囚犯是否醒着。如果根据这两个人物的状态可以向囚犯发信号，该方法返回`true`。否则返回`false`：

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. 检查是否可以解救囚犯

实现`canFreePrisoner()`方法，它接收四个布尔值。前三个形参分别表示骑士、弓箭手和囚犯是否醒着。最后一个形参表示 Annalyn 的宠物狗是否在场。如果根据这三个人物的状态以及 Annalyn 的宠物狗是否在场可以解救囚犯，该方法返回`true`。否则，返回`false`：

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
