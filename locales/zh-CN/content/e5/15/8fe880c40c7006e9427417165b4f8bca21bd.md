# 提示

## 通用

- 你需要定义[函数][functions]，并使用[算术运算符][arithmetics]。

## 1. 把预期的烘焙时间存入常量

- 定义一个 [const][const]，用来存储这个值。

## 2. 计算准备时间（分钟）

- 使用 [`times` 算术运算符][arithmetics]，将实参乘以 `2`。

## 3. 计算剩余的烘焙时间（分钟）

- 使用 [`minus` 算术运算符][arithmetics]，用 `60` 减去实参。

## 4. 计算总工作时间（分钟）

- 复用第一步中定义的 `preparation_time` 函数。
- 使用 [`plus` 算术运算符][arithmetics]，把 `preparation_time` 的返回值加到实参上。

[functions]: https://docs.julialang.org/en/v1/manual/functions/
