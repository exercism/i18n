# 介绍

## 通用语法

`for` 循环是用于重复执行某段逻辑的最常用语句之一。在 Go 中，它由 `for` 关键字、一个头部和一个循环体组成，循环体是包裹在花括号里的代码块。头部由 3 个用分号 `;` 分隔的部分组成：初始化、条件和后置。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **初始化**部分是一段只在循环开始前运行一次的代码。
- **条件**部分必须是一个求值为布尔值的表达式，用来控制循环何时停止。
  只要这个条件求值为 true，循环里的代码就会一直运行。
  一旦这个表达式求值为 false，循环就不会再执行任何迭代。
- **后置**部分是一段会在每次迭代结束时运行的代码。

**注意：** 与其他语言不同，头部的这三个部分周围没有括号 `()`。事实上，插入这样的括号会导致编译错误。不过，包裹循环体的花括号 `{ }` 始终是必需的。

## `for` 循环：一个示例

初始化部分通常用来设置一个计数器变量，条件部分检查循环应该继续还是停止，后置部分通常在每次重复的末尾让计数器自增。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```
