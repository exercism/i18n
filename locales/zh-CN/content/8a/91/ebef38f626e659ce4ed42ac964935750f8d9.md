# 简介

这个练习会用到[莉娅的美味千层面][lasagna]中的整数运算。在这里，你将处理浮点数，并为具体任务挑选合适的除法词。

## 整数与浮点数

Factor 会区分整数（`1`、`42`、`1_000_000`）和浮点数（`1.0`、`3.14`、`6.02e23`）。如果在一次计算中混用整数和浮点数，结果就是浮点数：

```factor
2 3 + .      ! => 5
2 3.0 + .    ! => 5.0
```

你也可以在数字里加下划线来给数位分组，比如 `1_000_000`，Factor 会直接忽略这些下划线。

## 除法词

Factor 为除法提供了几个不同的词，它们都属于[`math`][math]词汇表。

```
/    ( x y -- x/y )    ! exact: ratio for two integers, float if either is a float
/f   ( x y -- f   )    ! always a float
/i   ( x y -- q   )    ! integer division (truncates toward zero)
mod  ( x y -- r   )    ! remainder
/mod ( x y -- q r )    ! quotient and remainder together
```

```factor
1 2 / .        ! => 1/2     (a proper ratio)
16 3 / .       ! => 5+1/3   (an improper ratio, printed as a mixed numeral)
16 3 /f .      ! => 5.333333333333333
16 3 /i .      ! => 5      (truncated)
16 3 mod .     ! => 1
16 3 /mod .s   ! quotient and remainder in one pass
! => 5
! => 1
16.0 3 / .     ! => 5.333333333333333
```

对两个整数来说，`/`得到的是`ratio`（Factor 的精确有理数类型）；只要有一个输入是浮点数，结果就是`float`。`/f`即使两个输入都是整数，也会强制返回浮点数结果。`/i`始终向零截断。

## 检查

来自[`math`][math]、[`math.functions`][math.functions]和[`math.primes`][math.primes]的数字判定词：

```
zero?    ( x       -- ? )
even?    ( x       -- ? )
odd?     ( x       -- ? )
prime?   ( x       -- ? )
divisor? ( m n     -- ? )    ! true when n divides m
integer? ( x       -- ? )    ! true for ints (fixnum or bignum)
float?   ( x       -- ? )    ! true for floats
number?  ( x       -- ? )    ! true for any numeric kind
```

```factor
0 zero? .            ! => t
0.0 zero? .          ! => t
3 zero? .            ! => f

4 even? .            ! => t
7 even? .            ! => f
7 odd? .             ! => t

7 prime? .           ! => t
9 prime? .           ! => f

15 5 divisor? .      ! => t   (5 divides 15)
15 4 divisor? .      ! => f
```

## 浮点数转整数

[`math.functions`][math.functions]词汇表里的`floor`、`ceiling`和`round`都返回浮点数（`3.0`，而不是`3`）。要得到真正的整数，可以接着调用`>integer`：

```factor
3.7 floor >integer .       ! => 3
3.2 ceiling >integer .     ! => 4
```

## 乘方与绝对值

`sq`、`^`和`abs`（在[`math.functions`][math.functions]中）分别用来计算平方、任意次幂和绝对值：

```
sq  ( x   -- x*x )
^   ( x y -- x^y )
abs ( x   -- |x| )
```

```factor
5 sq .          ! => 25
2 10 ^ .        ! => 1024
2 0.5 ^ .       ! => 1.4142135623730951
-7 abs .        ! => 7
3 abs .         ! => 3
```

## 最小值和最大值

`min ( x y -- z )`和`max ( x y -- z )`（在[`math.order`][math.order]中）返回两个数中较小或较大的那个：

```factor
3 7 min .       ! => 3
3 7 max .       ! => 7
```

最常见的用法是*钳制*，也就是用`max`把一个值固定在下界（例如`0 max`能让值保持非负），或者用`min`把它固定在上界。

## 顺序判定词

`math.order`还提供了`before?`、`after?`、`before=?`和`after=?`，这些是比较判定词，适用于任何可排序的类型：数字、字符串和字符：

```
before?  ( obj1 obj2 -- ? )   ! obj1 <  obj2
before=? ( obj1 obj2 -- ? )   ! obj1 <= obj2
after?   ( obj1 obj2 -- ? )   ! obj1 >  obj2
after=?  ( obj1 obj2 -- ? )   ! obj1 >= obj2
```

当值可能是字符串时，请用这些判定词代替`<`/`<=`，因为算术运算符不会对字符串进行分派。
