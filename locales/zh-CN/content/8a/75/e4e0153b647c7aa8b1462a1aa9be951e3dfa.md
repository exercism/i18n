# 关于

Factor 的条件判断都以**引用**作为分支：引用就是用方括号 `[ ... ]` 写成的代码，它会作为值被压入栈，而不是立刻执行，要等条件判断选中它之后才会运行。（引用本身会在后面的练习里完整介绍。）

最基本的三个在`kernel`中：

```
if      ( ? then-quot else-quot -- )
when    ( ? quot -- )
unless  ( ? quot -- )
```

带星号的两个变体在布尔值为真时，会把它当作一个可用的值，这就是经典的“值或`f`”组合：

```
if*     ( ? true false -- )    ! truthy: true called WITH value
unless* ( ? false      -- )    ! falsy: false runs and pushes default
```

```factor
: abs   ( x -- y ) dup 0 < [ neg ] [ ] if ;
: shout ( s -- )   dup empty? [ drop ] [ >upper print ] if ;
```

分支多于两个时，用`combinators`中的`cond`：它会遍历一个由`{ predicate body }`对组成的数组，运行第一个成立的谓词所对应的主体。惯用的写法是在每个谓词里用`dup`，让输入保留下来；主体则以`drop`开头，先把它丢掉，再压入结果：

```factor
{
    { [ dup 0 <  ] [ drop "negative" ] }
    { [ dup 0 =  ] [ drop "zero"     ] }
    [ drop "positive" ]
} cond
```

末尾不带谓词的那一项就是默认分支。
