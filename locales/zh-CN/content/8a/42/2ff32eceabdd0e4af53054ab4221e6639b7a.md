# 测试

每个练习都包含一个测试文件。
使用`bats`程序运行测试。

```bash
bats hello_world.bats
```

如果你需要在本地运行测试时输出调试信息，请参阅[本地调试][debugging]。

需要先安装`bats`。
关于如何为你的系统安装`bats`，请参阅 [Bash 赛道上的测试][tests] 页面。

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

[bats-assert]: https://github.com/bats-core/bats-assert

## 跳过的测试

完成一道练习，意味着让它所有的测试都通过。
默认情况下，运行测试时只会执行一个测试（第一个）。
这是有意设计的，这样你可以专注于让这一个测试通过。
一旦它通过，你就可以注释掉或删除下一处标注，从而启用下一个测试：

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## 覆盖跳过设置

要运行所有测试，包括带有`skip`标注的测试，可以运行：

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

用包装函数来省去重复输入会很方便：

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

之后只需这样运行测试：

```bash
bats
```
