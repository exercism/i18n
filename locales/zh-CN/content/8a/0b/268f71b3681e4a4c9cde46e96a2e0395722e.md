# 关于

Dart 将面向对象编程和静态类型与 JavaScript 等动态语言的灵活性结合在一起。
Dart 的设计初衷是简化常见的编程任务，它迅速在软件开发社区中走红，这尤其得益于它与 [Flutter](https://flutter.dev) 的紧密集成。Flutter 是一个广泛使用的跨平台开发框架。

## Dart 的核心概念

- **简单且熟悉：** 对熟悉 Java、JavaScript 或 C# 等语言的开发者来说，Dart 很容易上手。
  它的语法简洁一致，非常平易近人。
- **现代面向对象语言：** Dart 融入了现代面向对象的原则，对类、继承和接口都提供了完善的支持。
- **强类型且灵活：** Dart 虽然是一门静态类型语言，却提供灵活的类型推断和动态特性，让开发者兼得两者之长。
- **异步编程轻而易举：** Dart 的 `async` 和 `await` 关键字简化了并发。
  事件驱动模型围绕**isolates**（轻量级的类线程结构）构建，无需复杂的线程就能高效地异步执行代码。
- **工具与库一应俱全：** Dart 提供大量内置库，其生态还得到 [Pub.dev](https://pub.dev) 的支持。Pub.dev 是一个包管理器，提供丰富的开源库和工具。
- **跨平台开发：** Dart 驱动着 [Flutter](https://flutter.dev)，它是最受欢迎的框架之一，可以用同一套代码为移动端、Web 和桌面端构建高性能的跨平台应用。
- **Web 支持：** Dart 代码可以转译成 JavaScript，因此既适合客户端 Web 开发，也适合服务端 Web 开发。
  像 [AngularDart](https://github.com/angulardart-community)（原 [https://github.com/angulardart](https://github.com/angulardart)）这样的框架，就是专门为 Dart Web 应用量身打造的。
- **服务端能力：** Dart 不只用于前端开发，还能配合 [Shelf](https://pub.dev/packages/shelf) 等框架构建可扩展的服务端应用。
- **高性能：** Dart 代码会被编译成移动端和桌面端应用的原生机器码，以及为 Web 优化的 JavaScript，从而在各平台上提供高性能。

## Dart 的多样用途

- **移动应用：** Dart 最突出的用途是通过 Flutter 开发移动应用，让 iOS 和 Android 共享一致的 UI 和业务逻辑。
- **Web 开发：** Dart 可以编译成 JavaScript 来构建现代 Web 应用，既可以借助原生的 Dart 框架，也可以使用 Flutter for web。
- **桌面开发：** 有了 Flutter，Dart 现在支持为 Windows、macOS 和 Linux 创建原生应用，真正实现跨平台。
- **后端服务：** 凭借简洁的语法和性能优化，Dart 在后端服务中的应用越来越多。
  它可以处理 RESTful API、微服务等。
- **Firebase 与云端集成：** Dart 通过官方库对 Firebase 及其他云服务的集成提供了完善的支持，是云端应用的热门选择。

## 近期改进

- **空安全：** Dart 引入了**健全的空安全**，通过在开发期间确保不可空类型被正确使用，帮助消除空引用错误。
- **更快的编译：** Dart 在改进编译流程方面取得了长足进步，同时提供**提前编译（AOT）**和**即时编译（JIT）**，保证快速的开发周期和优化后的发布构建。
- **桌面与嵌入式设备：** Flutter 扩展到桌面和嵌入式平台，让 Dart 变得前所未有的多面，开发者可以为移动端和 Web 之外的众多设备创建应用。

Dart 不断壮大的生态系统、强大的开发者支持以及跨平台能力，使其成为现代应用开发颇具吸引力的选择。
