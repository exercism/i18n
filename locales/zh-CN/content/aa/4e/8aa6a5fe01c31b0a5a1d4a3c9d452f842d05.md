# 简介

在 Elixir 中，我们可以定义模块属性，把它们当作函数中的常量使用。

```elixir
defmodule Example do
  # Defines the attribute as the value 1
  @constant_number 1

  def example_value() do
    # Returns the value 1
    @constant_number
  end
end
```

用来定义模块常量时，属性可以是任何能在编译时求值的表达式。编译之后，模块属性就无法访问了，因为它们会在编译时展开，这和 C 这类语言里定义的宏类似。
