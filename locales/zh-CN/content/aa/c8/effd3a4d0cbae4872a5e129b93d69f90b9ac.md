# 关于

C# 中的布尔值由`bool`类型表示，它的值可以是`true`或`false`。

C# 支持四种[布尔运算符][operators]：`!`（NOT）、`&&`（AND）、`||`（OR）和 `^`（XOR）。其中 `&&` 和 `||` 运算符使用_短路求值_，也就是说，只有当需要时才会去求运算符右侧的值。

```csharp
true || false // => true
true && false // => false
true ^ false  // => true
true ^ true   // => false
```

这三种布尔运算符各自的[_运算符优先级_][precedence]都不相同。因此，它们的求值顺序是：`not` 排第一，`&&` 第二，`^` 第三，最后是 `||`。如果想“绕过”这些规则，可以把布尔表达式用括号（`()`）括起来，因为括号的运算符优先级更高。

```csharp
!true && false   // => false
!(true && false) // => true
```
