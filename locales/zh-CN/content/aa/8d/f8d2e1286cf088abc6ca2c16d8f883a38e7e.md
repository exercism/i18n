# 说明补充

## 寄存器

| 寄存器 | 用途     | 类型    | 说明                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | 输入     | 地址 | 以 null 结尾的输入字符串                     |
| `$v0`    | 输出    | 布尔值 | 输入是全字母句（`0` = `false`，`1` = `true`） |
| `$t0-9`  | 临时 | 任意     | 用于临时存储                       |
