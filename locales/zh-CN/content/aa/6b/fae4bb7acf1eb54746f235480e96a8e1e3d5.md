# 关于

条件语句会根据条件为`true`还是`false`，执行不同的代码。

[`if` 语句][if_statement]只有当条件为 `true` 时才会执行它的主体。
Go 没有真值或假值的概念，因此条件必须是`bool`类型。
像`if mySlice { ... }`或`if 1 { ... }`这样的表达式会导致编译错误。

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

用`else if`检查更多条件，用`else`作为都不匹配时的兜底。
条件会从上到下依次求值，只有第一个条件为 true 的分支会运行。

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

一般来说，Go 更倾向于从特殊情况中提前返回，避免使用`else`。

```go
func getVal(connected bool) int {
    if !connected {
        return readLocalVal()
    }

    return readVal()
}
```

`if` 语句还可以包含一个简短的初始化语句。
常用来在调用之后立即检查错误：

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

在初始化语句中声明的变量，作用域仅限于整个`if`/`else`链。
值得注意的是，Go 没有三元运算符，这是为了让代码易于浏览而做出的有意设计选择。

想了解更多，请参阅 [Go by Example: If/Else][go_by_example_if]。
