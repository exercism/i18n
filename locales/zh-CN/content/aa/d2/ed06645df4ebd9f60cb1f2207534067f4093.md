# 关于

[匿名函数][anon-fns]在 Elixir 中经常单独使用，也用作返回值，或作为高阶函数（如`Enum.map/2`）的实参：

```elixir
Enum.map([1, 2, 3], fn n -> n + 1 end)
# => [2, 3, 4]
```

Elixir 中的函数被视为一等公民：

- 具名函数和匿名函数都可以赋值给变量。
- 具名函数和匿名函数都可以像数据一样，作为实参和返回值传来传去。
- 匿名函数可以动态创建。

匿名函数用[`fn`][kernel-fn]关键字创建，通过点号（`.`）调用：

```elixir
function_variable = fn n -> n + 1 end

function_variable.(1)
# => 2
```

匿名函数也可以用[`&`捕获简写][kernel-capture]创建。

- 开头的`&`表示捕获表达式的开始。
- `&1`、`&2`等指的是匿名函数的位置实参。

  ```elixir
  # Instead of:
  fn x, y -> abs(x) + abs(y) end

  # We can write:
  &(abs(&1) + abs(&2))
  ```

- `&`捕获运算符也可以用来[_捕获_现有的具名函数][capture]：

  ```elixir
  # Instead of:
  fn a, b -> a <= b end

  # We can capture the function using its name and arity:
  &<=/2
  ```

Elixir 中的匿名函数是[闭包][closure]。它们可以访问定义函数时处于作用域内的变量。在匿名函数内部赋值的变量，在函数外部无法访问：

```elixir
y = 2

square = fn ->
  x = 3
  x * y
end

square.()
# => 6

x
# => ** (CompileError): undefined function x/0
```
