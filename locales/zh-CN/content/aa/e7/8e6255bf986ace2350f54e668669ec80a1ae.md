# 测试

下载的练习包含以下文件，用于构建和测试你提交的解答：

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

文件名因练习而异。
把你提交的解答写在第一个`.vb`文件中。
第二个以`Tests.vb`结尾的文件是 [xUnit 测试套件][xunit]。
通常，你只会为了取消跳过后面的测试而修改这个文件。
最后两个文件你都不需要修改。
`.vbproj`文件包含项目的构建设置和直接包引用。
生成的`packages.lock.json`文件记录了已解析的直接和传递包版本。

~~~exercism/note
测试描述了提交的解答必须满足哪些行为才能通过。
它们有助于说明指令中没有涵盖的细节。
~~~

## 运行测试

在练习目录中打开终端，然后运行：

```bash
dotnet test
```

该命令会还原项目的依赖项、构建项目并运行测试。
你还可以使用`dotnet watch test`，在源文件发生变化时重新运行测试。

## 跳过的测试

练习一开始只启用第一个测试，让你可以一步一步地解决剩下的测试。
打开以`Tests.vb`结尾的文件即可找到这些测试。
每个测试都是一个`Sub`子程序，用 xUnit 的`<Fact>`特性标记。
只要测试的`<Fact>`特性带有`Skip`实参，它就会被跳过：

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

要启用这个测试，只需删掉`Skip`实参：

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

新启用的测试通过后，对下一个被跳过的测试重复这一过程。
当所有测试都已启用并通过时，你就完成了。
