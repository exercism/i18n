# 关于

ABAP 支持对数值使用常见的算术运算符：

- `+` 相加。
- `-` 相减。
- `*` 相乘。
- `/` 相除。
- `MOD` 返回整数除法的余数。

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

乘法和除法会先于加法和减法求值。如果想把某部分计算明确地归为一组，请使用括号。

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
