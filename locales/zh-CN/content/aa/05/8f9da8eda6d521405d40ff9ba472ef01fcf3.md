# 在命令行上测试

用下面的命令运行测试：

```bash
$ cargo test
```

除了第一个测试，其余测试都被忽略了。让第一个测试通过之后，打开位于`tests`目录中的测试源文件，去掉下一个测试上的`#[ignore]`标记，再让它通过。每个测试都是一个函数，函数上方带有`#[test]`标记。就这样继续下去，直到所有测试都通过。

如果你想在不修改测试源文件的情况下_只运行被忽略的_测试，可以用：

```bash
$ cargo test -- --ignored
```

如果你使用的是 Rust 1.51 或更高版本，可以用下面的命令运行_所有_测试：

```bash
$ cargo test -- --include-ignored
```

要运行某个特定的测试，比如`some_test`，可以用：

```bash
$ cargo test some_test
```

如果这个特定的测试被忽略了，可以用：

```bash
$ cargo test some_test -- --ignored
```

想进一步了解 Rust 的测试，可以参考在线[测试文档][rust-tests]。

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
