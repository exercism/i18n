# 说明补充

## 寄存器

| 寄存器 | 用途     | 类型    | 说明                                       |
| -------- | --------- | ------- | ------------------------------------------------- |
| `$a0`    | 输入     | 整数 | 起始数字                                   |
| `$v0`    | 输出    | 整数 | 预期的步数，如果数字无效则为 -1 |
| `$t0-9`  | 临时 | 任意     | 用于临时存储                        |
