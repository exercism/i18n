# 关于

`awk` 是一门解释型编程语言，专为文本处理而设计，通常用作数据提取和报表工具。
它是大多数类 Unix 操作系统的标准配置，并有 [POSIX 规范][posix]。

`awk` 的编程范式可以说是“数据驱动”：
`awk` 程序读取一行行文本（或其他文本单位），寻找_模式_的匹配。
一旦匹配成功，就执行指定的_动作_。

`awk` 程序大致长这样
```awk
pattern1 {action1}
pattern2 {action2}
...
```

_模式_可以是正则表达式，也可以是其他计算结果为 true/false 的表达式。
_模式_可以省略，此时对每条文本记录都执行_动作_。
_动作_也可以省略，此时默认动作是打印当前记录。

`awk` 是用户工具箱里非常好用的工具。
它非常擅长在命令行上输入的简短“单行”程序。
一个 `awk` 程序就能替代大多数由 `grep`、`sed`、`tr`、`cut` 组成的管道。

## 实现

`awk` 由 Alfred Aho、Peter Weinberger 和 Brian Kernighan 于 1977 年发明（这门语言的名字就来自他们三人的姓氏）。
这个实现后来被称为“old awk”。
1985 年发布了改进版本，被称为“BWK awk”、“new awk”或“the one-true-awk”。
这是 macOS 和部分 \*BSD 发行版随附的版本

另一个常见实现是 `mawk`，它基于字节码解释器。
`mawk` 速度非常快。
在许多 Linux 发行版上，`mawk` 是默认随附的 `/usr/bin/awk`。

### GNU awk

本学习轨道将使用 `gawk`，也就是 GNU 的 awk 实现。
`gawk` 可能没有 `mawk` 那样极致的速度，但功能非常丰富，文档完善，还有一些实用的命令行选项。

### Shebang

视平台而定，只要在文件顶部加上一行 [shebang][shebang]，就可以执行 awk 脚本。
在大多数系统上，下面两个 shebang 之一应该就能正常工作。
不过，由于没有哪个 shebang 能在所有系统上都适用，我们选择省略 shebang。

```bash
#!/usr/bin/env -S gawk -f
#!/usr/bin/gawk -f
```
