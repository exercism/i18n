# 介绍

## Result

`Result` 类型是 Elm 语言中用于错误报告的方案，也是实现错误恢复的基础。它与 `Maybe` 类型有些相似，但 `Maybe` 虽然可以由可能失败的函数返回，却不会告诉你任何关于失败原因的信息。`Result` 则包含了这些关于失败原因的上下文。

`Result` 类型的定义如下：

```elm
type Result error value
  = Ok value
  | Err error
```

这在 Elm 术语中称为“自定义类型”定义。
`OK value` 和 `Error error` 中的 `error` 和 `value` 表示类型变量，意思是它可以是任意类型，比如 `Int`、`Bool` 或 `String`。
因此，`Result String Int` 是一个预期包含 `Int` 的变量，如果出现错误，则会用 `String` 来表示。
有一个 [Result 模块](https://package.elm-lang.org/packages/elm/core/latest/Result)，其中包含许多处理结果的实用辅助函数。
