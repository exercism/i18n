# 说明

在这个练习里，你会玩一辆遥控车，你终于攒够钱把它买下来了。

汽车一开始的电池是满的（100%）。
每次你用遥控器驾驶这辆车，它都会行驶 20 米，并消耗 1% 的电量。
这辆车的昵称只有在创建时才会确定。

这辆遥控车有一个很酷的 LED 显示屏，可以显示两条信息：

- 它行驶的总距离，显示为：`"<METERS> meters"`。
- 电池的剩余电量，显示为：`"Battery at <PERCENTAGE>%"`。

如果电量降到 0%，你就不能再驾驶这辆车了，显示屏会显示 `"Battery empty"`。

## 1. 创建一辆全新的遥控车

实现 `new_remote_control_car/0` 函数，返回一个全新的遥控车对象：

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. 创建一辆带昵称的全新遥控车

实现 `new_remote_control_car/1` 函数，返回一个带有指定昵称的全新遥控车对象：

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. 显示距离

实现 `display_distance/0` 函数，它接收一个汽车对象作为输入，并输出 LED 显示屏上显示的距离字符串：

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. 显示电量百分比

实现 `display_battery/0` 函数，它接收一个汽车对象作为输入，并输出 LED 显示屏上显示的电量百分比字符串：

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

如果电量降到 0%，显示屏会显示 "Battery empty"。

## 5. 驾驶会改变电量和行驶距离

实现 `drive/0` 函数，它会：

- 接收一个汽车对象作为输入
- 把行驶的米数增加 20
- 消耗 1% 的电量
- 输出修改后的汽车对象

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. 处理电量耗尽时的驾驶

更新 `drive/0` 函数，使其在电量耗尽（为 0%）时既不增加行驶距离，也不减少电量：

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
