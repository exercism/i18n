# 说明补充

## 子类型

本练习定义了一个名为 `Positive` 的子类型，适用于所有大于 0 的自然数。
子类型可以看作一个二元组 `⟨x, h⟩`，其中 x 是值，h 是该值有效的证明。

子类型内部的值（这里是 x）可以通过 `.val` 访问，例如 `x.val`。
它的证明可以通过 `.property` 访问，例如 `x.property`。
两者也都和往常一样，可以通过模式匹配来访问。

要为子类型构造一个值，必须先证明它有效，在这里就是要证明这个数字大于 0。

Lean 中有许多引理和定理可以作为这个证明的起点。
例如，`Nat.zero_lt_succ` 是一条引理，它断言对任意自然数 `n` 都有：`0 < n + 1`。
