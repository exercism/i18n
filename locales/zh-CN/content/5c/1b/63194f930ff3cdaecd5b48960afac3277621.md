# 简介

许多程序需要（看似）随机的值来模拟现实世界中的事件。

常见且熟悉的例子包括：

- 抛硬币：一个随机值，取值为`"H"`或`"T"`。
- 掷骰子：一个 1 到 6 的随机整数。
- 洗一副牌：一个牌列表的随机顺序。

用计算机生成真正随机的值是一项[出奇困难的技术挑战][web-truly-random]，因此这些结果有时会被称为“伪随机”。

***重要***：本概念*不*涉及密码学安全的随机数，那是一项困难得多的挑战。

不过，R 源自一个统计软件包，常被用于模拟，因此它提供了丰富多样的生成随机值的方法。对于建模、模拟和游戏中的大多数应用来说，这些结果已经足够好了。

## [有放回与无放回抽样][yt-sampling-with-replacement]

假设我们有一个袋子，里面有 3 个红球和 4 个绿球，我们随机从袋子里摸出一个球。要再摸第二个球，有两种可能：

1. 把第一个球放回袋子，充分摇匀后再摸出另一个。此时球的数量和之前一样（7 个），而且*红球与绿球的比例也相同*。
2. 把第一个球放在桌上，再摸出第二个。此时袋子里只剩 6 个球，而且*红球与绿球的比例取决于第一个球的颜色*。

情形 1 是有放回，情形 2 是无放回，*两者会给出不同的结果*。

## 用`sample`生成离散值

要从有限数量的离散值中选取，可以带放回或不带放回地使用`sample()`。这对整数、字符串等都很有用。

```R
sample(1:10, 5) # no repeats by default
#> [1] 8 3 4 2 6

sample(1:10, 5, replace = TRUE) # repeats are OK
#> [1] 10 10  7 10  9

languages <- c("Fortran", "R", "Python", "Julia")
sample(languages, 1)
#> [1] "Python"

sample(c("H", "T"), 5, replace = TRUE) # coin flips
#> [1] "T" "T" "H" "H" "H"

sample(c(TRUE, FALSE), 5, replace = TRUE) # alternative coin flips
#> [1] FALSE  TRUE FALSE  TRUE  TRUE
```

抽样很适合放进数据管道。例如，生成随机的字母数字字符串：

```R
library(stringr)

c(letters, LETTERS, 0:9) |> sample(50) |> str_flatten()
#> [1] "5tX71jhbM9zUmKrpENBQyGYaZdJPVAx06leSF2s8gcfw3OviIH"
```

## 洗牌

其他几门语言都提供了专门打乱序列的函数。

R 没有洗牌函数。*为什么？*

要理解这一点，再来看一眼`sample`函数。

完整形式是`sample(x, size, replace = FALSE, prob = NULL)`，其中`x`（通常）是要从中抽样的序列，`size`是要选取的元素个数。

我们已经讨论过`replace`，它的默认值是无放回抽样。现在先忽略`prob`，它可以让你为`x`中的各个元素赋予不相等的权重。

如果省略`size`，只提供`x`，会发生什么？

```R
x <- letters[1:6]
x
#> [1] "a" "b" "c" "d" "e" "f"
sample(x)
#> [1] "e" "a" "f" "b" "c" "d"
```

以典型的 R 风格，这个模式是输入向量、输出向量，而`size`默认为`length(x)`。

“对`x`的所有元素做无放回抽样”只是“打乱`x`”的一种更技术化的说法。

*因此*，没有`shuffle`函数，因为`sample`已经完全做到了我们需要的事！

## 使用分布

上面的例子描述的都是所有结果等可能的情形。例如，`sample(1:100)`给出 1 到 100 之间任意整数的概率相同。

这称为`uniform`分布。

许多现实世界的情形远比这复杂。因此，统计学家创造了各种各样的`distributions`，用数学方式描述“现实世界”的结果。

## 浮点数

### 均匀分布

要生成等权重的浮点数分布，请使用`runif()`（重点看“**r**andom-**unif**orm”，并抵制把它读成“run if”这种自然但*错误*的倾向）。`min`和`max`都可以指定，默认值分别为 0 和 1。

```R
runif(5)  # generate 5 values
#> [1] 0.3038506 0.3527959 0.3319309 0.4846354 0.4386279

# generate 5 non-negative values <= 100.0
runif(5, max = 100)
#> [1] 79.70762 51.62232 52.85281 71.08571 63.94380
```
