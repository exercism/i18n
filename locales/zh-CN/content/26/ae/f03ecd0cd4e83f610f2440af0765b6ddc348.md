# 说明补充

## 词

实现：

- `grep ( pattern flags files -- lines )`

`pattern` 是搜索字符串，`flags` 是由零个或多个标志字符串`"-n"`、`"-l"`、`"-i"`、`"-v"`和`"-x"`组成的数组，`files` 是由一个或多个文件名组成的数组。把匹配的行（连同所请求的文件名和行号前缀）以字符串数组的形式返回。

当指定了 `-l` 标志时，返回一个数组，其中包含至少有一行匹配的文件名。

## 读取文件

使用`file-lines`读取一个文件的行，并传入一种编码：

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

三个测试数据文件（`iliad.txt`、`midsummer-night.txt`和`paradise-lost.txt`）随练习一起放在工作目录中，所以直接按文件名读取即可。
