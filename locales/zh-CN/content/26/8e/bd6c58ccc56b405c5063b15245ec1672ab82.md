# 简介

在 Go 1.18 中，Go 加入了对**泛型**的支持。
泛型让你可以编写适用于不同数据类型的函数和数据结构，而不必重复代码。

## 为什么需要泛型？

在 Go 中，函数和类型通常只针对特定的类型，比如`int`或`string`。
在泛型出现之前，要支持多种类型，你有两个选择。
第一种是编写多个名字不同的函数，比如`SumInts`和`SumFloats`。
这种做法会产生重复代码，难以维护。
第二种是使用空接口`any`（`interface{}`）。
然而，空接口取消了编译时的类型检查，并且需要在运行时做类型断言。
泛型在提供类型安全的同时避免了重复代码，从而解决了这个问题。

## 泛型函数

在函数名后面用方括号`[...]`加上**类型形参**，就定义了一个泛型函数。
下面是一个返回反转切片的泛型函数示例：

```go
func Reverse[T any](s []T) []T {
    result := make([]T, len(s))
    for i, v := range s {
        result[len(s)-1-i] = v
    }
    return result
}
```

在这个例子中，`T`是一个类型形参。
你可以把`T`看作真实类型的占位符。
方括号里的`any`关键字是**类型约束**。
约束告诉编译器，`T`允许使用哪些类型。
在这里，`any`表示`T`可以是任意类型。

### 调用泛型函数

你可以在方括号里传入实际的类型来调用泛型函数。
这个实际的类型叫做**类型实参**。

```go
numbers := []int{1, 2, 3}
reversedNumbers := Reverse[int](numbers)
```

大多数情况下，Go 编译器能从函数实参自动推断出类型。
这个特性叫做**类型推断**。
有了类型推断，你就不必在方括号里写出类型实参了。

```go
words := []string{"apple", "banana"}
reversedWords := Reverse(words)
```

在这个例子中，编译器看出`words`是一个字符串切片，于是推断出`T`是`string`。

## 类型约束

每个类型形参都必须有约束。
约束规定了哪些类型可以作为类型实参使用。
约束还决定了你能对该类型的值执行哪些操作。

### `any`约束

`any`约束允许任意类型。
在 Go 中，`any`是空接口`interface{}`的别名。
因为`any`允许所有类型，所以函数只能执行对所有 Go 类型都适用的操作。
例如，如果你有两个`any`值，里面装的是切片，那么它们不能用`==`比较，因为切片本身就不能用`==`比较。

### `comparable`约束

Go 提供了一个名为`comparable`的内置约束。
`comparable`约束允许任何支持`==`和`!=`运算符的类型。
可比较的类型包括布尔值、数字、字符串、指针、通道，以及由可比较类型构成的结构体或数组。

下面是一个检查切片中是否包含某个特定元素的函数示例：

```go
func Contains[T comparable](elems []T, target T) bool {
    for _, elem := range elems {
        if elem == target {
            return true
        }
    }
    return false
}
```

因为`T`使用了`comparable`约束，所以`elem == target`是合法的。
如果把`comparable`换成`any`，编译器就会报错。

### 使用接口类型集的自定义约束

从 Go 1.18 开始，接口除了方法之外，还可以定义类型集。
你可以用竖线`|`在接口中列出允许的类型。

```go
type Number interface {
    int | int64 | float64
}
```

现在你可以把`Number`用作函数的约束：

```go
func Double[T Number](value T) T {
    return value * 2
}
```

因为`Number`中的所有类型都支持`*`运算符，所以 Go 允许在函数体内使用`value * 2`。

### 用`~`近似底层类型

有时你会基于基本类型定义自己的类型：

```go
type MyInt int
```

上面定义的`Number`约束只允许`int`、`int64`和`float64`这几种确切的类型。
如果向`Double`传入一个`MyInt`值，编译器会报错，因为`MyInt`与`int`不匹配。
要允许所有底层类型为`int`的类型，在类型前面加上波浪号`~`：

```go
type Number interface {
    ~int | ~int64 | ~float64
}
```

现在你就可以用`Double`处理`MyInt`类型的值了。

### `cmp.Ordered`约束

标准库在[`cmp`包][doc-cmp]中提供了`cmp.Ordered`约束。
`cmp.Ordered`约束允许任何支持比较运算符`<`、`<=`、`>`和`>=`的类型。

## 泛型类型

你也可以用类型形参来定义泛型类型，比如结构体。
下面是一个泛型`Stack`数据结构的示例：

```go
type Stack[T any] struct {
    elements []T
}

func (s *Stack[T]) Push(v T) {
    s.elements = append(s.elements, v)
}

func (s *Stack[T]) Pop() (T, bool) {
    if len(s.elements) == 0 {
        var zero T
        return zero, false
    }
    lastIndex := len(s.elements) - 1
    top := s.elements[lastIndex]
    s.elements = s.elements[:lastIndex]
    return top, true
}
```

声明泛型类型的变量时，必须在方括号中提供类型实参：

```go
intStack := Stack[int]{}
intStack.Push(42)

stringStack := Stack[string]{}
stringStack.Push("hello")
```

类型推断只适用于泛型函数。
创建泛型类型的值时，必须始终指定类型实参。

## 何时使用泛型

泛型是很强大的特性，但并不是每个问题都需要用到它。

在以下情况下使用泛型：
- 你在构建适用于任意元素类型的数据结构，比如树、链表或缓存。
- 你在编写作用于任意类型切片或映射的工具函数，比如过滤、排序或查找。
- 你需要在多个类型上使用完全相同的实现，并且想要编译时的类型安全。

在以下情况下改用接口：
- 你关心的是行为和方法，而不是底层的数据类型。
  例如，如果你想读取并处理来自各种类型数据源（文件、网络、TTY）的数据，那么比起`func Process[T](src T)`，你会选择`func Process(src io.Reader)`。
- 不同类型需要不同的方法实现才能完成各自的工作。
