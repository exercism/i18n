# 安装

本赛道全程依赖[Wren Console][wren-console]，为 Wren 提供本地运行时。也就是说，我们假定你在电脑上运行 Wren 的所有操作都通过[Wren Console][wren-console]来完成。请不要把它和官方的 Wren <abbr title="命令行界面">CLI</abbr>搞混。在理想情况下，你本可以使用那个运行时，但它目前[有](https://github.com/wren-lang/wren-cli/pull/74)[几个](https://github.com/wren-lang/wren/pull/1006)[不同的](https://github.com/wren-lang/wren-cli/issues/108)[问题](https://github.com/wren-lang/wren-cli/pull/105)，这让它算不上用 Exercism 学习 Wren 的理想选择。

Wren Console 从 Wren CLI 分支而来，解决了这些问题，并增加了一些功能，让你的学习体验更加顺畅。别担心，你在这里学到的 Wren 语言知识和概念，将来无论想在什么地方使用 Wren，都同样适用。

## 安装概览

- 安装 Git，以获得`git`命令
- 安装[Wren Console][wren-console]，以获得`wrenc`命令

### 安装 Git

你需要安装`git`二进制文件，并把它加入你的 PATH。Wren Package 就是这样安装软件包的（比如测试练习时需要的测试套件等）。

- **Windows**：官方的 [Git 下载页面](https://git-scm.com/download/win)是个不错的起点。
- **Linux**：你最顺手的包管理器应该能帮到你。
- **Mac**：所有较新版本的 Mac OS 都直接内置了`git`。

你可以用`git --version`确认 Git 是否已安装：

```
$ git --version
git version 2.31.1
```

就算版本号不完全一致也不用担心，这通常没那么重要。


### 安装 Wren Console

#### Windows

你多半会想从 GitHub [下载最新版本][releases]。下载后需要解压，并把`wrenc`可执行文件复制到你的 PATH 中。

也可以使用 Visual Studio [从源码构建][build-from-source]。

#### Linux

你可以从 GitHub [下载最新版本][releases]，或者[从源码构建][build-from-source]。

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

然后确认它已加入你的`PATH`。

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

最简单的安装方式是使用 Exercism 的 [Homebrew][homebrew] tap 和 formula：

```
brew tap exercism/wren
brew install wren-console
```

或者，你也可以从 GitHub [下载最新版本][releases]，然后按照 Linux 部分的说明手动安装。如果你对这类事情比较熟悉，从源码构建也相当简单。

### 测试安装

确认二进制文件安装无误后，最好测试一下一切是否正常工作。

1. 打开一个*终端*（`Terminal`、`cmd`、`Powershell`、`bash`等）
2. 运行`wrenc -v`

你应该会同时看到`wrenc`和 Wren 两个版本号：

```
wrenc v0.3.1 (wren v0.4.0)
```

**注意**：一定要打开一个*新*的终端窗口。安装完成后，已经打开的终端窗口可能没有刷新，也就是说，这些终端并不知道刚安装了新程序。

> _**帮助**_：`'wrenc' is not recognised`
>
> 你多半没有把`wrenc`放进 PATH……在 MacOS 和 Linux 上，你可以把下面这行加到
> `~/.bash_profile` 或 `~/.zshrc` 中，来修改你的路径：
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **不知道这些内容是否都正确。**
> 在 Windows 上，打开开始菜单，搜索“environment variables”。你需要
> 编辑`PATH`这一项，把`wrenc`可执行文件所在的路径*添加*进去。
> 这些文件通常位于`C:\Program Files\nodejs`。如果你用
> `File Explorer`打开这里，应该能找到`node.exe`、`npm.bat`和`npx.bat`。
>
> 关闭所有已打开的终端，再打开一个新的。

## 练习要求

请按照[这些说明][cli-walkthrough]，为你的操作系统下载`exercism` CLI。

CLI 全部设置并配置好后，下载第一个练习`hello-world`：

```bash
$ exercism download --exercise=hello-world --track=wren
```

之后每个练习都需要一些 Wren 软件包才能运行测试。在练习目录中运行下面的命令即可安装：

```bash
$ wrenc package.wren install
```
