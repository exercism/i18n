# 说明

和几乎所有有工作的人一样，Lisp 外星人 Layla 有时也需要做报告，让别人了解一些信息。他们想请你帮忙，把她为这些报告准备的数据格式化好。

## 1. 格式化季度数值

Layla 首先需要一个函数：`format-quarter-value`，它接收两个形参：日历季度和数值，并把它们格式化后用于报告。它应该求值为一个字符串。

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. 双季度报告

Layla 感谢你写了 `format-quarter-value`函数，并说它在*下一个*需要的函数中会非常有用。

下一份报告需要把两个季度的季度和数值分别打印在两行上。

另外，输出需要写入作为第一个实参传入的流。

例如：`(format-two-quarters t "last" 3.14 "this" 0)`会在标准输出上产生以下内容：

```

The value last quarter: 3.14
The value this quarter: 0

```

注意它前后的空行。

## 3. 人类可读与 Lisp 外星人可读

Layla 忘了告诉你，Lisp 外星人喜欢以可读作 Lisp 数据的方式来查看值。所以他们需要一个新函数，它的输出可以当作 Lisp 数据读取（同样写入指定的流）：

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
