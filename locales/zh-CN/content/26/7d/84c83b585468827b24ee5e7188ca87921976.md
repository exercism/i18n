# 说明

小提琴要靠耳朵对照一个基准音来调音。各根弦的音高相差很远，涉及的数字也不是整数。

五项任务都写在`TUNING_THE_STRINGS`类里。

## 1. 升高一个八度

高一个八度的音，频率是原来的两倍。

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. 降低一个八度

低一个八度就是一半。

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. 取中间值

给定两个频率，返回正好在它们中间的那个。

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. 差多远？

当两个音很接近但不完全相同时，它们每相差一个周期，你每秒就会听到一次拍音。返回这两个频率相差多少。不管哪个音更高，答案都不会是负数。

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. 分摊练习时间

给定分钟数和演奏者人数，每人分到多少分钟？分钟数和人数都是整数，但答案可能不是。

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
