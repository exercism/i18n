# 关于

Swift 中的[闭包][closures]是自包含的代码块，可以向它们传入实参来触发计算并返回值。
闭包还会从环境中捕获值，并在自己的计算中使用这些值。
由于它们是自包含的，因此可以像其他值一样在程序中被传来传去，也可以赋给常量和变量。

闭包听起来和 Swift 函数很像，事实确实如此，而且这有充分的理由。
Swift 中的函数是闭包的一种特例，它们必须有名字，并且使用略有不同的语法来定义。

虽然从技术上说，Swift 中的函数也是闭包，但当人们在 Swift 里提到“闭包”时，指的其实是[闭包表达式][closure-expressions]。
闭包表达式的写法是：一个形参列表，后面跟着返回类型，然后是关键字`in`，再后面是闭包体，整体用一对花括号包住：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

这段代码定义了一个类型为`(Double, Double) -> Double`的闭包表达式，可以像执行这个类型的函数一样，把它应用到类型合适的实参上来执行：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

由于每次想执行都要写出完整的闭包表达式很不方便，闭包可以像 Swift 中的其他值一样赋给名字。
之后就可以通过把名字应用到实参上来调用它：

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

如上所示，和普通函数一样，如果闭包体只有一个表达式，闭包可以省略`return`关键字。

大多数情况下，闭包会和[高阶函数]一起使用，要么作为实参传入，要么作为结果返回：

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```

## 推断闭包类型

当返回类型或形参类型可以[从上下文推断][inferring-closure-types]出来时，就能在闭包表达式中省略它们。
此外，如果可以省略形参类型，那么形参名外面的括号也可以省略：

```swift
let mean: (Double, Double) -> Double = { a, b in a + b / 2.0 }

func makeAdder(base: Int) -> (Int) -> Int {
  { x in base + x }
}

["apple", "ball", "carrot"].sorted(by: { s1, s2 in s1.count < s2.count })
```

- 在第一个例子中，类型可以从常量`mean`上的类型标注推断出来。
- 在第二个例子中，编译器从`makeAdder`的定义得知`base`是一个 int，并且返回的函数必须是`(Int) -> Int`类型。由此它可以验证：如果`x`是`Int`，那么闭包的类型就将是`(Int) -> Int`，因此我们可以省略闭包中的类型签名，因为`(Int) -> Int`是闭包唯一可能拥有的有效签名。
- 第三个例子类似，但编译器需要从该方法所作用的数组那里获取一些类型信息。它知道`sorted(by:)`方法接受一个闭包作为形参，这个闭包有两个形参，它们的类型与被排序集合的元素类型相同，并且返回一个`Bool`，因此编译器可以推断闭包的返回类型必须是`Bool`。又因为该方法作用在一个 String 数组上，所以它能确定形参`s1`和`s2`的类型都必须是`String`。

## 闭包的限制

如前所述，Swift 中函数和闭包非常相似，但也有一些重要的区别：

- 闭包不能使用外部实参标签。没有办法定义它们，而且调用闭包时试图使用形参的名字会导致错误：

```swift
let add5 = { x in x + 5 }
add5(x: 10)
// Error: Extraneous argument label 'x:' in call
```

- 闭包中的形参不能有默认值。
- 闭包中的形参可以是可变参数，但必须带有名字和类型标注。
