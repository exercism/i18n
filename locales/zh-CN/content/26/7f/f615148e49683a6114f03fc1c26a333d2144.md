# Instructions

复数是一种形如 `a + b * i` 的数，其中 `a` 和 `b` 是实数，`i` 满足 `i^2 = -1`。

`a` 称为 `z` 的实部，`b` 称为 `z` 的虚部。
数 `a + b * i` 的共轭是数 `a - b * i`。
复数 `z = a + b * i` 的绝对值是一个实数 `|z| = sqrt(a^2 + b^2)`。绝对值的平方 `|z|^2` 是 `z` 与其复共轭相乘的结果。

两个复数的和/差，就是把它们的实部和虚部分别相加/相减：
`(a + i * b) + (c + i * d) = (a + c) + (b + d) * i`,
`(a + i * b) - (c + i * d) = (a - c) + (b - d) * i`.

乘法结果按定义为
`(a + i * b) * (c + i * d) = (a * c - b * d) + (b * c + a * d) * i`.

非零复数的倒数是
`1 / (a + i * b) = a/(a^2 + b^2) - b/(a^2 + b^2) * i`.

复数 `a + i * b` 除以另一个复数 `c + i * d` 得到：
`(a + i * b) / (c + i * d) = (a * c + b * d)/(c^2 + d^2) + (b * c - a * d)/(c^2 + d^2) * i`.

把 e 提升到复数指数可以写成 `e^(a + i * b) = e^a * e^(i * b)`，其中最后一项由欧拉公式 `e^(i * b) = cos(b) + i * sin(b)` 给出。

实现以下运算：
 - 两个复数的加法、减法、乘法和除法，
 - 给定复数的共轭、绝对值和指数。


假设你使用的编程语言没有复数的实现。
