# 关于

[Red](https://www.red-lang.org) 的许多特点都源自它最初以 [Rebol](http://www.rebol.com) 为基础，而 Red 的开发最初则是作为开源社区的一个替代方案起步的。与此同时，Rebol 的开发已经停止，Red 却在不断发展。

## Rebol 的传承

和 Rebol 一样，Red 是一门**通用**编程语言。你可以用它创建任何你想要的应用程序。为了尽可能让开发者感到熟悉，它实现了**多种范式**：*命令式*、*函数式*、*对象式*、*符号式*和*响应式*。虽然它的整个工具链下载下来只有 1.5 MB，但它为所有主流操作系统（Windows、Linux、macOS）提供了**图形用户界面**实现，并且不依赖外部库。

Red 力求**尽可能简单**。它通过做出最实用的妥协、选择合理的默认值来设计，让你能完成每一项任务，而不会被大量选择压得不知所措。它注重人的**可读性**，因此语法糖被减到最少，程序也尽量像自然语言的句子。因此，Red 和 Rebol [极具表现力](https://redmonk.com/dberkholz/2013/03/25/programming-languages-ranked-by-expressiveness/)。

Red 的一个不同寻常之处是它的**同像性**，因此 Red 程序可以像任何 Red 数据结构一样被操作。所以，Red 和 Rebol 也是数据格式。一个有趣的事实是，[JSON 的灵感来自 Rebol](http://www.rebol.com/article/0522.html)。

## Red

与 Rebol 相比，Red 有了很大的改进。它可以**编译**成适用于每个受支持的平台的单个可执行文件，并且可以在其中任意一个平台上完成编译。所以，你可以在 Linux 上编译 Windows 程序，或在 Windows 上编译 macOS 程序。它还提供了**REPL 控制台**，有命令行和图形界面两种，让你可以逐条输入 Red 命令，即时操作数据。

让 Red 与众不同的另一点是它的方言 Red/System，这使 Red 成为**全栈**语言，可以像 C 语言那样开发底层代码。

## 使命

* 让编程重新充满**乐趣**
* 对抗软件复杂性

## 开发

Red 是开源的。它的开发托管在 [GitHub 代码仓库](https://github.com/red/red)。目前项目处于 **alpha 阶段**，所以要做好它发生变化甚至出问题的准备。
