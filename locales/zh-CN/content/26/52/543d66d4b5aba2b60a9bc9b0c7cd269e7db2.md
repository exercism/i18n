# 简介

方法是一种带有特殊_接收者_实参的函数。接收者出现在它自己的实参列表中，位于`func`关键字和方法名之间。

```go
func (receiver type) MethodName(parameters) (returnTypes) {

}
```

只有当接收者的类型与方法定义在同一个包中时，你才能为它定义方法。

```go
type Person struct {
    Name string
}

func (p Person) Greetings() string {
	return fmt.Sprintf("Welcome %s!", p.Name)
}

s := Person{Name: "Bronson"}
fmt.Println(s.Greetings())
// Output: Welcome Bronson!
```

接收者有两种：值接收者和指针接收者。

使用值接收者的方法操作的是传入值的副本，也就是说，在方法内部对接收者所做的任何修改，调用方都看不到。

你可以声明使用指针接收者的方法，以便修改接收者所指向的值。做法是在类型名前加上`*`，例如对于`rect`类型，指针接收者会声明为`*rect`。这样的修改对方法的调用方同样可见。

```go
type rect struct {
	width, height int
}
func (r *rect) squareIt() {
	r.height = r.width
}

r := rect{width: 10, height: 20}
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 20

r.squareIt()
fmt.Printf("Width: %d, Height: %d\n", r.width, r.height)
// Output: Width: 10, Height: 10

```
