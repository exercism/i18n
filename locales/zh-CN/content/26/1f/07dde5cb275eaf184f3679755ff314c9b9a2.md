# 关于

`throw`表达式是 `throw` 语句之外的另一种写法，尤其能提升三元表达式和其他复合表达式的表现力。

```csharp
string trimmed = str == null ? throw new ArgumentException() : str.Trim();
```

在上面的代码中，如果 `str` 为 `null`，就会抛出异常。
