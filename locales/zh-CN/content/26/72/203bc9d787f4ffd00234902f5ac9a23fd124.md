# 关于

给形参指定一个默认值，就能把它变成可选形参。调用带有可选形参的方法时，调用方不必为它们传值。如果没有为某个可选形参传值，就会使用它的默认值。

可选形参必须放在形参列表的末尾，后面不能再有非可选形参。

```haxe
class Card {
  static function newYear(year = 2021):String {
    return "Happy " + year;
  }
}

Card.newYear(); // Happy 2020
Card.newYear(1990); // Happy 1990
```

在变量名前面加上`?`运算符，就可以把可选形参设为`null`：

```haxe
function newYear(?year:Int) {
  if (year != null)
    return "It's " + year;
  return "Year is null";
}

newYear(); // Year is null
```
