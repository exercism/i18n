# 关于

可以借助 [Bitwise 模块][bitwise-hexdocs] 中的函数，对整数进行[按位二元运算][bitwise-wiki]。

- [`band/2`][bitwise-and]：按位与
- [`bsl/2`][bitwise-shift-left]：按位左移
- [`bsr/2`][bitwise-shift-right]：按位右移
- [`bxor/2`][bitwise-xor]：按位异或
- [`bor/2`][bitwise-or]：按位或
- [`bnot/1`][bitwise-not]：按位取反

```elixir
Bitwise.band(0b1110, 0b1001)
# => 8 # 0b1000

Bitwise.bxor(0b1110, 0b1001)
# => 7 # 0b0111
```
