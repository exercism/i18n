# 说明

用基本原理把以字符串表示的二进制数（例如 '101010'）转换为其十进制等价值。

实现二进制到十进制的转换。
给定一个二进制输入字符串，你的程序应输出一个十进制结果。
程序应能处理无效输入。

## 注意

- 自己实现这个转换。
  不要借助其他东西替你完成转换。

## 关于二进制（基数为 2）

十进制是以 10 为基数的系统。

以 10 为基数的记法中，数字 23 可以理解为 10 的各次幂的线性组合：

- 最右边的数字乘以 10^0 = 1
- 下一位数字乘以 10^1 = 10
- ...
- 第 n 位数字乘以 10^_(n-1)_。
- 最后把所有值相加。

所以：`23 => 2*10^1 + 3*10^0 => 2*10 + 3*1 = 23 base 10`

二进制与之类似，但用的是 2 的幂，而不是 10 的幂。

所以：`101 => 1*2^2 + 0*2^1 + 1*2^0 => 1*4 + 0*2 + 1*1 => 4 + 1 => 5 base 10`。
