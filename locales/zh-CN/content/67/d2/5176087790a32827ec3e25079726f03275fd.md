# 说明

你的朋友 Li Mei 经营着一家果汁吧，卖各种美味的混合果汁。
你是她店里的常客，觉得自己可以让朋友的生活轻松一些。
你决定用自己的编程技能来帮 Li Mei 处理工作。

## 1. 确定调制一杯果汁需要多长时间

Li Mei 喜欢提前告诉顾客，他们点的菜单上的果汁需要等多久。
不同果汁的调制时间各不相同，所以她很难记住确切的数字。
`"Pure Strawberry Joy"`需要 0.5 分钟，`"Energizer"`和`"Green Garden"`各需要 1.5 分钟，`"Tropical Island"`需要 3 分钟，`"All or Nothing"`需要 5 分钟。
其他所有饮品（比如特价饮品），可以假定调制时间为 2.5 分钟。

为了帮你的朋友，请写一个函数`time_to_mix_juice`，它接收菜单上的一种果汁作为实参，返回调制该饮品所需的分钟数。

```R
time_to_mix_juice("Tropical Island")
# => 3

time_to_mix_juice("Berries & Lime")
# => 2.5
```

## 2. 补充青柠角

Li Mei 调制的许多饮品都会用到青柠角，有的用作配料，有的用来装饰。
所以每天早上开始当班时，她都要确保装青柠角的容器是满的，够用一整天。

实现函数`limes_to_cut`，它接收 Li Mei 需要切出的青柠角数量，以及一个数组，表示她手头现有的整个青柠。
一个`"small"`青柠可以切出 6 个青柠角，一个`"medium"`青柠可以切出 8 个，一个`"large"`青柠可以切出 10 个。
她总是按照青柠在数组中的顺序来切，从第一项开始。
她一直切下去，直到切够所需的青柠角数量，或者青柠用完了。

Li Mei 希望提前知道她需要切多少个青柠。
函数`limes_to_cut`应返回需要切的青柠数量。

```R
limes_to_cut(25, c("small", "small", "large", "medium", "small"))
# => 4
```

## 3. 列出队列中每个订单的调制时间

Li Mei 想在显示器上随时了解顾客等待中的订单各需要多长时间调制。

实现函数`order_times`，它接收一个订单队列，并把调制每个订单所需的时间*打印*到 stdout。

```R
order_times(c("Energizer", "Tropical Island"))
# => 1.5 
# => 3
```

## 4. 收尾当班

Li Mei 总是工作到下午 3 点。
之后由她的员工 Dmitry 接班。
Li Mei 下班时，常常还有一些已经点单但还没调制的饮品。
Dmitry 会接着调制剩下的果汁。

为了方便交接，请实现函数`remaining_orders`，它接收 Li Mei 当班剩下的分钟数，以及一个数组，里面是已经点单但还没调制的果汁。
该函数应返回 Li Mei 在下班前无法开始调制的订单。

当班剩余时间总是大于 0。
待调制的果汁数组永远不会为空。
此外，订单按照它们在数组中出现的顺序调制。
如果 Li Mei 开始调制某种果汁，她一定会把它做完，哪怕要多工作一会儿。
如果没有需要 Dmitry 处理的剩余订单，则应返回一个空的向量。

```R
remaining_orders(5, c("Energizer", "All or Nothing", "Green Garden"))
# => c("Green Garden")
```
