# 简介

Python 中的字典（`dict`）是一种数据结构，它把[可哈希][term-hashable]的_键_与_值_关联起来。在其他编程语言中，它被称为可调整大小的[哈希表][hashtable-wikipedia]、哈希映射或[关联数组][associative-array]。字典是 Python 唯一的内置[映射类型][mapping-types-dict]。

`keys`必须是可哈希的，并且在字典中唯一。键的类型可以包括`number`、`str`或`tuple`（由_不可变_的值构成）。键不能包含_可变_的数据结构，例如`list`、`dict`或`set`。从 Python 3.7 起，`dict` 的键顺序保证与条目的插入顺序一致。

`values`可以是任何数据类型或结构。值还可以_任意_嵌套，因此可以包含数组的数组、子字典以及其他自定义或复合数据结构。

给定一个`key`，字典可以在（平均）常数时间内检索出对应的`value`（_与条目数量无关_）。与在`list`或`array`中查找值（_不知道`index`位置_）相比，`dict`占用的内存明显更多，但检索速度非常快。

当元素集合很大，并且需要频繁访问和更新时，字典尤其有用。
