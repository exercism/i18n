# 调试

YS 内置了一个`DBG`函数，可以用来调试解答代码。
它接受任意数量的实参，并把它们打印到 stderr 上。
它会返回最后一个实参，因此你可以在代码中内联使用它。


你可以使用`.>`内联运算符，它是`.DBG()`的快捷方式。

下面是一个示例代码文件：

```yaml
# file: program.ys

!YS-v0

defn do-it(nums):
  x =: 5

  DBG: -'my vars' x nums

  nums: .map(\(_ * x)).>
        .reverse().>
        .map(str).>
        .join(' - ')

say: do-it(3 .. 5)
```

用`ys`运行这段代码时，你会看到以下输出：

```txt
>>>
"my vars"
5
(3 4 5)
<<<
>>>(15 20 25)<<<
>>>(25 20 15)<<<
>>>("25" "20" "15")<<<
25 - 20 - 15
```


## 编译

另一个常用的排查问题的方法，是查看你的 YS 代码编译成的 Clojure 代码。

你可以带`-c`标志运行`ys`命令行翻译来做到这一点。

上面的`program.ys`文件编译后是这样的：

```clojure
$ ys -c program.ys
(defn do-it [nums]
 (let [x 5]
  (DBG "my vars" x nums)
  (join
   (DBG
    (+map
     (DBG (reverse (DBG (+map nums (fn [& [_1]] (mul+ _1 x))))))
     str))
   " - ")))
(say (do-it (rng 3 5)))
```

你可以清楚地看到`.>`运算符是如何编译成`DBG`函数调用的。
