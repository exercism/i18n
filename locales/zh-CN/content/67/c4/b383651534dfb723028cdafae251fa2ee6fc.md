# 说明

学习 ABAP 内表的基础知识。

你的类中有一个名为`initial_data`的内表。它有三列：`GROUP`、`NUMBER` 和 `DESCRIPTION`。

```abap
TYPES group TYPE c LENGTH 1.
TYPES: BEGIN OF initial_type,
         group       TYPE group,
         number      TYPE i,
         description TYPE string,
       END OF initial_type,
       initial_data TYPE STANDARD TABLE OF initial_type WITH EMPTY KEY.
```

## 第 1 步

你的第一个任务是完成 `fill_itab` 方法，并向这个内表写入 6 条记录，取值如下：

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 10 | Group A-2 |
| B | 5 | Group B |
| A | 6 | Group A-1 |
| C | 22 | Group C-1 |
| A | 13 | Group A-3 |
| C | 500 | Group C-2 |

## 第 2 步

接下来实现 `add_to_itab` 方法，向这个内表的末尾添加一条记录，取值如下：

| GROUP | NUMBER | DESCRIPTION |
| --- | ----------- | ----------- |
| A | 19 | Group A-4 |

## 第 3 步

现在请在 `sort_itab` 方法中对这个内表排序，`GROUP` 列按字母顺序，`NUMBER` 列按降序。

## 第 4 步

在 `search_itab` 方法中，在已排序的表中查找，并返回 `NUMBER` 列值为 6 的那条记录的下标。
