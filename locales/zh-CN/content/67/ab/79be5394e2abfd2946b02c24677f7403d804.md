# 关于

Elm 是一门纯函数式语言，因此没有语句，只有表达式，函数也总是一个表达式。

这会鼓励你把函数写得小而简单，总体上是件好事。但有时函数不可避免地会更加复杂，我们需要一种方式，让这些函数也能写得优雅。

`let`表达式正是为此而生的。它由两部分组成：`let`部分，你可以在其中按需创建任意多个定义；然后是`in`部分，它是一个表达式，可以使用前面这些定义。

在计算机领域里，`let`创建的作用域只限于`in`中的那个表达式。

`let`表达式在以下几种情况下很有用：

- 简化表达式
- 为中间表达式的结果命名
- 当表达式变得很大时，把它拆成更小的部分

在`let`表达式中，大多数事情都可以做，包括解构，但以下内容不行：

- 自定义类型
- 类型别名
- 名称遮蔽（不能重新定义或复用已经在作用域中的名称）

## 简化表达式

这个表达式把 3 个数字的立方相加，但很难读懂，而且计算不同数字时很容易出现不一致。

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

我们可以在`let`表达式中定义一个`cube`函数，让计算更简单、更具表现力，也更安全。这个函数可以带类型注解，但在地道的 Elm 代码中，这种做法相对少见。

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## 为中间表达式的结果命名

这段代码定义了 sideArea 和 topArea，让计算更简单、更具表现力。

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## 拆分大型表达式

这段代码为 [Game of Life](https://playgameoflife.com/)（一个常见的编程练习示例）创建了一个初始图案。

不必完全弄懂它的工作原理，但应该很容易看出：如果不用`let`，把它写成单个表达式会非常庞大。

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
