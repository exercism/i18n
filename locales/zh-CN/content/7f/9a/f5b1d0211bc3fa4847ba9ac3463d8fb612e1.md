# 说明

马戏演出是把多个节目按顺序排在一起。不同节目的内部完全不同，而编排演出的人需要从每个节目那里获得相同的两项信息。

这是你第一次在一个文件里写多个类的练习。代码桩给出了抽象类；请在它下面编写其余部分。

## 1. 三个节目

编写三个类，每个都是一种`$ACT`。

| 类 | `name` | `minutes` |
| --- | --- | --- |
| `JUGGLING` | `"Juggling"` | 5 |
| `TUMBLING` | `"Tumbling"` | 3 |
| `TRAPEZE` | `"Trapeze at "`然后是高度，然后`"m"` | 8 |

`JUGGLING`和`TUMBLING`不带参数创建。`TRAPEZE`用高度（以米为单位）创建：

```sather
#JUGGLING
#TRAPEZE(4)
```

所以`#TRAPEZE(4).name`是`"Trapeze at 4m"`。

## 2. 整场演出

编写一个`CIRCUS_ACTS`类，包含三个例程，每个例程都接收演出顺序作为`ARRAY{$ACT}`。

**`total_minutes`**，表示整场演出需要多长时间。

```sather
CIRCUS_ACTS::total_minutes(|#JUGGLING, #TUMBLING|)
-- => 8
```

**`billing`**，把各节目的名称用`", "`连接起来。

```sather
CIRCUS_ACTS::billing(|#JUGGLING, #TUMBLING|)
-- => "Juggling, Tumbling"
```

**`longest`**，耗时最长节目的名称。如果有两个并列，靠前的那个胜出。空演出没有最长节目，所以答案是`""`。

```sather
CIRCUS_ACTS::longest(|#JUGGLING, #TUMBLING|)
-- => "Juggling"
```

这三个例程都不能询问自己拿到的是哪种节目。
