# 说明附录

## 实现

本练习会介绍[泛型](https://docs.oracle.com/javase/tutorial/java/generics/index.html)。
要让测试通过，你需要把自己的类构造成能接受任意类型的输入，比如`Integer`或`String`。

泛型很有用，因为它让你能写出更通用、可复用的代码。
Java 的 [List](https://docs.oracle.com/javase/8/docs/api/java/util/List.html) 和 [Map](https://docs.oracle.com/javase/8/docs/api/java/util/Map.html) 实现，都是使用泛型的类的例子。
借助它们，你可以构造一个包含`Integers`的`List`，或者一个包含`Strings`的列表，或者任意其他类型的列表。

泛型中使用的类型有一些限制。
其中之一是，一旦你构造了一个包含`Integers`的`List`，就不能再往里面放`Strings`。
构造类的时候，你必须指定想往里面放哪种类型，之后这个实例就只能用于该类型。

例如，你可以构造一个`Integers`列表：

`List<Integer> someList = new LinkedList<>();`

现在`someList`只能包含`Integers`。你也可以这样写：

`List<String> someOtherList = new LinkedList<>()`

现在`someOtherList`只能包含`Strings`。

另一个限制是，与泛型一起使用的任何类型都不能是[基本类型](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/datatypes.html)，比如`int`或`long`。
不过，每种基本类型都有对应的引用类型，所以你可以用 [`Integer`](https://docs.oracle.com/javase/8/docs/api/java/lang/Integer.html) 代替`int`，用 [`Long`](https://docs.oracle.com/javase/8/docs/api/java/lang/Long.html) 代替`long`。

不妨看一下[泛型的使用示例](https://docs.oracle.com/javase/tutorial/java/generics/types.html)，帮助你入门。
