# 关于

在 Common Lisp 中，全局的具名函数用`defun`定义。

这个形式的第一个参数是所定义函数的参数列表（这个参数列表也叫“lambda list”）。
之后，它还可以选择性地接收一个字符串，作为该函数的文档。
最后是零个或多个表达式，它们构成函数体。

调用函数的方式是，把函数名作为表达式的第一个元素，后面跟上要传给该函数的参数。

```lisp
(defun add-one (x) (1+ x))

(add-one 3) ;; => 4
```

函数还可以接收[可选参数][concept-optional-parameters]、[关键字参数][concept-keyword-parameters]、[剩余参数][concept-rest-parameters]。
这些内容会在后面的概念中讨论。

函数名在函数体的作用域之内，因此可以实现递归。

```lisp
(defun countdown (x)
  (if (zerop x) (print 'BLAST-OFF)
    (progn (print x) (countdown (1- x)))))

(countdown 3) ;; will print "3","2", "1" and "BLAST-OFF" to
              ;; standard output before evalutaing to 'BLAST-OFF
```
