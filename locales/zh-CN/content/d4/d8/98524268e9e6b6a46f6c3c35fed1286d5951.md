# 说明

你刚刚被一家新的出租车服务公司录用，这家公司想在已经饱和的市场中与其他竞争对手拉开差距。
为了实现这一目标，首席执行官决定在曼哈顿推出一项超豪华服务，在每个路口都安排服务员，在乘客上车前和下车后为他们提供帮助。
现在，你需要写一些代码来协助这项服务的运营。

## 1. 简单的复数

由于曼哈顿的街道布局基本上是网格状的，首席执行官决定用复数来表示街道的交叉口，这样非常方便。
其中，正实数和负实数分别表示东和西，正虚数和负虚数分别表示北和南。

由于在 R 中实例化一个复数有点……呃，特别，所以上级要求你实现一个简单的复数函数。

实现`simplex(a, b)`函数，它接收整数`a`和`b`。
返回复数`a+bi`。

```r
simplex(1, 1)
#> 1+1i

simplex(-3, 4)
#> -3+4i
```

## 2. 获取司机行驶方向

当乘客给出目的地的交叉口后，司机就会得到如何前往那里的方向指引。
这些方向以复数的形式给出，其中实部表示需要往北/南走多少个街区，虚部表示东西方向的距离。
为了与标准指南针保持一致，你的项目经理决定让北为虚轴正方向，南为虚轴负方向。
同样，东为实轴正方向，西为实轴负方向。

实现`driver_directions(start, end)`函数，它接收起点交叉口坐标`start`和终点坐标`end`。
返回一个复数，表示司机需要往东/西以及北/南走多少个街区。

```r
driver_directions(0+0i, 7+5i)
#> 7+5i

driver_directions(-2+3i, 4-5i)
#> 6-8i
```

## 3. 获取曼哈顿距离

乘客需要按出租车行驶的距离付费。
由于曼哈顿的街道布局呈网格状，出租车只能沿着这些路线行驶。
这种结构使得距离的度量必须沿着网格线进行。
距离可以通过把经过的路线数或到达的交叉口数相加得到（即不包括起点交叉口）。
这种度量通常被称为曼哈顿距离或 L1 范数。

实现`manhattan(start, end)`函数，它接收起点交叉口`start`和终点交叉口`end`。
返回`start`和`end`两个交叉口之间的曼哈顿距离。

```r
manhattan(0+0i, 3+4i)
#> 7

manhattan(-2-3i, -1+1i)
#> 5
```

## 4. 获取“乌鸦直线飞行”距离

首席执行官成功说服了投资银行参与进来，他强调这项服务不仅超豪华，而且很环保，因为它会用训练过的乌鸦在各个路口的服务员之间传递消息（这些消息传递乘客信息，以提供个性化体验）。
看来没有一位投资银行家愿意花时间去搞清楚这到底为什么环保，甚至也没人关心什么样的首席执行官会在空闲时间训练乌鸦，因为投资资金已经源源不断地涌了进来。

这项服务同样按行驶距离收费。
不过，由于乌鸦会飞，它们不必沿着网格状的道路网走，可以走最短的路径。
当然，如果到处都是巨大的摩天大楼，情况可能就不是这样了，但首席执行官把这项服务放在了堪萨斯州的曼哈顿（又名“小苹果”），那里的乌鸦可以轻松飞过低矮的建筑。
堪萨斯州曼哈顿对这种服务的潜在需求，以及当地行人对这些鸟儿满天飞会作何感想，都是后话了。

实现`as_crow_flies(start, end)`函数，它接收起点交叉口`start`和终点交叉口`end`。
返回两者之间的直线飞行距离。

```r
as_crow_flies(0+0i, 3+4i)
#> 5
```

## 5. 获取乌鸦的方向

首席执行官训练乌鸦遵循与司机类似的方向指引。
不过，这位首席执行官热爱南半球，他训练乌鸦时所用的指南针与你项目经理在系统其余部分使用的不同。
你的首席执行官原来是个相当古怪的人。
在首席执行官的指南针里，北是虚轴负方向，南是虚轴正方向。
这与司机的北/南方向正好相反，而东/西方向保持不变。

实现`crows_directions(start, end)`函数，它接收起点交叉口`start`和终点交叉口`end`。
返回一个与司机方向类似的复数，但南北方向相反。

```r
driver_directions(0+0i, 7+5i)
#> 7-5i

driver_directions(-2+3i, 4-5i)
#> 6+8i
```
