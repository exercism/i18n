# 提示

## 通用

- `<min-heap>`、`heap-push`、`heap-peek` 和 `heap-pop-all` 都在[`heaps`][heaps]里；`values`在[`assocs`][assocs]里。
- 堆把每一项存成一个*值*加一个*键*，键就是优先级。`heap-push`接收它们的顺序是`( value key heap -- )`。

## 1. 开启队列

- `<min-heap>`会构建一个空的最小堆，最小的键会最先被服务。

## 2. 添加顾客

- 顾客姓名是值，优先级是键，这正是`heap-push`想要的顺序。
- `heap-push`会消耗掉队列。用`[ heap-push ] keep`来添加顾客，同时仍然返回队列。

## 3. 下一位是谁？

- `heap-peek`会返回队首那一项的`value key`，但不会把它移除。你只要姓名，所以用`drop`把键丢掉。

## 4. 服务所有人

- `heap-pop-all`会把堆清空成一个由`{ key value }`对组成的关联列表，而且已经按优先级排好了序。
- `values`只保留值，也就是姓名。

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
