# 说明

欢迎来到 *ChronoRealms* 的世界，这是一片神奇的土地，强大的 Timekeeper 掌控着时间的流动。

在这个世界里，Timekeeper 管理着“TimeShard”，这是一种特殊单位，可以相加、相减、比较，甚至检查是否相等。

你的任务是帮助 Timekeeper，为操作这些 TimeShard 实现自定义运算符。

Timekeeper 需要你创建一个自定义结构体 `TimeShard`，支持以下操作：

1. **TimeShard 的相加与相减**：Timekeeper 需要能够对 TimeShard 做加法和减法，以此控制时间线。
2. **比较 TimeShard**：有时需要比较两个 TimeShard，看看哪个更大，或者它们是否相等。
3. **检查相等性**：Timekeeper 需要检查两个 TimeShard 的值是否完全相同。

你的任务是：为 `TimeShard` 结构体实现以下 trait：

1. **加法（`Add`）**：让两个 `TimeShard` 实例可以相加。
2. **减法（`Sub`）**：让一个 `TimeShard` 可以减去另一个。
3. **相等（`PartialEq`）**：让 Timekeeper 可以检查两个 `TimeShard` 实例是否相同。
4. **比较（`PartialOrd`）**：让两个 `TimeShard` 实例可以比较大小。

`TimeShard` 用一个结构体来表示，内部保存一个整数值（`i32`）。

实现这些必要的 trait，让 Timekeeper 的工作更轻松。

```rust
let shard1 = TimeShard { value: 5 };
let shard2 = TimeShard { value: 3 };

// Adding TimeShards
let sum = shard1 + shard2; // TimeShard { value: 8 }

// Subtracting TimeShards
let difference = shard1 - shard2; // TimeShard { value: 2 }

// Checking equality
let are_equal = shard1 == shard2; // false

// Comparing TimeShards
let is_greater = shard1 > shard2; // true
```
