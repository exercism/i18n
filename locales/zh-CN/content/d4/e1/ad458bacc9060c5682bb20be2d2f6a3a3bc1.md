# 简介

在 Cairo 中，运算符重载让你可以为自己的类型定义`+`、`-`、`==`、`<`等标准运算符的行为。

具体做法是为自定义类型实现特定的 trait。

## 运算符的核心 trait

### `Add`和`Sub`

`Add`和`Sub`这两个 trait 让你定义自己的类型如何做加法（`+`）和减法（`-`）：

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

`PartialEq` trait 让你可以比较自己的类型的两个实例是否相等（`==`和`!=`）。

这个 trait 通常可以用`#[derive(PartialEq)]`自动派生。

### `PartialOrd`

`PartialOrd` trait 让你可以对自己的类型的实例进行比较运算（`<`、`>`、`<=`、`>=`）。

它要求你至少实现`lt`（小于，less than）方法：

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
