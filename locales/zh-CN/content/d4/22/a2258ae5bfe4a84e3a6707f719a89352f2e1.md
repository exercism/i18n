# 附加说明

## 提示

[双向链表](https://en.wikipedia.org/wiki/Doubly_linked_list)是一种可变的数据结构。由于 F# 是一门函数式优先的语言，通常更倾向于不可变性，但有些语言特性允许在需要时使用可变操作。

- `mutable`关键字可以放在 `let` 绑定和[记录](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records)字段前面，让你可以给它们赋新值。

- [类](https://fsharpforfunandprofit.com/posts/classes)的属性可以通过用`set`关键字指定 setter 来变为可变。

可变绑定必须用`<-`重新赋值

```fsharp
let mutable x = "initial value"
x <- "new value"
```
