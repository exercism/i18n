# 简介

## 比较运算符

Julia 中的比较运算符与许多其他语言相似，不过为数学爱好者多准备了一些选项。

判断相等时，运算符有`==`（等于）和`!=`或`≠`（不等于）。

```julia
txt = "abc"
txt == "abc"  # true
txt != "abc"  # false
txt ≠ "abc"  # false (synonym for !=)
```

除此之外，还有各种大于/小于运算符。

```julia
1 < 3  # true
3 > 3  # false
3 <= 3  # true
3 ≤ 3  # true (synonym for <=)
4 >= 3  # true
4 ≥ 3  # true (synonym for >=)
```

和 Julia 的一贯风格一样，合适的编辑器能让你轻松输入这些数学符号。输入`\ne`、`\le`或`\ge`，然后按`TAB`，就能得到`≠`、`≤`或`≥`。

上一个例子只用了数字，但在教学大纲的其他部分我们会看到，各种其他类型也有大小顺序的概念，可以进行大于/小于比较。

比较运算符可以串联使用，从而实现简洁明了的语法：

```julia
n = 3
1 ≤ n ≤ 5  # true (n "between" two limits)
```

上一个例子等同于`1 ≤ n && n ≤ 5`。

## 用`if`分支

下面是`if`语句的完整形式：

```julia
if conditional1
    statements...
elseif conditional2
    statements...
else
    statements...
end
```

不需要圆括号`()`或大括号`{}`，缩进“仅仅”是为了提高可读性_（但可读性非常重要！）_。

`elseif`和`else`都是可选的，并且可以有多个`elseif`分支。不过，`end`是必需的。

`if`语句可以嵌套，不过你也许想通过合理使用括号、缩进和注释来帮助提高可读性。

`if`语句最短的形式大概是这样：

```julia
if n < 0
    n = 0
end
```

提醒一下：只有求值为`true`或`false`的表达式才能用作条件。Julia 有意避开了“真值性”这一概念，所以零值、空字符串和空数组_不_等同于`false`。

## 三元运算符

一种简单而常见的情形是：根据条件在两个值中取一个。

和许多语言一样，Julia 提供了三元运算符，让这件事更简洁。

语法是`conditional ? value_if_true : value_if_false`。

所以上一个例子可以改写成：

```julia
n = n < 0 ? 0 : n
```

编译器并不要求加括号，但加上括号可以提高可读性。
