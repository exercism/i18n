# 说明

作为一名国际象棋爱好者，你很想写出属于自己的版本。没错，网上可能已经有很多现成的国际象棋实现了，但你的版本会独一无二！

不过，在放飞想象力之前，得先把基础打好。我们就从生成棋盘开始吧。

棋盘上的每一格都由一个字母与数字的组合来标识。竖直方向的一列格子称为 file，用字母 A 到 H 标记；水平方向的一行格子称为 rank，用数字 1 到 8 编号。

## 1. 定义 rank 范围

实现`rank_range()`函数，它应该返回一个整数范围，从 1 到 8。

```julia-repl
julia> rank_range()
# output omitted
```

## 2. 定义 file 范围

实现`file_range()`函数，它应该返回一个字符范围，从大写字母 A 到大写字母 H。

```julia-repl
julia> file_range()
# output omitted
```

## 3. 将 rank 范围转换成 rank 向量

实现`ranks()`函数，它应该返回一个整数向量，从 1 到 8。不要手动写出这个向量，而是用`rank_range()`函数返回的范围来生成它。

```julia-repl
julia> ranks()
[1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. 将 file 范围转换成 file 向量

实现`files`函数，它应该返回一个字符向量，从 'A' 到 'H'。不要手动写出这个向量，而是用`file_range()`函数返回的范围来生成它。

```julia-repl
julia> files()
['A', 'B', 'C', 'D', 'E', 'F', 'G', 'H']
```
