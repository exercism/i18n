# Bash Shell 中的算术入门

Bash 可以做算术运算，但_只能用整数_。
如果你需要做浮点数运算，就得调用外部程序（比如 [awk][awk] 或 [bc][bc]）。

算术运算符都在手册里列出（按优先级排列）：[Shell Arithmetic][arithmetic]。

另外，Bash 只在某些地方执行算术运算，这些地方称为算术“上下文”。

## 算术展开

算术展开看起来很像[命令替换][cmd-sub]，只不过用的是双括号。

```bash
$(( expression ))
```

这种语法会展开为表达式求值后的结果。
它常用来把结果保存到变量里：

```bash
x=$(( 3 + 4 ))
```

~~~~exercism/note
括号里放多少空白由你决定。
这纯粹是风格和可读性的问题。

```bash
x=$(( 3 + 4 ))
y=$((5+6))
```

你友好的作者喜欢加上空格，好让算术表达式在括号里更显眼。
~~~~

## 算术条件式

算术条件式写在双括号里，_不带_开头的 `$`：

```bash
(( expression ))
```

它不会展开成结果。
但它会产生一个_退出状态_。

* 如果表达式的结果是**非零**，退出状态就是 0（成功）。
* 如果表达式的结果是**零**，退出状态就是 1（失败）。

~~~~exercism/note
在`((`里，Bash 对 true/false 的理解和 C 语言一样：零为假，非零为真。
**这和 Bash 判断退出状态的方式恰好相反！**
~~~~

这种语法通常用在两个地方：

1. 作为[`if` 语句][conditional-if]或[`while` 循环][looping-while]的 COMMAND 部分。

   ```bash
   if (( x == y - 1 )); then ...
   while (( y > 0 )); do ...
   ```

1. 作为一条独立的命令，用来改变变量的值。

   ```bash
   (( x = x + 1 ))
   echo "new value for x is $x"
   ```

   ~~~~exercism/caution
   把这种算术写法和 `set -e` 组合使用时要小心。
   如果表达式求值为零，退出状态就是非零的，Bash 会直接终止。

   ```bash
   x=0
   (( x++ ))
   echo "you will see this"

   set -e
   x=0
   (( x++ ))
   echo "shell exits on the previous line; you won't see this"
   ```

   想更详细地了解 `++` 运算符，可以读一读 [Postincrement vs Preincrement][incr] 这篇文章。

   [incr]: https://thisvsthat.io/postincrement-vs-preincrement
   ~~~~


## 其他使用算术上下文的地方

还有几个地方也属于算术上下文：

* [算术 `for` 循环][looping-for]。

  ```bash
  for (( i = 0; i < 10; i++ )); do
      echo "$i"
  done
  ```

* 数值下标数组中的下标部分。

  ```bash
  echo "The next element is ${array[x + 1]}"
  # ................................^^^^^
  ```

  想进一步了解数组，可以阅读[数组][arrays]概念文档。

* `${var:offset:length}`展开中的偏移量和长度部分。
* [`let` 内置命令][let]。
  * 注意，应优先使用`(( expression ))`，而不是`let "expresson"`。
    与算术条件式不同，`let` 表达式会受到文件名展开和分词的影响，而且需要加引号。
* 变量赋值，前提是变量带有“整数属性”。

  ```bash
  # variable x does not have the integer attribute
  x="3 + 4"
  declare -p x      # => declare -- x="3 + 4"

  # variable y has the integer attribute
  declare -i y
  y="4 + 5"
  declare -p y      # => declare -i y="9"
  ```

  ~~~~exercism/note
  作者认为`declare -i`的用处有限。
  它最大的好处是允许“裸”算术（不写算术表达式语法）。
  但这可能会让阅读你代码的人感到困惑，因为算术表达式会在意想不到的地方被求值。
  ~~~~

## 在算术表达式中使用变量

这里介绍算术上下文中一个能提升可读性的方面。

```bash
height=10
width=20
area=$(( height * width ))
```

你注意到没有，算术表达式里的变量都没写`$`美元符号？
Bash 允许这样做。
这样表达式读起来就轻松多了。

手册里说：

> 在表达式中，shell 变量也可以直接按名字引用，而不必使用参数展开语法。

连数组元素也一样：

```bash
point1=(10 15)  # these are (x, y) coordinates
point2=(20 7)
distance_squared=$(( (point1[0] - point2[0])**2 + (point1[1] - point2[1])**2 ))
```

但其他参数表达式还是得用各自的特殊语法。
比如，把字符串的长度翻倍：

```bash
s="hello world"
len=$(( ${#s} * 2 ))
```

位置参数也是如此。
如果前两个位置参数分别代表宽度和高度：

```bash
area=$(( $1 * $2 ))
```
