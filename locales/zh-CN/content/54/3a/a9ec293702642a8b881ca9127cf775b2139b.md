# 学习

Pascal 编程语言有着悠久的历史，网上的很多文档都是面向初学者的。这些教程大多讲的是控制台程序，也就是把信息打印到屏幕上，和/或读取用户输入。例如，最常见的初学者教程之一，就是把 'Hello World' 打印到屏幕上的程序：

```pascal
program HelloWorld;
begin
  writeln('Hello World!');
end.
```

在控制台/终端中运行时，这个程序会在屏幕上打印 'Hello World'。

在 Exercism，我们使用自动化测试来确保你提交的解答正确，因此我们需要使用**单元**，而不是**程序**。主要的区别在于，你需要从函数中返回一个值，而不是把内容打印到终端：

```pascal
writeln('Hello World!');
```

变成了

```pascal
result := 'Hello World!'
```

在显示信息，或获取命令、数学运算等输出的文本表示时，write/writeln 命令仍然很有用。
