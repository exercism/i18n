# 简介

## 比较运算符

比较运算符与许多其他语言类似。

用于判断相等性的是 `==`（相等）和 `!=`（不相等）这两个运算符。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

大于和小于运算符同样是常规写法。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## 用 `if` 进行分支

下面是 `if` 表达式的完整形式：

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 每个条件两边的括号 `()` 是必需的。
- 条件必须求值为布尔值`true`或`false`。
  Kotlin 没有某些语言里那种 “truthy” 和 “falsy” 的概念。
- 如果只有一个表达式，大括号 `{}` 可以省略。
- `else if` 和 `else` 都是可选的，并且可以有多个 `else if` 块。

`if` 表达式还可以用来“选择”一个值：

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 替代方案？

出于有意的设计，Kotlin _并不_ 具备 Java 中那样的三元运算符 `? :`。更推荐使用 `if ... else` 的简洁写法：

```Kotlin
return if (isOK) goodValue else badValue
```
