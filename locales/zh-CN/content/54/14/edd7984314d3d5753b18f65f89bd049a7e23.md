# 简介

Julia 中的`String`是由 [Unicode](https://en.wikipedia.org/wiki/Unicode) 字符组成的不可变有限序列，采用 [UTF-8](https://en.wikipedia.org/wiki/UTF-8) 编码。

`String`字面量是用双引号括起来的一串字符：

```julia-repl
julia> "Christopher"
"Christopher"
```

字符串可以用`*`运算符拼接：

```julia-repl
julia> "Christopher" * " " * "Paolini"
"Christopher Paolini"
```

~~~~exercism/advanced
如果你好奇 Julia 为什么用`*`而不是`+`来拼接字符串，可以看看 [Julia 手册](https://docs.julialang.org/en/v1/manual/strings/#man-concatenation)。
~~~~

有些特殊字符需要在前面加上反斜杠来转义：

```julia-repl
julia> println("\t or spaces?")
         or spaces?
```

Julia 默认自带了很多处理字符串的实用函数：

```julia-repl
julia> lowercase("TEST")
"test"

julia> titlecase("TEST")
"Test"
```
