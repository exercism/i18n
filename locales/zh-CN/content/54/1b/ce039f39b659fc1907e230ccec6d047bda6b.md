# 关于

浮点数是指小数点后有一位或多位数字的数字。

```gleam
let float = 3.45
// -> 3.45
```

浮点数也有自己的一组运算符。

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

为清晰起见，浮点数中也可以插入下划线。

```gleam
1_000_000.0 // One million
```

浮点数还可以使用科学计数法：

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
