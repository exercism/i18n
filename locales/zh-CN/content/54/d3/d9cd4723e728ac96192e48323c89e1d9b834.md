# 关于

在 Gleam 中，可以使用`case`表达式来按条件执行代码。借助 case 表达式，可以把一个值拿来与一个或多个_模式_进行匹配。其中一种模式是_字面量模式_，它会把值与字面量值（例如 `1` 或 `"hello"`）进行匹配。

case 表达式使用`case`关键字书写：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    1 -> "One"
  }
}
```

虽然这看起来像其他语言里的`switch`语句，但当你还使用其他模式时，模式匹配才真正展现出它的威力。其中一种是_变量模式_，它允许把一个值赋给一个变量。在这个例子中，如果`number`不是`0`，变量`i`就会被赋值为`number`的值：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i -> "Non zero"
  }
}
```

有时候，你可能想给模式再加一个条件。这叫作_守卫_（子句），可以用`if`关键字添加：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
  }
}
```

出于性能方面的考虑，守卫中只允许使用基本的数学运算符和布尔运算符，不能使用其他函数。

在上面的例子中，并不是所有可能的输入都能匹配到模式。编译器会发现这一点，并输出一个错误。这叫作_穷尽性检查_。要消除这个警告，就必须处理所有情况。为此，可以使用_丢弃模式_，它能匹配任何值：

```gleam
pub fn describe(number: Int) -> String {
  case number {
    0 -> "Zero"
    i if i < 0 -> "Negative number"
    _ -> "Positive number"
  }
}

// No compiler error
```

case 表达式会从上到下依次用每个模式测试这个值，直到找到匹配的模式，并执行与该模式关联的逻辑。模式的顺序很重要！
