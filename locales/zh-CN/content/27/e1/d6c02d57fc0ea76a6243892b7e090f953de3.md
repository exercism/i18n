# 简介

F# 中的`string`是一个对象，它用一系列 Unicode 字符（字母、数字、标点等）表示不可变的文本，定义方式如下：

```fsharp
let fruit = "Apple"
```

操作字符串有两种方式：调用字符串的方法，或者使用`String`模块里的函数。字符串一旦创建，它的值就永远不会改变。任何看似修改字符串的方法或函数，实际上都会返回一个新的字符串。

拼接或格式化字符串有几种不同的方式。
* 可以使用`+`运算符进行拼接：
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* 可以使用`sprintf`函数格式化文本，在格式文本中放置占位符（`%s`用于`string`），并把相应的值作为实参传入：
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
