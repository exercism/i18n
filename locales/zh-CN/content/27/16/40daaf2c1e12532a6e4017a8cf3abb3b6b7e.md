# 关于

## 简介

泛型是一种语言特性，它让代码可以复用。
例如，要计算一个数组的长度，不应该关心它里面装的是什么类型。
正因如此，`length`函数的类型签名里用了一个泛型类型参数`a`。

```elm
length : List a -> Int
```

## 类型中的参数

当一个类型泛化于另一个类型之上时，我们用小写名称来表示那个类型，并把它叫做类型参数。
常见的例子有 `List`、`Maybe` 和 `Result` 这几个自定义类型。

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

关于类型参数的名字，有一点很重要：它们可以有多个字符。
唯一的限制是必须使用小写名称。
因此，在有用的时候，我们倾向于给它们起描述性的名字。

一个类型可以泛化于多个其他类型之上，因而拥有多个类型参数。
这种情况下，每个彼此独立的类型都会得到不同的小写名称。
相互独立并不意味着它们不能是同一个类型，只是允许它们可以不同。

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

记录类型别名也可以有类型参数，不过不太常见。

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

## 函数中的类型参数

既然类型可以是泛型的，函数也可以。
处理泛型类型的函数也能写出来，比如 `Maybe.withDefault`。

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

把其他函数作为形参的函数叫做高阶函数，它们也可以是泛型的。

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
