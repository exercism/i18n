# 简介

元组是一个有序的值容器。和所有 Gleam 数据类型一样，元组是不可变的。元组中的每个元素都可以是不同类型，甚至可以是其他元组。

元组的写法是用逗号分隔的值，放在`#(`和`)`之间：`#(1, 2.0, "Three")`。

```gleam
#("one", 2)      // Tuple pair (2 values)
#("one", 2, 3.0) // Tuple triplet (3 values)
```

长度相同、类型相同（顺序也相同）的元组可以比较是否相等。

```gleam
#(1, 2) == #(1, 2) // Same length, same types, same values, same order
// -> True

#(1, 2) == #(2, 1) // Same length, same types, same values, different order
// -> False

#(1, 2) == #(1, "2") // Same length, different types
// Compile error!

#(1, 2) == #(1, 2, 3) // Different length
// Compile error!
```

要从元组中取出里面的值，有三种方式：

- 下标访问。
- 用`let`进行模式匹配。
- 用`case`进行模式匹配。

```gleam
let person = #("Jordan", 52)

// Option 1: Indexing
person.0 // -> "Jordan"
person.1 // -> 52

// Option 2: let
let #(name2, length2) = person
// -> name2 = "Jordan"
// -> length2 = 52

// Option 3: case
case person {
  #(name3, length3) -> {
    name3   // -> "Jordan"
    length3 // -> 52
  }
}
```

元组的下标访问可以用在 `case` 表达式的守卫中。

```gleam
pub fn is_18(person) {
  case person {
    _ if person.1 >= 18 -> True
    _ -> False
  }
}
```
