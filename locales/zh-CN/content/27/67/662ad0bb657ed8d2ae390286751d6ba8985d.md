# 简介

如果某个东西可以用它自身来定义，这种能力就叫做递归。在 F# 中，递归最常见于递归函数，也就是会调用自身的函数。

递归函数至少需要有一个_基线条件_和一个_递归条件_。_基线条件_直接返回一个值，不再调用函数自身。_递归条件_会再次调用函数，并修改传入的参数，让它最终能够匹配基线条件。

递归函数的定义方式和普通函数一样，只是多了一个`rec`修饰符。没有这个修饰符，函数就_无法_调用自身，任何这样的尝试都会导致编译错误。因此，递归必须显式声明。

```fsharp
let rec factorial x =
    // Base case
    if x = 1 then
        1
    // Recursive case
    else
        x * factorial (x - 1)
```

F# 还通过可区分联合类型支持递归类型。递归可区分联合类型的一个或多个用例会在各自的数据中引用这个可区分联合类型自身。和递归函数一样，递归类型也必须有基线条件。与递归函数不同的是，递归类型不使用`rec`关键字。

```fsharp
type RussianDoll =
    | Doll                 // Base case
    | Layer of RussianDoll // Recursive case
```
