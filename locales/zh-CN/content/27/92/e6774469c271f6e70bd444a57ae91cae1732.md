# 简介

Elixir 中的映射是一种以键值对存储信息的数据结构。在其他语言中，它也可能被称为关联数组（PHP）、哈希（Perl 5、Raku）或字典（Python）。

键和值可以是任何数据类型，但如果键是原子，就可以使用一种简写语法。映射在访问或返回时并不保证其条目的顺序。

## 字面量形式

空映射直接用`%{}`声明。如果想往映射字面量里添加条目，可以使用两种形式：

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

虽然没有固定的标准格式，但要选择一种一致的方式来书写键值对字面量。

## Map 模块函数

Elixir 在 _Map 模块_ 中提供了许多处理映射的函数。有些 _Map 模块_ 函数需要传入一个 _匿名_ 函数，来协助完成映射的转换。
