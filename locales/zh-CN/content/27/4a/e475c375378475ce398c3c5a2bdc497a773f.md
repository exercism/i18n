# 简介

在 Go 中，`map` 是一种内置的数据类型，它把键映射到值。
在其他编程语言里，你可能已经熟悉类似 `map` 的概念，比如字典、哈希表、键值存储或关联数组。

从语法上看，`map` 长这样：

```go
map[KeyType]ElementType
```

另外还有一点很重要：每个键都是唯一的，也就是说，对同一个键赋值两次，会覆盖这个键对应的值。

要创建 map，可以这样写：

```go
  // With map literal
  foo := map[string]int{}
```

或者

```go
  // or with make function
  foo := make(map[string]int)
```

下面是一些你可以对 map 进行的操作

```go
  // Add a value in a map with the `=` operator:
  foo["bar"] = 42
  // Here we update the element of `bar`
  foo["bar"] = 73
  // To retrieve a map value, you can use
  baz := foo["bar"]
  // To delete an item from a map, you can use
  delete(foo, "bar")
```

如果你试图获取 map 中不存在的键对应的值，它会返回值类型的零值。
这可能会让你感到困惑，尤其是当你的 `ElementType` 的默认值（例如 int 的 0）本身就是一个有效值时。
要检查某个键是否存在于 map 中，可以使用

```go
  value, exists := foo["baz"]
  // If the key "baz" does not exist,
  // value: 0; exists: false
```
