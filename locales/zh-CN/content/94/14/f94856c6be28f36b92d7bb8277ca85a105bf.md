# 介绍

## `for` 循环

`for` 语句会重复执行一个代码块。它的第一行控制代码块重复的频率：

```go
for init; condition; post {
    // loop body
}
```

- **初始化**语句在第一次迭代之前运行一次。通常会声明并初始化循环使用的计数器变量。
- **条件**是一个布尔表达式，在每次迭代之前求值。当它求值为 `false` 时，循环就会停止。
- **后置**语句在每次迭代完成后运行。可以用它来更新计数器。

不要用括号把 `init; condition; post` 括起来。不过，包裹循环体的花括号始终是必需的。

这个循环把 `i` 初始化为 `1`，打印 `i` 的当前值，为下一次迭代把它自增，并在 `i` 达到 `10` 时停止：

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
