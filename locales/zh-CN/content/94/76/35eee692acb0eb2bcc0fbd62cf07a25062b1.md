# 说明

你是圣诞老人物流部门的一名精灵，老板交给了你两项任务，用于升级系统的软件。

## 1. 获取玩具的名称

系统需要能够从数据库中获取玩具的名称。
数据库由类型为`(name: String, quantity: Int)`的元组组成。

实现函数`getName(_:)`，它接收一个实参，该实参保存着类型为`(name: String, quantity: Int)`的元组。

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. 向数据库中添加新玩具

玩具市场瞬息万变，热门的东西变化得非常快。
因此需要一个能够创建新玩具的函数。

实现函数`createToy(name:amount:)`，它接收两个实参：`name`保存玩具的名称，`amount`保存玩具的数量。

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. 更新玩具的数量

圣诞老人工坊里的精灵们不断地制造更多的玩具，而圣诞老人需要跟踪每种玩具的数量。
为此，系统需要能够更新数据库中玩具的数量。

实现函数`updateQuantity(_:toy:Amount:)`，它接收以下实参：
- `toys`，它保存一个由类型为`(name: String, quantity: Int)`的元组组成的数组。
- `toy`，它保存要更新的玩具的名称。
- `amount`，它保存玩具的新数量。

你可以假设玩具已经在数据库中，不需要为此做检查。

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. 为玩具添加分类键

圣诞老人希望能够对数据库中的玩具进行分类。
这样，当他们需要送货时就能轻松找到玩具，也能够对数据库中的玩具进行排序。

然而，系统最初实现时，分类键被遗漏了。
现在，系统需要能够为数据库中的玩具添加分类键。

实现函数`addCategory(_:category:)`，它接收以下实参：
- `toys`，它保存一个由类型为`(name: String, quantity: Int)`的元组组成的数组。
- `category`，它保存要添加到玩具的分类键。

你可以假设玩具已经在数据库中，不需要为此做检查。
你也可以假设玩具中还没有分类键。

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
