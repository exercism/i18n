# 说明

Elena 是一家报社的新任质量经理。
她刚来到公司，就决定检查一下工厂里的一些流程，看看有什么可以改进的地方。

她发现技术人员需要手工完成大量质量检查。

她觉得这是个实现自动化的好机会，于是请身为自由职业开发者的你开发一个软件，用来监控部分机器。

## 1. 监控房间的湿度

你的第一个任务是写一个软件来监控生产车间的湿度。
公司软件上已经连接了一个传感器，它会定期返回房间的湿度百分比。

你需要在软件中实现一个函数，当湿度百分比过高时抛出错误。
这个函数应该叫`check_humidity_level`，并把湿度百分比作为形参。

如果百分比超过 70%，你应该抛出错误并停止（错误消息本身不重要）。
否则，发出一条包含“humidity test passed”的消息，并返回`TRUE`，确认测量结果正常。

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. 检测过热

Elena 对你的第一个任务非常满意，于是让你负责监控机器的温度。
在和一位名叫 Greg 的技术人员聊天时，你得知如果机器的温度超过 500°C，技术人员就会开始担心过热问题。

机器上装有一个测量其内部温度的传感器。
你要知道，这个传感器非常敏感，经常损坏。
发生这种情况时，技术人员就需要更换它。

你的任务是实现一个函数`report_overheating`，它把温度作为形参，并在传感器损坏或机器开始过热时抛出错误。

考虑到之后你需要根据不同的错误做出不同的反应，你需要一种机制来区分这两类错误。

- 如果传感器损坏，温度会是`NULL`。
  这时，你应该抛出一条错误消息，并让消息中包含“Sensor Broken”这个字符串。
- 如果传感器正常工作，温度超过 600°C 时，你应该抛出一条包含该温度的消息。
- 如果温度超过 500°C 但不到 600°C，你应该发出一条包含该温度的警告，并返回`FALSE`。
- 否则，一切正常，发出消息`"temperature check passed: t °C"`，其中`t`是温度，并返回`TRUE`。

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. 监控机器

既然你的机器已经能检测错误，而且你有了一个自定义的机器错误，你就再添加一个包装函数来报告整体运行情况。
除了返回前面那些函数产生的日志，这个包装函数还需要根据发生的故障类型添加日志。

- 检查湿度和温度。
- 如果有问题，就让`check_humidity_level()`和`report_overheating()`输出它们各自的日志。
- 如果一切正常，添加一条包含“All OK”的消息。

实现一个函数`monitor_the_machine()`，把湿度和温度作为实参。

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
