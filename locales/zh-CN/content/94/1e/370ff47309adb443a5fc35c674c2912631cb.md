# 数据库大额支出

## 问题陈述

ABC Corp 需要你找出付款金额大于给定金额（例如`3000.00`）的员工的姓名和部门。

创建一个名为`HighPayment`的记录，用来返回所需的数据。该记录的定义如下。

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

使用 JDBC 客户端的`query`操作，从数据库中获取所需的数据。

> 注意：结果按`payment_id`升序排序。

## 数据库详情

本题使用提供的 H2 数据库。

> 示例数据库文件是`gofigure.mv.db`，数据库名称是`gofigure`。文件放在`db`文件夹里。

示例 H2 数据库中已经有下面这些表，里面带有一些示例数据。列名和数据类型如下。

**表名**：`Employee`

| **列：**      | 类型 |
| -----------       | ----------- |
| `employee_id`     | 整数，自增主键       |
| `name`            | 字符串        |
| `city`            | 字符串        |
| `department`      | 字符串        |
| `age`             | 整数        |

**表名**：`Payment`

| **列：**      | 类型 |
| -----------       | ----------- |
| `payment_id`      | 整数，自增主键       |
| `date`            | 日期        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 字符串        |

* 数据库文件是`gofigure.mv.db`。JDBC URL 请使用`jdbc:h2:file:/path/to/db/file`
* 用户名：`root`
* 密码：`root`

## 约束条件

* 使用`db`文件夹中提供的 H2 数据库文件来验证查询和 Ballerina 示例
* 使用 maven 依赖参数的方式，在 Ballerina.toml 中将 H2 数据库驱动添加为平台依赖

## 测试环境

* 可以用`bal test`运行测试，测试会针对给定的示例数据库执行。

## 示例

### 示例 1

**输入：** dbFilePath：`“/Path/to/file/gofigure”`，amount：`3000`

**输出：**`[{"name":"Anita Bath","department":"Marketing", "amount":3400, "reason": "Stationary"}, {"name":"Amanda Hug","department":"Engineering", "amount":4400, "reason": "Travel expenses"}]`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模块来操作数据库
* 请参考[前提条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)一节，了解将 JDBC 驱动添加为依赖的步骤
* 使用 [query](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-query) 远程方法从数据库中查询数据
* 参考[简单查询](https://ballerina.io/learn/by-example/mysql-query-operation)示例
* 使用 Ballerina 的 [stream](https://ballerina.io/learn/by-example/stream-type) 类型来访问数据
* 使用 SQL 连接从数据库中找出所需的数据集
