# 简介

Python 中的`str`是一种[不可变序列][text sequence]，由[Unicode 码点][unicode code points]组成。
这些码点可能包括字母、变音符号、定位字符、数字、货币符号、emoji、标点符号、各种空格、换行符等等。

字符串实现了所有[通用序列操作][common sequence operations]，可以用`for item in <str>`或`for index, item in enumerate(<str>)`语法来迭代。
字符串可以用`<str> + <other str>`或`<str>.join(<iterable>)`拼接，用`<str>.split(<separator>)`拆分，还提供多种格式化和组合选项。

要进一步操作字符串，Python 提供了一整套丰富的[字符串方法][str-methods]，可以用来搜索、清理、转换、翻译以及执行许多其他操作。

因为`str`是_不可变_的，对象在内存中的值不会改变；那些看起来会修改字符串的方法，实际上返回的是该`str`对象的一个新副本或新实例。
