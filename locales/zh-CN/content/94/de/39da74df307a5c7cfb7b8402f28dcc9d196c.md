# 说明

在这个练习中，你将为一位朋友正在开发的新角色扮演游戏实现任务逻辑。

游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛而忠诚的宠物狗。不幸的是，灾难降临了：她最好的朋友在森林里采摘浆果时被绑架了。

Annalyn 会尝试找到并解救她最好的朋友，在这次冒险中她可以选择是否带上她的狗。

沿着最好朋友的踪迹追踪了一段时间后，她找到了关押她最好朋友的营地。原来有 2 个绑匪：一个强大的骑士和一个狡猾的弓箭手。

找到绑匪后，Annalyn 开始考虑她可以采取以下哪些行动：

- _快速攻击_：如果骑士正在睡觉，就可以发动快速攻击。因为他穿上盔甲需要时间，所以这段时间他会很脆弱。
- _侦查_：只要他们中至少有一个人醒着，就可以侦查他们。否则，侦查只是浪费时间。
- _向囚犯发信号_：如果囚犯醒着而弓箭手正在睡觉，就可以用鸟叫声向囚犯发信号。因为弓箭手受过鸟叫信号的训练，可能会截获消息。
- _解救囚犯_：Annalyn 可以尝试潜入营地解救囚犯。
  这样做风险很大，只有下面 2 种方式之一能成功：
  - 如果 Annalyn 带着她的宠物狗，那么在弓箭手睡着时她就能救出囚犯。
    骑士害怕这只狗，而弓箭手来不及做好准备，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没有带狗，那她和囚犯就必须非常小心！
    如果囚犯醒着，而且骑士和弓箭手都在睡觉，Annalyn 就能解救囚犯；但如果囚犯在睡觉，就无法解救他：Annalyn 突然出现会吓到囚犯，从而惊醒骑士和弓箭手。

你有 4 个任务：根据在森林里发现的 3 个角色的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可用的逻辑。

## 1. 检查是否可以发动快速攻击

实现 `canFastAttack()` 方法，它接受一个布尔值，表示骑士是否醒着。如果根据骑士的状态可以发动快速攻击，该方法返回 `true`；否则返回 `false`：

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. 检查是否可以侦查这群人

实现 `canSpy()` 方法，它接受 3 个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。如果根据这 3 个角色的状态可以侦查他们，该方法返回 `true`；否则返回 `false`：

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. 检查是否可以给囚犯发信号

实现 `canSignalPrisoner()` 方法，它接受 2 个布尔值，分别表示弓箭手和囚犯是否醒着。如果根据这 2 个角色的状态可以给囚犯发信号，该方法返回 `true`；否则返回 `false`：

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. 检查是否可以解救囚犯

实现 `canFreePrisoner()` 方法，它接受 4 个布尔值。前 3 个形参分别表示骑士、弓箭手和囚犯是否醒着。最后一个形参表示 Annalyn 的宠物狗是否在场。如果根据这 3 个角色的状态以及 Annalyn 的宠物狗是否在场可以解救囚犯，该方法返回 `true`；否则返回 `false`：

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
