# 简介

Cairo 中的布尔值由预声明的布尔类型`bool`表示，它的值可以是`true`或`false`。

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo 支持 3 种逻辑运算符，它们可以把表达式求值为布尔值，返回`true`或`false`。

| 运算符      | 含义                                          |
| ----------- | --------------------------------------------- |
| `&&` (and)  | 两个判定都为真时，结果为真。                  |
| `\|\|` (or) | 至少一个判定为真时，结果为真。                |
| `!` (not)   | 仅当判定为假时，结果为真。                    |
