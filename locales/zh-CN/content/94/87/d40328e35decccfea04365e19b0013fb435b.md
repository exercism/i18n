# 精确数字

你已经见过的数字类型中，有两种是要有所取舍的。

`INT`正好是 32 位，所以它能保存的数字大约在 -20 亿到 20 亿之间，再往外就不行了。超出这个范围，它会悄悄回绕，不报错，只是给你一个错误答案。

`FLTD`能保存小数，但只是近似值。`0.1d + 0.2d`非常接近`0.3`，但并不精确。

当这些差异对你的工作确实重要时，库为这两种情况各提供了一个类型。

## INTI：任意大小的整数

`INTI`能保存任意大小的整数，唯一的限制是内存。

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

`INT`存不下这个数。`FLTD`能存一个接近它的值，但会丢掉最后 20 位数字。

你可以用`INT`来创建一个，也可以在数字太大、一开始就写不成`INT`时用字符串来创建：

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

之后`+`、`-`、`*`、`/`和比较运算都照常工作，`.str`会给出每一位数字。

算出一个舞团有多少种排队方式，是想要这个类型的典型理由。12 位舞者有 479001600 种排法，`INT`存得下；13 位有 6227020800 种，就存不下了。

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT：精确的分数

`RAT`用一个整数除以另一个整数来表示，并且始终保持这种形式。

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

不会发生舍入，因为任何东西都不会被转换成小数。

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

`RAT`会自己约分：`#RAT(2, 4)`就是`1/2`，打印出来也是`1/2`。如果结果正好是整数，就按整数打印：`#RAT(6, 3)`打印出`2`。

## 代价

这两种类型都比内置类型慢，而且都会分配内存。`INT`和`FLTD`是单条机器指令；`INTI`和`RAT`则是在软件中进行运算的对象。

在精确性至关重要的地方用它们，其他地方就用普通类型。
