# 简介

和许多其他语言一样，C++ 也有_指针_。
你已经知道_引用_和_指针_很相似，但不妨把它们看作更贴近计算机内部运作的一个层次。
_指针_是保存对象地址的变量。
用它们可以直接与对象交互，从而在 C++ 中实现动态内存分配和高效的数据处理。

如果你是第一次接触_指针_，可能会觉得它有点神秘，但一旦用熟了，就会发现它其实很直白。

它是 C++ 中至关重要的一部分，所以花点时间真正理解它。
这个知识点里介绍的最基础的版本也叫_笨指针_或_原始指针_。
现代 C++ 中还有_智能指针_，而这里的基础类型一点也不智能，所有工作都得你手动处理。

在深入细节之前，值得先理解_指针_的用途。
_指针_可以把对象的地址共享给程序的其他部分，这在两个主要方面很有用：

1. 和_引用_一样，指针可以避免拷贝，有助于减少程序的资源占用。
1. 与_引用_不同，指针可以重新指向别的对象。
1. 指针还可以指向空值，表示它当前没有指向任何对象。

## 通用语法

在 C++ 中声明指针，需要指定指针所指向的数据类型，后面跟一个星号（`*`）和指针的名字。
声明指针时，它不会自动初始化。
如果没有显式赋值，指针通常保存着一个不确定的值，常被称为“垃圾地址”。
虽然有些编译器可能会把指针初始化为`nullptr`，但并非所有编译器都保证这一行为，所以千万不要依赖它。
为了避免潜在问题，最佳做法是显式地初始化原始指针，并在使用前确认它不为空。

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

要把一个变量的地址赋给指针，可以使用取地址运算符（`&`）。
解引用指针则要使用_间接运算符_（`*`）。

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

注意：解引用必须显式写出，而_引用_用起来就像别名。

## 指针运算

_指针运算_让你可以对指针做算术操作，在配合数组使用时尤其有用。
给指针加上一个整数，它就会指向另一个元素。

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
在 C++ 中，指针运算如果处理不当，很容易导致__未定义行为__。
未定义行为可能表现为意料之外的运行结果、程序崩溃，甚至安全漏洞。
未定义行为的后果有一个臭名昭著的例子：1996 年的[阿丽亚娜 5 号火箭爆炸][ariane-flight-v88]。当时，把一个 64 位浮点数转换成 16 位有符号整数所引发的软件异常，最终导致了灾难性的失败。

## 访问成员变量

在 C++ 中，`->`运算符用于通过指向某个对象的指针来访问该对象的成员。
它是一种简写方式，简化了访问指针所指对象成员的操作。
例如，如果`ptr`是指向某个对象的指针，而该对象有一个成员变量`x`，那么你可以直接用`ptr->x`，而不必写`(*ptr).x`。
这个运算符提高了代码的可读性，也让处理对象指针时不再那么冗长。

下面是一个简短的例子，其中有一个名为`Superhero`的_结构体_，它带有一个成员变量`superpower`。
主函数创建了一个指向`Superhero`对象的指针`dianaPrince`（代表神奇女侠）。
这里用`->`运算符访问成员变量`superpower`，展示了神奇女侠标志性的“Lasso of Truth”。

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
```

## 指针与引用

指针和引用都能间接访问对象，但它们的能力和安全性考量不同。
指针可以灵活地更换所指向的对象，也可以被赋为空值。
不过，这种灵活性也带来了风险，比如解引用空指针，或者产生悬空指针。
而引用不能为空，并且在创建时就绑定到有效的对象上，因此避免了这些风险。
正因如此，除非确实需要指针提供的额外功能，否则应该优先使用引用。
