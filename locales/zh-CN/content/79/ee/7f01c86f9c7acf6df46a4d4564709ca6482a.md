# 简介

R 中的`vector`是同一`mode`的值的集合：`numeric`、`character`等。如果输入中混有不同类型，R 会悄悄把它们全部强制转换成同一种类型（通常是 character），这可能带来意想不到的结果。

## 创建向量

如果所有值都已经有了，就用`c()`（“concatenate”或“combine”的缩写）：

```R
x <- 10
v <- c(4, 7, x)
```

`c()`函数非常灵活，输入可以包含其他向量和范围。`c()`可以接受任意数量和种类的输入，并把它们展平成一个向量。

## 范围

对于一连串连续的值（递增或递减），可以使用`:`表示法：

```R
v <- 1:5 # equivalent to c(1, 2, 3, 4, 5)
w <- 10:7 # c(10, 9, 8, 7)
```

## 访问向量元素

和许多语言一样，我们可以用方括号里的下标来访问：

```R
> v <- 4:7
> v[2]
[1] 5
> v[2:4]
[1] 5 6 7
```

但要注意：***R 默认使用从 1 开始的下标***。

这在科学计算语言（Fortran、Matlab、Julia）中很常见，但与 C 及其众多后继语言的从 0 开始的下标不同。

范围既可以像上面的例子那样使用，也可以用在非常灵活的`c()`函数中：

```R
v <- c(4, 7, 10)
w <- c(2, v[2:3], 11) # c(2, 7, 10, 11)
```

`vectors`（和 R 中的大多数东西一样）可以视为可变的，用同样灵活的语法就能写入单个或多个元素：

```R
> v <- 1:10
> v[2] <- 42
> v[4:6] <- c(11, 12, 13)
> v
 [1]  1 42  3 11 12 13  7  8  9 10
```

## 负下标

熟悉其他语言的程序员可能会以为`v[-1]`是访问向量最后一个元素的方式。
错！

负下标其实是***删除***元素的一种方式，会返回一个更短的向量：

```R
> v <- c(2, 4, 6)
> v[-2]
[1] 2 6  # second element gone
```
