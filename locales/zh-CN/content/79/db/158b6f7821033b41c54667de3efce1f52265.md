# 关于

`Complex numbers`并不复杂。
它只是需要一个不那么吓人的名字。

复数非常有用，特别是在工程和科学领域，因此 R 把[复数][web-complex]和整数、双精度浮点数、逻辑值、字符、原始类型一样，列为标准的[原子类型][ref-atomic]。

## 基础

在 R 中，`complex`数是一个单独的值。
但在实际使用时，它可以被看作一对数字。
由于一些不幸的历史原因，这两个部分被称为“实部”和“虚部”。
同样，最好把注意力放在它本质上的简单之处，而不是这些奇怪的名字上。

要用两个实数创建复数，只需给虚部加上后缀 `i`。

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

如果要从实数变量创建复数，上面这种写法行不通。
写成`r + imi`会让解析器以为 `imi` 是一个（并不存在的）变量名。

你可以把虚部乘以 `1i`，也可以使用 [`complex()`][ref-complex] 函数：

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

你也许会问，为什么是 `i` 而不是 `j`？

大多数工程师更喜欢 `j`。
大多数科学家和数学家更喜欢用数学记号 `i` 来表示_虚_，但在电气工程中，`i` 已经被用来表示_电流_，两种记号就冲突了。

R 选择了 `i`，Python 选择了 `j`，而 Julia 避开了这场争论，选择了 `im`。
在理工科的不同编程语言之间切换时，要格外小心。

要分别取出复数的各个部分：

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

任一部分都可以为零，数学家会把这种数称为“纯实数”或“纯虚数”。
不过，它在 R 中仍然是复数。

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

你可能听说过“`i`（或 `j`）是 -1 的平方根”。

就目前来说，这只是说虚部_按定义_满足下面这个等式：

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

这个想法很简单，却能引出有趣的结论。

## 运算

用于浮点数和整数的大部分[`operators`][ref-operators]同样适用于复数：

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

复数乘法和除法的规则超出了本概念的范围（_而且你也不太需要经常“手工”做这些运算_）。

如果你想深入研究这个话题，任何一篇介绍复数的[数学][web-math-complex]或[电气工程][web-engineering-complex]入门材料都会讲到这些。

另外，Exercism 有一个[`Complex Numbers`][exercise-complex-numbers]练习，你可以从最基本的原理出发，实现一个带这些运算的复数类。

复数一般___不能___做整数除法，因此 `%/%` 和 `%%` 运算符对复数类型会失败。

## 函数

大多数数学函数都能接受复数输入。

不过，提供实数输入却指望得到复数输出，通常是不行的。

```r
sqrt(z1)
#> [1] 1.414214+0.707107i

sqrt(-1)  # fails!
#> Warning in sqrt(-1) : NaNs produced
#> [1] NaN

sqrt(-1 + 0i)  # succeeds with complex input
#> [1] 0+1i

sin(z1)
#> [1] 3.752771+0.256554i
```

除了 `Re()` 和 `Im()` 之外，还有几个函数和复数关系特别密切。
如果这些内容你看不懂，直接跳过就好！

- `Conj()` 只是把复数虚部的符号反过来（_从 + 变成 -，或者反过来_）。
  - 由于复数乘法的运作方式，它的用处比你想象的更大。
- `abs(<complex number>)` 保证返回一个不含虚部的实数（它的“模”），`Mod(<complex number>)` 是它的同义词。
- `Arg(<complex number>)` 返回以弧度表示的相位角。

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```

给喜欢数学的人一个简略的解释_（还是那句话，可以跳过）_：

- `z1` 的 `(real, imag)` 表示法实际上是在复平面上使用笛卡尔坐标。
- 同一个复数也可以用极坐标的 `(r, θ)` 记号来表示。
- 这里，`r` 和 `θ` 分别由 `abs(z1)` 和 `Arg(z1)` 给出。

下面用几个常数举个例子：

```r
 euler <- exp(1i * pi)

euler
#> [1] -1+0i
```

就这样，一个包含自然界三个最重要常数 `e`、`i`（或 `j`）和 `pi` 的简单表达式，结果居然是 `-1`。
有些人认为这是整个数学中最美的结果。
它大约可以追溯到 1740 年。

## 选读部分：复数常见问题

除非你有兴趣，否则这部分可以跳过。

### 这难道不是某种奇怪的新纯数学吗？

在 16 世纪，它确实是奇怪而新鲜的。

500 年后，它已经成为大多数工程学科和自然科学的核心。

### 为什么会有人用复数？

原来，复数正是描述任何旋转现象、或任何具有波动性质的事物最简单的方式。
因此它们被广泛应用于电气工程、音频处理、物理、电脑游戏和导航，这里只列举了其中一小部分应用。

你能看到东西在旋转。
复数也许不能让世界转动起来，却非常擅长解释世界转动_所带来的结果_：看看任何一张大型风暴的卫星图就明白了。

不那么显而易见的是，声音具有波动性，光具有波动性，无线电信号具有波动性，甚至你所在国家的经济也至少带有几分波动性。

这类波动处理有很多可以用三角函数（`sin()` 和 `cos()`）来完成，但很快就会变得很乱。

而复指数用起来要___容易很多___。

### 但我用不到复数啊！

只有当你住在山洞里、靠采集食物为生时，这话才成立。

如果你是在任何一种屏幕上读到这段话，那么你完全依赖于 20 世纪借助复数取得的一些实用进展。

__半导体芯片__。

- 它们在经典物理中毫无意义，只能用量子力学（QM）来解释（和设计）。
- 在量子力学中，按照定义，一切都是复数值。（_往下全是波形_）

__快速傅里叶变换算法__。

- FFT 是复数的一个应用，凡是和声音传输、音频处理、照片和视频有关的东西，_都_有它的身影。

- MP3 和其他音频格式用 FFT 来压缩，这样就能在更小的存储空间里放下更多音频。
- 在许多图像和视频格式中，JPEG 压缩和 MP4 视频同样用 FFT 来做压缩。

- FFT 也被用在数字滤波器里，让手机基站能把你的个人手机信号和其他人的信号分离开。

所以，你大概正在使用每秒依赖复数运算成千上万次的技术。
