# 说明

在这个练习中，你将组织各种遥控车之间的比赛。每辆车都有自己的特性，在整个锦标赛赛季的比赛中驶过许多不同的赛道。

~~~~exercism/note
本练习中的函数在一个 C 源文件中按照给出的签名声明。
你的 x86-64 汇编代码必须遵循这些规范。
~~~~

## 1. 创建一辆遥控车

你已经定义了一个结构体 `car_t` 来表示遥控车：

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

通过用 x86-64 汇编定义函数 `new_car` 来创建遥控车。
字段 `battery` 始终以值 `100.0` 开始。

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. 创建新赛道

赛道用结构体 `track_t` 表示：

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

`enum surface_t` 记录了赛道的不同路面：

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

通过用 x86-64 汇编定义函数 `new_track` 来创建新赛道。

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. 创建一场比赛

每场比赛最多有 6 辆车参加，在赛道上跑指定的圈数。
比赛用结构体 `race_t` 表示：

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

用 x86-64 汇编定义函数 `new_race`。
开始时，比赛还没有已确认的参赛车辆：

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. 确认一辆车参赛

当车主提出让某辆车参加比赛时，只有在名单还没有满的情况下，这辆车的参赛才会得到确认。

用 x86-64 汇编定义函数 `add_participant`。
如果比赛中还能再容纳一辆参赛车辆，就把这辆车加入名单，更新计数器，它的参赛就得到确认。
否则，赛事组织者必须告知车主，这次无法参赛。

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. 创建一场锦标赛

你用一个结构体 `tournament_t` 记录本赛季安排好的比赛：

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

用 x86 汇编定义函数 `add_race`，把一场比赛加入锦标赛的数组，并更新它的计数器。
你可以认为 `races` 数组里总是有足够的空间容纳新的比赛。

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
