# 简介

## 比较数字

在 JavaScript 中，可以使用以下关系和相等运算符来比较数字。

| 比较             | 运算符  |
| ---------------------- | --------- |
| 大于           | `a > b`   |
| 大于或等于 | `a >= b`  |
| 小于              | `a < b`   |
| 小于或等于    | `a <= b`  |
| （严格）等于        | `a === b` |
| 不（严格）等于    | `a !== b` |

比较的结果始终是布尔值，即`true`或`false`。

```javascript
1 < 3;
// => true

2 !== 2;
// => false

1 === 1.0;
// => true
// All numbers are floating-points, so this is different syntax for
// the exact same value.
```

## 比较字符串

在 JavaScript 中，上面的比较运算符也可以用来比较字符串。
此时会应用字典顺序（也就是字典序）。
你可以在[这里][utf-16-list]找到所有字符确切顺序的列表。

```javascript
'Apple' > 'Pear';
// => false

'a' < 'above';
// => true

'a' === 'A';
// => false
```

## 严格相等

你可能会想，JavaScript 里为什么用三个等号来检查相等。
`===`表示对_严格相等_的检查，也就是说不会进行类型转换，不同类型的值永远不相等。

```javascript
'3' === 3;
// => false
// The value on the left has type string, the value on the right has type number.

1 === 1n;
// => false
// The value on the left has type number, the value on the right has type bigint.
```

在 JavaScript 中，推荐使用`===`和`!==`来检查相等。

还有`==`和`!=`，它们表示检查_宽松相等_。
你应该避免使用它们，因为它们会在进行比较之前应用隐式类型转换。
这种情况下结果很难预测，有时也和你预期的不一样。

```javascript
0 == false;
// => true
```
