# 安装

[Godot Engine][godot-engine] 用来运行 GDScript 代码。
Godot Engine 可以在 Windows、Linux、macOS 和 Android 上运行。



## 安装 Godot Engine

Godot Engine 可以直接从 [Godot Engine 网站][download] 下载。
下载内容是一个单独的可执行文件，以 Godot Engine 的版本号命名。
这个文件需要重命名为`godot`，并放入`$PATH`中的某个目录。
完成安装后，你可以在终端中运行以下命令，以验证 CLI 是否安装成功：

```bash
godot --version
```

该 track 使用 Godot 4.7.2 版本。

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
