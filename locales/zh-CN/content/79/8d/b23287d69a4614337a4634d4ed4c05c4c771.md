# 提示

## 通用

- 也许你想创建一个基于标签和记录列表的 DSL，就像这样：

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- 或者，你也许更愿意使用基于链式函数调用的 DSL，就像这样：

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  又或者，你有一个完全不同的方案？
  放手去做吧！

- 话虽如此，一个 DSL 如果清晰、简洁，又不会太出人意料，通常就会更好（例如，`minus`函数是用来做减法的，不是用来在两个节点之间建立边的，就像`node("a") - node("b")`这样）。
