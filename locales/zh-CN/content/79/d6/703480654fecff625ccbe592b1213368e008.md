## 1. 编写一个闭包来交换两根电线

每颗臭弹上都有三根颜色不同的电线。
编写一个闭包，它接收一个`(String, String, String)`元组，返回将前两个元素顺序交换后的元组。
把这个闭包赋值给名称`flip`。

需要注意的是，类型必须是`ChangeClosure`（或某种可发送类型），类型定义已在桩文件中给出。
否则代码将无法编译。

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. 编写一个闭包来轮换电线

编写一个闭包，它接收一个`(String, String, String)`元组，返回将电线顺序向左轮换后的元组。
把这个闭包赋值给名称`rotate`。

需要注意的是，类型必须是`ChangeClosure`（或某种可发送类型），类型定义已在桩文件中给出。

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. 实现一个电线打乱生成器

为了弄清剪断臭弹电线的顺序，你需要实现一个函数，它根据臭弹的 ID 编号生成相应的打乱函数。

实现这个函数：

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

它接收一个交换两根电线的闭包和一个轮换三根电线的闭包作为输入，并返回一个闭包。
返回的这个闭包接收臭弹的 ID 编号和三根电线的顺序，然后计算电线需要剪断的顺序。
ID 编号由八个二进制位组成，每一位都会决定是交换还是轮换电线。

对于 ID 编号中的每一位，从最右边的位开始，如果该位是 0，就对电线元组应用`flipper`闭包；如果该位是 1，就应用`rotator`闭包，从而得到电线的新状态。
当 ID 的全部八位都应用了相应的闭包后，电线的最终状态就是需要剪断的顺序。

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
