# 简介

在 Common Lisp 中，假值由空列表 `()` 或符号 `nil` 表示。这些值可以被引用，也可以不被引用。

```lisp
;; Equivalent False Values
()   ; => NIL
nil  ; => NIL
'()  ; => NIL
'nil ; => NIL
```

Lisp 中的所有其他值都表示真。
此外还有一个特殊的常量符号 `t`，它总是等于 `t`（因此总是为真）。

```lisp
;; Some Different True Values
42                        ; => 42
"this statement is false" ; => "this statement is false"
t                         ; => T
't                        ; => T
```
