# 简介

这是一个_很大_的主题！
关于它完全可以写出一本厚书，而且已经有好几个人这么做了（在 Amazon 上搜索 “unicode book” 就能看到一些例子）。

## 一段极简史

在更早的几十年里，计算机处理字符要简单得多，那时程序员默认英语是唯一重要的语言。
于是：26 个字母（含大小写）、10 个数字、几个标点符号，再加上一个用来响铃的编码（0x07），全部塞进 7 个比特：这就是 ASCII 字符集。

自然而然，人们开始问 à、ä 和 Ł 怎么办，接着又有人开始问 ऄ、ஹ 和 ญ，而年轻人则想要 emoji 😱。
该怎么办？

长话短说，许多聪明又有耐心的人在委员会里工作了好多年，才把 Unicode 字符集以及 UTF-8 这类编码的细节敲定下来，而大量软件都需要进行_极其_复杂的重写。
同时，还引入了大量新的 bug。

为了防止_一切_都崩溃，Unicode/UTF-8 的设计确保前 127 个编码与 ASCII 完全相同（_连响铃的编码也是_）。

## Julia 中的字符

大约 2005 年之后设计的语言有一个巨大的优势：当时已经有了一个相当稳定的 Unicode 标准。

Julia（2012 年首次发布）可以假定一切都是 Unicode：字符、字符串、变量名和函数名、数学运算符……

引用手册里的话：“Julia 让处理纯 ASCII 文本变得简单高效，而处理 Unicode 也同样尽可能简单高效。”
注意“尽可能”这几个字，它是这句话里很重要的一部分。

***字符字面量用单引号书写，与用双引号书写的字符串截然不同。***

对来自 C/C++ 世界的人来说这显而易见，但对 Python 和 Javascript 程序员来说可能会造成困惑。

```julia-repl
julia> a = 'a'  # Roman alphabet
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)

julia> typeof(a)
Char

julia> jha = 'झ'  # Devanagari alphabet
'झ': Unicode U+091D (category Lo: Letter, other)

julia> typeof(jha)
Char

julia> '❤'  # heart emoji
'❤': Unicode U+2764 (category So: Symbol, other)
```

从这些例子可以看出，类型是`Char`，而且 Julia 还提供了关于字符类别的更多信息。

仔细看会发现，这些字符可以用 4 个十六进制数字表示。
而完整的字符集最多需要 6 个十六进制数字。

这些数字称为“码点”，目前的取值范围是 U+0000 到 U+10FFFF。
它们会显示在 REPL 中，但在代码里要用`codepoints()`获取。

在`Char`和`Int`之间转换很简单：

```julia-repl
julia> Int('a')
97

julia> Char(97)
'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

编译器允许对`Char`进行_某些_形式的整数运算：

```julia-repl
julia> 'b' - 'a'  # interval, in alphabetic order
1

julia> 'b' + 'a'
ERROR: MethodError: no method matching +(::Char, ::Char)

julia> 'a' + 5
'f': ASCII/Unicode U+0066 (category Ll: Letter, lowercase)

julia> 'f' + ('A' - 'a')  # same as `uppercase('f')`
'F': ASCII/Unicode U+0046 (category Lu: Letter, uppercase)
```

## 处理字符的函数

许多处理字符串的函数也能作用于`Char`输入。

- 对适用的大小写字母表，可以用`uppercase()`和`lowercase()`改变大小写。
- 用`isuppercase()`和`islowercase()`检测大小写。
- 用以下函数检测字符类型：
  - `isletter()`，覆盖许多字母表
  - `isdigit()`，只检测 0:9
  - `isnumeric()`，比`isdigit`更宽泛，¾ 以及各种非欧洲文字都返回`true`
  - `isxdigit()`，十六进制数字
  - `isascii()`，Unicode 之前的字符
  - `ispunct()`，标点符号
  - `isspace()`，任何空白字符
  - `isprint()`，可打印字符（反之为`iscntrl()`）

```julia
islowercase('A')  # false
uppercase('γ')  # 'Γ': Unicode U+0393 (category Lu: Letter, uppercase)
ispunct('@')  # true
isdigit('A')  # false
isxdigit('A')  # true
```

## Char 向量与字符串之间的转换

要把字符串转成 Char 向量，可以使用`collect()`。

要把 Char 向量转成字符串，可以用`String()`构造器。

```julia-repl
julia> s = "abcde"
"abcde"

julia> cv = collect(s)
5-element Vector{Char}:
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
 'd': ASCII/Unicode U+0064 (category Ll: Letter, lowercase)
 'e': ASCII/Unicode U+0065 (category Ll: Letter, lowercase)

julia> String(cv)
"abcde"
```

这对任何字符都适用，不只是 ASCII。

```julia-repl
julia> collect("❤,😱")
3-element Vector{Char}:
 '❤': Unicode U+2764 (category So: Symbol, other)
 ',': ASCII/Unicode U+002C (category Po: Punctuation, other)
 '😱': Unicode U+1F631 (category So: Symbol, other)
```

注意，`String()`构造器作用于 Vector。
要把单个`Char`_强制转换_成只含一个字符的字符串，要用`string()`函数，注意是小写的`s`。

```julia-repl
julia> string('a')
"a"
```

## 存储

到目前为止，本文的内容看起来都相对简单，那真的没什么可担心的吗？

可惜，这也太乐观了！

一个麻烦来自每个码点“最多”需要 6 个十六进制数字。
这意味着不同的字符在 UTF-8 编码下占用的内存空间各不相同。

一个字节只能存放最大到 255 的（无符号）数字，也就是两个十六进制数字，所以 UTF-8 用可变数量的字节（1 到 4 个）来存储一个`Char`。
这些称为“码元”，`ncodeunits()`函数会返回给定字符所需的字节数。

```julia-repl
julia> codepoint(jha)  # jha 'झ' is defined in an earlier example
0x0000091d

julia> ncodeunits(jha)
3

julia> ncodeunits('a')  # ASCII character
1

julia> ncodeunits('😱')  # emoji
4
```

另外，并不是所有能在屏幕上显示的东西都有自己独一无二的码点。
有些视觉上明显不同的字符被认为是派生自其他字符，因此 Unicode 把它们当作一个父字符加一个修饰符来处理。
