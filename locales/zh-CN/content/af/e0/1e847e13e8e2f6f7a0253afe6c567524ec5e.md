# 关于

属性的两种主要类型是：

1. 自动实现的属性，其`get`和`set`访问器没有方法体。它们可以显式初始化，也可以不初始化。例如：
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. 访问器会对表达式求值并执行语句的属性。代码可以简单到只是返回或赋值一个后备字段。例如：
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

属性和方法在行为和能力上有相当大的重叠。非自动实现的属性可以包含任何能出现在类的作用域内的语句或表达式。常见情况下，人们常把它们描述为对后备字段的封装。虽然在很多时候，某个具体情况下把行为写成属性还是方法一目了然，但这对开发者来说往往是个需要判断的取舍，尤其是访问器内应该执行多少代码。常见的做法是：在 set 访问器中进行验证，在 get 访问器中进行简单计算或格式化：

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

与其他类成员类似，属性也可以有访问级别。大多数情况下，属性会有一个与其核心用途相符的非私有访问级别。有时其中一个访问器的访问级别会与属性本身不同。在`TareWeight`的例子中，出于相当刻意的“安全”限制，可以让一个公共属性拥有私有的 get 访问器。这意味着类外部的代码可以设置该属性的值，但只有类内部的代码才能读取（get）它。

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

也支持非公共的 set 访问器，但更常见的情况是完全省略 set 访问器。这也许是因为属性的值在类的构造函数中设置。

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```

本练习介绍了属性的基本用法。你会在其他练习中找到更高级的主题：

- 表达式主体属性、get 访问器和 set 访问器（由“表达式主体成员”涵盖）
- 接口上的属性（由“接口”涵盖）
- 抽象类上的属性/抽象属性（由“继承”涵盖）
- `readonly`关键字与属性一起使用（由“不可变性”涵盖）
- 静态属性（由“静态”涵盖）
- 索引器（由“索引器”涵盖）
