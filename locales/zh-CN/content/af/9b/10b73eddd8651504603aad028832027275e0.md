# 测试

运行测试需要先执行 `cmake -G`，然后使用适合你所使用平台的构建命令。详细步骤见 exercism.org 上 C++ 的[运行测试][cpp-tests-instructions]页面。

## 通过测试

在本地开始一个新练习时，文件已经配置好，只会执行第一个测试。按照[测试驱动开发的三条规则][three-laws-of-tdd]，让第一个测试通过编译、链接并通过。只需声明命名空间、函数、类等，建立刚好够用的结构，消除编译错误，让测试失败。然后写刚好够用的代码，让测试通过。做完这些之后，把 `if defined(EXERCISM_RUN_ALL_TESTS)` 这一行移到下一个测试之前，取消对下一个测试的注释。

参见下面 Bob 练习中的例子（文件 `bob_test.cpp`，第 15 行）：

```diff
-#if defined(EXERCISM_RUN_ALL_TESTS)
TEST_CASE("shouting")
{
    REQUIRE("Whoa, chill out!" == bob::hey("WATCH OUT!"));
}
+#if defined(EXERCISM_RUN_ALL_TESTS)
```

把这一行移到下一个测试之前，可能会出现编译错误，因为这时会用到你尚未声明或定义的新结构。同样，以最小的改动消除编译错误，得到一个失败的测试；再以最小的改动修改代码，让测试通过；然后重构你的实现，让它更易读、表达更清晰，接着进行下一个测试。

尽量使用 C++17 标准库提供的功能，而不是自己手写底层的算法或工具。
