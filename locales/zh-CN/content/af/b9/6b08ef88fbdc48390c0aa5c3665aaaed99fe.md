# 简介

Haxe 内置了对正则表达式的支持。你可以用正则表达式验证字符串的格式、转换字符串，或者从给定文本中提取一些规律性数据。

要创建正则表达式，在`~/`和`/`之间输入内容：

```haxe
var r = ~/haxe/i;
```

另一种做法是使用`EReg()`实例：

```haxe
var r = new EReg("haxe", "i");
```

这里的`i`是一个标志，它让模式不区分大小写。还有其他标志，包括：

- `g`：全局替换。
- `m`：多行匹配

在`~/`和`/`之间，你输入正则表达式的模式。例如，你想查找一个包含从 A 到 Z 字母的字符串。这里我们可以使用范围模式`[A-Z]`。有很多表达式模式，包括：

- `.`：任意字符
- `*`：重复零次或多次
- `+`：重复一次或多次
- `[A-Z0-9]`：字符范围
