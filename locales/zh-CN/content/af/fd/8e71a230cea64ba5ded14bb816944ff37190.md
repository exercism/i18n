# 关于

`Time` 模块用于显示人类可读的日期和时间。虽然从技术上讲，用 `Time` 也能操作时间，但 Elm 社区有一些更适合这项任务的包，例如 [`justinmimbs/date`][date] 或 [`CoderDennis/elm-time-format`][elm-time-format]。

## Posix

时间由不透明类型 `Posix` 表示，它包装了 Unix 纪元时间，也就是自 1970 年 1 月 1 日 UTC 午夜以来经过的毫秒数。`Posix` 是一个无歧义的值，不会因时区不同而变化，因此很适合用来记录时间。在 Elm 应用中，`Posix` 时间通常由外部来源提供，例如浏览器。

可以用下面这两个函数把 `Posix` 转换成毫秒数，反过来也可以：

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## 时区

在日常生活中，我们人类通常不会去读 `Posix`，而是更愿意使用本地时间，它取决于我们在地球上的位置以及当地的夏令时规则。在 Elm 中，这些信息编码在不透明类型 `Zone` 里，通常由浏览器提供。

有一个特殊的 `Zone` 始终可用：

```elm
utc : Zone
```

## 人类可读的时间

有了 `Posix` 和 `Zone`，我们就有足够的信息以任意细致程度显示本地时间。下面列出了可以用于此目的的函数：

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

你可能已经注意到 `Time` 还有两个自定义类型：

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

把这些自定义类型转换成人类可读的值，就交给用户自己了。
