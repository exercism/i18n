# 关于

当一个类型可以通过_类型参数_来容纳任意类型的值时，它就是一个_泛型类型_。

例如，这个`Box`类型有类型参数`a`（用小写字母书写）。

```gleam
pub type Box(a) {
  Box(a)
}
```

类型参数`a`是任意类型的占位符，所以`Box`可以用于字符串、整数或任何其他类型。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

一个类型可以有多个类型参数，用逗号分隔即可。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## 泛型函数

类型参数也可以用在函数的实参中。

这个函数接收一个类型为`a`的值，并把一个接收`a`、返回`b`的函数调用两次。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
