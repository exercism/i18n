# 占位符

## 实现 List 操作

这个练习的目标，是你自己动手实现一些 List 的方法。
在底层用一个 List 对象来保存数据是很自然的做法。
不要用 List 自带的方法（比如`where`、`map`等）。

有一些“基本”的 List 操作是绕不开的，比如：

* 切片：`list[from..to]`
* 添加：`list.add(item)`

## 迭代器协议

要实现这些 List 操作，重点都在于用各种方式迭代。
先去读一读[迭代器协议][iter]。
之后你就能这样写了：

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
