# 补充说明

## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，应该始终包含一条**有意义的错误消息**，指明错误的来源。这能让代码更易读，对调试也有很大帮助。如果你知道错误的来源属于某种特定类型，可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍然应该包含一条有意义的错误消息。

本练习要求在无法用给定的硬币凑出找零时，使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)来“抛出”`ValueError`。只有既`raise`这个`exception`，又给它附带一条消息，测试才会通过。

要抛出带消息的`ValueError`，请把消息作为实参传给`exception`类型：

```python
# example when change cannot be made with the coins passed in
raise ValueError("can't make target with given coins")
```
