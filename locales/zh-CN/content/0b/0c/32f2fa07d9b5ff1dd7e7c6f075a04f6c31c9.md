# 整数

整数是不含小数部分的数，它们属于集合 `{..., -2, -1, 0, 1, 2, ...}`。
整数的最大值和最小值取决于 PHP 所运行的系统。
在大多数现代系统中，整数通常是 64 位的值，也就是说它可以表示从 `-9_223_372_036_854_775_808` 到 `9_223_372_036_854_775_807`（含两端）的整数。

```php
<?php

$a = 1234;
$a = 1_234_567;
```

除了十进制，你还可以使用进制前缀来书写整数字面量：

```php
<?php

$a = 0123; // octal number (equivalent to 83 decimal)
$a = 0o123; // octal number (as of PHP 8.1.0)
$a = 0x1A; // hexadecimal number (equivalent to 26 decimal)
$a = 0b11111111; // binary number (equivalent to 255 decimal)
```
