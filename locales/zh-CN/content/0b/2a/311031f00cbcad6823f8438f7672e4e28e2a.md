# 附加说明

## 轨道专属说明

在这个练习中，你需要定义一个名为`robot`的**locale**，其中定义了**nouns**`position`和`direction`，以及一个**verb**`move`。

- `robot`的`create` verb把初始位置和方向作为一个由 box 组成的数组接收。
    
    ```j
      r=. (0 0;'north') conew 'robot'
    ```
- `move`会更新所创建的**实例**中`position`和`direction`的值。
    ```j
      r=. (0,0;'north') conew 'robot'
      
      NB. initial state
      NB. ====================================
      position__r
        0 0
      direction__r
        north
      
      NB. new states after `move` is executed 
      NB. ====================================
      move__r 'LA'
      position__r
        _1 0
      direction__r
        west      
    ```
