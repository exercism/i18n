# 忽略

## 额外的 jq 命令行选项

你会注意到测试中给 `jq` 加了一些额外的选项。

```sh
run jq -s -R -c -f flower-field.jq << 'END_INPUT'
```

它们是做什么的？

- `-s`

  这是“slurp”模式。
  它不会把输入当作一串 JSON 对象来处理，
  而是把所有输入都收进一个数组里。

  ```sh
  $ seq 5 | jq -c '.'
  1
  2
  3
  4
  5
  $ seq 5 | jq -s -c '.'
  [1,2,3,4,5]
  ```

- `-R`

  你可能已经见过 `-r`，它用来输出“原始”字符串（不带引号）。
  这个选项正好相反。
  每一行输入都会被当作一个字符串。

  两个例子：

  ```sh
  $ seq 5 | jq -R -c .
  "1"
  "2"
  "3"
  "4"
  "5"

  $ echo 42 | jq '. * 2'      # input is a JSON number
  84
  $ echo 42 | jq -R '. * 2'   # input is a JSON string
  "4242"
  ```

把这两个选项放在一起时，你得到的_不是_一个字符串数组，而是整个输入作为单个字符串，连每行末尾的换行符也包含在内。

```sh
$ seq 5 | jq -s -R -c .
"1\n2\n3\n4\n5\n"
```

处理这一点正是这道练习的挑战之一。
