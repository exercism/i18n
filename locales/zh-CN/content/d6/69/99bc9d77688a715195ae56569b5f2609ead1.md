# 测试

在尝试运行测试之前，请按照安装步骤把练习文件夹正确设置好，也就是执行 `corepack yarn install`，并完成 Editor SDK 的配置。

用下面的命令运行测试：

```bash
$ corepack yarn test
```

和其他用户一样，确保你的代码遵循最佳实践，可以使用 eslint，它能对代码做静态分析。这类工具能帮你省下一些时间，及时发现代码里的拼写错误或低级失误：

```bash
$ corepack yarn lint
```

也可以两者同时运行：

```bash
$ corepack yarn test && corepack yarn lint
```

Exercism 上的 TypeScript 赛道不强制代码_风格_，所以你可以在分号、制表符还是空格，以及其他各种写法之间自由选择。

## 创建你的第一个模块

通常，本赛道的测试会以模块的形式导入你的实现来加载它：`import Bob from './bob';`。
要让这种方式生效，你需要在测试寻找你的模块的文件 `bob.ts` 里导出自己的实现：

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

我们在每个练习里都提供了桩文件，并帮你把这段 `export` 写好了。
