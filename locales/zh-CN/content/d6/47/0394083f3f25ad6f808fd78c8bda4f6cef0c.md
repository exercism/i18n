# 关于匿名函数与闭包

PHP 允许在其他函数内部声明函数。这些函数不需要有名字，但可以赋值给变量，甚至可以直接传给另一个需要函数形参的函数。

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

上面定义并传给 array_filter 的函数就是一个匿名函数。`array_filter` 用它来判断数组中的某个值是否会出现在 `array_filter` 的结果里。如果这个函数对某个值返回 `true`，那么这个值就会被包含在结果数组中。

匿名函数还可以在函数内部引用函数作用域之外的变量。这就是所谓函数的作用域对所用变量“闭合”，因此得名“闭包”。在某些语言中，作用域内的所有变量都自动允许在闭包中使用。对于 PHP，指代当前对象的 `$this` 会自动允许在闭包中使用。其他所有变量都必须通过 `use` 关键字显式引用。

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

在上面的 `makeAdderFunction` 函数中，传入的 `$number` 值被“闭合”在内部定义的匿名函数里，随后这个匿名函数被返回。之后这个函数无论何时执行，都知道传入的 `$number` 的值。如果你再用另一个数字调用这个函数，会返回一个完全不同的函数，不会改变第一次调用所返回的函数的值或功能。
如果你需要闭合多个变量，可以把它们都写进 `use` 关键字，用逗号分隔。

PHP 还有一种更简短的函数语法，叫做 `arrow functions`。它们必须相当简单，基本形式如下：

```php
fn(arguments) => expression
```

在这种函数写法中，你不需要使用 `use`。它会自动闭合并捕获父作用域中的任何值。箭头函数中的表达式会自动返回，无需使用 `return` 关键字。这样我们就可以把上面的 `onlyOdds` 函数改写成：

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

上面的 `makeAdderFunction` 可以改写成这样：

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**注意：** 如果这个函数无法写成一个表达式，那么就不能使用更简短的箭头函数语法。

变量以按值的方式传入匿名函数和闭包，并在其中使用。这意味着如果你在函数内部改变了变量的值，不会影响函数外部该变量的值。如果你需要修改这个值，可以按引用传递。

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

在上面的例子中，`array_walk` 会遍历数组中的每个元素，把每个值传给调用中声明的函数。它用 `$total` 记录累加的总和，每次加入的值都是该数字的绝对值。它还记录一共有多少个数字。这两个变量都在闭包中按引用使用，这由 `use` 部分中每个变量前面的 `&` 表示。这意味着当 `array_walk` 完成时，变量身上的修改依然有效，因此这个函数可以返回数组中各数字绝对值的平均值。

匿名函数和闭包提供了一种方便的方式，用来定义可能只在单一场景中用到的函数，或者定义这样一个函数：它根据一组形参返回一个动态函数，而这些形参的确定时间与函数真正被使用的时间并不相同。
