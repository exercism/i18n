# 简介

`Time`模块用于显示人类可读的日期和时间。
虽然从技术上讲，用`Time`来操作时间也是可以的，但 Elm 社区有一些更适合这项任务的软件包，比如 [`justinmimbs/date`][date] 或 [`CoderDennis/elm-time-format`][elm-time-format]。

## Posix

时间由不透明类型`Posix`表示，它封装了 Unix 纪元时间，也就是自 1970 年 1 月 1 日 UTC 午夜以来经过的毫秒数。
`Posix`是一个无歧义的值，不会因时区而改变，因此很适合用来记录时间。
在 Elm 应用中，`Posix`时间通常由外部来源提供，比如浏览器。

借助下面这些函数，可以在`Posix`和毫秒数之间相互转换：

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## 时区

在日常生活中，我们人类通常不会去读`Posix`，而是更喜欢本地时间，它取决于我们在地球上的位置以及当地夏令时的规则。
在 Elm 中，这些信息编码在不透明类型`Zone`里，通常由浏览器提供。

有一个特殊的`Zone`始终可以访问：

```elm
utc : Zone
```

## 人类可读的时间

有了`Posix`和`Zone`，我们就掌握了足够的信息，可以按任意详细程度显示本地时间。
下面列出可以用来做这件事的函数：

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

你还会注意到另外两个`Time`自定义类型：

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

把这些自定义类型转换成人类可读的值，就得靠用户自己了。
