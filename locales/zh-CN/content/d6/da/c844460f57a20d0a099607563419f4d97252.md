# 简介

在 Factor 中，*引用*本身就是一种值，就像数字或字符串一样。所谓引用，就是用 `[ ]` 括起来的代码。你可以把它存进变量，放进数组，传给另一个词，之后再*调用*它。

## `call`

`call`（位于[`kernel`][kernel]中）会运行一个引用：

```factor
3 4 [ + ] call .
! => 7
```

如果在 Factor 无法推断栈效应的上下文中`call`一个引用，就必须显式声明该效应：

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .
! => 2
```

这会编译一段运行时检查，确认该引用确实具有所声明的效应。

## 序列中的引用

因为引用是值，所以数组里可以同时存放数字和引用：

```factor
{ 3 4 [ + ] }
```

这样一来，“一段程序”就成了一个普通的序列，而`each`也就成了运行它的自然方式：

```
each ( seq quot -- )
```

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .
! 5 -> 6 -> 12
```

## 截取序列的末尾

`head*`返回除最后`n`个元素之外的所有元素；`last2`返回最后两个元素：

```
head* ( seq n -- headseq )
last2 ( seq -- penultimate last )
```

```factor
{ 1 2 3 4 5 } 2 head* .    ! => { 1 2 3 }
{ 1 2 3 4 5 } last2 .s
! => 4
! => 5
```

配合`suffix`，你就能写出“消耗栈顶两个元素、压入一个结果”这样的栈操作了。
