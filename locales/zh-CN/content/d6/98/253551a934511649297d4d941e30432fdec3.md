# 简介

[`function`][function]是一种把代码分隔开的方式，这样程序中的一个或多个位置就能通过名字调用它。
函数用来完成特定的、重复性的任务。

更正式地说：函数是任何可以应用[`function call`][calls]操作的 Python 对象。
函数可以用[`return`][return]返回一个或多个值，作为某些操作的结果；也可以用来产生一个或多个[`side effects`][side effects]。
如果函数没有指定返回值，它仍然会返回`None`。

下面是一个带副作用的函数示例：

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

在上面的示例中，[`def`][def]关键字用来表示函数定义的开始。
`hello`是函数的名称。
空括号表示没有向函数传递任何值。
函数体是那条单独的`print("Hello")`语句。
`print`本身也是一个函数。
`print`函数括号里的`"Hello"`被称为[`argument`][arguments]。
`print`函数用这个实参来确定要打印什么。
注意，函数体是缩进的。
缩进很重要，因为 Python 要靠它来判断那块代码在哪里结束。
函数体结束于程序末尾，或者刚好在下一行_没有_缩进的代码之前。
由于`hello()`没有指定`return`值，它会先执行副作用（也就是调用`print()`），然后返回`None`。
最后，我们用函数名和那对括号来调用它，这就告诉 Python 翻译这个名字是_可调用的_。

下面是一个带返回值的函数示例：

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

这个函数的函数体从_调用_`print`改成了_返回_`string` "Hello"。
最终，这段代码仍然会打印`"Hello"`，但副作用发生在_调用代码_里，而不是在`hello`函数里。
如果调用`hello`函数时漏掉了括号（比如`print(hello)`），那么`print`会输出类似这样的内容：

```
<function hello at 0x0000026E18E93E20>
```

重要的是，即使函数不接受任何实参（_也就是没有形参_），也必须用空括号来正确地_调用_它。
这不同于 Ruby 之类的语言，它们调用不带任何实参的函数时不需要空括号。

函数可以定义零个或多个[`parameters`][parameters]。形参定义了函数接受哪些实参。

下面是一个接受实参的函数示例：

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

形参定义为`name`。
`"Bob"`是程序传给`hello`函数的实参。
这个函数_返回_`string` "Hello, Bob"。

如果有人调用`hello`时没有传实参，会怎样？
程序会抛出错误：

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

如果不希望程序因为没有实参而报错（_但又想让调用代码可以不提供实参_），可以定义一个[默认实参][default arguments]。
默认实参定义了调用函数时缺少实参该用什么值。

下面是一个带默认实参的函数示例：

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

`name`形参的默认实参是`"you"`，所以如果没有传入`name`实参，程序会输出`Hello, you`。

关于函数实参的更多内容，请参阅[函数实参][function arguments]概念。
