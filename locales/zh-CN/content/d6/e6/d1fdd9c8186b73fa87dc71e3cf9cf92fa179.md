# 说明

你正在为录音棚里的一台小型调音台编写数字核心部分。

声音以一连串采样的形式传入。
每个采样都是一个数字，描述某个瞬间扬声器纸盆的位置。
调音台会一次处理整块采样，对每个采样应用相同的运算。

你有五个任务，每个任务都对内存中的一块采样进行运算。
你通过内存地址接收操作数，并通过结果地址写出答案。

~~~~exercism/note
这个练习中的计算应当使用 SIMD 指令完成，而不是标量运算。
~~~~

## 1. 混合两条音轨

录音棚有时会把不同乐器录在不同的音轨上。
为了让它们通过同一组扬声器播放，你要把两条音轨相加为一条。

实现 `mix_tracks` 函数，它逐采样地把两条音轨相加。
每条音轨都是一块 8 个有符号 16 位采样。
超出有符号 16 位范围的求和结果必须钳位，而不是回绕。

这个函数按以下顺序接收实参：

- `result`：一段 16 字节对齐的内存地址，指向写入 8 个混合后采样的缓冲区。
- `track_a`：第一条音轨的 16 字节对齐内存地址，包含 8 个有符号 16 位采样。
- `track_b`：第二条音轨的 16 字节对齐内存地址，包含 8 个有符号 16 位采样。

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

这个函数没有返回值。

## 2. 消除串音

当两支麦克风同时录音时，每一支都会拾取到另一支所录声源的微弱副本。
这种不需要的副本叫做_串音_。
一旦测出这种串音，就必须把它减掉，以清理音轨。

实现 `remove_bleed` 函数，它逐采样地从音轨块中减去串音块。
每个块都是 8 个有符号 16 位采样，减法必须饱和。

这个函数按以下顺序接收实参：

- `result`：写入 8 个清理后采样的内存地址（不保证对齐）。
- `track`：所录音轨的 16 字节对齐内存地址，8 个有符号 16 位采样。
- `bleed`：要消除的串音的内存地址，8 个有符号 16 位采样（不保证对齐）。

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

这个函数没有返回值。

## 3. 合并电平表

每个声道的上方都有一个电平表，一个小条，其亮度表示该声道有多响。
前面板上有一个主电平表，它的亮度应当相当于两个声道合并起来的亮度。
你把两个电平表块相加来驱动它。

注意，明亮的电平表会保持最亮，而不会回绕变暗，所以求和是饱和的。

实现 `combine_meters` 函数，它逐采样地把两个电平表块相加。
这个函数按以下顺序接收实参：

- `result`：写入 16 个合并后数值的 16 字节对齐内存地址。
- `meter_a`：第一个声道的电平表块的 16 字节对齐内存地址，包含 16 个打包的无符号 8 位值。
- `meter_b`：第二个声道的电平表块的 16 字节对齐内存地址，包含 16 个打包的无符号 8 位值。

每个块都是 16 个无符号 8 位值。
它们应当相加，并饱和到无符号范围。

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

这个函数没有返回值。

## 4. 应用淡出

歌曲不应该戛然而止，而应在结尾处淡出。
你有一块_增益系数_，每个采样对应一个，它们逐步递减，越来越轻。

每个系数都是一个以 `65536` 为分母的分数。
例如，如果一个采样的值是 `16384`，它实际表示 `16384 / 65536`，也就是 `1 / 4`。
可用的最大值 `32767` 略小于二分之一。

由于 `65536` 是 `2^16`，把采样乘以它的系数并保留乘积的_高半部分_，就得到 `sample * gain / 65536`。

实现 `apply_fade` 函数，它按系数缩放每个采样。
这个函数按以下顺序接收实参：

- `result`：写入所有缩放后采样的 16 字节对齐内存地址。
- `track`：音轨的 16 字节对齐内存地址，包含 `n` 个有符号 16 位采样。
- `gains`：增益系数的 16 字节对齐内存地址，包含 `n` 个有符号 16 位值，每个都在 `0` 到 `32767` 范围内。
- `n`：采样的数量，始终非零且是 `8` 的倍数，为 64 位无符号整数。

注意，音轨是一个数组，存放 `n` 个有符号 16 位采样，其中 `n` 永不为零，且始终是 `8` 的倍数。
对每个采样来说，缩放后的结果是该有符号乘积的高 16 位：`sample * gain`。

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
保留高半部分会向负无穷取整。
这就是为什么 `20000 * 32767` 缩放后是 `9999`，而 `-20000 * 32767` 缩放后是 `-10000` 而不是 `-9999`。
~~~~

这个函数没有返回值。

## 5. 衰减音轨

鼓手录得声音太大了。
为了把整条音轨的音量降下来，你要把每个采样都除以一个常数。

实现 `attenuate_track` 函数。
这个函数按以下顺序接收实参：

- `result`：写入结果的 16 字节对齐内存地址，结果为 32 位有符号整数。
- `samples`：采样的 16 字节对齐内存地址，`n` 个有符号 16 位值。
- `divisor`：除数的 4 个相同副本的 16 字节对齐内存地址，为 32 位整数。
- `n` 是采样的数量，始终非零且是 `4` 的倍数，为 64 位无符号整数。

注意，`samples` 是一个数组，存放 `n` 个有符号 16 位采样，其中 `n` 永不为零，且始终是 `4` 的倍数。

除数以同一个 32 位整数的 `4` 个副本提供，已经复制好，以便一次填满全部四个通道。

整数 SIMD 没有打包除法，所以这项工作用打包浮点数完成，然后再转换回打包的 32 位整数，存入 `result`。
转换回来时向零截断，所以商 `2.3` 变成 `2`，`-2.3` 变成 `-2`。

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

这个函数没有返回值。
