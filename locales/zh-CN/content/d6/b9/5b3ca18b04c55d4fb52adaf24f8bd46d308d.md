# 说明

在这个练习中，你将编写代码，帮助一位自由职业者与项目经理沟通。
你的任务是提供几个工具，用来快速计算日薪和月薪，并且可以选择性地应用给定的折扣。

我们先约定自由职业者和项目经理之间的几条规则：

- 日薪是时薪的 8 倍。
- 一个月有 22 个可计费工作日。

有时，自由职业者会愿意在日薪上给出折扣（例如针对最忠实的客户或非营利客户）。

折扣用表示百分比的小数来建模，例如`25.0`（25%）。

## 1. 根据时薪计算日薪

实现一个名为`daily_rate`的函数，接收时薪作为形参，计算日薪。
约定中规定一天有 8 个可计费工时。

```cpp
daily_rate(60)
// => 480.0
```

返回的日薪应该是`double`类型。

## 2. 计算折扣后的价格

实现一个`apply_discount`函数，用来计算打折后的价格。
它应该接收两个形参：原价和以百分比表示的折扣。

```cpp
apply_discount(150, 10)
// => 135.0
```

返回值应始终是`double`类型，不要做任何取整。

## 3. 根据时薪和折扣计算月薪

实现一个`monthly_rate`函数，用来计算折扣后的月薪。
它应该有两个形参：时薪和以百分比表示的折扣。

```cpp
monthly_rate(77, 10.5)
// => 12130
```

返回的月薪应该向上取整（取上限）到最接近的整数。

## 4. 根据预算、时薪和折扣计算完整的工作日天数

实现一个`days_in_budget`函数，接收预算、时薪和折扣，计算出这些预算能覆盖多少个完整的工作日。

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

返回的天数应该向下取整（取下限）到最接近的整数。
