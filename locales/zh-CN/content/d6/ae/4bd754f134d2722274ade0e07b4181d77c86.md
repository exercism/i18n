# 简介

Java 的`char`基本类型用 16 位来表示单个 Unicode 字符。

~~~~exercism/note
`char`类型基于[最早的 Unicode 规范][unicode-specification]，该规范用 16 位来表示字符。
这足以覆盖大多数常见字母，涵盖 0x0000 到 0xFFFF 范围内的字符。
此后，该规范把可用字符的范围扩展到了 0x01FFFF。

[unicode-specification]: https://www.unicode.org/versions/Unicode1.0.0/
~~~~

多个`char`可以组成一个字符串，比如`"word"`，`char`也可以单独处理。
`char`字面量用单引号括起来（例如`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## 获取`String`中的`char`

`String.toCharArray`方法会把字符串的字符作为数组返回。
正如[数组][concept-arrays]中提到的，你可以用`for`循环来遍历这个数组。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## [Character][docs-character]类

有很多内置的库方法可以用来检查和操作`char`。
它们是[`java.lang.Character`][docs-character]类的静态方法。
下面是一些例子：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

~~~~exercism/note
Character 类中的一些方法有重载，因此既可以接收`char`，也可以接收`int`。
例如，`isDigit`有一个重载接受[`char`][is-digit-char]，另一个接受[`int`][is-digit-int]。
前面提到过，`char`类型只能表示 0x0000 到 0xFFFF 范围内的字符。
而`int`可以表示所有字符，所以才有了这些接收`int`的重载。

[is-digit-char]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(char)
[is-digit-int]: https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Character.html#isDigit(int)
~~~~

## 把`char`添加到`String`中

可以用`+`运算符把`char`添加到`String`中。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
注意，_不要_用`+`把两个`char`连接成一个`String`！
用这种方式把两个`char`相加得到的是`int`，_不是_`String`！
例如：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

这是因为 Java 会把`char`提升为`int`（参见[Java Language Specification][jls-main]的[4.2 Primitive Types and Values ][jls-primitives]）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

不过，当需要添加的字符很多时，改用[`StringBuilder`][docs-stringBuilder]会更高效：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
