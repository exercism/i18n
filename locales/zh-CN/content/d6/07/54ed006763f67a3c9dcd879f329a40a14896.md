# 布尔值

Crystal 有一种类型，叫做[`Bool`][bools]。
它表示`true`和`false`这两个值。

## 逻辑运算符

Crystal 有三个逻辑运算符（`!`、`||`、`&&`），它们可以组合布尔值，生成结果不同的表达式。

### 与（`&&`）

在 Crystal 中，[_与_运算符][and]用`&&`表示：如果两个值都是`true`，就返回`true`；否则返回`false`。
使用_与_运算符时，一个布尔值放在`&&`右边，另一个放在左边。

```crystal
true && true
# => true

true && false
# => false
```

### 或（`||`）

在 Crystal 中，[_或_运算符][or]用`||`表示：只要给定的值中**至少有一个**是`true`，它就返回`true`。
如果两个值都是`false`，它就返回`false`。
使用_或_运算符时，一个布尔值应放在`||`右边，另一个放在左边。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### 非（`!`）

在 Crystal 中，_非_运算符用`!`表示：如果给定的布尔值是`false`，就返回`true`；如果给的是`true`，就返回`false`。
使用_非_运算符时，布尔值应放在运算符（`!`）之后。

```crystal
!true
# => false

!false
# => true
```

## 使用括号（`()`）

处理布尔值时，可以用括号来决定先计算哪个布尔值。
括号的用法不同，结果也可能不同。
在 Crystal 中，括号里的内容会先被计算。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

由于括号里的内容会先被计算，所以在下面的例子中，_非_运算符会作用于括号内的表达式。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
只有当括号会影响结果时才应该使用它；否则应当省略。
~~~~
