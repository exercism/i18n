# 说明附录

## 词

定义一个`linked-list-node`元组。

定义一个`linked-list`元组，并提供一个`M: linked-list length`方法（来自`sequences`），这样测试就能直接在你的链表上调用`length`。

- `<linked-list> ( -- linked-list )`：构造一个空链表。
- `>linked-list ( seq -- linked-list )`：按顺序把`seq`中的每个元素压入一个新链表。
- `linked-list>array ( linked-list -- array )`：返回各个值，链表顶部的值在最前面。
- `list-push ( linked-list value -- linked-list )`：把一个值压入顶部。
- `list-pop ( linked-list -- linked-list value )`：移除并返回顶部的值。
- `list-peek ( linked-list -- value )`：返回顶部的值，但不移除它。
- `list-reverse ( linked-list -- linked-list )`：返回一个元素顺序相反的链表。

当链表为空时，从`list-pop`和`list-peek`中抛出`list-empty`错误类。
