# 说明

在这个练习中，你要写一些代码，帮你照着最喜欢的烹饪书做一份美味的千层面。

一共有四项任务，都和烹饪千层面所花的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义`Lasagna.expectedMinutesInOven()`方法，它不接收任何形参，返回千层面应该在烤箱里烤多少分钟。根据烹饪书，烤箱的预期时间是 40 分钟：

```scala
val lasagna = new Lasagna()
lasagna.expectedMinutesInOven()
// => 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`Lasagna.remainingMinutesInOven()`方法，它把千层面已经在烤箱里烤的实际分钟数作为形参，并根据上一项任务得出的烤箱预期时间，返回千层面还需要在烤箱里烤多少分钟。

```scala
val lasagna = new Lasagna()
lasagna.remainingMinutesInOven(30)
// => 10
```

## 3. 计算准备时间（分钟）

定义`Lasagna.preparationTimeInMinutes()`方法，它把你往千层面里加了多少层作为形参，并返回你准备千层面花了多少分钟，假设每加一层需要 2 分钟。

```scala
val lasagna = new Lasagna()
lasagna.preparationTimeInMinutes(2)
// => 4
```

## 4. 计算已用时间（分钟）

定义`Lasagna.elapsedTimeInMinutes()`方法，它接收两个形参：第一个形参是你往千层面里加的层数，第二个形参是千层面已经在烤箱里烤的分钟数。函数应该返回你烹饪千层面一共花了多少分钟，也就是准备时间的分钟数，加上此刻千层面在烤箱里已经烤的分钟数。

```scala
var lasagna = new Lasagna()
lasagna.elapsedTimeInMinutes(3, 20)
// => 26
```
