# 错误处理

在本练习中，你将实现一个名为 `processString` 的函数，它负责处理给定的输入字符串，并妥善处理可能出现的错误。

你将学到：

- 检查输入类型，并在输入无效时抛出错误。
- 针对特定情况（例如空字符串）抛出错误。
- 如果字符串有效，返回它的大写形式。
- 使用 try..catch 代码块处理和捕获错误


使用 `try…catch` 代码块实现 processString 函数。

在 `try` 代码块内：
- 如果输入不是字符串，抛出 `TypeError`。
- 如果输入是空字符串，返回 `null`。
- 如果输入长度大于 100，或小于 10，抛出 `RangeError`
- 如果输入同时包含字母和数字，抛出 `SyntaxError`。
- 否则，以`uppercase`形式返回输入。

*抛出错误时别忘了附上合适的错误信息！一条信息明确、结构清晰的错误信息能帮你省下好几个小时的调试时间。*

在 `catch` 代码块内：
- 使用 `console.log` 记录错误信息
- `throw` 抛出 `error`，这样可以测试它的类型。
