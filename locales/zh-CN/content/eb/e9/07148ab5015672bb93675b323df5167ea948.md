# 测试

要测试提交的解答，只需**运行测试脚本**。你可以在 Red Console 中使用`do`函数并搭配测试脚本的路径，就像这样：

```red
do %exercism/red/hello-world/hello-world-test.red
```

或者，直接在系统终端里把它作为参数传给 Red 可执行文件：

```shell
red exercism/red/hello-world/hello-world-test.red
```

一开始，测试文件中只有第一个测试会处于启用状态。这样是为了鼓励你一次只解决一个练习。第一个测试通过以后，把测试文件开头的`test-init`函数的第二个*实参*改一下，再运行一次。这个值是启用测试的数量，所以把它从`1`改成`2`就会启用第二个测试。你也可以去掉`test-init`函数的`\limit`精化和第二个实参，这样就能运行所有测试，不再跳过任何一个。
