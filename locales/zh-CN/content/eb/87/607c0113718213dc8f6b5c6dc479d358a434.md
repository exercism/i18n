# 说明补充

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的姓名字符串，或 null 指针 |
| `$a1`    | 输入/输出 | 地址 | 以 null 结尾的结果字符串                |
| `$t0-9`  | 临时    | 任意     | 用于临时存储                        |
