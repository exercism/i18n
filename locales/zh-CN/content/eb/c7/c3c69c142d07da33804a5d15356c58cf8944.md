# 说明附录

## 寄存器

| 寄存器 | 用途 | 类型 | 描述 |
| -------- | ------------ | ------- | ------------------------------------------- |
| `$a0`    | 输入        | 整数 | 输入硬币的数量                       |
| `$a1`    | 输入        | 整数 | 目标金额                             |
| `$a2`    | 输入/输出   | 地址 | 可覆写的硬币值数组                      |
| `$v0`    | 输出        | 整数 | 输出硬币的数量，输入无效时为 -1          |
| `$t0-9`  | 临时        | 任意 | 用于临时存储                          |
