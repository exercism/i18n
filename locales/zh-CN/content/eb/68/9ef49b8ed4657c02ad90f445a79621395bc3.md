# 关于

Factor 中的大部分迭代都是用组合子（`each`、`map`、`reduce`）来表达的，不过显式递归仍有它的用武之地：当递归不是数组形状的时候，当基本情况并不简单的时候，或者当你要自己实现一个组合子的时候。

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

有几点需要了解：

- 普通的 `:` 定义就能递归，不需要任何特殊语法。编译器会跨递归调用推断栈效应。
- `loop ( quot -- )` 让你可以迭代一个返回布尔值的引用：只要返回的结果为真，就一直循环下去。
- 尾调用会编译成跳转，所以深度递归的词不会把栈撑爆。

`unclip` 和 `if-empty` 这一对是标准的序列递归形式；`cond` 则是标准的多分支分派形式。
