# 简介

当 Elixir 解析要调用的函数时，它会使用模块名进行查找。如果模块名绑定到了变量，查找就可以动态进行。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

在内部，模块名是一个原子。所有 Elixir 模块原子都会自动加上前缀`Elixir.`

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
