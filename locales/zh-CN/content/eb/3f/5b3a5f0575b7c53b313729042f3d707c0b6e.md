# 简介

Gleam 用`Bool`类型表示 true 和 false 值。它只有两个值：`True`和`False`。这些值可以绑定到变量上：

```gleam
let true_variable = True
let false_variable = False
```

可以用`&&`、`||`和`!`运算符来操作布尔值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`运算符采用短路求值，也就是说，只有当需要时，才会计算运算符右侧的表达式。

各运算符的优先级不同，其中`!`会先于`&&`和`||`计算。可以用大括号让表达式的一部分先于其他部分计算：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
