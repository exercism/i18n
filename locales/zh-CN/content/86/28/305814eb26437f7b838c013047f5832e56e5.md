# 简介

知道一份数据的类型，对代码能否顺利运行、不出错往往非常重要。

JavaScript 有几种方法可以检查一个值或对象的类型。

```exercism/note
JavaScript 的类型检查机制有时并不太可靠。

想要更好的类型安全和更强的类型，你或许应该使用 TypeScript。这种语言建立在 JavaScript 之上，但采用了静态类型语言的类型语法。
```

## `typeof`运算符

`typeof`运算符返回其操作数的类型。
结果是一个字符串，与某个[原始数据类型][primitives]的名称一致，唯一的例外是`"null"`。
它还可能是`"function"`或`"object"`。

```javascript
typeof undefined;
// => "undefined"

typeof true;
// => "boolean"

typeof 42;
// => "number"

typeof 'Hello, World!';
// => "string"

typeof function () {
  return 'Hello, World';
};
// => "function"

typeof [1, 2, 3, 4];
// => "object"

typeof { city: 'Stockholm', country: 'Sweden' };
// => "object"
```

出于[历史原因][`typeof null` is `"object"`]。

## `instanceof`运算符

要检查对象的类型，可以使用`instanceof`运算符。
它会根据第二个操作数是否出现在第一个操作数的[原型链][prototype chain]中，计算出一个`boolean`。
更清楚地说，`instanceof`返回的是第一个操作数是否为第二个操作数的实例，或者是它某个子类的实例。
`instanceof`只能用于对象。

```javascript
class Beverage {
  // ...
}

// The Coffee class is a child of the Beverage class.
class Coffee extends Beverage {
  // ...
}

const java = new Coffee();

java instanceof Coffee;
// => true

java instanceof Beverage;
// => true
```

````exercism/advanced
`Array`类有一个名为`Array.isArray()`的方法，用来检查它的实参是否为数组。

对于在不同领域中创建的数组，比如网页里的`iframe`，`instanceof Array`不会生效，而`Array.isArray()`可以。

这是因为`Array`类在每个领域中都有不同的构造函数，而每个`iframe`都有自己的领域，也就是说原型链中的函数会不一样，导致`instanceof Array`失败。
`Array.isArray()`能够忽略这一点，只要有可能就应该始终使用它。

它还能应对误报：有些对象其实并不是`Array`，只是原型链里有`Array`。

```javascript
({ __proto__: Array.prototype }) instanceof Array
// => true

Array.isArray({ __proto__: Array.prototype })
// => false
```

````

## `in`运算符

`in`运算符返回第一个操作数是否为第二个操作数的属性。
它不会检查该属性是否已经有一个确定的值。
被设为`undefined`的属性仍然会被`in`检测到。

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
    this.isDarkMatter = undefined;
  }

  coolDown() {
    this.temperature = 'warm';
  }
}

const espresso = new Coffee();

'temperature' in espresso;
// => true

'color' in espresso;
// => false

'isDarkMatter' in espresso;
// => true
```

````exercism/note
对于继承来的属性和方法，`in`会返回`true`。

```javascript
"coolDown" in espresso
// => true

"constructor" in espresso
// => true
```

要避免这种情况，请改用`Object.hasOwn()`。
````

## `Object.hasOwn()`函数

`Object.hasOwn()`方法返回指定的对象是否_拥有给定的属性_（即该属性不是继承来的，也不是方法）。

```javascript
class Coffee {
  constructor() {
    this.temperature = 'hot';
  }

  coolDown() {
    this.temperature = 'warm';
  }
}
const cappuccino = new Coffee();

Object.hasOwn(cappucino, 'temperature');
// => true

Object.hasOwn(cappucino, 'constructor');
// => false

Object.hasOwn(cappucino, 'coolDown');
// => false
```
