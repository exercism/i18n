# 简介

Factor 中的大部分数据都存放在*序列*里。数组、向量和字符串都是序列，并且共享来自 [`sequences`][sequences] 词表的同一组单词。

## 数组字面量

字面量数组用 `{ }` 表示，元素之间用空白分隔：

```factor
{ 1 2 3 } .          ! => { 1 2 3 }
{ "a" "b" "c" } .    ! => { "a" "b" "c" }
```

数组长度固定，所以像`suffix`和`remove-nth`这类会改变元素个数的单词，返回的是一个*新*序列，而不是在原序列上增长。

## 长度与下标

```
length   ( seq -- n   )
first    ( seq -- elt )
rest     ( seq -- tailseq )    ! everything but the first element
last     ( seq -- elt )
but-last ( seq -- headseq )    ! everything but the last element
nth      ( n seq -- elt )      ! 0-based
?nth     ( n seq -- elt/f )    ! 0-based; f when out of bounds
```

```factor
{ 10 20 30 } length .       ! => 3
{ 10 20 30 } first .        ! => 10
{ 10 20 30 } rest .         ! => { 20 30 }
{ 10 20 30 } last .         ! => 30
{ 10 20 30 } but-last .     ! => { 10 20 }
1 { 10 20 30 } nth .        ! => 20
```

`?nth`是带边界保护的版本：不用先检查长度，就能探测某个位置。

```factor
1 { 10 20 30 } ?nth .       ! => 20
9 { 10 20 30 } ?nth .       ! => f  (out of bounds, no error)
```

## 切片

```
head ( seq n -- headseq )    ! first n elements
tail ( seq n -- tailseq )    ! drop first n
```

```factor
{ 1 2 3 4 5 } 3 head .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 3 tail .   ! => { 4 5 }
```

如果`n`大于序列的长度，两者都会抛出错误。如果`n`太大，`index-or-length`会把它缩小到序列的长度，这样接下来的切片就不会越界：

```
index-or-length ( seq n -- seq n' )
```

```factor
{ 10 20 30 40 50 } 3 index-or-length head .   ! => { 10 20 30 }
{ 10 20 } 3 index-or-length head .            ! => { 10 20 }
```

带星号的变体`head*`和`tail*`从末尾开始计数：`head*`丢掉最后`n`个元素，`tail*`保留最后`n`个元素：

```
head* ( seq n -- headseq )   ! everything except the last n
tail* ( seq n -- tailseq )   ! the last n elements
```

```factor
{ 1 2 3 4 5 } 2 head* .   ! => { 1 2 3 }
{ 1 2 3 4 5 } 2 tail* .   ! => { 4 5 }
```

要在两个下标之间切出任意一段，可以用`subseq`，它接收*起点*（包含）和*终点*（不包含）：

```
subseq ( from to seq -- subseq )
```

```factor
1 4 { 10 20 30 40 50 } subseq .   ! => { 20 30 40 }
1 4 "hello" subseq .              ! => "ell"
```

当你手上是*起点和长度*时，把它们相加就得到终点：

```factor
2 dup 3 + "hello world" subseq .  ! => "llo"
```

（也就是下标范围 `[2, 5)`，从位置 2 开始取 3 个字符。）

反过来问*子序列出现的位置*，就交给`subseq-index`：它返回第一个匹配项的起始下标，没有匹配时返回`f`：

```
subseq-index ( seq subseq -- i/f )
```

```factor
"hello world" "o w" subseq-index .   ! => 4
"hello world" "xyz" subseq-index .   ! => f
```

## 填充

```
pad-head ( seq n elt -- padded )    ! prepend copies of elt
pad-tail ( seq n elt -- padded )    ! append copies of elt
```

两者都会扩展`seq`，直到它的长度至少为`n`。如果`seq`已经这么长，就原样返回。

```factor
{ 2 5 0 } 6 0 pad-tail .   ! => { 2 5 0 0 0 0 }
{ 4 1 } 5 9 pad-head .     ! => { 9 9 9 4 1 }
```

## 同样的单词也适用于字符串

字符串是字符组成的序列，所以上面这些同样适用于字符串，只不过结果是另一个字符串，而不是数组：

```factor
"hello" length .            ! => 5
"hello" 3 head .             ! => "hel"
"abc" 6 CHAR: . pad-tail .   ! => "abc..."
```

## 聚合

`sum`和`product`（在 [`sequences`][sequences] 中）会把一个数字序列的元素相加或相乘：

```factor
{ 2 5 0 7 } sum .        ! => 14
{ 2 5 3 7 } product .    ! => 210
```

`count`会在序列上运行一个谓词，返回有多少个元素使它为真：

```
count ( seq quot -- n )
```

```factor
{ 2 5 0 7 4 1 } [ even? ] count .    ! => 3
```

## 作用于整个序列的谓词

```
any?   ( seq quot -- ? )
all?   ( seq quot -- ? )
empty? ( seq -- ? )
```

```factor
{ 2 5 0 7 } [ 4 > ] any? .      ! => t
{ 2 5 0 7 } [ 0 > ] all? .      ! => f
```

## 构建新序列

`suffix`把一个元素加到序列末尾，`prefix`把一个元素加到开头。`unclip`剥掉第一个元素，`unclip-last`剥掉最后一个元素：

```
prefix      ( seq elt -- newseq )
suffix      ( seq elt -- newseq )
unclip      ( seq -- rest first )
unclip-last ( seq -- butlast last )
```

```factor
{ 7 9 } 3 prefix .             ! => { 3 7 9 }
{ 7 9 } 3 suffix .             ! => { 7 9 3 }
{ 4 0 9 } unclip .s
! => { 0 9 }
! => 4
```

把`unclip-last`和`suffix`组合起来，就能非破坏性地更新最后一个元素（`unclip`加`prefix`对第一个元素也是同样效果）：

```factor
{ 10 20 30 } unclip-last 2 * suffix .
! => { 10 20 60 }
```

## 在序列类型之间转换

`>array`、`>vector`和`>string`（在 [`arrays`][arrays] 及相应的词表中）会把一个序列强制转换成某种具体类型。当某个操作返回的是切片或泛型序列，而你需要拿回数组（或字符串）时，这就很有用。

```factor
{ 1 2 3 } 1 tail >array .   ! => { 2 3 }
"hello" >array .            ! => { 104 101 108 108 111 }
{ 65 66 67 } >string .      ! => "ABC"
```
