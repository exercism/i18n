# 说明补充

## 提示

你需要实现`rotate`函数，它接收一个`Int`和一个`String`，然后用旋转密码对它进行编码。
如果你不确定类型，可以使用给出的签名，但不要让它限制你的创造力。

本练习处理的是文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是一个字符列表。为了更高效地处理文本数据，可以使用`Text`类型。

作为本练习的一个可选扩展，你可以

- 阅读 Haskell 中关于[字符串类型](https://haskell-lang.org/tutorial/string-types)的内容。
- 在 package.yaml 的依赖列表中添加`- text`。
- 用[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 使用`Text`类型，例如`rotate :: Int -> Text -> Text`，并以`T.pack`这样的方式引用`Data.Text`中的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档。
- 把 RotationalCipher.hs 中所有出现的`String`替换为`Text`，即：

```haskell
rotate :: Int -> Text -> Text
```

这部分完全是可选的。
