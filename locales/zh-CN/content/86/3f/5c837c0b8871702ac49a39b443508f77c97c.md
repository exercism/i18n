# 简介

## 比较运算符

[比较运算符][comparison-operators]会比较两个相同类型的值，并返回一个`Bool`值（`true`或`false`）。
如果尝试比较不同类型的值，编译器会产生错误。

Swift 中标准的比较运算符有：

| 运算符 | 说明 | 示例 |
| -------- | ------------------------ | --------------- |
| `==`     | 等于 | `1 == 1`（true） |
| `!=`     | 不等于 | `1 != 2`（true） |
| `<`      | 小于 | `4 < 5`（true） |
| `<=`     | 小于或等于 | `4 <= 4`（true） |
| `>`      | 大于 | `3 > 1`（true） |
| `>=`     | 大于或等于 | `2 >= 2`（true） |

## `if`和`else`语句

[条件语句][conditional-statement]会根据条件的求值结果是`true`还是`false`来执行对应的代码。
最常见的条件语句是[`if`语句][if]，它只在条件为`true`时才运行代码块。
用`if`关键字编写`if`语句，后面跟上条件，以及用大括号括起来的代码块：

```swift
let wheelCount = 4
if wheelCount == 4 {
    print("Your vehicle is a car")
}
// Prints "Your vehicle is a car"
```

你可以把`if`和`else`子句搭配起来，在条件为`false`时运行另一段代码：

```swift
let precipitationInMM = 0.5
if precipitationInMM > 0.5 {
    print("You will need an umbrella")
} else {
    print("You will not need an umbrella")
}
// Prints "You will not need an umbrella"
```

要依次判断多个条件，可以用`else if`把多个语句串起来。
`if`语句不要求必须有`else`分支，但可以加上一个，用来处理所有条件都不匹配的情况：

```swift
let favoriteFruit = "Apple"

if favoriteFruit == "Banana" {
    print("Your favorite fruit is a banana")
} else if favoriteFruit == "Orange" {
    print("Your favorite fruit is an orange")
} else if favoriteFruit == "Apple" {
    print("Your favorite fruit is an apple")
} else {
    print("Your favorite fruit is not a banana, orange, or apple")
}
// Prints "Your favorite fruit is an apple"
```

## `if`表达式

在现代 Swift 中，`if`语句也可以作为表达式使用，产生一个值。
每个分支都会求出一个值，这让按条件赋值变得很简单：

```swift
let cpuBits = 32
let architecture = if cpuBits == 64 {
    "x86_64"
} else {
    "x86_32"
}

print(architecture)
// Prints "x86_32"
```

## 三元运算符

[三元条件运算符][ternary-operator]是`if-else`表达式的一种简洁写法。
它会对一个条件求值，并根据该条件是`true`还是`false`，返回两个值中的一个。

该运算符由三部分组成：`condition ? trueExpression : falseExpression`。
如果`condition`求值为`true`，就求出并返回`trueExpression`；否则求出并返回`falseExpression`。

三元运算符非常适合简单的单行选择：

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

上面的例子与下面这段代码等价，但更简洁：

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```
