# 说明

你在“为美而预约”练习里帮过忙的那家纽约美容院，如今经营得很不错，很多客户都成了常客。
常客们不再每次到店都单独预约，而是有固定的安排：“每隔一个星期二”“每月最后一个星期五”，等等。
店主想请你写一个辅助工具，算出这些安排对应的日期，以及美容院自己每月例行事务的日期。

## 1. 求出常客的固定预约日

实现 `SalonCalendar.standingAppointment()` 方法，它接收年份、月份、第几次出现（`1` 表示第一次，`2` 表示第二次，以此类推）和一个星期几。
该方法返回该月内这个星期几第几次出现的那一天：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. 求出常客的月末预约日

有些常客更喜欢当月自己那个星期几的最后一次。
实现 `SalonCalendar.lastAppointment()` 方法，它接收年份、月份和一个星期几，返回该月内这个星期几最后一次出现的那一天：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. 求出散客下一个可预约的日子

前台来了位客户，想要“下一个星期六”。
如果客户询问的当天就是星期六，那指的就是当天。
实现 `SalonCalendar.nextAvailable()` 方法，它接收一个日期和一个星期几，返回给定日期当天或之后第一个落在该星期几的日期：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. 求出结账日

美容院在每月最后一天结账。
不过美容院周末不营业，所以当月末最后一天是星期六或星期日时，就提前到之前的那个星期五结账。
实现 `SalonCalendar.bookkeepingDay()` 方法，它接收年份和月份，返回该月的结账日：

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. 把周末规则复用到发薪日上

员工的薪水在每月 15 号发放，同样适用周末规则：当 15 号是星期六或星期日时，发薪日提前到之前的那个星期五。
与其把这条规则再写一遍，不如把它做成一个可复用的调整器。

实现 `SalonCalendar.precedingWorkday()` 方法，它返回一个 `TemporalAdjuster`：工作日保持不变，星期六或星期日则往前移到前一个星期五。
然后实现 `SalonCalendar.payday()` 方法，它接收年份和月份，并使用这个调整器：

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

也欢迎你回头在 `bookkeepingDay()` 里用上这个调整器。
