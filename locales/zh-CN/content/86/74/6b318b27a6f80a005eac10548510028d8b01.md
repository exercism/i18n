# 说明

在这个练习中，你要为纽约一家于 2012 年 9 月 15 日开业的美容沙龙编写一套预约调度系统。

你需要完成 4 个任务，它们都与预约日期有关。日期和时间会使用下面三种格式之一：

- `"7/25/2019 13:45:00"`
- `"July 25, 2019 13:45:00"`
- `"Thursday, July 25, 2019 13:45:00"`

测试会自动把区域设置设为 `en-US`，你不需要自己设置或指定区域设置。

## 1. 解析预约日期

实现（_static_）`Appointment.Schedule()` 方法，把预约日期的文本表示解析为对应的 `DateTime` 格式：

```csharp
Appointment.Schedule("7/25/2019 13:45:00")
// => new DateTime(2019, 7, 25, 13, 45, 0)
```

## 2. 检查预约是否已经过去

实现（_static_）`Appointment.HasPassed()` 方法，它接收一个预约日期，并检查该预约是否在过去：

```csharp
Appointment.HasPassed(new DateTime(1999, 12, 31, 9, 0, 0))
// => true
```

## 3. 检查预约是否在下午

实现（_static_）`Appointment.IsAfternoonAppointment()` 方法，它接收一个预约日期，并检查该预约是否在下午（>= 12:00 且 < 18:00）：

```csharp
Appointment.IsAfternoonAppointment(new DateTime(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述预约的时间和日期

实现（_static_）`Appointment.Description()` 方法，它接收一个预约日期，并返回对该日期和时间的描述：

```csharp
Appointment.Description(new DateTime(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on 3/29/2019 3:00:00 PM."
```

## 5. 返回周年纪念日

实现（_static_）`Appointment.AnniversaryDate()` 方法，它返回今年的周年纪念日，也就是 9 月 15 日：

```csharp
Appointment.AnniversaryDate()
// => new DateTime(2019, 9, 15, 0, 0, 0)
```
