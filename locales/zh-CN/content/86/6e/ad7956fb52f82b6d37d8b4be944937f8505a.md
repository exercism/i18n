# 关于

在 Common Lisp 中，时间有三种表示方式

- 通用时间是一个绝对时间，它是一个整数，表示自`1900-01-01T00:00:00Z`（即 UTC 时间的 1900 年 1 月 1 日午夜）以来经过的秒数。
- 解码时间是由 9 个值组成的元组，这些值共同表示一个具体的日历时间：秒、分、时、日、月、年、星期、夏令时标志、时区。
（下面会详细讨论。）
- 内部时间是一个正整数，单位是由具体实现定义的“内部时间单位”，可用于测量运行时间。

## 通用时间

要获取当前的通用时间，可以使用`get-universal-time`或`get-decoded-time`。
前者返回自`1900-01-01T00:00Z`以来到当前时刻的秒数，后者则以解码格式返回同样的数据。

注意，由于这个数是一个正整数，因此无法编码 1900 年之前的日期。

## 解码时间

`decode-universal-time`和`encode-universal-time`是处理时间的主要函数。
前者接受一个通用时间，并以[多值][concept-multiple-values]的形式返回一个解码时间值；后者接受各个解码时间值作为实参，返回一个通用时间。

两者都接受一个可选的时区参数。
时区的格式见下文。

解码时间是一组值：

- *秒*：0 到 59 之间的整数
- *分*：0 到 59 之间的整数
- *时*：0 到 23 之间的整数
- *日*：1 到 31 之间的整数（显然，上限取决于月份和年份）
- *月*：1 到 12 之间的整数
- *年*：表示年份的整数。
- *星期*：0 到 6 之间的整数。0 表示星期一，1 表示星期二，依此类推……6 表示星期日。
- *夏令时标志*：值为 true 表示夏令时正在生效。
- *时区*：介于 -24 和 24 之间的小时数，表示与 UTC 的偏移量。
该数是有理数，必须是`1/3600`的整数倍

```lisp
(encode-universal-time 1 2 3 4 5 2000 0) ; => 3166398121
(decode-universal-time 3166398121 0)     ; => 1
                                         ;    2
                                         ;    3
                                         ;    4
                                         ;    5
                                         ;    2000
                                         ;    3 (Thursday)
                                         ;    NIL
                                         ;    0
(decode-universal-time 2208988800 0)     ; => 0
                                         ;    0
                                         ;    0
                                         ;    1
                                         ;    1
                                         ;    1970
                                         ;    3
                                         ;    NIL
                                         ;    0
```

注意，当不提供时区参数时，会有一些有趣的行为。
详情请查阅[`decode-universal-time`][hyperspec-decode-universal-time]和[`encode-universal-time`][hyperspec-encode-universal-time]的文档。

## 内部时间

内部时间是一个正整数，单位是“内部时间单位”。两个内部时间之差可用于在运行期测量时间。

- `get-internal-real-time`返回当前的“真实”时间，也就是“时钟”时间。
- `get-internal-run-time`很大程度上取决于具体实现，例如，它可能包含也可能不包含用于分页或垃圾回收的时间。

变量`internal-time-units-per-second`的值，是当前运行的 Lisp 环境中每秒包含的“内部时间单位”数。
