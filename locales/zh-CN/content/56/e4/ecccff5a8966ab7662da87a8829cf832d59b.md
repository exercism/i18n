# 简介

布尔表达式是针对一个或多个值提出的问题，答案可以是`true`或`false`。
结果为`true`的表达式返回`1`；结果为`false`的表达式返回`0`。
另外，数字也有真假之分。零是`false`，非零是`true`。

旧式 C 代码要么直接用`int`类型表示布尔值，要么由程序员定义`TRUE`和`FALSE`这样的常量，把`1`和`0`映射成布尔表示。

C99 版本引入了`_Bool`类型。
`stdbool.h`头文件定义了三个新的布尔符号：`bool`、`true`和`false`。
`true`映射为`1`，`false`映射为`0`，`bool`映射为`_Bool`。
所以现在，程序员不必直接使用`int`，也不必自己实现布尔映射，只要包含`stdbool.h`，就能在代码中自动获得布尔符号。

## 比较运算符

C 支持六种比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于或等于）、`<=`（小于或等于）。
这些运算符比较值之间的关系，并把结果归为布尔值。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 布尔运算符

C 支持三种布尔运算符：`||`（或）、`&&`（与）和`!`（非）。

`!`只接受一个操作数。
它会把操作数的布尔值取反。
例如，`0`是`false`，而`!0`是`true`。

`||`和`&&`需要两个操作数。
只有当左侧操作数无法确定整个表达式的结果时，才会对右侧操作数求值。
也就是说，只有当左侧操作数求值为`false`时，`||`才会对右侧操作数求值。
只有当左侧操作数求值为`true`时，`&&`才会对右侧操作数求值。
