# 关于

在 Haxe 中，异常是处理代码运行时出现的错误的一种安全方式。所有异常都应包含一条描述该错误的消息。我们可以使用`throw`关键字来_抛出_异常：

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

异常被抛出时，代码会去寻找一段负责处理该错误的代码。如果找不到，它就会显示错误消息，同时停止程序的运行。

要在 Haxe 中处理异常，我们使用`try-catch`代码块。这种语句由一个`try`块和一个或多个`catch`块组成。`try`块会_尝试_执行一段代码，而`catch`块则随时待命，一旦有异常被抛出就_捕获_它，这样执行就不会被中断。当`catch`块捕获到异常时，它还会执行该块内的所有内容：

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`块的实参类型应当省略。

需要注意的是，异常应当用在真正发生了异常情况的时候，也就是错误需要特殊处理的时候。不应把它用于程序的控制流，因为那被认为是糟糕的设计，往往会导致性能和可维护性变差。
