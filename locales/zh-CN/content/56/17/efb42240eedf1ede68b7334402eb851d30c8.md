# 说明

在本练习中，你将运用[围棋的规则](https://matmoore.github.io/learngo/)。规则本身已经写好，你只需要运用它们来更新 Game，并处理错误或违反规则的情况。

游戏用下面的方式表示：

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

游戏中有 4 条规则：

- 每个点只能有一颗棋子。
- 可以吃掉对方的棋子。
- 不能把棋子下在会把自己吃掉的位置。
- 同一个点不能使用两次。

## 1. 运用规则

编写`apply_rules`函数的内容：它接收一个初始的`Game`和一组规则，并在这组规则应用之后返回新的`Game`。

其中三条规则都会检查是否违反规则，可能返回错误，因此返回类型是`Result(Game, String)`。如果这些规则中的任何一条失败，就应该返回原来的游戏，但要把`error`字段更新为相应的错误。

另一条规则不检查是否违反规则，因此不会失败（不过它可以返回一个改动过的`Game`），所以返回类型是`Game`。

如果所有规则都通过，就保留规则对`Game`做出的所有改动，并且要更换玩家。

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
