# 关于

[列表][list]是 Haskell 中的一种基本数据类型，用于保存一组值。
列表是_不可变的_，也就是说无法被修改。
任何改变列表的操作都会返回一个新的列表。
Prelude 中有几个方法可以让你处理列表。

Haskell 中的列表是用[链表][linked-list-wiki]实现的，而不是用连续内存地址的数组。
因此，访问列表中的元素所需的时间与列表的长度成线性关系。

列表可以用字面量形式、头尾表示法（使用 `cons` 运算符 `:`）或两者的组合来书写：

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

头尾表示法可以用来向列表添加元素。

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

在迭代过程中向列表添加元素被认为是一种反模式。
添加一个元素需要遍历整个列表，并把元素加到末尾；因此，如果每次迭代都要添加一个新元素，那么每次迭代都需要遍历整个列表。

我们可以先把元素添加到反转后的列表的头部，然后再把结果反转回来，从而得到相同的结果。在头部添加元素是一个很快的操作，只需要常数时间。

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Prelude 中有几个常用的列表函数：

- [`head`][head]返回列表的_头部_，即列表中的_第一个_元素。
- [`tail`][tail]返回列表的_尾部_，即列表_去掉第一个元素_后的部分。
- [`length`][length]返回列表中元素的个数。
- [`elem`][elem]返回一个布尔值，表示该元素是否在列表中。

还有 [`Data.List`模块][list]。

## 列表的类型

在 Haskell 中，列表是**同质的**。
这表示列表中的所有元素都具有相同的类型。
如果你试图把不同类型的元素放进同一个列表，就会得到类型错误。

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

列表的类型标注是 `[a]`，其中 a 是列表所存放的类型，例如 `String` 或 `Int`。

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
