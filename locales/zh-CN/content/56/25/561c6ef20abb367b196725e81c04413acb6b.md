# 安装

想获得适合你所使用平台的推荐安装说明，请前往[官方 Rust 网站][the official Rust website]。

装好工具链并不代表万事俱备！IDE 支持能大幅提升生产力，大多数开发者早已对此习以为常。如果你使用 Visual Studio Code，可以看看它[关于 Rust 支持的文档][vscode]。我们也衷心建议你启用[用 clippy 做代码检查][vscode-linting]！

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
