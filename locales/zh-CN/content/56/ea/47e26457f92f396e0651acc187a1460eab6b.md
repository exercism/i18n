# 说明

你的朋友李梅经营着一家果汁吧，售卖各种美味的混合果汁。
你是她店里的常客，也意识到自己可以让朋友的工作轻松一些。
你决定用自己的编程技能来帮李梅分担工作。

## 1. 判断调制一杯果汁需要多长时间

李梅喜欢提前告诉顾客，他们点的菜单上的果汁需要等多久。
她很难记住具体的数字，因为调制不同果汁所需的时间各不相同。
`'Pure Strawberry Joy'`需要 0.5 分钟，`'Energizer'`和`'Green Garden'`各需要 1.5 分钟，`'Tropical Island'`需要 3 分钟，`'All or Nothing'`需要 5 分钟。
对于其他所有饮品（例如特价饮品），可以假设调制时间为 2.5 分钟。

为了帮助你的朋友，请编写一个函数`timeToMixJuice`，它接收菜单上的果汁作为实参，并返回调制这杯饮品所需的分钟数。

```javascript
timeToMixJuice('Tropical Island');
// => 3

timeToMixJuice('Berries & Lime');
// => 2.5
```

## 2. 补充青柠角

李梅的很多作品都会用到青柠角，有的作为配料，有的作为装饰。
所以每天早上开始上班时，她都要确保青柠角的料盒装满，够一整天使用。

实现函数`limesToCut`，它接收李梅需要切出的青柠角数量，以及一个表示她手头整颗青柠库存的数组。
一颗`'small'`青柠可以切出 6 个青柠角，一颗`'medium'`青柠可以切出 8 个，一颗`'large'`青柠可以切出 10 个。
她总是按照青柠在列表中的顺序来切，从第一项开始。
她会一直切下去，直到切够所需的青柠角数量，或者青柠用完为止。

李梅希望提前知道她需要切几颗青柠。
`limesToCut`函数应该返回需要切的青柠数量。

```javascript
limesToCut(25, ['small', 'small', 'large', 'medium', 'small']);
// => 4
```

## 3. 结束当班

李梅总是工作到下午 3 点。
然后由她的员工德米特里接替。
李梅下班时，常常还有一些已下单但还没调制的饮品。
这时德米特里会接着调制剩下的果汁。

为了让交接更顺利，请实现函数`remainingOrders`，它接收李梅当班剩余的分钟数，以及一个数组，里面是已下单但还没调制的果汁。
该函数应该返回李梅在下班前无法开始调制的订单。

当班剩余时间总是大于 0。
待调制的果汁数组永远不会为空。
此外，订单按照它们在数组中出现的顺序调制。
如果李梅开始调制某杯果汁，她一定会把它做完，即使要多加一会儿班。
如果没有剩下需要德米特里处理的订单，则应该返回一个空数组。

```javascript
remainingOrders(5, ['Energizer', 'All or Nothing', 'Green Garden']);
// => ['Green Garden']
```
