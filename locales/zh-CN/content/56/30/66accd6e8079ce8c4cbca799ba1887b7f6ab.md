# 说明补充

## `Print` 不会为字符串值加引号

这个练习涉及对数字分数的处理。
#[a: 1]` and `#[a: "1"]`并不相同：

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

常见的调试做法是用`print`打印值。
不过，输出不会在字符串两侧加上引号。
因此，像`"1"`这样的数字字符串打印出来，和整数`1`看起来一样。

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
在这个练习的测试输出中，你可能会看到类似`:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`的结果。
被比较的两个字典打印出来看起来一样。
但是，第一个字典的值是数字字符串，第二个字典的值是整数，所以它们并不相同。
调试时，可以用`inspect`查看字典的内容。

## `Express` 会为字符串值加引号

`express`会把值转换成 Arturo 代码，并返回表示该代码形式的字符串。
在这个结果中，任何字符串值都会带上引号。
因此，`express "1"`会返回`"1"`，而不是`1`。

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
