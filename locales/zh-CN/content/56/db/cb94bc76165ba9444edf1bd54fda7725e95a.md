# 说明

你的朋友刚给你发来一条带有重要秘密的消息。为了不让别人轻易读懂，这条消息经过了一系列位操作加密。你需要编写相应的函数来帮助解密这条消息。

## 1. 把位右移回去

解密消息的第一步，是还原加密过程中的移位，也就是把位向右移回去。解密过程的后续步骤会假定 `0` 是从左侧插入的。

实现 `shiftBack` 函数，它接受要移动的位数和一个值，并完成这次移位。

```elm
shiftBack 2 42 --> 10
```

## 2. 设置一些位

接下来，有一些位需要设置为 `1`。

实现 `setBits` 函数，它接受一个掩码和一个值，并返回把值中的某些位设置为 `1` 之后的结果。当掩码中的对应位也是 `1` 时，值中对应的位应设置为 `1`。其他所有位保持不变。

```elm
setBits 66 212 --> 64
```

## 3. 翻转特定的位

加密过程中有些位会被翻转。要解密消息，就需要把它们翻转回来。

实现 `flipBits` 函数，它接受一个掩码和一个值。掩码指明要翻转值中的哪些位。如果掩码中的某一位是 `1`，就翻转值中对应的位。其他所有位保持不变。

```elm
flipBits 23 157 --> 138
```

## 4. 清除特定的位

还有一些位解密后始终是 0。

实现 `clearBits` 函数，它接受一个掩码和一个值。当掩码中的某一位是 1 时，`value` 中对应的位应设置为 0。其他所有位保持不变。

```elm
clearBits 2 15 --> 13
```

## 5. 解密消息

现在你已经有了解密所需的全部函数，可以解码朋友发来的消息了。实现 `decrypt` 函数，它执行以下操作：

1. 用你朋友出生的那一年（1996）来设置位
2. 用你们初次见面的那一年（2009）来翻转结果
3. 按你们一起上课的门数（5）把位右移回去
4. 清除第一位和第五位。

```elm
decrypt 380182 --> 11840
```

请用你在前面各个任务中实现的所有函数来实现 `decrypt`。
