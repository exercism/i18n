# 内部链接

通过 Exercism 的 Markdown 解析器渲染的链接会被检查是否为内部链接；如果是，就可能附带提示框。

一个概念的提示框可能长这样：

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## 用法

这种链接装饰没有特殊的语法。我们只是检查链接的 href 是否属于以下两种形式之一：

- 一个 URL，例如 https://exercism.org/tracks/ruby/concepts/basics
- 一个绝对路径，例如 /tracks/ruby/concepts/basics

我们目前不支持相对 URL（例如以`./`或`../`开头的 URL），因为 Markdown 解析器并不知道它所渲染的文档的上下文、它渲染时所处的上下文，也不知道 git 代码仓库的结构。

## 替代方案

除了使用普通链接，你也不妨渲染 Widgets。它们通常用在文档末尾，用来推荐额外的阅读材料，或者推荐一些有助于学习的好练习。

更多细节请参阅 [Widgets 文档](/docs/building/markdown/widgets)。
