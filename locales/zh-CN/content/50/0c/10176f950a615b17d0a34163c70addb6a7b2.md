# 关于

和其他语言一样，C++ 也提供了 `switch` 语句。
switch 语句是编写冗长的 `if ... else if` 语句的一种更简短的写法。
要创建一个 switch，我们先使用关键字 `switch`，后面跟一个整数。
然后我们用 `case` 关键字声明每一个分支。
我们还可以声明一个 `default` 分支，当之前的所有 `case` 条件都不匹配时，它就会运行。
每个分支都应以 `break`（或 `return`）语句结束。

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## 穿透

关于 switch 结构，有一点很重要：代码会一直继续执行，直到被 `break`（或 `return`）语句停止。
这可能导致意外的行为。

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

这种连续执行特性的主要用途，是让一条语句带有多个标签。
多个 switch 结果可以映射到同一段要执行的代码。
这样一来，比如在一个预订应用中，团体人数为 2 和 3 时调用的函数就可以是同一个：
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
如你所见，与其他语言相比，C++ 的 switch 语句非常受限。
许多语言可以基于布尔表达式甚至正则表达式来编写分支。
你可以把 C++ 的版本看作是一种扩展的 goto/switch 结构。
只有 switch 语句可以跳转到标签。
之后其他所有标签都会被忽略，你必须使用 `break` 语句才能跳出代码块。
~~~~
