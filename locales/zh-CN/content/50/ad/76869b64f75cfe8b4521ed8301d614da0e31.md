# 简介

正如[`Nothingness`][concept-nothingness]概念中所介绍的，R 有多种方式表示缺失（`NULL`）、未知（`NA`）或数学上无效（`NaN`、`Inf`）的数据。
通常，R 会就地用这些值标记问题，并继续运行，而不会抛出异常。

## `stop()`

有些问题太过根本，不能让程序继续运行。
这种情况下，可以用 `stop(msg)` 立即中止程序，抛出一个 `Error` 并打印 `msg`。

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

它类似于其他语言中的 `assert`，是 `stop()` 的一个便捷封装。
它的形参是任意多个用逗号分隔的布尔条件，只有当它们全部为 `TRUE` 时，程序才会继续运行。

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `warning()`和`message()`

它们是对非致命条件的响应，例如：

- 警告程序至少还能部分恢复的问题。
- 在长时间运行的程序中向用户告知进度。

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

在 Exercism 中，`suppressWarnings()` 函数偶尔很有用，可以避免多余的输出干扰测试运行器。
