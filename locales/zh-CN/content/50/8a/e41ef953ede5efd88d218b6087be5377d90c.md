# 关于

Java 是一种静态类型语言，这意味着所有东西在编译时都有类型。把一个值赋给一个名字，称为定义变量。

```java
int explicitVar = 10; // Explicitly typed
```

使用[`=`运算符][assignment]可以给变量赋值，也可以更新变量的值。变量一旦定义，它的类型就永远不能改变。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java 是一种面向对象的语言，它要求所有函数都定义在*类*中，而类使用[`class`关键字][classes]来定义。类中的函数称为*方法*。每个[方法][methods]可以有零个或多个形参。所有形参都必须显式指定类型，形参没有类型推断。同样，返回类型也必须显式指定。函数使用[`return`关键字][return]返回值。要让方法能被其他类调用，必须加上`public`访问修饰符。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

调用方法时，需要指定它所在的类和方法名，并为方法的每个形参传入实参。

```java
int sum = new Calculator().add(1, 2);
```

如果一个方法不使用任何类的*状态*（本练习就是这种情况），就可以用`static`修饰符把方法变成*静态*的。同样，如果一个类只有静态方法，它也可以用`static`修饰符变成静态的。

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

Java 中的作用域由`{`和`}`两个字符界定。

Java 支持两种[注释][comments]。单行注释以`//`开头，多行注释写在`/*`和`*/`之间。

整数由一个或多个（连续的）数字组成，并支持[默认的数学运算符][operators]。
