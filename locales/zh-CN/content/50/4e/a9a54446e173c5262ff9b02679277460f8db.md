# 说明

在这个练习中，你要和最好的朋友们一起玩一款名为“Wizard and Warriors”的角色扮演游戏。你是游戏主持人，负责让游戏世界在玩家眼前活起来。其中很关键的一点，就是向玩家描述游戏内容：角色的状态如何、他们正在造访的城镇长什么样，等等。

你有五个任务，需要向玩家描述游戏的不同部分。

## 1. 描述一个角色

每个角色都有职业、等级和生命值，其描述格式为：`"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`。实现（静态）`GameMaster.Describe` 方法，它接受一个 `Character` 作为唯一参数，并返回对应的描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. 描述一个目的地

每个目的地都有名称和居民数量，其描述格式为：`"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`。实现（静态）`GameMaster.Describe` 方法，它接受一个 `Destination` 作为唯一参数，并返回对应的描述。

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. 描述出行方式

角色可以使用以下两种方式之一前往目的地：

- 步行，描述为：`"You're traveling to your destination by walking."`
- 骑马，描述为：`"You're traveling to your destination on horseback."`

实现（静态）`GameMaster.Describe` 方法，它接受一个 `TravelMethod` 作为唯一参数，并返回对应的描述。

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. 描述一个角色前往目的地的情形

当角色前往某个目的地时，描述由各个单独的描述组合而成：`"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`。实现（静态）`GameMaster.Describe` 方法，它接受一个 `Character`、一个 `Destination` 和一个 `TravelMethod` 作为参数，并返回对应的描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. 在不指定出行方式的情况下描述角色前往目的地的情形

大多数情况下，角色都是步行前往目的地的。为了方便，玩家可以省略出行方式，此时会默认出行方式是步行。实现（静态）`GameMaster.Describe` 方法，它接受一个 `Character` 和一个 `Destination` 作为参数，并返回对应的描述。

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
