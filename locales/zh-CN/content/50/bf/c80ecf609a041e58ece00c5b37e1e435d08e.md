# 关于

使用关键字`final`（而不是`var`）声明的变量只能被赋值一次。

```haxe
final a = "hello";
var b = "world";
trace(a, b); // hello, world
b = "haxe";
trace(a, b); // hello, haxe

// The following line would cause a compilation error:
// a = "bye";
```

需要注意的是，对于数组或对象这类并非不可变的类型，`final`可能不会产生预期的效果：

```haxe
final a = [0, 1, 2];
trace(a); // [0,1,2]

// this would cause a compilation error:
// a = [0, 1, 2, 3];

// but the following line works:
a.push(3);
trace(a); // [0,1,2,3]
```
