# 关于

局部变量并不会取代栈代码，而是与它并存。在以下情况可以考虑使用局部变量：

- 同一个输入被引用多次。
- 操作的自然顺序与栈的顺序不一致。
- 你身处一个高阶词内部，它一次性把多个值交给匿名函数（`assoc-map`的`( key value -- newkey newvalue )`）。

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]`可以在代码块内部或监听器处引入局部绑定，否则`:>`就没有词法作用域可供绑定：

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

`:>`这个可变后缀让你可以重新绑定局部变量，在带有命令式风格的循环中很有用：

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
