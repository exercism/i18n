# 关于

“Racket（原名 PLT Scheme）是 Lisp/Scheme 家族中的一门通用多范式编程语言。其设计目标之一是成为语言创建、设计与实现的平台。这门语言被用于脚本编写、通用编程、计算机科学教育和研究等多种场景。”（[维基百科][wikipedia racket page]）

你可以通过几本不同的书学习 Racket 的基础知识。先从[*How to Design Programs*][htdp]入手，用没那么正式但很好玩的[*Realm of Racket*][realm]做几款自己的游戏，或者借助[*Racket Programming the Fun Way*][the fun way]探索 Racket 各式各样的库。

去看看[官方网站][racket homepage]和 [Github 代码仓库][racket github]。你可以在[Twitter][racket twitter]、[邮件列表][racket listserv]、[Discord][racket discord]和[Slack][racket slack]上找到这个社区。
