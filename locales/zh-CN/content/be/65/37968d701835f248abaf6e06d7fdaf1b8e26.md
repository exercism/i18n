# 简介

在 Haxe 中，抽象类型是一种在运行时表现为另一种类型的类型。它是一种编译期特性，可以在具体类型“之上”定义类型，从而修改或增强它们的行为：

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

这里我们使用`abstract`关键字声明了`AbstractInt`类型。它的语法与`class`非常相似。和类一样，抽象类型也可以有方法。它们也可以像类一样被实例化和使用：

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```
