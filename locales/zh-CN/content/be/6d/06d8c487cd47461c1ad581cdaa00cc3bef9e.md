# https://www.php.net/manual/en/language.basic-syntax.phptags.php"作用域解析运算符

作用域解析运算符（`::`）让我们可以引用某个类，以访问它的名称常量、静态属性或静态方法。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 结合作用域解析运算符使用`self`和`static`

有时对象需要引用自身所在的作用域。为此，`self`关键字可以让类引用它自己的作用域。使用`self`关键字能让类与它自己的名字解耦，从而让代码在长期维护中更轻松。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

不过，`self`是按词法绑定到它所在的那个类的。

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

求值`MyOtherClass::getMyValue`得到的仍然是`1`，而不是`99`。要解决这个问题，可以把`static`关键字与作用域解析运算符一起使用，将引用“延迟绑定”到当前的后代类上。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 结合作用域解析运算符使用`parent`

有时需要专门引用父作用域中可用的常量、属性或方法：

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

在面向对象编程中，最常见的是在实例化对象时用`parent`调用父类的构造函数：

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意事项

### 常量、属性和方法的可见性

作用域解析运算符仍然遵循`public`、`private`和`protected`这些可见性修饰符所设定的规则。
