# 关于

`List`和[`Array`][array]非常相似。但是，两者之间还有一些不容忽视的重大区别：

1. 不能用方括号来索引列表，例如`[0]`。
2. 列表无法初始化。
3. 没有列表推导式。
4. 列表在迭代过程中可以自由修改其中的元素。

`List`是`haxe.ds`包中的一员，因此每次想使用列表时，都需要导入它所在的包：

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
