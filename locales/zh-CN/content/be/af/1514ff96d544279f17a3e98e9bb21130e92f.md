# 简介

还记得高中时第一次学代数的情形吗？

通常，我们会拿到一个方程组，要求解出 `x` 和 `y`。

```
4x - 3y = -2
2x + 7y = 16
```

两个方程，两个未知数：代入消元一下，很快就能看出 `x = 1, y = 2`。

再仔细看看上一个例子的左边。
它看起来像一个矩阵 `[4 -3; 2 7]` 乘以未知向量 `[x, y]`，得到向量 `[-2, 16]`。

用线性代数记号写出来就是 **A** **x** = **b**，遵循矩阵用大写字母、向量用小写字母的通常约定。

## **A x = 0**与零空间

一个重要的特殊情况是，所有方程等号右边都是零。

```
4x - 3y = 0
2x + 7y = 0
```

在上面的例子里，唯一的解是 `x = y = 0`，这通常没什么意思。

只有当**A**的行列式为零时，**A x = 0**才存在非平凡解。

```julia-repl
julia> using LinearAlgebra

julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> det(A)  # not zero!
34.0
```

换一组方程看看：

```
4x - 3y = 0
8x + 6y = 0
```

第二个方程恰好是第一个方程的两倍，没有带来任何新信息。
只要满足 `x = 0.75y` 的取值都是解。

这些 `(x, y)` 值落在二维空间中的一条直线上。
解有无穷多个，它们构成了这个矩阵的零空间。

这种情况下矩阵的各行不是线性无关的，矩阵的秩小于行数或列数。

```julia-repl
julia> A = [4 -3; 8 -6]
2×2 Matrix{Int64}:
 4  -3
 8  -6

julia> det(A)
0.0

julia> size(A)  # total number of rows and columns
(2, 2)

julia> rank(A)  # number of linearly-independent rows (or columns)
1

julia> nullspace(A)
2×1 Matrix{Float64}:
 -0.6
 -0.8

julia> nullspace(A) |> norm  # Julia returns unit vectors when possible
1.0
```

`nullspace()`函数返回一个点，它被归一化为单位向量，但这个向量的任意标量倍数也都在零空间中。

## 求解**A x = b**

现在假设你有 1000 个方程、1000 个未知数，会怎样？
如果这听起来很荒唐，别忘了现在无线数字传感器既便宜又全能（可以测量应变、风速、三轴加速度，等等……）。
用 1000 个传感器监测悬索桥这样的现代结构，完全合情合理。
还需要一套控制系统来解读数据流，一旦情况不妙就发出警报。

同样是**A** **x** = **b**，其中**A**（来自工程设计）和**b**（传感器测得的数值）都是已知的，需要求出**x**。

对不熟悉的人来说，第一个念头大概是想办法“两边同除以**A**”，把它移到右边。

事实上，**A**确实有逆矩阵（大多数方阵都有，但并非全部：行列式必须非零），这样算也能算出来（只是_很慢_！）。

```julia-repl
julia> A = [4 -3; 2 7]
2×2 Matrix{Int64}:
 4  -3
 2   7

julia> b = [-2, 16]
2-element Vector{Int64}:
 -2
 16

# the inverse matrix
julia> inv(A)
2×2 Matrix{Float64}:
  0.205882   0.0882353
 -0.0588235  0.117647

julia> inv(A) * b
2-element Vector{Float64}:
 0.9999999999999999
 2.0
```

可惜的是，求逆矩阵对小矩阵就很慢，对大矩阵更是慢如冰川。
如果你的桥在计算过程中塌了，这可不妙！

所幸还有快得多的算法（这里用的是高斯消元法）。

Julia（跟 Matlab 一样）用反斜杠来做求解器（严格说是“左除”）。

```julia-repl
julia> x = A \ b
2-element Vector{Float64}:
 1.0
 2.0
```

这只是一个简单的例子，但有几个细节需要注意。

- 系数需要按列对齐，缺项的地方要补上零。
- 方程（也就是矩阵的行）需要线性无关。如果第 3 行恰好是第 1 行和第 2 行之和，它就没有带来新信息，问题就是欠定的。

`rank()`命令可以给出线性无关的行/列数，最好让它等于未知数的个数。

```julia-repl
julia> rank(A)
2
```

### 长方形矩阵

大概在你还是个十来岁的孩子时，老师就告诉过你：求解 `N` 个未知数需要 `N` 个方程组成的方程组。

和数学里的大多数事情一样，现实要微妙一些（不只是上一节提到的线性无关那点细节）。

#### 行数“太少”

只有 `N-1` 个方程（矩阵 `A` 有 `N-1` 行）时，问题是欠定的。
我们就要绝望地放弃吗？

这得看情况！

这 `N-1` 个方程仍然包含大量信息。
从几何上说，要确定解是 N 维空间中的一个_点_，需要 `N` 个方程；但 `pseudoinverse` 个方程会告诉我们，解必定落在某条_直线_上。

这样一来，解有无穷多个，但参数空间里也有无穷多的地方_没有_解。

你的解直线是否会穿过参数空间中某个让正派工程师应该担心的区域？
或者某个足以成为封闭结构、禁止公众通行的理由的区域（_悬索桥在强侧风下可是会晃动起来的_）？
也许值得再做些计算来弄清楚这一点！

```julia-repl
julia> A3 = [4 -3 1; 2 2 2; 3 -4 -3]
3×3 Matrix{Int64}:
 4  -3   1
 2   2   2
 3  -4  -3

julia> b3 = [1, 12, -14]
3-element Vector{Int64}:
   1
  12
 -14

# fully-determined solution
julia> A3 \ b3
3-element Vector{Float64}:
 1.0
 2.0
 3.0

# remove row 3 from A3 and B3
julia> A2 = A3[1:2, :]
2×3 Matrix{Int64}:
 4  -3  1
 2   2  2

julia> b2 = b3[1:2]
2-element Vector{Int64}:
  1
 12

# an under-determined solution
julia> z1 = A2 \ b2
3-element Vector{Float64}:
 1.594594594594594
 2.445945945945947
 1.9594594594594592
```

反斜杠求解器给了我们一个解！
据非官方说法，这似乎就是范数最小的解（从几何上看，就是离原点最近的那个）。

要得到其他解，我们需要 `A2` 的 `nullspace`。

把零空间的任意标量倍数加到原来的解上，都会得到另一个有效的解。

```julia-repl
# get the nummspace of A2
julia> N = nullspace(A2)
3×1 Matrix{Float64}:
 -0.46499055497527725
 -0.3487429162314578
  0.813733471206735

# add a random multiple of the nullspace to the earlier solution
julia> z = z1 + rand() * N
3×1 Matrix{Float64}:
 1.274331860650258
 2.205748895487695
 2.5199192438620472

# our random z is a valid solution, recovering b2 = [1, 12]
julia> A2 * z
2×1 Matrix{Float64}:
  0.9999999999999947
 12.0
```

同样，`N-2` 个方程会把（无穷多的）解限制在一个平面上，同样的原则依然适用。

#### 行数“太多”

相反的情况是方程数_多于_未知数，但它们依然是线性无关的。

_在现实工程中，这完全正常，而且被视为一件好事！_

传感器精度有限，**b**向量的精度也有限，计算过程中还有噪声。
这时，解就是对含噪数据的最小二乘拟合。

最简单的做法是使用矩阵的伪逆，Julia 把它实现为 `pinv()` 函数。

它的用法很像（非奇异）方阵的逆矩阵，给出的是变量的最小二乘估计，而不是精确解。

```julia-repl
# create 5-row A and b for 2 variables
julia> A5 = [4 -3; 2 7; -1 2; 1 -1; 3 1]
5×2 Matrix{Int64}:
  4  -3
  2   7
 -1   2
  1  -1
  3   1

julia> rank(A5)
2

# add some random-normal noise to b5
julia> b5n = [-2, 16, 3, -1, 5] + randn(5) * 0.1
5-element Vector{Float64}:
 -1.9337349223581917
 16.024913008059457
  3.0087646177373992
 -0.8675748721176717
  4.914568047308805

# solve to get x ≈ 1, y ≈ 2, using the pseudoinverse
julia> pinv(A5) * b5n
2-element Vector{Float64}:
 1.006117942769543
 1.9962973764508272
```

## 特征值与特征向量

上一节讲的是**A** **x** = **b** 的解，这等价于我们熟悉的代数。

本节要讲的是**A** **x** = λ**x** 的解，其中 λ 是一个标量。

这是线性代数里相当独特的概念，但我们可以从几何上理解它：

_对于合适的**x**和 λ，方阵**A**会把非零向量**x**的长度缩放 λ 倍，而不改变它的方向（除非 λ 为负，那就会反向）_。

这听起来很小众，但实际上用处_大得离谱_！

***术语：*** 有效的 λ 值就是**A**的_特征值_，对应的**x**值就是**A**的_特征向量_。
_可惜的是，我们只能忍受这些中途换语言的词。_

学生通常要学手工计算 2×2 矩阵的特征值/特征向量，但用计算机要容易得多（不过仍然相当慢，一般情况下，`n×n` 矩阵的复杂度按`O(n^3)`增长）。

```julia-repl
julia> A = rand(-9:9, 2, 2)
2×2 Matrix{Int64}:
 9  5
 3  2

julia> F = eigen(A)
Eigen{Float64, Float64, Matrix{Float64}, Vector{Float64}}
values:
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274
vectors:
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317

# eigenvalues
julia> F.values
2-element Vector{Float64}:
  0.27984674554472466
 10.720153254455274

# each column is an eigenvector, normalized to a unit vector
julia> F.vectors
2×2 Matrix{Float64}:
 -0.497417  0.945605
  0.867511  0.325317
```

一般来说，`n×n` 矩阵有 `n` 个特征值，不过它们的值不总是_互不相同_。
可以把它们看作一个 `n` 次多项式的根（称为特征多项式），这些根可能重复，而且即使矩阵是实值的，它们也常常是复数。

每个特征向量代表一个方向，它的任意标量倍数也是合法的特征向量。
为了方便后续计算，Julia 返回的是范数为 1 的单位向量。

### 应用

要解释清楚特征向量为什么重要，最好写一本 500 页的教科书，而不是靠几段短文。
这个主题渗透在_太多_现代应用数学的领域里。

从宏观上说，特征向量代表数据集中“最重要”的轴（方向）。
特征值则表示每个轴的“相对重要性”（_前提是对输入做了一些归一化的假设_）。

这实际上_意味着_什么，取决于具体应用。

#### 主成分分析

在典型的数据科学问题中，我们可能有 100 个甚至更多的“特征”，以数据列的形式存储。
几乎不可避免地会有噪声、冗余和多余的关联。

我们需要降维，而 PCA 就是给这团混乱带来秩序的一种方法：

- 计算数据的协方差矩阵。
- 现在我们有了一个方阵，接着计算特征值和特征向量。
- 按特征值从大到小排列特征向量（更准确地说，是按绝对值 `|λ|` 排序）。
- 排在最前的 `k` 个特征向量就是你的`principal components`，其中 `k` 明显小于原来特征的数量。
- 把整个数据集投影到这 `k` 个轴上，然后开始寻找有意思的模式。

以这种形式，PCA 被各种各样的群体使用过：既有想在药物设计中改进分子性质的医学科学家，也有想从民调数据中了解选民偏好的政治竞选团队。
大概还有想向你推销东西的营销团队，不过任何技术都既能行善也能作恶。

PCA 并不包含在 Julia 的最小安装里，但在 Exercism 之外，MultivariateStats 包里有你需要的东西。

#### 图像处理

把 PCA 的思路再推进一步，数字图像其实就是像素值构成的矩阵，我们也可以为它计算主成分。

几十年来，它一直被用于图像压缩：在缩小文件体积时，PCA 能指导我们哪些内容最值得保留。

在面部识别等图像分类器中，PCA 正日益成为关键的一环。
下次你走过机场时，老大哥不只是在盯着你，他还会用线性代数来理解他看到的东西！

#### 机械工程

换个没什么争议的例子：机械部件的惯性主轴，就是它的转动惯量张量 ***I*** 的特征向量（所谓的张量，不过是换了个名字的矩阵）。

你车上的每个轮子大概都装有一块或几块平衡配重，用来把张量 ***I*** 中的非对角元素调到零。
修车师傅肯定懒得去算这些数学（飞机设计师和火箭工程师就不同了），但“抖动”不过是描述张量中交叉项的一个日常说法，而这些交叉项会让你的旅程更颠簸，还会加剧轴承的机械磨损。
