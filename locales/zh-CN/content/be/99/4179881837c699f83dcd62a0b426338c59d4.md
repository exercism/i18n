# 安装

只需下载 Scarb 即可安装 Cairo。Scarb 把 Cairo 编译器和 Cairo 语言服务器打包成一个易于安装的整体，让你可以立刻开始编写 Cairo 代码。Scarb 同时也是 Cairo 的包管理器。

想获取适合你所在平台的推荐安装说明，请访问 [Cairo 官方网站](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/)。

按操作系统分类：

- Linux/MacOS
    1. 安装 [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. 安装 [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. 在新终端会话中运行`scarb --version`验证安装
- Windows
    1. 安装 [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. 在新终端会话中运行`scarb --version`验证安装

光装好工具链还不够！IDE 支持能大幅提升效率，大多数开发者早已对它习以为常。
如果你使用 Visual Studio Code，我们建议你安装 [Cairo 扩展](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1)，它提供语法高亮、代码补全以及其他实用功能！
