# 简介

在 Go 中，`for range`会针对范围表达式中的值重复执行一段代码。
范围表达式决定每次迭代产生一个值还是两个值。

## 范围表达式

### 遍历切片

对切片使用 `range` 会按顺序产生每个元素的下标和值：

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(i, v)
}
// 0 10
// 1 20
// 2 30
```

### 遍历映射

对映射使用 `range` 会产生每个键和值，但迭代顺序没有保证。
Go 故意打乱映射的迭代顺序，因此同一个程序每次运行都可能产生不同的输出。

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
    fmt.Println(k, v)
}
// 99 20
// 999 30
// 9 10
```

### 遍历字符串

对字符串使用 `range` 会产生字节下标和每个 rune（Unicode 码点）。
在下面的例子中，`子`占三个字节，所以`猫`从字节下标`3`开始，而不是`1`。

```go
for i, r := range "子猫" {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 3 29483 猫
```

如果你需要的是 rune 下标，就把字符串转换成 rune 切片：

```go
for i, r := range []rune("子猫") {
    fmt.Println(i, r, string(r))
}
// 0 23376 子
// 1 29483 猫
```

### 遍历整数

`range`可以直接对整数进行迭代，产生的值从`0`开始，一直到该整数为止，但不包含这个整数。
零和负数也是合法的，但不会产生任何迭代。

```go
for n := range 3 {
    fmt.Println(n)
}
// 0
// 1
// 2
```

### 遍历迭代器

`range`接受 `iter.Seq[V]` 或 `iter.Seq2[K, V]` 类型的迭代器。
迭代器是一种函数，它会一次一个地产生一系列值。
然后`range`可以逐个遍历这些值。

```go
text := "The quick brown fox"
for word := range strings.FieldsSeq(text) {
    fmt.Println(word)
}
// The
// quick
// brown
// fox

names := []string{"Alice", "Bob", "Vera"}
for i, v := range slices.All(names) {
    fmt.Println(i, ":", v)
}
// 0 : Alice
// 1 : Bob
// 2 : Vera
```

### 遍历通道

最后，`range`可以接收通过通道发送的值，直到该通道在其他地方被关闭。
通道会在本课程后面的教学大纲中更深入地讲解。

## 省略下标或值

如果声明了变量却从未使用，Go 将无法编译。

```go
vals := []int{10, 20, 30}
for i, v := range vals {
    fmt.Println(v)
}
// Go build failed: declared and not used: i
```

如果只需要值，就把下标或键赋给 `_` 以忽略它。

```go
vals := []int{10, 20, 30}
for _, v := range vals {
    fmt.Println(v)
}
// 10
// 20
// 30
```

如果只需要下标，就把值完全省略：

```go
vals := []int{10, 20, 30}
for i := range vals {
    fmt.Println(i)
}
// 0
// 1
// 2
```

如果下标和值都不需要，两者都可以省略：

```go
vals := []int{10, 20, 30}
count := 0
for range vals {
    count++
}
// count == 3
```
