# 简介

## JavaScript 中的正则表达式

[正则表达式][mdn-regular-expressions]（或 Regex）是由字符组成的序列，我们可以用它来定位和操作字符串中的特定元素。因此，我们可以：

- 在字符串中**搜索**文本
- **替换**字符串中的子串
- 从字符串中**提取**信息

> 💡 JavaScript 的正则表达式风格是该语言 ECMA-262 标准的一部分。这意味着你不必担心浏览器之间的兼容性问题。

## 如何创建正则表达式

在 JavaScript 中，正则表达式通常写成`/pattern/modifiers`的形式。

我们有两种创建正则表达式的方式：

1. **正则表达式字面量**：

```javascript
const regex = /[a-z]/;
```

2. 构造函数**RegExp**：

```javascript
const regex = new RegExp('[a-z]');
```

两种方式都会让 JavaScript 用正则表达式创建一个对象。建议默认使用字面量这种不可变的写法。

如果正则表达式会发生变化，或者我们还不确定它是什么（比如来自用户的输入），就可以使用 RegExp 构造函数。

## 🏴‍☠️ 标志

正则表达式拥有一些可选的超能力，叫做 [`flags`][mdn-flags]，可以启用更多功能。

其中一些常用的标志是：

- `/g` - 全局搜索
- `/i` - 不区分大小写
- `/m` - 多行搜索

下面是一个简单的例子：

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

// => ["Home", "home"]
```

`g`字符让我们能够解析字符串中所有可能的匹配。如果没有这个功能，JavaScript 只会提取第一个`Home`匹配。

不区分大小写标志`/i`让我们在查找模式时更加灵活。这样一来，无论要找的内容是`UPPERCASE`还是`lowercase`都没关系。

使用`RegExp`构造函数时，添加标志的语法有所不同。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## 最常用的函数

当正则表达式与 JavaScript 内置的函数结合使用时，我们就能用一些强大的方式操作字符串并从中获取数据。

以下是常与正则表达式搭配使用的一些函数。

### 测试

[test()][mdn-regex-test]] 方法会在正则表达式和指定字符串之间执行一次匹配搜索。返回 true 或 false。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### 匹配

使用 [match()][mdn-regex-match] 方法，我们可以得到一个有用的数组，其内容取决于是否找到了匹配项。

这样，我们既能**搜索**，也能从任意字符串中**提取**信息。例如：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 3, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

当存在全局搜索标志`/g`时，该方法不会再只返回唯一的匹配项及其下标、输入等有用信息，而是返回数组中列出的所有匹配项：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### 替换

JavaScript 的 [replace()][mdn-regex-replace] 方法让我们可以在给定字符串中搜索某个值，并把它替换成想要的新值。

```javascript
string.replace(searchValue, newValue);
```

用于搜索和替换的模式可以是一个字符串，也可以是一个正则表达式。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

此外，我们还可以在替换位置传入一个函数，对每个值做额外的处理。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});

// => "Say HELLO to the CHATBOT"
```

### 分割

JavaScript 的 [split()][mdn-regex-split] 方法展示了用正则表达式使用和操作字符串的另一种方式。

这样，我们就可以通过识别某个模式来分割给定字符串，例如`str.split(/[,.\s]/)`。这个模式会被用作`separator`。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
