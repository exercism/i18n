# 介绍

## 自定义类型

Elm 中的[自定义类型][custom-types]表示一组固定数量的具名情况。每个值都恰好对应其中一种具名情况。

自定义类型使用`type`关键字定义，需要的语法非常少。它是 Elm 编程中最重要的技术之一，用来让代码中可能出现的值与现实世界中合法的值完全吻合，从而不给无效数据留下任何空间，也让[不可能的状态无法在代码中表示][impossible-states]。

```elm
type Season
    = Spring
    | Summer
    | Autumn
    | Winter
```

自定义类型的每个情况都可以关联数据，也可以不关联；不同的情况可以关联不同类型的数据。如果所有情况都没有关联数据，这种可辨识联合就类似于其他语言通常所说的_枚举_（或 _enum_）。

```elm
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

为特定的情况创建值，可以直接引用它的名字（`Spring`），前提是该类型定义在同一个模块中，或者已通过`import SeasonModule exposing (Season(..))`这种语法导入；也可以通过它的完全限定名（`Season.Spring`）来引用，前提是已通过`import SeasonModule exposing (Season)`这种语法导入。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

自定义类型和 Elm 中的其他一切一样，都具有_结构相等性_，也就是说，同一个情况、且（可选的）数据也相同的两个值是等价的。

处理自定义类型的首选方式是[模式匹配][pattern-matching]：

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
