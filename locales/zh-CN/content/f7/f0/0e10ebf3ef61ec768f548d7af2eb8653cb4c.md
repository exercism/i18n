# 关于

[Elixir](https://elixir-lang.org/) 于 2012 年首次发布，它扩展了 Erlang 本就强大的特性，同时对初学者来说也更易上手、易读、易测试、易编写。

Elixir 的创造者 José Valim 在[他 2012 年的会议演讲](https://vimeo.com/53221562)中解释了他是如何构建这门语言的，目的是让应用程序具备以下特性：

  1. 分布式
  2. 容错
  3. 软实时
  4. 热代码替换（可以在不停止服务器的情况下引入新代码）

Elixir 实际上会先编译成[字节码](https://en.wikipedia.org/wiki/Bytecode)，再在 [BEAM Erlang 虚拟机](https://codesync.global/media/robert-virding-co-creator-of-erlang-explains-the-beam/) 上运行。

调用 Erlang 没有“转换成本”，也就是说你可以把 Erlang 代码直接和 Elixir 代码放在一起运行。

作为一门函数式语言，Elixir 中的一切都是表达式。

Elixir 拥有“一等文档”，这意味着可以把注释附加到函数上，让它们更容易被找到。

正则表达式也被当作一等公民对待，从而免去了字符串里繁琐的转义。

Elixir 的异步通信实现让代码既轻量，又能承载大规模的并发。

程序员使用 Elixir 在单个服务器节点上*并发*处理成千上万的请求和响应。

它已被成功用于需要快速消费和提供大量 API 的微服务。

[Phoenix 框架](https://www.phoenixframework.org/)有助于构建面向 Web 的 Elixir 应用结构。
