# 说明

你正在经营一家线上时装精品店。库存里的每一件商品都是一个包含 2 个元素的数组`{ name price }`，而整个库存就是由这些商品组成的数组。

没有价格的商品，价格记为`f`。

## 1. 按价格给库存排序

定义`sort-by-price`，返回一个新数组，其中的商品按价格升序排列。

```factor
{ { "Maxi Brown Dress" 65 } { "Red Skirt" 50 } { "Bamboo Socks Cats" 20 } }
sort-by-price .
! => { { "Bamboo Socks Cats" 20 } { "Red Skirt" 50 } { "Maxi Brown Dress" 65 } }
```

## 2. 找出没有设置价格的商品

定义`with-missing-price`，返回一个数组，其中只包含价格为`f`的商品。

```factor
{ { "Black T-shirt" 40 } { "Denim Pants" f } { "Orange T-shirt" 40 } }
with-missing-price .
! => { { "Denim Pants" f } }
```

## 3. 统计昂贵的商品

定义`expensive-items`，它接收一个库存和一个价格阈值，返回价格严格高于该阈值的商品有多少件。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
50 expensive-items .
! => 2

{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } { "Dress" 80 } }
0 expensive-items .
! => 4
```

## 4. 找出最便宜的商品

定义`cheapest-item`，返回价格最低的商品。没有价格（`f`）的商品不会出现在输入中。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } cheapest-item .
! => { "Hat" 25 }
```

## 5. 汇总所有价格

定义`total-price`，返回所有价格的总和。没有价格（`f`）的商品不会出现在输入中。

```factor
{ { "Skirt" 50 } { "Coat" 120 } { "Hat" 25 } } total-price .
! => 195
```

## 6. 把商品格式化为价格标签

定义`format-price-tag`，对一件商品返回形如`"name: $price"`的字符串。没有价格（`f`）的商品不会出现在这里。

```factor
{ "Skirt" 50 } format-price-tag .
! => "Skirt: $50"
```
