# 说明

你是一名助教，正在批改学生的考试试卷。
手动记录成绩既枯燥又容易出错。
你决定让这件事变得有点意思：编写几个函数，来统计和计算全班的成绩。

## 1. 分数取整

考试题目可以给“部分分数”，但总成绩必须是`int`。
所以在对全班成绩做任何处理之前，你需要先遍历这些分数，把所有`float`分数转成`int`。幸运的是，Python 内置的`round()`[round]函数正好可以用。

创建函数 `round_scores(student_scores)`，它接收一个包含 `student_scores` 的 `list`。
这个函数应该_消耗_输入的 `list`，并 `return` 一个新的数组，其中所有分数都转换成了`int`。
得到的`list`中，分数的顺序并不重要。

```python
>>> student_scores = [90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3]
>>> round_scores(student_scores)
...
[40, 39, 95, 80, 25, 31, 70, 55, 40, 90]
```

## 2. 不及格的学生

批改试卷时，你注意到有些学生的表现没有你期望的那么好。
但你当时分了心，忘了准确记下到底有_多少_名学生不及格。

创建函数 `count_failed_students(student_scores)`，它接收一个包含 `student_scores` 的 `list`。
这个函数应该统计出没有及格的学生人数，并以整数返回这个数字。
学生需要考到高于**40**的分数，才能在这门考试中及格。

```python
>>> count_failed_students(student_scores=[90,40,55,70,30,25,80,95,38,40])
5
```

## 3. “最好”的成绩

你协助的老师想找出在这门考试中表现“最好”的那群学生。
“最好”的标准会波动，所以你需要找出**大于或等于**当前阈值的那些学生分数。

创建函数 `above_threshold(student_scores, threshold)`，以 `student_scores`（一个由成绩组成的 `list`）和 `threshold`（“最高分”阈值）作为形参。
这个函数应该返回一个 `list`，其中包含所有 `>=` `threshold` 的分数。

```python
>>> above_threshold(student_scores=[90,40,55,70,30,68,70,75,83,96], threshold=75)
[90,75,83,96]
```

## 4. 计算字母等级

你协助的这位老师既喜欢给分数，也喜欢给字母等级。
因为学生很少能在考试中拿到 100 分，“字母等级”的下限是根据最高分来计算的，并在最高分与**<= 40**的不及格线之间均匀递增。

创建函数 `letter_grades(highest)`，它以考试中的“最高”分作为实参，返回一个 `list`，其中包含每个“美式”等级区间的分数下限：`["D", "C", "B", "A"]`。


```python
"""Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
"""

>>> letter_grades(highest=100)
[41, 56, 71, 86]


"""Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
"""

>>> letter_grades(highest=88)
[41, 53, 65, 77]
```

## 5. 把姓名与分数配对

你有一个按降序排列的考试分数数组，还有一个学生姓名数组，也是按他们的考试分数降序排列的。
你想把每个学生的姓名和他们的考试分数对应起来，并打印出全班的总排名。

创建函数 `student_ranking(student_scores, student_names)`，形参为 `student_scores` 和 `student_names`。
把 student_names `list` 中的每个学生姓名，与 student_scores `list` 中对应的分数配对。
你可以假定每个实参 `list` 都已按分数从高到低排好序。
这个函数应该返回一个由字符串组成的 `list`，格式为 `<rank>. <student name>: <student score>`。

```python
>>> student_scores = [100, 99, 90, 84, 66, 53, 47]
>>> student_names =  ['Joci', 'Sara','Kora','Jan','John','Bern', 'Fred']
>>> student_ranking(student_scores, student_names)
...
['1. Joci: 100', '2. Sara: 99', '3. Kora: 90', '4. Jan: 84', '5. John: 66', '6. Bern: 53', '7. Fred: 47']
```

## 6. “完美”的分数

虽然考试中拿到 100 分的“完美”成绩很罕见，但知道是否至少有一名学生做到了，还是挺有意思的。

创建函数 `perfect_score(student_info)`，形参为 `student_info`。
`student_info` 是一个 `list`，其中每个数组都包含一名学生的姓名和分数：`[["Charles", 90], ["Tony", 80]]`。
这个函数应该 `return` 考试中拿到 100 分的那名学生的_第一对_ `[<name>, <score>]`。

如果在 `student_info` 中没有找到 100 分，就应该返回一个空的 `list`（即 `[]`）。

```python
>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80], ["Alex", 100]])
["Alex", 100]

>>> perfect_score(student_info=[["Charles", 90], ["Tony", 80]])
[]
```

[round]: https://docs.python.org/3/library/functions.html#round
