# 简介

有时，一部分状态需要在多个词之间共享，而不必每次都顺着它们的栈效应层层传递。Factor 的*动态变量*（用`SYMBOL:`声明）让每个词都能访问存储在命名空间中的值。

```factor
USING: namespaces ;

SYMBOL: counter

0 counter set-global
counter [ 1 + ] change-global
counter get-global .       ! => 1
```

`set-global`和`get-global`作用于全局命名空间。`set`和`get`作用于*当前*的动态作用域，当你想要一个有作用域的绑定，而不是整个进程范围的绑定时，通常会在`with-variable`代码块里使用它们。

`SYMBOLS: a b c ;`可以一次声明多个符号。
