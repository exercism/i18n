# 简介

C# 的[`enum` 类型](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum)表示一组固定的命名常量（即枚举）。

通常情况下，一个`enum`成员只能引用其中一个命名常量。但有时，引用多个常量会很有用。为此，可以用 [`Flags` 特性](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute)标注`enum`。

标志枚举可以像下面这样定义（使用二进制整数表示法`0b`）：

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

值为`0b00000011`的`PhoneFeatures`实例，`Call`和`Text`标志都被设置了。

默认情况下，枚举成员的值使用`int`类型。可以在枚举声明中指定类型，从而使用其他整数类型：

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
