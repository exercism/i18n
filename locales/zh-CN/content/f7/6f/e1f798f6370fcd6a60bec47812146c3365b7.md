# 测试

运行测试的步骤如下：

- 进入题目所在目录（例如`~/Exercism/hello-world`）。
- 在终端中启动`jconsole`会话（例如输入`jconsole`或`ijconsole`）。
- 加载你的解答文件（例如`load 'hello-world.ijs'`）
- 输入`load  'general/unittest'`加载单元测试框架
- 输入`unittest 'test.ijs'`测试你的解答。
<br></br>
- 或者，也可以用一行命令运行测试：`jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`。

## 跳过的测试

一开始，只会启用第一个测试。
这种方法鼓励你一步一步地解决练习。
每个测试的定义上方都有一个名词，其名称以 _'\_ignore'_ 结尾。
要运行该测试，把它的值改成 0。

### 示例：

```
    leap_test_02_ignore=: 1 NB. Change this value to 0 to run this test
    test_leap_test_02  =: monad define
    ...                     NB. test definitions
    )
```
