# 安装

## Windows 用户

请先安装 [Windows Subsystem for Linux][wsl-link]，然后阅读下一节。

## Linux/Mac 用户

### 使用 brew 安装

这是安装 Chapel 最简单的方式。
它会给你一个基本可用的安装环境，足以满足学习 Exercism 上这个 track 的需求。
水平更高的用户可能想从源代码构建 Chapel（见下一节）。

0. 如果还没有安装，请先安装 [brew][brew-link] 包管理器。
1. 先运行`brew update`，确保 brew 是最新版本。
2. 运行`brew install chapel`安装 Chapel。
3. 运行`chpl --version`，确认安装成功。

这会安装 Chapel 编译器（`chpl`）、我们用来运行测试的包管理器 `mason`，以及文档生成工具 `chpldoc`。Exercism 上用不到 `chpldoc`，不过如果你想（也是迟早的事 :)）用 Chapel 开发自己的库，有它会很方便。

### 从源代码构建 Chapel

水平更高的用户可能想自己从源代码构建 Chapel。具体做法如下：

1. 安装[前置依赖][prereqs-link]
2. [下载][download-link]最新发布的 Chapel 压缩包并解压。
3. 首先，你需要为安装做准备，并设置好想要安装 Chapel 的位置。
这可以通过运行随包提供的`configure`脚本来完成。
直接运行

```
./configure
```

会将二进制文件、库和共享文件安装到`/usr/local/`，你可以用`--prefix`选项修改这个路径。
例如，如果你想把 Chapel 安装到`~/.chapel`，可以这样做

```
./configure --prefix=~/.chapel
```

4. 要安装编译器和工具，请运行

```
make
make mason
make chpldoc
make install
```

5. 确保`/dir/for/install/bin`文件夹在你的`PATH`环境变量中。

想了解安装 Chapel 和从源代码构建的其他方式，请参阅文档中的 [Building Chapel][building-link] 页面。
