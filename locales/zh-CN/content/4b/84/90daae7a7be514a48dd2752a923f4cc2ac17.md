# 说明

你正在实现一个角色扮演游戏。玩家的角色由下面的结构表示：

```rust
pub struct Player {
    health: u32,
    mana: Option<u32>,
    level: u32,
}
```

这个游戏里的玩家必须先升到 10 级，才能解锁法力池，进而开始施放法术。在那之前，玩家（Player）的法力值为 `None`。

你要实现这个游戏里的两项功能：复活机制和施法机制。

`revive`方法应当先检查 Player 是否确实已经死亡（生命值已经降到 0）。如果确实如此，就返回一个生命值为 100 的新 Player 实例。
如果 Player 的等级在 10 级或以上，复活时还应带 100 法力值。
如果 Player 的等级低于 10 级，其法力值应为 `None`。`revive`方法应当保留 Player 的等级。

```rust
let dead_player = Player { health: 0, mana: None, level: 2 };
dead_player.revive()
// Returns Player { health: 100, mana: None, level: 2 }
```

如果对一个生命值为 1 或以上的 Player 调用`revive`方法，那么该方法应当返回 `None`。

```rust
let alive_player = Player { health: 1, mana: Some(15), level: 11 };
alive_player.revive()
// Returns None
```

`cast_spell`方法接受 Player 的可变引用，以及一个 `mana_cost` 形参，用来表示这个法术消耗多少法力。它返回所施放法术造成的伤害量。如果法术成功施放，伤害量始终是法术法力消耗的两倍。

- 如果玩家无法力池可用，尝试施放法术会使其生命值减少该法术的法力消耗。返回的伤害必须是 0。

  ```rust
  let not_a_wizard_yet = Player { health: 79, mana: None, level: 9 };
  assert_eq!(not_a_wizard_yet.cast_spell(5), 0)
  assert_eq!(not_a_wizard_yet.health, 74);
  assert_eq!(not_a_wizard_yet.mana, None);
  ```

- 如果玩家有法力池但法力不足，该方法不应影响法力池，而应返回 0

  ```rust
  let low_mana_wizard = Player { health: 93, mana: Some(3), level: 12 };
  assert_eq!(low_mana_wizard.cast_spell(10), 0);
  assert_eq!(low_mana_wizard.health, 93);
  assert_eq!(low_mana_wizard.mana, Some(3));
  ```

- 否则，应从 Player 的法力池中扣除 `mana_cost`，并返回相应的伤害量。

  ```rust
  let wizard = Player { health: 123, mana: Some(30), level: 18 };
  assert_eq!(wizard.cast_spell(10), 20);
  assert_eq!(wizard.health, 123);
  assert_eq!(wizard.mana, Some(20));
  ```
