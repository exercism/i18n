# 简介

## Julia 中的布尔值

布尔值由`Bool`类型表示。
它只包含两个值：`true`和`false`。

```julia-repl
julia> true
true

julia> false
false
```

## 布尔运算符

Julia 中有 3 种布尔运算符。

`&&`是布尔“与”。
如果`&&`*两侧*的表达式都是`true`，则结果为`true`。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`是布尔“或”。
如果`||`*任意一侧*的表达式为`true`，则结果为`true`。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`是布尔“非”。
它会交换`true`和`false`的值。

```julia-repl
julia> !true
false

julia> !false
true
```

对于更长、更复杂的表达式，最好使用括号来明确你的意图。

```julia-repl
julia> (true || false) && (false && true)
false
```
