# 暂停社区贡献

有些代码仓库没有足够的资源来分类处理或审查非维护者用户提交的 issue 或 pull request。

暂停社区贡献方案

如果代码仓库启用了该工作流，那么当新开的 issue 或 pull request 的作者并非 Exercism 的 GitHub 组织成员时，它会自动在该 issue 或 pull request 下留言。留言会建议用户先到 Exercism 论坛上发一个主题帖。

## 启用该工作流

把 [.github/workflows/pause-community-contributions.yml 文件](https://github.com/exercism/github-actions/blob/b5424c17f661f5529493258a1ad480013351aa9e/.github/workflows/pause-community-contributions.yml)添加到你的代码仓库中。

## 禁用该工作流

从你的代码仓库中删除该工作流文件。

## 来源

该工作流定义在 `.github/workflows/pause-community-contributions.yml` 文件中。
