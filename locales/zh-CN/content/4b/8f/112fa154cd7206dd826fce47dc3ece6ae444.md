# 关于

能够存放零个或多个元素的数据结构称为_集合_。
Ruby 中的**数组**是一种集合，它会保持对象添加时的顺序。
数组可以存放任意对象。
可以使用下标向数组添加对象，也可以从中取出对象。
Ruby 的数组下标从零开始，也就是说第一个元素的下标始终为 0：

```ruby
# Declare an array containing two values
two_ints = [1,2]

# Assign first and second element by index
two_ints[0] = 7
two_ints[1] = 8

# Retrieve the second element by index
two_ints[1] # => 8

# Check the length of the array
two_ints.size # => 2
```

在 Ruby 中，创建数组有多种方式：

- 使用字面量构造器 `[]`_（最常见）_
- 显式调用 `Array.new`
- 调用 Kernel 的 `Array()` 方法

`Array.new` 方法支持两个可选实参：数组的初始大小和一个默认对象。

当同时提供大小和默认对象时，数组会被填入默认对象的 `size` 个副本。

```ruby
a = Array.new(2, Hash.new)
# => [{}, {}]
```

由于数组的所有元素保存的是同一个哈希，修改其中一个会影响到全部。

```ruby
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {"cat"=>"feline"}]

a[1]['cat'] = 'Felix'
a # => [{"cat"=>"Felix"}, {"cat"=>"Felix"}]
```

如果你想要的是多个副本，就应该使用带块的版本，它会在每次需要初始化数组元素时使用该块的结果：

```ruby
a = Array.new(2) {Hash.new}
a[0]['cat'] = 'feline'
a # => [{"cat"=>"feline"}, {}]
```

Ruby 数组的另一个特点是，它们混入了 [Enumerable][enumerable-module] 模块，从而带来了许多便捷的方法，可用于迭代、查找、排序、筛选数组元素等。
