# 关于

PHP 提供了许多用于执行算术运算的运算符。PHP 的算术运算符遵循标准的数学运算顺序。PHP 提供的运算符有：

* 取正（+）
* 取负（-）
* 加法（+）
* 减法（-）
* 乘法（*）
* 除法（/）
* 求模（%）
* 幂运算（**）

下面我们逐一看看每个运算符，以及它们可以怎么使用：

## 取正（+）

取正运算符（+）作用于单个值（一元运算符）。它会得到该变量的`float`或`int`值。

```php
$value = '42';
$answer = +$value; // 42 (int)
```

## 取负（-）

取负运算符作用于单个值（一元运算符），返回该数值的相反数。

```php
$forward = 65;
$reverse = -$forward; // -65
```

## 加法（+）与减法（-）

加法运算符会把位于它两侧的两个值相加，而减法运算符会从左值中减去右值。

```php
$apples = 5;
$yourApples = 0;

$apples = $apples - 2; // 3
$yourApples = $yourApples + 2; 2
```

## 除法（/）

除法运算符给出左值除以右值的结果。如果右值为 0，就会引发`DivisionByZeroError`错误。

```php
$slicesOfPizza = 8;
$people = 4;
$slicesPerPerson = $slicesOfPizza / $people; // 2
```

## 乘法（*）

乘法运算符返回左值与右值相乘的结果。

```php
$tires = 4;
$priceOfTire = 250;
$totalCost = $tires * $priceOfTire; // 1000
```

## 求模（%）

求模运算符返回左值除以右值后的余数。这个运算符在判断一个数能否被另一个数整除、判断一个值是偶数还是奇数，以及许多其他场景中都非常有用。

```php
$value = 3;
$isOdd = $value % 2;
if ($isOdd === 1) {
    echo 'Yes, it is odd!';
} else {
    echo 'It is even.';
}
```

## 幂运算（**）

幂运算符用于把左值提升到右值次幂。在 PHP 5.6 之前，你需要使用`pow`函数来完成同样的事情。

```php
$sideLength = 13;
$areaOfSquare = $sideLength ** 2; // 169
```

幂运算符两侧都支持整数和浮点数，所以你可以用它来计算平方根（或其他次方根），或者更复杂的指数值。

```php
$squareArea = 144;
$side = $squareArea ** .5; // 12
```

## 运算顺序

PHP 遵循标准的数学运算顺序。这意味着它不是从左到右依次执行运算，而是每个运算符都有一个优先级，运算会按照各自的优先级依次求解。运算顺序为：

* 圆括号
* 幂运算
* 乘法、除法
* 加法、减法

乘法和除法处于同一优先级。同样，加法和减法也处于同一优先级。

这意味着下面这个值会是 17 而不是 10，因为乘法的优先级高于加法：

```php
$value = 2 + 3 * 5;
```

PHP 还提供了许多有用的赋值运算符，当你对一个变量进行运算并把结果赋值回该变量本身时，它们会把算术运算符和赋值结合起来。这些内容会在`Assignment Operators`概念中介绍。
