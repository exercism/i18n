# 关于类型转换

Go 要求在不同类型之间进行显式转换。
例如，下面的代码会引发编译错误：

```go
var x int = 42
var f float64 = x // compiler error x is an int not a float64
```

类型之间的转换（也称为**类型强制转换**）通过一个与目标类型同名的函数来完成。
使用`T(v)`可以把值`v`转换为类型`T`。
例如，要把`int`转换为`float64`，需要这样做：

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

这同样适用于任何自定义类型：

```go
type Id int
var number int = 121 // number has type int
userId := Id(number) // userId now has type Id
```

## 在基本类型和字符串之间转换

有一个`strconv`包，用于在基本类型（如`int`）和`string`之间进行转换。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

警告：使用标准的类型转换方法不会有这种行为。
例如：

```go
var num int = 65
str := string(num) // str is now "A" not "65"
```

下面是其他一些常见的转换方法：

| 方法        | 用途                        |
| ----------- | --------------------------- |
| ParseBool   | 将`string`转换为`bool`      |
| FormatBool  | 将`bool`转换为`string`      |
| ParseFloat  | 将`string`转换为`float`     |
| FormatFloat | 将`float`转换为`string`     |
| ParseInt    | 将`string`转换为`int`       |
| FormatInt   | 将`int`转换为`string`       |
