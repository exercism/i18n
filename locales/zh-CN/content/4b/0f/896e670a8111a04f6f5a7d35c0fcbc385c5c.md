## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，应始终附带一条**有意义的错误消息**，说明错误的来源是什么。这能让代码更易读，也对调试大有帮助。如果你知道错误来源属于某种确定的类型，可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍应附带一条有意义的消息。

本练习要求你使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在游戏已经结束但玩家还想继续玩时“抛出”`ValueError`。只有既`raise`了该`exception`，又附上一条消息，测试才会通过。

要抛出带消息的`ValueError`，请把这条消息写成传给`exception`类型的实参：

```python
# when player tries to play, but the game is already over.
raise ValueError("The game has already ended.")
```
