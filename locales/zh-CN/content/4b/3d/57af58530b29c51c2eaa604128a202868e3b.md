# 说明

你将初始化空缓冲区，并列出斐波那契数列的前五个数字（或元素）。

斐波那契数列是一组数字，其中下一个元素是前两个元素之和。我们从 1 开始，所以前两个元素是 1 和 1。

## 1. 创建一个包含`count`个零的缓冲区。

创建一个包含`count`个零的缓冲区。

```rust
let my_buffer = create_buffer(5);
// [0, 0, 0, 0, 0]
```

## 2. 列出斐波那契数列的前五个元素

创建一个返回斐波那契数列前五个数字的函数。
前五个元素是`1, 1, 2, 3, 5`

```rust
let first_five = fibonacci();
// [1, 1, 2, 3, 5]
```
