# 测试

由于 OCaml 是一门编译型语言，在运行测试之前，你需要先编译自己的提交内容和测试代码。
我们使用[`dune`](https://dune.build/)来构建。
每个文件夹都有一个 dune 文件，说明如何构建，还有一个 Makefile，负责把工作交给 dune 处理。

要编译并运行测试，只需在练习文件夹中键入：

```bash
make
```

## 创建你的第一个 OCaml 模块

要创建一个能与 `bob` 练习中的测试一起使用的模块，请把以下内容放在名为 `bob.ml` 的文件中：

```ocaml

```
