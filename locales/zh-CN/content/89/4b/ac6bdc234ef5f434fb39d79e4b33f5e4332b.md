# 关于

*并查集*（一种 union-find 结构）把一组值划分成互不重叠的组，并能快速回答一个问题：这两个值在同一个组里吗？它位于[`disjoint-sets`][disjoint-sets]词汇表中。

`<disjoint-set>`会构建一个空结构。值，也就是*元素*，用`add-atom`添加，或者用`add-atoms`批量添加；每个元素一开始都单独成组：

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms   ! four singleton groups
```

`equate`会合并包含两个元素的组。合并具有传递性：一旦`a`与`b`合并、`b`与`c`合并，这三个元素就同属一个组。

```
equate ( atom1 atom2 disjoint-set -- )
```

每个组都由一个唯一的成员来标识，这个成员就是该组的*代表元*。`representative`返回这个代表元；两个元素属于同一个组，当且仅当它们的代表元相等。`equiv?`可以直接进行这项判断：

```
representative ( atom disjoint-set -- representative )
equiv?         ( atom1 atom2 disjoint-set -- ? )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ "a" "b" "c" "d" } over add-atoms
"a" "b" pick equate
"b" "c" pick equate
"a" "c" pick equiv? .          ! => t   (transitively connected)
"a" "d" pick equiv? .          ! => f
"a" over representative
"c" pick representative = .     ! => t   (same representative)
```

哪个元素被选为组的代表元属于内部实现细节：它可以是组里的任意一个成员，并且会随着组的合并而变化。不要依赖某个特定元素就是代表元，只能依赖同一组里两个元素的代表元一致这一点。

`disjoint-set-members`返回所有已经添加的元素。

这个结构是*可变的*：`equate`和`add-atom`会就地修改并查集，而不是返回一个新的并查集。实现采用了按秩合并与路径压缩，因此连续多次调用`equate`和`representative`时，每次实际上都只需要常数时间。
