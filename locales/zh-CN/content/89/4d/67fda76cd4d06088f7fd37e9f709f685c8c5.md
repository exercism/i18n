# 提示

## 通用

- 在 Roc 中，透镜用得不多，因为记录更新语法已经很好地覆盖了大多数场景。例如，看看这个嵌套记录：

  ```roc
  bob = { hair: { color: Brown, length: Long }, mouth: Smiling, height: 6.0 }
  ```

  现在给 Bob 剪个头发：

  ```roc
  new_bob = { ..bob, hair: { ..bob.hair, length: Short } }
  ```

  完全不需要透镜！

- 话虽如此，虽然透镜在 Roc 里很少见，但在 Haskell、Scala 等其他语言中却很常见，所以你也许会好奇怎样在 Roc 里实现透镜。这也是练习 Roc 一些进阶特性的好方法，比如参数化类型，以及包含函数的记录。事实上，下面就是一种用 Roc 表示透镜的方式：

  ```roc
  Lens(whole, part) := {
      get : whole -> part,
      set : whole, part -> whole,
  }
  ```

  这是一个参数化类型：`whole`和`part`可以是任意类型。`whole`通常是记录，而`part`可以是任意字段类型。`get`字段包含一个函数，返回给定`whole`中特定的`part`；`set`字段包含一个函数，返回给定`whole`的副本，只是把其中特定的`part`换成给定的`part`。

  例如，下面这个透镜可以获取或设置一个人的头发：

  ```roc
  hair_lens = {
      get: |person| person.hair,
      set: |person, hair| { ..person, hair },
  }
  ```

  我们可以用这个透镜聚焦到 Bob 的头发上，像这样：

  ```roc
  bob_hair = bob |> hair_lens.get
  ```

  也可以这样改变他的发型：

  ```roc
  new_hair = { ..bob.hair, length: Short }
  new_bob = bob |> (hair_lens.set)(new_hair)
  ```

- 注意：`hair_lens.set`外面的括号是必需的；没有括号，Roc 会在`hair_lens`的类型里寻找一个名为`set`的函数。

- 当你开始组合透镜时，它们会变得特别有用，能让你获取和设置深层嵌套的部分。实现一个像下面这样的函数即可做到：

  ```roc
  compose : Lens(outer, inner), Lens(inner, part) -> Lens(outer, part)
  ```

  实现这个函数之后，就可以用它创建一个头发长度透镜：

  ```roc
  length_lens = {
      get: |hair| hair.length,
      set: |hair, length| { ..hair, length },
  }
  hair_length_lens = compose(hair_lens, length_lens)

  ```

  现在可以再给 Bob 剪一次头发：

  ```roc
  set_hair_length = hair_length_lens.set
  new_bob = bob |> set_hair_length(Short)
  ```

- 你也许还想实现一个函数，对嵌套的部分施加任意变换：

  ```roc
  over : Lens(whole, part), whole, (part -> part) -> whole
  ```

  实现之后，可以这样使用`over`：

  ```roc
  cut_hair = |current_length| match current_length {
      Long => Short
      Short => Bald
      Bald => Bald
  }
  new_bob = hair_length_lens |> over(bob, cut_hair)
  ```

- 我们建议你先用 Roc 的记录更新语法通过测试，然后再试着改用透镜。
