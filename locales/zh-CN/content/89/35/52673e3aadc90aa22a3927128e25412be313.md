# 设置

本 track 使用两个工具来运行测试套件，并确保符合最佳实践：

1. [vader.vim](https://github.com/junegunn/vader.vim)
2. [vint](https://github.com/Kuniwak/vint)

## 运行测试

1. 安装 [vader.vim](https://github.com/junegunn/vader.vim/#installation)。
1. 打开你提交的解答：
    ```
    $ vim exercise.vim
    ```
1. source 当前文件，让它里面的全局函数可供 Vim 使用：
    ```
    :source %
    ```
1. 运行测试：
    ```
    :Vader exercise.vader
    ```

路径可能有所不同。

如果你想为上面的步骤准备一个方便的快捷方式，可以把下面这段放进你的 vimrc：

```vim
function! s:exercism_tests()
  if expand('%:e') == 'vim'
    let testfile = printf('%s/%s.vader', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(testfile)
      echoerr 'File does not exist: '. testfile
      return
    endif
    source %
    execute 'Vader' testfile
  else
    let sourcefile = printf('%s/%s.vim', expand('%:p:h'),
          \ tr(expand('%:p:h:t'), '-', '_'))
    if !filereadable(sourcefile)
      echoerr 'File does not exist: '. sourcefile
      return
    endif
    execute 'source' sourcefile
    Vader
  endif
endfunction

autocmd BufRead *.{vader,vim}
      \ command! -buffer Test call s:exercism_tests()
```

之后，从练习目录中打开任意`.vim`或`.vader`文件，然后运行`:Test`命令。

## 检查 Vim 文件的代码风格

1. 安装 [vint](https://github.com/Kuniwak/vint#quick-start)。
1. 递归检查所有 Vim 文件：
    ```
    $ vint .
    ```

想了解 Vim script track 的更多详细信息，请查看[帮助页面](https://exercism.org/languages/vimscript)。
