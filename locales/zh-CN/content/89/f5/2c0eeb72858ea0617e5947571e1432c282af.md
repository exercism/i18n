# 提示

## 1. 获取句子的第一个字母

- 回顾简介，了解如何取出字符串中的某个字母。
- 下标从 0 开始计数。

## 2. 将单词首字母大写

- 首字母大写意味着只有一个_大写_字符，后面跟着_小写_字符。
- 所以首先要提取第一个字母，把它[转换为大写][mdn-to-upper-case]。
- 然后要确定字符串的其余部分（除第一个字符以外的所有内容）。[slice 方法][mdn-slice]可以帮你做到这一点。
- 在[转换为小写][mdn-to-lower-case]之后，你可以用加法运算符`+`把第一个字母和其余部分拼接起来。

## 3. 获取句子的最后一个字母

- 回顾简介，了解如何取出字符串中的某个字母。
- 最后一个字母的下标可以从字符串的`.length`属性和下标从 0 开始计数这一点推导出来。
- 字符串带有 [trim][mdn-trim] 方法，可以删除开头和末尾的空白字符。

## 4. 保持礼貌

- 复用已有的函数来把单词首字母大写。
- 加法运算符`+`可以用来拼接两个字符串。
