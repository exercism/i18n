# 关于

## 术语

你已经在好几个概念里用过、也写过 C++ 函数了。现在该讲点技术细节了。下面的代码片段列出了最常用的术语，方便随时查阅。C++ 会忽略空白字符，所以这里调整了格式，把每个元素单独放在一行。

```cpp
// Function declaration:
bool                                              // Return type
admin_detected(string user, string password)      // Type signature
;                                                 // Don't forget the ';' for the declaration

// Function definition:
bool                                              // Return type
admin_detected                                    // Function name
(string user, string password)                    // Parameter list
{ return user == "admin" && password == "1234"; } // Function body
```
~~~~exercism/advanced
声明就像是给编译器的一张便条，告诉它存在一个具有该名称、返回类型和形参列表的函数。如果缺少定义，代码就无法运行。声明是可选的，只有在你于定义之前使用该函数时才需要。声明还能解决循环引用之类的问题，也可以用来把接口和实现分开。
~~~~

## `const`限定符

有时你希望确保值在初始化之后无法再被修改。C++ 使用`const`关键字作为常量的限定符。

```cpp
const int number_of_dragon_balls{7};
number_of_dragon_balls--; // compilation error
```

~~~~exercism/note
你经常会看到常量写成 _UPPER_SNAKE_CASE_。如果没有其他约定，建议把这种写法留给宏使用。
~~~~

如果你试图在常量变量设定之后修改它，代码就无法通过编译。这有助于避免意外的改动，同时也为编译器带来了优化的可能。作为人类，知道某些部分不会受到影响，也更容易理解代码。

你也可以把`const`用作函数形参的限定符。

```cpp
string guess_number(const int& secret, const int& guess) {
    if (secret < guess) return "lower.";
    if (secret > guess) return "higher.";
    return "exact!";
}
```

当你向函数传入一个`const`引用时，可以确信它不会被改动。对于复制代价可能很高的对象，比如较长的字符串，你经常会看到使用`const`引用。`const`限定符的第三种用法，是那些不会改变类实例的成员函数。

```cpp
class Stubborn {
    public:
    Stubborn(string reply) {
        response = reply;
    }
    string answer(const string& question) const {
        if (question.length() == 0) { return "";}
        return response;
    }
    private:
    string response{};
};
```

`Stubborn`的成员函数`answer`使用`const string&`引用作为形参。这样就避免了从传入函数的原始对象进行复制操作。

## 函数重载

只要形参列表不同，多个函数就可以同名。这叫做函数重载，通常在这些函数执行非常相似的任务时使用。

去掉返回类型的函数头就是函数的__类型签名__。类型签名一变，就是一个新的函数。

`play_sound`这个例子有六个不同的重载版本，以适应不同的场景：

```cpp
// different argument types:
void play_sound(char note);         // C, D, E, ..., B
void play_sound(string solfege);    // do, re, mi, ..., ti
void play_sound(int jianpu);        // 1, 2, 3, ..., 7

// different number of arguments:
void play_sound(string solfege, double duration);

// different qualifiers:
void play_sound(vector<string>& solfege);
void play_sound(const vector<string>& solfege);
```

~~~~exercism/advanced
类型签名由函数名、形参的数量、类型以及限定符决定（但不包括形参的名字）。返回类型明确不属于类型签名的一部分，如果你有两个仅在返回类型上不同的函数，就会遇到编译错误。编译器会报错，因为无法确定该用哪一个。
~~~~

## 默认实参

有些函数会变得很长，而很多调用可能对大部分形参都使用相同的值。用默认实参就能避免这些调用里的重复。

```cpp
void record_new_horse_birth(string name, int weight, string color="brown-ish", string dam="Alruccaba", string sire="Poseidon");

record_new_horse_birth("Urban Sea", 130); // color will be brown, dam "Alruccabam", sire "Poseidon"
record_new_horse_birth("Highclere", 175, "off-white", "Fall Aspen");   // sire will be "Poseidon"
```

由于函数声明常常在定义之前被读到，所以它更适合用来设定默认实参。如果某个形参带有默认值声明，那么它右侧的所有形参也都需要有默认值声明。有时可以把复杂的函数重载重构为数量更少、带默认实参的函数，以提高可维护性。
