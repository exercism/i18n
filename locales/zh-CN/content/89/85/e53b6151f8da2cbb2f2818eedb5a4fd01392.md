# 简介

在 JavaScript 中，数组是一种类似列表的结构，长度不固定，可以存放任意类型的原始值或对象，甚至可以混合存放不同类型。

要创建数组，把元素写在方括号`[]`之间。
要从数组中读取元素，把下标放在标识符后面的方括号`[]`里。
数组的下标从 0 开始。

例如：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

要获取数组中有多少个元素，可以使用`length`属性：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

要修改数组中的某个元素，就在对应的下标处赋值：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## 方法

每个 Array 对象都可以使用一些[方法][array_methods]，用来向数组中添加或删除元素。

### push

> `push()`方法会向数组末尾添加一个或多个元素，并返回数组的新长度。[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> `pop()`方法会移除数组的最后一个元素，并返回该元素。
> 这个方法会改变数组的长度。[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> `shift()`方法会移除数组的第一个元素，并返回被移除的那个元素。
> 这个方法会改变数组的长度。[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> unshift() 方法会向数组开头添加一个或多个元素，并返回数组的新长度。[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> splice() 方法会通过原地移除或替换已有元素，以及添加新元素来改变数组的内容。这个方法会返回一个数组，其中包含被删除的元素。[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
