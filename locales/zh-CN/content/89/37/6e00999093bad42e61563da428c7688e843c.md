# 关于

Swift 中的[闭包][closures]是自包含的代码块，可以向它传入实参来触发计算并返回值。
闭包还会捕获所在环境中的值，并在计算中使用它们。
由于是自包含的，闭包可以像其他值一样在程序中传来传去，也可以赋给常量或变量。

闭包听起来很像 Swift 的函数，确实如此，而且事出有因。
Swift 中的函数是闭包的一种特例：函数必须有名字，而且定义时使用的语法略有不同。

严格来说，Swift 中的函数也是闭包，但当人们提到 Swift 里的“闭包”时，指的其实是[闭包表达式][closure-expressions]。
闭包表达式的写法是：先写形参列表，接着是返回类型和关键字`in`，然后是闭包体，整体放在一对大括号里：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

这定义了一个类型为`(Double, Double) -> Double`的闭包表达式，它的执行方式与这种类型的函数类似：向它传入相应类型的参数即可：

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

每次要执行时都写出完整的闭包表达式并不方便，所以闭包可以像 Swift 中的其他值一样赋给一个名字。
之后，只要把参数应用到这个名字上就能调用它：

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

如上所示，闭包和普通函数一样，如果闭包体只有一个表达式，就可以省略`return`关键字。

闭包最常见的用法是与高阶函数配合：要么作为参数传入，要么作为结果返回：

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
