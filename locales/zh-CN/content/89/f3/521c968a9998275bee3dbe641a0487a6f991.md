# 关于条件语句

## 比较运算符

[比较运算符][operators]与许多其他语言类似，但有一些扩展。

判断是否相等时，运算符是`==`（相等）和`!=`（不相等）。

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

此外，`===`和`!==`运算符用于检验[“引用相等”][referential-equality]：当且仅当`a`和`b`指向同一个对象时，`a === b` 才成立。这一点在教学大纲后面的内容中会更好理解。

大于和小于运算符也都是常规写法。

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## 用 `if` 进行分支

这是[`if`表达式][if-else]的完整形式：

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- 每个条件都必须用括号`()`括起来。
- 条件的求值结果必须是布尔值`true`或`false`。Kotlin 没有某些语言中“真值”和“假值”的概念。
- 如果只有一个表达式，大括号`{}`是可选的。
- `else if`和`else`都是可选的，并且可以有多个`else if`块。

`if`表达式也可以用来“选择”一个值：

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## 替代方案？

Kotlin 有意_不_提供 Java 中的三元运算符`? :`。它更倾向于使用简洁的`if ... else`形式：

```Kotlin
val result = if (isOk) goodValue else badValue

return if (isOK) goodValue else badValue
```

与 Ruby 不同，简洁的`if ... else`形式*总是*需要`else`，因此不能用作守卫语句：

```kotlin
return 42 if (isOk)
// Syntax error: Unexpected tokens (use ';' to separate expressions on the same line).
// Syntax error: Expecting an expression.

return if (isOk) true
// 'if' must have both main and 'else' branches when used as an expression.
```

注意，在 Kotlin 中，`if`是一个[_表达式_][expression]，会返回一个值。它不像 Java 中那样是[_语句_][statement]。

在后面的某个概念中我们会看到，Kotlin 有一个强大的[`when`][when]结构，它用模式匹配取代一长串`else if`子句。
