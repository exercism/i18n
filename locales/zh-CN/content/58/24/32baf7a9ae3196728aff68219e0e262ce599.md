# 字符串

`String`数据类型是由 UTF-8 编码的线性字符序列，适合用来存储文本数据。

## 创建字符串

可以使用关联函数`String::new()`或`String::from()`来创建字符串。许多类型都带有`to_string`方法，可以生成字符串，例如从数字生成一个字符串。

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### `format!`宏

由于从若干较小的数据类型拼出一个大字符串是很常见的操作，Rust 还提供了一种简写，可以省去调用`to_string`的细节，那就是`format!`宏。例如，上面那个复合字符串的构造可以简化成下面这样：

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## 字符串切片

字符串和字符串切片关系密切。字符串切片是对一块已知大小的内存区域的不可变引用，该区域包含由 UTF-8 编码的线性字符序列。通过用解引用运算符（`&`）借用，任何字符串都能被强制转换为字符串切片。要把字符串切片转换成字符串，用`to_string()`方法或`String::from`都可以。

在 Rust 代码中，字符串字面量用双引号括起来。这些字符串字面量始终是字符串切片，因为它们引用的是程序可执行文件内的一块不可变内存区域。

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## 修改字符串

要在字符串后面拼接单个字符，用`push`方法。要在字符串后面拼接字符串切片，用`push_str`方法或`+`运算符。

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## 访问字符串中的字符

由于 Rust 字符串采用 UTF-8 编码，各个字符的大小并不都一样。因此`String`数据类型没有提供索引运算符（`[]`）。要访问字符串中的所有字符或某个特定字符，可以使用`chars()`方法。它会按顺序对字符串中的每个字符进行迭代。

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
