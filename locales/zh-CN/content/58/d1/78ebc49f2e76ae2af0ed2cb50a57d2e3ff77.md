# 简介

一个*不相交集*（并查集结构）维护一组值，把它们划分成互不重叠的组，并能快速回答一个问题：这两个值是否在同一组？它位于[`disjoint-sets`][disjoint-sets]词汇表中。

## 构建不相交集

`<disjoint-set>`构建一个空结构。值，也就是*原子*，可以用`add-atom`一次添加一个，也可以用`add-atoms`从一个序列中添加。每个原子一开始都单独成组。

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

不相交集是*可变的*：`add-atom`、`add-atoms`和`equate`会就地修改它，而不是返回一个新的。当某个单词消耗掉不相交集之后，你想再把它放回栈上时，`keep`就很好用。

## 合并组

`equate`会合并包含其原子的那两个组。合并具有传递性：先合并两个原子，再把其中一个与第三个合并，这三个原子最终就在同一个组里。

```
equate ( atom1 atom2 disjoint-set -- )
```

## 代表元

每个组都有一个规范成员，也就是它的*代表元*。`representative`会返回它，而两个原子属于同一组，当且仅当它们的代表元相等。

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

一个组会选哪个原子作为代表元，属于内部细节：永远不要依赖某个特定原子被选中，只需依赖同一组中的两个原子能得到一致的结果。
