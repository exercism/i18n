# 关于

[守卫][guards]用于补充[模式匹配][exercism-pattern-matching]，我们会在后面的概念中介绍模式匹配。守卫让我们可以根据输入的值，为同一个函数提供不同的实现，还能进行更复杂的检查。

守卫语句由竖线`|`引出，后面跟一个布尔表达式，最后以等号`=`和函数体结束。一个函数可以有多个守卫语句。守卫语句自上而下求值，第一个求值为`True`的会被执行。守卫语句可以包含一个`otherwise`语句，用来兜住所有不匹配前面守卫语句的值。

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

我们也可以定义自己的函数，并在守卫语句中使用它。

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
