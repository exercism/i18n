# 介绍

初始化器是一种特殊的方法，用来为枚举设置一个值。它们的定义和方法很像，只是没有`func`关键字，没有返回类型，名字必须是`init`，而且初始化器_必须_把一个枚举值赋给`self`。调用初始化器既可以用点语法，也可以把初始化器的形参传给枚举的名字。

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
