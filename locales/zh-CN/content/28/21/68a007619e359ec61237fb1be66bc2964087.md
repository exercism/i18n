# 说明补充

## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。抛出异常时，应该始终附上一条**有意义的错误消息**，说明错误的来源。这样能让你的代码更易读，对调试也大有帮助。如果已知错误的来源会是某种特定类型，你可以选择抛出[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)中的一种，但仍然要附上有意义的消息。

这道练习要求你在`matrix`不规则时，用 [`raise` 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)“抛出”`ValueError`。只有既`raise`了这个`exception`，又附上消息，测试才会通过。

要抛出带消息的`ValueError`，就把消息写成`exception`类型的实参：

```python
# if the matrix is irregular
raise ValueError("irregular matrix")
```
