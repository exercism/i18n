# 简介

在 Ruby 中，**数组**是有序的、以整数为下标的集合，可以容纳任何对象。
数组的下标从`0`开始。
负下标表示从数组末尾开始计数，也就是说，下标`-1`表示数组的最后一个元素，`-2`表示倒数第二个元素，依此类推。
Ruby 数组混入了 [Enumerable 模块][enumerable-module]，它提供了若干遍历和查找方法，还提供了排序能力。

## 创建数组

- Ruby 中的数组可以包含不同类型的对象。

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## 元素赋值

使用下标可以访问或修改元素。
指定起始下标和长度，就可以访问子数组。

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- 负下标会从数组末尾往前计数。

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## 元素引用

- 可以使用 #[] 方法获取数组中的元素。
- 它返回指定下标处的元素，或者返回一个子数组：从起始下标开始，连续返回 length 个元素。

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- 负下标会从数组末尾往前计数（-1 是最后一个元素）

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## 获取数组的信息

数组始终记录着自己的长度。
要查询数组包含多少个元素，可以使用 length、count 或 size。

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## 向数组添加元素

可以使用`push`或`<<`把元素添加到数组末尾：

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## 从数组移除元素

pop 方法会移除数组的最后一个元素并把它返回：

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
