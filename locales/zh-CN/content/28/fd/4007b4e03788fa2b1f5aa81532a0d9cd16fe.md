# 说明

在本练习中，你正在玩一款名为“Wizards and Warriors”的角色扮演游戏。要玩这个游戏，你需要一个通用的掷骰方法来确定各种结果。这是一个传统的 18 面骰，数字从 1 到 18。玩家还需要生成随机的法术强度。

## 1. 让 _Wizards and Warriors_ 玩家掷骰子

在`Player`类上实现一个`RollDie()`方法。

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. 玩家需要自己的法术强度。提供生成法术强度的方式

在玩家类上实现一个`GenerateSpellStrength()`方法。
法术强度介于 0.0 和 100.0 之间（包含 0.0，不包含 100.0）。

注意，法术强度必须是浮点数（不能是整数），这样在比较两个对手的强度时，可以减少出现平局的可能性。

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
