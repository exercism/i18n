# 关于

在 Kotlin 中，布尔值用`Boolean`类型表示，它的取值可以是`true`或`false`。

Kotlin 支持三个内置的[布尔运算符][reference]：`!`（取反，即 NOT）、`&&`（惰性与运算，即 AND）和`||`（惰性或运算，即 OR）。`&&`和`||`运算符采用_短路求值_，也就是说，只有当需要时，运算符右侧的表达式才会被求值。

```kotlin
true || false // => true
true && false // => false
```

这三个布尔运算符的[_运算符优先级_][precedence]各不相同。因此，它们的求值顺序是：先`!`，再`&&`，最后是`||`。如果你想“绕过”这些规则，可以用括号（`()`）把布尔表达式括起来，因为括号的运算符优先级还要更高。

```kotlin
!true && false   // => false
!(true && false) // => true
```

[reference]: https://kotlinlang.org/docs/reference/basic-types.html#booleans
[precedence]: https://kotlinlang.org/docs/reference/grammar.html#expressions
