# 调试

与许多语言不同，WebAssembly 代码无法自动访问控制台之类的全局资源。这类功能必须通过导入来提供。

为了提供类似 `console.log` 的功能以及其他一些便利功能，Exercism 的 WebAssembly 赛道在所有练习中都提供了一个标准函数库。

这些函数必须在 WebAssembly 模块的顶部导入，之后就可以在 WebAssembly 代码中调用。

`log_mem_*` 函数需要能够访问 WebAssembly 模块的线性内存。默认情况下，这是私有状态，因此为了让它可访问，你必须在导出名 `mem` 下导出你的线性内存。方法如下：

```wasm
(memory (export "mem") 1)
```

# 记录局部变量和全局变量

我们为每种 WebAssembly 原始类型都提供了记录函数。这对记录全局变量和局部变量很有用。

## log_i32_s - 向控制台记录一个 32 位有符号整数

```wasm
(module
  (import "console" "log_i32_s" (func $log_i32_s (param i32)))
  (func $main
    ;; logs -1
    (call $log_i32_s (i32.const -1))
  )
)
```

# 从线性内存中记录

WebAssembly 线性内存是一个可按字节寻址的值数组。它相当于 WebAssembly 程序的虚拟内存。

我们提供了一些记录函数，把线性内存中一段地址范围解释为特定类型的静态数组。这与 JavaScript 的 TypedArray 类似。长度参数不是以字节为单位，而是以该函数对应类型的连续元素个数为单位。

**为了让这些函数正常工作，你的 WebAssembly 模块必须使用导出名 `mem` 声明并导出它的线性内存。**

```wasm
(memory (export "mem") 1)
```

## log_mem_as_utf8 - 向控制台记录一串 UTF8 字符

```wasm
(module
  (import "console" "log_mem_as_utf8" (func $log_mem_as_utf8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (data (i32.const 64) "Goodbye, Mars!")
  (func $main
    ;; Logs "Goodbye, Mars!" to console
    (call $log_mem_as_utf8 (i32.const 64) (i32.const 14))
  )
)
```

## log_mem_as_i8 - 向控制台记录一串有符号 8 位整数

```wasm
(module
  (import "console" "log_mem_as_i8" (func $log_mem_as_i8 (param $byteOffset i32) (param $length i32)))
  (memory (export "mem") 1)
  (func $main
    (memory.fill (i32.const 128) (i32.const -42) (i32.const 10))
    ;; Logs an array of 10x -42 to console
    (call $log_mem_as_u8 (i32.const 128) (i32.const 10))
  )
)
```
