# 说明

在这个练习中，你将编写一些代码，帮你照着最喜欢的烹饪书做出一份美味的千层面。

你有四个任务，全都和烹饪千层面所花的时间有关。

## 1. 将预计烘焙时间存入常量

定义`expected_bake_time`常量，它返回千层面需要在烤箱中烘焙多少分钟。

按照这本烹饪书，千层面需要在烤箱中总共烤 60 分钟。

```julia-repl
julia> expected_bake_time
60
```

## 2. 计算准备时间（分钟）

定义`preparation_time`函数，它接收你给千层面添加的层数作为实参，并返回你准备千层面花了多少分钟。假设每加一层需要 2 分钟准备。

```julia-repl
julia> preparation_time(4)
8
```

## 3. 计算剩余的烘焙时间（分钟）

定义`remaining_time`函数，它接收千层面已经在烤箱中度过的实际分钟数作为形参，并返回千层面还需要在烤箱中烤多少分钟。

```julia-repl
julia> remaining_time(50)
10
```

## 4. 计算总的工作时间（分钟）

定义`total_working_time`函数，它接收两个实参：第一个实参是你给千层面添加的层数，第二个实参是千层面已经在烤箱中度过的分钟数。

该函数应返回你烹饪千层面总共花了多少分钟，也就是准备时间的分钟数与此刻千层面在烤箱中已度过的分钟数之和。

```julia-repl
julia> total_working_time(3, 20)
26
```
