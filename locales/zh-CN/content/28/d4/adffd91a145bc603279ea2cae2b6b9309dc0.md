# 练习说明补充

## 异常消息

有时需要[抛出异常][raising-exceptions]。
抛出异常时，一定要附上**有意义的错误消息**，说明错误的来源。
这样代码更易读，对调试也有很大帮助。
如果已知错误来源属于某种类型，可以选择抛出[内置错误类型][error-base-classes]中的一种，但仍然要附上有意义的消息。


一局有效的`Tic Tac Toe`对局在一方获胜时结束。
如果双方都处于获胜状态，这道练习要求你在解答中使用 [raise 语句][raise]，“抛出”一个`ValueError`。
如果某一方被判定连续走了两步，或者本该后手却先落子，你的代码也应该抛出一个`ValueError`。


要抛出带有消息的`ValueError`，把消息作为参数传给`exception`类型：

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

测试会精确比对错误消息，所以请仔细阅读预期结果。
