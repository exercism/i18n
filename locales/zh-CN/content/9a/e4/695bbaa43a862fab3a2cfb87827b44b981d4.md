# 简介

`Option` 类型是 F# 语言用来处理“可能存在、也可能不存在”的值的机制。
它提供了一种类型安全的替代方案，取代其他语言中处理这类值常用的 `null`。
许多标准 F# 库函数都用到它，因此要高效使用标准 F# 库，理解它非常关键。

## 用法 

`Option` 类型是一种泛型类型（带有底层类型）。  
`Option` 值要么是 `Some value`，表示某个具体的值，要么是 `None`，表示没有值。

下面的函数演示了如何创建一个 `Option` 值：

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` 是与 `Option<T>` 等价的后缀写法，这两种写法可以互换使用。
不过，按照 F# 风格指南，Option 类型更推荐使用后缀写法（参见 [F# 风格指南中关于类型格式化和类型标注的部分](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)）。

## 读取 Option 值的内容

读取 `Option` 值的惯用方式是模式匹配，如下例所示：

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 使用默认值解包 Option

使用 `Option.defaultValue` 函数提供默认值，就可以把 `Option`“解包”（转换为它所包含的类型）。
当你想确保值不是 `None` 时，这尤其有用。
例如：

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
