# Instructions

你附近的一所学校有一个非常活跃的学生会。
学生会由一名会长管理，每 2 年举行一次选举，选出新会长。

在今年的选举中，大家决定需要一套新的数字系统来计票。学校需要你帮忙搭建这套新系统。

## 1. 从`ElectionResult`获取票数

新系统需要一种从计数器获取票数的方式。

选举结果结构体已经为你创建好了，它的定义如下：

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

由于`struct`中的所有成员都是公有的，你不需要编写`constructor`来初始化`ElectionResult`对象。
你可以改用`initializer list`：

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

创建一个函数`vote_count`，它接受一个`ElectionResult`的引用作为实参，并返回该`ElectionResult`中的票数。

```cpp
vote_count(hamilton);
// => 1804
```

## 2. 增加`ElectionResult`的票数

终于到了处理选票的时候了！
现在你需要一种增加`ElectionResult`中票数的方式。

创建一个`void`函数`increment_vote_count`，它接受一个`ElectionResult`的引用以及要增加的票数，并将该`ElectionResult`增加相应的票数。

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. 计票与会长职位

学校已经提交了他们的选票，现在是时候检查结果，找出获胜者了。

创建一个函数`determine_result`，它接收最终计票结果的引用，并返回新会长的`ElectionResult`的引用。
它还应该通过在获胜者姓名前加上“President”来修改获胜者的姓名。
最终计票结果以`reference`的形式给出，指向`std::vector<ElectionResult>`，这是一个包含所有参选候选人的`ElectionResults`的向量。

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

为了简单起见，你可以假设：
- `vector`中至少有一个元素。
- 第一名不会出现平局。
