# 关于

## `for` 循环

`for` 语句用于重复执行一段代码。它的第一行控制这段代码重复的次数：

```go
for init; condition; post {
    // loop body
}
```

- **init** 语句在第一次迭代之前运行一次。通常在这里声明并初始化循环使用的计数器变量。
- **condition** 是一个布尔表达式，在每次迭代之前求值。当它求值为 `false` 时，循环停止。
- **post** 语句在每次迭代结束后运行。可以用它更新计数器。

不要在`init; condition; post`外面加括号。不过，包裹循环体的花括号`{ }`始终是必需的。

这个循环让`i`从`1`开始，打印`i`的当前值，在进入下一次迭代前把它自增，并在`i`达到`10`时停止：

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## 其他循环形式

### 只有条件的循环

初始化和后置语句可以省略。只带条件的`for`语句，作用和其他语言里的`while`循环相同。Go 里没有`while`关键字。

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### 无限循环

`for`语句也可以不写条件：

```go
for {
    // loop body
}
```

这个循环不会自行终止。必须显式地离开循环，例如使用`break`或`return`。

## 控制循环

### `break` 和 `continue`

在这个循环里，`break`会退出循环：

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue`会跳过当前循环体剩下的部分，开始下一次迭代：

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### 带标签的 `break` 和 `continue`

在嵌套循环中，不带标签的`break`或`continue`作用于最内层的循环。
要给外层循环加标签，就在它正上方的一行写一个标识符，后面跟一个冒号。然后把该循环的标签写在`break`或`continue`后面，就能把操作指向这个循环：

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
