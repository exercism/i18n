# 关于

Bash 是一门你会渐渐爱上的语言！

日常电脑上的许多任务，都能用它写出的简洁脚本完成。你很快就会发现，虽然大多数事情都能通过图形用户界面来做，但用这门强大的语言其实会快得多！命令解释器通常运行在文本窗口中，用户可以在其中输入命令（操作也可以来自某些文件，也就是所谓的 Bash 脚本）。

更正式地说，Bash（**B**ourne-**a**gain **sh**ell 的缩写，是围绕 Bourne shell 和“born-again”一词的双关）是一个 Unix 命令解释器。相比其他几种 shell，它提供了许多改进（Bash 在命令历史、作业控制和命令行编辑方面都有一些实用的功能）。

理解 Bash 的一个很好的方式是这样的：

> 虽然大多数用户把 shell 看作一个交互式命令解释器，但它实际上是一门编程语言，其中的每条语句都会运行一条命令。由于它必须同时满足命令执行的交互性和编程性，所以它是一门奇特的语言，既由设计塑造，也由历史塑造。（Brian Kernighan 与 Rob Pike）

_引用：Kernighan, Brian W.; Pike, Rob (1984). The UNIX Programming Environment. Englewood Cliffs: Prentice-Hall. ISBN 0-13-937699-2._

尽管 Bash 由自由软件基金会的 Brian Fox 编写，并在几十年前首次发布，但它如今依然在世界各地每天被使用！从自动化到把一个项目的各部分拼接起来，这门语言依然和过去一样用途广泛。这门语言年代久远带来的另一个好处，是你能找到围绕它的丰富文档。如果你哪天卡住了，不清楚该怎么完成一个练习，一个很好的起点就是内置帮助，用`info bash`或`man bash`就能打开。

这个 track 旨在帮助你在这样一门奇妙的脚本语言上积累一些经验。

**祝你 Bash 愉快！**
