# 说明

你是一位热心的观鸟爱好者，一直在记录过去七天里有多少只鸟来过你的花园。

你有六个任务，全都和来你花园的鸟的数量有关。

## 1. 查看上周的计数是多少

为了便于比较，你总是把上周的计数留一份在手边，它们是：0、2、5、3、7、8 和 4。定义`lastWeek`绑定，用来存放上周的计数：

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. 查看昨天有多少只鸟来访

实现`yesterday`函数，返回昨天来你花园的鸟的数量。鸟类计数按天排列：第一个元素是最早那天的计数，最后一个元素是今天的计数。

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. 计算来访鸟的总数

实现`total`函数，返回来你花园的鸟的总数：

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. 检查是否有哪天没有鸟来访

实现`dayWithoutBirds`函数，如果有一天没有鸟来花园，就返回`true`；否则返回`false`：

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. 自增今天的计数

实现`incrementTodaysCount`函数，把今天的计数自增，并返回更新后的计数：

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. 检查是否有不寻常的一周

在过去一年里，你发现有些星期会出现同样的、不寻常的模式：
- 每周的偶数天，都没有鸟
- 每周的偶数天，正好看到 10 只鸟
- 每周的奇数天，正好看到 5 只鸟

实现`unusualWeek`函数，如果这一周的鸟类计数模式符合其中一种不寻常模式，就返回`true`：

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

（注意，天的奇偶性从 1 开始计数，而不是从 0 开始，数组的第一个元素对应奇数天）
