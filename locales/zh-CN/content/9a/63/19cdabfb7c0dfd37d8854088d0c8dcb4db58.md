# 关于

只要给方法的形参指定一个默认值，它就会变成可选参数。形参可选时，调用方不必再为它提供实参，这时会使用默认值。可选参数_必须_放在参数列表的末尾，后面不能再跟非可选参数。如果方法有多个可选参数，你可以用命名实参只指定其中一部分。

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

可选参数的值必须是下面之一：

- 常量表达式（例如`"hi"`、`2`、`DayOfWeek.Friday`、`null`等）
- 值类型的`new`表达式
- 值类型的`default`表达式
