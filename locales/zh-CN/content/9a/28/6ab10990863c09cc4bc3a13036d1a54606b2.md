# 关于

Elm 把自己描述为一门“用于构建可靠 Web 应用的令人愉悦的语言”。它的目标是打造性能出色、且不会出现运行时异常的 Web 应用。

具体来说，它是一门会编译成 JavaScript 的函数式编程语言。它的语法和特性源自 ML 系语言，例如 Haskell，但[特别强调易学与简洁][blog-syntax]。

你可以在官方网站 [elm-lang.org][elm-lang] 上了解更多关于 Elm 的信息。初学者可以先看 Elm 指南，地址是 [guide.elm-lang.org][guide]。
