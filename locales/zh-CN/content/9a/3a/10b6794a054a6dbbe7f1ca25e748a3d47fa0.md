# 关于

默认情况下，变量的作用域仅限于定义它的那层作用域。如果变量定义在函数或类之外的某个文件里，它的作用域就仅限于这个文件；如果定义在函数或类中，作用域就仅限于该函数或类。

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## 全局作用域

在变量赋值前使用关键字`global`，可以创建一个全局作用域的变量。这种写法通常并不推荐，因为它会造成[紧耦合的代码](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>)。

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## 静态作用域

在变量赋值或声明前使用关键字`static`，变量的作用域保持不变，但它的值会在不同的执行作用域之间保留下来。

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

在这个例子中，`$count`变量_只在第一次调用函数时_才会被初始化为 0。之后每次调用，这个值都会延续到下一次调用。因此，每次调用该函数都会返回一个递增的整数。
