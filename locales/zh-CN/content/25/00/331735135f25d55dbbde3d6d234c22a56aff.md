# 关于

关于 C# 字符串，需要记住的关键一点是：它们是表示文本的不可变对象，文本由一系列 Unicode 字符（字母、数字、标点等）组成。双引号用于定义`string`实例：

```csharp
string fruit = "Apple";
```

操作字符串可以通过调用它的某个[方法][methods]或[属性][properties]来完成。由于字符串值一经定义就永远无法更改，所有字符串操作方法都会返回一个新字符串。

字符串由双引号（`"`）字符分隔。有些特殊字符需要使用反斜杠（`\`）字符进行[转义][escaping]。字符串还可以加上 at（`@`）符号前缀，使其成为[逐字字符串][verbatim]，从而忽略任何转义字符。

```csharp
string escaped = "c:\\test.txt";
string verbatim = @"c:\test.txt";
escaped == verbatim;
// => true
```

如果只需要字符串的一部分，可以使用[`Substring()`方法][substring]来提取那一部分：

```csharp
string sentence = "Frank chases the bus.";
string name = sentence.Substring(0, 5);
// => "Frank"
```

[`IndexOf`()方法][indexof]可用于查找某个`string`在另一个`string`中第一次出现的下标，如果找不到指定值则返回`-1`：

```csharp
"continuous-integration".IndexOf("integration")
// => 11

"continuous-integration".IndexOf("deployment")
// => -1
```

最后，[拼接字符串的方法有很多][concatenation]。最简单的方法是使用[`+`运算符][plus-operator]。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

对于比简单拼接更复杂的字符串格式设置，首选[字符串内插][interpolation]。要在字符串中启用内插，请在它前面加上美元（`$`）符号。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
