# 说明

当 Lisp 外星人第一次来到地球时，他们遇到了无数稀奇古怪又妙不可言的东西，但他们最喜欢的发现之一是“宠物”。说实话，有哪个外星人不会对小狗或小猫赞不绝口呢？

Ludwig 最近去地球度了个假，回来后决定自己也要养一只宠物！唯一的问题是？选择实在太多了！也许你可以写一个程序，帮 Ludwig 找到并照顾下一位可以抱在怀里的伙伴？

## 1. 挑选伙伴

虽然 Ludwig 打定主意要养宠物，但他们的思考也就到此为止了。那么，第一步就是决定养哪种宠物！

Ludwig 想找一个性格与自己互补的伙伴。你能给 Ludwig 写一个名为`pal-picker`的函数吗？它接收某种性格特征（一个关键字），并返回具有该特征的宠物类型（一个字符串）。

具体来说：

- `:lazy` -> `"Cat"`
- `:energetic` -> `"Dog"`
- `:quiet` -> `"Fish"`
- `:hungry` -> `"Rabbit"`
- `:talkative` -> `"Bird"`

对于其他未知的性格，你的函数应当求值为：`"I don't know... A dragon?"`

```lisp
(pal-picker :quiet) ; => "Fish"
```

## 2. 在自然栖息地中

现在 Ludwig 有了新朋友，还需要一个住的地方！你能帮 Ludwig 为宠物挑选合适尺寸的床 / 水缸 / 笼子吗？

这里，Ludwig 需要一个名为`habitat-fitter`的函数，根据宠物的体重（以千克为单位的整数）来选择合适的栖息地尺寸（一个关键字）。

每种体型的宠物所需的栖息地分别是：

- 大于或等于 40 千克 -> `:massive`
- 20 千克到 39 千克（含）-> `:large`
- 10 千克到 19 千克（含）-> `:medium`
- 1 千克到 9 千克（含）-> `:small`
- 小于或等于 0 千克 -> `:just-your-imagination`

```lisp
(habitat-fitter 42) ; => :MASSIVE
```

## 3. 现在，开饭吧

所有地球宠物都有一个共同点：它们需要食物！不过，这个概念对 Ludwig 来说有点陌生，因为他们总是忘记给宠物的食盆添食。

Ludwig 可以用一个名为`feeding-time`的简单函数，在食盆需要添食时提醒他们。该函数接收饱食度百分比（一个整数），并以字符串的形式返回一条消息。

如果食物量：

- 高于 20% -> `"All is well."`
- 等于或低于 20% -> `"It's feeding time!"`

```lisp
(feeding-time 15) ; => "It's feeding time!"
```

## 4. 行为准则

把基本的都安排妥当后，Ludwig 正期待着尝试各种有趣的事，比如“抚摸”和玩“捡东西”游戏。话虽如此，并不是每只宠物都适合这些活动。

Ludwig 想要一对函数，`pet`和`play-fetch`，它们接收宠物的类型（一个字符串），如果动作不合适，就返回空值或一条类似`"Maybe not with this pet..."`的消息。

假设只有`"Dog"`会玩捡东西，并且除了`"Fish"`之外的所有宠物都可以被抚摸。

```lisp
(pet "Dog")         ; => NIL
(play-fetch "Fish") ; => "Maybe not with this pet..."
```
