# 关于

[元组](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples)是一种_不可变_的分组，其中的值没有名字，但顺序固定。元组可以存放任意一种（也可以是多种）数据类型，也包括其他元组。

元组的写法是用逗号分隔的值，放在`(`和`)`之间：`(<element_1>, ... , <element_n>)`。

```fsharp
("one", 2) // Tuple pair (2 values)
("one", 2, true) // Tuple triplet (3 values)
```

只有长度相同、类型相同（顺序也相同）的元组才能相互比较。元组具有结构相等性，也就是说，只有所有值都相等，两个元组才相等。

```fsharp
(1, 2) = (1, 2) // Same length, same types, same values, same order
// => true

(1, 2) = (2, 1) // Same length, same types, same values, different order
// => false

(1, 2) = (1, "2") // Same length, different types
// compiler error

(1, 2) = (1, 2, 3) // Different length
// compiler error
```

从元组中提取值有[三种方式](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values)：

- `fst`和`snd`函数
- 元组解构
- 模式匹配

```fsharp
let person = ("Jordan", 170)

// Option 1: fst/snd
let name1 = fst person
let length1 = snd person

// Option 2: deconstruction
let (name2, length2) = person

// Option 3: pattern matching
match person with
| name3, length3 -> printf "%s: %d" name3 length3
```

~~~~exercism/note
严格来说，你可以用元组的`.Item1`、`.Item2`等属性来访问它的值，但不推荐这么做，这会让编译器给出警告。
~~~~

## 元组的要点

关于元组，有几点需要了解：

- 某个具体的元组类型实例是一个单独的对象，类似于 C# 中的双元素数组。把它和函数一起使用时，它只算作一个形参。唯一的例外是调用带多个形参的非 F# 代码：这时你传入一个元组，它的各个值会自动提取出来，对应到相应的形参值。
- 无法给元组类型指定显式的名字。元组类型的“名字”取决于参与相乘的类型组合。
- 定义元组的关键符号是逗号，而不是括号。你可以不带括号地定义元组，尽管有时会让人困惑。在 F# 中，只要看到逗号，它多半就是某个元组的一部分。
- 元组可以用作函数的实参，也可以作为函数的返回值。
