# 说明

你在记录每天有多少只鸟来你的花园。数据以整数数组的形式存储，**今天的数量排在最前面**。

## 1. 今天的数量

定义 `today`，从栈上取出一个每日数量的数组，返回今天的数量；如果数组为空，返回 `f`。

```factor
{ 2 5 1 } today .
! => 2

{ } today .
! => f
```

## 2. 让今天的数量自增

定义 `increment-day-count`，返回一个新数组，其中今天的数量加一。如果输入为空，返回 `{ 1 }`。

```factor
{ 4 0 2 } increment-day-count .
! => { 5 0 2 }

{ } increment-day-count .
! => { 1 }
```

## 3. 有没有哪一天没有鸟？

定义 `has-day-without-birds?`，如果至少有一天记录的鸟数为零，返回 `t`，否则返回 `f`。

**使用递归**，而不要用 `any?` 或其他高阶序列词。

```factor
{ 2 0 4 } has-day-without-birds? .   ! => t
{ 3 8 1 5 } has-day-without-birds? . ! => f
```

## 4. 从开始记录至今的鸟总数

定义 `total`，返回所有数量的总和。

**使用递归**，而不要用 `sum`。

```factor
{ 4 0 9 0 5 } total .
! => 18
```

## 5. 忙碌的日子

忙碌的日子是指有 5 只或更多鸟的一天。定义 `busy-days`，返回忙碌日子的数量。

**使用递归**，而不要用 `count`。

```factor
{ 4 5 0 0 6 } busy-days .
! => 2
```
