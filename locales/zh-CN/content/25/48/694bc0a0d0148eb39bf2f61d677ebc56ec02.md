# 说明

你是 IT 服务台的一员，你想改进工单系统，让它更高效，并为你的经理提供统计数据。

一张工单有一个状态（new、in progress……），有一个创建者（由用户名和员工编号标识），可以分配给某位 IT 员工，并包含评论历史。

下面有四个任务，它们能改进你当前的工单系统。

## 1. 检测空评论

空评论会让界面变得杂乱，又不提供任何信息，你想把它们过滤掉。

定义一个辅助函数`emptyComment`，它接收一个用户/评论对，并对空评论返回`True`。

直接在函数参数中使用解构来提取用户和评论。用不到用户信息，可以忽略它。

```elm
emptyComment ( User "Alice", "" )
-- => True
```

## 2. 统计创建者发表的评论数

你的经理想要了解用户在工单流程中参与情况的统计数据。
她让你查看工单创建者添加了多少条评论。

定义`numberOfCreatorComments`，它接收一张工单，并返回工单创建者添加的评论数。

在函数参数中使用解构，从`Ticket`类型中提取记录，同时提取你需要的字段。
然后，在`let`绑定中对`createdBy`进行解构，这样你就能统计相关评论了。
使用`List`函数来完成计数，并在匿名函数的参数中使用解构，把用户/评论对分开。

```elm
numberOfCreatorComments
numberOfCreatorComments
    (Ticket
        { status = Closed
        , createdBy = ( User "Chiaki", 1 )
        , assignedTo = Nothing
        , comments = [ ( User "Chiaki", "Never mind, fixed it." ) ]
        }
    )
-- => 1
```

## 3. 检测分配给开发团队的工单

有些工单必须上报给开发团队的 Alice、Bob 或 Charlie。
密切关注这些工单、确保它们在推进，这一点很重要。

定义一个辅助函数`assignedToDevTeam`，检查一张工单是否分配给了开发团队的成员。

在函数参数中使用解构，从`Ticket`类型中提取记录以及你需要的字段。
然后，使用单个`case`语句来检查工单是否分配给了 Alice、Bob 或 Charlie：用递归模式匹配提取他们的用户名，用字面量模式匹配来匹配它们。

```elm
assignedToDevTeam
    (Ticket
        { status = InProgress
        , createdBy = ( User "Bill", 2 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Bill", "What's an 'undefined'?" ) ]
        }
    )
-- => True
```

## 4. 把工单分配给 IT 员工

有时一批工单需要重新分配给其他 IT 员工。

定义一个函数`assignTicketTo`来帮你完成这件事。这个函数接收两个参数：要分配工单的目标用户，以及一张工单。
如果工单的状态是`New`，就把它分配给新用户，并把状态改为`InProgress`。
对于其他状态，只需把工单重新分配给新用户；但状态为`Archived`的工单除外，它们完全不应该被修改。

在函数参数中使用解构，从`Ticket`类型中提取记录以及你需要的字段，同时使用`as`关键字按原样捕获整个记录。
使用单个`case`语句对状态进行模式匹配，并返回相应的工单，这个工单由你通过`as`关键字捕获的原始记录修改而来。

```elm
assignTicketTo (User "Danny")
    (Ticket
        { status = New
        , createdBy = ( User "Jesse", 3 )
        , assignedTo = Just (User "Alice")
        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
        }
    )
-- => Ticket

--        , createdBy = ( User "Jesse", 3 )
--        , assignedTo = Just (User "Danny")
--        , comments = [ ( User "Jesse", "I've been waiting for 6 months!!" ) ]
--        }
```
