# 位运算简介

Java 提供了一些运算符，用来操作`byte`、`short`、`int`、`long`或`char`的各个位。

## 移位运算符

使用`<<`将位向左移，使用`>>`将位向右移。

```java
// Shift two places to the left
0b0000_1011 << 2;
// # => 0b0010_1100

// Shift two places to the right
0b0000_1011 >> 2;
// # => 0b0000_0010
```

`<<`运算符总是在右侧插入 0。不过，`>>`插入的位与最左边一位相同（如果该数是负数则为 1，是正数则为 0）。

```java
// Shift 2 places to the right preserves the sign
// This is a negative value, whose binary representation is
// 1000_0000_0000_0000_0000_0000_0010_0110
int value = -0x7FFFFFDA;

// Shift two places to the right, preserving the sign bit
value >> 2;
// # => 1110_0000_0000_0000_0000_0000_0000_1001
```

如果向右移位时需要插入 0，就改用`>>>`。

```java
// Shift two places to the right, inserting 0s on the left
value >>> 2;
// # => 0010_0000_0000_0000_0000_0000_0000_1001
```

## 按位运算

### 按位与

按位与运算符（`&`）接收两个值，对每一位执行与运算。它会把第一个值的每一位与第二个值中相同位置的位进行比较。如果两者都为 1，结果的对应位就是 1。否则，结果的对应位就是 0。

```java
0b0110_0101 & 0b0011_1100;
// # => 0b0010_0100
```

### 按位或

按位或运算符（`|`）接收两个值，对每一位执行或运算。它会把第一个值的每一位与第二个值中相同位置的位进行比较。只要有任意一位是 1，结果的对应位就是 1。否则就是 0。

```java
0b0110_0101 | 0b0011_1100;
// # => 0b0111_1101
```

### 按位异或

按位异或运算符（`^`）对两个值执行按位异或运算。与按位与、按位或运算符一样，它会把第一个值的每一位与第二个值中相同位置的位进行比较。如果其中只有一位是 1，结果的对应位就是 1。否则就是 0。

```java
0b0110_0101 ^ 0b0011_1100;
// # => 0b0101_1001
```

### 按位非（`~`）

最后，按位非运算符（`~`）会翻转每一位。与前面的运算符不同，这是一个一元运算符，只作用于一个值。

```java
~0b0110_0101;
// # => 0b1001_1010
```
