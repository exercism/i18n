# 提示

## 1. 创建一位新居民

- 回顾[struct 概念](/tracks/go/concepts/structs)，了解如何创建 struct。

## 2. 验证居民信息

- 字符串的零值是 `""`。
- map 的零值是 `nil`。
- 回顾[map 概念](/tracks/go/concepts/maps)，了解如何判断某个 map 键是否存在。

## 3. 删除居民信息

- 当一位居民的所有字段都被设为零值时，就认为该居民已被删除。
- 回顾[零值概念](/tracks/go/concepts/zero-values)，了解每种 Go 类型的零值。

## 4. 统计居民数量

- 回顾[range 迭代概念](/tracks/go/concepts/range-iteration)，了解如何用 range 遍历切片。
