# 说明

你的朋友 Linus 是一名火车司机，在城市之间驾驶货运列车。虽然他非常擅长摆弄火车，但在处理物流和电脑方面就不太在行了。他想请你用编程帮他整理列车信息，并修正路线数据中的错误。

~~~~exercism/note
这道练习用切片、索引和各种`Dict`方法就能轻松解决。不过，我们希望你在完成下面每个任务时，练习打包（即 slurping）、解包（即 splatting）和多重赋值。
~~~~

## 1. 创建包含所有车厢的向量

你的朋友一直在记录每个车厢的标识符（ID），但他从不确定系统在某一时刻需要处理多少节车厢。如果把这些数据打包成一个统一的`Vector`，物流程序的其余部分就会轻松得多。

实现一个函数`get_vector_of_wagons(args...)`，它接受任意数量的车厢 ID。每个 ID 都是一个正整数。函数随后应当把这些 ID 作为单个`Vector` `return`。

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. 修正车厢向量

到这里，你已经开始了解这些数据以及它们在物流程序中的用法。ID 系统总是给机车分配**1**这个 ID，列车上其余的车厢则被分配一个大于**1**的随机 ID。

你的朋友把两节新车厢挂到了列车上，却忘了更新系统！现在，列车`Vector`中的前两节车厢必须移到末尾，否则整个顺序都会乱掉。

更麻烦的是，你的朋友刚发现第二个`Vector`，里面似乎装着缺失的车厢 ID。他唯一记得的是，新车厢移好之后，第二个`Vector`中的 ID 应当直接放在指定机车的后面。

如果你能帮他改正错误并整理好数据，Linus 会非常感激。

实现一个函数`fix_vector_of_wagons(each_wagons_id, missing_wagons)`，它接受两个包含车厢 ID 的`Vector`。它应当把第一个`Vector`的前两项移到末尾，并把第二个`Vector`中的值插入到机车 ID（**1**）之后（_也就是它的右侧_）。然后函数应当`return`修改后的`Vector`。

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. 添加缺失的站点

现在所有车厢数据都正确了，Linus 想请你更新系统的路线信息。在一条运输路线上，列车可能会在几个不同的车站停靠，装卸货物。每趟行程的这类中途交付点数量可能各不相同。你的朋友想请你在系统的路线`Dict`中补上缺失或额外的交付信息。

实现一个函数`add_missing_stops(route, stops...)`，它接受一个路线`Dict`，后面跟可变数量的`stop_number => city` Pair。函数随后应当返回更新后的路线`Dict`，其中额外多了一个`key`，它的值是按顺序排列的所有新增站点的`Vectors`。

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. 扩展路线信息

Linus 一直在开发路线程序，他注意到有些路线缺少一些重要细节。初始路线信息是用`Dict`构建的，你的朋友想请你在那个`Dict`里补上可能缺失的内容。系统中的每条路线所需的细节都略有不同，所以 Linus 很希望有一个通用的解决方案。

实现一个名为`extend_route_information(route; more_route_information...)`的函数，它接受一个`Dict`，其中包含列车路线往返的起点和终点城市，再加上可变数量的关键字参数，参数中包含列车速度、长度或温度等路线细节。函数应当返回一个合并了所有路线信息的`Dict`。

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
