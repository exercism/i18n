# 说明

你是一位狂热的观鸟爱好者，会记录每天有多少只鸟造访你的花园。

你决定把观鸟提升到一个新的水平，实现几个工具来帮助你记录和处理这些数据。

你选择把数据存储为整数数组。
数组中的第一个数字是今天造访你花园的鸟的数量，第二个是昨天的，以此类推。

```exercism/note
在真实的应用中，只要适用，就应该始终使用核心模块；不过为了学习递归，本练习中不要使用任何 `List` 函数。
```

## 1. 检查今天有多少只鸟造访

实现 `today` 函数。
它应该接收一个每日鸟数量的数组，并返回今天的数量。
如果数组为空，它应该返回 `Nothing`，否则数量会被包装在 `Just` 中。

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. 增加今天的数量

实现 `incrementDayCount` 函数。
它应该接收一个每日鸟数量的数组，并把今天的数量增加 1。
如果数组为空，返回 `[1]`。

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. 检查是否存在没有鸟造访的日子

实现 `hasDayWithoutBirds` 函数。
它应该接收一个每日鸟数量的数组。
如果至少有一天没有鸟造访花园，它应该返回 `True`，否则返回 `False`。

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. 计算造访鸟的总数

实现 `total` 函数。
它应该接收一个每日鸟数量的数组，并返回自你开始收集数据以来造访花园的鸟的总数。

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. 计算忙碌日子的数量

有些日子比其他日子更忙。
忙碌的日子是指有 5 只或更多鸟造访你花园的日子。

实现 `busyDays` 函数。
它应该接收一个每日鸟数量的数组，并返回忙碌日子的数量。

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
