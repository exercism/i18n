# 说明

在这个练习中，我们来试着解决一个经典问题。

Bob 是个小偷。经过数月的精心策划，他终于成功破解了一幢高档公寓的安保系统。

他面前摆着许多物品，每件物品都有一个价值（v）和一个重量（w）。Bob 当然想让拿到的总价值尽可能大；只要拿得动，他会很乐意把所有物品都拿走。然而，令他惊恐的是，他发现自己随身携带的背包只能承受有限的重量（W）。

给定一个承重上限为 W 的背包，请帮 Bob 算出他能从这间屋子里的物品中获得的最高价值。注意，每件物品 Bob 只能拿一件。

给出的所有价值都是严格正数。物品会以一个数组的形式给出，每件物品都有重量和价值。

例如：

```none
Items: [
  { "weight": 5, "value": 10 },
  { "weight": 4, "value": 40 },
  { "weight": 6, "value": 30 },
  { "weight": 4, "value": 50 }
]

Knapsack Limit: 10
```

在上面的例子中，第一件物品重量为 5、价值为 10，第二件物品重量为 4、价值为 40，以此类推。

在这个例子里，Bob 应该拿走第二件和第四件物品，才能让价值最大化，在本例中是 90。他不可能拿到超过 90 的价值，因为背包的重量上限是 10。
