# 说明补充

这是一个很好的练习，可以用来尝试非标准字符串字面量和元编程。

这篇[博客文章](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html)简要介绍了非标准字符串字面量。详细的元编程指南可以在[手册](https://docs.julialang.org/en/v1/manual/metaprogramming/)中找到。

你可以通过添加下面描述的功能来扩展你提交的解答。

加分题 A 只需要博客文章中介绍的基础知识。加分题 B 则需要对 Julia 元编程有深入得多的了解。

## 加分题 A
实现一个字符串字面量，让它对字符串起到 `ROT13` 的作用：
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## 加分题 B
实现字符串字面量 `R<i>`（`i = 0, ..., 26`），它们会按照 `i` 的值对字符串进行移位：
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
