# 维护者须知

## 用于创建 Fortran 测试的辅助脚本：create_fortran_test.py

创建练习测试的一个简单方法是使用脚本`bin/create\_fortran\_test.py`。

用这个脚本生成一个初始的 <exercise>\_test.f90 文件，它可以作为你编写测试的模板。通常，你需要把生成文件里的“response”函数替换成正确的函数调用。

另外要注意，Fortran 对 `\n` 和 `\t` 这类特殊字符有问题，处理它们时要格外小心。

### 前提条件

- 可用的 CMake 和 Fortran 编译器
- Python3.x（你也许能让它在 Python2 上运行，但我没有花功夫让它向下兼容）
- https://github.com/exercism/problem-specifications.git 的最新版本
- git

### 创建新测试的工作流

- 从`exercism/problem-specifications`拉取最新改动，例如 git clone git@github.com:exercism/problem-specifications.git
- 为创建新练习新建一个分支，例如 git checkout -b exercise-bob
- 针对你想创建的示例运行这个脚本
- 把`config/CMakeLists.txt`复制到练习目录（可以用`bin/update-cmake-files`来完成）
- 实现一个可以正常运行的练习
- 修复可能有问题的测试（参见 exercise/bob 的“Test 20”和“Test 24”）
- 确保`ctest`命令能无错误地完成验证
- 把你的解答复制到 .meta/example.f90，再从练习文件（例如 bob.f90）中删掉实际的实现
- 更新 .docs 和 .meta 目录
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - 把“# Description”替换为“# Instructions”
  - 手动填写 .meta/tests.toml（在有自动化方式之前）
  - 手动填写 .meta/config.json（在有自动化方式之前）
    - 参考 ../problem-specifications/exercises/bob/metadata.yml
- 针对你的改动发起一个拉取请求

以 bob 为例：

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### 修改`CMakeLists.txt`

修改 cmake 文件时，要更新`config/`里的主副本，并用`bin/update-cmake-files`把它复制到所有练习目录。

## 解答

准备好解答后，把它作为“example.f90”复制到“.meta”目录。

也许你想留下一个函数或子程序的骨架实现，方便学生参考，同时把文件名与练习名相同的那个文件留在练习目录里。
