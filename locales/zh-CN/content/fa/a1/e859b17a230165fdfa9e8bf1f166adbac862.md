# 提示

## 通用

- 每个任务都在循环里构建文本，所以每个任务都以`#FSTR`开头，以`.str`结尾。
- 把每个`+`的结果都赋值回构建器：`script := script + ...`。

## 1. 重复一条提示

- `1.upto!(times)`会按正确的次数运行循环。它给出的值用不上，所以可以直接存进一个从不使用的变量，或者改用`times.times!`，它什么都不返回。
- 次数为零也不需要特殊处理：循环根本不会运行。

## 2. 演员名字的首字母

- `names.elt!`会给出每个名字；`[0]`取它的第一个字符。
- `FSTR`可以直接接受`CHAR`，所以不需要先把它转换成字符串。

## 3. 给各行编号

- 像上一个练习那样，在一个循环里用两个迭代器：用`1.up!`取编号，用`lines.elt!`取文本。
- 换行要加在除第一行之外的每一行*之前*。最简单的办法是判断编号：`if number > 1 then ... end`。
- `FSTR`可以直接接受数字，所以`script + number + ". "`不用转换就能用。

## 4. 大声念出一行

- `line.elt!`会逐个字符遍历字符串。
- `.upper`不会改动任何非字母字符，所以空格不需要特殊处理。
