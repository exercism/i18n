# 安装

安装 PureScript 最简单的方式是通过 Node.js 和 NPM。

如果你的电脑上还没有安装 Node.js，可以从[Node.js 官网](https://nodejs.org/)下载。等 Node.js 装好并能运行之后，在终端中输入下面这条命令，即可安装 PureScript 编译器和 Spago 构建工具：

    npm install --global purescript spago

更多信息参见[PureScript 代码仓库](https://github.com/purescript/purescript/blob/master/INSTALL.md)。
