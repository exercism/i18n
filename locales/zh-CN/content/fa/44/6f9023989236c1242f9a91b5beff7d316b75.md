# 简介

_“日期和时间这种东西，我们连小孩子都教。这能有多难？”_

许多程序员都犯过这个错误，而随之而来的经历往往会对他们的健康和幸福感造成不小的伤害。

任何要用日期和时间做稍微复杂一点的编程的人，至少都应该做好准备，去理解并减轻可能出现的问题。

本文会尝试概述 Julia 如何处理日期和时间，但要了解更详细的细节，还是得查阅[手册][Dates]。
还有一本 [Wikibook][Wikibook]，有些读者可能觉得它的讲解更清楚，其中还附有一张很有帮助的[类型层级图][type-hierarchy]。

## `Dates`模块

大部分基础功能都在`Dates`模块里。它随默认安装一起提供，但并不属于标准库。

要使用这个模块，有两种方式：

1. 加上 `import Dates`，然后在所有函数调用前面加上 `Dates.`
2. 加上 `using Dates`，这会把整个模块引入当前命名空间（_除了少数有问题的名字_）。

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

`Dates`模块既庞大又复杂，但它提供四大类功能：

- `Dates.Date`：包含年月日，但不包含一天中的时间。
- `Dates.Time`：包含一天中的时间，但不包含日期。
- `Dates.DateTime`：把日期和时间合在一起。
- `Dates.Period`：处理时间/日期间隔。

请注意，`DateTime` 通常_不_包含时区信息（Python 会把这种对象称为“naive”日期时间）。
一个例外是 `now()`：它从系统时钟获取本地时间，必要时还可以把它转换成 UTC。

最常见的使用场景大概是：

- 解析合适的输入格式，构造出`Dates`类型。
- 从`Dates`类型中取出所需的数字或字符串格式。
- 给`Date`、`Time`或`DateTime`值加上偏移量。
- 计算两个这样的值之间的间隔。
- 获取当前日期（用`today()`）和/或时间（用`now()`）。

~~~~exercism/note
为了减少视觉干扰，本文其余部分的大部分示例代码都假设已经 `using Dates`，并且不再在函数调用中写出模块名 `Dates.`。
~~~~

### 日期和时间格式

日期和时间的写法有很多种，而且往往因文化而异。
像“7/6/23”这样全用数字的日期既含糊又让人困惑，在跨国公司里已经酿成了许多代价高昂的错误（_作者本人就吃过这个苦头_）。

国际标准由 `ISO 8601` 定义，它有两个主要优点：

- 解析快速且没有歧义。
- 排序很容易，因为日期时间可以当作普通文本，按字母顺序排序。

在前面的例子里，我们见过 `Date.now()` 返回 `2025-06-21T16:03:04.161`。

它由几个部分组成：

- `YYYY-MM-DD`是日期部分。
- `hh:mm:ss`是时间部分。
- 小数点后面可选地跟上毫秒（或更小的单位）。

其他字符串格式会在后面的小节里讨论。

## 日期

`Dates.Date`是一种相对简单的、只表示日期的类型，它不了解时间，也不了解时区。

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

有一些访问函数可以取出日期中的各个部分，而且它们成对出现，用大小写区分。

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### 查询函数

有各种函数对日历有一定了解。
下面这个例子只展示了其中几个。

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## 时间

`Dates.Time`是基本的、只表示时间的类型。
它不了解日期：到了午夜，时间会自动回到 `Time(0, 0, 0)`。

完整的构造函数格式是 `Time(hour, min, sec, millisec, microsec)`，或者等价的 ISO 8601 写法。

所有参数都是可选的，默认值为 `0`。

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

和`Date`一样，各个部分可以用访问函数取得：

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## 日期时间

`Dates.DateTime`结合了`Date`和`Time`类型的大部分特性。

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

年、月、日参数默认为 `1`，时间参数都默认为 `0`。

要记住所有这些参数的顺序并不容易，所以输入时用 ISO 格式可能更好。

另外，也可以像上面的例子那样，用`Date`和`Time`构造出一个`DateTime`。

## 时间段

日期/时间的每个组成部分都有自己的`Period`类型，从`Year`一直到`Nanosecond`，表示一段时间间隔。
它们在算术运算里特别有用。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

处理`Period`类型时，Julia 会尽量智能地应对月份长度之类的日历不规则情况，必要时进行舍入。

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## 字符串表示

前面提到过 ISO 8601 标准，它是 Julia 在格式化或解析字符串时默认采用的日期/时间表示方式。

显然，还有很多其他格式被频繁使用，而且往往带有文化特色。
为了处理这些格式，Julia 提供了 `DateFormat` 类型，它可以用任意复杂度的格式字符串构造出来。

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

上面的例子非常简单，只是一个欧洲常见的日/月/年格式的日期。
这里展示了两种语法写法，但结果完全相同。

之后就可以用 `DateFormat` 来解析任何合适的字符串：

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

创建 `DateFormat` 的开销不小，所以（像这里用 `dtfmt` 那样）只做一次，在循环处理大量日期/时间字符串时对性能很有帮助。

格式可以比这复杂得多，详情请查阅[手册][dateformat]。

同一个 `DateFormat` 也可以用来把日期/时间输出成任意想要的字符串格式，用的是 [`Dates.format()`][format] 函数。

遗憾的是，`format` 似乎存在命名空间冲突（至少在 Julia 1.11.5 里是这样），所以即使在 `using Dates` 之后，最好也加上 `Dates.` 前缀。

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

如[文档][wiki-format]所述，`"e, u d"` 给出的是星期几和月份的缩写文本表示。

文本表示默认是英语。
也可以添加其他语言，不过目前这方面的支持还不尽如人意。
