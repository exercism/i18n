# 说明

一些“其他”开发者一直在开发遥控车项目的练习[csharp/remote-control-competition]()。现在请你来清理这些代码。

## 1. 分离汽车本身与遥测系统之间的关注点

重构`RemoteControlCar`类，把遥测方法和属性分离出去，改为通过`Telemetry`属性访问。

```csharp
var car = new RemoteControlCar();
car.Telemetry.Calibrate();
car.Telemetry.SelfTest();
car.Telemetry.ShowSponsor("Walker Industries Inc.");
car.CurrentSponsor
// => "Walker Industries Inc."
car.Telemetry.SetSpeed(100, "cps");
car.GetSpeed()
// => "100 centimeters per second"
```

## 2. 防止其他代码对 Telemetry 类型产生过多依赖

确保`Telemetry`实例不能在汽车的作用域之外创建。

## 3. 防止其他代码依赖 Speed 结构体

确保`Speed`结构体不能在`RemoteControlCar`类的作用域之外使用。

## 4. 防止其他代码依赖 SpeedUnits 枚举

确保`SpeedUnits`枚举不能在`RemoteControlCar`类的作用域之外使用。
