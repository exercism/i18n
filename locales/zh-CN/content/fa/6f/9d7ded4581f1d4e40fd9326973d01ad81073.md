# 简介

## 字符串

在 Common Lisp 中，字符串是[字符][concept-characters]的[向量][concept-vectors]。字符串写成用双引号括起来的一串字符（_例如_ "Hello World!"）。

只有当给定的值是字符串时，`stringp`谓词才会返回 true。

可以用`subseq`函数把字符串拆分成子字符串，它接收一个字符串、一个起始下标，以及一个可选的结束下标。下标从 0 开始。

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

可以用`string=`比较字符串是否相等。如果要忽略字符的大小写，可以用`string-equal`。

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

字符串的大小写转换，比如转成大写、转成小写和首字母大写，可以分别用`string-upcase`、`string-downcase`和`string-capitalize`完成。

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
