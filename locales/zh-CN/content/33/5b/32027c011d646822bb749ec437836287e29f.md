# 导入

[特殊形式 `import`][import]让你无需写出模块名，就能使用外部模块中的函数和宏。

导入整个外部模块可能会与已有的本地函数产生冲突。为了避免这种情况，有两个可选项：`:except`和`:only`。两者都接受一个关键字列表，其中键是函数名，值是函数的参数个数。

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

导入通常写在模块定义的开头，但也可以写在任何位置。导入具有词法作用域，这意味着在某个函数定义内部添加的导入，在另一个函数里是不可用的。

未使用的导入会触发编译器警告。

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
