# 说明

在这个练习中，你将编写代码，记录一份你想在 Exercism 上学习的编程语言数组。

共有 9 个任务，每一个都要和数组打交道。

## 1. 创建一个新数组

为了记录你想学习的语言，你需要创建一个新数组。

实现静态方法 `Languages.NewList()`，让它返回一个新的空数组。

```csharp
Languages.NewList()
// => empty list
```

## 2. 定义一个已有的数组

目前，你手上有张纸，上面列出了你想学习的语言：C#、Clojure 和 Elm。

请实现静态方法 `Languages.GetExistingLanguages()`，返回这个数组。

```csharp
Languages.GetExistingLanguages();
// => {"C#", "Clojure", "Elm"}
```

## 3. 向数组中添加一门新语言

当你在 Exercism 上探索、发现更多有趣的语言时，你会想把它们加进数组里。

实现静态函数 `Languages.AddLanguage()`，把一门新语言添加到数组末尾。

```csharp
Languages.AddLanguage(Languages.GetExistingLanguages(), "VBA");
// => {"C#", "Clojure", "Elm", "VBA"}
```

## 4. 统计数组中的语言数量

一门一门地清点语言很不方便。

实现静态方法 `Languages.CountLanguages()`，统计数组中语言的数量。

```csharp
Languages.CountLanguages(Languages.GetExistingLanguages())
// => 3
```

## 5. 检查某门语言是否在数组中

实现静态方法 `Languages.HasLanguage()`，检查某门语言是否存在。

```csharp
Languages.HasLanguage(Languages.GetExistingLanguages(), "Elm")
// => true
```

## 6. 反转数组

某一天你发现，你的数组其实是倒序排列的！

实现静态方法 `Languages.ReverseList()`，反转你的数组。

```csharp
Languages.ReverseList(Languages.GetExistingLanguages())
// => {"Elm", "Clojure", "C#"}
```

## 7. 检查数组是否令人兴奋

虽然你热爱所有语言，但 C# 在你心中有特殊的位置。因此，只要满足下面任意一个条件，你就会对一份语言数组感到非常兴奋：

- 数组中的第一个是 C#。
- 数组中的第二项是 C#，并且数组包含两门或三门语言。

实现静态方法 `Languages.IsExciting()`，检查一份语言数组是否令人兴奋：

```csharp
Languages.IsExciting(Languages.GetExistingLanguages())
// => true
```

## 8.移除语言

请实现静态方法 `Languages.RemoveLanguage()`，从数组中移除指定的语言。

```csharp
Languages.RemoveLanguage(Languages.GetExistingLanguages(), "Clojure")
// => { "C#", "Elm" }
```

## 9. 检查数组中的所有语言是否都唯一

请实现静态方法 `Languages.IsUnique()`，检查数组中是否有任何语言重复出现。

调用这个方法时，语言数组（也就是那个形参）保证不为空，数组是否被修改也没有关系。

```csharp
Languages.IsUnique(Languages.GetExistingLanguages())
// => true
```
