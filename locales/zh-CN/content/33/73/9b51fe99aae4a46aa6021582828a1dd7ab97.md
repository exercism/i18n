# 说明

Lucian 的女朋友正在回家的路上，而他还没有做他们的纪念日晚餐！

在本练习中，你将编写一些代码，帮助 Lucian 按照他最爱的食谱做出一道美味的千层面。

与制作千层面所花时间相关的任务一共有四个。

## 1. 定义预期的烤箱时间（分钟）

定义`expected_minutes_in_oven`常量，它表示千层面应该在烤箱里烤多少分钟。根据这本烹饪书，预期的烤箱时间是`40`分钟。

## 2. 计算剩余的烤箱时间（分钟）

实现`remaining_minutes_in_oven`方法，它接收千层面已经在烤箱里烤的实际分钟数作为_形参_，并根据上一个任务中的**预期的烤箱时间（分钟）**，_返回_千层面还需要在烤箱里烤多少分钟。

```abap
remaining_minutes_in_oven( 30 ).
// => 10
```

## 3. 计算准备时间（分钟）

实现`preparation_time_in_minutes`方法，它接收你给千层面添加的层数作为_形参_，并_返回_你准备千层面花了多少分钟，假设每层需要 2 分钟来准备。

```abap
preparation_time_in_minutes( 2 ).
// => 4
```

## 4. 计算总工作时间（分钟）

实现`total_time_in_minutes`方法，它接收_两个形参_：`numbernumber_of_layers`形参是你给千层面添加的层数，`actual_minutes_in_oven`形参是千层面已经在烤箱里烤的分钟数。该方法应该_返回_你烹饪千层面总共工作了多少分钟，也就是准备时间的分钟数与千层面此刻在烤箱里所花分钟数之和。

```abap
total_time_in_minutes( 
  numbernumber_of_layers = 3
  actual_minutes_in_oven = 20 ).
// => 26
```
