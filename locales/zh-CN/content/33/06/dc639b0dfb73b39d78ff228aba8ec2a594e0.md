# 关于

F# 中的[`list`][lists]是不可变的集合，包含零个或多个值。列表中的所有值都必须具有相同的类型。由于列表不可变，一旦构造完成，它的值就永远无法改变。F# 的列表有一个_头_（第一个元素）和一个_尾_（第一个元素之后的所有内容）。列表的尾本身也是一个列表。

列表可以这样定义：

```fsharp
let empty = []
let emptyAlternative = List.empty

let singleValue = [5]
let singleValueAlternative = List.singleton 5

let threeValues = ["a"; "b"; "c"]
```

向列表中添加元素最常见的方式是使用`::`（cons）运算符：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

列表可以用`@`运算符或`List.append`来追加：

```fsharp
[6; 7] @ [8; 9]           // => [6; 7; 8; 9]
List.append [6; 7] [8; 9] // => [6; 7; 8; 9]
```

列表由[`List`模块][list-module]中定义的函数和运算符来操作。其中一些函数也可以作为`list`实例的[属性][list-properties]来使用：

```fsharp
List.length [7; 8] // => 2
[7; 8].Length      // => 2
```

这里没有对错之分。总的来说，`List`模块中的函数与类型推断配合得更好，而属性则能写出更简洁的代码。

任何看起来会修改列表的函数或运算符（例如添加元素），实际上都会返回一个新的列表。不过性能通常不是问题，因为列表的实现避免了不必要的分配和复制。

由于列表是以单向链表实现的，在列表前面添加元素（使用`::`运算符）非常快，而按下标访问元素则可能相对较慢。

列表还可以通过[_list_][list-pattern]和[_cons_][cons-pattern]模式进行模式匹配来处理：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [ 1 ] -> "Singleton list with 1"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Singleton list with 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

在模式匹配时，你也可以_丢弃_某个值；如果你在某个具体分支中_不_关心某个值（也就是说，你不会_用到_它），可以用下划线（`'_'`）来表示：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

单独出现的`'_'`在模式匹配时应始终放在_最后_，凡是_不_匹配其他任何分支的值，都会由这个分支处理。
