# 说明

这是当地俱乐部的赛季收官战。你在终点线负责排行榜：选手们按顺序冲线，赛道需要标注，而官方台账也得在下一轮比赛开始前写好备注。

选手的名字以数组的形式传入，按冲线顺序排列：第 0 个名字是冠军，第 1 个是亚军，依此类推。

## 1. 分配号码布

定义`assign-bibs`，接收一个选手名字的数组，返回由`{ position name }`对组成的数组，位置在前。

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. 赛道标签

定义`lane-labels`，接收一个选手名字的数组，返回形如`"Lane 0: Bolt"`的字符串。

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. 给选手打标签

定义`tag-racers`，接收一个选手名字的数组*和*一个标签字符串，返回形如`"<tag>/<index>: <name>"`的标签。每个标签里都嵌入同一个标签字符串。

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. 记录完赛情况

定义`record-finishes`，接收一个选手名字的数组和一个台账（一个 vector）。对每个选手，就地往台账里追加一个形如`"<index>: <name>"`的字符串。不返回任何值。

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. 报圈铃声

定义`lap-bells`，接收一个数字`laps`，返回一个由`"ding "`重复`laps`次拼接而成的字符串。

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
