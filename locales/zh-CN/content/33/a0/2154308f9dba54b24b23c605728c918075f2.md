# 简介

## 数组

在 Gleam 中，数组是一个不可变的集合，可以包含零个或多个值。数组中的所有值必须具有相同的类型。由于数组是不可变的，一旦数组被创建，它的值就永远不会改变。任何看起来会修改数组的函数或运算符（例如添加一个元素），实际上都会返回一个新的数组。

数组可以这样定义：

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

向数组中添加元素最常见的方式是使用展开语法：

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam 标准库中的 [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) 模块包含许多用于处理数组的实用函数。这个模块在 Gleam 代码中非常常用，所以熟悉它是很有好处的。

数组模式可以用在 case 表达式中，用来匹配数组，并把包含的值赋给变量：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

除了匹配长度完全相同的数组之外，还可以使用展开语法来匹配长度至少为某个值的数组：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

展开语法还可以用来把数组的剩余部分赋给一个变量：

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

case 表达式应该为被匹配类型的每一个可能值都提供一个模式，因此通常会用一个最终的丢弃模式（`_`）来处理剩余的所有值。
