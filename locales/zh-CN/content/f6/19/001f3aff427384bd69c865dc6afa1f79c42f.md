# 说明

学校话剧里的每个角色都有一名替补演员：有人能随时顶上，把这个角色该做的事做好，而舞台监督根本不需要知道他们是谁。

五个任务都写在`UNDERSTUDY`类里。前两个是普通的例程，后面的任务会把它们绑定起来。

## 1. 两种说台词的方式

编写`shout`，它返回大写的台词；再编写`whisper`，它返回小写的台词，并在两端加上`"..."`。

```sather
UNDERSTUDY::shout("who's there")
-- => "WHO'S THERE"
UNDERSTUDY::whisper("Who's There")
-- => "...who's there..."
```

## 2. 排练一句台词

`rehearse`接收一句台词和一种说台词的方式，返回结果。它的第二个实参类型是`ROUT{STR}:STR`。

```sather
UNDERSTUDY::rehearse("who's there", bind(UNDERSTUDY::shout(_)))
-- => "WHO'S THERE"
```

## 3. 整场戏

`run_scene`接收一个台词数组和一种说台词的方式，返回所有台词都按这种方式说出后的结果，中间用`" "`连接。

```sather
UNDERSTUDY::run_scene(|"Enter", "Exit"|, bind(UNDERSTUDY::shout(_)))
-- => "ENTER EXIT"
```

空场景就是空字符串。

## 4. 返回一种说台词的方式

`understudy_for`接收一个风格的名称（`"shout"`或其他任何值），返回一个`ROUT{STR}:STR`。传入`"shout"`得到大声说的那种，传入其他任何值得到小声说的那种。

```sather
part ::= UNDERSTUDY::understudy_for("shout");
part.call("who's there")
-- => "WHO'S THERE"
```

## 5. 固定一个实参

编写`repeat`，它接收一个次数和一句台词，返回把该台词重复那么多次、中间不加任何东西的结果：

```sather
UNDERSTUDY::repeat(3, "Ha")
-- => "HaHaHa"
```

然后编写`doubler`，它不接收任何实参，返回一个`ROUT{STR}:STR`，把传给它的内容重复两遍。做法是绑定`repeat`，并预先填好那个次数。

```sather
UNDERSTUDY::doubler.call("Ha")
-- => "HaHa"
```
