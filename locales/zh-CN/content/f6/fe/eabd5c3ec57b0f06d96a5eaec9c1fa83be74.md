# 介绍

## 整数

C# 和许多静态类型语言一样，提供了多种用于表示整数的类型，每种类型都有自己的取值范围。在数值范围的低端，`sbyte` 类型的最小值为 -128，最大值为 127。和所有整数类型一样，这些值都可以通过 `<type>.MinValue` 和 `<type>.MaxValue` 获取。在高端，`long` 类型的最小值为 -9,223,372,036,854,775,808，最大值为 9,223,372,036,854,775,807。介于两者之间的是 `short` 和 `int` 类型。

这些取值范围由类型在系统中分配的存储宽度决定。例如，`byte` 占 8 位，`long` 占 64 位。

上述每种类型都有一个对应的无符号版本：`sbyte`/`byte`、`short`/`ushort`、`int`/`uint` 和 `long`/`ulong`。在所有情况下，取值范围都是从 0 到有符号最大值的相反数乘以 2 再加 1。

| 类型   | 宽度   | 最小值                     | 最大值                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 位   | -128                       | +127                        |
| short  | 16 位  | -32_768                    | +32_767                     |
| int    | 32 位  | -2_147_483_648             | +2_147_483_647              |
| long   | 64 位  | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 位   | 0                          | +255                        |
| ushort | 16 位  | 0                          | +65_535                     |
| uint   | 32 位  | 0                          | +4_294_967_295              |
| ulong  | 64 位  | 0                          | +18_446_744_073_709_551_615 |

一种类型的变量（或表达式）可以很方便地转换为另一种类型。例如，在赋值操作中，如果要赋的值（lhs）的类型能确保该值落在赋值目标类型（rhs）的取值范围内，那么这就是一次简单赋值：

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

反过来，如果被赋值来源类型的取值范围不是目标类型取值范围的子集，那么即使具体的值落在目标类型的取值范围内，也仍然需要强制转换（`()` 操作）：

```csharp
short s = 42;
uint ui = (uint)s;
```
