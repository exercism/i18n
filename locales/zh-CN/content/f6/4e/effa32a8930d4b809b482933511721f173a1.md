# 简介

在 Elm 中，字符和字符串构成了文本表示的基础。
字符串可以看作字符的列表，`List`模块中的大多数函数在`String`模块中都有对应的版本。

## 字符

`Char`类型表示单个 unicode 字符，用单引号括起来，例如`'a'`。
`Char`模块提供谓词函数（`Char -> Bool`），用于测试字符的各种性质：`isUpper`、`isLower`、`isAlpha`和`isAlphaNum`。
该模块还提供转换字符的函数：`toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`，以及在字符与其数值形式的 unicode 值（`Int`）之间相互转换的`toCode`和`fromCode`。

## 字符串

`String`类型为高效的字符串操作提供了内置的表示方式，可以表示任意 unicode 字符序列，例如 "this is an Elm string."
多行字符串使用三个双引号表示，其中可以包含未转义的引号和换行符。
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

## 字符串函数

`String`模块包含下表汇总的所有函数。
下面是一些最常用的函数：

`cons : Char -> String -> String`将一个字符添加到字符串的开头。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`追加两个字符串。
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`按照给定的分隔符将字符串拆分成一个字符串列表。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`用给定的分隔符将一个字符串列表拼接起来。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`替换给定子串的所有出现位置。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`返回字符串中字符的数量。
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`尝试将字符串转换为`Just Int`，对于格式不正确的字符串则返回`Nothing`。
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`检查第二个字符串是否包含第一个字符串。
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`将给定的函数应用到字符串中的每一个`Char`上。
注意，所提供的函数必须是`Char`到`Char`的映射。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
