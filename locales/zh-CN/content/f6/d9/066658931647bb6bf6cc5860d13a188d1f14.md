# 说明

在这个练习里，你是个超级体育迷，最近刚刚迷上了 NBA 篮球。由于刚接触 NBA 篮球，你正深入研究 NBA 的历史，记录各支球队、教练以及他们的胜负数据，并把它们相互比较。

你还没有最喜欢的球队，所以还要开发一个算法，来判断该不该支持某支球队。

你有 7 个任务，帮你打磨出属于你自己的_支持球队_算法。

## 1. 定义模型

定义`Coach`记录，它包含以下 2 个字段：

- `Name`：教练的姓名，类型为`string`。
- `FormerPlayer`：表示教练是否为前球员，类型为`bool`。

定义`Stats`记录，它包含以下 2 个字段：

- `Wins`：胜场数，类型为`int`。
- `Losses`：负场数，类型为`int`。

定义`Team`记录，它包含以下 3 个字段：

- `Name`：球队名称，类型为`string`。
- `Coach`：球队的教练，类型为`Coach`。
- `Stats`：球队的数据，类型为`Stats`。

## 2. 创建球队的教练

实现`createCoach`函数，它接收教练姓名和其是否为前球员作为形参，并返回对应的`Coach`记录：

```fsharp
createCoach "Larry Bird" true
// => { Name = "Larry Bird"; FormerPlayer = true }
```

## 3. 创建球队的数据

实现`createStats`函数，它接收胜场数和负场数作为形参，并返回对应的`Stats`记录：

```fsharp
createStats 58 24
// => { Wins = 58; Losses = 24 }
```

## 4. 创建球队

实现`createTeam`函数，它接收球队名称、教练和记录作为形参，并返回对应的`Team`记录：

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
createTeam "Indiana Pacers" coach record
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Larry Bird"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 5. 更换教练

NBA 的球队老板都没什么耐心，你发现战绩不佳往往会让教练被换掉。实现`replaceCoach`函数，它接收球队和新教练作为形参，并返回换上这位新教练后的球队：

```fsharp
let coach = createCoach "Larry Bird" true
let record = createStats 58 24
let team = createTeam "Indiana Pacers" coach record

let newCoach = createCoach "Isiah Thomas" true
replaceCoach team newCoach
// => { Name = "Indiana Pacers"
//      Coach = { Name = "Isiah Thomas"; FormerPlayer = true }
//      Stats = { Wins = 58; Losses = 24 } }
```

## 6. 检查是否为同一支球队

在钻研各种数据时，你会把球队和它们的记录整理成列表。有时你会弄错，列表里就出现了重复的条目。实现`isSameTeam`函数，它接收 2 支球队，如果它们是同一支球队就返回`true`；否则返回`false`：

```fsharp
let pacersCoach = createCoach "Larry Bird" true
let pacersStats = createStats 58 24
let pacersTeam = createTeam "Indiana Pacers" pacersCoach pacersStats

let lakersCoach = createCoach "Del Harris" false
let lakersStats = createStats 61 21
let lakersTeam = createTeam "LA Lakers" lakersCoach lakersStats

isSameTeam pacersTeam lakersTeam
// => false
```

## 7. 判断是否该支持某支球队

看过许多球队和比赛之后，你想出了一个算法。只要满足下面任意一条，你就支持这支球队：

- 教练的名字是“Gregg Popovich”
- 教练是前球员
- 球队的名字是“Chicago Bulls”
- 球队赢过 60 场或更多比赛
- 球队的负场多于胜场

实现`rootForTeam`函数，它接收一支球队，如果你应该支持这支球队就返回`true`；否则就`return` false：

```fsharp
let spursCoach = createCoach "Gregg Popovich" false
let spursStats = createStats 56 26
let spursTeam = createTeam "San Antonio Spurs" spursCoach spursStats
rootForTeam spursTeam
// => true
```
