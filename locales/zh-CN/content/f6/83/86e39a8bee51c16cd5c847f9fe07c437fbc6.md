# 简介

## 数字

许多编程语言都有专门的数字类型来表示不同类型的数字，但 JavaScript 只有两种：

- `number`：一种数字数据类型，采用双精度 64 位浮点格式（IEEE 754）。
  例如 `-6`、`-2.4`、`0`、`0.1`、`1`、`3.14`、`16.984025`、`25`、`976`、`1024.0` 和 `500000`。
- `bigint`：一种数字数据类型，可以用任意精度格式表示_整数_。
  例如 `-12n`、`0n`、`4n` 和 `9007199254740991n`。

如果你需要任意精度，或者要处理极其庞大的数字，就使用 `bigint` 类型。
否则，`number` 类型通常是更好的选择。

### 舍入

JavaScript 有一个名为 `Math` 的内置全局对象，它提供了各种[舍入函数][ref-math-object-rounding]。
例如，你可以把小数向下取整（`floor`）或向上取整（`ceil`），得到最接近的整数。

```javascript
Math.floor(234.34); // => 234
Math.ceil(234.34); // => 235
```

## 算术运算符

JavaScript 提供了 6 种不同的运算符，用来对数字进行基本的算术运算。

- `+`：加法运算符，用来求数字之和。
- `-`：减法运算符，用来求两个数字之差。
- `*`：乘法运算符，用来求两个数字之积。
- `/`：除法运算符，用来将两个数字相除。

```javascript
2 - 1.5; //=> 0.5
19 / 2; //=> 9.5
```

- `%`：求余运算符，用来求一次除法运算的余数。

  ```javascript
  40 % 4; // => 0
  -11 % 4; // => -3
  ```

- `**`：幂运算符，用来把一个数字提升到某个幂。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

### 运算顺序

在一行里使用多个运算符时，JavaScript 会按照[这张优先级表][mdn-operator-precedence]所示的顺序执行。
就我们的场景而言，可以简化成我们在小学数学课上学过的 PEDMAS 法则（括号、指数、除法/乘法、加法/减法）。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

### 简写赋值运算符

简写赋值运算符是一种更简短的写法：它对变量进行算术运算，并把新值赋值给同一个变量。
例如，假设有两个变量 `x` 和 `y`。
那么，`x += y` 等同于 `x = x + y`。
很多时候，这里用的是数字而不是变量 `y`。
其余 5 种运算也可以用类似的方式书写。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
