# 关于

Swift 的标准库提供了丰富的功能，但通过导入外部库和框架，你还能使用许多额外的特性。
这些模块可能直接来自 Swift 项目（例如 [Swift Argument Parser][argument-parser]），可能来自 Apple 平台的框架（例如 [Foundation][apple-foundation] 和 [Network Framework][network-framework]），也可能来自第三方开源库（例如 [SwiftyBeaver][swifty-beaver]）。

Foundation 是 Swift 中使用最广泛的库之一，像这样的核心模块随 Swift 工具链一起提供。
第三方库必须先添加到你的项目配置中（例如使用 Swift Package Manager），然后才能被导入。

要导入模块，写下 `import` 关键字，后面跟上模块名：

```swift
import Foundation
```

导入一个模块后，它的类型、方法和函数就可以在你的代码中使用了。
例如，导入 Foundation 会为 `String` 扩展出 `components(separatedBy:)` 这样实用的工具方法。

按照惯例，`import` 语句放在 Swift 文件的顶部，这样任何阅读代码的人都能一眼看到依赖项。

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
