# 简介

在 Python 中，`None`经常用来表示值的缺失，它是一个占位符，用于定义`null`（空）变量、对象或实参。

如果你在其他编程语言中听说过或使用过`NULL`或`nil`类型，那么 Python 中`None`的这种用法对你来说会很熟悉。`None`可以帮助你声明暂时还没有值的变量或函数实参。之后需要时，可以再把它们重新赋值为具体的值。

```python
a = None
print(a)
#=> None
type(a)
#=> <class 'NoneType'>

# Adding a Default Argument with `None`
def add_to_todos(new_task, todo_list=None):
  if todo_list is None:
    todo_list = []
    todo_list.append(new_task)
  return todo_list

```

在条件判断中使用时，`None`会求值为`False`，所以它很适合用来验证一个值是“存在”还是“缺失”，_任何_值都是如此。当函数或过程可能返回错误对象或错误消息时，这种模式很常用。

```python
a = None
if a: #=> a will be evaluated to False when its used in a conditional check.
    print("This will not be printed")
```
