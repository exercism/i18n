# 运行测试

要运行某个练习的测试，请在练习目录中运行`<exercise>.test`脚本：

```bash
tclsh <exercise>.test
```

对大多数练习来说，除了第一个测试，其余测试都会被“跳过”。
这样一来，作为开发者，你就可以采用测试驱动开发：一次只编写刚好通过一个测试的代码，逐个通过测试。
要覆盖这些跳过命令，请在运行测试套件之前，将`RUN_ALL`环境变量设置为一个有效的 Tcl true 值 \[1\]：

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]：Tcl 的 true/false 值记录在 C 库函数 [Tcl_GetBoolean][bool] 的手册页中。

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
