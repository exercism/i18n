# 说明

在这个练习中，你将编写一些代码，帮助你为购买一辆车做准备。

你有三个任务：确定自己能否负担得起月供，确定你需要哪种驾照，以及估算一辆二手车的合理价格。

## 1. 计算你能否负担得起某辆车的月供

你所在城镇的汽车经销商都在搞五年期、0% 利率的促销活动，你很想借此机会买车。但你不确定自己能否负担得起心仪车辆的月供。

月供就是车辆总价除以五年期内的月数。

实现 `canIBuy(vehicle:price:monthlyBudget:)` 函数，它接收以下实参：
- `vehicle`：你想购买的车辆的名称。
- `price`：你想购买的车辆的价格。
- `monthlyBudget`：你每月能负担的金额。

函数应根据以下条件返回相应的消息：
- 如果车辆的月供小于或等于你的月预算，返回消息 `"Yes! I'm getting a <vehicle>"`。
- 如果车辆的月供高出你的月预算，但高出幅度不超过 10%（含 10%），返回消息 `"I'll have to be frugal if I want a <vehicle>"`。
- 如果车辆的月供高出你的月预算超过 10%，返回消息 `"Darn! No <vehicle> for me"`。

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. 确定你需要哪种类型的驾照

你决定买一辆二手车，需要确定驾驶它需要哪种类型的驾照。

实现 `licenseType(numberOfWheels:)` 函数，它接收实参 `numberOfWheels`，也就是你想购买的车辆的轮子数量。

函数应根据以下条件返回相应的消息：
- 如果轮子数量是 2 或 3，返回消息 `"You will need a motorcycle license for your vehicle"`。
- 如果轮子数量是 4 或 6，返回消息 `"You will need an automobile license for your vehicle"`。
- 如果轮子数量是 18，返回消息 `"You will need a commercial trucking license for your vehicle"`。
- 如果是其他任何数字，返回消息 `"We do not issue licenses for those types of vehicles"`。

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. 估算一辆二手车的价格

既然你已经做出了决定，你就想确保在经销商那里能拿到一个公道的价格。因为你要买的是二手车，价格取决于车龄。粗略估算的话，假设车龄不到 3 年，价格为新车时原价的 80%；车龄至少 10 年，价格为原价的 50%；车龄至少 3 年但不超过 10 年，价格为原价的 70%。

实现 `calculateResellPrice(originalPrice:yearsOld:)` 函数，它接收实参 `originalPrice`（车辆的原始价格）和 `yearsOld`（车龄，以年为单位）。函数应返回车辆的转售价格。

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
