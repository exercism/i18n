# 安装 Swift

Swift 可用于 macOS、Linux 和 Windows。
安装过程因你所使用的操作系统而异。
在 Linux 方面需要注意的是，Swift 仅（官方）支持以下发行版：
- Ubuntu
- Debian
- RedHat
- Fedora
- Amazon Linux

如果你使用的是其他 Linux 发行版，就需要自己想办法安装 Swift。

## Xcode（macOS）

Swift 随 Xcode 一起提供，Xcode 是苹果为 macOS 和 iOS 开发打造的集成开发环境。
在 Exercism 的 Swift 练习中，你需要安装 Xcode 16.0 或更高版本。
Xcode 可以在 [Mac App Store][xcode] 上免费获取。
其他版本的 Xcode（包括最新的测试版）可以在[苹果开发者中心][apple-developer-center]找到。

## macOS 和 Linux

对于 macOS 和 Linux，有一个名为 [swiftly][swiftly] 的 Swift 安装管理器。
它是一个命令行工具，可以让你在系统上安装和管理多个版本的 Swift。
在 macOS 上安装 swiftly 的命令见[这里][swiftly-macos]，在 Linux 上安装的命令见[这里][swiftly-linux]。

macOS 上其他安装方式还有 [Homebrew][homebrew]。
在 Linux 上，你可以用 [Swift 官网][tarball]提供的压缩包进行安装。

## Windows

在 Windows 上安装 Swift，推荐使用 [WinGet 安装程序][winget-windows]。
你也可以通过 Scoop 包管理器安装 Swift，或者手动安装。
要了解所有安装方式，请看[在 Windows 上安装 Swift][swift-windows]页面。
