# 说明

在这个练习中，你将处理储蓄账户。
每年，储蓄账户的余额都会根据利率更新。
银行给你的利率取决于你账户里的金额（也就是余额）：

- 余额低于`0`美元时为 3.213%（余额会变得更负）。
- 余额大于或等于`0`美元且低于`1000`美元时为 0.5%。
- 余额大于或等于`1000`美元且低于`5000`美元时为 1.621%。
- 余额大于或等于`5000`美元时为 2.475%。

本练习共有四个任务，每个任务都会处理你的余额及其利率。

## 1. 计算利率

实现`InterestRate()`函数，根据给定的余额计算利率：

```go
InterestRate(200.75)
// => 0.5
```

注意，返回的值是`float32`类型。

## 2. 计算利息

实现`Interest()`函数，根据给定的余额计算利息：

```go
Interest(200.75)
// => 1.003750
```

注意，返回的值是`float64`类型。

## 3. 计算年度余额更新

实现`AnnualBalanceUpdate()`函数，计算年度余额更新，并考虑利率：

```go
AnnualBalanceUpdate(200.75)
// => 201.75375
```

注意，返回的值是`float64`类型。

## 4. 计算达到目标余额所需的年数

实现`YearsBeforeDesiredBalance()`函数，计算达到目标余额所需的最少年数，同时考虑到每年都会把利息加到余额上。
也就是说，一年后的余额是：起始余额 + 起始余额的利息。
第二年后的余额是：一年后的余额 + 一年后余额的利息。
依此类推，直到当年的余额大于或等于目标余额。

```go
balance := 200.75
targetBalance := 214.88
YearsBeforeDesiredBalance(balance, targetBalance)
// => 14
```

注意，返回的值是`int`类型。
