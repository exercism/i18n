# 测试

要用 CLI 运行练习的测试，请在练习目录下运行以下命令：

```bash
clojure -M:test
```

## REPL

要用 REPL 运行练习的测试，请在练习目录下运行以下命令：

```bash
$ clojure -m cljs.main -re node
```

然后 `require` 练习的测试命名空间和 Clojure 测试命名空间）：

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

把 ns 切换到测试命名空间：

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

然后调用 `run-tests`：

```clojure
=> (cljs.test/run-tests)
```
