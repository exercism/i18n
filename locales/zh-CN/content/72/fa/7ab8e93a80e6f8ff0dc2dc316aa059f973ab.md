# 补充说明

## 提示

要完成这道练习，你需要实现函数 `anagramsFor`。它接收一个*单词*和一组*单词*，并返回其中是给定*单词*的变位词的那些。

你必须按照候选单词中列出的顺序返回这些变位词。

如果是你第一次做这道练习，建议先使用下面提供的函数签名：

```haskell
anagramsFor :: String -> [String] -> [String]
```

之后，不妨回头重新做一遍这道题，试试其他数据类型和库：

- 来自*text*包的 `Text`。
- 来自*containers*包的 `Sequence` 和 `Set`。
- 来自*multiset*包的 `MultiSet`。

测试套件特意设计成几乎接受任何合理的类型签名，所以鼓励你去找出你认为最好的那一个。
