# 说明

你在海滨木板路游乐场经营着各种赌运气的游戏。玩家们掷骰子，抓娃娃机抓取奖品，牌桌则需要洗牌、发牌，这一切都靠随机性。到了收摊的时候，你还想要一个“重放”功能，让有争议的一局能用同一个种子再跑一遍。

## 1. 掷骰子

定义`roll-die`，接收骰子的面数，返回一个介于`1`到`sides`（含）之间的点数。

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. 抓取奖品

定义`pick-prize`，接收一个奖品序列，随机返回其中的一个。

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. 洗牌

定义`shuffle-deck`，接收一副牌（一个序列），返回牌序被打乱的这副牌。

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. 发牌

定义`deal-hand`，接收一副牌和一个数量`n`，返回这副牌中`n`张*不同的*牌。

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. 用种子重放

定义`play-seeded`，接收一个种子和一个引用，用这个整数作为种子初始化生成器，然后运行该引用，这样同一个种子总能重现相同的结果。引用的结果应返回给调用者。

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
