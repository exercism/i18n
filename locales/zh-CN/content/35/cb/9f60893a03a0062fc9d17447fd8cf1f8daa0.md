# 三元运算符

三元运算符提供了另一种语法，用来执行 `if..else..` 比较并返回一个值。

## 语法

PHP 提供了一种 if 语句，可以根据条件的“真假”来决定执行哪个操作。

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

也可以改用三元运算符来表示同样的操作：

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

这种比较语法很简短，写作`(condition) ? (evaluate if true) : (evaluate if false);`。
