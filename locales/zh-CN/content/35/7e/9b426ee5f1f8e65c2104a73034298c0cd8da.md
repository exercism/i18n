# Babashka 文本编辑器集成

## nREPL

### Emacs: [CIDER](https://cider.mx/)

这是最早出现的那个集成，它的 [Orchard](https://metaredux.com/posts/2018/11/09/ciders-orchard-the-heart.html) 生态为许多其他插件提供了支持。

1. 为你的平台安装 [Emacs](https://www.gnu.org/software/emacs/download.html)。

2. 选择一个现有的 Emacs 发行版（[Prelude](https://prelude.emacsredux.com/)、[Spacemacs](https://www.spacemacs.org/) 和 [Doom Emacs](https://github.com/hlissner/doom-emacs) 都很不错），或者把下面这段加到你的 `init.el` 里：

```elisp
(unless (package-installed-p 'cider)
  (package-install 'cider))
  
(add-hook 'clojure-mode-hook #'cider-mode)
```

以下内容摘自 [CIDER 文档](https://docs.cider.mx/cider/platforms/babashka.html)：

在项目目录中启动 nREPL 服务器：

```bash
$ bb --nrepl-server
```

用 `C-x C-f` 创建或打开任意 Clojure 文件（`.clj`），再用 `C-c C-x c j`（cider-connect-clj）连接到它。

[基本的 CIDER 快捷键](https://docs.cider.mx/cider/usage/cider_mode.html#key-reference)：

* `cider-load-buffer` - `C-c C-k`
* `cider-eval-last-sexp` - `C-x C-e` 或 `C-c C-e`
* `cider-eval-defun-at-point` - `C-M-x` 或 `C-c C-c`

### VSCode: [Calva](https://github.com/BetterThanTomorrow/calva)

1. 安装 [VSCode](https://code.visualstudio.com/)。

2. 安装 [Calva](https://marketplace.visualstudio.com/items?itemName=betterthantomorrow.calva)。

目前，Calva 把你的源代码理解为处于某个文件夹（即一个 Clojure 项目）的上下文中。创建项目的一个好办法是用 [clj-new](https://github.com/seancorfield/clj-new)：

```bash
$ clj -A:new lib myorg/bbtest
Generating a project called bbtest based on the 'lib' template.
The lib template is intended for library projects, not applications.
```
3. 在项目目录中启动 nREPL 服务器：

```bash
$ cd bbtest
bbtest$ bb --nrepl-server 1667
Started nREPL server at localhost:1667
For more info visit https://github.com/borkdude/babashka/blob/master/doc/repl.md#nrepl.
```

在 VSCode 中打开项目文件夹（Ctrl+K Ctrl+O），或者在另一个终端里执行：

```bash
$ cd bbtest
bbtest$ code .
```

4. 在 VSCode 中，运行 Calva 命令 `Connect to a running REPL`（ctrl+alt+c ctrl+alt+c）。提示时选择 `Generic` 项目，然后输入 `localhost:1667`。

REPL 命令：

* `Load Current File and Dependencies` ctrl+alt+c enter
* `Evaluate Current Form Inline` ctrl+alt+c e
* `Evaluate Current Top Level Form (defun)` ctrl+alt+c space

### IntelliJ: [Cursive](https://cursive-ide.com/)

1. 在[这里](https://www.jetbrains.com/idea/download/index.html)下载 IntelliJ。
2. 按照[用户指南](https://cursive-ide.com/userguide/)安装 Cursive，并[配置依赖](https://cursive-ide.com/userguide/deps.html)。
3. 更多信息请参见 [Cursive：配合 Babashka 使用](https://cursive-ide.com/userguide/babashka.html)。

## Socket REPL

### Atom: [chlorine](https://github.com/mauricioszabo/atom-chlorine)

1. 安装 [atom](https://flight-manual.atom.io/getting-started/sections/installing-atom/)

2. 安装 `chlorine` 包

3. 启动 socket REPL：

 ```
$ bb --socket-repl 1666
Babashka socket REPL started at localhost:1666
 ```

4. 打开 Atom 命令面板（ctrl+shift+p），执行命令 `Connect Clojure Socket REPL`，填入 `localhost` `1666`

5. 通过 `Edit` 菜单 -> `Keymap...` 编辑 keymap.cson 中的快捷键绑定：

```
'atom-text-editor[data-grammar="source clojure"]':
  'ctrl-; y':       'chlorine:connect-clojure-socket-repl'
  'ctrl-; e':       'chlorine:disconnect'
  'ctrl-; k':       'chlorine:clear-console'
  'ctrl-shift-enter':       'chlorine:load-file'
  'ctrl-enter':       'chlorine:evaluate-block'
  'shift-enter':       'chlorine:evaluate-top-block'
  'ctrl-; i':       'chlorine:inspect-block'
  'ctrl-; I':       'chlorine:inspect-top-block'
  'ctrl-; s':       'chlorine:evaluate-selection'
  'ctrl-; c':       'chlorine:break-evaluation'
  'ctrl-; S':       'chlorine:source-for-var'
  'ctrl-; d':       'chlorine:doc-for-var'
  'ctrl-; x':       'chlorine:run-tests-in-ns'
  'ctrl-; t':       'chlorine:run-test-for-var'
```

### Emacs: [inf-clojure](https://github.com/clojure-emacs/inf-clojure)

对于 Emacs，把下面这段加到你的 `init.el` 里来安装 [inf-clojure](https://github.com/clojure-emacs/inf-clojure)：

```
(unless (package-installed-p 'inf-clojure)
  (package-refresh-contents)
  (package-install 'inf-clojure))

(add-hook 'clojure-mode-hook #'inf-clojure-minor-mode)
```

像上面那样启动 socket REPL，然后在 Emacs 中执行 `M-x inf-clojure-connect`（C-c M-c）。

用 C-c C-e 求值表达式。想查看 inf-clojure-mode（也就是 REPL）和 inf-clojure-minor-mode 中所有可用命令的列表，你可以调用 C-h f RET inf-clojure-mode 和 C-h f RET inf-clojure-minor-mode，也可以直接浏览它们的菜单。

### Vim: [vim-iced](https://github.com/liquidz/vim-iced)

下载 [Neovim appimage](https://github.com/neovim/neovim/releases/download/v0.4.3/nvim.appimage)，并把它取别名为 `vim`。

* 安装 [vim-plug](https://github.com/junegunn/vim-plug)：

```
$ curl -fLo ~/.local/share/nvim/site/autoload/plug.vim --create-dirs \
    https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

创建 `~/.config/nvim/init.vim`：

```
call plug#begin('~/.vim/plugged')

Plug 'liuchengxu/vim-clap'
Plug 'guns/vim-sexp',    {'for': 'clojure'}
Plug 'liquidz/vim-iced', {'for': 'clojure'}

call plug#end()

" Enable vim-iced's default key mapping
" This is recommended for newbies
let g:iced_enable_default_key_mappings = v:true
```

打开 Neovim，运行命令 `:PlugInstall`。

把 `iced` 命令加入 $PATH：

`$ export PATH=$PATH:~/.vim/plugged/vim-iced/bin`

* 启动 socket REPL 服务器，打开源文件并执行 `:IcedConnectSocketRepl 1666`。

默认的 REPL 命令（默认的 `<Leader>` 是 `\`）：

- `<Leader>ei`：求值内层元素
- `<Leader>ee`：求值外层列表
- `<Leader>et`：求值外层顶层列表
