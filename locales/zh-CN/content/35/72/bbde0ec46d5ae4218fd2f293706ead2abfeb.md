# 循环

**循环**会把同一件事一遍又一遍地做下去。

```sather
   loop
      ...
   end;
```

光是这样永远不会停，所以里面必须有东西来结束它。

## 一个保存计数的地方

循环几乎总是需要一个随着进行而改变的值。那就是**变量**，用 `::=` 可以创建一个：

```sather
   total ::= 0;
```

这个变量叫做`total`，它从`0`开始，Sather 根据这个`0`推断出它保存的是一个`INT`。之后，用`:=`放入新值：

```sather
   total := total + 5;
```

从右往左读：取`total`当前的值，加上 5，再把结果放回`total`。

这样创建的变量会一直存活到例程结束。

## until!

`until!`接受一个问题。每次循环都会问它一次，当答案为 true 时，循环就当场停在那里。

```sather
   sum_to(last : INT) : INT is
      total ::= 0;
      n ::= 1;
      loop
         until!(n > last);
         total := total + n;
         n := n + 1;
      end;
      return total;
   end;
```

`n`从 1、2、3 一直数下去……循环在`n`第一次超过`last`时结束。如果没有`n := n + 1`，这个问题的答案就永远不会改变，循环会一直运行下去。

`until!`不必是第一行。把它放在问题说得通的位置：放在顶部，循环可能一次都不运行；放在底部，它至少会运行一次。

`!`是名字的一部分。Sather 用这种方式标记某些东西；这个标记的含义以后再讲。

## break!

`break!`会立即结束循环，不附带任何问题。当停止的原因出现在工作过程中间时，它就派上用场了。

```sather
   loop
      if too_far then break!; end;
      ...
   end;
```

`until!`和`break!`只有在`loop`内部才有意义。两者都不能单独使用。
