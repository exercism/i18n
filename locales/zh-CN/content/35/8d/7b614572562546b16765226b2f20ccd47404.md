# 使用类型规范

[comment]: # (当解答没有类型规范时，会触发此警告)

使用[类型规范](https://elixir-lang.org/getting-started/typespecs-and-behaviours.html#types-and-specs)（`@spec`）来说明函数的输入与输出之间的契约。

- Elixir 是一门动态类型语言，也就是说，类型检查只在运行时进行。使用类型规范可以让 linter 和静态分析工具（比如基于 Erlang 的 [`Dialyzer`](http://erlang.org/doc/man/dialyzer.html) 的 [`Dialyxir`](https://hexdocs.pm/dialyxir/readme.html)）检查代码中是否存在非预期的行为。
- 你可以在[语言文档](https://hexdocs.pm/elixir/typespecs.html#content)中找到所有内置类型的[完整列表](https://hexdocs.pm/elixir/typespecs.html#basic-types)
- 类型可以带括号，也可以不带括号：`atom()`与`atom`
  - Exercism Elixir 的风格是不带括号。

```elixir
# Example 1
@spec add_one(int) :: int
def add_one(n) when is_integer(n) do
  n + 1
end

# Example 2
@spec hello(String.t) :: String.t
def hello(what \\ "world") when is_binary(what) do
  "Hello, #{what}"
end
```
