# 没有使用 gofmt

对提交的解答运行 `gofmt`，它可以帮助你格式化 Go 代码。

在 Go 社区里，代码格式非常重要。
大多数 IDE 都可以设置成每次保存时自动格式化代码。例如：

- Visual Studio Code 对 Go 有[很好的支持](https://code.visualstudio.com/docs/languages/go)
- Vim 也有[非常棒的 Go 扩展](https://github.com/fatih/vim-go)
- [Jetbrains Goland](https://www.jetbrains.com/go/) 本身就是一个完整的 Go IDE

手动运行 `gofmt`：

```bash
# will only show the differences
gofmt -d filename.go

# will apply the changes
gofmt -w filename.go
```

```git
%{gofmt}
```
