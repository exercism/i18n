# 说明

在这个练习中，你要帮助一对高中情侣在社交媒体上公开表白他们的爱意。

## 1. 用爱心分隔显示情侣的名字

请实现静态方法`HighSchoolSweethearts.DisplaySingleLine()`，它接收两个名字，并将它们用一个爱心分隔后显示出来。
格式化后的文本宽度应为 61 个字符，爱心位于字符串的正中央。

所有名字都保证能轻松容纳在这一行的宽度之内。

```csharp
HighSchoolSweethearts.DisplaySingleLine("Lance Green", "Pat Riley");
// => "                  Lance Green ♡ Pat Riley                    "
```

实现静态方法`HighSchoolSweethearts.DisplayBanner()`，它显示两组姓名首字母，并用加号分隔。

HighSchoolSweethearts.DisplayBanner("L. G.", "P. R.");

## 3. 用区域设置敏感的声明，让德国交换生有宾至如归的感觉。

实现静态方法`HighSchoolSweethearts.DisplayGermanExchangeStudents()`，为我们的德国交换生显示恋爱开始的日期以及在一起的时间长度。

```csharp
HighSchoolSweethearts.DisplayGermanExchangeStudents("Norbert", "Heidi", new DateTime(2019, 1, 22), 1535.22f);
// => "Norbert and Heidi have been dating since 22.01.2019 - that's 1.535,22 hours"
```
