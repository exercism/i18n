# 介绍

当一个 quotation 需要*记住*周围环境中的值时（其他语言把这种结构叫做*闭包*），Factor 会用两个工具：`curry` 这个词，以及 `'[ ]` 的 *fry* 语法。

## `curry`：捕获一个值

`curry`（位于 [`kernel`][kernel] 中）接收一个值和一个 quotation，并返回一个新的 quotation，其中已经嵌入了这个值：

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .
! => [ 3 + ]

10 3 [ + ] curry call .
! => 13
```

连续调用两次 `curry`，就能捕获两个值：

```factor
2 3 [ + + ] curry curry .
! => [ 2 3 + + ]
```

## `compose`：把两个 quotation 接在一起

`compose`（位于 [`kernel`][kernel] 中）把两个 quotation 粘合成一个：

```
compose ( quot1 quot2 -- quot )
```

```factor
[ 1 + ] [ 2 * ] compose .
! => [ 1 + 2 * ]

5 [ 1 + ] [ 2 * ] compose call .
! => 12
```

## Fry quotation：捕获多个值

当需要捕获的值超过一两个时，链式调用 `curry` 就会变得难以阅读。*fry* 使用 `'[ … ]`，里面带一个或多个 `_` 占位符；每个 `_` 都会按顺序被一个从数据栈上取下的值替换：

```factor
2 3 '[ _ _ + + ] .
! => [ 2 3 + + ]
```

无论 `curry` 还是 fry，都会在闭包构建的那一刻从栈上*消耗*掉自己的值。上面这行代码不会在栈上留下任何东西，可以直接替代 `[ + + ] curry curry`。

占位符从左到右填入，栈上的值则从下到上取用：`2 3 '[ _ _ ]` 得到的是 `[ 2 3 ]`，而不是 `[ 3 2 ]`。

fry 还能*深入*嵌套的 quotation，从而把捕获的值放在你确切想要的位置：

```factor
2 '[ [ _ > ] filter ] { 1 2 3 4 5 } swap call( s -- s ) .
! => { 3 4 5 }
```

这个 `_` 位于内层的 `[ … ]` 之中，但 fry 仍然会把它填上。

## 带效果声明的 `call`

当你最终运行一个存下来的 quotation 时，要在 `call` 上声明它的栈效果，这样编译器才能对它进行类型检查：

```factor
{ 3 4 5 } [ first2 + ] call( p -- n ) .
! => 7

{ 3 4 5 } [ first ] call( p -- n ) .
! => 3
```

## 向量运算

[`math.vectors`][math.vectors] 词汇表会按元素把两个长度相同的序列组合起来。`v+` 和 `v*` 分别对它们做加法或乘法；`vmax` 和 `vmin` 则保留每个分量中较大或较小的那个。两者都会返回一个长度为 2 的数组：

```factor
{ 1 1 } { 3 4 } v+ .    ! => { 4 5 }
{ 2 5 } { 3 -1 } v* .   ! => { 6 -5 }
{ 1 9 } { 4 4 } vmax .  ! => { 4 9 }
{ 1 9 } { 4 4 } vmin .  ! => { 1 4 }
```
