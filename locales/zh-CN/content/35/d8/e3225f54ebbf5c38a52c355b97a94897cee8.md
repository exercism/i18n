# 简介

本练习讨论 C# 中方法形参的一些细节及其用法。

形参把信息从调用方法传递给被调用的方法。

- 形参的行为可以通过`ref`、`out`等修饰符来修改。

- 带`out`修饰符的形参把值从被调用的方法传回给调用方。这个形参无需初始化就可以传给被调用的方法，而且无论如何，在被调用的方法内部，它都按进入时尚未初始化来处理。要理解形参修饰符的行为和规则，最简便的方式是看示例（见下）和编译器消息。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- 在被调用的方法内部，必须给`out`形参赋值。

- 带`ref`修饰符的形参把值传入被调用的方法。方法返回时，调用方会在这个形参中看到被调用方法所做的所有更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`形参必须是变量，因为被调用的方法会直接操作调用方所看到的那个形参。
- 无论在被调用方法的签名处，还是在调用处，都必须写出`out`和`ref`修饰符。
