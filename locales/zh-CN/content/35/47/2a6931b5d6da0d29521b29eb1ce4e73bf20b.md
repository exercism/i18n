# 介绍

[`Basics`][basics]概念介绍了两种定义函数的方法。

最常见的是多行形式：

```julia
function muladd(x, y, z)
    x * y + z
end
```

用于简短定义的“赋值”形式，也就是“单行”形式：
```julia
muladd(x, y, z) = x * y + z
```

还有第三种更简短的形式：一个简短、只用一次的函数，可以不必命名就创建出来：

```julia-repl
julia> map(x -> 2x, 1:3)
4-element Vector{Int64}:
 2
 4
 6

julia> map((x, y) -> x * y, 1:3, 4:6)
3-element Vector{Int64}:
  4
 10
 18
```

在这里，`x -> 2x`就是一个“匿名函数”。
这相当于其他一些语言所说的“lambda 函数”。

注意，多个参数需要用括号括起来，比如`(x, y) -> x * y`。

匿名函数在 Julia 代码中很常见，尤其是和`map()`、`filter()`这类高阶函数结合起来使用时（后面的概念会更详细地讲到这些内容）。

```julia-repl
julia> map(x -> x^4, [1, 2, 3])
3-element Vector{Int64}:
  1
 16
 81
```

## 函数参数

到目前为止，在这门课里我们只看了参数数量固定、并且要求调用函数时按正确顺序提供全部参数的函数。
这样会很有局限，也很不方便，所以还有好几种其他选择。

### 可选参数

和许多语言一样，Julia 允许在定义函数时为各个参数提供默认值。

调用函数时，既可以给这个参数提供一个值，也可以省略它，直接使用默认值。

```julia-repl
julia> f(x, y=10) = x * y
f (generic function with 2 methods)

julia> f(2, 3)
6

julia> f(2)
20
```

所有_没有_默认值的参数都必须放在_有_默认值的参数前面，也就是说`f(x=2, y)`是无效的。

### 关键字参数

到目前为止，所有例子用的都是`positional arguments`，也就是调用函数时提供的值，必须与函数定义中对应参数的顺序一致。

和许多语言一样，Julia 也支持`keyword arguments`。
调用函数时必须指定参数名，但多个关键字参数可以按任意顺序给出。

Julia 的一个独特之处在于：函数定义中的关键字参数（如果有的话）前面必须有一个分号`;`，用来把它们和位置参数分开。
调用函数时，可以在最后一个位置参数和第一个关键字参数之间用`;`或`,`。

```julia-repl
julia> b(x; y) = x + y
b (generic function with 1 method)

julia> b(2, y=3)
5

# keyword is required when calling
julia> b(2, 3)
ERROR: MethodError: no method matching b(::Int64, ::Int64)
The function `b` exists, but no method is defined for this combination of argument types.
```

也可以和位置参数一样，选择性地指定默认值。

当预先算好了一个和参数同名的变量时，函数调用里常常会出现像`myarg=myarg`这样的写法。
这种情况下可以使用简写语法：

```julia-repl
julia> width = 4.0
4.0

julia> height = √ width
2.0

julia> area(; width, height) = width * height
area (generic function with 1 method)

# repetition
julia> area(; width=width, height=height)
8.0

# shorthand form
julia> area(; width, height)
8.0
```

### Splat 和 slurp

这两个是 Julia 语法中某个实用特性的标准叫法，免得你好奇。
两者指的都是`...`运算符。

#### Splat

Splat 用在函数_调用_中，把集合展开成函数所需要的各个单独的值。

这个用示例演示，可能比解释更容易：

```julia-repl
julia> fxyz(x, y, z) = x * y * z
fxyz (generic function with 1 method)

julia> xyz = [2, 3, 4]
3-element Vector{Int64}:
 2
 3
 4

# Using the vector directly in a function call is invalid
julia> fxyz(xyz)
ERROR: MethodError: no method matching fxyz(::Vector{Int64})
The function `fxyz` exists, but no method is defined for this combination of argument types.

# splatting converts the vector to 3 numbers, used as positional arguments
julia> fxyz(xyz...)
24
```

有些“函数调用”被语法糖藏了起来，所以 splat 也能用在不太明显的地方。

例如，多重赋值在内部就用到了一个元组构造函数：

```julia-repl
julia> first, rest... = [1, 2, 3, 4]
4-element Vector{Int64}:
 1
 2
 3
 4

julia> first
1

julia> rest
3-element Vector{Int64}:
 2
 3
 4
```

关键字参数也可以用 splat 来提供，通常使用`named tuple`。
用`Dict`也行，但键必须是符号（字符串不行）。

```julia-repl
# function with 3 keyword arguments
julia> fabc(; a, b, c) = a + b + c
fabc (generic function with 1 method)

# named tuple
julia> abc_nt = (a=2, b=3, c=4)
(a = 2, b = 3, c = 4)

# there are no positional arguments, so need to use ; before kw argument
julia> fabc(;abc_nt...)
9

# Dict
julia> abc_dict = Dict(:a=>2, :b=>3, :c=>4)
Dict{Symbol, Int64} with 3 entries:
  :a => 2
  :b => 3
  :c => 4

julia> fabc(;abc_dict...)
9
```

#### Slurp

Slurp 用在函数_定义_中，把任意数量的单独的值打包进一个集合里。

```julia-repl
julia> f_more(i, j, more...) = i + j + sum(more)
f_more (generic function with 1 method)

julia> f_more(1, 3, 5, 7, 9, 11)
36
```

被 slurp 的那个参数（这里是`more`）叫什么名字并不重要。
这个变量的类型由编译器决定，但对位置参数来说，很可能是`tuple`或类似的东西。

关键字参数也可以被 slurp，得到一个`Dict`（或类似的东西）。

```julia-repl
julia> f_kwslurp(x, y; switches...) = :mult in keys(switches) ? x * y : x + y
f_kwslurp (generic function with 1 method)

julia> f_kwslurp(5, 6; mult=true)
30

julia> f_kwslurp(5, 6)
11
```

调用时可以使用任意关键字参数。
至于响应哪些关键字、忽略哪些关键字，由函数定义来决定。
