# 说明

在这个练习中，你将编写一些代码，帮助你为购买一辆车做准备。

共有三个任务：判断你是否需要取得驾照；在两辆车之间做出选择；以及估算一辆二手车可接受的价格。

## 1. 判断你是否需要驾照

有些类型的车辆需要驾照才能驾驶。
假定只有`"car"`和`"truck"`这两种类型需要驾照；其他所有类型都可以在没有驾照的情况下驾驶。

实现 `needs_license` 函数，它接收车辆类型，并返回一个布尔值，表示该类型的车辆是否需要驾照。

```jq
"car" | needs_license
# => true

"bike" | needs_license
# => false
```

## 2. 在两辆候选车辆之间做出选择

你已经评估了可选车辆的各个选项。
你成功把范围缩小到两个选项，但需要帮助来做最终决定。
实现函数 `choose_vehicle`，它接收一个包含两辆车的数组作为输入，并返回一个决定，即按字典序排在前面的那个选项。

```jq
["Wuling Hongguang", "Toyota Corolla"] | choose_vehicle
# =>  "Toyota Corolla is clearly the better choice."

["Volkswagen Beetle", "Volkswagen Golf"] | choose_vehicle
# =>  "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算一辆二手车的价格

既然你已经做出了决定，你想要确保在经销商那里拿到一个公道的价格。
由于你有意购买一辆二手车，价格取决于车龄。
作为粗略估算，假定车龄不到 3 年，价格为全新时原价的 80%。
如果车龄超过 10 年，则为 50%。
如果车龄至少 3 年但不超过 10 年，则为原价的 70%。

实现 `resell_price` 函数，用 `if`、`elif` 和 `else` 来实现这套逻辑。
它接收一个包含原价和车龄的对象，并返回在经销商处的估算价格。

```jq
{"original_price": 1000, "age": 1} | resell_price
# => 800

{"original_price": 1000, "age": 5} | resell_price
# => 700

{"original_price": 1000, "age": 15} | resell_price
# => 500
```
