# 关于

Factor 的字符是*整数*，也就是 Unicode 码点，所以直接用数字的 `<`、`>`、`=`，就能得到区分大小写的排序。[`unicode`][unicode]词汇表在此基础上添加了能感知 Unicode 的谓词和单字符大小写转换。

## 谓词

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
alpha?   ( c -- ? )    ! letter or decimal digit
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: \n blank? .    ! => t
```

## 大小写转换

```
ch>upper  ( c -- c' )
ch>lower  ( c -- c' )
ch>title  ( c -- c' )
```

字符串层面的 `>upper`、`>lower` 和 `>title` 会把它们应用到字符串中的每一个字符。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
