# 简介

接口是一种类型，它包含的成员定义了一组相关的功能。接口将类的使用与实现分开，从而允许存在多种不同的实现，或支持某种通用行为，例如格式化、比较或转换。

接口的语法与类或结构体相似，区别在于方法和属性只以签名形式出现，不提供任何实现。

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

接口定义的所有操作都必须实现。

接口可以包含实例方法和属性，以及其他成员。
