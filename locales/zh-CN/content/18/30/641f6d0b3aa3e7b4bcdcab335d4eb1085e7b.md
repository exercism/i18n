# 关于

[可变参数][variadic-parameters]允许函数为单个形参接受零个或多个指定类型的值。
要定义可变参数，只需在形参的类型标注后面加上`...`。

在函数体内，Swift 会将这些值以指定类型的数组形式提供给你：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函数在可变参数之后还包含额外的形参，那么紧随可变参数之后的第一个形参**必须**带有显式实参标签，这样 Swift 才能知道可变实参列表在哪里结束。
~~~~
