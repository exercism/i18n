# 简介

C++ 内置的数字类型可以分为整数和浮点数。
整数是不带小数部分的数，例如`0`、`691`或`-2`。
浮点数是带小数点的数，例如`6.02214076`、`0.1`或`-1.616`。

## 整数

下面的例子展示了四个不同变量的声明和初始化

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

给`int`变量赋值时，可以直接使用字面量。
字面量是像`9241`这样硬编码的数字。
针对不同的进制表示，有不同类型的整数字面量。
十进制整数字面量最常见，使用`0`到`9`这些数字。
加上特殊的前缀，比如`0x`，就可以使用其他进制。
上面的例子展示了数字`9241`的四种表示形式及对应的前缀。
所有变量都被初始化为同一个值。

想进一步了解各种进制表示法，可以看看[这篇小教程][cpp_numerical_bases]。

你可以用撇号分隔数字，让代码更易读。
`9'241`与`0b0100'100'0001'1001`或`92'4'1`是同一个值。

## 浮点数

浮点数字面量有两种写法。
除了直观的`0.0024`，还可以使用它的科学计数法写法`2.4e-3`。
最常见的浮点类型是`double`。

## 算术

C++ 支持用`+`、`-`、`*`、`/`、`(`、`)`和`%`来构成表达式。
两个整数之间进行运算，结果也是整数。
`5 / 2`会返回`2`。
当参与运算的类型中有一个是浮点类型时，结果也会是浮点数。
`5.0 / 2`和`5 / 2.0`会返回`2.5`。
`%`是求模运算符，会返回整数除法的余数：`5%3`的结果是`2`。

## 赋值运算符

赋值运算符用字面量给变量赋值。
赋值总是从右向左进行，绝不会反过来。

```cpp
int length = 5;
int width = 2;
length = width;
```

这里整数`5`被赋给变量`length`。
接着整数`2`被赋给变量`width`。
最后`width`的值被复制到变量`length`，原来的值`5`就丢失了。
还要注意，我们只是在赋值操作发生的那一刻把`width`的值赋给`length`。
因此，如果`width`的值之后发生变化，并不会影响`length`的值。

赋值运算符可以与其他运算符（算术运算符和位运算符）组合使用，这就是所谓的`compound assignment`运算符，包括`+=`、`-=`、`*=`、`/=`、`%=`。
这些运算符会先对变量的当前值执行一次运算，然后再修改它。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

变量`people`和`eggs`被初始化为`0`。
然后，我们把整数`2`加到变量`people`原有的值`0`上，再赋值回`people`。
现在`people`变成了`2`。
接着，我们给每人加`3`个鸡蛋，总共就是`6`个鸡蛋。
现在把`6`加到变量`eggs`原有的值`0`上，再赋值回`eggs`。
现在`eggs`就是`6`了。
等价的表达式是`people = people + 2`和`eggs = eggs + (3 * people)`。
