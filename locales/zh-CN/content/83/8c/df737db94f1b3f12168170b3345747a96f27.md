# 简介

字符串用于表示文本数据。
在 Swift 中，[`String`][strings-and-characters] 是由 `Character` 值组成的有序集合，其中每个字符都代表一个 Unicode 字符。

使用字符串字面量创建字符串，字符串字面量是由双引号（`"`）包围的字符序列。
对于多行字符串，使用三个双引号（`"""`）：

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Swift 字符串可以与 Foundation 框架的 [`NSString`][nsstring-docs] 类无缝衔接，从而获得丰富的文本处理能力。

## 字符

一个 `Character` 表示单个扩展字形簇，也就是一个由一到多个 [Unicode 标量值][unicode-scalar-values] 组成的、人类可读的字符。
Unicode 标量值是一个 21 位的码点，取值在 `U+0000` 到 `U+D7FF` 之间（含两端），或在 `U+E000` 到 `U+10FFFF` 之间（含两端）。

```swift
let aChar: Character = "A"
```

## 类型推断

当你编写字符串字面量时，Swift 会自动将其类型推断为 `String`。
若要将单个字符存储为 `Character`，必须提供显式的类型注解：

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## 拼接

你可以使用加法运算符（`+`）把字符串拼接在一起：

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

如果不先把字符转换成字符串，就无法用 `+` 直接把 `Character` 拼接到 `String` 上。
不过，你可以使用 [`append(_:)`][append] 方法，把字符串或字符直接追加到可变字符串上：

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## 字符串插值

[字符串插值][string-interpolation] 让你可以在字符串字面量中嵌入常量、变量、字面量和表达式，从而构造出字符串。
每个表达式都要放进一对括号里，并在括号前加上反斜杠（`\(` ... `)`）：

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## 字符串和字符的属性

字符串和字符提供了若干属性，用于查看它们的内容。

### 字符串属性

常见的字符串属性包括：

| 属性      | 说明                                           | 示例                             |
| --------- | ---------------------------------------------- | -------------------------------- |
| `isEmpty` | 如果字符串不含任何字符，则返回 `true`          | `"Hello".isEmpty` 的值为 `false` |
| `count`   | 返回字符串中字符的个数                         | `"Hello".count` 的值为 `5`       |

完整的属性列表请参阅 [Apple 的 String 文档][string-docs]。

### 字符属性

常见的字符属性包括：

| 属性           | 说明                                       | 示例                                 |
| -------------- | ------------------------------------------ | ------------------------------------ |
| `isLowercase`  | 如果字符是小写，则返回 `true`              | `"a".isLowercase` 的值为 `true`      |
| `isUppercase`  | 如果字符是大写，则返回 `true`              | `"A".isUppercase` 的值为 `true`      |
| `isNumber`     | 如果字符是数字，则返回 `true`              | `"1".isNumber` 的值为 `true`         |
| `isWhitespace` | 如果字符是空白字符，则返回 `true`          | `" ".isWhitespace` 的值为 `true`     |

完整的属性列表请参阅 [Apple 的 Character 文档][character-docs]。

## 类型转换

你可以使用 `String(_:)` 构造器把其他类型转换成字符串，它支持 `Int`、`Double` 和 `Character` 等标准类型：

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## 特殊字符

Swift 字符串字面量支持多种[转义序列][special-characters]，用于表示特殊字符：

| 序列       | 说明                          |
| ---------- | ----------------------------- |
| `\0`       | 空字符                        |
| `\\`       | 反斜杠                        |
| `\t`       | 水平制表符                    |
| `\n`       | 换行符                        |
| `\r`       | 回车符                        |
| `\'`       | 单引号                        |
| `\"`       | 双引号                        |
| `\u{n}`    | 任意 Unicode 标量（十六进制） |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
