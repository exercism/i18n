# 关于

[符号][symbols]是具名标识符，可以用来指代某个值。符号通过符号字面量创建，做法是在名称前加上 `:` 字符，例如 `:foo`。符号也可以写成带引号的形式，例如 `:"foo"`，这样一来，名称中就可以包含空格等内容。

```ruby
:foo # => :foo
:"foo boo" # => :"foo boo"
```

符号在这门语言中用途广泛，包括用作哈希的键，以及表示方法名和变量名。

## 标识符

符号与字符串的区别在于，符号是标识符，并不表示数据或文本。这意味着同名的两个符号永远是同一个对象。

```ruby
"foo".object_id # => 60
"foo".object_id # => 80
:foo.object_id # => 1086748
:foo.object_id # => 1086748
```

## 修改符号

符号是不可变的，这意味着它们不能被修改。因此，当你“修改”一个符号时，实际上是在创建一个新符号。有几个方法可以用来操作符号，它们都会返回新的符号。所有方法都可以在 [Symbol API][symbols-api] 中找到。

```ruby
:foo.upcase # => :FOO

:foo.object_id # => 1086748
:foo.upcase.object_id # => 60
```

符号不可变的好处是，它们比字符串更节省内存，用作标识符也更安全。

## 转换

符号可以转换成字符串，反过来也可以。当你想修改一个符号，或者想把符号当作字符串使用时，这会很有用。要把字符串表示为符号，可以使用 `String#to_sym` 方法；要反过来，可以使用 `Symbol#to_s` 方法。由于符号可用的方法数量有限，如果需要得到一个新符号，先把符号转成字符串，再对它使用字符串方法，会很有用。

```ruby
:foo.to_s # => "foo"
"foo".to_sym # => :foo
```
