# 说明补充

## 词

定义一个`school`元组来保存名单（如何在其内部存储学生由你决定），然后实现下面的词。

- `<school> ( -- school )`：构造一个空的 school。
- `add-student ( school name grade -- ? )`：将`name`添加到`grade`。成功时返回`t`，如果`name`已经被添加过（无论是这个年级还是其他年级），则返回`f`，此时名单保持不变。
- `roster ( school -- names )`：所有学生，先按年级排序，再按名字的字母顺序排序。
- `grade ( school n -- names )`：年级`n`中的学生，按名字的字母顺序排序。
