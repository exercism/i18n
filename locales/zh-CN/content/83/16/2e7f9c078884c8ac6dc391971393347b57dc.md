# 介绍

## 泛型

一个类型如果可以使用*类型参数*容纳任意类型的值，那么它就是*泛型类型*。

例如，下面这个`Box`类型的类型参数是`a`（用小写字母写出）。

```gleam
pub type Box(a) {
  Box(a)
}
```

`a`类型参数是任意类型的占位符，所以`Box`可以用于字符串、整数或其他任何类型。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

一个类型可以有多个类型参数，它们之间用逗号分隔。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

### 泛型函数

类型参数也可以用在函数的形参中。

下面这个函数接受一个`a`类型的值，并把一个接受`a`、返回`b`的函数调用两次。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
