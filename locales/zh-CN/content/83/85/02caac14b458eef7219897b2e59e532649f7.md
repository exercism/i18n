# 介绍

函数是一段有组织、可重复使用的代码块，用来执行某种操作。
在 JavaScript 中，定义函数有多种方式。
这里我们来看看_函数声明_和_函数表达式_。
其他方式，比如[箭头函数][concept-arrow-functions]，会在其他概念中介绍。

## 函数声明

在 JavaScript 中，定义函数的标准方式是_函数声明_，也叫_函数定义_或_函数语句_。

它由`function`关键字、函数名，以及写在括号中、用逗号分隔的形参列表组成。
后面是用大括号括起来的函数体（一组定义函数做什么的语句）。

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

在 JavaScript 中，要调用一个函数，先写出函数名，再在后面跟上含有实参的括号。

```javascript
someName(arg1, arg2, arg3);
```

## 形参

在函数体内使用形参时，要留意可能出现的副作用。

- [基本数据类型][mdn-primitives]的值是_不可变的_。
  函数体中对实参做了什么，都不会影响原始值。
- 对于其他所有值（对象、数组、函数），重新赋值不会影响原始值。
  不过，如果你修改了这样的实参（比如给对象添加一个键），传入的原始值也会一并被修改。

在 JavaScript 中，函数声明里定义的所有形参默认都是可选的。
如果你提供的实参比形参少，缺少的实参在函数内部就是`undefined`，参见 [Null 与 Undefined][concept-null-undefined]。
很多时候，赋一个比`undefined`更合适的默认值是有意义的。
只要在函数定义中直接指定默认形参就能做到。

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## `return`语句

`return`语句会结束函数的执行，并指定一个返回给函数调用者的值。一个函数可以有多个`return`语句。

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

如果函数没有返回值，也没有`return`语句，那么它的结果就是`undefined`。
JavaScript 中没有隐式的`return`。

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

在 JavaScript 中，你只能返回一个值。
如果想传递更多信息，就需要先把它们组合成一个整体，通常是一个[对象][concept-objects]或一个[数组][concept-arrays]。

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## 函数表达式

函数声明是一条独立的语句。
但有时，把函数定义成另一个表达式的一部分会更有用，比如在赋值中、作为函数形参（[回调][concept-callbacks]），或者作为[对象][concept-objects]中的值。
这可以用函数表达式来实现。
它的语法和函数声明相同，只是可以省略函数名，从而创建一个_匿名函数_。

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
