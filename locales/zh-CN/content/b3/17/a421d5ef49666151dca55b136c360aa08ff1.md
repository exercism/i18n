# 关于

Gleam 用`Bool`类型表示 true 和 false 值。只有两个值：`True`和`False`。这些值可以绑定到变量：

```gleam
let true_variable = True
let false_variable = False
```

`&&`、`||`和`!`运算符可用于操作布尔值：

```gleam
True && True  // -> True
True && False // -> False

False || True  // -> True
False || False // -> False

!False // -> True
!True  // -> False
```

`&&`和`||`运算符使用短路求值，这意味着运算符右侧的表达式只在需要时才会被求值。

每个运算符都有不同的优先级，其中`!`在`&&`和`||`之前求值。可以使用大括号来先求值表达式的一部分，然后再求值其他部分：

```gleam
!True && False   // -> False
!{True && False} // -> True
```
