# `for`循环

循环是编程中的一个基础概念，它让你可以多次运行同一个代码块。
在 Swift 中，循环分为两种：[`for-in`循环][for-loops]和`while`循环。
本章将介绍`for-in`循环。

`for`循环让你可以迭代一个值序列，依次取出每个元素，把它绑定到一个你自己命名的变量上。
Swift 允许你迭代各种序列，比如范围、数组和字符串（还有更多类型，稍后会讲到）。
序列中的每个元素都迭代完后，循环就会结束。

`for`循环使用`for`关键字声明，后面依次跟一个变量名、`in`关键字，以及要迭代的值序列。
`for-in`循环中给出的变量是不可变的，也就是说，你无法在循环内部修改它的值。
下面是一个`for-in`循环迭代数字数组的例子：

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
`number`变量是在`for-in`循环中声明的，只在循环的作用域内可用。

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## 迭代范围

你也可以用`for-in`循环迭代一个数字范围。
这样可以让你把一段代码运行指定的次数。例如，范围`1...5`会迭代数字 1、2、3、4、5，所以循环会运行 5 次。
有时你想迭代数组这类数据结构中的下标，这时可以使用`0..<array.count`范围。

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## 迭代字符串

你也可以用`for-in`循环迭代字符串。
这样可以遍历字符串中的每个字符。需要特别注意的是，循环中给出的类型是`Character`。

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift 还提供了`stride`函数，让你可以按指定的步长在一个范围上创建序列。
然后可以用`for-in`循环来迭代它。
`stride`有两种形式：[`stride(from:to:by:)`][stride-to]和[`stride(from:through:by:)`][stride-through]，前一种不包含终点，后一种包含终点。

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

注意，`to`形参不包含终点，所以循环会一直迭代到`to`形参之前的那个数字；而`through`形参包含终点，所以在这里也会包含`10`。

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
