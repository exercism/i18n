# 关于

**单词**是 Factor 对函数的称呼。你已经在`basics`里见过数据栈和重排单词；这里你要定义自己的单词，让它们用输入来计算。

```factor
: square ( x -- x*x ) dup * ;
: hello  ( -- )       "Hello, world!" print ;
: max3   ( a b c -- max ) max max ;
```

一个定义由`:`、栈效果、主体，以及末尾的`;`组成。`( … -- … )`里的名称是写给读者看的；编译器实际检查的是输入和输出的*数量*。数量不匹配就是编译期错误，它能捕获一类 bug，而在没有这类声明的动态类型语言中，这类 bug 会变成运行时错误。

整数运算单词`+`、`-`、`*`来自`math`词汇表，每个都从栈顶取用两个数字。栈顶是右边的操作数，所以`8 3 -`计算的是`8 - 3`。

`CONSTANT:`为一个固定值定义名称；调用这个名字会把值压入栈，和其他任何单词完全一样。请把常量放在文件顶部，放在任何用到它们的单词之前。

单词的主体可以调用任何已经在作用域内的单词，包括同一文件中更早的定义、来自已导入词汇表的单词，以及你声明的常量。把小的、用途单一的单词组合起来，是构建程序的常规做法。

按照惯例：

- 单词和常量使用`lowercase-kebab-case`。
- 谓词以`?`结尾，并产生布尔值（`even?`、`empty?`）。
- 会修改输入的单词，常常和不会修改的版本共用一个名称，只能靠上下文区分。
