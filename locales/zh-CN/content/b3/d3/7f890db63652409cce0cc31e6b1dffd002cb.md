# 说明

在这个练习中，你将编写一些代码，帮助你为购买车辆做准备。

你有三个任务：一个判断你是否需要驾照，一个帮你在两辆车之间做出选择，还有一个估算一辆二手车的合理价格。

## 1. 判断你是否需要驾照

有些类型的车辆需要驾照才能驾驶。
假设只有`car`和`truck`这两类需要驾照，其他所有车辆都可以无证驾驶。

实现 `needs_license(kind)` 函数，它接收车辆的类型，返回一个布尔值，表示这种类型的车辆是否需要驾照。

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. 在两辆可能购买的车辆之间做出选择

你评估了手头可选的车辆。
你把范围缩小到了两个选项，但还需要有人帮你做最终决定。
为此，实现 `choose_vehicle(option1, option2)` 函数，它接收两辆车作为实参，返回的决定就是按字典序排在最前面的那个选项。

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. 估算一辆二手车的价格

既然你已经做出了决定，你希望在经销商那里拿到一个公道的价格。
由于你想买一辆二手车，价格取决于车龄。
粗略估算一下：假设车辆不到 3 年，价格为全新时原价的 80%。
如果超过 10 年，价格为原价的 50%。
如果车辆至少 3 年但不超过 10 年，价格为原价的 70%。

实现 `calculate_resale_price(original_price, age)` 函数。
它接收原价和车龄作为实参，返回在经销商的估算价格。

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
