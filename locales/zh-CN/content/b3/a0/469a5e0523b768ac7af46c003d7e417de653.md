# 简介

*堆*是一种集合，它总是知道自己最小的元素，并且能让你快速把这个元素取出来。它是*优先队列*的天然工具：一条等待队列，下一个被处理的不是等待最久的元素，而是最重要的元素。堆位于 [`heaps`][heaps] 词汇表中。

## 构建堆

`<min-heap>` 构建一个空堆，*最小*的键会最先出来；`<max-heap>` 则是它的镜像。

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
```

## 添加元素

每个元素都以一个*值*加一个*键*的形式存储，键就是 Factor 用来排序的优先级。`heap-push` 用来添加一个元素：

```
heap-push ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push   ! value "alice", priority 5
"bob"   2 pick heap-push   ! value "bob",   priority 2
```

堆是*可变的*：`heap-push` 会就地修改它，而不是返回一个新的堆。`heap-push` 消耗掉堆之后，用 `keep` 可以把堆重新取回到栈上。

## 查看和移除队首

`heap-peek` 返回队首元素，也就是键最小的那个值，并且*不会*把它移除。`heap-pop` 既返回这个元素，又把它移除。`heap-empty?` 会报告是否还有元素剩下，这样你就知道什么时候该停止弹出。`heap-pop-all` 一次性移除所有元素，按优先级顺序返回一个由 `{ key value }` 对组成的关联列表。

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-empty?  ( heap -- ? )
heap-pop-all ( heap -- alist )
```

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-empty? .        ! => f      (two items waiting)
dup heap-peek drop .     ! => "bob"  (smallest key, still in the heap)
dup heap-pop drop .      ! => "bob"  (smallest key, now removed)
heap-pop-all .           ! => { { 5 "alice" } }
```

`heap-pop` 和 `heap-empty?` 是一次处理一个元素的基本构件：查看或弹出队首，对它进行操作，一旦 `heap-empty?` 返回 `t` 就停下来。下面的任务用 `heap-pop-all` 一步清空整个队列，但如果一直弹出直到堆为空，得到的顺序也是一样的。

`heap-pop-all` 返回的这些对是一个*关联列表*：`values`（位于 `assocs` 中）只保留值，丢弃键。
