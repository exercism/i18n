# 关于

值的作用域指的是在程序中可以访问该值的位置。

## 作用域的四种类型：代码块、函数、函数原型、文件

### 代码块作用域

具有代码块作用域的值只能从定义它的代码块内部访问。
关于代码块的更多内容，请参阅[代码块概念](../blocks/introduction.md#Introduction)。

### 函数作用域

函数作用域是一种特殊的作用域，适用于与`goto`语句一起使用的标签。
在同一个函数中，不能使用两个同名的标签，即使这两个标签定义在函数内不同的代码块中。

### 函数原型作用域

函数原型作用域是另一种特殊的作用域，只适用于在原型（也叫声明，注意并非所有声明都是原型）中命名的形参。
在函数声明中，形参的名称通常是可选的。
名称的作用域只在声明内部有效。
在下面的例子中，`len`标识符先被定义，随后在函数声明中被引用。

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

注意，在同一个声明中，引用同一个变量时，名称必须对应得上。
如果把`my_func`声明为`void my_func(int len, int numbers[length]);`，就会产生类似下面这样的编译错误

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

函数定义不必为形参使用与函数声明中相同的名称。
在上面的例子中，声明中使用了`len`，定义中使用了`length`，这说明`len`标识符的作用域仅限该函数声明内部。

### 文件作用域

具有文件作用域的值可以在文件中的任何位置访问。
这类值都定义在函数之外。
