# 简介

## 相等性

Elm 类型可以用相等运算符`(==)`来检查是否“相同”。不等运算符是`(/=)`（*不是*许多语言里的`!=`）。相等运算符适用于字面量、元组、记录和自定义类型。

```elm
1 == 2
    --> False

1 /= 2
    --> True

(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

注意，*绝对不要*比较函数，这会导致程序在运行时崩溃。

## 比较

比较运算符`(<)`、`(<=)`、`(>)`、`(>=)`以及函数`min`、`max`、`compare`适用于`comparable`类型。`comparable`类型是一种特殊类型，它把所有可以比较的内置类型归为一类：数字、字符、字符串、由可比较项组成的数组，以及由可比较项组成的元组。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")
```

记录、自定义类型等其他类型的值不能直接比较。

有些内置类型要求其内容必须是`comparable`，比如`Set`或`Dict`的键，因为它们的结构依赖内部排序。

由`comparable`值组成的数组可以用`List.sort`排序，能映射为可比较值的数组则可以用`List.sortBy`排序。如果你需要分级排序（先按一个属性排序，遇到相同的再用另一个属性区分），也可以对元组或数组使用`List.sortBy`，因为元组和数组都按字典序排序。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

函数`compare`接受两个`comparable`值，返回一个`Order`。`Order`是一种类型，它能在一次操作中判断一个值比另一个值大（`GT`）、相等（`EQ`）还是小（`LT`）。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

可以为任意类型构造比较函数，并用它来排序，例如配合`List.sortWith`使用：

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
