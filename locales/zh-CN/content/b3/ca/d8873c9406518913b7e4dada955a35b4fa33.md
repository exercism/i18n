# 简介

和许多语言一样，在 Common Lisp 中，数组是一组通过整数下标访问的元素。数组元素的类型可以各不相同。数组可以是多维的，而不只是一维的。

## 创建

`make-array`可以用来创建数组。它有很多选项，但最简单的几种用法就能创建 N 维数组：可以把所有元素都初始化为同一个值，也可以用另一个序列（比如数组）中的值来初始化数组。
它的第一个参数给出每个维度的大小。

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

（注意，N 维数组打印出来时会带上维数。）

也可以直接用数组打印时的格式来创建数组：

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

## 访问元素

要访问向量中的元素，可以使用`aref`，下标从 0 开始。
提供的下标数量必须与数组的秩一致。

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
