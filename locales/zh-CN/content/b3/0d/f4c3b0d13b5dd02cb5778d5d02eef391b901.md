# `while`循环和`until`循环

循环是一种控制结构，可以让代码根据给定的条件重复执行。

## `while`循环

`while`循环是一种控制结构，可以让代码根据给定的条件重复执行。
只要条件为真，`while`循环中的代码就会继续执行。
当迭代次数事先未知时，通常会用`while`循环；不过只要需要循环，任何场合都可以用它。

条件会在循环中的代码执行之前先求值，也就是说，如果条件为假，循环中的代码就永远不会执行。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

如果想迭代一个字符串，可以按照字符串的长度来循环。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`循环

`until`循环的工作方式和`while`循环相同，只是循环中的代码会一直执行，直到条件为真为止。
这和`if`与`unless`之间的区别是一样的。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 无限循环

使用`while`循环时，一个常见的错误是进入“无限循环”，从此再也退不出来。
无限循环可能是由于条件永远不为真也不为假造成的。
这通常是程序员的失误造成的，比如忘记让循环变量自增。
但有时候，无限循环是实现程序逻辑最清晰的方式。
有时候又必须让循环一直运行下去，比如 HTTP 服务器会等待一个连接进来，处理它，然后再等待下一个连接。

## `break`

用`break`关键字可以提前跳出循环。
当你想在特定条件下提前跳出循环时，它会很方便。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

用`next`关键字可以跳到循环的下一次迭代。
当你想跳过循环中的某几次迭代时，它会很方便。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## 循环中的类型

循环中变量的类型可能会发生变化。
在下面的例子中，`a`的类型是`Int32 | String`，因为在循环的前半部分，它既可能是`Int32`，也可能是`String`。
变量`a`只在循环的前半部分具有`Int32 | String`类型，因为循环开始时它保存的是`Int32`，而到第二次迭代时，它保存的是`String`。
这种多类型系统会在后面详细讲解。
不过，由于我们确信循环的后半部分只会保存`String`，所以在循环的后半部分，`a`的类型是`String`。
在运行时，它绝不会同时保存`Int32`和`String`。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```

# `return`

在 Crystal 中，方法会返回最后一个表达式的值。
不过，有时候你需要在最后一个表达式之前就返回一个值。
为此，可以使用`return`关键字，它会返回紧随其后的那个表达式的值。
写在`return`关键字后面的代码不会被执行。

```crystal
def speed_limit(road_number)
    if road_number == 1
        return 50
        puts "This will not be executed"
    elsif road_number == 2
        return 80
        puts "This will not be executed"
    end
    100
end

p speed_limit(1) # => 50
p speed_limit(2) # => 80
p speed_limit(3) # => 100
```

~~~~exercism/note
当方法中最后一个表达式就是要返回的值时，应省略`return`关键字。
~~~~
