# 说明

在本练习中，你将编写一些代码，帮助你按照最喜欢的烹饪书做出一份美味的千层面。

一共有五个任务，都和烹饪千层面所花的时间有关。

## 1. 定义预期的烤箱时间（分钟）

定义不可变变量`expectedMinutesInOven`，它返回千层面应该在烤箱中烤多少分钟。
这个变量必须导出。
根据烹饪书，预期的烤箱时间（分钟）是 40：

```nim
nim> expectedMinutesInOven
40 == type int
```

## 2. 计算剩余的烤箱时间（分钟）

实现`remainingMinutesInOven`过程，它接收千层面已经在烤箱中烤的分钟数作为参数，并根据上一任务中定义的预期烤箱时间（分钟），返回千层面还需要在烤箱中烤多少分钟。

```nim
nim> remainingMinutesInOven(30)
10 == type int
```

## 3. 计算准备时间（分钟）

实现`preparationTimeInMinutes`过程，它接收你为千层面添加的层数作为参数，并返回你准备千层面所花的分钟数，假设每层需要 2 分钟准备。

```nim
nim> preparationTimeInMinutes(2)
4 == type int
```

## 4. 计算总工作时间（分钟）

实现`totalTimeInMinutes`过程，它接收两个参数：`numberOfLayers`参数是你为千层面添加的层数，`actualMinutesInOven`参数是千层面已经在烤箱中烤的分钟数。
该过程应返回你在烹饪千层面上总共工作了多长时间（分钟），也就是准备时间（分钟）与千层面此刻在烤箱中已经烤的分钟数之和。

```nim
nim> totalTimeInMinutes(3, 20)
26 == type int
```
