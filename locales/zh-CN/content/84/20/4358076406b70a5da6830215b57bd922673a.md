# 关于

在 Java 中处理数字时，一个关键点就是区分整数（小数点后没有数字）和浮点数（小数点后有一位或多位数字）。

除了`int`和`double`，Java 还有其他[数据类型][numeric-datatypes]：

```java
// 8-Bit Integer
byte   a = 127;

// 16-Bit Integer
short  b = 262143;

// 64-Bit Integer
long   d = 18446744073709551999L;

// 32-bit Single-Precision Floating-Point
float  e = 5409.29f;
```

整数和浮点数都可以用`_`字符作为_数字分隔符_，在定义较大的数字时很有帮助：

```java
int largeInt = 1_000_000;
// => 1000000

double largeDouble = 9_876_543.21;
// => 9876543.21
```

算术运算使用标准的[算术运算符][arithmetic-operators]（`+`、`-`、`*` 等）。
数字可以用标准的[比较运算符][comparison-operators]（`<`、`>=` 等）进行比较，也可以用相等运算符（`==`）和不等运算符（`!=`）。

```java
5 * 6
// => 30

1.2 > 0.8
// => true

120 == 100
// => false

2 != 4
// => true
```

在数字类型之间转换时，有两种类型转换：

1. 隐式转换：不会丢失数据，也不需要额外的语法。
2. 显式转换：可能会丢失数据，需要额外的语法，也就是_强制转换_。

由于`int`的精度比`double`低，从`int`转换成`double`是安全的，因此属于[隐式转换][type-casting]。
不过，从`double`转换成`int`可能会丢失数据，所以需要[显式转换][type-casting]。

```java
int i = 9;
double d = 2.72;

// Safe conversion, thus implicit conversion
double fromInt = i;

// Potentially unsafe conversion, thus explicit conversion
int fromDouble = (int)d;
```
