# 说明补充

## 输入格式

每个骨牌都存储为单个字节，左半部分位于高 [nibble]，右半部分位于低 [nibble]。例如，骨牌 `[2|1]`、`[2|3]` 和 `[1|3]` 表示为字节 `0x21 0x23 0x13`。

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| ------ | ---- | ---- | ---- |
| `$a0` | 输入 | 地址 | 骨牌字节数组 |
| `$a1` | 输入 | 整数 | 骨牌的数量 |
| `$v0` | 输出 | 布尔值 | 骨牌能否连成一条链（`0` = `false`，`1` = `true`） |
| `$t0-9` | 临时 | 任意 | 用于临时存储 |


[nibble]: https://en.wikipedia.org/wiki/Nibble
