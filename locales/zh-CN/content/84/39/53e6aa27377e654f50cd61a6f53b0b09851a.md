# 说明

在这个练习中，你要帮一对高中情侣在社交媒体上表达爱意，用他们名字的首字母生成一个 ASCII 爱心：

```
❤ J.  +  M. ❤
```

## 1. 清理名字

实现`HighSchoolSweetheart.clean_up_name`方法。
它接收一个名字，把其中所有的`-`字符替换成空格。
同时还要去掉名字开头和结尾的空白字符。

```crystal
HighSchoolSweetheart.clean_up_name("Jane-Ann")
# => "Jane Ann"
```

## 2. 取名字的首字母

实现`HighSchoolSweetheart.first_letter`方法。
它接收一个名字，返回它的第一个字母。
记得复用上一步定义的`HighSchoolSweetheart.clean_up_name`。

```crystal
HighSchoolSweetheart.first_letter("Jane")
# => "J"
```

## 3. 把首字母格式化成缩写

实现`HighSchoolSweetheart.initial`方法。
它接收一个名字，返回它的大写首字母，后面跟一个点。
记得复用上一步定义的`HighSchoolSweetheart.first_letter`。

```crystal
HighSchoolSweetheart.initial("Robert")
# => "R."
```

## 4. 把缩写放进爱心里

实现`HighSchoolSweetheart.pair`方法。
它接收两个名字，返回首字母缩写，两边配上爱心 emoji。
记得复用上一步定义的`HighSchoolSweetheart.initial`。

```crystal
HighSchoolSweetheart.pair("Blake Miller", "Riley Lewis")
# => "❤ B.  +  R. ❤"
```
