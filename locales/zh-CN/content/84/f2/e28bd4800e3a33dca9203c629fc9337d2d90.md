# 提示

## 通用

- 每个任务都是拿一个值与一个固定的数组做比较，这正是`case`的用处。
- 每个`case`都需要一个`else`，即使它上面的分支看起来已经很完整。没有`else`，某个匹配不上任何分支的值就会让程序停下来。

## 1. 某个区域的车费

- 三个`when`分支和一个`else`。`else`覆盖所有不属于某个区域的数字。
- 0 区和未知区域都不收费，但它们是不同的情况；把它们写成单独的分支，才能表达出本意。

## 2. 哪种车票？

- `'c'`和`'s'`给出相同的答案，所以它们共用一个分支：`when 'c', 's' then`。
- 单引号：实参是`CHAR`，不是`STR`。

## 3. 哪类日子？

- 两个分支，一个列出两天，一个列出五天。
- 字符串用`=`比较的方式和数字一样，所以它们可以原样用在`case`里。

## 4. 每日上限

- 你已经有一个例程，可以把一天变成一类日子。调用它，然后对结果做`case`。
- 这样做意味着那组日子只写一次。在这里把它重复一遍，正是这个任务专门要让你犯的错误。
