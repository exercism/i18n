# 字符串

**字符串**是一段文本。Sather 中字符串的类型是`STR`，写在一对双引号之间。

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## 拼接字符串

`+`可以把两个字符串首尾相接。

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

它不会在两者之间自动加任何东西，所以想要空格就得自己加上。漏掉的话就会得到`"JeanSibelius"`。

## 字符串有多长？

`.size`表示字符串包含多少个字符。这是一个整数，所以类型是`INT`。

```sather
"Sibelius".size      -- 8
```

`.size`后面没有括号，就像不接收实参的例程一样。

## 截取一部分

`.head(n)`返回前`n`个字符，`.tail(n)`返回后`n`个字符。

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head`从前面数，`tail`从后面数。两者都不会改动原来的字符串，而是返回一个新的字符串。
