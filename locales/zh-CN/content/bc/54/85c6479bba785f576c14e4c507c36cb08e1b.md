# 介绍

## 匿名函数

Gleam 的函数是一等公民，也就是说函数就是普通的值：可以赋值给变量，可以作为实参传递，也可以从其他函数中返回。

在模块中定义的具名函数，可以通过它的名字来引用。

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam 也有匿名函数，它们定义在其他函数内部。

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

函数的类型使用与匿名函数类似的语法书写。一个接收`Int`和`Float`、返回`Int`的函数，它的类型是这样写的：

```gleam
fn(Int, Float) -> Int
```

匿名函数可以引用定义它们时处于作用域中的变量，这使它们成为_闭包_。

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_函数捕获_语法提供了一种便捷的简写方式，用来创建把单个实参传递给某个函数的匿名函数。下面两个表达式是等价的：

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
