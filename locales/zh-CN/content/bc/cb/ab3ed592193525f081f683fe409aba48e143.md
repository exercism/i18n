# 简介

switch 表达式可以把一个值与一组模式中的某一个情况相匹配，并返回关联的值，或执行关联的操作。这种关联由`=>`符号表示。此外，每个模式都可以有一个可选的分支守卫，用`when`关键字引入。只有当分支守卫表达式的求值结果为 true 时，switch 的这个分支才会被选中。这些情况（也叫 _switch 分支_）按文本顺序依次求值，一旦找到匹配，过程就会提前结束，并返回关联的值。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
