# 维护者的代码仓库权限

赛道维护者就是赛道 GitHub 团队的成员。加入赛道团队_仅限邀请_。

```exercism/note
如果你想成为赛道维护者，请在[论坛](https://forum.exercism.org/c/exercism/building-exercism/125)上发一个主题帖。
```

## 维护类别

维护类别共有五种：

1. `wip-track`
2. `unmaintained`
3. `maintained-solitary`
4. `maintained-autonomous`
5. `maintained`

赛道的维护类别由三个变量决定：

1. 赛道是否活跃（即学生可以在网站上加入该赛道）
2. 赛道维护者的数量
3. 同时也在 GitHub 团队 `cross-track-maintainers` 中的赛道维护者数量

要确定维护类别，请从下表中找到与赛道匹配的第一个类别：

| 类别                  | 是否活跃 | 维护者数量 | 跨赛道维护者数量 |
| --------------------- | ------- | --------------------- | --------------------------------- |
| wip-track             | 否      | 任意                   | 任意                               |
| unmaintained          | 是      | 0                     | 0                                 |
| maintained-autonomous | 是      | > 0                   | = 维护者数量           |
| maintained-solitary   | 是      | 1                     | 0                                 |
| maintained            | 是      | > 1                   | < 维护者数量           |

## 代码仓库权限

维护类别用于设置赛道的 GitHub 代码仓库的权限。

| 类别                  | 需要 PR | 需要 PR 审批 | 跨赛道团队审查 |
| --------------------- | ----------- | -------------------- | ------------------------ |
| wip-track             | 否          | 否                   | 否                       |
| unmaintained          | 是         | 是                  | 是                      |
| maintained-solitary   | 是         | 是                  | 是                      |
| maintained-autonomous | 是         | 否                   | 否                       |
| maintained            | 是         | 否                   | 否                       |

```exercism/caution
`wip-track`类别是唯一允许维护者推送到`main`的类别。
```

```exercism/caution
工具代码仓库_始终_需要 PR 审批，因为它们的内容通过 [CODEOWNERS 文件](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-code-owners)受到保护。
```
