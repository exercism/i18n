# 关于

Elixir 中有两种不同的数字：整数和浮点数。

整数是没有小数部分的数。

```elixir
integer = 3
# => 3
```

在[`Integer`][integer]模块中，有一些处理整数的实用函数。

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

大整数（浮点数也一样）通常会用下划线每 3 位数字分成一组。

```elixir
1_000_000
# => 1000000
```

Elixir 中数字的最大大小只受系统可用内存的限制，因为 Elixir 使用[任意精度算术][arbitrary-precision-arithmetic]。

Elixir 还支持用简写方式输入[二进制、八进制和十六进制整数][integers-in-other-bases]。

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## 比较

如果整数和浮点数的值相同，就可以认为它们相等（[`==`][kernel-equal]）。不过，它们是不同的数据类型，所以永远不会严格相等（[`===`][kernel-strictly-equal]）。

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
