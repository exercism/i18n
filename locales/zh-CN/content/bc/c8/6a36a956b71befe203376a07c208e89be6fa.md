# 简介

Unison 用 `Boolean`类型表示 true 和 false 这两种值。它只有两个值：`true`和`false`。

```unison
trueVariable = true
falseVariable = false
```

布尔表达式的求值会用到三种运算符：与运算符，写作 `&&`；或运算符，写作 `||`；以及非运算符，写作 `not`。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Unison 的布尔表达式支持短路求值：如果 `&&`表达式的第一个参数是 `false`，就没有必要继续计算第二个参数。同样，如果 `||`表达式的第一个参数是 `true`，表达式会立即返回 `true`。

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
