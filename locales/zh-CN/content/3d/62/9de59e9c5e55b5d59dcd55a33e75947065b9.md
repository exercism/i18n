# 自定义迭代器

```sather
   markers!(once spacing : INT, once count : INT) : INT is
      loop
         yield spacing * 1.upto!(count);
      end;
   end;
```

| | 例程 | 迭代器 |
| --- | --- | --- |
| 名称 | `foo` | `foo!` |
| 返回一个值 | `return` | `yield` |
| 结束方式 | `return`，或者走到末尾 | `quit`，或者耗尽 |
| 调用位置 | 任何地方 | 只能在`loop`里 |
| 记住位置 | 否 | 是 |

## yield

`yield`交出一个值，然后暂停。下一次轮到时，一切都会恢复：局部变量、它在自己的循环中的位置，以及它正在调用的任何迭代器的位置。

嵌套循环里的`yield`会在最内层循环处恢复，这正是让遍历嵌套结构的代码变得简单的原因：

```sather
   all_cells!(grid : ARRAY{ARRAY{INT}}) : INT is
      loop
         row ::= grid.elt!;
         loop
            yield row.elt!;
         end;
      end;
   end;
```

## quit

结束迭代器，也就结束了调用它的循环。它不携带任何值：`quit`不是最后的结果，而是宣告没有结果了。

有返回类型的迭代器，每次`yield`都必须交出一个值；`quit`正是它拒绝交出值的方式。

## once

```sather
   markers!(once count : INT) : INT is
```

`once`实参在进入循环时求值一次并保留下来。普通实参每一轮都会重新求值，当传入的表达式里含有另一个迭代器调用时，这一点很重要：

```sather
   loop
      #OUT + TRAIL::markers!(sizes.elt!);     -- a new count every turn
   end;
```

除非你确实想要每次重新求值，否则就把实参标记为`once`。整个库都这么做。

## self 和迭代器

迭代器可以在一个对象上调用，这时`self`就是那个对象。它暂停时的状态属于调用处，而不属于对象本身，所以两个遍历同一个对象的循环不会互相干扰。

## 什么时候该自己写一个

当答案是一个序列，而且应该由调用方决定取用其中多少时，就写一个迭代器。提前停止不花任何代价，也不会构建任何用不到的东西；相比之下，返回`ARRAY`的例程必须先构建出整个结果。
