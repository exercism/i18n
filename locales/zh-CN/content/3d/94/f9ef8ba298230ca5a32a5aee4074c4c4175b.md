# 简介


## 布尔值

PowerShell 有[`bool`][booleans]类型来表示 true 和 false 值。
这个类型只有两个值：`True`和`False`。
你可以用`$`前缀把这些值绑定到变量：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我们可以使用[逻辑运算符][logical-operators]来组合和求值布尔表达式，比如`-and`、`-or`和`-not`。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```


## 基于注释的帮助

PowerShell 中的[`Comment-based help`][comment-based help]可以为写在注释中的函数和脚本提供详细信息。
它使用特殊的帮助注释关键字来指定重点关注的主题，例如`.SYNOPSIS`、`.EXAMPLE`或`.NOTES`。

```powershell
function ExampleFunction($Arg) {
    <#
    .DESCRIPTION
    A detailed description of the function or script. This keyword can be used only once in each topic.

    .PARAMETER Arg
    The description of a parameter, it must be follow with the parameter name.
    #>
}
```

你可以使用 cmdlet `Get-Help`来显示基于注释的帮助信息。

```powershell
> Get-Help -Name "ExampleFunction"
```
