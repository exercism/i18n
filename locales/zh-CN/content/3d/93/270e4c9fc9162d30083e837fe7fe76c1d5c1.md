# 说明

你是一位热衷于观鸟的人，会记录过去 7 天里有多少只鸟来到你的花园。

你有 5 个任务，都与你花园里来访鸟类的数量有关。

## 1. 查看上周的计数

为了便于比较，你总是在手边保留一份上周计数的副本，它们是：0、2、5、3、7、8 和 4。实现`BirdCount.last_week`方法，返回上周的计数：

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. 查看昨天有多少只鸟来访

实现`BirdCount#yesterday`方法，返回昨天有多少只鸟来到你的花园。这些鸟类计数按天排序，第一个元素是最早那天的计数，最后一个元素是今天的计数。

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. 计算来访鸟类的总数

实现`BirdCount#total`方法，返回来过你花园的鸟的总数：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. 计算忙碌的天数

有些日子比其他日子更忙。忙碌的一天是指有 5 只或更多鸟来到你花园的日子。
实现`BirdCount#busy_days`方法，返回忙碌的天数：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. 检查是否存在没有鸟来访的一天

实现`BirdCount#day_without_birds?`方法，如果有一天没有鸟来访花园，就返回`true`；否则返回`false`：

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
