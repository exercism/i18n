# 简介

Haxe 支持在运行时反射类型和字段。要想正确使用反射，就必须了解它支持哪些操作、不支持哪些操作。由于反射本质上是动态的，这一点并不总能在编译时确定。

反射 API 由两个类组成：

- `Reflect`：一个轻量级 API，最适合处理匿名结构，对类的支持有限。
- `Type`：一个更强大的 API，用于处理类和枚举。

下面的示例以 JavaScript 为目标平台：

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```
