# Instructions

随着案件推进，侦探的笔记本会越写越满；当一条条调查线索被排除后，又会重新变空。

五个任务全部放在`CASE_NOTES`类中。

## 1. 开一个案件

返回一个新的空笔记本。

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. 写下一条线索

在笔记本末尾添加一条线索。这个操作不返回任何内容，只会修改传入的笔记本。

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. 有多少条线索？

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. 排除一条线索

从笔记本中取出指定位置的线索。它之后的所有线索都会向前移动。这个操作同样不返回任何内容。

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. 回顾案件

返回笔记本中的每一条线索，用`"; "`连接。空笔记本会读作空字符串。

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
