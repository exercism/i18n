# 测试

## clojure.test

Babashka 自带 clojure.test。当你准备好做某个练习，并创建了一个文件来存放解答（例如 `bob.clj`）之后，就可以按照[这里的说明](http://clojure.github.io/clojure/clojure.test-api.html#clojure.test/run-tests)，用 `clojure.test/run-tests` 运行测试。


REPL 让你可以轻松运行代码并立即得到反馈，也可以用来运行测试。建议使用 `rlwrap` 来启用行编辑，并用上下方向键翻阅命令历史。要测试某个练习，先切换到它的目录，然后把 `src` 和 `test` 目录加入类路径，再打开 socket REPL：
``` bash
/bob $ rlwrap bb --classpath src:test socket-repl 1666
```

首先，`require` 测试命名空间：
``` clojure
=> (require 'bob-test)
nil
```

然后在 `bob-test` 上调用 `run-tests`：
``` clojure
=> (clojure.test/run-tests 'bob-test)

Testing bob-test

Ran 25 tests containing 25 assertions.
0 failures, 0 errors.
{:test 25, :pass 25, :fail 0, :error 0, :type :summary}
```

要创建测试运行脚本：

``` clojure
#!/usr/bin/env bb

(require '[clojure.test :as t]
         '[babashka.classpath :as cp])

(cp/add-classpath "src:test")                        

(require 'bob-test)                  

(def test-results
  (t/run-tests 'bob-test))           

(def failures-and-errors
  (let [{:keys [:fail :error]} test-results]
    (+ fail error)))                                 

(System/exit failures-and-errors)
```
