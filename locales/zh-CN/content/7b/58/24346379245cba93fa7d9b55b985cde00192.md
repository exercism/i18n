# 简介

[`repeat-while`循环][repeat-loops]与`while`循环类似，但有一个关键区别：条件检查发生在循环体执行*之后*，而不是之前。
因此，`repeat-while`循环保证至少执行一次代码块。

```swift
repeat {
    print("This runs at least once")
} while false

print("Loop done")

// Prints:
// This runs at least once
// Loop done
```

[repeat-loops]: https://docs.swift.org/swift-book/LanguageGuide/ControlFlow.html#ID126
