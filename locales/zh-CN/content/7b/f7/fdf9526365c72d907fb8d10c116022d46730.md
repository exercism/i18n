# 说明追加

## 提示

你需要实现 `recite` 函数，它负责输出《The Twelve Days of Christmas》的歌词。如果对类型不太确定，可以使用提供的签名，但别让它限制你的创造力。

这一练习处理的是文本数据。由于历史原因，Haskell 的 `String` 类型等同于 `[Char]`，也就是字符列表。为了更高效地处理文本数据，可以使用 `Text` 类型。

作为本练习的可选扩展，你还可以：

- 阅读 Haskell 中关于[字符串类型](https://haskell-lang.org/tutorial/string-types)的内容。
- 在 package.yaml 的依赖列表中加入 `- text`。
- 按[下面这种方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入 `Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 例如写成 `recite :: Int -> Int -> [Text]`，并用 `T.pack` 这样的方式引用 `Data.Text` 的组合子。
- 查阅 [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html) 的文档。
- 把 TwelveDays.hs 中所有出现的 `String` 替换成 `Text`，即：

```haskell
recite :: Int -> Int -> [Text]
```

这一部分完全是可选的。
