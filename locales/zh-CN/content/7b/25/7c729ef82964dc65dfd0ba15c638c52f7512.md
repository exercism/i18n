# 简介

自定义类型是 Gleam 中定义新数据类型的方式。它可以有多个_变体_，每个变体都有自己的名字。

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

自定义类型的每个变体都可以选择性地携带一些数据，不同的变体可以携带不同类型的数据。当变体携带数据时，就称为_记录_。

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

要创建一个属于某个变体的值，如果该变体不携带额外数据（`Spring`），直接引用它的名字即可；如果携带数据（`SomeInt(2)`），就要像调用函数一样调用它。

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

自定义类型和 Gleam 中的一切一样，都具有_结构化相等性_，也就是说，属于同一个变体、数据也相同的两个值是相等的。

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

可以使用 case 表达式对自定义类型的变体进行模式匹配。

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
