# 带 is_ 的 def

[comment]: # （- expected：修正后的名称）

Elixir 有特定的命名约定，其中就包括如何命名[返回布尔值的函数](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)：

> 返回布尔值的函数，名称以问号结尾。

```elixir
# this is the expected name of functions that return a boolean

%{expected}

# this is the current name

%{actual}
```

注意，守卫、一些内置函数，以及那些返回布尔值且在守卫中有效的宏，遵循另一套约定：名称以 `is_` 为前缀（`def is_integer`、`defguard is_foo`、`defmacro is_foo`）。这两套约定不能混用。
