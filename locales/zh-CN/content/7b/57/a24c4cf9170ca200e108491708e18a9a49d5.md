# 说明

陛下将在[卡尔马联盟][kalmar_union]的首都哥本哈根举办一场晚宴。
这是全年最盛大的宴会，所有贵族都在受邀之列。
但全国各地都在流传谣言，说有人密谋毒害陛下。

陛下请你这位皇家验毒师查明，是否有食物或饮料被下了毒。
陛下计划只供应**Mushroom pasties**作为食物，但饮料则多种多样。

## 1. 检查食物是否正确

如果食物不是陛下点的，就极有可能被下了毒。如果食物不是陛下点的，就应该扔掉。

实现`check_food?`方法，它接受实参`food`，其中是以`String`表示的食物名称。
如果食物是`Mushroom pasties`，方法应返回该食物；否则应返回`nil`。

```crystal
CastleDinner.check_food?("Mushroom pasties")
# => "Mushroom pasties"

CastleDinner.check_food?("Bread")
# => nil
```

## 2. 检查饮料是否有毒

饮料有可能被下了毒，但判断起来要稍微困难一些。
如果饮料名称中**不**包含字母`i`，就说明它被下了毒，大小写不限。
如果饮料被下了毒，就应该扔掉。

实现`check_drink?`方法，它接受实参`drink`，其中是以`String`表示的饮料名称。
如果饮料没有被下毒，方法应返回该饮料，否则应返回`nil`。

```crystal
CastleDinner.check_drink?("Apple juice")
# => "Apple juice"

CastleDinner.check_drink?("Tea")
# => nil
```

## 3. 更换饮料

陛下不希望让宾客担心食物里有毒。
因此，如果饮料被下了毒，就应该换成一款新的饮料，也就是**Apple juice**。

实现`replace_drink`方法，它接受实参`drink`，其中是以`String`表示的饮料名称。
如果饮料没有被下毒，方法应返回该饮料，否则应返回`"Apple juice"`。

```crystal
CastleDinner.replace_drink("Orange juice")
# => "Orange juice"

CastleDinner.replace_drink("Tea")
# => "Apple juice"
```
