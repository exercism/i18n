# 简介

处理二进制数据可能比较棘手，所以 Gleam 提供了 `BitArray` 类型以及配套语法，用来构造和模式匹配二进制数据。

位数组字面量用`<<>>`语法定义。定义位数组字面量时，要按段来写。每个段都有一个值和一个标注，两者用`:`分隔。标注指定用多少位来编码这个值，也可以完全省略，省略时默认为 8 位整数值。

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

把类型写成`:1`，是`:size(1)`的简写。如果位大小来自一个变量，就需要用更长的写法。

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

## 二进制

写二进制整数字面量时，可以在字面量前面加上`0b`，直接用二进制记法书写。注意，在测试或你的程序中打印时，它们会显示为十进制数字。

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

## 截断

如果段的值超出了该段类型的容量，就会从左边被截断。

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

## 前插与追加

使用位数组语法，你既可以在一个已有位数组的开头插入内容，也可以在末尾追加内容。对已有的位数组，必须使用`:bits`标注。

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

## 拼接

我们可以用这种语法，把存在变量里的位数组拼接起来。拼接两个大小可变的位数组时，必须使用`:bits`标注。

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

## 模式匹配

也可以对位数组做模式匹配，从中获取值。你需要知道每个想要捕获的片段有多少位，只有一个例外：`:bits`标注可以用来对大小未知的位数组做模式匹配，但它只能用于最后一个片段。

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> true
```

## 查看位数组

~~~~exercism/note
位数组打印出来的格式可能和创建它时使用的格式不同。这在学习位数组时常常造成困惑。
~~~~

默认情况下，位数组以 8 位（一个字节）为片段显示，即使你创建它们时用的片段大小不同。

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

如果你创建的位数组表示一个可打印的 UTF-8 编码字符串，像`io.debug`这样的函数可能会把它显示成字符串。这源于 Gleam 在内部表示字符串方式的一个实现细节。

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
