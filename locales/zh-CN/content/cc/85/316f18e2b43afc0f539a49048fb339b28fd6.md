# 关于

C++ 中的布尔值由`bool`类型表示。
一个`bool`要么是`true`，要么是`false`。

## 逻辑运算符

C++ 支持三种布尔运算符：`!`（非）、`&&`（与）和`||`（或）。
你也可以使用替代版本`not`、`and`和`or`。

```cpp
true || false // => true
true && false // => false
!true // => false
not false // => true
```

## 优先级

这三个布尔运算符的_运算符优先级_各不相同。
因此，它们的求值顺序是：先`!`，再`&&`，最后`||`。
如果你想强制使用不同的顺序，可以把布尔表达式放在括号里（即`()`），因为括号的运算符优先级更高。

```cpp
!true && false   // => false
!(true and false) // => true
```

## 转换

如果在需要数字的地方使用`true`或`false`，它们会被分别转换为`1`和`0`。
如果在布尔运算中使用数字，那么除`0`以外的一切都会被当作`true`，甚至负数也一样。

```cpp
!true && 0.0   // => false
true + true + false // => 2
```
