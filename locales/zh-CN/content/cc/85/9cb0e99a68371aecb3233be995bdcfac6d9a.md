# 关于

处理数组时，你可能想针对数组中的每个值执行一段代码。这叫做对数组进行迭代或循环。

这里讨论的是不需要在过程中修改数组的情况。如果要变换数组，请参见[数组变换概念][concept-array-transformations]。

## `for` 循环

遍历数组最基本、通常性能也最好的方式，是使用`for`循环，参见 [for 循环概念][concept-for-loops]。

```javascript
const numbers = [6.0221515, 10, 23];

for (let i = 0; i < numbers.length; i++) {
  console.log(numbers[i]);
}
// => 6.0221515
// => 10
// => 23
```

## `for...of` 循环

如果你想在每次迭代中直接使用值，完全不需要下标，就可以使用`for...of`循环。

`for...of`和上面那个基本`for`循环的工作方式一样，只是不需要在循环中把_下标_当作变量来处理，而是直接得到_值_。

```javascript
const numbers = [6.0221515, 10, 23];

// Because re-assigning number inside the loop will be very
// confusing, disallowing that via const is preferable.
for (const number of numbers) {
  console.log(number);
}
// => 6.0221515
// => 10
// => 23
```

和普通的`for`循环一样，你可以用`continue`结束当前这次迭代，用`break`彻底结束循环的执行。

JavaScript 还有`for...in`循环，用来遍历对象中的键。要注意，`for...of`和`for...in`不能互换使用，详情请参见 [MDN 文档][mdn-for-in-for-of]。

## `forEach` 方法

每个数组都有一个`forEach`方法，也可以用它来遍历数组中的元素。

`forEach`接受一个[回调][concept-callbacks]作为形参。对数组中的每个元素，回调函数都会被调用一次。

```javascript
const numbers = [6.0221515, 10, 23];

numbers.forEach((number) => console.log(number));
// => 6.0221515
// => 10
// => 23
```

在上面的例子中，回调只把当前元素用作形参。如果需要，回调最多可以使用三个形参。

- 当前迭代的_值_
- 当前迭代的_下标_
- 整个_数组_

```javascript
const numbers = [6.0221515, 10, 23];

function callback(number, index, fullArray) {
  console.log(number, index, fullArray);
}

numbers.forEach(callback);
// => 6.0221515 0 [ 6.0221515, 10, 23 ]
// => 10 1 [ 6.0221515, 10, 23 ]
// => 23 2 [ 6.0221515, 10, 23 ]
```

除了回调之外，`forEach`还接受一个可选的第二个形参，用来指定迭代时要使用的`this`上下文。你可以在 [MDN 的“Using thisArg”一节][mdn-foreach-thisarg]中看到一个例子。

使用`forEach`时有几点需要注意。

- `forEach`循环一旦开始，就无法停止迭代。
  `break`和`continue`语句在这里并不存在。
- 如果在循环开始后修改数组，`forEach`的行为会很奇怪。
  追加到末尾的元素会被忽略，删除元素可能让其他元素被跳过，等等。
  要避免这类问题，就不要在回调中修改底层数组。
- `forEach`方法本身的返回值是`undefined`。
  因此，你无法在它后面继续链式调用其他数组方法。
- 如果你需要为性能优化代码，可以考虑改用`for`或`for...of`，因为两者的速度大约都是`forEach`的 3 倍。
