# 说明

在这个练习中，你将编写一些函数来管理预约。
系统把所有内容都存成 ISO 8601 格式的字符串，但人们使用日历时并不是这样。
要在这些格式之间相互转换，就需要用到各种函数。

## 1. 创建预约

创建一个从当前时刻起`n`天后的预约。
该函数接收`n`天，并返回从此刻起`n`天后的预约时间。

```javascript
createAppointment(4, now);
// Given now is Sun Oct 05 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
// => Sun Oct 09 2022 23:28:43 GMT+0600 (Bangladesh Standard Time)
```

如果第二个形参`now`未被使用，则应改用当前时间。

## 2. 把日期转换成时间戳

许多工具只能处理国际标准的 ISO 8601 格式。
编写函数`getAppointmentTimestamp`，让它接收一个日期，并返回这种格式的字符串。

```javascript
const appointment = new Date(Date.UTC(2010, 6, 16, 12, 42, 0, 0));

getAppointmentTimestamp(appointment);
// => '2010-07-16T12:42:00.000Z'
```

## 3. 获取预约的详细信息

时间戳很难阅读，而一个用来获取预约详情的函数可以帮上忙。
函数`getAppointmentDetails`接收一个 ISO 8601 格式的时间戳，并返回年、月、日、时和分。

```javascript
getAppointmentDetails('2022-04-24T08:15:00.000');
// => { year: 2022, month: 3, date: 24, hour: 8, minute: 15 }
```

## 4. 根据给定的选项更新预约

该函数接收的第一个实参是预约时间，第二个实参是由若干选项组成的对象。
你需要根据对象中的选项更新预约，并返回新的预约日期。
选项对象中可能包含多个选项。

```javascript
updateAppointment('2022-02-09T09:20:00.000', { month: 6 });
// => { year: 2022, month: 6, date: 9, hour: 10, minute: 20 }
```

## 5. 获取两个预约之间的可用时间

该函数接收两个预约（时间戳）作为实参。
你需要以秒为单位返回这两个时间之差。

因为半秒几乎没有意义，所以在返回之前要先把数字四舍五入。

```javascript
timeBetween('2022-12-12T09:20:00.000', '2022-12-18T08:30:00.000');
// => 515400
```

## 6. 检查预约当前是否有效

最后，预约创建之后，系统需要检查它是否有效。
换句话说，预约必须在将来，而不能在过去。

编写函数`isValid`，它接收两个实参：一个预约时间戳（字符串）和当前时间的时间戳（字符串）；给定当前时间，如果预约在将来，则返回`true`。

```javascript
isValid('2022-02-11T23:00:00.000', '2022-02-08T23:00:00.000');
// => true
```
