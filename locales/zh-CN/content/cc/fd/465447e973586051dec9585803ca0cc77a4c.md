# 说明补充

## 单词

定义一个`game`元组和一个构造函数`<game> ( -- game )`，它返回一局没有任何投球的新比赛。

提供以下用于操作一局比赛的单词：

- `roll ( pins game -- )`：记录击倒了`pins`个球瓶。当投球无效时，抛出一个错误：
  - `"Negative roll is invalid"`：球瓶数量为负数时。
  - `"Cannot roll after game is over"`：十格（以及任何补投球）全部投完后。
  - `"Pin count exceeds pins on the lane"`：被击倒的球瓶比站立的球瓶多时。
- `score ( game -- n )`：这一局比赛的总分。当比赛尚未完成时，抛出`"Score cannot be taken until the end of the game"`。

注意，`roll`会遮蔽来自`kernel`词汇表的`roll`洗牌单词。测试套件用`FROM: bowling => roll ;`来消除歧义。
