# 说明

在本练习中，你将处理储蓄账户。
每年，储蓄账户的余额都会根据其利率更新。
银行给你的利率取决于你账户里的金额（即余额）：

- 余额为负时，利率为 3.213%（余额会变得更负）。
- 余额为正且小于`1000`美元时，利率为 0.5%。
- 余额为正且大于等于`1000`美元且小于`5000`美元时，利率为 1.621%。
- 余额为正且大于等于`5000`美元时，利率为 2.475%。

本练习有四个任务，每个任务都会涉及你的余额及其利率。

## 1. 计算利率

实现方法`SavingsAccount.interest_rate()`，它接收一个余额作为实参。
该方法应返回给定余额对应的利率。

```Crystal
SavingsAccount.interest_rate(200.75)
# => 0.5
```

## 2. 计算利息

实现方法`SavingsAccount.interest()`，它接收一个余额作为实参。
该方法应返回给定余额对应的利息。

```Crystal
SavingsAccount.interest(200.75)
# => 1.00375
```

## 3. 计算年度余额更新

实现方法`SavingsAccount.annual_balance_update()`，它接收一个余额作为实参。
该方法应返回一年后的余额。

```Crystal
SavingsAccount.annual_balance_update(200.75)
# => 201.75375
```

## 4. 计算达到目标余额所需的年数

实现方法`SavingsAccount.years_before_desired_balance()`，它接收余额和目标余额作为实参。
该方法应返回达到目标余额所需的年数。

```Crystal
balance = 200.75
target_balance = 214.88
SavingsAccount.years_before_desired_balance(balance, target_balance)
# => 14
```

~~~~exercism/note
计算本金余额的单利时，将余额乘以利率，两者的乘积就是利息金额。

而复利则是定期计息。
每次计息时，先算出利息金额并加到本金余额上，这样后续的利息计算就会基于更大的本金余额。
~~~~
