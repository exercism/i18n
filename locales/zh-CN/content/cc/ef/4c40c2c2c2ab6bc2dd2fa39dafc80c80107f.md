# 阿姆斯特朗数的概念

> [阿姆斯特朗数](https://en.wikipedia.org/wiki/Narcissistic_number) 指的是这样的数：它等于自身各位数字的位数次幂之和。

## 示例解答

```rust
pub fn is_armstrong_number(num: u32) -> bool {
    let digits = format!("{}", num);
    digits
        .chars()
        .map(|c| c.to_digit(10).unwrap().pow(digits.len() as u32))
        .sum::<u32>()
    == num
}
```

## 概念

- 函数：验证解答、定义逻辑都离不开它
- 测试套件：验证解答所必需
- 整数：参数和恒等断言都使用 u32
- `&str`：需要用来统计数字的长度，因为 Rust 是强类型的
- `Option<T>`：访问 `char::to_digit` 的实际值所必需
- 类型转换：执行算术运算所必需
- 迭代器特性：
  - turbofish：让解答可以写成单个表达式
  - `map` 和 `sum`：方便地把表达式化简成我们需要断言的内容
