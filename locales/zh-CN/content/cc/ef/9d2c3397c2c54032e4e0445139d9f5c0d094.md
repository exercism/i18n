# 简介

PowerShell 是微软推出的一门动态隐式类型脚本语言（也支持强类型变量），主要专注于任务自动化和配置管理。

PowerShell 支持命令式、函数式、面向对象编程，甚至管道风格。

PowerShell 构建在 .NET 平台之上，于 2006 年首次发布。
所有现代 Windows 操作系统都默认包含它，也可以安装在 Mac 和 Linux 上。


## 变量

在 PowerShell 中，定义变量有两种常见方式。

PowerShell 中的变量名必须以`$`开头，并使用赋值运算符`=`把变量名绑定到一个值。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

如果你想强制使用特定的[类型][strong typed]，也可以显式指定变量的类型。
如果可能，PowerShell 会尽力把值从一种类型转换为另一种类型。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 常量

PowerShell 中的常量是只读变量，定义之后不能被**删除**。
这引出了定义变量的第二种方式：使用 cmdlet `New-Variable`。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

关于使用各种选项创建新变量的更详细、更高级的方法，请参阅 [New-Variable][New-Variable] cmdlet。


## 函数

PowerShell 中的[函数][functions]使用 `function` 关键字定义。
每个函数可以在 `()` 括号中拥有零个或多个[形参][parameters]，后面跟着它自己的[作用域][scope]，作用域以 `{` 开始，以 `}` 结束。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 中的函数可以使用 `FuncName $Arg` 语法调用，之后通过 `return` 关键字显式返回值。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

关于如何编写详细的函数定义，以及函数如何隐式返回值的进阶内容，将在 `Functions` 概念模块中介绍。


## 注释

PowerShell 中的单行注释以 `#` 开头，到行尾结束。
PowerShell 中的注释块以 `<#` 开头，以 `#>` 结束。
关于使用注释块创建基于注释的帮助的进阶演示，将在 `Functions` 概念模块中介绍。

```powershell
function Main() {
    #This is a comment
}
```
