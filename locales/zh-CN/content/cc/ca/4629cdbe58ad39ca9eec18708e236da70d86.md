# 关于

[守卫][guards]是[模式匹配][exercism-pattern-matching]的补充。借助它们可以进行更复杂的检查。它们可以用在[部分、但并非全部可以使用模式匹配的场合][where-guards-can-be-used]，例如函数子句或 case 子句中。

```elixir
def empty?(list) when is_list(list) and length(list) == 0 do
  true
end
```

- 守卫以`when`关键字开头，后面跟一个布尔表达式。
- 守卫表达式是特殊的函数，它们：
  - 必须是[纯函数][pure-function]，且不能修改任何全局状态。
  - 必须返回严格的`true`或`false`值。
- 常见守卫的列表可以在 Elixir 的[文档][kernel-guards]中找到。它们包括：
  - 类型检查：[`is_integer/1`][guard-is-integer]、[`is_list/1`][guard-is-list]、[`is_nil/1`][guard-is-nil] 等。
  - 算术运算符：[`+/2`][guard-plus]、[`-/2`][guard-minus] 等。
  - 比较：[`==/2`][guard-equals]、[`>/2`][guard-greater]、[`</2`][guard-less] 等。
  - 布尔运算符：[`and/2`][guard-and]、[`or/2`][guard-or]、[`not/1`][guard-not]
  - 成员运算符：[`in/2`][guard-in]
- 你可以用[`defguard`][defguard]定义自己的守卫。

  - 根据 Elixir 的[命名约定][naming]，守卫的名字应该以`is_`开头。

    ```elixir
    defmodule HTTP do
      defguard is_success(code) when code >= 200 and code < 300

      def handle_response(code) when is_success(code) do
        :ok
      end
    end
    ```
