# 关于

C# 中的`struct`与`class`紧密相关。
它们有状态和行为。
它们可以有相同类型的成员：构造函数、方法、字段、属性等。

字段和属性可以是简单类型、`struct`或引用类型。
`struct`遵守与`class`相同的作用域、读写规则和访问级别规则。

```csharp
enum Unit
{
    Kg,
    Lb
}

struct Weight
{
    private double count;
    private Unit unit;

    public Weight(double count, Unit unit)
    {
        this.count = count;
        this.unit = unit;
    }

    public override string ToString()
    {
        return count.ToString() + unit.ToString();
    }
}

new Weight(77.5, Unit.Kg).ToString();
// => "77.6Kg"
```

要记住的主要事情之一是，当一个 struct 被赋值给变量或作为参数传递时，值会被复制，因此对原始变量的更改不会影响复制出的变量，反之亦然。
总之，`struct`是**值类型**。

这篇[文章][class-or-struct]讨论了`struct`与`class`之间的区别。
从这篇文章中你会看到，`struct`往往很轻量，并且是[不可变][structs-immutable]的，尽管编译器或运行时（默认情况下）并不强制这一指导原则。

你会遇到几件事（编译器也会提醒你）：

1. `struct`的成员不能内联初始化。
2. `struct`不能被继承。
3. 即使提供了非默认构造函数，`struct`也总是有一个默认构造函数，而且你不能提供显式的无参数构造函数。

因此，根据上面的第 1 点和第 3 点，`struct`的开发者无法阻止无效实例的产生。

## 常见的 struct

从文档中你会看到，基元类型和 struct 之间有着密切的关系。
例如，请参阅[`Int32/int`][int32]。
`struct`更常规的例子是[`TimeSpan`][time-span]类型。

`TimeSpan`的实例行为很像数字，带有`>`和`<`之类的比较运算符以及算术运算符。
需要时，你可以为自己的`struct`实现这些运算符。

关于`TimeSpan`需要注意的一点是，它实现了许多接口，例如`IComparable<TimeSpan>`。
虽然`struct`不能从其他`struct`派生，但它们可以实现接口。

## 相等性

`struct`的相等性测试通常比`class`简单得多，因为默认情况下它只是比较字段是否相等。
无需重写`object.Equals()`（或`GetHashCode()`）。

请记住，如果你依赖`Object.GetHashCode()`，仍然必须确保生成哈希码所涉及的字段（也就是所有字段）在哈希集合使用期间不能改变。
实际上，这意味着以这种方式使用的 struct 应该是不可变的。

与`Equals()`方法不同，相等运算符`==`和`!=`没有默认实现。
如果你的`struct`需要它们，就必须自己实现。

另一方面，这篇[文章][equality]描述了如何通过创建自己的自定义`Equals()`和`GetHashCode()`方法来优化性能，就像`class`中经常做的那样。
在这个练习中，差异约为 20%，但这是一次不太严谨的比较，而且可能偏低，因为所有字段都是同一类型，详见下文。

[网上][equality-performance]有一些关于速度提升的讨论，讨论的是在未重写`Equals()`方法且所有字段类型相同的情况下性能的改进。
在这个练习中，包含不同类型字段带来的差异约为 60%。
Microsoft 的文档没有提到这一点，因此这是一个未文档化的实现细节，应当谨慎利用。

```csharp
public bool Equals(Weight other)
{
    return count.Equals(other.count) && unit.Equals(other.unit);
}

public override bool Equals(object obj)
{
    return obj is Weight other && Equals(other);
}

public override int GetHashCode()
{
    return HashCode.Combine(count, unit);
}
```
