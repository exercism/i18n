# 关于

这道编程练习展示了形参的若干特性：

- 不带修饰符（如`out`或`ref`）[传递][passing-parameters]的形参是按值传递的。也就是说，在被调用的方法中可以使用该形参，也可以给它赋值，但这些改动不会对调用方产生任何影响。
- 当形参是数组的引用或类的实例时，被调用的方法可以修改该实例的元素/字段，调用方也能看到这些改动。无论是否存在`ref`修饰符，情况都是如此。
- 带[`out`][out-parameter]修饰符的形参可以把值从被调用的方法传回调用方。该形参可以在未初始化的情况下传给被调用的方法，而且在被调用的方法内部，它一律被当作进入时尚未初始化来处理。要理解形参修饰符的行为和规则，最简便的方式就是看示例（见下文）和编译器消息。

```csharp
void Foo(out int val)
{
    val = 42;
}
void Bar(int val)
{
    val = 42;
}

int importantValue = 1729;
Foo(out importantValue);
var result = importantValue == 42;
// => true

importantValue = 1729;
Bar(importantValue);
result = importantValue == 1729;
// => true
```

- 被调用的方法中必须给`out`形参赋值。

- 带[`ref`][ref-parameter]修饰符的形参把值传入被调用的方法。方法返回后，调用方会在该形参中看到被调用方法所做的所有更新。

```csharp
void Foo(ref int val)
{
    val *= 7;
}

int importantValue = 6;
Foo(ref importantValue);
return importantValue;
// => 42
```

- `ref`形参必须是变量，因为被调用的方法会直接操作调用方所看到的那个形参。

- `out`和`ref`修饰符在被调用方法的签名中和调用处都是必需的。
- `out`形参可以在调用处内联声明，例如：`Foo(out int importantValue);`
- 如果调用一个带`out`形参的方法，却不关心其中某个或某些形参被赋予的值，那么可以使用[弃元][discard]占位符变量`_`，例如：`Foo(out int _);`

所有关于`ref`和`out`形参的规则都由编译器强制执行。

[`in`][in-parameter]形参也存在，但它们主要是一种性能优化，会在`structs`练习中讨论，因为在那里它们最为相关。

上面链接的文档概述如下：

- [passing-parameters][passing-parameters]：说明值如何作为实参传递。注意，结构体与形参这一主题会在`structs`练习中讨论。
- [ref-parameter][ref-parameter]：说明`ref`形参的工作方式。
- [out-parameter][out-parameter]：说明`out`形参的工作方式。

阅读文档时请注意，它使用了以下术语：

- parameter / formal parameter：指被调用的方法所看到的形参。
- argument：指调用方所看到的实参。

[可以说][so-tuples-vs-out]，C# 7 引入`tuples`之后，`out`形参的大部分价值已经被消除。`tuples`练习展示了用`tuples`返回多个值。

虽然`ref`用起来简单，也没有性能损失，但在广泛使用之前，值得先看看它所针对的那些问题在某个具体代码库中是如何处理的。还有一些替代做法，比如按值传入，再使用被调用方法返回语句中的值。同样，`tuples`也能派上用场。

从[文档][ref-parameter]中你会看到，`out`和`ref`在某些情况下不能使用，不过现在你可以先忽略它们。当这类情况出现时，编译器会告诉你。

注意，`optional parameters`和`named arguments`会在`method-overloading`练习中讨论。

相关主题[`ref local`][ref-local]和[`ref return`][ref-return]会在别处讨论。

## 栈分配

关于形参及其修饰符的规则足够直白，你可以直接按字面接受，并在它们自身的抽象层面上理解它们。不过，如果你对底层机制感兴趣，想知道这些关键字为什么可能带来性能差异，至少对`struct`s而言，那么可以从这篇[_维基百科文章_][calling-conventions]开始，注意 C# 在 x86/64 上使用`stdcall`。

其中的要点是：对于不带修饰符的形参，变量的**值**会被复制到程序的栈上，以便被调用的例程可以使用它；而对于`ref`、`out`和`in`形参，指向存放该值的内存的指针（**引用**）会被放到程序的栈上，值是赋给该引用所指向的内存的。
