# 简介

和其他许多语言一样，C++ 也有_指针_。
你已经知道_引用_和_指针_很相似，但可以把它们看作更接近计算机内部运作的一层。
_指针_是保存对象地址的变量。
它们用于直接操作对象，从而在 C++ 中实现动态内存分配和高效的数据处理。

如果你刚接触_指针_，可能会觉得它们有点神秘，但一旦习惯了，就会发现它们其实很直白。

它们是 C++ 至关重要的一部分，所以花点时间真正理解它们吧。
本概念里这个最基础的版本也叫_笨指针_或_裸指针_。
现代 C++ 中还有_智能指针_，而这里的基础类型一点也不智能，所有工作都得你手动处理。

在深入细节之前，值得先了解一下_指针_的用途。
_指针_是一种把对象地址共享给程序其他部分的方式，这样做主要有两个好处：

1. 与_引用_一样，指针可以避免拷贝，有助于减少程序的资源占用。
1. 与_引用_不同，指针可以重新指向其他对象。
1. 指针还可以指向空值，表示它们当前没有指向任何对象。

## 基本语法

在 C++ 中声明指针时，需要先指定指针所指向的数据类型，然后是星号（`*`），最后是指针的名称。
声明指针时，它们不会被自动初始化。
如果没有显式赋值，指针通常会保存一个不确定的值，通常称为“垃圾地址”。
虽然某些编译器可能会把指针初始化为 `nullptr`，但并非所有编译器都保证这种行为，所以千万不要依赖它。
最佳实践是显式初始化裸指针，并在使用前验证其非空状态，以避免潜在的问题。

```cpp
int* ptr{nullptr}; // Declares a pointer and makes sure it is not invalid
```

要把变量的地址赋给指针，可以使用取地址运算符（`&`）。
解引用指针则使用_间接寻址运算符_（`*`）。

```cpp
std::string opponent{"Solomon Lane"};
// 'ethan' points to the address of the string opponent
std::string* ethan{&opponent};
// Instead of ethan's, the opponent's name address is given to the passPort
std::string passportName{*ethan};
```

注意：解引用必须显式完成，而_引用_用起来就像别名一样。

## 指针运算

_指针运算_允许你对指针进行算术运算，在处理数组时尤其有用。
给指针加上一个整数，会让它指向另一个元素。

```cpp
// Stargate Coordinate Code
int gateCode[] = {462, 753, 218, 611, 977};
// 'ptr' points to the first element of 'gateCode'
int* ptr{&gateCode[0]};
// Accesses the third Stargate address through pointer arithmetic
int dialedAddress{*(ptr + 2)};
// Chevron encoded! Dialing Stargate address:
openStarGate(dialedAddress);
```

~~~~exercism/caution
在 C++ 中，如果处理不当，指针运算很容易导致__未定义行为__。
未定义行为可能表现为意料之外的程序结果、崩溃，甚至安全漏洞。
未定义行为造成后果的一个著名例子是 1996 年的[阿丽亚娜 5 号火箭爆炸][ariane-flight-v88]：把一个 64 位浮点数转换成 16 位有符号整数引发的软件异常，最终导致了灾难性的失败。

## 访问成员变量

在 C++ 中，`->` 运算符用于通过指向对象的指针来访问该对象的成员。
它是一种简写形式，简化了通过指针访问所指对象成员的过程。
例如，如果 `ptr` 是指向某个对象的指针，而该对象有一个成员变量 `x`，那么你可以直接使用 `ptr->x`，而不必写 `(*ptr).x`。
在处理指向对象的指针时，这个运算符能提高代码的可读性，减少冗余。

下面是一个简短的例子，其中有一个 _struct_ `Superhero`，它包含成员变量 `superpower`。
main 函数创建了一个指向 `Superhero` 对象的指针 `dianaPrince`（代表神奇女侠）。
`->` 运算符用于访问成员变量 `superpower`，展示了神奇女侠标志性的“真言套索”。

```cpp
struct Superhero {
    std::string superpower;
};
Superhero wonder_woman{};
Superhero* dianaPrince = &wonder_woman;
dianaPrince->superpower = "Lasso of Truth";
// Using the -> operator to access member variable superpower:
std::cout << "Wonder Woman, possesses the mighty " << dianaPrince->superpower;
// Memory cleanup:
delete dianaPrince;
```

## 指针与引用

指针和引用都能间接访问对象，但它们在能力和安全性方面有所不同。
指针的灵活之处在于可以改变所指向的对象，也可以被赋值为 null。
然而，这种灵活性也带来了风险，比如解引用空指针或产生悬空指针。
而引用则不能为空，并且在创建时就绑定到有效的对象上，从而避免了这些风险。
由于引用更安全，除非确实需要指针提供的额外功能，否则应优先使用引用。
