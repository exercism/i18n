# 说明补充

## 构建你自己的 DSL

在这道练习中，你可以完全自由地设计你梦想中的图 DSL。

也许你想基于标签和记录列表来创建 DSL，像这样：

```roc
my_graph =
    Graph.new([
        Title("My Graph"),
        Node("a", { color: Green }),
        Node("b", { color: Blue }),
        Edge("a", "b", { style: Dotted }),
    ])
```

又或者，你更想基于函数调用链来设计 DSL，像这样：

```roc
my_graph =
    Graph.new
        .with_title("My Graph")
        .add_node("a", Attr.new.with_color(Green))
        ...
```

也可能你有一个完全不同的方案？那就放手去做吧！测试只要求你创建几个特定的图，至于怎么构建，完全由你决定。

话虽如此，如果 DSL 清晰、简洁，而且不会太出人意料，通常会更好（例如，`minus`函数是用来做减法的，而不是用来在两个节点之间建立一条边，比如`node("a") - node("b")`）。

想让乐趣加倍的话，你还可以选择实现一个`to_dot`函数，把你的图转换成 DOT 格式！
