# 安装

本 track 的练习解答使用 32 位的 RISC-V 汇编编写，并在模拟环境中运行，所以不需要 RISC-V 硬件。
每个练习都自带一个 Makefile，用来构建测试并运行它们。
要使用它，你需要三个工具：

- [Zig][zig]，它通过 `zig cc` 提供 RISC-V 汇编器、C 编译器和链接器。
- [Make][make]，用来执行构建。
- 来自 [QEMU][qemu] 的 `qemu-riscv32`，用来运行生成的可执行程序。

## macOS

用任意合适的虚拟化方案（例如 [Lima][lima]）启动一台 Linux 虚拟机，然后参照下面某个 Linux 发行版的步骤操作。

## Windows

使用 [Windows Subsystem for Linux][wsl]，然后参照下面某个 Linux 发行版的步骤操作。
或者，也可以搭一台 Linux 虚拟机。

## Debian / Ubuntu

安装 Make 和 QEMU 的用户态模拟器：

```shell
sudo apt install make qemu-user
```

然后按照[直接下载][zig-install]一节中的说明，安装 Zig 0.15.2 或更高版本。

## Fedora

一条命令即可安装全部三个工具：

```shell
sudo dnf install zig make qemu-user
```

## Arch Linux

一条命令即可安装全部三个工具：

```shell
sudo pacman -S zig make qemu-user
```

## openSUSE Tumbleweed

一条命令即可安装全部三个工具：

```shell
sudo zypper install zig make qemu-linux-user
```

## 检查安装结果

确认这三个工具都能被找到：

```shell
zig version
make --version
qemu-riscv32 --version
```

然后用 Exercism CLI 下载一个练习并运行它的测试：

```shell
exercism download --track=risc-v --exercise=hello-world
cd ~/exercism/risc-v/hello-world/
make
```
