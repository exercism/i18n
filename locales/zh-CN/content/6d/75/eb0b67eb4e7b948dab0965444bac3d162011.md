# 简介

在 Gleam 中，对值进行模式匹配时，我们必须确保模式能匹配该类型所有可能的值，否则代码无法编译。

下面这个函数无法通过编译，因为它没有处理数组为空的情况：

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

在大多数 Gleam 程序里，我们想处理所有可能的情况，但在某些程序（比如原型和临时脚本）中，我们可能只想关注正常路径，不为其他情况写代码。这时就要用到 Gleam 的`let assert`了。

使用`let assert`时，模式可以只匹配类型的部分可能值；如果模式没能匹配到某个值，程序就会崩溃。用`let assert`，上面的函数可以改写成这样：

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam 的库永远不应该使用`let assert`，因为这样可能导致程序崩溃。库应该改用`Result`类型，让应用开发者自行决定如何处理错误。
