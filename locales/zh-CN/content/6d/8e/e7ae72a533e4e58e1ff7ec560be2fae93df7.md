# 资源

* [The Rust Programming Language](https://doc.rust-lang.org/book/) 无论你是刚开始学 Rust，还是想深入了解 Rust 的某些具体特性，它都是很好的资源。
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) 用示例展示你在 Rust 中最常写到的那些内容。
* [Rust API Documentation](http://doc.rust-lang.org/std/) 可以用来发现新方法，并了解它们的用法。
* [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) 可以用来搜索你的问题，看看是否已经有人解答过。你也可以提问和回答问题。
* [Rust User Forum](http://users.rust-lang.org) 用于关于 Rust 的一般性讨论。
* [/r/rust](http://www.reddit.com/r/rust/) 是 Rust 的官方 subreddit。
* [The Rust Programming Language](https://discord.gg/rust-lang) 在 [Discord](https://discordapp.com/) 上的官方服务器，可用于快速提问和讨论这门语言。
