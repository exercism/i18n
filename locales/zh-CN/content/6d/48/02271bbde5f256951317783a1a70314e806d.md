# 安装

## 安装 .NET

C# 学习轨道建立在 [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) 平台之上，该平台可在 Windows、Linux 和 macOS 上运行。
要构建 .NET 项目，你可以使用 .NET 命令行（CLI）。
这个 CLI 是 .NET SDK 的一部分，你可以按照[安装说明](https://dotnet.microsoft.com/download/dotnet/8.0)来安装。
注意：C# 学习轨道要求 SDK 版本为 9.0 或更高。

安装完成后，你可以在终端中运行以下命令，验证 CLI 是否安装成功：

```bash
dotnet --version
```

如果输出的版本大于或等于`9.0.100`，就说明 .NET SDK 安装成功了。

## 使用 IDE

如果你想要功能更全面的编辑体验，可能需要使用 [IDE（集成开发环境）](https://en.wikipedia.org/wiki/Integrated_development_environment)。
以下是支持构建 .NET 项目的最流行的 IDE：

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) 搭配 [C# 扩展](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

注意：由于 .NET 项目格式与早期版本差别很大，旧版 IDE（如 Visual Studio 2015）不受支持。
