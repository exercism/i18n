# 说明

墨尔本的有轨电车按区域收费，市中心免费。你要为售票机编写票价规则。所有票价均以分为单位。

这四个任务都写在`TRAM_FARES`类中。

## 1. 一个区域的票价

0 区是免费电车区，不收费。1 区是 550，2 区是 370。其他任何数字都不是电车区域，也不收费。

```sather
TRAM_FARES::zone_fare(1)
-- => 550
TRAM_FARES::zone_fare(7)
-- => 0
```

## 2. 哪种车票？

车票上带有一个字母。`'f'` 是全额票价。`'c'` 和 `'s'` 都是优惠票，一个给儿童，一个给学生。`'x'` 是免费乘车证。其他任何内容都是未知的。

```sather
TRAM_FARES::ticket_kind('s')
-- => "Concession"
TRAM_FARES::ticket_kind('q')
-- => "Unknown"
```

四个答案分别是 `"Full fare"`、`"Concession"`、`"Free pass"` 和 `"Unknown"`。

## 3. 什么样的日子？

`"Sat"` 和 `"Sun"` 是周末。`"Mon"` 到 `"Fri"` 是工作日。其他任何内容都是未知的。

```sather
TRAM_FARES::day_type("Sun")
-- => "Weekend"
```

三个答案分别是 `"Weekend"`、`"Weekday"` 和 `"Unknown"`。

## 4. 每日上限

无论你乘坐多少次电车，当天支付的票价都不会超过上限：工作日 1100，周末 700。无法识别的日子没有上限，即 0。

```sather
TRAM_FARES::daily_cap("Sat")
-- => 700
```
