# 说明

在这个练习中，你需要把经典游戏 Pac-Man 里的一些规则翻译成 Haskell 函数。

你要翻译 4 条规则，它们都与游戏状态有关。

> 不用担心这些实参是怎么来的，只要专注于把它们组合起来，返回预期的结果就好。

## 1. 定义 Pac-Man 是否吃掉幽灵

定义`eatsGhost`函数，它接收两个实参（_Pac-Man 是否处于能量豆生效状态_ 和 _Pac-Man 是否碰到幽灵_），并在 Pac-Man 能吃掉幽灵时返回一个`Bool`值。
只有当 Pac-Man 处于能量豆生效状态并且碰到幽灵时，这个函数才应该返回`True`。

```haskell
eatsGhost False True
-- -> False
```

## 2. 定义 Pac-Man 是否得分

定义`scores`函数，它接收两个实参（_Pac-Man 是否碰到能量豆_ 和 _Pac-Man 是否碰到豆子_），如果 Pac-Man 得分就返回一个`Bool`值。
当 Pac-Man 碰到能量豆或豆子时，这个函数应该返回`True`。

```haskell
scores True True
-- -> True
```

## 3. 定义 Pac-Man 是否会输

定义`loses`函数，它接收两个实参（_Pac-Man 是否处于能量豆生效状态_ 和 _Pac-Man 是否碰到幽灵_），如果 Pac-Man 输了就返回一个`Bool`值。
当 Pac-Man 碰到幽灵、并且没有处于能量豆生效状态时，这个函数应该返回`True`。

```haskell
loses False True
-- -> True
```

## 4. 定义 Pac-Man 是否会赢

定义`wins`函数，它接收三个实参（_Pac-Man 是否已经吃掉所有豆子_、_Pac-Man 是否处于能量豆生效状态_ 和 _Pac-Man 是否碰到幽灵_），如果 Pac-Man 赢了就返回一个`Bool`值。
当 Pac-Man 已经吃掉所有豆子，_并且_依据第 3 部分中定义的实参没有输掉时，这个函数应该返回`True`。

```haskell
wins False True False
-- -> False
```
