# 学习

Haskell 是一门纯函数式语言，这种范式与更常见的[面向对象方法](https://en.wikipedia.org/wiki/Object-oriented_programming)有着根本的不同。正因如此，学习 Haskell 的感受，可能和随手再学一门语言不太一样。

好在有大量资源都假定读者已经具备一些编程基础，比如

  - An opinionated beginner's guide to Haskell（[2019](https://github.com/theindigamer/not-a-blog/blob/master/opinionated-haskell-guide-2019.md)、[2018](https://lexi-lambda.github.io/blog/2018/02/10/an-opinionated-guide-to-haskell-in-2018/)）
  - 广受欢迎且免费的在线书 [Learn You a Haskell For Great Good!](https://learnyouahaskell.github.io/)
  - 格拉斯哥大学的 [Functional Programming in Haskell](https://www.futurelearn.com/courses/functional-programming-haskell) 课程
  - FP Complete 的 [School of Haskell](https://www.schoolofhaskell.com/)
  - [Happy Learn Haskell Tutorial](http://www.happylearnhaskelltutorial.com/)
  - [Haskell for Mac](http://learn.hfm.io/) 的教程

近期出版的一些 Haskell 书籍有
  - Christopher Allen 和 Julie Moronuki 合著的 [Haskell Programming From First Principles](https://haskellbook.com)（这本书不要求读者具备编程基础）
  - Graham Hutton 的 [Programming in Haskell](https://www.cambridge.org/us/academic/subjects/computer-science/programming-languages-and-applied-logic/programming-haskell-2nd-edition?format=PB&isbn=9781316626221)

你也可以参考 [Haskell wiki](https://wiki.haskell.org/Learning_Haskell#Online_tutorials)，那里有大量入门资源。
