# 布尔值

有些问题只有两个答案：是或不是。Sather 中用来表示这种答案的类型是`BOOL`，这两个答案写作`true`和`false`。

```sather
   ready : BOOL is
      return true;
   end;
```

## 比较

比较两个数字会得到一个`BOOL`。

| 运算符 | 问的是 |
| --- | --- |
| `=` | 它们相同吗？ |
| `/=` | 它们不同吗？ |
| `<` | 左边那个更小吗？ |
| `<=` | 更小，还是相同？ |
| `>` | 左边那个更大吗？ |
| `>=` | 更大，还是相同？ |

```sather
   old_enough(age : INT) : BOOL is
      return age >= 13;
   end;
```

注意，`=`问的是一个问题。把值*放进*某个东西用的是`:=`，这个你已经见过了，两者并不相同。

## 组合

有三个运算符可以用小问题搭出更大的问题。

当**两边**都为 true 时，`and`的结果才是 true。

```sather
harness_on and rope_checked
```

当**任意一边**为 true，或两边都为 true 时，`or`的结果是 true。

```sather
mat_below or net_below
```

`~`把一个答案翻转过来：它把 true 变成 false，把 false 变成 true。

```sather
~ready       -- true exactly when ready is false
```

`and`和`or`放在两个答案之间；`~`放在一个答案前面。
