# 资源

## 获取帮助

1. [The Emacs Wiki](http://emacswiki.org/) 非常有价值，值得花大量时间在这里。
2. [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) 是 GNU Emacs 的官方手册。
3. IRC：在 [Libera.Chat](https://libera.chat/) 上有 `#emacs`、`#org-mode` 以及许多 Emacs 包的频道，也有很多热心人。而且用了 Emacs，上 IRC 就只差 `M-x erc` 这一步。
4. Matrix：在 [Matrix](https://matrix.org/) 上有 [emacs](https://matrix.to/#/#emacs:matrix.org)、[org-mode](https://matrix.to/#/#org-mode:matrix.org) 以及其他 Emacs 包的房间。你可以[加入 Emacs Matrix space](https://matrix.to/#/#emacs-space:matrix.org)，了解有哪些可用的频道。要在 Emacs 里加入 Matrix，可以使用 [Ement.el](https://github.com/alphapapa/ement.el) 包。
5. [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) 和 [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) 可以用来搜索你的问题，看看是否已经有人解答过。你也可以在这里提问和回答问题。
