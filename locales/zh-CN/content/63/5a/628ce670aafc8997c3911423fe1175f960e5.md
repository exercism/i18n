# 说明

Lucian 的女朋友正在回家的路上，而他还没做好他们的周年纪念晚餐！

在这个练习里，你要写一些代码，帮 Lucian 按照他最爱的食谱做出一份美味的千层面。

你有四个任务，它们都和烹饪千层面所花的时间有关。

## 1. 定义预计的烘烤时间（分钟）

定义`Lasagna.ExpectedMinutesInOven()`方法，它不接收任何形参，返回千层面应该在烤箱里烤多少分钟。根据食谱，预计的烘烤时间是 40 分钟：

```csharp
var lasagna = new Lasagna();
lasagna.ExpectedMinutesInOven();
// => 40
```

## 2. 计算剩余的烘烤时间（分钟）

定义`Lasagna.RemainingMinutesInOven()`方法，它接收千层面已经在烤箱里烤的分钟数作为形参，并根据上一个任务中得出的预计烘烤时间，返回千层面还需要在烤箱里烤多少分钟。

```csharp
var lasagna = new Lasagna();
lasagna.RemainingMinutesInOven(30);
// => 10
```

## 3. 计算准备时间（分钟）

定义`Lasagna.PreparationTimeInMinutes()`方法，它接收你往千层面里加的层数作为形参，并返回你准备千层面花了多少分钟，假设准备每一层需要 2 分钟。

```csharp
var lasagna = new Lasagna();
lasagna.PreparationTimeInMinutes(2);
// => 4
```

## 4. 计算已经过的时间（分钟）

定义`Lasagna.ElapsedTimeInMinutes()`方法，它接收两个形参：第一个形参是你往千层面里加的层数，第二个形参是千层面已经在烤箱里烤的分钟数。这个函数应该返回你烹饪千层面一共花了多少分钟，也就是准备时间的分钟数，加上千层面此刻在烤箱里已经烤的分钟数。

```csharp
var lasagna = new Lasagna();
lasagna.ElapsedTimeInMinutes(3, 20);
// => 26
```
