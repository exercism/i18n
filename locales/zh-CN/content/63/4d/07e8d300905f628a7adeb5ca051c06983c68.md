# 说明

你的朋友刚给你发来一条带有重要秘密的消息。为了不让别人轻易读懂，这条消息经过了一系列位操作加密。你需要写出相应的单词，来帮助解密这条消息。

## 1. 把位右移回去

解密消息的第一步，是把加密过程中的移位还原，也就是把这些位向右移回去。后面的步骤假定零是从左侧补入的。

定义一个`shift-back`，接收一个 32 位值和一个移位量，返回把该值向右移动这个移位量、并在左侧补零后的结果。

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. 设置某些位

接下来，有些位需要被置为 1。

定义一个`set-bits`，接收一个值和一个掩码。`value`中每一位，只要`mask`中对应的位是 1，就应该置为 1；其他位保持不变。

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. 翻转特定的位

加密过程中有些位被翻转了。要解密这条消息，就需要把它们翻转回去。

定义一个`flip-bits`，接收一个值和一个掩码。`value`中每一位，只要`mask`中对应的位是 1，就应该翻转；其他位保持不变。

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. 清除特定的位

最后，还有一些位解密后总是 0。

定义一个`clear-bits`，接收一个值和一个掩码。`value`中每一位，只要`mask`中对应的位是 1，就应该清零；其他位保持不变。

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
