# 简介

从`PHP 8.0.0`起，**联合类型声明**可以接受多种不同类型的值，而不只是单一类型。联合类型定义使用竖线（`|`）来分隔类型。

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

在严格模式下，如果传入的实参既不是`float`也不是`int`，PHP 会抛出`TypeError`。在非严格模式下，如果传入的实参无法被强制转换为`float`或`int`，则会抛出类型错误。

同样，如果函数返回的值不是声明的类型之一，PHP 会在运行时抛出`TypeError`。
