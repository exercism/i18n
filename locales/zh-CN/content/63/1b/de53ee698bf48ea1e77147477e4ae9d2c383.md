# 提示

## 通用

- `locals`词汇表提供了`::`和`[| | ]`。
- 局部变量并不能取代栈上的代码，请只在能让代码更清晰的地方使用它们。

## 1. 判断烹饪状态

- [`combinators`][combinators]里的`cond`正是合适的形态：一个分支检查`dup not`（计时器为`f`），另一个检查`dup zero?`，其余情况交给默认分支处理。每个分支都应该先`drop`掉计时器，再压入字符串。

## 2. 估算准备时间

- 使用`:: preparation-time ( layers minutes-per-layer -- total )`，其中用到`layers length minutes-per-layer *`。

## 3. 计算所需的面条和酱料

- 有了局部变量，你不必用`dup`就能两次引用`layers`。用谓词`[ "noodles" = ]`（或`"sauce" =`）调用`count`，就能数出各有多少层。
- `1/5`是 Factor 的有理数字面量。

## 4. 加入秘密配料

- `last`（在[`sequences`][sequences]中）读取最后一个元素；`suffix`把一个元素追加到末尾。

## 5. 按比例缩放食谱

- 缩放系数是`portions / 2`。局部变量让你能在 lambda 内部引用`portions`。
- [`assocs`][assocs]里的`assoc-map`接受一个形如`( key value -- newkey newvalue )`的 quotation。在`[| key value | … ]`内部，返回两个值即可保持同一个键并生成新的值。
