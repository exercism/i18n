# 说明

你正在维护一份野外指南：一份从动物名称到它栖息地的映射。

全部 5 个任务都写在`FIELD_GUIDE`类里。

## 1. 它在指南里吗？

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. 它住在哪里？

返回为某种动物记录的栖息地。如果指南里没有这种动物，就返回`"Unknown"`。

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. 添加一条记录

返回一份多 1 种动物的指南。如果这种动物已经记录在案，就替换它的栖息地。

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

它返回的内容就是之后要使用的指南。向一份完全空的指南里添加记录同样可行，会得到一份只有 1 种动物的指南。

## 4. 有多少种动物？

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. 有哪些栖息地？

返回指南中提到的所有栖息地组成的集合。多种动物可能共享同一个栖息地，而它只应出现一次。

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
