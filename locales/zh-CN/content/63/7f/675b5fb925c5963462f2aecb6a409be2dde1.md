# 说明

在这一练习中，你将协助一位密码学家管理和验证一套安全通信系统。
该系统高度依赖域元素，具体来说是 Cairo 里的`felt252`类型，以确保所有算术运算都保持在规定的范围内。

## 1. 计算两条消息之和

两条加密消息各自用一个`felt252`表示，需要相加，得到一条合并后的消息。
不过，由于加密的缘故，任何超过最大值$P - 1$的结果都必须用模$P$回绕。

实现一个函数，接收两个`felt252`值并返回它们的和，确保结果保持在有效范围内：

```rust
add_messages(3618502788666131213697322783095070105623107215331596699973092056135007822949, 987654321)
// => 123456789
```

> **注意：** 返回值应为`felt252`。

## 2. 计算两条消息之差

有时需要把消息相减，以取回原始数据。
如果相减的结果为负数，系统会自动给结果加上$P$，把它拉回到有效`felt252`值的范围内。

实现一个函数，接收两个`felt252`值并返回它们的差，确保结果保持在有效范围内：

```rust
subtract_messages(123456789, 987654321)
// => 3618502788666131213697322783095070105623107215331596699973092056135007822949
```

> **注意：** 返回值应为`felt252`。

## 3. 计算两条消息的有效乘积

为了确保加密数据的完整性，密码系统常常把两条消息（`felt252`）相乘，以保证它们的乘积保持在有效范围内。
结果必须按模$P$计算，以确保它仍处于有效范围内。

实现一个函数，接收两个`felt252`值并返回它们的乘积，确保结果保持在有效范围内：

```rust
multiply_messages(382927772233671078546147897004315551461400594453673204174697055647611, 9449570)
// => 123456789
```

> **注意：** 返回值应为`felt252`。
