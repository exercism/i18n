# 说明

镇上新开了一家诗歌俱乐部，你正想着去参加。
因为过去发生过一些意外，俱乐部有一套非常严格的门禁规矩，你得先掌握它们，才能尝试进入。

诗歌俱乐部有两扇门，一扇前门，一扇后门，两扇门都有人把守。
想要进去，你得先弄清楚当天的密码。

密码总是以一首诗为基础，可以通过两个步骤推导出来。

1. 守卫会逐行朗诵这首诗，你要针对每一行回答一个合适的字母。
2. 守卫接着会把你回答过的所有字母一次性告诉你，你需要按特定格式把它们写在一张纸上。

具体流程取决于你想进哪扇门。

## 1. 获取句子的第一个字母

要确定前门密码的字母，你需要针对守卫朗诵的每一行诗，回答那一行的第一个字母。

为了让密码好看些，诗歌俱乐部的成员喜欢用_藏头诗_。
也就是说，每句话的第一个字母能拼成一个单词。
下面是他们最喜欢的作家之一 Michael Lockwood 写的一个例子。

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

所以当守卫朗诵 **Stands so high** 时，你要回答 **S**；当守卫朗诵 **Huge hooves too** 时，你要回答 **H**。

实现函数 `frontDoorResponse`，它接收一行诗作为实参，返回那一行的第一个字母。

```javascript
frontDoorResponse('Stands so high');
// => "S"
```

## 2. 将单词首字母大写

现在你已经拿到了所有正确的字母，要得到前门密码，只需要把单词的首字母正确地大写就行了。

实现函数 `frontDoorPassword`，它接收一个字符串（你在任务 1 中找到的组合字母），返回首字母大写后的结果。

```javascript
frontDoorPassword('SHIRE');
// => "Shire"

frontDoorPassword('shire');
// => "Shire"
```

## 3. 获取句子的最后一个字母

要确定后门密码的字母，你需要针对守卫朗诵的每一行诗，回答那一行的最后一个字母。

诗歌俱乐部的成员真的很聪明。
前面提到的那首诗同时也是_藏尾诗_，也就是说，每句话的最后一个字母也能拼成一个单词：

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

当守卫朗诵 **Stands so high** 时，你要回答 **h**；当守卫朗诵 **Huge hooves too** 时，你要回答 **o**。

注意，守卫有时会在行首或行尾做风格化的停顿（表现为空白字符）。
你需要忽略这些停顿，才能得出正确的字母。

实现函数 `backDoorResponse`，它接收一行诗作为实参，返回那一行中最后一个不是空白字符的字母。

```javascript
backDoorResponse('Stands so high');
// => "h"

backDoorResponse('Stands so high   ');
// => "h"
```

## 4. 讲礼貌

要从后门进入诗歌俱乐部，你需要格外有礼貌。
所以要得出密码，这次你需要把单词的首字母正确地大写，并在末尾加上 `', please'`。

实现函数 `backDoorPassword`，它接收一个字符串（你在任务 3 中找到的组合字母），返回首字母大写后的密码的礼貌版本。

```javascript
backDoorPassword('horse');
// => "Horse, please"
```
