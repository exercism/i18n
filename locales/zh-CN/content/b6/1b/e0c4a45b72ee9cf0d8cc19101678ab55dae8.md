# Hints

## 通用

## 1. 实现`new()`方法

- `new()`方法接收我们用来实例化`User`实例的实参。它应该返回一个`User`实例，其中包含指定的姓名、年龄和体重。

- 关于定义和实例化结构体的更多示例，参见[这里](https://doc.rust-lang.org/book/ch05-01-defining-structs.html)。

## 2. 实现取值方法

- `name()`、`age()`和`weight()`方法是取值方法。换句话说，它们负责返回结构体实例中对应的字段。

- 注意，`User`结构体上的`name`字段是`String`，而`name`方法返回的却是`&str`。怎样才能让`&str`和`String`友好相处呢？

- 在 Rust 中，除非你明确希望函数或方法提前返回，否则没必要使用`return`语句。其他情况下，更符合习惯的做法是省略分号，用_隐式_返回来得到我们想要的结果。使用显式返回并不算_错_，但尽可能利用隐式返回会更简洁。

```rust
fn foo() -> i32 {
    1
}
```

- 关于在结构体上定义方法的更多示例，参见[这里](https://doc.rust-lang.org/book/ch05-03-method-syntax.html)。

## 3. 实现设值方法

- `set_age()`和`set_weight()`方法是设值方法，负责用输入的实参更新结构体实例中对应的字段。

- 正如这些方法的签名所指定的那样，设值方法不应该返回任何值。
