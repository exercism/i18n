# 说明

## 1. 概览

[逆波兰表示法](https://en.wikipedia.org/wiki/Reverse_Polish_notation)（RPN）是一种书写数学表达式的方式。
与传统的中缀表示法不同，RPN 的运算符*跟在*操作数后面。
例如，不写成：

```
2 + 2
```

而是写成：

```
2 2 +
```

逆波兰表示法的主要优点是，它比中缀表示法容易解析得多。
RPN 免去了复杂表达式中的运算顺序规则和括号。
例如：

```
(4 + 8) / (7 - 5)
```

可以写成

```
4 8 + 7 5 - /
```

这两种情况下，表达式的求值结果都是 6。

## 2. 示例

让我们手动对这个复杂表达式求值。
正如我们在介绍中学到的，RPN 的求值需要一个栈。
这个栈用来存放运算符所操作的数值。
我们让计算器从空栈开始，然后依次对每个元素求值。

首先，我们遇到一个`4`，
于是把它压入刚创建好的栈。

```
4
```

接下来，我们遇到一个`8`。
也把它压入栈。

```
4 8
```

现在，我们遇到一个`+`。
我们弹出最上面的两个值（4 和 8），
把它们相加，
再把和压回栈中。

```
12
```

我们对`7`、`5`和`-`做类似的事情：

```
12 7
12 7 5
12 2
```

现在我们遇到一个`/`。
尽管上一个遇到的是`-`，
但栈上有两个元素。
我们弹出这两个元素，
把它们相除，
再把结果压回栈中。

```
6
```

最后，由于栈上恰好有一个元素，
我们可以说该表达式的求值结果是 6。

## 3. 目标

你的目标是编写一个计算器，对一组按逆波兰表示法排列的输入进行求值，并返回栈上最后剩下的元素。

如果最后栈中不是恰好一个元素，则返回 `None`。

如果某个运算符的操作数太少（比如输入 `2 +`），则返回 `None`。
