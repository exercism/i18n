# 简介

## 基础

C# 是一门静态类型语言，也就是说，所有东西在编译时都有一个类型。把一个值赋给一个名字，叫做定义变量。定义变量时，既可以显式指定它的类型，也可以让 C# 编译器根据所赋的值推断出它的类型（这叫做_类型推断_）。因此，下面两种变量定义是等价的：

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

更新变量的值要通过`=`运算符来完成。变量一旦定义，它的类型就永远不会改变。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是一门[面向对象的语言][object-oriented-programming]，要求所有函数都定义在_类_里面。定义类要用`class`关键字。对象（或_实例_）通过`new`关键字来创建。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

类里面的函数叫做_方法_。每个方法可以有零个或多个形参。所有形参都必须显式声明类型，形参没有类型推断。同样，返回类型也必须显式声明。方法用`return`关键字返回值。要让其他文件中的代码能够调用某个方法，必须加上`public`访问修饰符。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

调用方法时，要在实例上使用点（`.`）语法，写明要调用的方法名，并为方法的每个形参传入实参。实参可以选择性地指定对应形参的名字。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C# 中的作用域定义在`{`和`}`之间。

C# 支持两种注释。单行注释以`//`开头，多行注释写在`/*`和`*/`之间。

[object-oriented-programming]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming
