# 说明补充

## 寄存器

| 寄存器 | 用途        | 类型    | 说明                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的数字字符串 |
| `$a1`    | 输入        | 整数 | 跨度                          |
| `$v0`    | 输出       | 整数 | 最大连续乘积        |
| `$t0-9`  | 临时    | 任意     | 用于临时存储         |
