# 简介

C# 和许多静态类型语言一样，提供了多种表示整数的类型，每种类型都有自己的取值范围。范围最小的是`sbyte`类型，最小值为 -128，最大值为 127。和所有整数类型一样，这些值可以通过`<type>.MinValue`和`<type>.MaxValue`获取。范围最大的是`long`类型，最小值为 -9,223,372,036,854,775,808，最大值为 9,223,372,036,854,775,807。介于两者之间的是`short`和`int`类型。

取值范围由系统为该类型分配的存储宽度决定。例如，`byte`占 8 位，`long`占 64 位。

上述每种类型都有一个对应的无符号类型：`sbyte`/`byte`、`short`/`ushort`、`int`/`uint`和`long`/`ulong`。在所有情况下，取值范围都是从 0 到有符号负数最大值乘以 2 再加 1。

| 类型   | 宽度  | 最小值                     | 最大值                      |
| ------ | ------ | -------------------------- | --------------------------- |
| sbyte  | 8 位   | -128                       | +127                        |
| short  | 16 位  | -32_768                    | +32_767                     |
| int    | 32 位  | -2_147_483_648             | +2_147_483_647              |
| long   | 64 位  | -9_223_372_036_854_775_808 | +9_223_372_036_854_775_807  |
| byte   | 8 位   | 0                          | +255                        |
| ushort | 16 位  | 0                          | +65_535                     |
| uint   | 32 位  | 0                          | +4_294_967_295              |
| ulong  | 64 位  | 0                          | +18_446_744_073_709_551_615 |

一种类型的变量（或表达式）可以很容易地转换成另一种类型。例如，在赋值操作中，如果要赋的值（`lhs`）的类型能保证该值处于赋值目标类型（`rhs`）的取值范围内，那么直接赋值即可：

```csharp
uint ui = uint.MaxValue;
ulong ul = ui;    // no problem
```

另一方面，如果要赋值的来源类型的取值范围不是赋值目标取值范围的子集，那么就需要进行强制转换，即`()`操作，即使该具体数值落在赋值目标的取值范围内也一样：

```csharp
short s = 42;
uint ui = (uint)s;
```
