# 简介

## Julia 中的布尔值

true 或 false 这样的值由`Bool`类型表示。
它只包含两个值：`true`和`false`。

```julia-repl
julia> true
true

julia> false
false
```

## 布尔运算符

Julia 中有三个布尔运算符。

`&&`是布尔“与”。
当`&&`*两侧*的表达式都为`true`时，它的求值结果为`true`。

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||`是布尔“或”。
当`||`*任意*一侧的表达式为`true`时，它的求值结果为`true`。

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!`是布尔“非”。
它会把`true`和`false`互换。

```julia-repl
julia> !true
false

julia> !false
true
```

对于更长、更复杂的表达式，最好用括号来清楚地表达你的意图。

```julia-repl
julia> (true || false) && (false && true)
false
```
