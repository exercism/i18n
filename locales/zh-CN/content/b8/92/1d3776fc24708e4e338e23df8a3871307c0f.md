# 简介

## 真与假

在 Ruby 中，逻辑上的真与假用`true`和`false`表示。它们既可以单独作为字面量使用，也可以作为逻辑方法或比较方法的返回值。

```ruby
happy = true
sad = false

true && false
# => false

1 < 2
# => true
```

## _truthy_ 与 _falsey_

在`if`语句或其他布尔上下文中对对象求值时，除了`false`和`nil`，所有对象都视为 _truthy_。

## 控制流

_truthy_ 和 _falsey_ 的求值在控制流中很有用。和过程式语言一样，Ruby 也有 `if`...`else` 结构，但更常见的做法是把 `if` 当作“守卫”语句，用来改变表达式的求值。

```ruby
def falsey
  nil || false
end

def truthy
  not falsey
end

if truthy
  # this block is evaluated
end

if falsey
  # this block is not evaluated
else
  # this block is evaluated
end

1 + 1 if truthy
# this will evaluate and return 2

2 + 2 if falsey
# the numbers are not added because of the modifier, nil is returned
```

Ruby 提供了`unless`，让代码读起来更通顺。例如，与其写`eat_desert if not too_full`，我们也可以写成`eat_desert unless too_full`。

```ruby
3 + 3 unless truthy
# the numbers are not added because of the modifier, nil is returned

4 + 4 unless falsey
# this will evaluate and return 8
```
