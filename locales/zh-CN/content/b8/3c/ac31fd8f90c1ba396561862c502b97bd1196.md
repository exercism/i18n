# 数组简介

在 Java 中，数组是一种把多个同类型的值存储在同一个结构中的方式。
与其他数据结构不同，数组一旦创建，大小就是固定的。
你可以使用下标给数组中的元素赋值，也可以使用下标获取元素。
Java 数组使用从 0 开始的下标：第一个元素的下标是 0，第二个元素的下标是 1，依此类推。

下面是初始化数组的标准语法：

```java
type[] variableName = new type[size];
```

`type` 是数组中元素的类型，它既可以是基本类型（例如 `int`），也可以是类（例如 `String`）。

`size` 是这个数组能容纳的元素个数（之后无法修改）。
数组创建后，元素会被初始化为各自的默认值（通常是 `0`、`false` 或 `null`）。

```java
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];
```

数组也可以使用一种简写形式来定义，让你可以同时创建数组并设置它的值：

```java
// Two equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = { 4, 9, 7 };
```

由于编译器现在能推断出数组会有多少个元素，长度可以省略。

数组元素可以使用带方括号的下标表示法来赋值和访问：

```java
// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index and assign to the int element
int secondElement = twoInts[1];
```

如果访问的下标超出了数组的有效范围，就会抛出 `IndexOutOfBoundsException`。

你可以通过调用数组实例的方法或属性来操作数组，也可以使用 `Arrays` 类中定义的静态方法（通常只在泛型代码中使用）。
`length` 属性保存数组的长度。
可以像这样访问它：

```java
int arrayLength = someArray.length;
```

Java 还提供了一个很好用的工具类 [`java.util.Arrays`](https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/util/Arrays.html)，其中有许多实用的数组相关方法（例如 `Arrays.equals`）。

Java 还支持[多维数组](https://www.programiz.com/java-programming/multidimensional-array)，比如 `int[][] arr = new int[3][4];`，它们非常有用。

数组同时也是一种*集合*，这意味着除了按下标访问值之外，你还可以用 `for-each` 循环遍历它的*所有*值：

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for(char vowel: vowels) {
    // Output the vowel
    System.out.print(vowel);
}

// => aeiou
```

如果你想更精细地控制遍历哪些值，可以使用 `for` 循环：

```java
char[] vowels = { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < 3; i++) {
    // Output the vowel
    System.out.print(vowels[i]);
}

// => aei
```
