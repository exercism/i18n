# 关于

[范围][range]表示两个值之间的区间。
范围常用于`Int`、`String`和`Character`等类型，用来遍历序列、对集合进行切片，或检查某个值是否落在边界内。

Swift 提供了两种主要的范围运算符：

- **闭区间运算符（`...`）**：同时包含起始值和结束值（`1...5`包含 1、2、3、4 和 5）。
- **半开区间运算符（`..<`）**：包含起始值，但不包含结束值（`1..<5`包含 1、2、3 和 4）。

```swift
let closed = 1...5
let halfOpen = 1..<5
```

直接在范围字面量上调用方法时，要把范围表达式放在括号里，让编译器先计算范围：

```swift
(1...5).contains(3) // Returns true
```

## 将范围转换为数组

你可以使用`Array(_:)`初始化器把数字范围转换为`Array`：

```swift
let range = 1...5
let numbers = Array(range)
// numbers is [1, 2, 3, 4, 5]
```

## 使用范围对数组进行切片

你可以使用范围来切分数组的一部分：

```swift
let array = [10, 20, 30, 40, 50]
let slice = array[1...3]
// slice contains [20, 30, 40]
```

## 范围的属性和方法

范围的常见操作包括：

| 成员                  | 说明                                                       | 示例                                 |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------ |
| `count`                 | 返回范围中的元素数量                                        | `(1...5).count`返回`5`               |
| [`contains(_:)`][contains] | 如果范围包含指定的值，则返回`true`                        | `(1...5).contains(3)`返回`true`      |

## 单边范围

Swift 还支持单边（部分）范围，可以省略起始值或结束值：

- `array[2...]`：从下标 2 到集合末尾。
- `array[...2]`：从集合开头到下标 2（包含下标 2）。
- `array[..<2]`：从集合开头到下标 2（不包含下标 2）。

## 字符串和字符范围

也可以在符合`Comparable`的字符或字符串之间创建范围：

```swift
let letters = "a"..."z"
print(letters.contains("m")) // Prints true
print(letters.contains("A")) // Prints false
```
