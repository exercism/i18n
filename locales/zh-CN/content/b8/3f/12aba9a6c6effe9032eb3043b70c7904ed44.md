# 路线图

本文档概述了贡献者和维护者在未来几个月里可能会重点关注的几个主要主题。

## 主题概览

- 改进现有的概念练习（见[跟踪 issue](https://github.com/exercism/javascript/issues/1415)）
- 创建更多概念练习（见下方的教学大纲概览）
- 为所有实践练习定义`prerequisites`和`practices`列表（见[跟踪 issue](https://github.com/exercism/javascript/issues/960)）
- 改进[测试运行器](https://github.com/exercism/javascript-test-runner/)
  - 修复 bug
  - 当变量定义在测试用例之外时，给出更友好的输出
  - 把测试和任务关联起来
- 为所有现有的概念练习添加[分析器](https://github.com/exercism/javascript-analyzer/)注释
- 改进、更新和校对各类文档（贡献指南、如何实现一个概念练习、docs、exercises/shared、reference 文件夹）

## 教学大纲概览

### 已存在的概念，或已创建 issue 的概念

- `basics`
- `strings`（含字符串方法）
- `numbers`
- `booleans`
- `conditionals`（if/else）和`comparison`
- `for-loops`和`increment-decrement`
- `while-loops`
- `conditionals-switch`
- `objects`（作为键值对集合）
- `null-undefined`
- `functions`
- `type-conversion`（含 truthy/falsy）
- `template-strings`
- `conditionals-ternary`
- `callbacks`
- `arrow-functions`
- `classes`和`prototypes`
- `inheritance`
- `errors`
- `arrays`（含用 push、pop 等进行的数组操作）
- `array-loops`
- `array-analysis`
- `array-transformation`
- `array-destructering`
- `rest-and-spread`
- `promises`
- `recursion`
- `closures`
- `sets`
- `randomness`
- `regular-expressions`
- `dates`
- `async-await`
- `type-checking`

### 未来可能的概念

- `maps`（可以加入 Sets 练习，WeakSet/WeakMap 可以先作为第一版放进 about）
- `JSON`
- `math`
- getters/setters、flags、descriptors
- `proxy`
- `variables`（深入讲解 const/let/var）
- `immutability`（含 freeze，可以与 variables 概念合并）
- `object-helpers`（例如 Object.assign）
- 字符与码点
- this 和作用域（含 call/bind）
- 迭代器和“enumerators”
- 生成器和 yield
- 异步生成器和迭代器
- 按位运算符
- 模块、导入、导出、动态导入
- 鸭子类型
- 国际化 API
- `bigint`
- `symbol`
- JSDoc 注释
- 异步、事件循环
- setTimeout/setInterval
- 事件
- 有时“一切都是对象”（函数、数组和原始类型与对象的关系，例如装箱类型）
