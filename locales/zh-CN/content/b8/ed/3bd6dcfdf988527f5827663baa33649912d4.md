# 关于

有时候，你不需要为创建带状态的对象而付出额外的开销。这种情况下，可以使用`module`。

模块和类非常相似（实际上，在对象层次结构中，`Module`是`Classes`的父级），主要区别在于我们不使用实例方法，而是使用类方法。类方法以`self.`开头，可以直接在模块上调用。

例如：

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```
