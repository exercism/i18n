# 范围

[范围][range]表示两个值之间的一段区间。
最常见的支持范围的类型是`Int`、`Char`和`String`。
它们有很多用途，比如快速创建集合、截取字符串、检查某个值是否在范围内，以及迭代。
范围用范围运算符`..`或`...`创建（前者包含结尾值，后者不包含）。

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

之所以有两个范围运算符，是为了能创建包含或不包含结尾值的范围。比如在处理从 0 开始的下标时，这就很有用。

范围也可以用`Range`初始化器创建。

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
在 Crystal 中用范围运算符`..`或`...`创建范围后，如果想在范围上调用方法，需要把范围用括号括起来。
否则，方法会被作用在范围运算符的第二个参数上。

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## 获取子字符串

想截取字符串时，可以用范围运算符获取子字符串，也就是用子字符串的起始下标和结束下标创建一个范围。

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

也可以用负下标，从字符串末尾开始截取子字符串。

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## 范围方法

范围自带一组可以操作它们的方法。
例如，这些方法可以求范围中所有值之和，或者检查范围是否包含某个值。

| 方法                    | 描述                                                                    | 示例                            |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | 返回范围内所有值之和                                                    | `(1..5).sum # => 15`            |
| [`size`][size]          | 返回范围的大小                                                          | `(1..5).size # => 5`            |
| [`includes?`][indludes] | 如果范围包含给定的值则返回 `true`，否则返回 `false`                     | `(1..5).includes?(3) # => true` |

## 无开头和无结尾的范围

范围可以没有结尾，也可以没有开头。
无结尾或无开头的范围，其结尾值或开头值就是`nil`，但在定义范围时可以省略`nil`。

当你想从字符串开头开始截取，或者一直截取到结尾时，无开头或无结尾的范围就很有用。

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
如果不用在集合上，无结尾的范围可能会产生无限的序列，使用时务必小心。
~~~~

## Char 范围

Char 也可以用在范围里，让你得到两个 Char 之间的一段字符。
比如，想得到字母表时就很有用。

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## String 范围

String 也可以用在范围里，从而得到两个字符串之间的一段字符串。
不过当字符串范围里包含多个字符时，它的行为与`Char`略有不同。
字符串范围如果更复杂，它的行为可能会让人困惑，所以要小心使用。

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
