# 有状态的类

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr、readonly attr、private attr

| 写法 | 能否从外部读取 | 能否从外部修改 |
| --- | --- | --- |
| `attr x : INT` | 能 | 能 |
| `readonly attr x : INT` | 能 | 不能 |
| `private attr x : INT` | 不能 | 不能 |

`readonly`是默认就该用的那个。它让任何人都能看到比分，同时坚持对它的修改必须经过`home_goal`，关于计分的规则就写在那里。

## create 和 new

`new`会生成这个类的一个对象，其中每个属性都为空。它只能在类的内部使用。

`create`是一个名字固定的普通例程：`#C(args)`完全等同于`C::create(args)`。一个类可以有多个`create`，靠实参来区分；而一个都没有的类，根本无法用`#`来创建。

## SAME

`SAME`代表它所在的那个类。在`create`里它是返回类型；它也能用在实参中，正是它让被继承的例程指代继承它的那个类，而不是原来定义它的那个类。

## 没有返回类型的例程

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

没有`:`，也没有类型。这样的例程以语句的形式调用，不能出现在表达式里。它表明这次调用的重点在于它造成的那次改变。

## self

在例程内部，`self`就是调用它的那个对象。它很少需要写出来，因为单独写出的属性或例程名，已经表示它属于`self`。当这个对象需要被传递或返回时，就需要用到它：

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`、`new`、`void`、`result`、`value`和`out`都是 Sather 已经占用的词，都不能用作你自己起的名字。

## 引用，而非值

对象是通过引用来访问的。同一个记分牌的两个名字，看到的是同一个比分：

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

稍后出现的`immutable class`，就是获得另一种行为的方式。
