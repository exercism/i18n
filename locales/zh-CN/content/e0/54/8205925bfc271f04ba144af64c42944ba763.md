# 关于括号的说明

Tcl 是一门[非常简单的语言](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm)，但它的翻译解析代码的方式有几个棘手的边界情况。

## 花括号

在 Tcl 中，花括号只是把一段文本括起来的一种方式，这段文本可以被解释为代码或数据。花括号内可以出现嵌套的花括号，但嵌套的花括号必须配对。Tcl 的 man 手册页是这样写的：

> 花括号在词内嵌套：每多一个左花括号，就必须多一个右花括号（不过，如果词内的左花括号或右花括号_用反斜杠转义_，那么在查找匹配的右花括号时就不会计入它）。

那里的措辞相当具体：如果你想使用一个不配对的左花括号或右花括号字符，就必须用反斜杠转义。所以不要这样做：
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "{"}]
    # ......................^ will not work
}
```
应该这样做
```tcl
proc isOpenBrace {char} {
    return [expr {$char eq "\{"}]
    # ......................^^ will work
}
```

这在与 Tcl 解析注释的方式结合时可能会带来麻烦，而 Tcl 解析注释的方式与大多数语言不同。更多讨论见 [Tcl wiki](https://wiki.tcl-lang.org/page/Why+can+I+not+place+unmatched+braces+in+Tcl+comments)。

## 方括号

同样，由于 Tcl 用方括号进行[命令替换](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M11)，即使在双引号字符串内，也要小心转义左方括号。

## 圆括号

除了[关联数组变量](https://tcl.tk/man/tcl8.6/TclCmd/Tcl.htm#M12)之外，圆括号只是普通字符。
