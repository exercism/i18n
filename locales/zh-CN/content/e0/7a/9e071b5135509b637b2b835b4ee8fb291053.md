# 说明

在这个练习中，你将检查一个网络论坛上用户账户的权限。该论坛支持三种不同的权限：

- Read
- Write
- Delete

共有三种账户类型，每种都有不同的默认权限：

- Guest：可以读取帖子。
- User：可以读取和写入帖子。
- Moderator：可以读取、写入和删除帖子，拥有全部权限。

有时可以单独修改某项权限。例如，可以给访客账户加上写帖子的权限；而撤销某个账户的所有权限，结果就是该账户什么权限都没有。

## 1. 获取账户类型的默认权限

首先，定义一个 `AccountType` 枚举，表示三种账户类型：`Guest`、`User` 和 `Moderator`。

接下来，定义一个 `Permission` 枚举，表示三种权限类型：`Read`、`Write`、`Delete`，另外还有两个：`All` 表示拥有全部权限，`None` 表示没有任何权限。

然后实现（_静态_）`Permissions.Default()` 方法，返回特定账户类型的默认权限：

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. 授予权限

实现（_静态_）`Permissions.Grant()` 方法，用于授予（添加）一项权限：

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. 撤销权限

实现（_静态_）`Permissions.Revoke()` 方法，用于撤销（移除）一项权限：

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. 检查权限

实现（_静态_）`Permissions.Check()` 方法，它接收账户当前的权限，并检查该账户是否被授权拥有某项给定的权限：

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
