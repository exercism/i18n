# 简介

## 接口是一组方法

在最简单的形式下，**接口类型**就是一组方法签名。
下面是一个接口定义的例子，它包含两个方法 `Add` 和 `Value`：

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

像 `increment` 这样的形参名可以从接口定义中省略，但它们通常能提高可读性。

Go 中的接口名不包含 `Interface` 或 `I` 这个词。
相反，它们通常以 `er` 结尾，例如 `Reader`、`Stringer`。

## 实现接口

任何定义了接口方法的类型，都会自动隐式地“实现”该接口。
Go 中没有 `implements` 关键字。

下面的类型实现了我们上面看到的 `Counter` 接口。

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

对于实现接口来说，方法使用的是值接收者还是指针接收者都无所谓。
（如果你对这些内容不确定，可以回顾[方法的概念][concept-methods]。）

> 接口类型的值可以保存任何实现了这些方法的值。[^1]

这意味着现在凡是需要 `Counter` 接口的地方，都可以使用 `Stats`。

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

由于接口是隐式实现的，一个类型可以轻松实现多个接口。
它只需要定义好所有必需的方法。

## 空接口

Go 中有一种非常特殊的接口类型，即包含零个方法的**空接口**类型。
空接口这样写：`interface{}`。
`any` 是 `interface{}` 的别名，而且更常用。

由于空接口没有方法，所以每个类型都隐式地实现了它。
这对于定义一个能泛化地接受任何值的函数很有帮助。
在这种情况下，函数形参就使用空接口类型。
