# 简介

`Bool`类型是这门语言的基本构件之一。它旨在描述某个事物是 true 还是 false，分别用 `True` 和 `False` 这两个值来表示。

布尔值可以通过`&&`（“与”）和`||`（“或”）运算符组合，也可以用`not`函数取反。

布尔值在代码中创建分支时也非常有用，这些分支只有在满足特定条件时才会执行。在 Elm 中，这通过`if-then-else`表达式来实现，用法如下。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
