- Python 官方文档中的[布尔运算][boolean operations]是复习`bools`的好材料，Real Python 的[布尔值][python booleans]教程也是如此。
- Python 官方文档中的[比较][comparisons]和[比较示例][python comparisons examples]是复习比较的好材料。

## 1. 检查临界状态

- 比较运算符（[比较][comparisons review]）和布尔运算（[concept:python/bools]()）可以结合起来，与条件语句一起使用。
- 条件表达式必须求值为`True`或`False`。
- 当所有条件判断都返回`False`时，可以用`else`来执行对应的代码块。

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. 确定功率输出范围

- 比较运算符可以结合起来，与条件语句一起使用。
- 可以用任意数量的`elif`语句作为决策“分支”。
- 每个“分支”都可以有自己的`return`，不过代码检查工具可能会认为这是“不良写法”。
- 如果代码检查工具报错，可以考虑把某个分支的输出赋值给一个公共变量，然后再`return`该变量。
