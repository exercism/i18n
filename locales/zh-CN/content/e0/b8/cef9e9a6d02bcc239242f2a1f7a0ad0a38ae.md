# 提示

## 通用

- 前六个整数实参通过`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`传给函数。
- 内存中的地址是 64 位（8 字节）的值。

## 1. 为每个物品创建一条记录

- 前六个整数实参通过`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`传给函数。
- 内存中的地址是 64 位（8 字节）的值。
- 第六个之后的所有整数实参都通过栈传递，第一个位于`rsp + 8`。
- 额外实参的数量等于类别的数量，后者通过`r9`传入。
- 你可以用循环逐个添加这些额外实参，也可以把 [movsq][movs] 和 [rep][rep] 结合使用。

## 2. 为每月的物品列表预留空间

- 前六个整数实参通过`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`传给函数。
- 内存中的地址是 64 位（8 字节）的值。
- 调用分配函数之后，你需要知道数组的大小，才能清空它的字节。
- 调用外部函数时，它可能会修改任何_调用者保存寄存器_中的值。
- 你可以通过 [push][push] 把寄存器的值保存在栈中，也可以直接操作`rsp`。
- 对`rsp`的任何修改，包括通过`push`进行的修改，都必须在函数返回前撤销，可以用 [pop][pop]，也可以直接修改`rsp`。

## 3. 把物品插入每月的列表

- 前六个整数实参通过`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`传给函数。
- 内存中的地址是 64 位（8 字节）的值。
- 放不进寄存器的值要通过栈传给函数。
- 每个物品的记录占 120 字节的空间，远大于寄存器的最大容量（8 字节）。
- 通过栈传递的实参位于从`rsp + 8`开始的地址中。
- 你可以用循环把这些值写入目标内存位置，也可以把 [movsb][movs] 和 [rep][rep] 结合使用。

## 4. 打印一条物品

- 前六个整数实参通过`rdi`、`rsi`、`rdx`、`rcx`、`r8`和`r9`传给函数。
- 内存中的地址是 64 位（8 字节）的值。
- 介绍性字符串是可选的，你也可以改用`0`调用打印函数。
- 如果把介绍性字符串传给打印函数，它最多只能有 50 个 ASCII 字符，其中已经包含 NUL 终止符（值`0`）。
- 每次调用函数时，都必须为第六个之后的实参在栈上预留空间。
- System V ABI 规定，调用函数前栈应当按 16 字节对齐，这对调用外部函数尤其重要。
- 列表中每个物品的记录占 120 字节的空间。
