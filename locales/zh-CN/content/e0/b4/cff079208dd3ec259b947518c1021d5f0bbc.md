# 介绍

在 Java 中，`null`字面量用来表示值不存在。

Java 中的基本数据类型都有一个默认值，因此永远不能为`null`。
按照惯例，它们以小写字母开头，例如`int`。

引用类型包含对象的内存地址，并且可以取值为`null`。
它们通常以大写字母开头，例如`String`。

尝试给基本类型变量赋值为`null`会导致编译时错误，因为该变量始终保存着所赋类型的基本值。

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

给引用变量赋`null`值不会导致编译时错误，因为引用变量可以为`null`。

```java
//No error will occur as the String variable str is nullable
String str = null;
```
