# 示例

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

以点开头的行是_指示符_：它们是给汇编器的指令，而不是给处理器的指令。
`.equ` 把名字 `FRAME_SIZE` 赋给数字 16。
`.text` 表示后面的内容是代码。
`.global` 让标签 `is_triple` 在本文件之外也可见，这样其他代码就能调用它。
你可能还会见到 `.globl`，它的意思是一样的。

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` 检查 `a² + b² = c²` 是否成立，成立就返回 1，否则返回 0。
例如 `(6, 8, 10)` 得 1，因为 `36 + 64 = 100`。
标签 `is_triple` 标出函数的起始位置。
调用它时，`a`、`b` 和 `c` 分别放在寄存器 `a0`、`a1` 和 `a2` 中。

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

寄存器 `ra` 保存着_返回地址_，也就是函数结束时回到调用者中的位置。
每次 `call` 都会覆盖 `ra`，所以我们先把它保存到_栈_上。
栈向下增长，朝地址更小的方向延伸，所以从栈指针 `sp` 减去 16 就为我们预留了 16 个字节。
（`sp` 必须始终是 16 的倍数。）
我们还保存了 `b` 和 `c`，因为我们调用的函数可以修改 `a` 系列寄存器。

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` 已经在 `a0` 里了，`square` 正是从这里取它的输入。
`call` 把 `ra` 设为下一条指令的地址，然后跳到 `square`，`square` 会把结果放在 `a0` 中返回。

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

我们从栈上把 `b` 重新载入，求它的平方，再加到 `a * a` 上。

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

当且仅当 `a² + b² = c²` 时，这个差为零。
`seqz`（“若等于零则置位”）把它变成 1 或 0。

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

我们恢复 `ra`，并归还那 16 个字节的栈空间。
接着 `ret` 跳到 `ra` 中的地址，回到调用者。

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` 不调用其他函数，所以 `ra` 保持不变，没有什么需要保存。
它没有标成 `.global`，因为只有 `is_triple` 会用到它。
