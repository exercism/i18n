# 说明

你对 Blorkemon™️ 卡牌的怀旧之情丝毫没有减弱的迹象，甚至还重新开始收集它们，还拉上朋友们一起。

在这个练习中，卡牌收藏用`Set(String)`表示，因为当你的目标是收集所有已存在的卡牌时，重复的卡牌并不重要。

## 1. 开始收藏

你非常希望朋友们也加入你的 Blorkemon™️ 狂热，最好的办法就是送他们一张卡牌，帮他们开启自己的收藏。

实现`new_collection`，它把一张卡牌变成一个收藏。

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. 扩充收藏

一旦你有了一个收藏，它就有了自己的生命，必须不断成长。

实现`add_card`，它接收一张卡牌和一个收藏，返回一个包含两个值的元组：一个`Bool`，表示这张卡牌是否已经在收藏中；以及加入了这张卡牌后的收藏。

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. 开始交换

既然你的朋友们又为 Blorkemon™️ 疯狂了，你就可以借此通过交换卡牌来扩充自己的收藏。

并不是每次交换都值得做，有些甚至根本做不了。
你不能交换一张自己没有的卡牌，也不应该用一张卡牌去换你已经有的卡牌。

实现`trade_card`，它接收要交换的两张卡牌（你的和对方的）以及你当前的收藏。
返回值是一个包含两个值的元组：一个`Bool`，说明这次交换是否可行且值得；以及如果你真的完成了交换，最终会得到的收藏（即使实际上并不可行）。

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. 大家都有的卡牌

你和热爱 Blorkemon™️ 的朋友们聚在一起，想知道哪些卡牌最常见。

实现`boring_cards`，它接收一个收藏列表，返回一个排序后的卡牌列表，这些卡牌是所有收藏都有的。

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. 全部的卡牌

你和朋友们加起来是否拥有全部的 Blorkemon™️ 卡牌？

实现`total_cards`，它接收一个收藏列表，返回所有收藏中不同卡牌的总数。

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. 闪卡必胜

你的侄子马上就要来看你了，你想给他留下深刻印象。
小孩子都喜欢亮闪闪的东西，对吧？
Blorkemon™️ 卡牌也可以是闪光的！

实现`shiny_cards`，它接收一个收藏，返回一个集合，其中包含所有以`"Shiny "`开头的卡牌。

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
