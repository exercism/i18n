# 简介

## 继承

在 C# 中，可以借助_继承_来定义_类_的层次结构，让派生类（`Car`）继承父类（`Vehicle`）的行为和数据。如果没有指定父类，该类就会继承`object`类。

父类可以通过三种方式为派生类提供功能：

- 定义一个普通方法。
- 定义一个`virtual`方法，它和普通方法类似，只不过是派生类_可以_修改的方法。
- 定义一个`abstract`方法，这种方法没有实现，派生类_必须_实现它。含有`abstract`方法的类也必须标记为`abstract`。抽象类不能被实例化。

`protected`访问修饰符允许在派生类中访问父类的成员，但会阻止其他类访问。

派生类可以通过`base`关键字访问父类的成员。

```csharp
// Inherits from the 'object' class
abstract class Vehicle
{
    // Can be overridden
    public virtual void Drive()
    {
    }

    // Must be overridden
    protected abstract int Speed();
}

class Car : Vehicle
{
    public override void Drive()
    {
        // Override virtual method

        // Call parent implementation
        base.Drive();
    }

    protected override int Speed()
    {
        // Implement abstract method
    }
}
```

派生类的构造函数会在执行自身构造函数的逻辑_之前_，自动调用父类的构造函数。可以使用`base`关键字把实参传给父类的构造函数：

```csharp
abstract class Vehicle
{
    protected Vehicle(int wheels)
    {
        Console.WriteLine("Called first");
    }
}

class Car : Vehicle
{
    public Car() : base(4)
    {
        Console.WriteLine("Called second");
    }
}
```

如果有多个类派生自同一个基类，这两个（或更多）类往往会以不同的方式实现基类的同一个方法。这是一个非常重要的原则，叫做多态。例如，在上面例子的一个变体中，我们展示了使用`Vehicle`的代码如何根据实例化的是哪种载具而改变自己的行为。

```csharp
abstract class Vehicle
{
   public abstract string GetDescription();
}

class Car : Vehicle
{
   public Car()
   {
   }

   public override string GetDescription()
   {
      return "Runabout";
   }
}

class Rig : Vehicle
{
   public Rig()
   {
   }

   public override string GetDescription()
   {
      return "Big Rig";
   }
}

Vehicle v1 = new Car();
Vehicle v2 = new Rig();

v1.GetDescription();
// => Runabout
v2.GetDescription();
// => Big Rig
```
