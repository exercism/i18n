# 简介

`Option` 类型用于表示可能缺失、也可能存在的值。

它在 `gleam/option` 模块中的定义如下：

```gleam
type Option(a) {
  Some(a)
  None
}
```

`Some` 构造器用于在值存在时将其包装起来，`None` 构造器则用于表示值的缺失。

访问 `Option` 的内容通常通过模式匹配来完成。

```gleam
import gleam/option.{type Option, None, Some}

pub fn say_hello(person: Option(String)) -> String {
  case person {
    Some(name) -> "Hello, " <> name <> "!"
    None -> "Hello, Friend!"
  }
}
```

```gleam
say_hello(Some("Matthieu"))
// -> "Hello, Matthieu!"

say_hello(None)
// -> "Hello, Friend!"
```

`gleam/option` 模块还定义了一些处理 `Option` 类型的实用函数，比如 `unwrap`：它返回 `Option` 的内容，如果该 `Option` 为 `None`，则返回一个默认值。

```gleam
import gleam/option.{type Option}

pub fn say_hello_again(person: Option(String)) -> String {
  let name = option.unwrap(person, "Friend")
  "Hello, " <> name <> "!"
}
```
