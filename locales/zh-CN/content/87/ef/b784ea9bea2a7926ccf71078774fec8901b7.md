# 说明

在这个练习中，你将处理日志行。

每一行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志有三个不同的级别：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会接收一行日志，并要求你对它做一些处理。

## 1. 从日志行中获取消息

实现（_static_）`LogLine.Message()`方法，返回日志行的消息：

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

开头和结尾的空白字符都应被移除：

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现（_static_）`LogLine.LogLevel()`方法，返回日志行的日志级别，并以小写形式返回：

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. 重新格式化日志行

实现（_static_）`LogLine.Reformat()`方法，重新格式化日志行：把消息放在最前面，日志级别放在它后面并用括号括起来：

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
