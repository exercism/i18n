# 简介

`List` 与 `Array` 非常相似。不过，两者之间有一些重要的区别，这些可不能跳过：

1. 列表不能用方括号来索引，也就是不能用 `[0]`。
2. 列表不能初始化。
3. 没有列表推导式。
4. 列表可以在迭代过程中自由修改元素。

`List` 是 `haxe.ds` 包的一员，所以每当你想使用列表时，都需要导入它所在的包：

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```
