# 简介

`Integer` 可以保存任意大小的数字，只要不超过机器内存的上限；而 `Int` 对应的是能用 32 位或 64 位表示的正负整数集合（至少保证涵盖 -2^29 到 2^29）。

`Float` 对应实数集合，受计算机精度的限制。
针对数字定义的运算通常只适用于其中一种类型，而不能同时适用于两者。

在 `Float` 和 `Integer` 之间转换的函数有很多，其中包括把 `Int`/`Integer` 转换成 `Float` 的 `toFloat`，以及把 `Float` 转换成 `Int` 的 `ceiling`。

从整数类型（`Int` 或 `Integer`）转换到其他任何数字类型，都用函数 `fromIntegral` 完成。
目标类型会自动推断出来。
例如：

```haskell
n :: Integer
n = 6
x :: Float
x = fromIntegral n      --> x = 6.0

m :: Int
m = 7
y :: Double
y = fromIntegral m      --> y = 7.0
```
