# 说明

安特卫普编组站又是一个忙碌的夜晚。你是当班的调度员：驶入的货车要重新编组成出发列车，车钩要逐一检查，线路要在道岔处拆分，相同的货物要归并到一起以便计费。

每节*车厢*都是一个字符串，标明它装载的货物：`"coal"`、`"timber"`、`"crates"` 等。

## 1. 把车厢连成列车

定义`couple`，接收一个车厢数组和一个长度`n`，返回若干列互不重叠的列车，每列`n`节车厢。如果车厢总数不能整除，最后一列列车可以短一些。

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. 查看车钩

定义`peek-couplings`，接收一个车厢数组，返回每一对相邻车厢，好让检查员逐处查看车钩。

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. 在道岔处拆分车列

定义`split-at-junctions`，接收一个车厢数组和一个`junctions`数组（标记断点的车厢），返回各节道岔车厢之间的区段。道岔车厢本身不保留。

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. 归并相同的货物

定义`coalesce-cargo`，接收一个车厢数组，把装载相同货物的*连续*车厢归并成一段。

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
