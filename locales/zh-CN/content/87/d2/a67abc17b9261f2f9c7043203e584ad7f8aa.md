# 说明补充

完成这个练习有很多种方法，不过这个练习是专门为想练习编写自己的[能力处理器][ability-handler-docs]的人准备的。

编写一个 `Zipper` 能力，让你能在二叉树这种数据结构中来回移动。

`Zipper` 能力本身已经为你定义好了，但你需要自己实现它的处理器，让它能在我们指定的二叉树数据结构中导航。

给定下面这棵二叉树，如果我们依次调用 `Zipper.right`、`Zipper.right`、`Zipper.up`，再调用 `Zipper.left`，就应该停在值为 `5` 的节点上。

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

就本练习而言，如果你在一棵没有左分支或右分支的二叉树上调用 `left` 或 `right`，可以返回当前节点上的值。

## 值得思考的问题

能力处理器本身在哪些方面像一个拉链？你能把一个函数的 `continuation` 看作指向程序中下一个“节点”的指针吗？你能在处理器里保存过去对续延的调用，从而“回到”更早的状态吗？

你还能用这种方式遍历哪些其他数据结构？你能为 JSON 写一个 Zipper，或者为 HTML DOM 树写一个吗？
