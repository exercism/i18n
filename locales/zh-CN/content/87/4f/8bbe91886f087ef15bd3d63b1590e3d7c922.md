# 关于字符串

在 Kotlin 中，[`string`][ref-string]是一串不可变的 Unicode 字符序列。

[`Immutable`][wiki-immutable] 意味着对字符串的任何操作都必须返回一个新字符串：原字符串永远不会改变。

[`Unicode`][wiki-unicode] 意味着世界上大多数书写系统都能表示出来，但与 C 这样的早期语言不同，字符和字节之间没有一一对应的关系。
这一点会在 [`Chars`][concept-chars] 概念中进一步讨论。

字符串用双引号`" "`括起来。

有些字符需要转义：`\\`，以及常见的非打印字符，比如 `\t`（制表符）和 `\n`（换行符）。

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

多行字符串用 3 个双引号括起来，可以包含任意文本（无需转义）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

用 [trimIndent][trimIndent-doc] 去掉各行共同的缩进。
这在格式化字符串时很有用：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

或者，[trimMargin][trimMargin-doc] 允许你指定一个分隔符。
这样 `String` 里的每一行都从分隔符之后开始。
分隔符默认是 `|`，但你可以把不同的分隔符作为形参传入。
例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字符串可以用 `+` 拼接，但最好只用在简短简单的情况下。
还有别的、通常更好的做法。

## 字符串模板

[`Templates`][ref-templates] 指的是其他一些语言所说的“插值”。

如果字符串里有一个美元符号 `$` 后跟标识符，或者有把表达式包起来的花括号（`{expression}`），它们会分别被替换成该标识符的值或该表达式的结果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## 字符串格式化

在 JVM 平台（且仅限该平台）上，`String.format()` 可以进行比字符串模板更精确的格式化，其[语法][web-formats]类似于（_非常古老！_）[`printf`][wiki-printf] 函数。

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

## 字符串函数

Kotlin 提供了_许多_[`functions`][ref-string-functions] 来操作字符串。

它们大多是 [`extensions functions`][ref-extensions]，而不是 `String` 类的成员，不过这对我们如何使用它们几乎没有影响。

~~~~exercism/note
Kotlin 那相当复杂的[文档][ref-string-functions]页面默认会隐藏扩展函数。
在撰写本文时，最有价值的内容藏在一个名为 `Members & Extensions` 的标签页里。
点击它可以展开这一部分，查看 `String` 类上所有可用的成员和扩展。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

下面这个例子只展示了可用功能中的一小部分：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## 构建字符串

有时一个长字符串需要分阶段逐步构建，比如在循环里。

用 `+` 拼接字符串很快就会既不优雅、性能又差：不可变性意味着需要_大量_复制。

Kotlin 有几种更高效的方式来组合多个字符串：

- 字符串模板，前面已经介绍过。
- [`joinToString()][ref-jointostring]，会在 [Lists][concept-lists] 概念中讲到。
- Java 的 [`StringBuilder`][ref-stringbuilder]，它并不被认为是特别地道的 Kotlin 写法。
- Kotlin 的 [`buildString()`][ref-buildstring]，它用更简洁、更地道的语法把 `StringBuilder` 包装起来。
它把构建字符串的逻辑作为 lambda 实参接收，这会在后面的概念中讨论。

本质上，`StringBuilder` 是一种类似列表的结构，带有许多方便的方法。
这里只列出一小部分：

- [`append()`][ref-sb-append]：添加到末尾。
- [`insert()`][ref-sb-insert]：在指定位置插入。
- [`deleteAt()`][ref-sb-deleteat] 和 [`deleteRange()`][ref-sb-deleterange]：从指定位置删除。
- `toString()`：最后转换成普通字符串，用一次高效的操作把所有内容拼接起来。

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

下面是一个 `buildString()` 的例子，用到了后面概念中的语法：

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
