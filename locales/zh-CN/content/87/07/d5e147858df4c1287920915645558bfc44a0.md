# 简介

这可以说是一个_很大_的主题！
完全可以为它写一整本厚书，而且确实有好几个人这么做了（在 Amazon 上搜索 “unicode book” 就能看到一些例子）。

## 极简历史

在早几十年，计算机处理字符要简单得多，因为那时的程序员认为英语是唯一重要的语言。
于是就有了：26 个字母（区分大小写）、10 个数字、几个标点符号，再加上一个让铃声响起的编码（0x07），而这一切都能塞进 7 位里：这就是 [ASCII][wiki-ascii] 字符集。

自然，人们开始问：那 à、ä 和 Ł 怎么办呢？接着又有人问起 ऄ、ஹ 和 ญ，而年轻人则想要 emoji 😱。
该怎么做呢？

长话短说，许多聪明又有耐心的人在委员会里工作了好些年，才敲定 [Unicode][web-unicode] 字符集以及 [UTF-8][wiki-utf-8] 之类编码的细节，同时大量软件也需要进行_极其_复杂的重写。
而且，也因此引入了许多新的 bug。

为了防止_所有东西_都崩掉，Unicode/UTF-8 的设计保证了前 127 个编码与 ASCII 完全一致_（连那个铃声也不例外）_。

## Kotlin 中的字符

在大约 2005 年之后设计的语言有一个巨大的优势：当时已经存在一个相当稳定的 Unicode 标准。

Kotlin（2011 年首次发布）可以假定用户会使用各种各样的（人类）语言，并且需要用 Unicode 来表达它们。

字符字面量用单引号书写，与用双引号书写的字符串不同。
这对来自 C/C++ 世界的人来说大概显而易见，但对 Python 和 JavaScript 程序员来说可能有些困惑。

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

在 `Char` 和 `Int` 之间转换很简单：

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

编译器允许对 `Char` 进行_某些_形式的整数运算：

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## `Char` 的一些函数

和往常一样，[函数][ref-char-lib]多到在这里根本讲不完，所以下面只是挑选了一部分。

- 对支持大小写的字母表，可以用 [`uppercase()`][ref-uppercase] 和 [`lowercase()`][ref-lowercase] 转换大小写。
- 用 [`isUpperCase()`][ref-isuppercase] 和 [`isLowerCase()`][ref-islowercase] 判断大小写。
- 用下面的函数判断字符类型：
    - [`isLetter()`][ref-isletter]，涵盖许多字母表
    - [`isDigit()`][ref-isdigit]，范围 0..9
    - `isLetterOrDigit()`，是前两个的组合
    - [`isWhitespace()`][ref-iswhitespace]，任意空白字符

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Char 列表与 String 的相互转换

要把 String 变成 Char 列表，可以用 `toList()`。

要把 Char 列表变回 String，则有 [`joinToString()`][ref-jointostring] 函数，它接收一个分隔符（通常是空字符串）作为实参。

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

注意，`joinToString()` 作用于 List 或 Array。
要把单个 `Char` _转换_成只含 1 个字符的字符串，请用 `toString()`。

```kotlin
'a'.toString() // => "a"
```

要检查某个字符是否存在于 `String` 中，或者存在于 `Char` 列表或数组中，可以用 `in`，它对应 [`contains()`][ref-contains] 函数。

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
