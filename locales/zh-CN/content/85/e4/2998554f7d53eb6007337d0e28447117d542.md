# 说明

你在一座研究站负责安保工作。员工佩戴的*徽章*，其代码遵循严格的格式；访问日志里满是这样混在普通文本中的代码，日志在分享出去之前必须先清理干净。正则表达式正是完成这些任务的好工具。

有效的徽章代码是**2 个大写字母、1 个连字符，然后是 4 位数字**，例如`NS-1024`。

## 1. 检查徽章代码

定义`valid-badge?`，它接收一个徽章字符串，当*整个*字符串是一个有效的徽章代码时返回`t`，否则返回`f`。

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. 从日志行中提取所有代码

定义`badge-codes`，它接收访问日志中的一行，按顺序返回其中出现的所有徽章代码组成的序列。

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. 统计代码中的数字个数

定义`digit-count`，它接收一个字符串，返回其中包含的数字个数。

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. 对密码脱敏

日志行有时会把密码记录为`pass=`后跟密码内容（任意一串非空格字符）。定义`redact`，它接收一行日志，返回将这类密码全部替换为`pass=****`后的结果。

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
