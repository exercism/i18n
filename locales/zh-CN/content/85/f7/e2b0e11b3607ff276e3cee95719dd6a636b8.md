# 测试

## 运行测试

要运行测试，请执行以下命令：

```bash
dotnet test
```

## 完成练习

完成一道练习，意味着让它所有的测试都通过。默认情况下，运行测试时只会执行一个测试（第一个）。这是有意为之的，这样你就能专注于只让这一个测试通过。一旦它通过了，你就可以通过删除测试的 `[<Fact>]` 或 `[<Theory>]` 属性中的 `Skip = "Remove this Skip property to run this test"` 来启用下一个测试。当所有测试都被启用，并且你的实现让它们全部通过时，你就完成了这道练习！

为了帮你上手，每道练习都附带一个存根实现文件。你可以把这个文件作为构建解答的起点。如果你觉得这样做是对的，可以随意删除或修改这个文件。

## 使用包

大多数练习不用任何外部包就能完成。不过，对于确实想使用外部包的练习，你可以通过运行以下命令把它添加到项目中：

```bash
dotnet add package [package-name]
```
