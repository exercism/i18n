# 说明补充

## 寄存器

| 寄存器 | 用途        | 类型    | 说明                            |
| -------- | ------------ | ------- | -------------------------------------- |
| `$a0`    | 输入        | 地址 | 第一个颜色，以 null 结尾的字符串  |
| `$a1`    | 输入        | 地址 | 第二个颜色，以 null 结尾的字符串 |
| `$a2`    | 输入        | 地址 | 第三个颜色，以 null 结尾的字符串  |
| `$a3`    | 输入/输出 | 地址 | 以 null 结尾的输出字符串          |
| `$t0-9`  | 临时        | 任意     | 用于临时存储             |
