# 关于

字符列表使用`~c`Sigil 创建。

```elixir
~c"hello"
```

~~~~exercism/note
注意，在较旧版本的 Elixir 中，字符列表用单引号表示为 `'hello'`。
~~~~

字符列表是整数的数组。这些整数表示某个字符的 Unicode 值，也就是码点。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

## 字符列表_就是_数组

```elixir
~c"" === []
# => true

is_list(~c"hello")
# => true
```

因为字符列表就是数组，你可以像处理任何其他数组一样处理它们：使用递归和模式匹配，或者使用 [`List`][list] 模块。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99

List.first(~c"hello")
# => 104
List.pop_at(~c"hello", 0)
# => {104, ~c"ello"}

```

你可以用 [`++`][kernel-concat-list] 把两个数组拼接在一起。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

第一个数组越长，拼接就越慢，所以要避免反复向任意长度的数组追加元素。

## 可打印性

如果一个整数数组中只包含可打印字符的码点，它就会显示为字符列表，即使它是用 `[]` 语法定义的。

```elixir
~c"ABC"
# => ~c"ABC"

[65, 66, 67]
# => ~c"ABC"
```

如果一个整数数组中哪怕只有一个不可打印字符的码点（例如 `0-6`、`14-26`、`28-31`），它也会显示为数组，即使它是用`~c""`语法定义的。

```elixir
~c"ABC\0"
# => [65, 66, 67, 0]

[65, 66, 67, 0]
# => [65, 66, 67, 0]
```

可以用 [`List.ascii_printable?`][list-ascii-printable] 检查可打印性。

```elixir
List.ascii_printable?([65, 66, 67])
# => true
List.ascii_printable?([65, 66, 67, 0])
# => false
```

请记住，这只是_显示_同一份数据的两种不同方式。它们的值完全相等。

```elixir
~c"ABC" === [65, 66, 67]
# => true
```

用 [`IO.inspect`][io-inspect] 打印数组时，可以用 [`:charlists`][inspect-opts] 选项来控制数组的打印方式。

```elixir
IO.inspect(~c"ABC", charlists: :as_charlists)
# => prints ~c"ABC"

IO.inspect(~c"ABC", charlists: :as_lists)
# => prints [65, 66, 67]
```

## 码点

在字符前加上`?`就能得到它的码点。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

## 字符列表与字符串

由相同字符组成的字符列表和字符串并不相等。

```elixir
~c"hello" == "hello"
false
```

字符列表中的每个值都是[字符的 Unicode 码点][unicode-table]，而在字符串中，这些码点按 [UTF-8][utf8] 编码。

```elixir
IO.inspect(~c"tschüss", charlists: :as_lists)
# => prints [116, 115, 99, 104, 252, 115, 115]

IO.inspect("tschüss", binaries: :as_binaries)
# => prints <<116, 115, 99, 104, 195, 188, 115, 115>>
```

注意，`ü` 的码点是 `252`，在 UTF-8 中编码为 `195` 和 `188`。

**在实际中，字符列表很少使用**。它的主要用途是与 Erlang 交互，尤其是在使用不接受二进制数据作为参数的旧库时。

在 Elixir 中处理文本时，**请用字符串来存储文本**。`String` 模块提供了大量处理文本的函数，字符列表则没有这些函数。

可以用 [`to_string`][kernel-to-string] 把字符列表转换成字符串。

```elixir
to_string(~c"hello")
# => "hello"
```
