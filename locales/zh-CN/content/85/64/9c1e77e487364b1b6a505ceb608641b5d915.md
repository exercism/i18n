# 说明

在这个练习中，你要编写代码，帮助一位自由职业者就某些项目的价格与客户沟通。
你将编写几个工具函数，快速算出客户的费用。

```exercism/note
`ratePerHour` 变量和 `dayRate` 函数都与钱有关。
它们的计量单位是每个单位时间对应的金额：分别是小时和天。
```

## 1. 根据时薪计算日薪

一位客户联系这位自由职业者，询问收费标准。
自由职业者解释说，他们**_每天工作 8 小时。_**
但他们只知道这个项目的时薪。
请根据时薪帮他们估算日薪。

```javascript
dayRate(89);
// => 712
```

日薪不需要四舍五入，也不需要转换成“固定”精度。

## 2. 根据固定预算计算工作天数

又过了一天，一位项目经理请这位自由职业者做一个预算固定的项目。
请根据固定预算和这位自由职业者的时薪，帮他们算出预算用完之前可以工作多少天。
结果_必须_**向下取整**为最接近的整数。

```javascript
daysInBudget(20000, 89);
// => 28
```

## 3. 计算大型项目的折扣价

客户常常请这位自由职业者做持续好几个月的大项目。
这种情况下，自由职业者决定对每个完整月份给出折扣，剩余的天数按日薪计费。
你的工作与生活平衡得很好，每个自然月只工作 22 天，所以**_每个月的计费天数是 22 天。_**
请根据时薪、项目包含的计费天数以及每月折扣率，帮他们估算这类项目的费用。
折扣总是以数字形式传入，其中 `42%` 会写成 `0.42`。结果_必须_**向上取整**为最接近的整数。

```javascript
priceWithMonthlyDiscount(89, 230, 0.42);
// => 97972
```
