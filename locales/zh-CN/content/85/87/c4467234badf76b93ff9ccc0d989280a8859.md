# 介绍

*disposable* 指的是任何持有操作系统资源（打开的文件、套接字、基于哈希表的锁）的东西，用完之后必须释放。Factor 的 `destructors` vocab 把这些东西包进一个小框架里，这样即使异常让栈展开，清理也照样会发生。

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` 会带着资源运行这段 quotation，并在退出时释放它。如果有多个资源，就用 `with-destructors` 开一个作用域，再用 `&dispose`（正常退出*和*出错时都释放）或 `|dispose`（只在出错时释放）把每个资源注册进去。

一个类通过继承 `disposable`、实现 `dispose*` 泛型来加入这个框架；框架对每个对象只调用它一次，而且只调用一次。调用方使用的公开 word 是 `dispose`。

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
