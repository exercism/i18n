# 说明

在本练习中，你将编写一些代码，帮助你按照最爱的烹饪书做出一份绝妙的千层面。
你有四个任务，都与烹饪千层面所花的时间有关。

## 1. 定义预计的烘烤时间（分钟）

定义常量`expectedMinutesInOven`，用来存储千层面应该在烤箱里放多少分钟。
根据烹饪书，预计的烘烤时间是 40 分钟：

```swift
expectedMinutesInOven
// Returns 40
```

## 2. 计算剩余的烘烤时间（分钟）

定义函数`remainingMinutesInOven(elapsedMinutes:)`，它接受实参`elapsedMinutes`，表示千层面已经在烤箱里待过的分钟数。
该函数应返回千层面还需要在烤箱里待多少分钟，依据是上一个任务中预计的烘烤时间。

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
```

## 3. 计算准备时间（分钟）

定义函数`preparationTimeInMinutes(layers:)`，它接受实参`layers`，表示你往千层面里添加的层数。
假设每准备一层需要 2 分钟，该函数应返回你准备千层面所花的分钟数。

```swift
preparationTimeInMinutes(layers: 2)
// Returns 4
```

## 4. 计算总工作时间（分钟）

定义函数`totalTimeInMinutes(layers:elapsedMinutes:)`，它接受两个实参：`layers`形参是你添加到千层面中的层数，`elapsedMinutes`形参是千层面已经在烤箱里待过的分钟数。
该函数应返回你烹饪千层面总共工作了多少分钟，也就是准备时间（分钟）与千层面此刻在烤箱里所花时间（分钟）之和。

```swift
totalTimeInMinutes(layers: 3, elapsedMinutes: 20)
// Returns 26
```
