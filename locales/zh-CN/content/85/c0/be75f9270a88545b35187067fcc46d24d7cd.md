不过事情有点乱：Azara 的坐标格式和排序似乎与 Rui 的不同，他们得不停地在两份清单之间来回对照，才能弄清楚哪个宝藏对应哪个地点。
作为初学 Julia 的程序员，他们来找你帮忙写一个小程序（其实是一组函数），好把寻宝信息整理得更清楚。

## 1. 提取坐标

实现`get_cooordinate()`函数，它接收 Azara 清单中的一个`(treasure, coordinate)`对，只返回提取出来的地图坐标。

```julia-repl
julia> get_cooordinate( ("Scrimshaw Whale's Tooth", "2A") )
"2A"
```

## 2. 格式化坐标

实现`convert_coordinate()`函数，它接收一个 "2A" 格式的坐标，返回一个`('2', 'A')`格式的元组。

```julia-repl
julia> convert_coordinate("2A")
('2', 'A')
```

## 3. 匹配坐标

实现`compare_records()`函数，它接收一个`(treasure, coordinate)`对和一个`(location, coordinate, quadrant)`记录，并比较双方的坐标。
如果坐标“匹配”，返回 **`true`**；如果不匹配，返回 **`false`**。
为准确比较，按需重新格式化坐标。

```julia-repl
julia> compare_records(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "blue"))
false

julia> compare_records(("Model Ship in Large Bottle", "8A"), ("Harbor Managers Office", ('8', 'A'), "purple"))
true
```

## 4. 合并匹配的记录

实现`create_record()`函数，它接收 Azara 清单中的一个`(treasure, coordinate)`对和 Rui 清单中的一个`(location, coordinate, quadrant)`记录，**如果坐标匹配**，就返回`(coordinate, location, quadrant, treasure)`。

如果坐标_不_匹配，返回一个空元组。
为准确比较，按需重新格式化坐标。

```julia-repl
julia> create_record(("Brass Spyglass", "4B"), ("Abandoned Lighthouse", ('4', 'B'), "Blue"))
("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

julia> create_record(("Brass Spyglass", "4B"), ("Seaside Cottages", ('1', 'C'), "Blue"))
()
```
