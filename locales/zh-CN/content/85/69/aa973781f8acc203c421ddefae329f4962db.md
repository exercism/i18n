# 简介

## 数字

Java 中有两种不同的数字类型：

- 整数：小数点后没有数字的数（即整数）。例如`-6`、`0`、`1`、`25`、`976`和`-500000`。
- 浮点数：小数点后可以有一位或更多位数字的数。例如`-20.4`、`0.1`、`2.72`、`16.984025`和`1024.0`。

Java 中最常见的两种数字类型是`int`和`double`。`int`是 32 位整数，`double`是 64 位浮点数。

算术运算使用标准的算术运算符完成。数字可以使用标准的数值比较运算符（例如`5 > 4`和`4 <= 5`）以及相等（`==`）和不等（`!=`）运算符进行比较。

Java 有两种数值转换：

1. 隐式转换：不会丢失数据，也不需要额外的语法。
2. 显式转换：可能会丢失数据，需要以_强制类型转换_的形式添加额外的语法。

由于`int`的精度低于`double`，从`int`转换为`double`是安全的，因此属于隐式转换。然而，从`double`转换为`int`可能会丢失数据，因此需要显式转换。

## if-else 语句

### _if-then_ 语句

Java 中最基本的控制流语句是 _if-then_ 语句。只有当特定条件为`true`时，这种语句才会执行某段代码。_if-then_ 语句使用`if`子句定义：

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

在上面的例子中，如果汽车没有燃料了，调用`Car.drive`方法什么也不会发生。

### _if-then-else_ 语句

当`if`子句中的条件求值为`false`时，_if-then-else_ 语句会提供一条替代的执行路径。这条替代执行路径跟在`if`子句之后，使用`else`子句定义：

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，如果汽车没有燃料了，调用`Car.drive`方法会调用另一个方法来让汽车停下。

_if-then-else_ 语句还可以借助`else if`子句支持多个条件：

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，当燃料小于或等于`5`时驾驶汽车，汽车仍会行驶，但会点亮燃料指示灯。当燃料降到`0`时，汽车会停止行驶。
