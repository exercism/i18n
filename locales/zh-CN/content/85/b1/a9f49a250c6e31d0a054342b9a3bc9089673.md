# 说明附录

## 提示

单元测试里给出了一些单词的示例。试着把辅音归类，而不要只针对单元测试中出现的那些具体辅音组合来做。

这个练习处理的是文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是一个字符列表。如果想更高效地处理文本数据，可以使用`Text`类型。

作为这个练习的可选扩展，你可以

- 阅读 Haskell 中[字符串类型](https://haskell-lang.org/tutorial/string-types)的相关内容。
- 在 package.yaml 的依赖列表里加上`- text`。
- 按照[下面的方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

      import qualified Data.Text as T
      import           Data.Text (Text)

- 现在你可以写出例如`translate :: Text -> Text`这样的签名，并用`T.isSuffixOf`这样的方式引用`Data.Text`里的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档。

这一部分完全是可选的。
