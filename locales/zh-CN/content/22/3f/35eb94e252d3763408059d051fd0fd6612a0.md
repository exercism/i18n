# 关于
C++ 内置的数字类型可以分为整数和浮点数。
整数是没有小数部分的数字，比如`0`、`691`或`-2`。
浮点数是带有小数点的数字，比如`6.02214076`、`0.1`或`-1.616`。

## 整数
下面的例子展示了四个不同变量的声明和初始化。

```cpp
int m_morales{9241};              // base 10: 0-9
int a_apaec{0x24CD};              // base 16: 0-9 and A-F
int m_gargan{0b10010000011001};   // base  2: 0-1
int b_reilly{022031};             // base  8: 0-7
                                  // Leading with a 0 not the letter o.
```

给`int`变量赋值时，可以直接使用字面量。
字面量是直接写死在代码里的数字，比如`9241`。
不同的进制有各自的整数字面量。
十进制整数字面量最常见，使用`0`到`9`这些数字。
加上特殊前缀（比如`0x`）就能使用其他进制。
上面的例子展示了数字`9421`的四种表示形式和前缀。
所有变量都被初始化为同一个值。

想了解各种进制表示系统的更多细节，可以看看[这篇小教程][cpp_numerical_bases]。

可以用撇号分隔数字，方便阅读。
`9'241`等同于`0b0100'100'0001'1001`或`92'4'1`。

## 浮点数

浮点字面量有两种写法。
除了直观的`0.0024`，还可以使用它的科学计数法`2.4e-3`。
最常用的浮点类型是`double`。

## 算术运算

C++ 支持用`+`、`-`、`*`、`/`、`(`、`)`和`%`构成表达式。
两个整数之间运算的结果仍然是整数。
`5 / 2`的结果是`2`。
当参与运算的类型中有一个是浮点类型时，结果也会是浮点数。
`5.0 / 2`和`5 / 2.0`的结果都是`2.5`。
`%`是求模运算符，返回整数除法的余数：`5%3`的结果是`2`。

## 赋值运算符

赋值运算符用一个字面量给变量赋值。
赋值总是从右到左进行，反之则不行。

```cpp
int length = 5;
int width = 2;
length = width;
```

这里，整数值`5`被赋给变量`length`。
接着，整数值`2`被赋给变量`width`。
最后，`width`的值被复制到变量`length`中，原来的值`5`就丢失了。
还要注意，我们只是在执行赋值操作的那一刻把`width`的值赋给`length`。
因此，如果之后`width`的值发生变化，也不会影响`length`取得的值。

赋值运算符可以和其他运算符（算术运算符和位运算符）组合，这类运算符称为`compound assignment`运算符，即`+=`、`-=`、`*=`、`/=`、`%=`。
这些运算符会对变量的当前值执行运算，从而修改它。

```cpp
// we start with 0 people
int people{};
// we need 0 eggs
int eggs{};
// two people joined:
people += 2;
// people is now 2
// let's add 3 eggs per person
eggs += 3 * people;
// eggs is now 6
```

变量`people`和`eggs`被初始化为`0`。
然后，我们在变量`people`现有的值`0`上加上整数值`2`，再赋值回`people`。
现在`people`变成了`2`。
接着，我们为每个人加上`3`个鸡蛋，总共是`6`个鸡蛋。
现在把这个`6`加到变量`eggs`现有的值`0`上，再赋值回`eggs`。
现在`eggs`就是`6`了。
等价的表达式是`people = people + 2`和`eggs = eggs + (3 * people)`。

## 类型转换

类型转换是把一种类型转换成另一种类型。
如果需要`double`，可以用`int`来代替。
上面的`5.0 / 2`例子就是通过把`2`隐式转换为`2.0`来处理的。
把`double`转换成`int`可能会丢失信息。
好的做法是用`static_cast<T>`把到另一种类型 T 的转换写成显式的。
通过`(T)`进行的旧式 C 风格转换在现代 C++ 中不推荐使用，但仍应有所了解。

```cpp
double pi{3.14};
int about_2_times_pi_cpp{static_cast<int>(pi) * 2};
// Old C-style cast:
int about_2_times_pi_c{(int)pi * 2};
```

## 精度与表示

C++ 中的数字不能任意大。
比如`int`用 32 位表示。
这足以表示`2^32`个数字，大约 40 亿。
算上`0`，`int`能表示的最大和最小数字分别是`-2^31`和`2^31 - 1`。

浮点数通常使用 15 位小数的精度来实现，但具体的表示方式会因宿主系统而异。
