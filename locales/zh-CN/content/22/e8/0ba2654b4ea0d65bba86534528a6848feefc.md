# 关于

[Reason](https://reasonml.github.io/) 是一套面向 Javascript 程序员的语法和工具链，基于函数式语言 [OCaml](https://ocaml.org/)。

由于采用静态类型，它可能比 Javascript 更安全，但强大的类型推断意味着类型标注不会成为你的负担。

Exercism 上的练习会直接编译成 JS，而 Reason 可以通过 OCaml 工具链编译成原生代码，用于 IoS、Android，甚至[微控制器](http://www.algo-prog.info/ocapic/web/index.php?id=ocapic)
