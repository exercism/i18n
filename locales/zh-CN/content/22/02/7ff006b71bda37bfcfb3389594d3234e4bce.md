# 关于

Gleam 中的数组是一个不可变的集合，可以包含零个或多个值。数组中的值必须类型相同。由于数组不可变，一旦创建完成，它的值就永远不会改变。任何看起来会修改数组的函数或运算符（比如添加一个元素），实际上都会返回一个新的数组。

数组可以这样定义：

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

给数组添加元素最常见的方式，是用展开语法把它添加到最前面：

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

Gleam 标准库中的 [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) 模块包含许多处理数组的实用函数。这个模块在 Gleam 代码中非常常用，所以熟悉它很有好处。

数组模式可以用在 `case` 表达式中，匹配数组并把其中的值赋给变量：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

除了匹配长度完全相同的数组，展开语法还可以用来匹配长度至少为某个值的数组：

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

展开语法还可以把数组剩余的部分赋给一个变量：

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

`case` 表达式应该为所匹配类型的每一个可能的值都提供一个模式，所以最后常常用一个丢弃模式（`_`）来处理剩下的所有值。
