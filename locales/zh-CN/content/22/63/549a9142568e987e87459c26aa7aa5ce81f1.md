# 简介

在 Clojure 中，`vector`是一种有序、带下标、不可变的集合，可以包含零个或多个值。这意味着，一旦创建了 vector，就无法再修改它。用于操作 vector 的函数会返回一个新的 vector，而原来的 vector 保持不变。vector 中值的类型可以不同。vector 可以这样定义：

```clojure
(def empty [])
(def single-value [5])
```

可以使用下标从 vector 中取出元素。Clojure 的 vector 下标从零开始，也就是说，第一个元素的下标始终是零：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原来的 vector 保持不变：

```clojure
numbers
;;=> [2 3 5]
```

要记住更新后的值，我们需要把它传递下去，或者用 var 保存起来：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
