# 简介

Python 中的 `str` 是一个由 [Unicode 码点][unicode code points] 组成的[不可变序列][text sequence]。
这些码点可以包括字母、变音符号、定位字符、数字、货币符号、emoji、标点符号、空格和换行符等等。

字符串实现了所有[通用序列操作][common sequence operations]，也可以用 `for item in <string>` 或 `for index, item in enumerate(<string>)` 语法迭代。

字符串可以用 `<str> + <other str>` 或 `<str>.join(<iterable>)` 拼接，也可以用 `<str>.split(<separator>)` 拆分。
字符串还提供多种额外的格式化、组装和模板选项。

由于不可变，`str` 对象在内存中的值不会改变；那些看起来会修改字符串的方法，实际返回的是新的副本或新的 `str` 实例。
