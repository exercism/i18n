# 简介

**闭包**是一种 [Clojure 中的][clojure-guide-closures]编程模式，它允许在函数内部使用来自外层[词法作用域][wiki-lexical-scope]的变量。Clojure 透明地支持闭包，很多时候人们用了它，却并不知道它是什么。

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## 用闭包保存状态并传递值

使用 atom 可以保留一部分状态：

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

每调用一次`increment`，它的计数器就会自增：

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
