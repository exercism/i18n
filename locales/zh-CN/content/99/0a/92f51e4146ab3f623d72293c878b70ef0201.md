# 使用字符串插值

[comment]: # (This warning is raised when the solution doesn't use string interpolation)

使用[字符串插值](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20)将`name`形参插入到输出的字符串中。

- 在可能的情况下，Exercism 的 Elixir track 建议使用字符串插值而不是字符串拼接，以提高可读性。

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [任何 Elixir 表达式](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30)都可以写在字符串插值语法中

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
