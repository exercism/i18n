# 说明补充

## 提示

带有*返回类型*的函数只能返回该*类型*的数据和`null`。不过，函数调用方只期望得到一种数据类型。

示例：
```dart
String hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
```
为了更清楚地说明这个函数还可以返回`null`或其他数据类型，请使用`dynamic`。
```dart
dynamic hello(int a){
    if ( a == 0){
        return "a";
    } else {
        return null;
    }
}
