# 简介

在`Promise`类出现之前，处理异步代码只有一种方式：_回调模式_。

回调是一个函数，它作为实参传给另一个函数，并在那个函数中的某个操作完成后被调用。这类回调函数有一个常见的模式：把“错误”作为第一个形参（见下面的示例）。

```javascript
function callback(error, arg2, arg3) {}
```

这和异步代码有什么关系？

过去，回调一直被用来让我们在异步任务完成后做一些工作，同时不阻塞整个程序。

```javascript
fetchProduct(productId, function (error, data) {
  if (error) {
    // Handle the error
  } else {
    // Do some work
  }
});
```

在上面的示例中，`fetchProduct`函数（它是异步的）接收一个回调作为第二个实参，用来决定取回商品数据后该做什么。
