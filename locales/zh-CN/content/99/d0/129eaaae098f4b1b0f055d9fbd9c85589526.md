# 说明

你的朋友 Linus 是一名火车司机，在城市之间驾驶货运列车。虽然他开火车很在行，但对物流和电脑却一窍不通。他想请你用编程帮忙整理列车信息，并修正路线数据里的错误。

~~~~exercism/note
这道练习用切片、索引和各种 `dict` 方法就能轻松解决。不过，我们希望你在完成下面每个任务时练习打包、解包和多重赋值。
~~~~

## 1. 创建包含所有车厢的数组

你的朋友一直在记录每节车厢的标识符（ID），但系统在任意时刻要处理多少节车厢，他从来都说不准。如果能把这些数据打包成一个统一的`list`，物流程序的其余部分就会轻松得多。

请实现一个函数 `get_list_of_wagons()`，它接受任意数量的车厢 ID。每个 ID 都是正整数。函数应当`return`一个`list`，其中包含给定的这些 ID。

```python
>>> get_list_of_wagons(1, 7, 12, 3, 14, 8, 5)
[1, 7, 12, 3, 14, 8, 5]
```

## 2. 修正车厢数组

到这里，你对这些数据以及它在物流程序中的用法已经开始有感觉了。ID 系统总是把**1**这个 ID 分配给机车，列车中其余车厢则分配一个随机选取的、大于**1**的 ID。

你的朋友往列车上接了两节新车厢，却忘了更新系统！现在，必须把列车`list`中的前两节车厢移到末尾，否则整个顺序都会乱掉。

更麻烦的是，你的朋友刚又发现了一个`list`，里面似乎装着缺失的车厢 ID。他只记得，一旦新车厢移好位置，这个`list`里的 ID 就应该紧跟在指定机车的后面。

如果你能帮他改正错误、把数据合并起来，Linus 会非常感激。

请实现一个函数 `fix_list_of_wagons()`，它接收两个包含车厢 ID 的`lists`。函数应把第一个`list`的前两项移到末尾，并把第二个`list`中的值插入到机车 ID（**1**）之后（也就是它的右侧）。然后函数应当`return`一个修改后的`list`。

```python
>>> fix_list_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
[1, 3, 17, 6, 15, 7, 4, 12, 6, 3, 13, 2, 5]
```

## 3. 添加缺失的停靠站

现在车厢数据都正确了，Linus 希望你更新系统的路线信息。在一条运输路线上，列车可能会在几个不同的车站停靠，装卸货物。每趟行程的这些中间交货点数量可能各不相同。你的朋友希望你把这些缺失或额外的交货信息补充到系统的路线`dict`中。

请实现一个函数 `add_missing_stops()`，它先接收一个路线`dict`，后面再跟可变数量的关键字实参。这些实参可以是一个包含一个或多个停靠站的`dict`，也可以是任意数量的 `stop_number=city` 关键字对。函数随后应当返回更新后的路线`dict`，其中多了一个`key`，按顺序存放所有新增停靠站的`list`。

```python
>>> add_missing_stops({"from": "New York", "to": "Miami"},
                      stop_1="Washington, DC", stop_2="Charlotte", stop_3="Atlanta",
                      stop_4="Jacksonville", stop_5="Orlando")

{"from": "New York", "to": "Miami", "stops": ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville", "Orlando"]}
```

## 4. 扩展路线信息

Linus 一直在做路线程序，他发现有些路线缺少一些重要细节。初始路线信息已经构建成一个`dict`，你的朋友希望你把这个`dict`里可能缺的内容补上。系统中每条路线需要的细节都略有不同，所以 Linus 很想要一个通用的解决方案。

请实现一个名为 `extend_route_information()` 的函数，它接收两个`dicts`。第一个`dict`包含列车路线往来的起点和终点城市。

第二个`dict`包含其他路线细节，比如列车速度、长度或温度。函数应当返回一个合并了所有路线信息的`dict`。

~~~~exercism/note
第二个`dict`可以包含与示例中不同的、或者更多的属性。
~~~~

```python
>>> extend_route_information({"from": "Berlin", "to": "Hamburg"}, {"length": "100", "speed": "50"})
{"from": "Berlin", "to": "Hamburg", "length": "100", "speed": "50"}
```

## 5. 整理车厢存放场

Linus 在查看车厢存放场时发现，车厢没有按正确的顺序存放。除了 ID 之外，每节车厢还有一种颜色，对应它所运载的货物类型。车厢在存放场里按网格存放，网格中每一列的车厢颜色都相同。

可是，物流系统显示，要存进存放场的车厢`lists`里，每一_行_都按颜色归在了一起。但要让存放网格正常工作，每一_行_都应该有三种不同的颜色，这样各_列_才能按颜色对齐。你的朋友希望你把这些车厢存放场`lists`理顺，好让车厢正确存放。

请实现一个名为 `fix_wagon_depot()` 的函数，它接收一个包含三项的`list`。这个`list`的每一项都是一个子数组（也就是“行”），里面包含三个`tuples`。每个`tuple`是一个 `(<wagon ID>, <wagon color>)` 对。

函数应当返回一个`list`，其中的三个“行”`lists`已重新排序，把车厢交换到了正确的位置。

```python
>>> fix_wagon_depot([
                    [(2, "red"), (4, "red"), (8, "red")],
                    [(5, "blue"), (9, "blue"), (13,"blue")],
                    [(3, "orange"), (7, "orange"), (11, "orange")],
                    ])

[
[(2, "red"), (5, "blue"), (3, "orange")],
[(4, "red"), (9, "blue"), (7, "orange")],
[(8, "red"), (13,"blue"), (11, "orange")]
]
```
