# 安装 Kotlin

除了 Exercism CLI 和你常用的文本编辑器之外，在 Kotlin 中练习 Exercism 练习还需要：

* **Java Development Kit**（JDK）：Kotlin 会编译成 Java 字节码；你需要安装 JDK，它同时包含 Java 运行时*和*开发工具（其中最常用的是 Java 编译器）；以及
* **Gradle**：一款专为基于 JVM 的项目打造的构建工具，支持 Kotlin。

选择你的操作系统：

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... 或者 ...

* 如果你不想使用包管理器，也可以[手动安装](#h-install-manually)。

此外，你还可以选择使用 [Java IDE](#h-java-ides)。

----

## Windows

打开一个管理员命令提示符。（如果你需要帮助来打开管理员提示符，请参见[在 Windows 8+ 中打开提升权限的提示符](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/)，或 [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)。）

1. 如果你还没有安装 Chocolatey，请现在安装：

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  安装 JDK：

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

我们建议关闭管理员命令提示符，然后打开一个新的命令提示符：练习 Exercism 练习并不需要管理员权限。

现在，你已经可以开始学习 Exercism 的 Kotlin 轨道了！

开始学习请参见“[运行测试](https://exercism.org/docs/tracks/kotlin/tests)”。

## macOS

下面是使用最常见的方法（Homebrew）进行安装的说明。如果你愿意，也可以[在 macOS 上不使用 Homebrew 进行安装](#h-installing-on-macos-without-homebrew)。

### 安装

1. 如果你还没有安装 [Homebrew](http://brew.sh)，请现在安装：

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Tap [Homebrew Cask](https://caskroom.github.io/)，这样就能安装像 JDK 这样的预编译二进制文件。

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  安装 JDK：

       ```
        $ brew install --cask adoptopenjdk11
       ```

现在，你已经可以开始学习 Exercism 的 Kotlin 轨道了！

开始学习请参见“[运行测试](https://exercism.org/docs/tracks/kotlin/tests)”。

## Linux

下面是使用你的发行版包管理器进行安装的说明。如果你愿意，也可以[在 Linux 上不使用包管理器进行安装](#h-installing-on-linux-without-a-package-manager)。

* [Debian](#h-debian)
* [其他 Linux 发行版](#h-other-linux-distributions)

### Debian

如果你使用的是 Debian 或其衍生版本（如 Ubuntu 或 Linux Mint），请使用 APT：

*（已在 Ubuntu 14、16 和 18 上验证）*

1. 安装 JDK：

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


现在，你已经可以开始学习 Exercism 的 Kotlin 轨道了！

开始学习请参见“[运行测试](https://exercism.org/docs/tracks/kotlin/tests)”。

----

### 其他 Linux 发行版

安装 JDK 11 的方法有很多，但最简单的方法之一是使用 SDKMAN，它能让你轻松安装 OpenJDK 11。请按以下步骤操作：

1. 安装 SDKMAN：
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    （如果这样不行，可以看看这里的说明：https://sdkman.io/install ）
1. 安装 openjdk11：
    ```
    $ sdk install java 11.0.2-open
    ```

开始学习请参见“[运行测试](https://exercism.org/docs/tracks/kotlin/tests)”。

### 在 Windows 上手动安装

*注意：这些说明面向有经验的 Windows 用户。如果你还不知道如何设置环境变量，或者不太熟悉管理目录结构，我们强烈建议你使用[上面](#h-windows)基于 Chocolatey 的安装方式。*

1. 安装 JDK：
   1. 从 [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) 下载“**OpenJDK 11 (LTS)**”（选择 **“Install JDK”**）。
   -  运行安装程序，全部使用默认设置。

现在，你已经可以开始学习 Exercism 的 Kotlin 轨道了！

开始学习请参见“[运行测试](https://exercism.org/docs/tracks/kotlin/tests)”。

## Java IDE

可用的 Java IDE 有很多，其中最流行的三个是：

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/)（下载“Community”版）
  - 它由 Kotlin 的作者开发，对这门语言的支持最好。
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/)（下载“Java SE”包）

此外还有[其他选择](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs)。
