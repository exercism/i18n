# 提示

## 1. 为员工打印工牌

- 在 Base R 中构造字符串时，[`sprintf`][ref-sprintf]函数很有用。
- 如果想用 Tidyverse 的方式，可以使用 `stringr` 库中的[`str_glue`][ref-str_glue]。

## 2. 为新员工打印工牌

- 根据[`is.na`][ref-isna]进行分支判断。

## 3. 为老板打印工牌

- 根据[`is.null`][ref-isnull]进行分支判断。

## 4. 计算没有 ID 的员工工资总额

- 你可以根据[`is.na`][ref-isna]进行[过滤][concept-vector-filtering]，再用[`sum`][ref-sum]求和。
- 如果没有员工缺少 ID，`salaries[is.na(ids)]`是什么？在 R 控制台里验证一下会很有用。如果你的电脑上没有安装 R，可以试试 [rdrr.io][web-rdrr] 这类在线控制台。
