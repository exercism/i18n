# 关于

JavaScript 是一种编程语言，它让网页能够动态变化。它是一门解释型语言，这意味着它不需要编译：解释器（例如网页浏览器）会解析代码，并把它转换成机器可以运行的代码，非常适合用来创建能在*任何电脑*上的任何浏览器里运行的动态网站！

JavaScript 不只能用在浏览器里。诸如 [Node.js][web-nodejs] 和 [Deno][web-deno] 这样的 JavaScript 运行时，让你可以在 Web 服务器上编写代码、启动服务并响应请求。
其他框架，例如 [Electron][web-electron]，则用 JavaScript 来编写适用于 Windows、Linux 和 macOS 的*跨平台应用*。
移动应用开发同样可行，可以借助 [React Native][web-react-native]、[Ionic][web-ionic] 等各种工具，而 [Expo][web-expo] 现在还能同时面向 Android、iOS 和 Web。

ECMAScript 是定义 JavaScript 的[标准][web-ecma]。

> “ECMAScript 已经发展成为世界上使用最广泛的通用编程语言之一。
> 它最为人熟知的身份是内嵌于网页浏览器中的语言，但也被广泛用于服务器和嵌入式应用。”
> 出自 [ECMA International Language Specification][web-ecma-2019]

从 2015 年的第 6 版（通常称为 ES2015 或 ES6）开始，该标准每年都会发布一个新版本。
第 6 版是一次重大更新，相比 ES5 带来了许多增强，其中包括模板字符串、富有表现力的箭头函数语法，以及更简洁的类定义语法。

但由于 JavaScript 的新语法和新特性*每年*都在涌现，[当前浏览器][web-compat-browsers] 和[最新的 Node.js][web-compat-node] 对它们的支持往往并不完整。
这并不意味着我们没法用。
[Babel][web-babel] 这样的工具为大多数特性提供了[转译][wiki-transpilation]，让我们可以*像写未来一样*写代码。

**注意**：本 track 通过 Babel 和 [@babel/preset-env][web-babel-preset-env] 插件支持最新的 ECMAScript 语法；该插件每次更新，都会启用新的实验性特性，与规范的发布保持同步。
它会自动适配*你本地的 Node.js* 安装环境。
这意味着你无需担心哪些特性受支持、哪些不受支持。
