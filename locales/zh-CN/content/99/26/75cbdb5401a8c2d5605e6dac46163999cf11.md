# 在本地解决练习

在本地机器上解决练习，你可以用自己熟悉的环境编写所有代码。

## 安装 CLI

要在本地机器上解决练习，首先需要按照[这些说明](https://exercism.org/cli-walkthrough)安装并配置 Exercism 命令行界面（CLI）。

### 配置

你需要告诉 CLI 你是谁，这样我们才能正确地下载内容。
你可以在[设置页面](/settings/api_cli)里找到自己的令牌。
然后就可以用下面的命令配置 CLI，把`<your-api-token>`替换成设置页面里的值：

```
exercism configure --token=<your-api-token>
```

## 下载练习

安装完成后，你可以使用下面的命令，通过 CLI 把练习下载到本地机器（把`<exercise-slug>`和`<track-slug>`换成相应的值）：

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

你不需要记住这条命令的结构，练习页面会列出该练习对应的命令。

下载命令执行完毕后，练习的文件就会下载到你的本地机器上。

## 解决练习

每道练习的目标都是写出一个能通过所有测试的实现。
这样的实现称为_解答_。

为了帮你做到这一点，每道练习都包含以下文件：

- README.md：说明你需要完成什么
- HELP.md：介绍如何运行测试，以及卡住时如何寻求帮助
- HINTS.md（可选）：帮助你解决练习的提示
- 测试文件：包含验证你的解答是否正确的测试
- 起始文件：提供一个起点，帮你开始编写实现

根据不同的轨道，可能还会有其他文件，是轨道工具运行测试所需要的。

## 提交你的解答

当你的解答通过所有测试后，就可以用下面的命令提交：

```
exercism submit <implementation_file_paths>
```

这条命令会把你的解答上传到 Exercism 网站，并打印解答页面的网址。

同样，你不需要记住这条命令，练习的`HELP.md`文件中会列出正确的命令。

你也可以提交一份不完整的解答，这样可以：

- 看看别人是怎么完成这道练习的
- 向导师寻求帮助

## CLI 的其他功能

### 查看所有命令

运行 help 子命令，获取所有可用命令的完整列表。

```bash
exercism help
```

### 排查问题

请确保你使用的是最新版本。

查看你当前的版本：

```bash
exercism version
```

对照最新发布版本检查一下，如果你的版本不是最新的，就升级。

升级之后，再核对一遍版本。如果版本没有变化，请确认你运行的是升级后的可执行文件。

```bash
which exercism
```

如果仍然有问题，请带着 troubleshoot 命令的输出，在 GitHub 上的 exercism/cli 仓库中提交问题。

```bash
exercism troubleshoot
```

你可以在[我们的问题追踪器](https://github.com/exercism/exercism/issues)上提交问题，社区会尽力帮助你。**在提交任何问题之前，请务必先完整走一遍[交互式引导](https://exercism.org/cli-walkthrough)。**
