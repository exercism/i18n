# 简介

字面量是直接在代码中使用的固定值。
它们在运行时不需要任何计算。
字面量有多种形式，可以高效地表示不同的数据类型。
最常见的字面量是数字类型的，但日期、时间和字符串类型也有对应的字面量运算符。
后面的概念会介绍如何使用用户定义的字面量运算符。

## 数字字面量

数字字面量包括十进制、八进制、十六进制和二进制表示。
这些基础知识已经在[数字概念][numbers-concept]中介绍过了。

像 `23`、`0x50f7ba11` 和 `0xba5eba11` 这样的表示，编译器都会理解为 `int`。
通用的 `int` 类型是有符号的，其范围（[取决于编译器和系统][in-depth-integers]）通常是 `-2'147'483'648` 到 `2'147'483'647`。
大多数情况下这已经足够，你不需要担心具体用哪种类型。

有些场景需要更大的范围，或者需要程序占用非常小的内存。
为了明确指定，可以直接在数字字面量上标注具体的整数类型。

当不需要负数，但想要更大的范围时，可以使用 `u` 或 `U` 后缀表示_无符号_整数。
如果需要更大的范围，可以用 `L` 甚至 `LL` 来表示 long 和 long long 类型。

~~~~exercism/caution
允许使用小写 `l`，但它容易与数字 `1` 混淆，因此不推荐。
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

浮点数在编译时通常会解析为 `double`。
这是一个不错的默认选择，需要更窄的 `float` 类型的场景，比上面无符号整数的例子还少见。

~~~~exercism/advanced
[C++23 标准][cpp23-literals]引入了更精细的控制，例如 `f128` 或 `F16` 这样的字面量。
有些编译器允许使用它们自己的字面量。
GCC 允许把 `d` 用作字面量，但标准中并没有这种用法，可能会影响跨平台兼容性。

[cpp23-literals]: https://en.cppreference.com/w/cpp/language/floating_literal

~~~~

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 字符字面量和字符串字面量

其他概念中已经用过单引号形式的字符字面量，比如 `'}'` 或 `'@'`。

在 C++ 中，`char` 仅限于前 128 个 [ascii 字符编码][ascii-code]。
要使用多个 ascii 字符，或者像 `‰` 这样的扩展 ascii 字符，甚至像 `麗` 和 `ẞ` 这样的 unicode 字符，就需要其他类型。
在之前的概念中，字符串字面量是用_双引号_引入的：`"一体どういう意味ですか。C++です"`。
这个日文短语的实际类型是 `const char (&)[46]`，即 C 风格字符串。

字符串字面量的使用默认并没有启用。
要使用 _string_ 字面量 `""s` 或 _string-view_ 字面量 `""sv`，用户必须通过相关的命名空间来指明：

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_ 可以看作是对 const 字符串的一个引用。
