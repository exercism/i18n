# 简介

和许多其他语言一样，Go 也有指针。
如果你刚接触指针，可能会觉得它们有点神秘，但一旦用惯了，就会发现它们相当简单。
指针是 Go 中至关重要的一部分，所以花点时间真正理解它们吧。

在深入细节之前，值得先理解指针的用途。
指针是一种与程序其他部分共享内存的方式，它之所以有用，主要有两个原因：

1. 当数据量很大时，在函数之间传递数据还要复制一份，效率极低。
   改为传递数据所存储的内存位置，就能大幅降低程序的资源占用。
2. 通过在函数之间传递指针，我们可以直接访问和修改那份唯一的数据副本，这意味着一个函数所做的修改，在函数结束后会立即被程序的其他部分看到。

## 变量与内存

假设我们有一个普通的整数变量`a`：

```go
var a int
```

当我们声明一个变量时，Go 必须找到内存中的一块地方来存储它的值。
这个过程对我们来说基本上是透明的：当我们需要取出那块内存里存的值时，只要用变量名引用它就可以了。

例如，当我们写`a + 2`时，实际上是在取出变量`a`所关联的内存中存储的值，并给它加上 2。

同样，当我们需要修改`a`那块内存中的值时，可以使用变量名进行赋值：

```go
a = 3
```

与`a`关联的那块内存现在将存储值`3`。

## 指针

变量让我们能够引用内存中的值，但有时知道变量所指向的**内存地址**会很有用。**指针**保存的就是这些值的内存地址。
声明指针类型的变量时，只需在底层类型前面加一个星号：

```go
var p *int // 'p' contains the memory address of an integer
```

这里我们声明了一个变量`p`，它的类型是“指向 int 的指针”（`*int`）。
这意味着`p`将保存一个整数的内存地址。
指针的零值是`nil`，因为`nil`指针不保存任何内存地址。

### 获取指向变量的指针

要找出变量值的内存地址，可以使用`&`运算符。
例如，如果我们想找到变量`a`的内存地址并把它存到指针`p`里，可以这样做：

```go
var a int
a = 2

var p *int
p = &a // the variable 'p' contains the memory address of 'a'
```

### 通过指针访问值（解引用）

有了指针之后，我们可能想知道该指针所代表的内存地址中存储的值。
可以使用`*`运算符做到这一点：

```go
var a int
a = 2

var p *int
p = &a // the variable 'p' contains the memory address of 'a'

var b int
b = *p // b == 2
```

`*p`这个操作会取出`p`中存储的内存地址处的值。
这个操作通常称为“解引用”。

我们也可以用解引用运算符给指针所引用的内存地址赋一个新值：

```go
var a int        // declare int variable 'a'
a = 2            // assign 'a' the value of 2

var pa *int
pa = &a          // 'pa' now contains to the memory address of 'a'
*pa = *pa + 2    // increment by 2 the value at memory address 'pa'

fmt.Println(a)   // Output: 4
                 // 'a' will have the new value that was changed via the pointer!
```

给`*pa`赋值会改变`pa`所保存的内存地址中存储的值。
由于`pa`保存的是`a`的内存地址，给`*pa`赋值实际上就是在改变`a`的值！

不过要小心：在解引用之前，一定要检查指针是否为`nil`。
解引用`nil`指针会让程序在运行时崩溃！

```go
var p *int // p is nil initially
fmt.Println(*p)
// panic: runtime error: invalid memory address or nil pointer dereference
```

### 指向结构体的指针

到目前为止，我们看到的都只是指向基本类型值的指针。
我们也可以为结构体创建指针：

```go
type Person struct {
    Name string
    Age  int
}

var peter Person
peter = Person{Name: "Peter", Age: 22}

var p *Person
p = &peter
```

我们也可以创建一个新的`Person`，并立即存储一个指向它的指针：

```go
var p *Person
p = &Person{Name: "Peter", Age: 22}
```

当我们有一个指向结构体的指针时，访问其中某个字段之前不需要先解引用这个指针：

```go
var p *Person
p = &Person{Name: "Peter", Age: 22}

fmt.Println(p.Name) // Output: "Peter"
                    // Go automatically dereferences 'p' to allow
                    // access to the 'Name' field
```

## 切片和映射本身就是指针

切片和映射是特殊的类型，因为它们的实现中已经包含指针。
这意味着大多数情况下，我们不需要为这些类型创建指针来共享它们值的内存地址。
假设我们有一个函数，用来把映射中某个键的值加一：

```go
func incrementPeterAge(m map[string]int) {
	m["Peter"] += 1
}
```

如果我们创建一个映射并调用这个函数，函数对映射所做的修改会在函数结束后保留下来。
这和使用指针时得到的行为类似，但请注意，在这个例子里我们完全没有使用取地址/解引用，也没有用到任何指针语法：

```go
ages := map[string]int{
  "Peter": 21
}
incrementPeterAge(ages)
fmt.Println(ages)
// Output: map[Peter:22]
// The changes the function 'incrementPeterAge' made to the map are visible after the function ends!
```

修改切片中已有的元素时也是如此。

不过，像`append`这样返回新切片的操作是个特例，它**可能不会**修改函数外部的切片。
这与切片的内部工作方式有关，本练习不会详细讲解，因为这属于更进阶的话题。
如果你真的好奇，可以在 [Go 博客：append 的机制][mechanics-of-append] 中读到更多内容。
