# 关于

.NET 基类库提供了 [`Regex`][regex] 类来处理正则表达式。

关于 C# 与其他正则表达式风格的比较，参见这篇[文章][regex-comparison]。

## 捕获组

需要考虑的一个方面是捕获组，它会返回与正则表达式模式各部分相匹配的文本片段。捕获组的用法需要慢慢适应。参见这份[文档][capture]。

注意，涉及捕获组 `(?<capture-name>pattern)` 时存在一个层级结构：

- 返回一组零个或多个匹配项（文本中每找到一个匹配就有一个）。
- 每个匹配项包含若干捕获组。
- 每个组包含若干捕获。

此外：

- `Match` 派生自 `Group`
- `Group` 派生自 `Capture`

注意事项：

- 最稳妥的做法是使用命名捕获。
- 捕获组在 `Groups` 集合中的顺序通常与它们在文本中出现的顺序一致。
- `Groups[0]` 似乎对应整个匹配项。
- 你想要的几乎肯定是 `Groups[<capture name>].Value`。如果存在单个捕获（`Caputures[0]` 除外），它们似乎是为诊断目的而设的。

## 正则表达式选项

熟悉一下 [`RegexOptions`][regex-options]。

除了常见的 `IgnoreCase` 选项外，还有 `MultiLine`（便于一次性处理多行文本）和 `IgnorePatternWhitespace`，后者与逐字字符串、字符串内插和注释搭配使用时可以非常富有表现力，如下例所示：

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

另一个值得关注的选项是 `RegexOptions.Compiled`，用于[编译][regex-compilation]正则表达式。
