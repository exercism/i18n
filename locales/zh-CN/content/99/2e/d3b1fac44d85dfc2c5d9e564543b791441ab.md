# 补充说明

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| -------- | ------------ | ------- | ---------------------------- |
| `$a0`    | 输入 | 整数 | N，三角形三边之和 |
| `$a1`    | 输入/输出 | 地址 | a 的值 |
| `$a2`    | 输入/输出 | 地址 | b 的值 |
| `$a3`    | 输入/输出 | 地址 | c 的值 |
| `$v0`    | 输出 | 整数 | 三元组的个数 |
| `$t0-9`  | 临时 | 任意 | 用于临时存储 |
