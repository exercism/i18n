# 说明

注意：本练习是 `need-for-speed` 练习的延续。

在本练习中，你将组织各种遥控车之间的比赛。每辆汽车都有自己的速度和耗电特性。

汽车一开始的电池是满的（100%）。
每次你使用遥控器驾驶汽车时，它会前进相当于车速的米数，同时剩余电量百分比会按其耗电量减少。

如果汽车的电池低于它的耗电百分比，你就不能再驾驶这辆汽车了。

遥控车有一个炫酷的 LED 显示屏，会显示两项信息：

- 它行驶的总距离，显示为：`"Driven <METERS> meters"`。
- 剩余电量，显示为：`"Battery at <PERCENTAGE>%"`。

每条赛道都有自己的距离。
测试汽车的方式，是检查它们能否在不耗尽电池的情况下跑完赛道。

## 1. 驾驶汽车

在`Car`上实现`Drive`方法，根据汽车的速度更新行驶的米数，并按照耗电量减少电池电量：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

注意：如果驾驶汽车会导致其电池低于 0，就不要尝试驾驶。

## 2. 显示行驶的距离

在`Car`上实现`DisplayDistance`方法，以`string`的形式返回 LED 显示屏上显示的距离：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. 显示电池电量百分比

在`Car`上实现`DisplayBattery`方法，以`string`的形式返回 LED 显示屏上显示的电池电量百分比：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. 检查遥控车能否跑完比赛

要跑完一场比赛，汽车必须能够行驶完赛道的距离。
也就是说，它不能在越过终点线之前耗尽电量。
实现`CanFinish`方法，该方法接收一个`trackDistance int`作为形参，如果汽车能跑完比赛就返回`true`，否则返回`false`：

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
