# 说明

你突然很想吃薄煎饼。
作为一个喜欢钻研技术的现代人，你用 JSON 格式写了一份薄煎饼食材的购物清单。
清单的结构如下：

```json
{
  "name": "name of shopping list",
  "ingredients": [ ...list of ingredients... ],
  "optional ingredients": [ ...list of ingredients... ]
}
```

每一种食材都用一个 JSON 对象表示，例如：

```json
{
  "item": "flour",
  "amount": {
    "quantity": 2,
    "unit": "cup"
  }
}
```

食材还有一个名为 `"substitute"` 的可选属性，它的值是一个字符串，表示可以用来替代它的另一种食材。

我们来看看如何用`jq`查看这份购物清单。

## 1. 提取购物清单的名称

写一个表达式，输出购物清单的 "name" 元素。

## 2. 数一数需要多少食材

只统计“必需”的食材。不要算上可选食材。

## 3. 需要多少糖？

写一个表达式，输出糖的用量。
只需要数字部分。

## 4. 映射可以被替换的食材

有些食材是可以替换的（如果没有食材 X，可以用 Y 代替）。
输出一个 JSON 对象，把推荐的食材映射到它的替代品。
映射中要包含可选食材。
