# 说明

在这个练习中，你将处理日志行。

每一行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志共有三个级别：

- `INFO`
- `WARNING`
- `ERROR`

你有几个任务，每个任务都会接收一行日志，并要求你对它做一些处理。

## 1. 获取某个子字符串之后的字符串

查看上个月的日志，你发现测试消息总是位于某个子字符串之后。想到不久之后可能还要提取这条测试消息，你决定创建一个辅助方法来帮你完成这项工作。

实现（静态）扩展方法 `LogAnalysis.SubstringAfter()`，它接收一个字符串分隔符，并返回该分隔符之后的子字符串。

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringAfter(": "); // => returns "File Deleted."
```

## 2. 获取两个子字符串之间的字符串

进一步检查后，你发现日志级别总是位于方括号（`[` 和 `]`）之间。同样，想到不久之后可能还要提取日志级别，你决定再创建一个辅助方法来帮你完成这项工作。

实现（静态）扩展方法 `LogAnalysis.SubstringBetween()`，它接收两个字符串分隔符，并返回位于这两个分隔符之间的子字符串。

```csharp
var log = "[INFO]: File Deleted.";
log.SubstringBetween("[", "]"); // => returns "INFO"
```

## 3. 解析日志中的消息

实现（静态）扩展方法 `LogAnalysis.Message()`，返回日志中包含的消息。

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.Message(); // => returns "Missing ; on line 20."
```

## 4. 解析日志中的日志级别

实现（静态）扩展方法 `LogAnalysis.LogLevel()`，返回日志的日志级别。

```csharp
var log = "[ERROR]: Missing ; on line 20.";
log.LogLevel(); // => returns "ERROR"
```
