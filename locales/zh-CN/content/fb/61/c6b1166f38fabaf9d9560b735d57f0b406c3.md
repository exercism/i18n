# Elm 语法基础 1

## 常量与函数

Elm 程序由定义和表达式组成。
在 Elm 中，一切要么是定义，要么是表达式。

常量值用`name = expression`定义。

```elm
five = 5

six = 3 + 3
```

函数用`name parameters... = expression`定义，形参之间只用空格分隔。

```elm
add number1 number2 = number1 + number2
```

调用函数本身也是一个表达式，做法是写出函数名，并为函数的每个形参依次传入实参，实参之间用空格分隔，和定义函数时一样。

```elm
five = add 2 3
```

可以用括号来指定表达式的求值顺序。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 缩进 / 有意义的空白

Elm 不使用大括号、圆括号或分号之类的语法标记来划定代码边界，而是使用空白和缩进。

- 模块、导入语句和顶层函数定义必须从最左侧那一列开始。
- 如果表达式被拆分成多行，属于该表达式的代码必须缩进到该表达式下方，且至少缩进一个空格。
- 表达式中归为一组的各部分，应当使用相同数量的空格缩进。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## 模块

Elm 中的每个文件都是一个模块，且必须在所有其他代码之前包含`module`语句。
模块名必须与其文件名一致，所以模块`Calculator`必须位于文件 Calculator.elm 中。
模块内定义的所有内容都只在该模块内可见，除非在`exposing`中列出，否则无法从模块外部访问。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 注释

注释是 Elm 文件中的一些文本，不会被当作代码解释。
它主要是给你自己和其他程序员阅读的。
单行注释有一种基于双连字符的轻量语法。
多行注释也可以通过`{-`和`-}`这对开始和结束分隔符来实现。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
