# 多余的分支语句

这份提交的解答不必要地使用了[分支语句][conditionals]。
把[默认参数][default argument]与 [str.format][str.format] 或 [f-strings][f-strings] 结合使用（_又称 “formatted string literals” 或 “interpolated strings”_），可以让代码更清晰、更简洁。

更多细节请见这篇关于 [Python 默认参数][python default arguments] 的文章。
博客文章 [Python 中的字符串格式化][string formatting in python] 也是了解 Python 字符串格式化选项的不错起点。
