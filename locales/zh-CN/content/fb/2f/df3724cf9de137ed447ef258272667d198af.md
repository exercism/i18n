代码库的公开接口应当仔细考量，因为每个公开函数都会增加长期维护成本，也让重构变得更困难。

在每一个 Exercism 练习中，公开接口都由测试套件定义。
如果一个函数会被测试，它就必须是公开的。
其他所有函数都应该是私有的，包括同名但参数个数不同的函数。

```elixir
# you defined the following public function

%{actual}

# make it private like this

%{expected}
```
注意，默认参数会改变函数的参数个数。

在编写库时，常常需要把函数设为公开，以便在各个模块之间使用。
为了把这类函数从文档中隐藏起来，库作者会在函数定义前加上`@doc false`，或者用`@moduledoc false`把整个模块隐藏起来。
