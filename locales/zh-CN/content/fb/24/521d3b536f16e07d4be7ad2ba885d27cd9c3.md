# 关于

过滤是指从原序列中复制出除某些元素之外的所有元素，从而由一个序列生成另一个序列的过程。
新序列中包含哪些元素，可以由谓词函数（即求值结果为布尔值的函数）决定，也可以通过判断元素是否与某个特定对象相等来决定。

## 按谓词移除

`remove-if`是一个函数，它接受一个谓词函数和一个序列作为实参，并返回一个只包含那些谓词求值为 false 的元素的序列。
换句话说，它会“移除”序列中所有让谓词求值为 true 的元素。不过要注意，这个函数不会修改原序列！
相反，它会返回一个新序列，其中不含这些元素。如果谓词对所有值都为 true，那么返回的就是一个空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 按谓词保留元素

还有一个`remove-if-not`函数，它与`remove-if`几乎一样，区别在于它会*保留*谓词求值为 true 的元素。

或者，也可以用`complement`把一个谓词变成它的“反面”。

```lisp
(remove-if #'evenp '(1 2 3 4 5 6))             ; => (1 3 5)
(remove-if-not #'oddp '(1 2 3 4 5 6))          ; => (1 3 5)
(remove-if (complement #'oddp) '(1 2 3 4 5 6)) ; => (1 3 5)
```

## 移除特定元素

如果想从序列中移除某个特定元素，可以使用`remove`，它接受要移除的元素和一个序列。
序列中所有不等于该元素的元素都会被返回。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```

用于判断是否相等的函数可以通过`:test`[关键字形参][concept-keyword-parameters]来指定。

注意，只要写一个测试对象是否与某个特定元素相等的谓词，就可以用`remove-if`来实现`remove`。

## 众多选项

这些函数各自还接受许多其他[关键字形参][concept-keyword-parameters]，让它们可以只作用于子序列、只应用特定次数，等等。完整细节请查看[Hyperspec 文档][hyperspec-remove]。


## 破坏性操作

除了`remove`、`remove-if`和`remove-if-not`之外，还有`delete`、`delete-if`和`delete-if-not`，它们的效果相同，只是可能会修改传给它们的序列。
