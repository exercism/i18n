# 说明补充

## 提示

这道练习处理的是文本数据。由于历史原因，Haskell 的`String`类型等同于`[Char]`，也就是由字符组成的数组。要更高效地处理文本数据，可以使用`Text`类型。

作为这道练习的可选扩展，你可以

- 阅读 Haskell 的[字符串类型](https://haskell-lang.org/tutorial/string-types)。
- 在 package.yaml 的依赖列表里加上`- text`。
- 按照[下面这种方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

        import qualified Data.Text as T
        import           Data.Text (Text)

- 现在你可以写例如`transform :: Map Int Text -> Map Char Int`，并用例如`T.toLower`来引用`Data.Text`中的组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档。

这部分完全是可选的。
