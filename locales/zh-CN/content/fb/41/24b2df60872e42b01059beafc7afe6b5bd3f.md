# 简介

就像指针可以指向 `int` 或其他基本数据类型一样，指针也可以指向函数。
函数指针可以用来把一个函数传给另一个函数。
作为实参值传给另一个函数的函数，称为一等函数。
接受一个或多个函数作为形参，或者返回一个函数的函数，称为高阶函数。

在下面的示例中，`is_even`和`is_odd`是一等函数。
高阶函数则是`test_number`。

```c
#include <stdio.h>
#include <stdbool.h>

bool is_even (int number) {
    return number & 1 != 1;
}

bool is_odd (int number) {
    return number & 1 == 1;
}

// this function takes any other function which takes a number and returns a bool
void test_number(bool (*func) (int), int number, char *text){
    printf(text, number, func(number)? "true": "false");
}

int main() {
    // prints Testing odd for 3 is true
    test_number(is_odd, 3,"Testing odd for %d is %s\n");
    // prints Testing even for 3 is false
    test_number(is_even, 3,"Testing even for %d is %s\n");
}
```
`test_number`第一个实参的函数签名`bool (*func) (int)`，与传入函数的签名相匹配。
`is_even`和`is_odd`都接受一个`int`形参，并返回一个`bool`。
在`(*func)`中，`func`表示要使用的函数的名称。
如果改用`(*fn)`，那么调用方式就会是这样：`printf(text, number, fn(number)? "true": "false");`。
为了满足函数指针形参的要求，我们在调用`test_number`时传入一个具有所期望签名的函数名。
由此可见，函数名指向该具名函数的地址。
