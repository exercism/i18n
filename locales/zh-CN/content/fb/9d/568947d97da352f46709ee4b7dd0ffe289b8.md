# 关于

Kotlin 由 JetBrains 设计和开发，这家公司也是 IntelliJ 的出品方。
它是一门运行在 JVM 上的语言，可以面向 6 及更高版本（包括 [Android 平台](https://blog.jetbrains.com/kotlin/2017/05/kotlin-on-android-now-official/)）。
JetBrains 想使用一门静态类型语言，既能消除 Java 的样板代码，又能提供现代的函数式范式，还要能与他们现有的代码库实现无缝的双向 Java 互操作。
JVM 上已经有 Groovy 和 Scala 等替代语言，但它们都不符合 JetBrains 的标准，于是他们自己创造了 Kotlin。

Kotlin 的语法与 Scala 和 Swift 相似，但吸收了 C# 和 Groovy 等其他语言中最优秀的功能。
Kotlin 在语言特性的取舍上采取了务实的做法，只提供已被证明对开发者有用的功能。
基于这一决定，他们只实现了 Scala 的一部分特性，希望这样能带来更易维护的代码，也让寻找“更好的 Java”的开发者更容易上手。

JetBrains 有一支专门的开发团队在开发 Kotlin，代码库托管在 [Github](https://github.com/JetBrains/kotlin) 上。
