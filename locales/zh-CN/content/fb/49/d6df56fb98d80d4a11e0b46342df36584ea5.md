# 详细介绍

Swift 中的 `guard` 语句用于从 Swift 函数中提前返回：当继续处理所必需的条件没有得到满足时，就可以用它返回。例如：

```swift
guard myValue = 0 else { return 0 }
let root = myValue.squareRoot()
```

这里，`guard` 会检查 `guard` 关键字后面的布尔表达式的求值结果是否为真。如果为真，处理就继续执行 guard 语句后面的代码（这里是 `let root = myValue.squareRoot()`）。否则，就会执行 else 子句中的代码。与 `if` 语句不同，`guard` 语句_必须_带有 else 子句；而且与 if-else 的 else 子句不同，guard 的 else 子句_必须_退出 guard 语句所在的作用域。也就是说，它必须使用 `return`、`continue`、`break` 这类控制转移语句，或者抛出一个错误，或者终止程序。

一个例子是 sinc 函数，它等于 sin(x)/x，其中 sinc(0) 被定义为 1，从而避免了除以 0 的问题。在 Swift 中，可以用 `guard` 这样写这个函数：

```swift
func sinc(_ x: Double) -> Double {
    guard x != 0 else { return 1 }
    return sin(x) / x
}

sinc(0)              // returns 1
sinc(Double.pi / 2)  // returns 0.6366197723675814
```
