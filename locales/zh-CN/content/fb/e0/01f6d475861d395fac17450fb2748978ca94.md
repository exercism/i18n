# 简介

在 Swift 中，不能使用整数对字符串进行索引（例如`string[3]`）。因为 Swift 字符串由可变长度的 Unicode 字符组成，所以要找到某个字符，就必须逐个经过排在它前面的字符。

要访问特定位置的字符，你必须计算一个类型为`String.Index`的索引。这些索引被称为*不透明索引*，因为它们的内部结构由 Swift 管理，而不能直接当作原始整数来操作：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
