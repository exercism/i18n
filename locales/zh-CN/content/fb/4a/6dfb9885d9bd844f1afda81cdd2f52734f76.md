# 说明

给定一个 0 到 999,999,999,999 之间的数字，用英文把它拼写出来。

## 第 1 步

处理 0 到 99 的基础情况。

如果程序的输入是 `22`，那么输出应该是 `'twenty-two'`。

如果传入的数字超出了允许范围，程序应当大声报错。

以下是一些不错的测试用例：

- 0
- 14
- 50
- 98
- -1
- 100

### 扩展

如果你用的是 Mac，可以调用 Mac OS X 的 `say` 程序把数字读出来。
如果你用的是 Linux 或 Windows，也许可以通过 `espeak` 命令使用 eSpeakNG。

## 第 2 步

实现把一个数字按千位拆分成若干块。

比如 `1234567890` 应该得到 1、234、567 和 890 这样的列表，而简单得多的 `1000` 应该只得到 1 和 0。

程序还必须报告任何超出范围的数值。

## 第 3 步

现在处理在这些块之间插入相应的量级词。

比如 `1234567890` 应该得到 `'1 billion 234 million 567 thousand 890'`。

程序还必须报告任何超出范围的数值。
到 “trillion” 为止即可。

## 第 4 步

把它们组合起来，得到纯粹的英文。

`12345` 应该得到 `twelve thousand three hundred forty-five`。

程序还必须报告任何超出范围的数值。
