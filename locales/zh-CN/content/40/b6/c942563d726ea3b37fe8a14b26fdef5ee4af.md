# 关于

Go 的爱好者（自称 _gophers_）这样形容 Go：它既有 Python、Ruby 这类动态语言的表现力，又有 C、C++ 这类编译型语言的性能。

这门语言是开源的，最初由 Google 的工程师发起。它采用 C 风格的语法，变量是静态类型的，通过垃圾回收管理内存，并会被编译成独立的可执行文件。

Go 以语言核心内置的[并发编程特性](https://golang.org/doc/effective_go.html#concurrency)著称，标准库中提供了[网络相关的包（比如一个 Web 服务器）](https://pkg.go.dev/net/http)，而且编译和执行速度都很快。它简洁、克制而一致的语言设计带来愉悦的使用体验，而丰富周到的工具链则解决了[一致的格式化](https://pkg.go.dev/cmd/gofmt)和[文档](https://pkg.go.dev/golang.org/x/tools/cmd/godoc)等传统问题。

Go 的主页是 [go.dev](https://go.dev/)，[tour.go.dev](https://tour.go.dev/) 上还有一份非常出色的交互式教程。
