# 关于

实现了 [`IEnumerable<T>`][IEnumerable] 接口的类型称为*可枚举*类型。
所有内置集合类型都实现了这个接口。

可枚举类型可以用 `foreach` 循环进行迭代：

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

要实现 `IEnumerable<T>`，类型必须实现一个方法：`IEnumerator<T> GetEnumerator()`。
如上所示，可枚举对象会把对集合的实际迭代工作交给 `IEnumerator<T>` 类型。
这个接口有一个属性和三个方法需要实现：

- `public T Current { get; }`：获取当前元素。
- `public bool MoveNext ();`：移动到下一个元素，如果成功移动到下一个元素就返回 `true`，否则返回 `false`（没有更多元素）。
- `public void Reset ();`：把枚举器重置到初始状态（第一个元素之前）。

[IEnumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
