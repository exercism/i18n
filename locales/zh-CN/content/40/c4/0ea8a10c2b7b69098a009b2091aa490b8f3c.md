# 简介

Python 中的[比较运算符][comparisons]（_也叫 Python 关系运算符_）会比较两个[操作数][operand]的_值_，并根据 `comparison` 条件是否成立，返回布尔值 `True` 或 `False`。

下表列出了 Python 中最常见的比较运算符：

| 运算符   | 运算                       | 说明                                                                      |
| -------- | -------------------------- | ------------------------------------------------------------------------- |
| `>`      | “大于”                     | 如果 `a` 的值**严格**大于 `b`，则 `a > b` 为 `True`                       |
| `<`      | “小于”                     | 如果 `a` 的值**严格**小于 `b`，则 `a < b` 为 `True`                       |
| `==`     | “等于”                     | 如果 `a` 的值**严格**等于 `b`，则 `a == b` 为 `True`                      |
| `>=`     | “大于或等于”               | 如果 `a > b`，或者 `a == b`，则 `a >= b` 为 `True`                        |
| `<=`     | “小于或等于”               | 如果 `a < b`，或者 `a == b`，则 `a <= b` 为 `True`                        |
| `!=`     | “不等于”                   | 如果 `a == b` 为 `False`，则 `a != b` 为 `True`                           |
| `is`     | “同一性”                   | 当且仅当 `a` 和 `b` 是同一个_对象_时，`a is b` 为 `True`                  |
| `is not` | “否定同一性”               | 当且仅当 `a` 和 `b` **不是**同一个_对象_时，`a is not b` 为 `True`        |
| `in`     | “包含测试”                 | 如果 `a` 是 `b` 的成员、子集或元素，则 `a in b` 为 `True`                 |
| `not in` | “否定的包含测试”           | 如果 `a` 不是 `b` 的成员、子集或元素，则 `a not in b` 为 `True`           |

它们的优先级都相同（高于[布尔运算][boolean operations]，但低于算术运算或位运算）。

## 不同数据类型之间的比较

默认情况下，类型不同的对象（数值类型除外）永远不会比较相等。
除非 `class` 定义了特殊方法来定制 `object` 的默认比较行为，否则同一个 `class` 的不同实例也_**不会**_比较相等。

数值类型（大部分情况下）是这条类型匹配规则的例外。
只要类型可以为了比较而被隐式转换，`integer` **可以**被视为等于 `float`（或者 [`octal`][octal] 等于 [`hexadecimal`][hex]）。

对于其他数值类型（[复数][complex numbers]、[十进制数][decimal numbers]、[分数][rational numbers]），比较运算符在“有意义”的地方有定义（即隐式转换不会改变结果），但如果底层对象无法为了比较而准确转换，就会抛出 `TypeError`。

## 比较对象同一性

`is` 和 `is not` 这两个运算符测试的是对象的[_同一性_][object identity]，而不是对象的_值_。
对象创建之后，其同一性永远不会改变，可以通过 [`id()`][id function] 函数获取。

当且仅当 `id(<apple>)` == `id(<orange>)` 时，`<apple> is <orange>` 求值为 `True`。
`<apple> is not <orange>`则得到相反的结果。

## 成员关系比较

`in` 和 `not in` 这两个运算符测试的是_成员关系_。
如果 `<fish>` 是 `<soup>` 的成员（即 `<fish>` 是 `<soup>` 的子集，或者包含在 `<soup>` 之中），`<fish> in <soup>` 求值为 `True`，否则求值为 `False`。
`<fish> not in <soup>` 返回否定结果，也就是 `<fish> in <soup>` 的_反面_。

对于字符串和 bytes 类型，当且仅当 `<name>` 是 `<fullname>` 的子串时，`<name> in <fullname>` 为 `True`。
