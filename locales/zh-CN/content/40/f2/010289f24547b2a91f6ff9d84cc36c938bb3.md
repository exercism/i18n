# 提示

## 通用

- [数字教程][numbers]。

## 1. 计算每秒的生产速率

- 可以通过[分支语句][if-statement]来确定成功率。
- Java 允许将乘法应用于两种不同的数字类型（例如`int`和`double`）。它会自动返回“更宽泛”的数据类型。
- 可以使用内置的[比较运算符][comparison-operators]和[相等运算符][comparison-operators]来比较数字。

## 2. 计算每秒生产的可用物品数量

- `int`可以自动转换为`double`，但反过来不行。原因在于`int`的精度比`double`低，因此必须进行舍入；而且`int`能表示的数值范围也比`double`小。要强制进行这种转换，可以使用[强制转换为 int][cast-int]。
