# 测试

在尝试运行测试之前，请先按照安装步骤正确设置好练习文件夹，也就是 `corepack yarn install` 和 Editor SDK 的配置。

用下面的命令运行测试：

```bash
$ corepack yarn test
```

## 被跳过的测试

在测试套件中，除第一个测试外，其余测试都被跳过了。

当某个测试通过后，你可以把 `xit` 改成 `it`，从而启用下一个测试。
此外，还可以用 `xdescribe` 把测试分组。
把这个改成 `describe` 就能启用整组测试。
最后，有些练习可能包含可选测试 `it.skip`。
去掉 `.skip` 就能运行这个可选测试。
