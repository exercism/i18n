# 安装

## 该选择哪个版本？

我们建议使用仍在积极支持的稳定版 PHP。
目前是**PHP 8.2、8.3 和 8.4**。
关于当前各版本及其支持时间线的详细信息，请查阅 [PHP 官方文档](https://www.php.net/supported-versions.php)。

## 安装 PHP

Linux 和 macOS 上的大多数包管理器都提供预编译好的软件包。
PHP 也可以从源代码下载并编译，见 [php.net/downloads.php](https://php.net/downloads.php) 或 [windows.php.net/download](https://windows.php.net/download)。

~~~~exercism/note
完成这些练习并不需要 nginx 或 Apache HTTP server 这类 Web 服务器。
~~~~

### Linux

不同的发行版有不同的做法。
根据你使用的包管理器，你可以运行

```shell
yum install php
```

或者

```shell
apt-get install php
```

更多说明请阅读 PHP 手册中的[在 Unix 系统上安装](https://www.php.net/manual/en/install.unix.php)。

### macOS

虽然 macOS 通常自带 PHP，但版本往往已经过时。
我们建议通过 [Homebrew](https://brew.sh/) 安装 PHP。
你可以按照[其主页](https://brew.sh/#install)上的说明安装 Homebrew。

要确认它是否安装成功，可以运行下面的命令，在撰写本文时它应输出 Homebrew `4.5.x`。

```shell
brew --version 
```

通过 Homebrew 安装 PHP

```shell
brew install php@8.4
```

这应该会显示当前已安装的 PHP 版本，至少为 `8.2.0`。

```shell
php -v
```

更多说明请阅读手册中的[在 macOS 上安装](https://www.php.net/manual/en/install.macosx.php)。

### Windows

Windows 的官方 PHP 二进制文件可以从 [windows.php.net/download](https://windows.php.net/download) 下载。

还有一些预打包的集成环境，例如 [WAMP](https://www.wampserver.com/en/)（Windows、Apache、MySQL、PHP）和 [XAMPP](https://www.apachefriends.org/de/index.html)。

更多说明请阅读手册中的[在 Windows 系统上安装](https://www.php.net/manual/en/install.windows.php)。

### Docker

如果你更喜欢容器化方案，可以从 [Docker Hub 下载官方 PHP 镜像](https://hub.docker.com/_/php)。
你还需要安装 [Docker](https://docs.docker.com/engine/install/)。

### 其他

如果你想使用其他操作系统，请参阅 [php.net/manual/en/install](https://www.php.net/manual/en/install.php) 上的说明。

## 安装 PHPUnit

目前尚不支持 PHPUnit 12！
~~~~

### 通过 PHP 归档文件（PHAR）

在 Exercism 练习中使用 PHPUnit 最简单的方式，是下载以 PHP 归档文件（PHAR）形式打包的发行版，这也是使用 PHPUnit 的推荐方式。
把 PHAR 放在你存放 `exercism` CLI 的位置，这样无论你在哪个目录都能运行 PHPUnit。

你可以下载以 PHP 归档文件形式发布的 PHPUnit 发行包：

```shell
wget -O phpunit.phar https://phar.phpunit.de/phpunit-11.phar
```

然后让下载的文件变为可执行：

```shell
chmod +x phpunit.phar
```

再把它移到你存放 `exercism` CLI 的同一位置，并将命令命名为 `phpunit`：

```shell
mv phpunit.phar ~/bin/phpunit
```

现在你可以在任何目录下运行 `phpunit`，如 [PHP track 测试文档](https://exercism.org/docs/tracks/php/tests) 所示：

```shell
phpunit --version
```

输出应该类似这样：

```text
PHPUnit 11.5.45 by Sebastian Bergmann and contributors.
```

你也可以按照官方的[安装 PHPUnit 说明](https://docs.phpunit.de/en/11.5/installation.html#installing-phpunit)来安装 PHPUnit。

### 通过 Composer

PHPUnit 11 也可以通过 [Composer](https://getcomposer.org) 安装。

#### 安装 Composer

按照你设备操作系统的[安装说明](https://getcomposer.org/doc/00-intro.md)安装 [Composer](https://getcomposer.org)。为了方便使用，我们建议进行全局安装。

#### 将 PHPUnit 添加为全局工具

使用下面的命令：

```shell
composer global require phpunit/phpunit ^11.5
```

请确保安装的是 11.5 或更高版本。
