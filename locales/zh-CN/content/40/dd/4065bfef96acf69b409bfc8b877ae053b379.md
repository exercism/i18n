# 说明

两位小提琴手正在排练一首二重奏。每个声部都是一个数组，保存每个小节里的音符数，而且两个声部的长度并不总是相同。

四个任务都要放在 `DUET_PRACTICE` 类中。

## 1. 他们一起演奏多少个小节？

只要两个声部都还有小节，他们就会一直一起演奏。

```sather
DUET_PRACTICE::bars_together(|4, 4, 8, 8|, |4, 4|)
-- => 2
```

## 2. 有多少个小节是一致的？

统计两个声部音符数相同的小节。只有两个声部都有的那些小节才可能一致。

```sather
DUET_PRACTICE::in_unison(|4, 4, 8|, |4, 2, 8|)
-- => 2
```

## 3. 哪个声部更忙？

统计第一个声部的音符数多于第二个声部的小节。

```sather
DUET_PRACTICE::louder_bars(|4, 8, 2|, |4, 2, 8|)
-- => 1
```

## 4. 给小节加权

越往后的小节越难，所以每个小节的分量等于它的位置：第一个小节算一次，第二个算两次，第三个算三次。把每个小节的音符数乘以它的序号，再把所有结果加起来。

```sather
DUET_PRACTICE::weighted_total(|4, 4, 8|)
-- => 36
```

也就是 1×4 + 2×4 + 3×8。小节从 1 开始编号，而不是从 0 开始。
