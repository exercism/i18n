# 简介

Factor 中的大部分数据都存在于*序列*中。数组（`{ … }`）、向量（`V{ … }`）和字符串都共享来自[`sequences`][sequences]的同一个[协议][sequence-protocol]。

```factor
{ 1 2 3 } length .    ! => 3
{ 1 2 3 } first .     ! => 1
{ 1 2 3 } last .      ! => 3
{ 1 2 3 4 5 } 3 head .! => { 1 2 3 }
```

聚合操作，`sum`、`count`、`any?`、`all?`，以及像`empty?`和`member?`这样的谓词，在所有序列类型上的工作方式都一致。无需修改原序列即可构建新序列：`prefix`、`suffix`、`append`、`unclip`、`unclip-last`。

当你需要从泛型操作中取回某个具体类型时，`>array`、`>vector`和`>string`（在[`arrays`][arrays]和对应的词汇表中）可以在序列类型之间转换。

[arrays]: https://docs.factorcode.org/content/vocab-arrays.html

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
[sequence-protocol]: https://docs.factorcode.org/content/article-sequence-protocol.html
