# 介绍

Clojure 的所有标准数据类型都是不可变的，因此它提供了*引用类型*，用来进行受控的修改。其中最简单、也最常用的就是 Atom。

用`atom`函数可以创建一个 Atom，并传入一个初始值：

```clojure
(def players (atom ()))
```

可以用`deref`或`@`简写来解引用 atom 的当前值：

```clojure
@players
;;=> ()
```

用`swap!`可以修改`players`这个 atom 的当前值，它会应用一个函数来更新值：

```clojure
(swap! players conj :player1)
;;=> (:player1)
```

`reset!`函数会替换 atom 的值，不考虑它当前的值：

```clojure
(reset! players ())
```
