# 补充说明

## 输出

在本练习中，你将实现一个动词，用来生成帕斯卡三角，生成到指定的行数为止。你的动词的输出可以采用以下两种格式之一：

  1. 由装箱列表组成的数组，其中每个列表代表帕斯卡三角的一行。
  1. 一个表格，其中数字右对齐，左侧的空位用 0 填充。

### 示例输出

以下是`pascal 3`的两种有效输出：

  - 由装箱列表组成的数组：
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - 带填充的表格：
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
