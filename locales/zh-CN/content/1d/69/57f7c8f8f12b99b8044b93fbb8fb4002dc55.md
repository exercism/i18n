# 关于

模式匹配是指根据一个值是否匹配给定的、可能很深的模式来进行分支的过程。在 Haxe 中，**模式匹配**通过 `switch` 表达式和各个 `case` 表达式完成。

看看这个数据结构：

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- 模式总是从上到下进行匹配。
- 最上面那个匹配输入值的模式，会执行它对应的表达式。
- `_`模式匹配任何内容，因此`case _:`等同于`default:`。

## 枚举匹配

枚举可以按其构造器自然地进行匹配：

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
