# 关于

关于 Java 字符串，要记住的关键一点是：它们是不可变对象，将文本表示为一串 Unicode 字符（字母、数字、标点等）。双引号用于定义`String`实例：

```java
String fruit = "Apple";
```

操作字符串可以使用[`String`][string-class]类的方法。由于字符串值一旦定义就无法更改，所有字符串操作方法都会返回一个新的字符串。

字符串由双引号（`"`）字符分隔。有些特殊字符需要使用反斜杠（`\`）字符进行转义。在 Java 中需要转义的字符：

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

最后，拼接字符串有很多种方法。最简单的是`+`运算符：

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

对于比简单拼接更复杂的字符串格式化，首选`String.format`方法。

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

其他可能的方法有：

- 使用[`StringBuilder`类][string-builder]
- 使用[`String.concat`方法][string-concat]
