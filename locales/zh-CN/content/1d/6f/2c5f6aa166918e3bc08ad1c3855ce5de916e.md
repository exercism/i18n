# 安装 Emacs

由于 Emacs Lisp（elisp）是 Emacs 的扩展语言，你需要先安装 [GNU Emacs](http://www.gnu.org/software/emacs/)。

建议安装最新版的 Emacs，不过 28.1 或更高版本应视为这些练习的目标实现版本。
如果你已经安装了 Emacs，可以用 `M-x emacs-version RET` 查看 Emacs 版本。

## 在 OS X 上
最简单的方法是访问 [Emacs For Mac OS X](http://emacsformacosx.com/) 并下载 dmg，它会以打包好的 OS X 应用形式安装 GNU Emacs。

也有其他选择，比如 Aquamacs（不推荐），或者如果你愿意，也可以通过 [Homebrew](https://formulae.brew.sh/formula/emacs) 安装。

## 在 Linux 上
在某些发行版上，Emacs 已经预先装好了，因为它是 GNU 的一部分。

### Ubuntu
目前推荐使用 [snap](https://snapcraft.io/emacs) 来安装最新版的 Emacs：

```
sudo snap install emacs --classic
```

如果你不想使用 snap，也可以通过 snap 安装 Emacs，但 Ubuntu 软件源里提供的版本往往已经过时。
如果你想通过 apt 安装更新版本的 Emacs，需要使用 [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) 或[从源码构建](https://www.emacswiki.org/emacs/BuildingEmacs)。

如果你不在意是不是最新版本，那只要这样就行了：

```
sudo apt-get install emacs
```

### Arch
Arch 通常自带最新版的 Emacs，所以运行：

```
sudo pacman -S emacs
```

就可以了。

### 其他发行版
查一下你的发行版当前提供哪个版本，然后按需使用包管理器或从源码构建。

### Windows
要在 Windows 上安装 Emacs，请前往就近的 [FTP 归档镜像](https://ftpmirror.gnu.org/emacs/windows)，下载安装程序（=emacs-XX.X-installer.exe=），然后启动它。
如果你想无需安装就使用 Emacs，可以下载符合 =emacs-XX.x.zip= 这个模式的文件，解压后启动 `bin\runemacs.exe`。

如果你使用的是 [MSYS2](https://www.msys2.org/)，可以用下面的命令安装 64 位版本的 Emacs：

```
pacman -S mingw-w64-x86_64-emacs
```

32 位版本则用：

```
pacman -S mingw-w64-i686-emacs
```
