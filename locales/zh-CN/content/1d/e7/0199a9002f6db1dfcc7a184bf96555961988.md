# 关于

## 条件语句

条件语句是决策语句，既可以执行副作用，也可以控制程序的执行流程。
条件语句包括 `if`、`if/else`、`switch`和 `ternary`语句。

条件语句用来针对某个值或者值之间的关系提出问题。
问题会得出一个布尔答案，但 `if`语句本身既可以返回任意值，也可以只是执行一个副作用。

## `if`语句

最简单的 `if`语句会求值一个表达式并执行一行代码。
被测试的表达式总是放在括号里。

它可以执行一个副作用

```c
if (count > 10)
    printf("count is greater than 10");
```

也可以改变执行的流程


```c
if (count > 10)
    return sum;
```

如果 `if`语句要执行不止一行，就必须把这些行放进大括号里

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

有些开发团队可能会规定，`if`语句一律使用大括号，即使只有一行。


## `if`和 `else`

`if`语句可以和 `else`搭配使用

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if`和 `else if`


`else`可以和另一个 `if`搭配，形成所谓的 `if-else-if ladder`。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


有时用 `switch`来表示 `if-else-if ladder`会更好。
和 `if`一样，被测试的表达式总是放在括号里。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

如果被测试的值和前面任何一个分支都不匹配，就会执行 `default`分支。

如果 `switch`的某个分支不返回值，通常要在每个分支末尾加一个 `break`来结束它，否则逻辑会“贯穿”到下一个分支。
有时贯穿是故意为之

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

如果贯穿是无意发生的，那就是一个 bug。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

当需要针对具体的值而不是值的范围进行判断时，`switch`会很有用。
它可能比 `if-else-if ladder`更快，因为编译器或许能以某些方式优化 `switch`语句，而这些方式对阶梯并不适用。
有时 `switch`看起来也比阶梯更易读。

## 三元（条件）运算符

三元运算符是一种由三部分组成的条件语句，常用来设置某个值。
要测试的表达式位于问号之前，不一定要放在括号里。
条件为真时返回的值在冒号前，为假时返回的值在冒号后。
返回的既可以是字面量，也可以是变量。

```c
int i = j > 5 ? 5: j;
```

三元运算符可以嵌套，以减少语法上的杂乱。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## 浮点数值的条件比较

由于浮点数的实现方式，一个简单的数学运算就可能产生舍入误差，以致相等性判断得不到预期的结果。

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

可以使用一个称为 `epsilon`的容差值来确定一个范围：只要某个值落在这个范围内，它与另一个值相比较时就可以视为相等。
有些平台为 float 和 double 的 epsilon 内置了常量。
想了解更多，请参阅你所使用编译器的文档。
计算 epsilon 可能相当复杂，而且会因平台而异，甚至因具体的机器而异。
下面是一个使用简单比较的示例程序。

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

在比较 `float`或 `double`是否相等时要当心！
