# 迭代器组合

一个循环可以调用多个迭代器。每一轮中，每个迭代器都会被索取它的下一个值，它们一起向前推进。

```sather
   loop
      first ::= violin_one.elt!;
      second ::= violin_two.elt!;
      #OUT + first + " against " + second + "\n";
   end;
```

这样就会并排遍历两个数组：第一个元素配第一个元素，第二个配第二个。

## 让所有人都感到意外的那条规则

**只要迭代器中*第一个*耗尽，循环就会结束。**

不是在最后一个耗尽时，也不是在全部耗尽时，而是第一个。

所以，如果`violin_one`里有四个小节，而`violin_two`里有两个，上面的循环只会运行**两次**。第一部分的第三和第四小节根本不会被看到，因为那时第二部分已经没有东西可以提供了。

这通常正是我们想要的：只有在成对存在时，配对才有意义。不过这一点必须事先知道，而不是自己偶然发现。

## 一边循环一边计数

一个永远不会耗尽的迭代器之所以有用，正是因为这条规则。`up!`会一直计数下去：

```sather
1.up!        -- 1, 2, 3, 4, ... and never ends
```

单独使用时，它会永远循环下去。与一个会结束的迭代器配对时，它就能给这些值编号，而不必决定要数到多少：

```sather
   loop
      number ::= 1.up!;
      bar ::= part.elt!;
      #OUT + "Bar " + number + ": " + bar + "\n";
   end;
```

`part.elt!`结束循环，`1.up!`提供编号。两者都不需要知道这部分有多长。

## 顺序无关紧要

每一轮中，所有迭代器都会被索取一次，所以哪个写在前面没有区别。真正重要的是，每个迭代器都恰好被索取一次：在一轮里写两次`part.elt!`，拿到的是两个值，而不是一个。
