# 关于

C# 是一门静态类型语言，也就是说，一切在编译时都有类型。为[变量][variable]选择名字称为定义变量。变量定义好之后，设置或更新它的值称为变量赋值。定义变量时，既可以显式指定它的类型，也可以使用 [`var` 关键字][var]，让 C# 编译器根据所赋的值推断它的类型。使用 `var` 的做法称为_类型推断_。

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

变量的值可以用 [`=` 运算符][assignment]来赋值和更新。变量一旦定义，它的类型就永远不能改变。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是一门面向对象的语言，它要求所有[函数][function]都必须定义在_类_中，而类是用 [`class` 关键字][classes]定义的。对象（或称_实例_）通过 `new` 关键字创建。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

类里面的函数称为_方法_。每个[方法][methods]可以有零个或多个形参。所有形参都必须显式声明类型，形参没有类型推断。同样，返回类型也必须显式写出。方法用 [`return` 关键字][return]返回值。要让其他文件中的代码能够调用某个方法，必须加上 `public` 访问修饰符。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

调用方法时，要在实例上使用点号（`.`）语法，指明要调用的方法名，并为方法的每个形参传入实参。实参也可以选择性地写出对应形参的名字。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

如果要调用的方法与调用它的方法定义在同一个类中，可以省略类名。

如果某个方法不使用任何对象_状态_，就可以用 `static` 修饰符把它设为_静态_方法。静态方法同样使用点号（`.`）语法调用，但要在类本身上调用，而不是在类的实例上。

如果一个类只包含静态方法，这个类本身也可以用 `static` 修饰符设为静态。这表达了该类的意图。

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

C# 中的作用域是用 `{` 和 `}` 这两个字符界定的。

C# 支持两种[注释][comments]。单行注释以 `//` 开头，多行注释则写在 `/*` 和 `*/` 之间。

整数值由一个或多个（连续的）数字组成，支持[默认的数学运算符][operators]。

变量名[必须遵循一些规则][identifier-names]，例如必须以字母或下划线开头，并且[应遵循 C# 的命名约定][naming-guidelines]。如果变量名与保留的 [C# 关键字][csharp-keywords]冲突，就必须用 `@` 转义。不推荐使用这种写法，但在特殊情况下可能会遇到，例如：`var @this`、`var @class` 或 `var @var`。

有几个概念对 C# 这样的 C 系语言来说极其基础，几乎在任何一段稍微复杂一点的代码里都会自然出现。它们就是[可变性][mutation]和[作用域][scope]。可变性指的是变量的值可以在程序运行期间发生改变。作用域指的是与某个名字（程序元素的名字）相关联的值只能在该名字被定义所在的代码“区域”内访问。C# 中主要的代码区域是_类/结构体_和_函数_（通常是方法），但也可以包括循环体和其他结构。
