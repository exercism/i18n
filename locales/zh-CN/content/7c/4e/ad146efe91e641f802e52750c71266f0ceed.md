# 维护者须知

## 生成测试：`bin/generate_tests.py`

测试文件由 [exercism/problem-specifications](https://github.com/exercism/problem-specifications) 中的规范数据生成，使用的是每个练习里`.meta/template.j2`存放的 Jinja 模板。

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

脚本从 configlet 的缓存（`~/.cache/exercism/configlet/problem-specifications`，由`bin/configlet sync`填充）中读取 problem-specifications，或者从名为`problem-specifications`的上级目录中读取。
只有包含在`.meta/tests.toml`中的用例才会被生成。

Fortran 字符串字面量不能包含`\n`和`\t`这类转义字符。
`escape_quote_whitespace`模板过滤器会把它们改写成
`" // NEWLINE // "`、`" // TAB // "`和`" // CARRIAGE_RETURN // "`，
所以模板必须声明这些常量（参见`exercises/practice/bob/.meta/template.j2`）。

### 前提条件

- 可用的 CMake 和 Fortran 编译器
- Python 3.12+，并装有`jinja2`
- git

### 添加新练习的工作流

以`bob`为例：

- 新建一个分支，例如`git checkout -b exercise-bob`
- 运行`bin/add-exercise bob`（需要`jq`和`curl`）。它会：
  - 获取 configlet 并运行`configlet create`，这一步会把练习加入`config.json`，并从 problem-specifications 同步它的文档、元数据和`tests.toml`
  - 用`bin/reorder-exercises`对`config.json`排序
  - 把`exercises/shared/CMakeLists.txt`复制到练习目录
  - 写出一份占位解答、一份占位`.meta/example.f90`，以及一个起步用的`.meta/template.j2`（来自`exercises/shared/template.j2`）

  除非你传入`-a <username>`，否则它会提示你输入 GitHub 用户名；除非你传入`-d <difficulty>`，否则难度会被设为 1。

- 编辑`.meta/template.j2`，让每个用例都用正确的输入调用正确的函数，然后生成测试：

  ```bash
  bin/generate_tests.py bob
  ```

- 在`.meta/example.f90`中写出能正常运行的解答。把学生文件（例如`bob.f90`）替换成测试所调用的函数或子程序的骨架，帮助学生起步
- 确保所有测试都通过，在代码仓库根目录执行完整构建：

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- 运行`bin/reorder-exercises`和`bin/configlet lint`
- 如果一切通过，就带上你的改动发起一个拉取请求

### 修改`CMakeLists.txt`

修改 cmake 文件时，要更新`exercises/shared/`里的主副本，并用`bin/update-cmake-files`把它复制到所有练习目录。
