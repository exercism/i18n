# 说明

Lisp 外星人 Leslie 要去购物了。有一份购物清单非常重要。你需要往上面添加物品，也要从上面移除物品。

当然，区区纸笔可满足不了 Lisp 外星人。要知道，“list”几乎就是“Lisp”这个词的大半！总得写几个函数来帮忙管理购物清单。

你能帮 Leslie 管理这份购物清单吗？

## 1. 创建一个新列表

首先，Leslie 需要创建一个空列表。一个叫`new-list`的函数就再合适不过了。

```lisp
(new-list) ; => ()
```

哦不……Leslie 心里已经想好了几样东西，所以还需要一个接收 3 个物品的函数（好在 Leslie 只会创建 3 个物品的列表。不多不少！），用它创建一份装着这些东西的新购物清单。写一个函数`list-of-things`，它接收 3 个物品，返回由这些物品组成的列表。

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. 往列表里添加东西。

去商店之前，Leslie 会先看看食品储藏室里有什么，确认自己还缺什么。请帮他们写一个函数`add-to-list`，它会把物品添加到列表的开头。

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. 列表上接下来要买的是什么？

购物时，Leslie 想知道接下来该找什么。他们还喜欢往列表后面瞄一眼，看看第 2 个、第 3 个，甚至第 23 个物品（那是他们的幸运数字）。

- `first-thing`会求值为列表上的第 1 个物品
- `second-thing`会求值为第 2 个物品
- `third-thing`会求值为第 3 个物品
- `twenty-third-thing`会求值为第 23 个物品

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. 从列表中移除物品

Leslie 想找到列表中的第 1 个物品，并把它从货架上取下来。请帮他们写一个函数`remove-first-item`，它的求值结果是输入列表中除第 1 个物品之外的所有物品组成的列表。

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. 用更小的列表拼出更大的列表

Leslie 发现自己不小心做了 2 份购物清单，而不是 1 份！写一个函数`list-append`，它返回的列表中，先是第一个列表里的元素，接着是第二个列表里的元素。

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. 到底有多长？

Leslie 开始担心这趟购物会花上不少时间。这个列表上到底有多少物品？写一个函数`just-how-long`，告诉他们列表有多长。

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
