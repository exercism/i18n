# 关于

## 可选类型

Swift 使用[_可选类型_][optionals]来让程序员表示某个值可能不存在。可选类型是一种类型，它要么持有一个值，要么是 [`nil`][nil]，而 `nil` 表示值不存在。使用可选类型时，程序必须先检查值是否确实存在，然后才能解包并使用它。

只要在类型名末尾加上一个`?`，任何类型都能变成可选类型。因此，可选整数的类型是 `Int?`，可选字符串的类型是 `String?`。定义可选类型的常量或变量并给它们赋值，与处理非可选类型的值完全一样。

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

只要给可选类型的变量赋上特殊值 `nil`，就相当于把“值不存在”赋给了它。`nil` 可以用在任何可选类型上，但赋给两个不同类型可选类型的 `nil` 并不属于同一类型，既不能互换，甚至不能比较。

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

还要注意，虽然 `nil` 可以赋给任何可选类型，却不能赋给非可选类型，哪怕这个非可选类型实际上并不持有 `nil`。而期待非可选类型的方法，在不解包的情况下就不能接收可选类型的值。

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## 使用可选类型

可选类型与它的基础类型并不是同一种类型，所以两者的用法并不相同。例如：`Int("123") + 1` 会导致编译器报错“Value of optional type 'Int?' must be unwrapped to a value of type 'Int'”。这是因为 `Int("123")` 返回的是可选类型 `Int?`，而不是 `Int`，因为如果字符串无法转换成整数，结果就是 `nil`。想从这次转换中取出 `Int`，就必须先把它“解包”。

在 Swift 中，最常见的做法是使用 `if-let` 和 `guard-let` 结构进行[_可选绑定_][optional-binding]：它们会检查 `nil`，如果值存在，就沿一条代码路径走下去，并把解包后的值绑定到一个给定的名字上；如果发现是 `nil`，则走另一条代码路径。

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

值得注意的是，`safeNum` 这个变量的类型是 `Int`，而不是 `Int?`。在下面的例子中，`num` 的类型是 `Int?`，`safeNum` 的类型是 `Int`。

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

这种_可选绑定_很重要，因为它会把可选类型从值上解包（也就是“移除”）掉，让这个值能像非可选值一样使用。如果你只是用条件判断检查这个值是不是 `nil`，那么值的类型仍然是可选类型：

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

在需要提前返回的场景下，也可以使用 `guard-let`：

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## 比较可选类型

注意，即使两个可选值的基础类型可以用标准的比较运算符来比较，可选值本身也不能比较。它们只能做相等性检查。如果两个可选值都是 `nil`，或者它们所包裹的值在各自的基础类型下相等，那么这两个可选值就相等。

不过，也可以编写代码，对两个可选值进行自定义比较。下面是一个 `switch` 语句的例子：只有当两个可选值都非 nil，且第一个值小于第二个值时，它才会返回 `true`。为此，它使用了 _可选模式_ `varName?`，这种模式只匹配非 nil 的可选值，并把可选值里面的值绑定到名字 `varName` 上。

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
