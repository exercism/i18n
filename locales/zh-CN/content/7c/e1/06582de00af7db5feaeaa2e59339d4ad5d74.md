# 简介

`if/else`表达式可以用来执行条件逻辑，不过 Haskell 还有一种更强大的方式：[模式匹配][pattern-matching]。借助模式匹配，可以用一个或多个_模式_来检验一个值。这类模式的一个例子是_常量模式_，它把一个值与一个常量进行匹配（例如`1`或`"hello"`）。

定义函数时，可以为不同的模式分别定义函数体。这样写出的代码干净、简单、易读。你可以对任何数据类型做模式匹配，数字、字符、数组、元组等等都行。

例如，一个接收整数（`Int`）并让它离 _0_ 更近 _1_ 的简单函数可以这样写：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

模式匹配与其他模式搭配使用时才真正显出身手，比如_变量模式_：

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

上面的例子把 _0_ 之外的所有输入都一视同仁，对负数会得出错误的结果。这可以用条件模式来解决，也就是所谓的_守卫_，用`|`符号表示：

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

在上面的例子里，并非所有可能的输入都有匹配的模式。编译器会检测到这一点并给出警告。这是 Haskell 一个非常有用的特性，它有助于确保覆盖所有可能的路径，避免运行时错误。这被称为_穷尽性检查_。要消除这个警告，就必须处理所有情况。在_守卫_中，可以使用表达式`otherwise`作为`True`的语法糖，来捕获所有剩余的模式。

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

模式匹配会自上而下地把值与每个模式逐一比对，直到找到匹配的模式，并执行与该模式相关的逻辑。**模式的顺序很重要！**
