# 关于

[符号][symbols]是具名的标识符，可以用来引用某个值。符号通过符号字面量创建，方式是在名称前加上 `:` 字符，例如 `:foo`。它们也可以用引号书写，例如 `:"foo"`，这样名称中就可以包含空格。

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

符号在这门语言中随处可见，包括用作具名元组的键，以及表示方法和变量名。

## Crystal 中的符号

Crystal 中的符号与 Ruby 差别很大。在 Crystal 中，符号是一种常量，因此在编译期就被赋值。这意味着符号无法动态创建，而在 Ruby 中这是可以做到的。

Crystal 中的符号以 `Int32` 表示，因此非常高效。

## 转换

符号可以转换为字符串，反过来则不行。这是因为符号在编译期创建，而字符串在运行时创建。

```crystal
:foo.to_s # => "foo"
```
