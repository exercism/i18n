# 构造函数属性提升

在声明了很多属性的类中，如果分别声明类、属性和用来设置这些属性的构造函数，就会产生重复。
使用构造函数属性提升，可以减少重复。

```php
<?php

class Book
{
    private string $isbn;
    private string $doi;
    private string $title;

    public function __construct(string $isbn, string, $doi, string $title)
    {
        $this->isbn = $isbn;
        $this->doi = $doi;
        $this->title = $title;
    }
}

// Using constructor property promotion
class Book
{
    public function __construct(
        private string $isbn,
        private string $doi,
        private string $title
    ) {
    }
}
