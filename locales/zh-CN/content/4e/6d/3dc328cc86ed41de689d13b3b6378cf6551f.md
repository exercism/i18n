# 简介

## _if-then_ 语句

Java 中最基础的控制流语句是 _if-then_ 语句。
这种语句用于在特定条件为`true`时才执行某段代码。
_if-then_ 语句通过`if`子句来定义：

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

在上面的例子中，如果汽车没有燃料，调用`Car.drive`方法将什么也不做。

## _if-then-else_ 语句

当`if`子句中的条件求值为`false`时，_if-then-else_ 语句提供了另一条执行路径。
这条替代执行路径跟在`if`子句之后，通过`else`子句来定义：

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，如果汽车没有燃料，调用`Car.drive`方法会调用另一个方法来让汽车停下。

_if-then-else_ 语句还可以通过`else if`子句来支持多个条件：

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

在上面的例子中，当燃料小于等于`5`时驾驶汽车，汽车会行驶，但会点亮燃料指示灯。
当燃料降到`0`时，汽车就会停止行驶。
