# 说明

你的任务是解析 Smart Game Format（SGF）字符串，并返回表示这局棋的树形数据结构。

一个 SGF 字符串表示一棵由节点组成的树。整棵树都包在括号`()`里。树中的每个节点用分号`;`表示，后面跟着一串属性。一个属性由一个大写标识符（例如`AB`）和后面的一个或多个值组成，值放在方括号`[]`里。

例如，字符串`(;FF[4]C[root])`表示一棵只有一个根节点的树。这个节点有两个属性：
- 属性`FF`，值为`4`
- 属性`C`，值为`root`

**变体（树与分支）**
SGF 通过嵌套树来支持棋局的变体。一棵树可以有多个子树，子树同样包在括号里。
例如，`(;A[B](;C[D])(;E[F]))`表示一个带有属性`A`的根节点，它有两个子分支：
1. 一个带有属性`C`、值为`D`的节点
2. 一个带有属性`E`、值为`F`的节点

**格式与转义**
方括号里的值可以包含转义字符。反斜杠`\`后面跟任意一个字符，表示的就是那个字符本身（例如，`\]`应当解析成字面的`]`）。另外，如果换行符前面有一个反斜杠，它就起到续行的作用，应当从值里去掉。值里其他的换行符都应保留。

**错误处理**
遇到无效的 SGF 字符串时，你必须抛出错误。下面是一些无效 SGF 的例子：
- 树不是以括号`()`开头。
- 节点不是以分号`;`开头。
- 属性标识符不是全部由大写字母组成。
- 缺少方括号，或者圆括号不匹配。

### 数据结构

你的解析函数应当返回这棵树的表示形式。一种常见的做法是把每棵树表示成一个带两个字段的对象：
- `properties`：一个对象（或 Map），键是属性标识符（字符串），值是字符串数组（因为一个属性可以有多个值）。
- `children`：一个数组，里面放着各个子树。


示例：

输入：`(;FF[4]C[root])`
输出：`{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

输入：`(;A[B](;C[D])(;E[F]))`
输出：`{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
