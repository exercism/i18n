# 说明

Lisp 外星人 Lilly 又回来啦，这次要做更多的菜！这一次，他们要制作 Lisp 外星千层面，这道菜和人类的千层面并非完全不同。

Lilly 需要有人帮忙写几个函数，用来算出千层面的烹饪时间。每个函数都要有良好的文档，这样 Lilly 才不会忘记每个函数是做什么的。

你能帮 Lilly 写几个函数，帮他们算出千层面的烹饪时间吗？

## 1. 定义以分钟为单位的预期烤箱时间

定义 `expected-time-in-oven` 函数，它不接收任何形参，返回千层面应该在烤箱里待多少分钟。按照 Lisp 外星人的传统（就像 Lilly 的“父母单位”以前做饭那样），以分钟为单位的预期烤箱时间是 337：

```lisp
(expected-time-in-oven) ;; => 337
```

## 2. 计算以分钟为单位的剩余烤箱时间

定义 `remaining-minutes-in-oven` 函数，它接收千层面实际已在烤箱里待的分钟数作为形参，并根据上一个任务中得到的、以分钟为单位的预期烤箱时间，返回千层面还需要在烤箱里待多少分钟。

```lisp
(remaining-minutes-in-oven 100) ;; => 237
```

## 3. 计算以分钟为单位的准备时间

定义 `preparation-time-in-minutes` 函数，它接收 Lilly 给千层面加的层数作为形参，并返回 Lilly 准备千层面花了多少分钟，假设每一层需要 19 分钟来准备。

```lisp
(preparation-time-in-minutes 3) ;; => 57
```

## 4. 计算以分钟为单位的已用时间

定义 `elapsed-time-in-minutes` 函数，它接收两个形参：第一个形参是 Lilly 给千层面加的层数，第二个形参是千层面已在烤箱里待的分钟数。这个函数应该返回 Lilly 烹饪千层面所花的分钟数，也就是准备时间（分钟）与千层面此刻已在烤箱里待的分钟数之和。

```lisp
(elapsed-time-in-minutes 3 100) ;; => 157
```
