# 说明

在这个练习里，你要为一个朋友正在开发的新 RPG 游戏实现任务逻辑。游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛又忠诚的宠物狗。不幸的是，灾难降临了：她最好的朋友在森林里采摘浆果时被绑架了。Annalyn 要找到并救出她最好的朋友，这次冒险她可以选择带上自己的狗，也可以不带。

沿着最好朋友的踪迹追寻了一段时间后，她找到了关押她最好朋友的营地。原来绑架者有 2 个：一位强悍的骑士和一名狡猾的弓箭手。

找到绑架者之后，Annalyn 开始考虑自己可以采取下列哪些行动：

- 快速攻击：如果骑士正在睡觉，就可以发动快速攻击，因为他穿上盔甲需要时间，这段时间他会毫无防备。
- 侦察：只要他们中至少有 1 个人醒着，就可以对他们进行侦察。否则，侦察就是浪费时间。
- 向囚犯发信号：如果囚犯醒着而弓箭手在睡觉，就可以用鸟叫声给囚犯发信号，因为弓箭手受过识别鸟类信号的训练，可能会截获这条消息。
- _释放囚犯_：Annalyn 可以试着潜入营地救出囚犯。
  这件事风险很大，只有在以下 2 种情况之一才能成功：
  - 如果 Annalyn 带着她的宠物狗，那么在弓箭手睡着时她就能救出囚犯。
    骑士怕狗，弓箭手也来不及准备好，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没带狗，那她和囚犯就必须非常小心谨慎！
    如果囚犯醒着，而骑士和弓箭手都在睡觉，Annalyn 就能救出囚犯；但如果囚犯在睡觉，那就救不了：Annalyn 突然出现会吓到囚犯，结果把骑士和弓箭手都吵醒。

你有 4 项任务：根据森林里这 3 个角色的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可用的逻辑。

## 1. 检查“快速攻击”行动是否可行

实现一个名为`canExecuteFastAttack`的函数，它接收一个布尔值，表示骑士是否醒着。如果根据该角色的状态，“快速攻击”行动可用，这个函数就返回`true`，否则返回`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. 检查“侦察”行动是否可行

实现一个名为`canSpy`的函数，它接收 3 个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。如果根据这些角色的状态，“侦察”行动可用，这个函数就返回`true`，否则返回`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. 检查“向囚犯发信号”行动是否可行

实现一个名为`canSignalPrisoner`的函数，它接收 2 个布尔值，分别表示弓箭手和囚犯是否醒着。如果根据这些角色的状态，“向囚犯发信号”行动可用，这个函数就返回`true`，否则返回`false`：

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. 检查“释放囚犯”行动是否可行

实现一个名为`canFreePrisoner`的函数，它接收 4 个布尔值。前三个参数分别表示骑士、弓箭手和囚犯是否醒着。最后一个参数表示 Annalyn 的宠物狗是否在场。如果根据这些角色的状态以及 Annalyn 的宠物狗是否在场，“释放囚犯”行动可用，这个函数就返回`true`，否则返回`false`：

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
