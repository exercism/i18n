# 简介

当一个类型能通过_类型参数_容纳任意类型的值时，它就是_泛型类型_。

例如，这个`Box`类型有一个类型参数`a`（用小写字母书写）。

```gleam
pub type Box(a) {
  Box(a)
}
```

类型参数`a`是任意类型的占位符，所以`Box`可以配合字符串、整数或任何其他类型使用。

```gleam
Box("Hello, Joe!") // The type is Box(String)

Box(42) // The type is Box(Int)
```

一个类型可以有多个类型参数，用逗号把它们分隔开即可。

```gleam
pub type Pair(a, b) {
  Pair(a, b)
}
```

## 泛型函数

类型参数也可以用在函数的形参中。

这个函数接收一个类型为`a`的值，并两次调用一个接收`a`、返回`b`的函数。

```gleam
pub fn twice(value: a, f: fn(a) -> b) -> b {
  f(value)
  f(value)
}
```
```gleam
// The type is fn(String, fn(String) -> Nil) -> Nil
twice("Hello, Joe!", io.println)
```
