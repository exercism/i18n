本练习的目标是在“密码检查器”练习的基础上进一步改进。由于同一个密码往往可能同时违反多条规则，一个好用的密码检查器应该把所有被违反的规则都告诉用户，而不是只报告碰巧最先发现的那一条。改进后的密码检查器应该一次性指出给定密码违反的所有规则。

这个密码检查器的规则与上一个“密码检查器”练习相同：

- 至少要有 12 个字符
- 至少要有一个大写字母
- 至少要有一个小写字母
- 至少要有一个数字
- 至少要有一个 !@#$%^&\* 中的符号

## 1. 修改`PasswordError`可区分联合，让其中的各个值可以当作标志来使用

请注意，如果不先完成这个关键步骤，测试就无法编译。

## 2. 实现`checkPassword`函数

`checkPassword`函数会按照前面提到的规则检查给定的密码。这个函数应该返回一个`Result`值：当密码满足所有规则时返回`Ok`，当密码违反一条或多条规则时返回`Error`值。如果给定的密码违反了多条规则，`PasswordError`值应该表示所有被违反的规则。

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implement the ``getStatusPhrases` function

`getStatusPhrases`函数会返回一组字符串，其中每个字符串都是一个人类可读的短语，对应`checkPassword`返回的结果中的某一项错误。

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
