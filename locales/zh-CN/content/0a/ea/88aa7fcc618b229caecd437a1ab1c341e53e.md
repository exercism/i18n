# 说明

你在一个小型家具作坊当学徒。木匠师傅的平板电脑上运行着 Factor，用来跟踪下料清单：每块放到工作台上的木板，在第一次下锯之前，都要先算出一组派生值。

前任学徒把收银台的代码留在一片 `dup`、`over`、`swap` 和 `rot` 的丛林里。你的任务是用*组合子*重写五个小词。

每块木板进入工作流时，栈上只有它的原始长度（单位：厘米）。

## 1. 加上锯缝余量

每锯一次，锯片都会从木料上削掉薄薄的一条，这就是*锯缝*。作坊给每块木板都多留 2% 的长度来弥补这部分损耗。

定义 `with-kerf`，接收一个长度，返回该长度加上 2% 的锯缝余量。

```factor
100 with-kerf .
! => 102
```

## 2. 计算锯缝和精加工余量

切割之后是精加工，也就是打磨和刨平，它会再削去原始长度的 5%。

定义 `kerf-and-finish`，把这两个余量并排返回（锯缝在下，精加工在上）。

```factor
100 kerf-and-finish .s
! => 2
! => 5
```

## 3. 生成下料卡

师傅每切一块木板，都会在上面贴一张小卡片，上面写着原始长度、锯缝余量和精加工余量，三个数字，按这个顺序排列。

定义 `cut-card`，返回这三个数字。

```factor
100 cut-card .s
! => 100
! => 2
! => 5
```

## 4. 每段的长度

作坊还会收到成捆的木材，需要把它们分成等长的若干段。整捆的长度先加上一次锯缝余量，再把结果除以段数。

定义 `per-piece`，接收整捆的长度和段数（段数在栈顶），返回每一段的长度。

```factor
100 2 per-piece .
! => 51

100 4 per-piece .
! => 25+1/2
```

## 5. 比较两捆木材

有时师傅在木材场挑选两捆木材，想一眼看出它们的锯缝余量谁多谁少。

定义 `compare-bolts`，从栈上取出两个长度，按同样的顺序分别返回它们的锯缝余量。

```factor
50 100 compare-bolts .s
! => 1
! => 2
```
