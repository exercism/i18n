# 说明

郊区板球场的场地管理员想请你帮忙算几个数字：边界需要多长的绳子，一次击球飞了多远、朝哪个方向，以及球在守场员赶到之前会滚多远。

所有距离都以米为单位，所有速度都以米每秒为单位。场地上的位置从球道中央开始量起：`x` 是沿球场纵向的米数，`y` 是横向的米数，左边为正，右边为负。

## 1. 边界用的绳子

边界是环绕球道中央的一个圆。定义 `boundary-length`，接收半径，返回所需的绳子长度，也就是 2 × π × 半径。

```factor
70.0 boundary-length .
! => 439.822971502571
```

## 2. 离球道有多远？

定义 `distance-from-pitch`，接收守场员的 `x` 和 `y`，返回他离球道中央有多远：x² + y² 的平方根。

```factor
30.0 40.0 distance-from-pitch .
! => 50.0
```

## 3. 球飞向了哪个方向？

定义 `shot-angle`，接收击球落点的 `x` 和 `y`，返回它的方向，单位是**度**：0 表示沿球场正前方，90 表示正左方，-90 表示正右方，180 表示穿过守门手笔直向后。

```factor
50.0 50.0 shot-angle .
! => 45.0
```

## 4. 球飞了多远？

以 `speed` 击出、以 `angle` **度**的仰角升起的球，在第一次落地前会飞出 speed² × sin(2 × angle) ÷ 9.8 米。定义 `carry`，接收速度和角度，返回这段距离。

```factor
30.0 45.0 carry .
! => 91.83673469387755
```

## 5. 在草地上减速

球沿着外场滚动时会损失速度：滚过 `metres` 之后，它的速度是 speed × e^(−0.02 × metres)。定义 `speed-after`，接收起始速度和滚过的米数，返回剩下的速度。

```factor
30.0 50.0 speed-after .
! => 11.03638323514327
```

## 6. 滚到哪里就不值得再追了？

把任务 5 反过来。定义 `metres-until`，接收球开始滚动时的速度和一个更慢的 `target` 速度，返回它在降到目标速度之前滚了多少米：ln(speed ÷ target) ÷ 0.02。

```factor
30.0 15.0 metres-until .
! => 34.657359027997266
```
