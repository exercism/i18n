# 提示

## General

- 可以用`*T`声明指向类型`T`的指针变量，例如`var i *int`声明了变量`i`，它是指向`int`的指针。
- 对变量使用 `&` 运算符，就能取得指向它的指针（也就是它的内存地址），例如`mypointer := &anIntVariable`。
- 对指针使用 `*` 运算符，就能取得指针中存储的值，例如`var i int = *aPointerToInt`。
  这叫作解引用指针。
- 在解引用指针之前，要检查它是不是`nil`。
  尝试解引用`nil`指针会引发运行时错误。
- 如果不确定指针是怎么工作的，可以读一读 [Tour of Go: Pointers][go-tour-pointers] 或 [Go by Example: Pointers][go-by-example-pointers]

## 1. 创建一个计票器

- 你需要创建一个指向`int`的指针，也就是`*int`。
- 可以对变量使用 `&` 运算符，创建指向它的指针，例如`&myInt`
- 你可以创建一个指向自己新定义的变量的指针，也可以直接使用函数参数中的变量

## 2. 从计票器中获取票数

- 可以对指针使用 `*` 运算符来解引用它并取得它的值，例如`*myPointer`
- 解引用`nil`指针会引发运行时错误。
  解引用之前，一定要确认指针不是`nil`。

## 3. 增加计票器的票数

- 如果你有一个指针`var myPointer *int`，可以对`*myPointer`赋值，从而改变`myPointer`所指向的值
- 要取得指针当前指向的值，需要用 `*` 运算符解引用它，或者调用你在上一个任务中写的函数。

## 4. 创建选举结果

- 新建一个`ElectionResult`字面量或变量，把它的`Name`和`Votes`字段设为函数实参中的值。
- 在变量名或字面量前面加上 `&` 运算符，就能从变量或字面量创建指针，例如`&myVariable`或`&ElectionResult{Name: "John", Votes: 1}`

## 5. 公布结果

- 虽然你收到的是指向`ElectionResult`的指针，但仍然可以用点 `.` 语法访问它的字段，就好像它不是指针一样！
- 通过访问结构体上的`Name`和`Value`字段来构建消息。
- 即使你是从指向结构体的指针访问字段，也不需要做任何解引用。
  Go 会自动为你解引用指针，就像下面这个例子：

```go
result := &ElectionResult{
    Name: "John",
    Votes: 32
}

result.Name // "John" - Go will automatically dereference the pointer
            //          and access the 'Name' field of the dereferenced struct 
```

## 6. 重新计票

- 可以把 map 直接看作指针。
  也就是说，你在函数内部对 map 做的修改，在函数外部也能看到。
- 要增加`var m map[string]int`中某个键的值，有几种写法：`m["mykey"] = m["mykey"] + 1`、`m["mykey"] += 1`或`m["mykey"]++`。
