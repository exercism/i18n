# 提示

## 1. 计算一个披萨的价格

- 定义一个递归函数，让它返回“不含该额外配料的披萨价格”加上“这一份额外配料的价格”。
- 如果抛出`Maximum call stack size exceeded`错误，就检查一下是不是漏掉了基本情况。
- 如果遇到`Memory Allocation Error`，就检查一下是不是在复制配料这个输入数组，而不是直接修改它。

## 2. 计算一份订单的总价

- 用`pizzaPrice`算出数组中每个披萨的价格，再累加到一个总和里。
- 如果抛出`Maximum call stack size exceeded`错误，而且有不止一个测试没通过，就检查一下是不是漏掉了基本情况。如果只有一个测试没通过，试着用循环来实现！
- 如果遇到`Memory Allocation Error`，就检查一下是不是在复制输入数组，而不是直接修改它。
