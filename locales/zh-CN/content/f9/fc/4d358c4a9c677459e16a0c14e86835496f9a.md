# 说明

在本练习中，你将编写一些代码，帮助你照着最喜欢的烹饪书做出一份美味的千层面。

共有 5 个任务，都与烹饪千层面所花的时间有关。

## 1. 定义预期的烤箱时间（分钟）

在`Lasagna`类中实现`expectedCookTime`函数，它不接收任何实参，返回千层面应该在烤箱里烤多少分钟。
根据烹饪书，预期的烤箱时间是 40 分钟：

```php
<?php
$timer = new Lasagna();
$timer->expectedCookTime()
// => 40
```

## 2. 计算剩余的烤箱时间（分钟）

在`Lasagna`类中实现`remainingCookTime`函数，它接收千层面已经在烤箱里烤了多少分钟作为实参，并根据上一个任务中得出的预期烤箱时间，返回千层面还需要在烤箱里烤多少分钟。

```php
<?php
$timer = new Lasagna();
$timer->remainingCookTime(30)
// => 10
```

## 3. 计算准备时间（分钟）

在`Lasagna`类中实现`totalPreparationTime`函数，它接收你往千层面里加了多少层作为实参，返回你准备千层面花了多少分钟，假设每准备一层需要 2 分钟。

```php
<?php
$timer = new Lasagna();
$timer->totalPreparationTime(3)
// => 6
```

## 4. 计算总工作时间（分钟）

在`Lasagna`类中实现`totalElapsedTime`函数，它接收两个实参：第一个实参是你往千层面里加了多少层，第二个实参是千层面已经在烤箱里烤了多少分钟。
该函数应返回你烹饪千层面总共工作了多少分钟，也就是准备时间的分钟数，加上此刻千层面在烤箱里所花的时间。

```php
<?php
$timer = new Lasagna();
$timer->totalElapsedTime(3, 20)
// => 26
```

## 5. 创建一条千层面已做好的通知

在`Lasagna`类中实现`alarm`函数，它不接收任何实参，返回一条表示千层面可以开吃了的消息。

```php
<?php
$timer = new Lasagna();
$timer->alarm()
// => "Ding!"
```
