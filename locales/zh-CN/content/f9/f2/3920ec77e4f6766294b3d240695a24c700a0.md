Elixir 有一套特定的命名约定，其中就包括如何命名[返回布尔值、且在守卫子句中有效的检查](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)：

> 在守卫子句中允许的类型检查和其他布尔检查，都以 `is_` 前缀命名。

这类检查包括一些内置函数、一些宏和守卫。

```elixir
# this is the expected name for checks that return booleans and are valid in guard clauses

%{expected}

# this is the current name

%{actual}
```
注意，返回布尔值但在守卫子句中无效的函数和宏遵循另一套约定，以 `?` 后缀命名（`def foo?`、`defmacro foo?`）。这两套约定不能混用。
