# 说明

你期盼已久的那一天终于到来了，现在你自豪地成为了阿尔卑斯山上一座美丽农场的主人。

你依然不喜欢一大早爬起来喂牛。作为一名出色的工程师，你造了一台投喂机，取名`FEED-M-ALL`。

完成这个项目还差最后一步：一段计算每头牛应得饲料量的代码。重要的是每头牛分到的量要一样，你得避免它们起冲突。牛可是很敏感的。

幸运的是，你不需要自己推导所有计算饲料量的公式。你用了一个在网上找到的神秘外部库。据说它能让牛过得最开心。这个库导出了一个类型，实现了下面这个接口。你接下来自己写的代码就要依赖它。

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

在编写代码的过程中，你会逐步改进错误处理，让它更健壮，日后在日常农场生活中使用时也更容易调试。

## 1. 平均分配食物

首先，你专心写出计算每头牛饲料量所需的代码。

实现一个`DivideFood`函数，它接受一个`FodderCalculator`和一个作为整数的奶牛数量作为实参。
*在这个任务中，你可以假设传入的奶牛数量总是大于 0。*
该函数应返回每头牛的食物量，类型为`float64`；如果出错，则返回错误。

要进行计算，你首先需要获取所有奶牛所需饲料的总量。这通过调用`FodderAmount`方法并传入奶牛数量来完成。此外，你还需要一个用来乘以这个总量的系数。调用`FatteningFactor`方法即可得到这个系数。有了这两个值和奶牛数量，你现在就能算出每头牛的食物量（类型为`float64`）。这正是`DivideFood`函数应当返回的结果。

如果你调用的某个方法返回了错误，执行就应停止，并把这个错误原样从`DivideFood`函数返回。

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. 检查奶牛数量

在做上面第一个任务时，你发现所用的外部库并没有想象中那么高质量。比如，它无法正确处理无效输入。你希望在自己的代码里加上对输入值的检查，来绕过这个限制。

编写一个`ValidateInputAndDivideFood`函数，它的签名与上面的`DivideFood`相同。

- 如果传入的奶牛数量大于 0，函数应调用`DivideFood`并返回该调用的结果。
- 如果奶牛数量小于或等于 0，函数应返回一个错误，消息为`"invalid number of cows"`。

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. 改进错误处理

在把数量传下去之前先做检查是个好办法，但你对那条不够具体的错误消息不太满意。你决定做得更好：创建一个名为`InvalidCowsError`的自定义错误类型。

这个自定义错误应保存奶牛数量（`int`）和一条自定义消息（`string`），并且`Error`方法应按以下格式序列化这些数据：

```txt
{number of cows} cows are invalid: {custom message}
```

有了这个自定义错误，实现一个`ValidateNumberOfCows`函数，它接受整数形式的奶牛数量，并返回一个错误（或 nil）。

- 如果奶牛数量小于 0，函数返回一个`InvalidCowsError`，其自定义消息设为`"there are no negative cows"`。
- 如果奶牛数量等于 0，函数返回一个`InvalidCowsError`，其自定义消息设为`"no cows don't need food"`。
- 否则，函数返回`nil`，表示验证成功。

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```
