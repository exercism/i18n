# 简介

与 _`if`/`else`_ 语句类似，`switch` 语句让你可以通过有条件地执行代码来改变程序的流程。
区别在于，`switch` 语句只能把基本类型或字符串表达式的值与预先定义的常量值进行比较。

使用 `switch` 语句时，有几个关键字很有用。

- `switch`：这个关键字让你声明 `switch` 的结构。
  后面跟着决定结果的表达式或变量。
- `case`：你会用这个关键字来声明结果的不同可能性。
- `break`：`break` 关键字非常有用，可以在想要的流程结束时停止 `switch` 的执行。
  如果忘了它，程序会继续执行，可能导致意外的结果。
- `default`：顾名思义，当没有其他 `case` 匹配你的表达式结果时，用它作为默认结果。

最简单的情况下，它们会测试一个基本类型或字符串表达式，并根据其值做出决定。
例如：

```java
String direction = getDirection();
switch (direction) {
    case "left":
        goLeft();
        break;
    case "right":
        goRight();
        break;
    default:
        // otherwise
        markTime();
        break;
}
```
