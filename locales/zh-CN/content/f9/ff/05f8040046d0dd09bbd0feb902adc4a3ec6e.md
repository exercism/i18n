# 关于

布尔表达式是对一个或多个值提出的问题，可以用`true`或`false`来回答。
表达式的结果为 true 时返回`1`，为 false 时返回`0`。
另外，数字也有 true/false 的取值：0 表示`false`，非零表示`true`。

早期的 C 代码要么直接用`int`类型表示布尔值，要么由程序员自己定义`TRUE`和`FALSE`之类的常量，把`1`和`0`映射成布尔表示。

到了 C99 版本，新增了`_Bool`类型。
`stdbool.h`头文件定义了三个新的布尔符号：`bool`、`true`和`false`。
`true`映射为`1`，`false`映射为`0`，`bool`映射为`_Bool`。
所以现在，程序员不用再直接使用`int`，也不用自己搞一套布尔映射，只要包含`stdbool.h`，代码里就能自动获得布尔符号。

## 比较运算符

C 支持六种比较运算符：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于或等于）、`<=`（小于或等于）。
这些运算符比较值之间的关系，并把结果化为布尔值。

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## 布尔运算符

C 支持三种布尔运算符：`||`（或）、`&&`（与）和`!`（非）。

`!`只需要一个操作数，它会反转操作数的布尔值。
例如，`0`是`false`，但`!0`是`true`。

`||`和`&&`需要两个操作数。
只有当左侧的操作数还不足以决定整个表达式的结果时，才会计算右侧的操作数。
也就是说，只有左侧操作数求值为`false`时，`||`才会计算右侧的操作数；只有左侧操作数求值为`true`时，`&&`才会计算右侧的操作数。

## 短路

不计算所有操作数，这种做法叫做“短路”。
短路是一种简洁而强大的手段，可以处理某些特定情况。
例如，一种常见的惯用法是：先检查指针是否不为`NULL`，并且（&&）在不为`NULL`时对它解引用，从而避免解引用`NULL`指针。
但短路也可能导致 bug。
有时程序员会忘记，`||`或`&&`右侧的操作数并不一定会被计算。
如果右侧的操作数是一个带有副作用的表达式，而程序员以为这个副作用总会发生，那么会不会出 bug 就取决于左侧操作数的布尔值。

## 返回布尔表达式

布尔表达式的结果可以直接返回。
例如，下面这个`if`语句

```c
if (count > 0)
    return true;
else
    return false;
end
```

可以替换为

```c
return count > 0;
```
