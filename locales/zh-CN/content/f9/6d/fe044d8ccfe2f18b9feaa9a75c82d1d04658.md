# 关于

[SQLite][sqlite] 是一套开源、轻量、无服务器且自包含的[关系型数据库][relational-database]管理系统。
它以简单、易用和零配置著称。
SQLite 可以嵌入到应用程序当中，是各类应用、嵌入式系统以及中小型项目的理想选择。

[D. Richard Hipp][hipp] 创造了 SQLite，它遵循 [ACID][acid] 特性，旨在支持可靠的事务处理。
凭借极小的体积和高效的表现，SQLite 在各行各业得到了广泛使用。

SQLite 采用直观的基于 SQL 的语法来定义和操作数据库。
表、索引和查询都用标准 SQL 语句创建，为开发者管理数据库提供了熟悉且富有表现力的方式。
数据库引擎是自包含的，无需单独的服务器进程。
这种简单性，再加上强大的能力，使 SQLite 成为那些优先考虑易用性与效率的项目的绝佳选择。
