# 简介

## 比较运算符

R 的运算符和其他许多语言是一样的：

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 分支

if-else 的基本形式如下：

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

在这里，布尔值外面的圆括号 `()` 和语句外面的大括号 `{}` 都是必需的。
简单的 `if` 语句可以简写：

```R
if (x == 0) return("success")
```
