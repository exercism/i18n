# 简介

*quotation*是用 `[ ]` 括起来的一段代码。它本身就是一个值：你可以把它压入栈、传给另一个函数，或者存进数组里。

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

大多数高阶函数都接受一个 quotation 作为第二个参数：

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

quotation 的主体就是普通的 Factor 代码，用的就是你平时用的那些运算符和栈效果。

当你用数据来构建代码时，比如拼接代码片段、把 token 映射到操作，得到的结果是一个序列；把它传给`>quotation`，就能让它变成可调用的：

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
