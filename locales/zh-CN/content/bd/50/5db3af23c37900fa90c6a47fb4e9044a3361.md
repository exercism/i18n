# 说明补充

## 构建你自己的 DSL

在这道练习中，你可以完全自由地设计你梦想中的图 DSL。

测试只要求你创建几个特定的图，至于怎么构建，完全由你决定。

想让乐趣加倍的话，你还可以选择实现一个`to_dot`函数，把你的图转换成 DOT 格式！

## 图的表示

在`Graph.roc`中定义你的 DSL，然后用它来构建代码骨架所要求的图。
每个`EdgeId`中的两个节点 ID 必须按字母顺序排列。

| 定义 | 要构建的图 |
| --- | --- |
| `empty_graph` | 一个空图 |
| `graph_with_one_node` | 一个节点 |
| `graph_with_one_node_with_attribute` | 一个带属性的节点 |
| `graph_with_one_edge` | 一条边 |
| `graph_with_one_attribute` | 一个图属性 |
| `graph_with_nodes_edges_and_attributes` | 节点、边和属性 |
| `multiple_edges_on_one_line` | 在同一行表示多条边 |
| `only_1_edge_between_nodes` | 每对节点之间只有一条边 |
