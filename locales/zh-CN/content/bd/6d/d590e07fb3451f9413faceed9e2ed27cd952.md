# 简介

## 继承

Java 把继承作为核心功能，并借助继承来实现许多面向对象的原则，比如抽象。

一个类可以使用`extends`关键字扩展另一个类，也可以使用`implements`关键字从接口继承。

## 访问修饰符

访问修饰符为类的成员变量和方法定义了访问规则，决定它们能否被其他类（或代码中的任何位置）访问。

访问修饰符有四种：

- `private`
- `public`
- `protected`
- 默认（不需要关键字）

你可以在[这篇文章][access-modifiers]中了解更多。

## 继承与组合

这两个概念非常相似，常常被人混淆。

- 继承意味着子类与父类之间是 IS-A 关系。

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

这里，`Dog` IS-A `Animal`。

- 组合表示 HAS-A 关系。

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

这里，`Car` HAS-A `Engine`。
