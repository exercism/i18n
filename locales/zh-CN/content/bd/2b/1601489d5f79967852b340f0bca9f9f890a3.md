# 简介

`Result`类型使得函数可以返回一个单一的值，用来表示以下所有信息：

- 操作成功还是失败
- 成功时，操作的结果值
- 失败时，失败的原因

## 用法

`Result`是一种泛型类型，包含两种底层类型：

- 成功操作时结果值的类型
- 失败时表示失败原因的类型

`Result`类型也是一种[可区分联合][discriminated-union]，有以下可能情况：

- `Ok <value>`表示成功的结果
- `Error <reason>`表示失败

下面的函数演示了如何创建`Result`值：

```fsharp
let validateName (name: string) : Result<string, string> =
    match name with
    | null -> Error "Name not found."
    | "" -> Error "Name is empty."
    | _ -> Ok name
```

在这个示例中，`Ok`值是字符串（给定的名字），`Error`值也是字符串（错误原因，以人类可读的形式）。

## 读取`Result`值的内容

看看以下类型定义和函数签名：

```
type FileOpenError =
| NotFound
| AccessDenied
| FileLocked

let openFile (filename: string) : Result<int, FileOpenError> =
```

调用`openFile`函数的代码可以使用模式匹配来处理成功和失败的情况，如下例所示：

```fsharp
match openFile(filename) with
| Ok handle -> doSomethingWithFile(handle)
| Error NotFound -> printfn $"Error: file {filename} was not found."
| Error AccessDenied -> printfn $"Error: you do not have permission to open the file {filename}."
| Error FileLocked -> printfn $"Error: file {filename} is already in use."
```
