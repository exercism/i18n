# 简介

## 入门

### 变量

你可以定义[变量][constants-variables]来存储和命名值。
定义变量后，你可以在整个代码中用它的名字来引用那个值。
变量是_可变的_，也就是说它们的值在定义之后可以改变。

使用`var`关键字定义变量：

```swift
var variableName = 10
```

Swift 是一门静态类型语言，也就是说每个值在编译时都有已知的类型。
你可以用[类型注解][type annotations]显式声明类型，也可以让 Swift 编译器根据赋给的值[推断类型][type-inferring]：

```swift
var explicitVar: Int = 10 // Explicitly typed
var implicitVar = 10      // Implicitly typed (inferred as Int)
```

你可以使用赋值运算符（`=`）来更新变量的值：

~~~~exercism/note
变量在声明后，其类型不能改变。

```swift
variableName = 13 // Allowed: same type (Int)

// Compiler error: cannot assign a different type
variableName = "Hello, world!" // Cannot assign value of type 'String' to type 'Int'
```
~~~~

你可以只指定类型而不赋初始值来声明一个变量，但在使用它之前必须先赋一个值：

```swift
var someInt: Int

// This triggers a compiler error:
// print(someInt) // Variable 'someInt' used before being initialized

// Assign a value first
someInt = 169
print(someInt) // Prints 169
```

### 常量

[常量][constants-variables]同样把名字和值关联起来，但它们的值在赋值后不能更改。
它们是_不可变的_。
使用`let`关键字定义常量：

```swift
let constantName = 10          // Inferred constant
let explicitConstant: Int = 10 // Explicitly typed constant
```

### 算术运算符

Swift 为基本数学运算提供了标准的[算术运算符][arithmetical-operators]：

- 加法：`+`
- 减法：`-`
- 乘法：`*`

```swift
print(1 + 1) // Prints 2
print(2 - 1) // Prints 1
print(2 * 2) // Prints 4
```

### 函数

在 Swift 中，[函数][functions]是执行特定任务的独立代码块。
函数可以接受输入、返回一个值，也可以作为值传递给其他函数。
使用`func`关键字定义函数，后面跟上函数名、括号中的参数列表，以及可选的返回类型：

```swift
func functionName(argumentLabel parameterName: ParameterType) -> ReturnType {
    // Function body
}
```

Swift 函数使用[实参标签][argument-labels]，让代码读起来像自然的句子：

- **实参标签**在调用函数时使用。
- **形参名称**在函数体内部用来访问该值。

如果只指定一个名称，Swift 会把它同时用作实参标签和形参名称：

```swift
func greet(name: String) {
    print("Hello, \(name)!")
}

greet(name: "Alice")
```

如果调用函数时不想要实参标签，就在形参名称前写一个下划线（`_`）：

```swift
func square(_ number: Int) -> Int {
    return number * number
}

square(5) // Called without an argument label
```

函数的所有形参默认都是常量（`let`），也就是说它们的值不能在函数体内部修改。

要从函数返回一个值，在`->`后指定返回类型，并使用`return`关键字：

```swift
func addTen(to value: Int) -> Int {
    return value + 10
}

addTen(to: 10) // Returns 20
```

当函数不返回值时，它的返回类型是`Void`（相当于空元组`()`）。
在这类函数中，你可以同时省略`-> Void`返回类型和`return`语句。

### 注释

Swift 支持两种形式的[注释][comments]：

- **单行注释**以`//`开头，一直延续到该行末尾。
- **多行注释**写在`/*`和`*/`之间。

```swift
// This is a single-line comment

/* This is a comment
   that spans multiple lines */
```
