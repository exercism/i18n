# 介绍

_字符串_是 JavaScript 中用来存储文本数据的数据类型。

## 创建字符串

把文本用单引号或双引号包起来，就创建了一个字符串。
在 Exercism 上，使用单引号。

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## 字符串作为字符数组

可以把字符串看作一个字符数组，其中第一个字符的下标是 `0`。
使用方括号和你想获取的字符的下标，就能访问字符串中的单个字符。

```javascript
'cat'[1];
// => 'a'
```

通过访问 `length` 属性，可以确定字符串中字符的数量。

```javascript
'cat'.length;
// => 3
```

## 拼接和方法

拼接字符串最简单的方式是使用加法运算符 `+`。

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

字符串提供了很多辅助方法，完整列表见 [MDN 上关于字符串方法的文档][mdn-string-methods]。
下面列出了一些常用的辅助方法。

- [`toUpperCase`][mdn-to-upper-case] 和 [`toLowerCase`][mdn-to-lower-case]：改变所有字符的大小写
- [`trim`][mdn-trim]：去掉开头和结尾的空白
- [`includes`][mdn-includes]、[`startsWith`][mdn-starts-with] 和 [`endsWith`][mdn-ends-with]：判断另一个字符串是否是给定字符串的一部分
- [`slice`][mdn-slice]：截取字符串的一部分

在 JavaScript 中，字符串是不可变的。因此，所谓的“修改”（比如使用上面某些方法）总是会创建一个新字符串。
