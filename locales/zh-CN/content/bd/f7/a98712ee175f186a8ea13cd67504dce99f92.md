# 简介

## 命名空间

命名空间是一种把相关代码组织在一起、避免名称冲突的方式，除了最简单的代码库以外，几乎所有代码库都会用到它。

语法如下：

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

在命名空间作用域之外引用其中的类型时，需要用点号语法给类型名加上前缀。另一种更常见的做法是在文件开头（或某个命名空间内）加上 `using` 指令，这样使用类型时就不需要加前缀。在同一个命名空间内，则不需要限定类型名。

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

你可以用 `using MyAlias = MySpace;` 这样的语法给命名空间起别名，之后凡是能使用该命名空间的地方，都可以使用这个别名。
