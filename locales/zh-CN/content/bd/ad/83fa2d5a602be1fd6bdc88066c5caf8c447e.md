# 简介

## 资源生命周期

[concept:csharp/resource-cleanup]() 使用 `IDispose` 接口来表示：当某个对象不再需要时，它的资源或其他程序状态需要被释放或重置（而且依赖垃圾回收器无法实现这一点，也无法提供所需的控制程度），而 `IDisposable.Dispose()` 方法就是执行这类清理操作的自然位置。

还有一种结构，即 `using` 块，它从调用方的角度出发，把所有资源生命周期管理集中到一条语句里。

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

在上面的例子中，退出 `using` 块时，与 `file` 关联的文件系统资源会被交还给操作系统释放。

要让这个模式生效，`using` 语句中的变量必须是实现了 `IDisposable` 接口的引用类型，并且必须在它的 `Dispose()` 方法中释放资源、重置程序状态。

C# 8 对该模式做了一处改进：`using` 语句可以放在代码块的开头。

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 开发者可能认出，这类似于 Java 7 引入的_自动资源管理_机制。
