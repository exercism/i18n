# 关于

[D](https://dlang.org) 是一门系统编程语言，语法类似 C，采用静态类型。它把效率、控制力和建模能力，与安全性和程序员生产力结合在一起。这门语言最初由 [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) 和 [Andrei Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) 开发，始于 D 2 版本。

D 汇聚了数十年来为各种不同语言实现编译器的经验，拥有大量[独特特性](http://dlang.org/overview.html)：

- 高级结构，建模能力出色
- 高性能的编译型语言
- 静态类型
- C++ 的演进（没有那些错误）
- 直接与操作系统 API 和硬件交互
- 编译速度极快
- 支持内存安全的编程（SafeD）
- 可维护、易于理解的代码。
- 学习曲线平缓（类似 C 的语法，与 Java 等语言相似）
- 与 C 应用程序二进制接口兼容
- 多范式（命令式、结构化、面向对象、泛型、函数式编程的纯粹性，甚至汇编）
- 内置的错误预防（契约、单元测试）

[D 语言基金会](https://dlang.org/foundation.html)是致力于开发和推进 D 语言的组织。
