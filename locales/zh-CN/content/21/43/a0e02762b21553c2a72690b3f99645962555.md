# 简介

在 Clojure 中，把一个值绑定到一个名字上称为 _变量_。顶层（全局）变量与其他语言中的常量类似。

使用`def`定义顶层变量：

```clojure
(def fingers 10)

fingers
;;=> 10
```

你可以用`defn`定义接受零个或多个实参的函数。下面这个函数把 2 个数字相加：

```clojure
(defn add [x y]
  (+ x y))
```

这个函数接受 2 个实参，它们放在向量`[x y]`中，接着是函数的 *函数体*，函数体可以包含任意数量的表达式。返回值始终是求值函数体中最后一个表达式 `(+ x y)` 的结果。这个表达式是一个表示函数调用的列表。列表的第一项是`+`函数，它把后面的项`x`和`y`作为实参来求值。

上面定义的`add`函数用同样的方式调用：

```clojure
(add 2 3)
;;=> 5
```

Clojure 中的函数和值只能在定义 _之后_ 使用，也就是说，形式总是按它们出现的顺序求值。

在 Clojure 中，空白除了用于排版之外没有任何意义。

Clojure 的函数和变量按命名空间组织。命名空间把相关的功能归为一组，使用`ns`宏定义：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支持两种注释。单行注释以`;`开头，而`comment`形式用于阻止对`(comment`和`)`之间所有内容的求值。
