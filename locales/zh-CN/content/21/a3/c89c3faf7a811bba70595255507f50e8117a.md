# 字典

在 Cairo 中，字典是一种键值对存储，类似其他语言中的映射或哈希表。

不过，由于 Cairo 采用不可变内存模型，字典有一些独特的性质。

## 核心概念

`Felt252Dict<T>` 类型在 Cairo 中提供字典功能，键的类型是 `felt252`，值的类型可以是任意受支持的类型 `T`。

```rust
use core::dict::Felt252Dict;

fn main() {
    let mut balances: Felt252Dict<u64> = Default::default();
    balances.insert('Alice', 100);
    let balance = balances.get('Alice'); // Returns 100
}
```

## 重要特性

与其他语言中的字典不同，Cairo 的字典有一些特殊性质：

1. 键必须是 `felt252` 值。
2. 所有键都隐式地以零作为初始值。
3. 不能删除条目，只能更新值。
4. 值必须实现 `Felt252DictValue` trait。

## 性能说明

由于 Cairo 的不可变内存模型，字典操作的复杂度为 $O(n)$，其中 $n$ 是对该字典执行的操作次数。

每次操作都会创建一条新记录，记下这次改动。

## 处理复杂类型

对于没有实现 `Felt252DictValue` 的类型（比如数组或结构体），可以把它们包装进 `Nullable<T>`：

```rust
let mut dict: Felt252Dict<Nullable<Span<felt252>>> = Default::default();
dict.insert(0, NullableTrait::new(array![1, 2, 3].span()));
```

## 内存管理

字典实现了 `Destruct` trait，也就是说，当它们离开作用域时会被自动“压缩”（校验并优化）。

这是 Cairo 证明系统的一部分，在幕后自动完成。

请记住：字典看起来可能不如其他语言中的那么高效，但这样设计是为了配合 Cairo 独特的内存模型和证明系统的要求。
