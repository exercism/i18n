# 说明

Astrid 是一位爱冒险的炼金术士，她正试着将从不同国度收集来的魔法计量单位统一起来。
有些国度使用有符号的计量值（可能为负），另一些则使用无符号的计量值（始终为正）。
除此之外，Astrid 还为几种稀有材料定义了两个自定义类型，她需要一种能在这些类型之间轻松转换的方式。

你的任务是帮助 Astrid 在有符号整数和无符号整数之间进行转换，并使用 Cairo 的`Into`和`TryInto`特征，为她的特殊材料类型创建自定义类型转换。

## 1. 在有符号和无符号之间转换魔法单位

Astrid 收集到的计量值有时为正，有时为负（有符号整数），但在某些任务中，她需要确保这些值始终为正（无符号整数）。

请编写一个函数来帮助 Astrid，它能完成以下转换：

1. 将有符号整数（`i32`）转换为无符号整数（`u16`）。
2. 将无符号整数（`u16`）转换为有符号整数（`i32`）。

```rust
let signed_value: i32 = -42;
match convert_signed_to_unsigned(signed_value) {
    Option::Some(v) => println!("Converted to unsigned: {}", v),
    Option::None => println!("Failed to convert: {}", signed_value),
} // prints "Failed to convert: -42"

let unsigned_value: u16 = 42;
let signed_value: i32 = convert_unsigned_to_signed(unsigned_value);
println!("Converted to signed: {}", signed_value); // prints "Converted to signed: 42"
```

## 2. 自定义材料类型的转换

Astrid 会接触两种稀有材料：**Essence**和**Elixir**，它们由自定义类型表示。
她希望能把**Essence**转换成**Elixir**，但反过来不行。

请创建两个自定义类型`Essence`和`Elixir`，并实现`Into`特征，把`Essence`转换为`Elixir`，以此帮助 Astrid。

请编写一个函数，接受一个`Essence`，并用`.into()`把它转换成`Elixir`。

```rust
#[derive(Drop)]
struct Essence {
    potency: u16,
}

#[derive(Drop)]
struct Elixir {
    strength: u16,
}

fn convert_essence_to_elixir(essence: Essence) -> Elixir {
    // Convert the Essence to Elixir using the Into trait.
    essence.into()
}

fn main() {
    let essence = Essence { potency: 100 };
    let elixir: Elixir = convert_essence_to_elixir(essence);
    println!("Elixir strength: {}", elixir.strength); // Elixir strength: 100
}
```
