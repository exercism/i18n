# 简介

### 包含

一般来说，编程时不必重复造轮子。
许多标准算法，可能早就有人替你写好了。

### `include`指令

要包含其他文件的内容，C++ 使用`include`指令。
这些包含语句应写在文件顶部。
编译时，带有该指令的那一行会被相应文件的内容替换。
包含之后，命名空间与原始文件中保持一致。

### 标准库

标准库提供了许多常用的函数、算法和数据结构。
标准库使用`std`命名空间。

C 数值库`cmath`就是一个例子。
它提供了许多常见的数学运算。

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
标准库用尖括号`<>`包含，而不是双引号`"`。
区别在于编译器搜索相应文件的位置。
使用尖括号时会跳过在当前项目中的搜索，直接从系统的包含目录开始。
如果要包含本地文件，则应使用双引号：`#include "myfile"`
~~~~

## 字符串

在 C++ 中，`string`是一个可变对象，它把文本表示为字符序列（字母、数字、标点等）。
字符串通过调用它的方法来操作。

### 字符串库

在 C++ 中，字符串类型和相关函数在使用前必须先包含字符串库。
只需在文件顶部添加`#include <string>`即可。
这样它们就会加入`std`命名空间。
字符串类型的完全限定名是`std::string`。
字符串字面量使用双引号字符：`"`。

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

### 常见的字符串操作

可以用`+`运算符来拼接字符串：

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

要使用字符串库，你需要知道：可以调用从属于某个对象的函数。
这种函数称为成员函数。
在后面的教学大纲中，你会进一步了解成员函数以及与之相关的类概念。

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```

`find`函数也非常有用。
它以字符串成员函数的形式调用，并接受一个字符串作为实参。
`find`返回子串在字符串中_首次_出现的位置，下标从 0 开始。

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```
