作为见习魔术师，Elyse 需要练习一些基本功。
她有一副牌，想要对它进行操作。

为了方便一点，她只用编号 1 到 10 的牌。

## 1. 从牌堆中取出一张牌

返回给定牌堆中位置`idx`处的牌。

```julia-repl
julia> idx = 2;

julia> card([1, 3, 4, 1], idx)
3
```

## 2. 交换牌堆中的一张牌

把位置`idx`处的牌换成提供的新牌，并返回调整后的牌堆。
注意，这会修改（改变）输入的数组，这没问题。

```julia-repl
julia> idx = 2; new_card = 6;

julia> replace_card!([1, 3, 4, 1], idx => new_card)
[1, 6, 4, 1]
```

## 3. 在牌堆顶部插入一张牌

在牌堆顶部插入一张新牌，并返回牌堆。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_top!([1, 3, 4, 1], new_card)
[1, 3, 4, 1, 8]
```

## 4. 从牌堆中移除一张牌

移除牌堆中位置`idx`处的牌，并返回牌堆。

```julia-repl
julia> idx = 2;

julia> remove_card!([1, 3, 4, 1], idx)
[1, 4, 1]
```

## 5. 移除牌堆顶部的牌

移除牌堆顶部的那张牌，并返回牌堆。

```julia-repl
julia> remove_card_from_top!([1, 3, 4, 1])
[1, 3, 4]
```

## 6. 在牌堆底部插入一张牌

在牌堆底部插入一张新牌，并返回牌堆。

```julia-repl
julia> new_card = 8;

julia> insert_card_at_bottom!([1, 3, 4, 1], new_card)
[8, 1, 3, 4, 1]
```

## 7. 从牌堆底部移除一张牌

移除牌堆底部的那张牌，并返回牌堆。

```julia-repl
julia> remove_card_at_bottom!([1, 3, 4, 1])
[3, 4, 1]
```

## 8. 检查牌堆的大小

检查牌堆的大小是否等于给定的`deck_size`。

```julia-repl
julia> deck_size = 4;

julia> check_deck_size([1, 3, 4, 1], deck_size)
true

julia> check_deck_size([1, 3, 4, 1, 5], deck_size)
false
```
