# 介绍

Gleam 可以运行在 Erlang 虚拟机（BEAM）上，也可以运行在 JavaScript 运行时上。还有许多其他语言也使用这些运行时，而且我们常常需要从 Gleam 调用用这些语言编写的代码。

Gleam 的_外部函数_功能允许把其他语言中的函数导入 Gleam，并在调用时没有任何运行时开销。

如果你的 Gleam 项目运行在 Erlang 虚拟机上，并且你想调用 Erlang `lists` 模块中的 `reverse` 函数，可以像这样给 Gleam 函数头加上 `@external` 属性：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

之后就可以像普通 Gleam 函数一样调用它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果你尝试为 JavaScript 运行时编译这段代码，编译会失败并报错，因为 JavaScript 没有对应的实现。可以为 JavaScript 运行时另外指定一个实现，像这样：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

也可以写一个 Gleam 实现，在当前编译目标没有外部实现时就会用它：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
