# 说明

在这个练习中，你将编写一个程序，帮助你为购买车辆做准备。

你有两个任务：判断你是否需要取得驾照，以及估算一辆二手车的合理价格。

## 1. 判断你是否需要驾照

有些类型的车辆需要驾照才能驾驶。
假设只有名称中包含`car`或`truck`的车辆才需要驾照，其他车辆都不需要驾照即可驾驶。

实现一对`pattern {action}`，当第一个字段是`needs_license`时匹配。
它应该从第二个字段中获取车辆类型，如果你需要为这类车辆取得驾照，就打印“true”。
如果不需要驾照，就什么都不用打印。

```sh
echo "needs_license,dumptruck" | gawk -f vehicle-purchase.awk
# => true

echo "needs_license,bike" | gawk -f vehicle-purchase.awk
# => (empty output)
```

## 2. 估算二手车的价格

既然已经做出了决定，你还想确保自己在经销商那里能拿到公道的价格。
既然你想买的是二手车，价格就取决于车龄。
粗略估算一下，假设车龄不到 3 年，价格就是新车原价的 80%。
如果车龄超过 10 年，价格就是 50%。
如果车龄至少 3 年但不超过 10 年，价格就是原价的 70%。

实现一对`pattern {action}`，当第一个字段是`resell_price`时匹配。
它应该从第二个字段获取车辆的原价，从第三个字段获取车龄。
动作应该打印估算出的价格。

```sh
echo "resell_price,1000,1" | gawk -f vehicle-purchase.awk
# => 800

echo "resell_price,1000,5" | gawk -f vehicle-purchase.awk
# => 700

echo "resell_price,1000,15" | gawk -f vehicle-purchase.awk
# => 500
```
