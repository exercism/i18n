# 简介

Elixir 中的正则表达式遵循 **PCRE** 规范（**P**erl **C**ompatible **R**egular **E**xpressions），与 Java、JavaScript 或 Ruby 等其他常用语言类似。

`Regex`模块提供了处理正则表达式的函数。`String`模块的一些函数也接受正则表达式作为实参。

~~~~exercism/note
本练习假设你已经了解正则表达式的语法，包括字符类、量词、分组和捕获。

如果你需要复习一下正则表达式知识，可以参考以下资源之一：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

## 印记

创建正则表达式最常见的方式是使用`~r`印记。

```elixir
~r/test/
```

注意，所有 Elixir 印记都支持[不同种类的分隔符][sigils]，而不只是`/`。

## 匹配

可以用`=~/2`运算符执行正则匹配，它会返回`boolean`结果。此外，`Regex`模块和`String`模块中都有`match?/2`函数。

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

## 捕获

如果简单的布尔检查不够用，可以用`Regex.run/3`函数获取所有捕获结果的数组（如果没有匹配，则返回`nil`）。返回数组的第一个元素始终是整个正则表达式的匹配，后面的元素则是各个匹配的分组。

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

## 修饰符

正则表达式的行为可以通过附加特殊的标志来修改。使用印记创建正则表达式时，把修饰符加在第二个分隔符之后。

常见的修饰符有：
- `i`：让匹配不区分大小写。
- `u`：启用像`\p`这样的 Unicode 专用模式，并让`\w`、`\s`等字符类也能匹配 Unicode。

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
