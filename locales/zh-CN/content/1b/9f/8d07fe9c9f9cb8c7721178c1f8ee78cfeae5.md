# 练习说明补充

## 关于 Enum

enum 语句让你可以创建一组强类型的标签。
你可以在代码中使用这个枚举，无需解析，也不必担心拼写错误。

枚举在内部以整数表示，起始值为 0。
默认情况下，PowerShell 会把列表中的第一个标签赋值为 0，其余标签则依次赋予连续的整数。

示例：
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

想进一步了解 PowerShell 中的 Enum，请查看 [Enum 模块](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)。
