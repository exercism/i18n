# 条件判断

Crystal 中有所谓的控制表达式，它们用来控制程序的运行方式，并接受真值或假值。
有些运算符可以用来生成真值或假值，它们被称为[相等与比较运算符][equality-and-comparison]。

有两个主要的控制表达式，用来决定哪些代码会运行、哪些不会运行。
也就是决定哪个分支会执行。

这两个是：`if` 表达式和 `unless` 表达式。

## 比较运算符

比较运算符用来比较值，并返回 `true` 或 `false`。
这类运算符要求被比较的两个值类型相同。
如果两个值的类型不同，编译器就会抛出错误。
下面列出了各个比较运算符，以及它们在什么情况下会得到 `true` 值：

| 方法 | 说明           | 示例 |
| ------ | --------------------- | ------- |
| <      | 小于             | 4 < 5   |
| <=     | 小于或等于    | 4 <= 4  |
| >      | 大于          | 3 > 1   |
| >=     | 大于或等于 | 2 >= 2  |

## 相等运算符

相等运算符与比较运算符类似，但它们用来检查两个值是否相等。

`==` 运算符检查两个值是否相等，包括值的类型。
如果两个值相同，它就返回 `true`，否则返回 `false`。
`==` 运算符可以把任意类型的值与任意其他类型的值进行比较。
`!=` 的工作方式相同，但在两个值不相等时返回 `true`，相等时返回 `false`。

## 飞船运算符

飞船运算符是一种独特的比较运算符，它的名字来源于它的样子。
它的独特之处在于，它不返回真值或假值，而是返回一个数字。
它写作 `<=>`，用于比较两个值。
如果左边的值大于右边的值，它返回 `1`；如果左边的值小于右边的值，则返回 `-1`；如果两个值相等，则返回 `0`。

```crystal
1 <=> 2 # => -1
2 <=> 2 # => 0
3 <=> 2 # => 1
```

## `if` 语句

[`if`][if] 语句用来检查给定的条件是真值还是假值。
如果条件是真值，`if` 语句内部的代码就会运行。
`if` 语句以 `end` 关键字结束。

```crystal
if 1 == 1
  puts "1 is equal to 1"
end
# => 1 is equal to 1

if 1 > 2
  puts "1 is greater than 2"
end
# => no output
```

## `unless` 语句

[`unless`][unless] 语句的工作方式与 `if` 语句非常相似，但如果条件是假值，它就会运行 `unless` 语句内部的代码。

```crystal
unless 1 == 1
  puts "1 is not equal to 1"
end
# => no output

unless 1 > 2
  puts "1 is not greater than 2"
end
# => 1 is not greater than 2
```

## `else` 语句

`else` 语句可以与 `if` 和 `unless` 语句配合使用。
如果 `if` 分支或 `unless` 分支没有执行，`else` 语句就会执行。

~~~~exercism/warning
尽管 `else` 分支可以与 `unless,` 配合使用，但不建议这么做，因为这样会损害可读性。
建议改用 `if !condition` 搭配 `else` 分支。
~~~~

```crystal
if 1 == 1
  puts "1 is equal to 1"
else
  puts "1 is not equal to 1"
end
# => 1 is equal to 1

unless 1 < 2
  puts "1 is not greater than 2"
else
  puts "1 is greater than 2"
end
# => 1 is greater than 2
```

## “级联 if”语句

`elsif` 语句可以与 `if` 语句配合使用。
如果 `if` 分支没有执行，而 `elsif` 语句的条件是真值，`elsif` 语句就会执行。
多个 `elsif` 语句可以串联在一起，第一个为真值的条件会执行。
`if` 语句末尾还可以有一个 `else` 语句，如果前面的语句都不为真，它就会运行。

```crystal
if 1 != 1
  puts "1 is not equal to 1"
elsif 1 > 2
  puts "1 is greater than 2"
else
  puts "1 is not equal to 1 and 1 is not greater than 2"
end
# => 1 is not equal to 1 and 1 is not greater than 2
```

## 三元运算符

Crystal 有一个三元运算符，即单行的 if-else 语句：`condition ? expression_if_truthy : expression_if_falsey`

```crystal
1 == 1 ? puts("1 is equal to 1") : puts("1 is not equal to 1")
# => 1 is equal to 1
```

## if 和 unless 作为后缀

if 和 unless 语句还可以用作[后缀][if-as-suffix]，当你只想在条件成立时运行一行代码，这很有用。
做法是把 if 或 unless 语句放在你想运行的那行代码后面。

```crystal
puts "1 is equal to 1" if 1 == 1
# => 1 is equal to 1

puts "1 is not equal to 1" unless 1 == 1
# => no output
```

## 条件判断中的类型

当变量被赋以不同类型的值时，它会同时带有这两种类型。
这是因为编译器不知道哪个分支会执行。
这种多重赋值也称为联合类型，会在后面的概念中讲解。
下面的例子展示了这一点：

```crystal
if 1 == 1
  a = 1
else
  a = "1"
end

typeof(a) # => Int32 | String
```
