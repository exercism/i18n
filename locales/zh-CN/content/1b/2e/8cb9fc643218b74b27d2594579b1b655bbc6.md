# 类

类是[面向对象编程][object-oriented-programming]中的核心概念。[在 Crystal 中，一切皆对象][everything-is-an-object]，每个对象都有一个类型，并且能够响应一些方法。类是创建对象的蓝图，为状态（比如变量）提供初始值，也为行为（比如方法）提供实现。对象是类的实例，保存着所有的实例变量和状态。

## 类的定义

类使用`class`关键字定义，后面跟上用`UpperCamelCase`写的类名。

```crystal
class Account
end
```

## 创建实例

要[创建类的实例][new-initialize]，可以用`new`方法调用类名。

```crystal
class Account
end

account = Account.new
```

在上面的例子中，变量`account`是类`Account`的一个实例。

创建实例时，一个名为`initialize`的特殊方法充当构造函数。它在创建实例时被调用。构造函数让你可以设置实例的初始状态。`initialize`方法可以接收实参，这些实参在创建实例时传入。

```crystal
class Account
  def initialize(number)
    5 + number # => 9
  end
end

Account.new(4)
```

~~~~exercism/note
`initialize`方法不能手动返回值，而是由`new`返回新创建的实例。

```crystal
class Account
  def initialize(number)
    5 + number
  end
end

Account.new(4)
# => #<Account:0x7f5dc33dcea0>
```
~~~~

## 实例方法

实例方法是类实例可用的方法，可以在该实例上调用。实例方法使用`def`关键字定义，后面跟上方法名。它们定义在类内部。

```crystal
class Account
  def balance
    100
  end
end

account = Account.new
account.balance # => 100
```

## 实例变量

[实例变量][instance-variable]是实例的所有方法都可用的变量。要访问实例变量，你需要定义一个实例方法。它们可以在`initialize`方法中初始化。它们使用`@`前缀定义。

```crystal
class Account
  def initialize
    @balance = 100
  end

  def balance
    @balance
  end
end

account = Account.new
account.balance
# => 100
```

实例变量也可以在类内部定义。

```crystal
class Account
  @age = 0
end
```

### 带初始化的实例变量

实例变量可以用传给`initialize`方法的实参来初始化。由于 Crystal 无法推断初始化时所用实参的类型，因此必须指定类型。如果想深入了解，可以阅读：[类型推断][type-inference]。要指定变量的类型，可以使用`:`符号，后面跟上类型。例如，如果你想创建一个名为`balance`、类型为`Int32`的实例变量，可以这样写：`@balance : Int32`。或者，如果你想创建一个名为`raining`、类型为`Bool`的实例变量，可以这样写：`@raining : Bool`。

有几种实现方式。一种是在`initialize`方法中声明带类型的实参，再把实参赋值给实例变量，如下例所示：

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def balance
    @balance
  end
end

account = Account.new(1)
account_2 = Account.new(5)

account.balance
# => 1

account_2.balance
# => 5
```

另一种方式是在类内部按`@<variable> : <Type>`的形式声明实例变量的类型，如下例所示：

```crystal
class Weather

  @raining : Bool

  def initialize(raining)
    @raining = raining
  end

  def raining
    @raining
  end
end

weather = Weather.new(true)
weather.raining
# => true
```

### 初始化实例变量的简写

在`initialize`方法的实参中初始化实例变量有一种简写，使用相同的`@<variable> : <Type>`语法。它同时完成了把实参赋值给实例变量和声明实例变量类型这两件事。

```crystal
class Account
  def initialize(@balance : Int32)
  end
end
```

## 修改实例变量

方法可以修改实例变量。这些方法可以在类的实例上调用。当方法修改实例变量时，该改动只在调用它的那个类实例中生效。

```crystal
class Account
  def initialize(balance : Int32)
    @balance = balance
  end

  def withdraw(amount)
    @balance -= amount
  end

  def balance
    @balance
  end
end

account = Account.new(10)
account_2 = Account.new(10)
account.balance
# => 10

account_2.balance
# => 10

account.withdraw(5)
account.balance
# => 5

account_2.balance
# => 10
```

## 类方法

[类方法][class-methods]是为类（而不是其实例）定义的方法。它们提供了一种途径，用来创建不依赖实例状态的方法。它们使用`def`关键字定义，后面跟上`self.<method name>`。`self`是对调用`self`的命名空间的引用。在这里，它指的是类`Account`。这和写`Account.`是一样的，但更推荐用`self.`。

```crystal
class Account
  def self.balance
    100
  end
end

Account.balance
# => 100
```
