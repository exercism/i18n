# 说明

你的任务是为 Mickey 和 Minerva 生成完美的迷宫：只有唯一解，而且没有孤立的区域。
下面是你需要知道的内容：

- 迷宫是矩形，起点和终点各有一个开口。
- 迷宫由房间和通道组成，它们以直角相交。
- 程序应接受两个参数：行数和列数。迷宫的大小应在 5 到 100 个格子之间。
- 宽为`x`列、高为`y`行的迷宫，宽度应为`2x + 1`个字符，高度应为`2y + 1`个字符。
- 如果没有提供种子，就随机生成一个迷宫。如果多次提供同一个种子，每次生成的迷宫都应该相同。
- 使用[制表符号][Box-drawing]来绘制墙壁，并用箭头符号（⇨）表示左侧的入口和右侧的出口。

现在，为这两只爱冒险的老鼠创造一些完美的迷宫吧！

## 示例

1. 一个 5x5 格的小正方形迷宫（即 11x11 个字符）

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. 一个 6x18 格的长方形迷宫

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```
