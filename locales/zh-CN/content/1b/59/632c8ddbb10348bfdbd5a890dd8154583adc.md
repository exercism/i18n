# 贡献者工具

学生只需要 [INSTALLATION.md](INSTALLATION.md) 里的工具。贡献者还需要几个工具，因为该轨道的脚本会用到它们：

- `git`，用于克隆代码仓库并创建拉取请求。
- `jq`，被 `bin/verify-exercises` 和 `bin/add-practice-exercise` 使用。
- `curl`，被 `bin/fetch-configlet` 使用。
- Python 3.11 或更高版本，用于测试生成器。
- `clang-format`，测试生成器会对它写出的文件运行这个工具。
- `pre-commit`，在每次提交前运行代码仓库的各项检查。

请用与你所用发行版对应的命令安装它们，然后按照“设置代码仓库”下的步骤操作。

## Debian / Ubuntu

```shell
sudo apt install git jq curl clang-format pre-commit
```

## Fedora

```shell
sudo dnf install git jq curl pre-commit clang-tools-extra diffutils
```

## Arch Linux

```shell
sudo pacman -S git jq curl pre-commit clang diffutils
```

## openSUSE Tumbleweed

```shell
sudo zypper install git jq curl python3-pre-commit clang-tools diffutils
```

## 设置代码仓库

在代码仓库根目录下执行：

```shell
bin/fetch-configlet
bin/configlet info
pre-commit install
pre-commit run --all-files
```
