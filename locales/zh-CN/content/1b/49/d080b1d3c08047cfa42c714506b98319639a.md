# 测试

选择你当前使用的操作系统：

* [Windows](##windows)
* [macOS](##macos)
* [Linux](##linux)

# 运行测试

## Windows

1. 打开命令提示符。

2. 获取第一个练习：

    ```batchfile
     C:\Users\USERNAME> exercism download --exercise hello-world --track cobol
    ```

3. 进入练习文件夹：

    ```batchfile
     C:\Users\USERNAME> cd C:\Users\USERNAME\exercism\cobol\hello-world
    ```
   
4. 运行测试：

    ```batchfile
     C:\Users\USERNAME\exercism\cobol\hello-world> test.ps1
    ```
    *（第一次运行测试时如果失败不用担心，每个练习都是这样开始的。）*

5. 完成练习。
    阅读 `instructions.md`，了解如何解决这个练习（[在 GitHub 上查看](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


祝你好运，玩得开心，欢迎来到 COBOL track！

## macOS

1. 打开终端窗口。

2. 获取第一个练习：

    ```
     $ exercism download --exercise hello-world --track cobol
    ```

3. 进入练习文件夹：

    ```
     $ cd /Users/USERNAME/exercism/cobol/hello-world
    ```

4. 运行测试：

    ```
     $ bash test.sh
    ```
    *（第一次运行测试时如果失败不用担心，每个练习都是这样开始的。）*

    提示：如果遇到提示说缺少 `basename`，可以用 [brew](https://brew.sh/) 安装 coreutils。（`brew install coreutils`）

5. 完成练习。

    阅读 `instructions.md`，了解如何解决这个练习（[在 GitHub 上查看](https://github.com/exercism/cobol/blob/main/exercises/practice/hello-world/.docs/instructions.md)）。


祝你好运，玩得开心，欢迎来到 COBOL track！
