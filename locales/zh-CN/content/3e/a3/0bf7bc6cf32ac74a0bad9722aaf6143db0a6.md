# 数组简介

Bash 提供两种类型的参数：标量值和数组。
标量值可以是字符串或数字，代表单个“东西”。

大多数时候，标量值就足以容纳你的数据。
但有时，你需要存储一组标量值。
这时就要用到_数组_。

数组有两种：

* 数字索引数组把整数键映射到字符串值。
  （其他语言可能称之为“数组”或“序列”。）
* 关联数组把字符串键映射到字符串值。
  （其他语言可能称之为“映射”或“字典”。）

本文档的前几节会介绍数字索引数组（下文简称为“数组”）。
关联数组的细节会在最后出现。

~~~~exercism/caution
Bash 数组_只能_存储标量值。
无法创建二维数组（数组的数组）。
~~~~

## 声明并初始化数组变量

你可以把一组元素（可以为空）用括号括起来赋值给变量，从而初始化数组。

```bash
myarray=("one" "two" "three")
```

和所有变量赋值一样，等号两边不能有空格。

注意元素之间没有逗号分隔，它们是一组以空白分隔的字符串。

实际上，括号里用多少空白完全随意。
也可以换行，为了可读性想换几行都行。

```bash
myarray=(
    "first element"
    "second element"
    "this is the last element"
)
```

用这种方式把一组字符串赋值给数组变量时，第一个字符串存放在下标 0，下一个存放在下标 1，再下一个存放在下标 2，依此类推。

也可以通过指定需要的下标来初始化“稀疏数组”。

```bash
raindrops=([3]="Pling" [5]="Plang [7]="Plong")
```

~~~~exercism/note
再强调一次：数组下标从 0 开始。
下面这段代码会输出 "true"：

```bash
myarray=("one" "two" "three")
[[ "${myarray[0]}" == "one" ]] && echo true || echo false
```
~~~~

你可以用`declare`命令（在函数内则用`local`）来指定某个变量将存放数组。

```bash
declare -a myarray
```

更地道的做法是直接赋值一个括号里的内容（可以为空）来初始化变量。

## 访问数组元素

正如上面的提示所说，访问数组元素的语法是`${myarray[$index]}`。
下标写在方括号里。
花括号是必需的。

~~~~exercism/note
对于数字索引数组，下标是一个算术表达式。
Bash 手册[写道][arithmetic]：

> 在算术表达式里，shell 变量也可以直接按名称引用，而不必使用参数展开的语法。

这意味着对于“简单”的变量展开，`$`不是必需的。
可以像下面这样访问元素，读起来会稍微清楚一些：

```bash
i=5
echo "${myarray[i]}"
# ..............^
```

[arithmetic]: https://www.gnu.org/software/bash/manual/bash.html#Shell-Arithmetic
~~~~

如果给定的下标在数组中不存在，展开结果就是空字符串。

## 给数组赋值

要给数组中的某个元素赋值，使用下面的语法：

```bash
myarray[10]="hello"
```

要向数组_追加_内容，使用`+=`拼接赋值运算符，并加上括号：

```bash
myarray+=("new element 1" "new element 2")
```

## 迭代数组

你通常需要迭代数组中的_值_。
使用`for`循环（你在[循环][looping]概念里见过）：

```bash
myarray=("one" "two" "three")
for value in "${myarray[@]}"; do
    echo "$value"
done
```

注意展开数组的特殊语法：`"${myarray[@]}"`
这种参数展开形式会把数组的各个值作为独立的词展开。
它大致相当于：

```bash
for value in "${myarray[0]}" "${myarray[1]}" ... "${myarray[n]}"
```

`"${myarray[@]}"`这种写法对稀疏数组同样有效，只会展开已定义的值。

这种特殊展开，也就是把下标写成 `@`，只有在双引号内部才具有特殊含义。

#### 其他特殊的参数展开

下面再介绍几段迭代数组时会用到的特殊语法。
Bash 手册在 [Shell 参数展开][man-expn] 一节里介绍了它们。

要获取数组的_长度_，使用`${#myarray[@]}`，并在名称前加上 `#`。
数组的“长度”指的是其中元素的个数。

要取出数组的所有_下标_，使用`"${!myarray[@]}"`，在名称前加上 `!`，并把整个展开放进双引号里。
对于数字索引数组，下标会按数字顺序展开。

### 迭代数组下标

有时你既需要值，也需要下标。
有几种办法可以做到。

1. 当你确定下标是一段连续序列时，可以使用_算术_ `for` 循环。

   ```bash
   for ((i = 0; i < ${#myarray[@]}; i++)); do
       echo "$i -> ${myarray[i]}"
   done
   ```

   注意`${#myarray[@]}`这种语法，`#`字符放在数组名前面。
   由于数组下标从 0 开始，最后一个下标比数组长度小 1。

2. 当数组是稀疏的时候，可以用这种写法：

   ```bash
   for index in "${!raindrops[@]}"; do
       echo "$index -> ${raindrops[index]}"
   done
   ```

   注意`${!myarray[@]}`这种语法，`!`字符放在数组名前面。

## 查看数组

如果你想查看数组的内容，可以使用带 `-p` 选项的`declare`命令：

```bash
a=("the 'first' element"
   second
   third
   'the "last" element')
declare -p a
```

它会以 shell 的规范引用形式输出内容。

```bash
declare -a a=([0]="the 'first' element" [1]="second" [2]="third" [3]="the \"last\" element")
```

## 关联数组

再强调一次，关联数组用字符串而不是数字作为下标。
上面讲的内容对关联数组同样适用，只是有些细微差别。
一般来说，我们用“键”而不是“下标”这个说法：关联数组把键映射到值。

### 声明关联数组

和普通数组不同，关联数组**必须**声明。
给`declare`加上 `-A` 选项（在函数内则用`local`）：

```bash
declare -A mymap

myfunc() {
    local -A my_local_map
    # ...
}
```

### 初始化关联数组

键值对写在括号里：

```bash
mymap=([first]=foo [second]=bar [third]=baz)
declare -p mymap
```

输出结果如下：

```
declare -A mymap=([second]="bar" [first]="foo" [third]="baz")
```

~~~~exercism/note
要注意，关联数组是**无序**的。
~~~~

声明和初始化可以写在同一行。

```bash
declare -A mymap=([first]=foo [second]=bar [third]=baz)
```

在较新的 Bash 版本中，初始化可以写成`(key value key value ...)`这种形式。

```bash
declare -A mymap=(first foo second bar third baz)
```

### 访问值

访问元素用的还是前面那套语法：`${mymap[$key]}`。

关联数组的键不会在算术上下文中求值。
必须使用常规的参数展开语法。

### 给关联数组赋值

赋值用的还是前面那套语法：

```bash
mymap[$key]="$value"
```

### 迭代

你可以用`for value in "${mymap[@]}"`循环来迭代。
不过，你通常还想把键和值一起拿到。

使用前面见过的`"${!mymap[@]}"`语法。

```bash
for key in "${!mymap[@]}"; do
    echo "$key -> ${mymap[$key]}"
done
```

输出结果为

```
second -> bar
first -> foo
third -> baz
```

再次强调，键之间没有顺序。
