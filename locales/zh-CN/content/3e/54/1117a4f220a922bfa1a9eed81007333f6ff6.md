# 测试

如果你用 CLI 工具下载了一个练习，就会看到一个以该练习命名的 Uiua 文件，以及一个`tests.ua`文件。
这个文件包含所有测试用例，它们与你上传提交的解答时测试运行器所运行的用例一致。
你还可以随意添加额外的测试用例来做实验。
不过，修改测试不会影响在线测试运行器的流程。

## 本地测试

要运行某个练习的测试，请先在练习所在目录中打开终端，再运行`uiua test tests.ua`命令。

例如，未修改过的`hello-world`练习，输出可能像这样：

```bash
$ uiua test tests.ua
Error: Goodbye, Mars!
  at tests.ua:3:1
3 | ⍤⤙≍ "Hello, World!" Hello
    ─
Test failed
```

`Error`行显示的是代码实际的输出。
行号指出预期结果在`tests.ua`中的位置。
提交的解答正确时，会输出：

```bash
$ uiua test tests.ua
Test passed
```
