# 说明

在本练习中，你将为一家美容院开发一个预约安排程序。

你有三个任务，它们都与预约日期有关。

## 1. 检查预约时间是否已经过去

实现`appointment_has_passed`子程序，它接收一个日期字符串，并检查该预约时间是否已经过去：

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

日期字符串会以 ISO 8601 日期时间格式传入：`YYYY-mm-ddTHH:MM:SS`

你需要实现私有的`_parse_datetime`子程序。
这里为你推荐两个模块：

- [Time::Piece][time-piece] 是 Perl 的核心模块。
- [DateTime::Tiny][datetime-tiny] 可从 CPAN 获取。

## 2. 检查预约是否在下午

实现`is_afternoon_appointment`函数，它接收一个日期字符串，并检查该预约是否在下午（>= 12:00 且 < 18:00）：

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. 描述预约的时间和日期

实现`describe_appointment`函数，它接收一个日期字符串，并返回对该日期和时间的描述：

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

注意，小时的范围是 0-12，没有前导零或空格。

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
