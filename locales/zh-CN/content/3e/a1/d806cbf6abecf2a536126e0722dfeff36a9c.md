# 简介

在 C# 中，`string`是一个对象，它将不可变文本表示为 Unicode 字符（字母、数字、标点符号等）的序列。双引号用于定义`string`实例：

```csharp
string fruit = "Apple";
```

字符串通过调用其方法来操作。字符串一旦创建，它的值就永远无法改变。任何看似会修改字符串的方法，实际上都会返回一个新字符串。

多个字符串可以拼接（相加）在一起。要做到这一点，最简单的方法是使用`+`运算符。

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

对于比简单拼接更复杂的字符串格式化，首选字符串内插。要在字符串中使用内插，请在它前面加上美元符号（`$`）。然后，你可以使用大括号（`{}`）来访问字符串中的任何变量。

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
