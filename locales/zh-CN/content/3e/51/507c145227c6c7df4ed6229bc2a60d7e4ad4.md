## 简介

指针是一种变量或常量，它的值是另一个变量或常量的地址。
指针是 C 语言中强大、同时也可能很危险的一个特性。
理解指针可能并不容易。

变量和常量把它们的值存储在某个内存位置中。
这个内存位置就称为该变量或常量的地址。

要获取一个变量的地址，我们使用取地址运算符，也就是`&`。
```c
int i = 5;
int *i_address = &i;
```

一个类型后面跟一个`*`，再跟一个标识符，就是声明指向该类型变量的指针的写法。
`*`被称为间接运算符，因为它间接地指向该指针所保存地址对应的值。

当我们这样创建一个数组时

```c
int my_ints[] = {1, 2};
```

`my_ints`的值实际上就是它的地址，而这个地址恰好也和它第一个元素的地址相同。
它第二个元素的地址，就是第一个元素的地址加上一个`int`在当前系统上的大小。

这就是指针要声明为某个特定类型的原因。
如果指针不知道自己指向的是什么类型，那么在对它加`1`时，它就不知道应该前进多少个字节。
对指针加`1`并不一定意味着给地址加上一个字节。
它的意思是加上`1`乘以该类型以字节为单位的长度。
