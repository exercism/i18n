# 补充说明

## 寄存器

| 寄存器   | 用途 | 类型 | 说明                                                                        |
| -------- | ---- | ---- | --------------------------------------------------------------------------- |
| `$a0`    | 输入 | 整数 | 边 a                                                                        |
| `$a1`    | 输入 | 整数 | 边 b                                                                        |
| `$a2`    | 输入 | 整数 | 边 c                                                                        |
| `$v0`    | 输出 | 整数 | 三角形的类型（`0` 表示不等边，`1` 表示等腰，`2` 表示等边，`3` 表示无效）    |
| `$t0-9`  | 临时 | 任意 | 用于临时存储                                                                |
