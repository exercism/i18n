# 说明

准魔术师 Elyse 继续她的训练。她会拿到好几叠牌，用来完成她的魔术。
为了让事情简单一些，她只用 1 到 10 这些牌。

在这个练习中，使用内置方法来分析数组的内容。

## 1. 找出某张牌的位置

Elyse 想知道某张牌在牌堆中的位置（下标）。

```javascript
const card = 2;
getCardPosition([9, 7, 3, 2], card);
// => 3
```

## 2. 判断某张牌是否存在

Elyse 想判断某张牌是否在牌堆中，换句话说，牌堆中是否包含某个特定的`number`。

```javascript
const card = 3;
doesStackIncludeCard([2, 3, 4, 5], card);
// => true
```

## 3. 判断每张牌是否都是偶数

Elyse 想知道是否每张牌都是偶数，换句话说，牌堆中的每个`number`是否都是偶数。

```javascript
isEachCardEven([2, 4, 6, 7]);
// => false
```

## 4. 检查牌堆中是否有奇数牌

Elyse 想知道牌堆中是否有奇数。

```javascript
doesStackIncludeOddCard([3, 2, 6, 4, 8]);
// => true
```

## 5. 获取牌堆中第一张奇数牌

Elyse 想知道第一张奇数牌的值。

```javascript
getFirstOddCard([4, 2, 8, 7, 9]);
// => 7
```

## 6. 找出第一张偶数牌的位置

Elyse 想知道第一张偶数牌的位置。

```javascript
getFirstEvenCardPosition([5, 2, 3, 1]);
// => 1
```
