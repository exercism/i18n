# 介绍

**word**是 Factor 对函数的称呼。这个概念从`basics`的数据栈出发，讲的是如何定义你自己的 word：做算术、给固定值命名，以及用其他 word 组合出新的 word。

定义时先写`:`，接着写出栈效果，然后是主体，最后写`;`。编译器会检查主体是否与声明的效果相符：

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

整数算术 word`+`、`-`、`*`都会弹出两个数字，再压入结果。它们属于`math`词汇表，所以用到它们的文件要在`USING:`那一行里写上`math`。栈顶是右边的操作数：

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:`用来给固定值命名。常量本身也是一个 word，调用它就会把这个值压栈：

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

一个 word 的主体可以调用任何已在作用域内的 word，包括你在同一文件里更早定义的那些：

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

栈效果输出部分末尾的`?`是表示“布尔值”的约定，word 和常量都使用`lowercase-kebab-case`。
