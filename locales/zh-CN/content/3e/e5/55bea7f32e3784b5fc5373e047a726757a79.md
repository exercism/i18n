# 说明

你的镇上有好几家披萨店，你想写一个网页应用，用来比较两种不同的披萨配置，看看哪家给你的切片更大。

## 1. 编写一个计算切片大小的函数，对无效输入返回 nil

实现函数`sliceSize(diameter: Double?, slices: Int?) -> Double?`：给定一张披萨的直径和它切成的片数，返回切片的面积。
对于负的直径，以及小于 1 的片数，返回`nil`，因为不存在直径为负数的披萨，也无法把一张披萨切成少于 1 片。
如果任一参数为`nil`，也返回`nil`。

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. 处理来自网页应用的输入，判断哪片更大

你的网页应用会向函数`biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`传入四个字符串。
第一个和第二个字符串分别是第一张披萨的直径和片数，第三个和第四个分别是第二张披萨的直径和片数。

实现`biggestSlice`，让它尝试把每张披萨的直径和片数分别转换成`Double`和`Int`。
如果这两个值都能从字符串中得到，就用第一个函数尝试算出面积，否则该切片的面积就是`nil`。
得到两片切片的面积后，按照下面的规则比较这两个面积：

1. 如果切片 A 的面积是`Double`，而切片 B 的面积为`nil`，返回“Slice A is bigger”。如果情况相反，返回“Slice B is bigger”。
2. 如果两个面积都是`Double`s，根据哪片面积更大，返回“Slice A is bigger”或“Slice B is bigger”。
3. 如果两个面积都是`nil`，或者两个都是`Double`s且相等，返回“Neither slice is bigger”。

~~~~exercism/note
即使输入算出的切片面积为 0，该切片仍然算作有效，并且应当被视为比面积为`nil`的切片更大。
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
