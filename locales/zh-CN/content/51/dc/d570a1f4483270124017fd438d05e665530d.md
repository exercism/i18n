# 简介

使用`~c` Sigil 创建字符列表。

```elixir
~c"hello"
```

~~~~exercism/note
注意，在旧版本的 Elixir 中，字符列表用一对单引号表示成`'hello'`。
~~~~

字符列表看起来和字符串很像，但这两种数据类型其实差别很大。字符列表是整数组成的数组，这些整数表示某个字符的 Unicode 值，也就是码点。

```elixir
[65, 66, 67]
# => ~c"ABC"
```

在字符前面加上`?`，就能得到它的码点。

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

因为字符列表本身就是数组，所以你可以像处理其他任何数组一样处理它，比如用递归和模式匹配。

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

用`++`可以把两个数组拼接起来。

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

第一个数组越长，拼接就越慢，所以要避免反复往任意长度的数组末尾追加内容。
