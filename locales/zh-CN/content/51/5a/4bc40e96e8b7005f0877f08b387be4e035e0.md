# 说明

在这个练习中，你将编写代码，为工厂员工打印工牌。

## 1. 为员工打印工牌

员工有编号、姓名和部门名称。
员工工牌标签的格式如下：`"[id] - name - DEPARTMENT"`。
实现`printBadge()`方法，返回员工的工牌标签：

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
注意，标签上的部门名称应大写。
~~~~

## 2. 为新员工打印工牌

由于计算机系统的一个小毛病，新员工在工厂开始工作时，有时还没有编号。
由于必须佩戴工牌，他们会获得一个不带编号前缀的临时工牌。
修改`printBadge()`方法，以支持还没有编号的新员工：

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. 为老板打印工牌

即使是工厂老板也必须始终佩戴工牌。
不过，老板没有部门。
这种情况下，标签上应打印`"OWNER"`，而不是部门名称。
修改`printBadge()`方法，为老板打印标签：

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
注意，老板也可能是新员工：

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
