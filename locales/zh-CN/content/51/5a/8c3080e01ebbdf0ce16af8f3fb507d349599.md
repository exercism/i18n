# 简介

`Agent`模块为生成[进程和“接收-发送”循环][exercism-processes]提供了一种抽象。接下来，我们把通过`Agent`模块启动的进程称为“agent 进程”。我们可以用一个 agent 进程来表示中心的共享状态。

要启动一个 agent 进程，`Agent`模块提供了`start/2`函数。用`start`启动 agent 进程时传入的那个函数，会返回该进程的初始状态：

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

和`Map`、`List`一样，`Agent`也提供了许多用于操作 agent 进程的函数。

通常的做法是，把与`Agent`相关的全部功能都整理并封装进为所建模领域创建的一个模块里。

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
