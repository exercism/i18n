# 关于

当你需要*修改*序列时，Factor 的序列有两种形式：

- **数组**（`{ … }`）长度固定。你可以用`set-nth` / `change-nth`修改某个位置*上*的元素，但无法让数组变长或变短。
- **向量**（`V{ … }`）长度可变。`push`向末尾添加元素，`pop`移除并返回最后一个元素。

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| 词              | 作用                                           |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`，由`n`个`elt`副本组成的数组 |
| `<vector>`      | `( n -- vector )`，容量为`n`的空向量            |
| `V{ }`          | 空向量字面量                                   |
| `set-nth`       | `( elt n seq -- )`，给下标为`n`的元素赋值       |
| `change-nth`    | `( i seq quot -- )`，对下标为`i`的元素应用`quot` |
| `push`          | `( elt seq -- )`，向向量末尾追加                |
| `suffix!`       | `( seq elt -- seq )`，原地追加，返回该向量      |
| `pop`           | `( seq -- elt )`，移除并返回最后一个元素        |
| `pop*`          | `( seq -- )`，移除最后一个元素并丢弃            |
| `clone`         | `( obj -- copy )`，全新的独立副本               |
| `new-sequence`  | `( n exemplar -- newseq )`，与`exemplar`同类的新序列 |
| `new-resizable` | `( n exemplar -- newseq )`，可调整大小的新变体  |

当你修改调用者传入的序列时，改动对调用者可见，因为他们持有的是同一个对象。如果你不需要这种效果，先用`clone`得到一份独立的副本。
