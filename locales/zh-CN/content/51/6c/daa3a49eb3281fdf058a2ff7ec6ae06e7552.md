# 简介

## Pair 类型

`Pair`就是把两个项组合在一起。这两个项则被形象地称为`first`和`second`。

你可以用`=>`运算符或`Pair()`构造函数来创建它们。

```julia-repl
julia> p1 = "k" => 2
"k" => 2

julia> p2 = Pair("k", 2)
"k" => 2

# Both forms of syntax give the same result
julia> p1 == p2
true

# Each component has its own separate type
julia> dump(p1)
Pair{String, Int64}
  first: String "k"
  second: Int64 2

# Get a component using dot syntax
julia> p1.first
"k"

julia> p1.second
2
```

## Dict 类型

由 Pair 构成的`Vector`和其他任何数组一样：有序、类型一致，并且在内存中连续存储。

```julia-repl
julia> pv = ['a' => 1, 'b' => 2, 'c' => 3]
3-element Vector{Pair{Char, Int64}}:
 'a' => 1
 'b' => 2
 'c' => 3

# Each pair is a single entry
julia> length(pv)
3
```

`Dict`表面上很相似，但它的存储实现方式允许按键快速查找，即使条目数量变得很大。

```julia-repl
julia> pd = Dict('a' => 1, 'b' => 2, 'c' => 3)
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

julia> pd['b']
2

# Key must exist
julia> pd['d']
ERROR: KeyError: key 'd' not found

# Generators are accepted in the constructor (and note the unordered output)
julia> Dict(x => 1 / x for x in 1:5)
Dict{Int64, Float64} with 5 entries:
  5 => 0.2
  4 => 0.25
  2 => 0.5
  3 => 0.333333
  1 => 1.0
  ```

在其他语言里，和`Dict`非常相似的东西可能叫字典（Python）、Hash（Ruby）或 HashMap（Java）。

对于 Pair，无论单独出现还是放在 Vector 里，对每个组成部分的类型都没有太多限制。

要想在`Dict`中有效，`Pair`必须是`key => value`键值对，其中`key`必须是“可哈希的”。最重要的一点是，这意味着`key`必须是_不可变的_，所以`Char`、`Int`、`String`、`Symbol`和`Tuple`都可以，但不允许使用`Vector`。

### 修改 Dict

条目可以用新的键添加，也可以用已有的键覆盖。

```julia-repl
julia> pd
Dict{Char, Int64} with 3 entries:
  'a' => 1
  'c' => 3
  'b' => 2

# Add
julia> pd['d'] = 4
4

# Overwrite
julia> pd['a'] = 42
42

julia> pd
Dict{Char, Int64} with 4 entries:
  'a' => 42
  'c' => 3
  'd' => 4
  'b' => 2
```

要删除某个条目，可以使用`delete!()`函数：如果键存在，它会修改 Dict，否则会静默地什么都不做。

```julia-repl
julia> delete!(pd, 'd')
Dict{Char, Int64} with 3 entries:
  'a' => 42
  'c' => 3
  'b' => 2
```

### 检查键或值是否存在

有几种不同的做法。要检查某个键，可以使用`haskey()`函数：

```julia-repl
julia> haskey(pd, 'b')
true
```

也可以改为在键或值中查找：

```julia-repl
julia> 'b' in keys(pd)
true

julia> 43 in values(pd)
false

julia> 42 ∈ values(pd)
true
```
