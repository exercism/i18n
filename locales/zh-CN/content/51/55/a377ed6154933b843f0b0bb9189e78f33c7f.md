# 简介

循环用于重复执行一组语句。每执行一遍这组语句，称为一次迭代。

## `while` 循环

`while` 循环会在循环顶部的布尔表达式为 true 时执行一组语句。当布尔表达式为 false 时，循环停止运行，程序从循环后面的下一行代码继续执行。

如果布尔表达式一开始就为 false，`while` 循环根本不会执行，程序直接从循环后面的下一行代码继续。

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

循环必须要有一个结束条件，否则就会变成无限循环，代码将无法继续向下执行。如果上面的代码去掉了 `i` 上的 `++`，就会变成无限循环。

## `do` 循环

`do` 循环的布尔表达式在循环底部进行检查。`do` 循环至少会执行一次，如下例所示

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

换成 `while` 循环来写，就啰嗦得多

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## `for` 循环

循环常常需要更新一个变量，并在变量达到某个值时结束。`for` 循环可以在一行中用括号一次性初始化、更新和检测一个或多个变量。第一部分用于初始化变量，第二部分用于检测变量，第三部分用于更新变量的值。

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

这比等价的 `while` 循环简洁，而且依然易读。
