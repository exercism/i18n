# 匹配基础

`match`表达式可以方便地把一个值与一系列模式逐一比较，然后根据匹配到的模式运行相应的代码。模式可以由字面量、变量名、通配符以及许多其他内容构成。

```rust
#[derive(Drop)]
enum Color {
    Red,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red => println!("The color is Red"),
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Yellow;
    print_color_type(color); // prints "The color is Yellow"
}
```

如果某个分支需要运行多行代码，就用大括号`{}`把它包起来：

```rust
fn specified_color(color: Color) -> felt252 {
    let mut response: felt252 = '';

    match color {
        Color::Red => {
            response = 'You passed in Red';
        },
        Color::Yellow => {
            response = 'You passed in Yellow';
        },
        Color::Green => {
            response = 'You passed in Green';
        },
    }

    response
}
```

`match`表达式还有一个功能：可以绑定到匹配该模式的值。这样就能取出枚举变体携带的关联值。

```rust
#[derive(Drop, Debug)]
enum ColorType {
    Light,
    Dark,
}

#[derive(Drop)]
enum Color {
    Red: ColorType,
    Yellow,
    Green,
}

fn print_color_type(color: Color) {
    match color {
        Color::Red(state) => {
            println!("The color is Red");
            println!("The Color Type is {:?}", state);
        },
        Color::Yellow => println!("The color is Yellow"),
        Color::Green => println!("The color is Green"),
    }
}

fn main() {
    let color = Color::Red(ColorType::Dark);
    print_color_type(color);
}
```

这里把`Color`枚举的`Red`变体扩展为携带一个关联枚举。借助`match`表达式，我们可以取出这个关联值，也就是`state`。它只是一个变量名，之后可以在该分支的代码里使用。

## 匹配`Option`枚举类型

内置的`Option`枚举同样可以用`match`表达式处理。

我们来设计一个函数，它接收一个`Option<u8>`参数。如果传入的参数里有值，就把这个值加一；否则函数不做任何操作，返回`None`值。

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
        Option::None => Option::None,
    }
}

fn main() {
    let three: Option<u8> = Option::Some(3);
    let four: Option<u8> = add_one(three);
    let none = add_one(Option::None);

    println!("{three:?}"); // prints "Option::Some(3)"
    println!("{four:?}"); // prints "Option::Some(4)"
    println!("{none:?}"); // prints "Option::None(())"
}
```

> 注意：`{:?}`是一种特殊的格式化语法，可以打印传给`println!`宏的参数的调试形式。
> 更多相关信息请参阅 [The Cairo Book][debugging]。

使用`match`控制流的一个好处是它的穷尽性：每个分支的模式必须覆盖_所有_可能的情况。看看前面那个例子中没有处理`None`情况的版本：

```rust
fn add_one(x: Option<u8>) -> Option<u8> {
    match x {
        Option::Some(val) => Option::Some(val + 1),
    }
     // this code does not compile, as we forgot to handle the `None` case
}
```

## 使用`_`通配符的兜底模式

使用枚举时，我们还可以对少数几个特定的值采取特殊操作，而对其他所有值执行同一个默认操作，只要在`match`表达式的最后一个分支里用`_`作为模式即可。`_`是一种特殊模式，它能匹配任何值，但不会绑定到该值。

`is_red`函数接收一个参数，如果颜色是`Red`就返回`true`，是其他颜色则返回`false`：

```rust
fn is_red(color: Color) -> bool {
    match color {
        Color::Red => true,
        _ => false,
    }
}
```

## 用`|`运算符进行模式匹配

Cairo 的`match`控制流结构允许用`|`（_或_）运算符把一个值与多个模式进行匹配，这有助于简化代码。

例如，对于`Color`枚举，我们想写一个函数：颜色是`Red`或`Green`时返回`true`，其他颜色返回`false`：

```rust
fn is_red_or_green(color: Color) -> bool {
    match color {
        Color::Red | Color::Green => true,
        _ => false,
    }
}
```

## 用`felt252`和整数变量进行模式匹配

`felt252`和整数变量可以针对一组值进行匹配。不过有一些限制；

- 只支持能放进单个`felt252`的整数（也就是说，不支持`u256`）。
- 0 必须是第一个分支。
- 各分支必须构成连续的一段，彼此相邻。

我们来写一个掷六面骰子的小游戏。掷出骰子后，会得到一个 0 到 5 之间的数字。掷出 0、1 或 2，你赢了。掷出 3，可以再掷一次。其他值就输了：

```rust
fn toss(value: u8) {
    match value {
        0 | 1 | 2 => println!("you won!"),
        3 => println!("you can roll again!"),
        _ => println!("you lost...")
    }
}

fn main() {
    toss(2); // prints "you won!".
    toss(3); // prints "you can roll again!".
    toss(5); // prints "you lost...".
}
```

## 匹配元组

元组也可以针对一组模式进行匹配。这些模式的写法和元组本身类似。

```rust
#[derive(Drop)]
enum DayType {
    Week,
    Weekend,
    Holiday
}

enum Coin {
    Penny,
    Nickel,
    Dime,
    Quarter,
}

fn vending_machine_accept(c: (DayType, Coin)) -> bool {
    match c {
        (DayType::Week, _) => true, // accepts all coins during week day
        (_, Coin::Dime) | (_, Coin::Quarter) => true, // accepts only Dime or Quarter coin for all specified days
        (_, _) => false, // returns false for other instances
    }
}
```

在最后一个分支里，用`(_, _)`还是只用`_`通配符来匹配任意的日期与颜色组合都无所谓，因为它们在功能上是一样的。
