# 关于

在 Clojure 中，把一个值绑定到一个名字上称为 [_var_][vars]。顶层（全局）var 类似于其他语言中的常量，但通常会被重新定义，以便进行动态开发。

顶层 var 使用 [`def`][def] 定义：

```clojure
(def fingers 10)
```

你可以使用核心函数来进行[数字运算][operators]，对值执行算术操作。

`defn` 宏可以用来定义一个接受零个或多个实参的[函数][functions]。函数总是返回其函数体中最后一个表达式的结果。

```clojure
(defn add [x y]
  (+ x y))
```

调用一个函数，就是写出它的名字，并为函数的每个形参传入实参。

```clojure
(def five (add 2 3))
```

Clojure 中的函数和值只能在定义_之后_使用。在定义之前就使用它，会导致编译错误。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

在 Clojure 中，空白除了用于排版之外没有任何意义。

Clojure 的函数和 var 按命名空间组织。命名空间把相关的功能归为一组，使用 `ns` 宏定义：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支持两种注释。单行注释以 `;` 开头，而 `comment` 形式用于阻止对 `(comment` 和 `)` 之间的所有内容求值。
