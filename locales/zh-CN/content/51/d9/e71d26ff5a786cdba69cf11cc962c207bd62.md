# 说明

你的任务是解出一个二进制谜题。
每个二进制谜题都恰好有 _一个_ 解，应用以下规则就能找到它：

1. 每个格子都必须填入 0 或 1。
2. 不能有三个或更多相同的数字相邻。因此，如果两个相邻的格子含有相同的数字，那么紧挨着它们的格子必须含有另一个数字。
3. 每一行和每一列都必须包含相同数量的 0 和 1。
4. 每一行和每一列都互不相同。

你拿到的谜题是未完成的，由多行 0 和 1 组成，未知的值用占位符（`_`）表示。
目标是定义这个二进制谜题的规则，好让测试推断出占位符的值（这一步不需要你来做）。
你的实现必须使用 Prolog 的[有限域约束逻辑编程（CLP(FD)）](https://www.swi-prolog.org/man/clpfd.html)，它非常适合这类任务。

````exercism/note

```prolog
:- use_module(library(clpfd)).
```
````
