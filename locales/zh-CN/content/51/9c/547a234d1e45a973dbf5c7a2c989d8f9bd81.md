# 说明

在这个练习里，你会玩一辆遥控车，你终于攒够了钱把它买下来了。

车一开始的电池是满的（100%）。每次你用遥控器驾驶这辆车，它都会行驶 20 米，并消耗 1% 的电量。

这辆遥控车有一个酷炫的 LED 显示屏，可以显示两项信息：

- 它总共行驶的距离，显示为：`"Driven <METERS> meters"`。
- 剩余电量，显示为：`"Battery at <PERCENTAGE>%"`。

如果电量为 0%，你就不能再驾驶这辆车了，电量显示屏会显示 `"Battery empty"`。

你有六个任务，每个任务都会用到遥控车实例。

## 1. 购买一辆全新的遥控车

实现（_静态_）`RemoteControlCar.Buy()` 方法，返回一个全新的遥控车实例：

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. 显示行驶的距离

实现 `RemoteControlCar.DistanceDisplay()` 方法，返回 LED 显示屏上显示的距离：

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. 显示电池百分比

实现 `RemoteControlCar.BatteryDisplay()` 方法，返回 LED 显示屏上显示的电池百分比：

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. 驾驶时更新行驶的米数

实现 `RemoteControlCar.Drive()` 方法，更新行驶的米数：

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. 驾驶时更新电池百分比

更新 `RemoteControlCar.Drive()` 方法，让它更新电池百分比：

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. 电池耗尽时禁止驾驶

更新 `RemoteControlCar.Drive()` 方法，让它在电池耗尽（为 0%）时既不增加行驶的距离，也不减少电池百分比：

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
