# 简介

## 可空性

在 Java 中，`null`字面量用来表示值的缺失。

Java 中的基本数据类型都有默认值，因此永远不可能是`null`。按照约定，它们以小写字母开头，例如`int`。

引用类型保存的是对象的内存地址，其值可以是`null`。它们通常以大写字母开头，例如`String`。

如果试图把`null`赋值给基本类型变量，就会导致编译时错误，因为该变量始终保存着其所属类型的基本类型值。

```java
//Throws compile time error stating the required type is int, but null was provided
int number = null;
```

把`null`赋值给引用变量不会导致编译时错误，因为引用变量是可空的。

```java
//No error will occur as the String variable str is nullable
String str = null;
```
