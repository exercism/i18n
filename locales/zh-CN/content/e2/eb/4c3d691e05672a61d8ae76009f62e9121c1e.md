# 简介

## 类型转换

类型转换有时也叫强制类型转换。
类型转换是指为了执行某种运算，把两个不同类型的值转换成同一类型。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

这种转换可以隐式进行（见上面的例子），也可以用 `C` 风格的强制类型转换显式完成：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手动强制类型转换允许的类型有：`bool`、`int`、`float`、`string`、`array`、`object`。
最常见的情况是用强制类型转换把整数（`int`）变成浮点数（`float`），或者反过来。
