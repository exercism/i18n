# Nil

Crystal 有一种类型叫做[`Nil`][nil]，它只能有一个值：`nil`。
它用来表示值的缺失，类似于其他语言中的`null`或`None`。

许多方法都可能返回 Nil 值，例如[`String#[]?`][string-index]，当索引越界时它会返回`nil`。

```crystal
"foo"[10]? # => nil
```

Crystal 有所谓的**空引用检查**，这意味着默认情况下所有类型都不能为 nil。
也就是说，除非你显式地把变量声明为`Nil`类型，否则不能把`nil`赋给它。
反过来，这意味着编译器会自动检查空引用。

## 假值

处理`nil`值有几种办法。
`nil`和`false`一样，都是[假值][truthy-falsey]。
这意味着，在语句以及其他需要真值或假值的地方，它都会被当作`false`来处理。

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

这意味着，如果一个可为 nil 的变量的值是`nil`，就不会进入真值分支。

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## 检查是否为 nil

Crystal 有一个方法可以用来检查某个值是否为`nil`。
它叫做[`nil?`][nil?]，所有对象都可以使用。

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

如果只是把这个值用在`if`语句里，情况会有些不同：在上面的例子里，`false`和`nil`都会被当作假值。
而在这里，只有`nil`会被当作假值，因为如果它是`false`，那它就不是`nil`，因此会是真值。

## or 运算符

处理`nil`值最简单的办法，就是从一开始就确保它们不会变成`nil`。
or 运算符（[`||`][or]）常用于处理`Bools`，但只要理解正确，它也可以用来处理`nil`值。
or 运算符会检查第一个值是否为真值，如果不是，就使用第二个值。
这样，如果值是`nil`，它就是假值，于是会使用第二个值。

```crystal
"foo"[10]? || "bar" # => "bar"
```
