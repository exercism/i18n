# 调试

运行每个测试时，Red 脚本的所有输出都会显示在控制台里。你想打印什么都可以用`print`，比如单词的值：

```red
print ["x =" x]
```

另外，`probe`函数也非常有用。对它求值时，它会先对输入求值，然后以能反映其类型的方式打印结果，最后把结果返回。所以在大多数情况下它是“透明”的，可以把它直接插进表达式里：

```red
x: 10
y: probe x + 5
```

有时，一个名为`type?`的函数（没错，它的名字里确实有问号！）可以用来检查值的类型：

```red
print ["x type:" type? x]
```

还有一些更高级的调试技巧，[列在 Red 的 Wiki 上](https://github.com/red/red/wiki/%5BDOC%5D-Debugging)。
