# 提示

## 通用

- Go 中的切片下标从 0 开始。
  切片里的第一个下标是`0`。
- 内置的[`append`][append-builtin]函数是[`variadic`][variadic-gobyexample]的
- 可以使用三个点（...）表示法，把一个切片的元素追加到另一个切片：

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. 创建包含特定卡牌的切片

- 要创建一个预先填充了一些数据的切片，请使用切片字面量语法：`s := []T{x1, x2, ..., xn}`。

## 2. 从牌堆中取出一张卡牌

- 要获取切片的第`n`项，[使用下标][go-slices]。
- 要检查切片中是否存在某一项，请使用条件判断，并把下标与[切片的长度][len-builtin]进行比较。

## 3. 交换牌堆中的一张卡牌

- 要设置切片中的第`n`项，[使用下标][go-slices]并给它赋一个新值。
- 要在切片的末尾添加一项，请使用`append`函数。

## 4. 把卡牌添加到牌堆顶部

- 要把元素添加到切片的前面，可以把原切片的元素追加到`value`实参切片中。

## 5. 从牌堆中移除一张卡牌

- 要从切片中移除一项，可以把`index`之后的部分追加到 index 之前的部分。
