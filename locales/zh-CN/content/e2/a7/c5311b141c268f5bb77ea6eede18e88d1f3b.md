# 提示

## 通用

- 一个[整数值][integers]可以定义为一个或多个连续的数字。
- 如果运行测试时看到`panic:`错误，说明你还没有实现某个函数（错误信息里会指出是哪一个），或者你还没有删掉模板代码。你需要从给出的代码中删掉`panic(...)`那一行，换成真正的实现。

## 1. 定义烤箱的预期用时（分钟）

- 你需要定义一个[常量][constants]，并把烤箱的预期用时（分钟）赋给它。
- 如果你看到`undefined: OvenTime`错误，请再确认一下你是否定义了这个常量。
- 如果你看到`invalid operation: got != tc.expected (mismatched types float64 and int)`错误，很可能是你在`OvenTime`里写了小数点，导致 Go 把类型推断成浮点数。去掉小数点，类型就会被推断为`int`。
- 如果你看到`syntax error: non-declaration statement outside function body`错误，很可能是你忘了写`const`关键字。
- 如果你看到`syntax error: unexpected :=, expecting =`错误，很可能是你想用`:=`像变量那样给常量赋值；常量要用`=`赋值，而不是`:=`。

## 2. 计算剩余的烤箱用时（分钟）

- 你需要定义一个带单个形参的[函数][functions]。
- 函数必须[显式返回一个整数][return]。
- 函数的形参是[整数][integers]。
- 你可以[调用][calls]之前定义过的其他函数。
- 你可以使用[减法运算符][operators]来相减。

## 3. 计算准备用时（分钟）

- 你需要定义一个带单个形参的[函数][functions]。
- 函数必须[显式返回一个整数][return]。
- 函数的形参是[整数][integers]。
- 你可以使用[乘法运算符][operators]来相乘。

## 4. 计算已用的工作用时（分钟）

- 你需要定义一个带两个形参的[函数][functions]。
- 函数必须[显式返回一个整数][return]。
- 函数的形参是[整数][integers]。
- 你可以[调用][calls]之前定义过的其他函数。
- 你可以使用[加法运算符][operators]来相加。
