# 说明补充

## 输出格式

每种国籍都用一个字母表示。（`E` = `Englishman`，`J` = `Japanese`，`N` = `Norwegian`，`S` = `Spaniard`，`U` = `Ukrainian`）

## 寄存器

| 寄存器 | 用途     | 类型    | 说明                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | 输出    | 字节    | 喝水者的国籍 |
| `$v1`    | 输出    | 字节    | 养斑马者的国籍   |
| `$t0-9`  | 临时 | 任意     | 用于临时存储        |
