# 说明

在这个练习中，你是一位狂热的体育迷，刚刚发现自己迷上了 NBA 篮球。
作为 NBA 篮球的新手，你正在深入研究 NBA 的历史，追踪各支球队、教练以及他们的胜负数据，并把它们相互比较。

由于你还没有最喜欢的球队，你还要开发一个算法，来判断某支球队是否值得支持。
你有 7 个任务来帮你开发这套专属的_支持某支球队_算法。

## 1. 定义模型

定义一个`Coach`类型别名，表示一个包含以下两个字段的记录，字段顺序如下：

- `name`：教练的名字，类型为`String`。
- `formerPlayer`：表示该教练是否曾是球员，类型为`Bool`。

定义一个`Stats`类型别名，表示一个包含以下两个字段的记录，字段顺序如下：

- `wins`：胜场数，类型为`Int`。
- `losses`：负场数，类型为`Int`。

定义一个`Team`类型别名，表示一个包含以下三个字段的记录，字段顺序如下：

- `name`：球队的名字，类型为`String`。
- `coach`：球队的教练，类型为`Coach`。
- `stats`：球队的数据，类型为`Stats`。

## 2. 创建球队

你想与一些第三方代码对接，它们有球队的概念，但调用你的代码时实参的顺序不一样。添加一个`createTeam`函数，签名为`String -> Stats -> Coach -> Team`。

## 3. 更换教练

NBA 的老板们没什么耐心，你发现球队战绩不好，往往会导致教练被换掉。
实现`replaceCoach`函数，它接收新教练和球队作为形参，返回带上了新教练的那支球队：

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. 判断某支球队是否值得支持

将来你打算设计一套复杂的算法，来判断一支球队是否值得支持。但第一次尝试时，你决定只要一支球队的胜场数多于负场数，就支持它。

你希望这个函数能在其他场景中复用，所以在类型签名里使用可扩展记录，来接受任何包含相关字段的记录。
为了让函数尽可能简洁，你想用模式匹配从函数形参中取出`stats`。
实现`rootForTeam`函数，它接收一支球队；如果你应该支持这支球队，就返回`True`，否则返回`False`。

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
