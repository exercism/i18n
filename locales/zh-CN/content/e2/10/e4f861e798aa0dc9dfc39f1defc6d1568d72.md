# 简介

[结构体][structs-and-classes]（通常称为 *structs*）是 Swift 程序的主要构建单元之一。
结构体让你可以创建自定义类型，把相关的属性（数据）和方法（行为）组合在一起。
事实上，Swift 的标准类型，包括`Int`、`Double`、`Bool`、`String`、`Array`和`Dictionary`，都是以结构体实现的。

## 定义结构体

使用`struct`关键字定义结构体，后面跟上类型名，以及包含定义内容的大括号。
按照 Swift 的命名约定，结构体名称使用`UpperCamelCase`：

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## 创建实例

结构体定义只是一张蓝图。
要创建结构体的*实例*，就调用它的初始化器：写上类型名，后面加上一对括号：

```swift
var someStats = CharacterStats()
```

这样创建的实例，会用定义里的默认属性值填充。

Swift 还会为结构体自动生成一个**逐成员初始化器**，让你可以按名称初始化各个属性：

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## 访问和修改属性

你可以使用*点语法*来访问和修改实例的属性：

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

由于结构体是值类型，要修改实例的属性，实例本身必须用`var`声明。
如果实例用`let`声明，它的所有属性都不可变。
