# 附加说明

## 单词

定义一个`cmplx`元组，包含`real`和`imaginary`两个槽位。槽位访问器`real>>`和`imaginary>>`随元组定义一并提供，测试正是用它们来读取各个分量。

- `<cmplx> ( real imag -- cmplx )`，构造一个复数。
- `>cmplx ( pair -- cmplx )`，根据`{ real imaginary }`构造一个`cmplx`。
- `cmplx>pair ( cmplx -- pair )`，返回`{ real imaginary }`。
- `c+ ( a b -- c )`、`c- ( a b -- c )`、`c* ( a b -- c )`、`c/ ( a b -- c )`，对两个复数进行算术运算。
- `c-abs ( a -- |a| )`，绝对值（一个实数）。
- `c-conj ( a -- a* )`，复共轭。
- `c-exp ( z -- e^z )`，复指数。

Factor 的`MATH:`泛型（`+`、`-`、`*`、`/`）只在内置的数学层级结构上进行分派，因此本练习使用专门定义的名字，而不是在这些泛型上定义方法。

混合实数和复数的算术运算测试已被排除，这里每个运算都是在两个`cmplx`值之间进行的。
