# 关于

哈希是 Perl 中的一种数据类型，它包含一组无序的字符串键，每个键都与一个标量值配对。

哈希变量通常通过给它赋值一个列表来填充，例如`my %scores = (Alice => 10, Bob => 15, Charlie => 20);`。

列表中的元素通常用逗号分隔，但你经常会看到用所谓的“胖逗号”`=>`来分隔列表中的键和值。
它的行为与逗号几乎完全相同，但额外的好处是会把左侧的元素当作字符串来解释。

也可以通过给单个键赋值来填充哈希，例如`$scores{Alice} = 10;`。

访问哈希的值时，可以通过下标指定键，例如`$scores{Bob} # 15`。

哈希中的键是唯一的。
如果一个键被重复给出，只有最后给出的那个值会被保留。

## 函数

用于处理哈希的函数包括 [keys][keys] 和 [values][values]，它们分别用来把哈希中对应的部分以列表的形式取出。
[keys][keys] 和 [values][values] 函数返回的列表可以用于 [grep][grep]、[map][map]、[sort][sort] 等列表函数，也可以用于 [for][for] 循环。

其他哈希函数还包括 [exists][exists]，用于检查某个键是否存在于哈希中（即使它的值是`undef`），以及 [delete][delete]，用于从哈希中删除某个键。

## 印记的差异

获取哈希的值时，所用的印记决定了结果。
变量名末尾的下标`{}`告诉 Perl，你正在访问以这个名字命名的哈希。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

虽然这样做是允许的，但为了可读性，建议不要让不同类型的变量共用同一个名字。
