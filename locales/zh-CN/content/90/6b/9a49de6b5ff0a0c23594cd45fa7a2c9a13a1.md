# 说明

ESA（Exercism Space Agency）正在全速规划一次前往火星卫星 [Phobos][phobos] 的新任务。这次任务的目标是让探测器降落在 Phobos 表面，并回传有关该表面的数据。ESA 请你帮忙为探测器构建导航计算机。导航计算机的内存有限，所以我们需要让内存占用尽可能低。因此，我们需要使用合适的数据类型。

## 1. 导航常量

导航计算机需要知道太空中某些物体之间的距离，才能进行正确的计算。距离以千米为单位。

定义以下常量：

- `NEPTUNE_DISTANCE`的值为`4_400_000_000`，应存储为`Int64`
- `MARS_DISTANCE`的值为`227_940_000`，应存储为`Int32`
- `ATMOSPHERE_DISTANCE`的值为`10_000`，应存储为`Int16`

## 2. 修正面积分析

导航计算机需要知道太空中某些物体的面积，才能进行正确的计算。
面积**不能**为负数。
工程师原本计划让程序在面积为负数时产生溢出错误。
但是，工程师忘了把有符号整数改成无符号整数。

因此，工程师希望有一个能把有符号整数转换为无符号整数的程序。

实现`Navigation#correct_area_analysis`方法，它接受一个`measurement`作为实参，并返回 32 位无符号整数形式的面积。

~~~~exercism/note
给定的面积总能放进一个 32 位的无符号整数。
~~~~

```crystal
measurement = 52554
measurement.class
# => Int32

Navigation.new.correct_area_analysis(measurement)
# => 52554

Navigation.new.correct_area_analysis(measurement).class
# => UInt32
```

## 3. 计算速度

导航计算机需要知道探测器的速度。
速度以 m/s 为单位。

要计算速度，我们需要知道所走的距离，以及走完这段距离所用的时间。
然后用距离除以时间。

速度不必非常精确，而且永远不会是一个很大的数。
因此，我们可以使用`Float32`。

实现`Navigation#calculate_velocity`方法，它接受`distance`和`time`作为实参，并返回 32 位`Float`形式的速度。

```crystal
distance = 52554
time = 2.5

Navigation.new.calculate_velocity(distance, time)
# => 21021.6

Navigation.new.calculate_velocity(distance, time).class
# => Float32
```
