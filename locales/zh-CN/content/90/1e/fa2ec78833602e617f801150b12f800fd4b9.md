# 简介

F# 中的`array`是一个可变的集合，可以包含 0 个或多个值，长度固定。这意味着数组一旦创建，大小就不能改变，但其中的值可以改变。数组中的所有值必须是同一类型。数组可以这样定义：

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

元素可以通过下标赋值到数组中，也可以从数组中读取。F# 数组的下标从 0 开始，也就是说第一个元素的下标始终是 0：

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

操作数组有两种方式：使用`Array`模块中定义的函数和运算符，或者使用 _数组_ 模式手动进行模式匹配：

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

在模式匹配时，你也可以_丢弃_某个值；当你在某个分支中_不_关心某个值（也就是说，你不打算_使用_这个值）时，可以用下划线（`'_'`）来表示：

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

在模式匹配时，单独的`'_'`应始终放在_最后_。任何_不_匹配其他分支的值，都会由这个分支处理。
