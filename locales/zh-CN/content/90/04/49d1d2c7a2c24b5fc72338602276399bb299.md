# 说明

在本练习中，你将编写一些代码，帮助你按照最喜欢的那本烹饪书做一份千层面。

共有四个任务，都与做这道菜有关。

## 1. 定义预计的烤箱时间（分钟）

定义`lasagna.oven_time`表字段，表示千层面应该在烤箱里烤多少分钟。根据烹饪书，预计的烤箱时间是 40 分钟：

```lua
lasagna.oven_time
-- => 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`lasagna.remaining_oven_time`函数，它接受千层面已经在烤箱里烤了多少分钟作为实参，并根据上一个任务中预计的烤箱时间，返回千层面还需要在烤箱里烤多少分钟。

```lua
lasagna.remaining_oven_time(30)
-- => 10
```

## 3. 计算准备时间（分钟）

定义`lasagna.preparation_time`函数，它接受你往千层面里加了多少层作为实参，并返回你花在准备千层面上的分钟数，假设准备每一层需要 2 分钟。

```lua
lasagna.preparation_time(2)
-- => 4
```

## 4. 计算已经过去的工作时间（分钟）

定义`lasagna.elapsed_time`函数，它接受两个实参：第一个实参是你往千层面里加了多少层，第二个实参是千层面已经在烤箱里烤了多少分钟。函数应该返回你制作千层面总共花费的分钟数，也就是准备时间的分钟数与千层面此刻在烤箱里已经烤过的分钟数之和。

```lua
lasagna.elapsed_time(3, 20)
-- => 26
```
