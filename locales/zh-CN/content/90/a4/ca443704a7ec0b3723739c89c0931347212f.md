# 关于注释

Go 有[很棒的指南](https://golang.org/doc/effective_go.html)，讲解如何编写注释。文档注释有一种标准格式，`godoc`工具可以据此自动生成漂亮的文档。

包注释应当以`Package`一词开头，后面跟上包名，就像这样：

```go
// Package cook provides handy conversion methods for units typically used in recipes.
package cook
```

对于导出的函数、方法、常量和包级变量，注释应当以名称开头，后面接一个动词短语：

```go
// TbsToMl converts tablespoons to milliliters.
func TbsToMl(tbs int) int {
	// ...
}
```

[CodeReviewComments](https://github.com/golang/go/wiki/CodeReviewComments#comment-sentences) wiki 进一步说明，文档注释应当是完整的句子，并以句号结尾。

除了优化可读性之外，遵循这些建议还能让你的代码在 [Go 的文档工具](http://whipperstacker.com/2015/09/30/go-documentation-godoc-godoc-godoc-org-and-go-doc/)（例如 [godoc.org](http://godoc.org)、`godoc`和`go doc`）中看起来更好。

花点时间读一读官方风格指南 [Effective Go](https://golang.org/doc/effective_go.html) 中关于文档注释的一节，了解这些选择背后的理由。
