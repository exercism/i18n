你的任务是编写一对工具，帮你潜入 UMBRA（United Minions Being Really Awful）总部，取回他们最新那个糟糕透顶的阴谋的计划书。这项任务，如果你选择接受的话。
完成这次任务，你需要三个工具。

## 1. 生成 id 编号

每个手下都有一个唯一的标识符，它每天都会变化，并取决于该手下掌握的秘密数量和睡眠小时数。
你需要编写一个函数，它接收天数（以`Int`表示），并为这一天创建一个标识符生成函数。
这个标识符生成函数接收两个形参：

1. 掌握的秘密数量
2. 手下的睡眠小时数

标识符的计算方法如下：

1. 把掌握的秘密数量乘以睡眠小时数
2. 在结果上加上天数（以`Int`表示）

```kotlin
val idGenerator = makeIdGenerator(4)
idGenerator(3, 6)
// => 22

idGenerator(11, 5)
//  => 59
```

## 2. 用密码保护找回的秘密计划

拿到秘密计划后，你需要把它保护起来，让只有知道密码的人才能取回。
为此，你需要实现函数`protectSecret(secret: String, password: String) : (String) -> String`。
这个函数会返回另一个函数，它接收各种可能的密码字符串作为输入。
如果输入的密码正确，新函数就会返回隐藏的秘密；如果密码不正确，函数会返回“Sorry. No hidden secrets here.”

```kotlin
val secretFunction = protectSecret("Steal the world's supply of french fries!", "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 3. 找出密码

UMBRA 基地有许多房间，每个房间都由一名保安看守，他会向你索要密码。
密码取决于房间的编号。
遗憾的是，我们只知道推算密码所需算法的一半。
另一半可以通过询问某位手下得到。

实现`getPassword`函数，它接收以下内容并返回密码：

1. 房间编号
2. 手下的函数，并返回密码

调用手下的函数，并传入另一个代表我们所知算法的函数，就能得到密码。
我们掌握的这部分算法：

1. 接收两个数字并将它们相加
2. 把结果乘以房间 id

```kotlin
val minionFunction = { yourFunc : (Int, Int) -> Int ->
    "Password=${yourFunc(1, 3)}"
}

getPassword(5, minionFunction)
// Returns "Password=20"
```
