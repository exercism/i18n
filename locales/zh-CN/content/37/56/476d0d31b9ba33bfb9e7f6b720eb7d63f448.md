# 引言

在编程中，优雅地处理错误至关重要，这样才能确保意外情况不会导致程序崩溃或出现不可预测的行为。
Cairo 提供了两种主要的错误处理机制：

1. 用`panic`处理**不可恢复的错误**，它会立即终止程序。
2. 用`Result`处理**可恢复的错误**，它允许程序处理错误并做出响应。

## 使用`panic`处理不可恢复的错误

有时，程序遇到的错误过于严重，以至无法继续运行。
在这种情况下，Cairo 会用`panic`函数立即终止执行。
当某个错误（比如试图访问越界的下标）让程序无法再以合理的方式继续运行时，这就很有用。
`panic`函数接受一条`ByteArray`消息，用来描述错误的原因。

例如，在 Cairo 中：

```rust
fn main() {
    let data = array![1, 2];
    panic("An unrecoverable error has occurred!");
}
```

这个例子演示了一次强制的 panic，它会立即终止程序，并给出一条消息。

### `assert!`宏

`assert!`宏是一个很有用的工具，可以强制代码满足特定条件。
如果`assert!`中的条件求值为`false`，程序就会 panic，并给出一条`ByteArray`错误消息。
它通常用来在开发过程中验证假设，确保各个值满足特定的标准。

例如：

```rust
fn main() {
    let x = 5;
    assert!(x > 0, "x must be greater than zero");
}
```

如果`x`不大于零，程序就会 panic，并给出`"x must be greater than zero"`这条消息。`assert!`有助于检查不变量和前置条件，而无需手写错误处理代码。

## 使用`Result`处理可恢复的错误

并非所有错误都需要让程序停下来。
有些错误可以妥善处理，让程序继续运行。
Cairo 的`Result`枚举就表示这类可恢复的错误，它有两个变体：

- `Result::Ok`表示成功。
- `Result::Err`表示错误。

有了`Result`，函数既可以返回成功的值，也可以返回错误，这样调用它的函数就能决定下一步该怎么做。

```rust
fn divide(a: u32, b: u32) -> Result<u32, ByteArray> {
    if b == 0 {
        Result::Err("Error: Division by zero")
    } else {
        Result::Ok(a / b)
    }
}
```

在这个例子中，如果`b`是零，就返回一个错误；否则返回相除的结果。
