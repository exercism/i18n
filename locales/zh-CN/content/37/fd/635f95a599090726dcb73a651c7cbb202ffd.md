# 指令附录

## 打印树

本练习预置了一些类方法，可以帮你以美观的格式打印这棵树。它们的主要用途是辅助调试，让输出更加清晰。只要你正确实现了类的其余部分，它就会为你打印出这棵树。

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
