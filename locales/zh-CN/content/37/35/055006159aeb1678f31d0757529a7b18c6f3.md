# 关于

[元组][tuple]常用于把信息归到一组。它与数组的区别在于大小固定，并且可以存放不同的数据类型。
元组用花括号`()`创建，常用来从函数中返回多个值。

```haskell
tuple = (1, "abc", False)
```

比如，当你想在二维空间中保存一个坐标时，这就很有用。你知道这个元组始终有两个元素，即 x 坐标和 y 坐标。

```haskell
coordinate = (3, 4)
```

## 访问元素

你经常处理的都是短元组，这时可以用`fst`和`snd`函数来访问其中的元素。

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
