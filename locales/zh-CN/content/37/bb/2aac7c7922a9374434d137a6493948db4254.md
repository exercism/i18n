# 简介

每个 Factor 源文件都会用 `IN:` 声明一个*词汇表*，并用 `USING:` 导入它用到的其他词汇表。

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

目录结构与带点号的词汇表名称相对应：

- 词汇表`my-vocab`位于`my-vocab/my-vocab.factor`
- 词汇表`my-vocab.helpers`位于`my-vocab/helpers/helpers.factor`

Factor 的词汇表加载器会顺着`USING:`声明传递下去：当你引入的文件导入另一个词汇表时，那个词汇表会被自动加载。

你常常需要把一段大型例程拆分到两个词汇表中：一个放着小巧可复用单词的辅助词汇表，以及一个导入它们并把结果组合起来的主词汇表。
