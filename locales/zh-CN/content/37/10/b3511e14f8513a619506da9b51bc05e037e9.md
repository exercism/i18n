# 简介

Go 没有变量值为空、null 或 undefined 的概念。
声明变量时如果没有显式指定初始值，变量会默认为其对应类型的零值。

布尔、数字和字符串等基本类型的零值分别是`false`、`0`和`""`。

标识符`nil`意为零，它是指针、函数、接口、切片、通道和映射等更复杂类型的零值。

下表详细列出了 Go 各类型的零值。

| 类型      | 零值       |
| --------- | ---------- |
| 布尔      | `false`    |
| 数字      | `0`        |
| 字符串    | `""`       |
| 指针      | `nil`      |
| 函数      | `nil`      |
| 接口      | `nil`      |
| 切片      | `nil`      |
| 通道      | `nil`      |
| 映射      | `nil`      |

你可能已经注意到，上表中没有结构体类型。
这是因为结构体类型的零值取决于它的字段。
当结构体的所有字段都被设为其各自的零值时，结构体就被设为其零值。
