# 字符串

Crystal 有一个名为 [`String`][strings] 的类型，用于表示文本。
Crystal 字符串是 Unicode 字符的序列。
字符串是不可变的，也就是说，一旦创建就不能更改。
这意味着每次修改字符串都会创建一个新字符串，因此原字符串不会被修改。

定义字符串要使用双引号`"`。

```crystal
"Hello World"
```

## 拼接

拼接两个字符串要使用`+`运算符。
`+`运算符会返回一个结合两个字符串的新字符串。

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 字符串与数字之间的转换

`to_i`方法把字符串转换为整数。
也可以用`to_f`方法返回浮点数。
如果字符串无法转换为数字，就会抛出`ArgumentError`。

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

使用`to_s`方法可以把整数或浮点数转换为字符串。

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 插值

插值是一种便捷的方式，可以把字符串组合起来，并把表达式嵌入字符串中。
要在字符串中插值，可以使用`#`字符后跟大括号`{}`，把表达式写在括号里。

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal 会自动把表达式的结果转换为字符串。

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## 大小

当你需要知道字符串中的字符数时，可以使用`size`方法，它返回字符串的长度，是一个整数。
字符串的大小是字符串的一个存储属性，所以每次调用该方法时不必重新计算大小，因此速度非常快。

```crystal
"Hello World".size
# => 11
```

## 下标

所谓下标，就是从字符串中取出某个特定字符。
要从`String`中取出一个字符，可以使用熟悉的方括号写法。

~~~~exercism/note
`[]` is implemented as a String instance method, where the index is the method argument.
~~~~

字符串的第一个字符位于下标 0。

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

要从字符串末尾取字符，可以用字符串长度减 1 得到最后一个字符的下标，用长度减 2 得到倒数第二个字符的下标，依此类推。
对此有一个简便写法，就是直接用负数下标：最后一个字符的下标是 -1，倒数第二个字符的下标是 -2，依此类推。

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### 子串测试

Crystal 支持用下标来测试字符串是否包含某个子串。
用同样的方括号写法即可，只是括号里给的不是下标，而是子串。
如果在字符串中找到了该子串，就返回该子串，否则抛出`NilAssertionError`。

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

如果你想要一个`Bool`值来表示是否找到了子串，可以使用`includes?`方法。

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## 转义

有些字符不能直接写在字符串里，必须使用转义序列。
例如，如果想在字符串中使用双引号，就必须对双引号进行转义。
你可以使用`\`字符来写转义序列，后面跟上你想要转义的字符。

Crystal 中的特殊字符如下：

| 值       | 描述                          |
| -------- | ----------------------------- |
| `\a`     | 响铃                          |
| `\b`     | 退格                          |
| `\e`     | 转义                          |
| `\f`     | 换页                          |
| `\n`     | 换行                          |
| `\r`     | 回车                          |
| `\t`     | 水平制表符                    |
| `\v`     | 垂直制表符                    |
| `\\`     | 反斜杠                        |
| `\'`     | 单引号                        |
| `\"`     | 双引号                        |
| `\377`   | 八进制 ASCII 字符             |
| `\xFF`   | 十六进制 ASCII 字符           |
| `\uFFFF` | 十六进制 Unicode 字符         |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 多行字符串

要写多行字符串，使用的语法与单行字符串相同，只是字符串里想有多少行就换多少次行。

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] 是一套标准，用于对不同书写系统的文本进行编码、表示和处理。
Unicode 支持超过 100,000 个字符，包括字母、标点符号、符号和 emoji。

由于 Crystal 用 Unicode 表示字符串，你可以往字符串里放 emoji。

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

有时你想使用某个字符，但你的编辑器或系统里并没有这个字符。
这时，你可以使用 Unicode 转义序列来写出该字符。

```crystal
"\u{1F310}"
# => "🌐"
```
