# 关于

在 Haxe 中，抽象类型在运行时其实是另一种类型。它是一种编译期特性，用于在具体类型“之上”定义类型，以修改或增强它们的行为：

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

这里我们用`abstract`关键字声明了`AbstractInt`类型。它的语法与`class`非常相似。和类一样，抽象类型也可以有方法。它们同样可以像类那样被实例化并使用：

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

如上文所述，抽象类型是一种编译期特性。把上面的例子编译成 JavaScript 后会得到：

```javascript
var a = 12;
console.log(a)
```

抽象类型`AbstractInt`从输出中完全消失。这是因为`Abstract`的构造函数是[内联][inline]的，稍后我们会看到。

[inline]: https://haxe.org/manual/class-field-inline.html
