# 说明补充

## 本练习专属说明

这些函数需要返回乘积，以及因数数组的偏移量和长度。
因数只是以 i32 对的形式写入内存：

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

对于最大的一位数回文乘积，结果看起来是这样的：

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
