# 关于

在 Factor 中，字符串是字符序列，它共享完整的[`sequences`协议][sequence-protocol]：`length`、`nth`、`head`、`tail`、`map`、`filter`等等，此外还拥有自己专属的词汇表。

```factor
"hello"  length .       ! => 5
"hello"  reverse .      ! => "olleh"
"abcdef" 3 head .       ! => "abc"
```

专门处理字符串的单词大多位于[`splitting`][splitting]、[`ascii`][ascii]和[`unicode`][unicode]：

| 单词         | 词汇表         | 作用                          |
|--------------|---------------|---------------------------------------|
| `split1`     | [`splitting`][splitting]   | 在第一次出现处切分           |
| `split`      | [`splitting`][splitting]   | 按集合中的任一字符切分         |
| `harvest`    | [`sequences`][sequences]   | 从切分结果中去掉空片段 |
| `replace`    | [`splitting`][splitting]   | 替换子字符串                |
| `surround`   | [`sequences`][sequences]   | 用前缀和后缀包裹         |
| `glue`       | [`sequences`][sequences]   | 用分隔符连接两个字符串     |
| `join`       | [`sequences`][sequences]   | 用分隔符连接字符串数组 |
| `>lower`     | [`ascii`][ascii]       | 转为小写（ASCII）                     |
| `>upper`     | [`ascii`][ascii]       | 转为大写（ASCII）                     |
| `[ blank? ] trim` | [`sequences`][sequences] | 去除首尾空白 |
| `first`、`second`、`third`、`fourth` | [`sequences`][sequences] | 取开头的元素 |
| `first2`、`first3`         | [`sequences`][sequences]   | 解包开头两个或三个元素 |
| `>string`    | [`strings`][strings]     | 把字符序列转换成字符串 |
| `1string`    | [`strings`][strings]     | 把单个字符包装成只含一个字符的字符串 |
| `CHAR: x`    | parser        | 单字符字面量（例如`CHAR: A` → `65`） |

如需在数字和字符串之间来回转换，[`math.parser`][math.parser]提供了`number>string`和`string>number`。如需格式化字符串输出，[`formatting`][formatting]提供了`sprintf`等单词。

如需支持 Unicode 的大小写转换或字符分类，请使用[`unicode`][unicode]中对应的单词。
