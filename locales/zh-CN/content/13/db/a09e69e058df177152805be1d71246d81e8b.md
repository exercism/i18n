# 说明

你的无挡板篮球俱乐部需要在每轮比赛后算出积分榜。

四个任务都放在`NETBALL_LADDER`类里。

## 1. 积分

赢一场得 4 分，平一场得 2 分。输球不得分。

```sather
NETBALL_LADDER::ladder_points(3, 1)
-- => 14
```

## 2. 净胜球

进球数减去失球数，结果可能为负。

```sather
NETBALL_LADDER::goal_difference(180, 205)
-- => -25
```

## 3. 完整的节数

一节比赛是 15 分钟。给定一个分钟数，这相当于多少节完整的比赛？

```sather
NETBALL_LADDER::whole_quarters(38)
-- => 2
```

## 4. 本节已进行的分钟数

同样给定一个分钟数，当前这一节已经进行了多少分钟？

```sather
NETBALL_LADDER::minutes_into_quarter(38)
-- => 8
```
