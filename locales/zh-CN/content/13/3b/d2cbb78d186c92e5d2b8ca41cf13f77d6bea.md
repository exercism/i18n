# 说明

把一个短语转换成它的首字母缩写。

技术爱好者最爱他们的 TLA（三个字母的缩写）了！

帮忙造点行话吧：写一个程序，把像 Portable Network Graphics 这样的长名称转换成它的缩写（PNG）。

标点按下面的方式处理：连字符是单词分隔符（和空白字符一样）；其他标点都可以从输入中删除。

例如：

| 输入                     | 输出 |
| ------------------------- | ------ |
| As Soon As Possible       | ASAP   |
| Liquid-crystal display    | LCD    |
| Thank George It's Friday! | TGIF   |
