# 指令补充

## 寄存器

| 寄存器   | 用途     | 类型    | 说明                          |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | 输入     | 地址    | 由因子词组成的数组            |
| `$a1`    | 输入     | 整数    | 因子的个数                    |
| `$a2`    | 输入     | 整数    | 上限                          |
| `$v0`    | 输出     | 整数    | 上限以内所有倍数之和          |
| `$t0-9`  | 临时     | 任意    | 用于临时存储                  |
