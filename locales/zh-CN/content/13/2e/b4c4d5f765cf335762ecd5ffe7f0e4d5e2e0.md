# 帮助

## 运行测试

Factor 学习轨道使用 **Factor 0.101**。[安装](https://exercism.org/docs/tracks/factor/installation)完成后，在本练习的目录下运行：

```
factor -roots=. -run=exercism-tools <exercise>
```

例如，对于 `hello-world`：

```
factor -roots=. -run=exercism-tools hello-world
```

每个练习都自带一个内置的 `exercism-tools` 词汇表，由它来驱动测试运行。当所有测试都通过时，运行器以状态码 0 退出；如果有测试失败，则以非零状态码退出，并附带诊断输出。

### 跳过测试

默认情况下，只有第一个测试会运行。其原理是测试文件里的 `STOP-HERE` 这一行：在解析阶段，它会告诉 Factor 的词法分析器忽略它下面的一切，因此运行器只能看到位于它上面的测试。第一个测试通过之后，你可以用两种方式启用更多测试：

- **删除 `STOP-HERE` 这一行**，一次性启用所有剩余的测试。
- **把 `STOP-HERE` 这一行往下移**，逐个启用测试，或者一次启用一个任务。概念练习会把测试按 `TASK:` 标记分组，把 `STOP-HERE` 移到下一个 `TASK:` 之前，是很自然的一步。

当所有测试都通过时，你就解决了这个练习。

## 提交你的解答

在本练习的目录下：

```
exercism submit <exercise>/<exercise>.factor
```

例如：

```
exercism submit hello-world/hello-world.factor
```

如果练习的 `.meta/config.json` 列出了多个解答文件（有些概念练习会把解答拆分到一个辅助子词汇表中），请把你编辑过的每个文件都传给 `exercism submit`。

## 提交未完成的解答

即使测试没通过，你也可以提交解答，这样你就能看到别人是如何解决这道练习的，还能就你目前完成的部分向导师寻求反馈。

## 获取更多帮助

- [Exercism 论坛上的 Factor 板块](https://forum.exercism.org/c/programming/factor/)是提出和反馈 Factor 学习轨道相关问题的最佳去处。
- [Exercism Discord](https://exercism.org/r/discord)里既有通用帮助频道，也有各个学习轨道的频道。
- Factor 的官方文档可以搜索，内容也很详尽。这里有两个不错的切入点：
  - [Factor 手册](https://docs.factorcode.org/content/article-handbook.html)
    风格偏参考手册，按词汇表组织。
  - [Factor 烹饪书](https://docs.factorcode.org/content/article-cookbook.html)
    按主题给出简短而地道的示例。
- Andrea Ferretti 的
  [Factor 教程](https://andreaferretti.github.io/factor-tutorial/)
  是一份快速而友好的入门材料，带你了解这门语言和开发环境。
