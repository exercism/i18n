# 说明

延续 wizards and warriors 游戏的主题，现在该添加一个通用的掷骰方法了。这是一个传统的 18 面骰，数字从 1 到 18。玩家还需要生成法术强度。

## 1. 让 _wizards and warriors_ 玩家掷骰子

在`Player`类上实现一个`RollDie()`方法。

```csharp
var player = new Player();
player.RollDie();
// => >= 1 <= 18
```

## 2. 玩家需要自己的法术强度。提供生成法术强度的方式

在玩家类上实现一个`GenerateSpellStrength()`方法。法术强度介于 0.0 和 100.0 之间（包含 0.0，不包含 100.0）。

注意，法术强度必须是实数（不能是整数），这样在比较两个对手的强度时，可以减少出现平局的可能性。

```csharp
var player = new Player();
player.GenerateSpellStrength();
// => >= 0.0 < 100.0
```
