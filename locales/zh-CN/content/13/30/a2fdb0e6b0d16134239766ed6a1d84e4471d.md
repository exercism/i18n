# 简介

Gleam 不用异常来处理错误，而是由可能成功也可能失败的函数返回泛型的`Result`类型。

`Result`类型内置于语言中，所以不需要定义或导入它。不过如果你想自己定义，它大概长这样：

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

函数成功时返回`Ok`变体，失败时返回`Error`变体。

Result 在 Gleam 中非常常见，Gleam 程序员通常会用 [`gleam/result`模块](https://hexdocs.pm/gleam_stdlib/gleam/result.html)来简化对它的操作。

如果结果是 `Ok`，可以用`result.map`函数对其中包含的值调用一个函数；如果是 `Error`，则原样传递。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try`函数与之类似，但它要求回调函数返回一个结果。这在把多个返回结果的函数串联起来时很有用。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
