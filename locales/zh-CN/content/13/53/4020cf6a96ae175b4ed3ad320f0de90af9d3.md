# 变量简介

## 变量

_变量_是存放数据的地方。
Bash 有两种数据：字符串和数组。
数组我们稍后再讲。

像这样给变量赋值：

```bash
name="value"
```

~~~~exercism/note
**重要**：等号两边_不能有空格_！

像下面这个例子这样有空格时，

```bash
x = 10
```

bash 会把 `x` 当作**命令**来调用，并把 `=` 和 `10` 当作**两个参数**！
~~~~

变量有时也被称为_参数_。
在本文档中，这两个词会交替使用。

bash 使用或设置的一些重要参数包括：

* `PATH`：以冒号分隔的目录列表，用于查找外部命令。
* `IFS`：即“内部字段分隔符”。
   下面我们会看到它的用法。
* `PWD`：你当前的工作目录。
   它的值与 `pwd` 命令的输出相同。
* `RANDOM`：0 到 32767 之间的伪随机整数。
* `BASH_VERSION`：当前运行的 bash 实例的版本字符串。

## 变量名

变量名由_大写字母、小写字母、数字和下划线_组成。
不能以数字开头。

~~~~exercism/caution
最好是**避免使用全大写的变量名**。
shell 用这种约定来命名它自己的参数，而你肯定不想不小心覆盖掉那些有特殊含义的 shell 参数。

## 参数展开

用`$varname`语法可以取得参数的值。

```bash
x=10
echo "The value of x is $x"
```

为避免变量名与周围的文本混淆，可以把变量名用大括号括起来。
例如，要打印字符串 `10x10`

```bash
echo "${x}x$x"
# or
echo "${x}x${x}"
```

一些[风格指南][google-style-guide]建议在大多数情况下都使用大括号，以便提高可读性和（或）保持一致性。

## 位置参数

正如我们在[命令和参数][cmds-args]这节课中讨论的，命令可以接受参数。
Bash 脚本也不例外。
传给当前 bash 实例的参数称为_位置参数_。
可以用这些特殊参数来获取它们：

* `$1`：第一个位置参数
* `$2` ... `$9`：后续参数
* `${10}` ...：两位数需要用大括号。
* `$0`：当前脚本的名称。

shell 函数的参数同样是位置参数，处理方式与上面完全一样。
后面的课程中我们会进一步了解函数。

### 特殊位置参数

有一些_特殊参数_可以帮你处理位置参数。

* `$#` 会展开为位置参数的_数量_。
* `"$@"` 会展开为所有位置参数组成的列表，每个参数作为一个独立的单词。
* `"$*"` 会展开为单个字符串，其中所有位置参数由某个字符连接在一起。
  * 连接字符是 `$IFS` 变量的_第一个字符_，默认是一个空格。

把位置参数传给另一个命令、同时保证它们被正确引用，`"$@"` 是最安全的方式。
它也是你用来循环处理位置参数的方式：

```bash
for arg in "$@"; do
    do_something_with "$arg"
done
```

实践中，`"$@"` 比 `"$*"` 用得更频繁。

## 命令替换

在 bash 脚本中，你经常要做的一个操作是把命令的输出捕获下来，存进变量里。
为此，你要使用_命令替换_。

```bash
var=$(command)
```

例如，要把字符串转换成大写，可以这样做：

```bash
text="Hello world!"
uppercase=$(echo "$text" | tr '[:lower:]' '[:upper:]')
echo "$uppercase"
# => HELLO WORLD!
```

## 关于参数展开的更多内容

Bash 提供了许多内置功能来操作变量和字符串，这样你就不必调用外部命令。

* 把文本转换成大写。
  上一节中我演示了怎样用 `tr` 把文本转换成大写。
  要在 bash 里做到这一点：

  ```bash
  echo "${text^^}"
  ```

  类似地，`${text,,}` 会把值转换为小写。

* 如果变量为空，提供一个默认值。

  ```bash
  default="nothing here"
  result=""
  echo "${result:-$default}"
  # => nothing here
  ```

* 搜索并替换。

  ```bash
  text="Hello world!"
  echo "${text//[aeiou]/X}"
  # => HXllX wXrld!"
  ```

还有很多其他有趣的参数展开：提取子字符串、获取字符串长度、_赋值_一个默认值、从值的开头或结尾删除文本，等等。
可以在[手册][param-exp]里了解它们。
