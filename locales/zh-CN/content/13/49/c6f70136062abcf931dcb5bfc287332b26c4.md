# 布尔值

Haskell 有一种类型叫[`Bool`][bools]，它是`True`和`False`的枚举。

## 逻辑运算符

Haskell 有三个逻辑运算符（`not`、`||`、`&&`），它们组合布尔值，构成求值结果不同的表达式。

### 与（`&&`）

Haskell 中的[“与”运算符][and]用`&&`表示，当两个值都是`True`时返回`True`，否则返回`False`。
使用“与”运算符时，一个布尔值放在`&&`的右边，另一个放在左边。

```haskell
True && True
-- -> True

True && False
-- -> False
```

### 或（`||`）

Haskell 中的[“或”运算符][or]用`||`表示，只要给定的值中**至少有一个**是`True`，它就返回`True`。
如果两个值都是`False`，则返回`False`。
使用“或”运算符时，一个布尔值应放在`||`的右边，另一个放在左边。

```haskell
True || True
-- -> True

True || False
-- -> True

False || False
-- -> False
```

### 非（`not`）

Haskell 中的“非”运算符用`not`表示：如果给定的布尔值是`False`，就返回`True`；如果给的是`True`，则返回`False`。
使用“非”运算符时，一个布尔值应放在运算符（`not`）之后。

```haskell
not True
-- -> False

not False
-- -> True
```

## 使用括号（`()`）

处理布尔值时，可以用括号决定先计算哪些布尔值。括号的用法不同，结果也可能不同。在 Haskell 中，括号里的内容会先被求值。

```haskell
True && False && False || True
-- -> True

True && False && (False || True)
-- -> False
```

由于括号里的内容会先被求值，在下面的例子里，“非”运算符会作用于括号内的表达式。

```haskell
not True && False
-- -> False

not (True && False)
-- -> True
```

~~~~exercism/note
只有当括号会影响结果时才应该使用括号；否则就应该省略。
~~~~
