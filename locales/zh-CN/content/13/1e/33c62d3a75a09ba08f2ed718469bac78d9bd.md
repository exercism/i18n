# 安装

C 语言学习路径要求你的系统上安装以下软件：

* 一款现代的 C 编译器
* Make 构建工具

Apple 的 Xcode IDE 将编译器和原生构建系统整合到同一个 IDE（集成开发环境）中。
Linux 环境通常将编译器和原生构建系统作为单独的命令行工具提供。

## Linux

Linux 用户需要 gcc 或 clang 作为编译器，原生构建则需要`make`。
Make 在大多数 Unix 系统上都已预装，但多半可以通过你的包管理器安装。
在基于 Debian 和 Ubuntu 的发行版上，如果需要的一切尚未安装，可以用`sudo apt-get install build-essential`来安装。

## MacOS

MacOS 用户可以通过 [Homebrew][] 用`brew install gcc`或`brew install llvm`安装 gcc 或 clang。

## Windows

建议 Windows 10 用户使用 [Windows Subsystem for Linux][]，然后按照上面的 Linux 说明操作。

如果你使用的是更早版本的 Windows，或者无法使用 WSL Bash，可以使用 [MSYS][] 或 [mingw-w64][]。

[Homebrew]: https://brew.sh
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[MSYS]: https://www.msys2.org
[mingw-w64]: http://mingw-w64.org
