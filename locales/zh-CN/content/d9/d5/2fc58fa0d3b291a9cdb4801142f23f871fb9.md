# 提示

## 通用

关于继承的详细说明可以查看[继承][inheritance-concept]。
整个继承概念与[重写][java-overriding]相关的概念有很大关系。

## 1. 创建 Warrior 类

- 复习 [concept:java/classes](https://github.com/exercism/java/tree/main/concepts/classes) 概念。
- 复习[继承][inheritance-concept]概念。

## 2. 描述 Warrior

- 在 Java 中，`toString()` 方法实际上存在于 `Object` 类中（它是 Java 中所有类的父类）。
  你可以在官方的 [Oracle 文档][object-class-java] 中了解更多。
- 要在你的实现类中重写这个方法，你需要有一个同名的方法，即 `toString()`，以及相同的返回类型，即 `String`。
- `toString()` 方法必须是 `public`。

## 3. 让 Warrior 不受伤害

- 在 `Warrior` 类中重写 `isVulnerable()` 方法，让 Warrior 始终不受伤害。

## 4. 计算 Warrior 的伤害点数

- 在 `Warrior` 类中重写 `getDamagePoints(Fighter)` 方法。
- 使用[分支语句][if-else]返回伤害点数，并考虑目标是否易受伤害。

## 5. 创建 Wizard 类

- 复习 [concept:java/classes](https://github.com/exercism/java/tree/main/concepts/classes) 概念。
- 复习[继承][inheritance-concept]概念。

## 6. 描述 Wizard

- 在 Java 中，`toString()` 方法实际上存在于 `Object` 类中（它是 Java 中所有类的父类）。
  你可以在官方的 [Oracle 文档][object-class-java] 中了解更多。
- 要在你的实现类中重写这个方法，你需要有一个同名的方法，即 `toString()`，以及相同的返回类型，即 `String`。
- `toString()` 方法必须是 `public`。

## 7. 让 Wizard 能够准备法术，并在未准备法术时变得易受伤害

- 只有 Wizard 才能准备法术。所以，把这个属性定义在 `Wizard` 类中是合理的。
- 在 `Wizard` 类中创建 `prepareSpell()` 方法。
- 记住：父类（这里是 `Fighter`）无法访问子类的属性（例如 `Wizard`）。
- 记住：由于这个方法没有返回类型，你应该改用 `void`。
- 在 `Wizard` 类中重写 `isVulnerable()` 方法，让 Wizard 在没有准备法术时易受伤害。

## 8. 计算 Wizard 的伤害点数

- 在 `Wizard` 类中重写 `getDamagePoints(Fighter)` 方法。
- 使用[分支语句][if-else]返回伤害点数，并考虑准备法术字段的值。
