# 简介

## 常量

Gleam 中的常量是一种给值命名的方式。使用`const`关键字来定义它们。

```gleam
pub const pi: Float = 3.14159

pub fn circle_area(radius: Float) -> Float {
  radius *. radius *. pi
}
```

用`pub`关键字定义时，模块常量可以被其他模块访问；否则只能在定义它们的模块内部访问。

## Order 类型

Gleam 标准库中的`gleam/order`模块包含`Order`类型，用来比较值。

`Order`的定义如下：

```gleam
pub type Order {
  Gt
  Eq
  Lt
}
```

这个类型有三个变体，每个都用来表示一个值与另一个值之间的关系：

- `Gt`：该值_大于_另一个值。
- `Eq`：该值_等于_另一个值。
- `Lt`：该值_小于_另一个值。

如果一个数据类型可以按大小比较，模块通常会定义一个返回`Order`值的`compare`函数。例如，`gleam/float`和`gleam/int`分别定义了用于浮点数和整数的`compare`函数。

```gleam
int.compare(1, 2)
// -> Lt

int.compare(2, 2)
// -> Eq

float.compare(1.0, 2.0)
// -> Lt
```

像`list.sort`这样的排序函数通常会接收一个返回`Order`值的函数，让调用方自行决定数组该如何排序。

```gleam
list.sort([3, 7, 3, 1], by: int.compare)
// -> [1, 3, 3, 7]
```
