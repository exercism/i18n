# 关于

## if 表达式

`jq`的**条件表达式**是`if A then B else C end`。

`if-then-else`和所有`jq`内置函数一样，是一个过滤器：它接受一个输入并产生一个输出。

如果表达式`A`产生一个“真值”，那么`if`过滤器会求值`B`。
否则它会求值`C`。
`if`过滤器的输入会传给`B`或`C`。

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
`else`子句是**可选的**；下面两个语句是等价的。

```jq
if A then B else . end
if A then B end
```
~~~~

## 嵌套 if 语句

可以用`elif`添加更多条件。

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

需要多少个`elif`子句就用多少个。

## 真值性

`jq`中只有两个“false”值：`false`和`null`。
其他一切都是“true”，甚至包括数字零、空字符串、空数组和空对象。

## 布尔运算符

**布尔运算符**`and`和`or`可以用来构建复杂查询。

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

要取反，请使用`not`。它是一个**过滤器**，而不是运算符。

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

## 替代运算符

**替代运算符**允许你指定一个“默认”值，当表达式为 false 或 null 时。

```jq
A // B

# This is identical to
if A then A else B end
```

演示一下：

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```

## 还有更多吗？

来自不同语言的程序员可能期待更多种类的条件命令，比如`cond`、`case`、`switch`、`when`、`unless`、三元运算符等等。
上面列出的运算符就是`jq`提供的全部内容。
