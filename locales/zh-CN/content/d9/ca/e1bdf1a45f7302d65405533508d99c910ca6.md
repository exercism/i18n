# 简介

*泛型词*声明一种操作，它的实现可以随实参所属的类而不同。方法通过`M:`添加。

```factor
USING: kernel math ;

GENERIC: area ( shape -- n )

TUPLE: square side ;
TUPLE: circle radius ;

M: square area side>> dup * ;
M: circle area radius>> dup * 3.14159 * ;
```

```factor
T{ square { side 4 } } area .    ! => 16
T{ circle { radius 2 } } area .  ! => 12.56636
```

`GENERIC:`声明这个词及其栈效应。`M:`在特定的类上定义一个方法，Factor 会在运行时根据栈顶实参的类进行分派。

你可以向泛型词询问它已经为哪些类定义了方法，也可以事后再添加或删除方法。这里没有专门的继承语法：任何元组类都自动可以在其上定义方法。
