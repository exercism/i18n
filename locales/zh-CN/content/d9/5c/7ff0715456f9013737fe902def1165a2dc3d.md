# 介绍

`Complex numbers`并不复杂。
它们只是需要一个不那么吓人的名字。

它们在工程和科学领域尤其有用，因此 Julia 把复数也作为标准数值类型，与整数和浮点数并列。

## 基础

Julia 中的`complex`值本质上是一对数字：通常是浮点数，但也不尽然。
由于一些不幸的历史原因，它们被称为“实部”和“虚部”。
再说一次，最好专注于它本质上的简单，而不要纠结于这些奇怪的名字。

要用两个实数创建复数，只需给虚部加上后缀`im`。

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> typeof(z)
ComplexF64 (alias for Complex{Float64})
julia> zi = 1 + 2im
1 + 2im
julia> typeof(zi)
Complex{Int64}
```

因此存在各种`Complex`类型，它们由对应的整数或浮点数类型派生而来。

要用实数变量创建复数，上面的语法就行不通了。
写成`a + bim`会让解析器以为`bim`是一个（并不存在的）变量名。

写`b*im`也可以，但更推荐的做法是使用`complex()`函数，它能绕开乘法和加法运算。

```julia-repl
julia> a = 1.2; b = 3.4; complex(a, b)
1.2 + 3.4im
```

要分别获取复数的各个部分：

```julia-repl
julia> z = 1.2 + 3.4im
1.2 + 3.4im
julia> real(z)
1.2
julia> imag(z)
3.4
```

或者一起获取：

```julia-repl
julia> reim(z)
(1.2, 3.4)
```

任一部分都可以为 0，数学家可能会说这个数“完全是实数”或“完全是虚数”。
不过，在 Julia 中它仍然是一个复数。

```julia-repl
julia> zr = 1.2 + 0im
1.2 + 0.0im
julia> typeof(zr)
ComplexF64 (alias for Complex{Float64})
julia> zi = 3.4im
0.0 + 3.4im
julia> typeof(zi)
ComplexF64 (alias for Complex{Float64})
```

你可能听说过“`i`（或`j`）是 -1 的平方根”。

目前，这一切只意味着虚部_按定义_满足下面这个等式：

```julia-repl
julia> 1im * 1im == -1
true
```

这是一个简单的想法，但会引出一些有趣的结论。

## 算术

所有用于浮点数和整数的标准数学`operators`和初等函数，也都适用于复数。来看几个小例子：

```julia-repl
julia> z1 = 1.5 + 2im
1.5 + 2.0im
julia> z2 = 2 + 1.5im
2.0 + 1.5im
julia> z1 + z2  # addition
3.5 + 3.5im
julia> z1 * z2  # multiplication
0.0 + 6.25im
julia> z1 / z2  # division
0.96 + 0.28im
julia> z1^2  # exponentiation
-1.75 + 6.0im
julia> 2^z1  # another exponentiation
0.5188946835878313 + 2.7804223253571183im
```

## 函数

除了`real()`和`imag()`，还有几个函数与复数尤其相关。

- `conj()`就是把复数虚部的符号翻转（_从 + 变 -，或反过来_）。
    - 由于复数乘法的运作方式，它比你想象的更有用。
- `abs(<complex number>)`保证返回一个没有虚部的实数。
- `abs2(<complex number>)`返回`abs(<complex number>)`的平方：计算起来比`abs()`更快，而且往往正是计算所需要的。
- `angle(<complex number>)`返回以弧度表示的相位角。

```julia-repl
julia> z1
1.5 + 2.0im
julia> conj(z1)
1.5 - 2.0im
julia> abs(z1)
2.5
julia> abs2(z1)
6.25
julia> angle(z1)
0.9272952180016122
```
面向有数学头脑的读者，这里做一点解释：

- `z1`的`(real, imag)`表示实际上用的是复平面上的笛卡尔坐标。
- 同一个复数也可以用极坐标下的`(r, θ)`表示法来表示。
- 这里，`r`和`θ`分别由`abs(z1)`和`angle(z1)`给出。

下面是一个用到一些常量的例子：

```julia-repl
julia> euler = exp(1im * π)
-1.0 + 1.2246467991473532e-16im
julia> real(euler)
-1.0
julia> round(imag(euler), digits=15)  # round to 15 decimal places
0.0
```

极坐标`(r, θ)`表示法非常有用，以至于有内置函数`cis`（`cos(x) + isin(x)`的缩写）和`cispi`（`cos(πx) + isin(πx)`的缩写），它们能帮助更高效地构造这种表示。

极坐标表示法的用处体现在欧拉那个优美的公式里：`ℯ^(iθ) = cos(θ) + isin(θ) = x + iy`，其中`|x + iy| = 1`。
当`|x + iy| = r`时，我们就得到更一般的极坐标形式`r * ℯ^(iθ) = r * (cos(θ) + isin(θ)) = x + iy`。
注意，指数形式尤其紧凑，也容易运算。

```julia-repl
julia> exp(1im * π) ≈ cis(π) ≈ cispi(1)
true
```

上面的近似相等，是因为函数`cis`和`cispi`能给出更理想的数值输出，尤其是`cispi`，在处理 π 的任意倍数作为实参时更是如此（比如弧度！）。

```julia-repl
julia> cis(π)
-1.0 + 0.0im
julia> cispi(1)
-1.0 + 0.0im
julia> θ = π/2;
julia> exp(im*θ)
6.123233995736766e-17 + 1.0im
julia> cis(θ)
6.123233995736766e-17 + 1.0im
julia> cispi(θ / π)  # θ/π == 1/2
0.0 + 1.0im
```

顺便提一下，这让复数在做二维旋转和径向位移时非常有用。

对于旋转，复数`z = x + iy`可以通过一次简单的乘法绕原点旋转角度`θ`：`z * ℯ^(iθ)`。
注意，这里的`x`和`y`就是真实的二维笛卡尔平面上通常的坐标，正角度会得到*逆时针*旋转，负角度则会得到*顺时针*旋转。

同样简单，要做一个径向位移`Δr`，只需把它加到极坐标形式下复数的模`r`上（例如`z = r * ℯ^(iθ)` -> `z' = (r + Δr) * ℯ^(iθ)`）。
注意角度部分保持不变，只有模`r`发生变化，正如预期的那样。
