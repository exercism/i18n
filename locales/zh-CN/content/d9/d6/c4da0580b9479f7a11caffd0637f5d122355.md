# 提示

## 通用

- `unparse`在[`prettyprint`][prettyprint]中；切片变体在[`sequences`][sequences]中；多输入的 cleave 系列在[`combinators`][combinators]中。

## 1. 引用一个值

- 一个词：`unparse`。

## 2. 剥去标志的外框

- 用`1 tail-slice`去掉开头的标记，再用`1 head-slice*`去掉末尾的标记。

## 3. 拆分标志

- `head-slice`和`tail-slice`都需要把标志*和*头部长度放到栈上。也就是`[ head-slice ] [ tail-slice ] 2bi`。

## 4. 从两个读数做三角测量

- 三段不同的引用，每段都接收相同的两个读数：`[ - ] [ + 2 / ] [ / ] 2tri`。

## 5. 汇总三个读数

- 三段引用，每段各接收三个输入：`3tri`。求和的那段是`[ + + ]`；求积的那段是`[ * * ]`；求最大值的那段是`[ max max ]`。
