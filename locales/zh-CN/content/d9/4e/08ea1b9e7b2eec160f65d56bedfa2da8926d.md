# 简介

向量是一维数组。
它们可以包含不同类型的元素。

## 创建向量

可以通过`vector`函数创建向量，也可以使用它的读取器形式`#()`：

```lisp
(vector 1 t "foo" 'b) ; => #(1 T "foo" B)
#(2 nil "bar" a)      ; => #(2 NIL "bar" A)
```

由于向量也是数组，所以还可以用`make-array`创建：

```lisp
(make-array 3 :initial-element 'x)        ; => #(X X X)
(make-array 3 :initial-contents '(a b c)) ; => #(A B C)
```

## 向量判定

要检查一个对象是不是向量，用谓词`vectorp`即可。

## 访问元素

要访问向量中的元素，使用`aref`，下标从 0 开始：

```lisp
(aref #(1 2 3) 1) ; => 2
(aref #(a b c) 0) ; => A
```
