# 介绍

在 Go 中，你可以用`for`和下标来遍历`slice`，也可以使用`range`。`range`还允许你遍历`map`。

每次迭代都会返回两个值：下标/键，以及该下标/键对应元素的副本。

## 遍历 slice

小菜一碟，遍历`slice`时，顺序和预期一致。

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## 遍历 map

遍历`map`会带来一个新问题。
现在的顺序是随机的。

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
上面的输出看起来可能不对，因为人们会以为在声明 map 时最先出现的键值对`9 10`应该最先打印，而不是最后一个。
然而，map 天生就是无序的，并不存在第一个或最后一个键值对。
因此，在遍历 map 的条目时，访问条目的顺序是随机的，不会遵循任何特定规律。
这意味着上面的输出是有可能的，但你自己运行这段代码时得到的结果可能不一样。
想了解更多，请参阅 [Go 语言规范：range 子句](https://go.dev/ref/spec#RangeClause)。
~~~~

## 省略键或值的迭代

在 Go 中，未使用的变量会在构建时引发错误。
有时你只需要值，就像第一个例子那样：

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

你可以用`_`替换`i`，这告诉编译器我们不使用那个值：

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

如果你只想打印下标，可以用`_`替换`x`，或者干脆省略声明：

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 非结构体类型

你之前见过如何定义结构体类型。
也可以定义非结构体类型，把它用作内置类型声明的别名，还可以在它们上面定义接收者函数，像结构体类型那样对它们进行扩展。

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

你还可以定义由数组和 map 组成的非结构体类型。

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
