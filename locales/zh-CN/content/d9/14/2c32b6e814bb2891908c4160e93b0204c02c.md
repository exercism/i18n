# 说明

你是一名专业的调酒师，为客人们调制美味的饮品，让他们在夜晚外出时尽情享用。不过你想，写点代码来帮自己完成工作，也许能让日子轻松一些。

## 1. 判断完成一笔订单需要多长时间

不同的饮品需要的准备时间各不相同：

- `"beer"`、`"soda"`和`"water"`各需要 0.5 分钟。
- `"shot"`需要 1.0 分钟，`"mixed drink"`需要 1.5 分钟，
- `"fancy drink"`需要 2.5 分钟，
- `"frozen drink"`需要 3.0 分钟。

实现函数 `timeToPrepare(drinks:)`，它接收参数 `drinks`，该参数是一个字符串数组，表示需要准备的饮品。
函数应返回准备数组中所有饮品所需的总时间。

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. 补充你的青柠角储备

开始一个班次时要做的头几件事之一，就是确保你那一小盒青柠角在接下来的班次里是满的。
青柠大小不同，切出的青柠角数量也不同：一个 "small" 青柠能切出 6 个青柠角，一个 "medium" 青柠能切出 8 个，一个 "large" 青柠能切出 10 个。

当你还需要更多青柠角，而手里也还有青柠可以切时，就从数组中取出第一个青柠，并从你还需要的数量中减去相应数量的青柠角。
一直继续，直到你不再需要青柠角，或者青柠用完为止。

实现函数 `makeWedges(needed:limes:)`，它接收参数 `needed`（你需要切出的青柠角数量）和 `limes`（一个字符串数组，表示你可用来切青柠的青柠大小）。
函数应返回你切了多少个青柠。

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. 结束你的班次

恭喜！漫长的一天工作快结束了，你很快就能回家去开发你的新应用。不过在你把订单交接给下一个班次、然后离开之前，还有一连串的饮品订单要做。

只要班次里还有剩余时间，你就先处理数组中的第一笔订单，然后把该订单从数组中移除。
接着，根据你的函数 `timeToPrepare(drinks:)`，从班次的剩余时间中减去准备这笔订单所花的时间。

实现函数 `finishShift(minutesLeft:remainingOrders:)`，它接收班次剩余的分钟数（保证大于 0）和一个非空的饮品订单数组。
函数应返回在班次结束前你还没处理到的订单数组。

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. 追踪特定的订单

为了确保啤酒和汽水保持新鲜，你需要追踪它们的订单以及下单的时间。

实现函数 `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`，当给定订单和时间的列表时，返回一对可选元组，其中包含啤酒和汽水第一笔和最后一笔订单的时间，以及各自的订单总数；如果这些饮品没有订单，则为 `nil`。你不需要追踪其他饮品。

实现函数 `orderTracker(orders:)`，它接收一个元组数组，每个元组包含所点的饮品和下单时间。
函数应返回一个元组，其中包含啤酒第一笔和最后一笔订单的时间、啤酒订单总数、汽水第一笔和最后一笔订单的时间，以及汽水订单总数。
返回的元组格式为：`(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`。

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
