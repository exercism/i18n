# 关于

## 包含

C++ 使用`include`指令来包含其他文件的内容。这些包含指令应写在文件开头。编译期间，带有该指令的那一行会被替换为对应文件的内容。包含完成后，命名空间与原文件中的保持一致。

## 标准库

标准库提供了许多常用的函数、算法和数据结构。标准库使用`std`命名空间。

一个例子是 C 的数值库`cmath`。它提供了许多常用的数学运算。

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
标准库用尖括号`<>`包含，而不是双引号`"`。区别在于编译器搜索相应文件的位置。使用尖括号时，会跳过在当前项目中的搜索，直接从系统的包含目录开始搜索。如果要包含本地文件，就使用双引号：`#include "myfile"`
~~~~
