# 安装

你需要 [Vim](http://www.vim.org) 来完成这些练习：

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [源码](#source)

## macOS

macOS 默认自带 Vim，但版本已经过时得不像话了。

你大概会用 [MacPorts](https://www.macports.org) 或 [Homebrew](https://brew.sh) 来安装软件。

Homebrew：

```
$ brew update
$ brew install vim
```

MacPorts：

```
$ sudo port install vim +huge
```

如果你想要图形界面，可以改用 [MacVim](https://macvim-dev.github.io/macvim)。

## Ubuntu / Debian

安装带图形界面支持的完整版 Vim（`gvim`）：

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

使用 [Chocolatey](https://chocolatey.org)：

```
C:\> choco install vim
```

或者直接从[这里](http://www.vim.org/download.php#pc)下载并安装。
