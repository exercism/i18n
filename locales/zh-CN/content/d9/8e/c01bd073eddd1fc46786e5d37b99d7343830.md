# 说明

Lucy 开了一家在线贴纸店，卖各种可爱的贴纸，贴纸上印着大家最喜欢的编程语言。世界各地的人都来买她的贴纸，而她在应付各种不同货币时遇到了一些麻烦。

编写一个程序，让 Lucy 用它来计算价格，同时确保她始终使用的是正确的货币。

## 1. 定义`Usd`、`Eur`和`Jpy`类型

这些类型用于表示 Lucy 的顾客购买贴纸时使用的不同货币。

它们用作幻影类型，不需要有任何构造函数。

## 2. 定义`Money`类型

`Money`类型应该有一个用于表示金额的`Int`字段、一个货币幻影类型参数，并且是不透明类型。

## 3. 定义`dollar`、`euro`和`yen`函数

定义`dollar`、`euro`和`yen`函数，它们接收一个`Int`实参，并返回一个带正确货币的`Money`值。

## 4. 定义`total`函数

定义`total`函数，它接收一个由`Money`值组成的数组，并返回数组中金额的总和。

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
