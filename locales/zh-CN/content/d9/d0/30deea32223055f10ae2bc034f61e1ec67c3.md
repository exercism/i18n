# 介绍

## 布尔值

`Bool`类型是这门编程语言的基本组成部分之一。它用来描述某个东西是真的还是假的，对应的值分别是`True`和`False`。

布尔值可以用`&&`（“AND”）和`||`（“OR”）运算符组合，也可以用`not`函数取反。

布尔值还非常适合用来在代码中创建分支：只有当满足特定条件时，这些分支才会执行。在 Elm 中，这通过`if-then-else`表达式实现，用法如下。

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
