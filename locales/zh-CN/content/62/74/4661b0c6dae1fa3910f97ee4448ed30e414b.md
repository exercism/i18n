# PowerShell

自动化一切！
在任何操作系统上编写脚本，管理文件、进程、数据中心或云服务。
交互式地探索 JSON、XML 和 CSV 等结构化数据；从 Web API 和 CIM 到命令行应用，各种管理接口都能驾驭。

# 关于 PowerShell

PowerShell 是一门开源、跨平台的 .NET 脚本语言、shell 和配置管理框架，能帮助 IT 专业人员与高级用户控制和自动化几乎任何事情。

PowerShell 构建在 .NET Framework 之上，它改造了经典的 Unix 管道概念，把它从只传递文本或二进制流，扩展为可以传递对象实例，这些实例携带着类型信息（例如日期和时间），以及带有结构化数据的复杂状态。
在传统 shell 中，你可能需要用文本处理从命令的输出里提取特定的信息；而在 PowerShell 里，你可以直接访问属性和方法（包括检查对象、确定它有哪些属性和方法的办法）。
你可以处理 CSV 文件、把 JSON 转换成哈希表、浏览 XML 文档，还有更多，让许多用文本解析会变得困难甚至不切实际的任务都能轻松组合起来。

PowerShell 是可扩展的。
它的可扩展性不只是像其他 shell 那样通过独立的命令行工具实现，还可以通过以模块形式分发的脚本、函数和 cmdlet 实现，这些模块真正与 PowerShell 的帮助系统、带语法高亮的命令行编辑器、自动形参发现和 Tab 补全完全集成。
你甚至可以把文件系统那套简单、可探索的“属性 + 内容”语法，扩展到 Windows 注册表、证书存储、SQL Server 乃至 Azure 这样的数据存储上！

PowerShell 还包含许多额外功能：

- 内置的“cmdlet”，用于常见的系统管理任务，比如管理文件、服务、进程，甚至注册表、事件日志、通用信息模型（CIM），以及 Web 请求等。
- 兼容现有的脚本和命令行工具。
- 可扩展的接口，以及易于发现的模块和命令。
- 对 .NET Framework 的完全访问，以及通过来自 NuGet 的 .NET 程序集进行扩展。
- 丰富的命令历史，包含命令执行是否成功以及耗时多久的信息。
- 强大的对象操作能力。对象可以被直接操作、序列化，甚至发送给其他工具或数据库。

关于 PowerShell 这门语言及其核心概念和功能的详细文档，可以随安装程序一起找到，网址是 https://docs.microsoft.com/en-us/powershell。
