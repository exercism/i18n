# 简介

## 随机性

在 Java 中，可以使用`java.util.Random`类的实例来生成随机数。

### 随机整数

可以使用`nextInt()`方法生成一个随机整数。
它生成的值介于`Integer.MIN_VALUE`和`Integer.MAX_VALUE`之间。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

要限制生成值的范围，可以使用`nextInt(int)`。
它生成的值从`0`（包含）到给定的上界（不包含）。

例如，下面这行代码会生成一个从`0`到`9`的随机数。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

而下面这行代码会生成一个从`10`到`19`的随机数。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### 随机双精度浮点数

可以使用`nextDouble()`方法生成一个随机的双精度浮点数。
它生成的值介于`0.0`和`1.0`之间。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

而下面这行代码会生成一个从`100.0`到`200.0`的随机数。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
