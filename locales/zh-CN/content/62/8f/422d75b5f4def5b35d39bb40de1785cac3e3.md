# 说明

在本练习中，你将实现一组不完整的工具例程，用来帮助开发者清理标识符名称。
你将在 5 个任务中逐步构建 `Clean` 例程。
有效的标识符由零个或多个字母和下划线组成。
在所有情况下，输入字符串都保证不为 null。
如果向 `Clean` 函数传入空字符串，则应返回空字符串。
请注意，调用方应避免用空标识符调用 `Clean` 例程，因为这样的标识符没有实际作用。

## 1. 把遇到的所有空格替换为下划线

实现（_static_）`Identifier.Clean()`方法，把任意空格替换为下划线。
这也适用于开头和结尾的空格。

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. 把控制字符替换为大写字符串 "CTRL"

修改（_static_）`Identifier.Clean()`方法，把控制字符替换为大写字符串`"CTRL"`。

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. 把 kebab-case 转换为 camelCase

修改（_static_）`Identifier.Clean()`方法，把 kebab-case 转换为 camelCase。

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. 省略所有不是字母的字符

修改（_static_）`Identifier.Clean()`方法，省略所有不是字母的字符。

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. 省略小写希腊字母

修改（_static_）`Identifier.Clean()`方法，省略从 'α' 到 'ω' 范围内的所有希腊字母。

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
