# 说明

在这个练习中，你要和朋友玩一个猜数字的游戏。规则很简单：你偷偷选定`1`到`100`之间的一个数字，然后让朋友来猜你选的是哪个数。为了帮朋友缩小范围，你要根据猜测值与所选数字（`42`）的接近程度给出不同的回复。不同回复的规则如下：

- 如果猜测是`42`："Correct"
- 如果猜测是`41`或`43`："So close"
- 如果猜测小于`41`："Too low"
- 如果猜测大于`43`："Too high"

你有四个任务，来完成对各种猜测的回复。

## 1. 回复猜对的情况

实现`reply`函数，让它能回复猜对的情况：

```fsharp
reply 42
// => "Correct"
```

## 2. 回复猜得很接近的情况

修改`reply`函数，让它能回复猜得很接近的情况：

```fsharp
reply 41
// => "So close"
```

## 3. 回复猜测值偏低的情况

修改`reply`函数，让它能回复猜测值偏低的情况：

```fsharp
reply 25
// => "Too low"
```

## 4. 回复猜测值偏高的情况

修改`reply`函数，让它能回复猜测值偏高的情况：

```fsharp
reply 88
// => "Too high"
```
