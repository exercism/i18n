# 关于

[WebAssembly](https://webassembly.org/) 是一种面向基于栈的虚拟机的二进制指令格式。它是 W3C 标准，已内置于所有主流浏览器中，并支持流式编译，还能与 JavaScript 方便地互操作。[大多数编译型语言](https://github.com/appcypher/awesome-wasm-langs)现在都能生成 WebAssembly 二进制文件，让 JavaScript 以外的语言也能在客户端执行。此外，[许多服务端运行时](https://github.com/appcypher/awesome-wasm-runtimes)和云服务会执行 WebAssembly，其中不少都支持新兴的 [WebAssembly 系统接口（WASI）](https://wasi.dev/)。

本学习路径的重点是手写 WebAssembly 文本格式（\*.wat）文件，以便熟悉虚拟机、指令集架构，以及核心规范提供的模块抽象。虽然大多数 WebAssembly 的生产部署都是从更高级的语言编译而来，但许多开发者依赖相对重量级的框架，这些框架通过重量级的 JavaScript 胶水代码把 WebAssembly 虚拟机抽象掉，并生成相对较大、动辄数兆字节的二进制文件，导致启动时间变慢。更深入地理解 WebAssembly，能让你创建更小的模块，并完全掌控模块与周围宿主环境的交互方式。你可能会惊讶，用[手写的几 KB WebAssembly](https://github.com/binji/raw-wasm) 竟能做到什么！
