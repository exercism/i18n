# 测试

## 练习文件

下载的练习会包含以下文件，用于构建并测试你提交的解答：

```text
hello-world/
├── HelloWorld.vb       # Your solution
├── HelloWorldTests.vb  # The test suite
├── HelloWorld.vbproj   # Project and build configuration
└── packages.lock.json  # Resolved project dependencies
```

文件名因练习而异。
把解答写在名称不以 `Tests` 结尾的 `.vb` 文件中。
以 `Tests.vb` 结尾的文件是 xUnit 测试套件；通常只有为了去掉 `Skip` 实参时才需要编辑它。
一般情况下，你不需要编辑项目文件或锁定文件。

## 运行测试

在练习目录中打开终端，然后运行：

```bash
dotnet test
```

这个命令会还原项目的依赖项、构建项目并运行其中的测试。
也可以用 `dotnet watch test`，这样每当源文件发生变化时都会重新运行测试。

## 跳过的测试

练习一开始只会启用第一个测试，这样你就可以一步一步地解决剩下的测试。
打开以 `Tests.vb` 结尾的文件就能找到这些测试。
每个测试都是一个用 xUnit `<Fact>` 特性标记的 `Sub` 子例程。
只要某个测试的 `<Fact>` 特性带有 `Skip` 实参，这个测试就会被跳过：

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

要启用这个测试，只需去掉 `Skip` 实参：

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

新启用的测试通过后，用下一个被跳过的测试重复这个过程。
当所有测试都已启用并通过时，你就完成了。
