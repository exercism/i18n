# 布尔值

`bool` 类型（布尔值的缩写）只有两个值：`true`和`false`。
在代码中，`true`和`false`这两个字面量不区分大小写。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

布尔值常出现在逻辑表达式中，作为运算符的运算结果，然后又用在控制结构里。

## 逻辑运算符

逻辑运算符有以下几个：

- `!$a`：如果 `$a` 不是 `true`，就返回 `true`
- `$a && $b`：如果 `$a` 和 `$b` 都是 `true`，就返回 `true`
- `$a || $b`：如果 `$a` 或 `$b` 中有一个是 `true`，就返回 `true`

~~~~exercism/caution
`and`和`or`这两个运算符分别与`&&`和`||`相对应。
但它们的行为与`&&`和`||`并不相同，可能会产生意想不到的结果，因此不建议使用。
~~~~
