# 说明

你是一位热衷于观鸟的人，会记录过去 7 天里有多少只鸟来过你的花园。

你有 6 个任务，它们都与来过你花园的鸟的数量有关。

## 1. 查看今天有多少只鸟来访

实现 `today()` 函数，返回今天有多少只鸟来过你的花园。
鸟的数量按天排列，第一个元素是最早那天的数量，最后一个元素是今天的数量。

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> today(birds_per_day)
1
```

## 2. 增加今天的计数

实现 `increment_todays_count()` 函数，把今天的计数加一：

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> increment_todays_count(birds_per_day)
[2, 5, 0, 7, 4, 2]
```

## 3. 检查是否存在没有鸟来访的一天

实现 `has_day_without_birds()` 函数，如果存在某一天没有鸟来过花园，就返回 `true`，否则返回 `false`：

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> has_day_without_birds(birds_per_day)
true
```

## 4. 计算前若干天来访鸟的数量

实现 `count_for_first_days()` 函数，返回从这周开始以来来过你花园的鸟的数量，但只统计从这周开始算起的指定天数。

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> count_for_first_days(birds_per_day, 4)
14
```

## 5. 计算繁忙的天数

有些天比其他天更忙。
繁忙的一天指的是至少有 5 只鸟来过你的花园。
实现 `busy_days()` 函数，返回繁忙的天数：

```julia-repl
julia> birds_per_day = [2, 5, 0, 7, 4, 1]
julia> busy_days(birds_per_day)
2
```

## 6. 按一周中的每天计算平均值

你决定扩展记录，保存多周的数据。
每种情况下，计数都按一周中的天排列，第一个条目是周一，最后一个是周日。

实现 `average_per_day()` 函数，返回 2 周的平均值。

```julia-repl
julia> week1 = [7, 2, 9, 1, 3, 0, 10]
julia> week2 = [2, 6, 4, 1, 3, 8, 9]
julia> average_per_day(week1, week2)
[4.5, 4.0, 6.5, 1.0, 4.0, 3.0, 9.5]
```
