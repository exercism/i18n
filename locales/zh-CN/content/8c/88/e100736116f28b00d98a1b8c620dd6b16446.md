# 说明

如果你想用 Raspberry Pi 做点什么，多半会用到_电阻器_。
在这个练习中，你需要了解关于它们的 2 件事：

- 每个电阻器都有一个电阻值。
- 电阻器很小，小到如果把电阻值印在上面，会很难看清。

为了解决这个问题，制造商会把带有颜色编码的色环印到电阻器上，用来表示它们的电阻值。
每个色环都有一个位置和一个数值。

电阻器的前 2 个色环采用简单的编码方案：每种颜色对应一个数字。

第 3 个色环是乘数。

在这个练习中，你将编写一个实用的小程序，这样就不必费心去记各个色环的值了。

关于电阻器颜色编码的更多信息，可以在[维基百科的电子色码条目][e-color-code]中找到。

## 1. 定义命名向量

颜色的编码方式如下：

- black: 0
- brown: 1
- red: 2
- orange: 3
- yellow: 4
- green: 5
- blue: 6
- violet: 7
- grey: 8
- white: 9

创建命名向量`resistor_bands`，让它以颜色作为名称，以数字作为值。

## 2. 返回一个色环对应的值

首先，你需要能够找出任意一个有颜色的色环对应的那个值。

定义一个函数`band_value(band)`，它接收一个表示色环颜色的`string`。
该函数返回这个颜色对应的值。

```R
band_value("green")
# => [1] 5

band_value("violet")
# => [1] 7
```

## 3. 返回两个色环对应的值

电阻器上的前 2 个色环组合起来，构成一个数字。
如果前 2 个色环对应的数字分别是`m`和`n`，它们组合起来就构成数字`mn`。

定义一个函数`two_band_value(bands)`，它接收一个包含 2 个色环颜色的`string`的`vector`。
该函数返回这 2 种颜色组合起来对应的值。

```R
two_band_value(c("yellow", "red"))
# => [1] 42

two_band_value(c("green", "violet"))
# => [1] 57
```

## 4. 返回三个色环对应的欧姆值

最后，你需要结合前 2 个色环和第 3 个色环，求出完整的欧姆值。
为此，你需要求出 2 个色环组合的值和一个乘数。
乘数可以理解为在 2 个色环组合的值后面补上多少个零。

定义一个函数`ohms(bands)`，它接收一个包含 3 个色环颜色的`string`的`vector`。
该函数返回这 3 种颜色组合起来对应的欧姆值。

```R
ohms(c("yellow", "red", "orange"))
# => [1] 42000

ohms(c("green", "violet", "yellow"))
# => [1] 570000
```
