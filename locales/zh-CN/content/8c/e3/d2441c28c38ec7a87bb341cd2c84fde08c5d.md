# 指令补充

## 弃用 `String.lowercase`

根据你安装的 OCaml 版本，使用`String.lowercase`可能并不被推荐。
从 4.03.0 版本开始，`String.lowercase`已被弃用，应改用`String.lowercase_ascii`。
所以不要这样写

```ocaml
String.lowercase "Hello, World!"
```

而要这样写

```ocaml
String.lowercase_ascii "Hello, World!"
```

更多实用函数请参阅 [String 文档][string]。

[string]: http://caml.inria.fr/pub/docs/manual-ocaml/libref/String.html
