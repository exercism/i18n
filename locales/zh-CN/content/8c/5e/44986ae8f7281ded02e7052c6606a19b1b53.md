# 介绍

## 数字

Haskell 有一个类型`Num`，它是所有数字类型的基础类型。
数字类型下主要有四个子类型：[`Int`][int]、[`Integer`][integer]、[`Double`][double] 和 [`Float`][float]。

Haskell 中有两种整数类型，用来表示整数。
`Int`是固定大小的整数，而`Integer`是任意精度的整数。
`Integer`可以保存任意大小的数字，直到达到计算机内存的限制；而`Int`对应的是可以用 32 或 64 位表示的正整数和负整数集合（保证至少为 -2^29 到 2^29 - 1）。

注意，写负数时应该用圆括号，以免产生歧义。

```haskell
1

(-1)
```

`Float`对应实数集合，但受计算机精度的限制。
为数字定义的操作通常只适用于一种类型，而不是两种都适用。
`Double`是双精度浮点数。

```haskell
10.5
```

### 整数与浮点数之间的转换

使用`toFloat`函数可以将`Int`或`Integer`转换成`Float`。

```haskell
toFloat 1
-- -> 1.0
```

还有`fromIntegral`，它可以把任意数字类型转换成推断出的所需数字类型。

```haskell
fromIntegral 1
-- -> 1.0
```

要把`Float`转换成`Int`，可以使用[`round`][round]、[`floor`][floor]或[`ceiling`][ceiling]函数。
`round`函数舍入到最接近的整数，`floor`向下取整，`ceiling`向上取整。

```haskell
round 1.5
-- -> 2

floor 1.5
-- -> 1

ceiling 1.5
-- -> 2
```

### 算术运算符

你可以在数字类型上使用[基本算术运算符][math]。
运算符有`+`、`-`、`*`、`/`和`%`。
使用这些运算符时，数字的类型必须匹配。
`fromIntegral`函数会进行转换，使类型匹配。

#### 加法、减法与乘法

`+`运算符用于加法，`-`运算符用于减法，`*`运算符用于乘法。

| 运算符 | 示例        |
| -------- | -------------- |
| `+`      | `4 + 6 => 10`  |
| `-`      | `15 - 10 => 5` |
| `*`      | `2 * 3 => 6`   |

#### 除法

除法用于把数字相除。
`/`运算符用于除法。
结果始终是浮点数。

```haskell
4.0 / 2.5
-- -> 1.6

4 / 2
-- -> 2.0
```

~~~~exercism/caution
在某些编程语言中，除以零会得到错误。

在 Haskell 中，除以零的结果是`Infinity`或`-Infinity`。
唯一的例外是零除以零，结果为`NaN`（非数）。

```haskell
1 / 0
-- -> Infinity

(-1) / 0
-- -> -Infinity

0 / 0
-- -> NaN
```
~~~~

### 整数除法

整数除法用于对整数做除法，并得到结果的整数部分。
Haskell 有两个整数除法函数，它们在结果为负数时的舍入方式不同：

- `div`向下舍入，朝负无穷方向。
- `quot`向零舍入。

```haskell
6 `div` 2
-- -> 3

5 `div` 2
-- -> 2

(-5) `div` 2
-- -> -3

5 `quot` 2
-- -> 2

(-5) `quot` 2
-- -> -2
```

~~~~exercism/caution
使用整数除法时除以零会导致异常。
这与普通除法不同。
~~~~

#### 余数

整数除法的余数可以用`mod`或`rem`求得。
当其中一个数字为负数时，它们的结果符号不同：

- `mod`与`div`配套使用，其结果与除数符号相同。
- `rem`与`quot`配套使用，其结果与被除数符号相同。

```haskell
5 `mod` 3
-- -> 2

(-5) `mod` 3
-- -> 1

5 `mod` (-3)
-- -> -1

5 `rem` 3
-- -> 2

(-5) `rem` 3
-- -> -2

5 `rem` (-3)
-- -> 2
```

对于任意`x`和`y`（其中`y`不为零），以下等式成立：

```haskell
(x `div` y) * y + (x `mod` y) == x
(x `quot` y) * y + (x `rem` y) == x
```

~~~~exercism/note
当两个数字都为正时，`div`和`quot`结果相同，`mod`和`rem`也相同。
在这种情况下，`quot`和`rem`可能稍微更高效，因为`div`和`mod`需要额外步骤来处理负数。
~~~~

~~~~exercism/caution
使用`mod`或`rem`时除以零会导致异常。
这与普通除法不同。

```haskell
1 `mod` 0
-- Exception: divide by zero
```
~~~~

### 幂运算

Haskell 有三个“求幂”运算符，它们的工作方式不同，接受的实参类型也不同。

- `**`接受两个**浮点数**，并使用对数计算幂。
- `^^`接受一个**浮点数**，并将其提升到正或负**整数**次幂。
- `^`接受**任意数字类型**，并将其提升到**正整数**次幂。

```haskell
3.0 ** 2.1
-- -> 10.04510856630514

2.5 ^^ 2
-- -> 6.25

2 ^ 3
-- -> 8
```

### 优先级与圆括号

Haskell 允许使用圆括号（`()`），可以用来对表达式分组。
当你想改变运算顺序时，这很有用。

使用多个算术运算符时，运算顺序与数学中相同，也称为 [PEMDAS][pemdas]。
它遵循的顺序是：圆括号（`()`）、指数（`**`）、乘法（`*`）和除法（`/`），以及加法（`+`）和减法（`-`）。

```haskell
2 + 3 - 4 * 4
-- -> -11

(2 + 3 - 4) * 4
-- -> 4
```
