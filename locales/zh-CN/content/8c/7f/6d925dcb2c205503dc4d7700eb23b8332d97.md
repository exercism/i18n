# 简介

`call`（位于 [`kernel`][kernel] 中）用于运行 quotation。当 quotation 的栈效果无法推断时（通常是因为该 quotation 来自别处），需要在 `call` 上显式声明其效果：

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

由于 quotation 本身就是值，一个数组里可以混放数字和 quotation，于是“程序”也不过是另一种序列：

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
