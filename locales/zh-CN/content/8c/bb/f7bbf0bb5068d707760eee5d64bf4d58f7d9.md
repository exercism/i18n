# 安装

## 安装 R 运行时
访问 [CRAN 主页](https://cran.r-project.org/)。在那里你可以找到 Linux、Mac OSX 和 Windows 的下载链接。下载并运行适用于你的操作系统的安装程序。

## 安装 RStudio IDE（推荐）
RStudio 是一款流行的跨平台集成开发环境（IDE），用于 R 编程（也支持 Python、JavaScript 和 Markdown 等其他语言）。使用 RStudio 可以让编写解答代码和运行测试更加轻松。

下载并安装[当前稳定版 RStudio](https://www.rstudio.com/products/rstudio/download/)。或者，也可以获取即将发布的[预览版](https://www.rstudio.com/products/rstudio/download/preview/)。

## 安装适用于 R 的 Visual Studio Code 扩展（备选方案）
Visual Studio Code 的 R 扩展支持扩展语法高亮、代码补全、代码检查、格式化、与 R 终端交互、查看数据、图表、工作区变量、帮助页面、管理包，以及处理 R Markdown 文档。

下载并安装[当前版本的 R 扩展](https://code.visualstudio.com/docs/languages/r)

## 安装用于运行测试的 R 包
用于运行测试的测试运行器是 Hadley Wickham 的 [`testthat`](https://github.com/hadley/testthat) 库，它是 R 包作者的热门选择。

要安装这个库，请在 RStudio 控制台（或你使用 R 的任何地方）输入以下内容。

```{R}
install.packages("testthat")
```

虽然你不太可能_需要_安装包来解决 Exercism 的练习，但你可能想引入像 [`tidyverse`](https://github.com/tidyverse/tidyverse) 这样符合你编程风格的通用工具包。要安装并加载像 `tidyverse` 这样的包：

```{R}
install.packages("tidyverse")
library(tidyverse)
```
