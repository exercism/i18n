# 数组方法

数组是一种常用的数据结构。因此，有一系列方法可以用来处理数组，包括排序、反转、插入等等。

其中一些方法是破坏性的，也就是说它们会修改原数组。另一些则是非破坏性的，也就是说它们会返回一个新数组，不会修改原数组。

下面是处理数组时最常用的一些方法：

## insert

向数组中插入元素时，可以使用 [`insert`][insert] 方法，它接收一个下标和一个元素作为实参。
元素会被插入到指定的下标处，数组的其余部分会向右移动。
如果下标越界，就会抛出 `IndexError`。

```crystal
numbers = [1, 2, 3]
numbers.insert(1, 4)
numbers # => [1, 4, 2, 3]

numbers.insert(5, 5) # => Error: Index out of bounds (IndexError)
```

## delete

当你想要从数组中删除某个特定元素时，可以使用 [`delete`][delete] 方法，它接收一个元素作为实参。
该方法会返回被删除的元素。
如果数组中不存在该元素，则返回 `nil`。

```crystal
numbers = [1, 2, 3]
numbers.delete(2) # => 2
numbers           # => [1, 3]
```

## first & last

当你想要获取数组的第一个或最后一个元素时，可以使用 [`first`][first] 和 [`last`][last] 方法。
这些方法接收一个可选的实参，用来指定返回多少个元素。
与使用下标 `0` 或 `-1`、或者使用范围相比，这样更具可读性。
如果数组为空，就会抛出 `Enumerable::EmptyError`。

```crystal
numbers = [1, 2, 3]
numbers.first # => 1
numbers.last  # => 3

numbers.first(2) # => [1, 2]
numbers.last(2)  # => [2, 3]

empty_array = [] of Int32
empty_array.last # => Error: Empty enumerable (Enumerable::EmptyError)
```

## reverse

当你想要反转数组时，可以使用 [`reverse`][reverse] 方法，它会返回一个元素顺序相反的新数组。
需要注意的是，`reverse` 返回的是一个新数组，不会修改原数组。
如果你想修改原数组，可以在方法名末尾加上 `!`。

```crystal
numbers = [1, 2, 3]
numbers.reverse # => [3, 2, 1]
numbers         # => [1, 2, 3]

numbers.reverse! # => [3, 2, 1]
numbers          # => [3, 2, 1]
```

## Concat(`+`)

追加方法（`<<`）在向数组添加对象时很有用。
不过，在合并两个数组时，可以使用 [`+`][concat] 运算符，它会返回一个包含两个数组所有元素的新数组。

```crystal
[1, 2] + [3, 4] # => [1, 2, 3, 4]
```

如果你把一个数组追加到另一个数组，这个数组会作为单个元素被添加进去。

```crystal
[1, 2] << [3, 4] # => [1, 2, [3, 4]]
```

## empty?

当你想要检查数组是否为空时，可以使用 [`empty?`][empty?] 方法，如果数组为空就返回 `true`，否则返回 `false`。
与用 `0` 比较数组的长度相比，这样更具可读性。

```crystal
[].empty? # => true
[1, 2, 3].empty? # => false
```

## index

当你想要获取某个元素在数组中的下标时，可以使用 [`index`][index] 方法，它接收一个元素作为实参。
如果数组中不存在该元素，则返回 `nil`。

```crystal
numbers = [1, 2, 3]
numbers.index(2) # => 1
```

## size

当你想要知道数组中元素的个数时，可以使用 [`size`][size] 方法。

```crystal
numbers = [1, 2, 3]
numbers.size # => 3
```

## count

当你想要统计某个元素在数组中出现的次数时，可以使用 [`count`][count] 方法。

```crystal
fruits = ["apple", "banana", "apple"]
fruits.count("apple")      # => 2
fruits.count("banana")     # => 1
fruits.count("watermelon") # => 0
```

## sort

当你想要对数组排序时，可以使用 [`sort`][sort] 方法，它会返回一个元素已排好序的新数组。
和 `reverse` 一样，这个方法返回的是一个新数组，不会修改原数组。

```crystal
numbers = [3, 2, 1]
numbers.sort # => [1, 2, 3]
numbers      # => [3, 2, 1]

numbers.sort! # => [1, 2, 3]
numbers       # => [1, 2, 3]
```
