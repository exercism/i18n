# 命令与实参入门

本 track 讲的不是如何把 bash 当作交互式 shell 来用。
它讲的是学习如何用 bash 这门编程语言来编写程序。

一个 bash 程序，或者说_脚本_，就是存放在文件里的一串命令。
bash（那个可执行程序）会读取这个文件，并按顺序执行其中的命令。

## shebang

脚本的第一行通常是一条_解释器指令_，也叫 _hashbang_ 或 _shebang_：

```bash
#!/usr/bin/env bash
```

当操作系统执行一个非二进制文件时，它会读取第一行。
如果这一行以`#!`开头，内核就会根据它来决定用哪个解释器来执行这个文件。
`#!`必须位于文件的最开头，前面不能有空格或空行。

这里，`env`会在`PATH`中搜索`bash`可执行文件。
你可能还会见到更简单的`#!/bin/bash`，它把解释器的位置写死了；`env`这种写法可移植性更好。

~~~~exercism/note
请不要被网上用`/bin/sh`当解释器的脚本或示例骗了。
**`sh` 不是 `bash`！**
Bash 是“与 sh 兼容”的，能运行大多数`sh`脚本，但 bash 的一些功能在`sh`里会出错或表现异常。
~~~~

## 注释

以`#`开头的一行是一条_注释_，bash 会忽略它。
注释也可以跟在同一行的命令后面：从`#`到行尾的所有内容都会被忽略。
注释是给人读脚本时看的。

## 单词与实参

Bash 从它的输入（通常要么是终端，要么是文件）中读取命令。
它读取的每一行输入都会被当作一条_命令_，也就是一条要执行的指令。
（有一些高级情况，比如跨多行的命令，稍后再讨论。）

Bash 把每条命令拆分成由空白字符（空格和制表符）分隔的**单词**。
第一个单词就是要执行的_命令_的名字。
其余所有单词都成为该命令的_实参_（选项、文件名等）。

命令可以是一个 bash _内置命令_，比如`echo`，也可以是一个_可执行_程序，比如`head`、`awk`或`sed`。

## `echo` 命令

`echo`会把它的实参打印出来，实参之间用单个空格分隔，最后输出一个换行：

```bash
echo flour sugar eggs
```

输出：

```text
flour sugar eggs
```

实参之间有多少空白并不重要：

```bash
echo flour       sugar        eggs
```

```text
flour sugar eggs
```

不带任何实参调用`echo`会打印一个空行。

## 选项也是实参

许多命令都接受_选项_，用来改变它们的行为。
对 bash 来说，选项没有任何特别之处：它就是一个普通的单词，和相邻的单词用空白隔开。
命令自己决定如何解读它的实参。
按照惯例，选项以`-`开头。

`head`命令会打印文件开头的几行。
假设有一个文件`list.txt`：

```bash
head -n 2 list.txt
```

Bash 会把这一行拆成四个单词：

| 单词 | 作用 |
| ---------- | ------------------------------------------- |
| `head`     | 要执行的命令 |
| `-n`       | 一个选项，告诉`head`要计数的是_行_ |
| `2`        | `-n`选项的值 |
| `list.txt` | 要读取的文件 |

Bash 会把后三个单词原样传给`head`。
是`head`自己明白`-n`后面跟着一个数字，而剩下的那个单词是一个文件。

因为单词是靠空白分隔的，所以空白放在哪里很关键。
`head -n 2`会给`head`两个实参（`-n`和`2`），而`head -n2`只给它一个（`-n2`）。
许多命令两种写法都接受，但这取决于命令本身。
Bash 并不关心；它只负责把这一行拆成单词。

## 给实参加引号

[引号][Quotes]会把多个单词归为一个_单个实参_。
引号内的空白会被保留，而引号字符本身并不属于实参：

```bash
echo "flour       sugar        eggs"
```

```text
flour       sugar        eggs
```

如果某个实参（比如文件名）含有空白，就用引号把它括起来：

```bash
head -n 1 my shopping list.txt     # three files: "my", "shopping", "list.txt"
head -n 1 "my shopping list.txt"   # one file
```

## 运行脚本

要运行一个脚本，把它作为实参传给`bash`命令：

```bash
bash myscript
```

这样使用时，`#!`那一行只是一条注释。
你是在告诉操作系统如何运行这个文件。

另一种做法是给脚本文件加上可执行权限，然后像运行其他任何程序一样运行它：

```bash
chmod +x myscript
./myscript
```

这时，操作系统会根据`#!`那一行来决定用哪个解释器。
