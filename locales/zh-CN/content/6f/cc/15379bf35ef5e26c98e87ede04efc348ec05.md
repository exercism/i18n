# 简介

集合的定义通常包含一个写在尖括号里的占位符，按惯例常常是 T。这样的集合称为泛型。这样一来，集合的使用者就能指定集合里存放什么类型的元素。在上面的示例代码中，我们实例化了一个字符串数组。

要让一个类或函数成为**泛型**，可以使用`@:generic`特性。这样编译器就会把这个类或函数识别为泛型：

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
