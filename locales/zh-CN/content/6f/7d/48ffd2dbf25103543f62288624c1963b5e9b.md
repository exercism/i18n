# 简介

摘自[手册][man-types]

> jq 支持与 JSON 相同的一组数据类型：数字、字符串、布尔值、数组、对象（用 JSON 的话说，就是键只能是字符串的哈希），以及 "null"。

下面我们重点看**数字**。

## 数字与数字运算符

所有数字，无论是整数还是其他类型，都是 IEEE754 双精度浮点数。
这使我们的精度限制在 53 位。

数字可以使用常见的运算符：

- 算术：`+`、`-`、`*`、`/`、`%`
- 比较：`==`、`!=`、`<`、`<=`、`>=`、`>`
- 标准的[数学函数][man-math]

  对于只有一个输入的函数，用管道把值传给函数

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  对于有两个输入的函数，函数会忽略输入，而是期望把这些输入作为形参传入（还记得吗，形参之间用分号分隔）

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  分号是函数实参的分隔符，不是逗号。

## 其他 `jq` 表达式

要完成这个练习，你需要了解条件表达式。

### 条件表达式

`jq` 用 [`if-then-else` 表达式][if-then-else]来表示**条件表达式**。
作为一种_表达式_，它被放在管道里。

语法是：`if CONDITION then TRUE_EXPR else FALSE_EXPR end`。

`else` 子句是可选的。

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

更多条件使用 `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
