# 简介

## 布尔值

Java 中的布尔值由`boolean`类型表示，它的取值可以是`true`或`false`。

Java 支持三种布尔运算符：  

- `!`（NOT）：对布尔值取反  
- `&&`（AND）：接受两个布尔值，如果它们都是`true`，就返回`true`
- `||`（OR）：只要两个布尔值中有一个是`true`，就返回`true`

### 示例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
