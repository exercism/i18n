# 说明补充

本练习要求你处理异常。[异常](https://docs.oracle.com/javase/tutorial/essential/exceptions/definition.html)是程序运行期间发生的事件，它会打断程序指令的正常执行流程。

在 Java 中，异常分为两种：受检异常和非受检异常。

- [Java 中的受检异常与非受检异常](https://www.geeksforgeeks.org/checked-vs-unchecked-exceptions-in-java/)

- [非受检异常：争议](https://docs.oracle.com/javase/tutorial/essential/exceptions/runtime.html)

## 受检异常

受检异常是指在[编译时](https://en.wikipedia.org/wiki/Compile_time)进行检查的异常。

### 实际影响

对于任何可能[抛出](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)受检异常的方法，你必须在它的[方法签名](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html)中声明这些异常；而调用任何可能抛出受检异常的方法时，必须处理或重新抛出它们。

这是因为受检异常本来是设计为在运行时处理的，也就是说，它们是你能够从中恢复的错误。

### 使用场景示例

当方法无法返回任何有效结果时，就常常会用到它们。例如，一个查找方法没有找到它正在查找的那一项。

它是返回 null 或错误码之外的另一种选择。受检异常比这些做法更好，因为它会迫使方法的调用者去考虑出错的情况。

## 非受检异常

非受检异常是指不在[编译时](https://en.wikipedia.org/wiki/Compile_time)进行检查的异常。

### 实际影响

对于可能[抛出](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)非受检异常的方法，你不需要在它的[方法签名](https://docs.oracle.com/javase/tutorial/java/javaOO/methods.html)中声明这些异常；而调用任何可能抛出非受检异常的方法时，也不需要处理或重新抛出它们。

### 使用场景示例

非受检异常通常由程序中的缺陷引起，可以通过正确的编码来避免。例如：只要确保数组下标介于 0 和数组长度之间，就能避免 ArrayIndexOutOfBoundsException。
