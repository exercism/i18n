# 安装

## 安装 .NET

F# 学习轨道构建在 [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet) 平台之上，该平台可在 Windows、Linux 和 macOS 上运行。要构建 .NET 项目，你可以使用 .NET 命令行接口（CLI）。这个 CLI 是 .NET SDK 的一部分，你可以按照[安装说明](https://dotnet.microsoft.com/download)来安装它。注意：F# 学习轨道需要 SDK 8.0 或更高版本。

安装完成后，你可以在终端中运行以下命令，验证 CLI 是否安装成功：

```bash
dotnet --version
```

如果输出的版本大于或等于`8.0.100`，就说明 .NET SDK 已经成功安装。

## 使用 IDE

如果你想要功能更全面的编辑体验，大概会想用 IDE。以下是最受欢迎、且支持构建 .NET 项目的 IDE：

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) 加上 [Ionide-fsharp 扩展](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

注意：由于 .NET 项目格式与早期版本差异很大，较旧的 IDE（如 Visual Studio 2015）不受支持。
