# 简介

在 JavaScript 中，数组是一种类似列表的结构，长度不固定，可以存放任意类型的原始值或对象，甚至可以在同一个数组里混用不同类型。

要创建数组，把元素写在方括号`[]`之间。
要从数组中读取元素，把下标写在标识符后面的方括号`[]`里。
数组的下标从 0 开始。

例如：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

要获取数组中元素的个数，可以使用`length`属性：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

要修改数组中的某个元素，给对应的下标赋值即可：

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## 方法

每个数组对象都可以使用一些[方法][mdn-array]，用它们可以往数组中添加元素或删除元素。
下面介绍几个完成本练习时可能用到的：

### push

使用`.push(value)`可以把`value`_添加_到数组末尾。
该方法返回数组的新长度。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

使用`.pop()`可以把_最后一个_`value`从数组中_删除_。
该方法返回被删除的值。
这一改动会让数组的长度减少。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

使用`.shift()`可以把_第一个_`value`从数组中_删除_。
该方法返回被删除的值。
这一改动会让数组的长度减少。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

使用`.unshift(value)`可以把`value`_添加_到数组开头。
该方法返回数组的新长度。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

使用`.splice(index, 1)`可以把数组中指定`index`处的`value`_删除_。
该方法返回被删除的元素。

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
这些方法比上面介绍的更强大：

- `push`和`unshift`都允许一次推入或插入多个值，只需添加更多的实参。
  完成本练习并不需要这样做。
- Splice 可以通过增大第二个实参来删除多个值。
  完成本练习并不需要这样做。
- Splice 还可以把多个值作为实参添加在`deleteCount`之后。
  这样就可以替换值，或者在数组中间插入值（例如删除 0 个元素）。
  完成本练习并不需要这样做。
