# 简介

[`Set`][set] 是一种集合，用来存放元素，具有以下特点：

- 无序。
- 每个条目都是唯一的，重复添加不会有任何效果。
- 支持许多数学中集合常见的运算。

可以用 `Set()` 构造函数创建，任何迭代器都可以作为形参。

```julia-repl
julia> s1 = Set(1:4)
Set([4, 2, 3, 1])
```

用 `push!()` 添加新元素（和数组一样），用 `delete!()` 删除元素。

```julia-repl
julia> push!(s1, 5)
Set([5, 4, 2, 3, 1])

# Duplicates are ignored
julia> push!(s1, 3)
Set([5, 4, 2, 3, 1])

julia> delete!(s1, 5)
Set([4, 2, 3, 1])

julia> length(s1)  # length counts entries, despite the non-sequential type
4
```

## 集合运算

和其他几种集合类型一样，可以用 `in` 或 `∈` 运算符检查某个条目是否在集合中（输入 `\in` 然后按 Tab 键即可打出该符号）。

```julia-repl
julia> 3 ∈ s1
true
```

支持对两个集合进行以下运算（括号中给出了运算符符号的输入快捷方式）。

- `union(A, B)` 或 `A ∪ B`（`\cup`）：属于 A、属于 B，或同时属于两者的所有条目。
- `intersect(A, B)` 或 `A ∩ B`（`\cap`）：A 和 B 共有的所有条目。
- `setdiff(A, B)`（无符号）：属于 A 但不属于 B 的条目。
- `symdiff(A, B)`（无符号）：属于 A 或属于 B，但不同时属于两者的条目。
- `issubset(A, B)` 或 `A ⊆ B`（`\subseteq`）或 `B ⊇ A`（`\supseteq`）：如果 A 中的所有条目也都在 B 中，则为 `true`。
- `issetequal(A, B)`（无符号）：如果 A 和 B 包含完全相同的条目，则为 `true`。
- `isdisjoint(A, B)`（无符号）：如果 A 和 B 没有任何共同的条目（即交集为空），则为 `true`。

```julia-repl
julia> s1 = Set(1:4);
julia> s2 = Set(3:6);
julia> s1 ∪ s2  # union
Set([5, 4, 6, 2, 3, 1])

julia> s1 ∩ s2  # intersect
Set([4, 3])
  
julia> setdiff(s1, s2)
Set([2, 1])

julia> symdiff(s1, s2)
Set([5, 6, 2, 1])
  
julia> s1 ⊇ s2  # issubset
false
```

其中许多运算还有会修改原集合的版本，只需在函数名末尾加上 `!`。
完整的函数列表请参阅[手册][set]。
