# 安装

## 环境要求

* 64 位 x86 CPU
* 现代 C 编译器
* Make 构建工具
* Netwide Assembler（NASM）

请注意，本轨道仅支持 System V AMD64 ABI 的调用约定。Windows 用户需要安装 Windows Subsystem for Linux（WSL），或搭建一台 Linux 虚拟机。

## Linux

使用系统的包管理器安装所需软件：

* Ubuntu、Debian：`$ sudo apt-get install gcc make nasm`
* Fedora：`$ sudo dnf install gcc make nasm`
* CentOS、RHEL：`$ sudo yum install gcc make nasm`
* Arch Linux：`$ sudo pacman -S gcc make nasm`
* OpenSUSE：`$ sudo zypper install gcc make nasm`

## macOS

安装 Xcode 命令行工具：

```bash
$ xcode-select --install
```

使用 [Homebrew](http://brew.sh/) 安装 NASM：

```bash
$ brew install nasm
```

## Windows

要安装 WSL，请参阅 https://docs.microsoft.com/en-us/windows/wsl/install-win10。
