# 资源

除了[学习][learning]资源，以下几个地方也能帮你更好地学习 Odin：

* [Odin 演练场][play]，可以直接在浏览器里动手尝试。
* [odin-lang/Odin][gh] GitHub 代码仓库。
* Odin 的[社区][community]链接（论坛、Discord、Reddit 等）。
* [文章][articles]由 Odin 的创造者 gingerBill 撰写。
  这些文章能让你了解这门语言的一些设计理念。
* [风格指南][style]。
* [Awesome Odin][awesome]，收集了 Odin 库和资源的链接。
* 一系列关于 Odin 以及如何用它做游戏开发的[视频][vids]。
  作者是 Karl Zylinski，也是《Understanding Odin》一书的作者。
