# 指令补充

## 实现说明

测试程序通过反复调用可变参数的`New`函数来创建树。
例如，下面这条语句

```go
tree := New("a",New("b"),New("c",New("d")))
```

会构造出下面这棵树：

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

可以假定测试用的树中没有重复的值。

测试程序会用`Value`和`Children`这两个方法把树拆解开。

在开始练习中有趣的部分之前，基本的树构造和拆解必须已经能正常工作，所以前三项测试会单独测试这部分。

---

`FromPov`和`PathTo`这两个方法是练习中有趣的部分。

`FromPov`方法接收一个字符串实参`from`，它通过值指定树中的一个节点。
它应返回一棵根节点的值为`from`的树。
你可以修改原来的树并返回它，也可以新建一棵树并返回新树。
如果返回的是新树，你可以随意消耗或销毁原来的树。
当然，不改动它更好。

`PathTo`方法接收两个字符串实参`from`和`to`，它们通过值指定树中的两个节点。
它应返回树中从第一个节点到第二个节点的最短路径。
