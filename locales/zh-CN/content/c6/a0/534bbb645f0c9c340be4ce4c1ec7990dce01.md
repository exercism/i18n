# 说明

你所在的公司即将发布一款全新的智能手机，名叫 **Smarty 5**。它拥有全新的相机系统、全新的设计，以及一颗革命性的新处理器，运行着名为 **smartyOS** 的全新操作系统。

这颗新处理器能处理比以往更安全的密码，公司决定好好利用这一点。他们请你为这款手机实现一套密码锁系统，让用户可以设置密码，然后检查给定的密码是否正确。

~~~~exercism/caution
本练习中实践的密码系统并不安全，仅用于教学目的。
**切勿**将其用于任何真实的应用中。
~~~~

## 1. 设置密码

这款手机允许用户使用多种不同类型的密码：从简单的数字密码，到更安全的字母数字密码，甚至是可以存储指纹的密码。

这些不同类型的密码使用不同的数据类型：数字密码使用 `Int32`，字母数字密码使用 `String`，指纹密码使用 `Float64`。

实现 `PasswordLock` 类，它的初始化方法接受这三种密码中的任意一种作为实参，并将其存储在名为 `@password` 的实例变量中。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. 加密密码

公司决定加密密码，使它不以明文形式存储，并要求你实现一个用于加密密码的方法。

每种密码类型都有各自独特的加密方式：

- `Int32` 密码：密码除以 2，并四舍五入到最接近的整数。
- `String` 密码：密码被反转。
- `Float64` 密码：密码乘以 4。

实现一个名为 `encrypt` 的实例方法，它不接受任何实参，并修改 `@password` 实例变量，使其完成加密。

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. 检查密码是否正确

公司还要求你实现一个方法，用于检查给定的密码是否正确。

他们希望该方法在密码不正确时返回 `nil`，在密码正确时返回 `"Unlocked"`。

实现一个名为 `unlock?` 的实例方法，它把要检查的密码作为实参传入。
密码不正确时该方法应返回 `nil`，密码正确时应返回 `"Unlocked"`。

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
