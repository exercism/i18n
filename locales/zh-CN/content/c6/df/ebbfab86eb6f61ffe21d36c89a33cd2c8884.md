# 简介

Swift 的标准库虽然提供了丰富的功能，但你还可以通过导入外部库和框架，使用许多额外的功能。
这些模块可能直接来自 Swift 项目（比如 [Swift Argument Parser][argument-parser]），可能来自 Apple 平台的框架（比如 [Foundation][apple-foundation] 和 [Network Framework][network-framework]），也可能来自第三方开源库（比如 [SwiftyBeaver][swifty-beaver]）。

像 Foundation 这样的核心模块，是 Swift 中使用最广泛的库之一，会随 Swift 工具链一起提供。
第三方库必须先添加到你的项目配置中（例如使用 Swift Package Manager），然后才能导入。

要导入一个模块，先写`import`关键字，后面跟上模块名：

```swift
import Foundation
```

导入一个模块后，它的类型、方法和函数就能在你的代码中使用了。
比如，导入 Foundation 会为`String`扩展一些实用的方法，例如`components(separatedBy:)`。

按照惯例，`import`语句会放在 Swift 文件的开头，这样任何人阅读代码时都能立刻看到它依赖了哪些模块。

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
