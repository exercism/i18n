# 提示

## 1. 估算准备时间

- 使用向量的 [`size()`][size-func] 来确定层的数量（即 layers 切片的长度）。

## 2. 计算所需的面条和酱汁用量

- 首先，创建一个 `amount` 对象来记录面条和酱汁的用量。
- 使用 [`for` 循环][for-loop] 来遍历各层。
- 如果在循环中遇到 `"noodles"` 或 `"sauce"` 层，就相应地增加 `amount` 对象中记录的用量。

## 3. 加入秘密配料

- 重温[向量][concept-vector]，了解如何从向量中取出元素，以及如何替换向量中的元素。
- 向量 `a` 中最后一个元素的下标是 `a.size() - 1`，或者你也可以直接使用 `a.back()`。

## 4. 按比例调整食谱

- 首先，创建一个与输入切片大小相同的新切片。
- 使用 [`for` 循环][for-loop] 来遍历输入切片并生成输出切片。

## 5. 解锁家族秘方

- 你可以复用任务 3 中的代码。
- 这个任务需要用到[函数重载][function overloading]。
