# 简介

Factor 的错误系统由三部分组成：用`throw`发出错误信号，用`recover`处理错误，以及用`ERROR:`定义你自己的错误类型。

## `throw`

`throw`（位于[`kernel`][kernel]中）会抛出一个错误。它的参数可以是*任意*值，比如字符串、数字或元组，这个值会成为你之后可以检查的那个错误：

```factor
! DOCTEST: SKIP
"file not found" throw
```

`throw`不会返回；当前单词的其余部分会被跳过。

## `recover`

`recover`（位于[`continuations`][continuations]中）就是 Factor 的 try/catch。它接受一个 *try* 引用和一个 *recovery* 引用：

```
recover ( try recovery -- )
```

如果`try`执行完毕时没有抛出错误，`recovery`会被忽略。如果`try`抛出了错误，这个错误会被压入栈中，然后运行`recovery`：

```factor
[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"

[ "ok" ] [ drop "never runs" ] recover .
! => "ok"
```

来自[`kernel`][kernel]的`when`是它的天然搭档：只有当栈顶为真值时，它才会运行一个引用：

```factor
: check-positive ( n -- )
    0 < [ "negative!" throw ] when ;
```

## `ERROR:`

`ERROR:`既定义了一个元组类，*也*定义了一个单词，这个单词会构造一个新实例并把它抛出：

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

不带槽位的错误只需写成`ERROR: name ;`，调用`name`会抛出一个空实例。用`ERROR:`定义的元组会带有一个类谓词`name?`，你可以用它来判断捕获到的错误是否属于该类型。

## 读回槽位

捕获到的错误就是一个元组，所以每个`ERROR:`槽位都带有和其他任何元组相同的、自动生成的`slot>>`读取器。

```factor
! DOCTEST: SKIP
{
    T{ not-found { path "/a" } }
    T{ not-found { path "/b" } }
}
[ path>> ] map .   ! => { "/a" "/b" }
```
