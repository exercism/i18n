# 简介

在 JavaScript 中，_模板字符串_可以在字符串中嵌入表达式，也被称为字符串插值。
这一功能扩展了内置的[`String`][string-reference]全局对象的功能。

在 JavaScript 中，你可以用反引号包裹文本来创建模板字符串。
模板字符串不仅允许文本包含换行和其他特殊字符，还可以嵌入变量和其他表达式。

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

在上面的例子中，反引号（<code>\`\`</code>）用于表示模板字符串。`${...}`是用于替换的占位符。
任何非字符串类型都会被_隐式_转换为字符串。
这一话题在[类型转换][type-conversion-concept]概念中有所介绍。
各种类型的表达式都可以用于模板字符串。

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

当你需要让字符串跨多行排版时：

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

借助可用的替换能力，你还可以在过程中引入逻辑，来决定输出的字符串应该是什么。

一个例子就是嵌入[三元运算符][ternary-operator]。
这个运算符是编写`if/else`语句的简写形式。
语法是`condition ? consequent-expression : alternative-expression`。
如果条件为真值，就会返回冒号左侧的操作数。
否则，三元表达式的结果就是冒号右侧的操作数。

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
