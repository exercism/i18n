# 字符串类型

Cairo 没有原生的字符串数据类型。
不过，有两种表示字符串类型的方式：用单个`felt252`表示的短字符串，以及用`ByteArray`表示的任意长度字符串。

## 短字符串

短字符串用单引号书写，其中组成字符串的每个字符都按照 [ASCII 标准][ascii-table] 编码为一个字节。

作为 ASCII 字符串，`'abc'`例如会是这样：

- `'a'`等价于`0x61`
- `'b'`等价于`0x62`
- `'c'`等价于`0x63`
- `'abc'`等价于`0x616263`

在 Cairo 中，短字符串由`felt252`数据类型存储。
由于`felt252`只有 251 位，短字符串最多只能有 31 个字符（31 \* 8 = 248 位，这是能放进 251 位的 8 的最大倍数）。

短字符串的声明示例：

```rust
    let my_first_char = 'D';
    let my_first_char_in_hex = 0x44;

    let my_first_string = 'Hello world';
    let my_first_string_in_hex = 0x48656C6C6F20776F726C64;
```

### ByteArray

ByteArray 结构体是在 Cairo 2.4.0 中引入的。
ByteArray 字符串用双引号书写，如下所示：

```rust
    let long_string: ByteArray = "this is a string which has more than 31 characters";
```

从技术上讲，这次更新还引入了`bytes31`类型，它保存 31 个字节，可以放进一个 felt 中。
`ByteArray`结构体基本上是用一个由`bytes31`组成的数组来表示长字符串：这些`bytes31`保存“完整字”（即填满整个 felt 的字），以及一个保存“不完整的字”的 felt 字段（其中的字节数由单独的长度字段指定）。

```rust
#[derive(Drop, Clone, PartialEq, Serde, Default)]
struct ByteArray {
    data: Array<bytes31>,
    pending_word: felt252,
    pending_word_len: usize,
}
```

[ascii-table]: https://www.asciitable.com/
