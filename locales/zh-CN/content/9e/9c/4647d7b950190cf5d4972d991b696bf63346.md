# 说明

珍在一家大型工厂的分拣室工作。
分拣室需要处理送进来的一切东西，给它们贴上标签分类。
珍负责那些被预先归类为数字的东西，她需要一个程序来帮她分拣。

大多数基本值都应该得到简单直接的标签。
对于数字，她想要`"This is the number 2.0"`这样的字符串（如果这个数字是 2）。
无论是整数还是浮点数，珍都想要同样的输出。

有几个`Box`接口，需要拆开它们才能取出里面的内容。
对于`NumberBox`，她想要`"This is a box containing the number 3.0"`这样的字符串（如果`Number()`方法返回 3）。
对于`FancyNumberBox`，她想要`"This is a fancy box containing the number 4.0"`这样的字符串，但只有当它的类型是`FancyNumber`时才可以。

任何意料之外的东西都应该返回`"Return to sender"`，这样珍就能把它们退回到原来的地方。

## 1. 描述简单的数字

珍希望数字返回像`"This is the number 2.0"`这样的字符串（小数点后保留一位）：

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. 描述数字盒子

珍希望数字盒子返回像`"This is a box containing the number 2.0"`这样的字符串（同样，小数点后保留一位）：

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. 实现一个从花式数字盒子中提取数字的方法

珍需要一个辅助函数，从`FancyNumberBox`中提取数字。
如果`FancyNumberBox`是`FancyNumber`，就提取它的值，并把`string`转换成`int`。
其他任何类型的`FancyNumberBox`都应该返回 0。

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. 描述花式数字盒子

如果`FancyNumberBox`是`FancyNumber`，珍想要`"This is a fancy box containing the number 4.0"`这样的字符串。
其他任何类型的`FancyNumberBox`都应该返回`"This is a fancy box containing the number 0.0"`。

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

注意：我们应该使用`ExtractFancyNumber`函数！

## 5. 实现会用到以上所有的`DescribeAnything`

这是珍需要的主函数，它接受任意输入。
`DescribeAnything`应该根据传入值的类型，把工作委托给其他函数。
具体来说：

- `int`和`float64`都应该委托给`DescribeNumber`
- `NumberBox`应该委托给`DescribeNumberBox`
- `FancyNumberBox`应该委托给`DescribeFancyNumberBox`
- 其他任何情况都应该返回`"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
