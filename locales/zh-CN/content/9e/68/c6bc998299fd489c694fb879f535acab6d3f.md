# 测试

要使用测试运行器，你需要先[安装好 Godot][installation]。

## 运行测试

[测试运行器][test runner]用于加载和测试提交的解答。
要运行测试运行器，先把它下载到本地，然后用`godot`来运行。
将来使用`exercism download`时，测试运行器会随着练习一起自动下载。

```bash
godot --headless -s /path/to/test_runner.gd -- <solution-slug> <path/to/solution>
```
