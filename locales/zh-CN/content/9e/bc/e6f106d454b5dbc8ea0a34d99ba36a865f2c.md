# 说明

在这个练习中，你在一家为顾客提供外送服务的披萨店工作。

店里提供三种披萨：

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

顾客还可以支付少量额外费用，选择两种附加选项：

1. 额外酱料: \$1
1. 额外配料: \$2

顾客下单时，如果只订购一到两个披萨，还会收取一笔额外费用：

- 1 个披萨: \$3
- 2 个披萨: \$2

你有三个任务，每个任务都会处理披萨及其价格。

## 1. 定义披萨类型和选项

定义 `Pizza` 可区分联合，用来表示披萨类型以及可以添加到一个披萨上的两个附加选项：

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

## 2. 计算披萨的价格

实现 `pizzaPrice` 函数，用来计算一个披萨的价格：

```fsharp
pizzaPrice Caprese
// => 9
```

## 3. 计算订单的价格

实现 `orderPrice` 函数，用来计算一份披萨订单的价格：

```fsharp
orderPrice [Margherita; Formaggio]
// => 19
```
