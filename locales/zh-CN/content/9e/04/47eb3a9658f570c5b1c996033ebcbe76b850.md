# 测试

## 交互式测试

在你正在做的练习所在目录中启动你的 Common Lisp 实现（如果 Common Lisp 实现已经在运行，就把它的当前目录切换到该目录）。
用 roswell 的话，可以用`ros run`来完成。

（这里的所有示例都假设练习名为`exercise-name`，请按需调整。）

把测试文件加载到正在运行的 Lisp 实现中，例如`(load "exercise-name-test")`。
（这也会顺便为你加载解答文件。）
测试文件加载完成后，你可以在 REPL 中求值`(exercise-name-test:run-tests)`来运行测试。

随着你不断修改正在编写的解答，用你的编辑器功能加载这些改动，或者求值`(load "exercise-name")`来加载你的解答文件。

记得在加载更新后的解答之后，求值`(exercise-name-test:run-tests)`来重新运行测试。

## 从命令行测试

你可以用下面这条命令行调用启动测试（同样，把“exercise”替换成两个地方对应的名字）

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

这条命令相当笨重。
有位贡献者写了一些笔记，介绍[如何让调用更简单](https://glennj.github.io/exercism/cli)。
