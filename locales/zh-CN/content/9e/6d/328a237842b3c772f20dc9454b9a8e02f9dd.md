# 简介

正如[`Nothingness`][concept-nothingness]概念中所探讨的，R 有多种方式来表示缺失（`NULL`）、未知（`NA`）或数学上无效（`NaN`、`Inf`）的数据。
一般来说，R 会尝试用它们就地标记问题，然后继续运行，而不会抛出异常。

## `stop()`

有些问题太过根本，程序无法继续运行。
在这种情况下，用 `stop(msg)` 立即终止程序，抛出一个 `Error` 并打印 `msg`。

```R
f <- function() {
    stop("I have a problem")
}
f()
#> Error in f() : I have a problem
```

## `stopifnot()`

它类似于其他语言中的 `assert`，是 `stop()` 的一个便捷封装。
它的参数是任意数量的布尔条件，用逗号分隔，只有当它们全部为 `TRUE` 时，程序才会继续运行。

```R
stopifnot(1 < 2) # continues OK
stopifnot(1 < 2, 1 == 2)
#> Error: 1 == 2 is not TRUE
```

## `try()`

R 有多种处理错误的方式。
它们基于 Common Lisp，与许多流行语言的做法差别很大。

最简单的一种，就是把可能出问题的代码包在 `try()` 里。

```R
g <- function(val) {
  log10(val)
}

g(3)
#> [1] 0.4771213

g("3")
#> Error in log10(val) : non-numeric argument to mathematical function

# with try() and a default value
h <- function(val) {
  result <- NA
  try(result <- log10(val))
  result
}

h(3) # works as before
#> [1] 0.4771213

h("3") # returns a default value plus the error message
#> Error in log10(val) : non-numeric argument to mathematical function
#> [1] NA
```

## `warning()`和`message()`

它们用于响应非致命的情况，例如：

- 警告程序至少还能部分恢复的问题。
- 告知用户长时间运行的程序当前的进度。

```R
w <- function() {
  warning("something strange happened")
  -1
}

w()
#> [1] -1
#> Warning message:
#> In w() : something strange happened

# if warnings are not wanted
suppressWarnings(w())
#> [1] -1
```

在 Exercism 中，`suppressWarnings()` 函数偶尔会很有用，可以避免不需要的输出干扰测试运行器。
