## 布尔值

Raku 有`True`和`False`这两个布尔字面量。
在布尔上下文中，任何未定义的值都会被视为`False`。
除了`Bool::False`本身以外，被视为`False`的已定义值还包括`0`、`NaN`、`()`（空列表）、`""`（空字符串），以及类型为`Failure`的对象。

[前缀 `?`][&prefix:<?>]运算符会强制对对象施加布尔上下文。
它的行为与在该对象上调用[`Bool`][routine/Bool]方法相同。
[前缀 `!`][&prefix:<!>]运算符会得到前缀`?`的相反值。

## 布尔中缀运算符

### 智能匹配

[中缀 `~~`][&infix:<~~>]又称智能匹配运算符，是 Raku 中常用的工具。
它的行为取决于运算符右侧给出的对象，因为它是该对象[`ACCEPTS`][routine/ACCEPTS]方法的简写。
左侧的值会作为实参传给`ACCEPTS`。
结果是布尔值。

### 逻辑 AND/OR

Raku 有[`&&`][&infix:<&&>]/[`and`][&infix:<and>]、[`||`][&infix:<||>]/[`or`][&infix:<or>]、[`//`][&infix:<//>]/[`orelse`][&infix:<orelse>]和[`^^`][&infix:<^^>]/[`xor`][&infix:<xor>]这些用于布尔逻辑的运算符（分别是紧和松的优先级）。
这些运算符可以链式使用。

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### 三元运算符

Raku 有一个三元/条件[中缀 `?? !!`][infix-??-!!]运算符，写作`$condition ?? $true !! $false`。

## 控制流

### if/elsif/else

[`if`][control-if]语句用于有条件地运行一个代码块。
要创建`if`语句，先写`if`关键字，后面跟一个[表达式][statements-and-expressions]，再跟一个[代码块][control-block]。

表达式会在[布尔上下文][contexts-boolean]中求值，如果求值结果为`True`，就会执行该代码块。

`if`语句可以用[`elsif` 和 `else`][control-else/elsif]关键字来扩展，写法与`if`相同。
如果之前所有表达式的求值结果都是`False`，就会执行`else`代码块；`elsif`代码块也是如此，当它自己的表达式求值为`True`时就会执行。

另外，`if`也可以用在语句修饰符形式中：

```raku
say 'success' if True;
```

语句修饰符形式不能与`elsif`或`else`一起使用。

### given/when/default

[`given`][control-given]语句是 Raku 的话题化关键字，类似于 C 等语言中`switch`的话题化方式。
各个情况的关键字是[`when` 和 `default`][control-default-and-when]。

### for/while/loop

[`for`][control-for]语句会遍历给定的列表，并对列表中的每一项运行一次代码块。

[`while`][control-while]语句会在给定表达式求值为`True`时，反复运行一个代码块。

[`loop`][control-loop]语句有两种写法。
如果只给它一个代码块，它就会反复运行该代码块，直到有东西显式地跳出循环。
它也可以写成 C 风格的`for`循环，把初始化、条件和自增放在代码块前面的括号里。

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
