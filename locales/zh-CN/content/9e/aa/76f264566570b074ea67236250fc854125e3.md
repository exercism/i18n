# 帮助

如果遇到问题需要帮助，可以使用以下资源之一：

- [ClojureScript API](http://cljs.github.io/api/) 官方 API 文档。
- [Clojurescript Cheat-Sheet](https://clojure.org/api/cheatsheet)，一份官方速查表。
- [/r/clojurescript](https://www.reddit.com/r/clojurescript) 是 C# 的子版块。
- [StackOverflow](http://stackoverflow.com/questions/tagged/clojurescript) 可以用来搜索你遇到的问题，看看是否已经有人解答过。你也可以在上面提问和回答问题。
