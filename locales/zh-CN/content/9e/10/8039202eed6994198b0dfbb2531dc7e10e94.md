# 介绍

除了 `cond`，Elixir 还提供了宏 [`if/2`][getting-started-if]，当你只需要检查一个条件时，它就派得上用场。

[`if/2`][kernel-if] 接受一个条件和两个选项。如果条件为_真值_，就返回第一个选项；如果条件为_假值_，就返回第二个选项。

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

也可以把 `if` 表达式写在一行里。注意条件后面的那个逗号。

```elixir
if age > 16, do: "beer", else: "no beer"
```

这种语法适合非常短的表达式，但如果表达式放不下一行，就该避免使用。

## _真值_与_假值_

在 Elixir 中，所有数据类型出现在布尔上下文（比如`if`表达式）里时，都会求值为真值或假值。除了 `false` 和 `nil`，所有数据都被视为真值。特别地，空字符串、整数`0`和空数组在 Elixir 中都算真值。
