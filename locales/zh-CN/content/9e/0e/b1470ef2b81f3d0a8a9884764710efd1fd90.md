# 关于

[范围][range]表示一个或多个连续整数的序列。它们：

- 使用[`..`运算符][range-operator]创建，可以是升序，也可以是降序。
- 默认步长是`1`，但可以用[`..//`运算符][range-operator-with-step]修改（从 Elixir 1.12 起）。
- 包含第一个和最后一个值。
- 实现了[_Enumerable 协议_][enumerable]。
- 在内部表示为结构体，但可以用`..`进行模式匹配。
- 可用于以二进制、八进制、十六进制和码点表示法书写的整数。
- 可以通过[`Enum.to_list/1`][enum-to-list]或[`Enum.map/2`][enum-map]等函数转换为列表。

```elixir
Enum.to_list(9..1)
# => [9, 8, 7, 6, 5, 4, 3, 2, 1]

Enum.map(?A..?F, &<<&1>>)
["A", "B", "C", "D", "E", "F"]
```
