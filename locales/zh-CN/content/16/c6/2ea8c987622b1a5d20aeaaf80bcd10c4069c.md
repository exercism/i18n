# 简介

Clojure 中有几种基本的[流程控制](https://clojure.org/guides/learn/flow)结构。`if`是最重要的条件表达式：它由一个条件、一个“then”分支和一个可选的“else”分支组成。`if`只会求值条件选中的那个分支。

```clojure
(if (even? 2) "even" "odd")
```

`cond`是一系列测试和表达式。每个测试按顺序求值，第一个为真的测试所对应的表达式会被求值并返回。

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
