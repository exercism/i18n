## 1. 用密码保护找回的机密计划

拿到机密计划后，你需要把它保护起来，这样只有知道密码的人才能取回。

为此，你需要实现函数`protectSecret(_ secret: String, withPassword password: String) -> (String) -> String`。
这个函数会返回另一个函数，后者接收可能的密码字符串作为输入。
如果输入的密码正确，新函数就会返回隐藏的机密；如果密码不正确，函数就会返回 “Sorry. No hidden secrets here.”

```swift
let secretFunction = protectSecret("Steal the world's supply of french fries!", withPassword: "5up3r53cr37")

secretFunction("Open sesame")
// Returns "Sorry. No hidden secrets here."

secretFunction("5up3r53cr37")
// Returns "Steal the world's supply of french fries!"
```

## 2. 生成打开他们保险箱的密码组合

我们了解到，UMBRA 的保险箱密码组合全都基于它们所在房间的编号。
保险箱密码组合的生成方式，是对房间编号反复施加一个特殊的函数。
所以，组合的第一个数字来自把函数作用于房间编号，第二个数字来自把函数作用于第一个数字，第三个数字则来自把函数作用于第二个数字。

不过，UMBRA 会定期更换用来生成组合的函数，所以你的工具需要同时接收房间编号和相应的函数，才能生成组合。

实现函数`generateCombination(forRoom room: Int, usingFunction f: (Int) -> Int) -> (Int, Int, Int)`，用它生成你需要的组合。

```swift
func makeCombo(_ x: Int) -> Int {
  (x * 13) % 256
}

generateCombination(forRoom: 227, usingFunction: makeCombo)
// Returns (135, 219, 31)
```
