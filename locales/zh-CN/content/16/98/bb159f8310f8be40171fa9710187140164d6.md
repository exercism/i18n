# 说明

你的朋友 Johannes 热爱 DIY 硬件，也就是自己动手做的硬件。
他们刚做了一台榨汁机，Johannes 为此兴奋不已。
Johannes 的目标是每天早上都能做出新鲜的果汁。

Johannes 的榨汁机有很多花哨的功能。
比如内置的测量系统，可以告诉你杯子里有多少果汁。
它还有一个计时器，告诉你机器已经运行了多久。

Johannes 不太擅长编程，但想写一个程序来控制这台机器。
因此，他们请你来帮忙。

## 1. 调试灯

机器上有一个调试灯，原理很简单：只要机器通电，调试灯就会亮。
只有调试灯亮着，程序才会运行。

这个方法应该是`JuiceMaker`类的一个类方法。

定义类方法`JuiceMaker.debug_light_on?`，让它返回`true`。

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. 初始化机器

机器通电时，应该创建一个名为`JuiceMaker`的类的实例。
机器应该有一个初始化状态。
初始化状态应该保存以下信息：

1. 机器是否正在运行。开机时，这个值应该始终是`false`。
2. 杯子里果汁的量，这会是一个测量杯中果汁量的传感器。

定义初始化状态，它接收杯中果汁的量作为形参，并构造这个初始化状态。
初始化状态应该包含一个设置为`false`的实例变量`@running`，以及一个实例变量`@fluid`，它的值基于初始化该类时传入的实参。

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. 开启机器

机器可以开启和关闭。
你需要定义一个方法来开启机器。
机器开启时，运行状态应该设置为`true`。

定义方法`JuiceMaker#start`，用来开启机器。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. 机器的状态

机器需要能够告诉你它的状态。
如果机器正在运行，它应该返回`true`；如果没有运行，则返回`false`。

定义方法`JuiceMaker#running?`，返回机器的状态。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. 加入果汁

机器可以把果汁加入杯子。
机器能知道往杯子里加了多少果汁。
加入果汁后，机器需要一些帮助才能知道杯子里有多少果汁。

定义方法`JuiceMaker#add_fluid`，它接收加入的果汁量作为形参，并更新杯中果汁的量。

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. 关闭机器

机器可以开启和关闭。
你需要定义一个方法来关闭机器。
这个方法只会在机器运行时被调用。
机器关闭时，运行状态应该设置为`false`。
机器还需要一些帮助，才能确定关闭后杯子里有多少果汁。
机器每分钟消耗 5 个单位的果汁。

定义方法`JuiceMaker#stop`，它接收机器已运行的分钟数作为形参，并返回机器关闭后杯中果汁的量。

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
