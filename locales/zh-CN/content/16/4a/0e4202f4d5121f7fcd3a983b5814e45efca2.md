# 简介

许多程序需要用（_看起来_）随机的值来模拟现实世界中的事件。

常见、熟悉的例子包括：
- 抛硬币：从`('Heads', 'Tails')`中取一个随机值。
- 掷骰子：1 到 6 之间的随机整数。
- 洗牌：把牌的列表随机排序。
- 在三维图形模拟中生成树木和灌木。

用计算机生成_真正_随机的值是一项[出奇困难的技术挑战][truly-random]，所以这些结果有时会被称为“伪随机”。

在实践中，像 Python 标准库中的[`random`][random]模块这样设计良好的库，速度快、灵活，而且给出的结果对于建模、模拟和游戏中的大多数应用来说已经足够好了。

在这篇简短的介绍中，我们会展示这个模块中最常用的四个函数。
我们鼓励你去探索完整的[`random`][random]文档，因为里面有很多工具和选项。

在使用`random`模块中的工具之前，你必须先导入它：

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

为了避免每次都输入模块名，你可以按名称导入特定的函数：

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()`和`randint()`

如上面的第一个例子所示，`randrange()`函数有三种形式：

1. `randrange(stop)`给出一个整数`n`，满足`0 <= n < stop`
2. `randrange(start, stop)`给出一个整数`n`，满足`start <= n < stop`
3. `randrange(start, stop, step)`给出一个整数`n`，满足`start <= n < stop`，并且`n`位于序列`start, start + step, start + 2*step...`中

对于`step == 1`这种最常见的情况，`randint(a, b)`可能更方便、更易读。
`randint()`可能的结果_包括_上界，所以`randint(a, b)`等同于使用`randrange(a, b+1)`。



## `choice()`和`choices()`

这两个函数假定你的起点是某种[序列][sequence-types]或其他容器。
通常是一个`list`，或者在某些限制下，是一个`tuple`或`set`（_`tuple`不可变，`set`无序_）。

`choice()`函数会从给定的序列中随机返回一个成员，而`choices()`会从给定序列中随机返回指定数量（`k`）的成员。
在上面展示的例子中，我们假设硬币是均匀的，正面和反面的概率相等，但也可以指定权重。

例如，如果一个袋子里有 10 个红球和 15 个绿球，我们想随机取出一个：


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
