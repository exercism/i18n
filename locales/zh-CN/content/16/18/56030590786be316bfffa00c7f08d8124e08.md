# 说明附录

## 词

定义两个包装元组，它们继承`disposable`（来自`destructors`），并与`bytes`和`ops`两个整数计数器一同保存底层流：

- `metered-input < disposable`，槽位为`stream`、`bytes`、`ops`。
- `metered-output < disposable`，槽位为`stream`、`bytes`、`ops`。

用`new-disposable`（而非`new`）来构造它们，这样这个包装元组就会注册到析构器框架中。

- `<metered-input> ( stream -- m )`，包装一个输入流。
- `<metered-output> ( stream -- m )`，包装一个输出流。

将每个元组声明为相应流混入类的实例：

```
INSTANCE: metered-input  input-stream
INSTANCE: metered-output output-stream
```

然后提供`M:`方法，在更新计数器的同时把操作委托给底层流：

- 对于`metered-input`：[`stream-read1`][stream-read1]、[`stream-read-unsafe`][stream-read-unsafe]、[`stream-element-type`][stream-element-type]（委托），以及[`dispose*`][dispose*]。
- 对于`metered-output`：[`stream-write1`][stream-write1]、[`stream-write`][stream-write]、[`stream-flush`][stream-flush]（委托），以及[`dispose*`][dispose*]。

每次成功的读取或写入都应把传输的字节数加到`bytes>>`，并令`ops>>`自增 1。遭遇文件结尾的读取仍算一次操作，但传输的字节数为 0。`dispose*`应直接透传给底层流。
