# 说明

在这个练习中，你将组织各种遥控车之间的比赛。每辆车都有自己的速度和电池耗电特性。

车一开始的电池电量是满的（100%）。每次用遥控器驾驶车辆时，车会前进相当于其速度的距离（以米为单位），剩余电量百分比则减少它的电池耗电量。

如果一辆车的电池电量低于它的电池耗电百分比，就不能再驾驶这辆车了。

每条赛道都有自己的距离。测试车辆的方式，是检查它们能否在电量耗尽之前跑完赛道。

一共有六个任务，每个任务都会用到遥控车实例。

## 1. 创建一辆遥控车

为`RemoteControlCar`类定义一个构造函数，接收车辆的速度（以米为单位）和电池耗电百分比作为它的两个形参（类型都是`int`），这样就可以创建一辆遥控车：

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
```

## 2. 创建一条赛道

为`RaceTrack`类定义一个构造函数，接收赛道的距离（以米为单位）作为它唯一的形参（类型是`int`），这样就可以创建一条赛道：

```csharp
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. 驾驶车辆

实现`RemoteControlCar.Drive()`方法，让它根据车辆的速度更新已行驶的米数。同时实现`RemoteControlCar.DistanceDriven()`方法，返回车辆已行驶的米数：

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.DistanceDriven();
// => 5
```

## 4. 检查电池是否耗尽

更新`RemoteControlCar.Drive()`方法，让它根据车辆的电池耗电量消耗电量。同时实现`RemoteControlCar.BatteryDrained()`方法，用来表示电池是否已经耗尽：

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);
car.Drive();

car.BatteryDrained();
// => false
```

## 5. 创建 Nitro 遥控车

最畅销的遥控车是 Nitro，它的最高速度高达 50 米，电池耗电量为 4%。实现（static）`RemoteControlCar.Nitro()`方法，返回这种类型的车：

```csharp
var car = RemoteControlCar.Nitro();
car.Drive();
car.DistanceDriven();
// => 50
```
## 6. 检查遥控车能否跑完比赛

要想跑完一条赛道，车辆必须能够行驶赛道的距离。也就是说，它不能在冲过终点线之前耗尽电量。实现`RaceTrack.TryFinishTrack()`方法，它接收一个`RemoteControlCar`实例作为形参，如果这辆车能跑完赛道就返回`true`，否则返回`false`：

```csharp
int speed = 5;
int batteryDrain = 2;
var car = new RemoteControlCar(speed, batteryDrain);

int distance = 100;
var raceTrack = new RaceTrack(distance);

raceTrack.TryFinishTrack(car);
// => true
```
