# 提示

## 通用

- 所有清理相关的词都在[`destructors`][destructors]里。
- `:>`和`::`（局部变量）能让多泵的代码体保持可读，如果你要用到它们，就把`locals`加入`USING:`。

## 1. 排空舱底积水

- 一个词：`dispose`。

## 2. 抽排例程

- 一个词：`with-disposal`。在结尾的`;`后面加上`inline`，这样编译器就能看穿 quotation 参数：
  `: pump-out ( pump quot -- ) with-disposal ; inline`。

## 3. 整班次例程

- 用`with-destructors`打开作用域。在里面用`&dispose`注册每个泵，然后`call`调用 quotation。使用局部变量时：
  `[ pump-a &dispose pump-b &dispose quot call ] with-destructors`。

## 4. 有风险的抽排

- 与任务 3 的结构相同，但在单个泵上使用`|dispose`（仅失败时）。

## 5. 自定义 disposable：阀门

- `TUPLE: valve < disposable is-open ;`：`<`扩展了`disposable`，因此继承了框架的机制。
- `<valve>`使用`new-disposable`（而不是普通的`new`），这样新阀门就会注册到框架中。
- `M: valve dispose*`是你的清理钩子。在栈上不返回任何东西很重要：`>>is-open`会把元组留在栈顶，所以结尾要用`drop`。
