# 关于

Swift 提供了三种主要的循环结构：

- **`while` 循环**：只要指定的条件仍然为 `true`，就重复执行一段代码。条件在运行循环体之前先求值。
- **`repeat-while` 循环**：与 `while` 循环类似，但条件在运行循环体之后才求值。这样可以保证循环体至少执行一次。
- **`for-in` 循环**：对序列或集合（例如区间、数组或字符串）中的每个元素执行一次代码块。
