在处理 Rust 中的文本数据时，`String` 和 `&str` 是两种最基本的方式。

`String` 是有所有权的、可变的 `u8` 字节向量。
`&str` 是对 String 切片的借用引用，因此不可变。

你也可以使用 `String` 众多方法中的某一个来创建和修改 `String`，比如 `push`。
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

你也可以通过转换 `&str` 来创建 `String`：
```rust
let a_string = "hello".to_string();
```
