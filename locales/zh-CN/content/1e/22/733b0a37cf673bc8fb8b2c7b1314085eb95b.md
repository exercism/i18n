# 关于

## 位运算

位运算允许我们操作二进制数中的单个位。
这些运算在计算中非常基础，提供了一种高效执行底层任务的方法，例如控制内存中的特定位、优化数学计算、加密、通信以及编码/解码数据。

### 理解 Elm 中的 32 位整数

在 Elm 中，整数使用[补码](https://en.wikipedia.org/wiki/Two%27s_complement)表示法存储为 32 位有符号整数，这意味着它们使用 32 个二进制数字（_位_）来存储每个整数值。
这个位数限制影响了 Elm 可以直接表示的整数范围：

正数范围：0 到 2<sup>31</sup> - 1（即 0 到 2,147,483,647）
负数范围：-2<sup>31</sup> 到 -1（即 -2,147,483,648 到 -1）。

例如，整数`5`在二进制中表示为`00000000000000000000000000000101`，不过通常我们会忽略前导零，只说`101`。

### Bitwise

Elm 在其 [Bitwise 模块](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)中提供了几个位运算符。

## 基本操作

修改数字中的单个位称为_掩码操作_。
一个_掩码_是一个数字，其中特定的位以特定方式设置，以便使用`and`、`or`和`xor`等位运算符来操作另一个数字。

### and

`and`合并两个数字，只保留在两个数字中都为`1`的位。
这可用于检查单个位是否已设置。
例如，要检查数字的第 4 位是否设置为`1`，可以将它与掩码`01000`（十进制中的`8`）进行`and`运算，然后看结果是否非零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or`合并两个数字，只要在其中一个或两个数字中为`1`，就将每个位设为`1`。
这可用于将特定位设置为`1`。
例如，要将`10101`中的第 2 位设置为`1`，可以将它与掩码`00010`进行`or`运算：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### 异或（xor）

`xor`合并两个数字，只要在一个数字中为`1`而在另一个数字中为`0`，就将每个位设为`1`。
这可用于将某个位翻转为相反的值：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### 按位取反

`complement`会反转数字的每个位（`0`变成`1`，`1`变成`0`）。

注意，这会导致正数变成负数，负数变成正数。
这是因为二进制中的负数用最左侧位置为`1`来表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### 位移

以下运算符将位向左或向右移动指定的位数，实际上相当于乘以或除以 2 的幂。

`shiftLeftBy`将位向左移动，并从右侧用`0`填充。
例如，将`21`左移 3 位：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

这等同于`21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`：将位向右移动：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

向右移动 2 位相当于整数除以 4。

注意，这个函数会复制最左侧位的值。
因此，负数会保持为负数：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你想右移并用零填充，请使用`shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
