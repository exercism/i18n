# 简介

## 溢出

当算术运算或类型转换等计算产生的结果值超出接收类型的容量时，就会发生算术溢出。

类型为`int`和`long`的表达式及其无符号对应类型，在这种情况下会静默地回绕。

整数运算的行为可以通过使用`checked`关键字来修改。当`checked`块内发生溢出时，会抛出`OverflowException`的实例。

```csharp
int one = 1;
checked
{
    int expr = int.MaxValue + one;   // OverflowException is thrown
}

// or

int expr2 = checked(int.MaxValue + one);     // OverflowException is thrown
```

类型为`float`和`double`的表达式会取特殊值无穷大。

类型为`decimal`的表达式会抛出`OverflowException`的实例。
