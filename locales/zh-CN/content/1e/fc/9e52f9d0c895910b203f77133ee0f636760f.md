# 简介

R 没有单独的[集合][wiki-set]类型，而是用各种函数对向量执行类似的操作。

`%in%`运算符用于测试集合成员关系。
这个中缀运算符是函数`is.element()`的同义词。

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

相关的函数包括：

- [`unique()`][ref-unique]：去除重复元素。
- [`union()`][ref-sets]：合并集合（数学上记作 `A ∪ B`）。
- [`intersect()`][ref-sets]：找出两个集合共有的元素（`A ∩ B`）。
- [`setdiff()`][ref-sets]：从一个集合中减去另一个集合（`A - B`）。
- [`setequal`][ref-sets]：判断两个集合是否相等，忽略重复元素和顺序。

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

在每种情况下，函数都会返回一个副本，原参数保持不变。

## 哈希表

上面介绍的这些向量操作都是 base R 的一部分。
处理小规模问题时它们很有用，但集合一大就会变慢。

各种第三方包实现了[哈希表][wiki-hash]，以便在某些场景下提升性能。

例如，[`hashtable`][ref-hashtable]包提供了 `hashmap` 和 `hashset` 的实现，它们的扩展性更好。
和大多数外部包一样，这个包在 Exercism 上无法使用，但值得在处理实际问题时研究一下。
