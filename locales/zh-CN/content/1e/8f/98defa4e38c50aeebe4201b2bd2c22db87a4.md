# 说明

你受 Isaac's Asteroid Exploration Co. 认领部门的委托，改进他们的土地认领系统的性能。

每当一颗小行星可以开采时，投机者就会被邀请认领一块土地。
小行星上的土地被划分为互不重叠的矩形地块。
这些地块大小各不相同，但每条边都平行于坐标轴。
投机者通过指定坐标来认领其中一块土地。

你的目标是开发一套高性能的系统，来应对这场曾多次导致网站崩溃的抢地热潮。

度量单位是 100 米，但在这些任务中可以忽略。

## 1. 定义 Point

定义一个`struct`来保存`x`和`y`坐标。
它们都是相当小的非负整数，所以请使用`UInt16`类型。

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. 定义 Plot

因为所有地块都必须是矩形，边为水平或竖直，所以只需两个对角就能确定它们。

实现`Plot`结构体，让它的构造函数接收两个 Coord 结构体。

`Plot`应该是一个关键字结构体，包含`bottom_left`和`top_right`两个字段。

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. 检查你的认领是否已经被登记

这些认领存在竞争，所以在你的认领被接受之前，会先和登记簿里已有的认领进行比对。

实现`is_claim_staked()`函数，判断某块地是否已经被人认领过。

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. 投机者可以通过指定由角坐标确定的地块来认领土地

实现会修改状态的`stake_claim!()`函数，让认领可以被登记。

如果同一块地已经被认领，返回`false`。

如果这是一个新的认领，就把它加入登记簿并返回`true`。

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. 求出一块地较长一边的长度。

实现`get_longest_side()`函数，获取一块地较长的一边（水平或竖直）。

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. 找出较长一边最长的那个认领地块，供研究之用

实现`get_claim_with_longest_side()`函数，检查所有已登记的认领，并返回较长一边最长的那个（或那些）认领。

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

把结果 Plot（可能不止一个）作为`Set`返回：如果最长的地块只有一个，集合里就只有一个元素；如果出现并列，则有多个。
