# 说明

在这个练习中，你将编写一些代码，帮你照着最喜欢的烹饪书做出一份美味的千层面。

你有三个任务，它们都和烹饪千层面所花的时间有关。

## 1. 定义烤箱的预期时间（分钟）

定义`expectedMinutesInOven`常量，用来检查千层面应该在烤箱里烤多少分钟。根据烹饪书，预期的烤箱时间是 40 分钟：

```Haskell
expectedMinutesInOven
    --> 40
```

## 2. 计算准备时间（分钟）

定义`preparationTimeInMinutes`函数，它接受你加到千层面里的层数作为形参，并返回你准备这份千层面所花的分钟数。假设每铺一层需要 2 分钟。

```Haskell
preparationTimeInMinutes 3
    --> 6
```

## 3. 计算已用时间（分钟）

定义`elapsedTimeInMinutes`函数，它接受两个形参：第一个形参是你加到千层面里的层数，第二个形参是千层面已经在烤箱里烤了多少分钟。该函数应返回你在烹饪这份千层面上花掉的分钟数，也就是准备时间加上千层面此刻在烤箱里已用的时间。

```Haskell
elapsedTimeInMinutes 3 20
    --> 26
```
