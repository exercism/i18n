# 简介

Go 中的`string`是不可变的字节序列，其中的字节不一定表示字符。

字符串字面量定义在双引号之间：

```go
const name = "Jane"
```

可以使用`+`运算符拼接字符串：

```go
"Jane" + " " + "Austen"
// => "Jane Austen"
```

有些特殊字符需要用前导反斜杠转义，比如字符串中的`\t`表示制表符，`\n`表示换行符。

```go
"How is the weather today?\nIt's sunny"  
// =>
// How is the weather today?
// It's sunny
```

`strings`包中包含许多处理字符串的实用函数。
想了解更多关于字符串函数的信息，请查看 [strings 包文档](https://pkg.go.dev/strings)。
下面是一些例子：

```go
import "strings"

// strings.ToLower returns the string given as argument with all its characters lowercased
strings.ToLower("MaKEmeLoweRCase")
// => "makemelowercase"

// strings.Repeat returns a string with a substring given as argument repeated many times
strings.Repeat("Go", 3)
// => "GoGoGo"
```
