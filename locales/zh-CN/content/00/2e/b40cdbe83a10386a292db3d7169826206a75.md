# 简介

Common Lisp 中有一个打印器的概念，它包含所有用于写出 Lisp 数据文本表示的函数。其中一个函数是`format`，它让程序员可以按自己的需要格式化数据。

`format`的能力和 Lisp 打印器整体涉及的话题很广；这里将介绍使用`format`的基础知识。

## FORMAT 函数

函数`format`至少接收两个实参：要打印到的流，以及定义要打印什么、如何打印的控制字符串。

流本身是一个独立的概念，会在别处介绍。现在只需要知道，打印是输出到流上的，而这个实参有两个特殊值：`t`和`nil`。`t`表示打印到标准输出（实际上是变量`*standard-output*`所绑定的那个流），`nil`表示创建一个字符串并返回它。

注意，除了后一种把`nil`指定为流的情况之外，`format`的求值结果始终是`nil`。这是进行简单字符串插值或字符串构造的常见做法。

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## 格式指令

控制字符串里可以包含“格式指令”，它们告诉`format`要打印什么，以及如何理解传给`format`的其他实参。从某种意义上说，控制字符串就是一个程序，`format`会解释并运行它。所有指令都以`~`开头，后面跟一个字符（例如`~A`、`~D`、`~&`）。字符的大小写无关紧要。

大多数格式指令只是把传给`format`的一个实参插入到输出中。这被称为“消耗”该实参。有些指令不消耗实参，有些则消耗不止一个。甚至有一个指令可以让你在实参列表中前后跳转，或跳过某些实参。

## 基本格式化

一个用途非常广泛的格式指令是`~A`。它会打印出数据的“人类可读”版本。

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

另一个有用的格式指令是`~S`。它会打印出数据的“机器可读”版本。如果你想让自己生成的输出能够被当作 Lisp 数据读回来，这会非常有用。对很多东西来说，它的输出看起来和`~A`一样，但要注意，比如对字符串而言，输出中会包含引号（当它被放进另一个字符串时会被转义），这样这个值就能被当作字符串重新读回来。

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

另外两个非常有用的指令是`~%`和`~&`。前者输出一个换行符，后者则输出一个“新的一行”。区别在于：`~%`总是输出一个换行符，而`~&`只在当前不在行首时才会输出一个。这两个指令都不消耗实参。

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

最后，`~~`是一个简单的指令，它会输出一个字面量`~`。
