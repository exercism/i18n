# 简介

元组是一种轻量的方式，可以把固定数量的、类型各异的任意数据组合在一起。元组没有专门的名字；一旦给数据结构起了名字，它就变成了`struct`。元组的字段没有名字；需要通过解构或按位置来访问它们。

## 语法

### 创建

元组总是通过元组表达式来创建：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元组可以有任意数量的元素。

### 通过解构访问

可以通过解构来访问元组的元素。这只是说，给元组的各个元素分别赋予变量名，同时把原元组消耗掉。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### 按位置访问

也可以通过数字位置下标来访问元组的元素。和往常一样，下标从 0 开始。

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## 元组结构体

你还会被要求处理元组结构体。和普通结构体一样，它们是具名类型；但与普通结构体不同的是，它们的字段是匿名的。它们的语法和普通元组的语法非常相似。既可以解构，也可以按位置访问。

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### 字段可见性

匿名元组的所有字段始终是公开的。不过，元组结构体的每个字段都有各自的可见性，默认是私有的，这一点和标准结构体一样。你可以像在标准结构体里那样，用`pub`修饰符把字段设为公开。

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
