# 简介

`Tuple`在很多方面都和`Vector`（一维`array`）非常相似。
不过，它们之间有几个重要的区别。

- 元组写在圆括号`( )`里，而不是方括号`[ ]`里；不过当含义明确时，圆括号可以省略。
- 元组不要求元素类型一致：每个元素的类型都单独存储。
- 元组是不可变的。

不可变性让编译器可以进行更多优化，也让元组的性能优于向量，因此在不需要可变性的场合，应当优先使用元组。

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

还有一个`Tuple()`构造函数，它能把任何可迭代的集合变成元组。
很方便的一点是，它会把字符串当作由字符组成的可迭代集合。

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

对任何元组，都可以通过下标访问元素，也可以遍历它们。

任何纯数值元组也能用在`sum()`这样的数学函数里，和数组完全一样。

## 解包

使用多重赋值可以把元组解包成一个个单独的元素。
对于不需要的元素，用下划线`_`作为占位变量。

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Python 程序员对这种多重赋值语法会非常熟悉。

## 具名元组

`Tuple`只包含值。
`NamedTuple`则把每个值和一个名字配成一对。

之后就可以用“点”记法访问各个字段：

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

名字在内部以`Symbol`存储（一种不可变类型，名字前面带一个冒号`:`），所以还有一种替代语法可用：

```julia-repl
julia> nt[:b]
7.3
```

想单独取出名字（也叫“键”）或值都很容易：

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

注意，迭代具名元组时只会得到_值_，_名字_会被忽略。

元组（无论是否具名）是在函数之间传递结构化数据的非常常见的方式。
在这种场景下，不可变性很有好处：它能保证数据安全，也让编译器可以进行更激进的优化。
