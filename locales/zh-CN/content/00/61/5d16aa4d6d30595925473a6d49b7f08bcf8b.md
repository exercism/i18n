# 说明

马戏团的每一条安全带都有一个以千克为单位的额定承重，数字没核对清楚之前，谁也不能上去。

`SAFETY_HARNESS`类需要下面这些内容。桩代码已经给出了这个类和它的属性，其余的部分由你来补。下面的每个例程都带有一份契约，至于分别是哪种，提示里会说明。

## 1. 装好一条安全带

`create`接收这条安全带的额定承重，并返回一条安全带。额定值为零或更小的根本算不上安全带，所以那是一个`pre`。

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. 还剩多少余量？

`spare_capacity`接收安全带上的负载，返回它还能再承受多少。负载不能为负数，也不能超过额定值，两者都是`pre`。答案永远不为负数，这是一个`post`。

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. 它有多满？

`percent_used`接收负载，返回它占额定值的百分比，向下取整。负载不能为负数，答案也永远不为负数。

```sather
harness.percent_used(60)
-- => 50
```

## 4. 它安全吗？

`is_safe`接收负载，判断它是否在额定值以内。任何负载都可以拿来问，哪怕是荒唐的负载也行，所以对负载没有`pre`，但要写一个`post`，说明当且仅当负载在额定值以内时，答案才为真。

```sather
harness.is_safe(200)
-- => false
```
