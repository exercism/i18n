# 基础

一个 Sather 程序由**类**组成。类是一个有名字的盒子，里面装着例程。**例程**是一段有名字的工作，它会产生一个结果。

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

从上往下读：

- `class GREETER is` 打开这个盒子，并给它命名。类名用大写字母书写。
- `hello : STR is` 开始一个名叫 `hello` 的例程，它会产生一个 `STR`，也就是一段文本，叫做*字符串*。`: STR` 是一份承诺，说明会返回什么类型的结果。
- `return "Hello!";` 把结果交回来。文本写在双引号之间。
- `end;` 关闭这个例程，第二个 `end;` 关闭这个类。

一行里 `--` 之后的所有内容都是**注释**。Sather 会忽略它，它是写给人看的。

```sather
-- This line is for the reader, not the computer.
```

想从别处使用一个例程时，写上类名、两个冒号，然后是例程名：

```sather
GREETER::hello        -- this is "Hello!"
```

在同一个类里，可以省略类名：

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

不接受实参的例程，调用时不加括号，写 `hello`，而不是 `hello()`。
