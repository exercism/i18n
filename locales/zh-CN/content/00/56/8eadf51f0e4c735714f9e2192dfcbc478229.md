# 简介

有时你需要把一个序列看成一系列*片段*，而不是逐个元素地看。[`grouping`][grouping]、[`splitting`][splitting]和[`splitting.monotonic`][splitting.monotonic]这几个词汇表提供了四种做法。

## `group`：大小为 *n* 的不重叠分块

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

如果序列的长度不是 *n* 的倍数，最后一组会比 *n* 短。

## `clump`：大小为 *n* 的重叠滑动窗口

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

如果序列比 *n* 短，结果就是空的。

## `split-when`：在谓词成立的位置断开

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

每个元素都会单独调用一次谓词；返回真值的元素就是*断点*，不会保留在结果里。

## `monotonic-split`：相邻元素对检查失败时断开连续段

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

谓词作用于*相邻的两个元素*。只要它返回真值，当前连续段就继续延伸；一旦返回 `f`，就开启新的连续段。用 `[ = ]` 会得到由相等元素组成的连续段，用 `[ <= ]` 会得到非递减的连续段，诸如此类。

## 什么时候该用哪个

- **`group`/`clump`**：你已经知道想要的*大小*。
- **`split-when`**：你已经知道*断点元素*长什么样。
- **`monotonic-split`**：你知道什么条件会让相邻的两个元素*仍然属于同一段*。
