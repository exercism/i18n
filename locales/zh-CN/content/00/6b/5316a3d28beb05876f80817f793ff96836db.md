# 关于

Elixir 中的函数可以动态派发。

所有模块名都是原子。所有 Elixir 模块名在编译时都会自动加上`Elixir.`前缀。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir 可以在运行时解析出要调用的函数，并通过模块名进行查找。如果模块名绑定到变量，查找就可以动态完成。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
