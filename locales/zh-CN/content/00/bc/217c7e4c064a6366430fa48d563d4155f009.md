# 简介

在 JavaScript 中，按条件执行逻辑的一种常见方式就是 `if` 语句。它由`if`关键字、用圆括号括起来的条件和用大括号括起来的代码块组成。只有当条件的求值结果为`true`时，这段代码块才会执行。

```javascript
if (condition) {
  // code that is executed if "condition" is true
}
```

它既可以单独使用，也可以和`else`关键字结合使用。

```javascript
if (condition) {
  // code that is executed if "condition" is true
} else {
  // code that is executed otherwise
}
```

想在`else`语句里再嵌套一个条件，可以使用`else if`。

```javascript
if (condition1) {
  // code that is executed if "condition1" is true
} else if (condition2) {
  // code that is executed if "condition2" is true
  // but "condition1" was false
} else {
  // code that is executed otherwise
}
```
