Haxe 中的布尔值由 `Bool` 类型表示，它的值可以是`true`或`false`。

Haxe 支持 3 种[布尔运算符][operators]：`!`（一元 NOT）、`&&`（二元 AND）和`||`（二元 OR）

复合布尔表达式（`&&`和`||`）采用_短路_求值：表达式从左到右求值，但只求到必要的程度为止。在下面这类情况下，这一点很重要：

```haxe
object != null && object.field == x
```

第一个布尔判断确保只有在 `object` 不为 `null` 时才访问 `object.field`，从而避免运行时错误。

这 3 种布尔运算符的[优先级][precedence]不同，求值顺序为：`!` -> `&&` -> `||`。

用括号 `()` 把表达式括起来可以覆盖这些优先级规则，因为括号的优先级更高。

```haxe
!true && false   // => false
!(true && false) // => true
```

[operators]: https://haxe.org/manual/expression-operators-binops.html
[precedence]: https://haxe.org/manual/expression-operators-precedence.html
