# 简介

Haxe 中的迭代器用来通过`for`循环迭代一个值。迭代器有两种类型：

- `Iterator`，用来迭代一个值。
- `Iterable`数据，它让一个数据类型可以被迭代。

这两个概念分别由`Iterator<T>`和`Iterable<T>`来表示：

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

任何与这两种类型之一相统一的类，都可以用`for`循环来迭代。如果一个类定义了`hasNext`和`next`方法，它就被视为迭代器；如果它定义的是`iterator`方法，那它就是一个可迭代类型。
