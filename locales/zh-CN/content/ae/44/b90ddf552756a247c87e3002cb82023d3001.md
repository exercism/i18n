# 列表

`ARRAY`是固定长度的。它在创建时定下大小，之后一直保持这个大小：既不能往里追加元素，也不能从中删除元素。

侦探的笔记本可不是这样。线索一条一条地出现，一旦排除就划掉。这种情况你需要的是**列表**。

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes.append("broken window");
   notes.size                   -- 2
```

`LIST{T}`和数组一样，按顺序保存类型为`T`的值，并且会随你的需要变大或缩小。

## 就地修改

`append`会修改调用它的那个列表，自己什么也不返回：

```sather
   notes.append("muddy boots");        -- yes
   notes := notes.append("muddy boots");   -- no: append answers nothing
```

这和`FMAP`、`FSET`不同，在那里每一次修改都必须再赋值回去。`LIST`是普通对象，和`SCOREBOARD`一样：把它交给一个例程，例程就能改掉你手上的那个列表。

## 读取和写入

用方括号，从 0 开始计数，和数组完全一样：

```sather
   notes[0]                     -- "muddy boots"
   notes[1] := "smashed window";
   notes.size                   -- how many
   notes.is_empty               -- true when there are none
```

## 移除元素

`remove_index`会把某个位置上的元素移除，它后面的一切都往前移一格：

```sather
   notes.remove_index(0);       -- the first clue is struck out
```

所以位置并不是固定不变的。前面的线索被移除后，后面线索的位置就会改变，因此在保存某个位置之前，这一点值得记住。

## 遍历列表

`elt!`也能用，和数组上一样：

```sather
   loop
      #OUT + notes.elt! + "\n";
   end;
```

## 大括号

`LIST{STR}`是字符串列表，`LIST{INT}`是数字列表。它是一个泛型类，和你在`lost-property`里写的那个完全一样。现在，你也能用同样的方式读懂标准库里的泛型类了。
