# 说明

在这个练习中，你将管理一个库存系统。

库存应该按物品名称来组织，并记录可用物品的数量。

你需要处理向库存中添加物品。每当某个物品在给定的向量中出现一次，库存中该物品的数量就应该增加`1`。你还需要处理从库存中删除物品：在要求删除时，把相应的数量减少`1`。

最后，你需要实现一个函数，把给定库存中的所有键值对以由`pair`组成的`vector`的形式返回。

~~~~exercism/note
本练习的测试并不关心函数是否修改了输入，但函数名表明它们应该是非修改性的。
如果你想使用介绍中提到的函数，又不想修改输入，`copy()`函数会很有帮助。
~~~~

## 1. 根据向量创建库存

实现`create_inventory(<input vector>)`函数，它根据输入的物品向量创建一个“库存”。该函数应返回一个`dict`，其中每个物品名称都与其对应的数量配对。

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. 将向量中的物品添加到现有字典

实现`add_items(<inventory dict>, <item vector>)`函数，它把物品向量添加到传入的库存中：

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. 减少库存中的物品数量

实现`decrement_items(<inventory dict>, <items vector>)`函数，它接收由物品组成的`vector`。物品每在`vector`中出现一次，你的函数就应该把该物品的数量减去`1`：

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

库存中物品的数量不应降到 0 以下。如果某个物品在输入`vector`中出现的次数超过了库存中可用的数量，该物品记录的数量应保持为 0。一旦数量降到 0，多余的减少请求应被忽略。

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. 从库存中彻底移除一个条目

实现`remove_item(<inventory dict>, <item>)`函数，它从库存中彻底移除某个物品及其数量：

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

如果在库存中找不到该物品，函数应原样返回原来的库存。

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. 返回库存的全部内容

实现`list_inventory(<inventory dict>)`函数，它接收一个库存，并返回由`(item, quantity)`对组成的向量。

向量中只应包含_可用_的物品（_数量大于 0_），并应按物品名称的字母顺序排序：

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
