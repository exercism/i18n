# 简介

C++ 中的条件语句与其他语言类似。任何条件运算的底层类型都是`bool`类型，它的值可以是`true`或`false`。条件语句经常被用作流程控制机制，用来检查各种条件。

可以使用`if`语句：当底层条件为`true`时，它就会执行里面的代码，像这样：

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

当情况不止一种时，可以用`else if`和`else`语句把多个`if`语句串联起来。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

从 C++17 起，if 语句还可以包含一段简短的初始化语句，用来为这个 if 语句初始化一个或多个变量。例如：

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：在初始化语句中创建的任何变量，在 if 语句结束后都无法访问。
