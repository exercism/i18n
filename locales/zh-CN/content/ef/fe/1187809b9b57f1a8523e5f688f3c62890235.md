# 介绍

Swift 提供了一种名为 [`Bool`][bools] 的内置类型，用来表示真值：`true`和`false`。

## 逻辑运算符

Swift 提供了三个[逻辑运算符][logical-operators]（`!`、`&&`和`||`），用来组合和求值布尔表达式。

### 逻辑与（`&&`）

[与运算符][and]（`&&`）只有在两个操作数都为`true`时才返回`true`。
只要有一个操作数是`false`，它就返回`false`。
在`&&`符号的两侧各放一个表达式或布尔值：

```swift
true && true  // true
true && false // false
```

### 逻辑或（`||`）

[或运算符][or]（`||`）只要**至少有一个**操作数为`true`就返回`true`。
只有当两个操作数都为`false`时，它才返回`false`。
在`||`符号的两侧各放一个表达式或布尔值：

```swift
true || true   // true
true || false  // true
false || false // false
```

### 逻辑非（`!`）

[非运算符][not]（`!`）会对布尔值取反。
如果值为`false`，它就返回`true`；如果值为`true`，它就返回`false`。
把`!`运算符放在值或表达式的正前方：

```swift
!true  // false
!false // true
```

## 使用括号（`()`）

你可以用[括号][explicit-parentheses]把表达式分组，从而控制求值顺序。
在 Swift 中，括号内的表达式会先求值：

```swift
true && false && false || true   // true
true && false && (false || true) // false
```

用括号分组还会决定非运算符如何作用于复杂表达式：

```swift
!true && false   // false (evaluates (!true) first, then false && false)
!(true && false) // true  (evaluates (true && false) first to false, then !false)
```

~~~~exercism/note
当你需要明确求值顺序，或让复杂条件更容易读懂时，就使用括号。如果默认的优先级已经很清晰，就不要添加多余的括号。
~~~~
