# 简介

C# 中的异常为处理运行时出现的错误情况提供了一种结构化、统一且类型安全的方式。想要防止应用程序崩溃，妥善处理异常和错误就很重要。

在 C# 中，所有异常的基类型都是`System.Exception`类。它包含一些重要的属性，比如`Message`，其中保存着便于人阅读的说明，解释了异常被抛出的原因。

要表明代码的某一处出现了错误，需要创建一个新的异常对象，然后用`throw`关键字把它抛出：

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

异常被抛出后，运行时会负责找到一段处理该异常的代码。如果没有找到合适的处理程序，运行时除了停止程序执行之外，还会显示未处理异常的消息。

要为异常创建处理程序，C# 使用 try-catch 语句，它由一个`try`代码块和一个或多个`catch`子句组成。`try`代码块中应该包含并守护可能抛出异常的代码。`catch`子句中则应该包含错误发生后处理程序行为的代码。需要注意的是，`try`代码块之后各异常的顺序很重要，因为当列出多个异常时，只会执行第一个匹配的`catch`子句。

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
