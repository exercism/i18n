## Pairs

`Pair`是一种数据结构，它正好包含两个元素，可通过`first`和`second`字段访问。

可以用`x => y`来构造：

```julia-repl
julia> p = 3 => true
3 => true

julia> p.first
3

julia> p.second
true
```

`Pair`的两个元素可以是不同的类型：

```julia-repl
julia> typeof(p)
Pair{Int64,Bool}
```

在 Julia 中，`Pair`有两种常见的用途：字典和替换。

### Replacements

许多替换方法会接收一个`Pair`作为实参，以明确正在替换的是哪个元素。
这样就可以使用类似下面的语法

```julia-repl
julia> replace!([1, 3, 4, 1], 4 => 0)
4-element Array{Int64,1}:
 1
 3
 0
 1
```

其中集合里的每个`4`都会被替换成`0`，而不是下面这种不够清晰的语法

```julia
replace!([1, 3, 4, 1], 4, 0) # this method doesn't exist
```
