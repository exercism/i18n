# 关于

`|>`运算符叫做管道运算符。可以用它把多个函数调用串联起来，让上一次函数调用返回的值传给下一次函数调用。

```gleam
"hello"
|> string.uppercase
|> string.append("?!")
// -> "HELLO?!"
```

上面的代码等价于下面这段：

```gleam
string.append(string.uppercase("hello"), "?!")
```

管道运算符会把值作为第一个实参传给函数调用，或者作为唯一实参传给一次新的调用，具体取决于哪种方式能得到正确的类型。

```gleam
100
|> function_that_takes_two_arguments(1)

// Is equivalent to
function_that_takes_two_arguments(100, 1)
```

```gleam
100
|> function_that_returns_a_function(1)

// Is equivalent to
function_that_returns_a_function(1)(100)
```

有时我们想把值传到其他位置，这时可以用`_`占位符来指明值应该插入的位置。

```gleam
100
|> some_function(1, _, 2)
```
