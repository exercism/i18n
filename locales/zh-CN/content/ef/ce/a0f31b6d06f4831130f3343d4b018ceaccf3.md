# 布尔值

Crystal 有一个叫`Bool`的类型。
它表示`true`和`false`这两个值。

## 逻辑运算符

Crystal 有三个逻辑运算符（`!`、`||`、`&&`），它们把布尔值组合起来，构成会产生不同值的表达式。

### 与（`&&`）

Crystal 中的[_与_运算符][and]用`&&`表示，如果两个值都是`true`，就返回`true`；否则返回`false`。
使用_与_运算符时，一个布尔值放在`&&`的右边，另一个放在左边。

```crystal
true && true
# => true

true && false
# => false
```

### 或（`||`）

Crystal 中的[_或_运算符][or]用`||`表示，只要给定的值中**至少有一个**是`true`，就返回`true`。
如果两个值都是`false`，则返回`false`。
使用_或_运算符时，一个布尔值应放在`||`的右边，另一个放在左边。

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### 非（`!`）

Crystal 中的_非_运算符用`!`表示：如果给定的布尔值是`false`，就返回`true`；如果给定的是`true`，则返回`false`。
使用_非_运算符时，一个布尔值应放在运算符（`!`）之后。

```crystal
!true
# => false

!false
# => true
```

## 使用括号（`()`）

处理布尔值时，可以用括号来决定先计算哪些布尔值。
括号的用法不同，结果也会不同。
在 Crystal 中，括号里的内容会先求值。

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

由于括号里的内容会先求值，在下面的例子中，_非_运算符会作用于括号内的表达式。

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
只有在括号会影响结果时才应该使用括号；否则应省略。
~~~~

## 真值与假值

在 Crystal 中，“假值”包括：`false`、`nil`和空指针；**其他所有值**都是“真值”。
这些值都可以和上面提到的逻辑运算符一起使用。

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## 布尔值方法的命名约定

在 Crystal 中，返回真值或假值的方法通常以问号（`?`）命名。
大多数情况下，这样的方法会返回布尔值，但并非必须如此。
这意味着，凡是需要真值或假值的地方都可以使用这种方法，比如作为`if`语句的条件：

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

名字末尾带问号、却不返回布尔值的方法，往往会返回`nil`。`nil`_类似于其他语言中的`None`或`null`_。
