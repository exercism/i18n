# 关于

在 Common Lisp 中，一切都是表达式。
表达式要么是单个东西（称为原子），要么是由多个东西组成的列表（用括号 `()` 括起来）。

## 引用

所有 S-表达式，和符号一样，都可以被引用：

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

引用会阻止对 S-表达式求值，转而把它当作数据来处理。
这里有一个很棒的 [Stack Overflow 回答][so-quoting]，更详细地讨论了引用。
