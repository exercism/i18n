# 介绍

## 比较

在 C++ 中，你可以使用比较运算符来比较值。

| 比较        | 运算符  |
| ------------------| --------- |
| 相等             | `==`      |
| 不相等         | `!=`      |
| 小于              | `<`       |
| 小于或等于     | `<=`      |
| 大于           | `>`       |
| 大于或等于  | `>=`      |

这些比较的结果始终是布尔值：

```cpp
int a{3};

bool eq1 = a != 4; // true

bool eq2 = a > 5;  // false
```

`==`和`!=`运算符分别用来检查一个值是否等于另一个值。
下面是一些常见的例子：

```cpp
bool eq3 = 2 == 3; // false, integer comparison

bool eq4 = 2.1 != 2.2; // true, float comparison

bool eq5 = "hello" == "hello"; // true, string comparison
```

其他运算符用来检查一个值是否大于（`>`）、大于或等于（`>=`）、小于（`<`）或小于或等于（`<=`）另一个值。
这类比较适用于数字和字符串。
比较字符串时，遵循的是字典顺序（也称为词典序）。

```cpp
bool eq6 = 2 > 3; // false, integer comparison

bool eq7 = 1.2 < 1.3; // true, float comparison

bool eq8 = "Hello" < "World"; // true, string comparison
```

## `if`语句

C++ 中的条件判断和其他语言类似。
任何条件运算的底层类型都是`bool`类型，它的值可以是`true`或`false`。
条件判断常被用作流程控制手段，用来检查各种条件。

可以使用`if`语句，当底层条件为`true`时执行它的代码，就像这样：

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

当情况不止一种时，可以用`else if`和`else`语句把多个`if`语句串联起来。

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

从 C++17 开始，`if`语句还可以包含一个简短的初始化语句，用来为该`if`语句初始化一个或多个变量。
例如：

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> 注意：在初始化语句中创建的变量，在`if`语句结束后就无法访问了。
