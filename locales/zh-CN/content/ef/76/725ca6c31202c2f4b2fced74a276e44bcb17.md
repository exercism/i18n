# 说明补充

## 本赛道专用说明

历史上，Elm 曾使用函数式响应式编程，直到后来专门改用 Elm Architecture。

请把这道练习当作是在用 Elm Architecture 编写一个网页应用来解答。
程序的输出应该是具有以下结构的 HTML

```html
<div>
  <dl>
    <dt>State</dt>
    <dd>Ongoing</dd>
    <dt>Word</dt>
    <dd>______</dd>
    <dt>Remaining failures</dt>
    <dd>5</dd>
  </dl>
</div>
```

其中`<dl>`是描述列表元素，`<dt>`是描述术语元素，`<dd>`是描述详情元素，它们都是标准的 HTML 元素。

如果发生错误，输出应该具有以下结构

```html
<div>
  <p>error message</p>
</div>
```
