# 调试

由于当前的测试运行器使用了 [PonyTest](https://stdlib.ponylang.io/pony_test--index/)，Main actor 位于 test.pony 中，不应作为解答的一部分去修改。

按照 Pony 应用的最佳实践，除非确有需要，我们不会开放对 `Env` 的访问。这意味着在几乎所有情况下，你都无法借助 `env.out.print()` 进行 printf 风格的调试。

不过，Pony 有一个 [debug](https://stdlib.ponylang.io/debug--index/) 模块，它让使用 `-d` 标志编译的程序无需访问 `Env` 就能特殊访问 STDOUT 和 STDERR。

如果你需要进行 printf 风格的调试，就应该使用这个功能。

调试示例：

```pony
use "debug"

actor Main
  new create(env: Env) =>
    MySolution.examplefn("First String", 42)

primitive MySolution
  fun examplefn(arg1: String, arg2: USize) =>
    Debug.out("arg1: " + arg1 + ", arg2: " + arg2.string() + " were provided to MySolution.examplefn()")
```
