# 简介

## 命名空间

代码组织的一种重要方法是使用命名空间。
两个函数可能会发生命名冲突，把它们放到不同的命名空间中即可解决。
命名空间可以嵌套，这有助于组织大型代码库。
访问命名空间要通过作用域解析运算符`::`。

下面的例子展示了两个不同的`foo`函数。
通过给它们加上各自命名空间的前缀，就能一起使用它们。

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
