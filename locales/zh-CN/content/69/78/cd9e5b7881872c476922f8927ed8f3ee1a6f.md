## 安装 Z3

### 下载 Python（如果尚未安装）

Python 的最新版本可以从[这里](https://python.org)下载。

* 安装时，请务必勾选将 Python 添加到 PATH 的复选框

### 下载 Visual Studio（如果尚未安装）

Visual Studio 的最新版本可以从[这里](https://visualstudio.microsoft.com/downloads/?utm_medium=microsoft&utm_source=docs.microsoft.com&utm_campaign=inline+link&utm_content=download+vs2019)下载。

* 安装时，请选择**Python Development**工作负载
* 勾选右侧所有可选的 Python 开发包复选框

安装完成后，打开 Visual Studio 并设置你的初始首选项。

### 安装 Git 命令

Git 的安装说明可以在[这里](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)找到。

* 你需要[把 Git 添加到系统变量中](https://stackoverflow.com/questions/4492979/git-is-not-recognized-as-an-internal-or-external-command)

### 克隆 Z3

前往 [Z3 Github 仓库](https://github.com/Z3Prover/z3)查看该项目。

在电脑上打开终端，导航到你想要克隆 Z3 仓库的位置（例如：C:\Z3）。

在该位置运行：

```bash
git clone https://github.com/z3Prover/z3.git
```

### 在 Windows 上使用 Visual Studio 命令提示符构建 Z3

从开始菜单打开**Developer Command Prompt for VS 2019**。

导航到你克隆 Z3 仓库的文件夹（例如：C:\Z3）。

对于 32 位构建，运行：

```bash
python scripts/mk_make.py
```

对于 64 位构建，运行：

```bash
python scripts/mk_make.py -x
```

然后运行：

```bash
cd build
pip install z3-solver
```



现在你应该可以打开 Visual Studio，并使用 Z3 的 Python 绑定来运行 Z3 了。


要测试，可以运行：
```python
from x3 import *
x = Real('x')
y = Real('y)
s = Solver()
s.add(x + y > 5, x > 1, y > 1)
print(s.check())
print(s.model())
```

最后两行应该会输出 `sat` 和 `[y = 4, x = 2]`。
