# 关于

[键值对与字典][pairs-dicts] 概念介绍了 Julia 字典类型的基础知识。

由于 [`Dict`][dict] 是重要且常用的集合类型，所以也有很多操作它们的函数。

## 获取条目

获取条目最简单的方法是通过键（就像许多语言里那样）。
不过，请求一个不存在的键会引发 `KeyError`。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)

# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

我们可以在尝试获取之前先检查这个键是否存在（比如用 `haskey(d, 4)` 或 `4 ∈ keys(d)`），但直接为缺失的键取一个默认值往往也很实用。

为此，有 [`get()`][get] 函数，以及它的可变版本 [`get!()`][get-bang]。
两者的区别在于是否会把“缺失”的键加入 `Dict`。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'

julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)

# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

在之前的那个概念里我们看到，`delete!()` 会按键删除一个条目。
这个操作可以和获取值结合起来，用的是 `pop!()` 函数。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'

# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)

# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 迭代

对 `Dict` 进行迭代时，默认会产出 `key => value` 键值对。
这两个组成部分可以用常见的 `.first` 和 `.second` 命名方式来访问。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

通常，我们只想使用键或只想使用值，这很容易做到。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1

julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## 合并

把两个 `Dict` 合并起来可能很有用，但我们必须弄清楚要如何处理同时出现在多个输入里的键。

[`merge()`][merge] 和 [`merge!()`][merge-bang] 函数会按从左到右的顺序合并任意数量传入的 `Dict`。

已存在的键，其值会被直接覆盖，所以最右边的 `Dict` 会“获胜”。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"

julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)

# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

[`mergewith()`][mergewith] 和 [`mergewith!()`][mergewith-bang] 函数允许我们把一个函数作为第一个参数传入，用来定义重复的键应该怎样合并。
加法就是一个简单的例子。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"

julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5

# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

在合并时，拼接两个向量是另一种常见的操作。
为此，Julia 使用 [`vcat()`][vcat] 函数，原因在 [`Multi Dimensional Arrays`][multidim] 概念中有说明。

```julia-repl
julia> d7 = Dict("vals" => [1, 2, 3])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3]

julia> d8 = Dict("vals" => [4, 5])
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [4, 5]

julia> mergewith(vcat, d7, d8)
Dict{String, Vector{Int64}} with 1 entry:
  "vals" => [1, 2, 3, 4, 5]
```

对于多个 [`Set`][sets]，对应的合并函数是 [`union`][union]。

注意，`mergewith` 系列函数是[高阶函数][hof]实际应用的一个很好例子。
