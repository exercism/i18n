# 简介

属性用于在结构体和类中存储数据。同样，你也可以定义_方法_，用它把函数存储在结构体或类中。

方法的定义方式与普通函数相同，只是要写在结构体或类的内部。注意，如果某个函数要改变结构体中属性的值，就必须在它前面加上`mutating`关键字。另外，如果某个属性会被方法改变，那么这个属性必须用`var`定义，而不能用`let`，就像普通变量一样。

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

调用这些方法时要用点语法，和访问属性一样。

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
