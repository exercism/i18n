# 说明补充

## 单词

- `<bst> ( data-seq -- tree )`，依次把 `data-seq` 的每个元素插入，构建出一棵树。
- `sorted-data ( tree -- seq )`，按升序返回树中的元素（中序遍历）。

## 元组的层次结构

二叉搜索树中的节点要么是*空*，要么*包含数据以及两棵子树*。可以用一个小型的继承层次来建模：

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` 是抽象父类，`leaf` 是空树的情形，`branch` 携带一个值以及两个 `bst` 子节点（它们各自要么是 `leaf`，要么是 `branch`）。

## 排序

用 `before=?`（来自 `math.order`）来比较数据，它既能处理数字，也能处理字符串，测试用的就是 `"1"`、`"2"`、`"3"` 这样的字符串数据。
