# 说明

在本练习中，你将编写一些代码，帮助 Lisp 外星人 Larry 解析和格式化日志字符串。这些日志字符串来自各种系统，需要经过处理，才能把其中的消息显示在一个信息丰富的监控界面上。

日志字符串的形式为`"[<level>]: <message>"`。级别会是以下值之一：`info`、`warn` 或 `ohno`。

## 1. 提取消息

定义一个函数`log-message`，它接受一个日志字符串，并求值得到其中包含的消息。

```lisp
(log-message "[ohno]: whoops!") ; => "whoops!"
```

## 2. 判断严重程度

日志字符串的级别决定了它的严重程度。

- 级别为`info`时，严重程度为`:everything-ok`
- 级别为`warn`时，严重程度为`:getting-worried`
- 级别为`ohno`时，严重程度为`:run-for-cover`

定义一个函数`log-severity`，它接受一个日志字符串，并求值得到对应的严重程度。

```lisp
(log-severity "[warn]: might want to get that checked") ; => :getting-worried
```

## 3. 应对现实中难以预料的情况

遗憾的是，有时日志字符串的格式并不总是正确。具体来说，日志级别可能并非如上文所述那样全部为小写。请修改`log-severity`来处理这种情况。

```lisp
(log-severity "[WaRn]: string case system failing") ; => :getting-worried
```

## 4. 根据日志的严重程度重新格式化日志消息

根据严重程度的不同，消息需要以不同的方式修改：

- 严重程度为`:everything-ok`时，消息应改为全部小写。
- 严重程度为`:getting-worried`时，消息应改为每个单词首字母大写。
- 严重程度为`:run-for-cover`时，消息应改为全部大写。

定义一个函数`log-format`，它接受一条日志消息，并求值得到格式正确的消息。

```lisp
(log-format "[ohno]: whoops!") ; => WHOOPS!
```
