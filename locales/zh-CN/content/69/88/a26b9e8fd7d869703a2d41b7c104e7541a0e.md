# 关于 `for` 循环

[`for` 循环](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html)提供了一种机制，用来重复执行一组语句，直到满足某个条件为止。
循环由四个部分组成：

```java
for (initialization; test; update) {
    body;
}
```

`initialization` 用于设置循环的初始状态，它只在循环开始时执行一次。
通常它会声明并赋值一个变量，供 `test` 表达式和 `update` 语句使用。
例如：

```java
int i = 1
```

`test` 表达式用来判断循环是否应该结束。
如果它的结果为 true，就会先执行循环体，再执行 `update` 表达式。
如果结果为 false，那么循环体和 `update` 语句都不会执行，程序会从循环的右花括号之后继续执行。
它通常会检查在 `initialization` 中赋值的那个变量。
例如：

```java
i <= 10
```

执行完循环体之后，会执行 `update` 表达式。
它通常会把循环变量自增或自减某个值。
例如：

```java
i++
```

下面的 `for` 循环会打印出前四个平方数：

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

如果要遍历集合中的每个元素，最好使用 `for-each` 循环，但用 `for` 循环也能做到，就像这样：

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

相比 `for-each` 循环，`for` 循环确实有一些优势：

- 可以从想要的下标开始或结束。
- 可以使用任意（布尔）终止条件。
- 可以通过自定义循环变量的增量来跳过某些元素。
- 可以通过倒着计数，从后往前处理集合。
- 可以在不涉及集合的场景中使用 `for` 循环。
