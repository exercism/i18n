# 说明

在本练习中，你将处理日志报告中的一行行日志。
每行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志共有三个不同的级别：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会拿到一行日志，要求你对它做点什么。

## 1. 从日志行中获取消息

实现 `log_line::message` 方法，返回某行日志中的消息：

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. 从日志行中获取日志级别

实现 `log_line::log_level` 方法，返回某行日志的日志级别，返回值应为大写：

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. 重新格式化日志行

实现 `log_line::reformat` 方法，重新格式化日志行：把消息放在前面，日志级别用括号放在其后：

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
