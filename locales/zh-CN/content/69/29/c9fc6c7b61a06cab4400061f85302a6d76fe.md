# 说明

在这个练习中，你将处理日志行。

每行日志都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

一共有三种日志级别：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会接收一行日志，并要求你对它进行某种处理。

## 1. 从日志行中获取消息

实现 `message`函数，返回日志行中的消息：

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

应去掉开头和结尾的空白字符：

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现 `log_level`函数，返回日志行的日志级别，返回值应为小写：

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. 重新格式化日志行

实现 `reformat`函数，重新格式化日志行：把消息放在前面，日志级别放在后面并用括号括起来：

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
