# 说明补充

## Rust 的下标从 0 开始

按约定，Rust 中值的有序序列，其内容都是从 0 开始编号（也就是“下标”）的。无论本 README 中练习描述的其余部分怎么说，这一点都成立，比如描述里提到从 1 开始的下标时也是如此。所以，要把那些下标编号换算成 Rust 的下标编号，你得减去 1。

## 效率提示

本练习使用_向量组成的向量_来存储矩阵的内容。本练习旨在帮助学生理解向量的一些基本概念（例如下标），以及嵌套数据类型是合法的，不过对于高性能的矩阵代数，以及任何类似的对大量数据进行高效处理的场景来说，_向量组成的向量_都不是最佳选择。

关于这种低效之处的详细解释，超出了本练习乃至整个学习路径的范围。这个方面叫做[缓存局部性](https://stackoverflow.com/questions/12065774/why-does-cache-locality-matter-for-array-performance)，如果你想进一步了解现代计算机体系结构的细节，点击那个链接就能找到一篇不错的入门介绍。
