# 控制流

`if` 表达式和循环控制 Cairo 中代码的执行流程，方式如下：
`

- **`if` 表达式**根据条件是否求值为 `true` 来决定是否运行代码。
- **循环**（例如 `loop`、`while` 和 `for`）会在指定条件保持为真时反复执行代码，直到满足某个中断条件。

这些结构是 Cairo 实现逻辑和迭代的基础。

## `if` 表达式

Cairo 中的 `if` 表达式让你可以根据条件逻辑控制执行流程。
它们的结构是：代码根据布尔条件求值为 `true` 还是 `false` 来决定是否执行。

```rust
fn main() {
    let temperature = 30;

    if temperature > 25 {
        println!("It's hot outside!");
    }
}
```

这个例子演示了 Cairo 中一个简单的 `if` 代码块。
只有当条件 `temperature > 25` 求值为 `true` 时，才会打印消息 `"It's hot outside!"`。
如果条件为 `false`，则不执行任何代码，程序继续运行。

```rust
fn main() {
    let number: u32 = 5;

    if number < 10 {
        println!("The number is less than 10.");
    } else {
        println!("The number is 10 or greater.");
    }
}
```

运行这段代码会在控制台打印 `"The number is less than 10."`。

### 用 `else if` 处理多个条件

你可以用 `else if` 表达式把 `if` 和 `else` 组合起来，处理多个条件。

```rust
fn main() {
    let score: u64 = 85;

    if score >= 90 {
        println!("Grade: A");
    } else if score >= 80 {
        println!("Grade: B");
    } else if score >= 70 {
        println!("Grade: C");
    } else {
        println!("Grade: F");
    }
}
```

运行这段代码会在控制台打印 `"Grade: B"`。

### 在 `let` 语句中使用 `if`

Cairo 中的 `if` 表达式可以用在 `let` 语句的右侧，把结果赋值给一个变量。

```rust
fn main() {
    let condition: bool = true;
    let number: felt252 = if condition {
        5
    } else {
        6
    };

    if number == 5 {
        println!("condition was true and number is {}", number);
    }
}
```

## 循环

循环是一种基础结构，它让代码块可以重复执行，从而高效、可控地完成任务。
循环可以遍历一个序列，也可以根据条件反复执行代码。
Cairo 提供了三种主要的循环形式：

- **loop**：一种基本循环，会一直运行，除非用 `break` 语句显式停止。
- **while**：只要指定条件保持为 `true` 就继续执行。
  当条件变为 `false` 时停止。
- **for**：遍历集合（例如数组）中的元素，对每个元素执行代码。

### 用 `loop` 重复执行代码

`loop` 关键字告诉 Cairo 一遍又一遍地执行某个代码块，直到你显式让它停止。

```rust
fn main() {
    loop {
        println!("again!");
    }
}
```

执行这段代码会在控制台无限打印 `"again!"`，直到程序耗尽 gas，或者我们手动停止它。

> 注意：Cairo 通过引入 gas 计量器，防止我们运行带有无限循环的程序。
> gas 计量器是一种限制程序可执行计算量的机制。
> gas 是衡量一条指令计算成本的单位。
> 当 gas 计量器耗尽时，程序就会停止。

要跳出循环，把 `break` 关键字放在循环内，告诉程序何时停止执行它。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

`continue` 关键字告诉程序进入循环的下一次迭代，并跳过本次迭代中剩余的代码。

```rust
fn main() {
    let mut i: usize = 0;
    loop {
        if i > 10 {
            break;
        }
        if i == 5 {
            i += 1;
            continue;
        }
        println!("i = {}", i);
        i += 1;
    }
}
```

执行这个程序时，当 `i` 等于 `5` 时不会打印 `i` 的值。

#### 从 `loop` 返回值

你可以用 `break` 关键字后跟想要返回的值，从 `loop` 中返回一个值。
这样就能退出 `loop`，把结果传给代码的其他部分。

```rust
fn main() {
    let mut counter = 0;

    let result = loop {
        if counter == 10 {
            break counter * 2;
        }
        counter += 1;
    };

    println!("The result is {}", result); // prints "The result is 20"
}
```

### 用 `while` 实现条件循环

`while` 在条件为 `true` 时运行代码，并在条件变为 `false` 时退出。

```rust
fn main() {
    let mut number = 3;
    while number != 0 {
        println!("{}!", number);
        number -= 1;
    }
    println!("LIFTOFF!!!");
}
```

### 用 `for` 遍历集合

`for` 遍历集合中的每一项，对每一项执行代码。

```rust
fn main() {
    let a = [10, 20, 30, 40, 50].span();
    for element in a {
        println!("the value is: {}", element);
    }
}
```
