# 安装

你需要 Node Package Manager（npm）来安装 Reason。请按照[这里](https://www.npmjs.com/get-npm)的说明操作。

装好 npm 之后，就可以安装 Reason 了：

```
npm install -g bs-platform
```

Reason 已经集成到多款编辑器中，参见[这里](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)。

一些命令行工具（包括一个可以在 shell 中求值 Reason 表达式的 REPL）可以在[这里](https://github.com/reasonml/reason-cli)找到。
