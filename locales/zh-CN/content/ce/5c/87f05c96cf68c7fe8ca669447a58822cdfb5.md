# 简介

Factor 的错误系统由三部分组成：`throw`（在[`kernel`][kernel]中）负责抛出错误，`recover`（在[`continuations`][continuations]中）负责捕获错误，而`ERROR:`则用来定义元组类型的错误类。

```factor
! "file not found" throw          (raises a string as the error)

[ "boom" throw ] [ drop "caught" ] recover .
! => "caught"
```

`recover ( try recovery -- )` 会运行 *try* quotation；如果它抛出错误，错误就会被压入栈，然后运行 *recovery* quotation。

`ERROR:` 既声明了类本身*和*一个构造函数，这个构造函数会抛出全新的实例：

```factor
! DOCTEST: SKIP
ERROR: not-found path ;

"/missing" not-found
! throws T{ not-found { path "/missing" } }
```

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
[continuations]: https://docs.factorcode.org/content/vocab-continuations.html
