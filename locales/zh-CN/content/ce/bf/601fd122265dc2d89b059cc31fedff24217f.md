# 简介

Haxe 中的`String`是一个对象，表示以 Unicode 字符序列（字母、数字、标点等）形式呈现的不可变文本。使用双引号可以定义一个`String`实例：

```haxe
var fruit:String = "Apple";
```

字符串通过调用其方法来操作。字符串一旦创建，其值就永远无法更改。任何看似修改字符串的方法，实际上都会返回一个新的字符串。

多个字符串可以拼接（相加）在一起。最简单的方法就是使用`+`运算符。

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

对于比简单拼接更复杂的字符串格式化，推荐使用字符串插值。要在字符串中使用插值，请用单引号（`'`）将其括起来。然后就可以使用美元符号（`$`）来触发插值：

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
