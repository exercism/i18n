# Exercism API

## 说明

大多数 Exercism 语言轨道都使用`exercism`命令行工具来获取和提交练习，该工具通过 REST API 与`exercism.io`交互。而 Pharo Smalltalk 语言轨道则直接使用同一个 REST API，无需任何中间工具，就能把练习导入和导出 Pharo 镜像。本文档详细介绍 Exercism API，并重点说明 Pharo Smalltalk 语言轨道如何使用它。它的目标读者是 Pharo Smalltalk 工具链的维护者。

## 请求头

所有端点都要求在请求中把请求头设置为以下值：

```
Authorization: Bearer <token>
```

`<token>`的值是用户的 CLI 身份验证令牌，可在`https://exercism.io/my/settings`获取。

## 获取练习

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

在上面的 URL 中，`<slug>`是练习的名称，例如`hello-world`，`<language>`是语言轨道，例如`pharo-smalltalk`。

### 响应

#### 200

请求成功时，响应中会包含一份 JSON 数据。JSON 中有练习的相关信息，以及一个可用来下载练习文件的 URL。

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

语言轨道名称有歧义，或者提交的练习文件没有变化。

#### 403

该提交的解答未对用户解锁，或者用户尚未加入该语言轨道。

#### 404

找不到该语言轨道或练习。

## 提交练习

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### 响应

#### 201

提交成功。

#### 400

提交的文件过大（超过 1 MB），或者该提交的解答是重复的。

#### 403

该提交的解答对当前用户不可访问。解答的用户 ID 与当前用户 ID 不匹配。

#### 404

未找到该提交的解答的 ID。
