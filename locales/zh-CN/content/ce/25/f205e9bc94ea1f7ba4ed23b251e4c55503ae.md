# 说明

编写一个函数，把普通数字转换成罗马数字。

罗马人是一群聪明人。他们征服了欧洲的大部分地区，统治了数百年。他们发明了混凝土、笔直的道路，甚至还有比基尼。不过，有一样东西他们始终没有发现，那就是数字零。这让书写和标注他们丰功伟绩的漫长历史变得稍微麻烦了一点，但他们想出的这套数字体系至今仍在使用。比如，BBC 就用罗马数字来标注节目的日期。

罗马人用字母来写数字，也就是 I、V、X、L、C、D、M。（注意这些字母有很多直线，因此很容易凿刻到石板上。）

```text
 1  => I
10  => X
 7  => VII
```

不需要能够转换大于约 3000 的数字。（罗马人自己一般也不会用到更大的数。）

维基百科上写道：现代罗马数字……是把每个数位单独表示出来，从最左边的一位开始，并跳过任何值为零的数位。

想看看实际效果，就来看看 1990 这个例子。

用罗马数字写出来，1990 是 MCMXC：

1000=M
900=CM
90=XC

2008 写成 MMVIII：

2000=MM
8=VIII
