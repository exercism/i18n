# 提示

## 1. 调制一杯果汁

- `cond`（在[`combinators`][combinators]中）是根据一连串相等性测试来选取值的最简洁方式。

## 2. 补充青柠角供应

- 最自然的选择是一个带两部分状态的`while`循环，即还需要的青柠角和手头现有的青柠。用`::`和`:> name!`声明这两部分状态，可以让循环体更易读。
- `unclip ( seq -- rest first )`会剥下第一个青柠，随时可以喂给`wedges-from-lime`。

## 3. 列出队列中每笔订单的调制时间

- [`sequences`][sequences]里的一个词就能完成全部工作。

## 4. 完成本轮班次

- 结构和任务 2 一样：一个由两部分状态驱动的`while`循环，即班次剩余的分钟数和仍在等待的订单。只要其中一个耗尽就停下来。

[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
