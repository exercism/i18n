# Rust 学习路径的练习顺序

练习顺序和主题的真正权威来源是 [config.json](config.json)，不过本文件记录了我们在该文件中这样安排练习顺序背后的理由。

## 我们的做法

我们是为正在学习 Rust 的学生安排练习顺序的。考虑到这样的读者，我们在添加新练习时遵循 2 条规则。

- 一道练习只应引入一个新概念
- 练习应该从 Rust 基础循序渐进到进阶的 Rust 概念

### 一个新概念

如果一道练习的解答需要同时用到`Result`和`HashMap`，那么这两个概念中至少有一个应该由更早的练习引入。

如果这条学习路径中有多道练习都依赖同一个概念，就把它们放在一起，以加强学习效果。

### 循序渐进地学习 Rust

#### 前段练习

前段的练习应该聚焦 Rust 的语法，以及许多编程语言中都有的概念：条件判断、循环、高阶函数。

#### 中段练习

学习路径中段的练习应该引入一些不太常见的概念，比如`Result`、`Option`和 Trait；或者`while let`这样的语法。

通过学习路径的中段，学生应该熟悉各种不同的 Rust 概念。

#### 后段练习

学习路径后段的练习应该做到以下 2 件事之一：

1. 引入高级概念：生命周期、并发、不安全代码
2. 要求写出一份复杂的解答，把学生到目前为止学到的知识综合起来
