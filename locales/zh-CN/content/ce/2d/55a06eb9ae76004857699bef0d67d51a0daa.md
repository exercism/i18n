# 使用守卫

[comment]: # (当解答完全没有使用守卫时，就会报这个错误)

使用[守卫](https://hexdocs.pm/elixir/master/guards.html)来防止`two_fer/1`对非二进制输入执行代码。

> 请记住，在 elixir 中，[字符串](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)被视为[二进制数据](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html)。

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> 这个守卫可以在`iex`中测试

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
