# 关于高阶函数

函数在 Kotlin 中是头等公民。
这意味着它们可以存入变量、作为实参传递，甚至由其他函数返回。
例如，把一个函数赋值给变量`addOne`：

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

函数也可以返回另一个函数：

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}
```

赋值之后，就可以通过这个变量调用该函数，就像调用其他函数一样：
```kotlin
addOne(3)
// => 4
```

## 声明函数类型

变量或形参的类型可以用`(parameter types) -> return type`这种语法来声明。
例如，声明一个变量：

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

以及为形参声明类型：

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## lambda 表达式

lambda 表达式是定义函数的一种更简短的方式。
它们的写法是`{ parameters -> body }`。
表达式会返回主体中最后一条语句的值。
例如：

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

只要有足够的信息，Kotlin 就能推断出类型。
例如，上面的例子也可以写成：

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it`：用于单形参 lambda

当表达式只有一个形参时，可以省略这个形参。
这时 Kotlin 会在主体中提供一个名为`it`的形参。
例如：

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## 传递尾随 lambda

当函数的最后一个实参是 lambda 时，lambda 表达式要直接写在括号_之后_。
例如：

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
