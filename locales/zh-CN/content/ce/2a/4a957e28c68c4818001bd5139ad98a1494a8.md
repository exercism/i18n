# 布尔

`bool`类型（boolean 的缩写）只有两个值：`true`和`false`。
在代码中，字面量`true`和`false`不区分大小写。

```php
<?php

$value_is_true = true;
$value_is_false = false;
```

布尔值常用在逻辑表达式中，作为运算符的结果，随后用在控制结构里。

## 逻辑运算符

有以下几个逻辑运算符：

- `!$a`：如果`$a`不是`true`，就返回`true`
- `$a && $b`：如果`$a`和`$b`都是`true`，就返回`true`
- `$a || $b`：如果`$a`或`$b`中有一个是`true`，就返回`true`

~~~~exercism/caution
还有`and`和`or`运算符，它们分别与`&&`和`||`互补。
它们的行为与`&&`和`||`不同，可能会产生意想不到的结果，因此不建议使用。
~~~~
