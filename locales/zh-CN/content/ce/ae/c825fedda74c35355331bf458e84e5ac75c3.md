# 引言

对于短小的单词来说，堆栈操作就够了。当一个单词有多个输入，而且你需要按名字引用它们时，Factor 提供了 *locals*：也就是用 `::`（用于单词定义）或 `[| | ]`（用于内联 lambda）引入的命名绑定，两者都来自 [`locals`][locals]。

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

在引用内部，`[| inputs | body ]` 是一个带命名输入的 lambda：

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
