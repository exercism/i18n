# 简介

有时，一份状态需要在多个单词之间共享，而不必每次都让它在各自的栈效应中层层传递。Factor 的*动态变量*（用`SYMBOL:`声明）让每个单词都能访问存放在命名空间里的值。

## `SYMBOL:`和`SYMBOLS:`

`SYMBOL: name`声明一个变量。`SYMBOLS: a b c ;`可以一次声明多个：

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## 设置与获取

`set-global`和`get-global`（位于[`namespaces`][namespaces]）操作的是全局命名空间：

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

对于模块级状态，你要的正是带 `-global` 后缀的那一套写法。

## 用`with-variable`做作用域绑定

动态变量还支持第二种*作用域内*的用法。`set`/`get`/`change`（不带 `-global` 后缀）读写的是*当前*的动态作用域，而`with-variable`（位于[`namespaces`][namespaces]）会在一段引用执行期间创建一个全新的作用域：

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

在`quot`执行期间，变量会绑定到`value`；一旦`quot`返回，这个绑定就消失了。这样，外层的调用方就能“注入”一个值，让内层代码直接读取，而不必把它塞进每一个栈签名里。

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

本练习自始至终都使用全局那一种，不过在你阅读别人的代码时，认出与之对应的`set`/`get`/`change`系列会很有用。

## 可变向量

因为动态变量保存的是引用，所以你可以把*可变*的集合放进一个动态变量里，并就地更新它：

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }`是字面量向量。保存`V{ }`字面量之前一定要先`clone`：字面量在多次调用之间是共享的。

## `find`：第一个匹配项

`find`（位于[`sequences`][sequences]）返回第一个让谓词为真的元素，以及它的下标：

```
find ( seq quot -- index elt/f )
```

如果没有任何元素匹配，两个值都是`f`。用`nip`丢掉下标，再用`unless*`，这就是标准的“缺失时取默认值”组合。

## `reject`：丢掉匹配项

`reject`（同样位于[`sequences`][sequences]）与`filter`相反：它返回那些*未通过*谓词的元素。
