# 简介

Factor 的条件语句在**quotations**之间选择，也就是写在方括号`[ ... ]`中的代码片段。写入`[ ... ]`会把代码作为一个值压入栈中，而不是运行它；然后条件语句再决定运行哪个 quotation。（quotations 会在后面的练习中完整介绍。）

`if`（在[`kernel`][kernel]中）是 Factor 的基本条件语句。它接受一个布尔值和两个 quotation，如果布尔值为真就运行第一个，否则运行第二个。

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when`只在布尔值为真时运行它的 quotation，`unless`只在布尔值为假时运行。对于多路分支，还有`cond`（在[`combinators`][combinators]中）：

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
