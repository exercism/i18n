# 简介

## Try/Rescue/Else/After

使用`try..rescue`是捕获错误时非常强大的结构。捕获错误让函数能够在必要时返回已定义的值。`try..rescue`结构还提供了两个我们可以使用的附加特性：

- `else`块
  - 当 try 块执行成功时，结果会与这个块匹配。
- `after`块
  - 无论 try 块成功还是抛出异常，只要程序当时仍在运行，`after`块中的代码就总会执行。
  - `after`块的结果不会返回给调用作用域。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```

## 动态派发

Elixir 解析要调用的函数时，会使用模块名来进行查找。如果模块名绑定到了一个变量，查找就可以动态进行。

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```

在内部，模块名是一个原子。所有 Elixir 模块原子都会自动加上`Elixir.`前缀。

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```
