# 关于

Rust 中的布尔值由`bool`类型表示，它的值只能是`true`或`false`。

Rust 支持 1 种[布尔取反运算符][negation operators]：`!`（取反）。

Rust 支持 6 种[比较运算符][comparison operators]：`==`（等于）、`!=`（不等于）、`>`（大于）、`<`（小于）、`>=`（大于或等于）、`<=`（小于或等于）。可以用它们判断非布尔值之间的关系，并得出一个布尔值。

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

与某些语言不同，`0`不是`false`，非零值也不是`true`。

Rust 支持 3 种[逻辑二元运算符][logical binary operators]：`&`（逻辑与）、`|`（逻辑或）、`^`（逻辑异或）。

Rust 支持 2 种[布尔运算符][lazy boolean operators]：`||`（或）、`&&`（与）。它们与`|`和`&`的区别在于：只有当左侧操作数无法决定整个表达式的结果时，才会对右侧操作数求值。也就是说，只有当左侧操作数的求值结果为`false`时，`||`才会对右侧操作数求值；而`&&`只在左侧操作数的求值结果为`true`时才会。

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
