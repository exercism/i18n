# 余数

在数学中，**余数**是做某种计算后“剩下”的量。例如，`5 / 3` 的余数是 `2`。

许多编程语言用百分号（`%`）作为运算符来计算余数。例如：
```javascript
5 % 3 == 2
```

余数通常可以同时对整数和浮点数计算。例如，
```javascript
5.3 % 3 == 2.3
```

处理负数时，结果的正负号始终与被除数（等号左边被除的那个数）相同。例如：
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

有些语言（例如 Python）用 `%` 运算符做的是求模运算，而不是求余运算。这两种运算对负数的处理方式不同。你可以前往[维基百科](https://en.wikipedia.org/wiki/Modulo)了解更多。
