# 关于

[while 循环][while-loops]是一种控制流语句，它允许在某个条件为 true 时执行代码。
Swift 提供两种 while 循环：while 循环和 repeat-while 循环。
while 循环的条件在循环体执行之前求值；如果条件为 false，循环体根本不会执行。
Swift 中的 while 循环结构如下：

```swift
while <#condition#> {
  <#code#>
}
```

在这里，只要 count 大于 0，循环就会一直执行，从而打印出数字 2、1 和 “Liftoff!”。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[repeat-while 循环][while-loops]与 while 循环类似，但条件在循环体执行之后才求值。
这意味着循环体至少会执行一次，即使条件为 false。
Swift 中的 repeat-while 循环结构如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

在这里，因为条件为 false，循环只会执行一次。
由于它是 repeat-while 循环，循环体会在条件求值之前先执行一次。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## 可选绑定循环

Swift 中 while 循环的一个常见变体是可选绑定 while 循环。
只要对某个返回可选值的函数的调用返回一个非 `nil` 值，这类循环就会重复执行。
随后这个（非可选的）值会被绑定到你选定的名字上，并可以在循环体中使用。

```swift
var arr = [1,2]
while let count = arr.popLast() {
  print("\(count)…")
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```
