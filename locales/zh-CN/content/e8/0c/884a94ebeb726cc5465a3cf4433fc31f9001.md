# 介绍

## 条件判断 If

### 逻辑运算符

Java 支持三个逻辑运算符：`&&`（AND）、`||`（OR）和`!`（NOT）。

### if 语句

任何条件运算的底层类型都是`boolean`类型，它的值可以是`true`或`false`。条件判断常被用作流程控制机制，用来检查各种条件。如果要检查某种特定情况，可以使用`if`语句：当底层条件为`true`时，它就会执行自己的代码，像这样：

```java
int val;

if(val == 9) {
    // conditional code
}
```

在涉及不止一种情况的场景中，可以用`else if`和`else`语句把多个`if`语句串联起来。

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### switch 语句

Java 还提供了`switch`语句，用于处理有多个选项的场景。

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
