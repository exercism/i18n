# 关于

[Nil][nil-dictionary] 是一个英语单词，意思是“没有”或“零”。在 Elixir 中，`nil` 是一个特殊的值，表示值的_缺失_。

```elixir
# I do not have a favorite color
favorite_color = nil
```

`nil` 是一个原子，但通常写作 `nil`，而不是 `:nil`。布尔值 `true` 和 `false` 也是原子。

[//]: # (elixir-formatter-disable-next-block)

```elixir
nil === :nil
# => true

true === :true
# => true
```

你可以使用 [`==`][kernel-equal]、模式匹配，或 [`is_nil` 守卫][kernel-is-nil]来检查变量的值是否为 `nil`。

```elixir
def call(phone_number) do
  if phone_number == nil do
    :error
  end
end
```

```elixir
def call(phone_number) when is_nil(phone_number) do
  :error
end
```

```elixir
def call(nil) do
  :error
end
```
