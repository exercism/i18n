# 简介

F# 的`char`类型是 16 位的值，用于表示文本中最小的可寻址单元，默认不可变。

`char`可以用单引号定义为字面量：

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

字符串是由字符组成的序列。

通过（从 0 开始的）下标，可以从字符串中取出单个`char`：

```fsharp
"Exercism"[4] //  =>  'c'
```

遍历字符串时，每一步都会返回一个`char`。

为了方便起见，下一个示例使用了高阶函数和匿名函数。这些内容会在后面的教学大纲中详细讲解，不过现在，它们是遍历字符串中字符的一种简洁写法。

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

如上所示，`char`可以转换为其`int`值。这对其他文字（*至少在某些情况下*）也适用：

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

比较字符时，使用的是底层的 Int16：

```fsharp
'A' < 'D'  // =>  true
```

另外，`int`也可以转换为`char`：

```fsharp
char 77  // => 'M'
```

`System.Char`库包含了 .NET 语言应有的一整套方法，例如大小写转换：

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
