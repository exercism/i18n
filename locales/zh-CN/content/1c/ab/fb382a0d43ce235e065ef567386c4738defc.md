# 指令补充

## 等等，这根本不可能！

在 Roc 中，不使用_任何_内置函数来实现这些数组操作几乎是不可能的，因为你总得有办法向数组追加或前置元素。
在其他语言里，你可能会用 Haskell 的 `:` 或 Python 的 `+=` 这类运算符，但在 Roc 中，你必须使用 [`List`函数](https://www.roc-lang.org/builtins/main/#Builtin.List)。

所以在本次练习中，你可以使用 `List.append`（但请避免使用其他任何内置函数）。

许多函数式编程语言把链表作为主要的集合类型。
在链表中，前置一个元素或弹出第一个元素都很高效，所以在那些语言里，你会用 `List.prepend` 实现数组操作。
不过在 Roc 中，`List`就是一个数组（一块连续的字节）。
数组的特性与链表不同，比如它可以高效地按下标访问元素，也能高效地追加新元素。
正因如此，在 Roc 中我们经常使用 `List.append`，很少使用 `List.prepend`。

## 命名

Roc 使用的名字和通用指令中列出的略有不同：

- 用 `concat`，而不是 `append`
- 用 `join`，而不是 `concatenate`
- 用 `len`，而不是 `length`
- 用 `fold`，而不是 `foldl`
- 用 `fold_rev`，而不是 `foldr`

不过，以下函数名在 Roc 中是标准的：

- `filter`
- `map`
- `reverse`

## 提示

试试这样写：

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

或者

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
