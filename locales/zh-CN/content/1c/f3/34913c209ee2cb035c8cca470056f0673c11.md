# 说明

在这个练习中，你将编写代码，借助一个国际电话区号哈希映射来记录国际电话区号。

这个映射用整数作为键（也就是区号），用字符串（国家名称）作为值。

本练习共有 11 个任务，都涉及电话区号。

## 1. 创建一个预先填充的哈希映射

有一个预先填充好的哈希映射，其中包含以下 3 个电话区号：“United States of America”（区号为 1）、“Brazil”（区号为 55）和“India”（区号为 91）。定义 `countries` 变量来保存这个预先填充的哈希映射：

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. 向映射中添加一个国家

把区号为 44 的“United Kingdom”添加到任务 1 创建的映射中：

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. 获取与区号匹配的国家名称

获取区号为 55 的国家的名称：

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. 更新国家名称

把“United States of America”的名称改为“Les États-Unis”：

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. 检查映射中是否存在某个国家

检查任务 1 创建的映射中是否存在 Brazil 的记录：

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. 尝试更新映射中不存在的国家名称

试着修改一个区号不在映射中的国家名称，比如 999。这不会让映射发生任何变化：

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. 从映射中移除一个国家

从映射中移除 India：

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. 找出名称最长的国家

处理映射中的值，找出名称最长的那个：

```clojure
(longest-name countries)
;;=> "United States of America"
```
