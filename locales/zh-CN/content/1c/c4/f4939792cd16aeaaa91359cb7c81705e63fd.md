# 说明

你是一名热衷观鸟的人，一直在记录过去 7 天里有多少只鸟造访了你的花园。

你有 5 个任务，它们都与造访你花园的鸟的数量有关。

## 1. 查看上周的计数

你用 JSON 格式记录鸟的数量。
一个“main”数组里存放着一周又一周的计数数组。
每一周的计数都是一个由 7 个整数组成的数组，一周中的每一天对应一个数字。
新的一周总是追加在 main 数组的末尾。
实现一个过滤器，返回上周的计数。

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. 查看昨天有多少只鸟造访

实现一个过滤器，返回昨天有多少只鸟造访了你的花园。
鸟的数量按天排列，第一个元素是最早一天的计数，最后一个元素是今天的计数。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. 计算造访鸟类的总数

实现一个过滤器，返回本周造访你花园的鸟的总数。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. 计算忙碌的天数

有些日子比其他日子更忙。
只要一天里有 5 只或更多的鸟造访了你的花园，这一天就算忙碌。
实现一个过滤器，返回本周忙碌的天数。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. 检查是否有哪一天没有鸟造访

实现一个过滤器：如果本周有任何一天没有鸟造访花园，就返回`true`；否则返回`false`。

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
