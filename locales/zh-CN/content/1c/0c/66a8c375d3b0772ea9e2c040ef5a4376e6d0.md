# 简介

在 Factor 中，你只要把单词一个接一个写出来，就把它们组合起来了。你书写的顺序*就是*它们组合的方式。（程序员把这叫做*函数组合*。）一个单词的本体本身就是一个单词序列：每个单词都从栈上消耗一些值，再压入自己的结果，下一个单词接着上一个单词停下的地方继续。所以，定义

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

本身就已经*是*`cleanupname`、`first`和`1string`的组合。

这个练习还会介绍**引用**：一段你可以当作值存起来、以后再运行的代码，而不是当场就把它运行掉。

## 引用

引用就是一段用方括号包起来的代码。它写下来的时候并不会运行，而是作为一个值待在栈上：

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call`会运行一个引用：

```factor
3 [ 2 * ] call .    ! => 6
```

当你需要把代码当作数据传递时，就写一个引用：留到以后再运行，或者传给一个*组合子*，也就是接收引用作为输入的单词。

## `compose`

`compose ( quot1 quot2 -- combined )`把两个引用粘合成一个，按书写的顺序依次运行它们：

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

你通常会发现，用`:` ... `;`定义一个小单词比`compose`更好读，但当你需要临时构造引用时，`compose`就很方便。当这些积木本身不是引用时，`>quotation ( seq -- quot )`（来自[`quotations`][quotations]）可以把一组值和单词引用组成的序列变成一个可调用的引用：

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## 把一个引用应用到两个输入

`bi@ ( x y quot -- ... )`先在`x`上运行这个引用，再在`y`上运行一遍，把两个结果都留在栈上：

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

这个练习的`couple`任务接收两个名字；`bi@`是把`initial`分别应用到它们身上的自然做法。

## 几个字符串单词

这个练习需要几个小的字符串单词，它们来自三个词汇表（[`sequences`][sequences]、[`ascii`][ascii]和[`strings`][strings]）：

- `replace ( seq old new -- new-seq )`（在`splitting`中）：替换子串。
- `[ blank? ] trim`（`trim`在`sequences`中，`blank?`在`ascii`中）：去掉开头和结尾的空白。
- `1string ( char -- str )`（在`strings`中）：把一个字符包装成字符串。
- `>upper ( str -- upper )`（在`ascii`中）：把字符串变成大写。
- `append ( s1 s2 -- s )`（在`sequences`中）：拼接两个字符串。
- `prepend ( s1 s2 -- s )`（在`sequences`中）：先拼接`s2`，再拼接`s1`（相当于把`append`的输入调换顺序）。
- `glue ( s1 s2 sep -- s )`（在`sequences`中）：用分隔符把两个字符串拼接起来，分隔符在两者中间。
- `surround ( seq pre post -- new )`（在`sequences`中）：用一个前缀和一个后缀把字符串包起来。

在字符串里，Unicode 字符可以写成`\u{XXXX}`，其中`XXXX`是十六进制的码点。这个练习里会出现心形`\u{2764}`（❤）。

## 格式化输出

当`append`/`glue`/`surround`表达力不够时，[`formatting`][formatting]提供了 printf 风格的`sprintf`：

```
sprintf ( inputs... format-string -- str )
```

`%s`插入一个字符串，`%d`插入一个整数，`%f`插入一个浮点数；可选的宽度、精度和填充修饰符放在`%`和类型字母之间：

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

要在数字和字符串之间来回转换，[`math.parser`][math.parser]提供了`number>string`和`string>number`：

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
