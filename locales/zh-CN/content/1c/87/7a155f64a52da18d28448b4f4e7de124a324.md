# 说明补充

## 加分题

用这个字符串来测试你的函数：`uüu`，看看会发生什么。
试着写一个能正确反转这个字符串的函数。
提示：字素簇

要让加分测试跑起来，请删掉最后一个测试上的忽略标记（`#[ignore]`），然后用下面的命令运行测试：

```bash
cargo test --features grapheme
```

加分任务需要用到外部库（在 Rust 的行话里叫 `crate`）。
寻找这类库的好去处是 [crates.io](https://crates.io/)，它是 crate 的官方仓库。
请记住，我们的测试运行器只支持有限的一部分 crate。
完整列表在 [这个文件](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) 的 `[dependencies]` 一节中。

[查看文档](https://doc.rust-lang.org/cargo/guide/dependencies.html)，了解如何在项目中使用外部 crate。
