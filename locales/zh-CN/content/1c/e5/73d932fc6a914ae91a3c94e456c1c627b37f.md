# 说明

你的日本朋友 Kuroko 是一位面向国际观众的主播。Kuroko 的直播日程相当复杂，每天的直播似乎都在不同的时间开始。

他请你帮忙做一个小应用，用观众所在的本地时区来显示他的日程：Kuroko's Clock。他还有一个额外的要求：这个应用要能用两种不同的语言显示时间：日语和美式英语。

## 1. 日期

定义一个函数 `showLocalDate : Locale -> Int -> Month -> Int -> String`，用来显示一个（有效的）本地日期。

在`US`区域中，格式为`Month/Day/Year`，不补前导零。

在`JP`区域中，格式为`Year年Month月Day日`，同样不补前导零。

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. 时间到

定义一个函数 `showLocalTime : Locale -> Int -> Int -> String`，用来显示一个（有效的）本地时间。

在`US`区域中，小时会以 12 小时制显示，并附上“PM”或“AM”，分钟则会补前导零。

在`JP`区域中，小时会以 24 小时制显示在“時”之前，分钟则不补前导零，显示在“分”之前。

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. 进入时区

定义一个函数 `showDateTime : Locale -> Zone -> Posix -> String`，用来按照特定的区域，显示相对于某个时区的日期和时间。

使用`showLocalDate`和`showLocalTime`来显示最终结果。

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
