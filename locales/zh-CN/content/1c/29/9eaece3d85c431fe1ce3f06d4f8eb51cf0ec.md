# 说明补充

## 实现

在 Cairo 中，原生并不支持浮点数，所以我们用整数来表示小数值。

在区块链开发中，这种做法对于保持计算精度至关重要。

在本练习中，我们把公转周期换算成微秒，从而使用**定点运算**。

例如，水星 `0.2408467` 地球年的公转周期，乘以 `1,000,000` 之后就变成 `240,846,700` 微秒。

为了处理小数精度，测试用例假定得到的年龄保留**两位小数**，并用整数表示。

也就是说，代码中会把 `31.69` 岁的年龄存成 `3169`。

为此，我们在做除法之前先乘以 100。

下面是一个例子：

```rust
let mercury_orbital_period = 240_846_700; // in microseconds
let age_microseconds = age_seconds * 1_000_000;
// multiplying with 100 to retain 2 decimal places
age_microseconds * 100 / mercury_orbital_period
```

使用这种方法，你就能在保持所需两位小数精度的同时，把小数值准确地表示为整数，而这对通过测试至关重要。
