# 关于基础

基础概念把 [Go](https://golang.org) 介绍为一门静态类型、编译型的编程语言。
由于过去的域名是 golang.org，这门语言常被称为 Golang，但它的正式名称是 Go。

基础概念介绍了这门语言的三大特性：包、函数和变量。

## 包

Go 应用是按包来组织的。
包是放在同一个目录下的一组源文件。
同一个目录下的所有源文件必须共用同一个包名。
按照惯例，包名取导入路径中的最后一个目录名。
例如，[“math/rand”包](https://golang.org/src/math/rand/)中的文件都以语句`package rand`开头。
导入一个包后，只有名称以大写字母开头的实体（函数、类型、变量、常量）才能被使用或访问。
在 Go 中，推荐的命名风格是：标识符使用`camelCase`命名，只有需要跨包访问的标识符才使用`PascalCase`。

```go
package lasagna
```

## 变量

Go 是静态类型的，也就是说所有变量在编译期都[必须具有明确的类型](https://en.wikipedia.org/wiki/Type_system)。

定义变量时，可以显式指定类型：

```go
var explicit int // Explicitly typed
```

也可以使用初始值，编译器会把变量的类型设置为与该初始值的类型一致。

```go
implicit := 10   // Implicitly typed as an int
```

变量一旦声明，就可以用`=`运算符给它赋值。
变量一旦声明，它的类型就永远不会改变。

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## 常量

常量和变量一样，也保存着一份数据，但它的值在程序运行期间不能改变。

常量用`const`关键字定义，可以是数字、字符、字符串或布尔值：

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## 函数

Go 函数接受零个或多个形参。
形参必须显式标注类型，Go 不做类型推断。

函数通过`return`关键字返回值。

调用函数时，需要写出函数名，并为函数的每个形参传入实参。

注意，Go 支持两种注释。
单行注释以`//`开头，多行注释写在`/*`和`*/`之间。

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
