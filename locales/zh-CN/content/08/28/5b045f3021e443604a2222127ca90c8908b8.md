# 关于

在 Go 中，我们可以使用相等运算符和关系运算符来比较值。这类运算符一共有 6 个：

| 比较        | 运算符  |
| ------------------| --------- |
| 相等             | `==`      |
| 不相等         | `!=`      |
| 小于              | `<`       |
| 小于等于     | `<=`      |
| 大于           | `>`       |
| 大于等于  | `>=`      |

比较的结果总是一个布尔值：

```go
a := 3

a != 4 // true
a > 5  // false
```

## 相等运算符

相等运算符`==`和`!=`分别用来判断一个值是否等于另一个值。在 Go 中，大多数类型都可以使用相等运算符。下面是一些常见的例子：

```go
2 == 3 // false, integer comparison

2.1 != 2.2 // true, float comparison 

"hello" == "hello" // true, string comparison

'a' != 'b' // true, rune/byte comparison
```

## 关系运算符

关系运算符用于判断一个值是否大于（`>`）、大于等于（`>=`）、小于（`<`）或小于等于（`<=`）另一个值。数字、字节、rune 和字符串都可以进行这种比较。比较字符串时，遵循字典顺序（也就是词典序）。

```go
2 > 3 // false, integer comparison

1.2 < 1.3 // true, float comparison

'a' > 'b' // false, rune/byte comparison

"Hello" < "World" // true, string comparison
```
