# 简介

Cairo 中的控制流让你可以根据条件和重复来控制程序的执行路径。

## 条件执行

使用`if`表达式根据条件运行代码：

```rust
let number = 42;
if number > 0 {
    println!("Positive number");
} else if number < 0 {
    println!("Negative number");  
} else {
    println!("Zero");
}
```

`if`是一个表达式，因此可以返回值：

```rust
let result = if condition { 5 } else { 10 };
```

## 循环

使用`loop`让代码重复运行。
循环会一直运行下去，除非你停止它；当满足条件时，使用`break`跳出循环。

```rust
let mut counter = 0;
loop {
    if counter == 5 {
        break;
    }
    println!("Counter: {}", counter);
    counter += 1;
}
```

循环可以使用`break`返回值：

```rust
let result = loop {
    counter += 1;
    if counter == 10 {
        break counter * 2; // Returns 20
    }
};
```

使用`continue`跳到下一次迭代：

```rust
let mut i = 0;
loop {
    i += 1;
    if i % 2 == 0 {
        continue; // Skip even numbers
    }
    if i > 10 {
        break;
    }
    println!("{}", i); // Only prints odd numbers
}
```
