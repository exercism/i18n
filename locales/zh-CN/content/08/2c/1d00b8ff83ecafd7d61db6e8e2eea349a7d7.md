# 说明

你的朋友刚给你发来一条消息，里面有一个重要的秘密。为了不让别人轻易看懂，这条消息经过了一系列位运算加密。你需要编写函数来帮助解密这条消息。

## 1. 把位移回去

解密这条消息的第一步，是抵消加密过程中的移位操作：把位向右移回去。后面的解密步骤会假定左侧移入的是 0。

实现`shiftBack`函数，它接收一个值和要移位的位数，并执行移位。

```kotlin
shiftBack(0b1001, 2)
# => 0b0010
```

## 2. 将某些位置为 1

接下来，有些位需要置为 1。

实现`setBits`函数，它接收一个值和一个掩码，返回将该值中的某些位置为 1 后的结果。掩码中为 1 的位，值中对应的位也应置为 1。其余所有位保持不变。

```kotlin
setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. 翻转特定的位

加密过程中有些位被翻转了。要解密这条消息，需要把它们再翻转回来。

实现`flipBits`函数，它接收一个值和一个掩码。掩码指明值中哪些位需要翻转。如果掩码中某一位是 1，值中对应的位就会被翻转。其余所有位保持不变。

```java
flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. 清除特定的位

最后，还有一些位解密后总是 0。

实现`clearBits`函数，它接收一个值和一个掩码。掩码中为 1 的位，`value`中对应的位应置为 0。其余所有位保持不变。

```java
clearBits(0b0110, 0b0101);
# => 0b0010
```
