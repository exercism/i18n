# 说明

在本练习中，你将模拟一个基于窗口的计算机系统。
你将创建一些窗口，它们可以被移动、调整大小，并显示自己的内容。

## 1. 定义一个 `Size` 结构体

定义一个名为`Size`的结构体，它有两个`Int`属性：`width`和`height`，分别存储窗口当前的宽度和高度。
初始的宽度和高度应分别为 80 和 60。
再添加一个方法`resize(newWidth:newHeight:)`，它接收新的宽度和高度形参，并修改这些属性以反映新的尺寸。

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. 定义一个 `Position` 结构体

定义一个名为`Position`的结构体，它有两个`Int`属性：`x`和`y`，分别存储窗口左上角当前的水平位置和垂直位置。
`x`和`y`的初始值都应为 0。位置 (0, 0) 是屏幕的左上角；向右移动时`x`值增大，向下移动时`y`值增大。

再添加一个方法`moveTo(newX:newY:)`，它接收新的`x`和`y`形参，并修改这些属性以反映新的位置。

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. 定义一个 `Window` 类

定义一个窗口类，它包含以下属性：

- `title`：`String`，初始值为 "New Window"
- `screenSize`：`Size`，常量，`width` = 800，`height` = 600
- `size`：`Size`，初始值为`Size`结构体的默认值
- `position`：`Position`，初始值为`Position`结构体的默认值
- `contents`：`String?`，初始值为`nil`

你还应该为这个类定义一个空的初始化器。

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. 添加一个调整窗口大小的方法

- `resize(to:)`：`(Size) -> ()` - 该方法接收一个`Size`结构体作为输入，尝试把窗口调整为指定的大小。不过，新的大小不能超出某些界限。
- 允许的最小高度或宽度为 1。
  请求的高度或宽度小于 1 时会被截断为 1。
- 最大高度和宽度取决于窗口当前的位置，窗口的边不能越过屏幕的边。
  比这些界限更大的值会被截断为它们能取到的最大尺寸。
  例如，如果窗口的位置是`x` = 400、`y` = 300，而请求把`height`调整为 400、`width`调整为 300，那么窗口会被调整为`height` = 300、`width` = 300，因为屏幕在`y`方向上不够大，无法完全容纳这个请求。

## 5. 添加一个移动窗口的方法

- `move(to:)`：`(Position) -> ()` - 这与`resize(to:)`类似，不过该方法把窗口的_位置_调整为请求的值，而不是大小。和`resize`一样，新位置也不能超出某些限制。
- 最小的位置是 0，`x`和`y`都是如此。
- 两个方向上的最大位置都取决于窗口当前的尺寸；窗口的边不能越过屏幕的边。
  比这些界限更大的值会被截断为它们能取到的最大尺寸。例如，如果窗口的尺寸是`x` = 250、`y` = 100，而请求移动到`x` = 600、`y` = 200，那么窗口会被移动到`x` = 550、`y` = 200，因为屏幕在`x`方向上不够大，无法完全容纳这个请求。

## 6. 添加更新窗口文本和显示窗口信息的方法

- `update(title:)`：`(String) -> ()` - 该方法把`title`属性设置为传入的字符串的值。
- `update(text:)`：`(String?) -> ()` - 该方法把`contents`属性设置为传入的可选字符串的值。
- `display()`：`() -> String` - 该方法返回一个描述窗口当前状态的字符串。例如，如果窗口的`title`为 "My First Window"，position 为 x = 10、y = 100，size 为 width = 200、height = 150，contents 为 "I 😍 my window"，那么它应返回字符串：`"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - 如果`contents`为 nil，最后一行应为 "[This window intentionally left blank]"

## 7. 为 `Window` 类创建一个初始化器

窗口系统应该有一个初始化器，以便用自定义的输入来创建窗口。
为`Window`类创建**另一个**初始化器。
该初始化器应接收以下形参：`title`、`contents`，以及两个可选的形参`size`和`position`。
`size`和`position`这两个形参应默认为`Size`和`Position`结构体的默认值。

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
