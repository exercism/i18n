# 说明补充

## 异常信息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。这样做时，务必附上一条**有意义的错误信息**，指明错误的来源。这能让代码更易读，也大大有助于调试。如果你已经知道错误来源属于某种特定类型，可以选择抛出某个[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍应附上有意义的信息。

本题要求你使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在输入缺少正确的定界符、不是全大写、无法构成带节点的树，或根本无法构成树时“抛出”`ValueError`。只有当代码同时`raise`了`exception`并附上信息时，测试才会通过。

要抛出带信息的`ValueError`，请把信息作为实参传给`exception`类型：

```python
# if the tree properties as given do not have proper delimiters.
raise ValueError("properties without delimiter")

# if the tree properties as given are not all in uppercase.
raise ValueError("property must be in uppercase")

# if the input does not form a tree, or is empty.
raise ValueError("tree missing")

# if the input is a tree without any nodes.
raise ValueError("tree with no nodes")
```
