# 说明

在这个练习中，你将编写一些代码，帮助你照着最喜欢的食谱做出一份美味的千层面。

你有三个任务，它们都与烹饪千层面所花的时间有关。

## 1. 定义千层面在烤箱中所需的分钟数

定义`expectedMinutesInOven`，计算出千层面应该在烤箱里烤多少分钟。根据食谱，在烤箱中所需的分钟数是 40：

```elm
expectedMinutesInOven
    --> 40
```

## 2. 计算准备时间的分钟数

定义`preparationTimeInMinutes`，它接收千层面的层数作为形参，返回准备千层面需要多少分钟，假设每层需要 2 分钟来准备。

```elm
preparationTimeInMinutes 3
    --> 6
```

## 3. 计算经过时间的分钟数

定义`elapsedTimeInMinutes`函数，它接收两个形参：第一个形参是千层面的层数，第二个形参是千层面在烤箱里已经烤了多少分钟。该函数应返回你烹饪千层面所花的总分钟数，也就是准备时间与千层面此刻在烤箱中已经烤过的分钟数之和。

```elm
elapsedTimeInMinutes 3 20
    --> 26
```
