# Instructions

在这个练习中，你要实现一种方式来记录本地街机厅里最热门游戏的高分。

## 1. 把玩家添加到高分榜

要把玩家添加到高分榜，需要定义两个`add_player!`方法，它们接收以下实参：

- 第一个实参是分数字典。
- 第二个实参是玩家的名字，类型为字符串。
- 第三个实参是分数，类型为整数。
  这个实参是可选的；如果没有给出值，分数应设为 0。

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. 从高分榜中移除玩家

要从高分榜中移除玩家，需要定义`remove_player!`，它接收 2 个实参：

- 第一个实参是分数字典。
- 第二个实参是玩家的名字，类型为字符串。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. 更新玩家的分数

要通过替换之前的分数来更新玩家的分数，需要定义`update_score!`，它接收 3 个实参：

- 第一个实参是分数字典。
- 第二个实参是玩家的名字，类型为字符串，也就是你想更新分数的那位玩家。
- 第三个实参是你想保存为高分的新分数。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. 重置玩家的分数

要重置玩家的分数，需要定义`reset_score!`，它接收 2 个实参：

- 第一个实参是分数字典。
- 第二个实参是玩家的名字，类型为字符串，也就是你想重置分数的那位玩家。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores
Dict{String, Int64} with 2 entries:
  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. 获取玩家数组

要获取玩家数组，需要定义`players`，它接收 1 个实参：

- 第一个实参是分数字典。

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
