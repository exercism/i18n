# 指令补充

输出应按照[行主序](https://en.wikipedia.org/wiki/Row-_and_column-major_order)排列：先是第一行中的所有字，然后是第二行中的所有字，依此类推。

## 寄存器

| 寄存器   | 用途         | 类型    | 描述                     |
| -------- | ------------ | ------- | ------------------------ |
| `$a0`    | 输入         | 整数    | 大小                     |
| `$a1`    | 输入/输出    | 地址    | 按行主序排列的字矩阵     |
| `$v0`    | 输出         | 整数    | 矩阵中字的数量           |
| `$t0-9`  | 临时         | 任意    | 用于临时存储             |
