# 说明

在这个练习中，你将编写代码来分析汽车工厂的生产情况。

## 1. 计算每小时生产的合格汽车数量

汽车在流水线上生产。
流水线有一定的速度，而且速度可以调整。
流水线速度越快，生产的汽车就越多。
不过，调整流水线的速度也会改变成功生产的汽车数量，也就是生产过程中没有任何错误的汽车。

实现一个函数，接收每小时生产的汽车数量和成功率，计算每小时成功生产的汽车数量。
成功率以百分比表示，范围从`0`到`100`：

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**注意：**返回值应该是`float64`。

## 2. 计算每分钟生产的合格汽车数量

实现一个函数，接收每小时生产的汽车数量和成功率，计算每分钟成功生产多少辆汽车：

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**注意：**返回值应该是`int`。

## 3. 计算生产成本

通常，单独生产一辆汽车的成本是 $10,000，无论它是否合格。
但只要稍作规划，10 辆汽车一起生产的成本就是 $95,000。

例如，37 辆汽车可以按下面的方式生产：
37 = 3 组十辆 + 7 辆单独的汽车

所以 37 辆汽车的成本是：
3\*95,000+7\*10,000=355,000

实现函数`CalculateCost`，计算生产一定数量汽车的成本，无论它们是否合格：

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**注意：**返回值应该是`uint`。
