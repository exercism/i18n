# 提示

## 1. 从栈中取出一张卡牌

- `Vector` 的下标从 `1` 开始。
- 可以用 `v[n]` 取出向量 `v` 中的第 `n` 个值。

## 2. 交换栈中的一张卡牌

- `Vector` 是可变的，你可以随时通过赋一个新值来改变它们的内容。

## 3. 在栈顶插入一张卡牌

- Base 中有一个方法 [`push!`][push]，可以向集合的末尾添加一个新值。

## 4. 从栈中移除一张卡牌

- Base 中有一个方法 [`deleteat!`][deleteat]，可以按下标删除 `Vector` 中的一个元素。

## 5. 移除栈顶的卡牌

- Base 中有一个方法 [`pop!`][pop]，可以移除集合末尾的元素。

## 6. 在栈底插入一张卡牌

- Base 中有一个方法 [`pushfirst!`][pushfirst]，可以向集合的开头插入一个新值。

## 7. 从栈底移除一张卡牌

- Base 中有一个方法 [`popfirst!`][popfirst]，可以移除集合开头的元素。

## 8. 查看栈的大小

- Base 中有一个方法 [`length`][length]，可以获取集合的长度。
