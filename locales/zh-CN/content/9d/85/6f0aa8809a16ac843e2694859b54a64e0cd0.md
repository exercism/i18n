# 说明

在这个练习中，你将编写代码，帮助一家标牌公司为他们的标牌制作自定义信息。

## 1. 创建一组有用的字符串

定义以下常量字符串，它们将用于制作标牌：

- `birthday`：它保存值 “Birthday”
- `valentine`：它保存值 “Valentine's Day”
- `anniversary`：它保存字符串 “Anniversary”

## 2. 创建一组有用的字符

定义以下常量字符，它们将用于制作标牌：

- `space`：它保存值 “ ”（单个空格）
- `exclamation`：它保存值 “!”

## 3. 组合短语来构建消息

实现函数 `buildSign(for:name:)`，它接受实参 `for`，该实参保存你在第一个任务中定义的三个字符串之一；以及实参 `name`，它是一个保存标牌所属者姓名的字符串。
你需要使用拼接来构建标牌的信息，并记得复用已定义的常量。
函数应以字符串形式返回标牌信息。

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. 制作毕业标牌

实现函数 `graduationFor(name:year:)`，它接受实参 `name`，该实参是一个保存标牌所属者姓名的字符串；以及实参 `year`，它是一个保存此人毕业年份的整数。
你需要使用模板字符串来构建标牌的信息。
函数应以字符串形式返回标牌信息。

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. 计算标牌的费用

实现函数 `costOf(sign:)`，它接受实参 `sign`，该实参是一个保存标牌信息的字符串。
标牌的基础价格为 20（以给定货币计）。此外，每个字母花费 2（空白字符也计入计算）。
函数应以整数形式返回标牌的费用。

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
