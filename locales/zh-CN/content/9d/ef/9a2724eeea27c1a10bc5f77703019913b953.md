# 介绍

## 强制类型转换

强制类型转换和类型转换是两种不同的方式，都能把表达式从一种数据类型转换成另一种数据类型。

表达式可以使用强制类型转换运算符`(<type>)`转换成另一种类型。

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

如果类型不兼容，就会抛出`InvalidCastException`的实例。对于数字来说，这表明接收类型无法表示转换后的值。对于类来说，其中一个类型必须派生自另一个类型（这一点对结构体也自然成立）。

除了_强制类型转换_，另一种做法是使用`is`运算符进行_类型转换_。它通常用于引用类型和可空类型。

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

如果你需要检测对象的精确类型，那么`is`可能有点过于宽松，因为对于某个类，以及它直接或间接派生的任何类和接口，它都会返回 true。在这种情况下，`typeof`和`Object.GetType()`就是解决办法。

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
