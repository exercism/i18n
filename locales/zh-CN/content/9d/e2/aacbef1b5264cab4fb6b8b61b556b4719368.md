# 测试

Clojurescript REPL 让你可以轻松运行代码并获得即时反馈，也可以用它来运行测试。

## Leiningen
要使用 Clojure CLI 打开 REPL，请切换到包含该练习的目录，然后运行：
``` bash
$ clojure -m cljs.main -re node
```

注意：系统中需要安装 Node。

当你准备好做某个练习，并且已经创建了用来存放解答的文件（例如 `bob.cljs`）之后，就可以在终端里用 `$ clojure -A:test` 来运行测试。

首先，`require` 测试命名空间：
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

把 ns 切换到测试命名空间：
```clojure
=> (ns bob-test)
nil
```

然后对 `bob-test` 调用 `run-tests`：
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

要用 Clojure CLI 运行某个练习的测试，只需调用：
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
