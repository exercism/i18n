# 说明补充

## 定义归纳类型

本练习要求返回值是一个[归纳类型][inductive]`Classification`，你需要自己定义它。

这个类型必须有 [BEq][beq] 实例，也就是说，它可以进行布尔相等性测试；还必须有 [Repr][repr] 实例，也就是说，该类型的值可以被格式化以便显示。

关于实例声明，你可以参考[这一页][instance]。
Lean 可以为许多类自动[生成实例][deriving]。

## 子类型

`classify`函数的实参是一个名为`Positive`的[子类型][subtype]：

```
def Positive := { x : Nat // x > 0 }
```

子类型表示某个特定类型中满足某个谓词的那些元素。
`Positive`表示`Nat`中大于`0`的元素。

子类型的任意元素都可以看作一个组合，由底层类型的一个值，以及一个数学意义上的证明构成，证明这个值满足相应的谓词。

子类型在类型层面施加不变式，确保无法构造出不合规范的值。
