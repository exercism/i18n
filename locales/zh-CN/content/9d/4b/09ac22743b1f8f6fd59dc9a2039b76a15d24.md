# 简介

## JavaScript 中的正则表达式

[正则表达式][mdn-regular-expressions]（Regular Expression，简称 Regex）是一串字符，我们可以用它来定位和操作字符串中的某些元素。因此，我们可以：

- **搜索**字符串中的文本
- **替换**字符串中的子串
- **提取**字符串中的信息

> 💡 JavaScript 的正则表达式风格属于该语言的 ECMA-262 标准。这意味着你不必担心浏览器特定的兼容性问题。

## 如何创建正则表达式

在 JavaScript 中，正则表达式通常写成`/pattern/modifiers`这样的格式。

创建正则表达式有两种方式：

1. **正则表达式字面量**：

```javascript
const regex = /[a-z]/;
```

2. 构造函数**RegExp**：

```javascript
const regex = new RegExp('[a-z]');
```

这两种情况下，JavaScript 都会根据正则表达式创建一个对象。建议默认使用字面量这种不可变的写法。

如果正则表达式会发生变化，或者我们还不知道它是什么（比如来自用户的输入），就可以使用 RegExp 构造函数。

## 🏴‍☠️ 标志

正则表达式有一些可选的超能力，叫做[`flags`][mdn-flags]，能提供额外的功能。

其中一些常用的标志有：

- `/g` - 全局搜索
- `/i` - 忽略大小写
- `/m` - 多行搜索

下面是一个简单的例子：

```javascript
const re = /home/gi;
const str = 'Home, sweet home.';
const myArray = str.match(re);
console.log(myArray);

=> // ["Home", "home"]
```

`g`字符让我们能够解析字符串中所有可能的匹配项。如果没有这个功能，JavaScript 只会提取出第一个匹配的`Home`。

忽略大小写标志`/i`让我们在查找模式时更加灵活。这样，我们要找的内容是大写`UPPERCASE`还是小写`lowercase`都没有关系。

使用`RegExp`构造函数时，添加标志的语法有所不同。

```javascript
let regex = /[a-z]/gi; // literal notation
let regex = new RegExp('[a-z]', 'gi'); // constructor with string pattern as first argument
let regex = new RegExp(/[a-z]/, 'gi'); // constructor with regular expression literal as first argument (Starting with ECMAScript 6)
```

## 最常用的函数

当正则表达式与 JavaScript 现有的内置函数结合使用时，我们就能以一些强大的方式操作字符串并从中获取数据。

下面是一些最常与正则表达式一起使用的函数。

### Test

[test()][mdn-regex-test] 方法会在正则表达式与指定字符串之间搜索匹配项。返回 true 或 false。

```javascript
const str = 'It is difficult to test if you have a virus';
const result = /virus$/.test(str);

console.log(result);

// => true
```

### Match

使用 [match()][mdn-regex-match] 方法，我们可以得到一个有用的数组，其内容取决于是否找到了匹配项。

这样，我们既能**搜索**，也能**提取**任意字符串中的信息。例如：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';
const regex1 = /someone/;
const regex2 = /happy/;

funnyQuote.match(regex1);
// => ["someone", index: 11, input: "If you see someone crying, ask if it is because of their haircut.", groups: undefined]

funnyQuote.match(regex2);
// => null
```

当存在全局搜索标志`/g`时，该方法不会只返回唯一的匹配项以及索引或输入等有用信息，而是返回数组中显示的所有匹配项：

```javascript
const funnyQuote =
  'If you see someone crying, ask if it is because of their haircut.';

const regex3 = /if/gi;

funnyQuote.match(regex3);
// => ["If", "if"];
```

### Replace

JavaScript 中的 [replace()][mdn-regex-replace] 方法允许我们在给定的字符串中搜索一个值，并将其替换为想要的新值。

```javascript
string.replace(searchValue, newValue);
```

用于搜索替换的模式可以是单个字符串，也可以是正则表达式。

```javascript
let string = 'I like dogs!';
let result = string.replace('dogs', 'cats');

let string = 'I would love to travel to Japan';
let result = string.replace(/Japan/g, 'Hawaii');
```

此外，我们还可以在替换位置应用一个函数，以便对每个值做进一步的修改。

```javascript
let text = 'Say hello to the chatbot.';
let result = text.replace(/chatbot|hello/gi, function (word) {
  return word.toUpperCase();
});
// => "Say HELLO to the CHATBOT"
```

### Split

JavaScript 中的 [split()][mdn-regex-split] 方法展示了使用正则表达式来操作字符串的另一种方式。

这样，我们会用正则表达式通过识别某个模式来划分给定的字符串，例如`str.split(/[,.\s]/)`。这个模式将用作`separator`。

```javascript
const str = 'hello,user.how are.you';

const result = str.split(/[,.\s]/);

console.log(result);
// => ['hello', 'user', 'how', 'are', 'you']
```
