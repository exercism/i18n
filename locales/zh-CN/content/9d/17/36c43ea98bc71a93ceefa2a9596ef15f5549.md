# 简介

当为只能取一组特定可能状态的数据建模时（比如星期几、指南针方向，或手柄上的按钮），像`Int`或`String`这样的基本类型有明显缺点。使用整数或字符串时，代码必须不断检查无效值（比如状态码`999`，或拼写成`"leftt"`这样的错误），而读者也无法一眼看出这些数字代表什么。

Swift 用[_枚举_][enumerations]（也常简称为*枚举*）解决这个问题。枚举为一组相互关联、有名字的值定义一种共同的类型。因为编译器提前知道所有可能的成员，所以能在编译时检查代码是否正确和完整。枚举还可以有方法、构造器和计算属性。

## 定义枚举

使用`enum`关键字定义枚举，后面跟上类型名，并在大括号内列出各个成员。按照 Swift 的约定，类型名使用`UpperCamelCase`，而每个成员使用`lowerCamelCase`：

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

也可以在一行中定义多个成员，用逗号分隔：

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

要引用某个枚举成员，请写出枚举类型名、一个点号（`.`）以及成员名。一旦类型已知，或者编译器能够推断出来，就可以省略类型名，使用更简短的点语法：

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 方法和构造器

枚举可以定义方法和自定义构造器，就像类和结构体那样。在枚举方法内部，`self`指的是当前成员值：

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 原始值

枚举成员可以预先填充默认值，这些默认值称为[_原始值_][raw-values]。一个枚举中的所有原始值必须共享同一类型（比如`Int`、`String`或`Character`）：

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

可以使用`init(rawValue:)`从原始值初始化枚举。因为可能提供无效的原始值，所以这个构造器返回一个可选值：

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift 可以为`String`和`Int`枚举自动分配原始值：

- 对于`String`枚举，每个成员的原始值默认为其成员名。
- 对于`Int`枚举，原始值从`0`开始，除非另有指定，否则每次自增 1。

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```
