# 说明

在这个练习中，你要为一个朋友正在开发的新角色扮演游戏（RPG）实现冒险任务的逻辑。游戏的主角叫 Annalyn，是个勇敢的女孩，身边有一只凶猛又忠诚的宠物狗。不幸的是，灾难降临了：她最好的朋友在森林里采浆果时被绑架了。Annalyn 会设法找到并解救她最好的朋友，在这次冒险中她可以选择带上自己的狗。

沿着最好朋友的踪迹追踪了一段时间后，她找到了关押着她最好朋友的营地。原来有两个绑匪：一个强大的骑士和一个狡猾的弓箭手。

找到绑匪之后，Annalyn 思考自己可以采取以下哪些行动：

- _快速攻击_：如果骑士正在睡觉，就可以发动快速攻击，因为他穿上盔甲需要时间，这段时间里他很脆弱。
- _潜行攻击_：如果 Annalyn 能在不被发现的情况下接近睡着的骑士，她的潜行攻击会造成 12 点伤害。否则，她对骑士只能造成 7 点伤害。
- _侦查_：只要这群人里至少有一个醒着，就可以对他们进行侦查。否则，侦查就是浪费时间。
- _向囚犯发信号_：如果囚犯醒着，而弓箭手在睡觉，就可以用鸟叫声向囚犯发信号，因为弓箭手受过鸟叫信号的训练，可能会截获信息。
- _解救囚犯_：Annalyn 可以试着潜入营地解救囚犯。
  这么做风险很大，只有两种情况下能成功：
  - 如果 Annalyn 带着她的宠物狗，那么在弓箭手睡着时她就能救出囚犯。
    骑士怕狗，弓箭手来不及做好准备，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没带狗，那她和囚犯就必须非常小心地行动！
    如果囚犯醒着，且骑士和弓箭手都睡着了，Annalyn 就能解救囚犯；但如果囚犯在睡觉，就没法救：Annalyn 突然出现会吓到囚犯，囚犯会惊醒骑士和弓箭手。

你有五项任务：根据森林里这三个角色的状态，以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可行的逻辑。

## 1. 检查是否可以发动快速攻击

实现 `canFastAttack` 函数，它接受一个布尔值，表示骑士是否醒着。如果根据骑士的状态可以发动快速攻击，这个函数返回 `True`。否则，返回 `False`：

```elm
knightIsAwake = True

canFastAttack knightIsAwake
    --> False
```

## 2. 检查是否可以侦查这群人

实现 `canSpy` 函数，它接受三个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。如果根据这三个角色的状态可以侦查这群人，这个函数返回 `True`。否则，返回 `False`：

```elm
knightIsAwake = False
archerIsAwake = True
prisonerIsAwake = False

canSpy knightIsAwake archerIsAwake prisonerIsAwake
    --> True
```

## 3. 检查是否可以给囚犯发信号

实现 `canSignalPrisoner` 函数，它接受两个布尔值，分别表示弓箭手和囚犯是否醒着。如果根据这两个角色的状态可以给囚犯发信号，这个函数返回 `True`。否则，返回 `False`：

```elm
archerIsAwake = False
prisonerIsAwake = True

canSignalPrisoner archerIsAwake prisonerIsAwake
    --> True
```

## 4. 检查是否可以解救囚犯

实现 `canFreePrisoner` 函数，它接受四个布尔值。前三个形参分别表示骑士、弓箭手和囚犯是否醒着，最后一个形参表示 Annalyn 的宠物狗是否在场。如果根据这三个角色的状态以及 Annalyn 的宠物狗是否在场可以解救囚犯，这个函数返回 `True`。否则，它返回 `False`：

```elm
knightIsAwake = False
archerIsAwake = True
prisonerIsAwake = False
petDogIsPresent = False

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
    --> False
```

## 5. 计算潜行攻击可以造成的伤害

实现 `stealthAttackDamage` 函数，它接受一个布尔值，表示 Annalyn 是否被发现。如果她被发现，这个函数返回 7，否则返回 12。

```elm
annalynIsDetected = True

stealthAttackDamage annalynIsDetected
    --> 7
```
