# 简介

## 比较运算符

R 有一套与其他许多语言相同的运算符：

```R
1 == 2 # FALSE
1 != 2 # TRUE
1 < 2 # TRUE
1 > 2 # FALSE
1 <= 2 # TRUE
1 >= 2 # FALSE
```

## 分支

if-else 的基本形式是：

```R
if (x > 10) {
    y <- "big"
} else if (x > 2) {
    y <- "medium"
} else {
    y <- "tiny"
}
```

在这种情况下，布尔值两侧的圆括号`()`和代码块两侧的花括号`{}`都是必需的。

简单的`if`语句可以简写为：

```R
if (x == 0) return("success")
```
