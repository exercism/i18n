# 关于

## 相等性

Elm 中的类型可以用相等运算符 `(==)`来检查是否“相同”。
不等运算符是 `(/=)`（*不是*许多语言里的 `!=`）。

```elm
1 == 2
    --> False

1 /= 2
    --> True
```

参与比较的两个值必须是同一类型。
相等运算符可用于字面量、元组、记录和自定义类型。
该运算符检查的是结构相等性，也就是说，相等的值具有相同的内容和深层结构，与类型标注或内存中的位置无关。

```elm
(1, 2) == (2, 1)
    --> False

type alias MyRecord = { myInt : Int, myStrings : List String }
a : MyRecord
a = MyRecord (1 + 1) ["hello world"]

type alias MyOtherRecord = { myInt : Int, myStrings : List String }
myStrings =  (String.join " " ["hello", "world"]) :: []
b : MyOtherRecord
b = { myInt = 2, myStrings = myStrings}

a == b
    --> True
```

注意，你*绝不要*比较函数，因为那会让程序在运行时崩溃。
关于这一限制的更多信息，见[这里][equality-operator]。

## 比较

比较运算符 `(<)`、`(<=)`、`(>)`、`(>=)`以及函数 `min`、`max`、`compare`都作用于 `comparable`类型。
`comparable`类型是一种特殊类型，它把所有可以比较的内置类型归为一组：数字、字符、字符串、由可比较元素组成的数组，以及由可比较元素组成的元组。
字符按其[Unicode 码点][unicode-codepoint]进行比较。

```elm
1 < 1 + 1
    --> True

'x' < 'X'
    --> False

'互' < '🙏'
    --> True
```

序列类类型（字符串、数组和元组）按[字典序][lexicographic-order]进行比较。
简单来说，序列中的元素会按顺序两两比较，直到找到较小的元素，或者其中一个序列结束。

```elm
"abc" < "abz"
    --> True

"abc" < "abcd"
    --> True

"abc" < "b"
    --> True

min [1 , 2, 9000] [10]
    --> [1 , 2, 9000]

min (1, "hello") (3, "bye")
    --> (1, "hello")

min (1, ['a', 'b']) (1, ['A', 'B'])
    --> (1, ['A', 'B'])
```

记录或自定义类型等其他类型的值不能直接比较。

有些内置类型要求其内容必须是 `comparable`，比如 `Set`或`Dict`的键，因为它们的结构依赖内部排序。
这意味着自定义类型不能存入 `Set`，不过社区提供了替代方案：[`AnySet`][any-set]、[`AnyDict`][any-dict]、[`Sort`][sort] 等等。

`comparable`值的数组可以用 `List.sort`排序，而可以映射为可比较值的数组可以用 `List.sortBy`排序。
如果你需要多级排序（先按一个属性排序，再用另一个属性打破并列），可以把元组或数组配合 `List.sortBy`使用（还有其他[替代方案][sort-by]），因为元组和数组都是按字典序排序的。


```elm
List.sort ["hi", "hello", "bye", "goodbye"]
    --> ["bye", "goodbye", "hello", "hi"]

List.sortBy String.length ["hi", "hello", "bye", "goodbye"]
    --> ["hi", "bye", "hello", "goodbye"]

-- sort by length, then alphabetically
List.sortBy (\str -> (String.length str, str)) ["hi", "mum", "hello", "sis", "bye", "dad"]
    --> ["hi", "bye", "dad", "mum", "sis", "hello"]
```

函数 `compare`接受两个 `comparable`值，返回一个 `Order`。
`Order`是一种类型，它能在一次操作中判断一个值比另一个值大（`GT`）、相等（`EQ`）还是小（`LT`）。

```elm
compare 1 2
    --> LT

compare "" ""
    --> EQ

compare [12] []
    --> GT
```

也可以为任意类型构造比较函数，例如用来配合 `List.sortWith`排序：

```elm
type Color = Red | Green | Blue

compareColors : Color -> Color -> Order
compareColors a b =
  case (a, b) of
    (Red, Red) -> EQ
    (Red, _) -> LT
    (_, Red) -> GT
    (Green, Green) -> EQ
    (Green, _) -> LT
    (_, Green) -> GT
    (Blue, Blue) -> EQ

List.sortWith compareColors [Blue, Red, Green, Green, Blue]
    --> [Red, Green, Green, Blue, Blue]
```
