# 介绍

## 不透明类型

Gleam 中的不透明类型是一种自定义类型，只有定义该类型的模块才能构造或模式匹配该类型的值。这有助于创建只能以特定方式使用的类型。

不透明类型使用`opaque`关键字定义。

```gleam
pub opaque type PositiveInt {
  PositiveInt(inner: Int)
}
```

这个`PositiveInt`类型适用于需要整数、但该整数必须大于等于零的场合。普通的 Gleam`Int`不能这样用，因为它们也可以是负数。

定义该类型的模块可以定义一个函数来获取内部的 int 值，以及一个用于创建`PositiveInt`类型的函数，如果值不是正数，该函数会返回一个错误。

```gleam
pub fn from_int(i: Int) -> Result(PositiveInt, String) {
  case i {
    _ if i < 0 -> Error("Value must be positive")
    _ -> Ok(PositiveInt(i))
  }
}

pub fn to_int(i: PositiveInt) -> Int {
  i.inner
}
```

有了这个 API，其他模块无法用负值构造`PositiveInt`，因此任何接受`PositiveInt`的函数都可以确定该值是正数。
