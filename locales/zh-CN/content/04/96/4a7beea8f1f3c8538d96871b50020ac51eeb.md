# 未使用默认实参

在这个提交的解答里，函数定义中没有使用[默认实参][default argument]。
[Python 中的默认实参][default arguments in python]有助于防范以下情况：调用函数时没有提供预期的实参，或者没有实参可传。
`Default arguments`还可以帮助避免函数内部出现不必要的条件代码或检查。

这个提交的解答可以这样改进：把`default argument`与 [str.format][str.format] 或 [f-strings][f-strings] 结合使用（_又称“格式化字符串字面量”或“插值字符串”_）。

Real Python 的 [String Formatting in Python][string formatting in python] 是了解 Python 字符串格式化选项的一个不错的起点。
