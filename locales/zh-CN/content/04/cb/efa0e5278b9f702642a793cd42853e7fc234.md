# 说明补充

## 自定义异常并抛出异常

有时，你需要在代码中同时[自定义](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions)和[`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)异常。这样做时，一定要附上一句**有意义的错误信息**，说明错误的来源是什么。这会让你的代码更易读，对调试也有很大帮助。

自定义异常可以通过创建新的异常类来实现（详见[`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes)），这些异常类通常是[`Exception`](https://docs.python.org/3/library/exceptions.html#Exception)的子类。

如果你知道错误的来源会是某种异常类型的派生类，可以选择继承 _Exception_ 类下的某个[`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes)。抛出错误时，仍然要附上一条有意义的信息。

这个练习要求你创建两个_自定义异常_。一个用于在循环缓冲区**满**时[抛出](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)（也就是“thrown”），另一个用于缓冲区**空**时。只有当你自定义了合适的异常、`raise`这些异常，并附上合适的错误信息时，测试才会通过。

要自定义`built-in exception`，请创建一个继承该异常的`class`。抛出带信息的自定义异常时，把这条信息作为参数传给`exception`类型：

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
