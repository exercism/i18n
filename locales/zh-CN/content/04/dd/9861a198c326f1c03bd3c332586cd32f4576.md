# 数字

`INT`用来存放整数。在这个 Sather 里，它恰好占 32 位，所以取值范围是从 -2147483648 到 2147483647。

```sather
   goals : INT is
      return 42;
   end;
```

## 形参

例程在括号里接收形参，每个形参都带一个类型：

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

类型相同的形参可以合并到同一个声明里，这也是常见的写法：

```sather
   total(first, second : INT) : INT is
```

## 算术

| 运算符 | 含义 |
| --- | --- |
| `+` | 相加 |
| `-` | 相减，以及取负 |
| `*` | 相乘 |
| `/` | 相除，舍去余数 |
| `%` | 该除法得到的余数 |

两个`INT`之间的`/`永远不会产生小数：

```sather
7 / 2      -- 3
7 % 2      -- 1
```

如果你想要小数，就需要`FLTD`，它稍后才会讲到。

乘除的优先级高于加减，和普通算术一样。需要别的运算顺序时，可以用括号分组：

```sather
2 + 3 * 4        -- 14
(2 + 3) * 4      -- 20
```

## INT 上常用的例程

```sather
7.max(3)     -- 7
7.min(3)     -- 3
(-7).abs     -- 7
7.str        -- "7", the number written as text
```

等你学过字符串之后，`.str`就是让数字成为句子一部分的办法。
