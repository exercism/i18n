# 数据库员工入职

## 问题陈述

ABC 公司计划把所有支付给员工的备用金信息保存在数据库中。你正在帮助 ABC 公司的财务部门实现这个功能。由于 ABC 公司业务不断扩张，因新员工入职而需要向系统中添加新员工是常有的事。

你的任务是：把提供的新员工信息添加到数据库的 `Employee` 表中，并返回自动生成的 `employee_id` 列的值，不要再向数据库发起一次查询去查找它。如果执行过程中发生错误，应返回 `-1`。

## 数据库详情

本题使用提供的 H2 数据库。

> 示例数据库文件是 `gofigure.mv.db`，数据库名是 `gofigure`。它位于 `db` 文件夹中。

示例 H2 数据库中已经有下面这些表，并带有一些示例数据。各列的名称和数据类型如下。

**表名**：`Employee`

| **列**      | 类型 |
| -----------       | ----------- |
| `employee_id`     | 整数，自动递增主键       |
| `name`            | 字符串        |
| `city`            | 字符串        |
| `department`      | 字符串        |
| `age`             | 整数        |

**表名**：`Payment`

| **列**      | 类型 |
| -----------       | ----------- |
| `payment_id`      | 整数，自动递增主键       |
| `date`            | 日期        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 字符串        |

* 数据库文件是 `gofigure.mv.db`。JDBC URL 使用 `jdbc:h2:file:/path/to/db/file`
* 用户名：`root`
* 密码：`root`

## 约束条件

* 使用 `db` 文件夹中提供的 H2 数据库文件来验证查询和 Ballerina 示例
* 使用 maven 依赖参数的方式，把 H2 数据库驱动作为平台依赖添加到你的 Ballerina.toml 中
* 不要再向数据库发起查询来查找自动生成的 id


## 测试环境

* 你可以用 `bal test` 运行测试，它会针对给定的示例数据库运行测试。

## 示例

### 示例 1

**输入**：dbFilePath: `"./db/gofigure"`, name : `“John Doe”`, city: `“Omaha”`, department : `“Sales”`, age: `24`

**输出**：`4`
