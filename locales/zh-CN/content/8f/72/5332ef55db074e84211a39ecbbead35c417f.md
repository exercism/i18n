## 说明

你的任务是给 Mickey 和 Minerva 生成完美的迷宫，也就是只有一个解、没有孤立区域的迷宫。
你需要了解以下几点：

- 迷宫是矩形，起点和终点各有一个开口。
- 迷宫里有房间和通道，它们以直角相交。
- 程序应接受两个形参：行数和列数。迷宫的大小应在 5 到 100 格之间。
- 如果迷宫宽`x`列、高`y`行，那么它的宽度应为`2x + 1`个字符，高度应为`2y + 1`个字符。
- 如果没有提供种子，就生成一个随机迷宫。如果多次提供同一个种子，每次生成的迷宫都应相同。
- 用[框线][Box-drawing]字符绘制墙壁，并用箭头符号（⇨）表示左侧的入口和右侧的出口。

现在，为这些爱冒险的小老鼠创造完美的迷宫吧！

### 示例

1. 5x5 格的小正方形迷宫（即 11x11 个字符）
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. 6x18 格的矩形迷宫
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
