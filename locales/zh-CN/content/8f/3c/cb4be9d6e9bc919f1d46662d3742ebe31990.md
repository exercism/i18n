# 说明

今天是情人节。你的另一半有几个活动想法，想请你给每个活动打分：`yes`、`no` 或 `maybe`。

活动用包含 2 个元素的数组`{ tag value }`表示，其中`tag`是`board-game`、`chill`、`movie`、`restaurant`或`walk`之一。

| 活动                          | 形式                          |
| ------------------------- | --------------------------- |
| 玩桌游         | `{ board-game f }`          |
| 放松一下                 | `{ chill f }`               |
| 看一部`genre`类型的电影  | `{ movie genre }`           |
| 去一家`cuisine`餐厅吃饭  | `{ restaurant cuisine }`    |
| 步行`km`公里      | `{ walk km }`               |

类型是`crime`、`horror`、`romance`、`thriller`之一。菜系是`korean`或`turkish`。

## 1. 给菜系打分

定义`rate-restaurant`，从栈上取下一个菜系并返回你的评分：

- `korean` → `yes`
- `turkish` → `maybe`

```factor
korean rate-restaurant .   ! => yes
turkish rate-restaurant .  ! => maybe
```

## 2. 给电影类型打分

定义`rate-movie`，接收一个类型并返回：

- `romance` → `yes`
- 其他任何情况 → `no`

```factor
romance rate-movie .   ! => yes
horror rate-movie .    ! => no
```

## 3. 给散步打分

定义`rate-walk`，接收一个公里数并返回：

- 大于`11` → `yes`
- 大于`6`、不超过`11` → `maybe`
- 其他情况 → `no`

```factor
12 rate-walk .   ! => yes
8 rate-walk .    ! => maybe
3 rate-walk .    ! => no
```

## 4. 给活动打分

定义`rate-activity`，从栈上取下一个`{ tag value }`活动并返回你的评分。复用上面的辅助函数：

- `board-game`、`chill` → 总是`no`
- `movie` → 交给`rate-movie`处理
- `restaurant` → 交给`rate-restaurant`处理
- `walk` → 交给`rate-walk`处理

```factor
{ restaurant turkish } rate-activity .   ! => maybe
{ movie horror } rate-activity .         ! => no
{ walk 12 } rate-activity .              ! => yes
{ board-game f } rate-activity .         ! => no
```

## 5. 统计评分

定义`approval-counts`，接收一个活动列表，返回一个包含 3 个元素的数组`{ yes-count maybe-count no-count }`，表示每种评分各有多少个。

```factor
{ { restaurant korean } { restaurant turkish } { walk 3 } { movie romance } }
approval-counts .
! => { 2 1 1 }
```
