# 简介

使用`try..rescue`是捕获错误时非常强大的结构。捕获错误能让函数在必要时返回确定的值。`try..rescue`结构还提供了另外两个我们可以利用的特性：

- `else`块
  - 当`try`块执行成功时，其结果会与这个块进行匹配。
- `after`块
  - 无论`try`块是成功还是抛出异常，只要程序此时仍在运行，`after`块中的代码就总会被执行。
  - `after`块的结果不会返回给调用方作用域。

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
