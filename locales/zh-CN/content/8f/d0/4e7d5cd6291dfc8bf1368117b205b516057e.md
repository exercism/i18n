# 作用域解析运算符

作用域解析运算符（`::`）允许我们引用一个类，以访问它的名称常量、静态属性或静态方法。

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## 在作用域解析运算符中使用`self`和`static`

对象有时可能需要引用自己的作用域。为此，`self`关键字允许类引用自己的作用域。使用`self`关键字可以让类与自己的名称解耦，从而更易于长期维护代码。

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

将`static`关键字与作用域解析运算符一起使用，可以对当前子类的引用进行“后期绑定”。

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## 将`parent`与作用域解析运算符一起使用

`parent`关键字用于引用父类的常量、属性或方法。通常，它在对象实例化时用来调用父类的构造函数：

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## 注意事项

### 常量、属性和方法的可见性

作用域解析运算符仍然遵循由`public`、`private`和`protected`可见性修饰符所设定的规则。
