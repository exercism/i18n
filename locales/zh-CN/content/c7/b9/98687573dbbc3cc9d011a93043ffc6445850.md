# 提示

## 通用

- 你可以使用 [Random 类][random-class] 来生成随机数。
- 阅读文章了解更多：[Random Number Generators in Java 17][random-number-generators]。

## 迷宫生成

你可以用任意算法生成完美迷宫。[递归回溯][recursive-backtracker] 是个不错的选择。
