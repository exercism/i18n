在 Raku 中，代码块随处可见。
它是函数的基础，但也用于`grep`和`map`这类工具，用作`if`、`for`、`while`和`given`语句的块，甚至用作数组下标。

## Routines

[`Subs`][type/Sub]和[`Methods`][type/Method]是 Raku 中[`Routines`][type/Routine]的类型。

例程可以用[`return`][control-return]关键字随时带着返回值退出，这是创建函数时很有用的工具。
如果没有指定`return`，例程的最后一条语句就是它的隐式返回值。

例程可以在代码块之前，在括号里带一个[`Signature`][language/signatures]。

[`Routine`][type/Routine]是[`Block`][type/Block]的子类。

```raku
sub add ($x, $y --> Int) { return $x + $y }
say add(1, 2); # 3
```

方法会在涉及类和对象的另一个概念中介绍。

## Blocks

[`Block`][type/Block]是可复用的代码对象，通常用来创建 lambda。

块的最后一条语句就是它的隐式返回值。

块可以在代码块之前带一个以`->`开头的[`Signature`][language/signatures]。

[`Block`][type/Block]是[`Code`][type/Code]的子类，而[`Code`][type/Code]是 Raku 中所有代码对象的最终基类。

```raku
my $add = -> $x, $y { $x + $y };
say $add(1, 2); # 3
```

## Signatures

一个[`Signature`][language/signatures]由零个或多个[`Parameters`][type/Parameter]组成，之间用逗号分隔。

在签名末尾，可以用[返回类型箭头][signatures-return-type-arrow]`-->`指定返回类型。

签名可以用来指定`Block`会接受的实参。

这个概念会让签名保持简单，只使用标量印记变量作为位置形参，再加上一个返回类型。
这些内容会在其他概念中进一步展开。

## Multi-Dispatch

Raku 允许用`multi`关键字编写多个名字相同但签名不同的例程。
这个特性称为[多重分派][multi-dispatch]。
当按名字调用例程时，运行时环境会确定合适的候选项并调用它。

这会在关于类型的概念中更详细地介绍。

```raku
multi foo () { say 'No arguments given'}

multi foo ($bar) { say "One argument given: $bar" }
```

## WhateverCode

当[`Whatever`][type/Whatever]星号`*`与大多数运算符组合使用时，就会创建[`WhateverCode`][type/WhateverCode]对象。
这样就能用更简单的语法创建块。

```raku
# These will all give code blocks that increment a single argument by 1:
-> $x { $x  + 1 }; # Explicit signature
      { $^x + 1 }; # Signature via placeholder variable
      { $_  + 1 }; # Topic variable
          * + 1;   # WhateverCode
```
