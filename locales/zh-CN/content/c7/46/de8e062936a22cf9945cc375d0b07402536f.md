## 编辑器

### 免费/开源

- [VS Code](https://code.visualstudio.com)

  VS Code 是一款开源代码编辑器。你可以[在这里](https://code.visualstudio.com/docs/languages/typescript)了解如何配置 TypeScript。Microsoft 同时维护着 VS Code 和 TypeScript，因此 VS Code 对这门语言的支持很好，它也因此成为很受欢迎的 TypeScript 编辑器；VS Code 无需任何额外配置就能支持 TypeScript。事实上，VS Code 本身就是用 TypeScript 编写的！

  VS Code 和 TypeScript 的一个常见问题是编辑器版本与项目版本不一致，这可能会让 VS Code 显示一条令人困惑的错误信息。关于如何处理这个错误的说明在[这里](https://code.visualstudio.com/docs/typescript/typescript-compiling#_using-newer-typescript-versions)

### 商业授权

- [Sublime Text](https://www.sublimetext.com)

  Sublime Text 是一款流行的代码编辑器，通过可安装的插件支持大多数语言。它可以免费试用，但会不断提示你购买许可证，目前的价格是 \$70 USD。

- [WebStorm](https://www.jetbrains.com/webstorm/)

  WebStorm 是一款功能齐全的 JavaScript/TypeScript IDE（集成开发环境）。它无需额外配置就能支持 TypeScript，并集成了测试、调试和代码分析功能。它可以免费试用 30 天，之后的年度许可证第一年的费用是 \$129 USD。
