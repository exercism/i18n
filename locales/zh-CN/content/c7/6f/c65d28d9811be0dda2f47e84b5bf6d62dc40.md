# 简介

[concept:csharp/resource-cleanup]() 使用`IDispose`接口来表明，当对象不再需要时，它的资源或其他程序状态需要被释放或重置（依赖垃圾回收器既做不到这一点，也提供不了所需的控制程度），而`IDisposable.Dispose()`方法正是进行这类清理操作的自然位置。

还有另一种结构，即`using`块，它能让调用方把所有资源生命周期的管理都收拢到一条语句中。

```csharp
using (var file = new File("my_secrets"))
{
    file.WriteSecret("xxxxxxx");
}
```

在上面的示例中，当退出`using`块时，与`file`关联的文件系统资源会被释放回操作系统。

要让这个模式生效，using 语句中的变量必须是实现了`IDisposable`接口的引用类型，并且必须在自己的`Dispose()`方法中释放资源、重置程序状态。

C# 8 对这个模式做了进一步的改进。using 语句可以放在块的开头。

```csharp
using var drawingResource = some_provided_or_new_object;
try
{
    drawingResource.DrawSomething();
}
catch (Exception)
{
    throw;
}
```

Java 开发者可能会认出，这相当于 Java 7 引入的 _自动资源管理_ 机制。
