# 说明附录

对于 Python 学习路径，本练习要求你创建一个 `SpaceAge`_类_（_[concept:python/classes]()_），其中包含太阳系所有行星的方法。

方法应遵循`on_<planet name>`这一命名约定。

每个方法都应`return`年龄（_在该行星上_），以年为单位，保留两位小数：

```python
#creating an instance with one billion seconds, and calling .on_earth().
>>> SpaceAge(1000000000).on_earth()

#This is one billion seconds on Earth in years
31.69
```
