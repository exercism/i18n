# 关于

在 Elm 这样的纯函数式语言中，用相同的实参调用同一个函数，必须总是返回相同的值。
因此，类型签名为`rand : Int`的函数只能用(`rand = 4`)[xkcd-random]这种方式实现，而这对生成随机整数来说可不是什么好兆头。

那么，在 Elm 中怎样才能生成随机值呢？
我们把问题拆成两步：先用`Random.Generator a`描述想要生成的值，再把值生成出来。

生成值的第一种方式，是通过`initialSeed : Int -> Seed`创建一个`Random.Seed`。
`Seed`是一种不透明类型，内部包含一个整数，并且知道如何以看似随机的方式（也就是伪随机）来变换这个整数。
有了`Seed`之后，就可以用它配合`Generator a`来生成一个值。
`Generator a`也是一种不透明类型，它知道如何利用种子里的整数，生成一个类型为`a`的伪随机值，以及一个带有新整数的新种子。

要生成值，可以使用`step : Generator a -> Seed -> ( a, Seed )`，它返回一个值和一个新种子，我们可以用这个新种子继续生成更多的值。

下面就用这些函数，从一个生成器里取出`n`个随机值：

```elm
generate : Int -> Generator a -> List a
generate n generator = generateValuesFromSeed n generator (Random.initialSeed 42)

generateValuesFromSeed : Int -> Generator a -> Seed -> List a
generateValuesFromSeed n generator seed =
    if n <= 0 then
        []
    else
        let ( value, nextSeed ) = Random.step generator seed
        in value :: generateValuesFromSeed (n - 1) generator nextSeed
```

注意，这些函数都是纯函数，所以用相同的实参调用两次，得到的结果也完全相同。

```elm
generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]

generate 10 (Random.int 1 6)
    --> [4, 5, 3, 3, 5, 1, 2, 4, 6, 6]
```

生成值的第二种方式是使用`Random.generate : (a -> msg) -> Generator a -> Cmd msg`，但这只能在 Elm 应用内部进行。
这种情况下，Elm 运行时除了`step`之外，还可能借助外部的、非纯的资源来生成种子，因此同一个函数调用两次会得到不同的结果。

从现在起，我们只关注生成器。

`Random`模块提供了两个基础生成器，用来在指定范围内生成整数和浮点数：

```elm
generate 5 (Random.int -5 5)
    --> [0, 3, -5, 5, 0]

generate 3 (Random.float 0 5)
    --> [1.61803, 3.14159, 2.71828]
```

这些值可以组合成元组，也可以组合成值的数组：

```elm
generate 2 (Random.list 3 (Random.int 0 3))
    --> [[0, 3, 3], [1, 3, 2]]

generate 2 (Random.pair (Random.int 0 3) (Random.float 10 10.3))
    --> [(0, 10.23412), (2, 10.17094)]
```

(`elm-community/random-extra`)[random-extra]这个包提供了更多针对各种数据结构的生成器：字符串、日期、字典、数组、集合等等。

用`Random.constant`可以创建始终只返回同一个值的生成器：

```elm
generate 4 (Random.constant "hello")
    --> ["hello", "hello", "hello", "hello"]
```

用`Random.uniform`可以从给定的元素中等概率地随机挑选：

```elm
generate 5 (Random.uniform Red [Green, Blue])
    --> [Red, Blue, Blue, Green, Red]
```

`Random.uniform`接受两个实参（`Red`和`[Green, Blue]`），以保证至少有一个值可供挑选，因为单独一个数组有可能是空的。

用`Random.weighted`还能调整各个值被选中的概率：

```elm
generate 5 (Random.weighted (80, Red) [(15, Green), (5, Blue)])
    --> [Red, Red, Green, Red, Red]
```

这些数值不需要加起来等于 100，它们无论如何都会被重新归一化。

用`Random.map`可以访问生成器内部的值：

```elm
generate 3 (Random.int 1 6 |> Random.map (\n -> n * 10))
    --> [30, 60, 10]
```

还可以使用从`Random.map2`一直到`Random.map5`的一系列函数，把更多的生成器组合起来：

```elm
position =
    Random.map3
      (\x y z -> Position x y z)
      (Random.float -100 100)
      (Random.float -100 100)
      (Random.float -100 100)

generate 1 position
    --> [Position 33.788 -98.321 10.0845]
```

对于更复杂的用法，还有`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，它可以用一个生成器产生的值来创建另一个生成器：

```elm
bool = Random.uniform True [False]

failHalfOfTheTime : Generator a -> Generator (Maybe a)
failHalfOfTheTime generator =
    bool
        |> Random.andThen
            (\boolResult ->
                if boolResult then
                    Random.map Just generator

                else
                    Random.constant Nothing
            )

generate 6 (Random.int 0 1 |> failHalfOfTheTime)
    --> [Nothing, Just 1, Just 0, Nothing, Just 1, Nothing]
```

有时我们会想让一个生成器递归地定义自己。
这种情况下，可能需要用`Random.lazy`来防止编译器无限地展开这个生成器。

```elm
type Peano
    = Zero
    | Next Peano


peano : Generator Peano
peano =
    Random.uniform (Random.constant Zero)
        [ Random.map Next (Random.lazy (\_ -> peano))
        ]
        |> Random.andThen identity

generate 12 peano
    --> [Zero, Next(Next(Zero)), Zero, Next(Zero), Zero, Zero, Next(Zero), Zero, Zero, Next(Zero), Next(Next(Next(Zero)))]
```

这个例子有点复杂，我们把它拆开来看。

`Peano`是一种表示正整数的类型：`Zero`是 0，`Next(Zero)`是 1，`Next(Next(Zero))`是 2，依此类推。
我们定义了`peano`，用来生成一个随机的`Peano`数。

首先要注意，`Random.lazy`并没有给逻辑增加任何东西，它只是防止编译器把`peano`无限地写进`peano`里。

我们用`Random.uniform`在零（50% 的概率）和另一个`Peano`数加一（50% 的概率）之间做出选择。
不过，和前面的例子不同，这里的`Random.uniform`不是从值（比如`Zero`）中挑选，而是从生成器（比如`Random.constant Zero`）中挑选，因为我们想用的是`peano`本身。
这意味着`Random.uniform`返回的值的类型是`Generator (Generator Peano)`，而这并不是我们需要的。

为了把这个生成器“展平”，我们把它通过管道传给`Random.andThen : (a -> Generator b) -> Generator a -> Generator b`，其中我们希望`b`是`Peano`。
既然`Generator a`就是`Generator (Generator Peano)`，那么`a`必定是`Generator Peano`，而函数`(a -> Generator b)`的类型必定是`(Generator Peano -> Generator Peano)`。
我们不想做任何修改，所以`identity`正是合适的选择。

最后，`peano`会生成什么样的数呢？
我们知道，它有 50% 的概率生成 0，有 50% 的概率生成自身又一次迭代的结果再加一。
也就是说，生成的数会是 0（50% 的概率）、1（25% 的概率）、2（12% 的概率）、3（6% 的概率）等等。
`peano`可以生成任意大的数，但概率会呈指数级下降。
