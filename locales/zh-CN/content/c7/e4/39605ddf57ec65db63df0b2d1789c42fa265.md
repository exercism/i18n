# 说明

你将要写一些代码，帮你照着最喜欢的菜谱做一份千层面。

一共有五个任务，都和你烹饪这道菜有关。

## 1. 定义烤箱的预期时间（分钟）

设置 `$EXPECTED-MINUTES-IN-OVEN` 常量，表示千层面应该在烤箱里烤多少分钟。根据菜谱，烤箱的预期时间（分钟）是 40：

```raku
$EXPECTED-MINUTES-IN-OVEN
# => 40
```

## 2. 计算烤箱的剩余时间（分钟）

修改 `remaining-minutes-in-oven` 子程序，它接受千层面已经在烤箱里烤过的实际分钟数作为实参，返回千层面还需要在烤箱里待多少分钟，这要根据上一个任务中烤箱的预期时间（分钟）来计算。

```raku
remaining-minutes-in-oven(30)
# => 10
```

## 3. 计算准备时间（分钟）

修改 `preparation-time-in-minutes` 子程序，它接受你往千层面里加的层数作为实参，返回你准备千层面花了多少分钟，假设准备每一层需要 2 分钟。

```raku
preparation-time-in-minutes(2)
# => 4
```

## 4. 计算总工作时间（分钟）

修改 `total-time-in-minutes` 子程序，它接受两个实参：第一个实参是你往千层面里加的层数，第二个实参是千层面已经在烤箱里烤过的分钟数。
这个子程序应该返回你烹饪千层面总共花了多少分钟，也就是准备时间（分钟）与此刻千层面已经在烤箱里待的分钟数之和。

```raku
total-time-in-minutes(3, 20)
# => 26
```

## 5. 创建一条千层面烤好的通知

修改 `oven-alarm` 子程序，它不接受任何实参，返回一条消息，表示千层面已经可以吃了。

```raku
oven-alarm()
# => 'Ding!'
```
