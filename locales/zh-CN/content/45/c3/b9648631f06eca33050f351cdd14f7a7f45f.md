# 说明

给定两个数组，判断第一个数组是否包含在第二个数组中、第二个数组是否包含在第一个数组中、两个数组是否互相包含，或者以上情况都不成立。

具体来说，如果从 B 的前面去掉 0 个或多个元素，再从 B 的后面去掉 0 个或多个元素，得到的数组与 A 完全相等，那么数组 A 就是数组 B 的子数组。

示例：

 * A = [1, 2, 3]，B = [1, 2, 3, 4, 5]，A 是 B 的子数组
 * A = [3, 4, 5]，B = [1, 2, 3, 4, 5]，A 是 B 的子数组
 * A = [3, 4]，B = [1, 2, 3, 4, 5]，A 是 B 的子数组
 * A = [1, 2, 3]，B = [1, 2, 3]，A 等于 B
 * A = [1, 2, 3, 4, 5]，B = [2, 3, 4]，A 是 B 的超数组
 * A = [1, 2, 4]，B = [1, 2, 3, 4, 5]，A 既不是 B 的超数组，也不是 B 的子数组，也不等于 B
