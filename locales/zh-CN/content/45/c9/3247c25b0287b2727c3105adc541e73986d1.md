# 简介

## 包

在 Go 中，应用程序是按包来组织的。
一个包就是位于同一个文件夹中的一组源文件。
同一个文件夹中的所有源文件，都必须在文件顶部声明相同的包名。
按照惯例，包的名称与其所在的文件夹名称相同。

```go
package greeting
```

Go 提供了内容丰富的标准库，你可以用`import`关键字把这些包引入到自己的程序里。
标准库中的包通过它们各自的名称来导入。

```go
package greeting

import "fmt"
```

导入之后，就可以通过包名来使用这个包：

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

一个条目能否被其他包中的代码调用，取决于它在 Go 中的声明方式。
要让函数、类型、变量、常量或结构体字段对外可见（称为_导出_），名称必须以大写字母开头。

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```

## 字符串格式化

Go 内置了一个名为`fmt`的包（格式化包），它提供了各种函数来操作输入和输出的格式。
最常用的函数是`Sprintf`，它使用`%s`这类动词把值插值到字符串中，并返回这个字符串。

```go
import "fmt"

food := "taco"
fmt.Sprintf("Bring me a %s", food)
// Returns: Bring me a taco
```

在 Go 中，浮点数可以方便地用 Sprintf 的动词来格式化：`%g`（紧凑表示）、`%e`（指数）或`%f`（非指数）。
这三个动词都可以控制字段的宽度和精度。

```go
import "fmt"

number := 4.3242
fmt.Sprintf("%.2f", number)
// Returns: 4.32
```

你可以在[格式化包文档][fmt-docs]中找到可用动词的完整列表。

`fmt`还包含其他处理字符串的函数，比如`Println`，它只是把接收到的实参打印到控制台；还有`Printf`，它会先像`Sprintf`那样格式化输入，再打印出来。

[fmt-docs]: https://pkg.go.dev/fmt
