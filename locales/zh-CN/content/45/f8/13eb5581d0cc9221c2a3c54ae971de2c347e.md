# 测试

## 准备工作

按照 [JavaScript 的安装说明][docs-exercism-javascript] 完成环境配置，安装必要的依赖。

## 安装依赖

安装练习所需的依赖：

```shell
corepack pnpm install
```

如果`corepack`提示未启用，可以运行以下命令来启用：

```bash
corepack enable pnpm
```

## 让测试套件通过

所有练习都附带一套测试，帮助你在提交前验证自己的解答。你可以在练习目录下打开命令行，然后运行：

```bash
corepack pnpm test
```

在某些测试套件中，除第一个测试外的所有测试都被跳过了。

当你让一个测试通过后，可以把`xtest`改成`test`来启用下一个测试。

## 编写自定义测试

如果你想编写额外的自定义测试，请新建一个`custom.spec.js`文件，并把它连同你的解答一起提交：

```shell
exercism submit numbers.js custom.spec.js
```
