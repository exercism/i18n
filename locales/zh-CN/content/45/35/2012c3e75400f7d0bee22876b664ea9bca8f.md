# 类型声明

PHP 是一门_动态类型_语言，这意味着变量可以包含任意类型的信息。
PHP 确实允许对类属性、函数实参和函数返回值进行_可选的_强类型声明。
PHP 中的强类型声明会在运行时提供类型断言，不过，如果可能，PHP 会尝试强制转换标量类型以匹配声明。
可以使用文件顶部的`strict_types`声明来禁用这种强制转换行为。

```php
<?php
declare(strict_types=1);
```

此外，函数的返回类型可以是`void`，表示该函数不返回任何值。

```php
<?php
declare(strict_types=1);

class Driver
{
    string $serial_number;

    function setSerialNumber(string $number): void
    {
        $this->serial_number = $number;
    }

    function getSerialNumber(): string
    {
        return $this->serial_number; 
    }
}

$driver = new Driver(); 
$driver->setSerialNumber(1234);
// => This will throw a TypeError with strict_types=1
```

## 类型联合

如果函数实参、返回值或类属性可以是多种类型，就可以声明一个类型联合。

```php
<?php

class IdentityCard
{
    private int|float $id = 0;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

## 混合类型

在编写代码时，我们可能无法指定类型。
从 PHP 8.0 开始，提供了一种名为`mixed`的应急类型。
`mixed`等价于`object|resource|array|string|float|int|bool|null`的类型联合。
