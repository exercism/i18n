# 测试

Factor 练习路径使用**Factor 0.101**。每个练习都自带一个`exercism-tools`词库，其中定义了`STOP-HERE`和`TASK:`等解析词，以及一个测试运行器。在练习所在目录下运行：

```
factor -roots=. -run=exercism-tools <exercise>
```

例如，对于`hello-world`练习：

```
factor -roots=. -run=exercism-tools hello-world
```

所有测试通过时，运行器会以状态 0 退出；只要有测试失败，就会以非零状态退出，并输出诊断信息。

## 跳过的测试

解出一道练习，意味着让它所有的测试都通过。默认情况下，运行测试时只会执行一个测试（第一个）。这是有意为之，好让你能专注地把这一个测试做通过。

这套机制靠的是测试文件里的`STOP-HERE`行：解析时，它会告诉 Factor 忽略这一行下面的所有内容，所以运行器只能看到它上面的测试。第一个测试通过后，你可以用两种方式启用更多测试：

- **删掉`STOP-HERE`这一行**，一次性启用剩下的所有测试。
- **把`STOP-HERE`往下移**，一次启用一个测试，或者一次启用一个任务。概念练习会把测试分组放在`TASK:`标记之下，把`STOP-HERE`移到下一个`TASK:`之前，是很自然的一步。

当所有测试都启用，而且你的实现能让它们全部通过时，你就成功解出这道练习了！
