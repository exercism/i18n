# 关于

在 Elixir 中，要从可枚举的数据结构（如数组、范围）中随机选取一个元素，可以使用 [`Enum.random/1`][enum-random]。这个函数会选取单个元素，每个元素被选中的概率都相同。从范围中选取单个随机值是在常数时间内执行的，无需遍历整个范围。

## 随机整数和字母

- 选取随机整数
  ```elixir
  Enum.random(1..10)
  # => 7
  ```
- 以字符串形式选取随机字母
  ```elixir
  <<Enum.random(?A..?Z)>>
  # => "K"
  ```
- 以字符列表形式选取随机字母
  ```elixir
  [Enum.random(?A..?Z)]
  # => ~c"J"
  ```

如果要从可枚举的数据结构中选取多个元素，可以使用 [`Enum.take_random/2`][enum-take-random]。如果要按随机顺序排列可枚举的数据结构，可以使用 [`Enum.shuffle/1`][enum-shuffle]。

## 随机浮点数

Elixir 自身没有用于选取随机浮点数的函数。要做到这一点，我们必须使用 Erlang 的 [`rand`][erl-rand] 模块，`Enum.random` 底层用的也正是它。

- 选取随机浮点数（大于或等于 0.0 且小于 1.0）：

  ```elixir
  :rand.uniform()
  # => 0.275329955448815
  ```

- 选取随机浮点数（大于或等于`a`且小于`b`）：
  ```elixir
  a = 13
  b = 20
  :rand.uniform() * (b - a) + a
  # => 18.96815556890448
  ```

## 正态分布

上面提到的所有函数在选取随机值时，每个可能的值被选中的概率都相同。这称为_均匀分布_。`rand`模块还提供了 [`normal/0`][erl-rand-normal-0] 和 [`normal/2`][erl-rand-normal-2] 函数，它们会按[正态分布][normal-distribution]选取随机浮点数。

## 随机种子

重要的是要理解，这些“随机”值是由[伪随机数生成器][prng]生成的。PRNG 是一种算法：给定一个称为_种子_的初始值，它就会生成一串看起来随机、实际却完全不随机的数字。

调试时，了解这一点可能很有用。通过用 [`:rand.seed/2`][rand-seed-2] 重置种子，你可以强制 Erlang（以及 Elixir）的伪随机数生成器产生相同的序列值。第一个参数是具体的 PRNG 算法，第二个是一个由 3 个整数组成的元组，也就是种子。

```elixir
:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]

:rand.seed(:exsss, {1, 2, 3})
Enum.take_random(100..999, 3)
# => [680, 127, 622]
```

## 密码学

`Enum.random` 和 Erlang 的 `rand` 模块返回的随机值并不是[密码学安全的][cryptographically-secure-rng]。不要用它们生成密钥、密码或随机数。对于这种用途，可以使用 Erlang 的 [`:crypto.strong_rand_bytes/1`][erl-crypto-strong-rand-bytes]。
