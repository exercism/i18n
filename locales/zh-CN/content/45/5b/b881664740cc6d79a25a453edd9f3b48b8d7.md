# 说明

在这个练习中，你将处理日志行。

每条日志行都是一个字符串，格式如下：`"[<LEVEL>]: <MESSAGE>"`。

日志级别共有三种：

- `INFO`
- `WARNING`
- `ERROR`

你有三个任务，每个任务都会接收一条日志行，并要求你对它做点什么。

## 1. 从日志行中获取消息

实现`message`函数，返回日志行中的消息：

```clojure
(message "[ERROR]: Invalid operation")
;;=> "Invalid operation"
```

开头和结尾的空白字符都应被移除：

```clojure
(message "[WARNING]:  Disk almost full\r\n")
;;=> "Disk almost full"
```

## 2. 从日志行中获取日志级别

实现`log-level`函数，返回日志行的日志级别，且返回值应为小写：

```clojure
(log-level "[ERROR]: Invalid operation")
;;=> "error"
```

## 3. 重新格式化日志行

实现`reformat`函数，重新格式化日志行：把消息放在前面，日志级别放在后面并用括号括起来：

```clojure
(reformat "[INFO]: Operation completed")
;;=> "Operation completed (info)"
```
