# 简介

在 Go 中，函数是一等值。这意味着，你可以对函数做和其他值一样的事情：把函数赋值给变量、把函数作为实参传给其他函数，甚至从其他函数中返回函数。

下面我们创建两个函数：`engGreeting`和`espGreeting`，并把它们赋值给变量`greeting`：

```go
import "fmt"

func engGreeting(name string) string {
	return fmt.Sprintf("Hello %s, nice to meet you!", name)
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := engGreeting			// greeting is a variable of type func(string) string
fmt.Println(greeting("Alice"))	// Hello Alice, nice to meet you!

greeting = espGreeting
fmt.Println(greeting("Alice")) 	// ¡Hola Alice, mucho gusto!
```

函数值让我们不仅能用数据参数化函数，还能用行为参数化函数。在下面的例子中，我们通过`greetingFunc`形参把行为传给`dialog`函数：

```go
func dialog(name string, greetingFunc func(string) string) {
	fmt.Println(greetingFunc(name))
	fmt.Println("I'm a dialog bot.")
}

func espGreeting(name string) string {
	return fmt.Sprintf("¡Hola %s, mucho gusto!", name)
}

greeting := espGreeting
dialog("Alice", greeting)
// Output:
// ¡Hola Alice, mucho gusto!
// I'm a dialog bot.
```

函数类型的变量如果没有初始化，它的值就是`nil`。因此，调用值为`nil`的函数会引发 panic。

```go
var dutchGreeting func(string) string
dutchGreeting("Alice") // panic: call of nil function
```

函数值可以和`nil`比较。这有助于避免程序出现不必要的 panic。

```go
var dutchGreeting func(string) string
if dutchGreeting != nil {
	dutchGreeting("Alice") // safe to call dutchGreeting
}
```

## 函数类型

之所以能使用函数值，要归功于 Go 中的函数类型。函数类型表示所有形参类型序列相同、结果类型序列也相同的函数构成的集合。可以在函数类型的基础上声明自定义类型。例如，前面例子中的`dialog`函数可以改写如下：

```go
type greetingFunc func(string) string

func dialog(name string, f greetingFunc) {
	fmt.Println(f(name))
	fmt.Println("I'm a dialog bot.")
}
```

## 匿名函数

由于支持一等函数，我们还能使用另一个强大的工具：匿名函数。匿名函数在使用处定义，`func`关键字后面没有名字。这类函数可以访问外层函数中的变量。

例如：

```go
func fib() func() int {
	var n1, n2 int

	return func() int {
		if n1 == 0 && n2 == 0 {
			n1 = 1
		} else {
			n1, n2 = n2, n1 + n2
		}
		return n2
	}
}

next := fib()
for i := 0; i < N; i++ {
  fmt.Printf("F%d\t= %4d\n", i, next())
}
```

调用`fib`会声明变量`n1`和`n2`，并返回一个匿名函数；这个匿名函数每次被调用时，都会改变这些变量的值。第 N 次调用这个匿名函数，会返回从 0 开始的斐波那契数列中的第 N 个数。这个匿名内部函数可以访问外层函数`fib`的局部变量（`n1`和`n2`）。这是让函数值在多次调用之间保持状态的一种好方法。我们说，这个匿名函数是变量`n1`和`n2`的闭包。[闭包][closure]在编程中被广泛使用，你可能也会看到其他语言支持它们。

[closure]: https://en.wikipedia.org/wiki/Closure_(computer_programming)
