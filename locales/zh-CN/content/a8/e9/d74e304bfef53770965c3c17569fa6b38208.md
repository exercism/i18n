# 简介

Julia 鼓励程序员把尽可能多的代码放进可以被 JIT 编译的函数里，而且按照设计，创建许多小函数本来就是高效的。

这样一来，程序里往往会有很多小而简单的函数，而要完成不那么简单的任务，就需要把它们组合起来。

一种显而易见的做法是嵌套调用函数。下面这个例子非常刻意，但能说明问题。

```julia-repl
julia> first.(titlecase.(reverse.(["my", "test", "strings"])))
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

这种做法的缺点是，嵌套越深，可读性下降得越快。

我们需要一种更简单、也更灵活的做法。

## 函数组合

这是数学家们钟爱的方法，Julia 直接照搬了数学里的写法。

任意数量的函数都可以用`∘`运算符把它们[`composed`][comp]在一起（输入 `\circ` 再按 Tab 键）。得到的结果可以当作一个函数来使用。

```julia-repl
julia> compfunc = first ∘ titlecase ∘ reverse
first ∘ titlecase ∘ reverse
julia> compfunc.(["my", "test", "strings"])
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
# alternative syntax, giving the same result
julia> (first ∘ titlecase ∘ reverse).(["my", "test", "strings"])
```

有几点需要注意：

- 起始函数的出现顺序与嵌套时相同，执行顺序则是从右到左。
- 组合时使用广播并不方便，但在调用组合后的函数时可以广播。

## 管道

另一种做法或许可以看作是_程序员_的思路，而不是_数学家_的。

[`Pipelines`][comp]在 Unix shell 脚本里已经用了很久，近年来又在主流编程语言里流行起来（有人把它的普及归功于 F#）。

基本思路是：从一份数据出发，把它依次经过一串函数，得到最终结果。

管道运算符是`|>`（F# 和较新版本的 R 都是这样），不过 Julia 还有一个广播版本`.|>`。

```julia-repl
julia> ["my", "test", "strings"] .|> reverse .|> titlecase .|> first
3-element Vector{Char}:
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'T': ASCII/Unicode U+0054 (category Lu: Letter, uppercase)
 'S': ASCII/Unicode U+0053 (category Lu: Letter, uppercase)
```

现在执行顺序严格从左到右，每个函数的输出沿着箭头方向流动，成为下一个函数的输入。

## 局限、变通办法与其他选择

用来演示组合和管道的那些函数都只接受_一个_实参，这并非巧合。

有些纯函数式语言会把_第一个_实参送入函数，同时允许再传入其他实参。

相比之下，Julia 在管道里只接受函数_名_（或与之等价的东西），不接受任何额外的实参。

这样设计有重要的技术原因（与 [`currying`][currying] 并非语言设计中的标准部分有关）。_很多_不了解柯里化的人只需接受这一点：这个限制并不是粗心大意造成的疏忽，而且在未来的 Julia 版本里也不太可能改变。

### 变通办法

我们需要只接受单个实参、又能完成所需工作的函数。好在 Julia 里定义新函数很容易。

最简单的方式是使用[`anonymous function`][anonymous-function]。例如，如果有一个输入字符串，想按下划线分割：

```julia-repl
julia> "my_test_strings" |> (s -> split(s, '_'))
3-element Vector{SubString{String}}:
 "my"
 "test"
 "strings"
```

然后就可以像之前一样，把这个数组送入管道传给其他函数。

在这种情况下，把匿名函数用括号括起来是可选的，但一般来说，这是减少歧义的好办法。

同样，我们也可以在程序更早的地方定义一个具名函数，需要时重复使用。
