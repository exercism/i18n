# 简介

`for` 循环是最常用的语句之一，用来重复执行某段逻辑。在 JavaScript 中，它由`for`关键字、包在圆括号里的_头部_，以及包在大括号里、含有循环_体_的代码块组成。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初始化部分通常用来设置一个计数器变量，条件用来判断循环应该继续还是停止，而在每次重复结束时，步进会让计数器自增。头部的各个部分之间用分号分隔。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

定义步进时，常常会像上面的例子那样使用 JavaScript 的自增或自减运算符。这些运算符会就地修改变量。`++`让一个数字加一，`--`让一个数字减一。

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
