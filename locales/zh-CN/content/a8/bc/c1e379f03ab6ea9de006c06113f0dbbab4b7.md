# 不使用 rescue

不要用异常来做流程控制。
试着在不使用 `rescue` 的情况下解出这道练习。

如果你用的标准库函数名字以 `!` 结尾（会抛出错误），就找一个不带 `!` 的等效函数（通常返回 `{:ok, result}` 或 `{:error, message}`）。

注意：如果你提交的解答上出现了这条自动评论，其他自动评论可能并不准确。
请先解决这个问题！

```elixir
# preferred: for example `case`

case Date.new(1999, 13, 1) do
  {:ok, date} -> date
  {:error, _} -> nil
end

# discouraged: rescuing exceptions

try do
  Date.new!(1999, 13, 1)
rescue
  ArgumentError ->
    nil
end
```
