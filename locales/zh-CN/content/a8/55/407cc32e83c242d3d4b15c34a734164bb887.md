# 简介

常量是在编译时确定的值，不能被重新赋值。
使用`const`关键字可以声明单个常量：

```go
const greeting = "hello"
```

多个常量可以放在一个块中声明。
在块内，如果某个常量没有显式指定值，就会重复上一个表达式：

```go
const (
    greeting    = "hello"
    buffSize    = 4096
    chunkSize   // 4096
)
```

常量通常声明在包级别，不过也可以在函数内部声明。

## 有类型常量和无类型常量

声明常量时不指定类型，它就是无类型的。
无类型常量没有固定的类型；它的值决定了它兼容哪些类型。
只要底层的值兼容，编译器就会在每次使用时把它转换成所需的类型：

```go
const numA = 2

math.Sqrt(numA)  // numA is treated as float64 here
var numB int = numA  // numA is treated as int here
```

有类型常量会在声明时就固定类型：

```go
const num int = 2

math.Sqrt(num)  // compile error because a float is expected
```

## 哪些值可以作为常量

常量只能保存布尔值、数字、字符串和 rune。
由于这些值在编译时就已经确定，函数调用的结果不能用作常量。

```go
const s = math.Sqrt(4)  // compile error because the value isn't known at compile time
```

## iota

在常量块内，`iota`表示该常量在块中的位置：

```go
const (
    Sunday    = iota // 0
    Monday           // 1
    Tuesday          // 2
    Wednesday        // 3
)
```

第一个之后的每个常量都会继承同一个表达式，而`iota`每次自增 1。

`iota`也可以用在表达式中。

```go
const (
    _  = iota             // position 0: value discarded
    KB = 1 << (10 * iota) // position 1: 1 << 10 = 1024
    MB                    // position 2: 1 << 20 = 1048576
    GB                    // position 3: 1 << 30 = 1073741824
)
```
