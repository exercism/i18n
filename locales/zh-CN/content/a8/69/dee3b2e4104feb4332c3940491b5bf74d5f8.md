# 简介

behaviour 让我们可以在一个 _behaviour 模块_中定义接口（一组函数和宏），之后由不同的_回调模块_来实现。得益于这个共享的接口，这些回调模块可以互换使用。

~~~~exercism/note
注意“behaviours”用的是英式拼写。
~~~~

## 定义 behaviour

要定义 behaviour，我们需要创建一个新模块，并列出属于目标接口的函数。每个函数都需要用 `@callback` 模块属性来定义。语法与[函数类型规格][concept-typespecs]（`@spec`）完全相同。我们需要指明函数名、参数类型列表，以及所有可能的返回类型。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer
end
```

## 实现 behaviour

要为我们的模块添加一个现有的 behaviour（也就是创建一个回调模块），可以使用 `@behaviour` 模块属性。它的值应该是要添加的 behaviour 模块的名字。

然后，我们需要定义该 behaviour 模块要求的所有函数（回调）。如果要实现别人的 behaviour，比如 Elixir 内置的 `Access` 或 `GenServer` behaviour，可以在 [hexdocs.pm][hexdocs] 上的文档里找到该 behaviour 所有回调的列表。

回调模块并不局限于只实现其 behaviour 所包含的那些函数。一个模块也可以同时实现多个 behaviour。

为了标明某个函数来自哪个 behaviour，我们应该在每个函数前使用模块属性 `@impl`。它的值应该是定义这个回调的 behaviour 模块的名字。

```elixir
defmodule BookCollection do
  @behaviour Countable

  defstruct [:list, :owner]

  @impl Countable
  def count(collection) do
    Enum.count(collection.list)
  end

  def mark_as_read(collection, book) do
    # other function unrelated to the Countable behaviour
  end
end
```

## 回调的默认实现

定义 behaviour 时，可以为某个回调提供默认实现。这个实现应该定义在 `__using__/1` 宏的 quote 表达式里。为了让 behaviour 模块的使用者能够覆盖默认实现，请在函数实现之后调用 `defoverridable/1` 宏。它接受一个关键字列表，以函数名为键，以函数元数为值。

```elixir
defmodule Countable do
  @callback count(collection :: any) :: pos_integer

  defmacro __using__(_) do
    quote do
      @behaviour Countable
      def count(collection), do: Enum.count(collection)
      defoverridable count: 1
    end
  end
end
```

请注意，除非是为了定义默认回调实现，否则不建议在 `__using__/1` 里定义函数；不过你随时可以在另一个模块里定义函数，再在 `__using__/1` 宏里导入它们。
