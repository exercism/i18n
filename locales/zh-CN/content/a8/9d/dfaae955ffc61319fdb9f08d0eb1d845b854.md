# 说明

你正在开发一款备受好评的新游戏 **Wings Quest**。
在游戏中，你是一只四处移动、收集种子的鸟。
玩家拾取所有种子即可获胜。
如果玩家碰到老鹰，就会失去所有种子，并输掉游戏。
这条规则有一个例外：玩家可以拥有一个处于激活状态的强化道具，让自己飞得比其他鸟更高。

你的目标是编写一些将用于这款游戏的规则。

## 1. 定义鸟是否获得奖励分

在游戏中，如果鸟在拥有强化道具时碰到老鹰，就会获得奖励分。

定义函数`bonusPoints(powerUpActive:touchingEagle:)`，它接收两个实参：`powerUpActive`表示鸟是否有处于激活状态的强化道具，`touchingEagle`表示鸟是否正碰到老鹰。
只有当鸟拥有处于激活状态的强化道具且正碰到老鹰时，函数才应返回`true`，否则返回`false`。

```Swift
bonusPoints(powerUpActive: false, touchingEagle: true)
// Returns false
```

## 2. 定义鸟是否得分

在游戏中，玩家拾取种子或强化道具时会得分。

定义函数`score(touchingPowerUp:touchingSeed:)`，它接收两个实参：`touchingPowerUp`表示鸟是否正碰到强化道具，`touchingSeed`表示鸟是否正碰到种子。
如果鸟正碰到强化道具或种子，函数应返回`true`，否则返回`false`。

```Swift
score(touchingPowerUp: true, touchingSeed: true)
// Returns true
```

## 3. 定义鸟是否失败

定义函数`lose(powerUpActive:touchingEagle:)`，它接收两个实参：`powerUpActive`表示鸟是否有处于激活状态的强化道具，`touchingEagle`表示鸟是否正碰到老鹰。
如果角色正碰到老鹰且没有处于激活状态的强化道具，函数应返回`true`，否则返回`false`。

```Swift
lose(powerUpActive: false, touchingEagle: true)
// Returns true
```

## 4. 定义鸟是否获胜

定义函数`win(hasPickedUpAllSeeds:powerUpActive:touchingEagle:)`，它接收以下实参：

- `hasPickedUpAllSeeds`，表示鸟是否已经拾取了所有种子。
- `powerUpActive`，表示鸟是否有处于激活状态的强化道具。
- `touchingEagle`，表示鸟是否正碰到老鹰。

如果鸟已经收集了所有种子，并且根据第 3 部分中定义的实参判断它没有失败，函数应返回`true`，否则返回`false`。

```Swift
win(hasPickedUpAllSeeds: false, powerUpActive: true, touchingEagle: false)
// Returns false
```
