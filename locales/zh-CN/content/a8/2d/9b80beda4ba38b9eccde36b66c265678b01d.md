# 简介

## 接口是一组方法

在最简单的形式中，**接口类型**是一组方法签名。
下面是一个接口定义的例子，其中包含两个方法 `Add` 和 `Value`：

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

像 `increment` 这样的参数名可以从接口定义中省略，但写上它们往往能提高可读性。

Go 中的接口名不包含 `Interface` 或 `I` 这个词。相反，它们通常以 `er` 结尾，比如 `Reader`、`Stringer`。

## 实现接口

任何类型，只要定义了接口中的方法，就自动地、隐式地“实现”了该接口。Go 里没有 `implements` 关键字。

下面这个类型实现了我们前面看到的 `Counter` 接口。

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

对于实现接口而言，方法用的是值接收者还是指针接收者并不重要。（如果你对这两个概念不太确定，可以回头看看[方法概念][concept-methods]。）

> 接口类型的值可以保存任何实现了这些方法的值。((Go Tour: Interfaces)[go-tour-interfaces])

这意味着，凡是需要 `Counter` 接口的地方，现在都可以使用 `Stats`。

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

因为接口是隐式实现的，所以一个类型可以轻松实现多个接口。它只需要把所需的方法全部定义好。

## 空接口

Go 里有一种非常特殊的接口类型，即包含零个方法的**空接口**。空接口写作 `interface{}`。在 Go 1.18 或更高版本中，也可以使用 `any`，它被定义为一个别名。

由于空接口没有任何方法，所以每个类型都隐式地实现了它。这对于定义能够通用地接受任意值的函数很有帮助。这种情况下，函数的形参就使用空接口类型。
