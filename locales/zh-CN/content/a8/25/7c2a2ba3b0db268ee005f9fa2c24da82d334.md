# 说明

在这个练习中，你将编写代码，帮助一位自由职业者与项目经理沟通。
你的任务是提供几个实用工具，用来快速计算日费率和月费率，并且可以选择应用给定的折扣。

我们首先在自由职业者和项目经理之间约定几条规则：

- 日费率是小时费率的 8 倍。
- 一个月有 22 个可计费日。

有时，自由职业者会主动在自己的日费率上提供折扣（例如针对最忠诚的客户或非营利客户）。

折扣用表示百分比的小数来建模，例如 `25.0`（25%）。

~~~~exercism/note
这些是浮点指令的后缀：

| 后缀 | 操作数大小 |
|--------|--------------|
| `ss`   | 32 位       |
| `sd`   | 64 位       |

以下是本概念中提到的一些指令：

| 指令       | 说明                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | 把 b 复制到 a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | 把整数 b 转换为浮点数 a                                |
| roundss/roundsd a, b, c | 根据 c 对浮点数 b 进行舍入，并把结果存入 a             |
| cvtss2si/cvtsd2si a, b  | 把浮点数 b 转换为整数 a                                |
| comiss/comisd a, b      | 在 a 和 b 之间进行比较，如果是`NaN`则抛出异常          |
| ucomiss/ucomisd a, b    | 在 a 和 b 之间进行比较，如果是`NaN`则设置`PF`          |

以下是 `roundss` 和 `roundsd` 中的舍入控制数字：

| 编号 | 模式         |
|:-------|:-------------|
| 0      | 最近         |
| 1      | 向下取整     |
| 2      | 向上取整     |
| 3      | 截断         |
~~~~

## 1. 根据小时费率计算日费率

实现一个名为`daily_rate`的函数，根据作为参数传入的小时费率来计算日费率，该费率为 64 位浮点数。
合约规定一天有 8 个可计费小时。

```c
daily_rate(60)
// => 480.0
```

返回的日费率应该是一个 64 位浮点数。

## 2. 计算折扣后的价格

实现一个`apply_discount`函数，计算折扣后的价格。
它应该接受两个参数：原价和以百分比表示的折扣率，两者都是 64 位浮点数。

```c
apply_discount(150.0, 10.0)
// => 135.0
```

返回值应该始终是 64 位浮点数。

## 3. 根据小时费率和折扣计算月费率

实现一个`monthly_rate`函数，计算折扣后的月费率。
它接受两个参数，小时费率和以百分比表示的折扣，两者都是 64 位浮点数。

```c
monthly_rate(77.0, 10.5)
// => 12130
```

返回的月费率应该向上取整（即取上限），成为最接近的 64 位整数。

## 4. 根据预算、小时费率和折扣计算完整工作日的数量

实现一个`days_in_budget`函数，接受以下参数：

1. 预算，一个 64 位无符号整数。
2. 小时费率，一个 64 位浮点数。
3. 以百分比表示的折扣，一个 64 位浮点数。

这个函数应该返回预算所能覆盖的完整工作天数。

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

返回的天数应该向下取整（即取下限），成为最接近的 32 位整数。
