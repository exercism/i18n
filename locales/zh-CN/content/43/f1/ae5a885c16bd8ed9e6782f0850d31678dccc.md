# 说明

在本练习中，你要实现一种记录你当地街机厅里最热门游戏高分的方式。

你有 7 个函数要实现，它们都和返回以及操作一个高分数据字典有关。

## 1. 定义一个新的高分字典

创建一个函数 `newScoreBoard()`，它不接受任何形参，并返回一个新的高分字典，其中键的类型为`String`，值的类型为`Int`。

## 2. 向高分字典中添加玩家

要把玩家添加到高分字典中，请定义 `addPlayer(_:_:_:)`，这是一个接受 3 个形参的函数：

- 第一个形参是分数字典。
    这个形参应该是输入输出形参。
- 第二个形参是玩家的名字，类型为字符串。
- 第三个形参是分数，类型为整数。
    这个形参是可选的，请把第三个形参实现为默认值为 0 的形参。

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. 从分数字典中移除玩家

要把玩家从高分字典中移除，请定义 `removePlayer(_:_:)`，它接受 2 个形参：

- 第一个形参是分数字典。
    这个形参应该是输入输出形参。
- 第二个形参是玩家的名字，类型为字符串。

如果该玩家在字典中，这个函数应把他从字典中移除，否则什么也不做。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. 重置玩家的分数

要重置玩家的分数，请定义 `resetPlayer(_:_:)`，它接受 2 个形参：

- 第一个形参是分数字典。
    这个形参应该是输入输出形参。
- 第二个形参是玩家的名字，类型为字符串，你想重置的就是这位玩家的分数。

这个函数会把玩家的分数设为 0。
如果玩家不在字典中，则什么也不应发生。

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. 更新玩家的分数

要通过在之前的分数上累加来更新玩家的分数，请定义 `updateScore`，它接受 3 个形参：

- 第一个形参是分数字典。这个形参应该是输入输出形参。
- 第二个形参是玩家的名字，类型为字符串，你想更新的就是这位玩家的分数。
- 第三个形参是你想**加到**已记录的高分上的分数。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. 获取按玩家姓名排序的玩家及其分数数组

定义函数 `orderByPlayers`，它接受 1 个形参：

- 第一个形参是分数字典。

这个函数会返回一个由 `(String, Int)` 元组组成的数组，其中是玩家及其高分，按玩家姓名升序排列。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. 获取按玩家分数降序排列的玩家数组

要获取按分数降序排列的玩家数组，请定义 `orderByScores`，它接受 1 个形参：

- 第一个形参是分数字典。

这个函数会返回一个由 `(String, Int)` 元组组成的数组，其中是玩家及其高分，按玩家分数降序排列。

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
