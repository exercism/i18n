# 字符串

Crystal 有一种叫做[`String`][strings]的类型，用来表示文本。Crystal 的字符串是 Unicode 字符的序列。字符串是不可变的，一旦创建就无法更改。也就是说，每次修改字符串都会创建一个新的字符串，原字符串本身不会被改动。

要定义字符串，使用双引号 `"`。

```crystal
"Hello World"
```

## 拼接

要拼接两个字符串，使用`+`运算符。`+`运算符会返回一个把两个字符串合在一起的新字符串。

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## 字符串与数字之间的转换

`to_i`方法能把字符串转换成整数。也可以用`to_f`方法返回一个浮点数。如果字符串无法转换成数字，就会抛出`ArgumentError`。

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

整数或浮点数可以用`to_s`方法转换成字符串。

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## 插值

插值是一种把字符串拼接起来、并在字符串中嵌入表达式的便捷方式。要进行插值，可以使用`#`字符，后面跟上花括号`{}`，把表达式写进花括号里。

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal 会自动把表达式的结果转换成字符串。

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## 大小

当你想知道一个字符串里有多少个字符时，可以使用`size`方法，它会以整数的形式返回字符串的长度。字符串的大小是字符串自身存储的一个属性，所以每次调用该方法时不必重新计算，速度非常快。

```crystal
"Hello World".size
# => 11
```

## 下标

下标用于从字符串中取出某个特定的字符。要从`String`中取出一个字符，可以使用你熟悉的方括号表示法。

~~~~exercism/note
`[]`是作为`String`的实例方法实现的，其中的下标就是该方法的实参。
~~~~

字符串的第一个字符位于下标 0。

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

要从字符串末尾取字符，可以用字符串的长度减一来得到最后一个字符的下标，要取倒数第二个字符，就用长度减二，依此类推。这有个捷径，就是直接使用负下标：最后一个字符的下标是 -1，倒数第二个字符的下标是 -2，依此类推。

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

## 转义

有些字符不能直接写在字符串里，必须使用转义序列。例如，如果你想在字符串里使用双引号，就得对双引号进行转义。可以用`\`字符写一个转义序列，后面跟上你想转义的字符。

下面是 Crystal 中的特殊字符：

| 值 | 说明 |
| -------- | ----------------------------- |
| `\a`     | 响铃                         |
| `\b`     | 退格                         |
| `\e`     | 转义                         |
| `\f`     | 换页                         |
| `\n`     | 换行                         |
| `\r`     | 回车                         |
| `\t`     | 水平制表符                    |
| `\v`     | 垂直制表符                    |
| `\\`     | 反斜杠                       |
| `\'`     | 单引号                       |
| `\"`     | 双引号                       |
| `\377`   | 八进制 ASCII 字符            |
| `\xFF`   | 十六进制 ASCII 字符          |
| `\uFFFF` | 十六进制 Unicode 字符        |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## 多行字符串

要写多行字符串，语法和单行字符串一样，只是字符串中的每一行都要另起一行。

```crystal
"Hello
World"
# => "Hello\nWorld"
```
