# 安装

## 安装 Godot Engine

GDScript track 基于[Godot Engine][godot-engine]构建，它可以在 Windows、Linux、macOS 和 Android 上运行。
目前，用于[在本地练习][working-locally]的测试运行器需要 Linux。
该 track 需要 Godot 4.0 或更高版本。

完成安装后，你可以在终端中运行以下命令，以验证 CLI 是否安装成功：

```bash
godot --version
```

## 安装 Exercism GDScript track 测试运行器

你需要先正确[安装 Godot][installation]，才能使用测试运行器。

为了在 Exercism 上构建和测试 GDScript 脚本，Godot 将通过 CLI 以“无头”模式运行。
这些说明目前需要 Linux 和 bash。

### 第 1 步：安装测试运行器的整体基础设施

要准备测试环境，请克隆[https://github.com/exercism/gdscript-test-runner][gdscript-test-runner]，并将其内容移动到`/opt/test-runner/`：

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 第 2 步：下载单个练习的测试运行器脚本

假设你已经设置好`exercism`工具，并且至少下载了一个 GDScript 练习，那么它应该已经在你的工作区下创建了一个`gdscript`文件夹（如运行`exercism configure`所示），用于存放这些练习。
将[测试运行器][test-local-gdscript-solution]保存到此文件夹中，并将该文件标记为可执行文件。

## 运行测试

完成安装步骤后，你应该可以从任意练习目录（例如`~/exercism/gdscript/two-fer`）开始，运行该脚本（它位于上一级目录，即`../`）来测试你对该练习的本地解答：

```sh
../test-local-gdscript-solution.sh
```

## 使用集成开发环境

要在[Visual Studio Code][vscode]之类的编辑器中获得 GDScript 语法高亮，你需要安装[godot-tools][godot-tools]这样的扩展，并运行一个调试服务器。
每当在 Godot 自带的编辑器中打开项目时，Godot 都会自动启动这个调试服务器，并让它一直运行，直到项目或 Godot 本身关闭。
