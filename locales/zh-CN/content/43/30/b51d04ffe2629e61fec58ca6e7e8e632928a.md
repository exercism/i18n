# 说明

你附近的一所学校有一个非常活跃的学生会。
学生会由一名主席管理，每隔 2 年就会举行一次选举，选出新一任主席。
在今年的选举中，大家决定需要一个全新的数字化计票系统。

学校需要你的帮助来构建这个新系统。

## 1. 创建投票计数器

新投票系统最先需要的东西之一就是投票计数器。
这个计数器用来记录某位候选人获得的票数。

创建一个`new_vote_counter`函数，它接受某位候选人的初始票数，并返回一个`VoteCounter`结构体的快照，该快照用给定的初始票数初始化。

```rust
let initial_votes: u32 = 2;
let counter: @VoteCounter = new_vote_counter(initial_votes);
// @VoteCounter {
//     value: 2,
// }
```

## 2. 从计数器获取票数

现在你已经能创建新的计数器了！
但你意识到，新系统还需要一种从计数器中获取票数的方式。

创建一个`vote_count`函数，它接受一个计数器（`@VoteCounter`）作为实参，并返回该计数器中的票数。

```rust
let initial_votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);

let count = vote_count(vote_counter);
// => 3
```

## 3. 增加计数器的票数

终于到了计票的时候了！
现在你需要一种增加计数器中票数的方式。

创建一个`increment_vote_count`函数，它接受一个计数器（`@VoteCounter`）和一个票数作为实参，并将计数器增加相应的票数。

```rust
let votes: u32 = 3;
let vote_counter: @VoteCounter = new_vote_counter(initial_votes);
let vote_counter: VoteCounter = increment_vote_count(vote_counter, 2);

let count = vote_count(@vote_counter);
// => 5
```

## 4. 创建选举结果

现在所有票都已统计完毕，是时候准备向全校公布结果了。
为此，你发现只有票数计数器还不够。
需要一种方式把票数和具体的候选人关联起来。

创建一个`new_election_result`函数，它接收候选人的名字和其票数，并返回一个新的选举结果。

```rust
let result: ElectionResult = new_election_result("Peter", 3);
// ElectionResult {
//     name: "Peter",
//     votes: @VoteCounter {
//         value: 3,
//     },
// }
```

选举结果结构体已经为你创建好了，它的定义如下：

```rust
struct ElectionResult {
    name: ByteArray,
    counter: @VoteCounter,
}
```

## 5. 公布结果

是时候向学校公布新主席了！
新主席会显示在学校里那些小小的电子公告板上。

消息应显示新主席的名字和其获得的票数，格式如下：`<candidate_name> (<votes>)`。
下面是一条这样的消息示例：`"Peter (51)"`。

创建一个`display_result`函数，它接收一个`@ElectionResult`作为实参，并返回一个包含待显示消息的`ByteArray`。

```rust
let result = ElectionResult {
    name: "John",
    votes: @VoteCounter {
        value: 32,
    },
};

let msg = display_result(@result);
// => "John (32)"
```

## 6. 重新计票

为了确保最终结果准确无误，大家对选票进行了重新统计。
在重新计票过程中，发现有些候选人的票数差了一票。

创建一个`decrement_votes_of_candidate`函数，它接收最终结果以及某位候选人的名字，并应减少该候选人的票数。
最终结果以`Felt252Dict<u32>`的形式给出，其中键是候选人的名字，值是候选人的总票数。

```rust
let mut final_results: Felt252Dict<u32> = Default::default();
final_results.insert('Mary', 10);
final_results.insert('John', 51);

decrement_votes_of_candidate(ref final_results, 'Mary');

let decremented_votes = final_results.get('Mary');
// => 9
```
