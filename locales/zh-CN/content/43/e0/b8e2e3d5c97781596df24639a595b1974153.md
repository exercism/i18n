# 关于

整数是不带小数点的整数（如`-6`、`0`、`25`、`1234` 等）。

整数类型分为两个子类型：`fixnum`和`bignum`。
* `fixnum` 至少被定义为 16 位的有符号整数，但根据具体实现，它很可能更大。
* `bignum` 是包含任何比`fixnum`更大的整数的类型。

在 Common Lisp 中，整数可以任意大，也可以任意小，所以使用它们时不必担心“溢出”。其他一些语言可能会损失精度或对大数进行回绕，而在 Common Lisp 中，整数的大小只受可用内存量的限制。

```lisp
;; Big integers are no problem
(expt 2 200) ; => 1606938044258990275541962092341162602522202993782792835301376
```
