# 简介

[可变参数][variadic-parameters]允许函数用同一个形参接收零个或多个指定类型的值。
在形参的类型标注后面加上三个点（`...`），就能定义一个可变参数。

在函数体内部，Swift 会把这些值作为指定类型的数组提供：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函数在可变参数后面还有其他形参，那么紧跟在可变参数后面的第一个形参**必须**有明确的实参标签，这样 Swift 才知道可变参数列表在哪里结束。
~~~~
