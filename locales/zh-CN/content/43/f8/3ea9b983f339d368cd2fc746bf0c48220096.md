## AWK 的新概念

参考 [`matrix`练习的说明][ex-matrix]，复习一些有趣的 GNU awk 语言特性。

### 动态函数调用

awk 函数不是一等对象：它们不能像在其他一些语言里那样被传来传去。
不过，变量可以保存函数的_名称_（一个字符串），然后用特殊的 `@varname(args)` 写法来调用该函数。
例如：

```awk
function greet(name) {
    print "Hello, " name
}
BEGIN {
    greet("John")       # => "Hello, John"

    f = "greet"
    f("Bill")           # => error
    @f("Bill")          # => "Hello, Bill"
}
```
这一点在[间接函数调用][indirect]中有说明。
这是 `gawk` 的一个扩展。
