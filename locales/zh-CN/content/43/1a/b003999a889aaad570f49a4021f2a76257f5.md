# 测试

如果你的 PATH 中有 8th 二进制文件，请输入命令：

```bash
8th -f test.8th
```

如果 PATH 中没有 8th 二进制文件，在 Windows 中输入

```cmd
\path\to\8th -f test.8th
```

Linux 或 macOS：

```bash
/path/to/8th -f test.8th
```

## 在 REPL 中测试

启动 8th，加载 test-words.8th：

```sh
8th -f test-words.8th
```

这会启动一个 CLI 会话，等你在解答文件中写好一些代码后，就可以把它加载进 REPL。
例如，对于 “word-count” 练习，你可以输入：

```8th
"word-count.8th" f:include
```

你也可以用下面的命令运行测试
```sh
"word-count-tests.8th" f:include
```

或者，你可以从该文件中复制粘贴单个测试，也可以输入自己的测试。

## 跳过的测试

解答一道练习意味着让它所有的测试都通过。
默认情况下，运行测试时只会执行一个测试（第一个）。
这是有意为之的，这样你可以专注于让这一个测试通过。
一旦它通过，你就可以把 `SKIP-REST-OF-TESTS` 这个词移到它后面，从而启用下一个测试。

## 覆盖跳过设置

要运行所有测试，包括 `SKIP-REST-OF-TESTS` 之后的测试，你可以把环境变量 `RUN_ALL_TESTS` 的值设为 `true`。
一种只在运行测试期间设置它的方法是（macOS 和 Linux）：

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
