# 说明补充

## 寄存器

| Register | Usage        | Type    | Description                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入         | 地址    | 以 null 结尾的名称字符串      |
| `$a1`    | 输入         | 整数    | 数字                          |
| `$a2`    | 输入/输出    | 地址    | 以 null 结尾的结果字符串      |
| `$t0-9`  | 临时         | 任意    | 用于临时存储                  |
