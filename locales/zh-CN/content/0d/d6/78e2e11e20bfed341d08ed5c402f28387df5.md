# 说明

舞台监督想要把排练剧本录入下来，其中几个部分是通过重复或拼接内容来完成的。

四个任务都放在`REHEARSAL_SCRIPT`类中。

## 1. 重复提示

给定一个提示和一个数字，返回将该提示重复那么多次的字符串，中间不加任何内容。

```sather
REHEARSAL_SCRIPT::repeat_cue("Ha", 3)
-- => "HaHaHa"
```

将某个内容重复零次会得到空字符串。

## 2. 演员姓名首字母

给定演员名单，返回每个名字的首字母，并拼接在一起。

```sather
REHEARSAL_SCRIPT::initials(|"Mia", "Ana", "Ben"|)
-- => "MAB"
```

## 3. 给各行编号

给定场景中的各行，从 1 开始给它们编号，每行单独占一行。

```sather
REHEARSAL_SCRIPT::numbered_lines(|"Enter", "Exit"|)
-- => "1. Enter\n2. Exit"
```

各行*之间*有一个换行，最后一行之后没有换行。没有行的场景会得到空字符串。

## 4. 大声喊出一行

返回一行，把其中每个字母都变成大写。

```sather
REHEARSAL_SCRIPT::shout("quiet please")
-- => "QUIET PLEASE"
```
