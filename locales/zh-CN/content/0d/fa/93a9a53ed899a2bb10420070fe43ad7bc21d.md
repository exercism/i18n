# 简介

## 数组

在 C# 中，能够容纳零个或多个元素的数据结构称为_集合_。**数组**是一种集合，它的大小/长度固定，并且所有元素都必须是同一类型。可以使用下标把元素赋给数组，也可以从数组中取出元素。C# 数组的下标从零开始，也就是说第一个元素的下标总是 0：

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

数组也可以用一种简写方式来定义，这种方式既能创建数组，又能同时设置它的值。既然编译器现在能知道数组会有多少个元素，长度就可以省略：

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

可以通过调用数组实例的方法或属性，或者使用`Array`类中定义的静态方法来操作数组。

## `for`循环

`for`循环可以重复执行一段代码，直到满足某个条件为止。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

一个`for`循环由四个部分组成：

1. 初始化：在进入循环之前执行一次。通常用来定义循环中会用到的变量。
2. 条件：在每次循环迭代之前执行。只要它的求值结果为`true`，循环就会继续执行。
3. 迭代：在每次循环迭代之后执行。通常用来修改（常常是自增或自减）循环变量。
4. 循环体：每次循环迭代实际执行的代码。

## `foreach`循环

数组同时也是_集合_，这意味着除了按下标访问值之外，你还可以用`foreach`循环遍历它的_所有_值：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
