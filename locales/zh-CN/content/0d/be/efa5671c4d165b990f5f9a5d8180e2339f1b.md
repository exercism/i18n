# 关于

Elm 中的[自定义类型][custom-types]表示固定数量的具名情况。每个值都恰好对应其中一种具名情况。在其他语言或语境中，这类东西被称为_和类型_、_可辨识联合_、_标签联合_和_代数数据类型_。

可辨识联合的每种情况都可以选择性地携带数据，不同情况可以携带不同类型的数据。如果所有情况都不携带数据，那么这种可辨识联合就类似于其他语言通常所说的_枚举_（或 _enum_）。

自定义类型用`type`关键字定义，需要的语法非常少。它是 Elm 编程中最重要的技术之一，用来让代码中可能出现的值与现实生活中的有效值完全对应，从而不给无效数据留下任何余地，并让[不可能的状态无法在代码中表示出来][impossible-states]。

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

为某种情况创建值时，如果它定义在同一个模块中，或者是通过`import SeasonModule exposing (Season(..))`这种语法导入的，可以直接引用它的名字（`Spring`）；如果是通过`import SeasonModule exposing (Season)`这种语法导入的，则需要引用它的完全限定名（`Season.Spring`）。

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

自定义类型和 Elm 中的其他一切一样，具有_结构相等性_，也就是说，同一个情况、且（可选）数据也相同的两个值是等价的。

处理自定义类型的首选方式是[模式匹配][pattern-matching]：

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
