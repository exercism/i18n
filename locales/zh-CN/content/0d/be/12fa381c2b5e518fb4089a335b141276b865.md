# 简介

函数可以为一个或多个形参声明默认值。来看这个函数：

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

编译后，Elixir 会为`number/0`（不带形参）和`number/1`（带一个形参）各创建一个函数定义。

如果有多个形参带有默认值，默认值会从左到右依次应用到函数上，用来填补缺失的实参。

如果函数有多个子句，默认形参应该定义在函数头（一个没有函数体的函数）里，并且要放在这些子句之前：

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
