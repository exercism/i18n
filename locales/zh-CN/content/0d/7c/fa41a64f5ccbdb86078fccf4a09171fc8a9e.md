# 关于

任何值都可以是错误。`throw`（在`kernel`中）会发出信号；当前词的栈效应被放弃，控制权会回溯到最近的外层`recover`。

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:`是一个解析词，一次就能定义出一个错误元组类*和*一个构造词：

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

这样一来，每个自定义错误都会有唯一的类、一个易用的抛出构造词，以及一个用来检验捕获到的错误的类谓词（`name?`）：

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

如果需要 finally 风格的清理，请参阅`continuations`里的`cleanup`。如果需要可重启的条件，请参阅`condition`。
