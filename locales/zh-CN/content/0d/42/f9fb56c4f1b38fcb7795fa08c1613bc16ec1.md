# 关于

类是 Swift 程序的基本构建块。它们让你可以把相关的属性（数据）和方法（函数）组合成自包含的功能单元。

### 定义类

要定义一个类，使用`class`关键字，后面跟上类名，类定义放在大括号里：

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id = makeRandomID()
}
```

类的主体可以包含存储属性，它们的定义方式和行为都和普通的常量（`let`）或变量（`var`）一样。

### 实例

类的定义相当于一份蓝图：它定义了一个新类型，描述了这种类型的值是什么样的，但它本身不会创建任何实例。

要创建类的*实例*，就调用它的初始化方法，写下类名，后面加上那对括号：

```swift
let someCharacter = GameCharacter()
```

这会创建一个新实例，它的属性会用类定义中指定的默认值初始化。
对于没有明确默认值的可选属性（比如`name`），Swift 会把它们默认为`nil`。

### 访问属性

你可以用*点语法*访问实例的属性：写下实例名、一个点（`.`）和属性名。
点语法同样适用于嵌套属性。

你可以用点语法读取值；如果属性是可变的（`var`），还可以给它赋新值：

```swift
someCharacter.name
// => nil

someCharacter.name = "Luther"
someCharacter.name
// => "Luther"

someCharacter.id = "new id"
// Error: Cannot assign to property: 'id' is a 'let' constant
```

### 方法

除了属性，类还可以定义*方法*，也就是与类相关联的函数。

在类的主体里用标准的`func`语法定义方法。
如果某个方法要修改属性，那么这个属性必须用`var`声明：

```swift
class GameCharacter {
    var characterClass: String?
    var name: String?
    var active = false
    let id: String = makeRandomID()

    func takesDamage(_ damage: Double) {
        if damage > 100 {
            active = false
        }
    }

    func sayName() -> String {
        return "My name is \(name ?? "no one"), my class is \(characterClass ?? "undetermined")"
    }
}
```

在实例上调用方法，和访问属性一样使用点语法：

```swift
var myChar = GameCharacter()
myChar.active = true
myChar.takesDamage(200)
myChar.active
// => false
```

### Self

类的每个实例都有一个名为`self`的隐式属性，它指向实例本身。
在引用属性或方法时，`self`常常可以省略，但当属性名和方法形参名相同时，通常会用`self`来区分二者。
