# 介绍

## 基础

我们假设你已经熟悉 JSON 语法和数据类型。

jq 的工作方式是让传入的 JSON 数据经过一个_单一表达式_（写作_过滤器管道_），从而得到你想要的转换后的数据。

<!-- prettier-ignore -->
~~~~exercism/note
`jq`语言由一个`jq`_程序_实现。这个程序提供了一些便捷的命令行选项，用来控制输入如何被读取，以及输出如何被呈现。

在下面的示例中，你会遇到：

- `-n`或`--null-input`

    通常`jq`程序会拿到一个要读取的文件，或者你把数据发送到它的输入。`--null-input`选项让你可以在没有任何输入的情况下生成 JSON 数据。

- `-c`或`--compact-output`

    默认情况下，`jq`会把输出打印得漂漂亮亮。当数据被整齐地格式化之后，人查看起来会极其方便。但机器并不需要这样：`--compact-output`选项会去掉格式化用的空白，把生成的 JSON 体积降到最小。

- `-f filename`或`--from-file filename`

    从`filename`读取`jq`程序，而不是在命令行里直接给出它。`sed`和`awk`都用`-f`选项来达到同样的目的。你会在练习的测试脚本里看到它的用法。

本课的其余部分将聚焦于`jq`_语言_本身。
~~~~

<!-- prettier-ignore-end -->

### 过滤器与管道

**过滤器**也叫**表达式**。

一个_过滤器_接收输入并产生输出。就像你在 Unix shell 里工作的方式，你可以用管道`|`把多个_过滤器_连接起来，让一个_过滤器_的输出接到另一个_过滤器_的输入上。

### 恒等过滤器：`.`

这是最简单的_过滤器_。它只是把输入原样传给输出。

```sh
$ echo '[1, 2, 3]' | jq '.'
[
  1,
  2,
  3
]
```

### 数组

下面快速介绍一下如何处理**数组**。我们稍后会更详细地讲这个主题。

_数组_的元素用方括号访问，下标从 0 开始。

```sh
$ echo '[10, 20, 30]' | jq '.[1]'
20
```

一个_过滤器_可以把表达式包在`[`和`]`里来构建一个_数组_。

- 用一组已知的元素：

  ```sh
  jq -n '[1, 2, 3]'
  ```

- 收集一串元素：例如，`range`是一个函数，会输出一串数字

  ```sh
  $ jq -n 'range(10; 70; 15)'
  10
  25
  40
  55
  ```

  用`[]`把表达式的结果收集成一个数组

  ```sh
  $ jq -c -n '[range(10; 70; 15)]'
  [10,25,40,55]
  ```

### 逗号是一个运算符

_逗号_不只是分隔_数组_元素的语法。**逗号**是一个**运算符**，用来连接数据流。

例如，`[1, 2, 3]`是一个_过滤器_，它用_数组_构造器`[]`把`1`、`2`和`3`这三个表达式连接后的结果收集起来。

你注意到上面`range(10; 70; 15)`里的分号了吗？因为_逗号_在`jq`语言里有特定的用途，所以接收多个实参的函数用分号来分隔实参。

### 对象

快速介绍一下**对象**。

和许多编程语言类似，用点号来访问_对象_的属性

```sh
$ echo '{"foo": {"bar": "qux"}}' | jq '.foo.bar'
"qux"
```

<!-- prettier-ignore -->
~~~~exercism/note
方括号也可以用于_对象_，但这时字符串字面量需要加上引号。这是处理包含空格的键的一种方法。

```sh
$ echo '{"foo bar": "qux"}' | jq '.["foo bar"]'
"qux"
```
~~~~

<!-- prettier-ignore-end -->

你可以用`{}`和`key: value`键值对来构造一个_对象_。对于“简单”字符串的_键_，不需要加引号。

```sh
jq -n '{question: (6 * 9), answer: 42}'
```

输出

```none
{
  "question": 54,
  "answer": 42
}
```

如果要把_键_当作_表达式_来处理，就必须把它包在圆括号里（下面这段的输出也和上面相同）。

```sh
echo '[{"key":"question", "value":54}, {"key":"answer", "value":42}]' \
| jq '{(.[0].key): .[0].value, (.[1].key): .[1].value}'
```

### 管道

例如，假设`file.json`的内容是

```json
{
  "key1": "value1",
  "key2": [5, 15, 25]
}
```

我们来计算一下 key2 这个_数组_的长度：

```sh
$ jq '.key2 | length' file.json
3
```

我们把`.key2`表达式的输出_通过管道_传给`length`作为输入，它不出所料地输出了_数组_中元素的个数。

### 过滤器可以忽略它的输入

在这个例子里，输入的 JSON 数据被忽略，对输出没有任何影响：

```sh
$ echo '{"answer": 42}' | jq '6 * 9'
54
```

### 过滤器可以输出数据流

一个_过滤器_可以输出多个值。例如，`.[]`这个_过滤器_会把_数组_的每个元素作为一个单独的值输出：

```sh
$ jq -n -c '[1, 2, 3]'
[1,2,3]

$ jq -n -c '[1, 2, 3] | .[]'
1
2
3
```

把这样一个_过滤器_用管道接到另一个_过滤器_上，就会**_对每个值_**执行第二个_过滤器_：

```sh
$ jq -n -c '[1, 2, 3] | .[] | . * 2'
2
4
6
```

这有点像隐式迭代。一旦你理解了这个技巧，就会发现，非常强大的`jq`_过滤器_可以写得非常简洁。

### 圆括号

**圆括号**用来把子表达式组合在一起，以强制运算顺序，就像其他语言里一样。在`jq`里，需要用到它们的地方有时会显得有点出人意料。

例如，假设我们想构造一个含 2 个元素的_数组_：9 的平方根，以及 _e_ 的 1 次幂。这两个单独的表达式是`9 | sqrt`和`1 | exp`。我们期望输出的是_数组_`[3, 2.7...]`

```jq
$ jq -n '[ 9|sqrt, 1|exp ]'
[
  20.085536923187668,
  2.718281828459045
]
```

为什么没有得到我们期望的结果？`jq`是这样解释的：

```jq
[ ((9|sqrt), 1) | exp ]
```

`jq`构建了一个含两个元素（`3`和`1`）的数据流，它们各自被传给了`exp`。

我们需要确保`exp`只接收一个数字作为输入。换句话说，我们要强制管道先于逗号求值。

```jq
$ jq -n '[ 9|sqrt, (1|exp) ]'
[
  3,
  2.718281828459045
]
```

### 函数与运算符

这里不深入展开（函数会是另一个练习的主题），下面是一些有用的内置函数：

- `length`

  给定一个数组作为输入，输出数组中元素的个数。

  ```sh
  $ jq -n '[10, 20, 30, 40] | length'
  4
  ```

- `+`

  这个运算符会根据操作数的类型做不同的事：相加数字，拼接字符串，追加数组，合并对象。

  ```sh
  $ jq -c -n '
      3 + 4,
      "foo" + "bar",
      ["a", "b"] + ["c"],
      {"m": 10} + {"n": 20}
  '
  7
  "foobar"
  ["a","b","c"]
  {"m":10,"n":20}
  ```

  `add`是一个函数，它接收一个数组，按照`+`的规则把所有元素加在一起后返回一个结果。`[1, 2, 3] | add`输出`6`。

- `map`

  给定一个数组作为输入、一个过滤器作为实参，输出一个把该过滤器应用到每个元素上的数组

  ```sh
  $ jq -c -n '[10, 20, 30, 40] | map(. / 5)'
  [2,4,6,8]
  ```

- `select`

  给定_某些_输入和一个过滤器作为实参：
  - 如果对输入应用该过滤器后得到一个 _true_ 值，就原样输出输入
  - 否则，就_什么也不输出_（不是`null`值，而是真正的没有输出）

  例如，给定一些数字，选出能被 3 整除的那些

  ```sh
  $ jq -n 'range(10) | select(. % 3 == 0)'
  0
  3
  6
  9
  ```

  回想一下，`range`输出的是一个数字_数据流_。`select`会对每个数字调用一次。只有“通过”这个表达式的数字才会被输出。

  你经常需要从数组中选出想要的元素。有几种方法可以做到。

  给定输入`["Anne", "Bob", "Cathy", "Dave"]`，选出长度为 4 的名字。
  - 把`map`和`select`一起用

    ```jq
    map(select(length == 4))
    ```

  - 把数组拆成一个个元素，对那个数据流做`select`，再把结果收集起来

    ```jq
    [ .[] | select(length == 4) ]
    ```
