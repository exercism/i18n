# 说明

你被一家正在开发 Chatbot 的公司聘为正则表达式专家。

这个项目正处于非常基础的开发阶段，因此你的任务是用正则表达式提升 Chatbot 理解和生成自然语言的能力。

## 检查命令是否有效

除了聪明，Chatbot 还是一位忠诚的助手。

要向 Chatbot 提问，用户必须在命令的第一个位置说出“**Chatbot**”这个词。

关键字是大写还是小写都没关系。这里重要的是这个词的位置。

实现函数`isValidCommand()`，帮助 Chatbot 识别用户何时是在下达命令。

```javascript
isValidCommand("Chatbot, play a song from the 80's.";
// => True
isValidCommand("Hey Chatbot, where is the closest pharmacy?";
// => False
isValidCommand("CHATBOT, do you have a solution for this challenge?";
// => True
```

## 移除加密的 emoji

Chatbot 很难理解人类如何使用 emoji 来表达情感。

当 Chatbot 收到用户消息时，每个 emoji 都表示为“_emoji_”后跟它的 _id_ 编号。

实现 `removeEmoji()` 方法，让它接收一个字符串，并移除整条消息中所有 emoji 的加密内容。

不含 emoji 文本的行应原样返回。

只移除 emoji 字符串。不要尝试调整空白。

对于这个挑战，请使用构造函数语法来创建正则表达式。

```javascript
removeEmoji("I love playing videogames emoji3465 it's one of my hobbies");
// => "I love playing videogames  it's one of my hobbies"
```

## 检查电话号码是否有效

考虑到 Chatbot 的功能可以下载到手机应用中，用户需要在对话中输入电话号码。

问题在于，Chatbot 只能读取并验证符合特定格式的号码。

如果号码有效（符合**正则表达式**指定的字符序列），Chatbot 会回复一条消息，感谢用户并确认该号码。如果号码无效，函数会告知用户这个电话号码无效。

期望的格式是：(+##) ###-###-###

```javascript
checkPhoneNumber('(+34) 659-771-594');
// => "Thanks! You can now download me to your phone."
checkPhoneNumber('659-771-594');
// => "Oops, it seems like I can't reach out to 659-771-594"
```

## 获取网站链接

Chatbot 是一款非常好奇的软件。尽管它能在互联网上搜索特定主题，它还是喜欢向用户打听有趣的网站或 URL，从而找到相关信息。

对话示例：

- **Chatbot**：嘿，用户名，我想学习如何用 JavaScript 编程，你知道有什么很酷的网站可以让我学吗？
- **用户**：我从 [exercism.org](http://exercism.org) 学到了很多。

实现函数`getURL()`，它能够返回一个数组，其中只包含每个网站的链接。写一个能识别任意 URL 的正则表达式会非常复杂，但 Chatbot 只需要读取简单的 URL。在这个练习中，URL 就是任意由 `"."` 分隔的单词序列。

```javascript
getURL(
  'I learned a lot from exercism.org and developer.mozilla.org, but I found ts39.es very boring!',
);
// => ["exercism.org", "developer.mozilla.org", "ts39.es"];
```

## 向用户问好

为了存储所有与它对话过的人的数据，Chatbot 能够以这种格式从用户资料中获取全名：**“smith, john”**。

这样，我们希望 Chatbot 非常有礼貌，给人留下好印象。

编写函数`niceToMeetYou()`，它接收一个包含用户全名的字符串，并返回字符串**“Nice to meet you, John Smith”**

为了学习，请使用正则表达式中的**替换方法**来实现这个函数。

```javascript
let str = 'Smith, John';

niceToMeetYou(str);
// => "Nice to meet you, John Smith"
```
