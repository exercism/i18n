# 说明

在准备给朋友们烤饼干时，你发现食谱里的某些用量需要换算。你只熟悉公制，所以得想个办法，把美国烘焙中常见的计量单位换算成毫升（mL），好让自己用起来方便些。

解答时请使用下面这张换算表：

| 要换算的单位 | 容积 | 毫升（mL） |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| 美制杯          | 1      | 240                 |
| 美制液量盎司    | 1      | 30                  |
| 美制茶匙        | 1      | 5                   |
| 美制汤匙        | 1      | 15                  |

作为一名有天赋的程序员学员，你决定用毫升作为中间单位，方便把表中任意一个单位换算成另一个单位（甚至它自己）。

## 1. 从体积对中取出数值部分

实现`KitchenCalculator.get_volume`方法。
给定一个体积对元组，它应该只返回其中的数值部分。

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. 把体积对换算成毫升

实现`KitchenCalculator.to_milliliter`方法。
给定一个体积对元组，它应该使用换算表把体积换算成毫升。

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. 把毫升体积对换算成其他单位

实现`KitchenCalculator.from_milliliter`方法。
给定一个体积对元组和目标单位，它应该使用换算表把体积换算成目标单位。

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. 在任意单位之间换算

实现`KitchenCalculator.convert`方法。
给定一个体积对元组和目标单位，它应该把给定的体积换算成目标单位。

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
