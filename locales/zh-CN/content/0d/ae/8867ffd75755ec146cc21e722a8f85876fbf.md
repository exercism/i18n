# 说明

按照尼科马库斯（公元 60 至 120 年）为正整数提出的分类方案，判断一个数是 perfect、abundant 还是 deficient。

这位古希腊数学家[尼科马库斯][nicomachus]为正整数设计了一套分类方案：根据每个数的[真因数和][aliquot-sum]，把每个数唯一地归入 **perfect**、**abundant**或**deficient**中的一类。

真因数和就是一个数的所有因数之和，不包括这个数本身。

例如，15 的真因数和是 (1 + 3 + 5) = 9。

- **Perfect**：真因数和等于这个数本身
  - 6 属于 perfect，因为 (1 + 2 + 3) = 6
  - 28 属于 perfect，因为 (1 + 2 + 4 + 7 + 14) = 28
- **Abundant**：真因数和大于这个数本身
  - 12 属于 abundant，因为 (1 + 2 + 3 + 4 + 6) = 16
  - 24 属于 abundant，因为 (1 + 2 + 3 + 4 + 6 + 8 + 12) = 36
- **Deficient**：真因数和小于这个数本身
  - 8 属于 deficient，因为 (1 + 2 + 4) = 7
  - 质数都属于 deficient

请实现一种判断给定数是否为 **perfect** 的方法。
根据你所在的编程语言，可能还需要实现判断给定数是 **abundant** 还是 **deficient** 的方法。
