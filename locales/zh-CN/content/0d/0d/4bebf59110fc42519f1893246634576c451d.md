# 有些括号是多余的

如果你用`||`表达式把两个较小的表达式进行或运算，而其中一个表达式被括号括起来，括号里只是用与运算把若干项连在一起（例如`knightIsAwake || (archerIsAwake && !prisonerIsAwake)`），那么这些括号可以省略，因为`&&`的优先级高于`||`：

```java
// instead of
knightIsAwake || (archerIsAwake && !prisonerIsAwake);

// use
knightIsAwake || archerIsAwake && !prisonerIsAwake;
```

请注意，在某些复杂的情况下，使用括号可以提高可读性，让这个条件更容易理解。
