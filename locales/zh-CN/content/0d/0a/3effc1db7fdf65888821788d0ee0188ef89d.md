# 资源

* Libera Chat 上的 [#haskell](https://web.libera.chat/?channel=#haskell) IRC 频道，其目标是“鼓励学习与讨论 Haskell、函数式编程以及一般意义上的编程”。有关该 IRC 频道的更多信息，请见[该频道的 Haskell Wiki 页面](https://wiki.haskell.org/IRC_channel)。
* [Hoogle](https://www.haskell.org/hoogle/) 是一个 Haskell API 搜索引擎。它让你在只知道函数名的情况下，也能查出这个函数是做什么的。或许更有趣的是，它还支持按类型签名搜索：如果你想知道哪些函数的类型签名是 [(a -> b) -> [a] -> [b]](https://www.haskell.org/hoogle/?hoogle=%28a+-%3E+b%29+-%3E+[a]+-%3E+[b])，Hoogle 可以帮你找到！
* 你可以用 [Stack Overflow](https://stackoverflow.com/questions/tagged/haskell) 搜索你的问题，看看是否已经有人回答过。你也可以提问和回答问题。
* [/r/haskell](https://www.reddit.com/r/haskell) 是 Haskell 的 subreddit。
* [Haskell 社区页面](https://www.haskell.org/community/) 链接到许多 Haskell 开发者聚集和交流的社区；从这里你可以选择自己喜欢的交流方式。
