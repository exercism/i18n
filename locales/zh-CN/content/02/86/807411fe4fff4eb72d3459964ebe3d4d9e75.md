# 简介

使用`while`循环，只要某个条件成立，你就能反复执行代码。
它的写法是：先写`while`关键字，然后是一个用圆括号括起来的条件，最后是一个用大括号括起来的代码块，代码块中包含循环的_循环体_。

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript 还有 do-while 循环。
它的条件会在循环体执行完毕之后才检查。
当条件取决于循环体中代码的执行结果时，这种写法很有用。

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

在循环体内部，你可以使用`break`关键字彻底停止循环的执行。
与之相反，`continue`关键字只会停止当前这一次迭代，然后继续下一次迭代。
借助`continue`，你常常可以避免把循环体的大部分内容都包进一个`if`语句里。

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```
