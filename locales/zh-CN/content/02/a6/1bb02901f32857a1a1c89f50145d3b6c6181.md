# 提示

## 通用

- 元组的各个组成部分可以通过在元组名称后附加 _.n_ 来访问，其中 _n_ 是组成部分的下标，从 0 开始。

## 1. 获取玩具的名称

- 你可以使用 `.n` 语法访问玩具的名称。

## 2. 向数据库添加新玩具

- 你可以使用元组语法 `(name1: value1, name2: value2, ...)` 创建一个新元组。

## 3. 更新玩具的数量

- 你可以使用 [`for` 循环][for-loop] 遍历元组数组，并更新玩具的数量。
- 你可以使用之前实现的函数来获取玩具的名称。
- 你可以使用[分支语句][conditional-statement]来检查玩具的名称是否与你想更新的那个匹配。
- 你可以使用 `.n` 语法更新玩具的数量，例如：`toys.price = 3`。

## 4. 为玩具添加分类键

- 你可以使用 [`for` 循环][for-loop] 遍历元组数组，并为玩具添加分类键。
- 元组是不可变的，因此你需要创建一个添加了分类键的新元组。

[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
