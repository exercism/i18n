# 位操作

Crystal 提供了位运算符，可以在二进制层面操作[`Int`][ints]。

## 移位运算符

Crystal 提供了[移位运算符][shift]，可以把二进制位向左（`<<`）或向右（`>>`）移动。

### 左移（`<<`）

左移运算符（`<<`）把二进制位向左移动。
要移动的值写在左边，移动的位数写在右边。

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

如果这个数字是负数，那么实际上会向右移动。

```crystal
0b0010 << -1
# => 0b0001
```

### 右移（`>>`）

右移运算符（`>>`）把二进制位向右移动。
和左移运算符一样，要移动的值写在左边，移动的位数写在右边。

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

同样地，如果这个数字是负数，运算符会改为向左移动。

```crystal
0b0100 >> -1
# => 0b1000
```

## 二元运算符

Crystal 有 3 个用于进行位运算的[二元运算符][binary]（`&`、`|`、`^`），以及一个`~`运算符。

### 按位与（`&`）

二元与运算符（`&`）对两个值执行按位与运算。
它会把第一个值中的每一位与第二个值中相同位置的位进行比较。
如果两个位都是 1，结果位就设为 1。
否则设为 0。

```crystal
0b0011 & 0b1010
# => 0b0010
```

### 按位或（`|`）

二元或运算符（`|`）对两个值执行按位或运算。
它同样会把第一个值中的每一位与第二个值中相同位置的位进行比较。
只要其中任意一位是 1，结果位就设为 1。
否则设为 0。

```crystal
0b0011 | 0b1010
# => 0b1011
```

### 按位异或（`^`）

二元异或运算符（`^`）执行按位异或运算。
和按位与、按位或运算符一样，它会把第一个值中的每一位与第二个值中相同位置的位进行比较。
如果其中_只有一位_是 1，结果位就是 1。
否则为 0。

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### 按位非（`~`）

最后，按位非运算符（`~`）会把值中的每一位取反。
与其他二元运算符不同，这是一个一元运算符，只对它右边的值进行操作。

```crystal
~0b1110_0010
# => 0b0001_1101
```
