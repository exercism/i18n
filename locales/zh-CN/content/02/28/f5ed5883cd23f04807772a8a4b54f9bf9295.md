# 数据库支付批次

## 问题描述

你需要把一批支付数据插入 `Payment` 表。你的任务是：从给定的输入 JSON 文件中读取支付数据，并使用 JDBC Client 的 `batchExecute` 操作把这些支付数据插入 `Payment` 表。示例输入文件为 `payments.json`。

输入 JSON 文件的内容基于以下 JSON schema。

```json
{
  "type": "array",
  "items": [
    {
      "type": "object",
      "properties": {
        "employee_id": {
          "type": "integer"
        },
        "amount": {
          "type": "number"
        },
        "reason": {
          "type": "string"
        },
        "date": {
          "type": "string"
        }
      },
      "required": [
        "employee_id",
        "amount",
        "reason",
        "date"
      ]
    }
  ]
}

```

你需要返回该批次中插入的支付数据自动生成的支付 ID 作为输出，并且不能再向数据库发起查询。

你可以假设 `payments.json` 文件中给出的 `employee_id` 都是有效的，并且已经存在于 `Employee` 表中。

## 数据库详情

本题请使用提供的 H2 数据库。

> 示例数据库文件为 `gofigure.mv.db`，数据库名为 `gofigure`。它位于 `db` 文件夹中。

以下这些表已经存在于示例 H2 数据库中，并带有一些示例数据。列名和数据类型如下。

**表名**：`Employee`

| **列：**      | 类型 |
| -----------       | ----------- |
| `employee_id`     | 整数，自增主键       |
| `name`            | 字符串        |
| `city`            | 字符串        |
| `department`      | 字符串        |
| `age`             | 整数        |

**表名**：`Payment`

| **列：**      | 类型 |
| -----------       | ----------- |
| `payment_id`      | 整数，自增主键       |
| `date`            | 日期        |
| `amount`          | 小数        |
| `employee_id`     | 整数        |
| `reason`          | 字符串        |

* 数据库文件为 `gofigure.mv.db`。使用 `jdbc:h2:file:/path/to/db/file` 作为 JDBC URL
* 用户名：`root`
* 密码：`root`

## 约束条件

* 使用 `db` 文件夹中提供的 H2 数据库文件来验证查询和 Ballerina 示例
* 使用 maven 依赖参数的方式，在你的 Ballerina.toml 中把 H2 数据库驱动添加为平台依赖
* 你需要在不再向数据库发起查询的情况下找出自动生成的支付 ID。

## 测试环境

* 你可以用 `bal test` 运行测试，它会对给定的示例数据库运行测试。

## 示例

### 示例 1

**输入：** dbFilePath: `"/path/to/file/gofigure"`, paymentFilePath: `"/path/to/file/payments.json"`

示例 `payments.json` 文件数据：

```json
[{
        "employee_id": 4,
        "amount": 12500.50,
        "reason": "Fuel for the month January",
        "date": "2022-02-03"
    },
    {
        "employee_id": 1,
        "amount": 10500.50,
        "reason": "Medical Expenses for the month January",
        "date": "2022-02-04"
    },
    {
        "employee_id": 4,
        "amount": 500.50,
        "reason": "Fuel for the month February",
        "date": "2022-03-03"
    }
]

```

**输出：** `[1,2,3]`

## 提示

* 使用 [ballerinax/java.jdbc](https://central.ballerina.io/ballerinax/java.jdbc) 模块来操作数据库
* 参考[先决条件](https://lib.ballerina.io/ballerinax/java.jdbc/latest)一节，了解把 JDBC 驱动添加为依赖的步骤
* 使用 [io:fileReadJson](https://lib.ballerina.io/ballerina/io/latest/functions#fileReadJson) 读取 JSON 输入文件
* 把 JSON 值转换成应用特定的类型，以便以类型安全的方式处理数据。参考[转换为用户定义类型](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type/)示例
* 使用 [sql:ParameterizedQuery](https://lib.ballerina.io/ballerina/sql/latest#ParameterizedQuery) 和 [batchExecute](https://lib.ballerina.io/ballerinax/java.jdbc/latest#Client-batchExecute) 远程方法来操作数据库
* 参考[批量执行](https://ballerina.io/learn/by-example/mysql-batch-execute-operation/)示例
