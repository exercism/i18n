# 简介

## 数字

Lua 用两种方式表示数字：64 位整数和双精度浮点数。它支持常用的一组算术运算符：加、减、乘、除和取负。此外，它还支持向下取整除法、求模和幂运算。

| 运算符 | 示例                |
| -------- | ------------------- |
| `+`      | `1 + 2 --> 3`       |
| `-`      | `2 - 1 --> 1`       |
| `*`      | `2 * 2 --> 4`       |
| `/`      | `4 / 2 --> 2.0`     |
| `//`     | `11 // 3 --> 3`     |
| `%`      | `11 % 3 --> 2`      |
| `^`      | `10 ^ 2 --> 100.0`  |
| `-`      | `-(2 * 2) --> -4`   |
