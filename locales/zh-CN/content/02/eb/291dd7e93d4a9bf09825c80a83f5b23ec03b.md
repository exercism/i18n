# 闰年的概念

我更偏好第一个示例解答，因为它简洁，符合我所见到的地道 Rust 写法。它也避免了标准解答中额外引入的闭包概念。

## 提取出的概念

### 通用

- 布尔逻辑
  - 布尔值
- 表达式
  - Rust 函数隐式返回表达式
- 算术
  - 求模

### 类型

- 无符号整数：`u64`
- 布尔值：`bool`

## 示例练习 1

["desi-belokonska"](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09) 的解答

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## 示例练习 2

[标准解答](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
