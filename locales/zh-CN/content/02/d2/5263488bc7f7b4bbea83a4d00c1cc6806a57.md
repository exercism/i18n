# 关于

[`switch`语句][switch]让你可以把一个值跟多个可能的匹配值进行比较。相比使用多个`else-if`语句，它能让你写出更简洁的代码。`switch`语句以`switch`关键字开头，后面跟上要比较的值。接着，你可以用`case`关键字来定义各个分支，后面跟上要比较的目标值。`default`关键字用于定义默认分支，在没有任何分支匹配时执行。和`else-if`语句一样，`switch`语句只会执行第一个匹配分支所对应的代码块。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

看看下面这个例子：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

也可以改写成这样：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 绑定与`where`子句

`switch`语句中被匹配的值也可以绑定到名字上，这些名字可以在分支的主体中使用。它们还可以用在`where`子句中，`where`子句是额外的布尔表达式，必须求值为`true`，该分支才会匹配。

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
