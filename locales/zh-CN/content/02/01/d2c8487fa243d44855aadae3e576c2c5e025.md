# 说明

在**Chrono Realms**中，Time Keepers 要处理的往往不只是由时间线构成的树，还有**Chrono Chains**，也就是由一个个**TimeNode**链接而成的序列，每个节点都代表时间中的某个特定时刻。
**Chrono Chain**是一条由先后相继的时刻组成的直线路径，其中每个**TimeNode**都连接到下一个节点。
在穿梭于一系列特定事件时，**Chrono Chains**很有用，因为它们让 Time Keepers 能够沿着单条时间线前进。

不过，要处理这些可能很长的**Chrono Chains**，Time Keepers 会使用**智能指针（Box<T>）**来安全地管理和遍历这些时刻列表，而不会造成不必要的内存复制或溢出。
每个**TimeNode**都持有对下一个节点的引用，从而构成递归结构。

作为学徒，你的任务是用智能指针把**Chrono Chain**实现为一种递归的列表结构。

在这个练习中，你将：

1. 创建一个递归的`ChronoChain`枚举，用来表示一串时刻。
2. 使用`Box<T>`智能指针来存储递归的节点。
3. 实现一个函数，从由`u32`值组成的数组创建`ChronoChain`。
4. 实现一个函数，遍历`ChronoChain`并把列表中存储的值相加。

## 1. 定义递归的`ChronoChain`枚举

创建一个包含两个变体的递归枚举`ChronoChain`：

- `End`：表示列表的结尾。
- `Link`：包含一个`u32`值，以及一个指向链中下一个节点的装箱引用。

## 2. 编写一个函数来构建 ChronoChain

编写一个函数`ChronoChain::build`，接收一个由`u32`值组成的数组，返回一个`ChronoChain`，并使用智能指针把这些值按顺序链接起来。

## 3. 实现求和函数

编写一个函数`ChronoChain::sum`，递归地遍历`ChronoChain`，并把所有节点的值相加。

## 示例用法

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
