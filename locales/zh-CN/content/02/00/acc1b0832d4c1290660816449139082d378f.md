# 简介

在 Elixir 中，元组是一种用于组织数据的数据结构，它保存固定数量的、可以是任意类型的元素，但每个元素都没有明确的名称。在 Elixir 中，元组常用于内存读取密集型的操作，因为读取其中的元素是常数时间的操作。当元素需要动态地添加或删除时，通常不会使用元组，因为此时不是修改现有的元组，而是创建一个新元组，这就需要预先分配内存。

在实际使用中，Elixir 用大括号创建元组。使用`elem/2`函数，可以通过从 0 开始的下标单独访问元组中的元素：

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## 元组表示分组信息

在实际中，元组常用来表示分组信息。

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
