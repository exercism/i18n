# 关于

[Python][python docs] 是一门[动态且强类型][dynamic typing in python]的[面向对象][object oriented programming]编程语言。
它同时使用[鸭子类型][duck typing]和[渐进类型][gradual typing]（通过[类型提示][type hints]）。
它支持多种编程范式，包括命令式（_面向对象、过程式_）和声明式（_函数式、并发式_）两种风格。
但别误会：虽然完全支持跨范式编程，[Python 中的一切皆对象][everythings an object]。


Python 由 Guido van Rossum 创建，于 1991 年首次发布。
[Python 软件基金会][psf]负责管理和调配 Python 与 CPython 开发的资源，并通过 [Python 增强提案（PEP）][peps]接收社区[成员][psf membership]对语言变更的建议。
它被认为是一门很适合[刚踏上编程之旅][python for beginners]的程序员的语言，社区友好，为各种水平和兴趣的学习者提供了丰富的资源。


Python 非常重视代码的可读性，并（_与 Haskell 类似_）使用[显著缩进][significant indentation]来表示函数、方法和类的定义。
代码可以在命令行、交互式解释器会话、JupyterLab（Jupyter Notebooks）或各种代码编辑器和 IDE 中编写和运行。

[Python 应用广泛][python is used extensively]，涉及科学计算、金融、游戏、网络、互联网开发，以及将其他程序组装成流水线。


[Python 之禅（PEP 20）][the zen of python]和[什么是 Pythonic？][what is pythonic]阐述了关于这门语言的更多理念和观点。


本赛道的测试和工具目前分别支持`Python 3.10 - 3.13.7`（_测试_）和[`Python 3.13.7`][313-new-features]（_工具_）。
强烈建议学生升级到至少`Python 3.10`，因为本赛道用到的一些功能在更早的版本中可能不受支持。
话虽如此，大多数练习在`Python 3.6+`甚至更早的版本上也能正常工作。
但我们不保证支持未列入[当前活跃的 Python 版本][active-python-releases]的版本。
如果某个功能只在特定版本中可用，我们会尽量注明。


本赛道所用 Python 版本（`3.13.x`）的完整文档见 [docs.python.org][python docs]。
