# 介绍

Gleam 有一等函数，也就是说，函数是普通的值，可以赋值给变量、作为实参传递，也可以从其他函数中返回。

模块中定义的具名函数可以通过它的名字来引用。

```gleam
pub fn main() {
  // Assign the function to a variable
  let f = add_one
  
  // Invoke the function
  f(1) // -> 2
  f(2) // -> 3
}

fn add_one(x) {
  x + 1
}
```

Gleam 也有匿名函数，它们定义在其他函数的内部。

```gleam
// Define the function
let f = fn(x) { x + 1 }

// Invoke the function
f(1) // -> 2
f(2) // -> 3
```

函数的类型使用与匿名函数类似的语法书写。一个接受`Int`和`Float`并返回`Int`的函数，它的类型是这样写的：

```gleam
fn(Int, Float) -> Int
```

匿名函数可以引用定义它们时处于作用域内的变量，这让它们成为_闭包_。

```gleam
let secret_number = 42

// This function always returns 42
fn() { secret_number }
```

_函数捕获_语法为创建匿名函数提供了一种便捷的简写形式，这类匿名函数会把单个实参传给一个函数。下面两个表达式是等价的：

```gleam
// Anonymous function syntax
let f = fn(x) { my_function(1, 2, x) }

// Function capture syntax
let f = my_function(1, 2, _)
```
