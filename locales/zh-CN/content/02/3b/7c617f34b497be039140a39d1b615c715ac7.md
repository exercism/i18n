# 关于

[TypeScript](https://www.typescriptlang.org/)（TS）是 JavaScript（JS）的超集，由微软创建，起因是开发者们在用 JS 开发大型应用时屡屡受挫。在一个大型 JS 项目里，要搞清楚自己定义的对象有哪些属性、自己的函数接受哪些实参（以及它们需要是什么类型），会变得很困难。同样，既然没有办法智能地检查 JS 代码，当你引入一个包（比如从 `npm` 安装的包）时，就必须持续维护文档，才能知道有哪些方法可用、它们接受哪些实参。TS 解决了这些问题。它目前是一个托管在 Github 上的开源项目。它支持适用于任何浏览器以及 Node 的工具，可在任何主机、任何操作系统上使用。TS 会编译成可读的、符合标准的 JavaScript。

除了接口（自定义类型）之外，TS 还为 JS 加入了一套灵活的类型系统，并修改了某些 ECMAScript 特性（如类）的语法。类型是可选的，也很灵活（例如，你可以指定某个实参是字符串或数字）。类型让大多数代码编辑器中可用的工具得以发挥作用，比如代码补全和方法检测，从而改善开发体验，无论对你自己写的代码还是你使用的包都是如此。它支持许多即将到来的 ECMAScript 特性（例如 async/await）。TS 可以用面向对象或函数式的风格来编写。它与所有现有的 JS 包兼容。TS 可转译成整洁、可读的 JS。

到[演练场](https://www.typescriptlang.org/play)试一试，并通过[TypeScript 博客](https://devblogs.microsoft.com/typescript/)和 [Twitter 账号](https://twitter.com/typescript)了解最新动态。
