# 提示

## 1. 创建一个包含所有车厢的数组

- 用经典的`for`/`while`循环配合`push!`往`Vector`里添加元素就行。
- 另外，[`collect()`][collect]函数会更简洁。
- 也可以改用展开，直接写在数组构造函数里：

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. 修正车厢数组

- 把前面的车厢和车头从其余部分中分出来会很有帮助，这样才能按正确的顺序把它们重新组合起来。
- 配合展开使用的多重赋值可能会帮到你（见简介）。

## 3. 添加缺失的站点

- 记住，这个函数不会修改输入！要新建一个`Dict`。
- 只需要站点名称，不需要站点编号，所以每一对都必须拆开。
- 组装名称数组有多种方式：
  -  用`for`/`while`循环配合`push!()`往`Vector`里添加。
  -  数组[推导式][comprehensions]
  -  用[`map()`][map]把函数映射到数组上。
  -  还可以对[匿名][anonymous]函数进行[广播][broadcasting]：

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. 扩展路线信息

- 收集参数之后，`more_route_information`是一个`Pairs()`集合。
- [`merge()`][merge]函数可以合并两个或多个`Dict`，但也能接受一个`Pairs()`集合。
  把`Pairs()`集合显式转换成`Dict`是可以的，但没有必要。
