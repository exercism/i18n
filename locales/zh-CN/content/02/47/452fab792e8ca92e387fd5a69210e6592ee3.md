# 简介

数组和列表包含一组有序的标量。
如果不使用引用（这会在另一个概念中介绍），这意味着数组和列表始终是扁平的，也就是说，它们不能包含其他数组或列表。

大多数情况下，列表由括号`()`括起来，元素之间用逗号`,`分隔。

数组变量通常通过把列表赋值给它来填充，例如，`my @names = ('Alice', 'Bob', 'Charlie');`。

可以通过下标指定索引来访问数组或列表的元素，例如，`('Alice', 'Bob', 'Charlie')[1] # 'Bob'`。

Perl 中的下标从`0`开始。
负下标会从数组或列表的末尾开始计数，例如，`('Alice', 'Bob', 'Charlie')[-1] # 'Charlie'`。

## 函数

有许多用于操作数组和列表的函数，其中最有用的一些包括 [grep][grep]（生成由符合条件的元素组成的新列表）、[map][map]（把元素转换成新的值列表）和 [sort][sort]（生成重新排序后的元素列表）。

用于操作数组的函数包括 [push][push]（把元素添加到末尾）、[pop][pop]（移除最后一个元素）、[shift][shift]（移除第一个元素）、[unshift][unshift]（在开头添加元素）以及 [splice][splice]（进行更复杂的修改）。

用 [for(each)][perlsynforeach] 语句遍历数组和列表，也是你会经常遇到的操作。

## 符号的差异

访问数组元素时，所用的符号决定结果。
变量名末尾的下标`[]`告诉 Perl，你正在访问该名称对应的数组。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

$names[0]; # 'Alice'      <- A scalar
@names[0]; # ('Alice')    <- A slice (with only one index, this probably isn't what you want. There will be a warning.)
%names[0]; # (0, 'Alice') <- A key/index + value slice

$names[1, 2]; # 'Charlie'                <- A scalar (via unsupported syntax for an ancient feature. Probably not what you want. There will be a warning.)
@names[1, 2]; # ('Bob', 'Charlie')       <- A slice
%names[1, 2]; # (1, 'Bob', 2, 'Charlie') <- A key/index + value slice
```

虽然这是允许的，但为了可读性，建议不要让不同类型的变量共用同一个名称。

## 数组与列表的区别

数组和列表有许多相似之处，在很多地方可以互换使用，但它们并不是同一种东西。
列表是固定且不可变的标量集合。
数组是一个可变的标量集合，其内容和数组本身的大小都可以改变。

在某些上下文中，它们的行为不同。
在标量上下文中使用数组，会得到数组的大小。
在标量上下文中使用列表，会得到列表的最后一个元素，并且可能会收到一些警告，提示其余内容被用在了空上下文中。

```perl
my @names = ('Alice', 'Bob', 'Charlie');

scalar @names; # 3
scalar ('Alice', 'Bob', 'Charlie'); # 'Charlie' (and some warnings).
```
