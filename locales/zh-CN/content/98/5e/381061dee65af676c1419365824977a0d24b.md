# 说明

在这个练习中，你要为纽约一家美容院开发一个预约调度程序，这家美容院于 2012 年 9 月 15 日开业。

## 1. 解析预约日期

实现 `AppointmentScheduler.schedule()` 方法，把预约日期的文本表示解析成对应的 `LocalDateTime`：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.schedule("7/25/2019 13:45:00");
// => LocalDateTime.of(2019, 7, 25, 13, 45, 0)
```

## 2. 检查预约是否已经过去

实现 `AppointmentScheduler.hasPassed()` 方法，它接收一个预约日期，检查该预约是否已经过去：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.hasPassed(LocalDateTime.of(1999, 12, 31, 9, 0, 0));
// => true
```

## 3. 检查预约是否在下午

实现 `AppointmentScheduler.isAfternoonAppointment()` 方法，它接收一个预约日期，检查该预约是否在下午（>= 12:00 且 < 18:00）：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.isAfternoonAppointment(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => true
```

## 4. 描述预约的时间和日期

实现 `AppointmentScheduler.getDescription()` 方法，它接收一个预约日期，返回该日期和时间的描述：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getDescription(LocalDateTime.of(2019, 03, 29, 15, 0, 0))
// => "You have an appointment on Friday, March 29, 2019, at 3:00 PM."
```

## 5. 返回周年纪念日

实现 `AppointmentScheduler.getAnniversaryDate()` 方法，它返回今年的周年纪念日，也就是 9 月 15 日：

```java
AppointmentScheduler scheduler = new AppointmentScheduler();
scheduler.getAnniversaryDate()
// => LocalDate.of(<current year>, 9, 15)
```
