# `while`循环与`until`循环

循环是一种控制结构，它让代码可以根据给定的条件重复执行。

## `while`循环

`while`循环是一种控制结构，它让代码可以根据给定的条件重复执行。只要条件求值为 true，`while`循环里的代码就会一直执行下去。当事先不知道要迭代多少次时，常常会用到`while`循环；不过任何需要循环的场景都可以用它。

条件会在循环里的代码执行之前先求值，这意味着如果条件为 false，循环里的代码就永远不会执行。

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

想遍历字符串时，可以按字符串的长度来循环。

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## `until`循环

`until`循环和`while`循环的工作方式相同，区别在于：循环里的代码会一直执行，直到条件求值为 true。这就像`if`和`unless`之间的区别一样。

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### 无限循环

`while`循环的一个常见错误是陷入“无限循环”，永远也出不来。造成无限循环的原因，可能是某个条件_永远_不会求值为 true 或 false。这通常是程序员的失误，比如忘记让循环变量自增。但有时候，无限循环是实现程序逻辑最清晰的方式。有时又必须一直循环下去，例如 HTTP 服务器会等待传入的连接，处理它，然后等待下一个连接。

## `break`

`break`关键字可以用于提前跳出循环。当你想在满足某些条件时提前跳出循环，它会很方便。

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## `next`

`next`关键字可以用于跳到循环的下一次迭代。当你想跳过循环中的某些迭代时，它会很方便。

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## 循环中的类型

变量的类型在循环过程中可能会发生变化。在下面的例子里，`a`的类型是`Int32 | String`，因为在循环的第一部分里，它既可以是`Int32`，也可以是`String`。变量`a`只在循环的第一部分才带有`Int32 | String`类型：循环开始时它持有`Int32`，到第二次迭代时又持有`String`。这套多类型系统稍后会有详细说明。但由于可以确定循环的第二部分只会持有`String`，所以`a`在循环的第二部分里类型是`String`。在运行时，它绝不会同时持有`Int32`和`String`。

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
