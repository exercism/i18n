# 简介

哈希是 Perl 中的一种数据类型，它是由字符串键和与之配对的标量值组成的无序集合。

哈希变量通常通过给它赋值一个数组来填充，例如 `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`。

数组通常用逗号分隔，但你会经常看到用所谓的“胖逗号”`=>`来分隔数组中的键和值。它的行为与逗号几乎完全相同，但额外的好处是会把左侧的元素解释为字符串。

哈希也可以通过给单独的键赋值来填充，例如 `$scores{Alice} = 10;`。

哈希的值可以通过下标指定键来获取，例如 `$scores{Bob} # 15`。

哈希中的键是唯一的。如果同一个键出现多次，只会保留最后给出的那个值。

## 函数

用于操作哈希的函数包括 [keys][keys] 和 [values][values]，它们分别把哈希的对应部分取出为一个数组。[keys][keys] 和 [values][values] 函数返回的数组可以用于 [grep][grep]、[map][map]、[sort][sort] 等数组函数，以及 [for][for] 循环。

其他哈希函数包括 [exists][exists]，用于检查某个键是否存在于哈希中（即使它的值是`undef`），以及 [delete][delete]，用于从哈希中删除一个键。

## 印记差异

获取哈希的值时，所用的印记决定了结果。变量名末尾的下标 `{}` 告诉 Perl，你正在访问一个叫这个名字的哈希。

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

虽然允许这样做，但为了可读性，建议不要让不同类型的变量共用同一个名字。
