## 1. 检查传感器连接（`connection_check`）

你的第一个任务是确保 Pillar Men 传感器连接正常。不能让传感器断连引发误报。
你将编写`connection_check`函数，它通过检查`nullptr`来判断传感器指针是否有效。

- 定义一个函数，接受一个指向`pillar_men_sensor` struct 的指针。
- 如果传感器指针不为空，函数应返回`true`，否则返回`false`。

```cpp
pillar_men_sensor* sensor{nullptr};
bool isConnected = connection_check(sensor);
// isConnected => false
```

## 2. 统计传感器的活动量（`activity_counter`）

Pillar Men 潜伏在暗处，我们需要知道传感器是否检测到了任何活动。
你将编写`activity_counter`函数，它接受一个传感器数组，以及一个表示数组中传感器数量的容量值。

- 定义一个函数，接受指向数组第一个元素的指针以及数组的容量。
- 使用指针运算遍历传感器数组，累加活动读数。
- 返回累加后的活动量。

```cpp
pillar_men_sensor sensor_array[3] = {{0}, {101}, {22}};
int totalActivity = activity_counter(sensor_array, 3);
// totalActivity => 123
```

## 3. 报警控制（`alarm_control`）

除非真的存在危险，否则并非每个传感器都应该触发报警。
`alarm_control`函数确保只有当传感器的活动量大于 0 时才触发报警。
这个函数还应检查空传感器，以防止系统崩溃。

- 定义一个函数，接受指向`pillar_men_sensor`的指针。
- 函数应首先检查传感器是否为`nullptr`。如果传感器是`nullptr`，返回`false`。
- 如果传感器有效且其活动量大于 0，返回`true`；否则返回`false`。

```cpp
pillar_men_sensor db{9008, "songokunoie", {7, 7, 7}};
bool alarm = alarm_control(&db);
// alarm => true
```

## 4. 用`uv_alarm`函数检查数据中的异常

在这个任务中，你将实现`uv_alarm`函数，根据紫外线照射水平和传感器活动量来判断是否应该触发报警。
`uv_alarm`函数应使用提供的`uv_light_heuristic`函数，后者对一个数据向量进行处理，并根据特定的阈值返回一个值。
这是生产环境中将要运行的复杂代码的模拟版本，请不要修改接口。

在`speedywagon`命名空间中定义`uv_alarm`函数。它应该：

- 接受一个指向`pillar_men_sensor` struct 的指针作为形参。
- 如果传感器指针为空，返回`false`。
- 调用`uv_light_heuristic`函数，并传入传感器`data`数组的地址。
- 如果`uv_light_heuristic`返回的值大于`sensor->activity`的活动水平，返回`true`，否则返回`false`。
