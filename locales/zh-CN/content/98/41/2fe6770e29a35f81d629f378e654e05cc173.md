# 字符串构建器

一个`STR`永远不会改变。所以`+`不能往里面追加内容，它只能新建一个完整的字符串，把两者的内容都放进去。

这么做一次没问题，放进循环里就不行了：

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

每一轮都会把目前为止构建的内容全部复制进一个新字符串，再把旧的丢掉。十行就是十次复制，而且一次比一次长。一百行就是一百次。工作量随行数的*平方*增长，一个看起来无害的循环就成了程序里最慢的部分。

## FSTR

`FSTR`是一种*可以*修改的字符串，也就是**字符串构建器**。往里面追加内容通常只是写进它已有的空间，所以遍历一百行的循环，工作量大约相当于一百行，而不是复制一百次。

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

有三点值得注意。

**`#FSTR`会创建一个空的构建器。**`#FSTR(100)`创建的构建器已经预留了一百个字符的空间，在提前知道大小时值得这么做。

**必须把结果赋回去。**要用`script := script + ...`，绝不能只写`script + ...`。通常返回的是传进去的那个构建器，但当空间用尽时，它会是一个更大的新构建器，而丢掉返回值就意味着你还在往旧的那个里面写。

**末尾的`.str`。**声明返回`: STR`的例程必须交回一个`STR`，而`.str`就是从这个构建器造出一个`STR`。

## 能追加什么

`FSTR`上的`+`可以接受字符串、字符、整数或布尔值，所以通常不需要事先转换：

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## 换行

字符串里的`"\n"`表示一个换行，它是一个字符，却要写两个字符。

```sather
   script := script + "Enter" + "\n" + "Exit";
```
