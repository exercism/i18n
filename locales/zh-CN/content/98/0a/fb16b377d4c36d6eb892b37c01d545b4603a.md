# 提示

## 通用

- 看看 [Elm Guide][elm-guide]，里面有一个类似的完整示例，写得很不错。

## 1. 为应用定义 Model 和 Msg 类型，并编写 init 函数

- `Model` 包含应用的状态，也就是应用需要的全部数据。
- 它应该是一个[记录][record]。
- 这个应用只需要一个 `String` 来存储文本框里的文本（测试要求它命名为 `content`）。

- `Msg` 类型定义了传递给 `update` 函数的消息，用来触发模型中特定的变化。
- 它应该是一个[自定义类型][custom-type]。
- 这个应用只需要对模型做一处改动，也就是在文本框中的文本发生变化时更新模型。

- `init` 函数只需返回一个带有合理默认值的 `Model`（测试要求默认值是空字符串）。

## 2. 编写 update 函数

- 在任何有用的应用里，update 函数都会用 `case` 语句对 `Msg` 参数进行模式匹配。
- 在 case 语句的每个分支中，它会从 `Msg` 参数里提取所需的信息，并返回更新后的 `Model`。
- `Model` 应该是一个记录，通常使用[记录更新语法][record-update-syntax]。

## 3. 编写 view 函数

- `view` 函数应该为根元素返回一个 `div`。
- 第一个子元素应该是一个 `input`，带有一个 `value` 属性表示当前文本，以及一个 `onInput` 属性/事件，使用 `Msg` 中相应的变体。
- 第二个子元素应该是另一个 `div`，里面包含一个 `text` 子元素，用来显示文本是否为回文。

## 4. 编写 main 函数

- main 函数只需调用 [`Browser.sandbox`][browser-sandbox]。
- `Browser.sandbox` 需要一个[记录][record]实参，其中包含 `init`、`update` 和 `view` 函数。
