# 说明

在这个练习中，你将编写一些代码，帮助你为购买一辆车做好准备。

你有三个任务：判断你是否需要驾照，帮助你在两辆车之间做出选择，以及估算一辆二手车的合理价格。

## 1. 判断你是否需要驾照

有些类型的车辆需要驾照才能驾驶。
假设只有 `"car"` 和 `"truck"` 这两种类型需要驾照，其他所有类型都可以无照驾驶。

实现 `needsLicense(kind)` 函数，它接收车辆类型，并返回一个布尔值，表示这种类型的车辆是否需要驾照。

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. 在两辆可能购买的车辆之间做选择

你评估了手头可以选择的车辆。
你成功把范围缩小到两个选项，但还需要有人帮你做最终决定。
为此，实现 `chooseVehicle(option1, option2)` 函数，它接收两辆车作为实参，并返回一个决定，其中包含按[字典序][lexicographical-order]排在前面的那个选项。

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算一辆二手车的价格

既然你已经做出了决定，你就想确保在经销商那里能拿到一个合理的价格。
既然你想买的是二手车，价格就取决于车龄。
粗略估算一下，假设车龄不到 3 年，价格是它全新时原价的 80%。
如果车龄至少 10 年，价格是原价的 50%。
如果车龄至少 3 年但不到 10 年，价格是原价的 70%。

实现 `calculateResellPrice(originalPrice, age)` 函数，用 `if`、`else if` 和 `else` 来应用这套逻辑（如果你想练习，也可以用其他方式）。
它接收原价和车龄作为实参，并返回经销商处的估算价格。

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
