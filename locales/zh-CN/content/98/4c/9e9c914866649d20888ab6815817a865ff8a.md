# 路线图

本文档概述了贡献者和维护者在未来几个月可能会重点关注的主要主题。

## 主题概览

- 改进现有的概念练习
- 新增概念练习（见下文的教学大纲概览）
- 为所有实践练习定义`prerequisites`和`practices`列表（见 [Issue 1396](https://github.com/exercism/go/issues/1396)）
- 修复 [测试运行器](https://github.com/exercism/go-test-runner/) 中剩余的 bug
- 修复并重新启用 [分析器](https://github.com/exercism/go-analyzer/)（例如见 [Issue 16](https://github.com/exercism/go-analyzer/issues/16)），并修复其他 bug
- 完成一个稳定、好用的 [representer](https://github.com/exercism/go-representer/) 版本并正式上线
- 改进/补充练习的解题思路
- 与 [problem specs](https://github.com/exercism/problem-specifications) 同步测试

## 教学大纲概览

### 已有概念

- `basics`
- `strings`和`strings-package`
- `numbers`（基础）和`arithmetic-operators`
- `floating-point-numbers`
- `booleans`
- `comments`
- `conditionals-if`和`comparison`
- `conditionals-switch`
- `structs`
- `type-definitions`
- `slices`
- `iteration`（`for` 循环）
- `functions`（包括多个返回值）
- `maps`
- `range-iteration`
- `runes`
- `pointers`
- `methods`
- `interfaces`
- `errors`
- `zero-values`（包括 nil）
- `type-conversion`
- `type-assertion`
- `constants`
- `string-formatting`
- `packages`（import/export）
- `time`
- `variadic-functions`（引入`...`）
- `randomness`
- `regular-expressions`
- `stringers`

### 未来可能的概念

- `time-duration`
- `integer-types`
- `panic-recover`
- `error-wrapping`（errors.Is、errors.As）
- `bytes`
- `bitwise-operators`
- `goroutines`
- `waitgroups`
- `mutexes`
- `channels`和`select`
- `closures`/`anonymous-functions`/`higher-order-functions`
- `JSON`
- `defer`
- `Buffer`、`io.Reader`/`io.Writer`
- `typed-parameters`（泛型）
- `context`
- 时间辅助函数（ticket、sleep 等）
- `reflection`
- `unsafe`
- `init`
- 函数式选项模式
- 嵌入文件

可能超出概念练习范围的其他主题：

- 工具（go fmt、go vet、go doc 等）
- 编写测试和示例
- 基准测试
- 性能分析
- go generate
- 编译器选项
