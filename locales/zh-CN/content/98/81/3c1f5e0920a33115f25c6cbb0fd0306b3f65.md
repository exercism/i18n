# 说明附录

## 词

定义一个`custom-set`元组，并用`INSTANCE: custom-set set`将其声明为`set`混入类的实例。

- `<custom-set> ( -- set )`：构造一个空集合。
- `>custom-set ( seq -- set )`：从序列构建集合，静默丢弃重复项。

然后为`custom-set`在`members`、`in?`、`adjoin`和`set-like`上提供来自`sets`的`M:`方法。

有了`INSTANCE:`声明和这四个方法后，来自`sets`词汇表的`null?`、`union`、`intersect`、`diff`、`subset?`、`set=`和`intersects?`都会通过协议的默认实现对你的集合生效。测试会直接调用这些词。

`adjoin ( elt set -- )`会原地修改：如果`elt`尚未存在，就把它加入`set`。
