# 克隆 ABAP 学习路径

## 前提条件

1. ABAP 系统 7.4 或更高版本
2. abapGit v1.115.0 或更高版本
3. 创建 ABAP 包、程序和类所需的权限

## 安装 abapGit

ABAP 学习路径及其全部练习都是用一个 abapGit 代码仓库实现的。要把这个学习路径克隆到你自己的系统，你需要先安装 abapGit。

1. 打开 [https://github.com/abapGit/abapGit](https://github.com/abapGit/abapGit)
2. 下载 `zabapgit_standalone.prog.abap` 文件
3. 在你自己的系统中创建程序 `zabapgit_standalone`
4. 把 `zabapgit_standalone.prog.abap` 中的源代码上传到程序 `zabapgit_standalone`
5. 激活该程序

## 安装 Exercism ABAP 学习路径

### 在线代码仓库

如果你的系统已连接互联网，并且能访问 GitHub.com，请使用这种方法（推荐做法）。

1. 运行 abapGit

![abapGit 在线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_01.png?raw=true)

2. 在“Repository Overview”中选择“New Online”
3. 输入以下值
- URL：`https://github.com/exercism/abap`
- Package：`$exer`
- Display Name：`Exercism - ABAP Track`

注意：如果包名太长（比如 `$exercism`），导入代码仓库时会报错。请像上面那样把名称写短一些。

![abapGit 在线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_02.png?raw=true)

4. 选择“Create Online Repository”。你应该会看到一列状态为“A”的对象：

![abapGit 在线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_03.png?raw=true)

5. 选择“Pull”，把所有对象克隆到你的系统。完成后，所有对象的状态都应显示为空白

![abapGit 在线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_04.png?raw=true)

### 离线代码仓库

如果你的系统*没有*连接互联网，请使用这种方法。

1. 打开 [https://github.com/exercism/abap](https://github.com/exercism/abap)
2. 下载该代码仓库的 ZIP 文件

![abapGit 离线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_10.png?raw=true)

3. 运行 abapGit
4. 在“Repository Overview”中选择“New Offline”
5. 输入以下值
- Repository Name：`Exercism - ABAP Track`
- Package：`$exer`

![abapGit 离线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_11.png?raw=true)

6. 选择“Create Offline Repository”

![abapGit 离线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_12.png?raw=true)

7. 选择“Import ZIP”，然后选择下载好的 ZIP 文件。你应该会看到一列状态为“A”的对象：

![abapGit 离线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_13.png?raw=true)

8. 选择“Pull ZIP”，把所有对象克隆到你的系统。完成后，所有对象的状态都应显示为空白

![abapGit 离线代码仓库](https://github.com/exercism/abap/blob/main/docs/clone_14.png?raw=true)

## 卸载 Exercism ABAP 学习路径

你可以用下面的方式从系统中移除所有对象：

1. 运行 abapGit
2. 打开 `Execism - ABAP Track` 代码仓库
3. 选择“Advanced > Uninstall”
4. 确认删除所有对象和该代码仓库

## 疑难解答

- 如果遇到连接问题，请检查 [SSL Setup](https://docs.abapgit.org/user-guide/setup/ssl-setup.html)
- 如果出现错误 `Package $EXERCISM_DIFFERENCE-OF-SQUARES exceeds ABAP 30-characters name limit`，请改用更短的包名，比如 `$exer`。
- 把内容拉取到 ABAP 系统后，有些文件会显示差异。与文件结尾字符或字节顺序标记相关的差异可以忽略。
