# 关于

除了`if`语句，还有`switch`语句，用来按条件执行不同的逻辑。当同一个变量需要与多个可能的值进行比较时，就会用到它。对于某个变量 x，Haxe 中的`switch`语句写法如下。

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

当其他分支都不匹配时，就会执行`default`分支。
