# 关于

函数可以为某一个或多个实参声明[默认值][default-arguments]。

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

- 编译上面的示例时，Elixir 会为 `number/0`（不带实参）和 `number/1`（带一个实参）分别创建函数定义。
- 如果不止一个实参有默认值，这些默认值会从左到右依次应用到函数上，补上缺失的实参。
- 如果函数有多个子句，就必须为默认实参写一个[函数头][function-header]。
- 任何表达式都可以作为默认值。
- 匿名函数不能有默认实参。

```elixir
def guess(number \\ 5)
def guess(number) when number != 5, do: false
def guess(number) when number == 5, do: true

guess()
# => true
```
