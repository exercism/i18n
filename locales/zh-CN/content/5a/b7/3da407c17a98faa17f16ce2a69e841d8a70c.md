# Char

`Char`是 Crystal 中的一种数据类型，表示一个 32 位的 [Unicode][unicode] 码点。它们体积小，因此内存效率高，并具有一些字符串所不具备的属性。字符使用单引号（`'`）创建，其中只能放入一个 Unicode 码点。

```crystal
'a' # => 'a'
'a'.class # => Char
```

在 Crystal 中处理字符串时，经常需要用到字符，因为 String 类中有不少方法会返回字符，或者把字符作为实参。例如，[`String#[]`][index]方法会返回一个字符，[`String#chars`][chars]方法则返回一个字符集合。

## 自增 / 自减

由于字符本身就是一个 32 位的 Unicode 码点，所以支持自增和自减。也就是说，如果你有`'a'`，加一就能得到`'b'`。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

此外，还有一个名为[`Char#succ`][succ]的方法，它返回 Unicode 表中该字符的下一个字符；以及名为[`Char#pred`][pred]的方法，它返回 Unicode 表中该字符的前一个字符。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 拼接

由于字符只用于表示一个 32 位的 Unicode 码点，所以两个字符无法拼接。因此，字符只能与字符串拼接。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 属性方法

Crystal 提供了一些方法来获取字符的信息，比如判断它是数字还是字母，是大写还是小写。下面是其中一些方法的列表，完整列表请见 [Char API][char-api]：

| 方法                           | 说明                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | 如果该字符是数字，返回`true`               |
| [`Char#letter?`][letter]         | 如果该字符是字母，返回`true`               |
| [`Char#lowercase?`][lowercase]   | 如果该字符是小写，返回`true`              |
| [`Char#uppercase?`][uppercase]   | 如果该字符是大写，返回`true`              |
| [`Char#ascii?`][ascii]           | 如果该字符是 ASCII 字符，返回`true`     |
| [`Char#whitespace?`][whitespace] | 如果该字符是空白字符，返回`true` |

## 转换

### 在码点和字符之间转换

由于字符就是一个 32 位的 Unicode 码点，所以可以在字符和码点（Int）之间相互转换。这可以使用[`Char#ord`][ord]方法，它返回该字符的码点；也可以使用[`Int#chr`][chr]方法，它返回该码点对应的字符。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 在类型之间转换

和其他数据类型一样，字符也有一些用于类型转换的方法。最常用的是`Char#to_s`方法，它把字符转换为字符串；此外还有`Char#to_i`方法，把字符转换为整数；以及`Char#to_f`方法，把字符转换为浮点数。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## 转义

和字符串一样，有些字符无法直接书写，要写出它们就需要进行转义。你可以用`\`字符来写一个转义序列，后面跟上你想转义的那个字符。

Crystal 中的特殊字符如下：

| 值    | 说明                   |
| -------- | ----------------------------- |
| `\a`     | 响铃                         |
| `\b`     | 退格                     |
| `\e`     | 转义                        |
| `\f`     | 换页                     |
| `\n`     | 换行          |
| `\r`     | 回车               |
| `\t`     | 水平制表符                |
| `\v`     | 垂直制表符                  |
| `\\`     | 反斜杠                     |
| `\'`     | 单引号                  |
| `\"`     | 双引号                  |
| `\377`   | 八进制 ASCII 字符         |
| `\xFF`   | 十六进制 ASCII 字符   |
| `\uFFFF` | 十六进制 Unicode 字符 |
