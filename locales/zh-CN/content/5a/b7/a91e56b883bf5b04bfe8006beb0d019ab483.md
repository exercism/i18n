# 简介

## R 中的布尔值

真值和假值由 `logical` 类型表示。
它只包含两个值：`TRUE` 和 `FALSE`。

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## 布尔运算符

R 中有五个布尔运算符，但在教学大纲的这个阶段，只有三个是相关的。
另外两个在处理向量时会很重要，它们会在后面几个概念中讲到。

`&&` 是布尔“与”。
如果 `&&` *两侧*的表达式都为 `TRUE`，它就求值结果为 `TRUE`。

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` 是布尔“或”。
只要 `||` *任意一侧*的表达式为 `TRUE`，它就求值结果为 `TRUE`。

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` 是布尔“非”。
它会交换 `TRUE` 和 `FALSE` 的值。

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

对于更长、更复杂的表达式，最好用括号把你的意图表达清楚。

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
