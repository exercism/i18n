# 说明

在这个练习中，你将编写代码来分析汽车工厂里一条装配线的产量。装配线的速度范围从`0`（关闭）到`10`（最高）。

在最低速度（`1`）下，每小时生产`221`辆汽车。产量随速度线性增长。因此当速度设为`4`时，每小时应生产`4 * 221 = 884`辆汽车。不过，速度越高，生产出有缺陷汽车的可能性就越大，这些汽车随后会被报废。下表展示了速度如何影响成功率：

- `1` 到 `4`：成功率 100%。
- `5` 到 `8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有两项任务。

## 1. 计算每小时的生产率

实现`CarsAssemble.productionRatePerHour()`方法，计算装配线每小时的生产率，同时考虑装配线当前的速度和成功率：

```Java
CarsAssemble.productionRatePerHour(6)
// => 1193.4
```

注意，返回值是`double`类型。

## 2. 计算每分钟生产的可用汽车数量

实现`CarsAssemble.workingItemsPerMinute()`方法，计算每分钟生产多少辆可用的汽车：

```Java
CarsAssemble.workingItemsPerMinute(6)
// => 19
```

注意，返回值是`int`类型。
