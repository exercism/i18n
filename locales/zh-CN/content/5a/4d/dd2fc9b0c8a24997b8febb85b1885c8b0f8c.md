# 简介

代码块是一组语句和声明，它们被归入同一个语法单元。
代码块通常用大括号定义，但并非总是如此。
代码块可以嵌套在函数中，也可以嵌套在其他代码块中。

函数在某种程度上类似代码块。
在函数中定义的变量，其标识符在函数外部是看不到的；同样，在代码块中定义的变量，其标识符在代码块外部也看不到。
两个函数中的两个变量可以同名，因为这两个函数看不到彼此的内部；同样，两个代码块中的两个变量也可以同名，因为这两个代码块看不到彼此的内部。
但函数和代码块并不完全相同。
函数不能嵌套在另一个函数中，而代码块可以嵌套在另一个代码块中。

在下面的示例中，`number`定义在`main`函数中。
`flag`定义在嵌套于`main`函数中的`if`代码块里。
在代码块中定义的变量只在该代码块内有效。
因此，尝试编译这段代码会导致编译错误。

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

这个错误信息可能会让人困惑，因为`flag`_确实_在函数的前面被用到了。
然而，`flag`是定义在函数内部的一个代码块里的。
内层代码块可以“看到”外层函数中的变量`number`，但外层函数却无法“看到”定义在其内层代码块中的`flag`变量。
一旦执行离开这个代码块，`flag`变量就会被自动销毁，程序再也无法使用它。
`main`函数本身直到最后一条`printf`语句才第一次看到`flag`这个标识符。
如果删掉最后一条`printf`语句，程序就能编译通过，运行时打印`1`。
这是因为`flag`变量在包含第一条`printf`语句的那个代码块内是有效的。

从`C99`开始，单行的`if`、`for`、`while`和`do`语句也被视为代码块。
在下面的示例中，虽然`i`没有定义在大括号内，但它只存在于由`for`语句定义的那个代码块中，外层`main`函数看不到它。

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

如果删掉最后一条`printf`语句，程序就能编译通过，运行时打印`0 2 4 6 8 10 `。
有些语言（例如 Go 和 Rust）明确规定，单行的条件语句和循环语句也构成一个代码块。
它们要求这类单行语句仍然要用大括号括起来。
