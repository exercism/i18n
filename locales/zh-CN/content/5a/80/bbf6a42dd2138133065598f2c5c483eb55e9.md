# 关于

处理文件的函数由[`File`][file]模块提供。

要读取整个文件，使用[`File.read/1`][file-read]。要写入文件，使用[`File.write/2`][file-write]。

该模块还提供用于复制、删除、重命名等操作的文件函数。它们的名称与 UNIX 中的对应命令相似，例如：

- [`File.cp/3`][file-cp]：复制文件。
- [`File.rm/1`][file-rm]：删除文件。
- [`File.rename/2`][file-rename]：重命名或移动文件。
- [`File.mkdir/1`][file-mkdir]：创建目录。
- [`File.cwd/0`][file-cwd]：获取当前工作目录。

上面提到的 `File` 模块中的所有函数都有一个带`!`的变体，它抛出错误，而不是返回错误元组（例如[`File.read!/1`][file-read-bang]）。如果你不打算处理文件不存在、权限不足这类错误，就用这个变体。

```elixir
File.read("does_not_exist")
# => {:error, :enoent}

File.read!("does_not_exist")
# => ** (File.Error) could not read file "does_not_exist": no such file or directory
#        (elixir 1.10.4) lib/file.ex:353: File.read!/1
```

## 文件与进程

每次用[`File.write/2`][file-write]写入文件时，都会打开一个文件描述符，并启动一个新的 Elixir [进程][exercism-processes]。因此，应避免在循环中使用[`File.write/2`][file-write]写入文件。

改用[`File.open/2`][file-open]打开文件。[`File.open/2`][file-open]的第二个实参是一个模式列表，用来指定你是想以读取还是写入的方式打开文件。

常用的模式有：

- `:read`：以读取方式打开，文件必须存在
- `:write`：以写入方式打开，文件不存在时会创建，已有内容会被覆盖
- `:append`：以写入方式打开，文件不存在时会创建，已有内容会保留

完整的模式列表见[`File.open/2`][file-open]的文档。

[`File.open/2`][file-open]返回处理该文件的进程的 PID。要读写该文件，使用[`IO`][io]模块中的函数，并把这个 PID 作为 [IO 设备][io-io-devices]传入。

文件用完后，用[`File.close/1`][file-close]把它关闭。

```elixir
file = File.open!("README.txt", [:write])
# => #PID<0.157.0>

IO.puts(file, "# README")
# => :ok

File.close(file)
# => :ok
```

## 流式处理文件

用[`File.read/1`][file-read]读取文件会一次性把整个文件加载到内存中。处理非常大的文件时，这可能是个问题。要高效地处理它们，你可以用[`File.open/2`][file-open]和[`IO.read/2`][io-read]逐行读取文件，也可以用[`File.stream/3`][file-stream]把文件当作流来处理。这个流同时实现了[`Enumerable`][enumerable]和[`Collectable`][collectable]这两种协议，也就是说，它既能用来读取，也能用来写入。

```elixir
File.stream!("file.txt")
|> Stream.map(&(&1 <> "!"))
|> Stream.into(File.stream!("new_file.txt"))
|> Stream.run()
```

## 路径

所有处理文件的函数都需要一个文件路径。文件路径可以是绝对路径，也可以是相对于当前目录的相对路径。要操作路径，使用[`Path`][path]模块中的函数。为了跨平台兼容，请用[`Path.join/1`][path-join]来创建路径，它会选择适合当前平台的分隔符。

```elixir
Path.expand(Path.join(["~", "documents", "important.txt"]))
"/home/user/documents/important.txt"
```
