# 说明

你的任务是找到完美的餐桌座位安排。
为此，你需要声明_事实_（总是为真的事情）和_规则_（在特定条件下为真的事情）。

## 1. 列出健谈的人

定义`chatty`事实来表示健谈的人。
`chatty`事实接受一个实参：健谈的人的小写名字。

```prolog
chatty(gustavo).
true.
```

## 2. 列出谁喜欢谁

定义`likes`事实来表示谁喜欢谁。
`likes`事实接受两个实参：

1. 喜欢对方的人的小写名字
2. 被喜欢的人的小写名字

```prolog
likes(esteban, malena).
true.
```

## 3. 互相喜欢的人能组成好的配对

当两个人互相喜欢时，定义`pairing`规则为真。
该配对规则接受两个实参：

1. 第一个人的小写名字
2. 第二个人的小写名字

```prolog
pairing(malena, esteban).
true.
```

## 4. 健谈的人可以和任何人配对

当被配对的两个人中（至少）有一个是健谈的人时，定义`pairing`规则为真。

```prolog
pairing(valeria, jaime).
true.
```

## 5. 检查座位安排

当五对都是好的配对时，定义`seating`规则为真。

该配对规则接受五个实参：

1. 第一个人的小写名字
2. 第二个人的小写名字
3. 第三个人的小写名字
4. 第四个人的小写名字
5. 第五个人的小写名字

使用刚刚定义的事实和规则来检查座位安排。

```prolog
seating(esteban, jaime, gustavo, malena, valeria).
false.
```
