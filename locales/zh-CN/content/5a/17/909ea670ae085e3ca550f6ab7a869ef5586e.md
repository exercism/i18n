# 安装 [Scala](http://www.scala-lang.org)

除了 Exercism CLI 和你常用的文本编辑器之外，用 Exercism 练习 Scala 还需要一些额外的工具。

这些工具都可以用`Coursier`自动安装。

详情请见[下载页面](https://www.scala-lang.org/download/)。

---

运行`cs setup`之后，你就可以开始学习 Exercism 的 Scala 学习轨道了。

要开始学习，请参见“[运行测试](https://exercism.org/docs/tracks/scala/tests)”。

---

# Scala 的 IDE

* [在 VS Code 中使用 Metals](https://scalameta.org/metals/docs/editors/vscode)
* [在 Vim 或 Neovim 中使用 Metals](https://scalameta.org/metals/docs/editors/vim)
* [在 Gitpod 等在线 IDE 中使用 Metals](https://scalameta.org/metals/docs/editors/online-ides)
* [在 Zed 中使用 Metals](https://github.com/scalameta/metals-zed)
* [安装了 Scala 插件的 IntelliJ IDEA](https://www.jetbrains.com/idea/)
