# 介绍

## for 循环

`for`语句会重复执行一个代码块。它的第一行决定这个代码块重复执行多少次：

```go
for init; condition; post {
    // loop body
}
```

- **init**语句在第一次迭代之前运行一次。通常会声明并初始化一个供循环使用的计数器变量。
- **condition**是一个布尔表达式，在每次迭代前求值。当它求值为`false`时，循环就会停止。
- **post**语句在每次迭代完成后运行。可以用它来更新计数器。

不要用括号把`init; condition; post`括起来。不过，包裹循环体的花括号`{ }`始终是必需的。

这个循环让`i`从`1`开始，打印`i`的当前值，为下一次迭代将它自增，并在`i`达到`10`时停止：

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
