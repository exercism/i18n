# 数字类型

Crystal 有多种不同的数字类型，适用于各种用途。
例如，有些类型速度更快，但可能值的范围比另一些更小。
有些类型可能值的范围更大，但速度更慢。

在 Crystal 中，既有有符号整数类型，也有无符号整数类型。
有符号整数类型可以是正数或负数。
无符号整数类型只能是正数。

## 有符号整数类型

这些是 Crystal 中的[有符号整数类型][int]：

| 类型     | 大小（位） | 范围                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 到 127                                                                                                 |
| `Int16`  | 16          | -32_768 到 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 到 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 到 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 到 170_141_183_460_469_231_731_687_303_715_884_105_727 |

较小的类型占用内存更少，速度也比更大的类型更快，但可能值的范围更小。

如果你知道值会在某个范围内，最好使用尽可能小的类型来节省内存并提升性能。

默认整数类型是`Int32`。
要声明具有特定类型的整数，可以添加`<number>_I <bit>`，也就是把类型名作为后缀。

```crystal
1_i8.class
# => Int8
```

可以使用`to_i<bit>`方法在不同整数类型之间转换。
`to_i`方法会转换为默认整数类型`Int32`。

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## 无符号整数类型

这些是 Crystal 中的[无符号整数][uint]类型：

`UInt8`、`UInt16`、`UInt32`、`UInt64`、`UInt128`

有符号整数和无符号整数唯一的区别是，无符号整数只能是正数。
要声明具有特定类型的无符号整数，可以添加`<number>_u<bit>`，也就是把类型名作为后缀。
可以使用`to_u<bit>`方法在不同无符号整数类型之间转换。
`to_u`方法会转换为默认无符号整数类型`UInt32`。

```crystal
1_u8.to_u16.class
# => UInt16
```

## 浮点数类型

这些是 Crystal 中的浮点数类型：

| 类型      | 大小（位） | 范围                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 到 3.4E+38   |
| `Float64` | 64          | 2.3E-308 到 1.7E+308 |

有两种不同的[浮点数类型][float]，其中一种比另一种更精确。

默认浮点数类型是`Float64`。

可以使用`to_f<bit>`方法在不同浮点数类型之间转换。
`to_f`方法会转换为默认浮点数类型`Float64`。

## 运算后的类型

当你在两个数字之间执行运算时，结果的类型将是精度最高的数字的类型。
浮点数比整数更精确，整数比无符号整数更精确。
而`Float64`比 Float32 更精确，依此类推。

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## 深入探索：无符号整数与有符号整数

~~~~exercism/advanced
在底层，无符号整数和有符号整数的区别在于，有符号整数用第一位来存储符号。
符号要么为正，要么为负。
对于无符号整数，第一位用来存储数值。
因此，有符号 32 位整数的最大值是 2^31 - 1。
无符号 32 位整数的最大值是 2^32 - 1。

如果你想进一步了解有符号和无符号的区别，可以在[维基百科](https://en.wikipedia.org/wiki/Signedness)上阅读更多内容。
~~~~
