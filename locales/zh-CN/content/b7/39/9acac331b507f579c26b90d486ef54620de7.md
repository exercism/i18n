# 简介

在 Haxe 中，可以用异常来安全地处理代码运行时出现的错误。所有异常都应包含一条描述该错误的消息。我们可以使用`throw`关键字来_抛出_异常：

```haxe
public function main(num:Int) {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
  // ...
}
```

异常被抛出时，代码会去寻找负责处理这个错误的代码段。如果找不到，程序在显示错误消息的同时，也会停止运行。

要在 Haxe 中处理异常，我们使用`try-catch`块。这种语句由一个`try`块和一个或多个`catch`块组成。`try`块会_尝试_执行一段代码，而`catch`块则等待异常抛出并将其_捕获_，这样程序就不会中止运行。当`catch`块捕获到异常时，它还会执行块内的所有内容：

```haxe
try {
  if (num < 10) {
    throw "Argument num cannot be greater than 10";
  }
} catch (e) {
  // All exceptions will be caught here
  trace(e.message); // Argument num cannot be greater than 10
}
```

`catch`块的实参类型应当省略。
