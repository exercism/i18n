# 简介

## 数字与字符串

AWK 是一门非常小的语言，只有几种基本数据类型。
本课将介绍数字和字符串。

### 数字

在 AWK 中，数字以双精度浮点数的形式实现。
整数、浮点数和双精度数之间没有区分。

AWK 支持八进制数字常量（以`0`开头）和十六进制数字常量（以`0x`或`0X`开头）。

#### 数值运算

你可以使用标准算术运算符`+`、`-`、`*`、`/`、`%`。
幂运算符是`^`。
AWK 还有一些内置的数值函数，包括三角函数、随机数生成，以及把数字截断为 _x_ 与零之间最接近整数的`int(x)`。

### 字符串

AWK 字符串是字符组成的序列。
用双引号来表示字符串常量。

#### 字符串运算

字符串运算只有一种：拼接。
拼接没有专门的运算符，
只要把两个字符串并排放在一起，它们就会拼接起来：

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print`是**语句**，不是函数。
`print`不需要括号。
~~~~

AWK 有大量用于处理字符串的函数。
随着我们在这条学习路径上不断深入，我们会全面地认识它们。

### 数字与字符串之间的转换

数字和字符串之间没有显式的转换运算符。
AWK 会根据程序的上下文隐式地完成转换。
这让处理输入字段的值变得非常简单：AWK 通常就按你的想法行事。

* `print x + y`会借助`+`的数值运算，把`x`和`y`变量的值转换为数字。
* `print x y`会借助拼接运算，把`x`和`y`变量的值转换为字符串。

如果你想显式地转换，`0 + x`会给出 _x_ 的数字表示，`"" x`会给出 _x_ 的字符串表示。

#### 从字符串到数字

AWK 把字符串转换为数字的方式可能会让人困惑。
一个简单的理解方式是：AWK 会从字符串开头开始读取“数字字符”，直到遇到“非数字”字符为止。
例如：

* `"2.5"`转换为数字`2.5`；
* `"1e3"`转换为数字`1000`（科学计数法）；
* `"456abc"`转换为数字`456`（因为`a`不是“数字”，转换到此停止）。
* `"abc789"`转换为数字`0`（字符串**开头**没有数字）。
