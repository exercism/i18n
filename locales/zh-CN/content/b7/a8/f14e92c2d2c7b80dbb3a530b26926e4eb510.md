# 打印

在 Cairo 中，打印让你可以把消息和值显示到控制台，从而更容易调试程序，或在执行过程中传达信息。

打印系统既灵活又直观，提供了格式化并输出各种类型数据的工具。

## 打印基础

Cairo 提供了两个主要的宏，用来把文本打印到控制台：

- **`println!`**：在新的一行上输出。
- **`print!`**：在同一行内输出，不添加换行。

两个宏都以`ByteArray`作为主要参数，它可以是简单的字符串，也可以是带有值占位符的格式化字符串。

```rust
// Printing a simple message
println!("Hello, Cairo!");

// Printing with values
let x = 10;
let y = 20;
println!("Values: x = {}, y = {}", x, y);
```

在上面的例子中：

- `{}`占位符会被`x`和`y`的值替换。
- `println!`会确保输出以换行结束。

## 格式化字符串

有时，你可能需要先创建一个格式化字符串，而不立即打印它。

`format!`宏可以帮你做到这一点。

它的工作方式与`println!`类似，但返回一个`ByteArray`，而不是把输出发送到控制台。

```rust
let s1: ByteArray = "tic";
let s2: ByteArray = "tac";
let s3: ByteArray = "toe";

// Create a formatted string
let result = format!("{s1}-{s2}-{s3}");

println!("{}", result); // Output: tic-tac-toe
```

在这个例子中：

- `format!`把`s1`、`s2`和`s3`合并成一个字符串，并用短横线（`-`）分隔。
- 生成的字符串可以在之后重复使用或打印。

## 打印自定义数据类型

默认情况下，Cairo 只能打印整数和字符串这类基本类型。

如果你想打印自定义类型，比如结构体，那么除非该类型实现了`Display`或`Debug` trait，否则就会遇到错误。

### 使用`Display`进行自定义格式化

`Display` trait 让你可以定义自定义类型应该如何打印。

下面是一个例子：

```rust
use core::fmt::{Display, Formatter, Error};

struct Point {
    x: u8,
    y: u8,
}

impl PointDisplay of Display<Point> {
    fn fmt(self: @Point, ref f: Formatter) -> Result<(), Error> {
        write!(f, "Point({}, {})", *self.x, *self.y)
    }
}

let p = Point { x: 3, y: 4 };
println!("{}", p); // Output: Point(3, 4)
```

在这个例子中：

- `fmt`函数定义了`Point`结构体如何转换成可打印的字符串。
- `write!`宏把格式化后的字符串追加到`Formatter`上。

### 用`Debug`调试

为了便于调试，Cairo 提供了`Debug` trait。

对大多数类型，你可以自动派生它，从而快速轻松地打印结构体的内部细节。

```rust
#[derive(Debug)]
struct Point {
    x: u8,
    y: u8,
}

let p = Point { x: 3, y: 4 };
println!("{:?}", p); // Output: Point { x: 3, y: 4 }
```

在这个例子中：

- `#[derive(Debug)]`会自动生成`Debug` trait 的实现。
- `{:?}`占位符告诉`println!`使用`Debug` trait 来格式化。

## 以十六进制打印

Cairo 允许使用`{:x}`占位符以十六进制格式打印整数。

```rust
let value: u32 = 255;
println!("{:x}", value); // Output: ff
```

在处理底层数据表示时，这尤其有用。
