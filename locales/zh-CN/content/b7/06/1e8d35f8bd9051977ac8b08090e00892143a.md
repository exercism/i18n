# Getter 和 setter

Getter 和 setter 是方法，可以用来读取和写入对象属性的值。
Crystal 有宏，因此为属性定义 getter 和 setter 很容易。
宏是一种在编译时生成代码的方式，后面的宏概念会详细讲解。

在 Ruby 中，这些方法是使用 `attr_reader`、`attr_writer` 和 `attr_accessor` 方法定义的，表面上和 Crystal 的实现非常相似。
Crystal 把它们定义成了 `getter`、`setter` 和 `property` 宏。

## Getter

Getter 是一个宏，它定义的方法会返回实例变量的值。
这意味着，当你想访问实例变量时，不再需要在它前面写上 `@`（在方法中，`initialize` 除外）；取而代之的是，你可以调用 getter 宏所定义的方法。

getter 宏可以接受多个实例变量，用逗号分隔即可。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name
    @name
  end

  def age
    @age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  getter name, :age
end
```

可以看到，使用 getter 能减少你要写的代码量，也让代码更容易阅读。
另外，Ruby 和 Crystal 还有一处区别：Crystal 的 getter 宏既接受变量名，也接受 symbol 作为参数。
Symbol 会在后面的 symbol 概念中讲到。

## Setter

Setter 是一个宏，它定义的方法用于设置实例变量的值。
这个宏并不常见，通常会用 `property` 宏代替。
创建出来的方法形如 `name_of_method=`；正是 `=` 让属性可以被设置。

这种方法的定义有点特殊，因为方法接收的参数写在 `=` 之后。
Crystal 中还有其他几个特殊方法使用这种语法，比如 `+` 方法。

和 getter 宏一样，定义好 setter 之后，当你想更新实例变量的值时，可以调用 setter 宏所定义的方法。

```crystal
# This:
class Person
  @name : String
  @age : Int32

  def name=(name : String)
    @name = name
  end

  def age=(age : Int32)
    @age = age
  end
end

# Is the same as this:
class Person
  @name : String
  @age : Int32

  setter name, :age
end
```

## Property

Property 是一个宏，它同时为实例变量定义 getter 和 setter。

```crystal
class Person
  @name : String
  @age : Int32

  property name, :age
end
```
