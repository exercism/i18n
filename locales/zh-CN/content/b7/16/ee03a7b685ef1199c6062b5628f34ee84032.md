# 说明

在本练习中，你将编写一些代码，帮助你为购买新车辆做准备。

共有三个任务：一个是帮你确定你能负担得起的车辆价格，一个是判断你是否需要驾照，还有一个是帮你计算注册费。

## 1. 计算你能否负担得起某辆车的月供

你所在城市的车辆经销商都在推出 5 年期、0% 利率的促销活动，你想好好利用一下。
实现 `canibuy(vehicle, price, monthly_budget)` 函数，它接收你正在看的车辆名称、它的价格以及你的月度预算，返回一个字符串，告诉你是否负担得起这辆车；如果月供与你的月度预算相差不超过 10，你就要返回一条特别的提醒，提醒自己节俭一些：

```julia-repl
julia> canibuy("1974 Ford Pinto", 516, 100)
"Yes! I'm getting a 1974 Ford Pinto."

julia> canibuy("2014 Bugatti Veyron", 562_500, 5000)
"Damn! No 2014 Bugatti Veryon for me."

julia> canibuy("2020 Gazelle Medeo", 3000, 50)
"I'll have to be frugal if I want a 2020 Gazelle Medeo."
```

~~~~exercism/note
Julia 中的数字可以包含 `_`，用来把数字分组。
例如，`562_500` 等于 `562500`。
~~~~

## 2. 判断你是否需要驾照

如果你决定买一辆汽车，就需要驾照。
自行车不需要驾照。
实现 `licence(vehicle, kind)` 函数，它接收车辆的名称以及车辆的种类（`"car"` 或 `"bike"`），返回你是否需要驾照：

```julia-repl
julia> licence("2014 Bugatti Veyron", "car")
"The 2014 Bugatti Veyron requires a licence to operate."

julia> licence("2020 Gazelle Medeo", "bike")
"The 2020 Gazelle Medeo requires no licence to operate."
```

## 3. 计算新车的注册费

你新车的注册费根据以下公式计算：

- 自行车无需注册，因此费用为 0€。
- 对于车龄 10 年及以上的汽车，费用固定为 25€。
- 对于更新的汽车：
  1. 先确定一个基础费用：取汽车的制造商标准零售价（MSRP）或 25&nbsp;000€ 中较大的那个。
  2. 车龄每增加一年，就减去基础价格的 10%。
  3. 再用这个值除以 100，得到的就是你需要支付的注册费。

实现 `fee(msrp, age, kind)` 函数，它接收车辆的 MSRP、车龄（年）以及车辆的种类（`"car"` 或 `"bike"`），并根据上面的公式返回该车辆的注册费。

```julia-repl
julia> fee(562_500, 6, "car")
2250

julia> fee(25_000, 3, "car")
175

julia> fee(34_000, 30, "car")
25

julia> fee(3000, 0, "bike")
0
```
