# 简介

当程序或代码中出现错误或意料之外的情况时，用错误来报告会很有用。

错误是 JavaScript 对象。

这个对象的主要属性是 `message`：

```javascript
const error = new Error('Oops, something went wrong');

console.log(error.message);
// => "Oops, something went wrong"
```

使用 `throw` 语法可以抛出一个错误。

```javascript
throw new Error('Oops');
```

当抛出 `Error` 时，当前的执行会停止，然后在调用栈的第一个 catch 块中恢复执行。

```javascript
try {
  throw new Error('Oops');
} catch (error) {
  console.log(error.message);
  // => "Oops"
}
```

和 JavaScript 中的任何类一样，子类可以使用 `extends` 关键字继承 `Error`，从而创建自定义错误。
`instanceof` 语法会检查捕获到的错误是否是 `Error` 某个特定子类的实例。

```javascript
class CustomError extends Error {}

try {
  // ... Code that may throw an error
} catch (error) {
  if (error instanceof CustomError) {
    console.log('The error thrown is an instance of the CustomError');
  }
}
```
