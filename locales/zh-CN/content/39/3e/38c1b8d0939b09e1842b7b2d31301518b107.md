# 说明

Lucian 的女朋友正在回家的路上，而他还没做好他们的周年纪念晚餐！

在这个练习中，你将编写一些代码，帮助 Lucian 按照他最喜欢的食谱做出一份美味的千层面。

这个练习共有四个任务，都与做千层面所花的时间有关。

## 1. 定义预期的烤箱时间（分钟）

定义常量 `EXPECTED_MINUTES_IN_OVEN`，表示千层面应该在烤箱里烤多少分钟。它必须被导出。根据这本食谱，预期的烤箱时间是 `40` 分钟。

## 2. 计算剩余的烤箱时间（分钟）

实现 `remainingMinutesInOven` 函数，它接收千层面已经在烤箱里烤了多少分钟作为_形参_，并_返回_千层面还需要在烤箱里烤多少分钟，这个值根据上一个任务中的**预期烤箱时间（分钟）**计算得出。

```javascript
remainingMinutesInOven(30);
// => 10
```

## 3. 计算准备时间（分钟）

实现 `preparationTimeInMinutes` 函数，它接收你往千层面里加了几层作为_形参_，并_返回_你准备千层面花了多少分钟，假设每加一层需要 2 分钟。

```javascript
preparationTimeInMinutes(2);
// => 4
```

## 4. 计算总工作时间（分钟）

实现 `totalTimeInMinutes` 函数，它接收_两个形参_：`numberOfLayers` 是你往千层面里加的层数，`actualMinutesInOven` 是千层面已经在烤箱里烤了多少分钟。这个函数应该_返回_你烹饪千层面总共花了多少分钟，也就是准备时间（分钟）与千层面此刻在烤箱里所花分钟数之和。

```javascript
totalTimeInMinutes(3, 20);
// => 26
```
