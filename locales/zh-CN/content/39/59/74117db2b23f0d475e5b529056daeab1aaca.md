# 说明

无板篮球训练从跑圈开始。教练让每一圈都比上一圈稍微长一点：第一圈 100 米，第二圈 110 米，第三圈 120 米，以此类推，每圈多 10 米。

三个任务都写在`WARM_UP_LAPS`类中。

## 1. 总共多远？

给定圈数，算出总距离。

```sather
WARM_UP_LAPS::distance_run(3)
-- => 330
```

也就是 100 + 110 + 120。0 圈就是 0 米。

## 2. 多少圈才能达到指定距离？

给定一个距离（单位：米），要跑多少圈，总距离才能至少达到这个数？

```sather
WARM_UP_LAPS::laps_to_reach(330)
-- => 3
WARM_UP_LAPS::laps_to_reach(331)
-- => 4
```

0 米不用跑任何一圈。

## 3. 哪一圈最先变长？

给定一个距离（单位：米），哪一圈*本身*的长度最先超过它？第 1 圈是 100 米，第 2 圈是 110 米，以此类推。

```sather
WARM_UP_LAPS::first_long_lap(115)
-- => 3
```

第 3 圈是 120 米，是第一个超过 115 的一圈。
