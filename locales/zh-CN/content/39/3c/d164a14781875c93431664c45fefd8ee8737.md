# 元组

Elm 中的元组可以容纳 2 个或 3 个值，每个值都可以是任意类型。
在 Elm 中，元组大多用于简单的临时类型。
因此，元组最多只有 3 个值，而且为了进一步引导，也只针对 2 个值提供了便捷函数。
数据更复杂时，最好改用记录。
一个常见的用途是需要从函数返回多个值。
元组的字段没有名字，要通过解构或按位置来访问。

你可以阅读[元组简明介绍][tuples-concise]。
还有[更深入的介绍][tuples-in-depth]，[Tuple 模块的 API 文档][tuple-core]中也包含代码示例和详细文档。

## 声明

元组的类型用圆括号创建，各个元素类型之间用逗号分隔。

```elm
type alias IntStringTuple = (Int, String)
```

### 创建

元组用圆括号创建，各个元素之间用逗号分隔。

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

你也可以用`Tuple.pair`创建包含 2 个值的元组。

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### 访问

还有按位置访问元组值的函数：`Tuple.first`和`Tuple.second`。

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

使用元组模式匹配，可以在绑定中对元组进行_解构_。
解构可以在 `let` 表达式、函数声明和 `case` 语句中进行。

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

`case` 语句中的模式匹配还允许你匹配值的内容：

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
