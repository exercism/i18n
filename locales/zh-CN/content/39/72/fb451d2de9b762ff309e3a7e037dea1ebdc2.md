# 简介

`Enum`是一个非常实用的模块，提供了一组用于处理可枚举数据的算法。它可以排序、筛选、分组、计数、搜索、查找最大值和最小值，等等。

一般来说，_可枚举_是指任何可以被迭代的数据，也就是一个集合。在 Elixir 中，可枚举类型是指任何实现了 `Enumerable`[协议][exercism-protocols]的数据类型。其中最常见的是[列表][exercism-lists]和[映射][exercism-maps]。

很多`Enum`函数都接受一个函数作为实参。

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

最常用的`Enum`函数是`map`和`reduce`。

## `map/2`

`Enum.map/2`可以让你把可枚举数据中的每个元素替换成另一个元素。`Enum.map/2`的第二个实参是一个函数，它接受原来的元素，并返回替换后的元素。

## `reduce/3`

`Enum.reduce/3`可以让你把整个可枚举数据_归约_成一个值。为此，需要用一个特殊的变量，叫做_累加器_。累加器在每次迭代之间保存归约的中间状态。

`Enum.reduce/3`的第二个实参是累加器的初始值。第三个实参是一个函数，它接受一个元素和一个累加器，并返回累加器的新值。

## 处理映射

把映射传给`Enum`函数时，映射会自动转换成一个列表，其中的元素是 2 元的`{key, value}`元组。

要把它转换回映射，可以使用`Enum.into/2`。`Enum.into/2`是一个把可枚举数据转换成可收集结构的函数。可收集结构是指任何实现了 `Collectable`协议的数据结构。可以把它看作`Enum.reduce/3`的反操作。

`Enum`还有`Enum.into/3`。`Enum.into/3`是`Enum.into/2`的一个变体，它接受一个转换函数，在把可枚举数据转换成可收集结构的过程中应用。

### 映射的映射

除了用`Enum.into/3`，或者用`Enum.map/2`加`Enum.into/2`来对映射做转换（映射）之外，还可以使用专门的`Map.new/2`函数。它的工作方式和`Enum.into/3`完全一样，都接受一个可枚举数据和一个转换函数，但它总是返回一个新的映射，而不允许我们选择可收集结构。
