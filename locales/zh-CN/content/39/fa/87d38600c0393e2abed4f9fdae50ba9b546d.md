# 简介

Common Lisp 中的哈希表是一种用于存储关联数据的数据结构。
它把键（可以是任意对象）映射到值（也可以是任意对象）。
其他语言可能把这一概念称为映射、字典或哈希。

## 创建哈希表

哈希表可以用`make-hash-table`函数创建。

`(make-hash-table) ; => #<HASH-TABLE :TEST EQL :COUNT 0 {10024AD2B3}>`

（注意，哈希表的打印形式取决于具体实现，所以在你的 REPL 中显示的样子可能不同。）

## 按键取值

要从哈希表中按键取出值，可以使用`gethash`函数：

```lisp
*h* ; => #<HASH-TABLE :TEST EQL :COUNT 3 {10024AD2B3}>`
(gethash :foo *h*) ; => :bar
                   ;    T
```

`gethash`会返回[多个值][concept-multiple-values]，这会在另一个概念中讲解。

## 插入值

要向哈希表中插入值，可以像这样把`setf`和`gethash`搭配使用：

`(setf (gethash :foo *hash-table*) :bar) : => :bar`

这会把哈希表`*hash-table*`中键`:foo`对应的值修改为`:bar`。
它会返回这个值。

`setf`的用法会在另一个概念中讲解。
