# 简介

R 中的`list`是元素的有序集合，它与`vectors`有几点不同：

- 元素可以是不同的类型（例如把`numeric`和`character`混在一起）。
- 元素可以是复杂的结构（例如向量、其他列表等）。
- 访问元素所用的语法有些不同。

与其他语言作类比并不精确。 
R 的`list`有点类似于 Python 的字典，不过`list`是有序的，可以通过数字下标访问。
它有点类似于 C 的`struct`，只是`list`可以在运行时轻松扩展。

## 创建列表

给元素起名字（通常称为“标签”）在列表中比在向量中更常见：

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

不过标签是可选的，此时 R 会改用下标编号：

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## 访问列表元素

有三种方法可以做到，各自适用于不同的场景。

### 1. 使用`$tag`表示法

如果事先知道标签名，这种写法非常常用。

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. 使用`[[tag]]`表示法

这种写法的优点是，标签名可以在运行时再决定。
注意这里用的是双括号。

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. 使用位置下标

无论列表有没有标签，这种方法都有效。
同样，括号要写双层。

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## 添加和删除元素

很简单：给某个元素赋值时，如果它已经存在就修改，如果是新的就插入。

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

要删除，就给不想要的元素赋`NULL`。

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
