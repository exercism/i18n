# configlet 生成文档

[configlet](/docs/building/configlet) 的次要用途是生成文档。

## 用法

可以用 `generate` 命令从模板生成 instructions/introductions 文档。

```
configlet [global-options] generate

Global options:
  -h, --help                   Show this help message and exit
      --version                Show this tool's version information and exit
  -t, --track-dir <dir>        Specify a track directory to use instead of the current directory
  -v, --verbosity <verbosity>  The verbosity of output. Allowed values: q[uiet], n[ormal], d[etailed]
```

## 文档

以下是 configlet 可以生成的文档。

### 文档：概念练习的 introduction.md 文件

每个[概念练习](/docs/building/tracks/concept-exercises)都有一个[`introduction.md`文件](/docs/building/tracks/concept-exercises#docsintroductionmd)。每个练习还可以有一个可选的[`introduction.md.tpl`文件](/docs/building/tracks/concept-exercises#docsintroductionmdtploptional)。

模板文件应当像普通的 Markdown 文件一样处理，但多了一项功能：可以指定占位符。支持以下占位符：

- `%{concept:<slug>}`：指向该概念的[`introduction.md`文档](/docs/building/tracks/concepts#fileintroductionmd)

当 configlet 检测到某个概念练习有`introduction.md.tpl`文件时，它会根据该文件生成一个`introduction.md`文件。生成的 introduction 内容与模板相同，只有其中的占位符会被替换为它们所指文档的内容。

### 文档：实践练习的 introduction.md 文件

当 configlet 检测到某个实践练习实现了某个带有`introduction.md`文件的[问题规范练习](https://github.com/exercism/problem-specifications/)时，configlet 会把该实践练习的`.meta/introduction.md`文件与问题规范练习的`introduction.md`文件同步。

### 文档：实践练习的 instructions.md 文件

当 configlet 检测到某个实践练习实现了某个[问题规范练习](https://github.com/exercism/problem-specifications/)时，configlet 会把该实践练习的`.meta/instructions.md`文件与问题规范练习的`instructions.md`文件同步；如果没有找到`instructions.md`文件，则改为与其`description.md`文件同步。

### 文档：实践练习的 .meta/config.json 文件

当 configlet 检测到某个实践练习实现了某个[问题规范练习](https://github.com/exercism/problem-specifications/)时，configlet 会把问题规范练习的`metadata.yml`文件中的`source`和`source_url`键同步到该实践练习`.meta/config.json`文件中的`source`和`source_url`属性。
