# 说明

你的一位朋友有一家老式批发店，名叫**Gross Store**。

这个名字来自这家店出售商品的数量：它们全都以[罗][gross-unit]为单位。

朋友请你为他的店实现一个销售点（POS）系统。

**首先，你想为它做一个原型。**

**在你的原型里，系统只记录数量。**

你的朋友给了你一份测量单位清单，方便你参考：

| 单位               | 数值 |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. 在程序中存储计量单位

为了使用这些计量单位，你需要在程序中把它们存储起来。

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. 创建新的顾客账单

你需要实现一个函数，为顾客创建一张新的（空的）账单。

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. 向顾客账单中添加商品

要实现这一点，你需要：

- 如果给定的`unit`不在`units`映射中，返回`false`。
- 否则把商品加入顾客的`bill`，以商品名称为索引，然后返回`true`。
- 如果该商品已经在账单里，就按所给`unit`对应的数值增加它的数量。

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> 注意，返回值的类型是`bool`。

## 4. 从顾客账单中移除商品

要实现这一点，你需要：

- 如果给定的商品**不在**账单中，返回`false`。
如果某件商品的数量为 0，就认为它不在账单中。
- 如果给定的`unit`不在`units`映射中，返回`false`。
- 如果新的数量会小于 0，返回`false`。
- 如果新的数量是 0，就认为该商品已从`bill`中移除，此时返回`true`。
- 否则，减少该商品的数量并返回`true`。

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> 注意，返回值的类型是`bool`。

## 5. 返回顾客账单中某件商品的数量

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> 注意，返回值的类型是`u32`。
