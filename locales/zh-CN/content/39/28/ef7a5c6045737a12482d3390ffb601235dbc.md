# 数字

`INT`是 Sather 中表示整数的类型：`0`、`7`、`-3`。一个返回整数的例程会在冒号后面写明这一点，就像返回文本的例程会写上`STR`一样。

```sather
   goals : INT is
      return 42;
   end;
```

例程可以接受**实参**，也就是调用例程时传入的值。每个实参都有一个名字和一个类型，写在例程名后面的括号里：

```sather
   total(first : INT, second : INT) : INT is
      return first + second;
   end;
```

当两个实参的类型相同时，可以把它们写在一起：

```sather
   total(first, second : INT) : INT is
```

调用时，把值放进括号里：

```sather
SCORES::total(3, 4)     -- this is 7
```

算术运算符有五个：`+`、`-`、`*`、`/`和`%`。

`/`作用在两个`INT`上时，做的是**整数除法**：它会舍弃余数，而不是给出小数。

```sather
7 / 2      -- 3, not 3.5
```

`%`给出的是那次除法剩下的部分。

```sather
7 % 2      -- 1
```

两者是一致的：`7`就是`3`个`2`，还剩下`1`。
