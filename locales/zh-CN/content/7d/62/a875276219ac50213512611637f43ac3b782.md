# 简介

在 Exercism 上，你解决的每道练习都会附带一份示例解答。
在 Julia 轨道上，这些解答通常包含[文档字符串](https://en.wikipedia.org/wiki/Docstring)。
完成这道练习后，你将了解文档字符串的结构、如何编写它们，以及如何通过 REPL 访问文档字符串。

~~~~exercism/note
在 Julia 轨道上做练习时，如果你不想为函数写文档字符串，也可以不写。
~~~~

## 语法

紧挨在任何一种 Julia 对象（例如函数或类型）前面的字符串，都会被解释为记录该对象的文档字符串。
例如：

```julia
"Tell a joke."
joke() = ...
```

Julia 中的文档字符串使用 [Markdown](https://en.wikipedia.org/wiki/Markdown) 格式化。
这样就能在文档字符串中使用缩进、代码块或粗体等格式。

~~~~exercism/note
你可以在 [Markdown 标准库的文档](https://docs.julialang.org/en/v1/stdlib/Markdown/) 中找到支持的 Markdown 功能列表。
~~~~

更复杂的文档字符串可能长这样：

````julia
"""
    mean(x, y)

Compute the mean value of `x` and `y`.
"""
mean(x, y) = (x + y) / 2
````

Julia 手册中有一些应当遵循的约定：

> - 始终在文档顶部显示函数的签名，并缩进四个空格，以便它按 Julia 代码的形式显示。
> - 在简化签名块之后，用一句话说明函数的作用或该对象代表什么。
>    如有需要，可在空行后的第二段中提供更多细节。
>    为函数编写文档时，这句话应使用祈使语气（“做这个”“返回那个”），而不要用第三人称（不要写“返回长度……”）。
>    句末要加句号。
> - 不要重复已经说过的内容。
>    既然函数名已经由签名给出，就不必以“函数`mean`……”开头，直接说重点即可。
> - 用反引号标出代码和公式。
> - 起始和结尾的`"""`字符各自单独占一行。

~~~~exercism/note
上面这份列表只涵盖你在 Exercism 中可能需要或遇到的约定。
你可以在 [Julia 手册](https://docs.julialang.org/en/v1/manual/documentation/) 中找到完整、未删减的列表。
关于为更进阶的 Julia 概念编写文档的更多约定，会在后续练习中随相应概念一起介绍。
~~~~

## 访问文档字符串

在 REPL 中，输入`?`再加上函数或对象的名称，就能搜索文档字符串，例如：

```julia-repl
help?> println
search: println printstyled print sprint isprint

  println([io::IO], xs...)


  Print (using print) xs followed by a newline. If io is not supplied, prints to stdout.

  Examples
  ==========

  julia> println("Hello, world")
  Hello, world

  julia> io = IOBuffer();

  julia> println(io, "Hello, world")

  julia> String(take!(io))
  "Hello, world\n"
```

这也可以当作一种基本的搜索手段，比如当你不确定某个函数的确切拼写时：

```julia-repl
help?> printline
search:

Couldn't find printline
Perhaps you meant println, pipeline, @inline or print
  No documentation found.

  Binding printline does not exist.
```
