# 简介

## 运算符重载

主要的算术运算符和比较运算符可以改造，让你自己的类和结构体也能使用。这称为_运算符重载_。

大多数运算符的形式如下：

```csharp
static <return type> operator <operator symbols>(<parameters>);
```

类型转换运算符的形式如下：

```csharp
static (explicit|implicit) operator <cast-to-type>(<cast-from-type> <parameter name>);
```

运算符的行为与静态方法相同。运算符符号代替方法标识符，并且它们有形参和返回类型。关于形参和返回类型的类型规则符合你的直觉，你可以依靠编译器提供详细指导。
