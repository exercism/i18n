# 通用

- API 文档：[regexp 包][package-regexp]
- 正则表达式语法：[regexp/syntax][regexp-syntax]
- 网站 [regex101.com][regex101] 提供在线正则表达式测试器。
- 建议把正则表达式写成用反引号括起来的[原始字符串字面量][raw-string-literals]。

## 1. 找出乱码的日志行

- 这里可能用得上函数 [regexp.MatchString][fun-re-match-string] 或方法 [MatchString][method-match-string]。
- 在正则表达式中，字符`^`匹配行或字符串的开头。

## 2. 拆分日志行

- 这里可能用得上方法 [Split][regexp-split]。

## 3. 统计引号中包含 `password` 的行数

- 在正则表达式前面加上 `(?i)`，就能让匹配区分大小写。
  这会设置 `i` 标志。
  参见[这篇教程][yourbasic-i-flag]。

## 4. 从日志中移除多余的部分

- 这里可能用得上方法 [ReplaceAllString][replace-all-string]。

## 5. 给日志行标上用户名

- 这里可能用得上方法 [FindStringSubmatch][find-string-submatch]。
