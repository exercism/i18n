# 帮助

如果你遇到问题需要帮助，可以使用以下资源：

- [Dart API 文档](https://api.dart.dev/)
- [Dart Gitter 聊天室](https://gitter.im/dart-lang/home)
- [社区信息](https://www.dart.dev/community)
- [/r/dartlang](https://www.reddit.com/r/dartlang) 是 Dart 的子版块。
- [StackOverflow](https://stackoverflow.com/questions/tagged/dart) 可以用来搜索你的问题，看看是否已经有人回答过。你也可以提问和回答问题。
