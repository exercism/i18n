# 简介

异常是一种错误处理方式。
它们之所以叫“异常”，是因为通常出现在处理某些意外事件的时候。

在代码的任何位置，我们都可以抛出异常。
我们使用 `raise` 方法来做这件事，传入一个对象，通常是 Exception 对象，不过也可以使用普通的字符串。
例如，你会在练习的代码桩中看到，我们用内置的 `RuntimeError` 告诉 Ruby 某个方法还没有实现。
你也可以使用 `raise(ExceptionObject, params)` 这种简写语法。
如果省略了异常类，默认会使用 `RuntimeError`。
例如：

```ruby
# These are equivalent
raise RuntimeError.new("Please implement this method")
raise RuntimeError, "Please implement this method"
raise "Please implement this method"
```

当 Ruby 看到这行代码时，它会把这个错误向上冒泡到程序的顶层，然后退出。
例如，如果你尝试用某个数除以零，会看到类似这样的输出：
```ruby
5/0

#=> Traceback (most recent call last):
#=> ...
#=> ZeroDivisionError (divided by 0)
```
