# 关于

用 `[ ]` 写成的 quotation 是 Factor 中匿名函数或代码块的对应物。它是一种一等值，可以压入栈、保存或四处传递，并且只有在被*调用*时才会运行。

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

quotation 是一串单词，凡是某段行为需要被延迟或参数化的地方，Factor 都会用到它：

- `if` / `when` / `unless` / `cond` 的分支
- `filter`、`count`、`any?`、`all?` 的谓词
- `map`、`each`、`reduce` 的变换
- `times`、`while`、`loop` 的主体

quotation 的栈效应通常可以推断出来。推断不出来时（通常是它被保存起来、稍后再用 `call` 调用的情况），就显式声明这个效应：`call( a b -- c )`。

## 组合 quotation

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose`把两个 quotation 首尾拼接成一个新的 quotation，先运行第一个，再运行第二个。`curry`前置一个固定值，返回一个 quotation，它会在调用原 quotation 之前先把这个值压入栈。两者产生的都是普通的 quotation，你可以 `call`、保存，或者传给组合子。

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
