# 说明

在这个练习中，你需要实现一些方法来操作一个编程语言数组。

## 1. 定义一个返回空语言数组的方法

定义 `LanguageList.list` 方法，它不接受任何实参，并返回一个类型为 `Array(String)` 的空数组。

```crystal
LanguageList.list()
# => []
```

## 2. 定义一个向数组中添加语言的方法

定义 `LanguageList.add` 方法，它接受 2 个实参（一个_语言数组_和一个_语言_的字符串字面量）。
该方法应返回添加了新语言后的数组，新语言位于数组末尾。

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. 定义一个从数组中移除语言的方法

定义 `LanguageList.remove` 方法，它接受 1 个实参（一个_语言数组_）。
该方法应返回去掉最后一项后的数组。
假设数组至少有 1 项。

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. 定义一个返回数组中第 n 项的方法

定义 `LanguageList.at` 函数，它接受 2 个实参（一个_语言数组_和一个下标）。
该方法应返回数组中下标为 n 的语言。
假设该下标处总是存在一种语言。

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. 定义一个解析语言字符串的方法

定义 `LanguageList.parse` 方法，它接受 1 个实参（一个由逗号分隔的语言字符串字面量）。
该方法应返回一个语言数组。

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
