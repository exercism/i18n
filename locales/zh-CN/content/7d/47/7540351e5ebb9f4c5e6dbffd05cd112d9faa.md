# 指令附录

## 花园格式

花园用一个以 null 结尾的字符串表示，每行末尾都有一个换行符。

例如：`"   \n * \n   \n"`

## 寄存器

| 寄存器 | 用途   | 类型 | 说明               |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 地址 | 以 null 结尾的输入字符串  |
| `$a1`    | 输入/输出 | 地址 | 以 null 结尾的输出字符串 |
| `$t0-9`  | 临时    | 任意     | 用于临时存储         |
