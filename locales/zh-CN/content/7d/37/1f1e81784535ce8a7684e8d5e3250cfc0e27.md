## 异常消息

有时需要[抛出异常](https://docs.python.org/3/tutorial/errors.html#raising-exceptions)。抛出异常时，应始终附上**有意义的错误消息**，说明错误的来源。这会让代码更易读，也大大有助于调试。如果你知道错误来源属于某种特定类型，可以选择抛出某个[内置错误类型](https://docs.python.org/3/library/exceptions.html#base-classes)，但仍应附上有意义的消息。

本练习要求你使用 [raise 语句](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)，在向`Queen`构造函数传入负数，或传入不是有效行或列的数值时，“抛出”`ValueErrors`。只有当你在`raise`异常的同时附上消息，测试才会通过。另外，如果传给`can_attack()`方法的两个皇后位于同一位置，你也应该`raise`一个`ValueError`。

要带着消息`raise`一个`ValueError`，请把消息写成`exception`类型的实参：

```python
# if the row parameter is negative
raise ValueError("row not positive")

# if the row parameter is not on the defined board
raise ValueError("row not on board")

# if the column parameter is negative
raise ValueError("column not positive")

# if the column parameter is not on the defined board
raise ValueError("column not on board")

# if both the queens are on the same location
raise ValueError("Invalid queen position: both queens in the same square")
```
