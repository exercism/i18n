# 关于

三元运算符允许在表达式中定义 `if` 条件，而不是在语句块中定义。这与函数式编程的思路相呼应，往往能让代码更具表现力，也更不容易出错。

三元运算符把 3 个表达式组合在一起：一个条件，后面跟着条件为真时求值并返回的表达式（`if`部分，由`?`引入），以及条件为假时求值并返回的表达式（`else`部分，由`:`引入）。

```haxe
trace(true ? "Haxe" : "Not Haxe"); // Haxe
trace(1 == 2 ? "Something is wrong" : "That's obvious"); // That's obvious
```
