# 简介

在 JavaScript 中，[集合][mdn-sets]是一种类似列表的结构，其中包含唯一的值，这些值可以是原始值，也可以是对象引用，或者两者兼有。和数组不同，集合的元素不能通过下标访问。

如果一个值与集合中的任何元素都[严格相等][mdn-strict-equality]，那么这个值就不能被添加到集合中。

```javascript
const set = new Set();
const object = { color: 'lime green' };
const functionallyIdenticalObject = { color: 'lime green' };

set.add(object);
set.add('wow');
set.add(77);

console.log(set.size);
//=> 3

set.add(functionallyIdenticalObject); // added because functionallyIdenticalObject is not strictly equal to object
console.log(set.size);
//=> 4

set.add(77); // not added because 77 is strictly equal to 77
console.log(set.size);
//=> 4
```

创建集合时，你可以把一个数组作为实参传入，数组中的值会成为集合的值，重复的值也会被去掉。

```javascript
const array = [1, 5, 4, 1];
const set = new Set(array); // the set's values become [1, 5, 4]

console.log(set.size);
//=> 3
```

要把集合转换为数组，可以使用 [Array.from()][mdn-array-from]，它能把可迭代对象（比如集合或映射）转换为数组。

```javascript
const set = new Set();

set.add(1);
set.add(2);
set.add(3);
set.add(4);

const array = Array.from(set);
console.log(array);
//=> [1, 2, 3, 4]
```
