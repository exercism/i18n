# 简介

浮点数是小数点后还有一位或多位数字的数。它们使用 64 位双精度浮点数格式。

```elixir
float = 3.45
# => 3.45
```

## 数字运算

在 [`Integer`][integer-functions]和[`Float`][float-functions]模块中，你可以找到一些处理这两种类型的有用函数。基本的算术运算符定义在 [`Kernel`][kernel-arithmetic-operators]模块中。

## 转换

整数和浮点数可以混合在同一个算术表达式中使用。表达式中只要出现了浮点数，结果也一定会是浮点数。

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

不过，做除法时，结果总是浮点数，即使只用到了整数。

```elixir
6 / 2
# => 3.0
```

要把浮点数转换成整数，可以用 [`trunc/1`][trunc-1]舍弃小数部分。
