# 帮助

如果你遇到问题，下面这些资源可以提供帮助：

- [The PSF](https://www.python.org) 提供 Python 的下载、文档和社区资源。
- [Python Community Forums](https://discuss.python.org/) 可以寻求帮助、讨论 PEP、联系 Python 核心提交者，还有更多内容。
- [Exercism 社区的 Discord](https://exercism.org/r/discord)
- [Exercism 社区讨论论坛](https://forum.exercsim.org)
- [Python 社区的 Discord](https://pythondiscord.com/) 是一个非常热心、非常活跃的社区。
- [/r/learnpython/](https://www.reddit.com/r/learnpython/) 是专为 Python 学习者设立的子版块。
- [Libera.chat 上的 #python](https://www.python.org/community/irc/) 是这门语言的核心开发者们聚集和交流工作的地方。
- [Free Code Camp 社区论坛](https://forum.freecodecamp.org/)
- [Pythontutor](http://pythontutor.com/) 可以直观地单步执行小段代码。

此外，[StackOverflow](http://stackoverflow.com/questions/tagged/python) 也是搜索你的问题、看看是否已经有人问过的好地方。如果没有，你随时可以[提问](https://stackoverflow.com/help/how-to-ask)，或者[回答](https://stackoverflow.com/help/how-to-answer)别人的问题。
