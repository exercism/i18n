# 补充说明

## 输出格式

输出一个以`null`结尾的字符串，用逗号和空格作为分隔符。

一个示例输出是`"491, 914, 142"`

如果输入无效，输出一个空字符串。

## 寄存器

| 寄存器   | 用途         | 类型    | 描述                           |
| -------- | ------------ | ------- | ------------------------------ |
| `$a0`    | 输入         | 地址    | 以`null`结尾的数列字符串       |
| `$a1`    | 输入         | 整数    | 切片长度                       |
| `$a2`    | 输入/输出    | 地址    | 以`null`结尾的输出字符串       |
| `$t0-9`  | 临时         | 任意    | 用于临时存储                   |
