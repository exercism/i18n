# 简介

*元组*是 Factor 的记录/结构体/类类型。每个元组类都有一组固定的具名槽位，Factor 会自动为它们生成获取方法和设置方法。

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;

T{ point { x 3 } { y 4 } } x>> .   ! => 3
3 4 point boa .                    ! => T{ point { x 3 } { y 4 } }
point new .                        ! => T{ point }
```

`boa`（“按参数顺序”）会按声明顺序从栈上填充各个槽位。`new` 则创建一个实例，每个槽位都取声明时 `initial:` 指定的值（没有指定就是 `f`）。

每个槽位的获取方法是 `slot>>`，设置方法是 `>>slot`。设置方法会*修改*原对象，所以如果需要非破坏性更新，请先 `clone`：

```factor
T{ point { x 3 } { y 4 } } clone 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

槽位的默认值写成 `{ name initial: value }`；不写 `initial:` 时，默认值就是 `f`。
