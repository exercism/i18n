# 学习

Cairo 是首个图灵完备的语言，用于为通用计算创建可证明的程序。它是一种类似 Rust 的高级语言。与 Rust 一样，它的目标是让开发者能够轻松编写高效且安全的代码。

我们认为最好的学习方式就是动手玩、动手练：既可以创建自己的编程项目，也可以解决一些小问题，就像 Exercism 上的这些练习一样！

下面这些资源或许能帮你快速开启 Cairo 之旅：

- [Cairo Programming Language](https://www.cairo-lang.org/) 介绍了 Cairo 语言，并列出了许多学习和使用 Cairo 的相关资源。
- [The Cairo Book](https://book.cairo-lang.org/) 是学习 Cairo 以及深入了解 Cairo 特定功能的绝佳资源。
- [Cairo Documentation](https://docs.cairo-lang.org/) 讲解了这门语言的各种结构和语义。
- [Cairo by Example](https://cairo-by-example.com/) 用示例展示你在 Cairo 中会写到的最常见的内容。
- [Node Guardians](https://nodeguardians.io/campaigns?f=3%3D2) “一个面向智能合约开发者的奇幻主题学习平台。”
- [Cairo Community Forum](https://community.cairo-lang.org/) 能解答各个水平的问题。
