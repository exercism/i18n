# 说明

在马戏团里，安全检查通过之前，谁也不能上高空秋千。
你把这些检查写下来，是为了让同样的规则适用于每个人。

五个任务都写在`SAFETY_CHECK`类里。

## 1. 垫子准备好了吗？

只有当垫子既已放下又干净时，才算准备就绪。

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. 有东西可以落在上面吗？

下面必须有垫子，或者有安全网。有其中一样就行，两样都有也可以。

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. 谁还需要听讲解？

凡是还没听过讲解的人，都需要听讲解。

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. 这位表演者的年龄够了吗？

高空秋千面向 13 岁及以上的表演者。

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. 把它们组合起来

当表演者年龄足够、已经听过讲解，并且垫子也准备就绪时，才算通过高空秋千的安全检查。

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

这四个实参依次是年龄、是否已经听过讲解、垫子是否已放下，以及垫子是否干净。
