# 抽象类

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end;

class JUGGLING < $ACT is
   name : STR is return "Juggling"; end;
   minutes : INT is return 5; end;
   create : SAME is return new; end;
end;
```

## `$`是名字的一部分

每个抽象类的名字都以`$`开头，也只有抽象类才这样。所以，以`$`开头的类型，你没法用它创建对象；而且只要名字出现在哪里，这一点就能在哪里看出来。

## 里面可以放什么

例程和迭代器的签名，到分号为止。没有方法体，没有属性，也没有`create`。抽象类描述的，是你可以对某个东西*要求*什么，而不是它里面存着什么。

## 符合性

```sather
class TRAPEZE < $ACT is
```

类必须定义列出的每一个例程，实参类型和返回类型都要相符。这一点由编译器检查。

一个类可以符合多个抽象类：

```sather
class TRAPEZE < $ACT, $RISKY is
```

抽象类之间也可以相互继承：

```sather
abstract class $TIMED_ACT < $ACT is
   overrun : INT;
end;
```

## 分派发生在哪里

抽象类型的变量持有对某个符合它的对象的引用。在它上面调用例程时，会在运行时选中属于该对象真实类的那个版本。

这是 Sather 唯一在运行时做决定的地方。而对具体类型的变量发起的调用，在编译时就已经确定。

## typecase

有时候，具体是哪种类型确实很要紧。`typecase`问的是：

```sather
   typecase act
   when TRAPEZE then #OUT + "rig the net";
   else            #OUT + "nothing to rig";
   end;
```

在分支内部，变量的类型会更窄。但请少用它：如果要对每一种 act 都写一遍`typecase`，那通常说明这个例程本来就该放在抽象类里。

## $OB

`$OB`是所有对象都要符合的抽象类。它偶尔有用，但更多时候，它意味着某个类型在途中丢失了。

## 为什么不用继承？

Sather 把大多数语言合二为一的两件事拆开了。`<`只说明一个类能*做*什么。要从别处取得实现，用的是`include`，那是下下个练习的内容，而且是一个独立的决定。
