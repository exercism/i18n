# 说明

在这个练习中，你要写一个有用的程序，这样就不必再记住色带对应的数值了。
程序会接收 1、4 或 5 种颜色作为输入，并输出以欧姆为单位的正确数值。
色带的编码如下：

| 颜色   | 数值 |
| ------ | ----- |
| Black  | 0     |
| Brown  | 1     |
| Red    | 2     |
| Orange | 3     |
| Yellow | 4     |
| Green  | 5     |
| Blue   | 6     |
| Violet | 7     |
| Gray   | 8     |
| White  | 9     |

在[`Resistor Color Trio`][resistor-color-trio-exercise]中，你解析了前三条色带。
例如：orange-orange-brown 对应主值 `330`。
在这个练习里，你还要把*容差*加进来。
容差是指数值可以高出或低于主值的最大幅度。
例如，如果最后一条色带是 green，最大容差就是 `±0.5%`。

容差色带的取值是下面这些之一：

| 颜色   | 容差 |
| ------ | --------: |
| Grey   |    ±0.05% |
| Violet |    ±0.10% |
| Blue   |    ±0.25% |
| Green  |    ±0.50% |
| Brown  |    ±1.00% |
| Red    |    ±2.00% |
| Gold   |    ±5.00% |
| Silver |   ±10.00% |

四色环电阻是这样构成的：

| 色带 1 | 色带 2 | 色带 3 | 色带 4 |
| ------- | ------- | ---------- | --------- |
| 数值 1 | 数值 2 | 乘数 | 容差 |

例如：

- orange-orange-brown-green 对应 `330` 欧姆，容差为 `±0.5%`。
- orange-orange-red-grey 对应 `3300` 欧姆，容差为 `±0.05%`。

四色环电阻和五色环电阻的区别在于，五色环电阻多了一条色带，用来表示更精确的数值。

| 色带 1 | 色带 2 | 色带 3 | 色带 4 | 色带 5 |
| ------- | ------- | ------- | ---------- | --------- |
| 数值 1 | 数值 2 | 数值 3 | 乘数 | 容差 |

例如：

- orange-orange-orange-black-green 对应 `333` 欧姆，容差为 `±0.5%`。
- orange-red-orange-blue-violet 对应 `323 million` 欧姆，容差为 `±0.1%`。

此外还有一色环电阻。
一色环电阻只有 black 这一种颜色，数值为 0。

你的程序应当把输入的电阻色带颜色 `list` 转换成这样的标签：

"... ohms ±...%"

因此，输入`["orange", "orange", "black", "green"]`这样的`list`，应当返回：

"33 ohms ±0.5%"

当欧姆数达到几千时，我们说“kiloohms”。
这就像把 1000 米说成“kilometer”、把 1000 克说成“kilograms”一样。

因此，输入`["orange", "orange", "orange", "grey"]`这样的`list`，应当返回：

"33 kiloohms ±0.05%"

当欧姆数达到几百万时，我们说“megaohms”。

因此，输入`["orange", "orange", "blue", "red"]`这样的`list`，应当返回：

"33 megaohms ±2%"
