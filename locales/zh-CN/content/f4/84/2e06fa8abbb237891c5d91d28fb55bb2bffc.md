# 资源

## 通用资源

- [vim-galore](https://github.com/mhinz/vim-galore) 是一份涵盖 Vim 方方面面的详尽指南。
- [Why, oh WHY, do those #?@! nutheads use vi?](http://www.viemu.com/a-why-vi-vim.html) 解释了人们对 vi 和 Vim 常见的误解。
- [Your problem with Vim is that you don't grok vi](http://stackoverflow.com/a/1220118) 是不可多得的佳作。不妨时不时读一读。
