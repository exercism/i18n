# 说明

Lucian 的女朋友正在回家的路上，而他还没做好他们的周年纪念晚餐！

在这个练习中，你要写一些代码，帮助 Lucian 参照他最爱的食谱做出一道精致的千层面。

你有四个任务，都与做千层面所花的时间有关。

## 1. 定义预期的烤箱时间（分钟）

定义`ovenTime()`函数，它不接受任何实参，返回千层面应该在烤箱里烤多少分钟。
根据食谱，预期的烤箱时间是 40 分钟：

```cpp
ovenTime();
// => 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`remainingOvenTime(int actualMinutesInOven)`函数，它以千层面已经在烤箱里烤的分钟数作为实参，并基于上一个任务中预期的烤箱时间（分钟），返回千层面还需要在烤箱里烤多少分钟。

```cpp
remainingOvenTime(30);
// => 10
```

## 3. 计算准备时间（分钟）

定义`preparationTime(int numberOfLayers)`函数，它以你给千层面加的层数作为实参，返回你准备千层面花了多少分钟，假设每准备一层需要 2 分钟。

```cpp
preparationTime(2);
// => 4
```

## 4. 计算已用时间（分钟）

定义`elapsedTime(int numberOfLayers, int actualMinutesInOven)`函数，它接受两个实参：第一个实参是你给千层面加的层数，第二个实参是千层面已经在烤箱里烤的分钟数。该函数应返回你做这道千层面已经花了多少分钟，它等于准备时间（分钟）与千层面此刻在烤箱里所花时间（分钟）之和。

```cpp
elapsedTime(3, 20);
// => 26
```
