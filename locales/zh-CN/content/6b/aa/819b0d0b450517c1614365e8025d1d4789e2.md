# 关于

Tcl，读作“tickle”，是 Tool Command Language 的缩写，一门动态的开源编程语言。

它的设计目标是既简单又强大。它简单到整套语法用[短短 12 条规则][rules]就能完整描述，但它却是一门功能完备的编程语言。

Tcl 把一切都变成*命令*，变量赋值、过程定义和控制流也不例外。因此，它既像 shell 脚本，又像 Lisp。

Tcl 支持多种编程范式，包括面向对象、命令式和函数式风格。Tcl 最常见的用途，是作为 C 应用程序中嵌入的脚本运行时，以及用 Tk GUI 工具包来开发 GUI 原型。
