# 说明

_Instruments of Texas_ 的 RPN 计算器项目进展顺利。你的团队现在希望能把算式的字符串形式写入 _IO_ 资源。

## 1. 打开文件

你的团队还没决定要把算式写入哪种设备，所以你建议采用 _动态分发_ 的方式，把资源注入函数，而不是把它写死在函数里。实现`write/3`函数，用资源和文件名打开一个 _IO 设备_。

你可以假定`resource`始终是一个原子，代表一个模块，该模块有一个`open/1`函数，返回`{:ok, io_device}`。

函数成功时，返回一个包含算式的 ok 元组。

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. 尝试写入 IO 设备

现在已经打开了 IO 设备，试着用`IO.write/2`向它写入内容。

扩展`write/3`函数来完成这个操作。写入尝试可能会抛出错误，此时请 rescue 该错误，并返回一个 error 元组：

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. 关闭 IO 设备

一个好习惯是，即使使用资源的函数抛出了错误，也要尽量释放已经打开的资源。扩展`write/3`函数，调用资源的关闭函数来关闭 _IO 设备_。

你可以假定`resource`始终是一个原子，代表一个模块，该模块有一个`close/1`函数，它接受一个 _IO 设备_。
