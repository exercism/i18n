# 说明

你的团队正在开发一个气象应用。
他们定义了一组 API，其中包含表示气象数据的各种类型和常量，参见文件`meteorology.go`。

你的任务是给所有类型添加合适的`String`方法，让它们都实现`Stringer`接口。

## 1. 为`TemperatureUnit`类型实现`Stringer`接口

经过一番讨论，团队决定温度单位要么是`Celsius`，要么是`Fahrenheit`。
取值应按下方的示例格式化。

为`TemperatureUnit`类型添加一个`String`方法，使其实现`Stringer`接口。
如果温度单位是摄氏度，该方法必须返回字符串`"°C"`；如果温度单位是华氏度，则必须返回字符串`"°F"`。

```go
celsiusUnit := Celsius
fahrenheitUnit := Fahrenheit

celsiusUnit.String()
// => °C
fahrenheitUnit.String()
// => °F
fmt.Sprint(celsiusUnit)
// Output: °C
```

## 2. 为`Temperature`类型实现`Stringer`接口

温度值由一个整数和一个温度单位组成。
它们应按下方的示例格式化。

要做到这一点，请为`Temperature`类型添加一个`String`方法，使其实现`Stringer`接口。
该方法应返回一个字符串，其中温度的数字值和温度单位之间用一个空格分隔：`<temperature> <unit>`：

```go
celsiusTemp := Temperature{
    degree: 21,
    unit: Celsius,
}
celsiusTemp.String()
// => 21 °C
fmt.Sprint(celsiusTemp)
// Output: 21 °C

fahrenheitTemp := Temperature{
    degree: 75,
    unit: Fahrenheit,
}
fahrenheitTemp.String()
// => 75 °F
fmt.Sprint(fahrenheitTemp)
// Output: 75 °F
```

## 3. 为`SpeedUnit`类型实现`Stringer`接口

经过长时间的讨论，团队决定风速的单位要么是`KmPerHour`，要么是`MilesPerHour`。
取值应按下方的示例格式化。

要做到这一点，请为`SpeedUnit`类型添加一个`String`方法，使其实现`Stringer`接口。
如果速度单位是千米每小时，该方法必须返回字符串`"km/h"`；如果速度单位是英里每小时，则必须返回字符串`"mph"`：

```go
mphUnit := MilesPerHour
mphUnit.String()
// => mph
fmt.Sprint(mphUnit)
// Output: mph

kmhUnit := KmPerHour
kmhUnit.String()
// => km/h
fmt.Sprint(kmhUnit)
// Output: km/h
```

## 4. 为`Speed`实现`Stringer`接口

风速值由一个整数和一个速度单位组成。
它们应按下方的示例格式化。

要做到这一点，请为`Speed`类型添加一个`String`方法，使其实现`Stringer`接口。
该方法应返回一个字符串，其中速度的数字值和速度单位之间用一个空格分隔：`<speed> <unit>`：

```go
windSpeedNow := Speed{
    magnitude: 18,
    unit: KmPerHour,
}
windSpeedNow.String()
// => 18 km/h
fmt.Sprintf(windSpeedNow)
// Output: 18 km/h

windSpeedYesterday := Speed{
    magnitude: 22,
    unit: MilesPerHour,
}
windSpeedYesterday.String()
// => 22 mph
fmt.Sprint(windSpeedYesterday)
// Output: 22 mph
```

## 5. 为`MeteorologyData`类型实现`Stringer`接口

气象数据包含地点、温度、风向、风速和湿度。
它的格式应如下方的示例所示：

要做到这一点，请为`MeteorologyData`类型添加一个`String`方法，使其实现`Stringer`接口。
该方法应按以下格式返回气象数据：

```text
<location>: <temperature>, Wind <wind_direction> at <wind_speed>, <humidity>% Humidity
```

```go
sfData := MeteorologyData{
    location: "San Francisco",
    temperature: Temperature{
        degree: 57,
        unit: Fahrenheit
    },
    windDirection: "NW",
    windSpeed: Speed{
        magnitude: 19,
        unit: MilesPerHour
    },
    humidity: 60
}

sfData.String()
// => San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
fmt.Sprint(sfData)
// Output: San Francisco: 57 °F, Wind NW at 19 mph, 60% Humidity
```
