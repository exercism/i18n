# 关于

在 F# 中，布尔值由 `bool` 类型表示，其取值可以是 `true` 或 `false`。

F# 支持三种[布尔运算符][operators]：`not`（非）、`&&`（与）和 `||`（或）。`&&` 和 `||` 运算符使用_短路求值_，也就是说，只有需要时才会对运算符右侧求值。

```fsharp
true || false // => true
true && false // => false
```

这三种布尔运算符各有不同的[_运算符优先级_][precedence]。因此，它们的求值顺序是：先 `not`，再 `&&`，最后 `||`。如果你想“绕开”这些规则，可以把布尔表达式用括号（`()`）括起来，因为括号的运算符优先级更高。

```fsharp
not true && false   // => false
not (true && false) // => true
```
