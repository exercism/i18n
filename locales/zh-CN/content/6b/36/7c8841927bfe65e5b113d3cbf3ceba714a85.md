# 说明补充

## 提示

你需要实现`decode`和`encode`函数，它们使用仿射密码对`String`进行解码和编码。
如果不确定类型，可以使用提供的函数签名，但不要让它限制你的创造力。

这个练习处理的是文本数据。
由于历史原因，Haskell 的`String`类型等同于`[Char]`，即一个字符列表。
为了更高效地处理文本数据，可以使用`Text`类型。

作为这个练习的可选扩展，你可以

- 在 package.yaml 的依赖列表中加入`- text`。
- 按[以下方式](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c)导入`Data.Text`：

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- 使用`Text`类型，例如`decode :: Text -> Text`，并以`T.pack`这样的形式引用`Data.Text`组合子。
- 查阅[`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html)的文档。
- 把 Affine.hs 中所有`String`替换为`Text`，即：

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

这部分完全是可选的。
