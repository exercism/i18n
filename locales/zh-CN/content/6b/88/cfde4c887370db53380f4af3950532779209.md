# 介绍

Unison 用`Boolean`类型表示 true 和 false 值。它只有两个值：`true`和`false`。

```unison
trueVariable = true
falseVariable = false
```

我们可以用与、或、非运算符对布尔表达式求值：与运算用`&&`表示，或运算用`||`表示，非运算用`not`表示。

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```
