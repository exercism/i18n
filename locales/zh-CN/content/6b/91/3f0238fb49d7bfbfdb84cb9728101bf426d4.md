# 关于

Gleam 中的`Iterator`和数组很像，它同样是一个有序的值集合，且所有值的类型都相同。它与数组的区别在于它是惰性的，也就是说，它不会一次性把所有值都存在内存里，而是按需计算。

在处理非常大甚至无限大的序列时，这一点非常有用，因为即使空闲内存不足以一次性保存所有值，我们也能处理这些序列。

`gleam/iterator`模块定义了`Iterator`类型，以及一系列用于处理迭代器的函数。

数组的许多函数在迭代器上也有对应版本，比如`map`、`filter`和`take`。这些函数返回的是迭代器，所以在迭代器被消费之前，函数实际上什么都不会做。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

可以用`unfold`函数来创建迭代器：它接收一个会被反复调用的函数，用来生成序列中的下一个值。

下面的例子用`unfold`函数创建了一个生成斐波那契序列的迭代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

这里的序列是无限的，所以在把值收集到数组中之前，需要先用`take`函数把它变成有限的。如果对一个无限迭代器调用`to_list`，程序会一直运行下去，直到内存耗尽并崩溃。
