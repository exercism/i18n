# 说明

在这个练习中，你将编写一些代码，帮助自由职业者与项目经理沟通：提供几个实用工具，用来快速计算日费率和月费率，并且可以选择应用给定的折扣。

首先，我们约定自由职业者和项目经理之间的几条规则：

- 日费率是小时费率的 8 倍。
- 一个月有 22 个计费日。

有时，自由职业者会希望在日费率的基础上给出折扣（例如给最忠实的客户，或者给非营利客户）。

折扣用表示百分比的小数来表示，例如 `25.0`（25%）。

## 1. 根据小时费率计算日费率

实现一个函数，根据小时费率计算日费率：

```haskell
dailyRate 60
-- -> 480.0
```

返回的日费率应为双精度浮点数。

## 2. 计算折后价格

实现一个函数，计算应用折扣后的价格。

```haskell
applyDiscount 150 10
-- -> 135.0
```

返回值应始终为双精度浮点数，不能以任何方式取整。

## 3. 根据小时费率和折扣计算月费率

实现一个函数，计算月费率并应用折扣：

```haskell
monthlyRate 77 10.5
-- -> 12130
```

返回的月费率应向上取整为最接近的整数。

## 4. 根据预算、小时费率和折扣计算工作天数

实现一个函数，接收预算、小时费率和折扣，计算这些条件能覆盖多少天的工作。

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

返回的天数应向下取整，保留一位小数。
