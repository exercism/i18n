# 关于

## 模块

Gleam 代码以模块的形式组织，每个文件就是一个 Gleam 模块。

到目前为止，我们一直用`pub fn`语法编写函数，它定义的函数对其他模块公开可用。用`fn`定义的函数则是私有的，只有定义它的模块能使用，其他模块无法使用。

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Gleam 模块有名字，名字取决于它在`src`或`test`目录下的文件路径。

例如，定义在`src\geometry\rectangle.gleam`（Windows 系统）或`src/geometry/rectangle.gleam`（类 UNIX 操作系统）中的模块，名字就是`geometry/rectangle`。

## 从其他模块导入函数

要访问其他模块中定义的函数，需要通过导入来实现。导入某个模块时，该模块对外暴露的所有函数都会变为可访问。不过，访问它们的方式取决于模块的导入方式。

限定导入是默认方式。要访问这类模块中的函数（比如`gleam/list`模块里的`map`函数），需要在前面加上模块名（`list.map`）。

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

默认情况下，用来指代模块的名字是模块名的最后一部分，也就是这里的`int`，但可以用`as`关键字修改。

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

非限定导入可以直接访问该模块暴露的函数，无需加前缀。

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

更推荐使用限定导入，因为它能让读者更清楚地看出函数来自哪里，也有助于避免命名冲突。
