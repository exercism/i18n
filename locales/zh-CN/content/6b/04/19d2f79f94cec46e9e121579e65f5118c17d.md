# 说明

在这个练习中，你将实现一部分工具方法，帮助开发者清理 SqueakyClean 名称。

在这 4 个任务中，你将逐步构建`clean`方法。
有效的 SqueakyClean 名称由零个或多个字母和下划线组成。

在所有情况下，输入字符串都保证不为 null。注意，`clean`方法应把空字符串视为有效。

## 1. 把遇到的空格替换为下划线

实现（_static_）`SqueakyClean.clean()`方法，把任何空格替换为下划线。这也适用于开头和结尾的空格。

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. 把 kebab-case 转换为 camelCase

修改（_static_）`SqueakyClean.clean()`方法，把 kebab-case 转换为 camelCase。

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. 把黑客语转换为普通文本

修改（_static_）`SqueakyClean.clean()`方法，把[黑客语][leet-speak]转换为普通文本。

为简单起见，我们只把`4`、`3`、`0`、`1`和`7`分别替换为`a`、`e`、`o`、`l`和`t`。

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. 省略不是字母的字符

修改（_static_）`SqueakyClean.clean()`方法，省略任何不是字母的字符。

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
