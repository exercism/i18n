# 说明

在这个练习中，你将编写代码来分析汽车工厂装配线的生产情况。
装配线的速度范围可以从`0`（关闭）到`10`（最大）。

在最低速度（`1`）下，每小时生产 `221` 辆汽车。
产量会随速度线性增长。
所以当速度设为`4`时，每小时应生产`4 * 221 = 884`辆汽车。
不过，速度越高，生产出瑕疵车（随后只能报废）的可能性就越大。

你需要完成三个任务。

## 1. 计算成功率

实现（_static_）方法 `AssemblyLine.SuccessRate()`，计算在给定速度下生产出无瑕疵产品的比率。
下表展示了速度如何影响成功率：

- `0`：成功率为 0%。
- `1`到`4`：成功率为 100%。
- `5`到`8`：成功率为 90%。
- `9`：成功率为 80%。
- `10`：成功率为 77%。

```csharp
AssemblyLine.SuccessRate(10)
// => 0.77
```

## 2. 计算每小时生产率

实现（_static_）方法 `AssemblyLine.ProductionRatePerHour()`，计算装配线每小时的产量，并考虑其成功率：

```csharp
AssemblyLine.ProductionRatePerHour(6)
// => 1193.4
```

注意，返回的值是一个`double`。

## 3. 计算每分钟产出的可用车辆数

实现（_static_）方法 `AssemblyLine.WorkingItemsPerMinute()`，计算每分钟生产出多少辆可用汽车：

```csharp
AssemblyLine.WorkingItemsPerMinute(6)
// => 19
```

注意，返回的值是一个`int`。
