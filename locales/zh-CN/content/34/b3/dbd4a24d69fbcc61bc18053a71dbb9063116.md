# 说明补充

## 实现说明

树对象有两个属性：

- `String`标签
- `List<Tree>`子节点

测试程序通过反复调用`Tree.of`构建函数来创建树。例如，下面这条语句

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

会构造出下面这棵树：

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

你可以假设测试用的树中不会有重复的值。

---

`FromPov`和`PathTo`这两个方法是这道练习最有意思的部分。

`FromPov`方法接收一个字符串实参`from`，它通过节点的值来指定树中的一个节点。它应当返回一棵以`from`的值为根节点的树。你可以修改原来的树并返回它，也可以新建一棵树并返回新树。如果返回新树，你可以随意消耗或销毁原来的树。当然，能不改动它就更好了。

`PathTo`方法接收两个字符串实参`from`和`to`，它们通过节点的值来指定树中的两个节点。它应当返回树中从第一个节点到第二个节点的最短路径。

## 异常消息

有时需要[抛出一个异常](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)。这样做时，应当始终附上**有意义的错误消息**，说明错误的来源。这会让你的代码更易读，也大大有助于调试。

这道练习要求你使用 [throw 关键字](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)，在传给`Tree()`类的树无法重新定向，或者无法在`start node`和`end node`之间找到路径时，多次“抛出”`UnsupportedOperationException`。只有当你既`throw`了`exception`，又附带了消息，测试才会通过。

要抛出带有消息的`UnsupportedOperationException`，请把消息作为实参传给该`exception`类型：

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
