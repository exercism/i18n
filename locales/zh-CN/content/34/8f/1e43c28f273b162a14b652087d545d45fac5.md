# 简介

Java 中的布尔值由 `boolean` 类型表示，它的值可以是 `true` 或 `false`。

Java 支持三种布尔运算符：  

- `!`（NOT）：对一个布尔值取反  
- `&&`（AND）：接受两个布尔值，当两者都为 `true` 时结果为 `true`  
- `||`（OR）：两个布尔值中任意一个为 `true` 时结果为 `true`  

## 示例

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
