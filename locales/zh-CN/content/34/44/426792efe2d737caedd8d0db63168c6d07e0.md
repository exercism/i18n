# 简介

## Nil

Gleam 中的 `Nil` 是一种类型，它只有一个值，这个值也叫 `Nil`。它类似于其他语言中的 `void`，用在函数没有更合适的值可以返回的时候。

```gleam
io.println("Hello, Joe!")
// -> Nil
```

Gleam 中的值不像其他一些语言那样可以是“空值”或“可空的”。只有当值的类型是 `Nil` 时，这个值才可能是 `Nil`，而其他任何类型的值都不可能是 `Nil`。

## IO

和大多数编程语言一样，Gleam 也有“副作用”：函数除了返回一个值，还可以读取和改变外部世界的状态。

Gleam 标准库中的 `gleam/io`模块提供了一些函数，用于把字符串打印到控制台。

```gleam
io.println("Hello, Joe!")
// Hello, Joe!
// -> Nil
```

其他包可能会提供别的 IO 函数，比如 `simplifile`，这个包提供了读取和写入文件的函数。

```gleam
simplifile.read("favourite-colour.txt")
// -> Ok("Pink\n")
```
