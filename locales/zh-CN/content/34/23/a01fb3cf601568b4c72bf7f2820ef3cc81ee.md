# 测试

## 运行测试
Haxe 轨道使用测试框架 [Buddy](https://github.com/ciscoheat/buddy)。
你可以用下面的命令安装它：

```bash
haxelib install buddy
```

要运行测试，请执行以下命令：

```bash
haxe test.hxml
```

在测试文件里，每个 describe 块标记着练习测试的一个部分，每个测试都是一个`it`或`xit`块。
运行测试时，`it`块会执行，而`xit`块是待定的测试。
提交解答时，Exercism 的测试运行器会运行所有的`it`或`xit`块。
在本地运行时，默认只会运行第一个测试。
要运行其他测试，把对应的`xit`块改成`it`块，然后重新运行`haxe test.hxml`。


此外，有些练习可能需要用 haxelib 安装额外的库。
遇到这种情况时，练习说明中会有提示。

## 解答练习

解答一个练习，意味着让它所有的测试都通过。
为了帮你上手，每个练习都附带一个存根实现文件。
你可以把这个文件作为起点来构建你的解答。
如果你觉得合适，完全可以删除或修改这个文件。
在逐步完成解答的过程中，试着一次只专注于一个测试。
