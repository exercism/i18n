# 简介

Python 有三种不同的内置数字类型：整数（[`int`][int]）、浮点数（[`float`][float]）和复数（[`complex`][complex]）。
分数（[`fractions.Fraction`][fractions]）和十进制数（[`decimal.Decimal`][decimals]）也可以从标准库中导入使用。

包括十六进制（[_`hex()`_][hex]）、八进制（[_`oct()`_][oct]）和二进制（[_`bin()`_][bin]）在内、**不带**小数位的整数，也同样被识别为`ints`。

Python 完全支持这些不同数字类型之间的算术运算；在与二元算术运算符（`+`、`-`、`*`、`/`、`//` 和 `%`）一起使用时，它会把范围较窄的数字转换成与之对应的范围较宽的数字。
