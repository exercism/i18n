# 关于

处理输入和输出的函数由[`IO`模块][module-io]提供。

- [`IO.puts/2`][io-puts]把字符串写入标准输出，并在后面加上换行符。返回`:ok`。
- [`IO.write/2`][io-write]把字符串写入标准输出，但不添加换行符。返回`:ok`。
- [`IO.gets/2`][io-gets]从标准输入读取一行。
- [`IO.inspect/2`][io-inspect]可以把任何值写入标准输出，并接受`:label`这类实用选项。它会原样返回传入的值，很适合调试。

## `String.Chars`协议

如果你传给[`IO.puts/2`][io-puts]一个它无法打印的值，就会看到`Protocol.UndefinedError`错误。

```elixir
IO.puts({:ok, 7})
# ** (Protocol.UndefinedError) protocol String.Chars not implemented for {:ok, 7} of type Tuple
```

遇到这种情况时，你可以改用[`IO.inspect/2`][io-inspect]。

## 用`IO.inspect/2`调试

[`IO.inspect/2`][io-inspect]非常适合调试：它会原样返回自己的实参，能打印任何值，还提供了`:label`选项。

```elixir
"HELLO\n"
|> String.trim()
|> IO.inspect(label: "step 1")
|> String.downcase()
|> IO.inspect(label: "step 2")

# > step 1: "HELLO"
# > step 2: "hello"
# => "hello"
```

## IO 设备

所有这些函数的第一个实参都是一个 [IO 设备][io-devices]，默认值为`:stdio`（标准输入/输出）。如果要写入标准错误设备，请改用`:stderr`。IO 设备也可以是一个进程，例如通过调用[`File.open/2`][file-open]创建的进程，这样就可以写入文件了。
