# 简介

JavaScript 是一门动态语言，支持面向对象、命令式和声明式（比如函数式编程）等多种风格。

## （重新）赋值

在 JavaScript 中，给名字赋值主要有两种方式：使用变量或常量。在 Exercism 上，变量一律写成 [camelCase][wiki-camel-case]，常量写成 [SCREAMING_SNAKE_CASE][wiki-snake-case]。并没有官方指南可循，不同的公司和组织也各有自己的风格指南。_你完全可以用任何自己喜欢的方式写变量_。按照练习准备时的写法来写，好处是它们会在网页界面和大多数 IDE 里以不同的样式高亮显示。

在 JavaScript 中，可以用`const`、`let`或`var`关键字来定义变量。

用`let`或`var`定义的变量，在它的生命周期里可以引用不同的值。例如，用赋值运算符`=`可以把`myFirstVariable`定义并重新定义很多次：

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

与`let`和`var`不同，用`const`定义的变量只能赋值一次。JavaScript 用它来定义常量。

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 在后面的某个学习练习中，我们会探讨并解释常量的赋值/绑定与常量的值之间的区别。

## 函数声明

在 JavaScript 中，功能单元被封装在_函数_里。如果几个函数属于同一组，通常会把它们放在同一个文件中。函数可以接收形参（实参），并通过`return`关键字_返回_一个值。函数通过`()`语法来调用。

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 在 JavaScript 中，声明函数的方式_有很多_。这些方式和用`function`关键字不同。本课程会尽量逐步介绍它们，但如果你已经了解，用哪种都可以。大多数情况下，用哪种方式并没有好坏之分。

## 供其他文件使用

要让`function`、常量或变量在_其他文件_中可用，需要用`export`关键字把它们[导出][mdn-export]。然后另一个文件就可以用`import`关键字[导入][mdn-import]它们。这也叫做模块系统。一个很好的例子就是所有测试的运作方式。每个练习至少有一个文件，比如`lasagna.js`，里面装着_实现_。此外还至少有一个别的文件，比如`lasagna.spec.js`，里面装着_测试_。这个文件会_导入_公开的（也就是导出的）实体，以便测试实现：

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
