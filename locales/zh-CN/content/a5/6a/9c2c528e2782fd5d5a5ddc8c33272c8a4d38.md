# 简介

Factor 的字符就是整数，即 Unicode 码点，所以用数值比较 `<`、`>`、`=` 就能直接得到区分大小写的排序。[`unicode`][unicode]词汇表提供了支持 Unicode 的谓词，以及单字符的大小写转换。

## 字符谓词

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## 大小写转换

`ch>upper`和`ch>lower`转换单个字符。字符串层面的`>upper`和`>lower`则把转换应用到字符串中的每个字符。

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize`先把整个字符串转为小写，再把首字符转为大写，也就是单个单词的标题式大小写：

```factor
"hELLO" capitalize .   ! => "Hello"
```

## 字符字面量

`CHAR: A`会解析为`A`的整数码点。对于有名称的字符，可以使用`space`、`tab`、`\n`等名称：

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## 符号

当某个词需要返回标签而不是值时（比如返回`yes`/`no`/`maybe`而不是布尔值），就把每个标签声明为一个*符号*。符号是一种在被调用时把自身压入数据栈的词，只有名称相同的两个符号才相等。

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name`声明一个符号；`SYMBOLS: a b c ;`声明多个。
