# 简介

你见过的多数序列单词都会返回*新*序列，不会改动输入，例如 `suffix`、`reverse`、`map` 等等。但数组和向量也支持**原地修改**，当你想记录会随时间变化的状态时，这两种都会用到。

## 可变序列的两种形式

- **数组**（`{ … }`）长度固定。`<array> ( n elt -- array )`（在 [`arrays`][arrays] 中）会新建一个长度为 `n` 的数组，里面填满 `elt` 的副本。
- **向量**（`V{ … }`）可以增长和缩短。用 `V{ } clone` 得到一个新的空向量；`<vector> ( n -- vector )`（在 [`vectors`][vectors] 中）会为 `n` 个元素预分配容量。

```factor
USING: arrays kernel prettyprint vectors ;

5 0 <array> .   ! => { 0 0 0 0 0 }
V{ } clone .    ! => V{ }
```

## 修改某个位置

这两个单词对两种序列都适用：它们都要求把序列放在下标之后：

```
set-nth    ( elt n seq -- )
change-nth ( n seq quot -- )
```

`set-nth` 进行赋值；`change-nth` 则对位置 `n` 上的元素应用一个引用。这两个 [`sequences`][sequences] 单词不会在栈上返回任何东西，修改本身就是它的效果。

```factor
USING: arrays kernel math prettyprint sequences ;

5 0 <array>                 ! { 0 0 0 0 0 }
7 2 pick set-nth            ! mutates: position 2 becomes 7
0 over [ 1 + ] change-nth   ! mutates: position 0 += 1
.                           ! => { 1 0 7 0 0 }
```

## 增长与缩短

这三个单词只对向量有意义，因为数组无法改变长度：

```
push  ( elt seq -- )    ! append to the end
pop   ( seq -- elt )    ! remove and return the last
pop*  ( seq -- )        ! remove the last, discard
```

```factor
USING: kernel sequences vectors ;

V{ } clone              ! a fresh empty vector
"alice" over push       ! V{ "alice" }
"bob"   over push       ! V{ "alice" "bob" }
dup pop .               ! prints "bob"
.                       ! prints V{ "alice" }
```

## 向量 → 数组

当你构建好一个向量，想交回一个长度固定的数组时，`>array ( seq -- array )`（在 [`arrays`][arrays] 中）会返回一个包含相同元素的新数组：

```factor
USING: arrays kernel prettyprint sequences vectors ;

V{ "alice" "bob" "carol" } >array .
! => { "alice" "bob" "carol" }
```

## `clone`，保留一份快照

原地修改会直接改动序列本身。如果调用方把一个序列交给你，而你正要改动它，`clone`（在 [`kernel`][kernel] 中）会给你一份全新的独立副本，这样调用方看到的内容就不会在你手下发生变化：

```factor
USING: kernel prettyprint ;

V{ "a" "b" "c" } clone .    ! => V{ "a" "b" "c" }   (a fresh copy)
```

同样的注意事项也适用于 `V{ }` 以及其他空字面量。在一些语言中，每次对表达式求值，`[]` 或 `vec![]` 都会分配一个全新的容器。而在 Factor 中，你在源码里写下的字面量 `V{ }` 是*同一个*对象，会被每一个提到它的调用点共享。如果你直接往 `V{ }` 上 `push`，下一次调用就会看到上一次留下的东西。`V{ } clone` 才能给你几乎总是想要的那份全新副本。
