# 测试

## 安装 Exercism GDScript track 测试运行器

要使用测试运行器，你需要先[安装好 Godot][installation]。

要为 Exercism 构建和测试 GDScript 脚本，需要通过 CLI 以“无头”模式运行 Godot。
这些说明目前需要 Linux 和 bash。

### 第 1 步：安装测试运行器的整体基础设施

要准备测试环境，请克隆 [https://github.com/exercism/gdscript-test-runner][gdscript-test-runner]，并把其中的内容移动到 `/opt/test-runner/`：

```sh
git clone https://github.com/exercism/gdscript-test-runner.git
sudo mkdir -p /opt/
sudo mv gdscript-test-runner/ /opt/test-runner/
```

### 第 2 步：下载单个练习的测试运行器脚本

假设你已经配置好 `exercism` 工具，并且至少下载了一个 GDScript 练习，那么它应该已经创建了一个 `exercism/gdscript` 文件夹来存放这些练习。
把[测试运行器][test-local-gdscript-solution]保存到这个文件夹里，并将该文件标记为可执行，或者直接为它创建一个链接：

```sh
cd ~/exercism/gdscript # replace with your exercism/gdscript directory
ln /opt/test-runner/bin/test-local-gdscript-solution.sh
```

## 运行测试

安装步骤完成后，你可以从任意练习目录（例如 `~/exercism/gdscript/two-fer`）开始，运行上一级目录（即 `../`）中的脚本，来测试你在该练习中的本地解答：

```sh
../test-local-gdscript-solution.sh
```
