# 说明

在这个练习中，你将编写代码来分析汽车工厂装配线的生产情况。装配线的速度可以从`0`（关闭）到`10`（最大）。

在最低速度（`1`）下，每小时生产`221`辆汽车。产量随速度线性增长。所以当速度设为`4`时，每小时应生产`4 * 221 = 884`辆汽车。不过，速度越高，生产出故障汽车的可能性就越大，这些汽车随后必须被丢弃。下表展示了速度如何影响成功率：

- `0`：成功率 0%。
- `1`到`4`：成功率 100%。
- `5`到`8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有两个任务。

## 1. 计算每小时的产量

实现`production-rate`函数，计算装配线每小时的产量，并把成功率考虑在内：

```clojure
(production-rate 6)
;;=> 1193.4
```

注意，返回的值是`double`。

## 2. 计算每分钟生产的可用汽车数量

实现`working-items`函数，计算每分钟生产多少辆可用汽车：

```clojure
(working-items 6)
;;=> 19
```

注意，返回的值是`int`。
