# 关于

Gleam 不使用异常来处理错误，而是由可能成功、也可能失败的函数返回泛型`Result`类型。

`Result`类型内置于这门语言之中，因此你不需要定义或导入它。但如果你自己来定义，它会是这样的：

```gleam
pub type Result(value, error) {
  Ok(value)
  Error(error)
}
```

函数成功时返回`Ok`变体，函数失败时返回`Error`变体。

结果在 Gleam 中非常常见，Gleam 程序员通常会使用[`gleam/result`模块](https://hexdocs.pm/gleam_stdlib/gleam/result.html)，让处理结果变得更轻松。

如果结果是`Ok`，可以用`result.map`函数对结果内部的值调用一个函数；如果结果是`Error`，则原样传递。

```gleam
Ok(1)
|> result.map(fn(x) { x + 1 })
// -> Ok(2)

Error("Oh no!")
|> result.map(fn(x) { x + 1 })
// -> Error("Oh no!")
```

`result.try`函数与之类似，但它期望回调函数返回一个结果。当你需要把多个返回结果的函数串联起来时，这很有用。

```gleam
Ok(1)
|> result.try(fn(x) { Ok(x + 1) })
// -> Ok(2)

Ok(1)
|> result.try(fn(x) { Error("Nope!") })
// -> Error("Nope!")
```
