# 关于

当类型无法隐式转换时，你必须使用显式转换[运算符][cast-operator]。转换运算符无非就是把目标类型用括号括起来，放在要转换的值前面：

```csharp

int i = 7;
byte b = (byte)i; // Explicit cast from int to byte
```

使用显式转换可能有潜在危险。最常见的两种错误是：

- 转换为不兼容的类型。这会在运行时抛出异常。
- 转换为“宽度”不足的数值类型。对于整数，这可能导致符号冲突，或者抛出溢出异常。

注意：一个 `int` 类型的表达式可以显式转换为 `char`。这可能会产生一个无效的 `char`。

[cast-operator]: https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/operators/type-testing-and-cast#cast-expression
