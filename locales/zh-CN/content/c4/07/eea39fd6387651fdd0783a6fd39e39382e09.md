# 简介

## 映射

**Map**是一种用于存储键值对的数据结构。
它类似于其他编程语言中的字典。
[Map][map-javadoc]接口定义了映射上的各种操作。

Java 有多种不同的 Map 实现。
[HashMap][hashmap-javadoc]是常用的一种。

```java
// Make an instance
Map<String, Integer> fruitPrices = new HashMap<>();
```

用[put][map-put-javadoc]向映射中添加条目。

```java
fruitPrices.put("apple", 100);
fruitPrices.put("pear", 80);
// => { "apple" => 100, "pear" => 80 }
```

每个键只能关联一个值。
用同一个键调用`put`会更新该键的值。

```java
fruitPrices.put("pear", 40);
// => { "apple" => 100, "pear" => 40 }
```

用[get][map-get-javadoc]获取某个键对应的值。

```java
fruitPrices.get("apple"); // => 100
```

用[containsKey][map-containskey-javadoc]检查映射中是否包含某个特定的键。

```java
fruitPrices.containsKey("apple");  // => true
fruitPrices.containsKey("orange"); // => false
```

用[remove][map-remove-javadoc]删除条目。

```java
fruitPrices.put("plum", 90);  // Add plum to map
fruitPrices.remove("plum");   // Removes plum from map
```

[size][map-size-javadoc]方法返回条目的数量。

```java
fruitPrices.size();  // Returns 2
```

你可以用[keySet][map-keyset-javadoc]或[values][map-values-javadoc]方法，分别以 Set 或集合的形式获取 Map 中的键或值。

```java
fruitPrices.keySet();  // Returns "apple" and "pear" in a set
fruitPrices.values();  // Returns 100 and 80, in a Collection
```
