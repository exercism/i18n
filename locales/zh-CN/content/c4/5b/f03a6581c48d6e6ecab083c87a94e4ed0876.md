# 测试

运行测试：

```shell
corepack pnpm test
```

确保你的代码像其他用户一样遵循最佳实践和编码风格。为此可以使用 ESLint，一个对你的代码进行静态分析的工具。有时，这类工具能帮你省下一些时间，发现 JavaScript 代码里的拼写错误或低级失误：

```shell
corepack pnpm lint
```

你也可以让 Jest 以“监视”模式运行，这样当你保存对代码或测试模块的修改时，它会自动重新运行测试：

```shell
corepack pnpm watch
```

## 理解跳过的测试

skip 方法会告诉测试套件不要运行某个测试，这个函数也可以使用下面的别名：`it.skip(name, fn)` 或 `xit(name, fn)` 或 `xtest(name, fn)`

- 为什么要跳过它们？

让用户可以一次专注于一个测试，再随着提交的解答逐步完善，把它们一个个启用。

- 如何启用它们？

把 `xtest` 改成 `test`。

```javascript
test('title cased phrases', () => {
  expect(Acronyms.parse('Portable Network Graphics')).toEqual('PNG');
});
```

## 编写你的第一个 JavaScript 2015 模块

通常，这条学习路径上的测试会先把你的实现作为 JavaScript 模块导入，再加载它：`import { Bob } from './bob.js';`。
你只需要从所引用的文件 `bob.js` 中导出你的实现：

```javascript
export function hey(message) {}
```

想了解更多关于模块的信息，可以查看 [Babel 文档](https://babeljs.io/docs/learn-es2015/#modules)。
