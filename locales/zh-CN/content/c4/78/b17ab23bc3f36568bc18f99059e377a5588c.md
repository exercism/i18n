# 关于

Nim 是一门通用编程语言，由 Andreas Rumpf 设计和开发，于 2008 年首次出现。它的设计目标是高效、富有表现力且优雅。Nim 是静态类型、编译型的语言，却能让你写出运行高效的优雅代码。通过把代码编译成 C、C++、JavaScript 或 Objective-C，Nim 可以面向多种平台。Nim 的语法与 Python 相似，也共享 Python 的许多特点，同时从 C、C++、C#、Lisp、Ada、Go、Oberon 等众多语言中汲取了灵感。

作为一门通用编程语言，Nim 可以用在很多场景，但它在游戏开发和系统编程（包括嵌入式系统）领域一直填补着一项实实在在的空白。

Nim 为你带来许多在 Python 和其他语言中能找到的便利，比如易于阅读的语法、让你在项目中使用新库的包管理系统，以及方便调试错误的友好回溯信息。

Nim 为你带来 C 的速度和可移植性，同时还有高性能的垃圾回收器和优雅的语法，让这门语言对新手非常友好。Nim 也把控制权交给你，你可以更换垃圾回收器，或者把它完全关闭，自己管理内存。在 Nim 中，你可以使用多种编程范式和抽象层次。
