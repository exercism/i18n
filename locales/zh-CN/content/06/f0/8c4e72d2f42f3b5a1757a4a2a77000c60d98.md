# 简介

**正则表达式**（regexes）是指定文本搜索模式的字符序列。

学习正则表达式的语法超出了本主题的范围。
我们将重点介绍 `jq` 提供的、用于使用正则表达式的那些表达式。

## 正则表达式的风格

不同的工具实现了不同版本的正则表达式。
`jq` 内置了 [Oniguruma][oniguruma] 正则表达式库，它与 Perl v5.8 的正则表达式基本兼容。

`jq` 所使用的具体语法可以[在 Oniguruma 的 GitHub 仓库中找到][onig-syntax]。

<!-- prettier-ignore -->
~~~~exercism/caution
`jq` 没有为正则表达式提供任何特殊语法。
它们只是以字符串的形式表示。
这意味着正则表达式中任何反斜杠都需要在字符串中转义。

例如，数字字符类（`\d`）必须写成 `"\\d"`。
~~~~

<!-- prettier-ignore-end -->

## 正则表达式函数

`jq` 中的正则表达式仅限于[一组过滤器][jq-regex-funcs]。

### 简单匹配

当你需要判断一个字符串是否匹配某个模式时，使用 `test` 过滤器。

```jq
STRING | test(REGEX)
STRING | test(REGEX; FLAGS)
STRING | test([REGEX, FLAGS])
```

该过滤器会输出一个*布尔*结果。

```jq
"Hello World!" | test("W")    # => true
"Goodbye Mars" | test("W")    # => false
```

### 关于匹配的信息

当你需要提取真正匹配该模式的子字符串时，使用 `match` 过滤器。

```jq
STRING | match(REGEX)
STRING | match(REGEX; FLAGS)
STRING | match([REGEX, FLAGS])
```

该过滤器会输出：

- 如果没有匹配，则什么都不输出，或者
- 如果存在匹配，则输出一个包含各种属性的对象。

下面这个例子使用反向引用语法 `\1`，查找两个相同的连续元音。

```jq
"Hello World!" | match("([aeiou])\\1")
# => empty

"Goodbye Mars" | match("([aeiou])\\1")
# => {
#      "offset": 1,
#      "length": 2,
#      "string": "oo",
#      "captures": [
#        {
#          "offset": 1,
#          "length": 1,
#          "string": "o",
#          "name": null
#        }
#      ]
#    }
```

`match` 过滤器会为*每个*匹配返回一个对象。
这个例子演示了 `"g"` 标志的实际用法，用来查找所有元音。

```jq
"Goodbye Mars" | match("[aeiou]"; "g")
# => { "offset": 1, "length": 1, "string": "o", "captures": [] }
#    { "offset": 2, "length": 1, "string": "o", "captures": [] }
#    { "offset": 6, "length": 1, "string": "e", "captures": [] }
#    { "offset": 9, "length": 1, "string": "a", "captures": [] }
```

### 捕获的子字符串

与 `match` 过滤器类似，`capture` 过滤器在存在匹配时会返回一个对象。

```jq
STRING | capture(REGEX)
STRING | capture(REGEX; FLAGS)
STRING | capture([REGEX, FLAGS])
```

返回的对象是**命名捕获**的映射。

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")
# => {
#      "project": "JIRAISSUE",
#      "issue_num": "1234"
#    }
```

### 只要子字符串

`scan` 过滤器类似于带 `"g"` 标志的 `match`。

```jq
STRING | scan(REGEX)
STRING | scan(REGEX; FLAGS)
```

`scan` 会输出一个子字符串的*流*。

```jq
"Goodbye Mars" | scan("[aeiou]")
# => "o"
#    "o"
#    "e"
#    "a"
```

使用 `[...]` 数组构造器来捕获这些子字符串。

```jq
"Goodbye Mars" | [ scan("[aeiou]") ]
# => ["o", "o", "e", "a"]
```

### 拆分字符串

如果你知道想**保留**字符串的哪些部分，就使用 `match` 或 `scan`。
如果你知道想**丢弃**哪些部分，就使用 `split`。

```jq
STRING | split(REGEX; FLAGS)
```

<!-- prettier-ignore -->
~~~~exercism/caution
**单参数**的 `split` 过滤器会把它的参数当作**固定字符串**。

要在 `split` 中使用正则表达式，你**必须**提供第二个参数；使用空字符串也可以。
~~~~

<!-- prettier-ignore-end -->

下面这个例子按任意空白字符拆分字符串。

```jq
"first   second           third fourth" | split("\\s+"; "")
# => ["first", "second", "third", "fourth"]
```

### 替换

`sub` 和 `gsub` 过滤器可以转换输入字符串，用替换字符串替换输入中匹配的部分。

如果只想替换第一个匹配，使用 `sub`。
如果要替换所有匹配，使用 `gsub`。

```jq
STRING | sub(REGEX; REPLACEMENT)
STRING | sub(REGEX; REPLACEMENT; FLAGS)
STRING | gsub(REGEX; REPLACEMENT)
STRING | gsub(REGEX; REPLACEMENT; FLAGS)
```

```jq
"Goodnight kittens. Goodnight mittens." | sub("night"; " morning")
# => "Good morning kittens. Goodnight mittens."

"Goodnight kittens. Goodnight mittens." | gsub("night"; " morning")
# => "Good morning kittens. Good morning mittens."
```

替换文本可以引用匹配到的子字符串；使用命名捕获和[字符串插值][jq-interp]。

```jq
"Some 3-letter acronyms: gnu, csv, png"
| gsub( "\\b(?<tla>[[:alpha:]]{3})\\b";     # find words 3 letters long
        "\(.tla | ascii_upcase)" )          # upper-case the match
# => "Some 3-letter acronyms: GNU, CSV, PNG"
```

## 标志

在上面所有的过滤器中，FLAGS 是一个由零个或多个受支持的标志组成的字符串。

- `g` - 全局搜索（查找所有匹配，而不只是第一个）
- `i` - 不区分大小写的搜索
- `m` - 多行模式（'.' 会匹配换行符）
- `n` - 忽略空匹配
- `p` - 同时启用 s 和 m 模式
- `s` - 单行模式（'^' -> '\A'，'$' -> '\Z'）
- `l` - 查找可能的最长匹配
- `x` - 扩展正则表达式格式（忽略空白和注释）

例如

```jq
"JIRAISSUE-1234" | capture("(?<project>\\w+)-(?<issue_num>\\d+)")

# or with Extended formatting

"JIRAISSUE-1234" | capture("
                     (?<project>   \\w+ )  # the Jira project
                     -                     # followed by a hyphen
                     (?<issue_num> \\d+ )  # followed by digits
                   "; "x")
```
