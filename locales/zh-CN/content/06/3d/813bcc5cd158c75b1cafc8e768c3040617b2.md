# 说明

你突然涌起一阵怀旧之情，特别想把那盒旧 Blorkemon™️ 卡牌翻出来掸掸灰。
Blorkemon™️ 卡牌是一款非常棒的老派集换式卡牌游戏。
每张`Card`上都画着一只 Blorkemon™️ 怪兽，还标注了攻击力等级；运气好的话，这张卡甚至还是闪卡。

## 1. 比较力量值

每张 Blorkemon™️ 卡牌看着都比下一张更强，不过最好还是亲自比一比。

实现`isMorePowerful`函数。如果第一个实参所代表的卡牌严格强于另一张，就返回`True`，否则返回`False`。

```elm
newthree = Card "Newthree" 120 False
scientuna = Card "Scientuna" 6 True

isMorePowerful newthree scientuna
    --> True
```

## 2. 找出最高的力量值

手上一把 Blorkemon™️ 卡牌，你应该能凑出最具毁灭性的一击。

实现`maxPower`函数，返回两张卡中较高的力量值。

```elm
maxPower newthree scientuna
    --> 120
```

## 3. 给卡牌排序

你依稀记得每种 Blorkemon™️ 你都至少有一张，不过距离上次清点已经过去很久了；你该把卡牌整理排序，好跟 Pulpapedia 上的官方图鉴对照。

实现`sortByMonsterName`函数，它接收一个`Cards`列表，返回按怪兽名字排好序的列表。

```elm
sortByMonsterName [newthree, scientuna]
    --> [Card "Newthree" 120 False, Card "Scientuna" 6 True]
```

## 4. 最酷的卡牌排前面

Blorkemon™️ 是世界上最酷的东西。
你说这话可不是随便说说，你有一套科学方法来证明它。

实现`sortByCoolness`函数，它会给一列卡牌排序，把最酷的排在前面。
一张卡的酷炫程度首先取决于它闪不闪：所有闪卡都比其他卡酷得多。
第二个因素是力量值，越高越酷。

```elm
sortByCoolness [newthree, scientuna]
    --> [Card "Scientuna" 6 True, Card "Newthree" 120 False]
```

## 5. 闪光力量

闪光可不只是为了好看，在两只力量值相同的 Blorkemon™️ 对战时，闪的那只总能获胜。
这就叫闪光力量。

实现`compareShinyPower`函数，把这一特性写进代码。
如果两张卡的力量值不同，它们的`Order`由力量值决定；如果力量值相同，那么闪卡更大。

```elm
compareShinyPower newthree scientuna
    --> GT
```

## 6. 来下注吧

玩 Blorkemon™️ 卡牌游戏时，什么都有可能发生，但更强的卡还是往往更容易赢。

实现`expectedWinner`函数，它按照`compareShinyPower`的排序，返回最有可能获胜的怪兽名字。
这个函数应该返回预期获胜怪兽的名字；如果双方对手的闪光力量相同，则返回“too close to call”。

```elm
expectedWinner newthree scientuna
    --> "Newthree"
```
