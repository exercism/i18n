# 说明附录

## 本练习在 Python 赛道上的组织方式

本练习的测试要求你把程序实现为一个 Garden [`class`][classes in python]（另见 [concept:python/classes]()）。
如果你不熟悉 Python 中的类，这篇 [Real Python 教程][how-to-make-a-class] 是不错的额外起点。

你的 `class` 需要实现一个名为 `plants` 的 [`method`][methods]，它接收学生的名字作为实参，并返回属于该学生的植物名称 `list`。


## 构造函数

创建示例花园：

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

在测试中会表示为 `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`。

要让这种表示方式生效，你的 `class` 需要实现一个 [`__init__()`][init] [特殊方法][special-methods]。
如果你不熟悉 `__init__()` 或[_构造函数_][what-is-a-constructor]，Python 文档中的[类和实例对象][class vs instance objects in python]有更详细的说明。


## 默认参数

在某些测试中，会把一个由学生组成的 `list` 作为实参传给 `__init__()`。
它应该覆盖题目说明中提供的 12 名学生名单。
下面这两条语句都必须能在你的 `__init__()` 方法下正常工作：


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

一种做法是把学生 `list` 设为[默认实参][default argument values]；Python 文档在讲解[函数定义][function definitions]时深入介绍了`default parameters`。
