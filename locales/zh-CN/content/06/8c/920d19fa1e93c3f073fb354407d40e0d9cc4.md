# 简介

实现`IEnumerable<T>`接口的类型被称为_可枚举_类型。所有内置集合类型都实现了这个接口。

可枚举类型可以用`foreach`循环来迭代：

```csharp
var primes = new[] { 2, 3, 5, 7 };
foreach (var prime in primes)
{
    Console.Write(prime);
}
// => 2357
```

要实现`IEnumerable<T>`，类型只需实现一个方法：`IEnumerator<T> GetEnumerator()`。如你所见，可枚举类型把对集合的实际迭代工作交给`IEnumerator<T>`类型来完成。这个接口有一个属性和三个方法需要实现：

- `public T Current { get; }`：获取当前元素。
- `public bool MoveNext ();`：移动到下一个元素，成功则返回`true`，否则（没有更多元素）返回`false`。
- `public void Reset ();`：将枚举器重置到初始状态（第一个元素之前）。
