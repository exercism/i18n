不过情况有点乱：Azara 的坐标格式和排序似乎跟 Rui 的不一样，两人只能来回对照两份清单，才能弄清楚哪些宝物对应哪些地点。
作为初露头角的 F# 爱好者，他们来找你帮忙，想写一个小程序（确切地说，是一组函数），把寻宝信息整理得更有条理。

## 1. 提取坐标

实现 `getCooordinate()` 函数，它接收 Azara 清单中的一个 `(treasure, coordinate)` 二元组，只返回提取出的地图坐标。

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. 格式化坐标

实现 `convertCoordinate()` 函数，它接收一个 "2A" 格式的坐标，返回一个 `(2, 'A')` 格式的元组。

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. 匹配坐标

实现 `compareRecords()` 函数，它接收一个 `(treasure, coordinate)` 二元组和一个 `(location, coordinate, quadrant)` 记录，并比较两者的坐标。
如果坐标“匹配”，返回 **`true`**；如果不匹配，返回 **`false`**。
为了准确比较，按需重新格式化坐标。

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. 合并匹配的记录

实现 `createrecord()` 函数，它接收 Azara 清单中的一个 `(treasure, coordinate)` 二元组和 Rui 清单中的一个 `(location, coordinate, quadrant)` 记录；**如果坐标匹配**，返回 `(coordinate, location, quadrant, treasure)`。
如果坐标*不*匹配，返回一个形状相同、但各项都填 `""` 的元组。
为了准确比较，按需重新格式化坐标。

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
