# If、Elseif、Else

使用`if`、`elseif`和`else`的条件语句是程序控制流的基本组成部分。
`if`语句会对一个表达式求值，如果结果为`true`，就会执行对应的代码分支。

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

如果表达式不是布尔值，求值过程会判断这个值算“真”还是“非假”。
在 PHP 中，以下值被认为等于`false`：

- 布尔值`false`
- 整数`0`
- 浮点数`0.0`和`-0.0`
- 空数组`[]`
- 空字符串`""`或数字字符串`"0"`
- `null`

其他所有值都被视为 true。

## 响应多个条件

在`if`语句之后，你可以用`elseif`和`else`串联多个条件。

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

只有一个求值为真的分支会被执行。
所以，如果有多个条件都可能为真，它们的书写顺序就很重要。

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
