# 简介

靠运气的游戏需要一个随机性来源。Factor 的 [`random`][random] 词汇表提供了一个泛型单词 `random`，它会根据你交给它的东西自动调整，另外还有用于洗牌和抽样的辅助单词，以及一种让随机性在测试中变得*可复现*的办法。

## 把单词标记为 `inline`

这个练习中的有些任务会定义一个单词，它接收一个*引用*（一个`[ … ]`块）作为实参并运行它。Factor 对此有一条硬性规定：**如果一个单词用`call`s 调用它作为实参接收到的引用，就必须声明为`inline`**，写法就是把`inline`紧跟在结尾的`;`后面。

`inline`会告诉编译器，把这个单词的函数体插入到每个调用点，而不是把它单独编译一次。

- 调用方的引用会被直接嵌入，因此**引用留在栈上的任何东西都会回到调用方**，即便这个单词自身的栈效应并没有声明任何输出。

下面这个小小的单词会压入`10`，然后运行传给它的引用：

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

它的栈效应`( quot -- )`没有声明任何输出，但用两个效果*不同*的引用调用它，却会产生不同的结果，而且都会回到调用方：

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`：单个元素

`random`（在 [`random`][random] 中）对它接收的实参是泛型的：

```
random ( obj -- elt )
```

- 传入一个**整数**`n`时，它返回`[0, n)`中的一个随机整数：

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- 传入一个**序列**时，它返回一个随机元素：

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

要掷一颗普通骰子，把范围整体加一就行：`6`的`random`结果在 0 到 5 之间，所以`6 random 1 +`会得到 1 到 6。

## 抽取多个值

要收集固定数量的随机结果，可以用`replicate`（在 [`sequences`][sequences] 中）重复执行一个引用：

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`：原地洗牌

`randomize`（在 [`random`][random] 中）返回元素顺序随机的同一个序列：

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

它会**原地**洗牌，并返回同一个序列，所以如果你需要保留原来的顺序，请先`clone`。

## `sample`：多个不同的元素

`sample`（在 [`random`][random] 中）从一个序列中抽取`n`个*不同的*元素，就像发一手牌，绝不会出现两张一样的牌：

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

请求的元素数量超过序列实际拥有的数量就会出错。

## 可复现的随机性

默认情况下，`random`从一个用系统时钟播种的全局生成器中取值，所以每次运行的结果都不一样。在测试中，或者任何时候你想要一个能*重放*的游戏，都可以用一个固定的**种子**来绑定生成器。

`<mersenne-twister>`（在 [`random.mersenne-twister`][mt] 中）用整数种子构建一个生成器，`with-random`（在 [`random`][random] 中）则在装好该生成器的情况下运行一个引用：

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

引用内部的一切，`random`、`randomize`、`sample`，都从这个已播种的生成器中取值，所以同一个种子总能重现同样的结果。

如果一个单词接收引用作为实参，并通过`with-random`运行它，就落在[把单词标记为`inline`](#marking-a-word-inline)那条规则的范围内：`with-random`最终会`call`ing 那个引用，所以这样的包装单词必须标记为`inline`。
