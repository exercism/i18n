# 简介

条件表达式用于根据条件是**true**还是**false**来执行代码。这类表达式写成：

```haxe
if (condition) {
  expressions
};
```

条件的结果是`Bool`类型，所以当结果为`true`时，就会执行其中的表达式。

有时条件实际为`false`，但我们希望执行另一段代码，这时就要用到`else`表达式。当初始条件为`false`时，`else`会执行相应的表达式。但如果想针对多种可能的情况检查条件呢？这时就用`else if (condition)`。下面是一个完整的例子：

```haxe
var a = 10;

if (a == 2) {
  trace("a is 2");
} else if (a == 5) {
  trace("a is 5");
} else {
  trace("a is 10");
}

// a is 10
```
