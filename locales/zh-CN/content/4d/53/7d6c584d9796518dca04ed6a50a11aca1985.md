# 安装

## Ubuntu（以及其他大多数基于 Debian 的发行版）

要在本地构建代码，你需要 gcc 和 make，可以通过下面的命令安装

```shell
sudo apt install gcc make
```

如果你的硬件不是 ARM64，请使用下面的命令安装 [QEMU][] 模拟器和 GCC ARM64 交叉工具链

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

使用 [Windows Subsystem for Linux][] 搭配基于 Debian 的发行版，然后按照上面的 Ubuntu 步骤操作。或者，搭建一台 Linux 虚拟机。

## macOS

可以用任何合适的虚拟化方案启动一台 Linux 虚拟机（例如 [Lima][]）。

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
