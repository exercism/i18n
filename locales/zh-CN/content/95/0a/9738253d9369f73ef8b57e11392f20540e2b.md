# 简介

错误总会发生。在 Elixir 里，虽然人们常说“让它崩溃”，但有时我们仍然需要把函数调用挽救到一个已知的良好状态，以满足软件约定。在某些语言中，错误被用作控制流的一种手段，但在 Elixir 里，这种模式并不被提倡。我们常常只看函数的名字就能认出哪些函数可能会抛出错误：会抛出错误的函数，名字末尾带 `!`。这一点与那些返回 `{:ok, value}` 或 `:error` 的函数形成对比。看看下面这些库示例：

```elixir
Map.fetch(%{a: 1}, :b)
# => :error
Map.fetch!(%{a: 1}, :b)
# => raises KeyError
```
