# 介绍

在 Go 中，你可以用`for`和下标来遍历`slice`，也可以使用`range`。`range`还允许你遍历`map`。

每次迭代都会返回两个值：下标/键，以及该下标/键对应元素的副本。

## 遍历 slice

小菜一碟，遍历`slice`时，顺序和预期一致。

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(i, x)
}
// outputs:
// 0, 10
// 1, 20
// 2, 30
```

## 遍历 map

遍历`map`会带来一个新问题。
现在的顺序是随机的。

```go
hash := map[int]int{9: 10, 99: 20, 999: 30}
for k, v := range hash {
  fmt.Println(k, v)
}
// outputs, for example:
// 99 20
// 999 30
// 9 10
```

~~~~exercism/note
上面的输出看起来可能不对，因为人们会以为在声明 map 时最先出现的键值对`9 10`应该最先打印，而不是最后一个。
然而，map 天生就是无序的，并不存在第一个或最后一个键值对。
因此，在遍历 map 的条目时，访问条目的顺序是随机的，不会遵循任何特定规律。
这意味着上面的输出是有可能的，但你自己运行这段代码时得到的结果可能不一样。
想了解更多，请参阅 [Go 语言规范：range 子句](https://go.dev/ref/spec#RangeClause)。
~~~~

## 省略键或值的迭代

在 Go 中，未使用的变量会在构建时引发错误。
有时你只需要值，就像第一个例子那样：

```go
xi := []int{10, 20, 30}
for i, x := range xi {
  fmt.Println(x)
}
// Go build failed: i declared but not used
```

你可以用`_`替换`i`，这告诉编译器我们不使用那个值：

```go
xi := []int{10, 20, 30}
for _, x := range xi {
  fmt.Println(x)
}
// outputs:
// 10
// 20
// 30
```

如果你只想打印下标，可以用`_`替换`x`，或者干脆省略声明：

```go
xi := []int{10, 20, 30}
// for i, _ := range xi {
for i := range xi {
  fmt.Println(i)
}
// outputs:
// 0
// 1
// 2
```

## 定义类型

类型定义会创建一个新的具名类型，它与其他任何类型都不相同，哪怕另一个类型的底层类型和它一样。

```go
type File []bool
```

这里的`File`指的是棋盘上的一条竖列，通常用 A 到 H 标注。
这一列中的每个格子都用一个布尔值表示，标记它是否被占据。
既然`File`已经定义好了，我们就可以在其他定义里使用它：

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard`把列的标识符映射到`File`值。
每个`File`都是一个布尔值切片，表示一条竖列中的各个格子。
没有这些类型定义，`board`就会是`map[string][]bool`，这会让人更难理解我们到底在表示什么。
