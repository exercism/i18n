# 关于

集合类型的定义通常包含一个尖括号括起来的占位符，按照惯例常常是 T。这样的集合被称为泛型类型。这样，集合的使用者就可以指定集合中存放的是哪种类型的元素。在上面的示例代码中，我们实例化了一个字符串数组。

让一个类或函数变成**泛型**的方式，是使用 `@:generic` 特性。这会让编译器将该类或函数识别为泛型：

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
