# 简介

## 异常

C# 中的异常为处理运行时发生的错误情况提供了一种结构化、统一且类型安全的方式。想要防止应用程序崩溃，妥善处理异常和错误就很重要。

在 C# 中，所有异常的基类型都是`System.Exception`类。它包含一些重要的属性，例如`Message`，其中含有供人阅读的说明，解释抛出该异常的原因。

如果要在代码的某个部分表明出现了错误，就需要创建一个新的异常对象，然后用`throw`关键字把它抛出：

```csharp
using System;
static int Square(int number)
{
    if (number >= 46341)
    {
        throw new ArgumentException($"Argument {number} cannot be higher than 46340 as its' square doesn't fit into int type.");
    }
    return number * number;
}
```

异常被抛出后，运行时会负责找到处理该异常的那段代码。如果找不到合适的处理程序，运行时除了停止程序的执行外，还会显示未处理异常的消息。

要为异常创建处理程序，C# 使用 try-catch 语句，它由一个`try`代码块和一个或多个`catch`子句组成。`try`代码块中应当包含并守护可能抛出异常的代码。`catch`子句则应当包含在错误发生后处理程序行为的代码。需要注意，`try`代码块之后各异常的顺序很重要：当列出多个异常时，会执行第一个匹配的`catch`子句。

```csharp
try
{
   if (number == 42)
   {
       throw new ArgumentException("The number cannot be equal to 42.", "number");
   }

   if (number < 0)
   {
      throw new ArgumentOutOfRangeException("number", "The number cannot be negative.");
   }

    // Process number ...
}
catch (ArgumentOutOfRangeException e)
{
    Console.WriteLine($"Number is out of range: {e.Message}.");
}
catch (ArgumentException)
{
    Console.WriteLine("Invalid number.");
}
```
