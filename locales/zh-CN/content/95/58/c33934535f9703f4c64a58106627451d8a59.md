# 说明补充

## 本练习在 Python 中的结构

本练习最好用 Python 的 `%`（[求模][modulo]）运算符来解决，它返回正整数除法的余数。
它有一个等价的方法，即[运算符模块][operator-mod]中的 `operator.mod()`。

Python 在[数学模块][math-module]中还提供了其他一些“求余”方法。
[`math.fmod()`][fmod] 的行为与 `%` 类似，但它操作的是浮点数。
[`math.remainder()`][remainder] 用一种“最接近零的一步”算法来计算除法的余数。
我们鼓励你熟悉这些方法，但它们都不会与 `%` 的结果完全一致，因此不建议在本练习中使用。

内置函数 [`divmod()`][divmod] 在用于两个正整数时，也能得到与 `%` 一致的余数，但它返回的是一个需要解包的 `tuple`。
