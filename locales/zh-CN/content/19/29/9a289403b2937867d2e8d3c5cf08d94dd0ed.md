# 简介

[Python 之禅][zen-of-python]主张，“做一件事应该有一种*明显*的方式”。
对于 Python 3.6+，[**字面量字符串插值**][string-interpolation]（[**`f-string`**][f-string]）通常是格式化字符串时最直观、也最受青睐的方式：

```python
>>> adjective = "easy"
>>> f"This is an {adjective} way to format strings!"
'This is an easy way to format strings!'
```

不过，鉴于 Python 历史悠久、应用场景多样，Python 中还有**三种**其他常见的字符串格式化方式，也就不足为奇了：

1. [`str.format()`][str-format]功能全面、非常强大，并且既兼容 [`gnu gettext`][gettext]，也兼容大多数 Python 版本。
2. 如果你需要的是简单、安全，或者大量的国际化处理，可以用 [`string.Template()`][string-template]来降低处理输入时的风险，也适合包装要翻译的字符串。
3. `%`运算符在新代码中通常被认为已经过时，不过在如今的 Python 中它仍然有效。
  它主要用于兼容较旧的代码库。
  `%`格式化在显示非 ASCII 和 Unicode 字符时可能会出问题，而且和其他方式相比，错误更多、功能更少。
  如果你打算使用它，请查看你所用的具体 Python 发行版，了解支持情况。
