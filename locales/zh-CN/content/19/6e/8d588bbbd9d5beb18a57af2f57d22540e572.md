# 说明补充

## 寄存器

| 寄存器   | 用途     | 类型   | 说明                          |
| -------- | -------- | ------ | ----------------------------- |
| `$a0`    | 输入     | 地址   | 第一个以 null 结尾的字符串    |
| `$a1`    | 输入     | 地址   | 第二个以 null 结尾的字符串    |
| `$v0`    | 输出     | 整数   | 汉明距离                      |
| `$t0-9`  | 临时     | 任意   | 用于临时存储                  |
