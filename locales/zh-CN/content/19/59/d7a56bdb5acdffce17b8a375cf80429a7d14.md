# 简介

`const`修饰符可以（而且通常应该）用于任何在编译时就能确定其值、并且在程序运行期间不会改变的字段。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly`修饰符可以（而且通常应该）用于任何无法设为`const`的字段。这类字段的值在程序运行期间不会改变，并且要么由内联初始化器设置，要么在实例化时设置（由构造函数或由构造函数调用的方法设置）。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```
