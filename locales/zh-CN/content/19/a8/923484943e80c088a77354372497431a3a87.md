# 简介

## 位数组

处理二进制数据可能很棘手，因此 Gleam 提供了`BitArray`类型以及配套语法，用来构造二进制数据，并对其进行模式匹配。

位数组字面量使用`<<>>`语法定义。定义位数组字面量时，它按段来定义。每个段都有一个值和标注，二者用`:`分隔。标注指定用多少位来编码该值，并且可以完全省略；省略时会默认为 8 位整数值。

```gleam
// This defines a bit array with three segments of a single bit each
<<0:1, 1:1, 0:1>>

// This defines a bit array with three segments of 8 bits each
<<0, 1, 0>>
```

将类型指定为`:1`是写`:size(1)`的简写。如果位大小来自变量，就需要使用较长的语法。

```gleam
let segment_size = 1
<<0:size(segment_size), 1:size(segment_size), 0:size(segment_size)>>
```

### 二进制

写二进制整数字面量时，可以直接用二进制表示法来写，只需在字面量前加上`0b`。注意，在测试或程序中打印时，它们会显示为十进制数。

```gleam
<<0b1011:4>> == <<11:4>>
// -> True
```

### 截断

如果段的值超出该段类型的容量，就会从左侧截断。

```gleam
<<0b1011:3>> == <<0b0011:3>>
// -> True
```

### 前置与追加

你可以使用位数组语法，在现有位数组的前面添加内容，也可以在其后面追加内容。对现有位数组必须使用`:bits`标注。

```gleam
let value = <<0b110:3, 0b001:3>>
let new_value = <<0b011:3, value:bits, 0b000:3>>
// -> <<120, 8:size(4)>>
```

### 拼接

我们可以使用位数组语法拼接存储在变量中的位数组。拼接两个大小可变的位数组时，必须使用`:bits`标注。

```gleam
let first = <<0b110:3>>
let second = <<0b001:3>>
let concatenated = <<first:bits, second:bits>>
// -> <<49:size(6)>>
```

### 模式匹配

还可以通过模式匹配从位数组中获取值。你必须知道要捕获的每个段的位数，但有一个例外：`:bits`标注可用于对大小未知的位数组进行模式匹配，不过它只能用于最后一个段。

```gleam
let assert <<value:4, rest:bits>> = <<0b01101001:8>>
value == 0b0110
// -> True
```

### 检查位数组

~~~~exercism/note
位数组打印出来的格式可能不同于创建它们时使用的格式。这在学习位数组时常常会造成困惑。
~~~~

默认情况下，位数组以 8 位（一个字节）为一段来显示，即使你创建它们时使用的段大小不同。

```gleam
<<2011:11>>
// -> <<251, 3:size(3)>>
```

如果你创建的位数组表示可打印的 UTF-8 编码字符串，它可能会被`io.debug`之类的函数显示为字符串。这是由于 Gleam 在内部表示字符串的实现细节。

```gleam
<<>>
// -> ""

<<65, 66, 67>>
// -> "ABC"
```
