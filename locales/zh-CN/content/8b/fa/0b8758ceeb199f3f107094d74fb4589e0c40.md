# 表示

[Java 表示器][github-java-representer]会进行以下规范化：

- 所有注释都会被移除
- 所有 import 声明都会被移除
- 标识符会被规范化为占位值

完成上述规范化后，生成的表示会按照 [Google Java Style][google-java-style] 进行格式化，以消除代码格式上残留的差异。

## 提交之前

请检查以下几点：

- 你没有重复分析器给出的反馈。
- 你检查提交对话框中的“示例”标签页，看看反馈是否对所有标签页都说得通。
- 你确认自己没有提到空白符或注释。
- 你确认自己没有提及提交的解答中出现的函数名或变量名，而是使用提供的映射（或者省略名字）。
  只有练习测试用到的标识符才能放心提及，因为对每个人来说它们总是相同的。
