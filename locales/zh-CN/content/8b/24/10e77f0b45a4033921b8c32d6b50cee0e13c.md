# 简介

## 迭代器

Gleam 中的`Iterator`和数组类似，它是有序的值集合，其中所有值的类型都相同。它和数组的不同之处在于它是惰性的，也就是说它不会一次把所有值都存进内存，而是按需计算。

在处理非常大的、甚至无限长的序列时，这一点很有用，因为即使没有足够的空闲内存一次性存下全部值，我们也能处理它们。

`gleam/iterator`模块定义了`Iterator`类型，也定义了各种用于操作迭代器的函数。

很多用于数组的函数在迭代器上也有，比如`map`、`filter`和`take`。这些函数返回迭代器，所以在迭代器被消费之前，它们实际上不会做任何工作。

```gleam
let iter = 
  [1, 2, 3, 4, 5, 6]
  |> iterator.from_list
  |> iterator.filter(fn(x) { x > 2 })
  |> iterator.take(2)

// No work has been done yet as the iterator has not been consumed

// Consume the iterator and collect the values into a list
iterator.to_list(iter)
// -> [3, 4]
```

`unfold`函数可以用一个会被反复调用的函数来创建迭代器，这个函数负责生成序列中的下一个值。

这里用`unfold`函数创建了一个生成斐波那契数列的迭代器：

```gleam 
iterator.unfold(#(0, 1), fn(pair) {
  let x = pair.0 + pair.1
  iterator.Next(element: x, accumulator: #(pair.1, x))
})
|> iterator.take(6)
|> iterator.to_list
// -> [1, 2, 3, 5, 8, 13]
```

这里的序列是无限的，所以在把值收集到数组里之前，要先用`take`函数让它变成有限的。如果对一个无限迭代器调用`to_list`，程序会一直运行，直到内存耗尽并崩溃。
