# SQLite 专用说明

**result**列应包含 JSON 编码的对象，其值也都是对象：每个单词作为键，计数为整数值。

例如，看上面那个句子：`"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
这段输入的**result**应为：

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## 表结构

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
