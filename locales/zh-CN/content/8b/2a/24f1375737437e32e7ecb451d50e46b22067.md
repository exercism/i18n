# 简介

过滤是指从另一个序列创建新序列的过程，做法是复制原序列中除某些元素之外的所有元素。
新序列要包含哪些元素，可以由谓词函数（求值结果为布尔值的函数）决定，也可以由与某个特定对象的相等性决定。

## 用谓词移除

`remove-if`是一个函数，接受一个谓词函数和一个序列作为实参，返回的序列只包含那些谓词求值结果为 false 的元素。
换句话说，它会把序列中所有让谓词求值结果为 true 的元素“移除”掉。不过要注意，这个函数不会修改原序列！
它返回的是一个去掉了相应元素的新序列。如果谓词对所有的值都为 true，则返回一个空序列。

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## 移除特定元素

如果想从序列中移除某个特定元素，可以使用`remove`，它接受要移除的元素和一个序列。
返回的是序列中所有不等于要移除的那个元素的值。
注意：默认情况下，相等性由`eql`[通用相等谓词][concept-equality]来检查。

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
