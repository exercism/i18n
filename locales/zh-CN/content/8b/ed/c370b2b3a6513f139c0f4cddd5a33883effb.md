# 提示

## 概述

- [`Map` API 文档][map-docs] 中列出了 `Map` 接口上可用的方法。

## 1. 返回映射中的区号

- 你需要以[某种方式][declaring-members]定义一个`Map`，这样才能在类的方法中使用它。

## 2. 向字典中添加条目

- 映射有一个[方法][map-put-docs]，可以添加和更新某个键的值。

## 3. 查找区号对应的国家

- 映射有一个[方法][map-get-docs]，可以获取键对应的值。

## 4. 不允许重复

- 有办法检查映射中是否存在某个[键][map-contains-key-docs]或[值][map-contains-value-docs]。

## 5. 查找某个国家的区号

- 有一种[方式][map-entry-set-docs]，可以获取映射中所有条目的可迭代集合，从而遍历这些键值对。

## 6. 更新某个国家的区号

- 别忘了，这个国家之前的区号仍然会留在映射中。
- 有一个[方法][map-remove-docs]，可以从映射中移除条目。
