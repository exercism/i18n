# 测试


我们使用 [pytest][pytest: Getting Started Guide] 作为网站的测试运行器。
如果你想在本地运行 Python 轨道的测试，就需要在自己的开发机上安装`pytest`。
你还应该安装以下`pytest`插件：

- [pytest-cache][pytest-cache]
- [pytest-subtests][pytest-subtests]

更多信息可以在我们网站的 [Python 测试指南][Python track tests page] 中找到。


### 运行测试

要运行附带的测试，请在终端里用`cd`进入练习所在的文件夹（_把下面的`<exercise-folder-location>`替换成你自己的路径_）。
测试文件通常以`_test.py`结尾；你在网站上上传解答时，运行的就是这些测试。

Linux/MacOS
```bash
$ cd <path/to/exercise-folder-location>
```

Windows
```powershell
PS C:\Users\foobar> cd <path\to\exercise-folder-location>
```

<br>

接下来，在终端里运行`pytest`命令，把`<exercise_test.py>`换成测试文件的名字：

Linux/MacOS
```bash
$ python3 -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```

Windows
```powershell
PS C:\Users\foobar> py -m pytest -o markers=task <exercise_test.py>
==================== 7 passed in 0.08s ====================
```


### 常用选项
- `-o`：覆盖默认的`pytest.ini`（_可以用它来避免标记警告_）
- `-v`：启用详细输出。
- `-x`：第一次失败就停止运行测试。
- `--ff`：先运行上次失败的测试，再运行其他测试用例。

更多选项请使用`python3 -m pytest -h`或`py -m pytest -h`。


### 消除警告

调用`pytest`时如果没有加上`pytest -o markers=task`，对于那些使用我们新语法的测试，你可能会收到`PytestUnknownMarkWarning`：

```bash
PytestUnknownMarkWarning: Unknown pytest.mark.task - is this a typo?  You can register custom marks to avoid this warning - for details, see https://docs.pytest.org/en/stable/mark.html
```

为了避免每次运行测试都要输入`pytest -o markers=task`，你可以使用一个`pytest.ini`配置文件。
我们做好了一个，可以从 Python 轨道目录的顶层下载：[pytest.ini][pytest.ini]。

你也可以按照下面的内容创建自己的`pytest.ini`文件：

```ini
[pytest]
markers =
    task: A concept exercise task.
```

把`pytest.ini`文件放在 Python 轨道练习的_根目录_或_工作目录_下，就能注册这些标记并消除警告。
关于 pytest 标记的更多信息，可以在`pytest`文档的[标记测试函数][pytest: marking test functions with attributes]和[使用自定义标记][pytest: working with custom markers]中找到。

关于自定义 pytest 配置的信息，可以在`pytest`文档的[配置文件格式][pytest: configuration file formats]中找到。
