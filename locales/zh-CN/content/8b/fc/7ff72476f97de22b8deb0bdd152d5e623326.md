# 在`jq`中调试的技巧

`jq`自带一个很方便的[`debug`][debug]过滤器。在开发练习解答的过程中，可以用它来查看当前流经 jq 管道的数据。

`debug`会把一个“调试数组”打印到**stderr**。它会原样输出输入。数组的第一个元素是字符串“DEBUG:”。第二个元素取决于你如何调用`debug`。

1. 不带参数的`debug`函数会把输入的一个紧凑表示放进调试数组：

   ```sh
   jq -n '[11, 22, 33] | debug | map(. * 2)'
   ```

   输出

   ```none
    ["DEBUG:",[11,22,33]]
    [
      22,
      44,
      66
    ]
   ```

2. 带一个参数的版本会把输入传给指定的过滤器：

   ```sh
   jq -n '[11, 22, 33] | debug("length: \(length), last: \(.[-1])") | map(. * 2)'
   ```

   ```none
    ["DEBUG:","length: 3, last: 33"]
    [
      22,
      44,
      66
    ]
   ```

   过滤器不必是字符串。它可以是任何东西，包括用逗号分隔的多个表达式，从而得到“多行”的调试输出：

   ```sh
   jq -n '[11, 22, 33] as $a | 44 | debug("I am here:", $a, .)'
   ```

   ```none
   ["DEBUG:","I am here:"]
   ["DEBUG:",[11,22,33]]
   ["DEBUG:",44]
   44
   ```

[debug]: https://jqlang.org/manual/#debug
