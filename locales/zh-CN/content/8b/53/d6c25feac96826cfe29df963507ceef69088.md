# 简介

## 枚举

_枚举类型_是一种特殊的数据类型，它让变量的取值可以是一组预定义的常量。
变量必须等于为它预定义的值之一。
常见的例子包括指南针方向（`NORTH`、`SOUTH`、`EAST`和`WEST`这几个值）以及一周中的各天。

由于它们是常量，枚举类型中字段的名称使用大写字母。

### 定义枚举类型

在 Java 编程语言中，使用 `enum` 关键字来定义枚举类型。
例如，你可以这样定义一个表示一周中各天的枚举类型：

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

只要你需要表示一组固定的常量，就应该使用枚举类型。
这包括像太阳系中的行星这样的自然枚举类型，以及你在编译时就知道所有可能取值的数据集，例如菜单中的选项、命令行标志等等。

### 使用枚举类型

下面这段代码展示了如何使用上面定义的 `DayOfWeek` 枚举：

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### 添加方法和字段

Java 编程语言的枚举类型比其他语言中对应的类型强大得多。
`enum` 声明定义了一个_类_（称为_枚举类型_）。
枚举类的类体可以包含方法和其他字段：

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

在 `Rating` 枚举类型的某个成员上调用 `getNumberOfStars` 方法：

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
