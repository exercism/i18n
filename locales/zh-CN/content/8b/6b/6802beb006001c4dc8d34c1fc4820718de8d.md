# 说明

你的任务是创建一个密码检查器。
密码检查器会验证用户提出的密码，确保它满足一组由控制该资源访问权限的组织所定义的要求。

在本练习中，密码的要求如下：
* 必须包含 12 个或更多字符
* 必须至少包含一个大写字母
* 必须至少包含一个小写字母
* 必须至少包含一个数字
* 必须至少包含一个符号，该符号来自集合 !@#$%^&*

你的解答必须使用`Result`来封装成功或失败的状态。
对于成功的情况，`Result`必须以字符串的形式给出通过验证的密码。
对于失败的情况，`Result`必须给出失败时被违反的那条规则。

~~~~exercism/note
在本练习中，密码检查器会非常简化，它只会在有一条规则被违反时给出提示。
后续的练习会探讨一个更贴近现实的密码检查器，它可以同时指出多条被违反的规则。
~~~~

## 1. 实现`checkPassword`函数

`checkPassword`函数会根据上述规则检查给定的密码。检查失败时，它会把某个`PasswordRule`值封装在结果值中，以此来指出被违反的规则。

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. 实现``getStatusMessage`函数

`getStatusMessage`函数会返回一个字符串，其中包含一条人类可读的消息，说明`checkPassword`所返回结果的含义。

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
