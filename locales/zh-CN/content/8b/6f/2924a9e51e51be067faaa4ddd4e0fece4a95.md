# 简介

## 递归

递归函数就是会调用自身的函数。

递归函数至少需要一个*基准情形*和一个*递归情形*。

*基准情形*会直接返回一个值，不再调用函数本身。
*递归情形*会再次调用函数，同时修改输入，使它最终能够匹配基准情形。

在 Elm 中，递归函数通常用模式匹配来定义，也就是使用`case`表达式或多个函数子句。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### 用递归实现循环

由于不可变性，Elm 中的循环写法和命令式语言不同。
例如，循环通常长这样：

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

在 Elm 这样的函数式语言里，无法修改变量。
因此，循环只能用递归来实现。

在 Elm 中，与`for`循环等价的形式是这样的：

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

实践中，在 Elm 里遍历数组和其他数据结构，最常用的方法是使用`List`模块中的函数，比如`List.map`、`List.filter`和`List.foldl`。
在底层，这些函数都是用递归实现的。
