# 简介

## 外部函数

Gleam 可以运行在 Erlang 虚拟机（BEAM）上，也可以运行在 JavaScript 运行时上。还有许多其他语言也使用这些运行时，而从 Gleam 中调用用这些语言编写的代码往往很有用。

Gleam 的_外部函数_特性允许把其他语言中的函数导入 Gleam 并调用，且不会带来运行时开销。

如果你的 Gleam 项目运行在 Erlang 虚拟机上，并且你想调用 Erlang `lists`模块中的 `reverse`函数，可以像这样给 Gleam 的函数头部添加 `@external`属性：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

这样就可以像调用普通 Gleam 函数一样调用它：

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

如果你尝试为 JavaScript 运行时编译这段代码，编译会失败并给出错误信息，因为 JavaScript 没有对应的实现。可以像这样为 JavaScript 运行时指定另一个实现：

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

也可以编写一个 Gleam 实现，在当前编译目标没有外部实现时使用：

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```

## 外部类型

外部类型可以用来引用其他语言中定义的数据类型，例如 Erlang 或 JavaScript。

要定义外部类型，只需声明一个类型，但不提供任何构造函数。之后就可以像使用其他任何类型一样使用它。

```gleam
pub type OrderedDictionary(element)
```
