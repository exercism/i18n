# 简介

Gleam 中有两种不同的数字：整数和浮点数。

整数是不带小数部分的数字。

```gleam
let integer = 3
// -> 3
```

为了提高可读性，整数中也可以加入下划线。

```gleam
1_000_000 // One million
```

Gleam 提供了几个可用于整数的运算符。

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
