# 介绍

二进制数字最终直接对应到 CPU 或 RAM 里的晶体管，以及每个晶体管是“开”还是“关”。

底层操作，俗称“摆弄比特”，在系统编程语言中尤为重要。

像 Julia 这样的高级语言通常会把这些细节大部分抽象掉。
不过，这门语言本身就提供了一整套位级运算。

***注意：*** 想在 REPL 里看到人类可读的二进制输出，下面几乎所有的例子都需要用`bitstring()`函数包一层。
这在视觉上很干扰阅读，所以大部分地方都把这个函数省略掉了。

## 移位运算

整数类型，无论有符号还是无符号，都可以表示成一串 1 和 0。

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

移位就是把所有位向左或向右移动指定的位数。
对于`UInt`类型，一端会有一些位被挤掉，另一端则用零补齐：

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

每次左移都会让值翻倍，每次右移都会让值减半（会发生截断）。
用十进制表示会更明显：

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

这种移位比“正经”的算术运算快得多，所以这个技巧在底层编程中非常流行。

对于有符号整数，就得更小心一点了。

左移相对简单：

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

因此，左移正的有符号整数和无符号整数是一样的。

负值以[补码][2complement]形式存储，也就是说最左边的那一位是 1。
左移没问题，但右移时，最左边的那些位该怎么补呢？

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

`>>`运算符执行算术移位，会保留符号位。

`>>>`运算符执行逻辑移位，像对待无符号数那样用零补齐。

## 按位逻辑

在前面的概念中我们看到，运算符`&&`（与）、`||`（或）和`!`（非）用于布尔值。

还有对应的运算符`&`（按位与）、`|`（按位或）和`~`（波浪号，按位非），用来比较两个整数中的各位。

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

这里的`xor()`表示异或，是以函数的形式使用的。

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
