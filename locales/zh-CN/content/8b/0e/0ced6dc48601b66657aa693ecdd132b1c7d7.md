# 说明

你正在开发一款备受好评的新游戏**Crystal Hunter**。
在游戏中，你扮演一个四处走动、收集水晶的角色。
玩家捡起所有水晶即可获胜。
如果玩家碰到强盗，就会失去所有水晶，并且输掉游戏。
这条规则有一个例外：玩家可以拥有激活的能量道具，让强盗看不见自己。

你的任务是编写一些将在游戏中使用的规则。

## 1. 判断角色是否获得奖励点数

在游戏中，如果角色在拥有能量道具的情况下碰到强盗，就会获得奖励点数。

定义`Rules#bonus_points?`方法，它接收两个实参（_角色是否拥有激活的能量道具_ 和 _角色是否正碰到强盗_），并返回一个布尔值，表示角色是否会获得奖励点数。
只有当角色拥有激活的能量道具且正碰到强盗时，该方法才应返回`true`，否则返回`false`。

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. 判断角色是否得分

在游戏中，玩家捡起水晶或能量道具时会得分。

定义`Rules#score?`方法，它接收两个实参（_角色是否正碰到能量道具_ 和 _角色是否正碰到水晶_），并返回一个布尔值，表示角色是否得分。
如果角色碰到能量道具或水晶，该方法应返回`true`，否则返回`false`。

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. 判断角色是否失败

定义`Rules#lose?`方法，它接收两个实参（_角色是否拥有激活的能量道具_ 和 _角色是否正碰到强盗_），并返回一个布尔值，表示角色是否失败。
如果角色碰到强盗且没有激活的能量道具，该方法应返回`true`，否则返回`false`。

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. 判断角色是否获胜

定义`Rules#win?`方法，它接收三个实参（_角色是否已捡起所有水晶_、_角色是否拥有激活的能量道具_，以及_角色是否正碰到强盗_），并返回一个布尔值，表示角色是否获胜。
如果角色已收集所有水晶，并且根据第 3 部分定义的实参判断没有失败，该方法应返回`true`，否则返回`false`。

```crystal
Rules.new.win?(false, true, false)
# => false
```
