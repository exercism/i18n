# 说明

在这个练习中，你要为一个朋友正在开发的新 RPG 游戏实现任务逻辑。
游戏的主角是 Annalyn，一个勇敢的女孩，她有一只凶猛又忠诚的宠物狗。
不幸的是，灾难降临了：她最好的朋友在森林里采浆果时被绑架了。
Annalyn 会设法找到并解救她最好的朋友，在这次冒险中她可以选择带上她的狗。

沿着最好朋友的踪迹追踪了一段时间后，她找到了关押她最好朋友的营地。
原来有两个绑匪：一个强大的骑士和一个狡猾的弓箭手。

找到绑匪后，Annalyn 开始考虑自己可以采取以下哪些行动：

- _快速攻击_：如果骑士正在睡觉，就可以发动快速攻击，因为他穿上盔甲需要时间，所以会处于脆弱状态。
- _侦察_：只要他们中至少有一个人醒着，就可以侦察这群人。
  否则，侦察只是浪费时间。
- _向囚犯发信号_：如果囚犯醒着而弓箭手正在睡觉，就可以用鸟叫声向囚犯发信号，因为弓箭手受过鸟叫信号的训练，可能会截获消息。
- _解救囚犯_：Annalyn 可以试着潜入营地去解救囚犯。
  这很冒险，只有两种方式之一能成功：
  - 如果 Annalyn 带着她的宠物狗，那么只要弓箭手睡着了，她就能救出囚犯。
    骑士怕狗，而弓箭手来不及准备好，Annalyn 和囚犯就能逃走。
  - 如果 Annalyn 没带狗，那她和囚犯就必须非常小心！
    如果囚犯醒着，且骑士和弓箭手都在睡觉，Annalyn 就能解救囚犯；但如果囚犯在睡觉，就无法救他：囚犯会被 Annalyn 的突然出现吓到，从而吵醒骑士和弓箭手。

你有四个任务：根据森林里这三个角色的状态以及 Annalyn 的宠物狗是否在场，实现判断上述行动是否可用的逻辑。

## 1. 检查是否可以发动快速攻击

定义`can_fast_attack()`函数，它接收一个布尔值，表示骑士是否醒着。
如果根据骑士的状态可以发动快速攻击，该函数返回`true`。
否则返回`false`：

```rust
let knight_awake = true;
can_fast_attack(knight_awake); // false
```

## 2. 检查是否可以侦察这群人

定义`can_spy()`函数，它接收三个布尔值，分别表示骑士、弓箭手和囚犯是否醒着。
如果根据这三个角色的状态可以侦察这群人，该函数返回`true`。
否则返回`false`：

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
can_spy(knight_awake, archer_awake, prisoner_awake); // true
```

## 3. 检查是否可以向囚犯发信号

定义`can_signal_prisoner()`函数，它接收两个布尔值，分别表示弓箭手和囚犯是否醒着。
如果根据这两个角色的状态可以向囚犯发信号，该函数返回`true`。
否则返回`false`：

```rust
let archer_awake = false;
let prisoner_awake = true;
can_signal_prisoner(archer_awake, prisoner_awake); // true
```

## 4. 检查是否可以解救囚犯

定义`can_free_prisoner()`函数，它接收四个布尔值。
前三个形参分别表示骑士、弓箭手和囚犯是否醒着。
最后一个形参表示 Annalyn 的宠物狗是否在场。
如果根据这三个角色的状态以及 Annalyn 的宠物狗是否在场可以解救囚犯，该函数返回`true`。
否则返回`false`：

```rust
let knight_awake = false;
let archer_awake = true;
let prisoner_awake = false;
let dog_present = false;
can_free_prisoner(knight_awake, archer_awake, prisoner_awake, dog_present); // false
```
