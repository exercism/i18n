# 介绍

ABAP 支持一种面向对象的编程模型，它基于 ABAP Objects 的类和接口。

## （重新）赋值

在 ABAP 中，给名称赋值主要有几种方式：使用变量或常量。在 Exercism 上，变量一律用[蛇形命名法][wiki-snake-case]书写。这方面没有官方指南可循，不同的公司和组织各有各的风格指南。_你可以随意选择变量的写法_。按练习准备好的方式来写，好处是它们在网页界面和大多数 IDE 中会有不同的高亮效果。

在 ABAP 中，可以使用关键字[`constant`][constant]或[`data`][data]来定义变量。

使用`data`时，变量在其生命周期内可以引用不同的值。例如，可以用[赋值运算符 `=`][assignment]多次定义和重新定义`my_first_variable`：

```abap
DATA my_first_variable TYPE i. " integer

my_first_variable = 1.
my_first_variable = 4711 * 3.
my_first_variable = some_complex_calculation( ).
```

与`data`不同，用`constant`定义的变量只能赋值一次。在 ABAP 中，常量就是这样定义的。

```abap
CONSTANT my_first_constant TYPE i VALUE 10.

" Can not be re-assigned
my_first_constant = 20.
// => SyntaxError: Assignment to constant variable.
```

## 类与方法声明

在 ABAP 中，功能单元被封装在_方法_里：如果若干方法属于同一个[类][classes]，通常会把它们归到一起。这些方法可以接收形参（实参），并且可以在方法定义中用`returning`关键字_返回_一个值。方法通过`( )`语法调用。

```abap
CLASS my_class DEFINITION.

  PUBLIC SECTION.

    METHODS add
      IMPORTING
        num1          TYPE i
        num2          TYPE i
      RETURNING
        VALUE(result) TYPE i.

ENDCLASS.

CLASS my_class IMPLEMENTATION.

  METHOD add.
    result = num1 + num2.
  ENDMETHOD.

ENDCLASS.

add( num1 = 1 num2 = 3 ).
// => 4
```

> 💡 在 ABAP 中，声明类和方法的方式_非常多_。本学习路径会逐步介绍它们，不过如果你已经了解，可以随意使用其中任何一种。大多数情况下，用哪种都无所谓好坏。
