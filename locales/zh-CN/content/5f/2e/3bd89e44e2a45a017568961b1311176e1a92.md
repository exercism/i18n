# 安装

## Linux

Bash 是 GNU 的 shell，任何 GNU/Linux 系统上都能找到它。
BSD 和其他 UNIX 衍生系统通常需要用户自行安装。
如果你使用的是 BSD、AIX，或者没有自带 bash 的 Linux，请查阅你的操作系统相关资料，了解如何安装非核心软件包。

在你所用的图形界面中，找到名为“Terminal”的应用程序：它可能位于“Administrative/System Tools”一栏下。

要查看可用的 Bash 版本，在命令行或终端中运行：

    echo $BASH_VERSION

如果你的 shell 是`bash`，它应该会显示类似这样的内容：

    4.4.19(1)-release

除此之外你不需要再做别的事：既然 bash 就是你当前使用的 shell，此时它应该已经安装好，并且已经在你的 PATH 中。

如果你的 shell 不是 bash，也没有必要去改它。
即使不在 bash shell 里，你同样可以编写并运行 bash 脚本。

要查看已安装的 bash 版本，运行：

```plain
bash --version
```

它会显示类似这样的内容：

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

如果没有显示，可能说明你还没有安装 bash。
你可以用发行版的包管理器来安装它。

## Windows

对于 Windows 10，你可以安装 [WSL](https://docs.microsoft.com/en-us/windows/wsl/about)。
这会安装一个完整的（嗯，是不带图形界面组件的）Linux 发行版，它原生运行在 Windows 上。

或者，你也可以安装：

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* 在[虚拟机](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)中安装一个完整的 Linux 发行版

## MacOS

对于 Apple OSX：

* 打开 Finder，
* 打开你的 Applications 文件夹，
* 打开 Utilities 文件夹，
* 最后打开`Terminal`应用程序。

请注意，MacOS 上自带安装的 bash 版本非常旧，是 3.2。
这有两个原因：一是较新的 bash 版本采用 GPLv3 许可，二是 Apple 不希望被迫遵守该许可的条款。
此外，Apple 已表示 bash 将逐渐从 MacOS 中淡出：默认登录 shell 最近已[从 bash 改为 zsh](https://support.apple.com/en-us/HT208050)。

要在 Mac 上获得一个最新版的 bash：

1. 安装 [Homebrew](https://brew.sh)
1. 在终端中输入：`brew install bash`

这会安装一个最新版的 bash，路径（我认为）是`/usr/local/bin/bash`（这样系统默认的 bash 就不会被覆盖，其他工具可能依赖 /bin/bash）。

如果你希望输入`bash`时启动的是 Homebrew 的 bash，就编辑你的 ~/.bash_profile（或 ~/.profile）文件，让 /usr/local/bin 在 PATH 中排在 /bin 的*前面*：

    PATH=/usr/local/bin:$PATH
