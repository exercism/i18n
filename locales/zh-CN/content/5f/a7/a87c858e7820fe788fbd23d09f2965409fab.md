# 测试

## 编写代码

在`src/lib.cairo`中编写你的代码。
每个练习都会自带一个`src/lib.cairo`存根文件，其中会展示你需要编写的代码的签名。

对大多数练习来说，最好把全部代码都写在`src/lib.cairo`这个文件里。
如果你想把解答拆分到多个文件中，可以参考 The Cairo Book 的[模块章节][chapter-modules]。

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## 运行测试

要运行测试，首先需要把工作目录切换到你想测试的练习所在的目录：

```bash
cd path/to/exercise
```

然后运行以下命令：

```bash
scarb cairo-test
```

默认情况下，只有第一个测试是启用的。
当你准备好通过下一个测试时，把下一个测试的 ignore 标志（`#[ignore]`）去掉即可。

要运行包括被忽略的测试在内的所有测试，你可以去掉所有测试的`ignore`标志，也可以直接运行：

```bash
scarb cairo-test --include-ignored
```

只要能通过测试，写尽可能少的代码也没关系。
测试失败会告诉你接下来该写什么。

由于 Cairo 会在编译时检查所有代码，你可能会发现，在写出所需的代码之前，测试根本无法编译。
即使是标为`ignore`的测试，也会在编译时被检查。
对于无法编译的测试，你可以把每一行都加上`//`来[注释掉][comments]。
等你准备好处理那个测试时，再取消注释即可。
Cairo 还有一个名为`panic!()`的特殊宏，你可以在尚未完成的代码路径上使用它，让程序通过编译。

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
