# 字符

**字符**是单个字母、数字、空格或符号。Sather 中表示单个字符的类型是 `CHAR`，字符写在单引号之间。

```sather
   initial : CHAR is
      return 'M';
   end;
```

单个字符用单引号，字符串用双引号。`'M'`和`"M"`是不同的类型，不能互换。

## 从字符串中取出字符

字符串是一串字符，用方括号按位置取出其中一个，从 0 开始数，这一点和数组一样。

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## 询问字符

| 调用 | 返回 |
| --- | --- |
| `c.is_alpha` | 是字母吗？ |
| `c.is_digit` | 是 `0` 到 `9` 之一吗？ |
| `c.is_upper` | 是大写字母吗？ |
| `c.is_lower` | 是小写字母吗？ |

每个都返回 `true` 或 `false`。

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## 改变大小写

`.upper` 返回字母的大写形式，`.lower` 返回小写形式。不是字母的字符会原样返回。

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## 字符作为数字

每个字符都对应一个数字。`.int` 可以取得它，`.char` 则把数字变回字符。

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

具体数字通常并不重要。重要的是字母 `a` 到 `z` 按顺序排列，而且彼此相邻，所以 `'c'.int - 'a'.int` 等于 2，也就是`c`在字母表中前进的距离。这正是密码转盘能够工作的原因。
