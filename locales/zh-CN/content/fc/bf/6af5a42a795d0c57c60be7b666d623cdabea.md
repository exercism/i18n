# Char

`Char`是 Crystal 中的一种数据类型，表示一个 32 位的 [Unicode][unicode] 码点。
它的体积小，因此内存效率很高，也具有 String 所没有的一些特性。
`Char`使用单引号（`'`）创建，引号内只能放置一个 Unicode 码点。

```crystal
'a' # => 'a'
'a'.class # => Char
```

在 Crystal 中处理 String 时，经常需要用到 Char，因为 String 类的不少方法都会返回 Char，或者接受 Char 作为实参。
例如，[`String#[]`][index] 方法返回一个 Char，而 [`String#chars`][chars] 方法返回一组 Char。

## 自增 / 自减

由于 Char 就是一个 32 位的 Unicode 码点，所以它支持自增和自减。这意味着，如果你有 `'a'`，加上 1 就能得到 `'b'`。

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

还有 [`Char#succ`][succ] 方法，它返回 Unicode 表中的下一个字符；以及 [`Char#pred`][pred] 方法，它返回 Unicode 表中的上一个字符。

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## 拼接

Char 只用于表示一个 32 位的 Unicode 码点，所以两个字符无法拼接。
因此，Char 只能与 String 拼接。

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## 属性方法

Crystal 提供了一些方法来获取字符的信息，比如它是不是数字或字母，是大写还是小写。
下面列出其中一部分方法，完整列表见 [Char API][char-api]：

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | 如果该字符是数字，返回 `true`                        |
| [`Char#letter?`][letter]         | 如果该字符是字母，返回 `true`                        |
| [`Char#lowercase?`][lowercase]   | 如果该字符是小写，返回 `true`                        |
| [`Char#uppercase?`][uppercase]   | 如果该字符是大写，返回 `true`                        |
| [`Char#ascii?`][ascii]           | 如果该字符是 ASCII 字符，返回 `true`                 |
| [`Char#whitespace?`][whitespace] | 如果该字符是空白字符，返回 `true`                    |

## 转换

### 在码点和 Char 之间转换

由于 Char 是 32 位的 Unicode 码点，你可以在 Char 和码点（Int）之间转换。
这可以用 [`Char#ord`][ord] 方法完成，它返回该 Char 的码点；也可以用 [`Int#chr`][chr] 方法，它返回该码点对应的 Char。

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### 在不同类型之间转换

和其他数据类型一样，Char 也有一些用于在类型之间转换的方法。
最常用的是 `Char#to_s` 方法，它把 Char 转换成 String。此外还有 `Char#to_i` 方法，把 Char 转换成 Int，以及 `Char#to_f` 方法，把 Char 转换成 Float。

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
