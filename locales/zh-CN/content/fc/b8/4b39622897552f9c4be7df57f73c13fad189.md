# 介绍

## 基础

### 函数

在 Gleam 中，函数使用`pub fn`语法定义。

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

这个函数接收两个实参，类型都是`Int`，并返回一个类型为`Int`的值。Gleam 中没有`return`关键字，函数中最后一个表达式的值总是会被_隐式返回_。

实参和返回值的类型标注是可选的，并且 Gleam 始终会对你的代码进行完整的类型检查。通常，Gleam 程序员为了清晰会给函数加上类型标注，但如果愿意，也可以省略。

```gleam
pub fn add(x, y) {
  x + y
}
```

可以使用`function_name(argument1, argument2)`语法调用函数。

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### 变量

在 Gleam 中，变量使用`let name = expression`语法定义。

```gleam
pub fn main() {
  let count = 1
}
```

变量可以用类型标注来声明。和函数实参一样，这些标注是可选的，不过大多数 Gleam 程序员为了简洁会省略变量的类型标注。

```gleam
pub fn main() {
  let count: Int = 1
}
```

### 字符串字面量

在 Gleam 中，字符串使用双引号书写。

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### 代码注释

注释可以用来给阅读源代码的其他开发者留下说明。Gleam 中的注释是以`//`开头的单行。

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
