# 简介

Swift 中的`guard`语句用于从 Swift 函数中提前返回：当继续处理所必需的条件得不到满足时，就会用到它。例如：

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

这里，`guard`会检查跟在`guard`关键字后面的布尔表达式是否求值为 true。如果为 true，就继续执行 guard 语句后面的代码（这里是`let root = myValue.squareRoot()`）。否则就会执行 else 子句中的代码。与`if`语句不同，`guard`语句必须要有 else 子句；而且与 if-else 的 else 子句不同，guard 的 else 子句必须退出 guard 语句的作用域。也就是说，它必须使用`return`、`continue`、`break`这样的控制转移语句，或者必须抛出错误或退出程序。
