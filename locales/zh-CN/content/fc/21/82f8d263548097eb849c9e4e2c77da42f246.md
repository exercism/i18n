# 说明

我们即将创办一个奶酪俱乐部。俱乐部会利用机器学习，根据客户的购买历史和口味，挑选出新的奶酪推荐给热爱奶酪的客户。

新会员需要填写一份初始问卷，好让我们先收集一些基础数据。通过这些问卷，我们发现有一小部分极端客户的评价不够细腻。由于这可能会给更精细的算法带来无法挽回的偏差，我们专门设置了另一套算法来满足他们的需求。需要你提供一些辅助函数来整理他们的数据。

~~~~exercism/note
虽然解决下面这些任务可能有多种方法，但每个任务都可以用不超过两个高阶函数解决。
~~~~

## 1. 对客户分类

评分系统以五星为基准，也就是由整数`1:5`组成。极端客户只会给出`1`或`5`的评分，我们想知道某位客户是否表现出这种行为。

实现`all_15()`，它接收一个评分向量，如果所有评分都是`1`或`5`，就返回`true`，否则返回 false。

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. 为客户命名

我们需要把客户姓名（或 ID）与他们的评分关联起来。

实现`name_customers()`，它接收一个姓名向量和一个评分列表，把它们“配对”成一个列表的列表。

内层列表元素的名称应为`name`和`rating`。

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. 筛出极端客户

我们需要把更极端的客户与其他客户分开。

实现`emphatics()`，它接收客户和评分，返回一个列表，其中只保留只用`1`或`5`星评分的客户。`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. 把评分转换为二进制

由于极端客户只用`1`和`5`两种评分，把这些评分转换成`0`和`1`在计算上会更方便。

实现`to_binary()`，它接收一个极端评分向量，返回二进制评分，其中`1`已转换为`0`，`5`已转换为`1`。

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. 计算随时间变化的平均评分

随着你对每位客户（而不只是极端客户）的口味了解得越来越深入，你会希望不断改进为他们提供的推荐。

实现`satisfactions()`，它接收一个评分向量，返回截至当前为止的累计平均评分。把结果四舍五入到 2 位小数。

希望这些数字不断增长，让客户满意！

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
