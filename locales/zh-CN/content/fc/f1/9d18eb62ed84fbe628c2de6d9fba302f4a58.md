# 说明

舞蹈团表演的每一段舞蹈都建立在同一套热身动作之上，之后便各走各的路。

起始代码已经提供了`WARM_UP`。在它下面再写三个类。

## 1. 爵士舞段

`JAZZ_ROUTINE`原封不动地继承`WARM_UP`的全部内容，什么也不添加。

```sather
JAZZ_ROUTINE::counts
-- => 8
JAZZ_ROUTINE::describe
-- => "8 counts"
```

## 2. 踢踏舞段

`TAP_ROUTINE`从`WARM_UP`中取得`counts`，但用自己的方式描述自己。把`describe`排除在 include 之外，再写一个新的。

```sather
TAP_ROUTINE::counts
-- => 8
TAP_ROUTINE::describe
-- => "Tap: 8 counts"
```

## 3. 终场

`FINALE`从`WARM_UP`中取得`counts`，并以`warm_up_counts`这个名字保存，同时把`describe`排除在外。它还有自己的`counts`，数值是热身的两倍，以及自己的`describe`。

```sather
FINALE::warm_up_counts
-- => 8
FINALE::counts
-- => 16
FINALE::describe
-- => "Finale: 16 counts"
```

注意这说明了什么：`FINALE::counts`和`WARM_UP::counts`并不是同一个，但两者在同一个类里以不同的名字同时存在。
