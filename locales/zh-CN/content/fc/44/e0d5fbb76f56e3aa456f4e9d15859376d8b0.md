# 关于

[Groovy](http://www.groovy-lang.org/) 是 Apache 基金会旗下一门强大的动态语言，类型可选，同时也具备静态类型和静态编译的能力。

Groovy 的目标是借助简洁易学的语法提升开发者效率。它便于编写脚本，也适合创建领域特定语言、进行运行时和编译时的元编程以及函数式编程。

它可以使用整个 Java 库生态，并与 Java 应用无缝集成。

它既可以作为简单的脚本语言使用，也可以加入到复杂的 Java 框架中。
它为以下技术提供支持：
* Gradle，
* Spock，
* Ratpack，
* Grails，
* 以及 Jenkins 中的脚本功能。

而且，它很有趣。
