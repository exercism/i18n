## 简介

对于我们的练习，大家提交的解答千差万别。
在大多数语言轨道中，最基础的“正式”练习是`TwoFer`。
一份典型的提交的解答长这样（这里用的是 Ruby，但大多数语言都类似）：

```ruby
module TwoFer
  def self.two_fer(name='you')
    "One for #{name}, one for me."
  end
end
```

然而，在最近通过测试的 500 份提交的解答中，有 350 多份是独一无二的 😲
即使你把空白字符、变量名这类东西都标准化，仍然有超过一半是真正独一无二的提交的解答。

所以，看看大家是怎么解题的，会是一件特别有意思的事。
但这又完全不现实。Exercism 上有数百万份提交的解答，把它们全部读完，真的需要花上一辈子。

不过！我们的团队设计了这些练习，也指导过数十万人完成它们，所以对大家采用的各种解题思路相当了解。
因此我们新增了“Dig Deeper”标签页，用来展示解决同一个练习的各种地道（或者不那么地道，但很有意思）的方式。

## 一个例子

我们来看一个例子，看看它是怎么运作的。
在 C# 中，翻转字符串有多种方式。

你可以使用`Array.Reverse()`方法：
```csharp
var chars = input.ToCharArray();
Array.Reverse(chars);
return new string(chars);
```

或者用更短的、基于 LINQ 的方式：
```csharp
return new string(input.Reverse().ToArray());
```

也可以用一个`StringBuilder`：
```
var chars = new StringBuilder();
for (var i = input.Length - 1; i >= 0; i--)
{
    chars.Append(input[i]);
}
return chars.ToString();
```

甚至可以稍微不那么地道（但性能更好！），改用`Span<T>`：

```csharp
Span<char> chars = stackalloc[input.Length];
for (var i = 0; i < input.Length; i++)
{
    chars[input.Length - 1 - i] = input[i];
}
return new string(chars);
```

我们把每一种都称为一种“解题思路”，每一种都有独立的文章进行讲解。
这个练习的 Dig Deeper 页面把它们汇集在一起，还附有一篇探讨性能取舍的文章。
