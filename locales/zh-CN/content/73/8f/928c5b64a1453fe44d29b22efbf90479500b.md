# 说明

你的任务是计算单词的 Scrabble 得分：把各个字母的分值相加。

各个字母的分值如下：

| 字母                         | 分值 |
| ---------------------------- | ----- |
| A, E, I, O, U, L, N, R, S, T | 1     |
| D, G                         | 2     |
| B, C, M, P                   | 3     |
| F, H, V, W, Y                | 4     |
| K                            | 5     |
| J, X                         | 8     |
| Q, Z                         | 10    |

例如，单词 “cabbage” 的得分是 14 分：

- C 得 3 分
- A 得 1 分
- B 得 3 分
- B 得 3 分
- A 得 1 分
- G 得 2 分
- E 得 1 分
