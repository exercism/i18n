# 简介

循环基本上有两种：

1. 一直循环，直到满足某个条件。
2. 遍历集合中的元素。

两种在 R 里都能实现，不过第一种可能更常见。

## `while`和`repeat`

对于循环次数事先无法确定的开放性问题，R 提供了带条件的`while`循环，以及不带条件的`repeat`循环（等价于`while (TRUE)`）。

基本形式相当简单：

```R
while (condition) {
  do_something()
}
```

在这种情况下，程序会一直循环，直到`condition`不再是`TRUE`。

有两种提前退出循环的方法：

- `break`会让循环退出，执行会从循环右大括号`}`之后的那一行继续。
- `return(x)`会停止当前函数的执行，并把返回值`x`传回给调用方。

有了这些选项，有时候用`repeat { ... }`创建一个“无限”循环会很方便，然后靠循环体里的停止条件来触发`break`或`return`。

这三种写法是等价的，最终结果都是`x == 0.4444...`：

```R
x <- 12
while (x > 1) {
  x <- x / 3
}

x <- 12
while (TRUE) {
  x <- x/3
  if (x <= 1) break
}

x <- 12
# no boolean clause 
repeat { 
  x <- x/3
  if (x <= 1) break
}
```

## 遍历向量

在 R 里这通常是不必要的。
正如其他概念中所讨论的，很多函数会作用于整个向量。

不过，显式循环有时无法避免。
在以下情况尤其如此：

- 循环体带有副作用，比如打印或文件 I/O。
- 循环会一直进行，直到满足某个条件，而迭代次数无法预知。

循环条件必须放在括号里。
和函数体一样，对于单行循环体，大括号是可选的（但通常会加上）。

```R
words <- c("This", "is", "a", "loop")
for (w in words) { print(w) } # the braces are optional here
#> [1] "This"
#> [1] "is"
#> [1] "a"
#> [1] "loop"
```

如果当前迭代不满足某个条件，可以用`next`立即跳到下一次迭代：

```R
for (n in 1:10) {
    if (is_useless(n)) next
     
    # we decided this iteration could be useful
    do_something_slow(n)
}
```

如果需要数字下标，就用`seq_along()`。

```R
v <- LETTERS[1:3]
v
#> [1] "A" "B" "C"

for (i in seq_along(v)) { print(sprintf("%s%i", v[i], i)) }
#> [1] "A1"
#> [1] "B2"
#> [1] "C3"
```

不推荐使用`i in 1:length(v)`，因为当`length(v)`为零时会出问题。
区间`1:0`等价于`c(1, 0)`，所以循环体会执行，而且很可能会出错。
`seq_along()`函数正是为了正确处理这种情况而设计的。
