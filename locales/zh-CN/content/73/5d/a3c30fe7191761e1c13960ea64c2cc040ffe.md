# 关于

[Lua](https://lua.org) 是一种简单却强大、高效、轻量、可嵌入的脚本语言。自 1993 年起，它由 Roberto Ierusalimschy、Waldemar Celes 和 Luiz Henrique de Figueiredo 组成的团队在巴西的 [PUC-RIO](https://www.puc-rio.br/) 设计、实现和维护。

## 注释

Lua 中的单行注释以 `--` 开头，多行注释以 `--[[` 开头，以 `]]` 结尾。
```lua
-- This is a single line comment.

--[[This is
a multiline
comment
]]
```

## 变量

Lua 中有三种变量：全局变量、局部变量和表字段。为简单起见，这里只解释局部变量。默认情况下，所有变量都是全局的，所以我们必须使用关键字 `local` 将变量声明为局部变量。
```lua
local x
```

可以使用 `=` 运算符将值赋给变量。
```lua
local x = 1
```

`local`变量的作用域仅限于声明它的代码块。代码块可以是控制结构的主体、函数体，或者声明该变量的文件或字符串。
```lua
local x = 1

if x == 1 then
  local x = 2
  print(x) -- prints 2
end

print(x) -- prints 1
```

## 函数

函数使用关键字 `function` 声明，并且和变量一样，默认是全局的。函数定义包含名称、形参列表和函数体。函数在遇到关键字 `return` 时退出，并返回其后列出的所有值。如果没有指定 `return`，函数将返回 `nil`。

```lua
-- Defining a local function which returns "Hello " followed by 
-- the name which was given as parameter
local function say_hello(name)
  return 'Hello ' .. name
end
```

## 表

表是 Lua 中唯一的数据组织机制，而且非常强大。它们用于表示数组、集合、对象、模块等等。本质上，Lua 中的表就是关联数组。
```lua
-- create a table and assign its reference to tbl
local tbl = {}

-- new entry with key 'x' and value 1
tbl['x'] = 1

-- printing the value
print(tbl['x'])  --> 1

-- uninitialized table fields evaluate to nil
print(tbl['y'])  --> nil

-- there is also syntactic sugar - the following is the same as above
tbl.y = 1
print(tbl.y)    --> 1
```

这只是为下一节准备的一点小知识。我们稍后会详细回来讨论这个主题。

## 模块

模块是存储在 `.lua` 源文件中的代码集合。模块导出的所有内容都存储在一个表中，并在文件末尾返回这个表。因此这个表基本上充当一种命名空间。
```lua
-- say-hello.lua

-- defining the table 'say' which is exported at the end
local say = {}

-- defining the function 'hello' as a table field
-- this is syntax sugar for: say.hello = function() print('Hello!') end
function say.hello()
  print('Hello!')
end

-- returning (exporting) the table 'say'
return say
```

然后可以通过函数 `require` 将该模块加载到另一个文件中，它会返回这个表。
```lua
-- lets_say_hello.lua
local say = require('say-hello')
say.hello() -- prints "Hello!"
```

当我们看到 `say.hello` 时，会想到“来自模块 `say` 的函数 `hello`”。但知道我们的 `say-hello.lua` 返回一个表，再回顾表那一节，就会注意到在 Lua 中这个表达式表示“用字符串 `hello` 作为键来索引表 `say`”。

尽管模块返回表是一种好做法，但返回其他任何类型也同样可行，例如函数。

```lua
--- say-bye.lua
local function bye()
  print('Bye!')
end

return bye
```
