# 测试

你可以使用 Exercism 网站上的在线编辑器来解练习。或者，把练习下载到自己的电脑上，在本地解题，然后再提交到 Exercism。本文档的其余部分介绍如何在本地工作。

## Exercism CLI

你需要 `exercism` 命令行工具来下载和提交练习。关于下载和配置它的说明，请参见 [exercism CLI 文档][exercism-cli]。

要下载一个练习，请执行以下命令：

```bash
exercism download --track 8th --exercise hello-world
```

然后切换到练习目录：

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

如果你使用的是 Windows：

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

注意，你可以使用 `exercism configure` 命令获取你的 Exercism 工作区。

## 在本地测试

要运行某个练习的测试，你必须位于正确的练习目录中。然后用下面的命令启动测试：

```bash
8th -f test.8th
```

## 跳过的测试

解出一道练习，意味着让它所有的测试都通过。默认情况下，运行测试时只会执行一个测试（即第一个）。这是有意为之的，这样你就能集中精力只让这一个测试通过。一旦它通过，你就可以把 `SKIP-REST-OF-TESTS` 这一行移到下一个测试的下面，从而启用下一个测试。

### 覆盖跳过设置

要运行所有测试，包括 `SKIP-REST-OF-TESTS` 之后的那些，你可以把环境变量 `RUN_ALL_TESTS` 设置为 `true`。只在运行测试期间这样设置的一种方法如下（macOS 和 Linux）：

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## 提交你的解答

要使用 exercism 工具把你的解答上传到 Exercism 网站：

```bash
exercism submit
```

注意，即使你的代码没有通过全部测试，也可以上传。如果你卡住了，需要导师帮忙，这样做很有用。
