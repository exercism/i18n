# 关于

[switch 表达式][switch-expressions] 的行为与 [concept:csharp/switch-statements]() 中介绍的 [switch 语句][switch-statements] 类似。它们支持一种决策表，把输入条件映射到操作或值。

switch 表达式的核心是 _模式匹配_。在编程练习中，我们把值和 `const`模式进行匹配。在这里，`switch`的输入是一个 _范围表达式_，它会被拿来与 const 值和 _case 守卫_ 所用的值进行匹配。

这些 case（也称为 _switch 分支_）按文本顺序求值，一旦找到匹配项，过程就会提前结束，并返回对应的值。

位于列表最后的 `_`分支有助于确保匹配是穷尽的，并避免可能出现的运行时错误。

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```

当模式与范围变量匹配，并且任何 case 守卫的计算结果为 true 时，`switch`的某个“分支”就会被选中。

switch 表达式还支持[类型模式][pattern-matching]和递归匹配。
