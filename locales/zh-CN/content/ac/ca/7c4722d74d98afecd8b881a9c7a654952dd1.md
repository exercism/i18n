# 简介

用自身来定义自身的能力称为递归。在 Gleam 中，递归最常出现在递归函数里，也就是会调用自身的函数。

递归函数至少需要一个*基本情况*和一个*递归情况*。*基本情况*直接返回一个值，不再调用函数。*递归情况*会再次调用函数，并修改输入，让它最终能匹配基本情况。

```gleam
pub fn factorial(x: Int) -> Int {
  case x {
    // Base case
    1 -> 1

    // Recursive case
    _ -> x * factorial(x - 1)
  }
}
```

Gleam 没有专门的循环语法，所以所有循环都是靠递归完成的。

```gleam
pub fn list_length(list: List(String)) -> Int {
  case list {
    [] -> 0
    [_, ..rest] -> 1 + list_length(rest)
  }
}
```

Gleam 也支持递归自定义类型。一个递归自定义类型会有一个或多个变体在其包含的数据中引用自身。

```gleam
pub type RussianDoll {
  Child               // Base case
  Mother(RussianDoll) // Recursive case
}
```
```gleam
let very_big_doll = Mother(Mother(Mother(Child)))
let small_doll = Mother(Child)
```
