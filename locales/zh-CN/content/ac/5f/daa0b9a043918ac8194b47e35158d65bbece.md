# 提示

## 通用

- 要新建一个全新的可变哈希表，正确的做法是用 `H{ } clone`，因为 `H{ }` 字面量会在不同调用之间共享。
- [`assocs`][assocs] 里的 `inc-at` 会给某个键的值加 1（如果该键不存在，就把它插入为 1）。

## 1. 根据列表构建库存

- 先从 `H{ } clone` 开始，对每个元素使用 `inc-at`。fry quotation `'[ _ inc-at ]` 会捕获这个哈希表，这样你就能把它传给 `each`。
- 用 `[ … ] keep` 把这次迭代包起来，这样留在栈上的值就是那个哈希表。

## 2. 添加更多物品

- 形式和任务 1 一样，区别在于起点是输入库存的 `clone`，而不是一个空哈希表。

## 3. 减少计数

- 先用 `key?`，只有已经在库存里的物品才会被改动。
- `change-at` 接受一个 quotation `( old -- new )`，把它和 `[ 1 - 0 max ]` 搭配使用（`max` 来自 [`math.order`][math.order]），这样计数就永远不会变成负数。

## 4. 完全移除某个物品

- `delete-at` 会原地修改哈希表并且不返回任何值。所以要先 `clone`，再 `delete-at`，最后把这个克隆留在栈上。

## 5. 列出可用的物品

- `>alist` 把哈希表转换成由键值对组成的序列。
- `[ second 0 > ] filter` 只保留仍有库存的物品。
- `sort-keys`（在 [`sorting`][sorting] 里）按键对 alist 排序。

[assocs]: https://docs.factorcode.org/content/vocab-assocs.html
[math.order]: https://docs.factorcode.org/content/vocab-math.order.html
[sorting]: https://docs.factorcode.org/content/vocab-sorting.html
