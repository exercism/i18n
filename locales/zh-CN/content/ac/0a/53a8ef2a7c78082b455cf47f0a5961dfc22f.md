# 生成器

`generator`是一种函数或表达式，它返回一种特殊的[迭代器][iterator]，叫作[`generator iterator`][generator-iterator]。
`Generator-iterator`是[惰性][lazy iterator]的：它们不把`values`存在内存里，而是在需要时才_生成_这些值。

生成器函数看起来和其他函数一样，但它包含一个或多个 [yield 表达式][yield expression]。
每个`yield`都会暂停代码执行，保存当前的执行状态（_包括所有局部变量和 try 语句_）。
当生成器恢复执行时，它会从暂停的地方接着执行，而不像普通函数那样每次调用都会重置。


## 构造生成器

生成器的构造方式和其他循环或递归函数很像，但需要一个 [`yield`表达式](#the-yield-expression)，稍后我们会详细探讨。

一个例子是返回给定数字数组中各项_平方_的函数。
按现在的写法，必须先处理完所有输入，才能返回任何值：

```python
>>> def squares(list_of_numbers):
...     squares = []
...     for number in list_of_numbers:
...         squares.append(number ** 2)
...     return squares
```

可以像这样把这个函数改写成生成器：

```python
>>> def squares_generator(list_of_numbers):
...     for number in list_of_numbers:
...         yield number ** 2
```

这样做的道理是：当你不需要_一次性_产出所有值时，就可以使用生成器。
这能节省内存和运算能力，因为只计算你_当前正在处理_的那个值。


## 使用生成器

在 Python 中，生成器可以替代大多数`iterables`。
这包括那些需要一个`iterable`/`iterator`作为参数的_函数_或_对象_。

要使用`squares_generator()`生成器：

```python
>>> squared_numbers = squares_generator([1, 2, 3, 4])

>>> for square in squared_numbers:
...     print(square)
...
1
4
9
16
```

`generator`中的值也可以通过`next()`函数来产出或访问。
`next()`会调用 generator-iterator 对象的`__next__()`方法，“推进”或求值代码直到它的`yield`表达式，然后该表达式会“产出”或返回一个值：

```python
>>> squared_numbers = squares_generator([1, 2])

>>> next(squared_numbers)
1
>>> next(squared_numbers)
4
```

当`generator-iterator`被完全消费、没有更多值可返回时，它会抛出`StopIteration`错误。

```python
>>> next(squared_numbers)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
StopIteration
```


~~~~exercism/note

生成器迭代器是[迭代器][iterator]的一个特殊子集。
`Iterators`是让程序能够循环遍历_可迭代对象_的机制或协议。
生成器迭代器和常见的 Python [`iterables`][iterables]返回的迭代器行为非常相似，但有一些重要的区别需要注意：

- 它们是_[惰性求值][lazy evaluation]_的；迭代是_单向_的，无法“退回”到之前的值。
- 它们会随着对返回值的迭代而被_消费_；不会重置，也不会保存在内存中。
- 它们不可排序，也不能反转。
- 它们不是序列类型，_没有_`indexes`。
  不能用加法或减法引用前一个或后一个值，也不能使用方括号（`[]`）写法或切片。
- 它们不能用于`len()`函数，因为没有长度。
- 它们可以是_有限_的，也可以是_无限_的。从_无限_`generator-iterator`中收集所有值时要小心！

## yield 表达式

[yield 表达式][yield expression]和`return`表达式非常相似。
_与_`return`表达式_不同_，`yield`会在一个_特定的点_把值交给调用方，并暂停对其他值的求值或返回，直到这些值被请求为止。
当`yield`被求值时，它会暂停所在函数的执行，并返回函数_在那一刻_的值。
之后函数会_保持在作用域中_，而当`__next__()`被调用时，执行会恢复，直到再次遇到`yield`。


~~~~exercism/note
在函数之外禁止使用`yield`表达式。
~~~~

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1

>>> lets_try = infinite_sequence()
>>> lets_try.__next__()
0
>>> lets_try.__next__()
1
```


## 为什么要创建生成器？

生成器在很多场景中都很有用。

当处理可能很大的数据集合时，你可能不想把它们全部放进内存。
生成器可以逐块处理较大的数据，既节省内存，又能提升性能。

当某个过程或计算_复杂_、_昂贵_或_无限_时，生成器也很有帮助：

```python
>>> def infinite_sequence():
...     current_number = 0
...     while True:
...         yield current_number
...         current_number += 1
```

现在，每当对`infinite_sequence`对象调用`__next__()`时，它都会返回_上一个数字_ + 1。
