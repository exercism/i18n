# 说明

Bob 是一名理财顾问，帮助人们管理自己的支出。
Bob 的客户会把支出记录发给他，让他分析。
Bob 手上有过去各个时间段的记录，因此能看出消费的变化。
Bob 不喜欢日历，他用 *Bob 纪元*来代替日期。
Bob 纪元是自 Bob 的客户开始活动以来所经过的天数。

在本练习中，你将编写一个程序，帮助 Bob 管理和分析客户的支出。

Bob 的工作围绕`Record`和`DaysPeriod`展开。

`Record`表示一条支出记录，包含支出发生的日期、花费的金额以及支出的类别。

```go
// Record represents an expense record.
type Record struct {
	Day         int
	Amount      float64
	Category    string
}
```

`DaysPeriod`表示一段日期范围，包含从 `From` 那天到 `To` 那天之间的所有天。
范围的两端都包含在内。

```go
// DaysPeriod represents a period of days.
type DaysPeriod struct {
	From int
	To   int
}

p := DaysPeriod{From: 1, To: 31}
// p represents all days from the day 1 to the day 31:
//  - days 1, 20, 16 and 31 are examples of days that are included
//    in the range of time specified by p
//  - days 50 and 40 are examples of days that are not included
//    in the range of time specified by p
```

## 1. 实现一个通用的记录过滤器

Bob 每天要处理大量记录，但根据他所做的分析不同，并不是每条记录都值得关注。
我们来帮 Bob 对记录做一些基本的过滤。

实现通用的`Filter`函数，按照一个函数给出的条件来过滤记录。
这个过滤函数接收一个记录集合和一个谓词函数，只返回集合中满足该谓词的记录。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
}

// Day1Records only returns true for records that are from day 1
func Day1Records(r Record) bool {
  return r.Day == 1
}

Filter(records, Day1Records)
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"}
// ]
```

## 2. 按时间段过滤记录

Bob 经常需要过滤出位于某个给定时间段内的记录。

实现`ByDaysPeriod`函数，帮助 Bob 创建这样的过滤器。
该函数接收一个`DaysPeriod`，返回一个函数；这个返回的函数接收一条记录，并判断该记录是否位于作为实参传入的`DaysPeriod`所指定的时间段内。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

period := DaysPeriod{From: 1, To: 15}

Filter(records, ByDaysPeriod(period))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 11, Amount: 300, Category: "utility-bills"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 3. 按类别过滤记录

除了按时间段过滤记录，Bob 还需要按类别过滤记录。

实现`ByCategory`函数，帮助 Bob 创建这样的过滤器。
该函数接收一个类别，返回一个函数；这个返回的函数接收一条记录，并判断该记录的类别是否与作为实参传入的类别相同。

```go
records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

Filter(records, ByCategory("groceries"))
// =>
// [
//   {Day: 1, Amount: 15, Category: "groceries"},
//   {Day: 12, Amount: 28, Category: "groceries"},
// ]
```

## 4. 计算某个时间段内的支出总额

Bob 还想知道某个时间段内支出的总额。

实现`TotalByPeriod`函数，返回该时间段内支出的总和。

```go
records := []Record{
  {Day: 15, Amount: 16, Category: "entertainment"},
  {Day: 32, Amount: 20, Category: "groceries"},
  {Day: 40, Amount: 30, Category: "entertainment"}
}

p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

TotalByPeriod(records, p1)
// => 16

TotalByPeriod(records, p2)
// => 50
```

## 5. 计算某个类别在某个时间段内的支出总额

在 Bob 给客户做的最复杂的报告中，他需要同时按类别和时间段来过滤记录。
也就是说，Bob 想知道某个类别在给定时间段内的支出总额。

实现`CategoryExpenses`函数，返回某个类别在给定日期范围内的支出总额。
该函数还应区分两种情况：给定类别没有出现在支出记录中，以及所提供的时间段内该类别没有支出。
当该类别不属于任何一条记录的类别时（无论时间段如何），函数应返回一个错误。

```go
p1 := DaysPeriod{From: 1, To: 30}
p2 := DaysPeriod{From: 31, To: 60}

records := []Record{
  {Day: 1, Amount: 15, Category: "groceries"},
  {Day: 11, Amount: 300, Category: "utility-bills"},
  {Day: 12, Amount: 28, Category: "groceries"},
  {Day: 26, Amount: 300, Category: "university"},
  {Day: 28, Amount: 1300, Category: "rent"},
}

CategoryExpenses(records, p1, "entertainment")
// => 0, error(unknown category entertainment)

CategoryExpenses(records, p1, "rent")
// => 1300, nil

CategoryExpenses(records, p2, "rent")
// => 0, nil
```
