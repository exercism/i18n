# 说明

在这个练习中，你将处理日志行。

每条日志行都是一个格式如下的字符串：`"[<LVL>]: <MESSAGE>"`。

日志级别有以下几种：

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

本练习共有三个任务，需要逐一完成，才能实现完整的功能。

## 1. 创建 LogLevel 枚举

定义`LogLevel`枚举，它包含六个枚举成员，分别对应上面的日志级别，另外再加一个未知成员，用于表示缺失或非标准的日志级别。

- `trace`
- `debug`
- `info`
- `warning`
- `error`
- `fatal`
- `unknown`

## 2. 解析日志级别

接下来，实现`LogLevel`初始化方法，用它解析日志行的日志级别：

```swift
LogLevel("[INF]: File deleted")
// Returns LogLevel.info
LogLevel("Something went wrong!")
// Returns LogLevel.unknown
```

## 3. 将日志行转换为短格式

日志行里的日志级别相当冗长。
为了减少存储日志行所需的磁盘空间，人们设计了一种短格式：`"<ENCODED_LEVEL>:<MESSAGE>"`。

编码后的日志级别就是把日志级别简单映射成一个数字：

- `trace` - `0`
- `debug` - `1`
- `info` - `4`
- `warning` - `5`
- `error` - `6`
- `fatal` - `7`
- `unknown` - `42`

实现`shortFormat(message: String) -> String`方法，它能将日志行以缩短后的格式输出为`String`：

```swift
let overflow = LogLevel.error
overflow.shortFormat(message: "Stack overflow")
// Returns "6:Stack overflow"
```
