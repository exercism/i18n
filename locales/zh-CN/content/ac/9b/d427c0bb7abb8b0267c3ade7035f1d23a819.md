# 带`_is`和问号的 defmacro

[comment]: # (需要 3 个参数：)
[comment]: # (- actual：学生使用的不正确的名称)
[comment]: # (- option1：函数的正确名称)
[comment]: # (- option2：守卫子句的正确名称)

Elixir 对命名有特定的约定，其中包括如何为[返回布尔值的函数](https://hexdocs.pm/elixir/naming-conventions.html#trailing-question-mark-foo)以及[返回布尔值且在守卫子句中有效的检查](https://hexdocs.pm/elixir/naming-conventions.html#is_-prefix-is_foo)命名：

> 返回布尔值的函数，命名时末尾加问号。

> 类型检查以及其他允许在守卫子句中使用的布尔检查，命名时以`is_`前缀开头。

宏在这两种场景下都可以使用，所以具体的写法要看情况，但两套命名约定不能混用。

```elixir
# this is the expected name of macros that return booleans

%{option1}

# this is the expected name of macros that return booleans and are valid in guard clauses

%{option2}

# this is the current name

%{actual}
```
