# 所有权

在 Cairo 中，所有权这个概念依附在_变量_上，而不是变量所持有的_值_上。

Cairo 中的值是不可变的。这种不可变性保证了即使有多个变量引用同一个值，值本身也保持不变，不会被修改。
因此，编译器必须确保程序员正确地使用它们。
这就是变量_所有权_的含义：所有者就是可以读取该变量的代码（如果变量可变，还可以写入）。

## 变量的所有权规则

```console
1. Each variable in Cairo has an owner.
2. There can only be one owner at a time.
3. When the owner goes out of scope, the variable is destroyed.
```

## 变量的作用域

作用域是程序中变量保持有效的范围。
来看下面这个例子，它声明了一个无符号整数类型的变量`x`，注释标出了变量有效的位置：

```rust
fn main() {
                      // `x` is not valid here, it has not been declared yet
    let x: u32 = 3;   // `x` is declared, it is valid from this point forward
                      // do stuff with `x`

} // this scope ended here, `x` goes out of scope and is no longer valid
```

说明：

- 当`x`进入作用域时，它就是有效的。
- 它会一直有效，直到离开作用域，在这个例子里就是直到`main()`函数结束。

## 移动值

当一个值被传给另一个函数时，就会发生移动：原来引用该值的变量被销毁（因此这个变量也就没用了），同时创建一个新变量来持有同一个值。

数组就是这样一种复杂类型：把它传给另一个函数时，它会被移动。
下面简单回顾一下数组长什么样：

```rust
    let mut arr: Array<u128> = array![];
    arr.append(1);
    arr.append(2);
```

类型系统如何确保 Cairo 程序永远不会试图对同一个内存单元写入两次？
看看下面这段代码，我们试图两次移除数组开头的元素：

```rust
fn foo(mut arr: Array<u128>) {
    arr.pop_front();
}

fn main() {
    let arr: Array<u128> = array![1];
    foo(arr);
    foo(arr); // -> compiler error: Variable was previously moved.
}
```

在这个例子里，我们试图把同一个值（也就是`arr`变量里的那个数组）传给两次函数调用。
这意味着代码会两次移除第一个元素，也就是试图对同一个内存单元写入两次，而这是 Cairo VM 禁止的行为，会导致运行时错误。
好在，这段代码实际上编译不过去。
一旦把数组传给`foo`函数，变量`arr`就不能再用了。
我们会得到这样一个编译时错误，它告诉我们，需要让`Array`实现`Copy`特征：

## `Copy`特征

如果一个类型实现了`Copy`特征，那么把它传给函数时不会移动值，而是创建一个引用同一个值的新变量。
这是一个没有代价的操作，因为变量只是 Cairo 的一层抽象，而值始终是不可变的。

要为你的类型实现`Copy`特征，只需在类型定义上加上`#[derive(Copy)]`标注。
不过，如果该类型或它的任何一个组成部分没有实现`Copy`特征，Cairo 就不会允许这样做。

```rust
#[derive(Copy, Drop)]
struct Point {
    x: u128,
    y: u128,
}

fn main() {
    let p1 = Point { x: 5, y: 10 };
    foo(p1);
    foo(p1);
}

fn foo(p: Point) { // do something with p
}
```

## 销毁值

线性类型也可以通过被销毁来使用，这能确保相关联的资源被正确释放。
要做到这一点，需要实现或派生`Drop`特征，它告诉编译器：这个类型在不再有用之后可以安全地销毁。

```rust
#[derive(Drop)]
struct A {}

fn main() {
    A {}; // this value can be destroyed after going out of scope
}
```

目前，所有类型都可以派生`Drop`实现，但字典（`Felt252Dict`）以及包含字典的类型除外。
这是因为字典在被销毁时必须被“压缩”。
为此，我们要派生`Destruct`特征：

```rust
#[derive(Destruct)]
struct A {
    dict: Felt252Dict<u128>
}

fn main() {
    A { dict: Default::default() };
}
```

## 返回值与作用域

返回值和移动值是等价的。
下面这个例子展示了一个返回值的函数：

```rust
#[derive(Drop)]
struct A {}

fn main() {
    let a1 = gives_ownership();           // gives_ownership moves its return
                                          // value into a1

    let a2 = A {};                        // a2 comes into scope

    let a3 = takes_and_gives_back(a2);    // a2 is moved into
                                          // takes_and_gives_back, which also
                                          // moves its return value into a3

} // Here, a3 goes out of scope and is dropped. a2 was moved, so nothing
  // happens. a1 goes out of scope and is dropped.

fn gives_ownership() -> A {               // gives_ownership will move its
                                          // return value into the function
                                          // that calls it

    let some_a = A {};                    // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}

// This function takes an instance some_a of A and returns it
fn takes_and_gives_back(some_a: A) -> A { // some_a comes into scope

    some_a                                // some_a is returned and
                                          // moves ownership to the calling
                                          // function
}
```
