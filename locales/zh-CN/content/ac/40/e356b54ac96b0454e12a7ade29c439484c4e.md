# 说明

你的朋友刚刚给你发来一条消息，里面有一个重要的秘密。
为了不让别人轻易读到它，这条消息通过一系列位操作进行了加密。
你需要写一个程序来帮忙解密这条消息。

## 1. 将位移回去

解密消息的第一步，是撤销加密过程中的移位：把位再向左移回去。
不同消息需要移动的位数可能不一样。

实现方法`Secrets.shift_back`，它接收一个值和要向左移动的位数。

```crystal
Secrets.shift_back(0b0001, 2)
# => 0b0100
```

## 2. 应用位掩码

下一步是应用一个位掩码，提取某些位的值。
应用掩码的方式，是对值和掩码执行按位与。

实现方法`Secrets.apply_mask`，它接收一个值并应用一个掩码。

```crystal
Secrets.apply_mask(0b0110, 0b0101)
# => 0b0100
```

## 3. 设置某些位

向左移位会新添一些 0 位。
其中一些新位需要被设为 1。
按位或可以把某些位设为 1，同时保留其余位不变。

实现方法`Secrets.set_bits`，它接收两个值并执行按位或。

```crystal
Secrets.set_bits(0b0110, 0b0101)
# => 0b111
```

## 4. 反转异或

加密过程中的一部分，是把数据和约定的值做异或。
要还原成原始值，只需把加密后的值再和约定的值做一次异或即可。
不过，因为一场误会，你的朋友在做异或之前，先把约定值的各位翻转了（也就是对约定值做了按位取反）。

实现`Secrets.reverse_xor`方法，它接收加密值和约定值，并算出原始值。

```crystal
Secrets.reverse_xor(0b1100, 0b0101)
# => 0b(0110)
```
