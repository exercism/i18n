# 说明

判断一个三角形是 *equilateral*、*isosceles* 还是 *scalene*。

*equilateral* 三角形的 3 条边长度相同。

*isosceles* 三角形至少有 2 条边长度相同。
（有时它被定义为恰好有 2 条边长度相同，但在这个练习中，我们说的是至少 2 条。）

*scalene* 三角形的 3 条边长度各不相同。

## 注意

一个图形要成为三角形，每条边的长度都必须大于 0，而且任意两条边的长度之和都必须大于或等于第三条边的长度。

用式子表示：

设 `a`、`b`、`c` 为三角形的三条边。
那么下面三个表达式都必须成立：

```text
a + b ≥ c
b + c ≥ a
a + c ≥ b
```

参见[三角形不等式][triangle-inequality]
