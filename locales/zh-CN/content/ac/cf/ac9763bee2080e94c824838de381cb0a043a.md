# 简介

理解引用是高效使用 Perl 的基础。由于引用是标量，而数组和哈希只能包含标量，因此引用是嵌套这些数据结构的关键。

引用可以通过反斜杠运算符 `\` 为现有变量和子程序创建：

* `\$scalar` 创建标量引用（可以是任意标量，例如 `\1`，而不只是变量）。
* `\@array` 创建数组引用。
* `\%hash` 创建哈希引用。
* `\&sub` 创建代码引用。

你还可以为数组、哈希和子程序创建所谓的匿名引用：

* `['Alice', 'Bob', 'Charlie']` 创建匿名数组引用。
* `{foo => 'a', bar => 'b', baz => 'c'}` 创建匿名哈希引用。
* `sub { return 1 }` 创建匿名代码引用。

警告：Perl 中的花括号在某些上下文中可能产生歧义。如果你没有得到预期的哈希引用，可以在前面加一个加号来消除歧义，例如 `+{}`。更多信息请参见[花括号][perlrefcurlybrackets]。

引用可以通过箭头运算符 `->` 访问：

* `$ref->[0]` 访问数组引用中的元素。
* `$ref->{foo}` 访问哈希引用中的值。
* `$ref->($arg)` 通过代码引用调用子程序。

复杂数据结构（例如多维数组和嵌套哈希）中的数据，可以通过链式下标来访问，例如 `$ref->{foo}[0]{bar}`（等同于 `$ref->{foo}->[0]->{bar}`）。

如果你想解引用整个数组或哈希，可以使用箭头运算符，后面分别接 `@*` 或 `%*`，例如 `$ref->@*` 或 `$ref->%*`。
你也可以把 `*` 替换为下标，来获取数组或哈希引用的切片，例如 `$ref->@[0..2]` 或 `$ref->@{'Foo', 'Bar'}`。
对切片而言，符号的变化方式与数组和哈希变量相同。

[perlrefcurlybrackets]: https://perldoc.perl.org/perlref#Curly-Brackets
