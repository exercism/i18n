# 说明

你正在实现一个健康监测系统。作为其中的一部分，你需要记录用户的健康统计数据。

你会从`impl`块中的一些桩函数开始，同时还有下面这个结构体定义：

```rust
pub struct User {
    name: String,
    age: u32,
    weight: u32,
}
```

你的目标是实现`impl`块中定义的`User` `struct`上那些待实现的桩方法。

例如，`new`方法应该返回一个`User`结构体实例，其中包含指定的 name、age 和 weight 值。

```rust
let mut bob = User::new("Bob", 32, 72);
// Returns: a User with name "Bob", age 32, and weight 72
```

`weight`方法应该返回该`User`的 weight 值。

```rust
bob.weight();
// Returns: 72
```

`set_age`方法应该设置`User`的 age 值。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
