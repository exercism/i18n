# 解答练习

Exercism 帮助你学习的主要方式就是做练习。

在 Exercism 上解答练习有两种方式：

1. [通过网站内置的浏览器编辑器在线完成](/docs/using/solving-exercises/using-the-online-editor)
2. [通过 CLI 在你的本地机器上完成](/docs/using/solving-exercises/working-locally)

## 我应该选哪一种？

使用在线编辑器和 CLI 各有利弊：

|            | 在线编辑器                     | CLI                                          |
| ---------- | ------------------------------ | -------------------------------------------- |
| 安装       | 不需要                         | 需要（例如 SDK）                             |
| 编辑       | 浏览器                         | 你惯用的编辑器                               |
| 测试       | 在网站上运行测试               | 在本地运行测试                               |
| 调试       | 支持有限（仅部分学习路径支持） | 完整支持（取决于你的环境）                   |

一般来说，在线编辑器非常适合开始新的学习路径；如果你想使用自己定制的编程环境，基于 CLI 的方式则更为合适。
