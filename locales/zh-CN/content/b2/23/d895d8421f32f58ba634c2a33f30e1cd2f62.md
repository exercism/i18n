# 补充说明

网格的每一行用一个字表示。

例如，

```
    0 1 0
    1 0 0
    1 1 0
```

表示为

```
0x2
0x4
0x6
```

网格最多有 32 列。

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| -------- | ------------ | ------- | --------------------------- |
| `$a0`    | 输入        | 整数 | 行数              |
| `$a1`    | 输入        | 整数 | 列数           |
| `$a2`    | 输入        | 地址 | 当前代的网格 |
| `$a3`    | 输入/输出 | 地址 | 下一代的网格    |
| `$t0-9`  | 临时    | 任意     | 用于临时存储  |
