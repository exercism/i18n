# 简介

## let assert 断言

在 Gleam 中对值进行模式匹配时，我们必须确保模式覆盖了该类型所有可能的值，否则代码无法编译。

下面这个函数应该被拒绝，因为它没有处理数组为空的情况：

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  case items {
    [item, ..] -> item
  }
}
```

在大多数 Gleam 程序中，我们希望处理所有可能的情况；但在原型、快速脚本这类程序里，我们可能只想关注正常路径，不为其他情况写代码。这时就该 Gleam 的`let assert`出场了。

使用 let assert，模式可以只匹配某个类型的一部分可能取值，如果模式没有匹配到值，程序就会崩溃。使用`let assert`，我们可以把上面的函数写成这样：

```gleam
pub fn get_first_element_or_crash(items: List(e)) -> e {
  let assert [item, ..] = items
  item
}
```

Gleam 库永远不应使用 let assert 断言，因为它们可能导致程序崩溃。库应该改用`Result`类型，让应用开发者自己决定如何处理错误。
