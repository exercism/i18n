# 关于

在 Swift 中，不能使用整数为字符串编制下标（例如`string[3]`）。
因为 Swift 字符串由长度可变的 Unicode 字符组成，要找到某个字符，必须依次走过它前面的字符。

要访问特定位置的字符，必须先计算出一个 `String.Index` 类型的下标。
这些下标被称为*不透明下标*，因为它们的内部结构由 Swift 管理，而不是当作原始整数直接操作：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,gooseberry"
let index = csv.index(csv.startIndex, offsetBy: 21)
print(csv[index])
// Prints "g"

print(index)
// Prints internal representation: Index(_rawBits: ...)
```
