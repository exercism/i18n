# 测试

这些练习都使用 [Pester][pester] 框架进行模拟和测试。
所有测试都位于名为`[Exercise].tests.ps1`的文件中，这也是 Pester 框架的标准做法。
前提是你所在的目录正确（即包含`[Exercise].ps1`和`[Exercise].tests.ps1`的目录）。
你可以在 PowerShell 中通过下面的命令来运行测试：

``` PowerShell
Invoke-Pester
```

它会运行目录中所有能找到的`.tests.ps1`文件。

如果你用的不是 PowerShell，而是其他 shell，可以通过下面的命令来运行测试：

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## 在 Visual Studio Code 中运行测试

你需要确保在 Visual Studio Code 中安装了 [PowerShell 扩展][extension]。

在 Visual Studio Code 中有几种运行测试的方法：

- 从 Debug 菜单运行`.Tests.ps1`脚本。快捷键是：`F5` 或 `Shift + F5`
- 在编辑器中，点击测试代码里`Describe`关键字上方的“Run Tests”链接
- 配置一个 Task 来运行 Pester 框架

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
