# 帮助

如果遇到问题需要帮助，可以使用以下资源：

- [/r/javascript](https://www.reddit.com/r/javascript) 是 JavaScript 的 subreddit。
- [StackOverflow](https://stackoverflow.com/questions/tagged/javascript+exercism) 可以用来搜索你的问题，看看是否已经有人解答过。你也可以在上面提问和回答问题。
- [GitHub issue 追踪器](https://github.com/exercism/javascript/issues) 是我们跟踪 Exercism 上 JavaScript 练习的开发和维护情况的地方。如果以上链接都帮不上忙，也欢迎在这里提一个 issue。
