# 说明补充

## 输出格式

用一个以 null 结尾的字符串输出该学生的植物，使用逗号和空格作为分隔符。

## 寄存器

| 寄存器 | 用途 | 类型 | 说明 |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | 输入        | 地址 | 花园示意图                |
| `$a1`    | 输入        | 地址 | 学生姓名                |
| `$a2`    | 输入/输出 | 地址 | 以 null 结尾的输出字符串 |
| `$t0-9`  | 临时        | 任意 | 用于临时存储    |
