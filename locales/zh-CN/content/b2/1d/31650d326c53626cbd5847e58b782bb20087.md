# 说明

你在一家工厂工作，现在需要生成员工工牌上要打印的文字。你决定用 JavaScript 来实现这个函数。

一张工牌需要员工的 `id`、员工的 `name`，以及员工所在的部门。

## 1. 创建工牌文字

实现一个名为 `printBadge` 的函数，返回要打印在工牌上的文字。

员工的姓名总是会提供，但员工的 `id` 编号和部门名称可能是 `null`。员工的 `id` 编号如果提供了，应该放在方括号之间（例如 `[20]`）。

老板的工牌不应带有 `id` 或 `department`。

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
