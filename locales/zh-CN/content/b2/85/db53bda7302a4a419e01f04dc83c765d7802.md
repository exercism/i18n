# 说明

在这个练习中，我们将模拟[二十一点][blackjack]游戏的第一个回合。

## 1. 计算任意一张牌的点数

你会拿到两张牌，并且能看到庄家亮出的那张明牌。
所有牌都用字符串表示，例如 “ace”、“king”、“three”、“two” 等。每张牌的点数如下：

| 牌 | 点数 | 牌 | 点数 |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _其他_ |   0   |

~~~~exercism/note
通常，A 既可以算作 1，也可以算作 11，但为了简单起见，我们假设它只能算作 11。
~~~~

实现 `Blackjack.parse_card` 方法，它接收一个字符串形式的牌名作为实参。
该方法应以整数形式返回这张牌的点数。

```ruby
Blackjack.parse_card("ace")
# => 11
```

## 2. 为点数范围命名

玩家的得分需要划分到不同的点数范围内。
玩家得分由两张手牌的点数相加得到。
使用的范围如下：

| 范围 | 点数 |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

实现 `Blackjack.card_range` 方法，它接收两个字符串形式的牌名作为实参。
该方法应返回这两张牌所属点数范围的名称。

```ruby
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. 实现第一回合的决策逻辑

根据你的两张牌和庄家的明牌，游戏的第一回合有一套策略，你可以做出以下几种选择：

- 停牌（S）
- 要牌（H）
- 分牌（P）
- 自动获胜（W）

虽然这套策略还不是最优的，但你会采用你的朋友 Alex 一直在完善的策略，具体如下：

- 如果你拿到一对 A，就必须分牌。
- 如果你拿到二十一点（两张牌的点数之和为 21），而庄家没有 A、花牌或 10，你就自动获胜。
  如果庄家确实有这些牌中的任意一张，你就只能停牌，等待庄家亮出另一张牌。
- 如果你的两张牌之和在 [17, 20] 范围内，就应该总是停牌。
- 如果你的两张牌之和在 [12, 16] 范围内，就应该总是停牌，除非庄家的牌是 7 或更大，这时就应该要牌。
- 如果你的两张牌之和为 11 或更低，就应该要牌。

实现 `Blackjack.first_turn` 方法，它接收三个字符串形式的牌名作为实参。
该方法应以字符串形式返回你应该采取的决策。

```ruby
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
