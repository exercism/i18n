# 说明

这道练习让你分析电话号码。

你需要实现 2 个功能。

传给这些例程的电话号码保证是 NNN-NNN-NNNN 的形式，例如 212-515-9876，且不为 null。

## 1. 分析电话号码

你的分析应当返回 3 项数据

1. 表明该号码是否使用纽约区号，即前 3 位数字为 212
2. 表明该号码是否为伪造号码，即第 5 位到第 7 位（从 1 开始计数）为前缀码 555
3. 该号码的最后 4 位数字。

实现（静态）方法`PhoneNumber.Analyze()`，生成电话号码信息。

```csharp
PhoneNumber.Analyze("631-555-1234");
// => (false, true, "1234")
```

## 2. 检测电话号码是否带有伪造前缀码（555）

实现（静态）方法`PhoneNumber.IsFake()`，使用任务 1 中生成的电话号码信息来检测该电话号码是否为伪造号码。

```csharp
PhoneNumber.IsFake(PhoneNumbers.Analyze("631-555-1234"));
// => true
```
