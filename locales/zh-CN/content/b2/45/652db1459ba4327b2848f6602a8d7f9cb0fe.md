# 简介

键值对与字典概念讨论过 Julia 字典类型的基础知识。

由于`Dict`是一种重要且常用的集合类型，因此也有许多用来操作它们的函数。

## 获取条目

获取条目最简单的方式是通过键（许多语言都是如此）。不过，如果请求一个不存在的键，就会得到`KeyError`。

```julia-repl
julia> d = Dict(i => ('a':'c')[i] for i in 1:3)
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> d[2]
'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
# missing key
julia> d[4]
ERROR: KeyError: key 4 not found
```

我们可以在尝试获取之前先检查一下键是否存在（比如用`haskey(d, 4)`），但直接为缺失的键取一个默认值往往也很有用。

为此，我们有`get()`函数，以及会修改原字典的变体`get!()`。二者的区别在于，是否会把“缺失”的键添加到`Dict`中。

```julia-repl
julia> get(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get() leaves Dict unchanged
julia> d
Dict{Int64, Char} with 3 entries:
  2 => 'b'
  3 => 'c'
  1 => 'a'
julia> get!(d, 4, '!')
'!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
# get!() adds new key to Dict
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
```

在前面的概念中我们看到，`delete!()`可以按键删除一个条目。借助`pop!()`函数，我们还可以把删除和获取值这两件事合并起来。

```julia-repl
julia> d
Dict{Int64, Char} with 4 entries:
  4 => '!'
  2 => 'b'
  3 => 'c'
  1 => 'a'
# popped value is returned
julia> pop!(d, 3)
'c': ASCII/Unicode U+0063 (category Ll: Letter, lowercase)
# Dict is shrunk
julia> d
Dict{Int64, Char} with 3 entries:
  4 => '!'
  2 => 'b'
  1 => 'a'
```

## 迭代

迭代`Dict`时，默认会产出`key => value`键值对。可以用惯用的`.first`和`.second`来访问这两个组成部分。

```julia-repl
# d is from the previous example
julia> [(kv.first, kv.second) for kv in d]
3-element Vector{Tuple{Int64, Char}}:
 (4, '!')
 (2, 'b')
 (1, 'a')
```

很多时候，我们只想用键，或者只用值，这很容易做到。

```juliajulia> [k for k in keys(d)]
julia> [k for k in keys(d)]
3-element Vector{Int64}:
 4
 2
 1
julia> [v for v in values(d)]
3-element Vector{Char}:
 '!': ASCII/Unicode U+0021 (category Po: Punctuation, other)
 'b': ASCII/Unicode U+0062 (category Ll: Letter, lowercase)
 'a': ASCII/Unicode U+0061 (category Ll: Letter, lowercase)
```

## 合并

合并两个`Dict`很有用，但我们需要说清楚：对于在多个输入中都出现的键，我们打算怎么处理。

`merge()`和`merge!()`函数会按从左到右的顺序合并任意数量的`Dict`。

已存在的键，其值会被直接覆盖，所以最右边的`Dict`会“胜出”。

```julia-repl
julia> d3 = Dict("color" => "red", "shape" => "circle")
Dict{String, String} with 2 entries:
  "shape" => "circle"
  "color" => "red"
julia> d4 = Dict("color" => "blue", "coords" => (3, 2))
Dict{String, Any} with 2 entries:
  "color"  => "blue"
  "coords" => (3, 2)
# color from d3 is lost
julia> merge(d3, d4)
Dict{String, Any} with 3 entries:
  "shape"  => "circle"
  "color"  => "blue"
  "coords" => (3, 2)
```

`mergewith()`和`mergewith!()`函数允许我们把一个函数作为第一个参数传进去，用来定义重复的键应该如何合并。加法就是一个简单的例子。

```julia-repl
julia> d5 = Dict("color" => "red", "area" => 3)
Dict{String, Any} with 2 entries:
  "area"  => 3
  "color" => "red"
julia> d6 = Dict("shape" => "circle", "area" => 5)
Dict{String, Any} with 2 entries:
  "shape" => "circle"
  "area"  => 5
# area values are added, not overwritten
julia> mergewith(+, d5, d6)
Dict{String, Any} with 3 entries:
  "shape" => "circle"
  "area"  => 8
  "color" => "red"
```

注意，`mergewith`系列函数是高阶函数在实际应用中的一个很好的例子。
