# 说明

在这个练习中，你要编写代码，为工厂员工打印姓名牌。
员工有一个 ID、一个姓名和一个部门名称。
员工姓名牌标签的格式如下：`"[id] - name - DEPARTMENT"`。

## 1. 为员工打印姓名牌

实现 `print_name_badge` 函数。它应接受一个 ID、一个姓名和一个部门。
它应返回姓名牌标签，其中部门名称为大写。

```R
print_name_badge(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. 为新员工打印姓名牌

由于计算机系统的一个小毛病，新员工刚进厂工作时有时还没有 ID。
姓名牌是必需的，所以他们会拿到一张不带 ID 前缀的临时姓名牌。

扩展 `print_name_badge` 函数。当 ID 缺失时，它应打印一张不带 ID 的姓名牌。

```R
print_name_badge(NA, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. 为老板打印姓名牌

即使是工厂的老板，也必须始终佩戴姓名牌。
不过，老板没有部门，也永远不会有：他们凌驾于所有部门之上。
在这种情况下，标签应打印 `"OWNER"`，而不是部门名称。

扩展 `print_name_badge` 函数。当部门为 `NULL` 时，就假定这张姓名牌属于公司老板。

```R
print_name_badge(204, "Rachel Miller", NULL)
# => "[204] - Rachel Miller - OWNER"
```

注意，老板也有可能同时是新员工。

```R
print_name_badge(NA, "Rachel Miller", NULL)
# => "Rachel Miller - OWNER"
```

## 4. 计算没有 ID 的员工的总工资

作为衡量 ID 发放情况的一个粗略指标，你想看看没有 ID 的员工的工资总和。
数值高意味着有很多人在等待，或者这个问题影响到了资深员工：这两种情况都很糟糕。

实现 `salaries_no_id` 函数，它接受一个 ID 向量和一个对应的工资向量，并返回还没有 ID 的人的工资总和。
两个向量的长度相同。

```R
ids <- c(204, NA, 210, 352, NA, 263)
salaries <- c(23, 21, 47, 35, 17, 101) * 1000
salaries_no_id(ids, salaries)
# => 38,000
```
