# 关于

C# 是一门多范式、静态类型的编程语言，具备面向对象、声明式、函数式、泛型、惰性求值、集成查询等特性，以及类型推断。

**静态类型**意味着标识符在编译时就已经确定了[类型](https://en.wikipedia.org/wiki/Type_system#Static_type_checking)，就像 Java、C++ 或 Haskell 中的那样，而不是像 Python、Ruby 或 JavaScript 那样可以保存任意类型的数据。

**面向对象**意味着 C# 提供命令式的[基于类的对象](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/object-oriented-programming)，并具备单继承、接口和封装等特性。

**声明式**指的是编写[要做什么](https://stackoverflow.com/questions/1784664/what-is-the-difference-between-declarative-and-imperative-programming)，而不是怎么做（也就是命令式编程）。后者属于实现细节，可能会分散你对领域或业务逻辑的注意力。

**函数式**意味着[函数是一等数据类型](https://livebook.manning.com/#!/book/functional-programming-in-c-sharp/chapter-1)，可以作为实参传递给其他函数，也可以从其他函数中返回。

**泛型**意味着算法是围绕[稍后才指定的类型](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/generics/generic-type-parameters)来编写的，在需要时，再针对作为形参传入的具体类型进行实例化。

**惰性求值**[（也就是“延迟执行”）](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/)意味着编译器会把对某项的求值推迟到真正需要时再进行。这样就能安全地做一些奇怪的事情，比如操作一个无限列表：语言只会创建到最后一个需要的值为止。

**集成查询**意味着语言中有一项名为 [LINQ“Language-Integrated Query”](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/linq/) 的特性，它让你能直接在语言内部进行惰性查询，不仅能查询自身的对象，还能通过 XML、JSON、SQL、NoSQL 数据库和事件流等格式查询外部数据源。

**类型推断**意味着编译器常常会自己推断出标识符的类型，你就不必手动指定。Scala 和 F# 都会这样做。

**语法**与其他 C 风格的语言类似，比如 C、C++ 和 Java。

**.NET**是 C# 运行所在的托管环境，因此你可以访问整个 .NET 生态系统，包括 [nuget.org](http://www.nuget.org) 上的所有包。.NET 过去只能在 Windows 上运行，但随着 [.NET Core](https://www.microsoft.com/net/core) 以及 [Mono](http://www.mono-project.com/) 的发布，你现在也可以在 Mac、Linux 或基于 Unix 的系统上使用 C#，甚至还能在移动平台上使用。

C# 还提供了许多其他特性，让多线程/多处理器编程、并行化、异步、在托管环境中使用非托管代码以及语言互操作性都变得更加容易。它由 Microsoft 开发和维护，官方[文档](https://docs.microsoft.com/en-us/dotnet/csharp/)也由它提供。
