# 说明

你在社区艺术中心做志愿者，正门上方正在拼一幅长长的陶瓷瓷砖马赛克。设计团队把作品**一行一行**地排好：每一行都是一个瓷砖颜色的数组，整幅马赛克则是一个由行组成的数组。

当志愿者们切割、摆放和重新排列瓷砖时，你正在编写一些小型、可复用的单词，用来构建、组合和查找设计中的各个部分。

## 1. 只有一块瓷砖的条

定义 `tile-strip`，它接收一个颜色，返回一个只包含该颜色的单元素行。

```factor
"sky-blue" tile-strip .
! => { "sky-blue" }
```

## 2. 一行三块瓷砖

定义 `row-of-three`，它从栈上取走三个颜色，返回一个包含三个元素的行。

```factor
"red" "white" "blue" row-of-three .
! => { "red" "white" "blue" }
```

## 3. 把各行合并成一个扁平的瓷砖列表

设计团队需要快速核对整幅马赛克所有行中的颜色总数。定义 `combine-rows`，它接收一个由行组成的数组，按顺序返回包含每一块瓷砖的单个序列。

```factor
{ { "red" "white" } { "blue" "red" } } combine-rows .
! => { "red" "white" "blue" "red" }
```

## 4. 镜像一行

对于对称的面板，团队会先把一行镜像，再把副本放到对面一侧。定义 `mirror-row`，返回顺序颠倒的行。

```factor
{ "red" "white" "blue" } mirror-row .
! => { "blue" "white" "red" }
```

## 5. 这个颜色在行中的哪个位置？

定义 `tile-position`，它接收一行和一个颜色，返回该行中第一块具有该颜色的瓷砖的下标（从 0 开始）。如果该颜色不存在，就返回 `f`。

```factor
{ "red" "white" "blue" } "white" tile-position .
! => 1

{ "red" "white" "blue" } "green" tile-position .
! => f
```

## 6. 这一行包含这个颜色吗？

定义 `has-colour?`，它接收一行和一个颜色，如果该颜色出现在这一行的任何位置就返回 `t`，否则返回 `f`。

```factor
{ "red" "white" "blue" } "white" has-colour? .
! => t

{ "red" "white" "blue" } "green" has-colour? .
! => f
```
