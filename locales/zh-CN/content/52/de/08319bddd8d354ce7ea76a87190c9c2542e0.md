# 关于

JavaScript 使用`true`和`false`表示逻辑中的两个真值。

在 JavaScript 中，三种逻辑运算（与、或、非）都有对应的运算符：`&&`、`||`和`!`。
一般来说，运算顺序是有规则的；在这种情况下，先应用`!`（非），然后应用`&&`（与），最后应用`||`（或）。

运算符之间的运算顺序可以通过使用优先级更高的运算符来改变：`( )`，它叫作“分组运算符”，或者简单地说就是“括号”。
事实上，`( )`运算符在所有 JavaScript 运算符中优先级最高。
