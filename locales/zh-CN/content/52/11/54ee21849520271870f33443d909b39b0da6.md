# 简介

循环用来重复执行某段逻辑。
最常见的两种是`while loop`循环（不定次数循环）和`for loop`循环（定次数循环，也叫计数循环）。
还有一种`for each`循环，会在后面的概念里出现。


## 基本语法

`for loop`循环由一个头部和一个代码块组成，代码块里是用大括号括起来的循环体。
头部由 3 个部分组成，用分号`;`分隔：初始化语句、条件和另一个表达式。
其中每一部分都可以为空。

```cpp
for (init-statement; condition; expression) {
  some_statement;
}
```

- **初始化**部分是一段只在循环开始前运行一次的代码。
- **条件**部分必须是一个求值结果为布尔值的表达式，用来控制循环该在什么时候停止。
只要这个条件的求值结果为 true，循环里的代码就会一直运行。
一旦这个表达式的求值结果为 false，循环就不会再进行迭代。
- **表达式**部分是一段会在每次迭代结束时运行的代码。


`while loop`循环只要条件检查为 true，就会一直执行循环体。
下面的代码片段展示了如何把 for 改写成 while 循环。

```cpp
init-statement;
while(condition) {
    some_statement;
    expression;
}
```

## 插曲：自增与自减

处理循环时，经常需要给计数器变量加 1 或减 1。
这种操作太常见了，所以有专门的运算符：`++`和`--`。

它们有前缀和后缀两种形式。
前缀形式会在语句中使用该变量之前先改变它，后缀形式则在之后改变。
大多数情况下，你多半想用前缀形式。

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

## for 循环：一个例子

初始化部分通常用来设置计数器变量，条件部分检查循环应该继续还是停止，而后置部分通常会在每次重复结束时让计数器自增。

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

这个循环会把从`1`到`9`的数字相加（包括`9`）。

## break 和 continue

在循环体内部，可以用`break`关键字彻底停止循环的执行：

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

相比之下，关键字`continue`只会停止当前这次迭代，然后继续下一次：

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```
> 注意：当`break`和`continue`的使用减到最少或完全避免时，循环的逻辑通常更容易理解。
