# 说明

在本练习中，你将编写代码，帮助一位自由职业者与项目经理沟通。
你的任务是提供几个实用函数，用来快速计算日薪和月薪，也可以选择应用给定的折扣。

我们先确定自由职业者和项目经理之间的几条规则：

- 日薪是时薪的 8 倍。
- 一个月有 22 个计费日。

有时，自由职业者会提出在日薪基础上给出折扣（例如对最忠实的客户或非营利客户）。

折扣用表示百分比的小数来建模，例如`25.0`（25%）。

## 1. 根据时薪计算日薪

实现一个名为`dailyRateFrom`的函数，根据作为形参传入的时薪计算日薪。
约定规定一天有 8 个计费小时。

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

返回的日薪应该是`Double`类型。

## 2. 根据时薪和折扣计算月薪

实现`monthlyRateFrom`函数，用来计算折扣后的月薪。
它接收两个形参：时薪和以百分比表示的折扣。


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

返回的月薪应该向上取整（取上整）到最接近的整数。

## 3. 根据预算、时薪和折扣计算完整的工作日数量

实现函数`workdaysIn`，它接收预算、时薪和折扣，并计算出这些条件可以覆盖多少个完整的工作日。

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
返回的天数应该向下取整（取下整）到最接近的整数。
