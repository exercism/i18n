# 条件语句

Ruby 中有一种叫做流程控制表达式的东西，它们用来控制程序的运行方式，并会接受真值或假值。
有些运算符可以用来生成真值或假值，它们被称为[比较运算符][comparison-operators]。

主要有两种控制表达式，用来控制哪些代码会运行、哪些不会运行。
也就是指会执行其中哪个分支。

这两种分别是：`if` 和 `unless` 表达式。

## 比较运算符

[比较运算符][comparison-operators]用于比较值，并返回 `true`或`false`值。
下面这些运算符要求被比较的两个值属于同一种类型。
如果两个值的类型不同，编译器就会抛出错误。
下面列出了这些运算符，以及它们得到 `true` 值的示例：

| Method | Description           | Example |
| ------ | --------------------- | ------- |
| <      | 小于             | 4 < 5   |
| <=     | 小于或等于    | 4 <= 4  |
| >      | 大于          | 3 > 1   |
| >=     | 大于或等于 | 2 >= 2  |

与前面提到的运算符不同，等于和不等于运算符可以用来比较任何类型的值。
`==` 运算符用于检查两个值是否相等，这包括检查值的类型。
`!=` 的工作方式相同，但如果两个值不相等就返回 `true`，相等则返回 `false`。
下面列出了等于和不等于运算符，以及它们得到 `true` 值的示例：

| Method | Description  | Example |
| ------ | ------------ | ------- |
| ==     | 相等        | 4 == 4  |
| !=     | 不相等    | 5 != 4  |

## `if` 语句

[`if`][if] 语句用于检查给定条件是为真还是为假。
如果条件为真，就会运行 `if` 语句内部的代码。
`if` 语句以 `end` 关键字结束。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## `unless` 语句

`unless` 语句的工作方式与 `if` 语句非常相似，但当条件为假时，它会运行 `unless` 语句内部的代码。

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## `else` 语句

`else` 语句可以和 `if` 语句搭配使用。
如果 `if` 分支没有执行，就会执行 `else` 语句。

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## “级联 if”语句

`elsif` 语句可以和 `if` 语句搭配使用。
如果 `if` 分支没有执行，并且 `elsif` 语句的条件为真，就会执行 `elsif` 语句。
`elsif` 语句可以串联在一起，第一个为真的条件会被执行。
`if` 语句的末尾还可以有一个 `else` 语句，如果前面的语句都不为真，它就会执行。

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
