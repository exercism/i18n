# 说明

在卡牌游戏 Spellbound Steel 中，你有一副卡牌，牌面要么是不同的角色，比如战士、法师和盗贼，要么是不同的法术，比如火球、冰风暴和闪电箭。
游戏有两到四名玩家，目标是通过打出能量等级更高的卡牌来击败其他玩家。

你想通过编写各种方法来计算、排序和比较卡牌的能量等级，从而在游戏中占据上风。

## 1. 在牌组中查找卡牌

你不确定某张卡牌是否在牌组里。因此，你想要一个方法，告诉你能在牌组中哪里找到你想要的那种卡牌中的第一张。如果牌组里没有这张卡牌，你也希望知道这一点。

实现一个方法`SpellboundSteel.find_card?`，它接收一个由`String`卡牌组成的`Array`，以及一张要查找的`String`卡牌。该方法应返回牌组中第一张与要查找的卡牌匹配的卡牌的下标。如果牌组中没有这张卡牌，方法应返回`nil`。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt", "Mage"]
SpellboundSteel.find_card?(cards, "Mage")
# => 1
```

## 2. 将所有字符改为大写

为了让卡牌更易读，你希望把卡牌名称中的所有字符都改为大写。这样你在打出卡牌时就能轻松看清卡牌名称。

实现一个方法`SpellboundSteel.capitalize_cards`，它接收一个由`String`卡牌组成的`Array`，并返回所有字符都已大写的卡牌。

```crystal
cards = ["warrior", "mage", "rogue", "fireball", "ice storm", "lightning bolt"]
SpellboundSteel.capitalize_cards(cards)
# => ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
```

## 3. 计算所有卡牌的能量等级

在游戏中，计算所有卡牌的能量等级很重要。所有卡牌的能量可以在下表中看到：

| Card Type      | Power Level |
|----------------|-------------|
| Warrior        | 10          |
| Mage           | 20          |
| Rogue          | 30          |
| Fireball       | 15          |
| Ice Storm      | 25          |
| Lightning Bolt | 35          |

实现一个方法`SpellboundSteel.calculate_power_level`，它接收一个由`String`卡牌组成的`Array`，并返回所有卡牌的能量等级总和。

```crystal
cards = ["Warrior", "Mage", "Rogue", "Fireball", "Ice Storm", "Lightning Bolt"]
SpellboundSteel.calculate_power_level(cards)
# => 135
```

## 4. 解码卡牌

在游戏中，有一种被称为诅咒卡牌的卡牌。这类卡牌是隐藏的，只有打出它的玩家才能解码。要解码卡牌，你需要取出卡牌名称中每隔一个的字符并删掉，这样就能得到卡牌的名称。

实现一个方法`SpellboundSteel.decode_card`，它接收一张`String`卡牌，并返回解码后的卡牌。

```crystal
SpellboundSteel.decode_card("Wbalrrrlimoqr")
# => "Warrior"
```
