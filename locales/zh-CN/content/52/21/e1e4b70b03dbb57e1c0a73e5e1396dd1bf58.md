# 关于

`Option`类型是 F# 语言中用来处理那些可能存在、也可能不存在的值的机制。
它提供了类型安全的替代方案，可以取代其他语言中常用于处理这类值的`null`。
许多 F# 标准库函数都会用到它，因此理解它是有效使用 F# 标准库的关键。

## 使用 `Option` 类型的好处

* __编译时安全__：通过在类型系统中明确表示值的存在与否，编译器可以确保你处理“没有值”的情况，从而避免一大类使用`null`时可能出现的 bug。

* __运行时安全__：F# 使用`None`而不是`null`来表示值的缺失，因此不可能发生`NullReferenceException`。

* __强制显式处理__：类型系统要求代码显式处理`Some value`和`None`两种情况，让你的代码更健壮、更可预测。

* __与模式匹配配合良好__：`Option`能与 F# 的模式匹配惯用法无缝配合，提供一种干净、安全的方式来解构并处理存在的值，或者在没有值时执行另一种操作。

## 用法

`Option`类型是一种泛型类型（有一个底层类型）。  
`Option`的值要么是`Some value`，表示某个具体的值，要么是`None`，表示没有值。

下面的函数演示了如何创建一个`Option`值：

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option`是`Option<T>`的后缀写法，两种写法可以互换使用。
不过，根据 F# 风格指南，对于 Option 类型更推荐使用后缀写法（参见 [F# 风格指南中关于类型与类型标注格式的部分](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)）。
~~~~

`Option`的一个典型用途是搜索函数。
例如，当元素位于列表中时，`List.tryFind`函数会返回`Some index`（其中`index`是所查找的值在列表中的位置），当元素不在列表中时则返回`None`。

## 读取 Option 值的内容

读取`Option`值的惯用方式是通过模式匹配，如下例所示：

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## 用默认值解包 Option

通过`Option.defaultValue`函数提供默认值，可以把`Option`“解包”（转换为其包含的类型）。
当你想要确保值不是`None`时，这一点尤其有用。
例如：

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## `Option`模块中的更多函数

`Option`模块还包含与列表、数组、序列及其他集合类型的可用函数相对应的函数，比如`Option.map`、`Option.iter`、`Option.forall`、`Option.count`。
这些函数让`Option`可以像由零个或一个元素组成的集合那样被处理。
