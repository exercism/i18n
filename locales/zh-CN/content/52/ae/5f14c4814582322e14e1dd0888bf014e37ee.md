## 1. 试着提取一些最初的线索

你查看了从测试文件中恢复出来的两行代码：

```cpp
heaven::Vessel bob{"Robert Johansson", 1};
heaven::Vessel will{"Riker", 2, star_map::System::BetaHydri};
```

你敏锐的眼睛立刻认出了一个命名空间`heaven`。
你还看出，一定存在一个名为`Vessel`的类。
这个构造函数显然可以用两个或三个实参来调用。
第一个实参的类型似乎是`string`，第二个是一个数字。
还可以用第三个实参来初始化`Vessel`类。
第三个实参来自一个`star_map`命名空间。
它是`System`类型的枚举项。
你甚至还得到了其中一个枚举项：`BetaHydri`。

根据你发现的这些信息，准备好源文件和头文件。
你需要两个命名空间：`heaven`和`star_map`。
`heaven`命名空间中有一个类`Vessel`，它可以用两个或三个实参来调用。
`System`枚举要放在`star_map`命名空间中，并且有一个`BetaHydri`枚举项。
留意其他枚举项，这样你就能不断更新`System`枚举。

## 2. 找出更多细节

你又从测试中发现了更多代码行：

```cpp
heaven::Vessel bob{"Robert Johansson", 1};
REQUIRE(bob.current_system == star_map::System::Sol);
REQUIRE(bob.generation == 1);
heaven::Vessel bob5 = bob.replicate("Mario");
REQUIRE(bob5.current_system == star_map::System::Sol);
REQUIRE(bob5.generation == 2);
```

新发现的测试代码行揭示了`Vessel`类的另一个成员函数：`replicate`。
这个函数接收一个字符串，并返回另一个`Vessel`实例。
从上一个任务中，你能大致了解构造函数第三个实参的默认值。
你还看到了`Vessel`类的两个公有成员变量，以及`replicate`成员函数的规格说明。

把`replicate`函数以及公有成员变量`current_system`和`generation`添加到头文件和源文件中。

## 3. 探究内部工作原理

你在恢复出来的测试文件中又找到了一些有趣的代码行：

```cpp
heaven::Vessel bob6{"Homer", 3, star_map::System::EpsilonEridani};
REQUIRE(bob6.busters == 0);
bob6.make_buster();
REQUIRE(bob6.busters == 1);
bool success = bob6.shoot_buster();
REQUIRE(success);
REQUIRE(bob6.busters == 0);
success = bob6.shoot_buster();
REQUIRE_FALSE(success);
```

显然，`Vessel`类有一个成员变量`busters`，它可以通过`make_buster`和`shoot_buster`这两个类成员函数来改变。
在其他信息出现之前，你猜测`make_buster`函数返回`void`。
由于有一个针对`shoot_buster`返回值的测试，你假设这个函数返回`bool`。

把这两个函数和这个成员变量添加到`Vessel`类中。
继续寻找其他`System`枚举项。

## 4. 补全全貌

在浏览测试文件的过程中，你只找到两段尚未弄清楚的代码：

```cpp
heaven::Vessel bob1{"Bob", 1, star_map::System::AlphaCentauri};
heaven::Vessel marv{"Marvin", 2, star_map::System::DeltaEridani};
heaven::Vessel milo{"Milo", 3, star_map::System::DeltaEridani};
heaven::Vessel howie{"Howard", 4, star_map::System::Omicron2Eridani};

REQUIRE("Bob" == heaven::get_older_bob(bob1, marv));
REQUIRE(heaven::in_the_same_system(marv, milo));
REQUIRE_FALSE(heaven::in_the_same_system(marv, howie));
```

你看到两个函数，它们不是`Vessel`类的成员，因为它们并不是通过实例调用的。
`get_older_bob`比较两个`Vessel`实例并返回一个`string`。
`in_the_same_system`比较两个`Vessel`实例并返回一个`bool`。

根据上面恢复出来的代码行，实现最后缺失的函数。
