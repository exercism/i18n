# 输入

本练习的输入包括：

- `target`：一个字符串（例如`'stone'`），将作为_左参数_。
- `candidates`：一组装箱字符串（例如`'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`），将作为_右参数_。

你的动词会这样被调用：

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## 输出

你的动词应返回一个由装箱组成的_列表_，箱子里装着与目标字符串互为变位词的字符串。如果没有变位词，结果应为 `empty`。
