# 说明

在本练习中，你将实现一个角色扮演游戏的机制。
玩家的角色由以下类型表示：

```elm
type alias Player =
    { name : Maybe String
    , level : Int
    , health : Int
    , mana : Maybe Int
    }
```

本游戏中的玩家必须达到 10 级才能解锁法力池，进而开始施放法术。
你正在开发这个游戏的两项功能：复活机制和法术施放机制。

## 1. 自我介绍

编写`introduce`函数的内容。
潜行的玩家可能隐藏了自己的名字，他们会被介绍为`"Mighty Magician"`。
否则，直接用自己的名字来介绍自己。

```elm
introduce { name = Nothing, level = 2, health = 8, mana = Nothing }
    --> "Mighty Magician"

introduce { name = Just "Merlin", level = 2, health = 8, mana = Nothing }
    --> "Merlin"
```

## 2. 实现复活机制

`revive`函数应检查玩家的角色确实已经死亡（生命值降到了 0）。
如果是，它应返回一个生命值为 100 的新`Player`实例。
否则，如果玩家的角色没有死亡，`revive`函数返回`Nothing`。

如果玩家的等级达到 10 级或以上，复活时还应恢复 100 点法力。
如果玩家的等级低于 10 级，其法力值应为`Nothing`。
`revive`函数应保留玩家的等级。

```elm
deadPlayer = { name = Nothing, level = 2, health = 0, mana = Nothing }

revive deadPlayer
    --> Just { name = Nothing, level = 2, health = 100, mana = Nothing }
```

如果对一个生命值在 1 或以上的玩家调用`revive`方法，那么该函数应返回`Nothing`。

```elm
alivePlayer = { name = Nothing, level = 2, health = 42, mana = Nothing }

revive alivePlayer
    --> Nothing
```

## 3. 实现法术施放机制

`castSpell`函数接收一个表示法术消耗多少法力的`Int`和一个`Player`作为实参。
它返回更新后的玩家，以及所施放法术造成的伤害量。
成功施放法术造成的伤害等于法术法力消耗的两倍。
但是，如果玩家的法力不足，什么都不会发生：玩家保持不变，也不会造成伤害。
如果玩家甚至没有法力池，尝试施放法术必须使其生命值减少法术的法力消耗，并且不造成任何伤害。

```elm
wizard = { name = Nothing, level = 18, health = 123, mana = Just 30 }

( updatedWizard, damage ) = castSpell 14 wizard

updatedWizard.mana --> Just 16
damage             --> 28
```
