# 同步到 GitHub

大家好！

过去几个月，我们一直在努力打磨[编程基础](https://exercism.org/courses/coding-fundamentals)和[前端基础训练营](https://exercism.org/courses/front-end-fundamentals)，这两门课程给我们带来了非常棒的体验。现在它们已经完成，我们正抽时间给 Exercism 主站添加一些新功能！

今天，我们在 Exercism 上推出**两项新功能**：
1. 把你的解答同步到 GitHub。
2. 保存并浏览你的 Favorites。

## 把你的解答同步到 GitHub

拥有自己的公开解答备份，是大家呼吁已久的功能。
很多人会手动把解答同步到 GitHub，甚至为此自己写脚本，而现在这个功能已经**内置在 Exercism 中**！

启用该功能后，你的解答会自动开始备份到 GitHub。你可以配置备份是通过拉取请求还是提交来进行，还可以把历史上所有解答一次性批量上传！

一个月前，我们低调地向 Insiders 开放了这个功能，如今已经向 GitHub 备份了数万个解答。用的人越多，就越喜欢它。正如一位 Insider 所说：

> 这个功能刚被提出时，我没什么特别的感觉，但现在它已经上线，我非常高兴你们把它做了出来！我已经无法想象没有它的 Exercism 了。
> 
> \- W8CYE，来自 Discord

想开始使用，只需前往新的 [GitHub 同步设置页面](https://exercism.org/settings/github_syncer)，连接一个代码仓库就行！

## Favorites

今天我们还推出了 [Exercism Favorites](https://exercism.org/favorites)，用来保存和浏览你在 Exercism 上找到的最佳解答。

Favorites 的设计初衷，是让你把一切有趣、有启发或让你印象深刻的解答都收集起来：你可以在浏览网站时给解答加星，之后想深入研究时再回来查看。

想添加收藏，只需点击任意社区解答上的 “Favorite” 按钮。你会看到文字变成 “Favorited”，星星也变成金色！
想取消收藏，再点一次就可以了。

<img src="https://assets.exercism.org/images/community/favorites-button.png" alt="社区解答页面的截图，其中显示了 Favorite 按钮" style="width:100%; max-width:600px;" width="2182" height="980" />

你之前加过星的解答已经自动迁移到你的 Favorites 中。你可以通过 Learn 菜单进入 Favorites，也可以直接点击[这个链接](https://exercism.org/favorites)。
