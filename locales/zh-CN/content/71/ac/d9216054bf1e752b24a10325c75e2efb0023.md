# 简介

大多数 Factor 序列词都会返回*新的*序列，而不改动传入的值；不过，数组和向量都支持**原地修改**，可以用来记录会随时间变化的状态。

`set-nth`和`change-nth`会原地修改其中的一个位置，而且对数组和向量都适用。`<array>`用于构建长度固定的可变数组；`V{ }`字面量、`<vector>`、`push`和`pop`则是只属于向量的一组词，因为数组的长度无法改变。`clone`会复制整个序列，这样后续的修改就不会影响原来的序列。

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
