# 说明

在本练习中，你将管理一个库存系统。

库存应按物品名称组织，并记录每种物品的可用数量。

你需要处理向库存中添加物品。每当某个物品在给定的数组中出现一次，该物品在库存中的数量就应增加`1`。你还需要处理从库存中删除物品：在收到请求时把数量减少`1`。

最后，你需要实现一个函数，它把给定库存中的所有键值对作为一个由`tuples`组成的`list`返回。


## 1. 根据数组创建库存

实现`create_inventory(<input list>)`函数，它根据输入的物品数组创建一个“库存”。它应返回一个`dict`，其中每个物品名称都与对应的数量配对。

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. 把数组中的物品添加到现有字典

实现`add_items(<inventory dict>, <item list>)`函数，它把物品数组添加到传入的库存中：

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. 减少库存中的物品数量

实现`decrement_items(<inventory dict>, <items list>)`函数，它接收一个物品`list`。物品在`list`中每出现一次，你的函数就应把该物品的计数减`1`：

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

库存中物品的计数不应低于 0。如果某个物品在输入`list`中出现的次数超过了可用的计数，该物品记录的数量应保持在 0。一旦计数降为零，后续的减少计数的请求都应被忽略。

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. 从库存中彻底删除某个条目

实现`remove_item(<inventory dict>, <item>)`函数，它把某个物品及其计数从库存中彻底删除：

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

如果在库存中找不到该物品，函数应原样返回原来的库存。

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. 返回库存的全部内容

实现`list_inventory(<inventory dict>)`函数，它接收一个库存，并返回一个由`(item, quantity)`元组组成的数组。该数组只应包含*可用的*物品（*数量大于零*）：

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
