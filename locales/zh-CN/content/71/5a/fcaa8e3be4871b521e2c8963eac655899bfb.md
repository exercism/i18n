# 提示

## 通用

- `<dlist>`在[`dlists`][dlists]中；push/pop 相关的单词在[`deques`][deques]中。
- `MEMO:`在[`memoize`][memoize]中。
- 局部变量（`::`和`:>`）能让 BFS 的循环体保持易读；谓词看到的局部变量与循环体相同。

## 1. 排空潮汐队列

- 先用`<dlist>`，用`[ push-back ] each`把它填满，再用`until`循环（谓词为`[ deque-empty? ]`）把它排空：把队首弹出到一个`V{ } clone`里，最后用`>array`转成数组。

## 2. 可达的海湾

- 模式：用`HS{ } clone`表示`visited`，用`<dlist>`表示`frontier`，把`start`标记为已访问并把它压入 frontier，然后循环直到 frontier 为空：弹出队首，用`at`在 chart 里查找它的邻居，对每个没见过的邻居，adjoin 到`visited`，再 push-back 到 frontier 上。

## 3. 跳数

- 和任务 2 结构相同，但双端队列里装的是`{ cove distance }`对。当你弹出的某个对，其 cove 等于目标时，把距离记为答案并停止。使用可变局部变量（`f :> answer!`），并让`until`循环以`frontier deque-empty? answer or`为条件。

## 4. 金币数量

- 一条声明：`MEMO: gold-count ( cove -- n ) gold-distribution at 0 or ;`。`MEMO:`替代开头的`:`；其余部分就是普通的单词定义。键不存在时`at`返回`f`；`0 or`则用 0 代替。

## 5. 寻宝路线

- `coves-reachable`返回一个哈希集合；`members`（在`sets`中）把它转成一个序列。用`[ [ gold-count ] keep 2array ] map`构建一个由`{ gold cove }`对组成的数组，然后`sort`这个数组（它会按第一个元素给这些对排序），再用`last second`取出金币最多的那一对里的 cove。
