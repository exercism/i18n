# 测试

## 运行测试

进入某道练习所在的目录后，你会看到两个子目录：

* `Sources/<Exercise>` 里放着你为该练习编写的解答
* `Tests/<Exercise>Tests` 里放着该练习要运行的测试

如果你在正确的目录中（也就是包含 `Sources` 和 `Tests` 的那个目录），只要运行 `swift test`，就能运行这道练习的测试：

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

当某个测试通过后，删除 `@Test` 语句中的 `.enabled(if: RUNALL)`，就能启用下一个测试。另一种做法是，在 Linux 或 macOS 上把环境变量 `RUNALL` 设为 `true`，一次性运行所有测试：

```bash
$ export RUNALL=true
```

如果你在 Windows 上使用 PowerShell：

```powershell
set RUNALL=true
```

## 提交你的解答

要把解答上传到 Exercism，你必须位于包含 `Sources` 和 `Tests` 目录的那个目录中。

```bash
$ exercism submit 
```
