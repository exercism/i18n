# 简介

## 基础

Java 是一种静态类型语言，这意味着变量的类型在编译期就已确定。
把值赋给一个名字，称为定义变量。
定义变量时需要显式指定它的类型。

```java
int explicitVar = 10;
```

更新变量的值要通过`=`运算符完成。
这里的`=`并不表示数学意义上的相等，它只是把一个值赋给变量。
变量一旦定义，它的类型就永远无法改变。

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning a different type
// count = false;
```

Java 是一种[面向对象语言][object-oriented-programming]，要求所有函数都定义在_类_中。
`class`关键字用于定义类。

```java
class Calculator {
    // ...
}
```

类中的函数称为_方法_。
每个方法可以有零个或多个形参。
所有形参都必须显式标注类型，形参没有类型推断。
同样，返回类型也必须显式写出。
方法通过`return`关键字返回值。
要让其他类能够调用某个方法，必须加上`public`访问修饰符。

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

调用方法时，需要指定它所属的类和方法名，并为方法的每个形参传入实参。

```java
int sum = new Calculator().add(1, 2);  // here the  "add" method has been called to perform the task of addition
```

Java 中的作用域定义在`{`和`}`字符之间。

Java 支持两种注释。
单行注释以`//`开头，多行注释写在`/*`和`*/`之间。

[object-oriented-programming]: https://docs.oracle.com/javase/tutorial/java/javaOO/index.html
