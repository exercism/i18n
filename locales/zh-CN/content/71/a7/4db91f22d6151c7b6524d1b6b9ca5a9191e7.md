# 简介

Gleam 中的字符串是不可变的文本，用双引号括起来。字符串支持 Unicode 字符，也可以是多行的。

```gleam
let greeting = "Hello, Joe! 📞"

let multi_line_string = "one
two
three"
```

可以用 `<>` 运算符把字符串拼接起来：

```gleam
let name = "Mike"
"Hello, " <> name <> "!"
// -> "Hello, Mike!"
```

标准库中的[`gleam/string`][stdlib]模块提供了处理字符串的函数。

字符串可以在 `case` 表达式中进行匹配：

```gleam
pub fn on_an_excellent_adventure(name: String) -> Bool {
  case name {
    "Bill" -> True
    "Ted" -> True
    _ -> False
  }
}
```

如果想匹配字符串的开头，并把剩余部分赋值给一个变量，可以使用 `<>` 运算符模式：

```gleam
pub fn profession(name: String) -> String {
  case name {
    "Dr " <> rest -> rest <> " is a doctor"
    _ -> "I'm not sure what " <> name <> " does"
  }
}
```

[stdlib]: https://hexdocs.pm/gleam_stdlib/gleam/string.html
