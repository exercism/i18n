# 简介

F# 中的`list`是一个不可变的集合，包含零个或多个值。数组中的所有值必须都具有相同的类型。由于数组是不可变的，一旦构造了一个数组，它的值就永远不会改变。任何看起来会修改数组的函数/运算符（例如添加元素）实际上都会返回一个新的数组。

数组可以这样定义：

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

向数组中添加元素最常见的方式是通过`::`（cons）运算符：

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

一个 F# 数组有一个 _头部_（第一个元素）和一个 _尾部_（第一个元素之后的所有内容）。数组的尾部本身也是一个数组。

数组可以通过`List`模块中定义的函数和运算符来操作，也可以手动使用模式匹配，借助 _数组_ 和 _cons_ 模式：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

在模式匹配时，你还可以 _丢弃_ 一个值；当你在某个特定分支中 _不_ 关心某个值时（也就是说，你不会 _使用_ 这个值），可以使用下划线（`'_'`）来表示这一点：

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

单个`'_'`在模式匹配时应始终放在 _最后_，所有 _不_ 匹配其他任何分支的值都会由这个分支处理。
