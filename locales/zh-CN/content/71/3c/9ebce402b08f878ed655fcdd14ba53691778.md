你需要编写一个服务来接收事件。每个事件都带有一个日期，但你注意到，有 3 种不同的格式被提交到服务的端点：

- `"01/01/1970"`
- `"January 1, 1970"`
- `"Thursday, January 1, 1970"`

你能看出它们之间存在一些相似之处，于是决定编写一些可组合的正则表达式模式。

## 1. 匹配日期中的日、月和年

实现 `day`、`month` 和 `year`，让它们返回一个字符串模式；该模式在执行时，能够匹配 `"01/01/1970"`（`dd/mm/yyyy`）中的数字部分。日和月可能写成 `1` 或 `01`（左侧补零）。

不用担心错误检查。你可以假定传入的永远是有效的数字部分。

```clojure
(day "31")
;;=> "31"
(month "12")
;;=> "12"
(year "1970")
;;=> "1970"
```

## 2. 匹配星期几和月份

实现 `day-name` 和 `month-name`，让它们分别返回一个字符串模式；该模式在执行时，能够匹配星期几的名称和月份的名称。

```clojure
(day-name "Tuesday")
;;=> "Tuesday"
(month-name "June")
;;=> "June"
```

## 3. 捕获日、月和年

实现 `capture-day`、`capture-month`、`capture-year`、`capture-day-name`、`capture-month-name`，让它们返回一个映射，把各个组成部分映射到对应的名称：`"day"`、`"month"`、`"year"`、`"day-name"`、`"month-name"`

```clojure
(capture-month-name "December")
;;=> {:month-name "December"}
```

## 4. 组合各个捕获，以捕获整个日期

实现 `capture-numeric-date`、`capture-month-name-date` 和 `capture-day-month-name-date`，让它们使用对应的日期格式，返回第 3 部分中各个组成部分组成的映射。

```clojure
(capture-numeric-date "01/01/1970")
;;=> {:day "01", :month "01", :year "1970"}
```
