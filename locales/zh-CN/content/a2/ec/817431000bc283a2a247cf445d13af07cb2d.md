# 关于

PowerShell 是微软推出的一门动态、隐式类型的脚本语言（_但也支持[强类型][strong typed]变量_），主要面向任务自动化和配置管理。

PowerShell 支持命令式、函数式、面向对象乃至管道风格的编程。

PowerShell 基于 .NET 平台构建，于 2006 年首次发布。它已默认包含在所有现代 Windows 操作系统中，也可以安装在 Mac 和 Linux 上。


## 变量

在 PowerShell 中，定义变量有两种常见方式。

PowerShell 中的变量名必须以`$`开头，并使用赋值运算符`=`把变量名绑定到一个值。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

如果你希望强制要求值属于某种类型，也可以显式指定变量的类型。只要可行，PowerShell 会尽力把值从一种类型转换为另一种类型。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### 常量

PowerShell 中的常量是定义之后既不能**更改**也不能**删除**的变量。这就引出了定义变量的第二种方式：使用 cmdlet `New-Variable`。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## 函数

PowerShell 中使用`function`关键字定义函数。每个函数可以在`()`括号内有零个或多个形参，后面跟着以`{`开始、以`}`结束的函数作用域。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 中的函数在使用语法`FuncName $Arg`调用之后，可以通过`return`关键字显式返回值。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## 注释

PowerShell 中的单行注释以`#`开头，到行尾结束。注释块以`<#`开头，以`#>`结束。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
