# 测试

你可以在练习目录中运行以下命令来运行测试：

```bash
dub test
```

## 通过测试

先按照[测试驱动开发的三条规则](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd)，让第一个测试通过编译、链接并运行成功。通过声明命名空间、函数、类等，只搭建刚好够用的结构，消除编译器报错，让测试失败。然后只写刚好够用的代码，让测试通过。完成之后，把下面这行移到下一个测试之后，取消对下一个测试的注释。

```D
static if (all_tests_enabled)
```

这时可能会出现编译错误，因为新调用的结构你还没有声明或定义。同样，用最小的改动修掉编译错误，得到一个失败的测试，再用最小的改动修改代码，让测试通过，然后重构你的实现，让它更易读、表达力更强，接着再去做下一个测试。

尽量使用 D 的标准功能，而不是自己动手编写底层的算法或工具。
