# 简介

## 字符串

在 Elm 中，字符和字符串是文本表示的基础。
可以把字符串看作由字符组成的数组，`List` 模块里的大多数函数在 `String` 模块中都有对应的版本。

### 字符

`Char` 类型用单引号表示单个 Unicode 字符，例如`'a'`。
`Char` 模块提供了一些谓词函数（`Char -> Bool`），用来判断字符的性质：`isUpper`、`isLower`、`isAlpha` 和 `isAlphaNum`。
该模块还提供了一些函数，用于转换字符，如 `toUpper`、`toLower`、`toLocaleUpper`、`toLocaleLower`，以及通过 `toCode` 和 `fromCode` 在字符与它的 Unicode 数值（`Int`）之间互相转换。

### 字符串

`String` 类型为高效的字符串操作提供了内置表示，可以表示任意 Unicode 字符序列，例如 "this is an Elm string."
多行字符串用三个双引号表示，其中可以包含未转义的引号和换行。
```elm
"""
    This is a multiline string.
All line-breaks and whitespace,
are preserved. 
"""
```

### 字符串函数

`String` 模块包含下表汇总的所有函数。
以下是一些最常用的函数：

`cons : Char -> String -> String`会在字符串开头添加一个字符。
```elm
cons 'T' "he truth is out there" 
    --> "The truth is out there"
```

`(++): String -> String -> String`会把两个字符串拼接起来。
```elm
"butter" ++ "fly" 
    --> "butterfly"
```

`split : String -> String -> List String`会按给定的分隔符把字符串拆分成字符串数组。
```elm
split ";" "cat;dog;cow" 
    --> ["cat", "dog", "cow"]
```

`join : String -> List String -> String`会用给定的分隔符把一个字符串数组拼接起来。
```elm
join "a" ["H", "w", "ii", "n"] 
    --> "Hawaiian"
```
`replace : String -> String -> String -> String`会替换所有出现的给定子串。
```elm
replace "Hello" "Goodbye cruel" "Hello world." 
    --> "Goodbye cruel world."
```

`length : String -> Int`返回字符串中字符的个数。
```elm 
length "Hello world." 
    --> 12
```

`toInt : String -> Maybe Int`会尝试把字符串转换成 `Just Int`，对于格式不正确的字符串则返回 `Nothing`。
```elm
toInt "-42" 
    --> Just -42
```    

`contains : String -> String -> Bool`检查第二个字符串是否包含第一个字符串。
```elm
contains "the" "theory" 
    --> True
```

`map : (Char -> Char) -> String -> String`会把给定的函数应用到字符串中的每个 `Char`。
注意，传入的函数必须是从 `Char` 到 `Char` 的映射。
```elm
map (\c -> if c == '/' then '.' else c) "a/b/c" 
    --> "a.b.c"
```
