# 学习

## 从零开始学习 C

一般来说，Exercism 假定你已经掌握了某个 track 中编程语言的语法和机制。不过，了解一门语言的语法，只是掌握它的第一步。Exercism 让你练习解决问题，并与其他解决过同一问题的开发者交流讨论。正是在这样的讨论中，我们获得经验和洞见，一步步成为更好的开发者。

如果你是刚接触 C 语言的新手，应该先花些时间学习这门语言的基础知识。下面这些资源可以帮你入门：

* [Learn C][]
* [CS50x][]

[CodeChef][] 是一个简单的网页表单界面，直接连接 C 编译器，可以让你试着运行小程序。有时候，比起在本地用集成开发环境搭建点什么，这是做个快速实验更省事的办法。

## C 语言中的测试驱动开发

Exercism 假定你熟悉测试驱动开发的概念。每道练习都自带一系列已经为你写好的测试。你一次通过一个测试来推进练习，逐步写出实现，满足这些测试。

如果你没接触过测试驱动开发，强烈建议你先读一读[一些 C 测试框架的快速概览][test-frameworks]，或者看看 James Grenning 的 [Test-Driven Development for Embedded C][tdd]。这些资源介绍了 [Unity][] 和 [CppUTest][]；这个 track 使用的是 Unity。
