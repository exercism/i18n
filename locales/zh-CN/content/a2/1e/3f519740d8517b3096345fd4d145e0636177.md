# 简介

元组是一种轻量的方式，可以把一组数量固定、类型任意的数据组合在一起。
元组没有特定的名字；一旦给数据结构起了名字，它就变成了`struct`。
元组的字段没有名字；要通过解构或按位置来访问它们。

## 创建

元组总是通过元组表达式创建的：

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

元组可以有任意数量的元素。

## 通过解构访问

可以通过解构来访问元组中的元素。
这其实就是把变量名分别赋给元组中的各个元素，并消耗掉该元组。

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```
