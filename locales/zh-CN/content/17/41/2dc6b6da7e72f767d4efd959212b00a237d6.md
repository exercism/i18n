# 说明

你正在实现一个健康监测系统。为此，你需要记录用户的健康统计数据。

一开始，`impl`块中会有一些存根函数，以及下面这个结构体定义：

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

你的目标是实现`impl`块中定义的`User` `struct`上的这些存根方法。

例如，`new`方法应该返回一个`User`结构体实例，其中包含指定的姓名、年龄和体重值。

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

`weight`方法应该返回`User`的体重。

```rust
bob.weight();
// Returns: 155.2
```

`set_age`方法应该设置`User`的年龄。

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```
