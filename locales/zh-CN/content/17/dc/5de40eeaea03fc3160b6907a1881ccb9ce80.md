# 说明

在这道练习中，你在一家为顾客提供外送服务的披萨店工作。

你们提供三种披萨：

- Margherita：7 美元
- Caprese：9 美元
- Formaggio：10 美元

顾客还可以支付少量额外费用，选择两种附加选项：

1. 额外酱料：1 美元
1. 额外配料：2 美元

顾客下单时，如果只订一两个披萨，就会被加收一笔额外费用：

- 1 个披萨：3 美元
- 2 个披萨：2 美元

你有三个任务，每个任务都与披萨及其价格有关。

## 1. 定义披萨类型和选项

定义`Pizza`自定义类型，以表示不同的披萨类型和选项：

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce`和`ExtraToppings`应该包装`Pizza`类型。

## 2. 计算披萨的价格

实现`pizza_price`函数来计算一个披萨的价格：

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. 计算订单的价格

实现`order_price`函数来计算一个披萨订单的价格：

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
