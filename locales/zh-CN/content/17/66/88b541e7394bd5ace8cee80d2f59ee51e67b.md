# 简介

方法可以有一个可变参数，这样调用方就能像传入普通参数一样传入零个或多个实参。方法会在一个数组中接收这些实参。

要把某个参数声明为可变参数，只需在参数声明中加上 [`params` 关键字](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/keywords/params)：

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
