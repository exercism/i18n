# 介绍

## 数字

Swift 提供两大类数字：整数和浮点数。

- [整数][integers]表示没有小数部分的整数，例如`0`、`1`、`-1`、`42`和`-273`。
- [浮点数][floatingpoint]表示带小数部分的数字，例如`0.0`、`3.14`和`-1.36969e-10`。

你可以往数字字面量里插入下划线来提高可读性：`1_000_000`与`1000000`完全相同。
浮点字面量可以用十进制或指数记法书写。

大多数情况下，整数用[`Int`][int]，浮点数用[`Double`][double]：

```swift
let speed: Int = 42                           // Explicit Int
let pi: Double = 3.14                         // Explicit Double
let giga: Double = 1_000_000_000              // Double with readability underscores
let plancksConstant: Double = 6.62607015e-34  // Double in scientific notation
```

## 算术运算符

Swift 提供标准的[算术运算符][arithmetic-operators]用于数字计算：

| 运算符 | 说明 | 示例 |
| -------- | -------------- | ------- |
| `+`      | 加法       | `4 + 6`的结果是`10` |
| `-`      | 减法       | `15 - 10`的结果是`5` |
| `*`      | 乘法       | `2 * 3`的结果是`6`  |

~~~~exercism/caution
Swift 是类型安全的，不允许在算术运算中混用不同的数字类型。
你不能直接把`Int`和`Double`相加或相乘，必须先把其中一个类型转换成与另一个匹配的类型。
~~~~

### 除法

`/`运算符执行除法。
当两个操作数都是整数时，整数除法会截断小数部分：

```swift
5.0 / 2.0 // 2.5 (Double division)
5 / 2     // 2 (integer division truncates the remainder)
```

非零浮点数除以零会得到`inf`或`-inf`。
`0.0`除以`0.0`会得到`nan`（非数字）。
相比之下，整数除以零会导致编译时或运行时错误：

```swift
print(5.0 / 0.0)  // Prints inf
print(-5.0 / 0.0) // Prints -inf
print(0.0 / 0.0)  // Prints nan

// The following line will not compile:
// print(5 / 0) // Error: Division by zero
```

### 求余运算符

[求余运算符][remainder-operator]（`%`）用来计算两个整数相除后剩下的余数：

```swift
5 % 2  // 1
-5 % 2 // -1

// Dividing by zero produces an error:
// 5 % 0 // Error: Division by zero
```

~~~~exercism/note
在 Swift 中，`%`是真正的*求余*运算符，而不是求模运算符。
结果始终取第一个操作数（被除数）的符号，与第二个操作数的符号无关：

```swift
5 % -2  // 1
-5 % 2  // -1
```
~~~~

## 浮点数取整

你可以用`rounded()`方法对浮点数取整。
默认情况下，`rounded()`取最接近的整数。
你也可以指定具体的[取整规则][rounding-rule]，例如`.up`或`.down`：

```swift
let x = 3.14
let y = x.rounded()      // 3.0
let w = x.rounded(.down) // 3.0
let z = x.rounded(.up)   // 4.0
```

## 类型推断

声明数字常量或变量时如果不写类型标注，Swift 会推断它的类型：

- 整数默认为`Int`。
- 带小数点的数字默认为`Double`。

```swift
let x = 42         // Inferred as Int
let y = 42.0       // Inferred as Double
let z: Double = 42 // Explicitly typed as Double
```

## 类型转换

要在不同类型的值之间进行运算，可以用`Double(_:)`或`Int(_:)`这样的类型初始化器转换其中一个值：

```swift
let integerCount = 42
let floatingCount = Double(integerCount)
print(floatingCount) // Prints 42.0

let pi = 3.14
let integerPi = Int(pi)
print(integerPi) // Prints 3 (fractional part is truncated)
```
