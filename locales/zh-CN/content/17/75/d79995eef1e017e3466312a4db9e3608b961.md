# 介绍

递归是一种在函数中重复代码的方式，靠的是函数调用自身。也可以把它看成循环或迭代的另一种做法。
和循环一样，递归也用布尔表达式或 `True`/`False` 判断来决定什么时候停止递归执行。
_与循环不同_，Python 中不带终止条件的递归无法无限运行下去。
每次函数调用使用的值，都会放在 Python [翻译栈][what-is-the-call-stack]上属于它们自己的[帧][stack-frame]中。
如果函数调用的总数占用的空间超过了栈的容量，就会导致错误。

```python
def print_increment(step, max_value):
    if step > max_value:
        return
    print(f'The step is {step}')
    print_increment(step + 1, max_value)


def main():
    print_increment(1, 2)
    print("After recursion")

if __name__ == "__main__":
    main()

```

这会输出

```
The step is 1
The step is 2
After recursion
```

有些情况用递归表达，会比用循环表达更易读，也更容易理清思路。
