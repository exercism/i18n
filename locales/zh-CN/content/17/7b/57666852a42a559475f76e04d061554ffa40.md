# 说明

你的公司受托根据用户输入生成 CSV 记录。

我们需要一个 CSV 记录构建器，按照[RFC 4180](https://tools.ietf.org/html/rfc4180)中定义的标准。

虽然存在正式规范，但你的公司只需要实现以下功能：
- 创建一个新的记录构建器
- 向记录中添加单个字段
- 使用基本转义序列化记录

基本转义是指：

- 包含换行符、双引号和逗号的字段应该用双引号括起来。

- 如果用双引号把字段括起来，那么字段内部出现的双引号必须通过在它前面再加一个双引号来转义。


## 1. 创建新的构建器

你需要实现`new`方法来创建一个新的构建器。

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. 向记录中添加单个字段

你需要实现`add`方法，把字段追加到记录构建器中。
`add`接受不可变字符串切片`&str`作为实参。

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. 使用基本转义序列化记录

你需要实现`build`方法。
`build`会消耗构建器并返回一条 CSV 记录。
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
