# 说明

你是海岸巡逻艇上的信号员。今天的手袋里，需要在早班值守开始前备好五个小词。

## 1. 引用一个值

日志本用*Factor 源码形式*记录每一次观测，也就是解析器之后会读回的同一段文本。定义 `quote-value`，把任意值转换成它的源码形式字符串。

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. 剥去信号旗的边框

收到的信号旗两端各有一个标记字符作为边框。定义 `flag-body`，返回两个标记*之间*的所有内容，也就是去掉第一个字符、去掉最后一个字符。

返回切片（视图），而不是复制一份。

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. 拆分一面信号旗

每面信号旗都带有一个简短的前缀码，后面跟着载荷。定义 `split-flag`，接收一面信号旗和一个头部长度，返回头部切片和主体切片*两者*。

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. 根据两次读数三角定位

两次连续的信号读数可以得出三个派生测量值：它们的*差* `a - b`、它们的*中点* `(a + b) / 2`，以及它们的*比值* `a / b`。每个测量值都要用到这两次读数。

定义 `triangulate`，根据一对读数返回这三个值。

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. 汇总三次读数

三次连续的读数会被汇总为它们的**和**、**积**和**最大值**。每个统计量都要用到这三次读数。

定义 `triangle-stats`，返回这三个值。

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
