# 关于

Common Lisp 为程序员提供了多种不同的条件表达式，可以按照它们支持的分支数量来分类。

另外，与许多其他编程语言不同，Common Lisp 中的所有条件表达式都是_表达式_，而不是语句。
这意味着所有 Lisp 条件表达式都会求值得到某个值，因此可以替代具体的参数。

举个例子：

```lisp
;; Doubles x when it's even
(* x (if (evenp x) 2 1))
```

## 单分支条件表达式

条件表达式 `when` 和 `unless` 分别在给出的测试为 true 和 false 时才执行某些代码，否则求值结果为 `nil`。

测试表达式后面的部分可以不止一个表达式。

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

## 双分支条件表达式

`if` 条件表达式在测试为 true 时对主体中的第一个表达式求值，否则对第二个表达式求值。

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

注意，then 子句和 else 子句都只能是一个表达式。

## 多分支条件表达式

Lisp 的“超级条件表达式”是 `cond`，它可以有无数个分支。
每个分支都有一个测试条件和一个主体表达式，外面还多包了一对括号。
如果所有测试都求值为 false，则返回 `nil`。

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

注意，测试表达式后面的表达式数量没有限制。


如果你只是想拿一个值与若干个分支作比较，可以使用更简洁的 `case` 表达式。
如果没有任何分支匹配，则返回 `nil`。
`t` 和 `otherwise` 都可以用作兜底分支：

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

注意，和 `cond` 一样，测试表达式后面的表达式数量没有限制。

## 隐形的条件表达式

Common Lisp 中的布尔运算 `and` 和 `or` 是会短路的宏，可以用来减少某些条件表达式中的重复。

`and` 宏只要遇到一个 false 值就会立即返回 `nil`，否则返回 `and` 中最后一个 true 值：

```lisp
(and 42 "Magic" :cool) ; => :COOL
(and () "Magic" :cool) ; => NIL
```

`or` 宏返回它遇到的第一个 true 值，如果没有 true 值则返回 `nil`：

```lisp
(or () 42 nil)  ; => 42
(or () NIL nil) ; => NIL
```

## 我快穷尽了……

如前所述，当 `case` 语句中的分支全都不匹配，又没有 `otherwise` 子句时，就会返回 `nil`。
不过有时候，匹配不上任何分支应当被视为错误，这时就该 `ecase` 登场了（用于**穷尽**匹配）。

它的用法和 `case` 完全相同，但在匹配不到时会抛出错误，而不是返回 `nil`。

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => NIL

(ecase 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark"))
; => ERROR: ELDER-BEAST fell through ECASE expression. Wanted one of (CAT BIRD DOG).
```
