# 简介

`switch()`函数可以简洁地替代一长串 `if` ... `else if` 判断。
用于 switch 的变量通常是一个字符串，这种情况下，选择器里可以省略引号。

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

注意，只有像上面例子中的 `M` 那样把值留空时，选项才会向下穿透。
不像其他一些语言那样，这里不需要写 `break` 语句。

对 `character` 类型进行 switch 时，最后一个值就是默认值，就像这里一样。
而对于整数类型，则无法指定默认值。

## `dplyr`中的函数

base R 中的`switch`相当有限：它只能对单个输入做精确匹配。
在 1993 年 R 首次发布时，这看起来很合理，但按现代的使用需求，它还有待改进。

~~~~exercism/note

只需在代码顶部加上`library(dplyr)`（用于单个包）或`library(tidyverse)`（用于整个系列），就能把`dplyr`包引入作用域。

`dplyr`库提供了两个与`switch`相关的额外函数。

### `recode_values`和`replace_values`函数

这两个相关的函数可以把旧值以类似 switch 的、向量化的方式映射为新值。

它们的主要区别在于，`recode_values()`会创建一个全新的向量，而`replace_values()`允许对已有向量做部分更新。

匹配仍然是精确匹配，不过：

- 左侧的选项可以是向量，只要其中任一元素匹配，输入就算匹配。
- 左侧的选项和右侧的结果用波浪号`~`连接，而不是`=`。
- 所有情况下都可以指定默认值。

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### `case_when`函数

`case_when`把`case_match`的语法又推进了一步：它允许在`~`左侧写任意逻辑表达式。

输入向量（下面例子中的`x`）不是作为实参传入的，它只需要已经定义好。

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

`between()`函数也是`dplyr`的一部分。
