# 简介

在 Java 中，可以用`java.util.Random`类的实例来生成随机数。

## 随机整数

可以使用`nextInt()`方法生成一个随机整数。
这会生成一个从`Integer.MIN_VALUE`到`Integer.MAX_VALUE`范围内的值。

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

要限制生成值的范围，可以使用`nextInt(int)`。
它生成的值从`0`（包含）到给定的上界（不包含）。

例如，下面的代码会生成一个`0`到`9`之间的随机数。

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

下面的代码则会生成一个`10`到`19`之间的随机数。

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

## 随机浮点数

可以使用`nextDouble()`方法生成一个随机浮点数。
它会生成一个从`0.0`到`1.0`范围内的值。

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

下面的代码则会生成一个`100.0`到`200.0`之间的随机数。

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
