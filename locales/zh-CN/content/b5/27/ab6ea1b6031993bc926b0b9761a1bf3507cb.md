# 说明

你期盼已久的这一天终于到来了，现在你自豪地成为了阿尔卑斯山上一座美丽农场的主人。

不过，你仍然不喜欢一大早起床去喂牛。
因为你是一名出色的工程师，所以你造了一台自动喂食器，就叫`FEED-M-ALL`。

完成这个项目还差最后一步：一段计算每头牛应该分到多少饲料的代码。
每头牛分到的量必须相同，否则会引发冲突。
牛可是非常敏感的。

幸运的是，你不需要自己推导计算饲料用量的所有公式。
你用了一个从网上找到的神秘外部库，据说它能让牛过上最幸福的生活。
这个库对外暴露了一个类，它实现了以下接口。
你自己写的代码会依赖它。

```crystal
class FodderCalculator
  def fodder_amount! : Number 
  end

  def fattening_factor! : Number
  end
end
```

在编写代码的过程中，你会逐步改进错误处理，让代码更健壮，日后在日常农场生活中使用时也更容易调试。

## 1. 平均分配食物

首先，你专注于编写计算每头牛饲料用量所需的代码。

实现一个方法`TheFarm.divide_food`，它的参数是一个`FodderCalculator`对象和一个表示牛数量的整数。
*在这个任务中，你可以假定传入的牛的数量总是大于 0。*
该方法应返回每头牛的食物量。

要进行计算，你首先需要获取所有牛的总饲料量。
这通过调用`fodder_amount!`方法并传入牛的数量来完成。
此外，你还需要一个系数，用来乘以这个总量。
这个系数可以通过调用`fattening_factor!`方法获得。
有了这两个值和牛的数量，你现在就可以计算出每头牛的食物量（类型为`float64`）。

如果你调用的某个方法返回错误，执行应立即停止并返回`0`。

```crystal
fodder_calculator = FodderCalculator.new(50, 1.5)
TheFarm.divide_food(fodder_calculator, 5)
# => 15.0

fodder_calculator = FodderCalculator.new(50, nil)
TheFarm.divide_food(fodder_calculator, 5)
# => 0
```

## 2. 检查牛的数量

在完成上面第一个任务的过程中，你发现所用的外部库并没有你想象中那么高质量。
比如，它无法正确处理无效输入。
你想在自己的代码里加一道输入检查来绕过这个限制。

编写一个函数`TheFarm.validate_input_and_divide_food`，它的签名与上面的`TheFarm.divide_food`相同。

- 如果传入的牛的数量大于 0，函数应调用`TheFarm.divide_food`并返回该调用的结果。
- 如果牛的数量小于等于 0，函数应抛出错误，错误消息为`"Number of cows must be greater than 0"`。

```crystal
TheFarm.validate_input_and_divide_food(fodderCalculator, 5)
# => 15

TheFarm.validate_input_and_divide_food(fodderCalculator, -2)
# Error: Number of cows must be greater than 0
```

## 3. 改进错误处理

在传入之前先检查牛的数量，这个做法很不错，但你对那条含糊的错误消息不太满意。
你决定做得更好一些，创建一个名为`InvalidCowsError`的自定义错误类。

这个自定义错误应保存牛的数量（`Int32`）和一条自定义消息（`String`），而`Expection`方法应按以下格式序列化数据：
```txt
{number of cows} cows are invalid: {custom message}
```

有了自定义错误，实现一个函数`TheFarm.validate_number_of_cows`，它接受整数形式的牛的数量，并返回一个错误（或 nil）。

- 如果牛的数量小于 0，函数返回一个`InvalidCowsError`，其自定义消息为`"there are no negative cows"`。
- 如果牛的数量为 0，函数返回一个`InvalidCowsError`，其自定义消息为`"no cows don't need food"`。
- 其他情况下，函数返回`nil`，表示验证通过。

```crystal
TheFarm.validate_number_of_cows(5)
# => nil

TheFarm.validate_number_of_cows(-5)
# => InvalidCowsError: -5 cows are invalid: there are no negative cows
```
