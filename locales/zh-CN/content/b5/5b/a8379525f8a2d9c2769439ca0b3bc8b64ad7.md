# 关于

Haxe 支持对类型和字段的运行时反射。要正确使用反射，必须先了解支持哪些操作、哪些不支持。由于反射具有动态特性，这一点并不总能在编译期确定。

反射 API 由两个类组成：

- `Reflect`：一个轻量级 API，最适合用于匿名结构，对类的支持有限。
- `Type`：一个更健壮的 API，用于处理类和枚举。

可用的方法在 [Reflect][reflect] 和 [Type][type] 的 API 文档中有详细说明。

下面的示例使用的是 JavaScript 目标平台：

```haxe
class Main {
  public static function main() {
    trace(Type.resolveClass("Main"));
  }
}

// This outputs
// class Test { static main() { console.log("Test.hx:3:",$hxClasses["Test"]); } }
```

[reflect]: https://api.haxe.org/Reflect.html
[type]: https://api.haxe.org/Type.html
