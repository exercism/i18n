# 提示

## 概述

- `accessors`提供了自动生成的`slot>>`取值器、`>>slot`赋值器和`change-slot`更新器。
- 赋值器和`change-slot`会*修改*元组。如果想进行非破坏性更新，先`clone`一下。

## 1. 定义`player`元组

- 槽位语法的写法是，在`TUPLE: …  ;`中写`{ name initial: value }`。
- 没有`initial:`子句的槽位默认为`f`。

## 2. 引入玩家

- `name>>`读取`name`槽位。
- 来自[`kernel`][kernel]的`unless*`就是“值为`f`时使用默认值”的惯用法。

## 3. 复活倒下的玩家

- `health>>`读取该槽位；来自[`math`][math]的`zero?`用来判断是否为零。
- 构建新玩家时，先用`clone`，再依次使用`100 >>health`和`100 >>mana`。
- 对于“仍然存活”的情况，返回`f`。

## 4. 承受伤害

- `change-health`接受一个引用`( old-health -- new-health )`。
- 一个 fry 引用`'[ _ - 0 max ]`（其中`max`来自[`math.order`][math.order]）可以实现“减去捕获的伤害，并把结果限制在零”。
- 记得在修改之前先`clone`。

[math]: https://docs.factorcode.org/content/vocab-math.html
