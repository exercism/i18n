# 说明

你在`classes`练习中启动的遥控车项目进展顺利（恭喜！），而且因为最近谈成了好几个赞助合作，预算里有了可以用于改进的资金。

其中一部分预算被用来提供遥测功能。

为了让赞助商满意，车上安装了一块面板，在车绕赛道行驶时显示赞助商名称。

你会注意到，引入这些花哨的新技术大幅缩短了汽车的电池续航。

## 1. 让遥控车能够显示赞助商名称

实现`SetSponsors()`，接收一个或多个赞助商名称并把它们存储在汽车上。

注意，`SetSponsors()`方法的实参保证非空。

实现`DisplaySponsor()`来显示选中的赞助商。传入的第一个赞助商的`sponsorNum`为 0，第二个为 1，以此类推。

```csharp
var car = RemoteControlCar.Buy();
car.SetSponsors("Exercism", "Walker Industries", "Acme Co.");
var sp2 = car.DisplaySponsor(sponsorNum: 1);
// => "Walker Industries"
```

## 2. 获取汽车的遥测数据

实现`RemoteControlCar.GetTelemetryData()`方法。

`GetTelemetryData()`应通过`out`形参提供电池电量百分比和以米为单位的已行驶距离。

如果 serialNum 实参小于之前收到的值，`GetTelemetryData()`应返回`false`。（这里涉及多个遥测节点的问题。）在这种情况下，`serialNum`会被设为之前最高的`serialNum`，电池电量百分比和已行驶米数都会被设为`-1`。调用成功时，`serialNum`保持不变。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
int serialNum = 4;
car.GetTelemetryData(ref serialNum, out int batteryPercentage, out int distanceDrivenInMeters);
// => true, 4L, 80, 4

serialNum = 1;
car.GetTelemetryData(ref serialNum, out batteryPercentage, out distanceDrivenInMeters);
// => false, 4L, -1, -1
```

## 3. 添加功能，让遥测系统能够获取每米电量消耗

实现`TelemetryClient.GetBatteryUsagePerMeter()`方法。

它会调用`RemoteControlCar.GetTelemetryData()`。如果`GetTelemetryData()`返回`false`，或者汽车还没有行驶过，那么这个例程应返回“no data”。如果`GetTelemetryData()`返回`true`，则应返回如下形式的消息“usage-per-meter=BATTERY-USAGE-PER-METER”。其中的计算方式是（100 减去当前电池电量百分比）除以目前行驶的米数。

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
var tc = new TelemetryClient(car);
int serialNum = 4;
tc.GetBatteryUsagePerMeter(serialNum);
// => "usage-per-meter=5"

serialNum = 1;
tc.GetBatteryUsagePerMeter(serialNum);
// => "no data"
```
