# 说明

你的任务是拿到一份比赛中进球球员的名单，然后统计每位球员打进了多少球。

`PlayerName`是`String`的类型别名，这样代码更容易阅读，也能把`String`的这种用法与它的其他用法区分开。

## 1. 汇总得分球员

首先实现`updateGoalCountForPlayer`，用来初始化或自增某位球员的进球数。
然后实现`aggregateScorers`函数，借助`updateGoalCountForPlayer`统计每位球员打进了多少球。
这个函数接收一个`List PlayerName`（打进球的球员名字，可能包含重复的球员名字），返回一个`Dict PlayerName Int`，其中包含列表中的所有球员以及他们各自的进球数。

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. 移除不重要的球员

实现`removeInsignificantPlayers`函数，把进球数低于阈值的球员过滤掉。

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. 重置球员的进球数

实现`resetPlayerGoalCount`函数，把某位球员的进球数重置为零。

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. 格式化单个球员的进球数

实现`formatPlayer`函数，把单个球员的进球数格式化成字符串。如果字典中没有该球员，就认为他的进球数为零。

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. 格式化所有球员的进球数

实现`formatPlayers`函数，把所有球员的进球数格式化成字符串。球员应按名字排序。

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. 合并多场比赛

实现`combineGames`函数，统计每位球员在两场比赛中的总进球数。

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
