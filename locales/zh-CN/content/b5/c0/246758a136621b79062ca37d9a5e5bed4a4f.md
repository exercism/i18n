# 简介

在 Common Lisp 中，函数的形参列表称为“lambda list”。
一个 lambda list 可以包含不同类型的形参。
这些不同的类型通过[“lambda list 关键字”][lambda-list-keyword]来指定，这类关键字都以 `&` 开头。
最常用的类型是可选形参、关键字形参和剩余形参。
在某个 lambda list 关键字之后的每个形参都属于该类型。
一个 lambda list 关键字在一个 lambda list 中只能使用一次。

lambda list 还用于其他结构，比如解构和宏，这些内容后面会讲到。
