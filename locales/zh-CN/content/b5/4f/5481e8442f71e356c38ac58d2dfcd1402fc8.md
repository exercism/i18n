# 简介

## 数组

JSON 将**数组**定义为：

> 数组是有序的值集合。
> 数组以左方括号`[`开头，以右方括号`]`结尾。
> 值之间用逗号`,`分隔。

数组可以包含零个或多个_任意类型_的 JSON 值。
数组元素不必都是同一类型。

### 创建数组

用方括号把元素收集到数组里。

```jq
[1, 2, 3]
```

把_流_用方括号括起来，就能把它的元素捕获成一个数组。

```jq
range(5)     # => a stream of 5 numbers
[range(5)]   # => the array [0, 1, 2, 3, 4]
```

### 大小

`length`函数返回数组中元素的个数。

### 下标与切片

数组下标从 0 开始计数。

用方括号表达式从数组中取出元素：`.[2]`获取第三个元素。

负数下标从数组末尾往前计数：`.[-1]`获取最后一个元素，`.[-2]`获取倒数第二个元素。

**切片**是数组的一个子序列。`.[10:15]`从下标 10 开始返回 5 个元素，结束下标_不包含_在内。

还有一些便捷函数：

- `first`获取第一个元素。
- `last`获取最后一个元素。
- `nth(n)`获取下标`n`处的元素。

### 迭代

`jq`提供了许多函数来满足常见的迭代需求：

- `map(expr)`返回一个新数组，把`expr`依次应用到每个元素上。

  ```jq
  [1, 2, 3] | map(. * 10)    # => [10, 20, 30]

  ```

- `select(expr)`是一个函数，会把`expr`应用到一个_单个值_上；如果表达式的结果为 true，就返回这个值；如果结果为 false，则_什么都不返回_，不是`null`，而是真的什么都没有。

  要把它应用到一个数组上，可以配合`map`使用。

  ```jq
  [range(10)] | map(select(. % 2 == 0))    # => [0, 2, 4, 6, 8]
  ```

  另一种做法是把`select`应用到_流_上，再收集结果。

  ```jq
  [range(10) | select(. % 2 == 0)]    # => [0, 2, 4, 6, 8]
  ```

- `any(condition)`和`all(condition)`返回一个布尔值，表示数组中是否有任一元素满足条件，或是否所有元素都满足条件。

  ```jq
  [1, 2, 3, 4] | any(. > 4)    # false
  [1, 2, 3, 4] | any(. >= 4)   # true

  [1, 2, 3, 4] | all(. >= 4)   # false
  [1, 2, 3, 4] | all(. <= 4)   # true
  ```
