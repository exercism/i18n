# 简介

TypeScript 是带有类型语法的 JavaScript，因此是一门强类型编程语言。它支持面向对象、命令式和声明式（例如函数式编程）风格，让你在任何规模下都能获得更好的工具支持。

因为[不学习 JavaScript 就无法学会 TypeScript][handbook-js-or-ts]，本轨道中的部分内容侧重讲解 JavaScript 概念，另一部分概念则只关注 TypeScript 特有的功能。

## （重新）赋值

在 TypeScript 中，给名字赋值主要有几种方式：使用变量或常量。在 Exercism 上，变量一律使用[camelCase][wiki-camel-case]书写，常量使用[SCREAMING_SNAKE_CASE][wiki-snake-case]书写。没有官方指南可循，不同的公司和组织有不同的风格指南。_变量怎么写都可以，随你喜好。_按照练习准备的方式书写变量，好处是它们在网页界面和大多数 IDE 中会有不同的高亮显示。

在 TypeScript 中，可以用`const`、`let`或`var`关键字来定义变量。

使用`let`或`var`时，变量在其生命周期内可以引用不同的值。例如，借助赋值运算符`=`，可以多次定义和重新定义`myFirstVariable`：

```typescript
let myFirstVariable = 1
myFirstVariable = 0
myFirstVariable = 42
```

与`let`和`var`不同，用`const`定义的变量只能赋值一次。在 TypeScript 中，常量就是这样定义的。

```typescript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

由于 TypeScript 能在静态阶段检测到这一点，TypeScript 编译器也会报错：

```typescript
// ^? Cannot assign to 'MY_FIRST_CONSTANT' because it is a constant.(2588)
```

这意味着你无需运行代码，就能发现这个`TypeError`。

## 类型推断

这里不深入探讨[类型推断][handbook-type-inference]这个话题，但你应该知道：即使没有类型注解，被赋值的变量通常也有一个推断出来的类型。

```typescript
const MY_FIRST_CONSTANT = 10
// ^? const MY_FIRST_CONSTANT: number
```

这个类型随后会在整个代码中强制执行。这也意味着，下面这段代码在 JavaScript 中是合法的：

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
```

但在 TypeScript 中就会报错：

```typescript
let myFirstVariable = 1
myFirstVariable = 'Some string'
// ^? Type 'string' is not assignable to type 'number'.(2322)
```

即使不使用类型注解，这一特性也能保证类型安全。

## 函数声明

在 TypeScript 中，功能单元被封装在_函数_里；如果几个函数属于同一组，通常会把它们放在同一个文件中。函数可以接收形参（实参），并可以用`return`关键字_返回_一个值。函数通过`()`语法来调用。

```typescript
function add(num1: number, num2: number): number {
  return num1 + num2
}

add(1, 3)
// => 4
```

函数形参通常应该标注类型，写法是冒号（`:`）后跟类型。函数返回值可以在形参列表结束后标注类型，写法同样是冒号（`:`）后跟类型。

## 类型注解

正如`add`的函数声明所示，形参带有显式的类型注解`: number`。变量声明、类属性、函数声明等都可以使用类型注解。

无论是显式的类型注解还是推断出来的类型，类型检查器都会强制执行。

```typescript
add('foo', 3)
// ^? Argument of type 'string' is not assignable to parameter of type 'number'.(2345)
```

## 暴露给其他文件

要让一个`function`、常量或变量在_其他文件_中可用，需要用`export`关键字把它们[导出][mdn-export]。之后另一个文件就可以用`import`关键字[导入][mdn-import]它们。这也称为模块系统。

所有测试的工作方式就是一个很好的例子。每个练习至少有一个文件，例如`lasagna.ts`，其中包含_实现_。此外，至少还有另一个文件，例如`lasagna.test.ts`，其中包含_测试_。这个文件会_导入_公开的（即导出的）实体，以便测试实现：

```typescript
// file.ts
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.test.ts
import { MY_VALUE, add } from './file.js'

add(MY_VALUE, 5)
// => 15
```
