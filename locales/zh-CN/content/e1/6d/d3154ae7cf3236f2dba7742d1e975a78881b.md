# 测试

进入包含相应`${slug}_test.sql`文件的目录，其中`${slug}`是练习的名称：用连字符代替空格，并且全部小写（例如`Hello World`练习对应的文件是`hello-world_test.sql`）。

```bash
sqlite3 -bail < ${slug}_test.sql
```

你可以使用`SELECT`语句来调试。
如果测试失败，输出会被转发到`user_output.md`，并显示在在线编辑器中。

更多信息请参见 [SQLite 的测试文档](https://exercism.org/docs/tracks/sqlite/tests)。
