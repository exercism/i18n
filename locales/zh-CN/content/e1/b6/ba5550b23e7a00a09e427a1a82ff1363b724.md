# 介绍

## 数字

Go 提供了一些基本的数字类型，用来表示整数或浮点数的集合。
你需要哪种类型，取决于你要表示的数值大小，以及程序运行所在计算机的架构（例如 32 位和 64 位）。

在本次练习中，你只需要接触以下几种：

- `int`：例如 `0`、`255`、`2147483647`。
  一个有符号整数，大小至少为 32 位（取值范围：-2147483648 到 2147483647）。
  但这取决于系统的架构。
  大多数现代计算机都是 64 位的，因此 `int` 的大小为 64 位（取值范围：-9223372036854775808 到 9223372036854775807）。

- `float64`：例如 `0.0`、`3.14`。
  包含所有 64 位浮点数。

- `uint`：例如 `0`、`255`。
  一个无符号整数，大小与 `int` 相同（取值范围：32 位时为 0 到 4294967295，64 位时为 0 到 18446744073709551615）

数字可以通过类型转换转换为其他数字类型。

## 算术运算符

Go 支持许多标准的算术运算符：

| 运算符 | 示例           |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

对于整数除法，余数会被舍去（例如 `5 / 2 == 2`）。

Go 为上述运算符提供了简写赋值形式（例如 `a += 5` 是 `a = a + 5` 的简写）。
Go 还支持自增和自减语句 `++` 和 `--`（例如 `a++`）。

## 在类型之间转换

类型之间的转换通过一个函数完成，该函数的名称就是你要转换到的类型名。
例如：

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## 对不同类型进行算术运算

在许多语言中，你可以对不同类型的变量进行算术运算，但在 Go 中这会报错。
例如：

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
