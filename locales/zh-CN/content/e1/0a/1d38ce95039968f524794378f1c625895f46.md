# 说明

在本练习中，你将编写代码，帮助一家标牌公司为其标牌创建自定义消息。

## 1. 制作场合标牌

实现方法`build_sign( )`，它接受一个字符串作为`occasion`形参，以及一个保存某人姓名的字符串作为`name`形参。这两个形参会被嵌入字符串模板，以输出标牌上的消息。

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. 制作生日标牌

实现方法`build_birthday_sign( )`，它接受一个年龄，并根据年龄决定标牌上的部分消息。如果年龄为 50 或更大，标牌将包含 _mature_ 一词，否则标牌将包含 _young_ 一词。

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. 制作毕业标牌

实现方法`graduation_for( )`，它接受一个字符串形参作为姓名，一个数值形参作为年份，并使用字符串模板创建标牌上的短语，该短语用换行符分隔消息的两行。

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. 计算标牌成本

实现函数`cost_of( sign currency )`，它接受一个保存标牌内容的字符串和一个表示货币的字符串。
标牌的基础价格为 20，以给定货币计。此外，每个字母花费 2。（空白字符也计入计算。）
返回的短语包含制作标牌的成本，保留小数点后两位，后面跟着货币字符串。

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
