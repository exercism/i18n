# 关于

[`while`循环][while-loops]是一种控制流语句，它允许在某个条件为 true 时执行代码。

Swift 提供了两种循环：`while`循环和`repeat-while`循环。

`while`循环的条件在循环体执行之前求值；如果条件为 false，循环体根本不会执行。

Swift 中的 `while`循环结构如下：

```swift
while <#condition#> {
  <#code#>
}
```

这里，只要 count 大于 0，循环就会一直执行，从而打印出数字 2、1 和 "Liftoff!"。

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

[`repeat-while`循环][while-loops]与 `while`循环类似，但条件是在循环体执行之后才求值。

这意味着，即使条件为 false，循环体也总是至少执行一次。

Swift 中的 `repeat-while`循环结构如下：

```swift
repeat {
  <#code#>
} while <#condition#>
```

这里，由于条件为 false，循环只会执行一次。
因为它是 `repeat-while`循环，所以循环体会在条件求值之前先执行一次。

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
