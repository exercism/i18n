# 关于

## 通用语法

`for` 循环是用于重复执行某些逻辑的最常用语句之一。
在 Go 中，它由 `for` 关键字、一个头部，以及一段用花括号包裹、包含循环体的代码块组成。
头部由 3 个用分号`;`分隔的部分组成：初始化、条件和后置。

```go
for init; condition; post {
  // loop body - code that is executed repeatedly as long as the condition is true
}
```

- **初始化**部分是一些只在循环开始前运行一次的代码。
- **条件**部分必须是某个求值为布尔值的表达式，用来控制循环何时停止。
  只要这个条件求值为 true，循环里的代码就会运行。
  一旦这个表达式求值为 false，循环就不会再进行任何迭代。
- **后置**部分是在每次迭代结束时运行的一些代码。

**注意：** 与其他语言不同，头部的这三个部分外面没有括号`()`。
事实上，加上这样的括号会导致编译错误。
不过，包裹循环体的花括号`{ }`始终是必需的。

## `for` 循环：一个示例

初始化部分通常用来设置一个计数器变量，条件部分检查循环应当继续还是停止，后置部分通常让计数器在每次重复结束时自增。

```go
for i := 1; i < 10; i++ {
  fmt.Println(i)
}
```

这个循环会打印从`1`到`9`（包括`9`）的数字。
定义步长通常用自增或自减语句来实现，就像上面的示例那样。

## 头部的可选部分

头部的初始化和后置部分是可选的：

```go
var sum = 1
for sum < 1000 {
	sum += sum
}
fmt.Println(sum)
// Output: 1024
```

像上面这样在 `for` 循环中省略初始化和后置部分，你就创建了一个 Go 中的 `while` 循环。
Go 里没有 `while` 关键字。
这体现了 Go 的一条原则：概念应当彼此正交。
既然已经有一个概念能实现 `while` 循环的行为，也就是 `for` 循环，就没有必要把 `while` 作为额外的概念再加进来。

## `break` 和 `continue`

在循环体里，你可以用 `break` 关键字彻底停止循环的执行：

```go
for n := 0; n <= 5; n++ {
  if n == 3 {
    break
  }
  fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

相反，`continue` 关键字只停止当前这一次迭代的执行，然后继续下一次迭代：

```go
for n := 0; n <= 5; n++ {
  if n%2 == 0 {
    continue
  }
  fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

## 无限 `for` 循环

循环头部的条件部分也是可选的。
事实上，你可以写一个没有头部的循环：

```go
for {
  // Endless loop...
}
```

这个循环只有在程序退出，或者循环体里有 `break` 时才会结束。

## 标签和 `goto`

当我们使用 `break` 时，Go 会停止最内层的循环。
同样地，当我们使用 `continue` 时，Go 会运行最内层循环的下一次迭代。

不过，这并不总是我们想要的。
我们可以把标签与 `break` 和 `continue` 一起使用，来分别精确指定我们想从哪个循环退出、或继续哪个循环。

在这个示例中，我们创建了一个标签 `OuterLoop`，它指向最外层的循环。
在最内层的循环里，要表示想从最外层循环退出，我们就在 `break` 后面跟上最外层循环的标签名：

```go
OuterLoop:
    for i := 0; i < 10; i++ {
        for j := 0; j < 10; j++ {
            // ...
            break OuterLoop
        }
    }
```

把标签和 `continue` 一起用也可以，这种情况下，Go 会继续执行标签所指向的那个循环的下一次迭代。

Go 还有一个 `goto` 关键字，用法类似，让我们可以从一处代码跳转到另一处带标签的代码。

**警告：** 尽管 Go 允许跳转到用标签标记的代码位置，但使用这个语言特性很容易让代码变得非常难以阅读。
因此，通常不建议使用标签。
