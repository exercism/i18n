# 介绍

命名空间是组织代码的一种重要方式。
两个函数可能会发生命名冲突，把它们放进不同的命名空间就能解决。
命名空间还可以嵌套，这有助于组织大型代码库。
通过作用域解析运算符`::`来访问命名空间。

下面的例子展示了两个不同的 `foo` 函数。
分别给它们加上各自的命名空间前缀，就可以一起使用。

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
