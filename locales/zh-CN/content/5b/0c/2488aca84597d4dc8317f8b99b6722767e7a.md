# 添加初始练习

实现`hello-world`练习之后，下一步就是再实现 20 多个练习。

## 练习类型

你可以实现两种类型的练习：

- 概念练习：用于向学生教授一个或多个概念。更多信息请查看[文档](/docs/building/tracks/concept-exercises)。
- 实践练习：用于练习已经学过的概念。更多信息请查看[文档](/docs/building/tracks/practice-exercises)。

一般来说，我们建议新的学习路径先实现实践练习，因为它们更容易实现，前期也不需要太多思考。
等你的学习路径顺利运行起来之后，随时可以再添加概念练习。

## 选择练习

为了帮助各条学习路径实现实践练习，我们创建了 [exercism/problem-specifications 代码仓库](https://github.com/exercism/problem-specifications)。
这个代码仓库包含 [100 多个实践练习的元数据](https://github.com/exercism/problem-specifications/tree/main/exercises)，不同的学习路径可以用它来实现各自版本的这些练习。
因此，你会发现许多不同的学习路径都实现了相同的练习。

那么，如何从这 100 多个练习中选出 20 多个呢？
下面是一些建议。

### 选择能让学生练习多种概念的练习

这 100 多个练习涉及的概念非常多样。
你应该尽量实现能让学生练习多种概念的练习。
所以，与其实现 20 个都围绕字符串的练习，不如实现关注不同概念的练习。

### 选择难度各异的练习

有些练习实现起来会比其他的更难。
你应该尽量选择难度不同的练习：有简单的，有中等难度的，也有困难的。

一个练习有多难取决于几个因素，比如涉及的概念以及学习路径所用的语言。
看看其他已经实现该练习的学习路径是怎么做的，能帮你更好地感受实现大概是什么样子。

下面是一些难度及对应的练习：

| 难度   | 练习                                                                                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 简单         | [darts][darts]、[gigasecond][gigasecond]、[isogram][isogram]、[leap][leap]、[resistor-color][resistor-color]、[space-age][space-age]                           |
| 中等 | [allergies][allergies]、[bob][bob]、[meetup][meetup]、[protein-translation][protein-translation]、[raindrops][raindrops]、[secret-handshake][secret-handshake] |
| 困难         | [alphametics][alphametics]、[forth][forth]、[react]、[pov][pov]、[zebra-puzzle][zebra-puzzle]、[zipper][zipper]                                                |

### 选择适合你的学习路径的练习

并不是所有练习都适合你的学习路径。
你应该只选择适合自己学习路径的练习；与其实现一个说不通的练习，不如干脆_不_实现。
举个例子，[lens-person 练习](https://github.com/exercism/problem-specifications/tree/main/exercises/lens-person)让学生使用_透镜_，而很多语言并不支持。

如果你发现某个练习不适合你的学习路径，可以把它的 slug 添加到[学习路径的 config.json 文件](/docs/building/tracks/config-json)中的 `exercises.foregone` 数组里。
这样，工具就会忽略这个练习。
