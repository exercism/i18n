# 简介

Factor 是一门*串接式*语言：每个单词都从共享的**数据栈**中读取输入，再把输出压回同一个栈。除此之外，没有别的方式传递值。

写下一个字面量，就会把它压入栈顶；代码从左到右依次读取：

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

*栈效应*声明记录了一个单词的契约：

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )`表示这个单词弹出两个值，再以相反的顺序把两个值留在栈上。那些名字只是文档，编译器只检查输入和输出的*数量*，而栈顶对应的是最右边的名字。

日常使用的`kernel`**重排单词**用来调整栈顶元素的顺序：

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

单词用`:`定义，以`;`结束；如果定义体与声明的栈效应不匹配，编译器会拒绝这条定义。
