# 简介

Factor 用 [`calendar`][calendar] 词库来对日期和时间建模。时间上的一个点就是 `timestamp`，一段时间的跨度则是 `duration`。

## 构造日期

`<date>`（位于 [`calendar`][calendar] 中）会在给定日期当天的午夜构造出一个 `timestamp`：

```
<date> ( year month day -- timestamp )
```

```factor
USING: calendar ;

1904 11 16 <date> .
! a timestamp at midnight on 1904-11-16
```

`>date<` 会把一个 `timestamp` 重新拆分成它的各个部分：

```
>date< ( timestamp -- year month day )
```

```factor
1904 11 16 <date> >date< .   ! => 16   (with 1904 and 11 below it)
```

## 查看日期

`day-of-week` 以整数形式返回星期几，`0` 表示星期日，一直到 `6` 表示星期六。`day-names`（位于 [`calendar.english`][english] 中）是与之对应的名字数组，因此 `day-names nth` 能把数字变成对应的单词：

```factor
USING: calendar calendar.english sequences ;

2024 1 8 <date> day-of-week .          ! => 1
day-names .   ! { "Sunday" "Monday" ... "Saturday" } — Sunday first
```

`leap-year?` 接受一个年份（或一个 `timestamp`），而 `days-in-month` 返回某个 `timestamp` 所在月份的长度，并且已经考虑了闰年：

```
leap-year?    ( obj -- ? )
days-in-month ( timestamp -- n )
```

```factor
2024 leap-year? .                ! => t
2024 2 1 <date> days-in-month .  ! => 29
```

## 日期运算

像 `days`、`weeks` 和 `hours` 这样的词会构造出一个 `duration`，而 `time+` 会把一个 `timestamp` 平移一段 `duration`：

```
days  ( x -- duration )
time+ ( timestamp duration -- timestamp )
```

```factor
2024 2 28 <date> 1 days time+ >date< .
! => 29   (2024-02-29, with 2024 and 2 below it)
```

运算能正确地跨越月份和年份的边界进位，而指向同一时刻的两个 `timestamp` 用 `=` 比较时是相等的。

## 一天中的时刻

`<timestamp>` 会构造一个完整的 `timestamp`，精确到秒。它的最后一个实参是与 UTC 的偏移量；`instant`（一个零长度的 `duration`）会让 `timestamp` 保持在 UTC：

```
<timestamp> ( year month day hour minute second gmt-offset -- timestamp )
```

```factor
USING: calendar ;

1969 7 21 2 56 15 instant <timestamp> .
! a timestamp at 02:56:15 on 1969-07-21
```

`>time<` 与 `>date<` 相对应，它把一个 `timestamp` 拆分成小时、分钟和秒：

```
>time< ( timestamp -- hour minute second )
```

```factor
1969 7 21 2 56 15 instant <timestamp> >time< .   ! => 15   (with 2 and 56 below it)
```

`seconds` 和 `minutes` 跟 `days`、`weeks`、`hours` 一样，都能构造出 `duration`，所以其中任何一个都能传给 `time+`：

```
seconds ( x -- duration )
minutes ( x -- duration )
```

`timestamp` 的各个字段可以用访问器 `year>>`、`month>>`、`day>>`、`hour>>`、`minute>>` 和 `second>>` 读取：

```factor
1969 7 21 2 56 15 instant <timestamp> hour>> .   ! => 2
```
