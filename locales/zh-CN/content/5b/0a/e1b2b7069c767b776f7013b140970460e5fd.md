# 关于

在 Haxe 中，`class`是主要的数据结构，它封装了数据（字段）和行为（方法）。字段和方法也称为类的成员。

可以使用[访问修饰符][visibility]来限制对成员的访问，这些修饰符包括：

- `public`：成员可以从任何地方访问。
- `private`：成员只能由同一个类访问。

类可以被视为创建实例的模板。要创建[实例][class-instance]，只需使用`new`关键字：

```haxe
class Car {
  public function new() {}
}

var myCar = new Car();
var yourCar = new Car();
```

要定义字段，请使用访问修饰符，后跟变量名和类型：

```haxe
class Car {
  public var weight:Int; // Accessable by anyone

  private var color:String; // Accessable only within this class
}
```

定义字段时，还可以设置初始值。如果字段未指定初始值，它将取值为`null`。可以使用点表示法访问字段：

```haxe
class Car {
  public var weight:Int = 2500; // Weight will be set to 2500
  public var year:Int; // year will be null

  public function new() {}
}

var newCar = new Car();
newCar.weight; // 2500
newCar.year; // null

// Update value of field
newCar.year = 2020;
```
