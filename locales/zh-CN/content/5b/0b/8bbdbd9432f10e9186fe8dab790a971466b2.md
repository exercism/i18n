# 说明

柏林的新机场为他们的机器人实验室招聘了开发者，你就要去那里开始工作了。
他们有一些笨重、外表有点像人的机器人，正试着用它们来改善客户服务。

你上班后的第一个任务是编写一个程序，让机器人在人们在自助值机柜台扫描护照后，能用他们的母语向人们问好。

机器人对自己的本领很自豪，所以它总是先说自己会说哪种语言，然后再向对方问好。
例如，如果有人扫描了一本德国护照，机器人会说：

```txt
I can speak German: Hallo Dietrich!
```

## 1. 创建抽象的问候功能

你不会亲自为各种语言编写代码，所以需要把机器人的代码组织好，让其他开发者日后能轻松添加更多语言。

第一步，定义一个包含两个方法的接口`Greeter`。

- `LanguageName`：返回机器人应当用来问候访客的语言名称（一个`string`）。
- `Greet`：接受访客的名字（一个`string`），并返回一个`string`，内容是某种特定语言的问候语。

接下来，实现一个函数`SayHello`，它接受访客的名字以及任何实现了`Greeter`接口的东西作为参数，并返回所需的问候字符串。
例如，假设有一个德语的`Greeter`实现，它的`LanguageName`返回`"German"`，`Greet`返回`"Hallo {name}!"`：

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. 实现意大利语

现在你的任务是让机器人也能为扫描意大利护照的人服务。

为此，创建一个结构体`Italian`，并实现两个方法，让该结构体满足你在任务 1 中建立的`Greeter`接口。
你可以用`"Ciao {name}!"`向人打招呼。

## 3. 实现葡萄牙语

在收工之前，你还应该完成用葡萄牙语问候别人的功能。

为此，创建一个结构体`Portuguese`，同样实现两个方法，让该结构体满足这里的`Greeter`接口。
你可以用`"Olá {name}!"`向人打招呼。
