# 提示

## 通用

- 阅读官方指南中关于[模式匹配][pattern-matching]的内容。
- 看看这份关于[解构][destructuring]的速查表。
- 关于记录的模式匹配，[这里][records-pattern-matching]有更详细的讲解。

## 1. 检测空评论

- 如果参数是一个元组，你可以直接在函数参数中使用`(a, b)`。
- 对于接收到但不使用的值，可以用通配符`_`代替。
- 要检查字符串是否为空，请查看[`String`文档][string-docs]。

## 2. 统计创建者发表的评论数

- 对于只有一个变体的自定义类型`type Box = Box AB`，你可以像这样直接在函数参数中解构：`(Box ab)`。
- 可以用`{ a }`对记录`{a : A, b : B}`的字段`a`进行模式匹配。
- 对于包含记录的自定义类型，你可以同时使用上面这两种技巧。
- 你无法直接对记录`{ ab : (A, B) }`中的元组`ab`进行模式匹配。必须先匹配`{ ab }`，然后在`let`绑定中使用`( a, b) = ab`。
- 要找出列表中满足某个条件的元素个数，请使用[`List`函数][list-docs]。
- 你也可以直接在匿名函数的参数中解构元组。

## 3. 检测分配给开发团队的工单

- 和第 2 题一样，你可以在函数参数中匹配被“装箱”的记录的相关字段。
- 你可以用模式匹配递归地匹配像`Just (Box "42")`这样的嵌套值。
- 在`case`语句中，你可以用通配符`_`匹配任何内容。

## 4. 把工单分配给 IT 员工

- 和第 2、3 题一样，你可以在函数参数中匹配被“装箱”的记录的相关字段。
- 此外，你还可以使用`as`关键字来匹配某个字段，同时绑定整个记录：`(Box ({ a } as ab))`。
- 你可以用`case`语句对自定义类型的值进行模式匹配。
- 使用类型构造器`Ticket`返回一张工单。
- 使用[记录更新语法][record-update]来修改记录。
