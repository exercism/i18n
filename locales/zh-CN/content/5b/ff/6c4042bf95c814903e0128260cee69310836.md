# 简介

## 常量与函数

常量值用`name = expression`定义。在 Elm 中，除了定义以外，其余一切都是表达式。

```elm
five = 5

six = 3 + 3
```

函数用`name parameters... = expression`定义，各个形参之间只用空格分隔。

```elm
add number1 number2 = number1 + number2
```

调用函数同样是一个表达式：写出函数名，并为函数的每个形参传入实参，之间用空格分隔，和定义函数时一样。

```elm
five = add 2 3
```

可以用括号来指定表达式的求值顺序。

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 缩进 / 有意义的空白

Elm 不使用大括号、圆括号或分号这类语法标记来界定代码的边界，而是使用空白和缩进。

- 模块、导入和顶层函数定义必须从最左侧那一列开始。
- 如果表达式被拆分成多行，那么属于该表达式的代码必须在它下面缩进至少 1 个空格。
- 表达式中归为一组的部分，应当缩进相同数量的空格。

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## 模块

Elm 中的每个文件都是一个模块，并且必须在所有其他代码之前包含一条`module`语句。模块名必须与文件名一致，因此模块`Calculator`必须位于文件 Calculator.elm 中。模块内定义的所有内容，其作用域都是该模块私有的，除非在`exposing`中列出，否则无法从该模块外部访问。

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## 注释

注释是 Elm 文件中不会被当作代码解释的一段文本，主要是写给你自己和其他程序员看的。单行注释有一种基于两个连字符的轻量语法。多行注释也可以用一对起止定界符`{-`和`-}`来写。

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
