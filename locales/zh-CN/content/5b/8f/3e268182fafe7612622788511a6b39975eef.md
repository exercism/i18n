你将创建一些可以移动、可以调整大小的窗口。

## 1. 定义程序窗口的属性

使用提供的类骨架，为`y`、`x`、`height`和`width`这几个值提供属性。

```php
<?php

$window = new ProgramWindow();
$window->y; // => null
$window->x; // => null
$window->height; // => null
$window->width; // => null
```

## 2. 定义程序窗口的初始值

为`ProgramWindow`定义一个构造函数。
它不应接收任何参数，但在构造函数执行期间要为其属性设置默认值。
它应将`y`和`x`的初始值设为`0`。
它应将初始的`height`和`width`设为`600x800`的屏幕尺寸。

```php
<?php

$window = new ProgramWindow();
$window->y; // => 0 
$window->x; // => 0
$window->height; // => 600
$window->width; // => 800
```

## 3. 定义一个用于调整窗口大小的函数

在`Size.php`中为 Size 类定义一个新类。
它的构造函数应接收参数，用来设置`height`和`width`属性。
此外，`ProgramWindow`还需要一个调整大小的函数，它接收`Size`对象实例并更新自己的属性。

```php
<?php 

$window = new ProgramWindow();
$size = new Size(764, 1080);
$window->resize($size)

$window->height;
// => 764
$window->width;
// => 1080
```

## 4. 定义一个用于移动窗口的函数

在`Position.php`中为 Position 类定义一个新类。
它的构造函数应接收参数，用来设置`y`和`x`属性。
此外，`ProgramWindow`还需要一个移动函数，它接收`Position`对象实例并更新自己的属性。

```php
<?php 

$window = new ProgramWindow();
$position = new Position(80, 313);
$window->move($position)

$window->y;
// => 80
$window->x;
// => 313
```
