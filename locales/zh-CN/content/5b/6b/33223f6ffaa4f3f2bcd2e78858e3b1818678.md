# 简介

PowerShell 是微软出品的一门动态、隐式类型的脚本语言（_同时也支持[强类型][strong typed]变量_），主要专注于任务自动化和配置管理。

PowerShell 支持命令式、函数式、面向对象，甚至管道风格的编程。

PowerShell 构建于 .NET 平台之上，于 2006 年首次发布。所有现代 Windows 操作系统都默认包含它，也可以安装在 Mac 和 Linux 上。


## 变量

在 PowerShell 中，定义变量有两种常见方式。

PowerShell 中的变量名必须以 `$` 开头，并使用赋值运算符 `=` 将变量名与值绑定。

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

如果你想强制要求值属于某种类型，也可以显式指定变量的类型。如果可能，PowerShell 会尽力将值从一种类型转换为另一种类型。

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```


### 常量

PowerShell 中的常量，是定义之后既不能**更改**也不能**删除**的变量。这引出了定义变量的第二种方式：使用 cmdlet `New-Variable`。

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
```

关于创建变量的更详细、更高级的方法，请阅读 [New-Variable][New-Variable]。


## 函数

PowerShell 中的[函数][functions]使用 `function` 关键字定义。每个函数可以在 `()` 括号中拥有零个或多个形参，随后是函数作用域，以 `{` 开始、以 `}` 结束。

```powershell
function Greeting {
    return "Hello!"
}
```

PowerShell 中的函数可以在使用语法 `FuncName $Arg` 调用之后，通过 `return` 关键字显式返回值。

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

如何编写详细的函数定义，以及函数如何隐式返回值，将在 `Functions` 概念模块中进一步介绍。


## 注释

PowerShell 中的单行注释以 `#` 开头，到行尾结束。PowerShell 中的注释块以 `<#` 开始，以 `#>` 结束。使用注释块创建基于注释的帮助的高级示例，将在 `Functions` 概念模块中介绍。

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
