# 简介

## 嵌套类型

C# 类型可以定义在类或结构体的作用域内。外层类型提供了一种命名空间。访问该类型需要通过外层类型，并使用点语法。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

你可以为内部类型设置访问级别。

外层类型的私有成员位于内部类型成员的作用域内，反之则不然。
