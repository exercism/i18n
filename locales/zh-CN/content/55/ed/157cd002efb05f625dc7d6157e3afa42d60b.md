# 说明

帕勒莫港是一个繁忙的港口，船只来来往往。长期以来，它一直靠一套人工系统来记录当前停靠在港内的船只。这套系统非常容易出错，于是港务长决定用一套计算机化的系统来取代它。

港务长雇请你来实现这套新系统。这套系统既要处理船只的标识符，也要处理目的地的标识符。

## 1. 创建港口的标识符

你首先要做的，是为帕勒莫港创建标识符。标识符是港口名称的前四个字母，并且要大写。

定义`Port::IDENTIFIER`常量，让它成为一个值为`:PALE`的符号。
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. 获取其他港口的标识符

程序还需要处理其他港口，所以你也得为它们创建标识符。港口希望这套系统能自动运行，而由于各个港口的命名习惯不同，标识符应当根据港口的名称生成。标识符是港口名称的前四个字母，并且要大写。

定义`Port.get_identifier`方法，让它接收一个字符串作为实参，并以符号的形式返回该港口的标识符。

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. 判断船只应该停靠在哪个码头

港口有两个码头，系统需要判断船只应该停靠在哪个码头。停靠哪个码头由船只的标识符决定。

标识符由 2 个部分组成：第一部分是 3 个大写字母，表示船上装载的是哪种货物；然后是 3 个数字，也就是这艘船的唯一标识符。

如果船只标识符中表示货物的部分是**OIL**或**GAS**，船只应停靠在**A**码头。否则船只应停靠在**B**码头。

定义`Port.get_terminal`方法，让它接收一个符号作为实参，也就是船只的标识符。该方法应以符号的形式返回码头。

```ruby
Port.get_terminal(:OIL123)
# => :A
```
