# 简介

在 Kotlin 中，可以用类来封装数据和行为。
使用 `class` 关键字声明类。
例如：

```kotlin
class Car
```

调用类即可创建它的实例。

```kotlin
val instance = Car()
```

## 属性

在上面的例子中，`Car` 类没有声明任何属性。
类的属性可以声明在类体中，也就是 `{}` 之间：可变的属性用 `var`，不可变的属性用 `val`。
例如：

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

另一种做法是在构造函数中定义属性，让构造函数接收这些属性。

## 构造函数

Kotlin 有两种构造函数：[主构造函数][primary-constructors]和[次级构造函数][secondary-constructors]。
主构造函数与类声明写在同一行。
例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

如果没有注解，也没有可见性修饰符，就可以省略 `constructor` 关键字：

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
如果类体中只有属性，Kotlin 允许定义类时省略大括号 `{}`：

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

一个类只能有一个主构造函数。
次级构造函数是额外的构造函数，可以用 `constructor` 关键字在类体中声明。
例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

次级构造函数必须通过调用 `this` 来调用主构造函数。

## 初始化块

主构造函数负责设置类的属性。
如果创建对象时还需要做更多事情，可以用 `init` 块执行额外的操作。

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## 函数

函数可以定义在类体中。
例如：

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## 可见性

属性可以是 `private`、`public`、`internal` 或 `protected`，函数也一样。

- `private`：只能在类内部访问
- `protected`：类内部以及任何子类都可以访问
- `internal`：同一个[模块][kotlin-modules]内部都可以访问
- `public`：使用该类的其他组件都可以访问

例如：

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```

[primary-constructors]: https://kotlinlang.org/docs/classes.html#primary-constructor
[secondary-constructors]: https://kotlinlang.org/docs/classes.html#secondary-constructors
