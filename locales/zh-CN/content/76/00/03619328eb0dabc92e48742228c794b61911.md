# 简介

在 Common Lisp 中，字符串是由[字符][concept-characters]组成的[向量][concept-vectors]。字符串的写法就是把字符用双引号括起来（例如 "Hello World!"）。

`stringp`谓词只有在给定的值是字符串时才会返回 true。

可以用`subseq`函数把字符串拆分成子字符串，它接受一个字符串、一个起始下标，以及一个可选的结束下标。下标从 0 开始。

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

可以用`string=`比较字符串是否相等。如果需要忽略字符的大小写，可以用`string-equal`。

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

把字符串转换为大写、小写或首字母大写等操作，可以分别用`string-upcase`、`string-downcase`和`string-capitalize`完成。

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
