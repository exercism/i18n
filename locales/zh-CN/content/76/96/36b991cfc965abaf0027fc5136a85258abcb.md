# 提示

## 通用

- 这三个任务都需要把日志行拆开。从 [`splitting`][splitting] 词汇表入手是个不错的起点。
- 至于去除空白的辅助函数，你需要 `ascii` 中的 `blank?` 和 [`sequences`][sequences] 中的 `trim`。

## 1. 从日志行中获取消息

- 用 `split1` 按 `": "` 切分这一行（栈效果为 `( seq subseq -- before after )`），丢弃前半部分，保留后半部分。`kernel` 中的 `nip ( x y -- y )` 会丢掉第二个值，所以 `split1 nip` 保留的是右半边。
- 用 `[ blank? ] trim` 去掉剩余内容里的空白。

## 2. 从日志行中获取日志级别

- 用 `"[]" split` 按方括号字符切分，会得到三段：`""`、日志级别，以及这一行剩下的内容。
- `harvest`（来自 [`sequences`][sequences]）会丢弃空的那一段。
- 取出剩下的第一个元素，对它调用 `>lower`。

## 3. 重新格式化日志行

- 复用 `message` 和 `log-level`。`kernel` 中的 `bi` 会对同一输入运行两个引用，并把两个结果都留在栈上。
- 用 `surround` 给日志级别加上括号。
- 用 `glue` 把消息和加了括号的日志级别连接起来，中间用一个空格作为分隔符。

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
[sequences]: https://docs.factorcode.org/content/vocab-sequences.html
