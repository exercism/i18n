# 关于

为了开启 C++ 之旅，我们先从变量、函数调用和注释开始。

## 注释

注释有两种：单行注释和多行注释。
同一行中`//`之后的所有内容都会被编译器忽略。
多行注释也叫 C 风格注释。
它们由`/*`和`*/`包围。
介于两者之间的内容也会被忽略。

## 变量

C++ 是一门类型化的语言。
所有类型都必须在编译期已知，而且通常需要显式地写出来。
变量的类型不能改变。
一个名为`years`的整数变量可以这样声明：

```cpp
int years;
```

在声明变量时就初始化它，是个好习惯。
C++ 提供了不同的机制来实现这一点。
使用花括号的写法更符合现代 C++，但使用等号的写法也很常见。

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ 确实允许使用未初始化的变量。
在变量被有意赋值之前，它的值是未定义的，可能包含任何内容。
为了避免“使用前未设置”的错误和未定义行为，最好**始终初始化**。
未定义行为可能在你最不希望的时刻让程序崩溃，而它之前一直运行得好好的。
再怎么强调也不为过：不惜一切代价避免未定义行为。
~~~~

## 算术运算

像`*`、`+`或`-`这样的算术运算符，可以出现在`3 * 2`或`tomatoes + potatoes`这样的表达式中。

## 更新变量

你可以重新给变量赋值，只要它们保持原有的类型：

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## 函数

函数有名字、返回类型以及（可能为空的）形参列表。
一个名为`always_fortyseven`、始终返回 47 的函数，大致长这样：

```cpp
int always_fortyseven() {
    return 47;
}
```

下面是`vip_fee`，它有一个形参：
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

还有`total_fee`，一个带 3 个形参、并且调用了另一个函数的函数。

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++ 中的函数不会像某些其他语言那样返回最后一条语句的值。
代码必须使用`return`关键字才能通过编译。

### 空白

空白用于格式化源代码，包括空格、制表符和换行符。
由于编译器会忽略多余的空白，你可以用它来组织代码的结构。
巧妙地使用空白可以提高代码的可读性。
存在不同的格式化标准，但它们都只是约定，编译器并不会强制执行。

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
