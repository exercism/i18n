# 介绍

JavaScript 是一门动态语言，支持面向对象、命令式和声明式（例如函数式编程）风格。

## （重新）赋值

在 JavaScript 中，给名字赋值主要有几种方式：使用变量或常量。在 Exercism 上，变量总是用 [camelCase][wiki-camel-case] 书写；常量用 [SCREAMING_SNAKE_CASE][wiki-snake-case] 书写。并没有必须遵循的官方指南，而且不同的公司和组织有不同的风格指南。_你可以随意按自己喜欢的方式命名变量_。按照练习准备的方式书写变量的好处是，它们在网页界面和大多数 IDE 中会有不同的高亮显示。

JavaScript 中的变量可以使用 [`const`][mdn-const]、[`let`][mdn-let] 或 [`var`][mdn-var] 关键字来定义。

使用`let`或`var`时，变量在其生命周期内可以引用不同的值。例如，使用赋值运算符`=`，`myFirstVariable`可以被多次定义和重新定义：

```javascript
let myFirstVariable = 1
myFirstVariable = 'Some string'
myFirstVariable = new SomeComplexClass()
```

与`let`和`var`不同，用`const`定义的变量只能被赋值一次。在 JavaScript 中，这被用来定义常量。

```javascript
const MY_FIRST_CONSTANT = 10

// Can not be re-assigned.
MY_FIRST_CONSTANT = 20
// => TypeError: Assignment to constant variable.
```

> 💡 在后面的一个概念练习中，会探讨并解释_常量_的赋值/绑定与_常量_的值之间的区别。

## 函数声明

在 JavaScript 中，功能单元被封装在_函数_里；如果某些函数属于同一组，通常会把它们放在同一个文件中。这些函数可以接收形参（实参），并可以使用`return`关键字_返回_一个值。函数通过`()`语法来调用。

```javascript
function add(num1, num2) {
  return num1 + num2
}

add(1, 3)
// => 4
```

> 💡 在 JavaScript 中，声明函数有_很多_不同的方式。这些其他方式看起来和使用`function`关键字不同。该 track 会尝试逐步介绍它们，但如果你已经了解它们，可以随意使用任何一种。在大多数情况下，用其中一种并不比另一种更好或更差。

## 暴露给其他文件

要让一个`function`、常量或变量在_其他文件_中可用，需要使用`export`关键字将它们[导出][mdn-export]。然后另一个文件可以使用`import`关键字[导入][mdn-import]这些内容。这也称为模块系统。一个很好的例子是所有测试的工作原理。每个练习至少有一个文件，例如`lasagna.js`，其中包含_实现_。此外还至少有一个其他文件，例如`lasagna.spec.js`，其中包含_测试_。这个文件会_导入_公开的（即导出的）实体，以便测试实现：

```javascript
// file.js
export const MY_VALUE = 10

export function add(num1, num2) {
  return num1 + num2
}

// file.spec.js
import { MY_VALUE, add } from './file'

add(MY_VALUE, 5)
// => 15
```
