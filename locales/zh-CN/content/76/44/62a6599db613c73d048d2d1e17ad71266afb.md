# 关于

`reduce`是 Factor 的通用折叠操作：它遍历一个序列，让累加器在一个二元 quotation 中传递，这个 quotation 接收当前的累加器和下一个元素，并产出新的累加器。

```
reduce ( seq init quot: ( prev elt -- next ) -- result )
```

```factor
USING: math sequences ;

{ 1 2 3 4 } 0 [ + ] reduce .         ! => 10
{ 1 2 3 4 } 1 [ * ] reduce .         ! => 24
```

自定义的初始值能让`reduce`表达出`sum`或`product`无法表达的折叠。例如，求序列中的最大值，并在每个元素都落败时准备一个默认值：

```factor
USING: math.order ;

{ 3 1 -4 5 -2 } 0 [ max ] reduce .   ! => 5
{ -3 -1 -4 }    0 [ max ] reduce .   ! => 0
```

初始值`0`也参与比较，所以全是负数的序列仍然会得到`0`，而不是它最小的那个值。

## `produce`：展开

`reduce`的对偶是`produce`（位于[`sequences`][sequences]中）：`reduce`*消耗*一个序列，`produce`则*生成*一个序列。一个谓词 quotation 检测当前的状态；只要它返回真值，主体 quotation 就产出下一个元素。

```
produce ( pred quot -- seq )
```

把两者一起使用，`reduce`和`produce`就构成了 Factor 的折叠/展开对。

## 累积归约

[`math.statistics`][math.statistics]中的累积函数族返回一个与输入等长的序列，其中每个元素都是到该位置（含该位置）为止的前缀上的归约结果：

| word          | running operation |
|---------------|-------------------|
| `cum-sum`     | running total      |
| `cum-product` | running product    |
| `cum-min`     | running minimum    |
| `cum-max`     | running maximum    |

```factor
USING: math.statistics ;

{ 3 1 4 1 5 9 2 6 } cum-sum .         ! => { 3 4 8 9 14 23 25 31 }
{ 3 1 4 1 5 9 2 6 } cum-min .         ! => { 3 1 1 1 1 1 1 1 }
{ 3 1 4 1 5 9 2 6 } cum-max .         ! => { 3 3 4 4 5 9 9 9 }
```

当你想要查看某个量在整个序列中*如何*变化，而不仅仅是它的最终值时，累积归约就很有用。把它们串联起来也很有用：一个累积操作的输出本身就是一个序列，可以直接喂给另一个累积操作。
