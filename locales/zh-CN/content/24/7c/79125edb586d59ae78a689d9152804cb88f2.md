# 关于

**浮点数**是一种可以带小数部分的数字，例如`-1.23`或`3.1415`。

为了把这样的数字表示成一个字节序列，x86-64 使用 [IEEE-754][ieee] 标准。这个标准中最常见的两种格式是单精度浮点数和双精度浮点数。x86-64 两种都支持。

单精度浮点数的宽度是 32 位，而双精度浮点数是 64 位。

## XMM 寄存器

在 x86-64 中，有 16 个专用于浮点运算的寄存器，名字从`xmm0`到`xmm15`。

这些寄存器至少宽 128 位，不过新一代处理器把这个宽度提高到 256 位或 512 位。但实际使用中，大多数浮点数只会用到最低的 32 位或 64 位，具体取决于所需的精度。

## 数字之间的转换

有一系列指令用于在不同数字格式之间转换：`cvtxx2yy`。

`xx`和`yy`都不是字面量，而是占位符：

- `xx`是源操作数类型的占位符。
- `yy`是目标操作数类型的占位符。

这种占位符有多种形式，其中包括：

| 占位符 | 含义 |
| ----------- | --------------------- |
| `si`        | 有符号整数        |
| `ss`        | 32 位浮点数 |
| `sd`        | 64 位浮点数 |

例如：

```x86asm
cvtsi2ss xmm0, eax ; converts a 32-bit signed integer to a single-precision floating-point
cvtsd2si rax, xmm1 ; converts a double-precision floating-point to a 64-bit signed integer
```

注意，可以把 32 位整数转换成 64 位浮点数，也可以把 64 位整数转换成 32 位浮点数。同样，也可以把 32 位浮点数转换成 64 位整数，或把 64 位浮点数转换成 32 位整数。换句话说，`cvtxx2yy`中两个操作数的大小_不必相同_：

```x86asm
cvtsi2sd xmm0, eax ; converts a 32-bit signed integer to a double-precision floating-point
cvtsi2ss xmm0, rax ; converts a 64-bit signed integer to a single-precision floating-point
cvtss2si rax, xmm0 ; converts a single-precision floating-point to a 64-bit signed integer
cvtsd2si eax, xmm0 ; converts a double-precision floating-point to a 32-bit signed integer
```

当浮点数无法精确表示为整数时，`cvtxx2si`会根据一个名为`mxcsr`的特殊寄存器中的舍入控制来对这个数字进行舍入。这可能是就近舍入、向下舍入、向上舍入或截断。函数入口处没有保证的默认值。

注意，精确的结果不会被舍入，因此也不受舍入控制的影响。例如，`42.0`_总是_会被转换成`42`。

还有一系列类似的指令，格式为`cvttxx2si`（多了一个`t`），它们总是截断结果。

## 舍入

`roundxx`系列指令把源操作数中的浮点数转换成舍入后的浮点数，并存放到目标操作数中。

这里，`xx`和往常一样是操作数类型的占位符：`ss`表示单精度，`sd`表示双精度浮点数。

这些指令把常数作为第三个操作数，这个数字表示舍入模式：

| 数字 | 模式         |
| :----- | :----------- |
| 0      | 就近      |
| 1      | 向下取整 |
| 2      | 向上取整    |
| 3      | 截断     |

例如：

```x86asm
roundss xmm0, xmm1, 1 ; this rounds down (takes the floor) a 32-bit floating-point in xmm1 and stores it in xmm0
roundsd xmm2, xmm2, 2 ; this rounds up (takes the ceil) a 64-bit floating-point in xmm2 and stores it in xmm2
```

由于这些指令产生的是精确结果，它们可以用来为`cvtxx2si`做准备。

## 算术指令

许多针对浮点数的运算，其指令名与对应的整数指令相似，只是在末尾加上了必要的占位符（`ss`或`sd`）。这些指令都是双操作数，语义与往常一样，即使是执行乘法或除法的指令也是如此：

```x86asm
addss xmm1, xmm2 ; xmm1 = xmm1 + xmm2 (all 32-bit floating-point)
mulsd xmm4, xmm5 ; xmm4 = xmm4 * xmm5 (all 64-bit floating-point)
divss xmm0, xmm3 ; xmm0 = xmm0 / xmm3 (all 32-bit floating-point)
```

## 移动

在 XMM 寄存器之间移动的指令是`movss`或`movsd`：

```x86asm
movss xmm1, xmm0 ; this copies a 32-bit floating-point from xmm0 to xmm1
movsd xmm6, xmm4 ; this copies a 64-bit floating-point from xmm4 to xmm6
```

**不能**把立即数（一个常数有符号整数）直接移动到 xmm 寄存器。这个数字需要先移动到一个通用寄存器，然后再用`cvtsi2xx`转换：

```x86asm
mov rax, 10        ; rax is a 64-bit integer with value 10
cvtsi2sd xmm0, rax ; xmm0 is a 64-bit floating-point with value 10.0
```

## 比较

有两组指令用于在两个浮点数之间进行比较，形式为`comixx`和`ucomixx`，其中`xx`是`ss`或`sd`。两者都会像往常一样设置`rflags`中的标志，语义与`cmp`相同。

它们的区别在于，如果两个浮点数中有一个是`NaN`值，`ucomixx`会设置`parity flag (PF)`，而`comixx`在这种情况下会抛出异常。

浮点数之间的比较是_无符号_的：

```x86asm
ucomisd xmm0, xmm1
ja .greater         ; 'ja' must be used for "greater", not 'jg'
jb .lesser          ; 'jb' must be used for "lesser", not 'jl'
```

## 其他指令

还有更多用于处理浮点数的指令，实现了常见的运算。其中一些是：

| 指令 | 说明                                      |
| :---------- | :----------------------------------------------- |
| `sqrtxx`    | 计算平方根（`sqrt(x)`）                 |
| `rcpss`     | 计算倒数（`1/x`）                      |
| `rsqrtss`   | 计算平方根的倒数（`1/sqrt(x)`） |
| `minxx`     | 计算最小值（`min(x, y)`）                   |
| `maxxx`     | 计算最大值（`max(x, y)`）                   |

凡是用到`xx`占位符的地方，它和往常一样可以是`ss`或`sd`。不过，`rcpss`和`rsqrtss`只能处理单精度浮点数。

这些指令都是双操作数。

## 调用约定

在 System V ABI 中，前八个浮点实参按顺序通过`xmm0`到`xmm7`传给函数。函数的浮点返回值放在`xmm0`中，必要时也放在`xmm1`中。

所有`xmm`寄存器都可以自由使用，没有哪一个是为调用者保留的。

## 内存

浮点值可以按照与同样大小的整数相同的语义在内存中定义。NASM（The Netwide Assembler，即本学习路径使用的汇编器）还允许以科学计数法声明浮点值。

```x86asm
section .data
    pi dq 3.141592653589793 ; this is a double-precision floating-point value
    exp_num dd 1.e5 ; this is a single precision floating-point value equal to 1 * 10⁵
    exp_num2 dd 1.e+5 ; this is a single precision floating-point value equal to 1 * 10⁵
    frac dq 1.e-10 ; this is a double precision floating-point value equal to 1 * 10⁻¹⁰, i.e., 0.0000000001
```

## AVX/AVX2

x86-64 架构的 AVX/AVX2 扩展为浮点指令引入了新的三操作数形式，把目标操作数与源操作数分开。它们带有一个`v`前缀（代表 _vector_），以区别于上面看到的旧式 SSE 形式：

```x86asm
vaddss xmm0, xmm1, xmm2 ; xmm0 = xmm1 + xmm2 (32-bit floating-point)
vmulsd xmm2, xmm3, xmm4 ; xmm2 = xmm3 * xmm4 (64-bit floating-point)
```

在本学习路径中，我们只使用到之前 SSE 扩展为止的指令和寄存器。这足以教授基础知识，并保证与各种 CPU 的兼容性。

不过，测试运行器完全支持 AVX 和 AVX2，你可以随意使用它们。
