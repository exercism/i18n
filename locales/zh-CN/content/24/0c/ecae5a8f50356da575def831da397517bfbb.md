# 简介

整数不仅可以视为数值，还可以视为位的模式。Factor 的`math`词汇表提供了针对这些位模式的标准底层操作，`math.bitwise`词汇表则补充了一些处理固定宽度数值的辅助工具。

## 位移

`shift ( m n -- m' )`把`m`的各位进行移位。`n`为*正数*时向左移位（每一步乘以 2）；`n`为*负数*时向右移位（每一步除以 2）：

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

对正整数来说，右移会把底部的位丢弃，并补零。对*负整数*来说，Factor 的`shift`是算术移位：它保留符号位，概念上从左侧填入符号位的副本。（Factor 的整数是任意精度的，所以“左侧”可以按需延伸。）

## 按位逻辑

四种基本逻辑运算如下：

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

对`0b1011`做`bitnot`的结果是`-12`，因为 Factor 的整数是任意精度的：把`0b1011`的各位取反，概念上就是“全是 1，而低四位翻转为`0100`”，把它按有符号大整数来读就是`-12`。

## 把一个值当作 N 位来处理

`math.bitwise`中的`bits ( x n -- y )`会把`x`掩码到它的低`n`位。这就是 Factor 中“把一个值重新解释为 N 位无符号整数”的做法：

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

第二个例子对这道练习很重要。如果你手上有一个负的二进制补码 Int32 值，想把它“逻辑”右移（从左侧补零）`amount`位，Factor 的习惯写法是：

```
( value -- shifted )
32 bits  amount neg  shift
```

先掩码到 32 位，切换到无符号解释，然后再移位。由于掩码后的值是非负的，`shift`只是把底部的位丢弃，并用零补齐。
