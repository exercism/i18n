# 说明

Larry 是一个 Lisp 外星人，喜欢写代码玩游戏。
今天，他们想写几个函数，帮自己完成一个很像井字棋的游戏。

和井字棋一样，这个游戏也在一个 3x3 的棋盘上进行。

## 1. 从零开始

首先，Larry 需要一个用来生成空白棋盘的函数 `make-empty-board`。
棋盘上所有格子的值都应该是 `NIL`。

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. 从已有的棋盘开始

接下来，Larry 需要一个能根据一组行来生成棋盘的函数。
例如：

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. 获胜条件

如果某一行里出现了 3 个相同的符号，那么该玩家就赢了。
Larry 需要一个函数 `all-the-same-p`：它接收一个包含 3 个元素的数组，如果所有元素都是同一个符号，就求值为 `T`。
（可以用 `eq` 判断两个符号是否相同。）

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. 取一行

现在，Larry 需要一种获取一行元素的方法。
函数 `row` 接收一个棋盘和一个行号，返回该行元素组成的数组。

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. 取一列

最后，Larry 需要一种获取一列元素的方法。
函数 `column` 接收一个棋盘和一个列号，返回该列元素组成的数组。

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
