# 简介

动态内存由库函数实现，程序员用它们在运行时分配和释放内存。既然内存的分配和释放都由程序员控制，动态内存的安全性就完全取决于程序员会不会犯人为错误。因此，动态内存是编程 bug 的主要来源之一，也是黑客攻击的主要目标。

## malloc

`malloc`是声明在`stdlib.h`中的一个函数，用来分配动态内存。如果分配成功，会返回一个指针，指向所分配内存第一个字节的地址。如果分配失败，则返回`NULL`。检查`malloc`的返回值是否为`NULL`，并在失败时妥善处理，是比较稳妥的做法。返回的指针类型是`pointer-to-void`，大致可以把它看作一个“通用”指针，可以转换成这块内存实际使用的具体类型。`malloc`有一个形参，即所需内存的字节数。为数组分配内存时，所需的总大小等于每个元素所属数据类型的大小乘以元素个数。通常使用`sizeof`运算符来获取每个元素所属数据类型的大小。下面的例子演示了这一点

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

要记住，`malloc`新分配的内存不会被初始化，其中可能保存着垃圾值。注意，对`numbers`指针使用`sizeof`得到的值，既不是数组元素的个数，也不是分配的总内存量。`malloc`返回的指针的大小，就是该系统中任意指针的大小。示例代码运行在 64 位系统上，因此指针的大小是 8 字节（乘以每字节 8 位 = 64 位）。指针类型从 pointer-to-void 隐式转换成了 pointer-to-int，也可以像这样显式转换：`int * numbers = (int *) malloc(sizeof(int) * count);`。如果这些值在被读取之前一定会被写入，那么用`malloc`分配内存可以很高效。但如果这些值有可能在被初始化之前就被读取，那么用`malloc`就有风险。更安全的分配内存方式是使用`calloc`，它会把新分配的内存初始化为零。

注意上面的例子中用到了`free(numbers)`。

## free

`free`是声明在`stdlib.h`中的一个函数，用来释放动态分配的内存。动态分配的内存在被`free`释放之前，会一直占用内存。有些操作系统会在程序结束时自动释放动态分配的内存，但最好不要依赖这一点。`free`有一个形参，即指向动态分配内存的指针。释放之后没有被设为`NULL`的指针称为悬空指针。悬空指针可能指向并非原本想要的那块内存。因此，悬空指针可能导致数据损坏，以及任意代码的替换和执行。指向已分配内存、但没有通过设为`NULL`来清除的指针，可以被用来攻击程序。最好在把指针传给`free`之后，将其设为`NULL`。

## calloc

`calloc`是声明在`stdlib.h`中的一个函数，既能分配动态内存，又能把新分配的内存初始化为零。如果分配成功，会返回一个指针，指向所分配内存第一个字节的地址。如果分配失败，则返回`NULL`。检查`calloc`的返回值是否为`NULL`，并在失败时妥善处理，是比较稳妥的做法。返回的指针类型是`pointer-to-void`，大致可以把它看作一个“通用”指针，可以转换成这块内存实际使用的具体类型。`calloc`有两个形参。第一个形参指定要分配多少个该数据类型的元素，第二个形参指定要分配的数据类型的大小。

在下面的例子中，所有`printf`语句都应该始终输出`0`，因为`calloc`保证把新分配的值置为零。

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc`是声明在`stdlib.h`中的一个函数，用来扩大或缩小已分配的内存。如果重新分配成功，会返回一个指针，指向重新分配后的内存第一个字节的地址。如果重新分配失败，则返回`NULL`。检查`realloc`的返回值是否为`NULL`，并在失败时妥善处理，是比较稳妥的做法。`realloc`有两个形参。第一个形参是指向要重新分配的现有内存的指针，第二个形参指定重新分配后的内存大小（以字节为单位）。在内存扩大之前已经设置的值会被保留。重要的是要记住，扩大内存时新增的内存不会初始化为零，其中的值可能是任何东西。另外，缩小内存时被移除的内存同样不会初始化，可能还保留着原来的值。下面的例子演示了数组的扩大和缩小

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
