# 数字

Crystal 有一个类型`Number`，它是所有数字类型的基础类型。
Number 类型内部有两个主要的子类型：[`Int`][int] 和 [`Float`][float]。

`Int`是 integer 的缩写，表示整数。
`Int`既可以是负数，也可以是正数，不带小数点。

```crystal
1.class
# => Int32

-1.class
# => Int32
```

`Float`表示带小数点的数字。
`Float`既可以是负数，也可以是正数。

```crystal
10.5.class
# => Float64
```

## 在`Int`和`Float`之间转换

使用 'to_i' 和 'to_f' 方法，可以在`Int`和`Float`之间进行转换。
从`Float`转换为`Int`时，数字会向下舍入。

```crystal
1.to_f
# => 1.0

1.0.to_i
# => 1

1.9.to_i
# => 1
```

## 算术运算符

你可以对`Int`和`Float`使用[基本算术运算符][math]。
运算符有`+`、`-`、`*`、`/`和`%`。
使用这些运算符时，你可以混用`Int`和`Float`。

### 加法、减法与乘法

`+`运算符用于加法，`-`运算符用于减法，`*`运算符用于乘法。

| 运算符 | 示例           |
| ------ | -------------- |
| `+`    | `4 + 6 => 10`  |
| `-`    | `15 - 10 => 5` |
| `*`    | `2 * 3 => 6`   |

### 除法

除法用来做数字的除法运算。
`/`运算符用于除法。
结果始终是 Float 类型。

```crystal
4 / 2
# => 2.0

4.0 / 2
# => 2.0
```

~~~~exercism/caution
在某些编程语言中，除以零会得到错误。

在 Crystal 中，除以零的结果是`Infinity`或`-Infinity`。
唯一的例外是零除以零，结果是`NaN`（Not a Number）。
`Infinity`和`NaN`是`Float`类型中的特殊值。

```crystal
1 / 0
# => Infinity

-1 / 0
# => -Infinity

0 / 0
# => NaN
```
~~~~

## 整数除法

整数除法用来做数字的除法运算，并取得结果的整数部分。
结果始终会向下舍入为 Int。

```crystal
4.0 // 2
# => 2

4.5 // 2
# => 2
```

~~~~exercism/caution
使用整数除法时，除以零会导致`DivisionByZeroError`。
这与普通除法不同。
~~~~

### 求模

求模用来取得除法运算的余数。
`%`运算符用于求模。

```crystal
5 % 2
# => 1

5.0 % 2
# => 1.0

5 % 3
# => 2
```

~~~~exercism/caution
使用求模时，除以零会导致 DivisionByZeroError。
这与普通除法不同。

```crystal
1 % 0
# Error: Unhandled exception: Division by 0 (DivisionByZeroError)
```
~~~~

## 幂运算

幂运算用来求一个数的幂。
`**`运算符用于幂运算。
用`Float`和`Int`进行运算时，结果会是`Float`。

```crystal
2 ** 2
# => 4

2.0 ** 2
# => 4.0
```

## 舍入

`round`方法接受一个可选的实参：要保留的小数位数。
默认的小数位数是 0。

```crystal
1.0.round
# => 1

1.5.round
# => 2

1.234.round(2)
# => 1.23
```

### 向上和向下舍入

你也可以用`ceil`和`floor`方法向上或向下舍入为`Int`。
`ceil`方法向上舍入，`floor`方法向下舍入。

```crystal
1.0.ceil
# => 1

1.2.ceil
# => 2

1.7.floor
# => 1
```

## 优先级与括号

Crystal 允许使用括号（`()`），可以用它对表达式进行分组。
当你想改变运算顺序时，这会很有用。

使用多个算术运算符时，运算顺序与数学中一致，也就是 [PEMDAS][pemdas]。
它遵循的顺序是括号（`()`）、指数（`**`）、乘法（`*`）和除法（`/`），以及加法（`+`）和减法（`-`）。

```crystal
2 + 3 - 4 * 4
# => -11

(2 + 3 - 4) * 4
# => 4
```
