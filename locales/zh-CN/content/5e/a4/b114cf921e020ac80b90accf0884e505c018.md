# Rust 参考

## 概念

Rust 的概念练习教授从基础知识到精通语言的各类概念。下文对它们进行了分类并列出。

Exercism 的概念以实用的方式服务于学习者，因此不同于抽象的理念。本文档定义这些概念在 Rust 中的含义。我们在下文添加了可视化分组，以帮助轨道维护者编写出一份有效的参考文档。此类分组_并不_构成教学上的划分。因此教学时请不要参考它们。

复选框表示这些概念是否已在练习映射列表中得到教授。

## 概念练习映射

虽然理想情况下，上面列出的每个概念都应有一个概念练习，只教授一个概念且只要求其前置知识，但完全这样做并不太现实。例如，要设计一个练习来讲解函数是什么，却完全不要求任何原始类型的知识，会很困难；同样，要借助测试套件讲解原始类型，却没有任何函数知识，也会很困难。

表中的练习应当构成一个有向无环图（DAG），最终覆盖上面列出的所有概念。

| 练习 | 前置知识 | 教授内容 | 叙事 |
| ---- | -------- | -------- | ---- |
| `hello-world`            | -                                            | 函数、测试套件                                   | 返回 `&str` 字面量 `"hello world"`                                        |
| `compiled-calculator`    | `hello-world`                                | 整数、变量赋值                            | 执行一组数学运算并隐式返回结果                |
| `conditionals`           | `hello-world`                                | 条件判断                                             | 应组织为包含 3 个分支的 `if` / `else if` / `else`；隐式返回          |
| `slices`                 | `hello-world`、`compiled-calculator`         | 切片                                                   | 从一个本身是整数切片的参数中取出一个切片                        |
| `loops`                  | `slices`                                     | 对切片的基本循环                               | 最好带有提前返回，这样用迭代器表达起来就很麻烦           |
| `iterator-use`           | `slices`                                     | 迭代器的使用、`collect`                                |
| `integer-sizes`          | `compiled-calculator`                        | 非 `i32` 的整数、类型转换                              | 仍然全部是有符号的                                                                 |
| `unsigned-ints`          | `integer-sizes`                              | 无符号整数                                            |
| `indexing`               | `integer-sizes`、`slices`                    | 下标、`usize`                                        |
| `floats`                 | `compiled-calculator`                        | 浮点数                                                   | 大概是同一个 compiled calculator 练习，只是结果为非整数             |
| `bools`                  | `compiled-calculator`                        | 布尔值、布尔运算符                                 |
| `char`                   | `compiled-calculator`                        | `char` 数据类型                                          | 应包含一些宽字符示例                                           |
| `str-use`                | `char`、`slices`                             | `&str`                                                   | 注意：不可变！                                                                 |
| `string-use`             | `str-use`                                    | `String`                                                 | 注意：拥有所有权，可变                                                             |
| `format-macro`           | `string-use`                                 | `format!` 宏                                          |
| `str-vs-string`          | `str-use`、`string-use`                      | 组合、转换、代价等                        |
| `generics-basics`        | `integer-sizes`、`floats`                    | 使用外部 trait 作为约束、泛型基础          | 可能仍然是 compiled-calculator，只是改为泛型                                 |
| `structs`                | `string-use`、`unsigned-ints`、`floats`      | 创建并使用结构体来管理数据               | `Person` 有名字、身高和拥有的鞋子数量                                   |
| `implicit-return`        | `compiled-calculator`                        | 作用域、表达式、隐式返回                     |
| `explicit-return`        | `implicit-return`、`conditionals`            | 显式 `return` 语句                              |
| `methods`                | `structs`、`explicit-return`                 | `impl` 块、方法                                   |
| `tuples`                 | `structs`                                    | 元组                                                   | 作为匿名结构体来讲解；讲解 `.0` 语法                                    |
| `tuple-structs`          | `tuples`、`structs`                          | 元组结构体（具名元组）                             |
| `basic-enums`            | `unsigned-ints`                              | 基础枚举（无字段）、`match`                         |
| `enums`                  | `basic-enums`、`tuple-structs`               | 枚举变体的元组语法                           |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | 默认不可变；显式可变性             |
| `let-expressions`        | `loops`、`option`、`result`                  | `if let`、`while let`                                    | 大概只会根据实现方式依赖 `option` 或 `result` 其中之一 |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`、`PartialOrd`、`Debug`、`Display`、`Default` |
| `implementing-traits`    | `deriving-traits`                            | 手动实现 trait                            | 大概会实现 `Iterator`                                                    |
| `collection-conversions` | `vectors`、`hashsets`、`implementing-traits` | `FromIterator`、`IntoIterator`                           |
