# MoonScript 赛道的测试

MoonScript 赛道的测试与 [Lua 赛道的测试][lua-tests]完全一样。
在练习目录下，输入：

```console
$ busted
```

## 待启用的测试

本赛道遵循 Exercism 的[测试驱动开发][tdd]方法。
你会拿到一套完整的测试，但只有第一个测试是“启用”状态。

要启用测试，把测试的命令从`pending`改为`it`。

如果你喜欢每次都运行全部测试，可以用命令行工具一次性把它们全部改掉。
下面是一个用 perl 实现的例子（perl 几乎到处都装了）：

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

在在线编辑器里工作时，测试运行器会自动运行所有测试。

## 使用 LuaRocks

Lua 本身就是一门很小的语言。
[LuaRocks][luarocks]是 Lua 模块的包管理器。

你可以在提交的解答中随意使用任何模块，但并非所有模块都能在在线测试运行器里使用。
测试运行器提供了以下这些：

**已作为`busted`的依赖提供**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**已作为 MoonScript 的依赖提供**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**日期时间**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
