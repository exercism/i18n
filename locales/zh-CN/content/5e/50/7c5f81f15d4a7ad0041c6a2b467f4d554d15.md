# 简介

[`fold`][fold]是一个[消费型迭代器适配器][consuming iterator adaptor]，它会把一个函数应用到迭代中的每个元素上，并把结果累积成一个新的值。

`fold`的每次迭代都接收两个实参。第一个是累加器的初始值。第二个是一个闭包，它本身接收两个实参：累加器和一个项。闭包的返回值就是累加器的下一个值。迭代器耗尽后，返回累加器的最终值。

当你想要把一个集合转换成单个值时，可以使用`fold`。例如，如果想求所有偶数的和：

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

输出`30`。

用`fold`能做到的事，往往用另一个函数或几个函数也能做到。对于上面的例子，先对`(1..=10)`使用[`filter`][filter]，再用[`sum`][sum]，会更简洁，得到的结果也一样，就像这样：

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

比`fold`更常用的其他函数还有[`product`][product]和[`collect`][collect]。

累加器也可以用来累积数值以外的内容。例如：

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

输出`FeeFiFoFum`
