# 运行测试

选择你的操作系统：

- [Windows](#windows)
- [macOS](#macos)
- [Linux](#linux)

## Windows

1. 打开 Command Prompt。
2. 获取第一个练习：

   ```batchfile
   C:\Users\JohnDoe>exercism download --exercise hello-world --track java
   ```

3. 切换到该练习所在的目录：

   ```batchfile
   C:\Users\JohnDoe>cd C:\Users\JohnDoe\exercism\java\hello-world
   ```

4. 运行测试：

   ```batchfile
   C:\Users\JohnDoe>gradlew.bat test
   ```

   _（一开始测试失败不用担心，每个练习都是这样开始的。）_

5. 完成练习。找到并按照`instructions.append.md`指南操作（[在 GitHub 上查看][hello-world-tutorial]）。

祝你好运！玩得开心！

## Linux

1. 在终端窗口中获取第一个练习：

   ```sh
   exercism download --exercise hello-world --track java
   ```

2. 切换到该练习所在的目录：

   ```sh
   cd /home/johndoe/exercism/java/hello-world
   ```

3. 运行测试：

   ```sh
   ./gradlew test
   ```

   _（一开始测试失败不用担心，每个练习都是这样开始的。）_

   如果出现以下错误：

   ```sh
   ./gradlew: Permission denied
   ```

   说明该文件缺少执行权限。要修复这个问题，请运行：

   ```sh
   chmod +x ./gradlew
   ```

   现在你应该可以运行上一条命令了。

4. 完成练习。找到并按照`instructions.append.md`指南操作（[在 GitHub 上查看][hello-world-tutorial]）。

祝你好运！玩得开心！
