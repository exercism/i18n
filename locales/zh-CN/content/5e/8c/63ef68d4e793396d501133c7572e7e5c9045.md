# 简介

在 Kotlin 中，可以用类来封装数据和行为。类使用`class`关键字声明。例如：

```kotlin
class Car
```

调用类就能创建它的一个实例。

```kotlin
val instance = Car()
```

## 属性

在上面的例子里，`Car`类没有声明任何属性。类的属性可以写在`{}`之间的类体里：可变属性用`var`，不可变属性用`val`。例如：

```kotlin
class Car {
    // color is mutable
    var color = "red"

    // year is immutable
    val year = 2025
}
```

另一种做法是把属性定义在接收这些属性的构造函数里。

## 构造函数

Kotlin 有两种构造函数：主构造函数和次构造函数。主构造函数写在类声明的同一行。例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

如果既没有注解，也没有可见性修饰符，`constructor`关键字可以省略：

```kotlin
class Car(var color : String = "red", val year : Int = 2025) {
    // ...
}
```

~~~~exercism/note
Kotlin 允许在类只包含属性时不写类体，也就是不需要那对`{}`：

```kotlin
class Car (var color : String = "red", val year : Int = 2025)
```
~~~~

一个类只能有一个主构造函数。次构造函数是额外的构造函数，只要在类体里用`constructor`关键字声明，就能添加。例如：

```kotlin
class Car constructor(var color : String = "red", val year : Int = 2025) {

    // This constructor allows the year to be provided as a String
    constructor(color : String = "red", yearText : String) : this(color, yearText.toIntOrNull() ?: 0)
}
```

次构造函数必须通过调用`this`来调用主构造函数。

## 初始化块

主构造函数负责设置类的属性。如果创建对象时还需要做别的事情，可以用`init`块来执行额外的操作。

```kotlin
class Car constructor(var color: String = "red", val year : Int = 2025) {
    init {
        println("Car is ${color}, made in ${year}")
    }
}
```

## 函数

函数可以定义在类体里。例如：

```kotlin
class Car (var color : String = "red", val year : Int = 2025) {
    fun repaint(newColor : String) {
        color = newColor
    }
}
```

## 可见性

属性和函数可以是`private`、`public`、`internal`或`protected`。

- `private`：只能在类内部访问
- `protected`：类内部的成员以及任何子类都可以访问
- `internal`：同一模块内的成员可以访问
- `public`：使用该类的其他组件都可以访问

例如：

```kotlin
class Car {
    private val color: String
    public val year: Int
    internal val model: String
    protected val brand: String

    private fun drive() {
        // ...
    }

    internal fun start() {
        // ...
    }

    protected fun stop() {
        // ...
    }

    public fun make() {
        // ...
    }
}
```
