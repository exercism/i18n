# 关于

[`switch`语句][switch]把一个值与多个可能的匹配模式进行比较。相比串联多个`if-else`语句，它更简洁、更易读。

`switch`语句以`switch`关键字开头，后面跟上要判断的值。每个可能的匹配都用`case`关键字引出。`default`关键字定义兜底分支，在所有显式分支都不匹配时执行。和`if-else`链一样，`switch`语句只会执行第一个匹配分支对应的代码块。

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

看看下面这条`if-else`链：

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

用`switch`语句可以写得更清晰：

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## 值绑定与`where`子句

`switch`的分支可以把匹配到的值绑定到临时常量或变量上，供该分支的主体使用。分支还可以带上`where`子句，在匹配前检查额外的布尔条件：

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
    print(total, "is a perfect number")
default:
    print(x, "is not a perfect number")
}
```
