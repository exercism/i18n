# 说明

你是一位热衷观鸟的爱好者，每天都会记录来花园里作客的鸟的数量。这些记录存储在一个数组中，最早的日期排在最前面。

## 1. 今天的数量

定义`today`，从栈上取出每日数量数组，返回今天的数量。

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. 自增今天的数量

定义`increment-todays-count`，返回一个新数组，其中今天的数量加一。不应修改原数组。

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. 有没有哪一天没有鸟？

定义`has-day-without-birds?`，如果至少有一天记录的鸟数为零，则返回`t`，否则返回`f`。

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. 求前几天的总和

定义`count-for-first-days`，接收一个数量数组和一个数字`n`，返回前`n`个数量之和。

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. 数一数繁忙的日子

繁忙的日子是指有 5 只或更多鸟的日子。定义`busy-days`，返回数组中繁忙日子的数量。

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. 补齐缺失的日子

如果你在连续`n`天里没有每天都观察，就把末尾缺失的日子用`0`补齐。定义`pad-missing-days`，接收一个数量数组和一个目标长度`n`，返回一个长度至少为`n`的数组，多出来的位置为`0`。已有的数量必须保持不变；如果输入的长度已经至少为`n`，就原样返回。

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
