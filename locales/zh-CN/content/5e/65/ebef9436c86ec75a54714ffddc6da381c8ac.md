# 说明

[领域特定语言（DSL）][dsl]是一种针对特定领域优化的小型语言。由于 DSL 有明确的针对性，它允许使用者声明自己_想要什么_，而不是_如何去_做，因此能极大地提升工作效率和理解程度。

它的一个常见应用领域是复杂的自定义和配置。

例如，[DOT 语言][dot-language]允许你用文本描述一张图，然后由 [Graphviz][graphviz] 工具（比如`dot`）将其转换成图片。一个简单的图长这样：

    graph {
        graph [bgcolor="yellow"]
        a [color="red"]
        b [color="blue"]
        a -- b [color="green"]
    }

把这段内容放进文件`example.dot`，再运行`dot example.dot -T png -o example.png`，就会生成一张`example.png`图片：黄色背景上，一个红色圆圈和一个蓝色圆圈由一条绿色线相连。

请编写一个类似 Graphviz dot 语言的领域特定语言。

我们的 DSL 与 Graphviz dot 语言相似，都是用来创建图数据结构的。不过，与 DOT 语言不同，我们的 DSL 是一种内部 DSL，只在本语言中使用。

[进一步了解内部 DSL 与外部 DSL 的区别][fowler-dsl]。
