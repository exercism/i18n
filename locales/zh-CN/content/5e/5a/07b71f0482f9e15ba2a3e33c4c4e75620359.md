# 简介

`when` 是用来筛选异常的关键字。它放在 `catch` 语句之后，可以接收一个布尔表达式，表达式里可以使用当时作用域内的任意值。如果表达式的计算结果为 true，就执行与该 `catch` 语句关联的代码块；否则会检查下一个 `catch` 语句（如果有的话）。

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
