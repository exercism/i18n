# 关于

[方法重载][method-overloading]是 Java 中的一个核心概念，它允许一个类拥有多个同名方法，只要每个方法的形参列表不同即可。
这一特性是 Java 面向对象编程的基础之一，它让我们可以用不同类型或数量的输入完成相似的操作。
方法重载让功能相似的方法可以共用同一个名字，从而提升代码的可读性和条理性。
要注意的是，是否构成重载取决于方法的签名，而签名由方法名和形参列表组成。

## 要点

- **签名才是关键**：返回类型不属于方法签名的一部分，所以仅仅改变方法的返回类型并不构成重载。
- **形参的差异**：重载的方法必须在形参的数量或类型上有所不同。
- **用法**：重载常常用来让同一个方法能更直观地处理不同类型的输入。

## 方法重载的示例

假设有一个可以对数字做加法的`Calculator`类。
借助重载，它可以支持不同类型的加法运算：

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## 最佳实践

- **保持清晰**：使用重载方法时，应让代码更直观。
  - 各个重载方法的行为应当彼此相关，并保持一致。
- **避免歧义**：确保每个重载方法都有明确的目的，并且形参列表之间的差异足够明显，不会让人混淆。
- **写好文档**：为每个重载版本都配上合适的文档。
  - 清晰的文档能帮助其他开发者理解每个方法变体的用途和用法。
- **返回类型保持一致**：重载方法的返回类型可以不同，但通常最好尽可能保持一致，以免造成混淆。
- **克制使用重载**：不要过度使用方法重载。
  - 过多的重载会让代码更难阅读和维护。

## 总结

方法重载是 Java 中一项强大的功能，只要使用得当，就能大幅提升代码的可读性和灵活性。
它让方法更加灵活，能适应不同的场景，也让你的 Java 程序更加模块化、更易维护。
