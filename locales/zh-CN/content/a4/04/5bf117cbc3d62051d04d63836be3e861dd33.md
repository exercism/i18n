# 关于

Elm 是一门令人愉悦的语言，适合用来构建可靠的 Web 应用。它有友好的错误信息、出色的性能、很小的打包体积，而且没有运行时异常。

Elm 最著名、被借鉴最多的部分大概要数 Elm 架构了。它是组织 Web 应用的一种简单模式，所有 Elm Web 应用都是这样写出来的。

核心思想是，你的代码围绕表示应用状态的 `Model`、更新模型的方式 `update`，以及展示模型的方式 `view` 来组织。

`Model` 保存应用的状态，也就是应用需要的所有数据。它可以是任意类型，但在任何有用的应用里，它通常是一个[记录][record]。想象一个简单的应用：有一个文本框，还有一段显示该文本反转结果的文字，那么模型大致如下。你也可以在 [Elm 指南][elm-guide-text-fields] 中看到这个示例。

```elm
type alias Model =
  { text : String
  }
```

`update` 是一个函数，当发生变化（比如用户点击按钮）时，它会被调用，并接收一个 `Msg`。它接收 `Msg` 和当前的 `Model`，返回一个新的 `Model`。`Msg` 可以是任意类型，但通常是[自定义类型][custom-type]。

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

和所有自定义类型一样，`Msg` 的各个变体可以根据需要携带任意多的信息。在上面的例子里，`TextChanged` 变体就携带了一个 `String`。

`view` 是一个函数，返回要在浏览器中展示给用户的 HTML。它接收当前的 `Model`，返回一个 `Html Msg`（Elm 用来表示 HTML 的类型）。每个 HTML 元素（例如 `<div>`）在 `Html` 包里都有一个对应的 Elm 函数（`Html.div`）。这些函数各自接收两个形参：第一个是属性列表（来自 `Html.Attributes` 和 `Html.Events` 包），第二个是子元素列表（即来自 `Html` 包的函数）。另外还有一个 `text` 函数，用来表示 HTML 的字符串内容；它只接收一个字符串形参，除此之外，用法和 `Html` 包里其他所有函数／元素一样。

`view` 函数可以指定：某些事件，比如点击按钮或在文本框中编辑文字，会产生一个 `Msg`，Elm 运行时随后会用它来调用 `update` 函数、修改 `Model`，并生成更新后的 HTML。在下面的代码里，这是通过 `Html.Events.onInput TextChanged` 实现的。

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

`Html.Events.onInput` 期望接收一个函数（`String -> Msg`），并用它来创建 `Msg`。不同的事件期望不同的函数，具体取决于它们能提供什么信息。例如 `Html.Events.onCheck`（用于复选框）期望 `Bool -> Msg`，而 `Html.Events.onClick` 只期望一个 `Msg`。

Elm 语言是纯函数式的，不可能发生任何修改，所以所有会变化的东西都由 Elm 运行时来处理。你可以在 Elm 包仓库里看到所有不同的 [HTML 元素][html-elements]、[元素属性][element-attributes] 和 [HTML 事件][html-events]。

用 Elm 可以编写 4 个“级别”的 Web 应用，它们越来越强大，也越来越复杂（不过 Elm 的语言和生态系统依然简单得令人愉悦）。这些级别都定义在 [Browser 包][browser-package] 中：

- [sandbox][browser-sandbox]：响应按钮、复选框之类的用户输入
- [element][browser-element]：借助 HTTP 和 JavaScript 互操作与外部世界通信
- [document][browser-document]：控制网页的 `<title>` 和 `<body>`
- [application][browser-application]：创建完整的单页应用，处理路由和 URL 变化

本概念使用的是 [sandbox][browser-sandbox]，因为它最简单（而且正因为是沙箱，配合 Exercism 在线编辑器使用也相对容易）。Elm 程序的入口模块必须叫 `Main`，创建应用的函数必须叫 `main`，如下所示。

```elm
import Browser
import Html exposing (Html, Attribute, div, input, text)
import Html.Attributes exposing (placeholder, value)
import Html.Events exposing (onInput)

main =
  Browser.sandbox { init = init, update = update, view = view }

init : Model
init =
  { text = "" }

-- Add Model, Msg, update and view here
```

我们已经见过 `update` 和 `view` 函数了，而 [sandbox][browser-sandbox] 还额外要求提供一个 `init` 函数，用来返回 `Model` 的初始状态。
