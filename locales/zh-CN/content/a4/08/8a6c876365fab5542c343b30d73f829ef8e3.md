# 枚举

枚举是 Cairo 的一种数据类型，用来定义一组预定义的变体，目的是提升代码的可读性和安全性。
在 Cairo 中，可以声明 `enum` 变体来保存不同的数据类型（整数、结构体、元组、其他枚举等）。

下面的代码片段展示了如何定义枚举：

```rust
#[derive(Drop)]
enum Direction {
    North,
    East,
    South,
    West,
}
```

上面声明的 `Direction` 枚举是一个简单的枚举，包含四个变体：`North`、`East`、`South` 和 `West`。
命名约定是：枚举变体使用 PascalCase。
每个变体都代表 `Direction` 枚举类型的一个不同的值。
这个枚举示例中的每个变体都没有关联值，可以用下面的语法实例化：

```rust
let direction = Direction::North;
```

下面还是同一个 `Direction` 枚举，但它的变体带有关联值，用来保存方向的具体角度：

```rust
#[derive(Drop)]
enum Direction {
    North: u128,
    East: u128,
    South: u128,
    West: u128,
}
```

从这个例子可以清楚地看出，`Direction` 枚举中的每个变体都有一个 `u128` 类型的关联值。
这种枚举可以这样实例化：

```rust
let direction = Direction::North(10);
```

## 使用自定义类型的复杂枚举示例

枚举的各个变体可以组合使用不同的数据类型。
在下面的例子中，`Action` 是一个复杂枚举，它的变体包括 `Quit`、`Direction`、`SendMessage`、`ChangeAvatar` 和 `ProfileState`。

```rust
#[derive(Drop)]
struct Move {
    up: u32,
    down: u32,
    right: u32,
    left: u32,
}

#[derive(Drop)]
enum UserCommand {
    Login,
    UpdateProfile,
    Logout,
}

#[derive(Drop)]
enum Action {
    Quit, //  variant with no associated value
    Direction: Move, // variant with the `Move` struct associated value
    SendMessage: felt252, // a single felt252 variant
    ChangeAvatarColor: (u8, u8, u8), // variant with the tuple of three associated values
    ProfileState: UserCommand // variant with an enum associated value
}
```

## 枚举的 trait 实现

在 Cairo 中，可以为自定义枚举定义并实现 trait。
这样你就能定义与枚举关联的方法和属性。
下面的例子中，我们定义了一个 `Message` 枚举，并为它实现 `Processing` trait：

```rust
#[derive(Drop)]
enum Message {
    Quit,
    Echo: felt252,
    Move: (u128, u128),
}

trait Processing {
    fn process(self: Message);
}

impl ProcessingImpl of Processing {
    fn process(self: Message) {
        match self {
            Message::Quit => { println!("quitting") },
            Message::Echo(value) => { println!("echoing {}", value) },
            Message::Move((x, y)) => { println!("moving from {} to {}", x, y) },
        }
    }
}
```

下面展示了如何用这个 trait 处理一条 `Quit` 消息：

```rust
let msg: Message = Message::Quit;
msg.process(); // prints "quitting"
```

在很多情况下，枚举都很有用，尤其是和 `match` 流程搭配使用时，就像上面 trait 实现中所做的那样。
想进一步了解 `match` 流程，请阅读 [The Cairo Book][match]。
