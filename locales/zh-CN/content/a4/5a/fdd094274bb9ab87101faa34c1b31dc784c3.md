# 空值

空值是一种原始值类型，它只有一个值：`null`。
空值常用来表示“什么都没有”。
它被视为“假值”，但与 `false` 以及其他假值不同。

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## 处理空值

在 PHP 中，空值常常是导致错误的常见原因，因为它们经常被用来代替错误状态返回，或者用来表示什么都没有。
要避免错误发生，通常需要进行“空值检查”，在操作某个值之前先断言它不是空值。

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

反复进行空值检查很容易出错，因此 PHP 提供了两个处理空值的运算符：空安全访问运算符 `?->` 和空值合并运算符 `??`。

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
