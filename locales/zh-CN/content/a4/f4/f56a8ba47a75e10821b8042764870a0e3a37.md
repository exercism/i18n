# 提示

## 通用

- 每个任务都需要一个变量来记录圈数，其中两个任务还需要第二个变量来保存累计总数。
- 第`n`圈的长度是`90 + 10 * n`米。验证一下：第 1 圈就是 100 米。
 
## 1. 总共跑了多远？

- 让`total`从 0 开始，`lap`从 1 开始。
- 用`until!(lap > laps)`作为循环的结束条件，把它放在循环开头，这样当圈数为 0 时循环体一次都不执行，总数也保持为 0。
- 把这一圈的长度加到总数上，然后给`lap`加 1。忘了这一步，循环就会永远跑下去。

## 2. 跑多少圈才能覆盖一段距离？

- 这里同样要记录累计总数，但这次关注的是总数而不是圈数：`until!(total >= metres)`。
- 同样把它放在开头。这样即使要跑的距离是 0 米，答案也是 0 圈，一圈都不用跑。
- 循环结束时，圈数计数器的值就是答案。

## 3. 哪一圈最先变长？

- 这里不需要累加任何东西，所以也不需要累计总数。
- 检查当前这一圈的长度，一旦超过题目问到的距离，就用`break!`跳出循环。
- 循环结束时`lap`的值就是答案。
