## 类型别名

在 Gleam 中，可以用类型别名给某个已有的类型起一个方便的名字，否则这个类型写起来会很繁琐。

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

用 `pub type` 声明时，这个别名可以在定义它的模块之外使用。如果省略 `pub`，这个别名就是私有的，无法在其他模块中被引用。
