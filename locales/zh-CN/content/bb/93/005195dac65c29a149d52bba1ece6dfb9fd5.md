# 带状态的类

到目前为止的每个类，都只是一盒例程。每个例程接收自己的实参，算出一个答案，然后把一切忘掉。

类也可以**记住**东西。记分牌就必须这样：现在的比分取决于比赛开始以来的每一个进球。

## 属性

`attr`让类有东西可以记住。

```sather
class SCOREBOARD is

   attr home_score : INT;
   attr away_score : INT;

end; -- class SCOREBOARD
```

每个`attr`都会变成一个读取该值的例程，以及一个修改该值的例程：

```sather
   board.home_score            -- read it
   board.home_score := 4;      -- change it
```

同一类型的属性可以共用一个声明，就像实参一样：

```sather
   attr home_score, away_score : INT;
```

## 对象

带属性的类，是一种用来创建**对象**的模式。每个对象都有自己的一份属性副本，所以 2 个记分牌会各自记录自己的比分。

`new`用来创建对象。它位于一个名为`create`的例程里，这个例程会把对象填好，再把它交回来：

```sather
   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;
```

`SAME`的意思是“这个类”。在那里写`SCOREBOARD`，表达的意思完全相同，但如果类被改名，`SAME`依然有效。

## 创建一个对象

`#`会调用`create`：

```sather
   board ::= #SCOREBOARD("Vixens", "Magpies");
```

从`rehearsal-script`起，你就一直在用`#`，`#FSTR`用的正是这个。

## 会修改对象的例程

在类内部，直接用名字就能使用属性，前面不用写对象。它指的就是调用该例程时所针对的那个对象。

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

`home_goal`没有声明返回类型，因为它不返回任何内容，只是修改对象。把它当作语句来调用：

```sather
   board.home_goal;
```

## 属性初始为空

没人赋过值的属性，对`INT`来说值是零，对`BOOL`来说是`false`，对字符串或对象来说是 void。所以一个新的记分牌一开始就显示 0 比 0，不需要任何东西专门说明。
