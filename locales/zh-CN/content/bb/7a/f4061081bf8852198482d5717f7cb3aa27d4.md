# 说明

你的设计团队正在把部分布局工作从 CSS 变换迁移到 Factor。为了让团队其他成员满意，你需要用 quotation 构建小巧、可复用的变换，它们接收一个二维点并返回一个二维点。

一个点是一个二元素数组 `{ x y }`。

## 1. 平移坐标

定义 `translate-2d`，从栈上取两个值 `dx` 和 `dy`，返回一个把点平移 `(dx, dy)` 的 quotation。

```factor
{ 4 8 } 2 0 translate-2d call( p -- p' ) .
! => { 6 8 }
```

## 2. 缩放坐标

用同样的方式定义 `scale-2d`，返回一个按 `(sx, sy)` 缩放点的 quotation。

```factor
{ 6 -3 } 2 2 scale-2d call( p -- p' ) .
! => { 12 -6 }
```

## 3. 组合两个变换

定义 `compose-transformations`，接收两个变换 quotation `f` 和 `g`，返回一个先应用 `f`、再应用 `g` 的 quotation。

```factor
{ 0 1 } 2 0 translate-2d 2 2 scale-2d compose-transformations
call( p -- p' ) .
! => { 4 2 }
```

## 4. 应用变换

定义 `apply-transformation`，从栈上取一个点和一个变换 quotation，返回变换后的点。

```factor
{ 4 8 } 2 0 translate-2d apply-transformation .
! => { 6 8 }
```

## 5. 一次变换多个点

定义 `transform-points`，接收一个点数组和一个变换 quotation，返回变换后的点数组。

```factor
{ { 0 0 } { 1 1 } { 2 2 } } 1 0 translate-2d transform-points .
! => { { 1 0 } { 2 1 } { 3 2 } }
```
