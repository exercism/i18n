# 提示

## 通用

- 手边有一份 PHP 所有[算术运算符][arithmetic-operations]的清单可能会很有用。

## 1. 面团比例

- 你可以用加法和乘法的基本算术运算符来完成这个任务。

## 2. 加一点酱料

- 要确保罐头数量是整数，你需要向上取整。
- PHP 提供了可以帮上忙的[数值函数][numeric-functions]。

## 3. 来点奶酪

- 你可以使用[幂运算符][arithmetic-operations]求一个数字的立方。
- 要确保披萨的数量是整数，你需要向下取整。
- PHP 提供了可以帮上忙的[数值函数][numeric-functions]。
- PHP 有一个表示圆周率（π）的[内置常量][pi-constant]。

## 4. 公平分配

- 使用[求模运算符][arithmetic-operations]（`%`）来获取除法后的余数。

[arithmetic-operations]: https://www.php.net/manual/en/language.operators.arithmetic.php
[pi-constant]: https://www.php.net/manual/en/function.pi.php
[numeric-functions]: https://www.php.net/manual/en/ref.math.php
