# 说明

本练习涉及日志文件的解析。

在最近的一次安全审查之后，有人要求你清理组织归档的日志文件。

所有传给这些方法的字符串都保证不为 null，且不含前导和尾随空格。

## 1. 找出格式错乱的日志行

你需要大致了解归档中有多少日志行不符合当前标准。你认为用一个简单的测试就能判断一行日志是否有效。要被视为有效，一行日志应当以以下字符串之一开头：

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

实现`LogParser.IsValidLine()`方法，如果字符串无效就返回`false`，否则返回`true`。

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. 拆分日志行

一个新团队加入了组织，你发现他们的日志文件对“字段”使用了奇怪的分隔符。他们不用像冒号 ":" 这样合理的东西，而是使用诸如 "<--->" 或 "<=>" 这样的字符串（因为这样更好看）。实际上，任何第一个字符是 "<"、最后一个字符是 ">"、中间是 "^"、"\*"、"=" 和 "-" 的任意组合的字符串都算。

实现`LogParser.SplitLogLine()`方法，它接收一行日志，返回一个字符串数组，其中每个元素包含一个字段。

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. 统计包含引号内密码的行数

团队需要了解出现在引号文本中的密码，以便人工检查。

实现`LogParser.CountQuotedPasswords()`方法，用来大致估计人工检查的工作量。

找出这样的日志行：字面字符串 "password"（大小写可以是任意组合）被引号包围。
你还要考虑到引号之内、"password" 之前和之后可能还有其他内容。

传给该例程的日志行可能有效，也可能无效（按任务 1 的定义）。无论是否有效，我们都以相同的方式处理它们。

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. 从日志中移除残留内容

你发现日志的某些上游处理把 "end-of-line" 加上一个行号（中间没有空格）这样的文本散布到了整个日志中。

实现`LogParser.RemoveEndOfLineText()`方法，接收一个字符串，移除其中的 end-of-line 文本，并返回一个“干净”的字符串。

不含 end-of-line 文本的日志行应当原样返回。

只移除 end-of-line 字符串就好，不要试图调整空白字符。

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. 列出密码极弱的日志行，好让违规者受到惩罚

在从文件中清除密码之前，我们需要列出所有密码以 "password" 开头的实例。

实现`LogParser.ListLinesWithPasswords()`方法，输出有问题的密码，后面跟上完整的日志行。

带引号密码的日志行已经被移除，并且你处理日志行时不管它们是否有效（按任务 1 的定义）。

含有问题密码的日志行应当以 "<password>: " 为前缀返回。

不含问题密码的日志行应当以 "--------: " 为前缀返回。

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
