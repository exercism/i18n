# 说明

在本练习中，你将进一步处理遥控车相关的工作。

一款实验车已经研发出来，测试赛道需要改造，以便同时容纳量产车型和实验车型。
这两种车都已经造好，你需要想办法让它们在测试赛道上共存。

此外，量产车开始取得一些成绩。
车队老板希望通过公布量产车的排名来保持竞争氛围。

## 1. 实现接口

请向`RemoteControlCar`接口中添加两个方法：

- `drive()`，不返回任何值，以及
- `getDistanceTravelled()`，返回一个`int`。

然后让`ProductionRemoteControlCar`和`ExperimentalRemoteControlCar`实现`RemoteControlCar`接口。
这包括实现该接口要求的所有方法。

## 2. 驾驶

每次调用`.drive()`都应让车行驶一段距离：

- `ProductionRemoteControlCar`行驶 10 个单位，
- `ExperimentalRemoteControlCar`行驶 20 个单位。

`.getDistanceTravelled()`方法应返回该车自启用以来行驶的总单位数。

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. 比赛

实现`TestTrack.race(RemoteControlCar car)`方法，其中的`car`会执行`drive()`。

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. 让量产车可以排序

请在`ProductionRemoteControlCar`类中实现`Comparable<T>`接口。
赛车的默认排序顺序应为按胜利次数降序排列。

实现静态方法`TestTrack.getRankedCars()`，返回传入的赛车，并按胜利次数降序排列。

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
