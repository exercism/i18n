# 简介

## chars

Java 的`char`基本类型用 16 位来表示单个字符。多个`char`可以组成一个字符串，比如`"word"`；`char`也可以单独处理。`char`字面量用单引号括起来（例如`'A'`）。

```java
char lowerA = 'a';
char upperB = 'B';
```

## 获取`String`中的`char`

`String.toCharArray`方法会把字符串中的各个字符以数组的形式返回。正如数组部分讲到的，你可以用`for`循环遍历这个数组。

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

## Character 类

标准库中有很多内置方法可以检查和操作`char`，它们都以静态方法的形式存在于`java.lang.Character`类中。下面是一些例子：

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

## 向`String`中添加`char`

可以用`+`运算符把`char`添加到`String`中。

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
注意，_不要_用`+`把两个`char`拼成一个`String`！这样把两个`char`相加得到的是`int`，_而不是_`String`！例如：

```java
'b' + 'c';
// => 197 (not the String "bc")
```

这是因为 Java 会把`char`提升为`int`（参见 [Java Language Specification][jls-main] 中的 [4.2 Primitive Types and Values ][jls-primitives]）。

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

不过，如果要添加的字符很多，改用`StringBuilder`会更高效：

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
