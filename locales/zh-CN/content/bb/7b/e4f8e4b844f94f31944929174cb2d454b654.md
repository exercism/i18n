# 关于

常见的数学函数都在[`math.functions`][math.functions]里，常量在[`math.constants`][math.constants]里，另外还有几个只处理浮点数的词在[`math.libm`][math.libm]里。每个词都从栈上取输入：

```factor
USING: kernel math math.constants math.functions math.libm prettyprint ;

9 sqrt .            ! => 3.0
1.0 1.0 fatan2 .    ! => 0.7853981633974483
```

## 常量

| 词 | 值 |
| --- | --- |
| `pi` | π, 3.14159… |
| `e` | *e*, 2.71828… |

## 根与幂

| 词 | 栈效应 | 结果 |
| --- | --- | --- |
| `sqrt` | `( x -- y )` | `x`的平方根 |
| `sq` | `( x -- y )` | `x * x` |
| `^` | `( x y -- z )` | `x`的`y`次幂，`y`不必是整数 |

## 三角函数

| 词 | 栈效应 | 结果 |
| --- | --- | --- |
| `sin` `cos` `tan` | `( x -- y )` | 角度为`x`（单位为弧度）时的正弦、余弦、正切 |
| `asin` `acos` `atan` | `( x -- y )` | 正弦、余弦或正切值为`x`的那个角，单位为弧度 |
| `fatan2` | `( y x -- z )` | 从`x`轴正方向转到点（`x`, `y`）的角度，单位为弧度 |
| `deg>rad` | `( x -- y )` | 把角度转换成弧度 |
| `rad>deg` | `( x -- y )` | 把弧度转换成角度 |

所有角度都以**弧度**为单位：一整圈是 2π，而不是 360。只在输入输出的边界处转换，中间过程一律用弧度。

在判断方向时，`fatan2`（来自`math.libm`）比`atan`更好。`1 1 / atan`分不清 (1, 1) 和 (−1, −1)，因为两者相除都得到`1`，而且当`x`为零时它会失败。`fatan2`会同时看两个符号，结果可以落在 −π 到 π 之间的任何位置：

```factor
1 1 / atan rad>deg .          ! => 45.0
-1 -1 / atan rad>deg .        ! => 45.0
-1.0 -1.0 fatan2 rad>deg .    ! => -135.0
```

## 指数与对数

| 词 | 栈效应 | 结果 |
| --- | --- | --- |
| `e^` | `( x -- y )` | *e*的`x`次幂 |
| `log` | `( x -- y )` | 自然对数：要让 *e* 的幂等于`x`，所需的就是这个指数 |
| `10^` | `( x -- y )` | 10 的`x`次幂 |
| `log10` | `( x -- y )` | 以 10 为底的对数 |
| `log2` | `( x -- y )` | 以 2 为底的对数 |

`e^`和`log`互为逆运算，`10^`和`log10`也一样。

每一步都按相同比例缩小的量，遵循`start * e^(-rate * t)`。从`start`降到`level`所需的时间是`log(start / level) / rate`。

## 没有实数答案的时候

这些词遇到棘手的输入都不会抛出错误。负数的平方根或对数会给出**复数**结果，打印时外面会套一层`C{ ... }`，而不是一个普通的数字：

```factor
-1 sqrt .     ! => C{ 0.0 1.0 }
-1.0 log .    ! => C{ 0.0 3.141592653589793 }
0.0 log .     ! => -1/0.
```

`-1/0.`是负无穷大。如果有可能传入不合法的参数，就在调用前先检查一下。等到三步计算之后才发现一个复数或无穷大，就很难追查来源了。

## 这里的舍入同样是近似值

这些词给出的是最接近的浮点数，而不是精确值，所以比较结果时要用`~ ( x y epsilon -- ? )`按容差来比，绝不要用`=`：

```factor
pi 6 / sin .             ! => 0.49999999999999994
pi 6 / sin 0.5 = .       ! => f
pi 6 / sin 0.5 1e-9 ~ .  ! => t
```
