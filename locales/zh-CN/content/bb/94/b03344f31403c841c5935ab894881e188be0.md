# 关于


现在该来看看 C++ 的核心范式之一了：面向对象编程（OOP）。
面向对象编程以`classes`为核心，也就是用户自定义的数据类型，它们带着自己的一整套相关函数。
我们会从基础讲起，更高级的主题会在教学大纲的后续部分再讲。

## 成员

类可以有**成员变量**和**成员函数**。
访问它们要用**成员选择**运算符 `.`。
和`classes`之外的变量一样，成员变量最好在声明时就赋一个初始值。
这个值会成为由这个类新建出来的对象的默认值。

## 封装与信息隐藏

类可以选择限制对其成员的访问。
最基本的两种情况是 `private` 和 `public`。
`private` 成员无法从类的外部访问。
`public` 成员则可以自由调用。
默认情况下所有成员都是 `private`，要想在类外部使用，必须显式标注。

## 基本示例

新 `class` 的定义见下面的例子。
注意定义末尾的 `;`。

```cpp
class Wizzard {
  public:               // from here on all members are accessible publicly
    int cast_spell() {  // defines the public member function cast_spell
      return damage;
    }
    std::string name{}; // defines the public member variable `name`
  private:              // from here on all members are private
    int damage{5};      // defines the private member variable `damage`
};

```

在类内部可以访问所有变量。
看看 `cast_spell` 函数里的 `damage`。
而在类外部，你无法读取或修改 `private` 成员：

```cpp
Wizzard silverhand{};
// calling the `cast_spell` function is okay, it is public:
silverhand.cast_spell();
// => 5

// name is public and can be changed:
silverhand.name = "Laeral";

// damage is private:
silverhand.damage = 500;
 // => Compilation error
```

## 构造函数

构造函数让你可以在创建对象时给成员变量赋值。
它的名字和 `class` 相同，而且没有返回类型。
一个类可以有多个构造函数。
如果你并不总是需要设置所有变量，这会很有用。

```cpp
class Wizzard {
  public:
    Wizzard(std::string new_name) {
      name = new_name;
    }
    Wizzard(std::string new_name, int new_damage) {
      name = new_name;
      damage = new_damage;
    }
    int cast_spell() {
      return damage;
    }
    std::string name{};
  private:
    int damage{5};
};

Wizzard el{"Eleven"};       // deals  5 damage
Wizzard vecna{"Vecna", 50}; // deals 50 damage
```

构造函数是个大话题，有很多细节。
如果你没有为 `class` 显式定义 `constructor`，那么（也只有在这种情况下）编译器会替你完成这件事。
上面的第一个例子就是这样。
_silverhand_ 对象是通过调用默认构造函数创建的，没有传入任何实参。
所有变量都被设成类定义中写明的值。
如果你在定义里没有给出任何值，这些变量可能未被初始化，从而带来意想不到的后果。

## 结构体

结构体源自这门语言最初的 C 语言根基，和 C++ 本身一样古老。
它们实际上和 `classes` 是一回事，只有一个重要区别。
默认情况下，`class` 里的一切都是 `private`。
而结构体除非另有声明，否则都是 `public`。
按照惯例，`struct` 关键字常用于**只存放数据的结构体**。
对于需要保证某些属性的对象，则更推荐用 `class` 关键字。
这样的不变式可以是：你的 `Wizzard` `class` 里的 `damage` 不能变成负数。
`damage` 变量是私有的，任何修改 damage 的函数都会确保这个不变式得到维持。
