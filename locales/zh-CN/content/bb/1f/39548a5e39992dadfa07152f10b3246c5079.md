# 简介

`Complex numbers`并不复杂。
它只是需要一个不那么吓人的名字。

它们非常有用，尤其在工程和科学领域，因此 R 把复数作为一种标准的原子类型，与整数、双精度浮点数、逻辑值、字符和 raw 并列。

## 基础

在 R 中，一个`complex`数是一个值。
但在使用时，可以把它看作一对数字。
出于一些不幸的历史原因，它们被称为“实部”和“虚部”。
还是那句话，最好把注意力放在它本质上有多简单，而不是那些奇怪的名字上。

要用两个实数创建复数，只需给虚部加上后缀`i`。

```r
2+3i
#> [1] 2+3i

typeof(2+3i)
#> [1] "complex"
```

要用实数变量创建复数，上面的写法行不通。
写成`r + imi`会让解析器误以为`imi`是一个（并不存在的）变量名。

要么把虚部乘以`1i`，要么使用 [`complex()`][ref-complex] 函数：

```r
r <- 2
im <- 3

r + im * 1i
#> [1] 2+3i

# must include the `real` and `imaginary` keywords
complex(real = r, imaginary = im)
#> [1] 2+3i
```

你也许会好奇，为什么用`i`而不是`j`？

大多数工程师更喜欢`j`。
大多数科学家和数学家更喜欢用数学记号`i`来表示_虚数_，但在电气工程中，`i`被用来表示_电流_，两种用法会冲突。

R 选择了`i`，Python 选择了`j`，而 Julia 则用`im`绕开了这场争议。
在 [STEM][wiki-STEM] 编程语言之间切换时要多加小心。

要单独访问复数的各个部分：

```r
z <- 2+3i

Re(z)  # real part
#> [1] 2

Im(z)  # imaginary part
#> [1] 3
```

任一部分都可以为零，这时数学家会说这个数是“纯实数”或“纯虚数”。
不过它在 R 中仍然是复数。

```r
1.2 + 0i
#> [1] 1.2+0i

typeof(1.2 + 0i)
#> [1] "complex"

2i
#> [1] 0+2i

typeof(2i)
#> [1] "complex"
```

你可能听说过“`i`（或`j`）是 -1 的平方根”。

就目前而言，这只是说虚部_按定义_满足下面这个等式：

```r
1i * 1i == -1  # more precisely, 1i * 1i == -1 + 0i
#> [1] TRUE
```

这是一个简单的想法，却能引出有趣的推论。

## 算术

用于浮点数和整数的大多数运算符也同样适用于复数：

```r
z1 = 1.5 + 2i
z2 = 2 + 1.5i

z1 + z2  # addition
#> [1] 3.5+3.5i

z1 * z2  # multiplication
#> [1] 0+6.25i

z1 / z2  # division
#> [1] 0.96+0.28i

z1^2  # exponentiation
#> [1] -1.75+6i

2^z1  # another exponentiation
#> [1] 0.518895+2.780422i
```

## 函数

大多数数学函数都能接受复数输入。

除了`Re()`和`Im()`之外，还有几个函数与复数特别相关。

- `Conj()`只是把复数虚部的符号取反（_从 + 变成 -，反之亦然_）。
  - 由于复数乘法的运算方式，它比你想象的更有用。
- `abs(<complex number>)`保证返回一个没有虚部的实数（它的“模”），而`Mod(<complex number>)`是它的同义词。
- `Arg(<complex number>)`返回以弧度表示的相位角。

```r
z1
#> [1] 1.5+2i

abs(z1)
#> [1] 2.5

Mod(z1)  # same as previous
#> [1] 2.5

Conj(z1)  # flip sign
#> [1] 1.5-2i

Arg(z1)
#> [1] 0.9272952
```
