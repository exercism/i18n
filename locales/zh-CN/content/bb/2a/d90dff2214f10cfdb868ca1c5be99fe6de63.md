# 关于

C# 类型可以定义在类或结构体的作用域之内。外层类型提供了一种命名空间的作用。访问该类型要通过外层类型，并加上点语法。

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## 访问级别

访问级别同样可以应用到内部类型上。例如，如果一个类是`private`的，那么它在外层类型的作用域之外就看不到，当然，其实例在外层作用域之外也无法看到或使用。

外层类的私有成员都在内部类所有成员的作用域之内，但只有内部类的非私有成员才在外层类成员的作用域之内。要访问外层类的成员，必须把外层类的一个实例交给内部类。

下面的示例可以说明这一点：

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## 防止独立实例化

有一种模式可以避免可实例化的类型在外层类型之外被创建：对外公开一个公有接口，同时把实现类保持私有。

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## 写给 Java 开发者

C# 的嵌套类是 Java 静态嵌套类和内部类的混合体。在 C# 中，外层类的私有成员在嵌套类成员的作用域之内，但没有特殊的语法来实例化嵌套类并把它们和外层类的实例关联起来。你必须使用上面示例中展示的模式的某种变体。

C# 确实有静态嵌套类，不过它们只是具有静态行为的封闭类。
