# 关于

Factor 最初由 Slava Pestov 在 2002 年设计，是运行在 JVM 上、面向游戏引擎的一门脚本语言。从那以后，这个平台和生态系统已经有了长足的发展，语言核心本身也是如此。Factor 的标准库已经变得极其庞大，而它的实现，包括自举的原生代码优化编译器，现在几乎完全是用 Factor 写成的。

Factor 可以创建独立应用，甚至 GUI 应用，它们在 Linux、Windows 和 Mac OS 上的行为完全一致。

Factor 是一门简单却强大、富有表现力的栈式高级语言，风格承袭了 Forth、Joy 和 Lisp。它提出了一种拼接式（无参且可组合）的数据流模型，同时具备极强的可扩展性，以及一套源自 [CLOS](https://enwp.org/Common_Lisp_Object_System) 的对象系统。

同像性是 Factor 编程模型的重要组成部分。所有的值，包括函数和 Factor 代码块，都放在同一个栈上，可以用同样的方式操作。这是一个简单却强大的范式，它能引出有趣的问题解法，也带来了无限的扩展性。

Factor 要求读者有一种不同于 C 或 Python 的思维方式。由于它采用可组合的编程模型，每个函数的输出都会作为下一个函数的输入。函数可以把其他函数，或者字面量 Factor 代码块，当作输入。从这个角度看，它很像一条（单向的）Unix 管道，却远比管道先进，同时又更简单。这需要花些时间才能适应，但交互式开发和 re-**Factor**ing 都受到鼓励，用起来也会变得相当有趣。

Factor 编程语言是开源的，你可以在 [GitHub](https://github.com/factor/factor) 上找到它，那里有活跃的开发。

如果你刚开始接触 Factor，哪怕只是一点点，都强烈建议你在继续之前先读一读 Factor 文档中的 [Factor 秘籍](https://docs.factorcode.org/content/article-cookbook.html) 和 [你的第一个程序](https://docs.factorcode.org/content/article-first-program.html) 部分。

## Factor 术语表

* **单词** 本质上是一个函数，它从**栈**上取参数，并把值返回给**栈**。所有单词都必须声明栈效果。Factor 语法的所有元素都是**单词**，因此定义新语法非常容易。
* **词汇表** 一组按目录或源文件组织起来的**单词**，类似于其他语言中的模块或库。
* **栈** 一个后进先出的列表，存放着对动态类型值的引用，所有操作都基于它；它是函数之间传递数据的主要方式。这只是实现细节；Factor 的大部分内容都可以用项重写来实现。
* **程序** 在运行时操作**栈**的一系列**单词**。这为这门语言提供了强大的基础，让许多抽象和范式都能构建在其之上。
