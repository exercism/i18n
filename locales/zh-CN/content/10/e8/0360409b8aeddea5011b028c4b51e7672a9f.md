# 提示

## 通用

- 阅读官方[字符串指南][string-guide]。
- 浏览[字符串可用的方法][string-methods]。

## 1. 清理名字

- 有一个[内置方法][string-replace]，可以替换字符串中所有出现的子串。
- 有一个[内置方法][string-strip]，可以去掉字符串开头和结尾的空白字符。

## 2. 获取名字的首字母

- 要从字符串中取出某个字符，可以使用[下标运算符][string-indexing]。

## 3. 把首字母格式化为缩写形式

- 有一个[内置方法][string-upcase]，可以把字符串中的所有字符转换为大写形式。

## 4. 把缩写放进爱心里

- 有一种特殊语法，可以把表达式[插值][string-interpolation]到字符串里。
- 你可以用转义的方式在字符串里放一个爱心表情符号：`\u<id>`，爱心表情符号的 id 是 `2764`。
