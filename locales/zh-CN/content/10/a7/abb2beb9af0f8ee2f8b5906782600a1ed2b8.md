# 简介

C# 是一种静态类型语言，这意味着一切在编译时都有类型。把值赋给一个名字，称为定义变量。定义变量时，既可以显式指定它的类型，也可以让 C# 编译器根据所赋的值推断它的类型（称为_类型推断_）。因此，下面两种变量定义是等价的：

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

更新变量的值要通过`=`运算符来完成。变量一旦定义，它的类型就永远不能改变。

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# 是一种[面向对象语言][object-oriented-programming]，它要求所有函数都定义在_类_中。`class`关键字用来定义类。对象（或_实例_）通过`new`关键字创建。

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

类中的函数称为_方法_。每个方法可以有 0 个或多个形参。所有形参都必须显式指明类型，形参没有类型推断。同样，返回类型也必须显式写出。方法使用`return`关键字返回值。要让其他文件中的代码能够调用某个方法，必须加上`public`访问修饰符。

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

调用方法时，要在实例上使用点号（`.`）语法，指定要调用的方法名，并为方法的每个形参传入实参。实参可以选择指定对应形参的名字。

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

C# 中的作用域定义在`{`和`}`字符之间。

C# 支持两种注释。单行注释以`//`开头，多行注释则写在`/*`和`*/`之间。
