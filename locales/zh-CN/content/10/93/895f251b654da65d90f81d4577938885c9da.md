# 说明

艾伦正在制作一款游戏，玩家要在游戏中与外星人战斗。
她刚刚学习了面向对象编程（OOP），迫不及待地想利用`classes`为她的程序带来的好处。

令艾伦高兴的是，你主动提出帮忙，于是她把这个任务交给了你：编写玩家要与之战斗的外星人程序。


## 1. 创建 Alien 类

定义一个 Alien 类，它的构造函数接受两个形参`<x_coordinate>`和`<y_coordinate>`，并把它们分别存入`x_coordinate`和`y_coordinate`两个实例变量。
每个外星人一开始的生命值都是 3，所以`health`变量也要初始化。

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

现在，每个外星人都应该能在内部跟踪自己的位置和生命值。

## 2. `hit`方法

艾伦希望 Alien 的`class`拥有一个`hit`方法，调用时能把外星人对象的生命值减 1。
这样，她只要调用`<alien>.hit()`就行，不必手动修改外星人的生命值。
`hit()`是把生命值减到零、还是减到零以下，由你决定。

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. `is_alive`方法

你意识到，如果生命值不断下降，某个时刻它很可能会降到 0（甚至更低！）。
最好加上一个`is_alive`方法，让艾伦能快速调用，检查外星人是不是……嗯……还活着。😉
`<alien>.is_alive()`应该返回一个布尔值。

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. `teleport`方法

在艾伦的游戏里，外星人拥有瞬移的能力！
你需要写一个`teleport`方法，接受新的`x_coordinate`和`y_coordinate`值，并相应地修改外星人的坐标。

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. `collision_detection`方法

显然，如果外星人会被什么东西击中，它们就得能检测到这种碰撞何时发生。
不过，碰撞检测算法可能很棘手，而你目前还不知道如何实现。
艾伦说她以后再实现，但她还是希望类里先出现`collision_detection`方法，提醒自己要把这个功能做出来。
它需要接受某种变量（很可能是另一个对象），不过你目前知道的就这些。
你要确保把方法定义放进类里后，调用它时不会出现任何错误：

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. 外星人计数器

艾伦又回来找你，提出了一个新需求。
她想记录游戏运行期间一共创建了多少个外星人。
她说这和计分系统有关。

例如：

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```

## 7. 创建外星人数组

艾伦很喜欢你目前做的一切，不过还想请你帮最后一个忙。
她想要一个独立的函数（位于`Alien()`类之外），给定一个位置数组（用`tuples`表示），它能创建一个由`Alien()`对象组成的`list`。

例如：

```python
>>> alien_start_positions = [(4, 7), (-1, 0)]
>>> aliens = new_aliens_collection(alien_start_positions)
...
>>> for alien in aliens:
...     print(alien.x_coordinate, alien.y_coordinate)
(4, 7)
(-1, 0)
```
