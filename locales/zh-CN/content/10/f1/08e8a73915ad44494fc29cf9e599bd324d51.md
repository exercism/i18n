# 安装

安装 Zig 的方法有很多，而且随着这门语言日渐成熟，安装 Zig 的方式还在不断增加。
好在所有主流的安装方式都列在 [Zig 安装页面][install-zig] 上。

## Zig 版本

Exercism 目前只支持 Zig 0.16.0（发布于 2026-04-14）。

某个练习可能兼容其他 Zig 版本，但这并没有保证。
Zig 尚未发布 1.0 版本，破坏性变更很常见。

## 其他工具

### Zig fmt：生成格式良好的代码

完成任何练习时，你都可以在解答中使用各种代码风格。
不过，在做练习之外的场合，比如开发应用或库时，让代码保持一致、易于阅读通常是个好主意。
当别人想要帮你处理项目、不得不读你的代码时，这一点尤为重要。

为了解决这个问题，Zig 编译器内置了一个轻量的[代码检查工具][linters]，可以方便地格式化你的代码。
这个代码格式化工具遵循 [Zig 文档][documentation]中已经确立的[风格指南][style-guide]。

要查看 Zig 自带格式化工具的功能，请使用以下命令：

```bash
zig fmt --help
```

### Zig Zen：写代码的准则

做任何任务时，一点指引有时都能起到很大作用，写代码也一样。
好在 Zig 编译器里内置了一个有趣的命令，可以提醒我们写出优秀 Zig 代码的一些目标。

想看看这些至理名言，可以使用以下命令：

```bash
zig zen
```

### Zig 语言服务器：全面的 Zig 编辑器支持

这款第三方软件提供编辑器补全和增强的 Zig 代码导航功能，可以帮你更快地学会这门语言。

最新安装说明请见 [ZLS 安装指南][install-zls]。
