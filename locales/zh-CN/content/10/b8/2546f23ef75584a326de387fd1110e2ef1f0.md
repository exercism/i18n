# 说明

在这个练习中，你将编写代码，使用`Map`来管理一个国际电话区号的字典。

字典可以用国际电话区号（映射的键，类型为`Integer`）来查找国家名称（映射的值，类型为`String`），

## 1. 以映射的形式返回这些区号

实现`getCodes`方法，它不接受任何形参，返回字典中当前的区号到国家的映射。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. 向字典中添加条目

字典需要被填充。
实现`setDialingCode`方法，它接收一个电话区号和对应的国家，并添加该电话区号和国家。
如果电话区号已经在映射中，就用提供的区号和国家更新映射。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. 查找某个电话区号对应的国家

实现`getCountry`方法，它接收一个电话区号，返回该电话区号对应的国家名称。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. 不要允许重复项

添加电话区号时，需要注意防止同一个区号或国家被添加两次。
出现这种情况时，可以认为第一个条目才是正确的条目。
实现`addNewDialingCode`方法，为给定的电话区号和国家添加一个条目。
不过，与`setDialingCode`不同，如果该电话区号或国家已经在映射中，它什么也不做。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. 查找某个国家的电话区号

这种情况很少见，但还是可能出错。
要纠正这个错误，我们需要知道该国家当前映射到哪个电话区号。
为了找出哪个电话区号需要纠正，实现`findDialingCode`方法，它接收一个国家，返回该国家的电话区号。
如果该国家_不在_映射中，返回`null`。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. 更新国家的电话区号

现在我们知道了哪个电话区号需要纠正，接下来就更新这个区号。
实现`updateCountryDialingCode`方法，它接收国家的新电话区号和国家的名称，并相应地进行更新。
如果该国家_不在_映射中，就什么也不做（这个方法只是为了帮助纠正错误）。

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
