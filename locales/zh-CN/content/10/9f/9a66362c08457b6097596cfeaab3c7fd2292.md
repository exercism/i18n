# 简介

递归函数是调用自身的函数。

一个递归函数至少需要一个_基准情况_，以及至少一个_递归情况_。

_基准情况_会返回一个值，而不再调用函数本身。
_递归情况_会再次调用函数，并修改输入，使它最终能与基准情况匹配。

在 Elm 中，递归函数通常用 `case` 表达式或多条函数子句的模式匹配来定义。

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

## 通过递归实现循环

由于不可变性，Elm 中循环的写法与命令式语言不同。
例如，循环通常长这样：

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

在 Elm 这样的函数式语言中，无法对变量进行修改。
因此，循环必须用递归来实现。

Elm 中 `for`循环的等价写法如下：

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

实际上，在 Elm 中遍历数组和其他数据结构时，最常用的是 `List`模块里的函数，比如 `List.map`、`List.filter` 和 `List.foldl`。
在底层，这些函数都是用递归实现的。
