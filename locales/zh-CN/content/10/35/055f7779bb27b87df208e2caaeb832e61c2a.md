# 说明

一位博物学家正在为生活在火山口周围的龙编目。它们彼此共享一些特征，每条龙都有名字、颜色和年龄，但各自又有独特的专长。你将构建一棵小小的龙类继承树，以及一个能让任何后代变老的词。

## 1. 龙的家族

先一次性定义好整个元组类的继承树（它们的构造函数会在后面的任务中出现）：

- `dragon`，包含槽位 `name`、`color`、`age`。
- `fire-dragon`，`dragon`的子类，新增一个`flame-temp`槽位。
- `ice-dragon`，`dragon`的另一个子类，新增一个`chill-temp`槽位。
- `volcano-dragon`，`fire-dragon`的子类，新增一个`lava-volume`槽位。

然后给`dragon`一个`<dragon>`构造函数。

```factor
"Falkor" "white" 100 <dragon> name>> .   ! => "Falkor"
```

## 2. 喷火的龙

给`fire-dragon`一个`<fire-dragon>`构造函数。

```factor
"Smaug" "red" 500 1200 <fire-dragon> flame-temp>> .   ! => 1200
"Smaug" "red" 500 1200 <fire-dragon> dragon? .        ! => t
```

## 3. 喷冰的龙

给`ice-dragon`一个`<ice-dragon>`构造函数。

```factor
"Frosty" "blue" 200 -40 <ice-dragon> chill-temp>> .   ! => -40
"Frosty" "blue" 200 -40 <ice-dragon> fire-dragon? .   ! => f   (siblings)
```

## 4. 住在火山里的龙

给`volcano-dragon`一个`<volcano-dragon>`构造函数。

```factor
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> dragon? .       ! => t
"Vesuvius" "red" 1000 1500 99 <volcano-dragon> fire-dragon? .  ! => t
```

## 5. 让任何龙变老

定义`age-dragon`，把任何龙（或其后代）的`age`槽位加一。不返回任何值。

```factor
"Falkor" "white" 100 <dragon> dup age-dragon age>> .   ! => 101
```

同一个词应当对每个后代都有效，这正是共享访问器的意义所在。
