# 说明

你的任务是构建一个秒表，精确记录单圈时间。

秒表使用四个命令（start、stop、lap 和 reset）来记录：

1. 当前单圈记录的时间
2. 之前记录的单圈时间

能使用哪些命令取决于秒表处于哪种状态：

1. Ready：初始状态
2. Running：正在计时
3. Stopped：未在计时

| 命令 | 起始状态 | 结束状态 | 效果                                                   |
| ------- | ----------- | --------- | -------------------------------------------------------- |
| Start   | Ready       | Running   | 开始计时                                      |
| Start   | Stopped     | Running   | 恢复计时                                     |
| Stop    | Running     | Stopped   | 停止计时                                     |
| Lap     | Running     | Running   | 把当前单圈加入之前的单圈，然后重置当前单圈 |
| Reset   | Stopped     | Ready     | 重置当前单圈并清空之前的单圈                |
