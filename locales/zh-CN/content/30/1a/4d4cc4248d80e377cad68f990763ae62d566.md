# 关于

对象初始值设定项是构造函数之外的一种选择。它的语法是一个用逗号分隔的“字段名=值”对列表，如下所示：

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

集合也可以用这种方式初始化。通常，这是通过如下所示的逗号分隔列表来完成的：

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

这种方法（以及这种语法）可以用于任何实现了`IEnumerable`并且有`Add()`方法的类。

字段可以按任意顺序列出，也可以完全省略。

字典使用以下语法：

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

被初始化的字段必须对调用方可见。通常这意味着它们必须是`public`或`internal`。

在语言的设计者和顶尖实践者当中，有一股推动不可变性的强烈潮流，因此以这种方式初始化的对象具有可变性，会被看作一个缺点。有人提议在该语言即将发布的版本 C# 9 中引入`init`子句，这或许能解决这一问题。
