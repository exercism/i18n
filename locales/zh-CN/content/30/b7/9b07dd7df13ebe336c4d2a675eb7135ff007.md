# 提示

## 1. 把遇到的空格替换成下划线

内置的 `clojure.string` 库中有一个 [`replace`][str-replace] 函数。

## 2. 把控制字符替换成大写字符串 “CTRL”

可以使用 Java `Character` 类中的 [`isISOControl`][java-ctrl] 方法。

## 3. 把 kebab-case 转换成 camelCase

试试用 [`split`][str-split] 按连字符拆分字符串。
如果字符串里没有连字符，就原样返回。可以用 [`includes?`][str-includes] 检查这一点。用 [`upper-case`][str-upper-case] 把驼峰部分变成大写。最后用 [`join`][str-join] 把它们拼接起来。

## 4. 省略不是字母的字符

可以用 [`Character/isLetter`][java-isletter] 作为谓词来过滤字符。

## 5. 省略希腊小写字母

希腊小写字母是 Unicode 码位`\u03B1`到`\u03C9`，即整数值 945 到 969。
