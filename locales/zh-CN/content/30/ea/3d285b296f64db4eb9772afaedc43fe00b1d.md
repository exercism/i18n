# 简介

在 Clojure 中，把一个值绑定到一个名字上称为 _变量_。顶层（全局）变量与其他语言中的常量类似，但为了便于动态开发，通常会重新定义。

使用`def`定义顶层变量：

```clojure
(def fingers 10)
```

`defn`宏可以定义接受零个或多个实参的函数。函数总是返回其函数体中最后一个表达式的结果。

```clojure
(defn add [x y]
  (+ x y))
```

调用函数时，需要写出函数的名称，并为函数的每个形参传入实参。

```clojure
(def five (add 2 3))
```

Clojure 中的函数和值只能在定义 _之后_ 使用。在定义之前就使用它，会导致编译错误。

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

在 Clojure 中，空白除了用于排版之外没有任何意义。

Clojure 的函数和变量按命名空间组织。命名空间把相关的功能归为一组，使用`ns`宏定义：

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure 支持两种注释。单行注释以`;`开头，而`comment`形式用于阻止对`(comment`和`)`之间所有内容的求值。
