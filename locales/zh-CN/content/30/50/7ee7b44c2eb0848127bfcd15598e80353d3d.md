# 附加说明

## 提示

要完成本练习，你需要实现`score`函数：它接收一连串保龄球*投球*，并返回最终得分，或者返回相应的错误：

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

你会看到这些定义已经写好了，但函数本身要由你来定义。

请记住，测试套件期望投球的编号从 0 开始。
