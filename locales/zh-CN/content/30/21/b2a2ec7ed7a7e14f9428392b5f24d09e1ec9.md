# 说明

在这个练习中，你要写一些代码，帮你照着最爱的烹饪书做出一份美味的千层面。

你有三个任务，全都和烹饪千层面所花的时间有关。

## 1. 定义预计的烤箱时间（分钟）

定义`expectedMinutesInOven`这一项，用来查看千层面应该在烤箱里烤多少分钟。根据烹饪书，预计的烤箱时间是 40 分钟：

```
> expectedMinutesInOven
  ⧩
  40
```

## 2. 计算准备时间（分钟）

定义`preparationTimeInMinutes`函数，它接受你往千层面里加的层数作为参数，并返回你准备千层面花了多少分钟。假设每层需要 2 分钟准备。

```
> preparationTimeInMinutes 3
  ⧩
  6
```

## 3. 计算经过的时间（分钟）

定义`elapsedTimeInMinutes`函数，它接受两个参数：第一个参数是你往千层面里加的层数，第二个参数是千层面在烤箱里已经放了多长时间（分钟）。这个函数应该返回你制作千层面所用的总分钟数，它是准备时间（分钟）与千层面此刻在烤箱中度过的时间（分钟）之和。

```
> elapsedTimeInMinutes 3 20
  ⧩
  26
```
