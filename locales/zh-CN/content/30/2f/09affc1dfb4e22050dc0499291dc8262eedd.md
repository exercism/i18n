# 关于

`assocs`是一种[协议][assoc-protocol]，而不是单一的数据类型。哈希表（`H{ }`）、关联列表（由`{ key value }`对组成的序列）和树映射都实现了它，而且大多数用于 assocs 的单词在它们之间可以互换。

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

完整的接口很广（排序迭代、映射、过滤），但练习层面的大部分工作只涉及一小部分：

| 单词        | 作用                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )`，区分“值为 f”和“键不存在” |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )`，会就地修改            |
| `change-at` | `( key assoc quot -- )`，其中`quot`为`( old -- new )` |
| `inc-at`    | `( key assoc -- )`，即`+1`，键不存在时插入`1`   |
| `delete-at` | `( key assoc -- )`，会就地修改                  |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys`和`sort-values`（位于`sorting`中）会按选定的字段对 alist 排序。

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
