# 说明

在这个练习中，你将为一个位于纽约的美容院编写预约安排程序，这家美容院于 2012 年 9 月 15 日开业。

一共有五个任务，全都与预约日期有关。
时间采用 24 小时制（没有 AM/PM）。

## 1. 解析全数字格式的预约日期

实现 `schedule_appointment()` 函数，把以文本表示的预约日期解析成对应的 `DateTime` 格式。

注意，输入采用美式的月/日/年顺序。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 检查预约是否已经过去

实现 `has_passed()` 函数，它接受一个预约日期，并检查该预约是否在过去：

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 检查预约是否在下午

实现 `is_afternoon_appointment()` 函数，它接受一个预约日期，并检查该预约是否在下午（>= 12:00 且 < 18:00）：

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 描述预约的时间和日期

实现 `description()` 函数，它接受一个预约日期，并返回对该日期和时间的描述：

```julia-repl
julia> describe(DateTime(2023, 3, 29, 15, 0, 0))
"You have an appointment on Wednesday, March 29, 2023 at 15:00"
```

## 5. 返回周年纪念日

实现 `anniversary_date()` 函数，它返回今年的周年纪念日，也就是 9 月 15 日：

```julia-repl
julia> anniversary_date()  # run during 2025
2025-09-15
```
