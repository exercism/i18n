# 简介

元组把若干个具名值打包进一个对象，也就是其他语言中的记录、结构体或类。每个元组类都有一组固定的具名槽位，Factor 会自动为这些槽位生成取值器和赋值器。

## 定义元组

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

每个槽位都这样声明：`{ name initial: default-value }`。如果不写 `initial:` 子句，默认值就是`f`。

## 构造元组

最简单的构造器是`new`：

```factor
point new .
! => T{ point }
```

`boa`（“按参数顺序”）会按声明顺序从数据栈中依次填充各个槽位：

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

字面量语法 `T{ class { slot value } … }` 让你可以只设置一部分槽位来构造元组，打印输出也是同样的形式：

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

当槽位的值与其默认值相同时，打印器会省略它。

## 读取槽位

Factor 会为每个槽位生成一个取值器 `slot>>`。取值器都在[`accessors`][accessors]里：

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## 更新槽位

赋值器写作`>>slot`，会*原地修改*元组：

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

如果想保留原对象不变，先`clone`：

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot`接收一个引用，把当前值映射为新值：

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x`同样是原地修改，所以如果想保留原对象，调用它之前要先`clone`。
