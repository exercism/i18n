# 关于

想象你有一个几十万行的代码库。你正在开发的某个方法被传入了开发者字典。也许你接到的任务是打印出有特权的开发者的详细信息。为了保护开发者的隐私，你决定把字典里的眼睛颜色清空。除非 `Authenticator.GetDevelopers()` 方法里对字典做了[深拷贝][so-deep-copy]，或者更好的做法是把它包进只读集合，否则你刚刚就把认证器毁了。

这就是[防御性复制][defensive-copying]的原则。通过避免把内部可写状态暴露给调用方，你就能确保自己的正式 API 不会被绕过。

[so-deep-copy]: https://stackoverflow.com/questions/78536/deep-cloning-objects
[defensive-copying]: https://www.informit.com/articles/article.aspx?p=31551&seqNum=2
