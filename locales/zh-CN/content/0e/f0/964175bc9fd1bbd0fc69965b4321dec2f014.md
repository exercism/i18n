# 简介

C# 中的属性是类的成员，用于访问该类中的数据。调用方可以设置或获取（get）这些数据。属性既可以是自动实现的，也可以带有后备字段。属性包含一个 set 访问器和/或一个 get 访问器。在其他语言中，“修改器”大致相当于 set 访问器，“访问器”大致相当于 get 访问器，不过语法的构成完全不同。

设置属性时，可以对输入值进行验证、格式化或其他处理，事实上，类中的代码能够执行的任何程序化操作都可以执行。

同样，获取属性时，数据也可以被计算或格式化，而类中可用的任何程序化操作同样能够执行。

属性像其他类成员一样有访问修饰符（`public`、`private` 等），但 set 访问器的访问级别可以独立于获取（get）访问器，反之亦然。属性不必同时具有两个访问器，也可以只有一个（get 或 set 都行）。

表达属性的基本语法有两种形式：

## 基于字段或表达式的属性：

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## 自动实现的属性

```
public int MyProperty { get; private set; } = 42;
```

初始化是可选的。
