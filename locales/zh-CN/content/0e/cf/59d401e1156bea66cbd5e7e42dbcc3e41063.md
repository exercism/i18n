# 简介

`String`中的单个字符，可以通过与数组相同的下标方式来访问。不过，字符串使用的[下标][string-indices]并_不是_整数，不能直接拿来用。它们必须根据其他已知的下标计算出来，比如`startIndex`，它指向非空字符串中第一个字符的位置；计算时要用到 [`String`][string-docs] 和 [`NSString`][nsstring-docs] 这两个库提供的方法（导入`Foundation`模块后，Swift 中的字符串就能使用 NSString 的全部属性和方法）。

例如，有下面这个字符串：

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

不能通过写`csv[21]`来取得“orange”中的“g”，必须改为计算出一个`String.Index`类型的值，再用这个下标来取字符。注意，这些下标本身并不是给人直接使用的。它们就是所谓的_不透明下标_，因为人不需要知道里面装着什么。

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

不过要注意，如果偏移量指向的不是有效下标，也就是算出的下标位于`startIndex`之前或`endIndex`之后，这个操作就会报错，导致程序崩溃。为了避免这个问题，可以指定一个用于限制的下标。这样返回的就是一个可选类型的下标；对于本来无效的下标，它会返回 nil。

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

另外，下标不能在不同字符串之间共用。比如，用上面算出的“orange”中“g”的`index`去索引字符串`fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`，也就是写`fam[index]`，会让程序崩溃。

造成这些现象的原因有很多，但归根结底就是一句话：“Unicode 很棘手”。

一般来说，如果你需要随机访问单个字符，那么最好换用别的数据结构，比如`Array<Character>`。

## 一些有用的方法

Swift 提供了`first`和`last`方法，用来获取字符串的第一个和最后一个字符。这两个方法返回的是可选类型的字符，所以如果字符串为空，它们会返回 nil。

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

你也可以用`prefix`和`suffix`方法获取字符串的子串。这两个方法接受一个整数作为实参，返回包含字符串前 n 个或后 n 个字符的子串。

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
