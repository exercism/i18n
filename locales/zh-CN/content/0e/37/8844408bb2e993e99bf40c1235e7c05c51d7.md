# 资源

- [The Zig Programming Language Documentation][documentation] 全面概述了 Zig 为使用者提供的所有语言特性。
- [The Zig Standard Library][std] 是学习如何编写 Zig 代码的优质参考，还展示了许多可以导入到自己代码中的函数。
- [Awesome Zig][awesome-zig] 是一份精心整理的 Zig 项目列表。
- irc.freenode.net 上的 [#zig][irc] 是主要的 Zig IRC 频道。
- [Stack Overflow][stack-overflow] 可以用来查找代码片段，以及那些别人可能已经问过、也许已经解决过的问题的解答。
- [/r/Zig][reddit] 是主要的 Zig 子版块。
- [The Zig Programming Language Discord][discord-zig] 是主要的 [Discord][discord] 服务器。
  它让你能方便地与整个 Zig 社区取得联系，也能快速获得针对各种 Zig 相关问题的直接帮助。
- [The Zig SHOWTIME Newsletter][newsletter] 发布新一期节目、重要活动，以及有趣的新 Zig 项目链接。
