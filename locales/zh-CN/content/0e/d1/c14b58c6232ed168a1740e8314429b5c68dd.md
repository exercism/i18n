# 类型转换

类型转换有时也被称为类型强制转换。
类型转换指的是把两个不同类型的值转换成同一种类型，以便执行某个运算。

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

这可以是隐式的（见上面的例子），也可以是显式的，比如使用 `C` 风格的强制类型转换：

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

手动转换时允许的类型有：`bool`、`int`、`float`、`string`、`array`、`object`。
最常见的情况，是用类型转换把整数（`int`）变成浮点数（`float`），或者反过来。
