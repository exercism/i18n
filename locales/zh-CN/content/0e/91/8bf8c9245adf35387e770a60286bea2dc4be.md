# 关于

浮点数就是小数点后带有零位或多位数字的数，例如`4.0`、`0.1`、`3.14`、`-6.4`、`16.984025`和`1024.0`。
在 Ruby 中，浮点数是通过 [Float][Float] 类实现的。

你可以在 [0.30000000000000004.com][0.30000000000000004.com] 找到一篇关于浮点数的简短介绍。

[Float Toy 页面][evanw.github.io-float-toy]用直观的图解说明了浮点数的二进制位是如何转换成实际的浮点数值的。

要重复执行一段逻辑，可以使用循环。
在这个例子中，`while`循环很有用，因为它会一直循环，只要某个条件求值为真值（即不是`false`或`nil`）。
Ruby 实现了一种与`while`循环类似的循环。
它叫做`until`循环，你大概已经猜到它的作用了。
它会一直循环，直到某个布尔条件求值为`true`。
在某些语言中，为了让一段代码无限次执行，会使用`while true`这样的写法。
在 Ruby 中，`loop`循环正是为此而存在的。
虽然`loop`循环不依赖单个条件，但可以用`return`或`break`关键字来终止它。

前一个练习中的`#years_before_desired_balance`方法，本可以用上面提到的这三种循环中的任意一种来写：

## `while`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  while current_balance < desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `until`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  until current_balance >= desired_balance
    current_balance = annual_balance_update(current_balance)
    years += 1
  end
  years
end
```

## `loop`

```ruby
def self.years_before_desired_balance(current_balance, desired_balance)
  years = 0
  loop do
    current_balance = annual_balance_update(current_balance)
    years += 1
    return years if current_balance >= desired_balance
  end
end
```

你可能已经注意到，Ruby 不像其他一些语言那样有自增运算符（`i++`）。
取而代之，可以使用像`i += 1`这样的写法（它等同于`i = i + 1`）。
