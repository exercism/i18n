# 关于

[`for`循环][for-statement]可以重复执行一段代码，直到满足某个条件。

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

一个`for`循环由四部分组成：

1. 初始化器：在进入循环之前执行一次。通常用来定义循环内部用到的变量。
2. 条件：在每次循环迭代之前执行。只要它求值为`true`，循环就继续执行。
3. 迭代器：在每次循环迭代之后执行。通常用来修改（往往是自增/自减）循环变量。
4. 循环体：每次循环迭代时执行的代码。

## for 循环与 foreach 循环

一般来说，比起`for`循环，[concept:csharp/foreach-loops]()更可取，原因如下：

- `foreach`循环保证会迭代_所有_值。使用`for`循环时，很容易漏掉元素，比如因为差一错误。
- `foreach`循环更_声明式_，代码表达的是你_想要做什么_，而`for`循环表达的是_想要怎么做_。
- `foreach`循环万无一失，而`for`循环很容易出现差一错误。
- `foreach`循环适用于所有集合类型，包括不支持用索引器访问元素的类型。

为了保证`foreach`循环会迭代_所有_值，编译器不允许在`foreach`循环内部更新集合：

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

相比于`foreach`循环，`for`循环确实有一些优势：

- 可以从任意想要的下标开始或结束。
- 可以使用任意（布尔）终止条件。
- 可以通过自定义循环变量的自增方式来跳过元素。
- 可以通过递减计数从后往前处理集合。
- 可以在不涉及集合的场景中使用`for`循环。
