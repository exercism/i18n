# 简介

`Map` 用于存储**键**与**值**的配对。`Maps` 的初始化方式和数组一样，只是要用到映射字面量运算符`=>`。你既可以显式定义键和值的类型，也可以让类型自动推断。键必须唯一，否则就会抛出错误。

```haxe
var map1:Map<Int, String> = [1 => "one", 2 => "two", 3 => "three"];

var map2 = ["one" => 1, "two" => 2, "three" => 3];

var map3 = [1 => "cat", 1 => "dog"]; // Error: Duplicate Key

var map4 = ["h" => "Hello", "b" => "Bye"];
trace(map4["h"]); // Hello
```

可以用`for`循环来迭代`Map`。你可以迭代它的值，也可以迭代它的键：

```haxe
for (value in map) {
  // ...
}

for (key in map.keys()) {
  // ...
}
```
