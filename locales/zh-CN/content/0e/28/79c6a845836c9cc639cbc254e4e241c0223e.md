# 简介

命名空间用于把相关的代码组织在一起，并避免命名冲突，除了最简单的代码库之外，几乎到处都能见到。

语法如下：

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

在命名空间外部引用其中的类型时，需要在类型名前加上点语法作为前缀。另一种更常见的做法是，在文件顶部（或命名空间内部）放置`using`指令，这样使用类型时就无需再加前缀。在同一个命名空间内，类型名无需限定。

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

你可以用`using MyAlias = MySpace;`这样的语法给命名空间起别名，之后凡是能用该命名空间的地方，都可以使用这个别名。
