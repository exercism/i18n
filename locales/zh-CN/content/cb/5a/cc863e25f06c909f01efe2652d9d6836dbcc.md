# 说明

作为一名国际象棋爱好者，你想自己写一个版本的国际象棋游戏。没错，网上可能已经有很多现成的国际象棋实现，但你的会是独一无二的！

你先从实现一个棋盘开始。

这盘棋将在一个宽 8 格、长 8 格的棋盘上进行，每个格子由一个字母和一个数字标识。

## 1. 定义排和列的范围

程序需要存储棋盘上的排。排就是棋盘的行，从 1 到 8 编号。

程序还需要存储棋盘上的列。列就是棋盘的纵列，用字母 A 到 H 标识。

定义`ranks`和`files`常量，分别存储排和列的范围。

```swift
ranks
// Returns 1..8

files
// Returns "A".."H"
```

## 2. 检查格子是否有效

程序需要检查一个格子是否有效。如果格子的排和列都在排和列的范围内，这个格子就有效。

定义`isValidSquare(rank:file:)`方法。它接受`rank`和`file`两个形参，`rank`存放表示排号的`Int`，`file`存放表示列号的`String`。如果排和列都在相应范围内，该方法返回`true`，否则返回`false`。

```swift
isValidSquare(rank: 1, file: "A")
// Returns true
```

## 3. 获取一行

程序会把棋盘上所有格子存进一个一维数组。每个格子由排和列拼成一个字符串，例如 “1A”、“8B”、“4G” 等。要获取某个格子所在的行，程序需要算出这一行第一个格子的下标。

定义`getRow(rank:)`方法。它接受形参`rank`，其中存放表示排号的`Int`。该方法应返回一个字符串数组，表示这一行的各个格子。

```swift
let board = ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H", "2A", ..., "8H"]
getRow(board, rank: 1)
// Returns ["1A", "1B", "1C", "1D", "1E", "1F", "1G", "1H"]
```
