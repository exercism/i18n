# 说明

在这个练习中，你将创建一些用于银行运作的常量。

你有 5 个任务：

## 1. 表示贷款的固定利率

创建一个无类型数值常量`FixedInterestRate`来保存 5%（5/100）的值，然后实现`GetFixedInterestRate`函数返回它：

```go
GetFixedInterestRate()
// => 0.05
```

## 2. 表示一年中的天数

创建一个`int`类型的常量`DaysPerYear`来保存 365 这个值，然后实现`GetDaysPerYear`函数返回它：

```go
GetDaysPerYear()
// => 365
```

## 3. 表示一年中的月份

在一个代码块中，使用 Go 的枚举器创建 12 个无类型数值常量，用来保存 1 到 12 这些值，分别对应一年中的各个月份。把它们命名为`Jan`、`Feb`、`Mar`等，然后实现`GetMonth`函数，返回给定月份对应的值：

```go
GetMonth(Jan)
// => 1
```

## 4. 表示账号

创建一个无类型字符串常量`AccountNo`来保存 XF348IJ 这个值，然后实现`GetAccountNumber`函数返回它：

```go
GetAccountNumber()
// => "XF348IJ"
```
