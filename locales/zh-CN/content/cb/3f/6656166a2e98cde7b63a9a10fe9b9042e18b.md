# 说明

在这个练习中，你将操作一辆遥控车，你终于攒够了钱把它买下来了。

遥控车出厂时电池是满的（100%）。每次使用遥控器驾驶这辆车，它会行驶 20 米，并消耗百分之一的电量。

这辆遥控车有一个炫酷的 LED 显示屏，可以显示两项信息：

- 总行驶距离，显示为：`"Driven <METERS> meters"`。
- 剩余电量，显示为：`"Battery at <PERCENTAGE>%"`。

如果电池电量为 0%，你就不能再驾驶这辆车了，电池显示屏会显示 `"Battery empty"`。

你有六个任务，每个任务都会操作遥控车实例。

## 1. 购买一辆全新的遥控车

实现（_static_）`JedliksToyCar.buy()`方法，返回一个全新的遥控车实例：

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. 显示已行驶的距离

实现`JedliksToyCar.distanceDisplay()`方法，返回 LED 显示屏上显示的距离：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. 显示电池电量百分比

实现`JedliksToyCar.batteryDisplay()`方法，返回 LED 显示屏上显示的电池电量百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. 驾驶时更新行驶的米数

实现`JedliksToyCar.drive()`方法，更新行驶的米数：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. 驾驶时更新电池电量百分比

更新`JedliksToyCar.drive()`方法，以更新电池电量百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. 电池耗尽时阻止驾驶

更新`JedliksToyCar.drive()`方法，使其在电池耗尽（电量为 0%）时，既不增加行驶距离，也不减少电池电量百分比：

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
