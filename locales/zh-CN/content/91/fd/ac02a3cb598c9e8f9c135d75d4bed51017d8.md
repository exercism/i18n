# 简介


PowerShell 用[`bool`][booleans]类型来表示 true 和 false 值。
这个类型里只有两个值：`True`和`False`。
你可以用`$`前缀把这些值绑定到变量上：

```powershell
> $TrueVar  = $true
> $FalseVar = $FALSE
#Case senstitivity doesn't matter here
```

我们可以使用`-and`、`-or`和`-not`等[逻辑运算符][logical-operators]来组合和计算布尔表达式。

```powershell
> $TrueVar  = $true -and $true
> $FalseVar = $true -and $false

> $TrueVar  = $true -or $false
> $FalseVar = $false -or $false

> $TrueVar  = -not $false
> $FalseVar = -not $true
```
