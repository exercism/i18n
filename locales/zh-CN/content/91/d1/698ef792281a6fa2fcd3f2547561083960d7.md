# 简介

## 位运算

位运算允许我们操作二进制数中的单个位。

Elm 在其 [Bitwise 模块](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)中提供了几个位运算符。

### 基本运算

修改数字的单个位称为_掩码操作_。
_掩码_是一个数字，其中特定的位已按特定方式设置，从而使用像 `and`、`or` 和 `xor` 这样的位运算符来操作另一个数字。

#### and

`and`通过只保留两个数中都是 `1` 的位来合并两个数。
这对于检查单个位是否已设置很有用。
例如，要检查数字的第 4 位是否设置为 `1`，可以用掩码`01000`（十进制中的`8`）对它进行 `and` 运算，然后看结果是否非零：

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

#### or

`or`通过以下方式合并两个数：如果某一位在其中一个或两个数中为 `1`，就将这一位设置为 `1`。
这对于将特定的一位设置为 `1` 很有用。
例如，要将 `10101` 中的第 2 位设置为 `1`，可以用掩码`00010`对它进行 `or` 运算：

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

#### 异或（xor）

`xor`通过以下方式合并两个数：如果某一位在一个数中为 `1`，而在另一个数中为 `0`，就将这一位设置为 `1`。
这对于将某一位翻转为相反值很有用：

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

#### 取反

`complement`会将数字的每一位取反（`0` 变成 `1`，`1` 变成 `0`）。

注意，这会导致正数变成负数，负数变成正数。
这是因为二进制中的负数在最左边的位置上用 `1` 表示。

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

#### 位移

以下运算符将位向左或向右移动指定的位数，实际上相当于乘以或除以 2 的幂。

`shiftLeftBy`将位向左移动，从右侧补 `0`。
例如，要将 `21` 左移 3 位：

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

这相当于说`21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`：将位向右移动：

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

向右移动 2 位等同于整数除以 4。

注意，这个函数会复制最左边位上的值。
因此，负数仍会保持为负数：

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

如果你想右移并用零填充，请使用 `shiftRightZfBy`：

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
