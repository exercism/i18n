# 说明

从前，有一位古怪的程序员，住在一座装着铁栅栏窗户的奇怪房子里。一天，他从一个在线招聘网站上接下一份工作：做一个派对机器人。这个机器人应该负责迎接客人，并把他们领到座位上。第一版做得非常技术化，暴露出这位程序员不擅长与人打交道。其中有些毛病也延续到了下一版。

## 1. 欢迎派对上的新客人

实现`Welcome`函数，用给定的名字返回一条欢迎信息：

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. 欢迎今天过生日的新客人

实现`HappyBirthday`函数，根据这个人的名字和年龄返回一条生日祝福信息。
遗憾的是，这位程序员有点爱炫耀，所以机器人必须展示出它知道每位客人的生日。

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. 指路

实现`AssignTable`函数来指路。
它应该接受 5 个形参。

- 要迎接的新客人的名字（`string`）
- 桌号（`int`）
- 邻座的名字（`string`）
- 桌子所在的方向（`string`）
- 到桌子的距离（`float64`）

确切的结果格式见下面的示例。

机器人会以 3 位数字的格式给出桌号。
如果数字不足 3 位，就会在前面补零，凑成 3 位（例如 3 变成 003）。
机器人还会提到桌子的距离。
幸运的是，精度只保留 1 位小数。

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
