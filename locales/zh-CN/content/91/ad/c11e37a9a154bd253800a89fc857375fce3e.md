# 关于

`SYMBOL:`并不*保存*值，它只是一个名字。值存放在命名空间里，名字就是访问它的键。

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

两种作用域：

- **全局**：用`set-global`、`get-global`、`change-global`写入和读取。值在进程的整个生命周期内一直存在。
- **动态**：用`set`、`get`、`change`写入和读取。绑定在`with-variable`形式的持续期间内存在，让外层代码可以“注入”一个值，供内层代码看到，而无需修改中间每一层的签名。

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:`和`SYMBOLS:`会在词汇表加载时声明符号，使它们成为可跨文件共享的引用。
