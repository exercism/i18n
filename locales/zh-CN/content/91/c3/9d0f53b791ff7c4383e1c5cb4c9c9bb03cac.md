# 说明

准魔术师 Elyse 继续着她的训练。
她会拿到几副牌，并用它们来完成自己的魔术表演。
为了方便起见，她只用 1 到 10 这些牌。
每种牌她只有一张，牌堆里没有重复的牌。

在本练习中，使用 Julia 的 Base 库中的方法来分析数组的内容。

## 1. 判断某张牌是否存在

Elyse 想知道某张牌是否在牌堆中，换句话说，牌堆里是否包含某个特定的数字。

```julia-repl
julia> card = 3;

julia> has_card([2, 3, 4, 5], card)
true
```

## 2. 找出某张牌的位置

Elyse 想知道某张牌在牌堆中的位置（下标）。
如果这张牌不在牌堆里，返回 `nothing`。

```julia-repl
julia> card = 2;

julia> find_card([9, 7, 3, 2], card)
4
```

## 3. 判断每张牌是否都是偶数

Elyse 想知道是否每张牌都是偶数，换句话说，牌堆里的每个数字是否都是偶数。

```julia-repl
julia> all_cards_even([2, 4, 6, 7])
false
```

## 4. 检查牌堆里是否有奇数牌

Elyse 想知道牌堆里是否有奇数。

```julia-repl
julia> any_odd_cards([3, 2, 6, 4, 8])
true
```

## 5. 找出第一张偶数牌的位置

Elyse 想知道第一张偶数牌的位置。
如果牌堆里没有偶数牌，返回 `nothing`。

```julia-repl
julia> first_even_card_idx([5, 2, 3, 1])
2
```

## 6. 从牌堆中取出第一张奇数牌

Elyse 想知道第一张奇数牌的值。
如果牌堆里没有奇数牌，返回 `nothing`。

```julia-repl
julia> first_odd_card([4, 2, 8, 7, 9])
7
```
