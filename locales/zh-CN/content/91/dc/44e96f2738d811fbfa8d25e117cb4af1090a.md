# 说明

作为一名国际象棋爱好者，你想写出自己的版本。没错，网上可能已经有很多现成的国际象棋实现，但你的独一无二！

首先，你要为棋子实现一套基本的移动系统。

这盘棋将在一个 8 格宽、8 格长的棋盘上进行。每个格子用一个字母和一个数字来标识。

## 1. 定义行与列的范围

游戏需要存储棋盘的行。行是棋盘的横排，编号从 1 到 8。

游戏还需要存储棋盘的列。列是棋盘的纵列，用字母 A 到 H 标识。

定义`Chess::RANKS`和`Chess::FILES`常量，分别存储行和列的范围。

```crystal
Chess::RANKS
# => 1..8

Chess::FILES
# => 'A'..'H'
```

## 2. 检查格子是否有效

游戏需要检查一个格子是否有效。如果格子的行和列都在行与列的范围内，这个格子就是有效的。

定义`Chess.valid_square?`方法，它接收`rank`和`file`两个实参：`rank`保存表示行的整数，`file`保存表示列的字符。如果行和列都在行与列的范围内，方法应返回`true`，否则返回`false`。

```crystal
Chess.valid_square?(1, 'A')
# => true
```

## 3. 获取玩家的昵称

游戏需要获取玩家的昵称。昵称由玩家名字的前两个字符和姓氏的后两个字符组成。昵称应该大写。

定义`Chess.nickname`方法，它接收`first_name`和`last_name`两个实参，分别保存玩家名字和姓氏的字符串。方法应以大写字符串的形式返回玩家的昵称。

```crystal
Chess.nickname("John", "Doe")
# => "JOOE"
```

## 4. 创建移动消息

游戏需要为一次移动创建一条消息，说明哪位玩家移动到了哪个格子。消息中要用到玩家的昵称和他们移动到的格子。游戏还必须检查格子的列和行是否都在列与行的范围内，从而判断这步移动是否有效。

如果移动有效，消息应该是：`"{nickname} moved to {square}"`
如果移动无效，消息应该是：`"{nickname} attempted to move to {square}, but that is not a valid square"`

定义`Chess.move_message`方法，它接收三个实参：`first_name`保存玩家名字的字符串，`last_name`保存玩家姓氏的字符串，`square`保存玩家移动到的格子的字符串。方法应以字符串的形式返回这步移动的消息。

```crystal
Chess.move_message("John", "Doe", "A1")
# => "JOOE moved to A1"
```
