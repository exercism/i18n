# 关于

浮点数是带有小数点的数，既可以是小数，也可以是整数（如 `3.14`、`-1.7`、`99.99`、`2048.0`）。

Common Lisp 中的浮点类型又细分为几个子类型，每个子类型都有自己的特性和精度：short-float、single-float、double-float 和 long-float。

short-float 子类型通常占用的内存最少，精度也是四个子类型中最低的。它适合内存占用需要关注、但对精度要求不高的场景。

single-float 子类型在内存占用和精度之间取得了平衡，常用于通用的浮点计算。

与 single-float 相比，double-float 子类型的精度更高，适合需要更精确计算的应用，比如科学计算和数值模拟。

long-float 子类型在四个子类型中精度最高，但相比其他子类型可能需要更多内存。它通常用于对计算精度要求极高的专门应用。

有了这些子类型，Common Lisp 程序员就可以根据自己应用的具体需求，选择合适的精度和内存占用量。

一般来说，如果你只处理整数，就应该优先使用整数，因为在大量计算中，整数不会像浮点数那样损失精度。

## 参考

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
