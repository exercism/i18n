# 说明

你的任务是解析 GPS 坐标。每个坐标都采用[十进制度数格式](https://en.wikipedia.org/wiki/Decimal_degrees)的变体，并显式标注半球：

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

每个组成部分的允许取值如下：

- `<LATITUDE_DEGREES>`：范围 0..90（含）内的浮点数
- `<LATITUDE_HEMISPHERE>`：`N`或`S`
- `<LONGITUDE_DEGREES>`：范围 0..180（含）内的浮点数
- `<LONGITUDE_HEMISPHERE>`：`E`或`W`

例如，`"48.8584 N, 2.2945 E"`解析为：

- `<LATITUDE_DEGREES>`：48.8584
- `<LATITUDE_HEMISPHERE>`：N
- `<LONGITUDE_DEGREES>`：2.2945
- `<LONGITUDE_HEMISPHERE>`：E

共有 11 个任务，你将逐步解析 GPS 坐标。你会用到 Prolog 的[定子句文法](https://en.wikipedia.org/wiki/Definite_clause_grammar)（DCG）支持，它正是为解析结构化文本而设计的。

````exercism/note
为了帮你上手，存根文件已经通过下面的代码引入了[`dcg/basics`库](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl)：

```prolog
:- use_module(library(dcg/basics)).
```
````

## 1. 解析逗号

实现`comma`规则来解析单个逗号（`","`）：

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. 解析空格

实现`space`规则来解析单个空格（`" "`）：

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. 支持所有空白字符（换行符除外）

修改`space`规则，让它解析*所有*空白字符，但不解析换行符：

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. 解析纬度的半球

纬度的半球可以是`"N"`或`"S"`，它们应被解析为`north`或`south`原子。实现`latitude_hemisphere`规则来解析纬度的半球：

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. 解析经度的半球

经度的半球可以是`"E"`或`"W"`，它们应被解析为`east`或`west`原子。实现`longitude_hemisphere`规则来解析经度的半球：

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. 解析度数

经度或纬度的度数被定义为浮点数。实现`degrees`规则来解析浮点数：

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. 解析纬度度数

纬度度数不只是普通的浮点数，而是范围 0..90（含）内的浮点数。实现`latitude_degrees`规则，用上面的范围来解析纬度度数：

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. 解析经度度数

经度度数不只是普通的浮点数，而是范围 0..180（含）内的浮点数。实现`longitude_degrees`规则，用上面的范围来解析经度度数：

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. 解析纬度

纬度由两部分组成：度数和半球，两者之间用一个空格分隔。实现`latitude`规则来解析纬度：

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. 解析经度

纬度由两部分组成：度数和半球，两者之间用一个空格分隔。实现`latitude`规则来解析纬度：

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. 解析坐标

坐标由两部分组成：纬度和经度，两者之间用一个逗号加一个空格分隔。实现`coordinate`规则，同时解析纬度（度数和半球）：

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
