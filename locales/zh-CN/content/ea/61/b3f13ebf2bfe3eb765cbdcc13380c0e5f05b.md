# 推荐学习资源

## 博客

- 官方的 [.NET 博客](https://blogs.msdn.microsoft.com/dotnet/) 上有许多有趣的 C# 文章，难度从入门到专家不等。
- Scott Hanselman 的[博客](http://www.hanselman.com/blog/)内容活跃、文笔出色，涵盖各种 C# 和 .NET 相关主题。
- Eric Lippert 的 [Fabulous adventures in coding](https://ericlippert.com/) 是一流的 C# 博客，不过他的话题通常相当进阶。
- James Michael Hare 的 [C#/.NET Little Wonders](https://www.slideshare.net/BlackRabbitCoder/little-wonders-5747749) 幻灯片，介绍鲜为人知的 C# 功能。
- James Michael Hare 的 [C#/.NET Little Pitfalls](https://www.slideshare.net/BlackRabbitCoder/cnet-little-pitfalls) 幻灯片，讲如何避免对 C# 的错误假设。

## 社交媒体

- 可以用 [StackOverflow](http://stackoverflow.com/questions/tagged/c%23) 搜索你的问题，看看是否已经有人问过。你也可以提问和回答问题。
- [/r/csharp](https://www.reddit.com/r/csharp) 是 C# 的 subreddit。
- [@dotnet](https://twitter.com/DotNet) 是 .NET 官方的 Twitter 账号。
- [Gitter](https://gitter.im/exercism/xcsharp) 是 C# 的 Gitter 聊天室，可以在这里获取支持和提出 C# 学习路径相关的问题。

## 视频

- 在 [On .NET](https://www.youtube.com/watch?v=GpLU0UdcGic&list=PL4Sf58qFxdyQuzB1mH5kln_otKpsIuoCO) 中，Bertrand Le Roy 就各种 C#/.NET 相关话题采访不同的人。
- PluralSight 上有很多很棒的 [C# 课程](https://www.pluralsight.com/search?q=*&categories=course&roles=software-development%7C&subjects=c%23)。缺点是：PluralSight 是付费服务，但你可以申请[免费试用](https://www.pluralsight.com/pricing)。

## 播客

- [.NET Rocks](https://www.dotnetrocks.com/) 是一档内容优质的 .NET 播客。

## 书籍

- [Expert C# 5.0](http://www.apress.com/us/book/9781430248606)
