# 简介

## 条件语句

条件语句是用来做判断的语句，它要么执行副作用，要么控制程序的执行流程。
条件语句包括 `if`、`if/else`、`switch` 和 `ternary`语句。

条件语句用来针对一个值或值之间的关系提出问题。
这个问题求值后会得到一个布尔值，但 `if`语句本身可以返回任意值，也可以只执行一个副作用。

## if 语句

最简单的 `if`语句会对一个表达式求值，并执行一行代码。
被测试的表达式始终写在括号里。

它可以执行副作用

```c
if (count > 10)
    printf("count is greater than 10");
```

也可以改变执行流程


```c
if (count > 10)
    return sum;
```

如果 `if`语句要执行多行，就必须把这些行放进大括号里

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

有些开发团队可能会统一规定：`if`语句始终使用大括号，即使只有一行。


## if/else

`if`语句可以和 `else`搭配使用

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## if-else-if


`else`可以和另一个 `if`搭配，组成所谓的 `if-else-if ladder`。

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## switch


有时用 `switch`来表示 `if-else-if ladder`会更合适。
和 `if`一样，被测试的表达式始终放在括号里。

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

如果被测试的值和前面任何一个分支都不匹配，就执行 `default`分支。

如果 `switch`的某个分支不是以返回结束，通常会在每个分支末尾插入一个 `break`，否则逻辑会“贯穿”到下一个分支。
有时贯穿是有意为之

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

贯穿如果不是有意为之，那就是一个 bug。

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

当测试针对的是具体的值而不是一个范围的值时，用 switch 会很有好处。
它可能比 `if-else-if ladder`更快，因为编译器可以用一些对阶梯无法使用的方式优化 `switch`语句。
有时 switch 看起来也比阶梯更易读。

## 三元运算符（又称条件运算符）

三元运算符是由三部分组成的条件语句，常用来给变量赋值。
要测试的表达式放在问号之前，而且不必写在括号里。
为 true 时返回的值放在冒号之前，为 false 时返回的值放在冒号之后。
返回的可以是字面量，也可以是变量。

```c
int i = j > 5 ? 5: j;
```

三元运算符可以嵌套，以减少语法上的杂乱。

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
