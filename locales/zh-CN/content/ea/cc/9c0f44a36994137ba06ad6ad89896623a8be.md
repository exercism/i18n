# 说明

Mecha Munch™ 是一家食品杂货购物自动化公司，最近刚聘请你参与他们的下单应用。你的团队负责打造一个 MVP（_[minimum viable product][mvp]_，最小可行产品），用来管理购物车的基本操作，让用户能够添加、移除和整理自己的杂货订单。好在，所有涉及金钱和结账的功能都由另一个团队负责！

## 1. 将商品添加到用户的购物车

这个 MVP 应该让用户能够把商品添加进购物车。既可以是单个商品，也可以一次添加多个商品。由于这只是一个 MVP，商品数量通过_重复出现_来表示。如果用户想添加 2 个 Oranges，输入的可迭代对象中就会出现两次 'Oranges'。如果购物车里已经有该商品，它的数量就加 1。如果该商品对购物车来说是_新_的，则应以数量 1 添加。

创建函数`add_items!(<cart>, <items>)`，它接受一个购物车字典和一个待添加商品的可迭代对象作为参数。函数应返回更新后的用户购物车字典。

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

应用里有一个“灵感”板块，里面是来自各种菜系的成品食谱。用户可以选择其中任意一份食谱，把它的所有食材自动添加到购物车。项目经理让你想个办法来编辑这些“灵感”食谱，因为内容团队总在调整食材和用量。

创建函数`update_recipes!(<ideas>, <updates>)`，它接受一个“灵感”字典和一个食谱更新字典作为参数。函数应返回更新后的“灵感”字典。

## 3. 把用户的购物车发送到门店备货

应用需要把指定用户的购物车发送到门店备货。不过，门店里的店员需要知道商品放在哪里，这要靠一个唯一的货架通道编号。为了让店员更高效，“备货清单”需要按商品的货架通道编号排序。

创建函数`send_to_store(<cart>, <aislecodes>)`，它接受一个用户购物车和一个记录了门店货架编号的字典。函数应返回一份合并后的“备货清单”，其中顾客订购的每件商品都对应一个`aislecode => quantity`键值对。各商品应按各自的货架通道编号顺序排列。

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. 更新门店库存，反映用户订购的商品

应用不能无休止地接受顾客下单。总有一天，门店的各种商品会卖光。所以你的 MVP 需要在用户每次把订单发送到门店时更新门店库存。否则，顾客就会订购到实际上并不存在的商品。

创建函数`update_store_inventory!(<inventory>, <cart>)`，它接受一个`cart`和一个`inventory`。函数应按“购物车”中“已订购”的数量扣减门店库存，然后返回一个字典，包含所有缺货的商品（也就是数量已经降到`0`的商品）。

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. 补订缺货商品

除了更新库存，你的应用还能帮忙补货。顾客下单后，对于任何缺货的商品，你的 MVP 都应该能准备一份小订单。这会简化触发大订单的流程。此外，有时会有不在库存清单里的限时促销商品。如果这些商品在促销期结束前就卖光了，说明它们很受欢迎，可以加入库存清单。

创建`reorder!(<outofstock>, <stock>)`，它接受`outofstock`和`stock`。`stock`字典包含标准库存商品及其补货数量。`outofstock`字典是`update_store_inventory!`的结果，也就是数量为零的商品字典。应把`outofstock`中各商品的数量更新为`stock`中的数量并返回。此外，`outofstock`里凡是不在`stock`中的商品，都应以默认数量`100`加入`stock`。

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
