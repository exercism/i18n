# 时尚精品店

## 故事

你正在经营一家线上时尚精品店。黑色星期五就要到了，所以你需要盘点库存，确保一切准备就绪。

库存中的单件商品用一个映射/字典表示，整个库存则是这类映射/字典组成的数组。

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 任务

- 按价格对商品排序
- 找出所有缺少价格的商品
- 增加商品的库存数量
- 计算商品的总数量
