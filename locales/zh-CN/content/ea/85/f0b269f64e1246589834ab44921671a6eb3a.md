# 简介

除了函数声明和函数表达式，JavaScript 还有一种非常简洁的函数定义语法。这类函数叫做_箭头函数_。

在这个概念里，我们将重点介绍编写箭头函数所使用的语法。箭头函数的工作方式存在一些差异，例如 _this_ 绑定，这些差异会在其他概念中介绍。

下面是函数声明与箭头函数的对比。

```javascript
function addUpTwoNumbers(num1, num2) {
  return num1 + num2;
}

// function keyword removed and => added
const addUpTwoNumbers = (num1, num2) => {
  return num1 + num2;
};
```

在上面的代码中可以看到，箭头函数的语法：

1. 去掉了关键字`function`
2. 把标识符`addUpTwoNumbers`声明为`const`
3. 增加了一个胖箭头`=>`

如果函数体只包含一条 return 语句，就像上面的例子那样，那么`{}`和`return`关键字都可以省略。

<!-- prettier-ignore-start -->
```javascript
const addUpTwoNumbers = (num1, num2) => { return num1 + num2 };

// can be shortened to
const addUpTwoNumbers = (num1, num2) => num1 + num2;
// braces {} and return removed
```
<!-- prettier-ignore-end -->

在箭头函数只返回一个对象这种特殊情况下，需要给对象加上圆括号，才能省略 return 语句。

```javascript
// explicit return of object
const addUpTwoNumbers = (num1, num2) => {
  return {
    num1,
    num2,
  };
};

// implicit return of object
const addUpTwoNumbers = (num1, num2) => ({ num1, num2 });
```

参数外面是否需要用括号，取决于参数的个数。

<!-- prettier-ignore-start -->
```javascript
// one parameter does not need parenthesis
const square = num => num * num;

// two or more parameters need to be wrapped in parenthesis
const addUpTwoNumbers = (num1, num2) => num1 + num2;
```
<!-- prettier-ignore-end -->
