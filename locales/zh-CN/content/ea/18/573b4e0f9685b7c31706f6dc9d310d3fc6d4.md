# 学习 C#

## 网站

- [C# 官方文档](https://docs.microsoft.com/en-us/dotnet/articles/csharp/)涵盖各种各样的主题，内容很丰富，其中包括[教程](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tutorials/index)和[语言导览](https://docs.microsoft.com/en-us/dotnet/articles/csharp/tour-of-csharp/index)。
- [Learn C#](http://www.learncs.org/)是一门交互式的浏览器内教程，带你了解 C# 编程的核心概念。

## 视频

- [C# 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oVxKLQCHpiUWun7vlJJvUiN)用现场编码演示讲解 C# 编程语言的概念和语法。
- [.NET Core 101](https://www.youtube.com/playlist?list=PLdo4fOcmZ0oWoazjhXQzBKMrFuArxpW80)深入浅出地讲解“什么是 .NET”，以及如何发布你的第一个应用程序。
- [Programming in C# Jump Start](https://channel9.msdn.com/Series/Programming-in-C-Jump-Start)是一份很棒的 C# 编程入门教程，循序渐进。
- [C# Fundamentals for Absolute Beginners](https://mva.microsoft.com/en-US/training-courses/c-fundamentals-for-absolute-beginners-16169?l=Lvld4EQIC_2706218949)是认识 C# 的好方法。
- [PluralSight](https://www.pluralsight.com/)有好几门[很棒](https://www.pluralsight.com/courses/csharp-6-from-scratch)的[入门](https://www.pluralsight.com/courses/c-sharp-fundamentals-with-visual-studio-2015)[课程](http://www.pluralsight.com/courses/csharp-best-practices-improving-basics)。缺点是：PluralSight 是付费服务，不过你可以申请[免费试用](https://www.pluralsight.com/pricing)。
