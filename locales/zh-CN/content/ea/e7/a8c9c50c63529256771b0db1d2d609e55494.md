# 简介

推导式提供了一种简便、声明式地转换 _Enumerables_ 的方式。

要声明一个非常简单的推导式，可以使用`for`关键字，后面跟一个_生成器_和一个_do 块_，由枚举出的值创建新的值。

```elixir
for n <- [0, 1, 2, 3], do: n + 1
# => [1, 2, 3, 4]
```

推导式还可以带有_过滤器_。没有通过过滤器的值会从最终列表中移除：

```elixir
for n <- [0, 1, 2, 3], n > 1, do: n + 1
# => [3, 4]
```

我们还可以在多行中声明更复杂的推导式：

```elixir
for {atom, number} <- [a: 1, b: 2, c: 3, d: 4],
    rem(number, 2) == 0 do
  atom
end

# => [:b, :d]
```

使用多个生成器可以创建_笛卡尔积_。也就是说，第一个生成器生成的每个值都会与第二个生成器生成的每个值配对一次：

```elixir
for x <- [0, 1],
    y <- [0, 1] do
  {x, y}
end

# => [{0, 0}, {0, 1}, {1, 0}, {1, 1}]
```
