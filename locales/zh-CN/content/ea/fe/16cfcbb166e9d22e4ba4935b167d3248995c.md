# 说明

你！对，就是你，勇敢的 Lisp 程序员！[Lisp 外星人 Lenny][alien] 需要你的帮助！Lenny 想和其他 Lisp 外星人一起出去玩，可他们的父母说了，房间不收拾干净，哪儿也别想去。

问题是，Lenny 几乎看不见地板！Lenny 分不清原子和 cons，分不清符号和关键字，分不清`car`和`cdr`！

你能帮 Lenny 把这团乱麻理清吗？别忘了[你的括号][xkcd]，你会用得上的！

## 1. 帮 Lenny 复习符号

Lenny 动工之前，得先复习一下符号和关键字长什么样。毕竟他们已经很久没收拾过房间了……帮帮 Lenny，定义两个函数：`lennys-favorite-food` 求值为某个符号，`lennys-secret-keyword` 求值为某个关键字。例如：

```lisp
(lennys-favorite-food) ; => LASAGNA
```

```lisp
(lennys-secret-keyword) ; => :ALIENS-ARE-REAL
```

注意，你可以返回任何你喜欢的符号或关键字（如果你不喜欢千层面，或者不相信外星人）。

## 2. 帮 Lenny 区分原子和 cons

Lenny 复习完符号和关键字，就该动手收拾了！要理清房间里散落一地的 S-表达式，Lenny 需要有人帮忙判断什么是 cons、什么是原子。你可以实现两个函数来帮忙：`is-an-atom-p` 和 `is-a-cons-p`：

```lisp
(is-an-atom-p 'one-thing)    ; => T
(is-an-atom-p '(two things)) ; => NIL
```

```lisp
(is-a-cons-p 'one-thing)    ; => NIL
(is-a-cons-p '(two things)) ; => T
```

这一节里，有几个内置的 Lisp 函数可能会派上用场。另外，现在你可以直接认为 `T` 为真、`NIL` 为假。

## 3. 帮 Lenny 拆分 cons

最后，Lenny 的 cons 太占地方，没法整齐地收好，得把它们拆成更小的部分。你能再定义两个函数来拆分这些 cons 吗（`first-thing` 和 `rest-of-it`）？

```lisp
(first-thing '(first second third)) ; => FIRST
(rest-of-it  '(first second third)) ; => (SECOND THIRD)
```

同样，Common Lisp 的一些内置函数在这里可能会派上用场。
