# 简介

## 常量

`const`修饰符可以（而且通常也应该）用在任何满足以下条件的字段上：它的值在编译时已知，并且在程序的生命周期内不会改变。

```csharp
private const int num = 1729;
public const string title = "Grand" + " Master";
```

`readonly`修饰符可以（而且通常也应该）用在这样的字段上：它无法声明为`const`，其值在程序的生命周期内不会改变，并且要么由内联初始化器赋值，要么在实例化时赋值（由构造函数或构造函数调用的方法来完成）。

```csharp
private readonly int num;
private readonly System.Random rand = new System.Random();

public MyClass(int num)
{
    this.num = num;
}
```

## 防御性复制

在对安全敏感的场景中（或者哪怕只是在一个大型代码库里，开发者们的优先级和目的各不相同），你都应该避免让类的公共 API 被绕过，比如接受并存储方法的可变形参，或者通过返回值、`out`参数把类的可变成员暴露出去。

## 只读集合

`readonly`修饰符可以防止字段中的值或引用被覆盖，但它无法保护引用类型的成员。

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

要确保引用类型的所有成员都受到保护，可以把字段声明为`readonly`，并定义不带`set`访问器的自动属性。

基类库（BCL）在需要阻止集合成员被更新时，提供了一些只读版本的集合。它们以包装器的形式提供：

- `ReadOnlyDictionary<T>`以只读方式公开`Dictionary<T>`。
- `ReadOnlyCollection<T>`以只读方式公开`List<T>`。
