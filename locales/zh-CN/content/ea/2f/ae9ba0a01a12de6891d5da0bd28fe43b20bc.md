# 说明

在本练习中，你将编写代码，为工厂员工打印工牌。

## 1. 为员工打印工牌

员工有 ID、姓名和部门名称。员工工牌标签的格式如下：`"[id] - name - DEPARTMENT"`。
实现`Badge.print()`方法，返回员工的工牌标签：

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

注意，标签上的部门名称应转换为大写。

## 2. 为新员工打印工牌

由于计算机系统的一个古怪之处，新员工刚开始在工厂工作时，有时还没有 ID。
由于必须佩戴工牌，他们会收到一个不带 ID 前缀的临时工牌。修改`Badge.print()`方法，使其支持还没有 ID 的新员工：

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. 为老板打印工牌

即使是工厂老板，也必须始终佩戴工牌。
不过，老板没有部门。在这种情况下，标签应打印`"OWNER"`，而不是部门名称。
修改`Badge.print()`方法，为老板打印标签：

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

注意，老板也可能是新员工：

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
