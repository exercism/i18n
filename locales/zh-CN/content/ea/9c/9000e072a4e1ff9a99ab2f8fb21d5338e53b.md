# 简介

在 Python 中，[枚举](https://docs.python.org/3/library/enum.html)是一组名称，这些名称绑定到唯一的`literal`或`constant`值。枚举通过继承`Enum`类来定义。内置枚举类型位于`enum`模块中，可以用`from enum import Enum`导入`Enum`类。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

注意，枚举成员的值可以是任何数据类型，比如 str、tuple、float 等。

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

在枚举中，如果把同一个值赋给两个成员，那么后赋值的成员会成为前者的别名。枚举中不允许两个成员使用相同的名称。

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

可以使用标准的`for member in`语法遍历枚举的成员：

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

枚举成员可以用 [`is`（_同一性运算符_）](https://www.w3schools.com/python/ref_keyword_is.asp)或`is not`进行比较。`==`或`!=`（_相等运算符_）也同样适用。

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

要根据给定的值访问枚举成员，可以使用`EnumName(value)`：

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
