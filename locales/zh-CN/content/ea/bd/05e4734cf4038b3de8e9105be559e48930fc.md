# 提示

## 通用

- Python 文档的[字符串教程][python-str-doc]概述了 Python 的`str`类型。
- 处理字符串时，字符串方法[`str.join()`][str-join]和[`str.split()`][str-split]非常有用。
- Python 文档中关于[序列类型][common sequence operations]的章节列出了所有序列共有的操作，包括`strings`、`lists`、`tuples`和`ranges`。

这个练习包含四个活动，每个活动都有一组要处理的文本或单词。

## 1. 给单词添加前缀

- 小字符串可以用`+`运算符拼接。

## 2. 给词组添加前缀

- 信不信由你，这里只需要[`str.join()`][str-join]。**不需要循环**。
- 测试会给你的函数传入一个`list`。只要能想出一个合适的分隔符字符串，就无需修改这个`list`。
- 记住，分隔符字符串放在元素之间，把它们“粘”成一个字符串。分隔符插入时_不带_空格，不过你可以在分隔符里包含空格字符。
- 和[`str.split()`][str-split]一样，`str.join()`可以处理由任意 Unicode 码点构成的任意长度字符串。_与_`str.split()`_不同_，它还能处理类似`list`、`tuple`和`set`这样的任意长度可迭代对象。

## 3. 从单词中移除后缀

- 字符串可以从左边（从 0 开始）或右边（从 -1 开始）按下标访问或切片。
- 如果你想获取任意长度字符串的最后一个码点，可以使用`[-1]`。
- 用负下标可以把字符串的最后三个字母“切掉”。例如：`beautiful'[:-3] == 'beauti`

## 4. 提取并转换单词

- 使用[`str.split()`][str-split]会返回一个`list`，里面的字符串是按空白拆分出来的。
- `lists`是序列，可以按下标访问。
- [`str.split()`][str-split]可以直接按下标访问：`'Exercism rocks!'.split()[0] == 'Exercism'`
- 注意标点符号！句点可以通过切片去掉：`'dark.'[:-1] == 'dark'`
