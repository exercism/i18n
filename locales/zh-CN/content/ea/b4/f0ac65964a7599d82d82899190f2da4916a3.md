# 练习说明附录

## 本练习在 Python 中的结构

Python 提供了丰富的数学函数，既有 [math 模块][math-module]，也有内置函数，比如幂运算符`**`、[`pow()`][pow]和[`sum()`][sum]。
不过，我们希望你能试试看，在不使用这些内置函数和模块的情况下解决这个练习。

虽然有一个数学公式可以求出_任意_数字的平方根，但我们选择只把[自然数][nautral-number]（正整数）作为解。  
只用自然数进行运算，就可以求出任意自然数的平方根。
