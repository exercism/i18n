# 泛型数据类型

Cairo 中的泛型让你能编写可复用的代码，用来处理各种类型，从而避免重复并提升可维护性。

泛型可用于函数、结构体、枚举、trait 和方法。

## 泛型函数

泛型函数可以处理不同的类型，而无需为每种类型单独实现。

例如：

```rust
fn largest_list<T>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

这里的`T`是任意类型的占位符。

不过，Cairo 要求使用 trait 约束，以确保泛型类型满足特定要求。

如果`T`需要可被 drop，我们可以更新函数签名：

```rust
fn largest_list<T, impl TDrop: Drop<T>>(l1: Array<T>, l2: Array<T>) -> Array<T> {
    if l1.len() > l2.len() {
        l1
    } else {
        l2
    }
}
```

`Drop`或`PartialOrd`这类 trait 约束会为泛型添加限制，以满足特定操作的需求。

## 匿名约束

如果函数中并未直接使用某个 trait 实现，你可以用`+`编写匿名约束：

```rust
fn smallest_element<T, +PartialOrd<T>, +Drop<T>, +Copy<T>>(list: @Array<T>) -> T {
    let mut smallest = *list[0];
    let mut index = 1;

    while index < list.len() {
        if *list[index] < smallest {
            smallest = *list[index];
        }
        index += 1;
    };

    smallest
}
```

这样可以避免给 trait 命名（例如`TPartialOrd`），减少冗余。

## 带泛型的结构体

结构体中的泛型让字段可以灵活变化。

例如：

```rust
#[derive(Drop)]
struct Wallet<T> {
    balance: T,
}

let w = Wallet { balance: 42 };
```

如果一个结构体需要多个泛型类型，只需添加更多占位符：

```rust
#[derive(Drop)]
struct Wallet<T, U> {
    balance: T,
    address: U,
}

let w = Wallet { balance: 42, address: '0xabc' };
```

## 带泛型的枚举

枚举也可以持有泛型数据类型。

例如：

```rust
enum Option<T> {
    Some: T,
    None,
}
```

`Option<T>`枚举可以表示任意类型的可选值。

类似地，`Result<T, E>`可以定义成功和失败的类型：

```rust
enum Result<T, E> {
    Ok: T,
    Err: E,
}
```

## 泛型方法

方法也可以使用泛型。

例如：

```rust
#[derive(Copy, Drop)]
struct Wallet<T> {
    balance: T,
}

trait WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T;
}

impl WalletImpl<T, +Copy<T>> of WalletTrait<T> {
    fn balance(self: @Wallet<T>) -> T {
        *self.balance
    }
}

let w = Wallet { balance: 50 };
assert!(w.balance() == 50);
```

你还可以为特定的泛型类型定义方法，例如`Wallet<u128>`：

```rust
trait WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128);
}

impl WalletReceiveImpl of WalletReceiveTrait {
    fn receive(ref self: Wallet<u128>, value: u128) {
        self.balance += value;
    }
}

let mut w = Wallet { balance: 50 };
w.receive(100);
assert!(w.balance() == 150);
```

## 混合泛型类型

泛型可以处理复杂的组合。

比如，把两个类型不同的`Wallet`实例组合起来：

```rust
trait WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2>;
}

impl WalletMixImpl<T1, +Drop<T1>, U1, +Drop<U1>> of WalletMixTrait<T1, U1> {
    fn mixup<T2, +Drop<T2>, U2, +Drop<U2>>(
        self: Wallet<T1, U1>, other: Wallet<T2, U2>,
    ) -> Wallet<T1, U2> {
        Wallet { balance: self.balance, address: other.address }
    }
}

let w1 = Wallet { balance: true, address: 10 };
let w2 = Wallet { balance: 32, address: 100 };
let w3 = w1.mixup(w2);

assert!(w3.balance);
assert!(w3.address == 100);
```

通过添加`+Drop`约束，编译器可以确保资源得到妥善处理。

泛型很强大，但需要小心管理约束。

用它来编写可复用、不依赖具体类型且简洁的代码。
