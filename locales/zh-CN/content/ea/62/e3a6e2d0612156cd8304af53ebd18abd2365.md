# 说明补充

## 项目结构

Exercism 上的 Clojure 练习支持两种最常见的依赖管理和测试工具：[leiningen][leiningen] 和 [Clojure CLI][clojure-cli]。

你会在`test`目录里找到一个名为`hello_world_test.clj`的测试文件。
把代码写在`src/hello_world.clj`中。它需要使用命名空间`hello-world`，这样测试才能找到它。

### 使用 Clojure CLI 运行测试

```
$ clj -X:test
```

### 使用 Leiningen 运行测试

```
$ lein test

lein test hello-world-test

Ran 3 tests containing 3 assertions.
0 failures, 0 errors.
```

然后用下面的命令提交练习：

```
$ exercism submit src/hello_world.clj
```

更详细的说明和学习资源请参考 [Exercism 的 Clojure 语言页面][exercism-clojure]。

[leiningen]: https://leiningen.org
[clojure-cli]: https://clojure.org/guides/deps_and_cli
