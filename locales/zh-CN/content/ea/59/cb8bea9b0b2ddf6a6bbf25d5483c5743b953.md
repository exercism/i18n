# 说明

这个练习里正逢情人节，你和伴侣打算一起做点有意思的事。伴侣有很多想法，现在要你给这些想法评分，好从中挑出一个活动来。

伴侣提出了以下想法：

- 玩桌游
- 放松一下
- 看一场电影
- 去餐厅
- 散步

你有六个任务，帮你选出情人节的活动。

## 1. 定义 Approval

对于伴侣提出的每个想法，你都要从三种选项中选择一个来回应：yes、no 或 maybe。

定义可区分联合`Approval`，用以下三个用例来表示这些选项：`Yes`、`No` 和 `Maybe`。

## 2. 定义 Cuisine

伴侣选出了两家可能去的餐厅：一家是 Korean 菜系，另一家是 Turkish 菜系。

定义可区分联合`Cuisine`，用以下两个用例来表示这两种菜系：`Korean` 和 `Turkish`。

## 3. 定义 Genre

可以选的电影多如牛毛，为了缩小范围，伴侣还列出了它们的类型。

定义可区分联合`Genre`，用以下用例来表示这些类型：`Crime`、`Horror`、`Romance` 和 `Thriller`。

## 4. 定义 Activity

如前所述，伴侣想出了五种不同的活动：玩桌游、放松一下、看电影、去餐厅和散步。

定义可区分联合`Activity`，用以下用例来表示这些活动类型：

- `BoardGame`：没有关联数据。
- `Chill`：没有关联数据。
- `Movie`：以它的`Genre`作为关联数据。
- `Restaurant`：以它的`Cuisine`作为关联数据。
- `Walk`：以一个`int`作为关联数据，表示要走的公里数。

## 5. 给活动评分

终于可以给伴侣的想法评分了。你对伴侣这些想法的感受是这样的：

- 玩桌游：no。
- 放松一下：no。
- 看电影：如果是爱情片，就 yes；否则 no。
- 去餐厅：如果是 Korean 菜系就 yes，如果是 Turkish 就 maybe。
- 散步：走路距离少于三公里就 yes；少于五公里就 maybe；否则 no。

实现一个名为`rateActivity`的函数，它接收一个`Activity`值，并根据上面的感受返回`Approval`：

```fsharp
rateActivity (Restaurant Turkish)
// => Maybe
```
