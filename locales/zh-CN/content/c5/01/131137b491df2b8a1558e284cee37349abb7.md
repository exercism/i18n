# 简介

Java 编程语言使用*异常*来处理错误以及其他异常事件。

## 什么是异常

异常是程序执行期间发生的、会打乱正常指令流程的事件。
在 Java 中，异常是被显式抛出的，抛出异常这一动作称为*抛出异常*。
处理异常这一动作称为*捕获异常*。

在 Java 中，所有异常都是`Exception`类的子类，而`Exception`本身又是`Throwable`的子类。

Java 区分两类异常：

1. 受检异常
2. 非受检异常

### 受检异常

*受检异常*是应用程序应当预见并从中恢复的异常情况。
受检异常的一个例子是`FileNotFoundException`，当方法试图读取一个不存在的文件时就会发生。

这类异常在编译期受检：抛出受检异常的方法应当在方法签名中说明这一点，而调用可能抛出受检异常的方法的代码必须处理它，否则代码无法通过编译。

所有受检异常都是`Exception`的子类，且不继承`RuntimeException`。

### 非受检异常

*非受检异常*是应用程序通常无法预见、也无法从中恢复的异常情况。
非受检异常的一个例子是`NullPointerException`，当方法期望一个非 null 值却收到`null`时就会发生。

这类异常不在编译期受检：抛出非受检异常的方法不必在方法签名中说明这一点，调用可能抛出非受检异常的方法的代码也不必处理它。

所有非受检异常都继承自`RuntimeException`，而`RuntimeException`本身又是`Exception`的扩展。

## 抛出异常

Java 中的方法可以使用`throw`语句抛出一个异常。

### 抛出受检异常

从方法中抛出受检异常时，必须在方法签名中使用`throws`关键字说明，如下例所示。
这迫使调用方预料到可能抛出异常，并相应地加以处理。

```java
public class InsufficientBalanceException extends Exception {

}

public class BankAccount {
  public void withdraw(double amount) throws InsufficientBalanceException {
    if (balance < amount) {
      throw new InsufficientBalanceException();
    }

    // rest of the method implementation
  }
}
```

### 抛出非受检异常

从方法中抛出非受检异常时，不必在方法签名中说明，不过也支持这么做。

```java
public class BankAccount {
  public void withdraw(double amount) {
    if (amount < 0) {
      throw new IllegalArgumentException("Cannot withdraw a negative amount");
    }

    // rest of the method implementation
  }
}
```

## 处理异常

在 Java 中处理异常要用`try`、`catch`和`finally`关键字。

- 可能抛出异常的代码语句应当包在`try`块中。
- `try`块后面跟着一个或多个`catch`块，用来捕获`try`块中抛出的异常。
- `catch`块后面可以可选地跟一个`finally`块，它在`try`块之后总会执行，无论是否抛出了异常。

下面的例子展示了这些关键字如何工作：

```java
public class ATM {
  public void withdraw(BankAccount bankAccount, double amount) {
    try {
      System.out.println("Withdrawing " + amount);
      bankAccount.withdraw(amount);
      System.out.println("Withdrawal succeeded");
    } catch (InsufficientBalanceException) {
      System.out.println("Withdrawal failed: insufficient balance");
    } catch (RuntimeException e) {
      System.out.println("Withdrawal failed: " + e.getMessage());
    } finally {
      System.out.println("Current balance: " + bankAccount.getBalance());
    }
  }
}
```

在这个例子中，当没有异常抛出时，会打印以下内容：

```text
Withdrawing 10.0
Withdrawal succeeded
Current balance: 5.0
```

然而，如果`bankAccount.withdraw(amount)`语句抛出了`InsufficientBalanceException`，则会打印以下内容：

```text
Withdrawing 10.0
Withdrawal failed: insufficient balance
Current balance: 5.0
```

或者，如果`bankAccount.withdraw(amount)`抛出了非受检异常，则会打印以下内容：

```text
Withdrawing -10.0
Withdrawal failed: Cannot withdraw a negative amount
Current balance: 5.0
```

## 错误

Java 还有一个单独的类别，叫做*错误*，它们是应用程序外部的严重问题。
错误的一个例子是`OutOfMemoryError`，当应用程序试图使用的内存超过系统可用内存时就会发生。

与非受检异常一样，错误也不在编译期受检。
区别在于，错误代表系统级的问题，通常由 Java 虚拟机或运行环境抛出，而不是由应用程序抛出。
应用程序通常不应尝试捕获或处理它们。

Java 中的所有错误都继承自`Error`类。
