# 简介

## 类型转换

Go 要求在不同类型之间进行显式转换。
类型之间的转换（也叫**类型强制转换**）通过一个以目标类型名为名称的函数来完成。
例如，要把 `int` 转换成 `float64`，需要这样做：

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## 基本类型与字符串之间的转换

`strconv` 包可以在基本类型（如 `int`）和 `string` 之间进行转换。

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## 类型断言

Go 中的接口可能会让底层类型变得不明确。
类型断言让我们可以用这样的语法提取接口值底层的具体值：`interfaceVariable.(concreteType)`。

例如：

```go
var input any = 12
number := input.(int)
```

注意：如果接口变量持有的值不是该具体类型，就会引发 panic。

利用类型断言的两个返回值，我们可以判断接口值是否持有某个具体类型：一个是底层的值，另一个是表示断言是否成功的布尔值。
例如：

```go
str, ok := input.(string) // no panic if input is not a string
```

如果 `input` 持有的是 `string`，那么 `str` 就是底层的值，`ok` 为 true。
如果 `input` 持有的不是 `string`，那么 `str` 就是 `string` 类型的零值（即 `""`，空字符串），`ok` 为 false。
无论哪种情况都不会发生 panic。

## 类型分支

**类型分支**可以依次执行多个类型断言。
它的语法和类型断言相同（`interfaceVariable.(concreteType)`），只是把 `concreteType` 换成了关键字 `type`。
下面是一个例子：

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
