# 说明

在这个练习中，你将生成半结构化的日志消息。

## 输出半结构化消息

起始时，你会拿到一些函数存根，以及下面这个枚举：

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

你的目标是输出如下格式的日志消息：`"[<LEVEL>]: <MESSAGE>"`。
你需要实现与各个日志级别相对应的函数。

例如，下面的代码片段展示了`log`函数的一种预期输出。

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

`info`则是：

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

玩得开心！
