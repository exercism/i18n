# 简介

Common Lisp 有许多不同的相等性谓词。
这与其他编程语言不同，那些语言可能只有一两个（例如`==`和`===`）。
这些谓词中，有些在 Common Lisp 中特定于类型，而另一些则是通用的。
这里将介绍后者。

有四个通用的相等性谓词，它们对什么算作“相等”的严格程度不同。
它们按限制从最严格到最宽松的顺序是：`eq`、`eql`、`equal`和`equalp`。

以下是一组快速定义（省略了一些细节）：

- `eq`：把相等定义为两个对象是同一对象。
  _例如_：

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`：把相等定义为：两个数字具有相同的类型和值，两个字符是相同的，或者对于其他任何东西，如果它们彼此`eq`。
  _例如_：

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`：把相等定义为：两个列表`equal`的条件是每个元素也`equal`；两个字符串`equal`的条件是每个元素`eql`；两个数组`equal`的条件是它们`eq`；其他所有东西`equal`的条件是它们`eql`。
  _例如_：

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`：把相等定义为：字符串和字符以不区分大小写的方式比较；数字比较时进行某种类型转换；如果每个元素也`equalp`，则列表和数组`equalp`；如果结构体是同一类型且所有槽都是`equalp`，则结构体`equalp`；如果哈希表的键和值都`equalp`，则哈希表`equalp`。
  _例如_：

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
