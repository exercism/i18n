# 说明

你附近的一所学校有一个非常活跃的学生会。
学生会由一名主席管理，每 2 年举行一次选举，选出一位新主席。

在今年的选举中，大家决定需要一套新的数字化计票系统。
学校需要你帮忙构建这套新系统。

## 1. 创建计票器

新的投票系统首先需要的东西之一就是计票器。
这个计票器用来记录某位特定候选人获得的票数。

创建一个函数 `NewVoteCounter`，它接受某位候选人的初始票数，并返回一个指向 `int` 的指针，该指针用给定的初始票数初始化。

```go
var initialVotes int
initialVotes = 2

var counter *int
counter = NewVoteCounter(initialVotes)
*counter == initialVotes // true
```

## 2. 从计票器获取票数

现在你有办法创建新的计票器了！但你意识到，新系统还需要一种从计票器获取票数的方法。

创建一个函数 `VoteCount`，它接收一个计票器（`*int`）作为实参，并返回该计票器中的票数。
如果计票器为 `nil`，就认为这个计票器没有票数：

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

VoteCount(voteCounter)
// => 3

var nilVoteCounter *int
VoteCount(nilVoteCounter)
// => 0
```

## 3. 增加计票器的票数

终于到了计票的时候了！现在你需要一种增加计票器票数的方法。

创建一个函数 `IncrementVoteCount`，它接收一个计票器（`*int`）和一个票数作为实参，并把计票器的票数增加该数量。
你可以假设传入的指针永远不是 `nil`。

```go
var votes int
votes = 3

var voteCounter *int
voteCounter = &votes

IncrementVoteCount(voteCounter, 2)

votes == 5          // true
*voteCounter == 5   // true
```

## 4. 创建选举结果

所有票都计完后，是时候准备向全校公布结果了。
为此，你发现只有票数计票器还不够。
需要一种把票数与特定候选人关联起来的方式。

创建一个函数 `NewElectionResult`，它接收候选人的名字和票数，并返回一个新的选举结果。

```go
var result *ElectionResult
result = NewElectionResult("Peter", 3)

result.Name == "Peter"  // true
result.Votes == 3       // true
```

选举结果的结构体已经为你创建好了，它定义为：

```go
type ElectionResult struct {
    // Name of the candidate
    Name    string
    // Votes of votes the candidate had
    Votes   int
}
```

## 5. 公布结果

是时候向全校公布新主席了！
新主席将在学校那些小型数字留言板上公布。
消息应显示新主席的名字和获得的票数，格式如下：`<candidate_name> (<votes>)`。
这样一条消息的示例：`"Peter (51)"`。

创建一个函数 `DisplayResult`，它接收一个 `*ElectionResult` 作为实参，并返回包含待显示消息的字符串。

```go
var result *ElectionResult
result = &ElectionResult{
    Name: "John",
    Votes: 32,
}

DisplayResult(result)
// => John (32)
```

## 6. 重新计票

为了确保最终结果准确，重新统计了票数。
在重新计票中发现，有些候选人的票数差了一票。

创建一个函数 `DecrementVotesOfCandidate`，它接收最终结果和某个候选人的名字，你需要把该候选人的票数减一。
最终结果以 `map[string]int` 的形式给出，其中键是候选人的名字，值是他们的总票数。

```go
var finalResults = map[string]int{
    "Mary":  10,
    "John":  51,
}

DecrementVotesOfCandidate(finalResults, "Mary")

finalResults["Mary"]
// => 9
```
