# 简介

在 Haxe 中，**数组**是（通常）相同类型元素的集合。在 Haxe 中创建数组有三种方式：一种是用构造函数，另一种是用声明语法。在 Haxe 中，数组第一个元素的下标是 0：

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

使用构造函数创建数组时，需要传入将包含在数组中的元素类型：

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

由于 Haxe 中的数组访问是无边界的，也就是说，它保证不会抛出异常，因此需要进一步说明：

- 如果读取一个不存在的下标，返回的值取决于目标平台。
- 如果使用越界的正下标进行写入，那么在最后一个已定义下标和新写入的下标之间的所有位置都会插入 `null`（在静态目标上则是基本类型的默认值）。
- 如果使用负下标进行写入，结果未指定。

如果我们希望数组包含多种类型的元素，就在类型标注中加入`Dynamic`类型：

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## 迭代

可以使用`for`循环迭代数组：

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
