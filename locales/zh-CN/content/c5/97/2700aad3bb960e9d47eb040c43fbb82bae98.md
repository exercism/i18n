# 说明补充

## 异常信息

有时需要[抛出异常][raise-an-exception]。这样做时，你应该始终附上一条**有意义的错误信息**，说明错误的来源是什么。这能让你的代码更易读，也会大大方便调试。如果你已经知道错误来源是某种特定类型，可以选择抛出某个[内置错误类型][built-in-errors]，但仍然要附上有意义的信息。

这道练习要求你使用 [raise 语句][raise-statement]，在传给`answer()`的问题格式错误或无效、或者包含未知运算时“抛出” `ValueError`。只有当你既 `raise` 了 `exception`，又给它附上一条信息，测试才会通过。
**请注意**：即使抛出的是同一种_错误类型_，每个场景所需的信息也不一样。
仔细查看测试。

要带着信息抛出 [`ValueError`][value-error]，请把这条信息作为实参传给 `exception` 类型：


```python
# if the question contains an unknown operation.
raise ValueError("unknown operation")

# if the question is malformed or invalid.
raise ValueError("syntax error")
```

要在某个代码块内_处理_抛出的错误，可以使用 [try-except][handling-exceptions]。
`try-except` 块会“包裹”可能出错的代码，把所有异常映射到一个错误、多个错误，或者映射到其他用来处理问题的代码片段：


```python
while len(equation) > 1:
        try:
           # The questionable/error-prone code goes here,in an indented block
           # It can contain statements, loops, if-else blocks, or other executable code.
           x_value, operation, y_value, *rest = equation
           ...
           ...

        except:
            # Code for what to do when an error gets thrown in the code above.
            # This could be one error, or more complicated logging, error checking and messaging.
            raise ValueError("syntax error")
```
