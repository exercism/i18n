# 说明

在本练习中，你将编写代码来分析汽车工厂里装配线的生产情况。
装配线的速度可以从 `0`（关闭）到 `10`（最大）。

在最慢的速度（`1`）下，每小时生产 `221` 辆汽车。
产量随速度线性增长。
因此当速度设为 `4` 时，每小时应生产 `4 * 221 = 884` 辆汽车。
不过，速度越高，生产出有缺陷汽车的可能性就越大，这些汽车随后必须被丢弃。
下表显示了速度如何影响成功率：

- `1` 到 `4`：成功率 100%。
- `5` 到 `8`：成功率 90%。
- `9`：成功率 80%。
- `10`：成功率 77%。

你有两个任务。

## 1. 计算每小时的产量

实现 `AssemblyLine#production_rate_per_hour` 方法，计算装配线每小时的产量，并考虑其成功率。
注意，返回的值是 `Float` 的实例。

```ruby
AssemblyLine.new(6).production_rate_per_hour
#=> 1193.4
```

## 2. 计算每分钟生产的可用汽车数量

实现 `AssemblyLine#working_items_per_minute` 方法，计算每分钟生产多少**完成且可用的汽车**。
注意，返回的值是 `Integer` 的实例。

```ruby
AssemblyLine.new(6).working_items_per_minute
#=> 19
```
