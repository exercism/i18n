# 简介

Kotlin 中的[`string`][ref-string]是一个不可变的 Unicode 字符序列。

[`Immutable`][wiki-immutable]意味着对字符串的任何操作都必须返回一个新的字符串：原始字符串永远不会改变。

[`Unicode`][wiki-unicode]意味着世界上大多数书写系统都能表示，但与较旧的语言（如 C）相比，字符和字节之间没有 1:1 的映射。

字符串通常用双引号`" "`包围。

有些字符需要转义：`\'`、`\\`，以及常见的非打印字符，如`\t`（制表符）和`\n`（换行符）。

```kotlin
val s = "Escape apostrophe \' and backslash \\."
// Escape apostrophe ' and backslash \.
```

多行字符串用 3 个双引号包围，可以包含任意文本（无需转义）。

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

使用 [trimIndent][trimIndent-doc] 删除各行共有的缩进。
这对格式化字符串很有用：

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

或者，[trimMargin][trimMargin-doc] 可以让你指定一个分隔符。
然后`String`中的每一行都从分隔符之后开始。
分隔符默认是`|`，但你可以把不同的分隔符指定为形参。
例如：

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

字符串可以用`+`拼接，但最好只限于简短和简单的情况。
还有其他通常更好的选择。

## 字符串模板

这指的是其他一些语言所说的“插值”。

如果字符串包含一个美元符号`$`，后面跟着一个标识符，或者包含围绕表达式的花括号（`{expression}`），那么它们会分别被替换为对应的值或表达式的结果。

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

如果不用花括号会让解析产生歧义，那么表达式周围就需要花括号`{ }`。

一般来说，使用字符串模板是比使用`+`更高效、更符合习惯的字符串组合方式。

## 字符串函数

Kotlin 提供了 _许多_[`functions`][ref-string-functions]来操作字符串。

大多数情况下，这些是[`extensions functions`][ref-extensions]而不是`String`类的成员，不过这对我们如何使用它们几乎没有影响。

~~~~exercism/note
Kotlin 相当复杂的[文档][ref-string-functions]页面在默认视图中隐藏了扩展函数。
请务必点击`Members & Extensions`以展开此部分。

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

以下示例只展示了可用功能中的一小部分：

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```
