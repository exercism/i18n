# 简介

为了开启 C++ 之旅，我们先从变量、函数调用和注释开始。

## 注释

注释有两种：单行注释和多行注释。
同一行上`//`之后的所有内容都会被编译器忽略。
多行注释也叫 C 风格注释。
它们由`/*`和`*/`包围。
位于这两者之间的任何内容同样会被忽略。

## 变量

C++ 是一门类型化的语言。
所有类型都必须在编译时确定，而且通常需要显式写明。
变量的类型不能改变。
一个名为`years`的整数变量可以这样声明：

```cpp
int years;
```

声明变量时进行初始化是一个好习惯。
C++ 提供了多种方式来实现这一点。
使用大括号的写法更符合现代 C++ 的风格，但等号写法也非常常见。

```cpp
int tomatoes{80};
int potatoes = 40;
```

~~~~exercism/caution
C++ 确实允许使用未初始化的变量。
在变量被有意设置之前，它的值是未定义的，可能包含任何内容。
为了避免“未设置就使用”的错误和未定义行为，建议**始终初始化**。
未定义行为可能在你最不希望的时刻让程序崩溃，哪怕它之前一直运行良好。
怎么强调都不为过：不惜一切代价避免未定义行为。
~~~~

## 算术运算

像`*`、`+`或`-`这样的运算符，可以构成`3 * 2`或`tomatoes + potatoes`这样的表达式。

## 更新变量

只要类型不变，就可以重新给变量赋值：

```cpp
tomatoes = tomatoes - 5; // tomatoes is now 75
potatoes = (32 * 2) + 11; // potatoes is now 75 as well
```

## 函数

函数有名称、返回类型，以及一个（可以为空的）形参列表。
下面是一个名为`always_fortyseven`、总是返回 47 的函数：

```cpp
int always_fortyseven() {
    return 47;
}
```

下面是`vip_fee`，它有一个形参：
```cpp
int vip_fee(int standard_fee) {
    /*
    vip_fee calculates the vip fee based on the standard_fee.
    */
    int vip_multi{3};
    return standard_fee * vip_multi;
}
```

还有`total_fee`，它有三个形参，并调用了另一个函数。

```cpp
int total_fee(int vips, int adults, int kids) {
    /*
    total_fee calculates the total price for a group of VIP and adult guests with kids.
    Kids get a flat discount on the standard fee.
    VIP guest fees are calculated by calling vip_fee.
    */
    int standard_fee{30};
    int kids_discount{15};

    int kids_total_fee = kids  * (standard_fee - kids_discount);
    int vips_total_fee = vips * vip_fee(standard_fee);
    int adult_total_fee = adults * standard_fee;

    return vips_total_fee + adult_total_fee + kids_total_fee;
}
```

C++ 中的函数不像某些语言那样返回最后一条语句的值。
代码要通过编译，必须使用`return`关键字。

### 空白字符

空白字符用于格式化源代码，包括空格、制表符和换行符。
编译器会忽略多余的空白字符，因此你可以用它们来组织代码结构。
巧妙使用空白字符可以提升代码的可读性。
格式化规范有很多种，但它们都只是约定，编译器并不会强制执行。

```cpp
// Formatting makes it easier to find bugs

int eggs_yolks =  3;
int      yeast = 15;

int flour=500;int sugar=200;// compact, but difficult to read
```
