# 安装

我们将使用 *PolyML* 作为 Standard ML 的实现。

如果你使用的是 Windows，可以从 [https://github.com/polyml/polyml/releases](https://github.com/polyml/polyml/releases) 下载安装程序。
Linux/OS X/Free BSD 的通用说明见 [https://github.com/polyml/polyml#readme](https://github.com/polyml/polyml#readme)。

如果你想从源码安装，过程相当简单：

```sh
$ git clone https://github.com/polyml/polyml.git
$ cd polyml
$ ./configure
```

如果你想把它安装到自定义位置，比如`$HOME/.local`：

```sh
$ ./configure --prefix=$HOME/.local
```

最后一步：

```sh
$ make compiler
$ make install
```

检查是否安装正确：

```sh
$ poly
```

如果看到了翻译，就说明你已经准备好了！
如果没有，你大概需要把`$HOME/.local/bin`（或`<you prefix>/bin`）加到`$PATH`里。
