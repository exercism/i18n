# 测试

按照[测试驱动开发的三条规则][3-tdd-rules]，先让第一个测试通过编译、链接并运行成功。

随附的 makefile 中有一个 `test` 任务，可以用它来构建并运行测试。

```console
$ make test
```

先只写出解决编译器报错所需的函数，让测试失败。
然后只写刚好能让测试通过的代码。
做完这一步，再进入下一个测试。

在逐个通过测试的过程中，花点时间重构你的实现，让它更易读、表达更清晰，然后再进入下一个测试。

尽量使用标准的 C99 设施，而不是自己动手编写底层的算法或功能。

## 检查内存泄漏

makefile 还附带了一个构建目标，用来检查内存泄漏和数组越界访问之类的常见错误。
要运行这些检查，请在命令行中执行：

```console
$ make memcheck
```
