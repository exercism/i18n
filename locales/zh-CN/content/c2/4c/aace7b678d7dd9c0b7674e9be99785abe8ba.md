# 简介

Elixir 是一门动态类型语言，也就是说它不提供编译时的类型检查。不过，类型规范仍然可以作为一种文档形式使用。

使用`@spec`模块属性，可以在函数定义之前为函数添加类型规范。`@spec`后面跟函数名，以及用括号括起来、以逗号分隔的所有实参类型。返回值的类型与函数的实参之间用双冒号`::`分隔。

```elixir
@spec longer_than?(String.t(), non_neg_integer()) :: boolean()
def longer_than?(string, length), do: String.length(string) > length
```

## 类型

最常用的类型包括：

- 布尔值：`boolean()`
- 字符串：`String.t()`
- 数字：`integer()`、`non_neg_integer()`、`pos_integer()`、`float()`
- 数组：`list()`
- 任意类型的值：`any()`

有些类型还可以参数化，例如`list(integer)`表示整数数组。

字面量也可以用作类型。

使用竖线`|`可以写出类型的联合。例如，`integer() | :error`表示一个整数，或者原子字面量`:error`。

所有类型的完整列表可以在[官方文档的“Typespecs”部分][types]中找到。

## 命名实参

类型规范中的实参也可以命名，这在区分多个同类型的实参时很有用。实参名后面跟一个双冒号，放在实参类型的前面。

```elixir
@spec to_hex({hue :: integer, saturation :: integer, lightness :: integer}) :: String.t()
```

## 自定义类型

类型规范并不局限于内置类型。使用`@type`模块属性可以定义自定义类型。自定义类型的定义以类型名开头，后面跟一个双冒号，然后是类型本身。

```elixir
@type color :: {hue :: integer, saturation :: integer, lightness :: integer}

@spec to_hex(color()) :: String.t()
```

自定义类型既可以在定义它的模块中使用，也可以在其他模块中使用。

[types]: https://hexdocs.pm/elixir/typespecs.html#types-and-their-syntax
