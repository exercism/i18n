# 提示

## 1. 检查“快速攻击”行动是否可行

- 逻辑非运算符（`!`）可以放在表达式前面，把它的值取反。
- 可以看看这篇关于逻辑运算符的 [MDN 文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!)

## 2. 检查“侦察”行动是否可行

- 逻辑表达式从左到右求值，并会检测是否可能出现“短路”。
- 想全面理解从左到右的求值机制，可以看看[这篇文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)！

## 3. 检查“向囚犯发信号”行动是否可行

- 逻辑运算符按优先级从高到低依次是：`!`、`&&`、`||`。
- 可以看看这篇关于运算符优先级的 [MDN 文章](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity)

## 4. 检查“释放囚犯”行动是否可行

- `()`是优先级最高的运算符。可以用它把逻辑表达式分组。
