# 说明

你的朋友 Chandler 打算去世界各地充满异国风情的国家旅行。可惜，Chandler 的数学不太好。他非常担心旅途中被货币兑换点坑，所以想让你帮他做一个货币计算器。以下是他对这个应用的具体要求：

## 1. 估算兑换后的价值

创建`exchange_money()`函数，它接收 2 个形参：

1. `budget`：你计划用于兑换的金额。
2. `exchange_rate`：一单位外币相当于多少本国货币。

这个函数应返回兑换后货币的价值。

**注意：**如果你的货币是美元，想把美元按`1.20`的汇率兑换成欧元，那么`1.20 USD == 1 EUR`。

```julia
julia> exchange_money(127.5, 1.2)
106.25
```

## 2. 计算兑换后剩余的金额

创建`get_change()`函数，它接收 2 个形参：

1. `budget`：兑换前的金额。
2. `exchanging_value`：从预算中*取走*用于兑换的金额。

这个函数应返回预算中*剩余*的金额。

```julia
julia> get_change(127.5, 120)
7.5
```

## 3. 计算纸币的价值

创建`get_value_of_bills()`函数，它接收 2 个形参：

1. `denomination`：单张纸币的面值。
2. `number_of_bills`：纸币的总张数。

这个兑换点只处理特定面额单位的现金。你收到的总额必须能被一张“纸币”或一个单位的面值整除，因此可能会留下小数或余数。你的函数应只返回兑换点返还的纸币的总价值（*不含小数部分*）。可惜的是，兑换点会把余数/零头留作额外的奖励。

```julia
julia> get_value_of_bills(5, 128)
640
```

## 4. 计算纸币的张数

创建`get_number_of_bills()`函数，它接收`amount`和`denomination`。

这个函数应返回在给定的*amount*内你能收到的*纸币张数*。换句话说：起始金额能装下多少张*整张纸币*？记住，你只能收到*整张纸币*，不能收到零碎的纸币，所以记得相应地做除法。实际上，你是在*向下*取整到最接近的整张纸币/面值。

```julia
julia> get_number_of_bills(127.5, 5)
25
```

## 5. 计算兑换成纸币后的剩余

创建`get_leftover_of_bills()`函数，它接收`amount`和`denomination`。

这个函数应返回在给定纸币面值的情况下，起始*amount*中无法返还的*剩余金额*。准确知道兑换点能留下多少钱非常重要。

```julia
julia> get_leftover_of_bills(127.5, 20)
7.5
```

## 6. 计算兑换后的价值

创建`exchangeable_value()`函数，它接收`budget`、`exchange_rate`、`spread`和`denomination`。

形参`spread`是作为兑换费*收取的百分比*，以整数表示。需要将它除以 100 转换成小数。如果`1.00 EUR == 1.20 USD`，而*spread*为`10`，那么实际的总汇率将是：`1.00 EUR == 1.32 USD`，因为 1.20 的 10% 是 0.12，这笔额外费用会加到兑换中。

这个函数应在计算出*汇率*加上*spread*之后，返回新货币的最大价值。记住，货币的*面值*是整数，不能再细分。

**注意：**返回值应为整数类型。

```julia
julia> exchangeable_value(127.25, 1.20, 10, 20)
80

julia> exchangeable_value(127.25, 1.20, 10, 5)
95
```
