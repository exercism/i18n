# 关于

Gleam 中的正则表达式遵循 **PCRE** 规范（**P**erl **C**ompatible **R**egular **E**xpressions），这一点与 Java、JavaScript、Ruby 等其他流行语言类似。

`gleam/regex`模块提供了处理正则表达式的函数。

~~~~exercism/note
本练习假设你已经了解正则表达式的语法，包括字符类、量词、分组和捕获。

如果需要复习正则表达式的知识，可以看看这些资料：[Regular-Expressions.info](https://www.regular-expressions.info)、[Rex Egg](https://www.rexegg.com/)、[RegexOne](https://regexone.com/)、[Regular Expressions 101](https://regex101.com/)、[RegExr](https://regexr.com/)。
~~~~

创建正则表达式最常见的方式是使用`regex.from_string`函数。

```gleam
let assert Ok(re) = regex.from_string("test")
```

如果正则表达式的语法无效，`regex.from_string`函数会返回`Error`，因此这里使用了 let 断言来确保正则表达式有效。

可以用`regex.check`函数来检查正则表达式是否匹配某个字符串。

```gleam
let assert Ok(re) = regex.from_string("test")

regex.check(re, "this is a test")
// -> True

regex.check(re, "this is too")
// -> False
```


## 捕获

如果想用正则表达式捕获子字符串，可以用`regex.scan`函数返回一个匹配结果的数组。

```gleam
let assert Ok(re) = regex.from_string("[oi]n a (\\w+)")
regex.scan(with: re, content: "I am on a boat in a lake.")
// -> [
//   Match(
//     content: "on a boat",
//     submatches: [Some("boat")]
//   ),
//   Match(
//     content: "in a lake",
//     submatches: [Some("lake")]
//   )
// ]
```

## 修饰符

使用`regex.compile`函数创建正则表达式并传入选项，就可以改变它的行为。

```gleam
let options = regex.Options(case_insensitive: True, multi_line: False)
let assert Ok(re) = regex.compile("[A-Z]", with: options)
regex.check(re, "abc123")
// -> True
```
