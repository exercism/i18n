# 燃油数据转换 JSON

## 问题描述

ABC 公司的每位员工都享有不限量的燃油补贴。员工每次给车加油时都必须提交一条记录。这些记录会追加到同一个 JSON 文件，在月底统一处理。

作为数字运营团队的一员，你的任务是读取这个 JSON 文件，并把结果写入另一个 JSON 文件。输出文件中应为每位员工保留一条记录，包含以下信息：

- 员工编号
- 加油次数
- 总燃油费用
- 总加仑数
- 累计里程

你会收到两个 `string` 参数。

1. 输入 JSON 文件路径。
1. 输出 JSON 文件路径。

输入 JSON 文件包含一个 JSON 对象数组。每个 JSON 对象的形式如下。


```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "odometerReading": {
                "type": "integer"
            },
            "gallons": {
                "type": "number"
            },
            "gasPrice": {
                "type": "number"
            }
        },
        "required": [
            "employeeId",
            "odometerReading",
            "gallons",
            "gasPrice"
        ]
    }
}
```

```ballerina
// Ballerina record type definition
type FillUpEntry record {|
    int employeeId;
    int odometerReading;
    decimal gallons;
    decimal gasPrice;
|};
```

你的任务是把输入的 JSON 转换成以下 JSON 格式，并把内容写入指定路径。输出文件中应为每位员工保留一条记录，并按 `employeeId` 升序排列。

```json
{
    "type": "array",
    "items": {
        "type": "object",
        "properties": {
            "employeeId": {
                "type": "integer"
            },
            "gasFillUpCount": {
                "type": "integer"
            },
            "totalFuelCost": {
                "type": "number"
            },
            "totalGallons": {
                "type": "number"
            },
            "totalMilesAccrued": {
                "type": "integer"
            }
        },
        "required": [
            "employeeId",
            "gasFillUpCount",
            "totalFuelCost",
            "totalGallons",
            "totalMilesAccrued"
        ]
    }
 }
```

```ballerina
// Ballerina record type definition
type EmployeeFillUpSummary record {|
    int employeeId;
    int gasFillUpCount;
    decimal totalFuelCost;
    decimal totalGallons;
    int totalMilesAccrued;
|};
```

## 约束条件

- 输入 JSON 文件中加油记录的数量 `n`：0 <= n <= 1000
- 公司员工数量：97
- 油价按加仑计算
- 没有缺失的加油记录

## 提示

- 使用 [`ballerina/io` 模块](https://lib.ballerina.io/ballerina/io/latest)读写 JSON 文件。
- 将 JSON 值转换为应用程序特定的类型，以便以类型安全的方式处理数据。相关信息请参阅 Ballerina By Examples (BBE) 中的[转换为用户定义类型的示例](https://ballerina.io/learn/by-example/convert-from-json-to-user-defined-type)。

```ballerina
   json jsonPayload = {id: "2", title: "Jeru", artist: "Gerry Mulligan", price: 17.99};

   // Using cloneWithType  
   Album album1 = check jsonPayload.cloneWithType();
   io:println(album1);
 
   // Using fromJsonWithType
   Album album2 = check jsonPayload.fromJsonWithType();
   io:println(album2);
```

- [解构记录](https://ballerina.io/learn/by-example/destructure-records-using-query)有助于减少代码的冗长。

```ballerina
   Album {id, title, artist, price} = album1;
   io:println(id);
   io:println(title);
```

- 对于只有一个表达式的函数，使用表达式函数体的写法。例如只有 `return` 语句的函数。

```ballerina
   function cfr(int deaths, int cases) returns decimal => <decimal>deaths / <decimal>cases * 100;
```
