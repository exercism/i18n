# 推荐学习资源

欢迎开始学习 ColdFusion（CFML）！CFML 是一门动态、弱类型的 JVM 脚本语言。它有两种不同的文件类型。`.cfm` 文件（ColdFusion 标记）完全是过程式的，使用基于标签的语法来生成 HTML 模板。如果构建网站，可以用它们作为视图：

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

另一种文件是 `.cfc`（ColdFusion 组件），用它来声明类。组件用于业务逻辑、模型和控制器。它们通常使用脚本语法，读起来和 JavaScript 很像。

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
