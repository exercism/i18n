## 导入

模块通常用`use`关键字加载。这个操作既会加载模块，也会调用它的`import`方法，导入所有已导出的符号。

包`@EXPORT`数组中的符号默认会被导入。包`@EXPORT_OK`数组中的符号则必须显式导入。

在 Perl `v5.37` 之前，模块必须以一个真值结尾（通常是 `1`），以表明模块已成功加载。使用 [`module_true`][module_true] 功能时就不再需要这样做了。

## 导出

一个符号要先被导出，才能被导入。[Exporter][Exporter] 模块随 Perl 一同提供，是导出符号最方便的选择之一。

定义模块：
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

使用模块：
```perl
use Foo ('bar');

bar();
```

## Pragma

pragma 是一种模块，可以影响 Perl 行为的某些方面。

人们通常建议使用 [`strict`][strict] 和 [`warnings`][warnings] 这两个 pragma，前者用来限制不安全的写法，后者用来标记潜在的问题。使用 `use v5.12` 或更高版本时，会自动启用 `strict` pragma；使用 `use v5.35` 或更高版本时，会自动启用 `warnings` pragma。

[`feature`][feature] pragma 让你可以启用较新和实验性的 Perl 功能。当`use`关键字指定了某个具体的 Perl 版本时，它会启用该版本对应的功能包。

## 核心模块

除了 [Exporter][Exporter]，Perl 还提供了大量可供使用的[核心模块][perl-core-modules]。你在这里可能遇到的练习中，一些有用的例子包括 [List::Util][List::Util]、[Time::Piece][Time::Piece] 和 [Math::BigRat][Math::BigRat]。

## CPAN

除了核心模块之外，[CPAN][metacpan] 还有数千个由 Perl 社区创建、可供安装的额外模块。Perl track 使用 [cpanfile][test-runner-cpanfile] 来安装一批模块，这些模块可以在 Exercism 的 Perl test runner 中使用。
