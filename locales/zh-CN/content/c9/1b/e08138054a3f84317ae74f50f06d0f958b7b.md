# 测试

## 运行测试

要运行测试，执行以下命令：

```bash
dotnet test
```

要在每次修改源文件后自动运行测试，执行以下命令：

```bash
dotnet watch test
```

## 完成练习

完成练习意味着让它的所有测试通过。默认情况下，运行测试时只会执行一个测试（第一个）。这是有意为之的，这样你就可以专注于让这一个测试通过。一旦它通过，你就可以从测试的 `[Fact]` 或 `[Theory]` 特性中删掉 `Skip = "Remove this Skip property to run this test"`，从而启用下一个测试。当所有测试都已启用，并且你的实现让它们全部通过时，你就完成了这个练习！

为了帮你起步，每个练习都附带一个存根实现文件。你可以以这个文件为起点来构建你提交的解答。如果你认为合适，可以随意删除或修改这个文件。

## 使用包

大多数练习不使用任何外部包就能完成。不过，对于确实想使用外部包的练习，你可以运行以下命令，把它添加到项目中：

```bash
dotnet add package [package-name]
```
