# 简介

`for` 循环是重复执行某段逻辑时最常用的语句之一。
在 JavaScript 中，它由`for`关键字、用圆括号括起来的_头部_，以及一个用大括号括起来、包含循环_主体_的代码块组成。

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

初始化通常用来创建一个计数器变量，条件用来判断循环该继续还是该停止，步进则在每次重复的末尾让计数器自增。
头部的各个部分之间用分号隔开。

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```
