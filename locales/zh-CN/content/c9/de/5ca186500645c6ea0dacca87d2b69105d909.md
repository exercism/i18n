# 说明

实现一个把英语翻译成 Pig Latin 的程序。

Pig Latin 是一门编造出来的儿童语言，本意就是让人听不懂。它只遵循几条简单的规则（见下文），但一旦说得快，非儿童（以及非母语者）就很难听懂。

- **规则 1**：如果单词以元音开头，就在词尾加上 "ay" 音。请注意，单词开头的 "xr" 和 "yt" 发的是元音（例如 "xray" -> "xrayay"，"yttria" -> "yttriaay"）。
- **规则 2**：如果单词以辅音开头，就把它移到词尾，然后再在词尾加上 "ay" 音。辅音可以由多个辅音字母组成，也就是辅音连缀（例如 "chair" -> "airchay"）。
- **规则 3**：如果单词以辅音后接 "qu" 开头，就把它移到词尾，然后再在词尾加上 "ay" 音（例如 "square" -> "aresquay"）。
- **规则 4**：如果单词里的 "y" 出现在辅音连缀之后，或者在两个字母的单词里充当第二个字母，它就发元音（例如 "rhythm" -> "ythmrhay"，"my" -> "ymay"）。

针对边界情况还有一些规则，而且也存在地区变体。

想了解更多，可以阅读[维基百科上的 Pig Latin][pig-latin]。
