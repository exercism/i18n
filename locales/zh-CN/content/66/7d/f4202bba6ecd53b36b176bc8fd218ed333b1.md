# 说明

你在为一场无挡板篮球比赛管理记分牌。与之前学过的所有内容不同，记分牌必须记住已经发生的事。

`SCOREBOARD`类需要具备以下内容。代码骨架已经给出了这个类及其两个属性声明，请补全其余部分。

## 1. 创建记分牌

`create`接收主队名称和客队名称，返回一个两队比分都为零的记分牌。

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. 得一分

`home_goal`给主队比分加一，`away_goal`给客队比分加一。两者都不返回任何东西。

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. 读取记分牌

`summary`返回记分牌的书面记录形式：主队名、主队比分、一个短横线、客队比分，然后是客队名。

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

空格与所示完全一致，短横线是一个单独的`-`。

## 4. 谁领先？

`leader`返回领先队伍的名称，当比分相同时返回`"Draw"`。

```sather
board.leader
-- => "Vixens"
```

## 5. 领先多少？

`margin`返回两队相差多少个进球。无论哪队领先，这个值都不会是负数。

```sather
board.margin
-- => 1
```
