# 说明

作为准魔术师，Elyse 需要练一些基本功。她有一副牌，想要对它做各种操作。

为了简单一点，她只用 1 到 10 这十张牌。

## 1. 从牌堆中取出一张牌

实现`getCard`函数，返回给定牌堆中位置为`index`的那张牌。如果这个下标不在牌堆中，就返回 Nothing。

```elm
getCard 2 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Just 4
getCard 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Nothing
```

## 2. 修改牌堆中的一张牌

实现`setCard`函数，它返回一个牌堆，其中位置为`index`的那张牌被替换为传入的新牌。
如果`index`不在牌堆中，就返回原来的牌堆。

```elm
setCard 2 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 6, 1 ]
setCard 6 6 ( Array.fromList [ 1, 2, 4, 1 ] )
    --> Array.fromList [ 1, 2, 4, 1 ]
```

## 3. 向牌堆中添加一张牌

实现`addCard`函数，返回加入了这张新牌的牌堆。

```elm
addCard 8 ( Array.fromList [ 5, 9, 7, 1 ] )
    --> Array.fromList [ 5, 9, 7, 1, 8 ]
```

## 4. 从牌堆中移除一张牌

实现`removeCard`函数，返回一个移除了位置为`index`的那张牌之后的牌堆。
如果给定的`index`不是牌堆中的有效下标，就返回原来的牌堆。

```elm
removeCard 2 ( Array.fromList [ 3, 2, 6, 4, 8 ] )
    --> Array.fromList [ 3, 2, 4, 8 ]
removeCard 2 ( Array.fromList [ 3, 2 ] )
    --> Array.fromList [ 3, 2 ]
```

## 5. 统计牌堆中偶数牌的数量

实现`evenCardCount`函数，统计牌堆中偶数牌的数量。

```elm
evenCardCount (Array.fromList [ 3, 8, 4, 5, 1, 6, 10 ] )
    --> 4
```
