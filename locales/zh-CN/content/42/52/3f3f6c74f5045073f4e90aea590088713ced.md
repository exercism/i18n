# 说明

Chaitana 经营着一座非常受欢迎的主题公园。
在风景优美的园区正中央，她只有一座游乐设施：The Biggest Roller Coaster in the World(TM)。
尽管只有这一个游乐项目，人们还是从世界各地赶来，排上几个小时的队，只为有机会坐上 Chaitana 的超级过山车。

这个项目有两条队列，每条都用一个`array`表示：

1. 普通队列
2. 快速队列（_也叫 Fast-track_），人们额外付费就能优先入场。

你需要写一些代码，来更好地管理公园里的游客。
你得尽快实现下面这些函数，免得游客（还有你的老板 Chaitana！）发脾气。

## 1. 把某人加入队列

定义`ColossalCoaster.add_to_queue`方法，它接收 4 个实参`<express_queue>, <normal_queue>, <ticket_type>, <person_name>`，并返回加入了此人姓名后的相应队列。

1. `<ticket_type>`是一个`Int32`，其中 1 == express_queue，0 == normal_queue。
2. `<person_name>`是要加入相应队列的那个人的名字（类型为`String`）。

```crystal
express_queue = ["Tony", "Bruce"]
normal_queue = ["RobotGuy", "WW"]
ColossalCoaster.add_to_queue(express_queue, normal_queue, 1, "RichieRich")
# => ["Tony", "Bruce", "RichieRich"]
```

## 2. 我的朋友在哪儿？

有个人来公园来晚了，却想加入朋友们正在排队的那条队列。
但他不知道朋友们排在哪儿，又没有手机信号，没法打电话联系他们。

定义`ColossalCoaster.find_my_friend`方法，它接收 2 个实参`queue`和`friend_name`，并返回这个人的名字在队列中的位置。

1. `<queue>`是排队人群组成的`array`。
2. `<friend_name>`是你要查找下标的那个朋友的名字（即他在队列中的位置）。

```crystal
ColossalCoaster.find_my_friend(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve")
# => 1
```

## 3. 我能加入他们吗？

既然已经找到了他们的朋友（见上面的任务 2），这位迟到的人就想排到朋友所在的位置。
定义`ColossalCoaster.add_with_friends`方法，它接收 3 个实参`queue`、`friend_name`和`person_name`。

1. `<queue>`是排队人群组成的`array`。
2. `<friend_name>`是朋友的名字，这个人要加到这个朋友所在的位置。
2. `<person_name>`是要加到该下标位置的人的名字。

返回加入了这位迟到者名字后的队列。

```crystal
ColossalCoaster.add_with_friends(["Natasha", "Steve", "T'challa", "Wanda", "Rocket"], "Steve", "Bucky")
# => ["Natasha", "Bucky", "Steve", "T'challa", "Wanda", "Rocket"]
```

## 4. 队列里的讨厌鬼

你刚从队列那边听说，有个特别讨厌的家伙又推又嚷，还在捣乱。
你得把这个捣蛋鬼赶出去，因为他行为不端！

定义`ColossalCoaster.remove_from_queue`方法，它接收 2 个实参`queue`和`person_name`。

1. `<queue>`是排队人群组成的`array`。
2. `<person_name>`是需要被赶出去的那个人的名字。

返回去掉这个讨厌鬼名字后的队列。

```crystal
ColossalCoaster.remove_from_queue(["Natasha", "Steve", "Eltran", "Wanda", "Rocket"], "Eltran")
# => ["Natasha", "Steve", "Wanda", "Rocket"]
```

## 5. 对队列排序

出于管理需要，你要把某个队列里的所有名字按字母顺序排好。

定义`ColossalCoaster.sorted_queue`方法，它接收 1 个实参`queue`（排队人群组成的`array`）。
该方法应返回排好序的`array`副本。

```crystal
ColossalCoaster.sorted_queue(["Natasha", "Steve", "Eltran", "Natasha", "Rocket"])
# => ['Eltran', 'Natasha', 'Natasha', 'Rocket', 'Steve']
```
