# 简介

## 默认参数值

在形参列表中，在形参的类型注解后面给该形参赋值，就能为函数的任意形参提供[默认参数值][default-parameter-values]。指定了默认参数值之后，函数的调用方在调用该函数时可以省略这个形参，转而使用默认值。

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## 可变参数

[可变参数][variadic-parameters]允许一个形参接受零个或多个指定类型的值。
定义可变参数的方法是：在形参的类型注解后面加上三个点（`...`）。

在函数体内部，Swift 会把这些值以指定类型的数组形式提供出来：

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
如果函数在可变参数之后还包含其他形参，那么紧随可变参数之后的第一个形参**必须**带一个显式的实参标签，这样 Swift 才知道可变实参列表在哪里结束。
~~~~


## 输入输出参数

在函数体内部，形参被当作常量而不是变量；试图修改形参的值会引发编译时错误。
如果函数想要修改形参的值，就必须使用[_输入输出参数_][in-out-parameters]，把这种可修改性明确表达出来。

要使用输入输出参数，程序员必须确认三件事：

1. 函数定义必须显式地标记输入输出参数：在形参类型注解的`:`和类型名之间写上关键字`inout`。
2. 传入输入输出参数的值必须声明为变量，而不能是常量。同样，它也不能是字面量。
3. 在调用函数时，变量名前面必须加一个`&`，显式地标明它是可修改的。

做到这一点后，函数会在内部复制一份输入输出参数，按照函数体中的指示修改它，然后在函数返回时把修改后的值复制回传入的那个变量。

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
关于输入输出参数，还有几条额外的规则需要注意。

1. 在带有输入输出参数的函数内部，不允许引用作为输入输出参数传入的那个变量。
2. 在同一个函数中，同一个变量不能作为多个输入输出参数传入。
   例如，`inoutFunc(&mutVar, &mutVar)`会引发编译器错误。
~~~~

## 嵌套函数

在 Swift 中，你可以把[函数定义在其他函数内部][nested-functions]。
这样的函数称为**嵌套函数**。

嵌套函数通常用作私有辅助函数，为所在的外层函数完成特定的任务，同时不会让外层作用域变得杂乱：

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

嵌套函数的行为与普通函数相同，但可见范围仅限于所在外层函数的函数体。
