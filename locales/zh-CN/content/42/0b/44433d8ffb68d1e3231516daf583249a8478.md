# 关于

字面量是直接在代码中使用的固定值。
它们在运行时不需要任何计算。
字面量有多种形式，可以高效地表示不同类型的数据。
最常见的字面量是数值型的，但日期、时间和字符串类型也有对应的字面量操作符。
后面的概念会介绍如何使用用户自定义的字面量操作符。

## 数值字面量

数值字面量包括十进制、八进制、十六进制和二进制表示。
这些基础知识已经在[数字概念][numbers-concept]中介绍过了。

`23`、`0x50f7ba11`和`0xba5eba11`这样的表示形式，都会被编译器理解为`int`。
通用的`int`类型是有符号的，（[取决于编译器和系统][in-depth-integers]）范围通常是`-2'147'483'648`到`2'147'483'647`。
大多数情况下这已经足够，你不需要担心具体的类型。

有些场景需要更大的范围，或者要求程序占用的内存非常小。
为了表达得更明确，可以直接在数值字面量中指定具体的整数类型。

当不需要负数、但想要更大的范围时，可以用`u`或`U`后缀表示_无符号_整数。
想要更大的范围，可以用`L`甚至`LL`表示 long 和 long long 类型。

~~~~exercism/caution
允许使用小写的`l`，但它很容易与数字`1`混淆，因此不推荐使用。
~~~~

```cpp
auto net_worth_christian_grey{2'500'000'000U}; // out of range for 32-bit integers
auto net_worth_carlisle_cullen{46'000'000'000LL}; // int and uint are not enough
```

浮点数在编译时通常会解析为`double`。
这是一个不错的默认情况，而使用范围更窄的`float`类型的场景，比上面无符号的例子要少见。

```cpp
auto light_year_in_m{9.46073e+15f}; // well in the range of float
auto earth_to_edge_comoving_distance_in_nm{4.32355e+32}; // needs double type for magnitude
auto eulers_number{2.718281828459045}; // needs double type for precision
```

## 字符和字符串字面量

其他概念已经用过单引号形式的字符字面量，比如`'}'`或`'@'`。

在 C++ 中，`char`仅限于前 128 个 [ASCII 字符编码][ascii-code]。
要使用多个 ASCII 字符，或像`‰`这样的扩展 ASCII 字符，甚至像`麗`和`ẞ`这样的 Unicode 字符，就需要其他类型。
前面的概念用_双引号_引入了字符串字面量：`"一体どういう意味ですか。C++です"`。
这个日语句子的实际类型是`const char (&)[46]`，也就是一个 C 风格的字符串。

字符串字面量默认不会自动生效。
要使用 _string_ 字面量`""s`或 _string-view_ 字面量`""sv`，用户必须通过相关的命名空间来指明：

```cpp
#include <string>
#include <string_view>

using namespace std::literals;

auto green_light{"무궁화 꽃 이 피었 습니다"};
// green_light type is const char (&)[36]
auto umbrella{"달고나"s};
// umbrella type is std::basic_string<char>, the same as std::string
auto il_nam{"보는 것이 하는 것보다 더 재미있을 수가 없지"sv};
// il_nam type is std::basic_string_view<char>
```

_string_view_ 可以看作是对一个 const 字符串的引用。
