# 安装

有关如何在你的系统上完成安装的说明，请参阅 [System/Installation][install-link]。

~~~exercism/caution
如果你已经安装了 Java Development Kit (JDK)，`jconsole`可执行文件可能会与同名的 Java Console 冲突。

可选的解决办法包括：

- 把 J 编程语言的`jconsole`可执行文件重命名为一个独特的名字（例如`jconsole-jlang`）。

- 调整系统的环境变量或 PATH，让它优先使用 J 编程语言的`jconsole`。

- **Linux 用户**：有一个位于`bin/install.sh`的 bash 脚本，它会在`/usr/`目录中创建一个名为`ijconsole`的**符号链接**。你可以在终端中输入`ijconsole`来使用这个链接。
~~~

J 安装完成后，在终端中打开 J 控制台，输入以下命令来安装单元测试框架：

```j
  load 'pacman'
  'update' jpkg ''
  'install' jpkg 'general/unittest'
  exit 0
```
