# 简介

Clojure 中的`vector`是一个有序、带下标、不可变的集合，可以包含零个或多个值。这意味着向量一旦创建，就无法修改。操作向量的函数会返回一个新向量，而原来的向量保持不变。向量中的值可以是不同的数据类型。可以这样定义向量：

```clojure
(def empty [])
(def single-value [5])
(def single-value-alternative (vector 5))
(def three-values [1 "a" "b"])
```

可以使用下标从向量中取出元素。Clojure 向量的下标从零开始，也就是说第一个元素的下标永远是 0：

```clojure
(def numbers [2 3 5])
;; Read value from vector
(get numbers 2)
;;=> 5
;; Update value in vector
(assoc numbers 2 9)
;;=> [2 3 9]
```

原来的向量并没有改变：

```clojure
numbers
;;=> [2 3 5]
```

要保留更新后的值，就需要把它传递下去，或者用 var 保存起来：

```clojure
(def updated-numbers
  (assoc numbers 2 9))
(get updated-numbers 2)
;;=> 9
```
