# 说明

你的朋友 Kojo 是个数字迷。
他有一个用来玩数字的小网站。
Kojo 的编程水平不太好，所以他向你求助。

你要为 Kojo 网站上的新数字游戏构建两个辅助方法，再构建第三个方法来验证用户可以输入的某些内容。

## 1. 计算老虎机上数字的和

Kojo 网站上的其中一个游戏看起来像一台老虎机，上面有两组带数字的转轮。
每一组数字代表一个数。
为了实现游戏机制，Kojo 需要知道这两个数的和。

编写一个方法 `sumUp`，它接受两个数组作为形参。
每个数组由一个或多个 0 到 9 之间的数字组成。
这个方法应该把每个数组解释成一个数，并返回这两个数的和。

```php
<?php
$lucky_numbers = new LuckyNumbers()

$lucky_numbers->sumUp([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. 判断一个数是否为回文数

网站上的另一个游戏是一个叫“Lucky Numbers”的小测验。
用户可以输入一个数，然后看到这个数是否属于某个秘密序列或模式。
“幸运数字”的序列或模式每个月都会变化，每个用户只有有限的尝试次数来猜出它。

本月的幸运数字应该是回文数。
回文数在把数字反转后仍然保持不变。

实现新的 `isPalindrome` 函数，它接受一个整数作为形参。
如果这个数是回文数，函数应该返回 `true`，否则返回 `false`。
输入的整数始终是正整数。

```php
<?php
$lucky_numbers = new LuckyNumbers()

$lucky_numbers->isPalindrome(1441);
//=>  true

$lucky_numbers->isPalindrome(123);
//=> false
```

## 3. 为无效的用户输入生成错误信息

网站上有多个地方设有输入框，用户可以在其中输入数字并点击按钮来触发某些操作。
Kojo 想提升网站的用户体验。
他希望当用户点击按钮、但输入框里的值无效时，显示一条错误信息。

下面是关于输入框的值是如何提供的一些补充说明。

- 如果用户在输入框中键入内容，与之关联的值始终是字符串，即使用户只键入了数字也是如此。
- 如果用户键入了内容又把它删掉，这个变量将是一个空字符串。
- 在用户开始键入之前，这个变量也是空字符串。

编写一个函数 `validate`，它接受用户输入作为形参。
如果用户没有提供任何输入，`validate` 应该返回 `'Required field'`。
如果输入不代表一个正的非零整数（依据 [PHP 类型转换规则][php-type-cast-int]），则应返回 `'Must be a whole number larger than 0'`。
在其他所有情况下，你可以假定输入是有效的，此时返回值应该是一个空字符串。

```php
<?php
$lucky_numbers = new LuckyNumbers()

$lucky_numbers->validate('123');
// => ''

$lucky_numbers->validate('');
// => 'Required field'

$lucky_numbers->validate('abc');
// => 'Must be a whole number larger than 0'
```

[php-type-cast-int]: https://www.php.net/manual/en/language.types.integer.php#language.types.integer.casting.from-string
