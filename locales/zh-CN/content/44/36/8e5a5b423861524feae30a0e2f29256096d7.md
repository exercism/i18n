# 说明

在这个练习中，你要为纽约一家美容院编写预约排期程序，这家美容院于 2012 年 9 月 15 日开业。

你有五个任务，它们都与预约日期有关。
时间采用 24 小时制（不使用 AM/PM）。
为了尽量简化时区问题，假设所有时间都使用 UTC。

## 1. 解析全数字格式的预约日期

实现`schedule_appointment()`函数，把预约日期的文本表示解析成对应的`DateTime`格式。

注意，输入的格式是美式的月/日/年顺序。

```julia-repl
julia> schedule_appointment("07/25/2023 13:45:00")
2023-07-25T13:45:00
```

## 2. 检查预约是否已经过去

实现`has_passed()`函数，它接收一个预约日期，检查该预约是否在过去：

```julia-repl
julia> has_passed(DateTime(1999, 12, 31, 9, 0, 0))
true
```

## 3. 检查预约是否在下午

实现`is_afternoon_appointment()`函数，它接收一个预约日期，检查该预约是否在下午（>= 12:00 且 < 18:00）：

```julia-repl
julia> is_afternoon_appointment(DateTime(2023, 3, 29, 15, 0, 0))
true
```

## 4. 检查预约是星期几

实现`day_of_week()`函数，返回星期几的_数字_表示。
美容院周日不营业，所以周一是第 1 天，周六是第 6 天。

```R
# a Friday
day_of_week(make_datetime(2026, 06, 05, 12, 30, 00))
#> [1] 5
```

## 5. 重新安排预约

当顾客需要改期时，预约会自动改到下周五的同一时间（因为周五是一周里最清闲的一天）。

实现`reschedule()`函数，它接收原始预约（以月/日/年顺序的文本字符串形式），返回重新安排后的预约。

```R
# a Saturday
reschedule("06/13/2026 12:30:00")
#> [1] "2026-06-19 12:30:00 UTC"
```

如果原预约在周一到周四，就改到_本_周五。
如果原预约在周五或周六，就改到_下_周五。
