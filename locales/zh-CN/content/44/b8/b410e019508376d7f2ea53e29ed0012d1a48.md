# 关于

`GENERIC:`声明引入一个词，它的行为取决于其中一个实参的类。具体的实现由针对特定类的*方法*（`M:`）提供。

```factor
GENERIC: stringify ( obj -- str )
M: integer stringify number>string ;
M: string  stringify ;
M: f       stringify drop "(none)" ;
```

调用 `stringify` 时，Factor 会检查栈顶，找到类与之匹配的最具体的方法，然后运行它。如果没有匹配的方法，就会抛出错误。

## 分派类

默认情况下，分派发生在最顶端的实参上（也就是栈效果中声明的第一个输入）。多实参分派请参见`HOOK:`和`MATH:`，它们分别根据第二个实参或数值提升进行分派。

## 为泛型词添加方法

你可以随时扩展一个泛型词，哪怕是在另一个词汇表里，只要能`USE:`这个泛型词和对应的类即可：

```factor
USING: math ;
M: ratio  area drop 0 ;     ! adds an `area` method for ratios
```

## 内置类上的方法

泛型词在内置类（`integer`、`string`、`array`、`f`、`t`）上和用户定义的元组上一样好用。针对`f`和`t`的方法对“is-set?”式的谓词特别有用，这类谓词有天然的默认值。

## 何时该用泛型词

在以下情况选择`GENERIC:`：

- 同一个操作针对不同的输入有*真正不同*的实现（而不只是根据标签做一次`case`分支）。
- 你预期以后会有其他代码加入新的类型。
- 你希望类型系统确保该操作对每个相关的类都有定义，Factor 可以为你列出缺失的方法。

如果变化只是少量固定的标签枚举，用`case`更简单。
