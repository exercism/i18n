# 关于

Elixir 使用[_行为_][behaviours]来提供通用的接口，同时让每个实现该行为的模块都能有自己的具体实现。其中一个行为就是 Access 行为。

Access 行为提供了一套通用接口，用于从数据结构中按键取出数据。映射和关键字列表都实现了它。

[`Access`][access]模块定义了该接口所需的回调。而[`Map`][map]和[`Keyword`][keyword]模块则实现了所需的回调：[`fetch/2`][map-fetch]、[`get_and_update/3`][map-get-and-update]和[`pop/2`][map-pop]。

要使用这个行为，你可以在一个绑定的变量后面接上_方括号_，然后用键取出与该键关联的值。映射支持任意类型的键，而关键字列表只支持原子键。

```elixir
# Atom as key
my_map = %{key: "my value"}
my_map[:key]
# => "my value"

# String as key
another_map = %{"key" => "my value"}
another_map["key"]
# => "my value"
```

如果数据结构中不存在该键，就会返回`nil`。这可能成为意料之外行为的来源，因为它不会抛出错误。

```elixir
my_map = %{key: "my value"}
my_map[:wrong_key][:other_wrong_key]
# => nil
```

注意，`nil`本身也实现了 Access 行为，对任何键都返回`nil`。

```elixir
nil[:key]
# => nil
```

结构体没有实现 Access 行为。
