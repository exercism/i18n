# 说明

作为一名国际象棋爱好者，你想写出属于自己的版本。没错，网上可能已经有很多现成的国际象棋实现，但你的版本一定会独一无二！

不过，在放飞想象力之前，得先把基础打好。我们先从生成棋盘开始吧。

棋盘的每一格都由一个字母和一个数字的组合来标识。竖直方向的各列（file）用 A 到 H 标记，水平方向的各行（rank）用 1 到 8 编号。

## 1. 定义行的范围

实现`rank_range/0`函数。它应返回一个整数范围，从 1 到 8。

```elixir
Chessboard.rank_range()
```

## 2. 定义列的范围

实现`file_range/0`函数。它应返回一个整数范围，从大写字母 A 的码点到大写字母 H 的码点。

```elixir
Chessboard.file_range()
```

## 3. 把行的范围转换成行数组

实现`ranks/0`函数。它应返回一个整数数组，从 1 到 8。不要手写这个数组，而要用`rank_range/0`函数返回的范围来生成它。

```elixir
Chessboard.ranks()
# => [1, 2, 3, 4, 5, 6, 7, 8]
```

## 4. 把列的范围转换成列数组

实现`files/0`函数。它应返回一个由字母（字符串）组成的数组，从 "A" 到 "H"。不要手写这个数组，而要用`file_range/0`函数返回的范围来生成它。

```elixir
Chessboard.files()
# => ["A", "B", "C", "D", "E", "F", "G", "H"]
```
