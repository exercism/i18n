# 简介

## 常量和函数

Haskell 程序由定义和表达式组成。

常量值用`name = expression`定义。

```haskell
five = 5

six = 3 + 3
```

函数用`name parameters... = expression`定义，其中的参数只用空格分隔。

```haskell
add number1 number2 = number1 + number2
```

调用函数也是一种表达式，写出函数名，并为函数的每个形参依次传入实参，用空格分隔，和定义函数时一样。

```haskell
five = add 2 3
```

可以用括号来指定表达式的求值顺序。

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## 缩进 / 有意义的空白

Haskell 使用空白和缩进来界定代码的边界。
***属于某个表达式的代码，缩进必须比该表达式的起始位置更靠右。***

- 模块、导入语句和顶层函数定义必须从最左边的一列开始。
- 如果表达式被拆成多行，属于该表达式的代码必须缩进到该表达式之下，并且至少缩进一个空格。
- 归为同一组的表达式各部分，应缩进相同数量的空格。

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## 模块

模块会导出函数。
也就是说，你可以使用模块在其导出语句中公开的函数。
模块也可以定义仅供内部使用的函数。
默认情况下，没有显式导出的函数不能在模块外部使用。

在模块的开头，我们要指定模块名。
如果文件叫 Calculator.hs，那么模块就应该命名为 Calculator。
接着指定它导出的函数，之后就可以开始写这些函数了。
所以我们从下面这行开始。

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## 注释

注释是 Haskell 文件中的一些文本，不会被当作代码解释。
它主要是给你自己和其他程序员阅读的。
单行注释有一种轻量的写法，基于两个连字符。
多行注释也可以用 `{-` 和 `-}` 这一对起止分隔符来实现。

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
