# 说明

在这个练习中，你将编写一些代码，帮助你按照最喜欢的烹饪书做出一份美味的千层面。

一共有四个任务，都与做千层面所花的时间有关。

## 1. 定义预期的烤箱时间（分钟）

定义`expected-time`变量，用来表示千层面需要在烤箱里烤多少分钟。根据烹饪书，预期的烤箱时间是 40 分钟：

```clojure
expected-time
;;=> 40
```

## 2. 计算剩余的烤箱时间（分钟）

定义`remaining-time`函数，它接收千层面已经在烤箱里烤了多少分钟作为实参，并根据上一个任务中得出的预期烤箱时间，返回千层面还需要在烤箱里烤多少分钟。

```clojure
(remaining-time 30)
;;=> 10
```

## 3. 计算准备时间（分钟）

定义`prep-time`函数，它接收你往千层面里加的层数作为实参，并返回你准备千层面花了多少分钟，假设每加一层需要 2 分钟。

```clojure
(prep-time 2)
;;=> 4
```

## 4. 计算总工作时间（分钟）

定义`total-time`函数，它接收两个实参：第一个实参是你往千层面里加的层数，第二个实参是千层面已经在烤箱里烤了多少分钟。这个函数应该返回你烹饪千层面总共花了多少分钟，也就是准备时间的分钟数加上千层面此刻在烤箱里已经烤的分钟数。

```clojure
(total-time 3 20)
;;=> 26
```
