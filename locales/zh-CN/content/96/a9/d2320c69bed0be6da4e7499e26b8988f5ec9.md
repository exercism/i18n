# 简介

`Result`类型是 Elm 语言中用于报告错误、并支持错误恢复的方案。它和`Maybe`类型有些相似，但`Maybe`虽然可以由可能失败的函数返回，却不会告诉你失败的原因。`Result`则包含了关于失败原因的上下文。

`Result`类型定义如下：

```elm
type Result error value
  = Ok value
  | Err error
```

在 Elm 术语中，这被称为“自定义类型”定义。
`OK value`和`Error error`中的`error`和`value`代表类型变量，意思是它可以是任意类型，比如`Int`、`Bool`或`String`。
因此，`Result String Int`是一个预期包含`Int`的值，如果出错，这个错误会用`String`来表示。
有一个[Result 模块](https://package.elm-lang.org/packages/elm/core/latest/Result)，其中包含许多处理 result 的实用辅助函数。
