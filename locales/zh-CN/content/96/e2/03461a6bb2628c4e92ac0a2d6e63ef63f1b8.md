# 说明附录

## 关于 `Stream` ability

`Stream` 是 Unison 的一种 ability，用于发出值。

如果你有一个函数，在调用过程中需要顺便产生一些值，就可以使用 `Stream` ability。例如，下面这个函数返回数组的最后一个值，但会在遍历到每个元素时发出一个累计总和：

```
emitRunningTotal : '{Stream Nat} Nat
emitRunningTotal = 'let
  use Nat +
  List.foldLeft (
    acc a -> let
      runningTotal = acc + a
      Stream.emit runningTotal
      a
    ) 0 [1,2,3,4,5]
```

我们可以借助 ability handler，把 Stream 具体化为 List，并同时拿到产生它的那个函数的返回值：

```
> Stream.toListWithResult! emitRunningTotal
  ⧩
  ([1, 3, 5, 7, 9], 5)
```
