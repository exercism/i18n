# 说明

甲板上的水手长每天都要做一次值班简报：固定的问候语，值班船员的点名，最后是解散词。你需要把简报拆分成几个有名字的小片段，再把它们组合起来。

本次练习你要编辑**两个文件**：

- `bosuns-briefing/helpers/helpers.factor`：可复用的小片段。词汇：`bosuns-briefing.helpers`。
- `bosuns-briefing/bosuns-briefing.factor`：组合各个辅助函数的主文件。词汇：`bosuns-briefing`。

## 1. 问候语

在`helpers.factor`中，定义`greeting`，让它返回固定的开场字符串`"All hands, attention!"`。

```factor
greeting .
! => "All hands, attention!"
```

## 2. 船员行

在`helpers.factor`中，定义`crew-line`，让它接收一个名字字符串，并返回在该名字前面加上`"  - "`之后的结果（两个空格、一个连字符、一个空格）。

```factor
"Lopez" crew-line .
! => "  - Lopez"
```

## 3. 解散词

在`helpers.factor`中，定义`closing`，让它返回固定的解散字符串`"Carry on."`。

```factor
closing .
! => "Carry on."
```

## 4. 名单

在`bosuns-briefing.factor`中，定义`roster`，让它接收一个由船员名字组成的数组，并返回一个多行字符串，其中每个名字都用`crew-line`格式化，再用换行符连接起来。

```factor
{ "Lopez" "Mwangi" } roster .
! => "  - Lopez\n  - Mwangi"

{ } roster .
! => ""
```

## 5. 简报

在`bosuns-briefing.factor`中，定义`briefing`，让它接收一个由船员名字组成的数组，并把完整简报作为单个字符串返回：第一行是问候语，接下来的几行是名单，最后一行是解散词。使用前面的辅助函数和`roster`。

```factor
{ "Lopez" "Mwangi" } briefing .
! => "All hands, attention!\n  - Lopez\n  - Mwangi\nCarry on."

{ } briefing .
! => "All hands, attention!\n\nCarry on."
```
