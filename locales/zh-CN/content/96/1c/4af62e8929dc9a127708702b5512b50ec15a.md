# 简介

## 变量

Elixir 是一门动态类型语言，变量的类型只在运行时才会被检查。借助匹配运算符`=`，我们可以把任意类型的值绑定到一个变量名上：

```elixir
# Bound an integer value of 1
count = 1
# You may re-bind variables
count = 2

# You may re-bind any type to a variable
count = false

# Strings can be created by enclosing characters within double quotes
message = "Success!"
```

## 模块

Elixir 是一门[函数式编程语言][functional-programming]，它要求所有具名函数都必须定义在_模块_中。使用`defmodule`关键字来定义模块。所有模块在运行时都可以被其他模块使用，不需要_访问修饰符_就能让程序的其它部分看到它们。_模块_相当于其他编程语言中的_类_。

```elixir
defmodule Calculator do
  # ...
end
```

## 具名函数

_具名函数_必须定义在模块中。使用`def`关键字来定义_公开的_具名函数。

每个函数可以有零个或多个实参。函数中最后一个表达式的值总是会被_隐式返回_。

```elixir
defmodule Calculator do
  def add(x, y) do
    x + y
  end
end
```

调用函数时，需要指明模块名和函数名，并为函数的每个实参传入对应的值。

```elixir
sum = Calculator.add(1, 2)
# => 3
```

可以用`defp`关键字代替`def`来定义_私有_函数。私有函数只能在定义它们的同一个模块内部使用。

在定义函数的同一个模块内部调用该函数时，可以省略模块名。

也可以用单行语法编写简短的函数（注意关键字`do`前后的逗号`,`和冒号`:`）。

```elixir
defmodule Calculator do
  def subtract(x, y) do
    private_subtract(x, y)
  end

  defp private_subtract(x, y), do: x - y
end

difference = Calculator.subtract(7, 2)
# => 5

difference = Calculator.private_subtract(7, 2)
# => ** (UndefinedFunctionError) function Calculator.private_subtract/2 is undefined or private
#       Calculator.private_subtract(7, 2)
```

## 函数的元数

人们通常用_元数_来称呼函数。函数的_元数_就是它接受的实参个数。

```elixir
# add/3 because this function has three arguments, thus an arity of 3
def add(x, y, z) do
  x + y + z
end
```

## 命名约定

模块名应使用`PascalCase`。模块名必须以大写字母`A-Z`开头，可以包含字母`a-zA-Z`、数字`0-9`和下划线`_`。

变量名和函数名应使用`snake_case`。变量名或函数名必须以小写字母`a-z`或下划线`_`开头，可以包含字母`a-zA-Z`、数字`0-9`和下划线`_`，并且可以以问号`?`或感叹号`!`结尾。

## 标准库

Elixir 有一个非常丰富、文档齐全的标准库。文档可以在线查阅：[hexdocs.pm/elixir][docs]。把这个链接保存好，你会经常用到它！

大多数内置数据类型都有对应的模块，提供处理该数据类型的函数。例如，`Integer`模块处理整数，`String`模块处理字符串，`List`模块处理列表，等等。

有一个很重要的模块是`Kernel`模块。它提供构建标准库其余部分所依赖的基础能力，比如算术运算符、控制流宏等等。`Kernel`模块中的函数会被自动导入，所以使用时不需要加`Kernel.`前缀。
