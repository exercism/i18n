# 说明

在这个练习中，你将编写一些代码，帮助你为购买车辆做好准备。

你有三个任务：一个判断你是否需要驾照，一个帮助你在两辆车之间做出选择，还有一个估算二手车的合理价格。

## 1. 判断你是否需要驾照

某些车辆类型需要驾照才能驾驶。
假设只有`"car"`和`"truck"`这两种类型需要驾照，其他类型都可以无证驾驶。

实现`NeedsLicense(kind)`函数，它接收车辆类型，并返回一个布尔值，表示该类型车辆是否需要驾照。

```go
needLicense := NeedsLicense("car")
// => true

needLicense = NeedsLicense("bike")
// => false

needLicense = NeedsLicense("truck")
// => true
```

## 2. 在两辆候选车辆之间做出选择

你评估了可选的车辆。
你把范围缩小到了两个选项，但需要帮助做出最终决定。
为此，实现`ChooseVehicle(option1, option2)`函数，它接收两辆车作为实参，并返回一个决定，其中包含按字典顺序排在前面的选项。

```go
vehicle := ChooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

ChooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. 估算二手车的价格

既然你已经做出决定，你希望确保在经销商处拿到公道的价格。
由于你打算购买二手车，价格取决于车龄。
粗略估算一下：如果车龄不到 3 年，价格为全新时原价的 80%。
如果车龄至少 10 年，价格为原价的 50%。
如果车龄至少 3 年但不到 10 年，价格为原价的 70%。

实现`CalculateResellPrice(originalPrice, age)`函数，使用`if`、`else if`和`else`来应用这套逻辑（如果你想练习，也可以用其他方法）。
它接收原价和车龄作为实参，并返回经销商处的估价。

```go
CalculateResellPrice(1000, 1)
// => 800

CalculateResellPrice(1000, 5)
// => 700

CalculateResellPrice(1000, 15)
// => 500
```

**注意**：返回值是`float64`。
