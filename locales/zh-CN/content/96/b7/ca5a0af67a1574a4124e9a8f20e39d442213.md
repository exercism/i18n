# 测试

每道练习都包含一个测试文件。
因为 Exercism 提倡[测试驱动开发][tdd]，测试*就是*需求。
一定要读一读测试，弄清楚你的代码会怎样被调用，以及期望得到什么输出。

要运行测试套件：
```bash
tclsh exercise.test
```

## 跳过的测试

完成一个练习，意味着让它所有的测试都通过。默认情况下，运行测试时只会执行一个测试（第一个）。这是有意为之，这样你可以专注于让这一个测试通过。它通过之后，你可以注释掉或删除它前面的`skip`命令，来启用下一个测试。

或者，如果你想不管测试是否处于“跳过”状态，运行全部测试：
```bash
RUN_ALL=1 tclsh exercise.test
```

[tdd]: https://exercism.org/docs/using/solving-exercises/tdd
