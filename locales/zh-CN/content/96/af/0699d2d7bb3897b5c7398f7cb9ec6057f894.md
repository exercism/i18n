# 关于

当你要为只能取一组特定状态的数据建模时，比如一周中的几天、指南针的方向，或者手柄上的按钮，像`Int`或`String`这样的基本类型就有很大的缺点。
使用整数或字符串时，代码必须不断检查无效值（比如状态码`999`，或者像`"leftt"`这样的拼写错误），而且人类读者也不容易看出这些数字代表什么。

Swift 用[枚举][enumerations]（通常简称为 *enum*）解决了这个问题。
枚举为一组相关的、有名字的值定义一个共同的类型。因为编译器提前知道所有可能的`case`，所以它能在编译期检查代码的正确性和完整性。
枚举还可以有方法、初始化器和计算属性。

## 定义枚举

用`enum`关键字定义一个枚举，后面跟上类型名，它的各个`case`列在花括号里。
按照 Swift 的约定，类型名使用`UpperCamelCase`，而每个`case`使用`lowerCamelCase`：

```swift
enum NESButton {
    case up
    case down
    case left
    case right
    case a
    case b
    case select
    case start
}
```

你也可以在一行里定义多个`case`，用逗号隔开：

```swift
enum NESButton {
    case up, down, left, right, a, b, select, start
}
```

要引用某个枚举`case`，先写枚举类型名，再写一个点（`.`），然后是`case`名。一旦类型已知，或者编译器能推断出类型，你就可以省略类型名，改用更简短的点语法：

```swift
var lastPressed = NESButton.up

// Swift infers the type, so you can omit the type name:
lastPressed = .down

let konamiCode: [NESButton] = [.up, .up, .down, .down, .left, .right, .left, .right, .b, .a]
```

## 枚举与`switch`语句

枚举可以和[`switch`语句][enums-and-switches]无缝配合使用。
因为 Swift 中的`switch`必须是穷尽的，编译器会确保你处理每一个可能的`case`：

```swift
lastPressed = .left
switch lastPressed {
case .up: print("You pressed the UP button")
case .down: print("You pressed the DOWN button")
case .left: print("You pressed the LEFT button")
case .right: print("You pressed the RIGHT button")
case .a: print("You pressed the A button")
case .b: print("You pressed the B button")
case .select: print("You pressed the SELECT button")
case .start: print("You pressed the START button")
}
// Prints "You pressed the LEFT button"
```

如果漏掉某个`case`又没有提供`default`子句，编译器就会报错：

```swift
switch lastPressed {
case .up, .down, .left, .right:
    print("You pressed a direction button.")
}
// Error: Switch must be exhaustive
```

把所有`case`都明确列出来，通常比用`default`更好。这样一来，如果你以后新增了一个`case`，编译器会立刻提醒你去更新所有处理该枚举的`switch`语句。

## 方法与初始化器

枚举可以像类和结构体一样定义方法和自定义初始化器。在枚举方法内部，`self`指的是当前的`case`值：

```swift
enum Coin {
    case heads
    case tails

    init(_ value: Int) {
        if value.isMultiple(of: 2) {
            self = .heads
        } else {
            self = .tails
        }
    }

    func flip() -> Coin {
        switch self {
        case .heads: return .tails
        case .tails: return .heads
        }
    }
}

let tails = Coin(13)     // .tails
let heads = Coin(0)      // .heads
let flipped = heads.flip() // .tails
```

## 原始值

枚举的`case`可以预置默认值，叫做[原始值][raw-values]。
一个枚举里所有原始值必须共享同一个类型（比如`Int`、`String`或`Character`）：

```swift
enum NESButton: Character {
    case up = "⬆️"
    case down = "⬇️"
    case left = "⬅️"
    case right = "➡️"
    case a = "🅰️"
    case b = "🅱️"
    case select = "✅"
    case start = "🚦"
}

print(NESButton.left.rawValue) // Prints "⬅️"
```

你可以用`init(rawValue:)`从原始值初始化一个枚举。因为可能传入无效的原始值，这个初始化器返回一个可选值：

```swift
let upButton = NESButton(rawValue: "⬆️") // Optional(NESButton.up)
let invalid = NESButton(rawValue: "🙄")  // nil
```

Swift 可以为`String`和`Int`枚举自动分配原始值：

- 对于`String`枚举，每个`case`的原始值默认就是它的`case`名。
- 对于`Int`枚举，原始值从`0`开始，每次自增 1，除非另有指定。

```swift
enum Planet: Int {
    case mercury = 1, venus, earth, mars
}

print(Planet.earth.rawValue) // Prints 3
```

## 关联值

枚举的`case`还可以附带存储类型各异的自定义值，这些值叫做[关联值][associated-values]：

```swift
enum Suit: Character {
    case diamonds = "♦️", clubs = "♣️", hearts = "♥️", spades = "♠️"
}

enum Card {
    case ace(Suit)
    case king(Suit)
    case queen(Suit)
    case jack(Suit)
    case number(Suit, Int)

    func description() -> String {
        switch self {
        case .ace(let suit): return "A\(suit.rawValue)"
        case .king(let suit): return "K\(suit.rawValue)"
        case .queen(let suit): return "Q\(suit.rawValue)"
        case .jack(let suit): return "J\(suit.rawValue)"
        case let .number(suit, value): return "\(value)\(suit.rawValue)"
        }
    }
}

let aceOfSpades = Card.ace(.spades)
let twoOfHearts = Card.number(.hearts, 2)

print(aceOfSpades.description()) // Prints "A♠️"
print(twoOfHearts.description()) // Prints "2♥️"
```

一个枚举可以使用原始值或关联值，但不能同时使用两者。

## 递归枚举

[递归枚举][recursive-enumerations]是指这样的枚举：它把一个或多个`case`的关联值设为该枚举的另一个实例。
要启用递归，就用`indirect`关键字标记这个`case`（或者整个枚举）：

```swift
enum BinaryTree {
    case leaf(value: Int)
    indirect case node(left: BinaryTree, value: Int, right: BinaryTree)
}

let tree: BinaryTree = .node(
    left: .leaf(value: 1),
    value: 3,
    right: .node(left: .leaf(value: 5), value: 6, right: .leaf(value: 9))
)
```
