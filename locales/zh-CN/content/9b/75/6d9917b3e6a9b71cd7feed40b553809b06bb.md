# 指令

重构一个 Markdown 解析器。

这道 Markdown 练习是一道重构练习。这里有一段代码，它会解析符合 [Markdown 语法][markdown] 的字符串，并返回该字符串对应的 HTML。尽管这段代码写得让人摸不着头脑，很难看懂，但它居然能正常运行，所有测试也都通过了！你的挑战是重写这段代码，让它更易读、更易维护，同时确保所有测试依然通过。

如果在重构的过程中用注释记下你做了哪些改动，让评审者能看到，会很有帮助，不过这并非必须。最重要的是让代码变得更好！

[markdown]: https://guides.github.com/features/mastering-markdown/
