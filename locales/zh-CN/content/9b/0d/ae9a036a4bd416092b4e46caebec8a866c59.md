# 说明

学校的失物招领处把所有的东西都放在盒子里，而盒子里装的是什么都有可能：一件毛衣、若干样东西、一个名字。

写一个 `LOST_BOX{T}` 类。桩代码已经给出了类的头部。

## 1. 收下物品

`create`接收物品，以及上交者的名字，返回一个盒子。盒子一开始是未认领状态。

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. 认领

`claim`把盒子标记为已认领。它不返回任何东西。

```sather
box.claim;
box.claimed
-- => true
```

## 3. 还在等待认领吗？

`waiting`返回盒子是否还没有被认领。

```sather
box.waiting
-- => false
```

## 4. 替换里面的东西

`replace`接收一个新物品，把它放进盒子里，并返回里面原来装的东西。放进去的和拿出来的都是`T`。

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. 写一段描述

`describe`返回一行关于盒子的描述，比如`"blue jumper, handed in by Mia"`。

要把物品放进字符串里，类必须知道`T`可以转换成一个字符串。约束一下形参：把类的头部写成`class LOST_BOX{T < $STR}`，这样`item.str`就能用了。

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
