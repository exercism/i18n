# 关于

## 算术运算符

JavaScript 提供了 6 个不同的运算符，用于对数字进行基本的算术运算。

- `+`：加法运算符用于求数字的和。

  ```javascript
  1 + 2; // => 3
  2.5 + 3.9; // => 6.5
  ```

- `-`：减法运算符用于求两个数字的差。

  ```javascript
  19 - 2; // => 17
  7.4 - 1.2; // => 6.2
  ```

- `*`：乘法运算符用于求两个数字的积。

  ```javascript
  7 * 5; // => 35
  9.2 * 6.3; // => 57.959999999999994
  ```

- `/`：除法运算符用于将两个数字相除。
  由于 JavaScript 的数字始终是浮点数，因此不存在整数除法。

  ```javascript
  8 / 2; // => 4
  25 / 3; // => 8.333333333333334
  ```

- `%`：求余运算符用于求相除之后的余数。

  ```javascript
  40 % 4; // => 0
  11 % 4; // => 3
  -11 % 4; // => -3
  ```

- `**`：指数运算符用于求一个数字的幂。
  它等同于使用 [`Math.pow()`][mdn-math-pow]。

  ```javascript
  4 ** 3; // => 64
  4 ** 1 / 2; // => 2
  ```

## 运算顺序

当一行中使用多个运算符时，JavaScript 会遵循一定的优先级顺序，如[这张优先级表][mdn-operator-precedence]所示。
简化到我们的语境中，JavaScript 使用的是我们在小学数学课上学过的 PEDMAS 规则（括号、指数、除法/乘法、加法/减法）。

<!-- prettier-ignore-start -->
```javascript
const result = 3 ** 3 + 9 * 4 / (3 - 1);
// => 3 ** 3 + 9 * 4/2
// => 27 + 9 * 4/2
// => 27 + 18
// => 45
```
<!-- prettier-ignore-end -->

## 简写赋值运算符

简写赋值运算符是一种更短的写法，用于对变量进行算术运算，并把新值赋给同一个变量。
例如，考虑两个变量 `x` 和 `y`。
那么，`x += y` 等同于 `x = x + y`。
通常，这里会用数字而不是变量 `y`。
其他 5 种运算也可以用类似的方式完成。

```javascript
let x = 5;
x += 25; // x is now 30

let y = 31;
y %= 3; // y is now 1
```
