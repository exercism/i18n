# 说明

当地的诗歌俱乐部要开始新的一季了。诗人加入俱乐部，只要其中两位合写一首诗，他们就属于同一个*写作圈*。俱乐部想记录谁和谁在同一个圈子里，于是请你编写管理它的那些词。

不相交集合再合适不过：每位诗人是一个原子，一个写作圈就是一个组。

## 1. 开办俱乐部

定义`new-club`，它接收一个诗人序列，返回一个全新的不相交集合，其中每位诗人都已登记。每位诗人一开始都待在自己的写作圈里。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. 记录一次合作

定义`collaborate`，它接收两位诗人和一个俱乐部。它把两位诗人的写作圈合并，并返回这个俱乐部，这样就可以一次接一次地记录合作。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. 找到一位诗人的圈子

定义`circle-of`，它接收一位诗人和一个俱乐部，返回这位诗人所在写作圈的代表。同一个圈子里的两位诗人，报告出来的代表总是同一个。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. 是否在同一个圈子？

定义`same-circle?`，它接收两位诗人和一个俱乐部，当两位诗人属于同一个写作圈时返回`t`，否则返回`f`。请比较这两位诗人的代表，不要使用内置的等价测试。

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
