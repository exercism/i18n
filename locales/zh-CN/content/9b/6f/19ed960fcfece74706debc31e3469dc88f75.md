# 关于

在 PHP 中，只要在变量后面加上括号[`()`]，就可以把它当作函数来调用。当 PHP 尝试调用该函数时，它会查找与变量值同名的函数。

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```

## 调用静态类函数

静态类函数也可以用同样的方式调用：

```php
class Rocket
{
    public static function launch()
    {
        return '3, 2, 1, Liftoff!';
    }
}

$func = 'Rocket::launch';
$func(); // This calls Rocket::launch()
```

## 调用实例类函数

调用类实例的函数也是可以的：

```php
class Rocket
{
    public function openDoor()
    {
        return 'Door open.';
    }
}

$rocket = new Rocket();
$func = [$rocket, 'openDoor'];
$func(); // This calls Rocket::openDoor()
```
