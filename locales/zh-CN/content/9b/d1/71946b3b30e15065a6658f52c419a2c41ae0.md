## 认识 “Hello, World!”

“Hello, World!” 大概是世界上最著名的程序。
几乎所有学过编程的人都至少写过它一次。
它的简洁和那句友好的问候，往往象征着迈入奇妙编程世界的第一步。

在 Exercism 上，你会得到一个名为`hello`的函数，它返回“Goodbye, Mars!”。

```python
def hello():
    return 'Goodbye, Mars!'
```

你的任务是修改它，让它改为返回“Hello, World!”。

## 传统解法

首先是最简单的解法，也是 Exercism 希望你采用的写法。
只要把字符串从“Goodbye, Mars!”简单地改成“Hello, World!”，我们就能放心地把它返回了！

```python
def hello() -> str:
    return 'Hello, World'
```

## 其他解法

我打算用我能想到的各种方法来解决这个练习。

为了叙述方便，我把这个简单的函数称为“机器”，这台机器唯一的工作就是返回一句“Hello, World!”问候。

看看会走到哪一步吧……！

### 拼接

机器已经认识其中一些词，但似乎没办法，呃，把它们串成一个字符串。

```python
def hello() -> str:
    words = ["Hello", " world!"]
    return ",".join(words)
```

### 首字母大写

今天机器的电池有点低，所有词都缺乏能量，没能正确地变成首字母大写。

```python
def hello() -> str:
    words = "hello, world!"
    return words.title()
```

### ASCII

你不小心把柠檬水泼到了机器上，现在它只给你显示这些奇怪的数字，而不是消息里常见的字符。

```python
def hello() -> str:
    ascii = [72, 101, 108, 108, 111, 44, 32, 87, 111, 114, 108, 100, 33]
    return ''.join(chr(value) for value in ascii)
```

### 字典

你看新闻时看到一个片段，讲一个男人用 S.O.S 信号获救。
“也许机器也该能处理摩尔斯电码！”你心里想着，但不确定为什么。
它唯一的工作就是返回那句问候……

```python
def hello(morse) -> str:
    morse_code = {
        "...."  : "H",
        "."     : "e",
        ".-.."  : "l",
        "---"   : "o",
        "--..--": ",",
        "/"     : " ",
        ".--"   : "W",
        ".-."   : "r",
        "-.."   : "d",
        "-.-.--": "!"

    }
```

### 函数式

### 排列

一场强烈的雷暴经过，你可怜的倒霉机器被闪电击中了。
它还能开机，但现在行为很怪异。
组装那句问候所需的所有字符都还在，但顺序全乱了，而且逻辑板受损意味着机器再也无法把消息的顺序弄对。
偏偏你运气这么差，你早先造的那台极其可靠、*坚不可摧*的小机器其实是可以被偷走的（没错，它不见了！）。
于是，你决定就让你的老朋友把所有这些字母用各种可能的方式重新排成正确的消息。
毕竟只有 13 个字符，而机器内存很大。应该很快……

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### 查找

你决定给机器升级，让它能用不同语言打招呼。
但它唯一的工作就是用英语说出“Hello, World!”，于是它一犯迷糊，就决定下载无数种说“Hello, World!”的方式，每种的大小写和位置都略有不同。
这让你很困惑，不知道该选哪一个，但至少它们都按照某种顺序排列着。
你得告诉机器正确的说法，这样它才能找到那句话，重新恢复正常（也许吧）。

```python
def hello(my_fav_phrase) -> str:

        "HELLO, WORLD!",
        # many many many items later,
        "hello, world!"
    ]

    lower = 0
    upper = len(combinations)

        mid = (lower + upper) // 2
        mid_val = combinations[mid]

        if mid_val == my_fav_phrase:
            return combinations[mid]

        else:
            high = mid - 1
    return "Error: Can't find {my_fav_phrase}"

hello("Hello, World!")
```

### 有格调的类

你决定做点实验，调整机器，让它根据按下的是哪个按钮而表现不同。
你考虑过让它随意一点，开口说“Hi”，但你是个*有格调*的人，于是决定永远只用`hello`方法，把另一个用胶带封起来。
你意识到自己在这类事情上还真有不少空闲时间……

```python
class Greeting:
    location = "World"

    def __init__(self) -> None:
        pass

    def hello(self):
        return f"Hello, {self.location}!"

    def hi(self):
        return f"Hi, {self.location}!"

salutation = Greeting()
salutation.hello()
```

### 递归

不知为什么，你觉得如果机器有点卡顿、总是晚 10 秒才回应会很好玩。
你弟弟又一次质疑这个功能背后的逻辑，因为据他说，用这台机器的只有你一个人。

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### 随机

突然有一天，你厌倦了一遍又一遍一成不变的问候，于是决定让它最后向你问候一次，然后彻底把这台机器退休，再也不碰它。
这台机器陪你同甘共苦了很久，你决定让这场“朋友”之间的最后相会交给命运来决定。
你最后一次给它通电，就让它转吧……

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
