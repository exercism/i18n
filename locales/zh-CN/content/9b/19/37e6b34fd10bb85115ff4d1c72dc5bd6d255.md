# 资源

以下是一些有用的资源，帮助你进一步了解 SQLite，提升自己的技能：

- [SQLite 官方文档][sqlite-docs]提供了全面的指南、教程和参考资料。

- [SQLite 命令行 shell][sqlite-shell]：SQLite 命令行 shell 的文档，让你可以用 SQL 命令与 SQLite 数据库交互。

- [SQLite 常见问题解答][sqlite-faq]：关于 SQLite 的常见问题，涵盖从安装到故障排除的各种主题。

- [SQLite 论坛][sqlite-forum]：SQLite 论坛用于提问、报告 bug、提出改进建议、寻求指导，以及讨论与 SQLite 相关的软件。

- [SQLite Browser][sqlite-browser]：一个用于创建、设计和管理 SQLite 数据库的可视化工具，可以浏览和编辑 SQLite 数据库文件。

探索这些资源，加深你对 SQLite 的理解，提升你使用这个强大数据库管理系统的熟练度。

[sqlite-docs]: https://www.sqlite.org/docs.html
[sqlite-shell]: https://www.sqlite.org/cli.html
[sqlite-faq]: https://www.sqlite.org/faq.html
[sqlite-forum]: https://sqlite.org/forum/forum
[sqlite-browser]: https://sqlitebrowser.org/
