## MacOS

首先，用 [Homebrew][1] 安装 Lua 和 [Luarocks][2]：

```shell
$ brew install lua luarocks
```

然后安装 Lua 的测试框架 [Busted][3]：

```shell
$ luarocks install --local busted
```

把`~/.luarocks/bin`添加到系统的`$PATH`中

```shell
export PATH="$HOME/.luarocks/bin:$PATH"
```

注意，这只是临时生效。如果要永久添加到`$PATH`，还需要根据你使用的 shell，把它加到`.bashrc`、`.zshrc`或`config.fish`中。

然后运行测试：

```shell
$ busted
```

## Ubuntu

首先，用 [Apt][6] 安装 Lua 和 [Luarocks][2]：

```shell
$ sudo apt-get install lua5.4 liblua5.4-dev luarocks
```

```shell
$ busted
```

## Windows 10: WSL

首先，你必须用 [PowerShell][8]（管理员）启用 [WSL（适用于 Linux 的 Windows 子系统）][7]：

```shell
PS> Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Windows-Subsystem-Linux
```

这需要重启电脑。

接下来，从 [Microsoft Store][9] 安装 Ubuntu，**或者**用 PowerShell 下载并安装：

```shell
PS> curl.exe -L -o ubuntu1804.appx https://aka.ms/wsl-ubuntu-1804
PS> Add-AppxPackage .\ubuntu1804.appx; rm .\ubuntu1804.appx
PS> ubuntu1804
```

然后更新软件包列表：

```shell
PS> wsl
$ sudo apt-get update
```

现在，按照上面的 [Ubuntu 安装说明](#ubuntu)，就可以安装 [LuaRocks][2] 和 [Busted][3] 了。

完成后，就可以直接在任意 Windows 命令行中运行测试：

```cmd
C:\> wsl busted
```

## Windows 10: Docker

### 安装 Gitbash

这一步是可选的。如果你更喜欢使用 Windows 自带的 CLI 或其他 CLI，可能需要稍微调整下面的步骤。

在[这里][10]下载。安装说明见[这里][11]。

### 安装 Docker

按照说明安装 [Docker for Windows][12]。安装完成后，可以运行以下命令，确认是否安装正确。

```shell
$ docker --version
```

_第一次运行 Docker 时可能会遇到错误。_

`cannot enable hyper-v service`

_如果出现这种情况，可以按照这些说明[启用 Hyper V][13]。你可能需要先禁用该设置，重启电脑，然后再重新启用。_

### 安装 busted

安装好 Gitbash 和 Docker 后，就可以安装 busted 的“容器”了。

在 Gitbash 中运行以下命令：

运行以下命令，拉取这个常用的 Docker 容器：

```shell
$ docker pull imega/busted
```

创建一个函数，这样就不必每次都输入完整命令。把下面这行加到你的`.bashrc`中：

```shell
dbusted() { docker run --rm -t -v "/$@":/data imega/busted; }
```

现在，在你的 CLI 中，切换到你想运行测试的目录，然后运行：

```shell
$ dbusted $PWD
```

你应该会看到 busted 测试的输出。
