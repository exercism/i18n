# Pistas

## General

- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el tarro de las galletas con un enfoque recursivo. Un caso base es un tarro vacío: tiene cero galletas. Si el tarro no está vacío, el número de galletas que contiene es igual a una galleta más el número de galletas que quedan tras sacar una.

## 1. Comprueba cuántos pájaros han visitado hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de un array usando una expresión case.

## 2. Incrementa el recuento de hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de un array y al resto del array usando una expresión case.

## 3. Comprueba si hubo un día sin pájaros visitantes

- Usa la recursión para iterar sobre los elementos del array hasta encontrar un día sin pájaros visitantes.
- El caso base es un array vacío.

## 4. Calcula el número total de pájaros visitantes

- Usa la recursión para iterar sobre todos los elementos del array.
- El caso base es un array vacío.

## 5. Calcula el número de días ajetreados

- Usa la recursión para iterar sobre todos los elementos del array.
- El caso base es un array vacío.
- Usa una guarda en una de las cláusulas de la expresión case.
