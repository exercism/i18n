# Instrucciones

En este ejercicio, implementarás la lógica de la misión de un nuevo juego de rol que está desarrollando un amigo.
La protagonista del juego es Annalyn, una chica valiente que tiene un perro fiero y leal.
Por desgracia, la tragedia se cierne sobre ella: su mejor amiga ha sido secuestrada mientras buscaba bayas en el bosque.
Annalyn intentará encontrar y liberar a su mejor amiga, llevando consigo a su perro si así lo desea.

Después de pasar un tiempo siguiendo el rastro de su mejor amiga, encuentra el campamento en el que está encerrada.
Resulta que hay dos secuestradores: un poderoso caballero y un astuto arquero.

Una vez encontrados los secuestradores, Annalyn se plantea cuáles de las siguientes acciones puede llevar a cabo:

- _Ataque rápido_: se puede realizar un ataque rápido si el **caballero** está **_dormido_**, ya que tarda un tiempo en ponerse la armadura, por lo que estará vulnerable.
- _Espiar_: se puede espiar al grupo si **al menos uno** de ellos está **_despierto_**. De lo contrario, espiar es una pérdida de tiempo.
- _Señalizar a la prisionera_: se puede dar una señal a la prisionera mediante sonidos de aves si la **prisionera** está **_despierta_** y el **arquero** está **_dormido_**, ya que los arqueros están entrenados en las señales con aves y podrían interceptar el mensaje.
- _Liberar a la prisionera_: Annalyn puede intentar colarse en el campamento para liberar a la prisionera.
  Es una acción arriesgada que solo puede salir bien de una de estas dos maneras:
  - Si Annalyn lleva a su perro consigo, puede rescatar a la prisionera si el **arquero** está **_dormido_**.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y la prisionera escapen.
  - Si Annalyn no lleva a su perro, ella y la prisionera tendrán que ser muy sigilosas.
    Annalyn puede liberar a la prisionera si esta está **_despierta_** y el **caballero** y el **arquero** están ambos **_dormidos_**, pero si la **prisionera** está **_dormida_** no se la puede rescatar: la prisionera se asustaría con la repentina aparición de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprobar si la acción «ataque rápido» es posible

Implementa una función llamada `canFastAttack` que recibe un valor Boolean que indica si el caballero está despierto.
La función devuelve `true` si la acción «ataque rápido» está disponible según el estado del personaje.
De lo contrario, devuelve `false`:

```php
<?php
$is_knight_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canFastAttack($is_knight_awake);
// => false
```

## 2. Comprobar si la acción «espiar» es posible

Implementa una función llamada `canSpy` que recibe tres valores Boolean, que indican si el caballero, el arquero y la prisionera, respectivamente, están despiertos.
La función devuelve `true` si la acción «espiar» está disponible según el estado de los personajes.
De lo contrario, devuelve `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSpy($is_knight_awake, $is_archer_awake, $is_prisoner_awake);
// => true
```

## 3. Comprobar si la acción «señalizar a la prisionera» es posible

Implementa una función llamada `canSignal` que recibe dos valores Boolean, que indican si el arquero y la prisionera, respectivamente, están despiertos.
La función devuelve `true` si la acción «señalizar a la prisionera» está disponible según el estado de los personajes.
De lo contrario, devuelve `false`:

```php
<?php
$is_archer_awake = false;
$is_prisoner_awake = true;

$infiltration = new AnnalynsInfiltration();
$infiltration->canSignal($is_archer_awake, $is_prisoner_awake);
// => true
```

## 4. Comprobar si la acción «liberar a la prisionera» es posible

Implementa una función llamada `canLiberate` que recibe cuatro valores Boolean.
Los tres primeros parámetros indican si el caballero, el arquero y la prisionera, respectivamente, están despiertos.
El último parámetro indica si el perro de Annalyn está presente.
La función devuelve `true` si la acción «liberar a la prisionera» está disponible según el estado de los personajes y la presencia del perro de Annalyn.
De lo contrario, devuelve `false`:

```php
<?php
$is_knight_awake = false;
$is_archer_awake = true;
$is_prisoner_awake = false;
$is_dog_present = false;

$infiltration = new AnnalynsInfiltration();
$infiltration->canLiberate(
    $is_knight_awake,
    $is_archer_awake,
    $is_prisoner_awake,
    $is_dog_present
);
// => false
```
