# Rutinas vinculadas

Hasta ahora todo ha ido pasando *valores*: números, strings, objetos. Una
**rutina vinculada** te permite pasar una rutina en sí, algo que se llamará
más tarde desde código que no sabe qué es.

Un suplente es exactamente la idea: el director de escena tiene una forma de
interpretar el papel, sin saber quién es ni qué hará.

## Crear una

`bind` recibe una llamada con huecos, escritos `_`:

```sather
   shout(line : STR) : STR is return line.upper; end;

   ...

   part ::= bind(shout(_));
```

`part` ahora es un valor como cualquier otro. Se llama más tarde:

```sather
   part.call("who's there")      -- "WHO'S THERE"
```

## El tipo

El tipo de una rutina vinculada es `ROUT`, con los tipos de los argumentos
entre llaves y el tipo devuelto después de dos puntos:

```sather
   part : ROUT{STR}:STR := bind(shout(_));
```

Lee `ROUT{STR}:STR` como «una rutina que recibe un `STR` y devuelve un `STR`».

| Escrito | Significa |
| --- | --- |
| `ROUT{STR}:STR` | recibe un `STR`, devuelve un `STR` |
| `ROUT{INT,INT}:BOOL` | recibe dos `INT`, devuelve un `BOOL` |
| `ROUT{STR}` | recibe un `STR`, no devuelve nada |
| `ROUT:INT` | no recibe nada, devuelve un `INT` |

Como es un tipo, puede ser un argumento:

```sather
   rehearse(line : STR, part : ROUT{STR}:STR) : STR is
      return part.call(line);
   end;
```

`rehearse` no tiene ni idea de lo que hace `part`. De eso se trata: puede
recibir `shout`, o `whisper`, o cualquier otra cosa con esa forma.

## Rellenar algunos argumentos

No todos los argumentos tienen que ser un hueco. Todo lo que se escribe queda
fijado cuando se produce la vinculación:

```sather
   repeat(times : INT, line : STR) : STR is ... end;

   twice ::= bind(repeat(2, _));      -- ROUT{STR}:STR
```

`twice` solo recibe la línea, porque el `2` ya está decidido. El valor se
calcula en el momento de la vinculación y se conserva, así que cambiar
después la variable de la que salió no supone ninguna diferencia.

Así es como una rutina general se convierte en muchas específicas.

## Vincular también el objeto

En una rutina de un objeto, el objeto es lo primero en la llamada y puede
fijarse o dejarse como hueco:

```sather
   bind(board.home_goal)      -- this board's, always
   bind(_.home_goal)          -- whichever board is handed in later
```
