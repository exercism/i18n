# Clases

Las clases son una unidad de organización del código en PHP.
El código que representa el comportamiento de un elemento o el comportamiento de un proceso se puede agrupar en una clase.
Las funciones que se asignan a una clase se denominan `methods` por convención.

```php
<?php

class Door
{
    function lock()
    {
        // ...
    }

    function unlock()
    {
        // ...
    }
}
```

Las clases se instancian con la palabra clave `new`, que reserva memoria para la instancia de la clase y llama al método constructor de la clase.
Las clases instanciadas se pueden asignar a una variable.
Para invocar los métodos de una instancia de una clase, podemos usar el operador de acceso `->`.

```php
<?php

$a_door = new Door();
$a_door->lock();
$a_door->unlock();
```

Una clase instanciada puede referirse a su propia instancia mediante la variable especial `$this`.
Las clases también pueden tener propiedades, que actúan como variables ligadas a la instancia del objeto de la clase.
Se puede hacer referencia a estas propiedades desde dentro o desde fuera.

```php
<?php

class Car
{
    public $color;

    function __construct($color)
    {
        $this->color = $color;
    }

    function getColor()
    {
        return $this->color;
    }
}

$a_car = new Car("red");
$a_car->color; // => "red" by accessing the property
$a_car->getColor(); // => "red" by invoking the instance method
```
