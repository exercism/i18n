# Acerca de los bucles for-each

El [bucle for-each](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) proporciona un mecanismo para ejecutar un bloque de código para cada elemento de una colección.
Algunas documentaciones (p. ej., la de Oracle) se refieren a ellos como bucles `for` mejorados.

Esta es la sintaxis general:

```java
for(declaration: collection) {
    body;
}
```

La `declaration` declara la variable que se usa para contener los valores asignados desde la colección.

La `collection` es un array o una colección que contiene los valores que se asignarán a la variable del bucle.

El `body` contiene las instrucciones que se ejecutarán una vez por cada valor de la colección.

Por ejemplo:

```java
char[] vowels = {'a', 'e', 'i', 'o', 'u'};

for(char vowel: vowels) {
    System.out.println(vowel);
}
```

que genera:

```text
a
e
i
o
u
```

En general, un bucle `for-each` es preferible a un bucle `for` por las siguientes razones:

- Un bucle `for-each` garantiza que se itera sobre _todos_ los valores.
- Un bucle `for-each` es más _declarativo_, lo que significa que el código comunica _qué_ hace en lugar de _cómo_ lo hace.
- Un bucle `for-each` es infalible, mientras que con los bucles `for` es fácil cometer un error de desfase por uno (piensa en usar `<` frente a `<=`).
- Un bucle `for-each` funciona con todos los tipos de colección, incluidos aquellos que no admiten el uso de un índice para acceder a los elementos (p. ej., un `Set`).
