# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
bats test-<exercise-slug>.bats
```

### bats está implementado en bash

El fichero de bats es un script de bash, con algunas funciones especiales que reconoce el comando `bats`.
Verás algunas pruebas que se parecen a

```bash
sed -E -f <exercise-slug>.sed <<< "$input"
```

Esa sintaxis `<<<` es un *Here String* de bash.
Envía el string de la derecha a la entrada estándar del programa de la izquierda.
Es aproximadamente lo mismo que

```bash
echo "$input" | sed -E -f <exercise-slug>.sed
```

## Pruebas omitidas

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una prueba (la primera).
Esto es intencionado, ya que te permite centrarte en hacer que solo esa prueba pase.
Cuando pase, puedes habilitar la siguiente prueba comentando o eliminando las

    [[ $BATS_RUN_SKIPPED == true ]] || skip

anotaciones que preceden a las demás pruebas.

## Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que tienen anotaciones `skip`, puedes ejecutar:

```bash
BATS_RUN_SKIPPED=true bats test-<exercise-slug>.bats
```

o puedes comentar o eliminar la línea:

```bash
[[ $BATS_RUN_SKIPPED == "true" ]] || skip
```

del fichero de pruebas.
