# Instrucciones

En este ejercicio vas a organizar carreras entre distintos tipos de coches teledirigidos. Cada coche tiene sus propias características de velocidad y consumo de batería.

Los coches empiezan con las baterías llenas (100 %). Cada vez que conduces el coche con el mando a distancia, recorre tantos metros como indica su velocidad y reduce el porcentaje de batería restante en su consumo de batería.

Si la batería de un coche está por debajo de su porcentaje de consumo de batería, ya no puedes conducirlo.

Cada pista de carreras tiene su propia distancia. Los coches se ponen a prueba comprobando si pueden terminar la pista sin quedarse sin batería.

Tienes seis tareas y cada una trabajará con instancias de coches teledirigidos.

## 1. Crear un coche teledirigido

Permite crear un coche teledirigido definiendo un constructor para la clase `NeedForSpeed` que reciba como parámetros la velocidad del coche en metros y el porcentaje de consumo de batería (ambos de tipo `int`):

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
```

## 2. Crear una pista de carreras

Permite crear una pista de carreras definiendo un constructor para la clase `RaceTrack` que reciba como único parámetro la distancia de la pista en metros (de tipo `int`):

```java
int distance = 800;
var raceTrack = new RaceTrack(distance);
```

## 3. Conducir el coche

Implementa el método `NeedForSpeed.drive()` que actualiza el número de metros recorridos en función de la velocidad del coche. Además, implementa el método `NeedForSpeed.distanceDriven()` para devolver el número de metros recorridos por el coche:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.distanceDriven();
// => 5
```

## 4. Comprobar si la batería se ha agotado

Actualiza el método `NeedForSpeed.drive()` para que consuma batería según el consumo de batería del coche. Además, implementa el método `NeedForSpeed.batteryDrained()` que indica si la batería está demasiado agotada para poder conducir:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);
car.drive();

car.batteryDrained();
// => false
```

## 5. Crear el coche teledirigido Nitro

El coche teledirigido más vendido es el Nitro, que tiene una velocidad punta impresionante de 50 metros con un consumo de batería del 4 %. Implementa el método (estático) `NeedForSpeed.nitro()` para devolver este tipo de coche:

```java
var car = NeedForSpeed.nitro();
car.drive();
car.distanceDriven();
// => 50
```

## 6. Comprobar si un coche teledirigido puede terminar una carrera

Para terminar una carrera, un coche tiene que ser capaz de recorrer la distancia de la carrera. Eso significa no agotar su batería antes de haber cruzado la línea de meta. Implementa el método `RaceTrack.canFinishRace()` que recibe una instancia de `NeedForSpeed` como parámetro y devuelve `true` si el coche puede terminar la carrera; en caso contrario, devuelve `false`:

```java
int speed = 5;
int batteryDrain = 2;
var car = new NeedForSpeed(speed, batteryDrain);

int distance1 = 100;
var race1 = new RaceTrack(distance1);

int distance2 = 300;
var race2 = new RaceTrack(distance2);

race1.canFinishRace(car);
// => true

race2.canFinishRace(car);
// => false
```
