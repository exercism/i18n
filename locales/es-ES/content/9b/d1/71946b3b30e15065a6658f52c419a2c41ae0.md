## Conoce a «Hello, World!»

«Hello, World!» es probablemente el programa más famoso del mundo.
Prácticamente cualquiera que haya aprendido a programar lo ha escrito al menos una vez.
Su sencillez y su mensaje amistoso suelen marcar el primer paso en el maravilloso mundo de la programación.

En Exercism se te proporciona una función llamada `hello` que devuelve «Goodbye, Mars!».

```python
def hello():
    return 'Goodbye, Mars!'
```

Tu tarea es cambiarla para que devuelva «Hello, World!» en su lugar.

## El enfoque tradicional

Para empezar, tenemos el enfoque más sencillo, el que Exercism espera que implementes.
Con solo cambiar el string de «Goodbye, Mars!» a «Hello, World!», ¡ya podemos devolverlo sin problema!

```python
def hello() -> str:
    return 'Hello, World'
```

## Enfoques alternativos

Voy a resolver este ejercicio usando todos los métodos distintos que se me ocurran.

### La permutación

Pasó una fuerte tormenta eléctrica y un rayo alcanzó a tu pobre y desafortunada máquina.
Todavía se enciende, pero ahora se comporta de forma extraña.
Todos los caracteres para armar el mensaje de saludo siguen ahí, pero están desordenados, y el daño en la placa lógica hace que la máquina ya no pueda acertar con el orden del mensaje.
Y para colmo de tu suerte, la pequeña máquina increíblemente fiable e *indestructible* que construiste antes resultó ser robable (sí, ¡ha desaparecido!).
Así que decides dejar que tu vieja amiga pruebe todas las formas posibles de reordenar esas letras hasta dar con el mensaje correcto.
Al fin y al cabo, solo son 13 caracteres y la máquina tiene mucha memoria. Esto debería ser rápido...

```python
from itertools import permutations

def hello() -> str:
    chars = ['H', 'e', 'l', 'l', 'o', ',', ' ', 'W', 'o', 'r', 'l', 'd', '!']

    all_permutations = permutations(chars)
    for perm in all_permutations:
        if ("".join(perm) == "Hello, World!"):
            return ''.join(perm)
```

### La recursión

Por alguna razón, decidiste que sería divertido que la máquina fuera un poco lenta y tardara 10 segundos en responder. Tu hermano vuelve a preguntarte por la lógica de esta funcionalidad, porque, según él, eres el único que usa la máquina.

```python
import time

def hello(n=10):
    if n == 0:
        return "Hello, World!"
    else:
        time.sleep(1)
        return hello(n-1)
```

### La aleatoriedad

De repente, un día te cansas del mismo saludo una y otra vez, así que decides dejar que te salude una última vez y jubilar la máquina para siempre, sin volver a tocarla jamás.
Como la máquina ha estado contigo en las buenas y en las malas durante mucho tiempo, decides dejar esta última cita entre «amigos» en manos del destino.
 La enciendes una última vez y dejas que gire...

```python
import random

def hello():
    chars = list("Helo,Wrld!")
    greeting = ""
    while (greeting != "Hello, World!"):
        greeting = "".join(random.choices(chars, k=13))
    return greeting
```
