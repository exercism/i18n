# Evitar la función init

Evita usar la función `init`:
1) Ralentiza el tiempo de arranque, y el desarrollador que use el paquete no puede hacer nada al respecto salvo eliminar la función `init`.
2) La función `init` se usa sobre todo para inicializar `global variables`.
Siempre que sea posible, [conviene evitar el estado global](https://dave.cheney.net/practical-go/presentations/qcon-china.html#_avoid_package_level_state).
