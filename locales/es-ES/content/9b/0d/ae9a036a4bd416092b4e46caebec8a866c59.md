# Instrucciones

La oficina de objetos perdidos del colegio guarda todo en cajas, y lo que va dentro de una caja puede ser cualquier cosa: un jersey, un número de cosas, un nombre.

Escribe una clase `LOST_BOX{T}`. El esqueleto te da la cabecera de la clase.

## 1. Recibir algo

`create` recibe la cosa y el nombre de quien la entregó, y devuelve una caja. Una caja empieza sin reclamar.

```sather
box ::= #LOST_BOX{STR}("blue jumper", "Mia");
box.item
-- => "blue jumper"
box.handed_in_by
-- => "Mia"
box.claimed
-- => false
```

## 2. Reclamarla

`claim` marca la caja como reclamada. No devuelve nada.

```sather
box.claim;
box.claimed
-- => true
```

## 3. ¿Sigue esperando?

`waiting` devuelve si la caja no ha sido reclamada.

```sather
box.waiting
-- => false
```

## 4. Intercambiar el contenido

`replace` recibe una cosa nueva, la mete en la caja y devuelve lo que había antes. Tanto la cosa que entra como la que sale son `T`.

```sather
old ::= box.replace("red jumper");
old
-- => "blue jumper"
box.item
-- => "red jumper"
```

## 5. Redactarlo

`describe` devuelve una línea sobre la caja, como `"blue jumper, handed in by Mia"`.

Para poner el elemento en un string, la clase necesita saber que un `T` se puede convertir en uno. Restringe el parámetro: escribe la cabecera de la clase como `class LOST_BOX{T < $STR}`, y entonces `item.str` está permitido.

```sather
box.describe
-- => "blue jumper, handed in by Mia"
```
