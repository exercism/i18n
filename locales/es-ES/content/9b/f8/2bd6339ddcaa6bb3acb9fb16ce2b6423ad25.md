# Ayuda

Si tienes problemas, puedes consultar uno de los siguientes recursos para obtener ayuda:

- [Crystal API](http://crystal-lang.org/api/)
- [r/crystal_programming/](https://www.reddit.com/r/crystal_programming/) es el subreddit de Crystal.
- [StackOverflow](https://stackoverflow.com/questions/tagged/crystal-lang) te sirve para buscar tu problema y ver si ya se ha respondido. También puedes hacer preguntas y responderlas.
- [Crystal Forum](https://forum.crystal-lang.org/) es el foro oficial de Crystal.
