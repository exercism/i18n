# Instrucciones

El club de poesía local empieza una nueva temporada. Los poetas se unen al club y, cuando dos de ellos escriben un poema juntos, pasan a formar parte del mismo *círculo de escritura*. El club quiere llevar un registro de quién comparte un círculo con quién, y te han pedido que escribas las palabras que lo gestionan.

Un conjunto disjunto es la opción perfecta: cada poeta es un átomo y un círculo de escritura es un grupo.

## 1. Abre el club

Define `new-club`, que toma una secuencia de poetas y devuelve un conjunto disjunto nuevo con todos los poetas registrados. Cada poeta empieza en un círculo de escritura propio.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
! => a disjoint set holding the three poets
```

## 2. Registra una colaboración

Define `collaborate`, que toma dos poetas y un club. Fusiona los círculos de escritura de los dos poetas y devuelve el club, para que las colaboraciones se puedan registrar una tras otra.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
! => the club, with Keats and Byron now in one circle
```

## 3. Encuentra el círculo de un poeta

Define `circle-of`, que toma un poeta y un club y devuelve el representante del círculo de escritura de ese poeta. Dos poetas que comparten un círculo siempre devuelven el mismo representante.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Dickinson" swap circle-of
! => "Dickinson"   (still in a circle of their own)
```

## 4. ¿Comparten un círculo?

Define `same-circle?`, que toma dos poetas y un club y devuelve `t` cuando ambos poetas pertenecen al mismo círculo de escritura y `f` en caso contrario. Compara los representantes de los poetas en lugar de usar una prueba de equivalencia incorporada.

```factor
{ "Keats" "Byron" "Dickinson" } new-club
"Keats" "Byron" rot collaborate
dup [ "Keats" "Byron" ] dip same-circle? .      ! => t
    [ "Keats" "Dickinson" ] dip same-circle? .  ! => f
```
