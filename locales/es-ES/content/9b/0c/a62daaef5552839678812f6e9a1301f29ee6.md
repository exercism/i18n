# Introducción

Go contiene tipos numéricos básicos que pueden representar conjuntos de valores enteros o de coma flotante.

Este concepto se centrará en dos tipos de números:

- `int`: p. ej. `0`, `255`, `2147483647`.
   Un entero con signo que ocupa al menos 32 bits (rango de valores: de -2147483648 a 2147483647).
   Pero esto dependerá de la arquitectura del sistema.
   La mayoría de los ordenadores modernos son de 64 bits, por lo que `int` ocupará 64 bits (rango de valores: de -9223372036854775808 a 9223372036854775807).

- `float64`: p. ej. `0.0`, `3.14`.
   Contiene el conjunto de todos los números de coma flotante de 64 bits.

Go admite el conjunto estándar de operadores aritméticos `+`, `-`, `*`, `/` y `%` (residuo, no módulo).

En Go, la asignación de un valor entre tipos diferentes requiere una conversión explícita.
Por ejemplo, para convertir un `int` a un `float64` tendrías que hacer lo siguiente:

```go
var x int = 42
f := float64(x)

fmt.Printf("x is of type: %s\n", reflect.TypeOf(x))
// Output: x is of type: int

fmt.Printf("f is of type: %s\n", reflect.TypeOf(f))
// Output: f is of type: float64
```
