# Apéndice de las instrucciones

## Pistas

Para completar este ejercicio tienes que implementar la función `wordCount`,
que recibe un *texto* y devuelve cuántas veces aparece cada *palabra*.

Si es la primera vez que resuelves este ejercicio, te recomendamos que te
ciñas a la firma que se proporciona:

```haskell
wordCount :: String -> [(String, Int)]
```

Más adelante puede ser buena idea volver sobre este problema y jugar con otros
tipos de datos y bibliotecas:

- `Text`, del paquete *text*.
- `Map`, del paquete *containers*.
- `MultiSet`, del paquete *multiset*

El conjunto de pruebas se diseñó a propósito para aceptar casi cualquier firma
de tipo que tenga sentido, así que te animamos a que encuentres la que creas
que es la mejor.
