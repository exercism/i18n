# Recursos

Aquí tienes algunos recursos útiles que te ayudarán a aprender más sobre SQLite y a mejorar tus habilidades:

- La [documentación oficial de SQLite][sqlite-docs] ofrece guías completas, tutoriales y referencias sobre SQLite.

- [SQLite Command-Line Shell][sqlite-shell]: documentación del shell de línea de comandos de SQLite, que te permite interactuar con bases de datos SQLite mediante comandos SQL.

- [SQLite FAQ][sqlite-faq]: preguntas frecuentes sobre SQLite, que abarcan desde la instalación hasta la resolución de problemas.

- [SQLite Forum][sqlite-forum]: el foro de SQLite sirve para hacer preguntas, informar de bugs, sugerir mejoras, pedir orientación y hablar sobre software relacionado con SQLite.

- [SQLite Browser][sqlite-browser]: una herramienta visual para crear, diseñar y gestionar bases de datos SQLite, que te permite explorar y editar ficheros de bases de datos SQLite.

Explora estos recursos para profundizar en tu conocimiento de SQLite y mejorar tu dominio de este potente sistema de gestión de bases de datos.

[sqlite-docs]: https://www.sqlite.org/docs.html
[sqlite-shell]: https://www.sqlite.org/cli.html
[sqlite-faq]: https://www.sqlite.org/faq.html
[sqlite-forum]: https://sqlite.org/forum/forum
[sqlite-browser]: https://sqlitebrowser.org/
