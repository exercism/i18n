# Instrucciones

En este ejercicio vas a documentar el código que acabas de escribir para ayudarte a cocinar una lasaña magnífica.
Es poco probable que vuelvas a mirar nunca este código relacionado con la lasaña, pero documentar el código resulta muy útil si quieres que cualquier proyecto más grande sea comprensible para los demás (¡o para ti mismo!).

Para documentar tu código, escribe un «docstring» para cada una de las tres funciones. Así es como se hace:

- Repasa la sección [Documentación][doc] del manual de Julia.
- Empieza por la firma de la función, indentada con 4 espacios.
- Incluye una única frase de una línea que describa qué hace la función, con tus propias palabras.

~~~~
