# Introducción

La memoria dinámica se implementa mediante funciones de biblioteca que el programador utiliza para reservar y liberar memoria en tiempo de ejecución.
Dado que el programador controla la reserva y la liberación de la memoria, la memoria dinámica es tan segura como lo sea el programador frente a los errores humanos.
Por ese motivo, la memoria dinámica es una de las principales fuentes de bugs de programación y uno de los principales objetivos de los ataques de hackers.

## malloc

`malloc` es una función declarada en `stdlib.h` que se utiliza para reservar memoria dinámica.
Si la reserva se realiza correctamente, se devuelve un puntero que apunta a la dirección del primer byte de la memoria reservada.
Si la reserva no se realiza correctamente, se devuelve `NULL`.
Es prudente comprobar si el resultado de `malloc` es `NULL` y gestionarlo con elegancia si falla.
El puntero devuelto es de tipo `pointer-to-void`, que se puede considerar a grandes rasgos como un puntero «genérico» que puede convertirse al tipo específico que utiliza la memoria.
`malloc` tiene un parámetro, que es el tamaño en bytes de la memoria deseada.
El tamaño total para reservar un array es el tamaño del tipo de dato de cada elemento multiplicado por el número de elementos.
El operador `sizeof` se utiliza habitualmente para obtener el tamaño del tipo de dato de cada elemento.
El siguiente ejemplo lo demuestra:

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // pointer-to-void from malloc is converted to a pointer-to-int
    int * numbers = malloc(sizeof(int) * count);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // printed The size of numbers is 8 bytes (can vary by system)
    printf("The size of numbers is %zu bytes\n", sizeof(numbers));
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 2
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 3
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

Es importante recordar que la memoria recién reservada por `malloc` no está inicializada, sino que puede contener valores basura.
Observa que el `sizeof` del puntero `numbers` no es el número de elementos del array ni la cantidad total de memoria reservada.
El tamaño del puntero devuelto por `malloc` es el tamaño de cualquier puntero en ese sistema en concreto.
El código del ejemplo se ejecutó en un sistema de 64 bits, por lo que el tamaño del puntero era de 8 bytes (multiplicado por 8 bits por byte = 64 bits).
El tipo del puntero se convirtió implícitamente de pointer-to-void a pointer-to-int.
También podría haberse convertido explícitamente así: `int * numbers = (int *) malloc(sizeof(int) * count);`.
Si los valores se van a escribir con seguridad antes de leerse, usar `malloc` puede ser una forma eficiente de reservar memoria.
Pero si hay alguna posibilidad de que los valores se lean antes de inicializarse, usar `malloc` es arriesgado.
Una forma más segura de reservar memoria es usar `calloc`, que inicializa a cero la memoria recién reservada.

Fíjate en que en los ejemplos anteriores se utilizó `free(numbers)`.

## free

`free` es una función declarada en `stdlib.h` que se utiliza para liberar memoria que se ha reservado dinámicamente.
La memoria reservada dinámicamente permanece ocupada hasta que `free` la libera.
Algunos sistemas operativos pueden liberar automáticamente la memoria reservada dinámicamente cuando el programa termina, pero es una buena práctica no depender de ello.
`free` tiene un parámetro, que es un puntero a la memoria que se reservó dinámicamente.
Un puntero al que no se le asigna `NULL` después de liberarlo se conoce como puntero colgante.
Un puntero colgante puede referirse a otra memoria distinta de la que se pretendía.
Por lo tanto, un puntero colgante puede provocar corrupción de datos y la sustitución y ejecución de código arbitrario.
Un puntero a memoria reservada que no se ha limpiado asignándole `NULL` puede utilizarse para hackear el programa.
Es una buena práctica asignar `NULL` a un puntero después de pasarlo a `free`.

## calloc

`calloc` es una función declarada en `stdlib.h` que se utiliza tanto para reservar memoria dinámica como para inicializar a cero la memoria recién reservada.
Si la reserva se realiza correctamente, se devuelve un puntero que apunta a la dirección del primer byte de la memoria reservada.
Si la reserva no se realiza correctamente, se devuelve `NULL`.
Es prudente comprobar si el resultado de `calloc` es `NULL` y gestionarlo con elegancia si falla.
El puntero devuelto es de tipo `pointer-to-void`, que se puede considerar a grandes rasgos como un puntero «genérico» que puede convertirse al tipo específico que utiliza la memoria.
`calloc` tiene dos parámetros.
El primero indica cuántos elementos del tipo de dato especificado se van a reservar.
El segundo es el tamaño del tipo de dato especificado que se va a reservar.

En el siguiente ejemplo, todas las instrucciones `printf` deberían mostrar siempre `0`, ya que `calloc` garantiza que los valores recién reservados se pongan a cero.

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    // prints The first element of the array is 0
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The second element of the array is 0
    printf("The second element of the array is %d\n", numbers[1]);
    // prints The third element of the array is 0
    printf("The third element of the array is %d\n", numbers[2]);
    free(numbers);
    numbers = NULL;
}
```

## realloc

`realloc` es una función declarada en `stdlib.h` que se utiliza para ampliar o reducir memoria ya reservada.
Si la nueva reserva se realiza correctamente, se devuelve un puntero que apunta a la dirección del primer byte de la memoria reasignada.
Si la nueva reserva no se realiza correctamente, se devuelve `NULL`.
Es prudente comprobar si el resultado de `realloc` es `NULL` y gestionarlo con elegancia si falla.
`realloc` tiene dos parámetros.
El primer parámetro es un puntero a la memoria existente que se va a reasignar.
El segundo es el tamaño en bytes de la memoria reasignada.
Los valores que se establecieron antes de ampliar la memoria se conservan.
Es importante recordar que la memoria que se añade al ampliarla no se inicializa a cero y sus valores pueden ser cualesquiera.
Además, la memoria que se elimina al reducirla tampoco se inicializa y podría conservar sus valores.
El siguiente ejemplo muestra cómo ampliar y reducir un array:

```c
#include <stdio.h>
#include <stdlib.h>

int * my_function(int count) {
    // allocates the amount of bytes in an int, multiplied by count
    int * numbers = calloc(count, sizeof(int));
    return numbers;
}

int * my_function_2 (int * ptr , int count) {
    // reallocates the memory to the size of an int multiplied by count
    int * numbers = realloc(ptr, sizeof(int) * count);
    // if realloc fails, exit the program
    if (!numbers) exit(-1);
    return numbers;
}

int main() {
    int * numbers = my_function(3);
    if (!numbers) return -1;
    numbers[0] = 1;
    numbers[1] = 2;
    numbers[2] = 3;
    // expand the size of the array
    numbers = my_function_2(numbers, 6);
    // prints The first element of the array is 1
    printf("The first element of the array is %d\n", numbers[0]);
    // prints The sixth element of the array is [whatever is there]
    // the additional memory is not initialized, so it could be
    // 0 or it could be 18728 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
    numbers[5] = 6;
    // shrink the size of the array
    numbers = my_function_2(numbers, 3);
    // prints The sixth element of the array is [whatever is there]
    // the removed memory is not initialized, so it could be
    // 6 or it could be 43164 or anything else
    printf("The sixth element of the array is %d\n", numbers[5]);
}
```
