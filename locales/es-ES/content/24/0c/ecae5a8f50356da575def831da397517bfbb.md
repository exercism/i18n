# Introducción

Los números enteros pueden verse no solo como valores numéricos, sino como patrones de bits. El vocabulario [`math`][math] de Factor incluye las operaciones estándar de bajo nivel sobre esos patrones de bits, y el vocabulario [`math.bitwise`][bitwise] añade algunos ayudantes para trabajar con valores de ancho fijo.

## Desplazamientos de bits

`shift ( m n -- m' )` desplaza los bits de `m`. Un `n` *positivo* desplaza a la izquierda (multiplicando por 2 en cada paso); un `n` *negativo* desplaza a la derecha (dividiendo por 2 en cada paso):

```factor
3 2 shift .     ! => 12   (3 << 2)
24 -3 shift .   ! => 3    (24 >> 3)
```

En los números enteros positivos, el desplazamiento a la derecha descarta bits por la parte inferior y rellena con ceros. En los números enteros *negativos*, el `shift` de Factor es aritmético: conserva el bit de signo, rellenando conceptualmente desde la izquierda con copias del bit de signo. (Los enteros de Factor tienen precisión arbitraria, así que «la izquierda» se extiende tanto como haga falta).

## Lógica bit a bit

Las cuatro operaciones lógicas básicas son:

```
bitor  ( x y -- z )   ! 1 in either operand
bitand ( x y -- z )   ! 1 in both operands
bitxor ( x y -- z )   ! 1 in exactly one operand
bitnot ( x   -- z )   ! flip every bit
bit?   ( x n -- ? )   ! true when bit at position n is set
```

```factor
0b1011 0b0010 bitor .    ! => 11  (0b1011)
0b1011 0b0010 bitand .   ! => 2   (0b0010)
0b1011 0b0010 bitxor .   ! => 9   (0b1001)
0b1011 bitnot .          ! => -12
0b1011 0 bit? .          ! => t   (low bit is set)
0b1011 2 bit? .          ! => f   (bit 2 is clear)
```

El `bitnot` de `0b1011` es `-12` porque los enteros de Factor tienen precisión arbitraria: invertir los bits de `0b1011` es conceptualmente «todos unos con los cuatro bits inferiores invertidos a `0100`», que leído como un número grande con signo es `-12`.

## Tratar un valor como N bits

`bits ( x n -- y )` de `math.bitwise` enmascara `x` a sus `n` bits menos significativos. Esta es la forma que tiene Factor de «reinterpretar un valor como un número entero sin signo de N bits»:

```factor
-1 8 bits .              ! => 255   (lowest 8 bits of -1 are all 1)
-2144333657 32 bits .    ! => 2150633639
```

Ese segundo ejemplo es importante para este ejercicio. Si empiezas con un valor Int32 negativo en complemento a dos y quieres desplazarlo «lógicamente» a la derecha (rellenando con ceros desde la izquierda) en `amount`, el idioma de Factor es:

```
( value -- shifted )
32 bits  amount neg  shift
```

Enmascara primero a 32 bits para pasar a la interpretación sin signo; después, desplaza. Como el valor enmascarado no es negativo, `shift` simplemente descarta bits por la parte inferior y rellena con ceros.
