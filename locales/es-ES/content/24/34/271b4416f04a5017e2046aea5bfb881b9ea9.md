# Instrucciones

Larry es un Lisp Alien al que le gusta escribir código para jugar a juegos.
Hoy quiere escribir unas cuantas funciones que le ayuden con un juego muy parecido al tres en raya.

Como el tres en raya, este juego se juega en un tablero que es una cuadrícula de 3x3.

## 1. Empezar desde cero

En primer lugar, Larry necesita una función para crear un tablero vacío, `make-empty-board`.
Todas las celdas del tablero deben ser `NIL`.

```lisp
(make-empty-board) ; => #2A((NIL NIL NIL) (NIL NIL NIL) (NIL NIL NIL))
```

## 2. Empezar desde un tablero existente

A continuación, Larry necesita una función para crear un tablero a partir de un array de filas.
Por ejemplo:

```lisp
(make-board-from-list '((A B C) (D E F) (G H I))) ; => #2A((A B C) (D E F) (G H I))
```

## 3. Condición de victoria

Si se da el caso de que hay 3 símbolos iguales en una fila, ese jugador ha ganado.
Larry necesitará una función, `all-the-same-p`, que, dado un array de 3 elementos, se evalúa como `T` si todos los elementos son el mismo símbolo.
(`eq` se puede usar para determinar si dos símbolos son iguales.)

```lisp
(all-the-same-p #(A A A)) ; => T
(all-the-same-p #(A B C)) ; => NIL
```

## 4. En una fila

Ahora Larry necesita una forma de obtener los elementos de una fila.
La función `row` toma un tablero y un número de fila y debe devolver un array con los elementos de esa fila.

```lisp
(row #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(4 5 6)
```

## 5. En una columna

Por último, Larry necesita una forma de obtener los elementos de una columna.
La función `column` toma un tablero y un número de columna y debe devolver un array con los elementos de esa columna.

```lisp
(column #2A((1 2 3) (4 5 6) (7 8 9)) 1) ; => #(2 5 8)
```
