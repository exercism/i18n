# Pistas

## General

- Lee sobre el módulo `Enum` en la [guía oficial de introducción][getting-started-enum] o en [elixirschool.com][elixir-school-enum].
- Echa un vistazo a la documentación para ver la [lista completa de funciones del módulo `Enum`][enum-functions].

## 1. Ordenar los artículos por precio

- Existe una [función incorporada][enum-sort-by] para ordenar enumerables usando una función de ordenación.

## 2. Encontrar todos los artículos a los que les falta el precio

- Existe una [función incorporada][enum-filter] para filtrar enumerables.

## 3. Actualizar los nombres de los artículos

- Existe una [función incorporada][enum-map] para transformar cada elemento de un enumerable.
- Existe una [función incorporada][string-replace] que puede reemplazar todas las apariciones de un string por otro distinto.

## 4. Incrementar la cantidad del artículo

- Los mapas implementan el protocolo Enumerable.
- Las funciones de `Enum` convierten los mapas en una lista de tuplas `{key, value}`.
- Hay dos funciones distintas que pueden transformar una lista de tuplas `{key, value}` de nuevo en un mapa usando una función de transformación. [Una de ellas siempre devuelve un mapa nuevo][map-new], mientras que [la otra te permite elegir el Collectable][enum-into].

## 5. Calcular la cantidad total del artículo

- Los mapas implementan el protocolo Enumerable.
- Las funciones de `Enum` convierten los mapas en una lista de tuplas `{key, value}`.
- Existe una [función incorporada][enum-reduce] para reducir un enumerable a un único valor.
