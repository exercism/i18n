# Aprendizaje

Exercism te ofrece ejercicios y comentarios, pero puede resultar difícil empezar si estás aprendiendo Pascal por primera vez. Estos recursos pueden ayudarte a dar los primeros pasos:

* [Pascal Tutorial](https://www.tutorialspoint.com/pascal/index.htm) parece un buen punto de partida para iniciarte con Pascal si no tienes ninguna experiencia con este lenguaje. No necesitas Delphi para completar los ejercicios que cubre este tutorial. Puede ser un buen sitio para practicar antes de lanzarte a los ejercicios de aquí, que sí requieren Delphi para completarse.
* [Pascal-Programming.info](http://www.pascal-programming.info/index.php) también parece tener un buen tutorial para quienes se acercan por primera vez a este lenguaje.
* También hay muchas más fuentes en internet para aprender Pascal, demasiadas para enumerarlas aquí.
