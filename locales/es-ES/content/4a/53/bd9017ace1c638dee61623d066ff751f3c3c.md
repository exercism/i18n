# Apéndice de instrucciones

## Pistas

Las pruebas de este ejercicio son diferentes de tus pruebas habituales. Normalmente, una prueba comprueba si, para una entrada dada, la salida coincide con el valor esperado. Esto se conoce como _pruebas basadas en valores_. Sin embargo, este ejercicio utiliza _pruebas basadas en propiedades_, en las que las pruebas comprueban si, para un rango de entradas, la salida tiene una propiedad concreta. Las dos diferencias clave que distinguen las pruebas basadas en propiedades de las pruebas basadas en valores son las siguientes:

1. Una prueba basada en propiedades no trabaja con un único valor de entrada, sino con muchos.
1. Una prueba basada en propiedades verifica propiedades, no valores concretos.

En este ejercicio, todas las pruebas verifican una propiedad de la forma del rombo que debe producir tu código. Además, todas las pruebas comprueban si la propiedad que verifican se cumple para todas las letras de entrada válidas ('A' a 'Z').

Para facilitar las pruebas basadas en propiedades, las pruebas de este ejercicio se apoyan en los paquetes [FsCheck](https://www.nuget.org/packages/FsCheck) y [FsCheck.Xunit](https://packages.nuget.org/packages/FsCheck.Xunit/2.2.0). Para saber más sobre FsCheck, puedes consultar la documentación del framework [aquí](https://fscheck.github.io/FsCheck/).

Si quieres más información sobre las pruebas basadas en propiedades, consulta [este artículo](http://www.erikschierboom.com/2016/02/22/property-based-testing/).
