# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo       | Descripción                              |
| -------- | --------- | ---------- | ---------------------------------------- |
| `$a0`    | entrada   | dirección  | string de entrada terminado en nulo      |
| `$v0`    | salida    | Boolean    | ISBN válido (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal  | cualquiera | se usan para almacenamiento temporal     |
