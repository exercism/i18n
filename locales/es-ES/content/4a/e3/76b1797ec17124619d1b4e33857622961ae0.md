# Introducción

Las funciones tienen vinculación externa por defecto y se pueden llamar desde cualquier otro archivo del proyecto.
Para obtener más información sobre la vinculación, consulta el [concepto de vinculación](../linkage/introduction.md#Introduction).
Una función `static` solo se puede llamar desde dentro del archivo fuente donde está definida.

Por ejemplo

```c
// file scope, internal linkage
// can only be called from within this file
static void some_function()
{
    // code snipped
}

// file scope, external linkage by default
// can be called from any other file in the project
int main()
{
    // code snipped
}
```
