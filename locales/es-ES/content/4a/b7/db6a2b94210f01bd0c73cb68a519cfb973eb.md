# Introducción

## Uniones discriminadas

El tipo de unión discriminada representa un número fijo de casos con nombre. Cada valor de una unión discriminada corresponde exactamente a uno de los casos con nombre.

Una unión discriminada se define usando la palabra clave `type`, con los casos separados por barras verticales (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de una unión discriminada puede tener, opcionalmente, datos asociados, y distintos casos pueden tener distintos tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada es similar a lo que otros lenguajes suelen llamar una _enumeración_ (o _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Se puede crear un valor para un caso específico haciendo referencia a su nombre (p. ej., `Success`). Como los nombres de los casos son solo funciones constructoras, los datos asociados se pueden pasar como un argumento de función normal. Si otra unión discriminada ha definido un caso con el mismo nombre, tendrás que usar su nombre completo (p. ej., `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Las uniones discriminadas tienen _igualdad estructural_, lo que significa que dos valores para el mismo caso y con los mismos datos (opcionales) son equivalentes.

Aunque se pueden usar expresiones `if/elif/else` para trabajar con uniones discriminadas, la forma recomendada de trabajar con ellas es mediante la coincidencia de patrones usando el _patrón de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
