# Introducción

Las funciones en Kotlin son ciudadanas de primera clase.
Esto significa que se pueden guardar en variables, pasar como argumentos e incluso devolver desde otras funciones.
Por ejemplo, asignar una función a la variable `addOne`:

```kotlin
val addOne = fun (num : Int) : Int {
    return num + 1
}
```

Una función también puede devolver otra función:

```kotlin
fun makeAddOne() : (Int) -> Int {
    return fun(num : Int) : Int {
        return num + 1
    }
}

val addOne = makeAddOne()
```

Una vez asignada, se puede llamar a la función a través de la variable como si fuera una función cualquiera:
```kotlin
addOne(3)
// => 4
```

## Declarar tipos de función

Se puede declarar el tipo de una variable o de un parámetro con la sintaxis `(parameter types) -> return type`.
Por ejemplo, declarar una variable:

```kotlin
val addOne : (Int) -> Int = fun (num : Int) : Int {
    return num + 1
}
```

Y para un parámetro de función:

```kotlin
fun perform(operation : (Int) -> Int) {
    operation(3)
}
```

## Expresiones lambda

Una expresión lambda es una forma más corta de definir una función.
Se escriben con la forma `{ parameters -> body }`.
La expresión devuelve el último valor de la última instrucción del cuerpo.
Por ejemplo:

```kotlin
// Assigning to a variable
val addOne = { num : Int -> num +  1}

// In a function call
perform({ num : Int -> num + 1 })
```

Kotlin puede inferir los tipos cuando hay suficiente información.
Por ejemplo, los ejemplos anteriores también se pueden escribir así:

```kotlin
// Assigning to a variable
val addOne : (Int) -> Int = { num -> num + 1 }

// Or ...
val addOne  = { num : Int -> num + 1 }

// Using in a function
perform({ num -> num + 1 })
```

## `it` para expresiones lambda de un solo parámetro

Cuando la expresión tiene un solo parámetro, se puede omitir el parámetro.
Kotlin pondrá entonces a disposición del cuerpo un parámetro llamado `it`.
Por ejemplo:

```kotlin
val addOne : (Int) -> Int = { it +  1 }
```

## Pasar expresiones lambda finales

Cuando el último argumento de una función es una expresión lambda, esta se escribe directamente _después_ de los paréntesis.
Por ejemplo:

```kotlin
// Function that takes a function as last argument
fun calculateFrom(from : Int, operation : (Int) -> Int) : Int {
    return operation(from)
}

// Call the calculateFrom function
calculateFrom(2) { it * 3 }
// => 6
```
