# Instrucciones

Te han contratado como especialista en expresiones regulares en una empresa que está desarrollando un chatbot.

Está en una fase de desarrollo muy básica, así que tu misión es usar expresiones regulares para mejorar la capacidad del chatbot de entender y generar lenguaje natural.

~~~~exercism/note
Con fines de aprendizaje, resuelve estas tareas usando expresiones regulares.

Sabemos que a veces son posibles otras alternativas (¡y puede que incluso sean más eficientes!).
~~~~

## 1. Comprobar que el comando es válido

Además de ser inteligente, el chatbot también es un asistente leal.

Para preguntarle algo al chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.

No importa si la palabra clave está en MAYÚSCULAS o en minúsculas.
Lo importante aquí es la posición de la palabra.

Implementa la función `is_valid_command()` que ayuda al chatbot a reconocer cuándo el usuario está dando un comando.

```R
is_valid_command("Chatbot, play a song from the 80's.")
[1] TRUE
> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
[1] FALSE
> is_valid_command("CHATBOT, do you have a solution for this challenge?")
[1] TRUE
```

## 2. Eliminar los emojis cifrados

Al chatbot le cuesta entender cómo los humanos usan los emojis para expresar sus emociones.

Cuando el chatbot recibe mensajes de usuario, cada emoji se representa como «_emoji_» seguido de su número _id_.

Implementa el método `remove_emoji()` para que tome un string y elimine todo el cifrado de los emojis a lo largo del mensaje.

Las líneas que no contengan el texto de un emoji deben devolverse sin modificar.

Solo elimina el string del emoji. No intentes ajustar los espacios en blanco.

```R
remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
[1] "I love playing videogames  it's one of my hobbies"
```

## 3. Comprobar que el número de teléfono es válido

Dado que las funcionalidades del chatbot se descargan en una app móvil, se espera que el usuario escriba un número de teléfono durante la conversación.

El problema es que el chatbot solo puede leer y validar un número con un formato específico.

Si el número es válido (coincide con la secuencia de caracteres especificada por la **expresión regular**), el chatbot responde con un mensaje que agradece al usuario y confirma el número. Si el número no es válido, la función informa al usuario de que el número de teléfono no es válido.

El formato esperado es: (+##) ###-###-###

```R
check_phone_number("(+34) 659-771-594")
[1] "Thanks! You can now download me to your phone."
> check_phone_number("659-771-594")
[1] "Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Saludar al usuario

Para almacenar los datos de todas las personas que han conversado con él, el chatbot es capaz de obtener el nombre completo del perfil del usuario con este formato: **«Smith, John»**.

De esta forma, queremos que nuestro chatbot sea muy educado y cause una buena impresión.

Escribe la función `nice_to_meet_you()` que toma un string con el nombre completo del usuario y devuelve el string **«Nice to meet you, John Smith»**

```R
nice_to_meet_you("Smith, John")
#> Nice to meet you, John Smith
```

## 5. Obtener el enlace de un sitio web

El chatbot es un software muy curioso. Aunque puede buscar en internet sobre un tema concreto, le gusta preguntar a los usuarios por sitios web o URL interesantes donde encontrar información relevante.

Ejemplo de conversación:

- **Chatbot**: Hola, usuario, me gustaría aprender a programar en JavaScript, ¿conoces algún sitio web interesante donde pueda aprender?
- **User**: Aprendí mucho en [exercism.org](http://exercism.org)

Implementa la función `get_URL()` que es capaz de devolver un array con solo el enlace de cada sitio web.

```R
get_URL("I learned a lot from exercism.org")
[1] "exercism.org"
```
