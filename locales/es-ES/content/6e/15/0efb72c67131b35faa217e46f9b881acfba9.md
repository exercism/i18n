# Introducción

En JavaScript, los valores pueden ser de distintos tipos. Cambiar el tipo de una variable puede hacerse mediante una _conversión de tipos_ explícita.
Además, JavaScript también realiza una _coerción de tipos_ (conversión de tipos implícita) cuando el contexto lo requiere.

## Conversión de tipos

JavaScript no tiene una construcción para convertir a un tipo (distinto), como sí tienen muchos otros lenguajes, pero en su lugar se pueden usar algunos ayudantes integrados.
En particular, `Boolean`, `Number` y `String` se pueden usar como funciones para convertir un valor al tipo correspondiente.

### Conversión a Boolean (valores truthy/falsy)

Con `Boolean(value)` puedes convertir cualquier valor a Boolean.
Hay un conjunto fijo de valores, los llamados valores _falsy_, que se convierten en `false`.
En concreto, `false`, `0`, el string vacío, `null`, `undefined` y `NaN` son falsy.

Para todos los demás valores, `Boolean` devuelve `true`.
Estos valores se llaman _truthy_.

```javascript
Boolean(-1);
// => true

Boolean(0);
// => false

Boolean(' ');
// => true

Boolean('');
// => false
```

Ten en cuenta que, debido a las reglas descritas, `'0'`, `'false'`, `[]` y `{}` son **truthy** en JavaScript.

### Conversión a número

`Number(value)` se puede usar para convertir un valor a número.
Los espacios en blanco al principio y al final de un string se ignoran, y un string vacío se convierte en `0`.
Si intentas convertir un valor no primitivo o un string que no representa un número, el resultado es `NaN` ([Not-A-Number][mdn-nan]).

```javascript
Number('  -12.34  ');
// => -12.34

Number('1,2');
// => NaN

Number('');
// => 0

Number({ num: 123 });
// => NaN
```

### Conversión a string

Con `String(value)` puedes convertir un valor a string.
El resultado es el que cabría esperar para valores primitivos.

```javascript
String(12.34);
// => '12.34'

String(false);
// => 'false'

String(null);
// => 'null'

String(undefined);
// => 'undefined'
```

Para los arrays, la función `String` aplicará la conversión a string a cada elemento y unirá los resultados con una coma.
También puedes aplicar tú mismo el [método `join`][mdn-join], por ejemplo para personalizar el separador.
Ten en cuenta que, en estos casos, `null` y `undefined` se convertirán en un string vacío.

```javascript
String([42, null, true, 'abc']);
// => '42,,true,abc'
```

Para los objetos, por defecto `String` devuelve un texto poco útil.

```javascript
String({ key: 'value' });
// => '[object Object]'
```

## Coerción de tipos

En ciertos contextos, JavaScript convierte automáticamente un valor a otro tipo de dato antes de evaluar alguna instrucción.
Esta conversión implícita se llama _coerción de tipos_.

### Contexto booleano

Cuando se usa un valor que no es booleano en un contexto booleano, JavaScript aplica las mismas reglas que la función `Boolean` para convertir el valor de forma implícita.

La coerción a booleano se da habitualmente en

- la condición de un [condicional][concept-conditionals]
- el primer operando del [operador ternario][mdn-ternary] `?`
- el operando del operador lógico NOT `!`
- los operandos de los operadores lógicos AND `&&` y OR `||` (el resultado de la expresión es uno de los operandos, no necesariamente un valor booleano)

```javascript
const num = 0;
if (num) {
  // this block is NOT executed because 0 is falsy
}
```

### Contexto de string

Si se usa el operador de suma `+` con valores primitivos y uno de los operandos es un string, el otro también se convertirá por coerción a string.
La lógica de conversión es la misma que al usar la función `String`.
Después, los dos strings se concatenan.

```javascript
let name;
'hello ' + name;
// => 'hello undefined'
```

### Contexto numérico

Muchos operadores convierten los operandos a números por coerción (si es necesario) según la lógica de la función `Number` explicada antes.

- Operadores aritméticos: `+` (si no hay ningún string de por medio), `-`, `*`, `/`, `%`, `**`
- Operadores unarios de suma y de negación: `+`, `-`
- Operadores relacionales (para operandos que no sean strings): `>`, `>=`, `<`, `<=`
- Operadores a nivel de bits: `|`, `&`, `^`, `~`

Consulta la [lista de operadores de MDN][mdn-operators] para obtener más detalles sobre cualquiera de esos operadores.

Para evitar errores, es buena práctica llamar siempre a `Number` explícitamente antes de aplicar esos operadores.
