# Anexo a las instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, conviene incluir siempre un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda muchísimo a la hora de depurar. En los casos en los que sepas que el origen del error va a ser de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así deberías incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» un `ValueError` si se pasa a la función `classify()` un número que no sea un _entero positivo_. Las pruebas solo pasarán si tanto usas `raise` con la `exception` como incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# if a number to be classified is less than 1.
raise ValueError("Classification is only possible for positive integers.")
```
