# Instrucciones

Implementa una función que, dados dos puntos en el plano de coordenadas 2D, produzca un tercer punto tal que al unir estos puntos se forme un triángulo equilátero. La función devolverá dos puntos, porque hay dos posibles puntos «terceros» que forman un triángulo equilátero a partir de los dos puntos iniciales. Cabe señalar que un triángulo equilátero se define como una figura de tres lados en la que los tres lados tienen la misma longitud.

La función recibe como entrada dos tuplas de Python, cada una de las cuales especifica las coordenadas x e y de cada punto, como números de coma flotante. Por ejemplo, (0.0, 0.0) y (1.0, 1.0) podrían ser entradas.

La función debe devolver una tupla formada por dos tuplas, cada una de las cuales especifica las coordenadas x e y de cada punto, como números de coma flotante. Por ejemplo, ((0.0, 0.0), (1.0, 1.0)) podría ser una posible salida.

La función debe lanzar una excepción ArithmeticError integrada de Python si el solucionador Z3 produce un resultado que no es satisfacible. También debe lanzar una ArithmeticError si los dos puntos de entrada son iguales.

La función no debe usar la función «set_option()» de la biblioteca z3 para establecer parámetros globales. Esto se hace dentro de los casos de prueba para asegurar que los números de coma flotante tengan la precisión esperada (número de decimales).

Dado que la interpretación del modelo de una variable Real de Z3 es una instancia de AlgebraicNumRef, IntNumRef o RatNumRef, se proporciona una función para convertir esta instancia en un número de coma flotante.
