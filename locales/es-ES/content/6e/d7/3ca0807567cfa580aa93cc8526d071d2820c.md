# Añadido a las instrucciones

## Implementación

Define una función, `cost`, que calcule el coste de un array de libros dado a partir de los descuentos definidos.

`cost` devolverá el coste total (tras los descuentos) en centavos.
Por ejemplo, para un solo libro, el coste es de 800 centavos, que equivalen a 8,00 $.
Para este ejercicio solo se necesitan cálculos con números enteros.
