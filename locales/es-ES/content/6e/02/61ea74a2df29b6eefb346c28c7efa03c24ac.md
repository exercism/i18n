# Introducción

En Common Lisp, una función puede tener algunos argumentos que son opcionales.
Estos se designan en la lista lambda mediante la palabra clave de la lista lambda `&optional`.
Un parámetro queda ligado al valor `nil` si no se especifica.
Si hay varios parámetros opcionales, se ligan en orden.
Se pueden especificar valores por defecto para los parámetros opcionales.
Por último, se puede especificar un símbolo para cada parámetro opcional, que quedará ligado a verdadero o falso dependiendo de si quien llama a la función suministró ese parámetro (esto se conoce como el «parámetro supplied-p»).

```lisp
(defun optional-parameters (&optional x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(optional-parameters)          ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(optional-parameters 5 nil 10) ; => (5 NIL (:Z-WAS-SUPPLIED 10))
```
