# Instrucciones

En este ejercicio vas a implementar un conjunto parcial de rutinas auxiliares para ayudar a un desarrollador a limpiar nombres de identificadores.

A lo largo de las 6 tareas irás construyendo gradualmente las funciones `transform`, para convertir caracteres individuales, y `clean`, para convertir strings.

Un identificador válido consta de cero o más letras, guiones bajos, guiones, signos de interrogación y emojis.

Si se pasa un string vacío a la función `clean`, debería devolverse un string vacío.

## 1. Sustituye los guiones que encuentres por guiones bajos

Implementa la función `transform` para sustituir los guiones por guiones bajos.

```fsharp
transform '-'  // => "_"
```

## 2. Elimina todos los espacios en blanco

Elimina todos los caracteres de espacio en blanco.
Esto incluye los espacios en blanco al principio y al final.

```fsharp
transform ' '  // => ""
```

## 3. Convierte camelCase a kebab-case

Modifica la función `transform` para convertir camelCase a kebab-case

```fsharp
transform 'D'  // => "-d"
```

## 4. Omite los caracteres que sean dígitos

Modifica la función `transform` para omitir los caracteres que sean numéricos.

```fsharp
transform '7'  // => ""
```

## 5. Sustituye las letras griegas minúsculas por signos de interrogación

Modifica la función `transform` para sustituir las letras griegas del rango de 'α' a 'ω'.

```fsharp
transform 'β' // => "?"
```

## 6. Combina estas operaciones para que actúen sobre un string

Implementa la función `clean` para aplicar estas operaciones a un string completo.

Los caracteres que queden fuera de las reglas deben pasar sin cambios.

```fsharp
clean "  a2b Cd-ω😀  " //  => "ab-cd_?😀"
```

## Cómo componer un string a partir de caracteres

Este tema se tratará en detalle más adelante en el temario.

Por ahora, puede resultarte útil saber que existe una [función de orden superior][higher-order-function] llamada [`String.collect`][string-collect] que convierte una colección de `char` en un string, usando una función que tú proporciones.

```fsharp
let transform ch = $"{ch}_"
String.collect transform "abc"  // =>  "a_b_c_"
```
