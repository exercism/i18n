# Instrucciones

El clásico ejercicio de introducción. Basta con decir "Hello, World!".

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) es el tradicional primer programa para empezar a programar en un lenguaje o entorno nuevos.

Los objetivos son sencillos:

- Escribe una función que devuelva el string "Hello, World!".
- Ejecuta la suite de pruebas y asegúrate de que pasa.
- Envía tu solución y compruébala en el sitio web.

Si todo va bien, estarás listo para obtener tu primer ejercicio real.
