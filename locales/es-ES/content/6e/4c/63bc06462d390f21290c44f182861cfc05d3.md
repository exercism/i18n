# Aprendizaje

Exercism ofrece ejercicios y comentarios, pero puede resultar difícil adentrarse para quienes están aprendiendo Reason por primera vez. Estos recursos pueden ayudarte a empezar:

[Página de inicio de Reason](https://reasonml.github.io/)
[Blog del programador](https://lucasmreis.github.io/blog/learning-reasonml-part-1/)

ReasonML puede usar [Belt](https://bucklescript.github.io/bucklescript/api/Belt.html), la biblioteca estándar que se distribuye con Bucklescript (el sistema Ocaml subyacente sobre el que se superpone).
