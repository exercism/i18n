# Array de lenguajes

## Historia

Esta historia facilita la exploración de los [arrays][types-list] en un lenguaje.

La premisa básica es que una persona quiere mantener un [array][types-list] de lenguajes que quiere aprender en el sitio web de Exercism.

## Tareas

Por lo general, el ejercicio guía a los estudiantes sobre cómo:

- Crear un array.
- Añadir elementos a un array.
- Eliminar elementos de un array.
- Contar la longitud de un array.
- Obtener el primer elemento de un array.
- Comprobar si un elemento es miembro de un array.
