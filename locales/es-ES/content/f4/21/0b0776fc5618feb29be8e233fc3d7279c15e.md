# Pistas

## 1. Define el tiempo esperado de horno en minutos

- Necesitas definir una [constante][constants] que contenga el valor [número entero][integers] indicado en la receta.
- El `::` que se usa en `Lasagna::EXPECTED_MINUTES_IN_OVEN` significa que `EXPECTED_MINUTES_IN_OVEN` debe definirse dentro de la clase `Lasagna`.

## 2. Calcula el tiempo restante de horno en minutos

- Necesitas definir un [método][methods] con un único parámetro para el tiempo transcurrido hasta ahora.
- Puedes [devolver implícitamente un número entero][return] desde el método.
- Puedes usar el [operador matemático de resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Necesitas definir un [método][methods] con un único parámetro para el número de capas.
- Puedes [devolver implícitamente un número entero][return] desde el método.
- Puedes usar el [operador matemático de multiplicación][operators] para multiplicar valores.
- Podrías definir una constante adicional para el tiempo en minutos por capa, o usar un «número mágico» en el código.

## 4. Calcula el tiempo total de trabajo en minutos

- Necesitas definir un [método][methods] con dos parámetros con nombre: `number_of_layers` y `actual_minutes_in_oven`.
- Puedes [devolver implícitamente un número entero][return] desde el método.
- Puedes [invocar][invocation] uno de los otros métodos que has definido previamente.
- Puedes usar el [operador matemático de suma][operators] para sumar valores.
