# Instrucciones

Nadie sube al trapecio en el circo hasta que se superan las comprobaciones de seguridad.
Vas a escribir estas comprobaciones para que las mismas reglas se apliquen a todo el mundo.

Las cinco tareas van en la clase `SAFETY_CHECK`.

## 1. ¿Está lista la colchoneta?

La colchoneta está lista solo cuando está colocada y limpia.

```sather
SAFETY_CHECK::mat_ready(true, false)
-- => false
```

## 2. ¿Hay algo sobre lo que aterrizar?

Tiene que haber una colchoneta debajo, o una red debajo. Cualquiera de las dos
sirve, y tener las dos también está bien.

```sather
SAFETY_CHECK::something_below(false, true)
-- => true
```

## 3. ¿Quién necesita todavía la sesión informativa?

Cualquiera que no haya recibido la sesión informativa la necesita.

```sather
SAFETY_CHECK::needs_briefing(false)
-- => true
```

## 4. ¿Este artista tiene la edad suficiente?

El trapecio es para artistas de 13 años o más.

```sather
SAFETY_CHECK::old_enough(13)
-- => true
```

## 5. Únelo todo

Un artista está autorizado para el trapecio cuando tiene la edad suficiente, ha
recibido la sesión informativa y la colchoneta está lista.

```sather
SAFETY_CHECK::cleared(14, true, true, true)
-- => true
```

Los cuatro argumentos son la edad, si ha recibido la sesión informativa, si la
colchoneta está colocada y si la colchoneta está limpia.
