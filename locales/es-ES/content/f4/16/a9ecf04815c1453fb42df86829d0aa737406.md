# Apéndice de instrucciones

## Formato de salida

Genera un string terminado en nulo, usando una coma y un espacio como separadores.

Un ejemplo de salida sería `"491, 914, 142"`

Si la entrada no es válida, devuelve un string vacío.

## Registros

| Registro | Uso           | Tipo      | Descripción                              |
| -------- | ------------- | --------- | ---------------------------------------- |
| `$a0`    | entrada       | dirección | string de la serie terminado en nulo     |
| `$a1`    | entrada       | entero    | longitud del fragmento                   |
| `$a2`    | entrada/salida | dirección | string de salida terminado en nulo       |
| `$t0-9`  | temporal      | cualquiera | usado para almacenamiento temporal       |
