# Aprender Visual Basic

## Sitios web

Visual Basic ha evolucionado mucho con los años, y muchos tutoriales de terceros hacen referencia a herramientas o funcionalidades obsoletas.
La [documentación oficial de Visual Basic](https://learn.microsoft.com/en-us/dotnet/visual-basic/) es el lugar más actualizado y fiable para comenzar tu andadura.

## El ecosistema .NET

Visual Basic se ejecuta en el runtime de .NET y comparte gran parte de su funcionalidad básica con C# y F#.
Por lo tanto, entender cómo funciona .NET te convertirá en un desarrollador de VB más competente.

- [¿Qué es .NET?](https://learn.microsoft.com/en-us/dotnet/core/introduction)
- [El glosario de .NET](https://learn.microsoft.com/en-us/dotnet/standard/glossary)
- [El sistema de tipos comunes (CTS)](https://learn.microsoft.com/en-us/dotnet/standard/base-types/common-type-system)
