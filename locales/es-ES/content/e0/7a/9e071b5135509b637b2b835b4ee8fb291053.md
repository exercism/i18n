# Instrucciones

En este ejercicio vas a comprobar los permisos de las cuentas de usuario de un foro de internet. El foro admite tres permisos distintos:

- Read
- Write
- Delete

Hay tres tipos de cuentas, cada una con permisos predeterminados diferentes:

- Invitados: pueden leer publicaciones.
- Usuarios: pueden leer y escribir publicaciones.
- Moderadores: pueden leer, escribir y borrar publicaciones, tienen todos los permisos.

A veces se pueden modificar los permisos individuales; es posible, por ejemplo, dar a una cuenta de invitado el permiso para escribir publicaciones también, o revocar todos los permisos de una cuenta daría como resultado que no tuviera ninguno.

## 1. Obtener los permisos predeterminados de un tipo de cuenta

Primero, define una enumeración `AccountType` para representar los tres tipos de cuenta: `Guest`, `User` y `Moderator`.

Después, define una enumeración `Permission` para representar los tres tipos de permiso: `Read`, `Write`, `Delete`, y dos más: `All` para tener todos los permisos y `None` para no tener ninguno.

A continuación, implementa el método (_estático_) `Permissions.Default()` para devolver los permisos predeterminados de un tipo de cuenta concreto:

```csharp
Permissions.Default(AccountType.Guest)
// => Permission.Read
```

## 2. Conceder un permiso

Implementa el método (_estático_) `Permissions.Grant()` que concede (añade) un permiso:

```csharp
Permissions.Grant(current: Permission.None, grant: Permission.Read)
// => Permission.Read
```

## 3. Revocar un permiso

Implementa el método (_estático_) `Permissions.Revoke()` que revoca (elimina) un permiso:

```csharp
Permissions.Revoke(current: Permission.Read, revoke: Permission.Read)
// => Permission.None
```

## 4. Comprobar un permiso

Implementa el método (_estático_) `Permissions.Check()` que toma los permisos actuales de la cuenta y comprueba si la cuenta está autorizada para un permiso dado:

```csharp
Permissions.Check(current: Permission.Write, check: Permission.Read)
// => false
```
