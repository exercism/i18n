## 1. Comprobar la criticidad

- Los operadores de comparación ([comparaciones][comparisons review]) y las operaciones booleanas ([concept:python/bools]()) se pueden combinar y usar con condicionales.
- Las expresiones condicionales deben evaluarse como `True` o `False`.
- `else` se puede usar para un bloque de código que se ejecutará cuando todas las comprobaciones condicionales devuelvan `False`.

  ```python
     >>> item = 'blue'
     >>> item_2 = 'green'
     
     >>>  if len(item) >= 3 and len(item_2) < 5:
            print('Both pass the test!')
          elif len(item) >= 3 or len(item_2) < 5:
            print('One passes the test!')
          else:
            print('None pass the test!')
    ...
    One passes the test!
  ```

## 2. Determinar el rango de potencia de salida

- Los operadores de comparación se pueden combinar y usar con condicionales.
- Cualquier número de instrucciones `elif` se puede usar como «ramas» de decisión.
- Cada «rama» puede tener un `return` separado, aunque las herramientas de linting podrían considerarlo «mala práctica».
- Si el linter se queja, considera asignar la salida de una rama a una variable común y luego devolver esa variable con `return`.
