# Ejemplo

```riscvasm
.equ FRAME_SIZE, 16

.text
.global is_triple
```

Las líneas que empiezan por un punto son _directivas_: instrucciones para el ensamblador, no para el procesador.
`.equ` da el nombre `FRAME_SIZE` al número 16.
`.text` indica que lo que sigue es código.
`.global` hace que la etiqueta `is_triple` sea visible fuera de este fichero, de modo que otro código pueda llamarla.
También puedes ver `.globl`, que significa lo mismo.

```riscvasm
/* bool is_triple(unsigned a, unsigned b, unsigned c); */
is_triple:
```

`is_triple` comprueba si `a² + b² = c²`, devolviendo 1 si se cumple y 0 en caso contrario.
Por ejemplo, `(6, 8, 10)` da 1, porque `36 + 64 = 100`.
La etiqueta `is_triple` marca dónde empieza la función.
Se llama con `a`, `b` y `c` en los registros `a0`, `a1` y `a2`.

```riscvasm
        addi    sp, sp, -FRAME_SIZE
        sw      ra, 12(sp)      /* save the return address */
        sw      a1, 8(sp)       /* save b */
        sw      a2, 4(sp)       /* save c */
```

El registro `ra` contiene la _dirección de retorno_, el lugar del código que hizo la llamada al que hay que volver cuando terminemos.
Cada `call` sobrescribe `ra`, así que primero lo guardamos en la _pila_.
La pila crece hacia abajo, hacia direcciones más pequeñas, así que restar 16 al puntero de pila `sp` nos reserva 16 bytes.
(`sp` siempre debe ser múltiplo de 16.)
También guardamos `b` y `c`, porque una función a la que llamamos puede cambiar los registros `a`.

```riscvasm
        call    square          /* a0 = a * a */
        sw      a0, 0(sp)       /* save a * a */
```

`a` ya está en `a0`, que es donde `square` espera su entrada.
`call` hace que `ra` apunte a la siguiente instrucción y salta a `square`, que devuelve su resultado en `a0`.

```riscvasm
        lw      a0, 8(sp)       /* a0 = b */
        call    square          /* a0 = b * b */
        lw      t0, 0(sp)       /* t0 = a * a */
        add     t0, t0, a0      /* t0 = a * a + b * b */
        sw      t0, 0(sp)       /* save a * a + b * b */
```

Cargamos `b` de nuevo desde la pila, la elevamos al cuadrado y la sumamos a `a * a`.

```riscvasm
        lw      a0, 4(sp)       /* a0 = c */
        call    square          /* a0 = c * c */
        lw      t0, 0(sp)       /* t0 = a * a + b * b */
        sub     a0, t0, a0      /* a0 = a * a + b * b - c * c */
        seqz    a0, a0          /* a0 = 1 if that is zero, otherwise 0 */
```

La diferencia es cero exactamente cuando `a² + b² = c²`.
`seqz` («establecer si es igual a cero») convierte eso en 1 o 0.

```riscvasm
        lw      ra, 12(sp)      /* restore the return address */
        addi    sp, sp, FRAME_SIZE
        ret
```

Restauramos `ra` y devolvemos los 16 bytes de pila.
`ret` salta entonces a la dirección que contiene `ra`, de vuelta a quien hizo la llamada.

```riscvasm
/* unsigned square(unsigned n); */
square:
        mul     a0, a0, a0      /* n * n */
        ret
```

`square` no llama a ninguna otra función, así que `ra` permanece intacto y no hay nada que guardar.
No lleva la marca `.global`, porque solo `is_triple` la usa.
