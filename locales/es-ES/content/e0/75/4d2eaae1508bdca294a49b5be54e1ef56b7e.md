# Anexo a las instrucciones

## Instrucciones específicas del track

Para este ejercicio, tu verbo recibirá dos argumentos:

- **Argumento izquierdo**: un array de números enteros que representa el conjunto de objetos mágicos recolectados.
- **Argumento derecho**: un número entero que representa el nivel completado.

Tu verbo debe definirse de forma que gestione estas entradas del modo siguiente:

```j
  factors =. 3 5
  limit   =. 20
  
  multiplesList sum upperLimit
```
