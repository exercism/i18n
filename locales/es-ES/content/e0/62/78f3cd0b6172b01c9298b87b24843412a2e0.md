# no uses la división ni el módulo

Tal y como se indica en las instrucciones, el objetivo de este ejercicio es construir una criba de Eratóstenes sin usar operaciones como la división o el módulo.
Consulta el [enlace a Wikipedia](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes) para ver una descripción del algoritmo.

Construir la criba de Eratóstenes en un lenguaje inmutable como Elm puede resultar un poco antinatural, pero es un algoritmo precioso inventado hace más de dos milenios que merece la pena aprender e implementar correctamente.
