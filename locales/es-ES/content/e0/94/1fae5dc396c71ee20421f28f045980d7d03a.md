# Instalación

Consulta [el wiki de `jq`][jq-wiki-install] para ver las instrucciones de instalación.

## Información sobre la versión

A fecha de junio de 2025, la versión actual de jq es la **1.8**.
Esta es la versión que se usa en el ejecutor de pruebas en línea de jq.

Muchos gestores de paquetes de Linux instalarán una versión anterior, la 1.6.
Deberías instalar manualmente una versión más reciente; ha habido muchos cambios beneficiosos desde que se publicó la v1.6 en 2018.

[jq-wiki-install]: https://github.com/jqlang/jq/wiki/Installation
