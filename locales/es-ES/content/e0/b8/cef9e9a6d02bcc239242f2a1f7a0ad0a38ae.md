# Pistas

## General

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones de memoria son valores de 64 bits (8 bytes).

## 1. Crea una entrada para cada objeto

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones de memoria son valores de 64 bits (8 bytes).
- Todos los argumentos enteros a partir del sexto se pasan en la pila, y el primero está en `rsp + 8`.
- El número de argumentos adicionales es igual al número de categorías, que se pasa en `r9`.
- Puedes usar un bucle para añadir los argumentos adicionales uno a uno, o puedes usar [movsq][movs] combinado con [rep][rep].

## 2. Reserva espacio para un array mensual de objetos

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones de memoria son valores de 64 bits (8 bytes).
- Necesitas conocer el tamaño del array para poder borrar sus bytes después de llamar a la función que reserva la memoria.
- Cuando llamas a una función externa, esta puede modificar el valor de cualquier _registro guardado por el llamador_.
- Puedes conservar el valor de un registro en la pila usando [push][push] o manipulando `rsp` directamente.
- Cualquier modificación de `rsp`, incluida la que se hace con `push`, debe revertirse antes de que la función devuelva el control, ya sea con [pop][pop] o cambiando `rsp` directamente.

## 3. Inserta un objeto en el array mensual

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones de memoria son valores de 64 bits (8 bytes).
- Un valor que no cabe en un registro se pasa a una función en la pila.
- Cada entrada de un objeto ocupa 120 bytes de espacio, mucho más que el tamaño máximo de un registro (8 bytes).
- Los argumentos que se pasan en la pila se encuentran en direcciones que empiezan en `rsp + 8`.
- Puedes usar un bucle para añadir los valores a la posición de memoria de destino, o puedes usar [movsb][movs] combinado con [rep][rep].

## 4. Imprime un objeto

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Las direcciones de memoria son valores de 64 bits (8 bytes).
- El string introductorio es opcional; en su lugar, puedes llamar a la función de impresión con `0`.
- Si se pasa el string introductorio a la función de impresión, debe tener como máximo 50 caracteres ASCII, incluido ya el terminador NUL (valor `0`).
- Siempre que llamas a una función, debes reservar espacio en la pila para cualquier argumento a partir del sexto.
- El ABI de System V establece que la pila debe estar alineada a 16 bytes antes de llamar a una función, lo cual es especialmente importante para las funciones externas.
- Cada entrada de un objeto en el array ocupa 120 bytes de espacio.
