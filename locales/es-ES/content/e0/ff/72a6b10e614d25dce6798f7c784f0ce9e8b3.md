# Introducción

Un bucle `for` permite ejecutar código repetidamente hasta que se cumple una condición.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un bucle `for` consta de cuatro partes:

1. La inicialización: se ejecuta una vez antes de entrar en el bucle. Normalmente se usa para definir las variables que se utilizan dentro del bucle.
2. La condición: se ejecuta antes de cada iteración del bucle. El bucle sigue ejecutándose mientras esta se evalúe como `true`.
3. El iterador: se ejecuta después de cada iteración del bucle. Normalmente se usa para modificar (a menudo, incrementar o decrementar) la o las variables del bucle.
4. El cuerpo: el código que se ejecuta en cada iteración del bucle.
