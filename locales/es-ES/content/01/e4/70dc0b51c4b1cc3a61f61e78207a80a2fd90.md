# Introducción

## Cadenas de caracteres

Una `string` en F# es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.) y se define de la siguiente manera:

```fsharp
let fruit = "Apple"
```

Las `string` se manipulan ya sea llamando a los métodos de la string o usando las funciones del módulo `String`. Una vez construida una `string`, su valor nunca puede cambiar. Cualquier método o función que parezca modificar una `string` en realidad devolverá una `string` nueva.

Las `string` se pueden concatenar o dar formato de varias maneras distintas.
* Puedes usar el operador `+` para concatenar:
```fsharp
let sentence = "Apple" + " is a type of fruit."
```
* Puedes usar la función `sprintf` para dar formato al texto, donde tienes marcadores de posición en un texto de formato (`%s` para una `string`) y proporcionas los valores como argumentos:
```fsharp
let sentence = sprintf "%s is a type of %s." "Apple" "fruit"
```
