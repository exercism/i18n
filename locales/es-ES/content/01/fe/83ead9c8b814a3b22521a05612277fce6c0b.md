# Funciones

Las funciones son fundamentales en Cairo.

Por convención, Cairo usa **snake case** para los nombres de funciones y variables, donde las palabras van en minúsculas y separadas por guiones bajos.

Aquí tienes un ejemplo:

```rust
fn another_function() {
    println!("Another function.");
}

fn main() {
    println!("Hello, world!");
    another_function();
}
```

Las funciones se definen con `fn`, seguidas de un nombre, paréntesis para los parámetros (si los hay), y un cuerpo encerrado entre llaves.

Puedes llamar a una función por su nombre seguido de paréntesis.

El orden de las funciones no importa siempre que estén en el scope.

## Parámetros

Las funciones pueden tomar **parámetros**, que son variables definidas en la firma de la función.

Cuando llamas a la función, proporcionas **argumentos**, los valores que se pasan a estos parámetros.

```rust
fn main() {
    another_function(5);
}

fn another_function(x: felt252) {
    println!("The value of x is: {}", x);
}
```

Aquí, `x` es un parámetro de tipo `felt252`.

Cuando se llama con `5`, la función imprime "The value of x is: 5".

Varios parámetros se separan por comas:

```rust
fn main() {
    print_labeled_measurement(5, "h");
}

fn print_labeled_measurement(value: u128, unit_label: ByteArray) {
    println!("The measurement is: {value}{unit_label}");
}
```

Esto imprime: `The measurement is: 5h`.

## Instrucciones y expresiones

Las funciones de Cairo se componen de **instrucciones** y **expresiones**:

- Las **instrucciones** realizan acciones pero no devuelven valores.
Por ejemplo, `let x = 3;` es una instrucción.
- Las **expresiones** se evalúan a un valor.
Por ejemplo, `5 + 6` se evalúa a `11`.

Los bloques encerrados entre llaves también son expresiones, y su valor final se devuelve:

```rust
fn main() {
    let y = {
        let x = 3;
        x + 1
    };
    println!("The value of y is: {}", y);
}
```

Aquí, a `y` se le asigna el valor `4`.

## Valores devueltos

Las funciones pueden devolver valores usando la sintaxis `->` para especificar el tipo de retorno.

Por defecto, una función devuelve el valor de su expresión final:

```rust
fn five() -> u32 {
    5
}

fn main() {
    let x = five();
    println!("The value of x is: {}", x);
}
```

Esto imprime: `The value of x is: 5`.

Para casos más complejos:

```rust
fn plus_one(x: u32) -> u32 {
    x + 1
}

fn main() {
    let x = plus_one(5);
    println!("The value of x is: {}", x);
}
```

Esto imprime: `The value of x is: 6`.

Ten cuidado de no añadir un punto y coma al final de la expresión final, ya que convertiría la expresión en una instrucción, haciendo que la función devuelva `()` (tipo unitario) en lugar del valor esperado.
