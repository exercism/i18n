# Pistas

## General
- [Este tutorial][string-tutorial] es útil.
- [Documentación de referencia][string-docs] para `String`.

## 1. Sustituye los espacios por guiones bajos
- `String` proporciona una función [replace][replace].

## 2. Sustituye los caracteres de control por el string en mayúsculas «[CTRL]»
- Puedes separar strings en un array de strings con `String.split`
- Puedes [concatenar][concat] o [añadir][append] varios strings.

## 3. Convierte kebab-case a camelCase
- Los literales de `char` se encierran entre comillas simples.
- [Char.toUpper][toUpper] convierte un carácter a mayúsculas.
- Considera el uso de funciones de orden superior para recorrer todo el string.

## 4. Omite los dígitos
- `Char` proporciona funciones para detectar [dígitos][isDigit] y caracteres [alfabéticos][isAlpha].

## 5. Omite las letras griegas minúsculas
- `Char` puede transformar caracteres [a/desde sus valores decimales Unicode][toCode].
- Las [letras griegas][greek] minúsculas forman un bloque Unicode contiguo.
