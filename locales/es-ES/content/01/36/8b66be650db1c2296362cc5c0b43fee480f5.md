# Debug

Puedes usar [Debug.log](https://package.elm-lang.org/packages/elm/core/latest/Debug#log) para adjuntar mensajes a los tests que fallan, así:

```elm
hoursToSeconds : Int -> Int
hoursToSeconds hours =
    let
        secondsInOneHour =
            Debug.log "secondsInOneHour" (60 * 60)
    in
    hours * secondsInOneHour
```

En un test que falla, el registro adjunto será `secondsInOneHour: 3600`.

Hay una advertencia: las constantes de nivel superior se evalúan solo una vez antes de que los tests empiecen a ejecutarse, por lo que los tests no pueden capturar sus mensajes de registro. Por ejemplo:

```elm
secondsInOneHour : Int
secondsInOneHour =
    Debug.log "secondsInOneHour" (60 * 60)
```

no registrará nada durante los tests porque la variable de JavaScript asociada a `secondsInOneHour` ya se ha evaluado al valor 3600.
