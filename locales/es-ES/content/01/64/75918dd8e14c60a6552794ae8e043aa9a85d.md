# Introducción

## Caracteres

### Caracteres

El tipo primitivo `char` de Java es una representación de 16 bits de un único carácter.
Varios `char` pueden componer un string, como `"word"`, o los `char` se pueden procesar de forma independiente.
Un literal de tipo `char` va entre comillas simples (por ejemplo, `'A'`).

```java
char lowerA = 'a';
char upperB = 'B';
```

### Obtener los `char` de un `String`

El método `String.toCharArray` devuelve los caracteres de un string en forma de array.
Como se menciona en arrays, puedes usar un bucle `for` para iterar sobre el array.

```java
String text = "Hello";
char[] asArray = text.toCharArray();

for (char ch: asArray) {
    System.out.println(ch);
}

// Outputs:
// H
// e
// l
// l
// o
```

### La clase Character

Hay muchos métodos incluidos en la biblioteca para inspeccionar y manipular `char`.
Puedes encontrarlos como métodos estáticos de la clase `java.lang.Character`.
Aquí tienes algunos ejemplos:

```java
Character.isWhitespace(' ');    // true
Character.isWhitespace('#');    // false

Character.isLetter('a');        // true
Character.isLetter('3');        // false

Character.isDigit('6');         // true
Character.isDigit('?');         // false
```

### Añadir un `char` a un `String`

El operador `+` se puede usar para añadir un `char` a un `String`.

```java
'a' + " banana"     // => "a banana"
"banana " + 'a'     // => "banana a"
```

~~~~exercism/caution
¡Ten cuidado de _no_ usar `+` para unir dos `char` y formar un `String`!
¡Sumar dos `char` de esta forma da como resultado un `int`, _no_ un `String`!
Por ejemplo:

```java
'b' + 'c';
// => 197 (not the String "bc")
```

Esto se debe a que Java promueve el `char` a un `int` (consulta [4.2 Primitive Types and Values ][jls-primitives] de la [Java Language Specification][jls-main]).

[jls-main]: https://docs.oracle.com/javase/specs/jls/se21/html/
[jls-primitives]: https://docs.oracle.com/javase/specs/jls/se21/html/jls-4.html#jls-4.2
~~~~

Sin embargo, cuando hay muchos caracteres que añadir, puede ser más eficiente usar un `StringBuilder`:

```java
StringBuilder builder = new StringBuilder();
builder.append('a');
builder.append('b');
builder.append('c');

String builtString = builder.toString();
// => abc
```
