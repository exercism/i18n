# Instrucciones

Refactoriza un algoritmo de construcción de árboles.

Algunos foros web tienen una estructura en forma de árbol, por lo que las publicaciones se presentan como un árbol.
Sin embargo, las publicaciones suelen almacenarse en una base de datos como un conjunto de registros sin ordenar.
Por lo tanto, al presentar las publicaciones al usuario hay que reconstruir la estructura de árbol.

Tu tarea será refactorizar un fragmento de código que funciona pero es lento y feo, y que implementa la lógica de construcción de árboles para registros muy abstractos.
Los registros solo contienen un número de ID y un número de ID del padre.
El número de ID siempre está entre 0 (incluido) y la longitud del array de registros (excluida).
Todos los registros tienen un ID del padre menor que su propio ID, excepto el registro raíz, cuyo ID del padre es igual a su propio ID.

Un ejemplo de árbol:

```text
root (ID: 0, parent ID: 0)
|-- child1 (ID: 1, parent ID: 0)
|    |-- grandchild1 (ID: 2, parent ID: 1)
|    +-- grandchild2 (ID: 4, parent ID: 1)
+-- child2 (ID: 3, parent ID: 0)
|    +-- grandchild3 (ID: 6, parent ID: 3)
+-- child3 (ID: 5, parent ID: 0)
```
