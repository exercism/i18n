# Introducción

Los condicionales son instrucciones que ejecutan código distinto en función de si una condición es `true` o `false`.

Una instrucción `if` ejecuta su cuerpo solo cuando su condición es `true`.
Go no tiene el concepto de valores truthy o falsy, así que la condición debe ser de tipo `bool`.
Expresiones como `if mySlice { ... }` o `if 1 { ... }` son errores de compilación.

```go
func describe(val string) string {
    if val == "val" {
        return "was val"
    }
    return "was not val"
}
```

Usa `else if` para comprobar condiciones adicionales y `else` como alternativa si no se cumple ninguna.
Las condiciones se evalúan de arriba abajo, y solo se ejecutará la primera rama cuya condición sea verdadera.

```go
number := 0
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Una instrucción `if` también puede incluir una breve instrucción de inicialización.
Las variables declaradas de esta forma solo están dentro del scope de toda la cadena `if`/`else`.

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```
