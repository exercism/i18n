# Instrucciones

El ejercicio introductorio clásico.
Solo tienes que decir «Hello, World!».

«Hello, World!» es el tradicional primer programa cuando se empieza a programar en un lenguaje o un entorno nuevos.

Los objetivos son sencillos:

- Modifica el código que se te proporciona para que produzca el string «Hello, World!».
- Ejecuta la suite de tests y asegúrate de que pasa.
- Envía tu solución y compruébala en el sitio web.

Si todo va bien, estarás listo para obtener tu primer ejercicio real.
