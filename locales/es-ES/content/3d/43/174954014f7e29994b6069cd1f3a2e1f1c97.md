# Aprendizaje

Vim ya incluye una magnífica documentación. La interfaz para acceder a ella es el comando `:help`.

Para una introducción, consulta `:h user-manual`.

Casi todas las instalaciones de Vim incluyen también un tutorial interactivo:

```
$ vimtutor
```

Vim tiene décadas de antigüedad y sigue siendo muy popular. Encontrarás en la web muchísimos recursos sobre él, algunos mejores que otros. Los buenos están recogidos [aquí](https://exercism.org/docs/tracks/vimscript/resources).
