# Apéndice de las instrucciones

## Formato de la salida

Imprime la secuencia de proteínas como un string terminado en nulo, con un carácter de nueva línea después de cada proteína.

Un ejemplo de salida sería `"Methionine\nPhenylalanine\nSerine\n"`

Si la entrada no es válida, imprime un string vacío.
