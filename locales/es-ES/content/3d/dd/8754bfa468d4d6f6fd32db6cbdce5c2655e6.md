# Instrucciones

El cuaderno de un detective se va llenando a medida que avanza un caso, y se vacía de nuevo a medida que se descartan líneas de investigación.

Las cinco tareas van en la clase `CASE_NOTES`.

## 1. Abre un caso

Devuelve un cuaderno nuevo y vacío.

```sather
notes ::= CASE_NOTES::new_case;
notes.size
-- => 0
```

## 2. Anota una pista

Añade una pista al final del cuaderno. Esto no devuelve nada: modifica el cuaderno que recibe.

```sather
CASE_NOTES::add_clue(notes, "muddy boots");
notes.size
-- => 1
```

## 3. ¿Cuántas pistas?

```sather
CASE_NOTES::clue_count(notes)
-- => 1
```

## 4. Descarta una pista

Saca del cuaderno la pista que está en una posición. Todo lo que hay después de ella se desplaza una posición hacia delante. Esto tampoco devuelve nada.

```sather
CASE_NOTES::rule_out(notes, 0);
```

## 5. Vuelve a leer el caso

Devuelve todas las pistas del cuaderno, unidas con `"; "`. Un cuaderno vacío se lee como el string vacío.

```sather
CASE_NOTES::summary(notes)
-- => "muddy boots; broken window"
```
