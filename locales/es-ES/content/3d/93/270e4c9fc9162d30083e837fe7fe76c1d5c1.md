# Instrucciones

Eres un aficionado a la observación de aves que lleva la cuenta de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes cinco tareas, todas relacionadas con el número de pájaros que han visitado tu jardín.

## 1. Comprueba cuáles fueron los recuentos de la semana pasada

Para poder comparar, siempre tienes a mano una copia de los recuentos de la semana pasada, que fueron: 0, 2, 5, 3, 7, 8 y 4. Implementa el método `BirdCount.last_week`, que devuelve los recuentos de la semana pasada:

```ruby
BirdCount.last_week
# => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Comprueba cuántos pájaros te visitaron ayer

Implementa el método `BirdCount#yesterday` para que devuelva cuántos pájaros visitaron tu jardín ayer. Los recuentos de pájaros están ordenados por días, donde el primer elemento es el recuento del día más antiguo y el último elemento es el recuento de hoy.

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.yesterday
# => 4
```

## 3. Calcula el número total de pájaros que han visitado el jardín

Implementa el método `BirdCount#total` para que devuelva el número total de pájaros que han visitado tu jardín:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.total
# => 19
```

## 4. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.
Implementa el método `BirdCount#busy_days` para que devuelva el número de días ajetreados:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.busy_days
# => 2
```

## 5. Comprueba si hubo algún día sin pájaros visitantes

Implementa el método `BirdCount#day_without_birds?`, que devuelve `true` si hubo algún día en el que ningún pájaro visitó el jardín; en caso contrario, devuelve `false`:

```ruby
birds_per_day = [2, 5, 0, 7, 4, 1]
bird_count = BirdCount.new(birds_per_day)
bird_count.day_without_birds?
# => true
```
