# Pistas

## 1. Escala las coordenadas

- El `point` es un vector; el escalado se hace con un vector `s` (ya sea explícitamente un vector o por reciclaje). - Ya conoces la multiplicación elemento a elemento de vectores.

## 2. Traslada las coordenadas

- Convierte los argumentos pasados con los puntos suspensivos en un vector.
- La función habitual [`c()`][ref-c] es lo bastante flexible para encargarse de esto.
- Desempaquetar los elementos de un vector en variables individuales normalmente _no_ es una buena forma de usar R: piensa en términos de operaciones con vectores.

## 3. Transforma un punto 2D

- Recuerda: primero traslada y _después_ escala.
- El argumento `s` de `transform2d()` es opcional, así que recuerda definir un valor predeterminado.
- `transform2d()` debe devolver una función que tome un `point` como único argumento.
- Si sigues con dudas, lee la introducción sobre entornos y funciones como valores devueltos, y mira los ejemplos de las instrucciones.
- Este es el tipo de tema que puede resultar confuso al principio, pero que se vuelve muy natural con un poco de práctica.

## 4. Transforma un punto 3D

- No es más que una extensión de la tarea 3.
- Se apoya en que las tareas 1 y 2 estén implementadas de forma sencilla y flexible.
