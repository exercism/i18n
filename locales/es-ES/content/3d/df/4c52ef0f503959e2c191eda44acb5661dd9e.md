# Consejos

## 1. Define la aprobación

- [Esta página][define] muestra cómo definir una unión discriminada.

## 4. Define la actividad

- [Esta página][define] muestra cómo definir una unión discriminada, tanto para casos con datos asociados como sin ellos.

## 5. Valora la actividad

- La mejor manera de ejecutar lógica en función del valor de la actividad es usar la [coincidencia de patrones][pattern-matching].
- Para hacer coincidir los casos de una unión discriminada (y, opcionalmente, sus datos asociados) se usan los [patrones de identificador][identifier-patterns].
- Si quieres añadir una condición adicional a un patrón, puedes añadir una [guarda][guards].
- Si quieres capturar más de un valor a la vez, puedes usar un [patrón comodín][wildcard-patterns].
