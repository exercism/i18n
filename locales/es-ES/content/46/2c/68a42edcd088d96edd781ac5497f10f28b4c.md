# Instrucciones

En este ejercicio, vas a ayudar a unos novios de instituto a declarar su amor en las redes sociales generando un corazón ASCII con sus iniciales:

```
     ******       ******
   **      **   **      **
 **         ** **         **
**            *            **
**                         **
**     J. K.  +  M. B.     **
 **                       **
   **                   **
     **               **
       **           **
         **       **
           **   **
             ***
              *
```

## 1. Obtén la primera letra del nombre

Implementa la función `first_letter`. Debe recibir un nombre y devolver su primera letra. También debe eliminar los espacios en blanco innecesarios del nombre.

```gleam
first_letter("Jane")
// -> "J"
```

## 2. Formatea la primera letra como una inicial

Implementa la función `initial`. Debe recibir un nombre y devolver su primera letra en mayúscula, seguida de un punto. Asegúrate de reutilizar `first_letter`, que definiste en el paso anterior.

```gleam
initial("Robert")
// -> "R."
```

## 3. Separa el nombre completo en el nombre y el apellido

Implementa la función `initials`. Debe recibir un nombre completo, formado por un nombre y un apellido separados por un espacio, y devolver las iniciales. Asegúrate de reutilizar `initial`, que definiste en el paso anterior.

```gleam
initials("Lance Green")
// -> "L. G."
```

## 4. Coloca las iniciales dentro del corazón

Implementa la función `pair`. Debe recibir dos nombres completos y devolver las iniciales dentro de un corazón ASCII. Asegúrate de reutilizar `initials`, que definiste en el paso anterior.

```gleam
pair("Blake Miller", "Riley Lewis")
// -> "
//      ******       ******
//    **      **   **      **
//  **         ** **         **
// **            *            **
// **                         **
// **     B. M.  +  R. L.     **
//  **                       **
//    **                   **
//      **               **
//        **           **
//          **       **
//            **   **
//              ***
//               *
// "
```
