# Acerca de

Las funciones **definidas por el usuario** se crean con la palabra clave `function`. Después, esta debe ir seguida de un nombre de función y una lista de argumentos.

```php
function alarm($hour, $minute, $second)
{
    return 'Alarm!';
}
```

Las funciones se pueden llamar en un fichero antes de definirlas, ya que se elevan al principio de su scope.

## Nomenclatura

Los nombres de las funciones en PHP siguen las reglas de otras etiquetas: deben empezar con un guion bajo o una letra y, después, pueden ir seguidos de cualquier número de letras, números o guiones bajos.
