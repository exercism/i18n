# Contador de líneas de código

El contador de líneas de código (LoC) toma una solución y cuenta sus líneas de código.

De forma predeterminada, solo se cuentan las LoC de los ficheros enviados por el estudiante.
Si el estudiante ha enviado un fichero de pruebas, este se ignorará.

Aunque esto funciona bien para la mayoría de los envíos, puede que algunos tracks necesiten ignorar ficheros adicionales.
Para ello, permitimos que el contador de líneas de código se pueda [personalizar para cada track][lines-of-code-counter-customize].

## Implementación

Usamos la biblioteca [tokei][tokei] para hacer el recuento real.
Como los pull requests a menudo no se fusionan con rapidez, hemos creado nuestro propio [fork][tokei-fork].
Esto nos permite iterar más rápido y añadir compatibilidad con cualquier lenguaje que queramos.

## Lenguajes compatibles

Puedes comprobar si tu lenguaje es compatible de serie buscándolo en el fichero [languages.json][languages.json].

### Añadir un nuevo lenguaje

Si tu lenguaje **no** es compatible, puedes añadir compatibilidad de la siguiente manera:

1. Añade una entrada para tu lenguaje en el fichero [languages.json].
   Consulta la [documentación sobre cómo añadir un lenguaje][adding-language] para obtener más información.
2. Añade pruebas para verificar que el recuento funciona correctamente para tu lenguaje.
   Consulta la [documentación sobre cómo añadir pruebas][adding-tests] para obtener más información.

Una vez hechos estos cambios, abre un pull request en el [repositorio exercism/tokei][tokei-fork].
Aquí tienes un [pull request de ejemplo][example-pr] que añade compatibilidad con el lenguaje Arturo.
