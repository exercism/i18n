# Acerca de

Common Lisp es una rama de la veterana familia de lenguajes de programación Lisp.
Es un lenguaje de programación multiparadigma que te permite elegir el enfoque y el paradigma según el dominio de tu aplicación.

Common Lisp tiene capacidad de prototipado rápido y un soporte excepcional para la programación orientada a objetos.
También presume de un sistema de macros que te permite adaptar el lenguaje a tus necesidades, y de un entorno de ejecución que permite modificar aplicaciones en ejecución.

Para saber más sobre Common Lisp, echa un vistazo a [la página principal de Common Lisp][common-lisp-net]

[common-lisp-net]: https://common-lisp.net/
