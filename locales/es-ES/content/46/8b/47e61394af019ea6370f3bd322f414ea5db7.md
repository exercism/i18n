# Pistas

## 1. Empezar desde cero

- Para crear un array puedes usar `make-array`.
- Las dimensiones de un array se especifican como una lista que se pasa a `make-array`.
- Para asignar a todos los elementos un valor inicial, usa el parámetro de palabra clave `:inital-element`.

## 2. Partir de un tablero existente

- Para establecer el contenido inicial de un array, usa el parámetro de palabra clave `:initial-contents`.

## 3. Condición de victoria

- Puedes usar `aref` para obtener el valor de una celda de un array.
- Puedes usar `eq` para determinar si dos símbolos son el mismo.
- Puedes usar `and` para combinar dos expresiones `eq` y comparar tres elementos.

## 4. En una fila

- Los argumentos de `aref` (para un array bidimensional) son «fila» y «columna».

## 5. En una columna

- Los argumentos de `aref` (para un array bidimensional) son «fila» y «columna».
