# Consejos

## 1. Define el tiempo de horneado esperado en minutos

- Tienes que definir una [constante][constants] que contenga el [número entero][integers] especificado en la receta.
- La constante debe definirse en la [clase][classes] `Lasagna`.
- Debe definirse fuera de un método.

## 2. Calcula el tiempo de horneado restante en minutos

- Tienes que definir un [método][methods] con un solo parámetro para el tiempo real transcurrido hasta el momento.
- Puedes usar el operador matemático (`-`) para restar valores.
- Es posible usar la [constante][constants] que definiste anteriormente.

## 3. Calcula el tiempo de preparación en minutos

- Tienes que definir un [método][methods] con un solo parámetro para el número de capas.
- Puedes usar el operador matemático (`*`) para multiplicar valores.

## 4. Calcula el tiempo de trabajo total en minutos

- Tienes que definir un [método][methods] con dos parámetros con nombre.
- Puedes llamar a uno de los otros métodos que definiste anteriormente.
- Puedes usar el operador matemático (`+`) para sumar valores.
