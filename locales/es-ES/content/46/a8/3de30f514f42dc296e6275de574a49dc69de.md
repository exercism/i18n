# Módulos y rutas en Cairo

Cairo usa **módulos** para organizar el código.

Los módulos ayudan a estructurar proyectos y controlar la visibilidad de elementos como funciones, estructuras y rasgos.

## Definir módulos

Los módulos se definen con `mod` y se pueden anidar:

```rust
mod front_of_house {
    pub mod hosting {
        pub fn add_to_waitlist() {}
    }
}
```

Las funciones, las estructuras y los rasgos son **privados por defecto**.

Usa `pub` para hacerlos accesibles desde fuera de su módulo.

## Rutas: absolutas frente a relativas

Para referirte a un elemento en otro módulo, puedes usar:

- **Rutas absolutas** (que comienzan desde `crate::`):

  ```rust
  crate::front_of_house::hosting::add_to_waitlist();
  ```

- **Rutas relativas** (que comienzan desde el módulo actual):

  ```rust
  front_of_house::hosting::add_to_waitlist();
  ```

  Esto funciona si `front_of_house` está en el mismo módulo.

## Traer módulos al scope con `use`

Escribir rutas completas repetidamente es incómodo.

La palabra clave `use` permite referencias más cortas:

```rust
use crate::front_of_house::hosting;

pub fn eat_at_restaurant() {
    hosting::add_to_waitlist(); // Shorter path
}
```

`use` se aplica **solo en el scope donde aparece**; si se necesita en otro lugar, debe repetirse.

### Uso idiomático de `use`

- Trae **módulos** al scope, no funciones:

  ```rust
  use crate::front_of_house::hosting; // ✅
  hosting::add_to_waitlist();
  ```

  En lugar de:

  ```rust
  use crate::front_of_house::hosting::add_to_waitlist; // ❌
  add_to_waitlist();
  ```

- Para **rasgos, estructuras y enumeraciones**, usa la ruta completa:

  ```rust
  use core::num::traits::BitSize;
  ```

### Alias con `as`

Renombra las importaciones cuando sea necesario:

```rust
use core::array::ArrayTrait as Arr;

fn main() {
    let mut arr = Arr::new();
    arr.append(1);
}
```

### Importar varios elementos

En lugar de varias instrucciones `use`, agrupa las importaciones:

```rust
use shapes::{Square, Circle, Triangle};
```

## Reexportar con `pub use`

Para exponer un módulo en una estructura diferente, usa `pub use`:

```rust
pub use crate::front_of_house::hosting;
```

Ahora el código externo puede usar `restaurant::hosting::add_to_waitlist()` en lugar de `restaurant::front_of_house::hosting::add_to_waitlist()`.

## Usar paquetes externos con Scarb

Para añadir una dependencia, actualiza `Scarb.toml`:

```toml
[dependencies]
alexandria_math = { git = "https://github.com/keep-starknet-strange/alexandria.git" }
```

Usa `scarb add <package>` para añadir dependencias y `scarb rm <package>` para eliminarlas.

## El operador glob (`*`)

Para importar todo desde un módulo:

```rust
use core::num::traits::*;
```

Esto debe usarse con cuidado, ya que puede hacer que el código sea más difícil de leer.
