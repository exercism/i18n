# Instrucciones

El mosaico del centro de arte comunitario terminó de instalarse el mes pasado, y ahora Magpie Marg lo ha descubierto. Casi todos los días cambia una tesela o dos por otras más brillantes de su **tesoro** cercano, o arranca una tesela y desaparece durante una hora.

Eres la persona voluntaria que registra cada cambio. El propio mosaico es un **array de tamaño fijo**: un hueco por cada posición de tesela, que contiene un string de color o `f` para «falta». El tesoro de Magpie Marg es un **vector** de teselas sueltas que ha robado.

## 1. Disponer una fila nueva

Define `fresh-mosaic` para que reciba una longitud `n` y devuelva un array de `n` huecos vacíos (cada uno `f`).

```factor
4 fresh-mosaic .
! => { f f f f }
```

## 2. Colocar una tesela

Define `place-tile` para que reciba una fila, una posición y un color, y actualice la fila in situ de modo que la posición indicada contenga ese color. La palabra no devuelve nada.

```factor
5 fresh-mosaic   ! { f f f f f }
dup 2 "ruby" place-tile
.
! => { f f "ruby" f f }
```

## 3. Arrancar una tesela

Define `chip-tile` para que reciba una fila y una posición, y actualice la fila in situ de modo que la posición indicada vuelva a ser `f`.

```factor
{ "ruby" "lapis" "jade" } 1 chip-tile .
! => { "ruby" f "jade" }
```

## 4. Volver a colorear una tesela

Define `recolour-tile` para que reciba una fila, una posición y una quotation de un argumento, y actualice la fila in situ aplicando la quotation a la tesela de esa posición.

```factor
{ "RUBY" "LAPIS" "JADE" } 1 [ >lower ] recolour-tile .
! => { "RUBY" "lapis" "JADE" }
```

## 5. Capturar una instantánea antes de que llegue Marg

Define `snapshot-mosaic` para que reciba una fila y devuelva una copia independiente que no se verá afectada por mutaciones posteriores de la original.

```factor
{ "ruby" "lapis" "jade" } dup snapshot-mosaic    ! two equal but independent copies
swap 0 "amber" place-tile                        ! mutate the first
.s
! => { "ruby" "lapis" "jade" }                   (the snapshot)
! => { "amber" "lapis" "jade" }                  (the mutated original)
```

## 6. Marg se guarda una tesela

Define `stash-tile` para que reciba el tesoro de Marg (un vector) y un color, y añada el color al tesoro. No devuelve nada.

```factor
V{ } clone   ! a fresh empty hoard
dup "ruby"  stash-tile
dup "lapis" stash-tile
.
! => V{ "ruby" "lapis" }
```

## 7. Marg devuelve una tesela

Define `return-tile` para que reciba el tesoro de Marg y elimine y devuelva la tesela guardada más recientemente (la que está arriba).

```factor
V{ "ruby" "lapis" "jade" } clone
dup return-tile .
! => "jade"
.
! => V{ "ruby" "lapis" }
```
