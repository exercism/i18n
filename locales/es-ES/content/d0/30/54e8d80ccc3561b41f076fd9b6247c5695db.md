# Tiene método main

Prueba a eliminar el método `Main` del código, ya que las pruebas no lo necesitan y hacen que el código sea un poco más difícil de leer.

Normalmente, el método `Main` se añade para ayudar a depurar el código. Sin embargo, un mejor enfoque es depurar el código mientras se ejecutan una o más pruebas unitarias. Esto tiene la ventaja añadida de que puedes centrarte en depurar un caso de prueba concreto. Aquí tienes algunos enlaces que explican cómo depurar código C# mientras se ejecutan pruebas unitarias en varios IDE:

- [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer?view=vs-2019)
- [VS Code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests)
- [Rider](https://www.jetbrains.com/help/rider/Unit_Testing__Index.html)
