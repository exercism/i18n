# Instrucciones

En este ejercicio vas a escribir código para ayudar a un profesional autónomo a comunicarse con un jefe de proyecto, proporcionando unas cuantas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Para empezar, establecemos unas cuantas reglas entre el autónomo y el jefe de proyecto:

La tarifa diaria es 8 veces la tarifa por hora.
Un mes tiene 22 días facturables.
El autónomo ofrece aplicar un descuento si el jefe de proyecto decide dejar que el autónomo facture por mes, lo cual puede venir bien si hay un presupuesto concreto con el que el jefe de proyecto tiene que trabajar.

Los descuentos se modelan como números fraccionarios que representan un porcentaje, por ejemplo 25,0 (25 %).

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función que calcule la tarifa diaria a partir de una tarifa por hora:

```gleam
freelancer_rates.daily_rate(60)
# => 480.0
```

La tarifa diaria devuelta debe ser un número decimal.

## 2. Calcula un precio con descuento

Implementa una función que calcule el precio después de aplicar un descuento.

```gleam
freelancer_rates.apply_discount(150, 10)
# => 135.0
```

El valor devuelto debe ser siempre un número decimal, sin redondear de ninguna manera.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función que calcule la tarifa mensual y aplique un descuento:

```gleam
freelancer_rates.monthly_rate(77, 10.5)
# => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al número entero más cercano.

## 4. Calcula el número de días de trabajo a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función que tome un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días de trabajo cubre eso.

```gleam
freelancer_rates.days_in_budget(20000, 80, 11.0)
# => 35
```

El número de días devuelto debe redondearse hacia abajo (tomar el suelo) a un decimal.
