# Tests

Para ejecutar los tests, ejecuta el siguiente comando:

```bash
make
```

## Tests omitidos

Resolver un ejercicio significa conseguir que todos sus tests pasen.
De forma predeterminada, cuando ejecutas los tests solo se ejecuta uno (el primero).
Esto es intencionado, ya que te permite centrarte únicamente en conseguir que ese test pase.
Cuando pase, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE()`.
Cuando hayas habilitado todos los tests y tu implementación consiga que todos pasen, ¡habrás resuelto el ejercicio!
