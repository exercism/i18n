# Instrucciones específicas de SQLite

Este ejercicio requiere que establezcas la columna `result` de la tabla `etl` al valor correcto a partir del objeto JSON que se encuentra en la columna `input`. Las claves del objeto de resultado deben estar ordenadas alfabéticamente.

## Esquema de la tabla

```sql
CREATE TABLE "etl" ("input" TEXT, "result" TEXT);
```
