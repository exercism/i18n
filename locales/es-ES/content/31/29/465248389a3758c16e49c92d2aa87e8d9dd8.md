# Evita las instrucciones de impresión

Intenta eliminar instrucciones como `System.out.println()` de tu código.
Los tests del ejercicio requieren que la solución _devuelva_ valores desde los métodos en lugar de imprimirlos.

Normalmente, este tipo de instrucciones se añaden para ayudar a depurar el código.
Sin embargo, un mejor enfoque es depurar el código mientras se ejecutan uno o más tests unitarios.
Esto tiene la ventaja añadida de que puedes centrarte en depurar un caso de test concreto.

Aquí tienes algunos enlaces que explican cómo depurar código Java mientras se ejecutan tests unitarios en varios IDE:

- [Ejecutar y depurar tests de Java en Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Depurar tests en IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
