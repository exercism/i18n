# Instrucciones

Elaine está trabajando en un nuevo juego para niños que incluye animales y varitas mágicas.
Es hora de programar funciones para tirar un dado, generar energía de la varita aleatoria y mezclar un slice.

## 1. Tirar un dado

Implementa una función `RollADie`.

Será el típico dado de veinte caras con números del 1 al 20.

```go
d := RollADie() // d will be assigned a random int, 1 <= d <= 20
```

## 2. Generar energía de la varita

Implementa una función `GenerateWandEnergy`.
La energía de la varita debe ser un número de coma flotante aleatorio mayor o igual que 0.0 y menor que 12.0.

```go
f := GenerateWandEnergy()  // f will be assigned a random float64, 0.0 <= f < 12.0
```

## 3. Mezclar un slice

El juego incluye ocho animales diferentes:

- ant
- beaver
- cat
- dog
- elephant
- fox
- giraffe
- hedgehog

Escribe una función `ShuffleAnimals` que devuelva un slice con los ocho animales en orden aleatorio.
