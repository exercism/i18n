# Introducción

## Filtrado de excepciones

`when` es la palabra clave para filtrar excepciones. Se coloca después de la sentencia catch y puede tomar una expresión Boolean que contenga cualquier valor que haya en el scope en ese momento. Si la expresión se evalúa como verdadera, se ejecuta el bloque asociado a esa sentencia `catch`; en caso contrario, se comprueba la siguiente sentencia `catch`, si la hay.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```

## Excepciones definidas por el usuario

Una excepción definida por el usuario es cualquier clase definida en tu código que derive de `System.Exception`. Está sujeta a todas las reglas de la herencia de clases, pero además el compilador y el entorno de ejecución del lenguaje tratan esas clases de forma especial, lo que permite lanzar y capturar sus instancias fuera del flujo de control normal, como se explica en el ejercicio `exceptions`.

Las excepciones definidas por el usuario se usan a menudo para llevar información adicional, como un mensaje y otros datos relevantes, que esté disponible para las rutinas que capturan la excepción.
