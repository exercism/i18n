# Instalación

## Instala Node.js

**Usuarios de Windows y OS X**: instala [Node.js][node] [a través del gestor de paquetes][node-download].

**Usuarios de Linux**: instala [Node.js][node] siguiendo las instrucciones que encuentres para tu distribución en el [gestor de paquetes de Node.js][linstall].

## Instala `jasmine-node` y `coffeescript`

Para la mayoría de los usuarios, bastará con ejecutar el siguiente comando:

```bash
$ npm install -g jasmine-node coffeescript
```

Según cuál sea tu configuración, es posible que necesites privilegios de superusuario para instalar un módulo de `npm` de forma global.
Este es el caso si has usado el instalador oficial enlazado más arriba.
Si NPM te da un error diciendo que no tienes acceso, añade `sudo` al comando anterior:

```bash
$ sudo npm install -g jasmine-node coffeescript
```

Si has usado el instalador oficial, tu `PATH` debería haberse configurado automáticamente, pero puede que tu shell tenga problemas para localizar los módulos que has instalado de forma global, o que hayas compilado Node.js desde el código fuente.
En ese caso, actualiza tu `PATH` para incluir los binarios de `npm` añadiendo lo siguiente a `~/.bash_profile` o a `~/.zshrc`:

```bash
$ export PATH=/usr/local/share/npm/bin:$PATH
```
