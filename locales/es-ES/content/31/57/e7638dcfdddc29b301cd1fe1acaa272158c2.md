# Pistas

## General

- Lee sobre [la recursión de la mano del creador de Elm][recursion].
- Usa la coincidencia de patrones con expresiones `case`.
- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el tarro de galletas con un enfoque recursivo. Un caso base es un tarro vacío: tiene cero galletas. Si el tarro no está vacío, el número de galletas que hay en él es igual a una galleta más el número de galletas que quedan en el tarro después de quitar una.

## 1. Comprueba cuántos pájaros han visitado hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de un array mediante la coincidencia de patrones con una expresión `case`.
- Recuerda envolver el resultado en `Just` cuando devuelvas un valor.

## 2. Incrementa el recuento de hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de un array mediante la coincidencia de patrones con una expresión `case`.
- Usa el [operador `::`][list-cons] para deconstruir y reconstruir el nuevo array.

## 3. Comprueba si hubo un día sin pájaros visitantes

- Usa la recursión para iterar sobre los elementos del array hasta encontrar un día sin pájaros visitantes.
- Los casos base son un array vacío o un día sin pájaros.
- Usa la coincidencia de patrones para comprobar si hay un `0` en el array.

## 4. Calcula el número total de pájaros visitantes

- Usa la recursión para iterar sobre cada elemento del array.
- El caso base es un array vacío.
- Usa el operador `+` para sumar el elemento actual al total del resto.

## 5. Calcula el número de días ajetreados

- Usa la recursión para iterar sobre cada elemento del array.
- El caso base es un array vacío.
- Usa una expresión `if` para comprobar si el día actual es ajetreado (5 pájaros o más).
- Suma 1 al recuento de días ajetreados del resto del array cuando encuentres un día ajetreado.
