# Introducción

En Go, una aplicación se organiza en paquetes.
Un paquete es una colección de ficheros fuente que se encuentran en la misma carpeta.
Todos los ficheros fuente de una carpeta deben tener el mismo nombre de paquete al principio del fichero.
Por convención, los paquetes se nombran igual que la carpeta en la que se encuentran.

```go
package greeting
```

Go proporciona una extensa biblioteca estándar de paquetes que puedes usar en tu programa con la palabra clave `import`.
Los paquetes de la biblioteca estándar se importan usando su nombre.

```go
package greeting

import "fmt"
```

A continuación, se hace referencia a un paquete importado con el nombre del paquete:

```go
world := "World"
fmt.Sprintf("Hello %s", world)
```

Go determina si el código de otros paquetes puede llamar a un elemento según cómo se declare.
Para que una función, un tipo, una variable, una constante o un campo de estructura sea visible desde fuera (lo que se conoce como _exportado_), el nombre debe empezar por una letra mayúscula.
Esto es análogo a cómo otros lenguajes de programación, como Java, usan modificadores de acceso como `public` y `private`.

```go
package greeting

// Hello is a public function (callable from other packages).
func Hello(name string) string {
    return "Hello " + name
}

// hello is a private function (not callable from other packages).
func hello(name string) string {
    return "Hello " + name
}
```
