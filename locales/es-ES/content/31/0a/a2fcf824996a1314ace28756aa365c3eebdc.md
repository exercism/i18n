# Cambiar un punto de código a string directamente

La forma más sencilla de convertir el punto de código de un carácter en un string con ese carácter es usar la forma especial `<<>>`. No hace falta usar una charlist como paso intermedio.

```elixir
# instead of:
to_string([?A])
# => "A"

# use:
<<?A>>
# => "A"
```
