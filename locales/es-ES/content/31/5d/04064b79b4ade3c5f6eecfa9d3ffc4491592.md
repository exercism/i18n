# usa un marcador de posición de fmt para el string

En Go, se suele preferir marcadores de posición específicos de tipo en lugar del genérico `%%v`. 
Esto se debe a dos razones. En primer lugar, los marcadores de posición más específicos suelen tener 
opciones adicionales; por ejemplo, el formato `%%f` para valores `float` también puede especificar la precisión: `%%.2f`. 
La segunda razón es que `%%v` acepta cualquier tipo de valor. Si el tipo de una variable cambia durante una refactorización, 
`%%v` imprimirá el valor predeterminado de ese tipo, que puede que no sea el comportamiento deseado. 
Un marcador de posición específico de tipo hará que el linter se queje, lo que permite detectar el error antes de que llegue a producción.
