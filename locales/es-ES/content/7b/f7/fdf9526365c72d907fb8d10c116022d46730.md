# Anexo a las instrucciones

## Pistas

Tienes que implementar la función `recite`, que genera la letra de «The Twelve Days of Christmas». Puedes usar la firma proporcionada si no estás seguro de los tipos, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos textuales. Por motivos históricos, el tipo `String` de Haskell es sinónimo de `[Char]`, un array de caracteres. Para tratar los datos textuales de forma más eficiente, se puede usar el tipo `Text`.

Como ampliación opcional de este ejercicio, puedes

- leer sobre los [tipos de string](https://haskell-lang.org/tutorial/string-types) en Haskell.
- añadir `- text` a tu lista de dependencias en package.yaml.
- importar `Data.Text` [de la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- escribir, por ejemplo, `recite :: Int -> Int -> [Text]` y referirte a los combinadores de `Data.Text` como, por ejemplo, `T.pack`.
- consultar la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- sustituir todas las apariciones de `String` por `Text` en TwelveDays.hs, es decir:

```haskell
recite :: Int -> Int -> [Text]
```

Esta parte es totalmente opcional.
