# Instrucciones

Dada una cuadrícula de 3 x 4 de barras verticales, guiones bajos y espacios, determina qué número se representa o si está ilegible.

## Paso uno

Para empezar, convierte una fuente binaria sencilla en un string que contenga 0 o 1.

La fuente binaria usa barras verticales y guiones bajos, con cuatro filas de alto y tres columnas de ancho.

```text
     _   #
    | |  # zero.
    |_|  #
         # the fourth row is always blank
```

Se convierte en «0»

```text
         #
      |  # one.
      |  #
         # (blank fourth row)
```

Se convierte en «1»

Si la entrada tiene el tamaño correcto, pero no es reconocible, tu programa debe devolver «?».

Si la entrada tiene un tamaño incorrecto, tu programa debe devolver un error.

## Paso dos

Actualiza tu programa para que reconozca strings binarios de varios caracteres, sustituyendo los números ilegibles por ?

## Paso tres

Actualiza tu programa para que reconozca todos los números del 0 al 9, tanto individualmente como formando parte de un string más grande.

```text
 _
 _|
|_

```

Se convierte en «2»

```text
      _  _     _  _  _  _  _  _  #
    | _| _||_||_ |_   ||_||_|| | # decimal numbers.
    ||_  _|  | _||_|  ||_| _||_| #
                                 # fourth line is always blank
```

Se convierte en «1234567890»

## Paso cuatro

Actualiza tu programa para que maneje varios números, uno por línea.
Al convertir varias líneas, une las líneas con comas.

```text
    _  _
  | _| _|
  ||_  _|

    _  _
|_||_ |_
  | _||_|

 _  _  _
  ||_||_|
  ||_| _|

```

Se convierte en «123,456,789».
