# Anexo a las instrucciones

## Nota

El truco de este ejercicio está en entender cómo iterar sobre un rango de números y también en comprobar si una Collection contiene múltiplos divisibles por un número.
Prueba a usar el Spotter para buscar posibles clases y explorar las categorías de métodos de esas clases. 

Recuerda también que el entorno de Pharo está muy interconectado mediante referencias cruzadas.
Puedes hacer clic con el botón derecho en cualquier clase o método y explorar las «references» de una clase (para ver cómo podría crearse), así como los «senders» de un método (para ver cómo podría usarse).
