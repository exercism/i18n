# Acerca de

Un bucle `do-while` es una alternativa a un bucle `while`, con la única diferencia de que un `do-while` se ejecuta al menos una vez:

```haxe
var i = 0;

do {
  trace("Hello");
} while (i < 10);
```

Los casos en los que conviene usar un bucle `do-while` son muy raros, así que en su lugar se usa el `while` normal.
