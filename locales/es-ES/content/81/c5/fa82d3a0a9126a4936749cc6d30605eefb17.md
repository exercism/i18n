# Instrucciones

En la ciudad ha abierto un nuevo club de poesía y estás pensando en apuntarte.
Como en el pasado ha habido incidentes, el club tiene una política de acceso muy concreta que tendrás que dominar antes de intentar entrar.

En el club de poesía hay dos puertas, una principal y otra trasera, y ambas están vigiladas.
Para entrar, tendrás que averiguar la contraseña del día.

La contraseña siempre se basa en un poema y se puede obtener mediante un proceso de dos pasos.

1. El guardia recitará el poema, línea a línea, y tú tendrás que responder con la letra correspondiente de esa línea.
2. Después, el guardia te dirá de una vez todas las letras con las que has respondido, y tú tendrás que escribirlas en un papel con un formato concreto.

Los detalles del proceso dependen de la puerta por la que intentes entrar.

~~~~exercism/note
Todos los strings de este ejercicio estarán codificados en ASCII y terminados en NUL.
Esto significa que todos los caracteres usan codificación ASCII y que cada string termina cuando se encuentra el '\0' (el carácter NUL, con valor `0`).
~~~~

~~~~exercism/note
Estas son las instrucciones de string mencionadas en este concepto:

| instrucción  | qué hace                                                                                                          |
|--------------|-------------------------------------------------------------------------------------------------------------------|
| `lods`       | carga en `rax` un valor desde una ubicación de memoria indicada por `rsi`                                         |
| `stos`       | almacena en una ubicación de memoria indicada por `rdi` un valor procedente de `rax`                              |
| `movs`       | copia un valor desde una ubicación de memoria indicada por `rsi` y lo almacena en una ubicación de memoria indicada por `rdi` |

Todas ellas deben llevar un sufijo que indique el tamaño de la operación:

| sufijo | tamaño           |
|--------|------------------|
| `b`    | byte             |
| `w`    | word (2 bytes)   |
| `d`    | dword (4 bytes)  |
| `q`    | qword (8 bytes)  |

Todas las instrucciones de string también modifican las direcciones de `rsi` y/o `rdi` (solo en aquellos registros que use la instrucción).
Por defecto, incrementan las direcciones en el tamaño de la operación.

El prefijo `rep` se puede añadir a cualquiera de las instrucciones de string anteriores para repetirla un número de veces igual a `rcx`.
~~~~

## 1. Obtén la primera letra de una frase

Para determinar las letras de la contraseña de la puerta principal, debes responder con la primera letra de la línea del poema que te recite el guardia.

Para conseguir una contraseña bonita, a los miembros del club de poesía les gusta usar poemas _acrósticos_.
Esto significa que la primera letra de cada frase forma una palabra.
Aquí tienes un ejemplo de uno de sus escritores favoritos, Michael Lockwood.

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Así, cuando el guardia recite **Stands so high**, responderás **S**, y cuando recite **Huge hooves too**, responderás **H**.

Implementa la función `front_door_response`, que toma como argumento la dirección en memoria de una línea del poema y devuelve la primera letra de esa línea.
Esa letra debe devolverse como un carácter codificado en ASCII, que ocupe 1 byte.

```c
front_door_response("Stands so high");
// => 'S'
```

## 2. Escribe una palabra con mayúscula inicial

Ahora que ya tienes todas las letras correctas, lo único que tienes que hacer para obtener la contraseña de la puerta principal es escribir la palabra con la mayúscula inicial correcta.

Implementa la función `front_door_password`, que toma como argumento la dirección en memoria de un string que contiene únicamente las letras combinadas que encontraste en la tarea 1.
Debe modificar el string de entrada [in situ][in-place], para que quede con la mayúscula inicial correcta.
Esto significa que el string correcto debe almacenarse en la misma ubicación de memoria que la entrada.

La función no tiene valor devuelto.

```c
front_door_password('SHIRE');
// => buffer == "Shire"

front_door_password('shire');
// => buffer == "Shire"
```

## 3. Obtén la última letra de una frase

Para determinar las letras de la contraseña de la puerta trasera, debes responder con la última letra de la línea del poema que te recite el guardia.

Los miembros del club de poesía son muy ingeniosos.
El poema mencionado antes también es un _telestiquio_, lo que significa que la última letra de cada frase también forma una palabra:

```text
Stands so high
Huge hooves too
Impatiently waits for
Reins and harness
Eager to leave
```

Cuando el guardia recite **Stands so high**, responderás **h**, y cuando recite **Huge hooves too**, responderás **o**.

Ten en cuenta que a veces el guardia hace pausas estilísticas (en forma de puntuación o de espacios en blanco) al recitar el poema.
Tendrás que ignorar esas pausas para obtener la letra correcta.

Implementa la función `back_door_response`, que toma como argumento la dirección en memoria de una línea del poema y devuelve la última letra de esa línea.
Esa letra debe devolverse como un carácter codificado en ASCII, que ocupe 1 byte.

```c
back_door_response('Stands so high');
// => "h"

back_door_response('Stands ... so high   ');
// => "h"
```

## 4. Sé cortés

Para entrar en el club de poesía por la puerta trasera tienes que ser especialmente cortés.
Así que, para obtener la contraseña, esta vez tendrás que escribir la palabra con la mayúscula inicial correcta y añadir `", please."` al final.

Implementa la función `back_door_password`, que acepta como argumentos, en este orden:

1. La dirección en memoria de un buffer donde se almacenará el string resultante.
2. La dirección en memoria de un string que contiene las letras combinadas que encontraste en la tarea 3.

La función debe almacenar en el [buffer][buffer] la versión cortés de la contraseña con mayúscula inicial.
Un _buffer_ es un array que se puede usar para almacenar valores en memoria y así moverlos entre distintas funciones.

Esta función no tiene valor devuelto.

```c
back_door_password("horse");
// => "Horse, please."
```
