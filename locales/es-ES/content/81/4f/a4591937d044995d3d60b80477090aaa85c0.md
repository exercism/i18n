# Introducción

## Números enteros

En Elixir hay dos tipos de números diferentes: los enteros y los números de coma flotante.

Los números enteros son números sin parte decimal.

```elixir
integer = 3
# => 3
```

## Números de coma flotante

Los números de coma flotante son números con uno o más dígitos después del separador decimal. Utilizan el formato de coma flotante de doble precisión de 64 bits.

```elixir
float = 3.45
# => 3.45
```

### Trabajar con números

En los módulos [`Integer`][integer-functions] y [`Float`][float-functions] puedes encontrar algunas funciones útiles para trabajar con estos tipos. Los operadores aritméticos básicos están definidos en el módulo [`Kernel`][kernel-arithmetic-operators].

### Conversión

Los números enteros y los de coma flotante se pueden mezclar en una misma expresión aritmética. Si usas un número de coma flotante en una expresión, el resultado también será un número de coma flotante.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Sin embargo, al hacer una división, el resultado siempre será un número de coma flotante, incluso si solo se usan números enteros.

```elixir
6 / 2
# => 3.0
```

Para convertir un número de coma flotante en uno entero, puedes descartar la parte decimal con [`trunc/1`][trunc-1].
