# Anexo a las instrucciones

## Registros

| Registro | Uso          | Tipo    | Descripción             |
| -------- | ------------ | ------- | ----------------------- |
| `$a0`    | entrada      | número entero | número de filas del triángulo |
| `$a1`    | entrada/salida | dirección | array de palabras       |
| `$v0`    | salida       | número entero | número de palabras de salida |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal |
