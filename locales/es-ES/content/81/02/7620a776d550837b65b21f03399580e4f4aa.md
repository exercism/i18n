# Instrucciones

Eres un ávido observador de pájaros que lleva la cuenta de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de pájaros que han visitado tu jardín.

## 1. Comprueba cuáles fueron los recuentos de la semana pasada

Para poder comparar, siempre tienes a mano una copia de los recuentos de la semana pasada, que eran: 0, 2, 5, 3, 7, 8 y 4. Implementa el método (_static_) `BirdCount.LastWeek()` que devuelve los recuentos de la semana pasada:

```csharp
BirdCount.LastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Comprueba cuántos pájaros han visitado hoy tu jardín

Implementa el método `BirdCount.Today()` para devolver cuántos pájaros han visitado hoy tu jardín. Los recuentos de pájaros están ordenados por día, siendo el primer elemento el recuento del día más antiguo y el último elemento el recuento de hoy.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.Today();
// => 1
```

## 3. Incrementa el recuento de hoy

Implementa el método `BirdCount.IncrementTodaysCount()` para incrementar el recuento de hoy:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.IncrementTodaysCount();
birdCount.Today();
// => 2
```

## 4. Comprueba si hubo un día sin pájaros visitantes

Implementa el método `BirdCount.HasDayWithoutBirds()` que devuelve `true` si hubo un día en el que ningún pájaro visitó el jardín; en caso contrario, devuelve `false`:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.HasDayWithoutBirds();
// => true
```

## 5. Calcula el número de pájaros visitantes durante los primeros días

Implementa el método `BirdCount.CountForFirstDays()` que devuelve el número de pájaros que han visitado tu jardín desde el comienzo de la semana, pero limita el recuento al número de días especificado desde el comienzo de la semana.

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.CountForFirstDays(4);
// => 14
```

## 6. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.
Implementa el método `BirdCount.BusyDays()` que devuelve el número de días ajetreados:

```csharp
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
var birdCount = new BirdCount(birdsPerDay);
birdCount.BusyDays();
// => 2
```
