# Introducción

Un diccionario es una colección de elementos donde cada elemento comprende una clave y un valor, de modo que si se pasa una clave a un método del diccionario, se devuelve su valor asociado. Tiene el mismo papel que los mapas o los arrays asociativos en otros lenguajes.

Un diccionario se puede crear de la siguiente manera:

```csharp
new Dictionary<int, string>();
// Empty dictionary
```

O

```csharp
new Dictionary<int, string>
{
    [1] = "One",
    [2] = "Two"
};

// Or

new Dictionary<int, string>
{
    {1, "One"},
    {2, "Two"}
};
// 1 => "One", 2 => "Two"
```

Ten en cuenta que los tipos de clave y valor forman parte de la definición del diccionario.

Una vez construido, se pueden añadir o eliminar entradas de un diccionario usando sus métodos integrados `Add` y `Remove`.

Recuperar o actualizar valores en un diccionario se hace indexando el diccionario con una clave:

```csharp
var numbers = new Dictionary<int, string>
{
   {1, "One"},
   {2, "Two"}
};

// Set the value of the element with key 2 to "Deux"
numbers[2] = "Deux";

// Get the value of the element with key 2
numbers[2];
// => "Deux"
```

Puedes comprobar si un valor existe en el diccionario con:

```csharp
var dict = new Dictionary<string, string>{/*...*/};
dict.ContainsKey("some key that exists");
// => true
```

Al enumerar un diccionario, se enumeran sus pares clave/valor. Los diccionarios también tienen propiedades que permiten enumerar sus claves o valores.
