# Introducción

Recuerda que `jq` admite los mismos tipos de datos que JSON.
JSON describe las **cadenas de caracteres** como:

> Una cadena de caracteres es una secuencia de cero o más caracteres Unicode, encerrada entre comillas dobles, usando secuencias de escape con barra invertida.

## Secuencias de escape

Dentro de un string, usa el carácter de barra invertida para incluir caracteres «especiales»:

- `\"` una comilla doble literal,
- `\\` una barra invertida literal,
- caracteres de espacio en blanco `\n`, `\t`, `\r`, `\f`, `\b`
- caracteres Unicode `\uAAAA`, donde `A` es un dígito hexadecimal

## Longitud de un string

Para averiguar el número de caracteres, usa la función `length`.

```sh
$ jq -cn --args  '$ARGS.positional[] | length' "Hello world!" "❄🌡🤧🤒🏥🕰😀"
12
7
```

## Subcadenas

La notación de **slice** se puede usar para extraer subcadenas.
La sintaxis es `.[i:j]`.
La subcadena devuelta tiene una longitud de `j - i` y devuelve caracteres desde el índice `i` (incluido) hasta el índice `j` (excluido).
Cualquiera de los dos índices puede ser negativo; en ese caso, cuenta hacia atrás desde el final del string.
También se puede omitir cualquiera de los dos índices; en ese caso, hace referencia al principio o al final del string.
Los índices empiezan en cero.

```jq
"abcdefghij"[3:6]   # => "def"
"abcdefghij"[3:]    # => "defghij"
"abcdefghij"[:-2]   # => "abcdefgh"
```

## Concatenación

Usa `+` para unir strings:

```jq
"Hello" + " " + "world!"
# => "Hello world!"
```

Usa `add` cuando tengas un array de strings:

```jq
["Hello", " ", "world!"] | add
# => "Hello world!"
```

## Dividir y unir

Para dividir, usa la función `split/1` o el operador `/`:

```jq
"Hello beautiful world!" | split(" ")   # => ["Hello", "beautiful", "world!"]
```

```jq
"Hello beautiful world!" / " "          # => ["Hello", "beautiful", "world!"]
```

La operación inversa de `split/1` es `join/1`.

A menudo es necesario convertir un string en un array de caracteres.
Hay dos formas de hacerlo:

1. dividir por un string vacío

   ```jq
   "Hi friend 😀" / ""   # => ["H","i"," ","f","r","i","e","n","d"," ","😀"]
   ```

1. `explode` en un array de _puntos de código_

   ```jq
   "Hi friend 😀" | explode   # => [72,105,32,102,114,105,101,110,100,32,128512]
   ```

   `implode` es la operación inversa de `explode`.

## Buscar el índice de una subcadena

Usa la función `index/1`; el índice empieza en cero.

```jq
"hello" | index("el")'   # => 1
```

Si la subcadena no está en el string, el resultado es `null`.

```jq
"hello" | index("elk")   # => null
```

## Interpolación de strings

Dentro de un string, la secuencia `\(expression)` inserta el _resultado_ de esa expresión [en el string][interpolate]:

```jq
"The current datetime is \(now | strflocaltime("%c"))"   # => "The current datetime is Wed Nov 16 17:06:33 2022"
```

## Conversión de mayúsculas y minúsculas

Usa las funciones `ascii_downcase` y `ascii_upcase`.
