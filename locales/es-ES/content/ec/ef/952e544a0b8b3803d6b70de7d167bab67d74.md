# Apéndice de instrucciones

## Formato de salida

Devuelve la edad en centésimas de año.

Por ejemplo, 100 × 1.000.000.000 ÷ 31.557.600 ≈ 3169, así que alguien de 1.000.000.000 segundos de edad tiene `3169` centésimas de año terrestre.

## Registros

| Registro | Uso       | Tipo    | Descripción                   |
| -------- | --------- | ------- | ----------------------------- |
| `$a0`    | entrada   | entero  | planeta (`0` = Mercurio, `1` = Venus, `2` = Tierra, `3` = Marte, `4` = Júpiter, `5` = Saturno, `6` = Urano, `7` = Neptuno) |
| `$a1`    | entrada   | entero  | segundos                      |
| `$v0`    | salida    | entero  | edad en centésimas de año     |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal |
