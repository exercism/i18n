# Instalación de Java

Además de la CLI de Exercism y tu editor de texto favorito,
practicar con los ejercicios de Java de Exercism requiere el **Java Development Kit** (JDK).
El JDK incluye tanto un entorno de ejecución de Java _como_ herramientas de desarrollo (en especial, el compilador de Java).

Hoy en día hay muchas variantes del JDK, algunas de las cuales son de código abierto.
Aquí en Exercism recomendamos usar [Eclipse Temurin de Adoptium][adoptium].

## Versiones de Java compatibles

La ruta de Java de Exercism es compatible con Java 25 LTS y anteriores.

## Instalación de Eclipse Temurin

Para instalar Eclipse Temurin en tu sistema, dirígete a sus excelentes [instrucciones de instalación][adoptium-installation-guide].
Aquí encontrarás instrucciones sobre cómo instalar el JDK con tu gestor de paquetes favorito,
y también contiene enlaces a instaladores descargables para los principales sistemas operativos.

## IDE de Java

Hay muchos entornos de desarrollo integrados (IDE) gratuitos para Java.
Aquí tienes algunas opciones populares:

- [IntelliJ IDEA Community Edition][intellij-idea]
- [Eclipse][eclipse]
- [Visual Studio Code con la extensión de Java][vscode-java]
