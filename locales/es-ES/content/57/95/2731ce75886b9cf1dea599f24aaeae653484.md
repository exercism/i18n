# Anexo a las instrucciones

## Registros

| Registro | Uso       | Tipo       | Descripción                       |
| -------- | --------- | ---------- | --------------------------------- |
| `$a0`    | entrada   | dirección  | array de palabras de libros       |
| `$a1`    | entrada   | entero     | número de libros                  |
| `$v0`    | salida    | entero     | precio, en céntimos               |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal |
