# Instrucciones

Elyse, futura maga, continúa su entrenamiento.
Tiene una baraja de cartas que quiere manipular.

Para que le resulte más fácil, normalmente solo parte de cartas numeradas del 2 al 10, aunque algunos de los trucos pueden incluir cartas adicionales (figuras).

<!-- prettier-ignore-start -->
~~~~exercism/note
Hay **muchas** formas de mezclar las cartas, pero para mantener la ilusión de la magia es vital que *no se use ni un solo método*; por ejemplo, Elyse no usa `splice`, `slice`, `shift`, `unshift`, `push`, `at`.
El acceso a arrays `array[index]` y el acceso a objetos (`object[key]` y `object.key`) tampoco deben usarse nunca.
~~~~
<!-- prettier-ignore-end -->

¿Quieres ayudar a Elyse a mejorar su magia?

<!-- prettier-ignore-start -->
~~~~exercism/advanced
Todas las funciones se pueden implementar usando los parámetros y un cuerpo de función con un único `return expression`.
~~~~
<!-- prettier-ignore-end -->

## 1. Obtén la primera carta

Elyse invocará la primera carta de la baraja sin usar `array[index]`, `.at(index)` ni `.shift()`.
Es como por arte de magia.

```javascript
const deck = [5, 9, 7, 1, 8];

getFirstCard(deck);
// => 5
```

## 2. Obtén la segunda carta

Elyse hace un juego de manos e invoca la segunda carta de la baraja sin usar `array[index]` ni `.shift()`.

```javascript
const deck = [3, 2, 10, 6, 7];

getSecondCard(deck);
// => 2
```

## 3. Intercambia dos cartas

Elyse hará que las dos cartas de la baraja cambien de sitio.
No necesita llamar a ninguna función.

```javascript
const deck = [10, 7];

swapTwoCards(deck);
// => [7, 10]
```

## 4. Desplaza tres cartas

Para hacer otro juego de manos, Elyse coge tres cartas y mueve rápidamente la carta de arriba al final, con lo que la carta del medio pasa a ser la primera y la que antes estaba abajo pasa a ser la del medio.
No necesita llamar a ninguna función.

```javascript
const deck = [2, 6, 10];

shiftThreeCardsAround(deck);
// => [6, 10, 2]
```

## 5. Elige el montón con nombre

Elyse separará la baraja en dos montones.
Luego pide al espectador que elija uno de los dos montones, al que llamaremos `chosen`.
El montón `disregarded` ya no importa, así que lo hace desaparecer.
No necesita llamar a ninguna función.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

pickNamedPile({ chosen, disregarded });
// => [5, 4]
```

## 5. Intercambia el montón elegido

Por desgracia, el espectador sigue eligiendo el montón «equivocado», pero con algo de magia rápida e ingeniosa, Elyse renombra el montón `chosen` como `disregarded` y el montón `disregarded` como el montón `chosen`.
No necesita llamar a ninguna función.

```javascript
const deck = [5, 4, 7, 10];
const chosen = [5, 4];
const disregarded = [7, 10];

swapNamedPile({ chosen, disregarded });
// => { chosen: [7, 10], disregarded: [5, 4] }
```
