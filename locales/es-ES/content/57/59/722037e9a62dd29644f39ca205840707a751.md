# Mapas y conjuntos

Un array guarda valores en posiciones numeradas. A veces la etiqueta útil no es un número.

## Mapas

Un **mapa** asocia cada **clave** con un **valor**. Busca algo por su clave y el mapa te da lo que se guardó bajo ella.

`FMAP{K,T}` es un mapa de claves de tipo `K` a valores de tipo `T`. Una guía que asocia el nombre de un animal con el lugar donde vive es `FMAP{STR,STR}`.

```sather
   guide ::= #FMAP{STR,STR};
   guide := guide.insert("emu", "grassland");
   guide.get("emu")               -- "grassland"
```

## Vuelve siempre a asignar el resultado

Fíjate otra vez en la línea del medio. `insert` devuelve el mapa con el par añadido, y hay que quedarse con lo que devuelve:

```sather
   guide := guide.insert("emu", "grassland");     -- yes
   guide.insert("emu", "grassland");              -- no: the answer is lost
```

Es la misma regla que en `FSTR`, y por la misma razón. Lo que devuelve suele ser el propio mapa que se pasó, modificado in situ; de vez en cuando, cuando el mapa se ha quedado sin espacio, es uno más grande. Como no puedes saber cuál de los dos casos es, **usa lo que devuelve y deja de usar el nombre antiguo.** Un nombre que queda de antes de un `insert` puede estar desactualizado o puede que ya no describa un mapa utilizable.

Eso también significa que un mapa que le pasas a una rutina no está a salvo de ella. Si el original tiene que sobrevivir, consulta `copy` en la página del concepto.

## ¿Está ahí?

`has_ind` pregunta si una clave está en el mapa. El nombre es la abreviatura de «has index», y un índice es lo que estos mapas llaman una clave.

```sather
   guide.has_ind("emu")           -- true
   guide.has_ind("moa")           -- false
```

Pedir una clave que no está **no** da ningún error. `get` devuelve el valor vacío del tipo: cero para un `INT` y void para un `STR`, lo que fallará más tarde y en otro sitio. Así que comprueba antes de pedir:

```sather
   if guide.has_ind(animal) then
      return guide.get(animal);
   else
      return "Unknown";
   end;
```

## Conjuntos

Un **conjunto** guarda valores sin repeticiones y sin orden. `FSET{T}` es un conjunto de valores de tipo `T`.

```sather
   seen ::= #FSET{STR};
   seen := seen.insert("emu");
   seen := seen.insert("emu");    -- already there; nothing changes
   seen.size                      -- 1
   seen.has("emu")                -- true
```

Insertar algo dos veces deja una sola copia. Para eso sirve un conjunto: para reunir cosas olvidando cuántas veces apareció cada una.

`insert` sobre un conjunto devuelve el conjunto que hay que usar a partir de entonces, exactamente igual que en el caso de un mapa, así que vuelve a asignarlo cada vez.

## Cuántos

`.size` funciona en ambos: cuántos pares contiene un mapa y cuántos valores hay en un conjunto.
