# Introducción

`OpenStruct` te permite crear un objeto a partir de un `Hash` con facilidad.
En lugar de tener que acceder mediante las claves del `Hash`, `OpenStruct` nos permite usar métodos para acceder a los valores y establecerlos.


```ruby
attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Una ventaja añadida de este planteamiento es que podemos aprovechar un atajo cuando usamos la sintaxis de bloque.
Cuando un bloque llama a un único método, puedes sustituir el bloque por `&:` seguido del nombre del método.
Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```

## Biblioteca estándar

Todas las clases que has visto en los ejercicios anteriores forman parte de la biblioteca principal de Ruby.

OpenStruct forma parte de la biblioteca estándar de Ruby (a menudo abreviada como «stdlib»), una colección de clases para trabajar con cosas como fechas, JSON y redes.
También incluye algunas funcionalidades útiles para que tu código sea más fácil de manejar.

Cuando usamos clases que no son de la biblioteca principal (tu propio código en otros archivos, clases de la biblioteca estándar o dependencias externas), tenemos que importarlas con el método `require` antes de poder usarlas.
Por ejemplo:

```ruby
require 'ostruct'

person = OpenStruct.new(name: "Jeremy Walker")
# ...
```
