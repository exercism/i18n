# Instrucciones

Boris es un gran aficionado a los trenes en miniatura y ha decidido compartir su pasión con el mundo lanzando un boletín. Empezará enviando el primer número del boletín a amigos y conocidos que comparten la afición; sus direcciones de correo electrónico están guardadas en un fichero de texto.

Pista: usa el módulo [simplifile](https://hexdocs.pm/simplifile/simplifile.html) para las operaciones con ficheros.

## 1. Lee direcciones de correo electrónico de un fichero

Implementa la función `read_emails`. Recibe una cadena con la ruta a un fichero de texto que contiene direcciones de correo electrónico separadas por saltos de línea y devuelve un array con las direcciones de correo electrónico del fichero.

```gleam
read_emails("/home/my_user/documents/model_train_friends_emails.txt")
// -> Ok(["rick@example.com", "choochoo42@example.com", "anna@example.com"])
```

## 2. Crea un fichero de registro para escribir

Enviar un correo electrónico es una tarea que puede fallar por muchas razones imprevisibles, como un error tipográfico en la dirección de correo electrónico o problemas temporales de red. Para asegurarte de que puedes reintentar el envío de los correos a todos tus amigos sin enviar duplicados, necesitas registrar las direcciones de correo electrónico que ya recibieron el correo. Para ello, necesitarás un fichero de registro.

Implementa la función `create_log_file`. Recibe la ruta de un fichero y crea un fichero nuevo y vacío en esa ubicación.

```gleam
create_log_file("/home/my_user/documents/newsletter_issue1_log.txt")
// -> Ok(Nil)
```

## 3. Registra un correo enviado

Implementa la función `log_sent_email`. Recibe la ruta a un fichero de registro y un string con la dirección de correo electrónico. Escribe la dirección de correo electrónico en el fichero, seguida de un salto de línea.

```gleam
log_sent_email(
  "/home/my_user/documents/newsletter_issue1_log.txt",
  "joe@example.com",
)
// -> Ok(Nil)
```

## 4. Envía el boletín

Ahora que tienes todas las piezas del proceso de envío de correos electrónicos, necesitas combinarlas en una sola función.

Implementa la función `send_newsletter`. Recibe la ruta del fichero con las direcciones de correo electrónico, la ruta de un fichero de registro y una función anónima que envía un correo electrónico a una dirección de correo electrónico dada.

Debe leer todas las direcciones de correo electrónico del fichero dado e intentar enviar un correo electrónico a cada una de ellas. Si la función anónima que envía el correo electrónico devuelve un valor `Ok`, escribe la dirección de correo electrónico en el fichero de registro. Asegúrate de hacerlo en cuanto se envíe el correo electrónico.

```gleam
send_newsletter(
  "model_train_friends_emails.txt",
  "newsletter_issue1_log.txt",
  send_email,
)
// -> Ok(Nil)
```
