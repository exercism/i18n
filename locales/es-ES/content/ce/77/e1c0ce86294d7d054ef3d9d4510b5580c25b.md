# Instrucciones

Estás desarrollando un sistema para ayudar al personal del sitio web de un club de fútbol a informar sobre los partidos.
Este sistema es capaz de analizar distintos aspectos del partido, tanto dentro como fuera del campo, y convertirlos en un flujo de eventos.

## 1. Muestra descripciones de los jugadores según su número de camiseta

El equipo juega siempre con una formación 4-3-3 y nunca ha aceptado el cambio de 1965 en las reglas que permitía las sustituciones, y mucho menos las plantillas ampliadas.

Las descripciones de los jugadores son las siguientes:

```text
1 -> "goalie"
2 -> "left back"
3 & 4 -> "center back"
5 -> "right back"
6, 7 & 8 -> "midfielder"
9 -> "left wing"
10 -> "striker"
11 -> "right wing"
```

Implementa el método estático `PlayAnalyzer.AnalyzeOnField()` para mostrar una descripción del jugador según su número de camiseta.

```csharp
PlayAnalyzer.AnalyzeOnField(10);
// => "striker"
```

## 2. Gestiona los números de camiseta desconocidos

Modifica el método `PlayAnalyzer.AnalyzeOnField()` para que devuelva `UNKNOWN` cuando se procese un número de camiseta fuera del rango 1-11.

## 3. Amplía la cobertura para incluir la actividad fuera del campo

Implementa el método `PlayAnalyzer.AnalyzeOffField()` para mostrar descripciones de las actividades y los personajes que rodean el terreno de juego.
Este método recibe distintos tipos de datos que deben analizarse y convertirse en el texto adecuado para ayudar a los periodistas.

Para empezar, vamos a cubrir los datos sobre el estadio:

- El número actual de aficionados en el estadio (cualquier `int`)
- Los anuncios hechos por el sistema de megafonía del estadio (cualquier `string`)

Los tipos de datos desconocidos no deben procesarse, así que si el método recibe datos de otro tipo, debe devolverse un string vacío.

```csharp
PlayAnalyzer.AnalyzeOffField(5000);
// => "There are 5000 supporters at the match."

PlayAnalyzer.AnalyzeOffField("5 minutes to go!");
// => "5 minutes to go!"

PlayAnalyzer.AnalyzeOffField(0.5);
// => ""
```

## 4. Informa sobre los incidentes durante el partido

Modifica el método `PlayAnalyzer.AnalyzeOffField()` para que muestre descripciones de los incidentes que ocurren durante el partido.

Los incidentes pueden ser cualquier subclase del tipo `Incident` y contienen una descripción del incidente.
Las lesiones son un tipo especial de incidente porque hacen que el partido se detenga, así que deben tratarse de forma distinta.

```csharp
PlayAnalyzer.AnalyzeOffField(new Foul());
// => "The referee deemed a foul."

PlayAnalyzer.AnalyzeOffField(new Injury(8));
// => "Oh no! Player 8 is injured. Medics are on the field."
```

## 5. Informa sobre los entrenadores de los clubes

Modifica el método `PlayAnalyzer.AnalyzeOffField()` para que mencione a los entrenadores de los clubes presentes durante el partido.

Los entrenadores son instancias del tipo `Manager` y tienen un nombre y el nombre del club que dirigen.
El club del entrenador puede ser desconocido, en cuyo caso se establecerá como `null`.
Si el club de un entrenador no se conoce, no debe formar parte de la descripción.

```csharp
PlayAnalyzer.AnalyzeOffField(new Manager("José Mário dos Santos Mourinho Félix", null));
// => "José Mário dos Santos Mourinho Félix"

PlayAnalyzer.AnalyzeOffField(new Manager("Jürgen Klopp", "Liverpool"));
// => "Jürgen Klopp (Liverpool)"
```
