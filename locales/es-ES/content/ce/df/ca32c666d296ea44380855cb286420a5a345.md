# API de Exercism

## Descripción

La mayoría de los tracks de lenguaje de Exercism usan la herramienta de línea de comandos `exercism` para obtener y enviar ejercicios, que interactúa con `exercism.io` mediante una API REST. El track de lenguaje de Pharo Smalltalk, en cambio, usa la misma API REST para introducir y extraer ejercicios de la imagen de Pharo sin usar ninguna herramienta intermedia. Este documento detalla la API de Exercism, centrándose en cómo la usa el track de lenguaje de Pharo Smalltalk. Está dirigido a quienes mantienen las herramientas de Pharo Smalltalk.

## Cabeceras

Todos los endpoints requieren que las cabeceras de la solicitud se establezcan en los siguientes valores:

```
Authorization: Bearer <token>
```

El valor `<token>` es el token de autenticación de la CLI del usuario, disponible en `https://exercism.io/my/settings`.

## Obtener ejercicios

```
Content-Type: application/json
```

`GET api.exercism.io/v1/solutions/latest?exercise_id=<slug>&track_id<language> HTTP/1.1`

En la URL anterior, `<slug>` es el nombre del ejercicio, p. ej. `hello-world`, y `<language>` es el track de lenguaje, p. ej. `pharo-smalltalk`.

### Respuesta

#### 200

Una solicitud correcta enviará una respuesta que contiene una carga útil JSON. Dentro del JSON habrá información sobre el ejercicio y una URL desde la que descargar los archivos del ejercicio.

```json
"solution":{
	"id":"<id-string>",
	"url":"https://exercism.io/my/solutions/<id-string>",
	"team":null,
	"user":{
		"handle":"<exercism-user-name>",
		"is_requester":true
		},
		"exercise":{
			"id":"isogram",
			"instructions_url":"https://exercism.io/my/solutions/<id-string>",
			"auto_approve":false,
			"track":{
				"id":"pharo-smalltalk",
				"language":"Pharo"
				}
			},
			"file_download_base_url":"https://api.exercism.io/v1/solutions/<id-string>/files/",
			"files":[
				"IsogramTest.class.st",
				"README.md"
				],
			"iteration":null
		}
	}
```

#### 400

El nombre del track de lenguaje es ambiguo, o los archivos de ejercicio enviados no han cambiado.

#### 403

La solución no está desbloqueada para el usuario o no se ha unido al track de lenguaje.

#### 404

No se ha podido encontrar el track de lenguaje o el ejercicio.

## Enviar ejercicios

```
Content-Type: application/octet-stream
```

`PATCH api.exercism.io//v1/solutions/<some-kind-of-token-or-hash> HTTP/1.1`

### Respuesta

#### 201

Un envío correcto.

#### 400

Un archivo enviado es demasiado grande (más de un megabyte), o la solución está duplicada.

#### 403

La solución no es accesible para el usuario. El ID de usuario de la solución y el ID de usuario actual no coinciden.

#### 404

No se ha encontrado el ID de la solución.
