# Descripción

Una terna pitagórica es un conjunto de tres números naturales, {a, b, c}, que cumple lo siguiente:

```text
a² + b² = c²
```

y además,

```text
a < b < c
```

Por ejemplo,

```text
3² + 4² = 5².
```

Dado un número entero de entrada N, encuentra todas las ternas pitagóricas para las que `a + b + c = N`.

Por ejemplo, con N = 1000, hay exactamente una terna pitagórica para la que `a + b + c = 1000`: `{200, 375, 425}`.
