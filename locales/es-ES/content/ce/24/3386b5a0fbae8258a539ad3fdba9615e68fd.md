# Anexo a las instrucciones

## Notas específicas del ejercicio para Rust

Esto cambia ligeramente en la versión de Rust, en comparación con otras versiones de este ejercicio en otros lenguajes. En lugar de pedirte que devuelvas errores para valores fuera de rango, usamos el sistema de tipos fuerte de Rust para limitar la entrada. Es mucho más fácil hacer que una función se ocupe de todas las entradas válidas, en lugar de pedir a quien use tu módulo que gestione los errores.

### Extensión

Añade la capacidad de convertir hasta el valor máximo para u64: `18_446_744_073_709_551_615`.

Para ver pistas sobre la salida que debería tener, mira el último caso de prueba.
