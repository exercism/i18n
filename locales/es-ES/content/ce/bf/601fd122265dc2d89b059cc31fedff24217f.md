# Introducción

Una cadena de caracteres (`String`) en Haxe es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Las comillas dobles se usan para definir una instancia de `String`:

```haxe
var fruit:String = "Apple";
```

Los strings se manipulan llamando a los métodos del string. Una vez construido un string, su valor nunca puede cambiar. Cualquier método que parezca modificar un string en realidad devolverá un nuevo string.

Se pueden concatenar (sumar) varios strings entre sí. La forma más sencilla de conseguirlo es usar el operador `+`.

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para cualquier formato de string más complejo que una simple concatenación, se prefiere la interpolación de strings. Para usar la interpolación en un string, enciérralo entre comillas simples (`'`). Después, puedes usar el signo del dólar (`$`) para activar la interpolación:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
```
