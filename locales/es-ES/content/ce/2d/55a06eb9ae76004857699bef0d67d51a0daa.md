# Usa guards

[comment]: # (This error is raised when the solution doesn't use guards at all)

Usa [guards](https://hexdocs.pm/elixir/master/guards.html) para evitar que `two_fer/1` ejecute código con entradas que no sean binarias.

> Recuerda que, en Elixir, los [strings](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html) se consideran [datos binarios](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html).

```elixir
# Consider this function with a guard:
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

> Puedes probar este guard en `iex`

```shell
iex> hello("world")
"Hello, world!"
iex> hello(123)
** (FunctionClauseError) no function clause matching in hello/1

    The following arguments were given to hello/1:

        # 1
        123
```
