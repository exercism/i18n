# Introducción

Para palabras cortas, hacer malabares con la pila está bien. Cuando una palabra tiene varias entradas y necesitas referirte a ellas por su nombre, Factor ofrece *locals*: enlaces con nombre introducidos con `::` (para definiciones de palabras) o `[| | ]` (para lambdas en línea), ambos de [`locals`][locals].

```factor
USING: locals ;

:: hypotenuse ( a b -- c )
    a a *
    b b *
    + sqrt ;
```

Dentro de una quotation, `[| inputs | body ]` es una lambda con entradas con nombre:

```factor
USING: assocs locals ;

H{ { "a" 1 } { "b" 2 } }
[| key value | key value 10 * ] assoc-map .
! => H{ { "a" 10 } { "b" 20 } }
```

[locals]: https://docs.factorcode.org/content/vocab-locals.html
