# Instrucciones

En este ejercicio, escribirás algo de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si podrás permitirte uno, otra para ayudarte a elegir entre dos vehículos y determinar qué licencia necesitarás, y otra para estimar el precio aceptable de un vehículo usado.

## 1. Calcula si puedes o no permitirte los pagos mensuales de un coche determinado

Los concesionarios de tu ciudad están ofreciendo una promoción de cinco años con un 0% de interés de la que te gustaría aprovecharte.
Pero no estás seguro de si puedes permitirte los pagos mensuales del coche que quieres.

El pago mensual es el precio total del coche dividido entre el número de meses del periodo de cinco años.

Implementa la función `canIBuy(vehicle:price:monthlyBudget:)` que toma los siguientes argumentos:
- `vehicle` - El nombre del vehículo que quieres comprar.
- `price` - El precio del vehículo que quieres comprar.
- `monthlyBudget` - La cantidad de dinero que puedes permitirte pagar cada mes.

La función debe devolver el siguiente mensaje según las siguientes condiciones:
- Si el pago mensual del vehículo es menor o igual que el presupuesto mensual, devuelve el mensaje `"Yes! I'm getting a <vehicle>"`.
- Si el pago mensual del vehículo supera tu presupuesto mensual en hasta un 10 % (inclusive), devuelve el mensaje `"I'll have to be frugal if I want a <vehicle>"`.
- Si el pago mensual del vehículo supera en más de un 10 % tu presupuesto mensual, devuelve el mensaje `"Darn! No <vehicle> for me"`.

```swift
canIBuy(vehicle: "1974 Ford Pinto", price: 516.32, monthlyBudget: 100.00)
// returns "Yes! I'm getting a 1974 Ford Pinto"
canIBuy(vehicle: "2011 Bugatti Veyron", price: 2_250_880.00, monthlyBudget: 10000.00)
// returns "Darn! No 2011 Bugatti Veyron for me"
canIBuy(vehicle: "2020 Indian FTR 1200", price: 12_500, monthlyBudget: 200)
// returns "I'll have to be frugal if I want a 2020 Indian FTR 1200"
```

## 2. Determina el tipo de carné de conducir que necesitarás

Has decidido comprar un vehículo usado y necesitas determinar qué tipo de carné de conducir necesitarás para conducirlo.

Implementa la función `licenseType(numberOfWheels:)` que toma el argumento `numberOfWheels`, que es el número de ruedas del vehículo que quieres comprar.

La función debe devolver el siguiente mensaje según las siguientes condiciones:
- Si el número de ruedas es 2 o 3, devuelve el mensaje `"You will need a motorcycle license for your vehicle"`.
- Si el número de ruedas es 4 o 6, devuelve el mensaje `"You will need an automobile license for your vehicle"`.
- Si el número de ruedas es 18, devuelve el mensaje `"You will need a commercial trucking license for your vehicle"`.
- Si el número es cualquier otro número, devuelve el mensaje `"We do not issue licenses for those types of vehicles"`.

```swift
licenseType(numberOfWheels: 2)
// returns "You will need a motorcycle license for your vehicle"
licenseType(numberOfWheels: 6)
// returns "You will need an automobile license for your vehicle"
licenseType(numberOfWheels: 18)
// returns "You will need a commercial trucking license for your vehicle"
licenseType(numberOfWheels: 0)
// returns "We do not issue licenses for those types of vehicles"
```

## 3. Calcula una estimación del precio de un vehículo usado

Ahora que has tomado tu decisión, quieres asegurarte de obtener un precio justo en el concesionario.
Como estás interesado en comprar un vehículo usado, el precio depende de la antigüedad del vehículo.
Como estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene al menos 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70 % del precio original.

Implementa la función `calculateResellPrice(originalPrice:yearsOld:)` que toma los argumentos `originalPrice`, que contiene el precio original del vehículo, y `yearsOld`, que contiene la antigüedad del vehículo en años.
La función debe devolver el precio de reventa del vehículo. 

```swift
calculateResellPrice(originalPrice: 1000, yearsOld: 1)
// returns 800
calculateResellPrice(originalPrice: 1000, yearsOld: 5)
// returns 700
calculateResellPrice(originalPrice: 1000, yearsOld: 15)
// returns 500
```
