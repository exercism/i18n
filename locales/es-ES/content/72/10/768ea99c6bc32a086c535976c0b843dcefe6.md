# Instrucciones

Vas a escribir código para gestionar un inventario de artículos en una tienda.
El inventario será una referencia a un hash que contendrá los artículos del inventario y sus cantidades.

## 1. Crea un nuevo inventario usando los artículos

Modifica la subrutina `InventoryManagement::create_inventory`, que toma como argumento una referencia a un array de artículos, para que devuelva una referencia a un hash de inventario recién creado, con las claves como nombres de los artículos y los valores como las cantidades.

## 2. Añade al inventario usando los artículos

Modifica la subrutina `InventoryManagement::add_items`, que toma como argumentos una referencia a un hash de inventario y una referencia a un array de artículos, para que devuelva una referencia a un hash con los artículos añadidos al inventario.

## 3. Quita los artículos del inventario

Modifica la subrutina `InventoryManagement::remove_items`, que toma como argumentos una referencia a un hash de inventario y una referencia a un array de artículos, para que devuelva una referencia a un hash con los artículos quitados del inventario.
Las cantidades de los artículos no deben bajar de cero.

## 4. Elimina el artículo por completo del inventario

Modifica la subrutina `InventoryManagement::delete_item`, que toma como argumentos una referencia a un hash de inventario y el nombre de un artículo, para que devuelva una referencia a un hash con el artículo eliminado por completo del inventario.
