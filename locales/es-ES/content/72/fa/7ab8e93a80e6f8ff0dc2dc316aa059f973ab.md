# Apéndice de instrucciones

## Pistas

Para completar este ejercicio tienes que implementar la función `anagramsFor`,
que recibe una *palabra* y un grupo de *palabras*, y devuelve las que son
anagramas de la *palabra* dada.

Debes devolver los anagramas en el mismo orden en que aparecen en las
palabras candidatas.


Si es la primera vez que resuelves este ejercicio, te recomendamos que te
ciñas a la signatura proporcionada:

```haskell
anagramsFor :: String -> [String] -> [String]
```

Más adelante, puede ser buena idea volver sobre este problema y jugar con otros
tipos de datos y bibliotecas:

- `Text`, del paquete *text*.
- `Sequence` y `Set`, del paquete *containers*.
- `MultiSet`, del paquete *multiset*

El conjunto de pruebas se diseñó intencionadamente para aceptar casi cualquier
signatura de tipo que tenga sentido, así que te animamos a encontrar la que
creas que es la mejor.
