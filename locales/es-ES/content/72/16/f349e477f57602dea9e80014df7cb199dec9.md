# Instalación

## Opciones de instalación

La versión actual de Unison está disponible para usuarios de Mac OS X, Linux de 64 bits y Windows. Esperamos que, si estás probando Unison, vengas a hablar con nosotros en el foro de Exercism o en el [Discord de Unison](https://unison-lang.org/discord). ¡Ven a hacer preguntas y a informar de los problemas que puedas encontrar! Queremos que tengas una experiencia acogedora y positiva cuando empieces. 😊

Unison se puede descargar con [homebrew](https://brew.sh/), [Nix](https://github.com/ceedubs/unison-nix/#usage) o directamente mediante binarios empaquetados. Todas estas opciones de descarga se describen en la [página de instrucciones de instalación de nuestro sitio web](https://www.unison-lang.org/learn/quickstart/#installation-options). Una vez que tengas instalado el UCM, ¡vuelve aquí!

### Opción 1: usar Homebrew

Primero [instala homebrew](https://brew.sh/) si aún no lo has hecho.

Después, desde la línea de comandos, introduce estos comandos:

```
brew tap unisonweb/unison
brew install unison-language
```

Esto instalará el ejecutable del gestor de base de código de Unison, `ucm`. Si estás actualizando desde una versión anterior, solo tienes que ejecutar

```
brew upgrade unison-language.
```

Nota: si en este punto se te pide un nombre de usuario y una contraseña de GitHub, asegúrate de haber escrito bien unisonweb/unison.

### Opción 2: instalar manualmente para usuarios de Mac y Linux

[Aquí se proporcionan los enlaces de instalación manual para Linux y Mac](https://www.unison-lang.org/learn/quickstart/#installation-options), en la sección correspondiente de descarga manual para Linux y Mac.

Ejecutarás en tu shell un comando parecido a este, pero el enlace de arriba contendrá el binario más actualizado:

```
mkdir unisonlanguage
curl -L https://github.com/unisonweb/unison/releases/download/release_VERSION_NAME/ucm-YOUR_PLATFORM.tar.gz --output unisonlanguage/ucm.tar.gz
tar -xzf unisonlanguage/ucm.tar.gz -C unisonlanguage
./unisonlanguage/ucm
```

### Opción 3: instalar manualmente para usuarios de Windows

1. Configura «Windows Terminal» como tu aplicación de terminal predeterminada para obtener los mejores resultados. Busca «Terminal» en Settings o sigue [esta guía.](https://bit.ly/3IXwdlY)
2. Si no estás seguro de tenerlo ya, instala Git:
  * Con winget: `winget install --id Git.Git -e --source winget`
  * Si usas Windows 10 y no tienes winget, puedes instalarlo desde [Microsoft Store](https://www.microsoft.com/en-us/p/app-installer/9nblggh4nns1) y después ejecutar el comando de arriba.
3. [Descarga el UCM con el enlace que se proporciona aquí](https://www.unison-lang.org/learn/quickstart/#installation-options) y extráelo en la ubicación que elijas.
4. Ejecuta `ucm.exe`

### Opción 4: instalación con Nix
Ve a [https://github.com/ceedubs/unison-nix/#usage](https://github.com/ceedubs/unison-nix/#usage) y sigue las instrucciones del readme que encontrarás allí.

## Crea tu base de código de Unison

Ejecuta `ucm` para inicializar una base de código de Unison en `$HOME/.unison`. Aquí es donde Unison almacenará las definiciones de funciones, los tipos, los espacios de nombres, etc. De forma predeterminada, el gestor de base de código de Unison (abreviado «UCM») empezará a descargar la biblioteca estándar, llamada `base`, que usarás para escribir código Unison. ¡Puede tardar un momento! 🕰

## Flujo de trabajo con Unison

Cuando quieras escribir código Unison, ejecutarás el comando `ucm` para iniciar el gestor de base de código. El UCM observará entonces los cambios de cualquier archivo con extensión `.u` en el directorio desde el que se invoca. Por ejemplo, puede que estés implementando funciones en un archivo llamado `scratch.u` dentro de un directorio llamado `~/exercism/unison/my-exercise/`. Deberías hacer `cd` a `~/exercism/unison/my-exercise/` y ejecutar `ucm`. Así te asegurarás de que el UCM esté vigilando los cambios en tu archivo `scratch.u`.

Si alguna vez no tienes claro en qué directorio está vigilando los cambios de archivos el `ucm`, se muestra en la pantalla de bienvenida al iniciar la CLI.

```
👀 I'm watching for changes to .u files under /Users/myUser/exercism/unison/my-exercise
```

[¡Aquí tienes más consejos sobre el flujo de trabajo!](https://exercism.org/docs/tracks/unison/workflow)

## Compatibilidad con los editores

Puedes usar cualquier editor de texto para escribir tus archivos `.u`. Unison tiene [compatibilidad con LSP](https://github.com/unisonweb/unison/blob/trunk/docs/language-server.markdown), así que tu IDE favorito puede ayudarte con cosas como los tipos al pasar el cursor y el autocompletado. A continuación se enumeran algunos editores populares compatibles con Unison:

### Vim

Con [vim-plug](https://github.com/junegunn/vim-plug):

1. Instala [`vim-plug`](https://github.com/junegunn/vim-plug) si aún no lo has hecho.
2. Añade lo siguiente a tu .vimrc: `Plug 'unisonweb/unison', { 'branch': 'trunk', 'rtp': 'editor-support/vim' }`
3. Ejecuta el comando de vim `:PlugInstall`.

Para obtener más información, ejecuta `:help unison`
desde vim o consulta la [documentación de ayuda en línea](https://github.com/unisonweb/unison/blob/trunk/editor-support/vim/doc/unison.txt).

### Atom
Desde la consola, ejecuta:

```
apm install unisonweb/atom-unison
```

### VS Code

1. Muestra la vista Extensions haciendo clic en el icono Extensions de la Activity Bar, en el lateral de VS Code, o con ⇧⌘X.
2. Busca «unison»
3. Instala la [extensión de Unison para VS Code](https://marketplace.visualstudio.com/items?itemName=unison-lang.unison)

### Emacs
Instala [`unison-mode`](https://github.com/dariooddenino/unison-mode-emacs).
