# Instrucciones

Llevas los juegos de azar del salón recreativo del paseo marítimo. Los jugadores tiran dados, la máquina de pinzas atrapa un premio y la mesa de cartas necesita que se barajen las cartas y se repartan las manos; todo ello impulsado por la aleatoriedad. Al final de la noche, también quieres una función de repetición para poder volver a ejecutar una partida en disputa desde la misma semilla.

## 1. Tira un dado

Define `roll-die` para que reciba el número de caras y devuelva una tirada en el rango de `1` a `sides`, ambos inclusive.

```factor
6 roll-die .
! => 4   (some value from 1..6)
```

## 2. Coge un premio

Define `pick-prize` para que reciba una secuencia de premios y devuelva uno de ellos al azar.

```factor
{ "teddy" "goldfish" "keyring" } pick-prize .
! => "goldfish"
```

## 3. Baraja las cartas

Define `shuffle-deck` para que reciba una baraja (una secuencia) y la devuelva con las cartas en un orden aleatorio.

```factor
{ 1 2 3 4 5 } shuffle-deck .
! => { 3 1 5 2 4 }
```

## 4. Reparte una mano

Define `deal-hand` para que reciba una baraja y una cantidad `n`, y devuelva `n` cartas *distintas* de la baraja.

```factor
{ 10 20 30 40 50 } 3 deal-hand .
! => { 40 10 30 }
```

## 5. Repite desde una semilla

Define `play-seeded` para que reciba una semilla y una cita, y ejecute la cita con un generador inicializado con ese entero como semilla, de modo que la misma semilla reproduzca siempre el mismo resultado. El resultado de la cita debe devolverse a quien la llama.

```factor
42 [ 6 roll-die ] play-seeded .
! => the same value every time for seed 42

! Same seed, same game:
99 [ 5 deal-hand ] play-seeded   99 [ 5 deal-hand ] play-seeded   =  .
! => t
```
