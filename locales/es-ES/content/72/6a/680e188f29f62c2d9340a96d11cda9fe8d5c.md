# Cómo ejecutar las pruebas

Para ejecutar las pruebas de un ejercicio, ejecuta el script `<exercise>.test` que está en el directorio del ejercicio:

```bash
tclsh <exercise>.test
```

En la mayoría de los ejercicios, todas las pruebas excepto la primera aparecerán como «skipped».
Esto te permite, como desarrollador, practicar el desarrollo guiado por pruebas: escribir únicamente el código necesario para superar cada prueba, una a una.
Para anular los comandos de omisión, asigna a la variable de entorno `RUN_ALL` un valor verdadero válido de Tcl \[1\] antes de ejecutar el conjunto de pruebas:

```bash
RUN_ALL=yes tclsh <exercise>.test
```

\[1\]: Los valores verdadero/falso de Tcl están documentados en la página de manual de la función de biblioteca de C [Tcl_GetBoolean][bool].

[bool]: https://www.tcl-lang.org/man/tcl8.6/TclLib/GetInt.htm
