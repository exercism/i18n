# Instrucciones

Usa la criba de Eratóstenes para encontrar todos los números primos desde el 2 hasta un número dado.

La criba de Eratóstenes es un algoritmo sencillo y antiguo para encontrar todos los números primos hasta cualquier límite dado. Lo hace marcando iterativamente como compuestos (es decir, no primos) los múltiplos de cada primo, empezando por los múltiplos de 2. No usa ninguna operación de división ni de residuo.

Crea tu rango, empezando en dos y continuando hasta el límite dado, inclusive (es decir, [2, límite]).

El algoritmo consiste en repetir una y otra vez lo siguiente:

- toma el siguiente número sin marcar disponible en tu array (es primo)
- marca todos los múltiplos de ese número (no son primos)

Repite hasta que hayas procesado cada número de tu rango.

Cuando el algoritmo termina, todos los números del array que no se han marcado son primos.

El artículo de Wikipedia tiene un gráfico útil que explica el algoritmo:
https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes

Fíjate en que se trata de un algoritmo muy concreto, y los tests no comprueban que hayas implementado el algoritmo, solo que has dado con el array de primos correcto. Un buen primer test es comprobar que no usas operaciones de división ni de residuo (div, /, mod o % según el lenguaje).
