# Pruebas

Para usar la CLI y ejecutar las pruebas del ejercicio, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
clojure -M:test
```

## REPL

Para usar el REPL y ejecutar las pruebas del ejercicio, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
$ clojure -m cljs.main -re node
```

Después, usa `require` para cargar el espacio de nombres de pruebas del ejercicio y el espacio de nombres de pruebas de Clojure:

```clojure
;; replace <exercise> with the exercise's name
=> (require '<exercise>-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia el ns al espacio de nombres de pruebas:

```clojure
;; replace <exercise> with the exercise's name
=> (ns <exercise>-test)
nil
```

Después, llama a `run-tests`:

```clojure
=> (cljs.test/run-tests)
```
