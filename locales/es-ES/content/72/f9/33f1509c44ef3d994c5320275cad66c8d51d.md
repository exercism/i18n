# Pistas


## 1. Convertir Fahrenheit a Celsius

- Fahrenheit se puede convertir a Celsius restando 32 y dividiendo después entre 1,8.
- La división tiene mayor precedencia que la resta, así que hay que envolver la resta en un bloque o asignarla a una variable para que se realice primero.

## 2. Comparar dos temperaturas

- La coincidencia de patrones sobre el tipo `Temperature` se puede usar para extraer el valor de las variantes `Celsius` y `Fahrenheit`.
- Una vez convertidas ambas temperaturas a la misma unidad, se puede usar la función `float.compare` para compararlas.

## 3. Ordenar ciudades por temperatura

- La función [`list.sort`][list-sort] se puede usar para ordenar una lista con una función de comparación dada.
