## 1. Define una estructura Size

Define una estructura llamada `Size` con dos propiedades de tipo `Int`, `width` y `height`, que almacenan el ancho y el alto actuales de la ventana, respectivamente.
El ancho y el alto iniciales deben ser 80 y 60, respectivamente.
Incluye un método `resize(newWidth:newHeight:)` que recibe nuevos parámetros de ancho y alto y cambia las propiedades para reflejar el nuevo tamaño.

```swift
let size1080x764 = Size(width: 1080, height: 764)
// Returns Size
var size1200x800 = size1080x764
// Returns Size
size1200x800.resize(newWidth: 1200, newHeight: 800)
size1200x800.height
// Returns 800
```

## 2. Define una estructura Position

Define una estructura llamada `Position` con dos propiedades de tipo `Int`, `x` e `y`, que almacenan la posición horizontal y vertical actuales, respectivamente, de la esquina superior izquierda de la ventana.
Los valores iniciales de x e y deben ser 0. La posición (0, 0) es la esquina superior izquierda de la pantalla, con los valores de `x` que aumentan a medida que te mueves hacia la derecha y los valores de `y` que aumentan a medida que te mueves hacia abajo.

Incluye un método `moveTo(newX:newY:)` que recibe nuevos parámetros x e y y cambia las propiedades para reflejar la nueva posición.

```swift
var point = Position(x: 10, y: 20)
// Returns Position
point.moveTo(newX: 100, newY: -100)
point.y
// Returns -100
```

## 3. Define una clase Window

Define una clase ventana con las siguientes propiedades:

- `title` : `String`, el valor inicial es "New Window"
- `screenSize` : `Size`, valor constante con `width` = 800 y `height` = 600
- `size` : `Size`, el valor inicial es el valor predeterminado de la estructura `Size`
- `position` : `Position`, el valor inicial es el valor predeterminado de la estructura `Position`
- `contents` : `String?`, el valor inicial es `nil`

También debes definir un inicializador vacío para la clase.

```swift
let window = Window()
window.title
// Returns "New Window"
```

## 4. Añade un método para redimensionar ventanas

- `resize(to:)` : `(Size) -> ()` - Este método recibe una estructura `Size` como entrada e intenta redimensionar la ventana al tamaño especificado. Sin embargo, el nuevo tamaño no puede superar ciertos límites.
- La altura o el ancho mínimos permitidos son 1.
  Las alturas o anchos solicitados menores que 1 se recortarán a 1.
- La altura y el ancho máximos dependen de la posición actual de la ventana; los bordes de la ventana no pueden sobrepasar los bordes de la pantalla.
  Los valores mayores que estos límites se recortarán al tamaño más grande que puedan tomar.
  Por ejemplo, si la posición de la ventana está en `x` = 400, `y` = 300 y se solicita un redimensionado a `height` = 400, `width` = 300, entonces la ventana se redimensionaría a `height` = 300, `width` = 300, ya que la pantalla no es lo suficientemente grande en la dirección `y` para satisfacer completamente la solicitud.

## 5. Añade un método para mover ventanas

- `move(to:)` : `(Position) -> ()` - Esto es similar a `resize(to:)`, pero este método ajusta la _posición_ de la ventana al valor solicitado, en lugar del tamaño. Al igual que con `resize`, la nueva posición no puede superar ciertos límites.
- La posición más pequeña es 0 tanto para `x` como para `y`.
- La posición máxima en cualquier dirección depende del tamaño actual de la ventana; los bordes no pueden sobrepasar los bordes de la pantalla.
       Los valores mayores que estos límites se recortarán al tamaño más grande que puedan tomar. Por ejemplo, si el tamaño de la ventana está en `x` = 250, `y` = 100 y se solicita un movimiento a `x` = 600, `y` = 200, entonces la ventana se movería a `x` = 550, `y` = 200, ya que la pantalla no es lo suficientemente grande en la dirección `x` para satisfacer completamente la solicitud.

## 6. Añade métodos para actualizar el texto de la ventana y mostrar información de la ventana

- `update(title:)` : `(String) -> ()` - Este método establece la propiedad `title` al valor del string que se pasó.
- `update(text:)` : `(String?) -> ()` - Este método establece la propiedad `contents` al valor del string opcional que se pasó.
- `display()` : `() -> String` - Este método devuelve un string que describe el estado actual de la ventana. Por ejemplo, si la ventana tiene el `title` "My First Window" con posición: x = 10, y = 100; tamaño: width = 200, height = 150; y contents: "I 😍 my window", debería devolver el string: `"My First Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"` - Si `contents` es nil, la última línea debería decir "[This window intentionally left blank]"

## 7. Crea un inicializador para la clase Window

El sistema de ventanas debería tener un inicializador para que la ventana se pueda crear con entradas personalizadas.
Crea **otro** inicializador para la clase `Window`.
El inicializador debe recibir los siguientes parámetros: `title`, `contents`, y dos parámetros opcionales `size` y `position`.
Los parámetros `size` y `position` deben tener como valores predeterminados los valores predeterminados de las estructuras `Size` y `Position`.

```swift
let window = Window(title: "My First Window", contents: "I 😍 my window")
window.display()
// Returns "My First Window\nPosition: (0, 0), Size: (80 x 60)\nI 😍 my window\n"

let window2 = Window(title: "My Second Window", contents: "I 😍 my window", size: Size(width: 200, height: 150), position: Position(x: 10, y: 100))
window2.display()
// Returns "My Second Window\nPosition: (10, 100), Size: (200 x 150)\nI 😍 my window\n"
```
