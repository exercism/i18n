# Pistas

## General

- Los bucles `while` se usan para iteraciones _indefinidas_ (no contadas).
- Los bucles `for` se usan para iteraciones _definidas_ (contadas).
- Las palabras clave `break` y `continue` ayudan a personalizar el comportamiento de los bucles.
- `std::to_string()` de la biblioteca `string` se puede usar para convertir un número entero en string.

Además, estar familiarizado con lo siguiente puede ayudarte a completar las tareas:

- [`vectors`][vectors]: indexación, tamaño, [`<vector>.emplace_back`][emplace], [`<vector>.pop_back()`][pop].
- [`string`][string]: usar el `+` para concatenar strings, la conversión de enteros a string, [`to_string`][to\_string].

## 1. Redondear las puntuaciones

- Los bucles `While` seguirán ejecutándose hasta que la condición que evalúan sea `False`.
- `<vector>.back()` devuelve el último elemento de un `vector`.
- `<vector>.pop_back()` elimina el último elemento de un `vector`.

## 2. Estudiantes que suspenden

- Sí que necesitas crear un contador de resultados e _incrementarlo_; cuando el bucle termine, querrás devolver con `return` el recuento de estudiantes que suspenden.

## 3. Calcular las calificaciones con letra

- La puntuación necesaria para no suspender es siempre 41, ya que una «F» es **<= 40**. El resto del rango de puntuaciones, de 41 a la puntuación más alta, debe dividirse en cuatro intervalos iguales, uno por cada calificación con letra.
- Resta 40 a la puntuación más alta para obtener el rango total de puntuaciones que dan derecho a una calificación con letra (de la A a la D).
- Divide ese rango total entre 4 para obtener el tamaño de cada intervalo de calificación.
- Suma repetidamente ese tamaño de intervalo a 40 para calcular el límite inferior de cada calificación con letra.
- `static_cast<int>` sin parámetros redondeará bien los incrementos.
- Se espera que devuelvas un array, no un vector.

## 4. Asociar nombres con puntuaciones

- Si ambos contenedores tienen la misma longitud y están ordenados de la misma forma, ¿podrías usar el `index` de uno para obtener un `value` del otro?
- `std::to_string(int)` se puede usar para convertir un número en string.
- No olvides seguir el formato de la salida del ejemplo.

## 5. Una puntuación «perfecta»

- Puede que haya o que no haya un estudiante con una puntuación de 100, y no puedes devolver un string vacío sin comprobar **todas** las puntuaciones.
- Las instrucciones de `control flow` `continue` y `break` pueden ser útiles aquí para saltar los valores no deseados.
