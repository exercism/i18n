# Instalación


## Consigue GHCup

La forma recomendada de instalar las herramientas de Haskell es a través de [GHCup][ghcup].

Con GHCup puedes gestionar los compiladores que tengas instalados, los gestores de proyectos y paquetes, y el servidor de lenguaje.


## Instala Stack

Para hacer los ejercicios de Exercism solo necesitas Stack.

Para instalar Stack, ejecuta el comando o el script de instalación de GHCup.
Sigue las opciones predeterminadas, pero indica que también quieres instalar Stack.

¿Has omitido la instalación de Stack sin querer?
No pasa nada: basta con ejecutar `ghcup install stack` después.

GHCup instalará

- **Un compilador** (GHC: el Glasgow Haskell Compiler)

  En sentido estricto, no lo necesitas para Exercism, pero resulta útil cuando quieres trastear con [GHCi][ghc-guide-ghci] fuera de los directorios de ejercicios.

- **Cabal**

  Un gestor de proyectos y paquetes.
  No lo necesitas para Exercism.

- **Stack**

  El gestor de proyectos y paquetes que usarás para Exercism.
  Se encargará de que tengas el compilador y las bibliotecas adecuadas para cada proyecto (ejercicio) concreto.

Para comprobar que la instalación se ha realizado correctamente, ejecuta cualquiera de estos comandos:

- `ghcup list`: si todo ha ido bien, verás una larga lista de versiones de herramientas, con Stack marcado como instalado
- `stack --version`: si todo ha ido bien, verás algo como `Version 2.7.5, Git revision ...`


## Consigue la versión correcta de GHC

Stack descargará e instalará GHC automáticamente cuando sea necesario.
Puedes iniciar la instalación y verificarla ejecutando los siguientes comandos en un terminal:

```bash
# Note: it only makes sense to run Stack
# inside projects, so navigate into an
# exercise directory first!
exercism download --exercise=hello-world --track=haskell
cd ~/Exercism/haskell/hello-world
stack ghc -- --version
```

Si esto muestra algo como

```
The Glorious Glasgow Haskell Compilation System, version 8.8.4
```

significa que GHC está instalado correctamente.


## Configura tu editor para trabajar con Haskell

La compatibilidad con Haskell la proporciona el Haskell Language Server (HLS).
La compatibilidad con el lenguaje no es obligatoria, pero se recomienda encarecidamente.


### Visual Studio Code (recomendado)

Solo tienes que instalar la [extensión de Haskell para Visual Studio Code][vscode-haskell].
Usará GHCup para instalar HLS automáticamente, y con eso ya lo tendrás todo listo.

**Nota:** con ejercicios recién descargados, es posible que HLS tenga problemas para arrancar.
Si te ocurre esto, ejecuta `stack test` y reinicia el servidor de lenguaje.


### Otros editores

Consulta la [documentación de HLS sobre la configuración del editor][hls-editor-config].
Es posible que tengas que instalar HLS manualmente.
Para ello, ejecuta `ghcup install hls`.
