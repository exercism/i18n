# Instalación

Para estos problemas usamos el popular simulador de MIPS [MARS](https://dpetersanderson.github.io/Help/MarsHelpIntro.html). Descarga el archivo jar de MARS desde [GitHub](https://github.com/dpetersanderson/MARS/releases) y colócalo en un lugar de fácil acceso. Instala también el SDK de Java si aún no lo tienes.
