# Tests

Un REPL de ClojureScript te permite ejecutar código fácilmente y obtener respuesta inmediata, y también puedes usarlo para ejecutar los tests.

## Leiningen
Para abrir un REPL con la CLI de Clojure, cambia al directorio que contiene el ejercicio y ejecuta:
``` bash
$ clojure -m cljs.main -re node
```

Ten en cuenta que Node debe estar instalado en tu sistema.

Cuando estés listo para trabajar en un ejercicio y hayas creado un fichero para tu solución (como `bob.cljs`), puedes ejecutar los tests en tu terminal con `$ clojure -A:test`.

Primero, usa `require` con el espacio de nombres de test:
``` clojure
=> (require 'bob-test)
nil
;; and the test namespace
=> (require 'cljs.test)
```

Cambia el ns al espacio de nombres de test:
```clojure
=> (ns bob-test)
nil
```

Después, llama a `run-tests` sobre `bob-test`:
``` clojure
=> (cljs.test/run-tests)

Testing bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
{:test 14, :pass 14, :fail 0, :error 0, :type :summary}
```

Para ejecutar los tests de un ejercicio con la CLI de Clojure, simplemente llama a:
``` bash
$ clojure -M:test

Testing bob-tests

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
