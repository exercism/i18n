# Instrucciones

En este ejercicio, vas a implementar una forma de llevar un registro de las mejores puntuaciones del juego más popular del salón de recreativos de tu zona.

## 1. Añadir jugadores a la tabla de mejores puntuaciones

Para añadir un jugador a la tabla de mejores puntuaciones, define dos métodos `add_player!` que reciben los siguientes argumentos:

- El primer argumento es el diccionario de puntuaciones.
- El segundo argumento es el nombre de un jugador como string.
- El tercer argumento es la puntuación como número entero.
  Este argumento es opcional; cuando no se proporcione un valor, la puntuación debe establecerse en 0.

```julia-repl
julia> scores = Dict{String, Int}()
Dict{String, Int64}()

julia> add_player!(scores, "Liselot", 486373)
Dict{String, Int64} with 1 entry:
  "Liselot" => 486373

julia> add_player!(scores, "Éimhín")
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0
```

## 2. Eliminar jugadores de la tabla de puntuaciones

Para eliminar un jugador de la tabla de puntuaciones, define `remove_player!`, que recibe 2 argumentos:

- El primer argumento es el diccionario de puntuaciones.
- El segundo argumento es el nombre del jugador como string.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> remove_player!(scores, "Liselot")
Dict{String, Int64} with 1 entry:
  "Éimhín" => 0
```

## 3. Actualizar la puntuación de un jugador

Para actualizar la puntuación de un jugador reemplazando la puntuación anterior, define `update_score!`, que recibe 3 argumentos:

- El primer argumento es el diccionario de puntuaciones.
- El segundo argumento es el nombre del jugador como string, cuya puntuación deseas actualizar.
- El tercer argumento es la puntuación que deseas establecer como la nueva puntuación almacenada.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> update_score!(scores, "Éimhín", 89479) # TODO: Should this return the dict?
89479

julia> scores

  "Liselot" => 486373
  "Éimhín"  => 89479
```

## 4. Restablecer la puntuación de un jugador

Para restablecer la puntuación de un jugador, define `reset_score!`, que recibe 2 argumentos:

- El primer argumento es el diccionario de puntuaciones.
- El segundo argumento es el nombre del jugador como string, cuya puntuación deseas restablecer.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> reset_score!(scores, "Liselot") # TODO: Should this return the dict?
0

julia> scores

  "Liselot" => 0
  "Éimhín"  => 0
```

## 5. Obtener un array de jugadores

Para obtener un array de jugadores, define `players`, que recibe 1 argumento:

- El primer argumento es el diccionario de puntuaciones.

```julia-repl
julia> scores = Dict(
           "Liselot" => 486373,
           "Éimhín"  => 0,
       )
Dict{String, Int64} with 2 entries:
  "Liselot" => 486373
  "Éimhín"  => 0

julia> players(scores)
2-element Vector{String}:
 "Liselot"
 "Éimhín"
```
