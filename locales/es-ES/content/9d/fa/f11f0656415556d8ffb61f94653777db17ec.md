# Instrucciones

En este ejercicio vas a escribir código para analizar la producción en una fábrica de coches.

## 1. Calcular el número de coches que funcionan producidos por hora

Los coches se producen en una cadena de montaje.
La cadena de montaje tiene una velocidad determinada, que se puede cambiar.
Cuanto mayor es la velocidad de la cadena de montaje, más coches se producen.
Sin embargo, cambiar la velocidad de la cadena de montaje también cambia el número de coches que se producen con éxito, es decir, coches sin ningún error en su producción.

Implementa una función que reciba el número de coches producidos por hora y la tasa de éxito, y calcule el número de coches producidos con éxito por hora.
La tasa de éxito se da como un porcentaje, de `0` a `100`:

```go
CalculateWorkingCarsPerHour(1547, 90)
// => 1392.3
```

**Nota:** el valor devuelto debe ser un `float64`.

## 2. Calcular el número de coches que funcionan producidos por minuto

Implementa una función que reciba el número de coches producidos por hora y la tasa de éxito, y calcule cuántos coches se producen con éxito cada minuto:

```go
CalculateWorkingCarsPerMinute(1105, 90)
// => 16
```

**Nota:** el valor devuelto debe ser un `int`.

## 3. Calcular el coste de producción

Normalmente, producir cada coche por separado cuesta 10.000 $, independientemente de si tiene éxito o no.
Pero con un poco de planificación, se pueden producir 10 coches juntos por 95.000 $.

Por ejemplo, 37 coches se pueden producir de la siguiente manera:
37 = 3 x grupos de diez + 7 coches individuales

Así que el coste de 37 coches es:
3\*95.000+7\*10.000=355.000

Implementa la función `CalculateCost` que calcula el coste de producir un número de coches, independientemente de si tienen éxito o no:

```go
CalculateCost(37)
// => 355000

CalculateCost(21)
// => 200000
```

**Nota:** el valor devuelto debe ser un `uint`.
