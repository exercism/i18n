# Acerca de

Los [verbatim strings][verbatim-strings] permiten escribir strings de varias líneas. Se introducen con una @. Se pueden usar con interpolación de strings. Basta con añadir un «\$» delante de la comilla de apertura.

```csharp
string str = @"
See no wretched
quotes everywhere
";
```

[verbatim-strings]: https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/strings/#regular-and-verbatim-string-literals
