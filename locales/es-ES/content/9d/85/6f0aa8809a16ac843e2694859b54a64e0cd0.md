# Instrucciones

En este ejercicio escribirás código para ayudar a una empresa de carteles a crear mensajes personalizados para sus carteles.

## 1. Crea un conjunto de strings útiles

Define los siguientes strings constantes que se usarán para crear carteles:

- `birthday`: contiene el valor "Birthday"
- `valentine`: contiene el valor "Valentine's Day"
- `anniversary`: contiene el string "Anniversary"

## 2. Crea un conjunto de caracteres útiles

Define los siguientes caracteres constantes que se usarán para crear carteles:

- `space`: contiene el valor " " (un solo espacio)
- `exclamation`: contiene el valor "!"

## 3. Combina frases para construir mensajes

Implementa la función `buildSign(for:name:)`, que recibe el argumento `for`, que contiene uno de los tres strings que definiste en la primera tarea, y el argumento `name`, que es un string que contiene el nombre de la persona a la que va dirigido el cartel.
Usa concatenación para construir el mensaje del cartel y recuerda reutilizar las constantes ya definidas.
La función debe devolver el mensaje del cartel como un string.

```swift
buildSign(for: birthday, name: "Otto")
// returns "Happy Birthday Otto!"

buildSign(for: anniversary, name: "Valentina")
// returns "Happy Anniversary Valentina!"
```

## 4. Crea un cartel de graduación

Implementa la función `graduationFor(name:year:)`, que recibe el argumento `name`, que es un string que contiene el nombre de la persona a la que va dirigido el cartel, y el argumento `year`, que es un número entero que contiene el año en el que se gradúa la persona.
Usa plantillas de string para construir el mensaje del cartel.
La función debe devolver el mensaje del cartel como un string.

```swift
graduationFor(name: "Padma", year: 2023)
// returns "Congratulations Padma!\nClass of 2023"
```

## 5. Calcula el coste de un cartel

Implementa la función `costOf(sign:)`, que recibe el argumento `sign`, que es un string que contiene el mensaje del cartel.
El cartel tiene un precio base de 20 en la moneda indicada. Además, cada letra cuesta 2 (los espacios en blanco se incluyen en el cálculo).
La función debe devolver el coste del cartel como un número entero.

```swift
costOf(sign: "Happy Birthday Grandma!")
// returns 66
```
