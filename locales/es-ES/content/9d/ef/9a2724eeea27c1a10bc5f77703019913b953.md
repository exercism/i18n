# Introducción

## Casting

El casting y la conversión de tipos son dos formas distintas de cambiar una expresión de un tipo de datos a otro.

Puedes hacer casting de una expresión a otro tipo con el operador de conversión `(<type>)`.

```csharp
long l = 1000L;
int i = (int)l;

object o = new Random();
Random r = (Random)o;
```

Si los tipos no son compatibles, se lanza una instancia de `InvalidCastException`. En el caso de los números, esto indica que el tipo de destino no puede representar el valor convertido. En el caso de las clases, uno de los tipos debe derivar del otro (esto también se cumple, de forma trivial, en las estructuras).

Una alternativa al _casting_ es la _conversión de tipos_ mediante el operador `is`. Normalmente, esta se aplica a tipos de referencia y a tipos anulables.

```csharp
object o = new Random();
if (o is Random rand)
{
    int ii = rand.Next();
    // now, do something random
}
```

Si necesitas detectar el tipo exacto de un objeto, `is` puede resultar demasiado permisivo, ya que devolverá true para una clase y para cualquiera de las clases e interfaces de las que derive, directa o indirectamente. En este caso, la solución es `typeof` y `Object.GetType()`.

```csharp
object o = new List<int>();

o is ICollection<int> // true
o.GetType() == typeof(ICollection<int>) // false
o is List<int> // true
o.GetType() == typeof(List<int>) // true
```
