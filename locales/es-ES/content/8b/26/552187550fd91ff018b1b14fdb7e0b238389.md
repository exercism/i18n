# Instrucciones

Tras una reciente revisión de seguridad, se te ha pedido que limpies los archivos de registro archivados de la organización.

## 1. Identifica las líneas de registro corruptas

Necesitas hacerte una idea de cuántas líneas de registro de tu archivo no cumplen con los estándares actuales.
Crees que una prueba sencilla revela si una línea de registro es válida.
Para considerarse válida, una línea debe empezar por uno de los siguientes strings:

- `[DEBUG]`
- `[INFO]`
- `[WARNING]`
- `[ERROR]`

Implementa la función `is_valid_line` para que devuelva `True` si la línea de registro es válida.

```gleam
log_parser.valid_line("[ERROR] Network Failure")
// -> True

log_parser.valid_line("Network Failure")
// -> False
```

## 2. Divide la línea de registro

Poco después de empezar el proyecto de análisis de registros, te das cuenta de que los registros de una aplicación no están divididos en líneas como los demás. En este proyecto, lo que deberían haber sido líneas separadas está, en cambio, en una sola línea, unido por flechas llamativas como `<--->` o `<*~*~>`.

De hecho, cualquier string que tenga `<` como primer carácter, `>` como último carácter y cero o más de los siguientes caracteres `~`, `*`, `=` y `-` entre ellos puede usarse como separador en los registros de este proyecto.

Implementa la función `split_line`, que recibe una línea y devuelve un array de strings.

```gleam
log_parser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
// -> ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Etiqueta las líneas con nombres de usuario

Te has dado cuenta de que algunas líneas de registro incluyen frases que se refieren a usuarios.
Estas frases siempre contienen el string `"User"`, seguido de uno o más espacios en blanco y, a continuación, un nombre de usuario.
Decides etiquetar esas líneas.

Implementa una función `tag_with_user_name` que procese líneas de registro:

- Las líneas que no contengan el string `"User"` se mantienen sin cambios.
- En las líneas que contengan el string `"User"`, añade al principio de la línea `[USER]` seguido del nombre de usuario.

```gleam
log_parser.tag_with_user_name("[INFO] User Alice created a new project")
// -> "[USER] Alice [INFO] User Alice created a new project"
```

Puedes suponer que:

- Cada aparición del string `"User"` va seguida de uno o más espacios en blanco y del nombre de usuario.
- Hay como máximo una aparición del string `"User"` en cada línea.
- Los nombres de usuario son strings no vacíos que no contienen espacios en blanco.
