# Introducción

En Gleam hay dos tipos diferentes de números: enteros y decimales.

Los enteros son números sin parte decimal.

```gleam
let integer = 3
// -> 3
```

También se pueden añadir guiones bajos a los enteros para mayor claridad.

```gleam
1_000_000 // One million
```

Gleam tiene varios operadores que funcionan con enteros.

```gleam
1 + 1 // -> 2
5 - 1 // -> 4
5 / 2 // -> 2
3 * 3 // -> 9
5 % 2 // -> 1

2 > 1  // -> True
2 < 1  // -> False
2 >= 1 // -> True
2 <= 1 // -> False
```
