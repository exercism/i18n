# Flujo de trabajo de despliegue

El flujo de trabajo de despliegue se usa para desplegar las herramientas del track en:

1. [Docker Hub](https://hub.docker.com/): se usa en scripts o para pruebas locales.
   De acceso público.
2. [ECR](https://aws.amazon.com/ecr/): se usa en el entorno de producción para probar soluciones enviadas.
   Privado.

## Origen

El flujo de trabajo se define en el archivo `.github/workflows/deploy.yml`.
