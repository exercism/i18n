# Pistas

## General

- La [documentación de la API de `Map`][map-docs] contiene una lista de métodos disponibles en la interfaz `Map`.

## 1. Devolver los códigos en un mapa

- Tendrás que definir un `Map` de [tal forma][declaring-members] que puedas usarlo en los métodos de la clase.

## 2. Añadir entradas al diccionario

- Los mapas tienen un [método][map-put-docs] para añadir y actualizar el valor de una clave.

## 3. Buscar el país de un código de marcado

- Los mapas tienen un [método][map-get-docs] para obtener el valor de la clave.

## 4. No permitir duplicados

- Hay una forma de comprobar si el mapa tiene una [clave][map-contains-key-docs] o un [valor][map-contains-value-docs].

## 5. Encontrar el código de marcado de un país

- Hay una [forma][map-entry-set-docs] de obtener una colección iterable de entradas de un mapa, lo que te permite recorrer los pares clave-valor.

## 6. Actualizar el código de marcado del país

- No olvides que el código de marcado anterior del país seguirá estando en el mapa.
- Hay un [método][map-remove-docs] para eliminar una entrada del mapa.
