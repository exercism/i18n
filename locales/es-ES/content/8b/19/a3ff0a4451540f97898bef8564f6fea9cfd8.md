# Pistas

## 1. Obtén el mensaje de una línea de registro

- Extrae el texto que sigue a los _primeros_ dos puntos.
  - Puedes usar `index/1` y la notación de rebanadas.
  - O explora usando las funciones de expresiones regulares.
- Usa la función `trim` que se proporciona.

## 2. Obtén el nivel de registro de una línea de registro

- Extrae el texto que hay dentro del primer par de corchetes (`[]`).
- Muestra el resultado en minúsculas.

## 3. Reformatea una línea de registro

- Reutiliza las funciones existentes.
- Dos formas de hacerlo son usar la interpolación de string o la concatenación.
