# Introducción

En Elixir, para elegir un elemento aleatorio de una estructura de datos enumerable (p. ej. lista, rango), usamos `Enum.random`. Esta función elige un único elemento, y todos los elementos tienen la misma probabilidad de ser elegidos.

Elixir no tiene funciones propias para elegir un número decimal aleatorio. Para ello, tenemos que usar Erlang directamente.
