# Instrucciones

Tu tarea es crear un verificador de contraseñas.
Un verificador de contraseñas valida la contraseña propuesta por un usuario para asegurarse de que cumple una serie de requisitos definidos por la organización que controla el acceso al recurso en cuestión.

Para este ejercicio, los requisitos de la contraseña son:
* Debe tener 12 caracteres o más
* Debe tener al menos una letra mayúscula
* Debe tener al menos una letra minúscula
* Debe tener al menos un dígito
* Debe tener al menos un símbolo del conjunto !@#$%^&*

Tu solución debe usar un `Result` para encapsular el estado de éxito o de fallo.
En el caso de éxito, el `Result` debe contener la contraseña validada como string.
En el caso de fallo, el `Result` debe contener la regla que se ha incumplido.

~~~~exercism/note
Para este ejercicio, el verificador de contraseñas será muy simple: solo indicará cuándo se ha incumplido una única regla.
En un ejercicio posterior veremos un verificador de contraseñas más realista, capaz de indicar cuándo se han incumplido varias reglas a la vez.
~~~~

## 1. Implementa la función `checkPassword`

La función `checkPassword` comprueba la contraseña dada con los requisitos mencionados.  Si falla, indica la regla que se ha incumplido encapsulando uno de los valores de `PasswordRule` dentro del valor del resultado.

```fsharp
checkPassword "abcdefghij5#"
// => Error MissingUppercaseLetter
```

## 2. Implementa la función ``getStatusMessage`

La función `getStatusMessage` devuelve un string que contiene un mensaje legible para las personas e indica el significado del resultado devuelto por `checkPassword`.

```fsharp
getStatusMessage (Error MissingDigit)
// => "Error: does not have at least one digit"
```
