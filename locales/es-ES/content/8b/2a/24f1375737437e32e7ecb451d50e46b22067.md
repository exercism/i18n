# Introducción

El filtrado es el proceso de crear una secuencia a partir de otra secuencia copiando todos los elementos de la secuencia original excepto algunos.
La elección de qué elementos incluir en la nueva secuencia se puede hacer mediante una función predicado (una función que evalúa a un valor booleano) o por igualdad con un objeto concreto.

## Eliminar mediante un predicado

`remove-if` es una función que toma una función predicado y una secuencia como argumentos, y devuelve una secuencia solo con aquellos elementos para los que el predicado evaluó a un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los que el predicado evalúa a verdadero. Sin embargo, ¡ten en cuenta que esta función no modifica la secuencia original!
En su lugar, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado era verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

## Eliminar un elemento concreto

Si se quiere eliminar un elemento concreto de una secuencia, se puede usar `remove`, que toma el elemento que se quiere eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no son iguales al elemento que se quiere eliminar.
NOTA: la igualdad se comprueba con el `eql` [predicado genérico de igualdad][concept-equality] de forma predeterminada.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
