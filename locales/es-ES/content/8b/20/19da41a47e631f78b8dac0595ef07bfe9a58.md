# Instrucciones específicas de SQLite

La columna **result** debe contener un objeto de objetos codificado en JSON, con cada palabra como clave y su recuento como número entero.

Por ejemplo, fíjate en la frase anterior: `"That's the password: 'PASSWORD 123'!", cried the Special Agent.\nSo I fled.`
El valor de **result** para esta entrada debería ser:

```json
{"123":1,"agent":1,"cried":1,"fled":1,"i":1,"password":2,"so":1,"special":1,"that's":1,"the":2}
```

## Esquema de la tabla

```sql
CREATE TABLE "word-count" (
    sentence TEXT NOT NULL,
    result   TEXT               -- json object
);
```
