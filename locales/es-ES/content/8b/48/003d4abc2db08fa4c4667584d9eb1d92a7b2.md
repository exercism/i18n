# Introducción

En última instancia, los dígitos binarios se corresponden directamente con los transistores de tu CPU o RAM, y con si cada uno está «encendido» o «apagado».

La manipulación de bajo nivel, llamada informalmente «trasteo de bits», es especialmente importante en los lenguajes de sistema.

Los lenguajes de alto nivel como Julia suelen abstraer la mayor parte de este detalle.
Sin embargo, el lenguaje base ofrece una gama completa de operaciones a nivel de bits.

***Nota:*** Para ver la salida binaria legible para humanos en el REPL, casi todos los ejemplos siguientes deben envolverse en una función `bitstring()`.
Esto distrae visualmente, así que se han eliminado la mayoría de las apariciones de esta función.

## Operaciones de desplazamiento de bits

Los tipos enteros, con signo o sin signo, pueden representarse como una cadena de unos y ceros.

```julia-repl
julia> bitstring(UInt8(5))
"00000101"
```

Los desplazamientos de bits simplemente mueven todo a la izquierda o a la derecha un número determinado de posiciones.
Con los tipos `UInt`, algunos bits se pierden por un extremo y el otro extremo se rellena con ceros:

```julia-repl
julia> ux::UInt8 = 5
5

julia> bitstring(ux)
"00000101"

julia> ux << 2 # left by 2
"00010100"

julia> ux >> 1 # right by 1
"00000010"
```

Cada desplazamiento a la izquierda duplica el valor y cada desplazamiento a la derecha lo reduce a la mitad (sujeto a truncamiento).
Esto es más evidente en la representación decimal:

```julia-repl
julia> 3 << 2
12

julia> 24 >> 3
3
```

Este tipo de desplazamiento de bits es mucho más rápido que la aritmética «convencional», lo que hace que la técnica sea muy popular en la programación de bajo nivel.

Con los enteros con signo, debemos tener un poco más de cuidado.

Los desplazamientos a la izquierda son relativamente sencillos:

```julia-repl
julia> sx = Int8(5)
5

julia> sx # positive integer
"00000101"

julia> sx << 2
"00010100"

julia> -sx # negative integer
"11111011"

julia> -sx << 2
"11101100"
```

Así pues, desplazar a la izquierda enteros positivos con signo es lo mismo que con enteros sin signo.

Los valores negativos se almacenan en forma de [complemento a dos][2complement], lo que significa que el bit más a la izquierda es 1.
No hay problema para un desplazamiento a la izquierda, pero al desplazar a la derecha, ¿cómo rellenamos los bits más a la izquierda?

```julia-repl
julia> sx >> 2 # simple for positive values!
"00000001"

julia> -sx # negative integer
"11111011"

julia> -sx >> 2 # pad with repeated sign bit
"11111110"

julia> -sx >>> 2 # pad with 0
"00111110"
```

El operador `>>` realiza un desplazamiento aritmético, conservando el bit de signo.

El operador `>>>` realiza un desplazamiento lógico, rellenando con ceros como si el número no tuviera signo.

## Lógica bit a bit

Vimos en un concepto anterior que los operadores `&&` (y), `||` (o) y `!` (no) se usan con valores Boolean.

Existen operadores equivalentes `&` (y bit a bit), `|` (o bit a bit) y `~` (una tilde, no bit a bit) para comparar los bits de dos números enteros.

```julia-repl
julia> 0b1011 & 0b0010 # bit is 1 in both numbers
"00000010"

julia> 0b1011 | 0b0010 # bit is 1 in at least one number
"00001011"

julia> ~0b1011 # flip all bits
"11110100"

julia> xor(0b1011, 0b0010) # bit is 1 in exactly one number, not both
"00001001"
```

Aquí, `xor()` es el OR exclusivo, usado como función.

[2complement]: https://en.wikipedia.org/wiki/Two%27s_complement
