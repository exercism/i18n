# Introducción

## Recursión

Las funciones recursivas son funciones que se llaman a sí mismas.

Una función recursiva necesita tener al menos un _caso base_ y al menos un _caso recursivo_.

Un _caso base_ devuelve un valor sin volver a llamar a la función.
Un _caso recursivo_ vuelve a llamar a la función modificando la entrada para que en algún momento coincida con el caso base.

En Elm, las funciones recursivas se suelen definir usando coincidencia de patrones con expresiones `case` o con varias cláusulas de función.

```elm
count : List a -> Int
count list =
    case list of
        [] ->
            0  -- base case

        _ :: tail ->
            1 + count tail  -- recursive case
```

### Bucles mediante recursión

Debido a la inmutabilidad, los bucles en Elm se escriben de forma distinta a los lenguajes imperativos.
Por ejemplo, los bucles suelen tener este aspecto:

```c
for(i = 0; i < array.length; i++) {
  // do something with array[i]
}
```

En un lenguaje funcional como Elm, no es posible mutar variables.
Por lo tanto, los bucles tienen que implementarse con recursión.

El equivalente de un bucle `for` en Elm sería así:

```elm
loop : List a -> (a -> b) -> List b
loop list f =
    case list of
        [] ->
            []

        head :: tail ->
            f head :: loop tail f
```

En la práctica, iterar sobre arrays y otras estructuras de datos en Elm se hace casi siempre con funciones del módulo `List`, como `List.map`, `List.filter` y `List.foldl`.
Internamente, estas funciones están implementadas con recursión.
