# Instrucciones

Estás desarrollando el nuevo y muy valorado juego **Crystal Hunter**.
En el juego, eres un personaje que se mueve y recoge cristales.
El jugador gana cuando recoge todos los cristales.
Si el jugador entra en contacto con un bandido, perderá todos sus cristales y la partida.
Hay una excepción a esta regla: el jugador puede tener activo un potenciador que lo hace invisible para los bandidos.

Tu objetivo es escribir algunas reglas que se usarán en el juego.

## 1. Define si el personaje obtiene puntos extra

En el juego, el personaje obtiene puntos extra si toca a un bandido mientras tiene un potenciador.

Define el método `Rules#bonus_points?`, que recibe dos argumentos (_si el personaje tiene un potenciador activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje obtendrá puntos extra.
El método debe devolver `true` únicamente si el personaje tiene un potenciador activo y está tocando a un bandido, y `false` en caso contrario.

```Crystal
Rules.new.bonus_points?(false, true)
# => false
```

## 2. Define si el personaje puntúa

El jugador obtiene puntos en el juego cuando recoge un cristal o un potenciador.

Define el método `Rules#score?`, que recibe dos argumentos (_si el personaje está tocando un potenciador_ y _si el personaje está tocando un cristal_) y devuelve un valor Boolean que indica si el personaje ha puntuado o no.
El método debe devolver `true` si el personaje toca un potenciador o un cristal, y `false` en caso contrario.

```crystal
Rules.new.score?(true, true)
# => true
```

## 3. Define si el personaje pierde

Define el método `Rules#lose?`, que recibe dos argumentos (_si el personaje tiene un potenciador activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje pierde o no.
El método debe devolver `true` si el personaje toca a un bandido y no tiene un potenciador activo, y `false` en caso contrario.

```crystal
Rules.new.lose?(false, true)
# => true
```

## 4. Define si el personaje gana

Define el método `Rules#win?`, que recibe tres argumentos (_si el personaje ha recogido todos los cristales_, _si el personaje tiene un potenciador activo_ y _si el personaje está tocando a un bandido_) y devuelve un valor Boolean que indica si el personaje gana o no.
El método debe devolver `true` si el personaje ha reunido todos los cristales y no ha perdido según los argumentos definidos en el apartado 3, y `false` en caso contrario.

```crystal
Rules.new.win?(false, true, false)
# => false
```
