# Debug

Cuando un test falla, se muestra un mensaje que describe qué salió mal y para qué entrada. Además, puedes aprovechar que cualquier [salida por consola][programiz.com-basic-input-output] también se mostrará. Puedes escribir en la consola usando:

```csharp
Console.WriteLine("Debug message");
```
