# Pistas

## General

- Lee sobre el [módulo `Agent`][getting-started-agent] en la guía de introducción.
- Lee la documentación sobre el [módulo `Agent`][elixir-doc-agent].
- Mira [ElixirCasts: Introduction to Agents][elixircasts-agent].

## 1. Abre el jardín

- Revisa la documentación de [`Agent`][elixir-doc-agent].
- La función que inicializa el estado del _proceso agente_ debe devolver el estado inicial.

## 2. Lista los registros

- El módulo [`Agent`][elixir-doc-agent] contiene muchas funciones para obtener el estado actual del _proceso agente_.

## 3. Registra parcelas a una persona

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener y actualizar el estado del _proceso agente_.
- Por lo general, estas funciones requieren una función que transforme el estado y devuelva una forma concreta.
- Para llevar un seguimiento del id de la próxima parcela que hay que asignar, el estado de tu _proceso agente_ debe llevar un registro de las parcelas y también del próximo id que hay que usar para una parcela.

## 4. Libera parcelas

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener y actualizar el estado del _proceso agente_.
- Por lo general, estas funciones requieren una función que transforme el estado y devuelva el estado siguiente.

## 5. Obtén una parcela registrada

- El módulo [`Agent`][elixir-doc-agent] contiene funciones para obtener el estado del _proceso agente_.
- Obtén la parcela y, a continuación, procesa el resultado para devolver el resultado correcto.
