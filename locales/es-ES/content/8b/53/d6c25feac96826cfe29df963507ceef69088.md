# Introducción

## Tipos enumerados

Un _tipo enumerado_ es un tipo de dato especial que permite que una variable sea un conjunto de constantes predefinidas.
La variable debe ser igual a uno de los valores que se han predefinido para ese tipo.
Entre los ejemplos habituales están los puntos cardinales (valores `NORTH`, `SOUTH`, `EAST` y `WEST`) y los días de la semana.

Como son constantes, los nombres de los campos de un tipo enumerado se escriben en mayúsculas.

### Definir un tipo enumerado

En el lenguaje de programación Java, defines un tipo enumerado con la palabra clave `enum`.
Por ejemplo, un tipo enumerado con los días de la semana se especificaría así:

```java
public enum DayOfWeek {
    SUNDAY,
    MONDAY,
    TUESDAY,
    WEDNESDAY,
    THURSDAY,
    FRIDAY,
    SATURDAY
}
```

Deberías usar tipos enumerados siempre que necesites representar un conjunto fijo de constantes.
Eso incluye tipos enumerados naturales, como los planetas de nuestro sistema solar, y conjuntos de datos en los que conoces todos los valores posibles en tiempo de compilación; por ejemplo, las opciones de un menú, los indicadores de línea de comandos, etcétera.

### Usar un tipo enumerado

Aquí tienes código que te muestra cómo usar el tipo enumerado `DayOfWeek` definido antes:

```java
public class Shop {
    public String getOpeningHours(DayOfWeek dayOfWeek) {
        switch (dayOfWeek) {
            case MONDAY:
            case TUESDAY:
            case WEDNESDAY:
            case THURSDAY:
            case FRIDAY:
                return "9am - 5pm";
            case SATURDAY:
                return "10am - 4pm"
            case SUNDAY:
                return "Closed.";
        }
    }
}
```

```java
var shop = new Shop();
shop.getOpeningHours(DayOfWeek.WEDNESDAY);
// => "9am - 5pm"
```

### Añadir métodos y campos

Los tipos enumerados del lenguaje de programación Java son mucho más potentes que sus equivalentes en otros lenguajes.
La declaración `enum` define una _clase_ (llamada _tipo enumerado_).
El cuerpo de la clase enum puede incluir métodos y otros campos:

```java
public enum Rating {
    GREAT(5),
    GOOD(4),
    OK(3),
    BAD(2),
    TERRIBLE(1);

    private final int numberOfStars;

    Rating(int numberOfStars) {
        this.numberOfStars = numberOfStars;
    }

    public int getNumberOfStars() {
        return this.numberOfStars;
    }
}
```

Llamar al método `getNumberOfStars` en un miembro del tipo enumerado `Rating`:

```java
Rating.GOOD.getNumberOfStars();
// => 4
```
