# Consejos para depurar en `jq`

`jq` incluye un filtro [`debug`][debug] muy práctico.
Úsalo mientras trabajas en tus soluciones de los ejercicios para inspeccionar los datos que hay en ese momento en la canalización de `jq`.

`debug` imprime un «array de depuración» en **stderr**.
Devuelve la entrada sin cambios.
El primer elemento del array es el string «DEBUG:».
El segundo elemento depende de cómo invoques `debug`.

1. la función debug sin argumentos coloca una representación compacta de la entrada en el array de depuración:

   ```sh
   jq -n '[11, 22, 33] | debug | map(. * 2)'
   ```

   produce:

   ```none
    ["DEBUG:",[11,22,33]]
    [
      22,
      44,
      66
    ]
   ```

2. la versión de un argumento canaliza la entrada por el filtro indicado:

   ```sh
   jq -n '[11, 22, 33] | debug("length: \(length), last: \(.[-1])") | map(. * 2)'
   ```

   ```none
    ["DEBUG:","length: 3, last: 33"]
    [
      22,
      44,
      66
    ]
   ```

   El filtro no tiene por qué ser un string.
   Puede ser cualquier cosa, incluidas varias expresiones separadas por comas para obtener una salida de depuración «multilínea»:

   ```sh
   jq -n '[11, 22, 33] as $a | 44 | debug("I am here:", $a, .)'
   ```

   ```none
   ["DEBUG:","I am here:"]
   ["DEBUG:",[11,22,33]]
   ["DEBUG:",44]
   44
   ```

[debug]: https://jqlang.org/manual/#debug
