# Acerca de

El tipo `Option` es una enumeración proporcionada por la biblioteca estándar. Es útil para expresar un valor que puede que no exista.
Aunque pueda sonar a `null` o `nil`, es bastante diferente y especial.

`Option<T>` contiene otros tipos y tiene dos variantes: `Some(T)` y `None`.

Por ejemplo, `Option<u32>` contiene el tipo `u32`.

## Uso

### Cómo usar la `T` dentro de `Option<T>`

Hay varios modismos comunes para usar el valor que podría estar presente en un `Option`:

- `if let Some(t) = optional { ... }`.

    El modismo `if let` extrae el valor de un `Option<T>` y lo vincula a la variable `t`. Esto te permite usarlo directamente en el scope de ese bloque.

- `match optional { Some(t) => {...}, None => {...}}`

    El operador `match` también te permite desempaquetar y gestionar los casos `None` en una sola instrucción o expresión. Es una alternativa a una cadena de instrucciones if y else. Usar `match` puede aumentar la legibilidad de algunas secciones de código.
- `optional.map(|t| ...)`
   `Option::map` actualiza un Option in situ, posiblemente con un tipo nuevo, mediante la función proporcionada.

   **Nota**: opera sobre el valor contenido si está presente. La vinculación pasa a ser un `Option<U>`, donde el closure dado es `FnOnce(T) -> U`.
- `optional.unwrap()`.
   Desempaquetar un `Option<T>` extrae `T`, pero provocará un panic si `T` no está ahí. En algunos casos resulta práctico.

   **Importante**: Desempaquetar puede facilitar el desarrollo a corto plazo o en el código de test, pero introduce la posibilidad de panics en tiempo de ejecución. Conviene evitarlo cuando sea posible.

- `optional.expect("Unexpected None found! Aborting program.)`.
   El método `expect` de `Option<T>` es bastante similar a `unwrap()`, pero provocará un panic con el mensaje proporcionado si el valor es `None`.

## Ejemplos

Cuando existe un valor en un `Option<u32>`:

```rust
let has_something: Option<u32> = Some(100);
assert_eq!(has_something.unwrap(), 100);
```

Cuando un valor *no* existe en un `Option<u32>`:

```rust
let has_nothing: Option<u32> = None;
assert_eq!(has_nothing, None);
```
