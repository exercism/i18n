# Pistas

## 1. Crea el identificador de los puertos

- Tienes que definir una [constante][constants] que contenga el valor de símbolo indicado en las instrucciones.

## 2. Obtén los identificadores de otros puertos

- Se puede [cortar][slice] una cadena para obtener partes de ella.
- Las `Strings` tienen un [método][upcase] para poner las letras en mayúsculas.
- Las `Strings` tienen un [método][to_sym] para convertir una cadena en un símbolo.

## 3. Determina en qué terminal debe atracar un barco

- Symbol tiene un [método][to_s] para convertir un símbolo en una cadena.
- Se puede [cortar][slice] una cadena para obtener partes de ella.
- Usa el condicional [`if`][doc-if] para comprobar si el barco transporta `"OIL"` o `"GAS"`.
