# Anexo de instrucciones

## Cómo está estructurado este ejercicio en el track de Python

Los tests de este ejercicio esperan que crees una `class` Matrix (ver también [concept:python/classes]()).
Esto es diferente de _usar_ un objeto Matrix de una biblioteca de terceros como [Numpy][numpy-matrix], que no es compatible.
 _¡No te preocupes, no es tan complicado como crees!_
 Para más puntos de partida y detalles sobre las `classes` y las estructuras de datos, echa un vistazo a los recursos que tienes a continuación:


-   [**Un primer vistazo a las clases**](https://docs.python.org/3/tutorial/classes.html#a-first-look-at-classes) de la documentación de Python 3. 
-   [**Cómo definir una clase en Python**](https://realpython.com/python3-object-oriented-programming/#how-to-define-a-class-in-python) del sitio web Real Python.  
-   [**Estructuras de datos en Python**](https://docs.python.org/3/tutorial/datastructures.html) de la documentación de Python 3.

[numpy-matrix]: https://numpy.org/doc/stable/reference/generated/numpy.matrix.html
