# Pruebas

Antes de intentar ejecutar las pruebas, asegúrate de que la carpeta del ejercicio esté configurada correctamente siguiendo los pasos de instalación, es decir, `corepack yarn install` y la configuración del Editor SDK.

Ejecuta las pruebas con:

```bash
$ corepack yarn test
```

## Pruebas omitidas

En los conjuntos de pruebas se han omitido todas las pruebas excepto la primera.

Cuando consigas que una prueba pase, puedes habilitar la siguiente cambiando `xit` por `it`.
Además, las pruebas pueden agruparse con `xdescribe`.
Habilita el grupo cambiándolo por `describe`.
Por último, algunos ejercicios pueden tener pruebas opcionales `it.skip`.
Elimina `.skip` para ejecutar la prueba opcional.
