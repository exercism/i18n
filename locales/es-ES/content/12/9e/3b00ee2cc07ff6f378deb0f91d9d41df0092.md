# Introducción

Una cadena de caracteres (`String`) en Java es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).
Para definir una instancia de `String` se usan comillas dobles:

```java
String fruit = "Apple";
```

Los strings se manipulan llamando a sus métodos.
Una vez construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string en realidad devolverá un string nuevo.
La clase `String` proporciona algunos métodos _estáticos_ para transformar los strings.
