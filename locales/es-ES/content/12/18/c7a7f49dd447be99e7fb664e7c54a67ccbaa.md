# Condicionales

Un **condicional** elige entre dos posibles formas de actuar en función de si
algo es verdadero.

```sather
   verdict(score : INT) : STR is
      if score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

Leyendo eso: `if`, luego una pregunta que responde `true` o `false`, y después
`then`. Las líneas que van después de `then` se ejecutan cuando la respuesta es
verdadera, y las que van después de `else` se ejecutan cuando es falsa. `end;`
cierra todo el conjunto.

## Más de dos caminos

`elsif` añade otra pregunta, que solo se plantea cuando las anteriores han
resultado falsas.

```sather
   verdict(score : INT) : STR is
      if score >= 8 then
         return "Cast";
      elsif score >= 5 then
         return "Recalled";
      else
         return "Thank you";
      end;
   end;
```

El orden importa. Una puntuación de `9` la captura la primera pregunta y nunca
llega a la segunda, aunque `9 >= 5` también sea verdadero. Escribir las
comprobaciones en el orden equivocado es la forma habitual de equivocarse aquí.

Se escribe `elsif`, no `elseif`, y tampoco `else if`.

## Omitir el else

Se puede prescindir de `else` cuando no hay nada que hacer en ese caso.

```sather
   if late then
      apologise;
   end;
```

Una rutina que debe devolver algo necesita que todos los caminos devuelvan un
valor, así que en este ejercicio todos los `if` conservan su `else`.
