# Concatenación de string

La concatenación de string es perfectamente válida en Ruby, pero una forma más común de componer un string es con la [interpolación de string](http://ruby-for-beginners.rubymonstas.org/bonus/string_interpolation.html). Por ejemplo:

```ruby
# Rather than:
"One for " + %{name_variable} + ", one for me"

# Consider:
"One for #{%{name_variable}}, one for me."
```
