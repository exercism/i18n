# Pistas

## 1. Calcula la suma de los números de la máquina tragaperras

- Puedes usar [join][mdn-join] para combinar los dígitos.
  Además, convertirá los números a string de forma implícita.
- Vuelve a consultar la sección de introducción para averiguar cómo convertir un string a un número.
- Suma los números una vez convertidos.

## 2. Determina si un número es un palíndromo

- Esta tarea se puede resolver tratando el número como un string y comprobando si el string es igual a su versión invertida.
- Para ello, primero tienes que convertir el número a un string.
  Vuelve a consultar la sección de introducción para averiguar cómo hacerlo.
- Para invertir el string, divídelo en un array con `split`, invierte el array con `reverse` y vuelve a unirlo con `join`.
- Por último, puedes [comparar][concept-comparison] el string original con el string invertido.

## 3. Genera un mensaje de error para una entrada de usuario no válida

- Puedes usar [condicionales][mdn-if-statement] para comprobar las distintas condiciones.
- En primer lugar, debes cubrir el caso en el que el valor no contiene ningún carácter.
  Al escribir la condición para ese caso, aprovecha la conversión implícita a Boolean y el hecho de que `null`, `undefined` y el string vacío son todos falsy.
- A continuación, aborda el caso en el que la entrada no es un número o es `0`.
  Usa la conversión explícita a `Number` que aprendiste en la introducción.
  Después, puedes volver a apoyarte en la conversión implícita a Boolean y en el hecho de que `NaN` y `0` son falsy.
- El [operador lógico NOT][mdn-not] `!` puede ayudarte a formular las condiciones.
