# Acerca de

En Common Lisp, una lista de parámetros (como la que se usa para definir una función) también se conoce como [lista lambda][lambda-list].
Las listas lambda también se usan para definir macros y para la desestructuración.

Las listas lambda pueden contener [palabras clave de lista lambda][lambda-list-keyword] como `&rest`, `&optional`, `&key` y otras.

Aunque se pueden combinar varios tipos de parámetros con otros tipos de parámetros (parámetros opcionales y de palabra clave), esto puede resultar problemático y conviene hacerlo con cuidado.
Consulta la sección ["Combinar distintos tipos de parámetros"][pcl-function] de Practical Common Lisp.
