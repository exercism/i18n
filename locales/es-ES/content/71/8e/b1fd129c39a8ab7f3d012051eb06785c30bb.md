# Instructions

Tu asociación vecinal te ha pedido que implementes una sencilla aplicación de registro para gestionar las inscripciones del huerto comunitario. La estructura `Plot` ya se te ha proporcionado.

## 1. Abrir el huerto

Implementa la función `CommunityGarden.start/1`; debe recibir una lista de palabras clave opcional con opciones que se pasarán al _proceso agente_. El estado inicial del huerto debe inicializarse de forma que represente una colección vacía de parcelas. Debe devolver una tupla `:ok` con el pid del huerto.

```elixir
{:ok, pid} = CommunityGarden.start()
# => {:ok, #PID<0.112.0>}
```

## 2. Listar las inscripciones

Implementa la función `CommunityGarden.list_registrations/1`. Debe recibir el `pid` del huerto comunitario. Debe devolver una lista de las parcelas almacenadas que estén registradas.

```elixir
CommunityGarden.list_registrations(pid)
# => []
```

> En este punto, todavía no hemos añadido la posibilidad de registrar una parcela, así que esta lista debería estar vacía

## 3. Registrar parcelas a nombre de una persona

Implementa la función `CommunityGarden.register/2`. Debe recibir el `pid` del huerto comunitario y un nombre con el que registrar la parcela. Cuando se realice correctamente, debe devolver la estructura `Plot` con el id de la parcela y la persona a la que está registrada.

Los id deben ser incrementales y únicos. Puedes mantener un contador de id en el estado del agente.

```elixir
CommunityGarden.register(pid, "Emma Balan")
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.list_registrations(pid)
# => [%Plot{plot_id: 1, registered_to: "Emma Balan"}]
```

## 4. Liberar parcelas

Implementa la función `CommunityGarden.release/2`. Debe recibir el `pid` y el `id` de la parcela que se va a liberar. Debe devolver `:ok` si se realiza correctamente. Cuando se libera una parcela, el id no se reutiliza; se usa únicamente como identificador único.

```elixir
CommunityGarden.release(pid, 1)
# => :ok
CommunityGarden.list_registrations(pid)
# => []
```

## 5. Obtener una parcela registrada

Implementa la función `CommunityGarden.get_registration/2`. Debe recibir el `pid` y el `id` de la parcela que se va a comprobar. Debe devolver la parcela si está registrada, y `:not_found` si no lo está.

```elixir
CommunityGarden.get_registration(pid, 1)
# => %Plot{plot_id: 1, registered_to: "Emma Balan"}
CommunityGarden.get_registration(pid, 7)
# => {:not_found, "plot is unregistered"}
```
