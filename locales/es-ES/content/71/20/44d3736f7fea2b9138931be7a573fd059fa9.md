# Introducción

Una `list` de F# es una colección inmutable de cero o más valores. Todos los valores de una lista deben tener el mismo tipo. Como las listas son inmutables, una vez creada una lista su valor nunca puede cambiar. Cualquier función u operador que parezca modificar una lista (como añadir un elemento) en realidad devolverá una lista nueva.

Las listas se pueden definir así:

```fsharp
let empty = []
let singleValue = [5]
let threeValues = ["a"; "b"; "c"]
```

La forma más habitual de añadir un elemento a una lista es mediante el operador `::` (cons):

```fsharp
let twoToFour = [2; 3; 4]
let oneToFour = 1 :: twoToFour
// => [1; 2; 3; 4]
```

Una lista de F# tiene una _cabeza_ (el primer elemento) y una _cola_ (todo lo que sigue al primer elemento). La cola de una lista es a su vez una lista.

Las listas se manipulan con las funciones y los operadores definidos en el módulo `List`, o manualmente mediante la coincidencia de patrones con los patrones _list_ y _cons_:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | head::tail -> sprintf "Non-empty list with head: %d" head

describe []        // => "Empty list"
describe [1]       // => "Non-empty with head: 1"
describe [5; 7; 9] // => "Non-empty with head: 5"
```

También puedes _descartar_ un valor al hacer coincidencia de patrones; cuando _no_ te importe un valor en un caso concreto (es decir, no vas a _usar_ ese valor), puedes usar un guion bajo (`'_'`) para indicarlo:

```fsharp
let describe list =
    match list with
    | [] -> "Empty list"
    | [x] -> "List with one item"
    | [_; y] -> "List with two items (first item ignored)"
    | _ -> "List with many items (all items ignored)"

describe []        // => "Empty list"
describe [1]       // => "List with one item"
describe [5; 7]     // => "List with two items (first item ignored)"
describe [5; 7; 9] // => "List with many items (all items ignored)"
```

El único `'_'` siempre debe ir _al final_ al hacer coincidencia de patrones; todos los valores que _no_ coincidan con ninguno de los otros casos los manejará este caso.
