# Introducción

La mayoría de las palabras de secuencia de Factor devuelven *nuevas* secuencias y dejan sus entradas intactas, pero tanto los arrays como los vectores también admiten **mutación in situ** cuando quieres registrar un estado que evoluciona con el tiempo.

`set-nth` y `change-nth` cambian una posición in situ y funcionan tanto con un array como con un vector. `<array>` crea un array mutable de longitud fija; los literales `V{ }`, `<vector>`, `push` y `pop` son el conjunto exclusivo de los vectores, ya que los arrays no pueden cambiar de longitud. `clone` duplica la secuencia para que las mutaciones posteriores no afecten a la original.

```factor
USING: arrays kernel sequences ;

5 0 <array>                 ! a fresh array { 0 0 0 0 0 }
dup 7 2 swap set-nth        ! { 0 0 7 0 0 } — set position 2 to 7
.

V{ } clone                  ! a fresh, empty vector
"alice" over push           ! V{ "alice" }
"bob" over push             ! V{ "alice" "bob" }
dup pop .                   ! "bob"
.                           ! V{ "alice" }
```
