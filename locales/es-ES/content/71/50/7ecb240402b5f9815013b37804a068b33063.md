# Pruebas

## Ejecutar las pruebas

Cuando estés en el directorio de un ejercicio, deberías ver dos subdirectorios:

* `Sources/<Exercise>` contiene tu solución al ejercicio
* `Tests/<Exercise>Tests` contiene las pruebas que hay que ejecutar para el ejercicio

Si estás en el directorio correcto (es decir, el que contiene `Sources` y `Tests`), puedes ejecutar las pruebas de ese ejercicio con `swift test`:

```bash
$ pwd
/Users/johndoe/Code/exercism/swift/hello-world

$ ls
HELP.md  Package.swift  README.md  Sources  Tests

$ swift test
```

Cuando consigas que una prueba pase, elimina `.enabled(if: RUNALL)` de la declaración `@Test` para habilitar la siguiente prueba. Como alternativa, puedes ejecutar todas las pruebas con la variable de entorno `RUNALL` establecida en `true` en Linux o macOS:

```bash
$ export RUNALL=true
```

O, si usas PowerShell en Windows:

```powershell
set RUNALL=true
```

## Enviar tu solución

Para subir una solución a Exercism, tienes que estar en el directorio que contiene los directorios `Sources` y `Tests`.

```bash
$ exercism submit 
```
