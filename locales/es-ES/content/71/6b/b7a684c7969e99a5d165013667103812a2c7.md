# Anexo a las instrucciones

## Pistas

Para completar este ejercicio, tienes que crear el tipo de datos `Allergen`, con instancias de `Eq` y `Show`, e implementar las siguientes funciones:

- `allergies`
- `isAllergicTo`

Encontrarás ya preparadas una declaración de datos ficticia y las firmas de tipo, pero eres tú quien debe definir las funciones y crear un tipo de datos, un `newtype` o un sinónimo de tipo que tenga sentido.
