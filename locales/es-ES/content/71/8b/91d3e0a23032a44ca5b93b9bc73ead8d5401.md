# Instrucciones

En este ejercicio, vas a gestionar un sistema de inventario.

El inventario debe organizarse por el nombre del elemento y debe llevar la cuenta del número de elementos disponibles.

Tendrás que ocuparte de añadir elementos a un inventario.
Cada vez que un elemento aparece en un array dado, la cantidad de ese elemento debe aumentar en `1` en el inventario.
También tendrás que ocuparte de eliminar elementos de un inventario, disminuyendo las cantidades en `1` cuando se solicite.

Por último, tendrás que implementar una función que devuelva todos los pares clave-valor de un inventario dado como una `list` de `tuples`.


## 1. Crear un inventario a partir de un array

Implementa la función `create_inventory(<input list>)`, que crea un «inventario» a partir de un array de elementos de entrada.
Debe devolver un `dict` que contenga el nombre de cada elemento junto con su cantidad respectiva.

```python
>>> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
{"coal":1, "wood":2, "diamond":3}
```

## 2. Añadir elementos de un array a un diccionario existente

Implementa la función `add_items(<inventory dict>, <item list>)`, que añade un array de elementos al inventario que se pasa:

```python
>>> add_items({"coal":1}, ["wood", "iron", "coal", "wood"])
{"coal":2, "wood":2, "iron":1}
```

## 3. Disminuir los elementos del inventario

Implementa la función `decrement_items(<inventory dict>, <items list>)`, que toma una `list` de elementos.
Tu función debe restar `1` del recuento de un elemento por cada vez que ese elemento aparezca en la `list`:

```python
>>> decrement_items({"coal":3, "diamond":1, "iron":5}, ["diamond", "coal", "iron", "iron"])
{"coal":2, "diamond":0, "iron":3}
```

No se debe permitir que los recuentos de elementos del inventario bajen por debajo de 0.
 Si el número de veces que un elemento aparece en la `list` de entrada supera el recuento disponible, la cantidad indicada para ese elemento debe permanecer en 0.
 Las peticiones adicionales para eliminar recuentos deben ignorarse una vez que el recuento llegue a cero.

```python
>>> decrement_items({"coal":2, "wood":1, "diamond":2}, ["coal", "coal", "wood", "wood", "diamond"])
{"coal":0, "wood":0, "diamond":1}
```

## 4. Eliminar un elemento del inventario por completo

Implementa la función `remove_item(<inventory dict>, <item>)`, que elimina un elemento y su recuento por completo de un inventario:

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "coal")
{"wood":1, "diamond":2}
```

Si el elemento no se encuentra en el inventario, la función debe devolver el inventario original sin cambios.

```python
>>> remove_item({"coal":2, "wood":1, "diamond":2}, "gold")
{"coal":2, "wood":1, "diamond":2}
```

## 5. Devolver todo el contenido del inventario

Implementa la función `list_inventory(<inventory dict>)`, que toma un inventario y devuelve un array de tuplas `(item, quantity)`.
El array solo debe incluir los elementos _disponibles_ (_con una cantidad mayor que cero_):

```python
>>> list_inventory({"coal":7, "wood":11, "diamond":2, "iron":7, "silver":0})
[('coal', 7), ('diamond', 2), ('iron', 7), ('wood', 11)]
```
