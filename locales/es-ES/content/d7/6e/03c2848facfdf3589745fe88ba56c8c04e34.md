# Anexo de instrucciones

## Sugerencias

Este es el primer ejercicio con pruebas que requieren que lances una [`Exception`][exception-docs].
Normalmente, las `Exception`s se lanzan para indicar que un programa se ha encontrado con una entrada o un estado inesperados.

Las pruebas a lo largo del track verificarán que las excepciones que lances sean:

1. instancias de un tipo de Java especificado;
2. (opcionalmente) inicializadas con un mensaje especificado.

[exception-docs]: https://docs.oracle.com/javase/8/docs/api/java/lang/Exception.html
