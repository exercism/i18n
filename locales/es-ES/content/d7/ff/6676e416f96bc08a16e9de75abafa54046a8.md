# Tests

## Ejecutar los tests

Para ejecutar los tests, ejecuta el siguiente comando:

```bash
make
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todos sus tests pasen. Por defecto, cuando ejecutas los tests solo se ejecuta uno (el primero). Esto es intencionado, ya que te permite centrarte en hacer que ese único test pase. Una vez que lo consigas, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE()`. Cuando hayas habilitado todos los tests y tu implementación los haga pasar todos, ¡habrás resuelto el ejercicio!
