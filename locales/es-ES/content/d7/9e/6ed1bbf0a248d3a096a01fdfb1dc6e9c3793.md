# Instrucciones

En este ejercicio, tienes que implementar algunas reglas de [Pac-Man][Pac-Man], el clásico juego de arcade de los años 80.

Tienes cuatro reglas que implementar, todas relacionadas con los estados del juego.

> _No te preocupes por cómo se derivan los argumentos; céntrate en combinarlos para devolver el resultado esperado._

## 1. Define si Pac-Man se come a un fantasma

Define la función `eat_ghost()`, que recibe dos parámetros (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man es capaz de comerse a un fantasma.
 La función debe devolver `True` solo si Pac-Man tiene activa una píldora de poder y está tocando a un fantasma.

```python
>>> eat_ghost(False, True)
...
False
```

## 2. Define si Pac-Man puntúa

Define la función `score()`, que recibe dos parámetros (_si Pac-Man está tocando una píldora de poder_ y _si Pac-Man está tocando un punto_) y devuelve un valor Boolean si Pac-Man ha puntuado.
 La función debe devolver `True` si Pac-Man está tocando una píldora de poder o un punto.

```python
>>> score(True, True)
...
True
```

## 3. Define si Pac-Man pierde

Define la función `lose()`, que recibe dos parámetros (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man pierde.
 La función debe devolver `True` si Pac-Man está tocando a un fantasma y no tiene activa una píldora de poder.

```python
>>> lose(False, True)
...
True
```

## 4. Define si Pac-Man gana

Define la función `win()`, que recibe tres parámetros (_si Pac-Man se ha comido todos los puntos_, _si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean si Pac-Man gana.
 La función debe devolver `True` si Pac-Man se ha comido todos los puntos y no ha perdido según las reglas definidas en la parte 3.

```python
>>> win(False, True, False)
...
False
```
