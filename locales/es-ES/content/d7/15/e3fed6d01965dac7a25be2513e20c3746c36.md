# Instalación

Crystal está disponible en Linux, macOS y Windows.

Cabe destacar que la compatibilidad de Crystal con Windows es experimental.
Esto significa que puede haber algunos casos límite que no funcionen y que quizá no sea lo ideal para casos de uso en producción.
Sin embargo, para Exercism y un uso básico, Windows nativo debería ser utilizable en gran medida.

Si buscas una experiencia que no sea de vista previa para desarrollar en Windows, te recomendamos usar [WSL (Windows Subsystem for Linux)][wsl].
Es una funcionalidad **gratuita** de Windows 10 (1903+) y 11 que permite a los desarrolladores ejecutar un entorno Linux sin necesidad de una máquina virtual.

Consulta una de las [guías de instalación][installation guides] para obtener instrucciones sobre cómo instalar Crystal.

[wsl]: https://learn.microsoft.com/en-us/windows/wsl/install
[installation guides]: https://crystal-lang.org/install/
