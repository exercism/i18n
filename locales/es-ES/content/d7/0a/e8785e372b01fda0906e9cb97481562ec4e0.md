# Instrucciones

Tu nostalgia por las cartas Blorkemon™️ no muestra signos de frenarse, incluso has vuelto a coleccionarlas y estás consiguiendo que tus amigos se unan a ti.

En este ejercicio, una colección de `Card` se representa mediante `Set Card`, ya que las cartas duplicadas no son importantes cuando tu objetivo es conseguir todas las cartas existentes.

## 1. Empieza una colección

Tienes muchas ganas de que tus amigos se unan a tu locura por Blorkemon™️, y la mejor forma es poner en marcha su colección regalándoles una carta.

Implementa `newCollection`, que transforma una carta en una colección.

```elm
newCollection "Newthree"
    --> Set.fromList ["Newthree"]
```

## 2. Haz crecer la colección

Una vez que tienes una colección, cobra vida propia y debe crecer.

Implementa `addCard`, que recibe una `Card` y una colección, y devuelve una `Tuple` con dos valores: un `Bool` que indica si la `Card` ya estaba en la colección, y la colección con la carta añadida.

```elm
addCard "Scientuna" (Set.fromList ["Newthree"])
    --> (False, Set.fromList ["Newthree", "Scientuna"])
```

## 3. Empieza a intercambiar

Ahora que tus amigos vuelven a estar locos por Blorkemon™️, puedes aprovechar esto para hacer crecer tu propia colección intercambiando cartas.

No todos los intercambios merecen la pena, ni siquiera pueden hacerse.
No puedes intercambiar una carta que no tienes, y no deberías intercambiar una carta por otra que ya tienes.

Implementa `tradeCard`, que recibe dos cartas para intercambiar (la tuya y la suya) y tu colección actual.
El valor devuelto es una `Tuple` de dos valores: un `Bool` que indica si el intercambio es posible y merece la pena, y la colección con la que terminarías si hicieras el intercambio (aunque en realidad no sea posible).

```elm
tradeCard "Scientuna" "Newthree" (Set.fromList ["Scientuna"])
    --> (True, Set.fromList ["Newthree"])
```

## 4. Solo puede haber una de cada

Encuentras un alijo antiguo de cartas en un mercadillo.
Debes ordenar las cartas y eliminar los duplicados para comparar la lista con tu colección.

Implementa `removeDuplicates`, que ordenará una lista de cartas y devolverá una lista de cartas ordenadas y únicas.

```elm
removeDuplicates ["Newthree", "Newthree", "Newthree", "Scientuna"]
    --> ["Newthree", "Scientuna"]
```

## 5. Las cartas que no tienen

Es hora de sentirte bien con tu colección.

Implementa `extraCards`, que recibe tu colección y otra colección, y devuelve el número de cartas que la otra colección no tiene.

```elm
extraCards (Set.fromList ["Scientuna"]) (Set.fromList ["Newthree", "Scientuna"])
    --> 0
```

## 6. Las cartas que todos tienen

Tú y tus amigos aficionados a Blorkemon™️ os reunís y os preguntáis qué cartas son las más comunes.

Implementa `boringCards`, que recibe una lista de colecciones y devuelve una lista de cartas ordenadas que tienen todas las colecciones.

```elm
boringCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> ["Scientuna"]
```

## 7. Todas las cartas

¿Tenéis tú y tus amigos, entre todos, todas las cartas Blorkemon™️?

Implementa `totalCards`, que recibe una lista de colecciones y devuelve el número total de cartas diferentes que hay en todas las colecciones.

```elm
totalCards [Set.fromList ["Scientuna"], Set.fromList ["Newthree", "Scientuna"]]
    --> 2
```

## 8. Brillantes para ganar

Tu sobrino viene pronto a visitarte y te apetece impresionarlo.
A los niños les gustan las cosas brillantes, ¿verdad?
¡Las cartas Blorkemon™️ pueden ser brillantes!

Implementa `splitShinyCards`, que recibe una colección y devuelve una `Tuple` con dos listas de cartas ordenadas: una con todas las cartas que empiezan por `"Shiny"` y otra con las demás cartas.

```elm
splitShinyCards (Set.fromList ["Newthree", "Scientuna", "Shiny Scientuna"])
    --> (["Shiny Scientuna"], ["Newthree", "Scientuna"])
```
