# Instalar Python

Si Python no está ya disponible en tu sistema, puedes encontrar instrucciones detalladas por plataforma en la sección [Python Setup and Usage][using python] de la documentación oficial.
Real Python también ofrece una [buena guía][helpful guide] para la instalación en varias plataformas, incluidas iOS y Android.

Por último, estas publicaciones de Brett Cannon, [A quick-and-dirty guide][quick-and-dirty] y [Why you should use `python -m pip`][python-m-pip], ofrecen consejos muy útiles sobre cómo gestionar instalaciones y paquetes de Python.

**Nota para usuarios de MacOS:** antes de MacOS Monterey (12.3), `Python 2.7` venía preinstalado con el sistema operativo.
No se admite el uso de `Python 2.7` con Exercism ni con la mayoría de los demás programas.
En su lugar, deberías instalar [Python 3][Python-three downloads] mediante uno de los métodos que se detallan a continuación.
A partir de MacOS Monterey (12.3), MacOS no preinstala ninguna versión de Python.

Algunos enlaces rápidos a la documentación por sistema operativo:

-  [Windows][windows] Además, este artículo de Microsoft sobre [instalar Python en Windows][python-on-windows] resulta útil.
-  [Unix & Linux Systems][unix-and-linux] (_estos funcionan en gran medida también para MacOS_)
-  [MacOS][macos]

   También te recomendamos revisar algunos de los métodos descritos en el artículo de Real Python [Installing Python][installing-python] o en los artículos de Brett Cannon enlazados arriba.


Actualmente, las pruebas y las herramientas de Exercism admiten `3.10` - `3.13.5` (_pruebas_) y [`Python 3.13.5`][313-new-features] (_herramientas_).
Las excepciones a esta compatibilidad se indican donde se producen.
La mayoría de los ejercicios funcionarán con `Python 3.6+`, o incluso con versiones anteriores.
Pero no garantizamos la compatibilidad con versiones que no aparezcan en [Active Python Releases][active-python-releases].


Consulta la [Python 3.13.x documentation][3.13 docs] para saber qué se admite actualmente.
