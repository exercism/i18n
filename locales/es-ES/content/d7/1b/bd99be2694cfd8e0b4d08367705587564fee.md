# Instrucciones

Tu amigo Kojo es un gran aficionado a los números.
Tiene un pequeño sitio web llamado «fun-with-numbers».
Kojo no es muy bueno programando, así que te ha pedido ayuda.

Vas a crear dos funciones auxiliares para nuevos juegos de números en el sitio web de Kojo, y una tercera para validar cierta entrada que el usuario puede introducir.

## 1. Calcula la suma de los números de la tragaperras

Uno de los juegos del sitio web de Kojo se parece a una máquina tragaperras que muestra dos grupos de ruedas con dígitos.
Cada grupo de dígitos representa un número.
Para la mecánica del juego, Kojo necesita saber la suma de esos dos números.

Escribe una función `twoSum` que acepte dos arrays como parámetros.
Cada array consta de uno o más números entre 0 y 9.
La función debe interpretar cada array como un número y devolver la suma de esos dos números.

```javascript
twoSum([1, 2, 3], [0, 7]);
//=> 130

// [1, 2, 3] represents 123 and [0, 7] represents 7.
// 123 + 7 = 130
```

## 2. Determina si un número es un palíndromo

Otro juego del sitio web es un pequeño concurso llamado «Números de la suerte».
El usuario puede introducir un número y luego ve si ese número pertenece a alguna secuencia o patrón secreto.
La secuencia o el patrón de los «números de la suerte» cambia cada mes, y cada usuario solo tiene un número limitado de intentos para adivinarla.

Los números de la suerte de este mes deben ser números que sean palíndromos.
Un número palindrómico no cambia al invertir sus dígitos.

Implementa la nueva función `luckyNumber`, que acepta un número como parámetro.
La función debe devolver `true` si el número es un palíndromo y `false` en caso contrario.
El número de entrada siempre será un entero positivo.

```javascript
luckyNumber(1441);
//=>  true

luckyNumber(123);
//=> false
```

## 3. Genera un mensaje de error para entradas de usuario no válidas

En varios lugares del sitio web hay campos de entrada donde los usuarios pueden introducir números y hacer clic en un botón para desencadenar alguna acción.
Kojo quiere mejorar la experiencia de usuario de su sitio.
Quiere mostrar un mensaje de error en caso de que el usuario haga clic en el botón pero el campo contenga un valor de entrada no válido.

Aquí tienes más información sobre cómo se proporciona el valor de un campo de entrada.

- Si el usuario escribe algo en un campo, el valor asociado siempre es un string, incluso si solo ha escrito números.
- Si el usuario escribe algo pero lo borra, la variable será un string vacío.
- Antes de que el usuario empiece a escribir, la variable puede ser `undefined` o `null`.

Escribe una función `errorMessage` que acepte la entrada del usuario como parámetro.
Si el usuario no ha proporcionado ninguna entrada, `errorMessage` debe devolver `'Required field'`.
Si la entrada no representa un número distinto de cero (según las reglas de conversión de JavaScript), debe devolverse `'Must be a number besides 0'`.
En todos los demás casos, puedes suponer que la entrada es válida y el valor devuelto debe ser un string vacío.

```javascript
errorMessage('123');
// => ''

errorMessage('');
// => 'Required field'

errorMessage('abc');
// => 'Must be a number besides 0'
```
