# Introducción

Las funciones y los métodos de Go pueden devolver varios valores:

```go
func GetCard() (Card, error) { ... }
```

Cada valor devuelto debe asignarse en orden y separarse con comas:

```go
card, err := GetCard()
```

Cada posición de la asignación declara una variable.
Go no compilará si alguna variable declarada no se usa nunca.
El identificador en blanco `_` ocupa el lugar de un nombre de variable para omitir ese valor devuelto:

```go
card, _ := GetCard()
```

`error` es una interfaz integrada.
Un error `nil` significa que no se ha producido ningún error; cualquier valor distinto de `nil` significa que algo ha ido mal.
Por convención, las funciones que pueden fallar deben devolver un `error` como último valor.
Quien llama debe comprobarlo antes de usar cualquier otro valor devuelto:

```go
card, err := GetCard()
if err != nil {
    return err // do not use card here
}
// safe to use card here
```
