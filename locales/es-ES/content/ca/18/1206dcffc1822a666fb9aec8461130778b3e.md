# Acerca de

Haxe incluye compatibilidad integrada con las expresiones regulares. Se pueden usar para verificar el formato de un string, transformar un string o extraer datos que sigan un patrón determinado de un texto dado.

Para crear una expresión regular, escribe entre `~/` y `/`:

```haxe
var r = ~/haxe/i;
```

Otra forma de hacerlo es mediante una instancia de `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aquí, la `i` es un flag que hace que el patrón no distinga entre mayúsculas y minúsculas. Hay otros flags, entre los que se incluyen:

- `g`: reemplazo global.
- `m`: coincidencia en varias líneas

Entre `~/` y `/`, escribes los patrones de la expresión regular. Por ejemplo, quieres buscar un string que contenga letras de la A a la Z. Aquí podemos usar el patrón de rango `[A-Z]`. Existen muchos patrones de expresión, entre los que se incluyen:

- `.`: cualquier carácter
- `*`: repetir cero o más veces
- `+`: repetir una o más veces
- `[A-Z0-9]`: rangos de caracteres
