# Instrucciones

Trabajas en un parque de atracciones y te han entregado la especificación de un sistema para gestionar la asistencia y las atracciones. Tu tarea consiste en modelar el Attendee (la persona que visita el parque).

## 1. Crea nuevos visitantes

Implementa el método `Attendee#initialize` de la clase `Attendee`; debe recibir una altura (en centímetros) y almacenarla en una variable de instancia.

```ruby
Attendee.new(106)
# => #<Attendee:0x000055c33e6c7e18 @height=106>
```

## 2. ¿Cuánto mide el visitante?

Implementa el getter `Attendee#height` de la clase `Attendee`; debe devolver la altura de la instancia.

```ruby
Attendee.new(106).height
# => 106
```

## 3. ¿Cuál es el id del pase de atracciones?

No todos los visitantes han comprado un pase de atracciones, pero necesitamos saber si lo tienen o no. Implementa el getter `Attendee#pass_id` de la clase `Attendee`; debe devolver el pass_id de la instancia o `nil` si el visitante no tiene uno.

```ruby
Attendee.new(106).pass_id
# => nil
```

## 4. Permite que la gente compre un pase

Implementa `Attendee#issue_pass!` para modificar el estado de la instancia y asignar a la variable de instancia del id del pase el valor del argumento. Debe devolver el id del pase.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.pass_id
# => 42
```

## 5. Revoca el pase

Algunos visitantes incumplen las normas con conductas peligrosas, así que el parque quiere poder revocar los pases. Implementa `Attendee#revoke_pass!` para modificar el estado de la instancia y asignar `nil` al id del pase.

```ruby
attendee = Attendee.new(106)
attendee.issue_pass!(42)
attendee.revoke_pass!
attendee.pass_id
# => nil
```
