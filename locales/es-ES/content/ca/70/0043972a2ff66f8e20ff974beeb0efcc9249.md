# Anexo de las instrucciones

## Trabajar con fechas en Prolog

El soporte integrado de Prolog para las fechas es [bastante rudimentario][built-in-dates-support]. Aunque puedes resolver este ejercicio solo con lo que Prolog trae de serie, una forma mucho más agradable de trabajar con fechas es el [paquete date_time][date-time-package].

### Instalar el paquete date_time

Si la versión de Swipl que tienes instalada es bastante reciente, puedes instalar el paquete ejecutando:

```bash
swipl pack install date_time
```

Si eso no funciona, puedes ejecutar:

```shell
swipl -g 'pack_install(date_time)'
```

~~~~exercism/note
Si usas el editor en línea, no necesitas instalar nada a mano.
~~~~

### Usar el paquete date_time

Añade el siguiente código al principio de tu archivo de solución para usar el paquete `date_time`:

```prolog
:- use_module(library(date_time)).
```
