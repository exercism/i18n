# Acerca de

`when` es la palabra clave que permite filtrar excepciones. Se coloca después de la instrucción `catch` y puede recibir una expresión Boolean que contenga cualquier valor que esté en el scope en ese momento. No tienen por qué ser solo miembros de la propia excepción. Si el tipo de la excepción coincide y la expresión se evalúa como verdadera, se ejecuta el bloque asociado a esa instrucción `catch`; en caso contrario, se comprueba la siguiente instrucción `catch`, si la hay.

```csharp
try
{
    // do stuff
}
catch (Exception ex) when (ex.Message != "")
{
    // output the message when it is not empty
}
catch (Exception ex)
{
    // show stack trace or something.
}
```
