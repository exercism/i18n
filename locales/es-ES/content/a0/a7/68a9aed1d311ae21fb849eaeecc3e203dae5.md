# Pistas

## 1. Dividir un string en líneas individuales

- Swift tiene un [método][nsstring-components-docs] para dividir un string en un array de strings usando un delimitador que le indiques.

## 2. Puerta principal

- El guardia recitará un poema y tendrás que dividirlo en líneas individuales. Para esto puedes usar una función que ya existe.
- Puedes usar un bucle `for` para recorrer las líneas del poema.
- Puedes usar la propiedad `first` de un string para obtener el primer carácter de un string.
- Para almacenar el primer carácter de cada línea, puedes usar un array de caracteres o un string.

## 3. Puerta trasera

- El guardia recitará un poema y tendrás que dividirlo en líneas individuales. Para esto puedes usar una función que ya existe.
- Puedes usar un bucle `for` para recorrer las líneas del poema.
- Puedes usar la propiedad `last` de un string para obtener el último carácter de un string.
- Para almacenar el último carácter de cada línea, puedes usar un array de caracteres o un string.

## 4. Sala secreta

- El guardia recitará un poema y tendrás que dividirlo en líneas individuales. Para esto puedes usar una función que ya existe.
- Puedes usar un bucle `for` que itere sobre la longitud de las líneas del poema.
- Swift tiene un [método][indexing] para obtener el carácter en un índice específico de un string.
- Swift tiene un [método][uppercased] para convertir un string a mayúsculas.
