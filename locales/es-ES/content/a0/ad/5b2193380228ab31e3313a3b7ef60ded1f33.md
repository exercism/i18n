# Anexo a las instrucciones

## Instrucciones específicas de este track

Tu lista también debe implementar la siguiente interfaz:

- `delete` (elimina la primera aparición de un valor especificado)
- `count` (cuenta el número de elementos de la lista)

Los esbozos de `linked-list.v` proporcionan el conjunto _mínimo_ de interfaces. Puede que quieras añadir tus propias definiciones, como una estructura que represente un elemento de la lista.

Sin embargo, _no_ uses una biblioteca para implementar este ejercicio y _no_ uses un array.
