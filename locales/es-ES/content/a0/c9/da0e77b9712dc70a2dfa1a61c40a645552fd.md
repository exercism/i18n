# Instrucciones

Cerca hay una tienda de electrodomésticos llamada «Tech Palace».
El dueño de la tienda ha instalado hace poco una gran pantalla para usarla en mensajes de marketing y para mostrar un saludo especial cuando los clientes escanean sus tarjetas de fidelidad en la entrada.
La pantalla se compone de muchas luces LED pequeñas y puede mostrar varias líneas de texto.

El dueño de la tienda necesita tu ayuda con el código que se usa para generar el texto de la nueva pantalla.

## 1. Crea el mensaje de bienvenida

<!-- markdownlint-disable-next-line MD038 -->
Para la mayoría de los clientes que escanean sus tarjetas de fidelidad, el dueño de la tienda quiere ver `Welcome to the Tech Palace, ` seguido del nombre del cliente en mayúsculas en la pantalla.

Implementa la función `welcome_message` que acepta el nombre del cliente como argumento de tipo string corto (`felt252`) y devuelve el mensaje deseado como un `ByteArray`.

```rust
welcome_message("Judy")
// => Welcome to the Tech Palace, JUDY
```

## 2. Añade un borde vistoso

Para los clientes fieles que compran mucho en la tienda, el dueño quiere que la pantalla de bienvenida sea más vistosa añadiendo una línea de estrellas antes y después del mensaje de bienvenida.
Todavía no saben con certeza cuántas estrellas debería haber en las líneas, así que quieren que eso sea configurable.

Escribe una función `add_border` que acepte un mensaje de bienvenida (un `ByteArray`) y el número de estrellas por línea (de tipo `u32`) como argumentos.
Debe devolver un `ByteArray` que conste de 3 líneas: una línea con el número de estrellas deseado, después el mensaje de bienvenida tal como se pasó y, por último, otra línea de estrellas.

```rust
add_border("Welcome!", 10)
```

Debería devolver lo siguiente:

```bash
**********
Welcome!
**********
```

## 3. Limpia los antiguos mensajes de marketing

Antes de instalar esta nueva pantalla, la tienda tenía una pantalla similar que solo podía mostrar líneas estáticas y no configurables.
Al dueño le gustaría reutilizar algunos de los antiguos mensajes de marketing en la nueva pantalla.
Sin embargo, los datos ya incluyen un borde de estrellas y algunos espacios en blanco no deseados.
Tu tarea es limpiar los mensajes para que se puedan reutilizar.

Implementa una función `clean_up_message` que acepte el antiguo mensaje de marketing como un `ByteArray`.
La función debe eliminar primero todas las estrellas del texto y, después, eliminar los espacios en blanco al principio y al final del texto restante.
A continuación, la función debe devolver el mensaje ya limpio.

```rust
let message: ByteArray = "
**************************
*    BUY NOW, SAVE 10%   *
**************************
";

clean_up_message(message)
// => BUY NOW, SAVE 10%
```
