# Acerca de

Los **closures** son un patrón de programación [en Clojure][clojure-guide-closures] que permite usar dentro de una función variables de un [scope léxico][wiki-lexical-scope] externo. Clojure admite los closures de forma transparente, y a menudo se usan sin saber qué son.

```clojure
;; Top-level definitions are global-scope
(def dozen 12)

;; Functions create a new scope.
;; Referencing the outer variable here is a closure.
(fn [n] (* dozen n))
```

## Closures para guardar estado y pasar valores

Usar un átomo permite conservar cierto estado:

```clojure
;; This function closure increments the counter's state
;; in the outer lexical context.
;; This way the counter can be shared between many calling contexts.

(def increment
  (let [counter (atom 0)]
    (fn [] (swap! counter inc))))
```

Cada llamada sucesiva a `increment` incrementa su contador:

``` clojure
(increment)
;;=> 1
(increment)
;;=> 2
```
