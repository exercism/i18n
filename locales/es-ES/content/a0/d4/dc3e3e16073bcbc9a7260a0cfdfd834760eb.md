# Anexo a las instrucciones

## Registros

| Registro | Uso          | Tipo    | Descripcion                   |
| -------- | ------------ | ------- | ----------------------------- |
| `$a0`    | entrada      | direccion | string de entrada terminado en nulo  |
| `$a1`    | entrada      | entero  | clave de desplazamiento       |
| `$a2`    | entrada/salida | direccion | string de resultado terminado en nulo |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal |
