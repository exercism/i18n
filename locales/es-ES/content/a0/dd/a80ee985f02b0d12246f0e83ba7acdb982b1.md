# Instrucciones

Eres un ávido observador de aves que lleva un registro de cuántos pájaros han visitado tu jardín.
Normalmente, usas un recuento en un cuaderno para contar los pájaros, pero quieres trabajar mejor con tus datos.
Ya has digitalizado los recuentos de pájaros por día de las últimas semanas que tenías en el cuaderno.

Ahora quieres determinar el número total de pájaros que contaste, calcular el recuento de pájaros de una semana concreta y corregir un error de conteo.

<!-- prettier-ignore -->
~~~~exercism/note
Para practicar, usa un bucle `for` para resolver cada una de las tareas siguientes.
~~~~

## 1. Determina el número total de pájaros que has contado hasta ahora

Empecemos analizando los datos para obtener una visión general.
Averigua cuántos pájaros has contado en total desde que empezaste tus registros.

Implementa una función `totalBirdCount` que acepte un objeto similar a un array que contenga el recuento de pájaros por día.
Debe devolver el número total de pájaros que has contado.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
totalBirdCount(birdsPerDay);
// => 34
```

## 2. Calcula el número de pájaros que te visitan en una semana concreta

Ahora que ya tienes una idea general de tus cifras de recuento de pájaros, quieres hacer un análisis más detallado.

Implementa una función `birdsInWeek` que acepte un objeto similar a un array con los recuentos de pájaros por día y un número de semana.
Devuelve el número total de pájaros que contaste en esa semana concreta.
Puedes dar por supuesto que las semanas siempre se registran completas.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1];
birdsInWeek(birdsPerDay, 2);
// => 12
```

## 3. Corrige un error de conteo

Te has dado cuenta de que, durante todo el tiempo que estuviste intentando llevar el registro de los pájaros, había uno escondido en un rincón lejano del jardín.
Has averiguado que este pájaro pasaba siempre un día sí y otro no en tu jardín.
No sabes exactamente dónde estaba entre esos días, pero desde luego no estaba en tu jardín.
Tu intuición de observador de aves también te dice que el pájaro estaba en tu jardín el primer día que registraste en tu array.

Con esta nueva información, escribe una función `fixBirdCountLog` que reciba como argumento un objeto similar a un array con los pájaros contados por día. Debe corregir el error de conteo modificando el array dado.

```javascript
birdsPerDay = [2, 5, 0, 7, 4, 1];
fixBirdCountLog(birdsPerDay);
// => [3, 5, 1, 7, 5, 1]
```
