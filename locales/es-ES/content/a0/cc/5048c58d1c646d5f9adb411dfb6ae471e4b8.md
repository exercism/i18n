# Introducción

Muchos lenguajes tienen una forma, como `null` o `none`, de indicar un valor inexistente.
Como R está diseñado para manejar grandes volúmenes de datos (a menudo desordenados), tiene múltiples formas de representar la nada.

El objetivo general es señalar los valores ausentes o sospechosos a medida que se encuentran, y luego continuar sin lanzar una excepción.

## NULL

Si un valor realmente no existe, se representa con `NULL`. Esto es probablemente lo más parecido a lo que harían C o Python.

```R
v <- c() # zero-length vector
v
#> NULL
is.null(v)
#> [1] TRUE
```

En muchos contextos, los valores `NULL` simplemente se ignoran:

```R
c(2, 3, NULL, 5)
#> [1] 2 3 5
```

## NA

Para las situaciones en las que un valor existe pero no sabemos cuál es, se usa `NA`. Por ejemplo, al contar los vehículos que circulan por una carretera, puede que los observadores humanos caigan enfermos o que los sensores automáticos se averíen, pero el tráfico sigue fluyendo.

```R
v <- c(1, 2, NA, 4, 5)
v
#> [1]  1  2 NA 4  5
is.na(v) # test for data gaps
#> [1] FALSE FALSE  TRUE FALSE FALSE
```

Así pues, `NA` es un marcador de posición que avisa a las personas de que deben decidir cómo tratarlo.

## NaN

`NaN` (abreviatura de «Not a Number») señala un problema de cálculo en situaciones en las que se esperaba un número.

```R
n <- c(0, 2, 4)
d <- c(0, 1, 2)
n / d
#> [1] NaN   2   2  # 0/0 is mathematically undefined
is.nan(n / d)
#> [1]  TRUE FALSE FALSE
```

No es la única posibilidad para los cálculos «no válidos».
Dividir por cero devolverá `Inf` o `-Inf` para un numerador distinto de cero, sin lanzar un error.

```R
1 / 0
#> [1] Inf
```

## Vectores vacíos

Quizá sorprenda que R no tenga una forma estándar de comprobar si algo está vacío.

Incluso generar un vector vacío no es del todo obvio.
Vimos en una sección anterior que `c()` sin argumentos devuelve `NULL`, no un vector.

```R
is.vector(c())
#> [1] FALSE
```

Funciones como `logical()` o `integer()` reciben un argumento que especifica la longitud deseada, que puede ser cero.

```R
z <- logical(0)
is.vector(z)
#> [1] TRUE
length(z)
#> [1] 0
```

También podemos generar un vector y después eliminar todos sus elementos, como se describe en el [concepto de vectores][concept-vectors].
El resultado es un vector de longitud 0 del tipo adecuado.

```R
v <- 5
v[-1]  # delete the first element
#> numeric(0)
```
