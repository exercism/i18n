# Introducción

En Haxe, un **array** es una colección de elementos (normalmente) del mismo tipo. Hay tres formas de crear un array en Haxe: con un constructor o con una sintaxis de declaración. En Haxe, el primer elemento de un array tiene índice cero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para crear un array con un constructor, tienes que indicar el tipo de los elementos que va a contener el array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Si queremos que un array contenga elementos de varios tipos, añadimos el tipo `Dynamic` al indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```
