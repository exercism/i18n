# Introducción

En C# hay dos tipos diferentes de números:

- Enteros: números sin dígitos detrás del separador decimal (números enteros). Algunos ejemplos son `-6`, `0`, `1`, `25`, `976` y `500000`.
- Números de coma flotante: números con cero o más dígitos detrás del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

Los dos tipos numéricos más comunes en C# son `int` y `double`. Un `int` es un entero de 32 bits y un `double` es un número de coma flotante de 64 bits.

Las operaciones aritméticas se realizan con los operadores aritméticos estándar. Los números se pueden comparar con los operadores de comparación numérica estándar y con los operadores de igualdad (`==`) y desigualdad (`!=`).

C# tiene dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se perderá ningún dato y no se necesita sintaxis adicional.
2. Conversiones explícitas: se podrían perder datos y se necesita sintaxis adicional en forma de _cast_.

Como un `int` tiene menos precisión que un `double`, convertir de `int` a `double` es seguro y, por tanto, es una conversión implícita. Sin embargo, convertir de `double` a `int` podría suponer perder datos, así que requiere una conversión explícita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```
