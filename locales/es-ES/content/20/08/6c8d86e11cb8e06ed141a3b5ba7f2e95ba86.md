# Introducción

PHP permite declarar funciones dentro de otras funciones. Estas funciones no necesitan tener nombre, pero pueden asignarse a variables o incluso pasarse directamente a otra función que necesite un parámetro que sea una función.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```
