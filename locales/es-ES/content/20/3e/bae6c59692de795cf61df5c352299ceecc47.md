# Pistas

## 1. Implementa el método calculate para admitir algunas operaciones básicas

- Usa una instrucción [`switch`][switch-statement-docs] para distinguir entre las distintas operaciones.

## 2. Gestiona las operaciones ilegales

- No puedes comprobar si hay `null` dentro de una instrucción `switch`.
- Usa un caso `default` para cualquier otra cosa al final del switch.

## 3. Gestiona la excepción que se lanza al dividir entre cero

- Usa un [bloque `try-catch`][exception-handling-docs] para capturar la `ArithmeticException` que se lanza al dividir entre cero.
- La clase `IllegalOperationException` tiene un constructor que recibe un mensaje y una causa como parámetros.

[switch-statement-docs]: https://docs.oracle.com/javase/tutorial/java/nutsandbolts/switch.html
[exception-handling-docs]: https://docs.oracle.com/javase/tutorial/essential/exceptions/handling.html
