# Descomposición y asignación múltiple

La descomposición se refiere al acto de extraer los elementos de una colección, como un `Array` o un `Hash`.
Los valores descompuestos se pueden asignar después a variables dentro de la misma instrucción.

La [asignación múltiple][multiple assignment] es la capacidad de asignar varias variables para descomponer valores dentro de una sola instrucción.
Esto permite que el código sea más conciso y legible, y se consigue separando con una coma las variables que se van a asignar, como en `first, second, third = [1, 2, 3]`.

El operador splat (`*`) y el operador doble splat (`**`) se usan a menudo en contextos de descomposición.
El operador splat (`*`) se puede usar para combinar varios **arrays** en un solo **array** _descomponiendo_ cada uno en un nuevo **array** común.
El operador doble splat (`**`) se puede usar para combinar varios **hashes** en un solo **hash** _descomponiendo_ cada uno en un nuevo **hash** común.
Se trata de una sintaxis que sirve para distinguir entre aceptar varios valores como un argumento posicional y aceptar uno o varios argumentos de palabra clave.

Cuando el operador splat (`*`) se usa sin una colección, _empaqueta_ (o compone) varios valores en un **array**.
Esto se usa a menudo en la asignación múltiple para agrupar en una sola variable todos los elementos «restantes» que no tienen una asignación individual.

En Ruby es habitual usar este comportamiento de descomposición/composición al usar o definir métodos que aceptan un número arbitrario de argumentos posicionales o de palabra clave.
A menudo verás estos argumentos definidos como `def some_method(*args, **kwargs)` y usados como `some_method(*some_array, **some_hash)`.

~~~~exercism/caution
No hay que confundir `*<variable_name>` y `**<variable_name>` con `*` y `**`.
Mientras que `*` y `**` se usan para la multiplicación y la exponenciación, respectivamente, `*<variable_name>` y `**<variable_name>` se usan como operadores de composición y descomposición.
~~~~
