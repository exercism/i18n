# Anexo a las instrucciones

## Instrucciones específicas del track

### Formato del campo de minas

El campo de minas se representa como un string, con un carácter de salto de línea al final de cada fila.

Un ejemplo sería `"   \n * \n   \n"`

### Memoria reservada

El búfer para el string de entrada usa los bytes 64 a 319 de la memoria lineal.

El string de entrada se puede modificar in situ si lo deseas.
