# Instrucciones

En este ejercicio vas a procesar entradas de registro.

Cada línea de registro es una cadena con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una recibirá una línea de registro y te pedirá que hagas algo con ella. Hay muchas formas de resolver estas tareas: elige tus técnicas favoritas de los ejemplos anteriores y mira qué se te ocurre.

## 1. Obtén el mensaje de una línea de registro

Implementa la función `message` para que devuelva el mensaje de una línea de registro:

```jq
"[ERROR]: Invalid operation" | message
# => "Invalid operation"
```

Debes eliminar los espacios en blanco del principio y del final:

```jq
"[WARNING]:  Disk almost full\r\n" | message
# => "Disk almost full"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `log_level` para que devuelva el nivel de registro de una línea de registro, que debe devolverse en minúsculas:

```ruby
"[ERROR]: Invalid operation" | log_level
# => "error"
```

## 3. Cambia el formato de una línea de registro

Implementa la función `reformat`, que cambia el formato de la línea de registro poniendo el mensaje primero y el nivel de registro después, entre paréntesis:

```ruby
"[INFO]: Operation completed" | reformat
# => "Operation completed (info)"
```
