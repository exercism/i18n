# Instrucciones

La compañía de danza se alinea en filas y tú llevas la cuenta de quién está en cada sitio.

Las cinco tareas van en la clase `DANCE_FORMATION`.

## 1. ¿Cuántos hay en la fila?

```sather
DANCE_FORMATION::dancer_count(|"Mia", "Ana", "Ben"|)
-- => 3
```

## 2. ¿Quién lidera?

El líder es quien va primero.

```sather
DANCE_FORMATION::leader(|"Mia", "Ana", "Ben"|)
-- => "Mia"
```

## 3. ¿Quién está al final?

Quien cierra la fila es el que va al final, por larga que sea la fila.

```sather
DANCE_FORMATION::back_marker(|"Mia", "Ana", "Ben"|)
-- => "Ben"
```

## 4. La formación inicial

La compañía siempre abre en el mismo orden: Mia, Ana, Ben. Devuelve esa fila.

```sather
DANCE_FORMATION::opening_row
-- => an array holding "Mia", "Ana" and "Ben", in that order
```

Esta rutina no recibe argumentos.

## 5. Cuenta los pasos

Cada bailarín tiene que dar un número de pasos. Súmalos.

```sather
DANCE_FORMATION::total_steps(|8, 16, 8|)
-- => 32
```

Una fila vacía son cero pasos.
