# Acerca de

El vocabulario [`sequences`][sequences] define un único
[protocolo][sequence-protocol] que implementan los arrays (`{ … }`), los vectores (`V{ … }`), los strings, los rangos y las
porciones. Todo lo que puedes hacer con uno, puedes hacerlo
con los demás.

| palabra     | efecto                            |
|-------------|-----------------------------------|
| `length`    | `( seq -- n )`                    |
| `first`     | `( seq -- elt )`                  |
| `second`    | `( seq -- elt )`                  |
| `third`     | `( seq -- elt )`                  |
| `fourth`    | `( seq -- elt )`                  |
| `last`      | `( seq -- elt )`                  |
| `rest`      | `( seq -- tailseq )`              |
| `but-last`  | `( seq -- headseq )`              |
| `nth`       | `( n seq -- elt )` (0-based)      |
| `head`      | `( seq n -- headseq )`            |
| `head*`     | `( seq n -- headseq )` (all but last n) |
| `tail`      | `( seq n -- tailseq )`            |
| `tail*`     | `( seq n -- tailseq )` (last n)   |
| `subseq`    | `( from to seq -- newseq )`       |
| `remove-nth`| `( n seq -- newseq )`             |
| `pad-head`  | `( seq n elt -- padded )`         |
| `pad-tail`  | `( seq n elt -- padded )`         |
| `prefix`    | `( seq elt -- newseq )`           |
| `suffix`    | `( seq elt -- newseq )`           |
| `unclip`    | `( seq -- rest first )`           |
| `unclip-last` | `( seq -- butlast last )`       |
| `empty?`    | `( seq -- ? )`                    |
| `if-empty`  | `( seq emptyquot nonemptyquot -- … )` |
| `member?`   | `( elt seq -- ? )`                |
| `reverse`   | `( seq -- newseq )`               |
| `index`     | `( elt seq -- i/f )`              |
| `index-or-length` | `( elt seq -- i )` (length when absent) |
| `count`     | `( seq quot -- n )`               |
| `concat`    | `( seqs -- seq )`                 |
| `sum`       | `( seq -- n )`                    |
| `product`   | `( seq -- n )`                    |
| `find`      | `( seq quot -- i/f elt/f )`       |
| `find-last` | `( seq quot -- i/f elt/f )`       |
| `produce`   | `( pred quot -- seq )`            |

Los arrays tienen longitud fija, así que las operaciones `prefix`/`suffix`/`append`/`prepend`
devuelven nuevas secuencias en lugar de ampliar la original.
Los vectores son redimensionables ( `push` y `pop` funcionan in situ ), pero `clone`
es el punto de partida adecuado si quieres una copia nueva.

## Conversiones

`>array`, `>string` y `>vector` (en sus respectivos vocabularios)
convierten cualquier secuencia al tipo concreto indicado. Úsalos cuando quien llama
quiera una representación concreta, o para materializar una porción
u otra secuencia perezosa.

```factor
USING: arrays sequences strings vectors ;

V{ 1 2 3 } >array  .   ! => { 1 2 3 }
{ 65 66 67 } >string . ! => "ABC"
"abc" >vector .        ! => V{ CHAR: a CHAR: b CHAR: c }
```
