# Anexo de instrucciones

## Palabras

Define una tupla `custom-set` y declárala como instancia del mixin `set`
con `INSTANCE: custom-set set`.

- `<custom-set> ( -- set )`: construye un conjunto vacío.
- `>custom-set ( seq -- set )`: construye un conjunto a partir de una secuencia,
  descartando los duplicados en silencio.

A continuación, proporciona métodos `M:` (de `sets`) sobre `members`, `in?`,
`adjoin` y `set-like` para `custom-set`. Con la declaración `INSTANCE:`
y esos cuatro métodos en su sitio, `null?`, `union`,
`intersect`, `diff`, `subset?`, `set=` e `intersects?` del
vocabulario `sets` funcionan sobre tu conjunto a través de las
implementaciones por defecto del protocolo. Los tests llaman a esas palabras
directamente.

`adjoin ( elt set -- )` es mutante: añade `elt` a `set` in
situ si no está ya presente.
