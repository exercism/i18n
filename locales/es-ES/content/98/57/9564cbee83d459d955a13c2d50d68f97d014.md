# Pistas

## 1. Define la aprobación

- Los tipos personalizados se pueden definir con la sintaxis `pub type Name { Variant1 }`.

## 4. Define la actividad

- Los tipos personalizados que contienen datos se pueden definir con la sintaxis `pub type Name { Variant1(SomeType) }`.

## 5. Puntúa la actividad

- Se puede hacer coincidir patrones con las variantes de un tipo personalizado usando expresiones case.
- Si quieres añadir una condición adicional a un patrón, puedes añadir una guarda a ese patrón con la palabra clave `if`.
