# Introducción

Los hashes son un tipo de datos de Perl que contiene una colección desordenada de claves de tipo string emparejadas con valores escalares.

Una variable de hash se suele rellenar asignándole una lista, por ejemplo, `my %scores = (Alice => 10, Bob => 15, Charlie => 20);`.

Las listas se suelen separar con comas, pero verás con frecuencia lo que se conoce como la «coma gorda» `=>` para separar claves y valores dentro de una lista.
Su comportamiento es casi idéntico al de una coma, pero tiene la ventaja adicional de interpretar el elemento de la izquierda como un string.

Los hashes se pueden rellenar asignando a claves individuales, por ejemplo, `$scores{Alice} = 10;`.

Se puede acceder a los valores de un hash especificando las claves mediante un subíndice, por ejemplo, `$scores{Bob} # 15`.

Las claves de un hash son únicas.
Si se da una clave varias veces, solo se conservará el último valor indicado.

## Funciones

Entre las funciones para trabajar con hashes están [keys][keys] y [values][values], que permiten obtener esas partes respectivas de un hash como una lista.
Las listas que devuelven las funciones [keys][keys] y [values][values] pueden ser útiles para funciones de listas como [grep][grep], [map][map] y [sort][sort], así como para bucles [for][for].

Otras funciones de hash son [exists][exists], para comprobar si una clave existe en un hash (aunque su valor sea `undef`), y [delete][delete], para eliminar una clave de un hash.

## Variación de sigilos

Al obtener valores de un hash, el sigilo que se use determina el resultado.
El subíndice `{}` al final del nombre de la variable es lo que le indica a Perl que estás accediendo a un hash con ese nombre.

```perl
my %names = (Alice => 10, Bob => 15, Charlie => 20);

$names{Alice}; # 10            <- A scalar
@names{Alice}; # (10)          <- A slice (with only one key, this probably isn't what you want. There will be a warning.)
%names{Alice}; # ('Alice', 10) <- A key/index + value slice

$names{'Bob', 'Charlie'}; #                            <- An error (disabled syntax for an ancient feature.)
@names{'Bob', 'Charlie'}; # (15, 20)                   <- A slice
%names{'Bob', 'Charlie'}; # ('Bob', 15, 'Charlie', 20) <- A key/index + value slice
```

Aunque está permitido, por claridad se recomienda no dar el mismo nombre a variables de tipos distintos.
