# Pistas

Este ejercicio gira en torno a un tipo compuesto con palabra clave y uniones de tipos.

## 1. Define uniones de tipos

- Consulta el ejemplo de la introducción en el que se daba nombre a un tipo.

## 2. Implementa el tipo compuesto Player

- Todos los campos deben estar *anotados con tipos*, y dos de ellos con uniones de tipos.
- Consulta el ejemplo de `Node` de la introducción para ver un ejemplo concreto de campos anotados con tipos.
- Todos los campos deben tener los valores predeterminados que se indican en las instrucciones.

## 3. Preséntate

- Puedes usar un [operador ternario][control-flow] para obtener una solución de una sola línea.
- La función `ismissing` resulta útil aquí.

## 4. Implementa los métodos de incremento

- Los argumentos de los métodos deben estar anotados con los tipos correctos para `name` y `mana`.
- Consulta más ejemplos de firmas de funciones y de anotación de argumentos en la introducción.
- Aquí también puedes usar [operadores ternarios][control-flow] para soluciones de una sola línea.
- Puede resultar útil estudiar o repasar el concepto de `Multiple Dispatch` si es necesario.

## 5. Implementa la función title

- Usa tu función `increment`.
- Puedes usar un [operador ternario][control-flow] para obtener una solución de una sola línea.

## 6. Implementa la función revive

- Usa tu función `increment`.
- Devuelve un jugador modificado si estaba muerto, o un jugador sin modificar si estaba vivo.
