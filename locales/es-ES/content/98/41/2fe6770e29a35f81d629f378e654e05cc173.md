# Constructores de strings

Un `STR` nunca cambia. Así que `+` no puede añadirle nada: tiene que crear un string completamente nuevo con el contenido de los dos.

Eso no supone ningún problema si ocurre una vez. Dentro de un bucle, sí lo supone:

```sather
   -- don't
   script ::= "";
   loop
      script := script + lines.elt!;
   end;
```

Cada vuelta copia todo lo construido hasta ese momento a un string nuevo y desecha el anterior. Diez líneas significan diez copias, cada una más larga que la anterior. Cien líneas significan cien. El trabajo crece con el *cuadrado* del número de líneas, y un bucle que parece inofensivo se convierte en la parte lenta del programa.

## FSTR

`FSTR` es un string que *puede* cambiarse: un **constructor de strings**. Añadir a uno normalmente solo escribe en el espacio que ya tiene, así que un bucle sobre cien líneas hace más o menos el trabajo equivalente a cien líneas, en lugar de cien copias.

```sather
   script ::= #FSTR;
   loop
      script := script + lines.elt!;
   end;
   return script.str;
```

Hay tres cosas que conviene observar.

**`#FSTR` crea uno vacío.** `#FSTR(100)` crea uno con espacio ya reservado para cien caracteres, algo que merece la pena cuando se conoce el tamaño.

**Tienes que asignar el resultado de vuelta.** `script := script + ...`, nunca `script + ...` por sí solo. Normalmente el resultado es el mismo constructor con el que empezaste, pero cuando se le ha acabado el espacio es uno nuevo y más grande, y desechar el resultado te dejaría escribiendo en el antiguo.

**`.str` al final.** Una rutina que promete `: STR` tiene que devolver un `STR`, y `.str` crea uno a partir del constructor.

## Qué se puede añadir

El `+` sobre un `FSTR` acepta un string, un carácter, un número entero o un Boolean, así que normalmente no hace falta convertir nada antes:

```sather
   line ::= #FSTR;
   line := line + 1 + ". " + "Enter" + '!';   -- "1. Enter!"
```

## Saltos de línea

`"\n"` dentro de un string es un salto de línea: un solo carácter, escrito con dos.

```sather
   script := script + "Enter" + "\n" + "Exit";
```
