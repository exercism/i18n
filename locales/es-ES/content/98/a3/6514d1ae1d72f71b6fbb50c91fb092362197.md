# Introducción

Por defecto, los valores en C# son _mutables_, es decir, pueden cambiar con el tiempo. Para hacer que un valor sea _inmutable_, hay dos opciones:

1. Añadir el modificador `const`
2. Añadir el modificador `readonly`

El modificador `const` tiene algunas restricciones:

1. Solo se puede aplicar a tipos «constantes»: strings, Boolean y números.
1. El valor `const` debe inicializarse inmediatamente.

Si tu valor es de un tipo no constante o necesitas inicializar el valor en un constructor, se puede usar `readonly` para garantizar la inmutabilidad.
