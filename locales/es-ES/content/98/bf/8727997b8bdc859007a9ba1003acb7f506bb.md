# Instrucciones

En este ejercicio vas a escribir algo de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitas un permiso de conducir, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo de segunda mano.

## 1. Determina si vas a necesitar un permiso de conducir

Algunos tipos de vehículo requieren un permiso de conducir para conducirlos.
Supón que solo los tipos `"car"` y `"truck"` requieren permiso; todo lo demás se puede conducir sin permiso.

Implementa la función `needsLicense(kind)`, que recibe el tipo de vehículo y devuelve un Boolean que indica si necesitas un permiso para ese tipo de vehículo.

```kotlin
needsLicense("car")
// => true

needsLicense("bike")
// => false

needsLicense("truck")
// => true
```

## 2. Elige entre dos posibles vehículos que comprar

Evalúas tus opciones entre los vehículos disponibles.
Consigues reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para ello, implementa la función `chooseVehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que aparece primero en el [orden lexicográfico][lexicographical-order].

```kotlin
chooseVehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

chooseVehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

## 3. Calcula una estimación del precio de un vehículo de segunda mano

Ahora que has tomado una decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo de segunda mano, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80% del precio original que tenía cuando era nuevo.
Si tiene al menos 10 años, cuesta el 50%.
Si el vehículo tiene al menos 3 años pero menos de 10, cuesta el 70% del precio original.

Implementa la función `calculateResellPrice(originalPrice, age)`, que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en el concesionario.

```kotlin
calculateResellPrice(1000, 1)
// => 800

calculateResellPrice(1000, 5)
// => 700

calculateResellPrice(1000, 15)
// => 500
```

[lexicographical-order]: https://en.wikipedia.org/wiki/Lexicographic_order
