# Pistas

## 1. Determina si vas a necesitar un carné de conducir

- Usa el [operador de igualdad][equality-operator] para comprobar si tu entrada es igual a un string determinado.
- Usa uno de los dos [operadores lógicos][logical-operators] que aprendiste en el concepto de Boolean para combinar los dos requisitos.
- **No** necesitas un condicional para resolver esta tarea. Puedes devolver directamente la expresión booleana que construyas.

## 2. Elige entre dos posibles vehículos para comprar

- Usa un [operador de comparación][comparison-operators] para determinar qué opción va primero en orden lexicográfico.
- Usa una [plantilla de string][string-templates] para crear la frase de recomendación.

## 3. Calcula una estimación del precio de un vehículo de segunda mano

- Usa una [instrucción if-else if-else][if-statement] para determinar el porcentaje.
- En las dos condiciones if usa [operadores de comparación][comparison-operators] para comparar la antigüedad del coche con los valores límite.
- Para calcular el resultado, aplica el porcentaje al precio original. Por ejemplo, `30% of x` se puede calcular dividiendo `30` entre `100` y multiplicando por `x`.
