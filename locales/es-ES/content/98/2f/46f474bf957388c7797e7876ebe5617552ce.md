# Bucles while y until

Un bucle es una estructura de control que permite ejecutar código repetidamente en función de una condición dada.

## Bucles while

Un bucle `while` es una estructura de control que permite ejecutar código repetidamente en función de una condición dada.
El código de un bucle `while` se seguirá ejecutando mientras la condición se evalúe como verdadera.
Los bucles `while` se usan a menudo cuando no se conoce de antemano el número de iteraciones, pero pueden emplearse en cualquier situación en la que se necesite un bucle.

La condición se evalúa antes de que se ejecute el código del bucle, lo que significa que, si la condición es falsa, el código del bucle no se ejecutará nunca.

```crystal
i = 0
while i < 3
  puts i
  i += 1
end

# Output:
# 0
# 1
# 2
```

Cuando quieras iterar sobre un string, puedes recorrer la longitud del string.

```crystal
str = "Hello"
i = 0
while i < str.size
  puts str[i]
  i += 1
end

# Output:
# H
# e
# l
# l
# o
```

## Bucles until

Los bucles `until` funcionan igual que los bucles `while`, salvo que el código del bucle se seguirá ejecutando hasta que la condición se evalúe como verdadera.
Es lo mismo que la diferencia entre `if` y `unless`.

```crystal
i = 0
until i == 3
  puts i
  i += 1
end
```

### Bucles infinitos

Un error habitual con los bucles `while` es entrar en un «bucle infinito», del que nunca se sale.
Un bucle infinito puede deberse a que una condición _nunca_ se evalúe como verdadera o falsa.
A menudo se debe a un error del programador; por ejemplo, olvidarse de incrementar la variable del bucle.
Pero a veces un bucle infinito es la forma más clara de implementar la lógica del programa.
O puede ser imprescindible repetir el bucle indefinidamente; por ejemplo, un servidor HTTP espera una conexión entrante, la atiende y luego espera la siguiente conexión.

## Break

La palabra clave `break` permite salir de un bucle antes de tiempo.
Esto puede resultar útil cuando quieres salir de un bucle antes de tiempo bajo ciertas condiciones.

```crystal
i = 0
while i <= 3
  puts i
  i += 1
  if i == 2
    break
  end
end

# Output:
# 0
# 1
```

## Next

La palabra clave `next` permite saltar a la siguiente iteración de un bucle.
Esto puede resultar útil cuando quieres saltarte iteraciones concretas de un bucle.

```crystal
i = 0
while i <= 3
  i += 1
  if i == 2
    next
  end
  puts i
end

# Output:
# 1
# 3
```

## Los tipos dentro de un bucle

El tipo de la variable puede ser diferente dentro de un bucle.
En el siguiente ejemplo, el tipo de `a` es `Int32 | String` porque puede ser `Int32` o `String` en la primera parte del bucle.
La variable `a` solo tendrá el tipo `Int32 | String` en la primera parte del bucle, ya que cuando el bucle empieza contiene `Int32`, y en la segunda iteración contiene un `String`.
Este sistema de tipos múltiples se explicará en detalle más adelante.
Pero como tenemos la certeza de que la segunda parte del bucle solo contendrá `String`, el tipo de `a` es `String` en la segunda parte del bucle.
En tiempo de ejecución, nunca contendrá `Int32` y `String` a la vez.

```crystal
i = 0
a = 4
while i < 3
  p typeof(a)
  # => Int32 | String
  a = "4"
  p typeof(a)
  # => String
  i += 1
end
```
