# Pistas

## General

- Lee sobre los [opcionales][optionals] y sobre las [condicionales][conditionals] en _A Tour of Swift_, de Apple.

## 1. Escribe una función que calcule los tamaños de las porciones y que devuelva nil si la entrada no es válida.

- El área de un círculo es _pi_ \* _r_<sup>2</sup>, donde _r_ es la mitad del diámetro.
- Puedes usar la conversión de tipos para convertir un `Int` en un `Double`.
- Puedes usar un condicional al estilo `guard` para salir antes si alguno de los parámetros no es válido.

## 2. Procesa la entrada de tu aplicación web para determinar la porción más grande.

- El enlace de opcionales se puede usar para determinar si un opcional tiene un valor y para extraer ese valor si lo hay.
- Puedes salir de la función antes de tiempo si sabes cuál debería ser el valor devuelto sin seguir procesando.
- No puedes comparar `nil` directamente con valores que no sean `nil`.
- Puedes usar instrucciones `switch` y patrones opcionales para comparar valores opcionales.
