# Instalación

Este track usa ReScript 12 y necesita [Node.js][nodejs] 22 o superior.
Muchos sistemas ya lo traen preinstalado, o puede que lo hayas instalado antes para otro track.

Abre un terminal y ejecuta:

```sh
node -v
```

Si Node no está instalado o se muestra una versión más antigua, sigue las [instrucciones oficiales de instalación de Node.js][nodejs-install] para tu plataforma.

## Instalación de dependencias

Cada ejercicio de ReScript es un proyecto npm independiente.
Después de descargar un ejercicio con la [CLI de Exercism][exercism-cli], instala las dependencias del proyecto, incluido ReScript, y ya puedes empezar:

```sh
cd /path/to/exercise
npm install
```

## Soporte para editores

El proyecto ReScript mantiene una [lista de plugins de editor, tanto oficiales como de la comunidad][rescript-plugins].
