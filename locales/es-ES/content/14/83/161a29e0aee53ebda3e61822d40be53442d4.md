# Introducción

Una declaración `MACRO:` es como `:`, pero el cuerpo se ejecuta en *tiempo de compilación* y debe devolver una quotation. El compilador sustituye esa quotation devuelta por la llamada al macro. Como el cuerpo es código Factor corriente, construir la quotation resultante no es más que manipular secuencias de palabras.

```factor
USING: kernel macros sequences ;

MACRO: twice ( quot -- compound )
    dup append ;

: shout-twice ( name -- ) [ " ahoy!" append print ] twice ;
! At compile time, the call site is replaced with
! [ " ahoy!" append print " ahoy!" append print ].
```

Las entradas de un macro son *valores literales en el lugar de la llamada*. Si pasas un valor que no es literal, el compilador se negará a especializarlo, porque el cuerpo del macro necesita el valor en tiempo de compilación, no en tiempo de ejecución.

Un pariente cercano es el bloque de evaluación en tiempo de análisis `<< … >>`, que ejecuta Factor arbitrario en tiempo de compilación sin el contrato de devolver una quotation. Ambos forman parte de la maquinaria [`macros`][macros] de Factor.
