# Acerca de

Un string representa datos textuales.
En Swift, un [`String`][strings-and-characters] es una colección ordenada de valores `Character`, donde cada carácter representa un carácter Unicode.

Creas un string con un literal de cadena, que es una secuencia de caracteres rodeada de comillas dobles (`"`).
Para strings de varias líneas, usa tres comillas dobles (`"""`):

```swift
let hello: String = "Hello, World!"

let poem: String = """
Roses are red,
Violets are blue.
Sugar is sweet,
And so are you.
"""
```

Los strings de Swift se integran a la perfección con la clase [`NSString`][nsstring-docs] del framework Foundation, lo que da acceso a amplias capacidades de procesamiento de texto.

## Caracteres

Un `Character` representa un único grupo de grafemas extendido, es decir, un carácter legible por humanos compuesto por uno o más [valores escalares de Unicode][unicode-scalar-values].
Un valor escalar de Unicode es un punto de código de 21 bits en el rango `U+0000` a `U+D7FF` inclusive, o `U+E000` a `U+10FFFF` inclusive.

```swift
let aChar: Character = "A"
```

## Inferencia de tipos

Cuando escribes un literal de cadena, Swift infiere automáticamente que su tipo es `String`.
Para almacenar un solo carácter como `Character`, debes indicar una anotación de tipo explícita:

```swift
let aString = "A"        // Inferred as String
let aChar: Character = "A" // Explicitly typed as Character
print(type(of: aString)) // Prints String
print(type(of: aChar))   // Prints Character

// The following code will not compile:
let badChar: Character = "Too many characters"
// Error: Cannot convert value of type 'String' to specified type 'Character'
```

## Concatenación

Puedes unir strings con el operador de suma (`+`):

```swift
print("honey" + "comb")
// Prints "honeycomb"
```

No puedes concatenar directamente un `Character` a un `String` con `+` sin convertir antes el carácter en un string.
Sin embargo, puedes usar el método [`append(_:)`][append] para añadir directamente un string o un carácter a un string mutable:

```swift
var greeting = "Hello"
let world = ", world"
let period: Character = "."

greeting.append(world)
print(greeting) // Prints "Hello, world"

greeting.append(period)
print(greeting) // Prints "Hello, world."
```

## Interpolación de strings

La [interpolación de strings][string-interpolation] te permite construir un string insertando constantes, variables, literales y expresiones dentro de literales de cadena.
Escribe cada expresión entre paréntesis precedidos de una barra invertida (`\(` ... `)`):

```swift
let radius = 5.0
let circle = "The area of a circle with radius \(radius) is \(Double.pi * radius * radius)"
print(circle) // Prints "The area of a circle with radius 5.0 is 78.53981633974483"
```

## Propiedades de los strings y los caracteres

Los strings y los caracteres ofrecen varias propiedades para inspeccionar su contenido.

### Propiedades de los strings

Entre las propiedades más comunes de los strings se incluyen:

| Propiedad | Descripción | Ejemplo |
| --------- | ----------- | ------- |
| `isEmpty` | Devuelve `true` si el string no tiene caracteres | `"Hello".isEmpty` se evalúa como `false` |
| `count`   | Devuelve el número de caracteres del string | `"Hello".count` se evalúa como `5` |

Para ver una lista completa de propiedades, consulta la [documentación de String de Apple][string-docs].

### Propiedades de los caracteres

Entre las propiedades más comunes de los caracteres se incluyen:

| Propiedad      | Descripción                                   | Ejemplo |
| -------------- | --------------------------------------------- | ------- |
| `isLowercase`  | Devuelve `true` si el carácter está en minúscula | `"a".isLowercase` se evalúa como `true` |
| `isUppercase`  | Devuelve `true` si el carácter está en mayúscula | `"A".isUppercase` se evalúa como `true` |
| `isNumber`     | Devuelve `true` si el carácter es un dígito   | `"1".isNumber` se evalúa como `true` |
| `isWhitespace` | Devuelve `true` si el carácter es un espacio en blanco | `" ".isWhitespace` se evalúa como `true` |

Para ver una lista completa de propiedades, consulta la [documentación de Character de Apple][character-docs].

## Conversión de tipos

Puedes convertir otros tipos en strings con el inicializador `String(_:)`, que admite tipos estándar como `Int`, `Double` y `Character`:

```swift
let charX: Character = "x"
print(String(charX))     // Prints "x"
print(String(110))       // Prints "110"
print(String(Double.pi)) // Prints "3.141592653589793"
```

## Caracteres especiales

Los literales de cadena de Swift admiten varias [secuencias de escape][special-characters] para caracteres especiales:

| Secuencia | Descripción |
| --------- | ----------- |
| `\0`      | Carácter nulo |
| `\\`      | Barra invertida |
| `\t`      | Tabulador horizontal |
| `\n`      | Salto de línea |
| `\r`      | Retorno de carro |
| `\'`      | Comilla simple |
| `\"`      | Comilla doble |
| `\u{n}`   | Valor escalar Unicode arbitrario (hexadecimal) |

```swift
let quote: String = "\"Hello\", he said."
print(quote) // Prints "Hello", he said.

let unicode: Character = "\u{1F496}"
print(unicode) // Prints 💖
```
