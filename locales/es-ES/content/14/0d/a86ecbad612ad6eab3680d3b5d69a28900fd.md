# Pistas

## General

- [Python Docs: Enum](https://docs.python.org/3/library/enum.html)

## 1. Analiza el nivel de registro

- Usa [`str.split`](https://www.w3schools.com/python/ref_string_split.asp) para extraer el nivel de registro del mensaje.
- Con la parte extraída del string, accede al miembro del enum usando `LogLevel(string)` y devuélvelo.

## 2. Admite niveles de registro desconocidos

- Crea en el enum existente un nuevo miembro de nivel de registro llamado Unknown.
- Comprueba si la parte extraída del string es un valor del enum `LogLevel`.
- Si el valor no coincide con ninguno de los valores de los miembros del enum, devuelve el miembro Unknown de `LogLevel`.

## 3. Convierte la línea de registro al formato corto

- Busca el código (un número entero) del nivel de registro a partir del nivel de registro; hay varias soluciones posibles: condicionales, otro enum o cualquier otra solución.
- Usa el formateo de strings para devolver un código de nivel y un mensaje con el formato adecuado.

## 4. Crea un alias

- Crea en el enum existente el nuevo miembro alias llamado Warn.
- Devuelve el miembro recién creado.

## 5. Todos los nombres y valores de los miembros

- Itera sobre todos los miembros del enum y devuelve un array de tuplas.
- La tupla se puede construir con `(item1, item2)`.
- Se puede acceder al nombre y al valor del enum con `member.name` y `member.value`.
- Devuelve el array que contiene todas las tuplas.
