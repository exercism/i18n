# Asignación de combustible

## Enunciado del problema

Todos los empleados de ABC Corp reciben una asignación de combustible ilimitada. Se pide a los empleados que envíen un registro cada vez que repostan en sus vehículos. Estos registros se añaden al mismo archivo CSV y se procesan a final de mes.

Como miembro del equipo de operaciones digitales, tu tarea consiste en leer este archivo CSV y escribir los resultados en otro archivo CSV. El archivo de salida debe contener una entrada por cada empleado con los siguientes datos:

- Número de empleado
- Número de repostajes
- Coste total del combustible
- Total de galones
- Total de millas acumuladas

Recibes dos argumentos de tipo `string`.

1. Ruta del archivo CSV de entrada
1. Ruta del archivo CSV de salida

El archivo CSV de entrada tiene `n` líneas y cada línea tiene el siguiente formato.

| Nombre de columna      | Tipo en Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| odometer_reading   | `int`       |
| gallons   | `decimal` |
| gas_price(USD)  |`decimal`|

El archivo de salida debe contener una entrada por cada empleado, ordenadas en orden ascendente según el `employee_id`. Cada línea tiene el siguiente formato:

| Nombre de columna      | Tipo en Ballerina |
| ----------- | ----------- |
| employee_id      | `int`       |
| gas_fill_up_count   | `int`        |
| total_fuel_cost(USD)   | `decimal` |
| total_gallons  |`decimal`|
| total_miles_accrued  |`int`|

## Restricciones

- Número de líneas `n` del archivo CSV de entrada: 2 <= n <= 1000
- Número de empleados de la empresa: 97
- El precio de la gasolina es por galón
- No hay registros de repostaje ausentes

## Ejemplo 1

- Entrada: `example01_input.csv`

```csv
2312,230,18.561,4.56
2312,500,19.345,4.89
```

- Salida: `example01_output.csv`

```csv
2312,2,179.23521,37.906,270
```
