# Anexo a las instrucciones

## Implementación

Debes definir un tipo personalizado 'DNA' con una función 'Counts' que devuelva dos valores:

- un recuento de frecuencias para la cadena de ADN dada
- un error (si hay nucleótidos no válidos)
