# Consejos

## General

- [El tutorial de diccionarios de Python][dict-tutorial] puede ser un buen punto de partida.
- La documentación de Python sobre [tipos de asignación: dicts][dict docs] también es bastante útil.

## 1. Crear un inventario a partir de un array

- Necesitas un [bucle `for`][for-loop] para recorrer el array de elementos y, después, insertar cada elemento en el diccionario si no está y aumentar el contador del elemento usando el acceso al diccionario.
- Puedes usar [`dict.setdefault`][dict setdefault] para asegurarte de que el valor esté establecido antes de aumentar el contador del elemento.
- Esta función debe [devolver][return-keyword] un dict.

## 2. Añadir elementos de un array a un diccionario existente

- Necesitas un [bucle `for`][for-loop] para recorrer el array de elementos y, después, insertar cada elemento si aún no está en el diccionario e [incrementar][increment] el contador del elemento usando el acceso al diccionario.
- Puedes usar [`dict.setdefault`][dict setdefault] para asegurarte de que el valor esté establecido antes de aumentar el contador del elemento.
- La función `create_inventory` puede usar la función `add_items` con un diccionario vacío como parámetro.
- Esta función debe [devolver][return-keyword] un dict.

## 3. Decrementar elementos del inventario

- Necesitas un [bucle `for`][for-loop] para recorrer el array de elementos; si el número de elementos no es `0`, entonces [decrementa][decrement] el número actual de elementos.
- Puedes usar la comprobación `key in dict`, que devuelve `True` si la clave existe, para asegurarte de que el valor está en el diccionario antes de decrementar el número de elementos.
- Esta función debe [devolver][return-keyword] un dict.

## 4. Eliminar un elemento por completo del inventario

- Si el elemento está en el diccionario, [elimínalo][dict-pop].
- Si el elemento no está en el diccionario, no hagas nada.
- Esta función debe [devolver][return-keyword] un dict.

## 5. Devolver el contenido del inventario

- Necesitas usar un [bucle `for`][for-loop] sobre el inventario y, si el número de elementos es mayor que `0`, añadir la `tuple` a una `list`.
- Puedes usar [`dict.items()`][dict items] para recorrer a la vez el elemento y el valor; `items()` devuelve una `tuple` que puedes usar o desestructurar, si es necesario.
- Esta función debe [devolver][return-keyword] un [array][list] de [tuplas][tuples].
