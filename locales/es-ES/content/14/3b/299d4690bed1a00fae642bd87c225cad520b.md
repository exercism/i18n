# Introducción

El ámbito de un valor se refiere al lugar del programa desde el que se puede acceder a ese valor.

## Los cuatro tipos de scope: bloque, función, prototipo de función y fichero

### Scope de bloque

Solo se puede acceder a un valor con scope de bloque desde dentro del bloque en el que se define.
Para obtener más información sobre los bloques, consulta el [concepto de bloque](../blocks/introduction.md#Introduction).

### Scope de función

El scope de función es un tipo especial de scope que se aplica a las etiquetas que se usan con las instrucciones `goto`.
No se pueden usar dos etiquetas con el mismo nombre en la misma función, aunque se definan en bloques distintos dentro de la función.

### Scope del prototipo de función

El scope del prototipo de función es otro tipo especial de scope que se aplica únicamente a los parámetros que se nombran dentro del prototipo (también llamado declaración, teniendo en cuenta que no todas las declaraciones son prototipos).
El nombre de un parámetro normalmente es opcional en una declaración de función.
El scope de un nombre solo es relevante dentro de la declaración.
Una definición de función no tiene por qué usar para un parámetro el mismo nombre que se usó en la declaración de la función.

### Scope de fichero

Se puede acceder a un valor con scope de fichero desde cualquier punto del fichero.
Cualquier valor de este tipo se define fuera de una función.
