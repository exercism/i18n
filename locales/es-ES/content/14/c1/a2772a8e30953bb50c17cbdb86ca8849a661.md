# Instrucciones

Izzy es una ávida observadora de pájaros que lleva la cuenta de cuántos pájaros han visitado su jardín en un día cualquiera.

Te ha pedido que la ayudes a llevar la observación de pájaros a un nuevo nivel y que implementes algunas herramientas que la ayuden a registrar y procesar los datos.

Has decidido almacenar los datos como un array de números enteros. El primer número del array es la cantidad de pájaros que han visitado tu jardín hoy, el segundo los de ayer, y así sucesivamente.

## 1. Comprueba cuántos pájaros han visitado hoy el jardín

Implementa la función `today`. Debe recibir un array con los recuentos diarios de pájaros y devolver el recuento de hoy. Si el array está vacío, debe devolver `0`.

```gleam
today([2, 5, 1])
// -> 2
```

## 2. Incrementa el recuento de hoy

Implementa la función `increment_day_count`. Debe recibir un array con los recuentos diarios de pájaros e incrementar en 1 el recuento de hoy. Si el array está vacío, devuelve `[1]`.

```gleam
increment_day_count([4, 0, 2])
// -> [5, 0, 2]
```

## 3. Comprueba si hubo algún día sin visitas de pájaros

Implementa la función `has_day_without_birds`. Debe recibir un array con los recuentos diarios de pájaros. Debe devolver `True` si hubo al menos un día en el que ningún pájaro visitó el jardín, y `False` en caso contrario. Si el array está vacío, esto cuenta como que todavía no se ha registrado ningún pájaro; devuelve `False`.

```gleam
has_day_without_birds([2, 0, 4])
// -> True

has_day_without_birds([3, 8, 1, 5])
// -> False
```

## 4. Calcula el número total de pájaros visitantes

Implementa la función `total`. Debe recibir un array con los recuentos diarios de pájaros y devolver el número total de pájaros que han visitado tu jardín desde que empezaste a recopilar los datos.

```gleam
total([4, 0, 9, 0, 5])
// -> 18
```

## 5. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.

Implementa la función `busy_days`. Debe recibir un array con los recuentos diarios de pájaros y devolver el número de días ajetreados.

```gleam
busy_days([4, 5, 0, 0, 6])
// -> 2
```
