# Introducción

El _operador ternario_ es una alternativa ligera y compacta para condicionales _if/else_ simples. Normalmente se usa en instrucciones de retorno (aunque no se limita a ellas) y solo necesita una única línea para tomar la decisión: devuelve el valor de la izquierda si la expresión es `true` y el valor de la derecha si es `false`, como se muestra a continuación:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muchas expresiones _if/else_ simples se pueden simplificar usando _operadores ternarios_.
