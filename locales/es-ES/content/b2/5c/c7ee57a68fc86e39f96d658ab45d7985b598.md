# Pruebas

Todos los ejercicios usan el framework [Pester][pester] para la simulación y la ejecución de pruebas.
Todas las pruebas estarán en un archivo llamado `[Exercise].tests.ps1`, como es el estándar en el framework Pester.
Si estás en el directorio correcto (es decir, el que contiene `[Exercise].ps1` y `[Exercise].tests.ps1`).
Puedes ejecutar las pruebas desde PowerShell llamando a:

``` PowerShell
Invoke-Pester
```

Esto ejecutará todos los archivos `.tests.ps1` que encuentre en el directorio.

Si usas un shell distinto de PowerShell, puedes ejecutar las pruebas llamando a:

``` PowerShell
pwsh -Command "Invoke-Pester"
```

## Ejecutar las pruebas en Visual Studio Code

Tienes que asegurarte de tener instalada [la extensión de PowerShell][extension] en Visual Studio Code.

Puedes ejecutar las pruebas en Visual Studio Code de varias maneras:

- Ejecutando el script `.Tests.ps1` desde el menú Debug. Los atajos de teclado son: `F5` o `Shift + F5`
- Desde el propio editor, haciendo clic en el enlace «Run Tests» que aparece encima de la palabra clave `Describe` en el código de la prueba
- Configurando una tarea para ejecutar el framework Pester

[pester]: https://github.com/pester/Pester
[extension]: https://marketplace.visualstudio.com/items?itemName=ms-vscode.PowerShell
