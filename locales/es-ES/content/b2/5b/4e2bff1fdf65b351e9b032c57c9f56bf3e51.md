# Pistas

## 1. Crea un nuevo visitante

- Vuelve a consultar el [concepto «Objetos»][concept-objects] para descubrir cómo crear un objeto con determinadas claves y valores.

## 2. Anula la entrada

- Usa el operador de asignación `=` para establecer la propiedad `ticketId` del objeto visitante en `null`.
- Después, devuelve el objeto visitante.

## 3. Determina el estado de la entrada

- Vuelve a consultar el [concepto «Condicionales»][concept-conditionals] para descubrir cómo devolver distintos valores desde la función de forma condicional.
- Usa la notación de corchetes para acceder al valor del `ticketId` dado en el objeto.
- Usa el operador de igualdad estricta `===` para comprobar si es `null` o `undefined`.

## 4. Mejora la respuesta del estado de la entrada

- Obtén el valor de un `ticketId` dado con notación de corchetes, como en la tarea anterior.
- No se necesita ningún condicional para resolver esta tarea.
- En su lugar, usa el [operador de coalescencia nula][mdn-nullish-coalescing] `??`.

## 5. Determina la versión de los términos y condiciones

- Vuelve a consultar el [concepto «Objetos»][concept-objects] para saber cómo acceder a valores anidados y empieza por escribir la expresión para obtener la versión.
- Después, usa el operador de [encadenamiento opcional][mdn-optional-chaining] para gestionar el caso del objeto gtc ausente.
- No se necesita ningún condicional para resolver esta tarea.
