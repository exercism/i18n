# Instrucciones

Trabajando para una fábrica, surge la necesidad de crear el mensaje impreso en las tarjetas identificativas de los empleados. Decides implementar esta función en JavaScript.

Una tarjeta identificativa necesita el `id` del empleado, el `name` del empleado, así como el departamento en el que trabaja.

## 1. Crea el texto de la tarjeta identificativa

Implementa una función llamada `printBadge` que devuelva el texto que se va a imprimir en la tarjeta identificativa.

El nombre del empleado siempre se proporciona, pero el número `id` del empleado y el nombre del departamento pueden ser `null`. El número `id` del empleado, si se proporciona, debe ir entre corchetes (por ejemplo, `[20]`).

La tarjeta identificativa de un propietario no debe tener `id` ni `department`.

```javascript
printBadge(20, 'Bob', 'Marketing');
// => '[20] Bob - MARKETING'
```
