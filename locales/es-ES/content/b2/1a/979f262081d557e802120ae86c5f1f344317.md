# Instrucciones


Eres el maître de un restaurante de hotel.
Tu tarea consiste en gestionar la distribución de los asientos del comedor en función del número de asientos disponibles hoy, el número de reservas y los invitados «sin reserva» que están esperando a que se les asigne un asiento.
A efectos de este ejercicio, los asientos se asignan por orden del primer asiento libre disponible.


En este ejercicio tienes que completar 6 retos diferentes de organización del comedor.


## 1. Crea el plano de asientos de hoy

Define la función `new_seating_chart(<size=22>)`, que recibe un argumento `size` que representa el número de asientos que se colocarán hoy en el comedor.
Si no se indica `size`, la función debe devolver un plano de asientos con 22 asientos.
Los valores de los asientos deben tener `None` como marcador para indicar que están disponibles para asignárselos a un invitado.


## 2. Organiza las reservas

Define la función `arrange_reservations(<guest_names>)` con 1 parámetro para un array de nombres de invitados.
Esto representa el número de personas que tienen un sitio reservado hoy en el comedor.


Esta función debe devolver un plano de asientos de tipo `dict` con el tamaño predeterminado (22 asientos), con los invitados asignados a los asientos en el orden en que aparecen en la lista de reservas.
Todos los asientos sin asignar deben establecerse a `None`.
Si no hay invitados, debe devolverse un plano de asientos «vacío» con todos los marcadores a `None`.


```python
>>> arrange_reservations(guests=["Walter", "Frank", "Jenny", "Carol", "Alice", "George"])
...
{1: 'Walter', 2: 'Frank', 3: 'Jenny', 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: None, 19: None, 20: None, 21: None, 22: None}
```


## 3. Encuentra todos los asientos «vacíos»

Define la función `find_all_available_seats(<seats>)`, que recibe 1 parámetro (_un diccionario con el plano de asientos_) y devuelve un `list` de números de asiento que están disponibles para los invitados que esperan en ese momento.
Si un asiento está vacío, su valor en el diccionario será `None`. Los asientos ocupados tendrán el nombre del invitado.


```python
>>> seats = {1: None, 2: 'Frank', 3: 'Jenny', 4: None, 5: 'Alice', 6: 'George', 7: None, 8: 'Carol', 9: None, 10: None, 11: None, 12: 'Walter'}

>>> find_all_available_seats(seats)
[1,4,7,9,10,11]
```

## 4. Capacidad actual de asientos libres

Define la función `current_empty_seat_capacity(<seats>)`, que recibe 1 parámetro: el `dict` de las reservas de asientos existentes.
La función debe devolver el número total de asientos que están vacíos.

```python
>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: "Occupied"})
1

>>> curr_empty_seat_capacity({1: "Occupied", 2: None, 3: None})
2
```


## 5. ¿Hay que hacer esperar a los invitados?

Define la función `accommodate_waiting_guests(<seats>, <guests>)`, que recibe dos parámetros.
El primer parámetro será un `dict` con el plano de asientos.
El segundo parámetro será un `list` de invitados que han llegado «sin reserva» de forma inesperada.
Primero tendrás que averiguar cuántos asientos hay disponibles y si puedes o no dar asiento a estos invitados que llegan sin avisar en ese momento.

Si no tienes suficientes asientos, devuelve el `dict` del plano de asientos sin cambios.

Si _sí_ hay asientos disponibles, asigna a los invitados sus sitios en el plano de asientos y devuélvelo actualizado.
**Consejo:** Puedes usar las funciones que has definido antes para hacer los cálculos por ti.


```python
# Guests cannot be accommodated.
>>> starting_reservations = {1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Carol', 2: 'Alice', 3: 'George', 4: None, 5: None, 6: None, 7: 'Frank', 8: 'Walter'}


# Guests can be accommodated.
>>> starting_reservations = {1: None, 2: None, 3: None, 4: 'Carol', 5: 'Alice', 6: 'George', 7: None, 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19:  'Jenny', 20: None, 21: None, 22: 'Walter'}
>>> accommodate_guests(starting_reservations, ["Mort", "Suze", "Phillip", "Tony"])
...
{1: 'Mort', 2: 'Suze', 3: 'Phillip', 4: 'Carol', 5: 'Alice', 6: 'George', 7: 'Tony', 8: None, 9: None, 10: None, 11: None, 12: None, 13: None, 14: None, 15: None, 16: None, 17: None, 18: 'Frank', 19: 'Jenny', 20: None, 21: None, 22: 'Walter'}
```

## 6. Vaciar asientos

Define la función `empty_seats(<seats>, <seat_numbers>)`, que recibe dos parámetros.
El primer parámetro será un diccionario con el plano de asientos.
El segundo parámetro es un array de números de asiento que tienes que «liberar» o vaciar; es decir, tienes que asignar el valor `None` al número de asiento.

Devuelve el `dict` de asientos después de actualizar los valores de los asientos que hay que vaciar.

```python
>>> empty_seats(seats={1: "Alice", 2: None, 3: "Bob", 4: "George", 5: "Gloria"}, seat_numbers=[5,3,1])
{1: None, 2: None, 3: None, 4: "George", 5: None}
```
