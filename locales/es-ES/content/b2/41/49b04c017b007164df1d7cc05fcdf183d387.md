# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de estos recursos:

- [Sitio web de CoffeeScript](http://coffeescript.org)
- [/r/coffeescript](https://www.reddit.com/r/coffeescript) es el subreddit de CoffeeScript.
- [StackOverflow](http://stackoverflow.com/questions/tagged/coffeescript) te sirve para buscar tu problema y ver si ya se ha respondido. También puedes hacer preguntas y responderlas.
