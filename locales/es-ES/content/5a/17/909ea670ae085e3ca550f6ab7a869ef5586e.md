# Instalación de [Scala](http://www.scala-lang.org)

Además de la CLI de Exercism y tu editor de texto favorito, para practicar con los ejercicios de Scala de Exercism necesitas pocas herramientas adicionales.

Todas ellas se pueden instalar automáticamente con la herramienta `Coursier`.

Consulta: [la página de descarga](https://www.scala-lang.org/download/) para obtener más detalles.

---

Después de ejecutar `cs setup`, estarás listo para empezar con la pista de Scala de Exercism.

Para empezar, consulta «[Ejecutar las pruebas](https://exercism.org/docs/tracks/scala/tests)».
