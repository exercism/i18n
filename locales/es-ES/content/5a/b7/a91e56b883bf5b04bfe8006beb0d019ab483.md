# Introducción

## Boolean en R

Los valores verdaderos o falsos están representados por el tipo `logical`.
Contiene solo dos valores: `TRUE` y `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

Hay cinco operadores Boolean en R, pero solo tres son relevantes en esta etapa del temario.
Los otros dos serán importantes al trabajar con vectores, que se tratan en varios conceptos posteriores.

`&&` es el «and» Boolean.
Se evalúa como `TRUE` si las expresiones a *ambos* lados de `&&` son `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` es el «or» Boolean.
Se evalúa como `TRUE` si una expresión a *cualquiera* de los dos lados de `||` es `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` es el «not» Boolean.
Intercambia los valores `TRUE` y `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expresiones más largas y complicadas, lo mejor es usar paréntesis para dejar clara tu intención.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE

TRUE || FALSE && (FALSE && TRUE)
#> [1] TRUE
```
