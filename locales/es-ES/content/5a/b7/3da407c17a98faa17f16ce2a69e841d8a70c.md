# Char

`Char` es un tipo de datos de Crystal que representa un punto de código [Unicode][unicode] de 32 bits.
Su tamaño los hace eficientes en memoria y les aporta propiedades específicas que los strings no tienen.
Se crean con comillas simples (`'`) y solo permiten que se coloque dentro un único punto de código Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Es bastante habitual trabajar con Char cuando se trabaja con strings en Crystal, ya que no pocos métodos de la clase String devuelven Char o aceptan Char como argumentos.
Por ejemplo, el método [`String#[]`][index] devuelve un Char, o el método [`String#chars`][chars] devuelve una colección de Char.

## Incremento y decremento

Como Char es un punto Unicode de 32 bits, admite incremento y decremento, de modo que si tienes `'a'`, puedes obtener `'b'` sumando uno.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

También existe un método llamado [`Char#succ`][succ], que devuelve el siguiente carácter de la tabla Unicode, y [`Char#pred`][pred], que devuelve el carácter anterior de la tabla Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## concatenación

Como Char solo está pensado para representar un punto Unicode de 32 bits, no se pueden concatenar dos Char.
Por lo tanto, un Char solo se puede concatenar con strings.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propiedades

Crystal tiene algunos métodos para obtener información sobre un carácter, como si es un número o una letra, o si es mayúscula o minúscula.
Aquí tienes una lista con algunos de los métodos; para ver la lista completa, consulta la [API de Char][char-api]:

| Method                           | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Devuelve `true` si el Char es un número              |
| [`Char#letter?`][letter]         | Devuelve `true` si el Char es una letra              |
| [`Char#lowercase?`][lowercase]   | Devuelve `true` si el Char es minúscula              |
| [`Char#uppercase?`][uppercase]   | Devuelve `true` si el Char es mayúscula              |
| [`Char#ascii?`][ascii]           | Devuelve `true` si el Char es un carácter ASCII      |
| [`Char#whitespace?`][whitespace] | Devuelve `true` si el Char es un carácter de espacio |

## Conversión

### Conversión entre puntos de código y Char

Como Char es un punto Unicode de 32 bits, puedes convertir entre Char y puntos de código (Int).
Esto se puede hacer con el método [`Char#ord`][ord], que devuelve el punto de código del Char, o con el método [`Int#chr`][chr], que devuelve el Char correspondiente al punto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Conversión entre tipos

Como ocurre con otros tipos de datos, Char tiene algunos métodos para convertir entre tipos.
El más habitual es el método `Char#to_s`, que convierte el Char en un string. Sin embargo, también existe el método `Char#to_i`, que convierte el Char en un Int, y el método `Char#to_f`, que convierte el Char en un Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```

## Secuencias de escape

Al igual que con los strings, hay ciertos caracteres que no se pueden escribir directamente y, para escribirlos, necesitas escaparlos.
Puedes usar el carácter `\` para escribir una secuencia de escape seguida del carácter que quieras escapar.

Estos son los caracteres especiales de Crystal:

| Value    | Description                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retroceso                     |
| `\e`     | Escape                        |
| `\f`     | Salto de página               |
| `\n`     | Salto de línea                |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulador horizontal          |
| `\v`     | Tabulador vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Comilla simple                |
| `\"`     | Comilla doble                 |
| `\377`   | Carácter ASCII octal          |
| `\xFF`   | Carácter ASCII hexadecimal    |
| `\uFFFF` | Carácter Unicode hexadecimal  |
