## General

- Para definir un string puedes usar comillas dobles `"`.
- Para concatenar strings puedes usar el operador `+`.
- Puedes usar `#{}` para interpolar un string.

## 1. Da la bienvenida a un nuevo invitado a la fiesta

- Un string se puede concatenar con otro string usando el operador `+`.

## 2. Da la bienvenida a un nuevo invitado a la fiesta cuyo cumpleaños es hoy

- Para convertir un número en un string puedes usar el método `to_s`.

## 3. Da indicaciones

- Para redondear un número, puedes usar el método `round`.
- Para obtener un carácter de un string puedes usar el método `[]`, que recibe un número entero, que es un índice.
