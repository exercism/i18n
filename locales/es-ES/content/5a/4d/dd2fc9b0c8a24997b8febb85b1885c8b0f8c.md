# Introducción

Un bloque es un conjunto de instrucciones y declaraciones agrupadas en una única unidad sintáctica.
Los bloques se definen a menudo, aunque no siempre, entre llaves.
Los bloques pueden anidarse dentro de funciones y dentro de otros bloques.

Una función se comporta en cierto modo como un bloque.
El identificador de una variable definida en una función no se puede ver fuera de la función, igual que el identificador de una variable definida en un bloque no se puede ver fuera del bloque.
Dos variables en dos funciones pueden tener el mismo nombre, ya que las dos funciones no se ven entre sí, igual que dos variables en dos bloques pueden tener el mismo nombre, ya que los dos bloques no se ven entre sí.
Pero las funciones y los bloques no son idénticos.
Una función no se puede anidar dentro de otra función, pero un bloque sí se puede anidar dentro de otro bloque.

En el siguiente ejemplo, `number` se define dentro de la función `main`.
`flag` se define dentro del bloque `if`, que está anidado dentro de la función `main`.
Las variables definidas dentro de un bloque solo son válidas dentro de ese bloque.
Por lo tanto, si intentas compilar el código, se produce un error de compilación.

```c
#include <stdio.h>

int main() {

  int number = 1;

  if (number == 1) {
      int flag = 1;
      printf("%d", flag);
  }

  // this line generates a compilation error
  // error: 'flag' undeclared (first use in this function)
  printf("%d", flag);
    
}
```

El mensaje de error puede resultar confuso, ya que `flag` _sí_ se usa antes en la función.
Sin embargo, `flag` se define dentro de un bloque que está dentro de la función.
El bloque interior puede «ver» la variable `number` de su función exterior, pero la función exterior no puede «ver» la variable `flag` definida dentro de su bloque interior.
En cuanto la ejecución sale del bloque, la variable `flag` se destruye automáticamente y deja de estar disponible para el programa.
La propia función `main` ve el identificador `flag` por primera vez en la última instrucción `printf`.
Si se elimina la última instrucción `printf`, el programa se compilará e imprimirá `1` al ejecutarse.
Esto se debe a que la variable `flag` es válida en el bloque que contiene la primera instrucción `printf`.

A partir de `C99`, las instrucciones `if`, `for`, `while` y `do` de una sola línea también se consideran bloques.
En el siguiente ejemplo, aunque `i` no se define entre llaves, solo existe en el bloque definido por la instrucción `for`, y no es visible para la función `main` exterior.

```c
#include <stdio.h>

int main() {

    for (int i = 0, j = 11; i < j; i+=2)
        printf("%d", i);

    // this line generates a compilation error
    // error: 'i' undeclared (first use in this function)
    printf("%d", i);
    
}
```

Si se elimina la última instrucción `printf`, el programa se compilará e imprimirá `0 2 4 6 8 10 ` al ejecutarse.
Algunos lenguajes, como Go y Rust, dejan claro explícitamente que las instrucciones condicionales y de bucle de una sola línea constituyen un bloque.
Exigen que esas instrucciones de una sola línea se sigan escribiendo entre llaves.
