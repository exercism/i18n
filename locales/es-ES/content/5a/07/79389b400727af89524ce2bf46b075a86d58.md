# Acerca de

Además del condicional `if`, también existe la instrucción `switch` para ejecutar lógica de forma condicional. Se usa cuando hay que comparar una sola variable con varias variantes. Para una variable cualquiera x, la instrucción `switch` de Haxe tiene la siguiente sintaxis.

```haxe
var a = 2;

switch (a) {
  case 0:
    trace("a is 0");
  case 1:
    trace("a is 1");
  case 2:
    trace("a is 2");
  default:
    trace("a is something else");
}

// a is 2
```

El caso `default` se ejecuta cuando no coincide ningún otro caso.
