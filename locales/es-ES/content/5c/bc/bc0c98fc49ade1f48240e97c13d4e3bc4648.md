# Introducción

## Result

El tipo `Result` es la solución que ofrece el lenguaje Elm para informar de errores y además permite recuperarse de ellos. Se parece bastante al tipo `Maybe`, pero, aunque `Maybe` lo pueden devolver funciones que quizá fallen, no te dice nada sobre por qué ha fallado. `Result` incluye ese contexto sobre por qué ha fallado algo.

El tipo `Result` se define así:

```elm
type Result error value
  = Ok value
  | Err error
```

Esto se conoce como una definición de «tipo personalizado» en la terminología de Elm.
La `error` y `value` de `OK value` y `Error error` representan una variable de tipo, lo que significa que puede ser cualquier tipo, como `Int`, `Bool` o `String`.
Por eso, un `Result String Int` es una variable que se espera que contenga un `Int`, y si hay un error, este se representará como un `String`.
Existe un [módulo Result](https://package.elm-lang.org/packages/elm/core/latest/Result) con un montón de funciones auxiliares muy útiles para trabajar con `Result`.
