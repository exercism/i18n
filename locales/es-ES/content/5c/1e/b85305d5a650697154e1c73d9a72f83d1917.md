# Instrucciones

En este ejercicio vas a jugar con un coche teledirigido, para el que por fin has ahorrado suficiente dinero para comprarlo.

Los coches empiezan con la batería llena (100%).
Cada vez que conduces el coche con el mando a distancia, recorre 20 metros y consume un uno por ciento de la batería.
El apodo del coche no se conoce hasta que se crea.

El coche teledirigido tiene una pantalla LED llamativa que muestra dos datos:

- La distancia total que ha recorrido, mostrada como: `"<METERS> meters"`.
- La carga restante de la batería, mostrada como: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0%, ya no puedes conducir el coche y la pantalla de la batería mostrará `"Battery empty"`.

## 1. Crea un coche teledirigido completamente nuevo

Implementa la función `new_remote_control_car/0` para que devuelva un objeto de coche teledirigido completamente nuevo:

```jq
new_remote_control_car
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": null
#    }
```

## 2. Crea un coche teledirigido completamente nuevo con un apodo

Implementa la función `new_remote_control_car/1` para que devuelva un objeto de coche teledirigido completamente nuevo con un apodo proporcionado:

```jq
new_remote_control_car("Blue")
# => {
#      "battery_percentage": 100,
#      "distance_driven_in_meters": 0,
#      "nickname": "Blue"
#    }
```

## 3. Muestra la distancia

Implementa la función `display_distance/0`, que toma un objeto de coche como entrada y devuelve el string de la distancia tal y como se muestra en la pantalla LED:

```jq
new_remote_control_car | display_distance
# => "0 meters"
```

## 4. Muestra el porcentaje de batería

Implementa la función `display_battery/0`, que toma un objeto de coche como entrada y devuelve el string del porcentaje de batería tal y como se muestra en la pantalla LED:

```jq
new_remote_control_car | display_battery
# => "Battery at 100%"
```

Si la batería está al 0%, la pantalla de la batería mostrará «Battery empty».

## 5. Conducir cambia la batería y la distancia recorrida

Implementa la función `drive/0` que:

- toma un objeto de coche como entrada
- incrementa en 20 el número de metros recorridos
- consume un 1% de la batería
- devuelve el objeto de coche modificado

```jq
new_remote_control_car("Red") | drive
# => {
#      "battery_percentage": 99,
#      "distance_driven_in_meters": 20,
#      "nickname": "Red"
#    }
```

## 6. Ten en cuenta la conducción con la batería agotada

Actualiza la función `drive/0` para que no aumente la distancia recorrida ni disminuya el porcentaje de batería cuando la batería está agotada (al 0%):

```jq
{
  battery_percentage: 0,
  distance_driven_in_meters: 2000,
  nickname: "Red"
} | drive
# => {
#      "battery_percentage": 0,
#      "distance_driven_in_meters": 2000,
#      "nickname": "Red"
#    }
```
