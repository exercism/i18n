# Instrucciones

Eres un gran aficionado a la observación de aves y llevas la cuenta de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de pájaros que han visitado tu jardín.

## 1. Comprueba cuáles eran los recuentos la semana pasada

Para poder comparar, siempre tienes cerca una copia de los recuentos de la semana pasada, que eran: 0, 2, 5, 3, 7, 8 y 4. Implementa el método `BirdWatcher.getLastWeek()`, que devuelve los recuentos de la semana pasada:

```java
BirdWatcher.getLastWeek();
// => [0, 2, 5, 3, 7, 8, 4]
```

## 2. Comprueba cuántos pájaros han visitado hoy

Implementa el método `BirdWatcher.getToday()` para devolver cuántos pájaros han visitado tu jardín hoy. Los recuentos de pájaros están ordenados por día: el primer elemento es el recuento del día más antiguo y el último es el recuento de hoy.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getToday();
// => 1
```

## 3. Incrementa el recuento de hoy

Implementa el método `BirdWatcher.incrementTodaysCount()` para incrementar el recuento de hoy:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.incrementTodaysCount();
birdCount.getToday();
// => 2
```

## 4. Comprueba si hubo un día sin pájaros visitantes

Implementa el método `BirdWatcher.hasDayWithoutBirds()`, que devuelve `true` si hubo un día en el que ningún pájaro visitó el jardín; en caso contrario, devuelve `false`:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.hasDayWithoutBirds();
// => true
```

## 5. Calcula el número de pájaros que han visitado durante los primeros días

Implementa el método `BirdWatcher.getCountForFirstDays()`, que devuelve el número de pájaros que han visitado tu jardín desde el comienzo de la semana, pero limita el recuento al número de días especificado desde el principio de la semana.

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getCountForFirstDays(4);
// => 14
```

## 6. Calcula el número de días ajetreados

Algunos días son más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.
Implementa el método `BirdWatcher.getBusyDays()` para devolver el número de días ajetreados:

```java
int[] birdsPerDay = { 2, 5, 0, 7, 4, 1 };
BirdWatcher birdCount = new BirdWatcher(birdsPerDay);
birdCount.getBusyDays();
// => 2
```
