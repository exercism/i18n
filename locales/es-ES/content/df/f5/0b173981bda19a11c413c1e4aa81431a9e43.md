# Introducción

## Números

En Python hay tres tipos diferentes de números integrados: `ints`, `floats` y `complex`. Sin embargo, en este ejercicio solo vas a trabajar con `ints` y `floats`.

### ints

Los `ints` son números enteros. Por ejemplo: `1234`, `-10`, `20201278`.

Los enteros en Python tienen [precisión arbitraria][arbitrary-precision]: el número de dígitos solo está limitado por la memoria disponible del sistema anfitrión.

### floats

Los `floats` son números que contienen un punto decimal. Por ejemplo: `0.0`, `3.14`, `-9.01`.

Los números de coma flotante se suelen implementar en Python usando un `double` de C (_15 decimales de precisión_), pero su representación varía según el sistema anfitrión y otros detalles de implementación. Esto puede dar alguna sorpresa al trabajar con floats, pero es «suficientemente bueno» para la mayoría de las situaciones.

## Aritmética

Python admite por completo la aritmética entre `ints` y `floats`. Convierte los números de tipo más estrecho para que coincidan con sus equivalentes de tipo más amplio cuando se usan con los operadores aritméticos binarios (`+`, `-`, `*`, `/`, `//` y `%`).

Python considera que los `ints` son más estrechos que los `floats`. Por eso, usar un float en una expresión garantiza que el resultado también sea un float. Sin embargo, al hacer una división, el resultado siempre será un float, incluso si solo se usan enteros.

```python
# The int is widened to a float here, and a float type is returned.
>>> 3 + 4.0
7.0
>>> 3 * 4.0
12.0
>>> 3 - 2.0
1.0
# Division always returns a float.
>>> 6 / 2
3.0
>>> 7 / 4
1.75
# Calculating remainders.
>>> 7 % 4
3
>>> 2 % 4
2
>>> 12.75 % 3
0.75
```

Si necesitas un resultado de tipo int, puedes usar `//` para truncar el resultado.

```python
>>> 6 // 2
3
>>> 7 // 4
1
```

Para convertir un float en un entero, puedes usar `int()`. Para convertir un entero en un float, puedes usar `float()`.

```python
>>> int(6 / 2)
3
>>> float(1 + 2)
3.0
```
