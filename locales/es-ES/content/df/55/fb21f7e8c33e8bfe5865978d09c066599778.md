# Acerca de

Los combinadores convierten los patrones de reordenación de la pila en palabras con nombre y componibles. Cuando ya has escrito suficiente Factor, dejas de pensar «necesito hacer `dup`, luego ejecutar F y luego conservar el original» y simplemente escribes `[ F ] keep`.

| patrón                             | reordenaciones                | combinador      |
|------------------------------------|-------------------------------|-----------------|
| aplicar F, conservar la entrada    | `dup F swap`                  | `[ F ] keep`    |
| dos funciones de una entrada       | `dup F swap G`                | `[ F ] [ G ] bi`|
| tres funciones de una entrada      | enrevesado                    | `[ F ] [ G ] [ H ] tri` |
| muchas funciones de una entrada    | muy enrevesado                | `{ Fs … } cleave`|
| operar sobre los valores *bajo* la cima | `swap F swap`            | `[ F ] dip`     |
| la misma operación sobre dos valores | `swap F swap F`             | `[ F ] bi@`     |
| operaciones distintas sobre dos valores | `swap F swap G`          | `[ F ] [ G ] bi*`|

La familia con prefijo `2` (`2bi`, `2dip`, `2tri`, `2dup`, `2drop`, `2nip`, `2swap`) hace lo mismo cuando cada operación necesita *dos* entradas; `3dup` y `4dup` extienden el recurso de duplicar a tres o cuatro valores de la parte superior de la pila.

Además de la familia cleave/dip/bi, [`kernel`][kernel] también ofrece variantes de flujo de control que propagan `f` limpiamente:

| palabra     | efecto                                              |
|-------------|-----------------------------------------------------|
| `if*`       | la rama verdadera ve el valor; la falsa, no         |
| `?last`     | el último elemento de una secuencia, o `f` si está vacía |
| `pop*`      | variante de `pop` que descarta (modifica un vector) |
| `dupd`      | duplica el *segundo* desde la cima                  |
| `pick`      | copia el *tercero* desde la cima a la cima          |
| `swapd`     | intercambia el segundo y el tercero desde la cima   |
| `rotd`      | rota los tres elementos inferiores de una pila de cuatro niveles |
| `tuck`      | copia la cima debajo del segundo desde la cima      |
| `with`      | incorpora un valor fijo en una quotation para HOS   |
| `while`     | bucle mientras se cumple un predicado               |
| `until`     | bucle hasta que se cumple un predicado              |

Elegir el combinador adecuado es en sí mismo una habilidad. La regla general: cuando el cuerpo de una definición contiene más de una palabra de reordenación seguida, normalmente hay un combinador que captura mejor la intención.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
