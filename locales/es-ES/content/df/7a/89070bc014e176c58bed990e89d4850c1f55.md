# Instrucciones

Eres docente.
Al final del año, has generado una nota numérica para cada uno de tus estudiantes.
Ahora tienes que traducir esa nota a una nota con letra y contar cuántos estudiantes han obtenido cada nota con letra.

## 1. Traduce una nota numérica a una nota con letra

La función `letter_grade` recibe como entrada una nota numérica y devuelve la letra.
Usa estos rangos:

| Letra |      Nota |
| :---: | --------: |
|   A   | 90% - 100% |
|   B   |  80% - 89% |
|   C   |  70% - 79% |
|   D   |  60% - 69% |
|   F   |   0% - 59% |

Ejemplo:

```jq
75 | letter_grade   # => "C"
```

## 2. Cuenta el número de estudiantes para cada nota con letra

La función `count_letter_grades` recibe un objeto que asocia los nombres de los estudiantes con sus notas.
La salida será un objeto que asocia cada nota con letra con el número de estudiantes que tienen esa nota.

Ejemplo:

```jq
{"Joe": 78, "Jane": 93, "Richard": 72} | count_letter_grades
# => {"A": 1, "B": 0, "C": 2, "D": 0, "F": 0}
```

Hay varias formas distintas de resolver esto.
Usa el filtro `reduce` para practicar.
