# Acerca de

El Printer de Common Lisp es la funcionalidad para enviar datos a flujos. Una función común en esta funcionalidad es `format`.

`format` recibe dos parámetros obligatorios: un flujo al que escribir y un string de control. El contenido del string de control determina cómo se utilizan los argumentos adicionales.

El primer parámetro tiene dos valores especiales: `t` y `nil`. `t` indica que se debe usar el flujo vinculado a `*standard-output*` y `nil` indica que se debe crear un string y devolverlo. `format` se evalúa a `nil` a menos que el parámetro de flujo sea `nil`.

El string de control puede contener directivas de formato, que se indican con un `~` seguido de un carácter (no importa si el carácter está en mayúscula o minúscula). La directiva de formato definirá si se consumen argumentos y cómo se formatean al flujo.

Las directivas de formato básicas importantes son:

* `~A` - formato _estéticamente_ de manera «legible para humanos».
* `~S` - formato en el _estándar_ para ser «legible para máquinas».
* `~%` - emite una nueva línea
* `~&` - emite una nueva línea a menos que ya se esté al principio de una línea.
* `~~` - emite una tilde.

Ejemplos:

```lisp
(format nil "The list is: ~A~%" (list 1 2 3)) ; => "The list is: (1 2 3)
                                                   "
(format nil "(format t ~S)" "hello world")    ; => "(format t \"hello world\""
(format nil "~&fresh~&lines")                 ;=> "fresh
                                                   lines"
(format nil "directives start with a ~~")     ; => "directives start with a ~"
```
