# Introducción

Python tiene dos construcciones de bucle.
Los bucles `while` sirven para la iteración _indefinida_ (no contada) y los bucles `for` para la iteración _definida_ (contada).
Las palabras clave `break`, `continue` y `else` ayudan a personalizar el comportamiento de los bucles.
Las funciones `range(<length of sequence>)` y `enumerate(<iterable>)` ayudan a contar las iteraciones y a gestionar los índices.


Los bucles `while` no tienen especificado un número de iteraciones que deban ejecutarse y continúan mientras la expresión `loop` o «test» se evalúe como `True`.
El bucle terminará cuando la expresión del bucle se evalúe como `False`.

```python
while expression:
    set_of_statements
```

Los bucles `for` recorren los valores de cualquier secuencia y terminan cuando no quedan más valores que devolver.
La función `range(<length of sequence>)` proporciona un contador `loop` o una secuencia cuando no hay ninguna estructura de datos ni otro iterable sobre el que iterar.

```python
# Python will keep track of the loop count internally.
for item in sequence:
    set_of_statements
    
# `range()` is used as an explicit loop counter.  
# This will loop 12 times, from index 0 to index 11.
for item in range(12):
    set_of_statements
```
