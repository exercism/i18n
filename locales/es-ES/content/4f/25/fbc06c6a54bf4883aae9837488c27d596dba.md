# Ejecutar las pruebas

Desde la terminal, cambia al directorio base del ejercicio y a continuación ejecuta las pruebas con:

```bash
$ gleam test
```

Esto ejecutará el archivo de pruebas que se encuentra en la subcarpeta `test`, un archivo que termina en `_test.gleam`.

## Funciones de prueba

Las pruebas usan un [framework de pruebas personalizado](https://github.com/exercism/gleam-test-runner/tree/main/runner).
Cualquier función pública en el directorio `test` cuyo nombre termine en `_test` será considerada una prueba por el framework de pruebas.

Por ejemplo:

```gleam
import bob
import exercism/should

pub fn shouting_test {
  bob.hey("WATCH OUT!")
  |> should.equal("Whoa, chill out!")
}
```
