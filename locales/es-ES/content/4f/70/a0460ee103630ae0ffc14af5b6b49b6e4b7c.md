## 1. Define el tipo `Fiberator`

- `n` indica cuántos números hay que generar.
- Mantenlo simple: no hace falta más información.

## 2. Implementa el método o los métodos `iterate`

- Consulta la Introducción para ver detalles importantes de la implementación.
- El argumento `state` no tiene por qué ser un número entero. Puede ser de cualquier tipo.
- Piensa qué valores necesitas para calcular el siguiente elemento. Una tupla de esos valores debería ser el argumento `state`.
- El método `iterate` devuelve una `Tuple` con dos valores `(item, state)`. `item` es el número de Fibonacci, es decir, el `item` en `for item in Fiberator(10)`.
- Si tu `state` incluye varios valores, considera usar una tupla con nombre para aclarar el significado de cada valor.
  - Esto es útil para desempaquetar, pero no es obligatorio.
