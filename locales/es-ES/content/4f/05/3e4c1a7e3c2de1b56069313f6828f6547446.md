Aunque concatenar strings manualmente en Haxe es posible, Haxe admite la [interpolación de strings][string-interpolation], que proporciona una sintaxis más corta y cómoda:

```haxe
var x = 42;
//The following two statements are equivalent:

// manual concatenation
trace("the number is " + x);

// using interpolation
trace('the number is $x');
```

Como se muestra arriba, los strings interpolados se encierran entre comillas simples (`'`), a diferencia de los [strings][strings] habituales, y pueden contener identificadores especiales denotados por el signo del dólar (`$`) que activan la interpolación.

Es posible incluir expresiones completas usando `${expr}`, donde `expr` es cualquier expresión válida de Haxe:

```haxe
trace('the next number is ${x + 1}');
```

Para suprimir la interpolación cuando se desea un signo de dólar real, se puede usar `$$`:

```haxe
trace('the price is $$42'); // outputs: the price is $42
```

Por último, ten en cuenta que la interpolación de strings es una funcionalidad de tiempo de compilación que no tiene ningún impacto en el rendimiento en tiempo de ejecución. Internamente, el compilador de Haxe genera el código equivalente a la concatenación manual.

[string-interpolation]: https://haxe.org/manual/lf-string-interpolation.html
[strings]: https://haxe.org/manual/std-String.html
