# Apéndice de instrucciones

## Declaración de constantes

En este ejercicio se te pide que declares una serie de constantes que sirven para identificar distintos tipos de triángulos.
Elige el tipo de datos que creas que funciona mejor para esto y consigue que pasen los tests.

Después, puede que merezca la pena leer sobre el identificador predeclarado de Go [iota](https://golang.org/ref/spec#Iota).
Hay [un excelente artículo al respecto](https://splice.com/blog/iota-elegant-constants-golang/).
