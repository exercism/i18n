# Pistas

## 1. Los tres números

- La cabecera de la clase nombra la clase abstracta después de `<`:
  `class JUGGLING < $ACT is`.
- Cada uno debe definir tanto `name` como `minutes`, tal y como los declara
  la clase abstracta. Si falta uno de los dos, se produce un error de
  compilación que nombra la rutina.
- Cada uno también necesita un `create`, o `#JUGGLING` no tendrá nada que
  llamar. `create : SAME is return new; end;` es todo lo que hace falta para
  dos de ellos.
- `TRAPEZE` necesita un atributo para la altura y un `create` que reciba la
  altura.
- `+` une un número a un string, así que `"Trapeze at " + height + "m"` no
  necesita ninguna conversión.

## 2. El espectáculo

- El tipo del argumento es `ARRAY{$ACT}`. Eso es lo que permite que un solo
  array contenga los tres tipos.
- `acts.elt!` devuelve un `$ACT`. Llamar a `.minutes` sobre él ejecuta el
  correcto por sí solo: eso es el despacho dinámico, y es el objetivo del
  ejercicio. No hay nada que comprobar ni ningún `typecase` que escribir.
- `billing` construye un string en un bucle, así que `FSTR`, y el `", "` va
  antes de cada nombre excepto el primero.
- `longest` guarda el mejor número hasta el momento. Empezar los mejores
  minutos en `-1` hace que el primer número siempre lo supere, lo que resuelve
  el espectáculo vacío sin necesidad de un caso especial: el nombre se queda en
  `""`.
