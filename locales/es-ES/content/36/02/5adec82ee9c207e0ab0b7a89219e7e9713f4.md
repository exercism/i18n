# Anexo de las instrucciones

## Formato de salida

Muestra la secuencia de acciones como un string terminado en nulo, usando una coma y un espacio como separadores.

## Registros

| Registro | Uso          | Tipo          | Descripción                          |
| -------- | ------------ | ------------- | ------------------------------------ |
| `$a0`    | entrada      | número entero | número entre 1 y 31                  |
| `$a1`    | entrada/salida | dirección   | string de salida terminado en nulo   |
| `$t0-9`  | temporal     | cualquiera    | se usa para almacenamiento temporal  |
