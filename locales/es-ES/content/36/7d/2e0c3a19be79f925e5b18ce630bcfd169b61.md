# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
call {slug}Test.bat
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
Cuando todas las pruebas pasen, ¡habrás resuelto el ejercicio!

Para ayudarte a empezar, cada ejercicio incluye un fichero de implementación provisional.
Puedes usar este fichero como punto de partida para construir tu solución.
No dudes en eliminar o modificar este fichero si crees que es lo adecuado.
