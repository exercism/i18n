# Pistas

## 1. Eliminar las canciones duplicadas

- Puedes ver un ejemplo de cómo crear un set a partir de un array en la [documentación de MDN][mdn-relation-to-arrays].
- Asegúrate de volver a convertir tu set en un array antes de devolverlo.
- Vuelve a consultar el [concepto de desestructuración de arrays][concept-array-destructuring] para repasar cómo se usa el operador de propagación.

## 2. Comprobar si ya se ha añadido una canción

- Existe un [método integrado][mdn-set-has] para comprobar si un elemento está en un set.

## 3. Añadir una canción

- Existe un [método integrado][mdn-set-add] para añadir un elemento a un set.
- Asegúrate de no llamar manualmente a `Set.has()` para comprobar si el elemento está presente antes de añadirlo; `Set.add()` se encarga de eso por ti.

## 4. Eliminar una canción

- Existe un [método integrado][mdn-set-delete] para eliminar un elemento de un set.
- Asegúrate de no llamar manualmente a `Set.has()` para comprobar si el elemento está presente antes de eliminarlo; `Set.delete()` se encarga de eso por ti.

## 5. Listar los artistas únicos

- Hay [varias formas distintas][mdn-set-iteration] de iterar sobre un set.
- Existe un [método integrado][mdn-string-split] para dividir un string en subcadenas.
- Vuelve a consultar el [concepto de desestructuración de arrays][concept-array-destructuring] para repasar cómo omitir un elemento al desestructurar un array.
