# Pistas

## 1. Define el tiempo esperado de horneado en minutos

- Debes asignar el valor correcto a la constante `$EXPECTED-MINUTES-IN-OVEN`.

## 2. Calcula el tiempo restante de horneado en minutos

- Puedes restar números entre sí con el [operador infijo `-`][&infix:<->].

## 3. Calcula el tiempo de preparación en minutos

- Puedes multiplicar números con los [operadores infijos `*` o `×`][&infix:<*>].

## 4. Calcula el tiempo total de trabajo en minutos

- Puedes llamar a otras funciones definidas que te resulten útiles, p. ej., `function($arg)`.
- Puedes sumar números entre sí con el [operador infijo `+`][&infix:<+>].

## 5. Crea una notificación de que la lasaña está lista

- Puedes crear un string encerrando el texto entre comillas simples `'foo'` o dobles `"bar"`.
  Consulta [Construcciones de comillas][quoting].
