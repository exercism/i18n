# Acerca de

El tipo `Maybe` es la solución que ofrece el lenguaje Elm para los valores opcionales.
Por eso está presente en las firmas de tipo de gran cantidad de funciones del núcleo de Elm, y entenderlo es fundamental.

## Definición y variable de tipo

El tipo `Maybe` se define del siguiente modo:

```elm
type Maybe a = Nothing | Just a
```

Esto se conoce como una definición de «tipo personalizado» en la terminología de Elm.
Los tipos personalizados se explican con detalle en otro concepto de este track, pero no los necesitamos para entender `Maybe` en concreto.
La `a` de `Maybe a` y de `Just a` representa una variable de tipo, lo que significa que puede ser cualquier tipo, como `Int`, `Bool` o `String`.
Así, un `Maybe String` es una variable que puede contener o no un `String`, mientras que un `Maybe Int` contendría o no un `Int`.

```elm
name : Maybe String
name = Just "Matthieu"

age : Maybe Int
age = Just 29
```

La barra vertical `|` en la definición de tipo de `Maybe` significa «O».
Indica que un valor de este tipo puede ser `Nothing` o ser un `Just` de algo de tipo `a`.
Imagina ahora que esa persona no hubiera rellenado el nombre y la edad; tendríamos lo siguiente.

```elm
name : Maybe String
name = Nothing

age : Maybe Int
age = Nothing
```

## Leer el contenido de un valor Maybe

Para leer el contenido de un valor `Maybe` se usa la «coincidencia de patrones».
La coincidencia de patrones también se explica con más detalle en otro concepto, así que nos centraremos solo en cómo funciona la coincidencia de patrones con un `Maybe`.

```elm
-- This function returns "Hello, <name>!" if the name was provided.
-- Otherwise, it just says "Hello, World!".
sayHello : Maybe String -> String
sayHello maybeName =
    case maybeName of
        Nothing -> "Hello, World!"
        Just someName -> "Hello, " ++ someName ++ "!"

sayHello (Just "Matthieu")
    --> "Hello, Matthieu!"

sayHello Nothing
    --> "Hello, World!"
```

Cada vez que uses un valor `Maybe`, el compilador de Elm comprobará que tu código contempla todas las posibilidades, así que nunca podrás hacer coincidir un patrón sobre un `Maybe` y ocuparte solo del caso en el que hay un `Just someValue`.
Al principio puede parecer molesto, pero es una de las mayores virtudes del lenguaje Elm.
Esto evitará cientos de bugs y hace que la refactorización guiada por el compilador sea una experiencia sin miedo y gratificante.

## Más funciones para manipular Maybe

También hay varias funciones útiles en el módulo `Maybe` para manipular valores de tipo `Maybe`.

```elm
sayHelloAgain : Maybe String -> String
sayHelloAgain name = "Hello, " ++ Maybe.withDefault "World" name ++ "!"

capitalizeName : Maybe String -> Maybe String
capitalizeName name = Maybe.map String.toUpper name

capitalizeName matthieu
    --> Just "MATTHIEU"

capitalizeName anon
    --> Nothing
```
