# Introducción

## Mapeo

El mapeo consiste en aplicar una función a cada elemento de una secuencia para producir una nueva secuencia.

Esto se puede hacer fácilmente sobre una lista con la función `mapcar`.
Supongamos que tenemos una función `double` que multiplica su argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Fíjate en que el primer argumento es una función que hay que llamar. El `#'` es una sintaxis especial de cita para especificar una función.

Primero se llamó a `double` con el primer elemento, luego con el segundo, etc.
Los resultados se recopilaron en una lista, que es el valor al que se evalúa la expresión.

## Filtrado

El filtrado es el proceso de crear una secuencia a partir de otra copiando todos los elementos de la secuencia original salvo algunos.
La elección de qué elementos incluir en la nueva secuencia se puede hacer mediante una función predicado (una función que se evalúa a un valor booleano) o mediante la igualdad con un objeto concreto.

### Eliminación mediante un predicado

`remove-if` es una función que toma una función predicado y una secuencia como argumentos, y devuelve una secuencia formada solo por aquellos elementos para los que el predicado se evaluó a un valor falso.
En otras palabras, «elimina» todos los elementos de la secuencia para los que el predicado se evalúa como verdadero. No obstante, ten en cuenta que esta función no modifica la secuencia original.
En su lugar, devuelve una nueva secuencia sin los elementos correspondientes. Si el predicado era verdadero para todos los valores, se devuelve una secuencia vacía.

```lisp
(remove-if #'evenp '(1 2 3 4 5)) ; => (1 3 5)
(remove-if #'oddp '(1 3 5))      ; => ()
```

### Eliminación de un elemento concreto

Si quieres eliminar un elemento concreto de una secuencia, puedes usar `remove`, que toma el elemento que hay que eliminar y una secuencia.
Se devuelven todos los valores de la secuencia que no son iguales al elemento que se quiere eliminar.
NOTA: por defecto, la igualdad se comprueba con el [predicado de igualdad genérico][concept-equality] `eql`.

```lisp
(remove 1 '(1 2 1 3 1 4)) ; => (2 3 4)
(remove #\l "hello")      ; => "heo"
```
