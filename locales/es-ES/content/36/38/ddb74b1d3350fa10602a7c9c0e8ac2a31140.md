# Instrucciones

Convierte un número ternario, representado como un string (por ejemplo, '102012'), a su equivalente decimal partiendo de los principios básicos.

El programa debe considerar que un string que especifique un ternario no válido tiene el valor 0.

Los números ternarios contienen tres símbolos: 0, 1 y 2.

El último lugar de un número ternario es el de las unidades. El penúltimo es el de los treses y el antepenúltimo, el de los nueves, etc.

```shell
# "102012"
    1       0       2       0       1       2    # the number
1*3^5 + 0*3^4 + 2*3^3 + 0*3^2 + 1*3^1 + 2*3^0    # the value
  243 +     0 +    54 +     0 +     3 +     2 =  302
```

Si tu lenguaje proporciona un método en la biblioteca estándar para hacer la conversión, haz como si no existiera e impleméntala tú mismo.
