# Acerca de

ABAP tiene varios tipos numéricos. Los más habituales en los ejercicios introductorios pequeños son `i` para valores enteros y `p` para valores decimales empaquetados.

Usa `i` cuando un valor deba ser un número entero, como un recuento de días. Usa un tipo decimal cuando un valor pueda contener dígitos fraccionarios, como una tarifa por hora.

```abap
DATA hours_per_day TYPE i VALUE 8.
DATA rate_per_hour TYPE p LENGTH 8 DECIMALS 2 VALUE '89.89'.

DATA day_rate TYPE p LENGTH 8 DECIMALS 2.
day_rate = hours_per_day * rate_per_hour.
```

Los números empaquetados se usan a menudo en aplicaciones empresariales cuando se requiere un número fijo de posiciones decimales. ABAP también tiene números decimales de coma flotante (`decfloat16` y `decfloat34`) y números binarios de coma flotante (`f`). Los números binarios de coma flotante pueden ser útiles para cálculos científicos, pero no son una buena opción por defecto para ejemplos de tipo monetario porque muchas fracciones decimales no se pueden representar con exactitud.
