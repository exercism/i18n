# Introducción

En Clojure, vincular un valor a un nombre se conoce como _var_. Las vars de nivel superior (globales) son similares a las constantes de otros lenguajes.

Las vars de nivel superior se definen con `def`:

```clojure
(def fingers 10)

fingers
;;=> 10
```

Puedes usar `defn` para definir una función que recibe cero o más argumentos. Esta es una función que suma dos números:

```clojure
(defn add [x y]
  (+ x y))
```

Esta función recibe dos argumentos que se colocan en el vector `[x y]`, seguidos del *cuerpo* de la función, que puede contener cualquier número de expresiones. El valor devuelto es siempre el resultado de evaluar la última expresión del cuerpo, `(+ x y)`. Esta expresión es una lista que representa una llamada a una función. El primer elemento de la lista es la función `+`, que se evalúa usando los siguientes elementos, `x` e `y`, como argumentos.

La función `add` definida antes se llama de la misma forma:

```clojure
(add 2 3)
;;=> 5
```

Las funciones y los valores en Clojure solo se pueden usar _después_ de haber sido definidos, es decir, las formas siempre se evalúan en el orden en que aparecen.

En Clojure, los espacios en blanco no tienen ninguna relevancia más allá del formato.

Las funciones y las vars de Clojure se organizan en namespaces. Un namespace agrupa funcionalidad relacionada y se define con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos de `;`, y la forma `comment` se usa para evitar la evaluación de todo lo que hay entre `(comment` y `)`.
