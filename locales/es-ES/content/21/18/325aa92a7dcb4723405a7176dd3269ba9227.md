# Introducción

Una `Tuple` es bastante similar a un `Vector` (un `array` unidimensional) en muchos aspectos.
Sin embargo, hay unas cuantas diferencias importantes.

- Las tuplas se escriben entre paréntesis `( )` en lugar de corchetes `[ ]`, aunque los paréntesis se pueden omitir cuando el significado es inequívoco.
- Las tuplas no tienen por qué ser homogéneas: el tipo de cada elemento se almacena de forma independiente.
- Las tuplas son inmutables.

La inmutabilidad permite más optimizaciones del compilador y hace que las tuplas tengan mejor rendimiento que los vectores, así que conviene preferirlas cuando no se necesita mutabilidad.

```julia-repl
julia> t = (3, 5.2, "xyz")
(3, 5.2, "xyz")

# Non-homogeneous:
julia> dump(t)
Tuple{Int64, Float64, String}
  1: Int64 3
  2: Float64 5.2
  3: String "xyz"

julia> t[2]
5.2

# Immutable:
julia> t[2] = 7.3
ERROR: MethodError: no method matching setindex!(::Tuple{Int64, Float64, String})
```

También existe un constructor `Tuple()`, que convierte cualquier colección iterable en una tupla.
Resulta útil que trate un string como una colección iterable de caracteres.

```julia-repl
julia> Tuple("Julia")
('J', 'u', 'l', 'i', 'a')
```

En cualquier tupla se puede acceder a los elementos por su índice o recorrerlos con un bucle.

Cualquier tupla puramente numérica también se puede usar en funciones matemáticas como `sum()`, exactamente igual que los arrays.

## Desempaquetado

Una tupla se puede desempaquetar en elementos individuales mediante la asignación múltiple.
Para los elementos que no necesites, usa el guion bajo `_` como variable ficticia.

```julia-repl
julia> tup = (1, "Julia", true)
(1, "Julia", true)

julia> num, name, _ = tup
(1, "Julia", true)

julia> uppercase(name), 2num
("JULIA", 2)
```

Si programas en Python, esta sintaxis de asignación múltiple te resultará muy familiar.

## Tuplas con nombre

Una `Tuple` solo contiene valores.
Una `NamedTuple` asocia cada valor con un nombre.

Después, se puede acceder a cada campo por separado con la notación de punto:

```jullia-repl
julia> nt = (a = 1, b = 7.3)
(a = 1, b = 7.3)

julia> dump(nt)
@NamedTuple{a::Int64, b::Float64}
  a: Int64 1
  b: Float64 7.3

julia> nt.b
7.3
```

El nombre se almacena internamente como un `Symbol` (un tipo inmutable, y el nombre va precedido de dos puntos `:`), así que hay una sintaxis alternativa disponible:

```julia-repl
julia> nt[:b]
7.3
```

Es fácil obtener por separado tanto los nombres (también llamados «claves») como los valores:

```julia-repl
julia> nt
(a = 1, b = 7.3)

julia> keys(nt)
(:a, :b)

julia> values(nt)
(1, 7.3)
```

Ten en cuenta que al iterar sobre una tupla con nombre solo se obtienen los _valores_, y los _nombres_ se ignoran.

Las tuplas (con nombre o sin él) son una forma muy habitual de transferir datos estructurados desde y hacia las funciones.
La inmutabilidad viene bien en este caso de uso, ya que aporta seguridad a los datos y permite optimizaciones del compilador más agresivas.
