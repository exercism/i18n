# Pistas

## 1. Determina cuántas cartas de un tipo concreto hay en la baraja

- Para empezar, crea una variable de tipo entero que lleve la cuenta del número de cartas de ese tipo.
- Después, como se explica en las instrucciones, usa [forEach][mdn-foreach] para recorrer la baraja.
- Aumenta tu variable contador dentro del callback cuando encuentres una carta del tipo que buscas.

## 2. Determina cuántas cartas pares o impares hay

- Para empezar, crea una variable de tipo entero que lleve la cuenta del número de cartas del tipo que buscas (pares o impares).
- Después, como se explica en las instrucciones, usa [for...of][mdn-for-of] para recorrer la baraja.
- El residuo de la división entre 2 te dice si un número es par o impar.
  Puedes calcular el residuo con el operador módulo (`%`).
- Aumenta tu variable contador cuando encuentres un número con el residuo que buscas.

[mdn-for-of]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of
