# Instrucciones

Estás de vuelta en la cocina, perfeccionando la receta de lasaña de [la deliciosa lasaña de Leah][lasagna]. Las tareas de aquí te piden manejar varias entradas a la vez, que es exactamente cuando *locals*, los enlaces con nombre de Factor, se ganan su sitio.

## 1. Determina el estado de cocción

Define `cooking-status` para que tome una lectura del temporizador de la pila y devuelva un string con el estado.

- `0` → `"Lasagna is done."`
- `f` (el temporizador nunca se ajustó) → `"You forgot to set the timer."`
- cualquier otro número → `"Not done, please wait."`

```factor
12 cooking-status .   ! => "Not done, please wait."
0 cooking-status .    ! => "Lasagna is done."
f cooking-status .    ! => "You forgot to set the timer."
```

## 2. Estima el tiempo de preparación

Define `preparation-time` para que tome un array con los nombres de las capas y un número medio de minutos por capa, y devuelva el tiempo total de preparación.

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } 3 preparation-time .
! => 18
```

## 3. Calcula la pasta y la salsa necesarias

Define `quantities` para que tome un array con los nombres de las capas y devuelva *dos* valores: los gramos de pasta necesarios (50 g por cada capa de pasta) y los litros de salsa necesarios (`1/5` de litro por cada capa de salsa).

```factor
{ "sauce" "noodles" "sauce" "meat" "mozzarella" "noodles" } quantities .s
! => 100
! => 2/5
```

## 4. Añade el ingrediente secreto

Tu amigo te envía un array de ingredientes; el *último* elemento es su secreto. Define `add-secret-ingredient` para que tome su array y el tuyo y devuelva tu array con el secreto añadido al final.

```factor
{ "noodles" "sauce" "mozzarella" "kampot pepper" }
{ "noodles" "meat" "sauce" "mozzarella" }
add-secret-ingredient .
! => { "noodles" "meat" "sauce" "mozzarella" "kampot pepper" }
```

## 5. Escala la receta

La receta del libro de recetas da para dos porciones. Define `scale-recipe` para que tome una receta (una tabla hash que asocia cada nombre de ingrediente con su cantidad) y un número de porciones objetivo, y devuelva una receta nueva escalada de forma adecuada.

```factor
H{ { "noodles" 200 } { "sauce" 1/2 } { "mozzarella" 1 } { "meat" 100 } }
4 scale-recipe .
! => H{ { "noodles" 400 } { "sauce" 1 } { "mozzarella" 2 } { "meat" 200 } }
```
