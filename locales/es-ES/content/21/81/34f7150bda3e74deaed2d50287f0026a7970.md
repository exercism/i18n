# Consejos

## 1. Determinar cuánto se tarda en preparar un zumo

- Configura una [sentencia `switch`][mdn-switch] para la variable `name`.
- Los distintos casos deben representar los distintos nombres de zumo.
- Usa el caso `default` para cubrir todos los demás nombres.
- Recuerda que los casos [se ejecutan en cascada de forma predeterminada][mdn-fallthrough], así que asegúrate de haber hecho algo para evitar ese comportamiento.

## 2. Reponer el suministro de gajos de lima

- Usa un [bucle `while`][mdn-while] para cortar una lima tras otra.
- Vuelve a consultar el [concepto de los arrays][concept-arrays] para encontrar la forma de eliminar las limas del array en el orden correcto.
- Configura una [sentencia `switch`][mdn-switch] para obtener el número de gajos según el tamaño de una lima.
- Tienes que llevar la cuenta de dos cosas: cuántas limas ya se han cortado y cuántos gajos faltan todavía.
- Puedes combinar dos condiciones para el bucle con [operadores lógicos][concept-booleans].

## 3. Terminar el turno

- Usa un [bucle `do-while`][mdn-do-while] para gestionar un pedido tras otro.
- Vuelve a consultar el [concepto de los arrays][concept-arrays] para encontrar la forma de eliminar las bebidas del array en el orden correcto.
- Ya tienes una función que determina el tiempo que se tarda en preparar una bebida; úsala para reducir el tiempo restante en consecuencia.
- Puedes combinar dos condiciones para el bucle con [operadores lógicos][concept-booleans].
