# Anexo a las instrucciones

## Implementación

Las funciones de este ejercicio aceptan un array que contiene uno o más números, cada uno de los cuales representa una «puntuación de una partida».

Las puntuaciones de las partidas del jugador se pueden leer desde

| `scores`   |
|---|
| `scores[0]` |
| `scores[1]` |
| ... |
| `scores[scores_len - 1]` |

`personal_top_three()` debe escribir las mejores puntuaciones del jugador en

| `output`   |
|---|
| `output[0]` |
| ... |
