# Pruebas

Para probar tu solución, abre el terminal y ejecuta

```
mason test
```

en la carpeta del ejercicio (la que contiene el fichero `Mason.toml` y las carpetas `src/` y `test/`).

Si crees que el mensaje de error no es lo bastante informativo, puedes probar lo siguiente para obtener uno más detallado.

```
mason test --show
```
