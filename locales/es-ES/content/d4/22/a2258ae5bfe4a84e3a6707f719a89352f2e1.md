# Anexo de instrucciones

## Sugerencias

Una [lista doblemente enlazada](https://en.wikipedia.org/wiki/Doubly_linked_list) es una estructura de datos mutable. Dado que F# es un lenguaje que prioriza el paradigma funcional, por lo general se prefiere la inmutabilidad, pero hay características del lenguaje que permiten usar la mutación cuando es necesario.

- La palabra clave `mutable` se puede colocar delante de los enlaces `let` y de los campos de un [registro](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/records), lo que te permite asignarles nuevos valores.

- Las propiedades de una [clase](https://fsharpforfunandprofit.com/posts/classes) se pueden hacer mutables especificando un establecedor de propiedad con la palabra clave `set`.

Los enlaces mutables deben reasignarse con `<-`

```fsharp
let mutable x = "initial value"
x <- "new value"
```
