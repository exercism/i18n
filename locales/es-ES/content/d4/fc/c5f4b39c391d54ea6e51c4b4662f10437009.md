# Pistas

## 1. Insertar una carta en la parte superior de la pila

- Se puede usar la [función `ArrayTrait::append`][append] para añadir al final de un array.

## 2. Quitar la carta superior de la pila

- Siempre puedes convertir un array en un span y usar la [función `SpanTrait::pop_back`][pop-back] para eliminar del final de un array.

## 3. Insertar una carta en la parte inferior de la pila

- No hay forma de añadir un elemento al principio del array, pero una alternativa es crear un array nuevo de un solo elemento y añadir el antiguo como span con [`ArrayTrait::append_span`][append-span].

## 4. Quitar una carta de la parte inferior de la pila

- Se puede usar la [función `ArrayTrait::pop_front`][pop-front] para eliminar del principio de un array.

## 5. Comprobar el tamaño de la pila

- Se puede usar la [función `ArrayTrait::len`][len] para obtener la longitud de un array.
