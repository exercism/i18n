## 1. Construye la ChronoChain a partir de un array de valores `u32`

- Podemos recorrer el array y construir una cadena en orden inverso, empezando por `End` y enlazando cada valor con la variante `Link`.
- Plantéate usar `span.pop_back()` para recorrer el array en orden inverso; esto nos ayudará a crear la cadena del final al principio.

## 2. Suma los valores de la ChronoChain

- Usa la coincidencia de patrones para manejar las dos variantes de `ChronoChain`.
- Cuando llegues a `End`, la suma es 0, y cuando llegues a `Link`, sumas el valor y sumas recursivamente el resto de la cadena.
- Este enfoque es similar a una función recursiva que recorre la estructura hasta alcanzar el caso base (`End`).
