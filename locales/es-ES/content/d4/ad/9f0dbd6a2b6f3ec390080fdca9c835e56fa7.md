# Pistas

## General

- `<min-heap>`, `heap-push`, `heap-peek` y `heap-pop-all` están todos en [`heaps`][heaps]; `values` está en [`assocs`][assocs].
- Un montículo guarda cada elemento como un *valor* con una *clave*; la clave es la prioridad. `heap-push` los recibe como `( value key heap -- )`.

## 1. Abre la cola

- `<min-heap>` construye un montículo mínimo vacío: se atiende primero la clave más pequeña.

## 2. Añade un cliente

- El nombre del cliente es el valor y la prioridad es la clave, que es exactamente el orden que espera `heap-push`.
- `heap-push` consume la cola. Usa `[ heap-push ] keep` para añadir al cliente y que la cola siga devolviéndose.

## 3. ¿Quién es el siguiente?

- `heap-peek` devuelve `value key` del elemento del frente sin quitarlo. Solo quieres el nombre, así que usa `drop` para descartar la clave.

## 4. Atiende a todos

- `heap-pop-all` vacía el montículo en una lista de asociación de pares `{ key value }`, ya en orden de prioridad.
- `values` conserva solo los valores, los nombres.
