# Introducción

En Cairo, la sobrecarga de operadores te permite definir un comportamiento personalizado para los operadores estándar como `+`, `-`, `==`, `<`, etc., cuando trabajas con tus propios tipos.

Esto se consigue implementando traits específicos para tus tipos personalizados.

## Traits principales para los operadores

### `Add` y `Sub`

Los traits `Add` y `Sub` te permiten definir cómo funcionan la suma (`+`) y la resta (`-`) con tu tipo:

```rust
impl MyTypeAdd of Add<MyType> {
    fn add(lhs: MyType, rhs: MyType) -> MyType {
        // Define addition behavior
    }
}
```

### `PartialEq`

El trait `PartialEq` permite comparar por igualdad (`==` y `!=`) instancias de tu tipo.

A menudo puedes derivarlo automáticamente con `#[derive(PartialEq)]`.

### `PartialOrd`

El trait `PartialOrd` permite realizar operaciones de comparación (`<`, `>`, `<=`, `>=`) entre instancias de tu tipo.

Requiere que implementes al menos el método `lt` (menor que):

```rust
impl MyTypePartialOrd of PartialOrd<MyType> {
    fn lt(lhs: MyType, rhs: MyType) -> bool {
        // Define "less than" behavior
    }
}
```
