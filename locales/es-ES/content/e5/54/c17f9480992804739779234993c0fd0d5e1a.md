# Aprendizaje de Batch

## Sitios web

- La [Official Batch-File Documentation](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-xp/bb490869(v=technet.10)?redirectedfrom=MSDN) es un lugar excelente para ver algunos ejemplos y aprender sobre el lenguaje.
- La [SS64 Command Documentation](https://ss64.com/nt/) es probablemente la documentación más completa sobre los comandos de Batch y además incluye ejemplos desde lo más básico hasta lo más avanzado.
- Las [Rob van der Woude's Scripting Pages](https://www.robvanderwoude.com/) son un recurso increíblemente útil para escribir scripts de Batch, con un montón de ejemplos y explicaciones; lo más interesante de este sitio web es que comparte el código de herramientas realmente singulares y lo explica todo de una forma comprensible. (Puede que al principio el sitio resulte un poco confuso, pero merece la pena).
- El [DosTips Forum](https://www.dostips.com/forum/) es un lugar excelente para hacer preguntas y conseguir ayuda con tus scripts de Batch.
- [Batch-Man](https://batch-man.com/) comparte un montón de herramientas y scripts útiles, y además los explica de una forma muy comprensible: cada script tiene una explicación detallada en el blog, un repositorio de GitHub, un montón de ejemplos y un vídeo de YouTube.

## Vídeos

- [Batch Tutorials by John Hammond](https://www.youtube.com/playlist?list=PL69BE3BF7D0BB69C4) está muy bien explicado para principiantes.
- El canal de [Batch-Man](https://www.youtube.com/@batch-man/videos) también crea contenido con regularidad y muestra técnicas.
