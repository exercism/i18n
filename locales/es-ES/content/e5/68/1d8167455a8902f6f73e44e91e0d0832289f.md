# Tests

Para cada ejemplo, hay que seguir estos pasos generales.

Primero, cambia al directorio del ejercicio que quieras practicar, en este caso `bob`.

```bash
$ cd </path/to/exercism>/lfe/bob
```

A continuación, ejecuta los tests. El objetivo `test` de make depende de `compile`, así que ejecutar `make test` hará que tu código fuente se compile y, después, ejecutará los tests.


```bash
$ make test
```

¡Enhorabuena! ¡Tienes tests fallando!

Ahora lee `README.md` para averiguar qué tienes que hacer para que todos tus tests pasen.

Corrige el primer error que señale el test y vuelve a ejecutar los tests.

```bash
$ make test
```

Continúa corrigiendo el siguiente test que falle en tu código fuente y ejecutándolo hasta que pasen todos los tests.

Cuando pasen todos tus tests, echa un último vistazo a tu código en el directorio `src` para asegurarte de que estás contento con tu código y envíalo a revisión.

Recibe comentarios, revisa la solución, envíala, prueba el siguiente ejercicio y repite hasta alcanzar la iluminación de LFE.
