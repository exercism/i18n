# Instrucciones

En este ejercicio, vas a implementar la lógica de la misión de un nuevo juego de rol que está desarrollando un amigo. La protagonista del juego es Annalyn, una chica valiente que tiene un perro feroz y leal como mascota. Por desgracia, ocurre una catástrofe: su mejor amiga ha sido secuestrada mientras buscaba bayas en el bosque. Annalyn intentará encontrar y liberar a su mejor amiga, y puede que lleve a su perro con ella en esta misión.

Después de seguir durante un tiempo el rastro de su mejor amiga, encuentra el campamento en el que está encerrada. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez encontrados los secuestradores, Annalyn se plantea cuáles de las siguientes acciones puede llevar a cabo:

- Ataque rápido: se puede hacer un ataque rápido si el caballero está dormido, ya que tarda un rato en ponerse la armadura y estará vulnerable.
- Espiar: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- Hacer señales al prisionero: se puede hacer señales al prisionero usando sonidos de pájaros si el prisionero está despierto y el arquero está dormido, ya que los arqueros están entrenados en hacer señales con sonidos de pájaros, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es una acción arriesgada y solo puede salir bien de una de estas dos formas:
  - Si Annalyn lleva a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero escapen.
  - Si Annalyn no lleva a su perro, ella y el prisionero tendrán que ser muy sigilosos.
    Annalyn puede liberar al prisionero si el prisionero está despierto y tanto el caballero como el arquero están dormidos, pero si el prisionero está dormido no se le puede rescatar: se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y según si el perro de Annalyn está presente o no.

## 1. Comprobar si se puede hacer un ataque rápido

Implementa el método `canFastAttack()` que recibe un valor Boolean que indica si el caballero está despierto. Este método devuelve `true` si se puede hacer un ataque rápido según el estado del caballero. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = true

canFastAttack(knightIsAwake)
// => false
```

## 2. Comprobar si se puede espiar al grupo

Implementa el método `canSpy()` que recibe tres valores Boolean, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false

canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake)
// => true
```

## 3. Comprobar si se puede hacer señales al prisionero

Implementa el método `canSignalPrisoner()` que recibe dos valores Boolean, que indican si el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se puede hacer señales al prisionero, según el estado de los dos personajes. De lo contrario, devuelve `false`:

```kotlin
val archerIsAwake = false
val prisonerIsAwake = true

canSignalPrisoner(archerIsAwake, prisonerIsAwake)
// => true
```

## 4. Comprobar si se puede liberar al prisionero

Implementa el método `canFreePrisoner()` que recibe cuatro valores Boolean. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. El método devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```kotlin
val knightIsAwake = false
val archerIsAwake = true
val prisonerIsAwake = false
val petDogIsPresent = false

canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent)
// => false
```
