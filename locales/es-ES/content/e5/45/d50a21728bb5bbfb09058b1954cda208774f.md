# Anexo de las instrucciones

## Pistas

Para que el reto tenga la dificultad adecuada, solo deberías usar la funcionalidad que ofrece Prelude. Intenta no usar Data.List, Data.Char, Data.Bits ni Numeric.

Intenta usar seq, $! o BangPatterns de forma adecuada para asegurarte de que la solución sea eficiente.

No es necesario gestionar entradas no válidas.

Si ya has hecho el ejercicio Octal, quizá deberías generalizarlo.
