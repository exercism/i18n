# Consejos

A menos que tengas mucha confianza en tus habilidades con las expresiones regulares, puede ayudarte elaborar la sintaxis en un entorno de pruebas en línea como [Regex101][regex101].

Recuerda establecer el sabor a PCRE2.

Definir previamente cada expresión regular como una `const` puede ser un estilo útil (por claridad y rendimiento).

## 1. Comprobar que el comando es válido

- El carácter de anclaje para el inicio de la cadena es `^`.
- Solo necesitas un valor booleano de la búsqueda con la expresión regular.
- Esto se podría resolver sin usar una expresión regular, pero mantente dentro del espíritu de un ejercicio de concepto.

## 2. Eliminar los emojis cifrados

- Basta con un [`replace()`][replace].

## 3. Comprobar que el número de teléfono es válido

- Necesita una expresión regular más larga, pero bastante repetitiva.
- Las `n` apariciones consecutivas se pueden especificar con la sintaxis `{n}`.
- Solo necesitamos un valor booleano para la coincidencia.

## 4. Obtener el enlace del sitio web

- Recuerda escapar el punto con `\.`
- Captura la parte anterior al punto en una [coincidencia][match].

## 5. Saludar al usuario

- Un `replace()` con capturas con nombre tiene el formato `r"(?<name>...) " => s"\g<name>... "`
- De nuevo, un `split()` podría resolver la tarea, pero practicar las expresiones regulares es útil.
