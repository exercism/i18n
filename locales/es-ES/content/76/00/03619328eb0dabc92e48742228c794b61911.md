# Introducción

En Common Lisp, los strings son [vectores][concept-vectors] de [caracteres][concept-characters]. Se escriben como caracteres rodeados de comillas dobles (por ejemplo, "Hello World!").

El predicado `stringp` solo devolverá verdadero si el valor dado es un string.

Los strings se pueden dividir en trozos más pequeños con la función `subseq`, que recibe el string, un índice de inicio y, opcionalmente, un índice de fin.
Los índices empiezan en cero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Los strings se pueden comparar por igualdad con `string=`.
Si hay que ignorar las mayúsculas y minúsculas de los caracteres, se puede usar `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Operaciones como poner un string en mayúsculas, ponerlo en minúsculas o capitalizarlo se pueden hacer con `string-upcase`, `string-downcase` y `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
