# Anexo de instrucciones

## Notas de implementación

La definición de la interfaz Cipher se encuentra en `cipher.go`.

Tus implementaciones deben ajustarse a la interfaz Cipher.

```go
type Cipher interface {
    Encode(string) string
    Decode(string) string
}
```

Se espera que `Encode` ignore todos los valores del string que no sean A-Za-z; no se representarán en la salida.
La salida también se normalizará a minúsculas.

Las funciones que se utilizan para obtener los cifrados son:

```go
func NewCaesar() Cipher { }

func NewShift(distance int) Cipher { }

func NewVigenere(key string) Cipher { }
```

El argumento de `NewShift` debe estar en el rango de 1 a 25 o de -1 a -25.
No se permite el cero.
Con argumentos no válidos, `NewShift` devuelve nil.

El argumento de `NewVigenere` debe constar únicamente de letras minúsculas de la a a la z.
No se permiten los valores que consten únicamente de la letra «a».
Con argumentos no válidos, `NewVigenere` devuelve `nil`.
