# Introducción

Los `Rational numbers` son fracciones con un numerador entero dividido entre un denominador entero.

Por ejemplo, podemos almacenar `2//3` como una fracción exacta en lugar del valor aproximado `Float64` `0.6666...`

La ventaja es que (salvo en el caso extremo de *desbordamiento de enteros*) un número racional seguirá siendo exacto, lo que evita los errores de redondeo que a menudo son inevitables con los números de coma flotante.

Los números racionales son un tipo numérico bastante sencillo y pretenden funcionar tal y como cabría esperar.
Como han sido un tipo estándar en Julia desde las primeras versiones, la mayoría de las funciones los aceptan como entrada igual que los enteros y los números decimales.

## Crear números racionales

Crearlos es tan sencillo como usar `//` entre dos enteros.

```julia-repl
julia> 3//4
3//4

julia> a = 3; b = 4;

julia> a//b
3//4
```

Los factores comunes se eliminan automáticamente, lo que convierte la fracción a su «mínima expresión»: los enteros más pequeños que representan con exactitud la fracción y con un denominador no negativo.

```julia-repl
julia> 5//15
1//3

julia> 5//-15
-1//3
```

## Aritmética con números racionales

Los `arithmetic operators` habituales `+ - * / ^ %` funcionan con los racionales, esencialmente igual que con otros tipos numéricos.

Se pueden incluir enteros y otros `Rational` y dan como resultado un `Rational`.
Si se incluye un `float` en la expresión, el resultado es un `float`, con la consiguiente (posible) pérdida de precisión.

Si se desea un `float`, basta con usar la función `float()` para convertir un racional.
Es bastante normal usar números racionales para conservar la precisión a lo largo de un cálculo largo y, después, convertir a un número decimal al final.

```julia-repl
julia> 3//4 + 1//3  # addition
13//12

julia> 3//4 * 1//3  # multiplication
1//4

julia> 3//4 / 1//3  # division
9//4

julia> 3//4 ^ 2  # exponentiation
3//16

julia> 3//4 + 5  # rational and int => rational
23//4

julia> 3//4 + 5.3  # rational and float => float
6.05

julia> float(3//4)  # casting
0.75
```

## Otras operaciones

En Julia, los números racionales son simplemente números.
El compilador suele convertir los tipos según sea necesario.

Sin embargo, ten en cuenta que las comparaciones funcionan para fracciones con una representación decimal finita:

```julia-repl
julia> 3//4 == 0.75
true

julia> 3//4 < 0.74
false
```

Pero, en caso contrario, hay que convertir un `Rational` a un `Float` para hacer comparaciones:

```julia-repl
julia> 1//3 == 1/3
false

julia> float(1//3) == 1/3
true
```

Las funciones matemáticas aceptan racionales como entrada, pero pueden dar un resultado de coma flotante:

```julia-repl
julia> sqrt(9//16)
0.75
```
