# Introducción

## Boolean en R

Los valores verdadero o falso se representan con el tipo `logical`.
Solo contiene dos valores: `TRUE` y `FALSE`.

```R
TRUE
#> [1] TRUE
FALSE
#> [1] FALSE
typeof(TRUE)
#> [1] "logical"
```

## Operadores Boolean

En R hay cinco operadores Boolean, pero en esta fase del temario solo tres son relevantes.
Los otros dos serán importantes cuando trabajes con vectores, algo que se trata en varios conceptos posteriores.

`&&` es el «y» Boolean.
Se evalúa como `TRUE` si las expresiones a *ambos* lados de `&&` son `TRUE`.

```R
TRUE && TRUE
#> [1] TRUE
TRUE && FALSE
#> [1] FALSE
```

`||` es el «o» Boolean.
Se evalúa como `TRUE` si una expresión a *cualquiera* de los dos lados de `||` es `TRUE`.

```R
TRUE || TRUE
#> [1] TRUE
FALSE || TRUE
#> [1] TRUE
```

`!` es el «no» Boolean.
Intercambia los valores `TRUE` y `FALSE`.

```R
!TRUE
#> [1] FALSE
!FALSE
#> [1] TRUE
```

Para expresiones más largas y complicadas, lo mejor es usar paréntesis para dejar clara tu intención.

```R
(TRUE || FALSE) && (FALSE && TRUE)
#> [1] FALSE
```
