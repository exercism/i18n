# Pistas

## 1. Obtener todos los vinos de un color dado

- Los argumentos de palabra clave se especifican escribiendo un nombre antes del nombre del argumento, separados por un espacio.
- La función [`list.filter`][list-filter] se puede usar para seleccionar de un array los elementos que cumplen un predicado dado.

## 2. Obtener todos los vinos de un color dado embotellados en un año dado

- Los argumentos de palabra clave se especifican escribiendo un nombre antes del nombre del argumento, separados por un espacio.
- La función [`list.filter`][list-filter] se puede usar para seleccionar de un array los elementos que cumplen un predicado dado.

## 3. Obtener todos los vinos de un color dado embotellados en un país dado

- Esta función se puede implementar llamando a `wines_from_country` y luego a `wines_of_color` sobre la salida.

[list-filter]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#filter
