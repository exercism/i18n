# Estructuras

Las estructuras son tipos de datos personalizados que te permiten nombrar y agrupar varios valores relacionados.
Son similares a las tuplas, pero más flexibles y te permiten nombrar cada pieza de datos, lo que hace que tu código sea más claro.
Las estructuras en Cairo tienen estas propiedades:

- Cada tipo de estructura tiene un nombre concreto.
- Cada miembro de una estructura se llama **campo**.
- Cada campo de una estructura tiene un nombre concreto.
- La visibilidad se gestiona a nivel de campo: cada campo puede ser público o privado de forma independiente.

## Definir e instanciar estructuras

Para definir una estructura, usa la palabra clave `struct` seguida de un nombre y llaves que contengan los campos con sus nombres y tipos:

```rust
#[derive(Drop)]
struct User {
    active: bool,
    username: ByteArray,
    email: ByteArray,
    sign_in_count: u64,
}
```

Para crear una instancia de `struct`, especifica el nombre de `struct` y usa llaves con pares clave-valor para los campos.
Ten en cuenta que puedes enumerar los campos en cualquier orden al crear una instancia:

```rust
let user1 = User {
   active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};

let user2 = User {
    sign_in_count: 1, username: "someusername123", active: true, email: "someone@example.com"
};
```

## Interactuar con una instancia de estructura

Usa la notación de punto para acceder a los campos de una instancia de `struct` o modificarlos.
Ten en cuenta que para modificar un campo, la instancia debe ser mutable:

```rust
let mut user1 = User {
    active: true, username: "someusername123", email: "someone@example.com", sign_in_count: 1
};
user1.email = "anotheremail@example.com";
```

Al igual que con cualquier expresión, podemos construir una nueva instancia de `struct` como última expresión en el cuerpo de la función para devolver implícitamente esa nueva instancia:

```rust
fn build_user(email: ByteArray, username: ByteArray) -> User {
    User {
        email: email,
        username: username,
        active: true,
        sign_in_count: 1,
    }
}
```

## Notación abreviada para inicializar campos

En el último ejemplo tenía sentido nombrar los parámetros de función `email` y `username` con los mismos nombres que los campos de `struct`, pero tener que repetirlos al asignarlos a los campos de la estructura es un poco tedioso.
Por suerte, existe una notación abreviada conveniente para inicializar campos de estructura a partir de variables con los mismos nombres:

```rust
fn build_user_short(email: ByteArray, username: ByteArray) -> User {
    User { email, username, active: true, sign_in_count: 1, }
}
```

## Crear instancias a partir de otras instancias con la sintaxis de actualización de estructuras

Usa la sintaxis de actualización de estructuras para crear una nueva instancia a partir de una existente, cambiando algunos de los campos y manteniendo el resto igual.
Esto se consigue usando el operador `..`.

Sin la sintaxis de actualización:

```rust
let user2 = User {
    active: user1.active,
    username: user1.username,
    email: "another@example.com",
    sign_in_count: user1.sign_in_count,
};
```

Con la sintaxis de actualización:

```rust
let user2 = User { email: "another@example.com", ..user1 };
```

La sintaxis `..user1` copia los campos restantes de `user1` a `user2`.
Ten en cuenta que esto mueve los datos de `user1` a `user2`, por lo que `user1` no se puede usar después si contiene tipos no copiables.
