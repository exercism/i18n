# Instrucciones

Estás ayudando a un amigo a generar un informe a partir de las lecturas que ha tomado en distintos rincones de su jardín.
Por desgracia, tu amigo ha guardado los datos en un formato extraño.
Cada lectura es un conjunto de campos separados por comas.
Sin embargo, ha guardado números de dos dígitos repartidos en dos columnas.

| número de campo | significado |
| --- | --- |
| 1 | número de ID |
| 2 | ubicación |
| 3 | primera lectura, valor de las decenas |
| 4 | primera lectura, valor de las unidades |
| 5 | segunda lectura, valor de las decenas |
| 6 | segunda lectura, valor de las unidades |

Para una fila de entrada como `101,house,4,2,5,4`
- la primera lectura es `42`,
- la segunda lectura es `54`.

## Tarea 1: Generar el informe

Tu tarea es encontrar la media de las dos lecturas y mostrar los resultados de cada fila en el siguiente formato

```none
#<id>, <label> = <average>
```

Como la media de 42 y 54 es 48, la salida para la fila de ejemplo debería ser:

```none
#101, house = 48
```
