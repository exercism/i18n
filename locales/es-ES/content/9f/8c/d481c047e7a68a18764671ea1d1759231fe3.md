# Instrucciones

Siguiendo con tu trabajo en el parque de atracciones, ahora tienes que escribir algunos métodos de utilidad que faciliten la comprobación de si un asistente puede subirse a una atracción.

## 1. Comprobar si un asistente tiene pase de atracción

Implementa el método `Attendee#has_pass?` para que devuelva un valor booleano (`true`/`false`) en función de si hay o no un pase de atracción.

```ruby
Attendee.new(100).has_pass?
# => false
```

## 2. Comprobar si un asistente cumple la altura para una atracción

Implementa el método `Attendee#fits_ride?` para ver si un asistente cumple la altura para subirse a una atracción según su estatura.
La altura mínima requerida para la atracción se proporciona como argumento.
La estatura del asistente debe ser mayor o igual que la altura mínima requerida para la atracción.

```ruby
Attendee.new(140).fits_ride?(100)
# => true
```

## 3. Comprobar si un asistente tiene permiso para subirse a una atracción

Implementa el método `Attendee#allowed_to_ride?` para ver si un asistente tiene permiso para subirse a una atracción. La altura mínima requerida para la atracción se proporciona como argumento. El asistente debe tener un pase de atracción y cumplir la altura necesaria para la atracción.

```ruby
attendee = Attendee.new(100)
attendee.issue_pass!(42)
attendee.allowed_to_ride?(120)
# => false
```
