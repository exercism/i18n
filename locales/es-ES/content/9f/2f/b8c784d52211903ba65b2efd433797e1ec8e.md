# Introducción

La entrada/salida (E/S) de Factor se basa en *flujos*: objetos de los que lees bytes o caracteres, o en los que los escribes. El vocabulario [`io`][io] te ofrece dos vistas del mismo [protocolo][stream-protocol].

## Las dos vistas

Las **palabras de flujo explícito** toman el flujo como argumento. Todas empiezan por `stream-`:

```
stream-read       ( n stream -- seq/f )
stream-readln     ( stream -- str/f )
stream-write      ( seq stream -- )
stream-flush      ( stream -- )
stream-contents   ( stream -- seq )
stream-lines      ( stream -- seq )
```

Las **palabras de flujo ambiente** leen o escriben en el flujo que esté *vinculado en ese momento*, es decir, la variable dinámica de todo el programa `input-stream` o `output-stream`. Tienen nombres cortos:

```
read1 read readln write write1 print flush
```

La forma ambiente es la que usa la mayoría del código del día a día. La forma explícita es la que usas cuando tienes un flujo concreto entre manos y no quieres cambiar el flujo ambiente.

## Flujos en memoria

En el ejercicio trabajarás con flujos basados en strings de [`io.streams.string`][io.streams.string]:

```
<string-reader>   ( str -- reader )
<string-writer>   ( -- writer )
```

Un `<string-reader>` lee de un string literal como si fuera un fichero; un `<string-writer>` recoge todo lo que se escribe en él para que puedas leerlo después. Ambos implementan el mismo protocolo que los flujos de fichero, así que lo aprendido se traslada directamente a `<file-reader>` / `<file-writer>`.

## Delimitar el scope con `with-…`

Para vincular un flujo explícito como el ambiente de una quotation y liberarlo después, usa un combinador `with-…`:

```
with-input-stream    ( stream quot -- )
with-output-stream   ( stream quot -- )
with-string-writer   ( quot -- str )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

[`with-string-writer`][with-string-writer] es la forma cómoda de «recoger lo que imprime esta quotation»: crea el writer, ejecuta la quotation con ese writer como salida ambiente y devuelve el string capturado:

```factor
USING: io io.streams.string ;

[ "captured" print ] with-string-writer .
! => "captured\n"
```

Todos los combinadores `with-…` son combinadores destructores (de la misma familia que `with-disposal` y `with-destructors` de [`boatswains-bilge`][boatswains-bilge]): el flujo se libera al salir aunque la quotation lance una excepción.
