# Acerca de

[F#](https://try.fsharp.org/) es un lenguaje fuertemente tipado y funcional que forma parte de la pila de lenguajes .NET de Microsoft.

Aunque F# es ideal para problemas de ciencia de datos, puede manejar con elegancia casi cualquier problema que le plantees.

Como F# se ejecuta en el entorno de ejecución de .NET, tienes acceso a todo el ecosistema .NET, incluidos todos los paquetes de [nuget.org](https://www.nuget.org/).

La integración con código .NET existente se simplifica aún más porque F# también te permite escribir código orientado a objetos.

La página principal de F# es [fsharp.org](http://fsharp.org/) y puedes encontrar una magnífica introducción a F# en el sitio web [F# for fun and profit](http://fsharpforfunandprofit.com/).
