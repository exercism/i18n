# Acerca de

La clase Lambda es una colección de métodos funcionales que permiten usar programación de estilo funcional con Haxe. Nos permite operar sobre un Iterable completo a la vez. A menudo es preferible a las rutinas con bucles, ya que es menos propenso a errores y más fácil de leer. Por comodidad, las clases Array y List contienen algunos de los métodos más usados de la clase Lambda.

Algunas de las funciones de la clase `Lambda` son:

- `Lambda.array`, `Lambda.list` Convierten un Iterable en un Array o una List. Siempre devuelven una nueva instancia.
- `Lambda.count` Cuenta el número de elementos. Si el Iterable es un Array o una List, es más rápido usar su propiedad length.
- `Lambda.has` Determina si el elemento especificado está en el Iterable.
- `Lambda.indexOf` Averigua el índice del elemento especificado.
- `Lambda.find` Encuentra el primer elemento que cumpla la función de búsqueda dada.
- `Lambda.concat` Combina dos Iterables y devuelve una nueva List.
- `Lambda.filter` Encuentra los elementos que cumplan un criterio y devuelve una nueva List.

Un ejemplo que muestra algunas funciones:

```haxe
using Lambda;

class Main {
  static function main() {
    var words = ["boat", "dog", "phone", "cat", "food"];

    var isThreeLetters = function(word) return word.length == 3;

    trace(words.filter(isThreeLetters)); // [dog,cat]
  }
}
```
