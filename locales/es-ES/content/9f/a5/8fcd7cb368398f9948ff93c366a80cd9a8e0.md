# Instrucciones

En este ejercicio vas a trabajar en un planificador de citas para un salón de belleza que abrió el 15 de septiembre de 2012.

Tienes cinco tareas, y todas ellas estarán relacionadas con fechas de citas.

## 1. Analizar la fecha de la cita

Implementa la función `Schedule` para analizar una representación textual de la fecha de una cita y convertirla al formato `time.Time` correspondiente:

```go
Schedule("7/25/2019 13:45:00")
// => 2019-07-25 13:45:00 +0000 UTC
```

## 2. Comprobar si una cita ya ha pasado

Implementa la función `HasPassed`, que recibe la fecha de una cita y comprueba si la cita tuvo lugar en algún momento del pasado:

```go
HasPassed("July 25, 2019 13:45:00")
// => true
```

## 3. Comprobar si la cita es por la tarde

Implementa la función `IsAfternoonAppointment`, que recibe la fecha de una cita y comprueba si la cita es por la tarde (>= 12:00 y < 18:00):

```go
IsAfternoonAppointment("Thursday, July 25, 2019 13:45:00")
// => true
```

## 4. Describir la hora y la fecha de la cita

Implementa la función `Description`, que recibe la fecha de una cita y devuelve una descripción de esa fecha y hora:

```go
Description("7/25/2019 13:45:00")
// => "You have an appointment on Thursday, July 25, 2019, at 13:45."
```

## 5. Devolver la fecha del aniversario de la apertura del salón

Implementa la función `AnniversaryDate`, que devuelve la fecha del aniversario de la apertura del salón para el año actual en UTC.

Suponiendo que el año actual es 2020:

```go
AnniversaryDate()

// => 2020-09-15 00:00:00 +0000 UTC
```

**Nota:** el valor devuelto es un `time.Time` y la hora del día no importa.
