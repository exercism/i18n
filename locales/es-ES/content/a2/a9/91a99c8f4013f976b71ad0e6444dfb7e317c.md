# Acerca de

Al ser un lenguaje funcional, las funciones en Clojure son ciudadanas de primera clase. Esto significa que se pueden pasar a otras funciones y ser generadas por ellas igual que los datos. Clojure, en particular, incluye un amplio conjunto de funciones de orden superior que derivan nuevas funciones a partir de otras existentes. Aquí exploraremos cuatro casos importantes: `partial`, `comp`, `memoize` y `juxt`. Estas funciones generadoras de funciones pertenecen a una categoría más amplia de funciones de orden superior, como `map`, `reduce`, `apply` o `complement`, por nombrar algunas, que operan sobre funciones existentes.

## partial

En general, dada una función existente `my-function`, con parámetros `p1, p2, ..., pN`, podemos fijar algunos de sus parámetros `p1, p2, ..., pM` para que tengan valores constantes `v1, v2, ..., vM`. Lo hacemos aplicando `partial` del siguiente modo: `(partial my-function v1 v2 ... vM)`.

El resultado es una nueva función que aplica la original `my-function` fijando `p1=v1, p2=v2, ..., pM=vM`. Nuestra nueva función toma como entrada los parámetros restantes `pM+1, pM+2, ..., pN`, cuyos valores no se han indicado al aplicar `partial`:

```clojure
(def my-new-function 
  (partial my-function v1 v2 ... vM))
(my-new-function xM+1 xM+2 ... xN)
; => equivalent to (my-function v1 v2 ... vM xM+1 xM+2 ... xN)
```

Como ejemplo sencillo, vamos a definir una función `inc-by-9` que aumenta en 9, una cantidad fija, independientemente de lo que le pasemos. Podríamos implementar esa función del siguiente modo:

```clojure
(def inc-by-9 (partial + 9))
(inc-by-9 5)
; => 14
```

Como segundo ejemplo, tenemos una función `generic-greetings` que usa el nombre de la persona a la que queremos saludar junto con un mensaje de texto inicial y otro final:

```clojure
(defn generic-greetings
  [initial-text final-text name]
  (println (str initial-text name final-text)))
```

Y usamos `partial` para usar siempre un mensaje de saludo concreto:

```clojure
(def say-hello-and-how-are-you-doing 
  (partial generic-greetings "Hello " ", how are you doing?"))
(say-hello-and-how-are-you-doing "Mary")
; => Hello Mary, how are you doing?
```

## comp

`comp` se puede usar para crear una composición de cualquier número de funciones que queramos componer. En general, componer `N` funciones `f1, f2, ..., fN` significa aplicarlas en orden secuencial, pasando la salida de la función anterior a la siguiente. En notación matemática, esto se expresa así:

```
f1 (f2 (... fN(x)))
```

En Clojure, esto equivale a hacer:
```clojure
(f1 (f2 (... (fN x))))
```

Al usar comp, podemos crear una nueva función que realice esta composición por nosotros:

```clojure
(def my-function-composition 
  (comp f1 f2 ... fN))
(my-function-composition x)
; equivalent to
(f1 (f2 (... (fN x))))
```

Como ejemplo, supongamos que queremos sumar una serie de números y luego multiplicar el resultado por 6. Podemos hacerlo así:


```clojure
(def six-times-result-sum 
  (comp (partial * 6) +))
(six-times-result-sum 3 2)
; = ((partial * 6) (+ 3 2))
; = (* 6 (+ 3 2))
; = 30
```

## memoize

`memoize` permite reutilizar resultados calculados previamente asociados a una entrada dada. Dada la misma entrada, la función *memorizada* devuelve el mismo resultado sin tener que volver a calcularlo. Aprovecha el hecho de que las funciones de `clojure` son, por defecto, *referencialmente transparentes*: dada la misma entrada, siempre producen la misma salida, lo que permite reutilizar cálculos anteriores con facilidad.

Para ver cómo funciona esto, usemos un caso sintético en el que la función se suspende durante dos segundos antes de producir la salida, de modo que podamos comparar fácilmente el *tiempo de cómputo* antes y después de usar `memoize`.

```clojure
(defn my-time-consuming-fn
    "Original, time-consuming function"
    [x]
    (Thread/sleep 2000)
    (* x 2)
)

; We measure the time it takes for the original function
(time (my-time-consuming-fn 3))
; => "Elapsed time: 2007.785622 msecs"
; => 6

; We define a memoized function
(def my-memoized-fn 
  (memoize my-time-consuming-fn) )

; We call the memoized function and measure its execution time. 
; The first execution actually runs the function, taking
; similar time as the original.
(time (my-memoized-fn 3))
; => "Elapsed time: 2001.364052 msecs"
; => 6

; Subsequent calls reuse the previous computation, taking less
; time. Time is further reduced in additional calls.
(time (my-memoized-fn 3))
; => "Elapsed time: 1.190291 msecs"
; => 6

(time (my-memoized-fn 3))
; => "Elapsed time: 0.043701 msecs"
; => 6

; Changing the input makes the function be executed, so that
; we observe a similar computation time as the original 
(time (my-memoized-fn 4))
; => "Elapsed time: 2000.29306 msecs"
; => 8

; Again, repeating the same input will make the 
; execution be skipped, and the associated output returned
(time (my-memoized-fn 4))
; => "Elapsed time: 0.043701 msecs"
; => 8
```

## juxt

`juxt` genera una función que aplica, en orden de izquierda a derecha, las funciones que se le pasan. El resultado es un vector con los resultados individuales de cada función como componentes del vector:

```clojure
((juxt f g h) x) ; => [(f x) (g x) (h x)]
```

Como ejemplo sencillo, generamos una función que calcula el producto de x por factores sucesivos, del 2 al 5:
```clojure
((juxt (partial * 2) (partial * 3) (partial * 4) (partial * 5)) 10) ; => [20 30 40 50]
```
