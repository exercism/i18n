# Acerca de

PowerShell es un lenguaje de scripting de Microsoft, dinámico y de tipado implícito (_pero que también admite variables [de tipado fuerte][strong typed]_), centrado sobre todo en la automatización de tareas y la gestión de la configuración.

PowerShell admite programación imperativa, funcional, orientada a objetos e incluso de estilo pipeline.

PowerShell se creó sobre la plataforma .NET y se publicó por primera vez en 2006.
Se incluye de forma predeterminada en todos los sistemas operativos Windows modernos y también se puede instalar en Mac y Linux.


## Variables

Hay dos formas habituales de definir una variable en PowerShell.

Los nombres de las variables en PowerShell deben empezar por `$` y usar el operador de asignación `=` para vincular el nombre de la variable a un valor.

```powershell
> $intVar = 1
> $doubleVar = 2.0
> $stringVar = "Hello"

# Checking a variable type using the GetType() method
> Write-Host $doubleVar.GetType()
System.Double
```

También puedes especificar el tipo de una variable de forma explícita, si quieres forzar o exigir que el valor sea de un tipo determinado.
PowerShell hará todo lo posible por convertir el valor de un tipo a otro, si es posible.

```powershell
# String represents a floating number can be converted to integer
> [int]$staticOne = "1.234"
> $staticOne
1

# String of letters can not be converted to double type
> [double]$staticTwo = "hello"
MetadataError: Cannot convert value "hello" to type "System.Double"
```

### Constantes

Las constantes en PowerShell son variables que no se pueden **cambiar** ni **eliminar** después de definirlas.
Esto nos lleva a la segunda forma de definir variables: usar el cmdlet `New-Variable`.

```powershell
> New-Variable -Name "MyConstant" -Value 100 -Option Constant
> $MyConstant
100
```


## Funciones

Las funciones en PowerShell se definen con la palabra clave `function`.
Cada función puede tener cero o más parámetros formales entre paréntesis (`()`), seguidos del scope de la función, que empieza por `{` y termina por `}`.

```powershell
function Greeting {
    return "Hello!"
}
```

Las funciones en PowerShell pueden devolver valores de forma explícita mediante la palabra clave `return`, después de llamarlas con la sintaxis `FuncName $Arg`.

```powershell
function AddTwoNumbers($NumOne, $NumTwo):
    $result = $NumOne + $NumTwo
    return $result

> AddTwoNumbers 10 20
30
```

## Comentarios

Los comentarios de una sola línea en PowerShell empiezan por `#` y terminan al final de la línea.
Los bloques de comentarios en PowerShell empiezan por `<#` y terminan por `#>`.

```powershell
function Main() {
    #This is a comment
    <#
    And this is a comment block
    that can span multiple lines
    #>
}
```
