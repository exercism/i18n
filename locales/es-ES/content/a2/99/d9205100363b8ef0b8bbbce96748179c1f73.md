# Tests

Puedes ejecutar los tests con el siguiente comando en el directorio del ejercicio:

```bash
dub test
```

## Superar los tests

Consigue que el primer test compile, enlace y pase siguiendo las [tres reglas
del desarrollo guiado por pruebas](http://butunclebob.com/ArticleS.UncleBob.TheThreeRulesOfTdd).
Crea la estructura mínima necesaria declarando espacios de nombres, funciones,
clases, etc., para satisfacer los errores del compilador y conseguir que el
test falle. Después, escribe el código mínimo necesario para que el test pase.
Cuando lo hayas hecho, descomenta el siguiente test moviendo la siguiente línea
más allá del siguiente test.

```D
static if (all_tests_enabled)
```

Esto puede provocar errores de compilación, ya que pueden aparecer nuevas
construcciones que aún no has declarado ni definido. De nuevo, corrige los
errores de compilación con el mínimo cambio para conseguir un test que falle;
después, cambia el código con el mínimo cambio para que el test pase,
refactoriza tu implementación para que sea más legible y expresiva y pasa al
siguiente test.

Intenta usar las utilidades estándar de D en lugar de escribir a mano tus
propios algoritmos o utilidades de bajo nivel.
