# Instrucciones

Jen trabaja en la sala de clasificación de una gran fábrica.
La sala de clasificación necesita procesar todo lo que llega a ella clasificándolo con una etiqueta.
Jen se encarga de las cosas que se han clasificado previamente como números y necesita un programa que la ayude con la clasificación.

La mayoría de los valores primitivos deberían recibir etiquetas sencillas.
Para los números, quiere strings que digan `"This is the number 2.0"` (si el número era 2).
Jen quiere la misma salida para números enteros y números decimales.

Hay unas cuantas interfaces `Box` que hay que desenvolver para obtener su contenido.
Para una `NumberBox`, quiere strings que digan `"This is a box containing the number 3.0"` (si el método `Number()` devuelve 3).
Para una `FancyNumberBox`, quiere strings que digan `"This is a fancy box containing the number 4.0"`, pero solo si el tipo es un `FancyNumber`.

Cualquier cosa inesperada debería devolver `"Return to sender"` para que Jen pueda devolverlas al lugar de donde vinieron.

## 1. Describe números sencillos

Jen quiere que los números devuelvan strings como `"This is the number 2.0"` (incluyendo un dígito después de la coma decimal):

```go
fmt.Println(DescribeNumber(-12.345))
// Output: This is the number -12.3
```

## 2. Describe una caja de números

Jen quiere que las cajas de números devuelvan strings como `"This is a box containing the number 2.0"` (de nuevo, incluyendo un dígito después de la coma decimal):

```go
fmt.Println(DescribeNumberBox(numberBoxContaining{12}))
// Output: This is a box containing the number 12.0
```

## 3. Implementa un método que extraiga el número de una caja de números elegante

Jen necesita una función auxiliar para extraer el número de una `FancyNumberBox`.
Si la `FancyNumberBox` es un `FancyNumber`, extrae su valor y conviértelo de `string` a `int`.
Cualquier otro tipo de `FancyNumberBox` debería devolver 0.

```go
fmt.Println(ExtractFancyNumber(FancyNumber{"10"}))
// Output: 10
fmt.Println(ExtractFancyNumber(AnotherFancyNumber{"4"}))
// Output: 0
```

## 4. Describe una caja de números elegante

Si la `FancyNumberBox` es un `FancyNumber`, Jen quiere strings que digan `"This is a fancy box containing the number 4.0"`.
Cualquier otro tipo de `FancyNumberBox` debería devolver `"This is a fancy box containing the number 0.0"`.

```go
fmt.Println(DescribeFancyNumberBox(FancyNumber{"10"}))
// Output: This is a fancy box containing the number 10.0
fmt.Println(DescribeFancyNumberBox(AnotherFancyNumber{"4"}))
// Output: This is a fancy box containing the number 0.0
```

NOTA: ¡deberíamos usar la función `ExtractFancyNumber`!

## 5. Implementa `DescribeAnything`, que usa todas las anteriores

Esta es la función principal que necesita Jen y que acepta cualquier entrada.
`DescribeAnything` debería delegar en las otras funciones según el tipo del valor que se le pasa.
Más concretamente:

- tanto `int` como `float64` deberían delegar en `DescribeNumber`
- `NumberBox` debería delegar en `DescribeNumberBox`
- `FancyNumberBox` debería delegar en `DescribeFancyNumberBox`
- cualquier otra cosa debería dar como resultado `"Return to sender"`

```go
fmt.Println(DescribeAnything(numberBoxContaining{12.345}))
// Output: This is a box containing the number 12.3
fmt.Println(DescribeAnything("some string"))
// Output: Return to sender
```
