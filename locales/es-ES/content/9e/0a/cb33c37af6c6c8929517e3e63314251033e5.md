# Instrucciones

A los alienígenas de Lisp les gusta celebrar aniversarios.
Para ellos, una fecha de aniversario importante es el gigasegundo.
Es decir: 1.000.000.000 segundos desde el acontecimiento.

## 1. Calcula la fecha del aniversario del gigasegundo

Escribe una función `from` que recibe 6 parámetros: `year`, `month`, `day`, `hour`, `min`, `sec`, y calcula la fecha y la hora del aniversario del gigasegundo.
Esta función debe devolver la fecha como un array con el mismo orden y significado que los parámetros de la entrada.

```
(from 2000 1 1 0 0 0) ; => (2031 9 9 1 46 40)
```
