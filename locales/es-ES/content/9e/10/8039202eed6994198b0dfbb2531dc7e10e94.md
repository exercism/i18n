# Introducción

Además de `cond`, Elixir también proporciona la macro [`if/2`][getting-started-if], que resulta útil cuando necesitas comprobar solo una condición.

[`if/2`][kernel-if] acepta una condición y dos opciones. Devuelve la primera opción si la condición es _verdadera_, y la segunda opción si la condición es _falsa_.

```elixir
age = 15

if age >= 16 do
  "You are allowed to drink beer in Germany."
else
  "No beer for you!"
end

# => "No beer for you!"
```

También es posible escribir una expresión `if` en una sola línea. Fíjate en la coma que hay después de la condición.

```elixir
if age > 16, do: "beer", else: "no beer"
```

Esta sintaxis resulta útil para expresiones muy cortas, pero conviene evitarla si la expresión no cabe en una sola línea.

## _Verdadero_ y _falso_

En Elixir, todos los tipos de datos se evalúan como un valor _verdadero_ o _falso_ cuando se encuentran en un contexto booleano (como una expresión `if`). Todos los datos se consideran _verdaderos_ **excepto** `false` y `nil`. En particular, los strings vacíos, el número entero `0` y las listas vacías se consideran _verdaderos_ en Elixir.
