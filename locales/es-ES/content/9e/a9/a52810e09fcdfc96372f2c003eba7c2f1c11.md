# Pistas

## 1. Devolver un array con los nombres de los artículos

- La [función `iterator.map`][map] se puede usar para transformar los artículos de un iterador.

## 2. Devolver los artículos baratos

- La [función `iterator.filter`][filter] se puede usar para eliminar algunos artículos de un iterador.

## 3. Devolver los artículos sin existencias

- La [función `iterator.filter`][filter] se puede usar para eliminar algunos artículos de un iterador.

## 4. Devolver el total de existencias

- La [función `iterator.fold`][fold] se puede usar para reducir un iterador a un único valor.
