# Tests

## Tests interactivos

Inicia tu implementación de Common Lisp en el directorio del ejercicio en el que estás trabajando (o cambia el directorio actual de una implementación de Common Lisp que ya se esté ejecutando a ese directorio).
Si usas roswell, hazlo con `ros run`.

(Todos los ejemplos de esta página suponen un ejercicio llamado `exercise-name`; ajústalos según sea necesario.)

Carga el fichero de tests en tu implementación de Lisp que esté en ejecución, por ejemplo, `(load "exercise-name-test")`. 
(Esto también cargará el fichero de la solución por ti.)
Una vez cargado el fichero de tests, puedes ejecutar los tests evaluando `(exercise-name-test:run-tests)` en el REPL.

A medida que hagas cambios en la solución que estás escribiendo, usa la funcionalidad de tu editor para cargar los cambios o evalúa `(load "exercise-name")` para cargar el fichero de tu solución.

Recuerda evaluar `(exercise-name-test:run-tests)` para volver a ejecutar los tests después de cargar tu solución actualizada.

## Tests desde la línea de comandos

Puedes lanzar los tests con esta invocación desde la línea de comandos (de nuevo, sustituye «exercise» por el nombre adecuado en los dos sitios)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```

Ese comando es bastante engorroso.
Un colaborador ha escrito algunas notas sobre [cómo hacer que sea más fácil de invocar](https://glennj.github.io/exercism/cli).
