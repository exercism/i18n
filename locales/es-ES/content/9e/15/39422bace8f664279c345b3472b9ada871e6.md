## Booleanos

Raku tiene los literales booleanos `True` y `False`.
En contexto booleano, cualquier valor indefinido se considerará `False`.
Además de `Bool::False` en sí, entre los valores definidos que se consideran `False` están `0`, `NaN`, `()` (lista vacía), `""` (cadena vacía) y los objetos de tipo `Failure`.

El operador [prefijo `?`][&prefix:<?>] fuerza el contexto booleano sobre un objeto.
Su comportamiento es el mismo que el de llamar al método [`Bool`][routine/Bool] sobre ese objeto.
El operador [prefijo `!`][&prefix:<!>] devuelve el inverso del prefijo `?`.

## Operadores infijos booleanos

### Coincidencia inteligente

El operador [infijo `~~`][&infix:<~~>], también conocido como operador de coincidencia inteligente, es una herramienta de uso habitual en Raku.
Su comportamiento depende del objeto que se dé en el lado derecho del operador, ya que es un atajo para el método [`ACCEPTS`][routine/ACCEPTS] de ese objeto.
El valor del lado izquierdo se pasa como argumento a `ACCEPTS`.
El resultado es un valor booleano.

### AND/OR lógicos

Raku tiene los operadores [`&&`][&infix:<&&>]/[`and`][&infix:<and>], [`||`][&infix:<||>]/[`or`][&infix:<or>], [`//`][&infix:<//>]/[`orelse`][&infix:<orelse>] y [`^^`][&infix:<^^>]/[`xor`][&infix:<xor>] para la lógica booleana (precedencia alta y baja, respectivamente).
Se pueden encadenar.

```raku
1 xor 1 xor 1;
# Nil in Raku, 1 in Perl (because the latter makes the first pair false).
```

### Ternario

Raku tiene un operador [infijo `?? !!`][infix-??-!!] ternario/condicional, que se escribe como `$condition ?? $true !! $false`.

## Flujo de control

### if/elsif/else

Una [instrucción `if`][control-if] se usa para ejecutar un bloque de código de forma condicional.
Para crear una instrucción `if`, la palabra clave `if` va seguida de una [expresión][statements-and-expressions] y, a continuación, de un [bloque][control-block].

La expresión se evalúa en [contexto booleano][contexts-boolean] y el bloque se ejecutará si la expresión se evalúa como `True`.

Una instrucción `if` se puede ampliar con las palabras clave [`elsif` y `else`][control-else/elsif], escritas de la misma forma que `if`. Un bloque `else` se ejecutará si todas las expresiones anteriores se evalúan como `False`, y un bloque `elsif` se ejecutará del mismo modo si su propia expresión se evalúa como `True`.

Como alternativa, `if` se puede usar en la forma de modificador de instrucción:

```raku
say 'success' if True;
```

La forma de modificador de instrucción no se puede usar con `elsif` ni con `else`.

### given/when/default

La [instrucción `given`][control-given] es la palabra clave topicalizadora de Raku, de forma similar a como `switch` topicaliza en lenguajes como C.
Las palabras clave para cada caso son [`when` y `default`][control-default-and-when].

### for/while/loop

Una [instrucción `for`][control-for] itera sobre una lista dada y ejecuta un bloque para cada elemento presente en esa lista.

Una [instrucción `while`][control-while] ejecuta un bloque repetidamente mientras su expresión se evalúe como `True`.

Una [instrucción `loop`][control-loop] se puede escribir de dos formas.
Si solo se le da un bloque, ejecutará ese bloque repetidamente hasta que algo rompa el bucle de forma explícita.
También se puede escribir como un bucle `for` al estilo de C, con un inicializador, una condición y un incrementador entre paréntesis antes del bloque.

```raku
loop (my $i = 0; $i < 10; $i++) {
    say $i;
}
```
