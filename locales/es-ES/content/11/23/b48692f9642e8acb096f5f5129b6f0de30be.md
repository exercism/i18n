# Pistas

## General

- Un `struct` es una secuencia de elementos con nombre, llamados campos, cada uno de los cuales tiene un nombre y un tipo.

## 1. Crear un coche teledirigido

- Crea una instancia de un nuevo [struct][struct] y rellena los campos excepto `distance`.
- Crea una función que devuelva el tipo del struct recién creado y actualiza los campos en consecuencia.

## 2. Crear una pista de carreras

- Define un nuevo [struct][struct] con 1 campo.
- Crea una función que devuelva el tipo del struct recién creado y actualice los campos en consecuencia.

## 3. Conducir el coche

- Añade un nuevo campo para llevar un registro de la distancia recorrida.
- Tienes que comprobar si hay batería suficiente para conducir el coche.

## 4. Comprobar si un coche teledirigido puede terminar una carrera

- Supón que el coche acaba de empezar la carrera.
- Tienes que calcular la distancia máxima que puede recorrer un coche con el nivel actual de batería.
- El número de veces que se puede conducir un coche se calcula con `battery / batteryDrain`.
- La distancia máxima que puede recorrer el coche es el producto de la velocidad del coche y el número de veces que se puede conducir.
- Conociendo la distancia máxima que puede recorrer el coche, compárala con la distancia de la pista de carreras.
