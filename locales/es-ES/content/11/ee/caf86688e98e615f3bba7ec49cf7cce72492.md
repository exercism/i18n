# Introducción

En Cairo, el concepto de propiedad se aplica a las _variables_ y define las reglas que rigen quién puede usar esas variables.
Cada variable declarada solo se puede usar una vez, lo que significa que, una vez usada, se destruirá o se moverá, según el tipo de uso.

La _destrucción_ puede ocurrir de varias formas:

- una variable sale del scope (con o sin uso).
- se desestructura un struct.
- destrucción explícita usando `destruct()`

_Mover_ un valor simplemente significa pasar ese valor a otra función.

El lenguaje Cairo usa un sistema de tipos lineales, del que se sirve para garantizar que todo el código sea demostrable (y verificable) a la vez que abstrae la memoria inmutable de la máquina virtual de Cairo.
