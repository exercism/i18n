# Instrucciones

Andrew, un desarrollador de su empresa, ha creado recientemente una utilidad ligera para generar consultas SQL destinada a una herramienta de migración de bases de datos.
Su primera implementación, bastante ingenua, funcionaba perfectamente con conjuntos de datos pequeños.
Sin embargo, durante las grandes migraciones en producción, la aplicación empezó a consumir una cantidad excesiva de memoria y se resentía bajo cargas intensas.
Tras analizar el rendimiento de la aplicación, Andrew se dio cuenta de que la concatenación de strings convencional dentro de los bucles obligaba a Go a reasignar memoria constantemente.
Ahora necesita tu ayuda para refactorizar la utilidad con `strings.Builder` de Go, de forma que la aplicación escale bien y sea capaz de manejar grandes volúmenes de texto sin colapsar el heap de memoria.

## 1. Genera consultas SELECT

Implementa la función `BuildSelectQuery`.
Recibe el nombre de una tabla (`string`) y un slice con los nombres de las columnas (`[]string`).
Debe devolver una sentencia SQL `SELECT` completa que termine en punto y coma.
Si el slice de columnas está vacío o es `nil`, la consulta debe recurrir al comodín `*` para seleccionar todas las columnas.

```go
columns := []string{"id", "name", "email"}
BuildSelectQuery("users", columns)
// Function return: "SELECT id, name, email FROM users;"

BuildSelectQuery("orders", nil)
// Function return: "SELECT * FROM orders;"
```

## 2. Genera sentencias INSERT por lotes

Implementa la función `BuildBatchInserts`.
Recibe el nombre de una tabla (`string`) y un slice bidimensional que representa las filas de la base de datos (`[][]ColumnValue`).
Cada elemento de una fila vincula un nombre de columna concreto con su valor de tipo string.
La función debe devolver un slice con sentencias SQL `INSERT` individuales.
El formato estructurado del slice garantiza un orden de salida de las consultas predecible y estable.
Si el slice de filas de entrada está vacío, devuelve un slice de strings vacío.
Si alguna fila concreta está vacía, sáltala.
Los valores de tipo string de la cláusula `VALUES` deben ir entre comillas simples `'`.

```go
rows := [][]ColumnValue{
    {
        {Column: "title", Value: "Book"},
        {Column: "price", Value: "100"},
    },
    {
        {Column: "title", Value: "Magazine"},
        {Column: "price", Value: "15"},
    },
}

BuildBatchInserts("products", rows)
// Function returns string slice: [
//   "INSERT INTO products (title, price) VALUES ('Book', '100');",
//   "INSERT INTO products (title, price) VALUES ('Magazine', '15');"
// ]
```
