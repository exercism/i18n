# Instrucciones

Añade el recuento de minas a un tablero de Minesweeper completado.

Minesweeper es un juego popular en el que el usuario tiene que encontrar las minas utilizando pistas numéricas que indican cuántas minas hay directamente adyacentes (en horizontal, en vertical, en diagonal) a una casilla.

En este ejercicio tienes que crear código que cuente el número de minas adyacentes a una casilla vacía concreta y sustituya esa casilla por el recuento.

El tablero es un rectángulo compuesto por caracteres de espacio en blanco (« »). Una mina se representa con un asterisco («\*»).

Si una casilla concreta no tiene ninguna mina adyacente, deja esa casilla en blanco.

## Ejemplos

Por ejemplo, puedes recibir un tablero de 5 x 4 como este (aquí los espacios vacíos se representan con el carácter «·» para mostrarlos en pantalla):

```
·*·*·
··*··
··*··
·····
```

Y tu código lo transformará en esto:

```
1*3*1
13*31
·2*2·
·111·
```
