# Pistas

## 1. Define el tiempo de horno esperado en minutos

- Tienes que definir una [var][vars] usando [def].

## 2. Calcula el tiempo de horno restante en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Puedes usar la var definida anteriormente y referirte a ella por su nombre.
- El resultado de evaluar la última expresión de una función se devuelve automáticamente desde la función; todas las funciones devuelven este valor.
- Puedes usar las funciones básicas de [operaciones con números][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Puedes usar las funciones básicas de [operaciones con números][operators] para multiplicar valores.

## 4. Calcula el tiempo transcurrido en minutos

- Tienes que definir una [función][functions] con dos parámetros.
- Puedes [llamar][calling] a una de las otras funciones que hayas definido anteriormente.
- Puedes usar las funciones básicas de [operaciones con números][operators] para sumar valores.
