# Instrucciones

Los endpoints HTTP mejoran con la comprobación de tipos. Añadir un tipo Record a una petición POST garantiza que siempre se envíen los datos correctos.

## Objetivos

- Modifica el código proporcionado.
- Añade los atributos necesarios a este record para que acepte dos operandos y un operador.
- Añade una función de recurso HTTP que acepte una petición POST en la ruta `/calc`.
- La función debe aceptar el tipo de record Calculation como carga útil y devolver un objeto JSON genérico.

### Acepta

```json
{ "operand1": 4, "operand2": 10.2, "operator": "+" }
```

### Devuelve

```json
{ "expression": "4+10.2", "result": 14.2 }
```
