## Instrucciones

Te ha contratado un centro de reciclaje.
Debido a la falta de espacio, todos los productos se colocan en la misma cinta transportadora, pero esto ha provocado que distintos materiales se mezclen y queden inservibles.
Para solucionarlo, se te ha encargado crear funciones que identifiquen el tipo de un producto.

### 1. Comprobar si un valor es un Boolean

Implementa la función `isBoolean`, que comprueba si un valor es un Boolean.

```javascript
isBoolean(true);
// => true

isBoolean(null);
// => false
```

### 2. Comprobar si un valor es un número.

Implementa la función `isNumber`, que comprueba si un valor es un `number` o un `bigint` _finitos_, es decir, que no es `NaN` ni `Infinity`.

A veces, el dispositivo lector de identificadores falla y lee un valor no numérico como `NaN` (no es un número) o `Infinity`.
Tu función también debería saber manejar esto correctamente.

```javascript
isNumber(42);
// => true

isNumber('Hello, World!');
// => false

isNumber(42n);
// => true

isNumber(NaN);
// => false
```

### 3. Comprobar si un valor es un objeto

Implementa la función `isObject`, que debe comprobar si el valor es un objeto.
En la cinta transportadora, `null` no es nada y no se considera un objeto.

```javascript
isObject({ greeting: 'Hello' });
// => true

isObject(25n);
// => false
```

### 4. Comprobar si un string es numérico

Implementa la función `isNumericString`, que debe comprobar si el valor es un string formado únicamente por dígitos, o por un signo menos seguido de dígitos que indique un número negativo.
Solo deben considerarse números enteros; los números decimales no se consideran numéricos para esta comprobación del robot de reciclaje.

```javascript
isNumericString(42);
// => false

isNumericString('42');
// => true

isNumericString('Hi!');
// => false
```

### 5. Comprobar si un objeto es electrónico

Implementa la función `isElectronic`, que comprueba si un objeto es una instancia de la clase `ElectronicDevice` proporcionada o de una de sus clases hijas.

```javascript
class Duck {
  //...
}

class WashingMachine extends ElectronicDevice {
  //...
}

isElectronic(new Duck());
// => false

isElectronic(new WashingMachine());
// => true
```

### 6. Comprobar si un valor es un array no vacío

Implementa la función `isNonEmptyArray`, que comprueba si un valor es un array no vacío.

```javascript
isNonEmptyArray([1, 2, 3]);
// => true

isNonEmptyArray([]);
// => false
```

### 7. Comprobar si un valor es un array vacío

Implementa la función `isEmptyArray`, que comprueba si un valor es un array vacío.

```javascript
isEmptyArray([1, 2, 3]);
// => false

isEmptyArray([]);
// => true
```

### 8. Comprobar si un objeto tiene una propiedad o un método `type`

Implementa la función `hasType`, que comprueba si un objeto tiene una propiedad o un método `type`.

```javascript
class Keyboard(){
  type(){
    // ...
  }
}
hasType({ type:"car", color:"red" })
// => true

hasType({ color:"green" })
// => false

hasType(new Keyboard())
// => true
```

### 9. Lanzar un error si un objeto no tiene una propiedad o un método `id`

Implementa la función `assertHasId`, que lanzará un `Error` si a un objeto le falta la propiedad `id`.

Si un objeto sí tiene la propiedad `id`, no debe devolver nada.

```javascript
assertHasId({ id: 42, color: 'red' });
// => undefined

assertHasId({ color: 'green' });
// Error: "Object is missing the 'id' property"
```

### 10. Comprobar si un objeto tiene una propiedad `id`

Implementa la función `hasIdProperty`, que comprueba si un objeto tiene una propiedad `id`.

```javascript
class SimpleData {
  constructor() {
    this.number = '42';
    this.id = 'BC269327FE1D9B95';
  }
}

class StealingData extends SimpleData {}

class MethodData {
  constructor() {
    this.number = '42';
    this._id = 'BC269327FE1D9B95';
  }

  get id() {
    return this._id;
  }
}

hasIdProperty(new SimpleData());
// => true

hasIdProperty(new MethodData());
// => false

hasIdProperty(new StealingData());
// => false
```

### 11. Comprobar si un objeto tiene una propiedad `type` definida

Implementa la función `hasDefinedType`, que comprueba si un objeto tiene una propiedad `type` que no sea `undefined`.

```javascript
hasDefinedType({ type: undefined, color: 'red' });
// => false

hasDefinedType({ type: 'car', color: 'green' });
// => true
```
