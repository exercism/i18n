# Introducción

El tipo `enum` de C# representa un conjunto fijo de constantes con nombre (una enumeración). Su propósito principal es ofrecer una forma segura respecto a los tipos de interactuar con constantes numéricas, limitando los valores disponibles a un conjunto predefinido. Un `enum` sencillo se puede definir de la siguiente manera:

```csharp
enum Season
{
    Spring,
    Summer,
    Autumn,
    Winter
}
```

Si no se definen explícitamente, a los miembros del `enum` se les asignan automáticamente valores enteros incrementales, y el primero de ellos es cero. También es posible asignar valores explícitamente:

```csharp
enum Answer
{
    Maybe = 1,
    Yes = 3,
    No = 5
}
```
