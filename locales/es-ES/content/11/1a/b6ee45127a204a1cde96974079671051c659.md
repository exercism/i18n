# Pruebas

Para ejecutar las pruebas en la línea de comandos, ejecuta el siguiente comando desde el directorio del ejercicio:

```bash
java -jar /path/to/mars.jar nc runner.mips impl.mips
```

## Interfaz gráfica

Para ejecutar las pruebas a través de la interfaz gráfica del simulador MARS, incluye tu implementación con `include` al final de `runner.mips`, descomentando la última línea.
