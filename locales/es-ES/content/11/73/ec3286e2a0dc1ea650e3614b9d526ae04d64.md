# Instalación

## Instalar Dart

Puedes encontrar las instrucciones para instalar el SDK de Dart en el sitio web de Dart: [Obtener Dart][get-dart]

## Complemento de Dart para tu IDE o editor

Si usas un IDE o un editor, [añade un complemento de Dart][editors] si existe para el editor que elijas.

[get-dart]: https://dart.dev/get-dart
[editors]:  https://dart.dev/tools#editors
