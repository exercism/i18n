# Anexo a las instrucciones

## Sugerencias

Para completar este ejercicio, necesitas crear el tipo de datos `Robot`, como una variable mutable, y el tipo de datos `RunState`. También necesitas implementar las siguientes funciones:

- `initialState`
- `mkRobot`
- `resetName`
- `robotName`

Encontrarás una declaración de datos ficticia y firmas de tipo ya en su sitio, pero depende de ti definir las funciones y crear un tipo de datos significativo, un newtype o un sinónimo de tipo. Para modelar el estado, este ejercicio utiliza la mónada [`State`](https://en.wikibooks.org/wiki/Haskell/Understanding_monads/State). Más concretamente, combinamos la mónada `State` con la mónada `IO` usando los [transformadores de mónada `StateT`](http://book.realworldhaskell.org/read/monad-transformers.html). Todas las pruebas se ejecutan con `initialState` como el estado que se pasa a `evalStateT`.
