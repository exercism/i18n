# Instrucciones adicionales

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** para indicar cuál es el origen del error. Esto hace que tu código sea más legible y ayuda en gran medida a la depuración. En situaciones en las que sabes que el origen del error será de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así debes incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» un error cuando no se siguen las reglas de puntuación o de juego. Las pruebas solo pasarán si tanto lanzas la `exception` con `raise` como incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento para el tipo `exception`:

```python
# example when a bonus is attempted with an open frame
raise IndexError("cannot throw bonus with an open tenth frame")

# example when fill balls are invalid
raise ValueError("invalid fill balls")
```
