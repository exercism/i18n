## Iteración de arrays

Un bucle `for` permite recorrer un array y repetir el código para cada elemento:

```haxe
var fruitList = ["apple", "banana", "pear"];

for (fruit in fruitList) {
  trace(fruit);
}

// apple
// banana
// pear
```

En el ejemplo anterior, `fruit` es la variable que contiene el valor de un elemento concreto del array `fruitList`. El compilador se asegura de que `fruitList` se pueda recorrer; de lo contrario, detendrá la ejecución.

## Iteración de rangos

Puedes recorrer números con el operador de rango. El operador toma dos operandos de tipo `Int` y se escribe como `min...max`. El `min` es inclusivo y el `max` es exclusivo (`min` <= i y `max` > i)

```haxe
for (i in 0...10) {
  trace(i); // from 0 to 9
}
```

## Iteración de pares clave-valor

Es posible recorrer colecciones de pares clave-valor. La única diferencia en la sintaxis es que, en lugar de una sola variable, se usa un identificador de variable para la clave, seguido de `=>`, seguido del identificador de variable para el valor:

```haxe
var map = [1 => 101, 2 => 202, 3 => 303];

for (k => v in map) {
  trace(key, value);
}

// 1, 101
// 2, 202
// 3, 303
```
