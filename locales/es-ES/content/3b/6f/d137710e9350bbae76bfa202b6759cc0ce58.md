# Crear ficheros con Configlet

Cuando añadas un nuevo enfoque, artículo o ejercicio, tendrás que crear ficheros con nombres muy concretos.
Además, requieren que se añadan o actualicen ficheros de configuración.
Con el comando `create`, [configlet](/docs/building/configlet) puede hacer todo esto por ti.

## Uso

El comando `create` sirve para crear los ficheros necesarios para añadir un nuevo enfoque, artículo o ejercicio, además de modificar los ficheros de configuración que haga falta.

```shell
configlet [global-options] create [command-options]

Options for create:
      --approach <slug>           The slug of the approach
      --article <slug>            The slug of the article
      --practice-exercise <slug>  The slug of the practice exercise
      --concept-exercise <slug>   The slug of the concept exercise
  -e, --exercise <slug>           Only operate on this exercise
  -o, --offline                   Do not update the cached 'problem-specifications' data
```

## Crear un ejercicio de práctica

La documentación sobre [cómo añadir ejercicios de práctica](/docs/building/tracks/practice-exercises/add) contiene instrucciones detalladas sobre cómo añadir un ejercicio de práctica.

## Crear un ejercicio de concepto

Para crear un ejercicio de concepto, hay que especificar su slug:

```shell
configlet create --concept-exercise bird-watcher
```

Esto creará los ficheros necesarios del ejercicio de concepto, tal y como se especifica en la [documentación de los ejercicios de concepto](/docs/building/tracks/concept-exercises).

Por supuesto, esto es solo el primer paso para crear un ejercicio.
A continuación, tendrás que:

- Añadir tests al fichero de tests
- Añadir una implementación ejemplar
- Definir el contenido del fichero stub
- Escribir la introducción en `.docs/introduction.md`
- Escribir las instrucciones en `.docs/instructions.md`
- En el fichero `.meta/config.json` del ejercicio:
  - Añadir el nombre de usuario de GitHub de los autores del ejercicio a la clave `authors`
- En el fichero `config.json` de la pista:
  - Comprobar/actualizar la dificultad del ejercicio
  - Añadir conceptos a la clave `concepts`
  - Añadir conceptos a la clave `prerequisites`

## Crear un enfoque

Para crear los ficheros de un enfoque, hay que especificar el slug del enfoque y el de su ejercicio:

```shell
configlet create --approach recursion --exercise collatz-conjecture
```

Esto creará los ficheros necesarios del enfoque, tal y como se especifica en la [documentación de los enfoques](/docs/building/tracks/approaches).

## Crear un artículo

Para crear los ficheros de un artículo, hay que especificar el slug del artículo y el de su ejercicio:

```shell
configlet create --article performance --exercise collatz-conjecture
```

Esto creará los ficheros necesarios del artículo, tal y como se especifica en la [documentación de los artículos](/docs/building/tracks/articles).
