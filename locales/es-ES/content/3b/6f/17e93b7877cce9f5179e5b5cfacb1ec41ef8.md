# Pistas

## 1. Crea un nuevo array

- Puedes encontrar en [esta página][create-and-initialize] cómo definir un array vacío.

## 2. Define un array existente

- Puedes encontrar en [esta página][create-and-initialize] cómo definir e inicializar un array con varios elementos.

## 3. Añade un nuevo lenguaje a un array

- Hay un [operador integrado][cons] para añadir un elemento al principio de un array.

## 4. Cuenta los lenguajes del array

- Hay una función en el módulo `List` para [contar los elementos de un array][length].

## 5. Invierte el array

- Hay una función en el módulo `List` para [invertir un array][reverse].

## 6. Comprueba si el array es emocionante

- Puedes usar la coincidencia de patrones con los patrones [cons][cons-pattern] y [list][list-pattern] para hacer coincidir estructuras de array concretas.
