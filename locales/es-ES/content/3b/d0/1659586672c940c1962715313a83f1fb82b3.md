# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que los demás lo leyeran con facilidad, el mensaje se cifró realizando una serie de manipulaciones de bits.
Tendrás que escribir las funciones que ayuden a descifrar el mensaje.

## 1. Desplaza los bits hacia atrás

El primer paso para descifrar el mensaje es deshacer el desplazamiento del proceso de cifrado desplazando los bits de nuevo a la derecha.
En el proceso de descifrado habrá pasos posteriores que dan por sentado que se insertan 0s desde el lado izquierdo.

Implementa la función `shift_back()`, que recibe un valor y el número de posiciones que hay que desplazar, y realiza el desplazamiento.

```julia
shift_back(0b1001, 2) # => 0b0010
```

## 2. Pon algunos bits a 1

A continuación, hay algunos bits que hay que poner a 1.

Implementa la función `set_bits()`, que recibe un valor y una máscara y devuelve el resultado de poner a 1 los bits de value.
Un bit de `value` debe ponerse a 1 cuando el bit correspondiente de `mask` también sea 1.
Todos los demás bits deben dejarse sin cambios.

```julia
set_bits(0b0110, 0b0101) # => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado.
Habrá que invertirlos de nuevo para descifrar el mensaje.

Implementa la función `flip_bits()`, que recibe un valor y la máscara.
La máscara indica qué bits del valor hay que invertir.
Si el bit es 1 en `mask`, el bit se invierte en `value`.
Todos los demás bits se dejan sin cambios.

```julia
flip_bits(0b1100, 0b0101) # => 0b1001
```

## 4. Borra bits específicos

Por último, también hay ciertos bits que siempre se descifran como 0.

Implementa la función `clear_bits()`, que recibe un valor y una máscara.
Los bits de `value` deben ponerse a 0 cuando el bit de la máscara sea 1.
Todos los demás bits deben dejarse sin cambios.

```julia
clear_bits(0b0110, 0b0101) # => 0b0010
```
