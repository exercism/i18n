# Anexo a las instrucciones

## Cómo se implementa este ejercicio en Python: recursión

Este ejercicio está pensado para completarse usando [concept:python/recursion](), en lugar de bucles.
Una función recursiva es una función que se llama a sí misma, lo cual es útil para resolver problemas que se definen en términos de sí mismos.
Para evitar la recursión infinita (o, más concretamente, para evitar desbordar la pila), se usa algo llamado «caso base».
Cuando se alcanza el caso base, se devuelve un valor no recursivo, lo que permite que la llamada anterior a la función se resuelva y devuelva su valor, y así sucesivamente, propagándose hacia atrás por la pila hasta que la primera llamada a la función devuelve la respuesta.
Podríamos escribir una función recursiva que halle la respuesta de 5! (es decir, 5 * 4 * 3 * 2 * 1) así:

````python
def factorial(number):
  if number <= 1:  # base case
    return 1

  return number * factorial(number - 1) # recursive case

print(factorial(5)) # returns 120
````

Por último, cabe señalar que Python limita el número de veces que se pueden hacer llamadas recursivas (1000 por defecto) y no optimiza la [recursión de cola][tail-recursion].

## Mensajes de excepción

A veces es necesario [lanzar una excepción][raising].
Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda enormemente con la depuración.
En situaciones en las que sabes que el origen del error va a ser de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados][built-in-errors], pero aun así debes incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción raise][raise-statement] para "lanzar" varios `ValueErrors` si se pasa un número negativo a la función `rows()`.
Las pruebas solo pasarán si lanzas la `exception` con `raise` y además incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# if the rows function is passed a negative number.
raise ValueError("number of rows is negative")
```
