# Mutabilidad

Cairo, con su diseño orientado a la blockchain, implementa por defecto un modelo de memoria inmutable.
Esto significa que, una vez que un valor se escribe en la memoria, no se puede sobrescribir, solo leer.
Sin embargo, Cairo ofrece un mecanismo para crear variables mutables usando la palabra clave `mut`.
Cuando una variable se declara como mutable y se cambia su valor, el nuevo valor se escribe en una nueva celda de memoria y la variable se actualiza para apuntar a la nueva celda.
Este mecanismo aporta flexibilidad a la vez que conserva las ventajas de la inmutabilidad.

En el ejemplo siguiente, `x` se declara como una variable inmutable.
Si se cambia el valor de `x`, el compilador lanzará un error.

```rust
let x = 5;
x = 2; // Error: cannot assign twice to immutable variable
```

Podemos declarar `x` como una variable mutable usando la palabra clave `mut`.
Esto permite cambiar el valor de `x` después de declararlo.

```rust
let mut x = 5;
x = 10;
```

En última instancia, decidir si usar mutabilidad o no depende de ti y de lo que consideres más claro en esa situación concreta.

## Constantes

Al igual que las variables inmutables, las constantes son valores vinculados a un nombre a los que no se les permite cambiar, pero hay unas cuantas diferencias entre constantes y variables:

- Las constantes se declaran con la palabra clave `const`
- No se permite usar `mut` con constantes
- El tipo del valor siempre debe indicarse de forma explícita
- Las constantes solo pueden declararse en el scope global
- Las constantes solo pueden establecerse con expresiones constantes, no con el resultado de un valor calculado en tiempo de ejecución

```rust
struct AnyStruct {
    a: u256,
    b: u32
}

enum AnyEnum {
    A: felt252,
    B: (usize, u256)
}

const ONE_HOUR_IN_SECONDS: u32 = 3600;
const STRUCT_INSTANCE: AnyStruct = AnyStruct { a: 0, b: 1 };
const ENUM_INSTANCE: AnyEnum = AnyEnum::A('any enum');
const BOOL_FIXED_SIZE_ARRAY: [bool; 2] = [true, false];
```

Es posible usar la macro `consteval_int!` para crear una variable `const` que sea el resultado de algún cálculo.

```rust
const ONE_HOUR_IN_SECONDS: u32 = consteval_int!(60 * 60);
```

## Shadowing

Es posible, y a menudo idiomático, reutilizar el nombre de una variable a medida que un valor concreto se transforma, volviéndola a declarar con varias invocaciones de `let`.
Esto se conoce como _shadowing_.
En la práctica, la segunda variable eclipsa a la primera y asume todos los usos del nombre de la variable hasta que ella misma quede eclipsada o hasta que termine el scope.

```rust
fn main() {
    let s: ByteArray = "my string";
    let s: ByteArray = s + " and a shadow";
    {
        let s: ByteArray = "a nested shadow";
        println!(s); // emits "a nested shadow"
    }
    println!(s); // emits "my string and a shadow"
}
```

Usando shadowing, podemos incluso cambiar el tipo de la variable reutilizando el mismo nombre.

```rust
fn main() {
    let x: u64 = 2;
    println!("x is u64, value: {}", x);               // prints "x is u64, value: 2"
    let x: ByteArray = format!("fizz");               // converts x to a ByteArray, type annotation is required
    println!("x is now ByteArray, value: \"{}\"", x); // prints 'x is now ByteArray, value: "fizz"'
}
```
