# Instrucciones case

```sather
   case zone
   when 0 then return 0;
   when 1, 2 then return 550;
   else return 920;
   end;
```

## Cómo se compara

El valor que sigue a `case` se compara con cada valor de `when` usando `=`, de arriba abajo. Se ejecuta la primera coincidencia, y solo esa. Las partes `when` restantes se omiten, y la ejecución continúa después del `end`.

Cualquier tipo que admita `=` puede usarse: `INT`, `CHAR`, `STR`, `BOOL`.

## El else

Un `case` sin coincidencia y sin `else` provoca un error fatal en tiempo de ejecución. Escribe siempre uno. Cuando los casos restantes realmente no deberían ocurrir, dilo ahí en lugar de omitirlo:

```sather
   else
      raise "unknown zone: " + zone;
   end;
```

`raise` llega más adelante; hasta entonces, devolver un valor predeterminado razonable está bien.

## Cuándo preferir if

`case` compara un valor con constantes. Cualquier otra cosa necesita `if`:

```sather
   -- ranges
   if age < 13 then ... elsif age < 16 then ... end;

   -- more than one value at a time
   if score >= 8 and sings then ... end;
```

Intentar forzar un rango dentro de un `case` produce algo más largo y peor que el `if` al que sustituye.

## case como expresión

`case` es una instrucción, no una expresión, así que esto no es Sather válido:

```sather
   -- wrong
   fare := case zone when 1 then 550 else 920 end;
```

Devuelve desde dentro de cada rama, o asigna a una variable dentro de cada rama.
