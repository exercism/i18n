# Instrucciones

En este ejercicio vamos a simular el primer turno de una partida de [Blackjack](https://en.wikipedia.org/wiki/Blackjack).

Recibirás dos cartas y podrás ver la carta descubierta del crupier. Todas las cartas se representan con un string como «ace», «king», «three», «two», etc. Los valores de cada carta son:

| carta | valor | carta | valor |
| :---: | :---: | :---: | :---: |
|  ace  |  11   | eight |   8   |
|  two  |   2   | nine  |   9   |
| three |   3   |  ten  |  10   |
| four  |   4   | jack  |  10   |
| five  |   5   | queen |  10   |
|  six  |   6   | king  |  10   |
| seven |   7   | other |   0   |

**Nota**: Normalmente, los ases pueden tomar el valor de 1 o 11, pero por simplicidad supondremos que solo pueden tomar el valor de 11.

Según tus dos cartas y la carta del crupier, existe una estrategia para el primer turno del juego, en la que tienes las siguientes opciones:

    - Plantarse (S)
    - Pedir carta (H)
    - Dividir (P)
    - Ganar automáticamente (W)

Aunque aún no es óptima, seguirás la estrategia que tu amigo Alex ha estado desarrollando, que es la siguiente:

Categoría: mano grande

- Si tienes una pareja de ases, siempre debes dividirlos.
- Si tienes un Blackjack (dos cartas que suman un valor de 21) y el crupier no tiene un as, una figura o un diez, ganas automáticamente. Si el crupier tiene alguna de esas cartas, tendrás que plantearte y esperar a que se revele la otra carta.

Categoría: mano pequeña

- Si tus cartas suman 17 o más, siempre debes plantearte.
- Si tus cartas suman 11 o menos, siempre debes pedir carta.
- Si tus cartas suman un valor dentro del intervalo [12, 16], siempre debes plantearte a menos que el crupier tenga un 7 o más, en cuyo caso siempre debes pedir carta.

La lógica general ya está implementada. Tienes cuatro tareas:

## 1. Calcula la puntuación de cualquier carta.

Implementa una función que calcule el valor numérico de una carta a partir de su nombre usando condicionales.

```java
parseCard("ace")
// returns 11
```

## 2. Determina si dos cartas forman un Blackjack.

Implementa una función que devuelva `true` si dos cartas forman un Blackjack y `false` en caso contrario.

```java
isBlackjack("queen", "ace")
// returns true
```

## 3. Implementa la lógica de decisión para puntuaciones de mano mayores de 20 puntos.

Implementa una función que devuelva la representación en forma de string de una decisión a partir de tus cartas. Esta función solo se llama si el `handScore` es mayor de 20. Recibirá 2 argumentos: `isBlackJack` y `dealerScore`. Debe implementar los puntos de la categoría «mano grande» anterior.

```java
isBlackJack = true
dealerScore = 7
largeHand(isBlackJack, dealerScore)
// returns "W"
```

## 4. Implementa la lógica de decisión para puntuaciones de mano con menos de 21 puntos.

Implementa una función que devuelva la representación en forma de string de una decisión a partir de tus cartas. Esta función solo se llama si el `handScore` es menor de 21. Recibirá 2 argumentos: `handScore` y `dealerScore`. Debe implementar los puntos de la categoría «mano pequeña» anterior.

```java
handScore = 15
dealerScore = 12
SmallHand(handScore, dealerScore)
// returns "H"
```
