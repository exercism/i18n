# Pistas

## General

- Existen tres [operadores booleanos][boolean-operators] para trabajar con valores booleanos.
- Se pueden combinar varios operadores en una sola expresión.

## 1. Comprobar si se puede realizar un ataque rápido

- El operador lógico NOT (`!`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprobar si se puede espiar al grupo

- Los operadores booleanos se suelen usar para evaluar si dos o más expresiones son verdaderas o no.

## 3. Comprobar si se puede enviar una señal al prisionero

- Los operadores booleanos se ejecutan en el orden de su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.
- Para más detalles, consulta la sección Operator Precedence en la [documentación oficial de Julia][operator-precedence].

## 4. Comprobar si se debe mostrar la opción «Free Prisoner»

- Los operadores booleanos se ejecutan en el orden de su precedencia (de mayor a menor): `!`, `&&`, `||`.
- En general, se recomienda usar paréntesis para que tu intención quede más clara.
