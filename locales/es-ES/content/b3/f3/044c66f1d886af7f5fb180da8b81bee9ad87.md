# Instrucciones

Refactoriza un analizador de Markdown.

El ejercicio Markdown es un ejercicio de refactorización.
Hay un código que analiza un string dado con [sintaxis de Markdown][markdown] y devuelve el HTML asociado a ese string.
Aunque este código está escrito de forma confusa y es difícil de seguir, ¡de algún modo funciona y todos los tests pasan!
Tu reto es reescribir este código para que sea más fácil de leer y de mantener, a la vez que te aseguras de que todos los tests sigan pasando.

Sería útil que anotaras en los comentarios lo que has hecho durante la refactorización, para que los revisores puedan verlo, pero no es estrictamente necesario.
¡Lo más importante es mejorar el código!

[markdown]: https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax
