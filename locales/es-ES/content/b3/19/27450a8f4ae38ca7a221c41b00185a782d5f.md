# Bucles `for`

La iteración es un concepto fundamental de la programación que te permite ejecutar un bloque de código varias veces.
En Swift hay dos tipos de bucles: los [bucles `for-in`][for-loops] y los bucles `while`.
En este capítulo aprenderás cómo funcionan los bucles `for-in`.

Los bucles `for` te permiten iterar sobre una secuencia de valores, tomando cada elemento por turno y vinculándolo a una variable que tú elijas.
Swift te permite iterar sobre diversos tipos de secuencias, como rangos, arrays y strings (y otros tipos que veremos más adelante).
Cuando se ha iterado sobre todos los elementos de la secuencia, el bucle termina.

Los bucles `for` se declaran con la palabra clave `for`, seguida de un nombre de variable, la palabra clave `in` y una secuencia de valores sobre la que iterar.
La variable que se declara en el bucle `for-in` es inmutable, lo que significa que no puedes cambiar su valor dentro del bucle.
Aquí tienes un ejemplo de un bucle `for-in` que itera sobre un array de números:

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
  print(number)
}
print("Done with numbers")

// prints:
// 3
// 10
// 7
// 11
// Done with numbers
```

~~~~exercism/note
La variable `number` se declara en el bucle `for-in` y solo está disponible dentro del scope del bucle.

```swift
let numbers = [3, 10, 7, 11]

for number in numbers {
    number + 1
}
number + 1
// Error: Use of unresolved identifier 'number'
```
~~~~

## Iterar sobre un rango

También puedes iterar sobre un rango de números con un bucle `for-in`.
Esto te permite ejecutar un bloque de código un número concreto de veces; por ejemplo, el rango `1...5` iterará sobre los números 1, 2, 3, 4 y 5, así que el bucle se ejecutará 5 veces.
A veces puede que quieras iterar sobre índices de una estructura de datos como un array; en ese caso puedes usar un rango `0..<array.count`.

```swift
let numbers = [3, 10, 7, 11]

for i in 0..<numbers.count {
  print(numbers[i])
}

// prints:
// 3
// 10
// 7
// 11
```

## Iterar sobre un string

También puedes iterar sobre un string con un bucle `for-in`.
Esto te permite iterar sobre cada carácter del string; fíjate en que el tipo que se declara en el bucle es `Character`.

```swift
let message = "Hello!"

for character in message {
  print(character)
}

// prints:
// H
// e
// l
// l
// o
// !
```

## stride

Swift también ofrece una función `stride` que te permite crear una secuencia sobre un rango con un paso concreto.
Luego puedes iterar sobre ella con un bucle `for-in`.
`stride` se define como [`stride(from:to:by:)`][stride-to] o [`stride(from:through:by:)`][stride-through]; la primera es exclusiva y la segunda es inclusiva.

```swift
for i in stride(from: 0, to: 10, by: 2) {
  print(i)
}

// prints:
// 0
// 2
// 4
// 6
// 8
```

Ten en cuenta que el parámetro `to` es exclusivo, así que el bucle iterará hasta el número anterior al parámetro `to`, mientras que el parámetro `through` es inclusivo, así que en este caso también incluiría el `10`.

[stride-to]: https://developer.apple.com/documentation/swift/stride(from:to:by:)
[stride-through]: https://developer.apple.com/documentation/swift/stride(from:through:by:)
[for-loops]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
