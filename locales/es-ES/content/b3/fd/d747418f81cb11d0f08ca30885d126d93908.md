# Anexo de instrucciones

## Cómo está estructurado este ejercicio en Python

Hemos añadido un descriptor de semana adicional (`fifth`) para el quinto día de la semana del mes, si lo hay.  
Si no hay un quinto día de la semana en un mes, debes lanzar una excepción.

## Personalizar y lanzar excepciones

A veces es necesario tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) como [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) excepciones en tu código. Cuando hagas esto, siempre debes incluir un **mensaje de error significativo** para indicar cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho con la depuración.

Las excepciones personalizadas se pueden crear mediante nuevas clases de excepción (consulta [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para más detalles) que normalmente son subclases de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

En situaciones en las que sabes que el origen del error será un derivado de cierto tipo de excepción, puedes optar por heredar de uno de los [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) bajo la clase _Exception_. Al lanzar el error, también debes incluir un mensaje significativo.

Este ejercicio en particular requiere que crees una _excepción personalizada_ que sea [lanzada](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«disparada» cuando a tu función `meetup()` se le dé una combinación de nombre de día de la semana y número que no sea válida. Las pruebas solo pasarán si personalizas las excepciones adecuadas, las lanzas con `raise` e incluyes los mensajes de error adecuados.

Para personalizar una `built-in exception`, crea una `class` que herede de esa excepción. Al lanzar la excepción personalizada con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# subclassing the built-in ValueError to create MeetupDayException
class MeetupDayException(ValueError):
    """Exception raised when the Meetup weekday and count do not result in a valid date.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a MeetupDayException
raise MeetupDayException("That day does not exist.")
```
