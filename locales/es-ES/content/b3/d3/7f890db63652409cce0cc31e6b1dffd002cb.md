# Instructions

En este ejercicio, escribirás algo de código que te ayudará a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitarás obtener un permiso de conducir, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo de segunda mano.

## 1. Determina si necesitarás un permiso de conducir

Algunos tipos de vehículos requieren un permiso de conducir para conducirlos.
Supón que solo los tipos `car` y `truck` requieren permiso; todo lo demás se puede conducir sin permiso.

Implementa la función `needs_license(kind)`, que recibe el tipo de vehículo y devuelve un valor que indica si necesitas un permiso para ese tipo de vehículo.

```R
needs_license("car");
# => TRUE

needs_license("bike");
# => FALSE
```

## 2. Elige entre dos posibles vehículos para comprar

Evalúas tus opciones de vehículos disponibles.
Consigues reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para ello, implementa la función `choose_vehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que es simplemente la opción que aparece primero en orden alfabético.

```R
choose_vehicle("Wuling Hongguang", "Toyota Corolla");
# =>  "Toyota Corolla"

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf");
# =>  "Volkswagen Beetle"
```

## 3. Calcula una estimación del precio de un vehículo de segunda mano

Ahora que has tomado tu decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo de segunda mano, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70 % del precio original.

Implementa la función `calculate_resale_price(original_price, age)`.
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en el concesionario.

```R
calculate_resale_price(1000, 1);
# => 800

calculate_resale_price(1000, 5);
# => 700

calculate_resale_price(1000, 15);
# => 500
```
