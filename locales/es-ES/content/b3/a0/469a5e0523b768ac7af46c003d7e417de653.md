# Introducción

Un *montículo* es una colección que siempre conoce su elemento más
pequeño y te permite sacarlo rápidamente. Es la herramienta natural
para una *cola de prioridad*: una cola de espera en la que se atiende
primero el elemento más importante, no el que lleva más tiempo
esperando. Los montículos viven en el vocabulario [`heaps`][heaps].

## Construir un montículo

`<min-heap>` construye un montículo vacío cuya clave *más pequeña* sale
primero; `<max-heap>` es su imagen especular.

```
<min-heap> ( -- min-heap )
<max-heap> ( -- max-heap )
```

## Añadir elementos

Cada elemento se guarda como un *valor* junto con una *clave*: la clave
es la prioridad que Factor usa para ordenar. `heap-push` añade uno:

```
heap-push ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push   ! value "alice", priority 5
"bob"   2 pick heap-push   ! value "bob",   priority 2
```

Un montículo es *mutable*: `heap-push` lo modifica in situ en lugar de
devolver uno nuevo. `keep` resulta práctico para volver a poner el
montículo en la pila después de que `heap-push` lo haya consumido.

## Consultar y extraer el elemento del frente

`heap-peek` devuelve el elemento del frente (el valor con la clave más
pequeña) *sin* extraerlo. `heap-pop` devuelve ese elemento *y* lo
extrae. `heap-empty?` indica si queda algo, para que sepas cuándo dejar
de extraer. `heap-pop-all` elimina todo de una vez y devuelve una lista
de asociaciones de pares `{ key value }` en orden de prioridad.

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-empty?  ( heap -- ? )
heap-pop-all ( heap -- alist )
```

```factor
USING: assocs heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-empty? .        ! => f      (two items waiting)
dup heap-peek drop .     ! => "bob"  (smallest key, still in the heap)
dup heap-pop drop .      ! => "bob"  (smallest key, now removed)
heap-pop-all .           ! => { { 5 "alice" } }
```

`heap-pop` y `heap-empty?` son las piezas básicas para servir
elementos de uno en uno: consulta el frente o extráelo, actúa sobre él
y para en cuanto `heap-empty?` devuelva `t`. Las tareas de abajo usan
`heap-pop-all` para vaciar toda la cola de un solo paso, pero el mismo
orden se obtiene extrayendo hasta que el montículo esté vacío.

Los pares que devuelve `heap-pop-all` son una *lista de asociaciones*:
`values` (de `assocs`) conserva solo los valores y descarta las claves.
