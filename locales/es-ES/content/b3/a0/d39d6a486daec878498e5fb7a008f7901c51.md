# Acerca de

El ámbito de un valor tiene que ver con el lugar del programa desde el que se puede acceder a ese valor.

## Los cuatro tipos de scope: bloque, función, prototipo de función, fichero

### Scope de bloque

Solo se puede acceder a un valor con scope de bloque desde dentro del bloque en el que se define.
Para saber más sobre los bloques, consulta el [concepto de bloque](../blocks/introduction.md#Introduction).

### Scope de función

El scope de función es un tipo especial de scope que se aplica a las etiquetas que se usan con instrucciones `goto`.
No se pueden usar dos etiquetas con el mismo nombre en la misma función, aunque las etiquetas se definan en bloques distintos dentro de la función.

### Scope de prototipo de función

El scope de prototipo de función es otro tipo especial de scope que solo se aplica a los parámetros con nombre dentro del prototipo (también llamado declaración, teniendo en cuenta que no todas las declaraciones son prototipos).
El nombre de un parámetro suele ser opcional en una declaración de función.
El scope de un nombre solo es relevante dentro de la declaración.
En el siguiente ejemplo, el identificador `len` se define y luego se hace referencia a él más adelante en la declaración de la función.

```c
#include <stdio.h>

// len is defined and then referred to
void my_func(int len, int numbers[len]);

int main() {
    int numbers[2];
    numbers[0] = 1;
    numbers[1] = 2;
    my_func(2, numbers);
}

void my_func(int length, int numbers[length]) {
    // prints numbers should have 2 elements
    printf("numbers should have %d elements", length);
}
```

Ten en cuenta que, dentro de una declaración, los nombres deben coincidir cuando se hace referencia a la misma variable.
Si `my_func` se declarara como `void my_func(int len, int numbers[length]);`, se generaría un error de compilación parecido a este:

```
/tmp/scn62kKPEZ.c:4:35: error: 'length' undeclared here (not in a function)
    3 | void my_func(int len, int numbers[length]);
      |                                   ^~~~~~
/tmp/scn62kKPEZ.c: In function 'main':
/tmp/scn62kKPEZ.c:10:16: error: type of formal parameter 2 is incomplete
   10 |     my_func(2, numbers);
```

Una definición de función no tiene por qué usar para un parámetro el mismo nombre que se usó en la declaración de la función.
En el ejemplo anterior, se usó `len` en la declaración y `length` en la definición, lo que demuestra que el scope del identificador `len` solo abarcaba la declaración de la función.

### Scope de fichero

Se puede acceder a un valor con scope de fichero desde cualquier lugar del fichero.
Todo valor de este tipo se define fuera de una función.
