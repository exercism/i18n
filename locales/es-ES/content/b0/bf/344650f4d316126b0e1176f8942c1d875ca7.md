# Consejos

## General

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Tienes que usar `[]` para desreferenciar direcciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.

## 1. Obtén la primera letra de una frase

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Tienes que usar `[]` para desreferenciar direcciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Los valores de 1 byte se devuelven en `al`.

## 2. Pon en mayúscula una palabra

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Tienes que usar `[]` para desreferenciar direcciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Poner en mayúscula significa tener un único carácter _en mayúscula_, seguido de caracteres _en minúscula_.
- Solo los valores entre 'a' y 'z' son letras minúsculas, y solo los valores entre 'A' y 'Z' son letras mayúsculas.
- Así que, primero, tienes que extraer la primera letra y convertirla a mayúscula si está en minúscula.
- Después, tienes que determinar el resto del string: cada carácter posterior al primero debe convertirse a minúscula si es una letra mayúscula, o dejarse sin cambios en caso contrario.
- El string termina cuando se encuentra `'\0'` (el carácter NUL).
- Puedes usar `lodsb` para cargar en `al` un byte de la dirección de memoria de `rsi`, incrementando `rsi` en 1.
- Puedes usar `stosb` para almacenar en la dirección de memoria de `rdi` un byte cargado en `al`, incrementando `rdi` en 1.

## 3. Obtén la última letra de una frase

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Tienes que usar `[]` para desreferenciar direcciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Tienes que recorrer el string con un bucle para encontrar la última letra.
- Solo los valores entre 'a' y 'z' son letras minúsculas, y solo los valores entre 'A' y 'Z' son letras mayúsculas.
- Los valores de 1 byte se devuelven en `al`.

## 4. Sé educado

- En un string codificado en ASCII, todos los caracteres ocupan 1 byte en memoria.
- Tienes que usar `[]` para desreferenciar direcciones de memoria.
- El valor ASCII de una letra mayúscula es 32 menos que el valor ASCII de la letra minúscula equivalente.
- Reutiliza una función existente para poner en mayúscula la palabra.
- Puedes usar `movsb` para copiar un byte de la dirección de memoria de `rsi` a la dirección de memoria de `rdi`, incrementando tanto `rsi` como `rdi` en 1.
- Puedes definir un string inicializado en _section .rodata_ o _section .data_.
- Debes usar `rel` para calcular una dirección relativa.
- Para un array declarado con la etiqueta `arr`, `$ - arr` sería el tamaño total de `arr` en bytes si se usa justo después de declarar el array.
- Puedes usar `rep` para repetir una instrucción de string como `movsb` un número de veces especificado por `rcx`.
- El string debe terminar con `'\0'` (el carácter NUL) como terminador.
- Recuerda que los caracteres especiales, con una barra invertida (como `'\0'`), deben definirse entre backticks (`` ` ``), o usando su valor decimal (que es `0` para NUL).
