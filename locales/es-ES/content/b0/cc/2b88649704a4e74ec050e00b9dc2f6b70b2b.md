# Anexo a las instrucciones

## Registros

| Registro | Uso        | Tipo    | Descripción                                          |
| -------- | ---------- | ------- | ---------------------------------------------------- |
| `$a0`    | entrada    | dirección | string de la pregunta terminado en nulo            |
| `$v0`    | salida     | entero  | resultado, 0 si la pregunta no es válida             |
| `$t0-9`  | temporal   | cualquiera | para almacenamiento temporal                      |
