# Introducción

## Bucles `while`

Con un bucle `while`, puedes ejecutar código de forma repetida siempre que se cumpla una condición.
Se escribe con la palabra clave `while`, seguida de una condición entre paréntesis y un bloque de código que contiene el _cuerpo_ del bucle entre llaves.

```javascript
while (condition) {
  // code that is executed repeatedly as long as the condition is true
}
```

JavaScript también tiene un bucle `do-while`.
Aquí la condición se comprueba después de ejecutar el cuerpo del bucle.
Esto es útil cuando la condición depende de evaluaciones realizadas en el cuerpo.

```javascript
do {
  // The code here will always be executed once and then
  // repeatedly while the condition is true.
} while (condition);
```

Dentro del cuerpo de un bucle, puedes usar la palabra clave `break` para detener por completo la ejecución del bucle.
En cambio, la palabra clave `continue` solo detiene la ejecución de la iteración actual y continúa con la siguiente.
Con `continue` puedes evitar a menudo envolver grandes partes del cuerpo del bucle en un condicional.

```javascript
let i = 0;

while (i < 100) {
  i = i + 2;

  if (i % 3 === 0) {
    continue;
  }

  // The code here will only be executed when i was not divisible
  // by 3 in the check above.
}
```

## Sentencias `switch`

Además del condicional, JavaScript también tiene la sentencia `switch` para ejecutar lógica de forma condicional.
Se usa cuando hay que comparar una sola variable con varias alternativas.
La comparación se hace comprobando la igualdad estricta (`===`); consulta [el concepto de comparación][concept-comparison].
Para cierta variable `x`, la sentencia `switch` de JavaScript tiene la siguiente sintaxis.

<!-- prettier-ignore-start -->
```javascript
switch (x) {
  case option1:
    // code that is executed when "x === option1" is true
    break;
  case option2:
    // code that is executed when "x === option2" is true
    break;
  default:
    // code that is executed when x does not equal any of the options
}
```
<!-- prettier-ignore-end -->

El caso `default` es opcional y se usa si quieres ejecutar algo de código cuando ninguna de las otras opciones coincide con la variable.

Las sentencias `break` anteriores son necesarias porque, de forma predeterminada, en JavaScript todos los casos pasan al siguiente.
Eso significa que, sin una sentencia `break`, se ejecutaría todo el código de los casos que hay por debajo de la primera opción que coincida, aunque `x` no coincidiera con esas opciones.
Este comportamiento de paso al siguiente caso de forma predeterminada es una trampa habitual cuando se usa `switch` en JavaScript.
Dentro de una función, también se puede usar `return` en lugar de `break` para evitar este problema.
