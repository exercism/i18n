# Instrucciones

En este ejercicio es el día de San Valentín y tú y tu pareja estáis planeando hacer algo bonito juntos. Tu pareja tiene un montón de ideas y ahora te pide que las valores para encontrar la actividad en la que participar.

Tu pareja propone las siguientes ideas:

- Jugar a un juego de mesa
- Relajarse
- Ver una película
- Ir a un restaurante
- Dar un paseo

Tienes seis tareas para ayudarte a elegir la actividad de San Valentín.

## 1. Define la aprobación

Para cada idea que propone tu pareja, respondes con una de estas tres opciones: sí, no o quizá.

Define el tipo personalizado `Approval` para representar estas opciones con los tres casos siguientes: `Yes`, `No` y `Maybe`.

## 2. Define las cocinas

Tu pareja ha seleccionado dos restaurantes posibles: uno de cocina coreana y otro de cocina turca.

Define el tipo personalizado `Cuisine` para representar estas cocinas con los dos casos siguientes: `Korean` y `Turkish`.

## 3. Define los géneros de películas

Hay muchísimas películas entre las que elegir, así que, para reducir las opciones, tu pareja también indica su género.

Define el tipo personalizado `Genre` para representar los siguientes géneros como casos: `Crime`, `Horror`, `Romance` y `Thriller`.

## 4. Define la actividad

Como ya se ha dicho, a tu pareja se le han ocurrido cinco actividades distintas: jugar a un juego de mesa, relajarse, ver una película, ir a un restaurante y dar un paseo.

Define el tipo personalizado `Activity` para representar estos tipos de actividad:

- `BoardGame`: sin datos asociados.
- `Chill`: sin datos asociados.
- `Movie`: tiene su `Genre` como datos asociados.
- `Restaurant`: tiene su `Cuisine` como datos asociados.
- `Walk`: tiene un `Int` que representa el número de kilómetros que hay que caminar como datos asociados.

## 5. Valora la actividad

Por último, ya estás listo para valorar las ideas de tu pareja. Así es como te sientes respecto a cada idea:

- Jugar a un juego de mesa: no.
- Relajarse: no.
- Ver una película: sí si es una película romántica; si no, no.
- Ir a un restaurante: sí si la cocina es coreana, quizá si es turca.
- Dar un paseo: sí si el paseo es de más de once kilómetros; quizá si es de más de seis kilómetros; si no, no.

Implementa una función llamada `rate_activity` que recibe un valor `Activity` y devuelve el `Approval` según las sensaciones anteriores:

```gleam
rate_activity(Restaurant(Turkish))
// -> Maybe
```
