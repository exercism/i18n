# Instrucciones

En este ejercicio, escribirás algo de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitarás un permiso de conducir, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo de segunda mano.

## 1. Determina si necesitarás un permiso de conducir

Algunos tipos de vehículos requieren un permiso de conducir para conducirlos.
Supón que solo los tipos `'car'` y `'truck'` requieren un permiso; todo lo demás se puede conducir sin permiso.

Implementa la función `needsLicense(kind)`, que recibe el tipo de vehículo y devuelve un valor booleano que indica si necesitas un permiso para ese tipo de vehículo.

```javascript
needsLicense('car');
// => true

needsLicense('bike');
// => false
```

## 2. Elige entre dos posibles vehículos que comprar

Evalúas tus opciones entre los vehículos disponibles.
Consigues reducirlas a dos opciones, pero necesitas ayuda para tomar la decisión final.
Para ello, implementa la función `chooseVehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que aparece primero en orden alfabético.

```javascript
chooseVehicle('Wuling Hongguang', 'Toyota Corolla');
// =>  'Toyota Corolla is clearly the better choice.'

chooseVehicle('Volkswagen Beetle', 'Volkswagen Golf');
// =>  'Volkswagen Beetle is clearly the better choice.'
```

## 3. Calcula una estimación del precio de un vehículo de segunda mano

Ahora que has tomado tu decisión, quieres asegurarte de que te dan un precio justo en el concesionario.
Como te interesa comprar un vehículo de segunda mano, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que si el vehículo tiene menos de 3 años, cuesta el 80% del precio original que tenía cuando era nuevo.
Si tiene más de 10 años, cuesta el 50%.
Si el vehículo tiene al menos 3 años pero no más de 10, cuesta el 70% del precio original.

Implementa la función `calculateResellPrice(originalPrice, age)`, que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en el concesionario.

```javascript
calculateResellPrice(1000, 1);
// => 800

calculateResellPrice(1000, 5);
// => 700

calculateResellPrice(1000, 15);
// => 500
```
