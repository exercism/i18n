# Acerca de

Toda instancia de una estructura o una clase tiene una propiedad implícita llamada `self`, que hace referencia a la propia instancia.
El uso más común de `self` es distinguir entre una propiedad de la instancia y un parámetro que tiene el mismo nombre:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Los tipos de Swift también ofrecen la palabra clave `Self` en mayúscula, que hace referencia al *tipo* de la instancia en lugar de a la propia instancia.
