# Preferir una constante de nivel superior

Considera extraer el número `GIGASECOND` como una constante:

```javascript
const %{name} = %{value}

// the rest of your code below it
export const gigasecond = (...)
```

Solo las funciones, las clases y las constantes que se `export`an son visibles y accesibles desde el exterior. Suele tener sentido dar un nombre a los [números mágicos](https://en.wikipedia.org/wiki/Magic_number_%%28programming%%29), lo que mejora la mantenibilidad. Estas constantes pueden vivir en el mismo archivo sin quedar expuestas a otro código.
