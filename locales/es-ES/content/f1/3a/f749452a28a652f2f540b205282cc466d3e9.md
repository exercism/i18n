# Introducción

## Comparación

### Comparación de números

En `jq` los números se pueden comparar con los siguientes operadores relacionales y de igualdad.

| Comparación            | Operador |
| ---------------------- | -------- |
| Mayor que              | `a > b`  |
| Mayor o igual que      | `a >= b` |
| Menor que              | `a < b`  |
| Menor o igual que      | `a <= b` |
| Igual a                | `a == b` |
| Distinto de            | `a != b` |

El resultado de la comparación siempre es un valor booleano, es decir, `true` o `false`.

```jq
1 < 3,      # => true
2 != 2,     # => false
1 == 1.0    # => true
            # All numbers are floating-points, so this is different syntax
            # for the exact same value.
```

### Comparación de strings

Los operadores de comparación anteriores también se pueden usar para comparar strings.
En ese caso, se aplica un orden de diccionario (lexicográfico).
El orden se basa en el _valor del punto de código Unicode_.

```jq
"Apple" > "Pear",   # => false
"a" < "above",      # => true
"a" == "A"          # => false
```

Debes tener cuidado cuando compares dos variables que parecen contener valores numéricos pero son de tipo string.
Debido al orden de diccionario, el resultado no será el mismo que al comparar valores de tipo número.

```jq
10 < 2,     # => false
"10" < "2"  # => true (because "1" comes before "2")
```

### Igualdad «estricta»

El operador `==` de `jq` es como el `===` de Javascript en el sentido de que dos cosas que «parecen» iguales, pero son de tipos diferentes, no son iguales.

```jq
"3" == 3    # => false
            # the value on the left has type string,
            # the value on the right has type number.
```

### Comparación de arrays

Dos arrays son iguales si todos los elementos correspondientes son iguales.

```jq
[1, 2, 3] == [1, 2, 3]      # => true
[1, 2, 3] == [1, 3, 2]      # => false, different order
[1, 2, 3] == [1, 2, "3"]    # => false, different types
```

### Comparación de objetos

Dos objetos son iguales si tienen los mismos pares clave-valor.

```jq
{name: "Joe", age: 42} == {age: 42, name: "Joe"}                # => true
{name: "Joe", age: 42} == {age: 42, name: "Jane"}               # => false
{name: "Joe", age: 42} == {age: "42", name: "Joe"}              # => false
{name: "Joe", age: 42} == {age: 42, name: "Joe", height: 175}   # => false

# comparisons will drill down as deeply as required
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2]}}}                  # => true
{a: {b: {c: [1, 2]}}} == {a: {b: {c: [1, 2, 3]}}}               # => false
```

## Condicionales

### Expresión if

La **expresión condicional** de `jq` es `if A then B else C end`.

`if-then-else` es un filtro como todas las funciones integradas de `jq`: recibe una entrada y produce una salida.

Si la expresión `A` produce un valor verdadero, el filtro `if` evalúa `B`.
En caso contrario, evalúa `C`.
La entrada del filtro `if` se pasa a `B` o a `C`.

```jq
42 | if . < 50 then "small" else "big" end      # => "small"
```

```jq
5 | if . % 2 == 0 then . / 2 else . * 4 end     # => 20
```

~~~~exercism/note
La cláusula `else` es **opcional**; las dos instrucciones siguientes son equivalentes.

```jq
if A then B else . end
if A then B end
```
~~~~

### Condicionales anidados

Se pueden añadir más condiciones con `elif`.

```jq
42 | if . < 33 then "small"
     elif . < 66 then "medium"
     else "big"
     end
# => "medium"
```

Usa tantas cláusulas `elif` como necesites.

### Veracidad

Los únicos valores «falsos» en `jq` son: `false` y `null`.
Todo lo demás es «verdadero», incluso el número cero y el string vacío, el array vacío y el objeto vacío.

### Operadores booleanos

Los **operadores booleanos** `and` y `or` se pueden usar para construir consultas complejas.

```jq
42 | if . < 33 or . > 66 then "big or small"
     else "medium"
     end
```

Para negar, usa `not`. Es un **filtro**, no un operador.

```jq
42 | if (. < 33 or . > 66 | not) then "medium"
     else "big or small"
     end
```

### Operador de alternativa

El **operador de alternativa** te permite especificar un valor «predeterminado» si una expresión es falsa o nula.

```jq
A // B

# This is identical to
if A then A else B end
```

Para demostrarlo

```jq
[3, 5, 18] | add / 2       # => 13
[]         | add / 2       # => error: null (null) and number (2) cannot be divided
[]         | add // 0 / 2  # => 0
```
