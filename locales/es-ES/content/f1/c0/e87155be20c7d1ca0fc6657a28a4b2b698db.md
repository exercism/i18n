# Acerca de

[Java](https://go.java/index.html) es uno de los lenguajes de programación más populares que hay, gracias a su versatilidad y su compatibilidad.
Se usa ampliamente para el desarrollo de software, las aplicaciones móviles y la creación de sistemas más grandes.

Java nació en 1995 y su mantenimiento corre a cargo de [Oracle](https://www.oracle.com/index.html).
A pesar de no ser tan joven como algunos de los lenguajes más recientes que hay por ahí, Java sigue siendo muy popular.
Se diseñó para ser rápido, seguro, fiable y apto para principiantes, además de muy portable.
Esta ventaja de portabilidad existe porque Java se ejecuta en una [máquina virtual de Java (JVM)](https://en.wikipedia.org/wiki/Java_virtual_machine) compatible con varias plataformas.
Las aplicaciones para Android también se desarrollan con Java, ya que el [sistema operativo Android](<https://en.wikipedia.org/wiki/Android_(operating_system)>) se ejecuta en un entorno del lenguaje Java.

¡La comunidad de Java es enorme!
GitHub, por ejemplo, tiene más de 1,5 millones de proyectos en Java.
También merece la pena mencionar que Java tiene la segunda comunidad más grande en [StackOverflow](https://stackoverflow.com/questions/tagged/java).
Esto es importante porque cuanto más grande es la comunidad de un lenguaje de programación, más apoyo es probable que recibas.

Java también tiene un conjunto potente y bien diseñado de [API (interfaz de programación de aplicaciones)](https://docs.oracle.com/en/java/javase/11/docs/api/index.html) integradas, que se pueden usar para diversas actividades como la conexión a bases de datos, las redes, la E/S, el análisis de XML, las utilidades y mucho más.

Desde los portátiles hasta los centros de datos, desde las consolas de videojuegos hasta los superordenadores científicos, desde los teléfonos móviles hasta Internet, [Java está en todas partes](https://en.wikipedia.org/wiki/Write_once,_run_anywhere).
