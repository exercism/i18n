# Pistas

## General

- Un array de nombres tiene el tipo `ARRAY{STR}`, y un array de números
  `ARRAY{INT}`. Tanto el argumento como, en la tarea 4, la respuesta deben
  indicar cuál de los dos.

## 1. ¿Cuántos hay en la fila?

- `.size`, sin paréntesis después.

## 2. ¿Quién va primero?

- La primera posición es `0`.

## 3. ¿Quién está al final?

- La última posición es una menos que el tamaño, porque se empieza a contar
  desde cero.
- Dedúcelo a partir de `.size` en lugar de escribir `2`. Los tests usan filas
  de varias longitudes diferentes.

## 4. La formación inicial

- La respuesta es un array de strings, por lo que la rutina se declara
  `: ARRAY{STR}`.
- Devuelve un array literal: los tres nombres entre las marcas `|`.

## 5. Cuenta los pasos

- Un total acumulado y un bucle, como en el ejercicio anterior.
- Cuenta una variable de posición desde `0` hacia arriba y termina el bucle
  con `until!(i >= steps.size)`.
- Empezar el total en `0` es lo que hace que la respuesta para una fila vacía
  sea cero sin necesidad de un tratamiento especial.
