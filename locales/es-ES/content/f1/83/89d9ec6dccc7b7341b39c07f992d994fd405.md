# Instrucciones

Un banco con mucha afluencia atiende a los clientes que esperan por *prioridad* en lugar de por orden de llegada. A cada cliente se le asigna un número de prioridad cuando coge un tique, y el cajero siempre atiende a continuación al cliente con el número más bajo (`1` es el más urgente). Un montículo mínimo es la cola de espera perfecta.

## 1. Abre la cola

Define `new-queue`, que no recibe nada y devuelve una cola de prioridad nueva y vacía.

```factor
new-queue
! => an empty priority queue
```

## 2. Añade un cliente

Define `join-queue`, que recibe el nombre de un cliente, un número de prioridad y una cola. Añade el cliente a la cola y devuelve la cola, de modo que se pueden añadir clientes uno tras otro.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
! => the queue, now holding alice (5) and bob (2)
```

## 3. ¿A quién le toca?

Define `next-name`, que recibe una cola y devuelve el nombre del cliente al que hay que atender a continuación, el que tiene el número de prioridad más bajo, *sin* eliminarlo de la cola.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue next-name .
! => "bob"
```

## 4. Atiende a todos

Define `serve-all`, que recibe una cola y devuelve los nombres de todos los clientes en espera, en el orden en que serían atendidos.

```factor
new-queue "alice" 5 rot join-queue "bob" 2 rot join-queue
"carol" 9 rot join-queue serve-all .
! => { "bob" "alice" "carol" }
```
