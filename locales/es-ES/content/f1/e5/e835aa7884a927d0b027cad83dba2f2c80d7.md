# preferir extraer la constante al scope de nivel superior

Plantéate extraer la constante al scope de nivel superior:

```javascript
const %{name} = %{value}

// the rest of your code below it
export %{method.signature}
```

Solo las funciones, las clases y las constantes marcadas con `export` son visibles y accesibles desde fuera.
Estas constantes pueden estar en el mismo archivo sin quedar expuestas a otro código.
Además, extraer constantes ahorra memoria, ya que evita asignaciones repetidas en las funciones cuando esas mismas constantes se reutilizan.
