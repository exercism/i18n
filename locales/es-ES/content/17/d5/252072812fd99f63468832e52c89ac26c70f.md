# Apéndice de instrucciones

## Implementación

Se permite usar características propias del lenguaje para construir y deconstruir arrays mediante desestructuración, así como el literal de array `[]`, pero no se debe usar ninguna función de `Array.prototype`.

Para poder probar tu solución, asegúrate de implementar `forEach`.

```typescript
const list = List.create(1, 2)
list.forEach((item) => console.log(item))
// =>
//    1
//    2
```
