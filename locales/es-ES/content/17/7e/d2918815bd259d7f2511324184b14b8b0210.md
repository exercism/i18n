## API de Roc

Utiliza un valor `React` inmutable. Cada operación devuelve un reactor actualizado; conserva ese valor para las operaciones posteriores. Las celdas se identifican mediante `cell_id`; los callbacks, mediante `callback_id`. Ambos identificadores son strings que se proporcionan cuando se registran. El registro y la eliminación de callbacks reciben ambos identificadores para especificar la celda y su callback.

Una función de cálculo recibe un array de valores de celdas en el mismo orden que su array `inputs` de identificadores de celdas. Devuelve `Ok(value)` si tiene éxito o `Err(message)` con un string que describe un fallo, como un número de entradas incorrecto o una división por cero. Sus dependencias ya deben existir cuando se añade la celda de cálculo. Tanto `add_compute` como `set_value` notifican los errores de cálculo como `ComputeFailed({ cell_id, message })`. Si un cálculo falla durante una actualización, no se devuelve ningún reactor actualizado y no se ejecuta ningún callback; el reactor original sigue siendo utilizable.

Los callbacks son funciones puras de tipo `React.CellValue, React.CallbackLog -> React.CallbackLog`. Cada callback recibe el nuevo valor de la celda y el log actual, y devuelve un log actualizado. `set_value` recibe un registro que contiene `cell_id`, `value` y el `log` inicial, y devuelve tanto el reactor actualizado como el log final. Pasa el log devuelto por cada callback al siguiente; el orden de los callbacks no está especificado.

`React.CallbackLog` es un alias de `Dict(Str, List(I64))`: registra los valores recibidos por cada identificador de callback. Las pruebas pasan un log vacío a cada actualización de entrada para comprobar que los callbacks se ejecutaron exactamente una vez o no se ejecutaron en absoluto.

Registrar un callback no hace que se llame. Eliminar el mismo callback más de una vez está permitido y no debe afectar a los demás callbacks. Todos los callbacks de una actualización deben observar los valores finales y estables de las celdas.
