# Instrucciones

Han contratado a tu empresa para generar registros CSV a partir de la entrada del usuario.

Necesitamos un constructor para un registro CSV según el estándar definido en [RFC 4180](https://tools.ietf.org/html/rfc4180).

Aunque existe una especificación formal, tu empresa solo necesita implementar la siguiente funcionalidad:
- crear un nuevo constructor de registros
- añadir un campo individual al registro
- serializar el registro con un escape básico

El escape básico significa:

- Los campos que contengan saltos de línea, comillas dobles y comas deben ir entre comillas dobles.

- Si se usan comillas dobles para encerrar campos, una comilla doble que aparezca dentro de un campo debe escaparse anteponiéndole otra comilla doble.


## 1. Crear un nuevo constructor

Tendrás que implementar el método `new` para crear un nuevo constructor.

```rust
let mut builder = CsvRecordBuilder::new();
```

## 2. Añadir campos individuales al registro

Tendrás que implementar el método `add` para añadir campos a tu constructor de registros.
`add` recibe como argumento slices de string inmutables, `&str`.

```rust
builder.add("ant");
builder.add("ba\"t");
builder.add("cat");
```


## 3. Serializar el registro con un escape básico

Tendrás que implementar el método `build`.
`build` consume el constructor y devuelve un registro CSV.
```rust
let record = builder.build();
// Note that from now on we cannot use `builder`
assert_eq!(&record, r#"ant,"ba""t",cat"#);
```
