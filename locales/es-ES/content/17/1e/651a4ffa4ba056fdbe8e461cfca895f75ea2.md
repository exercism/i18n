# Introducción

Un `string` de C++ es un objeto mutable que representa texto como una secuencia de caracteres (letras, dígitos, signos de puntuación, etc.).
Las cadenas de caracteres se manipulan llamando a sus métodos.

## La biblioteca de strings

En C++ hay que incluir el tipo string y las funciones asociadas de la biblioteca de strings antes de usarlos.
Puedes hacerlo añadiendo `#include <string>` al principio de tu archivo.
Con ello, pasarán a formar parte del espacio de nombres `std`.
El nombre completo del tipo string es `std::string`.
El literal de string usa el carácter de comillas dobles: `"`.

```cpp
#include <string>
std::string w_berry_quote{"A well-made sentence, I think, is a thing of beauty."};
```

## Operaciones habituales con strings

Puedes usar el operador `+` para concatenar strings:

```cpp
std::string original_title{"The School of Rock"};
std::string sequel_indicator{"Electric Boogaloo"};
std::string next_movie_title = original_title + " 2: " + sequel_indicator;
```

Para usar la biblioteca de strings, tienes que saber que es posible llamar a una función que pertenece a un objeto.
Estas se llaman funciones miembro.
Más adelante, en el temario, aprenderás más sobre las funciones miembro y el concepto de clase relacionado.

```cpp
std::string qualification{"awesome"};
// 1st argument: from the index to the end of the string:
std::string who_is_awesome = qualification.substr(5);
// => "me"

// 2nd optional argument for the length:
std::string material{"haunted books"};
std::string ghost = material.substr(8, 3);
// => "boo"
```


La función `find` también es muy útil.
Se llama como función miembro del string y toma un string como argumento.
`find` devuelve la posición, contando desde cero, de la _primera_ aparición en el string.

```cpp
std::string new_release{"apple released a new app!"};
new_release.find("app");
// => 0
new_release.find("e");
// => 4
```

También existe la función `std::to_string`, que puede usarse para convertir números enteros y valores float/double a string.

```cpp
int num{92};
double exponent{0.92e2};
std::string msg{ std::to_string(num) + " can also be written as " + std::to_string(exponent)};
// => 92 can also be written as 92.0000000
```
