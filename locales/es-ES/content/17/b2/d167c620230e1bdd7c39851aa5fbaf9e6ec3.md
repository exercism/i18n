# Instrucciones

Eres el señalero de un patrullero costero. El zurrón de hoy necesita
cinco palabras cortas listas antes de que empiece la guardia de la
mañana.

## 1. Citar un valor

El cuaderno de bitácora registra cada observación en *forma de código
fuente de Factor*: el mismo texto que el analizador sintáctico volverá
a leer. Define `quote-value` para convertir cualquier valor en su
string de forma de código fuente.

```factor
123 quote-value .   ! => "123"
"hi" quote-value .  ! => "\"hi\""
```

## 2. Quitar el marco de la bandera

Las banderas de señal entrantes llegan enmarcadas con un carácter
marcador en cada extremo. Define `flag-body` para devolver todo lo que
hay *entre* los dos marcadores: descarta el primer carácter y descarta
el último.

Devuelve un slice (una vista) en lugar de copiarlo.

```factor
"#NS-1024#" flag-body .   ! => "NS-1024"
```

## 3. Dividir una bandera

Cada bandera lleva un código de prefijo corto seguido de la carga útil.
Define `split-flag` para tomar una bandera y una longitud de cabecera,
y devolver *tanto* el slice de la cabecera como el slice del cuerpo.

```factor
"NS-1024" 2 split-flag .s
! => "NS"
! => "-1024"
```

## 4. Triangular a partir de dos lecturas

Dos lecturas de señal consecutivas dan tres medidas derivadas: su
*diferencia* `a - b`, su *punto medio* `(a + b) / 2` y su *razón*
`a / b`. Cada medida usa ambas lecturas.

Define `triangulate` para devolver las tres a partir de un par de
lecturas.

```factor
100 50 triangulate .s
! => 50
! => 75
! => 2
```

## 5. Resumir tres lecturas

Tres lecturas consecutivas se resumen en su **suma**, su **producto**
y su **máximo**. Cada estadístico usa las tres lecturas.

Define `triangle-stats` para devolver los tres.

```factor
5 3 8 triangle-stats .s
! => 16
! => 120
! => 8
```
