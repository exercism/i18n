# Instrucciones

Estás trabajando en la implementación de un sistema de monitorización de la salud. Como parte de ello, necesitas hacer un seguimiento de las estadísticas de salud de los usuarios.

Empezarás con algunos métodos esbozados en un bloque `impl`, además de la siguiente definición de `struct`:

```rust
pub struct User {
    name: String,
    age: u32,
    weight: f32,
}
```

Tu objetivo es implementar los métodos esbozados del `struct` `User` definido en el bloque `impl`.

Por ejemplo, el método `new` debería devolver una instancia del `struct` `User` con los valores especificados de nombre, edad y peso.

```rust
let mut bob = User::new(String::from("Bob"), 32, 155.2);
// Returns: a User with name "Bob", age 32, and weight 155.2
```

El método `weight` debería devolver el peso del `User`.

```rust
bob.weight();
// Returns: 155.2
```

El método `set_age` debería establecer la edad del `User`.

```rust
bob.set_age(33);
// Updates Bob's age to 33; happy birthday Bob!
```

¡Diviértete!
