# Introducción

La función `switch()` puede ser un reemplazo conciso de una larga serie de comprobaciones `if` ... `else if`.
La variable sobre la que se hace el `switch` suele ser un string y, en ese caso, las comillas pueden omitirse del selector.

```R
star <- function(type) {
  switch(type,
    M = , # will "fall through" if no value given
    K = "red dwarf",
    G = "Earth-like",
    "bigger star" # only correct for O,B,A,F
  )
}

> star("M")
[1] "red dwarf"
```

Ten en cuenta que las opciones solo pasan a la siguiente si el valor se deja en blanco, como ocurre con `M` en el ejemplo anterior.
No es necesario incluir instrucciones `break`, como sí se hace en otros lenguajes.

Cuando se hace el `switch` sobre tipos `character`, el valor final es un valor por defecto, como aquí.
Con los tipos enteros, no se puede indicar ningún valor por defecto.

## Funciones en `dplyr`

El `switch` de R base es bastante limitado: solo hace una coincidencia exacta con una única entrada.
Esto parecía razonable cuando R se lanzó por primera vez en 1993, pero necesita mejoras para el uso moderno.

~~~~exercism/note
Como se mencionó en el concepto [`Conditionals`][concept-conditionals], la colección de paquetes `tidyverse` está diseñada para complementar (y a veces reemplazar) la funcionalidad de R base sin afectar a la retrocompatibilidad.

Puedes incorporar el paquete `dplyr` al scope añadiendo al principio de tu código `library(dplyr)` (para el paquete individual) o `library(tidyverse)` (para toda la colección).

[concept-conditionals]: https://exercism.org/tracks/r/concepts/conditionals
~~~~

La biblioteca `dplyr` proporciona dos funciones adicionales relacionadas con `switch`.

### Las funciones `recode_values` y `replace_values`

Estas dos funciones relacionadas permiten un mapeo vectorizado, similar a `switch`, de valores antiguos a valores nuevos.

La principal diferencia entre ambas es que `recode_values()` crea un vector completamente nuevo, mientras que `replace_values()` permite actualizaciones parciales de un vector existente.

La coincidencia sigue siendo exacta, pero:

- Las opciones de la izquierda pueden ser vectores, y la entrada coincide si coincide algún elemento.
- Las opciones de la izquierda y los resultados de la derecha se vinculan con una tilde `~` en lugar de `=`.
- En todos los casos se puede especificar un valor por defecto.

```R
library(dplyr)

x <- c("a", "b", "a", "d", "b", NA, "c", "e", "z")
recode_values(
  x,
  "a" ~ 1,
  "b" ~ 2,
  "c" ~ 3,
  c("d", "e") ~ 4, # either "d' or "e" will match
  NA ~ 0,          # matches missing values
  default = 100   # note the different syntax for the default
)
#> [1]   1   2   1   4   2   0   3   4 100
```

### La función `case_when`

`case_when` lleva la sintaxis de `case_match` un paso más allá, ya que permite cualquier expresión lógica a la izquierda del `~`.

El vector de entrada (`x` en el ejemplo siguiente) no se pasa como argumento; simplemente tiene que estar ya definido.

```R
x <- 1:10
case_when(
  x < 3 ~ "low",
  between(x, 3, 5) ~ "mid",
  between(x, 6, 8) ~ "high",
  .default = "what?"
)
#>  [1] "low"   "low"   "mid"   "mid"   "mid"   "high"  "high"  "high"  "what?" "what?"
```

La función `between()` también forma parte de `dplyr`.
