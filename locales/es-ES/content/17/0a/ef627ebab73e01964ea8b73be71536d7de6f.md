# Pistas

## 1. Calcular el valor de cualquier carta.

- El método `Blackjack.parse_card` debe recibir un string (por ejemplo, `"ace"`) y devolver su valor (por ejemplo, 11).
- Define una [instrucción `case`][case] y asigna el valor de la carta como valor del caso.
- King, Queen, Jack y 10 se pueden manejar con un solo caso.
- La instrucción `case` puede tener un caso `else`.
  En cualquier caso, la función debe devolver `0` para las cartas desconocidas.

## 2. Nombrar rangos de valores.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Define una [instrucción `case`][case] y asigna el nombre del rango como valor del caso.
- La instrucción `case` puede usar objetos [`Range`][range] como casos para comprobar si un valor está dentro de un rango.

## 3. Implementar la lógica de decisión del primer turno.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Puedes usar una gran [instrucción `case`][case] sobre la puntuación del jugador (quizá con condicionales `if` anidados sobre la puntuación del crupier en algunos casos),
- o puedes distinguir distintas categorías de puntuación del jugador (digamos «manos pequeñas» con una puntuación inferior a 12, «manos medianas» con una puntuación en el rango 12..20 y «manos grandes» con una puntuación superior a 20) y escribir funciones independientes para todas (o algunas) de estas categorías.

[case]: https://www.rubyguides.com/2015/10/ruby-case/
[range]: https://docs.ruby-lang.org/en/master/Range.html
