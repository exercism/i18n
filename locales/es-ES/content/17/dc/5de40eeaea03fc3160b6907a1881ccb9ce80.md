# Instrucciones

En este ejercicio trabajas en una pizzería que reparte a domicilio.

Ofreces tres tipos de pizzas:

- Margherita: \$7
- Caprese: \$9
- Formaggio: \$10

Los clientes también pueden elegir dos opciones adicionales por un pequeño suplemento:

1. Salsa extra: \$1
1. Ingredientes extra: \$2

Cuando los clientes hacen un pedido, se añade un suplemento si solo piden una o dos pizzas:

- 1 pizza: \$3
- 2 pizzas: \$2

Tienes tres tareas, y cada una de ellas trabajará con pizzas y su precio.

## 1. Define los tipos de pizza y las opciones

Define el tipo personalizado `Pizza` para representar los distintos tipos de pizzas y de opciones:

- `Margherita`
- `Caprese`
- `Formaggio`
- `ExtraSauce`
- `ExtraToppings`

`ExtraSauce` y `ExtraToppings` deben envolver el tipo `Pizza`.

## 2. Calcula el precio de una pizza

Implementa la función `pizza_price` para calcular el precio de una pizza:

```gleam
pizza_price(Caprese)
// -> 9
```

## 3. Calcula el precio de un pedido

Implementa la función `order_price` para calcular el precio de un pedido de pizzas:

```gleam
order_price([Margherita, Formaggio])
// -> 19
```
