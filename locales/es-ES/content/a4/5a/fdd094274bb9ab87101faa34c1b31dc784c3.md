# Null

Null es un tipo de valor primitivo con un único valor: `null`.
Null se usa a menudo para representar la nada.
Se considera «falsey», pero es distinto de `false` y de otros valores falsey.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabajar con valores null

En PHP, los valores null pueden ser una causa habitual de errores, ya que a menudo se devuelven en lugar de un estado de error o para representar la nada.
Evitar que surjan errores suele requerir una «comprobación de null» para asegurarse de que el valor no es null antes de operar con él.

```php
<?php

$value = null;

$value->doSomething(); // throws an error as a null value is not an object instance.

if (!is_null($value)) {
    $value->doSomething(); // succeeds
}
```

Comprobar repetidamente si un valor es null puede ser propenso a errores, por lo que PHP ofrece dos operadores para trabajar con valores null: el operador de acceso seguro para null `?->` y el operador de coalescencia `??`.

```php
<?php

$value = null;
$result = $value?->doSomething(); // => return null rather than error
$result = $result ?? "default"; // => "default" is assigned to $result
```
