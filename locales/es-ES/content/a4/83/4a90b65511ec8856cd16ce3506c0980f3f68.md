# Introducción

En Clojure, vincular un valor a un nombre se conoce como _var_. Las vars de nivel superior (globales) son similares a las constantes de otros lenguajes, pero es habitual redefinirlas para facilitar el desarrollo dinámico.

Las vars de nivel superior se definen con `def`:

```clojure
(def fingers 10)
```

La macro `defn` sirve para definir una función que recibe cero o más argumentos. Una función siempre devuelve el resultado de la última expresión de su cuerpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para llamar a una función, se indica su nombre y se pasan argumentos para cada uno de los parámetros de la función.

```clojure
(def five (add 2 3))
```

Las funciones y los valores en Clojure solo se pueden usar _después_ de haber sido definidos. Usarlos antes de que se hayan definido provoca un error de compilación.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

En Clojure, los espacios en blanco no tienen ninguna relevancia más allá del formato.

Las funciones y las vars de Clojure se organizan en namespaces. Un namespace agrupa funcionalidad relacionada y se define con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos de `;`, y la forma `comment` se usa para evitar la evaluación de todo lo que hay entre `(comment` y `)`.
