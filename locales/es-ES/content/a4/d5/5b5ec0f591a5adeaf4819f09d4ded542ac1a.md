# Instrucciones

Este problema está inspirado en la planificación estática no apropiativa de los sistemas operativos de tiempo real, pero también es similar al problema de planificación de taller (Job-Shop Scheduling Problem, JSP) con un solo recurso. Este problema asume que todas las tareas se conocen de forma estática. En otras palabras, los tiempos de liberación de todas las tareas de este problema se conocen al principio del programa. En la práctica, los tiempos de liberación de las tareas no se conocen al inicio de un programa y pueden generarse en cualquier momento mediante E/S, interrupciones, etc.

Dada una lista de tareas con parámetros, determina una planificación en la que las tareas puedan ejecutarse de forma secuencial y sin solaparse. Como el problema está inspirado en la planificación de procesos de un RTOS, asumiremos que se necesita un tiempo distinto de cero entre tareas, también conocido como la sobrecarga de cambio de contexto. Hay dos tipos diferentes de tareas: periódicas y dinámicas. Ambos tipos tienen un parámetro de ID de tarea, que es una cadena que se usa para diferenciar entre las distintas tareas de la lista.

Una **tarea periódica** se define como una tarea que se ejecuta periódicamente. En otras palabras, la tarea se ejecutará una vez cada T segundos, donde T se define como el periodo.
Una tarea periódica se define mediante los siguientes parámetros:
* Tiempo de inicio: momento en que comienza la primera repetición, o instancia, de la tarea
* Periodo: tiempo entre el inicio de las repeticiones de la tarea
* Tiempo de ejecución: tiempo que se ejecuta cada repetición
* Tiempo de fin: momento en que la tarea deja por completo de planificarse

Una **tarea dinámica** se define como una tarea que solo se ejecuta una vez.
Una tarea dinámica se define mediante los siguientes parámetros:
* Tiempo de liberación: primera vez que la tarea PUEDE planificarse (NO es lo mismo que el tiempo de inicio)
* Tiempo de ejecución: tiempo que se ejecuta la tarea
* Fecha límite: momento en el que la tarea debe terminar su ejecución

Hay dos entradas para la función que hay que implementar. La primera entrada es una lista de instancias de `RealTimeTask`. Las instancias de `RealTimeTask` se darán como entrada como una instancia de `PeriodicRealTimeTask` o `DynamicRealTimeTask`, con todos los parámetros de la tarea como enteros.
La función integrada `isinstance()` de Python se puede usar para diferenciar entre los dos tipos de tarea de la lista. El orden de la lista es irrelevante; fíjate solo en los parámetros de las tareas.
La segunda entrada es un único entero que especifica la sobrecarga de cambio de contexto. La sobrecarga de cambio de contexto siempre será un entero no negativo.

La salida debe ser un diccionario cuyas claves sean el ID de tarea de las instancias de `RealTimeTask`, y cuyo valor sea una lista de tuplas de dos elementos. El formato de las tuplas de dos elementos es (tiempo de inicio, tiempo de fin). Las tareas dinámicas solo deben contener una tupla de dos elementos en la lista, mientras que las tareas periódicas pueden contener más de una. El orden de las tuplas de dos elementos en la lista es indiferente. Si no se puede crear una planificación válida a partir de la lista de tareas con la sobrecarga de cambio de contexto dada, lanza una excepción `NoRtosStaticScheduleProducible`. Ten en cuenta que los resultados del modelo Z3 para las variables deberán convertirse a enteros antes de mostrarse. Si el resultado del modelo Z3 es de tipo `IntNumRef`, se puede usar el método de clase `as_long()` para convertirlo en un entero.

Se proporciona una función adicional para permitir al usuario visualizar el orden secuencial de las tareas. Esta función también se puede habilitar para casos de prueba individuales estableciendo el argumento de palabra clave `plot` en `True` en la función `check()`. Se usa un gráfico de barras horizontales discontinuas para representar y etiquetar cada tarea. Para utilizar esta función, debe estar instalada la biblioteca de Python *matplotlib*. Los detalles de instalación de *matplotlib* se pueden encontrar [aquí](https://matplotlib.org/stable/users/installing.html).
