## Alias de tipos

En Gleam, un alias de tipo puede usarse para dar un nombre conveniente a un tipo existente que, de otro modo, resultaría engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias puede usarse fuera del módulo en el que se define. Si se omite `pub`, el alias es privado y no puede referenciarse desde otros módulos.
