# camelCase

[comment]: # "requiere 2 parámetros:"
[comment]: # "- incorrecto: nombre con las mayúsculas y minúsculas incorrectas"
[comment]: # "- correcto: nombre con las mayúsculas y minúsculas correctas"

La comunidad de Elm prefiere claramente usar camelCase para los nombres de variables y PascalCase para los tipos.

Hemos encontrado el nombre `%{wrong}`, que debería sustituirse por `%{correct}`.
