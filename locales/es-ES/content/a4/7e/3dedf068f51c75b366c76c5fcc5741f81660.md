# Acerca de

La [sobrecarga de métodos][method-overloading] es un concepto clave en Java, ya que permite que una clase tenga más de un método con el mismo nombre, siempre que cada método tenga una lista de parámetros distinta.
Esta característica es un aspecto fundamental de la programación orientada a objetos de Java y ofrece una forma de realizar operaciones similares con distintos tipos o cantidades de entradas.
La sobrecarga de métodos mejora la legibilidad y la organización del código al permitir que métodos que realizan operaciones similares compartan el mismo nombre.
Es importante señalar que la sobrecarga se determina por la firma del método, que incluye el nombre del método y la lista de parámetros.

## Puntos clave

- **La firma importa**: el tipo devuelto no forma parte de la firma del método, así que cambiar solo el tipo devuelto de un método no constituye una sobrecarga.
- **Diferencias entre parámetros**: los métodos sobrecargados deben diferenciarse en el número o el tipo de parámetros.
- **Uso**: la sobrecarga se usa a menudo para ofrecer formas más intuitivas de usar un método con distintos tipos de entradas.

## Ejemplos de sobrecarga de métodos

Imagina una clase `Calculator` que puede sumar números.
La sobrecarga permite distintos tipos de operaciones de suma:

```java
public class Calculator {

    public int add(int a, int b) {
        return a + b;
    }

    public double add(double a, double b) {
        return a + b;
    }

    public int add(int a, int b, int c) {
        return a + b + c;
    }
}
```

## Buenas prácticas

- **Claridad**: los métodos sobrecargados deben usarse de forma que hagan el código más intuitivo.
  - El comportamiento de los métodos sobrecargados debe estar relacionado y ser coherente.
- **Evitar la ambigüedad**: asegúrate de que cada método sobrecargado tenga un propósito claro y de que las diferencias entre las listas de parámetros sean lo bastante significativas como para evitar confusiones.
- **Documentación**: documenta adecuadamente cada versión de los métodos sobrecargados.
  - Una documentación clara ayuda a otros desarrolladores a entender el propósito y el uso de cada variante del método.
- **Tipos devueltos coherentes**: aunque los tipos devueltos pueden variar en los métodos sobrecargados, por lo general es buena práctica mantenerlos coherentes siempre que sea posible para evitar confusiones.
- **Limitar la sobrecarga**: evita abusar de la sobrecarga de métodos.
  - El exceso de sobrecarga puede hacer que el código sea más difícil de leer y de mantener.

## Conclusión

La sobrecarga de métodos es una característica muy potente de Java que, bien utilizada, puede mejorar enormemente la legibilidad y la flexibilidad de tu código.
Permite que los métodos sean más versátiles y se adapten a distintos contextos, lo que hace que tus programas de Java sean más modulares y fáciles de mantener.
