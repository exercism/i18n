# Pistas

## General

- Hay tres operadores lógicos '!`(logical NOT), '||` (OR lógico) y `&&` (AND lógico) cuando se trabaja con valores Boolean.
- Se pueden combinar varios operadores en una sola expresión.

## 1. Comprobar si se puede hacer un ataque rápido

- El operador NOT lógico (`!`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprobar si se puede espiar al grupo

- Los operadores lógicos se suelen usar para evaluar si dos o más expresiones son verdaderas o no lo son.

## 3. Comprobar si se puede hacer señales al prisionero

- Los operadores lógicos se ejecutan en el orden de su precedencia (de mayor a menor): `!`, `&&`, `||`.
