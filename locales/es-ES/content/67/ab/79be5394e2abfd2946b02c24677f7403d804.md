# Acerca de

Elm es un lenguaje totalmente funcional, así que no hay instrucciones, solo expresiones, y las funciones son siempre una única expresión.

Esto fomenta funciones pequeñas y sencillas, y en general es algo bueno, pero a veces las funciones son inevitablemente más complejas y necesitamos una forma de asegurarnos de que se puedan escribir de manera elegante.

Aquí es donde entran en juego las expresiones `let`. Tienen dos partes: una sección `let`, donde puedes crear tantas definiciones como necesites, y luego una sección `in`, que es una única expresión que puede usar esas definiciones.

En términos informáticos, `let` crea un scope local a la expresión que hay en `in`.

La expresión `let` es útil en varias situaciones:

- Para simplificar expresiones
- Para dar nombre a los resultados de expresiones intermedias
- Para dividir una expresión en trozos más pequeños si se está volviendo demasiado grande

Puedes hacer casi cualquier cosa dentro de una expresión `let`, incluida la desestructuración; sin embargo, lo siguiente no está permitido:

- Tipos personalizados
- Alias de tipo
- Sombreado de nombres (no puedes redefinir / reutilizar un nombre que ya está en el scope)

## Simplificar expresiones

Esta expresión suma los cubos de tres números, pero es difícil de leer, y sería fácil que el cálculo fuese distinto para cada número.

```elm
(a * a * a) + (b * b * b) + (c * c * c)
```

Podemos definir una función `cube` en una expresión `let` para que el cálculo sea más sencillo, más expresivo y más seguro. Esta función podría tener una anotación de tipo, pero en el código Elm idiomático esto es relativamente poco frecuente.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

## Dar nombre a los resultados de expresiones intermedias

Este código define sideArea y topArea para que el cálculo sea más sencillo y más expresivo.

```elm
cylinderArea : Float -> Float -> Float
cylinderArea radius height =
    let
        sideArea = 2 * pi * radius * height
        topArea = pi * radius ^2
    in
        sideArea + 2 * topArea
```

## Dividir una expresión grande

Este código crea un patrón inicial para el [Juego de la vida](https://playgameoflife.com/) (un ejercicio de ejemplo muy habitual en programación).

No es importante entender exactamente cómo funciona, pero seguramente sea evidente que sería muy grande si se escribiera como una única expresión, sin `let`.

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
