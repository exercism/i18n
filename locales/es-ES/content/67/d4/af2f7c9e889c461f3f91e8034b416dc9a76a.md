# Introducción

Muchos tipos de miembros de struct y de clase (los campos son la principal excepción) pueden usar la sintaxis de miembro con cuerpo de expresión. Definir un miembro con una expresión suele producir código más conciso y legible que los bloques o las instrucciones tradicionales.

Los métodos y las propiedades de solo lectura se encuentran entre los miembros que se pueden definir con cuerpos de expresión.

```csharp
public int Times3(int input) => input * 3;

public int Interesting => 1729;
```
