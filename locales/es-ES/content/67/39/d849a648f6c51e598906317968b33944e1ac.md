# Pistas

## 1. Determina cuánto tiempo se tarda en preparar un pedido

- Puedes usar un [bucle `for-in`][for-in-loops] para examinar una bebida a la vez.
- Puedes usar una instrucción `switch` para devolver el tiempo que se tarda en preparar cada tipo de bebida.

## 2. Repón tu suministro de gajos de lima

- Los [arrays tienen un método][array-docs] para eliminar el primer elemento de un array y devolvértelo.
- Tienes que hacer una copia en una variable de los parámetros de la función si quieres modificarlos.

## 3. Termina tu turno

- Si sabemos que todavía nos queda tiempo en el turno, sabemos que tendremos que preparar al menos un pedido.
    Esto es un buen indicio de que un [bucle `repeat-while`][repeat-loops] sería una buena opción.
- Los [arrays tienen un método][array-docs] para eliminar el primer elemento de un array y devolvértelo.

## 4. Haz un seguimiento de ciertos pedidos

- Puedes usar un [bucle `for-in`][for-in-loops] para trabajar en cada pedido de uno en uno.
- Puedes usar la descomposición de tuplas para dar nombre a los elementos individuales de la tupla en el bucle `for-in`.
- Puedes usar las [instrucciones de transferencia de control][control-transfer] para saltar a la siguiente iteración del bucle en las bebidas que no nos interesan.
