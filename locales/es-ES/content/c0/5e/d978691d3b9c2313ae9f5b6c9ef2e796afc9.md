# Consejos

## General

- Las [tuplas][tuple] son estructuras de datos inmutables, de tamaño fijo, y pueden contener cualquier tipo de dato.
- Los símbolos se pueden usar para denotar estados finitos: este ejercicio usa `:cup`, `:fluid_ounce`, `:teaspoon`, `:tablespoon` y `:milliliter` para denotar las unidades utilizadas.

## 1. Obtén el componente numérico de un par de volumen

- Considera indexar la tupla para devolver el componente numérico del par de volumen.

## 2. Convierte el par de volumen a mililitros

- Usa lógica de control de flujo para determinar qué lógica aplicar en función de la unidad.
- Implementa el método para convertir todas las unidades a mililitros, incluida la conversión de mililitros a mililitros.

## 3. Convierte el par de volumen en mililitros a otra unidad

- Usa lógica de control de flujo para determinar qué lógica aplicar en función de la unidad.
- Implementa el método para convertir mililitros a todas las unidades, incluida la conversión de mililitros a mililitros.

## 4. Convierte de cualquier unidad a cualquier unidad

- Reutiliza los métodos que ya has creado para realizar la conversión en el método `KitchenCalculator.convert`.
