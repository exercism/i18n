# Tests

## Clojure CLI

Los ejercicios de Clojure en Exercism incluyen un fichero `deps.edn` con un alias `:test` para invocar el [test-runner de cognitect-labs](https://github.com/cognitect-labs/test-runner):

``` bash
$ clj -X:test
```

Esto examinará el directorio `test` de tu proyecto en busca de los tests definidos con `clojure.test` y los ejecutará.

## Leiningen

Para ejecutar los tests de un ejercicio con Leiningen, basta con llamar a:

``` bash
$ lein test

lein test bob-test

Ran 14 tests containing 14 assertions.
0 failures, 0 errors.
```
