# Introducción

Un fichero no es más que un flujo con un nombre en el disco. El vocabulario [`io.files`][io.files] te ofrece dos formas de trabajar con él: palabras de conveniencia para ficheros completos, que leen o escriben todo en una sola llamada, y aperturas de flujo para cuando quieres leer o escribir de forma incremental.

Toda palabra que toca un fichero recibe una **codificación**, el esquema que convierte bytes en caracteres y viceversa. Para el texto, casi siempre es [`utf8`][utf8] de `io.encodings.utf8`.

## Leer un fichero completo

```
file-contents   ( path encoding -- str )
file-lines      ( path encoding -- seq )
```

`file-contents` devuelve el fichero entero como un solo string; `file-lines` devuelve un array con sus líneas, sin los saltos de línea.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents

"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"

"forecast.txt" utf8 file-lines .
! => { "sunny" "cloudy" }
```

## Escribir un fichero completo

```
set-file-contents   ( str path encoding -- )
set-file-lines      ( seq path encoding -- )
```

Ambas **reemplazan** el contenido del fichero (y lo crean si hace falta). `set-file-contents` escribe un string tal cual; `set-file-lines` escribe cada elemento de una secuencia en su propia línea y añade los saltos de línea por ti.

```factor
USING: io.encodings.utf8 io.files prettyprint ;

{ "sunny" "cloudy" } "forecast.txt" utf8 set-file-lines
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\n"
```

## Añadir a un fichero

Para añadir contenido a un fichero sin borrar lo que ya hay, ábrelo con un combinador `with-…` y escribe en el flujo ambiente dentro de la cita:

```
with-file-appender   ( path encoding quot -- )
with-file-reader     ( path encoding quot -- )
with-file-writer     ( path encoding quot -- )
```

```factor
USING: io io.encodings.utf8 io.files prettyprint ;

"sunny\ncloudy\n" "forecast.txt" utf8 set-file-contents
"forecast.txt" utf8 [ "rainy" print ] with-file-appender
"forecast.txt" utf8 file-contents .
! => "sunny\ncloudy\nrainy\n"
```

Como todo combinador `with-…`, estos son scopes de destructor: el descriptor del fichero se cierra cuando termina la cita, incluso si lanza una excepción.
