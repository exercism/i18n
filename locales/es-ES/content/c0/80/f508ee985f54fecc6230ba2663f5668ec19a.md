# Pistas

## General

- Echa un vistazo a la [documentación de `elm/parser`][elm-parser]
- La introducción presenta todos los conceptos necesarios para resolver el ejercicio

## 1. Analizar el precio de la pizza

- El [parser `int`][int] está pensado para analizar números enteros
- Más de un parser puede gestionar €, pero [`symbol`][symbol] es el más apropiado
- El [operador `(|.)`][(|.)] puede analizar dos cosas pero conservar solo una

## 2. Analizar el indicador de vegetariano

- El [parser `oneOf`][oneOf] puede probar distintas posibilidades
- Hay más de una forma de analizar un string concreto; en este caso, [`keyword`][keyword] o [`symbol`][symbol] son apropiados
- Hay más de una forma de devolver `True` cuando un parser tiene éxito; una buena es usar [`succeed`][succeed]

## 3. Analizar nombres de pizzas e ingredientes

- El [parser `chompWhile`][chompWhile] está pensado para analizar caracteres arbitrarios
- La [función `isAlpha`][isAlpha] puede validar caracteres ASCII en mayúscula y en minúscula
- La [función `map`][map] se puede usar para modificar el contenido de un parser
- La [función `String.toLower`][toLower] puede convertir un string a minúsculas

## 4. Analizar un array de ingredientes

- El [parser `sequence`][sequence] está pensado para analizar arrays de elementos
- Usa todas las funciones apropiadas que hayas definido hasta ahora

## 5. Analizar una pizza completa

- Con el [operador `(|=)`][(|=)] es bastante sencillo conservar más de una cosa en un pipeline
- Usa `Pizza` como constructor de tipo con [`succeed`][succeed]
- Más de un parser puede gestionar «:» y «-», pero [`symbol`][symbol] es el más apropiado
- El [parser `spaces`][spaces] resulta útil para deshacerse de los espacios sobrantes
- Usa todas las funciones apropiadas que hayas definido hasta ahora

## 6. Analizar un menú completo

- El [parser `sequence`][sequence] está pensado para analizar arrays de elementos
- Recuerda que `spaces` también consume caracteres de nueva línea; esto podría interferir con tu separador
- El [parser `end`][end] está pensado para comprobar que has llegado al final de un string
- El [operador `(|.)`][(|.)] puede analizar dos cosas pero conservar solo una
- Usa todas las funciones apropiadas que hayas definido hasta ahora

## 7. Analizar nombres de ingredientes de varias palabras

- El [parser `chompWhile`][chompWhile] está pensado para analizar caracteres arbitrarios
- La [función `isAlpha`][isAlpha] puede validar caracteres ASCII en mayúscula y en minúscula
- La [función `andThen`][andThen] se puede usar para inspeccionar el contenido de un parser
- La [función `problem`][problem] devuelve un parser que ha llegado a un punto muerto
- La [función `String.toLower`][toLower] puede convertir un string a minúsculas
- La [función `String.trim`][trim] puede deshacerse de los espacios en blanco de los extremos de un string
