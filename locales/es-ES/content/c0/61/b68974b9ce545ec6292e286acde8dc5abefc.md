# Introducción

Cada instancia de una estructura o una clase tiene una propiedad implícita llamada `self`, que hace referencia a la propia instancia.
El uso más habitual de `self` es distinguir entre una propiedad de instancia y un parámetro que tiene el mismo nombre:

```swift
struct Position {
    var x = 0

    mutating func move(x: Int) {
        // Here, 'self.x' refers to the struct's property,
        // while 'x' refers to the parameter passed to the method.
        self.x = x
    }
}
```

Los tipos de Swift también ofrecen la palabra clave `Self`, escrita con mayúscula inicial, que hace referencia al *tipo* de la instancia y no a la propia instancia.
