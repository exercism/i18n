# Anexo de instrucciones

## Gestión de errores

Para este ejercicio debes añadir un conjunto de errores `ComputationError` que contenga el error `IllegalArgument`.
¡Recuerda hacerlo público!
La función `steps` debe devolver `ComputationError.IllegalArgument` cuando su entrada sea igual a cero.

Normalmente, los ejercicios posteriores omitirán instrucciones explícitas como esta.
En general, Exercism espera que leas el fichero de test al implementar tu solución.

Para obtener más detalles sobre los errores en Zig, consulta:
