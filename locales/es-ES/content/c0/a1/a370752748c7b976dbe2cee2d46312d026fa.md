# Acerca de

Ceylon es un lenguaje de programación de propósito general cuya sintaxis es similar a la de Java y C#.
Es imperativo, de tipado estático, estructurado en bloques, orientado a objetos y de orden superior.
Por _de tipado estático_ queremos decir que el compilador realiza una exhaustiva comprobación de tipos,
con la ayuda de las anotaciones de tipo que aparecen en el código. Por _orientado a objetos_,
queremos decir que el lenguaje admite tipos definidos por el usuario y cuenta con un sistema de tipos
nominativo en el que un tipo es un conjunto de atributos y operaciones con nombre, y que admite
herencia y polimorfismo de subtipos. Por _de orden superior_, queremos decir que todo elemento
del programa al que se puede hacer referencia (todo atributo, toda operación y todo tipo) también
es un valor. Por _estructurado en bloques_, queremos decir que el lenguaje cuenta con ámbito
léxico y una sintaxis recursiva extremadamente regular para declaraciones e instrucciones.

Ceylon mejora el lenguaje y el sistema de tipos de Java para reducir la verbosidad y aumentar
la seguridad de tipos en comparación con Java y C#. Ceylon fomenta un estilo de programación
más funcional y algo menos imperativo, lo que da como resultado un código más fácil de
razonar y de refactorizar.
