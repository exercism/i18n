# Acerca de

El `<iota>` de Factor produce una secuencia *virtual* de los números
enteros `0, 1, …, n-1`. Recorrerla con `map` da como resultado una
secuencia tabulada en la que cada elemento es una función de su
posición:

```factor
USING: math sequences ;

5 <iota> [ sq ] map .         ! => { 0 1 4 9 16 }
8 <iota> [ 1 + ] map .        ! => { 1 2 3 4 5 6 7 8 }
```

Hay dos elementos que te permiten convertir una secuencia de códigos
enteros en un string:

| word      | role                                                    |
|-----------|---------------------------------------------------------|
| `CHAR:`   | literal en tiempo de análisis que apila el punto de código de un carácter |
| `>string` | convierte una secuencia de puntos de código en un string |

Combinados, forman el modismo habitual para construir una fila de
caracteres indexada por su posición:

```factor
USING: kernel math sequences strings ;

10 <iota> [ 2 mod zero? [ CHAR: O ] [ CHAR: . ] if ] map >string .
! => "O.O.O.O.O."
```

Elegir el carácter con `if` (o `?`) dentro de la quotation mantiene
la decisión de cada posición cerca del índice del que depende.
