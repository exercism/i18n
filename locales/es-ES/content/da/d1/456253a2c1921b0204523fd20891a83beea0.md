# Anexo de instrucciones

## Notas de implementación

El conjunto de pruebas pasa una instancia de la clase Function a los métodos `keep` y `discard` como [argumento de bloque][block-argument].
Para pasar las pruebas correctamente, tendrás que llamar a esa función dentro de tu código.
Si no sabes cómo hacerlo, consulta la [documentación de la clase Function][function-class].

[block-argument]: https://wren.io/functions.html#block-arguments
[function-class]: https://wren.io/modules/core/fn.html
