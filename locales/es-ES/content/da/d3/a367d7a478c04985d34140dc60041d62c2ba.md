# Instrucciones

En este ejercicio vas a escribir algo más de código relacionado con la preparación y el cocinado de tu magnífica lasaña de tu libro de recetas favorito.

Tienes cuatro tareas.
La primera está relacionada con el cocinado en sí, y las otras tres tratan sobre la preparación perfecta.

## 1. Calcula el tiempo de preparación

Para la próxima lasaña que prepares, quieres asegurarte de reservar tiempo suficiente para poder disfrutar del cocinado.
Ya has planificado qué capas tendrá tu lasaña.
Ahora quieres estimar cuánto tardará la preparación en función de eso.

Implementa una función `PreparationTime` que acepte un slice de capas como un `[]string` y el tiempo medio de preparación por capa en minutos como un `int`.
La función debe devolver la estimación del tiempo total de preparación en función del número de capas como un `int`.
Go no tiene valores por defecto para las funciones.
Si el tiempo medio de preparación se pasa como `0` (el valor inicial por defecto de un `int`), debe usarse el valor por defecto de `2`.

```go
layers := []string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"}
PreparationTime(layers, 3)
// => 18
PreparationTime(layers, 0)
// => 12
```

## 2. Calcula las cantidades de fideos y salsa necesarias

Además de reservar el tiempo, también quieres asegurarte de tener suficiente salsa y fideos para cocinar la lasaña de tus sueños.
Por cada capa de fideos de tu lasaña, necesitarás 50 gramos de fideos.
Por cada capa de salsa de tu lasaña, necesitarás 0,2 litros de salsa.

Define la función `Quantities` que toma un slice de capas como parámetro como un `[]string`.
La función determinará entonces la cantidad de fideos y salsa necesarios para preparar tu comida.
El resultado debe devolverse como dos valores: `noodles` como un `int` y `sauce` como un `float64`.

```go
Quantities([]string{"sauce", "noodles", "sauce", "meat", "mozzarella", "noodles"})
// => 100, 0.4
```

## 3. Añade el ingrediente secreto

Hace un tiempo visitaste a un amigo y comiste lasaña en su casa.
Estaba increíble y tenía algo especial.
Tu amigo te envió la lista de ingredientes y te dijo que el último elemento de la lista es el «ingrediente secreto» que hizo que la comida fuera tan especial.
Ahora quieres añadir ese ingrediente secreto también a tu receta.

Escribe una función `AddSecretIngredient` que acepte dos slices de ingredientes de tipo `[]string` como parámetros.
El primer parámetro es la lista que te envió tu amigo, y el segundo es la lista de ingredientes de tu propia receta.
El último elemento de tu lista de ingredientes siempre es `"?"`.
La función debe reemplazarlo por el último elemento de la lista de tu amigo.
**Nota:** `AddSecretIngredient` no devuelve nada; debes modificar la lista de tus ingredientes directamente.
La lista con los ingredientes de tu amigo **no** debe modificarse.
Además, como el `slice` se pasa a una función como punteros, los cambios en los dos argumentos `[]string` que se pasan a `AddSecretIngredient` se modificarán directamente.

```go
friendsList := []string{"noodles", "sauce", "mozzarella", "kampot pepper"}
myList := []string{"noodles", "meat", "sauce", "mozzarella","?"}

AddSecretIngredient(friendsList, myList)
// myList => []string{"noodles", "meat", "sauce", "mozzarella", "kampot pepper"}
```

## 4. Escala la receta

Las cantidades que figuran en tu libro de cocina solo dan para una lasaña de dos porciones.
Como la próxima vez quieres cocinar para más personas, quieres calcular las cantidades para distintos números de porciones.

Implementa una función `ScaleRecipe` que tome dos parámetros.

- Un slice de cantidades `float64` necesarias para 2 porciones.
- El número de porciones que quieres cocinar.

La función debe devolver un slice de `float64` con las cantidades necesarias para el número de porciones deseado.
Sin embargo, quieres conservar la receta original.
Esto significa que el argumento `quantities` no debe modificarse en esta función.

```go
quantities := []float64{ 1.2, 3.6, 10.5 }
scaledQuantities := ScaleRecipe(quantities, 4)
// => []float64{ 2.4, 7.2, 21 }
```
