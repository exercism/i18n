# Instalación

Necesitarás acceso a una base de datos Oracle montada. Si aún no tienes una instalada, aquí tienes algunas opciones:
* consigue un espacio de trabajo gratuito en https://apex.oracle.com
* descarga VirtualBox de Oracle y ejecuta una de las imágenes disponibles gratuitamente; en el momento de escribir esto, la más sencilla para empezar podría ser _Database App Development VM_. La imagen es bastante grande...
* descarga e instala una versión de la propia base de datos Oracle. Las licencias de desarrollador son gratuitas.
