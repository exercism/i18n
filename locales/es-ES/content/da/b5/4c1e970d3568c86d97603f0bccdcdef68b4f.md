# Break y continue

Al usar una estructura de control de bucle o iteración, las palabras clave `break` y `continue` pueden ayudar a controlar el flujo de un programa.
La palabra clave `break` sale del contexto del bucle al scope externo, terminando así el bucle.
La palabra clave `continue` omite el resto de la iteración actual y reinicia el contexto del bucle al principio de la siguiente iteración.
Aunque no es habitual, se puede proporcionar un número junto con la palabra clave para controlar de cuántos contextos salir o a cuántas iteraciones saltar.

```php
<?php
$i = 1;
while ($i <= 10) {

    if ($i <= 5) {
        i += 1;
        continue;
    }
    break;
}
```

En el ejemplo anterior, `continue` se ejecuta cinco (5) veces, pero en la sexta (6) iteración se ejecuta `break`, lo que hace que el código salga del bucle.
