# Introducción

Una función en Cairo te permite agrupar código en una unidad reutilizable, lo que hace que tus programas sean más modulares y fáciles de entender.
Las funciones en Cairo se componen de la palabra clave `fn`, seguida del nombre de la función, una lista de parámetros entre paréntesis y un bloque de código que define qué hace la función.

## Parámetros de función

En Cairo, todos los parámetros de una función deben tener un tipo explícito.
A diferencia de otros lenguajes, Cairo no infiere los tipos y no existen valores predeterminados para los parámetros, por lo que todos los parámetros son obligatorios.

```rust
// Function with no parameters
fn print_hello() {
    // Function body
}

// Function with two parameters
fn print_greeting_name(greeting: ByteArray, name: ByteArray) {
    // Function body
}
```

## Parámetros y argumentos

Es importante distinguir entre `parameters` y `arguments`:

- **Los parámetros** son los nombres de las variables que se usan en la definición de la función, como `greeting` y `name` en la función `print_greeting_name`.
- **Los argumentos** son los valores reales que se pasan a la función cuando se la llama.

```rust
// Calling the function with arguments
print_greeting_name(123, 456)
```

## Instrucciones y expresiones

El cuerpo de una función se compone de una serie de instrucciones que, de forma opcional, terminan en una expresión.

- Las instrucciones llevan a cabo alguna acción y no devuelven ningún valor.
- Las expresiones se evalúan y dan como resultado un valor.

Crear una variable y asignarle un valor con la palabra clave `let` es una instrucción.

```rust
let y = 6;
```

Pero el `6` de la instrucción anterior es una expresión que se evalúa al valor `6`.

Llamar a una función es una expresión, ya que siempre se evalúa a un valor: el valor devuelto explícito de la función, si se especifica, o el tipo «unit» `()` en caso contrario.

## Valores devueltos

Las funciones de Cairo pueden devolver valores al código que las llama.
Los valores devueltos se indican después de los parámetros, separados por una flecha `->`.
En Cairo, el valor devuelto de la función es sinónimo del valor de la última expresión del bloque del cuerpo de la función.
Puedes devolver un valor antes de tiempo desde una función con la palabra clave `return`, especificando el valor.

```rust
// Function returning the last (and only) expression
fn hello(name: ByteArray) -> ByteArray {
    "Hello " + name
}

// Function returning using the `return` keyword
fn double_if_even(value: u32) -> u32 {
    if value % 2 == 0 {
        return value * 2;
    }
    return value;
}
```

## Llamar a funciones

Para llamar a una función en Cairo, basta con usar el nombre de la función seguido de los argumentos entre paréntesis.

```rust
// Calling a function with no parameters
print_hello()

// Calling a function with one parameter
let greeting = hello("John")

// Calling a function with multiple parameters
print_greeting_name("Howdy", "Joel")
```
