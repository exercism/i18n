# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el formato siguiente: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, cada una de las cuales recibe una línea de registro y te pide que hagas algo con ella.
Hay muchas formas de resolver estas tareas: elige tus métodos favoritos de los ejemplos anteriores y a ver con qué se te ocurre.

## 1. Obtener el mensaje de una línea de registro

Implementa el método `LogLineParser#message` para devolver el mensaje de una línea de registro:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').message
# => "Invalid operation"
```

Debe eliminarse cualquier espacio en blanco al principio o al final:

```ruby
LogLineParser.new("[WARNING]:  Disk almost full\r\n").message
# => "Disk almost full"
```

## 2. Obtener el nivel de registro de una línea de registro

Implementa el método `LogLineParser#log_level` para devolver el nivel de registro de una línea de registro, que debe devolverse en minúsculas:

```ruby
LogLineParser.new('[ERROR]: Invalid operation').log_level
# => "error"
```

## 3. Cambiar el formato de una línea de registro

Implementa el método `LogLineParser#reformat`, que cambia el formato de la línea de registro poniendo primero el mensaje y después el nivel de registro entre paréntesis:

```ruby
LogLineParser.new('[INFO]: Operation completed').reformat
# => "Operation completed (info)"
```
