# Anexo a las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                     |
| -------- | --------- | ------- | ------------------------------- |
| `$a0`    | entrada   | dirección | primera cadena, terminada en nulo  |
| `$a1`    | entrada   | dirección | segunda cadena, terminada en nulo |
| `$v0`    | salida    | entero  | distancia de Hamming            |
| `$t0-9`  | temporal  | cualquiera | para almacenamiento temporal    |
