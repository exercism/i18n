# Pruebas

## Ejecutar las pruebas

El track de Haxe se basa en el framework de pruebas [Buddy](https://github.com/ciscoheat/buddy).
Puedes instalarlo con lo siguiente:

```bash
haxelib install buddy
```

Para ejecutar las pruebas, lanza el siguiente comando:

```bash
haxe test.hxml
```

En el archivo de pruebas, cada bloque describe marca una sección de las pruebas del ejercicio, y cada prueba es un bloque `it` o `xit`.
Los bloques `it` se ejecutarán cuando lances las pruebas, mientras que los bloques `xit` son pruebas pendientes.
Cuando envías una solución, el ejecutor de pruebas de Exercism ejecutará todos los bloques `it` o `xit`.
Cuando trabajas en local, solo se ejecutará la primera prueba por defecto.
Para ejecutar otras pruebas, cambia los bloques `xit` correspondientes por bloques `it` y vuelve a ejecutar `haxe test.hxml`.

Además, puede que algunos ejercicios necesiten que haxelib instale bibliotecas adicionales.
Cuando eso ocurra, habrá una nota en las instrucciones del ejercicio.

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
Para ayudarte a empezar, cada ejercicio incluye un archivo esqueleto de implementación.
Puedes usar este archivo como punto de partida para construir tu solución.
No dudes en eliminar o modificar este archivo si crees que es lo correcto.
Intenta centrarte en una sola prueba a la vez a medida que avanzas hacia la solución.
