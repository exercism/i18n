# Introducción

En Java, los valores booleanos se representan mediante el tipo `boolean`, cuyos valores pueden ser `true` o `false`.

Java admite tres operadores booleanos:

- `!` (NOT): niega el valor booleano
- `&&` (AND): toma dos valores booleanos y da como resultado true si ambos son true
- `||` (OR): da como resultado true si alguno de los dos valores booleanos es true

## Ejemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
