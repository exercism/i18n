# Apéndice de instrucciones

## Notas de implementación

El objeto Tree tiene dos atributos:

- `String` label
- `List<Tree>` children

El programa de pruebas crea árboles mediante la aplicación repetida de la función constructora `Tree.of`. Por ejemplo, la instrucción

```java
Tree tree = Tree.of("a", List.of(Tree.of("b"), Tree.of("c", List.of(Tree.of("d")))));
```

construye el siguiente árbol:

```text
      "a"
       |
    -------
    |     |
   "b"   "c"
          |
         "d"
```

Puedes suponer que no habrá valores duplicados en los árboles de prueba.

---

Los métodos `FromPov` y `PathTo` son la parte interesante del ejercicio.

El método `FromPov` recibe un argumento de tipo string, `from`, que especifica un nodo del árbol mediante su valor. Debe devolver un árbol con el valor `from` en la raíz. Puedes modificar el árbol original y devolverlo, o crear un árbol nuevo y devolver ese. Si devuelves un árbol nuevo, puedes consumir o destruir el árbol original sin problema. Por supuesto, es mejor dejarlo sin modificar.

El método `PathTo` recibe dos argumentos de tipo string, `from` y `to`, que especifican dos nodos del árbol mediante sus valores. Debe devolver el camino más corto en el árbol desde el primer nodo hasta el segundo.

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html).
Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar.

Este ejercicio en concreto requiere que uses la palabra clave [throw](https://docs.oracle.com/javase/tutorial/essential/exceptions/throwing.html)
para «lanzar» varias `UnsupportedOperationException` si se pasa a la clase `Tree()` un árbol que no se puede reorientar, o si no se encuentra un camino entre un `start node` y un `end node`.
Las pruebas solo pasarán si lanzas (`throw`) la excepción (`exception`) e incluyes un mensaje con ella.

Para lanzar una `UnsupportedOperationException` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```java
// when a tree cannot be oriented to a new node POV
throw new UnsupportedOperationException("Tree could not be reoriented");

// when a path cannot be found between a start and end node on the tree.
throw new UnsupportedOperationException("No path found");
```
