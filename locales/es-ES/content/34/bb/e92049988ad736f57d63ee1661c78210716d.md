# Acerca de

Haxe es un lenguaje de programación y compilador de código abierto, de alto nivel, fuertemente tipado, multiplataforma y orientado a objetos, que puede producir aplicaciones y código fuente para muchas plataformas informáticas diferentes a partir de una sola base de código.

Existen varios lenguajes de destino compatibles que permiten distintos casos de uso: [Lenguajes de destino compatibles][supported-target-languages]

[Tipos][types] presenta las siete clases diferentes de tipos que existen en Haxe y cómo interactúan entre sí. La explicación de los tipos continúa en [Sistema de tipos][type-system], donde se describen características como la unificación, los parámetros de tipo y la inferencia de tipos.

[Campos de clase][class-fields] trata en profundidad la estructura de las clases de Haxe y, entre otros temas, aborda las propiedades, los campos inline y las funciones genéricas.

En [Expresiones][expressions] vemos cómo hacer que los programas hagan algo de verdad usando expresiones.

[Características del lenguaje][language-features] concluye la referencia del lenguaje Haxe describiendo en detalle algunas características como la coincidencia de patrones, la interpolación de string y la eliminación de código muerto.
