# Pistas

## 1. Determina si vas a necesitar un carné de conducir

- Usa el [operador de igualdad][equality operator] para comprobar si tu entrada es igual a un string concreto.
- Usa uno de los dos [operadores booleanos][boolean operators] para combinar los dos requisitos.
- No necesitas una instrucción if para resolver esta tarea. Puedes devolver directamente la expresión booleana que construyas.

## 2. Elige entre dos posibles vehículos que comprar

- Para esta tarea necesitarás la [expresión condicional][conditional expression] `if-then-else`.
- Usa un [operador de comparación][comparison operator] para determinar qué opción va primero en orden alfabético.
- Por último, construye la frase de recomendación.
  Puedes usar la concatenación o la interpolación de strings que aprendiste en el concepto de Strings para construir la frase de recomendación.

## 3. Calcula una estimación del precio de un vehículo usado

- Empieza por determinar el porcentaje en función de la antigüedad del vehículo.
  Usa una expresión `if-elsif-else`.
- Para calcular el resultado, aplica el porcentaje al precio original.
  Por ejemplo, `30% of x` se puede calcular multiplicando `x` por `30` y dividiendo entre `100`.
