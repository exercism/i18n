# Pistas

## General

- Un bucle en x86-64 se consigue saltando a una etiqueta anterior y se puede salir de él saltando a una etiqueta que esté fuera del mismo.
- Para acceder al contenido almacenado en una dirección de memoria, tienes que desreferenciarla usando `[]`.
- El prefijo para acceder a valores de 4 bytes en memoria es `dword`.
- Un array se representa por su dirección, que es un valor de 8 bytes en x86-64.
- Si una función llamada modifica un registro, tienes que guardar cualquier valor de ese registro que vayas a usar más adelante.

## 3. Reponer las reservas de gajos de lima

- Tienes que llevar la cuenta de dos cosas: cuántas limas se han cortado ya y cuántos gajos faltan todavía.
- Es posible que no necesites ningún gajo desde el principio o que el array de entrada esté vacío, así que tienes que comprobar una condición de salida antes de ejecutar cualquier iteración del bucle.
- Puedes usar `sub` para restar al valor de un operando destino el valor de un operando origen.
- Puedes usar `inc` para sumar 1 al valor de un operando destino.
