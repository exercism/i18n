# Accesibilidad

La misión de Exercism es ayudar al mayor número de personas posible. Queremos que todo el mundo pueda usar nuestros servicios y nos esforzamos por conseguir que nuestro contenido cumpla los estándares de accesibilidad.

Hemos creado nuestro sitio web con los siguientes objetivos:

- El texto debe ser claro y sencillo de entender. Debes poder ampliar el zoom hasta un 300 % sin que el texto se salga de la pantalla
- Debes poder navegar por la mayor parte del sitio usando solo el teclado
- Debes poder navegar por la mayor parte del sitio usando software de reconocimiento de voz
- Debes poder escuchar la mayor parte del sitio con un lector de pantalla (incluidas las versiones más recientes de JAWS, NVDA y VoiceOver)

## ¿Qué accesibilidad tiene nuestro sitio web?

Nuestro sitio web cumple el estándar de las Pautas de Accesibilidad para el Contenido Web, versión 2.1, nivel AA.

## Mejorar la accesibilidad

Siempre nos interesa saber si alguna parte de nuestros sitios web no es accesible.
Si encuentras algo que no está a la altura, abre una incidencia en nuestro [gestor de incidencias](https://github.com/exercism/exercism/issues) explicando qué tenemos que mejorar.
