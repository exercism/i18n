# Uso de la cabecera de función

[comment]: # (Este error se produce cuando la solución usa una cabecera de función)

Una cabecera de función (una definición de función sin cuerpo) solo es necesaria para funciones con argumentos por defecto que tienen varias cláusulas.

```elixir
# necessary function header
def hello(what \\ "World")
def hello("Alice"), do: "Hello, darling!"
def hello(name), do: "Hello, #{name}!"
```

Para las funciones con argumentos por defecto que solo tienen una cláusula, los argumentos por defecto se pueden especificar directamente en esa cláusula.

```elixir
# preferred
def bye(name \\ "World"), do: "See you, #{name}!"

# not preferred - unnecessary function header
def bye(what \\ "World")
def bye(name), do: "See you, #{name}!"
```

La función `two_fer/1` solo necesita una cláusula, por lo que no necesita una cabecera de función.
