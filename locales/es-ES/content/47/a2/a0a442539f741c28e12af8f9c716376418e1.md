# Introducción

## Genéricos

### Introducción

Los genéricos son una funcionalidad del lenguaje que permite reutilizar código.
Por ejemplo, no debería importar qué tipo contiene un array para poder calcular su longitud.
Por eso la función `length` usa un parámetro de tipo genérico `a` en su signatura de tipo.

```elm
length : List a -> Int
```

### Parámetros en los tipos

Cuando un tipo es genérico respecto a otro tipo, usamos un nombre en minúscula para ese otro tipo y lo llamamos parámetro de tipo.
Ejemplos habituales son los tipos personalizados `List`, `Maybe` y `Result`.

```elm
-- Maybe is generic over the type a
type Maybe a
    = Nothing
    | Just a

someString : Maybe String
someString = Just "hello"

someInt : Maybe Int
someInt = Just 42
```

Una observación importante sobre los nombres de los parámetros de tipo es que pueden tener más de un carácter.
La única restricción es que deben ser nombres en minúscula.
Por eso, cuando resulta útil, solemos darles nombres descriptivos.

Un tipo puede ser genérico respecto a varios tipos a la vez y, por tanto, tener varios parámetros de tipo.
En ese caso, cada tipo independiente recibe un nombre en minúscula distinto.
Que sean independientes no impide que acaben siendo el mismo tipo; simplemente permite que sean distintos.

```elm
-- Result is generic over the types error and value
type Result error value
    = Ok value
    | Err error
```

Los alias de tipo de registro también pueden tener parámetros de tipo, aunque es menos habitual.

```elm
-- Event is generic over the type a
type alias Event a =
    { at : Time
    , data : a 
    }
```

### Parámetros de tipo en las funciones

Como los tipos pueden ser genéricos, las funciones también.
Se pueden escribir funciones que manejen tipos genéricos, como `Maybe.withDefault`.

```elm
withDefault : a -> Maybe a -> a
withDefault default maybe =
    case maybe of
      Just value -> value
      Nothing -> default
```

Las funciones que toman otras funciones como parámetros se llaman funciones de orden superior, y estas también pueden ser genéricas.

```elm
map : (a -> b) -> Maybe a -> Maybe b
map function maybe =
  case maybe of
    Just value ->
      Just (function value)

    Nothing ->
      Nothing
```
