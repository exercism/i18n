# Anexo de instrucciones

## Pistas

Tienes que implementar la función

```haskell
value :: (Color, Color) -> Int
```

que solo acepta dos colores y produce el valor numérico de la resistencia.

**Extra: pruebas de propiedades:**

Este ejercicio es una buena oportunidad para escribir algunas [pruebas de propiedades](https://en.wikipedia.org/wiki/Property_testing). Si nunca has escrito ninguna, aquí tienes algunos recursos:

1. [School of Haskell](https://www.schoolofhaskell.com/user/pbv/an-introduction-to-quickcheck-testing).
2. [Real world Haskell](http://book.realworldhaskell.org/read/testing-and-quality-assurance.html)

Hemos incluido un ejemplo de prueba de propiedades con QuickCheck en el fichero de pruebas.

Ejemplos de propiedades que se pueden comprobar:

- `value (x, y) >= 10` para todos los `(x, y)` en los que `x` no sea `Black`

- Llamar a `show` sobre `value (x, y)` produce el resultado de aplicar `reverse` al String que devuelve llamar a `show` sobre `value (y, x)`.

- Todos los colores tienen nombres únicos. (Para cualesquiera dos colores, si los colores son distintos, sus nombres también lo son.)
