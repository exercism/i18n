# Introducción

El operador `|>` se llama operador de tubería. Se puede usar para encadenar llamadas a funciones de forma que el valor devuelto por la llamada a la función anterior se pase como primer argumento a la siguiente llamada a función.

```elixir
"hello"
|> String.upcase()
|> Kernel.<>("?!")

# => "HELLO?!"
```
