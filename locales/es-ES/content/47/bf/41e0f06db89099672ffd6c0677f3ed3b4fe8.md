# Instalación

La versión actual de elm es la 0.19.1.
Las instrucciones de instalación cambian a medida que el lenguaje evoluciona.
Para consultar las instrucciones de instalación más actualizadas, dirígete a las
[instrucciones de instalación de la guía de elm][elm-install].

[elm-install]: https://guide.elm-lang.org/install/elm.html

## Herramientas adicionales

**elm-test**

La herramienta que se usa para ejecutar los tests desde la línea de comandos se llama elm-test.
Actualmente, elm-test requiere Node.js y npm, así que, si aún no lo has hecho,
[instala primero Node.js y npm][npm-install].
Una vez que tengas npm instalado, puedes instalar elm-test con:

```shell
npm install --global elm-test@latest-0.19.1
```

Encontrarás más información en la [página de npm de elm-test][elm-test].

[npm-install]: https://www.npmjs.com/get-npm
[elm-test]: https://www.npmjs.com/package/elm-test

**elm-format**

La mayoría de los desarrolladores de elm usan elm-format para dar formato a su código elm.
Es una herramienta de formato de código sin configuración.
Puede resultar un poco frustrante al principio si no estás acostumbrado
a las herramientas de formato automático, pero una vez que te acostumbras,
empiezas a preguntarte cómo podías programar antes sin ella.
También se puede instalar con npm:

```shell
npm install --global elm-format@latest-0.19.1
```

Encontrarás más información en la [página principal de elm-format en GitHub][elm-format].

[elm-format]: https://github.com/avh4/elm-format

**Editor de texto**

El soporte de Elm es bueno al menos para [IntelliJ][intellij],
y para editores de texto compatibles con el [servidor de lenguaje de elm][els],
como VS Code, Sublime Text o Vim.

[els]: https://github.com/elm-tooling/elm-language-server
[intellij]: https://github.com/klazuka/intellij-elm

## Errores de permisos con npm

Es posible que te encuentres con un error de permisos EACCESS con npm
al instalar elm-test o elm-format.
Si es el caso, sigue las instrucciones del sitio web de npm.
[Cómo resolver los errores de permisos EACCES al instalar paquetes de forma global][eaccess].

[eaccess]: https://docs.npmjs.com/resolving-eacces-permissions-errors-when-installing-packages-globally
