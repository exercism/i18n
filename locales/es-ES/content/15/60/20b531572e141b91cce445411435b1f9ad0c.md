# Introducción

La enumeración es el acto de recorrer una colección (`Array`, `Hash`, etc.) y realizar alguna acción sobre cada objeto.

La enumeración es un concepto clave en Ruby y se usa para ordenar (`sort_by`), agrupar (`group_by`), mapear (`map`), reducir (`reduce`) y mucho más.
Verás la enumeración con más frecuencia como la forma idiomática de recorrer colecciones en lugar de usar bucles.

Una enumeración sencilla que utiliza `map` y `with_index` tiene este aspecto:

```ruby
words = %w[the cat sat on the mat]
list = words.map.with_index do |word, index|
  "#{index}. #{word}"
end

puts list

# Output:
# 0. the
# 1. cat
# 2. sat
# 3. on
# 4. the
# 5. mat
```
