# Acerca de

Un [`Array`][array] en Elm es una colección inmutable y rápida de cero o más valores del mismo tipo.
Como los arrays son inmutables, una vez construido un array su valor nunca puede cambiar.
No existe una sintaxis literal para los arrays (como la hay para las listas), así que en su lugar se usa la sintaxis Array.fromList.
Por ejemplo, un `Array` con "a", "b" y "c" dentro se suele mostrar como `Array.fromList ["a", "b", "c"]`.
Verás esto en la salida de la consola, en el depurador y en otros lugares parecidos.

A diferencia de `List`, que es una [importación por defecto][default-imports], el módulo `Array` debe importarse explícitamente, usando `import Array` o similar.

Las anotaciones de tipo para los arrays se pueden definir del siguiente modo:

```elm
Array String --> an array of String
Array Int --> an array of Int
```

Los arrays se pueden definir del siguiente modo:

```elm
import Array exposing (Array)

empty : Array Char
empty = Array.empty

singleValue = Array.fromList [ 5 ] --> Array Int

repeatSingleValue = Array.repeat 2 5 --> Array.fromList [ 5, 5 ]

initialiseFromIndex = Array.initialise 3 (\index -> index * 2) --> Array.fromList [ 0, 2, 4 ]

initialisefromList = Array.fromList [ "a", "b", "c" ] --> Array.fromList [ "a", "b", "c" ]
```

Los elementos se añaden a un array usando `Array.push`:

```elm
twoToFour = Array.fromList [ 2, 3, 4 ]
oneToFour = Array.push 1 twoToFour --> Array.fromList [ 1, 2, 3, 4 ]
```

Los arrays se concatenan usando `Array.append`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
eightNine = Array.fromList [ 8, 9 ]
Array.append sixSeven eightNine --> Array.fromList [ 6, 7, 8, 9 ]
```

Un elemento de un array se obtiene usando `Array.get`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.get 0 sixSeven --> Just 6
```

Un elemento de un array se establece usando `Array.set`:

```elm
sixSeven = Array.fromList [ 6, 7 ]
Array.set 1 8 sixSeven --> Array.fromList [ 6, 8 ]
```

Los arrays se manipulan con funciones definidas en el [módulo `Array`][array-module].

```elm
oneTwo = Array.fromList [ 1, 2 ]
Array.length oneTwo --> 2
```

Cualquier función u operador que parezca modificar un `Array` (como añadir un elemento) en realidad devolverá un nuevo `Array`.
Aun así, el rendimiento normalmente no es un problema, ya que la implementación de `Array` evita asignaciones y copias innecesarias.
