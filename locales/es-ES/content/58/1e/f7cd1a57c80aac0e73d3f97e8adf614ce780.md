# Introducción

En general, no quieres reinventar la rueda cuando se trata de programación. Para muchos algoritmos estándar, es probable que alguien ya haya hecho el trabajo por ti.

## Inclusiones

Para incluir el contenido de otros archivos, C++ usa la directiva `include`. Estas inclusiones deben indicarse al principio del archivo. Durante la compilación, la línea con la directiva se sustituye por el contenido del archivo correspondiente. Los espacios de nombres se mantienen tal y como están en el archivo original después de las inclusiones.

## La biblioteca estándar

La biblioteca estándar ofrece muchas funciones, algoritmos y estructuras de datos comunes. La biblioteca estándar usa el espacio de nombres `std`.

Un ejemplo es la biblioteca numérica de C `cmath`. Proporciona muchas operaciones matemáticas comunes.

```cpp
#include <cmath>

int cube_me(int a) {
    // raise `a` to the third power
    return std::pow(a, 3);
}
```

~~~~exercism/note
Las bibliotecas estándar se incluyen con corchetes angulares `<>` en lugar de comillas dobles `"`. La diferencia está en la ubicación en la que el compilador busca los archivos correspondientes. En la versión con corchetes angulares se omite la búsqueda en el proyecto actual y se empieza directamente en los directorios de inclusión del sistema. Si quieres incluir archivos locales, usarías comillas dobles: `#include "myfile"`
~~~~
