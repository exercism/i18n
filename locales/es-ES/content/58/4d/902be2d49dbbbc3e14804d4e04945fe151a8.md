# Introducción

_Las fechas y las horas son algo que enseñamos a niños pequeños. ¿Qué puede tener de difícil?_

Muchos programadores han cometido ese error, y la experiencia posterior suele tener un efecto negativo en su salud y su felicidad.

Cualquiera que programe algo no trivial con fechas y horas debería estar al menos preparado para entender y mitigar los posibles problemas.

Este documento intentará dar una visión general de cómo Julia gestiona las fechas y las horas, pero será necesario consultar el [manual][Dates] para más detalles.
También hay un [Wikibook][Wikibook] cuyas explicaciones algunos lectores pueden encontrar más claras, e incluye un útil [diagrama][type-hierarchy] de la jerarquía de tipos.

## El módulo `Dates`

La mayor parte de la funcionalidad básica está en `Dates`, un módulo que se incluye en una instalación predeterminada pero que no forma parte de la biblioteca estándar.

Para usar el módulo, hay dos opciones:

1. Añadir `import Dates` y, a continuación, anteponer `Dates.` a todas las llamadas a funciones.
2. Añadir `using Dates`, lo que trae todo el módulo al espacio de nombres actual (_excepto unos pocos nombres problemáticos_).

```julia-repl
# option 1
julia> import Dates

julia> Dates.now()
2025-06-21T16:02:39.080

julia> now()  # wrong: need to include `Dates.` after an import
ERROR: UndefVarError: `now` not defined in `Main`


# option 2
julia> using Dates

julia> now()  # functions are now in the namespace
2025-06-21T16:03:04.161
```

El módulo `Dates` es grande y complicado, pero ofrece cuatro tipos principales de funcionalidad:

- `Dates.Date`, que incluye día, mes y año, pero no la hora del día.
- `Dates.Time`, que incluye la hora del día, pero no la fecha.
- `Dates.DateTime`, que combina fecha y hora.
- `Dates.Period`, que gestiona intervalos de tiempo y de fecha.

Ten en cuenta que un `DateTime` generalmente _no_ incluye información sobre la zona horaria (Python lo llamaría un datetime «naive»).
Una excepción es `now()`, que obtiene la hora local del reloj de tu sistema y puede convertirla a UTC si es necesario.

Quizá las necesidades más frecuentes sean:

- Analizar algún formato de entrada adecuado para construir un tipo de `Dates`.
- Obtener el formato numérico o de string que se necesite a partir de un tipo de `Dates`.
- Aplicar un desplazamiento a un valor `Date`, `Time` o `DateTime`.
- Calcular el intervalo entre dos de esos valores.
- Obtener la fecha actual (con `today()`) o la hora actual (con `now()`), o ambas.

~~~~exercism/note
Para reducir las distracciones visuales, la mayor parte del código de ejemplo del resto de este documento da por supuesto `using Dates` y evita incluir el nombre del módulo `Dates.` en las llamadas a funciones.
~~~~

### Formatos de fecha y hora

Hay muchas formas de escribir fechas y horas, que tienden a ser específicas de cada cultura.
Las fechas con solo números, como «7/6/23», son ambiguas, confusas y han provocado muchos errores costosos en organizaciones multinacionales (_el autor lo dice por amarga experiencia personal_).

El estándar internacional se define en `ISO 8601`, con dos ventajas principales:

- El análisis es rápido y no da lugar a ambigüedades.
- La ordenación es sencilla, ya que la fecha y la hora pueden tratarse como texto normal y ordenarse alfabéticamente.

Vimos en un ejemplo anterior que `Date.now()` devolvía `2025-06-21T16:03:04.161`.

Esto se compone de varias partes:

- `YYYY-MM-DD` para la parte de la fecha.
- `hh:mm:ss` para la parte de la hora.
- Opcionalmente, milisegundos (o una unidad aún más pequeña) tras el separador decimal.

Otros formatos de string se tratarán en una sección posterior.

## Fechas

`Dates.Date` es un tipo relativamente simple que solo representa fechas, sin ninguna noción de horas ni de zonas horarias.

```julia-repl
# constructor with year, month, day arguments
julia> date1 = Date(2025, 06, 23)
2025-06-23

# constructor with ISO 8601 string
julia> date2 = Date("2025-06-23")
2025-06-23

julia> date1 == date2
true

julia> typeof(date1)
Date
```

Existen funciones de acceso para las distintas partes de la fecha, y vienen en pares que se distinguen por el uso de mayúsculas o minúsculas.

```julia-repl
# lowercase returns an integer
julia> month(date1)
6

julia> typeof(month(date1))
Int64

# Propercase returns a Period type
julia> Month(date1)
6 months

julia> typeof(Month(date1))
Month
```

### Funciones de consulta

Hay diversas funciones con cierta noción del calendario.
El siguiente ejemplo muestra solo unas pocas.

```julia-repl
julia> date1
2025-06-23

julia> dayofweek(date1) # 1 = Monday, 7 = Sunday
1

julia> dayname(date1)
"Monday"

julia> daysinmonth(date1)
30

julia> isleapyear(date1)
false

julia> lastdayofmonth(date1)
2025-06-30
```

## Horas

`Dates.Time` es el tipo básico que solo representa horas.
No tiene ninguna noción de las fechas: las horas vuelven automáticamente a `Time(0, 0, 0)` al llegar la medianoche.

El formato completo del constructor es `Time(hour, min, sec, millisec, microsec)` o su equivalente en ISO 8601.

Todos los parámetros son opcionales y su valor predeterminado es `0`.

```julia-repl
julia> Time(14, 57, 25, 142)
14:57:25.142

julia> Time("14:57:25.142")
14:57:25.142

julia> Time(14, 57, 25, 142, 32)
14:57:25.142032
```

Igual que con `Date`, las distintas partes están disponibles mediante funciones de acceso:

```julia-repl
julia> minute(t) # => integer
57

julia> Minute(t) # => Period
57 minutes
```

## Fechas y horas

`Dates.DateTime` combina la mayoría de las características de los tipos `Date` y `Time`.

```julia-repl
julia> dt1 = DateTime(2025, 6, 23, 14, 57, 25, 142)
2025-06-23T14:57:25.142

# date1 and t were defined in previous examples
julia> dt2 = DateTime(date1, t)
2025-06-23T14:57:25.142
```

Los parámetros de año, mes y día tienen como valor predeterminado `1`, y todos los parámetros de hora tienen como valor predeterminado `0`.

No perder la pista de todos estos parámetros puede ser todo un reto, así que para la entrada puede ser preferible el formato ISO.

Como alternativa, un `DateTime` puede construirse a partir de un `Date` y un `Time`, como en el ejemplo anterior.

## Periodos

Cada uno de los componentes de fecha y hora tiene su propio tipo `Period`, desde `Year` hasta `Nanosecond`, que representa un intervalo de tiempo.
Resultan especialmente útiles para la aritmética.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Year(21)
21 years

julia> Second(61)
61 seconds

julia> dt1 + Year(21) - Second(61)
2046-06-23T14:56:24.142

julia> Date(2025, 07, 03) - Date(2025, 04, 25)
69 days
```

Cuando se trabaja con tipos `Period`, Julia intenta ser inteligente con las irregularidades del calendario, como la duración de los meses, y redondea cuando es necesario.

```julia-repl
# February has fewer days than January
julia> Date(2025, 1, 31) + Month(1) 
2025-02-28
```

## Representaciones de string

Antes hemos mencionado el estándar ISO 8601, que es la representación predeterminada de fecha y hora en Julia al formatear o analizar strings.

Obviamente, muchos otros formatos se usan con frecuencia, a menudo de formas específicas de cada cultura.
Para manejarlos, Julia dispone del tipo `DateFormat`, que puede construirse a partir de un string de formato de complejidad arbitraria.

```julia-repl
# dateformat"" string syntax
julia> dtfmt = dateformat"d/m/y"
dateformat"d/m/y"

julia> typeof(dtfmt)
DateFormat{Symbol("d/m/y"), Tuple{Dates.DatePart{'d'}, Dates.Delim{Char, 1}, Dates.DatePart{'m'}, Dates.Delim{Char, 1}, Dates.DatePart{'y'}}}

# DateFormat constructor
julia> DateFormat("d/m/y")
dateformat"d/m/y"
```

El ejemplo anterior es muy sencillo: solo una fecha en el formato día/mes/año habitual en Europa.
Se muestran dos variantes de la sintaxis, pero el resultado es idéntico.

Un `DateFormat` puede usarse después para analizar cualquier string adecuado:

```julia-repl
julia> DateTime("14/7/2023", dtfmt)
2023-07-14T00:00:00
```

Crear un `DateFormat` conlleva una sobrecarga considerable, así que hacer este paso una sola vez (como aquí con `dtfmt`) ayuda al rendimiento cuando se recorre en bucle un gran número de strings de fecha y hora.

Los formatos pueden ser mucho más complejos que este, así que consulta el [manual][dateformat] para más detalles.

El mismo `DateFormat` también puede usarse para mostrar una fecha y hora en cualquier formato de string deseado, mediante la función [`Dates.format()`][format].

Por desgracia, parece haber un conflicto de espacio de nombres con `format` (al menos en Julia 1.11.5), así que lo mejor es incluir el prefijo `Dates.` incluso después de `using Dates`.

```julia-repl
julia> dt1
2025-06-23T14:57:25.142

julia> Dates.format(dt1, dateformat"e, u d")
"Mon, Jun 23"
```

Como se [documenta][wiki-format], `"e, u d"` proporciona la representación de texto abreviada del día de la semana y del mes.

La representación de texto es en inglés por defecto.
Se pueden añadir otros idiomas, aunque actualmente el soporte para ello no es óptimo.
