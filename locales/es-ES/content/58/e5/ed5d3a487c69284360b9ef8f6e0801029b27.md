Puede que te apetezca incluir estos widgets tú mismo en documentos Markdown, por ejemplo al final de un documento para sugerir lecturas adicionales o buenos ejercicios con los que aprender algo.

**Nota:** También puedes usar enlaces normales para el texto en línea, y se les añadirán los tooltips. Consulta [la documentación sobre enlaces internos](/docs/building/markdown/internal-linking) para más detalles.

## Uso

Los widgets se pueden usar allí donde puedas usar Markdown, como en la documentación, los enfoques y las conversaciones entre estudiantes y mentores.

Se renderizan con el siguiente formato:

```md
[<type>:<id>]()
```

Las partes `<type>` e `<id>` son variables y dependen del widget que se use en cada caso.

El sitio web ignora la referencia del enlace, es decir, el contenido de `()`. Puedes apuntarla a lo que quieras con fines de mantenimiento.

## Widget de ejercicio

Formato del enlace: `[exercise:<track-slug>/<exercise-slug>]()`

### Ejemplo

```markdown
Great job on solving this exercise! Some other exercises that you might also like to try:

- [exercise:fsharp/anagram]()
- [exercise:fsharp/isogram]()
```

## Widget de concepto

Formato del enlace: `[concept:<track-slug>/<concept-slug>]()`

### Ejemplo

```markdown
There are three primary conditional statements that are used in Julia:

- [concept:julia/if-statements]()
- [concept:julia/ternary-operator]()
- [concept:julia/short-circuiting]()
```

## Widget de enfoque

Formato del enlace: `[approach:<track-slug>/<exercise-slug>/<approach-slug>]()`

### Ejemplo

```markdown
Here are some approaches you might want to checkout!

- [approach:csharp/two-fer/method-overloading]()
- [approach:csharp/two-fer/optional-parameter]()
```

## Widget de artículo

Formato del enlace: `[article:<track-slug>/<exercise-slug>/<article-slug>]()`

### Ejemplo

```markdown
We have an article you might be interested in:

- [article:csharp/reverse-string/performance]()
```
