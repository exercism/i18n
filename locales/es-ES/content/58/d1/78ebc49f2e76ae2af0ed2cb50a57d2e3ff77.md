# Introducción

Un *conjunto disjunto* (una estructura union-find) mantiene una colección de valores repartidos en grupos que no se solapan y responde con rapidez a una pregunta: ¿estos dos valores están en el mismo grupo? Vive en el vocabulario [`disjoint-sets`][disjoint-sets].

## Construir un conjunto disjunto

`<disjoint-set>` construye una estructura vacía. Los valores, los *átomos*, se añaden con `add-atom` de uno en uno, o con `add-atoms` a partir de una secuencia. Cada átomo empieza en un grupo por sí solo.

```
<disjoint-set> ( -- disjoint-set )
add-atom       ( atom disjoint-set -- )
add-atoms      ( seq disjoint-set -- )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms   ! 1, 2 and 3 each in their own group
```

El conjunto disjunto es *mutable*: `add-atom`, `add-atoms` y `equate` lo modifican en el sitio en lugar de devolver uno nuevo. `keep` resulta práctico cuando quieres recuperar el conjunto disjunto en la pila después de que una de estas palabras se lo haya llevado.

## Fusionar grupos

`equate` une los dos grupos que contienen sus átomos. La unión es transitiva: une dos átomos y después uno de ellos con un tercero, y los tres acaban en un mismo grupo.

```
equate ( atom1 atom2 disjoint-set -- )
```

## Representantes

Cada grupo tiene un miembro canónico, su *representante*. `representative` lo devuelve, y dos átomos pertenecen al mismo grupo exactamente cuando sus representantes son iguales.

```
representative ( atom disjoint-set -- representative )
```

```factor
USING: disjoint-sets ;

<disjoint-set>
{ 1 2 3 } over add-atoms
1 2 pick equate
1 over representative .   ! => 1
2 over representative .   ! => 1   (same representative as 1)
3 over representative .   ! => 3   (still on its own)
```

Qué átomo elige un grupo como representante es un detalle interno; no dependas nunca de que se elija un átomo concreto, solo de que dos átomos del mismo grupo coincidan.
