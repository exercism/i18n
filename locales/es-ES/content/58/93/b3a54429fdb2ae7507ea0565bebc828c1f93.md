# Acerca de

Las [guardas][guards] se usan como complemento de la [coincidencia de patrones][exercism-pattern-matching], que veremos en un concepto posterior.
Las guardas nos permiten tener distintas implementaciones de una función según el valor de la entrada.
También permiten hacer comprobaciones más complejas.

Una guarda se define con una barra vertical `|` seguida de una expresión booleana, y termina con un signo igual `=` y el cuerpo de la función.
Puede haber varias guardas para una misma función.
Las guardas se evalúan de arriba abajo, y se ejecuta la primera que se evalúe como `True`.
Una guarda puede incluir una cláusula `otherwise`, que actúa como comodín para cualquier valor que no coincida con las guardas anteriores.

```haskell
isEven :: Int -> String
isEven n
    | even n = "n is even"
    | otherwise = "n is odd"
```

También podemos definir nuestra función y usarla dentro de la guarda.

```haskell
isEven' :: Int -> Bool
isEven' n = even n

isEven :: Int -> String
isEven n
    | isEven' n = "n is even"
    | otherwise = "n is odd"
```
