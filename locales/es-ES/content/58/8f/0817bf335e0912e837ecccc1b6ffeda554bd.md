# Acerca de

[D](https://dlang.org) es un lenguaje de programación de sistemas con
sintaxis similar a la de C y tipado estático. Combina eficiencia, control y capacidad de
modelado con seguridad y productividad para el programador. El lenguaje fue desarrollado
originalmente por [Walter Bright](https://en.wikipedia.org/wiki/Walter_Bright) y [Andrei
Alexandrescu](https://en.wikipedia.org/wiki/Andrei_Alexandrescu) a partir de la versión 2 de D.

D es el resultado de décadas de experiencia implementando compiladores para muchos lenguajes
diversos y cuenta con un gran número de [características únicas](http://dlang.org/overview.html):

- construcciones de alto nivel para una gran capacidad de modelado
- lenguaje compilado de alto rendimiento
- tipado estático
- evolución de C++ (sin sus errores)
- interfaz directa con las API del sistema operativo y con el hardware
- tiempos de compilación rapidísimos
- permite programar de forma segura en cuanto a la memoria (SafeD)
- código mantenible y fácil de entender.
- curva de aprendizaje corta (sintaxis similar a la de C, parecida a la de Java y otros)
- compatible con la interfaz binaria de aplicaciones de C
- multiparadigma (imperativo, estructurado, orientado a objetos, genérico, funcional puro e incluso ensamblador)
- prevención de errores integrada (contratos, pruebas unitarias)

La [D Language Foundation](https://dlang.org/foundation.html) es la organización dedicada a desarrollar y
promover el lenguaje D.
