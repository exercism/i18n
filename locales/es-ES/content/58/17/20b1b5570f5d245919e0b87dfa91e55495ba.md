# Parámetro obligatorio inesperado

Al parámetro \`${'parameter.name'}\` se le llama con y sin un valor en las pruebas, pero _no está marcado como opcional_, lo que significa que las pruebas no pasarán. Un parámetro de TypeScript se puede marcar explícitamente como opcional con el sufijo `?`:

```typescript
function(${'parameter.name'}?: ${'parameter.type'}) {
  //
}
```

O, como alternativa, asignándole un valor por defecto:

```typescript
function(${'parameter.name'}: ${'parameter.type'} = <default>) {
  //
}
```
