# String

El tipo de dato `String` es una cadena de caracteres codificados en UTF-8. Es útil para almacenar datos textuales.

## Crear un string

Un string se puede crear usando las funciones asociadas `String::new()` o `String::from()`. Muchos tipos tienen un método `to_string` para producir un string, por ejemplo, a partir de un número.

```rust
let my_string = String::from("The answer is");
let answer = 42.to_string();
println!("{my_string} {answer}");
```

### La macro `format!`

Como producir un string grande a partir de una selección de tipos de datos más pequeños es una operación habitual, Rust también incluye una forma abreviada que omite los detalles de llamar a `to_string`: la macro `format!`. Por ejemplo, podríamos simplificar la construcción del string compuesto anterior del siguiente modo:

```rust
let the_answer = format!("{} {}.", "The answer is", 42);
assert_eq!("The answer is 42.", the_answer);
```

## Slices de string

Los strings tienen una relación estrecha con los slices de string. Un slice de string es una referencia inmutable a una región de memoria de tamaño conocido que contiene una secuencia lineal de caracteres codificados en UTF-8. Cualquier string se puede convertir en un slice de string tomando prestado con el operador de desreferencia (`&`). Para convertir un slice de string en un string, tanto el método `to_string()` como `String::from` son apropiados.

En el código de Rust, un string literal se escribe entre comillas dobles. Estos strings literales son siempre slices de string, porque se refieren a una región inmutable de memoria dentro del ejecutable del programa.

```rust
let string = String::from("string");
let slice = "string";
assert_eq!(slice, &string);
```

## Mutar un string

Para concatenar un solo carácter a un string, usa el método `push`. Para concatenar un slice de string a un string, usa el método `push_str` o el operador `+`.

```rust
fn main() {
    // For demonstration purposes, we're not using `format!`
    let s1 = String::from("tic");
    let s2 = String::from("tac");
    let s3 = String::from("toe");

    let s = s1 + "-" + &s2 + "-" + &s3;
    println!("{s}");
}
```

## Acceder a los caracteres de un string

Como los strings de Rust están codificados en UTF-8, no todos los caracteres individuales tienen el mismo tamaño. Por eso, el tipo de dato `String` no proporciona un operador de indexación (`[]`). Para acceder a todos los caracteres o a un carácter concreto de un string, se puede usar el método `chars()`. Este itera sobre cada carácter del string, en secuencia.

```rust
let alphabet: String = ('a'..='z').collect();
for c in alphabet.chars() {
    println!("{c}");
}
let j = alphabet.chars().nth(9);
println!("{j:?}"); // prints Some('j')
```
