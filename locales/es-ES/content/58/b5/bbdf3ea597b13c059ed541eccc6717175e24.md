# Pistas

## General

- Usa el [tipo de array (enlazado)][list] integrado.

## 1. Define una función para devolver un array de lenguajes vacío

- La función debe devolver `[]`.

## 2. Define una función para añadir un lenguaje al array

- Se puede anteponer un elemento a un array usando `|`.

## 3. Define una función para eliminar un lenguaje del array

- Elixir [proporciona una función][tl] para devolver un array con el primer elemento eliminado.

## 4. Define una función para devolver el primer elemento del array

- Elixir [proporciona una función][hd] para obtener el primer elemento de un array.

## 5. Define una función para devolver cuántos lenguajes hay en el array

- Elixir [proporciona una función][length] para contar la longitud de un array.

## 6. Define una función para determinar si el array incluye un lenguaje funcional

- Tu función debe devolver un valor booleano que indique si `"Elixir"` es un miembro del array. Elixir [proporciona una función][in] para comprobar la pertenencia a un array.
