# Pistas

## 1. Comprobar si un valor es booleano

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.

## 2. Comprobar si un valor es un número

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Tienes que comprobar `Infinity` y `NaN`.
- `NaN` nunca es igual a sí mismo, pero hay una [función integrada][isNaN] para comprobar si un valor es `NaN`.

## 3. Comprobar si un valor es un objeto

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Tendrás que comprobar si es `null`.

## 4. Comprobar si un string es numérico

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes recorrer un string para comprobar si todos sus caracteres son dígitos.

## 5. Comprobar si un objeto es electrónico

- Puedes usar `instanceof` para comprobar si un objeto es una instancia de una clase o de alguna de sus clases hijas.

## 6. Comprobar si un valor es un array no vacío

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes comprobar la longitud de un array para saber cuántos elementos contiene.

## 7. Comprobar si un valor es un array vacío

- Puedes usar `typeof` para averiguar el tipo de un valor.
- `typeof` devuelve un string.
- Puedes comprobar la longitud de un array para saber cuántos elementos contiene.

## 8. Comprobar si un objeto tiene una propiedad o un método `type`

- Puedes usar el operador `in` para comprobar si un objeto tiene una propiedad o un método.

## 9. Lanzar un error si un objeto no tiene la propiedad o el método `id`

- Puedes usar el operador `in` para comprobar si un objeto tiene una propiedad o un método.
- Si falta la propiedad o el método `id`, tu función debe lanzar un `Error`.

## 10. Comprobar si un objeto tiene una propiedad `id`

- Para comprobar si un objeto tiene una propiedad (no un método), puedes usar la función `Object.hasOwn()`.

## 11. Comprobar si un objeto tiene una propiedad `type` definida

- Para comprobar si un objeto tiene una propiedad (no un método), puedes usar la función `Object.hasOwn()`.
- Tendrás que acceder a la propiedad `type` y comprobar si está definida.

[isNaN]: https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/isNaN
