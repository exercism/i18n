# Introducción

Los métodos pueden tener un parámetro varargs, que permite a quien llama especificar cero o más argumentos como si fueran parámetros normales. El método recibirá esos argumentos en un único array.

Para convertir un parámetro en un parámetro varargs, añade la palabra clave `params` a la declaración del parámetro:

```csharp
public static void PrintNumbers(params int[] numbers)
{
    foreach (var number in numbers)
    {
        Console.Write(number)
    }
}

// No values for a varags parameter is allowed
PrintNumbers();

PrintNumbers(1);
// => 1

PrintNumbers(1, 2, 3);
// => 123
```
