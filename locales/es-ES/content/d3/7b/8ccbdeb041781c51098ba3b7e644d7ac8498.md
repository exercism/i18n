# Pistas

## 1. Seguimiento de las rondas de póker

- La función [`list`][list] devuelve un array formado por los argumentos que recibe.

## 2. Mantener todas las rondas en el mismo lugar

- La función [`concat`][concat] sirve para concatenar dos arrays.

## 3. Encontrar rondas anteriores

- La función [`some`][some] devuelve el primer valor lógicamente verdadero de una colección.
- La función [`boolean`][boolean] resulta útil cuando una función devuelve un valor pero las pruebas esperan un Boolean.

## 4. Calcular la media de los valores de las cartas

- Recuerda los operadores aritméticos básicos, como [`/`][division] y [`+`][addition].
- Una colección de números se puede sumar con [`apply`][apply] o con [`reduce`][reduce].
- La función [`count`][count] devuelve el número de elementos de una colección.
- La función [`/`][division] devuelve un valor de tipo ratio cuando opera con números enteros. Puedes usar [`double`][double] para convertir un ratio en un número decimal.

## 5. Medias alternativas

- Hay funciones de secuencia para devolver el [`first`][first] o el [`last`][last] elemento de una colección secuencial.
- Para encontrar la carta del medio, puedes dividir el número de cartas entre 2, redondear al entero inferior con [`int`][int] y obtener la carta que ocupa ese índice con [`nth`][nth].
- Usa [`or`][or] para determinar si se cumple alguna de las dos condiciones.

## 6. Más técnicas para calcular medias

- Una forma de obtener las cartas de los índices pares/impares sería aplicar [`map`][map] con una función que use [`nth`][nth] sobre un [`range`][range], que acepta un argumento `step` opcional.

## 7. Reglas de la ronda extra

- Recuerda cómo usar [`if`][if] del ejercicio de condicionales.
- Puedes devolver todos los elementos de una colección menos el último con [`butlast`][butlast].
