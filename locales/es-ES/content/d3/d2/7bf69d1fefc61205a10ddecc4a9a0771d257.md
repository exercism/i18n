# usa la interpolación de string en lugar de la concatenación de string

Usa la [interpolación de string](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) para construir un string de forma dinámica, en lugar de recurrir a la concatenación de string. La principal ventaja es que hay menos «ruido»; mientras que la concatenación de string exige añadir `+` entre cada string, la interpolación de string no tiene esa limitación. Como resultado, el código con interpolación de string suele ser algo más fácil de leer.
