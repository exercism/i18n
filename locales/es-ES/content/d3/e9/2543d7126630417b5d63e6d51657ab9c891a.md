# Instrucciones

El nuevo aeropuerto de Berlín te contrató como desarrollador para su laboratorio de robots.
Tienen unos robots torpes, de aspecto un tanto humanoide, que están intentando usar para mejorar la atención al cliente.

Tu primera tarea en el trabajo es programar el robot para que salude a las personas en su idioma nativo después de que hayan escaneado sus pasaportes en el mostrador de facturación automática.

El robot está orgulloso de sus habilidades, así que siempre dirá primero qué idioma sabe hablar y después saludará a la persona.
Por ejemplo, si alguien escanea un pasaporte alemán, el robot diría:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crea la funcionalidad abstracta de saludo

Necesitas estructurar tu código para que tú y otros desarrolladores podáis añadir idiomas fácilmente.

Como primer paso, define un trait `Greeter` con dos funciones.

- `language_name`, que devuelve el idioma (un `ByteArray`) que el robot usará para saludar al visitante.
- `greet`, que acepta el nombre de un visitante (un `ByteArray`) y devuelve el mensaje de saludo en un idioma concreto (un `ByteArray`).

A continuación, implementa una función `say_hello` que acepte el nombre del visitante y algo que implemente el trait `Greeter`, y que devuelva el saludo deseado (un `ByteArray`).
Por ejemplo, imagina una implementación alemana de `Greeter` en la que `language_name` devuelve `"German"` y `greet` devuelve `"Hallo {name}!"`:

```rust
say_hello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementa el italiano

Ahora haz que el robot funcione para las personas que escaneen pasaportes italianos.

Crea un struct `Italian` e implementa las dos funciones para cumplir con el trait `Greeter` de la tarea 1.
Puedes saludar a alguien en italiano con `"Ciao {name}!"`.

## 3. Implementa el francés

Antes de dar por terminado el día, se supone que debes añadir funcionalidad para saludar a la gente en francés.

Crea un struct `French` e implementa las dos funciones para cumplir con el trait `Greeter`.
Puedes saludar a alguien en francés con `"Bonjour {name}!"`.
