# Acerca de

ColdFusion (CFML) es un lenguaje de scripting de la JVM cuya sintaxis es similar a la de C o JavaScript.
Se compila JIT a código de bytes que se ejecuta en la JVM, pero es dinámico y de tipado flexible, lo que hace que desarrollar con él sea rápido y sencillo.
CF es un lenguaje multiparadigma, compatible con la programación orientada a objetos clásica y la programación funcional.

CFML también incorpora un lenguaje de plantillas basado en etiquetas que lo hace ideal para aplicaciones web.
Se ejecuta en un contenedor J2EE con muchas bibliotecas incluidas que lo hacen muy productivo sin necesidad de instalar muchos paquetes.
CFML tiene soporte nativo para archivos zip, generación de PDF y Excel, correos electrónicos, FTP, HTTP, sistemas de archivos S3, bibliotecas de seguridad ESAPI, controladores JDBC y API JSON y REST.

CFML también puede aprovechar cualquier proyecto Java con solo colocar los jars en el proyecto e instanciar objetos Java directamente en tu código.
Puedes aprender más sobre la sintaxis básica y los tipos de datos de primera clase en esta guía: [Modern ColdFusion (CFML) in 100 Minutes](https://modern-cfml.ortusbooks.com/)
