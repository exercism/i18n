# Pistas

## 1. Encontrar la posición de una carta

- Los índices de los arrays empiezan en `0`.
- Hay un método [integrado][indexof_method_docs] para obtener el índice de un valor dado.

## 2. Determinar si una carta está presente

- Hay un método [integrado][includes_method_docs] para comprobar si el valor está presente en el array.

## 3. Determinar si cada carta es par

- Hay un método [integrado][every_method_docs] para comprobar si cada valor cumple un predicado.

## 4. Comprobar si la pila contiene una carta con valor impar

- Hay un método [integrado][some_method_docs] para comprobar si al menos un valor cumple un predicado.

## 5. Obtener la primera carta impar de la pila

- Hay un método [integrado][find_method_docs] para obtener el primer elemento que cumple un predicado.

## 6. Determinar la posición de la primera carta que sea par

- Hay un método [integrado][findindex_method_docs] para obtener el primer índice del array en el que el valor cumple un predicado.
