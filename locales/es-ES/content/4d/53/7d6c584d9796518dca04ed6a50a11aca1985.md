# Instalación

## Ubuntu (y la mayoría de las demás distribuciones basadas en Debian)

Para compilar código localmente, necesitarás gcc y make, que puedes instalar con

```shell
sudo apt install gcc make
```

Si no trabajas sobre hardware ARM64, instala el emulador [QEMU][] y la cadena de herramientas cruzadas de GCC para ARM64 con

```shell
sudo apt install qemu-user libc6-dev-arm64-cross gcc-aarch64-linux-gnu
```

## Windows

Usa el [Subsistema de Windows para Linux][Windows Subsystem for Linux] con una distribución basada en Debian y sigue las instrucciones de Ubuntu de arriba. Como alternativa, configura una máquina virtual de Linux.

## macOS

Puedes iniciar una máquina virtual de Linux con cualquier solución de virtualización adecuada (por ejemplo, [Lima][]).

[QEMU]: https://www.qemu.org/
[Windows Subsystem for Linux]: https://docs.microsoft.com/en-gb/windows/wsl/about
[Lima]: https://lima-vm.io/
