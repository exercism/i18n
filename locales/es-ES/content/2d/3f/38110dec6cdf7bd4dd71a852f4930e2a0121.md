# Acerca de

Swift proporciona instrucciones de transferencia de control para alterar el flujo de ejecución de los bucles y de las instrucciones switch.
Además de `return`, Swift incluye `continue`, `break`, las etiquetas de bucle y `fallthrough`.

## Continue

La instrucción `continue` le indica a un bucle que deje de ejecutar la iteración actual y que comience de inmediato la siguiente iteración.
En un bucle `while` o `repeat-while`, salta directamente a la comprobación de la condición.
En un bucle `for-in`, avanza al siguiente elemento de la secuencia.

```swift
var count = 1
while count < 6 {
    count += 1
    if count == 4 {
        continue
    }
    print(count)
}

// Prints:
// 2
// 3
// 5
// 6
```

## Break

La instrucción `break` sale de un bucle o de una instrucción switch por completo, de inmediato.
La ejecución se reanuda en la primera línea de código que sigue al bucle o a la instrucción switch.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    if !fruit.count.isMultiple(of: 2) {
        break
    }
    print(fruit)
}

// Prints:
// banana
// grapes
```

## Instrucciones etiquetadas

Cuando los bucles están anidados, puede que quieras que `break` o `continue` afecten a un bucle externo en lugar de al bucle más interno.
Puedes etiquetar un bucle anteponiendo un nombre y dos puntos (`labelName:`).
Después puedes pasar esa etiqueta a `break` o a `continue`:

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
    print("\n--- \(fruit) ---")
    for letter in fruit {
        guard letter != "n" else {
            break outerLoop
        }
        print(letter)
    }
}

// Prints:
// --- banana ---
// b
// a
```

## Fallthrough

En Swift, las instrucciones `switch` no pasan al siguiente caso de forma predeterminada; la ejecución se detiene automáticamente al final del caso que coincide.
Si quieres explícitamente que la ejecución continúe en el siguiente caso sin evaluar su patrón, usa la palabra clave `fallthrough`:

```swift
let value = 1
switch value {
case 1:
    print("One")
    fallthrough
case 2:
    print("Two")
default:
    break
}

// Prints:
// One
// Two
```
