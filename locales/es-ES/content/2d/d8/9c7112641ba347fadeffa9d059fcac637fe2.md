# Anexo a las instrucciones

## Implementación

Define
`type Classification`
para contener los valores de clasificación de los números naturales.
Puedes elegir cualquier representación para este tipo.

Define tres constantes de tipo Classification llamadas

```text
	ClassificationDeficient
	ClassificationPerfect
	ClassificationAbundant
```

Implementa una función llamada Classify que acepte
una entrada de tipo int64 y devuelva una Classification y un valor de error.

Crea un error llamado ErrOnlyPositive
que se devuelve cuando la entrada no es un número entero positivo.
