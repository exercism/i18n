# Instrucciones

Estás ayudando con un censo de aves. Cada día alguien se sienta en un observatorio y cuenta lo que pasa volando, y los recuentos del día llegan como un array.

Las cinco tareas van en la clase `BIRD_SURVEY`.

## 1. El total

Suma el recuento de cada día.

```sather
BIRD_SURVEY::total_seen(|3, 0, 7|)
-- => 10
```

Un censo sin ningún día cuenta cero aves.

## 2. El mejor día

Devuelve el recuento más alto. Si no hubo ningún día, la respuesta es cero.

```sather
BIRD_SURVEY::busiest_day(|3, 0, 7|)
-- => 7
```

## 3. Los días de más actividad

¿Cuántos días tuvieron un recuento por encima de un número?

```sather
BIRD_SURVEY::days_over(|3, 0, 7|, 2)
-- => 2
```

Por encima significa por encima: un recuento de exactamente 2 no cuenta.

## 4. Observatorios que comprobar

El primer día del censo compruebas un observatorio, el segundo día dos, y así sucesivamente. ¿Cuántas comprobaciones de observatorios son en total?

```sather
BIRD_SURVEY::hides_to_check(4)
-- => 10
```

Es decir, 1 + 2 + 3 + 4.

## 5. El primer día de más actividad

¿Qué día fue el primero con un recuento por encima de un número? Los días se numeran desde cero, igual que las posiciones de un array. Si ningún día tuvo tanta actividad, la respuesta es `-1`.

```sather
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 5)
-- => 2
BIRD_SURVEY::first_busy_day(|3, 0, 7|, 9)
-- => -1
```
