# Introducción

## Booleanos

El tipo Boolean en Lua tiene los dos valores booleanos tradicionales: `true` y `false`. Estos valores pueden asignarse a una variable, combinarse con operadores lógicos (`and`, `or`, `not`) y usarse en comprobaciones condicionales (por ejemplo, en estructuras de control).

```lua
local is_true = true
local is_false = false

true and true  --> true
true and false --> false
false or true  --> true
false or false --> false
not false      --> true
not true       --> false

-- prints 0
if is_true == true then
  print(0)
else
  print(1)
end
```

Las comprobaciones condicionales y los operadores lógicos consideran tanto el `false` booleano como `nil` como falsos, y cualquier otra cosa como verdadera.
```lua
1 and 2          --> 2
nil and 2        --> nil
false and 2      --> false
1 or 2           --> 1
false or 'hello' --> "hello"
nil or false     --> false
```

Tanto `and` como `or` utilizan la *evaluación de cortocircuito*, lo que significa que evalúan su segundo operando solo cuando es necesario. Todas las operaciones se evalúan según la [precedencia de operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8), donde `not` se evalúa antes que `and` y `or`.
