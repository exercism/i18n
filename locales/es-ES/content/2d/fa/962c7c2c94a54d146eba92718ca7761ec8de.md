# sin export con nombre

No se ha encontrado [`export %{export.name}`](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export). Las pruebas no pasarán sin él.

Asegúrate de que `%{export.name}` exista y añade `export` delante de él:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
