# Agencia de diseño web

## Historia

Tu empresa de diseño ha estado trabajando principalmente con transformaciones CSS para crear páginas web. Tras debatirlo, se decide
empezar a usar JavaScript para realizar algunos de los cálculos de forma dinámica. Algunos de tus compañeros de equipo tienen menos
experiencia con JavaScript, así que decides usar una clausura de función para crear transformaciones reutilizables para pares de
coordenadas `{x, y}`.

## Tareas

- Crear una función cuyos argumentos se usen como clausura en una función devuelta.

  - Una función para una traslación en 2D, en la que la función externa especifica cuánto hay que trasladar, y la función devuelta acepta una coordenada x, y, y devuelve las coordenadas trasladadas.
  - Una función para un escalado en 2D, en la que la función externa especifica cuánto hay que escalar, y la función devuelta acepta una coordenada x, y, y devuelve las coordenadas trasladadas.
  - Una función que devuelve una función que compone otras dos, es decir, una función para `g(f(x))`

- Crear una función que memoice otra función.
