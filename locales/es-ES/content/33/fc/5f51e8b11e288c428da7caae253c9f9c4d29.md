# Pistas

## General

## 1. Calcula la tasa de producción por hora

- La tasa de éxito se puede determinar mediante una [instrucción condicional][if-else-unless].
- La multiplicación se puede hacer entre instancias de `Integer` y `Float`. El resultado siempre será una instancia de `Float`.
- Los números se pueden comparar con los [operadores de comparación][comparison-operators] integrados.

## 2. Calcula el número de artículos funcionales producidos por minuto

- La clase `Float` implementa un [método][to_i] para devolver una instancia de `Integer`.
- La clase `Integer` implementa un [método][to_f] para devolver una instancia de `Float`.
