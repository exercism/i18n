# Instrucciones

Es la final de temporada en el club local. Llevas la tabla de clasificación en la línea de meta: los corredores cruzan en orden, las calles necesitan rótulos y hay que anotar el registro oficial antes de la siguiente serie.

Los nombres de los corredores llegan en un array, en orden de llegada: el nombre en la posición 0 es el ganador, el de la posición 1 es el segundo, y así sucesivamente.

## 1. Asigna los dorsales

Define `assign-bibs` para que reciba un array de nombres de corredores y devuelva un array de pares `{ position name }`, con la posición primero.

```factor
{ "Bolt" "Comet" "Spirit" } assign-bibs .
! => { { 0 "Bolt" } { 1 "Comet" } { 2 "Spirit" } }
```

## 2. Rótulos de calle

Define `lane-labels` para que reciba un array de nombres de corredores y devuelva cadenas como `"Lane 0: Bolt"`.

```factor
{ "Bolt" "Comet" } lane-labels .
! => { "Lane 0: Bolt" "Lane 1: Comet" }
```

## 3. Etiqueta a los corredores

Define `tag-racers` para que reciba un array de nombres de corredores *y* una cadena de etiqueta, y devuelva rótulos con la forma `"<tag>/<index>: <name>"`. La misma etiqueta va integrada en todos los rótulos.

```factor
{ "Bolt" "Comet" } "Green" tag-racers .
! => { "Green/0: Bolt" "Green/1: Comet" }
```

## 4. Registra las llegadas

Define `record-finishes` para que reciba un array de nombres de corredores y un registro (un vector). Para cada corredor, añade al registro, in situ, una cadena con la forma `"<index>: <name>"`. No devuelve nada.

```factor
V{ } clone   ! a fresh empty ledger
{ "Bolt" "Comet" } over record-finishes
.
! => V{ "0: Bolt" "1: Comet" }
```

## 5. Campanas de vuelta

Define `lap-bells` para que reciba un número `laps` y devuelva una cadena formada por `"ding "` repetido `laps` veces.

```factor
0 lap-bells .   ! => ""
3 lap-bells .   ! => "ding ding ding "
```
