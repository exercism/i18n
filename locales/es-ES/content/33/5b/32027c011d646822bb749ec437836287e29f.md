# Import

La [forma especial `import`][import] te permite usar funciones y macros de un módulo externo sin usar el nombre del módulo.

Importar un módulo externo completo puede crear conflictos con las funciones locales que ya existen. Para evitarlo, tienes dos opciones: `:except` y `:only`. Ambas esperan una lista de palabras clave en la que la clave es el nombre de la función y el valor es la aridad de la función.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```

Normalmente, los imports se añaden al principio de la definición del módulo, pero pueden añadirse en cualquier parte. Tienen scope léxico, lo que significa que un import añadido dentro de la definición de una función no estará disponible en otra función.

Los imports que no se usan provocan advertencias del compilador.

[import]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#import/2
