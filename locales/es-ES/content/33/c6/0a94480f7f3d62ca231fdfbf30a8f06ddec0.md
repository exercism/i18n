# Convertir una variable en const

Plantéate convertir la variable `%{name}` en una `const`, ya que su valor no debe cambiar nunca. Normalmente, los valores `const` se definen a nivel de clase, porque se suelen usar en varios métodos. En este caso, el valor `const` se puede definir dentro del propio método, lo que significa que los demás métodos no pueden usar su valor.
