# Pistas

## General

- Usa `Bitwise` (o div/rem).
- Si usas `Bitwise`, una forma sencilla de ver si un bit concreto está activado es comparar el AND binario (`&&&`) de un conjunto de bits con el patrón de bits concreto que quieres comprobar, y determinar si el resultado es el mismo que el patrón que estás comprobando.
