# Introducción

Un bucle es una forma de llamar repetidamente a una o varias instrucciones agrupadas en un bloque.
Cada ejecución de un bloque de instrucciones se denomina iteración.

## Bucle `while`

Un bucle `while` ejecuta un bloque de instrucciones mientras una expresión booleana situada al principio del bucle es verdadera.
Cuando la expresión booleana es falsa, el bucle deja de ejecutarse y la ejecución continúa con la siguiente línea de código después del bucle.

Si la expresión booleana se evalúa como falsa desde el principio, el bucle `while` no llegará a ejecutarse y la ejecución continuará con la siguiente línea de código después del bucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Es importante que haya una condición que ponga fin al bucle; de lo contrario, se trata de un bucle infinito que bloqueará todo el avance del código.
Si al código anterior se le quitara el `++` de `i`, sería un bucle infinito.

## Bucle `do`

En un bucle `do`, la expresión booleana se comprueba al final del bucle.
Un bucle `do` siempre se ejecuta al menos una vez, como en el siguiente ejemplo:

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un bucle `while`, esto sería más verboso:

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Bucle `for`

A menudo, un bucle actualiza una variable y termina cuando esta alcanza un valor determinado.
Un bucle `for` es una forma de inicializar, actualizar y comprobar una o varias variables en una sola línea entre paréntesis.
La primera sección sirve para inicializar la variable, la segunda para comprobarla y la tercera para actualizar el valor de la variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Esto es menos verboso que el bucle `while` equivalente y, aun así, sigue siendo legible.
