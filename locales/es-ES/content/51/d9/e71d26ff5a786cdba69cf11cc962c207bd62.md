# Instrucciones

Tu tarea es resolver un puzle binario.
Todos los puzles binarios tienen exactamente _una_ solución, que se puede encontrar aplicando estas reglas:

1. Cada casilla debe contener un cero o un uno.
2. No puede haber más de dos dígitos iguales adyacentes. Por lo tanto, si dos casillas adyacentes contienen el mismo dígito, las casillas contiguas a esos dígitos deben contener el otro dígito.
3. Cada fila y cada columna deben contener el mismo número de ceros y de unos.
4. Cada fila y cada columna son únicas.

Recibirás un puzle sin completar en forma de filas de ceros y unos, con marcadores de posición (`_`) para los valores desconocidos.
El objetivo es definir las reglas del puzle binario, que permitirán a los tests averiguar los valores de los marcadores de posición (eso no lo haces tú).
Tu implementación debe usar la [programación lógica con restricciones sobre dominios finitos (CLP(FD))](https://www.swi-prolog.org/man/clpfd.html) de Prolog, que es perfecta para este tipo de tareas.
