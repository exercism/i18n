# Introducción

El módulo `Agent` facilita una abstracción para lanzar [procesos y el _bucle de recepción y envío_][exercism-processes]. A partir de aquí, llamaremos _«procesos agente»_ a los procesos iniciados con el módulo `Agent`. Un _proceso agente_ podría elegirse para representar un estado compartido central.

Para iniciar un _proceso agente_, `Agent` proporciona la función `start/2`. La función que se proporciona al _iniciar_ el _proceso agente_ con `start` devuelve el estado inicial del proceso:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Al igual que `Map` o `List`, `Agent` proporciona muchas funciones para trabajar con _procesos agente_.

Es habitual organizar y encapsular toda la funcionalidad relacionada con `Agent` en un módulo para el dominio que se está modelando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
