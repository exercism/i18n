# Instrucciones

En este ejercicio vas a escribir código para imprimir insignias con el nombre de los empleados de una fábrica.

## 1. Imprime una insignia para un empleado

Los empleados tienen un identificador, un nombre y el nombre de su departamento. 
Las etiquetas de las insignias de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.
Implementa el método `printBadge()` para devolver la etiqueta de la insignia de un empleado:

```kotlin
printBadge(734, "Ernest Johnny Payne", "Strategic Communication")
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

~~~~exercism/note
Ten en cuenta que el departamento debe escribirse en mayúsculas en la etiqueta.
~~~~

## 2. Imprime una insignia para un empleado nuevo

Debido a una peculiaridad del sistema informático, a veces los empleados nuevos todavía no tienen un identificador cuando empiezan a trabajar en la fábrica.
Como las insignias son obligatorias, recibirán una insignia temporal sin el prefijo del identificador. 
Modifica el método `printBadge()` para admitir a los empleados nuevos que todavía no tienen un identificador:

```kotlin
printBadge(null, "Jane Johnson", "Procurement")
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime una insignia para el propietario

Incluso el propietario de la fábrica tiene que llevar una insignia en todo momento.
Sin embargo, el propietario no tiene departamento. 
En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento.
Modifica el método `printBadge()` para imprimir la etiqueta del propietario:

```kotlin
printBadge(254, "Charlotte Hale", null)
// => "[254] - Charlotte Hale - OWNER"
```

~~~~exercism/note
Ten en cuenta que es posible que el propietario sea también un empleado nuevo:

```kotlin
printBadge(null, "Charlotte Hale", null)
// => "Charlotte Hale - OWNER"
```
~~~~
