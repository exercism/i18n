# Acerca de

En Clojure, vincular un valor a un nombre se conoce como una [_var_][vars]. Las vars de nivel superior (globales) son similares a las constantes de otros lenguajes, pero se suelen redefinir para facilitar el desarrollo dinámico.

Las vars de nivel superior se definen con [`def`][def]:

```clojure
(def fingers 10)
```

Puedes usar las funciones del núcleo de [operaciones con números][operators] para hacer cálculos aritméticos con valores.

La macro `defn` sirve para definir una [función][functions] que recibe cero o más argumentos. Una función siempre devuelve el resultado de la última expresión de su cuerpo.

```clojure
(defn add [x y]
  (+ x y))
```

Para invocar una función, escribe su nombre y pasa argumentos para cada uno de sus parámetros.

```clojure
(def five (add 2 3))
```

Las funciones y los valores de Clojure solo se pueden usar _después_ de haberlos definido. Usarlos antes de definirlos da lugar a un error de compilación.

```clojure
;; Compile error as `add` has not yet been defined
(def seven (add 3 4))

(defn add [x y]
  (+ x y))
```

En Clojure, los espacios en blanco no tienen ninguna relevancia salvo la de dar formato.

Las funciones y las vars de Clojure se organizan en espacios de nombres. Un espacio de nombres agrupa funcionalidad relacionada y se define con la macro `ns`:

```clojure
(ns calculator)

(def pi 3.14)

(defn add [x y]
  (+ x y))
```

Clojure admite dos tipos de comentarios. Los comentarios de una sola línea van precedidos de `;`, y la forma `comment` se usa para evitar la evaluación de todo lo que hay entre `(comment` y `)`.
