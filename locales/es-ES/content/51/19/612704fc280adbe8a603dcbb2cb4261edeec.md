# Acerca de

Las secuencias de Factor se presentan en dos variantes cuando necesitas *modificarlas*:

- **Arrays** (`{ … }`) tienen una longitud fija. Puedes cambiar lo que hay *en* cada posición con `set-nth` / `change-nth`, pero no puedes aumentar ni reducir su tamaño.
- **Vectores** (`V{ … }`) tienen longitud variable. `push` añade al final, `pop` elimina y devuelve el último elemento.

```factor
USING: arrays kernel sequences ;

! Fixed-length: build a counter array of zeros, then bump one slot.
3 0 <array>            ! { 0 0 0 }
dup [ 1 + ] 1 rot change-nth
.                      ! { 0 1 0 }

! Variable-length: build a vector of names by pushing.
V{ } clone
"alice" over push
"bob" over push
dup pop drop           ! removes "bob"
.                      ! V{ "alice" }
```

| palabra         | efecto                                         |
|-----------------|------------------------------------------------|
| `<array>`       | `( n elt -- array )`: array de `n` copias de `elt` |
| `<vector>`      | `( n -- vector )`: vector vacío con capacidad `n` |
| `V{ }`          | literal de vector vacío                        |
| `set-nth`       | `( elt n seq -- )`: asigna el elemento en el índice `n` |
| `change-nth`    | `( i seq quot -- )`: aplica `quot` al elemento en `i` |
| `push`          | `( elt seq -- )`: añade a un vector            |
| `suffix!`       | `( seq elt -- seq )`: añade in situ, devuelve el vector |
| `pop`           | `( seq -- elt )`: elimina y devuelve el último elemento |
| `pop*`          | `( seq -- )`: elimina el último, lo descarta   |
| `clone`         | `( obj -- copy )`: copia nueva e independiente |
| `new-sequence`  | `( n exemplar -- newseq )`: secuencia nueva de la misma clase que `exemplar` |
| `new-resizable` | `( n exemplar -- newseq )`: variante redimensionable nueva |

Cuando mutas una secuencia que el llamador ha pasado, el cambio es visible para el llamador: está trabajando con el mismo objeto. Si eso no es lo que quieres, usa `clone` primero para obtener una copia independiente.
