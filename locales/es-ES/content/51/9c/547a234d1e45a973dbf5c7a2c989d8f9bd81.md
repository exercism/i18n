# Instrucciones

En este ejercicio vas a estar jugando con un coche teledirigido, para el que por fin has ahorrado suficiente dinero.

Los coches empiezan con la batería llena (100 %). Cada vez que conduces el coche con el mando a distancia, recorre 20 metros y consume un 1 % de la batería.

El coche teledirigido tiene una moderna pantalla LED que muestra dos datos:

- La distancia total recorrida, mostrada como: `"Driven <METERS> meters"`.
- La carga restante de la batería, mostrada como: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0 %, ya no puedes conducir el coche y la pantalla de la batería mostrará `"Battery empty"`.

Tienes seis tareas, cada una de las cuales trabajará con instancias de coche teledirigido.

## 1. Compra un coche teledirigido nuevo

Implementa el método (_estático_) `RemoteControlCar.Buy()` para que devuelva una instancia nueva de coche teledirigido:

```csharp
RemoteControlCar car = RemoteControlCar.Buy();
```

## 2. Muestra la distancia recorrida

Implementa el método `RemoteControlCar.DistanceDisplay()` para que devuelva la distancia tal como se muestra en la pantalla LED:

```csharp
var car = RemoteControlCar.Buy();
car.DistanceDisplay();
// => "Driven 0 meters"
```

## 3. Muestra el porcentaje de batería

Implementa el método `RemoteControlCar.BatteryDisplay()` para que devuelva el porcentaje de batería tal como se muestra en la pantalla LED:

```csharp
var car = RemoteControlCar.Buy();
car.BatteryDisplay();
// => "Battery at 100%"
```

## 4. Actualiza el número de metros recorridos al conducir

Implementa el método `RemoteControlCar.Drive()` que actualiza el número de metros recorridos:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.DistanceDisplay();
// => "Driven 40 meters"
```

## 5. Actualiza el porcentaje de batería al conducir

Actualiza el método `RemoteControlCar.Drive()` para que actualice el porcentaje de batería:

```csharp
var car = RemoteControlCar.Buy();
car.Drive();
car.Drive();
car.BatteryDisplay();
// => "Battery at 98%"
```

## 6. Impide conducir cuando la batería esté agotada

Actualiza el método `RemoteControlCar.Drive()` para que no aumente la distancia recorrida ni disminuya el porcentaje de batería cuando la batería esté agotada (al 0 %):

```csharp
var car = RemoteControlCar.Buy();

// Drain the battery
// ...

car.DistanceDisplay();
// => "Driven 2000 meters"

car.BatteryDisplay();
// => "Battery empty"
```
