# Operadores de comparación

PHP tiene diez operadores de comparación integrados:

| Nombre  | Ejemplo    | Resultado                                             |
| ----- | ---------- | -------------------------------------------------- |
| Igual | `$a == $b` | true si `$a` es igual a `$b` tras la conversión de tipos. |
| Idéntico | `$a === $b` | true si `$a` es igual a `$b` y del mismo tipo. |
| Distinto | `$a != $b` | true si `$a` no es igual a `$b` tras la conversión de tipos. |
| Distinto | `$a <> $b` | true si `$a` no es igual a `$b` tras la conversión de tipos. |
| No idéntico | `$a !== $b` | true si `$a` no es igual a `$b` o no es del mismo tipo. |
| Menor que | `$a < $b` | true si `$a` es estrictamente menor que `$b`. |
| Mayor que | `$a > $b` | true si `$a` es estrictamente mayor que `$b`. |
| Menor o igual que | `$a <= $b` | true si `$a` es menor o igual que `$b`. |
| Mayor o igual que | `$a >= $b` | true si `$a` es mayor o igual que `$b`. |
| Nave espacial | `$a <=> $b` | devuelve un entero menor que, igual a o mayor que `0`i cuando `$a`. |

PHP tiene definiciones distintas que diferencian entre `equal` e `identical`.
A veces `identical` también se denomina `strictly equal`.

```php
<?php

// Comparisons between integer and numeric string values
1 == "1"; // => true, equal
1 === "1"; // => false, not identical

// Comparisons between integers and floating point values
1 == 1.0; // => true
1 === 1.0; // => false

// Comparisons between object instances
new stdClass() == new stdClass(); // => true, properties are equal
new stdClass() === new stdClass(); // => false, references are not identical
```
