# Pistas

## General

- Lee la documentación oficial de los [rangos][range].

## 1. Define el rango de filas

- Hay un [operador especial][range-creation-operator] para crear rangos.

## 2. Define el rango de columnas

- Hay un [operador especial][range-creation-operator] para crear rangos.
- Hay una [sintaxis especial][unicode-code-points] para escribir el punto de código de un carácter sin conocer explícitamente su valor.

## 3. Transforma el rango de filas en un array de filas

- Los rangos implementan el protocolo `Enumerable`.
- Hay una [función integrada][enum-to-list] para convertir una estructura de datos enumerable en un array.

## 4. Transforma el rango de columnas en un array de columnas

- Los rangos implementan el protocolo `Enumerable`.
- Hay una [función integrada][enum-map] para convertir una estructura de datos enumerable en un array mientras modifica sus elementos.
- La [forma especial bitstring][bitstring-special-form] se puede usar para convertir un punto de código en un string.
