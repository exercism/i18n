# Acerca de

Batch scripting es un lenguaje de scripting que se utiliza principalmente para ejecutar comandos en el Windows Command Prompt (cmd.exe).
Permite a los usuarios automatizar tareas, gestionar archivos y controlar el entorno del sistema mediante una serie de instrucciones de línea de comandos.

Aunque Batch scripting es sencillo, puede encargarse de una amplia variedad de tareas, desde operaciones sencillas con archivos hasta procesos de automatización más complejos.

Los archivos Batch tienen una extensión `.bat` o `.cmd` y pueden ejecutarse directamente con el intérprete de comandos de Windows.

La flexibilidad de Batch scripting lo convierte en una herramienta potente para administradores de sistemas, desarrolladores y usuarios avanzados que necesitan automatizar tareas rutinarias o crear herramientas de línea de comandos personalizadas.
