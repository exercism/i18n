# Introducción

## Comparación

En Go, los números se pueden comparar con los siguientes operadores relacionales y de igualdad.

| Comparación       | Operador  |
| ------------------| --------- |
| igual             | `==`      |
| distinto          | `!=`      |
| menor que         | `<`       |
| menor o igual que | `<=`      |
| mayor que         | `>`       |
| mayor o igual que | `>=`      |

El resultado de la comparación siempre es un valor de tipo Boolean, es decir, o bien `true` o bien `false`.

```go
a := 3

a != 4 // true
a > 5  // false
```

Los operadores de comparación anteriores también se pueden usar para comparar strings.
En ese caso se aplica un orden lexicográfico (de diccionario).
Por ejemplo:

```Go
	"apple" < "banana"  // true
	"apple" > "banana"  // false
```

## Condicionales

Los condicionales en Go son similares a los de otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
Los condicionales se usan a menudo como mecanismos de control de flujo para comprobar distintas condiciones.

Para comprobar un caso concreto se puede usar una sentencia `if`, que ejecuta su código si la condición subyacente es `true`, así:

```go
var value string

if value == "val" {
    return "was val"
}
```

Cuando hay más de un caso, se pueden encadenar varias sentencias `if` con las sentencias `else if` y `else`.

```go
var number int
result := "This number is "

if number > 0 {
    result += "positive"
} else if number < 0 {
    result += "negative"
} else {
    result += "zero"
}
```

Las sentencias `if` también pueden incluir una instrucción de inicialización corta que sirve para inicializar una o varias variables para la sentencia `if`.
Por ejemplo:

```go
num := 7
if v := 2 * num; v > 10 {
    fmt.Println(v)
} else {
    fmt.Println(num)
}
// Output: 14
```

> Nota: cualquier variable creada en la instrucción de inicialización queda fuera de scope cuando termina la sentencia `if`.
