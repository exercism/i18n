# Pistas

## General

- Las palabras de lectura están en [`io`][io]; los constructores de
  flujos de string y `with-string-writer` están en
  [`io.streams.string`][io.streams.string].
- Para la tarea de vaciado del escritor, los locales (`::` y `:>`)
  mantienen el cuerpo legible cuando necesitas tocar el mismo flujo dos
  veces.

## 1. Escúchalo todo

- Una sola palabra: `stream-contents`.

## 2. Cuenta los mensajes

- `stream-lines` divide el flujo en un array de líneas;
  `length` devuelve el número.

## 3. Haz eco de la última llamada

- El mismo `stream-lines` de antes, después `last` y, por último,
  `>upper` (de `ascii`).

## 4. Emite un mensaje

- `stream-write` escribe el mensaje y `stream-flush` lo expulsa.
  El escritor se usa dos veces, así que recurre a los locales `::`:
  `:: broadcast ( message writer -- ) message writer stream-write
  writer stream-flush ;`.

## 5. Captura la salida de una quotation

- Una sola palabra: `with-string-writer`. Añade `inline` después del
  `;` de cierre para que el compilador pueda ver a través del argumento
  quotation: `: capture ( quot -- captured ) with-string-writer ; inline`.
