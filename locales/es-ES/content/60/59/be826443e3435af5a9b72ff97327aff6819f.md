# Tests

Si tienes el binario de phix en tu PATH, introduce el comando:

```bash
p test 
```
Esto ejecutará el archivo de tests (test.exw).

Si el binario de phix no está en el PATH, en Windows introduce

```cmd
\path\to\p.exe test
```

Linux:

```bash
/path/to/p test
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, se ejecutan todos los tests del archivo test.exw.
Para omitir un test, añade dos guiones (el marcador de comentario estándar de Phix) al principio de la línea.

Ten en cuenta que los tests no respetan ningún flag include=false de tests.toml; más bien, es responsabilidad de quien escribe test.exw mantenerlos manualmente en ese archivo para reflejar la realidad en beneficio del sitio de Exercism (por ejemplo, para recopilar estadísticas del track), pero nada en el propio track hace uso alguno de ellos, incluidos concretamente el generador de tests y el ejecutor de tests.
