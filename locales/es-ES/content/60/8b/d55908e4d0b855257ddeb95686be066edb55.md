# Introducción

Un [`Attribute` de C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) ofrece una forma de decorar una declaración para asociarle metadatos: a una clase, un método, una enumeración, un campo, una propiedad o cualquier otra [declaración compatible](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Puedes aplicar un atributo añadiéndolo en la línea anterior a la declaración usando un `ClassAttribute` y un `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Estos metadatos declarativos solo asocian información estructurada adicional al código y no modifican su comportamiento, pero otras partes del código usan esos metadatos para cambiar el comportamiento de su destino o para añadir, cambiar, eliminar o restringir algunas de sus funcionalidades.

Existen muchos [atributos predefinidos y reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por ejemplo: `Flags`, `Obsolete`, `Conditional`; cada uno tiene una función específica que puedes consultar en la documentación de C#. Ten en cuenta que el nombre completo de un atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) es `FlagsAttribute` por convención, pero el sufijo _Attribute_ se puede omitir cuando se aplica a una declaración.
