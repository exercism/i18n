# Consejos

## General

- Lee sobre los [errores][errors] en la guía de introducción.
- Lee sobre [`try`][docs-try] en la documentación.

## 1. Avisa al equipo

- Permite que la función de la operación lance su error.
- Para invocar una función que está en una variable, usa el operador `.`.

## 2. Envuelve el error

- Usa try .. rescue para devolver el resultado deseado.

## 3. Transmite el mensaje

- Usa try .. rescue para devolver el resultado deseado.
- El bloque rescue te permite hacer coincidencia de patrones con el nombre del módulo del error y también vincular el error a una variable.
