# Pistas

## 1. Configura los tipos de usuario y los permisos.

- Para gestionar cada enumerador de `AccountStatus`, podrías usar una instrucción `if`, pero una [instrucción `switch`][switch] es una gran alternativa.


## 2. Asciende a los trolls solo a otros trolls.

- Puedes comparar enumeraciones como cualquier otro tipo con los operadores `!=` y `==`.

## 3. Comprueba los permisos de distintos usuarios.

- Si resuelves la tarea con una instrucción switch, las [caídas][fallthrough] podrían resultarte útiles.
- Puedes usar [etiquetas secuenciales][fallthrough] y la etiqueta [default][switch] para agrupar permisos.

## 4. Concede acceso al juego y empareja a los jugadores.

- Tu principal preocupación son las cuentas `guest` y `troll`; para otras combinaciones no necesitas dividir tu lógica.

## 5. Crea una cola de prioridades.

- Si ordenas correctamente tu enumeración `AccountStatus`, puedes usar `static_cast<int>` para comparar los enumeradores de forma compacta.
