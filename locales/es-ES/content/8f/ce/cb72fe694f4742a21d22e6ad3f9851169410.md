# Instrucciones

En este ejercicio, tienes la tarea de escribir el software de un dispositivo de cifrado que funciona aplicando transformaciones a los datos. Necesitas una forma de crear funciones complicadas de manera flexible combinando funciones más sencillas.

Para cada tarea, devuelve un bloque que se pueda invocar desde el scope que hace la llamada.

## 1. Crea un sumador

Implementa `secret-add`.
Debe devolver una función que recibe un argumento y le suma el argumento que se pasa a `secret-add`.

## 2. Crea un restador

Implementa `secret-subtract`.
Debe devolver una función que recibe un argumento y le resta el secreto que se pasa a `secret-subtract`.

## 3. Crea un multiplicador

Implementa `secret-multiply`.
Debe devolver una función que recibe un argumento y lo multiplica por el secreto que se pasa a `secret-multiply`.

## 4. Crea un divisor

Implementa `secret-divide`.
Debe devolver una función que recibe un argumento y lo divide por el secreto que se pasa a `secret-divide`.

## 5. Crea un combinador de funciones

Implementa `secret-combine`.
Debe devolver una función que recibe un argumento y le aplica, en orden, las dos funciones que se pasan a `secret-combine`.
