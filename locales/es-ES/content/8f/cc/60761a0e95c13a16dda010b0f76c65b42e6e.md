# Permisos de las cuentas del sitio web

## Historia

En este ejercicio comprobarás los permisos de las cuentas de usuario en un foro de internet. El foro admite tres permisos distintos:

- Lectura
- Escritura
- Eliminación

Hay tres tipos de cuentas, cada uno con distintos permisos por defecto:

- Invitados: pueden leer publicaciones.
- Usuarios: pueden leer y escribir publicaciones.
- Moderadores: pueden leer, escribir y eliminar publicaciones.

A veces se modifican permisos concretos; por ejemplo, se le concede a una cuenta de invitado el permiso de escribir publicaciones también.

## Tareas

Estas son tareas de ejemplo que encajan con el ejercicio de permisos del sitio web:

- Obtener los permisos por defecto de un tipo de cuenta
- Conceder un permiso
- Revocar un permiso
- Comprobar un permiso
