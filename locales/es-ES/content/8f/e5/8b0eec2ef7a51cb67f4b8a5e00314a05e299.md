# Incorporación de empleados en la base de datos

## Enunciado del problema

ABC Corp quiere guardar en una base de datos toda la información sobre los pagos de caja chica a sus empleados. Estás ayudando al departamento de finanzas de ABC Corp a implementarlo. Como ABC Corp está ampliando sus operaciones, incorporar al sistema a los empleados recién contratados es una necesidad habitual.

Tu tarea consiste en añadir los datos del nuevo empleado que se te proporcionan a la tabla `Employee` de la base de datos y devolver el valor de la columna `employee_id`, generada automáticamente, sin lanzar otra consulta a la base de datos para averiguarlo. Si se produce un error durante la ejecución, debe devolverse `-1`.

## Detalles de la base de datos

Para este problema, usa la base de datos H2 proporcionada.

> El fichero de base de datos de ejemplo es `gofigure.mv.db` y el nombre de la base de datos es `gofigure`. Se encuentra dentro de la carpeta `db`.

Las siguientes tablas ya están en la base de datos H2 de ejemplo, con algunos datos de muestra. Los nombres de las columnas y sus tipos de datos son los siguientes.

**Nombre de la tabla**: `Employee`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | entero, clave primaria con autoincremento       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | entero        |

**Nombre de la tabla**: `Payment`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | entero, clave primaria con autoincremento       |
| `date`            | fecha        |
| `amount`          | decimal        |
| `employee_id`     | entero        |
| `reason`          | string        |

* El fichero de la base de datos es `gofigure.mv.db`. Usa la URL de JDBC como `jdbc:h2:file:/path/to/db/file`
* Nombre de usuario: `root`
* Contraseña: `root`

## Restricciones

* Usa el fichero de base de datos H2 proporcionado en la carpeta `db` para validar las consultas y el ejemplo de Ballerina
* Usa el enfoque de parámetros de dependencia de Maven para añadir el controlador de base de datos H2 como dependencia de plataforma en tu Ballerina.toml
* No lances otra consulta a la base de datos para averiguar el id generado automáticamente


## Entorno de pruebas

* Puedes ejecutar las pruebas con `bal test`, que las ejecutará contra la base de datos de ejemplo proporcionada.
