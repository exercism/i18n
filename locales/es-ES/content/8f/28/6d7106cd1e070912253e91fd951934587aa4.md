# Introducción

Usar `try..rescue` es una construcción muy potente para capturar errores cuando se producen. Capturar los errores permite que las funciones devuelvan valores definidos cuando es necesario. La construcción `try..rescue` también nos ofrece dos funcionalidades adicionales que podemos aprovechar:

- el bloque `else`
  - Cuando el bloque `try` tiene éxito, el resultado se hace coincidir con este bloque.
- el bloque `after`
  - Tanto si el bloque `try` tiene éxito como si lanza un error, el código del bloque `after` siempre se ejecuta, siempre y cuando el programa siga en ejecución en ese momento.
  - El resultado del bloque `after` no se devuelve al scope que hace la llamada.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
