## Instrucciones

Tu tarea es generar los laberintos perfectos para Mickey y Minerva: aquellos con una sola solución y sin secciones aisladas.
Esto es lo que necesitas saber:

- El laberinto tiene forma rectangular con una abertura al principio y al final.
- El laberinto tiene salas y pasajes, que se cruzan en ángulo recto.
- El programa debe aceptar dos parámetros: rows y columns. El laberinto debe tener entre 5 y 100 celdas de tamaño.
- Un laberinto de `x` columnas de ancho y `y` filas de alto debe tener `2x + 1` caracteres de ancho y `2y + 1` caracteres de alto.
- Si no se proporciona una seed, genera un laberinto aleatorio. Si se proporciona la misma seed varias veces, el laberinto resultante debe ser el mismo cada vez.
- Usa [caracteres de dibujo de cuadros][Box-drawing] para dibujar los muros, y un símbolo de flecha (⇨) para la entrada a la izquierda y la salida a la derecha.

¡Es hora de crear unos laberintos perfectos para estos ratones aventureros!

### Ejemplos

1. El pequeño laberinto cuadrado de 5x5 celdas (u 11x11 caracteres)
```text
	┌───────┬─┐
	│       │ │
	│ ┌─┬── │ │
	│ │ │   │ ⇨
	│ │ │ ──┤ │
	⇨ │ │   │ │
	┌─┤ └── │ │
	│ │     │ │
	│ │ ────┘ │
	│         │
	└─────────┘
```
2. El laberinto rectangular de 6x18 celdas
```text
	┌───────────┬─────────┬───────────┬─┐
	│           │         │           │ │
	│ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
	│ │       │ │ │ │   │     │ │   │   ⇨
	│ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
	│   │ │ │   │   │   │   │ │ │   │   │
	└── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
	⇨   │   │       │ │   │   │ │   │   │
	┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
	│ │   │   │ │ │ │   │   │   │     │ │
	│ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
	│   │       │       │     │     │   │
	└───┴───────┴───────┴─────┴─────┴───┘
```
