# Operador de resolución de scope

El operador de resolución de scope (`::`) nos permite referenciar una clase para acceder a sus constantes de nombre, propiedades estáticas o métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Usar `self` y `static` con el operador de resolución de scope

Puede que un objeto necesite referenciar su propio scope. Para facilitarlo, la palabra clave `self` permite que una clase referencie su propio scope. Usar la palabra clave `self` desvincula la clase de su propio nombre, lo que facilita el mantenimiento del código con el tiempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Usa la palabra clave `static` con el operador de resolución de scope para «vincular de forma tardía» la referencia a la clase descendiente actual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Usar `parent` con el operador de resolución de scope

La palabra clave `parent` se usa para referenciar constantes, propiedades o métodos de la clase padre. Comúnmente se utiliza para llamar al constructor de la clase padre cuando se instancia un objeto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Salvedades

### Visibilidad de constantes, propiedades y métodos

El operador de resolución de scope sigue las reglas establecidas por los modificadores de visibilidad `public`, `private` y `protected`.
