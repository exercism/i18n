# Pistas

## General

- Presta mucha atención a la sintaxis de punteros.
  Vas a usar `*` (operador de desreferencia) y `->` (acceso a miembros a través de un puntero).
- Asegúrate de comprobar los punteros nulos (`nullptr`) cuando sea necesario para no acceder a memoria no válida.
- Puedes ejecutar las pruebas aunque tu código no esté completo; con una estructura básica basta para ver los resultados.
- Todas las funciones que usan las pruebas deben declararse en el fichero de cabecera.
- Si tu programa se bloquea o se comporta de forma inesperada, a menudo se debe a que se desreferencia un puntero nulo.
  Comprueba de nuevo que gestionas `nullptr` correctamente.
- Cuando uses aritmética de punteros, asegúrate de no salirte de los límites del array de sensores.
  Ir más allá de la capacidad del array puede provocar problemas de memoria.

## 1. Comprobar la conexión del sensor (`connection_check`)

- La tarea consiste principalmente en verificar si un puntero es nulo o no.
- Usa el operador de comparación `!=` para comprobar si un puntero es válido.
- Si no tienes claro si estás comprobando el puntero correctamente, piensa en qué representa `nullptr` (la ausencia de una dirección de memoria válida).


## 2. Contar la actividad de los sensores (`activity_counter`)

- Tienes que recorrer el array de sensores.
  En C++, un array puede tratarse como un puntero a su primer elemento.
- Usa aritmética de punteros (`sensor_array + i`) para acceder al sensor en el índice `i`.
- El operador `->` se usa para acceder a un miembro del struct a través de un puntero.

### Ejemplo

```cpp
int sum = (sensor_array + i)->activity; // Access activity using pointer arithmetic
```
