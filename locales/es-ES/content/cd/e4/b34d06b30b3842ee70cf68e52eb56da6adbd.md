# Apéndice de instrucciones

## Pistas

El valor devuelto por `countWords` puede ser cualquier tipo de tabla hash con una clave de tipo `string` y un valor de tipo `int`.

El módulo `tables` implementa las tablas hash (también conocidas como «diccionarios» o «mapas» en otros lenguajes de programación). Consulta la [documentation]

Por ejemplo, `countWords` podría devolver un `TableRef[string, int]`

```nim
proc countWords*(sentence: string): TableRef[string, int] =
  ...
```

[documentation]: https://nim-lang.org/docs/tables.html
