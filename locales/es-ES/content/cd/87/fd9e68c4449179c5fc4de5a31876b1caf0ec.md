# Marcador de posición

## General

- La [función numérica][rand-func] `rand` puede generar números aleatorios.
- La [función numérica][srand-func] `srand` te resultará útil para establecer la semilla de `rand`.

## Generación del laberinto

Puedes usar cualquier algoritmo para generar un laberinto perfecto. El [backtracking recursivo][recursive-backtracker] es una buena opción.

## Caracteres de dibujo de recuadros

| Carácter | Nombre                                  | Unicode |
|:---------:|:--------------------------------------|:--------|
|     ┌     | línea de recuadro hacia abajo y a la derecha     |  U+250C |
|     ─     | línea de recuadro horizontal         |  U+2500 |
|     ┬     | línea de recuadro hacia abajo y horizontal|  U+252C |
|     ┐     | línea de recuadro hacia abajo y a la izquierda      |  U+2510 |
|     │     | línea de recuadro vertical           |  U+2502 |
|     └     | línea de recuadro hacia arriba y a la derecha       |  U+2514 |
|     ┴     | línea de recuadro hacia arriba y horizontal  |  U+2534 |
|     ┘     | línea de recuadro hacia arriba y a la izquierda        |  U+2518 |
|     ├     | línea de recuadro vertical y a la derecha |  U+2520 |
|     ⇨     | flecha blanca hacia la derecha                |  U+21E8 |
