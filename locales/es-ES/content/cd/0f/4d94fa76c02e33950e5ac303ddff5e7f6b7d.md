# Pruebas

Puedes usar el editor en línea del sitio web de Exercism para resolver los ejercicios.
O bien, descarga los ejercicios en tu ordenador, resuélvelos en local y envíalos después a Exercism.

Si quieres trabajar en local, necesitarás el programa [`bats`][bats].
Consulta la página [Pruebas en el track de Bash][test-bash] para obtener las instrucciones de instalación.

[bats]: https://github.com/bats-core/bats-core
[test-bash]: https://exercism.org/docs/tracks/bash/tests
