# Flujo de trabajo de sincronización de etiquetas

El flujo de trabajo de sincronización de etiquetas sincroniza las [etiquetas de GitHub](https://docs.github.com/en/issues/using-labels-and-milestones-to-track-work/managing-labels) de un repositorio con el contenido del fichero `.github/labels.yml`.
Siempre que el fichero `.github/labels.yml` cambie, el flujo de trabajo de sincronización de etiquetas actualizará automáticamente las etiquetas del repositorio.

## Personalizar las etiquetas

Las etiquetas definidas en `.github/labels.yml` se presentan de dos formas:

- Etiquetas compartidas: son las etiquetas que usan _todos_ los repositorios de Exercism, y se definen en el [repositorio org-wide-files](https://github.com/exercism/org-wide-files/blob/main/global-files/.github/labels.yml)
- Etiquetas específicas de un track: se definen en un fichero `.appends/.github/labels.yml`

Para añadir etiquetas específicas de un track, tendrás que añadirlas al fichero `.appends/.github/labels.yml` (consulta [este ejemplo](https://github.com/exercism/python/blob/main/.appends/.github/labels.yml)).
Una vez que hayas fusionado los cambios en `main`, se abrirá automáticamente un pull request para cambiar el fichero `.github/labels.yml`.
Después de fusionar ese PR, las etiquetas se actualizarán automáticamente (consulta la descripción de arriba).

```exercism/caution
No edites nunca manualmente el fichero `.github/labels.yml`, ya que esos cambios se sobrescribirán la próxima vez que se sincronicen las etiquetas.
```

## Origen

El flujo de trabajo se define en el fichero `.github/workflows/sync-labels.yml`.
