# Consejos

## General

## 1. Implementa el método `new()`

- El método `new()` recibe los argumentos con los que queremos crear una instancia de `User`. Debe devolver una instancia de `User` con el nombre, la edad y el peso especificados.

- Consulta [aquí](https://doc.rust-lang.org/book/ch05-01-defining-structs.html) más ejemplos sobre cómo definir e instanciar structs.

## 2. Implementa los métodos getter

- Los métodos `name()`, `age()` y `weight()` son getters. Es decir, se encargan de devolver el campo correspondiente de una instancia de struct.

- Fíjate en que el método `name` devuelve un `&str`, mientras que el campo `name` del struct `User` es un `String`. ¿Cómo podemos hacer que `&str` y `String` se lleven bien entre sí?

- No hace falta usar una instrucción `return` en Rust a menos que quieras explícitamente que una función o un método devuelva antes de tiempo. En caso contrario, es más idiomático aprovechar una devolución _implícita_ omitiendo el punto y coma del resultado que queremos que devuelva una función o un método. No es _incorrecto_ usar una devolución explícita, pero es más limpio aprovechar las devoluciones implícitas cuando sea posible.

```rust
fn foo() -> i32 {
    1
}
```

- Consulta [aquí](https://doc.rust-lang.org/book/ch05-03-method-syntax.html) más ejemplos de cómo definir métodos en structs.

## 3. Implementa los métodos setter

- Los métodos `set_age()` y `set_weight()` son setters, y se encargan de actualizar el campo correspondiente de una instancia de struct con el argumento de entrada.

- Como indican las firmas de estos métodos, los métodos setter no deben devolver nada.
