# uso del signo más para concatenar

En este caso, usar `+` es casi con toda seguridad la opción correcta, ya que es más corto y, a menudo, más rápido para concatenaciones simples. Si no lo conoces, echa un vistazo al potente paquete `fmt`. Es lo que se suele usar para concatenaciones de strings más complicadas y para otras necesidades de formato de strings.
