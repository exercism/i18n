# Anexo a las instrucciones

## Registros

| Registro | Uso          | Tipo            | Descripción                          |
| -------- | ------------ | --------------- | ------------------------------------ |
| `$a0`    | entrada      | dirección       | cadena de dígitos terminada en nulo  |
| `$a1`    | entrada      | número entero   | span                                 |
| `$v0`    | salida       | número entero   | mayor producto de una serie          |
| `$t0-9`  | temporal     | cualquiera      | para almacenamiento temporal         |
