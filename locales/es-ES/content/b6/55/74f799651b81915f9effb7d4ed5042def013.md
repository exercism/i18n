# Pistas

## 1. Preséntate

- La función [`option.unwrap`][unwrap] se puede usar para obtener el valor de una opción, o un valor predeterminado si no hay ninguno.

## 2. Implementa la mecánica de revivir

- Los valores de tipo opción se pueden crear usando los constructores `Some` y `None` del módulo `gleam/option`.

## 3. Implementa la mecánica de lanzar hechizos

- La función [`int.max`][max] se puede usar para asegurarse de que la salud no baje de 0.

[max]: https://hexdocs.pm/gleam_stdlib/gleam/int.html#max
