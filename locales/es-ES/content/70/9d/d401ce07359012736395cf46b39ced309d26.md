# Apéndice de instrucciones

## Registros

| Registro | Uso      | Tipo          | Descripción                          |
| -------- | -------- | ------------- | ------------------------------------ |
| `$a0`    | entrada  | dirección     | array con los pesos de los objetos   |
| `$a1`    | entrada  | dirección     | array con los valores de los objetos |
| `$a2`    | entrada  | número entero | número de objetos                    |
| `$a3`    | entrada  | número entero | peso máximo                          |
| `$v0`    | salida   | número entero | valor máximo                         |
| `$t0-9`  | temporal | cualquiera    | se usa para almacenamiento temporal  |
