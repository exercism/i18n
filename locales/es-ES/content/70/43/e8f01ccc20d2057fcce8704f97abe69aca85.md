# Pruebas

La mayoría de las pruebas comprueban que, al asignar a [result] o al pasar un valor a [exit], devuelves el valor esperado.

Algunas pruebas comprueban que [raise] la excepción esperada.

## Ejecutar las pruebas

La utilidad `make` es una dependencia para ejecutar las pruebas.

Desde el directorio del ejercicio, escribe en una consola/terminal:

```sh
make
```

Si ni siquiera has tocado el fichero de solución del ejercicio, verás un mensaje como:

```
Please implement your solution.
```

Así que elimina esa línea antes de empezar a escribir tu solución.

Por defecto solo se ejecuta la primera prueba.

```text
TAP version 14
1..10
ok 1 - ...
```

Para ejecutar todas las pruebas, escribe:

```sh
make test=all
```

```text
TAP version 14
1..10
ok 1 - empty_sentence
ok 2 - perfect_lower_case
ok 3 - only_lower_case
ok 4 - missing_the_letter_x
ok 5 - missing_the_letter_h
ok 6 - with_underscores
ok 7 - with_numbers
ok 8 - missing_letters_replaced_by_numbers
ok 9 - mixed_case_and_punctuation
ok 10 - am_and_AM_are_26_different_characters_but_not_a_pangram
```

Cuando pasen todas las pruebas, habrás terminado el ejercicio y podrás enviar la solución.

Es posible elegir una sola prueba para ejecutarla pasando el número correspondiente, por ejemplo:

```sh
make test=2
```

solo ejecutaría la segunda prueba.
