# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- La [Groovy Language Documentation](http://docs.groovy-lang.org/docs/latest/html/documentation/)
- La entrada [Groovy Community](http://www.groovy-lang.org/community.html) de la Groovy Language Documentation
- [/r/groovy](https://www.reddit.com/r/groovy) es el subreddit de Groovy.
- [StackOverflow](http://stackoverflow.com/questions/tagged/groovy) te sirve para buscar tu problema y ver si ya se ha respondido antes. También puedes hacer y responder preguntas.
