# Introducción

Common Lisp tiene muchos predicados de igualdad distintos.
Esto lo diferencia de otros lenguajes de programación, que pueden tener solo uno o dos (quizá `==` y `===`, por ejemplo).
Algunos de estos predicados de Common Lisp son específicos de ciertos tipos, mientras que otros son genéricos.
Aquí vamos a ver estos últimos.

Hay cuatro predicados de igualdad genéricos y se diferencian en lo restrictivos que son con lo que consideran «igual».
Son, en orden de más a menos restrictivo: `eq`, `eql`, `equal` y `equalp`.

Un conjunto rápido de definiciones (dejando fuera algunos detalles) es el siguiente:

- `eq`: define la igualdad como que los dos objetos son idénticos.
  _p. ej._:

```lisp
(eq 'a 'a)                 ; => T
(eq (list 1 2) (list 1 2)) ; => NIL
```

- `eql`: define la igualdad como dos números con el mismo tipo y valor, dos caracteres que son iguales o, para cualquier otra cosa, si son `eq`.
  _p. ej._:

```lisp
(eql 1 1)     ; => T
(eql #\a #\a) ; => T
(eql 1 1.0)   ; => NIL
(eql #\a #\A) ; => NIL
```

- `equal`: define la igualdad del siguiente modo: dos listas son `equal` si cada elemento también es `equal`; dos strings son `equal` si cada elemento es `eql`; dos arrays son `equal` si son `eq`; todo lo demás es `equal` si es `eql`.
  _p. ej._:

```lisp
(equal (list 1 2) (list 1 2)) ; => T
(equal #(1 2) #(1 2))         ; => NIL
(equal "foo" "foo")           ; => T
```

- `equalp`: define la igualdad del siguiente modo: los strings y los caracteres se comparan sin distinguir entre mayúsculas y minúsculas; los números se comparan con cierta conversión de tipo; las listas y los arrays son `equalp` si cada elemento también es `equalp`; las estructuras, si son del mismo tipo y todos sus slots son `equalp`; y las tablas hash, si sus claves y sus valores son `equalp`.
  _p. ej._:

```lisp
(equalp "foo" "FoO")                          ; => T
(equalp 3 3.0)                                ; => T
(equalp (make-a-structure :slot1 1 :slot2 2) 
        (make-a-structure :slot1 1 :slot2 2)) ; => T
```
