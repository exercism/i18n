# Introducción

## Conversión de tipos

Go requiere una conversión explícita entre tipos distintos.
La conversión entre tipos (también conocida como **type casting**) se realiza mediante una función con el nombre del tipo al que te quieres convertir.
Por ejemplo, para convertir un `int` en un `float64` tendrías que hacer lo siguiente:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
```

## Conversión entre tipos primitivos y strings

Existe un paquete `strconv` para convertir entre tipos primitivos (como `int`) y `string`.

```go
import "strconv"

var intString string = "42"
var i, err = strconv.Atoi(intString)

var number int = 12
var s string = strconv.Itoa(number)
```

## Aserciones de tipo

Las interfaces de Go pueden introducir ambigüedad sobre el tipo subyacente.
Una aserción de tipo nos permite extraer el valor concreto subyacente de un valor de interfaz con esta sintaxis: `interfaceVariable.(concreteType)`.

Por ejemplo:

```go
var input any = 12
number := input.(int)
```

NOTA: esto provocará un pánico si la variable de interfaz no contiene un valor del tipo concreto.

Podemos comprobar si un valor de interfaz contiene un tipo concreto específico aprovechando los dos valores devueltos de la aserción de tipo: el valor subyacente y un valor booleano que indica si la aserción tuvo éxito.
Por ejemplo:

```go
str, ok := input.(string) // no panic if input is not a string
```

Si `input` contiene un `string`, `str` será el valor subyacente y `ok` será true.
Si `input` no contiene un `string`, `str` será el valor cero del tipo `string` (es decir, `""`, el string vacío) y `ok` será false.
En ningún caso se produce un pánico.

## Type switches

Un **type switch** puede realizar varias aserciones de tipo en serie.
Tiene la misma sintaxis que una aserción de tipo (`interfaceVariable.(concreteType)`), pero `concreteType` se sustituye por la palabra clave `type`.
Aquí tienes un ejemplo:

```go
var i any = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %s\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
