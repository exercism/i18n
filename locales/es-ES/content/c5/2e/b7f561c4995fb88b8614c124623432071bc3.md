# Instrucciones

En este ejercicio vas a generar mensajes de registro semiestructurados.

## Emite mensajes semiestructurados

Empezarás con algunas funciones stub y el siguiente enum:

```rust
#[derive(Drop, Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
    Debug
}
```

Tu objetivo es emitir un mensaje de registro de la siguiente forma: `"[<LEVEL>]: <MESSAGE>"`.
Tendrás que implementar funciones que correspondan a los niveles de registro.

Por ejemplo, el siguiente fragmento muestra una salida esperada para la función `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Y para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

¡Diviértete!
