# Acerca de

En Haxe, un **array** es una colección de elementos (normalmente) del mismo tipo. Hay tres formas de crear un array en Haxe; ya sea con un constructor o con una sintaxis de declaración. En Haxe, el primer elemento de un array tiene un índice cero:

```haxe
var a = [1, 2, 3];
trace(a); // [1,2,3]

// Here the second element is called by index
trace(a[1]); // 2

// The actual first element's index is 0
trace(a[0]); // 1
```

Para crear un array con un constructor, tienes que indicar el tipo de los elementos que va a contener el array:

```haxe
var a:Array<Int> = [0, 1, 2, 3];
a[1] = "Hello"; // Error: the array a takes integers only
```

Como el acceso a los arrays en Haxe no tiene límites, es decir, se garantiza que no lanza una excepción, esto merece una explicación más detallada:

- Si se hace una lectura en un índice que no existe, se devuelve un valor que depende de la plataforma de destino.
- Si se hace una escritura con un índice positivo que queda fuera de los límites, se inserta `null` (o el valor predeterminado para los tipos básicos en destinos estáticos) en todas las posiciones entre el último índice definido y el que se acaba de escribir.
- Si se hace una escritura con un índice negativo, el resultado no está especificado.

Si queremos que un array contenga elementos de varios tipos, añadimos el tipo `Dynamic` al indicador de tipo:

```haxe
var a:Array<Dynamic> = [10, "Bob", true]
```

## Iteración

Los arrays se pueden recorrer con un bucle `for`:

```haxe
var nums = [2, 3, 5];
var sum = 0;
for (num in nums) {
  sum += num;
}
trace(sum); // 10
```
