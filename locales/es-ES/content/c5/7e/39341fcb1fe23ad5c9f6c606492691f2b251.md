# Introducción

Los bucles `for` son el tipo de bucle más complejo en PHP. Se comportan como los bucles `for` de `C`, `Java` y `JavaScript`. Su forma básica es:

```php
for (expr1; expr2; expr3) {
  // statements
}
```

La primera expresión (_expr1_) se evalúa antes de que comience el bucle. La segunda expresión (_expr2_) se evalúa antes de cada iteración; si se evalúa como un valor _truthy_, se ejecutan las instrucciones. Después de ejecutar las instrucciones, se evalúa la tercera expresión (_expr3_).
