# Instrucciones

Tu tarea consiste en convertir descripciones de fechas de entrega en fechas de entrega _reales_, en función de cuándo empezó la reunión.

Hay dos tipos de descripciones de fecha de entrega:

1. Fijas: un conjunto de palabras predefinido.
2. Variables: palabras que tienen un componente variable, pero que siguen un conjunto de patrones predefinido.

## Descripciones de fecha de entrega fijas

Hay tres descripciones de fecha de entrega fijas:

- `"NOW"`
- `"ASAP"` (lo antes posible)
- `"EOW"` (final de la semana)

La siguiente tabla muestra cómo convertirlas:

| Descripción | Inicio de la reunión          | Fecha de entrega                      |
| ----------- | ----------------------------- | ------------------------------------- |
| `"NOW"`     | -                             | Dos horas después de empezar la reunión |
| `"ASAP"`    | Antes de las 13:00            | Hoy a las 17:00                       |
| `"ASAP"`    | A las 13:00 o después         | Mañana a las 13:00                    |
| `"EOW"`     | Lunes, martes o miércoles     | Viernes a las 17:00                   |
| `"EOW"`     | Jueves o viernes              | Domingo a las 20:00                   |

## Descripciones de fecha de entrega variables

Hay dos patrones de descripciones de fecha de entrega variables:

- `"<N>M"` (mes N)
- `"Q<N>"` (trimestre N)

| Descripción | Inicio de la reunión           | Fecha de entrega                                             |
| ----------- | ------------------------------ | ------------------------------------------------------------ |
| `"<N>M"`    | Antes del mes N                | A las 8:00 del _primer_ día laborable del mes N de este año  |
| `"<N>M"`    | En el mes N o después          | A las 8:00 del _primer_ día laborable del mes N del año que viene |
| `"Q<N>"`    | En el trimestre N o antes      | A las 8:00 del _último_ día laborable del trimestre N de este año |
| `"Q<N>"`    | Después del trimestre N        | A las 8:00 del _último_ día laborable del trimestre N del año que viene |

~~~~exercism/note
Un día laborable es lunes, martes, miércoles, jueves o viernes.

Un año tiene cuatro trimestres, cada uno con tres meses:
1. enero/febrero/marzo
2. abril/mayo/junio
3. julio/agosto/septiembre
4. octubre/noviembre/diciembre.
~~~~
