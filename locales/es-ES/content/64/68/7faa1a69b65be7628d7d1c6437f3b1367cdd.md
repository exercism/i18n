# Anexo a las instrucciones

## Implementación

Define una única función de Go, Cost, que calcula el coste para un array dado de libros a partir de los descuentos definidos.

Usa la siguiente firma para la función Cost:

```go
func Cost(books []int) int
```

Cost devolverá el coste total (tras aplicar los descuentos) en centavos.
Por ejemplo, para un solo libro, el coste es de 800 centavos, lo que equivale a 8,00 $.
Para este ejercicio solo se necesitan cálculos con números enteros.
