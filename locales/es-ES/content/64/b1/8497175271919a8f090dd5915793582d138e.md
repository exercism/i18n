# Introducción

## Hora

El concepto de _hora_ se trata en .NET con la estructura `DateTime`. Hay rutinas para convertir entre la hora local y la hora UTC. Se pueden realizar operaciones aritméticas con la ayuda de `TimeSpan`.

## Zona horaria

La clase `TimeZoneInfo` proporciona rutinas para gestionar las diferencias entre zonas horarias. La clase `TimeZoneInfo` también contiene métodos que facilitan el tratamiento del horario de verano.

La clase `CultureInfo` admite formatos de fecha y hora dependientes de la configuración regional.

Para facilitar la programación multiplataforma, la clase `RuntimeInformation` te permite detectar en qué sistema operativo se está ejecutando tu código: Linux, Windows u OSX.
