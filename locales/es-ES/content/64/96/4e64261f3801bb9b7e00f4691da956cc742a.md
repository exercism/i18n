# Descripción

El clásico ejercicio de introducción. Solo tienes que decir «Hello, World!».

«Hello, World!» es el primer programa tradicional para quienes empiezan a programar en un lenguaje o un entorno nuevos.

Los objetivos son sencillos:

- Modifica el código proporcionado para que produzca el string «Hello, World!».
- Ejecuta la suite de tests y asegúrate de que pasa.
- Envía tu solución y compruébala en la web.

Si todo va bien, ya podrás descargar tu primer ejercicio de verdad.
