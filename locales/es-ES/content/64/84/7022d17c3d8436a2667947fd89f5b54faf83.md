# Clases abstractas

Un espectáculo de circo es una lista de actuaciones. Los malabares, el trapecio y las
acrobacias son cosas diferentes por dentro, pero quien arma el orden de las actuaciones
solo necesita dos cosas de cada una: cómo se llama y cuánto dura.

Una **clase abstracta** describe eso y nada más.

```sather
abstract class $ACT is
   name : STR;
   minutes : INT;
end; -- abstract class $ACT
```

Su nombre empieza por `$`. Enumera rutinas sin cuerpo: solo firmas, cada una terminando
en punto y coma. No se puede crear nada a partir de ella: no hay `create` ni `new`.

## Conformidad

Una clase real promete ser `$ACT` escribiendo su nombre después de `<`:

```sather
class JUGGLING < $ACT is

   create : SAME is return new; end;

   name : STR is return "Juggling"; end;

   minutes : INT is return 5; end;

end; -- class JUGGLING
```

`<` se lee «es un». La clase debe proporcionar todas las rutinas que enumera la clase
abstracta, con los mismos argumentos y el mismo tipo devuelto. Dejar una fuera es un
error de compilación, no una sorpresa en tiempo de ejecución.

Una clase puede añadir todo lo demás que quiera. `TRAPEZE` puede tener una altura que no
tiene ninguna otra actuación; a la clase abstracta ni le consta ni le importa.

## Usar el tipo

`$ACT` es un tipo, así que cualquier cosa puede declararse con él:

```sather
   acts : ARRAY{$ACT} := |#JUGGLING, #TRAPEZE(4), #TUMBLING|;
```

Ese array contiene objetos de tres clases diferentes a la vez, cosa que un
`ARRAY{JUGGLING}` no podría.

## Despacho

```sather
   loop
      total := total + acts.elt!.minutes;
   end;
```

`acts.elt!` es `$ACT`. Qué `minutes` se ejecuta se decide cuando se ejecuta la línea,
según lo que el objeto es en realidad: `JUGGLING::minutes` para los malabares,
`TRAPEZE::minutes` para el trapecio. Esa elección se llama **despacho**.

La rutina que hace la suma nunca pregunta qué tipo de actuación tiene. Añadir un cuarto
tipo de actuación significa escribir una clase nueva y no cambiar nada más, que es la
razón de hacerlo así.
