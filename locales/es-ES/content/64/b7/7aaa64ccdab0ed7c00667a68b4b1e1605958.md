# Introducción

## Aleatoriedad

En Elixir, para elegir un elemento aleatorio de una estructura de datos enumerable (por ejemplo, una lista, un rango), usamos `Enum.random`. Esta función elige un único elemento, teniendo cada elemento la misma probabilidad de ser elegido.

Elixir no tiene funciones propias para elegir un número decimal aleatorio. Para hacer eso, tenemos que usar Erlang directamente.

## Bibliotecas de Erlang

El código de Elixir se ejecuta en la máquina virtual BEAM. BEAM es parte del sistema de tiempo de ejecución de Erlang. Inspirado en Erlang y compartiendo su entorno de ejecución, Elixir ofrece una gran interoperabilidad con las bibliotecas de Erlang. Esto significa que los desarrolladores de Elixir pueden usar bibliotecas de Erlang desde dentro de su código Elixir. De hecho, en la comunidad de Elixir se desaconseja escribir bibliotecas de Elixir para funcionalidades que ya proporcionan las bibliotecas de Erlang.

Como resultado, ciertas funcionalidades, como las operaciones matemáticas o las funciones de temporizador, solo están disponibles en Elixir a través de Erlang.

La biblioteca estándar de Erlang está disponible para usarse en nuestro código Elixir sin necesidad de pasos adicionales.

Las funciones de Erlang se pueden llamar de la misma manera en que llamamos a las funciones de Elixir, con una pequeña diferencia. Los nombres de los módulos de Erlang son átomos en `snake_case`. Por ejemplo, para llamar a la función `pi/0` de Erlang desde el módulo `math`, se escribiría:

```elixir
:math.pi()
# => 3.141592653589793
```

Las funciones de Erlang más utilizadas que no tienen un equivalente en Elixir son:

- `:timer.sleep/1`, que suspende un proceso durante la cantidad de milisegundos indicada.
- `:rand.uniform/0`, que genera un número decimal aleatorio `x`, donde `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que proporciona formato de cadenas al estilo de C (usando secuencias de control). Con esta función, podríamos, por ejemplo, imprimir un número entero en cualquier base entre 2 y 36 o formatear un número decimal con la precisión deseada. Ten en cuenta que esta función, como muchas funciones de Erlang, devuelve un charlist.
- El módulo `math`, que proporciona funciones matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` y más.

Para descubrir la biblioteca estándar de Erlang, explora el [Manual de referencia de STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
