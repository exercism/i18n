# Acerca de

`call` es la primitiva universal de «ejecuta esta quotation ahora».
Cuando el compilador puede ver la quotation de forma literal, puede
inferir el efecto; cuando la quotation proviene de una variable, de un
array o de un parámetro, debes declarar el efecto:

```factor
: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .   ! => 2
5 3 [ + ] apply-binary .   ! => 8
```

La declaración `call( a b -- c )` se compila a una comprobación en tiempo
de ejecución de que la quotation tiene realmente el efecto declarado: una
discrepancia se convierte en un error claro en lugar de un estado de pila
corrupto.

Tratar las quotations como datos (apilarlas, meterlas en arrays,
devolverlas desde palabras) es una de las cosas que hace que el código
concatenativo sea tan compacto. Un «programa» puede ser una simple
secuencia, y `each` con `call` basta para interpretarlo.
