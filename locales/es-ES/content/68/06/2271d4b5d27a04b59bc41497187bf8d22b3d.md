# Pistas

## 1. Define el rango de filas y columnas

- Necesitas definir dos [constantes][constants] que contengan un [`Range`][range] de filas y columnas.
- Las filas deben ser un `range` de [`Integer`][integers], del 1 al 8.
- Las columnas deben ser un `Range` de [`String`][string], de 'A' a 'H'.
- La constante debe definirse en el [módulo][module] `Chess`.

## 2. Comprueba si la casilla es válida

- Necesitas comprobar si un valor está dentro de un rango.
- Hay [un método][include] que puedes usar para comprobar si un valor está dentro de un rango.

## 3. Obtén el apodo del jugador

- Puedes obtener un fragmento usando un `Range` como entrada.
- Hay [un método][upcase] que puedes usar para convertir un string a mayúsculas.

## 4. Crea el mensaje del movimiento

- Puedes indexar el string de la casilla para obtener la fila y la columna.
- Puedes usar métodos ya definidos para obtener el apodo del jugador y comprobar si el movimiento es válido.
