# Acerca de

Un [`Attribute` de C#][attribute-concept] ofrece una forma de decorar una declaración para asociarle metadatos: una clase, un método, una enumeración, un campo, una propiedad o cualquier otra declaración [compatible][attribute-targets].

Puedes aplicar [un atributo][attribute] a una declaración añadiéndolo entre corchetes `[]` antes de la declaración; el siguiente ejemplo usa tanto un `ClassAttribute` como un `FieldAttribute`:

```csharp
[Class]
public class MyClass
{
    [Field] public int myField;
}
```

Los metadatos declarativos solo asocian información estructurada adicional al código y no modifican su comportamiento, pero otra parte del código usa esos metadatos para cambiar cómo se comportaría su destino, o para añadir, cambiar, eliminar o restringir algunas de sus funcionalidades.

Existen varios atributos predefinidos, como `Flags`, `Obsolete` y `Conditional`. Ten en cuenta que el nombre completo del [atributo `Flags`][flags-attribute] es `FlagsAttribute`, pero el sufijo «Attribute» se puede omitir al usar el atributo.

Los cuatro atributos predefinidos siguientes se usan con frecuencia:

- `[Flags]`: Predefinido en el espacio de nombres System. Indica que la enumeración admite tanto operaciones bit a bit como el método `Enum.HasFlag()`; además, `ToString` mostraría todas las banderas: [ver ejemplo][flags-example].
- `[Obsolete]`: Predefinido en el espacio de nombres System. Permite añadir un mensaje sobre por qué el código está obsoleto; se puede usar para mostrar advertencias o errores del compilador.
- `[Conditional]`: Predefinido en el espacio de nombres System.Diagnostics. Permite eliminar algunas llamadas a métodos en tiempo de compilación con fines de depuración (diagnóstico).
- `[CallerMemberName]`: Predefinido en el espacio de nombres System.Runtime.CompilerServices. Permite que un método obtenga información sobre quién lo llama.
