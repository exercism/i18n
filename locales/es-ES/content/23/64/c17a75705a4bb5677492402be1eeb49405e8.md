# Acerca de

`jq` es una herramienta para analizar y transformar datos JSON.
`jq` es como `sed` para datos JSON: puedes usarlo para cortar, filtrar, mapear y transformar datos estructurados con la misma facilidad con la que `sed`, `awk`, `grep` y compañía te permiten jugar con el texto.

`jq` es un lenguaje de programación funcional de tipado dinámico.
Todos los valores son inmutables.

Los programas de `jq` están formados por cadenas de «filtros»: cada filtro recibe un único elemento como entrada, actúa sobre él y produce cero o más elementos transformados.
Un «filtro» también puede llamarse «expresión».

La salida (o salidas) de una expresión puede pasarse a otra con el operador `|`.
`expressionA | expressionB` aplica `expressionA` a alguna entrada y, después, `expressionB` se ejecuta repetidamente para cada una de las salidas de `expressionA`.

Se puede hacer referencia explícita a la entrada de una expresión como `.`.
Una expresión que suma `1` a su entrada se escribe así: `. + 1` (o `1 + .`).

## `jq` (el programa) frente a `jq` (el lenguaje)

`jq` es un programa que puedes instalar como paquete en distintos sistemas operativos,
o compilarlo a partir del código fuente (está escrito en C).
Tiene varias [opciones de línea de comandos][cli-options] útiles y es bastante rápido.

El programa `jq` también implementa un _lenguaje_ que permite manipulaciones arbitrariamente complejas de los datos de entrada.

Este track de Exercism se centrará en el lenguaje.
Verás el uso del programa `jq` en los tests.

## JSON

De [json.org][json]:

> JSON (JavaScript Object Notation) es un formato ligero para el intercambio de datos.
> Es fácil de leer y escribir para los humanos.
> Es fácil de analizar y generar para las máquinas.
> Está basado en un subconjunto del lenguaje de programación JavaScript, estándar ECMA-262, 3.ª edición, de diciembre de 1999.
> JSON es un formato de texto completamente independiente del lenguaje, pero que usa convenciones familiares para los programadores de la familia de lenguajes C, incluidos C, C++, C#, Java, JavaScript, Perl, Python y muchos otros.
> Estas propiedades hacen de JSON un lenguaje ideal para el intercambio de datos.

Este track trata sobre `jq`, no sobre JSON.
Supondremos que ya conoces la [sintaxis y los tipos de datos de JSON][wiki-json].
