# Introducción

La herencia es un concepto fundamental en la POO (programación orientada a objetos).
Representa una relación «es-un».
En programación, significa literalmente lo mismo que en inglés: heredar características de un padre (en programación, las características normalmente son funciones y variables).

Considera una clase, `Animal`, como se muestra:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` es una clase padre, porque las propiedades que tiene esta clase se pueden extender a todos los animales en general.

Considera un animal llamado `Lion`, con una clase como la siguiente:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
La anotación `Override` se utiliza para indicar que un método de una subclase está sobrescribiendo un método de su superclase.
No es estrictamente necesario, pero es una buena práctica utilizarla.
~~~~

Ahora, cuando hagamos lo siguiente:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Nota: se inicializa la clase `Animal` con `Lion`.
La salida será algo como:

```java
Lion here!!
```

Según la POO, hay muchos tipos de herencia, pero Java solo admite algunos de ellos (multinivel y jerárquica).
Para leer más sobre esto, consulta [esto][java-inheritance].
