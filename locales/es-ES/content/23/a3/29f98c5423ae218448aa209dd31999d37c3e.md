# Auditoría de pagos en la base de datos

## Enunciado del problema

ABC Corp necesita que cargues todos los datos de la base de datos SQL en una [tabla de Ballerina](https://ballerina.io/learn/by-example/table-syntax/) para procesarlos después. A continuación, tienes que encontrar los nombres de los empleados que tienen registros de pago superiores a una cantidad dada (por ejemplo, 3000,00) consultando la tabla de Ballerina cargada.

**Paso 1:**

Crea una tabla de Ballerina con las siguientes columnas.

`payment_id` - entero

`amount` - número decimal

`employee_name` - string

**Paso 2:**

Rellena la tabla de Ballerina anterior cargando el conjunto de datos completo correspondiente en la base de datos H2. Usa `payment_id` como clave primaria de la tabla.

**Paso 3**

Consulta la tabla de Ballerina usando expresiones de consulta de Ballerina para encontrar los nombres de los empleados que tienen registros de pago superiores a la cantidad dada. Ordena el resultado por el nombre del empleado en orden ascendente. Elimina las entradas de nombres duplicados del resultado antes de devolverlo.

> NOTA: Es obligatorio usar una tabla de Ballerina para implementar la solución.
