# Tests

## Línea de comandos

Puedes usar el siguiente comando para ejecutar los tests desde la línea de comandos:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)'
```

Sustituye `<exercise>` por el nombre del ejercicio que estás implementando.

## Modo interactivo

Para ejecutar Prolog de forma interactiva, primero ejecuta:

```bash
swipl
```

Cuando se inicie la consola de Prolog, carga tu implementación y ejecuta los tests con:

```
?- ["<exercise>.pl"].
?- ["<exercise>_tests.plt"].
?- run_tests.
```

Sustituye `<exercise>` por el nombre del ejercicio que estás implementando.

### Recargar los cambios

Una vez cargados los ficheros anteriores, puedes aplicar los cambios que hayas hecho ejecutando:

```
?- make.
```

## Tests omitidos

Cuando empiezas un ejercicio, solo se ejecuta el primer test. Los demás se han omitido añadiendo `condition(pending)` al objetivo `test`. Cuando el primer test pase, activa el siguiente cambiando `pending` por `true` en `condition(pending)`. Repite esto con cada test hasta que todos se ejecuten y pasen.

### Línea de comandos

Añade el argumento `-- --all` al final del comando para ejecutar también los tests pendientes:

```bash
swipl -f <exercise>.pl -s <exercise>_tests.plt -g run_tests,halt -t 'halt(1)' -- --all
```
