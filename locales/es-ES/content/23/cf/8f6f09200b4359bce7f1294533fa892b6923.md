# Pruebas

Cada ejercicio requiere una configuración inicial que solo hay que hacer una vez y que puede tardar unos minutos:

```
npm install
```

Abre dos terminales y, en la primera, inicia el proceso de compilación.

```
npm start
```

En la segunda, empieza a ejecutar las pruebas.

```
npm test
```

A medida que edites el código, ambos procesos reconstruirán y volverán a ejecutar las pruebas continuamente.
