# Instalación

La forma más sencilla de instalar Ceylon es, simplemente, **no** instalarlo.
Deberías poder resolver la mayoría de los ejercicios con nuestro [IDE web](http://try.ceylon-lang.org/).

No obstante, si lo prefieres, puedes instalar la distribución de línea de comandos. La forma más sencilla de hacerlo es a través de [SDKMAN](http://sdkman.io/), así que primero tendrás que instalarlo si aún no lo tienes y, después, basta con escribir `sdk install ceylon` en tu terminal.

Los usuarios de OSX también pueden instalarlo a través del [gestor de paquetes Homebrew](http://mxcl.github.com/homebrew/).

Las instrucciones de instalación para otras plataformas, así como para el IDE de Ceylon, un plugin para Eclipse, están disponibles en [el sitio oficial](http://ceylon-lang.org/download/).
