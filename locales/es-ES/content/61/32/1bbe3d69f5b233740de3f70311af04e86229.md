# Instrucciones

Mary es una gran fan de la serie de televisión _Star Trek: The Next Generation_.
A menudo juega a juegos de rol de lápiz y papel, en los que ella y sus amigos se hacen pasar por la tripulación de la _Starship Enterprise_.
El personaje de Mary es el capitán Picard, lo que significa que tiene que llevar el cuaderno de bitácora del capitán.
Le encanta la parte creativa del juego, pero no le gusta tener que generar datos aleatorios sobre la marcha.

Ayuda a Mary creando generadores aleatorios para los datos que suelen aparecer en el cuaderno de bitácora del capitán.

~~~~exercism/note
La implementación inicial de este ejercicio recibe una instancia de `java.util.Random` como argumento del constructor.
Esto permite que los tests del ejercicio pasen una instancia con una semilla predefinida, lo que hace que los resultados de los tests sean predecibles.

Por lo tanto, se espera que uses en tu implementación la instancia de `java.util.Random` proporcionada.
~~~~

## 1. Genera un planeta aleatorio

La _Starship Enterprise_ se encuentra con muchos planetas en sus viajes.
Los planetas del universo de Star Trek se dividen en categorías según sus propiedades.
Por ejemplo, la Tierra es un planeta de clase `M`.
Todas las clases planetarias posibles son: `D`, `H`, `J`, `K`, `L`, `M`, `N`, `R`, `T` y `Y`.

Implementa el método `randomPlanetClass()`.
Debe devolver una de las clases planetarias de forma aleatoria.

```java
captainsLog.randomPlanetClass();
// => "K"
```

## 2. Genera un número de registro de nave estelar aleatorio

¡La Enterprise (número de registro `NCC-1701`) no es la única nave estelar que vuela por el espacio!
Cuando se encuentra con otra nave estelar, Mary necesita registrar el número de registro de esa nave.

Los números de registro empiezan por el prefijo «NCC-» y después usan un número del `1000` al `9999` (ambos incluidos).

Implementa el método `randomShipRegistryNumber()` que devuelve un número de registro de nave estelar aleatorio.

```java
captainsLog.randomShipRegistryNumber();
// => "NCC-1947"
```

## 3. Genera una fecha estelar aleatoria

¿De qué sirve un cuaderno de bitácora si no incluye fechas?

Una fecha estelar es un número de coma flotante.
Las aventuras de la _Starship Enterprise_ de la primera temporada de _The Next Generation_ transcurren entre las fechas estelares `41000.0` y `42000.0`.
El «4» corresponde al siglo XXIV y el «1», a la primera temporada.

Implementa el método `randomStardate()` que devuelve un número de coma flotante entre `41000.0` (incluido) y `42000.0` (excluido).

```java
captainsLog.randomStardate();
// => 41458.15721310934
```
