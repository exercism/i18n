# Introducción

[Nil][nil-dictionary] es una palabra inglesa que significa «nada» o «cero».
En Ruby, `nil` se usa para expresar la _ausencia_ de un objeto.
En otros lenguajes de programación, los valores `null` o `none` pueden desempeñar un papel similar.

```ruby
# I do not have a favorite color
favorite_color = nil
```

Ruby asigna a cualquier variable de instancia el valor predeterminado de `nil` la primera vez que se encuentra con ella, hasta que se le asigne otro valor.

[nil-dictionary]: https://www.merriam-webster.com/dictionary/nil
