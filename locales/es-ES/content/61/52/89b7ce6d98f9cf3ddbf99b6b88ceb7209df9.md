# Introducción

## Atributos

Un [`Attribute` de C#](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/) proporciona una forma de decorar una declaración para asociarle metadatos: una clase, un método, una enumeración, un campo, una propiedad o cualquier otra [declaración compatible](https://docs.microsoft.com/en-us/dotnet/csharp/programming-guide/concepts/attributes/#attribute-targets).

Puedes aplicar un atributo añadiéndolo en la línea anterior a la declaración, usando un `ClassAttribute` y un `FieldAttribute`:

```csharp
[Class]
class MyClass
{
    [Field]
    int myField;
}
```

Estos metadatos declarativos solo asocian información estructurada adicional al código y no modifican su comportamiento, pero esos metadatos los usa otra parte del código para cambiar cómo se comporta su destino, o para añadir, cambiar, eliminar o restringir algunas de sus funcionalidades.

Hay muchos [atributos predefinidos y reservados](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/attributes/general#conditional-attribute), por ejemplo: `Flags`, `Obsolete`, `Conditional` y `Experimental`. Cada uno tiene un significado semántico específico que puedes consultar en la documentación de C#. Ten en cuenta que el nombre completo de un atributo como [`Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute) tiene la forma `<Name>Attribute` (por ejemplo, `FlagsAttribute`).

## Enumeraciones de flags

El [tipo `enum` de C#](https://docs.microsoft.com/en-us/dotnet/csharp/language-reference/builtin-types/enum) representa un conjunto fijo de constantes con nombre (una enumeración).

Normalmente, un miembro de un `enum` solo puede referirse exactamente a una de esas constantes con nombre. Sin embargo, a veces es útil referirse a más de una constante. Para ello, se puede anotar el `enum` con el [atributo `Flags`](https://docs.microsoft.com/en-us/dotnet/api/system.flagsattribute).

Una enumeración de flags se puede definir así (usando la notación de enteros binarios `0b`):

```csharp
[Flags]
enum PhoneFeatures
{
    Call = 0b00000001,
    Text = 0b00000010
}
```

Una instancia de `PhoneFeatures` cuyo valor es `0b00000011` tiene establecidos tanto el flag `Call` _como_ el `Text`.

De forma predeterminada, se usa el tipo `int` para los valores de los miembros de la enumeración. Se puede usar un tipo entero diferente especificando el tipo en la declaración del `enum`:

```csharp
[Flags]
enum PhoneFeatures : byte
{
    Call = 0b00000001,
    Text = 0b00000010
}
```
