# Instrucciones

En este ejercicio vamos a simular el primer turno de una partida de [Blackjack][blackjack].

## 1. Calcula el valor de cualquier carta.

Recibirás dos cartas y podrás ver la carta boca arriba del crupier.
Todas las cartas se representan mediante un string como «ace», «king», «three», «two», etc.
Los valores de cada carta son:

| card  | value |  card   | value |
| :---: | :---: | :-----: | :---: |
|  ace  |  11   |  eight  |   8   |
|  two  |   2   |  nine   |   9   |
| three |   3   |   ten   |  10   |
| four  |   4   |  jack   |  10   |
| five  |   5   |  queen  |  10   |
|  six  |   6   |  king   |  10   |
| seven |   7   | _other_ |   0   |

~~~~exercism/note
Normalmente, las cartas «ace» pueden tomar el valor de 1 o de 11, pero, por simplificar, supondremos que solo pueden tomar el valor de 11.
~~~~

Implementa el método `Blackjack.parse_card`, que toma una carta como argumento de tipo string.
El método debe devolver el valor de la carta como número entero.

```Crystal
Blackjack.parse_card("ace")
# => 11
```

## 2. Nombra los rangos de valores.

La puntuación del jugador se tiene que clasificar en rangos de valores.
Las puntuaciones del jugador se calculan sumando los valores de las dos cartas del jugador.
Los rangos que se utilizan son:

|   range   |  value   |
| :-------: | :------: |
|    low    | [4, 11]  |
|    mid    | [12, 16] |
|   high    | [17, 20] |
| blackjack |   [21]   |

Implementa el método `Blackjack.card_range`, que toma dos cartas como argumentos de tipo string.
El método debe devolver el nombre del rango de valores al que pertenecen las dos cartas.

```Crystal
Blackjack.card_range("ten", "king")
# => "high"
```

## 3. Implementa la lógica de decisión para el primer turno.

En función de tus dos cartas y de la carta del crupier, existe una estrategia para el primer turno de la partida, en la que tienes las siguientes opciones:

- Plantarse (S)
- Pedir (H)
- Dividir (P)
- Ganar automáticamente (W)

Aunque todavía no es óptima, vas a seguir la estrategia que tu amigo Alex ha ido desarrollando, que es la siguiente:

- Si tienes una pareja de cartas «ace», siempre debes dividirlas.
- Si tienes un blackjack (dos cartas que suman un valor de 21) y el crupier no tiene un «ace», una figura ni un «ten», ganas automáticamente.
  Si el crupier tiene alguna de esas cartas, tendrás que plantearte y esperar a que se revele la otra carta.
- Si tus cartas suman un valor dentro del rango [17, 20], siempre debes plantearte.
- Si tus cartas suman un valor dentro del rango [12, 16], siempre debes plantearte a menos que el crupier tenga un 7 o más, en cuyo caso siempre debes pedir.
- Si tus cartas suman 11 o menos, siempre debes pedir.

Implementa el método `Blackjack.first_turn`, que toma tres cartas como argumentos de tipo string.
El método debe devolver como string la decisión que debes tomar.

```Crystal
Blackjack.first_turn("ace", "ace", "two")
# => "P"
```
