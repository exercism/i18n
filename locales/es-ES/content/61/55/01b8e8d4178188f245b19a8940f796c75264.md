# Alias

La [forma especial `alias`][alias] te permite acortar o cambiar el nombre con el que haces referencia a un módulo externo. Puedes especificar un nombre personalizado con la opción `:as`.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

Cuando se usa sin argumentos, reduce el nombre del módulo a su última parte, por ejemplo:

```elixir
alias MyApp.Account.User
# is the same as
alias MyApp.Account.User, as: User
```

Puedes agrupar varios alias con `{}`:

```elixir
alias MyApp.Account.{User, EmailValidation}
# is the same as
alias MyApp.Account.User
alias MyApp.Account.EmailValidation
```

Normalmente, los alias se añaden al principio de la definición del módulo, pero pueden añadirse en cualquier parte. Tienen scope léxico, lo que significa que un alias añadido dentro de la definición de una función no estará disponible en otra función.

Los alias sin usar provocan advertencias del compilador.

[alias]: https://hexdocs.pm/elixir/Kernel.SpecialForms.html#alias/2
