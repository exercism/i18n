# Pistas

## General

- El recuento de pájaros por día se guarda en un campo llamado `birdsPerDay`.
- El recuento de pájaros por día es un array que contiene exactamente 7 números enteros.

## 1. Comprueba cuáles fueron los recuentos la semana pasada

- Como guardamos la última semana, solo tenemos que devolver los valores de la última semana.

## 2. Comprueba cuántos pájaros han visitado hoy

- Recuerda que los recuentos están ordenados por día, del más antiguo al más reciente, y el último elemento representa hoy.
- Se puede acceder al último elemento usando su índice (fijo) (recuerda empezar a contar desde cero) o calculando su índice a partir del tamaño del array.

## 3. Incrementa el recuento de hoy

- Asigna al elemento que representa el recuento de hoy el valor del recuento de hoy más 1.

## 4. Comprueba si hubo un día sin pájaros visitantes

- Se puede recorrer el array con un bucle `for`.
- Otra solución es usar la Java Stream Api.

## 5. Calcula el número de pájaros visitantes durante los primeros días

- Se puede usar una variable para guardar el recuento del número de pájaros visitantes.
- Se puede recorrer el array con un bucle `for`.
- La variable se puede actualizar dentro del bucle.
- Recuerda: los arrays se indexan desde `0`.

## 6. Calcula el número de días ajetreados

- Se puede usar una variable para guardar el número de días ajetreados.
- Se puede recorrer el array con un bucle `foreach`.
- La variable se puede actualizar dentro del bucle.
- Se puede usar un condicional dentro del bucle.
