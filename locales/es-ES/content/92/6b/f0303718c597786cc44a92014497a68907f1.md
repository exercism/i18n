# Pistas

## 1. Comprueba que el comando es válido

- Usa la expresión [test][regex-test] para devolver un Boolean.
- Recuerda que puedes usar el argumento [flags][flags] para funcionalidades adicionales, como que no distinga entre mayúsculas y minúsculas.

## 2. Elimina los emojis cifrados

- Gracias a que el cifrado de cada emoji es común, puedes usar `[0-9]` para buscar cualquier dígito después de la palabra `emoji`.
- El carácter `+` coincide con uno o más elementos consecutivos.
- Usa el método [gsub][regex-gsub] para reemplazar cada emoji por un string vacío.

## 3. Comprueba que el número de teléfono es válido

- Este [artículo][phone-validation] explica muy bien distintas formas de validar un número de teléfono.
- Usa el filtro `test` para comprobar si el número de teléfono es válido o no.
- Devuelve la respuesta final con una expresión `if-then-else`.

## 4. Obtén el enlace del sitio web

- Nos centramos en palabras que están unidas por uno o más puntos (`.`).
- Puedes usar el filtro [match][regex-match] con el flag `g`.
- Quizá te resulte más fácil usar el filtro [scan][regex-scan].

## 5. Saluda al usuario

- Usar [grupos de captura con nombre][named-capture] es práctico para reutilizar el texto coincidente.
- El filtro [capture][regex-capture] resulta útil para referirte al grupo con nombre.

## 6. Analiza un CSV muy sencillo

- Aquí queremos usar [split][regex-split] porque conocemos el delimitador.
- El patrón es «una coma seguida de cero o más espacios en blanco».
- Tenemos que usar el filtro `split` de **aridad 2**; no hay ningún flag que especificar.
