# Apéndice de instrucciones

## Responsabilidades de Roc y del host

En el código de Roc, normalmente nos centramos en la lógica de negocio mientras la plataforma se encarga de la concurrencia y del estado compartido.
Por eso, en este ejercicio solo tienes que implementar las operaciones de la cuenta en `BankAccount.roc` sin preocuparte por la concurrencia.
Las cuentas empiezan cerradas, reabrir una cuenta restablece el saldo, y los depósitos y las retiradas deben ser positivos.

## Demostración opcional del servidor

El archivo `bank-account-demo.roc` incluido muestra cómo se puede usar tu implementación en un pequeño servicio web.
Puedes leerlo en el editor, pero es independiente de las pruebas y no forma parte de tu solución.

Para ejecutar la demostración, tienes que [instalar Roc](https://www.roc-lang.org/install/) en tu máquina, instalar la [CLI de Exercism](https://exercism.org/cli-walkthrough) y después ejecutar este comando en una terminal:

```sh
exercism download --exercise=bank-account --track=roc
```

A continuación, implementa `BankAccount.roc` y pruébalo con el siguiente comando (cambia la ubicación de descarga que muestra la CLI si no coincide con la ruta de abajo):

```sh
cd ~/Exercism/roc/bank-account
roc test bank-account-test.roc
```

Cuando pasen todas las pruebas, puedes iniciar el servidor de la demostración con el siguiente comando:

```sh
roc bank-account-demo.roc
```

El servidor usa la [plataforma basic-webserver](https://github.com/roc-lang/basic-webserver) y su compatibilidad integrada con SQLite (Roc descarga la plataforma la primera vez que se ejecuta).
No hace falta un servidor de base de datos aparte.
El servidor escucha en `http://127.0.0.1:8000` y crea `bank-account-demo.db` en tu directorio actual (define `DB_PATH` para usar otro fichero de base de datos).
Detén el servidor con Ctrl-C.
Los datos se conservan entre reinicios.

En otra terminal, puedes llamar al servicio web con `curl` (en Windows, usa `curl.exe` en todos los casos para evitar el alias `curl` de PowerShell).
Por ejemplo, así puedes abrir la cuenta n.º 123, depositar 50, retirar 10 y consultar su saldo:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/open
curl -X POST http://127.0.0.1:8000/accounts/123/deposit/50
curl -X POST http://127.0.0.1:8000/accounts/123/withdraw/10
curl http://127.0.0.1:8000/accounts/123/balance
```

El saldo es `40`.
Los identificadores de cuenta y las cantidades deben ser enteros sin signo.
Las actualizaciones devuelven `OK` si tienen éxito o un error de tu implementación de la cuenta si fallan.
Para cerrar la cuenta n.º 123:

```sh
curl -X POST http://127.0.0.1:8000/accounts/123/close
```

Para probar peticiones concurrentes en Linux/macOS, usa un identificador de cuenta nuevo y envía 100 depósitos desde ocho clientes:

```sh
curl -X POST http://127.0.0.1:8000/accounts/456/open
seq 100 | xargs -P 8 -I '{}' curl --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1
curl http://127.0.0.1:8000/accounts/456/balance
```

En Windows, usa [PowerShell 7+](https://learn.microsoft.com/powershell/scripting/install/installing-powershell-on-windows) para el ejemplo en paralelo:

```powershell
curl.exe -X POST http://127.0.0.1:8000/accounts/456/open
1..100 | ForEach-Object -Parallel { curl.exe --fail --silent --show-error -X POST http://127.0.0.1:8000/accounts/456/deposit/1 } -ThrottleLimit 8
curl.exe http://127.0.0.1:8000/accounts/456/balance
```

Todos los depósitos deberían tener éxito y el saldo debería ser `100`.

## Cómo gestiona la concurrencia la demostración

Cada petición lee la cuenta, llama a tus funciones de Roc y guarda el resultado dentro de una transacción `Immediate` de SQLite.
Las operaciones fallidas se revierten sin modificar la cuenta.
SQLite permite un solo escritor a la vez, lo que evita que las peticiones concurrentes sobrescriban las actualizaciones de las demás (incluso entre cuentas distintas).

Nota: el ejercicio usa `U64`, pero la demostración guarda los saldos como enteros de SQLite y rechaza las actualizaciones que superan el valor máximo de `I64` (`9223372036854775807`).

Para ver un ejemplo de cómo ejecutar cálculos independientes en paralelo, prueba el [ejercicio parallel-letter-frequency](https://exercism.org/tracks/roc/exercises/parallel-letter-frequency).
