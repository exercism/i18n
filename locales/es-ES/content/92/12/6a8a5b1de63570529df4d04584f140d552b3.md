# Anexo a las instrucciones

## El esqueleto

`src/TreeBuilding.hs` ya contiene una solución funcional que pasa todas las pruebas.
Es lenta y difícil de leer; tu tarea es mejorarla sin romper las pruebas.

`buildTree` devuelve `Nothing` cuando los registros no forman un árbol válido.

## Cambiar la representación

Las pruebas nunca usan los constructores de `Tree` directamente.
En su lugar, construyen los árboles esperados con la función

```haskell
node :: Int -> [Tree] -> Tree
```

donde `node i children` es el nodo con id `i` y los hijos indicados, en orden ascendente de id.

Esto significa que puedes cambiar libremente cómo se representa `Tree`, por ejemplo, a

```haskell
import qualified Data.Tree as T

type Tree = T.Tree Int

node :: Int -> [Tree] -> Tree
node = T.Node
```

siempre que `Tree` siga teniendo instancias de `Eq` y `Show` y `node` conserve su significado.
Si usas una biblioteca como `containers`, recuerda añadirla a las `dependencies` de `package.yaml`.
