# Instrucciones

En este ejercicio ayudarás a gestionar las operaciones diarias de una pequeña panadería utilizando las estructuras de control de flujo de Cairo.

## 1. Calcular el total del pedido

Implementa `calculate_total`, que calcula el coste de un pedido según el tipo de bollería y la cantidad:

- Croissant: 3 monedas cada uno
- Muffin: 2 monedas cada uno
- Cookie: 1 moneda cada una

```rust
calculate_total(Pastry::Croissant, 4) // Returns: 12 (4 * 3)
calculate_total(Pastry::Cookie, 10)   // Returns: 10 (10 * 1)
```

## 2. Aplicar descuentos por volumen

Implementa `apply_discount`, que aplica descuentos según el total del pedido.
Aplica el descuento porcentual al total y, a continuación, redondea hacia abajo hasta la moneda entera más cercana (floor).

- Pedidos ≥ 20 monedas: descuento del 10 %
- Pedidos ≥ 10 monedas: descuento del 5 %
- Pedidos < 10 monedas: sin descuento

```rust
apply_discount(25) // Returns: 22
apply_discount(15) // Returns: 14
apply_discount(8)  // Returns: 8
```

## 3. Crear el plan de horneado

Implementa `baking_schedule`, que crea un plan de horneado diario.
La panadería hornea en lotes de 5 pedidos por hora:

```rust
baking_schedule(18) // Returns: [5, 5, 5, 3] (3 full batches + 3 remaining)
baking_schedule(10) // Returns: [5, 5] (2 full batches)
baking_schedule(3)  // Returns: [3] (1 partial batch)
```

Utiliza las estructuras de control de flujo adecuadas (`if`/`else`, `loop`) para resolver cada problema de forma eficiente.
