# Instrucciones

En este ejercicio, tienes que traducir algunas reglas del clásico juego Pac-Man a funciones de Gleam.

Tienes cuatro reglas que traducir, todas relacionadas con los estados del juego.

> No te preocupes por cómo se derivan los argumentos, céntrate en combinar los argumentos para devolver el resultado esperado.

## 1. Define si Pac-Man se come a un fantasma

Define la función `eat_ghost`, que toma dos argumentos (_si Pac-Man tiene activa una píldora de energía_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean que indica si Pac-Man puede comerse a un fantasma. La función debe devolver `True` solo si Pac-Man tiene activa una píldora de energía y está tocando a un fantasma.

```gleam
eat_ghost(False, True)
// -> False
```

## 2. Define si Pac-Man puntúa

Define la función `score`, que toma dos argumentos (_si Pac-Man está tocando una píldora de energía_ y _si Pac-Man está tocando un punto_) y devuelve un valor Boolean que indica si Pac-Man ha puntuado. La función debe devolver `True` si Pac-Man está tocando una píldora de energía o un punto.

```gleam
score(True, True)
// -> True
```

## 3. Define si Pac-Man pierde

Define la función `lose`, que toma dos argumentos (_si Pac-Man tiene activa una píldora de energía_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean que indica si Pac-Man pierde. La función debe devolver `True` si Pac-Man está tocando a un fantasma y no tiene activa una píldora de energía.

```gleam
lose(False, True)
// -> True
```

## 4. Define si Pac-Man gana

Define la función `win`, que toma tres argumentos (_si Pac-Man se ha comido todos los puntos_, _si Pac-Man tiene activa una píldora de energía_ y _si Pac-Man está tocando a un fantasma_) y devuelve un valor Boolean que indica si Pac-Man gana. La función debe devolver `True` si Pac-Man se ha comido todos los puntos y no ha perdido según los argumentos definidos en la parte 3.

```gleam
win(False, True, False)
// -> False
```
