# Introducción

## Definir variables

Definir una variable significa asignar un valor a un nombre. En Scala hay dos tipos de variables: los val y los var.

Un `val` es inmutable, por lo que su valor ya no se puede cambiar después de la primera asignación:

```scala
val numberTen = 10

numberTen = 11
// --> compile error: Reassignment to val numberTen
```

Un `var`, en cambio, se puede reasignar a un nuevo valor del mismo tipo:

```scala
var someNumber = 10

someNumber = 11
// now someNumber has been reassigned
```

Scala es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación. Una variable se puede definir especificando su tipo explícitamente o dejando que el compilador de Scala infiera su tipo a partir del valor asignado (lo que se conoce como inferencia de tipos). Por lo tanto, las dos definiciones de variable siguientes son equivalentes:

```scala
val explicitNumber: Int = 10 // Explicitly typed
val implicitNumber = 10      // Implicitly typed
```

Una vez definida, el tipo de una variable nunca puede cambiar.

```scala
var count = 1 // Assigning an initial value of type Int
count = 2     // Updating to new value is possible, because it is defined as var

count = false
// --> compile error: Found: (false : Boolean), Required: Int
```

## Definir métodos dentro de clases

Scala es un _lenguaje orientado a objetos_ y en este ejercicio los métodos se definen en una _clase_. La palabra clave `class` se utiliza para definir una clase.

```scala
class Calculator
```

Dentro del cuerpo de una clase, que empieza después de dos puntos y está indentado debajo del nombre de la clase, los métodos se pueden definir empezando por la palabra clave `def`, seguida de un nombre. Cada método puede tener cero o más parámetros, que se enumeran separados por comas entre paréntesis. Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros. Después de la lista de parámetros, se define el tipo devuelto del método, separado por otros dos puntos.

A la definición del método le sigue un signo `=` que da comienzo al cuerpo del método. En el siguiente ejemplo, el cuerpo del método consta de dos instrucciones, cada una en su propia línea, indentadas debajo del método.

El método devolverá el valor de la última expresión; en este caso, el método `add` devuelve el valor de la variable `sum`:

```scala
class Calculator:
  // long form
  def add(x: Int, y: Int): Int =
    val sum = x + y
    sum
```

Hay algunas mejoras que se pueden aplicar para acortar ese método y mejorar así su legibilidad:

- como solo se accede a la variable `sum` una vez para devolver el valor, se puede omitir
- un método que consta de una sola expresión se puede escribir en una línea
- el tipo devuelto del método se puede inferir igual que el tipo de las variables

Esto da lugar al siguiente método de una sola línea con la misma funcionalidad:

```scala
class Calculator:
  // shortened form
  def add(x: Int, y: Int) = x + y
```

## Instanciar clases y llamar a métodos

Para invocar un método, primero se crea una instancia de una clase y, después, se llama al método sobre esa instancia con argumentos:

```scala
val calculator = Calculator()
val sum = calculator.add(5, 7)
// sum is of type Int with assigned value of 12
```

## Comentarios

Scala admite dos tipos de comentarios: comentarios de una sola línea y comentarios de varias líneas:

```scala
// this is a single line comment

/*
This comment spans across
multiple lines.
*/
```
