# Instrucciones

Estás en la caseta de radio costera, monitorizando el parloteo del canal: llegan mensajes por el cable, los registras y vuelves a enviar las respuestas. Cinco palabras pequeñas se encargan del trabajo de un turno.

Las pruebas te pasan entradas de `<string-reader>` (tráfico entrante) y usan `<string-writer>` para la salida. Pero todas las palabras que verás aquí funcionan igual contra un `<file-reader>` real o un socket.

## 1. Escúchalo todo

Define `hear-out` para vaciar un flujo de entrada en un solo string.

```factor
"all quiet on the channel" <string-reader> hear-out .
! => "all quiet on the channel"
```

## 2. Cuenta los mensajes

Define `count-messages` para leer todas las líneas de un flujo de entrada y devolver cuántas había.

```factor
"alpha\nbravo\ncharlie\n" <string-reader> count-messages .
! => 3
```

## 3. Repite la última llamada

Define `echo-back` para leer todas las líneas y devolver la **última en mayúsculas**, la respuesta estándar de radio «dijiste X».

```factor
"alpha\nbravo\n" <string-reader> echo-back .
! => "BRAVO"
```

## 4. Difunde un mensaje

Define `broadcast` para escribir un mensaje en un writer dado y vaciar el flujo para que salga de inmediato. No devuelve nada.

```factor
[ "mayday" output-stream get broadcast ] with-string-writer .
! => "mayday"
```

## 5. Captura la salida de una quotation

Define `capture` para ejecutar una quotation con un string-writer nuevo como salida ambiente y devolver lo que haya impreso la quotation. La quotation no acepta ningún argumento: simplemente escribe en el flujo ambiente como siempre.

```factor
[ "test broadcast" print ] capture .
! => "test broadcast\n"
```
