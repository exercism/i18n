# El tipo Boolean

En Cairo, el tipo Boolean es esencial para las operaciones lógicas y las instrucciones condicionales.
Un valor booleano en Cairo ocupa el tamaño de un `felt252`, lo que garantiza un uso eficiente del espacio a la vez que mantiene la sencillez de la lógica de verdadero/falso.

El tipo Boolean en Cairo se especifica con la palabra clave `bool`.
Esto permite declarar y manipular variables booleanas en el lenguaje.
Por ejemplo, fíjate en el siguiente ejemplo:

```rust
fn main() {
    let t = true;
    let f: bool = false; // with explicit type annotation
}
```

En este ejemplo se declaran dos variables booleanas.
La variable `t` se declara de forma implícita como booleana y se le asigna el valor `true`, mientras que la variable `f` lleva la anotación explícita del tipo `bool` y se le asigna el valor `false`.

Un aspecto importante que hay que tener en cuenta es que, al declarar una variable booleana en Cairo, es obligatorio usar como valor los literales `true` o `false`.
Esto significa que los literales enteros, como `0` o `1`, no pueden sustituir a `false` ni a `true`.
La aplicación estricta de esta regla garantiza la seguridad de tipos y evita posibles errores lógicos en el desarrollo de contratos inteligentes.

## Operadores booleanos en Cairo

- `||` (OR lógico): devuelve `true` si al menos uno de los operandos es `true`.
- `&&` (AND lógico): devuelve `true` si ambos operandos son `true`.
- `!` (NOT lógico): devuelve el valor booleano opuesto al operando.

## Código de ejemplo

El siguiente fragmento de código muestra cómo usar los tipos booleanos en Cairo.
Muestra la declaración de variables booleanas, la asignación de expresiones booleanas y el uso de aserciones para verificar que la lógica booleana es correcta:

```rust
fn main() {
    // Declaration of Boolean variables
    let t: bool = true;
    let f: bool = false;

    // Boolean expression evaluation
    let true_expr = 5 == 5; // true
    let false_expr = 7 == 5; // false

    // Using Boolean operators
    let or_expr = t || f; // true || false => true
    let and_expr = t && f; // true && false => false
    let not_expr = !f; // !false => true

    // Assertions to verify the correctness
    assert(t == true_expr, 'this should be true'); // t == true
    assert(f == false_expr, 'this should be false'); // f == false
    assert(or_expr == true, 'this should be true for OR'); // true
    assert(and_expr == false, 'this should be false for AND'); // false
    assert(not_expr == true, 'this should be true for NOT'); // true
}
```
