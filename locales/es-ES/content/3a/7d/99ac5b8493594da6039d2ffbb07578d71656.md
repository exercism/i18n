# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo       | Descripción                          |
| -------- | --------- | ---------- | ------------------------------------ |
| `$a0`    | entrada   | dirección  | color como string terminado en nulo  |
| `$v0`    | salida    | entero     | valor de la resistencia              |
| `$t0-9`  | temporal  | cualquiera | para almacenamiento temporal         |
