# Introducción

En situaciones delicadas para la seguridad (o incluso simplemente en una base de código grande, donde los desarrolladores tienen prioridades e intereses distintos) deberías evitar que se pueda eludir la API pública de una clase aceptando y almacenando los parámetros mutables de un método, o exponiendo un miembro mutable de la clase mediante un valor devuelto o como parámetro `out`.
