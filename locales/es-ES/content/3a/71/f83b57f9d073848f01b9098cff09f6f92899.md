# Introducción

Bombas, válvulas, mangueras: cualquier cosa que retenga un recurso del sistema operativo (un fichero abierto, una conexión de red) tiene que *liberarse* cuando ya no la necesitas. El vocabulario [`destructors`][destructors] de Factor envuelve todo esto en un framework que garantiza la limpieza, incluso cuando un error interrumpe tu código a mitad de camino.

## La clase y el genérico

Una clase se une al framework extendiendo `disposable` e implementando el genérico `dispose*`:

```factor
USING: accessors destructors kernel ;

TUPLE: pump < disposable opened ;

: <pump> ( -- pump )
    pump new-disposable t >>opened ;

M: pump dispose* f >>opened drop ;
```

`new-disposable ( class -- obj )` asigna la tupla *y* la registra en el framework, de modo que una excepción entre la asignación y el siguiente punto seguro no puede filtrar el recurso. El framework garantiza que `dispose*` se ejecuta **como máximo una vez** por objeto, así que las llamadas repetidas a `dispose` no tienen ningún efecto.

## Las llamadas públicas usan `dispose`

```
dispose          ( obj -- )                ! release; safe to call twice
with-disposal    ( disposable quot -- )    ! scope one resource
with-destructors ( quot -- )               ! open a registry scope
&dispose         ( obj -- obj )            ! dispose on normal *or* failure exit
|dispose         ( obj -- obj )            ! dispose only if the scope unwinds
```

`with-disposal` es la forma para un solo recurso: deja el disposable en la pila para la quotation interna y lo libera al salir.

```factor
USING: destructors io ;

<pump> [
    "pumping" print
] with-disposal
! pump released on the way out — even if `print` had thrown
```

Si tienes más de un recurso, abre un scope con `with-destructors` y registra cada adquisición. `&dispose` (el ampersand) significa «libera siempre al salir, tanto si todo va bien como si algo falla». `|dispose` (la barra vertical) significa «libera **solo** si algo falla», lo cual resulta útil cuando el camino de éxito le pasa el recurso a quien vaya a hacerse cargo de él.

```factor
[
    <pump> &dispose
    <pump> &dispose
    ! ... use the pumps ...
] with-destructors
! both pumps released
```

Si solo quieres un try/finally básico sin registro, [`cleanup`][cleanup] (en `continuations`) es la primitiva de más bajo nivel, pero `with-destructors` es el Factor moderno e idiomático.
