# Acerca de

La coincidencia de patrones es el proceso de ramificar en función de si un valor coincide con unos patrones dados, posiblemente profundos. En Haxe, la **coincidencia de patrones** se hace usando la expresión `switch` y expresiones `case` individuales.

Considera esta estructura de datos:

```haxe
enum Tree<T> {
  Leaf(v:T);
  Node(l:Tree<T>, r:Tree<T>);
}
```

- Los patrones siempre se comparan de arriba abajo.
- La expresión del patrón que esté más arriba y coincida con el valor de entrada es la que se ejecuta.
- Un patrón `_` coincide con cualquier cosa, así que `case _:` equivale a `default:`

## Coincidencia de enumeraciones

Las enumeraciones se pueden comparar por su constructor de forma natural:

```haxe
var myTree = Node(Leaf("foo"), Node(Leaf("bar"), Leaf("foobar")));

var match = switch (myTree) {
  // Matches any Leaf
  case Leaf(_):
    "0";

  // Matches any Node that has r = Leaf
  case Node(_, Leaf(_)):
    "1";

  // Matches any Node that has
  // r = another Node which has
  // l = Leaf("bar")
  case Node(_, Node(Leaf("bar", _))):
    "2";

  // Matches anything
  case _:
    "3";
}

trace(match); // 2
```
