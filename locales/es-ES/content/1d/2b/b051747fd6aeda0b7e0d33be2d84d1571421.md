# Anexo a las instrucciones

## Formato de salida

Devuelve la letra como un string terminado en nulo.

## Registros

| Registro | Uso           | Tipo    | Descripción                        |
| -------- | ------------- | ------- | ---------------------------------- |
| `$a0`    | entrada       | entero  | botellas iniciales                 |
| `$a1`    | entrada       | entero  | quitar                             |
| `$a2`    | entrada/salida | dirección | string de salida terminado en nulo |
| `$t0-9`  | temporal      | cualquiera | para almacenamiento temporal    |
