# Pistas

## 1. Obtener los permisos predeterminados para un tipo de cuenta

- Define el enum `Permission` con valores para los siguientes tipos de permiso: `None`, `Read`, `Write` y `Delete`.
- Usar las flags del enum permitiría usar operaciones bit a bit directamente con el enum `Permission`, [consulta `enum` `Flags`][docs-enum-flags].
- El miembro `All` del enum se puede definir como una combinación de los miembros `Read`, `Write` y `Delete` del enum.
- Define el enum `AccountType` con valores para los siguientes tipos de cuenta: `Guest`, `User` y `Moderator`.
- Para gestionar cada tipo de cuenta, se podría usar una instrucción `if`, pero la [instrucción `switch`][docs.microsoft.com-switch-keyword] es una gran alternativa.
- Combinar flags significa poner un bit concreto a `1` usando uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 2. Conceder un permiso

- Combinar flags significa poner un bit concreto a `1` usando uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 3. Revocar un permiso

- Quitar una flag significa poner un bit concreto a `0` usando una combinación de dos [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].

## 4. Comprobar un permiso

- Comprobar un permiso se puede hacer comprobando el resultado de aplicar uno de los [operadores bit a bit][docs.microsoft.com-bitwise-and-shift-operators].
