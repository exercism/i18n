# Anexo a las instrucciones

## Salida

En este ejercicio vas a implementar un verbo que genera el triángulo de Pascal hasta un número de filas dado. La salida de tu verbo puede tener uno de estos dos formatos:

  1. Como un array de arrays encajados, donde cada array representa una fila del triángulo de Pascal.
  1. Como una tabla, donde los números están alineados a la derecha y los ceros rellenan los espacios vacíos de la izquierda.

### Salida de ejemplo

Aquí tienes dos salidas válidas para `pascal 3`:

  - Como un array de arrays encajados:
```j
  (1 ; 1 1 ; 1 2 1) -: pascal 3          NB. This test will pass
```
  - Como una tabla con relleno:
```j
  (3 3$1 0 0 1 1 0 1 2 1) -: pascal 3   NB. This test also passes
```
