# Acerca de

Lo más importante que hay que recordar sobre las cadenas de caracteres de Java es que son objetos inmutables que representan texto como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).
Las comillas dobles se usan para definir una instancia de `String`:

```java
String fruit = "Apple";
```

La manipulación de un string se puede hacer usando los métodos de la clase [`String`][string-class].
Como los valores de tipo string nunca pueden cambiar después de haberse definido, todos los métodos de manipulación de strings devolverán un nuevo string.

Un string está delimitado por caracteres de comilla doble (`"`).
Algunos caracteres especiales necesitan escaparse usando el carácter de barra invertida (`\`).
Caracteres que hay que escapar en Java:

- `"`
- `\`

```java
String escaped = "c:\\test.txt";
// => c:\test.txt
```

Por último, hay muchas formas de concatenar un string.
La más sencilla es el operador `+`:

```java
String name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para cualquier formato de string más complejo que una simple concatenación, es preferible el método `String.format`.

```java
String name = "Jane";
String.format("Hello %s!",name);
// => "Hello Jane!"
```

Otras posibilidades son:

- usar la [clase `StringBuilder`][string-builder]
- usar el [método `String.concat`][string-concat]
