# Instrucciones

La kata del diamante toma como entrada una letra y la muestra con forma de diamante. Dada una letra, imprime un diamante que empieza por la 'A', con la letra indicada en el punto más ancho.

## Requisitos

* La primera fila contiene una 'A'.
* La última fila contiene una 'A'.
* Todas las filas, excepto la primera y la última, tienen exactamente dos letras idénticas.
* Todas las filas tienen tantos espacios finales como iniciales. (Pueden ser 0).
* El diamante es simétrico horizontalmente.
* El diamante es simétrico verticalmente.
* El diamante tiene forma cuadrada (la anchura es igual a la altura).
* Las letras forman una figura con forma de diamante.
* La mitad superior tiene las letras en orden ascendente.
* La mitad inferior tiene las letras en orden descendente.
* Las cuatro esquinas (que contienen los espacios) son triángulos.

## Ejemplos

En los siguientes ejemplos, los espacios se indican con el carácter `·`.

Diamante para la letra 'A':

```text
A
```

Diamante para la letra 'C':

```text
··A··
·B·B·
C···C
·B·B·
··A··
```

Diamante para la letra 'E':

```text
····A····
···B·B···
··C···C··
·D·····D·
E·······E
·D·····D·
··C···C··
···B·B···
····A····
```
