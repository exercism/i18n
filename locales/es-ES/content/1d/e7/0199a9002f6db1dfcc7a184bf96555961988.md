## Instrucciones condicionales

Las instrucciones condicionales son instrucciones que toman decisiones: pueden ejecutar efectos secundarios o controlar el flujo de ejecución de un programa.
Entre las instrucciones condicionales se incluyen `if`, `if/else`, `switch` y `ternary`.

Las instrucciones condicionales sirven para hacer preguntas sobre un valor o sobre la relación entre varios valores.
La pregunta se evalúa y da como resultado una respuesta Boolean, pero la propia instrucción `if` puede devolver cualquier valor o simplemente ejecutar un efecto secundario.

## La instrucción `if`

La instrucción `if` más simple evalúa una expresión y ejecuta una línea.
La expresión que se evalúa siempre va entre paréntesis.

Puede ejecutar un efecto secundario

```c
if (count > 10)
    printf("count is greater than 10");
```

o puede cambiar el flujo de ejecución


```c
if (count > 10)
    return sum;
```

Si una instrucción `if` ejecuta más de una línea, debe encerrarlas entre llaves

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algunos equipos de desarrollo pueden establecer como norma que las instrucciones `if` usen siempre llaves, incluso para una sola línea.


## `if` / `else`

Una instrucción `if` se puede combinar con un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if` / `else if`


`else` se puede combinar con otro `if` para crear lo que se conoce como `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


A veces, una `if-else-if ladder` se puede representar mejor con un `switch`.
Igual que con `if`, la expresión que se evalúa siempre se pone entre paréntesis.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

El caso `default` se ejecuta si el valor que se evalúa no coincide con ninguno de los casos anteriores.

Si un caso de `switch` no devuelve nada, normalmente se inserta un `break` para terminar cada caso; de lo contrario, la lógica «cae» al siguiente caso.
A veces, dejar que un caso caiga al siguiente se hace de forma intencionada

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Cuando un caso cae al siguiente sin querer, es un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Un `switch` puede resultar útil cuando se compara con valores concretos en lugar de con un rango de valores.
Puede ser más rápido que una `if-else-if ladder`, porque es posible que el compilador pueda optimizar la instrucción `switch` de formas que no puede aplicar a una escalera.
A veces, un `switch` puede resultar más legible que una escalera.

## El operador ternario (también llamado condicional)

El operador ternario es una instrucción condicional de tres partes que se usa a menudo para asignar un valor.
La expresión que se va a evaluar va antes del signo de interrogación y no tiene por qué ir entre paréntesis.
El valor que se devuelve si la condición es verdadera va antes de los dos puntos, y el que se devuelve si es falsa, después.
Se puede devolver un literal o una variable.

```c
int i = j > 5 ? 5: j;
```

Los operadores ternarios se pueden anidar para reducir el ruido sintáctico.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```

## Comparaciones condicionales con números de coma flotante

Debido a cómo se implementan los números de coma flotante, una operación matemática sencilla puede dar lugar a un error de redondeo que haga que una comprobación de igualdad no devuelva el resultado esperado.

```c
    a = 1.345f;
    b = 1.123f;
    c = a + b;
    // c may equal something like 2.4679999352
    if (c == 2.468)
        return "I won the lottery!";
```

Se puede usar un valor de tolerancia, conocido como `epsilon`, para determinar un rango en el que un valor puede situarse y seguir considerándose igual al compararlo con otro valor.
Algunas plataformas incluyen constantes propias para el epsilon de float y de double.
Consulta la documentación de tu compilador para obtener más información.
Calcular el epsilon puede ser complejo y puede variar de una plataforma a otra, incluso entre máquinas individuales.
Aquí tienes un programa de ejemplo que usa una comparación sencilla.

```c
#include <stdio.h>
#include <math.h>
#include <stdbool.h>

const double MY_EPSILON = .002;

bool same(double x, double y)
{
    return fabs(x - y) < MY_EPSILON;
}

int main()
{
    // Same should return true if the difference is less than MY_EPSILON
    printf("%s\n", same(1.1, 1.099) ? "true" : "false"); // prints true
    printf("%s\n", same(1.1, 1.098) ? "true" : "false"); // prints false
    return 0;
}
```

¡Ten cuidado al comparar `float`s o `double`s por igualdad!
