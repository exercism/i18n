# Instalar Emacs

Como Emacs Lisp (elisp) es el lenguaje de extensión de Emacs, primero tendrás que instalar [GNU Emacs](http://www.gnu.org/software/emacs/).

Se recomienda instalar la versión más reciente de Emacs, pero la 28.1 o superior debería considerarse la implementación objetivo de los ejercicios.
Si ya tienes Emacs instalado, puedes comprobar la versión de Emacs con `M-x emacs-version RET`.

## En OS X
La forma más sencilla es visitar [Emacs For Mac OS X](http://emacsformacosx.com/) y descargar el dmg, que instalará GNU Emacs como una aplicación empaquetada de OS X.

Existen alternativas, como Aquamacs (no recomendado) o instalarlo mediante [Homebrew](https://formulae.brew.sh/formula/emacs), si lo prefieres.

## En Linux
En algunas distribuciones, Emacs ya viene instalado, ya que forma parte de GNU.

### Ubuntu
La forma recomendada actualmente para instalar la versión más reciente de Emacs es mediante [snap](https://snapcraft.io/emacs):

```
sudo snap install emacs --classic
```

Si no quieres usar snap, también puedes instalar Emacs mediante snap, pero la versión disponible en los repositorios de Ubuntu suele estar desactualizada.
Si quieres instalar una versión más reciente de Emacs mediante apt, tendrás que usar un [PPA](https://launchpad.net/ubuntu/+ppas?name_filter=emacs) o [compilarlo desde el código fuente](https://www.emacswiki.org/emacs/BuildingEmacs).

Si no te importa instalar la última versión, debería bastar con

```
sudo apt-get install emacs
```

### Arch
Arch normalmente incluye la última versión de Emacs, así que ejecuta:

```
sudo pacman -S emacs
```

y ya deberías estar listo.

### Otras distribuciones
Consulta con tu distribución qué versión está disponible actualmente y usa tu gestor de paquetes o compila desde el código fuente según corresponda.

### Windows
Para instalar Emacs en Windows, ve al [espejo de archivo FTP](https://ftpmirror.gnu.org/emacs/windows) más cercano, descarga el instalador (=emacs-XX.X-installer.exe=) y ejecútalo.
Si no quieres usar Emacs sin instalarlo, puedes descargar el archivo con el patrón =emacs-XX.x.zip=, descomprimirlo y ejecutar `bin\runemacs.exe`.

Si usas [MSYS2](https://www.msys2.org/), puedes instalar la compilación de 64 bits de Emacs con

```
pacman -S mingw-w64-x86_64-emacs
```

o la compilación de 32 bits con

```
pacman -S mingw-w64-i686-emacs
```
