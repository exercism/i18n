# Pistas

## 1. Lee direcciones de correo electrónico de un fichero

- Puedes usar la [función `simplifile.read`][file-read] para leer el contenido de un fichero.

## 2. Crea un fichero de registro para escribir en él

- Puedes usar la [función `simplifile.create_file`][file-create] para crear un fichero vacío.

## 3. Registra un correo enviado

- Puedes usar la [función `simplifile.append`][file-append] para añadir texto a un fichero.

## 5. Envía el boletín

- Todas las operaciones necesarias con ficheros ya se han implementado en los pasos anteriores.
- Puedes usar la [función `result.try`][result-try] y la [función `list.try_each`][list-try-each] para trabajar con el tipo `Result`.
