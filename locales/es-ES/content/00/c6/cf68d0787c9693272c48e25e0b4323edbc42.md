# Introducción

Las tuplas son una forma ligera de agrupar un conjunto fijo de tipos de datos arbitrarios. Una tupla no tiene un nombre concreto; dar nombre a una estructura de datos la convierte en un `struct`. Los campos de una tupla no tienen nombres; se accede a ellos mediante desestructuración o por posición.

## Sintaxis

### Creación

Las tuplas siempre se crean con una expresión de tupla:

```rust
// pointless but legal
let unit = ();
// single element
let single_element = ("note the comma",);
// two element
let two_element = (123, "elements can be of differing types");
```

Las tuplas pueden tener un número arbitrario de elementos.

### Acceso por desestructuración

Es posible acceder a los elementos de una tupla mediante desestructuración. Esto significa simplemente asignar nombres de variables a los elementos individuales de la tupla, consumiéndola.

```rust
let (elem1, _elem2) = two_element;
assert_eq!(elem1, 123);
```

### Acceso por posición

También es posible acceder a los elementos de una tupla mediante un índice numérico posicional. La indexación, como siempre, empieza en 0.

```rust
let notation = single_element.0;
assert_eq!(notation, "note the comma");
```

## Estructuras de tupla

También se te pedirá que trabajes con estructuras de tupla. Al igual que las estructuras normales, son tipos con nombre; a diferencia de las estructuras normales, tienen campos anónimos. Su sintaxis es muy similar a la sintaxis normal de las tuplas. Es legal usar tanto la desestructuración como el acceso por posición.

```rust
struct TupleStruct(u8, i32);
let my_tuple_struct = TupleStruct(123, -321);
let neg = my_tuple_struct.1;
let TupleStruct(byte, _) = my_tuple_struct;
assert_eq!(neg, -321);
assert_eq!(byte, 123);
```

### Visibilidad de los campos

Todos los campos de las tuplas anónimas son siempre públicos. Sin embargo, los campos de las estructuras de tupla tienen visibilidad individual, que por defecto es privada, al igual que los campos de las estructuras estándar. Puedes hacer que los campos sean públicos con el modificador `pub`, igual que en una estructura estándar.

```rust
// fails due to private fields
mod tuple { pub struct TupleStruct(u8, i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```

```rust
// succeeds: fields are public
mod tuple { pub struct TupleStruct(pub u8, pub i32); }
fn main() { let _my_tuple_struct = tuple::TupleStruct(123, -321); }
```
