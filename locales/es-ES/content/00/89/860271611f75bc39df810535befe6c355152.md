# Sustituir los comentarios de plantilla

Sustituye los comentarios de plantilla por una descripción breve, pero útil, del paquete, y una o dos frases que expliquen qué hace la función, qué parámetros recibe y qué devuelve.
Unos comentarios precisos y útiles sobre cómo usar el código son muy importantes para los desarrolladores de Go.
Esta es una gran guía para escribir buenos comentarios: [Effective Go: Commentary](https://golang.org/doc/effective_go.html#commentary).
La herramienta `godoc` genera documentación a partir de los comentarios del código de forma automática, cuando se ejecuta.
Consulta [godoc.org](https://godoc.org) para ver ejemplos de cómo queda esto.
