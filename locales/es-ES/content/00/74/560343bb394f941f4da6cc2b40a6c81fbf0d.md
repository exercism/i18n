# Instrucciones

Convierte un número octal, representado como un string (por ejemplo, '1735263'), a su equivalente decimal partiendo de los principios básicos (es decir, no, no puedes usar bibliotecas internas ni externas para hacer la conversión).

Implementa la conversión de octal a decimal.
Dado un string de entrada en octal, tu programa debe producir una salida decimal.

## Nota

- Implementa tú mismo la conversión.
  No uses otra cosa que haga la conversión por ti.
- Trata la entrada no válida como un 0 octal.

## Sobre el octal (base 8)

El decimal es un sistema en base 10.

Un número como 233 en notación de base 10 puede entenderse
como una combinación lineal de potencias de 10:

- El dígito más a la derecha se multiplica por 10^0 = 1
- El siguiente se multiplica por 10^1 = 10
- ...
- El n-ésimo número se multiplica por 10^_(n-1)_.
- Todos estos valores se suman.

Entonces:

```text
   233 # decimal
 = 2*10^2 + 3*10^1 + 3*10^0
 = 2*100  + 3*10   + 3*1
```

El octal es similar, pero usa potencias de 8 en lugar de potencias de 10.

Entonces:

```text
   233 # octal
 = 2*8^2 + 3*8^1 + 3*8^0
 = 2*64  + 3*8   + 3*1
 = 128   + 24    + 3
 = 155
```
