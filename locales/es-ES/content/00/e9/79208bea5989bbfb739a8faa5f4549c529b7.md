# Pistas

Tu código debe contener una función frequency :: Int -> [Text] -> Map Char Int
que reciba un número de trabajadores para usar en paralelo y una lista de
textos, y que devuelva la frecuencia total de cada letra del texto.

## Benchmark

Comprueba cómo afecta al rendimiento de tu solución cambiar el número de
trabajadores ejecutando el benchmark. Usa `stack bench` para ejecutarlo. No dudes
en modificar `bench/Benchmark.hs` para explorar el rendimiento de tu solución con
distintas entradas.
