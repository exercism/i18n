# Introducción

Common Lisp tiene un concepto, The Printer, que incluye todas las funciones para escribir representaciones textuales de datos de Lisp. Una de esas funciones es `format`, que permite al programador dar formato a los datos como quiera.

Las capacidades de `format` y del Printer de Lisp en general son un tema amplio; aquí se describirán los conceptos básicos del uso de `format`.

## La función FORMAT

La función `format` toma al menos dos argumentos: un stream en el que imprimir y un string de control que define qué y cómo se debe imprimir.

Los streams son un concepto propio y se describirán en otro lugar. Pero por ahora todo lo que hay que saber es que la impresión se hace en el stream y que hay dos valores especiales para este argumento: `t` y `nil`. `t` significa imprimir en la salida estándar (en realidad, el stream al que está ligada la variable `*standard-output*`), y `nil` significa crear un string y devolverlo.

Fíjate en que `format` siempre se evaluará a `nil`, excepto en ese último caso, en el que se especifica `nil` como stream. Esta es una forma habitual de hacer una simple interpolación o construcción de strings.

```lisp
(format nil "hello world") ; => "hello world"
(format t "hello world")   ; => NIL (but "hello world" is printed to standard output)
```

## Directivas de formato

El string de control puede contener «directivas de formato», que dan instrucciones a `format` sobre qué imprimir y cómo interpretar cualquier otro parámetro que se le pase. En cierto sentido, el string de control es un programa que `format` interpretará y ejecutará. Todas las directivas empiezan por `~` y van seguidas de un carácter (_p. ej._, `~A`, `~D`, `~&`). El uso de mayúsculas o minúsculas en el carácter da igual.

La mayoría de las directivas de formato simplemente interpolarán un argumento de `format` en la salida. Se dice que «consumen» el argumento. Algunas directivas no consumen argumentos, o consumen más de uno. Una directiva incluso te permite saltar de un lado a otro en la lista de argumentos u omitir argumentos.

## Formato básico

Una directiva de formato muy versátil es `~A`. Imprime una versión «legible para humanos» de los datos.

```lisp
(format nil "Value = ~a" 10)                ; => "10"
(format nil "hello ~a" "world")             ; => "hello world"
(format nil "The list is: ~A" (list 1 2 3)) ; => "The list is: (1 2 3)"
```

Otra directiva de formato útil es `~S`. Imprime una versión «legible para máquinas» de los datos. Puede resultar muy útil si quieres poder interpretar la salida creada como datos de Lisp. Para muchas cosas se verá igual que `~A`, pero fíjate en que, por ejemplo, en el caso de los strings la salida incluirá las comillas (escapadas cuando se incluyan dentro de otro string), de modo que el valor pueda volver a leerse como el parámetro string.

```lisp
(format nil "~s" 10)            ; => "10"
(format nil "~s" "hello world") ; => "\"hello world\""
(format nil "~s" (list 1 2 3))  ; => "(1 2 3)"
```

Otras dos directivas muy útiles son `~%` y `~&`. La primera emite un carácter de nueva línea, mientras que la segunda emite una «fresh line». La diferencia es que `~%` siempre emite una nueva línea, mientras que `~&` la emitirá si actualmente no se está al principio de una línea. Ninguna de las dos consume un argumento.

```lisp
(format nil "~%new~%lines") ; => "
                                  new
                                  lines"

(format nil "~&new~&lines"  ; => "new
                                  lines"
```

Por último, `~~` es una directiva sencilla que emite un `~` literal.
