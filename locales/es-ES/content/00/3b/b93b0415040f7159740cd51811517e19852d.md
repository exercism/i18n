# Pruebas

Para usar el ejecutor de pruebas, necesitarás tener [Godot instalado][installation] correctamente.

## Ejecutar las pruebas

El [ejecutor de pruebas][test runner] se usa para cargar y probar soluciones.
Para ejecutar el ejecutor de pruebas, descárgalo localmente y luego usa `godot` para ejecutarlo.
En el futuro, el ejecutor de pruebas se descargará automáticamente junto con los ejercicios cuando uses `exercism download`.

### Descargar el ejecutor de pruebas

El siguiente fragmento de shell sirve para descargar el ejecutor de pruebas.

```bash
exercism download --track gdscript --exercise hello-world
cd "$(exercism workspace)/gdscript"
curl --remote-name https://raw.githubusercontent.com/exercism/gdscript-test-runner/refs/heads/main/bin/test_runner.gd
```

### Ejecutar el ejecutor de pruebas

El ejecutor de pruebas se ejecuta con `godot` en modo headless (sin IDE).
`-s` o `--script` le indica a Godot que ejecute el script del ejecutor de pruebas.
El ejecutor de pruebas espera dos argumentos: el slug y la ruta al directorio de la solución.

```bash
godot --headless -s to/test_runner.gd -- <solution-slug> <path/to/solution>
```

Por ejemplo,

```bash
godot --headless -s "$(exercism workspace)/gdscript/test_runner.gd" -- hello-world "$(exercism workspace)/gdscript/hello-world
```
