# Acerca de

Las funciones en Elixir pueden despacharse dinámicamente.

Todos los nombres de módulo son átomos. Todos los nombres de módulo de Elixir reciben automáticamente el prefijo `Elixir.` al compilarse.

```elixir
is_atom(Enum)
# => true
Enum == Elixir.Enum
# => true
```

Elixir puede resolver una función que se llamará en tiempo de ejecución, usando el nombre del módulo para hacer una búsqueda. La búsqueda puede hacerse dinámicamente si el nombre del módulo está vinculado a una variable.

```elixir
defmodule MyModule do
  def message(), do: "My message"
end

atom = MyModule
atom.message()
# => "My message"
```
