# Introducción

Una *expresión regular* (regex) es un patrón pequeño que describe cómo debería ser un texto. Las herramientas de regex de Factor se encuentran en el vocabulario [`regexp`][regexp], y un patrón se escribe entre `R/ ` y `/`.

La mayoría de los caracteres de un patrón se representan a sí mismos. Unas pocas piezas especiales representan *tipos* de carácter o *cuántos* esperar:

```
\d        ! any digit 0–9
\s        ! any whitespace; \S means any non-whitespace
[A-Z]     ! any one capital letter
.         ! any single character

{4}       ! exactly 4 times       +   ! one or more
{2,5}     ! 2 to 5 times          *   ! zero or more
?         ! optional (0 or 1)
```

Así, `R/ [A-Z]{2}-\d{4}/` significa «dos mayúsculas, un guion, cuatro dígitos».

`matches?` comprueba si un *string completo* encaja con el patrón:

```
matches? ( string regexp -- ? )
```

```factor
USING: regexp ;

"NS-1024" R/ [A-Z]{2}-\d{4}/ matches? .   ! => t
"NS-10"   R/ [A-Z]{2}-\d{4}/ matches? .   ! => f
```

Otras palabras buscan *dentro* de un string: `all-matching-subseqs` devuelve todas las coincidencias, `count-matches` las cuenta, `re-contains?` indica si hay alguna coincidencia, y `re-replace` sustituye cada coincidencia por un texto nuevo:

```
all-matching-subseqs ( string regexp -- seq )
count-matches        ( string regexp -- n )
re-contains?         ( string regexp -- ? )
re-replace           ( string regexp replacement -- result )
```

```factor
USING: regexp ;

"seen NS-1024 then AB-0007" R/ [A-Z]{2}-\d{4}/ all-matching-subseqs .
! => { "NS-1024" "AB-0007" }

"user=alice pass=hunter2" R/ pass=\S+/ "pass=****" re-replace .
! => "user=alice pass=****"
```

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
