# Fundamentos

Un programa Sather se compone de **clases**. Una clase es una caja con nombre que contiene rutinas. Una **rutina** es un fragmento de trabajo con nombre que produce una respuesta.

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

end; -- class GREETER
```

Si lo leemos de arriba abajo:

- `class GREETER is` abre la caja y le da nombre. Los nombres de las clases se escriben con mayúsculas.
- `hello : STR is` inicia una rutina llamada `hello` que produce un `STR`, un fragmento de texto al que llamamos *cadena de caracteres*. El `: STR` es una promesa sobre qué tipo de respuesta devuelve.
- `return "Hello!";` devuelve la respuesta. El texto se escribe entre comillas dobles.
- `end;` cierra la rutina, y el segundo `end;` cierra la clase.

Todo lo que hay después de `--` en una línea es un **comentario**. Sather lo ignora; está ahí para las personas.

```sather
-- This line is for the reader, not the computer.
```

Para usar una rutina desde otro sitio, escribe el nombre de la clase, dos dos puntos y el nombre de la rutina:

```sather
GREETER::hello        -- this is "Hello!"
```

Dentro de la misma clase puedes omitir el nombre de la clase:

```sather
class GREETER is

   hello : STR is
      return "Hello!";
   end;

   greeting_again : STR is
      return hello;      -- calls the routine just above
   end;

end; -- class GREETER
```

Una rutina que no recibe argumentos se llama sin paréntesis: `hello`, no `hello()`.
