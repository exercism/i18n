# Acerca de

Un [`list`][list] es una colección mutable de elementos en _secuencia_.
 Como la mayoría de las colecciones (_consulta las incorporadas [`tuple`][tuple], [`dict`][dict] y [`set`][set]_), los arrays pueden contener referencias a cualquier tipo o tipos de datos, incluidas otras arrays.
 Se consideran una [secuencia][sequence type] en Python y pueden copiarse total o parcialmente mediante la [notación de rebanadas][slice notation].
Como cualquier secuencia, los elementos dentro de `lists` pueden referenciarse mediante un número de `0-based index` desde la izquierda, o de `-1-based index` desde la derecha.

Los arrays admiten tanto las [operaciones comunes de secuencia][common sequence operations] como las [operaciones de secuencia mutables][mutable sequence operations], tales como `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` y `<list>.reverse()`.
 Se puede iterar sobre los elementos con la construcción `for item in <list>`, y con `for index, item in enumerate(<list>)` cuando se necesitan tanto el elemento como su índice.

Python proporciona muchos [métodos][list-methods] útiles para trabajar con arrays.

 Como los arrays son mutables, los métodos de array **alteran el objeto array original** que se pasa al método.
Si no queremos mutarlo, hay que hacer una `shallow copy` (_como mínimo_) del `list` original mediante `slice` o `<list>.copy()`.


## Añadir elementos

Añadir elementos al final de un array existente puede hacerse con `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

En lugar de _añadir al final_, `<list>.insert(<index>, <item>)` añade el elemento a un _índice concreto_ dentro del array.
`<index>` es el índice del elemento _delante del cual_ quieres que aparezca el nuevo elemento.
`<item>` es el elemento que se va a insertar.

**Nota**: Si `<index>` es 0, el elemento se añadirá al principio del array.
Si `<index>` es mayor que el último índice del array, el elemento se añadirá en la última posición, lo que equivale a usar `<list>.append(<item>)`.

```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```

Se puede _combinar_ un `iterable` con un array existente (concatenando los dos) mediante `<list>.extend(<iterable>)`.
`<list>.extend(<iterable>)` _desempaqueta_ el iterable proporcionado y añade sus elementos en el mismo orden al final del array de destino.
Usar `<list>.append(<item>)` en esta situación añadiría todo el iterable como un _**único elemento**_.


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]
```


## Eliminar elementos

`<list>.remove(<item>)` puede usarse para eliminar un elemento del array.
 `<list>.remove(<item>)` lanzará un `ValueError` si el elemento no está presente en el array.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError.
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```

Como alternativa, usar el método `<list>.pop(<index>)` elimina **y** devuelve con `return` un elemento para poder usarlo.

`<list>.pop(<index>)` acepta un parámetro opcional: el `index` del elemento que se va a eliminar y devolver.
Si no se especifica el argumento opcional `<index>`, se eliminará y devolverá el último elemento del array.
Si `<index>` es un número mayor que el último índice del array, se lanzará un `IndexError`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.pop(0)
1

>>> numbers
[2, 3]
>>> numbers.pop()
3

>>> numbers
[2]

# This will throw an error because there is only index 0.
>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Todos los elementos pueden eliminarse de un `list` con `<list>.clear()`. No acepta ningún parámetro.


```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```


## Invertir y reordenar

El orden de los elementos del array puede invertirse _**in situ**_ con `<list>.reverse()`. Esto mutará el array original.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```

Un array puede reordenarse _**in situ**_ con la ayuda de [`<list>.sort()`][sort].
El orden predeterminado es _ascendente_ desde la izquierda.
La documentación de Python ofrece [consejos y técnicas adicionales para ordenar][sorting how to].

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Para ordenar un array en orden _descendente_, pasa un argumento `reverse=True` al método:


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```


Cuando no se desee mutar el `list` original, pueden usarse las funciones incorporadas [`sorted()`][sorted] y [`reversed()`][reversed].
 `sorted(<list>)` devuelve una _copia_ ordenada y acepta los mismos parámetros que `<list>.sort()`.
 `reversed(<list>)` devuelve un _iterador_ que produce los elementos del array en orden inverso.
 `Iterators` se tratará en detalle en otro ejercicio.


## Apariciones de un elemento en un array

Para encontrar el número de apariciones de un elemento en un array puede usarse `<list>.count(<item>)`.
 Devuelve el número total de veces que `<item>` aparece como elemento del array.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```


## Encontrar el índice de los elementos

`<list>.index(<item>)` devuelve el número de índice de la _primera aparición_ de un elemento dado.
 Si no hay ninguna aparición, se lanza un `ValueError`.
 La indexación es `0-based` desde la izquierda, lo que significa que la posición del primer elemento es el índice `0`.
 También se admite la indexación desde la derecha, empezando por el índice `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]
>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

Proporcionar los índices `start` y `end` busca dentro de una sección concreta del array:


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]
>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```

Si no se necesita la posición exacta de un elemento, el operador incorporado `in` es más eficiente para verificar la pertenencia.


```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> "Thomas" in names
True
```


## Hacer copias

Recuerda que las variables en Python son nombres que apuntan a objetos subyacentes.
 Los nombres pueden vincularse o revincularse a distintos objetos a lo largo de la vida de un programa.
 Asignar un objeto `list` a un nuevo _**nombre**_ de variable no copia el objeto ni ninguno de sus datos referenciados.
 El nombre nuevo y el antiguo apuntarán ambos al mismo objeto `list`.
 Además, los arrays son objetos de tipo _contenedor_: para ahorrar espacio, los contenedores solo guardan _referencias_ a los elementos que contienen, no los elementos en sí.
 Esta «optimización» puede tener consecuencias inesperadas para quien no está atento.

`<list>.copy()` crea un nuevo objeto `list`, pero **no** crea nuevos objetos para los _elementos_ referenciados del array: la copia es «superficial».
 Una `shallow copy` suele bastar cuando quieres añadir o eliminar elementos de uno de los objetos `list` sin modificar el otro.
 Pero si existe alguna posibilidad de que los _elementos subyacentes_ de un `list` se muten por accidente (_mutando con ello todas las copias superficiales relacionadas_), debe usarse [`copy.deepcopy()`][deepcopy] del módulo `copy` para crear una copia completa, o «profunda», de **todas** las referencias y los objetos.

Para una explicación detallada del comportamiento de los nombres, los valores, los arrays y los arrays anidados, echa un vistazo a esta excelente entrada de blog de [Ned Batchelder][ned batchelder]: [Names and values: making a game board][names and values].
 [Shallow vs Deep Copying of Python Objects][shallow vs deep] también ofrece un buen resumen de las consideraciones sobre las copias.
