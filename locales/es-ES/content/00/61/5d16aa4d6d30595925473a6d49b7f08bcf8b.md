# Instrucciones

Todos los arneses del circo tienen una carga nominal en kilogramos, y nadie sube hasta que se hayan comprobado los números.

La clase `SAFETY_HARNESS` necesita lo siguiente. El esqueleto te da la clase y su atributo; añade el resto. Cada rutina de abajo lleva un contrato, y las pistas dicen cuál.

## 1. Monta un arnés

`create` recibe la carga para la que está clasificado el arnés y devuelve un arnés.
Una carga nominal de cero o menos no es un arnés en absoluto, así que eso es un `pre`.

```sather
harness ::= #SAFETY_HARNESS(120);
harness.limit
-- => 120
```

## 2. ¿Cuánto sobra?

`spare_capacity` recibe la carga que soporta el arnés y devuelve cuánto más podría
soportar. La carga no puede ser negativa ni superar el límite; ambas cosas son `pre`.
La respuesta nunca es negativa, lo cual es un `post`.

```sather
harness.spare_capacity(40)
-- => 80
```

## 3. ¿Cómo de lleno está?

`percent_used` recibe la carga y la devuelve como porcentaje del límite,
redondeado hacia abajo. La carga no puede ser negativa, y la respuesta nunca es
negativa.

```sather
harness.percent_used(60)
-- => 50
```

## 4. ¿Es seguro?

`is_safe` recibe la carga y responde si está dentro del límite. Se puede preguntar
por cualquier carga, incluso por una absurda, así que no hay ningún `pre` sobre la
carga, pero escribe un `post` que diga que la respuesta es verdadera exactamente
cuando la carga está dentro del límite.

```sather
harness.is_safe(200)
-- => false
```
