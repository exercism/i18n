# Introducción

A veces necesitas ver una secuencia como una serie de *piezas* en lugar de elemento por elemento. Los vocabularios [`grouping`][grouping], [`splitting`][splitting] y [`splitting.monotonic`][splitting.monotonic] te dan cuatro formas de hacerlo.

## `group`: fragmentos disjuntos de tamaño *n*

```
group ( seq n -- groups )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }
```

Si la longitud de la secuencia no es múltiplo de *n*, el grupo final es más corto que *n*.

## `clump`: ventana deslizante solapada de tamaño *n*

```
clump ( seq n -- clumps )
```

```factor
USING: grouping ;

{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }
```

Si la secuencia es más corta que *n*, el resultado está vacío.

## `split-when`: corta donde se active un predicado

```
split-when ( seq quot: ( elt -- ? ) -- pieces )
```

```factor
USING: splitting ;

{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }
```

Cada elemento recibe su propia llamada al predicado; los elementos verdaderos son los *puntos de corte* y no se conservan en el resultado.

## `monotonic-split`: corta las rachas cuando falla una comprobación de pares adyacentes

```
monotonic-split ( seq quot: ( a b -- ? ) -- pieces )
```

```factor
USING: splitting.monotonic ;

{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

El predicado se ejecuta sobre *pares adyacentes*. Mientras devuelve un valor verdadero, la racha continúa; cuando devuelve `f`, empieza una nueva pieza. Con `[ = ]` obtienes rachas de elementos iguales; con `[ <= ]` obtienes rachas no decrecientes; y así sucesivamente.

## Cuándo recurrir a cada uno

- **`group`/`clump`**: conoces el *tamaño* que quieres.
- **`split-when`**: sabes cómo es un *elemento de corte*.
- **`monotonic-split`**: sabes qué hace que dos elementos adyacentes *sigan perteneciendo juntos*.
