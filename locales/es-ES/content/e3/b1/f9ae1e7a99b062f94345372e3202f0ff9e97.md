# Instrucciones

Cerca de aquí hay una tienda de electrodomésticos llamada «Tech Palace».
El dueño de la tienda ha instalado hace poco una gran pantalla para mostrar mensajes publicitarios y para dar un saludo especial cuando los clientes escanean sus llamadas tarjetas de fidelización en la entrada.
La pantalla consta de muchas luces LED pequeñas y puede mostrar varias líneas de texto.

El dueño de la tienda necesita tu ayuda con el código que se usa para generar el texto de la nueva pantalla.

## 1. Crea el mensaje de bienvenida

Para la mayoría de los clientes que escanean sus tarjetas de fidelización, el dueño de la tienda quiere ver `Welcome to the Tech Palace, ` seguido del nombre del cliente en mayúsculas en la pantalla.

Implementa la función `welcome`, que acepta el nombre del cliente y devuelve como string el mensaje deseado.

```julia-repl
julia> welcome("Judy")
"Welcome to the Tech Palace, JUDY"
```

## 2. Añade un borde llamativo

Para los clientes fieles que compran mucho en la tienda, el dueño quiere que la pantalla de bienvenida sea más llamativa añadiendo una línea de estrellas antes y después del mensaje de bienvenida.
Todavía no tienen claro cuántas estrellas debe haber en las líneas, así que quieren que ese número sea configurable.

Escribe una función `add_border` que acepte un mensaje de bienvenida y el número de estrellas por línea como argumentos.
Debe devolver un string formado por 3 líneas: una línea con el número de estrellas deseado, después el mensaje de bienvenida tal como se pasó y, por último, otra línea de estrellas.

```julia-repl
julia> add_border("Welcome!", 10)
"**********\nWelcome!\n**********"
```

## 3. Limpia los mensajes publicitarios antiguos

Antes de instalar esta nueva pantalla, la tienda tenía una pantalla similar que solo podía mostrar líneas estáticas no configurables.
Al dueño le gustaría reutilizar algunos de los mensajes publicitarios antiguos en la nueva pantalla.
Sin embargo, los datos ya incluyen algunos espacios en blanco desafortunados que se usaban para alinear el texto entre varias pantallas apiladas unas sobre otras.
Tu tarea es limpiar los mensajes para que se puedan reutilizar.

Implementa una función `clean` que acepte el mensaje publicitario antiguo.
La función debe eliminar primero todos los espacios en blanco al principio y al final del texto y devolverlo.

```julia-repl
julia> clean("    BUY NOW, SAVE 10%   ")
"BUY NOW, SAVE 10%"
```
