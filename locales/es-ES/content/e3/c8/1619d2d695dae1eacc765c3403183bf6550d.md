# Acerca de

Cada proceso de Elixir tiene su propio identificador único: un _PID_ (identificador de proceso).

- Los PID son un tipo de datos propio.
  - Puedes comprobar si una variable es un PID con [`is_pid/1`][kernel-is-pid]
- Puedes obtener el PID del proceso actual con `self()`.
- Los PID funcionan como _direcciones de buzón_: si tienes el PID de un proceso, puedes enviar un mensaje a ese proceso.
- Por lo general, los PID se crean indirectamente, como valor devuelto de funciones que crean procesos nuevos, como `spawn`.
  - Los PID no deben ser creados directamente por el programador. Si fuera necesario, Erlang tiene una función [`list_to_pid/1`][erlang-list-to-pid].

[kernel-is-pid]: https://hexdocs.pm/elixir/Kernel.html#is_pid/1
[erlang-list-to-pid]: https://www.erlang.org/doc/man/erlang.html#list_to_pid-1
