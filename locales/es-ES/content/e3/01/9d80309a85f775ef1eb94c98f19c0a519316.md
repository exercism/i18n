# Aprender

Exercism ofrece ejercicios y comentarios, pero puede resultar difícil de abordar para quienes se acercan por primera vez a Common Lisp.
Estos recursos pueden ayudarte a empezar:

* [A Road to Common Lisp][road-to-cl], una entrada de blog que explica el camino de una persona hacia Common Lisp y su opinión sobre cómo empezar con él
* [Practical Common Lisp][practical-cl], un libro completo para aprender Common Lisp, disponible gratis en línea (y también en papel)
* [Common Lisp Cookbook][cl-cookbook]
* [Cliki.net Getting Start Started Page][cliki-getting-started]
* [Wikibooks book of Common Lisp, First steps][wikibooks-cl-first-steps]
  de varios colaboradores
* [Awesome Common Lisp Learning][awesome-cl]

Consulta también, dentro de esta pista de Common Lisp de Exercism: [Recursos importantes][track-resources].
