# Pistas

## General

- Lee sobre el uso de las bibliotecas de Erlang en la [guía oficial de introducción][getting-started-erlang-libraries] y, en particular, sobre cómo [dar formato a strings][getting-started-formatted-text-output].

## 1. Genera un planeta aleatorio

- Usa el atributo de módulo proporcionado con una lista de letras que representan las clases planetarias.
- Existe una [función integrada][enum-random] para elegir un elemento de una lista al azar.

## 2. Genera un número de registro de nave estelar aleatorio

- Existe una [función integrada][enum-random] para elegir un elemento de un rango al azar.

## 3. Genera una fecha estelar aleatoria

- No hay ninguna función de Elixir que devuelva un número decimal aleatorio.
- Existe una [función integrada de Erlang][erl-rand-uniform] que devuelve un número decimal aleatorio x tal que `0.0 <= x < 1.0`.
- Si `x` pertenece a un rango `0.0 <= x < 1.0`, pero necesitas un número de otro rango `a <= x < b`, puedes desplazar el rango de x multiplicándolo por la amplitud del rango (`b - a`) y sumando el inicio del rango (`a`). Es decir: `x * (b - a) + a`.

## 4. Formatea la fecha estelar

- No hay ninguna función de Elixir que pueda, en un solo paso, dar formato a un número decimal como string con una precisión determinada.
- Existe una [función integrada de Erlang][erl-io-lib-format] que toma un string de formato y una lista de datos, y devuelve un charlist.
- Existe una [función integrada][to-string] que convierte un charlist en un string.
- El string de formato de esa función contiene secuencias de control.
- Una secuencia de control empieza por `~` y tiene el patrón `~F.P.PadModC`, donde `F` representa el ancho de la salida, `P` representa la precisión, `Pad` representa el carácter de relleno, `Mod` representa el modificador de la secuencia de control y `C` es el tipo de la secuencia de control.
- Para dar formato a un número decimal con la precisión deseada, basta con una secuencia de control con el patrón `~.PC`.
- El tipo de secuencia de control para números decimales es `f`.
- El string de formato exacto que necesitas es `~.1f`.
