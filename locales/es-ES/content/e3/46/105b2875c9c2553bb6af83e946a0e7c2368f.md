# Introducción

## Protocolos

Los protocolos son un mecanismo para lograr polimorfismo en Elixir cuando quieres que el comportamiento varíe según el tipo de datos.

Los protocolos se definen con `defprotocol` y contienen una o más cabeceras de funciones.

```elixir
defprotocol Reversible do
  def reverse(term)
end
```

Los protocolos pueden implementarse con `defimpl`.

```elixir
defimpl Reversible, for: List do
  def reverse(term) do
    Enum.reverse(term)
  end
end
```

Un protocolo puede implementarse para cualquier tipo de datos de Elixir que ya exista o para un struct.

Cuando se invoca una función de un protocolo, la implementación adecuada se elige automáticamente en función del tipo del primer argumento.
