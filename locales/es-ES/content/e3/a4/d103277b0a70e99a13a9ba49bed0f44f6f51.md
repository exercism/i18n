# Introducción

La *combinatoria* es la matemática de contar y enumerar las formas en que se puede elegir u ordenar una colección de elementos. El vocabulario [`math.combinatorics`][math.combinatorics] de Factor cubre las dos preguntas básicas:

- **Combinaciones**: selecciones en las que el orden *no* importa.
- **Permutaciones**: ordenaciones en las que el orden *sí* importa.

Cada pregunta tiene una palabra de *recuento* que devuelve un número y una palabra de *listado* que devuelve las selecciones reales, además de una variante `each-` en streaming que llama a una quotation con cada una:

```
nCk              ( n k -- m )              ! count of k-combinations
nPk              ( n k -- m )              ! count of k-permutations
all-combinations ( seq k -- combinations )
all-permutations ( seq -- permutations )
each-combination ( seq k quot -- )
each-permutation ( seq quot -- )
```

```factor
USING: math.combinatorics prettyprint ;

5 2 nCk .                        ! => 10
{ 1 2 3 } 2 all-combinations .   ! => { { 1 2 } { 1 3 } { 2 3 } }
{ 1 2 } all-permutations .       ! => { { 1 2 } { 2 1 } }
```
