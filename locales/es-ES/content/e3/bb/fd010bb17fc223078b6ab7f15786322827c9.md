# Pistas

## General

- [Constantes][const]

## 1. Representa el tipo de interés fijo de un préstamo

- La constante no debe tener tipo, pero debe poder usarse en cualquier sitio donde se pueda usar un número decimal.
  La función debe devolver la constante.

## 2. Representa el número de días de un año

- La función debe devolver la constante.

## 3. Representa los meses del año

- Existe un [identificador][iota] para crear constantes enumeradas.
  Un bloque tiene [este aspecto][block].
  La función debe aceptar un argumento y devolverlo.

## 4. Representa un número de cuenta

- La constante no debe tener tipo, pero debe poder usarse en cualquier sitio donde se pueda usar un string.
  La función debe devolver la constante.

[const]: https://golang.org/doc/effective_go.html#constants
[iota]: https://golang.org/ref/spec#Iota
[block]: https://golang.org/pkg/debug/macho/#pkg-constants
