# Introducción

Recuerda que un programa de `jq` es un _pipeline de expresiones_.
**La asignación de variables** sigue esta regla: una _asignación de variable_ es una expresión con esta forma:

```jq
... | expr as $varname | ...
```

## El filtro devuelve la entrada

Igual que la _expresión de identidad_ `.`, la salida de la _asignación de variable_ es la misma que su entrada.
Asignar el valor de la variable es un efecto secundario.

Ejemplo, donde se ve que `.` después de la asignación es igual que la entrada inicial:

```sh
$ jq -c -n '42 | (. * 2) as $double | [., $double]'
[42,84]
```

## El ámbito de las variables

El ámbito de la variable es «léxico»: la variable estará en el ámbito durante el resto del pipeline.
Las variables definidas en funciones (ya llegaremos a las funciones) son «locales» a la función.

## Nombres de variables

La variable debe empezar por `$`.
El resto del nombre de la variable es un **identificador**: empieza por una letra o un guion bajo, seguido de letras, números o guiones bajos.

## Asignación por desestructuración

Del manual:

> Se pueden declarar varias variables con una sola expresión `as` proporcionando un patrón que _coincide con la estructura de la entrada_ (esto se conoce como «desestructuración»).

Ejemplos:

```jq
[1, 2, 3] as [$a, $b, $c]
| [$a, $b, $c]     # => [1, 2, 3]
```

```jq
{"foo": "bar", "len": [10, 20]} as {foo: $f, len: [$h, $w]}
| [$f, $h, $w]     # => ["bar", 10, 20]
```

Hacer coincidir el nombre de la variable con la _clave del objeto_ ofrece un atajo:

```jq
{"x": 4, "y": 7} as {$x, $y}
| [$x, $y]         # => [4, 7]
```

```jq
{"foo": "bar", "len": [10, 20]} as {$foo, $len}
| [$foo, $len]     # => ["bar", [10, 20]]
```

## Constantes

Como se muestra en el ejemplo anterior, las variables resultan útiles para almacenar constantes.
Es mejor dar un nombre a las constantes que dejar que aparezcan «números mágicos» en el código.

## A menudo no hacen falta variables

A menudo es más legible prescindir de las variables.

Piensa en calcular la media de un array de números

```jq
[2, 4, 8, 7]
| add as $sum
| length as $len
| $sum / $len
```

en comparación con

```jq
[2, 4, 8, 7] | add / length
```

Esto pone de relieve uno de los aspectos más potentes de `jq`: la entrada de un filtro se proporciona a _cada_ subexpresión:

- el array de entrada `[2,4,8,7]` se pasa a `add` (que suma los números aplicando el operador `+` a todos los elementos)
- _en paralelo_, `[2,4,8,7]` también se pasa a `length`
- cuando estas subexpresiones terminan, sus resultados se dividen, lo que devuelve el valor medio de los números del array de entrada.
