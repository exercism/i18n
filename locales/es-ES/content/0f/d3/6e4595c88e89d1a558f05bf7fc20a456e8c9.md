# Anexo de instrucciones

## Notas

Este ejercicio requiere que crees una estructura de datos de tipo lista enlazada que se pueda recorrer.

1. Implementa la propiedad `Count`: no debe ser posible cambiar su valor desde fuera.
2. Implementa el método `Push(T value)`, que añade un valor al principio de la lista.
3. Implementa el método `Pop()`, que elimina y devuelve un valor del principio.
4. Añade un constructor que permita la inicialización con un solo valor o con un iterable.
5. Implementa la interfaz `IEnumerable<T>`. Para obtener más información, consulta [esta página](https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1).
6. Asegúrate de que el método `Reverse()` esté disponible.
