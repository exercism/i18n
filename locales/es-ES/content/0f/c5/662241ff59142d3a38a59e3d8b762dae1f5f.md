# Pistas

## General

- [Propiedades][docs.microsoft.com-properties]
- [Usar propiedades][docs.microsoft.com-using-properties]

## 1. Permite que la báscula tenga una precisión

- Tienes que añadir una [propiedad de solo `get`][stackoverflow.com-get-only-properties] en la que guardar la precisión.
- Puedes inicializar la propiedad de solo `get` desde el constructor (y solo desde el constructor).

## 2. Permite que se ajuste el peso en la báscula

- Deberías añadir una propiedad con un [campo de respaldo][docs.microsoft.com-properties-with-backing-fields] privado.

## 3. Asegúrate de que se rechace un peso de entrada negativo

- La palabra clave `value` se usa para referirse al valor que quien llama quiere que tenga la propiedad.
- Añade [validación][stackoverflow.com-validating-properties] al accesor `set` de `Weight` para lanzar una excepción cuando el valor no sea válido.

## 4. Permite que se aplique un ajuste de tara a la báscula

- Deberías añadir una [propiedad autoimplementada][docs.microsoft.com-auto-implemented-properties] para el ajuste de tara.

## 5. Asegúrate de que la báscula tenga un ajuste de tara predeterminado

- Puedes inicializar una [propiedad autoimplementada][docs.microsoft.com-auto-implemented-properties] igual que puedes inicializar un campo.

## 6. Permite que se obtenga el peso

- Deberías añadir una propiedad de solo `get` en la que se calcule el peso mostrado correcto.

## 7. Muestra correctamente el string del peso mostrado

- Deberías [dar formato al string][stackoverflow.com-format-string] correctamente.
