# Pistas

## General

- Lee la documentación de los [operadores de comparación][comparison-operators]
- Lee la documentación sobre [cómo ordenar listas][list-sort]
- Recuerda cómo puedes [acceder a los registros o usar la coincidencia de patrones][records]

## 1. Compara los niveles de potencia

- Usa el [operador `(>)`][greater]

## 2. Encuentra la potencia más alta

- Usa la [función `max`][max]

## 3. Ordena las cartas

- Usa la [función `List.sortBy`][sort-by]

## 4. Las cartas más chulas primero

- Usa las funciones [`List.sortBy`][sort-by] o [`List.sortWith`][sort-with]
- Puedes usar tuplas para ordenaciones jerárquicas

## 5. Potencia variocolor

- Puedes definir explícitamente un orden o usar la [función `compare`][compare] con un valor concreto
- Puedes usar tuplas para ordenaciones jerárquicas

## 6. Haz tus apuestas

- Usa `compareShinyPower` en `expectedWinner`
- Usa un `case` para [usar la coincidencia de patrones con el orden][pattern-match]
