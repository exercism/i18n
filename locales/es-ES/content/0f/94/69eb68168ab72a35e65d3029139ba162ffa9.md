# Introducción

Una función es un bloque de código organizado y reutilizable que se utiliza para realizar alguna acción.
Hay varias formas de definir funciones en JavaScript.
Aquí veremos las _declaraciones de función_ y las _expresiones de función_.
Otras posibilidades, como las [funciones flecha][concept-arrow-functions], se tratarán en otros conceptos.

## Declaración de función

La forma estándar de definir una función en JavaScript es una _declaración de función_, también llamada _definición de función_ o _instrucción de función_.

Consta de la palabra clave `function`, el nombre de la función y una lista de parámetros separados por comas entre paréntesis.
A continuación viene el cuerpo de la función (el conjunto de instrucciones que define lo que hace la función), encerrado entre llaves.

```javascript
function someName(param1, param2, param3) {
  // ...
}
```

En JavaScript, una función se invoca (se llama) escribiendo el nombre de la función seguido de un paréntesis que contiene los argumentos.

```javascript
someName(arg1, arg2, arg3);
```

## Parámetros

Cuando trabajes con parámetros dentro del cuerpo de la función, ten en cuenta los posibles efectos secundarios.

- Los valores de los [tipos de datos primitivos][mdn-primitives] son _inmutables_.
  El valor original nunca se ve afectado por lo que le ocurra al argumento dentro del cuerpo de la función.
- En el caso del resto de valores (objetos, arrays, funciones), una reasignación no afectará al valor original.
  Sin embargo, si modificas ese argumento (por ejemplo, si añades una clave a un objeto), también modificarás el valor original que se pasó.

De forma predeterminada, en JavaScript todos los parámetros definidos en la declaración de función son opcionales.
Si proporcionas menos argumentos que parámetros, los argumentos que falten serán `undefined` dentro de la función; consulta [Null y Undefined][concept-null-undefined].
En muchos casos tiene sentido asignar un valor predeterminado más adecuado que `undefined`.
Esto puede hacerse especificando parámetros predeterminados directamente en la definición de la función.

```javascript
function someName(param1 = defaultValue1, param2 = defaultValue2) {
  // ...
}
```

## Instrucción return

Una instrucción `return` termina la ejecución de la función y especifica un valor que se devuelve a quien llamó a la función. Una función puede tener varias instrucciones `return`.

```javascript
function checkNumber(num) {
  if (num === 0) {
    return 'You passed 0, please provide another number.';
  }

  return 'Thanks for passing such a nice number.';
}
```

El valor devuelto por una función se puede almacenar en una variable.

```javascript
function sum(x, y) {
  return x + y;
}

const total = sum(5, 10);
// => 15
```

El resultado de una función que no devuelve ningún valor con `return` o que no tiene una instrucción `return` es `undefined`.
En JavaScript no hay `return` implícitos.

```javascript
function nakedReturn(a) {
  a * 2;
  return;
}

nakedReturn(1);
// => undefined

function noReturn(a) {
  a * 2;
}

noReturn(1);
// => undefined
```

En JavaScript solo puedes devolver exactamente un valor.
Si quieres pasar más información, primero tienes que combinarla en una sola entidad, normalmente en un [objeto][concept-objects] o un [array][concept-arrays].

```javascript
function divide(a, b) {
  return {
    quotient: Math.floor(a / b),
    remainder: a % b,
  };
}
```

## Expresión de función

Una declaración de función es una instrucción independiente.
Pero a veces resulta útil definir una función como parte de otra expresión, por ejemplo en una asignación, como parámetro de una función ([callback][concept-callbacks]) o como valor de un [objeto][concept-objects].
Esto puede hacerse con una expresión de función.
Tiene la misma sintaxis que una declaración de función, solo que se puede omitir el nombre de la función para crear una _función anónima_.

```javascript
const someFunction = function (param) {
  // ...
};

someOtherFunction(function (param) {
  // ...
});

const obj = {
  someFunction: function (param) {
    // ...
  },
};
```
