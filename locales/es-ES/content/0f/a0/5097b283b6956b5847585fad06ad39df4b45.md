# Aprender Crystal

- [Crystal Official Docs][offical-doc]: por ahora es el recurso de aprendizaje de referencia para Crystal. Además es bastante exhaustiva, desde los literales y las variables más básicos hasta cosas avanzadas como las macros. También tiene un estupendo [documento sobre convenciones de estilo][coding conventions].

- [Crystal for Rubyists][rubyists guide]: una introducción práctica al lenguaje Crystal.

- Crystal Playground: aunque Crystal no tiene un REPL integrado (como Ruby, Python o Node), sí ofrece una forma relativamente sencilla de experimentar con código. Solo tienes que ejecutar `crystal play` y tendrás un sitio donde experimentar con Crystal en tu navegador, en localhost:8080.

- [Editor en línea][online editor]: un REPL basado en web para Crystal; es un buen sitio para hacerte una idea del lenguaje.
  Sin tener que instalar nada.

[rubyists guide]: http://www.crystalforrubyists.com/
[offical-doc]: https://crystal-lang.org/reference/
[coding conventions]: https://crystal-lang.org/reference/conventions/coding_style.html
[online editor]: https://replit.com/languages/crystal
