# invertir el `if` para dejar el camino feliz a la izquierda

Para simplificar, invierte la condición del `if` que gestiona el caso de error y, a continuación, deshazte de la rama `else` devolviendo dentro del `if`. Un proverbio de Go dice que «[el camino feliz se alinea a la izquierda](https://medium.com/@matryer/line-of-sight-in-code-186dd7cdea88)», es decir, que el flujo normal de control sigue el margen izquierdo y solo los casos excepcionales o de error llevan sangría.
