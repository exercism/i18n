# Apéndice de instrucciones

## Ventajas e inconvenientes de `from_quote`

La función `Card.from_quote` analiza un string y lo convierte en una `Card`.
Esto permite escribir código como el siguiente:

```roc
card : Card
card = "Q"
```

Este código llama implícitamente a `Card.from_quote("Q")` en tiempo de compilación.
Ejecutar código en tiempo de compilación con este enfoque (u otros métodos descritos a continuación) puede acelerar potencialmente el programa, ya que no necesita encargarse del análisis ni de la validación de datos en tiempo de ejecución.
Además, garantiza que los datos no válidos (como un formato de fecha incorrecto) se rechacen en tiempo de compilación en lugar de en tiempo de ejecución, lo que hace que tu aplicación sea más robusta.
Por último, hace que el código sea agradable y legible.
Por ejemplo, este es uno de los tests de este ejercicio:

```roc
result = simulate_game({
    player_a: ["2", "A"],
    player_b: ["3", "4", "5", "6", "K"],
})
```

Sin embargo, alguien que lea este código podría suponer que la función `simulate_game` recibe un registro que contiene dos `List(Str)`, cuando en realidad es un registro que contiene dos `List(Card)`.
Esto puede dar lugar a confusión y errores.
Por este motivo, puede que prefieras el formato un poco más largo pero más explícito: `"Q".Card`, que también llama a `from_quote` en tiempo de compilación.

En tus propios programas, puede que prefieras usar `from_str` en su lugar:

```roc
Card := { ... }.{
    from_str : Str -> Try(Card, [InvalidCard])
    from_str = |card_str| ...
}
```

También puedes llamar a `from_str` (o a cualquier otra función pura) en tiempo de compilación, así:

```roc
Ok(card) = Card.from_str("Q")
```

Nota: colocar esta definición en el nivel superior hace que se ejecute en tiempo de compilación (ya que la función es pura y su entrada se conoce en tiempo de compilación).
Dentro de una función, puedes usar `from_str` en tiempo de ejecución.
