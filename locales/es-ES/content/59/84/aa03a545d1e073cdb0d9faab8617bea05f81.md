# Pistas

## General

- Recuerda consultar la tabla de las instrucciones.

## 1. Dada una extensión, devuelve el tipo de medio esperado

- Usa la [coincidencia de patrones][pattern-matching] para devolver el tipo de medio correcto.
- Puedes usar [varias cláusulas de función][mfc].

## 2. Dado un fichero binario, devuelve el tipo de medio esperado

- Usa la [forma especial binaria][special-forms] de la que dispones para escribir un literal binario.
- Usa la [coincidencia de patrones][binary-matching] para comparar con los primeros bytes del binario del fichero.

## 3. Dada una extensión y un fichero binario, comprueba que el fichero coincide con el tipo esperado

- Reutiliza las funciones que creaste para las partes 1 y 2.
- Compara el valor devuelto de cada función y, a continuación, devuelve el valor adecuado.
  - Puedes usar el [macro condicional `if`][if] para condiciones binarias.
