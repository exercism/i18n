# Anexo a las instrucciones

## Notas

El propósito de este ejercicio es investigar algunos de los paralelismos entre una instancia de un módulo de WebAssembly y una instancia de una clase en los lenguajes orientados a objetos.

En tu solución, una instancia de WebAssembly debe considerarse una instancia de una cuenta bancaria, y se deben usar globales mutables de WebAssembly para modelar estados privados como en una clase.

¡No debería hacer falta memoria lineal!
