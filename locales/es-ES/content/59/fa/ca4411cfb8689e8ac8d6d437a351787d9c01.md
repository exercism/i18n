# Bucles

```sather
   loop
      ...
   end;
```

Sather tiene exactamente una instrucción de bucle. No hay `while` ni `for`;
ambos se construyen a partir de `loop` y algo que lo termina.

## Variables

```sather
   total ::= 0;          -- declare, with a starting value
   total := total + 5;   -- assign
```

`::=` declara y toma el tipo del valor dado. Cuando una variable debe existir
antes de que haya un valor para ella, declárala con un tipo en su lugar:

```sather
   total : INT;
   total := 0;
```

Una variable declarada sin un valor empieza como cero para `INT`, `false` para
`BOOL`, y void para un string o un objeto.

## Terminar un bucle

| Escrito | Termina el bucle |
| --- | --- |
| `until!(q)` | cuando `q` es true |
| `while!(q)` | cuando `q` es false |
| `break!` | de inmediato |

Los tres pueden aparecer en cualquier parte del cuerpo, y un bucle puede usar más de uno.

```sather
   loop
      until!(n > last);      -- may run no times at all
      ...
   end;

   loop
      ...
      until!(done);          -- always runs at least once
   end;
```

## El signo de exclamación

`until!`, `while!` y `break!` terminan en `!` porque son **iteradores**:
cosas que solo pueden aparecer dentro de un bucle y que pueden terminarlo. Escribir uno
fuera de un bucle es un error y no una advertencia. En ejercicios posteriores se usan los
demás iteradores de la biblioteca y, con el tiempo, se escriben nuevos.

## Bucles infinitos

Un bucle sin nada que lo termine se ejecuta para siempre. En ocasiones es justo lo que
se busca, pero con mucha más frecuencia significa que el valor por el que pregunta la
condición nunca cambia. Si un programa se queda colgado, lo primero que hay que comprobar
es si algo dentro del bucle lo acerca a detenerse.
