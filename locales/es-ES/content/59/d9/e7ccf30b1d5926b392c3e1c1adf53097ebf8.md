# Instrucciones

En este ejercicio juegas a un juego de rol llamado «Wizard and Warriors», que te permite jugar como un mago o como un guerrero.

Hay reglas distintas para los guerreros y los magos a la hora de determinar cuántos puntos de daño infligen.

Para un guerrero, estas son las reglas:

- Inflige 6 puntos de daño si el personaje al que ataca no es vulnerable.
- Inflige 10 puntos de daño si el personaje al que ataca es vulnerable.

Para un mago, estas son las reglas:

- Inflige 12 puntos de daño si el mago ha preparado un hechizo con antelación.
- Inflige 3 puntos de daño si el mago no ha preparado un hechizo con antelación.

Por lo general, los personajes nunca son vulnerables. Sin embargo, los magos _sí_ son vulnerables si no han preparado un hechizo.

Tienes seis tareas que trabajan con personajes guerreros y magos.

## 1. Describe un personaje

Sobrescribe el método `ToString()` de la clase `Character` para que devuelva una descripción del personaje, con el formato `"Character is a <CHARACTER_TYPE>"`.

```csharp
var warrior = new Warrior();
warrior.ToString();
// => "Character is a Warrior"
```

## 2. Haz que los personajes no sean vulnerables de forma predeterminada

Asegúrate de que el método `Character.Vulnerable()` siempre devuelva `false`.

```csharp
var warrior = new Warrior();
warrior.Vulnerable();
// => false
```

## 3. Permite que los magos preparen un hechizo

Implementa el método `Wizard.PrepareSpell()` para permitir que un mago prepare un hechizo con antelación.

```csharp
var wizard = new Wizard();
wizard.PrepareSpell();
```

## 4. Haz que los magos sean vulnerables si no han preparado un hechizo

Asegúrate de que el método `Vulnerable()` devuelva `true` si el mago no ha preparado un hechizo; en caso contrario, que devuelva `false`.

```csharp
var wizard = new Wizard();
wizard.Vulnerable();
// => true
```

## 5. Calcula los puntos de daño de un mago

Implementa el método `Wizard.DamagePoints()` para que devuelva los puntos de daño infligidos: 12 puntos de daño cuando se ha preparado un hechizo y 3 puntos de daño cuando no.

```csharp
var wizard = new Wizard();
var warrior = new Warrior();

wizard.PrepareSpell();
wizard.DamagePoints(warrior);
// => 12
```

## 6. Calcula los puntos de daño de un guerrero

Implementa el método `Warrior.DamagePoints()` para que devuelva los puntos de daño infligidos: 10 puntos de daño cuando el objetivo es vulnerable y 6 puntos de daño cuando no.

```csharp
var warrior = new Warrior();
var wizard = new Wizard();

warrior.DamagePoints(wizard);
// => 10
```
