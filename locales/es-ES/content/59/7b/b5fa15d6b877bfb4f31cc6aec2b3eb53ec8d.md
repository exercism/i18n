# Introducción

Trabajas para una agencia gubernamental que ha interceptado una serie de señales de comunicación cifradas de un grupo de atracadores de bancos.
Las señales contienen una larga secuencia de dígitos.
Tu equipo tiene que usar diversas técnicas de procesamiento digital de señales para analizar las señales e identificar cualquier patrón que pueda indicar que se está planeando un atraco.
