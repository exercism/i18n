# Pistas

## 1. Duplica cada una de las cartas

- Hay un método integrado ideal para [transformaciones simples][map_method_docs] como esta.

## 2. Crea varias copias de cada 3 que haya en la baraja

- Hay un método integrado perfecto para transformaciones personalizadas o [acumulaciones][reduce_method_docs] (como sumar un array, etc.).

## 3. Encuentra dos cartas justo en el centro de la baraja

- Hay un método integrado para [cortar y trocear][slice_method_docs] arrays en segmentos más pequeños.

## 4. Las dos cartas de los extremos reaparecerán en el medio de la baraja

- Hay un método integrado para [insertar o eliminar][splice_method_docs] elementos en el medio de un array.
- El array también tiene métodos integrados para eliminar el primer y el último elemento; consulta la [documentación de Array en MDN][array_docs].

## 5. Todas las cartas que no sean 2 desaparecen

- Hay un método integrado para [filtrar][filter_method_docs] o excluir elementos de un array.

## 6. Convierte una baraja mezclada en una baraja perfectamente ordenada

- Hay un método integrado para [ordenar][sort_method_docs].

## 7. Reordena la baraja

- Hay un método integrado para [invertir][reverse_method_docs] un array.
