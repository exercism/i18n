# Pistas

## General

- Las instancias de una estructura se crean declarando el nombre de la estructura seguido de los valores de los campos entre llaves.
- `@T` se puede usar para declarar instantáneas de algún tipo `T`, por ejemplo `let i: @u32 = @1;` declara una variable `i` que es una instantánea del valor `u32` `1`;
- Puedes extraer un valor de una instantánea usando el operador `*` (desnap), por ejemplo `let int = *an_int_snapshot;`.
- Puedes declarar un valor como mutable usando la palabra clave `mut`, como en `let mut i = 1;`.

## 1. Crea un contador de votos

- Tienes que crear un puntero a una estructura `VoteCounter`, es decir, un `@VoteCounter`.
- Puedes asignar el parámetro `value` directamente al crear una instancia de la estructura.

## 2. Obtén el número de votos de un contador

- Puedes usar el operador `*` sobre una instantánea para hacerle desnap y obtener su valor, por ejemplo `*my_snapshot`

## 3. Incrementa los votos de un contador

- En lugar de modificar la instantánea `@VoteCounter`, tienes que devolver una nueva instancia de `VoteCounter` con los votos incrementados.
- Puedes hacer desnap del valor subyacente del contador de votos con el operador `*`, o llamar a la función que creaste en la tarea anterior.

## 4. Crea los resultados de la elección

- Crea una nueva estructura o variable `ElectionResult` con los campos `name` y `vote_counter` rellenados con los valores de los argumentos de la función.
- Puedes crear una instantánea de `VoteCounter` usando el operador `@` delante del nombre de la variable o de la declaración de la estructura, o llamar a la función `new_vote_counter` que hiciste en alguna de las tareas anteriores.

## 5. Anuncia los resultados

- Aunque recibes una instantánea de `ElectionResult`, puedes acceder a sus campos con la notación de punto `.`, ¡como si no fuera una instantánea!
- Construye el mensaje accediendo a los campos `name` y `vote_counter` de la estructura.
- Al hacer desnap de una instantánea anidada, tienes que aplicar tantos operadores `*` como instantáneas haya que desnap-ear:

```rust
let result = @ElectionResult {
    name: "John",
    vote_counter: @VoteCounter { value: 32 },
};

println!("{}", **result.vote_counter.value); 
// => 32
```

## 6. Recuento de votos

- Debido a [cómo se implementan los diccionarios][dictionaries underneath], es un requisito que sean mutables tanto para modificarlos como para leerlos, lo que significa que los cambios que hagas al diccionario dentro de la función serán visibles fuera de ella.
- Para incrementar el valor de una clave en un `let mut m: Felt252Dict<u32>`, debes combinar sus funciones `get` e `insert`: `m.insert('mykey', m.get('mykey') + 1);`
