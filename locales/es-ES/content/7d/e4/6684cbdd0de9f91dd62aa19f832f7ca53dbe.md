# Introducción

## Números

Del [manual][man-types]

> jq admite el mismo conjunto de tipos de datos que JSON: números, strings, booleans, arrays, objetos (que en jerga JSON son hashes con solo claves de tipo string) y «null».

Centrémonos en los **números**.

### Números y operadores numéricos

Todos los números, sean enteros o no, son números de coma flotante de doble precisión IEEE754.
Esto nos limita a 53 bits de precisión.

Los operadores habituales están disponibles para usarlos con números:

- aritméticos: `+`, `-`, `*`, `/`, `%`
- comparación: `==`, `!=`, `<`, `<=`, `>=`, `>`
- las [funciones matemáticas][man-math] estándar

  Para las funciones de una sola entrada, pasa el valor a la función a través de una tubería

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para las funciones de dos entradas, las funciones ignorarán la entrada y esperarán los
  valores como parámetros (recuerda que los parámetros se separan con puntos y coma)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  El punto y coma es el separador de los argumentos de una función, no la coma.

### Otras expresiones de `jq`

Para resolver el ejercicio, necesitarás conocer las expresiones condicionales.

#### Expresiones condicionales

`jq` usa una [expresión `if-then-else`][if-then-else] para las **expresiones condicionales**.
Como _expresión_, se coloca en una tubería.

La sintaxis es: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La cláusula `else` es opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Las condiciones adicionales usan `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
