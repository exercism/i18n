# Introducción

Por defecto, las variables están limitadas al scope en el que se definen. Si se definen en un archivo fuera de una función o una clase, están limitadas al scope del archivo. Si se definen dentro de una función o una clase, están limitadas al scope de la función o la clase.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

Las variables también pueden declararse específicamente para tener scope `global` o `static`.
