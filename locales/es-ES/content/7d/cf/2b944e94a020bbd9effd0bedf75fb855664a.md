# Acerca de

Una quotation, escrita entre `[ ]`, es el equivalente en Factor a una función anónima o a un bloque de código. Es un valor de primera clase que puedes apilar, guardar o pasar de un sitio a otro, y que solo se ejecuta cuando algo la *llama*.

```factor
[ 1 + ]              ! a quotation, sitting on the stack
5 [ 1 + ] call .     ! => 6
```

Las quotations son secuencias de palabras, y Factor las usa allí donde hace falta diferir o parametrizar un comportamiento:

- las ramas de `if` / `when` / `unless` / `cond`
- el predicado de `filter`, `count`, `any?`, `all?`
- la transformación de `map`, `each`, `reduce`
- el cuerpo de `times`, `while`, `loop`

El efecto sobre la pila de una quotation por lo general puede inferirse. Cuando no sea posible, normalmente porque se guarda y se llama con `call` más tarde, declara el efecto explícitamente: `call( a b -- c )`.

## Combinar quotations

```
compose ( quot1 quot2 -- compound )
curry   ( value quot  -- curried )
```

`compose` concatena dos quotations de principio a fin en una nueva quotation que ejecuta la primera y luego la segunda. `curry` antepone un valor fijo y devuelve una quotation que apilará ese valor antes de invocar la original. Ambas producen quotations normales que puedes llamar con `call`, guardar o pasar a otros combinadores.

```factor
USING: kernel math ;

3 [ 2 * ] [ 1 + ] compose call .   ! 3 2 * 1 + => 7
5 [ 1 + ] curry call .             ! 5 1 +     => 6
```
