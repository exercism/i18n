# Instrucciones

En este ejercicio tienes que implementar algunos métodos para manipular un array de lenguajes de programación.

## 1. Define un método que devuelva un array vacío de lenguajes

Define el método `LanguageList.list` que no recibe argumentos y devuelve un array vacío del tipo `Array(String)`.

```crystal
LanguageList.list()
# => []
```

## 2. Define un método para añadir un lenguaje al array

Define el método `LanguageList.add` que recibe 2 argumentos (un _array de lenguajes_ y un string con el nombre de un _lenguaje_).
El método debe devolver el array con el nuevo lenguaje añadido al final del array.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
```

## 3. Define un método para eliminar un lenguaje del array

Define el método `LanguageList.remove` que recibe 1 argumento (un _array de lenguajes_).
El método debe devolver el array sin el último elemento.
Supón que el array siempre tendrá al menos un elemento.

```crystal
language_list = LanguageList.list()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
language_list = LanguageList.remove(language_list)
# => ["Crystal"]
```

## 4. Define un método que devuelva el n-ésimo elemento del array

Define la función `LanguageList.at` que recibe 2 argumentos (un _array de lenguajes_ y un índice).
El método debe devolver el lenguaje que está en el índice n del array.
Supón que en ese índice siempre habrá un lenguaje.

```crystal
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Crystal")
# => ["Crystal"]
language_list = LanguageList.add(language_list, "Ruby")
# => ["Crystal", "Ruby"]
LanguageList.at(language_list, 1)
# => "Ruby"
```

## 5. Define un método para analizar un string de lenguajes

Define el método `LanguageList.parse` que recibe 1 argumento (un string de lenguajes separados por comas).
El método debe devolver un array de lenguajes.

```crystal
LanguageList.parse("Crystal, Ruby")
# => ["Crystal", "Ruby"]
```
