# Pistas

## 1. Comprueba cuáles fueron los recuentos la semana pasada

- Los [vectores][vectors] se representan en Clojure con corchetes (`[ ]`)

## 2. Comprueba cuántos pájaros han visitado hoy

- La función [`peek`][peek] se puede usar para devolver el último elemento de un vector.

## 3. Incrementa el recuento de hoy

- La función [`update`][update] se puede usar para devolver un vector nuevo con un elemento distinto en un índice dado.

- La función [`count`][count] se puede usar para hallar la longitud del vector.

- Las funciones [`inc`][inc] y [`dec`][dec] se pueden usar para incrementar y decrementar valores enteros.

## 4. Comprueba si hubo un día sin pájaros visitantes

- La función [`every?`][every?] se puede usar para comprobar si todos los elementos de una colección cumplen un predicado dado.

- El predicado [`pos?`][pos?] devuelve `true` si un número es mayor que cero.

- La función [`not`][not] devuelve `true` si una expresión se evalúa como falso lógico.

## 5. Calcula el número de pájaros visitantes durante los primeros días

- La función [`take`][take] se puede usar para devolver una secuencia con los primeros n elementos de una colección.

- La función [`reduce`][reduce] se puede usar para sumar todos los valores de una colección.

## 6. Calcula el número de días ajetreados

- La función de orden superior [`filter`][filter] se puede usar para devolver una secuencia con los elementos de una colección que cumplen un predicado dado.

## 7.  Comprueba si la semana es impar

- La función [`=`][equality] se puede usar para comprobar la igualdad.
