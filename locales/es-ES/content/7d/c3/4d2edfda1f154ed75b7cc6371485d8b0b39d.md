# Instrucciones

Traduce secuencias de ARN a proteínas.

El ARN se puede dividir en secuencias de tres nucleótidos llamadas codones y, a continuación, traducirse a un polipéptido, así:

ARN: `"AUGUUUUCU"` => se traduce a

Codones: `"AUG", "UUU", "UCU"`
=> que se convierten en un polipéptido con la siguiente secuencia =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Hay 64 codones que, a su vez, se corresponden con 20 aminoácidos; sin embargo, no todas las secuencias de codones ni los aminoácidos resultantes son importantes en este ejercicio.
Si funciona para un codón, el programa debería funcionar para todos ellos.
No obstante, no dudes en ampliar la lista del conjunto de pruebas para incluirlos todos.

También hay tres codones de terminación (también conocidos como codones «STOP»); si el ribosoma se topa con alguno de ellos, la traducción finaliza y la proteína queda terminada.

Todos los codones posteriores se ignoran, así:

ARN: `"AUGUUUUCUUAAAUG"` =>

Codones: `"AUG", "UUU", "UCU", "UAA", "AUG"` =>

Proteína: `"Methionine", "Phenylalanine", "Serine"`

Fíjate en que el codón de parada `"UAA"` termina la traducción y la metionina final no se traduce a la secuencia de proteína.

A continuación se muestran los codones y los aminoácidos resultantes que se necesitan para el ejercicio.

| Codón              | Proteína      |
| :----------------- | :------------ |
| AUG                | Methionine    |
| UUU, UUC           | Phenylalanine |
| UUA, UUG           | Leucine       |
| UCU, UCC, UCA, UCG | Serine        |
| UAU, UAC           | Tyrosine      |
| UGU, UGC           | Cysteine      |
| UGG                | Tryptophan    |
| UAA, UAG, UGA      | STOP          |

Puedes obtener más información sobre la [traducción de proteínas en Wikipedia][protein-translation].
