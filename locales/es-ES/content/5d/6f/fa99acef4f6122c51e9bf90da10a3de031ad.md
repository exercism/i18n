# Ejecutar los tests

## Descargar un ejercicio

Usa la [CLI de Exercism][cli] para descargar el ejercicio en el que quieras trabajar.

```sh
exercism download --track=dart --exercise=hello-world
```

A continuación, cambia al directorio del ejercicio.

```sh
cd /path/to/exercism/dart/hello-world
```

## Instalar las dependencias

Antes de ejecutar los tests, descarga las dependencias del ejercicio.

```sh
dart pub get
```

## Ejecutar los tests

```sh
dart test
```

## Interpretar los resultados de los tests

`dart test` usa el reporter compacto por defecto, que muestra un recuento continuo de tests superados, omitidos y fallidos en una sola línea.

```sh
$ dart test

  Expected: <3>
    Actual: <0>

  package:matcher                    expect
  test/binary_search_test.dart 13:5  main.<fn>


To run this test again: dart test test/binary_search_test.dart -p vm --plain-name 'finds a value in the middle of an array'
00:00 +1 ~9 -1: Some tests failed.
```

- `+1`: 1 test superado
- `~9`: 9 tests omitidos
- `-1`: 1 test fallido

## Trabajar con los tests

La mayoría de los ejercicios tienen varios tests, y todos menos el primero están omitidos por defecto.

```dart
void main() {
  final twoFer = TwoFer();

  group('TwoFer', () {
    test('no name given', () {
      final result = twoFer.statement();
      expect(result, equals('One for you, one for me.'));
    }, skip: false);

    test('a name given', () {
      final result = twoFer.statement('Alice');
      expect(result, equals('One for Alice, one for me.'));
    }, skip: true);

    test('another name given', () {
      final result = twoFer.statement('Bob');
      expect(result, equals('One for Bob, one for me.'));
    }, skip: true);
  });
}
```

Para trabajar con los tests de uno en uno, cambia `skip: true` por `skip: false` en cada test a medida que avances.
Como alternativa, ejecuta todos los tests a la vez sin editar el archivo.

```sh
dart test --run-skipped
```

El ejecutor de tests en línea ejecuta todos los tests al enviar la solución, incluidos los omitidos.

## Cómo gestionar el error «Could not find a command named frontend_server.dart.snapshot»

Supón que tienes un ejercicio que ya has resuelto y enviado, y que vuelves a él después de un tiempo.
Puede que te encuentres con este error cuando lo pruebes:

```sh
$ dart test
...
Could not find a command named "/path/to/frontend_server.dart.snapshot".
```

La [solución][solution] es eliminar el archivo `pubspec.lock`.
Después, ejecuta de nuevo el comando dart.
