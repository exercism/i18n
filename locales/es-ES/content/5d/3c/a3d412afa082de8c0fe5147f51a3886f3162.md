# Introducción

Ruby es un [lenguaje orientado a objetos][object-oriented-programming].
En Ruby todo es un [objeto][object].

En Ruby hay dos formas principales de asignar objetos a nombres: usar variables o usar constantes.
Las variables siempre se escriben en snake case.
Una variable puede hacer referencia a objetos diferentes a lo largo de su ciclo de vida.
Por ejemplo, `my_first_variable` se puede definir y redefinir muchas veces con el operador `=`:

```ruby
my_first_variable = 1
my_first_variable = "Some string"
my_first_variable = SomeComplexObject.new
```

Las constantes, en cambio, están pensadas para asignarse una sola vez.
Deben empezar por mayúscula y, por convención, se escriben enteras en mayúsculas, con las palabras separadas por guiones bajos.

Por ejemplo:

```ruby
MY_FIRST_CONSTANT = 10

# Redefining not allowed
# MY_FIRST_CONSTANT = "Some String"
```

Ruby se organiza en clases.
Las clases se definen con la palabra clave `class` seguida del nombre de la clase.
Normalmente, los objetos se crean instanciando clases con el método `.new`.

Por ejemplo:

```ruby
# Define the class
class Calculator
  #...
end

# Create an instance of it and assign it to a variable
my_first_calc = Calculator.new
```

Las unidades de funcionalidad se encapsulan en métodos, similares a las _funciones_ de otros lenguajes.
Un método puede definirse opcionalmente con argumentos posicionales o con argumentos de palabra clave, que se definen y se invocan con la sintaxis de `:`.
Los métodos devuelven implícitamente el resultado de la última instrucción evaluada, o pueden devolver explícitamente un objeto mediante la palabra clave `return`.
Los métodos se invocan con la sintaxis `.`.

```ruby
class Calculator

  # Unnamed params
  def add(num1, num2)
    return num1 + num2 # Explicit return
  end

  # Named params
  def multiply(num1:, num2:)
    num1 * num2 # Implicit return
  end
end

calc = Calculator.new
calc.add(1, 3)
calc.multiply(num1: 2, num2: 5)
```
