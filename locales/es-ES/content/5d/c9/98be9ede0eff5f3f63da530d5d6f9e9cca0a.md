# Aprendizaje

Tcl se diseñó con el objetivo de ser muy sencillo pero potente.
Por ese motivo, aprender [la sintaxis básica de Tcl][syntax] es bastante fácil.

Para un tutorial práctico, consulta [Learn X in Y minutes: Tcl][X-in-Y].

Para un tutorial completo con varias partes:
 - [El tutorial de Tcl][tutorial] cubre la versión 8.5 (la versión estable actual es la 9.0)
 - El soporte para la programación orientada a objetos se añadió al núcleo de Tcl en la versión 8.6.
   Magicsplat tiene un [tutorial de POO][oo-tutorial] exhaustivo que lo cubre.
