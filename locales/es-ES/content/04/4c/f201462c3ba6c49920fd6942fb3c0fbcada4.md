# Importar ANSI con :except

Las instrucciones mencionan «Tienes previsto añadir compatibilidad con otros colores de coche, así que quieres importar el módulo completo», sin la función `color` que entra en conflicto. Para ello, usa la opción `:except` de esta forma:

```elixir
import IO.ANSI, except: [color: 1]
```
