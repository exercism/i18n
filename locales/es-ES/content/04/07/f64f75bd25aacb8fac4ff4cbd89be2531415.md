# ignórame

## Entrada

Tu script recibirá el puzle alfamético como una sola cadena a través de la
entrada estándar (stdin). La cadena del puzle sigue el formato
`WORD1 + WORD2 + ... == RESULT`.

Por ejemplo:

```text
SEND + MORE == MONEY
```

## Salida

Si el puzle tiene solución, imprime una sola línea compuesta por pares
`LETTER=DIGIT` separados por espacios, ordenados alfabéticamente por letra.

Para el ejemplo anterior, la salida debería ser:

```text
D=7 E=5 M=1 N=6 O=0 R=8 S=9 Y=2
```

Si el puzle tiene varias soluciones válidas, se acepta imprimir cualquiera de
ellas.

Si el puzle no tiene solución, no imprimas nada (una línea vacía).
