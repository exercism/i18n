# Instrucciones

Eres el contramaestre de un carguero costero. La sentina, el compartimento más bajo del casco, recoge aguas residuales, y en cada turno hay que abrir el equipo de sentina, ponerlo en marcha y estibarlo. Pase lo que pase durante el bombeo, el equipo *debe* acabar de nuevo en su estado estibado.

Las pruebas te dan `<test-pump>` para obtener bombas nuevas. Cada bomba tiene un slot `opened>>` que lee `t` mientras está abierta y `f` una vez que se ha desechado.

## 1. Vaciar la sentina

Define `drain-bilge` para liberar una sola bomba. Llamar a `drain-bilge` sobre la misma bomba dos veces debería ser inofensivo: el framework se encarga de eso por ti.

```factor
<test-pump> dup drain-bilge opened>> .   ! => f
```

## 2. Rutina de bombeo

Define `pump-out` para que reciba una bomba y un quotation, ponga la bomba en la pila para que el quotation la use y libere la bomba después, *incluso si el quotation lanza una excepción*.

```factor
<test-pump> [ drop ] pump-out   ! pump released
```

## 3. Rutina de turno completo

Define `shift-routine` para que reciba dos bombas y un quotation. Abre un scope de destructores, registra *ambas* bombas para su liberación incondicional y luego llama al quotation. Ambas bombas acaban liberadas, tanto si el quotation termina con normalidad como si lanza una excepción.

El quotation recibe ambas bombas en la pila como entradas.

```factor
<test-pump> <test-pump> [ 2drop ] shift-routine
! both pumps released
```

## 4. Bombeo arriesgado

A veces una bomba está prestada: solo quieres descartarla si algo va mal; de lo contrario, la siguiente guardia la necesita abierta. Define `risky-pump-out` para que reciba una bomba y un quotation, registre la bomba para una liberación **solo en caso de fallo** y llame al quotation con la bomba en la pila.

Si el quotation se completa correctamente, la bomba permanece abierta. Si el quotation lanza una excepción, la bomba se libera y la excepción se propaga.

```factor
<test-pump> [ drop ] risky-pump-out                ! stays open
<test-pump> [ drop "boom" throw ] risky-pump-out   ! pump released, throws
```

## 5. Un disposable personalizado: la válvula

Completa el conjunto de herramientas con un disposable totalmente nuevo: una `valve`. La tupla ya está declarada:

```factor
TUPLE: valve < disposable is-open ;
```

- Define `<valve> ( -- valve )` para construir una válvula nueva mediante `new-disposable`, con `is-open` puesto a `t`.
- Implementa `M: valve dispose*` para cambiar `is-open` a `f`.

```factor
<valve> is-open>> .                ! => t
<valve> dup dispose is-open>> .    ! => f
```
