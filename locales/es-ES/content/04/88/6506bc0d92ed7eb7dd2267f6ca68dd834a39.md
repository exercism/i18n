# Instrucciones

En este ejercicio vas a implementar una forma de llevar un registro de las puntuaciones máximas del juego más popular de tu salón recreativo.

## 1. Define un nuevo mapa de puntuaciones máximas

Para crear un nuevo mapa de puntuaciones máximas, define la función `HighScore.new/0`, que no recibe ningún argumento y devuelve un mapa de puntuaciones máximas nuevo y vacío.

```elixir
HighScore.new()
# => %{}
```

## 2. Añade jugadores al mapa de puntuaciones máximas

Para añadir un jugador al mapa de puntuaciones máximas, define `HighScore.add_player/3`, una función que recibe 3 argumentos:

- El primer argumento es el mapa de puntuaciones.
- El segundo argumento es el nombre de un jugador como string.
- El tercer argumento es la puntuación como número entero. El argumento es opcional; implementa el tercer argumento con un valor predeterminado de 0.

Guarda la puntuación inicial predeterminada en un atributo de módulo. La necesitarás de nuevo.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 0, "José Valim"=> 486_373}
```

## 3. Elimina jugadores del mapa de puntuaciones

Para eliminar un jugador del mapa de puntuaciones máximas, define `HighScore.remove_player/2`, que recibe 2 argumentos:

- El primer argumento es el mapa de puntuaciones.
- El segundo argumento es el nombre del jugador como string.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas")
# => %{"Dave Thomas" => 0}
score_map = HighScore.remove_player(score_map, "Dave Thomas")
# => %{}
```

## 4. Restablece la puntuación de un jugador

Para restablecer la puntuación de un jugador, define `HighScore.reset_score/2`, que recibe 2 argumentos:

- El primer argumento es el mapa de puntuaciones.
- El segundo argumento es el nombre del jugador como string, cuya puntuación quieres restablecer.

La función también debe funcionar si el jugador no tiene una puntuación.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.reset_score(score_map, "José Valim")
# => %{"José Valim"=> 0}
```

## 5. Actualiza la puntuación de un jugador

Para actualizar la puntuación de un jugador sumándole la puntuación anterior, define `HighScore.update_score/3`, que recibe 3 argumentos:

- El primer argumento es el mapa de puntuaciones.
- El segundo argumento es el nombre del jugador como string, cuya puntuación quieres actualizar.
- El tercer argumento es la puntuación que quieres **añadir** a la puntuación máxima almacenada.

La función también debe funcionar si el jugador no tiene una puntuación previa: asume que la puntuación previa es 0.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"José Valim"=> 486_373}
score_map = HighScore.update_score(score_map, "José Valim", 5)
# => %{"José Valim"=> 486_378}
```

## 6. Obtén una lista de jugadores

Para obtener una lista de jugadores, define `HighScore.get_players/1`, que recibe 1 argumento:

- El primer argumento es el mapa de puntuaciones.

```elixir
score_map = HighScore.new()
# => %{}
score_map = HighScore.add_player(score_map, "Dave Thomas", 2_374)
# => %{"Dave Thomas" => 2_374}
score_map = HighScore.add_player(score_map, "José Valim", 486_373)
# => %{"Dave Thomas" => 2_374, "José Valim"=> 486_373}
HighScore.get_players(score_map)
# => ["Dave Thomas", "José Valim"]
```
