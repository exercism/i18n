# no se usan argumentos por defecto

No se usa ningún [argumento por defecto][default argument] en la definición de la función de esta solución.
Los [argumentos por defecto en Python][default arguments in python] pueden ayudar a protegerte frente a situaciones en las que se llama a una función sin un argumento esperado o en las que no hay ningún argumento disponible para pasar.
`Default arguments` también pueden ayudar a evitar código condicional innecesario o comprobaciones dentro de una función.

Esta solución se puede mejorar haciendo uso de un `default argument` junto con [str.format][str.format] o [f-strings][f-strings] (_también conocidos como «formatted string literals» o «interpolated strings»_).

[String Formatting in Python][string formatting in python], de Real Python, puede ser un buen punto de partida para aprender sobre las opciones de formato de strings de Python.
