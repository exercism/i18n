# Anexo a las instrucciones

## Personalizar y lanzar excepciones

A veces es necesario tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) las excepciones de tu código como usar [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) para lanzarlas. Cuando lo hagas, incluye siempre un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar.

Las excepciones personalizadas se pueden crear con nuevas clases de excepción (consulta [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para más detalles), que normalmente son subclases de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

En los casos en los que sepas que el origen del error será una derivación de un determinado tipo de excepción, puedes optar por heredar de uno de los [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) que hay bajo la clase _Exception_. Cuando lances el error, debes incluir igualmente un mensaje significativo.

Este ejercicio en concreto requiere que crees dos _excepciones personalizadas_. Una excepción que se [lance](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«arroje» cuando tu búfer circular esté **lleno** y otra para cuando esté **vacío**. Los tests solo pasarán si personalizas las excepciones adecuadas, usas `raise` para lanzarlas e incluyes los mensajes de error adecuados.

Para personalizar una `built-in exception`, crea una `class` que herede de esa excepción. Al lanzar la excepción personalizada con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# subclassing the built-in BufferError to create BufferFullException
class BufferFullException(BufferError):
    """Exception raised when CircularBuffer is full.

    message: explanation of the error.

    """
    def __init__(self, message):
        self.message = message

        
# raising a BufferFullException
raise BufferFullException("Circular buffer is full")
```
