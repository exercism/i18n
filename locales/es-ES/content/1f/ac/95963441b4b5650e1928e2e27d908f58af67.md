# formato con porcentaje o «estilo antiguo»

Esta solución usa `%%-formatting` o el [formato de estilo antiguo][old-style formatting] para los strings.

Aunque `%%-formatting` es un enfoque totalmente válido, puede dar lugar a problemas de representación o de legibilidad.
Usar el método [str.format()][str.format()] o los [f-strings][f-strings] (_también conocidos como «literales de cadena formateados» o «cadenas interpoladas»_) puede ofrecer opciones que mejoran la legibilidad y dejan más claro el reemplazo de variables dentro de los strings.

La entrada de blog [String Formatting in Python][string formatting in python] es un buen punto de partida para entender todas las opciones de formato de strings de Python, y [Newer Python String Format Techniques][newer python string format techniques] también ofrece algunos consejos y trucos útiles para usar `str.format()` y `f-strings`.
