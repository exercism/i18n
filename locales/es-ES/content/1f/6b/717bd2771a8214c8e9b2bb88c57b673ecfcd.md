# Instrucciones

La biblioteca de Luton es una gran biblioteca con una amplia colección de literatura, que abarca desde libros hasta arte.
La biblioteca tiene una sección en la que se estudia literatura y se añaden libros al sistema informático.

Ciertas partes pretenden automatizarse y te han pedido que les ayudes.
Esto incluye ayudar con cosas que van desde automatizar los formularios del proceso de inscripción hasta ayudar a descifrar textos.

## 1. Obtener la primera letra del título

Se supone que los libros de una biblioteca son fáciles de encontrar, por lo que se ordenan por la primera letra del título.

Implementa el método `Library.first_letter`, que recibe un argumento `title`, que contiene el título del libro.
El método debe devolver la primera letra del título.

```Crystal
Library.first_letter("Mystery of the Crystal Skull")
# => 'M'
```

## 2. Obtener las iniciales del autor

La biblioteca tiene muchos libros escritos por distintos autores.
A menudo se hace referencia a los autores por sus iniciales, así que la biblioteca pidió un sistema que proporcione las iniciales del autor introduciendo su nombre y su apellido.
Las iniciales deben tener este formato: `{first_letter_of_first_name}.{first_letter_of_last_name}`

Implementa el método `Library.initials`, que recibe dos argumentos, `first_name` y `last_name`, que contienen el nombre y el apellido del autor.
El método debe devolver las iniciales del autor.

```Crystal
Library.initials("William", "Shakespeare")
# => "W.S"
```

## 3. Descifrar una letra

Parte de la literatura está cifrada y la biblioteca tiene muchos textos cifrados.
A la biblioteca le gustaría contar con un nuevo sistema de descifrado para un cifrado especial.

El cifrado funciona tomando la letra y sustituyéndola por la letra que la precede en el alfabeto.
Por ejemplo, `a` se convierte en `z`, `b` se convierte en `a`, `c` se convierte en `b`, y así sucesivamente.

A la biblioteca le gustaría que fuese capaz de descifrar tanto letras mayúsculas como minúsculas y que conserve si son mayúsculas o minúsculas igual que la letra original.

Implementa el método `Library.decrypt_character`, que recibe un argumento `character`, que contiene la letra que hay que descifrar.
El método debe devolver la letra descifrada.

```Crystal
Library.decrypt_character('a')
# => 'z'
```

## 4. Descifrar un texto

A la biblioteca también le gustaría descifrar un texto completo, con el cifrado que toma la letra anterior del alfabeto.

El descifrador solo debe descifrar letras y dejar todos los demás caracteres tal cual están.

Implementa el método `Library.decrypt_text`, que recibe un argumento `text`, que contiene el texto que hay que descifrar.
El método debe devolver el texto descifrado.

```Crystal
Library.decrypt_text("Ifmmp Xpsme!")
# => "Hello World!"
```
