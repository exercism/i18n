# Introducción

## Átomos

El tipo `atom` de Elixir representa una constante fija. El valor de un átomo es simplemente su propio nombre. Esto nos da una forma segura en cuanto a tipos de interactuar con los datos. Los átomos se pueden definir así:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

Internamente, los _átomos_ se representan mediante un número entero en una tabla de búsqueda, que se asigna automáticamente. No es posible cambiar este valor interno.

## Cond

A menudo queremos escribir código que pueda ramificarse según una condición. Aunque en Elixir hay muchas formas de hacerlo, una de las más sencillas es usar `cond/1`.

En su forma más simple, `cond` sigue la primera rama que se evalúa como `true` de entre una o más ramas:

```elixir
cond do
  x > 10 -> :this_might_be_the_way
  y < 7 -> :or_that_might_be_the_way
  true -> :this_is_the_default_way
end
```

Si ninguna rama se evalúa como `true`, el entorno de ejecución lanza un error.
