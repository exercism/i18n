# Instrucciones

Llamar a APIs es una parte importante de escribir código en internet. En este ejercicio, tendrás que obtener datos de un endpoint y asegurarte de que se han recuperado correctamente.

## Objetivos

- Modifica el código proporcionado.
- Invoca el cliente HTTP e intenta obtener una cita. Este resultado debe ser un tipo unión formado por `string` y `error`.
- Si se recibe la cita, imprímela en la consola (usando `io:println()`).
- Si se ha producido un `error`, imprime el mensaje de error en la consola.
