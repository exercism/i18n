# Apéndice de instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, siempre deberías incluir un **mensaje de error significativo** para indicar cuál es el origen del error. Esto hace que tu código sea más legible y ayuda enormemente a la hora de depurar. En situaciones en las que sabes que el origen del error será de un tipo concreto, puedes optar por lanzar uno de los [tipos de error incorporados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así deberías incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» un `ValueError` cuando el valor dado no se encuentre dentro del array. Las pruebas solo pasarán si tanto haces `raise` de la `exception` como incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# example when value is not found in the array.
raise ValueError("value not in array")
```
