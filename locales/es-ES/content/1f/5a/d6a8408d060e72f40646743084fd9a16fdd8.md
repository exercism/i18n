# Null

Null es un tipo de valor primitivo con un solo valor: `null`.
Null se usa a menudo para representar la nada.
Se considera «falso», pero es distinto de `false` y de otros valores falsos.

```php
<?php

is_null(null); // => true
isset(null); // => false

null == true; // => false
null === true; // => false

null == false; // => true
null === false; // => false
```

## Trabajar con valores null

En PHP, los valores null pueden ser una causa común de error, ya que a menudo se devuelven en lugar de un estado de error o para representar la nada.
Prevenir que surjan errores a menudo requiere «comprobar si es null» para asegurarse de que el valor no es null antes de operar con él.

Comprobar repetidamente si es null puede ser propenso a errores, por lo que PHP proporciona dos operadores para trabajar con valores null: el operador de acceso seguro frente a null `?->` y el operador de fusión de null `??`.
