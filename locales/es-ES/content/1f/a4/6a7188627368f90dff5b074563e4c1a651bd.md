# Fundamentos de la sintaxis de Haskell

## Constantes y funciones

Los programas de Haskell se componen de definiciones y expresiones.

Un valor constante se define con `name = expression`.

```haskell
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`, donde los parámetros solo se separan con espacios.

```haskell
add number1 number2 = number1 + number2
```

Invocar una función también es una expresión, y se hace indicando su nombre y pasando argumentos para cada uno de los parámetros de la función, separados por espacios, igual que en las definiciones de funciones.

```haskell
five = add 2 3
```

Se pueden usar paréntesis para especificar el orden de evaluación de una expresión.

```haskell
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Sangría / espacios en blanco significativos

Haskell usa espacios en blanco y sangría para delimitar el código.
***El código que forma parte de una expresión debe estar más sangrado que el inicio de esa expresión.***

- Las definiciones de módulos, importaciones y funciones de nivel superior deben empezar en la columna más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe ir sangrado bajo esa expresión con al menos un espacio.
- Las partes de la expresión que van agrupadas deben ir sangradas con el mismo número de espacios.

```haskell
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://en.wikibooks.org/wiki/Haskell/Indentation

## Módulos

Los módulos exportan funciones.
Eso significa que puedes usar las funciones que el módulo pone a disposición en su declaración de exportación.
Un módulo también puede definir funciones solo para uso interno.
De forma predeterminada, las funciones que no se exportan explícitamente no se pueden usar desde fuera del módulo.

Al principio de un módulo, especificamos el nombre del módulo.
Si tenemos un archivo llamado Calculator.hs, deberíamos llamar Calculator a nuestro módulo.
Después, especificamos las funciones que exporta y, tras eso, podemos empezar a escribir las funciones.
Así que empezaremos con esto.

```haskell
module Calculator ( add ) where
```

https://learnyouahaskell.github.io/modules#making-our-own-modules

## Comentarios

Un comentario es un texto dentro del archivo de Haskell que no se interpreta como código.
Está pensado principalmente para que lo lean tú y otros programadores.
Hay una sintaxis ligera para los comentarios de una sola línea, basada en guiones dobles.
También se pueden escribir comentarios multilínea con el par de delimitadores de apertura y cierre `{-` y `-}`.

```haskell
-- a single line comment
-- another single line comment

{- a multiline comment
   spanning multiple lines
-}
```
