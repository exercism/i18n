# Acerca de

PHP es un lenguaje del lado del servidor orientado al desarrollo web. Su acrónimo es recursivo, ya que significa _PHP: Hypertext Preprocessor_.

Mucho más versátil que la programación de scripts CGI, PHP se usa a menudo para añadir interactividad a HTML básico y reforzar frameworks web.

El lenguaje se puede usar en cualquier sistema operativo. PHP es compatible con la mayoría de los servidores web habituales y a menudo se gestiona mediante un módulo intérprete. Esto combina el código web estático con inclusiones dinámicas.

PHP no es solo un framework de servidores web. También es útil para la programación de scripts en la línea de comandos (análisis sin interfaz gráfica) y para desarrollar interfaces gráficas.

Deberías aprender PHP porque:

- es un lenguaje de código abierto
- está bien documentado y cuenta con buen soporte
- es compatible con la mayoría de los servidores web habituales
- es fácil de aprender y de empezar con él
- es muy escalable y extensible
