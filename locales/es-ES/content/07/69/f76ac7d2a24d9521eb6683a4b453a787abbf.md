# Cómo escribir una buena solicitud de ayuda

¿Quieres ayuda con un ejercicio de Exercism?
Aumenta tus posibilidades de recibir una buena respuesta aprendiendo a escribir una buena solicitud de ayuda y animando a nuestra comunidad a apoyarte.

Aquí tienes algunos consejos clave.

## Usa bloques de código, no imágenes

Cuando quieras compartir código (ya sea el que has escrito tú o instrucciones), usa un bloque de código, no una imagen.

Como desarrolladores, somos mucho más rápidos leyendo código que teniendo que ampliar una imagen para ver las cosas.
Y muchos de nuestros usuarios usan lectores de pantalla, que no pueden leer las imágenes.
Así que, si quieres ser un buen miembro de la comunidad, animar a nuestros voluntarios a ayudarte y parecer todo un profesional, ¡comparte tu código como texto, no como imagen!

Por ejemplo, puedes escribir lo siguiente:

````
```
for number in range(10):
  total += number;
```
````

Eso se mostrará así:

```
for number in range(10):
  total += number;
```

Incluso puedes obtener resaltado de sintaxis añadiendo el lenguaje al inicio del bloque de código:

````
```python
for number in range(10):
  total += number;
```
````

que se convierte en:

```python
for number in range(10):
  total += number;
```

## Usa un lenguaje inclusivo

Exercism está formado por personas de distintos géneros.
Si apareces en nuestro Discord y dices cosas como «Hola chicos», estás excluyendo de inmediato a la mitad de nuestra comunidad.
Eso significa que es menos probable que te ayuden, pero también significa que el resto de la comunidad tiene menos probabilidades de ayudarte, porque en Exercism valoramos la inclusión.

Así que, si quieres recibir ayuda y quieres ser una buena persona, no uses un lenguaje que haga referencia al género.
Prueba con «Hola gente», «Hola a todos» o atrévete de verdad y elige «¡Hola, colegas Exercists!»

Para saber más sobre esto, lee nuestro artículo sobre [las palabras que usamos](./the-words-that-we-use).
