# Cómo probar los ejercicios

Sigue los pasos que se indican a continuación para desarrollar la solución de un ejercicio y probarla localmente.

## Descarga el ejercicio

Abre un Command Prompt y ejecuta el comando que aparece a continuación indicando el nombre del ejercicio que quieras descargar.

```sh
exercism download --track ballerina --exercise <exercise-name>
```

## Desarrolla tu solución

1. Ejecuta el comando que aparece a continuación para ir al directorio del ejercicio que acabas de descargar.

     >**Consejo:** La ubicación del directorio en el comando que aparece a continuación depende de tu sistema operativo y del espacio de trabajo de Exercism que tengas configurado. Puedes averiguar la ubicación de tu espacio de trabajo ejecutando el comando `exercism configure`.

     ```sh
     cd ~/exercism/ballerina/hello-world/
     ```

2. Sigue las instrucciones que se indican y desarrolla una solución para el ejercicio.

## Prueba tu solución

Algunos ejercicios de Ballerina tienen una sola prueba, mientras que otros tienen varias. Las pruebas se encuentran en el archivo de pruebas correspondiente del directorio `/tests`, dentro del directorio raíz del ejercicio.

### Probar un ejercicio con una sola prueba

Ejecuta el comando que aparece a continuación para ejecutar la prueba del ejercicio.

De forma predeterminada, solo la primera prueba está habilitada. Esto es intencionado, ya que te permite centrarte únicamente en hacer que esa prueba pase. 
     
```sh
bal test
```

### Probar un ejercicio con varias pruebas

Sigue los pasos que se indican a continuación para probar un ejercicio con varias pruebas.

1. Cuando la primera prueba pase, habilita la siguiente eliminando la propiedad `enable: false` de la anotación `@test:Config`.

     ```ballerina
     @test:Config {
       enable: false
     }
     function nextTestCase() {
     }
     ``` 

2.  Ejecuta el comando que aparece a continuación para ejecutar la prueba habilitada.

   ```sh
     bal test
   ```

3. Repite los dos pasos anteriores para habilitar las pruebas restantes.

Habrás completado el ejercicio con éxito cuando hayas habilitado todas las pruebas y te hayas asegurado de que tu implementación pasa cada una de ellas.
