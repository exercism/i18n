# Pistas

## General

Los condicionales se usan para comprobar determinadas condiciones y/o criterios. La forma más básica de realizar una operación condicional es usar una única instrucción `if`.

## 1. Calcula la puntuación de una carta cualquiera.

La función `parseCard` debe tomar el string `card` (p. ej. `ace`) y convertirlo en su valor (p. ej. 11).

- Usa una [instrucción `switch`][switch-statement] grande sobre la variable `card`.
- El rey, la reina, la jota y el 10 se pueden manejar con un solo caso.
- El `switch` puede tener un caso `default`. En cualquier caso, la función debe devolver `0` para las cartas desconocidas.

## 2. Determina si dos cartas forman un Blackjack.

`isBlackJack` comprueba si 2 cartas tienen el valor combinado de 21.

- Debe usar la función `parseCard` para obtener el valor de cada carta.
- Debe sumar los valores de las 2 cartas.
- Debe devolver `true` si la suma es igual a `21`.
- Aquí no se necesita ninguna instrucción adicional. Se puede devolver el resultado de la comparación.

## 3. Implementa la lógica de decisión para puntuaciones de mano superiores a 20 puntos.

Como solo se llama a la función `largeHand` para manos con un valor mayor que 20, solo hay 2 manos posibles diferentes: un **BlackJack** con un valor total de `21` y **2 ases** con un valor total de `22`.

- La función debe comprobar [si][if-statement] `isBlackJack` es `true` y, en caso contrario, devolver «P».
- Si `isBlackJack` es `true`, hay que comprobar si dealerScore es menor que 10. [Si][if-statement] es menor, devuelve «W»; en caso contrario, «S».

## 4. Implementa la lógica de decisión para puntuaciones de mano inferiores a 21 puntos.

Solo se llama a la función `smallHand` si no hay ases en la mano (`handScore` es menor que 21).

- Implementa cada condición usando [operadores lógicos][logical-operators] si es necesario:
  - [Si][if-statement] tus cartas suman 17 o más, siempre debes _plantarte_.
  - [Si][if-statement] tus cartas suman 11 o menos, siempre debes _pedir carta_.
  - [Si][if-statement] tus cartas suman un valor dentro del rango [12, 16], siempre debes _plantarte_ si el crupier tiene un 6 o menos.
  - [Si][if-statement] tus cartas suman un valor dentro del rango [12, 16], siempre debes _pedir carta_ si el crupier tiene un 7 o más.
- (opcional) Intenta optimizar las condiciones:
  - Reúne en una sola las condiciones para _plantarse_.
  - Reúne en una sola las condiciones para _pedir carta_.
  - Elimina las partes redundantes de las condiciones (p. ej. `A || !A && B` puede ser `A || B`).
