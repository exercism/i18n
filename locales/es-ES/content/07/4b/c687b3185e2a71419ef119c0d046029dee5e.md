## «null» en Tcl

Tcl no tiene un valor `null` ni `nil`.
En la práctica, el string vacío se usa a menudo para indicar «ningún valor».
Pero eso puede resultar complicado en situaciones en las que un string vacío es en realidad un valor válido, por ejemplo en un array que representa una fila de datos CSV.

Para este ejercicio, trata el string vacío como un valor null que hay que descartar.
