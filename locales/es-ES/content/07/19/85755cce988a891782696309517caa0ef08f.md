# Pistas

## General

- En una clase inmutable no hay `new`. `create` parte de una variable de la clase, que ya existe:

  ```sather
     create(d : INT) : SAME is
        b : SAME;
        return b.degrees(...);
     end;
  ```

- `b.degrees(x)` no cambia `b`. Devuelve un nuevo rumbo, y por eso es lo que se devuelve.

## 1. Toma un rumbo

- `%` sitúa un número dentro del rango, pero `-10 % 360` es `350` solo porque el `%` de Sather nunca da un resultado negativo cuando el lado derecho es positivo. Así que `d % 360` basta por sí solo.

## 2. Gira

- Suma el giro a los grados y crea un nuevo rumbo a partir del total: `#BEARING(degrees + by)`.
- `create` ya vuelve a situar la respuesta dentro del rango, así que no hay que preocuparse por girar más allá del norte.

## 3. Compara

- Una sola línea: compara los dos `degrees`.
- El tipo del argumento es `SAME`, y lees su atributo de la forma habitual: `other.degrees`.

## 4. Nombra el punto

- El truco consiste en desplazar medio segmento antes de dividir, de modo que el *centro* de cada punto sea la referencia desde la que se mide: `((degrees + 22) / 45) % 8` da 0 para el norte, 1 para el noreste, etcétera.
- Después, un `case` sobre ese número con los ocho nombres, y un `else`, que `case` siempre necesita aunque las ocho ramas cubran todos los valores posibles.

## 5. Escríbelo

- `+` une las piezas, pero solo a un string se le pueden sumar cosas. Aquí el número va primero, así que necesita `degrees.str` para iniciar la unión. `"a" + 1` está bien; `1 + "a"` no compila.
- Llama a `point` en lugar de volver a calcular el nombre.
