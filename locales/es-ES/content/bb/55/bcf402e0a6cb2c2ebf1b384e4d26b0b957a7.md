# Instrucciones

Este ejercicio aborda el análisis de archivos de registro.

Tras una revisión de seguridad reciente, se te ha pedido que limpies los archivos de registro archivados de la organización.

Se garantiza que todos los strings que se pasan a los métodos son no nulos y no tienen espacios al principio ni al final.

## 1. Identifica las líneas de registro distorsionadas

Necesitas hacerte una idea de cuántas líneas de registro de tu archivo no cumplen con los estándares actuales. Crees que una prueba sencilla revela si una línea de registro es válida. Para que se considere válida, una línea debe empezar por uno de los siguientes strings:

- [TRC]
- [DBG]
- [INF]
- [WRN]
- [ERR]
- [FTL]

Implementa el método `LogParser.IsValidLine()` para que devuelva `false` si un string no es válido y, en caso contrario, `true`.

```csharp
var lp = new LogParser();
lp.IsValidLine("[ERR] A good error here");
// => true
lp.IsValidLine("Any old [ERR] text");
// => false
lp.IsValidLine("[BOB] Any old text");
// => false
```

## 2. Divide la línea de registro

Un equipo nuevo se ha incorporado a la organización y descubres que sus archivos de registro usan un separador extraño para los «campos». En lugar de algo sensato como un signo de dos puntos «:», usan un string como «<--->» o «<=>» (porque es más bonito); de hecho, cualquier string cuyo primer carácter sea «<», cuyo último carácter sea «>» y que tenga en medio cualquier combinación de los siguientes caracteres: «^», «\*», «=» y «-».

Implementa el método `LogParser.SplitLogLine()`, que recibe una línea y devuelve un array de strings que contienen cada uno un campo.

```csharp
var lp = new LogParser();
lp.SplitLogLine("Section 1<===>Section 2<^-^>Section 3");
// => {"Section 1", "Section 2", "Section 3"}
```

## 3. Cuenta el número de líneas que contienen una contraseña entre comillas

El equipo necesita saber de las contraseñas que aparecen en texto entrecomillado para poder examinarlas manualmente.

Implementa el método `LogParser.CountQuotedPasswords()` para ofrecer una indicación de la probable magnitud del trabajo manual.

Identifica las líneas de registro en las que el string literal «password», que puede estar en cualquier combinación de mayúsculas y minúsculas, está rodeado de comillas.
Debes tener en cuenta la posibilidad de que haya contenido adicional entre las comillas, antes y después de «password».

Las líneas que se pasan a la rutina pueden ser válidas o no según lo definido en la tarea 1. Las procesamos del mismo modo, sean válidas o no.

```csharp
string lines =
    "[INF] passWord " + Environment.NewLine + // contains 'password' but not surrounded by quotation marks
    "\"passWord\"" + Environment.NewLine + // count this one
    "[INF] User saw error message \"Unexpected Error\" on page load." + Environment.NewLine + //does not contain 'password'
    "[INF] \"The secret password was added by the user\""; // count this one

var lp = new LogParser();
lp.CountQuotedPasswords(lines);
// => 2
```

## 4. Elimina artefactos del registro

Has descubierto que cierto procesamiento previo de los registros ha ido dispersando por todos los registros el texto «end-of-line» seguido de un número de línea (sin un espacio entre medias).

Implementa el método `LogParser.RemoveEndOfLineText()`, que recibe un string, elimina el texto «end-of-line» y devuelve un string «limpio».

Las líneas que no contengan el texto «end-of-line» deben devolverse sin modificar.

Limítate a eliminar el string «end-of-line». No intentes ajustar los espacios en blanco.

```csharp
var lp = new LogParser();
lp.RemoveEndOfLineText("[INF] end-of-line23033 Network Failure end-of-line27");
// => "[INF]  Network Failure "
```

## 5. Enumera las líneas con contraseñas extremadamente débiles para que se pueda castigar a los culpables

Antes de eliminar las contraseñas del archivo, necesitamos enumerar los casos en los que las contraseñas empiezan por el texto «password».

Implementa el método `LogParser.ListLinesWithPasswords()` para imprimir la contraseña infractora seguida de la línea completa.

Las líneas con contraseñas entre comillas ya se han eliminado, y procesas las líneas independientemente de si son válidas o no (según la tarea 1).

Las líneas que contengan una contraseña infractora deben devolverse con el prefijo «<password>: ».

Las líneas que no contengan una contraseña infractora deben devolverse con el prefijo «--------: ».

```csharp
var lp = new LogParser();
lp.ListLinesWithPasswords(new string[] {"my passwordsecret is great"});
// => "passwordsecret: my passwordsecret is great"
lp.ListLinesWithPasswords(new string[] {"my password secret"});
// => {"--------: my password secret"}

```
