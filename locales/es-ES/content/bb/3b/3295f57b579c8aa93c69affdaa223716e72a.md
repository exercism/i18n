# Pistas

## 1. ¿Cuántas tenemos?

- Pregunta primero a `has_ind` y haz un `raise` cuando la respuesta sea falsa.
- El mensaje se construye con `+`, como cualquier string:
  `raise "Unknown prop: " + prop;`
- Nada de lo que va después de un `raise` se ejecuta, así que no hay ningún `else` que escribir. El `return` que hay debajo solo se alcanza cuando la prop está presente.

## 2. Toma una

- Llama a `count_of` para obtener el número. Si la prop es desconocida, esa llamada lanza una excepción y `take_one` también: no tienes que escribir nada para ello, y no deberías.
- Luego comprueba si es cero y lanza `"Out of " + prop`.
- En caso contrario, devuelve uno menos.

## 3. Informa

- `protect` alrededor de una llamada a `take_one`, con una rama `when $STR then`.
- En la parte de `protect`, toma una y construye el mensaje de éxito a partir de lo que respondió.
- En la rama `when`, el mensaje es `exception.str` y nada más. No intentes averiguar qué fallo fue; lo que se haya lanzado ya son las palabras correctas.
