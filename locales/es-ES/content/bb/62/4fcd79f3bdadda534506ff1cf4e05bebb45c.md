# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [/r/fsharp](https://www.reddit.com/r/fsharp) es el subreddit de F#.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/f%23) para buscar tu problema y ver si ya se ha respondido. También puedes hacer preguntas y responderlas.

## Paquetes

El itinerario de F# admite un número limitado de paquetes.
Consulta la [lista de paquetes compatibles](https://exercism.org/docs/tracks/fsharp/packages) para saber cuáles son.
