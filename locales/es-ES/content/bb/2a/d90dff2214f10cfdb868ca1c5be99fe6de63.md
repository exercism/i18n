# Acerca de

Los tipos de C# pueden definirse dentro del scope de una clase o un struct. El tipo contenedor proporciona una especie de espacio de nombres. Se accede al tipo a través del tipo contenedor con la sintaxis de punto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

## Niveles de acceso

Los niveles de acceso pueden aplicarse a los tipos internos. Por ejemplo, si una clase es `private`, no puede verse fuera del scope del tipo contenedor y, por supuesto, sus instancias tampoco pueden verse ni usarse fuera de ese scope.

Los miembros privados de la clase externa están en el scope de todos los miembros de la clase interna, pero solo los miembros no privados de la clase interna están en el scope de los miembros de la clase externa. Para acceder a los miembros de la clase externa, hay que proporcionar a la clase interna una instancia de la clase externa.

Esto se puede ver en el siguiente ejemplo:

```csharp
class Outer
{
    public class InnerImpl
    {
        private Outer outer;

        public int Interesting = 42;

        public InnerImpl(Outer outer, int interesting)
        {
            this.outer = outer;
            Interesting = interesting;
        }

    }

    public InnerImpl Inner;
    public Outer()
    {
        Inner = new InnerImpl(this, 42);
    }
}

var outer = new Outer();
outer.Inner.Interesting
// => 42
var inner = new Outer.InnerImpl(outer, 1729);
outer.Inner.Interesting
// => 1729
```

## Evitar la instanciación independiente

Existe un patrón para evitar que un tipo instanciable se cree fuera del tipo contenedor. Expone una interfaz pública, pero mantiene privada la clase que la implementa.

```csharp
class Outer
{
    public interface IInner
    {
        void DoSomething();
    }

    private class InnerImpl : IInner
    {
        private Outer outer;
        public InnerImpl(Outer outer)
        {
            this.outer = outer;
        }
        public void DoSomething()
        {
            outer.DoSomethingElse();
        }
    }

    public IInner Inner;

    public Outer()
    {
        Inner = new InnerImpl(this);
    }
    private void DoSomethingElse()
    {
    }
}

var outer = new Outer();
outer.Inner.DoSomething();

// NOT var inner = new Outer.Inner(outer);
```

## Nota para desarrolladores de Java

Las clases anidadas de C# son un cruce entre las clases anidadas estáticas y las clases internas de Java. En C#, los miembros privados de la clase contenedora están en el scope de los miembros de la clase anidada, pero no hay ninguna sintaxis especial para instanciarlos y vincularlos a una instancia de la clase contenedora. Tienes que usar alguna variante del patrón ilustrado en los ejemplos anteriores.

C# sí tiene clases anidadas estáticas, pero no son más que clases contenidas con un comportamiento estático.
