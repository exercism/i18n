# Instrucciones

En este ejercicio vas a seguir trabajando con coches teledirigidos.

Se ha desarrollado un coche experimental y la pista de pruebas debe adaptarse para poder manejar tanto los modelos de producción como los experimentales.
Los dos tipos de coche ya están construidos y tienes que encontrar la forma de tratar con ambos en la pista de pruebas.

Además, los coches de producción están empezando a tener cierto éxito.
El jefe del equipo quiere mantener el espíritu competitivo publicando una clasificación de los coches de producción.

## 1. Implementa la interfaz

Añade dos métodos a la interfaz `RemoteControlCar`:

- `drive()`, que no devuelve nada, y
- `getDistanceTravelled()`, que devuelve un `int`.

Después, haz que `ProductionRemoteControlCar` y `ExperimentalRemoteControlCar` implementen la interfaz `RemoteControlCar`.
Esto incluye implementar todos los métodos que requiere la interfaz.

## 2. Conduce

Cada llamada a `.drive()` debe hacer que el coche recorra una cierta distancia:

- un `ProductionRemoteControlCar` recorre 10 unidades,
- un `ExperimentalRemoteControlCar` recorre 20 unidades.

El método `.getDistanceTravelled()` debe devolver el número de unidades que el coche ha recorrido a lo largo de su vida.

```java
ProductionRemoteControlCar prod = new ProductionRemoteControlCar();
prod.drive();
prod.getDistanceTravelled();
// => 10
        
ExperimentalRemoteControlCar exp = new ExperimentalRemoteControlCar();
exp.drive();
exp.getDistanceTravelled();
// => 20
```

## 3. Carrera

Implementa el método `TestTrack.race(RemoteControlCar car)`, en el que los `car` pueden llamar a `drive()`.

```java
TestTrack.race(new ProductionRemoteControlCar());
TestTrack.race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 4. Permite ordenar los coches de producción

Implementa la interfaz `Comparable<T>` en la clase `ProductionRemoteControlCar`.
El orden de clasificación predeterminado de los coches debe ser el orden descendente de victorias.

Implementa el método estático `TestTrack.getRankedCars()` para que devuelva los coches que se le pasan, ordenados de forma descendente por número de victorias.

```java
ProductionRemoteControlCar prc1 = new ProductionRemoteControlCar();
ProductionRemoteControlCar prc2 = new ProductionRemoteControlCar();
prc1.setNumberOfVictories(2);
prc2.setNumberOfVictories(3);
List<ProductionRemoteControlCar> unsortedCars = new ArrayList<>();
unsortedCars.add(prc1);
unsortedCars.add(prc2);
List<ProductionRemoteControlCar> rankings = TestTrack.getRankedCars(unsortedCars);
// => rankings.get(0) == prc2
// => rankings.get(1) == prc1
```
