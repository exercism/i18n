# Introducción

## Aleatoriedad

Se puede usar una instancia de la clase `java.util.Random` para generar números aleatorios en Java.

### Números enteros aleatorios

Se puede generar un número entero aleatorio con el método `nextInt()`.
Esto generará un valor en el rango desde `Integer.MIN_VALUE` hasta `Integer.MAX_VALUE`.

```java
Random random = new Random();

random.nextInt();
// => -1169335537
```

Para limitar el rango de los valores generados, usa `nextInt(int)`.
Esto generará un valor en el rango desde `0` (incluido) hasta el límite superior indicado (excluido).

Por ejemplo, esto generará un número aleatorio del `0` al `9`.

```java
Random random = new Random();

random.nextInt(10);
// => 6
```

Y esto generará un número aleatorio del `10` al `19`.

```java
Random random = new Random();

10 + random.nextInt(10);
// => 11
```

### Números decimales aleatorios

Se puede generar un número decimal aleatorio con el método `nextDouble()`.
Esto generará un valor en el rango desde `0.0` hasta `1.0`.

```java
Random random = new Random();

random.nextDouble();
// => 0.19250004204021398
```

Y esto generará un número aleatorio desde `100.0` hasta `200.0`.

```java
Random random = new Random();

100.0 + 100.0 * random.nextDouble();
// => 111.31849856260328
```
