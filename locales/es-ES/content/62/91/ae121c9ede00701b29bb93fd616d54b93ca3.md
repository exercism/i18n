## 1. Comprobar si un comando es válido

Además de ser inteligente, el chatbot también es un asistente leal.

Para preguntarle algo al chatbot, el usuario debe decir la palabra «**Chatbot**» en la primera posición del comando.

No importa si la palabra clave está en mayúsculas o en minúsculas. Lo importante aquí es la posición de la palabra.

Implementa la función `is_valid_command()` que ayuda al chatbot a reconocer cuándo el usuario está dando un comando.

```julia-repl
julia> is_valid_command("Chatbot, play a song from the 80's.")
True

julia> is_valid_command("Hey Chatbot, where is the closest pharmacy?")
False

julia> is_valid_command("CHATBOT, do you have a solution for this challenge?")
True
```

## 2. Eliminar los emojis cifrados

Al chatbot le cuesta entender cómo usan las personas los emojis para expresar sus emociones.

Cuando el chatbot recibe mensajes de los usuarios, cada emoji se representa como «_emoji_» seguido de su número _id_.

Implementa el método `remove_emoji()` para que tome un string y elimine todo el cifrado de emojis del mensaje.

Las líneas que no contengan el texto de un emoji deben devolverse sin modificar.

Elimina solo el texto del emoji. No intentes ajustar los espacios en blanco.

```julia-repl
julia> remove_emoji("I love playing videogames emoji3465 it's one of my hobbies")
"I love playing videogames  it's one of my hobbies"
```

## 3. Comprobar si un número de teléfono es válido

Teniendo en cuenta la descarga de funcionalidades del chatbot en una aplicación móvil, se espera que el usuario escriba un número de teléfono durante la conversación.

El problema es que el chatbot solo puede leer y validar un número con un formato específico.

Si el número es válido (coincide con la secuencia de caracteres especificada por la **expresión regular**), el chatbot responde con un mensaje que agradece al usuario y confirma el número. Si el número no es válido, la función informa al usuario de que el número de teléfono no es válido.

El formato esperado es: (+##) ###-###-###

```julia-repl
julia> check_phone_number("(+34) 659-771-594")
"Thanks! You can now download me to your phone."

julia> check_phone_number("659-771-594")
"Oops, it seems like I can't reach out to 659-771-594"
```

## 4. Obtener el enlace de un sitio web

El chatbot es un programa muy curioso. Aunque puede buscar en internet información sobre un tema concreto, le gusta preguntar a los usuarios por sitios web o URL interesantes donde encontrar información relevante.

Ejemplo de conversación:

- **Chatbot**: Hola, usuario, me gustaría aprender a programar en JavaScript, ¿conoces algún sitio web interesante donde pueda aprender?
- **Usuario**: Aprendí mucho en [exercism.org](http://exercism.org)

Implementa la función `getURL()` que es capaz de devolver un array solo con el enlace de cada sitio web.

```julia-repl
julia> getURL("I learned a lot from exercism.org")
["exercism.org"]
```

## 5. Saludar al usuario

Para almacenar los datos de todas las personas con las que ha conversado, el chatbot puede obtener el nombre completo del perfil del usuario con este estilo: **«smith, john»**.

De esta forma, queremos que nuestro chatbot sea muy educado y cause una buena impresión.

Escribe la función `nice_to_meet_you()` que toma un string con el nombre completo del usuario y devuelve el string **«Nice to meet you, John Smith»**

```julia-repl
julia> str = "Smith, John"

julia> nice_to_meet_you(str)
"Nice to meet you, John Smith"
```
