# Instructions

En este ejercicio, implementarás un conjunto parcial de rutinas de utilidad para ayudar a un desarrollador a limpiar nombres de identificadores.
A lo largo de las 5 tareas irás construyendo poco a poco la rutina `Clean`.
Un identificador válido se compone de cero o más letras y guiones bajos.
En todos los casos, se garantiza que el string de entrada no es nulo.
Si se pasa un string vacío a la función `Clean`, debe devolverse un string vacío.
Ten en cuenta que quien llama debería evitar llamar a la rutina `Clean` con un identificador vacío, ya que esos identificadores no tienen ningún efecto.

## 1. Sustituye los espacios que encuentres por guiones bajos

Implementa el método (_static_) `Identifier.Clean()` para sustituir los espacios por guiones bajos.
Esto también se aplica a los espacios al principio y al final.

```csharp
Identifier.Clean("my   Id");
// => "my___Id"
```

## 2. Sustituye los caracteres de control por el string en mayúsculas "CTRL"

Modifica el método (_static_) `Identifier.Clean()` para sustituir los caracteres de control por el string en mayúsculas `"CTRL"`.

```csharp
Identifier.Clean("my\0Id");
// => "myCTRLId",
```

## 3. Convierte kebab-case en camelCase

Modifica el método (_static_) `Identifier.Clean()` para convertir kebab-case en camelCase.

```csharp
Identifier.Clean("à-ḃç");
// => "àḂç"
```

## 4. Omite los caracteres que no sean letras

Modifica el método (_static_) `Identifier.Clean()` para omitir los caracteres que no sean letras.

```csharp
Identifier.Clean("1😀2😀3😀");
// => ""
```

## 5. Omite las letras griegas minúsculas

Modifica el método (_static_) `Identifier.Clean()` para omitir las letras griegas en el rango de la 'α' a la 'ω'.

```csharp
Identifier.Clean("MyΟβιεγτFinder");
// => "MyΟFinder"
```
