# PowerShell

¡Automatízalo todo!
Escribe scripts en cualquier sistema operativo para gestionar archivos, procesos, un centro de datos o servicios en la nube.
Explora de forma interactiva datos estructurados como JSON, XML y CSV; trabaja con todas las interfaces de administración, desde API web y CIM hasta aplicaciones de línea de comandos.

# Acerca de PowerShell

Un lenguaje de scripting .NET de código abierto y multiplataforma, un shell y un marco de trabajo de gestión de configuración, PowerShell ayuda a profesionales de TI y usuarios avanzados a controlar y automatizar casi cualquier cosa.

PowerShell está construido sobre .NET Framework y transforma el concepto clásico de tubería de Unix, extendiéndolo desde el paso de solo texto o flujos binarios hasta admitir el paso de instancias de objetos que incluyen información de tipo (por ejemplo, fechas y horas) y estado complejo con sus datos estructurados.
Mientras que en un shell tradicional podrías usar procesamiento de texto para extraer información concreta de la salida de un comando, en PowerShell tienes acceso a propiedades y métodos (incluidas formas de inspeccionar objetos para determinar qué propiedades y métodos están disponibles).
Puedes trabajar con archivos CSV, convertir JSON en tablas hash, navegar por documentos XML y mucho más, lo que hace que muchas tareas sean fácilmente componibles y que serían difíciles o poco prácticas con el análisis de texto.

PowerShell es extensible.
No solo mediante herramientas de línea de comandos independientes, que es como son extensibles otros shells, sino mediante scripts, funciones y cmdlets distribuidos en módulos que se integran totalmente con el sistema de ayuda de PowerShell, el editor de línea de comandos con resaltado de sintaxis, la detección automática de parámetros y el autocompletado con tabulador.
Incluso puedes extender la sintaxis simple y explorable de propiedades + contenido del sistema de archivos a almacenes de datos como el Registro de Windows y el almacén de certificados, SQL Server e incluso Azure.

PowerShell incluye muchas funcionalidades adicionales:

- Cmdlets integrados para tareas comunes de administración de sistemas, como gestionar archivos, servicios, procesos e incluso el Registro, los registros de eventos y el Modelo de información común (CIM), solicitudes web y mucho más.
- Compatibilidad con scripts y herramientas de línea de comandos existentes.
- Interfaces extensibles y módulos y comandos fáciles de descubrir.
- Acceso completo a .NET Framework y extensibilidad mediante ensamblados .NET de NuGet.
- Un historial de comandos completo con información sobre el éxito y la duración de la ejecución de un comando.
- Potentes capacidades de manipulación de objetos. Los objetos se pueden manipular directamente, serializar e incluso enviar a otras herramientas o bases de datos.

Puedes encontrar documentación detallada sobre PowerShell, el lenguaje, los conceptos básicos y las funcionalidades con los instaladores en https://docs.microsoft.com/en-us/powershell.
