# Consejos

## 1. Desplaza los bits hacia atrás

- Hay dos operadores para desplazar a la derecha, pero solo uno insertará siempre un 0.

## 2. Activa algunos bits

- Uno de los operadores bit a bit pondrá siempre un bit a 1 cuando los bits de ambos valores sean 1.

## 3. Invierte bits concretos

- Hay una operación de bits que invertirá un bit cuando la máscara sea 1.

## 4. Borra bits concretos

- Una de las operaciones de bits borra los bits cuando el bit de la máscara es 0.
- Pero es posible que tengas que combinarla con otro operador para borrar los bits cuando la máscara es 1.
