# Pistas

## General

- [Este tutorial][strings-tutorial] ofrece una buena introducción a los strings de C++.
- La clase `std::basic_string` tiene muchos [métodos integrados][cpp-reference-string] útiles.

## 1. Obtén el mensaje de una línea de registro

- Los métodos integrados ofrecen varias formas de [buscar][cpp-reference-string-find] texto en un string.
- Los métodos integrados pueden ayudarnos a [obtener una parte][cpp-reference-string-substr] de un string

## 2. Obtén el nivel de registro a partir de una línea de registro

Hay varias formas de concatenar strings; la más sencilla es usar el [operador `+`][cpp-reference-string-concatenation], aunque también hay [formas más avanzadas][cpp-reference-printf].
