# Acerca de

El concepto básico de `try .. rescue` se puede ampliar para admitir las cláusulas `else` y `after`:

- El bloque `else`:
  - Donde se produce una coincidencia de patrones con el resultado correcto del bloque `try`.
- El bloque `after`:
  - Donde se llama a funciones tanto si el bloque `try` tiene éxito como si se rescata, siempre que el programa se esté ejecutando.
  - El resultado del bloque `after` no se devuelve al scope desde el que se llama.

```elixir
try do
  :a
rescue
  _ -> :error
else
  :a -> :success
after
  :some_action
end

# => :success
```
