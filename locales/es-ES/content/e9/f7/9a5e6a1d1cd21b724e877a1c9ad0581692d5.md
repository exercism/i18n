# Instrucciones

Eres el telegrafista inalámbrico de un carguero. La señal llega por una línea ruidosa, entremezclada con el Morse que intentas escuchar: la maquinaria del barco, la estática del tiempo y alguna que otra conversación ajena. Para captar el mensaje, haces pasar el cable por un dispositivo de *cinta* que descarta todo salvo los símbolos Morse válidos (`.`, `-` y el espacio que separa las letras).

Tu tarea es construir la cinta como un flujo de entrada personalizado de Factor.

## 1. Define la cinta

Define una tupla `tape` que extienda `disposable` y tenga un slot, `wire`, para el flujo de entrada subyacente.

```factor
TUPLE: tape < disposable wire ;
```

Después, escribe el constructor `<tape> ( wire -- tape )`. Usa `new-disposable` (no `new`) para que el framework de destructores registre la cinta, y guarda el flujo subyacente en el slot `wire`.

## 2. Añade el mixin `input-stream`

Declara que `tape` es un `input-stream`:

```factor
INSTANCE: tape input-stream
```

Eso hace que los combinadores predeterminados del protocolo se despachen a tu clase.

## 3. Lee un símbolo Morse

Implementa `M: tape stream-read1 ( tape -- elt/f )`. Lee bytes del cable subyacente hasta que te encuentres con uno de `CHAR: .`, `CHAR: -` o `CHAR: \s` (espacio). Devuelve ese byte. Si el cable devuelve `f` (fin del flujo), devuelve `f` también: la cinta ha terminado.

```factor
"x.y -ab cz" <string-reader> <tape>
[ stream-read1 ] [ stream-read1 ] [ stream-read1 ] tri
! => CHAR: . CHAR: - CHAR: \s
```

## 4. Delega el tipo de elemento

Implementa `M: tape stream-element-type ( tape -- type )` delegando en el cable: la cinta no cambia el tipo de elementos que se leen.

## 5. Limpia

Implementa `M: tape dispose* ( tape -- )`. El framework llama a tu método exactamente una vez por cada `dispose`; solo tienes que liberar el cable subyacente.

Con esas cinco piezas en su sitio, la cinta funciona como un flujo de entrada normal: `with-input-stream`, `stream-read` y las demás palabras del protocolo se despachan a tus métodos automáticamente.
