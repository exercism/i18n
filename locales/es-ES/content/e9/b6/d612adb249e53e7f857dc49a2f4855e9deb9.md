## Instalación

Algunas distribuciones de Tcl no incluyen el paquete Thread de Tcl de forma predeterminada: puede que haya que instalarlo por separado.
Compruébalo con
```bash
$ echo 'package require Thread' | tclsh
```
Si no produce _ninguna salida_, significa que el paquete Thread ya está instalado.

Ejecuta `apt install tcl-thread` (o `dnf install tcl-thread`) según sea necesario.
