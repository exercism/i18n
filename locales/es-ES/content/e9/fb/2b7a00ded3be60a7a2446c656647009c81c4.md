# Anexo a las instrucciones

## ¿Debería usar `random` o `secrets` aquí?

A partir de Python 3.6, hay dos módulos distintos para generar números «aleatorios»:

El módulo llamado [`random`][random] es [_pseudoaleatorio_][pseudo-random], lo que significa que **no** genera aleatoriedad verdadera, sino que sigue un algoritmo que _simula_ la aleatoriedad.
Como estos «números aleatorios» se generan mediante un algoritmo conocido, no son verdaderamente aleatorios.
En consecuencia, el módulo `random` no es adecuado para la criptografía y no debería usarse, precisamente porque es pseudoaleatorio.


El módulo llamado [`secrets`][secrets] genera números «aleatorios» [criptográficamente fuertes][crypto-strong] que proporcionan la mayor seguridad que requiere la criptografía.
Siguen siendo pseudoaleatorios en el sentido más estricto, pero tienen garantías de que los números que producen son absolutamente impredecibles.


Como este es solo un ejercicio de práctica, usar el módulo `random` está bien, pero ten en cuenta que **sería muy inseguro si se usara realmente para criptografía.**

[pseudo-random]: https://en.wikipedia.org/wiki/Pseudorandomness
[random]: https://docs.python.org/3/library/random.html
[secrets]: https://docs.python.org/3/library/secrets.html
