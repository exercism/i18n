# El ayudante de Papá Noel

## Historia

Eres un elfo que trabaja en la división de logística de Papá Noel y el jefe te ha encargado un par de tareas para actualizar el software del sistema.

## Tareas

La historia facilita la exploración de las [tuplas][type-tuple] en un lenguaje. Lo consigue pidiendo al estudiante que extraiga valores de las tuplas, cree tuplas y trabaje con campos de tupla con nombre a lo largo de dos tareas.

- Convierte las coordenadas a polares
- Combina dos registros de una base de datos
