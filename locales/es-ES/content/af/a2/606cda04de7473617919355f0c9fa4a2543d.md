# Pistas

## General

- Cada tarea es una envoltura fina sobre una palabra del vocabulario de
  [`math.combinatorics`][math.combinatorics].
- Las palabras de recuento toman dos números enteros; las palabras de listado
  toman una secuencia.

## 1. Contar combinaciones

- `nCk ( n k -- m )` devuelve el número de formas de elegir `k` elementos
  de `n`. La pila ya está en el orden correcto, así que solo tienes que
  llamarla.

## 2. Contar permutaciones

- `nPk ( n k -- m )` devuelve el número de formas ordenadas de elegir `k`
  elementos de `n`.

## 3. Listar combinaciones

- `all-combinations ( seq k -- combinations )` devuelve todos los
  subconjuntos de `k` elementos de `seq`, en orden lexicográfico.

## 4. Listar permutaciones

- `all-permutations ( seq -- permutations )` devuelve todas las ordenaciones
  posibles de `seq`.

## 5. Combinaciones que suman un objetivo

- Empieza con todas las combinaciones de `k` elementos de `all-combinations`.
- Conserva solo aquellas cuyos elementos sumen `target`. `filter` de
  [`sequences`][sequences] toma una quotation que devuelve un valor booleano;
  dentro de ella, `sum` (de [`math`][math]) suma todos los elementos de una
  combinación y `=` la compara con el objetivo.
- Como la tarea necesita `target` dentro de la quotation, definir la palabra
  con `::` (de [`locals`][locals]) te permite referirte a `seq`, `k` y
  `target` por su nombre.
