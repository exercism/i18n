# Acerca de

Los dos tipos principales de propiedades son

1. propiedades autoimplementadas, donde los accesores `get` y `set` no tienen cuerpo. Pueden inicializarse explícitamente o no. Por ejemplo:
   ```csharp
   public int MyProperty {get; set;} = 42;
   ```
2. aquellas donde los accesores evalúan expresiones y ejecutan instrucciones. El código puede ser tan simple como devolver o asignar un campo de respaldo. Por ejemplo:
   ```csharp
   private int myField;
   public int MyProperty
   {
     get { return myField; }
     set { myField = value; }
   }
   ```

Existe una superposición considerable de comportamiento y capacidad entre propiedades y métodos.
Cuando no son autoimplementadas, las propiedades pueden contener cualquier instrucción o expresión que pueda aparecer dentro del scope de la clase. En un caso común, a menudo se describen como que envuelven un campo de respaldo.
Aunque la mayoría de las veces es obvio si codificar el comportamiento como una propiedad o un método en un caso concreto, a menudo es una decisión personal del desarrollador y, en particular, cuánto código debe ejecutarse dentro de los accesores. La validación en un accesor set y el cálculo o formato simple en un accesor get son comunes:

```csharp
private float fraction;
public float Percentage
{
  get { return fraction * 100; }
  set
  {
    if (value < 0 || value > 100)
    {
      throw new ArgumentException("Percentage must be between 0 and 100");
    }
    fraction = value / 100;
  }
}
```

De manera similar a otros miembros de la clase, las propiedades pueden tener niveles de acceso.
La mayoría de las veces, las propiedades tendrán un nivel de acceso no privado en consonancia con su propósito esencial. A veces, uno de los accesores tendrá un nivel de acceso diferente al de la propiedad. En el caso de `TareWeight`, bajo la restricción de «seguridad» bastante artificial, había la oportunidad de tener una propiedad pública con un accesor get privado. Esto significa que el código externo a la clase puede establecer el valor de la propiedad, pero solo puede ser leído (get) por código dentro de la clase.

```csharp
public int ConfidentialValueUsedInternally {private get; set; }
```

También se admiten accesores set no públicos, pero un caso más común es aquel en el que el accesor set puede omitirse por completo. Esto puede deberse a que el valor de la propiedad se establece en el constructor de la clase.

```csharp
class MyClass
{
  public MyClass( int importantValue)
  {
    ConstructedValue = importantValue;
  }
  public int ConstructedValue {get;}
}
```
