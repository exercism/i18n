# Introducción

Haxe tiene soporte integrado para expresiones regulares. Se pueden usar para verificar el formato de un string, transformar un string o extraer algunos datos regulares de un texto dado.

Para crear una expresión regular, escribe entre `~/` y `/`:

```haxe
var r = ~/haxe/i;
```

Otra forma de hacer esto es usar la instancia `EReg()`:

```haxe
var r = new EReg("haxe", "i");
```

Aquí la `i` es un flag que hace que el patrón no distinga entre mayúsculas y minúsculas. Hay otros flags, como:

- `g`: reemplazo global.
- `m`: coincidencia multilínea

Entre `~/` y `/`, escribes los patrones de expresión regular. Por ejemplo, quieres buscar un string que contenga letras de la A a la Z. Aquí podemos usar el patrón de rango `[A-Z]`. Hay muchos patrones de expresión, como:

- `.`: cualquier carácter
- `*`: repetir cero o más
- `+`: repetir uno o más
- `[A-Z0-9]`: rangos de caracteres
