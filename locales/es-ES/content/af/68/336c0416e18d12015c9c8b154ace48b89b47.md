# Instalación

El [Godot Engine][godot-engine] se usa para ejecutar código GDScript.
El Godot Engine funciona en Windows, Linux, macOS y Android.

## Instalar Godot Engine

El Godot Engine se puede descargar directamente desde [la web de Godot Engine][download].
La descarga contiene una carpeta zip con dos ejecutables, ambos con el nombre de la versión de Godot Engine.
Extráela y abre el primero de los ejecutables.

Si necesitas una guía en vídeo, tienes una [aquí][video-guide]. (Debería funcionar en Godot 4.7 o en cualquier otra versión de Godot)

Este track usa la versión 4.7.2 de Godot.

[godot-engine]: https://godotengine.org/
[download]: https://godotengine.org/download/
[video-guide]: https://www.youtube.com/watch?v=wOTZo0a_Fek
