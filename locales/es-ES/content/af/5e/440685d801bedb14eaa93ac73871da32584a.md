# Anexo a las instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, debes incluir siempre un **mensaje de error significativo** que indique cuál es el origen del error. Así tu código será más legible y te resultará mucho más fácil hacer debug. Si sabes que el origen del error va a ser de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así debes incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción `raise`](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) para «lanzar» un `ValueError` en los distintos casos de base de entrada y base de salida. Los tests solo pasarán si usas `raise` con la `exception` e incluyes con ella un mensaje significativo.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# for input.
raise ValueError("input base must be >= 2")

# another example for input.
raise ValueError("all digits must satisfy 0 <= d < input base")

# or, for output.
raise ValueError("output base must be >= 2")
```
