# Marcador de posición

## Implementar las operaciones de List

El objetivo de este ejercicio es que implementes tú mismo algunos de los métodos de List.
Es natural usar por debajo un objeto List para guardar los datos.
No toques los métodos de List (como `where`, `map`, etc.).

Hay algunas operaciones «primitivas» de List que son inevitables, como por ejemplo:

* cortar: `list[from..to]`
* añadir: `list.add(item)`

## El protocolo del iterador

Las operaciones de List que hay que implementar consisten en iterar de distintas maneras.
Lee sobre [el protocolo del iterador][iter].
Después podrás hacer lo siguiente:

```wren
var list = ListOps.new([1, 2, 3, 4])
for (item in list) {
    do_something_with(item)
}
```

[iter]: https://wren.io/control-flow.html#the-iterator-protocol
