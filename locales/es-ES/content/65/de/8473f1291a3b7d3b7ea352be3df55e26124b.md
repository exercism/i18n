# Acerca de

Una definición de tipo crea un nuevo tipo con nombre, distinto de cualquier otro tipo, incluso de uno con el mismo tipo subyacente.

## Definir tipos

Una definición de tipo empieza con la palabra clave `type`, seguida del nombre del nuevo tipo y de su tipo subyacente:

```go
type File []bool
```

Aquí, `File` hace referencia a una única columna vertical de un tablero de ajedrez, normalmente etiquetada de la A a la H.
Cada casilla de esta columna se representa con un valor Boolean que indica si está ocupada o no.
Ahora que `File` está definido, podemos usarlo dentro de otras definiciones:

```go
type Chessboard map[string]File

board := Chessboard{
    "A": File{true, false, true},
    "B": File{false, true, false},
}
```

`Chessboard` asigna identificadores de columna a valores `File`.
Cada `File` es un slice de valores Boolean que representa las casillas de una columna del tablero.
Sin estas definiciones de tipo, `board` sería un `map[string][]bool`, lo que haría más difícil entender qué estamos representando.

## Los tipos definidos son distintos

Aunque tanto `Score` como `int` contienen valores enteros, convertir entre ellos requiere una conversión explícita:

```go
type Score int

var number int = 42

// var score Score = number is a compile error
var score Score = Score(number)
var converted int = int(score)
```

`42` es una constante sin tipo, así que se puede asignar directamente a una variable de tipo `Score`.

Los tipos definidos también pueden tener métodos, algo que se trata en el concepto de métodos.

## Tipos struct

Las definiciones de struct utilizan la misma palabra clave `type`:

```go
type Player struct {
    Name  string
    Score Score
}
```

Los tipos struct se tratan en el concepto de structs.

## Alias de tipo

Un alias de tipo crea otro nombre para un tipo existente en lugar de crear un tipo nuevo.
Como un alias y su tipo original son idénticos, sus valores se pueden usar indistintamente.
Los alias se declaran utilizando la palabra clave `type`, el nombre del alias, el signo igual (`=`) y el tipo existente.

```go
type Square = bool

var isOccupied bool = true
var square Square = isOccupied // no conversion needed
```
