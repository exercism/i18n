# Consejos

## General

- Usa varios [operadores aritméticos][arithmeticoperators] para realizar operaciones matemáticas.
- Consulta la documentación de [`Int`][int] y [`Double`][double] para aprender qué funciones y operadores funcionan con `Int` y `Double`.

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

- Tendrás que convertir explícitamente entre `Int` y `Double`.

## 2. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

- Hay un [método disponible][rounded] para redondear valores `Double`.

## 3. Calcula el número de días laborables a partir de un presupuesto, una tarifa por hora y un descuento

- Hay un [método disponible][rounded] para redondear valores `Double` en el que puedes indicar la regla de redondeo que quieres usar.
