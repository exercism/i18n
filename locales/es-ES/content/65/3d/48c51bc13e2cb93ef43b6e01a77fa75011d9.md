# Aprender

¿Te interesa empezar con Groovy o aprender más mientras haces los ejercicios?

Prueba Groovy con

* [un navegador con un intérprete en línea](https://www.jdoodle.com/execute-groovy-online)
* [la Groovy Console](http://groovy-lang.org/groovyconsole.html) escribiendo `groovyConsole` en la línea de comandos
* [el Groovy Shell](http://groovy-lang.org/groovyconsole.html) escribiendo `groovysh` en la línea de comandos

Echa un vistazo rápido a Groovy con

* el [Groovy Tutorial for Java Developers](https://www.timroes.de/2015/06/27/groovy-tutorial-for-java-developers/) de Tim Rows, que es igual de útil para desarrolladores que no usan Java
* [Learn X in Y minutes, Where X=Groovy ](https://learnxinyminutes.com/docs/groovy/)
* los [Groovy Basics](http://docs.smartthings.com/en/latest/getting-started/groovy-basics.html) de SmartThings
* algunos de los [Groovy Koans en línea](http://www.groovy-koans.org/) de JDriven

Profundiza aún más con

* la [documentación de Groovy](http://www.groovy-lang.org/documentation.html)
* [Groovy In Action](https://www.manning.com/books/groovy-in-action-second-edition), _el libro_ de referencia sobre Groovy
* [Making Java Groovy](https://www.manning.com/books/making-java-groovy), de Ken Kousen
