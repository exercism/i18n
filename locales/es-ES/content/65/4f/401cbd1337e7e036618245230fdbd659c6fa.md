# Acerca de

Puede que sea difícil encontrar un lenguaje de programación más expresivo. [Raku](https://raku.org/) es un lenguaje moderno y multiparadigma. Raku ofrece metodologías de programación [procedural](https://docs.raku.org/language/functions), [orientada a objetos](https://docs.raku.org/language/objects) y [funcional](https://docs.raku.org/language/functions#Functions_are_first-class_objects).

[¿Tienes curiosidad?](https://raku.org/) Profundiza en la [documentación](https://docs.raku.org/) o en el [repositorio](https://raku.land/) de módulos (como pypi o CPAN).

Es un lenguaje sumamente [flexible](https://docs.raku.org/language/operators), que se [adapta](https://docs.raku.org/language/glossary#gradual_typing) a tu estilo de programación, ya sean [programas de una línea](https://docs.raku.org/language/create-cli) rápidos para administradores de sistemas, scripts para gestionar la importación de una base de datos o la pila completa de módulos necesaria para crear [un sitio web entero](https://cro.services/).

Raku aprende de otros lenguajes:

* Mejora el atractivo a largo plazo de Perl con un sistema de objetos apropiado que incluye [roles](https://docs.raku.org/language/typesystem#role), [hilos](https://docs.raku.org/language/concurrency) y despacho [multimétodo](https://docs.raku.org/language/glossary#Multi-dispatch).
* Toma los hilos de Java, [simplificados](https://docs.raku.org/language/concurrency) a un puñado de métodos.
* Usar interfaces de [función externa](https://docs.raku.org/language/nativecall) desde Lisp hace que acceder a las bibliotecas sea tan sencillo como una línea de código.
* Las [expresiones regulares](https://docs.raku.org/language/regexes) ahora suben hasta 11, con la introducción de [gramáticas](https://docs.raku.org/language/grammars) de expresiones de análisis, que te permiten abordar enormes tareas de análisis.
* Las restricciones y los avisos ahora son automáticos, lo que elimina una enorme cantidad de posibles errores.
* ... y sabe hacer [matemáticas](https://docs.raku.org/language/math): ```1/10 * 3 == 0.3 ```, ¡prueba eso en tu lenguaje favorito!

Los lemas de Raku:
* «Raku está diseñado para que las tareas fáciles sean fáciles, sin hacer imposibles las tareas difíciles.»
* «Hay más de una forma de hacerlo, ahora con aún más -Ofun (optimizado para la diversión) añadido.»
