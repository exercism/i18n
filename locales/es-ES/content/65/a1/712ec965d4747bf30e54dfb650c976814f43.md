# Clases y propiedades de solo lectura

Las clases y propiedades de solo lectura permiten que las clases especifiquen propiedades públicas para acceder a ellas fácilmente, pero impiden su modificación.
Para declarar una propiedad como de solo lectura hay que añadir `readonly` delante de la especificación del tipo.
La propiedad se puede asignar una vez, pero cualquier intento de volver a asignarla o de modificar su valor provocará un Error.

```php
<?php

class Block
{
    public function __construct(
        public readonly int $length,
        public readonly int $width,
    ) {
    }
}
```

Las clases de solo lectura se apoyan en este comportamiento y, si se declaran como `readonly`, aplican la declaración de solo lectura a cada propiedad.
Además, impiden añadir propiedades dinámicas.

```php
<?php

readonly class Block
{
    public function __construct(
        public int $length,
        public int $width,
    ) {
    }
}
```
