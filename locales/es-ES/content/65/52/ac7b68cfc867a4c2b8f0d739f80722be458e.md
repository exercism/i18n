# Ayuda

Si tienes problemas y necesitas ayuda, puedes usar uno de los siguientes recursos:

- [The Definition of Standard ML](https://github.com/SMLFamily/The-Definition-of-Standard-ML-Revised)
- [/r/sml](https://www.reddit.com/r/sml) es el subreddit de Standard ML.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/sml) para buscar tu problema y ver si ya se ha respondido. También puedes hacer y responder preguntas.
