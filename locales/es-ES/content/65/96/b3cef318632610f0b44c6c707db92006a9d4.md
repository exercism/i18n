# Introducción

Una definición con `:` puede llamarse a sí misma directamente. El compilador de Factor infiere el efecto de pila de las palabras recursivas igual que el de cualquier otra. No hace falta ninguna declaración especial para la recursión simple.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

{ 4 0 9 0 5 } total .    ! => 18
```

Las dos mitades son el *caso base* de la recursión (aquí, la secuencia vacía suma `0`) y el *paso recursivo* (quitar un elemento, aplicar la recursión al resto y combinar los resultados).

`if-empty` y `unclip` son los acompañantes canónicos para la recursión sobre secuencias. `if-empty ( seq emptyquot nonemptyquot -- )` ejecuta una de las dos quotations en función de la secuencia; `unclip` quita el primer elemento para que el paso recursivo tenga algo más simple.
