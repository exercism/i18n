# Introducción

Cuando una quotation necesita *recordar* valores de su entorno, Factor ofrece dos herramientas: `curry`/`compose` de [`kernel`][kernel], y la sintaxis fry `'[ … ]` de [`fry`][fry].

`curry` incorpora un valor al principio de una quotation:

```
curry ( value quot -- newquot )
```

```factor
3 [ + ] curry .          ! => [ 3 + ]
10 3 [ + ] curry call .  ! => 13
```

`compose` une dos quotations:

```factor
[ 1 + ] [ 2 * ] compose .       ! => [ 1 + 2 * ]
5 [ 1 + ] [ 2 * ] compose call . ! => 12
```

Cuando hay que capturar más de uno o dos valores, fry es más limpio. Cada marcador de posición `_` se rellena, en orden, con un valor extraído de la pila:

```factor
2 3 '[ _ _ + + ] .    ! => [ 2 3 + + ]
```

Fry también llega a quotations anidadas.

[fry]: https://docs.factorcode.org/content/vocab-fry.html
