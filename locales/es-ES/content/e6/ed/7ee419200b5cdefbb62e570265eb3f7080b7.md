# Anexo de instrucciones

## Operadores de números racionales

Las funciones aritméticas admiten llamadas a función normales, despacho estático (es decir, la sintaxis de llamada a método) y operadores:

| Llamada a función | Llamada a método | Operador |
| --- | --- | --- |
| `plus(r1, r2)` | `r1.plus(r2)` | `r1 + r2` |
| `minus(r1, r2)` | `r1.minus(r2)` | `r1 - r2` |
| `times(r1, r2)` | `r1.times(r2)` | `r1 * r2` |
| `div_by(r1, r2)` | `r1.div_by(r2)` | `r1 / r2` |

Implementa `reduce` para reducir un número racional a su forma irreducible, por ejemplo de `6 / 8` a `3 / 4`.
