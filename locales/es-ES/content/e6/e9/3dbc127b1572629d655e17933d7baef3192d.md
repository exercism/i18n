# Acerca de

CoffeeScript es un lenguaje que transpila a JavaScript, y se usa para crear sitios web dinámicos (tanto en el navegador como en el servidor).
El transpilador se usa para transformar código CoffeeScript en JavaScript antes de ejecutarlo, para mantener la compatibilidad y el mismo rendimiento de JavaScript a la vez que ofrece muchas funcionalidades nuevas.

CoffeeScript se creó para ofrecer una forma simplificada de escribir JavaScript, basada en una mezcla de los lenguajes Ruby y Python.
Una de las diferencias es el uso de la indentación y las flechas en lugar del verboso código de funciones de JavaScript, y además incorpora funcionalidades útiles de los lenguajes funcionales, como la coincidencia de patrones.

CoffeeScript es uno de los muchos lenguajes nuevos que transpilan a JavaScript, entre los que se incluyen TypeScript y Flow. La comunidad no deja de crecer y este tipo de lenguajes son muy populares.
