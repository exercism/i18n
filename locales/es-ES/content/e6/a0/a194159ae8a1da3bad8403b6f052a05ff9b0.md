# Introducción

Los arrays en C# son colecciones de valores primitivos o instancias de structs o clases. Se implementan en la biblioteca de clases base como `List<T>`, donde `T` es el tipo del elemento del array. La API expone un amplio conjunto de métodos para crear y manipular arrays.

Se pueden añadir y quitar elementos de los arrays. Crecen y se reducen según sea necesario.

```csharp
var listOfStrings = new List<string>();
```
