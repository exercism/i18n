# Arrays

En Cairo, un array es una estructura de datos que te permite almacenar una colección de elementos del mismo tipo.
Los arrays de Cairo tienen opciones de modificación limitadas.
Solo puedes añadir elementos al final de un array y eliminar elementos del principio.
De hecho, los arrays son colas cuyos valores no se pueden modificar.

## Construcción de un array

Los arrays se construyen principalmente con el trait `ArrayTrait`, y puedes usar cualquiera de estas 4 formas para construir un array de elementos `[1, 2]`:

```rust
// 1. Passing the type to the `ArrayTrait`
let mut arr_type_in_trait = ArrayTrait::<felt252>::new();
arr_type_in_trait.append(1);
arr_type_in_trait.append(2);

// 2. Setting the type on the variable itself
let mut arr_explicit_type: Array<felt252> = ArrayTrait::new();
arr_explicit_type.append(1);
arr_explicit_type.append(2);

// 3. Using the `array!` macro
let mut arr_from_macro: Array<felt252> = array![1, 2]; // assign values in-line

// 4. Allowing the compiler to infer the type from the type of values being assigned to it
let mut arr_implicit_type = ArrayTrait::new(); // compiler "knows" this is a `felt252` array
arr_implicit_type.append(1);
arr_implicit_type.append(2);
```

> Cada llamada a `append()` coloca un número nuevo al final del array.

## Eliminar elementos de un array

La única forma de eliminar elementos de un array en Cairo es por el principio.
Esta operación la facilita el método `pop_front()`, que devuelve un `Option` que puedes desenvolver y que contiene el elemento eliminado, o `Option::None` si el array está vacío.

```rust
fn main() {
    let mut a = array![10, 1, 2];
    let first_value = a.pop_front().unwrap(); // `unwrap()` is used to get the value from `Option`
    println!("The first value is {}", first_value); // prints "The first value is 10"
}
```

## Acceder a los valores de un array

Para acceder a los elementos de un array, puedes usar los métodos `get()` y `at()` del array, que devuelven tipos distintos.
Un equivalente a `arr.at(index)` es el operador de subíndice `arr[index]`.

### Usar el método get()

El método `get()` es como buscar un elemento en un array por su número.
Así es como funciona:

- `arr.get(index)` te permite obtener un elemento en una posición concreta (índice) del array.
- Devuelve un `Option::Some(value)` si el elemento existe en el índice dado, o `Option::None` si el índice está fuera de los límites.

Este método es ideal cuando quieres gestionar casos en los que el índice puede no ser válido sin que tu programa se bloquee.

```rust
fn main() {
    let arr: Array<u32> = array![1, 2, 3];

    let index = 1;

    match arr.get(index) {
        Option::Some(value) => { println!("Element at index {}: {}", index, value.unbox()); },
        Option::None => { println!("Index {} is out of bounds!", index); }
    }
}
```

### Usar el método at()

El método `at()` te da directamente una instantánea del elemento en un índice concreto, usando la operación `unbox()` para extraer el valor almacenado de la caja.
Una forma abreviada de este método es usar el operador de subíndice `arr[index]`.
Si intentas acceder a un índice que no existe (fuera de los límites), el programa entrará en pánico con un error.

```rust
fn main() {
    let a: Array<u32> = array![5, 8];

    println!("First: {}", *a.at(0)); // prints "First: 5"
    println!("Second: {}", a[1]); // prints "Second: 8"
    println!("Third: {}", a[2]); // panics with 'Index out of bounds'
}
```

## Métodos relacionados con el tamaño

Para determinar el número de elementos de un array, usa el método `len()`.
El valor devuelto es de tipo `usize`.

Si quieres comprobar si un array está vacío, puedes usar el método `is_empty()`, que devuelve `true` si el array está vacío y `false` en caso contrario.

## `Span`

`Span` es un struct que representa una instantánea de un `Array`.
Está diseñado para proporcionar un acceso seguro y controlado a los elementos de un array sin modificar el array original.
`Span` resulta especialmente útil para garantizar la integridad de los datos y evitar problemas de préstamo al pasar arrays entre funciones o al realizar operaciones de solo lectura.

> Todos los métodos que proporciona `Array` también se pueden usar con `Span`, excepto el método `append()`.

Para crear un `Span` a partir de un `Array`, llama al método `span()`:

```rust
let my_array: Array<u32> = array![1, 2, 3];
let my_span: Span<u32> = my_array.span();
```

## El tipo `Array` de tamaño fijo

En un array de tamaño fijo, los valores se escriben separados por comas y entre corchetes.
El tipo del array se escribe con corchetes que contienen el tipo de cada elemento, un punto y coma y, a continuación, el número de elementos del array.

```rust
let arr: [u64; 5] = [1, 2, 3, 4, 5];
```

> Nota: solo los arrays de tamaño fijo se pueden usar como constantes

Se puede acceder a los elementos de un array de tamaño fijo desestructurando el array o convirtiéndolo en un `Span`, que admite indexación.

```rust
fn main() {
    let arr = [1, 2, 3, 4, 5]; // implicit `felt252` array type

    // Accessing elements of a fixed-size array by deconstruction
    let [a, b, c, _, _] = arr;
    println!("c: {}", c); // c: 3
    
    // Accessing elements of a fixed-size array by index
    let my_span = arr.span();
    println!("my_span[2]: {}", my_span[2]); // my_span[2]: 3
}
```
