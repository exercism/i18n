# Instrucciones

Las audiciones para la obra de la escuela han terminado y el director necesita que las decisiones queden por escrito.

Las cuatro tareas van en la clase `CASTING_CALL`.

## 1. El veredicto

Cada aspirante recibe una puntuación sobre diez. Con ocho o más, entra en el reparto; de cinco a siete, pasa a la lista de reserva; por debajo de cinco, se le da las gracias.

```sather
CASTING_CALL::audition_outcome(8)
-- => "Cast"
CASTING_CALL::audition_outcome(6)
-- => "Recalled"
CASTING_CALL::audition_outcome(2)
-- => "Thank you"
```

## 2. ¿A qué grupo pertenece?

Los aspirantes menores de 13 años son Juniors. De 13 a 15 son Middles. A partir de 16, Seniors.

```sather
CASTING_CALL::age_group(13)
-- => "Middles"
```

## 3. Cuándo volver

Los Juniors vuelven a las cuatro, los Middles a las cinco y todos los demás a las seis.

```sather
CASTING_CALL::callback_time("Middles")
-- => "5pm"
```

El argumento es el nombre de un grupo, escrito exactamente como lo escribe la tarea 2.

## 4. Qué escribir en la hoja

Quien haya sacado ocho o más y sepa cantar es un `"Lead"`. Ocho o más sin cantar es `"Speaking part"`. Cualquier otro es `"Chorus"`.

```sather
CASTING_CALL::casting_note(9, true)
-- => "Lead"
CASTING_CALL::casting_note(9, false)
-- => "Speaking part"
CASTING_CALL::casting_note(4, true)
-- => "Chorus"
```
