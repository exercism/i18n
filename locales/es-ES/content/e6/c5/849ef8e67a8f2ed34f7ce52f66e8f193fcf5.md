# Instalación

## Inicio rápido

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install)
```

De forma predeterminada, se instalará en `/usr/local/bin`. Para cambiarlo, indica el nombre del directorio:

``` shellsession
$ bash <(curl -s https://raw.githubusercontent.com/borkdude/babashka/master/install) /tmp
```

## Brew

Los binarios para Linux y macOS se distribuyen a través de brew.

Instalar:

    brew install borkdude/brew/babashka

Actualizar:

    brew upgrade babashka

## Arch (Linux)

`babashka` está [disponible](https://aur.archlinux.org/packages/babashka-bin/) en el [Arch User Repository](https://aur.archlinux.org). Se puede instalar con tu asistente de [AUR](https://aur.archlinux.org) favorito, como
[yay](https://github.com/Jguer/yay), [yaourt](https://github.com/archlinuxfr/yaourt), [apacman](https://github.com/oshazard/apacman) y [pacaur](https://github.com/rmarquis/pacaur). Aquí tienes un ejemplo con `yay`:

    yay -S babashka-bin

## Windows

En Windows puedes instalar con [scoop](https://scoop.sh/) y el bucket
[scoop-clojure](https://github.com/littleli/scoop-clojure).

## Descarga

También puedes descargar un binario desde
[Github](https://github.com/borkdude/babashka/releases). Para Linux hay un
binario estático disponible que se puede usar en Alpine.
