# Introducción

## Boolean

En Java, los valores booleanos se representan con el tipo `boolean`, que puede tomar uno de estos dos valores: `true` o `false`.

Java admite tres operadores Boolean:  

- `!` (NOT): niega el valor booleano  
- `&&` (AND): toma dos valores booleanos y devuelve `true` si ambos son `true`
- `||` (OR): devuelve `true` si alguno de los dos valores booleanos es `true`

### Ejemplos

```java
!true // => false
!false // => true
true && false // => false
true && true // => true
false || false // => false
false || true // => true
```
