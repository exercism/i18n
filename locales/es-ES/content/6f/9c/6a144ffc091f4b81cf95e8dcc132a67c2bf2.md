# Introducción

En JavaScript, un array es una estructura similar a una lista, sin longitud fija, que puede contener cualquier tipo de primitivos u objetos, incluso tipos mezclados.

Para crear un array, añade elementos entre corchetes (`[]`).
Para leer del array, escribe el índice entre corchetes (`[]`) después del identificador.
Los índices de un array empiezan en cero.

Por ejemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obtener el número de elementos que hay en un array, usa la propiedad `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para cambiar un elemento del array, asigna un valor en el índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Algunos de los [métodos][mdn-array] disponibles en todos los objetos Array se pueden usar para añadir o quitar elementos de un array.
Aquí tienes algunos que puedes tener en cuenta al resolver este ejercicio:

### push

Se puede _añadir_ un `value` al final de un array usando `.push(value)`.
El método devuelve la nueva longitud del array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

Se puede _quitar_ el _último_ `value` de un array usando `.pop()`.
El método devuelve el valor quitado.
La longitud del array se reducirá con este cambio.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

Se puede _quitar_ el _primer_ `value` de un array usando `.shift()`.
El método devuelve el valor quitado.
La longitud del array se reducirá con este cambio.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

Se puede _añadir_ un `value` al principio de un array usando `.unshift(value)`.
El método devuelve la nueva longitud del array.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

Se puede _quitar_ un `value` en un `index` concreto de un array usando `.splice(index, 1)`.
El método devuelve el elemento o los elementos quitados.

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```

~~~exercism/advanced
Estos métodos son más potentes de lo que se describe aquí:

- Tanto `push` como `unshift` te permiten añadir varios valores a la vez, pasando más argumentos.
  Eso no es necesario para completar este ejercicio.
- Splice puede quitar varios valores aumentando el segundo argumento.
  Eso no es necesario para completar este ejercicio.
- Splice también puede añadir varios valores pasándolos como argumentos después del `deleteCount`.
  Esto se puede usar para reemplazar valores o insertar valores en medio de un array (por ejemplo, quitando 0 elementos).
  Eso no es necesario para completar este ejercicio.
