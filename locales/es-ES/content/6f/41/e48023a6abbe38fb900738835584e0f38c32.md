# Instalación

## Instalación de .NET

El track de F# se basa en la plataforma [.NET](https://dotnet.microsoft.com/learn/dotnet/what-is-dotnet), que funciona en Windows, Linux y macOS. Para compilar proyectos .NET, puedes usar la interfaz de línea de comandos (CLI) de .NET. Esta CLI forma parte del SDK de .NET, que puedes instalar siguiendo las [instrucciones de instalación](https://dotnet.microsoft.com/download). Nota: el track de F# requiere la versión 8.0 del SDK o superior.

Una vez completada la instalación, puedes comprobar si la CLI se ha instalado correctamente ejecutando este comando en la terminal:

```bash
dotnet --version
```

Si la salida es una versión igual o superior a `8.0.100`, el SDK de .NET se ha instalado correctamente.

## Uso de un IDE

Si quieres una experiencia de edición más completa, probablemente te venga bien usar un IDE. Estos son los IDE más populares que permiten compilar proyectos .NET:

- [Visual Studio 2022](https://www.visualstudio.com/downloads/)
- [Visual Studio Code](https://code.visualstudio.com/download) con la [extensión Ionide-fsharp](https://marketplace.visualstudio.com/items?itemName=Ionide.Ionide-fsharp)
- [Visual Studio for Mac](https://www.visualstudio.com/vs/visual-studio-mac/)
- [Project Rider](https://www.jetbrains.com/rider/download/)

Nota: como el formato de los proyectos de .NET es notablemente distinto del de versiones anteriores, los IDE más antiguos (como Visual Studio 2015) no son compatibles.
