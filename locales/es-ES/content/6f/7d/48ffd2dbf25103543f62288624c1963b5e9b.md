# Introducción

Del [manual][man-types]

> jq admite el mismo conjunto de tipos de datos que JSON: números, strings, Boolean, arrays, objetos (que en la jerga de JSON son hashes con claves que son solo strings) y “null”.

Vamos a centrarnos en los **números**.

## Números y operadores numéricos

Todos los números, ya sean enteros o no, son números de coma flotante de doble precisión IEEE754.
Esto nos limita a 53 bits de precisión.

Con los números puedes usar los operadores habituales:

- aritméticos: `+`, `-`, `*`, `/`, `%`
- de comparación: `==`, `!=`, `<`, `<=`, `>=`, `>`
- las [funciones matemáticas][man-math] estándar

  Para funciones de una entrada, pasa el valor a la función mediante una tubería

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para funciones de dos entradas, las funciones ignoran la entrada y esperan las
  entradas como parámetros (recuerda que los parámetros se separan con puntos y coma)

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  El punto y coma es el separador de los argumentos de una función, no la coma.

## Otras expresiones de `jq`

Para resolver el ejercicio, tendrás que conocer las expresiones condicionales.

### Expresiones condicionales

`jq` usa una [expresión `if-then-else`][if-then-else] para las **expresiones condicionales**.
Como _expresión_, se coloca dentro de una tubería.

La sintaxis es: `if CONDITION then TRUE_EXPR else FALSE_EXPR end`.

La cláusula `else` es opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Para condiciones adicionales se usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
