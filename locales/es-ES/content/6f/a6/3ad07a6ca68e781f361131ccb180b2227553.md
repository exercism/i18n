# Introducción

## Strings

Un `String` en Java es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.).
Las comillas dobles se usan para definir una instancia de `String`:

```java
String fruit = "Apple";
```

Los strings se manipulan llamando a los métodos del propio string.
Una vez que se ha construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string devolverá en realidad un string nuevo.
La clase `String` proporciona algunos métodos _estáticos_ para transformar los strings.
