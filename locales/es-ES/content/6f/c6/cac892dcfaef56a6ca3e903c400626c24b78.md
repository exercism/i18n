# Pistas

## 1. Crear la tabla de puntuaciones máximas

- La tabla de puntuaciones máximas debe ser una tabla hash.
- Puedes crear una tabla hash con `make-hash-table`.

## 2. Añadir un jugador a la tabla

- Para añadir un par clave/valor a una tabla hash, usa `(setf (gethash key table) value)`

## 3. Establecer la puntuación de un jugador

- Establecer la puntuación de un jugador es casi idéntico a añadir al jugador a la tabla.
- Para añadir un par clave/valor a una tabla hash, usa `(setf (gethash key table) value)`

## 4. Obtener una puntuación de la tabla

- Usa `gethash` para obtener el valor de una clave de la tabla hash.
- `gethash` tiene un tercer argumento opcional que es el valor que se usa si no se encuentra la clave.

## 5. Eliminar a un jugador de la tabla

- Usa `remhash` para eliminar una clave de la tabla.
