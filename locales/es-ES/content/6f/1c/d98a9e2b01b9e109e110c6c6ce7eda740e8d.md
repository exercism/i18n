# Números de coma flotante

`FLTD` contiene un número que puede tener una fracción. Un literal necesita un punto decimal y una `d`:

```sather
   440.0d
   0.5d
   -2.25d
```

`FLT` es la misma idea con la mitad de precisión. Este track usa `FLTD` en todo momento; no hay razón para recurrir a `FLT` a menos que la memoria sea escasa.

## Aritmética

| Operador | Significado |
| --- | --- |
| `+` `-` `*` | como para `INT` |
| `/` | división, conservando la fracción |

No hay `%` para `FLTD`.

Ambos operandos deben ser `FLTD`. Mezclar un `INT` es un error de compilación, no una conversión silenciosa, lo cual es una funcionalidad: el único sitio en el que esto da problemas es justo donde la gente se equivoca.

## Conversión

```sather
   7.fltd            -- 7.0, an INT made into an FLTD
   7.5d.int          -- 7, the fraction thrown away
   7.5d.round        -- 8, to the nearest whole number
   7.5d.floor        -- 7.0, down to a whole number
   7.5d.ceiling      -- 8.0, up to a whole number
```

Convierte antes de dividir, nunca después: `n.fltd / 2.0d` conserva la mitad, `(n / 2).fltd` ya la ha perdido.

## Rutinas útiles

```sather
   (-2.5d).abs       -- 2.5
   2.0d.sqrt         -- 1.41421
   (2.0d).max(3.0d)  -- 3.0
```

## Los números de coma flotante son aproximados

Un `FLTD` contiene una aproximación muy cercana, no el valor exacto. La mayoría de las fracciones decimales no se pueden almacenar exactamente, del mismo modo que un tercio no se puede escribir exactamente en decimal. Así que:

```sather
0.1d + 0.2d          -- very nearly 0.3, but not exactly
```

Dos consecuencias que conviene recordar:

**No compares con `=`.** Dos cálculos que deberían dar el mismo resultado a menudo difieren en los últimos dígitos. En su lugar, pregúntate si están cerca:

```sather
   (a - b).abs < 0.0001d
```

**Sumar muchos valores pequeños hace perder precisión.** Cada suma redondea un poco, y los errores se van acumulando.

Cuando los valores deban ser exactos, el dinero en particular, cuenta en unidades enteras con `INT` (céntimos en lugar de euros).

## Impresión

`.str` muestra unos seis dígitos significativos, menos de la precisión que realmente se guarda:

```sather
   #OUT + (1.0d / 3.0d).str;      -- 0.333333
```
