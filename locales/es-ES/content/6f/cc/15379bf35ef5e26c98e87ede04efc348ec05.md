# Introducción

Una definición de colección normalmente incluye un marcador de posición entre corchetes angulares, a menudo T por convención. A esa colección se la denomina tipo genérico. Esto permite a quien usa la colección especificar qué tipo de elementos almacenar en la colección. En el código de ejemplo anterior estamos instanciando un array de strings.

Una clase o una función se convierte en **genérica** usando el atributo `@:generic`. Esto hace que el compilador identifique la clase o la función como genéricas:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
