# Clases con estado

```sather
class SCOREBOARD is

   attr home_team, away_team : STR;
   attr home_score, away_score : INT;

   create(home, away : STR) : SAME is
      board ::= new;
      board.home_team := home;
      board.away_team := away;
      return board;
   end;

   home_goal is home_score := home_score + 1; end;

end; -- class SCOREBOARD
```

## attr, readonly attr, private attr

| Escrito | Se lee desde fuera | Se cambia desde fuera |
| --- | --- | --- |
| `attr x : INT` | sí | sí |
| `readonly attr x : INT` | sí | no |
| `private attr x : INT` | no | no |

`readonly` es el que conviene usar por defecto. Deja que cualquiera vea la
puntuación e insiste en que cambiarla pase por `home_goal`, que es donde
viven las reglas sobre cómo se puntúa.

## create and new

`new` produce un objeto de esta clase con todos los atributos vacíos. Solo
puede usarse dentro de la clase.

`create` es una rutina ordinaria con un nombre acordado: `#C(args)` es
exactamente `C::create(args)`. Una clase puede tener varias, distinguidas
por sus argumentos, y una clase que no tenga ninguna simplemente no se
puede crear con `#`.

## SAME

`SAME` representa la clase en la que está escrito. En `create` es el tipo
devuelto; también sirve en un argumento, y es lo que hace que una rutina
heredada se refiera a la clase que hereda y no a aquella de la que
procede.

## Rutinas sin tipo devuelto

```sather
   home_goal is
      home_score := home_score + 1;
   end;
```

Sin `:` y sin tipo. Una rutina así se llama como instrucción y no puede
aparecer en una expresión. Es la señal de que lo que importa de la llamada
es el cambio que produce.

## self

Dentro de una rutina, `self` es el objeto sobre el que se llamó. Rara vez
se escribe, porque un atributo o una rutina nombrados por sí solos ya se
refieren a los de `self`. Hace falta cuando hay que pasar o devolver el
objeto:

```sather
   with_goal : SAME is
      home_score := home_score + 1;
      return self;
   end;
```

`self`, `new`, `void`, `result`, `value` y `out` son palabras que Sather
ha reservado, y ninguna puede usarse como nombre propio.

## Referencia, no valor

A un objeto se llega a través de una referencia. Dos nombres para el mismo
marcador ven la misma puntuación:

```sather
   a ::= #SCOREBOARD("Vixens", "Magpies");
   b ::= a;         -- not a copy
   b.home_goal;
   a.home_score     -- 1
```

`immutable class`, más adelante, es la forma de conseguir el otro
comportamiento.
