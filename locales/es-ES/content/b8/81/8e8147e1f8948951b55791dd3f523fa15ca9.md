# Introducción

## Booleanos en Julia

Los valores verdadero o falso se representan mediante el tipo `Bool`.
Solo contiene dos valores: `true` y `false`.

```julia-repl
julia> true
true

julia> false
false
```

## Operadores booleanos

En Julia hay tres operadores booleanos.

`&&` es el «y» booleano.
Se evalúa como `true` si las expresiones a *ambos* lados de `&&` son `true`.

```julia-repl
julia> true && true
true

julia> true && false
false
```

`||` es el «o» booleano.
Se evalúa como `true` si la expresión a *cualquiera* de los dos lados de `||` es `true`.

```julia-repl
julia> true || true
true

julia> false || true
true
```

`!` es el «no» booleano.
Intercambia los valores `true` y `false`.

```julia-repl
julia> !true
false

julia> !false
true
```

Para expresiones más largas y complicadas, lo mejor es usar paréntesis para dejar clara tu intención.

```julia-repl
julia> (true || false) && (false && true)
false
```
