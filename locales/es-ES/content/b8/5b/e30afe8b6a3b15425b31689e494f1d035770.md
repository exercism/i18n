# Rangos

[Los rangos][range] representan un intervalo entre dos valores.
Los tipos más comunes que admiten rangos son `Int`, `Char` y `String`.
Se pueden usar para muchas cosas, como crear rápidamente una colección, cortar strings, comprobar si un valor está dentro de un rango e iterar.
Se crean con el operador de rango `..` o `...` (inclusivo y exclusivo, respectivamente).

```crystal
1..5  # A range containing 1, 2, 3, 4, 5
1...5 # A range containing 1, 2, 3, 4
```

La razón de tener dos operadores de rango es poder crear rangos que incluyan o excluyan el valor final, lo que puede ser útil cuando, por ejemplo, se trabaja con índices basados en cero.

Los rangos también se pueden crear usando el inicializador `Range`.

```crystal
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Cuando creas un rango en Crystal usando los operadores de rango `..` o `...`, y quieres llamar a un método sobre el rango, necesitas encerrar el rango entre paréntesis.
Esto se debe a que, de lo contrario, el método se llamaría sobre el segundo argumento del operador de rango.

```crystal
(1..5).size # => 5
1..5.size # => Error: undefined method 'size' for Int32
```
~~~~

## Obtener substrings

Cuando quieras cortar un string, puedes usar el operador de rango para obtener un substring.
Es decir, creando un rango con los índices de inicio y fin del substring.

```crystal
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

También puedes usar índices negativos para obtener el substring desde el final del string.

```crystal
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de los rangos

Los rangos sí que tienen un conjunto de métodos que se pueden usar para trabajar con ellos.
Por ejemplo, estos métodos se pueden usar para obtener la suma de todos los valores del rango o comprobar si el rango incluye un valor.

| Método                  | Descripción                                                             | Ejemplo                         |
|-------------------------|-------------------------------------------------------------------------|---------------------------------|
| [`sum`][sum]            | Devuelve la suma de todos los valores del rango                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Devuelve el tamaño del rango                                            | `(1..5).size # => 5`            |
| [`includes?`][indludes] | Devuelve `true` si el rango incluye el valor dado; en caso contrario, `false` | `(1..5).includes?(3) # => true` |

## Rangos sin fin y sin principio

Un rango puede ser sin fin y sin principio.
El rango sin fin o sin principio tiene su valor de inicio o de fin como `nil`, pero `nil` se puede omitir al definir el rango.

Usar rangos sin principio y sin fin es útil cuando quieres, por ejemplo, cortar un string desde el principio o hasta el final.

```crystal
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Si no se usa sobre una colección, el rango sin fin puede provocar una secuencia sin fin, si no se usa con cuidado.
~~~~

## Rangos de caracteres

Los caracteres se pueden usar en rangos y permiten obtener un intervalo de caracteres entre dos caracteres.
Por ejemplo, esto puede resultar útil cuando quieres obtener el alfabeto.

```crystal
'a'..'z' # A range containing ['a', 'b', 'c', ..., 'z']
```

## Rangos de strings

Los strings también se pueden usar en rangos, lo que permite obtener un intervalo de strings entre dos strings.
Pero su comportamiento es ligeramente distinto al de `Char` cuando se usan varios caracteres en un rango de strings.
Su comportamiento puede volverse confuso al hacer rangos de strings más complejos, así que ten cuidado.

```crystal
("aa".."az") # A range containing ["aa", "ab", "ac", ..., "az"]
```
