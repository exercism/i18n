## 1. Formatear los valores trimestrales

- `format` siempre devuelve `nil` a menos que el parámetro stream sea `nil`.
- `~A` se puede usar para formatear un valor.

## 2. El informe de dos trimestres

- Tu función anterior es perfecta para crear las dos líneas necesarias.
- `~%` y `~&` se pueden usar para crear saltos de línea.
