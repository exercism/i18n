# Ordenación

Poner cosas en orden es tan común que la biblioteca lo hace por ti.

```sather
   scores : ARRAY{INT} := |3, 1, 2|;
   scores.sort;              -- 1, 2, 3
```

`sort` funciona con cualquier cosa que ya sepa compararse, los números y los strings lo hacen, porque tienen un `is_lt`.

## Ordenar con tu propia regla

La mayoría de los órdenes no son el que viene integrado. Una clasificación de netball no es alfabética ni por longitud del nombre: es por puntos y, después, por diferencia de goles para los equipos empatados a puntos. No hay forma de que `ARRAY` lo adivine.

Así que entregas el orden, como una rutina vinculada:

```sather
   before(a, b : STR) : BOOL is
      return a.size < b.size;
   end;

   ...

   words.insertion_sort_by(bind(before(_, _)));
```

`insertion_sort_by` recibe un `ROUT{T,T}:BOOL`, una rutina que toma dos de las cosas que se ordenan y responde si la primera debe ir antes que la segunda. Llama a esa rutina tantas veces como necesita y coloca el array en el orden que implican las respuestas.

Para esto servía `understudy`. La biblioteca sabe ordenar y no sabe nada de tu idea de orden; la rutina vinculada es donde se encuentran las dos.

## Escribir la comparación

La rutina responde **true cuando el primer argumento va primero**.

```sather
   -- shortest first
   return a.size < b.size;

   -- longest first: turn it round
   return a.size > b.size;
```

Para una regla con más de una parte, trata las partes en orden de importancia:

```sather
   higher(a, b : TEAM) : BOOL is
      if a.points /= b.points then
         return a.points > b.points;      -- more points comes first
      end;
      return a.difference > b.difference; -- level: better difference wins
   end;
```

El primer `if` lo resuelve siempre que los puntos difieran. Solo cuando son iguales entra en juego la segunda línea. Escribir primero el desempate haría que los puntos nunca importaran.

## Ordenar cambia el array

`insertion_sort_by` ordena el propio array y no devuelve nada:

```sather
   teams.insertion_sort_by(bind(higher(_, _)));   -- teams is now sorted
```

Si el orden original importa, ordena una copia:

```sather
   ranked ::= teams.copy;
   ranked.insertion_sort_by(bind(higher(_, _)));
   return ranked;
```
