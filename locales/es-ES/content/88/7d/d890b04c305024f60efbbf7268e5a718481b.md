# Instrucciones

Tu amigo, un aspirante a artista, se puso en contacto contigo con una idea para un proyecto. Vamos a combinar su creatividad visual con tu experiencia técnica. ¡Es hora de experimentar con el [arte generativo][generative-art]!

Las restricciones ayudan a la creatividad y acortan los plazos de los proyectos, así que ambos habéis acordado limitar vuestra obra maestra a una sola forma: el círculo. Pero va a haber muchos círculos. ¡Y pueden moverse! Lo llamaréis... puntos bailarines.

Tu amigo querrá sin duda idear nuevos movimientos elaborados para los puntos, así que empezarás a programar creando una arquitectura que te permita definir después nuevas animaciones con facilidad.

## 1. Define el comportamiento de la animación

Cada módulo de animación debe implementar dos callbacks: `init/1` y `handle_frame/3`. Defínelos en el módulo `Animation`.

Define el callback `init/1`. Debe recibir un argumento de tipo `opts` y devolver una tupla `{:ok, opts}` o una tupla `{:error, error}`. Las implementaciones de este callback comprobarán si las opciones dadas son válidas para este tipo concreto de animación.

Define el callback `handle_frame/3`. Debe recibir tres argumentos: el punto, un número de fotograma y las opciones. Siempre debe devolver un punto. Las implementaciones de este callback modificarán los atributos del punto según el número de fotograma actual y las opciones de la animación.

## 2. Proporciona una implementación predeterminada del callback `init/1`

El comportamiento `Animation` debería ser fácil de incorporar a otros módulos llamando a `use DancingDots.Animation`.

Para lograrlo, implementa la macro `__using__` en el módulo `Animation` de forma que establezca el módulo `Animation` como el comportamiento del otro módulo. También debe proporcionar una implementación predeterminada del callback `init/1`. La implementación predeterminada de `init/1` debe devolver las opciones dadas sin cambios.

```elixir
defmodule MyCustomAnimation do
  use DancingDots.Animation
end

MyCustomAnimation.init(some_option: true)
# => {:ok, [some_option: true]}
```

## 3. Implementa la animación `Flicker`

Usa el comportamiento `Animation` para implementar una animación parpadeante.

Debe usar el callback `init/1` predeterminado porque no recibe ninguna opción.

Implementa el callback `handle_frame/3`, que gestiona un único fotograma. Si el número de fotograma es múltiplo de cuatro, la función debe devolver el punto con la mitad de su opacidad original. En los demás fotogramas, debe devolver el punto sin cambios.

Los fotogramas se cuentan a partir de `1`. El punto que se pasa a `handle_frame/3` es siempre el punto en su estado original, no en el estado del fotograma anterior.

```elixir
dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Flicker.handle_frame(dot, 1, [])
# => %DancingDots.Dot{opacity: 1, radius: 24, x: 100, y: 100}

DancingDots.Flicker.handle_frame(dot, 4, [])
# => %DancingDots.Dot{opacity: 0.5, radius: 24, x: 100, y: 100}
```

## 4. Implementa la animación `Zoom`

Usa el comportamiento `Animation` para implementar una animación de zoom.

Esta animación recibe una opción: la velocidad. La velocidad puede ser cualquier número. Si es negativa, el punto se aleja en lugar de acercarse.

Implementa el callback `init/1`. Debe validar que las opciones pasadas sean una lista de palabras clave con una clave `:velocity`. El valor de la velocidad debe ser un número. Si no es un número, devuelve el error `"The :velocity option is required, and its value must be a number. Got: #{inspect(velocity)}"`.

Implementa el callback `handle_frame/3`. Debe devolver el punto con su radio incrementado en el número de fotograma actual menos uno, multiplicado por la velocidad.

Los fotogramas se cuentan a partir de `1`. El punto que se pasa a `handle_frame/3` es siempre el punto en su estado original, no en el estado del fotograma anterior.

```elixir
DancingDots.Zoom.init(velocity: nil)
# => {:error, "The :velocity option is required, and its value must be a number. Got: nil"}

dot = %DancingDots.Dot{x: 100, y: 100, radius: 24, opacity: 1}

DancingDots.Zoom.handle_frame(dot, 1, velocity: 10)
# => %DancingDots.Dot{radius: 24, opacity: 1, x: 100, y: 100}

DancingDots.Zoom.handle_frame(dot, 2, velocity: 10)
# => %DancingDots.Dot{radius: 34, opacity: 1, x: 100, y: 100}
```
