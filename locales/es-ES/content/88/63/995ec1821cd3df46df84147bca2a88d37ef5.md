# Introducción

El principal constructo orientado a objetos de C# es la _clase_, que combina datos (_campos_) y comportamiento (_métodos_). Los campos y los métodos de una clase se conocen como sus _miembros_.

El acceso a los miembros puede restringirse mediante modificadores de acceso, de los cuales los dos más comunes son:

- `public`: cualquier código puede acceder al miembro (sin restricciones).
- `private`: solo el código de la misma clase puede acceder al miembro.

Puedes pensar en una clase como una plantilla para crear instancias de esa clase. Para crear una instancia de una clase (también conocida como _objeto_), se usa la palabra clave `new`:

```csharp
class Car
{
}

// Create two car instances
var myCar = new Car();
var yourCar = new Car();
```

Los campos tienen un tipo y pueden definirse en cualquier parte de una clase.
Los campos públicos se definen en PascalCase y los privados en camelCase, precedidos de un guion bajo `_`:

```csharp
class Car
{
    // Accessible by anyone
    public int Weight;

    // Only accessible by code in this class
    private string _color;
}
```

Opcionalmente, se puede asignar un valor inicial a un campo. Si un campo _no_ especifica un valor inicial, se le asignará el valor predeterminado de su tipo. Se puede acceder a los valores de los campos de una instancia y actualizarlos mediante la notación de punto.

```csharp
class Car
{
    // Will be set to specified value
    public int Weight = 2500;

    // Will be set to default value (0)
    public int Year;
}

var newCar = new Car();
newCar.Weight; // => 2500
newCar.Year;   // => 0

// Update value of the field
newCar.Year = 2018;
```

Los campos privados suelen actualizarse como efecto secundario de llamar a un método. Normalmente, estos métodos no devuelven ningún valor, en cuyo caso el tipo devuelto debe ser `void`:

```csharp
class CarImporter
{
    private int _carsImported;

    public void ImportCars(int numberOfCars)
    {
        // Update private field from public method
        _carsImported = _carsImported + numberOfCars;
    }
}
```
