# Instrucciones

Tras una reciente revisión de seguridad, te han pedido que limpies los archivos de registro archivados de la organización.

## 1. Identifica las líneas de registro corruptas

Necesitas hacerte una idea de cuántas líneas de registro de tu archivo no cumplen los estándares actuales.
Crees que una prueba sencilla revela si una línea de registro es válida.
Para que se considere válida, una línea debe empezar por uno de los siguientes strings:

- [DEBUG]
- [INFO]
- [WARNING]
- [ERROR]

Implementa la función `valid_line?/1` para que devuelva `true` si la línea de registro es válida.

```elixir
LogParser.valid_line?("[ERROR] Network Failure")
# => true

LogParser.valid_line?("Network Failure")
# => false
```

## 2. Divide la línea de registro

Poco después de empezar el proyecto de análisis de registros, te das cuenta de que los registros de una aplicación no están divididos en líneas como los de las demás. En este proyecto, lo que deberían haber sido líneas separadas está en una sola línea, conectado por flechas llamativas como `<--->` o `<*~*~>`.

De hecho, cualquier string que tenga como primer carácter `<`, como último carácter `>`, y cualquier combinación de los siguientes caracteres `~`, `*`, `=` y `-` en medio puede usarse como separador en los registros de este proyecto.

Implementa la función `split_line/1`, que recibe una línea y devuelve un array de strings.

```elixir
LogParser.split_line("[INFO] Start.<*>[INFO] Processing...<~~~>[INFO] Success.")
# => ["[INFO] Start.", "[INFO] Processing...", "[INFO] Success."]
```

## 3. Elimina los artefactos del registro

Has descubierto que cierto procesamiento previo de los registros ha ido dispersando el texto «end-of-line» seguido de un número de línea (sin un espacio intermedio) por todos los registros.

Implementa la función `remove_artifacts/1` para que reciba un string y elimine todas las apariciones del texto end-of-line (sin distinguir mayúsculas de minúsculas), y devuelva una línea de registro limpia.

Las líneas que no contengan el texto end-of-line deben devolverse sin modificar.

Solo hay que eliminar el texto end-of-line; no es necesario ajustar los espacios en blanco.

```elixir
LogParser.remove_artifacts("[WARNING] end-of-line23033 Network Failure end-of-line27")
# => "[WARNING]  Network Failure "
```

## 4. Etiqueta las líneas con nombres de usuario

Te has dado cuenta de que algunas de las líneas de registro incluyen frases que se refieren a usuarios.
Estas frases siempre contienen el string `"User"`, seguido de uno o más caracteres de espacio en blanco y, a continuación, un nombre de usuario.
Decides etiquetar esas líneas.

Implementa una función `tag_with_user_name/1` que procese las líneas de registro:

- Las líneas que no contengan el string `"User"` permanecen sin cambios.
- En las líneas que contengan el string `"User"`, añade al principio de la línea `[USER]` seguido del nombre de usuario.

```elixir
LogParser.tag_with_user_name("[INFO] User Alice created a new project")
# => "[USER] Alice [INFO] User Alice created a new project"
```

Puedes dar por supuesto que:

- Cada aparición del string `"User"` va seguida de uno o más caracteres de espacio en blanco y del nombre de usuario.
- Hay como máximo una aparición del string `"User"` en cada línea.
- Los nombres de usuario son strings no vacíos que no contienen espacios en blanco.
