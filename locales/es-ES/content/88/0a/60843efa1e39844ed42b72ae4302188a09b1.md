# Introducción

Los punteros inteligentes en Cairo son estructuras de datos avanzadas que garantizan una gestión de memoria segura y eficiente al añadir características de seguridad a los punteros normales, evitando problemas comunes como desreferenciar punteros nulos o acceder a memoria no inicializada.

## ¿Qué es un puntero inteligente?

Un puntero inteligente se comporta como un puntero normal, pero hace un seguimiento de la propiedad y garantiza un acceso seguro a la memoria, lo que evita problemas como la desreferenciación de punteros nulos o colgantes.

## Tipos de punteros inteligentes

Cairo proporciona varios tipos de punteros inteligentes, como `Box<T>` y `Nullable<T>`:

- **`Box<T>`**: almacena datos en un segmento de memoria especial, ideal para datos grandes o de tamaño dinámico.
                Permite transferir la propiedad sin copiar los datos.
- **`Nullable<T>`**: apunta a un valor válido de tipo `T` o a `null`, lo que resulta útil para gestionar valores opcionales.

## Seguridad de la memoria

Los punteros inteligentes ayudan a prevenir accesos inseguros a la memoria y garantizan que esta se libere automáticamente cuando ya no se necesita, lo que reduce el riesgo de fugas de memoria.

### Ejemplo: uso de `Box<T>` para tipos recursivos

Los punteros inteligentes como `Box<T>` permiten manejar tipos recursivos de forma segura, como en un árbol binario, asignando memoria de forma eficiente y evitando la recursión infinita.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

## Beneficios de rendimiento

Los punteros inteligentes mejoran el rendimiento al pasar referencias a los datos en lugar de copiar estructuras grandes, lo que reduce la sobrecarga de memoria.

```rust
// `Cart` is a large struct that contains a lot of information
fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}
```
