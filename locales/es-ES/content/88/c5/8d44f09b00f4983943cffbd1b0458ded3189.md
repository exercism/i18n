# Introducción

Los caracteres de Factor son números enteros, esto es, puntos de código Unicode, así que los operadores numéricos `<`, `>`, `=` te dan directamente un orden que distingue mayúsculas de minúsculas. El vocabulario [`unicode`][unicode] añade predicados que tienen en cuenta Unicode y la conversión de mayúsculas y minúsculas de un solo carácter.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
```

## Conversión entre mayúsculas y minúsculas

`ch>upper` y `ch>lower` convierten un solo carácter a mayúscula o a minúscula. Las versiones a nivel de string, `>upper` y `>lower`, las aplican a todos los caracteres de un string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```
