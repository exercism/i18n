# Instrucciones

En este ejercicio trabajarás con cuentas de ahorro. Cada año, el saldo de tu cuenta de ahorro se actualiza en función de su tipo de interés. El tipo de interés que te da tu banco depende de la cantidad de dinero que haya en tu cuenta (su saldo):

- 3,213% para un saldo negativo (da como resultado un interés negativo).
- 0,5% para un saldo positivo inferior a `1000` dólares.
- 1,621% para un saldo positivo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2,475% para un saldo positivo mayor o igual que `5000` dólares.

Cada año, el gobierno te permite donar un porcentaje de tu dinero a una organización benéfica, libre de impuestos. Como eres buena persona, si tu saldo acaba siendo positivo al final del año, coges el porcentaje libre de impuestos y lo duplicas, redondeando hacia abajo al dólar entero más cercano. No te importa pagar impuestos por la segunda mitad de la donación.

Tienes tres tareas, y cada una de ellas tratará sobre tu saldo y su tipo de interés.

## 1. Calcula el tipo de interés

Implementa la función `interestRate` para calcular el tipo de interés a partir del saldo especificado:

```fsharp
interestRate 200.75m
// => 0.5f
```

Ten en cuenta que el valor devuelto es un `single`.

## 2. Calcula el interés

Implementa el método `interest` para calcular el interés a partir del saldo especificado:

```fsharp
interest 200.75m
// => 1.00375m
```

Ten en cuenta que el valor devuelto es un `decimal`.

## 3. Calcula la actualización anual del saldo

Implementa la función `annualBalanceUpdate` para calcular la actualización anual del saldo, teniendo en cuenta el tipo de interés:

```fsharp
annualBalanceUpdate 200.75m
// => 201.75375m
```

Ten en cuenta que el valor devuelto es un `decimal`.

## 4. Calcula cuánto dinero donar

Implementa la función `amountToDonate` para calcular cuánto dinero donar a organizaciones benéficas a partir del saldo y el porcentaje libre de impuestos que permite el gobierno:

```fsharp
let balance = 550.5m
let taxFreePercentage = 2.5
amountToDonate balance taxFreePercentage
// => 27
```

Ten en cuenta que el valor devuelto es un `int`.
