# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con un jefe de proyecto.
Tu tarea es proporcionar unas cuantas utilidades que calculen rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos unas cuantas reglas entre el freelancer y el jefe de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más fieles o para clientes sin ánimo de lucro).

Los descuentos se modelan como números fraccionarios que representan porcentajes, por ejemplo, `25.0` (25%).

## 1. Calcular la tarifa diaria dada una tarifa por hora

Implementa una función llamada `daily_rate` que calcule la tarifa diaria dada una tarifa por hora como parámetro.
El contrato define que un día tiene 8 horas facturables.

```elixir
FreelancerRates.daily_rate(60)
# => 480.0
```

La tarifa diaria devuelta debe ser un número de coma flotante.

## 2. Calcular un precio con descuento

Implementa una función `apply_discount` que calcule el precio después de aplicar un descuento.

```elixir
FreelancerRates.apply_discount(150, 10)
# => 135.0
```

El valor devuelto debe ser siempre un número de coma flotante, sin redondear de ninguna manera.

## 3. Calcular la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función `monthly_rate` que calcule la tarifa mensual con descuento.
Recibe dos parámetros, una tarifa por hora y el descuento en porcentaje.

```elixir
FreelancerRates.monthly_rate(77, 10.5)
# => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba al entero más cercano.

## 4. Calcular el número de días completos de trabajo a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función `days_in_budget` que reciba un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días completos de trabajo cubre eso.

```elixir
FreelancerRates.days_in_budget(20000, 80, 11.0)
# => 35.1
```

El número de días devuelto debe redondearse hacia abajo a un decimal.
