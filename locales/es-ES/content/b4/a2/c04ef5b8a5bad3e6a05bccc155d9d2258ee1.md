# Instrucciones

Eres el sobrecargo del barco y gestionas el inventario de la despensa. El inventario es una tabla hash en la que cada clave es el nombre de un artículo y el valor es la cantidad en existencias.

## 1. Crear un inventario a partir de un array

Define `create-inventory` de forma que tome una secuencia de nombres de artículos y devuelva una tabla hash que asocie cada nombre único con su recuento.

```factor
{ "coal" "wood" "wood" "diamond" "diamond" "diamond" } create-inventory .
! => H{ { "coal" 1 } { "wood" 2 } { "diamond" 3 } }
```

## 2. Añadir más artículos

Define `add-items` de forma que tome un inventario y una secuencia de artículos y devuelva un inventario nuevo cuyos recuentos se hayan incrementado por cada artículo indicado. El inventario original no debe modificarse.

```factor
H{ { "coal" 1 } } { "wood" "iron" "coal" "wood" } add-items .
! => H{ { "coal" 2 } { "wood" 2 } { "iron" 1 } }
```

## 3. Decrementar los recuentos

Define `decrement-items` de forma que tome un inventario y una secuencia de artículos y devuelva un inventario nuevo cuyos recuentos se hayan reducido en uno por cada artículo indicado. Los recuentos nunca deben bajar de cero, y los artículos que no estén ya en el inventario deben omitirse (no se insertan entradas negativas).

```factor
H{ { "coal" 3 } { "diamond" 1 } { "iron" 5 } }
{ "diamond" "coal" "iron" "iron" } decrement-items .
! => H{ { "coal" 2 } { "diamond" 0 } { "iron" 3 } }
```

## 4. Eliminar un artículo por completo

Define `remove-item` de forma que tome un inventario y un artículo y devuelva un inventario nuevo con ese artículo eliminado. Si el artículo no está presente, devuelve una copia sin cambios.

```factor
H{ { "coal" 2 } { "wood" 1 } { "diamond" 2 } } "coal" remove-item .
! => H{ { "wood" 1 } { "diamond" 2 } }
```

## 5. Listar los artículos disponibles

Define `list-inventory` de forma que tome un inventario y devuelva un array de pares `{ name quantity }` que contenga solo los artículos cuya cantidad sea mayor que cero, ordenados alfabéticamente por nombre.

```factor
H{ { "coal" 7 } { "wood" 11 } { "diamond" 2 } { "iron" 7 } { "silver" 0 } }
list-inventory .
! => { { "coal" 7 } { "diamond" 2 } { "iron" 7 } { "wood" 11 } }
```
