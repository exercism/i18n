# Introduction

AWK es un lenguaje muy pequeño y solo tiene unos pocos tipos de datos básicos.
En esta lección veremos los números y los strings.

## Números

Los números en AWK se implementan como números de coma flotante de doble precisión.
No hay distinción entre enteros, decimales y dobles.

AWK entiende las constantes numéricas octales (que empiezan por `0`) y las constantes numéricas hexadecimales (que empiezan por `0x` o `0X`).

### Operaciones numéricas

Puedes usar los [operadores aritméticos estándar][ops-arith] `+`, `-`, `*`, `/`, `%`.
El operador de exponenciación es `^` (lo especifica POSIX), aunque también se puede usar `**`.
Hay algunas [funciones numéricas integradas][funcs-numeric], como las funciones trigonométricas, la generación de números aleatorios y `int(x)`, que trunca un número al entero más próximo entre _x_ y cero.

No hay _operadores_ bit a bit.
gawk los implementa como funciones.
Los argumentos deben ser números no negativos.

| función             | operación                                      |
| ------------------- | ---------------------------------------------- |
| `and(a, b [, ...])` | AND bit a bit de los argumentos                |
| `or(a, b [, ...])`  | OR bit a bit de los argumentos                 |
| `xor(a, b [, ...])` | XOR bit a bit de los argumentos                |
| `lshift(v, count)`  | el valor de _v_ desplazado _count_ bits a la izquierda |
| `rshift(v, count)`  | el valor de _v_ desplazado _count_ bits a la derecha   |
| `compl(v, count)`   | complemento bit a bit de _v_                   |

## Strings

Los strings de AWK son secuencias de caracteres.
Especifica una constante de tipo string usando comillas dobles.

~~~~exercism/caution
GNU awk permite caracteres Unicode en los strings; puede que otras implementaciones de awk no lo hagan.
Comparando `gawk` con `mawk`, otro AWK muy popular:

```sh
$ echo "Hi friend 😀!" | gawk '{print length($3)}'
2
$ echo "Hi friend 😀!" | mawk '{print length($3)}'
5
```
~~~~

### Operaciones con strings

Solo hay una operación con strings: la concatenación.
La concatenación no tiene un operador especial;
basta con colocar dos strings uno junto al otro para concatenarlos:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` es una **instrucción**, no una función.
`print` no requiere paréntesis.
~~~~

AWK cuenta con una gran cantidad de [funciones de manipulación de strings][funcs-string].
Las iremos conociendo en profundidad a medida que avancemos por el track.

## Conversión entre números y strings

No hay operadores explícitos para convertir entre números y strings.
AWK lo hace de forma implícita según el contexto del programa.
Esto hace que trabajar con los valores de los campos de entrada sea muy sencillo: por lo general, AWK simplemente hace lo que quieres que haga.

* `print x + y` convierte los valores de las variables `x` e `y` en números gracias a la operación numérica `+`.
* `print x y` convierte los valores de las variables `x` e `y` en strings gracias a la operación de concatenación.

Si quieres ser explícito, `0 + x` da la representación numérica de _x_ y `"" x` da la representación como string de _x_.

### De strings a números

La forma en que AWK convierte un string en un número puede resultar confusa.
Una forma sencilla de verlo es que AWK lee «caracteres numéricos» desde el inicio de un string hasta que encuentra un carácter que no lo es.
Algunos ejemplos son:

* `"2.5"` se convierte en el número `2.5`;
* `"1e3"` se convierte en el número `1000` (notación científica);
* `"456abc"` se convierte en el número `456` (como `a` no es un «numeral», la conversión se detiene ahí).
* `"abc789"` se convierte en el número `0` (no hay números al **principio** del string).

Todos los detalles están [en el manual][str-to-num].

## Determinar el tipo de una variable

La [función `typeof(var)`][func-typeof] devuelve el tipo como un string.

```awk
BEGIN {
    x = "42"
    print x, typeof(x)
    x = x + 1           # type conversion
    print x, typeof(x)
}
```
da como resultado:
```none
42 string
43 number
```
