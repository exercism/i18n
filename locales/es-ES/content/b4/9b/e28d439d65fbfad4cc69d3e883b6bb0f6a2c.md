# Anexo de instrucciones

## Estructuras de datos con estado

En los lenguajes funcionales, como Lean, la mayoría de los valores son inmutables por diseño.
Esto significa que las actualizaciones suelen hacerse creando un valor nuevo.
Tanto el valor antiguo como el nuevo coexisten y pueden referenciarse y usarse.

Sin embargo, hay muchas situaciones en las que se desea un valor _con estado_, o incluso es necesario.
Un valor con estado se actualiza mediante mutación, _reemplazando_ el valor antiguo en lugar de crear uno nuevo.
Tras una mutación, solo el valor actualizado sigue siendo accesible.

Ten en cuenta que las mutaciones pueden romper algunas garantías del lenguaje.
Una función pura debe devolver siempre el mismo resultado para el mismo conjunto de entradas, pero si una entrada puede cambiar con el tiempo, la función puede devolver resultados distintos incluso cuando se la llama con los mismos argumentos.
Del mismo modo, si una función puede producir cambios externos distintos de devolver un resultado, o puede leer de fuentes distintas de sus parámetros, dos llamadas a la misma función pueden tener resultados diferentes y, en ocasiones, impredecibles.

Para gestionar este tipo de comportamiento con estado, Lean, al igual que otros lenguajes funcionales, exige que las funciones con efectos se envuelvan en un tipo especial de estructura que las distingue de las funciones puras.
Estas estructuras se denominan _mónadas_.

Es importante señalar que, aunque todo valor con estado vive dentro de alguna mónada con efectos, no todas las mónadas representan estado mutable.
Algunos ejemplos destacados de mónadas «puras» son `Option`, `Except` e `Id`.

En este ejercicio vas a definir una estructura de datos con estado llamada `LinkedList`.
Las instancias de esta estructura de datos se actualizan mediante mutación.

Para ello, todas las funciones están envueltas dentro de la mónada `ST`.
En esta mónada, el estado mutable es el único efecto secundario, y las referencias mutables no pueden escapar.
Para obtener más información, puedes consultar la [referencia][reference].
