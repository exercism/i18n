# Introducción

Go no tiene un concepto de vacío, nulo o indefinido para los valores de las variables.
Las variables declaradas sin un valor inicial explícito toman el valor cero de su tipo correspondiente.

El valor cero de los tipos primitivos, como Boolean, los tipos numéricos y string, es `false`, `0` y `""`, respectivamente.

El identificador `nil`, que significa cero, es el valor cero de los tipos más complejos, como punteros, funciones, interfaces, slices, canales y mapas.

En la siguiente tabla se detalla el valor cero de los tipos de Go.

| Tipo      | Valor cero |
| --------- | ---------- |
| Boolean   | `false`    |
| numérico  | `0`        |
| string    | `""`       |
| puntero   | `nil`      |
| función   | `nil`      |
| interfaz  | `nil`      |
| slice     | `nil`      |
| canal     | `nil`      |
| mapa      | `nil`      |

Es posible que hayas notado que los tipos struct no aparecen en la tabla anterior.
Esto se debe a que el valor cero de un tipo struct depende de sus campos.
Los structs se establecen en su valor cero cuando todos sus campos se establecen en su valor cero respectivo.
