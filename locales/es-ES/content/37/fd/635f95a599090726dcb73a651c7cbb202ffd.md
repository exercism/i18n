# Anexo de instrucciones

## Imprimir el árbol

Este ejercicio incluye algunos métodos de clase predefinidos que ayudan a imprimir el árbol con un formato agradable.
Su propósito principal es facilitar la depuración y aportar claridad adicional.
Si implementas correctamente el resto de la clase, debería imprimir el árbol por ti.

```powershell
.Example
$tree = [BinarySearchTree]::new(@(50, 76, 1, 34, 89, 44, 25, 6, 26, 100, 13))
$tree.ToString()

Return:
@"
50
├──L:1
│   └──R:34
│       ├──L:25
│       │   ├──L:6
│       │   │   └──R:13    
│       │   └──R:26        
│       └──R:44
└──R:76
    └──R:89
        └──R:100
"@
```
