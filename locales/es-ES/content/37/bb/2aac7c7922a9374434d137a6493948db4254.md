# Introducción

Cada archivo fuente de Factor declara un *vocabulario* con `IN:` e importa cualquier otro que use con `USING:`.

```factor
USING: kernel sequences ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

La estructura de directorios sigue el nombre del vocabulario con puntos:

- el vocabulario `my-vocab` se encuentra en `my-vocab/my-vocab.factor`
- el vocabulario `my-vocab.helpers` se encuentra en `my-vocab/helpers/helpers.factor`

El cargador de vocabularios de Factor sigue las declaraciones `USING:` de forma transitiva: cuando un archivo que requieres importa otro vocabulario, ese vocabulario se carga automáticamente.

A menudo dividirás una rutina grande entre dos vocabularios: un vocabulario auxiliar con palabras pequeñas y reutilizables, y un vocabulario principal que las importa y compone el resultado.
