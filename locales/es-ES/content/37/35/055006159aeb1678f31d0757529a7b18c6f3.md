# Acerca de

Las [tuplas][tuple] se usan con frecuencia para agrupar información; se diferencian de las listas en que tienen un tamaño fijo y pueden contener distintos tipos de datos.
Las tuplas se crean con llaves, `()`, y a menudo se usan para devolver varios valores desde una función.

```haskell
tuple = (1, "abc", False)
```

Esto puede resultar útil cuando, por ejemplo, quieres almacenar una coordenada en un espacio 2D, ya que sabes que la tupla siempre tendrá dos elementos: las coordenadas x e y.

```haskell
coordinate = (3, 4)
```

## Acceder a los elementos

A menudo trabajarás con tuplas cortas, y puedes acceder a los elementos mediante las funciones `fst` y `snd`.

```haskell
x = fst coordinate
-- x = 3
y = snd coordinate
-- y = 4
```

[tuple]: https://hackage.haskell.org/package/base/docs/Data-Tuple.html
