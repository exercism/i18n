# Apéndice de instrucciones

## Instrucciones específicas del track

Se supone que las funciones devuelven el producto, y el desplazamiento y la longitud del array de factores.
Los factores se escriben simplemente como pares de i32 en memoria:

```
Return value:
[u32 $product] [u32 $factorsOffset] [u32 $factorsLength]

Memory at $factorsOffset
[u32 firstFactor] [u32 firstCofactor] [u32 secondFactor] [u32 secondCofactor] ...
```

Para el mayor producto palíndromo de un dígito, tendría este aspecto:

```
Return value
0009 0000 0004

Memory at offset 0
0001 0009 0003 0003
```
