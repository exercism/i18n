# Anexo de instrucciones

Si la entrada no es válida, devuelve una longitud vacía.

## Direcciones reservadas

El búfer del primer string usa los bytes 1024-2047 de la memoria lineal.
El búfer del segundo string usa los bytes 2048-3071 de la memoria lineal.
El búfer del tercer string usa los bytes 3072-4095 de la memoria lineal.

El primer segmento de los bytes 0-1023 de la memoria lineal se puede usar libremente.
