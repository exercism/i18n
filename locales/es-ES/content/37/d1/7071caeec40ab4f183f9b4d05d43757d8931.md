# Acerca de

En Haxe, un tipo abstracto es un tipo que es un tipo distinto en tiempo de ejecución. Es una característica en tiempo de compilación que define tipos «sobre» tipos concretos para modificar o ampliar su comportamiento:

```haxe
abstract AbstractInt(Int) {
    inline public function new(i:Int) {
        this = i;
    }
}
```

Aquí declaramos el tipo `AbstractInt` usando la palabra clave `abstract`. Su sintaxis es muy similar a la de `class`. Y, al igual que las clases, los tipos abstractos pueden tener métodos. También se pueden instanciar y usar igual que las clases:

```haxe
class Main {
    static public function main() {
        var a = new AbstractInt(12);
        trace(a); // 12
    }
}
```

Como se ha mencionado antes, los tipos abstractos son una característica en tiempo de compilación. Si compilamos el ejemplo anterior a JavaScript, obtenemos lo siguiente:

```javascript
var a = 12;
console.log(a)
```

El tipo abstracto `AbstractInt` desaparece por completo de la salida. Esto se debe a que el constructor de `Abstract` se [inserta en línea][inline], algo que veremos más adelante.

[inline]: https://haxe.org/manual/class-field-inline.html
