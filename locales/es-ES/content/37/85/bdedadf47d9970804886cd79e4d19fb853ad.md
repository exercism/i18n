# Resaltado de sintaxis

Hay dos tipos de resaltado de sintaxis en el sitio web:

1. Resaltar código _estático_ (fragmentos de código, iteraciones y similares).
   Consulta la [documentación sobre el resaltado de sintaxis estático](/docs/building/tracks/new/syntax-highlighting/static) para obtener más información.
2. Resaltar código _dinámico_ (el editor en línea).
   Consulta la [documentación sobre el resaltado de sintaxis dinámico](/docs/building/tracks/new/syntax-highlighting/dynamic) para obtener más información.

```exercism/note
Los requisitos para el resaltado de sintaxis estático y dinámico son _muy_ diferentes, y por eso utilizan bibliotecas distintas.
```
