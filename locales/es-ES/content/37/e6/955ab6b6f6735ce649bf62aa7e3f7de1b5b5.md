# Pistas

## 1. Comprueba si la acción «ataque rápido» es posible

- El operador lógico NOT (`not`) se puede colocar delante de una expresión para negar su valor.

## 2. Comprueba si la acción «acercarse y espiar» es posible

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueban los posibles «cortocircuitos».

## 3. Comprueba si la acción «hacer señales al prisionero» es posible

- Los operadores lógicos, por orden de precedencia (de mayor a menor): `not`, `&&`, `||`.
