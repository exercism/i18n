# Strings

Crystal tiene un tipo conocido como [`String`][strings], que se usa para representar texto.
Las cadenas de caracteres de Crystal son secuencias de caracteres Unicode.
Los strings son inmutables, lo que significa que no se pueden cambiar una vez creados.
Esto significa que se crea un nuevo string cada vez que modificas un string; por lo tanto, el string original no se modifica.

Para definir un string se usan comillas dobles `"`.

```crystal
"Hello World"
```

## Concatenación

Para concatenar dos strings, usa el operador `+`.
El operador `+` devolverá un nuevo string que combina los dos strings.

```crystal
hello = "Hello"
hello + " World"
# => "Hello World"
```

## Conversión entre strings y números

El método `to_i` convierte un string en un número entero.
Como alternativa, se puede usar el método `to_f` para devolver un número de coma flotante.
Si el string no se puede convertir en un número, se lanzará un `ArgumentError`.

```crystal
"1".to_i
# => 1

"1.0".to_f
# => 1.0

"Hello".to_i
# => ArgumentError: Invalid integer: Hello
```

Un número entero o un número de coma flotante se puede convertir en un string con el método `to_s`.

```crystal
1.to_s
# => "1"

1.0.to_s
# => "1.0"
```

## Interpolación

La interpolación es una forma cómoda de combinar strings e incrustar expresiones en strings.
Para interpolar un string, puedes usar el carácter `#` seguido de llaves `{}` con la expresión dentro de las llaves.

```crystal
name = "World"
"Hello #{name}!"
# => "Hello World!"
```

Crystal convertirá automáticamente el resultado de la expresión en un string.

```crystal
"Hello #{1 + 1}!"
# => "Hello 2!"
```

## Tamaño

Cuando necesitas saber el número de caracteres de un string, puedes usar el método `size`, que devuelve la longitud del string como un número entero.
El tamaño de un string es una propiedad almacenada del string, así que no tiene que calcular el tamaño cada vez que llamas al método, lo que lo hace muy rápido.

```crystal
"Hello World".size
# => 11
```

## Indexación

La indexación consiste en obtener un carácter concreto de un string.
Para obtener un carácter de un `String`, puedes usar la conocida notación de corchetes.

~~~~exercism/note
`[]` está implementado como un método de instancia de String, donde el índice es el argumento del método.
~~~~

En Crystal, el primer carácter de un string está en el índice 0.

```crystal
"Hello World"[0]
# => 'H'

"Hello World"[6]
# => 'W'
```

Para obtener un carácter desde el final de un string, puedes tomar la longitud del string menos uno para obtener el índice del último carácter; para obtener el penúltimo carácter, puedes tomar la longitud del string menos dos, y así sucesivamente.
Existe un atajo para esto y consiste simplemente en usar un índice negativo, donde el último carácter está en el índice -1, el penúltimo en el índice -2, y así sucesivamente.

```crystal
name = "Hello World"
name[name.size - 1]
# => 'd'

name[-1]
# => 'd'
```

### Comprobación de subcadenas

Crystal permite comprobar si un string contiene una subcadena usando la indexación.
La misma notación de corchetes sirve para ello, pero en lugar de un índice se indica una subcadena.
Si la subcadena se encuentra en el string, se devuelve la subcadena; en caso contrario, se lanza un `NilAssertionError`.

```crystal
"Hello World"["Hello"]
# => "Hello"

"Hello World"["Goodbye"]
# => NilAssertionError
```

Si quieres un valor `Bool` que indique si la subcadena se encuentra, puedes usar el método `includes?`.

```crystal
"Hello World".includes?("Hello")
# => true

"Hello World".includes?("Goodbye")
# => false
```

## Secuencias de escape

Algunos caracteres no se pueden escribir directamente en un string; para ello tienes que usar una secuencia de escape.
Por ejemplo, si quieres usar comillas dobles en un string, tienes que escapar las comillas dobles.
Puedes usar el carácter `\` para escribir una secuencia de escape seguida del carácter que quieres escapar.

Estos son los caracteres especiales de Crystal:

| Valor    | Descripción                   |
| -------- | ----------------------------- |
| `\a`     | Alerta                        |
| `\b`     | Retroceso                     |
| `\e`     | Escape                        |
| `\f`     | Salto de página               |
| `\n`     | Salto de línea                |
| `\r`     | Retorno de carro              |
| `\t`     | Tabulador horizontal          |
| `\v`     | Tabulador vertical            |
| `\\`     | Barra invertida               |
| `\'`     | Comilla simple                |
| `\"`     | Comilla doble                 |
| `\377`   | Carácter ASCII octal          |
| `\xFF`   | Carácter ASCII hexadecimal    |
| `\uFFFF` | Carácter Unicode hexadecimal  |

```crystal
puts "Hello \"World\""
# => Hello "World"

puts "Hello \nWorld"
# => Hello
# => World
```

## Strings multilínea

Para escribir un string multilínea, usas la misma sintaxis que en un string de una sola línea, pero haces un salto de línea por cada línea que quieras incluir en el string.

```crystal
"Hello
World"
# => "Hello\nWorld"
```

## Unicode

[Unicode][unicode] es un estándar para codificar, representar y procesar texto en distintos sistemas de escritura.
Unicode admite más de 100 000 caracteres, entre ellos letras, signos de puntuación, símbolos y emojis.

Como Crystal usa Unicode para los strings, puedes, por ejemplo, incluir emojis en los strings.

```crystal
"Hello 🌍"
# => "Hello 🌍"
```

A veces quieres usar un carácter que no está disponible en, por ejemplo, tu editor o tu sistema.
En ese caso, puedes usar la secuencia de escape de Unicode para escribir el carácter.

```crystal
"\u{1F310}"
# => "🌐"
```
