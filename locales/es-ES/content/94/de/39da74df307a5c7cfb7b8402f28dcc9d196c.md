# Instrucciones

En este ejercicio, vas a implementar la lógica de la misión para un nuevo juego de rol que está desarrollando un amigo.

La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Por desgracia, la tragedia llega cuando su mejor amigo es secuestrado mientras busca bayas en el bosque.

Annalyn intentará encontrar y liberar a su mejor amigo, con la opción de llevar a su perro con ella en esta misión.

Tras pasar un tiempo siguiendo el rastro de su mejor amigo, encuentra el campamento en el que está prisionero su mejor amigo. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez encontrados los secuestradores, Annalyn se plantea cuál de las siguientes acciones puede llevar a cabo:

- _Ataque rápido_: se puede hacer un ataque rápido si el caballero está durmiendo, ya que tarda un tiempo en ponerse la armadura, así que estará vulnerable.
- _Espiar_: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- _Hacer señales al prisionero_: se le pueden hacer señales al prisionero usando sonidos de pájaros si el prisionero está despierto y el arquero está durmiendo, ya que los arqueros están entrenados en la señalización con pájaros, por lo que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es una acción arriesgada y solo puede salir bien de una de estas dos formas:
  - Si Annalyn lleva a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - ¡Si Annalyn no lleva a su perro, ella y el prisionero tendrán que ser muy sigilosos!
    Annalyn puede liberar al prisionero si el prisionero está despierto y tanto el caballero como el arquero están durmiendo, pero si el prisionero está durmiendo no se le puede rescatar: el prisionero se sobresaltaría por la repentina aparición de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles según el estado de los tres personajes que se encuentran en el bosque y si el perro de Annalyn está presente o no.

## 1. Comprueba si se puede hacer un ataque rápido

Implementa el método `canFastAttack()` que recibe un valor booleano que indica si el caballero está despierto. Este método devuelve `true` si se puede hacer un ataque rápido según el estado del caballero. En caso contrario, devuelve `false`:

```haxe
var knightIsAwake = true;
canFastAttack(knightIsAwake);
// => false
```

## 2. Comprueba si se puede espiar al grupo

Implementa el método `canSpy()` que recibe tres valores booleanos, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se puede espiar al grupo, según el estado de los tres personajes. En caso contrario, devuelve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
canSpy(knightIsAwake, archerIsAwake, prisonerIsAwake);
// => true
```

## 3. Comprueba si se le pueden hacer señales al prisionero

Implementa el método `canSignalPrisoner()` que recibe dos valores booleanos, que indican si el arquero y el prisionero, respectivamente, están despiertos. El método devuelve `true` si se le pueden hacer señales al prisionero, según el estado de los dos personajes. En caso contrario, devuelve `false`:

```haxe
var archerIsAwake = false;
var prisonerIsAwake = true;
canSignalPrisoner(archerIsAwake, prisonerIsAwake);
// => true
```

## 4. Comprueba si se puede liberar al prisionero

Implementa el método `canFreePrisoner()` que recibe cuatro valores booleanos. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. El método devuelve `true` si se puede liberar al prisionero según el estado de los tres personajes y la presencia del perro de Annalyn. En caso contrario, devuelve `false`:

```haxe
var knightIsAwake = false;
var archerIsAwake = true;
var prisonerIsAwake = false;
var petDogIsPresent = false;
canFreePrisoner(knightIsAwake, archerIsAwake, prisonerIsAwake, petDogIsPresent);
// => false
```
