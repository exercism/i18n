# Números exactos

Dos de los tipos de número que has visto renuncian a algo.

`INT` ocupa exactamente 32 bits, así que contiene números desde unos menos dos
mil millones hasta dos mil millones, y ni uno más. Si te pasas de ahí, da la
vuelta sin avisar: ningún error, solo una respuesta incorrecta.

`FLTD` contiene fracciones, pero solo de forma aproximada. `0.1d + 0.2d` es
casi `0.3`, pero no exactamente.

Para el trabajo en el que eso importa, la biblioteca tiene un tipo para cada
caso.

## INTI: números enteros de cualquier tamaño

`INTI` contiene un número entero sin más límite que la memoria.

```sather
   #INTI(2).pow(100)
   -- 1267650600228229401496703205376
```

Un `INT` no puede contener eso. Un `FLTD` podría contener algo parecido, y
perdería los veinte últimos dígitos.

Puedes crear uno a partir de un `INT`, o a partir de un string cuando el
número es demasiado grande para escribirlo como `INT` desde el principio:

```sather
   #INTI(42)
   #INTI("123456789012345678901234567890")
```

Después, `+`, `-`, `*`, `/` y la comparación funcionan como siempre, y `.str`
te da todos los dígitos.

Contar las formas en que una compañía puede ponerse en fila es la razón
habitual para querer esto. Doce bailarines tienen 479001600 formas, que un
`INT` puede contener; trece tienen 6227020800, que ya no.

```sather
   #INTI(20).factorial
   -- 2432902008176640000
```

## RAT: fracciones exactas

`RAT` contiene un número entero sobre otro, y los mantiene así.

```sather
   #RAT(1, 3)          -- 1/3, exactly
   #RAT(1, 2) + #RAT(1, 3)
   -- 5/6
```

No se redondea nada, porque nunca se convierte nada a un número decimal.

```sather
   #RAT(1, 10) + #RAT(2, 10) = #RAT(3, 10)      -- true
   0.1d + 0.2d = 0.3d                            -- not to be relied on
```

Un `RAT` se simplifica solo: `#RAT(2, 4)` es `1/2`, y se imprime como `1/2`.
El que sale entero se imprime como un número entero: `#RAT(6, 3)` imprime `2`.

## El coste

Ambos son más lentos que los tipos integrados, y ambos reservan memoria. `INT`
y `FLTD` son una sola instrucción de máquina; `INTI` y `RAT` son objetos que
hacen aritmética por software.

Úsalos cuando lo importante sea la exactitud, y los tipos normales en todos los
demás casos.
