# Introducción

Los valores Boolean en Cairo se representan con el tipo predeclarado `bool`, cuyos valores pueden ser `true` o `false`.

```rust
let speeding = true;   // Boolean variable 'speeding' set to 'true'
let has_error = false; // Boolean variable 'has_error' set to 'false' 
```

Cairo admite tres operadores lógicos que pueden evaluar expresiones hasta obtener valores Boolean, devolviendo `true` o `false`.

| Operador    | Qué significa                                   |
| ----------- | ----------------------------------------------- |
| `&&` (and)  | Es verdadero si ambas afirmaciones son verdaderas. |
| `\|\|` (or) | Es verdadero si al menos una afirmación es verdadera. |
| `!` (not)   | Es verdadero solo si la afirmación es falsa.     |
