# Instrucciones

Eres un elfo que trabaja en la división de logística de Papá Noel y el jefe te ha encargado un par de tareas para mejorar el software del sistema.

## 1. Obtener el nombre del juguete

El sistema debe ser capaz de obtener el nombre de un juguete de la base de datos.
La base de datos está formada por tuplas de tipo `(name: String, quantity: Int)`.

Implementa la función `getName(_:)`, que recibe un argumento que contiene una tupla de tipo `(name: String, quantity: Int)`.

```swift
let toy = (name: "Doll", quantity: 10)
getName(toy)
// Returns "Doll"
```

## 2. Añadir un juguete nuevo a la base de datos

El mercado de los juguetes es un mercado rápido y cambiante; lo que está de moda cambia muy deprisa.
Por ello, se necesita una función que cree un juguete nuevo.

Implementa la función `createToy(name:amount:)`, que recibe un argumento `name` que contiene el nombre del juguete y `amount` que contiene la cantidad del juguete.

```swift
createToy(name: "Doll", amount: 10)
// Returns (name: "Doll", amount: 10)
```

## 3. Actualizar la cantidad de un juguete

Los elfos del taller de Papá Noel no dejan de fabricar juguetes, y Papá Noel necesita llevar un registro de la cantidad de cada juguete.
Para ello, el sistema debe ser capaz de actualizar la cantidad de un juguete en la base de datos.

Implementa la función `updateQuantity(_:toy:Amount:)`, que recibe los argumentos:
- `toys`, que contiene un array de tuplas de tipo `(name: String, quantity: Int)`.
- `toy`, que contiene el nombre del juguete que hay que actualizar.
- `amount`, que contiene la nueva cantidad del juguete.

Puedes suponer que el juguete ya está en la base de datos y no hace falta que lo compruebes.

```swift
let toys = [(name: "Doll", quantity: 10), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
updateQuantity(toys, toy: "Doll", amount: 15)
// Returns [(name: "Doll", quantity: 15), (name: "Car", quantity: 5), (name: "Train", quantity: 3)]
```

## 4. Añadir una clave de categoría a un juguete

Papá Noel quiere poder categorizar los juguetes de la base de datos.
Así puede encontrar fácilmente los juguetes cuando tiene que hacer una entrega y puede ordenarlos en la base de datos.

Sin embargo, cuando se implementó el sistema por primera vez, se olvidó la clave de categoría.
Ahora el sistema debe ser capaz de añadir una clave de categoría a un juguete de la base de datos.

Implementa la función `addCategory(_:category:)`, que recibe los argumentos:
- `toys`, que contiene un array de tuplas de tipo `(name: String, quantity: Int)`.
- `category`, que contiene la clave de categoría que hay que añadir a los juguetes.

Puedes suponer que el juguete ya está en la base de datos y no hace falta que lo compruebes.
También puedes suponer que el juguete aún no tiene ninguna clave de categoría.

```swift
let toys = [(name: "Car", quantity: 5), (name: "Train", quantity: 3)]
addCategory(toys, category: "Vehicle")
// Returns [(name: "Car", quantity: 5, category: "Vehicle"), (name: "Train", quantity: 3, category: "Vehicle")]
```
