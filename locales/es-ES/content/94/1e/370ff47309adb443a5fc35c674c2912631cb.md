# Grandes gastos en la base de datos

## Enunciado del problema

ABC Corp necesita que encuentres el nombre y el departamento de los empleados con registros de pago superiores a una cantidad dada (por ejemplo, `3000.00`).

Crea un registro llamado `HighPayment` para devolver los datos requeridos. La definición del registro es la siguiente.

```ballerina
type HighPayment record {
    string name;
    string department;
    decimal amount;
    string reason;
};
```

Usa la operación `query` del cliente JDBC para obtener los datos requeridos de la base de datos.

> NOTA: Ordena el resultado por `payment_id` en orden ascendente.

## Detalles de la base de datos

Usa la base de datos H2 proporcionada para este problema.

> El archivo de la base de datos de ejemplo es `gofigure.mv.db` y el nombre de la base de datos es `gofigure`. Se encuentra dentro de la carpeta `db`.

Las siguientes tablas ya están en la base de datos H2 de ejemplo con algunos datos de muestra. Los nombres de las columnas y los tipos de datos son los siguientes.

**Nombre de la tabla**: `Employee`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `employee_id`     | integer, clave primaria autoincrementada       |
| `name`            | string        |
| `city`            | string        |
| `department`      | string        |
| `age`             | integer        |

**Nombre de la tabla**: `Payment`

| **Columnas:**      | tipo |
| -----------       | ----------- |
| `payment_id`      | integer, clave primaria autoincrementada       |
| `date`            | date        |
| `amount`          | decimal        |
| `employee_id`     | integer        |
| `reason`          | string        |

* El archivo de la base de datos es `gofigure.mv.db`. Usa la URL de JDBC como `jdbc:h2:file:/path/to/db/file`
* Nombre de usuario: `root`
* Contraseña: `root`

## Restricciones

* Usa el archivo de base de datos H2 proporcionado en la carpeta `db` para validar las consultas y el ejemplo de Ballerina
* Usa el enfoque de parámetros de dependencia de Maven para añadir el controlador de la base de datos H2 como dependencia de plataforma en tu Ballerina.toml
