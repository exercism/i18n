# Marcador de posición

## Ordenar strings en Wren

Wren es todavía un lenguaje muy joven:
hay funcionalidades, quizá habituales en otros lenguajes, que aún no están implementadas.
Una de ellas es la capacidad de ordenar strings.

El método `sort` de List de Wren usa explícitamente la comparación `<`.
`String` no implementa `<(_)`.

Uno de los retos de este ejercicio es implementar una forma de ordenar un array de strings.
