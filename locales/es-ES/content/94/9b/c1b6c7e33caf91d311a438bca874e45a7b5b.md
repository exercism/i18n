# Instrucciones

Elena es la nueva responsable de calidad de una fábrica de periódicos.
Como acaba de llegar a la empresa, ha decidido revisar algunos de los procesos de la fábrica para ver qué se podría mejorar.

Ha descubierto que los técnicos hacen un montón de controles de calidad a mano.

Ve una buena oportunidad para la automatización y te pide a ti, desarrollador freelance, que escribas un programa para supervisar algunas de las máquinas.

## 1. Supervisa el nivel de humedad de la sala

Tu primera misión es escribir un programa que supervise el nivel de humedad de la sala de producción.
Ya hay un sensor conectado al software de la empresa que devuelve periódicamente el porcentaje de humedad de la sala.

Tienes que implementar una función en el software que lance un error si el porcentaje de humedad es demasiado alto.
La función debe llamarse `check_humidity_level` y recibir el porcentaje de humedad como parámetro.

Debes detenerte con un error (el mensaje no es importante) si el porcentaje supera el 70 %.
En caso contrario, emite un mensaje que incluya «humidity test passed» y devuelve `TRUE` para confirmar que la medición es correcta.

```R
check_humidity_level(60)
#> humidity test passed
#> [1] TRUE

check_humidity_level(100)
#> Error in check_humidity_level(100) : pct_humidity <= 70 is not TRUE
```

## 2. Detecta el sobrecalentamiento

Elena está muy contenta con tu primera tarea y te pide que te ocupes de supervisar la temperatura de las máquinas.
Mientras charlas con un técnico, Greg, este te cuenta que si la temperatura de una máquina supera los 500°C, los técnicos empiezan a preocuparse por un posible sobrecalentamiento.

La máquina está equipada con un sensor que mide su temperatura interna.
Debes saber que el sensor es muy sensible y a menudo se rompe.
En ese caso, los técnicos tendrán que cambiarlo.

Tu trabajo consiste en implementar una función `report_overheating` que reciba la temperatura como parámetro y lance un error si el sensor está roto o si la máquina empieza a sobrecalentarse.

Como más adelante tendrás que reaccionar de forma distinta según el error, necesitas un mecanismo para diferenciar los dos tipos de error.

- Si el sensor está roto, la temperatura será `NULL`.
  En este caso, debes detenerte con un mensaje de error que incluya «Sensor Broken» como parte del mensaje.
- Cuando el sensor funcione, si la temperatura supera los 600°C, debes detenerte con un mensaje que incluya la temperatura.
- Si la temperatura supera los 500°C pero no llega a 600°C, debes emitir una advertencia que incluya la temperatura y devolver `FALSE`.
- En caso contrario, todo va bien, así que emite el mensaje `"temperature check passed: t °C"`, donde `t` es la temperatura, y devuelve `TRUE`.

```R
report_overheating(NULL)
#> Error in report_overheating(NULL) : Sensor Broken

report_overheating(800)
#> Error in report_overheating(800) : Overheating: 800 C

report_overheating(550)
#> [1] FALSE
#> Warning message:
#> In report_overheating(550) : Risk of overheating: 550 C

report_overheating(450)
#> temperature check passed: 450 °C
#> [1] TRUE
```


## 3. Supervisa la máquina

Ahora que tu máquina puede detectar errores y tienes un error de máquina personalizado, añades una función envoltorio que puede informar de cómo está funcionando todo.
Además de devolver los registros de las funciones anteriores, este envoltorio también tendrá que añadir registros según el tipo o los tipos de fallos que se produzcan.

- Comprueba la humedad y la temperatura.
- Si hay problemas, deja que `check_humidity_level()` y `report_overheating()` muestren sus registros.
- Si todo va bien, añade un mensaje que incluya «All OK».

Implementa una función `monitor_the_machine()` que reciba la humedad y la temperatura como argumentos.

```R
# Working well
monitor_the_machine(53, 200)
#> humidity test passed
#> temperature check passed: 200 °C
#> All OK!

# High humidity
monitor_the_machine(90, 200)
#> Error in check_humidity_level(pct_humidity) : 
#>   pct_humidity <= 70 is not TRUE

# Faulty sensor
monitor_the_machine(53, NULL)
#> humidity test passed
#> Error in report_overheating(temperature) : Sensor Broken

# Mild overheating
monitor_the_machine(53, 550)
#> humidity test passed
#> Warning message:
#> In report_overheating(temperature) : Risk of overheating: 550 C

# Dangerous overheating: shutdown
monitor_the_machine(53, 650)
#> humidity test passed
#> Error in report_overheating(temperature) : Overheating: 650 C
```
