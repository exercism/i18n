# Consejos

## General

- Un valor entero se puede definir como uno o varios dígitos consecutivos.

## 1. Define el tiempo de horneado esperado en minutos

- Tienes que definir un [enlace][bindings].

## 2. Calcula el tiempo de horneado restante en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Puedes usar el enlace definido anteriormente y referirte a él por su nombre.
- La última expresión de una función se [devuelve automáticamente][return-values] desde la función; no tienes que indicar explícitamente qué valor devolver.
- Puedes usar el [operador matemático de resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Puedes usar el [operador matemático de multiplicación][operators] para multiplicar valores.

## 4. Calcula el tiempo transcurrido en minutos

- Tienes que definir una [función][functions] con dos parámetros.
- Puedes [llamar][calling] a una de las otras funciones que hayas definido anteriormente.
- Puedes usar el [operador matemático de suma][operators] para sumar valores.
