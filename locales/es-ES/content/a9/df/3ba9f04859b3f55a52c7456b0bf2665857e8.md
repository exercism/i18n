## 1. Error al dividir entre cero

Dividir un número entre cero produce un resultado no definido, que el equipo decide que es mejor representar con un error.

Implementa el módulo `DivisionByZeroError` para que tenga el mensaje de error: `"division by zero occurred"`

```elixir
raise DivisionByZeroError
# => ** (DivisionByZeroError) division by zero occurred
```

## 2. Error al encontrarse con un subdesbordamiento de pila

Las calculadoras RPN usan una _pila_ para llevar la cuenta de los números antes de sumarlos. El equipo representa esta _pila_ con una lista de números (enteros y de coma flotante), por ejemplo: `[3, 4.0]`. Cada operación necesita una cantidad concreta de números en la pila para poder realizar su cálculo. Cuando no hay suficientes números en la pila, se habla de un error de subdesbordamiento de pila. Implementa la excepción `StackUnderflowError`, que proporciona un mensaje por defecto y un contexto adicional opcional

```elixir
raise StackUnderflowError
# => ** (StackUnderflowError) stack underflow occurred

raise StackUnderflowError, "when dividing"
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing
```

## 3. Escribe una función que divida

Implementa la función `divide/1`, que recibe una pila _(una lista de dos números)_ y:

- lanza un _subdesbordamiento de pila_ cuando la pila no contiene suficientes números
- lanza una _división entre cero_ cuando el divisor es 0 (fíjate en que la pila de números se almacena en orden inverso)
- realiza la división cuando no se lanza ningún error

```elixir
RPNCalculator.Exception.divide([])
# => ** (StackUnderflowError) stack underflow occurred, context: when dividing

RPNCalculator.Exception.divide([0, 100])
# => ** (DivisionByZeroError) division by zero occurred

RPNCalculator.Exception.divide([4, 16])
# => 4
```

> ¡Fíjate en que el orden de la lista está invertido!
