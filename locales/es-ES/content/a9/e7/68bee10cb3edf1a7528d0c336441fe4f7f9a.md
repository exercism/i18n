# Acerca de

[Estructuras][structs-and-classes] (a las que se suele llamar *structs*) son uno de los componentes fundamentales de los programas en Swift.
Las estructuras te permiten crear tipos personalizados que agrupan propiedades (datos) y métodos (comportamiento) relacionados.
De hecho, los tipos estándar de Swift, como `Int`, `Double`, `Bool`, `String`, `Array` y `Dictionary`, están implementados como estructuras.

## Definir estructuras

Define una estructura con la palabra clave `struct`, seguida del nombre del tipo y llaves que contienen su definición.
Por convención en Swift, los nombres de las estructuras usan `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Crear instancias

La definición de una estructura es un plano.
Para crear una *instancia* de una estructura, llama a su inicializador escribiendo el nombre del tipo seguido de paréntesis:

```swift
var someStats = CharacterStats()
```

Esto crea una instancia con los valores de propiedad predeterminados de la definición.

Swift también genera un **inicializador por miembros** automático para las estructuras, que te permite inicializar propiedades por nombre:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Acceder a las propiedades y modificarlas

Puedes acceder a las propiedades de una instancia y modificarlas usando la *notación de punto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como las estructuras son tipos de valor, modificar las propiedades de una instancia requiere que la propia instancia se declare con `var`.
Si la instancia se declara con `let`, todas sus propiedades se vuelven inmutables.
