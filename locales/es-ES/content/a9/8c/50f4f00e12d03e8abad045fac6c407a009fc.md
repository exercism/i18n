# Acerca de

Un bucle es una forma de llamar repetidamente a una o varias instrucciones en conjunto.
Cada ejecución de un conjunto de instrucciones se denomina iteración.

## Bucle `while`

Un bucle `while` ejecuta un conjunto de instrucciones mientras una expresión Boolean situada en la parte superior del bucle es verdadera.
Cuando la expresión Boolean es falsa, el bucle deja de ejecutarse y la ejecución continúa en la siguiente línea de código después del bucle.

Si la expresión Boolean se evalúa como falsa desde el principio, el bucle `while` no se ejecutará en absoluto y la ejecución continuará en la siguiente línea de código después del bucle.

```c
int main() {
    int i = 0;
    while (i < 5) {
        printf("Number is %i\n", i++);
    }    
    return 0;
}
```

Es importante que exista una condición que termine el bucle; de lo contrario, se trata de un bucle infinito que bloqueará todo el avance del código.
Si al código anterior se le quitara el `++` de `i`, sería un bucle infinito.

## Bucle `do`

En un bucle `do`, la expresión Boolean se evalúa en la parte inferior del bucle.
Un bucle `do` siempre se ejecuta al menos una vez, como en el siguiente ejemplo

```c
do {
    printf("Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
} while (answer != 42); 
// Note that a semicolon is needed after the Boolean expression.
```

Con un bucle `while`, esto sería más verboso

```c
printf(""Enter the Answer to the Ultimate Question of Life: ");
scanf("%d", &answer);
while (answer != 42) {
    printf(""Enter the Answer to the Ultimate Question of Life: ");
    scanf("%d", &answer);
}
```

## Bucle `for`

A menudo, un bucle actualiza una variable y termina cuando la variable alcanza un valor determinado.
Un bucle `for` es una forma de inicializar, actualizar y evaluar una o varias variables en una sola línea, entre paréntesis.
La primera sección sirve para inicializar la variable, la segunda para evaluar la variable y la tercera para actualizar el valor de la variable.

```c
for (int i = 0; i < 5; i++) {
    printf("Number is %i\n", i);
}
```

Esto es menos verboso que el bucle `while` equivalente y, aun así, sigue siendo legible.

Las secciones de inicialización y actualización del bucle `for` pueden gestionar más de una variable usando el operador coma para separar las expresiones dentro de las condiciones.

```c
    int i, j;
    for (i = 0, j = 5; i < 5 && j > 2; i++, j--) {
        printf("i is %i\n", i);
        printf("j is %i\n", j);
    }
    printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 5
i is 1
j is 4
i is 2
j is 3
After the loop
```

No es necesario definir ninguna de las secciones del `for`.
Una expresión de evaluación vacía se evalúa como verdadera, así que un bucle `for` podría usarse para definir un bucle infinito de esta forma

```c
int i = 0;
for (;;) {
    printf("Number is %i\n", i++);
    if (i == 5) break;
}
```

Esto es similar al bucle `while`, en que `i` se inicializa antes del bucle y se incrementa dentro de él.
Además, `i` se evalúa dentro del bucle y el bucle termina con la instrucción `break`.

## Instrucción `break`

A veces, un bucle puede necesitar terminar ante una condición especial que no se evalúa en su expresión Boolean.
La instrucción `break` termina el bucle y la ejecución continúa en la siguiente línea de código después del bucle.

```c
int i, j, k;
for (int i = 0, j = 5, k = 3; i < 5 && j > 2; i++, j--) {
    printf("i is %i\n", i);
    printf("j is %i\n", j);
    if (k == 3) break;
}
printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 5
After the loop
```

## Instrucción `continue`

A veces, un bucle puede necesitar empezar su siguiente iteración sin completar la iteración actual.
La instrucción `continue` detiene la ejecución de la iteración actual y continúa la ejecución al principio de la siguiente iteración.

```c
int i, j;
for (int i = 0, j = 4; i < 4 && j > 0; i++, j--) {
    if (i == j) continue;
    printf("i is %i\n", i);
    printf("j is %i\n", j);
}
printf("After the loop");
```

Esto imprimirá

```
i is 0
j is 4
i is 1
j is 3
i is 3
j is 1
After the loop
```

No imprime los valores de `i` y `j` cuando ambos son `2`.
