# Instalación

El [Godot Engine][godot-engine] se usa para ejecutar código GDScript.
El Godot Engine funciona en Windows, Linux, macOS y Android.



## Instalar Godot Engine

El Godot Engine se puede descargar directamente desde [la web de Godot Engine][godot-engine].
La descarga contiene un único ejecutable, cuyo nombre incluye la versión de Godot Engine.
Hay que cambiar el nombre de este archivo a `godot` y colocarlo en uno de los directorios de `$PATH`.
Una vez completada la instalación, puedes comprobar si la CLI se instaló correctamente ejecutando este comando en una terminal:

```bash
godot --version
```

Este track usa la versión 4.7.2 de Godot.
