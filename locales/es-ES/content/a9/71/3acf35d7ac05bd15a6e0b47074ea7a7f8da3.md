# Introducción

Una cadena de caracteres en Factor es una secuencia de caracteres. La mayoría de las palabras del vocabulario [`sequences`][sequences] funcionan con strings, además de las palabras dedicadas al manejo de strings que hay en [`splitting`][splitting], [`ascii`][ascii] y compañía.

## Literales de string

Los strings se escriben entre comillas dobles. Se admiten los escapes habituales, como `\n`, `\t`, `\r`, `\\`, `\"`:

```factor
"hello, world" .                 ! => "hello, world"
"first\nsecond" print            ! prints two lines
```

## Longitud e indexación

Como un string es una secuencia, las palabras `length` y `nth` de [`sequences`][sequences] funcionan directamente sobre él.

`length` devuelve el número de caracteres:

```factor
"hello" length .    ! => 5
```

`nth` recibe un índice que empieza en 0 y la secuencia, y devuelve el elemento que está en esa posición. En el caso de un string, el elemento es un *carácter*, es decir, un punto de código (un número entero), no una subcadena de un solo carácter:

```factor
0 "hello" nth .     ! => 104   (CHAR: h)
4 "hello" nth .     ! => 111   (CHAR: o)
```

## De un carácter de vuelta a un string

Para convertir un único punto de código en un string de un solo carácter, usa `1string ( char -- str )`, del vocabulario [`strings`][strings]. `CHAR:` es la forma en tiempo de análisis de un punto de código literal:

```factor
CHAR: A 1string .                ! => "A"
0 "hello" nth 1string .          ! => "h"
```

## Dividir

El vocabulario [`splitting`][splitting] corta un string en fragmentos.

`split1` corta por la *primera* aparición de un separador y devuelve ambas mitades:

```
split1 ( seq subseq -- before after )
```

```factor
"foo: bar" ": " split1 .s
! => "foo"
! => "bar"
```

`split` corta por *cualquiera* de los caracteres de un conjunto de separadores y puede producir fragmentos vacíos:

```factor
"[ERROR]: Stack overflow" "[]" split .
! => { "" "ERROR" ": Stack overflow" }
```

`harvest` (en [`sequences`][sequences]) descarta los fragmentos vacíos:

```factor
"[ERROR]: Stack overflow" "[]" split harvest .
! => { "ERROR" ": Stack overflow" }
```

## Extraer un fragmento

Una vez que un string se ha dividido en un array de fragmentos, `first`, `second`, `third` y `fourth` (en [`sequences`][sequences]) devuelven el fragmento que está en esa posición:

```factor
"apple,bee,carrot,duck" "," split first .    ! => "apple"
"apple,bee,carrot,duck" "," split second .   ! => "bee"
"apple,bee,carrot,duck" "," split third .    ! => "carrot"
"apple,bee,carrot,duck" "," split fourth .   ! => "duck"
```

Cuando quieras tener en la pila todos los fragmentos iniciales a la vez, `first2` y `first3` desempaquetan dos o tres de ellos en un solo paso:

```factor
"apple,bee,carrot,duck" "," split first2 .s
! => "apple"
! => "bee"

"apple,bee,carrot,duck" "," split first3 .s
! => "apple"
! => "bee"
! => "carrot"
```

Aplicado a un string, `first` devuelve el primer **carácter**, un punto de código, en lugar de una subcadena:

```factor
"hello" first .                         ! => 104   (CHAR: h)
```

## Recortar

`[ blank? ] trim` (de [`sequences`][sequences], con `blank?` del vocabulario [`ascii`][ascii]) elimina los espacios en blanco al principio y al final:

```factor
"  Disk full \r\n" [ blank? ] trim .
! => "Disk full"
```

## Conversión de mayúsculas y minúsculas

`>lower` y `>upper` (de [`ascii`][ascii]) devuelven un string nuevo con las mayúsculas y minúsculas cambiadas:

```factor
"WARNING" >lower .    ! => "warning"
"hello" >upper .      ! => "HELLO"
```

## Unir

Dos palabras de [`sequences`][sequences] construyen strings:

`surround` envuelve un string con un prefijo y un sufijo:

```
surround ( seq pre post -- new-seq )
```

```factor
"warning" "(" ")" surround .    ! => "(warning)"
```

`glue` une dos strings con un separador entre ellos:

```
glue ( s1 s2 sep -- s )
```

```factor
"Disk full" "(error)" " " glue .    ! => "Disk full (error)"
```
