# Acerca de

Elm es un lenguaje encantador para crear aplicaciones web fiables.
Tiene mensajes de error amigables, un rendimiento excelente, recursos pequeños y ninguna excepción en tiempo de ejecución.

Probablemente, la parte más famosa y más copiada de Elm sea la arquitectura Elm, un patrón sencillo para estructurar aplicaciones web que es, además, la forma en que se escriben todas las aplicaciones web de Elm.

La idea central es que tu código se construye en torno a un `Model` con el estado de tu aplicación, una forma de actualizarlo con `update` y una forma de mostrarlo con `view`.

El `Model` contiene el estado de la aplicación: todos los datos que la aplicación necesita.
Si te imaginas una aplicación sencilla con un cuadro de texto y un texto que muestra ese mismo texto al revés, el modelo sería el siguiente.
También puedes ver este ejemplo en la [Elm Guide][elm-guide-text-fields].

```elm
type alias Model =
  { text : String
  }
```

`update` es una función a la que se llama con un `Msg` cuando hay un cambio (como cuando el usuario hace clic en un botón).
Recibe el `Msg` y el `Model` actual, y devuelve un nuevo `Model`.

```elm
type Msg
  = TextChanged String

update : Msg -> Model -> Model
update msg model =
  case msg of
    TextChanged newText ->
      { model | text = newText }
```

`view` es una función que devuelve el HTML que se muestra al usuario en el navegador.
Recibe el `Model` actual y devuelve un `Html Msg` (el tipo que Elm usa para representar HTML).

```elm
view : Model -> Html Msg
view model =
  Html.div []
    [ Html.input
      [ Html.Attributes.placeholder "Text to reverse"
      , Html.Attributes.value model.text
      , Html.Events.onInput TextChanged
      ]
      []
    , Html.div [] [ Html.text (String.reverse model.text) ]
    ]
```

[elm-guide-text-fields]: https://guide.elm-lang.org/architecture/text_fields
