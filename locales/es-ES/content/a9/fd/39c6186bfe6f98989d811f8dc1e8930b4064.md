# Pistas

## General

- [Estructuras y clases][structs-and-classes] comparten una sintaxis de definición similar.

## 1. Define una estructura Size

- Las propiedades deben definirse como `var`s si se pueden cambiar.
- Las propiedades height y width deben tener los valores predeterminados 80 y 60, respectivamente.
- Los métodos de una estructura deben marcarse como `mutating` si cambian propiedades de la estructura.

## 2. Define una estructura Position

- Las propiedades deben definirse como `var`s si se pueden cambiar.
- Las propiedades x e y deben tener el valor predeterminado 0.
- Los métodos de una estructura deben marcarse como `mutating` si cambian propiedades de la estructura.

## 3. Define una clase Window

- Las estructuras se pueden inicializar con distintos valores de propiedades usando [inicializadores por miembros][memberwise-initializers].
- Las propiedades constantes deben definirse con `let`.
- La propiedad `contents` debe ser opcional, ya que puede que no tenga un valor.
- Tienes que definir un inicializador vacío para la clase (`init() {}`).

## 4. Añade un método para redimensionar ventanas

- El método debe recibir un parámetro `to` de tipo `Size`.
- Es posible extraer width y height del parámetro `to` usando la notación de punto.

## 5. Añade un método para mover ventanas

- El método debe recibir un parámetro `to` de tipo `Position`.
- Es posible extraer x e y del parámetro `to` usando la notación de punto.

## 6. Añade un método para establecer el contenido de una ventana

- En Swift, es posible tener dos métodos con el mismo nombre pero con parámetros diferentes.
- Define un método con el parámetro `title` que establezca la propiedad `title`.
- Define un método con el parámetro `text` que establezca la propiedad `contents`.
- Define un método de visualización que imprima el título y el contenido de la ventana.

## 7. Crea un inicializador para la clase Window

- La clase debe tener dos inicializadores: uno que no recibe parámetros y otro que recibe parámetros.
- El nuevo inicializador debe tener los parámetros `title` y `contents`; también debe permitir los parámetros opcionales `size` y `position`
    Si no se proporcionan parámetros, se deben usar los valores predeterminados.
- Los parámetros opcionales se pueden conseguir usando [valores de parámetros predeterminados][default-parameters-vales].
