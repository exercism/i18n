# Introducción

Un *montículo* es una colección que siempre sabe cuál es su elemento más pequeño y te permite eliminarlo rápidamente: la implementación natural de una *cola de prioridad*. Los montículos viven en el vocabulario [`heaps`][heaps].

`<min-heap>` crea un montículo vacío cuya clave más pequeña sale primero; `<max-heap>` es la imagen especular. Cada elemento es un *valor* que se guarda bajo una *clave*, y la clave es la prioridad:

```
<min-heap> ( -- min-heap )
heap-push  ( value key heap -- )
```

```factor
USING: heaps ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
```

Un montículo es *mutable*: `heap-push` lo modifica in situ. `heap-peek` devuelve el valor y la clave del frente sin eliminarlos, `heap-pop` los elimina y los devuelve, y `heap-pop-all` vacía el montículo en una lista de asociación de pares `{ key value }` en orden de prioridad:

```
heap-peek    ( heap -- value key )
heap-pop     ( heap -- value key )
heap-pop-all ( heap -- alist )
```

```factor
USING: heaps kernel prettyprint ;

<min-heap>
"alice" 5 pick heap-push
"bob"   2 pick heap-push
dup heap-peek drop .     ! => "bob"
heap-pop-all .           ! => { { 2 "bob" } { 5 "alice" } }
```

[heaps]: https://docs.factorcode.org/content/vocab-heaps.html
