# Anexo a las instrucciones

## Personalizar y lanzar excepciones

A veces es necesario tanto [personalizar](https://docs.python.org/3/tutorial/errors.html#user-defined-exceptions) excepciones como lanzarlas con [`raise`](https://docs.python.org/3/tutorial/errors.html#raising-exceptions) en tu código. Cuando lo hagas, incluye siempre un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda enormemente con el debug.

Las excepciones personalizadas se pueden crear mediante nuevas clases de excepción (consulta [`classes`](https://docs.python.org/3/tutorial/classes.html#tut-classes) para más detalles), que normalmente son subclases de [`Exception`](https://docs.python.org/3/library/exceptions.html#Exception).

En los casos en los que sepas que el origen del error será una derivada de un tipo de excepción concreto, puedes optar por heredar de uno de los [`built in error types`](https://docs.python.org/3/library/exceptions.html#base-classes) que hay bajo la clase _Exception_. Cuando lances el error, sigue incluyendo un mensaje significativo.

Este ejercicio en concreto requiere que crees una _excepción personalizada_ que se [lance](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement)/«se arroje» cuando la pila no esté suficientemente llena. Los tests solo pasarán si personalizas una excepción adecuada, lanzas esa excepción con `raise` e incluyes los mensajes de error adecuados.


```python
# subclassing the Exception to create a StackUnderflowError
class StackUnderflowError(Exception):
    """Exception raised when Stack is not full.
       message: explanation of the error.
    """
    def __init__(self, message):
        self.message = message

        
# raising a StackUnderflowError
raise StackUnderflowError("Insufficient number of items in stack")
```

Además, este ejercicio requiere que lances varias `built-in exceptions` con mensajes de error.
Para lanzar una `built-in exception` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# an example when division by zero is attempted.
raise ZeroDivisionError("divide by zero")

#an example when the operation is undefined.
raise ValueError("undefined operation")
```
