# Introducción

En Go, una constante es un valor simple e invariable que se asigna a un nombre con la palabra clave `const`:

```go
const myWebsite = "Exercism"
```

Estas constantes no tienen tipo, pero se les asigna un tipo predeterminado basado en su sintaxis cuando se requiere un tipo, como cuando se pasan a un método.
Las constantes con tipo se pueden crear añadiendo un tipo de forma explícita:

```go
const myWebsite string = "Exercism"
```

Go no tiene enumeraciones como algunos otros lenguajes, pero sí tiene un identificador predeclarado llamado `iota` para crear constantes enumeradas.
Las constantes en un bloque se repiten de forma implícita:

```go
const (
    a = 9
    b
    c
    d = iota
    e
    f
    g
)
fmt.Print(a, b, c, d, e, f, g)
// Output: 9 9 9 3 4 5 6
```
