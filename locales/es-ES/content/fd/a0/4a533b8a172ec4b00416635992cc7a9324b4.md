# Pruebas

Puedes ejecutar las pruebas abriendo un símbolo del sistema en el directorio del ejercicio y, a continuación, ejecutando el [comando `dotnet test`](https://docs.microsoft.com/en-us/dotnet/core/tools/dotnet-test)
Como alternativa, la mayoría de los IDE tienen compatibilidad integrada para ejecutar pruebas, entre ellos [Visual Studio](https://docs.microsoft.com/en-us/visualstudio/test/run-unit-tests-with-test-explorer), [Rider](https://www.jetbrains.com/help/rider/Unit_Testing_in_Solution.html) y [Visual Studio code](https://github.com/OmniSharp/omnisharp-vscode/wiki/How-to-run-and-debug-unit-tests).
Consulta la [página de pruebas](https://exercism.org/docs/tracks/csharp/tests) para obtener más información.

## Pruebas omitidas

Al principio, solo la primera prueba estará habilitada.
Esto es para animarte a resolver el ejercicio paso a paso.
Cuando consigas que la primera prueba pase, elimina la propiedad `Skip` de la siguiente prueba y trabaja para conseguir que esa prueba pase.
