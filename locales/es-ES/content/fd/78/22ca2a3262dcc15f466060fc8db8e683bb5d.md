# Introducción

Swift tiene un conjunto de instrucciones que pueden usarse para alterar el flujo de control normal de los bucles.
Estas se conocen como instrucciones de transferencia de control.
Ya has visto `return`; en este concepto presentaremos otras, entre las que se incluyen `continue`, `break` y las etiquetas.
No veremos `fallthrough` en este concepto, pero puedes leer sobre él en el [libro de Swift][fallthrough].

## Continue

A veces es necesario saltar a la siguiente iteración de un bucle antes de tiempo, sin completar el resto de las instrucciones de la iteración actual del bucle.
La palabra clave `continue` sirve para esto.
Cuando se ejecuta `continue`, el bucle salta a la siguiente comprobación para ver si se puede ejecutar la siguiente iteración del bucle, es decir, el `while` en los bucles while y repeat-while, o la comprobación de si hay otro elemento en la secuencia en los bucles for-in.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

## Break

Break se usa para salir de un bucle antes de tiempo.
Cuando se ejecuta `break`, el bucle termina de inmediato y el programa continúa con la primera instrucción después del bucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

## Etiquetas

Cuando hay bucles anidados, a veces se quiere usar `break` o `continue` para salir o reiniciar los bucles externos que contienen el bucle en el que se usan `break` o `continue`.
En casos como estos, se pueden usar etiquetas para especificar el bucle del que se quiere salir o que se quiere reiniciar.
Un bucle se puede etiquetar poniendo un nombre seguido de dos puntos delante del `while`, `repeat` o `for` que inicia el bucle.

Para ver el efecto de usar etiquetas de esta forma, fíjate en el siguiente bucle.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
