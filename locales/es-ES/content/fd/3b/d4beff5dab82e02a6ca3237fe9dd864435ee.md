# Tests

Para ejecutar los tests desde el directorio del ejercicio, ejecuta el comando:

```sh
odin test .
```

Mientras ejecutas los tests, Odin puede hacer un «vet» de tu código: puede buscar cosas como importaciones y variables sin usar. Ejecuta tus tests con:

```sh
odin test . -vet
```

Para ver más opciones, consulta `odin test -help`.
