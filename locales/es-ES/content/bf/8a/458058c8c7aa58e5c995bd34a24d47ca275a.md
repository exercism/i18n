# Introducción

Hasta ahora hemos visto que los argumentos que se pasan a un método se emparejan con los parámetros declarados del método según su posición. Un enfoque alternativo, sobre todo cuando una rutina recibe un número elevado de argumentos, permite a quien llama emparejar los argumentos indicando el identificador del parámetro declarado.

El siguiente ejemplo ilustra la sintaxis:

```csharp
class Card
{
    static string NewYear(int year, int month, int day)
    {
        return $"Happy {year}-{month}-{day}!";
    }
}

Card.NewYear(month: 1, day: 1, year: 2020);  // => "Happy 2020-1-1!"
```
