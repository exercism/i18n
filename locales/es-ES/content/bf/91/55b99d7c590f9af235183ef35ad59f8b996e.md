# Ejecutar los tests

Los ejercicios que se han descargado con el [cliente de línea de comandos de Exercism](https://exercism.io/cli) se entregan con un mínimo de tres ficheros: un fichero `readme.md`, un fichero `.dpr` y un fichero `.pas`. El fichero `.dpr` es el fichero de proyecto de Delphi y el fichero `.pas` es el test runner. Carga el proyecto de Delphi haciendo doble clic en el fichero `.dpr` o abriendo el proyecto desde el propio Delphi. Serás responsable de crear un nuevo fichero `.pas` que contenga el código de tu solución contra el que se ejecutarán los tests. Consulta el fichero `readme.md` para saber cómo compilar y ejecutar tu código.

Todos los tests están ignorados excepto el primero, para que trabajes en él. Para continuar, basta con comentar el atributo `[Ignore]` del test para empezar a trabajar en él.

Asegúrate de que [DUnitX](https://github.com/VSoftTechnologies/DUnitX) está instalado, si no lo instalaste ya con la instalación anterior.
