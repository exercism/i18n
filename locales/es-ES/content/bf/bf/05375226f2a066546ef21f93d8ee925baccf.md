# Introducción

Un [`list`][list] es una colección mutable de elementos en _secuencia_.
 Como la mayoría de las colecciones (_consulta los tipos integrados [`tuple`][tuple], [`dict`][dict] y [`set`][set]_), los arrays pueden contener referencias a cualquier tipo de dato (o a varios), incluidos otros arrays.
 Los arrays se pueden copiar total o parcialmente mediante la [notación de rebanadas][slice notation] o usando `<list>.copy()`.
 Como ocurre con cualquier [secuencia][sequence type], se hace referencia a los elementos de `lists` mediante un número `0-based index` desde la izquierda, o `-1-based index` desde la derecha.

Los arrays admiten tanto [operaciones de secuencia comunes][common sequence operations] como [operaciones de secuencia mutables][mutable sequence operations], como `min(<list>)`/`max(<list>)`, `<list>.index()`, `<list>.append()` y `<list>.reverse()`.
 Se puede iterar por los elementos de un `list` con la construcción `for item in <list>`.
 Se puede usar `for index, item in enumerate(<list>)` cuando se necesitan tanto el índice como el valor del elemento.

Python también ofrece muchos [métodos de array][list-methods] útiles para trabajar con arrays.
 A continuación se explican algunos de estos `list methods`.


Ten en cuenta que, cuando manipulas un `list` con un `list-method`, **alteras el array** que se ha pasado.
 Si no quieres modificar el `list` original, tendrás que hacer al menos una `shallow copy` de él mediante un slice o `<list>.copy()`.


## Añadir elementos

Para añadir un elemento al final (el «lado derecho») de un array existente, usa `<list>.append(<item>)`:

```python
>>> numbers = [1, 2, 3]
>>> numbers.append(9)

>>> numbers
[1, 2, 3, 9]
```

En lugar de _añadir al final_, `<list>.insert()` te permite añadir el elemento en un _índice concreto_ del array.
Acepta dos parámetros:

1. el `<index>` en el que quieres insertar el elemento.
2. el `<item>` que se va a insertar.

**Nota**: Si el `index` indicado es 0, el elemento se añadirá al principio (el «lado izquierdo») del `list`.
 Si el `index` indicado es mayor que el último `index` del `list`, el elemento se añadirá en la última posición, lo que equivale a usar `<list>.append(<item>)`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.insert(0, -2)

>>> numbers
[-2, 1, 2, 3]

>>> numbers.insert(1, 0)

>>> numbers
[-2, 0, 1, 2, 3]
```


`<list>.extend(<item>)` se puede usar para combinar un array existente con los elementos de otro iterable (por ejemplo, un `set`, `tuple`, `str` o `list`).
  El iterable se _desempaqueta_ y los elementos se añaden en orden (_usar `<list>.append(<item>)` en este caso añadiría todo el iterable como un **único elemento**_).


```python
>>> numbers = [1, 2, 3]
>>> other_numbers = [5, 6, 7]

>>> numbers.extend(other_numbers)

>>> numbers
[1, 2, 3, 5, 6, 7]

>>> numbers.extend([8, 9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9]

>>> numbers.append([8,9])

>>> numbers
[1, 2, 3, 5, 6, 7, 8, 9, [8, 9]]
```


## Eliminar elementos

Para eliminar un elemento de un array, usa `<list>.remove(<item>)`, pasando como argumento el elemento que quieres eliminar.
 `<list>.remove(<item>)` lanzará un `ValueError` si el elemento no está presente en el `list`.


```python
>>> numbers = [1, 2, 3]
>>> numbers.remove(2)

>>> numbers
[1, 3]

# Trying to remove a value that is not in the list throws a ValueError
>>> numbers.remove(0)
ValueError: list.remove(x): x not in list
```


Como alternativa, el método `<list>.pop(<index>)` elimina **y** `return` un elemento para que puedas usarlo.


`<list>.pop(<index>)` acepta un parámetro opcional: el `index` del elemento que se va a eliminar y devolver.
 Si no se especifica el argumento (opcional) `index`, se eliminará y devolverá el último elemento del `list`.
 Si el `index` especificado es mayor que el `index` del último elemento, se lanza un `IndexError`.


```python
>>> numbers = [1, 2, 3]

>>> numbers.pop(0)
1

>>> numbers
[2, 3]

>>> numbers.pop()
3

>>> numbers
[2]

>>> numbers.pop(1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: pop index out of range
```

Se pueden eliminar todos los elementos de un `list` con `list.clear()`. No acepta ningún parámetro.

```python
>>> numbers = [1, 2, 3]
>>> numbers.clear()

>>> numbers
[]
```

## Invertir y reordenar

El método `<list>.reverse()` invierte el orden de los elementos **in situ**.


```python
>>> numbers = [1, 2, 3]
>>> numbers.reverse()

>>> numbers
[3, 2, 1]
```


Se puede reordenar un array _**in situ**_ con la ayuda de [`<list>.sort()`][sort].
El orden de ordenación predeterminado es _ascendente_ desde la izquierda.
La documentación de Python ofrece [más consejos y técnicas para ordenar][sorting how to].

~~~~exercism/note
 De 2002 a 2022, Python usó internamente un algoritmo llamado [`Timsort`][timsort] para ordenar arrays, pero cambió a [`Powersort`][powersort] a partir de `Python 3.11`.

[powersort]: https://www.wild-inter.net/publications/munro-wild-2018
[timsort]: https://en.wikipedia.org/wiki/Timsort
~~~~


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

# The default sort order is *ascending*.
>>> names.sort()

>>> names
["Bruce", "Natasha", "Thor", "Tony"]
```

Si quieres un orden _descendente_, pasa el argumento `reverse=True`:

```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]
>>> names.sort(reverse=True)

>>> names
["Tony", "Thor", "Natasha", "Bruce"]
```

Cuando no quieras modificar el array original, puedes usar la función integrada [`sorted(<iterable>)`][sorted] para devolver una **copia** ordenada.


```python
>>> names = ["Tony", "Natasha", "Thor", "Bruce"]

>>> sorted(names)
['Bruce', 'Natasha', 'Thor', 'Tony']
```


## Apariciones de un elemento en un array

El número de apariciones de un elemento en un array se puede calcular con `list.count(<item>)`.
 Acepta como argumento el `item` que se va a contar y devuelve el número total de veces que ese elemento aparece en el `list`.


```python
>>> items = [1, 4, 7, 8, 2, 9, 2, 1, 1, 0, 4, 3]

>>> items.count(1)
3
```

## Encontrar el índice de los elementos

`<list>.index(<item>)` devuelve el número de `index` de la _primera aparición_ del elemento que se le pasa.
 Si no hay ninguna aparición, se lanza un `ValueError`.
 Si no necesitas la posición exacta de un elemento, el operador integrado `in` es más eficiente para comprobar si un array contiene un valor dado.


La indexación empieza en cero desde la izquierda, así que la posición del «primer» elemento es `0`.
La indexación también funciona desde la derecha, empezando por `-1`.


```python
>>> items = [7, 4, 1, 0, 2, 5]

>>> items.index(4)
1

>>> items.index(10)
ValueError: 10 is not in list
```

También se pueden indicar los índices `start` y `end` para limitar la búsqueda a una sección concreta del `list`:

```python
>>> names = ["Tina", "Leo", "Thomas", "Tina", "Emily", "Justin"]

>>> names.index("Tina")
0

>>> names.index("Tina", 2, 5)
3
```
