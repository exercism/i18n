# Anexo a las instrucciones

## Pistas

Para este ejercicio, la siguiente funcionalidad de C# te resultará útil:
Los enumerables se evalúan de forma diferida. Te permiten trabajar con una secuencia infinita de valores.
Consulta [este artículo](https://blogs.msdn.microsoft.com/pedram/2007/06/02/lazy-evaluation-in-c/).

Nota: para ayudar a acelerar el cálculo, no deberías comprobar los números que de antemano sabes que nunca serán primos. Para más información, consulta la [criba de Eratóstenes](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
