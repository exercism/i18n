# CLI

## Configuración

La forma más sencilla de instalar Purescript es mediante Node.js y NPM.

Si aún no tienes Node.js instalado en tu ordenador, puedes descargarlo desde el [sitio web de Node.js][nodejs-website]. Una vez tengas Node.js funcionando, introduce este comando en la terminal para instalar el compilador de PureScript y Spago, el gestor de paquetes y herramienta de compilación.

```shell
npm install -g purescript spago
```

Puedes encontrar más información en el [repositorio de PureScript][purescript-repository].

## Requisitos

Instala las dependencias del ejercicio:

```shell
spago install
spago build
```

## Hacer que la suite de pruebas pase

Ejecuta las pruebas con:

```shell
spago test
```

En las suites de pruebas se han omitido todas las pruebas menos la primera. Así puedes resolver el ejercicio paso a paso.

Cuando consigas que una prueba pase, puedes activar la siguiente cambiando `xit` por `it`.

## Enviar la solución

Cuando ya no se omita ninguna prueba y todas pasen, puedes enviar tu solución con:

```shell
exercism submit src/<NAME>.purs
```

## Escribir pruebas personalizadas

Si quieres escribir pruebas adicionales y personalizadas, crea un archivo nuevo `test/Custom.purs` y envíalo junto con tu solución y el archivo nuevo:

```shell
exercism submit src/<NAME>.purs test/Custom.purs
```
