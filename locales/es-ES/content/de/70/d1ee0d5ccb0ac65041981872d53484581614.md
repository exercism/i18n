# Pistas

## General

- Usa el tipo array integrado [(con enlace)][list].

## 1. Define una función que devuelva un array de lenguajes vacío

- La función tiene que devolver `[]`.

## 2. Define una función para añadir un lenguaje al array

- Se puede anteponer un elemento a un array usando `:`.

## 3. Define una función para eliminar un lenguaje del array

- Haskell [proporciona una función][tail] para devolver un array con el primer elemento eliminado.

## 4. Define una función que devuelva el primer elemento del array

- Haskell [proporciona una función][head] para obtener el primer elemento de un array.

## 5. Define una función que devuelva cuántos lenguajes hay en el array

- Haskell [proporciona una función][length] para contar la longitud de un array.

## 6. Define una función que determine si el array incluye un lenguaje funcional

- Tu función debe devolver un valor Boolean que indique si `"Haskell"` es un miembro del array. 
  Haskell [proporciona una función][elem] para comprobar si un elemento pertenece al array.
