# Introducción

Haxe tiene dos tipos de números, los enteros y los decimales:

- `Int`: representa un número entero.
- `Float`: representa un número de coma flotante de doble precisión de 64 bits.

```haxe
var integer:Int = 10;
var floating:Float = 5.4;
```

Aunque cualquier `Int` se puede usar donde se espera un `Float` (es decir, `Int` **se puede asignar a** `Float` o **se unifica con** `Float`), lo contrario no es cierto: asignar un `Float` a un `Int` puede provocar una pérdida de precisión y, por tanto, no se permite de forma implícita.
