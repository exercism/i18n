# Instrucciones

En este ejercicio, vas a procesar mensajes de log con seis niveles de gravedad.

Cada línea de log es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los distintos niveles de log:

| NIVEL     | LVL   |
| --------- | ----- |
| `Trace`   | `TRC` |
| `Debug`   | `DBG` |
| `Info`    | `INF` |
| `Warning` | `WRN` |
| `Error`   | `ERR` |
| `Fatal`   | `FTL` |

## 1. Analizar el nivel de log

Define una enumeración `LogLevel` que tenga seis elementos correspondientes a los niveles de log definidos arriba.
A continuación, define la función `parse_log_level`, que recibe el mensaje de log como parámetro y devuelve el miembro de la enumeración correspondiente a su nivel.

```python
parse_log_level("[INF]: File deleted")
#=> LogLevel.Info
```

## 2. Admitir un nivel de log desconocido

Por desgracia, algunos mensajes de log aparecen de vez en cuando con una gravedad _desconocida_. Para gestionar con elegancia estos mensajes de log «misteriosos» en la función `parse_log_level`, añade un miembro `Unknown` a la enumeración `LogLevel` que se devuelva al analizar un nivel de log desconocido:

```python
parse_log_level("[XYZ]: Overly specific, out of context message")
#=> LogLevel.Unknown
```

## 3. Convertir un mensaje de log al formato corto

El nivel de log de una línea de log es bastante verboso. Para reducir el espacio en disco necesario para almacenar los mensajes de log, se define un formato corto: `"[<CODE_LEVEL>]:<MESSAGE>"`.

Los códigos de nivel de log siguen una correspondencia sencilla:

| NIVEL     | CÓDIGO |
| --------- | ---- |
| `Trace`   | `0`  |
| `Debug`   | `1`  |
| `Info`    | `4`  |
| `Warning` | `5`  |
| `Error`   | `6`  |
| `Fatal`   | `7`  |
| `Unknown` | `42` |

Define la función `convert_to_short_log()`, que recibe dos parámetros:

1. Nivel de log: el nivel de log del mensaje enviado. Por ejemplo: `LogLevel.Error`.
2. Mensaje de log: el mensaje de tipo `str`.

```python
convert_to_short_log(LogLevel.Error, "Stack overflow")
# => "6:Stack overflow"
```

## 4. Crear un alias

Parece que el usuario ha creado logs para `LogLevel.Warn` en lugar de `LogLevel.Warning`. Crea un `alias` para `LogLevel.Warning` y devuelve el nuevo miembro alias en la función `get_warn_alias`.

Esto se puede hacer en la misma clase de enumeración `LogLevel` ya definida al principio del archivo. Ambos miembros de LogLevel deben apuntar al mismo valor: `"WRN"`.

```python
get_warn_alias()
#=> LogLevel.Warn

get_warn_alias() == LogLevel.Warning
#=> True
```

## 5. Nombres y valores de todos los miembros

Define la función `get_members()`.

Esta función debe devolver un array de tuplas `(name, value)` que contenga todos los miembros de la enumeración `LogLevel`.

```python
get_members()
#=> [('Trace', 'TRC'), ('Debug', 'DBG'), ('Info', 'INF'), ('Warning', 'WRN'),
# ('Error', 'ERR'), ('Fatal', 'FTL'), ('Unknown', 'UKN')]
```
