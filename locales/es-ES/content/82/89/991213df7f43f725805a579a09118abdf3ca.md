# Anexo de instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                            |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | entrada   | dirección | primer color como cadena terminada en nulo           |
| `$a1`    | entrada   | dirección | segundo color como cadena terminada en nulo          |
| `$a2`    | entrada   | dirección | tercer color como cadena terminada en nulo (posiblemente vacía) |
| `$v0`    | salida    | entero  | valor de la resistencia                                |
| `$t0-9`  | temporal  | cualquiera | para almacenamiento temporal                        |
