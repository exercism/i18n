# Acerca de

[C++](https://en.wikipedia.org/wiki/C%2B%2B) (se pronuncia «ce más más») es un lenguaje de programación de propósito general desarrollado por [Bjarne Stroustrup](https://en.wikipedia.org/wiki/Bjarne_Stroustrup) a partir de 1979 en Bell Labs. Es inmensamente popular, sobre todo para aplicaciones que requieren velocidad y/o acceso a ciertas características de bajo nivel. Se considera un lenguaje de nivel intermedio, ya que encapsula características de lenguajes tanto de alto como de bajo nivel.

C++ admite la programación [procedimental](https://en.wikipedia.org/wiki/Procedural_programming), [orientada a objetos](https://en.wikipedia.org/wiki/Object-oriented_programming), [funcional](https://en.wikipedia.org/wiki/Functional_programming) y [genérica](https://en.wikipedia.org/wiki/Generic_programming). Hay compiladores de C++ para prácticamente cualquier plataforma, incluidas Windows, Mac OS y Linux.

Ventajas principales:
- **Seguridad de tipos:** encapsula las operaciones no seguras que sean necesarias
- **Seguridad de recursos:** no toda la gestión de recursos consiste en gestionar memoria
- **Rendimiento:** es importante para algunas partes de casi todos los sistemas
- **Previsibilidad:** para sistemas de tiempo real críticos y no críticos
- **Facilidad de enseñanza:** la complejidad del código debe ser proporcional a la complejidad de la tarea
- **Legibilidad:** para las personas y las máquinas («analizabilidad»)
- **Correspondencia directa con el hardware:** de las instrucciones y los tipos de datos fundamentales
- **Abstracción sin sobrecarga:** clases con constructores y destructores, herencia, programación genérica, técnicas de programación funcional

El estándar de C++ lo mantiene la Organización Internacional de Normalización (ISO), y la versión actual de C++ a fecha de junio de 2018 es C++17 (que no se llama así por ser la decimoséptima versión de C++, sino porque el estándar se ratificó en 2017).

Lo mejor de C++ es que funciona en todo, desde procesadores empotrados con recursos muy limitados hasta el mayor superordenador central y cualquier ordenador personal que haya en medio.
