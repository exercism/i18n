# Usa valores cero al devolver un error

Por convención, cuando se devuelve un valor `error`, no se usan los demás valores, y en esta situación se considera idiomático devolver el [valor cero](https://golang.org/ref/spec#The_zero_value).
El valor `error` hace que usar un valor inválido «fuera de banda» para señalar un error sea redundante en Go.
