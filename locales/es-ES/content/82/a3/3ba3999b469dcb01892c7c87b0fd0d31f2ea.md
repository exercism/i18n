# Clases inmutables

```sather
immutable class BEARING is
   readonly attr degrees : INT;
   create(d : INT) : SAME is
      b : SAME;
      return b.degrees(d);
   end;
end;
```

## Qué cambia

| | clase normal | clase inmutable |
| --- | --- | --- |
| asignación | comparte el objeto | copia el valor |
| puede ser void | sí | no |
| escritura de `attr` | `x.a := v` | `x := x.a(v)` |
| `new` | sí | no; `x : SAME` ya existe |

Un objeto inmutable no puede ser void, así que `void(b)` siempre es falso y ninguna rutina sobre él puede fallar por falta de un objeto. Eso elimina toda una clase de errores a cambio de no poder decir nunca «aún no hay ningún `BEARING`».

## Dónde vive el valor

El valor se almacena donde está la variable (dentro de otro objeto o en la pila), en lugar de alcanzarse a través de una referencia. Así, un `ARRAY{BEARING}` contiene los propios objetos `BEARING`, no punteros a ellos, lo que ocupa menos y es más rápido de recorrer.

El precio es la copia: pasar un objeto inmutable grande lo copia cada vez. Lo mejor es mantenerlos pequeños.

## Las rutinas de atributo

`readonly attr degrees : INT` proporciona dos rutinas:

```sather
   b.degrees          -- read: INT
   b.degrees(90)      -- answer a new BEARING with degrees changed
```

La segunda existe incluso con `readonly`, porque no cambia nada: construye un nuevo valor. Con un `attr` normal es pública; con `private attr` no lo es.

## is_eq y str

No se proporciona ninguno de los dos. Escribe `is_eq` para `=`, y `str` para que el objeto se pueda imprimir y unir a strings:

```sather
   is_eq(other : SAME) : BOOL is return degrees = other.degrees; end;
   str : STR is return degrees.str + " degrees"; end;
```

Escribir `str` hace que la clase conforme a `$STR`, que es lo que permite que `+` y `#OUT` lo acepten.

## Las integradas

`INT`, `BOOL`, `CHAR`, `FLTD` y `TUP` son todas clases inmutables. No tienen nada de especial: están escritas en Sather en la biblioteca de la misma manera, y se comportan como se comportan por las razones anteriores.
