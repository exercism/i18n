# Instrucciones

Como futura maga, Elyse necesita practicar algunos conceptos básicos. Tiene
un montón de cartas que quiere manipular.

Para que todo sea un poco más fácil, solo usa las cartas del 1 al 10, así que su
montón de cartas puede representarse con un array de números. La posición
de una carta concreta corresponde al índice dentro del array. Es decir, la
posición 0 se refiere a la primera carta, la posición 1 a la segunda
y así sucesivamente.

<!-- prettier-ignore-start -->
~~~~exercism/note
Todas las funciones menos dos deberían actualizar el array de cartas y luego devolver el array modificado, una forma de trabajar muy común conocida como el patrón Builder, que te permite encadenar funciones de forma muy elegante.

Las dos excepciones son `getItem`, que debería devolver la carta en la posición dada, y `checkSizeOfStack`, que debería devolver `true` si el tamaño dado coincide.
~~~~
<!-- prettier-ignore-end -->

## 1. Recupera una carta del montón

Para coger una carta, devuelve la carta que está en el índice `position` del
montón dado.

```javascript
const position = 2;
getItem([1, 2, 4, 1], position);
// => 4
```

## 2. Intercambia una carta del montón

Haz un poco de prestidigitación e intercambia la carta que está en el índice `position`
por la carta de reemplazo proporcionada.
Devuelve el montón ajustado.

```javascript
const position = 2;
const replacementCard = 6;
setItem([1, 2, 4, 1], position, replacementCard);
// => [1, 2, 6, 1]
```

## 3. Inserta una carta en la parte superior del montón

Haz aparecer una carta insertando una carta nueva en la parte superior del montón.
Devuelve el montón ajustado.

```javascript
const newCard = 8;
insertItemAtTop([5, 9, 7, 1], newCard);
// => [5, 9, 7, 1, 8]
```

## 4. Elimina una carta del montón

Haz desaparecer una carta eliminando del montón la carta que está en la `position` dada.
Devuelve el montón ajustado.

```javascript
const position = 2;
removeItem([3, 2, 6, 4, 8], position);
// => [3, 2, 4, 8]
```

## 5. Elimina la carta superior del montón

Haz desaparecer una carta eliminando la carta que está en la parte superior del montón.
Devuelve el montón ajustado.

```javascript
removeItemFromTop([3, 2, 6, 4, 8]);
// => [3, 2, 6, 4]
```

## 6. Inserta una carta en la parte inferior del montón

Haz aparecer una carta insertando una carta nueva en la parte inferior del montón.
Devuelve el montón ajustado.

```javascript
const newCard = 8;
insertItemAtBottom([5, 9, 7, 1], newCard);
// => [8, 5, 9, 7, 1]
```

## 7. Elimina una carta de la parte inferior del montón

Haz desaparecer una carta eliminando la carta que está en la parte inferior del montón.
Devuelve el montón ajustado.

```javascript
removeItemAtBottom([8, 5, 9, 7, 1]);
// => [5, 9, 7, 1]
```

## 8. Comprueba el tamaño del montón

Comprueba si el tamaño del montón es igual a `stackSize` o no.

```javascript
const stackSize = 4;
checkSizeOfStack([3, 2, 6, 4, 8], stackSize);
// => false
```
