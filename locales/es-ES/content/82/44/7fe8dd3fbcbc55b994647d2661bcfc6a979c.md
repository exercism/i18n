# Acerca de

Scala es un lenguaje de programación que escala contigo: desde pequeños scripts hasta grandes aplicaciones multiplataforma.

Scala combina la programación orientada a objetos y la programación funcional en un único lenguaje conciso y de alto nivel. Los tipos estáticos de Scala ayudan a evitar errores en aplicaciones complejas, y sus runtimes de JVM, JavaScript y Native te permiten crear sistemas de alto rendimiento con un acceso sencillo a enormes ecosistemas de bibliotecas.

* Funcionalidades
    * Interoperabilidad con la JVM: Scala se ejecuta en la JVM, así que los stacks de Java y Scala se pueden combinar para conseguir una integración total.
    * Interoperabilidad con JS y Native: Scala puede ejecutarse en el navegador y en dispositivos nativos, gracias a [Scala.js](https://www.scala-js.org/) y [Scala Native](https://github.com/scala-native/scala-native)
    * Inferencia de tipos: Scala tiene tipado estático. Sin embargo, ofrece inferencia de tipos para aligerar la carga de un sistema de tipos avanzado.
    * Orientado a objetos: Scala es un lenguaje puro orientado a objetos en el sentido de que todo valor es un objeto. Los tipos de datos y el comportamiento de los objetos se describen mediante clases y traits. Las abstracciones de clase se extienden mediante la creación de subclases y mediante un mecanismo flexible de composición basado en mixins que evita los problemas de la herencia múltiple.
    * Funcional: Scala es también un lenguaje funcional en el sentido de que toda función es un valor. Proporciona una sintaxis ligera para definir funciones anónimas, admite funciones de orden superior, permite anidar funciones y admite currying. Las case classes de Scala y su compatibilidad integrada con la coincidencia de patrones modelan los tipos algebraicos que se usan en muchos lenguajes de programación funcional. Los objetos singleton ofrecen una forma cómoda de agrupar funciones que no son miembros de una clase.
    * Concurrencia y distribución: usa operaciones paralelas sobre datos en las colecciones, usa actores para la concurrencia y la distribución, o futuros para la programación asíncrona.
