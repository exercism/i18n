## Formato

Aunque a Common Lisp no le importan la indentación ni la disposición del código, ni que uses espacios o tabuladores, es algo que conviene tener muy en cuenta al enviar soluciones a Exercism.
El widget de código de Exercism.org no gestiona bien la mezcla de tabuladores y espacios, por lo que se recomienda usar solo espacios para que el código resulte más legible para las personas que lo revisan.
Revisa la configuración de tu editor para ver cómo conseguirlo.
A continuación tienes instrucciones para editores populares de Common Lisp.

### VIM

Usa los siguientes comandos para asegurarte de que VIM use solo espacios para la indentación:

```vimscript
:set tabstop=2
:set shiftwidth=2
:set expandtab
```

(o en una sola línea, `:set tabstop=2 shiftwidth=2 expandtab`). Puedes añadirlo a tu archivo `~/.vimrc` para usarlo siempre.

### Emacs

Emacs es muy adecuado para editar Common Lisp y tiene muchos paquetes complementarios potentes disponibles. Lo único que hay que hacer con un Emacs de serie para que funcione bien con exercism.org es evaluar el siguiente código:

`(setq-default indent-tabs-mode nil)`

Puedes colocarlo en tu `~/.emacs` (o `~/.emacs.d/init.el`) para que se aplique cada vez que se inicie Emacs.

Un complemento recomendado para Emacs y Common Lisp es [SLIME][slime], que ofrece una integración estrecha con el REPL y hace que la programación y las pruebas iterativas sean muy sencillas.
