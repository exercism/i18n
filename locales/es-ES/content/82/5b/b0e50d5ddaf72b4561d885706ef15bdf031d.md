# Introducción

En C#, las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_. Un **array** es una colección que tiene un tamaño/longitud fijo y cuyos elementos deben ser todos del mismo tipo. Los elementos se pueden asignar a un array o recuperar de él mediante un índice. Los arrays de C# están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Los arrays también se pueden definir con una notación abreviada que te permite tanto crear el array como establecer su valor. Como el compilador ahora puede saber cuántos elementos tendrá el array, se puede omitir la longitud:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Los arrays se pueden manipular llamando a los métodos o las propiedades de una instancia de array, o usando los métodos estáticos definidos en la clase `Array`.
