# Instrucciones

Mika, la organizadora de eventos, ha ascendido en el trabajo y, como parte de sus nuevas responsabilidades, se encarga de la base de datos de eventos. Pronto se dio cuenta de que muchos datos se almacenan de formas que dificultan trabajar con ellos, así que formáis equipo para limpiarlos con un script de un solo uso.

Como el script solo se va a ejecutar una vez y estás seguro de la estructura de los datos, crees que este es un buen sitio para usar las _let assertions_ de Gleam.

## 1. Extraer los errores

Cada evento pasado tiene una lista de problemas que se produjeron durante el evento. Se han almacenado como resultados, pero siempre son la variante `Error`.

Implementa la función `extract_error`, que recibe un resultado del que se espera que siempre sea un `Error` y devuelve el valor de error que contiene.

```gleam
extract_error(Error("Not enough coffee"))
// -> "Not enough coffee"
```

## 2. Quitar el prefijo del equipo

Los nombres de los equipos llevan el prefijo "Team ", pero no es necesario. Implementa la función `remove_team_prefix` para quitar el prefijo del nombre del equipo.

```gleam
remove_team_prefix("Team Turtle")
// -> "Turtle"
```

## 3. Dividir la región y el equipo

Cada evento lo organiza un equipo, y cada equipo pertenece a una región. En la base de datos se guardan en un solo string, separados por una coma.

Implementa la función `split_region_and_team` para dividir el string en una tupla de dos strings, uno para la región y otro para el equipo. Se debe quitar el prefijo "Team " del nombre del equipo.

```gleam
split_region_and_team("East,Team Orange")
// -> #("East", "Orange")
```
