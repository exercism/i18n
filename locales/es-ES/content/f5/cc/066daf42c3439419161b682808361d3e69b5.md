# Cómo escribir el código

Escribe tu código en `<exercise_name>.zig`.
Algunos ejercicios vienen con firmas ya escritas para construcciones específicas de Zig, como [constantes][constants], [funciones][functions], [importaciones][imports], [estructuras][structs], ¡y [potencialmente muchas más][et-cetera]!

Estas firmas ya escritas están pensadas para ayudarte a completar los ejercicios, dándote un punto de partida claro.
Sin embargo, no es necesario partir de ellas.
Sobre todo porque cualquier código que pase los tests es una solución perfectamente válida.

## Ejecutar los tests

Para ejecutar los tests, lo único que tienes que hacer es ejecutar el siguiente comando:

```bash
zig test test_exercise_name.zig
```

sustituyendo `exercise_name` por el nombre del ejercicio.
El comando anterior hay que ejecutarlo desde el directorio raíz del ejercicio, ya que su archivo de tests debería estar en esa misma ubicación.
Además, todos los tests de cualquier ejercicio están habilitados por defecto, y ninguno de los tests se puede omitir.

Como todos los tests tienen estas condiciones, si quieres ir uno por uno tendrás que [comentar][comments] los tests que no pasen.
Comentar un test es tan sencillo como empezar cada línea con `//`.
De lo contrario, cuando tengas la seguridad de que tu solución puede pasar los tests, puedes volver a descomentarlos para ver si pasa.
