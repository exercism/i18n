# Clases genéricas

```sather
class LOST_BOX{T} is
   attr item : T;
   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;
end;
```

## Qué es el parámetro

`T` representa un tipo que se proporciona en el punto de uso. Cuando se compila el programa, Sather construye una clase distinta para cada combinación que se usa realmente. Así:

- `LOST_BOX{STR}` y `LOST_BOX{INT}` son tipos no relacionados;
- no hay comprobación en tiempo de ejecución, ni boxing, ni conversión;
- un error en la clase aparece por cada tipo con el que se usa.

Este es el mismo enfoque que las plantillas de C++ o los genéricos de Rust, y a diferencia de los genéricos de Java, donde el tipo se borra y todo es en realidad un objeto.

## Parámetros con restricciones

Una `T` sin restricciones se puede asignar, pasar y devolver, y nada más, porque no se sabe nada más sobre ella. Para llamar a rutinas sobre ella, hay que decir a qué debe ajustarse:

```sather
class LOST_BOX{T < $STR} is
   describe : STR is return "a box holding " + item.str; end;
end;
```

`T < $STR` exige que `T` se ajuste a `$STR` y, a cambio, permite llamar a `item.str`. Todo lo que una `T` sin restricciones no puede hacer se puede habilitar mediante una restricción.

Sin la restricción, `item.str` no compilará, y el mensaje señalará la línea dentro de la clase genérica, no la línea que la usó.

## ¿Rutinas genéricas?

No hay ninguna. Solo las clases aceptan parámetros. Una rutina que necesite operar sobre varios tipos o bien vive en una clase genérica, o bien acepta un tipo abstracto como `$STR`.

## Cómo elegir entre ellas

| | clase genérica | clase abstracta |
| --- | --- | --- |
| se decide | al compilar | al ejecutar |
| contiene | un tipo por instanciación | cualquier tipo que se ajuste |
| coste | ninguno | un despacho |

`ARRAY{$ACT}` usa las dos: genérica en el tipo de los elementos y abstracta en lo que ese elemento puede ser.

Recurre a una clase genérica cuando el tipo sea el mismo en todo momento y quien use la clase lo conozca. Recurre a una clase abstracta cuando varios tipos deban convivir en una misma colección.
