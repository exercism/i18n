# Anexo de instrucciones

## Implementación

Muchos de nuestros ejercicios de Pyret de nivel más básico se pueden resolver solo con [expresiones de aplicación de función][function application expressions] en la forma `foo(1)`.
Este ejercicio, sin embargo, espera que se puedan usar [expresiones de punto][dot expressions] para acceder a campos de datos y de métodos en lo que devuelve tu función.
Esto se puede hacer con [expresiones de objeto][object expressions], que te permiten acceder a los campos de un literal de objeto.
Las [declaraciones de datos][data declarations] son un enfoque similar pero más avanzado que también utiliza campos de datos y de métodos.

[function application expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3aapp-expr%29
[dot expressions]: https://pyret.org/docs/latest/Expressions.html#%28part._s~3adot-expr%29
[object expressions]: https://pyret.org/docs/latest/Expressions.html#%28elem._%28bnf-prod._%28.Pyret._obj-expr%29%29%29
[data declarations]: https://pyret.org/docs/latest/s_declarations.html#%28part._s~3adata-decl%29
