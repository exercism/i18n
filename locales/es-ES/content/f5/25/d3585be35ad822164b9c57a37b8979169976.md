# Instrucciones

En este ejercicio vas a implementar un programa que determina el estado de una partida de [tic-tac-toe][].
(_Quizá también conozcas el juego como «tres en raya»._)

El juego se juega en una cuadrícula de 3×3.
Los jugadores se turnan para colocar `X`s y `O`s en la cuadrícula.
El juego termina cuando un jugador gana al colocar tres marcas en fila, columna o diagonal de la cuadrícula, o cuando se completa toda la cuadrícula.

En este ejercicio, asumiremos que `X` empieza.

Tu trabajo es determinar en qué estado se encuentra una partida dada.

Hay 3 posibles estados de la partida:

- La partida está **ongoing**.
- La partida terminó en **draw**.
- La partida terminó en **win**.

Si el tablero dado no es válido, lanza un error adecuado.

Un tablero no es válido si cumple las siguientes condiciones:

- El tablero dado no puede alcanzarse cuando los turnos se toman en el orden correcto (recuerda que `X` empieza).
- Se siguió jugando después de que la partida ya había terminado.

## Ejemplos

### Partida en curso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### No válido

#### Orden de turnos incorrecto

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Se siguió jugando después de ganar

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
