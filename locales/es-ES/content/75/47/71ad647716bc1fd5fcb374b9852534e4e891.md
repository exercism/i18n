# Pruebas

Cada ejercicio proporciona las pruebas unitarias.
Tú aportas la implementación.
Cada fichero produce un ejecutable de consola que ejecuta las pruebas.
Al ejecutar el ejecutable de pruebas, se imprimen mensajes para cada prueba que falla y se notifica un código de salida distinto de cero cuando las pruebas fallan.

*Nota:* Tu código se somete a la suite de pruebas cada vez que compilas tu proyecto.
Si tu código no pasa una o varias pruebas pero es código D válido, se compilará de todos modos.

Trabajar en cada ejercicio es un proceso que consiste en:

* Ejecutar las pruebas con `dub test`
  * Si has decidido no instalar DUB, en su lugar usarías `dmd source/*.d -de -w -main -unittest` y después ejecutarías el binario resultante.
* Para cada prueba unitaria:
  * Resuelve los errores de compilación para que la prueba falle.
  * Implementa lo justo para que la prueba pase.
  * Refactoriza tu implementación para mejorar la legibilidad, reducir la duplicación, etc.
  * Habilita la siguiente prueba

*Nota:* D admite las pruebas unitarias directamente en el lenguaje, así que normalmente las pruebas unitarias se encuentran en el mismo fichero que la implementación.
Las pruebas unitarias se ejecutan antes del cuerpo de main y se habilitan en el ejecutable final usando la opción del compilador **-unittest**.

## Interpretar la salida de las pruebas unitarias

Si todas las pruebas se superan, la salida de las pruebas podría ser similar a esta

```none
$ dub test
             Generating test runner configuration 'dnd-character-test-library' for 'library' (library).
    Starting Performing "unittest" build using dmd for x86_64.
    Building dnd-character ~master: building configuration [dnd-character-test-library]
     Linking dnd-character-test-library
     Running dnd-character-test-library
1 modules passed unittests
```
