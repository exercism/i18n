# Introducción

`Option` es una enumeración que se utiliza para comprobar la validez de los valores devueltos por las funciones. Se define así:

```haxe
enum Option<T> {
  Some(v:T);
  None;
}
```

Forma parte del paquete `haxe.ds`:

```haxe
import haxe.ds.Option;

class Main {
  static public function main() {
    var result = trySomething();

    switch (result) {
      case None:
        trace("Nothing");
      case Some(s):
        trace("Got: " + s);
    }
  }

  static public function trySomething():Option<String> {
    if (Math.random() > 0.5) {
      return None;
    } else {
      return Some("Success");
    }
  }
}
```
