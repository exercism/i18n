# Instrucciones

Dados dos arrays `A` y `B`, determina si:

- El array `A` es equal al array `B`; o
- El array `A` contiene el array `B` (`A` es un superlist de `B`); o
- El array `A` está contenido en el array `B` (`A` es un sublist de `B`); o
- Ninguna de las anteriores es cierta, por lo que los arrays `A` y `B` son unequal

En concreto, el array `A` es equal al array `B` si ambos arrays tienen los mismos valores en el mismo orden.
El array `A` es un superlist de `B` si `A` contiene una subsecuencia de valores equal a `B`.
El array `A` es un sublist de `B` si `B` contiene una subsecuencia de valores equal a `A`.

Ejemplos:

- Si `A = []` y `B = []` (ambos arrays están vacíos), entonces `A` y `B` son equal
- Si `A = [1, 2, 3]` y `B = []`, entonces `A` es un superlist de `B`
- Si `A = []` y `B = [1, 2, 3]`, entonces `A` es un sublist de `B`
- Si `A = [1, 2, 3]` y `B = [1, 2, 3, 4, 5]`, entonces `A` es un sublist de `B`
- Si `A = [3, 4, 5]` y `B = [1, 2, 3, 4, 5]`, entonces `A` es un sublist de `B`
- Si `A = [3, 4]` y `B = [1, 2, 3, 4, 5]`, entonces `A` es un sublist de `B`
- Si `A = [1, 2, 3]` y `B = [1, 2, 3]`, entonces `A` y `B` son equal
- Si `A = [1, 2, 3, 4, 5]` y `B = [2, 3, 4]`, entonces `A` es un superlist de `B`
- Si `A = [1, 2, 4]` y `B = [1, 2, 3, 4, 5]`, entonces `A` y `B` son unequal
- Si `A = [1, 2, 3]` y `B = [1, 3, 2]`, entonces `A` y `B` son unequal
