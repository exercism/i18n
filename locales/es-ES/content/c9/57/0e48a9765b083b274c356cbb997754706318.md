# Instrucciones

El clásico ejercicio introductorio.
Solo tienes que decir «Hello, World!».

[«Hello, World!»][hello-world] es el primer programa tradicional para quienes se inician en la programación en un lenguaje o un entorno nuevos.

Los objetivos son sencillos:

- Modifica el código que te damos para que produzca el string «Hello, World!».
- Ejecuta la suite de pruebas y asegúrate de que pasa.
- Envía tu solución y compruébala en el sitio web.

Si todo va bien, ya podrás descargar tu primer ejercicio de verdad.

[hello-world]: https://en.wikipedia.org/wiki/%22Hello,_world!%22_program
