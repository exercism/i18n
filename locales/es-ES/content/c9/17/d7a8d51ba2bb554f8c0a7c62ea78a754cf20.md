# Listas

`LIST{T}` es una colección ordenada y ampliable, respaldada por un array que se sustituye por otro más grande cuando se llena.

```sather
   notes ::= #LIST{STR};
   notes.append("muddy boots");
   notes[0]                     -- "muddy boots"
   notes[0] := "clean boots";
   notes.size
   notes.is_empty
   notes.has("clean boots")
   notes.remove_index(0);
```

## ¿Array o lista?

| | `ARRAY{T}` | `LIST{T}` |
| --- | --- | --- |
| tamaño | fijo en el momento de crearlo | cambia |
| añadir | no | sí |
| eliminar | no | sí |
| indexación | `a[i]` | `l[i]` |
| sobrecarga | ninguna | un tamaño y espacio libre |

Usa un `ARRAY` cuando el tamaño se conoce y no va a cambiar: una fila de bailarines, una semana de recuentos. Usa una `LIST` cuando las cosas llegan o se van.

## In situ, no funcional

`append`, `remove_index` y `[i] :=` cambian la propia lista. No hace falta asignar nada de vuelta, y una lista que se pasa a una rutina no queda a salvo de ello.

Eso es lo contrario de `FMAP` y `FSET`, y merece la pena tener claro cuál tienes entre manos. La regla general: una `F` al principio del nombre significa funcional, y todo lo demás cambia in situ.

Para repartir una lista que nada pueda estropear, entrega una copia:

```sather
   return notes.copy;
```

## El coste de añadir

Añadir es barato de media. Cuando el array subyacente se llena, se toma uno nuevo del doble de tamaño y se copia todo, así que la mayoría de las veces añadir no cuesta casi nada y, de vez en cuando, cuesta una copia. A lo largo de muchos añadidos, eso da una media de un coste constante por cada uno, y por eso se duplica el tamaño en lugar de crecer de uno en uno.

`remove_index` no es barato: todo lo que hay después de la posición eliminada se desplaza una posición. Eliminar repetidamente desde el principio de una lista larga es lento de una forma que es fácil no notar.

## Rutinas útiles

| Llamada | Qué hace |
| --- | --- |
| `l.append(x)` | añade al final |
| `l.insert_before(i, x)` | añade en una posición |
| `l.remove_index(i)` | saca una posición |
| `l.has(x)` | ¿está dentro? |
| `l.copy` | una copia independiente |
| `l.str` | el contenido, entre llaves |
| `l.elt!`, `l.ind!` | recorre los valores o las posiciones |
