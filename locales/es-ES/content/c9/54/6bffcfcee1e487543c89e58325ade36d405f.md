# Instalación

Sigue las instrucciones para tu sistema en la página de instalación de [golang.org](http://golang.org/doc/install).

## Versión de Go

Este track usa Go 1.26.

Podrías usar una versión anterior de Go modificando el archivo `go.mod` de cada ejercicio y cambiando la línea `go 1.26`. Sin embargo, las pruebas usan funcionalidades introducidas en Go 1.22 y no funcionarán sin modificaciones con una versión anterior.
