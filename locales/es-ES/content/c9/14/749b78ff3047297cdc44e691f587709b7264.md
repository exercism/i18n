# Recursos de aprendizaje recomendados

¡Te damos la bienvenida al aprendizaje de ColdFusion (CFML)! CFML es un lenguaje de scripting dinámico y de tipado débil para la JVM. Tiene dos tipos de archivo distintos. Los archivos `.cfm` (ColdFusion markup) son puramente procedimentales y usan la sintaxis basada en etiquetas para generar HTML a partir de plantillas. Los usarías para las vistas si estás creando un sitio web:

**index.cfm**

```xml
<cfoutput>
	<html>
		<h1>Welcome to my site, #FirstName# #LastName#!
	</html>
</cfoutput>
```

El otro tipo de archivo es el `.cfc` (ColdFusion Component) y es como se declara una clase. Los componentes se usan para la lógica de negocio, los modelos y los controladores. Normalmente usan la sintaxis de script, que se lee de forma parecida a JavaScript.

**Car.cfc**

```js
component accessors=true {
	property name='make' type='string';
	property name='model' type='string';
	property name='year' type='number';

	function init() {
		return this;
	}
 
}
```
