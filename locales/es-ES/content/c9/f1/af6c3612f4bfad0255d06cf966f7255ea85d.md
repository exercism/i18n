# ¡Lanzamiento!

Para activar el track, basta con poner el interruptor `active` de `config.json` en `true`.
Al cabo de un rato, el track aparecerá en el [sitio web](https://exercism.org/tracks).

A partir de este momento, cualquier cambio que hagas en tu track se sincronizará automáticamente con el [sitio web](https://exercism.org/tracks).
