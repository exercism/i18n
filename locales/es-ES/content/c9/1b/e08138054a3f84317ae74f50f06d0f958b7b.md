# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
dotnet test
```

Para ejecutar las pruebas automáticamente cada vez que se modifique un archivo fuente, ejecuta el siguiente comando:

```bash
dotnet watch test
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen. De forma predeterminada, al ejecutar las pruebas solo se ejecuta una, la primera. Esto es intencionado, ya que te permite centrarte únicamente en hacer que esa prueba pase. Cuando lo consigas, puedes habilitar la siguiente prueba eliminando `Skip = "Remove this Skip property to run this test"` del atributo `[Fact]` o `[Theory]` de la prueba. ¡Cuando hayas habilitado todas las pruebas y tu implementación haga que todas pasen, habrás resuelto el ejercicio!

Para ayudarte a empezar, cada ejercicio incluye un archivo de implementación inicial. Puedes usar este archivo como punto de partida para construir tu solución. No dudes en eliminar o modificar este archivo si crees que es lo más adecuado.

## Usar paquetes

Deberías poder resolver la mayoría de los ejercicios sin usar paquetes externos. Sin embargo, en los ejercicios en los que sí quieras usar un paquete externo, puedes añadirlo a tu proyecto ejecutando el siguiente comando:

```bash
dotnet add package [package-name]
```
