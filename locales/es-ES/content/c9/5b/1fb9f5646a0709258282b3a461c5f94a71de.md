# Anexo a las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                      |
| -------- | --------- | ------- | ------------------------------------------------ |
| `$a0`    | entrada   | número entero | año que comprobar                          |
| `$v0`    | salida    | Boolean | la entrada es un año bisiesto (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal  | cualquiera | se usan para almacenamiento temporal          |
