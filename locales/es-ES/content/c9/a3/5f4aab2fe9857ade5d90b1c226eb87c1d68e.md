# Pistas

## 1. Comprueba si es posible la acción «Fast Attack»

- El operador lógico NOT (`!`) se puede colocar delante de una expresión para negar su valor.
- Echa un vistazo a [este artículo de MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Logical_Operators#Logical_NOT_!) sobre los operadores lógicos

## 2. Comprueba si es posible la acción «Spy»

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueba si pueden producirse «cortocircuitos».
- Para entender a fondo el mecanismo de izquierda a derecha, ¡echa un vistazo a [este artículo](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence)!

## 3. Comprueba si es posible la acción «Signal Prisoner»

- Los operadores lógicos, ordenados por precedencia (de mayor a menor): `!`, `&&`, `||`.
- Echa un vistazo a [este artículo de MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Operator_Precedence#Precedence_And_Associativity) sobre la precedencia de operadores

## 4. Comprueba si es posible la acción «Free Prisoner»

- `()` es el operador con mayor precedencia. Úsalo para agrupar expresiones lógicas.
