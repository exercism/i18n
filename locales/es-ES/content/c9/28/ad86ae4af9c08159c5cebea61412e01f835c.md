## Importar

Un módulo se carga normalmente con la palabra clave `use`.
Esto lo carga y llama a su método `import`, con lo que se importan los símbolos exportados.

Los símbolos del array `@EXPORT` del paquete se importan de forma predeterminada.
Los símbolos del array `@EXPORT_OK` del paquete deben importarse de forma explícita.

Antes de Perl `v5.37`, un módulo tenía que terminar en un valor verdadero (normalmente `1`) para indicar que se había cargado correctamente.
Esto ya no es necesario cuando se usa la funcionalidad [`module_true`][module_true].

## Exportar

Para que un símbolo se importe, primero hay que exportarlo.
El módulo [Exporter][Exporter] viene incluido con Perl y es una de las opciones más cómodas para exportar.

Definir el módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usar el módulo:
```perl
use Foo ('bar');

bar();
```

## Pragma

Un pragma es un módulo que influye en algún aspecto del comportamiento de Perl.

Los pragmas [`strict`][strict] y [`warnings`][warnings] se recomiendan habitualmente, para restringir construcciones inseguras y señalar posibles problemas, respectivamente.
El pragma `strict` se activa junto con `use v5.12` o una versión posterior.
El pragma `warnings` se activa junto con `use v5.35` o una versión posterior.

El pragma [`feature`][feature] te permite activar funcionalidades de Perl más recientes y experimentales.
Cuando a la palabra clave `use` se le indica una versión concreta de Perl, se activa el conjunto de funcionalidades correspondiente a esa versión.

## Módulos del núcleo

Además de [Exporter][Exporter], Perl tiene una gran variedad de [módulos del núcleo][perl-core-modules] disponibles para usar.
Algunos ejemplos útiles para los ejercicios que puedes encontrar aquí son [List::Util][List::Util], [Time::Piece][Time::Piece] y [Math::BigRat][Math::BigRat].

## CPAN

Además de los módulos del núcleo, [CPAN][metacpan] ofrece miles de módulos adicionales creados por la comunidad de Perl que puedes instalar.
El track de Perl usa un [cpanfile][test-runner-cpanfile] para instalar una selección de módulos que se pueden usar con el test runner de Perl de Exercism.
