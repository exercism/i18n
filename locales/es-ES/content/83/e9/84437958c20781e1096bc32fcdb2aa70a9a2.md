# Devolver en el caso de error

En Go, es habitual usar varios `return` y devolver desde una función lo antes posible. Normalmente, los casos límite y los casos de error se gestionan lo antes posible, dejando el camino feliz alineado con el borde izquierdo. Para ver una buena explicación de esta práctica, consulta [Alinea el camino feliz al borde izquierdo](https://medium.com/@matryer/line-of-sight-in-code-186dd7cdea88) o mira la charla que dio sobre este mismo tema.
