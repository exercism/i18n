# Apéndice de instrucciones

## Palabras

Define una tupla `school` para guardar el listado de estudiantes (cómo almacenes los estudiantes dentro de ella es cosa tuya) y, a continuación, implementa las palabras que aparecen abajo.

- `<school> ( -- school )`: construye una escuela vacía.
- `add-student ( school name grade -- ? )`: añade `name` a `grade`. Devuelve `t` si tiene éxito, o `f` si `name` ya se ha añadido (a este curso o a cualquier otro), en cuyo caso el listado se deja sin cambios.
- `roster ( school -- names )`: todos los estudiantes, ordenados por curso y, después, alfabéticamente por nombre.
- `grade ( school n -- names )`: los estudiantes del curso `n`, ordenados alfabéticamente por nombre.
