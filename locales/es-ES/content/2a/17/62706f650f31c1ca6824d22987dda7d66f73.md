# Introducción

## Charlists

Los charlists se crean mediante el sigilo `~c`.

```elixir
~c"hello"
```

~~~~exercism/note
Ten en cuenta que en versiones anteriores de Elixir, los charlists se representan como `'hello'` con comillas simples.
~~~~

Aunque se parecen mucho a los strings, estos dos tipos de datos son bastante diferentes entre sí. Un charlist es una lista de enteros. Los enteros representan los valores Unicode de un carácter dado, también conocidos como puntos de código.

```elixir
[65, 66, 67]
# => ~c"ABC"
```

Puedes anteponer `?` a un carácter para obtener su punto de código.

```elixir
?A
# => 65

[?:, ?)]
# => ~c":)"
```

Como los charlists son listas, puedes trabajar con ellos igual que con cualquier otra lista: mediante recursión y coincidencia de patrones.

```elixir
[first_letter | _] = ~c"cat"
first_letter
# => 99
```

Puedes concatenar dos listas con `++`.

```elixir
~c"hi" ++ ~c"!"
# => ~c"hi!"
```

Cuanto más larga sea la primera lista, más lenta será la concatenación, así que evita añadir elementos repetidamente a listas de longitud arbitraria.

## Case

`case` es una estructura de control de flujo que nos permite comparar un valor dado con muchos patrones. Las cláusulas de una expresión `case` se evalúan de arriba abajo, hasta que se encuentra una coincidencia.

```elixir
age = 15

case age do
  0 -> ~c"infant"
  age when age < 4 -> ~c"baby"
  age when age < 13 -> ~c"child"
  age when age < 18 -> ~c"teenager"
  _ -> ~c"adult"
end

# => ~c"teenager"
```
