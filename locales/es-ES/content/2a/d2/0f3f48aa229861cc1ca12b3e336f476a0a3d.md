# CLI (interfaz de línea de comandos)

Puedes ejecutar los tests abriendo una terminal en el directorio del ejercicio y ejecutando después el [comando `go test`][docs-go-test].
Como alternativa, la mayoría de los IDE tienen soporte integrado para ejecutar tests, incluidos [Visual Studio Code][docs-run-unit-tests-visual-studio-code] y [JetBrains GoLand][docs-run-unit-tests-goland].

Al principio, solo estará habilitado el primer test.
Esto es para animarte a resolver el ejercicio paso a paso.
Una vez que consigas que el primer test pase, quita la propiedad `Skip` del siguiente test y procura que ese test también pase.

Cuando ya no quede ningún test omitido y todos pasen, puedes enviar tu solución abriendo una terminal en el directorio del ejercicio y ejecutando el [comando `exercism submit`][docs-exercism-cli].

Para seguir leyendo, hay una introducción al [testing en Go][testing-in-go] que incluye cómo escribir tus propios tests.
