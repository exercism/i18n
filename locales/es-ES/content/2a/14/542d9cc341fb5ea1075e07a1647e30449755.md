# Introducción

Los números decimales son números con uno o más dígitos detrás del separador decimal. Usan el formato de coma flotante de doble precisión de 64 bits.

```elixir
float = 3.45
# => 3.45
```

## Trabajar con números

En los módulos [`Integer`][integer-functions] y [`Float`][float-functions] puedes encontrar algunas funciones útiles para trabajar con esos tipos. Los operadores aritméticos básicos están definidos en el módulo [`Kernel`][kernel-arithmetic-operators].

## Conversión

Los números enteros y los decimales se pueden mezclar en una misma expresión aritmética. Usar un número decimal en una expresión garantiza que el resultado también sea un número decimal.

```elixir
2 * 3
# => 6

2 * 3.0
# => 6.0
```

Sin embargo, al hacer una división, el resultado siempre será un número decimal, aunque solo se usen números enteros.

```elixir
6 / 2
# => 3.0
```

Para convertir un número decimal en un número entero, puedes descartar la parte decimal con [`trunc/1`][trunc-1].
