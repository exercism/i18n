# Pistas

## 1. Convertir una representación binaria a un número entero

- Existe un [método integrado][string-to_i] para convertir un string con una representación binaria en un número entero indicando la base.

## 2. Obtener el bit menos significativo de un número entero

- Existe un [método integrado][integer-bit] para obtener un bit de un número entero indicando un índice.
- El bit menos significativo es el bit que está más a la derecha.
  Se encuentra en el índice 0.

## 3. Obtener el valor hexadecimal de un canal de color

- Existe un [método integrado][integer-to_s] para convertir un número entero en un string con una representación hexadecimal indicando la base.
- El método puede aceptar un argumento opcional para especificar la precisión del número de dígitos generados.

## 4. Obtener el valor hexadecimal de RGB

- Puedes usar los métodos ya definidos para obtener el valor hexadecimal de un canal de color.
