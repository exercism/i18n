# Pruebas

Hay dos métodos distintos para preparar la ejecución de las pruebas con Objective-C:

- Crear un proyecto de Xcode con un destino de pruebas que ejecutará las pruebas.
- Usar la gema de Ruby `objc` como utilidad para ejecutar las pruebas.

Ambos se describen con más detalle aquí: https://exercism.org/tracks/objective-c/tests
