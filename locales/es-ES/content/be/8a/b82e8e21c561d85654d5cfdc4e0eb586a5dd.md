# Pistas

## General

- Revisa la referencia sobre la [conversión implícita de tipos][ref-type-juggling]
- Revisa la referencia sobre la conversión de tipos a [enteros][ref-type-cast-int] y [strings][ref-type-cast-string]
- Revisa la referencia sobre los [strings numéricos][ref-numeric-strings]

## 1. Calcula la suma de los números de la tragaperras

- Puedes usar [`implode`][ref-implode] para combinar los dígitos.
  `implode` convertirá implícitamente los dígitos del array en strings y devolverá un string.
- Para sumar los números, consulta el concepto de [operaciones aritméticas][ref-arithmetic-ops].
  Los operadores aritméticos convertirán implícitamente los strings en números enteros o decimales.

## 2. Determina si un número es un palíndromo

- Esta tarea se puede resolver comparando el número dado con su versión invertida.
  Para ello, primero tienes que invertir el número dado.
  Después, devuelve el resultado de comparar ambas versiones.
- Puedes usar [`strrev`][ref-strrev] para obtener el número invertido.
  `strrev` convertirá implícitamente el número en un string y devolverá un string.
- Por último, puedes [comparar][ref-comparison-ops] el número dado con el string invertido.
  Al escribir la condición para ello, usa la [comparación][ref-comparison-ops] que hace conversión implícita de tipos.
  PHP convertirá el string invertido en un número para esta comparación.
- El resultado de la comparación es un `bool`, que es el tipo que debes devolver.

## 3. Genera un mensaje de error para entradas de usuario no válidas

- Puedes usar [condicionales][ref-if-statement] para comprobar las distintas condiciones.
- Primero, debes cubrir el caso en que el valor no contenga ningún carácter.
- A continuación, aborda el caso en que la entrada no sea un número o `0`.
  Las reglas de conversión de tipos de los [operadores de comparación][ref-comparison-ops] juegan en tu contra en este caso.
  Hacen que PHP compare strings en algunos casos, y eso da resultados incorrectos.
  Usa la conversión explícita a `int` que aprendiste en la introducción.
  Entonces podrás confiar en los [operadores de comparación][ref-comparison-ops] para un número mayor que `0`.
