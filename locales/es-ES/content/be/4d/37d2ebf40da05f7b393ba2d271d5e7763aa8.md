# Instrucciones

En este ejercicio vas a trabajar con cuentas de ahorro. Cada año, el saldo de una cuenta de ahorro se actualiza según el tipo de interés. El tipo de interés que da el banco depende de la cantidad de dinero que haya en la cuenta (su saldo):

- 0,5% para un saldo no negativo inferior a `1000` dólares.
- 1,621% para un saldo positivo mayor o igual que `1000` dólares y menor que `5000` dólares.
- 2,475% para un saldo positivo mayor o igual que `5000` dólares.
- 3,213% para un saldo negativo (da lugar a un interés negativo).

Tienes tres tareas, y cada una de ellas trata con el saldo y su tipo de interés.

## 1. Calcula el tipo de interés

Implementa el método `SavingsAccount.interest_rate` para calcular el tipo de interés a partir del saldo especificado:

```ruby
SavingsAccount.interest_rate(200.75)
#=> 0.5
```

Ten en cuenta que el valor devuelto es una instancia de `Float`.

## 2. Calcula la actualización anual del saldo

Implementa el método `SavingsAccount.annual_balance_update` para calcular la actualización anual del saldo, teniendo en cuenta el tipo de interés:

```ruby
SavingsAccount.annual_balance_update(200.75)
#=> 201.75375
```

Ten en cuenta que el valor devuelto es una instancia de `Float`.

## 3. Calcula los años que faltan para alcanzar el saldo deseado

Implementa el método `SavingsAccount.years_before_desired_balance` para calcular el número mínimo de años necesarios para alcanzar el saldo deseado:

```ruby
SavingsAccount.years_before_desired_balance(200.75, 214.88)
#=> 14
```

Ten en cuenta que el valor devuelto es una instancia de `Integer`.
