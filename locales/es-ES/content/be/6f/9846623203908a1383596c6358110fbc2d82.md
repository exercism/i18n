# usa la interpolación de strings

Usa la [interpolación de strings](https://docs.scala-lang.org/overviews/core/string-interpolation.html) para construir un string de forma dinámica, en lugar de usar la concatenación de strings o `StringBuilder`.

La principal ventaja es que el código con interpolación de strings suele ser más fácil de leer que la concatenación de strings o `StringBuilder`.
