# Instalación

Cairo se puede instalar simplemente descargando Scarb. Scarb incluye el compilador de Cairo y el servidor de lenguaje de Cairo en un único paquete fácil de instalar, para que puedas empezar a escribir código Cairo de inmediato. Scarb es también el gestor de paquetes de Cairo.

Para obtener las instrucciones de instalación recomendadas para tu plataforma, dirígete a [la web oficial de Cairo](https://www.cairo-lang.org/tutorials/getting-started-with-cairo/).

Por sistema operativo:

- Linux/MacOS
    1. Instala [asdf](https://asdf-vm.com/guide/getting-started.html)
    2. Instala [scarb](https://docs.swmansion.com/scarb/download#install-via-asdf)
    3. Verifica la instalación en una nueva sesión de terminal `scarb --version`
- Windows
    1. Instala [scarb](https://docs.swmansion.com/scarb/download#windows)
    2. Verifica la instalación en una nueva sesión de terminal `scarb --version`

Tener instalada la cadena de herramientas no lo es todo. La compatibilidad con el IDE es un enorme impulso para la productividad que la mayoría de los desarrolladores ya da por hecho.
Si usas Visual Studio Code, te recomendamos instalar la [extensión de Cairo](https://marketplace.visualstudio.com/items?itemName=starkware.cairo1), que ofrece resaltado de sintaxis, autocompletado de código y otras funcionalidades útiles.
