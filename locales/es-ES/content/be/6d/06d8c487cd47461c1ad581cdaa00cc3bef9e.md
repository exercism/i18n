# https://www.php.net/manual/en/language.basic-syntax.phptags.php"Operador de resolución de scope

El operador de resolución de scope (`::`) nos permite hacer referencia a una clase para acceder a sus constantes, propiedades estáticas o métodos estáticos.

```php
class MyClass
{
  public const MY_VALUE = 1;
}

// MyClass::class => "MyClass"
// MyClass::MY_VALUE => 1
```

## Uso de `self` y `static` con el operador de resolución de scope

Puede que sea necesario que un objeto haga referencia a su propio scope. Para facilitarlo, la palabra clave `self` permite que una clase haga referencia a su propio scope. Usar la palabra clave `self` desacopla la clase de su propio nombre, lo que facilita el mantenimiento del código con el tiempo.

```php
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return self::MY_VALUE;
  }
}

// (new MyClass)->getMyValue() => 1
```

Sin embargo, `self` está vinculado lexicográficamente a la clase en la que aparece.

```php
class MyOtherClass extends MyClass
{
  public const MY_VALUE = 99;
}

// (new MyOtherClass)->getMyValue() => 1
```

Evaluar `MyOtherClass::getMyValue` sigue dando `1` en lugar de `99`. Para solucionar esto, usa la palabra clave `static` junto con el operador de resolución de scope para hacer un «enlace tardío» de la referencia a la clase descendiente actual.

```php
// Update MyClass:
class MyClass
{
  public const MY_VALUE = 1;

  public function getMyValue(): int
  {
    return static::MY_VALUE;
  }
}
```

## Uso de `parent` con el operador de resolución de scope

Puede que sea necesario hacer referencia de forma específica a una constante, una propiedad o un método disponibles desde el scope de la clase padre:

```php
class MyClass
{
  public function getMaximum(): int
  {
    return 5;
  }
}

class AnotherClass extends MyClass
{
  public function getMaximum(): int
  {
    return parent::getMaximum() * 2;
  }
}

// (new AnotherClass())->getMaximum() => 10
```

Lo más habitual en la programación orientada a objetos es usar `parent` para llamar al constructor de la clase padre cuando se instancia un objeto:

```php
class ChildClass extends ParentClass
{
  public function __construct(): void
  {
    parent::__construct();
  }
}
```

## Advertencias

### Visibilidad de constantes, propiedades y métodos

El operador de resolución de scope sigue las reglas establecidas por los modificadores de visibilidad `public`, `private` y `protected`.
