# Acerca de

Una `List` es muy similar a un [`Array`][array]. Sin embargo, hay diferencias importantes que no querrás perderte:

1. Una List no se puede indexar con corchetes, es decir, `[0]`.
2. Una List no se puede inicializar.
3. No existen las comprensiones de listas.
4. Una List puede modificar sus elementos libremente mientras se itera sobre ella.

`List` es un miembro del paquete `haxe.ds`, así que cada vez que quieras usar listas tendrás que importar su paquete:

```haxe
import haxe.ds.List;

class Main {
  static function main() {
    var myList = List<Int>();

    for (i in 0...5) {
      myList.add(i);
    }

    trace(myList); // {0, 1, 2, 3, 4}
  }
}
```

[array]: https://haxe.org/manual/std-Array.html
