# Acerca de

Disponibles a partir de `PHP 8.0.0`, las **declaraciones de tipos de unión** aceptan valores de varios tipos diferentes, en lugar de un solo tipo. Las definiciones de tipos de unión se hacen usando la barra vertical (`|`) para separar los tipos.

```php
function add(int|float $a, int|float $b): int|float
{
    return $a + $b;
}
```

## Matices

- Los tipos `null` pueden declararse como _anulables_ ya sea usando `?Type` o `Type1|Type2|null`.
- Declarar tipos duplicados o redundantes dará como resultado un error en tiempo de compilación.
- `void` no puede usarse como parte de una declaración de tipos de unión.
