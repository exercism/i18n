# Instrucciones

Estás cantando las señales para la producción de tu escuela. El director de escena quiere que las líneas estándar estén escritas para que cualquiera pueda llevar el control.

Tienes cuatro tareas, todas en la clase `STAGE_DIRECTIONS`.

## 1. Anuncia el comienzo

Devuelve la línea que abre el espectáculo.

```sather
STAGE_DIRECTIONS::opening_line
-- => "The curtain rises."
```

## 2. Anuncia el intermedio

Devuelve la línea que se canta en el descanso.

```sather
STAGE_DIRECTIONS::interval_line
-- => "Interval. Fifteen minutes."
```

## 3. Anuncia el final

Devuelve la línea que cierra el espectáculo.

```sather
STAGE_DIRECTIONS::closing_line
-- => "The curtain falls."
```

## 4. Canta la señal final

La señal final es la misma línea que cierra el espectáculo. En lugar de escribir el texto una segunda vez, llama a la rutina que ya has escrito.

```sather
STAGE_DIRECTIONS::final_cue
-- => "The curtain falls."
```
