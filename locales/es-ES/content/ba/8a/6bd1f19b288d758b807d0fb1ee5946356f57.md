# Instalación

Exercism te permite programar y probar tu código ABAP directamente en el navegador. No hace falta instalar nada más. Sin embargo, si prefieres programar y probar en tu propio sistema, puedes conseguir un sistema de prueba de ABAP.

Por supuesto, es posible que tu empresa ya utilice SAP. Consulta con tu departamento de TI si puedes acceder a un entorno de desarrollo de ABAP y cómo hacerlo.

## ¿Qué versión elegir?

Te recomendamos usar una versión actual de la plataforma ABAP con soporte activo. Actualmente es **ABAP 7.5 y posteriores**. Puedes encontrar más información sobre las versiones actuales y sus calendarios en [SAP Developer Center](hhttps://developers.sap.com/tutorials/mission-get-started-with-abap-development-on-premise).

## ¿Qué instalar?

Te recomendamos usar la versión más reciente de [ABAP Cloud Developer Trial](https://hub.docker.com/r/sapse/abap-cloud-developer-trial). Está basada en ABAP 7.58. Puedes instalar el sistema SAP ABAP como imagen de Docker o alojado en la SAP Cloud Appliance Library. Además, necesitas instalar SAP GUI, para Windows o para Java, según tu sistema operativo. Puedes descargar SAP GUI desde [aquí](https://www.sap.com/products/try-sap/trials-downloads.html?search=sap+gui).

Para más información, consulta esta entrada del blog de [SAP Community](https://community.sap.com/t5/technology-blog-posts-by-sap/abap-cloud-developer-trial-2023-available-now/ba-p/14057183).
