# Ejecutar los tests

Para ejecutar el test de un ejercicio concreto, entra en la carpeta con `cd` y ejecuta lo siguiente:

```bash 
box task run TestRunner
# Or start up a test watcher that will rerun when files change
box task run TestRunner --:watcher
```

Los tests usan una biblioteca llamada TestBox, que admite el estilo xUnit y el estilo BDD de pruebas. Todos los conjuntos de tests se escriben en el [estilo BDD](https://testbox.ortusbooks.com/content/primers/bdd/specs.html), que usa closures para definir las especificaciones de test. No tendrás que preocuparte por instalar TestBox. El ejecutor de tests de la CLI se encargará de eso por ti. Solo tienes que estar conectado a internet la primera vez que lo ejecutes. Puedes leer más sobre esto aquí:

[https://testbox.ortusbooks.com](https://testbox.ortusbooks.com)
