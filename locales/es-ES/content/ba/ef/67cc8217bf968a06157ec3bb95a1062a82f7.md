# Pistas

## 1. Crear una lista nueva

- Common Lisp tiene una [función con un nombre bastante descriptivo][hyper-list] para crear una _LIST_.

## 2. Añadir cosas a la lista.

- Para añadir algo al principio de una lista, lo idiomático es *CONS*truir una lista nueva con el elemento como `car` y la lista como `cdr`. En el Hyperspec puedes encontrar una [página][hyper-cons] que describe esta función.

## 3. ¿Qué hay a continuación en la lista?

- Common Lisp tiene una función de propósito general para obtener un elemento [de cualquier índice de una lista][hyper-nth].
- También tiene [varias funciones auxiliares][hyper-first-tenth] para acceder a índices inferiores a 11
- Los índices de las listas empiezan en cero.

## 4. Quitar algo de la lista

- Una forma idiomática de quitar el primer elemento de una lista es usar una función que puede separar el `cdr` de la lista del `car` de la lista. En el Hyperspec puedes encontrar una [página][hyper-rest] que describe una de las funciones para hacer esto.

## 5. Listas más grandes a partir de listas más pequeñas

- Common Lisp tiene una función [específicamente para añadir una lista al principio de otra][hyper-append]

## 6. ¿Cuánto mide?

- Common Lisp tiene una función [de nombre obvio][hyper-length] para obtener la longitud de una lista.
