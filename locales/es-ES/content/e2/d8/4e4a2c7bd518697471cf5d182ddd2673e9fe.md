# Anexo a las instrucciones

## Formato de salida

Cada nacionalidad se especifica con una sola letra. (`E` = `Englishman`, `J` = `Japanese`, `N` = `Norwegian`, `S` = `Spaniard`, `U` = `Ukrainian`)

## Registros

| Registro | Uso      | Tipo       | Descripción                  |
| -------- | --------- | ------- | ---------------------------- |
| `$v0`    | salida    | byte    | nacionalidad del bebedor de agua |
| `$v1`    | salida    | byte    | nacionalidad del dueño de la cebra |
| `$t0-9`  | temporal | cualquiera | para almacenamiento temporal |
