# Instrucciones

En este ejercicio eres un gran aficionado al deporte y acabas de descubrir tu pasión por el baloncesto de la NBA.
Como eres nuevo en el baloncesto de la NBA, te estás sumergiendo a fondo en la historia de la NBA, haciendo un seguimiento de los equipos, los entrenadores y sus estadísticas de victorias y derrotas, y comparándolos entre sí.

Como todavía no tienes un equipo favorito, también vas a desarrollar un algoritmo para averiguar si merece la pena animar a un equipo en concreto.
Tienes siete tareas que te ayudarán a desarrollar tu propio algoritmo _anima a un equipo_.

## 1. Define el modelo

Define el alias de tipo `Coach` para un registro con los dos campos siguientes, en este orden:

- `name`: el nombre del entrenador, de tipo `String`.
- `formerPlayer`: indica si el entrenador fue jugador anteriormente, de tipo `Bool`.

Define el alias de tipo `Stats` para un registro con los dos campos siguientes, en este orden:

- `wins`: el número de victorias, de tipo `Int`.
- `losses`: el número de derrotas, de tipo `Int`.

Define el alias de tipo `Team` para un registro con los tres campos siguientes, en este orden:

- `name`: el nombre del equipo, de tipo `String`.
- `coach`: el entrenador del equipo, de tipo `Coach`.
- `stats`: las estadísticas del equipo, de tipo `Stats`.

## 2. Crea un equipo

Quieres comunicarte con código de terceros que tiene el concepto de equipo, pero que llama a tu código con los parámetros en un orden diferente. Añade una función `createTeam` con la siguiente firma `String -> Stats -> Coach -> Team`.

## 3. Sustituye al entrenador

Como los propietarios de la NBA son impacientes, has descubierto que los malos resultados del equipo a menudo llevaban a que se sustituyera al entrenador.
Implementa la función `replaceCoach`, que toma el nuevo entrenador y el equipo como parámetros y devuelve el equipo, pero con el nuevo entrenador:

```elm
let
    coach = { name = "Larry Bird", formerPlayer = True }
    stats = { wins = 58, losses =  24 }
    team = { name = "Indiana Pacers", coach = coach, stats =  stats }
    newCoach = { name = "Isiah Thomas", formerPlayer = True }
in
replaceCoach newCoach team
--> { name = "Indiana Pacers"
--  , coach = { name = "Isiah Thomas", formerPlayer = True }
--  , stats = { wins = 58, losses = 24 } }
```

## 4. Comprueba si deberías animar a un equipo

En el futuro tienes pensado idear un algoritmo complicado para decidir si merece la pena animar a un equipo o no, pero para este primer intento has decidido que deberías animar a cualquier equipo que tenga más victorias que derrotas.

Quieres que esta función sea reutilizable en otros contextos, así que usa un registro extensible en la firma del tipo para aceptar cualquier registro que tenga los campos relevantes.
Para que la función sea lo más concisa posible, quieres usar la coincidencia de patrones para obtener `stats` del parámetro de la función.
Implementa la función `rootForTeam`, que toma un equipo y devuelve `True` si deberías animar a ese equipo; en caso contrario, devuelve `False`.

```elm
let
    spursCoach = { name = "Gregg Popovich", formerPlayer =  False }
    spursStats = { wins = 56, losses = 26 }
    spursTeam = { name = "San Antonio Spurs", coach = spursCoach, stats = spursStats }
in
rootForTeam spursTeam
--> True
```
