# Pistas

## General

- Los slices de Go están indexados desde cero.
  El primer índice de un slice es `0`.
- La función incorporada [`append`][append-builtin] es [`variadic`][variadic-gobyexample].
- Puedes añadir los elementos de un slice a otro slice usando la notación de los tres puntos:

```go
a := []int{1, 3}
b := []int{4, 2, 6}
c := append(a, b...)
fmt.Println(c)
// Output: [1 3 4 2 6]
```

## 1. Crea un slice con ciertas cartas

- Para crear un slice ya relleno con algunos datos, usa la notación de literal de slice: `s := []T{x1, x2, ..., xn}`.

## 2. Obtén una carta de una pila

- Para obtener el elemento número `n` de un slice, [usa un índice][go-slices].
- Para comprobar si un elemento existe en un slice, usa un condicional y compara el índice con la [longitud del slice][len-builtin].

## 3. Intercambia una carta de la pila

- Para establecer el elemento número `n` de un slice, [usa un índice][go-slices] y asígnale un valor nuevo.
- Para añadir un elemento nuevo al final de un slice, usa la función `append`.

## 4. Añade cartas a la parte superior de la pila

- Para añadir elementos al principio de un slice, puedes añadir los elementos del slice original al slice del argumento `value`.

## 5. Quita una carta de la pila

- Para quitar un elemento de un slice, puedes añadir la parte que hay después de `index` a la parte que hay antes de index.
