# Pistas

## General

- Un [valor entero][integers] se puede definir como uno o más dígitos consecutivos.
- Si ves un error `panic:` al ejecutar los tests, es porque no has implementado una de las funciones (debería indicar cuál) o porque has dejado la plantilla tal cual. Tienes que eliminar la línea `panic(...)` del código proporcionado y sustituirla por una implementación real.

## 1. Define el tiempo de horno esperado en minutos

- Tienes que definir una [constante][constants] y asignarle el tiempo de horno esperado en minutos.
- Si ves un error `undefined: OvenTime`, comprueba que tienes la constante definida.
- Si ves un error `invalid operation: got != tc.expected (mismatched types float64 and int)`, es probable que hayas puesto un punto decimal en `OvenTime`, lo que hace que Go infiera el tipo como número de coma flotante. Elimina el punto decimal y el tipo se inferirá como `int`.
- Si ves un error `syntax error: non-declaration statement outside function body`, es probable que te hayas olvidado de la palabra clave `const`.
- Si ves un error `syntax error: unexpected :=, expecting =`, es probable que estés intentando asignar la constante con `:=` como si fuera una variable; las constantes se asignan con `=`, no con `:=`.

## 2. Calcula el tiempo de horno restante en minutos

- Tienes que definir una [función][functions] con un solo parámetro.
- Tienes que [devolver explícitamente un número entero][return] desde una función.
- El parámetro de la función es un [número entero][integers].
- Puedes [llamar][calls] a una de las otras funciones que has definido antes.
- Puedes usar el [operador matemático de resta][operators] para restar valores.
