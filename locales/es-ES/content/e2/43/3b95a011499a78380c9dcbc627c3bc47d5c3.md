# Nil

Crystal tiene un tipo llamado [`Nil`][nil], que solo puede tener un valor: `nil`.
Se usa para representar la ausencia de un valor y es similar a `null` o `None` en otros lenguajes.

Los valores `Nil` pueden ser devueltos por varios métodos, por ejemplo [`String#[]?`][string-index], que devuelve `nil` si el índice está fuera de los límites.

```crystal
"foo"[10]? # => nil
```

Crystal tiene lo que se conoce como **COMPROBACIONES DE REFERENCIAS NULAS**, lo que significa que, por defecto, ningún tipo admite `nil`.
Esto quiere decir que no puedes asignar `nil` a una variable a menos que la declares explícitamente como de tipo `Nil`.
A su vez, esto significa que el compilador comprobará automáticamente si hay referencias nulas.

## Valor falso

Se pueden seguir varias estrategias para tratar los valores `nil`.
`nil` es un valor [falso][truthy-falsey], al igual que `false`.
Esto significa que, en las instrucciones y en otros lugares donde se espera un valor verdadero o falso, se tratará igual que `false`.

```crystal
if nil
  puts "nil is truthy"
else
  puts "nil is falsey"
end

# => nil is falsey
```

Esto significa que no se tomará la rama verdadera si una variable que admite `nil` tiene el valor `nil`.

```crystal
foo = "boo"[2]? # It is possible that foo is nil
if foo
  p foo.class # => Char
end
```

## Comprobar si es `nil`

Crystal tiene un método que se puede usar para comprobar si un valor es `nil`.
Se llama [`nil?`][nil?] y está disponible en todos los objetos.

```crystal
foo = "boo"[2]?
if foo.nil?
  puts "foo is nil"
else
  puts "foo is not nil"
end
```

Esto es un poco distinto cuando se usa el valor directamente en un condicional, ya que en los ejemplos anteriores tanto `false` como `nil` se trataban como falsos.
Aquí solo `nil` se trata como falso, porque si hubiera sido `false` no habría sido `nil` y, por tanto, habría sido verdadero.

## El operador o

La forma más sencilla de tratar con valores `nil` es asegurarse de que nunca lleguen a ser `nil`.
El operador o ([`||`][or]) se usa a menudo cuando se trabaja con `Bools`, pero, si se entiende bien, también se puede usar para tratar con valores `nil`.
El operador o comprueba si el primer valor es verdadero; si no lo es, se usa el segundo valor.
Esto se puede usar para conseguir que, si el valor es `nil`, sea falso y, por tanto, se use el segundo valor.

```crystal
"foo"[10]? || "bar" # => "bar"
```
