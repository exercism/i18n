# Anexo a las instrucciones

## Palabras

Define una tupla `cmplx` con los slots `real` e `imaginary`. Los accesores de slot `real>>` e `imaginary>>` vienen incluidos con la definición de la tupla y son los que usan los tests para leer los componentes.

- `<cmplx> ( real imag -- cmplx )`: construye un número complejo.
- `>cmplx ( pair -- cmplx )`: construye un `cmplx` a partir de
  `{ real imaginary }`.
- `cmplx>pair ( cmplx -- pair )`: devuelve `{ real imaginary }`.
- `c+ ( a b -- c )`, `c- ( a b -- c )`, `c* ( a b -- c )`,
  `c/ ( a b -- c )`: operaciones aritméticas entre dos números complejos.
- `c-abs ( a -- |a| )`: valor absoluto (un número real).
- `c-conj ( a -- a* )`: conjugado complejo.
- `c-exp ( z -- e^z )`: exponencial complejo.

Las palabras genéricas `MATH:` de Factor (`+`, `-`, `*`, `/`) solo despachan sobre
la jerarquía matemática integrada, así que este ejercicio usa nombres de palabra
propios en lugar de métodos sobre esas genéricas.

Se excluyen los tests de aritmética que mezcla números reales con números
complejos: todas las operaciones que hay aquí se realizan entre dos valores
`cmplx`.
