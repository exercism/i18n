# Introducción

Las [estructuras][structs-and-classes] (conocidas habitualmente como *structs*) son uno de los bloques fundamentales de los programas en Swift.
Los structs te permiten crear tipos personalizados que agrupan propiedades (datos) y métodos (comportamiento) relacionados entre sí.
De hecho, los tipos estándar de Swift, como `Int`, `Double`, `Bool`, `String`, `Array` y `Dictionary`, están implementados como structs.

## Definir structs

Define un struct con la palabra clave `struct`, seguida del nombre del tipo y de unas llaves que contienen su definición.
Por convención de Swift, los nombres de los structs usan `UpperCamelCase`:

```swift
struct CharacterStats {
    var health = 0.0
    var speed = 0
    var strength = 0
}
```

## Crear instancias

La definición de un struct es un plano.
Para crear una *instancia* de un struct, llama a su inicializador escribiendo el nombre del tipo seguido de un par de paréntesis:

```swift
var someStats = CharacterStats()
```

Esto crea una instancia con los valores predeterminados que tienen las propiedades en la definición.

Además, Swift genera automáticamente un **inicializador por miembros** para los structs, que te permite inicializar las propiedades por su nombre:

```swift
let customStats = CharacterStats(health: 100.0, speed: 6, strength: 18)
```

## Acceder a las propiedades y modificarlas

Accedes a las propiedades de una instancia y las modificas con la *notación de punto*:

```swift
var stats = CharacterStats()

print(stats.health) // Prints 0.0

stats.health = 87.3
print(stats.health) // Prints 87.3
```

Como los structs son tipos de valor, para modificar las propiedades de una instancia es necesario que la propia instancia se declare con `var`.
Si la instancia se declara con `let`, todas sus propiedades se vuelven inmutables.
