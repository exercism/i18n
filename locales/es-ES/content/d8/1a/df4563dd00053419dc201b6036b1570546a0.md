# Introducción

Common Lisp ofrece varias expresiones condicionales diferentes, y la principal diferencia entre ellas es el número de ramas que admiten.

- `when` y `unless` permiten una sola rama:

```lisp
(when (= 2 2) "All is well")      ; => "All is well"
(unless (= 2 2) "Time to panic!") ; => NIL
```

La sección que sigue a la expresión de prueba puede contener más de una expresión.

- `if` proporciona la clásica construcción if-then-else:

```lisp
(if (= 2 2) 'how-honest 'you-liar) ; => HOW-HONEST
```

Ten en cuenta que tanto la cláusula then como la else solo pueden contener una única expresión.

- `cond` permite tener varias ramas sin anidar expresiones `if`:

```lisp
(cond ((= 0 2) 'nope)
      ((= 1 2) 'try-again)
      ((= 2 2) 'quite-true)
      ((= 3 2) 'too-far)
      (t 'something-else))
; => QUITE-TRUE
```

Ten en cuenta que no hay límite en el número de expresiones que siguen a la expresión de prueba.

- `case` proporciona una construcción clásica al estilo «switch»: compara un único valor con varias ramas:

```lisp
(case 'elder-beast
  (cat "Meow")
  (bird "Chirp")
  (dog "Bark")
  (otherwise "???"))
; => "???"
```

Ten en cuenta que, igual que con `cond`, no hay límite en el número de expresiones que siguen a la expresión de prueba.
