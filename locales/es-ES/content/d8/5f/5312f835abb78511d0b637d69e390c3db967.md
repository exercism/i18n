# Encabezado de nivel superior ficticio

## Números en Euphoria

En Euphoria, un `atom` puede contener cualquier tipo de número, con el subtipo `integer` pensado para números enteros.
Es posible resolver este ejercicio en lenguajes tipo C devolviendo un entero de 64 bits sin signo.

Sin embargo, los enteros en Euphoria tienen signo y _son un bit más pequeños que la palabra de la máquina_, por lo que son demasiado pequeños para este ejercicio, mientras que los átomos pueden contener enteros más grandes con los 64 bits de precisión necesarios.

### 32 bits

Existe una versión de 32 bits de Euphoria, que sigue existiendo para que las aplicaciones heredadas puedan seguir usando dll/so de 32 bits precompilados cuando no hay disponible una versión de 64 bits, o cuando el wrapper de estos está lleno de desplazamientos de 32 bits codificados directamente.
Esta versión es totalmente inadecuada para resolver esta tarea, ya que esos átomos solo tienen 53 bits de precisión.
Si tienes problemas para resolver este ejercicio en local, asegúrate de que estás usando una versión de 64 bits de Euphoria.
