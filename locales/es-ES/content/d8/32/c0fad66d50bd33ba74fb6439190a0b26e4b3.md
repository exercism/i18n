# Instrucciones

En este ejercicio juegas a un juego de rol en el que distintos tipos de luchadores pueden combatir entre sí.
El juego tiene reglas distintas para cada tipo de luchador.
Nos vamos a centrar en dos tipos concretos: los magos y los guerreros.

Para un guerrero, estas son las reglas:

- Un guerrero nunca es vulnerable.
- Un guerrero inflige `6` puntos de daño si el luchador al que ataca no es vulnerable.
- Un guerrero inflige `10` puntos de daño si el luchador al que ataca es vulnerable.

Para un mago, estas son las reglas:

- Un mago puede preparar un hechizo con antelación.
- Un mago es vulnerable a menos que haya preparado un hechizo con antelación.
- Un mago inflige `12` puntos de daño si ha preparado un hechizo con antelación.
- Un mago inflige `3` puntos de daño si no ha preparado un hechizo con antelación.

## 1. Crea la clase Warrior

Crea una nueva clase llamada `Warrior`.
Esta clase debe heredar de la clase `Fighter` existente.

## 2. Describe a un guerrero

Actualiza la clase `Warrior` para que su método `toString()` describa qué tipo de luchador es.
El método debe devolver el string `"Fighter is a Warrior"`.

```java
Warrior warrior = new Warrior();
warrior.toString();
// => "Fighter is a Warrior"
```

## 3. Haz que los guerreros sean invulnerables

Actualiza la clase `Warrior` para que su método `isVulnerable()` devuelva siempre `false`.

```java
Warrior warrior = new Warrior();
warrior.isVulnerable();
// => false
```

## 4. Calcula los puntos de daño de un guerrero

Actualiza la clase `Warrior` para que su método `getDamagePoints(Fighter)` calcule el daño infligido por un guerrero según las reglas anteriores.

```java
Warrior warrior = new Warrior();
Wizard wizard = new Wizard();

warrior.getDamagePoints(wizard);
// => 10
```

## 5. Crea la clase Wizard

Crea otra nueva clase llamada `Wizard`.
Esta clase también debe heredar de la clase `Fighter` existente.

## 6. Describe a un mago

Actualiza la clase `Wizard` para que su método `toString()` describa qué tipo de luchador es.
El método debe devolver el string `"Fighter is a Wizard"`.

```java
Wizard wizard = new Wizard();
wizard.toString();
// => "Fighter is a Wizard"
```

## 7. Permite que los magos preparen un hechizo y haz que sean vulnerables cuando no lo hayan preparado

Actualiza la clase `Wizard` para añadir un método llamado `prepareSpell()`.
La clase debe recordar cuándo se llama a este método y asegurarse de que su método `isVulnerable()` devuelva `false` solo cuando se haya preparado un hechizo.

```java
Wizard wizard = new Wizard();
wizard.prepareSpell();
wizard.isVulnerable();
// => false
```

## 8. Calcula los puntos de daño de un mago

Actualiza la clase `Wizard` para que su método `getDamagePoints(Fighter)` calcule el daño infligido por un mago según las reglas anteriores.

```java
Wizard wizard = new Wizard();
Warrior warrior = new Warrior();

wizard.prepareSpell();
wizard.getDamagePoints(warrior);
// => 12
```
