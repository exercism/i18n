# Introducción

Las operaciones bit a bit nos permiten manipular dígitos individuales dentro de números binarios.

Elm proporciona varios operadores bit a bit en su [módulo Bitwise](https://package.elm-lang.org/packages/elm/core/latest/Bitwise)

## Operaciones básicas

Modificar bits individuales de un número se llama _enmascaramiento_.
Una _máscara_ es un número en el que se han establecido bits concretos de una forma determinada para manipular otro número mediante operadores bit a bit como `and`, `or` y `xor`.

### and

`and` combina dos números conservando solo los bits que son `1` en ambos.
Esto es útil para comprobar si un bit individual está establecido.
Por ejemplo, para comprobar si el cuarto bit de un número está establecido a `1`, aplícale `and` con una máscara de `01000` (`8` en decimal) y comprueba si el resultado no es cero:

```elm
Bitwise.and 13 8 --> 8
--  13 = 01101
--   8 = 01000
-- and = 01000 = 8
```

### or

`or` combina dos números estableciendo cada bit a `1` si es `1` en uno de los números o en ambos.
Esto es útil para poner un bit concreto a `1`.
Por ejemplo, para poner el segundo bit de `10101` a `1`, aplícale `or` con la máscara `00010`:

```elm
Bitwise.or 21 2 --> 23
-- 21 = 10101
--  2 = 00010
-- or = 10111 = 23
```

### O exclusivo (xor)

`xor` combina dos números estableciendo cada bit a `1` si es `1` en uno de los números pero `0` en el otro.
Esto es útil para invertir un bit a su valor opuesto:

```elm
Bitwise.xor 20 5 --> 17
--  20 = 10100
--   5 = 00101
-- xor = 10001 = 17
```

### Complemento

`complement` invierte cada bit de un número (`0` pasa a ser `1`, `1` pasa a ser `0`).

Ten en cuenta que esto hará que los números positivos pasen a ser negativos, y los negativos, positivos.
Esto se debe a que los números negativos en binario se representan con `1` en la posición más a la izquierda.

```elm
Bitwise.complement 21 --> -22
--         21 = 00000000000000000000000000010101
-- complement = 11111111111111111111111111101010 = -22
```

### Desplazamiento de bits

Los siguientes operadores mueven bits a la izquierda o a la derecha un número de posiciones determinado, lo que equivale a multiplicar o dividir por potencias de 2.

`shiftLeftBy` mueve los bits a la izquierda y rellena con `0` desde el lado derecho.
Por ejemplo, para desplazar `21` tres posiciones a la izquierda:

```elm
Bitwise.shiftLeftBy 3 21 --> 168
--  21 = 10101
-- shiftLeftBy 3 = 10101000 = 168
```

Esto es lo mismo que decir `21 * 2^3 = 21 * 2 * 2 * 2 = 168`

`shiftRightBy`: mueve los bits a la derecha:

```elm
Bitwise.shiftRightBy 2 21 --> 5
--  21 = 10101
-- shiftRightBy 2 = 00101 = 5
```

Desplazar dos posiciones a la derecha es lo mismo que una división entera entre 4.

Ten en cuenta que esta función duplica el valor que haya en el bit más a la izquierda.
Así, los números negativos seguirán siendo negativos:

```elm
Bitwise.shiftRightBy 3 -21 --> -3
--  -21 = 111...101011
-- shiftRightBy 3 = 111...11101 = -3
```

Si quieres desplazar a la derecha y rellenar con ceros, usa `shiftRightZfBy`:

```elm
Bitwise.shiftRightZfBy 3 -21 --> 536870909
--  -21 = 111...101011
-- shiftRightZfBy 3 = 00111...11101 = 536870909
```
