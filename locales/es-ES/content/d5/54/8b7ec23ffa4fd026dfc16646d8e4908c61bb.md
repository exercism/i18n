# Anexo a las instrucciones

## Pistas

Para completar este ejercicio, tienes que crear el tipo de datos `Deque`
e implementar las siguientes funciones:

- `mkDeque`
- `pop`
- `push`
- `unshift`
- `shift`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya presentes,
pero depende de ti definir las funciones y crear un tipo de datos, un newtype o un
sinónimo de tipo que tenga sentido.
