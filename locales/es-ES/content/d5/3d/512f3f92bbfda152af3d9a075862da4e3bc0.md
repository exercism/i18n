# Ejecutar los tests desde la línea de comandos

Ejecuta los tests con:

```bash
scarb cairo-test
```

Todos los tests excepto el primero están ignorados. Cuando consigas que el primer test pase, abre el archivo de código fuente de los tests, que se encuentra en el directorio `tests`, elimina el flag `#[ignore]` del siguiente test y consigue que los tests vuelvan a pasar. Cada test es una función con el flag `#[test]` encima. Continúa así hasta que pases todos los tests.

Si quieres ejecutar _todos_ los tests sin editar el archivo de código fuente de los tests, usa:

```bash
scarb cairo-test --include-ignored
```

Para ejecutar un test concreto, independientemente de si está ignorado o no, por ejemplo `some_test`, puedes usar:

```bash
scarb cairo-test -f some_test
```

Para saber más sobre los tests de Cairo, consulta la [documentación de los tests][cairo-tests] en línea.

[cairo-tests]: https://book.cairo-lang.org/ch10-01-how-to-write-tests.html
