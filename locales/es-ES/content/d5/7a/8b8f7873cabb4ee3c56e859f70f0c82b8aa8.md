# Pistas

## General

- Usa [funciones anónimas][anon-fns].
- Usa una [clausura][closure] para hacer referencia a la variable del scope externo.

## 1. Crea un sumador

- Devuelve una función anónima que sume el argumento de la función anónima al argumento que se le pasa a `Secret.secret_add/1`.

## 2. Crea un restador

- Devuelve una función anónima que reste el argumento que se le pasa a `Secret.secret_subtract/1` del argumento de la función anónima.

## 3. Crea un multiplicador

- Devuelve una función anónima que multiplique el argumento de la función anónima por el argumento que se le pasa a `Secret.secret_multiply/1`.

## 4. Crea un divisor

- Devuelve una función anónima que divida el argumento de la función anónima entre el argumento que se le pasa a `Secret.secret_divide/1`.
- Usa la [división entera][div].

## 5. Crea una función «and»

- Devuelve una función anónima que realice una [operación _and_ a nivel de bits][bitwise-wiki] usando el argumento que se le pasa a la función anónima y el argumento que se le pasa a `Secret.secret_and/1`
- Las funciones del [módulo Bitwise][bitwise-hexdocs] pueden serte útiles.
- Si usas la versión 1.9 de Elixir o una anterior, tendrás que llamar a `require Bitwise` al principio de la definición del módulo para poder usar el módulo _Bitwise_.

## 6. Crea una función «xor»

- Devuelve una función anónima que realice una [operación _xor_ a nivel de bits][bitwise-wiki] usando el argumento que se le pasa a la función anónima y el argumento que se le pasa a `Secret.secret_xor/1`
- Las funciones del [módulo Bitwise][bitwise-hexdocs] pueden serte útiles.
- Si usas la versión 1.9 de Elixir o una anterior, tendrás que llamar a `require Bitwise` al principio de la definición del módulo para poder usar el módulo _Bitwise_.

## 7. Crea un combinador de funciones

- Devuelve una función anónima que [componga las funciones][fn-composition] que se le pasan a `Secret.secret_combine/2`.
- Usa un `.` antes de `()` cuando llames a una función anónima.
