# Instalación

Para instalar Roc, sigue las instrucciones que encontrarás en [roc-lang.org/install](https://roc-lang.org/install).
Solo necesitas instalar Roc y, opcionalmente, las extensiones o los plugins del editor que prefieras; no necesitas instalar Rust ni Zig (que se usan para compilar el propio Roc).
