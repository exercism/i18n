# Anexo de instrucciones

## Registros

| Registro | Uso          | Tipo    | Descripción                                  |
| -------- | ------------ | ------- | -------------------------------------------- |
| `$a0`    | entrada      | dirección | string de nombre terminado en null, o puntero nulo |
| `$a1`    | entrada/salida | dirección | string de resultado terminado en null        |
| `$t0-9`  | temporal     | cualquiera | para almacenamiento temporal                 |
