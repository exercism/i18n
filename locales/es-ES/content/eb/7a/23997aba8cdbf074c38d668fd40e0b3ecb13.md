# Pistas

## 1. Vigila el nivel de humedad de la habitación

- Si la humedad es demasiado alta, basta con [stop][ref-stopifnot]; no hace falta ningún mensaje.
- Si las condiciones son buenas, tienes que emitir un [message][ref-message].

## 2. Detecta el sobrecalentamiento

- Hay varias condiciones que comprobar.
- Si necesitas [stop][ref-stop], el mensaje de error es importante.
- Una condición preocupante pero que aún no es fatal necesita un [warning][ref-warning].
- Un buen resultado necesita un [message][ref-message] tranquilizador.
- Recuerda el valor devuelto booleano.

## 3. Vigila la máquina

- Las tareas 1 y 2 tienen valores devueltos booleanos que puedes comprobar.
