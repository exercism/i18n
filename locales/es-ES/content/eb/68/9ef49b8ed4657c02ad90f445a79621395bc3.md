# Acerca de

La mayor parte de la iteración en Factor se expresa con combinadores (`each`, `map`, `reduce`), pero la recursión explícita sigue teniendo su lugar: cuando la recursión no tiene forma de lista, cuando el caso base no es trivial o cuando estás implementando tú mismo un combinador.

```factor
: total ( seq -- sum )
    [ 0 ] [ unclip swap total + ] if-empty ;

: gcd ( a b -- g )
    dup zero? [ drop ] [ tuck mod gcd ] if ;
```

Algunas cosas que conviene saber:

- Las definiciones con `:` a secas pueden recurrir sin ninguna sintaxis especial. El compilador infiere los efectos de pila a través de la llamada recursiva.
- `loop ( quot -- )` te permite iterar una quotation que devuelve un valor booleano: sigue mientras se evalúe como verdadero.
- Las llamadas de cola se compilan a saltos, así que las palabras profundamente recursivas no desbordan la pila.

El par `unclip` / `if-empty` es la forma estándar de la recursión sobre secuencias; `cond` es la forma estándar del despacho entre varios casos.
