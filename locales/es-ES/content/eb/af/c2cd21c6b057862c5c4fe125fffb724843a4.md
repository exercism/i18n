# Índice de runes usado con bytes

Recorrer los `runes` y usar el índice para obtener `bytes` individuales es seguro en este caso,
porque la entrada está formada únicamente por caracteres ASCII.
Para ver qué ocurre cuando se usan caracteres que no son ASCII, añade este caso de prueba:

```go
{
	s1:          "aüa",
	s2:          "aÃa",
	want:        1,
	expectError: false,
}
```
