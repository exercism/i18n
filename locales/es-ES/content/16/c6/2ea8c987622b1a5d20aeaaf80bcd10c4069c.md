# Introducción

En Clojure hay unas cuantas construcciones básicas de [control de flujo](https://clojure.org/guides/learn/flow). `if` es la expresión condicional más importante: consta de una condición, un «then» y un «else» opcional. `if` solo evaluará la rama que seleccione el condicional.

```clojure
(if (even? 2) "even" "odd")
```

`cond` es una serie de tests y expresiones. Cada test se evalúa en orden y la expresión se evalúa y se devuelve para el primer test que sea verdadero.

```clojure
(cond (= x 5) "Expression to evaluate when x equals 5"
      (> x 7) "Expression to evaluate when x is greater than 7"
      :else   "Expression to evaluate in all other cases")
```
