# Instrucciones

A tu amigo Johannes le encanta el hardware de bricolaje (hazlo tú mismo).
Acaba de construir una máquina de zumo y le hace mucha ilusión.
El objetivo de Johannes es poder preparar zumo fresco todas las mañanas.

La máquina de zumo de Johannes tiene un montón de funcionalidades sofisticadas.
Por ejemplo, un sistema de medición integrado que puede decirte cuánto zumo hay en el vaso.
También tiene un temporizador que te dice cuánto tiempo lleva funcionando la máquina.

Johannes no es el mejor programando, pero quiere hacer un programa para controlar la máquina.
Por eso te ha pedido que le ayudes.

## 1. Luz de debug

La máquina tiene una luz de debug, es un mecanismo sencillo: si la máquina recibe corriente, la luz de debug está encendida.
El programa solo se ejecutará si la luz de debug está encendida.

Este método debe ser un método de clase llamado `JuiceMaker`.

Define el método de clase `JuiceMaker.debug_light_on?` que devuelve `true`.

```crystal
JuiceMaker.debug_light_on?
#=> true
```

## 2. Inicializar la máquina

Cuando se enciende la máquina, debe crear una instancia de una clase llamada `JuiceMaker`.
Se supone que la máquina tiene un estado inicializado.
El estado inicializado debe contener la siguiente información:

1. Si la máquina está funcionando o no. Esto debe ser siempre `false` cuando se enciende la máquina.
2. La cantidad de zumo que hay en el vaso; este será un sensor que medirá la cantidad de zumo en el vaso.

Define el estado inicializado, que toma la cantidad de zumo en el vaso como parámetro, y construye el estado inicializado.
El estado inicializado debe albergar una variable de instancia `@running` que se establece en `false`, y una variable de instancia `@fluid` que se basa en un argumento dado cuando se inicializa la clase.

```crystal
JuiceMaker.new(5)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=5>
```

## 3. Encender la máquina

La máquina se puede encender y apagar.
Tienes que definir un método para encender la máquina.
Cuando se enciende la máquina, el estado de funcionamiento debe establecerse en `true`.

Define el método `JuiceMaker#start`, que enciende la máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=true, @fluid=5>
```

## 4. Estado de la máquina

La máquina tiene que poder decirte cuál es su estado.
Debe devolver `true` si la máquina está funcionando y `false` si no lo está.

Define el método `JuiceMaker#running?` que devuelve el estado de la máquina.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.start

juice_maker.running?
#=> true
```

## 5. Añadir zumo

La máquina puede añadir zumo al vaso.
La máquina puede saber cuánto zumo se añade al vaso.
La máquina necesita ayuda para saber cuánto zumo hay en el vaso después de añadirlo.

Define el método `JuiceMaker#add_fluid`, que toma la cantidad de zumo añadida como parámetro y actualiza la cantidad de zumo en el vaso.

```crystal
juice_maker = JuiceMaker.new(5)
juice_maker.add_fluid(5)

juice_maker
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=10>
```

## 6. Apagar la máquina

La máquina se puede encender y apagar.
Tienes que definir un método para apagar la máquina
Este método solo se llamará cuando la máquina esté funcionando.
Cuando se apague la máquina, el estado de funcionamiento debe establecerse en `false`.
La máquina también necesita ayuda para determinar cuánto zumo hay en el vaso después de apagarse.
La máquina consume cinco unidades de zumo por minuto.

Define el método `JuiceMaker#stop`, que toma el número de minutos que la máquina ha estado funcionando como parámetro y devuelve la cantidad de zumo en el vaso después de apagar la máquina.

```crystal
juice_maker = JuiceMaker.new(5)

juice_maker.start
juice_maker
#=> <JuiceMaker:0x10f0b8 @running=true, @fluid=5>

juice_maker.stop(1)
#=> #<JuiceMaker:0x10f0b8 @running=false, @fluid=0>
```
