# Introducción

Muchos programas necesitan valores aleatorios (_aparentemente_) para simular sucesos del mundo real.

Entre los ejemplos habituales y conocidos se incluyen:
- Lanzar una moneda: un valor aleatorio de `('Heads', 'Tails')`.
- La tirada de un dado: un número entero aleatorio del 1 al 6.
- Barajar una baraja de cartas: un orden aleatorio de un array de cartas.
- La creación de árboles y arbustos en una simulación de gráficos en 3D.

Generar valores _realmente_ aleatorios con un ordenador es un [desafío técnico sorprendentemente difícil][truly-random], por lo que puede que veas estos resultados denominados «pseudoaleatorios».

En la práctica, una biblioteca bien diseñada como el módulo [`random`][random] de la biblioteca estándar de Python es rápida, flexible y ofrece resultados más que suficientes para la mayoría de las aplicaciones de modelado, simulación y juegos.

En esta breve introducción, mostramos las cuatro funciones más utilizadas del módulo.
Te animamos a explorar la documentación completa de [`random`][random], ya que hay muchas herramientas y opciones.

Antes de poder utilizar las herramientas del módulo `random`, primero tienes que importarlo:

```python
>>> import random

# Choose random integer from a range
>>> random.randrange(1000)
360

>>> random.randrange(-1, 500)
228

>>> random.randrange(-10, 11, 2)
-8

# Choose random integer between two values (inclusive)
>>> random.randint(5, 25)
22

```

Para evitar escribir el nombre del módulo, puedes importar funciones concretas por su nombre:

```python
>>> from random import choice, choices

# Using choice() to pick Heads or Tails 10 times
>>> tosses = []
... for side in range(10):
...    tosses.append(choice(['H', 'T']))    

>>> print(tosses)
['H', 'H', 'H', 'H', 'H', 'H', 'H', 'T', 'T', 'H']


# Using choices() to pick Heads or Tails 8 times
>>> picks = []
... picks.extend(choices(['H', 'T'], k=8))
... print(picks)
['T', 'H', 'H', 'T', 'H', 'H', 'T', 'T']
```



## `randrange()` y `randint()`

Como se muestra en el primer ejemplo anterior, la función `randrange()` tiene tres formas:

1. `randrange(stop)` devuelve un número entero `n` tal que `0 <= n < stop`
2. `randrange(start, stop)` devuelve un número entero `n` tal que `start <= n < stop`
3. `randrange(start, stop, step)` devuelve un número entero `n` tal que `start <= n < stop`
    y `n` está en la secuencia `start, start + step, start + 2*step...`

Para el caso más común, en el que `step == 1`, `randint(a, b)` puede ser más cómodo y legible.
Los posibles resultados de `randint()` _incluyen_ el límite superior, por lo que `randint(a, b)` equivale a usar `randrange(a, b+1)`.



## `choice()` y `choices()`

Estas dos funciones suponen que partes de alguna [secuencia][sequence-types] u otro contenedor.
Normalmente será un `list` o, con algunas limitaciones, una `tuple` o un `set` (_una `tuple` es inmutable y un `set` no tiene orden_).

La función `choice()` devuelve un miembro elegido al azar de una secuencia dada, y `choices()` devuelve un número determinado de miembros (`k`) elegidos al azar de una secuencia dada.
En los ejemplos mostrados anteriormente, supusimos una moneda justa con la misma probabilidad de cara o cruz, pero también se pueden especificar pesos.

Por ejemplo, si una bolsa contiene 10 bolas rojas y 15 bolas verdes, y queremos sacar una al azar:


```python
>>> random.choices(['red', 'green'], [10, 15])
['red']
```
