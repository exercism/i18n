# Pistas

## 1. Determina si la lasaña está lista

- Usa una [sentencia condicional][mdn-if-else] para devolver un resultado en función de una condición.
- La tarea se resuelve mejor si compruebas primero las dos condiciones específicas.
- Recuerda que los parámetros que faltan serán `undefined` y que puedes comprobar si una variable es `undefined` con el operador de igualdad estricta `===`.

## 2. Estima el tiempo de preparación

- Usa un parámetro por defecto para establecer el tiempo medio de preparación en caso de que no se haya proporcionado al llamar a la función.
- Vuelve a consultar los [arrays][concept-arrays] para averiguar cómo determinar el número de capas (la longitud del array de capas).

## 3. Calcula las cantidades de fideos y salsa que se necesitan

- Primero, declara dos variables para llevar la cuenta de la cantidad de fideos y de salsa.
  Defínelas con `let` para que puedas cambiar su valor más adelante en tu código.
  Además, asígnales un valor inicial adecuado.
- Usa un [bucle `for`][concept-for-loops] para recorrer las capas.
- Si dentro del bucle te encuentras con una capa `'noodles'` o `'sauce'`, aumenta en consecuencia la cantidad almacenada en la variable correspondiente.
- Usa un [objeto][concept-objects] para devolver ambos resultados.

## 4. Añade el ingrediente secreto

- Vuelve a consultar los [arrays][concept-arrays] para averiguar cómo obtener un elemento de un array y cómo añadir algo al final de un array.
- El índice del último elemento de un array `a` es `a.length - 1`.
- La función no debe tener una instrucción `return`.

## 5. Escala la receta

- Primero, calcula el factor que tienes que aplicar a todas las cantidades en función de las raciones objetivo.
- Una forma de asegurarte de que no se modifican los argumentos es usar un objeto nuevo para guardar los resultados.
- Usa un [bucle `for...in`][mdn-for-in] para recorrer todas las entradas de la receta original y rellenar el objeto en consecuencia.
