# Instrucciones

En este ejercicio vas a escribir código para llevar un registro de un array de lenguajes de programación que quieres aprender en Exercism.

Tienes seis tareas, todas ellas relacionadas con arrays.

## 1. Crea un array nuevo

Para llevar un registro de los lenguajes que quieres aprender, necesitarás crear un array nuevo. Define la función `new_list` que devuelva un array nuevo y vacío.

```gleam
new_list()
// -> []
```

## 2. Define un array existente

Actualmente tienes un trozo de papel con los lenguajes que quieres aprender: Gleam, Go y TypeScript. Define la función `existing_list` para que devuelva este array.

```gleam
existing_list()
// -> ["Gleam", "Go", "TypeScript"]
```

## 3. Añade un lenguaje nuevo a un array

A medida que exploras Exercism y encuentras lenguajes más interesantes, quieres añadirlos a tu array. Implementa la función `add_language` para añadir un lenguaje nuevo al principio de tu array.

```gleam
add_language(["OCaml", "Elixir"], "Scheme")
// -> ["Scheme", "OCaml", "Elixir"]
```

## 4. Cuenta los lenguajes del array

Contar los lenguajes uno a uno es incómodo. Implementa la función `count_languages` para contar el número de lenguajes de tu array.

```gleam
count_languages(["jq", "Elm", "Rust", "Kotlin"])
// -> 4
```

## 5. Invierte el array

En algún momento te das cuenta de que tu array en realidad está ordenado al revés. Implementa la función `reverse_list` para invertir tu array.

```gleam
reverse_list(["Python", "Julia", "Idris", "COBOL"])
// -> ["COBOL", "Idris", "Julia", "Python"]
```

## 6. Comprueba si un array es emocionante

Aunque te encantan todos los lenguajes, Gleam ocupa un lugar especial en tu corazón. Por eso, un array de lenguajes te entusiasma mucho si:

- El primero del array es Gleam.
- El segundo elemento del array es Gleam y el array contiene dos o tres lenguajes.

Implementa la función `exciting_list` para comprobar si un array de lenguajes es emocionante:

```gleam
exciting_list(["Lua", "Gleam"])
// -> True
```
