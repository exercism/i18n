# Workflow de configlet

El workflow de configlet usa la [herramienta configlet](/docs/building/configlet) para comprobar si los ficheros (de configuración) de un track están bien estructurados, tanto sintáctica como semánticamente.
Para ello, ejecuta [`configlet lint`](/docs/building/configlet/lint).

## Activar la comprobación del formato de los ficheros

Los tracks pueden usar [`configlet fmt`](/docs/building/configlet/format) para dar formato a los distintos ficheros de configuración del track.
El mismo comando también sirve para comprobar si todos los ficheros de configuración tienen el formato correcto.

El workflow `configlet` permite verificar si los ficheros de configuración tienen el formato correcto, pero esto es opcional y está desactivado de forma predeterminada.
Para activar la verificación del formato de los ficheros de configuración, sigue estos pasos:

1. Crea un fichero `.github/org-wide-files-config.toml` con el siguiente contenido

```toml
[configlet]
fmt = true
```

2. Una vez que este fichero se fusione en `main`, se abrirá automáticamente un PR que modifica el workflow `configlet.yml` de la siguiente manera:

```diff
  jobs:
    configlet:
      uses: exercism/github-actions/.github/workflows/configlet.yml@main
+     with:
+       fmt: true
```

3. Una vez fusionado este PR, el workflow `configlet` también verificará el formato de los ficheros de configuración del track.

## Origen

El workflow se define en el fichero `.github/workflows/configlet.yml`.
