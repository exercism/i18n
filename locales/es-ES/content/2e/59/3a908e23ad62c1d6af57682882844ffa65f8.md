# Introducción

Aunque el modificador `readonly` impide que se sobrescriba el valor o la referencia de un campo, no ofrece ninguna protección para los miembros de un tipo de referencia.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para asegurarte de que todos los miembros de un tipo de referencia estén protegidos, puedes marcar los campos como `readonly` y definir propiedades automáticas sin un descriptor de acceso `set`.

La Biblioteca de Clases Base (BCL) proporciona algunas versiones de solo lectura de colecciones cuando se necesita impedir que se actualicen los miembros de una colección. Estas adoptan la forma de envoltorios:

- `ReadOnlyDictionary<T>` expone un `Dictionary<T>` como de solo lectura.
- `ReadOnlyCollection<T>` expone un `List<T>` como de solo lectura.
