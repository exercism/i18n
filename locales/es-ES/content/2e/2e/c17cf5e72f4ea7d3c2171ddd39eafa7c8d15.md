# Introducción

El uso de la coincidencia de patrones es dominante en el código de Elixir asertivo e idiomático. Quizá recuerdes que `=/2` se describe como un operador de coincidencia, y no como un operador de asignación. Al usar el operador de coincidencia, si el patrón de la izquierda coincide con el de la derecha, las variables de la izquierda se vinculan y se devuelve el valor del lado derecho. Si no hay coincidencia, se lanza un `MatchError`.

```elixir
2 = 2
# => 2
# Literals can be matched if they are the same

2 = 3
# => ** (MatchError) no match of right hand side value: 3

{_, denominator} = Float.ratio(0.25)
# => {1, 4}
# the variable `denominator` is bound to the value 4
```

Recuerda que las coincidencias se producen de derecha a izquierda.

En el último ejemplo, si no necesitamos una variable en una coincidencia de patrones, podemos descartarla haciendo referencia a `_`. El runtime no hace seguimiento de ninguna variable que empiece por `_`.

## Coincidencia de patrones en funciones con nombre

La coincidencia de patrones también es una herramienta útil cuando se crean varias cláusulas de función. Se puede usar la coincidencia de patrones en los argumentos de las funciones, lo que determina qué cláusula de función se invoca, empezando por la parte superior del archivo y bajando hasta la primera coincidencia. Las variables se pueden vincular en la cabecera de una función y usarse en el cuerpo de la función.

```elixir
defmodule Example do
  def named_function(:a = variable_a) do
    {variable_a, 1}
  end

  def named_function(:b = variable_b) do
    {variable_b, 2}
  end
end

Example.named_function(:a)
# => {:a, 1}

Example.named_function(:b)
# => {:b, 2}

Example.named_function(:c)
# => ** (FunctionClauseError) no function clause matching in Example.named_function/1
```
