# Excepciones

```sather
   raise "Unknown prop: " + prop;
```

```sather
   protect
      ...
   when $STR then
      #OUT + exception.str;
   end;
```

## raise

`raise` acepta cualquier objeto. Lanzar un `STR` es el caso simple y es lo que usa este ejercicio. Una clase propia conlleva más información (qué prop, cuántos se querían) a cambio de tener que definirla en algún sitio.

Una excepción viaja hacia el exterior a través de quienes llaman hasta que un `protect` la captura. Si ninguno lo hace, el programa se detiene y la imprime.

Sather no registra qué excepciones puede lanzar una rutina, ni obliga a quienes llaman a gestionarlas. Nada en el tipo de una rutina indica que pueda fallar.

## protect

```sather
   protect
      body
   when $STR then
      ...
   when SOME_CLASS then
      ...
   end;
```

Las ramas se prueban en orden, y se ejecuta la primera cuyo tipo coincida con el valor lanzado. `exception` es ese valor, y solo existe dentro del scope de una rama.

Un `protect` sin ninguna rama que coincida no captura: la excepción sigue hacia el exterior como si el `protect` no estuviera ahí.

## Dónde capturar

Captura donde de verdad se pueda hacer algo. Un `protect` que se traga una excepción y continúa con un valor inventado convierte un fallo ruidoso en una respuesta incorrecta silenciosa, que es peor.

```sather
   -- almost always wrong
   protect
      return risky;
   when $STR then
      return 0;
   end;
```

## ¿Excepciones o contratos?

Ambas tienen que ver con cosas que van mal, y son para casos opuestos.

Una **excepción** es para algo que puede ocurrir de verdad y que quien llama puede que razonablemente no haya podido evitar, como un prop que falta en la tabla o un fichero que no está.

Un **contrato**, que es el siguiente ejercicio, es para algo que no debe ocurrir nunca, como que quien llama pase un peso negativo, y es una afirmación de que quien llama tiene un bug. Los contratos solo se comprueban cuando se piden, y un contrato incumplido detiene el programa en lugar de lanzar algo que se pueda capturar.

A grandes rasgos: si quien llama con cuidado aun así podría encontrárselo, lánzalo. Si encontrárselo significa que quien llama se equivoca, ponlo en un contrato.
