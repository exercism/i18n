# CLI

## Enviar la solución

Cuando ya no haya ningún test omitido y todos pasen, puedes enviar tu solución usando `exercism submit numbers.js`.

## Enviar soluciones incompletas

Es posible enviar una solución incompleta para que veas cómo otros han completado el ejercicio.
