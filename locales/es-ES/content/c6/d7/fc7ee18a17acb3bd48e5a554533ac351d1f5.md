# Pistas

## 1. Estima el tiempo de preparación

- Usa el [`size()`][size-func] del vector para determinar el número de capas (la longitud del slice de capas).

## 2. Calcula las cantidades de fideos y salsa necesarias

- Primero, crea un objeto `amount` para llevar la cuenta de la cantidad de fideos y salsa.
- Usa un [bucle `for`][for-loop] para recorrer las capas.
- Si encuentras una capa `"noodles"` o `"sauce"` en el bucle, aumenta en consecuencia la cantidad guardada en el objeto `amount`.

## 3. Añade el ingrediente secreto

- Vuelve a consultar los [vectors][concept-vector] para descubrir cómo obtener un elemento de un vector y cómo reemplazar un elemento en un vector.
- El índice del último elemento de un vector `a` es `a.size() - 1`, o puedes usar `a.back()` directamente.

## 4. Escala la receta

- Primero, crea un nuevo slice del mismo tamaño que el slice de entrada
- Usa un [bucle `for`][for-loop] para recorrer el slice de entrada y generar el slice de salida

## 5. Desbloquea el secreto familiar

- Puedes reutilizar tu código de la tarea 3.
- Esta tarea necesita [sobrecarga de funciones][function overloading].
