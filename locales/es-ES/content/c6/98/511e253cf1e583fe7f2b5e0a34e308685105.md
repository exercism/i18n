# Anexo a las instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción](https://docs.python.org/3/tutorial/errors.html#raising-exceptions). Cuando lo hagas, deberías incluir siempre un **mensaje de error significativo** que indique cuál es el origen del error. Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar. En las situaciones en las que sabes que el origen del error será de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados](https://docs.python.org/3/library/exceptions.html#base-classes), pero aun así deberías incluir un mensaje significativo.

La conjetura de Collatz solo se ocupa de los **números enteros estrictamente positivos**, así que este ejercicio espera que uses la [instrucción raise](https://docs.python.org/3/reference/simple_stmts.html#the-raise-statement) y que «lances» un `ValueError` en tu solución si el valor dado es cero o un número entero negativo. Las pruebas solo pasarán si lanzas la `exception` con `raise` y además incluyes un mensaje con ella.

Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# example when argument is zero or a negative integer
raise ValueError("Only positive integers are allowed")
```
