# Introducción

## Métodos de extensión

Los métodos de extensión permiten añadir métodos a tipos existentes sin crear un nuevo tipo derivado, sin recompilar ni modificar de otro modo el tipo original. Se definen como métodos estáticos, pero se llaman utilizando la sintaxis de un método de instancia. Su primer parámetro va precedido por el modificador `this` y especifica sobre qué tipo opera el método; además, se incorporan al scope a nivel de espacio de nombres.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
