# Introducción

En JavaScript, las _template strings_ permiten incrustar expresiones dentro de strings, algo que también se conoce como interpolación de strings.
Esta funcionalidad amplía las capacidades del objeto global [`String`][string-reference] integrado en el lenguaje.

Puedes crear template strings en JavaScript encerrando el texto entre comillas invertidas.
No solo permiten que el texto incluya saltos de línea y otros caracteres especiales, sino que además puedes incrustar variables y otras expresiones.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

En el ejemplo anterior, las comillas invertidas (<code>\`\`</code>) se usan para representar una template string. El `${...}` es el marcador que se usa para la sustitución.
Cualquier tipo que no sea string se convierte en string de forma _implícita_.
Este tema se trata en el concepto [conversión de tipos][type-conversion-concept].
Con las template strings se puede usar cualquier tipo de expresión.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Cuando necesitas que los strings ocupen varias líneas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;
```

Gracias a las posibilidades de sustitución disponibles, también puedes introducir lógica en el proceso para determinar cuál debe ser el string de salida.

Un ejemplo de esto es incrustar un [operador ternario][ternary-operator].
Este operador es una forma abreviada de escribir una instrucción `if/else`.
La sintaxis es `condition ? consequent-expression : alternative-expression`.
Si la condición se evalúa como verdadera, se devuelve el operando que está a la izquierda de los dos puntos.
En caso contrario, el resultado de la expresión ternaria es el operando que está a la derecha de los dos puntos.

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
