# Instrucciones

La empresa para la que trabajas está a punto de lanzar su nuevo teléfono inteligente, llamado **Smarty 5**: incluye un sistema de cámara totalmente nuevo, un diseño nuevo y un procesador revolucionario que ejecuta un nuevo sistema operativo llamado **smartyOS**.

El nuevo procesador tiene potencia suficiente para gestionar contraseñas más seguras que nunca, y la empresa ha decidido aprovecharlo. Te ha pedido que implementes un sistema de bloqueo por contraseña para el teléfono que permita al usuario establecer una contraseña y, después, comprobar si una contraseña dada es correcta.

~~~~exercism/caution
El sistema de contraseñas que se practica en este ejercicio no es seguro y solo se usa con fines educativos.
**NO** debería usarse en ninguna aplicación del mundo real.
~~~~

## 1. Establecer una contraseña

El teléfono permite a los usuarios usar varios tipos distintos de contraseñas, desde una sencilla contraseña numérica hasta una contraseña alfanumérica más segura e incluso una contraseña que almacena su huella dactilar.

Estos distintos tipos de contraseñas usan tipos distintos: la contraseña numérica usa un `Int32`, la contraseña alfanumérica usa un `String` y la contraseña de huella dactilar usa un `Float64`.

Implementa la clase `PasswordLock` con un inicializador que reciba cualquiera de los tres tipos de contraseñas como argumento y lo almacene en una variable de instancia llamada `@password`.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>
```

## 2. Cifrar la contraseña

La empresa ha decidido cifrar la contraseña para que no se almacene en texto plano y te ha pedido que implementes un método para cifrarla.

Cada tipo de contraseña tiene su propia forma de cifrarse:

- Contraseña `Int32`: la contraseña se divide entre dos y se redondea al entero más cercano.
- Contraseña `String`: la contraseña se invierte.
- Contraseña `Float64`: la contraseña se multiplica por cuatro.

Implementa un método de instancia llamado `encrypt` que no reciba argumentos y modifique la variable de instancia `@password` para que quede cifrada.

```crystal
password_lock = PasswordLock.new(1234)
# => #<PasswordLock:0x7f8e1b8c0b80 @password=1234>

password_lock.encrypt
# => #<PasswordLock:0x7f8e1b8c0b80 @password=617>
```

## 3. Comprobar si una contraseña es correcta

La empresa también te ha pedido que implementes un método que compruebe si una contraseña dada es correcta.

Quieren que el método devuelva `nil` si la contraseña es incorrecta y `"Unlocked"` si la contraseña es correcta.

Implementa un método de instancia llamado `unlock?` que reciba como argumento la contraseña que hay que comprobar.
El método debe devolver `nil` si la contraseña es incorrecta y `"Unlocked"` si la contraseña es correcta.

```crystal
password_lock = PasswordLock.new(1234)
password_lock.encrypt
password_lock.unlock?(1234)
# => "Unlocked"
```
