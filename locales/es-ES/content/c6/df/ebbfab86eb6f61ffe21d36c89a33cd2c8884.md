# Introducción

Aunque Swift ofrece una amplia funcionalidad en su biblioteca estándar, puedes acceder a muchas más funcionalidades importando bibliotecas y frameworks externos.
Estos módulos pueden proceder directamente del proyecto Swift (como [Swift Argument Parser][argument-parser]), de los frameworks de las plataformas de Apple (como [Foundation][apple-foundation] y el [Network Framework][network-framework]), o de bibliotecas de código abierto de terceros (como [SwiftyBeaver][swifty-beaver]).

Los módulos principales como Foundation, una de las bibliotecas más utilizadas en Swift, se incluyen con la cadena de herramientas de Swift.
Las bibliotecas de terceros deben añadirse a la configuración de tu proyecto (por ejemplo, usando Swift Package Manager) antes de poder importarlas.

Para importar un módulo, escribe la palabra clave `import` seguida del nombre del módulo:

```swift
import Foundation
```

Importar un módulo hace que sus tipos, métodos y funciones estén disponibles para tu código.
Por ejemplo, al importar Foundation se amplía `String` con métodos de utilidad como `components(separatedBy:)`.

Por convención, las instrucciones `import` se colocan al principio de un archivo Swift para que las dependencias sean visibles de inmediato para cualquiera que lea el código.

[argument-parser]: https://apple.github.io/swift-argument-parser/documentation/argumentparser/
[network-framework]: https://developer.apple.com/documentation/network
[swifty-beaver]: https://github.com/SwiftyBeaver/SwiftyBeaver
[apple-foundation]: https://developer.apple.com/documentation/foundation
