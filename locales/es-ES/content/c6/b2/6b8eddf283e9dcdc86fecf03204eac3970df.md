# Pistas

## General

- Kotlin proporciona muchas [funciones][ref-strings] para trabajar con Strings. ¡No dejes de echar un vistazo a la pestaña `Members & Extensions`!

## 1. Obtener el mensaje de una línea de registro

- Existe una [función][ref-string-substringAfter] para extraer la parte de un `String` que hay después de un delimitador dado.
- Eliminar los espacios en blanco de un `String` se trata en [Remove All Whitespaces from a String in Kotlin][tutorial-trim-white-space].

## 2. Obtener el nivel de registro de una línea de registro

- También hay una [función][ref-string-substringBefore] para extraer la parte de un `String` que hay _antes_ de un delimitador dado.
- Hay una [forma][ref-string-lowercase] de convertir un `String` a minúsculas.

## 3. Reformatear una línea de registro

- Se pueden crear [plantillas de string][docs-string-template] con un [string multilínea][docs-string-multiline].
