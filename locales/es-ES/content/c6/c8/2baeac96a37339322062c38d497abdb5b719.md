# Pistas

## 1. Obtén la primera carta

- En [este artículo][mdn-destructuring] encontrarás una buena visión general de la desestructuración de arrays. Puedes ver un ejemplo de asignación básica de variables en la sección «Basic Array Destructuring».

## 2. Obtén la segunda carta

- Puedes usar marcadores de posición para ignorar uno o más valores del array.
- Puedes ver un ejemplo [en MDN][mdn-destructuring-ignore-value].

## 3. Intercambia las dos cartas

- Es posible intercambiar dos valores en una sola expresión de desestructuración.
- Puedes ver un ejemplo [en MDN][mdn-destructuring-swapping].

## 4. Reordena tres cartas

- Es posible cambiar la posición de tres valores en una sola expresión de desestructuración.
- Es lo mismo que intercambiar dos valores, pero con tres (o más).

## 5. Elige el montón con nombre

- Los objetos se pueden desestructurar igual que los arrays.
- Puedes ver un ejemplo [en MDN][mdn-object-destructuring-basic-assignment].

## 6. Intercambia montones con nombre

- Cuando se extrae una propiedad de un objeto, se puede renombrar con una sintaxis específica.
- Puedes ver un ejemplo [en MDN][mdn-object-destructuring-object-rename].
