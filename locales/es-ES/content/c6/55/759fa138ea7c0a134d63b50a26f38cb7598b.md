# Porciones de pizza

## Historia

Tienes varias pizzerías en tu ciudad y quieres escribir una aplicación web que te permita comparar dos configuraciones de pizza distintas para saber quién te dará la porción más grande.

## Tareas

La historia facilita la exploración de los [tipos opcionales][types-option-types], que se pueden usar para representar un valor o la ausencia de un valor.

- Escribe una función que calcule el tamaño de las porciones y que devuelva nil cuando la entrada no sea válida
- Procesa la entrada de tu aplicación web para determinar cuál es la porción más grande
