# Acerca de

Los Boolean en Java se representan mediante el tipo `boolean`, cuyos valores pueden ser `true` o `false`.

Java admite tres [operadores booleanos][operators]:

- `!` (NOT): niega el valor booleano
- `&&` (AND): toma dos valores booleanos y da como resultado true si los dos son true
- `||` (OR): da como resultado true si cualquiera de los dos valores booleanos es true

Los operadores `&&` y `||` usan la _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

También se conocen como operadores condicionales o lógicos.
En la documentación, `!` se clasifica a veces como una operación a nivel de bits, pero tiene la semántica convencional de _NOT_.

```java
true || false // => true
false || false // => false
false || true // => true
true && false // => false
true && true // => true
!true // => false
!false // => true
```

Los tres operadores booleanos tienen cada uno una [_precedencia de operadores_][precedence] distinta.
En consecuencia, se evalúan en este orden: primero `not`, después `&&` y, por último, `||`.
Si quieres «escapar» de estas reglas, puedes encerrar una expresión booleana entre paréntesis (`()`), ya que los paréntesis tienen una precedencia de operadores aún mayor.

```java
!true && false   // => false
!(true && false) // => true
```
