# Instrucciones

Tu tarea consiste en analizar un string de Smart Game Format (SGF) y devolver una estructura de datos en árbol que represente la partida.

Un string SGF representa un árbol de nodos. El árbol completo va encerrado entre paréntesis `()`.
Cada nodo del árbol se indica con un punto y coma `;`, seguido de una secuencia de propiedades.
Una propiedad consta de un identificador en mayúsculas (por ejemplo, `AB`), seguido de uno o varios valores encerrados entre corchetes `[]`.

Por ejemplo, el string `(;FF[4]C[root])` representa un árbol con un único nodo raíz. Ese nodo tiene dos propiedades:
- La propiedad `FF` con el valor `4`
- La propiedad `C` con el valor `root`

**Variaciones (árboles y ramas)**
SGF admite variaciones de la partida anidando árboles. Un árbol puede tener varios árboles hijos, que también van encerrados entre paréntesis.
Por ejemplo, `(;A[B](;C[D])(;E[F]))` representa un nodo raíz con la propiedad `A`, que tiene dos ramas hijas:
1. Un nodo con la propiedad `C` y el valor `D`
2. Un nodo con la propiedad `E` y el valor `F`

**Formato y escapes**
Los valores entre corchetes pueden contener caracteres de escape. Una barra invertida `\` seguida de cualquier carácter representa ese carácter literal (por ejemplo, `\]` debería analizarse como un `]` literal). Además, si un salto de línea va precedido de una barra invertida, actúa como continuación de línea y debe eliminarse del valor. El resto de saltos de línea dentro de un valor deben conservarse.

**Gestión de errores**
Debes lanzar un error cuando el string SGF no sea válido. Estos son algunos ejemplos de SGF no válido:
- Un árbol que no empieza por paréntesis `()`.
- Un nodo que no empieza por punto y coma `;`.
- Identificadores de propiedad que no están formados únicamente por letras mayúsculas.
- Corchetes que faltan o paréntesis mal emparejados.

### Estructura de datos

Tu función de análisis debe devolver una representación del árbol. Un enfoque habitual es representar cada árbol como un objeto con dos campos:
- `properties`: un objeto (o Map) en el que las claves son los identificadores de propiedad (strings) y los valores son arrays de strings (ya que una propiedad puede tener varios valores).
- `children`: un array que contiene los árboles hijos.


Ejemplo:

Input: `(;FF[4]C[root])`
Output: `{
  properties: {
    FF: ['4'],
    C: ['root']
  },
  children: []
}`

Input: `(;A[B](;C[D])(;E[F]))`
Output: `{
  properties: {
    A: ['B']
  },
  children: [
    {
      properties: {
        C: ['D']
      },
      children: []
    },
    {
      properties: {
        E: ['F']
      },
      children: []
    }
  ]
}`
