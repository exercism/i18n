# Introducción

## Interfaces

Una interfaz es un tipo que contiene miembros que definen un grupo de funcionalidad relacionada. Distancia los usos de una clase de la implementación, lo que permite múltiples implementaciones distintas o admitir un comportamiento genérico, como el formato, la comparación o la conversión.

La sintaxis de una interfaz es similar a la de una clase o una estructura, salvo que los métodos y las propiedades aparecen solo como la firma y no se proporciona ningún cuerpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Todas las operaciones definidas por la interfaz deben implementarse.

Las interfaces pueden contener métodos de instancia y propiedades, entre otros miembros.

## Ordenación

Para que un objeto se pueda comparar con otro objeto, debe implementar la interfaz `IComparable<T>`.
Esta interfaz tiene un único método que hay que implementar: `int CompareTo(T other)`.

El método `CompareTo` puede devolver tres valores distintos:

- Un valor menor que cero: el objeto actual es menor que el otro objeto.
- Un valor mayor que cero: el objeto actual es mayor que el otro objeto.
- Un valor igual a cero: el objeto actual es igual al otro objeto.
