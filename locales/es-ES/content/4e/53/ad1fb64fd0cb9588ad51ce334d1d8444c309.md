# Introducción

En el ejercicio anterior vimos que hay dos formas de escribir comentarios en Go: los comentarios de una sola línea, precedidos por `//`, y los bloques de comentarios de varias líneas, encerrados entre `/*` y `*/`.

## Comentarios de documentación

En Go, los comentarios desempeñan un papel importante a la hora de documentar el código.
Los utiliza el comando `godoc`, que extrae estos comentarios para crear documentación sobre los paquetes de Go.
Un comentario de documentación debe ser una oración completa que empiece por el nombre de lo que se describe y termine en punto.

Los comentarios deben preceder tanto a los paquetes como a los identificadores exportados, por ejemplo funciones exportadas, métodos, variables de paquete, constantes y structs, sobre los que aprenderás más en los próximos ejercicios.

Una variable a nivel de paquete puede tener este aspecto:

```go
// TemperatureCelsius represents a certain temperature in degrees Celsius.
var TemperatureCelsius float64
```

## Comentarios de paquete

Los comentarios de paquete deben escribirse justo antes de una cláusula de paquete (`package x`) y empezar por `Package x ...`, así:

```go
// Package kelvin provides tools to convert
// temperatures to and from Kelvin.
package kelvin
```

## Comentarios de función

Un comentario de función debe escribirse justo antes de la declaración de la función.
Debe ser una oración completa que empiece por el nombre de la función.
Por ejemplo, un comentario exportado para la función `Calculate` debe tener la forma `Calculate  ...`.
También debe explicar qué argumentos recibe la función, qué hace con ellos y qué significan sus valores devueltos:

```go
// CelsiusFreezingTemp returns an integer value equal to the temperature at which water freezes in degrees Celsius.
func CelsiusFreezingTemp() int {
	return 0
}
```
