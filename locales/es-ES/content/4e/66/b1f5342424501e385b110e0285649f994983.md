# Instrucciones

Mantienes el kit de herramientas de generación de código de una estación de señales.
Cada macro es un *molde*: una pequeña plantilla que el compilador usa para
estampar código especializado en cada punto de llamada.

Tú solo escribes las cuatro macros. El archivo de pruebas define unas pequeñas
palabras envoltorio que *llaman* a tus macros (una macro solo se puede
observar a través del código que genera) y luego comprueba los resultados
en tiempo de ejecución de los envoltorios. Deja los envoltorios tal y como están.

En cada tarea, el cuerpo recibe en la pila las entradas literales del punto
de llamada y debe dejar **una quotation**. Las líneas «compila a» muestran el
código lineal que debería producir tu quotation.

## 1. Dos veces

`twice` toma una quotation literal y devuelve una quotation que
ejecuta la original dos veces seguidas.

```factor
! : inc-twice ( x -- y ) [ 1 + ] twice ;
! body receives [ 1 + ]  ->  must build [ 1 + 1 + ]
5 inc-twice .   ! => 7
```

## 2. N repeticiones

`repeat-quot` toma una quotation literal y un número literal `n`,
y devuelve una quotation que ejecuta la original `n` veces seguidas.
`n = 0` devuelve la quotation vacía `[ ]`.

```factor
! : inc-thrice ( x -- y ) [ 1 + ] 3 repeat-quot ;
! body receives [ 1 + ] 3  ->  must build [ 1 + 1 + 1 + ]
5 inc-thrice .   ! => 8
```

## 3. Componer varias

`compose-many` toma un array literal de quotations y devuelve una
única quotation que ejecuta cada una a su vez. Un array vacío
devuelve la quotation vacía.

```factor
! : pipeline ( x -- y ) { [ 1 + ] [ 2 * ] [ 1 - ] } compose-many ;
! body receives { [ 1 + ] [ 2 * ] [ 1 - ] }  ->  must build [ 1 + 2 * 1 - ]
5 pipeline .   ! => 11
```

## 4. Iteración desenrollada

`each-literal` toma una secuencia literal y una quotation. Devuelve
una quotation que, para cada elemento de la secuencia, apila ese
elemento y después ejecuta la quotation: una iteración que ocurre en
tiempo de compilación, así que el código generado es lineal.

```factor
! : sum-three ( -- n ) 0 { 10 20 30 } [ + ] each-literal ;
! body receives { 10 20 30 } [ + ]  ->  must build [ 10 + 20 + 30 + ]
sum-three .   ! => 60
```

Esta es la más estructural de las cuatro: tanto la longitud de la
secuencia *como* los valores de sus elementos dan forma al código
generado. Las pistas te guían paso a paso para construirla.
