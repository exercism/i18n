# Acerca de

Los diccionarios, al igual que sus equivalentes en otros lenguajes como los mapas o los arrays asociativos, almacenan pares clave/valor de forma que se puede recuperar o cambiar un valor directamente pasando la clave a la propiedad de indizador del diccionario.

Además, se pueden añadir y eliminar pares clave/valor del diccionario. Se pueden enumerar las claves, los valores y los pares clave/valor.

Los valores pueden ser objetos de cualquier tipo de C#, lo que incluye primitivos, structs _y_ clases.

El objeto Dictionary permite que las claves sean objetos de cualquier tipo. Sin embargo, para garantizar un comportamiento correcto en tiempo de ejecución, las claves deben tener un código hash adecuado, como el que devuelve [GetHashCode][gethashcode].

No se puede acceder de forma segura a una instancia de diccionario desde más de un hilo (no es segura para varios hilos). [ConcurrentDictionary][concurrent-dictionary] está disponible para situaciones con varios hilos.

Consulta también [HashSet][hashset], [ConcurrentDictionary][concurrent-dictionary] y [SortedDictionary][sorted-dictionary].

Aunque no existe una versión no genérica de Dictionary, en la biblioteca siguen quedando varias clases para dar soporte a un mapa no genérico. Conviene que conozcas las versiones no genéricas IDictionary y Hashtable, sobre todo para que las reconozcas cuando te las encuentres. Es poco probable que tengas que usarlas salvo para mantener una base de código antigua.

A menudo querrás exponer y acceder al diccionario a través de su interfaz [`IDictionary<TKey, TValue>`][idictionary].

Ten en cuenta que, debido a la naturaleza de las [propiedades de indizador][indexer-properties], los valores primitivos se pueden modificar en el mismo sitio, por ejemplo:

```csharp
nums["some-number"] = 3;
nums["some-number"]++;
// nums["some-number"] == 4

```
