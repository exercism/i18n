# Representaciones

El [representer][representer] usa [`read`][cl-read] para leer la entrega y [`write`][cl-write] para escribir la representación, además de aplicar algunas normalizaciones adicionales.
A cada entrega se le aplican las siguientes normalizaciones:

- [Se eliminan todos los comentarios][remove-comments]
- [Se eliminan los strings de documentación][remove-doc-strings]
- [Se normalizan las mayúsculas y minúsculas del texto][normalize-case]
- [Se normaliza el formato del texto][normalize-formatting]
- [Se normalizan los nombres de los símbolos][normalize-names]
