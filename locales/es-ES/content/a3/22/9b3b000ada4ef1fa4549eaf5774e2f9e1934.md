# Introducción

## Importación

Aunque Swift ofrece una amplia funcionalidad en su biblioteca estándar, puedes acceder a muchas funcionalidades adicionales importando bibliotecas y frameworks externos.
Estos módulos pueden proceder directamente del proyecto Swift (como [Swift Argument Parser][argument-parser]), de frameworks de plataformas de Apple (como [Foundation][apple-foundation] y el [Network Framework][network-framework]), o de bibliotecas de código abierto de terceros (como [SwiftyBeaver][swifty-beaver]).

Los módulos principales como Foundation, una de las bibliotecas más usadas en Swift, se incluyen con la cadena de herramientas de Swift.
Las bibliotecas de terceros deben añadirse a la configuración de tu proyecto (por ejemplo, usando Swift Package Manager) antes de poder importarlas.

Para importar módulos se escribe la palabra clave `import` seguida del nombre del módulo.
Así, puedes importar Foundation añadiendo lo siguiente a tu programa.

```swift
import Foundation
```

Importar un módulo hace que sus tipos, métodos y funciones estén disponibles para tu código.
Por ejemplo, importar Foundation amplía `String` con métodos de utilidad como `components(separatedBy:)`.

Por convención, las instrucciones `import` se colocan al principio de un archivo Swift para que las dependencias sean visibles de inmediato para cualquiera que lea el código.

## Indexación de strings

Se puede acceder a los caracteres individuales de un `String` usando el método de subíndices que se usa con los arrays.
Sin embargo, los [índices][string-indices] que se usan con los strings _no_ son números enteros y no se puede trabajar con ellos directamente.
En su lugar, deben calcularse a partir de otro índice conocido, como `startIndex`, que apunta a la posición del primer carácter de un string no vacío, usando los métodos disponibles en las bibliotecas [`String`][string-docs] y [`NSString`][nsstring-docs] (cuando se importa el módulo `Foundation`, los strings en Swift tienen acceso a todas las propiedades y métodos de NSString).

Por ejemplo, dado el siguiente string:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

No se puede escribir `csv[21]` para obtener la «g» de «orange»; en su lugar hay que calcular un valor de tipo `String.Index` y proporcionar ese índice.
Ten en cuenta que estos índices no están pensados para que los consuman las personas por sí solos.
Son lo que se conoce como _índices opacos_, ya que las personas no necesitan saber qué hay dentro de ellos.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Ten en cuenta, no obstante, que si el desplazamiento no es un índice válido, es decir, si devolviera el índice anterior a `startIndex` o posterior a `endIndex`, la operación generará un error y el programa se bloqueará.
Para evitar este problema, se puede especificar un índice límite.
Esto devuelve un índice opcional y devolverá nil para índices que de otro modo no serían válidos.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Además, los índices no se pueden compartir entre strings.
Por ejemplo, usar el `index` de la «g» de «orange» calculado antes para indexar el string `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, es decir, `fam[index]`, bloqueará tu programa.

Hay muchas razones para todo esto, pero básicamente todas se reducen a que «Unicode es complicado».

En general, si necesitas acceso aleatorio a caracteres individuales, probablemente te convenga usar otra estructura de datos, como `Array<Character>`.

### Algunos métodos útiles

Swift tiene los métodos `first` y `last` para obtener el primer y el último carácter de un string.
Estos métodos devuelven un carácter opcional, así que si el string está vacío, devolverán nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

También puedes usar los métodos `prefix` y `suffix` para obtener una subcadena de un string.
Estos métodos toman un número entero como argumento y devuelven una subcadena que contiene los primeros o los últimos n caracteres del string.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```

## Métodos de string

Trabajar con texto es una tarea habitual en programación.
Swift, junto con el framework Foundation, ofrece muchos métodos y propiedades cómodos para inspeccionar, transformar y manipular strings.

## Dividir strings con `components(separatedBy:)`

Para dividir un string en un array de subcadenas según un delimitador, usa `components(separatedBy:)` (requiere importar Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Comprobar prefijos y sufijos con `hasPrefix(_:)` y `hasSuffix(_:)`

Para comprobar si un string empieza o termina con una secuencia concreta de caracteres, usa `hasPrefix(_:)` y `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Cambiar mayúsculas y minúsculas

Puedes transformar las mayúsculas y minúsculas de un string con estos métodos y propiedades estándar:

- `lowercased()`: Devuelve una copia del string en minúsculas.
- `uppercased()`: Devuelve una copia del string en mayúsculas.
- `capitalized`: Devuelve una copia en la que la primera letra de cada palabra está en mayúscula (de Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Reemplazar subcadenas con `replacingOccurrences(of:with:)`

Para reemplazar todas las apariciones de una subcadena objetivo por otro string, usa `replacingOccurrences(of:with:)` (de Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Unir strings con `joined(separator:)`

El método `joined(separator:)` pertenece a las colecciones de strings, como `[String]`.
Une los elementos en un único string usando un separador:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
