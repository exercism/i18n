# Pistas

## General

- El tipo que se proporciona es recursivo: `Nil` representa un árbol vacío y `Node(node)` contiene un registro con un valor y dos subárboles.
  Un `match` puede distinguir estos casos y enlazar el registro del nodo.

- Las actualizaciones de registro como `{ ..node, left: new_left }` conservan los demás campos; envuelve el registro actualizado en `Node(...)` para construir el árbol resultante.
