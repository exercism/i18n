# Introducción

## Tipos struct

Ya hemos visto los tipos struct; a modo de repaso, un `struct` es una secuencia de elementos con nombre llamados _campos_, y cada campo tiene un nombre y un tipo.
El nombre de un campo debe ser único dentro del struct.
Los structs se pueden comparar con la _clase_ del paradigma de la programación orientada a objetos.

Para crear un nuevo struct se utilizan las palabras clave `type` y `struct`, y después se definen explícitamente el nombre y el tipo de los campos, como se muestra en el ejemplo siguiente.

```go
type StructName struct{
    field1 fieldType1
    field2 fieldType2
}
```

## Tipos que no son struct

También es posible definir tipos que no son struct, que puedes usar como alias de declaraciones de tipos integrados.

```go
type Name string
func SayHello(n Name) {
  fmt.Printf("Hello %s\n", n)
}
n := Name("Fred")
SayHello(n)
// Output: Hello Fred
```

También puedes definir tipos que no son struct compuestos de arrays y mapas.

```go
type Names []string
func SayHello(n Names) {
  for _, name := range n {
    fmt.Printf("Hello %s\n", name)
  }
}
n := Names([]string{"Fred", "Bill"})
SayHello(n)
// Output:
// Hello Fred
// Hello Bill
```
