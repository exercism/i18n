# Instrucciones

En este ejercicio, implementarás la mecánica de un juego de rol.
El personaje de un jugador se representa con el siguiente tipo:

```fsharp
type Player = {
    Name: string option
    Level: int
    Health: int
    Mana: int option
}
```

Los jugadores de este juego deben alcanzar el nivel 10 antes de desbloquear una reserva de maná, para poder empezar a lanzar hechizos.
Trabajarás en dos partes de la funcionalidad de este juego: la mecánica de revivir y la mecánica de lanzar hechizos.

## 1. Preséntate

Escribe el contenido de la función `introduce`.
Ten en cuenta que el campo `Name` del registro `Player` es un `Option`.
Es posible que los jugadores sigilosos quieran ocultar su nombre dejándolo con el valor `None`; a esos jugadores se les presentará como `"Mighty Magician"`.
En caso contrario, basta con usar tu nombre para presentarte.

```fsharp
introduce { Name = None; Level = 2; Health = 8; Mana = None }
    --> "Mighty Magician"

introduce { Name = Some "Merlin"; Level = 2; Health = 8; Mana = None }
    --> "Merlin"
```

## 2. Implementa la mecánica de revivir

La función `revive` debe comprobar que el personaje del jugador está realmente muerto (su salud ha llegado a 0).
Si es así, debe devolver una nueva instancia de `Player` con 100 de salud.
En caso contrario, si el personaje del jugador no está muerto, la función `revive` devuelve `None`.

Si el nivel del jugador es 10 o superior, también debe revivir con 100 de maná.
Si el nivel del jugador es inferior a 10, su maná debe ser `None`.
La función `revive` debe conservar el nivel del jugador.

```fsharp
let deadPlayer = { Name = None; Level = 2; Health = 0; Mana = None }

revive deadPlayer
    --> Some { Name = None; Level = 2; Health = 100; Mana = None }
```

Si se llama a la función `revive` con un jugador cuya salud sea 1 o superior, la función debe devolver `None`.

```fsharp
let alivePlayer = { Name = None; Level = 2; Health = 42; Mana = None }

revive alivePlayer
    --> None
```

## 3. Implementa la mecánica de lanzar hechizos

La función `castSpell` recibe como argumentos un `int` que indica cuánto maná cuesta el hechizo, además de un `Player`.
Devuelve el jugador actualizado, así como la cantidad de daño que inflige el hechizo lanzado.
Un lanzamiento de hechizo correcto hace un daño igual al doble del coste de maná del hechizo.
Sin embargo, si el jugador no tiene maná suficiente, no ocurre nada, el jugador no cambia y no se hace ningún daño.
Si el jugador ni siquiera tiene una reserva de maná, intentar lanzar el hechizo debe reducir su salud en el coste de maná del hechizo y no hace ningún daño.

```fsharp
let wizard = { Name = None; Level = 18; Health = 123; Mana = Some 30 }

let updatedWizard, damage = castSpell 14 wizard

updatedWizard.Mana --> Some 16
damage             --> 28
```
