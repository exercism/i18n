# Pistas

## General

- Eli Bendersky ha escrito [una buena página][eli-lisp-equality] que explica las diferencias entre los predicados de igualdad genéricos en Common Lisp.
- El [Hyperspec][hyperspec] también es una buena referencia y tiene páginas que definen cada uno de los predicados: [`eq`][hyperspec-eq], [`eql`][hyperspec-eql], [`equal`][hyperspec-equal] y [`equalp`][hyperspec-equalp]
- Recuerda que los cuatro predicados van del más restrictivo al más permisivo en este orden: `eq`, `eql`, `equal`, `equalp`.

## 1. El laberinto de la igualdad de objetos

- Este laberinto necesita el predicado de igualdad más restrictivo disponible.
- [La página de referencia del Hyperspec para `eq`][hyperspec-eq] puede ser útil.

## 2. El laberinto de los números

- Las dos funciones necesarias para esto no tienen por qué usar los mismos predicados de igualdad. La primera sala necesita uno más restrictivo que la segunda.
- [La página de referencia del Hyperspec para `eql`][hyperspec-eql] y para [`equalp`][hyperspec-equalp] puede ser útil.

## 3. El laberinto de los caracteres

- Las dos funciones necesarias para esto no tienen por qué usar los mismos predicados de igualdad. La primera sala necesita uno más restrictivo que la segunda.
- [La página de referencia del Hyperspec para `eql`][hyperspec-eql] y para [`equalp`][hyperspec-equalp] puede volver a ser útil.

## 4. El laberinto de los strings

- Las dos funciones necesarias para esto no tienen por qué usar los mismos predicados de igualdad. La primera sala necesita uno más restrictivo que la segunda.
- [La página de referencia del Hyperspec para `equal`][hyperspec-equal] y para [`equalp`][hyperspec-equalp] puede ser útil.

## 5. El laberinto de los conses

- Las claves para estas salas tendrán que usar predicados de igualdad que estén definidos para comprobar el contenido de los conses.
- [`equal`][hyperspec-equal] es el primero de los predicados que comprueba la igualdad de los elementos _dentro_ de un cons.
- Como has aprendido, [`equalp`][hyperspec-equalp] permite una igualdad más permisiva, incluida la comprobación de igualdad sin distinguir mayúsculas y minúsculas.

## 6. El laberinto de los arrays

- Las claves para estas salas tendrán que usar predicados de igualdad que estén definidos para comprobar el contenido de los arrays.
- [La página de Eli Bendersky sobre la igualdad en Common Lisp][eli-lisp-equality] es una buena explicación.
- Para la primera parte hay que elegir un predicado que no tenga en cuenta el contenido de un array. Tanto [`eq`][hyperspec-eq] como [`eql`][hyperspec-eql] podrían ser útiles.
- [`equalp`][hyperspec-equalp] es el primer predicado que comprueba la igualdad del contenido de un array.
