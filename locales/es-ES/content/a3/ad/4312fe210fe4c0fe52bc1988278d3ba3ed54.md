# Introducción

La clase `TimeZoneInfo` proporciona rutinas para manejar las diferencias entre zonas horarias. La clase `TimeZoneInfo` también contiene métodos que facilitan el trabajo con el horario de verano.

La clase `CultureInfo` admite formatos de fecha y hora dependientes de la configuración regional.

Para permitir la programación multiplataforma, la clase `RuntimeInformation` te permite detectar en qué sistema operativo se está ejecutando tu código: Linux, Windows u OSX.
