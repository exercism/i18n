# Funciones

En JavaScript, las funciones son _objetos de primera clase_, lo que significa que se pueden asignar a variables y propiedades, pasar a otras funciones y devolver desde funciones. Pueden tener propiedades y métodos, igual que cualquier otro _objeto_.

## Entrada: pasar argumentos

Las funciones de JavaScript te permiten pasar argumentos cuando se llaman. Los argumentos siempre [se pasan por valor](https://dev.to/xpbytes/javascript-ruby-and-c-are-not-call-by-reference-23f7). Dicho de otro modo, si una función reasigna un parámetro dentro de la función, el valor no cambiará fuera de ella. Eso no significa que los objetos que se pasan no se puedan mutar.

> [!TIP]
> Cuando se pasa un objeto, lo que se pasa por valor es la referencia a ese objeto. Esto hace que _parezca_ que los objetos se tratan de forma distinta, pero no es el caso.

Un ejemplo de una función que toma dos argumentos y los multiplica es:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Salida: valor devuelto

JavaScript puede devolver un único valor desde una función con la palabra clave `return`, seguida de una expresión. Cuando una función no devuelve nada, el valor devuelto es `undefined`.

Un ejemplo de una función que devuelve un valor es:

```javascript
function multiply(a, b) {
  return a * b;
}

multiply(2, 3);
// => 6
```

## Definir funciones

En JavaScript hay cuatro variantes de funciones:

1. Funciones normales, que pueden devolver cualquier cosa y siempre se ejecutan hasta el final;
2. Funciones asíncronas, que siempre devuelven una `Promise` y se pueden pausar y reanudar con el operador `await`;
3. Funciones generadoras: que siempre devuelven un objeto `Generator` y se pueden pausar y reanudar con el operador `yield`;
4. Funciones generadoras asíncronas; que siempre devuelven un objeto `AsyncGenerator` y se pueden pausar y reanudar con _ambos_ operadores, el `yield` y el `await`.

Para cada una de estas cuatro variantes, hay tres formas de definirlas:

1. usando una declaración
2. usando una expresión
3. usando el constructor

Por último, hay una sintaxis especial para definir _funciones flecha y métodos_.
