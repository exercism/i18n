# Introducción

El código de Elixir se ejecuta en la máquina virtual BEAM. BEAM forma parte del sistema de ejecución de Erlang. Como se inspira en Erlang y comparte su entorno de ejecución, Elixir ofrece una gran interoperabilidad con las bibliotecas de Erlang. Esto significa que los desarrolladores de Elixir pueden usar bibliotecas de Erlang desde su propio código de Elixir. De hecho, en la comunidad de Elixir se desaconseja escribir bibliotecas de Elixir para funcionalidad que ya proporcionan las bibliotecas de Erlang.

Como resultado, ciertas funcionalidades, como las operaciones matemáticas o las funciones de temporizador, solo están disponibles en Elixir a través de Erlang.

La biblioteca estándar de Erlang está disponible para usarla en nuestro código de Elixir sin necesidad de ningún paso adicional.

Las funciones de Erlang se pueden llamar igual que llamamos a las funciones de Elixir, con una pequeña diferencia. Los nombres de los módulos de Erlang son átomos en `snake_case`. Por ejemplo, para llamar a la función `pi/0` de Erlang del módulo `math`, escribirías:

```elixir
:math.pi()
# => 3.141592653589793
```

Las funciones de Erlang más usadas que no tienen equivalente en Elixir son:

- `:timer.sleep/1`, que suspende un proceso durante la cantidad de milisegundos indicada.
- `:rand.uniform/0`, que genera un número decimal aleatorio `x`, donde `0.0 <= x < 1.0`.
- `:io_lib.format/2`, que ofrece un formateo de string al estilo de C (mediante secuencias de control). Con esta función podríamos, por ejemplo, imprimir un número entero en cualquier base entre 2 y 36 o dar formato a un número decimal con la precisión que queramos. Ten en cuenta que esta función, como muchas funciones de Erlang, devuelve un charlist.
- El módulo `math`, que proporciona funciones matemáticas como `sin/1`, `cos/1`, `log2/1`, `log10/1`, `pow/2` y muchas más.

Para descubrir la biblioteca estándar de Erlang, explora el [manual de referencia de STDLIB][erl-stdlib-ref].

[erl-stdlib-ref]: https://www.erlang.org/doc/apps/stdlib/index.html
