# Introducción

Igual que las propiedades, que almacenan datos en tus estructuras y clases, también puedes definir _métodos_, que almacenan funciones en tu estructura o clase.

Los métodos se definen igual que una función normal, solo que dentro del cuerpo de la estructura o la clase. Ten en cuenta que, si una función cambia el valor de una propiedad de una estructura, debe ir precedida de la palabra clave `mutating`. Además, si un método puede cambiar una propiedad, esa propiedad debe definirse con `var` en lugar de `let`, igual que las variables normales.

```swift
struct CharacterStats {
  var health = 0.0
  var speed = 0
  var strength = 0

  mutating func takeHit(_ damage: Double) {
    health = max(0.0, health - damage)
  }
  func canLift(_ weight: Int) -> Bool {
    weight < strength * 100
  }
}
```

Estos métodos se pueden llamar con notación de punto, igual que las propiedades.

```swift
var stats = CharacterStats(health: 72.8, speed: 19, strength: 6)
stats.canLift(500)
// => true
```
