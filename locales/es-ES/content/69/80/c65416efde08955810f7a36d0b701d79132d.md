# Instalación

Necesitarás el gestor de paquetes de Node (npm) para instalar Reason. Sigue las instrucciones [aquí](https://www.npmjs.com/get-npm)

Una vez tengas npm, instala Reason con:
```
npm install -g bs-platform
```

Reason tiene integración con varios editores; consulta [aquí](https://reasonml.github.io/docs/en/editor-plugins.html#officially-supported-editors)

Algunas herramientas de línea de comandos (incluido un REPL que te permite evaluar expresiones de Reason en un shell) se pueden encontrar [aquí](https://github.com/reasonml/reason-cli)
