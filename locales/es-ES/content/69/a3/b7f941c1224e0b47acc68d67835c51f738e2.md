# Escribir el código

Escribe tu código en `src/lib.rs`.
Los ejercicios incluyen un archivo esqueleto en `src/lib.rs` que te mostrará las signaturas del código que tendrás que escribir.

En la mayoría de los ejercicios, lo mejor es escribir todo tu código en el archivo `src/lib.rs`.
Si quieres dividir tu solución en varios archivos, consulta el [capítulo sobre módulos][chapter-modules] del libro de Rust.

[chapter-modules]: https://doc.rust-lang.org/book/ch07-02-defining-modules-to-control-scope-and-privacy.html

## Ejecutar los tests

Para ejecutar los tests, lo único que tienes que hacer es lanzar el siguiente comando:

```bash
$ cargo test
```

Por defecto, solo el primer test está habilitado.
Cuando estés listo para pasar el siguiente test, quita la marca `ignore` de ese siguiente test (`#[ignore]`).
También puedes quitar la marca de todos los tests a la vez si lo prefieres.

No dudes en escribir el menor código posible para que los tests pasen.
Los fallos de los tests te guiarán sobre qué escribir a continuación.

Como Rust comprueba todo el código en tiempo de compilación, puede que tus tests no compilen hasta que escribas el código necesario.
Incluso los tests marcados con `ignore` se comprueban en tiempo de compilación.
Puedes [comentar][comments] los tests que no compilen empezando cada línea con `//`.
Después, cuando estés listo para trabajar en ese test, puedes descomentarlo.
Rust también tiene una macro especial llamada `todo!()`, que puedes usar en partes del código sin terminar para que tu programa compile.

[comments]: https://doc.rust-lang.org/book/ch03-04-comments.html

## Usar librerías

Deberías poder resolver la mayoría de los ejercicios sin usar librerías externas.
Aun así, puedes añadir librerías (la comunidad de Rust las llama **crates**) ejecutando `cargo add crate-name` en el directorio de un ejercicio.

Los tests automáticos del sitio web solo admiten un conjunto predefinido de crates, que puedes encontrar [aquí][local-registry] en la sección `[dependencies]`.
No dudes en abrir una issue o un pull request si quieres que se añada compatibilidad con algún crate concreto.

[local-registry]: https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml
