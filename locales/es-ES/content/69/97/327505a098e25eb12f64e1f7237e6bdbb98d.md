# Instrucciones

En este ejercicio, vas a procesar las líneas de un informe de registro.
Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro distintos:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas; cada una recibe una línea de registro y te pide que hagas algo con ella.

## 1. Obtén el mensaje de una línea de registro

Implementa el método `log_line::message` para devolver el mensaje de una línea de registro:

```cpp
log_line::message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa el método `log_line::log_level` para devolver el nivel de registro de una línea de registro, que debe devolverse en mayúsculas:

```cpp
log_line::log_level("[ERROR]: Invalid operation")
// => "ERROR"
```

## 3. Reformatea una línea de registro

Implementa el método `log_line::reformat`, que reformatea la línea de registro y coloca el mensaje primero y el nivel de registro después, entre paréntesis:

```cpp
log_line::reformat("[INFO]: Operation completed")
// => "Operation completed (INFO)"
```
