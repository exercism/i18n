# Acerca de los bucles `for`

El [bucle `for`](https://docs.oracle.com/javase/tutorial/java/nutsandbolts/for.html) proporciona un mecanismo para ejecutar un grupo de instrucciones repetidamente hasta que se cumpla alguna condición.
El bucle consta de cuatro partes:

```java
for (initialization; test; update) {
    body;
}
```

La `initialization` establece un estado inicial para el bucle y se ejecuta exactamente una vez al comienzo de este.
Normalmente declara y asigna una variable que se usa en la expresión de prueba y en la instrucción de actualización.
Por ejemplo:

```java
int i = 1
```

La expresión `test` comprueba si el bucle debe terminar.
Si se evalúa como true, se ejecutará el cuerpo y, a continuación, la expresión de actualización.
Si se evalúa como false, no se ejecutará ni el cuerpo ni la instrucción de actualización, y la ejecución continúa después de la llave de cierre del bucle.
Normalmente comprueba la variable asignada en el bloque de inicialización.
Por ejemplo:

```java
i <= 10
```

Después de ejecutar el cuerpo del bucle, se ejecuta la expresión `update`.
Normalmente incrementa o decrementa la variable del bucle en algún valor.
Por ejemplo:

```java
i++
```

Un bucle `for` que imprima los cuatro primeros cuadrados tendría este aspecto:

```java
for (int i = 1; i <= 4; i++) {
    System.out.println(i * i);
}

/* =>
1
4
9
16
*/
```

Si se quiere recorrer cada elemento de una colección, es preferible usar un bucle `for-each`, pero también se puede hacer con un bucle `for` así:

```java
for (int i = 0; i < array.length; i++) {
    System.out.print(array[i]);
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `for-each`:

- Puedes empezar o parar en el índice que quieras.
- Puedes usar cualquier condición de terminación (booleana) que quieras.
- Puedes saltarte elementos personalizando cómo se incrementa la variable del bucle.
- Puedes procesar colecciones de atrás hacia delante contando hacia atrás.
- Puedes usar bucles `for` en escenarios que no impliquen colecciones.
