# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro diferentes:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una recibe una línea de registro y te pide que hagas algo con ella.

## 1. Obtén el mensaje de una línea de registro

Implementa la función `message` para que devuelva el mensaje de una línea de registro:

```gleam
message("[ERROR]: Invalid operation")
// -> "Invalid operation"
```

Hay que eliminar los espacios en blanco al principio y al final:

```gleam
message("[WARNING]:  Disk almost full\r\n")
// -> "Disk almost full"
```

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `log_level` para que devuelva el nivel de registro de una línea de registro, en minúsculas:

```gleam
log_level("[ERROR]: Invalid operation")
// -> "error"
```

## 3. Reformatea una línea de registro

Implementa la función `reformat`, que reformatea la línea de registro colocando primero el mensaje y después el nivel de registro entre paréntesis:

```gleam
reformat("[INFO]: Operation completed")
// -> "Operation completed (info)"
```
