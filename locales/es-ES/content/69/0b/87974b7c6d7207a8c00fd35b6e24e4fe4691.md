# Anexo a las instrucciones

## Palabras

- `<bst> ( data-seq -- tree )`: construye un árbol insertando cada
  elemento de `data-seq` en orden.
- `sorted-data ( tree -- seq )`: devuelve los elementos del árbol en
  orden ascendente (recorrido en inorden).

## Jerarquía de tuplas

Un nodo de un árbol binario de búsqueda o bien está *vacío* o bien
*tiene datos más dos subárboles*. Modela eso como una pequeña
jerarquía de herencia:

```factor
TUPLE: bst ;
TUPLE: leaf < bst ;
TUPLE: branch < bst data left right ;
```

`bst` es el padre abstracto; `leaf` es el caso del árbol vacío;
`branch` contiene un valor y dos hijos `bst` (cada uno de los cuales es
a su vez un `leaf` o un `branch`).

## Orden

Compara los datos con `before=?` (de `math.order`), que funciona
tanto con strings como con números: las pruebas usan datos de tipo
string como `"1"`, `"2"`, `"3"`.
