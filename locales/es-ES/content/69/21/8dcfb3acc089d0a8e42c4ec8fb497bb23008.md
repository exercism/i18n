# Introducción

## Namespaces

Una técnica importante para organizar el código es el uso de namespaces.
Dos funciones podrían tener una colisión de nombres, que se puede resolver colocándolas en namespaces distintos.
Los namespaces se pueden anidar, lo que puede ayudar a estructurar bases de código grandes.
Se accede a los namespaces mediante el operador de resolución de scope `::`.

El ejemplo siguiente muestra el uso de dos funciones `foo` distintas.
Se usan juntas anteponiendo sus respectivos namespaces.

```cpp
namespace my_ns {
    int foo() {
        return 44;
    }
    namespace my_inner_ns {
        int baz() {
            return 90;
        }
    }
}
namespace my_other_ns {
    int foo() {
        return -2;
    }
}

int myresult{my_ns::foo() + my_other_ns::foo() * my_ns::my_inner_ns::baz()};
```
