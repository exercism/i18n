# Pistas

## 1. Determina el número total de pájaros que has contado hasta ahora

- Consulta la introducción del ejercicio para ver un ejemplo de cómo usar un bucle `for` para iterar sobre un slice.
- Usa una variable auxiliar para almacenar el recuento total e ir aumentándola a medida que recorres el slice.
- Piensa en cuál sería el valor inicial correcto para esa variable auxiliar.

## 2. Calcula el número de pájaros visitantes en una semana concreta

- Esta tarea es similar a la primera; puedes copiar tu código como punto de partida.
- Piensa en qué índices del slice tendrías que tener en cuenta para la semana número 1 y la número 2, respectivamente.
- Ahora busca una forma general de calcular el primer y el último índice que se deben tener en cuenta.
- Con eso puedes configurar el bucle `for` para que itere solo sobre la sección relevante del slice.

## 3. Corrige un error de recuento

- De nuevo, tienes que configurar un bucle `for` para iterar sobre todo el slice del recuento de pájaros.
- Esta vez solo necesitas visitar una de cada dos entradas del slice.
- Cambia el paso para que la variable del contador se incremente en consecuencia después de cada iteración.
- En el cuerpo del bucle `for` puedes usar el operador de incremento para cambiar in situ el valor de un elemento del slice.
