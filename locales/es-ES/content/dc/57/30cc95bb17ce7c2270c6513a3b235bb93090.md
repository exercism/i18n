# Introducción

## Tipos genéricos

Una definición de colección suele incluir un marcador de posición entre corchetes angulares, a menudo `T` por convención. Una colección así se denomina tipo genérico. Esto permite que quien use la colección especifique qué tipo de elementos almacenar en ella. En el ejemplo de código que aparece a continuación, estamos instanciando un array de strings.

## Arrays

Los arrays en C# son colecciones de valores primitivos o instancias de structs o clases. Se implementan en la biblioteca de clases base como `List<T>`, donde `T` es el tipo del elemento del array. La API expone un amplio conjunto de métodos para crear y manipular arrays.

Se pueden añadir y eliminar elementos de los arrays. Crecen y se reducen según sea necesario.

```csharp
var listOfStrings = new List<string>();
```
