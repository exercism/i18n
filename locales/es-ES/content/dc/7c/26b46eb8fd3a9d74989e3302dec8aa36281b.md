# Anexo a las instrucciones

## Pruebas

Las pruebas ejecutarán algunas operaciones de forma concurrente.
Debes esforzarte por que las operaciones sobre la Account la dejen en un estado consistente.
Por ejemplo: varias goroutines pueden estar depositando y retirando dinero al mismo tiempo, y dos retiradas que ocurran de forma concurrente no deberían poder dejar el saldo en negativo.

Cuando trabajes en local, para comprobar que tu código gestiona correctamente la concurrencia y no introduce carreras de datos, ejecuta las pruebas con el flag `-race` activado.

```bash
cd exercism/project/directory/go/bank-account
go test -race
```
