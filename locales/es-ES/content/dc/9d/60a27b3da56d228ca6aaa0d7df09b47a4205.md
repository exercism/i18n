# Acerca de

A veces, cuando una función recibe muchos argumentos, puede resultar difícil recordar el orden en el que deben indicarse. Para facilitar la legibilidad, Gleam permite etiquetar los argumentos con un nombre.

Para etiquetar un argumento, indica el nombre de la etiqueta antes del nombre del argumento, separados por un espacio.

```gleam
pub fn replace(
  in string: String,
  each target: String,
  with replacement: String
) -> String {
  // ...
}
```

Al llamar a una función con argumentos etiquetados, los argumentos se pueden indicar en cualquier orden. Cada una de estas llamadas a `replace` es equivalente:

```gleam
replace(in: "🍔🍔🍔" each: "🍔", with: "🍕")

replace(each: "🍔", in: "🍔🍔🍔", with: "🍕")

replace(with: "🍕", each: "🍔", in: "🍔🍔🍔")
```

Las etiquetas siempre son opcionales. Aunque una función tenga argumentos etiquetados, se puede seguir llamando sin etiquetas.

```gleam
replace("🍔🍔🍔", "🍔", "🍕")
```

Al definir una función con argumentos etiquetados, todos los argumentos que van después del primer argumento etiquetado también deben estar etiquetados.

```gleam
// This function is valid
pub fn valid(
  x: Int,
  label1 y: Int,
  label2 z: Int
) -> Int {
  // ...
}

// This function is invalid
pub invalid(
  x: Int,
  label1 y: Int,
  z: Int
) -> Int {
  // ...
}
```
