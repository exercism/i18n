# Introducción

Muchos programas necesitan valores (pseudo)aleatorios para simular eventos del mundo real.

Entre los ejemplos más comunes y conocidos están:

- El lanzamiento de una moneda: un valor aleatorio de entre ('H', 'T').
- La tirada de un dado: un número entero aleatorio del 1 al 6.
- Barajar una baraja de cartas: una ordenación aleatoria de un array de cartas.
- La creación de árboles y arbustos en una simulación gráfica en 3D.

Generar valores verdaderamente aleatorios con un ordenador es un [desafío técnico sorprendentemente difícil][why-randomness-is-hard], y por eso también existen los generadores "pseudoaleatorios".

## Generar números aleatorios

En JavaScript, puedes generar números pseudoaleatorios con la función [`Math.random()`][Math.random].
Devuelve un número pseudoaleatorio de coma flotante entre 0 (incluido) y 1 (excluido).

Para obtener un número aleatorio entre _min_ (incluido) y _max_ (excluido), puedes usar una función parecida a esta:

```javascript
function getRandomInRange(min, max) {
  return min + Math.random() * (max - min);
}
getRandomInRange(4, 10);
// => 5.72
```

La mayoría de las técnicas sencillas para devolver un rango de números a partir del número generado aleatoriamente [introducen sesgo][bias].

La técnica de la multiplicación reparte el sesgo por todo el rango, así que será menos evidente y, en la mayoría de los casos, no supondrá un gran problema, pero conviene que lo tengas en cuenta.

## Generar números enteros aleatorios

Para generar un número entero aleatorio, puedes usar `Math.floor()` o `Math.ceil()` para convertir un número generado aleatoriamente en un número entero.
