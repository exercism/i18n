# Introducción

Dado que el nombre del lenguaje que estamos usando, Lisp, significa _LIST Processing_, se podría suponer que el lenguaje tiene herramientas para manejar listas de elementos, ¡y estarías en lo cierto!

Aunque Common Lisp tiene otras estructuras de datos además de las listas, las listas se siguen usando mucho.

Una lista en Common Lisp es una secuencia de elementos. También se la conoce como **cons** (por motivos históricos, sobre todo).
Los propios elementos no tienen que ser del mismo tipo.
Por ejemplo, puedes tener una lista con `1`, `two` y `"III"`.

## Crear listas

Puedes simplemente escribir una lista entrecomillada así: `'(1 two "III")`, y eso hará que se cree y se evalúe una lista (se evalúa como `(1 two "III")`).

También hay dos funciones principales que se usan para crear listas: `list` y `cons`.

`list` acepta cero o más argumentos y se evalúa como una lista creada con esos valores:

```lisp
(list 1 'two "III") ; => (1 two "III")
```

`cons` acepta dos elementos y crea una lista que tiene el primer elemento como su `car` (la cabeza de la lista) y el segundo como su `cdr` (el resto de la lista):

```lisp
(cons 1 2)            ; => (1 . 2) ;; (a list without `nil` as its `cdr` is printed in this way)
(cons 1 nil)          ; => (1)
(cons 1 (cons 2 nil)) ; => (1 2)
```

Las funciones `car` y `cdr` se pueden usar para acceder al `car` y al `cdr` de una lista.

(`first` y `rest` son sinónimos de `car` y `cdr` y funcionan exactamente igual).

## Longitud y acceso aleatorio

La longitud de una lista se puede determinar con `length`.
Una lista vacía tiene longitud cero.

Se puede acceder a un elemento cualquiera con `nth` (ten en cuenta que las listas están indexadas desde cero).

Pedir un índice mayor que la longitud de la lista _no_ es un error.
En su lugar, se evalúa como `nil`:

```lisp
(nth 23 '(short list)) ; => nil
```

También hay varios métodos auxiliares para acceder a los primeros elementos de una lista: `first`, `second`, `third`, y así hasta `tenth`. Práctico, ¿eh?

## Combinar listas

Se pueden combinar dos o más listas con `append`: 

```lisp
(append '(a b c) '(1 2 3)) ; => (A B C 1 2 3)
(append '(a b c) '())     ; => (A B C)
```

Cada argumento que se pasa a `append` tiene que ser una lista.
