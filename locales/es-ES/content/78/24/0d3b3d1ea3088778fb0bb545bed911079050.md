# Introducción

Una forma común de usar el tipo de unión discriminada en F# es representar un conjunto fijo de constantes con nombre, una estructura llamada «enum» en otros lenguajes.

Normalmente, en una unión discriminada de este tipo, cada caso solo puede referirse a exactamente una de esas constantes con nombre.
Sin embargo, a veces es útil referirse a más de una constante.
Para hacerlo, se puede anotar la unión discriminada con el atributo Flags.

Una unión discriminada con el atributo Flags se puede definir de la siguiente manera (usando notación de enteros binarios 0b):

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 0b00000001
| Text = 0b00000010
```

Una instancia de `PhoneFeatures` con el valor `0b00000011` tiene sus flags `Call` y `Text` establecidos.
