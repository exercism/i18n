# Introducción

## Números

En C# hay dos tipos diferentes de números:

- Enteros: números que no tienen dígitos detrás del separador decimal (números sin decimales). Algunos ejemplos son `-6`, `0`, `1`, `25`, `976` y `500000`.
- Números de coma flotante: números con cero o más dígitos detrás del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

Los dos tipos numéricos más comunes en C# son `int` y `double`. Un `int` es un entero de 32 bits y un `double` es un número de coma flotante de 64 bits.

La aritmética se realiza con los operadores aritméticos estándar. Los números se pueden comparar con los operadores de comparación numéricos estándar y con los operadores de igualdad (`==`) y desigualdad (`!=`).

C# tiene dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se pierde ningún dato y no se necesita sintaxis adicional.
2. Conversiones explícitas: se podrían perder datos y se necesita sintaxis adicional en forma de _cast_.

Como un `int` tiene menos precisión que un `double`, convertir de un `int` a un `double` es seguro y, por tanto, es una conversión implícita. Sin embargo, convertir de un `double` a un `int` podría suponer perder datos, así que requiere una conversión explícita.

```csharp
int softCool = 1358938113;
double notLost = 4.8151623;

// implicit cast: no loss of information
double macDebug = softCool;         // 1358938113.0

// explicit cast: possible loss of information 
int somethingLost = (int)notLost;   // 4
```

## Condicionales

En este ejercicio tienes que ejecutar lógica de forma condicional. La forma más habitual de hacerlo en C# es usar un condicional `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condición de un condicional `if` debe ser de tipo `bool`. C# no tiene el concepto de valores _truthy_.
