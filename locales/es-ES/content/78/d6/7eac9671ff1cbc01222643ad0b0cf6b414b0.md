# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [The Emacs Wiki](http://emacswiki.org/) es muy valiosa. Pasa mucho tiempo aquí.
- [The Emacs Editor](http://www.gnu.org/software/emacs/manual/html_node/emacs/index.html) es el manual oficial de GNU Emacs.
- IRC: hay canales de [Libera.Chat](https://libera.chat/) para `#emacs`, `#org-mode` y muchos paquetes
  de Emacs, y hay mucha gente dispuesta a ayudar. Además, con Emacs, IRC está a solo
  `M-x erc` de distancia.
- Matrix: en [Matrix](https://matrix.org/) hay salas para [emacs](https://matrix.to/#/#emacs:matrix.org), [org-mode](https://matrix.to/#/#org-mode:matrix.org) y otros paquetes de Emacs.
  Puedes [unirte al espacio de Emacs en Matrix](https://matrix.to/#/#emacs-space:matrix.org) para hacerte una idea de los canales disponibles.
  Para unirte a Matrix desde Emacs puedes usar el paquete [Ement.el](https://github.com/alphapapa/ement.el).
- [StackOverflow](http://stackoverflow.com/questions/tagged/elisp) y [Emacs StackExchange](https://emacs.stackexchange.com/questions/tagged/elisp) te sirven para buscar tu problema y ver si ya se ha respondido. También puedes preguntar y responder preguntas.
