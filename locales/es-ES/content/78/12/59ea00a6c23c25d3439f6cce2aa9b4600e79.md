## Apéndice

~~~~exercism/note
Las instrucciones anteriores se sincronizan con un repositorio compartido para garantizar la coherencia entre todos los tracks de lenguajes.
Este apéndice ofrece aclaraciones adicionales o modifica las instrucciones según sea necesario para ajustarse mejor a los objetivos del track de Clojure.
~~~~

Es importante no usar funciones integradas existentes con una funcionalidad similar a la de la función que estás implementando, ya que hacerlo reduciría el valor didáctico que el ejercicio pretende aportar.
En Clojure no hay ninguna función integrada para contar el número de bits de un número, así que puedes usar cualquier función de Clojure en tu implementación.
Sin embargo, Java sí incluye una función para este fin: `bitCount`.
