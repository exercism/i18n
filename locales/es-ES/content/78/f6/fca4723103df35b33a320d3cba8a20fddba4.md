# Pistas

## General

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Para acceder a menos de 64 bits de un registro, puedes consultar [el manual de AMD][manual] para saber el nombre adecuado.

## 1. Define `get_box_weight`

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Para acceder a menos de 64 bits de un registro, puedes consultar [el manual de AMD][manual] para saber el nombre adecuado.
- Puedes hacer un retorno anticipado para comprobar cada paso.
- Hay una [instrucción][movzx] para extender valores con ceros.

## 2. Define `max_number_of_boxes`

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Para acceder a menos de 64 bits de un registro, puedes consultar [el manual de AMD][manual] para saber el nombre adecuado.
- Puedes hacer un retorno anticipado para comprobar cada paso.
- Hay una [instrucción][div] para la división sin signo.

## 3. Define `items_to_be_moved`

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Para acceder a menos de 64 bits de un registro, puedes consultar [el manual de AMD][manual] para saber el nombre adecuado.
- Puedes hacer un retorno anticipado para comprobar cada paso.
- La resta funciona igual para números sin signo y con signo.

## 4. Define `calculate_payment`

- Los seis primeros argumentos enteros se pasan a una función en `rdi`, `rsi`, `rdx`, `rcx`, `r8` y `r9`.
- Para acceder a menos de 64 bits de un registro, puedes consultar [el manual de AMD][manual] para saber el nombre adecuado.
- Puedes hacer un retorno anticipado para comprobar cada paso.
- Si obtienes resultados muy grandes cuando esperas un número negativo, es probable que el signo de uno de los números sea incorrecto.
- Hay una [instrucción][cqo] para extender el signo de los valores de `rax` a `rdx`.
- Hay una [instrucción][idiv] para la división con signo.
- El pago se reparte entre tú y un cierto número de trabajadores, y tú también te quedas con el residuo.
- El residuo de una división se guarda en `rdx`.
