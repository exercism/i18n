# Anexo a las instrucciones

## Callable

En PHP existe el concepto de [callable](https://www.php.net/manual/en/language.types.callable.php).

Puede adoptar varias formas, pero nos centraremos en las [funciones anónimas](https://www.php.net/manual/en/functions.anonymous.php).

Es posible crear una función anónima y asignarla a una variable, y llamarla con parámetros:

```php
$double = function ($number) {
    return $number * 2;
};

$double(2); // returns 4
$double(4); // returns 8
```
