# Instrucciones

En este ejercicio vas a escribir código para llevar un registro de un array de lenguajes de programación que quieres aprender en Exercism.

Tienes seis tareas, y todas ellas implican trabajar con arrays.

## 1. Crea un array nuevo

Para llevar un registro de los lenguajes que quieres aprender, necesitarás crear un array nuevo. Define el binding `newList` que contiene un array nuevo y vacío.

```fsharp
newList
// => []
```

## 2. Define un array existente

Actualmente tienes una hoja de papel en la que figuran los lenguajes que quieres aprender: F#, Clojure y Haskell. Define el binding `existingList` para representar este array.

```fsharp
existingList
// => ["F#"; "Clojure"; "Haskell"]
```

## 3. Añade un lenguaje nuevo a un array

A medida que explores Exercism y encuentres lenguajes más interesantes, querrás añadirlos a tu array. Implementa la función `addLanguage` para añadir un lenguaje nuevo al principio de tu array.

```fsharp
addLanguage "TypeScript" ["JavaScript"; "CoffeeScript"]
// => ["TypeScript"; "JavaScript"; "CoffeeScript"]
```

## 4. Cuenta los lenguajes del array

Contar los lenguajes uno a uno es incómodo. Implementa la función `countLanguages` para contar cuántos lenguajes hay en tu array.

```fsharp
countLanguages ["C#"; "Racket"; "Rust"; "Ruby"]
// => 4
```

## 5. Invierte el array

¡Llega un momento en el que te das cuenta de que tu array está ordenado al revés! Implementa la función `reverseList` para invertir tu array.

```fsharp
reverseList ["Prolog"; "C"; "Idris"; "Assembly"]
// => ["Assembly"; "Idris"; "C"; "Prolog"]
```

## 6. Comprueba si el array es emocionante

Aunque te encantan todos los lenguajes, F# tiene un lugar especial en tu corazón. Por eso, un array de lenguajes te entusiasma mucho si:

- El primero del array es F#.
- El segundo elemento del array es F# y el array contiene dos o tres lenguajes.

Implementa la función `excitingList` para comprobar si un array de lenguajes es emocionante:

```fsharp
excitingList ["Nim"; "F#"]
// => true
```
