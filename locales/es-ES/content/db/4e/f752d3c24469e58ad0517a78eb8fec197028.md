# Introducción

## Alias de tipo

### Alias de tipo

Un alias de tipo puede usarse en Gleam para dar un nombre conveniente a un tipo existente que, de otro modo, sería engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias puede usarse fuera del módulo en el que se define. Si se omite `pub`, el alias es privado y no se puede hacer referencia a él desde otros módulos.

## Diccionarios

Los diccionarios en Gleam son la estructura de datos que permite almacenar información en pares clave-valor. En otros lenguajes, también pueden conocerse como arrays asociativos, hashes o diccionarios.

En un diccionario se puede usar cualquier tipo para las claves y los valores, y no se garantiza el orden de sus entradas al acceder a ellas o devolverlas.

### Trabajar con diccionarios

Los diccionarios se crean y manipulan con funciones del módulo `gleam/dict`.

```gleam
// Create an empty dict
let dict1 = dict.new()

// Create a dict with some values
let dict2 = dict.from_list([
  #("name", "Gleam"),
  #("colour", "Pink"),
])

// Add a value to a dict
let dict3 = dict.insert(dict2, "website", "https://gleam.run")

// Get a value from a dict
let name = dict.get(dict3, "name")
// -> Ok("Gleam")
```
