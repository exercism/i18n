# Consejos

## General

- Lee sobre los [errores][getting-started-errors] en la guía Getting Started.
- Lee sobre la [E/S][getting-started-io] en la guía Getting Started.

## 1. Abrir un fichero

- Usa el _despacho dinámico_ para invocar la función de apertura. Repasa el fragmento de código de la introducción.

## 2. Intentar escribir en el fichero

- Utiliza la construcción try-rescue.
- Hay una [función][io-write] en el módulo `IO` que te permite escribir en un dispositivo de E/S.
- Puedes usar el bloque `rescue` para hacer coincidir patrones con el error y devolver la tupla de error.
- Puedes usar el bloque `else` para hacer coincidir patrones con el valor devuelto de una escritura correcta.

## 3. Cerrar el fichero

- Puedes usar el bloque `after` para ejecutar una función tanto si un bloque `try` tiene éxito como si se rescata.
