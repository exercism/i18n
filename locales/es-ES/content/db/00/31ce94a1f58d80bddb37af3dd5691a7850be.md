# Introducción

Los Boolean en Rust se representan mediante el tipo `bool`, cuyos valores pueden ser `true` o `false`.

Rust admite seis operadores de comparación: `==` (igual a), `!=` (distinto de), `>` (mayor que), `<` (menor que), `>=`
(mayor o igual que), `<=` (menor o igual que). Se pueden usar para evaluar la relación entre valores que no son booleanos
y obtener así un valor booleano.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

A diferencia de otros lenguajes, `0` no es `false` ni un valor distinto de cero es `true`.

Rust admite dos operadores booleanos: `||` (o), `&&` (y). Solo se evalúan cuando el operando izquierdo no determina ya
el resultado de la expresión. Es decir, `||` solo evalúa su operando derecho cuando el operando izquierdo se evalúa
como `false`, y `&&` solo cuando este se evalúa como `true`.
