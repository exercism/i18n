# Anexo a las instrucciones

## Palabras

Define una tupla `stopwatch` y un constructor `<stopwatch> ( -- stopwatch )`
que devuelve un nuevo cronómetro en el estado `"ready"`, sin tiempo
transcurrido y sin vueltas anteriores.

Proporciona estas palabras que operan sobre un cronómetro:

- `state ( stopwatch -- str )`: `"ready"`, `"running"` o `"stopped"`.
- `current-lap ( stopwatch -- str )`: el tiempo transcurrido de la vuelta
  actual, como una cadena `"HH:MM:SS"`.
- `total ( stopwatch -- str )`: el tiempo transcurrido combinado de la vuelta
  actual y todas las vueltas anteriores, como una cadena `"HH:MM:SS"`.
- `previous-laps ( stopwatch -- seq )`: un array con las vueltas registradas
  anteriormente, cada una como una cadena `"HH:MM:SS"`.
- `start ( stopwatch -- )`, `stop ( stopwatch -- )`, `reset ( stopwatch -- )`
  y `lap ( stopwatch -- )`: los cuatro comandos de la tabla anterior. Llamar a
  uno desde un estado que no lo permita debe lanzar un error con `throw`.

El tiempo avanza con:

- `advance-time ( str stopwatch -- )`: añade la duración `"HH:MM:SS"` a la
  vuelta actual. Esto solo tiene efecto mientras el cronómetro está en marcha.
