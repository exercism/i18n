# Introducción

## Arrays

La biblioteca central de Cairo implementa un tipo `Array`.

Es similar a los tipos array habituales de otros lenguajes de programación, pero con algunas diferencias clave:

- Los elementos solo se pueden añadir de forma eficiente al final del tipo `Array`, y solo se pueden eliminar de forma eficiente del principio.
- Es imposible asignar manualmente un elemento usando el índice del array.

Los arrays se pueden crear con la función `ArrayTrait::new` y también con la macro `array!`:

```rust
let empty: Array<u32> = ArrayTrait::new();
let one_to_four = array![1, 2, 3, 4];
```

Los elementos se pueden añadir al array con la función `ArrayTrait::append`:

```rust
let mut num_array = array![1, 2, 3, 4];
num_array.append(5);
// -> [1, 2, 3, 4, 5]
```

Los elementos se pueden eliminar del array con la función `ArrayTrait::pop_front`:

```rust
let mut one_to_four = array![1, 2, 3, 4];

one_to_four.pop_front();
// -> [2, 3, 4]
```

Cairo también introduce un tipo `Span` que actúa como una «instantánea» del `Array`.

Cualquier `Array` se puede convertir en un `Span` con la función `ToSpanTrait::span`:

```rust
let one_to_four = array![1, 2, 3, 4];
let one_to_four_span = one_to_four.span();
// -> [1, 2, 3, 4]
```

Convertir un array en un `Span` es muy eficiente, ya que `Span` no es más que una estructura de datos que permite a Cairo «ver» una sección del array, sin modificarla de ninguna forma.

Al convertir un array en un `Span`, Cairo permite realizar más operaciones de las que se permitirían directamente sobre `Array`, como eliminar un elemento del principio del span.

```rust
let one_to_four = array![1, 2, 3, 4];
let mut one_to_four_span = one_to_four.span();
one_to_four_span.pop_back();
// -> [2, 3, 4]
```

Ten en cuenta que tuvimos que hacer mutable `one_to_four_span` con la palabra clave `mut` para invocar `pop_back`, que modifica el span acortando la sección del array que el span está «viendo».
