# Instrucciones

Josh está trabajando en un nuevo juego de rol y necesita tu ayuda para implementar algunas de las mecánicas.

## 1. Preséntate

Implementa la función `introduce`.

Los jugadores sigilosos pueden estar ocultando su nombre y se les presentará como `"Mighty Magician"`.
En caso contrario, usa simplemente el nombre del jugador para presentarlo.

```gleam
introduce(Player(name: None, level: 2, health: 8, mana: None))
// -> "Mighty Magician"

introduce(Player(name: Some("Merlin"), level: 2, health: 8, mana: None))
// -> "Merlin"
```

## 2. Implementa la mecánica de revivir

La función `revive` debe comprobar que el personaje del jugador está realmente muerto (su salud ha llegado a 0).
Si es así, debe devolver una nueva instancia de `Player` con 100 de salud.
En caso contrario, si el personaje del jugador no está muerto, la función `revive` devuelve `None`.

Si el nivel del jugador es 10 o superior, también debe revivir con 100 de maná.
Si el nivel del jugador es inferior a 10, su maná no debe tocarse.
La función `revive` debe conservar el nivel del jugador.

```gleam
let dead_player = Player(name: None, level: 2, health: 0, mana: None)

revive(dead_player)
// -> Some(Player(name: None, level: 2, health: 100, mana: None))
```

Si se llama al método `revive` sobre un jugador cuya salud es 1 o superior, la función debe devolver `None`.

```gleam
let alive_player = Player(name: None, level: 2, health: 42, mana: None)

revive(alive_player)
// -> None
```

## 3. Implementa la mecánica de lanzamiento de hechizos

La función `cast_spell` toma como argumentos un `Int` que indica cuánto maná cuesta el hechizo, así como un `Player`.
Devuelve el jugador actualizado, así como la cantidad de daño que inflige el hechizo lanzado.
Un lanzamiento de hechizo exitoso inflige un daño igual al doble del coste de maná del hechizo.
Sin embargo, si el jugador no tiene maná suficiente, no ocurre nada, el jugador no cambia y no se inflige daño.
Si el jugador ni siquiera tiene una reserva de maná, el intento de lanzar el hechizo debe reducir su salud en el coste de maná del hechizo y no inflige daño.
Ten en cuenta que la salud del jugador no puede estar por debajo de cero (0).

```gleam
let wizard = Player(name: None, level: 18, health: 123, mana: Some(30))
let #(wizard, damage) = cast_spell(wizard, 14)

wizard.mana // -> Some 16
damage      // -> 28
```
