# Instrucciones

En este ejercicio, tienes la tarea de escribir el software de un dispositivo de cifrado que funciona aplicando transformaciones a los datos. Necesitas una forma de crear funciones complicadas de manera flexible combinando funciones más sencillas.

Para cada tarea, devuelve una función anónima que se pueda invocar desde el ámbito de la llamada.

Todas las funciones deben aceptar argumentos enteros. Los números enteros también son adecuados para realizar operaciones a nivel de bits en Elixir.

## 1. Crea un sumador

Implementa `Secrets.secret_add/1`. Debe devolver una función que reciba un argumento y le sume el argumento que se pasa a `secret_add`.

```elixir
adder = Secrets.secret_add(3)
adder.(2)
# => 5
```

## 2. Crea un restador

Implementa `Secrets.secret_subtract/1`. Debe devolver una función que reciba un argumento y le reste el secreto que se pasa a `secret_subtract`.

```elixir
subtractor = Secrets.secret_subtract(2)
subtractor.(3)
# => 1
```

## 3. Crea un multiplicador

Implementa `Secrets.secret_multiply/1`. Debe devolver una función que reciba un argumento y lo multiplique por el secreto que se pasa a `secret_multiply`.

```elixir
multiplier = Secrets.secret_multiply(7)
multiplier.(3)
# => 21
```

## 4. Crea un divisor

Implementa `Secrets.secret_divide/1`. Debe devolver una función que reciba un argumento y lo divida entre el secreto que se pasa a `secret_divide`.

```elixir
divider = Secrets.secret_divide(3)
divider.(32)
# => 10
```

Usa la división entera para que la salida sea compatible con la entrada que esperan las demás funciones.

## 5. Crea un operador «and»

Implementa `Secrets.secret_and/1`. Debe devolver una función que reciba un argumento y realice una operación _and_ a nivel de bits con él y con el secreto que se pasa a `secret_and`.

```elixir
ander = Secrets.secret_and(1)
ander.(2)
# => 0
```

## 6. Crea un operador «xor»

Implementa `Secrets.secret_xor/1`. Debe devolver una función que reciba un argumento y realice una operación _xor_ a nivel de bits con él y con el secreto que se pasa a `secret_xor`.

```elixir
xorer = Secrets.secret_xor(1)
xorer.(3)
# => 2
```

## 7. Crea un combinador de funciones

Implementa `Secrets.secret_combine/2`. Debe devolver una función que reciba un argumento y le aplique las dos funciones que se pasan a `secret_combine` en orden.

```elixir
add_one = Secrets.secret_add(1)
multiply_by_2 = Secrets.secret_multiply(2)
combined = Secrets.secret_combine(add_one, multiply_by_2)

combined.(3)
# => 8
```
