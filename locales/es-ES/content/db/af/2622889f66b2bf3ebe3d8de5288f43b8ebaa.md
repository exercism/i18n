# Instrucciones

Te han tentado para que vuelvas a Hyperia (con su alta inflación) con una tarifa diaria desorbitada.

El Banco Central está pensando en introducir el dólar estadounidense como segunda moneda, por lo que todos los sistemas contables tendrán que adaptarse para gestionar varias monedas.

Te han pedido que implementes el objeto de importe monetario.

## 1. Permite comprobar la igualdad del importe monetario

Modifica el struct `CurrencyAmount` para que gestione la igualdad. Si los dos structs de importe monetario no tienen la misma moneda («USD» o «HD»), debe lanzarse una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(55, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA == amountB
// => true
amountA != amountB
// => false
amountA == amountC
// => ArgumentException
amountA != amountC
// => ArgumentException
```

## 2. Compara importes monetarios

Modifica el struct `CurrencyAmount` para que gestione las comparaciones (solo `>` y `<`). Si los dos structs de importe monetario no tienen la misma moneda («USD» o «HD»), debe lanzarse una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
amountA > new CurrencyAmount(50, "HD")
// => true
amountA < new CurrencyAmount(50, "HD")
// => false
amountA > new CurrencyAmount(50, "USD")
// => ArgumentException
```

## 3. Suma y resta importes monetarios

Modifica el struct `CurrencyAmount` para que gestione la suma y la resta aritméticas (solo `+` y `-`). Si los dos structs de importe monetario no tienen la misma moneda («USD» o «HD»), debe lanzarse una instancia de `ArgumentException`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55, "HD");
CurrencyAmount amountB = new CurrencyAmount(100, "HD");
CurrencyAmount amountC = new CurrencyAmount(55, "USD");
amountA + amountB
// => {155, HD}
amountB - amountA
// => {45, HD}
amountA + amountC
// => ArgumentException
```

## 4. Multiplica y divide importes monetarios

Modifica el struct `CurrencyAmount` para que gestione la multiplicación y la división aritméticas (solo `*` y `/`).

```csharp
CurrencyAmount amountA = new CurrencyAmount(10, "HD");
amountA * 2m
// => {20, HD}
amountA / 2m
// => {5, HD}
```

## 5. Convierte el importe monetario a un `double`

Modifica el struct `CurrencyAmount` para que una instancia se pueda convertir explícitamente a `double`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
(double)amountA
// => 55.5d
```

## 6. Convierte el importe monetario a un `decimal`

Modifica el struct `CurrencyAmount` para que una instancia se pueda convertir implícitamente a `decimal`.

```csharp
CurrencyAmount amountA = new CurrencyAmount(55.5m, "HD");
decimal d = amountA;
// => d == 55.5m
```
