# Introducción

Los espacios de nombres son una forma de agrupar código relacionado y de evitar conflictos de nombres, y, por lo general, están presentes en cualquier base de código que no sea de lo más trivial.

La sintaxis es la siguiente:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Los tipos incluidos en espacios de nombres se referencian fuera del scope del espacio de nombres anteponiendo al nombre del tipo la sintaxis de punto. Como alternativa, y más habitual, puedes colocar una directiva `using` al principio del archivo (o dentro de un espacio de nombres) y usar el tipo sin el prefijo. Dentro del mismo espacio de nombres no hace falta calificar los nombres de tipo.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Puedes asignar un alias a un espacio de nombres con la sintaxis `using MyAlias = MySpace;` y después usar el alias en cualquier lugar en el que se pudiera usar el espacio de nombres.
