# Conversión de tipos

La conversión de tipos también puede conocerse como coerción de tipos.
Hablamos de conversión de tipos cuando dos valores de tipos distintos se convierten al mismo tipo para poder realizar una operación.

```php
$baskets = 5 // int
$apples_per_basket = "3" // string
$baskets * $apples_per_basket
# => 15
```

Esto puede ocurrir de forma implícita (mira el ejemplo anterior) o de forma explícita con una conversión de tipos al estilo de `C`:

```php
$apples_per_basket = "3" // string
$my_number = (int) $apples_per_basket // cast string to int
# => 3 // int
```

Los tipos permitidos para la conversión manual de tipos son: `bool`, `int`, `float`, `string`, `array`, `object`.
Lo más habitual es usar la conversión de tipos para convertir un número entero (`int`) en un número decimal (`float`) o viceversa.
