# Introducción

Una propiedad en C# es un miembro de una clase que da acceso a los datos que hay dentro de esa clase. Quien llama puede establecer u obtener (get) esos datos. Las propiedades pueden estar implementadas automáticamente o tener un campo de respaldo. Constan de un descriptor de acceso set, de un descriptor de acceso get, o de ambos. En otros lenguajes, un «mutator» equivale más o menos a un descriptor de acceso set y un «accessor» equivale más o menos a un descriptor de acceso get, aunque la composición de la sintaxis es completamente distinta.

Al establecer una propiedad, el valor de entrada se puede validar, formatear o manipular de cualquier otra forma; de hecho, se puede ejecutar cualquier operación programática a la que tenga acceso el código de la clase.

De forma similar, al obtener una propiedad los datos se pueden calcular o formatear y, de nuevo, se puede ejecutar cualquier operación programática de la que disponga la clase.

Las propiedades tienen modificadores de acceso (`public`, `private`, etc.) igual que otros miembros de la clase, pero el descriptor de acceso set puede tener un nivel de acceso independiente del descriptor de acceso get y viceversa. Una propiedad no tiene por qué tener ambos descriptores de acceso; puede tener solo uno (get o set).

La sintaxis básica para expresar propiedades puede adoptar dos formas:

## Propiedades respaldadas por un campo o una expresión:

```csharp
private int myField;
public int MyProperty
{
    get { return myField; }
    set { myField = value; }
}
```

## Propiedades implementadas automáticamente

```
public int MyProperty { get; private set; } = 42;
```

La inicialización es opcional.
