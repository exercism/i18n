# Pistas

Usar números complejos para las rotaciones en 2D puede dejar las cosas mucho más limpias y numéricamente más precisas.

## 1. Construir un número complejo a partir de coordenadas cartesianas

- El método [`complex(x, y)`][complex] incorporado es más eficiente que asignar `x + im*y`.
- Consulta la introducción para repasar.

## 2. Construir un número complejo a partir de coordenadas polares

- Hay varias formas equivalentes de hacerlo (p. ej., `exp`, `cis`, `cispi`).
- Consulta la introducción y las instrucciones para repasar más a fondo.

## 3. Realizar una rotación de vector en 2D

- La [fórmula de Euler][euler] es tu aliada aquí y podrías usar tu función `euler`.
- Hay métodos para obtener la parte [real][real] y la parte [imaginaria][imaginary] de un número complejo, ¡o ambas!

## 4. Realizar un desplazamiento radial

- Tu función `euler` puede ser útil, o no...
- El método [`angle`][angle] incorporado se puede usar para encontrar rápidamente el argumento de un número complejo.
- El método [`abs`][abs] se puede usar para encontrar la magnitud de un número complejo.

## 5. Encontrar la canción deseada

- Esta es una buena oportunidad para componer tus funciones `rotate` y `rdisplace`.
