# Introducción

Una *tupla* agrupa varios valores con nombre en un solo objeto, lo que otros lenguajes llaman un registro, un struct o una clase. Cada clase de tupla tiene un conjunto fijo de ranuras con nombre, y Factor genera automáticamente los getters y setters correspondientes.

## Definir una tupla

```factor
TUPLE: point
    { x initial: 0 }
    { y initial: 0 } ;
```

Cada ranura se declara como `{ name initial: default-value }`. Sin una cláusula `initial:`, el valor por defecto es `f`.

## Construir una tupla

El constructor más sencillo es `new`:

```factor
point new .
! => T{ point }
```

`boa` («por orden de argumentos») rellena las ranuras en el orden de declaración desde la pila de datos:

```factor
3 4 point boa .
! => T{ point { x 3 } { y 4 } }
```

La sintaxis literal `T{ class { slot value } … }` te permite construir una tupla con un subconjunto de ranuras establecidas, y se imprime de la misma forma:

```factor
T{ point { x 3 } } .
! => T{ point { x 3 } }
```

Cuando el valor de una ranura coincide con su valor por defecto, se omite al imprimir.

## Leer una ranura

Factor genera un getter `slot>>` para cada ranura. Los getters viven en [`accessors`][accessors]:

```factor
T{ point { x 3 } { y 4 } } x>> .
! => 3
```

## Actualizar una ranura

Los setters se escriben `>>slot` y *mutan* la tupla in situ:

```factor
T{ point { x 3 } { y 4 } } 10 >>x .
! => T{ point { x 10 } { y 4 } }
```

Para no tocar el original, usa `clone` antes:

```factor
: shifted ( pt -- pt' )
    clone 10 >>x ;
```

`change-slot` toma una quotation que transforma el valor actual en el nuevo:

```factor
: shift-x ( pt dx -- pt )
    [ + ] curry change-x ;
```

`change-x` también muta la tupla, así que usa `clone` antes de llamarla si quieres conservar el original.
