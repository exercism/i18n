# Introducción

Se puede acceder a los caracteres individuales de un `String` usando el método de subíndices que se emplea con los arrays.
Sin embargo, los [índices][string-indices] que se usan con los strings _no_ son números enteros y no se puede trabajar con ellos directamente.
En su lugar, hay que calcularlos a partir de otro índice conocido, como `startIndex`, que apunta a la posición del primer carácter de un string no vacío, usando los métodos disponibles en las bibliotecas [`String`][string-docs] y [`NSString`][nsstring-docs] (cuando se importa el módulo `Foundation`, los strings de Swift tienen acceso a todas las propiedades y métodos de NSString).

Por ejemplo, dado el siguiente string:

```swift
let csv = "apple,pear,peach,orange,cherry,lime,goosberry"
```

No se puede escribir `csv[21]` para obtener la «g» de «orange»; en su lugar hay que calcular un valor de tipo `String.Index` y proporcionar ese índice.
Ten en cuenta que estos índices no están pensados para que una persona los interprete directamente.
Son lo que se conoce como _índices opacos_, ya que las personas no necesitan saber qué contienen.

```swift
let index = csv.index(csv.startIndex, offsetBy: 21)
csv[index]
// "g"
print(index)
// prints Index(_rawBits: 1376513)
```

Fíjate, sin embargo, en que si el desplazamiento no da como resultado un índice válido, es decir, si devolviera el índice anterior a `startIndex` o posterior a `endIndex`, la operación lanzará un error y hará que el programa se bloquee.
Para evitar este problema, se puede especificar un índice límite.
Este devuelve un índice opcional y devolverá nil para los índices que, de otro modo, no serían válidos.

```swift
let tooFar = csv.index(csv.startIndex, offsetBy: 200)
// error: Execution was interrupted, reason: EXC_BAD_INSTRUCTION (code=EXC_I386_INVOP, subcode=0x0).
let tooFarButSafe = csv.index(csv.startIndex, offsetBy: 200, limitedBy: csv.endIndex)
// nil
```

Además, los índices no se pueden compartir entre strings.
Por ejemplo, si usas el `index` de la «g» de «orange» calculado antes para indexar el string `fam = "This is my family: 👨‍👩‍👦‍👦, this is our dog: 🐶, this is our cat: 🐱!"`, es decir, `fam[index]`, el programa se bloqueará.

Hay muchas razones para todo esto, pero en esencia todas se reducen a que «Unicode es complicado».

En general, si necesitas acceder a caracteres individuales de forma aleatoria, probablemente te convenga usar otra estructura de datos, como `Array<Character>`.

## Algunos métodos útiles

Swift tiene los métodos `first` y `last` para obtener el primer y el último carácter de un string.
Estos métodos devuelven un carácter opcional, así que si el string está vacío, devolverán nil.

```swift
let str = "Hello, world!"
print(str.first) // Prints Optional("H")
print(str.last)  // Prints Optional("!")
```

También puedes usar los métodos `prefix` y `suffix` para obtener una subcadena de un string.
Estos métodos toman un número entero como argumento y devuelven una subcadena con los primeros o los últimos n caracteres del string.

```swift
let str = "Hello, world!"
print(str.prefix(5)) // Prints "Hello"
print(str.suffix(6)) // Prints "world!"
```
