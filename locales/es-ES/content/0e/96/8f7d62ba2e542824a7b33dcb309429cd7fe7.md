# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando en el directorio del ejercicio:

```shell
make
```

Esto ensambla tu solución, compila las pruebas, las enlaza en un programa RISC-V y lo ejecuta bajo `qemu-riscv32`.
El programa imprime una línea por cada prueba, mostrando si ha pasado, ha fallado o se ha ignorado, y después un resumen.

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen.
Por defecto, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencionado, ya que te permite centrarte en hacer que esa única prueba pase.
Cuando pase, puedes habilitar la siguiente prueba eliminando la línea `TEST_IGNORE();`.
Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!
