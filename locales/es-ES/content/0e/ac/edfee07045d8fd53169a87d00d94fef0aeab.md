# Introducción

La clase `str` ofrece [muchos métodos útiles][str methods] para trabajar con strings y componerlos. Entre ellos hay técnicas de búsqueda, limpieza, división, transformación, traducción y muchas otras.

Los strings son [secuencias][text sequence] de [puntos de código Unicode][unicode code points]. Se puede hacer referencia a los «caracteres» o puntos de código individuales (_strings de longitud 1_) mediante un número `0-based index` a partir de la izquierda, o un número `-1-based index` a partir de la derecha.
Los strings implementan todas las [operaciones comunes de secuencia][common sequence operations].

Se pueden recorrer con la sintaxis `for item in <str>` o `for index, item in enumerate(<str>)`.
También se pueden concatenar con `<str> + <other str>` o `<str>.join(<iterable>)`.

Los strings son _inmutables_, lo que significa que el valor de un objeto `str` en memoria no puede cambiar.
Las funciones o métodos que operan sobre un `str` (_como los que estamos aprendiendo aquí_) devolverán una nueva `instance` de ese objeto `str` en lugar de modificar el `str` original.

A continuación tienes una pequeña selección de métodos de string de Python.
Para ver la lista completa, consulta la [clase str][str methods] en la documentación de Python.


[`<str>.title()`][str-title] analiza un string y pone en mayúscula el primer «carácter» de cada «palabra» que encuentra.
En Python, esto depende en gran medida del [códec de idioma][codecs] que se use y de cómo representa ese idioma concreto las palabras y los caracteres.
También puede haber [reglas de configuración regional][locale] para un idioma o un conjunto de caracteres.


```python
man_in_hat_th = 'ผู้ชายใส่หมวก'
man_in_hat_ru = 'мужчина в шляпе'
man_in_hat_ko = '모자를 쓴 남자'
man_in_hat_en = 'the man in the hat.'

>>> man_in_hat_th.title()
'ผู้ชายใส่หมวก'

>>> man_in_hat_ru.title()
'Мужчина В Шляпе'

>>> man_in_hat_ko.title()
'모자를 쓴 남자'

>> man_in_hat_en.title()
'The Man In The Hat.'
```

[`<str>.endswith(<suffix>)`][str-endswith] devuelve `True` si el string termina con `<suffix>`, y `False` en caso contrario.


```python
>>> 'My heart breaks. 💔'.endswith('💔')
True

>>> 'cheerfulness'.endswith('ness')
True

# Punctuation is part of the string, so needs to be included in any endswith match.
>>> 'Do you want to 💃?'.endswith('💃')
False

>> 'The quick brown fox jumped over the lazy dog.'.endswith('dog')
False
```

[`<str>.strip(<chars>)`][str-strip] devuelve una copia del `str` con los `<chars>` del principio y del final eliminados.
Los puntos de código especificados en `<chars>` no son un prefijo ni un sufijo: se eliminarán **todas las combinaciones** de esos puntos de código empezando por **ambos extremos** del string.
 Si no se especifica nada para `<chars>`, se eliminarán todas las combinaciones de puntos de código de espacio en blanco.


 ```python
# This will remove "https://", because it can be formed from "/stph:". 
>>> 'https://unicode.org/emoji/'.strip('/stph:')
'unicode.org/emoji'

# Removal of all whitespace from both ends of the str.
>>> '   🐪🐪🐪🌟🐪🐪🐪   '.strip()
'🐪🐪🐪🌟🐪🐪🐪'

>>> justification = 'оправдание'
>>> justification.strip('еина')
'оправд'

# Prefix and suffix in one step.
>>> 'unaddressed'.strip('dnue')
'address'

>>> '  unaddressed  '.strip('dnue ')
'address'
```


[`<str>.replace(<substring>, <replacement substring>)`][str-replace] devuelve una copia del string en la que todas las apariciones de `<substring>` se sustituyen por `<replacement substring>`.

La cita que aparece a continuación es de [The Hunting of the Snark][The Hunting of the Snark], de [Lewis Carroll][Lewis Carroll]

```python
# The Hunting of the Snark, by Lewis Carroll
>>> quote = '''
"Just the place for a Snark!" the Bellman cried,
   As he landed his crew with care;
Supporting each man on the top of the tide
   By a finger entwined in his hair.

"Just the place for a Snark! I have said it twice:
   That alone should encourage the crew.
Just the place for a Snark! I have said it thrice:
   What I tell you three times is true."
'''

>>> quote.replace('Snark', '🐲')
...
'\n"Just the place for a 🐲!" the Bellman cried,\n   As he landed his crew with care;\nSupporting each man on the top of the tide\n   By a finger entwined in his hair.\n\n"Just the place for a 🐲! I have said it twice:\n   That alone should encourage the crew.\nJust the place for a 🐲! I have said it thrice:\n   What I tell you three times is true."\n'

>>> 'bookkeeper'.replace('kk', 'k k')
'book keeper'
```
