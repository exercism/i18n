# Instrucciones

Implementa el método clásico para componer mensajes secretos conocido como código cuadrado.

Dado un texto en inglés, devuelve la versión codificada de ese texto.

En primer lugar, la entrada se normaliza: se eliminan los espacios y los signos de puntuación del texto en inglés y el mensaje se convierte a minúsculas.

A continuación, los caracteres normalizados se dividen en filas. Estas filas se pueden considerar como formando un rectángulo cuando se imprimen con saltos de línea entre ellas.

Por ejemplo, la frase

```text
"If man was meant to stay on the ground, god would have given us roots."
```

se normaliza a:

```text
"ifmanwasmeanttostayonthegroundgodwouldhavegivenusroots"
```

El texto plano debe organizarse en un rectángulo. El tamaño del rectángulo (`r x c`) debe decidirse a partir de la longitud del mensaje, de forma que `c >= r` y `c - r <= 1`, donde `c` es el número de columnas y `r` el número de filas.

Nuestro texto normalizado tiene 54 caracteres, lo que da un rectángulo con `c = 8` y `r = 7`:

```text
"ifmanwas"
"meanttos"
"tayonthe"
"groundgo"
"dwouldha"
"vegivenu"
"sroots  "
```

El mensaje codificado se obtiene leyendo hacia abajo por las columnas, de izquierda a derecha.

El mensaje anterior se codifica así:

```text
"imtgdvsfearwermayoogoanouuiontnnlvtwttddesaohghnsseoau"
```

Devuelve el texto codificado en fragmentos que rellenen rectángulos perfectos `(r X c)`, con `c` fragmentos de longitud `r`, separados por espacios. Para las frases a las que les faltan `n` caracteres para completar el rectángulo perfecto, rellena cada uno de los últimos `n` fragmentos con un único espacio final.

```text
"imtgdvs fearwer mayoogo anouuio ntnnlvt wttddes aohghn  sseoau "
```

Fíjate en que, si apiláramos estos fragmentos, podríamos descifrar visualmente el texto cifrado y recuperar el mensaje original:

```text
"imtgdvs"
"fearwer"
"mayoogo"
"anouuio"
"ntnnlvt"
"wttddes"
"aohghn "
"sseoau "
```
