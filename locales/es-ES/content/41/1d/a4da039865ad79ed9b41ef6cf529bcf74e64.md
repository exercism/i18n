# Instalación

En primer lugar, asegúrate de tener Erlang instalado, siguiendo las instrucciones de la página de instalación de [Erlang][1] según corresponda.
[1]: /languages/erlang

## Homebrew para Mac OS X

Actualiza Homebrew a la última versión:

```bash
$ brew update
```

Instala LFE:

```bash
$ brew install lfe
```

## Instalación desde el código fuente

Instala las «developer tools» o los «essential build packages» de tu sistema, `git` y `erl` de Erlang.

Por ejemplo, en Ubuntu 18.04:

```bash
$ sudo apt-get install build-essential git erlang erlang-base-hipe
```

Después puedes descargar y compilar LFE con lo siguiente:

```bash
$ git clone https://github.com/lfe/lfe.git
$ cd lfe
$ make
$ make install
```

Una vez que tengas LFE compilado, puedes iniciar el REPL (sesión interactiva) ejecutando el binario ``lfe``:

```bash
$ ./bin/lfe
```
