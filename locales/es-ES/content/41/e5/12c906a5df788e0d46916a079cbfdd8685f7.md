# Acerca de

Ruby viene con una biblioteca estándar (a menudo abreviada como «stdlib»), una colección de clases para trabajar con cosas como fechas, json y redes.
También ofrece algunas funcionalidades útiles para que trabajar con tu código sea más fácil.

`OpenStruct` forma parte de la biblioteca estándar y te permite crear fácilmente un objeto a partir de un `Hash`.
En lugar de tener que acceder mediante claves de `Hash`, `OpenStruct` te permite usar métodos para acceder a los valores y establecerlos.

Cuando usas clases de la biblioteca estándar, o de cualquier otra biblioteca, necesitas requerir esa clase usando el método `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Una ventaja adicional de esto es que puedes aprovechar un atajo cuando usas la sintaxis de bloque.
Cuando un bloque llama a un único método, puedes sustituir el bloque por `&:` seguido del nombre del método.
Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
