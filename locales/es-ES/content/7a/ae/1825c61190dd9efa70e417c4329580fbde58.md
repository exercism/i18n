# Tests

Para ejecutar el conjunto de tests:
```bash
tclsh exercise.test
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen. De forma predeterminada, solo se ejecuta un test (el primero) cuando ejecutas los tests. Esto es intencionado, ya que te permite centrarte en hacer que ese único test pase. Una vez que pase, puedes habilitar el siguiente test comentando o eliminando el comando `skip` que lo precede.

Como alternativa, para ejecutar todos los tests independientemente de su estado de omisión:
```bash
RUN_ALL=1 tclsh exercise.test
```
