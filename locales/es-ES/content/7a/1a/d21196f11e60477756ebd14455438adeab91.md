# Pistas

## General

- Vuelve a repasar el [concepto de objetos][concept-class-basics] si necesitas refrescar lo básico.
- Lee con atención las instrucciones sobre la posición de los parámetros `x`, `y`, `width` y `height`. Es muy fácil confundirlos.

## 1. Define una clase ProgramWindow

- Recuerda usar la [sintaxis de clases][php-class] para esta tarea.
- Define las [propiedades][php-properties] añadiéndolas a la declaración de la clase.

## 2. Define un constructor para la clase ProgramWindow

- Comprueba que tu función constructora no acepta ningún argumento.
- Comprueba que cada propiedad se establece con el valor entero esperado.

## 3. Añade un método para cambiar el tamaño de la ventana

- Recuerda usar una nueva [clase][php-class] en el fichero `Size.php` para esta tarea.
  - Por convención, los ficheros suelen contener una sola clase.
- El constructor de `Size` debe aceptar argumentos para los valores iniciales de las [propiedades][php-properties] de la clase.
- Crea un método `resize` en el objeto `ProgramWindow` que aplique el cambio usando una instancia de `Size`.

## 4. Añade un método para mover la ventana

- Recuerda usar una nueva [clase][php-class] en el fichero `Position.php` para esta tarea.
  - Por convención, los ficheros suelen contener una sola clase.
- El constructor de `Position` debe aceptar argumentos para los valores iniciales de las [propiedades][php-properties] de la clase.
- Crea un método `move` en el objeto `ProgramWindow` que aplique el cambio usando una instancia de `Position`.
