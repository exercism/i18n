# Binario, octal y hexadecimal

El binario, el octal y el hexadecimal (_también conocido como hex_) son distintos [sistemas de numeración][numeral-systems] con bases diferentes.
El binario es base 2, el octal es base 8 y el hexadecimal es base 16.
Los números enteros normales son base 10 en Crystal.
El binario, el octal y el hexadecimal son representaciones de números enteros.
Esto significa que representan números positivos y negativos (_incluido el cero_) sin fracciones ni decimales, y admiten todas las operaciones que podemos hacer con números enteros.

## Binario

El [binario][binary] es un sistema de numeración en base 2 que utiliza únicamente los dígitos 0 y 1.
Suele representar los estados 0 («apagado») y 1 («encendido») del flujo eléctrico a través de transistores e interruptores en los ordenadores, así como las cargas positivas y negativas de los medios de almacenamiento magnético.
El binario puede representar todos los números enteros que se usan en base 10.

Un fragmento del sistema en base 2 es el siguiente, aunque continúa infinitamente y no se detiene en 128:

| 128      | 64       | 32       | 16       | 8        | 4        | 2        | 1        |
| -------- | -------- | -------- | -------- | -------- | -------- | -------- | -------- |
| 2 \*\* 7 | 2 \*\* 6 | 2 \*\* 5 | 2 \*\* 4 | 2 \*\* 3 | 2 \*\* 2 | 2 \*\* 1 | 2 \*\* 0 |

Así que si queremos representar el número 6, en binario sería: 110

| Place value   | 4   | 2   | 1   |
| ------------- | --- | --- | --- |
| Binary number | 1   | 1   | 0   |

Y la operación sería: `4 + 2 + 0 = 6`

Otro ejemplo: 19

| Place value   | 16  | 8   | 4   | 2   | 1   |
| ------------- | --- | --- | --- | --- | --- |
| Binary number | 1   | 0   | 0   | 1   | 1   |

El número binario sería: 10011
Y la operación sería: `16 + 0 + 0 + 2 + 1 = 19`

## El binario en Crystal

En Crystal, podemos representar literales binarios con el prefijo `0b`.
Si escribimos `0b10011`, Crystal lo interpretará como un número binario y lo convertirá a base 10.

```crystal
0b10011
# => 19

typeof(0b10011)
# => Int32
```

Si escribes un número con el prefijo `0b` que no esté en el sistema binario, se producirá un error de compilación.

```crystal
0b10211
# => Error: unexpected token: "211"
```

### Operaciones con números binarios

Como los números binarios son números enteros, podemos realizar con ellos todas las operaciones que hacemos con números enteros.

```crystal
0b10011 + 0b10011
# => 38

0b10011 * 0b10011
# => 361

0b10011 / 3
# => 6.333333333333333
```

### Convertir a y desde la representación binaria

Crystal convertirá automáticamente un literal binario en `Int32`.
Para convertir un `Int32` en una representación binaria, usa el método [`<int>.to_s(base)`][to_s] con el argumento base establecido en 2.
El método devolverá una representación del número binario como string:

```crystal
19.to_s(2)
# => "10011"
```

Para convertir la representación como string de un binario en un número entero, podemos usar el método [`<int>.to_i(base)`][to_i], pasando la base (2) como argumento:

```crystal
"10011".to_i(2)
# => 19
```

Si se indica una base incorrecta (_o una representación binaria no válida_), se producirá un `ArgumentError`:

```crystal
"011021".to_i(2)
# => Invalid Int32: "011021" (ArgumentError)
```

### Métodos del binario

Existen ciertos métodos que se pueden usar con números enteros para obtener información sobre la representación binaria del número.

[`<int>.bit_length`][bit_length] devolverá el número de bits necesarios para representar el número:

```crystal
19.bit_length
# => 5
```

[`<int>.bit(index)`][bit] devolverá el bit en el índice indicado, empezando por la derecha (_bit menos significativo_):

```crystal
19.bit(0)
# => 1

0b10011.bit(1)
# => 1
```

## Octal

El [octal][octal] es un sistema de numeración en base 8.
Utiliza los dígitos 0, 1, 2, 3, 4, 5, 6 y 7.

En Crystal, podemos representar números octales con el prefijo `0o`.
Al igual que con el binario, Crystal convierte automáticamente una representación octal en un `Int32`.

```crystal
0o123
# => 83
```

Si se añade el prefijo `0o` a un número que no esté en el sistema octal, se producirá un error de compilación.

### Convertir a y desde la representación octal

Al igual que con el binario, podemos usar el método [`<int>.to_s(base)`][to_s] para convertir un `Int32` en una representación octal.
Y podemos usar el método [`<int>.to_i(base)`][to_s] para convertir una representación octal en un `Int32`.

```crystal
83.to_s(8)
# => "123"

"123".to_i(8)
# => 83
```

Al igual que con el binario, si se indica una base incorrecta se producirá un `ArgumentError`.

## Hexadecimal

El [hexadecimal][hexadecimal] es un sistema de numeración en base 16.
Utiliza los dígitos del 0 al 9 y las letras A, B, C, D, E y F.
A es 10, B es 11, C es 12, D es 13, E es 14 y F es 15.

Podemos representar números hexadecimales en Crystal con el prefijo `0x`.
Al igual que con el binario y el octal, Crystal convertirá automáticamente los literales hexadecimales en `Int32`.

```crystal
#=> 0x123
291
```
 
Si se añade el prefijo `0x` a un número que no sea hexadecimal, se producirá un error de compilación.

### Convertir a y desde la representación hexadecimal

Al igual que con el binario, podemos usar el método [`<int>.to_s(base)`][to_i] para convertir un `Int32` en una representación hexadecimal.
Y podemos usar el método [`<int>.to_i(base)`][to_s] para convertir una representación hexadecimal en un `Int32`.

```crystal
291.to_s(16)
# => "123"

"123".to_i(16)
# => 291
```

Al igual que con el binario y el octal, si se indica una base incorrecta se producirá un `ArgumentError`.

## Precisión

Al convertir un número en una representación como string, podemos especificar la precisión del número.
Es decir, la cantidad **mínima** de cifras que se usan para representar el número.
Si el número tiene menos dígitos que la precisión, se añadirán ceros a la izquierda a la representación como string.
Esto se hace pasando el argumento `precision` al método [`<int>.to_s(<base>, precision: <value>)`][to_s].

```crystal
291.to_s(16, precision: 5)
# => "00123"

543.to_s(precision: 2)
# => "543"
```

## Upcase

Al convertir un número en una representación como string, podemos especificar si queremos que las letras del string se conviertan a mayúsculas.
Esto se hace pasando el argumento `upcase` al método [`<int>.to_s(<base>, upcase: <value>)`][to_s].

```crystal
255.to_s(16, upcase: true)
# => "FF"

255.to_s(16, upcase: false)
# => "ff"
```
