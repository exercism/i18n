# Pistas

Todas estas tareas requieren dividir la línea de registro en partes separadas.

- Consulta la función [`split()`][split] para ver las opciones.

## 1. Obtener el mensaje de una línea de registro

- La función `split()` devuelve un vector de strings.
- Tienes que obtener el elemento adecuado de este vector.
- Los espacios en blanco al principio y al final se pueden eliminar con [`strip()`][strip].

## 2. Obtener el nivel de registro de una línea de registro

- La función [`lowercase()`][lowercase] es útil aquí.
- Un string ASCII se puede indexar con un rango.
- El índice `end` hace referencia al último elemento de un vector.
- Como alternativa, la tarea se puede resolver usando [`replace()`][replace] para eliminar los caracteres no deseados.

## 3. Reformatear una línea de registro

- La [interpolación][interpolation] de strings es quizá el enfoque más sencillo aquí.
- Como alternativa, algunas personas (con experiencia en otros lenguajes) pueden preferir [`@sprintf()`][sprintf].
