# Para mantenedores

## Generar tests: `bin/generate_tests.py`

Los archivos de test se generan a partir de los datos canónicos de
[exercism/problem-specifications](https://github.com/exercism/problem-specifications)
con una plantilla de Jinja que se guarda en cada ejercicio en `.meta/template.j2`.

```bash
bin/generate_tests.py bob            # regenerate one exercise
bin/generate_tests.py                # regenerate every exercise that has a template
bin/generate_tests.py --no-pull bob  # skip `git pull` of problem-specifications
```

El script lee problem-specifications de la caché de configlet
(`~/.cache/exercism/configlet/problem-specifications`, que rellena `bin/configlet sync`),
o de un directorio padre llamado `problem-specifications`.
Solo se generan los casos incluidos en `.meta/tests.toml`.

Los literales de string de Fortran no pueden contener escapes como `\n` y `\t`.
El filtro de plantilla `escape_quote_whitespace` los reescribe como
`" // NEWLINE // "`, `" // TAB // "` y `" // CARRIAGE_RETURN // "`,
así que la plantilla debe declarar esas constantes (véase `exercises/practice/bob/.meta/template.j2`).

### Requisitos previos

- Tener CMake y un compilador de Fortran en funcionamiento
- Python 3.12 o superior con `jinja2`
- git

### Flujo de trabajo para añadir un nuevo ejercicio

Usando `bob` como ejemplo:

- Crea una nueva rama, por ejemplo, `git checkout -b exercise-bob`
- Ejecuta `bin/add-exercise bob` (necesita `jq` y `curl`). Esto:
  - descarga configlet y ejecuta `configlet create`, que añade el ejercicio a `config.json` y sincroniza sus documentos, sus metadatos y su `tests.toml` desde problem-specifications
  - ordena `config.json` con `bin/reorder-exercises`
  - copia `exercises/shared/CMakeLists.txt` al directorio del ejercicio
  - escribe una solución esqueleto, un `.meta/example.f90` esqueleto y un `.meta/template.j2` inicial (a partir de `exercises/shared/template.j2`)

  Te pide tu nombre de usuario de GitHub a menos que pases `-a <username>`, y establece la dificultad en 1 a menos que pases `-d <difficulty>`.

- Edita `.meta/template.j2` para que cada caso llame a la función correcta con las entradas correctas y, después, genera los tests:

  ```bash
  bin/generate_tests.py bob
  ```

- Escribe una solución que funcione en `.meta/example.f90`. Sustituye el archivo del estudiante (por ejemplo, `bob.f90`) por un esqueleto de las funciones o subrutinas a las que llaman los tests, para ayudar al estudiante a empezar
- Asegúrate de que todos los tests pasan, ejecutando la compilación completa desde la raíz del repositorio:

  ```bash
  mkdir -p build && cd build
  cmake ..
  cmake --build .
  ctest -V -R bob
  ```

- Ejecuta `bin/reorder-exercises` y `bin/configlet lint`
- Si todo pasa, abre una pull request con tus cambios

### Cambiar `CMakeLists.txt`

Cuando cambies el archivo cmake, actualiza la copia maestra en `exercises/shared/` y usa `bin/update-cmake-files` para copiarla a todos los directorios de ejercicios.
