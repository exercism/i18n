# Acerca de

C# es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación. Elegir un nombre para una [variable][variable] se conoce como definir una variable. Una vez definida una variable, establecer o actualizar un valor se denomina asignación de variable. Una variable se puede definir especificando explícitamente su tipo o usando la [palabra clave `var`][var] para que el compilador de C# infiera su tipo a partir del valor asignado. El uso de `var` se conoce como _inferencia de tipos_.

```csharp
int explicitVar = 10; // Explicitly typed
var implicitVar = 10; // Implicitly typed
```

El valor de una variable se puede asignar y actualizar usando el [operador `=`][assignment]. Una vez definida, el tipo de una variable nunca puede cambiar.

```csharp
var count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

C# es un lenguaje orientado a objetos y requiere que todas las [funciones][function] se definan dentro de una _clase_, que se define con la [palabra clave `class`][classes]. Los objetos (o _instancias_) se crean usando la palabra clave `new`.

```csharp
class Calculator
{
    // ...
}

var calculator = new Calculator();
```

Una función dentro de una clase se denomina _método_. Cada [método][methods] puede tener cero o más parámetros. Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros. Del mismo modo, el tipo devuelto también debe ser explícito. Los valores se devuelven desde los métodos con la [palabra clave `return`][return]. Para permitir que código de otros archivos llame a un método, hay que añadir el modificador de acceso `public`.

```csharp
class Calculator
{
    public int Add(int x, int y)
    {
        return x + y;
    }
}
```

Los métodos se invocan con la sintaxis de punto (`.`) sobre una instancia, indicando el nombre del método que se va a llamar y pasando argumentos para cada uno de los parámetros del método. Los argumentos pueden especificar opcionalmente el nombre del parámetro correspondiente.

```csharp
var calculator = new Calculator();
var sum_v1 = calculator.Add(1, 2);
var sum_v2 = calculator.Add(x: 1, y: 2);
```

Si el método al que se quiere llamar está definido en la misma clase que el método que lo llama, se puede omitir el nombre de la clase.

Si un método no usa ningún _estado_ del objeto, se puede convertir en _estático_ con el modificador `static`. Los métodos estáticos también se invocan con la sintaxis de punto (`.`), pero se invocan sobre la propia clase en lugar de sobre una instancia de la clase.

Si una clase solo tiene métodos estáticos, también se puede convertir en estática con el modificador `static`. Esto expresa la intención de la clase.

```csharp
static class Calculator
{
    public static int Multiply(int x, int y)
    {
        return x * y;
    }
}

Calculator.Multiply(2, 4); // => 8
```

El scope en C# se define entre los caracteres `{` y `}`.

C# admite dos tipos de [comentarios][comments]. Los comentarios de una sola línea van precedidos de `//` y los comentarios multilínea se insertan entre `/*` y `*/`.

Los valores enteros se definen como uno o más dígitos (consecutivos) y admiten los [operadores matemáticos predeterminados][operators].

Un nombre de variable [debe seguir algunas reglas][identifier-names], como empezar por una letra o un guion bajo, y [debería seguir la convención de nombres de C#][naming-guidelines]. Si un nombre de variable entra en conflicto con una [palabra clave de C#][csharp-keywords] reservada, hay que escaparlo usando `@`. No se recomienda usar esa notación, pero puede encontrarse en casos excepcionales, por ejemplo: `var @this`, `var @class` o `var @var`.

Hay un par de conceptos tan fundamentales para un lenguaje de la familia C como C# que aparecen de forma natural en casi cualquier fragmento de código no trivial. Se trata de la [mutación][mutation] y el [scope][scope]. La mutación es la idea de que el valor de una variable puede cambiar a lo largo de la vida de un programa. El scope es la idea de que el valor asociado a un nombre (de un elemento del programa) solo es accesible dentro del «área» de código donde se define. Las principales áreas de código en C# son _clase/struct_ y _función_ (normalmente métodos), pero también pueden incluir el cuerpo de bucles y otras construcciones.
