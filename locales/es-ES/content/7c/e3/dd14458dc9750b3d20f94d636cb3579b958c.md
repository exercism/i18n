# Acerca de

Una extensión estática permite pseudoextender tipos existentes sin modificar su código fuente. Esto se consigue con la instrucción `using`. Las extensiones estáticas pueden ser una herramienta potente que permite ampliar tipos sin cambiarlos realmente.

```haxe
using Main.IntExtender;

class Main {
  public static function main() {
    trace(2.triple()); // 6
  }
}

class IntExtender {
  public static function triple(i:Int):Int {
    return i * 3;
  }
}
```
