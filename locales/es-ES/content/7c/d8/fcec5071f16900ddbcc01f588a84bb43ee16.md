# Instrucciones

En este ejercicio vas a escribir algo más de código relacionado con la preparación y el cocinado de tu magnífica lasaña de tu libro de cocina favorito.

Tienes cinco tareas.
La primera está relacionada con el cocinado en sí, y las otras cuatro con la preparación perfecta.

## 1. Determina si la lasaña está lista

Cuando tienes una lasaña en el horno, quieres saber si ya puedes sacarla o no.
Para asegurarte de que la lasaña no se queme en el horno, normalmente pones un temporizador.
Pero a veces se te olvida.

Escribe una función `cookingStatus` que acepte como parámetro el tiempo restante del temporizador en minutos.
La función tiene tres resultados posibles.

- Si el temporizador muestra `0`, debe devolver `'Lasagna is done.'`.
- Si el temporizador muestra cualquier otro número, el resultado debe ser `'Not done, please wait.'`.
- Si se llama a la función sin un valor de temporizador, el resultado debe ser `'You forgot to set the timer.'`.

El temporizador nunca mostrará un valor inferior a 0.

```javascript
cookingStatus(12);
// => 'Not done, please wait.'

cookingStatus();
// => 'You forgot to set the timer.'
```

## 2. Estima el tiempo de preparación

Para la próxima lasaña que prepares, quieres asegurarte de reservar suficiente tiempo para poder disfrutar del cocinado.
Ya has hecho un plan con todas las capas que tendrá tu lasaña.
Ahora quieres estimar cuánto tardará la preparación a partir de eso.

Implementa una función `preparationTime` que acepte un array de capas y el tiempo medio de preparación por capa en minutos.
La función debe devolver la estimación del tiempo total de preparación a partir del número de capas.
Si se llama a la función sin proporcionar el tiempo medio de preparación, se debe asumir `2` minutos en su lugar.

```javascript
const layers = ['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles'];
preparationTime(layers, 3);
// => 18

preparationTime(layers);
// => 12
```

## 3. Calcula las cantidades necesarias de fideos y salsa

Además de reservar el tiempo, también quieres asegurarte de tener suficiente salsa y fideos para cocinar la lasaña de tus sueños.
Por cada capa de fideos de tu lasaña, necesitarás 50 gramos de fideos.
Por cada capa de salsa de tu lasaña, necesitarás 0,2 litros de salsa.

Define la función `quantities`, que toma un array de capas como parámetro.
A continuación, la función determinará la cantidad de fideos y salsa necesarios para preparar tu comida.
El resultado debe devolverse como un objeto con las claves `noodles` y `sauce`.

```javascript
quantities(['sauce', 'noodles', 'sauce', 'meat', 'mozzarella', 'noodles']);
// => { noodles: 100, sauce: 0.4 }
```

## 4. Añade el ingrediente secreto

Hace un tiempo visitaste a un amigo y comiste lasaña en su casa.
Estaba increíble y tenía algo especial.
El amigo te envió la lista de ingredientes y te dijo que el último elemento de la lista es el «ingrediente secreto» que hizo que la comida fuera tan especial.
Ahora quieres añadir ese ingrediente secreto también a tu receta.

Escribe una función `addSecretIngredient` que acepte dos arrays de ingredientes como parámetros.
El primer parámetro es el array que te envió tu amigo y el segundo es el array de ingredientes de tu propia receta.
La función debe añadir el último elemento del array de tu amigo al final de tu array.
El array que representa tu receta debe modificarse directamente y la función no debe devolver nada.
Sin embargo, el primer argumento no debe modificarse.

```javascript
const friendsList = ['noodles', 'sauce', 'mozzarella', 'kampot pepper'];
const myList = ['noodles', 'meat', 'sauce', 'mozzarella'];

addSecretIngredient(friendsList, myList);
// => undefined

console.log(myList);
// => ['noodles', 'meat', 'sauce', 'mozzarella', 'kampot pepper']
```

## 5. Escala la receta

Las cantidades que aparecen en tu libro de cocina solo dan para una lasaña de dos raciones.
Como la próxima vez quieres cocinar para más gente, quieres calcular las cantidades para distintos números de raciones.

Implementa una función `scaleRecipe` que tome dos parámetros.

- Un objeto de receta que contiene las cantidades necesarias para 2 raciones.
  El formato del objeto puede verse en el ejemplo de abajo.
- El número de raciones que quieres cocinar.

La función debe devolver un objeto de receta con las cantidades necesarias para el número de raciones deseado.
No obstante, quieres conservar la receta original.
Esto significa que, en esta tarea, el argumento de la receta no debe modificarse.

```javascript
const recipe = {
  noodles: 200,
  sauce: 0.5,
  mozzarella: 1,
  meat: 100,
};

scaleRecipe(recipe, 4);
// =>
// {
//   noodles: 400,
//   sauce: 1,
//   mozzarella: 2,
//   meat: 200,
// };

console.log(recipe);
// =>
// {
//   noodles: 200,
//   sauce: 0.5,
//   mozzarella: 1,
//   meat: 100,
// };
```
