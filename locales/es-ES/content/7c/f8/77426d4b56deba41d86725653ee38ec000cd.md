# Sitio web de un equipo de baloncesto

## Historia

Estás trabajando en un sitio web para un equipo de baloncesto. El sitio web muestra un montón de datos, pero, por desgracia, lo que se muestra cambia a menudo. Como los datos se almacenan en un único objeto, no es difícil de hacer, pero requiere mucho tiempo y es aburrido. Por eso has decidido automatizar las cosas.

## Tareas

Estos son ejemplos de tareas que encajan con la historia de automatizar el sitio web:

- Tu objetivo es permitir que el equipo de contenido elija por sí mismo qué datos mostrar. Para ello, especificará una ruta a los datos que se van a mostrar en el editor de contenido del sitio web. Tu tarea es crear una función extract que recibe un objeto y una ruta, separados por un carácter de punto. Devuelve el valor que hay en esa ruta, o un valor por defecto.

## Tareas adicionales

La historia puede continuar, por ejemplo:

- El equipo de contenido está muy entusiasmado con esta nueva funcionalidad y ya ha solicitado que se añada una nueva funcionalidad. Les gustaría poder mostrar los datos de elementos concretos de un array.
