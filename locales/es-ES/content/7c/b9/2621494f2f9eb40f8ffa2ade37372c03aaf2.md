# Instrucciones

Leslie, el alienígena de Lisp, necesita ir de compras. Es muy importante tener una lista de la compra. Hay que añadirle cosas y quitarle cosas.

Claro que un simple lápiz y papel no sirven para un alienígena de Lisp. Es más, «List» es casi toda la palabra «Lisp». Tiene que haber algunas funciones escritas que ayuden a llevar el control de la compra.

¿Puedes ayudar a Leslie a llevar el control de la lista de la compra?

## 1. Crear una nueva lista

Lo primero es que Leslie necesita crear una lista vacía. Una función llamada `new-list` sería perfecta para eso.

```lisp
(new-list) ; => ()
```

Oh, no... Leslie ya tiene algunas cosas en mente, así que necesita una función que reciba tres elementos (por suerte, Leslie solo crea listas de tres elementos. ¡Ni más ni menos!) y cree una nueva lista de la compra con esas cosas. Escribe una función, `list-of-things`, que reciba tres elementos y devuelva una lista con ellos.

```lisp
(list-of-things 'bread 'milk 'butter) ; => '(bread milk butter)
```

## 2. Añadir cosas a la lista.

Antes de ir a la tienda, Leslie mira en la despensa para ver qué necesita. Ayúdale escribiendo la función `add-to-list`, que añade un elemento al principio de una lista.

```lisp
(add-to-list 'butter '(bread)) ; => '(butter bread)
```

## 3. ¿Qué es lo siguiente en la lista?

Mientras compra, Leslie quiere saber qué buscar a continuación. También le gusta echar un vistazo a la lista para ver el segundo, el tercer o incluso el vigésimo tercer elemento (su número de la suerte).

- `first-thing` da como resultado la primera cosa de la lista
- `second-thing` da como resultado la segunda cosa
- `third-thing` da como resultado la tercera cosa
- `twenty-third-thing` da como resultado la vigésima tercera cosa

```lisp
(first-thing '(bread butter milk)) ; => 'bread
(second-thing '(bread butter milk)) ; => 'butter
(third-thing '(bread butter milk)) ; => 'milk
```

## 4. Quitar algo de la lista

Leslie quiere encontrar el primer elemento de la lista y quitarlo de la estantería. Ayúdale escribiendo una función `remove-first-item` que da como resultado una lista con todo menos el primer elemento de la lista de entrada.

```lisp
(remove-first-item '(bread butter milk)) ; => '(butter milk)
```

## 5. Listas más grandes a partir de listas más pequeñas

¡Leslie se ha dado cuenta de que ha hecho sin querer dos listas de la compra en lugar de una! Escribe una función, `list-append`, que devuelve una lista con los elementos de la primera lista seguidos de los de la segunda.

```lisp
(list-append '(bread salt) '(butter milk)) ; => '(bread salt butter milk)
```

## 6. ¿Cuánto más larga?

Leslie empieza a preocuparse de que esta compra le lleve un buen rato. ¿Cuántas cosas hay exactamente en esta lista? Escribe una función `just-how-long` que le diga cuánto mide su lista.

```lisp
(just-how-long '(bread milk butter salt)) ; => 4
```
