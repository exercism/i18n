## Opcionales

Swift usa [_opcionales_][optionals] para permitir que los programadores representen la posible ausencia de un valor.
Un opcional es un tipo que puede contener un valor o ser [`nil`][nil], que representa la ausencia de un valor.
Usar un opcional requiere que el programa compruebe si el valor existe de verdad antes de desenvolverlo y usarlo.

Cualquier tipo puede convertirse en un opcional añadiendo un `?` al final del nombre del tipo.
Así, un número entero opcional tendría el tipo `Int?` y un string opcional tendría el tipo `String?`.
Definir constantes o variables de tipo opcional y asignarles valores se hace igual que con los valores de tipos no opcionales.

```swift
let x: Int? = 42
var y: String? = "Hello"
y = "Goodbye"
```

Puedes asignar la ausencia de un valor a una variable de tipo opcional asignándole el valor especial `nil`.
`nil` se puede usar con todos los tipos opcionales, pero los `nil` asignados a dos tipos opcionales distintos no tienen el mismo tipo y no se pueden intercambiar ni siquiera comparar.

```swift
let intOpt: Int? = nil
let stringOpt: String? = nil

intOpt = stringOpt
// Compiler error: Cannot assign value of type 'String?' to type 'Int?'

intOpt == stringOpt
// Compiler error: Binary operator '==' cannot be applied to operands of type 'Int?' and 'String?'
```

Ten en cuenta también que, aunque `nil` se puede asignar a cualquier tipo opcional, no se puede asignar a un tipo no opcional (aunque en realidad no contenga `nil`).
Y a los métodos que esperan un tipo no opcional no se les puede pasar un tipo opcional sin desenvolverlo primero.

```swift
var x: Int = 42
var y: Int? = 42

y = x
// Works fine
x = y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
x + y
// error: value of optional type 'Int?' must be unwrapped to a value of type 'Int'
```

## Uso de los opcionales

Como los tipos opcionales no son los mismos tipos que sus tipos base, ambos no se pueden usar de la misma manera.
Por ejemplo: `Int("123") + 1` da como resultado un error del compilador: «Value of optional type 'Int?' must be unwrapped to a value of type 'Int'».
Esto se debe a que `Int("123")` devuelve un tipo `Int?` opcional, no un tipo `Int`, ya que si el string no se puede convertir en un número entero, el resultado será `nil`.
Para acceder al `Int` resultante de la conversión, primero hay que «desenvolverlo».

En Swift, esto se hace normalmente con las construcciones `if-let` y `guard-let` para el [_enlace opcional_][optional-binding], que comprueban si el valor es `nil` y, si el valor existe, siguen una ruta de código en la que el valor desenvuelto se vincula a un nombre proporcionado, y otra ruta distinta si se encontró `nil`.

```swift
if let safeNum = Int("123") {
	let sum = safeNum + 1
	…
} else {
  // code for the case where nil was found -- may be left out
}
```

Merece la pena señalar que la variable `safeNum` tiene el tipo `Int`, no `Int?`.
En el ejemplo siguiente, `num` es de tipo `Int?` y `safeNum` es de tipo `Int`.

```swift
let num = Int("123")
if let safeNum = num {
  // num is of type Int
}
```

Este _enlace opcional_ es importante porque desenvuelve (o «elimina») el tipo opcional del valor, lo que permite usarlo como un valor no opcional.
Si solo haces una comprobación condicional de si el valor es `nil`, el valor seguiría siendo de tipo opcional:

```swift
let num = Int("123")
if num != nil {
  // num is of type Int?
}
```

La opción `guard-let` también se puede usar en los casos en los que se desee un retorno anticipado:

```swift
guard let num = Int("123") else { return nil }
let sum = num + 1
…
```

## Comparación de opcionales

Ten en cuenta que, aunque el tipo base de un par de opcionales se pueda comparar con los operadores de comparación estándar, los propios opcionales no se pueden comparar.
Solo se puede comprobar si son iguales.
Dos opcionales son iguales si ambos son `nil` o si los valores que envuelven son iguales dentro de sus tipos base.

No obstante, se puede escribir código para hacer una comparación personalizada de dos valores opcionales.
A continuación hay un ejemplo de una instrucción `switch` que devolverá `true` solo si ambos valores opcionales no son `nil` y el primer valor es menor que el segundo.
Para ello usa el _patrón opcional_ `varName?`, que solo coincide con opcionales que no son `nil`, y vincula el valor que hay dentro del opcional al nombre `varName`.

```swift
switch (optionalA, optionalB) {
case let (valA?, valB?): return valA < valB
default: return false
}
```
