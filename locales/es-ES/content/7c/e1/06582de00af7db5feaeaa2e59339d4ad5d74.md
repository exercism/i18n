# Introducción

Aunque las expresiones `if/else` sirven para ejecutar lógica condicional, Haskell también ofrece una forma más potente de ejecutarla: la [coincidencia de patrones][pattern-matching].
Con la coincidencia de patrones, un valor se puede comprobar contra uno o varios _patrones_.
Un ejemplo de ese tipo de patrón es el _patrón constante_, que comprueba un valor contra una constante (por ejemplo, `1` o `"hello"`).

Al definir funciones, puedes definir cuerpos de función distintos para patrones distintos.
Esto da lugar a un código limpio, sencillo y legible.
Puedes usar la coincidencia de patrones con cualquier tipo de datos: números, caracteres, listas, tuplas, etc.

Por ejemplo, una función trivial que recibe un número entero (`Int`) y lo acerca _1_ a _0_ podría escribirse así:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

La coincidencia de patrones empieza a brillar cuando se usa junto con otros patrones, por ejemplo el _patrón de variable_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

El ejemplo anterior trata igual todas las entradas distintas de _0_ y produciría resultados incorrectos con números negativos.
Esto se puede resolver con patrones condicionales, conocidos como _guardas_, que se expresan con el símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

En los ejemplos anteriores no todas las entradas posibles tienen un patrón que coincida.
El compilador lo detectará y mostrará un aviso.
Esta es una funcionalidad muy útil de Haskell, que ayuda a asegurar que se cubren todos los caminos posibles para evitar errores en tiempo de ejecución.
Se conoce como _comprobación exhaustiva_.
Para resolver el aviso, tienes que contemplar todos los casos.
Dentro de las _guardas_ puedes usar la expresión `otherwise` como azúcar sintáctico de `True` para capturar todos los patrones restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

La coincidencia de patrones comprueba un valor contra cada patrón de arriba abajo, hasta que encuentra un patrón que coincide y ejecuta la lógica asociada a ese patrón.
**¡El orden de los patrones importa!**
