# Pistas

## 1. Crear un nuevo array

- Se puede crear un array vacío con la sintaxis `[]`.

## 2. Definir un array existente

- Se pueden crear arrays con varios elementos con la sintaxis `["a", "b", "c"]`.

## 3. Añadir un nuevo lenguaje a un array

- Se puede usar la sintaxis de propagación (`[x, ..list]`) para añadir un elemento al principio de un array.

## 4. Contar los lenguajes del array

- Hay una función en el módulo `gleam/list` para [contar los elementos de un array][length].

## 5. Invertir el array

- Hay una función en el módulo `gleam/list` para [invertir un array][reverse].

## 6. Comprobar si el array es emocionante

- Puedes usar la coincidencia de patrones con los patrones de array y de propagación de arrays para hacer coincidir estructuras de array concretas.

[reverse]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#reverse
[length]: https://hexdocs.pm/gleam_stdlib/gleam/list.html#length
