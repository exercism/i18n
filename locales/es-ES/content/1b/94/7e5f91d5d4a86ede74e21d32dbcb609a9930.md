# Sin literales de números enteros

Elixir tiene una [sintaxis especial](https://elixir-lang.org/getting-started/binaries-strings-and-char-lists.html#unicode-and-code-points) para escribir números enteros que corresponden a [puntos de código Unicode](https://en.wikipedia.org/wiki/Code_point): puedes usar un `?` delante del literal de carácter para revelar su punto de código.

Por ejemplo,

```elixir
?a === 97
?\s === 32
?ß === 223
?互 === 20114
```

En el contexto de manipular puntos de código, esta notación es mucho más legible que los números, así que deberías preferirla siempre.
