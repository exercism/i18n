# Anexo de instrucciones

## Sobre Enum

La instrucción enum te permite crear un conjunto de etiquetas con tipado fuerte.
Puedes usar esa enumeración en el código sin tener que analizarla ni comprobar errores ortográficos.

Las enumeraciones se representan internamente como números enteros con un valor inicial de cero.
Por defecto, PowerShell asigna a la primera etiqueta de la lista el valor cero, y asigna a las etiquetas restantes números enteros consecutivos.

Ejemplo:
```pwsh
Enum Fruits {
    APPLE       #default internal value 0
    ORANGE      #default internal value 1
    MANGO       #default internal value 2
}

$myFavFruit = [Fruits]::APPLE
Write-host $myFavFruit => APPLE
``````

Para obtener más información sobre Enum en PowerShell, consulta el [módulo Enum.](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_enum)
