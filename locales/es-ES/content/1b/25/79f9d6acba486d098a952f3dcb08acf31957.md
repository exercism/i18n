# Instrucciones

Tu tarea es generar los laberintos perfectos para Mickey y Minerva, es decir, aquellos que tienen una sola solución y ninguna sección aislada.
Esto es lo que necesitas saber:

- El laberinto tiene forma rectangular, con una abertura al principio y otra al final.
- El laberinto tiene salas y pasajes que se cruzan en ángulos rectos.
- El programa debe aceptar dos parámetros: filas y columnas. El laberinto debe tener un tamaño de entre 5 y 100 celdas.
- Un laberinto que mide `x` columnas de ancho e `y` filas de alto debe medir `2x + 1` caracteres de ancho y `2y + 1` caracteres de alto.
- Si no se proporciona una semilla, genera un laberinto aleatorio. Si se proporciona la misma semilla varias veces, el laberinto resultante debe ser el mismo cada vez.
- Usa [caracteres de dibujo de cajas][Box-drawing] para dibujar los muros y un símbolo de flecha (⇨) para la entrada a la izquierda y la salida a la derecha.

¡Ya es hora de crear algunos laberintos perfectos para estos ratones aventureros!

## Ejemplos

1. Un laberinto cuadrado pequeño de 5x5 celdas (o 11x11 caracteres)

    ```text
    ┌───────┬─┐
    │       │ │
    │ ┌─┬── │ │
    │ │ │   │ ⇨
    │ │ │ ──┤ │
    ⇨ │ │   │ │
    ┌─┤ └── │ │
    │ │     │ │
    │ │ ────┘ │
    │         │
    └─────────┘
    ```

2. Un laberinto rectangular de 6x18 celdas

    ```text
    ┌───────────┬─────────┬───────────┬─┐
    │           │         │           │ │
    │ ┌───────┐ │ ┌─┐ ──┐ └───┐ ┌───┐ │ │
    │ │       │ │ │ │   │     │ │   │   ⇨
    │ └─┐ ┌─┐ │ │ │ ├── ├───┐ │ │ ──┼── │
    │   │ │ │   │   │   │   │ │ │   │   │
    └── │ │ ├───┴───┤ ┌─┘ ┌─┘ │ ├── │ ──┤
    ⇨   │   │       │ │   │   │ │   │   │
    ┌─┬─┴─┐ └─┐ ┌─┐ │ └─┐ │ ┌─┘ │ ──┴─┐ │
    │ │   │   │ │ │ │   │   │   │     │ │
    │ │ │ └── │ │ │ └── │ ──┘ ┌─┘ ──┐ │ │
    │   │       │       │     │     │   │
    └───┴───────┴───────┴─────┴─────┴───┘
    ```
