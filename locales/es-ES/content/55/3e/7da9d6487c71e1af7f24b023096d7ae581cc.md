# Pistas

## General

- [Tutorial sobre cómo trabajar con enumeraciones][docs.microsoft.com-enumeration-types].

## 1. Analizar el nivel de registro

- Existe un [método para obtener una parte de un string][docs.microsoft.com_system_string_substring].
- Puedes usar una [instrucción `switch`][docs.microsoft.com_keyword_switch] para gestionar de forma elegante los distintos niveles de registro.

## 2. Admitir un nivel de registro desconocido

- Existe un [caso especial de `switch`][docs.microsoft.com_keyword_switch_default] que se puede usar para capturar los casos no especificados.

## 3. Convertir una línea de registro a formato corto

- Se pueden [asignar valores específicos a los miembros de una enumeración][docs.microsoft.com_creating-an-enumeration-type].
- Convertir una enumeración a un número se puede hacer mediante una [conversión de tipo][docs.microsoft.com_enumeration-types-casting] o usando una [cadena de formato][docs.microsoft.com_system.enum.tostring].
