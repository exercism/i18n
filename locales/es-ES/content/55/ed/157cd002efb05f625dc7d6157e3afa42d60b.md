# Instrucciones

El puerto de Palermo es un puerto ajetreado, con muchos barcos entrando y saliendo.
Desde hace mucho tiempo cuenta con un sistema manual para llevar el control de los barcos que hay actualmente en el puerto.
Este sistema es muy propenso a errores, y el jefe del puerto ha decidido sustituirlo por un sistema informatizado.

El jefe del puerto te ha contratado para implementar el nuevo sistema.
El sistema tiene que gestionar identificadores de barcos, pero también de destinos.

## 1. Crea el identificador del puerto

Lo primero que tienes que hacer es crear el identificador del puerto de Palermo.
El identificador son las cuatro primeras letras del nombre del puerto, en mayúsculas.

Define la constante `Port::IDENTIFIER` como un símbolo con el valor `:PALE`.
    
```ruby
Port::IDENTIFIER 
# => :PALE
```

## 2. Obtén los identificadores de otros puertos

El programa también tendrá que gestionar otros puertos, así que necesitas crear identificadores para ellos también.
Al puerto le gustaría que el sistema estuviera automatizado y, dado que los puertos usan convenciones de nombres distintas, los identificadores deben generarse a partir del nombre del puerto.
El identificador son las cuatro primeras letras del nombre del puerto, en mayúsculas.

Define el método `Port.get_identifier` para que reciba un string como argumento y devuelva el identificador como símbolo para ese puerto.

```ruby
Port.get_identifier("Hamburg") 
# => :HAMB
```

## 3. Determina en qué terminal debe atracar un barco

El puerto tiene dos terminales y el sistema necesita determinar en qué terminal debe atracar un barco.
La terminal viene determinada por el identificador del barco.

El identificador se compone de 2 partes: la primera son 3 letras en mayúscula que indican qué carga transporta el barco, y después 3 números, que son el identificador único del barco.

Si el identificador del barco indica **OIL** o **GAS**, el barco debe atracar en la terminal **A**.
En caso contrario, el barco debe atracar en la terminal **B**.

Define el método `Port.get_terminal` para que reciba un símbolo como argumento, que es el identificador del barco.
El método debe devolver la terminal como símbolo.

```ruby
Port.get_terminal(:OIL123)
# => :A
```
