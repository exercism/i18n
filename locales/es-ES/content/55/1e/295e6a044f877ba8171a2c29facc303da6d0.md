# Conjuntos

Un [`set`][type-set] es una colección _mutable_ y _desordenada_ de objetos [_hashable_][hashable].
Los miembros de un conjunto deben ser distintos: no se permiten elementos duplicados.
Pueden contener varios tipos de datos diferentes e incluso estructuras anidadas como una `tuple` de `tuples`, siempre que todos los elementos se puedan _hashear_.
Los conjuntos también vienen en una variante inmutable, [`frozenset`][type-frozenset].

Los conjuntos se usan sobre todo para eliminar rápidamente los duplicados de otras estructuras de datos o agrupaciones de elementos.
También se usan para hacer comparaciones eficientes cuando no se necesitan secuencias ni un seguimiento de duplicados.

Como otros tipos de colecciones (_diccionarios, arrays, tuplas_), los `sets` admiten:
- Iteración mediante `for item in <set>`,
- Comprobación de pertenencia mediante `in` y `not in`,
- Cálculo de la longitud mediante `len()`, y
- Copias superficiales mediante `copy()`.

Los `sets` no admiten:
- Indexación de cualquier tipo
- Ordenación mediante clasificación o inserción
- Segmentación
- Concatenación mediante `+`


Comprobar la pertenencia en un `set` tiene una complejidad temporal constante (de media), frente a comprobar la pertenencia en un `list` o un `string`, donde la complejidad temporal crece a medida que aumenta la longitud de los datos.
Métodos como `<set>.union()`, `<set>.intersection()` o `<set>.difference()` también tienen una complejidad temporal constante (de media).

[hashable]: https://docs.python.org/3.7/glossary.html#term-hashable
[type-frozenset]: https://docs.python.org/3/library/stdtypes.html#frozenset
