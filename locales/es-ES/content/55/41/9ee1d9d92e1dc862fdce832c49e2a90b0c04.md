# Introducción

## Tipos anidados

Los tipos de C# se pueden definir dentro del scope de un class o struct. El tipo contenedor proporciona una especie de espacio de nombres. El acceso al tipo se realiza a través del tipo contenedor con la sintaxis de punto.

```csharp
class Outer
{
    public interface IInner {}
    public enum EInner {}
    public class CInner {}
    public struct SInner {}
}

var outer = new Outer();
var inner = new Outer.CInner();
```

Puedes establecer niveles de acceso para los tipos internos.

Los miembros privados del tipo contenedor están en el scope de los miembros del tipo interno, pero no al revés.
