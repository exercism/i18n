Raku es un lenguaje de programación increíblemente rico, flexible y potente.
Su flexibilidad permite a los programadores escribir código expresivo que se ajuste a su propio estilo.

Raku es un lenguaje extenso, con mucha profundidad para aprender, explorar y experimentar.
Este temario pretende cubrir los fundamentos para que puedas empezar.

La programación orientada a objetos es el corazón de Raku, aunque no impone prácticas de programación orientada a objetos.
Debido a su naturaleza orientada a objetos, este temario hará referencia con frecuencia a [objetos, clases y métodos][object-orientation].

## Variables

En basics solo usaremos [variables][variables] escalares para mantener las cosas simples.

Las variables escalares son [identificadores][identifiers] precedidos por el sigilo `$`.

Las variables escalares pueden contener prácticamente cualquier cosa y tienen un tipo predeterminado [`Any`][Any].

La mayoría de las variables que uses necesitarán una [declaración][variable-declarator].
Por ahora, quédate con [`my`][my] y [`constant`][constant].

```raku
my $foo;
constant $BAR;
```

## Subrutinas

Una subrutina se declara con el declarador [`sub`][sub-declarator].

A una declaración `sub` le sigue un [identificador][identifiers] opcional, después una [firma][signatures] opcional y, por último, un [bloque][blocks].

Las subrutinas (entre otras cosas) se pueden exportar añadiendo el rasgo [`is export`][exporting].

Se puede llamar a una subrutina con un operador [postcircunfijo `( )`][postcircumfix-()] sobre el identificador.

```raku
sub foo ($bar) is export { ... } # Subroutine definition

foo($bar); # Subroutine call
```

## Operadores

Raku tiene una amplia variedad de [operadores][operators].
Usaremos algunos operadores matemáticos básicos en Raku, como `+` y `-`, para los ejercicios del concepto basics.

```raku
say 0.1 + 0.2 - 0.3;
# Raku is not like other languages -> https://0.30000000000000004.com/#raku
```

Puedes definir tus propios operadores en Raku fácilmente si quieres.
La mayoría de los operadores integrados también están disponibles como subrutinas.

## Paquetes y módulos

En Raku hay varios tipos de [paquetes][package-declarator]. En basics solo usaremos `module`.

Para declarar un archivo entero como `module`, la declaración del módulo se precede con `unit`.

```raku
unit module Foo;

sub bar () { ... }
```

## Comentarios

Raku tiene comentarios [de una línea][single-line-comments] y [de varias líneas o incrustados][multi-line-comments].

Los comentarios de una línea empiezan con `#` y continúan hasta el final de la línea.

Los comentarios de varias líneas o incrustados empiezan con una almohadilla seguida de un acento grave y un carácter de puntuación de apertura de Unicode.
Terminan con un carácter de cierre correspondiente.

```raku
# This is a single-line comment

#`(
    This is a
    multi-line/embedded comment
)
```

## Convenciones de estilo

Los [identificadores][identifiers] de variables y subrutinas en Raku se escriben en `kebab-case`.
Las constantes se escriben en `ALL-CAPS`.
Los nombres de los paquetes se escriben en `PascalCase`.
