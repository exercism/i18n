# No cambies las firmas proporcionadas

Como se menciona en las instrucciones, no deberías modificar las firmas de `makeChest` y `makeTreasureChest`.
Deben permanecer exactamente así:

```elm
makeChest : String -> treasure -> Chest treasure {}

makeTreasureChest : Chest treasure { conditions | securePassword : (), uniqueTreasure : () } -> TreasureChest treasure
```
