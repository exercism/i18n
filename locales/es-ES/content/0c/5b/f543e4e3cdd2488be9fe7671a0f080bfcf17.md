# Acerca de

ClojureScript es un compilador de Clojure dirigido a JavaScript. Emite código JavaScript compatible con el modo de compilación avanzada del compilador optimizador Google Closure.

## ¿Por qué Clojure?

Clojure es un lenguaje de programación dinámico y de propósito general que admite el desarrollo interactivo. Clojure es un lenguaje de programación funcional que incluye un rico conjunto de estructuras de datos inmutables y persistentes. Como dialecto de Lisp, tiene una filosofía de código como datos y un potente sistema de macros.

## ¿Por qué JavaScript?

La expansión del navegador y de las aplicaciones web ha dado a JavaScript un alcance exclusivo que ningún otro lenguaje ha igualado. Debido a su importancia, los motores de JavaScript también reciben una amplia labor de investigación y optimización, lo que permite a JavaScript competir en rendimiento con muchas plataformas más consolidadas, como la JVM.

## ¿Por qué Google Closure?

Como proveedores de algunas de las aplicaciones web de cliente y servidor más complicadas que se usan hoy en día, Google ha invertido mucho en crear la biblioteca Closure y el compilador Closure, que trabajan juntos para hacer posible la optimización de todo el programa, lo que da lugar a programas con tiempos de carga mínimos incluso cuando se usan muchas bibliotecas.

## Oportunidad

ClojureScript combina el alcance de la plataforma JavaScript, la flexibilidad y el desarrollo interactivo de Clojure, y la optimización de todo el programa de Google Closure para ofrecer el lenguaje más potente para programar para la web.
