# Carteles personalizados

## Historia

En este ejercicio escribirás código para ayudar a una empresa de carteles a crear mensajes personalizados para sus carteles.

## Tareas

Estas son tareas de ejemplo que encajan con la historia de un cliente que diseña un cartel personalizado:

- Crear un conjunto de strings útiles
- Crear un conjunto de caracteres útiles
- Combinar frases para construir mensajes
- Construir un cartel de graduación
- Calcular el coste de un cartel
