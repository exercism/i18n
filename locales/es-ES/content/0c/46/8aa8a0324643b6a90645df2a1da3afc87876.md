# Instructions

Gestionas un cine exclusivo.
Para poder ver una película, la gente tiene que comprar un abono anual y, a partir de ahí, puede ver películas gratis.

Tu cine lleva un registro de las entradas.
Quieres usar ese registro para saber qué socios han usado su abono anual este mes.
También quieres obtener información sobre los datos demográficos por edad de tus clientes.
Te das cuenta de que puedes usar conjuntos para lograr estos objetivos.

## Conjuntos

Un conjunto es el tipo de dato perfecto para guardar este tipo de datos.

Un conjunto es un tipo de dato que se usa para guardar valores distintos y únicos sin ningún orden en particular.
Que sean distintos y únicos significa que un elemento o está en el conjunto o no lo está; a diferencia de lo que ocurre con un array, no puede estar en el conjunto varias veces.
Normalmente los conjuntos no tienen orden; si enumeras los elementos de un conjunto, el orden que obtengas puede ser distinto del orden en que se añadieron, ¡o incluso distinto del que obtuviste en la enumeración anterior!

Una propiedad fundamental de los conjuntos son las comprobaciones de pertenencia: la capacidad de comprobar si un conjunto contiene un elemento.
Las comprobaciones de pertenencia son esenciales en casi todos los usos de un conjunto.

Go no incluye un tipo de dato de conjunto integrado.
Es habitual usar un `map[<type>]struct{}` o un `map[<type>]bool` en lugar de un conjunto; al igual que un conjunto, un `map` permite añadir elementos distintos y únicos y admite comprobaciones de pertenencia.

## 1. Un lugar donde guardar la información de los asistentes

Para hacer un seguimiento de la asistencia y de los datos demográficos por edad, quieres usar un conjunto.

No quieres escribir conjuntos separados para nombres y edades; en su lugar, puedes usar un conjunto genérico para ambos.
Define un tipo `Set` como un `map[T comparable]struct{}` para guardar a los asistentes.
Escribe una función `NewSet[T comparable]()` que devuelva un `Set[T]` vacío.

```go
names := NewSet[string]()
```

## 2. Hacer un seguimiento de los asistentes

Ya estás listo para registrar la información de los asistentes.

Escribe un método `Add[T]()` que añada un elemento al conjunto.

```go
names := NewSet[string]()
names.Add("Alice")
```

## 3. Comprobar los asistentes

Ahora que tienes un conjunto de asistentes, puedes comprobar si se presentaron determinados miembros y datos demográficos por edad.
Escribe un método `Contains[T](element)` que devuelva si un miembro o un dato demográfico por edad está en el `Set`.

```
names := NewSet[string]()
names.Add("Alice")
names.Contains("Alice")
// => true
names.Contains("Bob")
// => false
```

## 4. Comparar los asistentes

Ha pasado otro mes y tienes un nuevo `Set` de datos demográficos por edad.
Tu responsable de marketing quiere saber si los estrenos de este mes han cambiado los datos demográficos por edad que están apareciendo.
Escribe un método `Equals[T](other)` que determine si dos conjuntos tienen los mismos elementos.

```go
agesOne := NewSet[int]()
names.Add(25)

agesTwo := NewSet[int]()
names.Add(25)

agesOne.Equals(agesTwo)
// => true

agesThree := NewSet[int]()
names.Add(35)

agesOne.Equals(agesThree)
// => false
```
