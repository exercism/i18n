# Anexo de instrucciones

## Instrucciones específicas del track

### Memoria reservada

Los bytes 64-447 de la memoria lineal están reservados para el string de entrada.

El string de entrada se puede modificar in situ si se desea.

### Formato de la entrada

Cada línea contendrá el nombre del primer equipo, luego un punto y coma `;`, después el nombre del segundo equipo, otro punto y coma `;`, el resultado del partido (`"win"`, `"draw"`, `"loss"`) y, a continuación, un salto de línea `\n`.
