# Instrucciones

Tori es periodista y escribe sobre el clima. Quiere escribir un artículo sobre el tiempo en distintas ciudades. Tiene datos sobre el tiempo en distintas ciudades y quiere clasificarlas en función de su temperatura, pero algunas temperaturas están en Fahrenheit y otras en Celsius. Necesita tu ayuda para convertir las temperaturas a la misma unidad y ordenarlas.

## 1. Convierte Fahrenheit a Celsius

Define la función `fahrenheit_to_celsius`, que recibe como argumento una temperatura en Fahrenheit y devuelve la temperatura en Celsius.

Para convertir de Fahrenheit a Celsius, resta 32 al valor en Fahrenheit y, a continuación, divide el resultado entre 1,8.

```gleam
fahrenheit_to_celsius(72.5)
// -> 22.5
```

## 2. Compara dos temperaturas

Define la función `compare_temperature`, que recibe dos temperaturas y devuelve un valor `Order` que indica si la primera temperatura es menor que, igual que o mayor que la segunda.

```gleam
compare_temperature(Celsius(30.5), Fahrenheit(82.1))
// -> Gt
```

## 3. Ordena las ciudades por temperatura

Define la función `sort_cities_by_temperature`, que recibe un array de ciudades y las devuelve de la más fría a la más cálida.

```gleam
sort_cities_by_temperature([
  City(name: "London", temperature: Celsius(30.5)),
  City(name: "Paris", temperature: Fahrenheit(82.1))
])
// -> [
//   City(name: "Paris", temperature: Fahrenheit(82.1)),
//   City(name: "London", temperature: Celsius(30.5)))
// ]
```
