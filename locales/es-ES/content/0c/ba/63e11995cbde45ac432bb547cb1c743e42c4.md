# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [Recursos de Raku](https://raku.org/resources/)
- [/r/rakulang](https://www.reddit.com/r/rakulang) es el subreddit de Raku.
- [StackOverflow](http://stackoverflow.com/questions/tagged/raku) te sirve para buscar tu problema y comprobar si ya se ha respondido antes. También puedes hacer y responder preguntas.
