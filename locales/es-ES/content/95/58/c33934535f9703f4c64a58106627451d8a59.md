# Anexo de instrucciones

## Cómo está estructurado este ejercicio en Python

Este ejercicio se resuelve mejor con el operador `%` ([módulo][modulo]) de Python, que devuelve el residuo de una división entera de números positivos.
Tiene un método equivalente, `operator.mod()`, en el [módulo operator][operator-mod].


Python también ofrece otros métodos de «residuo» en el [módulo math][math-module].
[`math.fmod()`][fmod] se comporta como `%`, pero opera con números de coma flotante.
[`math.remainder()`][remainder] implementa un algoritmo de «paso más cercano a cero» para el residuo de una división.
Aunque te animamos a que te familiarices con estos métodos, ninguno de los dos coincide exactamente con el resultado de `%`, por lo que no se recomiendan para este ejercicio.

La función integrada [`divmod()`][divmod] también devuelve un residuo que coincide con el de `%` si se usa con dos números enteros positivos, pero devuelve una `tuple` que hay que desempaquetar.
