# Pistas

## General

-  Este ejercicio consiste en validar, «limpiar» y procesar la pregunta dada en el **_orden correcto_**.
-  Si lees con atención las instrucciones y los tests, verás que hay tres condiciones que deben cumplirse para que una pregunta sea «válida».
Si una pregunta no es válida, tendrás que [lanzar][raise-statement] un [ValueError][value-error] con un mensaje (_`ValueError("unknown operation")`_).
   Lo mejor es quitarse de en medio esta comprobación concreta antes de hacer cualquier otra cosa.
-  Procesar una pregunta antes de calcular la respuesta consiste en utilizar [métodos de string][str-methods].
Algunos de los más populares que puedes investigar son `str.removeprefix`, `str.removesuffix`, `str.replace` y `str.strip`.
Otros que quizá quieras consultar son `str.startswith`, `str.endswith` e `in` (_que no solo se aplica a los strings_).

-  Es posible iterar sobre un string.  Sin embargo, es **mucho** más fácil iterar sobre una lista de _palabras_ si el string que estás procesando es una frase o un fragmento con espacios.  [`str.split`][split]  puede dividir un string y devolver una lista de «palabras».
-  Un [`while-loop`][while-loop] es muy útil para iterar sobre la pregunta y procesar los elementos.
-  Para tener menos comprobaciones de errores y una gestión de errores más limpia, se recomienda usar un [`try-except`][handling-exceptions] mientras procesas la pregunta.
-  **Recuerda**: la pregunta se procesa **_de izquierda a derecha_**.  Eso significa que «1 plus 12 minus 3 multiplied by 4» se procesa así:
   -  Calcular «1 plus 12» (13),
   -  Calcular «13 minus 3» (10),
   -  Calcular «10 multiplied by 4» (40).
   -  El resultado del primer cálculo se _concatena con el resto de la pregunta para formar una nueva pregunta para el siguiente paso_.
       -  A esta técnica se la llama a veces [el patrón acumulador][accumulator-pattern], o [fold][fold] / [foldl][foldl] en lenguajes de programación funcional como [Haskell][haskell-folds] o Lisp.
       -  Python incluye dos métodos creados específicamente para aplicar el `accumulator-pattern` a estructuras de datos iterables como `lists`, `tuples` y `strings`.
               [`functools.reduce`][reduce] y [`itertools.accumulate`][accumulate] podrían ser interesantes de investigar aquí.

-  Este ejercicio tiene muchas soluciones posibles y muchos caminos que puedes seguir.
   Ningún camino es manifiestamente «mejor» que otro, aunque puede que un camino concreto te resulte más interesante o encaje mejor con lo que quieres aprender o explorar ahora mismo.
