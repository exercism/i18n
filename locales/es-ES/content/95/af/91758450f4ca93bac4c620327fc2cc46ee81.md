# Consejos

## General

- Lee sobre los [bitstrings][bitstring] en la guía de introducción.
- Repasa la documentación de la [forma especial bitstring][bitstring-form].
- Repasa [cómo convertir números decimales en números binarios][decimal-to-binary-youtube].
- Elixir admite [distintas formas de escribir números enteros][integer-literal], incluida la notación binaria.

## 1. Calcula el tamaño en bits de la paleta

- Esta tarea no utiliza el tipo de datos bitstring.
- Encuentra el número positivo más pequeño `n` tal que 2 elevado a la potencia de `n` sea mayor o igual que el número de colores que necesitamos representar.
- Crea una función recursiva para esto.
- Empieza con un tamaño en bits de 1. Si 2 elevado a la potencia del tamaño en bits es mayor o igual que el número de colores, has encontrado el tamaño en bits. Si no, suma 1 al tamaño en bits y vuelve a comprobarlo (recursión).
- Usa el [operador de potencia `**`][power-operator] para elevar 2 a una potencia dada.

## 2. Crea una imagen vacía

- Usa la [forma especial bitstring][bitstring-form] para crear un bitstring nuevo.

## 3. Crea una imagen de prueba

- Usa la [forma especial bitstring][bitstring-form] para crear un bitstring nuevo.
- Usa el [operador de tipo][type-operator] para especificar el tamaño en bits de cada fragmento.

## 4. Añade un píxel al principio de una imagen

- La [forma especial bitstring][bitstring-form] puede usarse para añadir un fragmento nuevo a un bitstring existente.
- Usa el [operador de tipo][type-operator] para especificar tanto el tamaño en bits del fragmento nuevo como el del bitstring existente.
- Usa la función `PaintByNumber.palette_bit_size/1` que has implementado antes para obtener el tamaño en bits del fragmento nuevo.
- Usa el tipo especial `::bitstring` para especificar que el fragmento antiguo tiene un tamaño desconocido.

## 5. Obtén el primer píxel de una imagen

- La [forma especial bitstring][bitstring-form] puede usarse para [aplicar la coincidencia de patrones a bitstrings][bitstring-matching].
- Usa la función `PaintByNumber.palette_bit_size/1` que has implementado antes para obtener el tamaño en bits de un píxel.
- Usa el tipo especial `::bitstring` para especificar que el resto del bitstring tiene un tamaño desconocido.

## 6. Elimina el primer píxel de una imagen

- La [forma especial bitstring][bitstring-form] puede usarse para [aplicar la coincidencia de patrones a bitstrings][bitstring-matching].
- Usa la función `PaintByNumber.palette_bit_size/1` que has implementado antes para obtener el tamaño en bits de un píxel.
- Usa el tipo especial `::bitstring` para especificar que el resto del bitstring tiene un tamaño desconocido.

## 7. Concatena dos imágenes

- La [forma especial bitstring][bitstring-form] puede usarse para concatenar dos bitstrings.
- Usa el tipo especial `::bitstring` para especificar que cada uno de los fragmentos de bitstring tiene un tamaño desconocido.
