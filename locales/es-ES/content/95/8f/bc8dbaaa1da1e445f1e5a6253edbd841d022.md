# Acerca de

La definición de una colección suele incluir un marcador de posición entre corchetes angulares, a menudo T por convención. Este tipo de colección se conoce como tipo genérico. Esto permite que quien use la colección especifique qué tipo de elementos se guardan en ella. En el código de ejemplo anterior instanciamos un array de strings.

Para que una clase o una función sea **genérica**, se usa el atributo `@:generic`. Esto hace que el compilador identifique la clase o la función como genérica:

```haxe
@:generic
class MyValue<T> {
  public var value:T;

  public function new(value:T) {
    this.value = value;
  }
}

var a = MyValue<String>("Hello");
trace(a.value); // Hello
```
