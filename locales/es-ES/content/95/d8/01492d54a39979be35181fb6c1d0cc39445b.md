# Introducción

La reducción consiste en aplicar repetidamente una función a cada elemento de
una secuencia e ir acumulando, de algún modo, los resultados.
La función que se aplica toma dos parámetros: el valor acumulado actual y el elemento que hay que procesar.
Debe dar como resultado el nuevo valor acumulado.

En Common Lisp, este proceso se lleva a cabo con la función `reduce`.
En su forma más simple, tiene este aspecto:

`(reduce #'function-to-apply sequence :initial-value value)`

Fíjate en que se proporciona un valor inicial: este será el «valor acumulado actual» que se pasa a la función cuando se procesa el primer elemento.

Aquí tienes un ejemplo que suma los números de la lista, empezando por un valor inicial de 10:

`(reduce #'+ '(1 2 3 4) :initial-value 10) ; => 20`

Ten en cuenta que, si la secuencia está vacía, la función nunca se llama y la forma se evalúa al valor inicial.
