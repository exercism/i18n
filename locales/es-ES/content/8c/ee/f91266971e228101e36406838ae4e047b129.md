# Introducción

## Fundamentos 2

### Exportar funciones

La exportación de funciones ya se trató en el primer concepto; aquí tienes un repaso rápido.

Cada archivo en Elm es un módulo y debe contener una instrucción `module` antes de cualquier otro código.

Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm, y el módulo `Parser.Utils` debe estar en el archivo Parser/Utils.elm.

Todo lo que se define dentro de un módulo tiene un ámbito privado dentro de él y no se puede acceder desde fuera de este módulo, a menos que se incluya en `exposing`.

```elm
-- Calculator.elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Calculator.elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Importar funciones desde otros módulos

Para acceder a las funciones definidas en otros módulos se usan las importaciones.
Todas las funciones de ese módulo que hayan sido expuestas por él pasan a ser accesibles al importar ese módulo.
Pero la forma de acceder a ellas varía según cómo se importe el módulo.

Las importaciones cualificadas son las predeterminadas, y para acceder a una función de ese módulo (por ejemplo, la función `map` del módulo `List`) se antepone el nombre del módulo (`List.map`).

Las importaciones abiertas permiten acceder directamente a las funciones expuestas de ese módulo, sin anteponer nada. Se hacen con la palabra clave `exposing`, de forma análoga a la que se usa en las exportaciones. Puedes exponer todas las funciones disponibles (con `..`) o solo algunas (por ejemplo, `map`).

También puedes importar tipos y sus constructores desde otros módulos, lo cual es un concepto que verás más adelante.

Se prefieren las importaciones cualificadas para favorecer la claridad y evitar conflictos de nombres.

```elm
-- qualified imports
import List                            -- List.map, List.foldl
import List as L                       -- L.map, L.foldl

-- open imports
import List exposing (..)              -- map, foldl, concat, ...
import List exposing ( map, foldl )    -- map, foldl, List.concat
```

https://elm-lang.org/docs/syntax#modules

### Anotaciones de tipo

Las anotaciones de tipo se definen con `name : parameter types -> return type`, y los tipos de los parámetros también se separan con `->`.

```elm
add : Int -> Int -> Int
add number1 number2 = number1 + number2
```

Se pueden usar paréntesis para definir los parámetros de una función (que a su vez se definen con la misma sintaxis, de ahí la necesidad de los paréntesis).

```elm
-- Transform every character in a string
map : (Char -> Char) -> String -> String
map charMapperFunction string =
    -- ...
```

https://elm-lang.org/docs/syntax#type-annotations

### Números

En Elm hay dos tipos de números, definidos por los tipos `Int` y `Float`.
`Int` se corresponde con el conjunto de los números enteros positivos y negativos.
`Float` se corresponde con el conjunto de los números reales, limitado por la precisión del ordenador.
Las operaciones definidas sobre números normalmente funcionan con un tipo u otro, pero no los mezclan.
Existen funciones para convertir entre ambos, como `toFloat`, que convierte `Int` en `Float`, y `round`, `floor`, `ceiling` o `truncate`, que convierten un `Float` en un `Int` con distintas semánticas.

https://package.elm-lang.org/packages/elm/core/latest/Basics#Int

### Operaciones con cadenas

Para describir palabras y frases en el código, Elm tiene un tipo `String` nativo.
Los literales de `String` se escriben entre comillas dobles, como `"Hello World!"`.
El operador `++` de concatenación de `String` y el operador `==` de igualdad están disponibles por defecto.

```elm
hello : String -> String
hello subject = "Hello " ++ subject

hello "World!" --> "Hello World!"
```

La mayoría de las demás funciones de `String` están en el módulo `String`, que debe importarse.

https://package.elm-lang.org/packages/elm/core/latest/String
