# Instalación

## Instala el entorno de ejecución de R
Visita la [página de inicio de CRAN](https://cran.r-project.org/). Allí encontrarás enlaces de descarga para Linux, Mac OSX y Windows. Descarga y ejecuta el instalador para tu sistema operativo.

## Instala el IDE de RStudio (recomendado)
RStudio es un entorno de desarrollo integrado (IDE) multiplataforma popular para programar en R (y también admite otros lenguajes como Python, JavaScript y Markdown). Usar RStudio te facilitará escribir las soluciones de tu código y ejecutar las pruebas.

Descarga e instala la [versión estable actual de RStudio](https://www.rstudio.com/products/rstudio/download/). O, como alternativa, consigue la [versión de vista previa](https://www.rstudio.com/products/rstudio/download/preview/) de un próximo lanzamiento.

## Instala la extensión de Visual Studio Code para R (alternativa)
La extensión de R para Visual Studio Code admite resaltado de sintaxis extendido, autocompletado de código, análisis estático, formateo, interactuar con terminales de R, ver datos, gráficos, variables del espacio de trabajo, páginas de ayuda, gestionar paquetes y trabajar con documentos de R Markdown.

Descarga e instala la [versión actual de la extensión de R](https://code.visualstudio.com/docs/languages/r)

## Instala los paquetes de R para ejecutar las pruebas
El ejecutor de pruebas para las especificaciones es la biblioteca [`testthat`](https://github.com/hadley/testthat) de Hadley Wickham, una opción popular entre quienes escriben paquetes de R.

Para instalar esta biblioteca, escribe lo siguiente en la consola de RStudio (o dondequiera que uses R).

```{R}
install.packages("testthat")
```

Aunque es poco probable que _necesites_ instalar paquetes para resolver los problemas de Exercism, puede que quieras incorporar un paquete de utilidades de propósito general como [`tidyverse`](https://github.com/tidyverse/tidyverse) que se adapte a tu estilo de programación. Para instalar y cargar un paquete como `tidyverse`:

```{R}
install.packages("tidyverse")
library(tidyverse)
```
