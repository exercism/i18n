# Introducción

`call` (en [`kernel`][kernel]) ejecuta una quotation. Cuando no se puede inferir el efecto de pila de la quotation (normalmente porque la quotation viene de otro sitio), declara explícitamente ese efecto en `call`:

```
call( stack-effect ) ! e.g. call( a b -- c )
```

```factor
3 4 [ + ] call .                 ! => 7
3 4 [ + ] call( a b -- c ) .     ! => 7

: apply-binary ( a b op -- c )
    call( a b -- c ) ;

5 3 [ - ] apply-binary .         ! => 2
```

Como las quotations son valores, un array puede contener una mezcla de números y quotations, lo que convierte «un programa» en una secuencia más:

```factor
{ [ 1 + ] [ 2 * ] } 5 swap [ call( x -- y ) ] each .   ! 5 -> 6 -> 12
```
