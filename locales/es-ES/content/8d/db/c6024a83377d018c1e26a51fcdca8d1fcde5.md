# Instrucciones

Dado un string de dígitos, calcula el mayor producto de una subcadena contigua
de dígitos de longitud n.

Por ejemplo, para la entrada `'1027839564'`, el mayor producto para una
serie de 3 dígitos es 270 (9 * 5 * 6), y el mayor producto para una
serie de 5 dígitos es 7560 (7 * 8 * 3 * 9 * 5).

Ten en cuenta que estas series solo tienen que ocupar *posiciones adyacentes*
en la entrada; los dígitos no tienen por qué ser *numéricamente consecutivos*.

Para la entrada `'73167176531330624919225119674426574742355349194934'`,
el mayor producto para una serie de 6 dígitos es 23520.
