# Pistas

## 1. Crea un nuevo residente

- Vuelve a consultar el [concepto de struct](/tracks/go/concepts/structs) para obtener información sobre cómo crear structs.

## 2. Valida la información del residente

- El valor cero de un string es `""`.
- El valor cero de un map es `nil`.
- Vuelve a consultar el [concepto de maps](/tracks/go/concepts/maps) para obtener información sobre cómo determinar si existe la clave de un map.

## 3. Elimina la información del residente

- Se considera que un residente está eliminado cuando todos sus campos se han establecido a su valor cero.
- Vuelve a consultar el [concepto de valores cero](/tracks/go/concepts/zero-values) para saber cuál es el valor cero de cada tipo de Go.

## 4. Cuenta los residentes

- Vuelve a consultar el [concepto de iteración con range](/tracks/go/concepts/range-iteration) para obtener información sobre cómo recorrer un slice con range.
