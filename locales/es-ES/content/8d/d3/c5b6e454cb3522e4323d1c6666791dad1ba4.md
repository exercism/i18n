# Instrucciones

En este ejercicio vas a implementar la lógica de combate de un nuevo juego de rol que está desarrollando un amigo.
La protagonista del juego es Annalyn, una chica valiente con un fiero y leal perro llamado Kazak.
En un momento dado, un monstruo les tiende una emboscada y ellos lo atacan.

## 1. Define attackWithSword1

Define `attackWithSword1`.
Debe recibir un `MonsterDamage` (un `String` que describe el daño infligido al monstruo) y un `Int` que indica la fuerza del ataque.
Debe devolver el string existente, con «Attacked with sword of strength {strength}.» añadido al final.

## 2. Define attackWithClaw1

Define `attackWithClaw1`.
Debe recibir un `MonsterDamage` y un `Int` que indica la fuerza del ataque.
Debe devolver el string existente, con «Attacked with claw of strength {strength}.» añadido al final.

## 3. Define attack1

Annalyn ataca con una espada y tiene una fuerza de 5.

Su leal perro Kazak ataca con sus garras y tiene una fuerza de 1.

Define `attack1`. Debe recibir un `MonsterDamage` y realizar los siguientes ataques, en el orden correcto:

- Annalyn
- Kazak
- Kazak
- Annalyn

La implementación de esta función será un poco engorrosa, ya que `attackWithSword1` y `attackWithClaw1` no tienen la estructura de datos principal (`MonsterDamage`) como último parámetro (no lo hacen de la forma recomendada).
En este primer caso no es posible ni aconsejable usar aplicación parcial.

## 4. Define attackWithSword2

Define `attackWithSword2`.
Esto es lo mismo que `attackWithSword1`, salvo que los parámetros están intercambiados.

## 5. Define attackWithClaw2

Define `attackWithClaw2`.
Esto es lo mismo que `attackWithClaw2`, salvo que los parámetros están intercambiados.

## 6. Define attack2

Define `attack2`.

Esto es lo mismo que `attack1`, pero debe usar `attackWithSword2` y `attackWithClaw2`.

Implementa la función usando la [aplicación parcial][partial-application] y el [operador de tubería `(|>)`][pipe-operator].
Ahora la implementación debería ser más elegante, ya que `attackWithSword2` y `attackWithClaw2` tienen `MonsterDamage` (la estructura de datos principal) como último parámetro, tal y como se recomienda.

## 7. Define attack3

Define `attack3`.

Esto es lo mismo que `attack2`, pero debe implementarse usando composición de funciones / el operador [`(>>)`][forward-composition].

Esta implementación también debería ser elegante y más pequeña que `attack2`, aunque puede que sea más difícil de entender.
