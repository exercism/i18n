# Instructions

Tu amigo Linus es maquinista y conduce trenes de mercancías entre ciudades.
Aunque se le dan fenomenal los trenes, no se le dan tan bien la logística ni los ordenadores.
Le gustaría pedirte ayuda con la programación para organizar los detalles de los trenes y corregir errores en los datos de las rutas.

~~~~exercism/note
Este ejercicio se podría resolver fácilmente con slicing, indexación y varios métodos de `Dict`.
Sin embargo, nos gustaría que practiques el empaquetado (es decir, slurping), el desempaquetado (es decir, splatting) y la asignación múltiple al resolver cada una de las tareas que aparecen a continuación.
~~~~

## 1. Crea un vector con todos los vagones

Tu amigo ha ido anotando el identificador (ID) de cada vagón, pero nunca está seguro de cuántos vagones tendrá que procesar el sistema en un momento dado.
Para el resto del programa de logística sería mucho más fácil tener estos datos empaquetados en un único `Vector`.

Implementa una función `get_vector_of_wagons(args...)` que acepte un número arbitrario de ID de vagones.
Cada ID será un número entero positivo.
La función debe entonces devolver, con `return`, los ID indicados como un único `Vector`.

```julia-repl
julia> get_vector_of_wagons(1, 7, 12, 3, 14, 8, 5)
7-element Vector{Int64}:
  1
  7
 12
  3
 14
  8
  5
```

## 2. Corrige el vector de vagones

A estas alturas, ya empiezas a hacerte una idea de los datos y de cómo se usan en el programa de logística.
El sistema de ID siempre asigna a la locomotora el ID **1**, y al resto de los vagones del tren les asigna un ID elegido al azar mayor que **1**.

¡Tu amigo tenía que enganchar dos vagones nuevos al tren y se olvidó de actualizar el sistema!
Ahora hay que mover los dos primeros vagones del `Vector` del tren al final, o todo quedará desordenado.

Para complicar más las cosas, tu amigo acaba de encontrar un segundo `Vector` que parece contener ID de vagones que faltan.
Lo único que recuerda es que, una vez movidos los vagones nuevos, los ID de este segundo `Vector` deben colocarse justo después de la locomotora designada.

Linus te estaría muy agradecido si corrigieras sus errores y consolidaras los datos.

Implementa una función `fix_vector_of_wagons(each_wagons_id, missing_wagons)` que reciba dos `Vector` con ID de vagones.
Debe recolocar los dos primeros elementos del primer `Vector` al final e insertar los valores del segundo `Vector` detrás de (_a la derecha de_) la locomotora, que tiene el ID (**1**).
La función debe entonces devolver, con `return`, un `Vector` con las modificaciones.

```julia-repl
julia> fix_vector_of_wagons([2, 5, 1, 7, 4, 12, 6, 3, 13], [3, 17, 6, 15])
13-element Vector{Int64}:
  1
  3
 17
  6
 15
  7
  4
 12
  6
  3
 13
  2
  5
```

## 3. Añade las paradas que faltan

Ahora que todos los datos de los vagones son correctos, a Linus le gustaría que actualizaras la información de rutas del sistema.
A lo largo de una ruta de transporte, un tren puede hacer paradas en varias estaciones distintas para recoger y/o dejar mercancía.
Cada trayecto puede tener un número diferente de estos puntos intermedios de entrega.
A tu amigo le gustaría que actualizaras el `Dict` de rutas del sistema con cualquier información de entrega que falte o que haya que añadir.

Implementa una función `add_missing_stops(route, stops...)` que acepte un `Dict` de rutas seguido de un número variable de pares `stop_number => city`.
A continuación, tu función debe devolver el `Dict` de rutas actualizado con una `key` adicional que contenga un `Vectors` con todas las paradas añadidas en orden.

```julia-repl
julia> add_missing_stops(Dict("from" => "New York", "to" => "Miami"), :stop_1 => "Washington, DC", :stop_2 => "Charlotte", :stop_3 => "Atlanta", :stop_4 => "Jacksonville")
Dict{String, Any} with 3 entries:
  "stops" => ["Washington, DC", "Charlotte", "Atlanta", "Jacksonville"]
  "to"    => "Miami"
  "from"  => "New York"
```

## 4. Amplía la información de rutas

Linus ha estado trabajando en el programa de rutas y se ha dado cuenta de que a ciertas rutas les faltan algunos detalles importantes.
La información inicial de la ruta se ha construido como un `Dict`, y a tu amigo le gustaría que actualizaras ese `Dict` con todo lo que pueda faltar.
Cada ruta del sistema requiere detalles ligeramente distintos, así que Linus preferiría sin duda una solución genérica.

Implementa una función llamada `extend_route_information(route; more_route_information...)` que acepte un `Dict` que contenga las ciudades de origen y destino entre las que circula la ruta del tren, además de un número variable de argumentos de palabra clave con detalles de la ruta, como la velocidad, la longitud o la temperatura del tren.
La función debe devolver un `Dict` consolidado con toda la información de la ruta.

```julia-repl
julia> extend_route_information(Dict("from" => "Berlin", "to" => "Hamburg"); length = "100", speed = "50")
Dict{Any, String} with 4 entries:
  :speed  => "50"
  "to"    => "Hamburg"
  "from"  => "Berlin"
  :length => "100"


julia> extend_route_information(Dict("from" => "Paris", "to" => "London"), length = "15", temperature = "20", timeOfArrival = "10:30")
Dict{Any, String} with 5 entries:
  :temperature   => "20"
  :timeOfArrival => "10:30"
  "to"           => "London"
  "from"         => "Paris"
  :length        => "15"
```
