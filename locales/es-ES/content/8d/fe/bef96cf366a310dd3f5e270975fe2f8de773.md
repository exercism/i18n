# Ayuda

A continuación tienes algunos recursos para conseguir ayuda si te encuentras con problemas:

- [La página web principal del proyecto Futhark][main] aloja [documentación][docs], [ejemplos][examples], una [referencia del lenguaje][language-reference] y mucho más.
- [Parallel Programming in Futhark][book] es un libro pensado como introducción al lenguaje.
- [La comunidad de Exercism en Discord][exercism-discord]
- El canal `#futhark` en [Libera][libera]
- El [canal de Gitter de futhark][gitter]
- [/r/futhark/][reddit] es un subreddit para lenguajes similares a APL.

Además, [StackOverflow][so] es un buen lugar donde buscar tu problema o tu pregunta para ver si ya se ha respondido.
Si no es así, siempre puedes [preguntar][ask-so] o [responder][answer-so] a la pregunta de otra persona.
