# Instrucciones

Eres un ávido observador de aves que lleva un registro de cuántos pájaros han visitado tu jardín en un día cualquiera.

Has decidido llevar tu afición por la observación de aves a un nuevo nivel e implementar algunas herramientas que te ayuden a registrar y procesar los datos.

Has optado por almacenar los datos como un array de números enteros.
El primer número del array es el número de pájaros que visitaron tu jardín hoy, el segundo el de ayer, y así sucesivamente.

~~~~exercism/note
En aplicaciones del mundo real, siempre deberías usar los módulos principales siempre que sea aplicable; sin embargo, con el objetivo de aprender sobre la recursión, no uses ninguna de las funciones de `List` en este ejercicio.
~~~~

## 1. Comprueba cuántos pájaros visitaron hoy

Implementa la función `today`.
Debe tomar un array con los recuentos diarios de pájaros y devolver el recuento de hoy.
Si el array está vacío, debe devolver `Nothing`; en caso contrario, el recuento irá envuelto en un `Just`.

```elm
BirdCount.today [2, 5, 1]
    -- Just 2
```

## 2. Incrementa el recuento de hoy

Implementa la función `incrementDayCount`.
Debe tomar un array con los recuentos diarios de pájaros e incrementar en 1 el recuento de hoy.
Si el array está vacío, devuelve `[1]`.

```elm
BirdCount.incrementDayCount [4, 0, 2]
    -- [5, 0, 2]
```

## 3. Comprueba si hubo un día sin pájaros visitantes

Implementa la función `hasDayWithoutBirds`.
Debe tomar un array con los recuentos diarios de pájaros.
Debe devolver `True` si hubo al menos un día en el que ningún pájaro visitó el jardín, y `False` en caso contrario.

```elm
BirdCount.hasDayWithoutBirds [2, 0, 4]
    -- True

BirdCount.hasDayWithoutBirds [3, 8, 1, 5]
    -- False
```

## 4. Calcula el número total de pájaros visitantes

Implementa la función `total`.
Debe tomar un array con los recuentos diarios de pájaros y devolver el número total que visitaron tu jardín desde que empezaste a recopilar los datos.

```elm
BirdCount.total [4, 0, 9, 0, 5]
    -- 18
```

## 5. Calcula el número de días ajetreados

Algunos días están más ajetreados que otros.
Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.

Implementa la función `busyDays`.
Debe tomar un array con los recuentos diarios de pájaros y devolver el número de días ajetreados.

```elm
BirdCount.busyDays [4, 5, 0, 0, 6]
    -- 2
```
