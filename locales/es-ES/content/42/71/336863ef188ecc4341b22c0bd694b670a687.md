# Introducción

En Python, una [tupla][tuple] es una colección _inmutable_ de elementos en _secuencia_.
Como la mayoría de las colecciones, las `tuples` pueden contener cualquier tipo (o varios tipos) de datos, incluidos otros `tuples`.
Las tuplas admiten todas las [operaciones comunes de secuencia][common sequence operations], pero **no** admiten las [operaciones de secuencia mutables][mutable sequence operations].
Los elementos de una tupla se pueden recorrer con la construcción `for item in <tuple>`.
Si necesitas tanto el índice como el valor del elemento, puedes usar `for index, item in enumerate(<tuple>)`.
Como cualquier secuencia, se puede acceder a los elementos de una tupla mediante la _notación de corchetes_, usando un número `0-based index` desde la izquierda o un número `-1-based index` desde la derecha.

[common sequence operations]: https://docs.python.org/3/library/stdtypes.html#common-sequence-operations
[mutable sequence operations]: https://docs.python.org/3/library/stdtypes.html#mutable-sequence-types
[tuple]: https://docs.python.org/3/library/stdtypes.html#tuple
