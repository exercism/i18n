# Anexo de instrucciones

## Pistas

Para completar este ejercicio, tienes que implementar las siguientes funciones:

- `territories` devuelve las coordenadas (con base 1, la de arriba a la izquierda es (1,1))
de los puntos de cada territorio, junto con quién «posee» el territorio.

- `territoriesFor` devuelve el territorio que contiene la coordenada,
junto con el propietario del territorio. Si la coordenada no apunta
a una posición vacía, devuelve *Nothing*.

Un territorio es propiedad de uno de los jugadores si las piedras de ese jugador
son las únicas piedras adyacentes al territorio.

Las firmas de tipo ya están puestas, pero definir las funciones depende de ti.
