# Tests

Cada ejercicio incluye los tests unitarios y una receta de compilación de Make.
Tú aportas la implementación.

Cada archivo de tests está pensado para enlazarse con tu implementación y generar un ejecutable de consola que ejecuta los tests.
Al ejecutar el ejecutable de tests se imprimen mensajes por cada test que falla y se devuelve un código de salida distinto de cero cuando los tests fallan.

Para avanzar en un ejercicio:
* Crea la compilación inicial con Make
* Para cada test unitario:
  * Elimina la línea `TEST_IGNORE()`.
  * Corrige los errores de compilación para que el test falle.
  * Implementa lo justo para que el test pase.
  * Refactoriza tu implementación para mejorar la legibilidad, reducir la duplicación, etc.
