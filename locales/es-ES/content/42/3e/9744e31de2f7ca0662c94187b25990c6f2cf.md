# Debug

Cuando una prueba falla, se muestra un mensaje que describe qué ha ido mal.
Si quieres una salida adicional, puedes usar la subrutina `::YYY()` alrededor del código que quieras inspeccionar.
(`::` es una abreviatura de `main::`).
Esta subrutina forma parte del módulo [XXX][XXX].

También puedes simplemente imprimir un mensaje con la función `say`, por ejemplo, `say 'Hello, World!';`.

El ejecutor de pruebas en línea utiliza el [Test Anything Protocol][TAP].
Debido a la naturaleza de TAP, se desaconseja encarecidamente el uso de `print` en el ejecutor de pruebas en línea.

[XXX]: https://metacpan.org/dist/XXX/view/lib/XXX.pod
[TAP]: https://testanything.org/
