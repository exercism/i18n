# Introducción

## Valores predeterminados de los parámetros

[Los valores predeterminados de los parámetros][default-parameter-values] se pueden indicar para cualquiera de los parámetros de una función asignando un valor al parámetro en la lista de parámetros, justo después de la anotación de tipo del parámetro. Cuando se especifica un valor predeterminado para un parámetro, quien llama a la función puede omitir ese parámetro al llamarla y, en su lugar, se usará el valor predeterminado.

```swift
func greeting(name: String = "guest", duration: Int = 2) -> String {
  "Welcome, \(name). Enjoy your \(duration) night stay."
}

greeting(name: "Bobo", duration: 7)
// Returns "Welcome, Bobo. Enjoy your 7 night stay."
greeting(duration: 3)
// Returns "Welcome, guest. Enjoy your 3 night stay."
greeting(name: "Wynona")
// Returns "Welcome, Wynona. Enjoy your 2 night stay."
greeting()
// Returns "Welcome, guest. Enjoy your 2 night stay."
```

## Parámetros variádicos

[Los parámetros variádicos][variadic-parameters] permiten que una función acepte cero o más valores de un tipo determinado en un solo parámetro.
Un parámetro variádico se define añadiendo tres puntos (`...`) a la anotación de tipo del parámetro.

Dentro del cuerpo de la función, Swift pone estos valores a tu disposición como un array del tipo determinado:

```swift
import Foundation

func geometricMean(_ numbers: Double...) -> Double {
    var total = 1.0
    for number in numbers {
        total *= number
    }
    return pow(total, 1.0 / Double(numbers.count))
}

let result = geometricMean(1, 2, 3, 4, 5)
// result is 2.605171084697352
```

~~~~exercism/note
Si una función incluye parámetros adicionales después de un parámetro variádico, el primer parámetro que sigue al variádico **debe** tener una etiqueta de argumento explícita para que Swift sepa dónde termina la lista de argumentos variádicos.
~~~~


## Parámetros in-out

Dentro del cuerpo de una función, los parámetros se tratan como constantes, no como variables; intentar modificar el valor de un parámetro provoca un error en tiempo de compilación.
Si una función quiere modificar el valor de un parámetro, debe usar un [_parámetro in-out_][in-out-parameters] para hacer explícita esta mutabilidad.

Para usar parámetros in-out, hay que tener claras tres cosas:

1. La definición de la función debe marcar explícitamente los parámetros in-out escribiendo la palabra clave `inout` entre el `:` y el nombre del tipo en la anotación de tipo del parámetro.
2. El valor que se pasa al parámetro in-out debe estar declarado como una variable, no como una constante. Del mismo modo, no puede ser un literal.
3. El nombre de la variable debe ir precedido por un `&` en la llamada a la función, lo que lo marca explícitamente como modificable.

Cuando se hace esto, la función crea una copia interna del parámetro in-out, la modifica según lo indicado en el cuerpo de la función y, cuando la función termina, copia el valor modificado de vuelta en la variable que se pasó.

```swift
func updateVersion(_ record: inout (version: Int, title: String)) {
  record.version += 1
}

var dbRecord = (version: 2, title: "Exercism")
updateVersion(&dbRecord)

// dbRecord is now (3, "Exercism")
```

~~~~exercism/warning
Hay un par de reglas adicionales que conviene conocer sobre los parámetros in-out.

1  Dentro de una función con parámetros in-out, no puedes hacer referencia a la variable que se pasó como parámetro in-out.
2. La misma variable no se puede pasar como varios parámetros in-out en la misma función.
   Por ejemplo, `inoutFunc(&mutVar, &mutVar)` provoca un error del compilador.
~~~~

## Funciones anidadas

En Swift, puedes definir [funciones dentro de otras funciones][nested-functions].
Estas se conocen como **funciones anidadas**.

Las funciones anidadas se usan habitualmente como auxiliares privados que realizan tareas concretas para la función que las contiene sin recargar el ámbito exterior:

```swift
func makeNumber(_ number: Int) -> Int {
    func double(_ x: Int) -> Int {
        x * 2
    }

    func increment(_ x: Int) -> Int {
        x + 1
    }

    return number.isMultiple(of: 2) ? increment(double(number)) : double(number)
}

print(makeNumber(3)) // Prints 6
print(makeNumber(4)) // Prints 9
```

Las funciones anidadas se comportan como funciones estándar, pero su visibilidad se limita al cuerpo de la función que las contiene.
