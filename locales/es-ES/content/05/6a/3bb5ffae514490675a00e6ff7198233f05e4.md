# Pistas

## 1. Crea un nuevo marcador de puntuaciones

- Crea un objeto nuevo usando llaves.
- Escribe la clave como un string para que la clave pueda contener espacios.
- Separa la clave y el valor con dos puntos.

## 2. Añade jugadores a un marcador de puntuaciones

- Usa la notación de corchetes para añadir una clave cuyo nombre está guardado en una variable (el argumento).
- Usa el operador de asignación (`=`) para establecer un valor para la nueva clave.
- Como alternativa, usa el operador [`+`][man-plus] para combinar el objeto entrante con uno nuevo.
- Recuerda que se necesitan paréntesis alrededor de las expresiones de las claves de los objetos.

## 3. Elimina jugadores de un marcador de puntuaciones

- Usa la [expresión del][man-del].
- Haz referencia a la clave como hiciste en la tarea anterior (notación de corchetes).
- Recuerda que el argumento de `del` es una _expresión de índice_, no solo un string.

## 4. Aumenta la puntuación de un jugador

- Primero piensa en cómo expresar el nuevo valor que quieres asignar.
- Después, usa el operador de asignación como en la tarea 2 para establecer ese nuevo valor.
- Si aún no lo has hecho, puedes usar el [operador aritmético de actualización y asignación][man-update-assignment] `+=`.

## 5. Aplica los puntos extra del lunes

- Este es un buen lugar para usar `to_entries`/`from_entries`, o `with_entries` para iterar sobre el objeto
- Para cada clave, establece el nuevo valor como hiciste en la tarea 4.

## 6. Calcula la puntuación total

- Queremos iterar sobre los _valores_ del objeto.
  Podemos usar [`map_values`][man-map_values] o [`.[]`][man-brackets] para generar un flujo de valores.
- La expresión `add` se puede usar para hallar la suma de los números de un array.
