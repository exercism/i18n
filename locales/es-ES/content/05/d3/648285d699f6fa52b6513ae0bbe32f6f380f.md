# Información adicional

## GNU awk y la aritmética de precisión arbitraria

De forma predeterminada, los números en `awk` se representan como números de coma flotante de doble precisión. Esto proporciona 53 bits de precisión (consulta la [Tabla 16.3][table-16.3] del manual). Lamentablemente, no es suficiente para completar este ejercicio (alerta de spoiler: un test requiere 63 bits de precisión).

«Precisión insuficiente» tiene este aspecto:
```sh
$ gawk 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
not enough precision
```

GNU `awk` tiene la capacidad de usar números de precisión arbitraria, si las bibliotecas correspondientes se han compilado en el ejecutable de `awk`. Comprueba tu versión de awk y busca «GNU MPFR»:
```sh
$ gawk --version
GNU Awk 5.0.1, API: 2.0 (GNU MPFR 4.0.2, GNU MP 6.2.0)
...
```

Si está presente, activa la capacidad con la opción `-M`:
```sh
$ gawk -M 'BEGIN {
  n = 2 ^ 54
  if (n == n + 1)
    print "not enough precision"
  else
    print "OK"
}'
```
```none
OK
```

¿Y si mi `awk` no tiene `-M`? Tendrás que llamar a un programa externo que pueda hacer aritmética de precisión arbitraria, como `bc`. Consulta la sección [Usar getline en una variable desde una tubería][getline-pipe] para ver un ejemplo de cómo hacerlo.


Para saber más: [Aritmética de precisión arbitraria][arbitrary]
