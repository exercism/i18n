# Introducción

El [operador condicional ternario][ternary-operator] es una forma abreviada y concisa de una expresión `if-else`.
Evalúa una condición y devuelve uno de dos valores en función de si esa condición es `true` o `false`.

El operador consta de tres partes: `condition ? trueExpression : falseExpression`.
Si `condition` se evalúa como `true`, se evalúa `trueExpression` y se devuelve; en caso contrario, se evalúa `falseExpression` y se devuelve.

El operador ternario es ideal para elecciones simples de una sola línea:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = showFahrenheit ? temperatureInCelsius * 9 / 5 + 32 : temperatureInCelsius
print(temperature)
// Prints 86
```

El ejemplo anterior es un equivalente compacto de:

```swift
let showFahrenheit = true
let temperatureInCelsius = 30

let temperature = if showFahrenheit {
    temperatureInCelsius * 9 / 5 + 32
} else {
    temperatureInCelsius
}
```

[ternary-operator]: https://docs.swift.org/swift-book/LanguageGuide/BasicOperators.html#ID71
