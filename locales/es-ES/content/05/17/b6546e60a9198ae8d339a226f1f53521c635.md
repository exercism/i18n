## Algunas notas sobre los strings de Arturo

Verás en los tests una sintaxis que quizá te resulte nueva: strings multilínea encerrados entre `{ braces }`.

### Literales de string de Arturo

Arturo tiene varias formas de escribir literales de string:

1. Strings de una sola línea encerrados entre comillas dobles

    ```arturo
    greeting: "Hello, World!"

    print express greeting     ; => "Hello, World!"
    ```

1. Strings de final de línea que usan una «comilla inteligente» `«`

    ```arturo
    farewell: « Goodbye, Mars!

    print express farewell     ; => "Goodbye, Mars!"
    ```

   Pueden quedar muy legibles si tienes un array de strings cortos:

    ```arturo
    numberWords: [
        « one
        « two
        « three
        « four, and so on
    ]
 
    print express numberWords    ; => ["one" "two" "three" "four, and so on"]
    ```

1. Strings multilínea encerrados entre llaves.
   Se eliminará la indentación «común».
   Se eliminan los saltos de línea iniciales y finales.

    ```arturo
    multiline: {
        First line
        Second line
            Third line keeps indentation
        Last line!


    }

    print express first multiline   ; => 'F'
    print express last multiline    ; => '!'
    lines: split.lines multiline
    print size lines                ; => 4
    print express lines\2           ; => "    Third line keeps indentation"
    ```

1. Los strings verbatim se conservan exactamente, incluidos los espacios en blanco iniciales y finales

    ```arturo
    code: {:
        greet: function [name][
            print ~"Hello, |name|~"

        greet "World""
    :}

    print ">" ++ code ++ "<"
    print express first code
        ; => prints a literal newline character between single quotes
    print express (split.lines code | get 1)
        ; => "    greet: function [name]["
    ```

1. Los strings de estilo heredoc se sitúan bajo una línea de 3 o más guiones hasta el final del fichero.
   Esto funciona igual que la palabra clave `__DATA__` de Perl.
   Este estilo puede resultar útil en un módulo, donde podrías guardar la documentación o el texto de la licencia en una variable al final del fichero.

    Si esto está en un fichero llamado «mymodule.art»

    ```arturo
    myLicense:
    ---------
    This text has been placed in the public domain.
    Do with it what you will.
    ```

    Entonces

    ```arturo
    import {mymodule}!
    print ~">|myLicense|<"  ; => >This text has been placed in the public domain.
                            ; => Do with it what you will.<
    ```
