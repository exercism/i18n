# Introducción

## Declaración de tipos

Las declaraciones de tipo en PHP proporcionan comprobaciones de tipo en tiempo de ejecución para los argumentos de una función, los valores devueltos y las propiedades de una clase.
En las funciones, se puede añadir un tipo de retorno `void` para indicar que la función no devuelve ningún valor.
Los tipos declarados también sirven como comprobaciones en tiempo de ejecución de que las funciones devuelven una respuesta con un tipo razonable.

```php
<?php

class Driver
{
    private int $serial_number;

    public function setSerialNumber(int $number): void
    {
        $this->serial_number = $number;
    }

    public function getSerialNumber(): int
    {
        return $this->serial_number; 
    }
}

$driver = new Driver();
$driver->setSerialNumber("Version 1b"); // This will throw a TypeError
```

### Uniones de tipos

Si el argumento de una función, el valor devuelto o una propiedad de clase puede ser de más de un tipo, se puede declarar una unión de tipos.

```php
<?php

class IdentityCard
{
    private int|null $id = null;

    public function assign(int|float $id): void
    {
        $this->id = intval($id);
    }
}

$card = new IdentityCard();
$card->assign(5.0);
```

### Tipos mixtos

Al trabajar con código, es posible que no podamos especificar un tipo.
A partir de PHP 8.0, se proporciona un tipo de escape llamado `mixed`.
`mixed` equivale a una unión de tipos de `object|resource|array|string|float|int|bool|null`.
