# Apéndice de instrucciones

## Cómo manejar los casos límite

Los distintos lenguajes de Exercism tienen expectativas diferentes sobre cuál debería ser el resultado si la longitud de las subcadenas es cero.
En la pista de Rust, no tenemos un test para ese caso, así que eres libre de hacer lo que consideres más apropiado.

Considera las ventajas y desventajas de las siguientes posibilidades:
- Hacer que el programa se bloquee con `panic!`.
- Devolver un `Result::Err`. (no es posible aquí, porque la firma de la función ya viene dada)
- Devolver un vector vacío.
- Devolver un vector que contenga tantos strings vacíos como la longitud del string «digits» **más uno**. (¡esto tiene algunas propiedades matemáticas interesantes!)
