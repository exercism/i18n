# Introducción

Un `bit` es el valor más granular en informática.
La palabra `bit` procede del inglés «binary digit», que significa «dígito binario».
Es una unidad de almacenamiento de datos del entorno de ejecución lo suficientemente grande como para contener un objeto que puede tener uno de dos valores.
Por ello, tiene un valor binario de `1` o `0`.
Todos los demás tipos de datos se componen de varios `bits`.
Por ejemplo, un `byte` suele constar de ocho `bits`.

## Máscaras de bits

Una máscara de bits puede ser cualquier valor que se utilice para establecer bits individuales.
Por ejemplo, el alfabeto inglés tiene veintiséis letras.
Un valor de al menos veintiséis bits, como un entero sin signo de 32 bits, podría usarse como máscara de bits para establecer una condición `true` o `false` para cada letra inglesa.
Cualquier valor con suficientes bits para manejar un conjunto necesario de condiciones `true` o `false` puede servir como máscara de bits.
Establecer y leer los bits individuales se hace mediante el uso de operadores a nivel de bits.

## Operadores a nivel de bits

Supongamos que queremos llevar un registro de qué letras aparecen en un `string`.
Para nuestro ejemplo, usaremos solo las veintiséis letras del alfabeto inglés.
Nuestra máscara de bits será un entero sin signo de 32 bits.
Un `0` representará que la letra no aparece.
Un `1` representará que la letra aparece una o más veces.
Al principio, la representación binaria de nuestra máscara de bits serán 32 `0s` seguidos: `00000000000000000000000000000000`.
La posición más a la derecha será para la `A`.
La segunda desde la izquierda será para la `B`, y así sucesivamente.
Supongamos que procesamos todas las letras del string en un bucle, así que queremos una línea de código que sirva para establecer cualquier letra.

### Operador de desplazamiento a la izquierda a nivel de bits: una forma de posicionar un bit

`<<` es el operador a nivel de bits para desplazar a la izquierda.

Si nuestra letra es `A`, no queremos desplazar a la izquierda, pero si nuestra letra es `B`, queremos desplazar una posición a la izquierda, y si nuestra letra es `C`, queremos desplazar dos posiciones a la izquierda, y así sucesivamente.
Aunque podemos percibir los `chars` como letras como `A` o `B`, un `char` se implementa como un tipo entero en memoria, así que podemos hacer operaciones matemáticas sencillas con un `char`.
Dada una variable llamada `letter` que representa el `char` que estamos procesando, podemos desplazar a la izquierda el número de posiciones necesario desplazando `1` a la izquierda la diferencia entre `letter` y el `char` `A`, así: `1 << letter - 'A'`.
`A` - `A` es `0`, así que desplazaría `0` posiciones a la izquierda si `letter` es `A`.
`B` - `A` es `1`, así que desplazaría `1` posición a la izquierda si `letter` es `B`, y así sucesivamente.

### Operador OR inclusivo a nivel de bits: una forma de establecer un bit

Una vez que sabemos _dónde_ queremos establecer un bit, podemos establecerlo usando el operador OR inclusivo a nivel de bits, que es `|`.
El resultado del operador `|` será `1` en cada posición en la que el operando izquierdo o el derecho tenga un bit establecido.
Así, el resultado de `0010 | 0001` sería `0011`.
(Es importante recordar que el valor es `11` en binario, pero es `3` en decimal.)
Para asignar el resultado a un valor, el operador `|` se puede combinar con el operador de asignación para establecer los bits así: `|=`.
Para simplificar, el siguiente ejemplo no usa un bucle, pero demuestra cómo podríamos procesar las letras `ABA` en una máscara de bits.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    // it's important to initialize the mask to 0 so we don't get garbage values
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    mask |= 1 << letter_A_again - 'A';
    // prints 3
    printf("%d", mask);
}
```

Establecemos la parte más a la derecha de nuestra máscara en `0001` para la `A`, y luego establecemos la máscara en `0011` para la `B`.
Establecer otra `A` no produce ningún cambio en la máscara existente.
Podríamos haber evitado volver a establecer el bit comprobando si la `A` ya se había establecido.

### Operador AND a nivel de bits: una forma de leer un bit

`&` es el operador AND a nivel de bits.
El resultado del operador `&` será `1` en cada posición en la que tanto el operando izquierdo como el derecho tengan un bit establecido.
Así, el resultado de `0011 & 0001` sería `0001`.
Podemos verlo en acción en el siguiente ejemplo.

```c
#include <stdio.h>
#include <stdint.h>

int main() {
    uint32_t mask = 0;
    char letter_A = 'A';
    char letter_B = 'B';
    char letter_A_again = 'A';
    mask |= 1 << letter_A - 'A';
    mask |= 1 << letter_B - 'A';
    // prints A already set
    if (mask & 1 << letter_A_again - 'A')
        printf("A already set\n");
    else
        mask |= 1 << letter_A_again - 'A';
    printf("%d", mask);
}
```

### Operador OR exclusivo a nivel de bits: una forma de alternar un bit

`^` es el operador OR exclusivo a nivel de bits.
Un operador OR _inclusivo_ implica que existe un operador OR _exclusivo_ con un comportamiento diferente.
El resultado del operador `^` será `1` en cada posición en la que _solo uno_ de los operandos, izquierdo o derecho, tenga un bit establecido.
Así, el resultado de `0001 ^ 0011` sería `0010`.
El bit más a la derecha no se establecerá porque _ambos_ operandos tienen `1` en la posición más a la derecha.
La operación OR exclusivo a veces se denota como XOR.
Si al resultado de un valor al que se le aplica XOR se le vuelve a aplicar XOR, devolverá el valor original.
Esto se puede usar para un cifrado muy sencillo en el que se usa la misma clave tanto para cifrar como para descifrar los datos.
Por ejemplo

```c
#include <stdio.h>

int main() {
    char a = 'a';
    char b = 'b';
    char c = 'c';
    // we will use "a" for the "key"
    char first = a ^ 'a';
    char second = b ^ 'a';
    char third = c ^ 'a';
    // prints three "dots" for unprintable characters
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 0 3 2
    printf("%d %d %d\n", first, second, third);
    first = first ^ 'a';
    second = second ^ 'a';
    third = third ^ 'a';
    // prints a b c
    printf("%c %c %c\n", first, second, third);
    // prints the ascii values 97 98 99
    printf("%d %d %d\n", first, second, third);
}
```

## Campos de bits

Hemos visto cómo los bits empaquetados en un tipo de datos simple se pueden direccionar por su posición.
Los bits empaquetados en una `struct` se pueden direccionar por su nombre.
Ese tipo de datos se llama `bit field`.
Un caso de uso de los `bit fields` puede darse cuando se necesita una colección de banderas ON/OFF y se desea minimizar el uso de memoria.

```c
#include <stdio.h>

int main() {

    struct lights {
        unsigned int number_of_lights;
        unsigned int red   : 1;
        unsigned int green : 1;
        unsigned int blue  : 1;
    };
    struct lights lightboard = {3, 0, 0, 0};
     
    //  prints 000
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    lightboard.green = 1;

    //  prints 010
    printf("%d", lightboard.red);
    printf("%d", lightboard.green);
    printf("%d\n", lightboard.blue);
    
    // prints 3
    printf("%d\n", lightboard.number_of_lights);
}
```

La sintaxis de `unsigned int variable_name : 1;` crea un campo de `1` bit dentro de un `unsigned int` colocado dentro de la struct.
En lugar de un `unsigned int`, se podría usar un `signed int` o, a partir de C99, un tipo `bool`.
Una struct que contiene campos de bits también puede contener campos de otros tipos de datos, como `number_of_lights` en el ejemplo anterior.
