# Instrucciones

En este ejercicio vas a generar mensajes de registro semiestructurados.

## 1. Emite mensajes semiestructurados

Empezarás con algunas funciones sin implementar y el siguiente enum:

```rust
#[derive(Clone, PartialEq, Debug)]
pub enum LogLevel {
    Info,
    Warning,
    Error,
}
```

Tu objetivo es emitir un mensaje de registro con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.
Tendrás que implementar funciones que se correspondan con los niveles de registro.

Por ejemplo, el siguiente fragmento muestra una salida esperada para la función `log`.

```rust
log(LogLevel::Error, "Stack overflow")
// Returns: "[ERROR]: Stack overflow"
```

Y para `info`:

```rust
info("Timezone changed")
// Returns: "[INFO]: Timezone changed"
```

¡Que te diviertas!

## 2. Práctica adicional opcional

En esta suite hay una prueba condicionada por una funcionalidad.
Las puertas de funcionalidad desactivan por completo la compilación de ciertas secciones de tu programa.
Se verán más adelante.
Por ahora, basta con saber que hay una prueba que solo se compila y se ejecuta cuando usas una invocación de pruebas especial:

```sh
cargo test --features add-a-variant
```

Esta prueba pretende mostrarte cómo añadir una variante a tu enum.
