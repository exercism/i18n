# Anexo a las instrucciones

## Pistas

En Java se considera una buena práctica usar métodos de instancia en lugar de métodos de clase. Sin embargo, hay situaciones en las que es totalmente apropiado que una función sea `static`. Como las clases en Java están cerradas a la modificación (es decir, no puedes añadir miembros a una clase fuera de su definición como sí puedes hacer en otros lenguajes como Ruby o JavaScript), no puedes añadir comportamiento nuevo directamente a la clase. ¿Qué hacer si aun así quieres definir comportamiento para un tipo determinado? La solución idiomática en este caso es escribir un método de utilidad.
Las agrupaciones de este tipo de métodos suelen denominarse «clases de utilidad». Entre los ejemplos de este tipo de clases dentro del JRE se encuentran [Arrays](https://docs.oracle.com/javase/9/docs/api/java/util/Arrays.html) y [Collections](https://docs.oracle.com/javase/9/docs/api/java/util/Collections.html).
En este ejercicio queremos que un array tenga métodos `map()`, `reduce()`, `filter()`, etc. No los tiene, así que usamos métodos estáticos.

Los métodos `foldLeft` y `foldRight` son funciones «fold», un concepto muy conocido en el mundo de la programación funcional, pero menos en el de la orientada a objetos. Consulta la página de Wikipedia sobre las funciones fold para obtener [contexto general](https://en.wikipedia.org/wiki/Fold_(higher-order_function)) y [pistas sobre la signatura y la implementación](https://en.wikipedia.org/wiki/Fold_(higher-order_function)#Linear_folds).
