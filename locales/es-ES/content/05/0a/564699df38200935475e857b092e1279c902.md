# Pistas

## 1. General

- Lee sobre ficheros en la [guía oficial de introducción][getting-started-file].
- Lee sobre ficheros en [joyofelixir.com][joy-of-elixir-file].
- Echa un vistazo a la [documentación del módulo `File`][file].

## 1. Leer direcciones de correo de un fichero

- Hay una [función integrada][file-read] para leer el contenido de un fichero de una sola vez.

## 2. Abrir un fichero de registro para escribir en él

- Hay una [función integrada][file-open] para abrir un fichero.
- El segundo argumento de esa función es una lista de modos que permite especificar que el fichero debe abrirse para escribir en él.

## 3. Registrar un correo enviado

- Las funciones para leer y escribir en un fichero abierto con [`File.open!/1`][file-open] se encuentran en el módulo [`IO`][io].
- Hay una [función integrada][io-puts] para escribir un string en un fichero, seguido de un salto de línea.

## 4. Cerrar el fichero de registro

- Hay una [función integrada][file-close] para cerrar un fichero.

## 5. Enviar el boletín

- Todas las operaciones necesarias sobre ficheros ya se implementaron en los pasos anteriores.
- Antes de escribir en un fichero, hay que abrirlo.
- Una vez terminadas todas las operaciones de escritura en un fichero, hay que cerrarlo.
