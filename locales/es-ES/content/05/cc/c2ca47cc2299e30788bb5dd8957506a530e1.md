# Pruebas

## Probar de forma interactiva

Inicia el REPL desde el directorio donde descargaste el ejercicio.

Puedes ejecutar las pruebas cargando el archivo de pruebas en el REPL con `(load "exercise-test")` (sustituyendo «exercise» por el nombre correspondiente). Después, evalúa `(exercise-test:run-tests)` para ejecutar todas las pruebas.

Si escribes tu código directamente en el REPL, simplemente evalúa `(exercise-test:run-tests)`.

Si escribes tu código en el archivo Lisp del ejercicio, cárgalo con `(load "exercise")` y después evalúa `(exercise-test:run-tests)`.

## Probar desde la línea de comandos

Puedes lanzar las pruebas con esta invocación de línea de comandos (de nuevo, sustituye «exercise» por el nombre correspondiente en dos sitios)

```sh
ros run --load exercise-test.lisp --eval '(uiop:quit (if (exercise-test:run-tests) 0 1))'
```
