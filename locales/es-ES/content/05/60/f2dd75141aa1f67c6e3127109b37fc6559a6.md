# Instalación

- macOS: ejecuta `brew install futhark`
- Linux: ejecuta `brew install futhark`
- Windows: usa WSL o sigue [las instrucciones específicas para Windows][windows-specific-instructions]

Puedes encontrar otros métodos de instalación en las [instrucciones oficiales de instalación][instructions].

[instructions]: https://futhark.readthedocs.io/en/stable/installation.html
[windows-specific-instructions]: https://futhark.readthedocs.io/en/stable/installation.html#windows-installation
