# Acerca de

Los números de coma flotante son números fraccionarios o enteros que incluyen un punto decimal (como `3.14`, `-1.7`, `99.99`, `2048.0`).

El tipo de coma flotante de Common Lisp se subdivide en varios subtipos, cada uno con sus propias características y precisión: short-float, single-float, double-float y long-float.

El subtipo short-float suele ocupar la menor cantidad de memoria y ofrece la precisión más baja de los cuatro subtipos. Es adecuado para situaciones en las que el uso de memoria es una preocupación, pero se puede aceptar menos precisión.

El subtipo single-float ofrece un equilibrio entre el uso de memoria y la precisión. Se usa habitualmente para cálculos de coma flotante de propósito general.

El subtipo double-float ofrece una precisión mayor que single-float y es adecuado para aplicaciones que requieren cálculos más precisos, como los cálculos científicos y las simulaciones numéricas.

El subtipo long-float ofrece la precisión más alta de los cuatro subtipos, pero puede requerir más memoria que los demás. Se suele usar en aplicaciones especializadas que exigen cálculos extremadamente precisos.

Estos subtipos permiten a los programadores de Common Lisp elegir el nivel de precisión y de uso de memoria adecuado según los requisitos de sus aplicaciones concretas.

En general, si trabajas solo con números enteros, es preferible que uses enteros, ya que no sufren la misma pérdida de precisión que los números de coma flotante tras muchos cálculos.

## Referencia

```lisp
;; Rounding to the Nearest Whole Number
(round 3.14)  ; => 3
(round -3.14) ; => -3
(round 2.72)  ; => 3
(round -2.72) ; => -3

;; Rounding Towards Zero
(truncate 3.14)  ; => 3
(truncate -3.14) ; => -3
(truncate 2.72)  ; => 2
(truncate -2.72) ; => -2

;; Rounding Towards Negative Infinity
(floor 3.14)  ; => 3
(floor -3.14) ; => -4
(floor 2.72)  ; => 2
(floor -2.72) ; => -3

;; Rounding Towards Positive Infinity
(ceiling 3.14)  ; => 4
(ceiling -3.14) ; => -3
(ceiling 2.72)  ; => 3
(ceiling -2.72) ; => -2
```
