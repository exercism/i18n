# Acerca de

Un `SYMBOL:` no *contiene* un valor: solo es un nombre. El valor vive en un espacio de nombres, y el nombre es la clave que apunta a él.

```factor
USING: namespaces ;

SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

Dos scopes:

- **global**: se escribe y se lee con `set-global`, `get-global`, `change-global`. Los valores persisten durante toda la vida del proceso.
- **dynamic**: se escribe y se lee con `set`, `get`, `change`. Las vinculaciones duran lo que dura una forma `with-variable`, lo que permite que el código externo «inyecte» un valor que ve el código interno sin cambiar todas las firmas que hay entre medias.

```factor
"verbose" log-level [
    log-level get .   ! => "verbose"
] with-variable
```

`SYMBOL:` y `SYMBOLS:` declaran símbolos en el momento de cargar el vocabulario, lo que los convierte en referencias que se pueden compartir entre ficheros.
