# Debug

Cuando un test falla, se muestra un mensaje que describe qué ha ido mal y con qué entrada. También puedes aprovechar que la [salida por consola][fmt-println] se mostrará. Puedes escribir en la consola usando:

```go
import "fmt"
fmt.Println("Debug message")
```

[fmt-println]: https://pkg.go.dev/fmt#Println

Nota: al depurar con el editor del navegador, usar, por ejemplo, `fmt.Print` no añade un salto de línea después de la salida, lo que puede provocar un bug en `go test --json` y dar lugar a una salida de tests desordenada.
