# Pistas

## General

- En la «Getting Started Guide» de Elixir encontrarás un buen repaso sobre las funciones con nombre.

## 1. Genera la respuesta cuando el intento coincida con el número secreto

- Puedes usar una [guarda][guard] para comprobar si los números son iguales con `===/2`.

## 2. Genera la respuesta cuando el intento sea mayor que el número secreto

- Puedes añadir una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es mayor `>/2` que el número secreto.

## 3. Genera la respuesta cuando el intento sea menor que el número secreto

- Puedes añadir una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es menor `</2` que el número secreto.

## 4. Genera las respuestas cuando el intento sea uno más o uno menos que el número secreto

- Puedes añadir una [cláusula de función][multiple-fn-clauses] y [guardas][guard] para comprobar si el intento es uno menos o uno más que el número secreto.
- Las expresiones de guarda pueden usar `and/2` u `or/2` para combinar expresiones booleanas.
- Presta atención al orden de las cláusulas de función.

## 5. Genera la respuesta cuando no haya intento

- Puedes hacer uso de un [argumento por defecto][default-arg] para el intento. El valor por defecto no tiene que ser un número entero.
- Usa una cabecera de función antes que el resto de cláusulas de función para definir el argumento por defecto.

[default-arg]: https://hexdocs.pm/elixir/modules-and-functions.html#default-arguments
[guard]: https://hexdocs.pm/elixir/Kernel.html#guards
[guide]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
[multiple-fn-clauses]: https://hexdocs.pm/elixir/modules-and-functions.html#function-definition
