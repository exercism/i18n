# Instrucciones

Tu tarea es parsear coordenadas GPS.
Cada coordenada está formateada usando la variante del [formato de grados decimales](https://en.wikipedia.org/wiki/Decimal_degrees) con hemisferios explícitos:

```text
<LATITUDE_DEGREES> <LATITUDE_HEMISPHERE>, <LONGITUDE_DEGREES> <LONGITUDE_HEMISPHERE>
```

Estos son los valores permitidos para cada componente individual:

- `<LATITUDE_DEGREES>`: un número de coma flotante en el rango 0..90 (ambos inclusive)
- `<LATITUDE_HEMISPHERE>`: ya sea `N` o `S`
- `<LONGITUDE_DEGREES>`: un número de coma flotante en el rango 0..180 (ambos inclusive)
- `<LONGITUDE_HEMISPHERE>`: ya sea `E` o `W`

Por ejemplo, `"48.8584 N, 2.2945 E"` se parsea como:

- `<LATITUDE_DEGREES>`: 48.8584
- `<LATITUDE_HEMISPHERE>`: N
- `<LONGITUDE_DEGREES>`: 2.2945
- `<LONGITUDE_HEMISPHERE>`: E

Tienes 11 tareas en las que irás parseando coordenadas GPS de forma incremental.
Usarás el soporte de [Gramáticas de Cláusulas Definidas](https://en.wikipedia.org/wiki/Definite_clause_grammar) (DCG) de Prolog, que están diseñadas para parsear texto estructurado.

````exercism/note
Para ayudarte a empezar, el archivo stub ya incluye la [biblioteca `dcg/basics`](https://www.swi-prolog.org/pldoc/doc/_SWI_/library/dcg/basics.pl) mediante:

```prolog

```
````

## 1. Parsear una coma

Implementa la regla `comma` para parsear una sola coma (`","`):

```prolog
?- string_codes(",", Codes), phrase(comma, Codes).
```

## 2. Parsear un espacio

Implementa la regla `space` para parsear un solo espacio (`" "`):

```prolog
?- string_codes(" ", Codes), phrase(space, Codes).
```

## 3. Admitir todos los espacios en blanco (excepto los saltos de línea)

Modifica la regla `space` para parsear _todos_ los espacios en blanco, excepto los saltos de línea:

```prolog
?- string_codes("\t", Codes), phrase(space, Codes).

?- string_codes("\n", Codes), phrase(space, Codes).
false.
```

## 4. Parsear el hemisferio de la latitud

El hemisferio de la latitud puede ser `"N"` o `"S"`, y debe parsearse al átomo `north` o `south`.
Implementa la regla `latitude_hemisphere` para parsear el hemisferio de la latitud:

```prolog
?- string_codes("N", Codes), phrase(latitude_hemisphere(Hemisphere), Codes).
Hemisphere = north.
```

## 5. Parsear el hemisferio de la longitud

El hemisferio de la longitud puede ser `"E"` o `"W"`, y debe parsearse al átomo `east` o `west`.
Implementa la regla `longitude_hemisphere` para parsear el hemisferio de la longitud:

```prolog
?- string_codes("E", Codes), phrase(longitude_hemisphere(Hemisphere), Codes).
Hemisphere = east.
```

## 6. Parsear los grados

Los grados de una longitud o de una latitud se definen como un número de coma flotante.
Implementa la regla `degrees` para parsear números de coma flotante:

```prolog
?- string_codes("748.012", Codes), phrase(degrees(Degrees), Codes).
Degrees = 748.012.
```

## 7. Parsear los grados de la latitud

Los grados de la latitud no son solo números de coma flotante, sino números de coma flotante en el rango 0..90 (ambos inclusive).
Implementa la regla `latitude_degrees` para parsear los grados de la latitud usando el rango anterior:

```prolog
?- string_codes("48.745", Codes), phrase(latitude_degrees(Degrees), Codes).
Degrees = 48.745.

?- string_codes("117.844", Codes), phrase(latitude_degrees(Degrees), Codes).
false.
```

## 8. Parsear los grados de la longitud

Los grados de la longitud no son solo números de coma flotante, sino números de coma flotante en el rango 0..180 (ambos inclusive).
Implementa la regla `longitude_degrees` para parsear los grados de la longitud usando el rango anterior:

```prolog
?- string_codes("178.773", Codes), phrase(longitude_degrees(Degrees), Codes).
Degrees = 178.773.

?- string_codes("-22.523", Codes), phrase(longitude_degrees(Degrees), Codes).
false.
```

## 9. Parsear la latitud

Las latitudes tienen dos partes: sus grados y su hemisferio, que están separados por un espacio.
Implementa la regla `latitude` para parsear una latitud:

```prolog
?- string_codes("56.101 N", Codes), phrase(latitude(Degrees, Hemisphere), Codes).
Degrees = 56.101,
Hemisphere = north.
```

## 10. Parsear la longitud

Las latitudes tienen dos partes: sus grados y su hemisferio, que están separados por un espacio.
Implementa la regla `latitude` para parsear una latitud:

```prolog
?- string_codes("143.889 W", Codes), phrase(longitude(Degrees, Hemisphere), Codes).
Degrees = 143.889,
Hemisphere = west.
```

## 11. Parsear la coordenada

Las coordenadas tienen dos partes: su latitud y su longitud, que están separadas por una coma seguida de un espacio.
Implementa la regla `coordinate` para parsear tanto la latitud (grados y hemisferio):

```prolog
?- string_codes("48.8584 N, 2.2945 E", Codes), phrase(coordinate(Latitude, LatitudeHemisphere, Longitude, LongitudeHemisphere), Codes).
Latitude = 48.8584,
LatitudeHemisphere = north,
Longitude = 2.2945,
LongitudeHemisphere = east.
```
