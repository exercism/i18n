# Instrucciones

Había una vez un programador excéntrico que vivía en una casa extraña con ventanas enrejadas.
Un día aceptó un encargo de un portal de empleo en línea para construir un robot de fiestas.
Se supone que el robot saluda a la gente y la ayuda a llegar a su asiento.
La primera edición era muy técnica y dejaba ver la falta de habilidades sociales del programador.
Parte de eso también se trasladó a la siguiente edición.

## 1. Da la bienvenida a un nuevo invitado a la fiesta

Implementa la función `Welcome` para que devuelva un mensaje de bienvenida usando el nombre dado:

```go
Welcome("Christiane")
// => Welcome to my party, Christiane!
```

## 2. Da la bienvenida a un nuevo invitado que cumple años hoy

Implementa la función `HappyBirthday` para que devuelva un mensaje de cumpleaños usando el nombre y la edad de la persona.
Por desgracia, el programador es un poco presumido, así que el robot tiene que demostrar que se sabe el cumpleaños de cada invitado.

```go
HappyBirthday("Frank", 58)
// => Happy birthday Frank! You are now 58 years old!
```

## 3. Da indicaciones

Implementa la función `AssignTable` para dar indicaciones.
Debe aceptar 5 parámetros.

- El nombre del nuevo invitado al que saludar (`string`)
- El número de mesa (`int`)
- El nombre de la persona que se sentará al lado (`string`)
- La dirección en la que se encuentra la mesa (`string`)
- La distancia a la mesa (`float64`)

El formato exacto del resultado puede verse en el ejemplo siguiente.

El robot proporciona el número de mesa en un formato de 3 dígitos.
Si el número tiene menos de 3 dígitos, se le añaden ceros a la izquierda hasta llegar a 3 dígitos (p. ej., 3 se convierte en 003).
El robot también menciona la distancia a la mesa.
Por suerte, solo con una precisión limitada a 1 dígito.

```go
AssignTable("Christiane", 27, "Frank", "on the left", 23.7834298)
// =>
// Welcome to my party, Christiane!
// You have been assigned to table 027. Your table is on the left, exactly 23.8 meters from here.
// You will be sitting next to Frank.
```
