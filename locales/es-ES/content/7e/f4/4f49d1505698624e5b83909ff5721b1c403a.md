# Introducción

Ruby viene con una biblioteca estándar (a la que a menudo se abrevia como «stdlib»), una colección de clases para trabajar con cosas como fechas, json o redes.
También ofrece algunas funcionalidades útiles para que tu código sea más fácil de manejar.

`OpenStruct` forma parte de la biblioteca estándar y te permite crear un objeto fácilmente a partir de un `Hash`.
En lugar de tener que acceder mediante las claves del `Hash`, `OpenStruct` nos permite usar métodos para acceder a los valores y establecerlos.

Cuando usas clases de la biblioteca estándar, o de cualquier otra biblioteca, necesitas requerir esa clase con el método `require`.

```ruby
require 'ostruct'

attributes = { name: "Jeremy Walker", age: 21, location: "Nomadic" }
person = OpenStruct.new(attributes)

person.name
#=> Jeremy Walker

person.location
#=> Nomadic

# Update the age
person.age = 35

# It sets correctly
person.age
#=> 35
```

Una ventaja adicional de esto es que puedes aprovechar un atajo al usar la sintaxis de bloque.
Cuando un bloque llama a un solo método, puedes sustituir el bloque por `&:` seguido del nombre del método.
Por ejemplo, estas dos líneas son sinónimas:

```ruby
people.sum { |person| person.age }
people.sum(&:age)
```
