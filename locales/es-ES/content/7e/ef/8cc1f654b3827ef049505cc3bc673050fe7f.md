# Introducción

R no tiene un tipo de dato Set propio, sino que usa una variedad de funciones para realizar operaciones similares sobre vectores.

El operador `%in%` comprueba la pertenencia a un conjunto.

```R
2 %in% 1:10 # TRUE
12 %in% 1:10 # FALSE
```

Entre las funciones relevantes están `unique` (para eliminar duplicados) y también `union()`, `intersect()`, `setdiff()` y `setequal()`, que operan sobre pares de conjuntos.

```R
> set_1 <- c("a", "b", "c", "b", "a")
> unique(set_1) # deduplicate
[1] "a" "b" "c"

> set_2 <- c('a', "c", "d")
> union(set_1, set_2) # values in either set
[1] "a" "b" "c" "d"

> intersect(set_1, set_2) # values in both sets
[1] "a" "c"

> setdiff(set_1, set_2) # values in set_1 but not set_2
[1] "b"

> setdiff(set_2, set_1) # values in set_2 but not set_1
[1] "d"

setequal(set_1, c("c", "b", "a", "b")) # are elements the same after deduplication?
[1] TRUE
```

En todos los casos, `set_1` y `set_2` permanecen sin cambios.
