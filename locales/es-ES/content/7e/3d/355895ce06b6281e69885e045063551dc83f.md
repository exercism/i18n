Diseña una suite de pruebas para una herramienta que cuente líneas, letras y caracteres.

Este es un ejercicio especial.
En lugar de escribir código que funcione con una suite de pruebas ya existente, eres tú quien define la suite de pruebas.
Para ayudarte, se han proporcionado varias variaciones del código que hay que probar; tu suite de pruebas debería ser capaz al menos de detectar los problemas que tengan (o la ausencia de ellos).

Se supone que el sistema bajo prueba es un sistema que cuenta el número de líneas, letras y caracteres totales en los strings que se le pasan.
La idea es que realices la operación «add string» varias veces, pasando strings, y que después llames a las funciones «lines», «letters» y «characters» para obtener los totales.
