# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el formato `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro: `INFO`, `WARNING` y `ERROR`.

Tienes tres tareas. Cada una recibe una única línea de registro de la pila.

## 1. Obtener el mensaje de una línea de registro

Define `message` para que devuelva el mensaje de la línea de registro. Hay que eliminar los espacios en blanco que haya al principio y al final.

```factor
"[ERROR]: Invalid operation" message .
! => "Invalid operation"

"[WARNING]:  Disk almost full\r\n" message .
! => "Disk almost full"
```

## 2. Obtener el nivel de una línea de registro

Define `log-level` para que devuelva el nivel de la línea de registro, en minúsculas.

```factor
"[ERROR]: Invalid operation" log-level .
! => "error"
```

## 3. Reformatear una línea de registro

Define `reformat` para que ponga el mensaje primero y, a continuación, el nivel de registro en minúsculas entre paréntesis.

```factor
"[INFO]: Operation completed" reformat .
! => "Operation completed (info)"
```

----

***Nota:*** Todos los strings de este ejercicio son ASCII. En ejercicios posteriores se abordará el tratamiento de strings con Unicode.
