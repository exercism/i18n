# Introducción

La memoria en C# se asigna (normalmente) _automáticamente_; no es necesario asignar memoria manualmente. Para permitir que la memoria asignada automáticamente también se libere cuando ya no se utiliza, C# usa un recolector de basura.

Hay dos tipos diferentes de memoria que se utilizan al trabajar con C#:

- La pila: de corta duración y con espacio limitado disponible.
- El montículo: de larga duración y con mucha memoria disponible.
