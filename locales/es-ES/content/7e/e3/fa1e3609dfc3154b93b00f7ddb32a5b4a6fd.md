# Instrucciones

Elyse, aspirante a maga, continúa su entrenamiento. Se le darán varias pilas de cartas con las que deberá realizar sus trucos.
Para ponérselo un poco más fácil, solo usa las cartas del 1 al 10.

En este ejercicio, usa métodos integrados para analizar el contenido de un vector.

## 1. Determinar si una carta está presente

Elyse quiere determinar si una carta está presente en la pila, es decir, si la pila contiene un número concreto.

```R
card = 3;
does_stack_include_card(c(2, 3, 4, 5), card);
# => TRUE
```

## 2. Encontrar la posición de una carta

Elyse quiere saber la posición (el índice) de una carta en la pila. 
Si la carta no está en la pila, devuelve `-1`.

```R
card = 2;
get_card_position(c(9, 7, 3, 2), card);
# => 4
```

## 3. Determinar si cada carta es par

Elyse quiere saber si todas las cartas son pares, es decir, si cada número de la pila es un número par.

```R
is_each_card_even(c(2, 4, 6, 7));
# => FALSE
```

## 4. Comprobar si la pila contiene una carta con un valor impar

Elyse quiere saber si hay algún número impar en la pila.

```R
does_stack_include_odd_card(c(3, 2, 6, 4, 8));
# => TRUE
```

## 5. Obtener la primera carta impar de la pila

Elyse quiere saber el valor de la primera carta que es impar.  
Si no hay ninguna carta impar en la pila, devuelve `-1`.

```R
get_first_odd_card(c(4, 2, 8, 7, 9));
# => 7
```

## 6. Determinar la posición de la primera carta que es par

Elyse quiere saber la posición de la primera carta que es par.
Si no hay ninguna carta par en la pila, devuelve `-1`.

```R
get_first_even_card_position(c(5, 2, 3, 1));
# => 2
```
