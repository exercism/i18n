# El operador ternario

Un condicional ternario es una forma más corta de escribir instrucciones `if/else` sencillas.
Si una instrucción `if/else` contiene solo dos ramas, una para cuando la condición es verdadera y otra para cuando es falsa, se puede reescribir como un condicional ternario.

Los ternarios usan una combinación de los símbolos `?` y `:` para dividir un condicional:
```ruby
condition ? true_branch : false_branch
```

El código a la izquierda del `?` es la condición y el código de la derecha contiene las dos ramas posibles, separadas por el `:`.
Si la condición es _verdadera_, se ejecuta el código que está a la _izquierda_ del `:`.
Si la condición es _falsa_, se ejecuta el código que está a la _derecha_ del `:`.

Por ejemplo:

```ruby
if traffic_light == 'green'
  cross_the_road
else
  wait
end
```

se puede reescribir como:

```ruby
traffic_light == 'green' ? cross_the_road : wait
```
