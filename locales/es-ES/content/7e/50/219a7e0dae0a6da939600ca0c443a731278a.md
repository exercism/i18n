# Instrucciones

Eres un ávido observador de aves que lleva la cuenta de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de pájaros que han visitado tu jardín.

## 1. Comprueba cuántos pájaros han visitado hoy el jardín

Implementa la función `today()` para que devuelva cuántos pájaros han visitado tu jardín hoy. Los recuentos de pájaros están ordenados por día, siendo el primer elemento el recuento del día más antiguo y el último elemento el recuento de hoy.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
today(birds_per_day)
# => 1
```

## 2. Incrementa el recuento de hoy

Implementa la función `increment_todays_count()` para incrementar el recuento de hoy:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
increment_todays_count(birds_per_day)
# => c(2, 5, 0, 7, 4, 2)
```

## 3. Comprueba si hubo un día sin pájaros visitantes

Implementa la función `has_day_without_birds()` que devuelve `TRUE` si hubo un día en el que cero pájaros visitaron el jardín; en caso contrario, devuelve `FALSE`:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
has_day_without_birds(birds_per_day)
# => true
```

## 4. Calcula el número de pájaros visitantes durante los primeros días indicados

Implementa la función `count_for_first_days()` que devuelve el número de pájaros que han visitado tu jardín desde el principio de la semana, pero limita el recuento al número de días especificado desde el principio de la semana.

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
count_for_first_days(birds_per_day, 4)
# => 14
```

## 5. Calcula el número de días ajetreados

Algunos días están más ajetreados que otros. Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.
Implementa la función `busy_days()` para que devuelva el número de días ajetreados:

```R
birds_per_day <- c(2, 5, 0, 7, 4, 1)
busy_days(birds_per_day)
# => 2
```

## 6. Calcula el total acumulado de visitas de pájaros durante la última semana

Tienes curiosidad por saber cuántos pájaros en total han visitado tu jardín en lo que va de semana.
Calcula los totales acumulados de cada día.

```R
running_total(c(7, 6, 5, 4, 3, 2, 1))
#> [1]  7 13 18 22 25 27 28
```

## 7. Ordena los nombres de los días según lo ajetreados que sean

Sospechas que las visitas de los pájaros se ven afectadas por patrones de tráfico rodado cercano, por lo que son diferentes los fines de semana que entre semana.

Ordena las abreviaturas de los días en orden _descendente_ según cuántos pájaros visitaron.

```R
day_names <- c("Mon", "Tue", "Wed", "Thu", "Fri", "Sat", "Sun")
birds_per_day <- c(5, 2, 4, 6, 0, 9, 8)
busy_days_of_week(birds_per_day, day_names)
#> [1] "Sat" "Sun" "Thu" "Mon" "Wed" "Tue" "Fri"
```
