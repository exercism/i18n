# Instalación para hackers de Linux (solo para uso avanzado de Linux)

Todavía estamos dándole vueltas a cuáles son las mejores instrucciones para esta parte, pero sabemos (y agradecemos) que muchos desarrolladores de Linux son muy exigentes con lo que instalan y con dónde debe ir cada cosa.

_Si lo que quieres es una instalación estándar, vuelve atrás y sigue [la instalación habitual](https://exercism.io/tracks/pharo-smalltalk/installation)._

Las siguientes instrucciones todavía están en desarrollo y se basan en ArchLinux, pero puede que sirvan para tu distribución (y si no te resultan útiles, ayúdanos a encontrar mejoras, y quizá también a plantear peticiones al propio proyecto Pharo). _Nota: todavía no está claro si estas instrucciones funcionan de forma fiable, así que agradeceríamos cualquier ayuda para mejorarlas._

- Instala una máquina virtual de Pharo en la ubicación que prefieras. Es posible que puedas usar una de AUR o su equivalente si ahí aparece pharo 7, O bien descargar una desde: [https://files.pharo.org/vm/pharo-spur64/linux/] (y elegir una máquina virtual stable-timer)
- A continuación, tienes que extraer un archivo Pharo.image para colocarlo en tu directorio de Exercism. Puedes obtenerlo en: [https://files.pharo.org/image/70/] y elegir el archivo zip de 64 bits más reciente.
- Ahora prueba una comprobación sencilla desde la línea de comandos para verificar si la máquina virtual y la imagen funcionan: `pharo Pharo.image eval "100 factorial"`. Si todo va bien, deberías obtener una respuesta.
- Ahora prueba el «load script» que se describe en la sección de OSX. Es posible que te aparezca un error que mencione `libgit2`; si es el caso, también deberías instalarlo y volver a intentarlo. También nos han comentado que instalar `libcurl-gnutls` puede ayudar (aunque todavía no está demostrado)
- También nos han comentado que, para algunos fallos de libgit2, hay un cambio interno en loadModule que quizá podamos incorporar desde el pharo en desarrollo. En ese caso, tienes que reemplazar el método `unixModuleName` de la clase `LGitLibrary` de la siguiente manera:
  1. Abre un Pharo con interfaz gráfica escribiendo `pharo-ui Pharo.image`
  1. Pulsa Ctrl+Espacio y escribe `unixModuleName`
  1. Selecciona la entrada `LGitLibrary >> unixModuleName` y pulsa Intro
  1. En el navegador que aparezca, sustituye el código del método `unixModuleName` por lo siguiente (cópialo y pégalo), pulsa guardar (ctrl-s) y, por último, guarda y sal del pharo.
```
LGitLibrary >> unixModuleName
	| pluginDir |
	pluginDir := Smalltalk vm binary parent.
	#('libgit2.so' 'libgit2.so.0')
		detect: [ :each | (pluginDir / each) exists ] 
		ifFound: [ :libName | ^ (pluginDir / libName) fullName ].

	self error: 'Module not found.' 
 ```

Ahora vuelve a probar el «load script» de Exercism para OSX que hemos mencionado antes. Si todo funciona correctamente, verás barras de progreso de carga parpadeando por la pantalla y, después, aparecerá una ventana del System Browser. Si no es así, visita el Discord de Pharo (como se explica más arriba).

Ahora deberías volver y seguir el resto de las [instrucciones para empezar](https://exercism.io/tracks/pharo-smalltalk/installation).
