# Introducción

## Herencia

La herencia es un concepto fundamental de la POO (programación orientada a objetos).
Representa una relación ES-UN.
Significa en programación exactamente lo mismo que en el lenguaje común: heredar características del padre (en programación, esas características suelen ser funciones y variables).

Considera una clase, `Animal`, como se muestra a continuación:

```java
//Creating an Animal class with bark() as a member function.
public class Animal {

    public void bark() {
        System.out.println("This is an animal");
    }

}
```

`Animal` es una clase padre, porque las propiedades que tiene esta clase se pueden extender a todos los animales en general.

Considera un animal llamado `Lion`, con una clase como esta:

```java
//Lion class is a child class of Animal.
public class Lion extends Animal {

    @Override
    public void bark() {
        System.out.println("Lion here!!");
    }

}
```

~~~~exercism/note
La anotación `Override` se usa para indicar que un método de una subclase sobrescribe un método de su superclase.
No es estrictamente necesaria, pero es una buena práctica usarla.
~~~~

Ahora, siempre que hagamos lo siguiente:

```java
Animal animal = new Lion(); //creating instance of Animal, of type Lion
animal.bark();
```

Nota: se inicializa la clase `Animal` con `Lion`.
La salida tendrá este aspecto:

```java
Lion here!!
```

Según la POO, existen muchos tipos de herencia, pero Java solo admite algunos de ellos (multinivel y jerárquica).
Para leer más sobre el tema, consulta [esto][java-inheritance].
