# Acerca de

JavaScript tiene un operador de incremento y un operador de decremento.
Modifican una variable directamente.
`++` suma uno a un número, `--` resta uno a un número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```

El ejemplo anterior muestra el operador de incremento/decremento posfijo.
En este caso, el operador se coloca después de la variable y el valor devuelto por la expresión es el valor que tenía la variable _antes_ del aumento o la disminución.

```javascript
let a = 3;
let b = a++;
// a = 4
// b = 3
```

También existe la variante prefija, en la que el operador se coloca antes de la variable.
Entonces, el valor devuelto es el valor de la variable _después_ del aumento o la disminución.

```javascript
let a = 3;
let b = ++a;
// a = 4
// b = 4
```
