# Instrucciones

A Lucy, la alienígena Lisp, le gustan los números y piensa que algunos son «magníficos».

Te pide ayuda para escribir funciones que hagan que los números sean más magníficos.

Lo que Lucy piensa que hace que un número sea magnífico puede cambiar, así que las funciones tendrán que ser flexibles.

## 1. Hazlos magníficos

Para convertir un array de números en un array de números más magníficos, tendrás que escribir una función `make-magnificent-maybe` que reciba una función que se aplique a los números y un array de números.
Debería evaluarse a un array de números que sean más magníficos (según la función proporcionada).

```lisp
(make-magnificent-maybe #'square '(1 2 3)) ; => (1 4 9)
(make-magnificent-maybe #'1+ '(1 2 3))     ; => (2 3 4)
```

## 2. Solo los mejores

Después de (con suerte) hacer que los números sean más magníficos, Lucy solo quiere ver los números que son verdaderamente magníficos.

Sabe con certeza que el 1 *nunca* es magnífico, así que tendrás que eliminarlo sin más.

Pero aparte de eso, Lucy cambia de opinión a veces, así que de nuevo te dará una función que te dirá si un número es magnífico o no.

Tendrás que escribir una función `only-the-best` que reciba una función y un array de números y devuelva solo los mejores números (ni `1` ni números para los que la función se evalúe como verdadero).

```lisp
(only-the-best #'evenp '(1 2 3 4 5)) ; => (3 5)
(only-the-best #'oddp '(1 3 5))    ; => ()
```
