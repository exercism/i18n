# Consejos

## 1. Determinar cuánto se tarda en mezclar un zumo

- Vuelve a consultar el concepto [Switch][concept-switch] para ver formas de abordar esto.

## 2. Reponer el suministro de gajos de lima

- Haz un bucle hasta que se cumpla una de las condiciones de las instrucciones.
- Puede resultar útil, aunque no es obligatorio, tener una pequeña función auxiliar que relacione los tamaños de las limas con el número de gajos que producen.
- De nuevo, el concepto [Switch][concept-switch] puede sugerirte enfoques prácticos.
- Devuelve cuántas limas se cortaron realmente.

## 3. Listar los tiempos de mezcla de cada pedido en la cola

- En esta etapa del temario, el enfoque más sencillo usa un bucle `for` sobre `orders`, pero también se puede hacer con `seq_along`.
- Una tarea anterior puede proporcionarte una función útil.
- Usa [`print()`][print-function] para mostrar los tiempos en orden (consulta la introducción para ver un ejemplo).
- No debes devolver nada en este ejercicio.

## 4. Terminar el turno

- Haz un bucle mientras queden pedidos y algo de tiempo.
- Devuelve un vector con los pedidos que no se hayan empezado.
