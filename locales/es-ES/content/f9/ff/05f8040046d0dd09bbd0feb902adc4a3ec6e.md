# Acerca de

Una expresión Boolean es una pregunta que se hace a uno o más valores y que puede responderse con `true` o `false`.
Una expresión verdadera devuelve `1`; una expresión falsa devuelve `0`.
Además, los números tienen valores de verdadero/falso. El cero es `false`; cualquier valor distinto de cero es `true`.

El código C antiguo usa directamente el tipo `int` para los valores Boolean o bien el programador puede haber definido constantes como `TRUE` y `FALSE` para asignar `1` y `0` a una representación Boolean.

Con la versión C99 se añadió el tipo `_Bool`.
El archivo de cabecera `stdbool.h` define tres nuevos símbolos Boolean: `bool`, `true` y `false`.
`true` se asigna a `1`, `false` se asigna a `0` y `bool` se asigna a `_Bool`.
Así que ahora, en lugar de usar directamente valores `int` o de crear sus propias asignaciones Boolean, los programadores pueden incluir `stdbool.h` y obtener automáticamente símbolos Boolean en su código.

## Operadores de comparación

C admite seis operadores de comparación: `==` (igual), `!=` (distinto de), `>` (mayor que), `<` (menor que), `>=` (mayor o igual que) y `<=` (menor o igual que).
Estos operadores comparan las relaciones entre valores y las resuelven en valores Boolean.

```c
0 == 0 // true. Although 0 is false, 0 equals 0 is true.
0 != 0 // false
1 > 0 // true
1 < 0 // false
1 >= 0 // true
1 <= 0 // false
```

## Operadores Boolean

C admite tres operadores Boolean: `||` (o), `&&` (y) y `!` (no).

`!` se usa con un operando.
Invierte el valor Boolean del operando.
Por ejemplo, `0` es `false`, pero `!0` es `true`.

`||` y `&&` se usan con dos operandos.
El operando de la derecha solo se evalúa cuando el operando de la izquierda no determina ya el resultado de la expresión.
Es decir, `||` solo evalúa su operando de la derecha cuando su operando de la izquierda se evalúa como `false`.
`&&` solo evalúa su operando de la derecha cuando su operando de la izquierda se evalúa como `true`.


## Cortocircuito

No evaluar todos los operandos se conoce como «cortocircuito».
El cortocircuito es una forma concisa y potente de manejar ciertas situaciones.
Por ejemplo, un uso habitual es comprobar que un puntero no es `NULL` y (&&), si no es `NULL`, desreferenciarlo, evitando así desreferenciar un puntero `NULL`.
Pero el cortocircuito también puede dar lugar a bugs.
A veces, un programador olvida que el operando de la derecha de `||` o `&&` puede que no siempre se evalúe.
Si el operando de la derecha es una expresión con un efecto secundario que se espera que ocurra siempre, entonces será un bug en función del valor Boolean del operando de la izquierda.


## Devolver una expresión Boolean

El resultado de una expresión Boolean se puede devolver directamente.
Por ejemplo, esta instrucción `if`

```c
if (count > 0)
    return true;
else
    return false;
end
```

se puede sustituir por

```c
return count > 0;
```
