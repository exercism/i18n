# Introducción

Este ejercicio se apoya en la pila de datos y en la notación de efectos de pila que conociste en [Cargo Shuffle][cargo-shuffle]. Aquí escribirás palabras que combinan valores booleanos.

## Palabras de reorganización

Las palabras de reorganización más habituales están en [`kernel`][kernel]:

```
dup    ( x -- x x )
dupd   ( x y -- x x y )
drop   ( x -- )
swap   ( x y -- y x )
swapd  ( x y z -- y x z )
over   ( x y -- x y x )
pick   ( x y z -- x y z x )
rot    ( x y z -- y z x )
-rot   ( x y z -- z x y )
rotd   ( w x y z -- w y z x )
spin   ( x y z -- z y x )
nip    ( x y -- y )
tuck   ( x y -- y x y )

2dup   ( x y -- x y x y )
3dup   ( x y z -- x y z x y z )
4dup   ( w x y z -- w x y z w x y z )
2drop  ( x y -- )
3drop  ( x y z -- )
4drop  ( w x y z -- )
2nip   ( x y z -- z )
2swap  ( x y z w -- z w x y )
```

## Valores booleanos

Los dos literales booleanos son `t` y `f`. `f` es el único valor falso de Factor: todo lo demás, incluidos `0` y las colecciones vacías, se evalúa como verdadero.

```factor
t .    ! => t
f .    ! => f
```

## Palabras booleanas

Estas tres palabras booleanas del vocabulario `kernel`:

```
and ( x y -- ? )    ! true when both inputs are truthy
or  ( x y -- ? )    ! true when either input is truthy
not ( x   -- ? )    ! inverts its argument
```

```factor
t t and .    ! => t
t f and .    ! => f
f t or .     ! => t
t not .      ! => f
```

El `?` en cada salida es la convención de los efectos de pila para indicar «un valor booleano».

Necesitarás `swap` para una de las tareas que se plantean a continuación.
