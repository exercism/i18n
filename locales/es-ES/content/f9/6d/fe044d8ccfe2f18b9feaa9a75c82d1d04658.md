# Acerca de

[SQLite][sqlite] es un sistema de gestión de [bases de datos relacionales][relational-database] de código abierto, ligero, sin servidor y autónomo.
Es conocido por su sencillez, su facilidad de uso y porque no requiere configuración alguna.
SQLite puede integrarse dentro de aplicaciones, lo que lo convierte en una opción ideal para aplicaciones, sistemas embebidos y proyectos de pequeña y mediana escala.

Creado por [D. Richard Hipp][hipp], SQLite sigue las propiedades [ACID][acid], pensadas para facilitar transacciones fiables.
Se utiliza ampliamente en diversos sectores gracias a su huella mínima y a su rendimiento eficiente.

SQLite emplea una sintaxis sencilla basada en SQL para definir bases de datos e interactuar con ellas.
Las tablas, los índices y las consultas se crean mediante instrucciones SQL estándar, lo que proporciona a los desarrolladores una forma familiar y expresiva de gestionar bases de datos.
El motor de la base de datos es autónomo, lo que elimina la necesidad de un proceso de servidor aparte.
Esta sencillez, combinada con sus potentes capacidades, convierte a SQLite en una excelente opción para proyectos en los que la facilidad de uso y la eficiencia son una prioridad.

Para obtener información detallada y documentación, consulta la [documentación oficial de SQLite][sqlite docs].
