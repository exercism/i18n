# Pistas

## 1. Calcula el precio de una pizza

- Crea una función recursiva que devuelva el precio de un ingrediente extra sumado al precio de la pizza sin ese ingrediente.
- Si aparece el error `Maximum call stack size exceeded`, comprueba si te has olvidado del caso base.
- Si te aparece un `Memory Allocation Error`, comprueba si estás duplicando el array de ingredientes de entrada en lugar de mutarlo.

## 2. Calcula el precio total de un pedido

- Usando `pizzaPrice`, calcula el precio de cada pizza del array y súmalo a un total.
- Si aparece el error `Maximum call stack size exceeded` y falla más de un test, comprueba si te has olvidado del caso base. Si solo falla un test, ¡prueba a implementar esto con un bucle!
- Si te aparece un `Memory Allocation Error`, comprueba si estás duplicando el array de entrada en lugar de mutarlo.
