# Introducción

Una *quotation* es un fragmento de código entre corchetes `[ ]`. Es un valor: puedes meterlo en la pila, pasarlo a otra palabra o guardarlo en un array.

```factor
[ 1 + ] .          ! => [ 1 + ]
5 [ 1 + ] call .   ! => 6
```

La mayoría de las palabras de orden superior reciben una quotation como segundo argumento:

```factor
{ 1 2 3 } [ sq ] map .    ! => { 1 4 9 }
{ 1 2 3 } [ even? ] filter .  ! => { 2 }
```

El cuerpo de una quotation no es más que código Factor normal: los mismos operadores y los mismos efectos de pila que usas en cualquier otro sitio.

Cuando construyes código a partir de datos (concatenando fragmentos, asociando tokens a operaciones), el resultado es una secuencia; pásalo por `>quotation` para que se pueda llamar:

```factor
{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```
