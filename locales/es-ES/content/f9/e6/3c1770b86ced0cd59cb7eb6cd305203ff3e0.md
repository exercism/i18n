# Instrucciones

Por fin llegó el día que tanto esperabas y ahora eres el orgulloso propietario de una preciosa granja en los Alpes.

Sigues sin querer madrugar para alimentar a tus vacas.
Como eres un ingeniero excelente, construyes un dispensador de comida, el `FEED-M-ALL`.

Lo último que necesitas para terminar tu proyecto es un fragmento de código que calcule la cantidad de forraje que debe recibir cada vaca.
Es importante que cada vaca reciba la misma cantidad; tienes que evitar conflictos.
Las vacas son muy sensibles.

Por suerte, no necesitas calcular tú mismo todas las fórmulas para determinar las cantidades de forraje.
Usas una misteriosa biblioteca externa que encontraste en internet.
Se supone que da como resultado las vacas más felices.
La biblioteca expone un tipo que cumple la siguiente interfaz.
Te basarás en esto en el código que escribas tú mismo.

```go
type FodderCalculator interface {
	FodderAmount(int) (float64, error)
	FatteningFactor() (float64, error)
}
```

A medida que trabajes en tu código, irás mejorando la gestión de errores para que sea más robusta y más fácil de depurar cuando lo uses en tu día a día en la granja.

## 1. Reparte la comida a partes iguales

En primer lugar, te centras en escribir el código necesario para calcular la cantidad de forraje por vaca.

Implementa una función `DivideFood` que acepte como argumentos un `FodderCalculator` y un número de vacas como entero.
*Para esta tarea, supones que el número de vacas que se pasa siempre es mayor que cero.*
La función debe devolver la cantidad de comida por vaca como un `float64` o un error si se ha producido alguno.

Para hacer el cálculo, primero tienes que obtener la cantidad total de forraje para todas las vacas.
Esto se hace llamando al método `FodderAmount` y pasándole el número de vacas.
Además, necesitas un factor por el que hay que multiplicar esa cantidad.
Obtienes este factor llamando al método `FatteningFactor`.
Con estos dos valores y el número de vacas, ya puedes calcular la cantidad de comida por vaca (como un `float64`).
Eso es lo que debe devolver la función `DivideFood`.

Si uno de los métodos a los que llamas devuelve un error, la ejecución debe detenerse y ese error debe devolverse (tal cual) desde la función `DivideFood`.

```go
// For this example, we assume FodderAmount returns 50
// and FatteningFactor returns 1.5.
DivideFood(fodderCalculator, 5)
// => 15 <nil>

// Now assuming FodderAmount returns an error with message "something went wrong".
DivideFood(fodderCalculator, 5)
// => 0 "something went wrong"
```

## 2. Comprueba el número de vacas

Mientras trabajabas en la primera tarea, te diste cuenta de que la biblioteca externa que usas no tiene tanta calidad como pensabas.
Por ejemplo, no puede gestionar correctamente entradas no válidas.
Quieres sortear esta limitación añadiendo una comprobación del valor de entrada en tu propio código.

Escribe una función `ValidateInputAndDivideFood` que tenga la misma firma que `DivideFood` de arriba.

- Si el número de vacas que se pasa es mayor que 0, la función debe llamar a `DivideFood` y devolver los resultados de esa llamada.
- Si el número de vacas es 0 o menos, la función debe devolver un error con el mensaje `"invalid number of cows"`.

```go
ValidateInputAndDivideFood(fodderCalculator, 5)
// => 15 <nil>

ValidateInputAndDivideFood(fodderCalculator, -2)
// => 0 "invalid number of cows"
```

## 3. Mejora la gestión de errores

Comprobar el número de vacas antes de pasarlo fue un buen movimiento, pero no estás del todo contento con el mensaje de error tan poco concreto.
Decides hacerlo mejor creando un tipo de error personalizado llamado `InvalidCowsError`.

El error personalizado debe contener el número de vacas (`int`) y un mensaje personalizado (`string`), y el método `Error` debe serializar los datos con el siguiente formato:

```txt
{number of cows} cows are invalid: {custom message}
```

Con tu error personalizado en mano, implementa una función `ValidateNumberOfCows` que acepte el número de vacas como un entero y devuelva un error (o nil).

- Si el número de vacas es menor que 0, la función devuelve un `InvalidCowsError` con el mensaje personalizado establecido en `"there are no negative cows"`.
- Si el número de vacas es 0, la función devuelve un `InvalidCowsError` con el mensaje personalizado establecido en `"no cows don't need food"`.
- En caso contrario, la función devuelve `nil` para indicar que la validación se ha realizado correctamente.

```go
err := ValidateNumberOfCows(-5)
err.Error()
// => "-5 cows are invalid: there are no negative cows"
```

Dejas para otro día la tarea de añadir de verdad la nueva función de validación a tu código.
