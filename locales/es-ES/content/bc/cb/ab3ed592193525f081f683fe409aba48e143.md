# Introducción

Una expresión switch puede hacer coincidir un valor con uno de los casos de un conjunto de patrones y devolver el valor asociado o realizar la acción asociada. La asociación se indica con el símbolo `=>`. Además, cada patrón puede tener una guarda de caso opcional, introducida con la palabra clave `when`. La expresión de la guarda de caso debe evaluarse como true para que se seleccione ese «brazo» del switch. Los casos (también conocidos como _brazos del switch_) se evalúan en el orden en que aparecen en el texto, el proceso se interrumpe y se devuelve el valor asociado en cuanto se encuentra una coincidencia.

```csharp
double xx = 42d;

string interesting = xx switch
{
    0 => "I suppose zero is interesting",
    3.14 when DateTime.Now.Day == 14 && DateTime.Now.Month == 3 => "Mmm pie!",
    3.14 => "π",
    42 => "a bit of a cliché",
    1729 => "only if you are a pure mathematician",
    _ => "not interesting"
};

// => interesting == "a bit of a cliché"
```
