# Introducción

Unison representa los valores verdadero y falso con el tipo `Boolean`. Solo hay dos valores: `true` y `false`.

```unison
trueVariable = true
falseVariable = false
```

Podemos evaluar expresiones booleanas con los operadores and, representado con `&&`; or, representado con `||`; y not, representado con `not`.

```unison
trueVariable = true && true
falseVariable = true && false

trueVariable = false || true
falseVariable = false || false

trueVariable = not false
falseVariable = not true
```

Las expresiones booleanas de Unison permiten el cortocircuito: si el primer argumento de una expresión `&&` es `false`, no hay motivo para seguir evaluando el segundo argumento. Del mismo modo, si el primer argumento de una expresión `||` es `true`, la expresión devolverá `true` inmediatamente.

```unison
> false && (base.bug "oh no")
  ⧩
  false
```

```unison
> true || (base.bug "oh no")
  ⧩
  true
```
