# Ayuda

Si tienes problemas, puedes recurrir a uno de los siguientes recursos para obtener ayuda:

- [TypeScript QuickStart](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [ECMAScript 2015 Language Specification](https://www.ecma-international.org/wp-content/uploads/ECMA-262_6th_edition_june_2015.pdf) (pdf)
- [Mozilla JavaScript Reference](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference)
- [/r/typescript](https://www.reddit.com/r/typescript) es el subreddit de TypeScript.
- [StackOverflow](https://stackoverflow.com/questions/tagged/typescript) puedes usarlo para buscar tu problema y comprobar si ya se ha respondido. También puedes hacer y responder preguntas.
