# Strings

Una **cadena de caracteres** es un fragmento de texto. El tipo de Sather para una es `STR`, y un string se escribe entre comillas dobles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

## Unir strings

`+` une dos strings de extremo a extremo.

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

No se pone nada entre ellos, así que hay que pedir un espacio. Si lo omites, obtienes `"JeanSibelius"`.

## ¿Cuánto mide?

`.size` indica cuántos caracteres contiene un string. Es un número entero, así que su tipo es `INT`.

```sather
"Sibelius".size      -- 8
```

No hay paréntesis después de `.size`, igual que una rutina que no recibe argumentos.

## Tomar un fragmento

`.head(n)` devuelve los primeros `n` caracteres. `.tail(n)` devuelve los últimos `n`.

```sather
"Sibelius".head(3)   -- "Sib"
"Sibelius".tail(4)   -- "lius"
```

`head` cuenta desde el principio, `tail` cuenta desde el final. Ambos dejan intacto el string original y devuelven uno nuevo.
