# Acerca de

En Elixir hay dos tipos diferentes de números: números enteros y números decimales.

Los números enteros son números sin parte fraccionaria.

```elixir
integer = 3
# => 3
```

Algunas funciones útiles para trabajar con números enteros se encuentran en el módulo [`Integer`][integer].

```elixir
Integer.digits(123)
# => [1, 2, 3]
```

Los números enteros grandes (y también los números decimales) se suelen formatear separando cada tres dígitos en grupos con un guion bajo.

```elixir
1_000_000
# => 1000000
```

El tamaño máximo de los números en Elixir solo está limitado por la memoria disponible en el sistema, porque Elixir utiliza [aritmética de precisión arbitraria][arbitrary-precision-arithmetic].

Elixir también admite notaciones abreviadas para introducir [números enteros binarios, octales y hexadecimales][integers-in-other-bases].

```elixir
0b0100
# => 4

0o555
# => 365

0xFF
# => 255
```

## Comparación

Los números enteros y los números decimales pueden considerarse iguales ([`==`][kernel-equal]) si tienen el mismo valor. Sin embargo, al ser tipos diferentes, nunca son estrictamente iguales ([`===`][kernel-strictly-equal]).

```elixir
1 == 1.0
# => true

1 === 1.0
# => false
```
