# Pistas

## General

- Hay tres operadores booleanos para trabajar con valores booleanos: `not`, `&&` y `||`.
- Se pueden combinar varios operadores en una sola expresión.

## 1. Define si pac-man puede comerse un fantasma

- La función debe devolver un valor `Bool`.
- Puedes usar el operador booleano `&&` para combinar los argumentos y obtener un resultado.

## 2. Define si pac-man puntúa

- La función debe devolver un valor `Bool`.
- Puedes usar el operador booleano `||` para combinar los argumentos y obtener un resultado.

## 3. Define si pac-man pierde

- La función debe devolver un valor `Bool`.
- Puedes usar los operadores booleanos `&&` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si pac-man gana

- La función debe devolver un valor `Bool`.
- Puedes usar los operadores booleanos `&&` y `not` para combinar los argumentos y el resultado de una de las funciones implementadas previamente.
