# Instrucciones

En este ejercicio vas a modelar una báscula.

## 1. Crea un estado inicial para la báscula

Al inicializarse, la báscula debe remitirse a su configuración de fábrica, que varía según dónde se venda.
Por eso, la báscula debe poder inicializarse con una precisión y con si es métrica o imperial.

Implementa el método `WeighingMachine#initialize`, que recibe dos argumentos: `precision`, que es un `Int32`, y `metric`, que es un `Bool`.
Cuando el argumento `metric` es `true`, significa que la báscula debe usar el sistema métrico; de lo contrario, debe usar el sistema imperial.
El método de inicialización también debe establecer la variable de instancia `@weight` a `0.0`.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
```

## 2. Permite que la báscula tenga una precisión

Para atender distintas necesidades, permitimos que cada báscula se personalice con una precisión (el número de dígitos después del separador decimal).

Implementa el método getter `WeighingMachine#precision` para que devuelva la precisión de la báscula.

```crystal
precision = 3
metric = true
vm = WeighingMachine.new(precision, metric)
vm.precision
# => 3
```

## 3. Permite establecer el peso en la báscula

Implementa la propiedad `WeighingMachine#weight` para permitir obtener _y_ establecer el peso:

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
wm.weight = 60.5
wm.weight
# => 60.5

wm.weigh
# => 60.5
```

## 4. Permite cambiar la báscula entre las unidades métrica e imperial

Implementa la propiedad `WeighingMachine#metric=` para permitir establecer la unidad.
Debe aceptar un valor de tipo Boolean.

```crystal
precision = 3
metric = true
wm = WeighingMachine.new(precision, metric)
vm.weight = 60.5
wm.metric = false

vm.weigh
# => 133.377
```
