# Instrucciones

Ozan está preparando una lista de reproducción para un próximo viaje por carretera. No quiere escuchar la misma canción más de una vez, pero la lista de reproducción se ha vuelto tan larga que le cuesta recordar qué canciones ya se han añadido.

La API del reproductor de música de Ozan solo sabe trabajar con arrays, así que intenta escribir algo de código que use `Array.indexOf()` para comprobar si una canción está presente antes de añadirla a la lista de reproducción. Por desgracia, su programa tarda demasiado en ejecutarse. ¡Necesita tu ayuda!

Al acudir en ayuda de Ozan, te asombras al descubrir que su lista de reproducción contiene _medio millón_ de canciones. ¿Quizá conoces otra estructura de datos que te permita manipular la lista de reproducción de forma más eficiente?

## 1. Eliminar las canciones duplicadas

Implementa la función `removeDuplicates`, que toma una lista de reproducción como _parámetro_ y _devuelve_ una nueva lista de reproducción en la que todas las canciones son únicas.

```javascript
const playlist = [
  'Court and Spark - Joni Mitchell',
  'Big Yellow Taxi - Joni Mitchell',
  'Court and Spark - Joni Mitchell',
];

removeDuplicates(playlist);
//=> ['Court and Spark - Joni Mitchell', 'Big Yellow Taxi - Joni Mitchell']
```

## 2. Comprobar si una canción ya se ha añadido

Implementa la función `hasTrack`, que toma una lista de reproducción y una canción como _parámetros_ y _devuelve_ un valor booleano que indica si la lista de reproducción contiene la canción.

```javascript
const playlist = [
  'The Fashion Show - Grace Jones',
  'Dr. Funkenstein - Parliament',
];

hasTrack(playlist, 'Dr. Funkenstein - Parliament');
//=> true

hasTrack(playlist, 'Walking in the Rain - Grace Jones');
//=> false
```

## 3. Añadir una canción

Implementa la función `addTrack`, que toma una lista de reproducción y una canción como _parámetros_ y _devuelve_ una nueva lista de reproducción que incluye la canción.

```javascript
const playlist = ['Selma - Bijelo Dugme'];

addTrack(playlist, 'Atomic Dog - George Clinton');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']

addTrack(playlist, 'Selma - Bijelo Dugme');
//=> ['Selma - Bijelo Dugme', 'Atomic Dog - George Clinton']
```

## 4. Eliminar una canción

Implementa la función `deleteTrack`, que toma una lista de reproducción y una canción como _parámetros_ y _devuelve_ una nueva lista de reproducción que no incluye la canción.

```javascript
const playlist = [
  'The Treasure - Fra Lippo Lippi',
  'After the Fall - Klaus Nomi',
];

deleteTrack(playlist, 'The Treasure - Fra Lippo Lippi');
//=> ['After the Fall - Klaus Nomi']

deleteTrack(playlist, 'I Feel the Magic - Belinda Carlisle');
//=> ['After the Fall - Klaus Nomi']
```

## 5. Listar los artistas únicos

Implementa la función `listArtists`, que toma una lista de reproducción como _parámetro_ y _devuelve_ la lista de artistas únicos de la lista de reproducción. Ten en cuenta que los nombres de las canciones tienen el formato `<SONG> - <ARTIST>`.

```javascript
const playlist = [
  'All Mine - Portishead',
  'Sight to Behold - Devendra Banhart',
  'Sour Times - Portishead',
];

listArtists(playlist);
//=> ['Portishead', 'Devendra Banhart']
```
