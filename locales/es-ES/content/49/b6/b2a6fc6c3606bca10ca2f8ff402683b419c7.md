# Instrucciones

En este ejercicio juegas a adivinar un número con un amigo. Las reglas son sencillas: eliges en secreto un número entre `1` y `100` y tu amigo intenta adivinar qué número has elegido. Para ayudarle, respondes de forma distinta según lo cerca que esté la conjetura del número que has elegido (`42`). Estas son las reglas para las distintas respuestas:

- Si la conjetura es `42`: «Correct»
- Si la conjetura es `41` o `43`: «So close»
- Si la conjetura es menor que `41`: «Too low»
- Si la conjetura es mayor que `43`: «Too high»

Tienes cuatro tareas para programar las respuestas a las conjeturas.

## 1. Responder a una conjetura correcta

Implementa la función `reply` para responder a una conjetura correcta:

```gleam
reply(42)
// -> "Correct"
```

## 2. Responder a una conjetura cercana

Modifica la función `reply` para responder a las conjeturas cercanas:

```gleam
reply(41)
// -> "So close"
```

## 3. Responder a conjeturas demasiado bajas

Modifica la función `reply` para responder a las conjeturas demasiado bajas:

```gleam
reply(25)
// -> "Too low"
```

## 4. Responder a conjeturas demasiado altas

Modifica la función `reply` para responder a las conjeturas demasiado altas:

```gleam
reply(88)
// -> "Too high"
```
