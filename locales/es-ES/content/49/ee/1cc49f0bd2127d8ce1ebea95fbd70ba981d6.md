# Introducción

AWK es un lenguaje muy pequeño y solo tiene unos pocos tipos de datos básicos.
En esta lección veremos los números y los strings.

## Números

Los números en AWK se implementan como números de coma flotante de doble precisión.
No hay distinción entre enteros, decimales y dobles.

AWK entiende constantes numéricas octales (que empiezan por `0`) y constantes numéricas hexadecimales (que empiezan por `0x` o `0X`).

### Operaciones numéricas

Puedes usar los operadores aritméticos estándar `+`, `-`, `*`, `/`, `%`.
El operador de exponenciación es `^`.
Hay algunas funciones numéricas integradas, como las funciones trigonométricas, la generación de números aleatorios y `int(x)` para truncar un número al entero más cercano entre _x_ y cero.

## Strings

Los strings de AWK son secuencias de caracteres.
Especifica una constante de tipo string usando comillas dobles.

### Operaciones con strings

Solo hay una operación con strings: la concatenación.
La concatenación no tiene un operador especial;
basta con colocar dos strings uno junto a otro para concatenarlos:

```awk
BEGIN {
    hw = "Hello" "World"
    print hw
}
# => HelloWorld
```

~~~~exercism/note
`print` es una **instrucción**, no una función.
`print` no requiere paréntesis.
~~~~

AWK tiene una gran cantidad de funciones para manipular strings.
Las iremos conociendo en profundidad a medida que avancemos por el track.

## Conversión entre números y strings

No hay operadores explícitos para convertir entre números y strings.
AWK lo hace de forma implícita según el contexto del programa.
Esto hace que trabajar con los valores de los campos de entrada sea muy sencillo: por lo general, AWK simplemente hace lo que quieres que haga.

* `print x + y` convertirá los valores de las variables `x` e `y` en números gracias a la operación numérica `+`.
* `print x y` convertirá los valores de las variables `x` e `y` en strings gracias a la operación de concatenación.

Si quieres ser explícito, `0 + x` da la representación numérica de _x_ y `"" x` da la representación como string de _x_.

### De strings a números

La forma en que AWK convierte un string en un número puede resultar confusa.
Una manera sencilla de verlo es que AWK lee «caracteres numéricos» desde el principio de un string hasta que encuentra un carácter «no numérico».
Algunos ejemplos son:

* `"2.5"` se convierte en el número `2.5`;
* `"1e3"` se convierte en el número `1000` (notación científica);
* `"456abc"` se convierte en el número `456` (como `a` no es un «numeral», la conversión se detiene ahí).
* `"abc789"` se convierte en el número `0` (no hay números al **principio** del string).
