# Acerca de

Factor concentra la aleatoriedad del vocabulario [`random`][random] en torno a una única palabra genérica:

```
random ( obj -- elt )
```

Esta despacha según su argumento:

- un **número entero** `n` produce un número entero aleatorio en `[0, n)`;
- una **secuencia** produce un elemento aleatorio;
- también se admiten los assocs, los hash-sets y las tuplas de `uniform-distribution`.

Sobre ella se apoyan dos funciones auxiliares para secuencias:

```factor
USING: random ;

{ 1 2 3 4 5 } randomize .   ! shuffle in place (Fisher–Yates)
{ 1 2 3 4 5 } 3 sample .    ! 3 distinct elements; error if too many
```

`randomize` modifica la secuencia y la devuelve, así que usa `clone` antes si necesitas conservar el orden original.

## De dónde viene la aleatoriedad

`random` lee el generador que guarda la variable dinámica `random-generator`. De forma predeterminada es un Mersenne Twister inicializado con una semilla tomada del reloj del sistema, por lo que cada proceso es distinto. Puedes instalar un generador diferente mientras dure una quotation:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ { 1 2 3 } randomize ] with-random .
! => the same ordering on every run
```

Como `with-random` se limita a enlazar `random-generator` durante el alcance dinámico de la quotation, una palabra que lo envuelva debería marcarse como `inline` para que la quotation pueda dejar su resultado en la pila para quien la llama.

Más allá de esto, `random` ofrece `random-bits`, `random-unit`, `uniform-random` y `normal-random` para otras distribuciones, además de `system-random-generator` y `secure-random-generator` para necesidades no reproducibles y criptográficas.

[random]: https://docs.factorcode.org/content/vocab-random.html
