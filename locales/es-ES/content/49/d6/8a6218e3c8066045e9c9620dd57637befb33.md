# Consejos

## General

- Para generar números aleatorios, `:rand.uniform` de Erlang o `Enum.random` son buenos puntos de partida.
- Puedes usar `Integer.pow` para calcular la potencia de un número, y `rem` para el residuo.
- Ninguno de los dos funciona especialmente bien (ni rápido) con números enteros muy grandes. La criptografía suele usar números de más de 1024 bits. El módulo `:crypto` de Erlang tiene una función útil para calcular el residuo de una potencia, sobre todo con números enormes, pero puede que necesites `:binary` para descodificarlo.
