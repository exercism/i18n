# Introducción

El tipo `Option` es el mecanismo del lenguaje F# para tratar con valores que pueden o no existir.
Proporciona una alternativa segura en cuanto a tipos al uso de `null`, común en otros lenguajes para tratar con tales valores.
Se utiliza en muchas funciones de la biblioteca estándar de F#, por lo que comprenderlo es esencial para un uso eficaz de la biblioteca estándar de F#.

## Uso

El tipo `Option` es un tipo genérico (que tiene un tipo subyacente).  
Los valores de `Option` son `Some value`, que representa un valor específico, o `None`, que representa la ausencia de valor.

La siguiente función demuestra cómo crear un valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` es la sintaxis postfija equivalente a `Option<T>`; las dos formas sintácticas se pueden usar indistintamente.
Sin embargo, según la Guía de estilo de F#, se prefiere la notación postfija para los tipos Option (ver [sección de la Guía de estilo de F# sobre Formato de tipos y anotaciones de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)). 
~~~~

## Leer el contenido de un valor Option

La forma idiomática de leer un valor `Option` es mediante la coincidencia de patrones, como se muestra en el siguiente ejemplo:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desenvolver Options con valores predeterminados

Los `Option` se pueden «desenvolver» (convertir a su tipo contenido) proporcionando valores predeterminados con la función `Option.defaultValue`. 
Esto es particularmente útil cuando quieres asegurarte de que el valor no sea `None`.
Por ejemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```
