# Acerca de

Un parámetro de un método puede convertirse en opcional si se le asigna un valor predeterminado. Cuando un parámetro es opcional, quien llama al método no tiene que proporcionar un argumento para ese parámetro, y en ese caso se usará el valor predeterminado. Los [parámetros opcionales][optional-arguments] _deben_ estar al final de la lista de parámetros; no pueden ir seguidos de parámetros no opcionales. Si un método tiene varios parámetros opcionales, puedes especificar solo algunos de ellos usando [argumentos con nombre][named-arguments].

```csharp
class Card
{
    static string NewYear(int year = 2020, string sender = "me")
    {
        return $"Happy {year} from {sender}!";
    }
}

Card.NewYear();     // => "Happy 2020 from me!"
Card.NewYear(1999); // => "Happy 1999 from me!"
Card.NewYear(sender: "mom"); // => "Happy 2020 from mom!"
```

El valor de un parámetro opcional debe ser uno de los siguientes:

- Una expresión constante (p. ej., `"hi"`, `2`, `DayOfWeek.Friday`, `null`, etc.)
- Una expresión `new` de un tipo de valor
- Una expresión `default` de un tipo de valor
