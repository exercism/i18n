# Instrucciones

Una escuela cercana tiene una asociación de estudiantes muy activa.
La asociación de estudiantes está gestionada por un presidente y, cada 2 años,
se celebran elecciones para elegir a un nuevo presidente.

En las elecciones de este año se ha decidido que hacía falta un nuevo sistema digital para
contar los votos. La escuela necesita tu ayuda para construir este nuevo sistema.

## 1. Obtener el número de votos de un `ElectionResult`

El nuevo sistema necesitará una forma de obtener el número de votos de un contador.

La estructura de resultado electoral ya está creada para ti y se define así:

```cpp
struct ElectionResult {
    // Name of the candidate
    std::string name{};
    // Number of votes the candidate has
    int votes{};
};
```

Como todos los miembros del `struct` son públicos, no necesitas escribir un `constructor` para inicializar un objeto `ElectionResult`.
En su lugar, puedes usar una `initializer list`:

```cpp
ElectionResult hamilton{"Alex", 1804};
// => the hamilton object was initialized with the name "Alex" and 1804 votes.
```

Crea una función `vote_count` que reciba una referencia a un `ElectionResult` como argumento y devuelva el número de votos del `ElectionResult`.

```cpp
vote_count(hamilton);
// => 1804
```

## 2. Incrementar los votos de un `ElectionResult`

¡Por fin ha llegado el momento de procesar los votos!
Ahora necesitas una forma de incrementar los votos de un `ElectionResult`.

Crea una función `void` `increment_vote_count` que reciba una referencia a un `ElectionResult` como argumento y un número de votos, e incremente el `ElectionResult` en ese número de votos.

```cpp
ElectionResult burr{"Aaron " 1801};

increment_vote_count(burr, 3);

vote_count(burr);
// => 1804
```

## 3. Recuento de votos y presidencia

La escuela ha entregado sus votos y ahora toca comprobar los resultados para ver quién es el ganador.

Crea una función `determine_result` que reciba una referencia a un recuento final y devuelva una referencia al `ElectionResult` del nuevo presidente.
También debe cambiar el nombre del ganador añadiéndole el prefijo «President».
El recuento final se da en forma de `reference` a `std::vector<ElectionResult>`, un vector con los `ElectionResults` de todos los candidatos participantes.

```cpp
ElectionResult sanchez{"Pedro", 471};
ElectionResult wheatley{"Summer", 340};
std::vector<ElectionResult> final_count{sanchez, wheatley};

ElectionResult& winner = determine_result(final_count);

winner.name;
// => "President Pedro"
```

Para simplificar, puedes dar por sentado lo siguiente:
- El `vector` tiene al menos un elemento.
- No habrá empates en el primer puesto.
