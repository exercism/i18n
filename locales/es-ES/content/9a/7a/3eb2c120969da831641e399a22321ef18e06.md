# Acerca de

## Bucles `for`

La instrucción `for` repite un bloque de código.
Su primera línea controla cuántas veces se repite el bloque:

```go
for init; condition; post {
    // loop body
}
```

- La instrucción de **inicialización** se ejecuta una vez antes de la primera iteración. Es habitual declarar e inicializar una variable contadora que usa el bucle.
- La **condición** es una expresión Boolean que se evalúa antes de cada iteración. El bucle se detiene cuando esta se evalúa como `false`.
- La instrucción **post** se ejecuta después de cada iteración completada. Se puede usar para actualizar un contador.

No rodees `init; condition; post` con paréntesis.
Sin embargo, las llaves `{ }` que rodean el cuerpo del bucle siempre son obligatorias.

Este bucle inicializa `i` en `1`, imprime el valor actual de `i`, lo incrementa para la siguiente iteración y se detiene cuando `i` llega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```

## Otras formas de bucle

### Bucle solo con condición

Las instrucciones de inicialización y post se pueden omitir.
Una instrucción `for` que solo tiene una condición cumple la misma función que un bucle `while` en otros lenguajes.
Go no tiene la palabra clave `while`.

```go
sum := 1
for sum < 1000 {
    sum += sum
}
fmt.Println(sum)
// Output: 1024
```

### Bucle infinito

Una instrucción `for` se puede escribir sin condición:

```go
for {
    // loop body
}
```

Este bucle no termina por sí solo.
La ejecución debe salir del bucle de forma explícita, por ejemplo con `break` o `return`.

## Control de los bucles

### `break` y `continue`

En este bucle, `break` sale del bucle:

```go
for n := 0; n <= 5; n++ {
    if n == 3 {
        break
    }
    fmt.Println(n)
}
// Output:
// 0
// 1
// 2
```

`continue` omite el resto del cuerpo del bucle actual y comienza la siguiente iteración:

```go
for n := 0; n <= 5; n++ {
    if n % 2 == 0 {
        continue
    }
    fmt.Println(n)
}
// Output:
// 1
// 3
// 5
```

### `break` y `continue` con etiquetas

Con bucles anidados, un `break` o un `continue` sin etiqueta se aplica al bucle más interno.
Para etiquetar un bucle contenedor, coloca un nombre seguido de dos puntos en la línea justo encima de él.
Después, escribe la etiqueta del bucle a continuación de `break` o `continue` para dirigir la acción a ese bucle:

```go
OuterLoop:
for i := 0; i < 10; i++ {
    for j := 0; j < 10; j++ {
        if i + j == 10 {
            break OuterLoop
        }
    }
}
```
