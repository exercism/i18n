# Acerca de

Por defecto, las variables están limitadas al scope en el que se definen. Si se definen en un fichero fuera de una función o una clase, están limitadas al scope del fichero. Si se definen dentro de una función o una clase, están limitadas al scope de la función o la clase.

```php
<?php

$file_scoped = "I am file scoped";

function example(): void
{
  $function_scoped = "I am function scoped!";
}
```

## Scope global

Usar la palabra clave `global` antes de asignar una variable crea una variable con scope global. Este patrón se desaconseja a menudo, ya que genera [código fuertemente acoplado](<https://en.wikipedia.org/wiki/Coupling_(computer_programming)#Disadvantages_of_tight_coupling>).

```php
function example(): void
{
  global $hello = "World!";
}

echo $hello; // #=> "World!"
```

## Scope estático

Usar la palabra clave `static` antes de una asignación o declaración de variable conservará el scope de la variable, pero su valor se conserva entre distintos scopes de ejecución.

```php
function counter(): int
{
  static $count = 0;
  $count += 1;
  return $count;
}
```

En este ejemplo, la variable `$count` se inicializa a 0 _solo en la primera llamada a la función_. En todas las llamadas posteriores, el valor se trasladará a la siguiente llamada. Así, cada invocación de la función devuelve como respuesta un número entero cada vez mayor.
