# Instrucciones

Eres un aficionado a la observación de aves que lleva la cuenta de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes seis tareas, todas relacionadas con el número de pájaros que han visitado tu jardín.

## 1. Comprueba cuáles eran los recuentos de la semana pasada

Para poder comparar, siempre tienes cerca una copia de los recuentos de la semana pasada, que fueron: 0, 2, 5, 3, 7, 8 y 4. Define el enlace `lastWeek` que contiene los recuentos de la semana pasada:

```fsharp
lastWeek
// => [| 0; 2; 5; 3; 7; 8; 4 |]
```

## 2. Comprueba cuántos pájaros visitaron ayer

Implementa la función `yesterday` para que devuelva cuántos pájaros visitaron tu jardín ayer. Los recuentos de pájaros están ordenados por día: el primer elemento es el recuento del día más antiguo y el último es el recuento de hoy.

```fsharp
yesterday [| 3; 5; 0; 7; 4; 1 |]
// => 4
```

## 3. Calcula el número total de pájaros que han visitado tu jardín

Implementa la función `total` para que devuelva el número total de pájaros que han visitado tu jardín:

```fsharp
total [| 3; 5; 0; 7; 4; 1 |]
// => 20
```

## 4. Comprueba si hubo algún día en el que no visitara ningún pájaro

Implementa la función `dayWithoutBirds` que devuelve `true` si hubo un día en el que ningún pájaro visitó el jardín; en caso contrario, devuelve `false`:

```fsharp
dayWithoutBirds [| 3; 5; 0; 7; 4; 1 |]
// => true
```

## 5. Incrementa el recuento de hoy

Implementa la función `incrementTodaysCount` para que incremente el recuento de hoy y devuelva los recuentos actualizados:

```fsharp
let birdCount = [| 3; 5; 0; 7; 4; 1 |]
incrementTodaysCount birdCount
// => [| 3; 5; 0; 7; 4; 2 |]
```

## 6. Comprueba si hay una semana inusual

Durante el último año, has descubierto que algunas semanas tienen los mismos patrones inusuales:
- En cada día par de la semana no había pájaros
- En cada día par de la semana se avistaban exactamente 10 pájaros
- En cada día impar de la semana se avistaban exactamente 5 pájaros

Implementa la función `unusualWeek` que devuelve `true` si el patrón de recuento de pájaros de esta semana coincide con uno de los patrones inusuales:

```fsharp
unusualWeek [| 1; 0; 5; 0; 12; 0; 2 |]
// => true

unusualWeek [| 5; 0; 5; 12; 5; 3; 5|]
// => true
```

(Ten en cuenta que la paridad de los días se cuenta desde 1, no desde 0: el primer elemento del array se corresponde con un día impar)
