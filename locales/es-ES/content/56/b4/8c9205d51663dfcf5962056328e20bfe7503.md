# Instrucciones

La Bellebrook Basketball League es una liga de varios equipos, cada uno con una plantilla de jugadores.
Está a punto de comenzar una nueva temporada y necesitan crear un nuevo sistema de venta de entradas para vender entradas para los partidos.
La temporada pasada vendían las entradas en la taquilla del estadio, pero la popularidad se ha disparado y han decidido vender entradas en línea esta temporada para gestionar el aumento de la demanda.

La liga se ha puesto en contacto contigo y te ha pedido que crees un sistema para gestionar la venta de entradas.

## 1. Crear un sistema de venta de entradas

En primer lugar, necesitas crear un sistema de venta de entradas para gestionar la venta de entradas.
El sistema de venta de entradas debe indicar cuántas entradas hay disponibles para un partido.

Se debe crear una instancia de una clase llamada `TicketSystem` para cada partido.
El estado inicializado debe contener la siguiente información:

1. Cuántas entradas hay disponibles para el partido.
2. En qué estadio se juega el partido.

Construye un estado inicializado a partir de argumentos que indiquen el número de entradas disponibles y en qué estadio se juega el partido.
El estado inicializado debe constar de las variables de instancia `@tickets_available` y `@stadium`.
Estas deben contener el primer y el segundo argumento proporcionados, respectivamente.

```crystal
TicketSystem.new(100, "Bellebrook")
# => #<TicketSystem:0x10f0b8 @tickets_available=100, @stadium="Bellebrook">
```

## 2. Obtener la cantidad de entradas disponibles

En primer lugar, necesitas crear un método que devuelva la cantidad de entradas disponibles para un partido dado.

Define un módulo llamado `TicketingReservation` encima de la clase ya definida.
Este módulo debe incluirse en la clase `TicketSystem`.

Dentro del módulo, define un método llamado `tickets_available`.
Este método debe devolver la cantidad de entradas disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.tickets_available
#=> 100
```

## 3. Pedir entradas

Debes crear un método que compruebe si hay entradas disponibles para un partido dado.
El partido necesita tener 100 entradas en reserva.
Esto es para garantizar que siempre haya entradas disponibles para las personas que compran entradas en la taquilla del estadio.

Dentro del módulo `TicketingReservation`, define un método llamado `order_ticket?`.
El método debe devolver `true` si hay al menos 100 entradas disponibles y `false` en caso contrario.
Si hay al menos 100 entradas disponibles, el método también debe reducir en 1 el número de entradas disponibles.

```crystal
ticket_system = TicketSystem.new(100)
ticket_system.order_ticket?
#=> true
```

## 4. Mensaje del pedido

El sistema de venta de entradas debe tener mensajes fáciles de entender para los usuarios.
Además, los mensajes deben resultar personales, así que deben incluir el nombre del usuario.

Si la compra de la entrada se ha realizado correctamente, el usuario debe recibir un mensaje que le indique que la compra se ha realizado correctamente, su número de entrada y en qué estadio se juega el partido.
El número de entrada debe ser el número de entradas disponibles antes del pedido.

Si la compra se ha realizado correctamente, el mensaje debe ser similar a este: `{name}, your purchase was successful, your ticket number is #{ticket_number}, and the game is played at the {stadium_name} stadium.`.
Si la compra no se ha realizado correctamente, el mensaje debe ser similar a este: `{name}, your purchase was unsuccessful, there are not enough tickets available.`.

Dentro del módulo `TicketingReservation,` define un método llamado `order_message` que recibe un argumento `name` con el nombre del comprador.
El método debe devolver un string con el mensaje.

```crystal
ticket_system = TicketSystem.new(100, "Bellebrook")
ticket_system.order_message("John")
#=> "John, your purchase was successful, your ticket number is #100, and the game is played at the Bellebrook stadium."
```
