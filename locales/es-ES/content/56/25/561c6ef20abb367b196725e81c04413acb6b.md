# Instalación

Para obtener las instrucciones de instalación recomendadas para tu plataforma, dirígete a [la web oficial de Rust].

¡Tener la cadena de herramientas instalada no lo es todo!
El soporte del IDE supone un enorme impulso de productividad que la mayoría de los desarrolladores ya dan por hecho.
Si utilizas Visual Studio Code, echa un vistazo a su [documentación sobre el soporte de Rust][vscode].
Además, te recomendamos encarecidamente que actives el [linting con clippy][vscode-linting].

[the official Rust website]: https://www.rust-lang.org/tools/install
[vscode]: https://code.visualstudio.com/docs/languages/rust
[vscode-linting]: https://code.visualstudio.com/docs/languages/rust#_linting
