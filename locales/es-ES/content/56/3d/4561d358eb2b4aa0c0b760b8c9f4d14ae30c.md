# Aprender

Si quieres aprender TypeScript, echa un vistazo a los siguientes recursos.

- [Tutorial de TS](https://www.typescriptlang.org/docs/handbook/release-notes/overview.html)
- [TS Playground](https://www.typescriptlang.org/play)

TypeScript es un superconjunto de JS.
TypeScript ofrece todas las funcionalidades de JavaScript y, además, una capa adicional por encima de estas: el sistema de tipos de TypeScript.

- [Exploring ES6](https://leanpub.com/exploring-es6), libro de Axel Rauschmayer
- [ES6 Katas](https://jskatas.org/#bundle-es6-katas), sitio web
- [Compilador Babel](https://github.com/babel/babel)
