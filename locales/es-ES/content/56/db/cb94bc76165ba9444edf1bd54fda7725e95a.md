# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que los demás pudieran leerlo con facilidad, el mensaje se cifró realizando una serie de manipulaciones de bits.
Tendrás que escribir las funciones que ayuden a descifrar el mensaje.

## 1. Desplaza los bits hacia atrás

El primer paso para descifrar el mensaje consiste en deshacer el desplazamiento del proceso de cifrado desplazando los bits de vuelta a la derecha.
En los pasos posteriores del proceso de descifrado se dará por supuesto que los `0`s se insertan por el lado izquierdo.

Implementa la función `shiftBack`, que recibe un número de posiciones que hay que desplazar y un valor, y realiza el desplazamiento.

```elm
shiftBack 2 42 --> 10
```

## 2. Pon algunos bits

A continuación, hay algunos bits que deben ponerse a `1`.

Implementa la función `setBits`, que recibe una máscara y un valor y devuelve el resultado de poner a `1` los bits de value.
Un bit de value debe ponerse a `1` allí donde el bit de la máscara también sea `1`.
Todos los demás bits deben permanecer sin cambios.

```elm
setBits 66 212 --> 64
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado.
Habrá que volver a invertirlos para descifrar el mensaje.

Implementa la función `flipBits`, que recibe una máscara y un valor.
La máscara indica qué bits del valor hay que invertir.
Si el bit es `1` en la máscara, el bit se invierte en el valor.
Todos los demás bits permanecen sin cambios.

```elm
flipBits 23 157 --> 138
```

## 4. Pon a cero bits específicos

También hay ciertos bits que siempre se descifran a 0.

Implementa la función `clearBits`, que recibe una máscara y un valor.
Los bits de `value` deben ponerse a 0 allí donde el bit de la máscara sea 1.
Todos los demás bits deben permanecer sin cambios.

```elm
clearBits 2 15 --> 13
```

## 5. Descifra un mensaje

Ahora que ya tienes todas las funciones que necesitas, puedes descifrar el mensaje de tu amigo.
Implementa la función `decrypt`, que realiza las siguientes operaciones:

1. Pon los bits del año en que nació tu amigo (1996).
2. Invierte el resultado con el año en que os conocisteis (2009).
3. Desplaza los bits hacia atrás según el número de clases que compartís (5).
4. Pon a cero el primer bit y el quinto.

```elm
decrypt 380182 --> 11840
```

Implementa `decrypt` con todas las funciones que has implementado en las tareas anteriores.
