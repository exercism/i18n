# Pistas

## General

- `matches?`, `all-matching-subseqs`, `count-matches` y `re-replace` viven en [`regexp`][regexp]. Escribe cada patrón como un literal entre `R/ ` y `/`.
- Un código de insignia válido consta de dos mayúsculas, un guion y cuatro dígitos:
  `R/ [A-Z]{2}-\d{4}/`.

## 1. Comprobar un código de insignia

- `matches?` comprueba el string *entero*, que es exactamente lo que necesita la pregunta «¿es válido este código de insignia?»: `R/ [A-Z]{2}-\d{4}/ matches?`.

## 2. Extraer todos los códigos de una línea de registro

- `all-matching-subseqs` devuelve cada coincidencia como una secuencia de strings. Pásale el mismo patrón de código de insignia.

## 3. Contar los dígitos de un código

- `\d` coincide con un dígito; `count-matches` cuenta cuántas veces coincide el patrón: `R/ \d/ count-matches`.

## 4. Censurar las contraseñas

- `\S` significa «un carácter que no es un espacio», así que `R/ pass=\S+/` coincide con `pass=` más el secreto que va después.
- `re-replace` toma el string, el patrón y el texto de reemplazo `"pass=****"`.

[regexp]: https://docs.factorcode.org/content/vocab-regexp.html
