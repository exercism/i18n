# Acerca de

Por defecto, los valores en C# son _mutables_, es decir, pueden cambiar con el tiempo. Para hacer que un valor sea _inmutable_, hay dos opciones:

1. Añadir el [modificador `const`][const-modifier].
2. Añadir el [modificador `readonly`][readonly-modifier].

El modificador `const` tiene algunas restricciones:

1. Solo puede aplicarse a tipos «constantes»: strings, Boolean y números.
1. El valor `const` debe inicializarse inmediatamente.

Consulta [cómo definir constantes][defining-constants] para obtener más información.

Si tu valor es de un tipo no constante o necesitas inicializar el valor en un constructor, puedes usar `readonly` para imponer la inmutabilidad.
