# Anexo a las instrucciones

## `Print` no entrecomilla los valores de tipo string

Este ejercicio implica manipular puntuaciones numéricas.
#[a: 1]` and `#[a: "1"]` no son lo mismo:

```arturo
inspect #[a: 1]
; [ :dictionary
;        a  :        1 :integer
; ]

inspect #[a: "1"]
; [ :dictionary
;        a  :        1 :string
; ]
equal? #[a: "1"] #[a: 1]
; false
```

Una práctica habitual al depurar es imprimir valores con `print`.
Sin embargo, la salida no añadirá comillas alrededor de los strings.
Por lo tanto, un string numérico como `"1"`, al imprimirlo, se ve igual que el número entero `1`.

```arturo
print #[a: 1]
; [a:1]
print #[a: "1"]
; [a:1]
```
En la salida de las pruebas de este ejercicio, es posible que veas un resultado como `:x: equal? [a:1 e:1 i:1 o:1 u:1] [a:1 e:1 i:1 o:1 u:1]`.
Los dos diccionarios que se comparan se ven iguales al imprimirlos.
Sin embargo, el primer diccionario tiene valores de tipo string numérico y el segundo tiene valores de tipo entero, así que no son lo mismo. 
Al depurar, puedes usar `inspect` para comprobar el contenido de tu diccionario.

## `Express` sí entrecomilla los valores de tipo string

`express` convierte un valor a código Arturo y devuelve un string que representa ese código.
En ese resultado, los valores de tipo string aparecerán entrecomillados.
Por lo tanto, `express "1"` devolverá `"1"`, no `1`.

```arturo
express #[name: "Octavius" age: 22]
; #[name: "Octavius" age: 22 ]
```
```arturo
express #[name: "Octavius" age: "22"]
; #[name: "Octavius" age: "22" ]
```
