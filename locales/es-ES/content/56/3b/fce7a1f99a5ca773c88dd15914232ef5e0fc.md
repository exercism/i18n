# Acerca de

Las [listas][list] son un tipo de dato básico en Haskell para almacenar una colección de valores.
Las listas son _inmutables_, lo que significa que no se pueden modificar.
Cualquier operación que cambie una lista devuelve una lista nueva.
El Prelude incluye varias funciones que te permiten trabajar con listas.

En Haskell, las listas se implementan como [listas enlazadas][linked-list-wiki], y no como arrays de posiciones de memoria contiguas.
Por lo tanto, acceder a un elemento de una lista requiere un tiempo lineal en función de la longitud de la lista.

Las listas se pueden escribir en forma literal, en notación cabeza-cola (que usa el operador `cons` `:`), o con una combinación de ambas:

```haskell
-- Literal Form
[]
[1]
[1, 2, 3]

-- Head-tail Notation
[]
-- same as [1]
1 : []
-- same as [1, 2, 3]
1 : (2 : (3 : []))

-- Mixed
-- same as [1, 2, 3]
1 : [2, 3]
```

La notación cabeza-cola se puede usar para añadir elementos a una lista.

```haskell
list = [2, 1]

[3, 2, 1] == 3 : list
-- -> True
```

Añadir elementos a una lista durante una iteración se considera un antipatrón.
Añadir un elemento requiere recorrer toda la lista y añadirlo al final; por lo tanto, añadir un elemento nuevo en cada iteración requeriría recorrer toda la lista en cada iteración.

Podemos conseguir el mismo resultado anteponiendo un elemento a la lista invertida y, después, invirtiendo el resultado. Anteponer es una operación rápida y requiere tiempo constante.

```haskell
-- Appending to the end of a list (potentially slow)
[1, 2, 3] ++ [4] ++ [5] ++ [6]

-- Prepend to the start of a list (faster, due to the nature of linked lists)
6 : (5 : (4 : [3, 2, 1]))
-- then reverse!
```

Hay varias funciones habituales del Prelude para listas:

- [`head`][head] devuelve la _cabeza_ de una lista, el _primer_ elemento de una lista.
- [`tail`][tail] devuelve la _cola_ de la lista, la lista _sin_ el _primer_ elemento.
- [`length`][length] devuelve el número de elementos de la lista.
- [`elem`][elem] devuelve un valor booleano que indica si el elemento está en la lista.

También existe el [módulo `Data.List`][list].

## Tipos de listas

En Haskell, las listas son **homogéneas**.
Esto significa que todos los elementos de una lista tienen el mismo tipo.
Si intentas meter elementos de tipos distintos en la misma lista, obtendrás un error de tipo.

```haskell
list = [1, "string"]
-- Error: No instance for (Num String) arising from the literal ‘1’
```

La anotación de tipo de una lista es `[a]`, donde a es el tipo que contiene la lista, por ejemplo `String` o `Int`.

``` haskell
a :: [Int] 
a = [1, 2, 3]
```
