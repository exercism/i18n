# Introducción

Go tiene tipado estático, así que toda variable tendrá un tipo conocido en tiempo de compilación. Una vez declarada, el tipo de una variable no puede cambiar.

## Crear una variable

La instrucción `var` puede declarar el tipo de una nueva variable, asignarle un valor o hacer ambas cosas a la vez:

```go
var total int     // Type explicitly declared, value implicitly set (see note on zero values below)
var count int = 1 // Type explicitly declared, value explicitly set
var sum = 100     // Type implictly declared, value explicitly set
```

Dentro de una función también se puede usar la instrucción de asignación corta `:=`.

```go
count := 1 // Type implictly declared, value explicitly set
```

Una variable en Go siempre tiene un valor. Si no se establece uno en la declaración, Go proporciona uno [llamado valor cero][zero-values], en función del tipo de la variable.

```go
var total int     // 0
var name string   // ""
var ready bool    // false
```

## Actualizar una variable

Dentro de una función, el operador de asignación `=` puede establecer un nuevo valor para una variable existente:

```go
count := 1
count = 2
```

El nuevo valor debe tener el mismo tipo que la variable:

```go
count := 1
count = false // compile error: a Boolean is not an int
```

[zero-values]: https://exercism.org/tracks/go/concepts/zero-values
