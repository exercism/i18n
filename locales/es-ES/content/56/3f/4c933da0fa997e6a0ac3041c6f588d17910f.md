# Instalación

Puedes descargar Phix para Windows o Linux desde [el sitio oficial][Download].

Después de la instalación, la estructura de directorios debería coincidir con la que se indica en la [documentación][Installation].

Para probar, ejecuta «p -test».

[Installation]: http://phix.x10.mx/docs/html/installation.htm
[Download]: http://phix.x10.mx/download.php
