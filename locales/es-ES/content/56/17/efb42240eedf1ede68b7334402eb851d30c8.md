# Instrucciones

En este ejercicio, aplicarás las [reglas del juego de Go](https://matmoore.github.io/learngo/). Las reglas ya están escritas; solo tienes que aplicarlas para actualizar la partida y gestionar los errores o las infracciones de las reglas.

La partida se representa así:

```gleam
pub type Player {
  Black
  White
}


pub type Game {
  Game(
    white_captured_stones: Int,
    black_captured_stones: Int,
    player: Player,
    error: String,
  )
}
```

En la partida hay 4 reglas:

- Cada punto solo puede tener una piedra.
- Las piedras del adversario se pueden capturar.
- No puedes colocar una piedra donde se capturaría a sí misma.
- No puedes usar el mismo punto dos veces.

## 1. Aplica las reglas

Escribe el contenido de la función `apply_rules`, que recibe un `Game` inicial y un conjunto de reglas, y devuelve el nuevo `Game` una vez aplicadas las reglas.

Tres de las reglas comprueban si se han infringido las reglas y pueden devolver un error, por lo que tienen el tipo de retorno `Result(Game, String)`. Si alguna de estas reglas falla, hay que devolver la partida original, pero con el campo `error` actualizado con el error correspondiente.

La otra regla no comprueba infracciones y, por tanto, no puede fallar (aunque puede devolver un `Game` modificado), así que tiene el tipo de retorno `Game`.

Si todas las reglas pasan, hay que conservar los cambios que hayan aplicado al `Game` y cambiar el jugador.

```gleam
pub fn apply_rules(
  game: Game,
  rule1: fn(Game) -> Result(Game, String),
  rule2: fn(Game) -> Game,
  rule3: fn(Game) -> Result(Game, String),
  rule4: fn(Game) -> Result(Game, String),
) -> Game {
  // -> If all rules pass, return a `Game` with all changes from the rules applied, and change player
  // -> If any rule fails, return the original Game, but with the error field set
}
```
