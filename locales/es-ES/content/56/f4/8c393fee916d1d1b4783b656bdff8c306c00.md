# Instrucciones

En este ejercicio vas a escribir código para imprimir tarjetas identificativas para los empleados de una fábrica. Los empleados tienen un id, un nombre y el nombre de un departamento. Las etiquetas de las tarjetas identificativas de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.

## 1. Imprime una tarjeta identificativa para un empleado

Implementa la función `NameBadge.print/3`. Debe recibir un id, un nombre y un departamento. Debe devolver la etiqueta de la tarjeta, con el nombre del departamento en mayúsculas.

```elixir
NameBadge.print(67, "Katherine Williams", "Strategic Communication")
# => "[67] - Katherine Williams - STRATEGIC COMMUNICATION"
```

## 2. Imprime una tarjeta identificativa para un empleado nuevo

Debido a una peculiaridad del sistema informático, a veces los empleados nuevos todavía no tienen un id cuando empiezan a trabajar en la fábrica. Como las tarjetas son obligatorias, recibirán una tarjeta temporal sin el prefijo del id.

Amplía la función `NameBadge.print/3`. Cuando falte el id, debe imprimir una tarjeta sin él.

```elixir
NameBadge.print(nil, "Robert Johnson", "Procurement")
# => "Robert Johnson - PROCUREMENT"
```

## 3. Imprime una tarjeta identificativa para el propietario

Incluso el propietario de la fábrica tiene que llevar una tarjeta en todo momento. Sin embargo, un propietario no tiene departamento. En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento.

Amplía la función `NameBadge.print/3`. Cuando falte el departamento, asume que la tarjeta pertenece al propietario de la empresa.

```elixir
NameBadge.print(204, "Rachel Miller", nil)
# => "[204] - Rachel Miller - OWNER"
```

Ten en cuenta que es posible que el propietario sea también un empleado nuevo.

```elixir
NameBadge.print(nil, "Rachel Miller", nil)
# => "Rachel Miller - OWNER"
```
