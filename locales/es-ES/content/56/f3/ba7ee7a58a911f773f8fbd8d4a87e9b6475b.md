# Introducción

Common Lisp permite al programador escribir «comentarios» que el ordenador ignora.
Los comentarios de una sola línea empiezan con uno o varios puntos y coma (`;`) y, de vez en cuando, puedes ver lo siguiente:

```lisp
(code...) ; => value
```

Ahí el comentario se usa para indicar qué valor devuelve Common Lisp después de ejecutar el código de esa línea.

Es idiomático usar un solo punto y coma para un comentario corto al final de una línea, dos para un comentario más largo encima de una sección de código, tres para un comentario largo que describe algo como una función, y cuatro para un comentario como un encabezado al principio de un fichero de código fuente.
