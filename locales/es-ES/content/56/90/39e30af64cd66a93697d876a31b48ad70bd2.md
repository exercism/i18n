# Instalar `testthat`

Los tests de este track hacen uso del paquete `testthat`.

Para instalar el paquete, basta con abrir R y ejecutar:

`install.packages("testthat")`

Puedes comprobar que el paquete se ha instalado correctamente ejecutando:

`library(testthat)`

# Ejecutar los tests

Cada ejercicio tendrá un script llamado `test_<exercise-name>.R` (p. ej. `test_hello-world.R`).

Para ejecutar los tests de un ejercicio, basta con ejecutar este script de R.

En RStudio, basta con abrir el script de tests y hacer clic en «Source» en la parte superior derecha del panel Source. Esto cargará el código de tu solución mediante el comando `source` de la primera línea del script de tests y, a continuación, ejecutará el conjunto de tests de `testthat` que vienen después.

Ten en cuenta, no obstante, que el comando `source()` de la primera línea del script de tests solo funcionará si tu script de solución (`<exercise-name>.R`) se encuentra en tu directorio de trabajo. Si no es así, tendrás que:
- cambiar tu directorio de trabajo, p. ej. `setwd('exercism/r/hello-world/')`, o
- actualizar la primera línea del script de tests, p. ej. `source('exercism/r/hello-world/hello-world.R')`

Si lo prefieres, también puedes ejecutar los tests desde la línea de comandos con `Rscript path_to_exercise_directory/test_<exercise-name>.R` (p. ej. `Rscript hello-world/test_hello-world.R`)

Otra forma práctica de ejecutar estos tests es usar [la función `auto_test` de testthat](https://www.rdocumentation.org/packages/testthat/topics/auto_test). Como el código y los tests de Exercism están en la misma carpeta, usa esa misma ruta para los parámetros `code_path` y `test_path`. Después de ejecutar `auto_test()`, los tests del ejercicio se ejecutarán automáticamente cada vez que actualices o guardes tu código R del ejercicio. Esto puede ayudarte a iterar rápidamente mientras trabajas en tu solución.
