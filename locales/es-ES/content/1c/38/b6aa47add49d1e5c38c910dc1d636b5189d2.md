# Pistas

- Puedes encontrar la documentación del paquete `Bitwise` [aquí][bitwise-docs].

## 1. Desplaza los bits hacia atrás

- Hay dos funciones para desplazar bits a la derecha, pero [solo una][bitwise-shiftRightZfBy] insertará siempre un 0.

## 2. Establece algunos bits

- [Una de las funciones bit a bit][bitwise-or] pondrá siempre un bit a 1 cuando los bits de ambos valores sean 1.

## 3. Invierte bits específicos

- Existe [una función bit a bit][bitwise-xor] que invertirá un bit cuando la máscara sea 1.

## 4. Borra bits específicos

- [Una de las funciones bit a bit][bitwise-and] borra los bits cuando el bit de la máscara es 0.
- Pero puede que tengas que combinarla con [otra función][bitwise-complement] para borrar los bits cuando la máscara es 1.

## 5. Descifra un mensaje

- Aplica las demás funciones que escribiste a la entrada en el siguiente orden, tomando la salida de una y usándola como entrada de la siguiente:

1. `setBits`
2. `flipBits`
3. `shiftBack`
4. `clearBits`

Para el paso 4, tendrás que convertir a decimal el número binario con el primer y el quinto bit a 1 (10001).
