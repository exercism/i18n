# Instrucciones

Eres un ávido observador de aves que lleva un registro de cuántos pájaros han visitado tu jardín en los últimos siete días.

Tienes cinco tareas, todas ellas relacionadas con las cantidades de pájaros que visitaron tu jardín.

## 1. Comprueba cuáles fueron los recuentos de la semana pasada

Almacenas tus recuentos de pájaros en formato JSON.
Un array «principal» almacena arrays de recuentos semanales.
Cada recuento semanal es un array de siete números enteros, un número por cada día de la semana.
Siempre añades las nuevas semanas al final del array principal.
Implementa el filtro que devuelve los recuentos de la semana pasada.

```sh
$ cat bird-counting-data.json
[
  ...,
  [0, 2, 5, 3, 7, 8, 4],
  [4, 5, 9, 10, 9, 4, 3]
]

$ jq -f bird-count.jq < bird-counting-data.json
{
  "last_week": [0, 2, 5, 3, 7, 8, 4],
  ...
```

## 2. Comprueba cuántos pájaros visitaron ayer

Implementa el filtro para devolver cuántos pájaros visitaron tu jardín ayer.
Los recuentos de pájaros están ordenados por día: el primer elemento es el recuento del día más antiguo y el último es el recuento de hoy.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "yesterday": 4,
  ...
```

## 3. Calcula el número total de pájaros que han visitado el jardín

Implementa el filtro para devolver el número total de pájaros que han visitado tu jardín esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "total": 44,
  ...
```

## 4. Calcula el número de días ajetreados

Algunos días están más ajetreados que otros.
Un día ajetreado es aquel en el que cinco o más pájaros han visitado tu jardín.
Implementa el filtro para devolver el número de días ajetreados de esta semana.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "busy_days": 4,
  ...
```

## 5. Comprueba si hubo algún día sin pájaros visitantes

Implementa el filtro que devuelve `true` si hubo algún día esta semana en el que cero pájaros visitaron el jardín; de lo contrario, devuelve `false`.

```jq
$ jq -f bird-count.jq < bird-counting-data.json
{
  ...
  "has_day_without_birds": false
}
```
