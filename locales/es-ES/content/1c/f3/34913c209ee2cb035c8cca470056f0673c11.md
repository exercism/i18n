# Instrucciones

En este ejercicio vas a escribir código para llevar un registro de los códigos de marcado internacionales mediante un mapa de códigos de marcado internacionales.

El mapa usa un número entero para sus claves (el código de marcado) y un string (el nombre del país) para sus valores.

Tienes 11 tareas relacionadas con los códigos de marcado.

## 1. Crea un mapa precargado

Existe un mapa precargado que contiene los siguientes 3 códigos de marcado: «United States of America», que tiene el código 1; «Brazil», que tiene el código 55, e «India», que tiene el código 91. Define la variable `countries` para almacenar el mapa precargado:

```clojure
countries
;;=> {1 "United States of America", 55 "Brazil", 91 "India"}
```

## 2. Añade un país a un mapa

Añade «United Kingdom», con el código de marcado 44, al mapa creado en la tarea 1:

```clojure
(add-country countries 44 "United Kingdom")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 3. Obtén el nombre del país que corresponde a un código

Obtén el nombre del país con el código de marcado 55

```clojure
(country-name countries 55)
;;=> "Brazil"
```

## 4. Actualiza el nombre de un país

Cambia el nombre de «United States of America» por «Les États-Unis»:

```clojure
(update-map countries 1 "Les États-Unis")
;;=> {1 "Les États-Unis", 55 "Brazil", 91 "India"}
```

## 5. Comprueba que un país existe en el mapa

Comprueba que existe un registro de Brazil en el mapa creado en la tarea 1

```clojure
(code-exists? countries 55)
;;=> true
```

## 6. Intenta actualizar el nombre de un país que no está en el mapa

Intenta cambiar el nombre de un país cuyo código no está en el mapa, por ejemplo el 999. Esto no debería modificar el mapa:

```clojure
(update-map countries 999, "Newlands")
;;=> {1 "United States of America", 44 "United Kingdom", 55 "Brazil", 91 "India"}
```

## 7. Elimina un país del mapa

Elimina India del mapa:

```clojure
(remove-country countries 91)
;;=> {1 "United States of America", 55 "Brazil"}
```

## 8. Encuentra el país con el nombre más largo

Recorre los valores del mapa para encontrar el que tiene el nombre más largo:

```clojure
(longest-name countries)
;;=> "United States of America"
```
