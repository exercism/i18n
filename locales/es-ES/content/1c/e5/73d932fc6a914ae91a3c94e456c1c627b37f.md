# Instrucciones

Tu amigo japonés Kuroko es un streamer con tirón internacional.
El calendario de directos de Kuroko es bastante enrevesado: cada directo parece empezar a una hora distinta cada día.

Te pide ayuda para crear una pequeña aplicación que muestre su horario en la zona horaria local de sus espectadores: el reloj de Kuroko.
Tiene un requisito adicional: la aplicación debe poder mostrar la hora en dos idiomas distintos, japonés e inglés estadounidense.

## 1. Es una cita

Define una función `showLocalDate : Locale -> Int -> Month -> Int -> String` que muestre una fecha local (válida).

Con la configuración regional `US`, el formato será `Month/Day/Year`, sin ceros a la izquierda.

Con la configuración regional `JP`, el formato será `Year年Month月Day日`, también sin ceros a la izquierda.

```elm
showLocalDate US 2025 May 1
    -- "5/1/2025"
showLocalDate JP 2025 May 1
    -- "2025年5月1日"
```

## 2. Es la hora del espectáculo

Define una función `showLocalTime : Locale -> Int -> Int -> String` que muestre una hora local (válida).

Con la configuración regional `US`, las horas se mostrarán en formato de 12 horas, junto con «PM» o «AM», y los minutos se mostrarán con ceros a la izquierda.

Con la configuración regional `JP`, la hora se mostrará en formato de 24 horas antes de «時» y los minutos se mostrarán sin ceros a la izquierda antes de «分».

```elm
showLocalTime US 13 8
    -- "1:08 PM"
showLocalTime JP 13 8
    -- "13時8分"
```

## 3. Entra en la zona

Define una función `showDateTime : Locale -> Zone -> Posix -> String` que muestre una fecha y una hora relativas a una zona horaria y en una configuración regional concreta.

Usa `showLocalDate` y `showLocalTime` para mostrar el resultado final.

```elm
showDateTime US Time.utc (Time.millisToPosix 0)
    -- "1/1/1970 12:00 AM"
showDateTime JP Time.utc (Time.millisToPosix 0)
    -- "1970年1月1日0時0分"
```
