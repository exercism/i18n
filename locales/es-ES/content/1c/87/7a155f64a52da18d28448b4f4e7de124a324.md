## Extra

Prueba tu función con este string: `uüu` y observa qué ocurre.
Intenta escribir una función que invierta correctamente este string.
Pista: grupos de grafemas

Para que se ejecute el test extra, elimina el flag de ignorar (`#[ignore]`) del último test y ejecuta los tests con:

```bash
cargo test --features grapheme
```

Para la tarea extra tendrás que usar bibliotecas externas (un `crate` en la jerga de Rust).
Un buen lugar donde buscarlas es [crates.io](https://crates.io/), el repositorio oficial de crates.
Recuerda que nuestro test runner solo admite un conjunto limitado de crates.
La lista completa está en [este archivo](https://github.com/exercism/rust-test-runner/blob/main/local-registry/Cargo.toml) en la sección `[dependencies]`.

[Consulta la documentación](https://doc.rust-lang.org/cargo/guide/dependencies.html) para saber cómo usar crates externos en tus proyectos.
