# Introducción

En Factor, combinas palabras simplemente escribiéndolas una tras otra:
el orden en que las escribes *es* la forma en que se unen. (Los
programadores llaman a esto *composición de funciones*.) El cuerpo de
una palabra es, a su vez, una secuencia de palabras: cada una consume
algunos valores de la pila y empuja su resultado, y la siguiente palabra
continúa donde lo dejó la anterior. Así, definir

```factor
! DOCTEST: SKIP   (cleanupname is hypothetical here — the exercise's job)
: firstletter ( name -- letter ) cleanupname first 1string ;
```

ya *es* la composición de `cleanupname`, `first` y `1string`.

Este ejercicio también presenta los **quotations**: un fragmento de
código que puedes guardar como valor y ejecutar más tarde, en lugar de
ejecutarlo en el momento.

## Quotations

Un quotation es un fragmento de código encerrado entre corchetes. No se
ejecuta al escribirlo; se queda en la pila como un valor:

```factor
[ 2 * ] .       ! => [ 2 * ]
```

`call` ejecuta un quotation:

```factor
3 [ 2 * ] call .    ! => 6
```

Escribes un quotation cuando necesitas pasar código como dato: para
ejecutarlo más tarde o para pasárselo a un *combinador*, una palabra que
toma un quotation como entrada.

## `compose`

`compose ( quot1 quot2 -- combined )` pega dos quotations en uno,
ejecutándolos en el orden en que están escritos:

```factor
[ 2 * ] [ 1 + ] compose .    ! => [ 2 * 1 + ]
```

Normalmente verás que definir una palabra pequeña con `:` ... `;` se lee
mejor que `compose`, pero `compose` resulta útil cuando necesitas
construir quotations sobre la marcha. Cuando los bloques de construcción
aún no son quotations, `>quotation ( seq -- quot )` (de
[`quotations`][quotations]) convierte una secuencia de valores y
referencias a palabras en un quotation al que se puede llamar:

```factor
USING: quotations sequences ;

{ [ 1 ] [ 2 + ] [ 3 * ] } concat >quotation call .   ! => 9
```

## Aplicar un quotation a dos entradas

`bi@ ( x y quot -- ... )` ejecuta el quotation sobre `x` y de nuevo
sobre `y`, dejando ambos resultados en la pila:

```factor
3 4 [ 2 * ] bi@ .s
! => 6
! => 8
```

La tarea `couple` del ejercicio toma dos nombres; `bi@` es la forma
natural de aplicar `initial` a cada uno.

## Algunas palabras para strings

El ejercicio necesita un puñado de pequeñas palabras para strings,
extraídas de tres vocabularios: [`sequences`][sequences],
[`ascii`][ascii] y [`strings`][strings]:

- `replace ( seq old new -- new-seq )` (en `splitting`): reemplaza una
  subcadena.
- `[ blank? ] trim` (`trim` en `sequences`, `blank?` en `ascii`):
  elimina los espacios en blanco del principio y del final.
- `1string ( char -- str )` (en `strings`): envuelve un solo
  carácter como string.
- `>upper ( str -- upper )` (en `ascii`): convierte un string a
  mayúsculas.
- `append ( s1 s2 -- s )` (en `sequences`): concatena dos strings.
- `prepend ( s1 s2 -- s )` (en `sequences`): concatena `s2` y luego
  `s1` (`append` con sus entradas en el orden inverso).
- `glue ( s1 s2 sep -- s )` (en `sequences`): concatena dos strings
  con un separador entre ellos.
- `surround ( seq pre post -- new )` (en `sequences`): envuelve un
  string con un prefijo y un sufijo.

Los caracteres Unicode se pueden escribir como `\u{XXXX}` dentro de un
string, donde `XXXX` es el punto de código en hexadecimal. El corazón
`\u{2764}` (❤) aparece en este ejercicio.

## Salida con formato

Cuando `append`/`glue`/`surround` no son lo bastante expresivos,
[`formatting`][formatting] proporciona `sprintf`, al estilo de printf:

```
sprintf ( inputs... format-string -- str )
```

`%s` interpola un string, `%d` un número entero, `%f` un número decimal;
los modificadores opcionales de ancho, precisión y relleno van entre
`%` y la letra del tipo:

```factor
USING: formatting ;

"Alice" "Bob" "%s & %s" sprintf .   ! => "Alice & Bob"
3.14159 "%.2f" sprintf .             ! => "3.14"
42 "%05d" sprintf .                  ! => "00042"
```

Para convertir en ambos sentidos entre números y strings,
[`math.parser`][math.parser] tiene `number>string` y
`string>number`:

```factor
USING: math.parser ;

42 number>string .       ! => "42"
"3.14" string>number .   ! => 3.14
```
