# Anexo a las instrucciones

## ¡Espera, es imposible!

Implementar estas operaciones con arrays sin usar _ninguna_ función integrada es prácticamente imposible en Roc, porque necesitas una forma de añadir o anteponer elementos a un array.
En otros lenguajes podrías usar operadores como `:` en Haskell o `+=` en Python, pero en Roc tienes que usar las [funciones de `List`](https://www.roc-lang.org/builtins/main/#Builtin.List).

Así que, para este ejercicio, puedes usar `List.append` (pero evita usar cualquier otra función integrada).

Muchos lenguajes de programación funcional usan listas enlazadas como tipo de colección principal.
Anteponer un elemento o extraer el primero de una lista enlazada es eficiente, así que en esos lenguajes implementarías las operaciones con arrays usando `List.prepend`.
En Roc, sin embargo, un `List` es un array (un fragmento contiguo de bytes).
Los arrays tienen propiedades distintas de las listas enlazadas, como la capacidad de acceder eficientemente a los elementos por índice y de añadir elementos nuevos.
Por eso, en Roc usamos `List.append` a menudo y rara vez usamos `List.prepend`.

## Nombres

Roc usa nombres ligeramente distintos de los que aparecen en las instrucciones generales:

- `concat` en lugar de `append`
- `join` en lugar de `concatenate`
- `len` en lugar de `length`
- `fold` en lugar de `foldl`
- `fold_rev` en lugar de `foldr`

Sin embargo, los siguientes nombres de función son estándar en Roc:
- `filter`
- `map`
- `reverse`

## Pista

Prueba a usar:

```roc
match list {
    [] => ...
    [first, .. as rest] => ...
}
```

o

```roc
match list {
    [] => ...
    [.. as rest, last] => ...
}
```
