# Instrucciones

En este ejercicio vas a implementar un conjunto parcial de rutinas auxiliares para ayudar a un desarrollador a limpiar nombres de identificadores.

En las 4 tareas irás construyendo poco a poco la rutina `clean`. Un identificador válido consta de cero o más letras y guiones bajos.

En todos los casos, se garantiza que el string de entrada no es nulo. Si se le pasa un string vacío a la función `clean`, debe devolverse un string vacío.

Ten en cuenta que quien llame a la rutina `clean` debería evitar pasarle un identificador vacío, ya que esos identificadores no sirven de nada.

## 1. Sustituye los espacios que encuentres por guiones bajos

Implementa la función `clean` para sustituir los espacios por guiones bajos. Esto también se aplica a los espacios al principio y al final.

```clojure
(clean "my   Id")
;;=> "my___Id"
```

## 2. Sustituye los caracteres de control por el string en mayúsculas "CTRL"

Modifica la función `clean` para sustituir los caracteres de control por el string en mayúsculas `"CTRL"`.

```clojure
(clean "my\0Id")
;;=> "myCTRLId"
```

## 3. Convierte kebab-case a camelCase

Modifica la función `clean` para convertir kebab-case en camelCase.

```clojure
(clean "à-ḃç")
;;=> "àḂç"
```

## 4. Omite las letras griegas minúsculas

Modifica la función `clean` para omitir cualquier letra griega en el rango de 'α' a 'ω'.

```clojure
(clean "MyΟβιεγτFinder")
;;=> "MyΟFinder"
```
