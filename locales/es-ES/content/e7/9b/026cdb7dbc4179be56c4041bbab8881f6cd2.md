# Acerca de

El atributo Flags permite representar los valores definidos en una unión discriminada como posiciones de bit (es decir, flags).
Como flags, esos valores se pueden combinar, lo que permite representar varias condiciones booleanas en un solo valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Activar un flag se puede hacer con el operador OR a nivel de bits (`|||`); desactivar un flag se puede hacer con una combinación del operador AND a nivel de bits (`&&&`) y el operador de negación a nivel de bits (`~~~`).
Aunque el estado de un flag se puede comprobar con el operador AND a nivel de bits, también se puede usar el método HasFlag().

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true

// Unset the Call flag
let lessFeatures = features &&& ~~~PhoneFeatures.Call

lessFeatures.HasFlag(PhoneFeatures.Call) // => false
lessFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Consulta el [resumen de los operadores a nivel de bits][bitwise-operators] para ver una lista completa de los operadores a nivel de bits disponibles en el lenguaje F#.
