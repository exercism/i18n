# no hay export con nombre

No se ha encontrado ningún [export](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/export) llamado `%{export.name}`. Los tests no pasarán sin él.

Asegúrate de que `%{export.name}` existe y añade `export` delante de él:
```javascript
// exporting a "const"
export const %{export.name} = /*...*/

// exporting a named function declaration
export function %{export.name}() { /* ... */ }
```
