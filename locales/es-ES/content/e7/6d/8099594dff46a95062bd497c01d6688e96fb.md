# Introducción

## Coincidencia de patrones con literales

Aunque las expresiones `if/else` se pueden usar para ejecutar lógica condicional, Haskell también tiene una forma más potente de ejecutar lógica condicional: la [coincidencia de patrones][pattern-matching].
Con la coincidencia de patrones, se puede probar un valor contra uno o varios _patrones_.
Un ejemplo de tal patrón es el _patrón constante_, que hace coincidir un valor con una constante (por ejemplo, `1` o `"hello"`).

Al definir funciones, puedes definir cuerpos de función distintos para patrones diferentes.
Esto da lugar a código limpio, sencillo y legible.
Puedes hacer coincidencia de patrones con cualquier tipo de datos, como números, caracteres, listas, tuplas, etc.

Por ejemplo, una función trivial que toma un número entero (`Int`) y lo acerca _1_ a _0_ se podría expresar así:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero 1 = 0
```

La coincidencia de patrones empieza a brillar cuando se usa junto con otros patrones, por ejemplo, el _patrón variable_:

```haskell
closerToZero :: Int -> Int
closerToZero 0 = 0
closerToZero n = n - 1
```

El ejemplo anterior trata por igual todos los valores de entrada distintos de _0_, y produciría resultados incorrectos para números negativos.
Esto se puede resolver usando patrones condicionales, conocidos como _guardas_, que se expresan con el símbolo `|`:

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
```

En los ejemplos anteriores, no todos los valores de entrada posibles tienen un patrón coincidente.
El compilador detectará esto y emitirá una advertencia.
Esta es una característica muy útil de Haskell que ayuda a garantizar que se cubran todos los caminos posibles para evitar errores en tiempo de ejecución.
Se conoce como _comprobación exhaustiva_.
Para resolver la advertencia, tienes que manejar todos los casos.
Dentro de las _guardas_, puedes usar la expresión `otherwise` como azúcar sintáctico para `True` para capturar todos los patrones restantes.

```haskell
closerToZero :: Int -> Int
closerToZero n
    | n < 0 = n + 1
    | n > 0 = n - 1
    | otherwise = 0
```

La coincidencia de patrones probará un valor contra cada patrón de arriba a abajo, hasta que encuentre un patrón coincidente y ejecute la lógica asociada a ese patrón.
**¡El orden de los patrones importa!**
