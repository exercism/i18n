# Introducción

Un [array][list] es una colección mutable de elementos en _secuencia_.
 Los arrays pueden contener referencias a cualquier tipo (o varios tipos) de datos, incluidos otros arrays u otras estructuras de datos como [tuplas][tuples], [conjuntos][sets] o [diccionarios][dicts].
 Se puede iterar sobre el contenido con la construcción `for item in <list>`.
 Si se necesitan índices junto con el contenido, se puede usar `for index, item in enumerate(<list>)`.
 Se puede acceder a los elementos de un `list` mediante un número `0-based index` contando desde la izquierda, o un número `-1-based index` contando desde la derecha.
 Los arrays se pueden copiar total o parcialmente con la _notación de segmentos_ o `<list>.copy()`.
 Python ofrece muchos [métodos][list-methods] útiles y prácticos para trabajar con arrays.
