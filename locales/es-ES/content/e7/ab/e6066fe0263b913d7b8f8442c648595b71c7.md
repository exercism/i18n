# Apéndice de instrucciones

## Pistas

Para conseguir que pase el test, vas a tener que crear algunos tipos para que tu código pueda trabajar con ellos. Necesitas un objeto para `School` que contenga una secuencia de tipo `Student`, que será una tupla de `string` e `int` para guardar el nombre y la nota de los estudiantes.

Aquí tienes algo de código con los tipos que podría serte útil para empezar

```nim
type
  Student* = tuple[name: string, grade: int]
  School* = object
    students*: seq[Student]
```
