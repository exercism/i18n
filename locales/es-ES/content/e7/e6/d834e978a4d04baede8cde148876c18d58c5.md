# Anexo a las instrucciones

## Memoria reservada

El búfer para la cadena de entrada usa los bytes 64-191 de la memoria lineal.

## Arrays

WebAssembly no tiene el concepto de arrays.
Para el test de los colores, devuelve un búfer de caracteres delimitado por comas con la forma: `black,brown,red,orange,yellow,green,blue,violet,grey,white`

Después tendrás que construir internamente un array de estructuras usando desplazamientos y longitudes para dar estructura a este búfer.
