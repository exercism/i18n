# Instrucciones

En este ejercicio vas a escribir algo más de código para ayudarte a cocinar tu magnífica lasaña, sacada de tu libro de cocina favorito.

Tienes cinco tareas, todas relacionadas con el tiempo empleado en cocinar la lasaña.

## 1. Permitir cambiar el tiempo esperado en el horno

Quieres escribir una función `remainingMinutesInOven` mejorada que reciba como parámetro el número de minutos transcurridos que la lasaña lleva en el horno y devuelva cuántos minutos le quedan todavía por permanecer en el horno, según el tiempo esperado en minutos de la tarea anterior.
Antes, te apoyabas en un valor constante, `expectedMinutesInOven`, que venía de fuera de la función `remainingMinutesInOven`.
Eso resultaba, por un lado, un poco demasiado enrevesado para tu gusto y, por otro, no era lo bastante flexible, ya que no te permitía cambiar el tiempo esperado en el horno.

Para poner un poco de orden, define la función `remainingMinutesInOven` que reciba como parámetro el número de minutos transcurridos que la lasaña lleva en el horno, además de un parámetro `expectedMinutesInOven` con un valor predeterminado de 40.
Tu función debe devolver cuántos minutos le quedan todavía a la lasaña por permanecer en el horno, según el tiempo esperado en minutos de la tarea anterior.

```swift
remainingMinutesInOven(elapsedMinutes: 30)
// Returns 10
remainingMinutesInOven(elapsedMinutes: 30, expectedMinutesInOven: 75)
// Returns 45
```

## 2. Permitir distinto número de capas

Antes habías escrito una función `preparationTimeInMinutes` que recibe como parámetro el número de capas que añadiste a la lasaña y devuelve cuántos minutos dedicaste a prepararla, suponiendo que cada capa te lleva 2 minutos preparar.
Sin embargo, no estás del todo contento con esta función, ya que tienes que contar tú mismo el número de capas de tu lasaña antes de poder llamarla, ¿y quién tiene tiempo para todo eso?

Para ponértelo más fácil, escribe una función, `preparationTimeInMinutes`, que reciba un parámetro `String` variádico, `layers`, donde enumeras las distintas capas de tu lasaña.
La función contará entonces el número de capas de tu lasaña y devolverá el tiempo de preparación necesario.

```swift
preparationTimeInMinutes(layers: "sauce", "noodles")
// Returns 4
preparationTimeInMinutes(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns 24
```

## 3. Calcular las cantidades de fideos y salsa

Antes de empezar a montar tu lasaña, quieres asegurarte de tener suficiente salsa y fideos para construir la lasaña de tus sueños.
Por cada capa de fideos de tu lasaña, necesitarás 3 fideos.
Por cada capa de salsa de tu lasaña, necesitarás 0,2 litros de salsa.

Define la función `quantities` que reciba un parámetro `String` variádico, `layers`, donde enumeras las distintas capas de tu lasaña.
La función determinará entonces la cantidad de fideos y salsa necesaria para preparar tu comida. El resultado debe devolverse en una tupla de tipo `(noodles: Int, sauce: Double)`.

```swift
quantities(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns (noodles: 9, sauce: 0.8)
quantities(layers: "sauce", "noodles", "sauce", "noodles", "meat", "noodles", "mozzarella")
// Returns (noodles: 9, sauce: 0.4)
```

## 4. Convertir litros a onzas líquidas in situ

Por desgracia, la salsa que tienes a mano tiene el volumen indicado en onzas líquidas en lugar de en litros.
Para ayudarte a saber si tienes suficiente salsa a mano, escribe una función, `toOz`, que reciba un parámetro tupla in-out, `(noodles: Int, sauce: Double)`, y convierta la cantidad de salsa a onzas líquidas.
Ten en cuenta que hay 33,814 onzas líquidas por litro.

```swift
var amount = (noodles: 9, sauce: 0.8)
toOz(&amount)

amount
// Returns (noodles: 9, sauce: 27.0512)
```

## 5. Determinar el mejor vino para servir

Por último, quieres saber qué tipo de vino servir con tu lasaña.
Has oído que deberías servir vino blanco si en la lasaña hay más mozzarella, ricotta y béchamel que carne y salsa, y vino tinto en caso contrario.
Escribe una función `redWine` que reciba un parámetro `String` variádico, `layers`, donde enumeras las distintas capas de tu lasaña.
La función usará cinco funciones anidadas para determinar el número de capas de mozzarella, ricotta, béchamel, salsa y carne de la lasaña, y comparará el número de capas para decidir si debe servirse vino tinto, devolviendo `true` si es así y `false` si no.

```swift
redWine(layers: "sauce", "noodles", "sauce", "meat", "mozzarella", "noodles", "sauce", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns true
redWine(layers: "sauce", "noodles", "béchamel", "meat", "mozzarella", "noodles", "ricotta", "eggplant", "béchamel", "noodles", "sauce", "mozzarella")
// Returns false
```
