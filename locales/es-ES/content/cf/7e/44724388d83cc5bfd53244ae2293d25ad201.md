# Introducción

Una función te permite agrupar código en una unidad reutilizable.
Se compone de la palabra clave `func`, el nombre de la función y una lista separada por comas de cero o más parámetros y tipos entre paréntesis.

## Parámetros de función

Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros.
Los parámetros no tienen valores predeterminados, por lo que todos los parámetros de función son obligatorios.

```go
import "fmt"

// No parameters
func PrintHello() {
    fmt.Println("Hello")
}

// One parameter
func PrintHelloName(name string) {
  fmt.Println("Hello " + name)
}
```

Los parámetros del mismo tipo se pueden declarar juntos, seguidos de una única declaración de tipo.

```go
import "fmt"

func PrintGreetingName(greeting, name string) {
  fmt.Println(greeting + " " + name)
}
```

## Parámetros y argumentos

Veamos rápidamente dos términos que a menudo se confunden entre sí: `parameters` y `arguments`.
Los parámetros de función son los nombres definidos en la signatura de la función, como `greeting` y `name` en la función `PrintGreetingName` de arriba.
Los argumentos de función son los valores concretos que se pasan a los parámetros de la función cuando llamamos a esta.
Por ejemplo, en el ejemplo de abajo, `"Hello"` y `"Katrina"` son los argumentos que se pasan a los parámetros `greeting` y `name`:

```go
PrintGreetingName("Hello", "Katrina")
```

## Valores devueltos

A los parámetros de la función les siguen cero o más valores devueltos, que también deben tener un tipo explícito.
Un único valor devuelto se escribe sin paréntesis; varios valores devueltos se envuelven entre paréntesis.
Los valores se devuelven al código que llama desde las funciones con la palabra clave `return`.
Puede haber varias instrucciones `return` en una función.
La ejecución de la función termina en cuanto se topa con una de esas instrucciones `return`.
Si una función debe devolver varios valores, estos se separan por comas.

```go
func Hello(name string) string {
  return "Hello " + name
}

func HelloAndGoodbye(name string) (string, string) {
  return "Hello " + name, "Goodbye " + name
}
```

## Llamar a funciones

Llamar a una función consiste en especificar el nombre de la función y pasar argumentos para cada uno de los parámetros de esta entre paréntesis.

```go
import "fmt"

// No parameters, no return value
func PrintHello() {
    fmt.Println("Hello")
}
// Called like this:
PrintHello()

// One parameter, one return value
func Hello(name string) string {
  return "Hello " + name
}
// Called like this:
greeting := Hello("Dave")

// Multiple parameters, multiple return values
func SumAndMultiply(a, b int) (int, int) {
    return a+b, a*b
}
// Called like this:
aplusb, atimesb := SumAndMultiply(a, b)
```

## Valores devueltos con nombre y return «desnudo»

Igual que los parámetros, los valores devueltos pueden tener nombre de forma opcional.
Si se usan valores devueltos con nombre, una instrucción `return` sin argumentos devolverá esos valores.
Esto se conoce como un return «desnudo».

```go
func SumAndMultiplyThenMinus(a, b, c int) (sum, mult int) {
    sum, mult = a+b, a*b
    sum -= c
    mult -= c
    return
}
```
