# Introducción

## Funciones con múltiples cláusulas

Elixir facilita las prácticas del **Open-Closed Principle** al permitir que las funciones tengan múltiples cláusulas, de modo que, en lugar de repartir y escribir de forma rígida la lógica de control, se pueden escribir funciones concretas para añadir o quitar comportamiento con facilidad.

Elixir ofrece _múltiples cláusulas de función_ y _guardas_ para escribir:

```elixir
def number(n) when n == 7 do
  "Awesome, that's my favorite"
end

def number(_n) do
  "That's not my favorite"
end
```

En tiempo de ejecución, Elixir comprobará, de arriba a abajo del archivo fuente, qué cláusula de función invocar.

Las variables que no se usan deben ir precedidas de un guion bajo.

## Guardas

Las guardas se usan para evitar que Elixir invoque funciones basándose en la evaluación de los argumentos mediante funciones de guarda. Las guardas comienzan con la palabra clave `when`, seguida de una expresión booleana. Las funciones de guarda son funciones especiales que:

- Deben ser puras y no modificar ningún estado global.
- Deben devolver valores `true` o `false` estrictos.

Puedes encontrar una lista de guardas habituales en la [documentación de Elixir][kernel-guards]. Incluye comprobaciones de tipo, aritmética básica, comparaciones y operadores estrictamente booleanos.

## Argumentos predeterminados

Las funciones pueden declarar valores predeterminados para uno o varios argumentos. Veamos esta función:

```elixir
def number(n \\ 13), do: "That's not my favorite"
```

Al compilarse, Elixir crea una definición de función para `number/0` (sin argumentos) y `number/1` (un argumento).

Si más de un argumento tiene valores predeterminados, los valores predeterminados se aplicarán a la función de izquierda a derecha para rellenar los argumentos que falten.

Si la función tiene más de una cláusula, los argumentos predeterminados deben definirse en una cabecera de función (una función sin cuerpo) antes de las cláusulas de la función:

```elixir
def number(n \\ 13)
def number(n) when n < 10, do: "Dream bigger!"
def number(n) when n > 100, do: "Not that big..."
```
