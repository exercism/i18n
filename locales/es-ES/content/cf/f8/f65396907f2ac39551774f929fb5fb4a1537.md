# Introducción

En este ejercicio debes ejecutar lógica de forma condicional. La forma más común de hacer esto en C# es usar una instrucción `if/else`:

```csharp
int x = 6;

if (x == 5)
{
    // Execute logic if x equals 5
}
else if (x > 7)
{
    // Execute logic if x greater than 7
}
else
{
    // Execute logic in all other cases
}
```

La condición de una instrucción `if` debe ser de tipo `bool`. C# no tiene el concepto de valores _truthy_.
