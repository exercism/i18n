# Instrucciones

Tu nostalgia por las cartas Blorkemon™️ no muestra signos de disminuir: incluso has vuelto a coleccionarlas y estás consiguiendo que tus amigos se unan a ti.

En este ejercicio, una colección de cartas se representa con un `MapSet`, ya que las cartas duplicadas no son importantes cuando tu objetivo es conseguir todas las cartas existentes.

## 1. Empieza una colección

Quieres de verdad que tus amigos se sumen a tu locura por Blorkemon™️, y la mejor forma es arrancar su colección regalándoles una carta.

Implementa `GottaSnatchEmAll.new_collection`, que transforma una carta en una colección.

```elixir
GottaSnatchEmAll.new_collection("Newthree")
# => MapSet.new(["Newthree"])
```

## 2. Haz crecer la colección

Una vez que tienes una colección, cobra vida propia y debe crecer.

Implementa `GottaSnatchEmAll.add_card`, que toma una carta y una colección, y devuelve una tupla con dos valores: un Boolean que indica si la carta ya estaba en la colección, y la colección con la carta añadida.

```elixir
GottaSnatchEmAll.add_card("Scientuna", MapSet.new(["Newthree"]))
# => {false, MapSet.new(["Newthree", "Scientuna"])}
```

## 3. Empieza a intercambiar

Ahora que tus amigos vuelven a estar locos por Blorkemon™️, puedes aprovecharlo para hacer crecer tu propia colección intercambiando cartas.

No todos los intercambios merecen la pena o pueden hacerse.
No puedes intercambiar una carta que no tienes, y no deberías cambiar una carta por otra que ya tienes.

Implementa `GottaSnatchEmAll.trade_card`, que toma dos cartas para intercambiar (la tuya y la suya) y tu colección actual.
El valor devuelto es una tupla de dos valores: un Boolean que indica si el intercambio es posible y merece la pena, y la colección con la que acabarías si hicieras el intercambio (aunque en realidad no sea posible).

```elixir
GottaSnatchEmAll.trade_card("Scientuna", "Newthree", MapSet.new(["Scientuna"]))
# => {true, MapSet.new(["Newthree"])}
```

## 4. Solo puede haber una de cada

Encuentras un viejo alijo de cartas en un mercadillo.
Debes ordenar las cartas y eliminar los duplicados para comparar la lista con tu colección.

Implementa `GottaSnatchEmAll.remove_duplicates`, que ordenará una lista de cartas y devolverá una lista de cartas únicas y ordenadas.

```elixir
GottaSnatchEmAll.remove_duplicates(["Newthree", "Newthree", "Newthree", "Scientuna"])
# => ["Newthree", "Scientuna"]
```

## 5. Cartas que no tienen

Es hora de sentirte bien con tu colección.

Implementa `GottaSnatchEmAll.extra_cards`, que toma tu colección y otra colección cualquiera, y devuelve el número de cartas que la otra colección no tiene.

```elixir
GottaSnatchEmAll.extra_cards(MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"]))
# => 0
```

## 6. Cartas que todos tienen

Tú y tus amigos aficionados a Blorkemon™️ os reunís y os preguntáis qué cartas son las más comunes.

Implementa `GottaSnatchEmAll.boring_cards`, que toma una lista de colecciones y devuelve una lista ordenada de las cartas que tienen todas las colecciones.

```elixir
GottaSnatchEmAll.boring_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => ["Scientuna"]
```

## 7. Todas las cartas

¿Tus amigos y tú tenéis, entre todos, todas las cartas de Blorkemon™️?

Implementa `GottaSnatchEmAll.total_cards`, que toma una lista de colecciones y devuelve el número total de cartas diferentes que hay en todas las colecciones.

```elixir
GottaSnatchEmAll.total_cards([MapSet.new(["Scientuna"]), MapSet.new(["Newthree", "Scientuna"])])
# => 2
```

## 8. Brillantes para ganar

Tu sobrino viene a visitarte pronto y te apetece impresionarlo.
A los niños les gustan las cosas brillantes, ¿verdad?
¡Las cartas Blorkemon™️ pueden ser brillantes!

Implementa `GottaSnatchEmAll.split_shiny_cards`, que toma una colección y devuelve una tupla con dos listas ordenadas de cartas: una con todas las cartas que empiezan por `"Shiny"` y otra con el resto de las cartas.

```elixir
GottaSnatchEmAll.split_shiny_cards(MapSet.new(["Newthree", "Scientuna", "Shiny Scientuna"]))
# => {["Shiny Scientuna"], ["Newthree", "Scientuna"]}
```
