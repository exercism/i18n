# Instrucciones

Estás creando un juego en línea sencillo en el que un amigo puede adivinar un número secreto. Quieres dar algún comentario, pero sin desvelar la respuesta con un intento. Necesitas idear una función que proporcione respuestas diferentes en función de cómo se relacione el intento con el número secreto.

| Condición                                                     | Respuesta      |
| ------------------------------------------------------------- | -------------- |
| Cuando el intento coincide con el número secreto              | "Correct"      |
| Cuando el intento es uno más o uno menos que el número secreto | "So close"     |
| Cuando el intento es mayor que el número secreto              | "Too high"     |
| Cuando el intento es menor que el número secreto              | "Too low"      |
| Cuando no se hace ningún intento                              | "Make a guess" |

Tanto los intentos como los números secretos son números enteros.

## 1. Genera la respuesta cuando el intento coincida con el número secreto

Implementa la función `compare/2`, que recibe dos argumentos, `secret_number` y `guess`, ambos números enteros.

```elixir
GuessingGame.compare(5, 5)
# => "Correct"
```

## 2. Genera la respuesta cuando el intento sea mayor que el número secreto

Modifica la función `compare` para que responda a los intentos que sean mayores que el número secreto.

```elixir
GuessingGame.compare(5, 8)
# => "Too high"
```

## 3. Genera la respuesta cuando el intento sea menor que el número secreto

Modifica la función `compare` para que responda a los intentos que sean menores que el número secreto.

```elixir
GuessingGame.compare(5, 2)
# => "Too low"
```

## 4. Genera las respuestas cuando el intento sea uno más o uno menos que el número secreto

Modifica la función `compare` para que responda a los intentos que estén cerca del número secreto.

```elixir
GuessingGame.compare(5, 6)
# => "So close"
GuessingGame.compare(5, 4)
# => "So close"
```

## 5. Genera la respuesta cuando no haya ningún intento

Modifica la función `compare` para que responda cuando no haya ningún intento.

```elixir
GuessingGame.compare(5)
# => "Make a guess"

GuessingGame.compare(5, :no_guess)
# => "Make a guess"
```
