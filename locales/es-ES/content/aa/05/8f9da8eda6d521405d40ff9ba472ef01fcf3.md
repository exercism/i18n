# Cómo ejecutar los tests en la línea de comandos

Ejecuta los tests con:

```bash
$ cargo test
```

Todos los tests menos el primero están ignorados. Cuando consigas que el primer test pase, abre el fichero de código fuente de los tests, que está en el directorio `tests`, elimina el flag `#[ignore]` del siguiente test y haz que los tests vuelvan a pasar. Cada test por separado es una función con el flag `#[test]` justo encima. Continúa así hasta que pases todos los tests.

Si quieres ejecutar _solo los tests ignorados_ sin editar el fichero de código fuente de los tests, usa:

```bash
$ cargo test -- --ignored
```

Si usas Rust 1.51 o posterior, puedes ejecutar _todos_ los tests con:

```bash
$ cargo test -- --include-ignored
```

Para ejecutar un test concreto, por ejemplo `some_test`, puedes usar:

```bash
$ cargo test some_test
```

Si el test concreto está ignorado, usa:

```bash
$ cargo test some_test -- --ignored
```

Para saber más sobre los tests de Rust, consulta la [documentación de los tests][rust-tests] en línea.

[rust-tests]: https://doc.rust-lang.org/book/ch11-02-running-tests.html
