# Introducción

El mapeo hace referencia a la aplicación de una función a cada elemento de una secuencia para producir una nueva secuencia.

Esto se puede hacer fácilmente en una lista con la función `mapcar`.
Supongamos que tenemos una función `double` que multiplica su argumento por `2`:

```lisp
(mapcar #'double '(1 2 3 4)) ; => (2 4 6 8)
```

Fíjate en que el primer argumento es una función que hay que llamar. El `#'` es una sintaxis especial de cita que sirve para especificar una función.

Primero se llamó a `double` con el primer elemento, después con el segundo, etc.
Los resultados se recogieron en una lista, que es el valor que resulta de evaluar la expresión.
