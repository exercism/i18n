# Anexo de las instrucciones

## Pistas

Para completar este ejercicio, tienes que crear el tipo de datos `Robot`
e implementar las siguientes funciones:

- `bearing`
- `coordinates`
- `mkRobot`
- `move`

Encontrarás una declaración de datos ficticia y las firmas de tipos ya preparadas,
pero eres tú quien debe definir las funciones y crear un tipo de datos,
un newtype o un sinónimo de tipo que tenga sentido.
