# Pruebas

Un ejercicio descargado incluye estos archivos para compilar y probar tu solución:

```text
hello-world/
├── HelloWorld.vb          # Your solution
├── HelloWorldTests.vb     # The test suite
├── HelloWorld.vbproj      # Project and build configuration
└── packages.lock.json     # Resolved project dependencies
```

Los nombres de los archivos varían según el ejercicio.
Escribe tu solución en el primer archivo `.vb`.
El segundo archivo, el que termina en `Tests.vb`, es la [suite de pruebas de xUnit][xunit].
Por lo general, solo editarás este archivo para habilitar las pruebas siguientes.
No necesitarás editar ninguno de los dos últimos archivos.
El archivo `.vbproj` contiene la configuración de compilación del proyecto y las referencias directas a paquetes.
El archivo `packages.lock.json` generado registra las versiones resueltas de los paquetes directos y transitivos.

~~~exercism/note
Las pruebas describen el comportamiento que debe cumplir una solución que pase.
Pueden ayudarte a aclarar detalles que no cubren las instrucciones.
~~~

## Ejecutar las pruebas

Abre una terminal en el directorio del ejercicio y ejecuta:

```bash
dotnet test
```

El comando restaura las dependencias del proyecto, compila el proyecto y ejecuta sus pruebas.
También puedes usar `dotnet watch test` para volver a ejecutar las pruebas cada vez que cambie un archivo fuente.

## Pruebas omitidas

Los ejercicios habilitan inicialmente solo la primera prueba, lo que te permite resolver el resto paso a paso.
Abre el archivo que termina en `Tests.vb` para encontrar las pruebas.
Cada prueba es una subrutina `Sub` marcada con un atributo `<Fact>` de xUnit.
Una prueba se omitirá siempre que su atributo `<Fact>` tenga un argumento `Skip`:

```vb
<Fact(Skip:="Remove this Skip property to run this test")>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Para habilitar la prueba, solo tienes que eliminar el argumento `Skip`:

```vb
<Fact>
Public Sub Lowercase_words()
    Assert.Equal("ROR", Abbreviate("Ruby on Rails"))
End Sub
```

Cuando la prueba recién habilitada pase, repite este proceso con la siguiente prueba omitida.
Cuando todas las pruebas estén habilitadas y pasen, habrás terminado.
