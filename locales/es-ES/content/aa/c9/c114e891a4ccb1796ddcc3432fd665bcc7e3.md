# Crear un analizador

En primer lugar, ¡gracias por tu interés en crear un analizador!

Estos son los pasos para empezar:

1. Consulta [nuestra lista de repositorios para ver si ya existe un `...-analyzer`](https://github.com/search?q=org%3Aexercism+analyzer&type=repositories) para asegurarte de que no haya ya uno.
2. Revisa el [contenido de este directorio](/docs/building/tooling/analyzers) para asegurarte de que te sientes cómodo con la idea de crear un analizador.
3. Abre un tema nuevo en [el foro de Exercism][building-exercism] para decirnos para qué lenguaje te gustaría crear un analizador.
4. Una vez que se haya creado un repositorio de analizador para ti, usa los documentos [la interfaz del analizador](/docs/building/tooling/analyzers/interface) y [Buenas prácticas](/docs/building/tooling/best-practices) para orientar tu implementación.

¡Tenemos una comunidad increíblemente amable y solidaria que estará encantada de ayudarte mientras avanzas!
Si te quedas atascado, abre un tema nuevo en [el foro de Exercism][building-exercism] o crea nuevos issues en [exercism/exercism][exercism-repo] si lo necesitas 🙂

[building-exercism]: https://forum.exercism.org/c/exercism/building-exercism/125
