# Track de prueba

_Antes de_ lanzar tu track (es decir, la clave `"active"` sigue siendo `false` en el `config.json` del track), es importante probarlo.
Esto ayudará a encontrar errores (habituales) y permite corregirlos _antes_ de que se lance el track, lo que significa que los estudiantes no se toparán nunca con ellos.

## Cómo habilitar el track para probarlo

Para habilitar el track para probarlo, hay que añadirlo a nuestra base de datos, algo que solo pueden hacer los administradores del sitio.
Abre un tema en [el foro](https://forum.exercism.org/c/exercism/building-exercism/125) para solicitarlo.

Ten en cuenta que añadir el track a la base de datos _no_ lanzará el track, pero _sí_ lo hará accesible en el sitio web para los usuarios mantenedores.

## Cómo encontrar personas que prueben el track

Las personas ideales para probar el track son otros mantenedores de tracks, ya que:

- Tienen experiencia creando un track (y por tanto saben qué debería haberse creado)
- Pueden acceder a tracks que aún no están activos

Para conseguir que los mantenedores prueben tu track, abre un tema en [el foro](https://forum.exercism.org/c/exercism/building-exercism/125) para solicitarlo.
