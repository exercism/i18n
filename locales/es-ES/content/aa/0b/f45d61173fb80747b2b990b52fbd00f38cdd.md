# Pistas

## 1. Comprobar si el comando es válido

- Probablemente necesites [`ignore_case`][ref-regex] en la definición de la expresión regular.
- Busca solo el principio del mensaje.

## 2. Eliminar los emojis cifrados

- `stringr` tiene tanto [`str_replace()`][ref-str_replace] como [`str_remove()`][ref-str_remove].

## 3. Comprobar si el número de teléfono es válido

- Ramifica el código según si la expresión regular se [detecta][ref-str_detect] o no.
- Consulta el [concepto de string][concept-strings] si tienes problemas para componer la salida.

## 4. Saludar al usuario

- Necesitarás varios grupos de captura.
- [`str_replace()`][ref-str_replace] funciona mejor con capturas _sin nombre_: mantenlo sencillo.

## 5. Obtener el enlace del sitio web

- Puede haber varias coincidencias en cada mensaje.
- Lee la introducción para ver los consejos (cerca del final) sobre cómo usar `str_match_all()` y desempaquetar los resultados: _un poco confuso, pero no realmente difícil_.
