# Acerca de

ABAP admite los operadores aritméticos habituales para valores numéricos:

- `+` suma valores.
- `-` resta valores.
- `*` multiplica valores.
- `/` divide valores.
- `MOD` devuelve el residuo de una división entera.

```abap
DATA total TYPE i.
total = 6 + 4 * 2.

DATA remaining_days TYPE i.
remaining_days = 70 MOD 22.
```

La multiplicación y la división se evalúan antes que la suma y la resta. Usa paréntesis cuando quieras agrupar un cálculo de forma explícita.

```abap
DATA result TYPE i.
result = ( 6 + 4 ) * 2.
```
