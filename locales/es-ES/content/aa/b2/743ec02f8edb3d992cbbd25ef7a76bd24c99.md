# Pistas

## General

- Usa el crate `enum-iterator` para poder iterar sobre enumeraciones. Echa un vistazo a la [documentación](https://docs.rs/enum-iterator/1.2.0/enum_iterator/) para saber cómo.

- Usa el crate `int-enum` para poder convertir de int a enumeración. Consulta la [documentación](https://docs.rs/int-enum/0.5.0/int_enum/) para más detalles.

- El trait `Debug` está ahí porque probablemente lo necesites.

- Tendrás que ampliar la lista de traits derivados con `derive` en tu enumeración de colores.
