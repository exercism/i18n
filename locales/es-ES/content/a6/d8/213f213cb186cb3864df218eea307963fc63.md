# Introducción

Una propiedad en Haxe es un miembro de una clase que da acceso a los datos que hay dentro de esa clase. Quien la usa puede establecer (set) o recuperar (get) los datos. Consta de un accesor de escritura y/o un accesor de lectura.

Las propiedades tienen modificadores de acceso (public, private, etc.) igual que cualquier otro miembro de la clase, pero el accesor de escritura puede tener un nivel de acceso independiente del accesor de lectura (get), y viceversa. Una propiedad no tiene por qué tener los dos accesores; puede tener solo uno (ya sea get o set).

El acceso de lectura y el acceso de escritura se reflejan directamente en la sintaxis, como muestra el siguiente ejemplo:

```haxe
class Main {
  public var x(default, null):Int;
}
```

Tanto `default` como `null` son **identificadores de acceso** especiales. Los identificadores de acceso determinan el comportamiento cuando se lee el campo (primer identificador) y cuando se escribe en él (segundo identificador). Los valores aceptados son:

- `default`: permite el acceso normal al campo si el campo es público.
- `null`: permite el acceso solo desde dentro de la clase en la que se define.
- `get/set`: el acceso se genera como una llamada a un método accesor (`get_x()`).
- `dynamic`: igual que `get/set`, pero no se puede verificar la existencia de un método accesor.
- `never`: no permite ningún tipo de acceso.

Aquí tienes un ejemplo completo:

```haxe
class Main {
  public var x(default, set):Int;

  public function set_x(x:Int):Int {
    return this.x = x + 2;
  }

  public function main() {
    trace(x); // null
    x = 2;
    trace(x); // 4
  }
}
```
