## 3. Define la función multiply_treasure

- El valor devuelto será un `TreasureChest{Vector{T}}`, donde `T` es el tipo del tesoro que hay en el cofre proporcionado.
  - En el espíritu del concepto, podrías obtener el tipo del tesoro y crear un cofre paramétrico con el parámetro configurado a un `Vector` del tipo original.
  - Mucho más sencillo (quizá sintiéndote _un poquito_ como si estuvieras haciendo trampa), podrías ignorar el parámetro y dejar que la inferencia de tipos se encargue.
- Para crear un vector con elementos repetidos, tienes dos funciones entre las que elegir:
  - [`fill(value, multiplier)`][fill] toma un valor escalar y lo repite.
  - [`repeat([value,], multiplier)`][repeat] repite el vector dado.
