# Acerca de

Gleam puede ejecutarse en la máquina virtual de Erlang (BEAM) o en runtimes de JavaScript. Hay muchos otros lenguajes que usan estos runtimes, y a menudo resulta útil poder llamar desde Gleam a código escrito en esos lenguajes.

La funcionalidad de _funciones externas_ de Gleam permite importar a Gleam funciones escritas en otros lenguajes y llamarlas sin ninguna sobrecarga en tiempo de ejecución.

Si tu proyecto de Gleam se ejecuta en la máquina virtual de Erlang y quieres llamar a la función `reverse` del módulo `lists` de Erlang, puedes hacerlo añadiendo el atributo `@external` a la cabecera de una función de Gleam así:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

Esta función se puede llamar entonces como cualquier otra función de Gleam:

```gleam
let reversed = reverse_list([1, 2, 3])
// -> [3, 2, 1]
```

Si intentas compilar este código para runtimes de JavaScript, fallará con un mensaje de error, ya que no hay ninguna implementación para JavaScript. Puedes especificar otra implementación para los runtimes de JavaScript así:

```gleam
@external(erlang, "lists", "reverse")
@external(javascript, "./my_module.mjs", "reverse")
pub fn reverse_list(x: List(a)) -> List(a)
```

También es posible escribir una implementación en Gleam que se use cuando no haya ninguna implementación externa para el objetivo de compilación actual:

```gleam
@external(erlang, "lists", "reverse")
pub fn reverse_list(x: List(a)) -> List(a) {
  tail_recursive_reverse(x, [])
}

fn tail_recursive_reverse(list, reversed) {
  case list {
    [] -> reversed
    [x, ..xs] -> tail_recursive_reverse(xs, [x, ..reversed])
  }
}
```
