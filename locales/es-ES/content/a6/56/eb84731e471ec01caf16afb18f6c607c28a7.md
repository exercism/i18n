# Anexo a las instrucciones

## Implementación

Se ha añadido una prueba opcional que comprueba que las letras puedan ser cualquier carácter unicode, no solo caracteres alfabéticos ASCII.
Estas pruebas no son accesibles desde el editor web, pero se ejecutan de forma predeterminada al ejecutarlas en local.

Para desactivar estas pruebas, cuando llames al comando de pruebas (`crystal spec`), añade el siguiente flag: `--tag "~optional"`
