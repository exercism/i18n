# Acerca de

Escribe código que se lea como inglés corriente.

Visual Basic se ejecuta en el mismo entorno de ejecución de .NET que C# y F#.
Tienes LINQ, genéricos y async/await, pero la sintaxis está pensada para leerse, no para descifrarse.

Si ya conoces C# o F#, el entorno de ejecución y las bibliotecas de .NET te resultarán familiares.
Si conoces VB6, VBA o VBScript, esa sintaxis que ya te resulta familiar ahora cuenta con el respaldo del entorno de ejecución de .NET, curtido en batalla.

Sin llaves que equilibrar, sin puntos y coma que perseguir.
