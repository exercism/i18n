# Anexo de las instrucciones

## Rasgos de Rust para `.to_string()`

También tendrás que implementar `.to_string()` para la estructura `Clock`.
Lo usaremos para mostrar el estado de `Clock`.
Puedes hacerlo implementándolo directamente o usando el [rasgo Display][display-trait].

En ese caso, intenta implementar el [rasgo Display][display-trait] para `Clock`.

Los rasgos permiten una forma común de implementar funcionalidad para varios tipos.

Para seguir aprendiendo, piensa en cómo podrías implementar `String::from` para el tipo `Clock`.
No hace falta que lo implementes de verdad: es redundante con `Display`, que por lo general es la
mejor opción cuando el tipo de destino es `String`, pero es útil tener unos cuantos rasgos de
conversión de tipos en tu caja de herramientas.

[display-trait]: https://doc.rust-lang.org/std/fmt/trait.Display.html
