`String` y `&str` son dos formas fundamentales de trabajar con datos textuales en Rust.

`String` es un vector de bytes `u8` con propiedad y es mutable.
`&str` es una referencia prestada a un segmento de `String` y, por tanto, inmutable.

También puedes crear y modificar `String` usando uno de sus muchos métodos, como `push`.
```rust
let mut a_string = String::from("hello");
a_string.push('!');
```

También puedes crear un `String` convirtiendo un `&str`:
```rust
let a_string = "hello".to_string();
```
