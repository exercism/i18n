# Anexo a las instrucciones

## Implementación

Hay muchas formas de resolver este ejercicio, pero hemos proporcionado algunos esqueletos adicionales para quienes quieran practicar escribiendo sus propios [manejadores de habilidades][ability-handler-docs].

La firma de la función auxiliar `checkBalance` que se proporciona para este ejercicio hace uso de un requisito de habilidad, `{Stack}`.
¡La habilidad `Stack` está definida para ti, pero el manejador, `Stack.run`, no lo está!
Si lo deseas, puedes implementar las funciones `Stack.run`, `checkBalance` e `isPaired`.
Los tests se ejecutarán aunque decidas no implementar este ejercicio con habilidades.

[ability-handler-docs]: https://www.unison-lang.org/learn/fundamentals/abilities/writing-abilities/
