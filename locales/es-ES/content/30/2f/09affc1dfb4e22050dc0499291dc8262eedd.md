# Acerca de

`assocs` es un [protocolo][assoc-protocol], no un único tipo de datos. Las tablas hash (`H{ }`), las listas de asociación (secuencias de pares `{ key value }`) y los mapas de árbol lo implementan, y la mayoría de las words de `assocs` son intercambiables entre ellos.

```factor
USING: assocs ;

H{ } clone "coal" over inc-at
"coal" over inc-at
"wood" over inc-at      ! => H{ { "coal" 2 } { "wood" 1 } }
```

La superficie completa es amplia (iteración ordenada, mapeo, filtrado), pero la mayor parte del trabajo a nivel de ejercicio gira en torno a un conjunto reducido:

| word        | efecto                                        |
|-------------|-----------------------------------------------|
| `at`        | `( key assoc -- value/f )`                    |
| `at*`       | `( key assoc -- value ? )` distingue f-como-valor de ausente |
| `key?`      | `( key assoc -- ? )`                          |
| `set-at`    | `( value key assoc -- )` — modifica           |
| `change-at` | `( key assoc quot -- )` — `quot` es `( old -- new )` |
| `inc-at`    | `( key assoc -- )` — `+1`, inserta `1` si no existe |
| `delete-at` | `( key assoc -- )` — modifica                 |
| `>alist`    | `( assoc -- pairs )`                          |

`sort-keys` y `sort-values` (en `sorting`) ordenan un alist según el campo elegido.

[assoc-protocol]: https://docs.factorcode.org/content/article-assocs-protocol.html
