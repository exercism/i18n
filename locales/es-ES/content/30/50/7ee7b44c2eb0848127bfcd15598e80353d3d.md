# Anexo a las instrucciones

## Pistas

Para completar este ejercicio tienes que implementar la función `score`,
que recibe una secuencia de *tiradas* de bolos y devuelve la puntuación final o
el error correspondiente:

```haskell
score :: [Int] -> Either BowlingError Int

data BowlingError = IncompleteGame
                  | InvalidRoll { rollIndex :: Int, rollValue :: Int }
                  deriving (Eq, Show)
```

Encontrarás estas definiciones ya puestas, pero eres tú quien debe
definir la función.

Ten en cuenta que el conjunto de pruebas espera que las tiradas estén
numeradas empezando por cero.
