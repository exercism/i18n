# Instrucciones

Tu tarea consiste en construir un cronómetro que lleve un registro preciso de los tiempos de vuelta.

El cronómetro usa cuatro comandos (start, stop, lap y reset) para llevar la cuenta de:

1. El tiempo registrado de la vuelta actual
2. Los tiempos de vuelta registrados previamente

Los comandos que se pueden usar dependen del estado en el que esté el cronómetro:

1. Preparado: estado inicial
2. En marcha: registrando el tiempo
3. Parado: sin registrar el tiempo

| Comando | Estado inicial | Estado final | Efecto                                                   |
| ------- | -------------- | ------------ | -------------------------------------------------------- |
| Start   | Preparado      | En marcha    | Empezar a registrar el tiempo                            |
| Start   | Parado         | En marcha    | Reanudar el registro del tiempo                          |
| Stop    | En marcha      | Parado       | Detener el registro del tiempo                           |
| Lap     | En marcha      | En marcha    | Añadir la vuelta actual a las anteriores y, después, reiniciar la vuelta actual |
| Reset   | Parado         | Preparado    | Reiniciar la vuelta actual y borrar las vueltas anteriores |
