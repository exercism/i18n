# Acerca de

Los inicializadores de objetos son una alternativa a los constructores. La sintaxis es una lista separada por comas de pares nombre=valor de campo, como se ilustra a continuación:

```csharp
public class Person
{
    public string Name;
    public string Address;
}

var person = new Person{Name="The President", Address = "Élysée Palace"};
```

Las colecciones también se pueden inicializar de esta manera. Normalmente, esto se consigue con listas separadas por comas, como se muestra aquí:

```csharp
IList<Person> people = new List<Person>{ new Person(), new Person{Name="Joe Shmo"}};
```

Este enfoque (y esta sintaxis) se puede usar con cualquier clase que implemente `IEnumerable` y tenga un método `Add()`.

Los campos se pueden enumerar en cualquier orden u omitirse por completo.

Los diccionarios usan la siguiente sintaxis:

```csharp
IDictionary<int, string> numbers = new Dictionary<int, string>{ [0] = "zero", [1] = "one"...};

// or

IDictionary<int, string> numbers = new Dictionary<int, string>{ {0, "zero" }, {1,  "one"}...};
```

Los campos inicializados deben ser accesibles para quien llama. Normalmente, esto significa que deben ser `public` o `internal`.

Existe una fuerte tendencia a promover la inmutabilidad entre los diseñadores del lenguaje y los desarrolladores destacados, por lo que la mutabilidad de los objetos inicializados de esta manera se considera una desventaja. Hay propuestas para introducir una cláusula `init` en la próxima versión del lenguaje, C# 9, que podría abordar esto.

- [documentación sobre inicializadores de objetos][object-initializers] describe cómo usar los inicializadores.
- [documentación sobre inicializadores de colecciones][collection-initializers] ofrece una vista previa de cómo se pueden usar los inicializadores con colecciones como diccionarios y listas.
