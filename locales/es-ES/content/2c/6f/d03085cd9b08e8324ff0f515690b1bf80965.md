# Instrucciones adicionales

## Instrucciones específicas del track

Tu tarea es escribir una función `nucleotideCounts` que recibe como entrada un string y devuelve como salida un array asociativo que cuenta cuántas veces aparece cada nucleótido.
Si el string es una secuencia no válida, la función debe lanzar un `IllegalArgumentError` con el mensaje `Invalid nucleotide in strand`.
