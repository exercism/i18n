# Instrucciones

En este ejercicio, tienes que implementar algunas reglas del clásico juego Pac-Man.

Tienes cuatro reglas que implementar, todas relacionadas con los estados del juego.

## 1. Define si Pac-Man se come un fantasma

Implementa una función que recibe como entrada si Pac-Man tiene una píldora de energía activa y si Pac-Man está tocando un fantasma, y devuelve un valor booleano que indica si Pac-Man es capaz de comerse un fantasma. La función debe devolver `true` solo si Pac-Man tiene una píldora de energía activa y está tocando un fantasma.

```lua
rules.eat_ghost(false, true)
-- => false
```

## 2. Define si Pac-Man puntúa

Implementa una función que recibe como entrada si Pac-Man está tocando una píldora de energía y si Pac-Man está tocando un punto, y devuelve un valor booleano que indica si Pac-Man ha puntuado. La función debe devolver `true` si Pac-Man está tocando una píldora de energía o un punto.

```lua
rules.score(true, true)
-- => true
```

## 3. Define si Pac-Man pierde

Implementa una función que recibe como entrada si Pac-Man tiene una píldora de energía activa y si Pac-Man está tocando un fantasma, y devuelve un valor booleano que indica si Pac-Man pierde. La función debe devolver `true` si Pac-Man está tocando un fantasma y no tiene una píldora de energía activa.

```lua
rules.lose(false, true)
-- => true
```

## 4. Define si Pac-Man gana

Implementa una función que recibe como entrada si Pac-Man se ha comido todos los puntos, si Pac-Man tiene una píldora de energía activa y si Pac-Man está tocando un fantasma, y devuelve un valor booleano que indica si Pac-Man gana. La función debe devolver `true` si Pac-Man se ha comido todos los puntos y no ha perdido según los argumentos definidos en la parte 3.

```lua
rules.win(false, true, false)
-- => false
```
