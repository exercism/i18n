# Tareas

Las tareas son issues de GitHub en los que nos gustaría que la gente colaborara, desde corregir textos hasta crear ejercicios de concepto.
Se muestran en el sitio web y enlazan con los issues correspondientes en GitHub.
Cada tarea lleva una o varias propiedades, que se rellenan a partir de las etiquetas del issue.
Así, el usuario puede filtrar las tareas según sus propiedades.

## Etiquetas

Para que un issue se considere una tarea, tiene que estar etiquetado con una o más etiquetas específicas de tareas.
De este modo, los mantenedores pueden elegir que solo algunos issues aparezcan como tareas.

Cada etiqueta de tarea se define como `x:<type>/<value>`, y se admiten cinco tipos de tarea:

- `action`
- `knowledge`
- `module`
- `size`
- `type`

### Etiqueta de acción

Las etiquetas `x:action/<value>` describen en qué tipo de trabajo participará el colaborador al trabajar en el issue.

| Etiqueta             | Descripción                            |
| -------------------- | -------------------------------------- |
| `x:action/create`    | Trabajar en algo desde cero            |
| `x:action/fix`       | Arreglar un issue                      |
| `x:action/improve`   | Mejorar funcionalidades o contenido ya existentes |
| `x:action/proofread` | Corregir textos                        |
| `x:action/sync`      | Sincronizar el contenido con su última versión |

### Etiqueta de conocimiento

Las etiquetas `x:knowledge/<value>` describen cuánto conocimiento de Exercism necesita el colaborador.

| Etiqueta                   | Descripción                                |
| -------------------------- | ------------------------------------------ |
| `x:knowledge/none`         | No se necesita ningún conocimiento previo de Exercism    |
| `x:knowledge/elementary`   | Se necesita poco conocimiento de Exercism  |
| `x:knowledge/intermediate` | Se necesita bastante conocimiento de Exercism |
| `x:knowledge/advanced`     | Se necesita un conocimiento amplio de Exercism  |

### Etiqueta de módulo

Las etiquetas `x:module/<value>` indican en qué parte de Exercism trabajará el colaborador.

| Etiqueta                     | Descripción                 |
| ---------------------------- | --------------------------- |
| `x:module/analyzer`          | Trabajar en los analizadores           |
| `x:module/concept`           | Trabajar en los conceptos            |
| `x:module/concept-exercise`  | Trabajar en los ejercicios de concepto   |
| `x:module/generator`         | Trabajar en los generadores de ejercicios |
| `x:module/practice-exercise` | Trabajar en los ejercicios de práctica  |
| `x:module/representer`       | Trabajar en los representadores        |
| `x:module/test-runner`       | Trabajar en los ejecutores de tests        |

### Etiqueta de tamaño

Las etiquetas `x:size/<value>` describen la cantidad de trabajo que se espera de un colaborador.

| Etiqueta         | Descripción            |
| ---------------- | ---------------------- |
| `x:size/tiny`    | Trabajo mínimo    |
| `x:size/small`   | Trabajo pequeño   |
| `x:size/medium`  | Trabajo medio  |
| `x:size/large`   | Trabajo grande   |
| `x:size/massive` | Trabajo enorme |

### Etiqueta de tipo

Las etiquetas `x:type/<value>` describen el tipo de trabajo en el que participará el colaborador.

| Etiqueta         | Descripción                                                                                                                                                                                                    |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `x:type/ci`      | Trabajar en integración continua (por ejemplo, flujos de trabajo de GitHub Actions)                                                                                                                                                 |
| `x:type/coding`  | Escribir código que no forma parte del contenido dirigido a los estudiantes. Normalmente son tareas relacionadas con las herramientas de producción (por ejemplo, los ejecutores de tests), las herramientas internas (generadores) o las bibliotecas que mantiene Exercism. |
| `x:type/content` | Trabajar en contenido (por ejemplo, ejercicios, conceptos)                                                                                                                                                                     |
| `x:type/docker`  | Trabajar en Dockerfiles                                                                                                                                                                                            |
| `x:type/docs`    | Trabajar en la documentación                                                                                                                                                                                          |

## Etiquetas reclamadas y no reclamadas

Para ocultar una tarea porque alguien ya está trabajando en ella, un issue puede añadir la etiqueta `x:status/claimed`.
