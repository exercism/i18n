# Instalación

Hay [binarios de Uiua precompilados][releases] disponibles, así que no es necesario compilar.
Consulta la [guía de instalación oficial][install-guide] para ver las instrucciones más recientes, incluidas la integración con el IDE y las fuentes.

```exercism/note
Actualmente, nuestro test-runner en línea usa la versión `0.18.1`.
Con el rápido ritmo de desarrollo de Uiua, eso podría cambiar, así que tenlo en cuenta si no consigues reproducir los resultados de las pruebas de la web.
```

Una vez lo hayas descargado en la ubicación que quieras, tendrás que añadir Uiua al PATH de tu sistema.

- **macOS:** Abre `Applications > Utilities > Terminal` con Finder. Introduce `export PATH="/path/to/uiua:$PATH"` para poder ejecutar Uiua desde cualquier ubicación.

- **Windows:** Abre «Edit Environment Variables» desde el menú Inicio. En «Path», añade tu carpeta de Uiua.

- **Linux:** Abre el Terminal y añade `export PATH="/path/to/uiua:$PATH"` a `~/.bashrc` o `~/.profile` para acceder a él fácilmente.

[releases]: https://github.com/uiua-lang/uiua/releases
[install-guide]: https://www.uiua.org/docs/install#basic
