# Anexo de instrucciones

## Pistas

Para que el reto tenga el nivel adecuado, deberías usar únicamente la funcionalidad que ofrece Prelude. Intenta no usar Data.List, Data.Char, Data.Bits ni Numeric.

Intenta usar seq, $! o BangPatterns de forma adecuada para que la solución sea eficiente.

No es necesario gestionar entradas no válidas.
