# Pistas

## General

- Las [tuplas](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples) son agrupaciones inmutables de valores sin nombre pero ordenados, posiblemente de tipos distintos.
- Los elementos de una tupla se pueden [obtener](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/tuples#obtaining-individual-values) mediante la coincidencia de patrones, la deconstrucción de tuplas o el uso de funciones auxiliares.
