# Instrucciones

En este ejercicio vas a escribir código para procesar un array de lenguajes de programación que tienes pensado practicar en la plataforma Exercism.

Tienes seis tareas.

## 1. Crear un array nuevo

Antes de poder añadir lenguajes, tendrás que empezar creando un array nuevo. Define una función que devuelva un array vacío.

```clojure
(new-list)
;; => ()
```

## 2. Añadir un lenguaje nuevo al array

A medida que explores Exercism y encuentres lenguajes que quieras aprender, necesitarás poder añadirlos a tu array. Define una función para añadir un lenguaje nuevo al principio de tu array.

```clojure
(add-language "JavaScript" '("Clojurescript"))
;; => '("JavaScript" "Clojurescript")
```

## 3. Comprobar el último lenguaje añadido

Querrás comprobar rápidamente qué lenguaje acabas de añadir. Define una función que devuelva el primer lenguaje de tu array.

```clojure
(first-language '("Haskell" "Python"))
;; => "Haskell"
```

## 4. Eliminar el primer lenguaje del array

A veces cambiarás de opinión sobre un lenguaje que acabas de añadir. Define una función para eliminar el primer lenguaje de tu array.

```clojure
(remove-language '("Common Lisp" "Racket" "Scheme"))
;; => '("Racket" "Scheme")
```

## 5. Contar los lenguajes del array

Contar los lenguajes uno a uno es incómodo. Define una función que cuente el número de lenguajes de tu array.

```clojure
(count-languages '("C#" "Racket" "Rust" "Ruby"))
;; => 4
```

## 6. Unirlo todo

Define una función `learning-list`, dentro de la cual usarás algunas de las funciones que has definido antes.

- Crea un array vacío.
- Añade 2 lenguajes de programación nuevos al array.

  - «Clojure»
  - «Lisp»

- Elimina «Lisp» del array, ya que puede que no tengas tiempo suficiente para el año, y es bastante similar a Clojure.
- Añade 2 lenguajes de programación más al array.

  - «Java»
  - «JavaScript»

- Devuelve el número total de lenguajes. Pista: debería ser 3.

```clojure
(learning-list)
;; => 3
```
