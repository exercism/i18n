# Booleanos

Crystal tiene un tipo conocido como [`Bool`][bools].
Representa los valores `true` y `false`.

## Operadores lógicos

Crystal tiene tres operadores lógicos (`!`, `||`, `&&`), que combinan valores booleanos y forman expresiones que producen valores diferentes.

### And (`&&`)

El [operador _and_][and] en Crystal se representa con `&&` y devuelve `true` si ambos valores son `true`; en caso contrario, devuelve `false`.
Al usar el operador _and_, se coloca un valor booleano a la derecha de `&&` y otro a la izquierda.

```crystal
true && true
# => true

true && false
# => false
```

### Or (`||`)

El [operador _or_][or] en Crystal se representa con `||` y devuelve `true` si **al menos uno** de los valores dados es `true`.
Si ambos valores son `false`, devuelve `false`.
Al usar el operador _or_, se coloca un valor booleano a la derecha de `||` y otro a la izquierda.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not (`!`)

El operador _not_ en Crystal se representa con `!` y devuelve `true` si el valor booleano dado es `false`, y devuelve `false` si se le proporciona `true`.
Al usar el operador _not_, se coloca un valor booleano después del operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Uso de los paréntesis (`()`)

Cuando trabajas con valores booleanos, puedes usar paréntesis para decidir qué valores se evalúan primero.
El resultado puede variar según cómo se usen los paréntesis.
En Crystal, lo que está entre paréntesis se evalúa primero.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como lo que está entre paréntesis se evalúa primero, en el siguiente ejemplo el operador _not_ se aplicará a la expresión que hay dentro de los paréntesis.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Solo deberías usar paréntesis cuando afecten al resultado; de lo contrario, es mejor omitirlos.
~~~~
