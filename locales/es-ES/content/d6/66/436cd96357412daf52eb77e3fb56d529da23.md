# Introducción

El módulo `Time` se usa para mostrar fechas y horas legibles para las personas.
Aunque técnicamente es posible manipular fechas y horas con `Time`, hay paquetes de la comunidad de Elm mucho más adecuados para esa tarea, como [`justinmimbs/date`][date] o [`CoderDennis/elm-time-format`][elm-time-format].

## Posix

Las fechas y horas se representan con el tipo opaco `Posix`, que envuelve el tiempo de la época Unix, el número de milisegundos transcurridos desde el 1 de enero de 1970 a medianoche UTC.
Un `Posix` es un valor no ambiguo que no varía entre zonas horarias, por lo que es una buena opción para guardar el tiempo.
En una aplicación Elm, lo habitual es que las fechas y horas `Posix` las proporcionen fuentes externas, como el navegador.

Es posible transformar un `Posix` en un número de milisegundos y viceversa con las siguientes funciones:

```elm
posixToMillis : Posix -> Int
millisToPosix : Int -> Posix
```

## Zonas horarias

En nuestro día a día, los humanos normalmente no leemos `Posix` y preferimos la hora local, que depende de nuestra ubicación en la Tierra y de las reglas locales de horario de verano.
En Elm, esta información se codifica en el tipo opaco `Zone`, que normalmente proporciona el navegador.

Hay una `Zone` especial que siempre está accesible:

```elm
utc : Zone
```

## Fechas y horas legibles

Con un `Posix` y una `Zone`, tenemos suficiente información para mostrar la hora local con cualquier nivel de detalle.
Aquí tienes una lista de las funciones que se pueden usar para ello:

```elm
toYear : Zone -> Posix -> Int
toMonth : Zone -> Posix -> Month
toDay : Zone -> Posix -> Int
toWeekday : Zone -> Posix -> Weekday
toHour : Zone -> Posix -> Int
toMinute : Zone -> Posix -> Int
toSecond : Zone -> Posix -> Int
toMillis : Zone -> Posix -> Int
```

Habrás visto otros dos tipos personalizados de `Time`:

```elm
type Month = Jan | Feb | Mar | Apr | May | Jun | Jul | Aug | Sep | Oct | Nov | Dec
type Weekday = Mon | Tue | Wed | Thu | Fri | Sat | Sun
```

Convertir estos tipos personalizados en valores legibles para las personas corresponde a quien los use.
