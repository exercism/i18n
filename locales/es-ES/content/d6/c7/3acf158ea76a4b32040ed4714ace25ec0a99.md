# Anexo de las instrucciones

## Palabras

Define una tupla `linked-list-node`.

Define una tupla `linked-list` y proporciona un método `M: linked-list length` (de `sequences`) para que las pruebas puedan llamar a `length` directamente sobre tu lista.

- `<linked-list> ( -- linked-list )`: construye una lista vacía.
- `>linked-list ( seq -- linked-list )`: introduce cada elemento de `seq` en una lista nueva, en orden.
- `linked-list>array ( linked-list -- array )`: devuelve los valores, empezando por el que está arriba de la lista.
- `list-push ( linked-list value -- linked-list )`: introduce un valor en la parte superior.
- `list-pop ( linked-list -- linked-list value )`: elimina y devuelve el valor de la parte superior.
- `list-peek ( linked-list -- value )`: devuelve el valor de la parte superior sin eliminarlo.
- `list-reverse ( linked-list -- linked-list )`: devuelve una lista con los elementos en orden inverso.

Lanza una clase de error `list-empty` desde `list-pop` y `list-peek` cuando la lista esté vacía.
