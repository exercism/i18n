# Acerca de las funciones anónimas y los closures

PHP permite declarar funciones dentro de otras funciones. Estas funciones no necesitan tener un nombre, pero se pueden asignar a variables o incluso pasarlas directamente a otra función que espere una función como parámetro.

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, function($num) {
        return $num % 2 === 1;
    });
}
```

La función definida y pasada a `array_filter` más arriba es una función anónima. La función `array_filter` la usa para determinar si un valor concreto de un array se devolverá en el resultado de `array_filter`. Si la función devuelve `true` para un valor, este se incluirá en el array resultante.

Las funciones anónimas también se pueden usar para hacer referencia, desde dentro de la función, a variables que están en el scope de fuera de la función. Esto se conoce como que el scope de la función se «cierra» sobre la variable que se usa en la función, de ahí el nombre «closure». En algunos lenguajes, todas las variables que están en el scope se pueden usar automáticamente dentro del closure. En PHP, `$this`, que hace referencia al objeto actual, se permite automáticamente dentro del closure. Todas las demás variables deben referenciarse explícitamente con la palabra clave `use`.

```php
function makeAdderFunction(int $number) {
    return function(int $x) use($number) {
        return $x + $number;
    }
}

$add5 = makeAdderFunction(5);
echo $add5(4); // echos 9
```

En la función `makeAdderFunction` de arriba, el valor de `$number` que se pasa se «cierra» dentro de la función anónima definida internamente, que después se devuelve. Así, cada vez que se ejecuta esa función, conoce el valor de `$number` que se pasó. Si volvieras a llamar a esta función con otro número, devolvería una función completamente distinta. No cambiaría los valores ni la funcionalidad que devuelve la primera llamada a la función.
Si necesitas cerrar sobre más de una variable, puedes añadirlas a la palabra clave `use` separadas por comas.

PHP también tiene una sintaxis de función más corta llamada `arrow functions`. Deben ser bastante simples. Su forma básica es:

```php
fn(arguments) => expression
```

Con este estilo de función, no necesitas usar `use`. Cerrará y capturará automáticamente cualquier valor que esté en el scope padre. La expresión de estas arrow functions se devuelve automáticamente sin necesidad de usar la palabra clave `return`. Eso nos permitiría reescribir la función `onlyOdds` de arriba así:

```php
function onlyOdds(array $numbers): array
{
    return array_filter($numbers, fn($n) => $n % 2 == 1);
}
```

La `makeAdderFunction` de arriba se podría reescribir así:

```php
function makeAdderFunction(int $number) {
    return fn(int $x) => $x + $number;
}
```

**Nota:** Si la función no se puede escribir como una expresión, no se puede usar la sintaxis abreviada de las arrow functions.

Las variables se pasan a las funciones anónimas y a los closures, y se usan dentro de ellos, por valor. Esto significa que si cambias el valor de la variable dentro de la función, no afectará al valor de la variable fuera de la función. Si necesitas que el valor se modifique, puedes pasarlo por referencia.

```php
function positiveAverage(array $numbers): float
{
    $total = 0;
    $count = 0;
    return array_walk(
      $numbers,
      function($num) use (&$count, &$total) {
          $total += abs($num);
          $count++;
      }
    );
    return $total / $count;
}
```

En el ejemplo de arriba, `array_walk` itera sobre cada elemento del array y envía cada valor a la función declarada en la llamada. Mantiene un total acumulado en `$total`, donde cada valor sumado es el valor absoluto del número. También lleva la cuenta de cuántos números había. Ambos valores se usan en el closure por referencia, lo que se indica con el `&` delante de cada variable dentro de la sección `use`. Esto significa que los cambios que sufran las variables seguirán vigentes cuando `array_walk` termine, de modo que la función pueda devolver la media de los valores absolutos de los números del array.

Las funciones anónimas y los closures son una forma cómoda de definir una función que quizá solo se necesite en un contexto concreto, o de definir una función que devuelve una función dinámica a partir de un conjunto de parámetros que se conocen en un momento distinto al de su uso real.
