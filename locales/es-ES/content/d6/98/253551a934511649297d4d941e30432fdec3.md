# Introducción

Una [`function`][function] es una forma de compartimentar el código para poder llamarla por su nombre desde uno o varios lugares del programa.
Las funciones se usan para realizar tareas concretas y repetitivas.

Más formalmente: una función es cualquier objeto de Python al que se puede aplicar la operación de [`function call`][calls].
Una función puede usarse para [`return`][return] uno o varios valores como resultado de una o varias operaciones, o puede usarse para uno o varios [`side effects`][side effects].
Si una función no especifica un valor devuelto, seguirá devolviendo `None`.

A continuación, un ejemplo de una función con un efecto secundario:

```python
>>> def hello():
...     print("Hello")
...
>>> hello()
Hello

```

En el ejemplo anterior, la palabra clave [`def`][def] se usa para señalar el comienzo de la definición de la función.
`hello` es el nombre de la función.
Los paréntesis vacíos indican que no se pasa ningún valor a la función.
El cuerpo de la función es la única instrucción `print("Hello")`.
`print` también es una función.
El `"Hello"` que aparece entre los paréntesis de la función `print` se conoce como un [`argument`][arguments].
La función `print` usa el argumento para saber qué imprimir.
Fíjate en que el cuerpo de la función está indentado.
La indentación es importante porque Python se basa en ella para saber dónde termina ese bloque de código.
El cuerpo de la función termina al final del programa o justo antes de la siguiente línea de código que _no_ esté indentada.
Como `hello()` no especifica un valor `return`, ejecuta su efecto secundario (que es llamar a `print()`) y luego devuelve `None`.
Por último, llamamos a la función usando su nombre y los paréntesis, lo que indica al intérprete de Python que ese es un nombre _invocable_.

A continuación, un ejemplo de una función con un valor devuelto:

```python
>>> def hello():
...     return "Hello"
... 
print(hello())
Hello

```

El cuerpo de esta función ha cambiado: en lugar de _llamar_ a `print`, ahora _devuelve_ el `string` "Hello".
Al final, el código sigue imprimiendo `"Hello"`, pero el efecto secundario tiene lugar en el _código que hace la llamada_ en lugar de en la función `hello`.
Si se omiten los paréntesis al llamar a la función `hello` (por ejemplo, `print(hello)`), `print` mostraría algo como

```
<function hello at 0x0000026E18E93E20>
```

Es importante que, aunque una función no acepte argumentos (_es decir, no tenga parámetros_), haya que usar los paréntesis vacíos para _llamarla_ correctamente.
Esto es distinto de un lenguaje como Ruby, que no requiere paréntesis vacíos para llamar a una función sin argumentos.

Una función puede definir cero o más [`parameters`][parameters]. Un parámetro define qué argumento(s) acepta la función.

A continuación, un ejemplo de una función que acepta un argumento:

```python
>>> def hello(name):
...     return f"Hello, {name}"
... 
>>> print(hello("Bob"))
Hello, Bob

```

El parámetro se define como `name`.
`"Bob"` es el argumento que el programa pasa a la función `hello`.
La función _devuelve_ el `string` "Hello, Bob".

¿Y si alguien llama a `hello` sin pasar un argumento?
El programa lanza un error:

```python
print(hello())
Traceback (most recent call last):

  Input In in <line: 1>
    print(hello())

TypeError: hello() missing 1 required positional argument: 'name'
```

Si no queremos que el programa dé error cuando no se pasa ningún argumento (_pero queremos permitir que el código que hace la llamada no lo proporcione_), podemos definir un [argumento predeterminado][default arguments].
Un argumento predeterminado define qué valor usar si falta el argumento cuando se llama a la función.

A continuación, un ejemplo de una función con un argumento predeterminado:

```python
>>> def hello(name="you"):
...     return f"Hello, {name}"
... 
>>> print(hello())
Hello, you

```

Al parámetro `name` se le da el argumento predeterminado `"you"`, así que el programa muestra `Hello, you` si no se le pasa un argumento `name`.

Para obtener más información sobre los argumentos de función, consulta el concepto [argumentos de función][function arguments].
