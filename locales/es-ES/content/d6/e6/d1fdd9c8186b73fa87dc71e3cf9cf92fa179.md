# Instrucciones

Estás escribiendo el núcleo digital de una pequeña mesa de mezclas en un estudio de grabación.

El sonido llega como un flujo de muestras.
Cada muestra es un número que describe la posición del cono de un altavoz en un instante.
Una mesa procesa un bloque completo de muestras a la vez, aplicando la misma operación a cada una.

Tienes cinco tareas, y cada una opera sobre un bloque de muestras que está en memoria.
Recibes los operandos a través de direcciones de memoria y escribes tu respuesta en una dirección de resultado.

~~~~exercism/note
Los cálculos de este ejercicio deben realizarse con instrucciones SIMD, no con operaciones escalares.
~~~~

## 1. Mezclar dos pistas

A veces, el estudio graba los instrumentos en pistas diferentes.
Para reproducirlos por los mismos altavoces, sumas las dos pistas en una sola.

Implementa la función `mix_tracks`, que suma dos pistas, muestra a muestra.
Cada pista es un bloque de 8 muestras de 16 bits con signo.
Una suma que desborde el rango de 16 bits con signo debe saturarse en lugar de dar la vuelta.

Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes de un búfer donde se escriben las 8 muestras mezcladas.
- `track_a`: dirección de memoria alineada a 16 bytes de la primera pista, con 8 muestras de 16 bits con signo.
- `track_b`: dirección de memoria alineada a 16 bytes de la segunda pista, con 8 muestras de 16 bits con signo.

```c
track_a = {10000, 30000, 20000, -30000, -20000, -100,  100, 0}
track_b = { 5000,  5000, 20000,  -5000, -20000,  100, -100, 0}
result  = {15000, 32767, 32767, -32768, -32768,    0,    0, 0}
```

Esta función no devuelve ningún valor.

## 2. Eliminar el sangrado

Cuando dos micrófonos graban a la vez, cada uno capta una copia tenue de la fuente del otro.
Esta copia no deseada se llama _sangrado_.
Una vez medido este sangrado, hay que restarlo para limpiar la pista.

Implementa la función `remove_bleed`, que resta el bloque de sangrado del bloque de la pista, muestra a muestra.
Cada bloque tiene 8 muestras de 16 bits con signo, y la resta debe saturarse.

Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria donde se escriben las 8 muestras limpias (no se garantiza la alineación).
- `track`: dirección de memoria alineada a 16 bytes de la pista grabada, 8 muestras de 16 bits con signo.
- `bleed`: dirección de memoria del sangrado que hay que eliminar, 8 muestras de 16 bits con signo (no se garantiza la alineación).

```c
track  = {10000, -30000, 5000, 32767, 0,  200, -200, 15000}
bleed  = { 2000,   5000, 5000,    -5, 0,  300,  300,  5000}
result = { 8000, -32768,    0, 32767, 0, -100, -500, 10000}
```

Esta función no devuelve ningún valor.

## 3. Combinar los medidores

Sobre cada canal hay un medidor de nivel, una pequeña barra cuyo brillo indica lo fuerte que suena ese canal.
El panel frontal tiene un medidor maestro que debe brillar tanto como los dos canales combinados.
Sumas los dos bloques de medidores para hacerlo funcionar.

Ten en cuenta que un medidor brillante se queda al máximo brillo en lugar de volver a apagarse, así que la suma es saturante.

Implementa la función `combine_meters`, que suma dos bloques de medidores muestra a muestra.
Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben los 16 valores combinados.
- `meter_a`: dirección de memoria alineada a 16 bytes del bloque de medidores del primer canal, con 16 valores de 8 bits sin signo empaquetados.
- `meter_b`: dirección de memoria alineada a 16 bytes del bloque de medidores del segundo canal, con 16 valores de 8 bits sin signo empaquetados.

Cada bloque tiene 16 valores de 8 bits sin signo.
Hay que sumarlos, saturando al rango sin signo.

```c
meter_a = {200, 100,  50, 255, 0, 128, 10, 240, 1, 2, 3, 4, 5, 6, 7, 8}
meter_b = {100, 100, 200,   1, 0, 128, 10,  20, 1, 2, 3, 4, 5, 6, 7, 8}
result  = {255, 200, 250, 255, 0, 255, 20, 255, 2, 4, 6, 8, 10, 12, 14, 16}
```

Esta función no devuelve ningún valor.

## 4. Aplicar un fundido

La canción no debe parar de golpe, sino que debe hacer un fundido de salida al final.
Tienes un bloque de _coeficientes de ganancia_, uno por muestra, que van disminuyendo cada vez más.

Cada coeficiente es una fracción expresada sobre `65536`.
Por ejemplo, si una muestra tiene un valor de `16384`, en realidad expresa `16384 / 65536`, que es `1 / 4`.
El valor más grande que se puede usar, `32767`, es justo un poco menos de la mitad.

Como `65536` es `2^16`, multiplicar una muestra por su coeficiente y quedarse con la _mitad alta_ del producto da `sample * gain / 65536`.

Implementa la función `apply_fade`, que escala cada muestra según su coeficiente.
Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben todas las muestras escaladas.
- `track`: dirección de memoria alineada a 16 bytes de la pista, con `n` muestras de 16 bits con signo.
- `gains`: dirección de memoria alineada a 16 bytes de los coeficientes de ganancia, con `n` valores de 16 bits con signo, cada uno en el rango de `0` a `32767`.
- `n`: el número de muestras, que nunca es cero y siempre es múltiplo de `8`, como un entero de 64 bits sin signo.

Ten en cuenta que la pista es un array que contiene `n` muestras de 16 bits con signo, donde `n` nunca es cero y siempre es múltiplo de `8`.
Para cada muestra, el resultado escalado son los 16 bits _altos_ del producto con signo: `sample * gain`.

```c
track  = {20000, 20000, 20000, 20000, -20000, -20000, -20000, -20000}
gains  = {32767, 24576, 16384,  8192,  32767,  24576,  16384,   8192}
result = { 9999,  7500,  5000,  2500, -10000,  -7500,  -5000,  -2500}
```

~~~~exercism/note
Quedarse con la mitad alta redondea hacia menos infinito.
Por eso `20000 * 32767` se escala a `9999`, mientras que `-20000 * 32767` se escala a `-10000` en lugar de a `-9999`.
~~~~

Esta función no devuelve ningún valor.

## 5. Atenuar una pista

El batería se grabó demasiado alto.
Para bajar toda la pista, divides cada muestra entre una constante.

Implementa la función `attenuate_track`.
Esta función recibe como argumentos, en este orden:

- `result`: dirección de memoria alineada a 16 bytes donde se escriben los resultados, como enteros de 32 bits con signo.
- `samples`: dirección de memoria alineada a 16 bytes de las muestras, `n` valores de 16 bits con signo.
- `divisor`: dirección de memoria alineada a 16 bytes de 4 copias idénticas del divisor, como enteros de 32 bits.
- `n`: el número de muestras, que nunca es cero y siempre es múltiplo de `4`, como un entero de 64 bits sin signo.

Ten en cuenta que `samples` es un array que contiene `n` muestras de 16 bits con signo, donde `n` nunca es cero y siempre es múltiplo de `4`.

El divisor se proporciona como `4` copias del mismo entero de 32 bits, ya replicadas para que pueda llenar los cuatro carriles a la vez.

El SIMD de enteros no tiene división empaquetada, así que el trabajo se hace en coma flotante empaquetada y luego se convierte de nuevo a enteros de 32 bits empaquetados para guardarlos en `result`.
Convierte de vuelta truncando hacia cero, de modo que un cociente de `2.3` se convierte en `2` y `-2.3` en `-2`.

```c
samples = {300, 150, 90, -120, 100, 50, -50, 7}
divisor = {3, 3, 3, 3}
result  = {100,  50, 30,  -40,  33, 16, -16, 2}
```

Esta función no devuelve ningún valor.
