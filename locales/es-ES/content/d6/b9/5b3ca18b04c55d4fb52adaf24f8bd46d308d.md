# Instrucciones

En este ejercicio, vas a escribir código para ayudar a una persona freelance a comunicarse con la persona que gestiona un proyecto.
Tu tarea consiste en crear unas cuantas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos unas cuantas reglas entre la persona freelance y la persona que gestiona el proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

En ocasiones, la persona freelance ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más fieles o para clientes sin ánimo de lucro).

Los descuentos se modelan como números decimales que representan porcentajes, por ejemplo, `25.0` (25 %).

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función llamada `daily_rate` que calcule la tarifa diaria a partir de una tarifa por hora que se pasa como parámetro.
El contrato establece que un día tiene 8 horas facturables.

```cpp
daily_rate(60)
// => 480.0
```

La tarifa diaria devuelta debe ser de tipo `double`.

## 2. Calcula un precio con descuento

Implementa una función `apply_discount` que calcule el precio después de aplicar un descuento.
Debe aceptar dos parámetros: el precio original y el porcentaje de descuento.

```cpp
apply_discount(150, 10)
// => 135.0
```

El valor devuelto debe ser siempre de tipo `double`, sin redondear de ninguna manera.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función `monthly_rate` que calcule la tarifa mensual con el descuento aplicado.
Debe tener dos parámetros: una tarifa por hora y el porcentaje de descuento.

```cpp
monthly_rate(77, 10.5)
// => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al número entero más próximo.

## 4. Calcula el número de días de trabajo completos a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función `days_in_budget` que reciba un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días completos de trabajo cubre.

```cpp
days_in_budget(20'000, 80, 11.0)
// => 35
```

El número de días devuelto debe redondearse hacia abajo (tomar el suelo) al número entero inferior.
