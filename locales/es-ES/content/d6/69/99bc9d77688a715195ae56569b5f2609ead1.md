# Pruebas

Antes de intentar ejecutar las pruebas, asegúrate de que la carpeta del ejercicio esté configurada correctamente siguiendo los pasos de instalación, concretamente `corepack yarn install` y la configuración del Editor SDK.

Ejecuta las pruebas con:

```bash
$ corepack yarn test
```

Asegúrate de que tu código sigue las buenas prácticas, como hacen otros usuarios, con eslint, una herramienta que realiza un análisis estático de tu código.
Herramientas como esta te ahorran algo de tiempo al detectar errores tipográficos o descuidos tontos en tu código:

```bash
$ corepack yarn lint
```

O haz ambas cosas a la vez:

```bash
$ corepack yarn test && corepack yarn lint
```

El track de TypeScript en Exercism no impone el _estilo_ del código, así que eres libre de elegir entre puntos y comas, tabulaciones o espacios, y todo lo que hay en medio.

## Crear tu primer módulo

Normalmente, las pruebas de este track cargan tu implementación importándola como un módulo: `import Bob from './bob';`.
Para que funcione, debes exportar tu implementación desde el archivo en el que las pruebas buscan tu módulo, `bob.ts`:

```typescript
export class Bob {
  public hey(message: string) {
    // Your solution here
  }
}
```

Hemos proporcionado plantillas en cada ejercicio y hemos colocado este `export` ahí para ti.
