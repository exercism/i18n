# Acerca de

JavaScript es un lenguaje de programación que permite que las páginas web sean dinámicas. Es un lenguaje interpretado, lo que significa que no necesita compilarse: en lugar de eso, el intérprete (como un navegador web) analizará el código y lo convertirá en código que la máquina pueda ejecutar, algo idóneo para crear sitios web dinámicos que puedan ejecutarse en cualquier navegador _¡en cualquier ordenador!_

JavaScript no solo se usa en el navegador. Los entornos de ejecución de JavaScript, como [Node.js][web-nodejs] y [Deno][web-deno], te permiten escribir, lanzar y atender peticiones en servidores web.
Otros frameworks, como [Electron][web-electron], usan JavaScript para escribir _aplicaciones multiplataforma_ para Windows, Linux y macOS.
El desarrollo de aplicaciones móviles también es una posibilidad, utilizando [React Native][web-react-native], [Ionic][web-ionic] y varios más, y ahora [Expo][web-expo] permite apuntar a Android, iOS y la web, todo a la vez.

ECMAScript es el [estándar][web-ecma] que define JavaScript.

> «ECMAScript se ha convertido en uno de los lenguajes de programación de propósito general más utilizados del mundo.
> Se le conoce sobre todo como el lenguaje integrado en los navegadores web, pero también se ha adoptado ampliamente para aplicaciones de servidor y embebidas.»
> [ECMA International Language Specification][web-ecma-2019]

A partir de la 6ª edición (conocida comúnmente como ES2015 o ES6) en 2015, se publica una nueva edición del estándar cada año.
La 6ª edición fue una actualización importante que aportó muchas mejoras respecto a ES5, entre las que destacan las plantillas de cadenas, una sintaxis expresiva de funciones flecha y una sintaxis más limpia para definir clases.

Pero como cada año llegan a JavaScript nuevas sintaxis y funcionalidades, el soporte para estos cambios suele ser incompleto en los [navegadores actuales][web-compat-browsers] y en [la última versión de Node.js][web-compat-node].
Esto no significa que no podamos usarlo.
Herramientas como [Babel][web-babel] ofrecen [transpilación][wiki-transpilation] para la mayoría de las funcionalidades, lo que nos permite _escribir_ como si estuviéramos en el futuro.

**Nota**: Este track admite la sintaxis más reciente de ECMAScript mediante Babel y el plugin [@babel/preset-env][web-babel-preset-env], y las nuevas funcionalidades experimentales se habilitan con cada actualización de ese plugin, a la par que la publicación de las especificaciones.
Se adapta automáticamente a _tu instalación local de Node.js_.
Esto significa que no tienes que preocuparte por lo que está y no está soportado.
