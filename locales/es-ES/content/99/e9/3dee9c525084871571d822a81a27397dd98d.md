# Instrucciones

Un pirata está trazando una ruta por una carta de calas ocultas.
La carta es una tabla hash indexada por el nombre de la cala; cada
valor es un array de las calas a las que puedes llegar directamente
desde esa misma.

## 1. Vacía la cola de marea

Define `tide-queue` para que tome un array de elementos, añada cada
uno a un deque nuevo (en orden) y luego los extraiga todos de vuelta
a un array que conserve el orden original. Esta es la forma FIFO:
añadir por detrás, extraer por delante.

```factor
{ "alpha" "bravo" "charlie" } tide-queue .
! => { "alpha" "bravo" "charlie" }
```

## 2. Calas alcanzables

Define `coves-reachable` para que tome una cala inicial y una carta,
y devuelva un hash-set de todas las calas alcanzables desde `start`,
incluida `start`.

```factor
"Skull Bay" H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { "Reef Point"  } }
    { "Reef Point"  { } }
} coves-reachable .
! => HS{ "Skull Bay" "Hidden Cove" "Reef Point" }
```

Usa un `<dlist>` como frontera del BFS y un `HS{ }` para el
conjunto de visitados.

## 3. Número de saltos

Define `hop-count` para que tome una cala inicial, una cala objetivo
y una carta, y devuelva el número mínimo de saltos entre ellas, o
`f` si no se puede llegar a la cala objetivo.

```factor
"Skull Bay" "Hidden Cove"
H{
    { "Skull Bay"   { "Hidden Cove" } }
    { "Hidden Cove" { } }
} hop-count .
! => 1
```

Lleva cada cala junto con su distancia desde el inicio en el
deque (un array de 2 elementos sirve).

## 4. Recuento de oro

El stub declara `gold-count` con `:`. Cámbialo a `MEMO:`
(no `:`) para que el resultado de cada cala se calcule una sola vez
y se guarde en caché. Busca el oro de la cala en la constante
`gold-distribution` que proporciona el ejercicio.
Una cala que no esté en la distribución tiene cero oro.

```factor
"Smuggler's Hollow" gold-count .   ! => 200
"Davy Jones' Locker" gold-count .  ! => 0
```

## 5. Ruta del tesoro

Define `treasure-route` para que tome una cala inicial y una carta, y
devuelva la cala alcanzable con más oro. Usa
`coves-reachable` de la tarea 2 y `gold-count` de la tarea 4.

```factor
"Skull Bay" some-chart treasure-route .
! => "Smuggler's Hollow"   (the richest reachable cove)
```

El `gold-count` con memoización hace que las búsquedas repetidas no
cuesten nada, lo que resulta útil cuando varias partes del algoritmo
consultan la misma cala.
