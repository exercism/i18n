# Resolver ejercicios en local

Resolver ejercicios en tu máquina local te permite escribir todo el código en un entorno que te resulta familiar.

## Instalar la CLI

Para resolver un ejercicio en tu máquina local, primero necesitas instalar y configurar la interfaz de línea de comandos de Exercism siguiendo [estas instrucciones](https://exercism.org/cli-walkthrough).

### Configuración

Necesitas decirle a la CLI quién eres para que podamos descargar las cosas correctamente.
Puedes encontrar tu token en tu [página de configuración](/settings/api_cli).
Después, puedes configurar la CLI con lo siguiente, reemplazando `<your-api-token>` por el valor de la página de configuración:

```
exercism configure --token=<your-api-token>
```

## Descargar el ejercicio

Una vez instalada, puedes usar la CLI para descargar el ejercicio a tu máquina local con el siguiente comando (reemplazando `<exercise-slug>` y `<track-slug>` por los valores correspondientes:

```
exercism download --exercise=<exercise-slug> --track=<track-slug>
```

No tienes que recordar la estructura de este comando, ya que la página del ejercicio muestra el comando adecuado para ese ejercicio.

Una vez que el comando de descarga haya terminado, los archivos del ejercicio se descargarán en tu máquina local.

## Resolver el ejercicio

El objetivo de cada ejercicio es crear una implementación que pase todas las pruebas.
A esa implementación se la conoce como _solución_.

Para ayudarte con eso, cada ejercicio contiene los siguientes archivos:

- README.md: las instrucciones que explican qué se espera de ti
- HELP.md: información sobre cómo ejecutar las pruebas y cómo obtener ayuda cuando te quedas atascado
- HINTS.md (opcional): pistas para ayudarte a resolver el ejercicio
- Archivo(s) de prueba: contienen las pruebas que verifican la corrección de tu solución
- Archivo(s) stub: proporcionan un punto de partida para ayudarte a empezar a construir tu implementación

Dependiendo de la pista, puede haber otros archivos que las herramientas de la pista requieran para que las pruebas se ejecuten.

## Enviar tu solución

Una vez que tu solución pase todas las pruebas, puedes enviar tu solución con el siguiente comando:

```
exercism submit <implementation_file_paths>
```

Este comando subirá tu solución al sitio web de Exercism e imprimirá la URL de la página de la solución.

Una vez más, no tienes que recordar este comando, ya que el archivo `HELP.md` del ejercicio mostrará el comando correcto.

Es posible enviar una solución incompleta, lo que te permite:

- Ver cómo otros han completado el ejercicio
- Solicitar ayuda a un mentor

## Otras funcionalidades de la CLI

### Ver todos los comandos

Ejecuta el subcomando de ayuda para obtener la lista completa de comandos disponibles.

```bash
exercism help
```

### Solución de problemas

Asegúrate de estar en la última versión.

Verifica qué versión tienes:

```bash
exercism version
```

Compruébala con la última versión publicada y actualiza si tu versión no es la más reciente.

Después de actualizar, vuelve a comprobar la versión. Si la versión no ha cambiado, asegúrate de que estás ejecutando el binario actualizado.

```bash
which exercism
```

Si sigues teniendo problemas, abre una incidencia en exercism/cli en GitHub con la salida del comando troubleshoot.

```bash
exercism troubleshoot
```

Puedes abrir incidencias en [nuestro rastreador de incidencias](https://github.com/exercism/exercism/issues) y la comunidad intentará ayudarte. **Asegúrate de haber completado el [Recorrido interactivo](https://exercism.org/cli-walkthrough) antes de abrir cualquier incidencia.**
