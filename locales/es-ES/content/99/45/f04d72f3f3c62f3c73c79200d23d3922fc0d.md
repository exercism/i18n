# Instrucciones

Nota: este ejercicio es una continuación del ejercicio `need-for-speed`.

En este ejercicio vas a organizar carreras entre varios tipos de coches teledirigidos.
Cada coche tiene sus propias características de velocidad y de consumo de batería.

Los coches empiezan con la batería llena (100 %).
Cada vez que conduces el coche con el mando a distancia, avanza tantos metros como indique la velocidad del coche y reduce el porcentaje de batería restante según su consumo de batería.

Si la batería de un coche está por debajo de su porcentaje de consumo de batería, ya no puedes conducirlo.

El coche teledirigido tiene una pantalla LED muy vistosa que muestra dos datos:

- La distancia total recorrida, que se muestra así: `"Driven <METERS> meters"`.
- La carga de batería restante, que se muestra así: `"Battery at <PERCENTAGE>%"`.

Cada pista de carreras tiene su propia distancia.
Los coches se ponen a prueba comprobando si pueden terminar la pista sin quedarse sin batería.

## 1. Conduce el coche

Implementa el método `Drive` de `Car`, que actualiza el número de metros recorridos según la velocidad del coche y reduce la batería según su consumo:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car.Drive()
// car is now Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

Nota: no intentes conducir el coche si al hacerlo la batería va a quedar por debajo de 0.

## 2. Muestra la distancia recorrida

Implementa un método `DisplayDistance` en `Car` que devuelva la distancia tal y como se muestra en la pantalla LED, como un `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayDistance())
// Output: "Driven 0 meters"
```

## 3. Muestra el porcentaje de batería

Implementa el método `DisplayBattery` de `Car` que devuelva el porcentaje de batería tal y como se muestra en la pantalla LED, como un `string`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

fmt.Println(car.DisplayBattery())
// Output: "Battery at 100%"
```

## 4. Comprueba si un coche teledirigido puede terminar una carrera

Para terminar una carrera, un coche tiene que ser capaz de recorrer la distancia de la carrera.
Esto significa no agotar la batería antes de cruzar la línea de meta.
Implementa el método `CanFinish`, que recibe un `trackDistance int` como parámetro y devuelve `true` si el coche puede terminar la carrera; en caso contrario, devuelve `false`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

trackDistance := 100

car.CanFinish(trackDistance)
// => true
```
