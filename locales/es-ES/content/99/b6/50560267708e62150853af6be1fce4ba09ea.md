# Instalación

Usa el binario `full` para tu plataforma, disponible en [la página oficial de versiones][official-releases].
De momento, el track está orientado a la versión Arizona Bark de Arturo 0.10.0.

~~~~exercism/caution
Homebrew es un método popular de terceros para instalar software en plataformas macOS y Linux.
Sin embargo, su receta para Arturo está orientada a la compilación `mini`, que es incompatible con este track.
~~~~

Si necesitas más ayuda para instalar Arturo, consulta el [Discord oficial de Arturo][discord].

## Ejecutar código de Arturo

Llegados a este punto, ¡ya estás listo para empezar a escribir código en Arturo!
Para acceder al REPL de Arturo, ejecuta `arturo` en la línea de comandos.
Para ejecutar un script de Arturo, ejecuta `arturo <file>` en la línea de comandos.

[official-releases]: https://arturo-lang.io/#download
