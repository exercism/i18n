# Instalar Kotlin

Además de la CLI de Exercism y tu editor de texto favorito, para practicar con los ejercicios de Kotlin de Exercism necesitas:

* el **Java Development Kit** (JDK): Kotlin compila a bytecode de Java, así que necesitas instalar el JDK, que incluye tanto un entorno de ejecución de Java *como* herramientas de desarrollo (en especial, el compilador de Java); y
* **Gradle**: una herramienta de compilación específica para proyectos basados en la JVM y compatible con Kotlin.

Elige tu sistema operativo:

* [Windows](#h-windows)
* [macOS](#h-macos)
* [Linux](#h-linux)

... o ...
* si prefieres no usar un gestor de paquetes, puedes [instalar manualmente](#h-install-manually).

Opcionalmente, también puedes usar un [IDE de Java](#h-java-ides).

----

## Windows

Abre un símbolo del sistema como administrador.  (Si necesitas ayuda para abrir un símbolo del sistema con privilegios administrativos, consulta [abrir un símbolo del sistema elevado en Windows 8+](http://www.howtogeek.com/194041/how-to-open-the-command-prompt-as-administrator-in-windows-8.1/) (o [Windows 7](http://www.howtogeek.com/howto/windows-vista/run-a-command-as-administrator-from-the-windows-vista-run-box/)).

1. Si aún no has instalado Chocolatey, hazlo ahora:

      ```batchfile
        C:\Windows\system32> @powershell -NoProfile -ExecutionPolicy unrestricted -Command "iex ((new-object net.webclient).DownloadString('https://chocolatey.org/install.ps1'))" && SET PATH=%PATH%;%ALLUSERSPROFILE%\chocolatey\bin
      ```

2.  Instala el JDK:

       ```batchfile
        C:\Windows\system32> choco install openjdk11
        ...
        C:\Windows\system32> refreshenv
        ...
       ```

Te recomendamos cerrar el símbolo del sistema administrativo y abrir uno nuevo: no necesitas privilegios de administrador para practicar los ejercicios de Exercism.

¡Ya puedes empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «Ejecutar los tests».

## macOS

A continuación tienes las instrucciones para instalarlo con el método más habitual, usando Homebrew.  Si lo prefieres, también puedes [instalarlo en macOS sin Homebrew](#h-installing-on-macos-without-homebrew).

### Instalación

1. Si aún no has instalado [Homebrew](http://brew.sh), hazlo ahora:

      ```sh
        $ /usr/bin/ruby -e "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install)"
      ```

2. Añade el [Homebrew Cask](https://caskroom.github.io/): así podrás instalar binarios ya compilados, como el JDK.

      ```
        $ brew tap adoptopenjdk/openjdk
      ```

3.  Instala el JDK:

       ```
        $ brew install --cask adoptopenjdk11
       ```

¡Ya puedes empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «Ejecutar los tests».

## Linux

A continuación tienes las instrucciones para instalarlo con el gestor de paquetes de tu distribución.  Si lo prefieres, también puedes [instalarlo en Linux sin un gestor de paquetes](#h-installing-on-linux-without-a-package-manager).

* [Debian](#h-debian)
* [Otras distribuciones de Linux](#h-other-linux-distributions)

### Debian

Si usas Debian o alguna de sus derivadas (como Ubuntu o Linux Mint), utiliza APT:

*(probado en: Ubuntu 14, 16 y 18)*

1. Instala el JDK:

      ```sh
        $ sudo apt-get update
        $ sudo apt-get install software-properties-common
        $ sudo add-apt-repository ppa:openjdk-r/ppa
        $ sudo apt-get update
        $ sudo apt-get install openjdk-11-jdk
      ```


¡Ya puedes empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «Ejecutar los tests».

----

### Otras distribuciones de Linux

Hay muchas formas de instalar el JDK 11, pero una de las más sencillas es usar SDKMAN, que te permite instalar OpenJDK 11 con facilidad. Sigue estos pasos:

1. Instala SDKMAN:
    ```sh
    $ curl -s "https://get.sdkman.io" | bash
    ``` 
    (si no funciona, echa un vistazo a las instrucciones que encontrarás aquí: https://sdkman.io/install )
1. Instala OpenJDK 11:
    ```
    $ sdk install java 11.0.2-open
    ``` 

¡Ya puedes empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «Ejecutar los tests».

### Instalar en Windows manualmente

*NOTA: estas instrucciones están pensadas para usuarios de Windows con experiencia.  Si aún no sabes cómo definir variables de entorno o no te sientes cómodo gestionando la estructura de directorios, te recomendamos encarecidamente que uses la instalación basada en Chocolatey, [más arriba](#h-windows).*

1. Instala el JDK:
   1. Descarga «**OpenJDK 11 (LTS)**» de [AdoptOpenJDK](https://adoptopenjdk.net/releases.html?variant=openjdk11#x64_win) (elige **«Install JDK»**).
   -  Ejecuta el instalador con todas las opciones predeterminadas.

¡Ya puedes empezar con la pista de Kotlin de Exercism!

Para empezar, consulta «Ejecutar los tests».

## IDEs de Java

Hay muchos IDEs de Java disponibles.  Estos son los tres más populares:

* [IntelliJ IDEA](https://www.jetbrains.com/idea/download/) (descarga la edición «Community»)
  - creado por los autores de Kotlin, este IDE ofrece el mejor soporte para el lenguaje.
- [Eclipse](https://www.eclipse.org/downloads/)
- [NetBeans](https://netbeans.org/downloads/) (descarga el paquete «Java SE»)

y hay [otros](https://en.wikibooks.org/wiki/Java_Programming/Java_IDEs).
