# Acerca de

Las bibliotecas de clases base de .NET proporcionan la clase [`Regex`][regex] para procesar expresiones regulares.

Consulta este [artículo][regex-comparison] para ver una comparación de C# con otras variantes de expresiones regulares.

## Grupos de captura

Un aspecto que hay que tener en cuenta es el de los grupos de captura, que devuelven partes del texto que coinciden con diversas partes del patrón de la expresión regular. El enfoque de los grupos de captura requiere acostumbrarse. Consulta esta [documentación][capture].

Ten en cuenta que hay una jerarquía en la que intervienen los grupos de captura, `(?<capture-name>pattern)`:

- se devuelve un conjunto de cero o más coincidencias (una por cada coincidencia encontrada en el texto).
- Cada coincidencia contiene una serie de grupos de captura
- Cada grupo contiene una serie de capturas.

Además:

- `Match` deriva de `Group`
- `Group` deriva de `Capture`

Advertencias:

- Lo más seguro es usar capturas con nombre.
- Por lo general, los grupos de captura aparecen en la colección `Groups` en el mismo orden en que aparecen en el texto.
- `Groups[0]` parece corresponder a la coincidencia completa.
- `Groups[<capture name>].Value` es casi con toda seguridad lo que te interesa. Las capturas individuales (aparte de `Caputures[0]`) parecen estar pensadas para fines de diagnóstico, si es que están presentes.

## Opciones de Regex

Familiarízate con [`RegexOptions`][regex-options].

Además de las opciones habituales `IgnoreCase`, hay otras para `MultiLine`, que resulta útil para procesar varias líneas de texto de una sola vez, y `IgnorePatternWhitespace`, que, junto con los strings textuales, la interpolación de strings y los comentarios, puede ser muy expresivo, como se muestra en este ejemplo:

```csharp
const string PREAMBLE = "preamble";
const string PWTEXT = "pwtext";
const string PW = "pw";
const string SPACE = "space";
const string POSTAMBLE = "postamble";

var pattern = $@"
    ^
    (?<{PREAMBLE}>.*)          # any text
    (?<{PWTEXT}>password)      # the literal text - password
    (?<{SPACE}>\s+)
    (?<{PW}>\w*)               # the password itself
    (?<{POSTAMBLE}>.*)         # any text
    $
  ";

var rewrittenLine = $"{grps[PREAMBLE].Value}{grps[PWTEXT].Value}{grps[SPACE].Value}{mask}{grps[POSTAMBLE].Value}";
```

Otra opción interesante es `RegexOptions.Compiled` para las expresiones regulares [compiladas][regex-compilation].
