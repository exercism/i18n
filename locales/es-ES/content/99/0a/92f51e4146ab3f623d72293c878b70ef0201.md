# Usa la interpolación de strings

[comment]: # (Esta advertencia aparece cuando la solución no usa la interpolación de strings)

Usa la [interpolación de strings](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L20) para insertar el parámetro `name` en el string de salida.

- Cuando sea posible, en el track de Elixir de Exercism se recomienda usar la interpolación de strings en lugar de la concatenación de strings por su legibilidad.

```elixir
def hello(what) do
  "Hello, #{what}"
end
```

- [Cualquier expresión de Elixir](https://github.com/elixir-lang/elixir/blob/9cac52833e91b5ebac0d322b20e39605d8dafad9/lib/elixir/lib/string.ex#L30) puede aparecer en la sintaxis de la interpolación de strings

```elixir
def pluralize_apple(n) when n >= 1 do
  "apple#{if n > 1, do: "s"}"
end
```
