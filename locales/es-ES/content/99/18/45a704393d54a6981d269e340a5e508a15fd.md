# Instrucciones

Estás ayudando a tu hermana pequeña con sus deberes de vocabulario de inglés, que le resultan muy tediosos.
 Su clase está aprendiendo a crear palabras nuevas añadiendo _prefijos_ y _sufijos_.
 Dado un conjunto de palabras, la profesora busca palabras transformadas correctamente y con la ortografía correcta, añadiendo el prefijo al principio o el sufijo al final.

La tarea tiene cuatro actividades, cada una con un conjunto de textos o palabras con las que trabajar.


## 1. Añadir un prefijo a una palabra

Uno de los prefijos más comunes en inglés es `un`, que significa «no».
 En esta actividad, tu hermana tiene que formar palabras negativas, o palabras con el significado «no», añadiéndoles `un`.

Implementa la función `add_prefix_un(<word>)`, que toma `word` como parámetro y devuelve una palabra nueva con el prefijo `un`:


```python
>>> add_prefix_un("happy")
'unhappy'

>>> add_prefix_un("manageable")
'unmanageable'
```


## 2. Añadir prefijos a grupos de palabras

Hay otros cuatro prefijos comunes que está estudiando la clase de tu hermana:
 `en` (_que significa «poner dentro de» o «cubrir con»_),
 `pre` (_que significa «antes» o «adelante»_),
 `auto` (_que significa «uno mismo» o «igual»_),
  y `inter` (_que significa «entre» o «entre varios»_).

 En este ejercicio, la clase está creando grupos de palabras de vocabulario con estos prefijos, para poder estudiarlas juntas.
 Cada prefijo viene en una lista con palabras comunes con las que se usa.
 Los estudiantes tienen que aplicar el prefijo y producir un string que muestre el prefijo aplicado a todas las palabras.

Implementa la función `make_word_groups(<vocab_words>)`, que toma `vocab_words` como parámetro con el siguiente formato:
 `[<prefix>, <word_1>, <word_2> .... <word_n>]`, y devuelve un string con el prefijo aplicado a cada palabra que tiene este aspecto:
  `'<prefix> :: <prefix><word_1> :: <prefix><word_2> :: <prefix><word_n>'`.

Aquí no hace falta crear un bucle `for` o `while` para procesar la entrada.
Piensa bien qué métodos de string (y delimitadores) podrías usar en su lugar.


```python
>>> make_word_groups(['en', 'close', 'joy', 'lighten'])
'en :: enclose :: enjoy :: enlighten'

>>> make_word_groups(['pre', 'serve', 'dispose', 'position'])
'pre :: preserve :: predispose :: preposition'

>> make_word_groups(['auto', 'didactic', 'graph', 'mate'])
'auto :: autodidactic :: autograph :: automate'

>>> make_word_groups(['inter', 'twine', 'connected', 'dependent'])
'inter :: intertwine :: interconnected :: interdependent'
```


## 3. Quitar un sufijo a una palabra

`ness` es un sufijo común que significa _«estado de ser»_.
 En esta actividad, tu hermana tiene que encontrar la palabra raíz original quitando el sufijo `ness`.
  Pero, claro, hay reglas ortográficas molestas: si la palabra raíz terminaba originalmente en una consonante seguida de una «y», entonces la «y» se cambiaba por una «i».
 Al quitar «ness» hay que restaurar la «y» en esas palabras raíz. Por ejemplo: `happiness` --> `happi` --> `happy`.

Implementa la función `remove_suffix_ness(<word>)`, que recibe un `word` y devuelve la palabra raíz sin el sufijo `ness`.


```python
>>> remove_suffix_ness("heaviness")
'heavy'

>>> remove_suffix_ness("sadness")
'sad'
```

## 4. Extraer y transformar una palabra

Los sufijos se usan a menudo para cambiar la categoría gramatical a la que pertenece una palabra.
 Una práctica común en inglés es la de «convertir en verbo», es decir, que un adjetivo _se convierta_ en verbo añadiéndole un sufijo `en`.

En esta tarea, tu hermana va a practicar la conversión de palabras en verbos extrayendo un adjetivo de una frase y convirtiéndolo en verbo.
 Por suerte, todas las palabras que hay que transformar aquí son «regulares»: no necesitan cambios ortográficos para añadir el sufijo.

Implementa la función `adjective_to_verb(<sentence>, <index>)`, que toma dos parámetros.
 Una `sentence` que use la palabra de vocabulario y el `index` de la palabra, una vez dividida la frase.
 La función debe devolver el adjetivo extraído en forma de verbo.


```python
>>> adjective_to_verb('I need to make that bright.', -1 )
'brighten'

>>> adjective_to_verb('It got dark as the sun set.', 2)
'darken'
```
