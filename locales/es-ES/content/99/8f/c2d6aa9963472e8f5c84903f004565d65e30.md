# Pistas

## 1. Crea un conjunto de strings útiles

- Los [strings][strings-and-characters] se definen como literales encerrando cero o más caracteres entre comillas dobles (`"`).

## 2. Crea un conjunto de caracteres útiles

- Los [caracteres][strings-and-characters] se definen como literales encerrando exactamente un carácter entre comillas dobles (`"`).
- Los caracteres definidos como literales necesitan que se les indique explícitamente una anotación de tipo `Character` para evitar que el compilador los interprete como strings.

## 3. Combina frases para construir mensajes

- Los strings se pueden concatenar con [el operador de string adecuado][string-docs].
- Los caracteres no se pueden concatenar con strings.
  Primero hay que convertirlos en strings.

## 4. Crea un cartel de graduación

- La [interpolación de strings][string-interpolation] se realiza colocando la expresión cuyo valor quieres incluir en el string dentro de un par de paréntesis precedidos por el carácter de barra invertida.

## 5. Calcula el coste de un cartel

- Swift tiene [una propiedad de string][string-count-docs] que devuelve el número de caracteres de un string.
