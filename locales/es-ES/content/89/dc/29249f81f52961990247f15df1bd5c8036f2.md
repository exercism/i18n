# Strings

Una cadena de caracteres es una serie de caracteres que va rodeada de comillas.
Se admiten tanto comillas simples como dobles.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansión de variables en strings

En los strings entre comillas dobles, si se hace referencia a una variable mientras está en el scope, el valor se inserta en el string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Compatibilidad con la codificación de caracteres

Históricamente, las funciones de string en PHP solo admitían caracteres ASCII y no admitían las codificaciones Unicode modernas.
Los caracteres ASCII ocupan 1 byte cada uno, mientras que los caracteres Unicode pueden tener entre 1 y 4 bytes de longitud.
Si necesitas manipular strings Unicode de forma segura, consulta las [versiones multibyte][multi-byte-fns] de las funciones históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
