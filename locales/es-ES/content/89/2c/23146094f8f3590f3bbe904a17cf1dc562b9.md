# Anexo a las instrucciones

## El comando `apply` de Tcl

Puede que los casos de prueba te parezcan confusos.
Se espera que implementes lo siguiente:

```tcl
set myList {alpha beta gamma delta}
listOps::filter $myList {{word} {expr {[string length $word] == 4}}
```

¿Por qué tiene tantas llaves ese último argumento?

Recuerda que el comando `proc` se define así:

```tcl
proc procName argList body
```

Tcl tiene un comando `apply`:

```tcl
apply func ?arg1 arg2 ...?
```

este «func» es una lista de dos elementos, `{argList body}`, que es, en esencia, un proc anónimo (o «lambda»).
El comando `apply` invoca ese proc anónimo y le pasa los argumentos que necesita.

Por ejemplo, todo esto es equivalente:

```tcl
# using proc
proc myReverse {str} {return [string reverse $str]}
puts [myReverse "Hello, World!"]

# using apply
puts [apply {{str} {string reverse $str}} "Hello, World!"]

# or, store the func in a variable
set func {{str} {string reverse $str}}
puts [apply $func "Hello, World!"]
```

Usar `apply` facilita pasar bloques de código de un sitio a otro.

Referencia: [`apply`](https://tcl.tk/man/tcl8.6/TclCmd/apply.htm), [`proc`](https://tcl.tk/man/tcl8.6/TclCmd/proc.htm).
