# Introducción

## Módulos

Hasta ahora, todos los ejercicios que has visto han usado clases.
A veces no necesitamos la sobrecarga de crear un objeto con estado, así que en su lugar usamos `module`.

Un módulo es muy similar a una clase (de hecho, `Module` es el padre de `Class` en la jerarquía de objetos); la principal diferencia es que, en lugar de usar métodos de instancia, usamos métodos de clase.
Los métodos de clase empiezan por `self.` y se llaman directamente sobre un módulo.

Por ejemplo:

```ruby
module Speaker
  def self.echo(something)
    "#{something} ... #{something}"
  end
end

Speaker.echo("Hello")   #=> "Hello ... Hello"
```

## Bucles

Hay varias formas de escribir bucles en Ruby, pero como tendemos a usar la enumeración en lugar del bucle en general, quizá el bucle más habitual sea el bucle `while`:

```ruby
counter = 0

while counter < 5
  counter += 1
end
```

También puedes usar su variante `until`

```ruby
counter = 0

until counter == 5
  counter += 1
end
```
