# Pistas

## 1. Comprueba cuántos pájaros han visitado hoy

- «Hoy» se refiere al último elemento del vector `birds_per_day`.
- Se puede acceder al último elemento de `v` mediante el índice `length(v)`.
- La función [`tail(v, n)`][ref-tail] resulta útil para leer (pero no modificar) el final de un vector.
  El argumento `v` es el vector y `n` es el número de elementos que se devuelven, con un valor predeterminado de 6.

## 2. Incrementa el recuento de hoy

- Puedes usar el índice `length(v)` para acceder al elemento de hoy.
- Otra opción es sumar el vector de longitud 7 correspondiente.
- Para construir un vector con elementos repetidos, la función [`rep()`][ref-rep] puede resultarte útil.
