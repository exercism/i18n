# Introducción

En JavaScript, un array es una estructura similar a una lista, sin longitud fija, que puede contener cualquier tipo de valores primitivos u objetos, incluso tipos mezclados.

Para crear un array, añade elementos entre corchetes (`[]`).
Para leer de un array, escribe el índice entre corchetes (`[]`) después del nombre.
Los índices de un array empiezan en cero.

Por ejemplo:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[2];
// => 3
```

Para obtener el número de elementos que hay en un array, usa la propiedad `length`:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.length;
// => 4
```

Para cambiar un elemento del array, asigna un valor en el índice:

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers[0] = 'one';
numbers;
// => ['one', 'two', 3, 'four']
```

## Métodos

Algunos de los [métodos][array_methods] que están disponibles en todos los objetos Array se pueden usar para añadir o eliminar elementos del array.

### push

> El método `push()` añade uno o más elementos al final de un array y devuelve la nueva longitud del array.[^1]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.push(5); // => 5
numbers;
// => [1, 'two', 3, 'four', 5]
```

### pop

> El método `pop()` elimina el último elemento de un array y devuelve ese elemento.
> Este método cambia la longitud del array.[^2]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.pop(); // => four
numbers;
// => [1, 'two', 3]
```

### shift

> El método `shift()` elimina el primer elemento de un array y devuelve ese elemento eliminado.
> Este método cambia la longitud del array.[^3]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.shift(); // => 1
numbers;
// => ['two', 3, 'four']
```

### unshift

> El método unshift() añade uno o más elementos al principio de un array y devuelve la nueva longitud del array.[^4]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.unshift('one'); // => 5
numbers;
// => ['one', 1, 'two', 3, 'four']
```

### splice

> El método splice() cambia el contenido de un array eliminando o reemplazando elementos existentes y/o añadiendo nuevos elementos en el mismo sitio. Este método devuelve un array que contiene los elementos eliminados.[^5]

```javascript
const numbers = [1, 'two', 3, 'four'];
numbers.splice(2, 1, 'one'); // => [3]
numbers;
// => [1, 'two', 'one', 'four']
```
