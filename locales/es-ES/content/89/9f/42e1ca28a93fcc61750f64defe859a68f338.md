# Pistas

## 1. Convertir ubicaciones

- Se puede acceder a los elementos de una tupla mediante la coincidencia de patrones o la indexación.

## 2. Comparar las ubicaciones del tesoro y del lugar

- Las tuplas se pueden comparar por igualdad si tienen la misma longitud y los mismos tipos en el mismo orden.

## 3. Contar las ubicaciones del tesoro

- La función `filter` del módulo `gleam/list` se puede usar para eliminar elementos de un array basándose en una función que devuelve un bool.
