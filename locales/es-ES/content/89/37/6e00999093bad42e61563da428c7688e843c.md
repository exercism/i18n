# Acerca de

[Los closures][closures] en Swift son bloques de código autocontenidos a los que se les pueden pasar parámetros para desencadenar su cómputo y devolver valores.
Los closures también capturan valores de su entorno y los usan en sus cómputos.
Como son autocontenidos, se pueden pasar de un sitio a otro en un programa como cualquier otro valor, o asignarlos a constantes y variables.

Los closures pueden sonar mucho a las funciones de Swift; y es así, y con razón.
Las funciones en Swift son casos especiales de closures que deben tener un nombre y se definen con una sintaxis ligeramente distinta.

Aunque las funciones en Swift son técnicamente closures, cuando la gente habla de «closures» en Swift, se refiere a las [expresiones de closure][closure-expressions].
Las expresiones de closure se escriben como una lista de parámetros seguida de un tipo devuelto y la palabra clave `in` seguida del cuerpo del closure, todo ello entre un par de llaves:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}
```

Esto define una expresión de closure de tipo `(Double, Double) -> Double`, y se puede ejecutar de forma similar a una función de este tipo, aplicándola a parámetros del tipo adecuado:

```swift
{ (a: Double, b: Double) -> Double in
  return (a + b) / 2.0
}(10.0, 15.0)
// returns 12.5
```

Como no es muy cómodo escribir la expresión de closure completa cada vez que se quiere ejecutar, los closures se pueden asignar a nombres, igual que cualquier otro valor en Swift.
Después, se pueden llamar aplicando el nombre a los parámetros:

```swift
let mean = { (a: Double, b: Double) -> Double in
  (a + b) / 2.0
}

mean(13.0, 100.0)
// returns 56.5
```

Como se ha visto antes, los closures, igual que las funciones normales, pueden omitir la palabra clave `return` si el cuerpo del closure es una única expresión.

Lo más habitual es usar los closures con funciones de orden superior, ya sea pasándolos como parámetros o devolviéndolos como resultados:

```swift
[11, 75, 3, 99, 53].contains(where: { (x: Int) -> Bool in x > 100 })
// returns false

["apple", "ball", "carrot"].sorted(by: { (s1: String, s2: String) -> Bool in s1.count < s2.count })
// returns ["ball", "apple", "carrot"]

func makeAdder(base: Int) -> (Int) -> Int {
  { (x: Int) -> Int in base + x }
}
```
