# Pistas

## General

- El [tutorial de números de Python][python-numbers-tutorial] y los [tipos numéricos de Python][python-numeric-types] pueden ser una gran introducción.

## 1. Estima el valor tras el cambio

- Puedes usar el [operador de división][division-operator] para obtener el valor de la moneda cambiada.

## 2. Calcula la moneda que queda tras un cambio

- Puedes usar el [operador de resta][subtraction-operator] para obtener la cantidad de cambio.

## 3. Calcula el valor de los billetes

- Puedes usar el [operador de multiplicación][multiplication-operator] para obtener el valor de los billetes.

## 4. Calcula el número de billetes

- Tienes que dividir `amount` entre `denomination`.
- Tienes que usar una conversión de tipo a `int` para obtener el número exacto de billetes.
- Para quitar los decimales de un `float`, puedes convertirlo a `int`.

  **Nota:** El operador `//` también realiza la división entera (redondeo hacia abajo). Pero si el operando es de tipo `float`, el resultado sigue siendo `float`.

## 5. Calcula lo que sobra tras cambiar a billetes

- Tienes que encontrar el residuo de `amount` que no equivale a una `denomination` completa.
- El operador módulo `%` puede ayudarte a encontrar el residuo.

## 6. Calcula el valor tras el cambio

- Tienes que calcular el `spread` por ciento de `exchange_rate` usando el operador de multiplicación y sumarlo a `exchange_rate` para obtener la moneda cambiada.
- Hay que calcular el tipo real. Recuerda sumar el _tipo de cambio_ y la _comisión_.
- Puedes obtener el dinero cambiado con la comisión aplicada usando la operación de división y una conversión de tipo a `int`.
