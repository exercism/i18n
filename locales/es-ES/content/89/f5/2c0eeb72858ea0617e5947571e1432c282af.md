# Pistas

## 1. Obtén la primera letra de una frase

- Vuelve a consultar la introducción para descubrir cómo obtener una letra concreta de un string.
- Los índices empiezan a contar desde 0.

## 2. Pon en mayúscula una palabra

- Poner en mayúscula significa tener un único carácter _en mayúscula_, seguido de caracteres _en minúscula_.
- Así que, primero, tienes que extraer la primera letra y convertirla [a mayúsculas][mdn-to-upper-case].
- Después, tienes que determinar el resto del string (todo excepto el primer carácter).
  El [método slice][mdn-slice] puede ayudarte con eso.
- Después de aplicar la conversión [a minúsculas][mdn-to-lower-case], puedes combinar la primera letra con el resto usando el operador de suma `+`.

## 3. Obtén la última letra de una frase

- Vuelve a consultar la introducción para descubrir cómo obtener una letra concreta de un string.
- El índice de la última letra se puede deducir a partir de la propiedad `.length` del string y del hecho de que los índices empiezan a contar en 0.
- Los strings incluyen un método [trim][mdn-trim] que elimina los espacios en blanco del principio y del final.

## 4. Sé educado

- Reutiliza una función existente para poner en mayúscula la palabra.
- El operador de suma `+` se puede usar para concatenar dos strings.
