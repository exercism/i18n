# Pruebas

Como OCaml es un lenguaje compilado, tienes que compilar tu solución y el código de las pruebas antes de poder ejecutarlas.
Usamos [`dune`](https://dune.build/) para compilar.
Cada carpeta tiene un fichero dune que especifica cómo compilar y también un Makefile que delega en dune.

Para compilar y ejecutar las pruebas, basta con escribir lo siguiente desde la carpeta del ejercicio:

```bash
make
```

## Cómo crear tu primer módulo de OCaml

Para crear un módulo que se pueda usar con la prueba del ejercicio `bob`, pon lo siguiente en un fichero llamado `bob.ml`:

```ocaml
open Base 

let response_for input = failwith "TODO"
```
