# Anexo a las instrucciones

## Palabras

`smallest` y `largest` devuelven cada una **dos** valores en la pila: el
valor palíndromo (o `f` si no existe ninguno en el rango) y un
array de pares de factores.

- `smallest ( mn mx -- value factors )`
- `largest  ( mn mx -- value factors )`

Cada par en `factors` es un array de dos elementos `{ a b }`. Lanza el
string `"min must be <= max"` si `mn > mx`.
