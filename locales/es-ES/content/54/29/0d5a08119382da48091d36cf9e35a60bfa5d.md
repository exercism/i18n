# Introducción

## Operadores de comparación

Los operadores de comparación son similares a los de muchos otros lenguajes.

Para la igualdad, los operadores son `==` (igual) y `!=` (distinto).

```Kotlin
val txt = "abc"
txt == "abc" // => true
txt != "abc" // => false
```

Los operadores de mayor y menor que también son los convencionales.

```Kotlin
1 < 3 // => true
3 > 3 // => false
3 <= 3 // => true
4 >= 3 // => true
```

## Bifurcación con `if`

Esta es la forma completa de una expresión `if`:

```Kotlin
if (conditional1) {
//    something...
} else if (conditional2) {
//    something...
} else {
//    something...
}
```

- Los paréntesis `()` alrededor de cada condicional son obligatorios.
- Un condicional debe evaluarse a un Boolean `true` o `false`.
  Kotlin no tiene el concepto de «truthy» y «falsy» que existe en algunos lenguajes.
- Las llaves `{}` son opcionales si solo hay una única expresión.
- Tanto `else if` como `else` son opcionales, y puede haber varios bloques `else if`.

La expresión `if` también puede usarse para «elegir» un valor:

```Kotlin
val number = 100000
val description = if (number > 100) "number is over 100" else "number is less than 100"
// => description = "number is over 100"
```

## ¿Alternativas?

Por decisión deliberada, Kotlin _no_ tiene el operador ternario `? :` que existe en Java.
Se prefiere una forma concisa de `if ... else`:

```Kotlin
return if (isOK) goodValue else badValue
```
