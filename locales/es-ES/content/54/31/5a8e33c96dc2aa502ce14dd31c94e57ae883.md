# Acerca de

Aunque el modificador `readonly` impide que se sobrescriba el valor o la referencia de un campo, no ofrece ninguna protección para los miembros de un tipo de referencia.

```csharp
readonly List<int> ints = new List<int>();

void Foo()
{
    ints.Add(1);    // ok
    ints = new List<int>(); // fails to compile
}
```

Para asegurarte de que todos los miembros de un tipo de referencia estén protegidos, puedes declarar los campos como `readonly` y definir propiedades automáticas sin un descriptor de acceso `set`.

La biblioteca de clases base (BCL) proporciona algunas versiones de solo lectura de las colecciones cuando es necesario evitar que se actualicen los miembros de una colección. Estas vienen en forma de envoltorios:

- [`ReadOnlyDictionary<T>`][ReadOnlyDictionary]
- [`ReadOnlyCollection<T>`][ReadOnlyCollection]

[ReadOnlyDictionary]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlydictionary-2
[ReadOnlyCollection]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.objectmodel.readonlycollection-1
