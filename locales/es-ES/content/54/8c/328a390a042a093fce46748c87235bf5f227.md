# Pistas

## 1. Calcular el número de coches funcionales producidos por hora

* El porcentaje (que se pasa como argumento) es un número entre 0 y 100. Para que este porcentaje sea un poco más fácil de manejar, empieza dividiéndolo entre 100.
* Para calcular el número de coches producidos correctamente, multiplica el porcentaje (dividido entre 100) por el número de coches producidos.

## 2. Calcular el número de coches funcionales producidos por minuto

* Empieza calculando la producción de coches funcionales por hora. Para ello, puedes usar la función `calculate_working_cars_per_hour` que escribiste antes.
* Conociendo la producción de coches por hora, puedes obtener la producción por minuto dividiendo la producción por hora entre 60 (el número de minutos que tiene una hora).
* Dado que el número devuelto debe ser un entero, el [operador de división entera](https://www.lua.org/manual/5.4/manual.html#3.4.1) puede resultarte útil para esto.

## 3. Calcular el coste de producción

* Empieza calculando cuántos grupos de 10 coches hay. Puedes hacerlo dividiendo el número de coches entre 10.
* Después, calcula cuántos coches quedan (el [operador módulo](https://www.lua.org/manual/5.4/manual.html#3.4.1) es útil para esto).
* Para obtener el coste total, multiplica el número de grupos por el coste de producir 10 coches y, después, multiplica el número de coches restantes por el coste de producir cada coche individual. Por último, suma entre sí los resultados de las multiplicaciones.
