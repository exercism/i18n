# Acerca de

Los números decimales son números con uno o más dígitos tras el separador decimal.

```gleam
let float = 3.45
// -> 3.45
```

Los números decimales también tienen su propio conjunto de operadores.

```gleam
1.0 +. 1.4 // -> 2.4
5.0 -. 1.5 // -> 3.5
5.0 /. 2.0 // -> 2.5
3.0 *. 3.1 // -> 9.3

2.0 >. 1.0  // -> True
2.0 <. 1.0  // -> False
2.0 >=. 1.0 // -> True
2.0 <=. 1.0 // -> False
```

También se pueden añadir guiones bajos a los números decimales para que se lean mejor.

```gleam
1_000_000.0 // One million
```

Con los números decimales también se puede usar la notación científica:

```gleam
1.01e3 // -> 1010
15.1e-3 // -> 0.0151
```
