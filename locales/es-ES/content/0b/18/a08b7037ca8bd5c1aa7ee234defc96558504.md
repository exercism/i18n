# Acerca de

Una función es [recursiva de cola][recursion-tc] si lo _último_ que ejecuta la función es una llamada a sí misma.

Cada vez que se llama a una función, se coloca un _marco de pila_ con sus variables locales, argumentos, etc. en la parte superior de [la pila de llamadas][call-stack]. Cuando una función devuelve, el marco de pila se elimina de la pila.

Las funciones recursivas de cola permiten la [optimización de llamadas de cola][tail-call-optimization]. Es una optimización que permite reutilizar el último marco de pila en la siguiente llamada a una función, porque la función anterior tiene la garantía de que ya no lo necesita. Esto reduce la preocupación por desbordar la pila de llamadas, que es una situación en la que hay tantos marcos en la pila de llamadas que no queda memoria para crear otro.

- Para conseguir la recursión de cola en Elixir, a menudo se necesita un acumulador debido a las reglas de inmutabilidad de los datos.

  - Un acumulador es una variable que se pasa a lo largo de la llamada recursiva y que mantiene el estado actual de la función recursiva _hasta el momento_, hasta que se devuelve el resultado final en el caso base.

    ```elixir
    # Count the length of a list without an accumulator
    def count([]), do: 0
    def count([_head | tail]), do: 1 + count(tail)

    # Count the length of a list with an accumulator
    def count(list), do: do_count(list, 0)

    defp do_count([], count), do: count
    defp do_count([_head | tail], count), do: do_count(tail, count + 1)
    ```

- Cuando trabajes con listas, recuerda que se implementan como listas enlazadas simples: las operaciones de añadir al principio son muy rápidas, pero las de añadir al final son muy lentas.

  ```elixir
  # Reverse a list with an accumulator
  def reverse(list), do: do_reverse(list, [])

  defp do_reverse([], acc), do: acc

  defp do_reverse([head | tail], acc) do
    do_reverse(tail, [head | acc])
  end
  ```
