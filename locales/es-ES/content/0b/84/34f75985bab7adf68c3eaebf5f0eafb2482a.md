# Anexo de instrucciones

## Implementación

En este ejercicio vas a instanciar una clase y añadir algunos métodos de instancia; puedes consultar [Escribir clases en Ruby][writing-classes] para saber cómo hacerlo.

Un HighScore acepta un array con uno o más números, cada uno de los cuales representa una «puntuación de juego».
La clase Array puede servir de inspiración para trabajar con arrays, consulta la [documentación de Ruby][ruby-docs-array].
