# Pistas

## General

- Quizá te venga bien echar un vistazo a [Interfaces en el Tour de Go][interfaces-tour-of-go] para ver más ejemplos si el ejercicio se te atraganta.

## 1. Crea la funcionalidad abstracta de saludo

- Vuelve al ejemplo `Counter` de la introducción para averiguar cómo definir una interfaz.
- Revisa los [conceptos de funciones][concept-functions] para repasar cómo escribir firmas de funciones en Go.
- El tipo abstracto `Greeter` puede usarse en una firma de función igual que un tipo concreto normal como `string`.
- Para implementar `SayHello`, llama a los métodos del argumento de tipo `Greeter`.
  Después, usa el formateo de string o la concatenación de string para construir el resultado final.

## 2. Implementa el italiano

- Revisa el [concepto de structs][concept-structs] para ver cómo definir un tipo struct.
- Para resolver la tarea, el struct no necesita ningún campo.
- Una vez que hayas definido el struct, querrás añadirle los métodos `LanguageName` y `Greet`.
  Revisa el [concepto de métodos][concept-methods] para averiguar cómo añadir un método a un tipo.
