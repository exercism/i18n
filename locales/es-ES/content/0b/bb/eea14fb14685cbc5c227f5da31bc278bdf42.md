# tiene función main

Elimina la función `Main`, ya que los tests no la necesitan y hace que el código sea un poco más difícil de leer.

Normalmente, la función `Main` se añade para ayudar a hacer debug del código. Sin embargo, un mejor enfoque es hacer debug del código mientras se ejecutan uno o más tests unitarios. Esto tiene la ventaja añadida de que puedes centrarte en hacer debug de un caso de test concreto. Aquí tienes algunos enlaces que explican cómo hacer debug de código Scala mientras se ejecutan tests unitarios en varios entornos de desarrollo integrados (IDE):

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
