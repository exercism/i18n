# Anexo de introducción

## Implementación

Hay varias formas de resolver **Año bisiesto**; este ejercicio se centra en no usar el método integrado `Time.leap_year?`.
Esto se debe a que el objetivo de este ejercicio es aprender a manejar comparaciones y lógica booleana.
Pero para cualquier otro propósito, se recomienda usar el método integrado.
