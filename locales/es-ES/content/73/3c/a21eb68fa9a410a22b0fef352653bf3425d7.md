# Tests

Puedes usar el editor en línea del sitio web de Exercism para resolver los ejercicios.
O bien descarga los ejercicios en tu ordenador, resuélvelos en local y envíalos después a Exercism.
El resto de este documento trata sobre cómo trabajar en local.

## Exercism CLI

Necesitarás la herramienta de línea de comandos `exercism` para descargar y enviar ejercicios.
Consulta [la documentación de la CLI de Exercism][exercism-cli] para ver las instrucciones de descarga y configuración.

Para descargar un ejercicio, haz lo siguiente:

```bash
exercism download --track 8th --exercise hello-world
```

Y cambia al directorio del ejercicio:

```bash
cd /path/to/your/exercism_workspace/8th/hello-world
```

o, si usas Windows:

```cmd
cd \path\to\your\exercism_workspace\8th\hello-world
```

Ten en cuenta que puedes obtener tu espacio de trabajo de Exercism con el comando `exercism configure`.

## Probar en local

Para ejecutar los tests de un ejercicio, debes estar en el directorio correcto del ejercicio.
Después, lanza los tests con este comando:

```bash
8th -f test.8th
```

## Tests omitidos

Resolver un ejercicio consiste en hacer que pasen todos sus tests.
De forma predeterminada, al ejecutar los tests solo se ejecuta uno (el primero).
Esto es intencionado, ya que te permite centrarte solo en hacer que pase ese test.
Cuando pase, puedes activar el siguiente test moviendo la línea `SKIP-REST-OF-TESTS` por debajo de él.

### Anular las omisiones

Para ejecutar todos los tests, incluidos los que están después de la palabra `SKIP-REST-OF-TESTS`, puedes asignar el valor `true` a una variable de entorno `RUN_ALL_TESTS`.
Una forma de establecerla solo mientras se ejecutan los tests es (macOS y Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```

## Envía tu solución

Para subir tu solución al sitio web de Exercism con la herramienta exercism:

```bash
exercism submit
```

Ten en cuenta que puedes subir tu código aunque no pase todos los tests.
Esto es útil si te has quedado atascado y necesitas ayuda de un mentor.
