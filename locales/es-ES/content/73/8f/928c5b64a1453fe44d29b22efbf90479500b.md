# Instrucciones

Tu tarea consiste en calcular la puntuación de Scrabble de una palabra sumando los valores de sus letras.

Las letras tienen los siguientes valores:

| Letra                        | Valor |
| ---------------------------- | ----- |
| A, E, I, O, U, L, N, R, S, T | 1     |
| D, G                         | 2     |
| B, C, M, P                   | 3     |
| F, H, V, W, Y                | 4     |
| K                            | 5     |
| J, X                         | 8     |
| Q, Z                         | 10    |

Por ejemplo, la palabra «cabbage» vale 14 puntos:

- 3 puntos para C
- 1 punto para A
- 3 puntos para B
- 3 puntos para B
- 1 punto para A
- 2 puntos para G
- 1 punto para E
