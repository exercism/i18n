# Acerca de

Z3 es un lenguaje de Satisfiability Modulo Theory (SMT) que se usa para ver si unas ecuaciones o fórmulas son satisfacibles, es decir, si tienen una posible solución.

Z3 se encuentra sobre todo en la verificación de software, la resolución de restricciones, los problemas geométricos, la seguridad y otras aplicaciones que se benefician de un cálculo matemático rápido.

Z3 fue creado por el grupo Research in Software Engineering (RiSE) de Microsoft Research y, desde 2015, es un lenguaje de código abierto. El repositorio de Github de código abierto de Z3 se encuentra en https://github.com/Z3Prover/z3.
