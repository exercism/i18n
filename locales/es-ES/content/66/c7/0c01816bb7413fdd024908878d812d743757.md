# Pruebas

Ejecuta las pruebas con:

```bash
$ gradlew test
```

> Usa `gradlew.bat` si estás en Windows

## Pruebas omitidas

En los conjuntos de pruebas, todas las pruebas excepto la primera se han omitido.

Cuando consigas que una prueba pase, puedes habilitar la siguiente eliminando la anotación `@Ignore`.
