# Instrucciones

Llevas el marcador de un partido de netball. A diferencia de todo lo visto hasta ahora, un marcador tiene que recordar lo que ha pasado.

La clase `SCOREBOARD` necesita lo siguiente. El esqueleto ya te da la clase y sus dos declaraciones de atributos; añade el resto.

## 1. Prepara el marcador

`create` recibe el nombre del equipo local y el nombre del equipo visitante, y devuelve un marcador con ambas puntuaciones a cero.

```sather
board ::= #SCOREBOARD("Vixens", "Magpies");
board.home_score
-- => 0
```

## 2. Anota un gol

`home_goal` suma uno a la puntuación del equipo local y `away_goal` suma uno a la del equipo visitante. Ninguno de los dos devuelve nada.

```sather
board.home_goal;
board.home_score
-- => 1
```

## 3. Lee el marcador

`summary` devuelve el marcador tal y como se escribiría: el equipo local, su puntuación, un guion, la puntuación del visitante y, por último, el equipo visitante.

```sather
board.summary
-- => "Vixens 1 - 0 Magpies"
```

Los espacios son exactamente los que se muestran y el guion es un único `-`.

## 4. ¿Quién va ganando?

`leader` devuelve el nombre del equipo que va por delante, o `"Draw"` cuando las puntuaciones están igualadas.

```sather
board.leader
-- => "Vixens"
```

## 5. ¿Cuánta ventaja hay?

`margin` devuelve cuántos goles separan a los equipos. Nunca es negativo, gane quien gane.

```sather
board.margin
-- => 1
```
