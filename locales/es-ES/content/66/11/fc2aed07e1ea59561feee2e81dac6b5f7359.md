## 1. Inicia una comprobación de fiabilidad para una sola entrada

- Para este paso no necesitas una tarea; basta con un proceso enlazado normal.
- Hay una [función integrada][spawn-link] que ejecuta una función anónima dada en un proceso nuevo y la enlaza al proceso actual.

## 2. Interpreta los resultados de una comprobación de fiabilidad

- Para recibir un solo mensaje, llama a [`receive`][receive] una vez. Leerá el primer mensaje que coincida con cualquiera de los patrones dados y dejará los demás mensajes en el buzón del proceso.
- Puedes usar un guard o [el operador pin][pin-operator] para asegurarte de que solo se reciban mensajes de un proceso cuyo PID coincida con el PID que se pasa a `await_reliability_check_result/2` como argumento.
- [`receive`][receive] acepta una cláusula `after` para gestionar los tiempos de espera.

## 3. Ejecuta una comprobación de fiabilidad concurrente para muchas entradas

- El proceso actual debe empezar a capturar las salidas antes de que se genere ningún proceso enlazado nuevo.
- La captura de salidas en un proceso se consigue estableciendo un flag en ese proceso.
- Hay una [función integrada][process-flag] que establece un flag en un proceso y devuelve el valor anterior de ese flag.
- El flag para capturar las salidas se llama `:trap_exit` y acepta un valor booleano.
- Usa funciones de `Enum` para iniciar primero un proceso para cada entrada y después esperar los mensajes de cada proceso. Usa las funciones implementadas en los dos pasos anteriores. Ten en cuenta que el mapa que devuelve `start_reliability_check/2` coincide con el mapa que `await_reliability_check_result/2` espera como primer argumento.

## 4. Ejecuta una comprobación de corrección concurrente para muchas entradas

- Para este paso, usa una tarea asíncrona.
- Hay una [función integrada][task-async] que inicia una tarea asíncrona.
- Hay una [función integrada][task-await] que espera a que una tarea asíncrona termine de ejecutarse y devuelve su resultado. Acepta un tiempo de espera como segundo argumento.
- Usa funciones de `Enum` para iniciar primero una tarea para cada entrada y después esperar cada tarea.
