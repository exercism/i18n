# Instrucciones

En este ejercicio tienes que implementar algunas funciones para manipular un array de lenguajes de programación.

## 1. Define una función que devuelva un array de lenguajes vacío

Define la función `new/0`, que no toma ningún argumento y devuelve un array vacío.

```elixir
LanguageList.new()
# => []
```

## 2. Define una función para añadir un lenguaje al array

Define la función `add/2`, que toma 2 argumentos (un _array de lenguajes_ y un literal de string de un _lenguaje_). Debe devolver el array resultante con el nuevo lenguaje antepuesto al array dado.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
```

## 3. Define una función para eliminar un lenguaje del array

Define la función `remove/1`, que toma 1 argumento (un _array de lenguajes_). Debe devolver el array sin el primer elemento. Supón que el array siempre tendrá al menos un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Clojure")
# => ["Clojure"]
language_list = LanguageList.add(language_list, "Haskell")
# => ["Haskell", "Clojure"]
language_list = LanguageList.remove(language_list)
# => ["Clojure"]
```

## 4. Define una función que devuelva el primer elemento del array

Define la función `first/1`, que toma 1 argumento (un _array de lenguajes_). Debe devolver el primer lenguaje del array. Supón que el array siempre tendrá al menos un elemento.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.first(language_list)
# => "Prolog"
```

## 5. Define una función que devuelva cuántos lenguajes hay en el array

Define la función `count/1`, que toma 1 argumento (un _array de lenguajes_). Debe devolver el número de lenguajes que hay en el array.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elm")
# => ["Elm"]
language_list = LanguageList.add(language_list, "Prolog")
# => ["Prolog", "Elm"]
LanguageList.count(language_list)
# => 2
```

## 6. Define una función para determinar si el array incluye un lenguaje funcional

Define la función `functional_list?/1`, que toma 1 argumento (un _array de lenguajes_). Debe devolver un valor de tipo Boolean. Debe devolver true si «Elixir» es uno de los lenguajes del array.

```elixir
language_list = LanguageList.new()
# => []
language_list = LanguageList.add(language_list, "Elixir")
# => ["Elixir"]
LanguageList.functional_list?(language_list)
# => true
```
