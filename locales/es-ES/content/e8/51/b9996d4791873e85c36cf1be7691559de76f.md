# Residuo

En matemáticas, el **residuo** es la cantidad que «sobra» después de realizar un cálculo.
Por ejemplo, el residuo de `5 / 3` es `2`.

Muchos lenguajes de programación usan el signo de porcentaje (`%`) como operador para
calcular el residuo. Por ejemplo:
```javascript
5 % 3 == 2
```

A menudo, el residuo puede calcularse tanto con números enteros como con números de coma
flotante. Por ejemplo:
```javascript
5.3 % 3 == 2.3
```

Cuando se trabaja con números negativos, el resultado siempre tiene el mismo signo que el
dividendo (el número que está a la izquierda y que se divide). Por ejemplo:
```javascript
-5 % 3 == -2
5 % -3 == 2
-5 % -3 == -2
```

Algunos lenguajes (como Python) usan el operador `%` para calcular el módulo, no el residuo.
Esto hace que los números negativos se traten de forma diferente. Puedes obtener más
información sobre esto [en Wikipedia](https://en.wikipedia.org/wiki/Modulo).
