# Introducción

Los condicionales de Factor eligen entre **quotations**, fragmentos de código escritos entre corchetes, `[ ... ]`. Escribir `[ ... ]` apila el código en la pila como un valor en lugar de ejecutarlo; el condicional decide entonces qué quotation ejecutar. (Las quotations se explican en detalle en un ejercicio posterior).

`if` (en [`kernel`][kernel]) es el condicional básico de Factor. Recibe un Boolean y dos quotations, y ejecuta la primera si el Boolean es verdadero y la segunda en caso contrario.

```
if ( ? then-quot else-quot -- )
```

```factor
: abs ( x -- y ) dup 0 < [ neg ] [ ] if ;
```

`when` ejecuta su quotation solo cuando el Boolean es verdadero, y `unless` solo cuando es falso. Para ramificar entre varias opciones existe `cond` (en [`combinators`][combinators]):

```factor
USING: combinators ;

: classify ( n -- s )
    {
        { [ dup 0 <  ] [ drop "negative" ] }
        { [ dup 0 =  ] [ drop "zero"     ] }
        [ drop "positive" ]
    } cond ;
```
