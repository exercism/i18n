# Introducción

## Agent

El módulo `Agent` facilita una abstracción para lanzar [procesos y el bucle de _recepción y envío_][exercism-processes]. A partir de aquí, llamaremos _procesos de agente_ a los procesos iniciados con el módulo `Agent`. Un _proceso de agente_ podría elegirse para representar un estado compartido central.

Para iniciar un _proceso de agente_, `Agent` proporciona la función `start/2`. La función proporcionada al llamar a `start` para _iniciar_ el _proceso de agente_ devuelve el estado inicial del proceso:

```elixir
# Start an agent process with an initial value of an empty list
{:ok, agent_pid} = Agent.start(fn -> [] end)
```

Al igual que `Map` o `List`, `Agent` proporciona muchas funciones para trabajar con _procesos de agente_.

Es habitual organizar y encapsular toda la funcionalidad relacionada con `Agent` en un módulo para el dominio que se está modelando.

[exercism-processes]: https://exercism.org/tracks/elixir/concepts/processes
