# errores de compilación

El código tiene uno o más errores de compilación, lo que impide que se ejecute la suite de pruebas. Un buen primer paso para averiguar cómo corregir los errores es examinar los mensajes de error que aparecen al intentar compilar el código. Estos mensajes de error incluyen un número de error y una descripción, lo que ayuda a identificar con precisión cuál es el problema exacto.
