# Pistas

## 1. Crea un coche teledirigido

- Devuelve un array con 4 elementos con nombre.
- `speed` y `battery_drain` se proporcionan como argumentos.
- `battery` y `distance_traveled` toman valores predeterminados.

## 2. Crea una pista de carreras

- Devuelve un array de longitud 1.

## 3. Comprueba si la batería está agotada

- Para que se considere «agotada», la carga de la batería no tiene por qué ser cero, solo lo suficientemente baja como para que no se pueda completar otro turno.
- El control del coche se realiza en pasos discretos. Cuando hablamos de «turno», significa «cada vez que se llama a `drive()`».

## 4. Conduce el coche

- ¿Está agotada la batería? Si es así, ¿debería actualizarse el coche?
- `battery_drain` es el porcentaje de carga que se pierde en cada turno.
- `speed` es la distancia recorrida en cada turno.
- Devuelve un coche actualizado, según corresponda.

## 5. Comprueba si un coche teledirigido puede terminar una carrera

- ¿Cuántos turnos más puede completar el coche?
- No hay turnos parciales, por lo que la función [`floor`][ref-round] puede ser útil. Como alternativa, la división entera `%/%` también funciona con valores de coma flotante, truncando el resultado.
- ¿Qué distancia puede recorrer el coche en este número de turnos?
- ¿Es suficiente?

## 6. Almacena si el coche puede terminar una pista con la batería llena

- Restablece `battery` y `distance_traveled` a los valores de un coche nuevo antes de hacer ningún cálculo.
- Los arrays son vectores _recursivos_, por lo que pueden contener otros arrays.
- El nombre del nuevo elemento se proporciona en tiempo de ejecución, por lo que la notación `$` no funcionará. La introducción sugiere alternativas.
- El valor del nuevo elemento es un `list` de longitud 2. No puede ser un `vector`, porque mezcla elementos numéricos y lógicos.
- Devuelve el coche actualizado.
- Supón que se pueden añadir varios elementos de pista, con nombres diferentes.

[ref-round]: https://www.rdocumentation.org/packages/base/versions/3.3.0/topics/Round
