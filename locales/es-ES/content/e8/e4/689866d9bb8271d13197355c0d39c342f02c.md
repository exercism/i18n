# Introducción

A veces, un fragmento de estado debe compartirse entre varias palabras sin tener que pasarlo cada vez por sus efectos de pila. Las *variables dinámicas* de Factor, declaradas con `SYMBOL:`, dan a cada palabra acceso a un valor almacenado en un espacio de nombres.

## `SYMBOL:` y `SYMBOLS:`

`SYMBOL: name` declara una variable. `SYMBOLS: a b c ;` declara varias a la vez:

```factor
USING: namespaces ;

SYMBOLS: counter total ;
```

## Establecer y obtener

`set-global` y `get-global` (en [`namespaces`][namespaces]) operan sobre el espacio de nombres global:

```
set-global    ( value variable -- )
get-global    ( variable -- value )
change-global ( variable quot: ( old -- new ) -- )
```

```factor
0 counter set-global
counter get-global .         ! => 0
counter [ 10 + ] change-global
counter get-global .         ! => 10
```

Para el estado a nivel de módulo, las variantes `-global` son las que necesitas.

## Vinculaciones con scope mediante `with-variable`

Una variable dinámica también admite una segunda variante, *con scope*. `set` / `get` / `change` (sin el sufijo `-global`) leen y escriben el scope dinámico *actual*, y `with-variable` (en [`namespaces`][namespaces]) crea un scope nuevo mientras dura una quotation:

```
with-variable ( value variable quot -- )
set           ( value variable -- )
get           ( variable -- value )
change        ( variable quot: ( old -- new ) -- )
```

La variable queda vinculada a `value` mientras se ejecuta `quot`; en cuanto este termina, la vinculación desaparece. Esto permite que quien llama desde fuera «inyecte» un valor que el código interno puede leer sin pasarlo por cada firma de pila.

```factor
SYMBOL: greeting

"Hello" greeting [
    greeting get .                ! => "Hello"
    "Howdy" greeting set
    greeting get .                ! => "Howdy"
    greeting [ "!" append ] change
    greeting get .                ! => "Howdy!"
] with-variable

greeting get-global .    ! => f   (the scoped binding is gone)
```

Este ejercicio usa la variante global en todo momento, pero reconocer la familia paralela `set`/`get`/`change` resulta útil cuando lees el código de otras personas.

## Vectores mutables

Como las variables dinámicas mantienen una referencia, puedes guardar una colección *mutable* dentro de una y actualizarla in situ:

```factor
SYMBOL: history

V{ } clone history set-global
"first event" history get-global push
"second event" history get-global push
history get-global .
! => V{ "first event" "second event" }
```

`V{ … }` es un vector literal. Haz siempre `clone` de un literal `V{ }` antes de guardarlo: los literales se comparten entre llamadas.

## `find`: la primera coincidencia

`find` (en [`sequences`][sequences]) devuelve el primer elemento para el que un predicado se evalúa como verdadero, junto con su índice:

```
find ( seq quot -- index elt/f )
```

Si nada coincide, ambos valores son `f`. Descartar el índice con `nip` y usar `unless*` es la combinación estándar de «valor por defecto si falta».

## `reject`: descartar las coincidencias

`reject` (también en [`sequences`][sequences]) es lo contrario de `filter`: devuelve los elementos que *no cumplen* el predicado.
