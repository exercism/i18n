# Acerca de

En Rust, los valores Boolean se representan con el tipo `bool`, y pueden ser `true` o `false`.

Rust admite un [operador de negación booleana][negation operators]: `!` (negación).

Rust admite seis [operadores de comparación][comparison operators]: `==` (igual), `!=` (distinto), `>` (mayor que), `<` (menor que), `>=`
(mayor o igual que), `<=` (menor o igual que). Se pueden usar para evaluar la relación entre valores no booleanos y obtener un valor Boolean.

```rust
1 > 0 // true
1 < 0 // false
1 == 0 // false
1 != 0 // true
1 >= 0 // true
1 <= 0 // false
```

A diferencia de otros lenguajes, `0` no es `false` y un valor distinto de cero no es `true`.

Rust admite tres [operadores binarios lógicos][logical binary operators]: `&` (Y lógico), `|` (O lógico), `^` (O exclusivo lógico).

Rust admite dos [operadores booleanos][lazy boolean operators]: `||` (O) y `&&` (Y). Se diferencian de `|` y `&` en que el operando de la derecha solo se evalúa cuando el operando de la izquierda aún no determina el resultado de la expresión. Es decir, `||` solo evalúa su operando derecho cuando el operando de la izquierda se evalúa como `false`, y `&&` solo cuando este se evalúa como `true`.

```rust
true || false // == true; the right-hand side was not evaluated
true && false // == false
```
