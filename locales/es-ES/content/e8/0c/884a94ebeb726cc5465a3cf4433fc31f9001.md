# Introducción

## Condicionales if

### Operadores lógicos

Java admite los tres operadores lógicos `&&` (AND), `||` (OR) y `!` (NOT).

### Condicional

El tipo subyacente de cualquier operación condicional es el tipo `boolean`, que puede tener el valor `true` o `false`. Los condicionales se usan a menudo como mecanismos de control de flujo para comprobar diversas condiciones. Para comprobar un caso concreto se puede usar un condicional `if`, que ejecuta su código si la condición subyacente es `true`, así:

```java
int val;

if(val == 9) {
    // conditional code
}
```

En escenarios con más de un caso, se pueden encadenar varios condicionales `if` usando las instrucciones `else if` y `else`.

```java
if(val == 10) {
    // conditional code
} else if(val == 17) {
    // conditional code
} else {
    // executes when val is different from 10 and 17
}
```

### Instrucción switch

Java también proporciona una instrucción `switch` para escenarios con múltiples opciones.

```java
int val;

// switch statement on variable content
switch(val) {
    case 1:
        // conditional code
        break;
    case 2: case 3: case 4:
        // conditional code
        break;
    default:
        // if all cases fail
        break;
}
```
