# Instrucciones

Tu tarea consiste en identificar si hay algún color de caramelo en una bolsa que represente la mayor parte de la bolsa. 🍬 El elemento mayoritario es el que ocupa más de la mitad del espacio de una colección. Dado un array de elementos que representan los colores, devuelve el color que se encuentre como mayoritario; de lo contrario, indica que no se ha encontrado ninguna mayoría.

Para un array simple, `[Red, Red, Blue, Red, Green]`, el valor devuelto debería ser Red porque Red aparece 3 veces de un array de 5. Pero para un array `[Red, Red, Blue, Green]`, no hay mayoría a pesar de que Red es el elemento más común, porque 2/4 no es mayor que la mitad de los elementos.
