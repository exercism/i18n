# Anexo a las instrucciones

## Mensajes de excepción

A veces es necesario [lanzar una excepción][raising-exceptions].
Cuando lo hagas, siempre deberías incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar.
En situaciones en las que sabes que el origen del error será de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados][error-base-classes], pero aun así deberías incluir un mensaje significativo.


Una partida válida de `Tic Tac Toe` termina cuando un jugador gana.
Si ambos jugadores están en un estado ganador, este ejercicio espera que uses la [instrucción raise][raise] y «lances» un `ValueError` en tu solución.
También se espera que tu código lance un `ValueError` si se determina que un jugador ha jugado dos turnos seguidos, o que ha jugado el primer movimiento cuando se le había asignado jugar el segundo.


Para lanzar un `ValueError` con un mensaje, escribe el mensaje como argumento del tipo `exception`:

```python
# Example when player O goes before player X.
raise ValueError("Wrong turn order: O started")

# Example when player X goes twice.
raise ValueError("Wrong turn order: X went twice")

# Example when player X wins AND player O wins.
raise ValueError("Impossible board: game should have ended after the game was won")
```

Los tests comprobarán que el mensaje de error coincida exactamente, así que lee con atención los resultados esperados.
