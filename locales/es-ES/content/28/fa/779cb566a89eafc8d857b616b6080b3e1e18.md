# Introducción

En Ruby, los **arrays** son colecciones ordenadas e indexadas por números enteros que pueden contener cualquier objeto.
La indexación de los arrays empieza en `0`.
Un índice negativo se considera relativo al final del array: un índice de `-1` indica el último elemento del array, `-2` es el penúltimo elemento y así sucesivamente.
Los arrays de Ruby incorporan el [módulo Enumerable][enumerable-module], que añade varios métodos de recorrido y búsqueda, además de la capacidad de ordenar.

## Crear un array

- Un array en Ruby puede contener objetos de distintos tipos.

```ruby
array = [1, "two", 3.0] #=> [1, "two", 3.0]
```

## Asignación de elementos

Se puede acceder a los elementos o modificarlos usando índices.
Se puede acceder a subarrays especificando un índice de inicio y un tamaño.

```ruby
a = ["", "", "", "", ""]

a[4] = "hello"  #=> [nil, nil, nil, nil, "hello"]
a[0, 3] = [ 'a', 'b', 'c' ] #=> ["a", "b", "c", nil, "hello"]
```

- Los índices negativos cuentan hacia atrás desde el final del array.

```ruby
a = ['a', 'b']

a[-1] = "Z"
a #=> ["a", "Z"]
```

## Referencia a elementos

- Se pueden recuperar elementos de un array con el método #[].
- Devuelve el elemento que está en el índice, o devuelve un subarray que empieza en el índice de inicio y continúa durante tantos elementos como indique length.

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[2]    #=> "c"
a[6]    #=> nil
a[1, 2] #=> [ "b", "c" ]
```

- Los índices negativos cuentan hacia atrás desde el final del array (-1 es el último elemento)

```ruby
a = [ "a", "b", "c", "d", "e" ]

a[-2]    #=> "d"
a[-3, 3] #=> [ "c", "d", "e" ]
```

## Obtener información sobre un array

Los arrays llevan un seguimiento de su propia longitud en todo momento.
Para consultar el número de elementos que contiene un array, usa length, count o size.

```ruby
browsers = ['Chrome', 'Firefox', 'Safari', 'Opera', 'IE']
browsers.length #=> 5
browsers.count  #=> 5
browsers.size   #=> 5
```

## Añadir elementos a un array

Se pueden añadir elementos al final de un array usando `push` o `<<`:

```ruby
arr = [1, 2, 3, 4]
arr.push(5) #=> [1, 2, 3, 4, 5]
arr << 6    #=> [1, 2, 3, 4, 5, 6]
```

## Eliminar elementos de un array

El método pop elimina el último elemento de un array y lo devuelve:

```ruby
arr = [1, 2, 3, 4, 5, 6]
arr.pop #=> 6
arr     #=> [1, 2, 3, 4, 5]
```
