# Introducción

Los inicializadores son métodos especiales que se usan para crear un valor de la enumeración. Su definición se parece mucho a la de un método, solo que no hay palabra clave `func`, ni tipo de retorno, y el nombre debe ser `init`, y el inicializador *debe* asignar un valor de la enumeración a `self`. Se llama a los inicializadores mediante la notación de punto o pasando los parámetros del inicializador al nombre de la enumeración.

```swift
enum Coin {
  case heads
  case tails

  init(_ i: Int) {
    if i.isMultiple(of: 2) {
      self = .heads
    } else {
      self = .tails
    }
  }

  func flip() -> Self {
    switch self {
    case .heads: return .tails
    case .tails: return .heads
    }
  }
}

let tails = Coin.init(13)
// .tails
let heads = Coin(0)
// .heads
let anotherTails = heads.flip()
// .tails
```
