# Tests

Si tienes el binario de 8th en tu PATH, introduce el comando:

```bash
8th -f test.8th
```

Si el binario de 8th no está en el PATH, en Windows introduce

```cmd
\path\to\8th -f test.8th
```

Linux o macOS:

```bash
/path/to/8th -f test.8th
```

## Probar en el REPL

Inicia 8th cargando test-words.8th:

```sh
8th -f test-words.8th
```

Esto iniciará una sesión de CLI en la que, una vez que hayas escrito algo de código en el archivo de tu solución, podrás cargarlo en el REPL.
Por ejemplo, para el ejercicio «word-count», escribirías:

```8th
"word-count.8th" f:include
```

Y puedes ejecutar los tests con
```sh
"word-count-tests.8th" f:include
```

O puedes copiar y pegar un solo test de ese archivo o escribir el tuyo propio.

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, cuando ejecutas los tests solo se ejecuta uno (el primero).
Esto es intencionado, ya que te permite centrarte únicamente en hacer que ese test pase.
Cuando pase, puedes habilitar el siguiente test moviendo la palabra `SKIP-REST-OF-TESTS` detrás de él.

## Anular las omisiones

Para ejecutar todos los tests, incluidos los que están después de la palabra `SKIP-REST-OF-TESTS`, puedes establecer la variable de entorno `RUN_ALL_TESTS` con el valor `true`.
Una forma de establecerla solo mientras se ejecutan los tests es (macOS y Linux):

```bash
RUN_ALL_TESTS=true 8th -f test.8th
```
