# Instrucciones

En este ejercicio vas a implementar una forma de llevar un registro de las puntuaciones máximas del juego más popular de tu salón recreativo.

Tienes que implementar 7 funciones, todas relacionadas con devolver y manipular un diccionario de datos de puntuaciones máximas.

## 1. Define un nuevo diccionario de puntuaciones máximas

Crea una función `newScoreBoard()` que no reciba parámetros y devuelva un nuevo diccionario de puntuaciones máximas que use valores de tipo `String` para las claves y valores de tipo `Int` como valores.

## 2. Añade jugadores al diccionario de puntuaciones máximas

Para añadir un jugador al diccionario de puntuaciones máximas, define `addPlayer(_:_:_:)`, una función que recibe 3 parámetros:

- El primer parámetro es el diccionario de puntuaciones. 
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre de un jugador como string.
- El tercer parámetro es la puntuación como número entero. 
    El parámetro es opcional; implementa el tercer parámetro con un valor por defecto de 0.

```swift
var highScores = newScoreBoard()
addPlayer(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0]
addPlayer(&highScores, "José Valim", 486_373)
// Returns ["Dave Thomas": 0, "José Valim": 486_373]
```

## 3. Elimina jugadores del diccionario de puntuaciones

Para eliminar a un jugador del diccionario de puntuaciones máximas, define `removePlayer(_:_:)`, que recibe 2 parámetros:

- El primer parámetro es el diccionario de puntuaciones. 
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string.

Esta función debe eliminar al jugador del diccionario si está en él y no hacer nada en caso contrario.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
removePlayer(&highScores, "Dave Thomas")
// Returns ["José Valim": 486_373]
removePlayer(&highScores, "Rose Fanaras")
// Returns ["José Valim": 486_373]
```

## 4. Restablece la puntuación de un jugador

Para restablecer la puntuación de un jugador, define `resetPlayer(_:_:)`, que recibe 2 parámetros:

- El primer parámetro es el diccionario de puntuaciones.
    Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string, cuya puntuación quieres restablecer.

La función establecerá la puntuación del jugador a 0. 
Si el jugador no está en el diccionario, no debe pasar nada.

```swift
var highScores = ["Dave Thomas": 486_373, "José Valim": 10]
resetScore(&highScores, "Dave Thomas")
// Returns ["Dave Thomas": 0, "José Valim": 10]
```

## 5. Actualiza la puntuación de un jugador

Para actualizar la puntuación de un jugador sumándola a la puntuación anterior, define `updateScore`, que recibe 3 parámetros:

- El primer parámetro es el diccionario de puntuaciones. Debe ser un parámetro de entrada y salida.
- El segundo parámetro es el nombre del jugador como string, cuya puntuación quieres actualizar.
- El tercer parámetro es la puntuación que quieres **añadir** a la puntuación máxima almacenada.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373]
addPlayer(&highScores, "Freyja Ćirić", 12_771_008)
updateScore(&highScores, "Freyja Ćirić", 73)
// Returns ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_081]
```

## 6. Obtén un array de jugadores con sus puntuaciones ordenado por nombre de jugador

Define la función `orderByPlayers`, que recibe 1 parámetro:

- El primer parámetro es el diccionario de puntuaciones.

La función devolverá un array de tuplas `(String, Int)` que son los jugadores y sus puntuaciones máximas, ordenado de forma ascendente por el nombre del jugador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByPlayers(highScores)
// Returns [("Dave Thomas", 0), ("Freyja Ćirić", 12_771_091), ("José Valim", 486_373)]
```

## 7. Obtén un array de jugadores ordenado por puntuación de forma descendente

Para obtener un array de jugadores ordenado por puntuaciones de forma descendente, define `orderByScores`, que recibe 1 parámetro:

- El primer parámetro es el diccionario de puntuaciones.

La función devolverá un array de tuplas `(String, Int)` que son los jugadores y sus puntuaciones máximas, ordenado de forma descendente por la puntuación del jugador.

```swift
var highScores = ["Dave Thomas": 0, "José Valim": 486_373, "Freyja Ćirić": 12_771_091]
orderByScores(highScores)
// Returns [("Freyja Ćirić", 12_771_091), ("José Valim", 486_373), ("Dave Thomas", 0)]
```
