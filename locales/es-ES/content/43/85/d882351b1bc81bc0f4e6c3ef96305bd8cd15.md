# Introducción

Los métodos de extensión permiten añadir métodos a tipos existentes sin crear un nuevo tipo derivado, sin recompilar ni modificar de ningún otro modo el tipo original. Se definen como métodos estáticos, pero se llaman con la sintaxis de un método de instancia. Su primer parámetro va precedido del modificador `this`, que especifica el tipo sobre el que opera el método, y se incorporan al scope a nivel de espacio de nombres.

```csharp
public static int WordCount(this string str)
{
    return str.Split().Length;
}

"Hello World".WordCount();
// => 2
```
