# Punteros inteligentes

Los punteros inteligentes de Cairo son una herramienta potente que ofrece una gestión de memoria segura y eficiente.

Un puntero inteligente es una estructura de datos que se comporta como un puntero normal, pero con características de seguridad añadidas que evitan problemas habituales de gestión de memoria, como desreferenciar punteros nulos o acceder a memoria no inicializada.

## ¿Qué es un puntero inteligente?

En general, un puntero es una variable que almacena una dirección de memoria y que, por lo general, apunta a un valor almacenado en esa dirección.

Sin embargo, los punteros sin procesar pueden ser peligrosos: si el puntero no apunta a memoria válida o se desreferencia de forma incorrecta, puede provocar fallos o comportamientos impredecibles.

Los punteros inteligentes resuelven este problema imponiendo reglas estrictas de gestión de memoria, lo que garantiza que se acceda a ella de forma segura y controlada.

Cairo, al igual que muchos lenguajes modernos como Rust, usa punteros inteligentes para evitar accesos inseguros a la memoria.

Un puntero inteligente en Cairo no solo almacena una dirección de memoria, sino que además hace un seguimiento de la propiedad y garantiza la seguridad de la memoria.

## Tipos de punteros inteligentes en Cairo

Cairo ofrece varios tipos de punteros inteligentes, como `Box<T>` y `Nullable<T>`, y cada uno tiene una finalidad distinta.

Veamos con más detalle cómo funcionan estos tipos y cuándo podrías usarlos.

### `Box<T>`

El tipo `Box<T>` es el principal puntero inteligente de Cairo.

Te permite almacenar datos en un segmento de memoria especial llamado «segmento boxed». Un `Box<T>` es un puntero que apunta a ese segmento y, cuando creas un box, reservas espacio para los datos en dicho segmento.

Los boxes son ideales en situaciones en las que:

- Necesitas almacenar un valor de un tipo cuyo tamaño no se puede determinar en tiempo de compilación.
- Tienes una gran cantidad de datos y quieres transferir la propiedad sin copiarlos.

Usando un box, puedes almacenar estructuras de datos grandes de forma más eficiente.

Cuando pasas un `Box<T>` a una función, solo se pasa el puntero, lo que evita tener que copiar todos los datos y mejora el rendimiento, sobre todo con estructuras grandes.

### `Nullable<T>`

El tipo `Nullable<T>` es otro puntero inteligente importante en Cairo.

Puede apuntar a un valor válido de tipo `T` o ser `null` si no hay ningún valor.

Este tipo resulta útil cuando necesitas almacenar valores que no siempre existen, como en un diccionario que puede contener elementos opcionales.

En Cairo, `Nullable<T>` se usa normalmente en diccionarios para gestionar los casos en los que no se puede aplicar ningún valor predeterminado.

Te permite almacenar valores de forma condicional, lo que facilita gestionar la ausencia de datos de manera segura.

## Seguridad de memoria con punteros inteligentes

Una de las principales ventajas de usar punteros inteligentes es que ayudan a garantizar la seguridad de la memoria.

Al gestionar la propiedad y las reglas de acceso, Cairo evita problemas habituales como desreferenciar punteros nulos o colgantes.

Los punteros inteligentes detectan cuándo ya no se necesitan los datos y pueden liberar la memoria automáticamente cuando estos quedan fuera del scope, lo que reduce el riesgo de fugas de memoria.

### Ejemplo: usar un `Box<T>` para tipos recursivos

Un reto habitual en muchos lenguajes de programación es manejar los tipos recursivos.

Los tipos recursivos son tipos que contienen referencias a sí mismos.

Sin una gestión de memoria adecuada, definir un tipo recursivo puede dar lugar a problemas como la recursión infinita.

En Cairo, `Box<T>` permite definir tipos recursivos de forma segura.

Por ejemplo, puedes usar `Box<T>` para implementar un árbol binario, en el que cada nodo contiene una referencia a otro nodo.

Al almacenar referencias en boxes, Cairo garantiza que el uso de memoria sea finito y que el compilador pueda determinar el tamaño de memoria necesario para la estructura.

```rust
use core::box::{BoxTrait};

#[derive(Copy, Drop)]
enum BinaryTree {
    Leaf: u32,
    Node: (u32, Box<BinaryTree>, Box<BinaryTree>),
}

fn main() {
    let leaf1 = BinaryTree::Leaf(1);
    let leaf2 = BinaryTree::Leaf(2);
    let node = BinaryTree::Node((3, BoxTrait::new(leaf1), BoxTrait::new(leaf2)));
    println!("{:?}", node);
}
```

### Ventajas de rendimiento de los punteros inteligentes

Los punteros inteligentes también mejoran el rendimiento de tus programas.

Cuando usas `Box<T>`, solo se pasa el puntero a los datos, en lugar de copiar toda la estructura de datos.

Esto resulta especialmente útil cuando se trabaja con grandes conjuntos de datos, ya que reduce de forma significativa la sobrecarga de las operaciones de memoria.

En el siguiente ejemplo, los datos se pasan por referencia usando un `Box<T>` para evitar el coste de copiar toda la estructura:

```rust
#[derive(Drop)]
struct Cart {
    paid: bool,
    items: u256,
    buyer: ByteArray,
}

fn pass_data(cart: Cart) {
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn pass_pointer(cart: Box<Cart>) {
    let cart = cart.unbox();
    println!("{} is shopping today and bought {} items", cart.buyer, cart.items);
}

fn main() {
    let new_cart = Cart { paid: true, items: 1, buyer: "John" };
    pass_data(new_cart);

    let new_box = BoxTrait::new(Cart { paid: false, items: 3, buyer: "Jane" });
    pass_pointer(new_box);
}
```

En este ejemplo, `pass_pointer` recibe un `Box<Cart>` en lugar de un `Cart`, lo que reduce la cantidad de memoria que se copia durante la llamada a la función.
