# General

- La [aplicación parcial][partial-application] y el [`(|>)`][pipe-operator] facilitan escribir código elegante y encadenado cuando la estructura de datos principal es el último argumento de las funciones. Todas las funciones habituales de la biblioteca estándar funcionan así, como `List.map`.
- Se puede usar una [declaración let][let] en las funciones `attack` para aplicar parcialmente las funciones `attackWithSword` y `attachWithClaw` con la fuerza correcta para Annalyn y Kazak.

[pipe-operator]: https://package.elm-lang.org/packages/elm/core/latest/Basics#|%3E
[partial-application]: https://riptutorial.com/elm/example/7499/partial-application
[let]: "https://elmprogramming.com/let-expression.html"
