# Instrucciones

En este ejercicio vas a trastear con un coche teledirigido, para el que por fin has ahorrado suficiente dinero como para comprarlo.

Los coches empiezan con las baterías llenas (100%). Cada vez que conduces el coche con el mando a distancia, recorre 20 metros y gasta un uno por ciento de la batería.

El coche teledirigido tiene una sofisticada pantalla LED que muestra dos datos:

- La distancia total que ha recorrido, mostrada como: `"Driven <METERS> meters"`.
- La carga de batería restante, mostrada como: `"Battery at <PERCENTAGE>%"`.

Si la batería está al 0%, ya no puedes conducir el coche y la pantalla de la batería mostrará `"Battery empty"`.

Tienes seis tareas, y cada una trabajará con instancias de coche teledirigido.

## 1. Compra un coche teledirigido nuevo

Implementa el método (_estático_) `JedliksToyCar.buy()` para devolver una instancia nueva de coche teledirigido:

```java
JedliksToyCar car = JedliksToyCar.buy();
```

## 2. Muestra la distancia recorrida

Implementa el método `JedliksToyCar.distanceDisplay()` para devolver la distancia tal y como se muestra en la pantalla LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.distanceDisplay();
// => "Driven 0 meters"
```

## 3. Muestra el porcentaje de batería

Implementa el método `JedliksToyCar.batteryDisplay()` para devolver el porcentaje de batería tal y como se muestra en la pantalla LED:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.batteryDisplay();
// => "Battery at 100%"
```

## 4. Actualiza el número de metros recorridos al conducir

Implementa el método `JedliksToyCar.drive()` que actualiza el número de metros recorridos:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.distanceDisplay();
// => "Driven 40 meters"
```

## 5. Actualiza el porcentaje de batería al conducir

Actualiza el método `JedliksToyCar.drive()` para que actualice el porcentaje de batería:

```java
JedliksToyCar car = JedliksToyCar.buy();
car.drive();
car.drive();
car.batteryDisplay();
// => "Battery at 98%"
```

## 6. Evita conducir cuando la batería se ha agotado

Actualiza el método `JedliksToyCar.drive()` para que no aumente la distancia recorrida ni disminuya el porcentaje de batería cuando la batería esté agotada (al 0%):

```java
JedliksToyCar car = JedliksToyCar.buy();

// Drain the battery
// ...

car.distanceDisplay();
// => "Driven 2000 meters"

car.batteryDisplay();
// => "Battery empty"
```
