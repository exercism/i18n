# Luhn: usando un trait personalizado

Antes de hacer este ejercicio, probablemente deberías hacer primero el ejercicio original de Luhn y su sucesor, «Luhn: usando el trait From».

Para obtener el ejercicio original de Luhn, ejecuta

```shell
exercism download --exercise=luhn --track=rust
```

Para obtener el ejercicio «Luhn: usando el trait From», ejecuta

```shell
exercism download --exercise=luhn-from --track=rust
```

En el ejercicio original de Luhn solo validabas strings, pero el algoritmo de Luhn también se puede aplicar a números enteros.

En «Luhn: usando el trait From» implementaste un trait From, que además te obligaba a crear una struct de Luhn.

En lugar de crear una struct solo para realizar la validación, ¿y si validaras los propios tipos primitivos (es decir, String, u8, etc.)?

En este ejercicio crearás e implementarás un [trait](https://doc.rust-lang.org/book/ch10-02-traits.html) personalizado que realiza la validación.
