# Instrucciones

En este ejercicio vas a establecer algunas constantes que se usarán en el funcionamiento de un banco.

Tienes cinco tareas:

## 1. Representa el tipo de interés fijo de un préstamo

Crea la constante numérica sin tipo `FixedInterestRate` para almacenar el valor del 5 % (5/100) y después implementa la función `GetFixedInterestRate` para que lo devuelva:

```go
GetFixedInterestRate()
// => 0.05
```

## 2. Representa el número de días de un año

Crea la constante `DaysPerYear` de tipo `int` para almacenar el valor 365 y después implementa la función `GetDaysPerYear` para que lo devuelva:

```go
GetDaysPerYear()
// => 365
```

## 3. Representa los meses del año

En un bloque, usa el enumerador de Go para crear doce constantes numéricas sin tipo que contengan los valores del 1 al 12 para los meses del año.
Nómbralas `Jan`, `Feb`, `Mar`, etc., y después implementa la función `GetMonth` para que devuelva el valor de un mes concreto:

```go
GetMonth(Jan)
// => 1
```

## 4. Representa un número de cuenta

Crea la constante string sin tipo `AccountNo` para almacenar el valor XF348IJ y después implementa la función `GetAccountNumber` para que lo devuelva:

```go
GetAccountNumber()
// => "XF348IJ"
```
