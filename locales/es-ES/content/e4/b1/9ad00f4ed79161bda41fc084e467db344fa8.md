# Recursos

## Módulos

Perl viene con un conjunto de módulos básicos que puedes encontrar en
[perldoc](https://perldoc.perl.org/modules). Normalmente podrás usar cualquiera de
estos módulos de inmediato. (Es posible que algunas distribuciones requieran
que instales los módulos básicos por separado).

[Awesome Perl](https://github.com/hachiojipm/awesome-perl) es una lista seleccionada de
módulos útiles, y también remite a una selección de otras listas de recomendaciones.

Hay varios instaladores de módulos disponibles para Perl, que te permitirán
instalar una amplia variedad de módulos disponibles en [CPAN](https://metacpan.org/).

### App::cpm
Un instalador de módulos muy rápido y sencillo.
Hay un tutorial disponible en [CPAN](https://metacpan.org/pod/App::cpm::Tutorial).

Ya tendrás esto instalado si seguiste las instrucciones de `local::lib`
de la [documentación de instalación](https://exercism.org/tracks/perl5/installation).

Simplemente ejecuta `cpm install` para instalar los módulos requeridos desde un `cpanfile`,
y usa `--with-recommends` o `--with-suggested` para instalar los módulos recomendados
o sugeridos, respectivamente.

Ejecuta `cpm install Module::Name` para instalar un módulo concreto de forma local, o
ejecuta `cpm install -g Module::Name` para instalarlo globalmente.

### App::cpanminus
El instalador de módulos más conocido y más usado.
Puedes encontrar las instrucciones de instalación en [CPAN](https://metacpan.org/pod/App::cpanminus).

Ejecuta `cpanm -L local --installdeps .` para instalar los módulos requeridos
desde un `cpanfile`.
Ejecuta `cpanm -L local Module::Name` para instalar un módulo concreto
de forma local, o ejecuta `cpanm Module::Name` para instalarlo globalmente.

## Estilo de código y análisis estático

Si buscas buenos consejos generales sobre cómo programar en Perl,
[Perl Best Practices][PBP] de Damian Conway es una buena referencia.

Para embellecer tu código, puedes usar el módulo
[Perl::Tidy][PerlTidy].

Después puedes usar el programa de utilidad `perltidy` que se incluye
para dar formato a tu código.

    # modify file in-place and save old version as some_script.pl.bak
    $ perltidy -b some_script.pl

`perltidy` tiene *muchísimas* opciones de configuración para todos los gustos. Están
documentadas [aquí][perltidyDocs].

También existe [tidyview], una interfaz visual que te permite
ajustar las distintas opciones y ver el resultado de inmediato.

Si quieres imponer prácticas de programación, también tienes
[Perl::Critic][perlcritic]. Incluye las reglas descritas en
el libro *Perl Best Practices* que mencionamos antes, pero existen
muchísimos plugins, y se puede personalizar para adaptarlo a cualquier
conjunto de reglas de estilo interno.

Para usarlo:

    $ perlcritic some_script.pl

La herramienta tiene muchísimas opciones de configuración; consulta su
[documentación][perlcriticdocs] para conocerlas todas a fondo.
