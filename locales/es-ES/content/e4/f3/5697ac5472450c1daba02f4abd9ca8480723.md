# Introducción

Cuando necesitas una fila de `n` valores en la que cada uno depende de su posición, `<iota>` y `map` de Factor cooperan para hacer el trabajo sin escribir un contador de bucle.

## `<iota>` y `map`

`<iota>` (en [`sequences`][sequences]) toma un número entero no negativo `n` y devuelve una secuencia *virtual* de los números enteros `0, 1, …, n-1`. Después, `map` la recorre aplicando tu quotation a cada elemento:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

La quotation recibe un número entero, el índice, y deja en la pila el valor de esa posición.

## Iterar y repetir por recuento

Cuando solo necesitas los *efectos secundarios* de visitar cada índice, y no una nueva secuencia, `each-integer` (en [`math`][math]) ejecuta una quotation sobre `0, 1, …, n-1`:

```
each-integer ( n quot: ( i -- ) -- )
```

`replicate` (en [`sequences`][sequences]) llama a una quotation `n` veces y recoge los resultados, ignorando el índice, lo que resulta práctico para construir `n` valores independientes:

```
replicate ( n quot: ( -- elt ) -- seq )
```

```factor
USING: sequences ;

3 [ { 0 0 } ] replicate .   ! => { { 0 0 } { 0 0 } { 0 0 } }
```

## Rangos acotados

Cuando el rango de índices no empieza en `0`, o quieres que sea inclusivo en ambos extremos, el vocabulario [`ranges`][ranges] ofrece literales con notación de corchetes. Los corchetes incluyen el extremo; los paréntesis lo excluyen.

```
[a..b]    ! a, a+1, …, b      (inclusive)
[a..b)    ! a, a+1, …, b-1    (half-open at the top)
```

```factor
USING: math ranges sequences ;

3 7 [a..b] [ 2 * ] map .   ! => { 6 8 10 12 14 }
3 7 [a..b) [ 2 * ] map .   ! => { 6 8 10 12 }
```

Algunas abreviaturas comunes con un argumento:

```
[1..b]    ! 1, 2, …, b        (same as 1 b [a..b])
[1..b)    ! 1, 2, …, b-1      (same as 1 b [a..b))
[0..b)    ! 0, 1, …, b-1      (same as 0 b [a..b), and same as `b <iota>`)
```

```factor
6 [1..b] [ sq ] map .      ! => { 1 4 9 16 25 36 }
6 [1..b) [ sq ] map .      ! => { 1 4 9 16 25 }
4 [0..b) [ 1 + ] map .     ! => { 1 2 3 4 }
```

`<iota>` es la forma más común; `[a..b]` y sus variantes son la herramienta adecuada cuando el rango empieza en un punto distinto de `0` o necesita un límite superior inclusivo.

## Límites inferiores abiertos y rangos posiblemente vacíos

Los corchetes *incluyen* un extremo; los paréntesis lo *excluyen*. El mismo truco a la izquierda da `(a..b]` y `(a..b)`:

```
(a..b]    ! a+1, …, b              (lower open, upper inclusive)
(a..b)    ! a+1, …, b-1            (both open)
```

`0 n (a..b]` da `{ 1 … n }` para `n > 0` y `{ }` para `n = 0`, la forma natural cuando se itera «todos los enteros positivos hasta `n` incluido».

## Rangos descendentes

Las cuatro formas de corchetes, `[a..b]`, `[a..b)`, `(a..b]` y `(a..b)`, cuentan *hacia abajo* cuando `a > b`, no hacia un resultado vacío:

```factor
USING: ranges sequences ;

5 1 [a..b] >array .   ! => { 5 4 3 2 1 }
1 0 [a..b] >array .   ! => { 1 0 }   (not empty!)
```

## Construir un string por posición

`map` produce la forma que devuelva su quotation. Si la quotation deja un código de carácter en la pila, `>string` (en [`strings`][strings]) convierte el resultado en un string:

```factor
USING: math sequences strings ;

4 <iota> [ 2 * CHAR: A + ] map >string .   ! => "ACEG"
```

`CHAR: A` se interpreta como el número entero `65`. La quotation de aquí duplica el índice y le suma esa base, con lo que cae en letras mayúsculas alternas. Cualquier aritmética que añadas sobre el índice decide qué carácter acaba en esa posición.

## Elegir según la posición

Cuando el carácter depende de una *condición* sobre el índice, haz la elección dentro de la quotation:

```factor
USING: kernel math sequences strings ;

5 <iota> [ 3 < [ CHAR: a ] [ CHAR: b ] if ] map >string .
! => "aaabb"
```

Las tres primeras posiciones evalúan `i 3 <` como `t`, así que obtienen `a`; el resto obtiene `b`. La misma forma, `[ <test> [ <yes> ] [ <no> ] if ]`, cubre las pruebas de paridad con `even?` / `odd?` (en [`math`][math]) y las pruebas de «cada k-ésima posición» con `mod` y `zero?`.
