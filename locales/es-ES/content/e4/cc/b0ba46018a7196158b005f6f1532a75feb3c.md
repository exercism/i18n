# Instrucciones

En este ejercicio vas a escribir código para ayudar a una empresa de carteles a crear mensajes personalizados para sus carteles.

## 1. Crea un cartel para una ocasión

Implementa la función `buildSign(occasion, name)`, que acepta un string como parámetro `occasion` y un string con el nombre de una persona como parámetro `name`.
Los dos parámetros se insertarán en una plantilla de string para generar el mensaje del cartel.

```javascript
buildSign('Birthday', 'Rob');
// => "Happy Birthday Rob!"
```

## 2. Crea un cartel de cumpleaños

Implementa la función `buildBirthdaySign(age)`, que acepta una edad y, según esa edad, determinará parte del mensaje del cartel.
Si la edad es 50 o más, el cartel se referirá al usuario como _mature_; de lo contrario, se referirá a él como _young_.
La salida esperada exacta se muestra a continuación:

```javascript
buildBirthdaySign(50);
// => "Happy Birthday! What a mature fellow you are."

buildBirthdaySign(45);
// => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un cartel de graduación

Implementa la función `graduationFor(name, year)`, que toma un nombre como parámetro de tipo string y un año como parámetro numérico, y usa la interpolación de cadenas para crear una frase para un cartel que emplea un salto de línea para separar las dos líneas del mensaje.

```javascript
graduationFor('Hannah', 2022);
/* => "Congratulations Hannah!
       Class of 2022"
*/
```

## 4. Calcula el coste de un cartel

Implementa la función `costOf(sign, currency)`, que toma un string con el contenido del cartel y un string que representa la moneda.
El cartel tiene un precio base de 20 en la moneda dada. Además, cada letra cuesta 2. (Los espacios en blanco se incluyen en el cálculo.)
La frase devuelta incluye el coste de crear el cartel, escrito con dos decimales, seguido del string de la moneda.

```javascript
costOf('Happy Birthday Rob!', 'dollars');
// => "Your sign costs 58.00 dollars."
```
