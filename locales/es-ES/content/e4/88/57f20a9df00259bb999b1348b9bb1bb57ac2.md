# Introducción

En Python, una [tupla][tuple] es una colección _inmutable_ de elementos en _secuencia_.
Como la mayoría de las colecciones, las `tuples` pueden contener cualquier tipo (o varios tipos) de datos, incluidas otras `tuples`.
Las tuplas admiten todas las [operaciones comunes de secuencia][common sequence operations], pero **no** admiten las [operaciones de secuencia mutables][mutable sequence operations].

Se puede iterar sobre los elementos de una tupla con la construcción `for item in <tuple>`.
Si se necesitan tanto el índice como el valor de un elemento, se puede usar `for index, item in enumerate(<tuple>)`.
Como en cualquier secuencia, se puede acceder a los elementos de las `tuples` mediante _notación de corchetes_, usando un `0-based index` desde la izquierda o un `-1-based index` desde la derecha.
Las tuplas también se pueden copiar total o parcialmente usando la notación de rebanadas (_`<tuple>[<start>:<stop>:<step>]`_).


## Construcción de tuplas

Las tuplas se pueden formar de varias maneras, usando el constructor de la clase `tuple(<iterable>)` o la declaración literal de `tuple`.

### Usar el constructor `tuple()` vacío o con un _iterable_:

```python
>>> no_elements = tuple()
()

# The constructor *requires* an iterable, so single elements must be passed in a list or another tuple.
>>> one_element = tuple([16])
(16,)
```

Los strings son iterables, así que usar un solo `str` como argumento del constructor `tuple()` puede tener resultados sorprendentes:

```python
# String elements (characters) are iterated through and added to the tuple
>>> multiple_elements_string = tuple("Timbuktu")
('T', 'i', 'm', 'b', 'u', 'k', 't', 'u')
```

Los iterables añaden sus elementos uno a uno:

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> multiple_elements_set = tuple({2, 3, 5, 7, 11})
(2,3,5,7,11)
```

#### Declarar una tupla como _literal_:

Como el constructor `tuple(<iterable>)` solo acepta _iterables_ (o nada) como argumentos, es mucho más fácil crear una tupla de un solo elemento con el método literal.

```python
>>> no_elements = ()
()

>>> one_element = ("Guava",)
("Guava",)
```

Se pueden incluir estructuras de datos anidadas como elementos de una `tuple`, incluidas otras `tuples`:

```python
>>> nested_data_structures = ({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))
({"fish": "gold", "monkey": "brown", "parrot" : "grey"}, ("fish", "mammal", "bird"))

>>> nested_data_structures_1 = (["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
(["fish", "gold", "monkey", "brown", "parrot", "grey"], ("fish", "mammal", "bird"))
```

## Concatenación de tuplas

Las tuplas se pueden concatenar con el operador más `+`, que desempaqueta cada `tuple` y crea una nueva `tuple` combinada.

```python
>>> new_via_concatenate = ("George", 5) + ("cat", "Tabby")
("George", 5, "cat", "Tabby")

#likewise, using the multiplication operator * is the equivalent of using + n times
>>> first_group = ("cat", "dog", "elephant")

>>> multiplied_group = first_group * 3
('cat', 'dog', 'elephant', 'cat', 'dog', 'elephant', 'cat', 'dog', 'elephant')
```

## Acceder a los elementos de una tupla

Se puede acceder a los elementos de una `tuple` mediante _notación de corchetes_, usando un `0-based index` desde la izquierda o un `-1-based index` desde la derecha.

```python
student_info = ("Alyssa", "grade 3", "female", 8 )

#gender is at index 2 or index -2
>>> student_gender = student_info[2]
'female'

>>> student_gender = student_info[-2]
'female'

#name is at index 0 or index -4
>>> student_name = student_info[0]
Alyssa

>>> student_name = student_info[-4]
Alyssa
```

## Iterar sobre los elementos de una tupla

Se puede _iterar sobre_ los elementos de una `tuple` en un bucle con la sintaxis `for item in <tuple>`.
Si se necesitan tanto los índices como los valores, se puede usar `for index, item in enumerate(<tuple>)`.

```python
>>> student_info = ("Alyssa", "grade 3", "female", 8 )
>>> for item in student_info:
...   print(item)

...
Alyssa
grade 3
female
8

>>> for index, item in enumerate(student_info):
...  print("Index is: " + str(index) + ", value is: " + str(item) +".")

...
Index is: 0, value is: Alyssa.
Index is: 1, value is: grade 3.
Index is: 2, value is: female.
Index is: 3, value is: 8.
```

## Comprobar la pertenencia a una tupla

El operador `in` se puede usar para comprobar si un elemento pertenece a una `tuple`.

```python
>>> multiple_elements_list = tuple(["Parrot", "Bird", 334782])
("Parrot", "Bird", 334782)

>>> "Parrot" in multiple_elements_list
True
```
