# Acerca de

`case` es el selector múltiple basado en la igualdad de Factor. Es la herramienta adecuada cuando la elección depende de que un *único* valor sea igual a una de varias alternativas, no cuando cada rama necesita una condición distinta (para eso está `cond`).

```factor
USING: combinators ;

SYMBOLS: yes no maybe ;

: invert ( ?/maybe -- ?'/maybe )
    {
        { yes [ no ] }
        { no  [ yes ] }
        [ ]            ! default: leave value alone
    } case ;
```

Algunas cosas que conviene tener claras:

- La igualdad se comprueba con `=`. Cualquier cosa que funcione con `=` sirve como clave: números, strings, caracteres, símbolos e incluso tuplas.
- Las ramas que *coinciden* ven la pila *sin* el valor de entrada. Las ramas *por defecto* lo siguen viendo en la parte superior.
- Un `case` sin rama por defecto y sin ninguna cláusula que coincida lanza un error.

`case` se compila a una tabla de saltos cuando es posible, así que no es solo azúcar sintáctico para una cadena de `if`: también es rápido.
