# Instrucciones adicionales

## Instrucciones específicas de SML

Los árboles binarios de búsqueda son útiles para cualquier tipo de datos ordenado, no solo para números.

La sección 2.6 de [Notes on Programming SML/NJ][notes] trata el polimorfismo, y la sección 4.1 trata el uso de las funciones _compare_.

[notes]: https://www.cs.cornell.edu/riccardo/prog-smlnj/notes-011001.pdf
