# Acerca de

Los Custom Types son la forma en que Gleam define nuevos tipos de datos. Pueden tener varias _variantes_, cada una con su propio nombre.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de un custom type puede contener datos de forma opcional, y casos distintos pueden tener distintos tipos de datos. Cuando una variante contiene datos, se denomina _record_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Puedes crear un valor para un caso concreto refiriéndote a su nombre si no contiene datos adicionales (`Spring`), o llamándolo como si fuera una función si los contiene (`SomeInt(2)`).

```gleam
let spring = Spring
let integer_two = SomeInt(2)
```

Los custom types, al igual que todo lo demás en Gleam, tienen _igualdad estructural_, lo que significa que dos valores de la misma variante y con los mismos datos son equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Se puede hacer pattern matching sobre las variantes de un custom type usando expresiones case.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
