# no uses funciones de arrays

No uses ningún módulo externo (como List, Enum o Stream) en tu implementación. El objetivo de este ejercicio es que crees tú mismo estas funciones básicas. Puedes usar funciones básicas de Kernel (como `Kernel.+/2` para sumar números), pero no uses funciones de Kernel para arrays como `++`, `--`, `hd`, `tl`, `in`, `for` y `length`.
