# Recursos

* [The Rust Programming Language](https://doc.rust-lang.org/book/) es un recurso excelente para empezar con Rust y también para profundizar en funcionalidades concretas del lenguaje.
* [Rust by Example](https://doc.rust-lang.org/stable/rust-by-example/) te muestra ejemplos de las cosas más habituales que escribirás en Rust.
* La [Rust API Documentation](http://doc.rust-lang.org/std/) te sirve para descubrir nuevos métodos y cómo funcionan.
* En [Stack Overflow](http://stackoverflow.com/questions/tagged/rust) puedes buscar tu problema y ver si ya se ha respondido. También puedes plantear preguntas y responder a las de otras personas.
* El [Rust User Forum](http://users.rust-lang.org) es para conversar en general sobre Rust.
* [/r/rust](http://www.reddit.com/r/rust/) es el subreddit oficial de Rust.
* El servidor oficial de [The Rust Programming Language](https://discord.gg/rust-lang) en [Discord](https://discordapp.com/) te sirve para hacer consultas rápidas y charlar sobre el lenguaje.
