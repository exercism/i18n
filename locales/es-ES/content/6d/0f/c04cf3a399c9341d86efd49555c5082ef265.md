# Introducción

## IO

El módulo `IO` proporciona funciones para manejar la entrada y la salida.

### Salida

Para escribir un string en la salida estándar, usa `IO.puts`. `IO.puts` siempre añade una nueva línea al final del string. Si no quieres ese comportamiento, usa `IO.write` en su lugar. Ambas funciones devuelven el átomo `:ok` si tienen éxito.

```elixir
IO.puts("Hi!")
# > Hi!
# => :ok
```

`IO.puts` es útil para escribir strings, pero no mucho más. Si necesitas una herramienta de depuración que te permita escribir cualquier valor en la salida estándar, usa `IO.inspect` en su lugar. `IO.inspect` devuelve el valor que se le pasó sin cambios, por lo que se puede insertar en cualquier punto de tu código. También acepta muchas opciones, por ejemplo `:label`, que te permitirán distinguirlo de otras llamadas a `IO.inspect`.

### Entrada

Para leer una línea de la entrada estándar, usa `IO.gets`. `IO.gets` acepta un argumento: un string que imprimirá como solicitud para la entrada. `IO.gets` no añade una nueva línea después de la solicitud; inclúyela tú mismo si la necesitas.

```elixir
IO.gets("What's your name?\n")
# > What's your name?
# < Mary
# => "Mary\n"
```
