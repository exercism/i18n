# Acerca de

Erlang es un lenguaje de programación funcional que se usa para crear sistemas distribuidos en tiempo real, capaces de escalar fácilmente de tamaño.

Es ideal para aplicaciones concurrentes, como las plataformas de mensajería instantánea y de banca, ya que cada llamada a función tiene su propio proceso y funciona de forma independiente.
Esto es útil porque el código puede ejecutarse durante mucho tiempo sin que surjan problemas.
Además, los procesos y el paso de mensajes vienen integrados en el lenguaje de forma predeterminada, ¡no necesitas ninguna biblioteca adicional!

Se diseñó en Ericsson, una empresa sueca de telecomunicaciones, para utilizarlo en sus redes, y actualmente se usa en equipos de telecomunicaciones.
