# Aprender

## Primeros pasos con Emacs

Ya has instalado Emacs. ¿Y ahora qué?

Puedes empezar el tutorial pulsando `C-h t`, y no es un mal punto de partida. El tutorial te enseñará lo básico sobre edición, búsqueda y navegación en Emacs.

Si eres completamente nuevo en Emacs, puede tener sentido hacerte con un starter kit, que ya viene con un conjunto de configuraciones y paquetes preparados.

El paquete [Emacs Prelude](http://batsov.com/prelude/) ofrece un buen conjunto de valores predeterminados sensatos y paquetes.

Para instalar Emacs Prelude, ejecuta lo siguiente en un terminal:

```
curl -L https://github.com/bbatsov/prelude/raw/master/utils/installer.sh | sh
```

y no te olvides de consultar la [guía de instalación](https://prelude.emacsredux.com/en/latest/installation/) para obtener más instrucciones.


Si estás familiarizado con vim, quizá te interese el starter kit [Doom Emacs](https://github.com/doomemacs/doomemacs), que integra emulación de vim gracias a [evil-mode](https://github.com/emacs-evil/evil).

Para instalar Doom Emacs, ejecuta lo siguiente en un terminal:

```
git clone --depth 1 https://github.com/doomemacs/doomemacs ~/.emacs.d
~/.emacs.d/bin/doom install
```

y no te olvides de consultar la [guía de instalación](https://github.com/doomemacs/doomemacs#install) para obtener más instrucciones.

## Configurar la comprobación de sintaxis y el linting

Se recomienda configurar la comprobación de sintaxis y el linting con [Flycheck](https://www.flycheck.org/en/latest/).

Si aún no has añadido el repositorio [MELPA](https://melpa.org/) a tu Emacs, hazlo añadiendo lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(require 'package)

(add-to-list 'package-archives
             '("MELPA Stable" . "https://stable.melpa.org/packages/") t)
(package-initialize)
(package-refresh-contents)
```

La instalación y la configuración de Flycheck sin [use-package](https://github.com/jwiegley/use-package) se hacen añadiendo lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(package-install 'flycheck)
(add-hook 'after-init-hook #'global-flycheck-mode)
```

La instalación y la configuración de Flycheck con [use-package](https://github.com/jwiegley/use-package) se hacen añadiendo lo siguiente a tu [archivo de inicialización](https://www.flycheck.org/en/latest/glossary.html#term-init-file)

```elisp
(use-package flycheck
  :ensure t
  :init (global-flycheck-mode))
```

Para obtener más información y resolver problemas, consulta la [documentación de Flycheck](https://www.flycheck.org/en/latest/user/troubleshooting.html).

## Aprender Emacs Lisp

La mejor documentación sobre Emacs Lisp es... ¡la que viene incluida con el propio Emacs! Para acceder a la
[Emacs Lisp Reference](https://www.gnu.org/software/emacs/manual/elisp.html),
escribe `C-h i` y busca la entrada de Elisp, o selecciona Help &rarr; More Manuals
&rarr; Emacs Lisp Reference. Ten en cuenta que el manual puede faltar en algunas
distribuciones; en ese caso, puedes encontrarlo
[en línea](https://www.gnu.org/software/emacs/manual/elisp.html).

Si eres totalmente nuevo en Elisp, puedes leer la
[Introduction to Emacs Lisp](http://www.emacswiki.org/emacs/EmacsLispIntro),
que se abre de la misma forma.

## Buenas prácticas y convenciones de Emacs Lisp

El manual de Emacs contiene una sección sobre [Coding Conventions](https://www.gnu.org/software/emacs/manual/html_node/elisp/Coding-Conventions.html) de Emacs Lisp.
También hay una [Style Guide](https://github.com/bbatsov/emacs-lisp-style-guide) mantenida por la comunidad en GitHub.
