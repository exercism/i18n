# Acerca de

Un conjunto es una colección de valores únicos. La implementación predeterminada de un conjunto en .NET es [`HashSet<T>`][HashSet].

La clase `HashSet` usa el [método `GetHashCode()`][GetHashCode] de cada elemento.

De forma predeterminada, la implementación de `GetHashCode()` para los tipos de referencia devuelve un hash de su ubicación en memoria. Esto significa que distintos objetos de tipo de referencia tendrán un código hash diferente (esto se conoce como igualdad de referencia). Los tipos de valor devuelven de forma predeterminada un hash de sus campos/propiedades. Esto significa que distintos objetos de tipo de valor con los mismos valores en sus campos/propiedades tendrán el mismo código hash (esto se conoce como igualdad estructural).

Puedes sobrescribir la implementación de `GetHashCode()` en tus propias clases, lo que podrías usar para conseguir que un tipo de referencia tenga igualdad estructural.

[GetHashCode]: https://docs.microsoft.com/en-us/dotnet/api/system.object.gethashcode
