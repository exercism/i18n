# Introducción

Las tuplas son una forma ligera de agrupar un conjunto fijo de datos de tipos arbitrarios.
Las tuplas pueden tener un número arbitrario de elementos.
Puedes acceder a los elementos mediante desestructuración.

```rust
fn main() {
    let tup: (u32, u64, bool) = (10, 20, true);
}

fn main() {
    let (x, y, z) = (500, 6, true);

    if y == 6 {
        println!("y is 6!");
    }
}
