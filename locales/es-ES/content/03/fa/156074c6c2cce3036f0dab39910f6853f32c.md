# Instrucciones

La empresa para la que trabajas quiere reducir su huella de carbono, así que quieren que escribas un programa que calcule el consumo de energía y el coste de hacer funcionar sus aparatos electrónicos.

## 1. Obtener las horas extra

Tu empleador tiene un programa que calcula el tiempo que se tarda en hacer funcionar distintos aparatos electrónicos.
Actualmente, el tiempo se almacena en horas.
Cuando tu empleador sumó las horas, se dio cuenta de que la duración no era correcta.
Quieren que añadas 3 horas extra a los datos de tiempo.
También les gustaría saber cuántas horas «extra» hay tras convertir los datos a días «completos» (un día son 24 horas).
Es posible que el tiempo que hay que convertir no esté en días completos.

Implementa una función `get_extra_hours()` que acepte un número entero que contenga el número de horas.
La función debe hacer el ajuste correspondiente de «horas extra» y, a continuación, devolver con `return` un número entero que represente cuántas horas hay que quitar del total para obtener el tiempo en días «completos».

```python
>>> get_extra_hours(25)
4
```

## 2. Obtener el valor en kW

Tu empleador quiere conocer el consumo de energía de los distintos aparatos electrónicos en kW.
kW significa kilovatio; el vatio es una unidad de potencia.
Kilo, en el nombre de la unidad, es un prefijo del sistema métrico que significa 1000.
Un kilovatio == 1000 vatios.

Implementa una función `get_kW_value()` que acepte un número entero que contenga el número de vatios.
La función debe devolver con `return` los vatios como kilovatios, redondeados a 1 decimal.

```python
>>> get_kW_value(1150)
1.2
```

## 3. Obtener el valor en kWh

Para poder calcular el coste de hacer funcionar los aparatos electrónicos, tu empleador necesita conocer el consumo de energía en kWh.
kWh significa kilovatio-hora, donde la hora es una unidad de tiempo.
Un kilovatio-hora == 1000 vatios utilizados durante 1 hora.
Una hora se compone de 60 minutos y un minuto se compone de 60 segundos.
Una hora equivale a 3600 segundos.
Para calcular el valor en kWh, debes convertir los vatios a kW y, a continuación, hacer una división entera del resultado entre 3600.

Implementa una función `get_kWh_value()` que acepte un número entero que contenga el número de vatios.
La función debe devolver con `return` los kilovatios-hora como un número entero.

```python
>>> get_kWh_value(5000000)
1
```

## 4. Obtener la eficiencia

Los aparatos electrónicos no son 100 % eficientes.
Por lo tanto, tu empleador quiere que calcules la _eficiencia_ de los aparatos electrónicos.
Para obtener la eficiencia, debes dividir el factor de potencia (_un número decimal entre 0 y 100_) entre 100.

Implementa una función `get_efficiency()` que acepte un número decimal que contenga el factor de potencia.
La función debe devolver con `return` la eficiencia calculada como un número decimal.

```python
>>> get_efficiency(80)
0.8
```

## 5. Obtener el coste

Tu empleador quiere conocer el coste de hacer funcionar los aparatos electrónicos.
El coste de hacer funcionar los aparatos electrónicos es la potencia utilizada multiplicada por el coste por kWh.
La potencia utilizada es la potencia dada dividida entre la eficiencia calculada.

Implementa una función `get_cost(<watts>,<power_factor>,<price>)` que acepte un número entero que contenga el número de vatios, un número decimal que tenga el factor de potencia y un número decimal que contenga el coste por kWh.
La función debe devolver con `return` el coste de hacer funcionar los aparatos electrónicos como un número decimal.

```python
>>> get_cost(5000000, 80, 0.25)
0.3125
```
