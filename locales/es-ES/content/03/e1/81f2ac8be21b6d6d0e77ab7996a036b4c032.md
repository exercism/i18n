# Apéndice de instrucciones

## Pistas

Para este ejercicio, la siguiente funcionalidad de F# resulta útil:

- [Secuencias](https://docs.microsoft.com/en-us/dotnet/articles/fsharp/language-reference/sequences) se evalúan de forma perezosa. Te permiten trabajar con una secuencia infinita de valores.

Nota: para acelerar el cálculo, no deberías comprobar números que sabes de antemano que nunca serán primos. Para más información, consulta la [criba de Eratóstenes](https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes).
