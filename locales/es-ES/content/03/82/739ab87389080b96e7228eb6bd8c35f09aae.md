# Instrucciones

Ellen está creando un juego en el que el jugador tiene que luchar contra alienígenas.
Acaba de aprender programación orientada a objetos (POO) y está deseosa de aprovechar lo que el uso de `classes` podría ofrecer a su programa.

Para alegría de Ellen, te has ofrecido a ayudarla y ella te ha encargado programar los alienígenas contra los que tiene que luchar el jugador.


## 1. Crea la clase `Alien`

Define la clase `Alien` con un constructor que acepte dos parámetros `int`, `x` e `y`, y los guarde en las variables miembro `x_coordinate` y `y_coordinate`.
Cada alienígena también empezará con un nivel de salud de `3`, así que la variable miembro `health` también debe inicializarse.

`health` debe ser una variable miembro privada.
Para que otras partes del programa puedan leer la información de salud, Ellen quiere tener un método `public` `get_health()` que devuelva un `int`.

```cpp
Alien alien{2, 0};
alien.x_coordinate;
// => 2
alien.y_coordinate;
// => 0
alien.get_health();
// => 3
```

Ahora, cada alienígena debe ser capaz de llevar internamente un seguimiento de su propia posición y su propia salud.

## 2. La función `hit`

A Ellen le gustaría que la `class` Alien tuviera un método `hit` que reduzca en `1` la salud de un objeto alienígena cuando se llame.
Así, puede simplemente llamar a `some_alien_instance.hit()` en lugar de tener que cambiar manualmente la salud de un alienígena.
Asegúrate de que los puntos de salud no bajen por debajo de cero.
La función debe devolver `true`.
Ellen quiere introducir escudos más adelante, que en ese caso devolverían `false` si el escudo está activo.

```cpp
Alien alien {0, 0};
alien.get_health();
// => 3 (Initial health value)

alien.hit(); // Decrements health by 1 point.
alien.get_health();
// => 2
```

## 3. La función `is_alive`

Te das cuenta de que, si la salud sigue disminuyendo, en algún momento probablemente llegará a `0`.
Sería buena idea añadir un método `is_alive` al que Ellen pueda llamar rápidamente para comprobar si el alienígena está... bueno... vivo. 😉
`some_alien_instance.is_alive()` debe devolver un Boolean.

```cpp
alien.get_health();
// => 1
alien.is_alive();
// => true
alien.hit();
alien.get_health();
// => 0
alien.is_alive();
// => false
```

## 4. La función `teleport`

¡En el juego de Ellen, los alienígenas pueden teletransportarse!
Tendrás que escribir un método `teleport` que reciba los valores `x_new` y `y_new` y cambie las coordenadas del alienígena en consecuencia.
Por ahora, la función debe devolver `true`.
Ellen quiere añadir bombas que bloqueen el teletransporte en niveles posteriores, que en ese caso devolverían `false` para los intentos de teletransporte fallidos.

```cpp
alien.teleport(5, -4);
alien.x_coordinate;
// => 5
alien.y_coordinate;
// => -4
```

## 5. La función `collision_detection`

Si algo puede golpear a los alienígenas, entonces estos tienen que ser capaces de detectar cuándo podría producirse esa colisión.
Ellen necesita saber si dos alienígenas ocupan las mismas coordenadas.
La función `collision_detection()` recibe otro objeto alienígena como argumento y devuelve un `bool`.

```cpp
Alien lrrr {3, 6};
Alien ndnd {-2, 12};
lrrr.collision_detection(ndnd);
// => false
ndnd.teleport(3, 6);
ndnd.collision_detection(lrrr);
// => true
```
