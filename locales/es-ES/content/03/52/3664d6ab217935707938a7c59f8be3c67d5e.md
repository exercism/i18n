# Pistas

## General

## 1. Comprueba cuáles fueron los recuentos la semana pasada

- Devuelve el _penúltimo_ elemento del array.

## 2. Comprueba cuántos pájaros visitaron ayer

- Como los datos son un array de arrays, tendrás que indexar una vez para obtener el array semanal correcto y, después, indexar de nuevo para obtener el día que quieres.
- «Hoy» es el último elemento del array semanal.

## 3. Calcula el número total de pájaros visitantes

- Es posible calcular la suma de un array con el filtro [add][manual-add].
  Viste esta expresión en el concepto Fundamentos y en el ejercicio Compras.

## 4. Calcula el número de días ocupados

- Tendrás que _seleccionar_ los días cuyo recuento sea mayor o igual que 5 y, después, devolver el tamaño del array resultante.

## 5. Comprueba si hubo un día sin pájaros visitantes

- La versión de un solo argumento del filtro [any][manual-any] será la adecuada.

[manual-add]: https://jqlang.org/manual/#add
[manual-any]: https://jqlang.org/manual/#any
