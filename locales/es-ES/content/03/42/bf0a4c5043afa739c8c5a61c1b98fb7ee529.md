# Instrucciones

El ejercicio introductorio clásico. Solo tienes que decir «Hello, World!».

["Hello, World!"](http://en.wikipedia.org/wiki/%22Hello,_world!%22_program) es el primer programa tradicional para empezar a programar en un lenguaje o un entorno nuevos.

Los objetivos son sencillos:

- Modifica el código proporcionado para que produzca el string «Hello, World!».
- Ejecuta la suite de tests y asegúrate de que pasa.
- Envía tu solución y compruébala en la web.

Si todo va bien, estarás listo para descargar tu primer ejercicio real.
