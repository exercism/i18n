# Instrucciones

El departamento de reclamaciones de Isaac's Asteroid Exploration Co. te ha encargado mejorar el rendimiento de su sistema de reclamación de tierras.

Cada vez que un asteroide está listo para su explotación, se invita a los especuladores a registrar su reclamación sobre una parcela de terreno.
La tierra del asteroide se divide en parcelas rectangulares que no se solapan.
Las dimensiones varían, pero todas tienen los lados paralelos a los ejes de coordenadas.
Los especuladores reclaman una de las parcelas indicando sus coordenadas.

Tu objetivo es desarrollar un sistema eficiente que gestione la avalancha de reclamaciones que en el pasado ha hecho caer la web.

La unidad de medida es 100 metros, pero puedes ignorarla en estas tareas.

## 1. Define un punto

Define una `struct` para almacenar las coordenadas `x` e `y`.
Son números enteros no negativos bastante pequeños, así que usa el tipo `UInt16`.

```julia-repl
julia> Coord(7, 3)
Coord(0x0007, 0x0003)  # unsigned integers display in hex format by default
```

## 2. Define Plot

Como todas las parcelas deben ser rectangulares, con lados horizontales y verticales, solo se necesitan dos esquinas opuestas para definirlas.

Implementa la `struct` `Plot`, que recibe dos structs Coord en su constructor.

`Plot` debe ser una struct de argumentos de palabra clave, con los campos `bottom_left` y `top_right`.

```julia-repl
julia> plot = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2))
Plot(Coord(0x000a, 0x0001), Coord(0x0014, 0x0002))

julia> plot.top_right
Coord(0x0014, 0x0002)
```

## 3. Comprueba si tu reclamación ya está registrada

Hay competencia por estas reclamaciones, así que antes de aceptar la tuya se comprobará con las reclamaciones que ya están en el registro.

Implementa la función `is_claim_staked()` para determinar si una reclamación ya ha sido registrada.

```julia-repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> is_claim_staked(claim, register)
false
```

## 4. Los especuladores pueden registrar su reclamación indicando una parcela identificada por las coordenadas de sus esquinas

Implementa la función mutadora `stake_claim!()` para permitir que se registre una reclamación.

Si la misma reclamación ya ha sido registrada, devuelve `false`.

Si la reclamación es nueva, añádela al registro y devuelve `true`.

```julia_repl
julia> claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));
julia> register = Set{Plot}();
julia> stake_claim!(claim, register)
true
```

## 5. Averigua la longitud del lado más largo de una parcela.

Implementa la función `get_longest_side()` para obtener el lado más largo (horizontal o vertical) de una reclamación.

```julia-repl
claim = Plot(bottom_left=Coord(10, 1), top_right=Coord(20, 2));

julia> get_longest_side(claim)
0x000a
```

## 6. Averigua la parcela reclamada con el lado más largo, con fines de investigación

Implementa la función `get_claim_with_longest_side()` para examinar todas las reclamaciones registradas y devolver la reclamación o reclamaciones con el lado más largo.

```julia-repl
julia> plot1 = Plot(bottom_left=Coord(5, 3), top_right=Coord(10, 5));
julia> plot2 = Plot(bottom_left=Coord(0, 0), top_right=Coord(3, 3));
julia> register = Set{Plot}([plot1, plot2]);

julia> get_claim_with_longest_side(register)
Plot(Coord(0x0005, 0x0003), Coord(0x000a, 0x0005))
```

Devuelve la o las `Plot` como un `Set`, con un elemento si hay una sola parcela más larga y varios en caso de empate.
