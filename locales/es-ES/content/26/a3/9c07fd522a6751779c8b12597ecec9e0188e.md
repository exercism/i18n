# Instrucciones

Como casi cualquier persona con un trabajo, Layla, la alienígena de Lisp, a veces necesita hacer informes para que los demás conozcan cierta información. Te pregunta si puedes ayudarla a dar formato a los datos que tiene para estos informes.

## 1. Dar formato a valores trimestrales

Lo primero que necesita Layla es una función: `format-quarter-value`, que toma dos parámetros, el trimestre del calendario y el valor, y les da formato para un informe. Debe evaluarse a un string.

```lisp
(format-quarter-value "last" 3.14) ; => "The value last quarter: 3.14"
(format-quarter-value "this" 0) ; => "The value this quarter: 0"
```

## 2. El informe de dos trimestres

Layla te da las gracias por la función `format-quarter-value` y dice que será muy útil en la *siguiente* función que se necesita.

El siguiente informe debe mostrar el trimestre y el valor de 2 trimestres impresos en dos líneas.

Además, la salida debe ir al stream proporcionado como primer argumento.

Por ejemplo: `(format-two-quarters t "last" 3.14 "this" 0)` producirá lo siguiente en la salida estándar:

```

The value last quarter: 3.14
The value this quarter: 0

```

Fíjate en las líneas en blanco que lo rodean.

## 3. Legible para humanos y para alienígenas de Lisp

Layla olvidó decirte que a los alienígenas de Lisp les gusta ver los valores de una forma que sea legible como datos de Lisp. Así que necesitan una nueva función cuyo resultado pueda leerse como datos de Lisp (de nuevo, en el stream indicado):

```lisp
(format-two-quarters-for-reading nil "last" 3.14 "this" 0) ; =>

"(\"The value last quarter: 3.14\" \"The value this quarter: 0\")"
```
