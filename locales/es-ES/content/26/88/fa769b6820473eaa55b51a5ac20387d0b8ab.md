# Pistas

## 1. Estima el tiempo de preparación

- Usa la [función incorporada `len()`][len-builtin] para determinar el número de capas (la longitud del slice de capas).

## 2. Calcula las cantidades necesarias de fideos y salsa

- Primero, declara dos variables para llevar la cuenta de la cantidad de fideos y salsa.
- Usa un bucle `for` para recorrer las capas.
- Si encuentras una capa `'noodles'` o `'sauce'` en el bucle, aumenta en consecuencia la cantidad almacenada en la variable correspondiente.

## 3. Añade el ingrediente secreto

- Vuelve a consultar [slices][concept-slices] para descubrir cómo obtener un elemento de un slice y cómo reemplazar un elemento en un slice.
- El índice del último elemento de un slice `a` es `len(a) - 1`.

## 4. Escala la receta

- Primero, crea un nuevo slice del mismo tamaño que el slice de entrada
- Usa un [bucle `for`][for-loop] para recorrer el slice de entrada y generar el slice de salida
