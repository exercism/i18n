# Anexo de instrucciones

## Palabras

Implementa:

- `grep ( pattern flags files -- lines )`

`pattern` es la cadena de búsqueda, `flags` es un array de cero o más cadenas de banderas `"-n"`, `"-l"`, `"-i"`, `"-v"` y `"-x"`, y `files` es un array de uno o más nombres de fichero. Devuelve las líneas coincidentes (con los prefijos de nombre de fichero y de número de línea que se hayan pedido) como un array de strings.

Cuando se da la bandera `-l`, devuelve un array con los nombres de los ficheros que contienen al menos una coincidencia.

## Lectura de ficheros

Lee las líneas de un fichero con `file-lines`, pasando una codificación:

```factor
USING: io.encodings.utf8 io.files ;

"iliad.txt" utf8 file-lines
! => { "Achilles sing, O Goddess! Peleus' son;" ... }
```

Los tres ficheros de prueba (`iliad.txt`, `midsummer-night.txt` y `paradise-lost.txt`) vienen con el ejercicio en el directorio de trabajo, así que puedes leerlos por su nombre sin más.
