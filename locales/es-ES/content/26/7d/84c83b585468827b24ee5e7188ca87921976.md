# Instrucciones

Un violín se afina de oído tomando como referencia una nota. Las cuerdas están muy alejadas entre sí en cuanto al tono, y los números que intervienen no son enteros.

Las cinco tareas van en la clase `TUNING_THE_STRINGS`.

## 1. Subir una octava

Una nota una octava más aguda tiene el doble de frecuencia.

```sather
TUNING_THE_STRINGS::octave_up(440.0d)
-- => 880.0d
```

## 2. Bajar una octava

Una octava más grave es la mitad.

```sather
TUNING_THE_STRINGS::octave_down(440.0d)
-- => 220.0d
```

## 3. El punto medio

Dadas dos frecuencias, devuelve la que está exactamente entre ellas.

```sather
TUNING_THE_STRINGS::midpoint(440.0d, 442.0d)
-- => 441.0d
```

## 4. ¿Cuánto difieren?

Cuando dos notas están cerca pero no son la misma, oyes un batido una vez por segundo por cada ciclo de diferencia. Devuelve cuánto distan las frecuencias. La respuesta nunca es negativa, sea cual sea la nota más aguda.

```sather
TUNING_THE_STRINGS::beats_per_second(441.5d, 440.0d)
-- => 1.5d
```

## 5. Repartir la práctica

Dados un número de minutos y un número de músicos, ¿cuántos minutos le tocan a cada uno? Los minutos y los músicos son números enteros, pero puede que la respuesta no lo sea.

```sather
TUNING_THE_STRINGS::minutes_each(45, 2)
-- => 22.5d
```
