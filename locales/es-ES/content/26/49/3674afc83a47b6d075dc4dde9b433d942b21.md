# Instalación

Este track se apoya en todo momento en [Wren Console][wren-console] para ofrecer un entorno de ejecución local para Wren. Esto significa que damos por hecho que toda ejecución de Wren en tu ordenador se hará con [Wren Console][wren-console]. Por favor, no lo confundas con la <abbr title="Interfaz de línea de comandos">CLI</abbr> oficial de Wren. En un mundo perfecto podrías usar ese entorno de ejecución, pero ahora mismo [tiene](https://github.com/wren-lang/wren-cli/pull/74) [varios](https://github.com/wren-lang/wren/pull/1006) [distintos](https://github.com/wren-lang/wren-cli/issues/108) [problemas](https://github.com/wren-lang/wren-cli/pull/105) que lo convierten en una opción poco óptima para aprender Wren con Exercism.

Wren Console deriva de Wren CLI, resuelve estos problemas y añade funcionalidades que hacen que tu experiencia de aprendizaje sea más fluida. No te preocupes: los conocimientos y conceptos del lenguaje Wren que aprendas aquí te servirán allí donde quieras usar Wren en el futuro.

## Resumen de la instalación

- Instala Git para tener el comando `git`
- Instala [Wren Console][wren-console] para tener el comando `wrenc`

### Instalar Git

Necesitarás el binario `git` instalado y disponible en tu PATH. Así es como Wren Package instala paquetes (como el conjunto de pruebas que necesitarás para probar tus ejercicios, etc.).

- **Windows**: la [descarga oficial de Git](https://git-scm.com/download/win) es un buen punto de partida.
- **Linux**: tu gestor de paquetes preferido debería ayudarte.
- **Mac**: todas las versiones recientes de Mac OS incluyen `git` de serie.

Puedes confirmar que Git está instalado con `git --version`:

```
$ git --version
git version 2.31.1
```

No te preocupes si la versión exacta no coincide; por lo general, esto no es tan importante.


### Instalar Wren Console

#### Windows

Lo más probable es que quieras [descargar la última versión][releases] desde GitHub. Después tendrás que descomprimirla y copiar el ejecutable `wrenc` en tu PATH.

También puedes [compilar desde el código fuente][build-from-source] usando Visual Studio.

#### Linux

Puedes [descargar la última versión][releases] desde GitHub o [compilar desde el código fuente][build-from-source].

```sh
wget -c https://github.com/joshgoebel/wren-console/releases/download/v0.3.1/wren-console-v0.3.1-linux.tar.gz
tar xzf wren-console-v0.3.1-linux.tar.gz
```

Y asegúrate de que está disponible en tu `PATH`.

```sh
cp bin/wrenc /usr/local/bin/
```


#### Mac

La instalación más sencilla es usar el tap y la fórmula de [Homebrew][homebrew] de Exercism:

```
brew tap exercism/wren
brew install wren-console
```

Como alternativa, puedes [descargar la última versión][releases] desde GitHub e instalarla manualmente como se muestra en las instrucciones para Linux. Compilar desde el código fuente también es bastante sencillo si estás familiarizado con este tipo de cosas.

### Probar la instalación

Cuando creas que has instalado el binario correctamente, conviene comprobar que todo funciona.

1. Abre un _terminal_ (`Terminal`, `cmd`, `Powershell`, `bash`, ...)
2. Ejecuta `wrenc -v`

Deberías ver tanto la versión de `wrenc` como la de Wren:

```
wrenc v0.3.1 (wren v0.4.0)
```

**Nota**: es importante que abras una ventana de terminal _nueva_. Es posible que las ventanas de terminal que ya tengas abiertas no se hayan actualizado al terminar la instalación. Eso significa que esos terminales no saben que se ha instalado un programa nuevo.

> _**Ayuda**_: `'wrenc' is not recognised`
>
> Probablemente no hayas colocado `wrenc` en tu PATH... En macOS y Linux puedes modificar tu PATH añadiendo lo siguiente a `~/.bash_profile` o a `~/.zshrc`:
>
> ```bash
> export PATH=/path/to/your/wrenc/:$PATH
> ```
> **No tengo ni idea de si algo de esto es correcto.**
> En Windows, abre el menú de inicio y busca «environment variables». Tendrás
> que editar la entrada `PATH` y _añadir_ aquí la ruta a los binarios de `wrenc`.
> Normalmente se encuentran en `C:\Program Files\nodejs`. Si navegas hasta ahí con
> tu `File Explorer`, deberías encontrar `node.exe`, `npm.bat` y `npx.bat`.
>
> Cierra todos los terminales que tengas abiertos y abre uno nuevo.

## Requisitos para los ejercicios

Sigue [estas instrucciones][cli-walkthrough] para descargar la CLI de `exercism` para tu sistema operativo.

Una vez que la CLI esté instalada y configurada, descarga el primer ejercicio, `hello-world`:

```bash
$ exercism download --exercise=hello-world --track=wren
```

Cada ejercicio necesita además algunos paquetes de Wren para ejecutar las pruebas. Puedes instalarlos ejecutando este comando dentro del directorio del ejercicio:

```bash
$ wrenc package.wren install
```
