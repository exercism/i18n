# Instrucciones

Un anagrama es una reordenación de las letras que forma una palabra nueva.
Dada una palabra y un array de candidatos, selecciona de entre ellos los que sean anagramas de la palabra dada.

Dados `"listen"` y un array de candidatos como `"enlists" "google"
"inlets" "banana"`, el programa debe devolver un array que contenga
`"inlets"`.
