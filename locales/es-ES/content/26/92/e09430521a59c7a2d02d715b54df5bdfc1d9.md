# Acerca de

Aunque lanzar un proceso es fácil, gestionar su estado y su comportamiento puede volverse muy complicado. El módulo [`Agent`][agent-module] es una abstracción que facilita la gestión de un estado compartido en un proceso de Elixir.

Cuando usas las funciones del módulo `Agent`, lo habitual es encapsular las funciones relacionadas con el agente en un único módulo.

```elixir
# A simple use of agent processes to represent a counter
defmodule Counter do
  def start_link(initial_value) do
    Agent.start(fn -> initial_value end)
  end

  def value(pid) do
    Agent.get(pid, & &1)
  end

  def increment(pid) do
    Agent.update(pid, &(&1 + 1))
  end
end
```

La decisión de usar el módulo `Agent`, o de usar varios procesos en general, depende de la relación que se quiera modelar con los datos. Los _procesos agente_ son útiles cuando varios procesos necesitan usar un estado compartido.

A menudo es mejor opción evitar usar un proceso aparte y usar una variable dentro del propio proceso para mantener el estado en una función. También conviene tener cuidado y no tratarlos sin más como una variable global, ya que otros procesos pueden manipularlos y crear condiciones de carrera o errores imposibles de rastrear.

Si decides usar un _proceso agente_, el objetivo debería ser mantener un estado sencillo, encapsulando las llamadas al _proceso agente_ en un módulo para organizar esas llamadas.

Si hay que hacer un trabajo costoso en otro proceso, conviene plantearte un _proceso de tarea_ (usando [`Task`][task-module]). Si se determina que un proceso debe mantener estado y realizar comportamientos, conviene plantearte un _proceso GenServer_ (usando [`GenServer`][genserver-module]).
