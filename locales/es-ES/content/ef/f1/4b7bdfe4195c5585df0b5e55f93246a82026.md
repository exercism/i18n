# Acerca de

En Common Lisp, todo es una expresión.
Una expresión es o bien una única cosa (llamada átomo) o una lista de cosas (delimitadas por paréntesis: `()`).

## Citar

Todas las S-expressions, como los símbolos, se pueden citar:

```lisp
;; This line is evaluated as code
(gimme-foo)  ; => FOO

;; This line is treated as data
'(gimme-foo) ; => (GIMME-FOO)
```

Esta cita impide la evaluación de una S-expression y, en su lugar, la trata como datos.
Aquí tienes una excelente [respuesta de Stack Overflow][so-quoting] que trata las citas con un poco más de detalle.

[so-quoting]: https://stackoverflow.com/questions/134887/when-to-use-or-quote-in-lisp
