# Pruebas

Para ejecutar las pruebas de tus ejercicios de SQLite, sigue estos pasos:

1. Abre la terminal que prefieras.
2. Ve al directorio que contiene el fichero `${slug}_test.sql` correspondiente, donde `${slug}` es el nombre del ejercicio, con guiones en lugar de espacios y todo en minúsculas.
3. Ejecuta el siguiente comando: 
```bash
sqlite3 -bail < ${slug}_test.sql
```
  
Este comando inicializa SQLite con una base de datos vacía, ejecuta las pruebas especificadas en `${slug}_test.sql` y sale al terminar.
`-bail` hace que la ejecución del código se detenga cuando el código no es válido.

Los resultados de las pruebas se muestran en la consola como una tabla, con la descripción de cada prueba, su estado (por ejemplo, "pass") y un mensaje si el estado es "fail".

## Depuración

Puedes usar instrucciones `SELECT` para depurar.
La salida se enviará a `user_output.md` y se mostrará en el editor web si las pruebas fallan.

## Detalles de ejecución

El fichero de pruebas (`${slug}_test.sql`) es un script bastante complejo.
Aquí tienes una visión general de lo que hace.

1. Crea las tablas leyendo `create_fixture.sql`.
   Esto crea las tablas y luego las rellena con valores de `data.csv` para los datos válidos y de `error_data.csv` para las entradas que deberían fallar.
   Durante las pruebas solo se comprueban esas tablas; los cambios en otras tablas se ignoran.
2. Ejecuta el código de la solución leyendo el fichero `${slug}.sql`.
3. Crea tablas para almacenar los casos de prueba y los resultados.
4. Rellena los resultados de las pruebas a partir de los datos de la tabla o las tablas que actualiza la solución.
5. Muestra los resultados de las pruebas (pass o fail y detalles opcionales).
Estos ficheros CSV contienen los datos necesarios para probar diversos escenarios.
