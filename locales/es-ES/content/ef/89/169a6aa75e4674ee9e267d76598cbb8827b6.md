# Instrucciones

Tu trabajo en la tienda de moda online continúa. Se te ocurre la idea de una funcionalidad del sitio web en la que se sugiere un conjunto al usuario. Aunque quieres dar muchas sugerencias, no quieres dar sugerencias malas, así que decides usar una comprensión de listas, ya que puedes _generar_ fácilmente combinaciones de conjuntos y luego _filtrarlas_ según algunos criterios.

Las prendas de ropa se almacenan como un mapa:

```elixir
%{
  item_name: "Descriptive Name",
  price: 99.00,
  color: "Ochre Red",
  base_color: "red"
}
```

## 1. Sugiere una combinación

Implementa `get_combinations/3` para que reciba un array de prendas superiores, un array de prendas inferiores y una lista de palabras clave de opciones. Por ahora, haz que las opciones tengan como valor predeterminado una lista de palabras clave vacía. La función debe devolver el producto cartesiano de los arrays.

```elixir
tops = [
  %{item_name: "Dress shirt"},
  %{item_name: "Casual shirt"}
]

bottoms = [
  %{item_name: "Jeans"},
  %{item_name: "Dress trousers"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Dress shirt"}, %{item_name: "Dress trousers"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Jeans"}},
#      {%{item_name: "Casual shirt"}, %{item_name: "Dress trousers"}}
#    ]
```

## 2. Filtra los conjuntos que desentonan

Cada prenda de ropa tiene un campo `:base_color`; usa este campo para filtrar todas las combinaciones en las que la prenda superior y la inferior tengan el mismo color base.

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue"},
  %{item_name: "Casual shirt", base_color: "black"}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue"},
  %{item_name: "Dress trousers", base_color: "black"}
]

BoutiqueSuggestions.get_combinations(tops, bottoms)
# => [
#      {%{item_name: "Dress shirt", base_color: "blue"},
#       %{item_name: "Dress trousers", base_color: "black"}},
#      {%{item_name: "Casual shirt", base_color: "black"},
#       %{item_name: "Jeans", base_color: "blue"}}
#    ]
```

## 3. Filtra por el precio del conjunto

Cada prenda de ropa tiene asociado un campo `:price`. Aunque quieres dar muchas sugerencias, quieres poder ofrecer a los usuarios la oportunidad de seleccionar un precio que se ajuste a su presupuesto. De la lista de palabras clave de opciones, usa `:maximum_price` para filtrar las combinaciones en las que el precio de la prenda superior y de la inferior supere el precio máximo.

Si no se especifica maximum_price, el valor predeterminado debe ser `100.00`

```elixir
tops = [
  %{item_name: "Dress shirt", base_color: "blue", price: 35},
  %{item_name: "Casual shirt", base_color: "black", price: 20}
]

bottoms = [
  %{item_name: "Jeans", base_color: "blue", price: 30},
  %{item_name: "Dress trousers", base_color: "black", price: 75}
]

BoutiqueSuggestions.get_combinations(tops, bottoms, maximum_price: 50)
# => [
#      {%{item_name: "Casual shirt", base_color: "black", price: 20},
#       %{item_name: "Jeans", base_color: "blue", price: 30}}
#    ]
```
