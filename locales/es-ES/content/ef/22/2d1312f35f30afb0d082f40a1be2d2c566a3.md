# Pistas

## General

- Usa `?` para trabajar con los [puntos de código][codepoint] de los caracteres.
- Puedes usar `\s` para representar un espacio.
- Usa la notación abreviada de [literal entero binario][integer-literal] para trabajar con los códigos.
- Intenta usar la estrategia de recursión de cola.

## 3. Codifica una charlist de ADN

- Crea una función recursiva de cola que tome un punto de código de la charlist y construya recursivamente el bitstring resultante.
- Las funciones recursivas de cola necesitan un acumulador.
- Recuerda que una [charlist][charlist] es una lista de [puntos de código enteros][codepoint].
- Puedes obtener el primer elemento y los restantes de una lista usando una función integrada del [módulo `Kernel`][kernel].
- También puedes hacer coincidencia de patrones en una lista usando la notación [`[head | tail]`][list].
- Usa funciones con múltiples cláusulas para separar el caso base de los casos recursivos.
- No olvides especificar los tipos de los segmentos del bitstring con el operador `::`.

## 4. Decodifica un bitstring de ADN

- Crea una función recursiva de cola que [coincida con los primeros 4 bits][bitstring-matching] del [bitstring][bitstring] y construya recursivamente el resultado de la [charlist][charlist].
- Las funciones recursivas de cola necesitan un acumulador.
- Recuerda que la [forma especial bitstring][bitstring-form] se puede usar para hacer coincidencia de patrones sobre bitstrings.
- No olvides especificar los tipos de los segmentos del bitstring con el operador `::`.
- Tendrás que invertir el acumulador al final. Escribe una función `reverse` privada y recursiva de cola para hacerlo, y úsala en el caso base de la función `decode`.
