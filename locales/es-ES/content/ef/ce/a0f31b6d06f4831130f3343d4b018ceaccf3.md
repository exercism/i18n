# Bools

Crystal tiene un tipo conocido como [`Bool`][bools].
Representa los valores `true` y `false`.

## Operadores lógicos

Crystal tiene tres operadores lógicos (`!`, `||`, `&&`), que combinan Bools y crean expresiones que producen valores distintos.

### And(`&&`)

El [operador _and_][and] en Crystal se representa con `&&` y devuelve `true` si ambos valores son `true`; en caso contrario, devuelve `false`.
Al usar el operador _and_, un Bool se coloca a la derecha del `&&` y otro a la izquierda.

```crystal
true && true
# => true

true && false
# => false
```

### Or(`||`)

El [operador _or_][or] en Crystal se representa con `||` y devuelve `true` si **al menos uno** de los valores dados es `true`.
Si ambos valores son `false`, devuelve `false`.
Al usar el operador _or_, un Bool debe colocarse a la derecha del `||` y otro a la izquierda.

```crystal
true || true
# => true

true || false
# => true

false || false
# => false
```

### Not(`!`)

El operador _not_ en Crystal se representa con `!` y devuelve `true` si el Bool dado es `false`, y devuelve `false` si se le pasa `true`.
Al usar el operador _not_, un Bool debe colocarse después del operador (`!`).

```crystal
!true
# => false

!false
# => true
```

## Usar paréntesis(`()`)

Al trabajar con booleanos, puedes usar paréntesis para decidir qué Bools se evalúan primero.
El resultado puede variar según cómo se usen los paréntesis.
En Crystal, lo que está entre paréntesis se evalúa primero.

```crystal
true && false && false || true
# => true

true && false && (false || true)
# => false
```

Como lo que está entre paréntesis se evalúa primero, en el siguiente ejemplo el operador _not_ se aplicará a la expresión que hay dentro de los paréntesis.

```crystal
!true && false
# => false

!(true && false)
# => true
```

~~~~exercism/note
Solo deberías usar paréntesis cuando afecten al resultado; en caso contrario, conviene omitirlos.
~~~~

## Valores «truthy» y «falsey»

En Crystal, los valores «falsey» son: `false`, `nil` y los punteros nulos; **todo lo demás** es «truthy».
Estos valores se pueden usar con los operadores lógicos mencionados anteriormente.

```crystal

true && nil
# => false

false && 4
# => false

true || nil
# => true
```

## Convenciones para nombrar métodos con booleanos

En Crystal, es habitual nombrar con un signo de interrogación (`?`) un método que devuelve un valor «truthy» o «falsey».
En la mayoría de los casos, este método devolverá un valor Bool, pero no tiene por qué.
Esto significa que el método se puede usar en lugares donde se espera un valor «truthy» o «falsey», por ejemplo, como condición de una sentencia condicional `if`:

```crystal
def exchange(value)
    if value.nil?
        value = 5
    end
    value
end

exchange(10)
# => 10

exchange(nil)
# => 5
```

Los métodos cuyo nombre termina en un signo de interrogación y que no devuelven un valor Bool suelen devolver `nil` en su lugar. `nil` es _similar a `None` o `null` de otros lenguajes_.
