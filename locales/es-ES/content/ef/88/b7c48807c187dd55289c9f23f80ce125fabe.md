# Anexo de las instrucciones

## Pistas

Para completar este ejercicio, necesitas crear el tipo de datos `LinkedList` e implementar las siguientes funciones:

- `datum`
- `fromList`
- `isNil`
- `new`
- `next`
- `nil`
- `reverseLinkedList`
- `toList`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya presentes, pero depende de ti definir las funciones y crear un tipo de datos, un newtype o un sinónimo de tipo con sentido.
