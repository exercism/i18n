Pero las cosas están un poco desorganizadas: las coordenadas de Azara parecen tener un formato y un orden distintos de las de Rui, y no dejan de mirar de una lista a otra para averiguar qué tesoros van con qué lugares.
Como fsharpies incipientes, han acudido a ti para que les ayudes a escribir un pequeño programa (en realidad, un conjunto de funciones) que organice mejor la información de su búsqueda.

## 1. Extraer coordenadas

Implementa la función `getCooordinate()` que toma un par `(treasure, coordinate)` de la lista de Azara y devuelve únicamente la coordenada del mapa extraída.

```fsharp
getCoordinate ("Scrimshaw Whale's Tooth", "2A")
// "2A"
```

## 2. Dar formato a las coordenadas

Implementa la función `convertCoordinate()` que toma una coordenada con el formato "2A" y devuelve una tupla con el formato `(2, 'A')`.

```fsharp
convertCoordinate "2A"
// (2, 'A')
```

## 3. Comparar coordenadas

Implementa la función `compareRecords()` que toma un par `(treasure, coordinate)` y un registro `(location, coordinate, quadrant)` y compara las coordenadas de cada uno.
Devuelve **`true`** si las coordenadas coinciden y **`false`** si no lo hacen.
Vuelve a dar formato a las coordenadas según sea necesario para compararlas con precisión.

```fsharp
compareRecords ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "blue")
// false

compareRecords ("Model Ship in Large Bottle", "8A") ("Harbor Managers Office", (8, 'A'), "purple")
// true
```

## 4. Combinar los registros coincidentes

Implementa la función `createrecord()` que toma un par `(treasure, coordinate)` de la lista de Azara y un registro `(location, coordinate, quadrant)` de la lista de Rui y devuelve `(coordinate, location, quadrant, treasure)` **si las coordenadas coinciden**.
Si las coordenadas _no_ coinciden, devuelve una tupla con la misma forma pero rellena con `""`.
Vuelve a dar formato a las coordenadas según sea necesario para compararlas con precisión.

```fsharp
createRecord ("Brass Spyglass", "4B") ("Abandoned Lighthouse", (4, 'B'), "Blue")
// ("4B", "Abandoned Lighthouse", "Blue", "Brass Spyglass")

createRecord ("Brass Spyglass", "4B") ("Seaside Cottages", (1, 'C'), "Blue")
// ("", "", "", "")
```
