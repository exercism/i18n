# If, elseif, else

Los condicionales que usan `if`, `elseif` y `else` son una parte fundamental del flujo de control de un programa.
El condicional `if` evalúa una expresión y, si es `true`, ejecutará la rama de código.

```php
<?php

if ($expression) {
    // .. executed if $expression is true
}
```

Si la expresión no es un valor booleano, la evaluación determina si el valor es «verdadero» o «no falso».
En PHP, los siguientes valores se consideran iguales a false:

- booleano `false`
- entero `0`
- número decimal `0.0` y `-0.0`
- un array vacío `[]`
- un string vacío `""` o un string numérico `"0"`
- `null`

Todos los demás valores se consideran true.

## Responder a múltiples condiciones

Después de una instrucción `if`, puedes encadenar múltiples condiciones usando `elseif` y `else`.

```php
<?php

if ($value === 0) {
    // .. do something
} elseif ($value === 1) {
    // .. do something else
} else {
    // ,, do this if nothing else
}
```

Solo se ejecutará un condicional evaluado como true.
Así que si varias condiciones pueden evaluarse como true, el orden en que se escriben es importante.

```php
<?php

if (true) {
    // .. always do something
} elseif (true)
    // .. will never be executed
} else {
    // .. will never be executed
}
```
