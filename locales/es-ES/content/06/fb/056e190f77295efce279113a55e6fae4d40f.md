# Apéndice de instrucciones

## Cómo está estructurado este ejercicio en el track de Python

Los tests de este ejercicio esperan que tu programa se implemente mediante una [`class`][classes in python] llamada Garden (_consulta también [concept:python/classes]()_).
Si no estás familiarizado con las clases en Python, este [tutorial de Real Python][how-to-make-a-class] podría ser un buen punto de partida adicional.

Tu `class` debería implementar un [`method`][methods] llamado `plants`, que recibe el nombre de un estudiante como argumento y devuelve la `list` de nombres de plantas que pertenecen a ese estudiante.


## Constructores

Crear el jardín de ejemplo:

```python
[window][window][window]
VRCGVVRVCGGCCGVRGCVCGCGV
VRCCCGCRRGVCGCRVVCVGCGCV
```

estaría representado en los tests como `Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV")`.

Para que esta representación funcione, tu `class` tendrá que implementar un [`__init__()`][init] [método especial][special-methods].
Si no estás familiarizado con `__init__()` o con los [_constructores_][what-is-a-constructor], la página sobre [objetos de clase y de instancia][class vs instance objects in python] de la documentación de Python ofrece una explicación más detallada.


## Parámetros por defecto

En algunos tests, se pasa una `list` de estudiantes como argumento a `__init__()`.
Esta debería reemplazar la plantilla de doce estudiantes que se proporciona en el enunciado del problema.
Ambas instrucciones tienen que funcionar con tu método `__init__()`:


```Python
# Make a garden based on the default 12-student roster.
Garden("VRCGVVRVCGGCCGVRGCVCGCGV\nVRCCCGCRRGVCGCRVVCVGCGCV") 

# Make a garden based on a 2-student roster.
Garden("VRCC\nVCGG", students=["Valorie", "Raven"]) 
```

Un enfoque es hacer que la `list` de estudiantes sea un [argumento por defecto][default argument values]; la documentación de Python describe los `default parameters` en profundidad al explicar las [definiciones de funciones][function definitions].
