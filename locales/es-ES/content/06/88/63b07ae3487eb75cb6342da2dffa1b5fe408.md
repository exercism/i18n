# Instrucciones

Considera una función polinómica de la forma f(x) = ax^3 + bx^2 + cx + d. Los mínimos locales se definen como f(x) < f(x - delta) y f(x) < f(x + delta). Usando esta definición, deduce una expresión para el mínimo local y también calcula un mínimo local con los coeficientes dados (a, b, c, d). Los coeficientes describirán una función con al menos un mínimo.
Devuelve la coordenada x donde se produce el mínimo.
