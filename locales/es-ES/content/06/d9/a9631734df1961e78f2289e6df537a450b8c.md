# Consejos

## 1. Define un nuevo diccionario de puntuaciones máximas

- Los [diccionarios vacíos][empty-dictionary] pueden inicializarse escribiendo el nombre del tipo seguido de un par de paréntesis vacíos o, si el tipo se puede determinar por el contexto, usando el literal de diccionario vacío.

## 2. Añade jugadores al diccionario de puntuaciones máximas

- Un diccionario debe declararse como variable para poder añadirle elementos.
- Se pueden añadir elementos a un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 3. Elimina jugadores del diccionario de puntuaciones

- Un diccionario debe declararse como variable para poder eliminar elementos.
- Se pueden eliminar elementos de un diccionario usando el [método adecuado][dictionary-docs].

## 4. Restablece la puntuación de un jugador

- Un diccionario debe declararse como variable para poder cambiar sus valores.
- Se pueden actualizar los valores de un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 5. Actualiza la puntuación de un jugador

- Un diccionario debe declararse como variable para poder cambiar sus valores.
- Se pueden actualizar los valores de un diccionario usando la [sintaxis de subíndices de diccionario][dictionary-subscripts].

## 6. Obtén un array de jugadores con las puntuaciones ordenadas por el nombre del jugador

- Los elementos de un diccionario se pueden ordenar usando el [método adecuado][dictionary-docs].
- Tendrás que definir una función de ordenación de tipo `((String, Int), (String, Int)) -> Bool` para pasarla al método `sorted(by:)`.
- La función de ordenación debe devolver `true` si el par clave/valor de la izquierda debe aparecer _antes_ que el par clave/valor de la derecha en la salida ordenada.

## 7. Obtén un array de jugadores ordenado por su puntuación de forma descendente

- Los elementos de un diccionario se pueden ordenar usando el [método adecuado][dictionary-docs].
- Tendrás que definir una función de ordenación de tipo `((String, Int), (String, Int)) -> Bool` para pasarla al método `sorted(by:)`.
- La función de ordenación debe devolver `true` si el par clave/valor de la izquierda debe aparecer _antes_ que el par clave/valor de la derecha en la salida ordenada.
