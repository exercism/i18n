# Instrucciones

Tu amigo José es profesor en un colegio local.
Se le ocurrió una idea para hacer unos experimentos divertidos con los que mostrar cómo se pueden combinar los colores para producir otros distintos.

Te ha pedido ayuda con esos experimentos.

~~~~exercism/note
En este ejercicio, un color se representa con un número de 32 bits (4 bytes) que codifica su valor `RGB`.

Un valor `RGB` consta de 3 canales, _rojo_, _verde_ y _azul_, y cada uno de ellos ocupa 8 bits (1 byte).
El cuarto byte suele reservarse para el canal _alfa_, pero en este ejercicio su valor estará vacío (`0`).
~~~~

## 1. Obtén el valor RGB de un color

Los valores de cada color ya están guardados en una tabla definida en otro fichero fuente.
Cada color se identifica por una dirección única en esa tabla.

Define una función `get_color_value` que devuelva el valor de 32 bits de un color.
Esta función recibe como parámetro una dirección válida de ese color en la tabla de colores.

```c
get_color_value(black)
// => 0
```

**Hint** - 32 bits equivalen a 4 bytes.

## 2. Añade un color base

Para mezclar distintos colores, José primero fijará uno base y solo cambiará el color secundario con el que se combina.

Define una función `add_base_color` que guarde el valor de 32 bits de un color en la variable `base_color`, para poder usarlo más adelante.
Esta función no devuelve ningún valor y recibe como parámetro la dirección del color en la tabla de colores.

La variable `base_color` la defines tú y debe ser accesible desde otros ficheros fuente.

No habrá más de 1 color base a la vez.
Si se añade un nuevo color base, se descarta el anterior.

De forma predeterminada, al inicio del programa, `base_color` debe inicializarse con el valor de 32 bits de _white_, que es `0xFFFFFF00`.

**Hint** - NASM acepta números definidos en hexadecimal usando `0x` al principio, como en `0xFFFFFF00`.

## 3. Define constantes para los colores primarios

José tiene previsto hacer muchas combinaciones con colores primarios, así que quiere tenerlos separados para acceder a ellos rápidamente.
Como usa `RGB` para representar colores, los colores primarios son:

- `RED`, con el valor `0xFF000000`.
- `GREEN`, con el valor `0x00FF0000`.
- `BLUE`, con el valor `0x0000FF00`.

Define una constante para cada uno de esos colores.
Esas constantes deben ser accesibles desde otros ficheros fuente.

## 4. Combina colores

Los colores deben combinarse según una `combining_function` definida en otro fichero fuente.
Esta función recibe como parámetros los valores de 32 bits de `base_color` y de un color secundario que se vaya a mezclar con él.
Devuelve el valor de 32 bits del color combinado.

Define una función `make_color_combination` que combine dos colores y guarde el resultado en memoria.
Esta función no devuelve ningún valor y recibe como parámetros, en este orden:

- La dirección donde debe guardarse el valor de 32 bits del color combinado.
- La dirección de un color secundario en la tabla de colores, que se combinará con el color primario.

~~~~exercism/caution
Ten en cuenta que `combining_function` puede modificar los valores de los registros que estás usando.
Asegúrate de guardar en memoria cualquier variable que necesites antes de llamar a la función.
~~~~
