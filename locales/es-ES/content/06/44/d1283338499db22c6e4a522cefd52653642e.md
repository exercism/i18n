# Introducción

Los juegos de azar necesitan una fuente de aleatoriedad. El vocabulario [`random`][random] de Factor proporciona una palabra genérica, `random`, que se adapta a lo que le pases, además de ayudas para barajar y tomar muestras, y una forma de hacer que la aleatoriedad sea *reproducible* para los tests.

## Marcar una palabra como `inline`

Algunas de las tareas de este ejercicio definen una palabra que toma una *quotation* (un bloque `[ … ]`) como argumento y la ejecuta. Factor tiene una regla firme al respecto: **una palabra que hace `call` a una quotation que recibió como argumento debe declararse `inline`**, lo que se escribe poniendo `inline` justo después del `;` de cierre.

`inline` le indica al compilador que inserte el cuerpo de la palabra en cada punto de llamada en lugar de compilarlo una sola vez por su cuenta.

- La quotation del llamador se inserta directamente, así que **todo lo que la quotation deja en la pila vuelve al llamador**, aunque el propio efecto de pila de la palabra no declare ninguna salida.

Aquí tienes una palabra pequeña que apila `10` y luego ejecuta la quotation que recibió:

```factor
USING: kernel math prettyprint ;

: with-ten ( quot -- ) 10 swap call ; inline
```

Su efecto de pila, `( quot -- )`, no nombra ninguna salida, y sin embargo, si la llamas con dos quotations de efectos *distintos*, produce resultados diferentes, todos los cuales vuelven al llamador:

```factor
[ 1 + ] with-ten .        ! => 11   (quotation ( n -- n ): one value back)
[ dup 2 * ] with-ten . .  ! => 20
                          ! => 10   (quotation ( n -- n n ): two values back)
```

## `random`: un elemento

`random` (en [`random`][random]) es genérico respecto a su argumento:

```
random ( obj -- elt )
```

- Dado un **número entero** `n`, devuelve un número entero aleatorio en `[0, n)`:

```factor
USING: random ;

6 random .    ! 4   (a value from 0 to 5)
```

- Dada una **secuencia**, devuelve un elemento aleatorio:

```factor
{ "rock" "paper" "scissors" } random .    ! "paper"
```

Para lanzar un dado normal, desplazas el rango una unidad hacia arriba: `random` de `6` da de 0 a 5, así que `6 random 1 +` da de 1 a 6.

## Extraer varios valores

Para reunir un número fijo de extracciones aleatorias, repite una quotation con `replicate` (en [`sequences`][sequences]):

```
replicate ( n quot -- seq )
```

```factor
USING: random sequences ;

3 [ 6 random 1 + ] replicate .    ! { 4 1 6 }   (three dice)
```

## `randomize`: barajar in situ

`randomize` (en [`random`][random]) devuelve la secuencia con sus elementos en un orden aleatorio:

```
randomize ( seq -- randomized )
```

```factor
{ 1 2 3 4 5 } randomize .    ! { 3 1 5 2 4 }
```

Baraja **in situ** y devuelve la misma secuencia, así que haz `clone` primero si necesitas conservar el orden original.

## `sample`: varios elementos distintos

`sample` (en [`random`][random]) extrae `n` elementos *distintos* de una secuencia, como repartir una mano de cartas, sin repetir nunca una carta:

```
sample ( seq n -- seq' )
```

```factor
{ 10 20 30 40 50 } 3 sample .    ! { 40 10 30 }
```

Pedir más elementos de los que contiene la secuencia es un error.

## Aleatoriedad reproducible

De forma predeterminada, `random` extrae de un generador global con semilla tomada del reloj del sistema, así que cada ejecución es distinta. Para los tests, o siempre que quieras una partida que puedas *volver a jugar*, vincula un generador con una **semilla** fija.

`<mersenne-twister>` (en [`random.mersenne-twister`][mt]) construye un generador a partir de una semilla entera, y `with-random` (en [`random`][random]) ejecuta una quotation con ese generador instalado:

```
<mersenne-twister> ( seed -- rnd )
with-random        ( rnd quot -- )
```

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random 1 + ] with-random .
! always the same value for seed 42
```

Todo lo que hay dentro de la quotation (`random`, `randomize`, `sample`) extrae del generador con semilla, así que la misma semilla reproduce siempre el mismo resultado.

Una palabra que toma una quotation como argumento y la ejecuta a través de `with-random` entra dentro de la regla de [Marcar una palabra como `inline`](#marking-a-word-inline): `with-random` acaba haciendo `call` a esa quotation, así que ese envoltorio debe marcarse como `inline`.
