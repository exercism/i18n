# Pruebas

Puedes implementar un ejercicio en tu propio sistema SAP. Sigue estos pasos:

1. Crea un paquete SAP para todos los ejercicios de Exercism en tu sistema (nombre recomendado: `$EXERCISM`)
2. Crea un paquete SAP para cada ejercicio como subpaquete (nombre recomendado: `$EXERCISM_<name-of-exercise>`, ejemplo: `$EXERCISM_HELLO-WORLD`)
3. Crea una clase ABAP correspondiente al ejercicio (ejemplo: `ZCL_HELLO_WORLD`)
4. Copia el código de la plantilla de Exercism a la clase
5. Mantén las clases de prueba y copia el código de Exercism a la clase de prueba

Ahora ya puedes completar la implementación de la clase y ejecutar la prueba unitaria para comprobar si tu solución funciona correctamente.

Nota: esta configuración de paquetes te permitirá hacer una copia de seguridad de todo tu trabajo con [abapGit](https://abapgit.org) creando un repositorio para el paquete `$EXERCISM`.

Para obtener más información, consulta la [documentación de ABAP de Exercism](https://exercism.org/docs/tracks/abap).
