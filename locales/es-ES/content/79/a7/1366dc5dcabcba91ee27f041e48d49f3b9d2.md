# Instrucciones

En este ejercicio vas a organizar carreras entre varios tipos de coches teledirigidos. Cada coche tiene sus propias características y corre en muchas pistas diferentes en carreras a lo largo de la temporada del torneo.

~~~~exercism/note
Las funciones de este ejercicio se declaran en un fichero fuente de C con las firmas proporcionadas.
Tu código de ensamblador x86-64 debe seguir esas especificaciones.
~~~~

## 1. Crear un coche teledirigido

Has definido un struct `car_t` para representar un coche teledirigido:

```c
struct car_t {
    char name[10];
    int16_t speed;
    float battery;
};
```

Permite crear un coche teledirigido definiendo una función `new_car` en ensamblador x86-64.
El campo `battery` siempre empieza con el valor `100.0`.

```c
struct car_t new_car(short speed, const char name[]);
```

## 2. Crear una pista nueva

Las pistas se representan con un struct `track_t`:

```c
struct track_t {
    enum surface_t surface;
    size_t distance;
};
```

El `enum surface_t` registra las distintas superficies de una pista:

```c
enum surface_t {
    ASPHALT,
    SAND,
    ICE,
    CLAY
};
```

Permite crear una pista nueva definiendo una función `new_track` en ensamblador x86-64.

```c
struct track_t new_track(enum surface_t surface, size_t distance);
```

## 3. Crear un evento de carreras

En cada carrera participan hasta 6 coches, que dan un número determinado de vueltas en una pista.
Las carreras se representan con un struct `race_t`:

```c
struct race_t {
    struct track_t track;
    uint8_t num_of_laps;
    struct car_t cars[6];
    uint8_t num_of_running_cars;
};
```

Define una función `new_race` en ensamblador x86-64.
Al principio, no hay ningún coche confirmado para participar en la carrera:

```c
struct race_t new_race(struct track_t track, uint8_t num_of_laps);
```

## 4. Confirmar un coche para la carrera

Cuando el dueño de un coche pide que participe en una carrera, su participación solo se confirma si la lista no está ya llena.

Define una función `add_participant` en ensamblador x86-64.
Si hay sitio para un participante más en la carrera, el coche se añade a la lista, se actualiza el contador y se confirma su participación.
En caso contrario, los organizadores de la carrera deben informar al dueño del coche de que esta vez no puede participar.

```c
bool add_participant(struct race_t *race, struct car_t car);
```

## 5. Crear un torneo

Llevas un registro de las carreras programadas para la temporada en un struct `tournament_t`:

```c
struct tournament_t {
    struct race_t races[20];
    size_t num_of_races;
};
```

Define una función `add_race` en ensamblador x86, para añadir una carrera al array del torneo y actualizar también su contador.
Puedes dar por hecho que siempre habrá espacio suficiente en el array `races` para la nueva carrera.

```c
void add_race(struct tournament_t *tournament, struct race_t race);
```
