# Instrucciones

Hola de nuevo, Agent Double-Null0111.

Las fuerzas de UMBRA están causando problemas otra vez, y te toca a ti frustrar su último plan.
Nuestro servicio de inteligencia nos informa de que esos Minions están planeando hacer estallar una bomba fétida en el baile del gobernador.

Como los minions son tan torpes, a menudo arman las bombas fétidas por accidente en sus laboratorios y oficinas.
Y como no dejan de olvidar cómo desactivar sus bombas fétidas, han implementado un sistema que genera las instrucciones de desactivación, en las que se indica el orden en que hay que cortar los cables a partir del número de identificación de la bomba.

Tu trabajo es escribir el código que te permita desactivar la bomba fétida del baile antes de que estalle.

## 1. Escribe un closure para intercambiar dos cables

Cada bomba fétida tiene tres cables de colores diferentes.
Escribe un closure que reciba una tupla `(String, String, String)` y devuelva la tupla con el orden de los dos primeros elementos intercambiado.
Asigna este closure al nombre `flip`.

Es importante tener en cuenta que el tipo tiene que ser el `ChangeClosure` (o un tipo sendable); la definición del tipo se encuentra en el fichero stub.
De lo contrario, el código no compilará.

```swift
flip(("red", "yellow", "blue"))
// Returns ("yellow", "red", "blue")
```

## 2. Escribe un closure para rotar los cables

Escribe un closure que reciba una tupla `(String, String, String)` y devuelva la tupla con el orden de los cables rotado hacia la izquierda.
Asigna este closure al nombre `rotate`.

Es importante tener en cuenta que el tipo tiene que ser el `ChangeClosure` (o un tipo sendable); la definición del tipo se encuentra en el fichero stub.

```swift
rotate(("red", "yellow", "blue"))
// Returns ("yellow", "blue", "red")
```

## 3. Implementa un generador de barajado de cables

Para averiguar el orden en que hay que cortar los cables de la bomba fétida, tendrás que implementar una función que genere la función de barajado adecuada a partir del número de identificación de la bomba fétida.

Implementa la función:

```swift
makeShuffle(
  flipper: @escaping ((String, String, String)) -> (String, String, String),
  rotator: @escaping ((String, String, String)) -> (String, String, String)
) -> ([UInt8], (String, String, String)) -> (String, String, String)
```

que recibe como entrada un closure que intercambia dos cables y un closure que rota los tres cables, y devuelve un closure.
Este closure devuelto recibe el número de identificación de la bomba fétida y el orden de los tres cables, y luego calcula el orden en que hay que cortar los cables.
El número de identificación se compone de ocho bits, y cada bit determinará si hay que intercambiar o rotar los cables.

Para cada bit del número de identificación, empezando por el bit más a la derecha, aplicarás el closure `flipper` a la tupla de cables si el bit es 0, y aplicarás el closure `rotator` si es 1, lo que da el nuevo estado de los cables.
Una vez aplicados los closures correspondientes a los ocho bits del número de identificación, el estado final de los cables es el orden en que hay que cortarlos.

```swift
let shuffler = makeShuffle(flipper: flip, rotator: rotate)
// Returns ([UInt8], (String, String, String)) -> (String, String, String)
shuffler([1, 0, 0, 1, 1, 0, 1, 1], ("red", "yellow", "blue"))
// Returns ("red", "blue", "yellow")
```
