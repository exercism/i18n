# Pistas

## General

- Quizá te apetezca crear un DSL basado en listas de etiquetas y registros, como este:

  ```roc
  my_graph =
      Graph.create([
          Title("My Graph"),
          Node("a", { color: Green }),
          Node("b", { color: Blue }),
          Edge("a", "b", { style: Dotted }),
      ])
  ```

- O quizá prefieras un DSL basado en cadenas de llamadas a funciones, como este:

  ```roc
  my_graph =
      Graph.create()
          .with_title("My Graph")
          .add_node("a", Attr.create().with_color(Green))
          ...
  ```

  ¿O tal vez tengas un plan totalmente distinto?
  ¡Adelante!

- Dicho esto, un DSL suele ser mejor si es claro, conciso y no demasiado sorprendente (por ejemplo, la función `minus` está pensada para restar, no para crear una arista entre dos nodos, como en `node("a") - node("b")`).
