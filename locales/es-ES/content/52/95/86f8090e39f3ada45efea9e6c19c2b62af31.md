# Condicionales

Ruby tiene lo que se conoce como expresiones de control de flujo. Se usan para controlar cómo se ejecuta el programa y toman un valor truthy o falsey.
Existen operadores que se pueden usar para crear valores truthy o falsey; se conocen como [operadores de comparación][comparison-operators].

Hay dos expresiones de control principales que se usan para decidir qué código se ejecuta y cuál no.
Es decir, qué rama se ejecutará en cada caso.

Esas dos son: la expresión `if` y la expresión `unless`.

## Operadores de comparación

Los [operadores de comparación][comparison-operators] se usan para comparar valores y devolver un valor `true` o `false`.
Los siguientes operadores requieren que los dos valores que se comparan sean del mismo tipo.
Si los valores no son del mismo tipo, el compilador lanzará un error.
Aquí tienes una lista de los operadores y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción           | Ejemplo |
| ------ | --------------------- | ------- |
| <      | menor que             | 4 < 5   |
| <=     | menor o igual que     | 4 <= 4  |
| >      | mayor que             | 3 > 1   |
| >=     | mayor o igual que     | 2 >= 2  |

A diferencia de los operadores ya mencionados, los operadores de igualdad y desigualdad se pueden usar para comparar cualquier tipo de valor.
El operador `==` se usa para comprobar si dos valores son iguales, lo que incluye comprobar el tipo del valor.
El `!=` funciona igual, pero devolverá `true` si los valores no son iguales y `false` si son iguales.
Aquí tienes una lista de los operadores de igualdad y desigualdad y un ejemplo de cuándo dan un valor `true`:

| Método | Descripción  | Ejemplo |
| ------ | ------------ | ------- |
| ==     | igual a      | 4 == 4  |
| !=     | distinto de  | 5 != 4  |

## Condicional if

El condicional [`if`][if] se usa para comprobar si una condición dada es «truthy» o «falsey».
Si la condición es truthy, se ejecutará el código que hay dentro del condicional if.
Un condicional `if` termina con la palabra clave `end`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
end
# => nil
```

## Condicional unless

El condicional `unless` funciona de forma muy parecida al condicional `if`, pero ejecutará el código que hay dentro del condicional `unless` si la condición es falsey.

```ruby
value = 1
unless value == 1
  "1 is not equal to 1"
end
# => nil

unless value > 2
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Condicional else

El condicional `else` se puede usar junto con el condicional `if`.
El condicional `else` se ejecutará si no se ejecuta la rama `if`.

```ruby
value = 1
if value == 1
  "1 is equal to 1"
else
  "1 is not equal to 1"
end
# => "1 is equal to 1"

if value > 2
  "1 is greater than 2"
else
  "1 is not greater than 2"
end
# => "1 is not greater than 2"
```

## Condicionales en cascada

El condicional `elsif` se puede usar junto con el condicional if.
El condicional `elsif` se ejecutará si no se ejecuta la rama if y la condición del condicional elsif es truthy.
Los condicionales elsif se pueden encadenar y se ejecutará la primera condición que sea truthy.
También puede haber un condicional else al final del condicional if, que se ejecutará si ninguno de los condicionales anteriores ha sido verdadero.

```ruby
value = 1
if value == 0
  "1 is equal to 0"
elsif value > 2
  "1 is greater than 2"
else
  "1 is not equal to 0 and 1 is not greater than 2"
end
# => "1 is not equal to 0 and 1 is not greater than 2"
```
