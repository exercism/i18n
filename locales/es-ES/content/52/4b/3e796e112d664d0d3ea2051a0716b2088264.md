# Anexo de instrucciones

# Entrada

La entrada de este ejercicio es:

- `target`: un string (por ejemplo, `'stone'`) que será el _argumento izquierdo_.
- `candidates`: un array de cajas con strings (por ejemplo, `'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'`) que será el _argumento derecho_.

Tu verbo se llamará así:

```j
  target     =. 'stone'
  candidates =. 'stone' ; 'tones' ; 'banana' ; 'tons' ; 'notes' ; 'Seton'
  
  subject findAnagrams candidates
```

## Salida

Tu verbo debe devolver un _array_ de cajas que contienen los strings que son anagramas del objetivo. Si no hay anagramas, el resultado debe ser `empty`.
