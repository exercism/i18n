# Introducción

## Bucles

Los bucles sirven para ejecutar una misma lógica de forma repetida.
Los dos tipos más comunes son el `while loop` (bucle indefinido) y el `for loop` (bucle definido o contado).
También existe el bucle `for each`, que aparecerá en un concepto posterior.

### Sintaxis general

El `for loop` consta de una cabecera y un bloque de código que contiene el cuerpo del bucle encerrado entre llaves.
La cabecera consta de 3 componentes separados por puntos y coma `;`: la instrucción de inicialización, la condición y otra expresión.
Cualquiera de ellos puede estar vacío.

```cpp
for (init_statement; condition; expression) {
  some_statement;
}
```

- El componente **init_statement** es código que se ejecuta una sola vez antes de que empiece el bucle.
- El componente **condition** debe ser una expresión que se evalúe a un `boolean` y que controle cuándo debe detenerse el bucle.
  El código que hay dentro del bucle se ejecutará mientras esta condición se evalúe como `true`.
  En cuanto esta expresión se evalúe como `false`, no se ejecutará ninguna iteración más del bucle.
- El componente **expression** es código que se ejecuta al final de cada iteración.

El `while loop` ejecuta su cuerpo mientras su comprobación de la **condition** sea `true`.
El fragmento de código siguiente muestra cómo transformar un `for` en un `while loop`.

```cpp
init_statement;
while(condition) {
    some_statement;
    expression;
}
```

### Interludio: incrementos y decrementos

Cuando se trabaja con bucles, a menudo hay que sumar o restar 1 a una variable contador que lleva la cuenta de las iteraciones.
Esto es tan habitual que las acciones de incremento y decremento tienen operadores propios: `++` y `--`.

Existen en una forma **prefija** y una forma **postfija**.
La forma prefija modifica la variable antes de que se use en la instrucción, y la postfija, después.
Lo más probable es que la mayoría de las veces quieras la versión prefija.

```cpp
int a{3};
int b{--a};
// b is 2, a is now 2
int c{a++};
// c is 2, a is now 3
```

### Bucles for: un ejemplo

El _componente de inicialización_ normalmente prepara una variable contador, la _condición_ comprueba si el bucle debe continuar o detenerse, y el _componente de incremento_ normalmente incrementa el contador al final de cada repetición.

```cpp
int sum{0};
for (int i{1}; i < 10; ++i) {
  sum += i;
}
```

Este bucle sumará los números del `1` al `9` (incluido el `9`).

### Break y continue

Dentro del cuerpo de un bucle, puedes usar la palabra clave `break` para detener por completo la ejecución del bucle:

```cpp
int sum{2};
while(true) {
    sum *= 2;
    if (sum > 1000)
        break;
}
// sum is now 1024
```

En cambio, la palabra clave `continue` solo detiene la ejecución de la iteración actual y continúa con la siguiente:

```cpp
int equal_sum{0};
for (int i{1}; i < 7; ++i) {
  if  (i%2 == 1) {
    continue;
  }
  equal_sum += i;
}
// equal_sum is now 12
```

~~~~exercism/note
Normalmente es más fácil entender la lógica del bucle cuando se minimiza o se evita por completo el uso de `break` y `continue`.
Ambas palabras clave se saltan ciertas secciones del código y a menudo hacen que sea más difícil seguirlo.
~~~~
