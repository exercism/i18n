# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelance a comunicarse con un jefe de proyecto. Tu tarea es proporcionar unas cuantas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos unas cuantas reglas entre el freelance y el jefe de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelance ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más fieles o para clientes sin ánimo de lucro).

Los descuentos se modelan como números fraccionarios que representan porcentajes, por ejemplo, `25.0` (25 %).

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función llamada `dailyRateFrom` para calcular la tarifa diaria a partir de una tarifa por hora como parámetro.
El contrato define que un día tiene 8 horas facturables.

```swift
dailyRateFrom(hourlyRate: 60)
// Returns 480.0
```

La tarifa diaria devuelta debe ser un `Double`.

## 2. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función `monthlyRateFrom` para calcular la tarifa mensual con descuento.
Recibe dos parámetros: una tarifa por hora y el descuento en porcentaje.


```swift
monthlyRateFrom(hourlyRate: 77, withDiscount: 10.5)
// Returns 12129
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al número entero más cercano.

## 3. Calcula el número de días laborables completos a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función `workdaysIn` que recibe un presupuesto, una tarifa por hora y un descuento, y calcula cuántos días completos de trabajo cubre.

```swift
workdaysIn(budget: 20000, hourlyRate: 80, withDiscount: 11.0)
// Returns 35.0
```
El número de días devuelto debe redondearse hacia abajo (tomar el suelo) al siguiente número entero.
