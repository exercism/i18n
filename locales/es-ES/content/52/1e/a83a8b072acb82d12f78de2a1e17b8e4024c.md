# Tests

Ejecuta los tests con `exercism test` o `eutest`. Todos los tests se ejecutan por defecto.

## Omitir tests

Una buena forma de empezar es comentar todos los tests excepto el primero en `t_<exercise>.e`.

```euphoria
test_equal("no name given", "One for you, one for me.", two_fer())
-- test_equal("a name given", "One for Alice, one for me.", two_fer("Alice"))
-- test_equal("another name given", "One for Bob, one for me.", two_fer("Bob"))
```

Trabájalos de uno en uno, descomentando el siguiente test cuando pase el actual.
Cuando pasen todos los tests, habrás completado el ejercicio.
