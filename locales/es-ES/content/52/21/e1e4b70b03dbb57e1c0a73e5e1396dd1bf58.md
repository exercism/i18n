# Acerca de

El tipo `Option` es el mecanismo del lenguaje F# para tratar con valores que pueden o no existir.
Proporciona una alternativa segura en cuanto a tipos al uso de `null`, que es común en otros lenguajes para tratar con dichos valores.
Se utiliza en muchas funciones estándar de la biblioteca de F#, por lo que entenderlo es esencial para un uso eficaz de la biblioteca estándar de F#.

## Beneficios de usar el tipo `Option`

* __Seguridad en tiempo de compilación__: Al hacer explícita la presencia o ausencia de un valor en el sistema de tipos, el compilador puede asegurarse de que manejas el caso «sin valor», evitando una gran categoría de errores que podrían ocurrir con los valores nulos.

* __Seguridad en tiempo de ejecución__: En lugar de usar `null`, F# usa `None` para representar la ausencia de un valor, lo que hace imposible que ocurra una `NullReferenceException`.

* __Fuerza el manejo explícito__: El sistema de tipos requiere que el código maneje explícitamente tanto el caso `Some value` como el caso `None`, lo que hace que tu código sea más robusto y predecible.

* __Funciona con la coincidencia de patrones__: Los `Option` funcionan a la perfección con la coincidencia de patrones idiomática de F#, proporcionando una forma limpia y segura de deconstruir y manejar el valor si existe, o realizar una acción diferente si no existe.

## Uso

El tipo `Option` es un tipo genérico (que tiene un tipo subyacente).  
Los valores `Option` son o bien `Some value`, que representa algún valor específico, o `None`, que representa la ausencia de valor.

La siguiente función demuestra cómo crear un valor `Option`:

```fsharp
let keepIfPositive (a: int) : int option = if a > 0 then Some a else None
```

~~~~exercism/note
`T option` es la sintaxis postfija equivalente a `Option<T>`; las dos formas de sintaxis se pueden usar indistintamente.
Sin embargo, según la Guía de estilo de F#, se prefiere la notación postfija para los tipos Option (consulta la [sección de la Guía de estilo de F# sobre Formato de tipos y anotaciones de tipo](https://learn.microsoft.com/en-us/dotnet/fsharp/style-guide/formatting#for-types-prefer-prefix-syntax-for-generics-foot-with-some-specific-exceptions)).
~~~~

Un caso de uso típico para un `Option` es el de las funciones de búsqueda. 
Por ejemplo, la función `List.tryFind` devuelve `Some index` cuando el elemento está en la lista (donde `index` es la posición del valor solicitado en la lista), o `None` cuando el elemento no está en la lista.

## Leer el contenido de un valor Option

La forma idiomática de leer un valor `Option` es mediante la coincidencia de patrones, como se muestra en el siguiente ejemplo:

```fsharp
// Returns "Hello, <name>!" if the name is provided; otherwise returns "Hello, you!"
let sayHello (optionalName: string option): string = 
    match optionalName with
    | Some name -> "Hello, " + name + "!"
    | None -> "Hello, you!"

sayHello (Some "Matthieu")
// --> "Hello, Matthieu!"

sayHello None
// --> "Hello, you!"
```

## Desenvolver Options con valores predeterminados

Los `Option` se pueden «desenvolver» (convertir a su tipo contenido) proporcionando valores predeterminados con la función `Option.defaultValue`. 
Esto es particularmente útil cuando quieres asegurarte de que el valor no es `None`.
Por ejemplo:

```fsharp
Option.defaultValue "" (Some "F#")
// --> "F#"

Option.defaultValue 0 None
// --> 0
```

## Más funciones en el módulo `Option`

El módulo `Option` también incluye funciones que corresponden a las funciones disponibles para listas, arrays, secuencias y otros tipos de colecciones, como `Option.map`, `Option.iter`, `Option.forall`, `Option.count`. 
Estas funciones permiten que los `Option` se traten como una colección de cero o un elemento.
