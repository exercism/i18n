# Introducción

En PHP, se puede llamar a una variable como si fuera una función aplicándole paréntesis [`()`]. Cuando PHP intenta invocar la función, buscará una función con el mismo nombre que el valor de la variable.

```php
function foo(): string
{
    return "foo() invoked";
}

$func = 'foo';
$func(); // This calls foo()
```
