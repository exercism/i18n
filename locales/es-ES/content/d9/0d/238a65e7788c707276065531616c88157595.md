# Elimina la función `main` y corrige el nombre del paquete

Elimina la función `main`, vuelve a poner `twofer` como nombre del paquete y ejecuta las pruebas.

La función `main` se usa como punto de entrada de un programa. Exercism usa TDD ([desarrollo guiado por pruebas](http://testfirst.org/about#tdd)). Esto significa que el código se ejecuta lanzando las pruebas para hacer que pasen. Para ejecutar las pruebas, usa `go test` desde la terminal. Las pruebas pasarán si la funcionalidad está implementada correctamente.
