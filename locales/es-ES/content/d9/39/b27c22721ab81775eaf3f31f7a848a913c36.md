# Instalación

Necesitas [Vim](http://www.vim.org) para hacer los ejercicios:

- [macOS](#macos)
- [Ubuntu / Debian](#ubuntu--debian)
- [Windows](#windows)
- [Source](#source)

## macOS

El sistema operativo ya incluye Vim, pero es una versión irremediablemente obsoleta.

Es probable que uses [MacPorts](https://www.macports.org) o
[Homebrew](https://brew.sh) para instalar software.

Homebrew:

```
$ brew update
$ brew install vim
```

MacPorts:

```
$ sudo port install vim +huge
```

Si quieres una interfaz gráfica, echa un vistazo a [MacVim](https://macvim-dev.github.io/macvim)
en su lugar.

## Ubuntu / Debian

Instala un Vim completo con soporte de interfaz gráfica (`gvim`):

```
$ sudo apt-get update
$ sudo apt-get install vim-gtk
```

## Windows

Con [Chocolatey](https://chocolatey.org):

```
C:\> choco install vim
```

O descárgalo e instálalo directamente desde [aquí](http://www.vim.org/download.php#pc).

## Source

Si quieres compilar tú mismo la última versión de Vim, echa un vistazo al [repositorio
oficial en GitHub](https://github.com/vim/vim).
