# Introducción

## Boolean

El tipo `Bool` es uno de los bloques fundamentales del lenguaje.
Su objetivo es describir si algo es verdadero o falso, con los respectivos valores `True` y `False`.

Los Boolean se pueden combinar con los operadores «AND» `&&` y «OR» `||`, y negar con la función `not`.

Los Boolean también son enormemente útiles para crear ramificaciones en tu código que solo se ejecuten si se cumplen ciertas condiciones.
En Elm, esto se hace con una expresión `if-then-else`, que se usa del siguiente modo.

```elm
if someCondition || (someOtherCondition && anotherCondition) then
    doSomething
else
    doSomethingElse
```
