# Instrucciones

Lucy tiene una tienda de pegatinas en línea, donde vende pegatinas monas con los lenguajes de programación favoritos de todo el mundo. Personas de todo el mundo compran sus pegatinas, y está teniendo problemas para lidiar con todas las distintas monedas.

Crea un programa que Lucy pueda usar para calcular precios y asegurarse de que siempre usa la moneda correcta.

## 1. Define los tipos `Usd`, `Eur` y `Jpy`

Estos tipos se usan para representar las distintas monedas que los clientes de Lucy usan para comprar sus pegatinas.

Deben usarse como tipos fantasma y no necesitan tener ningún constructor.

## 2. Define el tipo `Money`.

El tipo `Money` debe tener un campo `Int` para la cantidad de dinero, un parámetro de tipo fantasma de moneda, y debe ser un tipo opaco.

## 3. Define las funciones `dollar`, `euro` y `yen`

Define las funciones `dollar`, `euro` y `yen`, que reciben un argumento `Int` y devuelven un valor `Money` con la moneda correcta.

## 4. Define la función `total`

Define la función `total`, que recibe un array de valores `Money` y devuelve la cantidad total de dinero del array.

```gleam
total([euro(120), euro(200), euro(145)])
// -> euro(465)
```
