# Pistas

## 1. Determina el número total de pájaros que has contado hasta ahora

- Consulta la introducción del ejercicio para ver un ejemplo de cómo usar un bucle `for` para recorrer un array.
- Usa una variable auxiliar para almacenar el recuento total e incrementa esa variable a medida que recorres el array.
- Piensa en el valor inicial correcto para esa variable auxiliar.
- Vuelve a consultar el [concepto de array][concept-arrays] para repasar cómo obtener valores de un array.

## 2. Calcula el número de pájaros visitantes en una semana concreta

- Esta tarea es similar a la primera.
  Puedes copiar tu código como punto de partida.
- Piensa en qué índices del array tendrías que tener en cuenta para la semana número 1 y 2, respectivamente.
- Ahora, busca una forma general de calcular el primer y el último índice que se deben tener en cuenta.
- Con eso, puedes configurar el bucle `for` para que solo recorra la sección relevante del array.

## 3. Corrige un error de recuento

- De nuevo, necesitas configurar un bucle `for` para recorrer todo el array del recuento de pájaros.
- Esta vez solo necesitas visitar cada segundo elemento del array.
- Cambia el paso para que la variable del contador se incremente en consecuencia después de cada iteración.
- En el cuerpo del bucle `for` puedes usar el operador de incremento para cambiar in situ el valor de un elemento de un array.
