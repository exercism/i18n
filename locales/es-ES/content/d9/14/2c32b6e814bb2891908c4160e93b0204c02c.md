# Instrucciones

Eres un mixólogo experto y preparas bebidas ricas para que el público las disfrute cuando sale de noche.
Pero has pensado que podrías facilitarte la vida escribiendo un poco de código que te ayude con tu trabajo.

## 1. Determina cuánto se tarda en preparar un pedido

Las distintas bebidas tardan distinta cantidad de tiempo en prepararse:

- `"beer"`, `"soda"` y `"water"` tardan 0,5 minutos cada una.
- Los `"shot"` tardan 1,0 minutos, los `"mixed drink"` tardan 1,5 minutos,
- los `"fancy drink"` tardan 2,5 minutos,
- los `"frozen drink"` tardan 3,0 minutos.

Implementa la función `timeToPrepare(drinks:)`, que toma el argumento `drinks`, que contiene un array de strings que representan las bebidas que hay que preparar.
La función debe devolver el tiempo total que se tardará en preparar todas las bebidas del array.

```swift
timeToPrepare(drinks: ["beer", "frozen drink", "shot"])
// returns 4.5
```

## 2. Repón tu reserva de gajos de lima

Una de las primeras cosas que tienes que hacer al empezar tu turno es asegurarte de que tu pequeña cubeta de gajos de lima esté llena para el turno que tienes por delante.
Tendrás limas de distintos tamaños, que darán distinta cantidad de gajos: de una lima "small" puedes sacar 6 gajos, de una "medium" 8 gajos y de una "large" 10.

Mientras sigas necesitando más gajos y aún te queden limas por cortar, saca la primera lima del array y resta del número de gajos que necesitas la cantidad de gajos correspondiente.
Continúa así hasta que ya no necesites más gajos o te quedes sin limas.

Implementa la función `makeWedges(needed:limes:)`, que toma los argumentos `needed`, que contiene el número de gajos que necesitas cortar, y `limes`, que contiene un array de strings que representan los tamaños de las limas que tienes disponibles para cortar.
La función debe devolver el número de limas que has cortado.

```swift
makeWedges(needed: 25, limes: ["small", "small", "large", "medium", "small"])
// returns 4
```

## 3. Termina tu turno

¡Enhorabuena! Tu larga jornada de trabajo está a punto de terminar y pronto te irás a casa a trabajar en tu nueva app.
Pero todavía tienes un montón de pedidos de bebidas que preparar antes de poder pasar los pedidos al siguiente turno e irte.

Mientras te quede tiempo en el turno, debes preparar el primer pedido del array y luego eliminar ese pedido del array.
Después puedes restar del tiempo que te queda de turno el tiempo que se ha tardado en preparar ese pedido, según tu función `timeToPrepare(drinks:)`.

Implementa la función `finishShift(minutesLeft:remainingOrders:)`, que recibe el número de minutos que quedan en tu turno (se garantiza que es mayor que 0) y un array no vacío de pedidos de bebidas.
La función debe devolver el array de pedidos que aún no te ha dado tiempo a preparar antes de que acabe tu turno.

```swift
finishShift(minutesLeft: 5, remainingOrders: [["beer", "frozen drink", "shot"], ["fancy drink", "soda"], ["beer", "beer", "water"], ["mixed drink", "frozen drink"]])
// returns [["beer", "beer", "water"], ["mixed drink", "frozen drink"]]
```

## 4. Haz un seguimiento de ciertos pedidos

Para asegurarte de que la cerveza y el refresco se mantengan frescos, necesitas hacer un seguimiento de sus pedidos junto con las horas a las que se hicieron esos pedidos.

Implementa la función `orderTracker(orders: [(drink: String, time: String)]) -> (beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`, que, dado un array de pedidos y sus horas, devuelve un par de tuplas opcionales que contienen las horas del primer y el último pedido de cerveza y de refresco, junto con el número total de pedidos de cada uno, y `nil` si no se hizo ningún pedido de esas bebidas. No necesitas hacer un seguimiento de ninguna otra bebida.

Implementa la función `orderTracker(orders:)`, que recibe un array de tuplas, donde cada tupla contiene la bebida pedida y la hora a la que se hizo el pedido.
La función debe devolver una tupla que contenga la primera y la última hora a la que se pidió cerveza, el número total de pedidos de cerveza, la primera y la última hora a la que se pidió refresco y el número total de pedidos de refresco.
Debe devolverse como una tupla con el formato: `(beer: (first: String, last: String, total: Int)?, soda: (first: String, last: String, total: Int)?)`.

```swift
let orders = [
    (drink: "beer", time: "10:01"), (drink: "frozen drink", time: "10:02"),
    (drink: "shot", time: "10:05"), (drink: "fancy drink", time: "10:06"),
    (drink: "soda", time: "10:09"), (drink: "beer", time: "10:15"), (drink: "beer", time: "10:22"),
    (drink: "water", time: "10:26"), (drink: "mixed drink", time: "10:28"),
    (drink: "frozen drink", time: "10:33"),
]

orderTracker(orders: orders)

// returns (beer: (first "10:01", last "10:22", total 3), soda: (first "10:09", last "10:09", total 1))
```
