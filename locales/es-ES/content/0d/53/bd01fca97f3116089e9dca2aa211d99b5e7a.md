# Introducción

En Cairo, los módulos ayudan a organizar el código agrupando funciones, structs y traits relacionados en espacios de nombres separados.
La palabra clave `use` simplifica el acceso a estos elementos al traerlos al scope, lo que reduce la repetición al llamar a funciones o usar tipos.
Esta sección trata las buenas prácticas para estructurar módulos, importar elementos de forma eficiente y reexportar para conseguir un código más limpio y fácil de mantener.
