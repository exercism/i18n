# Acerca de

Los [tipos personalizados][custom-types] de Elm representan un número fijo de casos con nombre. Cada valor se corresponde con exactamente uno de esos casos. En otros lenguajes o contextos se conocen como _tipos suma_, _uniones discriminadas_, _uniones etiquetadas_ y _tipos de datos algebraicos_.

Cada caso de una unión discriminada puede tener datos asociados de forma opcional, y distintos casos pueden tener distintos tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada se parece a lo que en otros lenguajes se suele llamar una _enumeración_ (o _enum_).

Un tipo personalizado se define con la palabra clave `type` y necesita muy poca sintaxis. Son una de las técnicas más importantes de la programación en Elm y se usan para hacer que los valores posibles del código coincidan exactamente con los valores válidos de la vida real, lo que no deja lugar a datos inválidos y hace que [los estados imposibles sean imposibles de representar en el código][impossible-states].

```elm
-- Custom Type without associated data
type Season
    = Spring
    | Summer
    | Autumn
    | Winter

-- Custom Type with associated data
type FlexibleNumber
    = Integer Int
    | Float Float
    | Invalid
```

Para crear un valor de un caso concreto, puedes referirte a su nombre (`Spring`) cuando está definido en el mismo módulo, o cuando se importa con la sintaxis `import SeasonModule exposing (Season(..))`, o bien referirte a su nombre completo (`Season.Spring`) cuando se importa con la sintaxis `import SeasonModule exposing (Season)`.

```elm
integerTwo = Integer 2
invalid = FlexibleNumber.Invalid
```

Los tipos personalizados, al igual que todo en Elm, tienen _igualdad estructural_, lo que significa que dos valores del mismo caso y con los mismos datos (opcionales) son equivalentes.

La forma preferida de trabajar con tipos personalizados es la [coincidencia de patrones][pattern-matching]:

```elm
let describe flexibleNumber =
    case flexibleNumber of
        Integer i ->
            "Integer: " ++ fromInt(i)

        Float f ->
            "Float: " ++ fromFloat(f)

        Invalid   ->
            "Invalid"
```
