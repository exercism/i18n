# Excepciones

Algunas rutinas no pueden responder. Cuando se le pide una prop que no está sobre la mesa, `count_of` no tiene ningún número que dar. Y cero sería una mentira, porque cero significa «no tenemos ninguna de esas», no «no existe tal cosa».

Una **excepción** es la forma que tiene una rutina de decir que no puede responder.

## Lanzamiento

`raise` abandona la rutina y entrega un valor a quien la llamó.

```sather
   count_of(props : FMAP{STR,INT}, prop : STR) : INT is
      if ~props.has_ind(prop) then
         raise "Unknown prop: " + prop;
      end;
      return props.get(prop);
   end;
```

Nada de lo que hay después de un `raise` se ejecuta. La rutina no devuelve nada, así que no hay respuesta que comprobar ni forma de que quien la llamó siga adelante como si la hubiera.

El valor lanzado suele ser un string que dice qué ha ido mal.

## Captura

`protect` ejecuta un fragmento de código, preparado por si este lanza una excepción.

```sather
   protect
      taken ::= count_of(props, prop);
      #OUT + "There are " + taken;
   when $STR then
      #OUT + "Cannot: " + exception.str;
   end;
```

Si nada lanza una excepción, se ejecuta la parte que hay después de `protect` y se salta la rama `when`. Si algo lanza una excepción, se abandona el resto de la parte `protect` y en su lugar se ejecuta el `when` correspondiente.

`when $STR then` captura un string lanzado. `exception` es el valor que se lanzó, disponible dentro de la rama.

## Propagación

Una rutina que no captura una excepción no tiene que hacer nada al respecto. Esta se propaga hacia fuera, a través de cada rutina que la llama, hasta que algo la captura:

```sather
   take_one(props : FMAP{STR,INT}, prop : STR) : INT is
      -- If this raises, take_one raises too. Nothing here says so.
      have ::= count_of(props, prop);
      ...
   end;
```

Eso es precisamente lo útil de las excepciones. La rutina que detecta el problema y la rutina que sabe qué hacer al respecto normalmente no son la misma, y todo lo que hay entre ambas puede ignorarlo.
