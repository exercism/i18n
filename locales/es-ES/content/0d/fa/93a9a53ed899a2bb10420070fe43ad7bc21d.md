# Introducción

## Arrays

En C#, las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_. Un **array** es una colección que tiene un tamaño o longitud fijo y cuyos elementos deben ser todos del mismo tipo. Los elementos se pueden asignar a un array o recuperar de él mediante un índice. Los arrays de C# están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true
```

Los arrays también se pueden definir con una notación abreviada que te permite tanto crear el array como establecer su valor. Como ahora el compilador puede saber cuántos elementos tendrá el array, se puede omitir la longitud:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Los arrays se pueden manipular llamando a los métodos o propiedades de una instancia de array, o usando los métodos estáticos definidos en la clase `Array`.

## Bucles for

Un bucle `for` permite ejecutar código repetidamente en un bucle hasta que se cumple una condición.

```csharp
for (int i = 0; i < 5; i++)
{
    System.Console.Write(i);
}

// => 01234
```

Un bucle `for` consta de cuatro partes:

1. El inicializador: se ejecuta una vez antes de entrar en el bucle. Normalmente se usa para definir variables que se utilizan dentro del bucle.
2. La condición: se evalúa antes de cada iteración del bucle. El bucle sigue ejecutándose mientras esto se evalúe como `true`.
3. El iterador: se ejecuta después de cada iteración del bucle. Normalmente se usa para modificar (a menudo, incrementar o decrementar) la o las variables del bucle.
4. El cuerpo: el código que se ejecuta en cada iteración del bucle.

## Bucles foreach

Que un array sea también una _colección_ significa que, además de acceder a sus valores por índice, puedes iterar sobre _todos_ sus valores usando un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```
