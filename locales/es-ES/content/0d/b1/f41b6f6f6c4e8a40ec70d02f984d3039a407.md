# Ayuda

A continuación tienes algunos recursos para conseguir ayuda si te encuentras con algún problema:

- La [página web principal del proyecto Uiua][main] aloja [documentación][docs], ejemplos, tutoriales y recursos de la comunidad.
- [La comunidad de Exercism en Discord][exercism-discord]
- [La comunidad de Uiua en Discord][discord] es una comunidad muy activa y de gran ayuda.
- El [tutorial de introducción][tutorial] ofrece una visión general y tiene pequeños ejercicios para aprender Uiua.
- [Uiua Pad][pad] para recorrer pequeños fragmentos de código de forma visual.
- [/r/apljk/][apl-reddit] es un subreddit para lenguajes similares a APL.

Además, [StackOverflow][so] es un buen lugar para buscar tu problema o pregunta y ver si ya se ha respondido.
Si no es así, siempre puedes [preguntar][ask-so] o [responder][answer-so] a la pregunta de otra persona.
