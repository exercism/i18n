# Instrucciones

Mientras te preparas para hornear galletas para tus amigos, te has dado cuenta de que tienes que convertir algunas de las medidas que usa la receta.
Como solo conoces el sistema métrico, necesitas encontrar la forma de convertir las medidas de repostería estadounidenses más habituales a mililitros (mL) para tu propia comodidad.

Usa esta tabla de conversión para tu solución:

| Unidad a convertir | volumen | en mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| taza estadounidense          | 1      | 240                 |
| onza líquida estadounidense  | 1      | 30                  |
| cucharadita estadounidense     | 1      | 5                   |
| cucharada estadounidense   | 1      | 15                  |

Como eres un programador talentoso en formación, decides usar los mililitros como unidad de transición para facilitar la conversión de cualquier unidad de la lista a cualquier otra (incluso a sí misma).

## 1. Obtén el componente numérico de una tupla de volumen

Implementa el método `KitchenCalculator.get_volume`.
Dada una tupla de volumen, debe devolver solo el componente numérico.

```crystal
KitchenCalculator.get_volume({:cup, 2.0})
# => 2.0
```

## 2. Convierte la tupla de volumen a mililitros

Implementa el método `KitchenCalculator.to_milliliter`.
Dada una tupla de volumen, debe convertir el volumen a mililitros usando la tabla de conversión.

```crystal
KitchenCalculator.to_milliliter({:cup, 2.5})
# => {:milliliter, 600.0}
```

## 3. Convierte la tupla de volumen en mililitros a otra unidad

Implementa el método `KitchenCalculator.from_milliliter`.
Dada una tupla de volumen y la unidad deseada, debe convertir el volumen a la unidad deseada usando la tabla de conversión.

```crystal
KitchenCalculator.from_milliliter({:milliliter, 1320.0}, :cup)
# => {:cup, 5.5}
```

## 4. Convierte de cualquier unidad a cualquier unidad

Implementa el método `KitchenCalculator.convert`.
Dada una tupla de volumen y la unidad deseada, debe convertir el volumen dado a la unidad deseada.

```crystal
KitchenCalculator.convert({:teaspoon, 9.0}, :tablespoon)
# => {:tablespoon, 3.0}
```
