# Acerca de

Cualquier valor puede ser un error. `throw` (en `kernel`) lanza una señal; se abandona el efecto de pila de la word actual y el control se desenrolla hasta el `recover` envolvente más cercano.

```factor
[ 0 1 / ] [ "div by zero" prepend ] recover
```

`ERROR:` es una word de análisis sintáctico que define una clase de tupla de error *y* una word constructora de una sola vez:

```factor
ERROR: not-found path ;
! defines:
!   TUPLE: not-found path ;
!   : not-found ( path -- * ) \ not-found boa throw ;
!   : not-found? ( object -- ? ) … class predicate
```

Así, cada error personalizado tiene una clase única, un cómodo constructor que lo lanza y un predicado de clase (`name?`) con el que comprobar los errores capturados:

```factor
[ "/missing" not-found ]
[ dup not-found? [ path>> "missing: " prepend ] [ drop "other" ] if ]
recover
```

Para una limpieza al estilo de `finally`, consulta `cleanup` en `continuations`. Para condiciones reiniciables, consulta `condition`.
