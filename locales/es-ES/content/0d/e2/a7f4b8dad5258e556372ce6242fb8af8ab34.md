# Anexo a las instrucciones

## Implementación

Para completar este ejercicio necesitas definir el tipo de dato `stopwatch` e implementar las funciones:

- newStopwatch
- start
- stop
- lap
- reset
- advanceTime
- getState
- currentLap
- total
- previousLaps

Encontrarás una definición de tipo ficticia ya en su sitio, pero depende de ti definir las funciones y crear un tipo de dato que tenga sentido.
