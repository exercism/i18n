# Acerca de

Lua usa dos representaciones para los números: números enteros de 64 bits y números de coma flotante de doble precisión.

~~~exercism/note
Antes de la versión 5.3, Lua representaba todos los números con el formato de coma flotante de doble precisión.
~~~

Los números se pueden escribir con una parte decimal opcional, además de un exponente decimal opcional.
```lua
1               --> 1
0.2             --> 0.2
0.3e4           --> 3000.0
4.0e-3          --> 0.004
5.0e+20         --> 5e+20
```

Un número con una parte decimal o un exponente se considera un decimal, y sin ellos se trata como un entero, pero ambos tienen el tipo 'number'.
```lua
type(1)         --> number
type(2.0)       --> number
```

Si queremos distinguir entre decimales y enteros, se puede usar la función `type` del módulo `math`.
```lua
math.type(1)    --> integer
math.type(2.0)  --> float
```

## Comparación

Los enteros y los decimales con el mismo valor se comparan como iguales:
```lua
1 == 1.0        --> true
-2 == -2.0      --> true
0.3e3 == 300    --> true
```

## Aritmética

Lua admite el conjunto habitual de operadores aritméticos: suma, resta, multiplicación, división y negación. Además, admite la división entera, el módulo y la potenciación.

### Suma, resta, multiplicación y negación

Si ambos operandos son enteros, el resultado de la operación es un entero. Lo mismo se aplica a los decimales.
```lua
1 + 2     --> 3
1.0 + 2.0 --> 3.0
```

Si un operando es un decimal, los enteros restantes también se convertirán a decimales y la operación dará como resultado un decimal.
```lua
1.0 + 2   --> 3.0
```

### División

La división siempre opera con decimales y da un decimal como resultado.
```lua
1.0 / 2.0 --> 0.5
2 / 1     --> 2.0
```

Dividir por cero dará como resultado `inf` o `-inf`. Dividir cero por cero dará como resultado `-nan`.
```lua
1 / 0     --> inf
-1 / 0    --> -inf
0 / 0     --> -nan
```

### División entera

Si se necesita un resultado entero, se puede usar la división entera. La división entera siempre redondea el cociente hacia menos infinito, lo que garantiza un resultado entero para todos los operandos.

~~~exercism/note
Antes de la versión 5.3, Lua no tenía ningún operador aritmético para la división entera.
~~~

```lua
3 // 2    --> 1
6 // 2    --> 3
```

La división entera sigue las mismas reglas que los operadores de suma, resta, multiplicación y negación: si ambos operandos son enteros, el resultado de la operación es un entero; en caso contrario, el resultado es un decimal.

```lua
3.0 // 2   --> 1.0
6.0 // 2.0 --> 3.0
```

Al dividir por cero con la división entera, Lua lanzará un error.
```lua
3 // 0     --> stdin:1: attempt to divide by zero
```

### Módulo

El módulo se usa para obtener el residuo de la división de dos operandos.
```lua
8 % 2      --> 0
13 % 9     --> 4
-13 % -9   --> -4
-13 % 9    --> 5
13 % -9    --> -5
0.3 % 0.2  --> 0.1
```

### Potenciación

Al igual que la división, la potenciación también opera con decimales y da decimales como resultado.
```lua
10 ^ 2    --> 100.0
```

## Precedencia

Todas las operaciones se evalúan según la [precedencia de operadores](https://www.lua.org/manual/5.4/manual.html#3.4.8). Se pueden usar paréntesis para cambiar la precedencia de una expresión.

```lua
1 + 2 * 3   --> 7
(1 + 2) * 3 --> 9
```

## Redondeo

El módulo `math` proporciona tres funciones de redondeo: `floor` redondea «hacia abajo» (hacia menos infinito), `ceil` redondea «hacia arriba» (hacia más infinito) y `modf` redondea hacia cero.

### `math.floor`

`floor` redondea hacia menos infinito.
```lua
math.floor(1.3)    --> 1
math.floor(-1.3)   --> -2
```

### `math.ceil`

`ceil` redondea hacia más infinito.
```lua
math.ceil(1.3)    --> 2
math.ceil(-1.3)   --> -1
```

### `math.modf`

`modf` redondea hacia cero. La función devuelve el valor redondeado, así como la parte fraccionaria del número, que siempre es un decimal.
```lua
math.modf(1.3)    --> 1    0.3
math.modf(-1.3)   --> -1   -0.3
```

## Conversión

Si queremos convertir un entero en un decimal, podemos sumarle `0.0`.
```lua
1 + 0.0         --> 1.0
```

Si queremos convertir un decimal en un entero, podemos aplicarle un OR bit a bit con cero o usar la función `tointeger` del módulo `math`.
```lua
1.0 | 0              --> 1
math.tointeger(1.0)  --> 1
```

Si el número no se puede convertir a un entero, el operador OR lanzará un error y la función `tointeger` devolverá `nil`.
```lua
1.1 | 0              --> stdin:1: number has no integer representation
math.tointeger(1.1)  --> nil
```

## Hexadecimal

Como muchos otros lenguajes de programación, Lua admite números hexadecimales si se prefijan con `0x`, pero, a diferencia de muchos otros lenguajes de programación, Lua también admite números hexadecimales en coma flotante. Pueden tener una parte fraccionaria y un exponente binario, prefijado con «p» o «P».
```lua
0xff            --> 255
0x0.2           --> 0.125
0x3p-1          --> 1.5
0xa.bp2         --> 42.75
```
