# error al lanzar una cláusula de función

[comment]: # (Este error se produce cuando la solución incluye una llamada a `raise FunctionClauseError` en lugar de dejar que Elixir falle al hacer coincidir la llamada a la función two_fer para tipos que no son string.)

No llames directamente a `raise FunctionClauseError`.

> Lanzar este error es un [code smell](https://en.wikipedia.org/wiki/Code_smell) que indica que conviene reordenar las cláusulas de función o implementar guardas para evitar que la función coincida.

1. Cuando Elixir ejecuta código, intenta hacer coincidir la llamada a las [funciones con nombre](https://elixir-lang.org/getting-started/modules-and-functions.html#named-functions) y sus parámetros con cada función, de arriba abajo.
2. Si se usan [guardas](https://hexdocs.pm/elixir/master/guards.html), es posible evitar que se invoque una función con argumentos que no se correspondan con el uso previsto de esa función.
3. Si no hay coincidencia para una función con nombre, la [BEAM VM](<https://en.wikipedia.org/wiki/BEAM_(Erlang_virtual_machine)>) lanza un `FunctionClauseError` en tiempo de ejecución.
