# Instrucciones

Elena, la nueva responsable de calidad de una fábrica de periódicos, te pide
que escribas un pequeño programa para vigilar la sala de producción.

## 1. Define un error personalizado

Define una clase de tupla de error `machine-error` con la palabra de análisis
`ERROR:`. No necesita slots.

```factor
machine-error   ! throws a fresh machine-error
```

## 2. Comprueba la humedad

Define `check-humidity`. Toma una lectura de humedad de la pila y lanza con
`throw` la cadena `"humidity too high"` cuando la lectura es estrictamente
mayor que `70`. En caso contrario, no devuelve nada.

```factor
50 check-humidity   ! returns nothing
80 check-humidity   ! throws "humidity too high"
```

## 3. Comprueba la temperatura

Define `check-temperature`. Toma una lectura de temperatura y lanza con
`throw` la cadena `"temperature too high"` cuando la lectura es estrictamente
mayor que `500`. En caso contrario, no devuelve nada.

```factor
400 check-temperature   ! returns nothing
600 check-temperature   ! throws "temperature too high"
```

## 4. Vigila la máquina

Define `monitor` para que tome una humedad y una temperatura de la pila y
ejecute ambas comprobaciones. Si alguna de las comprobaciones lanza un error,
`monitor` debe lanzar en su lugar un `machine-error` nuevo. Si ambas pasan,
`monitor` no devuelve nada.

```factor
50 400 monitor   ! returns nothing
80 400 monitor   ! throws a machine-error
50 600 monitor   ! throws a machine-error
```

## 5. Vigila un lote de lecturas

Define `monitor-batch` para que tome un array de lecturas
`{ humidity temperature }` y devuelva cuántas de ellas fallarían (es decir,
cuántas harían que `monitor` lanzara un error).

```factor
{ { 50 400 } { 80 400 } { 50 600 } { 60 200 } } monitor-batch .
! => 2
```
