# Anexo de instrucciones

Una posible solución para este ejercicio es implementar tu propia función de exponenciación modular.
Para saber más al respecto, consulta la [siguiente página](https://en.wikipedia.org/wiki/Modular_exponentiation).

## Puntos extra

Muchas implementaciones no funcionan para todo el dominio de entradas.
Hay pruebas opcionales adicionales definidas que ayudan a garantizar que todas las entradas válidas produzcan resultados válidos.

Para ejecutar las pruebas de puntos extra, elimina el flag `#[ignore]` y ejecuta las pruebas con
la característica `big-primes`, así:

```bash
$ cargo test --features big-primes
```
