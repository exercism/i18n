# Introducción

## Arrays

En Common Lisp, como en otros lenguajes, un array es un conjunto de elementos a los que se accede mediante índices enteros.
Los tipos de los elementos pueden ser heterogéneos.
El array puede ser multidimensional (no solo unidimensional).

### Creación

`make-array` permite crear arrays.
Tiene muchas opciones, pero sus formas más sencillas permiten crear arrays N-dimensionales con todos los elementos inicializados a un único valor, o crear el array inicializado con los valores de otra secuencia (como una lista).
Su primer argumento es una lista con el tamaño de cada dimensión.

```lisp
(make-array '(4) :initial-element 3)    ; => #(3 3 3 3)
(make-array '(2 2) :initial-element 'x) ; => #2A((X X) (X X))
```

(Fíjate en que los arrays N-dimensionales se imprimen con el número de dimensiones.)

También se pueden crear arrays usando el mismo formato en el que se imprimen:

```lisp
#(x y z)         ; => #(X Y Z)
#2A((1 2) (3 4)) ; => #2A((1 2) (3 4))
```

### Acceso a los elementos

Para acceder a los elementos de un vector, usa `aref`; los índices empiezan en cero.
El número de índices proporcionados debe coincidir con el rango del array.

```lisp
(aref #2A((1 2 3) (3 4 5)) 
       1 0)           ; => 3
(aref #3A(((a b) (c d)) 
           ((e f) (g h)) 
           ((t u) (v w))) 
       2 0 1)         ; => U
(aref #2A((1) (2)) 0) ; => ERROR (because not enough indexes provided)
```
