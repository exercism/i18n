# Instrucciones

Un búfer circular, búfer cíclico o búfer en anillo es una estructura de datos que usa un único búfer de tamaño fijo como si estuviera conectado de extremo a extremo.

Un búfer circular empieza vacío y con una longitud predefinida.
Por ejemplo, este es un búfer de 7 elementos:

```text
[ ][ ][ ][ ][ ][ ][ ]
```

Supón que se escribe un 1 en el centro del búfer (la ubicación inicial exacta no importa en un búfer circular):

```text
[ ][ ][ ][1][ ][ ][ ]
```

Después, supón que se añaden dos elementos más, 2 y 3, que quedan a continuación del 1:

```text
[ ][ ][ ][1][2][3][ ]
```

Si luego se eliminan dos elementos del búfer, se eliminan los valores más antiguos que contiene.
Los dos elementos eliminados, en este caso, son el 1 y el 2, con lo que el búfer se queda solo con un 3:

```text
[ ][ ][ ][ ][ ][3][ ]
```

Si el búfer tiene 7 elementos, entonces está completamente lleno:

```text
[5][6][7][8][9][3][4]
```

Cuando el búfer está lleno se producirá un error, que avisará al cliente de que las escrituras posteriores están bloqueadas hasta que se libere una posición.

Cuando el búfer está lleno, el cliente puede optar por sobrescribir los datos más antiguos con una escritura forzada.
En este caso, se añaden dos elementos más, A y B, que sobrescriben el 3 y el 4:

```text
[5][6][7][8][9][A][B]
```

El 3 y el 4 han sido reemplazados por A y B, con lo que el 5 pasa a ser ahora el dato más antiguo del búfer.
Por último, si se eliminan dos elementos, lo que se devolvería es el 5 y el 6, lo que da como resultado el búfer:

```text
[ ][ ][7][8][9][A][B]
```

Como hay espacio disponible, si el cliente vuelve a usar la sobrescritura para guardar C y D, se usará el espacio donde antes se guardaron el 5 y el 6, no la ubicación del 7 y el 8.
El 7 sigue siendo el elemento más antiguo y el búfer vuelve a estar lleno.

```text
[C][D][7][8][9][A][B]
```
