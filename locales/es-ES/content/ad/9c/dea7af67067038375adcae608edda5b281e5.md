# Introducción

Cuando necesitas una secuencia de `n` valores en la que cada uno depende
de su índice, Factor te ofrece `<iota>`, una secuencia virtual de los
números enteros `0, 1, …, n-1`, y `map`:

```factor
USING: math sequences ;

5 <iota> [ 2 * ] map .   ! => { 0 2 4 6 8 }
```

`<iota>` no reserva los enteros de antemano; `map` los recorre
en orden y aplica la quotation a cada uno.

Si el resultado de cada posición es un código de carácter, `>string`
convierte el resultado en un string, la forma natural de ensamblar una
fila de caracteres a partir de decisiones basadas en el índice:

```factor
USING: strings ;

5 <iota> [ CHAR: a + ] map >string .   ! => "abcde"
```

[strings]: https://docs.factorcode.org/content/article-strings.html
