# Anexo de las instrucciones

## Palabras

- `can-chain? ( dominoes -- ? )`: devuelve `t` si las fichas de dominó se pueden colocar formando una cadena cerrada.

Cada ficha se guarda como un único byte, con la mitad izquierda en el [nibble] alto y la mitad derecha en el [nibble] bajo. Por ejemplo, las fichas `[2|1]`, `[2|3]` y `[1|3]` se representan como el array de bytes `{ 0x21 0x23 0x13 }`.

[nibble]: https://en.wikipedia.org/wiki/Nibble
