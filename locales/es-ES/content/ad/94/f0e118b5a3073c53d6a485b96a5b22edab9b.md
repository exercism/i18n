# Apéndice de las instrucciones

## Valor entero máximo

Según [la documentación de Vim][number]:

> Suponiendo que se usen números de 64 bits (consulta `v:numbersize`), un número sin signo se trunca a 0x7fffffffffffffff o 9223372036854775807.

En otras palabras, Vim script no puede expresar ningún número `2^63` o mayor como un entero.

Algunas de las pruebas de este ejercicio requieren enteros de 64 bits, lo que supera la limitación de tamaño de los enteros de Vim script.
Debido a esta limitación, los resultados de los cálculos se comprueban contra un string que expresa el valor entero, en lugar de expresar la respuesta como Integer.
¿Puedes resolverlo evitando los números que sean mayores de lo que el lenguaje permite directamente?

[number]: https://vimhelp.org/eval.txt.html#expr-number
