# Introducción

## Alias de tipo

En Gleam, un alias de tipo permite dar un nombre cómodo a un tipo que ya existe y que, de otro modo, resultaría engorroso de escribir.

```gleam
pub type Headers =
  List(#(String, String))

pub fn html_headers() -> Headers {
  [
    #("content-type", "text/html"),
    #("x-frame-options", "DENY"),
  ]
}
```

Cuando se escribe con `pub type`, el alias se puede usar fuera del módulo en el que se define. Si se omite `pub`, el alias es privado y no se puede hacer referencia a él desde otros módulos.
