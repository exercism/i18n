# Anexo a las instrucciones

## Pistas

Para completar este ejercicio tienes que crear el tipo de datos `School`
e implementar las siguientes funciones:

- `add`
- `empty`
- `grade`
- `sorted`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya en su
sitio, pero depende de ti definir las funciones y crear un tipo de datos, un
newtype o un sinónimo de tipo con sentido.
