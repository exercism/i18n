# Introducción

## Tipos personalizados

Los tipos personalizados son la forma de definir nuevos tipos de datos en Gleam. Pueden tener varias _variantes_, cada una con su propio nombre.

```gleam
pub type Season {
  Spring
  Summer
  Autumn
  Winter
}
```

Cada caso de un tipo personalizado puede contener datos de forma opcional, y casos distintos pueden tener distintos tipos de datos. Cuando una variante contiene datos, se denomina _registro_.

```gleam
pub type Number {
  SomeInt(Int)
  SomeFloat(Float)
  Invalid
}
```

Se puede crear un valor para un caso concreto refiriéndose a su nombre si no contiene datos adicionales (`Spring`), o llamándolo como si fuera una función si los contiene (`SomeInt(2)`).

```gleam
let spring = Spring
let integerTwo = SomeInt(2)
```

Los tipos personalizados, como todo en Gleam, tienen _igualdad estructural_, lo que significa que dos valores de la misma variante y con los mismos datos son equivalentes.

```gleam
Spring == Spring // -> True
Spring == Autumn // -> False
SomeInt(2) == SomeInt(2) // -> True
SomeInt(2) == SomeFloat(2.0) // -> False
```

Se puede hacer coincidir patrones sobre las variantes de un tipo personalizado usando expresiones `case`.

```gleam
import gleam/int
import gleam/float

pub fn describe(flexible_number: Number) -> String {
  case flexible_number {
    SomeFloat(f) -> "Float: " <> float.to_string(f)
    SomeInt(i) -> "Int: " <> int.to_string(i)
    Invalid -> "Neither a float nor an int"
  }
}
```
