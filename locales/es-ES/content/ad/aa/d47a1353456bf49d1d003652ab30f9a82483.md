# Requisitos previos

El track de D requiere que tengas el siguiente software instalado en tu sistema:

* un compilador de D versión 2
* (opcional, pero recomendado) DUB

## Requisito previo: compilador de D versión 2

En el sitio web del lenguaje D, [dlang.org](https://dlang.org), puedes descargar e instalar la versión más reciente del compilador de referencia DMD (Digital Mars D) para varias plataformas.
Consulta la [página oficial de descargas](https://dlang.org/download.html) para obtener más información.
En Windows, una solución alternativa es [usar Chocolatey](https://chocolatey.org/packages/dmd).
En los Mac con procesador Intel, una solución alternativa es [usar Homebrew](https://formulae.brew.sh/formula/dmd).

### Otros compiladores

Además del compilador de referencia DMD, que usa su propio backend, hay otros dos compiladores que puedes obtener en la sección de descargas de dlang.org:

* [GDC](http://gdcproject.org/downloads), que usa el backend de GCC
* [LDC](https://github.com/ldc-developers/ldc#installation), basado en el backend de LLVM

GDC y LDC no siempre están a la última versión del frontend de DMD, pero ofrecen mejores niveles de optimización, así como compatibilidad con otras plataformas, como ARM.

Consulta la wiki para [obtener más información](https://wiki.dlang.org/Compilers).

### Compatibilidad con IDE

También hay compatibilidad con el lenguaje D en varios IDE, por ejemplo [VisualD](http://rainers.github.io/visuald/visuald/StartPage.html) para Visual Studio y el [plugin de D](https://plugins.jetbrains.com/plugin/7727?pr=clion) para CLion de IntelliJ.
Consulta la wiki para [obtener más información](https://wiki.dlang.org/IDEs).

### Requisito previo: DUB

[DUB](https://github.com/dlang/dub) es un gestor de compilación para D.

Lo recomendamos para simplificar el proceso de ejecutar las pruebas, pero todavía es posible ejecutarlas sin DUB si no puedes instalarlo o no quieres hacerlo.

#### Windows

La [página de descargas del sitio web de DUB](https://code.dlang.org/download) tiene un instalador para Windows.

* La [página de descargas del sitio web de DUB](https://code.dlang.org/download) tiene binarios para macOS.
