# Instalación

## Qué se necesita

Los elementos básicos que se necesitan para desarrollar en Common Lisp son:

- Una «implementación» de Lisp, que te permitirá compilar y ejecutar código y también te proporcionará un REPL.
- Un editor de texto con herramientas para trabajar con código Lisp. 
- (Recomendable) La referencia que se usa a menudo para el lenguaje Common Lisp, el [«Common Lisp Hyperspec»][hyperspec].

## Roswell

[Roswell][roswell] es un comando para instalar y gestionar implementaciones de Common Lisp, y muchas funcionalidades que facilitan el desarrollo y la distribución de aplicaciones Lisp.
Lo usamos para simplificar los pasos de instalación y de pruebas.

### Instalar Roswell

Consulta la [guía de instalación][ros-inst] y sigue las instrucciones para tu plataforma.
Para la mayoría de los usuarios, lo siguiente será suficiente:

* Para MacOS y Linux, [Homebrew][brew] lo hace muy fácil:
  ```sh
  brew install roswell
  ```
* Para Windows, usa [Scoop][scoop]:
  ```powershell
  scoop install roswell
  ```

La primera vez que uses Roswell, descargará e instalará SBCL y Quicklisp.
Solo tienes que ejecutar esto:
```sh
ros help
```

Para entrar en el REPL, ejecuta
```sh
ros run
```

## Configura tu editor de texto

Quienes son nuevos en Common Lisp, y en particular quienes ya tienen experiencia previa con Emacs, pueden empezar de forma rápida y sencilla instalando [Portacle, el entorno portátil de Common Lisp][portacle]. 
Es gratuito y completo, funciona en todas las plataformas habituales y viene preconfigurado «listo para usar». Incluye:

- Una implementación de Lisp: SBCL, que incluye Quicklisp y ASDF.
- Un editor de texto: Emacs

... con un montón de complementos para escribir código Lisp: 
- SLIME, el «Superior Lisp Interaction Mode for Emacs», convierte Emacs en un IDE de Common Lisp
- ParEdit, que facilita el trabajo con paréntesis. 

Todo viene ya configurado y listo para usar. Instala Portacle descargándolo desde la [página principal][portacle].

Nota: Emacs (el editor de texto) puede resultar desconcertante al principio si no estás acostumbrado a él. Por suerte, hay muchos manuales introductorios sobre Emacs y SLIME disponibles en internet. 

## Inicio tradicional

Si prefieres instalar las herramientas necesarias por separado, tendrás que instalar y configurar:

- un editor de texto con soporte para Lisp: [Emacs][emacs] con el paquete [Slime][slime] o [Sly][sly] es una elección habitual, pero [VIM][vim] con [SLIMV][slimv], [Atom][atom] con [SLIMA][slima] o [VSCode][vscode] con un [complemento de Common Lisp][vscode-plugin] también son buenas opciones.
- una implementación de Common Lisp: [SBCL][sbcl] es una elección «segura» que funciona en Linux, MacOS y Windows. Como el lenguaje se basa en un estándar, otras [implementaciones conformes][awesome-cl-implementations] también funcionarán.
- [Quicklisp][quicklisp] para gestionar bibliotecas. Después de descargarlo, sigue las [instrucciones][quicklisp-install] para asegurarte de que se integra correctamente con tu implementación de Common Lisp.
