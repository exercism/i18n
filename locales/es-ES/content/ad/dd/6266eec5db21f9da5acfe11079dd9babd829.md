# Introducción

## Estructuras

Las estructuras son una extensión construida sobre los [mapas][exercism-maps] y proporcionan comprobaciones en tiempo de compilación y valores por defecto. Una estructura recibe el nombre del módulo en el que se define. Para definir una estructura, usa el constructor `defstruct`. El constructor normalmente va justo después de la definición del módulo. `defstruct` acepta una lista de átomos (para que los valores por defecto sean `nil`) o una lista de palabras clave (para valores por defecto especificados). Los campos sin valores por defecto deben preceder a los campos con valores por defecto.

```elixir
defmodule Plane do
  defstruct [:engine, wings: 2]
end

plane = %Plane{}
# => %Plane{engine: nil, wings: 2}
```

### Acceder a los campos y actualizarlos

Como las estructuras se construyen sobre mapas, podemos usar la mayoría de las funciones de mapas para obtener y manipular valores. El _comportamiento Access_ **no** está implementado para las estructuras. En su lugar, se recomienda usar el _operador de acceso estático_ `.` para acceder a los campos de la estructura.

- obtener/consultar los valores de los campos:

  ```elixir
  plane = %Plane{}
  plane.engine
  # => nil
  Map.fetch(plane, :wings)
  # => {:ok, 2}
  ```

- actualizar los valores de los campos

  ```elixir
  plane = %Plane{}
  %{plane | wings: 4}
  # => %Plane{engine: nil, wings: 4}
  ```

### Coincidencia de patrones

Las estructuras se pueden usar en la coincidencia de patrones con o sin el nombre de la estructura.

```elixir
plane = %Plane{}
%Plane{wings: wings} = plane
%{wings: wings} = plane
```

Al incluir el nombre de la estructura en el patrón, puedes asegurarte de que tanto el lado izquierdo como el derecho sean estructuras del mismo tipo.

```elixir
defmodule Helicopter do
  defstruct [:engine, rotors: 1]
end

%Plane{} = %Helicopter{}
# => (MatchError) no match of right hand side value: %Helicopter{engine: nil, rotors: 1}
```

### Forzar la inicialización de los valores de los campos

Podemos usar el atributo de módulo `@enforce_keys` con una lista de las claves de los campos para asegurarnos de que los valores se inicialicen cuando se crea la estructura. Si una clave no está en la lista, su valor será `nil`, como se ve en el ejemplo anterior. Si una clave forzada no se inicializa, se lanza un error.

```elixir
defmodule User do
  @enforce_keys [:username]
  defstruct [:username]
end

%User{}
# => (ArgumentError) the following keys must also be given when building struct User: [:username]
```
