# Instrucciones

Estamos poniendo en marcha un club de quesos que usará aprendizaje automático para seleccionar nuevos quesos que ofrecer a nuestros clientes amantes del queso, basándose en sus historiales y sus gustos.

Los nuevos miembros deben rellenar una encuesta inicial para que podamos recopilar algunos datos básicos con los que empezar. Gracias a ella, se ha descubierto que hay un subconjunto de clientes enfáticos que carecen de matices en sus críticas. Como esto puede acabar sesgando de forma irrevocable un algoritmo más matizado, hay un algoritmo aparte para atender sus necesidades. Se te pide que escribas algunas funciones auxiliares para manejar sus datos.

~~~~exercism/note
Aunque puede haber distintas maneras de resolver las siguientes tareas, todas se pueden resolver con no más de dos funciones de orden superior.
~~~~

## 1. Clasifica a los clientes

El sistema de valoraciones se basa en cinco estrellas, que simplemente se corresponden con los números enteros del `1:5`. Los clientes enfáticos solo darán valoraciones de `1` o `5`, y queremos saber si un cliente muestra este comportamiento.

Implementa `all_15()`, que recibe un vector de valoraciones y devuelve `true` si todas las valoraciones son `1` o `5`, y `false` en caso contrario.

```R
all_15(c(2, 3, 4, 4, 1))
#> [1] FALSE

all_15(c(1, 5, 5, 1, 5))
#> [1] TRUE
```

## 2. Nombra a los clientes

Necesitamos asociar el nombre del cliente (o su ID) con sus valoraciones.

Implementa `name_customers()`, que recibe un vector de nombres y una lista de valoraciones, y los «combina» en una lista de listas.

Los elementos de las listas interiores deben tener los nombres `name` y `rating`.

```R
names <- c("c1", "c2")
ratings <- list(c(2, 3, 5), c(1, 1, 5))
name_customers(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c1"

#> [[1]]$rating
#> [1] 2 3 5

#> [[2]]
#> [[2]]$name
#> [1] "c2"

#> [[2]]$rating
#> [1] 1 1 5
```

## 3. Separa a los clientes enfáticos

Necesitamos separar a los clientes más enfáticos de los demás.

Implementa `emphatics()`, que recibe clientes y valoraciones. Devuelve una lista restringida a aquellos que solo usan valoraciones de `1` o `5` estrellas.`

```R
# names and ratings as in the task 2 example

emphatics(names, ratings)
#> [[1]]
#> [[1]]$name
#> [1] "c2"

#> [[1]]$rating
#> [1] 1 1 5
```

## 4. Convierte las valoraciones a binario

Como los clientes enfáticos solo usan valoraciones de `1` y `5`, será más conveniente desde el punto de vista computacional cambiarlas a `0` y `1`.

Implementa `to_binary()`, que recibe un vector de valoraciones enfáticas. Devuelve las valoraciones en binario, donde `1` se ha cambiado a `0` y `5` se ha cambiado a `1`.

```R
to_binary(c(1, 1, 5, 5, 1))
#> [1] 0 0 1 1 0
```

## 5. Calcula la media de las valoraciones a lo largo del tiempo

Quieres seguir mejorando las recomendaciones para cada cliente (no solo para los enfáticos) con el tiempo, a medida que entiendes mejor sus gustos.

Implementa `satisfactions()`, que recibe un vector de valoraciones. Devuelve un vector de medias acumuladas hasta ese punto. Redondea los resultados a 2 decimales.

¡Esperemos que los números sigan creciendo, para tener clientes felices!

```R
satisfactions(c(1, 2, 2, 3))
#> [1] 1.00 1.50 1.67 2.00
```
