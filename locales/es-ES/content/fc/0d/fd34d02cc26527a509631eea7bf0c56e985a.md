# Caracteres

Un **carácter** es una sola letra, un dígito, un espacio o un signo. El tipo de Sather para un carácter es `CHAR`, y un carácter se escribe entre comillas simples.

```sather
   initial : CHAR is
      return 'M';
   end;
```

Comillas simples para un carácter, comillas dobles para un string. `'M'` y
`"M"` son tipos distintos y no se pueden intercambiar.

## Caracteres extraídos de un string

Un string es una fila de caracteres, y los corchetes alcanzan uno por su
posición, contando desde cero, igual que en un array.

```sather
"Marlowe"[0]      -- 'M'
"Marlowe"[3]      -- 'l'
```

## Preguntar por un carácter

| Llamada | Respuestas |
| --- | --- |
| `c.is_alpha` | ¿es una letra? |
| `c.is_digit` | ¿es uno de `0`–`9`? |
| `c.is_upper` | ¿es una mayúscula? |
| `c.is_lower` | ¿es una minúscula? |

Cada una responde `true` o `false`.

```sather
'M'.is_alpha      -- true
'7'.is_alpha      -- false
'7'.is_digit      -- true
```

## Cambiar entre mayúsculas y minúsculas

`.upper` devuelve la mayúscula de una letra, y `.lower` la minúscula.
Todo lo que no es una letra se devuelve tal cual.

```sather
'm'.upper         -- 'M'
'M'.lower         -- 'm'
'7'.upper         -- '7'
```

## Caracteres como números

Cada carácter tiene un número. `.int` lo devuelve, y `.char` convierte un
número de nuevo en un carácter.

```sather
'a'.int           -- 97
'b'.int           -- 98
98.char           -- 'b'
```

Los números exactos rara vez importan. Lo que importa es que las letras de
la `a` a la `z` estén en orden y unas junto a otras, así que
`'c'.int - 'a'.int` es 2, lo lejos que está la `c` a lo largo del alfabeto.
Eso es lo que hace funcionar una rueda de cifrado.
