# Introducción

La instrucción `guard` de Swift se usa para hacer retornos tempranos en funciones de Swift cuando no se cumple una condición necesaria que debe cumplirse para que continúe el procesamiento posterior, por ejemplo:

```swift
guard myValue >= 0 else { return 0 }
let root = myValue.squareRoot()
```

Aquí, el `guard` comprueba si la expresión booleana que sigue a la palabra clave `guard` se evalúa como verdadera. Si es así, el procesamiento continúa con el código que sigue a la instrucción `guard` (aquí `let root = myValue.squareRoot()`. En caso contrario, se ejecutará el código de la cláusula else. A diferencia de una instrucción `if`, una instrucción `guard` _debe_ tener una cláusula else, y a diferencia de la cláusula else de un if-else, la cláusula else de un guard _debe_ salir del scope de la instrucción guard. Es decir, debe usar una instrucción de transferencia de control como `return`, `continue` o `break`, o bien lanzar un error o salir del programa.
