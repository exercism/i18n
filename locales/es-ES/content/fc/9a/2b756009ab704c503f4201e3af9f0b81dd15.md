# Introducción

## Caracteres

El tipo `char` de C# es una cantidad de 16 bits que representa los componentes direccionables más pequeños del texto.
Varios `char` pueden formar un string como `"word"`, o bien los `char` pueden
procesarse de forma independiente. Sus literales se escriben entre comillas simples, por ejemplo `'A'`.

Los `char` de C# admiten la codificación Unicode UTF-16, por lo que, además del conjunto de caracteres latinos,
se pueden representar prácticamente todos los sistemas de escritura del mundo,
por ejemplo, la letra griega `'β'`.

Hay muchos métodos integrados en la biblioteca para inspeccionar y manipular `char`. Estos
se encuentran como métodos estáticos de la clase `System.Char`.

## String Builder

A veces, los `char` se usan junto con un objeto `StringBuilder`.
Este objeto tiene métodos que permiten construir un string
carácter a carácter y manipularlo. Al final del proceso
se puede llamar a `ToString` para obtener un string completo.
