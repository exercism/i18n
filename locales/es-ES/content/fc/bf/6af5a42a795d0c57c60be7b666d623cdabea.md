# Char

`Char` es un tipo de datos de Crystal que representa un punto de código [Unicode][unicode] de 32 bits.
Su tamaño los hace eficientes en memoria y les da propiedades específicas que los String no tienen.
Se crean con comillas simples (`'`) y solo permiten que se coloque dentro un único punto de código Unicode.

```crystal
'a' # => 'a'
'a'.class # => Char
```

Es bastante habitual trabajar con Char cuando se trabaja con String en Crystal, ya que bastantes métodos de la clase String devuelven Char o aceptan Char como argumentos.
Por ejemplo, el método [`String#[]`][index] devuelve un Char, o el método [`String#chars`][chars] devuelve una colección de Char.

## Incremento y decremento

Como un Char es un punto de código Unicode de 32 bits, admite incrementos y decrementos, lo que hace que, si tienes `'a'`, puedas obtener `'b'` sumando uno.

```crystal
'a' + 5
# => 'f'

'z' - 25
# => 'a'
```

También existe un método llamado [`Char#succ`][succ], que devuelve el siguiente Char de la tabla Unicode, y [`Char#pred`][pred], que devuelve el Char anterior de la tabla Unicode.

```crystal
'a'.succ
# => 'b'

'z'.pred
# => 'y'
```

## Concatenación

Como un Char solo está pensado para representar un punto de código Unicode de 32 bits, no se pueden concatenar dos Char.
Por lo tanto, los Char solo se pueden concatenar con String.

```Crystal
'a' + "bc"
# => "abc"

'a' + 'b'
# => error: expected argument #1 to 'Char#+' to be Int or String, not Char
```

## Métodos de propiedades

Crystal tiene algunos métodos para obtener información sobre un carácter, como si es un número o una letra, o si está en mayúsculas o en minúsculas.
Aquí tienes una lista con algunos de esos métodos; para ver la lista completa, consulta la [API de Char][char-api]:

| Método                           | Descripción                                          |
| -------------------------------- | ---------------------------------------------------- |
| [`Char#number?`][number]         | Devuelve `true` si el Char es un número              |
| [`Char#letter?`][letter]         | Devuelve `true` si el Char es una letra              |
| [`Char#lowercase?`][lowercase]   | Devuelve `true` si el Char está en minúsculas        |
| [`Char#uppercase?`][uppercase]   | Devuelve `true` si el Char está en mayúsculas        |
| [`Char#ascii?`][ascii]           | Devuelve `true` si el Char es un carácter ASCII      |
| [`Char#whitespace?`][whitespace] | Devuelve `true` si el Char es un carácter de espacio en blanco |

## Conversión

### Convertir entre puntos de código y Char

Como un Char es un punto de código Unicode de 32 bits, puedes convertir entre Char y puntos de código (Int).
Esto se puede hacer con el método [`Char#ord`][ord], que devuelve el punto de código del Char, o con el método [`Int#chr`][chr], que devuelve el Char correspondiente a ese punto de código.

```crystal
'a'.ord
# => 97

97.chr
# => 'a'
```

### Convertir entre tipos

Al igual que con otros tipos de datos, los Char tienen algunos métodos para convertir entre tipos.
El más habitual es el método `Char#to_s`, que convierte el Char en un String. Sin embargo, también están el método `Char#to_i`, que convierte el Char en un Int, y el método `Char#to_f`, que convierte el Char en un Float.

```crystal
'a'.to_s
# => "a"

'4'.to_i
# => 4

'a'.to_i
# => Error: Invalid integer: a (ArgumentError)
```
