# Acerca de

[Groovy](http://www.groovy-lang.org/) es el lenguaje dinámico, potente y con tipado opcional de la Apache Foundation, que además incorpora capacidades de tipado estático y de compilación estática.

Groovy tiene como objetivo mejorar la productividad de los desarrolladores gracias a una sintaxis concisa y fácil de aprender. Facilita el scripting, la creación de lenguajes específicos de dominio, la metaprogramación en tiempo de ejecución y en tiempo de compilación, y la programación funcional.

Permite acceder a todo el ecosistema de bibliotecas de Java y se integra a la perfección con aplicaciones Java.

Se puede usar como un lenguaje de scripting sencillo o añadir a complicados frameworks de Java.
Impulsa tecnologías como:
* Gradle,
* Spock,
* Ratpack,
* Grails,
* y el scripting en Jenkins.

Además, es divertido.
