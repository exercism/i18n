# Pistas

## General

- Para extraer varios argumentos en los parámetros de la función puedes empaquetarlos con `...<args>`.
- Para usar el resto y la propagación, usa el operador `...`.

## 1. Crea un array con todos los vagones

- Varios argumentos en los parámetros de la función se pueden empaquetar con la [sintaxis `...<args>` (spread)][spread-syntax].

## 2. Mueve los dos primeros elementos al final del array

- Puedes desempaquetar una serie de parámetros con [una asignación por desestructuración (`...`)][destructuring-assignment].
  Esto te permite extraer los dos primeros elementos de un `array` manteniendo intacto el resto.
- Para añadir otro `array` a un `array` existente, puedes usar el operador `...` para «propagar» el `array`.

## 3. Añade los valores que faltan

- Usando el desempaquetado con el operador rest (`...`), puedes extraer el primer elemento de un `array` manteniendo intacto el resto.
- Para añadir otro `array` a un `array` existente, puedes usar el operador `...` para «propagar» el `array`.

## 4. Amplía la información de ruta

- Para añadir otro `object` a un `object` existente, puedes usar el operador `...` para «propagar» el `object`.

## 5. Separa la hora de llegada de la información de ruta

- Para extraer un valor de un `object` manteniendo intacto el resto, puedes usar el operador rest (`...`).
