# Debug

Cuando falla un test, se muestra un mensaje que describe qué ha ido mal y con qué entrada.

Imprimir valores y el contenido de las variables también puede ayudar a entender qué ocurre.
PHP puede imprimir valores usando:

- `echo 'Debug message';` para mostrar un string de tu elección
- `var_dump($variable);` para obtener más información sobre un valor, por ejemplo, el tipo que ve PHP
