# Anexo a las instrucciones

## Nota

Construye este ejercicio pieza a pieza y no tengas miedo de extraer los conceptos útiles a una clase nueva.
Los ejercicios anteriores deberían darte la base para una solución limpia.

También podría resultarte útil repasar capítulos sobre el pensamiento orientado a objetos, por ejemplo [Inside Smalltalk - Capítulo 1](http://sdmeta.gforge.inria.fr/FreeBooks/InsideST/InsideSmalltalk.pdf) o [Smalltalk by Example - Capítulo 9](http://sdmeta.gforge.inria.fr/FreeBooks/ByExample/11%20-%20Chapter%209%20-%20Object-Oriente.pdf)
