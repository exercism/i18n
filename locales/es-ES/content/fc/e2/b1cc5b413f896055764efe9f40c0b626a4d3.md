# Mapas y conjuntos

| Tipo | Contiene | Se consulta por |
| --- | --- | --- |
| `ARRAY{T}` | valores en orden | posición |
| `FMAP{K,T}` | pares clave-valor | clave |
| `FSET{T}` | valores, sin repeticiones | pertenencia |

## FMAP

```sather
   m ::= #FMAP{STR,INT};
   m := m.insert("emu", 2);
   m.get("emu")          -- 2
   m.has_ind("emu")      -- true
   m.size                -- 1
   m := m.delete("emu");
```

`m["emu"]` **no** es la forma de leer un mapa; `FMAP` no tiene esa rutina y esa línea no compilará. Es `get`.

### Claves que faltan

`get` sobre una clave que no está devuelve el valor vacío del tipo en lugar de quejarse: `0`, `false` o void. Un `STR` void no falla donde se produce; falla después, allí donde se use finalmente. `has_ind` primero es el hábito que merece la pena adquirir.

## FSET

```sather
   s ::= #FSET{STR};
   s := s.insert("emu");
   s.has("emu")          -- true
   s.size                -- 1
   s := s.delete("emu");
```

Los conjuntos se combinan:

```sather
   a.union(b)            -- in either
   a.intersect(b)        -- in both
   a.difference(b)       -- in a but not b
   a.is_subset(b)
```

## Asignar de vuelta y copiar

`insert` y `delete` devuelven el contenedor que hay que usar a partir de ahora. Normalmente es el mismo objeto, modificado en el sitio; cuando tiene que crecer, es uno nuevo y más grande. Así que:

```sather
   m := m.insert(k, v);     -- always
```

y el nombre de la izquierda es el único en el que confiar después. Otro nombre para el mismo mapa, tomado antes del `insert`, puede haber quedado obsoleto.

Para conservar una copia independiente, obtén primero una:

```sather
   n ::= m.copy.insert(k, v);      -- m is unchanged
```

con un inconveniente: un mapa en el que nunca se ha insertado nada es **void**, y `copy` en un mapa void falla. `insert`, `get`, `has_ind` y `size` se las arreglan con un mapa void (`#FMAP{K,T}` es void, e insertar en él es así como un mapa empieza a existir), pero `copy` no.

`HMAP` y `HSET` son las versiones que solo cambian en el sitio. Son más rápidas para construir algo grande, y son una mala opción por defecto mientras se aprende.

## Recorrer un mapa o un conjunto

| Iterador | Devuelve |
| --- | --- |
| `m.ind!` | cada clave |
| `m.target!` | cada valor |
| `m.pair!` | cada clave y valor juntos |
| `s.elt!` | cada valor de un conjunto |

Ni un mapa ni un conjunto tienen orden. Dos ejecuciones pueden recorrerlos de forma distinta, así que nunca escribas nada que dependa de cuál va primero.

```sather
   loop
      #OUT + guide.ind! + "\n";
   end;
```
