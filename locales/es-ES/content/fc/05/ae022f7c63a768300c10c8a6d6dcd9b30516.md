# Pistas

**Recuerda**: Las pruebas de este ejercicio no comprueban si mutas los datos, pero los nombres de las funciones indican que estas no deberían mutar.
Si quieres usar funciones de la introducción sin mutar la entrada, la función `copy()` te resultará útil.

## 1. Crea un inventario a partir de un vector

- Puede que te resulte útil mirar la tarea 2 antes de empezar con esta.

## 2. Añade elementos de un vector a un diccionario existente

- El enfoque más sencillo es recorrer el vector de entrada elemento a elemento.
- La función [`haskey(dict, key)`][haskey] te resultará útil.

## 3. Decrementa los elementos del inventario

- El código es muy similar al de la tarea 2, con un cambio de signo.
- Recuerda no dejar que el recuento de elementos baje de cero.
- La lógica `if...else` funciona, pero la función [`max()`][max] permite escribir código conciso e idiomático.

## 4. Elimina por completo una entrada del inventario

- Julia tiene una función que hace exactamente esto: lee la introducción.

## 5. Devuelve todo el contenido del inventario

- Recuerda eliminar los elementos cuyo recuento sea cero.
- Para quienes empiezan, puede ser lo más fácil recorrer los elementos y usar [`push!()`][push] si procede.
- Una comprensión de listas al estilo de Python es mucho más concisa, y se permite añadir una cláusula `if` al final.
- Aunque requiere conocer conceptos posteriores, quienes estén familiarizados con la programación funcional quizá quieran investigar la función [`filter()`][filter].
- Se requiere una lista ordenada, y [`sort()`][sort] ordena por defecto por la primera parte de un par.
