# Usa varias cláusulas de función

[comment]: # (La intención de este comentario es decirle a la gente que use funciones con varias cláusulas, pero como es muy difícil escribir un buen análisis para eso, en su lugar comprueba si se usan if, case y cond)

El objetivo de este ejercicio es que aprendas a usar funciones con varias cláusulas. Resuélvelo sin usar `if`, `case` ni `cond`. En su lugar, define varias cláusulas de la función `compare`.
