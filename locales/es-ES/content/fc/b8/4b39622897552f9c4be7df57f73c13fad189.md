# Introducción

## Fundamentos

### Funciones

En Gleam, las funciones se definen con la sintaxis `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Esta función toma dos argumentos, ambos de tipo `Int`, y devuelve un valor de tipo `Int`. En Gleam no existe la palabra clave `return`; el valor de la última expresión de una función siempre se _devuelve de forma implícita_.

Las anotaciones de tipo para los argumentos y el tipo de retorno son opcionales, y Gleam siempre comprobará completamente los tipos de tu código. Normalmente, los programadores de Gleam añaden anotaciones de tipo a sus funciones por claridad, pero puedes omitirlas si lo deseas.

```gleam
pub fn add(x, y) {
  x + y
}
```

Se puede llamar a una función usando la sintaxis `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

### Variables

En Gleam, las variables se definen con la sintaxis `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Las variables se pueden declarar con anotaciones de tipo. Al igual que los argumentos de función, estas son opcionales, aunque la mayoría de los programadores de Gleam omiten las anotaciones de tipo para las variables por brevedad.

```gleam
pub fn main() {
  let count: Int = 1
}
```

### Literales de string

En Gleam, los strings se escriben usando comillas dobles.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

### Comentarios de código

Los comentarios se pueden usar para dejar notas a otros desarrolladores que lean el código fuente. Los comentarios en Gleam son líneas individuales precedidas por `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
