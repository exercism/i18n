# Tests

  ## Resumen rápido

  1. Haz tus cambios en el archivo `<myFileName>.u`
  2. Guarda el archivo `<myFileName>.u`
  3. Si el archivo pasa la comprobación de tipos, ejecuta los comandos `add` o `update` de UCM
    * Si el archivo no pasa la comprobación de tipos, haz cambios en el código de tu archivo `<myFileName>.u` hasta que compile. ¡Recuerda hacer `update` de tus funciones después de los cambios!
  4. Ejecuta el comando `load <myFileName>.test.u` en la CLI de UCM para traer los tests al scope y ejecutarlos

  ## Paso a paso

  Si estás trabajando en un problema de Exercism desde la línea de comandos, lo más probable es que implementes tu solución en el directorio que lleva el nombre del ejercicio en cuestión. Por ejemplo, si el ejercicio es `hello-world`, abre `ucm` desde la línea de comandos después de hacer `cd` a `~/exercism/unison/hello-world`. Haz tus cambios de implementación en el archivo `hello.u` y, cuando estés satisfecho con tu implementación, introduce el comando `add` o `update` en la CLI del gestor de base de código de Unison (UCM) para añadir tu trabajo desde el archivo a la base de código.

  El archivo que contiene los tests de cada ejercicio lleva el sufijo `.test.u`. Querrás usar el comando `load` de UCM para traer los tests al scope y ejecutarlos. El comando `load` toma una ruta de archivo como argumento. Esto es lo que podría verse para el ejercicio hello world:

  ```
  .> load hello.test.u
  ```

  Deberías ver un mensaje de UCM sobre los términos que se trajeron al scope y, lo que es más importante, el resultado de ejecutar el test:

  ```

    ⍟ These new definitions are ok to `add`:

      hello.test : Test.Test
      tests      : [Result]

  Now evaluating any watch expressions (lines starting with
  `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    🚫 FAILED
  ```

  Supongamos que tus tests no pasaron a la primera. Vuelve a editar tu archivo `myExercise.u` y, al guardar, puedes hacer `update`

  ```
  I found and typechecked these definitions in ~/Exercism/unison/hello-world/hello.u. If you do an
  `add` or `update`, here's how your codebase would change:

    ⍟ These names already exist. You can `update` them to your new definition:

      hello : Text

  .> update

  ⍟ I've updated these names to your new definition:

    hello : Text
  ```

  Ahora podemos volver a cargar los tests para ver si algo ha cambiado.

  ```
  .> load hello.test.u
    Now evaluating any watch expressions (lines starting with `>`)... Ctrl+C cancels.


    6 | test> tests = runAll [hello.test]

    ✅ Passed : Passed 1 tests.
  ```
