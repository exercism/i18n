# No compares valores booleanos con true o false

Comparar valores booleanos con true o false es redundante.
Usar `==` genera un valor booleano, así que es innecesario compararlo con otro valor booleano escrito directamente en el código.
Si quieres invertir el valor booleano, usa el operador `!`.

```crystal
# Rather than:
some_bool == true
some_bool == false

# Consider:
some_bool
!some_bool
```
