# Introducción
## Switch

Una [instrucción switch][switch] te permite comparar un valor con varios valores posibles.
Te permite escribir código más conciso que usando varias instrucciones `else-if`.
Una instrucción switch empieza con la palabra clave `switch` seguida del valor que se va a comparar.
Después puedes definir los casos con la palabra clave `case` seguida del valor con el que se compara.
La palabra clave `default` se usa para definir el caso por defecto, cuando no coincide ninguno de los demás.
Igual que las instrucciones `else-if`, las instrucciones `switch` solo ejecutan el bloque de código asociado al primer caso que coincida.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Fíjate en el siguiente ejemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

En su lugar, podría escribirse así:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Bucles `while`

Un [bucle `while`][while-loops] es una instrucción de control de flujo que permite ejecutar código mientras se cumple una condición.
Swift ofrece dos tipos de bucles `while`: los bucles `while` y los bucles `repeat-while`.
La condición del bucle `while` se evalúa antes de que se ejecute el cuerpo del bucle; si la condición es falsa, el cuerpo del bucle no se ejecutará en absoluto.
Los bucles `while` en Swift tienen la siguiente estructura:

```swift
while <#condition#> {
  <#code#>
}
```

Aquí el bucle se ejecutará mientras count sea mayor que 0 y, por tanto, imprimirá los números 2, 1 y «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [bucle `repeat-while`][while-loops] es similar a un bucle `while`, pero la condición se evalúa después de que se ejecute el cuerpo del bucle.
Esto significa que el cuerpo del bucle siempre se ejecutará al menos una vez, incluso si la condición es falsa.
Los bucles `repeat-while` en Swift tienen la siguiente estructura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aquí el bucle solo se ejecutará una vez, ya que la condición es falsa.
Como es un bucle `repeat-while`, el cuerpo del bucle se ejecutará una vez antes de que se evalúe la condición.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```

## Transferencia de control

Swift tiene un conjunto de instrucciones que pueden usarse para alterar el flujo de control normal de los bucles.
Se conocen como instrucciones de transferencia de control.
Ya has visto `return`; en este concepto conocerás otras, entre las que se incluyen `continue`, `break` y las etiquetas.
No trataremos `fallthrough` en este concepto, pero puedes leer sobre él en el [libro de Swift][fallthrough].

### Continue

A veces es necesario saltar antes de tiempo a la siguiente iteración de un bucle, sin completar el resto de las instrucciones de la iteración actual del bucle.
Para ello se puede usar la palabra clave `continue`.
Cuando se ejecuta `continue`, el bucle salta a la siguiente comprobación para ver si se puede ejecutar la siguiente iteración del bucle, es decir, el `while` en los bucles while y repeat-while, o la comprobación de si queda otro elemento en la secuencia en los bucles `for-in`.

```swift
count = 1
while count < 6 {
  count += 1
  if count == 4 { continue }
  print(count)
}

// prints:
// 2
// 3
// 5
```

### Break

Break se usa para salir antes de tiempo de un bucle.
Cuando se ejecuta `break`, el bucle sale de inmediato y el programa continúa con la primera instrucción después del bucle.

```swift
for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  if !fruit.count.isMultiple(of: 2) { break }
  print(fruit)
}

// prints:
// banana
// grapes
```

### Etiquetas

Cuando los bucles están anidados, hay ocasiones en las que se puede querer usar `break` o `continue` para salir o reiniciar los bucles externos que contienen el bucle en el que se usan `break` o `continue`.
En casos como estos, se pueden usar etiquetas para especificar el bucle del que se quiere salir o que se quiere reiniciar.
Un bucle se puede etiquetar escribiendo un nombre seguido de dos puntos antes del `while`, el `repeat` o el `for` que inicia el bucle.

Para ver el efecto de usar etiquetas de esta forma, fíjate en el siguiente bucle.

```swift
outerLoop: for fruit in ["banana", "grapes", "apple", "strawberry", "kiwi", "lemon"] {
  print("\n--- \(fruit) ---")
  for letter in fruit {
    guard letter != "n" else { break outerLoop }
    print(letter)
  }
}

// prints:
// --- banana ---
// b
// a
```
