# Introducción

Factor tiene dos valores Boolean: `t` (verdadero) y `f` (falso). Cuando se necesita una respuesta de «sí/no», las palabras apilan uno de estos en la pila.

Los operadores Boolean se encuentran en [`kernel`][kernel]:

```
and ( a b -- ? )
or  ( a b -- ? )
not ( a -- ? )
```

```factor
t f and .   ! => f
t f or .    ! => t
f not .     ! => t
```

`f` también es el único valor *falso* de Factor. Todos los demás valores (strings vacíos, cero, arrays vacíos) se consideran verdaderos.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
