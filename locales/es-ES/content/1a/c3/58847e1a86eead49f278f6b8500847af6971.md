# Pistas

## General

- `MACRO:` está en [`macros`][macros]. Los bloques de construcción están en
  `kernel` (`dup`, `curry`), `sequences` (`append`, `concat`,
  `<repetition>`, `map`) y `quotations` (`>quotation`).
- El cuerpo de una macro debe dejar **una quotation** en la pila. Si tu
  cuerpo produce un array de código, termina con `>quotation`.
- Para comprobar tu razonamiento, ejecuta las palabras del cuerpo sobre un
  literal en el listener y mira la quotation que obtienes: debería ser
  el código lineal de la línea «compiles to» de la tarea.

## 1. Dos veces

- Recibes `[ A ]` y quieres `[ A A ]`. Haz una copia y únelas:
  `dup append`.

## 2. N repeticiones

- Recibes `[ A ] n` y quieres `n` copias unidas entre sí.
- `<repetition>` construye las copias, pero su efecto es
  `( length elt -- repetition )`: el contador debe estar arriba, así que
  usa `swap` primero.
- Después, aplana y convierte: `swap <repetition> concat >quotation`.

  ```factor
  ! stack: [ 1 + ] 3
  swap <repetition>     ! 3 copies of [ 1 + ]
  concat >quotation     ! => [ 1 + 1 + 1 + ]
  ```

## 3. Componer muchas

- Ya recibes el array de quotations; solo tienes que aplanarlo en una.
  `concat >quotation` es el cuerpo entero.

## 4. Iteración desenrollada

Recibes una secuencia y una quotation, por ejemplo `{ 10 20 30 } [ + ]`,
y quieres `[ 10 + 20 + 30 + ]`. Constrúyelo en tres pasos.

**Un elemento.** Incrustar un elemento en la quotation es exactamente
lo que hace `curry`:

```factor
10 [ + ] curry .   ! => [ 10 + ]
```

**Todos los elementos.** Quieres aplicar `map` con eso sobre la secuencia,
pero `map` solo le pasa una entrada a la quotation de mapeo (el elemento),
mientras que tú también necesitas tener `[ + ]` a mano cada vez. Así que
incrusta primero `[ + ]` en la quotation de mapeo, de nuevo con `curry`:

```factor
! stack: { 10 20 30 } [ + ]
[ curry ] curry    ! => { 10 20 30 } [ [ + ] curry ]
map                ! runs  10 [ + ] curry,  20 [ + ] curry, …
                   ! => { [ 10 + ] [ 20 + ] [ 30 + ] }
```

`[ curry ] curry` se lee como «coloca la pequeña quotation `[ curry ]`
y luego haz curry de `[ + ]` dentro de ella», lo que da
`[ [ + ] curry ]`. Aplicar `map` con eso sobre un elemento `e` ejecuta
`e [ + ] curry`, que es `[ e + ]`.

**Únelas.** El mismo final que en las demás tareas:

```factor
concat >quotation  ! => [ 10 + 20 + 30 + ]
```

- El cuerpo completo: `[ curry ] curry map concat >quotation`.
