# Instrucciones

En este ejercicio vas a escribir código para llevar un registro de los lenguajes de programación que quieres aprender en Exercism.
Tienes seis tareas, y todas ellas consisten en trabajar con arrays.

## 1. Crea un array nuevo

Para llevar un registro de los lenguajes que quieres aprender, necesitarás crear un array nuevo.
Define la constante `newList`, que contiene un array nuevo y vacío.

```elm
newList
    --> []
```

## 2. Define un array existente

Actualmente tienes un papel en el que has anotado los lenguajes que quieres aprender: Elm, Clojure y Haskell.
Define la constante `existingList` para representar ese array.

```elm
existingList
    --> [ "Elm", "Clojure", "Haskell" ]
```

## 3. Añade un lenguaje nuevo a un array

A medida que exploras Exercism y encuentras lenguajes más interesantes, quieres añadirlos a tu array.
Implementa la función `addLanguage` para añadir un lenguaje nuevo al principio de tu array.

```elm
addLanguage "TypeScript" [ "JavaScript", "CoffeeScript" ]
    --> [ "TypeScript", "JavaScript", "CoffeeScript" ]
```

## 4. Cuenta los lenguajes del array

Contar los lenguajes a mano resulta incómodo.
Implementa la función `countLanguages` para contar el número de lenguajes que hay en tu array.

```elm
countLanguages [ "C#", "Racket", "Rust", "Ruby" ]
    --> 4
```

## 5. Invierte el array

¡En algún momento te das cuenta de que tu array está ordenado al revés!
Implementa la función `reverseList` para invertir tu array.

```elm
reverseList [ "Prolog", "C", "Idris", "Assembly" ]
    --> [ "Assembly", "Idris", "C", "Prolog" ]
```

## 6. Comprueba si el array te hace ilusión

Aunque te encantan todos los lenguajes, Elm ocupa un lugar especial en tu corazón.
Por eso, un array de lenguajes te hace mucha ilusión si:

- El primer elemento del array es Elm.
- O el segundo elemento del array es Elm y el array contiene tres lenguajes o menos.

Implementa la función `excitingList` para comprobar si un array de lenguajes te hace ilusión:

```elm
excitingList [ "Nim", "Elm" ]
    --> True
```
