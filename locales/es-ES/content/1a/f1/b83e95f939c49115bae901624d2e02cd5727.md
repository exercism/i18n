# Consejos

## General

- Un número de coma flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de coma flotante se pasan en `xmm0` a `xmm7`.

## 1. Calcular la tarifa diaria a partir de una tarifa por hora

- Un número de coma flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de coma flotante se pasan en `xmm0` a `xmm7`.
- Un número entero de 64 bits se puede convertir a un número de coma flotante de doble precisión usando `cvtsi2sd`.
- Un inmediato (un número constante) debe almacenarse en un registro de propósito general antes de convertirlo a un número de coma flotante.
- Dos números de coma flotante de doble precisión se pueden multiplicar con `mulsd`.

## 2. Calcular un precio con descuento

- Un número de coma flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de coma flotante se pasan en `xmm0` a `xmm7`.
- Dos números de coma flotante de doble precisión se pueden dividir con `divsd`.
- A un número de coma flotante de doble precisión se le puede restar otro con `subsd`.

## 3. Calcular la tarifa mensual a partir de una tarifa por hora y un descuento

- Un número de coma flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de coma flotante se pasan en `xmm0` a `xmm7`.
- Puedes usar `roundsd` para redondear un número de coma flotante de doble precisión, usando un tercer operando para indicar el modo de redondeo.
- El número para redondear hacia arriba (techo) es `2`.
- Puedes usar `cvtsd2si` para convertir un número de coma flotante de doble precisión a un número entero de 64 bits.

## 4. Calcular el número de días laborables a partir de un presupuesto, una tarifa por hora y un descuento

- Un número de coma flotante se devuelve en `xmm0`.
- Los primeros 8 argumentos de coma flotante se pasan en `xmm0` a `xmm7`.
- Puedes usar `roundsd` para redondear un número de coma flotante de doble precisión, usando un tercer operando para indicar el modo de redondeo.
- El número para redondear hacia abajo (suelo) es `1`.
- Puedes usar `cvtsd2si` para convertir un número de coma flotante de doble precisión a un número entero de 32 bits.
