# Introducción

## Antecedentes

Una cadena de caracteres es un fragmento de texto entre comillas.
Cualquier versión de R con soporte actual codifica los strings en UTF-8, por lo que se puede dar soporte a la mayoría de los idiomas del mundo.

```R
mystring <- "some text"
mystring
#> [1] "some text"
typeof(mystring)
#> [1] "character"
```

Lamentablemente, la terminología puede resultar confusa para quienes están familiarizados con otros lenguajes.

Aunque el `type` es `character`, R no distingue entre una sola letra (llamada `char` en varios otros lenguajes, pero _no_ en R) y un string largo.
Ambos son un único elemento y pueden ir indistintamente entre comillas simples `' '` o dobles `" "`.

La guía de estilo recomienda usar comillas dobles, excepto cuando quieras usar comillas dobles dentro del string sin tener que escaparlas.

```R
str2 <- 'String with "quotes"'  # convenience format
str2
#> [1] "String with \"quotes\""    # standard format
```

Un `character vector` es, por tanto, un vector de strings, donde cada string es un único elemento.

```R
s <- c("some", "strings")
s
#> [1] "some"    "strings"
length(s)
#> [1] 2
length(s[1])  # the number of vector elements, not the string length
#> [1] 1

nchar(s[1])  # the number of characters in the string "some"
#> [1] 4
```

En el ejemplo anterior, `length(s[1])` equivale a `length("some")`: el número de _elementos del vector_, no la _longitud del string_.

Manipular un string individual es obviamente posible, como con `nchar()` en el ejemplo anterior, pero requiere funciones concretas que veremos más adelante.

### Funciones para strings

Casi todo es _posible_ en R base, pero a muchos programadores les parece que el soporte para la manipulación de strings es más bien limitado y confuso.

Por suerte, existen paquetes de `tidyverse` que son mucho más intuitivos, flexibles y coherentes entre sí.

### R base

Sigue habiendo mucho código heredado que usa funciones de strings al estilo antiguo.
Esto incluye la mayoría de las soluciones de la comunidad en Exercism.

Además, para tareas pequeñas puede ser útil usar funciones integradas en lugar de importar una biblioteca grande.
Quienes mantienen el track de R suelen adoptar este enfoque al escribir soluciones de ejemplo para validar los ejercicios.

Por lo tanto, sigue mereciendo la pena conocer un poco los enfoques antiguos.

#### `nchar`

Devuelve el número de caracteres de un string.

```R
nchar("string")
#> [1] 6

nchar("Hrōðgār") # a person in Beowulf, written in Old English
#> [1] 7
```

El tema (_¡complicado!_) de qué significa «carácter» queda fuera de nuestro alcance.
Baste con fijarse en un par de detalles de los ejemplos anteriores:

- Aunque internamente estén implementados en C, los strings en R no terminan en `\0` (lo que sumaría 1 a la longitud).
- Los caracteres Unicode de varios bytes se tratan como cabría esperar o desear. «Hrōðgār» tiene 7 caracteres (también llamados «runes» o «puntos de código»), pero necesita 10 bytes para almacenarse.

#### `paste` y `paste0`

Combina un número arbitrario de strings en un único string.

Opcionalmente, se puede especificar un separador para `paste`: el valor predeterminado es un espacio.

`paste0(v)` equivale a `paste(v, sep = "")`.

```R
paste("bits", "of", "a", "string")
#> [1] "bits of a string"
paste0("bits", "of", "a", "string")
#> [1] "bitsofastring"
```

#### `sprintf`

Para un control más preciso del ensamblado de strings, R copia la función `sprintf` de C (y de varios lenguajes posteriores: Wikipedia [enumera][wiki-printf-ports] unos 30).

```R
r <- 5.3
pi <- 3.14159
sprintf("A circle of radius %.1f has area %.2f", r, pi * r^2)
#> [1] "A circle of radius 5.3 has area 88.25"
```

#### `trimws`

Los espacios en blanco al principio y/o al final se pueden eliminar con `trimws()`:

```R
s <- "    messy string   "
trimws(s)
#> [1] "messy string"
```

Existe un parámetro `which = "left"` (o `"right"`) para evitar recortar ambos extremos.

#### `substr`

Opera sobre un único string y devuelve la subcadena entre dos límites (ambos incluidos).

```R
substr("Exercism", 5, 7)
#> [1] "cis"
```

#### `strsplit`

Divide un string en una lista de R, a partir de un string separador.
El separador es obligatorio (no tiene valor predeterminado), pero puede ser un string vacío.

```R
strsplit("R, Python, Julia", ", ")
[[1]]
#> [1] "R"      "Python" "Julia" 

strsplit("Exercism", "")
[[1]]
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

Las listas se tratan en un [concepto][concept-lists] aparte.
Si aún no has llegado a esa parte del temario, por ahora basta con saber que la función `unlist()` convertirá (en este caso) una lista en un vector.

```R
unlist(strsplit("Exercism", ""))
#> [1] "E" "x" "e" "r" "c" "i" "s" "m"
```

### Tidyverse

Siendo benévolos, podríamos decir que las funciones de strings al estilo antiguo no son lo mejor que R tiene que ofrecer (_también hay opiniones menos benévolas_).

Para mejorar la situación, la biblioteca `stringr` está en desarrollo desde 2009 y hoy es una parte clave de la colección Tidyverse.

Impórtala a tu espacio de nombres con `library(stringr)` o `library(tidyverse)`.

Algunas de sus funcionalidades clave son:

- Todos los nombres de funciones llevan el prefijo `str_` e intentan dejar claro su propósito.
- El orden de los argumentos intenta ser coherente consigo mismo, con los datos de entrada como primer argumento.
- Las entradas pueden ir desde un único string hasta estructuras de datos complejas. Las funciones tratarán de adaptarse y hacer lo más sensato.

Como todos los paquetes de Tidyverse, `stringr` tiene una buena documentación, normalmente escrita por el autor o los autores del paquete.

- Un [sitio web de referencia][ref-stringr]
- Una [chuleta][cheat-stringr]
- Un [capítulo][book-strings] de «R for Data Science».

#### Inciso: una introducción rápida a los pipes

El uso de pipes `|>` para conectar funciones se tratará con más detalle en otras partes del temario.

Por ahora, es útil saber que:

- El resultado que está a la izquierda del pipe se convierte en el primer argumento de la función que está a la derecha (donde «derecha» ignora los saltos de línea opcionales).
- Los argumentos restantes se pueden incluir en la llamada a la función.
- En R, debemos aplicar el pipe a una _llamada_ a función, no solo a un _nombre_, por lo que los paréntesis siempre son necesarios (_esto difiere de algunos otros lenguajes_).

El ejemplo siguiente ilustra la sintaxis.
Las funciones individuales se tratarán más adelante.

```R
library(stringr)

"Monday-25-February" |> 
  str_split("-") |>     
  unlist() |>               # [1] "Monday"   "25"       "February"
  str_sub(1, 3) |>          # [1] "Mon" "25"  "Feb"
  str_to_upper() |>         # [1] "MON" "25"  "FEB"
  str_flatten(collapse = ", ")
#> [1] "MON, 25, FEB"
```

#### Gestionar longitudes

`str_length` cuenta puntos de código (similar a `nchars`).

Otras funciones manipulan los espacios en blanco, como `str_trim()` y `str_squish()`.
A menudo es una tarea de limpieza esencial al comienzo de cualquier proyecto de ciencia de datos.

```R
# The first 3 kernels in JuPyteR notebooks:
str_length(c("Julia", "Python", "R"))           #> [1] 1 6 5
#> [1] 5 6 1
str_pad(c("Julia", "Python", "R"), 8, "right")  # add spaces if necessary
#> [1] "Julia   " "Python  " "R       "

str_trim("Julia    Python    R    ")   # remove leading & trailing whitespace
#> [1] "Julia    Python    R"
str_squish("Julia   Python  R    ")  # trim, collapse multiple spaces 
#> [1] "Julia Python R"
```

#### Subconjuntos de strings

La función `str_sub(string, start, end)` devuelve la subcadena desde `start` hasta `end` (ambos incluidos), mientras que `str_sub_all()` puede operar sobre varios strings.

Hay mucha flexibilidad.
`start` y `end` toman por defecto el primer y el último carácter, respectivamente.
Pueden ser vectores de índices.
Al contrario que en la indexación de vectores, y esto se agradece, los valores negativos cuentan desde el final del string, al estilo de Python.

```R
s <- "abcdefgh"
str_sub(s, 2, 4)
#> [1] "bcd"
str_sub(s, 5)
#> [1] "efgh"
str_sub(s, -3, -2)
#> [1] "fg"
str_sub(s, c(1, 4), c(2, 5))
#> [1] "ab" "de"
str_sub(s, c(1, 4, 6), c(2, 5, -1))
#> [1] "ab"  "de"  "fgh"

s |> str_sub(2, 4) # these functions are designed for pipes
#> [1] "bcd"
```

#### Unir strings

`str_flatten` convierte un vector de caracteres en un único string.
El argumento `collapse` se inserta entre cada elemento y toma por defecto el valor `""`.

```R
c("R", "Julia", "Python") |> str_flatten()
#> [1] "RJuliaPython"
c("R", "Julia", "Python") |> str_flatten(collapse = " - ")
#> [1] "R - Julia - Python"
```

`str_c` convierte varios vectores de caracteres en un único vector de caracteres, reciclando cuando es necesario.

```R
str_c(LETTERS[1:8], 1:8, sep = ":")
#> [1] "A:1" "B:2" "C:3" "D:4" "E:5" "F:6" "G:7" "H:8"
```

`str_glue` aporta a R una interpolación de strings sencilla.
Las expresiones que hay dentro de las llaves `{ }` se interpretan y se sustituyen por su representación textual.

```R
r <- 5.3
pi <- 3.14159
str_glue("A circle of radius {r} has area {pi * r^2}")
A circle of radius 5.3 has area 88.2472631
```

#### Dividir strings

Un uso muy habitual de R es transformar datos desordenados en un formato coherente para su análisis.
Para ello, hay varias formas de dividir texto en subcadenas.
La mayoría quedan fuera del alcance de esta introducción.

`str_split_1` es la más sencilla: convierte un único string en un vector de fragmentos, dividiéndolo según un patrón especificado (no hay patrón predeterminado).

```R
s <- "R Julia Python"
str_split_1(s, " ")
#> [1] "R"      "Julia"  "Python"
```

#### Modificar strings

Algunos lenguajes (principalmente europeos) distinguen entre letras mayúsculas y minúsculas.
Hay un conjunto de funciones de `stringr` para convertir unas en otras, de forma adecuada a cada configuración regional:

- `str_to_lower()`
- `str_to_upper()`
- `str_to_title()` : pone en mayúscula la primera letra de cada palabra
- `str_to_sentence()` : pone en mayúscula la primera letra de la frase

```R
str_to_upper("elixir")    # defaults to locale = "en"
#> [1] "ELIXIR"
str_to_upper("ελληνικά")  # infers Greek
#> [1] "ΕΛΛΗΝΙΚΆ"

str_to_title("the cat sat on the mat")
#> [1] "The Cat Sat On The Mat"
str_to_sentence("the cat sat on the mat")
#> [1] "The cat sat on the mat"
```

Para sustituir subcadenas basándose en la coincidencia de patrones, `str_replace()` cambia la primera aparición del patrón y `str_replace_all()` cambia todas las apariciones.

Para sustituir subcadenas basándose en la indexación de caracteres, existe una forma de asignación de str_sub().

```R
 s <- "abcde"
str_sub(s, 3, 4) <- "yz"
s
#> [1] "abyze"
```
