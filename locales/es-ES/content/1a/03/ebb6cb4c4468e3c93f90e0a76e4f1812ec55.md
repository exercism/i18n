# Instrucciones

En este ejercicio vas a implementar un programa que determina el estado de una partida de [tic-tac-toe][].
(_También es posible que conozcas este juego como «tres en raya» o «equis y ceros»._)

El juego se juega en una cuadrícula de 3×3.
Los jugadores se turnan para colocar las `X` y las `O` en la cuadrícula.
El juego termina cuando un jugador gana al colocar tres de sus marcas en una fila, una columna o una diagonal de la cuadrícula, o cuando esta se llena por completo.

En este ejercicio, supondremos que empieza `X`.

Tu tarea es determinar en qué estado se encuentra una partida dada.

Hay 3 estados posibles de partida:

- La partida está **ongoing**.
- La partida terminó en **draw**.
- La partida terminó en **win**.

Si el tablero dado no es válido, lanza un error adecuado.

Un tablero no es válido si cumple las siguientes condiciones:

- No se puede llegar al tablero dado si los turnos se juegan en el orden correcto (recuerda que empieza `X`).
- Se jugó después de que la partida ya hubiera terminado.

## Ejemplos

### Partida en curso

```text
   |   |
 X |   |
___|___|___
   |   |
   | X | O
___|___|___
   |   |
 O | X |
   |   |
```

### Empate

```text
   |   |
 X | O | X
___|___|___
   |   |
 X | X | O
___|___|___
   |   |
 O | X | O
   |   |
```

### Victoria

```text
   |   |
 X | X | X
___|___|___
   |   |
   | O | O
___|___|___
   |   |
   |   |
   |   |
```

### No válido

#### Orden de turnos incorrecto

```text
   |   |
 O | O | X
___|___|___
   |   |
   |   |
___|___|___
   |   |
   |   |
   |   |
```

#### Continuar jugando después de ganar

```text
   |   |
 X | X | X
___|___|___
   |   |
 O | O | O
___|___|___
   |   |
   |   |
   |   |
```
