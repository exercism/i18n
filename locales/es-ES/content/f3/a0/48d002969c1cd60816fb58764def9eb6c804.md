# Instrucciones

Karl quiere llevar un registro de un array de lenguajes que aprender en el sitio web de Exercism.
Karl necesita poder añadir lenguajes nuevos, eliminar los antiguos y comprobar si ciertos lenguajes están en el array.
¡Sería muy emocionante que Karl quisiera aprender Java o Kotlin!

## 1. Define una función para comprobar si el array de lenguajes está vacío

Karl necesita saber si su array de lenguajes llega a quedarse vacío, para poder ir a buscar más que aprender.
Define un método llamado `isEmpty` que devuelva `true` si no hay ningún lenguaje en el array.

```java
if (languageList.isEmpty()) {
    findMoreLanguagesToLearn();
}
```

## 2. Define una función para añadir un lenguaje al array

¡Karl está deseando aprender Kotlin y Python!
Ayuda a Karl a empezar definiendo un método llamado `addLanguage` que reciba el lenguaje que quiere aprender y lo añada al array.

```java
languageList.addLanguage("Kotlin");
languageList.addLanguage("Python");
```

## 3. Define una función para eliminar un lenguaje del array

Karl ha decidido que no quiere aprender Scala ahora mismo.
Ayuda a Karl a eliminarlo del array definiendo un método llamado `removeLanguage` que reciba el lenguaje que se quiere eliminar y lo elimine del array.

```java
languageList.removeLanguage("Scala");
```

## 4. Define una función para devolver el primer elemento del array

Karl quiere recordar el primer lenguaje que añadió al array (que siga estando en el array).
Define un método llamado `firstLanguage` que devuelva el primer lenguaje del array.

```java
String kotlin = languageList.firstLanguage(); // "Kotlin"
```

## 5. Define una función para devolver cuántos lenguajes hay en el array

Karl necesita saber cuántos lenguajes está intentando aprender.
Ayuda a Karl a encontrar la respuesta definiendo un método llamado `count` que devuelva el número de lenguajes que hay en el array.

```java
int two = languageList.count(); // 2
```

## 6. Define una función para determinar si un lenguaje está en el array

Karl intenta recordar si quería aprender Python o Ruby.
Define un método llamado `containsLanguage` que reciba el lenguaje por el que pregunta, ¡para que Karl pueda averiguarlo!

```java
boolean learningPython = languageList.containsLanguage("Python"); // true
boolean learningRuby = languageList.containsLanguage("Ruby"); // false
```

## 7. Define una función para determinar si el array es emocionante

¡Si Karl quiere aprender Java o Kotlin, eso es muy emocionante!
Define un método llamado `isExciting` que devuelva true si Karl quiere aprender Java o Kotlin.

```java
javaLanguageList.isExciting() // true
neitherKotlinNorJavaLanguageList.isExciting() // false
```
