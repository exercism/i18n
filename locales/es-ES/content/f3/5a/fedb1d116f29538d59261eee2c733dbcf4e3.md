# Acerca de

Rust implementa el tipo [char][char type] para representar un único carácter. Un literal `char` se escribe entre comillas simples, como `'a'`.
Cada `char` ocupa cuatro bytes y representa un único [valor escalar Unicode][unicode scalar].

Sin embargo, un [`char`][character type] no siempre es lo que consideramos una letra. Hay algunos lenguajes, por ejemplo el hindi, que usan [diacríticos][diacritics],
que son símbolos especiales que modifican el carácter al que van unidos. Aunque el diacrítico en Rust es un `char` aparte, lo que normalmente
consideramos una letra es el diacrítico junto con el carácter que modifica.

El término para un carácter y su diacrítico es [grupo de grafemas][grapheme cluster]. Existen crates externos que se pueden usar para procesar grupos de grafemas,
como [unicode-segmentation][unicode-segmentation].

Ejemplo

```rust
pub fn main() {
    let text = "ü"; // a "u" with a diacritic
    let text_vec: Vec<char> = text.chars().collect(); // this gets the chars in "ü"
    println!("{:?}", text_vec.len()); // this prints the number of chars in "ü"
    println!("{:?}", text_vec[0]); // this prints the first char in "ü"
    println!("{:?}", text_vec[1]); // this prints the second char in "ü"
}
```

imprime

```rust
2
'u'
'\u{308}'
```

'\u{308}' es otra forma de escribir un literal `char`. `\u` indica que es un `char` Unicode, donde `{308}` es el número Unicode único de ese carácter
o diacrítico.
