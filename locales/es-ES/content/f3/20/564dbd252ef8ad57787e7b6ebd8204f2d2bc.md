# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: «[<LEVEL>]: <MESSAGE>*».

## 1. Obtén el mensaje de una línea de registro

Implementa la función `LogLevels.message()` para que devuelva el mensaje de una línea de registro, sin los espacios en blanco del principio ni del final.

## 2. Obtén el nivel de registro de una línea de registro

Implementa la función `LogLevels.logLevel()` para que devuelva el nivel de registro de una línea de registro en minúsculas.

## 3. Reformatea una línea de registro

Implementa el método `LogLevels.reformat()`, que recibe una línea de registro y un string de ubicación, y los reformatea en un mensaje que contiene dos líneas.
La primera línea tiene el formato `<LEVEL>@<LOCATIOON>:`, donde:

* `<LEVEL>` es el nivel de registro en minúsculas (como en el punto 2, «Obtén el nivel de registro de una línea de registro»).
* `<LOCATION>` es la ubicación que se pasa como segundo parámetro.

La segunda línea contiene exactamente dos espacios, seguidos del mensaje (como en el punto 1, «Obtén el mensaje de una línea de registro»):

```kotlin
reformat("[TRACE]: Start of function", 2, 8)
// => "trace@208:
  Start of function"
```
