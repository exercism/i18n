# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante.
Como no quería que a otros les resultara fácil leerlo, el mensaje se cifró realizando una serie de manipulaciones de bits.
Tendrás que escribir los métodos que te ayuden a descifrar el mensaje.

## 1. Desplaza los bits de vuelta a la derecha

El primer paso para descifrar el mensaje es deshacer el desplazamiento del proceso de cifrado desplazando los bits de vuelta a la derecha.
Habrá más pasos en el proceso de descifrado que asumen que se insertan ceros desde el lado izquierdo.

Implementa el método `Secrets.shiftBack` que toma un valor y el número de posiciones que hay que desplazar y realiza el desplazamiento.

```java
Secrets.shiftBack(0b1001, 2);
# => 0b0010
```

## 2. Establece algunos bits a 1

A continuación, hay algunos bits que deben establecerse a 1.

Implementa el método `Secrets.setBits` que toma un valor y una máscara y devuelve el resultado de establecer los bits del valor a 1.
Un bit del valor debe establecerse a 1 cuando el bit de la máscara también sea 1.
Todos los demás bits deben mantenerse sin cambios.

```java
Secrets.setBits(0b0110, 0b0101);
# => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado.
Habrá que invertirlos de nuevo para descifrar el mensaje.

Implementa el método `Secrets.flipBits` que toma un valor y la máscara.
La máscara indica qué bits del valor hay que invertir.
Si el bit es 1 en la máscara, ese bit se invierte en el valor.
Todos los demás bits se mantienen sin cambios.

```java
Secrets.flipBits(0b1100, 0b0101);
# => 0b1001
```

## 4. Borra bits específicos

Por último, también hay ciertos bits que siempre se convierten en 0 al descifrar.

Implementa el método `Secrets.clearBits` que toma un valor y una máscara.
Los bits de `value` deben establecerse a 0 donde el bit de la máscara sea 1.
Todos los demás bits deben mantenerse sin cambios.

```java
Secrets.clearBits(0b0110, 0b0101);
# => 0b0010
```
