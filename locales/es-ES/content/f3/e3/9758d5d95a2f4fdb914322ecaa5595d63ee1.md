# Palabras clave static de clase

Una clase es una unidad de organización del código en PHP, que suele representar una instancia de una cosa/servicio/procedimiento.
Usando las palabras clave `static` y `self`, las propiedades y los métodos pueden existir en referencia a la clase para todas las instancias (o para ninguna instancia).

```php
<?php

class Book
{
    static $genre = 'Adventure';

    static function getGenre()
    {
        return self::$genre;
    }
}

// Usage
$genre = Book::$genre;
$genre = Book::getGenre();
```

## Limitación

Los métodos static de clase solo pueden llamar a otras propiedades static de clase o a métodos de clase de su propia clase.
