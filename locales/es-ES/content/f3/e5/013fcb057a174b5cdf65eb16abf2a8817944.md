# Pistas

## 1. Crea un array vacío

Crear un array vacío es igual que crear un array con elementos. Se puede hacer usando `list` o usando `quote` sobre un array vacío.

## 2. Añade un nuevo lenguaje al array

Clojure tiene una función del núcleo que puede [anteponer un elemento a un array](https://clojuredocs.org/clojure.core/cons).

## 3. Comprueba el último lenguaje añadido

Como otros Lisps, Clojure tiene una función que [devuelve el primer elemento de un array](https://clojuredocs.org/clojure.core/first).

## 4. Elimina el primer lenguaje del array

Del mismo modo, Clojure también tiene una función para [devolver un array con el primer elemento eliminado](https://clojuredocs.org/clojure.core/rest).

## 5. Cuenta los lenguajes del array

El [número de elementos](https://clojuredocs.org/clojure.core/count) de un array se puede devolver fácilmente con una función del núcleo de Clojure.

## 6. Únelo todo

Recuerda que las llamadas a funciones se pueden anidar.
