# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con su jefe de proyecto, proporcionando algunas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos algunas reglas entre el freelancer y el jefe de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más fieles o para clientes sin ánimo de lucro).

Los descuentos se modelan como números fraccionarios que representan un porcentaje, por ejemplo `25.0` (25 %).

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función que calcule la tarifa diaria a partir de una tarifa por hora:

```haskell
dailyRate 60
-- -> 480.0
```

La tarifa diaria devuelta debe ser de tipo double.

## 2. Calcula un precio con descuento

Implementa una función que calcule el precio después de aplicar un descuento.

```haskell
applyDiscount 150 10
-- -> 135.0
```

El valor devuelto debe ser siempre un double, sin redondear de ninguna manera.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función que calcule la tarifa mensual y aplique un descuento:

```haskell
monthlyRate 77 10.5
-- -> 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (toma el valor techo) al número entero más cercano.

## 4. Calcula el número de días laborables a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función que reciba un presupuesto, una tarifa por hora y un descuento, y calcule cuántos días de trabajo cubre eso.

```haskell
daysInBudget 20000 80 11.0
-- -> 35.1
```

El número de días devuelto debe redondearse hacia abajo (toma el valor suelo) a un decimal.
