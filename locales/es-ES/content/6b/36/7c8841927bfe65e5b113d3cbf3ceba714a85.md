# Anexo a las instrucciones

## Pistas

Tienes que implementar las funciones `decode` y `encode`, que decodifican y codifican un `String` usando un cifrado afín.
Puedes usar la signatura proporcionada si no tienes claros los tipos, pero no dejes que limite tu creatividad.

Este ejercicio trabaja con datos textuales.
Por razones históricas, el tipo `String` de Haskell es sinónimo de `[Char]`, una lista de caracteres.
Para manejar datos textuales de forma más eficiente, se puede usar el tipo `Text`.

Como ampliación opcional de este ejercicio, puedes

- añadir `- text` a tu lista de dependencias en package.yaml.
- importar `Data.Text` [de la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

```haskell
import qualified Data.Text as T
import           Data.Text (Text)
```

- usar el tipo `Text`, p. ej. `decode :: Text -> Text`, y referirte a los combinadores de `Data.Text` como, p. ej., `T.pack`.
- consultar la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).
- sustituir todas las apariciones de `String` por `Text` en Affine.hs, es decir:

```haskell
encode :: (Int, Int) -> Text -> Maybe Text
encode key plainText = ...

decode :: (Int, Int) -> Text -> Maybe Text
decode key cipherText = ...
```

Esta parte es totalmente opcional.
