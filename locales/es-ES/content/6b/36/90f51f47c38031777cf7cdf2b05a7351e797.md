# Acerca de

En F#, los Boolean se representan con el tipo `bool`, cuyos valores pueden ser `true` o `false`.

F# admite tres [operadores booleanos][operators]: `not` (NOT), `&&` (AND) y `||` (OR). Los operadores `&&` y `||` usan la _evaluación de cortocircuito_, lo que significa que el lado derecho del operador solo se evalúa cuando es necesario.

```fsharp
true || false // => true
true && false // => false
```

Los tres operadores booleanos tienen cada uno una [_precedencia de operadores_][precedence] diferente. En consecuencia, se evalúan en este orden: `not` primero, `&&` después y, por último, `||`. Si quieres «escapar» de estas reglas, puedes encerrar una expresión booleana entre paréntesis (`()`), ya que los paréntesis tienen una precedencia de operadores aún mayor.

```fsharp
not true && false   // => false
not (true && false) // => true
```
