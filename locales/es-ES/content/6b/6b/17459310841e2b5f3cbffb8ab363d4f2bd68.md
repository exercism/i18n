# Instrucciones

El trabajo avanza bien en _Instruments of Texas_ con la calculadora RPN. Ahora tu equipo quiere poder escribir una versión en string de la ecuación en un recurso de E/S.

## 1. Abre un fichero

Tu equipo aún no ha decidido a qué tipo de dispositivo escribir la ecuación, así que propones usar un enfoque de _despacho dinámico_ para poder inyectar el recurso en la función en lugar de fijarlo directamente en el código. Implementa la función `write/3` para abrir un _dispositivo de E/S_ usando el recurso y el nombre de fichero.

Puedes suponer que `resource` siempre será un átomo que representa un módulo que tiene una función `open/1` que devuelve `{:ok, io_device}`.

Cuando la función tenga éxito, devuelve una tupla `:ok` con la ecuación.

```elixir
RPNCalculator.Output.write(resource, "file_to_be_written", "1 4 +")
# {:ok, "1 4 +"}
```

## 2. Intenta escribir en el dispositivo de E/S

Ahora que has abierto el dispositivo de E/S, intenta escribir en él usando `IO.write/2`.

Amplía la función `write/3` para realizar esta acción. El intento de escritura puede lanzar un error; rescata el error devolviendo una tupla de error:

```elixir
RPNCalculator.Output.write(resource, "bad_file", "1 4 +")
# {:error, "Unable to write to resource"}
```

## 3. Cierra el dispositivo de E/S

Es una buena práctica intentar siempre liberar los recursos que has abierto, incluso si la función que usa el recurso lanza un error. Amplía la función `write/3` para llamar a la función de cierre del recurso y cerrar así el _dispositivo de E/S_.

Puedes suponer que `resource` siempre será un átomo que representa un módulo que tiene una función `close/1` que recibe un _dispositivo de E/S_.
