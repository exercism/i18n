# Acerca de

Tcl, pronunciado «tickle» y abreviatura de Tool Command Language, es un lenguaje de programación dinámico y de código abierto.

Se diseñó con el objetivo de ser muy sencillo, pero potente.
Es tan sencillo que toda la sintaxis se describe por completo en [solo 12 reglas][rules].
Y, aun así, es un lenguaje de programación completo.

Tcl convierte todo en *comandos*, incluso las asignaciones de variables, las definiciones de procedimientos y el flujo de control.
Por ello, se parece tanto a la programación de scripts de shell como a Lisp.

Tcl admite varios paradigmas de programación, como el orientado a objetos, el imperativo y el funcional.
Los casos de uso más comunes de Tcl son como entornos de ejecución de scripts integrados en aplicaciones C, y para crear prototipos de interfaces gráficas de usuario (GUI) con el kit de herramientas GUI Tk.
