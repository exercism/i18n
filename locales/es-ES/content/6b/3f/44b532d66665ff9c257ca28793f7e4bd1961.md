# Introducción

Trabajas para una empresa de bioingeniería especializada en el desarrollo de soluciones terapéuticas.

Acaban de asignar a tu equipo un nuevo proyecto para desarrollar una terapia dirigida contra un tipo poco frecuente de cáncer.

~~~~exercism/note
Es todo muy complicado, pero la idea básica es que a veces el cuerpo de las personas produce demasiada cantidad de una proteína concreta.
Eso puede causar todo tipo de estragos.

Pero si consigues crear una molécula muy concreta (llamada micro-ARN), puede impedir que se produzca la proteína.

Esta técnica se llama [interferencia de ARN][rnai].

[rnai]: https://admin.acceleratingscience.com/ask-a-scientist/what-is-rnai/
