# Anexo de instrucciones

Quienes disfruten de un reto más exigente pueden activar los tests adicionales descomentando una línea de `rational-numbers.jl`.

Estos requieren un conocimiento mucho más avanzado de Julia y de su sistema de tipos.

El fichero `runtests.jl` contiene algunos enlaces que pueden resultarte útiles.

El fichero `rational-numbers.jl` no incluye a propósito ninguna indicación adicional para los tests adicionales: piensa con cuidado en las importaciones, las definiciones de tipos y las funciones extra.
