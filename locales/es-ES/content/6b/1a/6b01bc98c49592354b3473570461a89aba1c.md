## Módulos

El código de Gleam se organiza en módulos, y cada archivo es un módulo de Gleam.

Hasta ahora hemos escrito funciones con la sintaxis `pub fn`, que define una función disponible públicamente para otros módulos. Las funciones definidas con `fn` son privadas para el módulo en el que se definen y no pueden usarlas otros módulos.

```gleam
// This function is public
pub fn add(x, y) {
  x + y
}

// This function is private
fn subtract(x, y) {
  x - y
}
```

Los módulos de Gleam tienen nombre, y este se basa en la ruta del archivo dentro del directorio `src` o `test`.

Por ejemplo, un módulo definido en `src\geometry\rectangle.gleam` (en Windows) o `src/geometry/rectangle.gleam` (en sistemas operativos tipo UNIX) se llamaría `geometry/rectangle`.

## Importar funciones de otros módulos

Se accede a las funciones definidas en otros módulos mediante importaciones.
Todas las funciones de ese módulo que este expone se hacen accesibles al importar dicho módulo.
Pero la forma de acceder a ellas varía según cómo se importe el módulo.

Las importaciones cualificadas son las que se usan por defecto, y para acceder a una función de un módulo de este tipo (por ejemplo, la función `map` del módulo `gleam/list`) se antepone el nombre del módulo (`list.map`).

```gleam
// Import the int module
import gleam/int

pub fn run(x: Int) -> String {
  // Use the to_string function from the int module
  int.to_string(x)
}
```

De forma predeterminada, el nombre que se usa para referirse al módulo es la última parte del nombre del módulo, en este caso `int`, pero esto puede cambiarse con la palabra clave `as`.

```gleam
// Import the int module and refer to it as i
import gleam/int as i

pub fn run(x: Int) -> String {
  i.to_string(x)
}
```

Las importaciones sin cualificar permiten acceder directamente a las funciones expuestas de ese módulo, sin anteponer nada.

```gleam
// Import the to_string function from the int module
import gleam/int.{to_string}

pub fn run(x: Int) -> String {
  to_string(x)
}
```

Se prefieren las importaciones cualificadas porque dejan más claro al lector de dónde viene una función y ayudan a evitar conflictos de nombres.
