# Instrucciones

En este ejercicio implementarás un conjunto parcial de rutinas de utilidad para ayudar a un desarrollador a limpiar nombres SqueakyClean.

En las 4 tareas irás construyendo gradualmente el método `clean`.
Un nombre SqueakyClean válido consta de cero o más letras y guiones bajos.

En todos los casos se garantiza que el string de entrada no es null. Ten en cuenta que el método `clean` debe tratar un string vacío como válido.

## 1. Sustituye los espacios que encuentres por guiones bajos

Implementa el método (_static_) `SqueakyClean.clean()` para sustituir cualquier espacio por guiones bajos. Esto también se aplica a los espacios al principio y al final.

```java
SqueakyClean.clean("my   Id");
// => "my___Id"
```

## 2. Convierte kebab-case en camelCase

Modifica el método (_static_) `SqueakyClean.clean()` para convertir kebab-case en camelCase.

```java
SqueakyClean.clean("a-bc");
// => "aBc"
```

## 3. Convierte leetspeak a texto normal

Modifica el método (_static_) `SqueakyClean.clean()` para convertir [leetspeak][leet-speak] a texto normal.

Por simplicidad, solo sustituiremos `4`, `3`, `0`, `1` y `7` por `a`, `e`, `o`, `l` y `t`, respectivamente.

```java
SqueakyClean.clean("H3ll0 W0rld");
// => "Hello_World"
SqueakyClean.clean("4 73s7");
// => "a_test"
```

## 4. Omite los caracteres que no sean letras

Modifica el método (_static_) `SqueakyClean.clean()` para omitir cualquier carácter que no sea una letra.

```java
SqueakyClean.clean("a$#.b");
// => "ab"
```

[leet-speak]: https://en.wikipedia.org/wiki/Leet
