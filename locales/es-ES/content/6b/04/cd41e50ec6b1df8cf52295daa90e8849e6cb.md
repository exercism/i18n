# Apéndice de instrucciones

## Pistas

- Para analizar el texto, puedes intentar usar la biblioteca [Sprache](https://github.com/sprache/Sprache/blob/develop/README.md). También puedes encontrar un buen tutorial [aquí](https://www.thomaslevesque.com/2017/02/23/easy-text-parsing-in-c-with-sprache/).
- Puedes resolver este ejercicio con un algoritmo de fuerza bruta, pero es posible que su rendimiento en tiempo de ejecución sea malo.
  Intenta encontrar una solución más sofisticada.
- Pista: puedes probar el algoritmo de suma por columnas que suelen enseñar en la escuela.
