# Pistas

## General

- Puedes acceder a los componentes individuales de una tupla añadiendo un _.n_ al nombre de la tupla, donde _n_ es el índice del componente, empezando por 0.

## 1. Obtener el nombre del juguete

- Puedes acceder al nombre del juguete usando la sintaxis `.n`.

## 2. Añadir un juguete nuevo a la base de datos

- Puedes crear una tupla nueva usando la sintaxis de tupla `(name1: value1, name2: value2, ...)`.

## 3. Actualizar la cantidad de un juguete

- Puedes usar un [bucle `for`][for-loop] para iterar sobre el array de tuplas y actualizar la cantidad del juguete.
- Puedes usar las funciones que has implementado antes para obtener el nombre del juguete.
- Puedes usar una [instrucción condicional][conditional-statement] para comprobar si el nombre del juguete coincide con el que quieres actualizar.
- Puedes usar la sintaxis `.n` para actualizar la cantidad del juguete, por ejemplo: `toys.price = 3`.

## 4. Añadir la clave de categoría a un juguete

- Puedes usar un [bucle `for`][for-loop] para iterar sobre el array de tuplas y añadir la clave de categoría al juguete.
- Una tupla es inmutable, así que tienes que crear una tupla nueva con la clave de categoría añadida.
  
[for-loop]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#For-In-Loops
[conditional-statement]: https://docs.swift.org/swift-book/documentation/the-swift-programming-language/controlflow/#Conditional-Statements
