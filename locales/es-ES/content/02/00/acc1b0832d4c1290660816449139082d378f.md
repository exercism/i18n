# Introducción

En Elixir, una tupla es una estructura de datos que organiza datos: contiene un número fijo de elementos de cualquier tipo, pero sin nombres explícitos para cada elemento. Las tuplas se usan a menudo en Elixir en operaciones intensivas en lectura de memoria, ya que el acceso de lectura a un elemento es una operación de tiempo constante. No suelen usarse cuando puede que haya que añadir o eliminar elementos de forma dinámica, porque en lugar de modificar la tupla existente se crea una tupla nueva, lo que exige reservar memoria de antemano.

En la práctica, las tuplas se crean en Elixir con llaves. Se puede acceder a cada elemento de una tupla por separado con la función `elem/2`, usando una indexación que empieza en 0:

```elixir
empty_tuple = {}
one_element_tuple = {1}
multiple_element_tuple = {1, :a, "hello"}

elem(multiple_element_tuple, 2)
# => "hello"
```

## Las tuplas como información agrupada

En la práctica, las tuplas se usan a menudo para representar información agrupada.

```elixir
Float.ratio(0.25)
# => {1, 4} indicating the numerator and denominator of the fraction ¼
```
