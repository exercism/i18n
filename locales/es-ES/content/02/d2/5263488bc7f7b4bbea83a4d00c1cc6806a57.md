# Acerca de

Una [instrucción switch][switch] te permite comparar un valor con varios valores posibles que coincidan.
Te permite escribir código más conciso que usando varias instrucciones `else-if`.
Una instrucción switch comienza con la palabra clave `switch` seguida del valor que se va a comparar.
Después puedes definir los casos con la palabra clave `case` seguida del valor con el que se va a comparar.
La palabra clave `default` se usa para definir el caso por defecto cuando ninguno de los casos coincide.
Al igual que las instrucciones `else-if`, las instrucciones `switch` solo ejecutan el bloque de código asociado al primer caso que coincida.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Considera el siguiente ejemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

En su lugar, podría escribirse así:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```

## Vinculación y cláusulas where

Los valores que se comparan en las instrucciones `switch` también se pueden vincular a nombres que se pueden usar en el cuerpo del caso.
También se pueden usar en cláusulas `where`, que son expresiones Boolean adicionales que deben evaluarse como `true` para que el caso coincida.

```swift
let x = 1337
switch sumOfDivisors(of: x) {
case let total where total == x:
  print(total, "is a perfect number")
default:
  print(x, "is not a perfect number")
}
```
