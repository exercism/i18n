# Instrucciones

En **Chrono Realms**, los Guardianes del Tiempo a menudo tratan no solo con árboles de líneas temporales, sino también con **Cadenas Crono**: secuencias de **Nodos Temporales** enlazados, cada uno representando un momento específico en el tiempo.
Una **Cadena Crono** es un camino recto de momentos secuenciales, donde cada **Nodo Temporal** se conecta al siguiente.
Estas **Cadenas Crono** son útiles al viajar a través de una serie de eventos específicos, ya que permiten a los Guardianes del Tiempo seguir una única línea temporal.

Sin embargo, para manejar estas **Cadenas Crono** potencialmente largas, los Guardianes del Tiempo usan **punteros inteligentes (Box<T>)** para gestionar y recorrer de forma segura estas listas de momentos sin causar duplicación o desbordamiento de memoria innecesarios.
Cada **Nodo Temporal** contiene una referencia al siguiente nodo, formando una estructura recursiva.

Tu tarea como aprendiz es implementar una **Cadena Crono** como una estructura de lista recursiva usando punteros inteligentes.

En este ejercicio, harás lo siguiente:

1. Crear un enum recursivo `ChronoChain`, que represente una lista de momentos.
2. Usar el puntero inteligente `Box<T>` para almacenar los nodos recursivos.
3. Implementar una función para crear un `ChronoChain` a partir de un array de valores `u32`.
4. Implementar una función para recorrer el `ChronoChain` y sumar los valores almacenados en la lista.

## 1. Define el enum `ChronoChain` recursivo

Crea un enum recursivo `ChronoChain` con dos variantes:

- `End`: Representa el final de la lista.
- `Link`: Contiene un valor `u32` y una referencia empaquetada al siguiente nodo de la cadena.

## 2. Crea una función para construir una Cadena Crono

Escribe una función `ChronoChain::build` que tome un array de valores `u32` y devuelva un `ChronoChain`, enlazando los valores secuencialmente mediante punteros inteligentes.

## 3. Implementa la función de suma

Escribe una función `ChronoChain::sum` para recorrer recursivamente el `ChronoChain` y sumar los valores de todos los nodos.

## Ejemplo de uso

```rust
fn main() {
    // Create a ChronoChain from an array of values
    let chrono_chain = ChronoChain::build(array![10, 20, 30]);

    // Sum the values in the ChronoChain
    let total_sum = chrono_chain.sum();

    println!("Total Time Power: {}", total_sum);
}
```
