# Manipulación de bits

Crystal tiene operadores bit a bit para manipular [`Int`][ints] a nivel binario.

## Operadores de desplazamiento

Crystal tiene [operadores de desplazamiento][shift] para desplazar bits a la izquierda (`<<`) o a la derecha (`>>`).

### Desplazamiento a la izquierda (`<<`)

El operador de desplazamiento a la izquierda (`<<`) desplaza los bits hacia la izquierda.
El valor que hay que desplazar se indica a la izquierda y el número de posiciones que hay que desplazar, a la derecha.

```crystal
0b0010 << 1
# => 0b0100

0b0010 << 2
# => 0b1000
```

Si el número es negativo, se desplazará hacia la derecha en su lugar.

```crystal
0b0010 << -1
# => 0b0001
```

### Desplazamiento a la derecha (`>>`)

El operador de desplazamiento a la derecha (`>>`) desplaza los bits hacia la derecha.
Al igual que el operador de desplazamiento a la izquierda, el valor que hay que desplazar se indica a la izquierda y el número de posiciones que hay que desplazar, a la derecha.

```crystal
0b0100 >> 1
# => 0b0010

0b0100 >> 2
# => 0b0001
```

Y, de forma similar, el operador desplazará hacia la izquierda si el número es negativo.

```crystal
0b0100 >> -1
# => 0b1000
```

## Operadores binarios

Crystal tiene 3 [operadores binarios][binary] (`&`, `|`, `^`) y un operador `~` para realizar operaciones bit a bit.

### AND bit a bit (`&`)

El operador AND binario (`&`) realiza una operación AND bit a bit sobre dos valores.
Compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
El bit resultante se pone a 1 si ambos bits son 1.
En caso contrario, se pone a 0.

```crystal
0b0011 & 0b1010
# => 0b0010
```

### OR bit a bit (`|`)

El operador OR binario (`|`) realiza una operación OR bit a bit sobre dos valores.
También compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
Si cualquiera de los dos bits es 1, el bit resultante se pone a 1.
En caso contrario, se pone a 0.

```crystal
0b0011 | 0b1010
# => 0b1011
```

### XOR bit a bit (`^`)

El operador XOR binario (`^`) realiza una operación XOR bit a bit.
Al igual que los operadores AND y OR bit a bit, compara cada bit del primer valor con el bit que ocupa la misma posición en el segundo valor.
Si _solo uno_ de ellos es 1, el bit resultante es 1.
En caso contrario, es 0.

```crystal
0b0011 ^ 0b1010
# => 0b1001
```

### NOT bit a bit (`~`)

Por último, el operador NOT bit a bit (`~`) invierte cada uno de los bits del valor.
A diferencia de los demás operadores binarios, este es un operador unario, que opera solo sobre el valor de la derecha.

```crystal
~0b1110_0010
# => 0b0001_1101
```
