# Conceptos de Leap

Prefiero la primera solución de ejemplo porque su concisión se ajusta a lo que he visto del Rust idiomático. Además, evita el añadido del concepto de closure de la solución canónica.

## Conceptos extraídos

### General

- Lógica booleana
  - boolean
- Expresiones
  - Las funciones de Rust devuelven expresiones de forma implícita
- Aritmética
  - residuo (de la división)

### Tipos

- enteros sin signo - `u64`
- booleans - `bool`

## Ejercicio de ejemplo 1

La solución de [«desi-belokonska»](https://exercism.org/tracks/rust/exercises/leap/solutions/01d024321b6a491690321844aedf8b09)

```rust
pub fn is_leap_year(year: u64) -> bool {
  year % 400 == 0 || year % 4 == 0 && year % 100 != 0
}
```

## Ejercicio de ejemplo 2

[Canónica](https://github.com/exercism/rust/blob/master/exercises/leap/example.rs)

```rust
pub fn is_leap_year(year: u64) -> bool {
    let has_factor = |n| year % n == 0;
    has_factor(4) && (!has_factor(100) || has_factor(400))
}
```
