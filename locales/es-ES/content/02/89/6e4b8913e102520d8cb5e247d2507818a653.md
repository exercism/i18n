# Pistas

## 1. Crea un vector con todos los vagones

- Un bucle `for`/`while` clásico con `push!` sobre un `Vector` funcionará.
- Si no, la función [`collect()`][collect] puede ser más concisa.
- Como alternativa, el splatting funciona dentro de un constructor de vector:

```julia-repl
julia> input = (1, 5, 9)
(1, 5, 9)

julia> [input...]
3-element Vector{Int64}:
 1
 5
 9
```

## 2. Arregla el vector de vagones

- Es útil separar los vagones delanteros y la locomotora del resto, para poder volver a montarlos en el orden correcto.
- La asignación múltiple con splatting puede ayudarte (consulta la introducción).

## 3. Añade las paradas que faltan

- ¡Recuerda que esta función no modifica la entrada! Crea un `Dict` nuevo.
- Solo se necesita el nombre de la parada, no su número, así que hay que separar cada par.
- Hay varias formas de montar el vector de nombres:
  -  Un bucle `for`/`while` con `push!()` sobre un `Vector`.
  -  Una [comprensión de arrays][comprehensions]
  -  [`map()`][map] para aplicar una función sobre el vector.
  -  También es posible el [broadcasting][broadcasting] de una función [anónima][anonymous]:

 ```julia-repl
julia> (x -> x^4).([1, 2, 3]) == [1, 16, 81]
true
 ```

## 4. Amplía la información de ruta

- Después de hacer slurping, `more_route_information` es una colección `Pairs()`.
- La función [`merge()`][merge] combina dos o más `Dict`, pero también acepta una colección `Pairs()`.
  Convertir explícitamente la colección `Pairs()` a un `Dict` es posible, pero innecesario.
