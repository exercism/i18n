# Tarifas de freelance

## Historia

En este ejercicio escribirás código para ayudar a un freelance a comunicarse con un jefe de proyecto, proporcionando algunas utilidades que permitan calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Para empezar, establecemos unas cuantas reglas entre el freelance y el jefe de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora;
- Un mes tiene 22 días facturables.

El freelance se ofrece a aplicar un descuento si el jefe de proyecto decide permitir que el freelance facture por mes, lo que puede venir bien si el jefe de proyecto tiene que trabajar con un presupuesto determinado.

Los descuentos se modelan como números fraccionarios seguidos de un `%` (porcentaje) entre `0.0%` (sin descuento) y `90.0%` (descuento máximo).

## Tareas

Estas son tareas de ejemplo que encajan con la historia del freelance que se comunica con un jefe de proyecto:

- Calcular la tarifa diaria a partir de una tarifa por hora
- Calcular la tarifa mensual, a partir de una tarifa por hora y un descuento
- Calcular el número de días laborables a partir de un presupuesto, una tarifa y un descuento

## Terminología

Estas son recomendaciones, no reglas, para la terminología recurrente en las instrucciones (incluidos los comentarios del stub)

- La tarifa diaria es 8 veces la tarifa por hora; debería mencionarse
- La tarifa mensual es 22 veces la tarifa diaria; debería mencionarse
- Si el descuento se proporciona como un tipo _distinto_ de los tipos numéricos, usa la terminología **los descuentos se modelan como**
