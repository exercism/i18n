# Introducción

Los mapas en Elixir son la estructura de datos que sirve para almacenar información en pares clave-valor. En otros lenguajes también se conocen como arrays asociativos (PHP), hashes (Perl 5, Raku) o diccionarios (Python).

Las claves y los valores pueden ser de cualquier tipo de datos, pero si la clave es un átomo podemos usar una sintaxis abreviada. Los mapas no garantizan el orden de sus entradas cuando se accede a ellas o se devuelven.

## Formas literales

Un mapa vacío se declara simplemente con `%{}`. Si queremos añadir elementos a un literal de mapa, podemos usar dos formas:

```elixir
# If the key is an atom:
%{atom_key: 1}

# If the key is a different type:
%{1 => :atom_value}

# You can even mix these if the atom form comes second:
%{"first_form" => :a, atom_form: :b}
```

Aunque no existe un formato canónico, elige una forma coherente de representar los pares clave-valor del literal.

## Funciones del módulo Map

Elixir proporciona muchas funciones para trabajar con mapas en el _módulo Map_. Algunas funciones del _módulo Map_ requieren que se les pase una función _anónima_ para ayudar con la transformación del mapa.
