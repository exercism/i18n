# Introducción

El tipo `atom` de Elixir representa una constante fija. El valor de un átomo es simplemente su propio nombre. Esto nos da una forma de interactuar con los datos con seguridad de tipos. Los átomos pueden definirse así:

```elixir
# All atoms are preceded with a ':' then follow with alphanumeric snake-cased characters
variable = :an_atom
```

_Los átomos_ se representan internamente mediante un número entero en una tabla de búsqueda, que se asigna automáticamente. No es posible cambiar este valor interno.
