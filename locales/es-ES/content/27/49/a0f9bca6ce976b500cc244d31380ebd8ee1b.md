# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los distintos niveles de registro:

- `TRC` (trace)
- `DBG` (debug)
- `INF` (info)
- `WRN` (warning)
- `ERR` (error)
- `FTL` (fatal)

Tienes tres tareas.

## 1. Analizar el nivel de registro

Define un enum `LogLevel` que tenga seis elementos correspondientes a los niveles de registro anteriores.

- `Trace`
- `Debug`
- `Info`
- `Warning`
- `Error`
- `Fatal`

A continuación, implementa el método (_static_) `LogLine.ParseLogLevel()` para analizar el nivel de registro de una línea de registro:

```csharp
LogLine.ParseLogLevel("[INF]: File deleted")
// => LogLevel.Info
```

## 2. Admitir un nivel de registro desconocido

Lamentablemente, en ocasiones algunas líneas de registro tienen un nivel de registro desconocido. Para gestionar estas líneas de registro con elegancia, añade un elemento `Unknown` al enum `LogLevel`, que debe devolverse al analizar un nivel de registro desconocido:

```csharp
LogLine.ParseLogLevel("[XYZ]: Overly specific, out of context message")
// => LogLevel.Unknown
```

## 3. Convertir la línea de registro al formato corto

El nivel de registro de una línea de registro es bastante verboso. Para reducir el espacio en disco necesario para almacenar las líneas de registro, se ha desarrollado un formato corto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

El nivel de registro codificado es una asignación simple de un nivel de registro a un número:

- `Unknown` - `0`
- `Trace` - `1`
- `Debug` - `2`
- `Info` - `4`
- `Warning` - `5`
- `Error` - `6`
- `Fatal` - `42`

Implementa el método (_static_) `LogLine.OutputForShortLog()` que puede generar el formato corto de la línea de registro:

```csharp
LogLine.OutputForShortLog(LogLevel.Error, "Stack overflow")
// => "6:Stack overflow"
```
