# Apéndice de instrucciones

## Pistas

Para completar este ejercicio, tienes que implementar las siguientes funciones:

- `boardString`
- `canAttack`

Las firmas de tipo ya están puestas, pero eres tú quien debe definir las funciones.

Las posiciones se especifican como tuplas de dos elementos:

- El primer elemento es la fila («rank» en terminología del ajedrez).
- El segundo elemento es la columna («file» en terminología del ajedrez).
- (0, 0) es la esquina superior izquierda del tablero, (0, 7) es la superior derecha,
- (7, 0) es la inferior izquierda y (7, 7) es la inferior derecha.
