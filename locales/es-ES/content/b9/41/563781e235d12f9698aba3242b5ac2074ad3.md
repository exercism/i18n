# Tests

## Ejecutar Tests

Cuando estés en el directorio de un ejercicio, deberías ver dos subdirectorios:

* `src` contiene tu solución al ejercicio
* `spec` contiene los tests para ejecutar el ejercicio

Si estás en el directorio correcto (es decir, el que contiene `src` y `spec`), puedes ejecutar los tests de ese ejercicio ejecutando `crystal spec`:

```bash
$ pwd
/Users/johndoe/Code/exercism/crystal/hello-world

$ ls
GETTING_STARTED.md README.md          spec               src

$ crystal spec
```

Esto ejecutará todos los archivos de test en el directorio `spec`.

En cada archivo de test, todos los tests excepto el primero se han omitido.

Una vez que consigas que un test pase, puedes dejar de omitir el siguiente cambiando `pending` por `it`.

## Formato de Crystal

Antes de enviar, se recomienda que ejecutes `crystal tool format` en tu solución.

Puedes formatear todo en tu directorio actual con:

```bash
$ crystal tool format ./
```

O puedes formatear archivos selectivamente con:

```bash
$ crystal tool format ./<path>/<to>/<file>
```

## Enviar tu solución

Asegúrate de enviar el archivo fuente en el directorio `src` cuando envíes tu solución:

```bash
$ exercism submit src/<exercise>.cr
```
