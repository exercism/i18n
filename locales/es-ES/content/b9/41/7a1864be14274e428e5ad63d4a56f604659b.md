# Introducción

Common Lisp usa los operadores aritméticos estándar para la mayoría de las operaciones, pero tiene la particularidad de usar una «notación prefija» en lugar de la más familiar «notación infija».

Más visualmente:

```lisp
;; Infix-notation (non-lisp languages)
1 + 2 + 3 + 4 + 5 ; => 15
;; Prefix-notation (lisp languages)
(+ 1 2 3 4 5)     ; => 15
```

Aunque la notación prefija convierte algunas operaciones como `2 + 2` en la forma algo desconocida `(+ 2 2)`, hace que sea mucho más fácil operar con más de un número a la vez.

## Aritmética básica

Common Lisp tiene todas las funciones típicas: `+`, `-`, `*`, `/` para la suma, la resta, la multiplicación y la división.

Al considerar la división, puede que quieras saber el residuo de una división; esto se hace con la función `mod` (de módulo), que toma un número y un divisor como argumentos:

```lisp
(mod 4 2)  ; => 0
(mod 2 4)  ; => 2
(mod 10 3) ; => 1
```

## Comparar números

Por último, puede que te resulte útil comparar números diferentes usando funciones como `=` (igual), `/=` (distinto de), y `>=` (mayor o igual que).
Cuando estas comparaciones son verdaderas (como en `(= 1 1)`), devuelven `T` y cuando no lo son (como en `(> 0 1)`), devuelven `NIL`.
