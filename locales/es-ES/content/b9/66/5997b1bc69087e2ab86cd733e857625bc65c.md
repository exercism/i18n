# Tests

## Configuración

Sigue las [instrucciones de configuración para WebAssembly][docs-exercism-wasm] para instalar las dependencias necesarias.

## Requisitos

Instala las dependencias del ejercicio:

```shell
# Using npm
npm install

# Alternatively using yarn
yarn
```

## Cómo hacer que pase la suite de tests

Todos los ejercicios incluyen una suite de tests que te ayuda a validar tu solución antes de enviarla.
Puedes ejecutar estos tests abriendo una terminal en el directorio del ejercicio y ejecutando:

```bash
# Using npm
npm test

# Alternatively using yarn
yarn test
```

En algunas suites de tests se han omitido todos los tests excepto el primero.

Cuando consigas que pase un test, puedes activar el siguiente cambiando `xtest` por `test`.

## Escribir tests personalizados

Si quieres escribir tests adicionales personalizados, crea un nuevo archivo `custom.spec.js` y envíalo junto con tu solución:

```shell
exercism submit numbers.wat custom.spec.js
```

[docs-exercism-wasm]: https://exercism.org/docs/tracks/wasm/installation
