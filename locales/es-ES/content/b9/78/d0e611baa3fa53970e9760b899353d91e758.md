# Strings

`STR` contiene texto. Una cadena de caracteres se escribe entre comillas dobles.

```sather
   composer : STR is
      return "Sibelius";
   end;
```

Un `STR` nunca cambia una vez que existe. Todo lo que sigue responde con un *nuevo* string en lugar de alterar el string sobre el que se preguntó.

## Concatenación

```sather
"Jean" + " " + "Sibelius"      -- "Jean Sibelius"
```

`+` también une un número a un string, que es como un número entra en una frase:

```sather
"Opus " + 27           -- "Opus 27"
```

## Longitud

```sather
"Sibelius".size        -- 8
"".size                -- 0
```

`.size` cuenta caracteres y la respuesta es un `INT`.

## Partes

| Llamada | Respuesta |
| --- | --- |
| `"Sibelius".head(3)` | `"Sib"` |
| `"Sibelius".tail(4)` | `"lius"` |

Pedir más de lo que hay devuelve lo que hay, en lugar de fallar.

## Comparación

`=` pregunta si dos strings son el mismo texto, y `/=` si son diferentes.

```sather
"forte" = "forte"      -- true
"forte" = "Forte"      -- false
```

Las mayúsculas y minúsculas importan. `.upper` y `.lower` dan una copia en mayúsculas o minúsculas, que es la forma habitual de comparar sin preocuparse por el caso:

```sather
"Forte".lower                    -- "forte"
"Forte".lower = "forte".lower    -- true
```

## Una palabra sobre el tamaño

Un `STR` es una fila de bytes, y `.size` cuenta bytes. Para texto en inglés, eso es lo mismo que contar letras. Para texto con acentos u otros alfabetos, no lo es, porque esas letras ocupan más de un byte cada una.
