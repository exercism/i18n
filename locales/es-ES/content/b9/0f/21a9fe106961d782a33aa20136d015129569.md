# Anexo de instrucciones

## Cómo está estructurado este ejercicio en la pista de Python

Las pruebas de este ejercicio esperan que tu solución se implemente como una `class` RelativeDistance en Python.
Si no estás familiarizado con las `class`es en Python, [concept:python/classes]() y [`classes` en la documentación oficial de Python][classes in python] son buenos puntos de partida.


`RelativeDistance` debe inicializarse (_consulta [`__init__()`][init] para más información_) usando `family_tree`, un diccionario en el que las `keys` son individuos y los `values` son `list`s de los hijos de ese individuo.
También tendrás que implementar un [método][methods] `degree_of_separation` que devuelva el grado de separación entre `person_a` y `person_b`, que son individuos del árbol genealógico que se pasa.


Se te da una implementación esbozada para el [método especial][special-methods] `__init__` que se usa para crear una instancia de la clase RelativeDistance, así como un esbozo del método `degree_of_separation`.
En primer lugar, tendrás que personalizar el `__init__` con un atributo adecuado en `self` (_la instancia_) que represente los datos de `family_tree`.
Después podrás añadir tu lógica al método `degree_of_separation` para calcular el grado de separación entre `person_a` y `person_b`.


## Mensajes de excepción

A veces es necesario [lanzar una excepción][raising-exceptions].
Cuando lo hagas, siempre debes incluir un **mensaje de error significativo** que indique cuál es el origen del error.
Esto hace que tu código sea más legible y ayuda mucho a la hora de depurar.
En los casos en los que sepas que el origen del error será de un tipo concreto, puedes optar por lanzar uno de los [tipos de error integrados][base-error-classes], pero aun así deberías incluir un mensaje significativo.

Este ejercicio en concreto requiere que uses la [instrucción `raise`][raise-statement] para «lanzar» varios `ValueError`s.
En el primer caso, tendrás que lanzar un `ValueError` cuando una de las dos personas, o ambas, que se pasan al método `RelativeDistance.degree_of_separation` no estén presentes en el árbol genealógico.

```python
# Example when Person A is not in the tree.
raise ValueError("Person A not in family tree.")
```

Si ambas personas están presentes en el árbol genealógico, tendrás que lanzar un `ValueError` cuando no exista una conexión válida entre ellas según lo definido por las reglas.

```python
# Example when there are no valid connections.
raise ValueError("No connection between person A and person B.")
```

Las pruebas solo pasarán si lanzas el tipo de `exception` esperado y además incluyes junto a él el mensaje esperado.
Revisa con atención las pruebas y sus resultados esperados, ya que estas instrucciones no son exhaustivas.
