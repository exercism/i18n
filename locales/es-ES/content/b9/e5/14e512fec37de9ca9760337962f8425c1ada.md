## 1. Extraer las coordenadas

Implementa la función `get_coordinate()`, que recibe un par `(treasure, coordinate)` del array de Azara y devuelve únicamente la coordenada del mapa extraída.


```python
>>> get_coordinate(('Scrimshawed Whale Tooth', '2A'))
2A
```

## 2. Dar formato a las coordenadas

Implementa la función `convert_coordinate()`, que recibe una coordenada con el formato «2A» y devuelve una tupla con el formato `("2", "A")`.


```python
>>> convert_coordinate("2A")
("2", "A")
```

## 3. Comparar las coordenadas

Implementa la función `compare_records()`, que recibe un par `(treasure, coordinate)` y un registro `(location, coordinate, quadrant)` y compara las coordenadas de cada uno.
Devuelve **`True`** si las coordenadas «coinciden» y devuelve **`False`** si no.
Vuelve a dar formato a las coordenadas según sea necesario para compararlas con precisión.


```python
>>> compare_records(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
False

>>> compare_records(('Model Ship in Large Bottle', '8A'), ('Harbor Managers Office', ('8', 'A'), 'purple'))
True
```

## 4. Combinar los registros coincidentes

Implementa la función `create_record()`, que recibe un par `(treasure, coordinate)` del array de Azara y un registro `(location, coordinate, quadrant)` del array de Rui y devuelve `(treasure, coordinate, location, coordinate, quadrant)` **si las coordenadas coinciden**.
Si las coordenadas _no_ coinciden, devuelve el string **«not a match»**.
Vuelve a dar formato a la coordenada según sea necesario para compararla con precisión.


```python
>>> create_record(('Brass Spyglass', '4B'), ('Abandoned Lighthouse', ('4', 'B'), 'Blue'))
('Brass Spyglass', '4B', 'Abandoned Lighthouse', ('4', 'B'), 'Blue')

>>> create_record(('Brass Spyglass', '4B'), ('Seaside Cottages', ('1', 'C'), 'blue'))
"not a match"
```
