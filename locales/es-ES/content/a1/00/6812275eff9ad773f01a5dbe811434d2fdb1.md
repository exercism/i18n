# Anexo a las instrucciones

## Memoria reservada

El búfer para el string de entrada utiliza los bytes 64-319 de la memoria lineal.

## Resultados

El resultado debe devolverse como una tupla de 4 elementos: `(i32 i32 i32 i32)`. Cada número representa el recuento de las letras `A`, `C`, `G` y `T`, en este orden.
