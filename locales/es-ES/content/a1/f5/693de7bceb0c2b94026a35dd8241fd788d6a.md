# Instrucciones

Tienes en marcha un sistema formado por unas cuantas aplicaciones que producen muchos logs. Quieres escribir un pequeño programa que recopile esos logs y les asigne etiquetas en función de su nivel de gravedad. Todas las aplicaciones de tu sistema usan los mismos códigos de log, pero algunas de las aplicaciones heredadas no admiten todos los códigos.

| Código de log         | Etiqueta de log | ¿Admitido en las aplicaciones heredadas? |
|-----------------------| --------- | ------------------------- |
| 0                     | trace     | no                        |
| 1                     | debug     | sí                       |
| 2                     | info      | sí                       |
| 3                     | warning   | sí                       |
| 4                     | error     | sí                       |
| 5                     | fatal     | no                        |
| otro / no admitido | unknown   | -                         |

## 1. Determina la etiqueta del log

Implementa la función `LogLevel.to_label/2`. Debe recibir un código entero y un valor booleano que te indique si el log procede de una aplicación heredada, y devolver la etiqueta de una línea de log como átomo.

Los códigos de log que no aparecen en la tabla deben devolver la etiqueta _unknown_. Los códigos de log que la tabla indica como no admitidos en las aplicaciones heredadas también deben devolver la etiqueta _unknown_ si el log procede de una aplicación heredada.

```elixir
LogLevel.to_label(0, false)
# => :trace

LogLevel.to_label(0, true)
# => :unknown
```

## 2. Envía una alerta

Hay que avisar a alguien cuando ocurren cosas inesperadas.

Implementa la función `LogLevel.alert_recipient/2` para determinar a quién hay que enviar la alerta. La función debe recibir un código entero y un valor booleano que te indique si el log procede de una aplicación heredada, y devolver el nombre del destinatario como átomo.

Usa la función `LogLevel.to_label/2` de la tarea anterior. Si la etiqueta del log es _error_ o _fatal_, envía la alerta al equipo _ops_. Si recibes un log con una etiqueta _unknown_ procedente de un sistema heredado, envía la alerta al equipo _dev1_; las demás etiquetas unknown deben enviarse al equipo _dev2_. Todas las demás etiquetas de log se pueden ignorar sin problema devolviendo _false_.

```elixir
LogLevel.alert_recipient(-1, true)
# => :dev1

LogLevel.alert_recipient(0, false)
# => false
```
