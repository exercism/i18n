# Anexo a las instrucciones

Sobrescribe el string del número de teléfono proporcionado.
Si el número de teléfono no es válido, reemplázalo por un string vacío.

## Registros

| Registro | Uso            | Tipo       | Descripción                                      |
| -------- | -------------- | ---------- | ------------------------------------------------ |
| `$a0`    | entrada/salida | dirección  | número de teléfono como string terminado en null |
| `$t0-9`  | temporal       | cualquiera | se usa para almacenamiento temporal              |
