# Instrucciones

Vas a ayudar a unos novios de instituto a declarar su amor en las redes sociales generando un corazón unicode con sus iniciales:

```
❤ J.  +  M. ❤
```

## 1. Limpia el nombre

Define `cleanupname`, que toma un nombre de la pila. Sustituye cada `-` por un espacio y, después, elimina los espacios en blanco al principio y al final.

```factor
"Jane-Ann" cleanupname .
! => "Jane Ann"
```

## 2. Obtén la primera letra del nombre

Define `firstletter`, que toma un nombre. Reutiliza `cleanupname` de la tarea anterior, toma el primer carácter del resultado y devuélvelo como un string de un solo carácter.

```factor
"Jane" firstletter .
! => "J"
```

## 3. Da formato a la primera letra como inicial

Define `initial`, que toma un nombre. Reutiliza `firstletter` de la tarea anterior, ponla en mayúsculas y añade un `.`.

```factor
"Robert" initial .
! => "R."
```

## 4. Coloca las iniciales dentro del corazón

Define `couple`, que toma dos nombres de la pila. Reutiliza `initial` de la tarea anterior con cada nombre y, después, monta el resultado:

```factor
"Blake Miller" "Riley Lewis" couple .
! => "❤ B.  +  R. ❤"
```
