# Consejos

## General

En este ejercicio vas a escribir filtros de `jq` para cuatro tareas.
Como un programa de `jq` es una _única expresión_, esos cuatro filtros tienen que unirse con comas.
Usa paréntesis alrededor de las subexpresiones para controlar el orden de las operaciones.

## 1. Extrae el nombre de la lista de la compra

- Se puede acceder al contenido del fichero con el filtro `.`.
- Se puede acceder a una propiedad de un objeto con la notación de punto o la notación de corchetes.

## 2. Cuenta cuántos ingredientes se necesitan

- Tienes que obtener la longitud de un array.

## 3. ¿Cuánto azúcar?

- Tienes que seleccionar el ingrediente llamado «sugar».
- Tienes que acceder a una de sus propiedades.

## 4. Transforma los ingredientes que se pueden sustituir

- Tienes que concatenar dos arrays.
- Tienes que seleccionar elementos concretos del array resultante.
- Tienes que generar un objeto clave:valor para cada uno de estos elementos.
- Tienes que combinar estos objetos en un único objeto.
