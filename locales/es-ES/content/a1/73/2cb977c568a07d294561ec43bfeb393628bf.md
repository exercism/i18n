# Tests

## Ejecutar los tests

Ejecuta la especificación de tests con:

```bash
$ gradle test
```

## Activar más tests

Cuando tu código supere todos los tests activos, activa otro test eliminando el
`@Ignore` que precede al siguiente test que te interese. Para ello, elimina
la línea `@Ignore` o coméntala añadiendo dos barras inclinadas al principio de
la línea.

```Groovy
//@Ignore
def 'outputs "Hello, Alice!" when given the name "Alice"'() {
    expect: hello.hello('Alice') == 'Hello, Alice!'
}
```
