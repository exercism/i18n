# Ejecutar las pruebas

Para ejecutar la suite de pruebas, ejecuta el siguiente comando:

```bash
stack test
```

#### Si te aparece un mensaje de error como este...

```
No .cabal file found in directory
```

o

```
RedownloadInvalidResponse Request {
...
}
 "/home/username/.stack/build-plan/lts-xx.yy.yaml" (Response {responseStatus = Status {statusCode = 404, statusMessage = "Not Found"},
```

Probablemente estés usando una versión antigua de stack y necesites actualizarla. Prueba a ejecutar:

```bash
stack upgrade
```

O consulta otras opciones para actualizar stack en la [documentación de Stack](https://docs.haskellstack.org/en/stable/install_and_upgrade/#upgrade).

#### En caso contrario, si te aparece un mensaje de error como este...

```
No compiler found, expected minor version match with...
Try running "stack setup" to install the correct GHC...
```

Haz lo que dice y descargará e instalará la versión correcta del compilador:

```bash
stack setup
```

# Ejecutar *GHCi*

Si quieres experimentar con tu solución en GHCi, ejecuta el comando:

```bash
stack ghci
```
