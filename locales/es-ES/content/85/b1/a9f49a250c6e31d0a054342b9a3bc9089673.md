# Anexo a las instrucciones

## Pistas

Los tests unitarios proporcionan ejemplos de palabras. Intenta agrupar las
consonantes con independencia de las combinaciones concretas de consonantes
que aparecen en los tests unitarios.

Este ejercicio trabaja con datos textuales. Por motivos históricos, el tipo
`String` de Haskell es sinónimo de `[Char]`, una lista de caracteres. Para un
manejo más eficiente de los datos textuales, se puede usar el tipo `Text`.

Como ampliación opcional de este ejercicio, puedes

- Leer sobre los [tipos de string](https://haskell-lang.org/tutorial/string-types) en Haskell.
- Añadir `- text` a tu lista de dependencias en package.yaml.
- Importar `Data.Text` [de la siguiente manera](https://hackernoon.com/4-steps-to-a-better-imports-list-in-haskell-43a3d868273c):

      import qualified Data.Text as T
      import           Data.Text (Text)

- Ahora puedes escribir, por ejemplo, `translate :: Text -> Text` y referirte a los combinadores de `Data.Text` como, por ejemplo, `T.isSuffixOf`.
- Consultar la documentación de [`Data.Text`](https://hackage.haskell.org/package/text/docs/Data-Text.html).

Esta parte es totalmente opcional.
