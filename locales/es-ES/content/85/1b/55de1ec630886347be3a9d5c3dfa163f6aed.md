# Introducción

## Tipos de función

Si eliminamos todos los nombres y las etiquetas de la firma de una función de Swift, lo que queda es el tipo de la función.

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Fíjate en que los tipos de las dos primeras funciones son el mismo, `(String, Int) -> String`, aunque las dos firmas son distintas y las dos funciones funcionan de maneras muy diferentes. Ambas toman un `String` y un `Int` como entrada y devuelven un `String`. Y, como se puede ver en el tipo de la tercera función, aunque el cuerpo de la función no parece devolver nada, en realidad devuelve implícitamente `()`, el único valor de tipo `Void`.

Estos tipos de función se pueden usar de la misma manera que cualquier otro tipo en Swift; por ejemplo, se pueden usar en la declaración de variables o constantes. Y como en Swift las funciones son valores, se pueden asignar funciones ya existentes a esas constantes o variables:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."
```

Al igual que con otras variables o constantes, el valor que le asignes debe ser del tipo correcto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de función como tipos de parámetros

Como los tipos de función se pueden usar en cualquier lugar en el que se pueda usar otro tipo, se deduce que también se pueden usar como tipos de parámetros, pasarlos a otras funciones y llamarlos desde dentro de esas funciones.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"
```

## Tipos de función como tipos devueltos

Del mismo modo, los tipos de función pueden usarse como tipos devueltos de otras funciones. En otras palabras, puedes escribir funciones que crean y devuelven otras funciones. Al crear estas funciones, la función devuelta puede usar los otros parámetros que se pasan a la función o las variables locales creadas dentro de la función contenedora.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract20: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```
