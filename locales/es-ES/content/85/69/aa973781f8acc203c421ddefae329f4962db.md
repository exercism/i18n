# Introducción

## Números

En Java hay dos tipos diferentes de números:

- Enteros: números sin dígitos detrás del separador decimal (números enteros).
  Por ejemplo, `-6`, `0`, `1`, `25`, `976` y `-500000`.
- Números de coma flotante: números con cero o más dígitos detrás del separador decimal.
  Por ejemplo, `-20.4`, `0.1`, `2.72`, `16.984025` y `1024.0`.

Los dos tipos numéricos más comunes de Java son `int` y `double`.
Un `int` es un entero de 32 bits y un `double` es un número de coma flotante de 64 bits.

La aritmética se hace con los operadores aritméticos estándar.
Los números se pueden comparar con los operadores de comparación numéricos estándar (por ejemplo, `5 > 4` y `4 <= 5`) y con los operadores de igualdad (`==`) y desigualdad (`!=`).

Java tiene dos tipos de conversiones numéricas:

1. Conversiones implícitas: no se pierde ningún dato y no se necesita sintaxis adicional.
2. Conversiones explícitas: se pueden perder datos y se necesita sintaxis adicional en forma de _cast_.

Como un `int` tiene menos precisión que un `double`, convertir de `int` a `double` es seguro y, por tanto, es una conversión implícita.
Sin embargo, convertir de `double` a `int` podría implicar perder datos, así que requiere una conversión explícita.

## Condicionales if-else

### El condicional _if-then_

La instrucción de control de flujo más básica de Java es el condicional _if-then_.
Esta instrucción se usa para ejecutar una sección de código solo cuando una condición concreta es `true`.
Un condicional _if-then_ se define con la cláusula `if`:

```java
class Car {
    void drive() {
        // the "if" clause: the car needs to have fuel left to drive
        if (fuel > 0) {
            // the "then" clause: the car drives, consuming fuel
            fuel--;
        }
    }
}
```

En el ejemplo anterior, si el coche se queda sin combustible, llamar al método `Car.drive` no hará nada.

### El condicional _if-then-else_

El condicional _if-then-else_ ofrece una ruta de ejecución alternativa para cuando la condición de la cláusula `if` se evalúa como `false`.
Esta ruta de ejecución alternativa sigue a una cláusula `if` y se define con la cláusula `else`:

```java
class Car {
    void drive() {
        if (fuel > 0) {
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, si el coche se queda sin combustible, llamar al método `Car.drive` llamará a otro método para detener el coche.

El condicional _if-then-else_ también admite varias condiciones usando la cláusula `else if`:

```java
class Car {
    void drive() {
        if (fuel > 5) {
            fuel--;
        } else if (fuel > 0) {
            turnOnFuelLight();
            fuel--;
        } else {
            stop();
        }
    }
}
```

En el ejemplo anterior, conducir el coche cuando el combustible es menor o igual que `5` hará que el coche avance, pero se encenderá la luz de combustible.
Cuando el combustible llegue a `0`, el coche dejará de avanzar.
