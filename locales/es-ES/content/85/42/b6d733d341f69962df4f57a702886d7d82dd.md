# de prueba

## Módulo «io»

En este ejercicio tendrás que leer de ficheros.
La clase `File` que necesitas está en el módulo `io`.
Se describe en la [documentación del proyecto Wren CLI][wren-cli].

(Ten en cuenta que el proyecto `wren-console` [amplía el módulo `io`][wren-console] con algunos métodos,
aunque no son necesarios para este ejercicio).

[wren-cli]: https://wren.io/cli/modules/
[wren-console]: https://github.com/joshgoebel/wren-console#extended-library-support
