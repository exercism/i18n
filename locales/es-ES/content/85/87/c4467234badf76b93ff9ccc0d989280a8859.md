# Introducción

Un *disposable* es cualquier cosa que retiene un recurso del sistema operativo (un fichero abierto, un socket, un bloqueo respaldado por una tabla hash) y que hay que liberar cuando ya no lo necesitas. El vocabulario [`destructors`][destructors] de Factor engloba todo esto en un pequeño framework para que la limpieza se haga incluso cuando una excepción desenrolla la pila.

```factor
USING: destructors io.files io.encodings.utf8 ;

"log.txt" utf8 <file-writer> [
    "hello, world" write
] with-disposal
! file is closed even if write throws
```

`with-disposal ( disposable quot -- )` ejecuta el quotation con el recurso y lo libera al salir. Si tienes más de un recurso, abre un scope con `with-destructors` y registra cada uno con `&dispose` (se libera al salir con normalidad *y* también si hay un error) o `|dispose` (solo se libera si hay un error).

Una clase se une al framework extendiendo `disposable` e implementando el genérico `dispose*`. El framework lo llama una vez y solo una vez por objeto. La palabra pública que usan quienes llaman es `dispose`.

[destructors]: https://docs.factorcode.org/content/vocab-destructors.html
