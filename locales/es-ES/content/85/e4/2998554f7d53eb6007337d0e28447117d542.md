# Instrucciones

Llevas el puesto de seguridad de una estación de investigación. El personal lleva *insignias* cuyos códigos siguen un formato estricto, el registro de acceso está lleno de esos códigos mezclados entre texto normal, y hay que limpiar el registro antes de poder compartirlo. Las expresiones regulares son la herramienta adecuada para cada una de estas tareas.

Un código de insignia válido consta de **dos letras mayúsculas, un guion y cuatro dígitos**, por ejemplo `NS-1024`.

## 1. Comprobar un código de insignia

Define `valid-badge?`, que recibe un string con una insignia y devuelve `t` cuando el string *completo* es un código de insignia válido y `f` en caso contrario.

```factor
"NS-1024" valid-badge? .   ! => t
"NS-10"   valid-badge? .   ! => f
```

## 2. Extraer todos los códigos de una línea del registro

Define `badge-codes`, que recibe una línea del registro de acceso y devuelve una secuencia con todos los códigos de insignia que aparecen en ella, en orden.

```factor
"seen NS-1024 then AB-0007 today" badge-codes .
! => { "NS-1024" "AB-0007" }
```

## 3. Contar los dígitos de un código

Define `digit-count`, que recibe un string y devuelve cuántos dígitos contiene.

```factor
"NS-1024" digit-count .   ! => 4
```

## 4. Censurar las contraseñas

Las líneas del registro a veces incluyen una contraseña como `pass=` seguida del secreto (cualquier secuencia de caracteres que no sean espacios). Define `redact`, que recibe una línea y la devuelve con cada contraseña de ese tipo sustituida por `pass=****`.

```factor
"user=alice pass=hunter2 ok" redact .
! => "user=alice pass=**** ok"
```
