# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, ejecuta el siguiente comando:

```bash
dotnet test
```

## Resolver el ejercicio

Resolver un ejercicio significa hacer que todas sus pruebas pasen. De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera). Esto es intencionado, ya que te permite centrarte en hacer que esa única prueba pase. Cuando pase, puedes habilitar la siguiente prueba eliminando `Skip = "Remove this Skip property to run this test"` del atributo `[<Fact>]` o `[<Theory>]` de la prueba. Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!

Para ayudarte a empezar, cada ejercicio incluye un archivo de implementación inicial. Puedes usar este archivo como punto de partida para construir tu solución. No dudes en eliminar o modificar este archivo si crees que es lo adecuado.

## Usar paquetes

Deberías poder resolver la mayoría de los ejercicios sin usar ningún paquete externo. Sin embargo, en los ejercicios en los que sí quieras usar un paquete externo, puedes añadirlo a tu proyecto ejecutando el siguiente comando:

```bash
dotnet add package [package-name]
```
