# Instrucciones

En este ejercicio tienes que implementar varias funciones para manipular un array de lenguajes de programación.

## 1. Define una función que devuelva un array de lenguajes vacío

Define la función `new`, que no recibe argumentos y devuelve un array vacío.

```haskell
new
-- -> []
```

## 2. Define una función para añadir un lenguaje al array

Define la función `add/2`, que recibe 2 argumentos (un _array de lenguajes_ y un literal de string de un _lenguaje_).
Debe devolver el array resultante con el nuevo lenguaje antepuesto al array dado.

```haskell
add new "Clojure"
-- -> ["Clojure"]
add ["Clojure"] "Haskell"
-- -> ["Haskell", "Clojure"]
```

## 3. Define una función para eliminar un lenguaje del array

Define la función `remove`, que recibe 1 argumento (un _array de lenguajes_).
Debe devolver el array sin el primer elemento. Supón que el array siempre tendrá al menos un elemento.

```haskell
remove ["Haskell", "Clojure", "Erlang"]
-- -> ["Clojure", "Erlang"]
```

## 4. Define una función que devuelva el primer elemento del array

Define la función `first`, que recibe 1 argumento (un _array de lenguajes_).
Debe devolver el primer lenguaje del array.
Supón que el array siempre tendrá al menos un elemento.

```haskell
first ["Elixir", "Haskell", "Clojure", "Prolog"]
-- -> "Elixir"
```

## 5. Define una función que devuelva cuántos lenguajes hay en el array

Define la función `count`, que recibe 1 argumento (un _array de lenguajes_).
Debe devolver el número de lenguajes que hay en el array.

```haskell
count ["Prolog", "Elm"]
-- -> 2
```

## 6. Define una función para determinar si el array incluye un lenguaje funcional

Define la función `isFunctionalList`, que recibe 1 argumento (un _array de lenguajes_).
Debe devolver un valor Boolean.
Debe devolver `True` si _"Haskell"_ es uno de los lenguajes del array.

```haskell
isFunctionalList ["Haskell"]
-- -> True
```
