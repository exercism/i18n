# Anexo de instrucciones

## Instrucciones específicas del track

En el ejercicio «Yacht», crearás un verbo que calcula la puntuación de una única tirada de cinco dados en el juego Yacht, en función de la categoría elegida.

Para este ejercicio, tu verbo recibirá dos argumentos:

- **Argumento izquierdo**: un string que representa la categoría de puntuación que se aplicará a la tirada.
- **Argumento derecho**: un array de números enteros que representa los cinco dados lanzados.

Debes definir tu verbo para que maneje estas entradas del siguiente modo:

```j
  category =. 'Full House'
  dice     =. 1 3 3 3 5
  
  category scoreYacht dice
```
