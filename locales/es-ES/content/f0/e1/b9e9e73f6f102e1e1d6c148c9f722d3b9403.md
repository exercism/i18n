# Instrucciones

Mientras te preparabas para hornear galletas para tus amigos, te has dado cuenta de que tienes que convertir algunas de las medidas que usa la receta.
Como solo estás familiarizado con el sistema métrico, necesitas idear una forma de convertir las medidas de repostería estadounidenses más comunes a mililitros (mL) para tu propia comodidad.

Usa esta tabla de conversión para tu solución:

| Unidad a convertir | volumen | en mililitros (mL) |
| --------------- | ------ | ------------------- |
| mL              | 1      | 1                   |
| Taza estadounidense          | 1      | 240                 |
| Onza líquida estadounidense  | 1      | 30                  |
| Cucharadita estadounidense     | 1      | 5                   |
| Cucharada estadounidense   | 1      | 15                  |

Como eres un programador talentoso en formación, decides usar los mililitros como unidad de transición para facilitar la conversión de cualquier unidad de la lista a cualquier otra (incluso a sí misma).

## 1. Obtén el componente numérico de un par de volumen

Implementa la función `getVolume`. Dada una tupla de par de volumen, debe devolver solo el componente numérico.

```haskell
getVolume (Cup, 2.0)
-- -> 2.0
```

## 2. Convierte el par de volumen a mililitros

Implementa la función `toMilliliter`. Dada una tupla de par de volumen, debe convertir el volumen a mililitros usando la tabla de conversión.

Usa varias cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.
Devuelve el resultado de la conversión envuelto en una tupla.

```haskell
toMilliliter (Cup, 2.5)
-- -> (Milliliter, 600.0)
```

## 3. Convierte el par de volumen en mililitros a otra unidad

Implementa la función `fromMilliliter`. Dadas una tupla de par de volumen y la unidad deseada, debe convertir el volumen a la unidad deseada usando la tabla de conversión.

Usa varias cláusulas de función y coincidencia de patrones para crear las funciones de cada unidad. Los átomos que se usan para denotar cada unidad son: `Cup`, `FluidOunce`, `Teaspoon`, `Tablespoon`, `Milliliter`.

```haskell
fromMilliliter (Milliliter, 1320.0) Cup
-- -> (Cup, 5.5)
```

## 4. Convierte de cualquier unidad a cualquier unidad

Implementa la función `convert`. Dadas una tupla de par de volumen y la unidad deseada, debe convertir el volumen dado a la unidad deseada.

```haskell
convert (Teaspoon, 9.0) Tablespoon
-- -> (Tablespoon, 3.0)
```
