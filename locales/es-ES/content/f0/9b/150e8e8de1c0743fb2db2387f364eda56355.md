# Debug

```pyret
fun print-forty-two():
  print(42) # 42
end
```

```pyret
fun return-forty-two() block:
  print(42) # 42
  42
end
```

[print][print] es una expresión que devuelve un valor.
Pyret solo permite una única expresión dentro de un bloque de código determinado, a menos que el bloque exterior esté marcado con `block`.
En el segundo ejemplo, añadir `block` a la declaración de la función nos permite imprimir 42 antes de devolverlo.

## Espías

```pyret
fun do-something():
    x = "foo"
    y = "bar"
    spy "strings": x, y end
    a = 1
    b = 2
    spy "numbers": a, b end
end
do-something();

# Spying "strings" (at <clipped>/example.arr:4:4-4:27)
#  x: "foo"
#  y: "bar"
# Spying "numbers" (at <clipped>/example.arr:7:4-7:27)
#  a: 1
#  b: 2
```

Una instrucción spy acepta una etiqueta opcional y una o varias variables, e informa de cada variable y su valor.
Como no es una expresión, se puede usar un spy dentro de un bloque sin que el bloque exterior tenga que estar marcado con `block`.
