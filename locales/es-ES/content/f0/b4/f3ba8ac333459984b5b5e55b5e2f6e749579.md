# Acerca de

Si se pueden inferir los tipos de los parámetros, Swift también permite omitir los nombres de los parámetros y la palabra clave `in` de la definición del closure. En su lugar, se puede hacer referencia a los parámetros mediante una [sintaxis abreviada especial][shorthand-argument-names], en la que `$0` hace referencia al primer parámetro, `$1` al segundo, y así sucesivamente.

```swift
let mean: (Double, Double) -> Double = { $0 + $1 / 2.0 }

["apple", "ball", "carrot"].sorted(by: { $0.count < $1.count })
```

Este estilo se usa sobre todo cuando se pasan closures a funciones de orden superior y se valora la brevedad.

[shorthand-argument-names]: https://docs.swift.org/swift-book/LanguageGuide/Closures.html#ID100
