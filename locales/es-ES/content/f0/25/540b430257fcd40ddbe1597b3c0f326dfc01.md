# Acerca de

Un [`List`][lists] en Elm es una colección inmutable de cero o más valores del mismo tipo. Como los arrays son inmutables, una vez se ha construido un array, su valor no puede cambiar nunca. Los arrays de Elm tienen una _cabeza_ (el primer elemento) y una _cola_ (todo lo que viene después del primer elemento). La cola de un array es a su vez un array.

Las anotaciones de tipo para arrays se pueden definir así:

```elm
List String --> a list of String
List Int --> a list of Int
```

Los arrays se pueden definir así:

```elm
empty : List Char
empty = []

singleValue = [ 5 ] --> List Int
singleValueAlternative = List.singleton 5 --> List Int

threeValues = [ "a", "b", "c" ] --> List String
```

La forma más habitual de añadir un elemento a un array es mediante el operador `::` (cons):

```elm
twoToFour = [ 2, 3, 4 ]
oneToFour = 1 :: twoToFour --> [1; 2; 3; 4]
```

Se pueden añadir elementos al final de un array con el operador `++` o con `List.append`:

```elm
[ 6, 7 ] ++ [ 8, 9 ]           --> [6, 7, 8, 9]
List.append [ 6, 7 ] [ 8, 9 ]  --> [6, 7, 8, 9]
```

Los arrays se manipulan con funciones y operadores definidos en el [módulo `List`][list-module].

```elm
List.length [ 7, 8 ] --> 2
```

Cualquier función u operador que parezca modificar un array (como añadir un elemento) en realidad devuelve un array nuevo. No obstante, el rendimiento no suele ser un problema, ya que la implementación de los arrays evita asignaciones y copias innecesarias.

Los arrays también se pueden procesar mediante [coincidencia de patrones][list-destructuring].

```elm
describe : List String -> String
describe list =
    case list of
        [] ->
            "Empty list"

        [ "hello" ] ->
            "Singleton list with: hello"

        x :: xs ->
            "Non-empty list with head: " ++ x

describe []                   --> "Empty list"
describe [ "hello" ]          --> "Singleton list with: hello"
describe [ "hello", "world" ] --> "Non-empty list with head: hello"
```
