# Introducción

En Factor, defines una nueva palabra con `: name ( stack-effect ) body ;`.
El cuerpo es una secuencia de palabras; cuando llamas a tu nueva palabra, se
ejecutan en orden.

```factor
USING: kernel ;
IN: my-vocab

: shout ( str -- str ) "!" append ;
```

Cuando una rutina se hace grande, puedes (y deberías) *factorizarla*: extraer
grupos de palabras a palabras más pequeñas con nombre, cada una con una única
tarea. El lenguaje recibe su nombre de esto.

## Vocabularios

Cada fichero `.factor` declara un vocabulario con `IN:`. Las palabras de un
vocabulario pueden llamar a palabras de otro si incluyes el otro vocabulario
en `USING:`.

```factor
! file: my-vocab/helpers/helpers.factor
USING: kernel ;
IN: my-vocab.helpers

: shout-line ( str -- str ) "!" append ;
```

```factor
! file: my-vocab/my-vocab.factor
USING: kernel my-vocab.helpers sequences ;
IN: my-vocab

: announce ( names -- strs )
    [ shout-line ] map ;
```

La estructura de directorios sigue el nombre del vocabulario con puntos: el
vocabulario `my-vocab` está en `my-vocab/my-vocab.factor`; el vocabulario
`my-vocab.helpers` está en `my-vocab/helpers/helpers.factor`. El cargador de
Factor sigue las declaraciones `USING:` de forma transitiva y carga cada
vocabulario cuando se necesita.
