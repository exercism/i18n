## Números y operadores numéricos

Todos los **números**, ya sean enteros o no, son números de coma flotante de doble precisión IEEE754.
La implementación de `jq` usa el tipo `double` de C.
Esto nos limita a 53 bits de precisión.

Con los números puedes usar los operadores habituales:

- aritméticos: `+`, `-`, `*`, `/`, `%`
- comparación: `==`, `!=`, `<`, `<=`, `>=`, `>`
- [funciones matemáticas][man-math] estándar

  Para las funciones de una entrada, pasa el valor a la función mediante una tubería

  ```sh
  $ jq -n '(1 | atan) * 4'
  3.141592653589793
  ```

  Para las funciones de dos entradas, la función ignora la entrada y espera
  los valores como parámetros

  ```sh
  $ jq -n 'pow(2; 10)'
  1024
  ```

  El separador de los argumentos de una función es el punto y coma, no la coma.

~~~~exercism/caution
¿Qué significa decir «esto nos limita a 53 bits de precisión»?

Una demostración:

```sh
$ jq -n 'pow(2;52) as $n | [$n, $n+1]'
[
  4503599627370496,
  4503599627370497
]
```

Eso tiene buena pinta. ¿Y si aumentamos el exponente?

```sh
$ jq -n 'pow(2;53) as $n | [$n, $n+1]'
[
  9007199254740992,
  9007199254740992
]
```

Esos números no deberían ser iguales.
Así es lo que se ve cuando hay una «pérdida de precisión».
Esto significa que `jq` no puede trabajar con números arbitrariamente grandes.
~~~~

## Expresiones condicionales

`jq` usa una [expresión `if-then-else`][if-then-else] para las **expresiones condicionales**.
Como _expresión_, se coloca dentro de una tubería.

La sintaxis es: `if CONDTITION then TRUE_EXPR else FALSE_EXPR end`.

La cláusula `else` es opcional.

```jq
42 | if . < 33 then "small" else "larger" end
# => "larger"
```

Para condiciones adicionales se usa `elif`

```jq
42 | if . < 33 then "small"
     elif . < 67 then "medium"
     else "large"
     end
# => "medium"
```
