# Anexo de instrucciones

## Usa UTC

Para resolver este problema, tendrás que convertir un valor `time_t` en un valor `struct tm`.
La biblioteca [`time.h`][time.h] te ofrece dos funciones para hacerlo.
Asegúrate de usar la que dé como resultado un tiempo de calendario expresado en **UTC**.

[time.h]: https://en.cppreference.com/w/c/chrono
