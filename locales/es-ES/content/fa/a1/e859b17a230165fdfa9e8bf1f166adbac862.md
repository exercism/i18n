# Pistas

## General

- Todas las tareas construyen texto en un bucle, así que todas empiezan por `#FSTR` y
  terminan con `.str`.
- Asigna el resultado de cada `+` de vuelta a la variable que construye el texto:
  `script := script + ...`.

## 1. Repetir una señal

- `1.upto!(times)` ejecuta el bucle el número de veces correcto. El valor que
  devuelve no hace falta, así que puede ir directamente a una variable que no
  se use nunca, o puedes usar `times.times!`, que no devuelve nada en absoluto.
- Que no haya veces no necesita ningún tratamiento especial: el bucle simplemente no se ejecuta.

## 2. Las iniciales del reparto

- `names.elt!` te da cada nombre; `[0]` toma su primer carácter.
- Un `FSTR` acepta un `CHAR` directamente, así que no hace falta convertirlo en un
  string antes.

## 3. Numerar las líneas

- Dos iteradores en un mismo bucle, como en el ejercicio anterior: `1.up!` para el número
  y `lines.elt!` para el texto.
- El salto de línea va *antes* de cada línea excepto la primera. Comprobar el número
  es la forma más fácil: `if number > 1 then ... end`.
- Un `FSTR` acepta el número directamente, así que `script + number + ". "` funciona
  sin convertirlo.

## 4. Gritar una línea

- `line.elt!` recorre un string carácter a carácter.
- `.upper` deja intacto todo lo que no sea una letra, así que el espacio no necesita
  ningún tratamiento especial.
