# Instalación

La forma más sencilla de instalar PureScript es mediante Node.js y NPM.

Si aún no tienes Node.js instalado en tu ordenador, puedes descargarlo desde el [sitio web de Node.js](https://nodejs.org/). Cuando tengas Node.js en marcha, introduce este comando en el terminal para instalar el compilador de PureScript y la herramienta de compilación Spago:

    npm install --global purescript spago

Puedes encontrar más información en el [repositorio de PureScript](https://github.com/purescript/purescript/blob/master/INSTALL.md).
