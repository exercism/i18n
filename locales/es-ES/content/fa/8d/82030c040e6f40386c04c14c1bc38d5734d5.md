# Instrucciones

En este ejercicio vas a crear las reglas para la web de un cine.

## 1. Comprueba si un espectador tiene derecho al descuento para jubilados

El cine ofrece un descuento para los «jubilados».
Cualquier persona de 60 años o más paga 10,00 por la entrada.
Las personas más jóvenes pagan los 15,00 completos.

Escribe el método `Moviegoer#ticket_price` usando el operador ternario.

```ruby
Moviegoer.new(21).ticket_price
#=> 15

Moviegoer.new(65).ticket_price
#=> 10
```

## 2. Comprueba si un espectador puede ver películas de miedo

El cine tiene un sistema simplificado de verificación de edad.
Si tienes 18 años o más, puedes ver películas de miedo.
Si eres más joven, no puedes.

Implementa el método `Moviegoer#watch_scary_movie?`.
Debe devolver si alguien puede ver la película o no.

```ruby
Moviegoer.new(21).watch_scary_movie?
#=> true

Moviegoer.new(17).watch_scary_movie?
#=> false
```

## 3. Comprueba si un espectador tiene derecho a palomitas gratis

El cine tiene un programa llamado Movie Club.
Los socios reciben palomitas gratis cuando ven cualquier película.

Implementa el método `Moviegoer.claim_free_popcorn!`.
Si quien ve la película es socio del club, debe recibir sus palomitas gratis.
Si no lo es, el método debe lanzar la excepción `UnsupportedOperation` definida al principio del código.

```ruby
Moviegoer.new(21, member: true).claim_free_popcorn!
#=> 🍿

Moviegoer.new(17, member: false).claim_free_popcorn!
#=> Exception was raised! (NotMovieClubMemberError)
```

~~~~exercism/note
En este ejercicio, se espera que definas la excepción `UnsupportedOperation` para un scope concreto.
~~~~
