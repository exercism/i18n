# Temario: el primer ejercicio

El primer ejercicio debe cubrir el concepto `basics` y no debe tener requisitos previos.
Debe proporcionar solo la información suficiente para que el estudiante pueda resolver el ejercicio que tiene entre manos.

Muchos tracks ya han implementado un ejercicio que cubre `basics`.
Para familiarizarte con lo que se suele enseñar en este tipo de ejercicio, te recomendamos que te registres en unos cuantos tracks que tengan el Modo de aprendizaje y resuelvas el primer ejercicio de concepto.

Cada lenguaje es diferente, y puede que necesites introducir más cosas que otros tracks, o menos.
Por ejemplo, si necesitas compilar un programa para que funcione, esto es algo que conviene mencionar en la introducción del ejercicio.

Otras cosas que se suelen tratar en el ejercicio `basics` son:

- definiciones de funciones o métodos
- llamar a funciones
- pasar argumentos a funciones
- asignar un valor a un nombre (variables y/o constantes)

Utiliza el menor número posible de tipos de datos.
Si puedes, utiliza solo números enteros, ya que su notación es la misma en casi todos los lenguajes y resultará conocida para prácticamente todo el mundo.

Si existe un track para un lenguaje similar al tuyo, no dudes en comprobar si puedes hacer un fork de su ejercicio y usarlo como punto de partida.

Procura ser conciso; no quieres sobrecargar a los estudiantes con información.
La introducción debe explicar _lo justo_ para que el estudiante pueda mirar el código e identificar cuáles son las distintas partes.
No necesitan comprenderlo todo en profundidad, pero tampoco deberían quedarse con la duda de qué es cada cosa.

El estudiante solo debería necesitar _usar_ activamente uno o dos conceptos.
