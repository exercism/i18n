# Introducción

## Cadenas de caracteres

En Common Lisp, las cadenas de caracteres son [vectores][concept-vectors] de [caracteres][concept-characters].
Se escriben como caracteres rodeados de comillas dobles (_p. ej._ «Hello World!»).

El predicado `stringp` solo devolverá verdadero si el valor dado es un string.

Los strings se pueden dividir en partes más pequeñas con la función `subseq`, que recibe un string, un índice de inicio y, opcionalmente, un índice de fin.
Los índices comienzan en cero.

```lisp
(subseq "Hello World" 1 5)   ; => "ello"
(subseq "skip to the end" 5) ; => "to the end"
```

Los strings se pueden comparar para comprobar si son iguales con `string=`.
Si hay que ignorar las mayúsculas y minúsculas de los caracteres, se puede usar `string-equal`.

```lisp
(string= "macaroni" "macaroni")      ; => T
(string= "macaroni" "MACARONI")      ; => NIL
(string-equal "macaroni" "MACARONI") ; => T
```

Las operaciones como convertir a mayúsculas, convertir a minúsculas y capitalizar un string se pueden realizar con `string-upcase`, `string-downcase` y `string-capitalize`.

```lisp
(string-upcase "not too loud")                ; => "NOT TOO LOUD"
(string-downcase "YELL IT FROM THE ROOFTOPS") ; => "yell it from the rooftops"
(string-capitalize "practical COMMON LiSP")   ; => "Practical Common Lisp"
```
