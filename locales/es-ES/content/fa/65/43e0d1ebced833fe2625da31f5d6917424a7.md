# Para mantenedores

## Script de ayuda para crear tests de Fortran: create_fortran_test.py

Una forma sencilla de crear el test de un ejercicio es usar el script
`bin/create\_fortran\_test.py`

Usa este script para crear un archivo <exercise>\_test.f90 inicial que puedas usar como plantilla para tu test.
Normalmente, tendrás que sustituir la función «response» del archivo generado por la llamada a la función correcta.

Ten en cuenta también que Fortran tiene problemas con caracteres especiales como `\n` y `\t`, así que presta especial atención al manejarlos.

### Requisitos previos

- Tener CMake y un compilador de Fortran en funcionamiento
- Python3.x (puede que funcione con Python2, pero no me he molestado en
  hacerlo retrocompatible)
- la última versión de https://github.com/exercism/problem-specifications.git
- git

### Flujo de trabajo para crear un nuevo test

- trae los últimos cambios de `exercism/problem-specifications`, por ejemplo, git clone git@github.com:exercism/problem-specifications.git
- crea una nueva rama para el nuevo ejercicio, por ejemplo, git checkout -b exercise-bob
- ejecuta este script para el ejemplo que quieras crear
- copia `config/CMakeLists.txt` al directorio del ejercicio (puedes usar `bin/update-cmake-files` para esto)
- implementa un ejercicio que funcione
- corrige los posibles tests problemáticos (véase, por ejemplo, exercise/bob «Test 20» y «Test 24»)
- asegúrate de que el comando `ctest` se completa sin errores
- copia tu solución a .meta/example.f90 y elimina la implementación real del archivo del ejercicio, por ejemplo, bob.f90
- actualiza los directorios .docs y .meta
  - cp ../problem-specifications/exercises/bob/description.md exercises/practice/bob/.docs/instructions.md
    - sustituye «# Description» por «# Instructions»
  - rellena .meta/tests.toml a mano (hasta que exista una forma automatizada)
  - rellena .meta/config.json a mano (hasta que exista una forma automatizada)
    - usa ../problem-specifications/exercises/bob/metadata.yml
- abre una pull request con tus cambios

Para el ejemplo de bob:

```bash
$ python bin/create_fortran_test.py -j ../problem-specifications/main/exercises/bob/canonical-data.json -t exercises/practice/bob/bob_test.f90
Namespace(json='../problem-specifications/main/exercises/bob/canonical-data.json', target='exercises/practice/bob/bob_test.f90')
Wrote : exercises/practice/bob/bob_test.f90
$ cp config/CMakeLists.txt exercises/practice/bob/.
$ cd exercises/practice/bob
$ touch bob.f90
$ mkdir build
$ cd build
$ cmake ..
$ make
$ ctest -V
```

### Cambiar `CMakeLists.txt`

Cuando cambies el archivo cmake, actualiza la copia maestra en `config/` y usa `bin/update-cmake-files` para copiarla a todos los directorios de ejercicios.

## Solución

Cuando tengas una solución, copia esa solución al directorio «.meta» como «example.f90».

Quizá quieras dejar una implementación esqueleto de la función o la subrutina que ayude al estudiante, y dejar en el directorio del ejercicio el archivo con el nombre del ejercicio.
