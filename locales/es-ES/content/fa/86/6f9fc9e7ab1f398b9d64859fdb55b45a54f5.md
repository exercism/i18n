# Pistas

## General

- Este reto consiste en calcular si un punto cae _sobre, dentro o fuera_ de un círculo dado.
- Hay dos formas distintas de calcular si un punto cae sobre, dentro o fuera de un círculo.
  - Este artículo de _Stack Overflow_: [Ecuación para comprobar si un punto está dentro de un círculo][point-circle-equation] describe un método.
  - Este artículo de _DoubleRoot_: [Posición de un punto respecto a un círculo][point-to-circle] describe otro distinto.
  - Este artículo de _Math is Fun_ cubre un cálculo más general: [Distancia entre 2 puntos][distance-between-two-points].
- Como la diana es un conjunto de círculos _concéntricos_, el orden en el que calculas los puntos podría cambiar significativamente la respuesta.
  Debes prestar atención a la dirección en la que «se mueven» tus cálculos.
- Recuerda que este ejercicio tiene muchas soluciones posibles y muchos caminos que puedes seguir.
  Ningún camino es manifiestamente «mejor» que otro, aunque puede que un camino concreto sea más interesante o encaje mejor con lo que quieres aprender o explorar ahora mismo.
- Algunos caminos pueden cambiar velocidad por claridad.
  Otros pueden consumir más memoria, pero ser más escalables o fáciles de mantener.
- Te animamos a probar más de una estrategia de programación para ver qué ocurre.
