# Anexo de instrucciones

Este es un buen ejercicio para experimentar con literales de string no estándar y con la metaprogramación.

En esta [entrada de blog](https://web.archive.org/web/20170625222109/https://iaindunning.com/blog/julia-unicode.html) puedes encontrar una breve introducción a los literales de string no estándar. En el [manual](https://docs.julialang.org/en/v1/manual/metaprogramming/) hay una guía detallada de metaprogramación.

Puedes ampliar tu solución añadiendo la funcionalidad que se describe a continuación.

El extra A solo requiere los conceptos básicos descritos en la entrada de blog. El extra B requiere un conocimiento de la metaprogramación en Julia bastante mayor.

## Extra A
Implementa un literal de string que aplique `ROT13` al string:
```julia
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```

## Extra B
Implementa los literales de string `R<i>`, `i = 0, ..., 26`, que desplazan el string para los distintos valores de `i`:
```julia
R0"Hello, World!" == "Hello, World!"
R4"Testing 1 2 3 testing" == "Xiwxmrk 1 2 3 xiwxmrk"
R13"abcdefghijklmnopqrstuvwxyz" == "nopqrstuvwxyzabcdefghijklm"
```
