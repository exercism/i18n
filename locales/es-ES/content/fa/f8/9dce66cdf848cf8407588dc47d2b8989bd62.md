# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [Pharo Syntax Cheatsheet](http://files.pharo.org/media/pharoCheatSheet.pdf)
- [Pharo Community Resources](http://pharo.org/community) (incluye el enlace al chat de Discord)
- [/r/pharo](https://www.reddit.com/r/pharo) es el subreddit de Pharo.
- Puedes usar [StackOverflow](http://stackoverflow.com/questions/tagged/pharo) para buscar tu problema y ver si ya se ha respondido antes. También puedes hacer y responder preguntas.
