# Enlaces internos

Los enlaces renderizados por el analizador de Markdown de Exercism se comprueban para ver si son internos y, de ser así, pueden decorarse con tooltips.

Un tooltip para un concepto podría tener este aspecto:

<img src="https://raw.githubusercontent.com/exercism/docs/main/.imgs/concept-tooltip.png" height="200">

## Uso

No hay ninguna sintaxis especial para que los enlaces se decoren de esta forma.
En su lugar, comprobamos si el href del enlace sigue una de estas dos formas:

- Una URL. P. ej., https://exercism.org/tracks/ruby/concepts/basics
- Una ruta absoluta. P. ej., /tracks/ruby/concepts/basics

Actualmente no admitimos URL relativas (p. ej., las que empiezan por `./` o `../`) porque el analizador de Markdown no conoce el contexto del documento que renderiza, el contexto en el que se está renderizando ni la estructura de un repositorio de git.

## Alternativas

En lugar de usar enlaces normales, quizá prefieras renderizar Widgets.
Por lo general, se usan al final de un documento para sugerir lecturas adicionales o buenos ejercicios de los que aprender algo.

Consulta [la documentación de los Widgets](/docs/building/markdown/widgets) para obtener más detalles.
