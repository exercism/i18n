# Acerca de

Java es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación.
Asignar un valor a un nombre se conoce como definir una variable.

```java
int explicitVar = 10; // Explicitly typed
```

El valor de una variable puede asignarse y actualizarse con el [operador `=`][assignment].
Una vez definida, el tipo de una variable nunca puede cambiar.

```java
int count = 1; // Assign initial value
count = 2;     // Update to new value

// Compiler error when assigning different type
// count = false;
```

Java es un lenguaje orientado a objetos y exige que todas las funciones se definan dentro de una _clase_, que se define con la [palabra clave `class`][classes].
Una función dentro de una clase se conoce como _método_.
Cada [método][methods] puede tener cero o más parámetros.
Todos los parámetros deben tener un tipo explícito; no hay inferencia de tipos para los parámetros.
De forma similar, el tipo devuelto también debe indicarse de forma explícita.
Los valores se devuelven desde las funciones con la [palabra clave `return`][return].
Para que otras clases puedan llamar a un método, hay que añadir el modificador de acceso `public`.

```java
class Calculator {
    public int add(int x, int y) {
        return x + y;
    }
}
```

Para invocar un método, se especifica el nombre de su clase y del método y se pasan argumentos para cada uno de los parámetros del método.

```java
int sum = new Calculator().add(1, 2);
```

Si un método no usa ningún _estado_ de la clase (como ocurre en este ejercicio), se puede convertir en _estático_ con el modificador `static`.
De forma similar, si una clase solo tiene métodos estáticos, también puede convertirse en estática con el modificador `static`.

```java
static class Calculator {
    public static int multiply(int x, int y) {
        return x * y;
    }
}
```

El scope en Java se define entre los caracteres `{` y `}`.

Java admite dos tipos de [comentarios][comments].
Los comentarios de una sola línea van precedidos de `//` y los comentarios multilínea se insertan entre `/*` y `*/`.

Los valores enteros se definen como uno o más dígitos (consecutivos) y admiten los [operadores matemáticos por defecto][operators].
