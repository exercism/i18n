# Acerca de

Las variables locales no sustituyen al código de pila: conviven con él. Recurre a ellas cuando:

- Se hace referencia a la misma entrada más de una vez.
- El orden natural de las operaciones no coincide con el orden de la pila.
- Estás dentro de una palabra de orden superior que le pasa a la lambda varios valores a la vez (el `( key value -- newkey newvalue )` de `assoc-map`).

```factor
USING: locals ;

! Two references to ratio: stack-shuffled vs. local.
: average  ( a b -- avg ) + 2 / ;
:: average ( a b -- avg ) a b + 2 / ;        ! same effect
```

`[let code :> name code :> name ... body ]` introduce enlaces locales dentro de una quotation o en el listener, donde `:>` no tendría de otro modo un scope léxico en el que enlazar:

```factor
[let 5 :> x 10 :> y x y + ] .   ! => 15
```

El sufijo de mutación `:>` te permite volver a enlazar una variable local, algo útil en bucles de estilo imperativo:

```factor
:: collatz ( n -- count )
    n :> current!
    0 :> count!
    [ current 1 = ] [
        current odd?
        [ current 3 * 1 + current! ]
        [ current 2 / current! ] if
        count 1 + count!
    ] until
    count ;
```
