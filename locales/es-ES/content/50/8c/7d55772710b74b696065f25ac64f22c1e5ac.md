# Anexo de instrucciones

## Consejos

Para este ejercicio, la siguiente característica de F# resulta útil:

- [Recursión de cola](https://blogs.msdn.microsoft.com/fsharpteam/2011/07/08/tail-calls-in-f/) Evita los desbordamientos de pila con entradas grandes usando la recursión de cola. Aunque no hay casos de prueba que verifiquen esto explícitamente, usar la recursión de cola conduce a una solución más eficiente. Otro buen recurso sobre la recursión de cola es [esta entrada de blog](http://blog.ploeh.dk/2015/12/22/tail-recurse/).
- [Inferencia de tipos](https://docs.microsoft.com/en-us/dotnet/fsharp/language-reference/generics/#implicitly-generic-constructs) El compilador de F# puede inferir tipos automáticamente, lo que significa que a menudo no tienes que añadir ningún tipo en absoluto. Para obtener más información sobre cómo funciona y sus ventajas, consulta [esta página](https://fsharpforfunandprofit.com/posts/type-inference/).
