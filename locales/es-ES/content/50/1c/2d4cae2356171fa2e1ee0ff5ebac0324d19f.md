# Anexo a las instrucciones

## Funciones y pruebas

El código de partida que se te proporciona,
```scheme
(provide hello)

(define (hello)
  "Goodbye, Mars!")
```
define una función llamada `hello` y hace que se pueda ejecutar.
El ejecutor de pruebas toma esta función y la ejecuta, comparando el valor que devuelve con el valor que espera.
Usa esta definición de función de partida como base para tu solución.
