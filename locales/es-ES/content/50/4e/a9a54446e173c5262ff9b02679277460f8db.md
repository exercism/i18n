# Instrucciones

En este ejercicio juegas a un juego de rol llamado «Wizard and Warriors» con tus mejores amigos. Tú eres el Director de Juego, la persona encargada de hacer que el mundo del juego cobre vida para los jugadores. Un aspecto clave de esto es describir el juego a los jugadores: cuál es el estado de un personaje, cómo es el pueblo que están visitando, etc.

Tienes cinco tareas en las que describes partes del juego a los jugadores.

## 1. Describe un personaje

Cada personaje tiene una clase, un nivel y un número de puntos de golpe, y se describe así: `"You're a level <LEVEL> <CLASS> with <HIT_POINTS> hit points."`. Implementa el método (estático) `GameMaster.Describe`, que recibe un `Character` como único parámetro y devuelve su descripción.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

GameMaster.Describe(character);
// => "You're a level 4 Wizard with 28 hit points."
```

## 2. Describe un destino

Cada destino tiene un nombre y un número de habitantes, y se describe así: `"You've arrived at <NAME>, which has <INHABITANTS> inhabitants."`. Implementa el método (estático) `GameMaster.Describe`, que recibe un `Destination` como único parámetro y devuelve su descripción.

```csharp
var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(destination);
// => "You've arrived at Muros, which has 732 inhabitants."
```

## 3. Describe la forma de viaje

Los personajes pueden viajar a un destino de una de estas dos maneras:

- Andando, que se describe así: `"You're traveling to your destination by walking."`
- A caballo, que se describe así: `"You're traveling to your destination on horseback."`

Implementa el método (estático) `GameMaster.Describe`, que recibe un `TravelMethod` como único parámetro y devuelve su descripción.

```csharp
GameMaster.Describe(TravelMethod.Horseback);
// => "You're traveling to your destination on horseback."
```

## 4. Describe a un personaje que viaja a un destino

Cuando un personaje viaja a un destino, esto se describe como una combinación de las descripciones individuales: `"<CHARACTER> <TRAVEL_METHOD> <DESTINATION>"`. Implementa el método (estático) `GameMaster.Describe`, que recibe un `Character`, un `Destination` y un `TravelMethod` como parámetros y devuelve su descripción.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination, TravelMethod.Horseback);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination on horseback. You've arrived at Muros, which has 732 inhabitants."
```

## 5. Describe a un personaje que viaja a un destino sin especificar la forma de viaje

En la mayoría de los casos, los personajes viajan a un destino andando. Por comodidad, los jugadores pueden omitir su forma de viaje, en cuyo caso se dará por sentado que la forma de viaje es andar. Implementa el método (estático) `GameMaster.Describe`, que recibe un `Character` y un `Destination` como parámetros y devuelve su descripción.

```csharp
var character = new Character();
character.Class = "Wizard";
character.Level = 4;
character.HitPoints = 28;

var destination = new Destination();
destination.Name = "Muros";
destination.Inhabitants = 732;

GameMaster.Describe(character, destination);
// => "You're a level 4 Wizard with 28 hit points. You're traveling to your destination by walking. You've arrived at Muros, which has 732 inhabitants."
```
