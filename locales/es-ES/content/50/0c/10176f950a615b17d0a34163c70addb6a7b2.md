# Acerca de

Como otros lenguajes, C++ también proporciona una instrucción `switch`.
Las instrucciones `switch` son una forma más corta de escribir largas instrucciones `if ... else if`.
Para crear una instrucción `switch`, empezamos usando la palabra clave `switch` seguida de un número entero.
Después declaramos cada una de las condiciones con la palabra clave `case`.
También podemos declarar un caso `default`, que se ejecutará cuando no coincida ninguna de las condiciones `case` anteriores.
Cada caso debe terminar con una instrucción `break` (o `return`).

```cpp
int price{0};
int adults{3};
int kids{2};

switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
        break;
    case 2:
        price = 70;
        break;
    default:
        price = group_size * 30;
}
```

## Caída

Una cosa importante de la construcción switch es que el código seguirá ejecutándose hasta que lo detenga una instrucción `break` (o `return`).
Esto puede dar lugar a un comportamiento inesperado.

```cpp
int adults{1};
int kids{0};
switch (int group_size{adults + kids}) {
    case 1:
        price = 50;
    case 2:
        price = 70;
    default:
        price = group_size * 30;
}
// price will be 30!
```

El principal caso de uso de esta funcionalidad de ejecución continuada es una instrucción que tiene varias etiquetas.
Varios resultados del switch pueden corresponder al mismo fragmento de código que se va a ejecutar.
De esta forma, en una aplicación de reservas por ejemplo, la función a la que se llama para los tamaños de grupo 2 y 3 puede ser la misma:
```cpp
switch (group_size) {
case 1:
    book_room();
    break;
case 2:
case 3:
    book_apartment(group_size);
    break;
default:
    book_house(group_size);
}
// book_apartment happens wheng roup_size is 2 or 3
```

~~~~exercism/note
Como has visto, en C++ la instrucción switch es muy limitada si se compara con otros lenguajes.
Muchos lenguajes pueden hacer switch basándose en expresiones Boolean o incluso en expresiones regulares.
Puedes pensar que la versión de C++ es una construcción goto/switch ampliada.
Solo la instrucción switch puede saltar a una etiqueta.
Después, todas las demás etiquetas se ignoran y tienes que usar la instrucción `break` para salir del bloque de código.
~~~~
