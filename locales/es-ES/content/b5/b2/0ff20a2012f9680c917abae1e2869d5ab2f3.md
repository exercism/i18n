# Instrucciones

Implementa operaciones básicas con arrays.

En los lenguajes funcionales, las operaciones con arrays como `length`, `map` y
`reduce` son muy comunes. Implementa una serie de operaciones básicas con arrays,
sin usar funciones existentes.

El número y los nombres exactos de las operaciones que hay que implementar
dependerán del track, para evitar conflictos con nombres existentes, pero las
operaciones generales que implementarás incluyen:

* `append` (*dados dos arrays, añade todos los elementos del segundo array al final del primer array*);
* `concatenate` (*dada una serie de arrays, combina todos los elementos de todos los arrays en un único array aplanado*);
* `filter` (*dado un predicado y un array, devuelve el array de todos los elementos para los que `predicate(item)` es True*);
* `length` (*dado un array, devuelve el número total de elementos que contiene*);
* `map` (*dada una función y un array, devuelve el array con los resultados de aplicar `function(item)` a todos los elementos*);
* `foldl` (*dada una función, un array y un acumulador inicial, pliega (reduce) cada elemento en el acumulador desde la izquierda usando `function(accumulator, item)`*);
* `foldr` (*dada una función, un array y un acumulador inicial, pliega (reduce) cada elemento en el acumulador desde la derecha usando `function(item, accumulator)`*);
* `reverse` (*dado un array, devuelve un array con todos los elementos originales, pero en orden inverso*);
