# Instrucciones

Tu tarea consiste en tomar un array de goleadores de un partido y contar cuántos goles ha marcado cada jugador.

`PlayerName` es un alias de tipo para `String`, para que el código sea más fácil de leer y para distinguir este uso de `String` de otros usos de `String`.

## 1. Agrega los goleadores

Primero implementa `updateGoalCountForPlayer` para inicializar o incrementar el recuento de goles de un jugador.
Después implementa la función `aggregateScorers` para contar cuántos goles ha marcado cada jugador, usando `updateGoalCountForPlayer`.
Esta función toma un `List PlayerName` (los nombres de los jugadores que marcaron los goles, que puede contener nombres de jugador duplicados) y devuelve un `Dict PlayerName Int` que contiene todos los jugadores del array junto con cuántos goles han marcado.

```elm
aggregateScorers [ "Betty", "Cedd", "Betty" ]
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ]
```

## 2. Elimina los jugadores insignificantes

Implementa la función `removeInsignificantPlayers` para descartar a los jugadores que hayan marcado menos goles que el umbral.

```elm
removeInsignificantPlayers 2 (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ) ]
```

## 3. Restablece el recuento de goles de un jugador

Implementa la función `resetPlayerGoalCount` para restablecer a cero los goles marcados por un jugador.

```elm
resetPlayerGoalCount "Cedd" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 0 ) ]
```

## 4. Da formato al recuento de goles de un solo jugador

Implementa la función `formatPlayer` para dar formato al recuento de goles de un solo jugador como un string. Si el jugador no existe en el diccionario, asume que su recuento de goles es cero.

```elm
formatPlayer "Betty" (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2"
```

## 5. Da formato al recuento de goles de todos los jugadores

Implementa la función `formatPlayers` para dar formato al recuento de goles de todos los jugadores como un string. Los jugadores deben estar ordenados por nombre de jugador.

```elm
formatPlayers (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
--> "Betty: 2, Cedd: 1"
```

## 6. Combina los partidos

Implementa la función `combineGames`, contando el número total de goles que ha marcado cada jugador en ambos partidos.

```elm
combine Games
  (Dict.fromList [ ( "Betty", 2 ), ( "Cedd", 1 ) ] )
  (Dict.fromList [ ( "Betty", 2 ), ( "Mario", 3 ) ] )
--> Dict.fromList [ ( "Betty", 4 ), ( "Cedd", 1 ), ( "Mario", 3 ) ]
```
