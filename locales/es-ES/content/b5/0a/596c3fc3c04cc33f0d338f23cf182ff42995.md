# Tests

Para ejecutar los tests, ejecuta el siguiente comando en el directorio del ejercicio:

```shell
make
```

## Tests omitidos

Resolver un ejercicio significa hacer que todos sus tests pasen.
De forma predeterminada, cuando ejecutas los tests solo se ejecuta uno (el primero).
Esto es intencionado, ya que te permite centrarte en hacer que solo ese test pase.
Cuando pase, puedes habilitar el siguiente test eliminando la línea `TEST_IGNORE();`.
Cuando hayas habilitado todos los tests y tu implementación los haga pasar todos, ¡habrás resuelto el ejercicio!
