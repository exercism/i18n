# Introducción

Para permitir que un objeto se compare con otro, debe implementar la interfaz `IComparable<T>`.
Esta interfaz tiene un único método que hay que implementar: `int CompareTo(T other)`.

Hay tres posibles valores devueltos para el método `CompareTo`:

- Un valor menor que cero: el objeto actual es menor que el otro objeto.
- Un valor mayor que cero: el objeto actual es mayor que el otro objeto.
- El valor es cero: el objeto actual es igual al otro objeto.
