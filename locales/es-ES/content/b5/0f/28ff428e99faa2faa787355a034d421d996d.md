# Pistas

## 1. Cambia el nombre de una columna

- Recuerda que tienes que modificar el conjunto de datos `trees`, que está disponible si se llama a `library(datasets)`.
- Puede que quieras (o no) convertir el `data.frame` inicial en un `tibble`.
- Consulta la introducción para saber cómo cambiar el nombre de una columna.

## 2. Añade las columnas girth y weight

- Consulta la introducción para saber cómo añadir columnas.
- Las nuevas columnas se pueden calcular a partir de las columnas que ya existen.
- No olvides redondear a la precisión requerida.

## 3. Copia del conjunto de datos para el huerto

- Tienes que mover columnas y ordenar filas (consulta la introducción).

## 4. Copia del conjunto de datos para el cliente

- Tendrás que seleccionar un subconjunto de columnas.
- En la copia solo deben estar los árboles que tengan una altura entre la mínima y la máxima *y* un peso por debajo del máximo.
