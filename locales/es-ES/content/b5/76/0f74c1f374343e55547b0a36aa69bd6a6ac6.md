# Pistas

## 1. Calcula el valor de cualquier carta

- La función `ParseCard` debe recibir el string `card` (por ejemplo, `ace`) y devolver su valor (por ejemplo, 11).
- Usa una instrucción [`switch`][switch_statement] grande sobre la variable `card`.
- King, Queen, Jack y 10 se pueden manejar con un solo caso.
- La instrucción `switch` puede tener un caso `default`.
  En cualquier caso, la función debe devolver `0` para cartas desconocidas.

## 2. Implementa la lógica de decisión para el primer turno

- Usa la función `ParseCard` para determinar el valor de cada carta.
- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador
- Puedes usar una instrucción [`switch`][switch_statement] grande sobre la puntuación del jugador (quizá con condicionales `if` anidados sobre la puntuación del crupier en algunos casos).
- Como alternativa, podrías distinguir distintas categorías de puntuación del jugador (por ejemplo, «manos pequeñas» con una puntuación menor que 12, «manos medianas» con una puntuación en el rango 12..20 y «manos grandes» con una puntuación mayor que 20) y escribir funciones separadas para todas (o algunas) de estas categorías.

[switch_statement]: https://golang.org/ref/spec#Switch_statements
