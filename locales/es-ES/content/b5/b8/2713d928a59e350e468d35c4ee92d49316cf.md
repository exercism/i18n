# Instrucciones

Toma un array anidado de cualquier profundidad y devuelve un array totalmente aplanado.

Ten en cuenta que algunas rutas de lenguajes pueden incluir valores similares a null en el array de entrada, y la forma en que se representan estos valores varía según la ruta.
Estos valores deben excluirse del array aplanado.

Además, la entrada puede ser de un tipo de dato distinto y contener tipos diferentes, según la ruta.

Consulta el conjunto de pruebas para ver los detalles.

## Ejemplo

entrada: `[1, [2, 6, null], [[null, [4]], 5]]`

salida: `[1, 2, 6, 4, 5]`
