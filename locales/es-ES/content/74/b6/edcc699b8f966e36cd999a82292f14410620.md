# Instrucciones

Eres un entusiasta observador de pájaros que lleva la cuenta de cuántos pájaros han visitado tu jardín.
Normalmente usas una tabla de recuento en un cuaderno para contar los pájaros, pero para trabajar mejor con tus datos, has digitalizado los recuentos de pájaros de las últimas semanas.

## 1. Determina el número total de pájaros que has contado hasta ahora

Empecemos analizando los datos para obtener una visión general.
Averigua cuántos pájaros has contado en total desde que empezaste tus registros.

Implementa una función `TotalBirdCount` que acepta un slice de `int` que contiene el recuento de pájaros por día.
Debería devolver el número total de pájaros que has contado.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
TotalBirdCount(birdsPerDay)
// => 34
```

## 2. Calcula el número de pájaros visitantes en una semana concreta

Ahora que tienes una idea general de tus cifras de recuento de pájaros, quieres hacer un análisis más detallado.

Implementa una función `BirdsInWeek` que acepta un slice de recuentos de pájaros por día y un número de semana.

Devuelve el número total de pájaros que contaste en esa semana concreta.
Puedes suponer que las semanas siempre se registran completas.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1}
BirdsInWeek(birdsPerDay, 2)
// => 12
```

## 3. Corrige un error de recuento

Te diste cuenta de que, durante todo el tiempo que estuviste intentando llevar la cuenta de los pájaros, había un pájaro que se escondía en un rincón lejano del jardín.

Descubriste que este pájaro siempre pasaba un día sí y otro no en tu jardín.

No sabes exactamente dónde estaba entre esos días, pero desde luego no en tu jardín.

Tu intuición de observador de pájaros también te dice que el pájaro estaba en tu jardín el primer día que registraste en tu lista.

Con esta nueva información, escribe una función `FixBirdCountLog` que recibe un slice de pájaros contados por día como argumento y devuelve el slice después de corregir el error de recuento.

```go
birdsPerDay := []int{2, 5, 0, 7, 4, 1}
FixBirdCountLog(birdsPerDay)
// => [3 5 1 7 5 1]
```
