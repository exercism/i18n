# Introducción

Trabajar con texto es una tarea habitual en programación.
Swift, junto con el framework Foundation, ofrece muchos métodos y propiedades prácticos para inspeccionar, transformar y manipular strings.

## Dividir strings con `components(separatedBy:)`

Para dividir un string en un array de subcadenas a partir de un delimitador, usa `components(separatedBy:)` (requiere importar Foundation):

```swift
import Foundation

let sentence = "Hello, world!"
let words = sentence.components(separatedBy: " ")
print(words) // Prints ["Hello,", "world!"]
```

## Comprobar prefijos y sufijos con `hasPrefix(_:)` y `hasSuffix(_:)`

Para comprobar si un string empieza o termina con una secuencia de caracteres concreta, usa `hasPrefix(_:)` y `hasSuffix(_:)`:

```swift
let greeting = "Hello, world!"
print(greeting.hasPrefix("Hello"))  // Prints true
print(greeting.hasSuffix("world!")) // Prints true
```

## Cambiar mayúsculas y minúsculas

Puedes transformar las mayúsculas y minúsculas de un string con estos métodos y propiedades estándar:

- `lowercased()`: devuelve una copia del string en minúsculas.
- `uppercased()`: devuelve una copia del string en mayúsculas.
- `capitalized`: devuelve una copia en la que la primera letra de cada palabra va en mayúscula (de Foundation).

```swift
let greeting = "hello, world!"
print(greeting.lowercased())  // Prints "hello, world!"
print(greeting.uppercased())  // Prints "HELLO, WORLD!"
print(greeting.capitalized)   // Prints "Hello, World!"
```

## Reemplazar subcadenas con `replacingOccurrences(of:with:)`

Para reemplazar todas las apariciones de una subcadena concreta por otro string, usa `replacingOccurrences(of:with:)` (de Foundation):

```swift
let greeting = "Hello, world!"
let updated = greeting.replacingOccurrences(of: "world", with: "Swift")
print(updated) // Prints "Hello, Swift!"
```

## Unir strings con `joined(separator:)`

El método `joined(separator:)` pertenece a las colecciones de strings, como `[String]`.
Une los elementos en un único string usando un separador:

```swift
let words = ["Hello", "world"]
let sentence = words.joined(separator: ", ")
print(sentence) // Prints "Hello, world"
```
