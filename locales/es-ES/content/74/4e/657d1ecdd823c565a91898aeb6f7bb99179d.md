# Instrucciones

En este ejercicio tienes que traducir algunas reglas del clásico juego Pac-Man a funciones de C++.

Tienes cuatro reglas que traducir, todas relacionadas con los estados del juego.

> No te preocupes por cómo se obtienen los argumentos; céntrate en combinarlos para devolver el resultado esperado.

## 1. Define si Pac-Man se come un fantasma

Define la función `can_eat_ghost`, que recibe dos argumentos (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor booleano que indica si Pac-Man puede comerse al fantasma. La función debe devolver true solo si Pac-Man tiene activa una píldora de poder y está tocando un fantasma.

```cpp
can_eat_ghost(false, true);
// => false
```

## 2. Define si Pac-Man puntúa

Define la función `scored`, que recibe dos argumentos (_si Pac-Man está tocando una píldora de poder_ y _si Pac-Man está tocando una bolita_) y devuelve un valor booleano que indica si Pac-Man ha puntuado. La función debe devolver true si Pac-Man está tocando una píldora de poder o una bolita.

```cpp
scored(true, true);
// => true
```

## 3. Define si Pac-Man pierde

Define la función `lost`, que recibe dos argumentos (_si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor booleano que indica si Pac-Man pierde. La función debe devolver true si Pac-Man está tocando un fantasma y no tiene activa una píldora de poder.

```cpp
lost(false, true);
// => true
```

## 4. Define si Pac-Man gana

Define la función `won`, que recibe tres argumentos (_si Pac-Man se ha comido todas las bolitas_, _si Pac-Man tiene activa una píldora de poder_ y _si Pac-Man está tocando un fantasma_) y devuelve un valor booleano que indica si Pac-Man gana. La función debe devolver true si Pac-Man se ha comido todas las bolitas y no ha perdido según los argumentos definidos en la parte 3.

```cpp
won(false, true, false);
// => false
```
