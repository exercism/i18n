# Acerca de

Las estructuras de datos que pueden contener cero o más elementos se conocen como _colecciones_. Un **array** es una colección que tiene un tamaño/longitud fijo y cuyos elementos deben ser todos del mismo tipo. Los elementos se pueden asignar a un array o recuperar de él mediante un índice. Los arrays de C# están basados en cero, lo que significa que el índice del primer elemento es siempre cero:

```csharp
// Declare array with explicit size (size is 2)
int[] twoInts = new int[2];

// Assign second element by index
twoInts[1] = 8;

// Retrieve the second element by index
twoInts[1] == 8; // => true

// Check the length of the array
twoInts.Length == 2; // => true
```

Los arrays también se pueden definir con una notación abreviada que te permite tanto crear el array como establecer su valor. Como ahora el compilador puede saber cuántos elementos tendrá el array, se puede omitir la longitud:

```csharp
// Three equivalent ways to declare and initialize an array (size is 3)
int[] threeIntsV1 = new int[] { 4, 9, 7 };
int[] threeIntsV2 = new[] { 4, 9, 7 };
int[] threeIntsV3 = { 4, 9, 7 };
```

Los arrays se pueden manipular llamando a los [métodos][array-methods] o las [propiedades][array-properties] de una instancia de array, o usando los métodos estáticos definidos en la [clase `Array`][array-class].

## Iteración

Un array también es una _colección_, lo que significa que puedes iterar sobre _todos_ sus valores con un [bucle `foreach`][foreach-statement]:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // Output the vowel
    System.Console.Write(vowel);
}

// => aeiou
```

Se podría usar un [bucle `for`][for-statement] para iterar sobre un array:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

for (int i = 0; i < vowels.Length; i++)
{
    // Output the vowel
    System.Console.Write(vowels[i]);
}

// => aeiou
```

Sin embargo, en general un bucle `foreach` es preferible a un bucle `for` por las siguientes razones:

- Un bucle `foreach` garantiza que se itera sobre _todos_ los valores. Con un bucle `for` es fácil saltarse elementos, por ejemplo por un error de desfase de uno.
- Un bucle `foreach` es más _declarativo_: tu código comunica _qué_ quieres que haga, en lugar de un bucle `for` que comunica _cómo_ quieres hacerlo.
- Un bucle `foreach` es infalible, mientras que con los bucles `for` es fácil cometer un error de desfase de uno.
- Un bucle `foreach` funciona con todos los tipos de colección, incluidos aquellos que no admiten el uso de un indizador para acceder a los elementos.

Para garantizar que un bucle `foreach` itere sobre _todos_ los valores, el compilador no permite modificar una colección dentro de un bucle `foreach`:

```csharp
char[] vowels = new [] { 'a', 'e', 'i', 'o', 'u' };

foreach (char vowel in vowels)
{
    // This would result in a compiler error
    // vowel = 'Y';
}
```

Un bucle `for` sí tiene algunas ventajas sobre un bucle `foreach`:

- Puedes empezar o parar en el índice que quieras.
- Puedes usar cualquier condición de terminación (Boolean) que quieras.
- Puedes saltarte elementos personalizando el incremento de la variable del bucle.
- Puedes recorrer las colecciones del final al principio contando hacia atrás.
- Puedes usar bucles `for` en escenarios que no impliquen colecciones.

Temas relacionados:

- Debes saber que C# admite [arrays multidimensionales][multi-dimensional-arrays] como `int[,] arr = new int[10, 5]`, que pueden ser muy útiles.
- También debes saber que puedes instanciar objetos de tipo [`System.Array`][system-array-object] con `Array.CreateInstance`. Estos objetos tienen poca utilidad, principalmente para la interoperabilidad con código VB.NET. No son intercambiables con los arrays estándar (`T[]`). Pueden tener un límite inferior distinto de cero.
