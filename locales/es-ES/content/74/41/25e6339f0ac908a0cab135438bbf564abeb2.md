# Instrucciones

En este ejercicio, vas a aplicar las [reglas del juego de Go](https://matmoore.github.io/learngo/). Las reglas ya están escritas, tú solo tienes que aplicarlas para actualizar el `Game` y gestionar los posibles errores o violaciones de las reglas.

El juego se representa así:

```elm
type Player
    = Black
    | White


type alias Game =
    { whiteCapturedStones : Int
    , blackCapturedStones : Int
    , player : Player
    , error : String
    }
```

El juego tiene 4 reglas:

- Cada punto solo puede tener una piedra (`oneStonePerPointRule`)
- ¡Las piedras del oponente se pueden capturar! (`captureRule`)
- No puedes colocar una piedra donde se capturaría a sí misma (`libertyRule`)
- No puedes usar el mismo punto dos veces (`koRule`)

## 1. Aplica las reglas

Escribe el contenido de la función `applyRules`, que recibe un `Game` inicial y un conjunto de reglas, y devuelve el nuevo `Game` una vez aplicadas las reglas.

`oneStonePerPointRule`, `libertyRule` y `koRule` comprueban si se han violado las reglas y pueden devolver un error, por lo que su tipo de retorno es `Result String Game`. Si alguna de estas reglas falla, hay que devolver el juego original, pero con el campo `error` actualizado con el error correspondiente.

`captureRule` no comprueba si se han violado las reglas, por lo que no puede fallar (aunque sí puede devolver un `Game` modificado), así que su tipo de retorno es `Game`.

Si todas las reglas pasan, deben conservarse los cambios que hayan hecho en el `Game` y hay que cambiar el jugador. La función `changePlayer` se proporciona para hacer esto.

```elm
applyRules : Game -> Rule -> NonValidatingRule -> Rule -> Rule -> Game
applyRules game oneStonePerPointRule captureRule libertyRule koRule =
--> If all rules pass, return a `Game` with all changes from the rules applied, and changePlayer
--> If any rule fails, return the original Game, but with the error field set
```
