# Anexo de instrucciones

## Registros

| Registro | Uso          | Tipo    | Descripción                                    |
| -------- | ------------ | ------- | ---------------------------------------------- |
| `$a0`    | entrada      | dirección | array de palabras con capacidades de cubos    |
| `$a1`    | entrada      | entero  | cubo inicial (1 o 2)                           |
| `$a2`    | entrada      | entero  | volumen objetivo                               |
| `$a3`    | entrada/salida | dirección | array de palabras con el contenido final de los cubos |
| `$v0`    | salida       | entero  | número de acciones requeridas, -1 si no es posible |
| `$t0-9`  | temporal     | cualquiera | usado para almacenamiento temporal           |
