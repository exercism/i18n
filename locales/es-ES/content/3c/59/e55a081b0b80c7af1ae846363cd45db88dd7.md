# Pistas

## General

## 1. Estima el valor tras el cambio

- Puedes usar el [operador de división][division-operator] para obtener el valor de las divisas cambiadas.

## 2. Calcula las divisas que quedan tras un cambio

- Puedes usar el [operador de resta][subtraction-operator] para obtener la cantidad de cambio.

## 3. Calcula el valor de los billetes

- Puedes usar el [operador de multiplicación][multiplication-operator] para obtener el valor de los billetes.

## 4. Calcula el número de billetes

- Tienes que dividir `amount` entre `denomination`.
- Para eliminar los decimales de un número de coma flotante, puedes usar la función [`floor()`][floor].
- Necesitas un número entero para obtener el número exacto de billetes.
 La función `floor` puede recibir como parámetro el tipo de salida deseado.

  **Nota:** El [operador `÷`][div], o la función `div()`, también hace división entera. No obstante, si un operando es de coma flotante, el resultado sigue siendo de coma flotante.

## 5. Calcula lo que sobra tras cambiar a billetes

- Tienes que encontrar el residuo de `amount` que no equivale a una `denomination` entera.
- El [operador módulo][div] `%` puede ayudarte a encontrar el residuo.

## 6. Calcula el valor tras el cambio

- Tienes que calcular el porcentaje `spread` de `exchange_rate` usando el operador de multiplicación y sumarlo a `exchange_rate` para obtener el tipo de cambio total (consulta el ejemplo en las instrucciones).
- Una vez que tengas el tipo de cambio total a partir de `exchange_rate`, tienes que calcular el valor total de un cambio.
- Con el tipo de cambio total, el cambio se puede hacer en tres pasos en la aplicación:
    - Puedes calcular el cambio desde cero, o...
    - Puedes usar tres de tus funciones de las tareas anteriores.
- Presta atención al orden en que se procesan las funciones, 
    - Empieza con una función que use un tipo de cambio.
    - La salida de una función debería indicarte cuál se necesita a continuación.
