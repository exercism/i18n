# Pistas

## General

- Puedes usar la sintaxis `0b00` para especificar un int en sintaxis binaria en lugar de
  en sintaxis decimal.

## 1. Codifica el ácido nucleico como valor binario

- Puedes aplicar coincidencia de patrones al tipo de nucleótido con una expresión case.

## 2. Decodifica el valor binario al ácido nucleico

- La sintaxis binaria de int se puede usar en patrones.
- Devuelve `Error(Nil)` si el int no es un nucleótido válido.

## 3. Codifica un array de ADN

- Puedes usar la función `encode_nucleotide` para codificar un único nucleótido.

## 4. Decodifica un array de bits de ADN

- La sintaxis binaria de int se puede usar dentro de un patrón de array de bits.
- Devuelve `Error(Nil)` si el array de bits restante no es lo bastante largo para
  contener un nucleótido.
