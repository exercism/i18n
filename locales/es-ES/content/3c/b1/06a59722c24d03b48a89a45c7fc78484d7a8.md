# Introducción

La expresión `let` se usa para crear un scope local y resulta útil en varias situaciones:

- Para simplificar expresiones
- Para dar nombre a los resultados de expresiones intermedias
- Para dividir una expresión en partes más pequeñas si se está volviendo demasiado grande

Puedes hacer casi de todo dentro de una expresión `let`, incluida la desestructuración (encontrarás más detalles sobre esto en ejercicios posteriores), pero no es posible definir un nuevo Custom Type ni un Type Alias.

```elm
let
  cube x = x * x * x
in
  cube a + cube b + cube c
```

```elm
beginWithPattern : Size -> Padding -> Pattern -> GameOfLife
beginWithPattern minimumSize padding pattern =
    let
        size = calculateSize minimumSize padding pattern

        center = Size.center size

        centeredPattern = Pattern.centerAt center pattern

        dimensions = { width = size, height = size }

        deadCells = Matrix.create dimensions Dead
    in
    GameOfLife (bringPatternToLife deadCells centeredPattern)
```
