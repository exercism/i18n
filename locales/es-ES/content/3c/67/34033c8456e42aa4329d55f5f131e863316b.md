# Acerca de

Un búfer de strings es una forma eficiente de construir un string grande añadiendo pequeños elementos unos a otros. A diferencia de String, una instancia de StringBuf no es inmutable, en el sentido de que se puede pasar como argumento a funciones que la modifican añadiéndole más valores.

```haxe
var a = new StringBuf();
a.add("Hello");
trace(a.toString()); // Hello
a.add("Haxe!");
trace(a.toString()); // HelloHaxe
```
