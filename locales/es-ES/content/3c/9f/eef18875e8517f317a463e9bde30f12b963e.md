# Introducción

Un hashmap es una colección que se utiliza para almacenar pares clave-valor. Permite usar tipos arbitrarios como claves y como valores. Los hashmap tienen funciones de inserción y recuperación rápidas y son muy útiles, por ejemplo, para hacer recuentos de frecuencia, almacenar relaciones, etc. Los hashmap también incorporan la potente API `entry`, que hace que trabajar con ellos sea muy cómodo.
