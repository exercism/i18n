# Pistas

## General

- Lee sobre los procesos en la [guía oficial de introducción][getting-started-processes].
- Lee [esta entrada de blog][mullen-processes] sobre los procesos de Elixir.

## 1. Arranca la máquina

- La máquina debe ejecutarse en un proceso nuevo. Hay [una función integrada que inicia un proceso nuevo][kernel-spawn-1].
- Usa una función anónima de aridad 0 al iniciar un proceso nuevo. Esta función todavía no necesita hacer nada.

## 2. Informa del estado de la máquina

- Necesitarás una nueva función con nombre. Puedes llamarla, por ejemplo, `loop`.
- Esta nueva función debe aceptar un argumento, el estado.
- La función anónima de aridad 0 del paso anterior puede llamar a la nueva función con nombre, pasándole el estado inicial.
- La nueva función con nombre necesita responder a mensajes.
- Hay [una función integrada que espera a que llegue un mensaje al buzón del proceso][kernel-receive].
- Hay [una función integrada que envía un mensaje a otro proceso][kernel-send].
- Usa la recursión para esperar más de un mensaje.

## 3. Reparte números

- Este paso es conceptualmente igual que el paso anterior. La única diferencia es la necesidad de actualizar el estado de la máquina.

## 4. Detén la máquina

- Este paso no requiere enviar ningún mensaje como respuesta.
- Un proceso termina si no le queda más código por ejecutar.
- Cuando necesites crear un bloque de código «vacío» en Elixir, puedes usar `nil` como única expresión de ese bloque de código.
- Este es un caso base de la función recursiva.

## 5. Ignora los mensajes inesperados

- Este paso no requiere enviar ningún mensaje como respuesta.
- Puedes usar `_` para hacer coincidir todos los mensajes que no coincidieron con los patrones anteriores.
