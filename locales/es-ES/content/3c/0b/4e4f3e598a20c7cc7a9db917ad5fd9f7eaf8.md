# Introducción

Los objetos pueden guardar su propio estado definiendo _variables de instancia_, que se crean anteponiendo `@` a un nombre de variable.

```ruby
@name = 2
```

Los objetos suelen establecer su estado inicial en un método `initialize`, que se llama automáticamente al llamar a `new` en una clase.

```ruby
class Airplane
  def initialize
    @wings = 2
  end
end
```

El método `initialize` también puede recibir argumentos, de modo que cada instancia pueda empezar con un estado personalizado:

```ruby
class Suitcase
  def initialize(locked)
    @locked = locked
  end
end
```

Considera que las variables de _instancia_ son privadas frente a lecturas y escrituras externas. Deberían usarse métodos de _instancia_ para obtener y establecer las variables de instancia:

```ruby
class Suitcase
  #...

  def locked? # Query methods should be named with a trailing `?`
    @locked
  end

  def unlock! # Methods which mutate state should have trailing `!`
    @locked = false
  end
end
```
