# Pistas

## 1. Calcular el valor de cualquier carta

- Un `switch` al estilo antiguo funciona bien aquí, ya que solo necesita manejar una única carta en cada llamada.
- Usar `case_match` es otra opción, pero las comillas alrededor de los strings no se pueden omitir en este caso.

## 2. Implementar la lógica de decisión para el primer turno

- `case_when` es útil en esta tarea.
- La tarea se puede resolver en R base usando una serie de condicionales, pero de forma menos elegante.
