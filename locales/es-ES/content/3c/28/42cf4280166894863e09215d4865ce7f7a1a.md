# Alto secreto

## Historia

Te enfrentas al espionaje corporativo con la ayuda de una informante secreta que codifica mensajes secretos mediante su código.

## Tareas

El estudiante implementa una función para descifrar mensajes a partir de código fuente siguiendo estos pasos:

- Convertir el código fuente en un AST
- Analizar un único nodo: si el nodo es una definición de función, devolver el nombre de la función
- Ampliar el análisis: devolver solo un número de caracteres igual al número de argumentos que recibe la función
- Descifrar el mensaje: recorrer todos los nodos y concatenar los strings devueltos
