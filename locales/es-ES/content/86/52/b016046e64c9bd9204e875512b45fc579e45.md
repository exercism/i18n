# Instrucciones

El salón de belleza de Nueva York en el que ayudaste en el ejercicio Booking Up For Beauty va viento en popa, y muchos de sus clientes se han vuelto habituales.
En lugar de reservar cada visita por separado, un cliente habitual tiene una cita fija: «cada segundo martes», «el último viernes del mes», etcétera.
La dueña te ha pedido un ayudante que calcule las fechas que hay detrás de esas citas, además de las fechas de la rutina mensual del propio salón.

## 1. Encuentra la cita fija de un cliente habitual

Implementa el método `SalonCalendar.standingAppointment()`, que recibe un año, un mes, una ocurrencia (`1` para la primera, `2` para la segunda, etcétera) y un día de la semana.
Devuelve la fecha de esa ocurrencia del día de la semana dentro del mes:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.standingAppointment(2024, Month.AUGUST, 2, DayOfWeek.TUESDAY);
// => LocalDate.of(2024, 8, 13)
```

## 2. Encuentra la última cita del mes de un cliente habitual

Algunos clientes habituales prefieren la última ocurrencia de su día dentro del mes.
Implementa el método `SalonCalendar.lastAppointment()`, que recibe un año, un mes y un día de la semana, y devuelve la fecha de la última ocurrencia de ese día de la semana dentro del mes:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.lastAppointment(2024, Month.AUGUST, DayOfWeek.FRIDAY);
// => LocalDate.of(2024, 8, 30)
```

## 3. Encuentra el siguiente día disponible para un cliente sin cita

Un cliente en el mostrador de recepción pide «el próximo sábado».
Si el día en que lo pide ya es sábado, se refiere a ese mismo día.
Implementa el método `SalonCalendar.nextAvailable()`, que recibe una fecha y un día de la semana, y devuelve la primera fecha, a partir de la fecha dada, que caiga en ese día de la semana:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.nextAvailable(LocalDate.of(2024, 8, 15), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
calendar.nextAvailable(LocalDate.of(2024, 8, 17), DayOfWeek.SATURDAY);
// => LocalDate.of(2024, 8, 17)
```

## 4. Encuentra el día de cierre de cuentas

El salón cierra sus cuentas el último día de cada mes.
Sin embargo, el salón está cerrado los fines de semana, así que cuando el último día del mes cae en sábado o en domingo, las cuentas se cierran el viernes anterior.
Implementa el método `SalonCalendar.bookkeepingDay()`, que recibe un año y un mes, y devuelve el día de cierre de cuentas de ese mes:

```java
SalonCalendar calendar = new SalonCalendar();
calendar.bookkeepingDay(2024, Month.SEPTEMBER);
// => LocalDate.of(2024, 9, 30)
calendar.bookkeepingDay(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 30)
```

## 5. Reutiliza la regla del fin de semana para el día de pago

El personal cobra el día 15 de cada mes, con la misma regla del fin de semana: cuando el día 15 cae en sábado o en domingo, el día de pago es el viernes anterior.
En lugar de escribir la regla por segunda vez, conviértela en un ajustador reutilizable.

Implementa el método `SalonCalendar.precedingWorkday()`, que devuelve un `TemporalAdjuster` que deja sin cambios un día laborable y mueve un sábado o un domingo al viernes anterior.
Después implementa el método `SalonCalendar.payday()`, que recibe un año y un mes, usando ese ajustador:

```java
SalonCalendar calendar = new SalonCalendar();
LocalDate.of(2024, 6, 15).with(calendar.precedingWorkday());
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.JUNE);
// => LocalDate.of(2024, 6, 14)
calendar.payday(2024, Month.AUGUST);
// => LocalDate.of(2024, 8, 15)
```

No dudes en volver atrás y usar el ajustador también en `bookkeepingDay()`.
