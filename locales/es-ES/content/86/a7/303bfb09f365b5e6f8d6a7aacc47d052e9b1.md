# Pruebas

Para ejecutar las pruebas, ensambla y ejecuta el fichero del ejecutor de pruebas de un ejercicio dado, ya sea mediante la interfaz gráfica del simulador MARS o desde la línea de comandos. Para ejecutarlo desde la línea de comandos, especifica primero el fichero del ejecutor y después tu implementación, así:

    java -jar /path/to/mars.jar nc runner.mips impl.mips

Para ejecutarlo en la interfaz gráfica, añade tu implementación con `include` al final de «runner.mips», descomentando la última línea.

El ejecutor de pruebas terminará con un mensaje de «success» o se detendrá en la prueba que falle con un mensaje que especifique la entrada con la que falló esa prueba.
