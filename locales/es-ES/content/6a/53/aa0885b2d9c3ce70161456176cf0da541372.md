## General

- Strings: en concreto, el `str` siempre es un factor aquí
- Unicode: concesiones de rendimiento y funcionalidad de los métodos ASCII frente a los métodos Unicode. La comparación de rendimiento se sesga cuando el benchmark usa métodos Unicode y la solución usa métodos ASCII.
- Iteradores: iterar sobre la entrada o sobre fragmentos de ella.
- Colecciones: iterar sobre un `HashMap` y usar `Entry`. Es habitual recoger los handles en un `Vec`.
- Referencias
- Números: el trait `Add` en concreto
- Bucle `for`: no se pueden unir hilos en un iterador debido a move.
- **Opt** Visibilidad: mantener los detalles de implementación como no públicos
- **Opt** slices: `.chunks()` es un método muy usado para dividir la entrada entre hilos trabajadores. Como alternativa, se usan subslices.
- **Opt** Funciones de orden superior: los HashMaps se pueden fusionar con una función de orden superior junto con un iterador.
- **Opt** Tipos: para dividir la entrada podemos convertir números enteros en valores de coma flotante y aplicar un redondeo.
- **Opt** Crates

## Enfoque con std, con o sin canales

- Paralelismo: subtema de creación y unión de hilos.
- Iteradores: subtema de evaluación perezosa. Crear y unir hilos con el mismo iterador impide el paralelismo.
- Tiempos de vida: subtemas `'static lifetime` y la semántica explícita de `move`.
- Iteradores/tiempos de vida: subtema de iteradores consumidores. No se pueden unir hilos usando el iterador.
- Tipo Option: desenvolver los resultados de hilos o canales.
- Funciones: en concreto, se necesitan funciones de orden superior para crear hilos. Los closures son una opción aquí.

## Enfoque con std y canales

- Paralelismo: subtema de los canales.
- Tuplas: `mpsc::channel()` devuelve una tupla
- Desestructuración: la tupla se puede desestructurar en la asignación
- Tiempos de vida: `drop()`

## Enfoque alternativo con variables compartidas

- Recuento de referencias: compartir datos agregados entre hilos con una colección con recuento de referencias.
- **Mención de honor**: paralelismo, subtema de los mutex. No es necesario ni útil para este ejercicio, pero es un concepto habitual de todos modos. Relacionado: `RwLock`.

### Ejemplo de std con canales

```rust
use std::collections::HashMap;
use std::thread;
use std::sync::mpsc;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let (tx, rx) = mpsc::channel();

    let _handles = input.chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let tx = tx.clone();
            thread::spawn(move || {
                let mut map: HashMap<char, usize> = HashMap::new();
                for chr in slice.chars().filter(|c| c.is_alphabetic()) {
                    if let Some(c) = chr.to_lowercase().next() {
                        (*map.entry(c).or_insert(0)) += 1;
                    };
                }
                tx.send(map).unwrap()
            })
        }).collect::<Vec<_>>();

    drop(tx);

    let mut result: HashMap<char, usize> = HashMap::new();
    for received in rx {
        for (c, count) in received {
            *result.entry(c).or_insert(0) += count;
        }
    }

    result
}
```

### Ejemplo de crate con Arc

```rust
use std::collections::HashMap;
use std::iter::FromIterator;
use std::sync::Arc;
use dashmap::DashMap;

pub fn frequency(input: &[&str], worker_count: usize) -> HashMap<char, usize> {
    let map: Arc<DashMap<char, usize>> = Arc::new(DashMap::new());

    let handles = input
        .chunks((input.len() as f64 / worker_count as f64).ceil() as usize)
        .map(|slice| slice.concat())
        .map(|slice| {
            let map = map.clone();
            std::thread::spawn(move || {
                for c in slice.chars().filter(|c|c.is_alphabetic())
                  .flat_map(|c| c.to_lowercase().next()) {
                    *map.entry(c).or_insert(0) += 1;
                }
            })
        }).collect::<Vec<_>>();

    for h in handles {
        h.join().unwrap();
    }

    map.iter().map(|x| (*x.key(), *x.value())).collect()
}
```
