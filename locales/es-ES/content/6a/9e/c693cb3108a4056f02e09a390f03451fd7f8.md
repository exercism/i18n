# Crear un Test Runner

Antes de nada, ¡gracias por tu interés en crear un Test Runner!

Estos son los pasos para ponerte en marcha:

1. Consulta [nuestra lista de repositorios para ver si ya existe un `...-test-runner`](https://github.com/search?q=org%3Aexercism+test-runner&type=repositories) para asegurarte de que no haya ya uno.
2. Echa un vistazo al [contenido de este directorio](/docs/building/tooling/test-runners) para asegurarte de que te sientes cómodo con la idea de crear un Test Runner.
3. Abre un tema nuevo en [el foro de Exercism][building-exercism] y cuéntanos para qué lenguaje te gustaría crear un Test Runner.
4. Cuando se haya creado un repositorio de Test Runner para ti, usa los documentos [la interfaz del Test Runner](/docs/building/tooling/test-runners/interface) y [Buenas prácticas](/docs/building/tooling/best-practices) como guía para tu implementación.

Tenemos una comunidad increíblemente amable y solidaria que estará encantada de ayudarte mientras avanzas con todo esto.
Si te atascas, abre un tema nuevo en [el foro de Exercism][building-exercism] o crea nuevas issues en [exercism/exercism][exercism-repo] según lo necesites 🙂

[building-exercism]: https://forum.exercism.org/c/exercism/building-exercism/125
