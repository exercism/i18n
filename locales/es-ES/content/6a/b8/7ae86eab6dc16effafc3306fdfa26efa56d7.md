# Pistas

## General

- En Swift hay tres tipos principales de condicionales: los condicionales `if`, `switch` y `guard`.

## 1. Calcula si puedes permitirte o no los pagos mensuales de un coche concreto

- Asegúrate de dividir el precio total del coche entre el número de meses para calcular el pago mensual.
- Puedes usar `+` para concatenar dos strings.

## 2. Determina qué tipo de permiso de conducir necesitarás

- Los condicionales `switch` son útiles para gestionar un gran número de casos de forma limpia.
- Puedes gestionar varios casos con un solo caso de switch si el comportamiento debe ser el mismo para todos ellos.
- El caso `default` se encarga de todos los casos que no se enumeran explícitamente.

## 3. Calcula las tasas de matriculación de tu vehículo nuevo

- El condicional `guard` se usa en situaciones en las que es conveniente salir antes porque no se necesita (o no es posible) seguir procesando.
- Solo necesitas hacer el cálculo con la fórmula si el vehículo tiene menos de 10 años.
