# Introducción

En JavaScript, los _template strings_ permiten incrustar expresiones en strings, algo que también se conoce como interpolación de strings.
Esta funcionalidad amplía la funcionalidad del objeto global `String` incorporado.

Puedes crear template strings en JavaScript envolviendo el texto en comillas invertidas.
No solo permiten que el texto incluya nuevas líneas y otros caracteres especiales, sino que también puedes incrustar variables y otras expresiones.

```javascript
const num1 = 1;
const num2 = 2;

`Adding ${num1} and ${num2} gives ${num1 + num2}.`;
// => Adding 1 and 2 gives 3.
```

En el ejemplo anterior, las comillas invertidas (<code>\`\`</code>) se usan para representar un template string. El `${...}` es el marcador de posición que se usa para la sustitución.
Cualquier tipo que no sea un string se convierte _implícitamente_ en un string.
Este tema se trata en el concepto [conversión de tipos][type-conversion-concept].
Con los template strings se puede usar cualquier tipo de expresión.

```javascript
const track = 'JavaScript';

`This track on exercism.org is ${track.toUpperCase()}.`;
// => This track on exercism.org is JAVASCRIPT.
```

Cuando necesites que los strings tengan formato en varias líneas:

```javascript
`This is an example of using template
strings to accomplish multiple
lines`;

/* => This is an example of using template
     strings to accomplish multiple
     lines
*/
```

Si quieres representar una nueva línea dentro de un string normal en lugar de usar un template string (es decir, sin usar comillas invertidas), puedes usar la secuencia de escape de nueva línea `\n`:

```javascript
'This is an example of using the newline escape sequence!\nWithout backticks';

/* => This is an example of using the newline escape sequence!
      Without backticks
*/
```

Con las capacidades de sustitución disponibles, también puedes introducir lógica en el proceso para determinar cuál debería ser el string de salida.
Una forma de gestionar esa lógica podría ser usar el [operador ternario][ternary-operator].
Esto ofrece la misma funcionalidad condicional `if/else` con un formato ligeramente distinto.

Para implementar lógica en la sintaxis de los template strings:

```javascript
const grade = 95;

`You have ${grade > 90 ? 'passed' : 'failed'} the exam.`;
// => You have passed the exam.
```
