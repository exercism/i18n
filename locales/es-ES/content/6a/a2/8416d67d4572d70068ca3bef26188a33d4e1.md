# Apéndice de instrucciones

## Implementación

En el paquete twobucket, implementa una función de Go, Solve, con la siguiente firma:

```go
func Solve(sizeBucketOne,
	sizeBucketTwo, goalAmount int, startBucket string,
) (goalBucket string, numSteps, otherBucketLevel int, e error)
```

Solve devuelve cuatro valores: el cubo objetivo resultante («one» o «two»), el número de movimientos o pasos para alcanzar la cantidad objetivo, los litros que quedan en el otro cubo y un valor de error.
Devuelve un error si algún parámetro no es válido o si no es posible ninguna solución.
