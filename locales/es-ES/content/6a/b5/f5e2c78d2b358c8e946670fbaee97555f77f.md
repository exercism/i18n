# Introducción

## Expresiones regulares

Las expresiones regulares en Elixir siguen la especificación **PCRE** (**P**erl **C**ompatible **R**egular **E**xpressions), de forma similar a otros lenguajes populares como Java, JavaScript o Ruby.

El módulo `Regex` ofrece funciones para trabajar con expresiones regulares. Algunas de las funciones del módulo `String` también aceptan expresiones regulares como argumentos.

Este ejercicio da por supuesto que ya conoces la sintaxis de las expresiones regulares, incluidas las clases de caracteres, los cuantificadores, los grupos y las capturas.

### Sigilos

La forma más habitual de crear expresiones regulares es usar el sigilo `~r`.

```elixir
~r/test/
```

Ten en cuenta que todos los sigilos de Elixir admiten [distintos tipos de delimitadores][sigils], no solo `/`.

### Coincidencias

El operador `=~/2` sirve para comprobar si hay coincidencia con una expresión regular y devuelve un resultado `boolean`. Como alternativa, también hay funciones `match?/2` tanto en el módulo `Regex` como en el módulo `String`.

```elixir
"this is a test" =~ ~r/test/
# => true

String.match?("Alice has 7 apples", ~r/\d{2}/)
# => false
```

### Capturas

Si una simple comprobación booleana no es suficiente, usa la función `Regex.run/3` para obtener una lista con todas las capturas (o `nil` si no hubo ninguna coincidencia). El primer elemento de la lista devuelta siempre es la coincidencia con toda la expresión regular, y los elementos siguientes son los grupos que coincidieron.

```elixir
Regex.run(~r/(\d) apples/, "Alice has 7 apples")
# => ["7 apples", "7"]
```

### Modificadores

El comportamiento de una expresión regular se puede modificar añadiendo modificadores especiales. Cuando uses un sigilo para crear una expresión regular, añade los modificadores después del segundo delimitador.

Los modificadores más habituales son:
- `i`: hace que la coincidencia no distinga entre mayúsculas y minúsculas.
- `u`: habilita patrones específicos de Unicode como `\p` y hace que las clases de caracteres como `\w`, `\s`, etc. también coincidan con caracteres Unicode.

```elixir
"this is a TEST" =~ ~r/test/i
# => true
```
