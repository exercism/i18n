Instalación
============

Para escribir programas en YAMLScript necesitas instalar el intérprete de línea
de comandos de YAMLScript.
Es un archivo binario ejecutable llamado `ys`.
Actualmente funciona en:

* Linux / Intel
* Linux / ARM
* MacOS / Intel
* MacOS / ARM

> Nota: El soporte para Windows está planeado, pero aún no está disponible.

Las versiones están [disponibles en GitHub](
http://github.com/yaml/yamlscript/releases).


## Instalación automática

Para resolver los ejercicios de YAMLScript de Exercism, modificas tu programa de
solución repetidamente y ejecutas `make test` hasta que pasen todas las pruebas.

¡Eso es todo!

La primera vez que ejecutes `make test`, intentará instalar la versión específica
del intérprete `ys` que requiere el ejercicio en el directorio
`/path/to/exercism/yamlscript/.local/`.

Si ya has instalado esa versión de `ys` en algún lugar de tu `PATH`, copiará
silenciosamente el intérprete `ys` al lugar correcto.

Si no, te pedirá que hagas una instalación a partir de una versión binaria, que
normalmente solo tarda unos segundos.

Si eso falla (es raro, pero a veces pasa), te pedirá que hagas una compilación
automática desde el código fuente, que puede tardar unos minutos (pero es muy
fiable y no requiere ninguna interacción).

Solo te encontrarás con esto la primera vez que ejecutes `make test`.
Todos los ejercicios configurados para usar la misma versión de `ys` usarán la
misma instalación.

> Nota: También puedes usar el comando `make install-ys` por separado de `make
> test`.
> Hará exactamente el mismo proceso de instalación que `make test`, pero sin
> ejecutar las pruebas después.


Para obtener más información sobre cómo instalar YAMLScript, especialmente para
usarlo fuera de Exercism, consulta la [documentación de instalación de
YAMLScript](https://yamlscript.org/doc/install/).
