# Instrucciones

En este ejercicio vas a seguir trabajando con los coches teledirigidos.

Se ha desarrollado un coche experimental y la pista de pruebas debe adaptarse para manejar tanto los modelos de producción como los experimentales. Ya se han construido los dos tipos de coche y tienes que encontrar la manera de lidiar con ambos en la pista de pruebas.

Además, los coches de producción están empezando a tener cierto éxito. El jefe del equipo está muy interesado en mantener el espíritu competitivo publicando una clasificación de los coches de producción.

## 1. Permitir que los coches se conduzcan en la misma pista de pruebas

Añade un método a la interfaz `IRemoteControlCar` para exponer las implementaciones de `Drive()` de los dos tipos de coche.

```csharp
TestTrack.Race(new ProductionRemoteControlCar());
TestTrack.Race(new ExperimentalRemoteControlCar());
// this should execute without an exception being thrown
```

## 2. Permitir que se compare la distancia recorrida por los distintos modelos en la pista de pruebas

Añade una propiedad a la interfaz `IRemoteControlCar` para exponer las implementaciones de la propiedad `DistanceTravelled` de los dos tipos de coche.

```csharp
var prod = new ProductionRemoteControlCar();
TestTrack.Race(prod);
var exp = new ExperimentalRemoteControlCar();
TestTrack.Race(exp);
prod.DistanceTravelled
// => 10
exp.DistanceTravelled
// => 20
```

## 3. Permitir clasificar los coches de producción

Implementa la interfaz `IComparable<T>` en la clase `ProductionRemoteControlCar`. El orden de clasificación predeterminado de los coches debe ser el orden ascendente de victorias.

Implementa el método estático `TestTrack.GetRankedCars()` para que devuelva los coches pasados ordenados de forma ascendente según el número de victorias.

```csharp
var prc1 = new ProductionRemoteControlCar();
var prc2 = new ProductionRemoteControlCar();
prc1.NumberOfVictories = 3;
prc2.NumberOfVictories = 2;
var rankings = TestTrack.GetRankedCars(prc1, prc2);
// => rankings[1] == prc1
```
