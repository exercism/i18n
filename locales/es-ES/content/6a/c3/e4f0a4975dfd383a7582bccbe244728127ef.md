# Instrucciones

Llamar a las API puede ser propenso a errores cuando se usan texto sin formato o JSON. En este ejercicio, usarás los registros de Ballerina para organizar los payloads de las peticiones y garantizar una comunicación correcta con los endpoints de reserva externos.

## Objetivos

- Modifica el código proporcionado
- Reserva un billete de avión para el usuario llamando al servicio de reserva de vuelos. Envía una petición POST a airlineReservationService con el payload adecuado y obtén una respuesta
- Reserva una habitación de hotel para el usuario llamando al servicio de reserva de hoteles. Envía una petición POST a hotelReservationService con el payload adecuado y obtén una respuesta
- Alquila un coche para el usuario llamando al servicio de alquiler de coches. Envía una petición POST a carRentalService con el payload adecuado y comprueba la respuesta
- Si todo va bien, devuelve un cuerpo con un atributo message de «Congratulations! Your journey is ready!!»
