# Apéndice de instrucciones

## Formato de entrada y salida

La función recibe un único string de palabras, cada una seguida de un salto de línea.

La primera es la palabra de la que deben ser anagramas las restantes.

Devuelve un string con todos los anagramas válidos, cada uno seguido de un salto de línea.


## Direcciones reservadas

El búfer para el string de entrada usa los bytes 64-319 de la memoria lineal.

Puedes modificar este búfer in situ si quieres evitar asignaciones de memoria adicionales.
