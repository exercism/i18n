# Apéndice de instrucciones

## Instrucciones específicas del track

Phix no tiene punteros, y implementar algo como una lista enlazada, que ya de por sí es un poco complicado, aunque sea emulando punteros con índices, no solo sería todavía más complicado, sino también completamente inútil, dado que una secuencia estándar, la auténtica columna vertebral del lenguaje, se ocupa de este tipo de cosas de una forma mucho más sencilla y casi trivial.
Por eso, este ejercicio es muy sencillo: se trata de emular el comportamiento de una lista doblemente enlazada (/con doble extremo) usando una única secuencia (plana), sin ningún tipo de punteros ni nada parecido.
Aunque se podrían manejar varias listas devolviendo varios valores, o se podría usar el include de pila/cola que se proporciona (a ambos se les puede indicar que realicen una operación en su «otro» extremo), para simplificar aún más las cosas usaremos simplemente la única variable estática «list».
