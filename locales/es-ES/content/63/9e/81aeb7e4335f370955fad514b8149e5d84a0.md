# Ayuda

Si tienes problemas, puedes usar uno de los siguientes recursos para obtener ayuda:

- [SWI Prolog Documentation](http://www.swi-prolog.org)
- [Tutorials and Resources](http://www.swi-prolog.org/Links.html)
- [/r/prolog](https://www.reddit.com/r/prolog) es el subreddit de Prolog.
- [StackOverflow](http://stackoverflow.com/questions/tagged/prolog) se puede usar para buscar tu problema y ver si ya se ha respondido. También puedes hacer preguntas y responder a las de otras personas.
