# Instrucciones

Tu amigo acaba de enviarte un mensaje con un secreto importante. Para que a los demás no les resultara fácil leerlo, el mensaje se cifró mediante una serie de manipulaciones de bits. Tendrás que escribir las palabras que ayuden a descifrar el mensaje.

## 1. Desplaza los bits hacia atrás

El primer paso para descifrar el mensaje consiste en deshacer el desplazamiento del proceso de cifrado desplazando los bits de vuelta a la derecha. Los pasos posteriores dan por supuesto que se insertan ceros desde la izquierda.

Define `shift-back`, que toma un valor de 32 bits y una cantidad, y devuelve el valor desplazado a la derecha esa cantidad con relleno de ceros.

```factor
0b1001 2 shift-back .
! => 0b0010
```

## 2. Pon algunos bits a 1

A continuación, hay algunos bits que deben ponerse a 1.

Define `set-bits`, que toma un valor y una máscara. Todos los bits de `value` cuyo bit correspondiente de `mask` sea 1 deben ponerse a 1; el resto se deja sin cambios.

```factor
0b0110 0b0101 set-bits .
! => 0b0111
```

## 3. Invierte bits específicos

Algunos bits se invierten durante el cifrado. Habrá que volver a invertirlos para descifrar el mensaje.

Define `flip-bits`, que toma un valor y una máscara. Todos los bits de `value` cuyo bit correspondiente de `mask` sea 1 deben invertirse; el resto se deja sin cambios.

```factor
0b1100 0b0101 flip-bits .
! => 0b1001
```

## 4. Borra bits específicos

Por último, también hay ciertos bits que siempre se descifran como 0.

Define `clear-bits`, que toma un valor y una máscara. Todos los bits de `value` cuyo bit correspondiente de `mask` sea 1 deben borrarse, poniéndolos a 0; el resto se deja sin cambios.

```factor
0b0110 0b0101 clear-bits .
! => 0b0010
```
