# Instrucciones

Estás creando una guía de campo: un mapa que asocia el nombre de un animal con el hábitat en el que vive.

Las cinco tareas van en la clase `FIELD_GUIDE`.

## 1. ¿Está en la guía?

```sather
FIELD_GUIDE::is_listed(guide, "emu")
-- => true
```

## 2. ¿Dónde vive?

Devuelve el hábitat registrado para un animal. Si la guía no ha oído hablar de él, devuelve `"Unknown"`.

```sather
FIELD_GUIDE::habitat_of(guide, "emu")
-- => "grassland"
FIELD_GUIDE::habitat_of(guide, "moa")
-- => "Unknown"
```

## 3. Añade una entrada

Devuelve la guía con un animal más. Si un animal ya estaba en la lista, se sustituye su hábitat.

```sather
FIELD_GUIDE::add_entry(guide, "wombat", "forest")
-- => the guide, now with wombat in it
```

Lo que devuelva esto es la guía que debes usar a partir de entonces. Añadir a una guía completamente vacía funciona y da como resultado una guía con un animal.

## 4. ¿Cuántos animales?

```sather
FIELD_GUIDE::entry_count(guide)
-- => 3
```

## 5. ¿Qué hábitats?

Devuelve el conjunto de hábitats que menciona la guía. Varios animales pueden compartir un hábitat, y este debe aparecer una sola vez.

```sather
FIELD_GUIDE::all_habitats(guide)
-- => a set holding "grassland" and "forest"
```
