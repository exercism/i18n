## Tipos de funciones

Ya hemos visto antes cómo se definen las firmas de las funciones: un nombre de función seguido de una lista de etiquetas de parámetros separadas por comas junto con sus tipos, seguidas de `->` y del tipo de los valores que devuelve la función.

Si quitáramos todos los nombres y las etiquetas de esta firma, nos quedaríamos con el [tipo de la función][function-types].

```swift
func shoppingList(item: String, quantity: Int) -> String {
  "You need to buy \(quantity) \(item)."
}
// shoppingList: (String, Int) -> String

func repeater(_ phrase: String, times: Int) -> String {
  var result = ""
  for _ in 1...times {
    result += phrase
  }
  return result
}
// repeater: (String, Int) -> String

func printString(line: String) {
  print(line)
}
// printString: (String) -> ()
```

Fíjate en que los tipos de las dos primeras funciones son el mismo, `(String, Int) -> String`, aunque las dos funciones funcionan de forma muy distinta. Ambas reciben como entrada un `String` y un `Int` y devuelven un `String`. Y, como se puede ver en el tipo de la tercera función, aunque la función no parece devolver nada, en realidad devuelve `()`, el único valor de tipo `Void`. Ten en cuenta que `()` y `Void` son intercambiables como nombres de tipo, así que el tipo de `printString` también podría escribirse como `String) -> Void`.

Estos tipos se pueden usar igual que cualquier otro tipo de Swift; por ejemplo, se pueden usar en la declaración de variables o constantes. Y como las funciones son valores en Swift, puedes asignar funciones ya existentes a esas constantes o variables:

```swift
var stringAndIntToString: (String, Int) -> String

stringAndIntToString = shoppingList
stringAndIntToString("carrots", 3)
// => "You need to buy 3 carrots."

stringAndIntToString = repeater
stringAndIntToString("carrots", 3)
// => "carrotscarrotscarrots"
```

Al igual que con otras variables y constantes, el valor que le asignes debe ser del tipo correcto:

```swift
stringAndIntToString = printShoppingList
// Error: Cannot assign value of type '(String) -> ()' to type '(String, Int) -> String'
```

## Tipos de función como tipos de parámetros

Como los tipos de función se pueden usar en cualquier sitio donde se pueda usar otro tipo, se deduce que [se pueden usar como tipos de parámetros][functions-as-parameters], pasarlos a otras funciones y llamarlos desde dentro de esas funciones.

```swift
func apply3(to str: String, function f: (String, Int) -> String) -> String {
  f(str,3)
}
// apply3: ([String], (String, Int) -> String) -> [String]

apply3(to: "eggs", function: shoppingList)
// => "You need to buy 3 eggs."

apply3(to: "eggs", function: repeater)
// => "eggseggseggs"

func apply(functions fs: [(String, Int) -> String],
           to string: String,
          ) -> [String] {
  var result = [String]()
  for f in fs {
    result.append(f(string, 3))
  }
  return result

}
// apply: ([(String, Int) -> String], String) -> [String]


apply(functions: [shoppingList, repeater], to: "carrots")
// => ["You need to buy 3 carrots.", "carrotscarrotscarrots"]
```

## Tipos de función como tipos devueltos

Del mismo modo, [los tipos de función pueden usarse como tipos devueltos][functions-as-returns] de una función. En otras palabras, puedes escribir funciones que crean y devuelven otras funciones. Al crear estas funciones, la función que se devuelve puede usar los demás parámetros que se pasan a la función o las variables locales creadas dentro de la función contenedora.

```swift
func makeAdder(base: Int) -> (Int) -> Int {
  func adder(_ i: Int) -> Int {
    base + i
  }
  return adder
}
// makeAdder: (Int) -> (Int) -> Int

let add10 = makeAdder(base: 10)
// add10: (Int) -> Int

let subtract20 = makeAdder(base: -20)
// subtract10: (Int) -> Int

add10(5)
// => 15

subtract20(5)
// => -15
```

## Captura de valores

Como se ha visto con la función `makeAdder(base:)` de arriba, las funciones anidadas pueden acceder a los parámetros y las variables de las funciones que las rodean. Además, pueden mantener el acceso a estos valores después de que termine la función que las contiene. Esta acción de obtener y mantener el acceso se conoce como [_captura_][capturing-values].

## Funciones de orden superior

Las funciones que reciben funciones como parámetros, que devuelven funciones o ambas cosas se conocen como funciones de orden superior. Swift tiene muchas funciones de orden superior en sus distintas librerías. Por ejemplo, el método `sorted(by:)`, disponible en las colecciones de Swift como `Array`, que para un array con elementos de tipo `T` recibe una función de tipo `(T, T) -> Bool` que determina cuál de los dos valores debe ir antes que el otro en un array ordenado, devolviendo `true` si el valor de la izquierda debe aparecer primero y `false` si debe aparecer primero el de la derecha.

Otro ejemplo es el método `contains(where:)` de las colecciones, que para una colección con elementos de tipo `T` recibe una función de tipo `(T) -> Bool` que devuelve `true` si el elemento cumple alguna propiedad y `false` en caso contrario. `contains(where:)` devuelve entonces `true` si algún elemento de la colección cumple esta propiedad.

```swift
func longer(_ strA: String, _ strB: String) -> Bool {
  strA.count > strB.count
}
// longer: (String, String) -> Bool

["apple", "ball", "carrot"].sorted(by: longer)
// => ["carrot", "apple", "ball"]

["apple", "ball", "carrot"].sorted(by: >)
// => ["carrot", "ball", "apple"]


func isBig(_ i: Int) -> Bool {
  i > 100
}
// isBig: (Int) -> Bool

func isVowel(_ char: Character) -> Bool {
  switch char.lowercased() {
  case "a", "e", "i", "o", "u": return true
  default: return false
  }
}
// isVowel: (Character) -> Bool

[1, 75, 3, 99].contains(where: isBig)
// => false

"Owl".contains(where: isVowel)
// => true

```
