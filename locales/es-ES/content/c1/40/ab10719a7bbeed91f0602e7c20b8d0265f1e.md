# Introducción

## Coincidencia de patrones

Una expresión `if/elif/else` puede usarse para ejecutar lógica de forma condicional. F# también tiene otra forma más potente de ejecutar lógica de forma condicional: la coincidencia de patrones. Con la coincidencia de patrones, un valor puede compararse con uno o varios _patrones_. Un ejemplo de ese patrón es el _patrón constante_, que compara un valor con una constante (por ejemplo, `1` o `"hello"`).

En F#, la coincidencia de patrones se hace con la palabra clave `match`:

```fsharp
let describe number =
    match number with
    | 0 -> "Zero"
    | 1 -> "One"
```

Aunque esto pueda parecerse a las instrucciones `switch` de otros lenguajes, la coincidencia de patrones empieza a destacar cuando se usan también otros patrones. Uno de esos patrones es el _patrón de variable_, que permite capturar un valor:

```fsharp
match number with
| 0 -> "Zero"
| i -> sprintf "Non zero: %d" i
```

En algunos casos, es posible que quieras añadir una condición adicional a un patrón. Esto se conoce como _guarda_ (cláusula), que se puede añadir con la palabra clave `when`:

```fsharp
match number with
| 0 -> "Zero"
| i when i < 0 -> "Negative number"
```

En el ejemplo anterior, no todas las entradas posibles tendrán un patrón que coincida. El compilador lo detectará y mostrará una advertencia. Esto se conoce como _comprobación exhaustiva_. Para resolver la advertencia, hay que cubrir todos los casos. Para ello se puede usar el _patrón comodín_, que es un patrón que coincide con cualquier valor:

```fsharp
match number with
| i when i < 0 -> "Negative number"
| _ -> "Positive number"

// No compiler warning
```

La coincidencia de patrones compara un valor con cada patrón de arriba abajo, hasta que encuentra un patrón coincidente y ejecuta la lógica asociada a ese patrón. El orden de los patrones importa.
