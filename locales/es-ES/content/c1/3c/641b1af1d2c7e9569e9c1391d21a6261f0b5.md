# marcador de posición

## Valores ASCII

Este ejercicio requiere convertir caracteres ASCII a su valor numérico y viceversa. La [extensión ordchr][ordchr] de GNU awk proporciona esta funcionalidad. Para añadir las funciones `ord()` y `chr()`, carga la extensión `ordchr` añadiendo una directiva `@load` al principio de tu archivo:

```
@load "ordchr"
```

[ordchr]: https://www.gnu.org/software/gawk/manual/gawk.html#Extension-Sample-Ord
