# Introducción

El tipo unión discriminada representa un número fijo de casos con nombre. Cada valor de una unión discriminada se corresponde exactamente con uno de los casos con nombre.

Una unión discriminada se define con la palabra clave `type`, con los casos separados por el carácter de barra vertical (`|`):

```fsharp
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter
```

Cada caso de una unión discriminada puede tener datos asociados, y distintos casos pueden tener distintos tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada es similar a lo que en otros lenguajes se suele llamar una _enumeración_ (o _enum_).

```fsharp
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Se puede crear un valor para un caso concreto refiriéndose a su nombre (por ejemplo, `Success`). Como los nombres de los casos no son más que funciones constructoras, los datos asociados se pueden pasar como un argumento normal de función. Si otra unión discriminada ha definido un caso con el mismo nombre, tendrás que usar su nombre completo (por ejemplo, `Result.Success`).

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Las uniones discriminadas tienen _igualdad estructural_, lo que significa que dos valores del mismo caso y con los mismos datos (opcionales) son equivalentes.

Aunque se pueden usar expresiones `if/elif/else` para trabajar con uniones discriminadas, la forma recomendada de hacerlo es mediante la coincidencia de patrones usando el _patrón de identificador_:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
