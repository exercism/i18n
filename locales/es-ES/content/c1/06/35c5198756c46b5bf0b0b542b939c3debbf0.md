# Apéndice de las instrucciones

## Paquete de ordenación

Este ejercicio requiere que ordenes un array, pero esto no forma parte de la biblioteca estándar. Podrías escribir tu propia biblioteca de ordenación, pero una opción mejor es usar el [paquete sorts](https://github.com/diku-dk/sorts).

Puedes usar este paquete en tu solución ejecutando el siguiente comando en el directorio de la solución:

```shell
futhark pkg add github.com/diku-dk/sorts
futhark pkg sync
```

Después, importa los [algoritmos de ordenación que quieras](https://github.com/diku-dk/sorts/tree/master/lib/github.com/diku-dk/sorts) con:

```futhark
import "lib/github.com/diku-dk/sorts/<sorting algorithm>"
```
