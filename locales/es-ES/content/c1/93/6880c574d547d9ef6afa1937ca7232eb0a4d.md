# Acerca de

Una [función de orden superior](https://docs.microsoft.com/en-us/dotnet/fsharp/introduction-to-functional-programming/first-class-functions) es una función que cumple una de estas dos condiciones:

- Recibe una función como argumento
- Devuelve una función

Un argumento de función no es más que un argumento normal, solo que puedes invocarlo.

```fsharp
let double = fun x -> x * 2

let apply f x = f x

apply double 3
// => 6
```
