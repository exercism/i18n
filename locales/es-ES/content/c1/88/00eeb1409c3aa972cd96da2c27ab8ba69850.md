# Anexo a las instrucciones

## Pistas

Para completar este ejercicio, tienes que crear el tipo de datos `CustomSet`,
con las instancias `Eq` y `Show`, e implementar las siguientes funciones:

- `delete`
- `difference`
- `empty`
- `fromList`
- `insert`
- `intersection`
- `isDisjointFrom`
- `isSubsetOf`
- `member`
- `null`
- `size`
- `toList`
- `union`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya en su sitio,
pero depende de ti definir las funciones y crear un tipo de datos, un newtype o un
sinónimo de tipo que tenga sentido.

Si te interesa escribir una implementación eficiente pero no sabes muy bien
por dónde empezar, la mejor introducción que conozco es «Purely Functional Data
Structures», de Chris Okasaki, de la que puedes leer una versión aquí:
https://www.cs.cmu.edu/~rwh/theses/okasaki.pdf
