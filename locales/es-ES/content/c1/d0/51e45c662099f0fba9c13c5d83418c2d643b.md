# Introducción

El SGF (Smart Game Format) es un formato de archivo de texto muy popular que se utiliza para almacenar registros de partidas de juegos de mesa. Aunque se puede usar para muchos juegos distintos, como el ajedrez, el Othello o el Backgammon, es especialmente conocido y utilizado para el juego de Go.

Un archivo SGF está estructurado como un árbol de nodos. Esta estructura de árbol resulta especialmente útil porque permite que los registros de partidas se ramifiquen, lo que significa que puedes guardar la secuencia principal de movimientos, así como variantes alternativas, análisis y comentarios, todo en el mismo archivo.

Cada nodo del árbol contiene un conjunto de propiedades, y cada propiedad tiene uno o varios valores. Estas propiedades codifican desde los nombres y los rangos de los jugadores hasta el resultado de la partida, el tamaño del tablero y los movimientos individuales colocados en él.
