# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LVL>]: <MESSAGE>"`.

Estos son los diferentes niveles de registro:

- `TRC` (traza)
- `DBG` (depuración)
- `INF` (información)
- `WRN` (advertencia)
- `ERR` (error)
- `FTL` (fatal)

Tienes tres tareas.

## 1. Analizar el nivel de registro

Define un enum `LogLevel` que tiene seis elementos correspondientes a los niveles de registro anteriores.

- `TRACE`
- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`
- `FATAL`

A continuación, implementa el método `LogLine.getLogLevel()` que devuelve el nivel de registro analizado de una línea de registro:

```java
var logLine = new LogLine("[INF]: File deleted");
logLine.getLogLevel();
// => LogLevel.INFO
```

## 2. Soportar nivel de registro desconocido

Desafortunadamente, en ocasiones algunas líneas de registro tienen un nivel de registro desconocido.
Para manejar estas líneas de registro de forma controlada, añade un elemento `UNKNOWN` al enum `LogLevel` que debe devolverse al analizar un nivel de registro desconocido:

```java
var logLine = new LogLine("[XYZ]: Overly specific, out of context message");
logLine.getLogLevel();
// => LogLevel.UNKNOWN
```

## 3. Convertir la línea de registro al formato corto

El nivel de registro de una línea de registro es bastante verboso.
Para reducir el espacio en disco necesario para almacenar las líneas de registro, se desarrolla un formato corto: `"[<ENCODED_LEVEL>]:<MESSAGE>"`.

El nivel de registro codificado es una simple asignación de un nivel de registro a un número:

- `UNKNOWN` - `0`
- `TRACE` - `1`
- `DEBUG` - `2`
- `INFO` - `4`
- `WARNING` - `5`
- `ERROR` - `6`
- `FATAL` - `42`

Implementa el método `LogLine.getOutputForShortLog()` que puede generar el formato de línea de registro acortado:

```java
var logLine = new LogLine("[ERR]: Stack Overflow");
logLine.getOutputForShortLog();
// => "6:Stack Overflow"
```
