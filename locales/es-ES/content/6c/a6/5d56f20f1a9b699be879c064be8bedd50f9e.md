# Instrucciones

En tu laboratorio de investigación de ADN, has estado buscando distintas formas de comprimir los datos de tu investigación para ahorrar espacio de almacenamiento. Un compañero de equipo sugiere convertir los datos de ADN a una representación binaria:

| Ácido nucleico | Código |
| -------------- | ------ |
| un espacio     | `0000` |
| A              | `0001` |
| C              | `0010` |
| G              | `0100` |
| T              | `1000` |

Le das vueltas a la idea, ya que podría reducir a la mitad los costes de almacenamiento necesarios, pero a costa de la legibilidad para las personas. Decides escribir un módulo para codificar y decodificar tus datos y así poder medir el ahorro.

## 1. Codifica un ácido nucleico a un valor binario

Implementa `encode_nucleotide/1` para que acepte el punto de código del ácido nucleico y devuelva el valor entero del código codificado.

```elixir
DNA.encode_nucleotide(?A)
# => 1
# (which is equal to 0b0001)
```

## 2. Decodifica el valor binario al ácido nucleico

Implementa `decode_nucleotide/1` para que acepte el valor entero del código codificado y devuelva el punto de código del ácido nucleico.

```elixir
DNA.decode_nucleotide(0b0001)
# => 65
# (which is equal to ?A)
```

## 3. Codifica un charlist de ADN

Implementa `encode/1` para que acepte un charlist que represente ácidos nucleicos y huecos y devuelva un bitstring con los datos codificados.

```elixir
DNA.encode(~c"AC GT")
# => <<18, 4, 8::size(4)>>
```

## 4. Decodifica un bitstring de ADN

Implementa `decode/1` para que acepte un bitstring que represente ácidos nucleicos y huecos y devuelva los datos decodificados como un charlist.

```elixir
DNA.decode(<<132, 2, 1::size(4)>>)
# => ~c"TG CA"
```
