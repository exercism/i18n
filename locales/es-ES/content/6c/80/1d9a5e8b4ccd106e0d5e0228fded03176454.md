# Acerca de

Clojure usa el tipo subyacente `java.lang.Character`, que es una cantidad de 16 bits para representar los componentes direccionables más pequeños del texto.
Varios `char` pueden componer un string como `"word"`, o bien los `char` pueden procesarse por separado. Sus literales se escriben así: `\a \b \c`.

Los `char` de Clojure admiten la codificación Unicode UTF-16, por lo que, además del conjunto de caracteres latinos, se pueden representar prácticamente todos los sistemas de escritura que se usan en el mundo, por ejemplo, la letra griega `'β'`.

Hay muchos métodos de biblioteca para inspeccionar y manipular `char`. Se puede acceder a ellos mediante interoperabilidad, como métodos de la clase `Character`. Clojure también incluye una biblioteca de utilidades para strings, `clojure.string`, que ofrece muchas funciones potentes para operar con caracteres.
