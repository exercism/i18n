# Instrucciones

En este ejercicio vas a escribir código para imprimir etiquetas identificativas con el nombre de los empleados de una fábrica.

## 1. Imprime una etiqueta identificativa para un empleado

Los empleados tienen un ID, un nombre y el nombre de su departamento. Las etiquetas identificativas de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`. Implementa el método `Badge.Print()` (_static_) para devolver la etiqueta identificativa de un empleado:

```csharp
Badge.Print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Ten en cuenta que el departamento debe escribirse en mayúsculas en la etiqueta.

## 2. Imprime una etiqueta identificativa para un empleado nuevo

Debido a una peculiaridad del sistema informático, a veces los empleados nuevos aún no tienen un ID cuando empiezan a trabajar en la fábrica. Como las etiquetas identificativas son obligatorias, recibirán una etiqueta temporal sin el prefijo del ID. Modifica el método `Badge.Print()` (_static_) para admitir a los empleados nuevos que aún no tienen un ID:

```csharp
Badge.Print(id: null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime una etiqueta identificativa para el propietario

Incluso el propietario de la fábrica tiene que llevar una etiqueta identificativa en todo momento. Sin embargo, el propietario no tiene departamento. En este caso, la etiqueta debe imprimir `"OWNER"` en lugar del nombre del departamento. Modifica el método `Badge.Print()` (_static_) para imprimir una etiqueta para el propietario:

```csharp
Badge.Print(254, "Charlotte Hale", department: null);
// => "[254] - Charlotte Hale - OWNER"
```

Ten en cuenta que es posible que el propietario sea también un empleado nuevo:

```csharp
Badge.Print(id: null, "Charlotte Hale", department: null);
// => "Charlotte Hale - OWNER"
```
