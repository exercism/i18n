# Usar la interpolación de string en lugar de string format

Un enfoque más habitual en C# es usar la [interpolación de string](https://csharp.net-tutorials.com/operators/the-string-interpolation-operator/) en lugar de `string.Format` para construir un string de forma dinámica.

Ten en cuenta que la interpolación de string no es más que un truco del compilador, también conocido como azúcar sintáctico. Esto significa que, cuando se compila una expresión de interpolación de string, el compilador la convierte en realidad en una llamada a `string.Format`. Por tanto, la ventaja de usar la interpolación de string es puramente visual.
