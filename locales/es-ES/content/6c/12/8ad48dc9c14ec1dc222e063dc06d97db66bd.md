# Apéndice de instrucciones

Este ejercicio presenta un par de conceptos que quizá no hayas visto antes:

## Espacio de nombres definido por el usuario

En 8th, todas las palabras pertenecen a un espacio de nombres; por ejemplo, `a:new` hace referencia a la palabra `new` del espacio de nombres `a`.
También se pueden definir espacios de nombres personalizados, que es lo que hacemos al principio del archivo `circular-buffer.8th`:

```8th
ns: cb
```

Esto significa que se puede acceder a todas las palabras de ese archivo mediante `cb:<word>`, lo que es una forma excelente de agrupar funcionalidad relacionada.

Para obtener más información, consulta la documentación sobre [espacios de nombres][namespaces].

## Excepciones

Se espera que las palabras `read` y `write` lancen una excepción cuando se las llama sobre un búfer circular con un estado no válido.
Para obtener más información, consulta la documentación sobre [excepciones y gestión de errores][exceptions-and-error-handling].

## Objetos

Aunque eres libre de implementar el búfer circular como quieras, podrías considerar usar el [soporte de objetos][objects] de 8th.
