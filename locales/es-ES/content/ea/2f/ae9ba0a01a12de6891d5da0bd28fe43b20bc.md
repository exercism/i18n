# Instrucciones

En este ejercicio vas a escribir código para imprimir insignias con el nombre de los empleados de una fábrica.

## 1. Imprime una insignia para un empleado

Los empleados tienen un identificador, un nombre y el nombre de su departamento. Las etiquetas de las insignias de los empleados tienen el siguiente formato: `"[id] - name - DEPARTMENT"`.
Implementa el método `Badge.print()` para que devuelva la etiqueta de la insignia de un empleado:

```java
Badge badge = new Badge();
badge.print(734, "Ernest Johnny Payne", "Strategic Communication");
// => "[734] - Ernest Johnny Payne - STRATEGIC COMMUNICATION"
```

Ten en cuenta que el departamento debe escribirse en mayúsculas en la etiqueta.

## 2. Imprime una insignia para un nuevo empleado

Debido a una peculiaridad del sistema informático, a veces los nuevos empleados todavía no tienen un identificador cuando empiezan a trabajar en la fábrica.
Como las insignias son obligatorias, recibirán una insignia temporal sin el prefijo del identificador. Modifica el método `Badge.print()` para admitir a los nuevos empleados que todavía no tienen un identificador:

```java
Badge badge = new Badge();
Badge.print(null, "Jane Johnson", "Procurement");
// => "Jane Johnson - PROCUREMENT"
```

## 3. Imprime una insignia para el dueño

Incluso el dueño de la fábrica tiene que llevar una insignia en todo momento.
Sin embargo, un dueño no tiene departamento. En este caso, la etiqueta debe mostrar `"OWNER"` en lugar del nombre del departamento.
Modifica el método `Badge.print()` para imprimir una etiqueta para el dueño:

```java
Badge badge = new Badge();
badge.print(254, "Charlotte Hale", null);
// => "[254] - Charlotte Hale - OWNER"
```

Ten en cuenta que es posible que el dueño también sea un nuevo empleado:

```java
Badge badge = new Badge();
badge.print(null, "Charlotte Hale", null);
// => "Charlotte Hale - OWNER"
```
