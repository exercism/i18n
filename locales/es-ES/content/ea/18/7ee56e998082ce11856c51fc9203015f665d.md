# Depuración

Para ayudar con la depuración, puedes usar [`print` u otras funciones similares][cl-print] para escribir en la salida estándar, que será visible en la salida de las pruebas.

Por ejemplo, añadir `(print "hello there")` a la función que estás escribiendo hará que sea visible en las ejecuciones de las pruebas (dado que la prueba ejecuta esa función).

Un «truco»: si tienes varias cosas que imprimir, reúnelas en una lista y luego imprime eso: `(print (list :this "that" 'the-other))`.

[cl-print]: http://www.lispworks.com/documentation/HyperSpec/Body/f_wr_pr.htm
