# Introducción

## Condicionales

Los condicionales son instrucciones que toman decisiones: pueden ejecutar efectos secundarios o controlar el flujo de ejecución de un programa.
Entre los condicionales se incluyen las instrucciones `if`, `if/else`, `switch` y `ternary`.

Los condicionales se usan para hacer preguntas sobre un valor o sobre la relación entre varios valores.
La pregunta se evalúa a una respuesta Boolean, pero la propia instrucción `if` puede devolver cualquier valor o simplemente ejecutar un efecto secundario.

## Instrucciones `if`

La instrucción `if` más sencilla evalúa una expresión y ejecuta una línea.
La expresión que se evalúa siempre va entre paréntesis.

Puede ejecutar un efecto secundario

```c
if (count > 10)
    printf("count is greater than 10");
```

o puede cambiar el flujo de ejecución


```c
if (count > 10)
    return sum;
```

Si una instrucción `if` ejecuta más de una línea, debe colocar las líneas entre llaves

```c
if (count > 10) {
    printf("count is greater than 10");
    return sum;
}
```

Algunos equipos de programación pueden establecer como norma que las instrucciones `if` usen siempre llaves, incluso para una sola línea.


## `if` / `else`

Una instrucción `if` se puede combinar con un `else`

```c
if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `if` / `else if`


Un `else` se puede combinar con otro `if` para crear lo que se conoce como `if-else-if ladder`.

```c
if (number == 0)
    return "zero";
else if (number < 0)
    return "negative";
else if (number < 10)
    return "single digit";   
else if (number % 2 == 0)
    return "even";
else
    return "odd";
```

## `switch`


A veces, un `if-else-if ladder` se puede representar mejor con un `switch`.
Al igual que con `if`, la expresión que se evalúa siempre va entre paréntesis.

```c
switch (number) {
    case -1:
        return "negative one";
    case 0:
        return "zero";
    case 1:
        return "positive one";
    case 10:
        return "positive ten";
    case -10:
        return "negative ten";
    default:
        return "don't care";
}
```

El caso `default` se ejecuta si el valor que se evalúa no coincide con ninguno de los casos anteriores.

Si un caso de `switch` no devuelve nada, lo habitual es insertar un `break` para terminar cada caso; de lo contrario, la lógica «cae» al siguiente caso.
A veces, esa caída al caso siguiente se usa de forma intencionada

```c
switch (number) {
    case 0:
        msg = "zero"; break;
    case 1:
        msg = "one"; break;
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Cuando la caída al caso siguiente ocurre sin querer, es un bug.

```c
switch (number) {
    case 0:
        msg = "zero"; // bug! fallthrough of 0 will set msg to "one"
    case 1:
        msg = "one"; break; 
    case 2: case 3: case 4:
        msg = "more than one and less than five"; break;
    default:
        msg = "don't care";
}
```

Un `switch` puede resultar beneficioso cuando se compara con valores concretos en lugar de con un rango de valores.
Puede ser más rápido que un `if-else-if ladder` porque es posible que el compilador pueda optimizar la instrucción `switch` de formas que no puede aplicar a una escalera.
Un `switch` a veces puede resultar más legible que una escalera.

## El operador ternario (también llamado condicional)

El operador ternario es una instrucción condicional de tres partes que se usa a menudo para asignar un valor.
La expresión que se va a evaluar está antes del signo de interrogación y no tiene por qué ir entre paréntesis.
El valor que se devuelve si la condición es verdadera está antes de los dos puntos, y el valor que se devuelve si es falsa está después de los dos puntos.
Se puede devolver tanto un literal como una variable.

```c
int i = j > 5 ? 5: j;
```

Los operadores ternarios se pueden anidar para reducir el ruido sintáctico.

```c
// the below could also be 
i = j > 5 ? j :k > 5 ? k: 10;
// but that may not be quite as readable

i = j > 5 ? j
    :k > 5 ? k
    :10;

// which is the same as
if (j > 5) i = j;
else if (k > 5) i = k;
else i = 10;
```
