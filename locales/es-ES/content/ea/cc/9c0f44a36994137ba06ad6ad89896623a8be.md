# Instrucciones

Mecha Munch™, una empresa de automatización de la compra, acaba de contratarte para que trabajes en su aplicación de pedidos.
Tu equipo tiene la tarea de crear un MVP (_[producto mínimo viable][mvp]_) que gestione todas las actividades básicas del carrito de la compra, permitiendo a los usuarios añadir, eliminar y ordenar sus pedidos.
Por suerte, ¡otro equipo se encarga de todo lo relacionado con el dinero y el pago!

## 1. Añadir artículo(s) al carrito de la compra del usuario

El MVP debe permitir al usuario añadir artículos a su carrito de la compra.
Puede ser un solo artículo o varios a la vez.
Como se trata de un MVP, la cantidad de cada artículo se indica mediante _repeticiones_.
Si un usuario quiere añadir 2 naranjas, «Oranges» aparecerá dos veces en el iterable de entrada.
Si el usuario ya tiene el artículo en su carrito, la cantidad del carrito debe aumentarse en 1.
Si el artículo es _nuevo_ en el carrito, debe añadirse con una cantidad de 1.

Crea la función `add_items!(<cart>, <items>)`, que recibe como argumentos un diccionario del carrito y un iterable de artículos que añadir.
Debe devolver el diccionario actualizado del carrito de la compra del usuario.

```julia-repl
julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ("Apple", "Apple", "Orange", "Apple", "Banana"))
Dict{String, Int64} with 3 entries:
  "Apple"  => 5
  "Orange" => 2
  "Banana" => 4

julia> additems!(Dict("Banana" => 3, "Apple" => 2, "Orange" => 1),
                 ["Banana", "Orange", "Blueberries", "Banana"])
Dict{String, Int64} with 4 entries:
  "Blueberries" => 1
  "Apple"       => 2
  "Orange"      => 2
  "Banana"      => 5
```

## 2. Actualizar la sección de «ideas» de recetas

La aplicación tiene una sección de «ideas» que se llena con recetas terminadas de distintas cocinas.
El usuario puede seleccionar cualquiera de estas recetas y hacer que todos sus ingredientes se añadan automáticamente a su carrito de la compra.
El jefe de proyecto te ha pedido que crees una forma de editar estas recetas de «ideas», ya que el equipo de contenidos no para de cambiar ingredientes y cantidades.

Crea la función `update_recipes!(<ideas>, <updates>)`, que recibe como argumentos un diccionario de «ideas» y un diccionario de actualizaciones de recetas.
La función debe devolver el diccionario de «ideas» actualizado.

## 3. Enviar el carrito de la compra del usuario a la tienda para su preparación

La aplicación necesita enviar el carrito de un usuario determinado a la tienda para su preparación.
Sin embargo, los empleados de la tienda necesitan saber dónde se puede encontrar cada artículo mediante un código de pasillo único.
El «carrito de preparación» debe ordenarse según los códigos de pasillo de los artículos para ayudar a los empleados a ser más eficientes.

Crea la función `send_to_store(<cart>, <aislecodes>)`, que recibe un carrito de la compra del usuario y un diccionario con los números de pasillo de la tienda.
La función debe devolver un «carrito de preparación» combinado que tenga un par `aislecode => quantity` por cada artículo que pide el cliente.
Los artículos deben aparecer en el orden de sus códigos de pasillo.

```julia-repl
julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> aislecodes = Dict("Orange" => 2.4, "Milk" => 3.3, "Banana" => 2.6, "Apple" => 2.2, "Chocolate" => 5.7);

julia> send_to_store(cart, aislecodes)
5-element Vector{Pair{Float64, Int64}}:
 2.2 => 2
 2.4 => 1
 2.6 => 3
 3.3 => 2
 5.7 => 2
```

## 4. Actualizar el inventario de la tienda para reflejar lo que ha pedido un usuario.

La aplicación no puede limitarse a hacer pedidos de clientes sin fin.
Con el tiempo, la tienda se quedará sin varios productos.
Así que tu MVP debe actualizar el inventario de la tienda cada vez que un usuario envía su pedido a la tienda.
De lo contrario, los clientes pedirán productos que en realidad no están disponibles.

Crea la función `update_store_inventory!(<inventory>, <cart>)`, que recibe un `cart` y un `inventory`.
La función debe reducir las cantidades del inventario de la tienda según el número «ordered» del «cart» y, a continuación, devolver un diccionario con los artículos que se hayan agotado (es decir, los que hayan llegado a `0`).

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2);

julia> update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange" => 0

julia> inventory
Dict{String, Int64} with 4 entries:
  "Milk"   => 2
  "Apple"  => 10
  "Orange" => 0
  "Banana" => 12
```

## 5. Volver a pedir los artículos agotados.

Además de actualizar el inventario, tu aplicación puede ayudar a reponerlo.
Tu MVP debe ser capaz de preparar un mini pedido con los artículos que se hayan agotado tras el pedido de un cliente.
Esto ayudará a que lanzar un pedido grande sea más sencillo.
Es más, a veces hay artículos en promoción por tiempo limitado que no están en la lista de existencias.
Si se han agotado antes de que termine el periodo de promoción, es que han tenido éxito y pueden añadirse a la lista de existencias.

Crea la función `reorder!(<outofstock>, <stock>)`, que recibe `outofstock` y `stock`.
El diccionario `stock` contiene los artículos estándar en existencias y sus cantidades de reposición.
El diccionario `outofstock` es el resultado de `update_store_inventory!`, es decir, un diccionario de artículos con cantidad cero.
Las cantidades de `outofstock` deben actualizarse para reflejar las de `stock` y devolverse.
Además, cualquier artículo de `outofstock` que no esté presente en `stock` debe añadirse a `stock` con una cantidad predeterminada de `100`.

```julia-repl
julia> inventory = Dict("Banana" => 15, "Apple" => 12, "Orange" => 1, "Milk" => 4, "Chocolate" => 2);

julia> cart = Dict("Orange" => 1, "Milk" => 2, "Banana" => 3, "Apple" => 2, "Chocolate" => 2);

julia> stock = Dict("Banana" => 150, "Apple" => 120, "Orange" => 120, "Milk" => 45);

julia> outofstock = update_store_inventory!(inventory, cart)
Dict{String, Int64} with 1 entry:
  "Orange"    => 0
  "Chocolate" => 0

julia> reorder!(outofstock, stock)
Dict{String, Int64} with 1 entry:
  "Orange"    => 120
  "Chocolate" => 100

julia> stock 
Dict{String, Int64} with 5 entries:
  "Milk"      => 45
  "Apple"     => 120
  "Chocolate" => 100
  "Orange"    => 120
  "Banana"    => 150
```
