# Acerca de

Haxe tiene algunos operadores [unarios][unary] y [binarios][binary] para realizar manipulación de bits:

- `&`: AND bit a bit
- `|`: OR bit a bit
- `^`: XOR bit a bit
- `~`: NEGACIÓN bit a bit
- `<<`: desplazamiento a la izquierda
- `>>`: desplazamiento a la derecha
- `>>>`: desplazamiento a la derecha sin signo

[binary]: https://haxe.org/manual/expression-operators-binops.html#bitwise-operators
[unary]: https://haxe.org/manual/expression-operators-unops.html
