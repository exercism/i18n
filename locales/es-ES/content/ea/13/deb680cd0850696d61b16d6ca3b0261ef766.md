# Introducción

[Go](https://golang.org) es un lenguaje de programación compilado y de tipado estático.
Este ejercicio presenta tres características fundamentales del lenguaje: los paquetes, las funciones y las variables.

## Paquetes

Las aplicaciones de Go se organizan en paquetes.
Un paquete es un conjunto de archivos fuente que se encuentran en el mismo directorio.
Todos los archivos fuente de un directorio deben compartir el mismo nombre de paquete.
Cuando se importa un paquete, solo se pueden usar o consultar las entidades (funciones, tipos, variables, constantes) cuyos nombres empiecen por mayúscula.
El estilo recomendado para nombrar en Go es escribir los identificadores en `camelCase`, salvo los que deban ser accesibles desde otros paquetes, que deben escribirse en `PascalCase`.

```go
package lasagna
```

## Variables

Go tiene tipado estático, lo que significa que todas las variables [deben tener un tipo definido](https://en.wikipedia.org/wiki/Type_system) en tiempo de compilación.

Las variables se pueden definir especificando un tipo de forma explícita:

```go
var explicit int // Explicitly typed
```

También puedes usar un inicializador, y el compilador asignará a la variable un tipo que coincida con el del inicializador.

```go
implicit := 10   // Implicitly typed as an int
```

Una vez declaradas, se pueden asignar valores a las variables con el operador `=`.
Una vez declarada, el tipo de una variable no puede cambiar nunca.

```go
count := 1 // Assign initial value
count = 2  // Update to new value

count = false // This throws a compiler error due to assigning a non `int` type
```

## Constantes

Las constantes contienen un dato igual que las variables, pero su valor no puede cambiar durante la ejecución del programa.

Las constantes se definen con la palabra clave `const` y pueden ser números, caracteres, strings o valores booleanos:

```go
const Age = 21 // Defines a numeric constant 'Age' with the value of 21
```

## Funciones

Las funciones de Go aceptan cero o más parámetros.
Los parámetros deben tener un tipo explícito; no hay inferencia de tipos.

Los valores se devuelven desde las funciones con la palabra clave `return`.

Una función se invoca indicando el nombre de la función y pasando argumentos para cada uno de sus parámetros.

Ten en cuenta que Go admite dos tipos de comentarios.
Los comentarios de una sola línea van precedidos de `//`, y los comentarios multilínea se insertan entre `/*` y `*/`.

```go
package greeting

// Hello is a public function.
func Hello (name string) string {
    return hi(name)
}

// hi is a private function.
func hi (name string) string {
    return "hi " + name
}
```
