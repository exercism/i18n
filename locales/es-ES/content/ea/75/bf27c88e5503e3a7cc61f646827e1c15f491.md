# Boutique de moda

## Historia

Llevas una boutique de moda en línea. Se acerca el Black Friday, así que tienes que hacer un recuento de tu inventario para asegurarte de que estás listo.

Cada artículo del inventario se representa con un mapa/diccionario, y todo el inventario es un array de esos mapas/diccionarios.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## Tareas

- Ordenar los artículos por precio
- Encontrar todos los artículos a los que les falta el precio
- Aumentar la cantidad del artículo
- Calcular la cantidad total del artículo
