# Introducción

En Python, [un enum](https://docs.python.org/3/library/enum.html) es un conjunto de nombres que están vinculados a valores `literal` o `constant` únicos. Los enums se definen heredando de una clase `Enum`. Los tipos enum integrados están disponibles en el módulo `enum`, y la clase `Enum` se puede importar con `from enum import Enum`.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
```

Ten en cuenta que los valores de los miembros del enum pueden ser de cualquier tipo de datos, como str, tuple, float, etc.

```python
class Color(Enum):
    RED = 'red'
    GREEN = 'green'
```

Cuando se asigna el mismo valor a dos miembros de un enum, el miembro asignado en último lugar será un alias del miembro ya formado. No está permitido usar el mismo nombre para dos miembros de un enum.

```python
class Color(Enum):
    RED = 1
    GREEN = 2
    ALIAS_OF_RED = 1

Color.ALIAS_OF_RED
#=> <Color.RED: 1>

Color.ALIAS_OF_RED.value
#=> 1
```

Se puede iterar por los miembros del enum con la sintaxis estándar `for member in`:

```python
for member in Color:
    print((member.name, member.value))
#=> (RED, 1)
#=> (GREEN, 2)
```

Los miembros de un enum se pueden comparar con [`is` (_operador de identidad_)](https://www.w3schools.com/python/ref_keyword_is.asp) o `is not`. Los operadores `==` o `!=` (_operadores de igualdad_) funcionan igual.

```python
a = Color.RED

a is Color.RED
#=> True

a == Color.RED
#=> True
```

Para acceder a un miembro de un enum a partir de un valor dado, se puede usar `EnumName(value)`:

```python
g = Color(2)

g is Color.GREEN
#=> True

g
#=> <Color.GREEN: 2>
```
