# Pistas

## General

- La documentación de Python incluye un [tutorial sobre strings][python-str-doc] con una visión general del tipo `str` de Python.
- Los métodos de string [`str.join()`][str-join] y [`str.split()`][str-split] son muy útiles al procesar strings.
- La documentación de Python sobre [tipos de secuencia][common sequence operations] incluye un repaso de las operaciones comunes a todas las secuencias, como `strings`, `lists`, `tuples` y `ranges`.

La tarea consta de cuatro actividades, cada una con un conjunto de texto o palabras con el que trabajar.

## 1. Añadir un prefijo a una palabra

- Los strings cortos se pueden concatenar con el operador `+`.

## 2. Añadir prefijos a grupos de palabras

- Aunque no lo creas, [`str.join()`][str-join] es todo lo que necesitas aquí.  **No hace falta un bucle**.
- Los tests pasarán a tu función una `list`.  No tendrás que modificar esta `list` si das con un buen string delimitador.
- Recuerda que los strings delimitadores se colocan entre los elementos y los «pegan» para formar un único string. Los delimitadores se insertan _sin_ espacio, aunque puedes incluir espacios dentro de ellos.
- Al igual que [`str.split()`][str-split], `str.join()` puede procesar un string de longitud arbitraria, formado por cualquier punto de código unicode. A diferencia de `str.split()`, también puede procesar iterables de longitud arbitraria como `list`, `tuple` y `set`.

## 3. Eliminar un sufijo de una palabra

- Los strings se pueden indexar o cortar en porciones, tanto desde la izquierda (empezando en 0) como desde la derecha (empezando en -1).
- Si quieres el último punto de código de un string de longitud arbitraria, puedes usar `[-1]`.
- Las tres últimas letras de un string se pueden «cortar» con un índice negativo. Por ejemplo: `beautiful'[:-3] == 'beauti`

## 4. Extraer y transformar una palabra

- Usar [`str.split()`][str-split] devuelve una `list` de strings divididos por espacios en blanco.
- Las `lists` son secuencias y se pueden indexar.
- Se puede indexar directamente el resultado de [`str.split()`][str-split]: `'Exercism rocks!'.split()[0] == 'Exercism'`
- ¡Cuidado con la puntuación! Los puntos se pueden eliminar con un corte: `'dark.'[:-1] == 'dark'`
