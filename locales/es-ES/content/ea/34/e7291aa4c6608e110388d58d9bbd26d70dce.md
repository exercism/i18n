# Pistas

## 1. Comprobar el nivel de humedad de la sala

- Una lógica simple de if...else.
- Un operador ternario es suficiente.
- Esta tarea usa una función `error()`, no `throw()`.
- También se necesita la macro `@info`.
- Lee la sección sobre registro de la introducción para ver cómo generar mensajes de registro.

## 2. Comprobar el sobrecalentamiento

- Hay dos condiciones de fallo que comprobar.
- Cada una necesita un `throw()` si falla.
- La macro `@info` es necesaria para el caso de éxito.

## 3. Definir un error personalizado

- Consulta la introducción para ver un ejemplo de cómo definir un error personalizado.
- Los campos y los mensajes de impresión personalizados son posibles, pero no obligatorios.

## 4. Monitorizar la máquina

- Puedes usar las funciones `humiditycheck` y `temperaturecheck`, pero no es estrictamente necesario.
- Si las usas, deberías poder comprobar de forma independiente si ambas funciones lanzan errores y añadir los registros correspondientes.
- Una variable definida fuera de un bloque `try...catch` se puede actualizar desde dentro del bloque si es necesario.
- Recuerda: si falla una comprobación o ambas, solo necesitas lanzar un `MachineError` después de haber añadido los registros.
