# uso de la documentación de módulo

[comment]: # (Este error aparece cuando la solución no incluye @moduledoc para el módulo)

Se recomienda incluir un atributo [`@moduledoc`](https://hexdocs.pm/elixir/writing-documentation.html#module-attributes) que describa la intención del módulo.

- La documentación es un [ciudadano de primera clase](https://hexdocs.pm/elixir/writing-documentation.html) en Elixir: la documentación de Elixir está diseñada para que resulte fácil de leer y de escribir.
- Se admite la sintaxis de Markdown dentro de los atributos de documentación `@moduledoc` y `@doc`.
