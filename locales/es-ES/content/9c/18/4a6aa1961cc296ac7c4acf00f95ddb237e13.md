# Inclusión de código

`circus-acts` usaba `<` para decir que una clase *puede hacer* lo que describe una clase abstracta. No decía nada sobre cómo hacerlo.

`include` es la otra mitad: toma el código real de otra clase y pone una copia en esta.

```sather
class WARM_UP is

   count : INT is return 8; end;

   describe : STR is return count + " counts"; end;

end; -- class WARM_UP

class JAZZ_ROUTINE is

   include WARM_UP;

   -- count and describe are now here too, as though written out.

end; -- class JAZZ_ROUTINE
```

`JAZZ_ROUTINE::count` es 8, sin que `JAZZ_ROUTINE` lo mencione.

## Son dos decisiones distintas

La mayoría de los lenguajes las une: un único `extends` transmite el código y hace que la subclase se pueda usar donde se use la superclase. Sather las mantiene separadas.

| Lo que se escribe | Lo que dice |
| --- | --- |
| `class A < $B` | se puede usar un `A` donde se quiera un `$B` |
| `class A is include B` | `A` empieza con una copia del código de `B` |

O una sin la otra, o las dos. Incluir una clase **no** la convierte en un subtipo: después de `include WARM_UP`, un `JAZZ_ROUTINE` sigue sin poder usarse donde se quiera un `WARM_UP`, y nada pretende lo contrario.

## Cambiar el nombre

Una rutina incluida se puede traer con otro nombre:

```sather
   include WARM_UP count -> warm_up_count;
```

Varias se separan con comas:

```sather
   include WARM_UP count -> warm_up_count, describe -> warm_up_describe;
```

## Dejar una fuera

Cambiar el nombre a *nada* la deja fuera, y así es como se reemplaza:

```sather
class TAP_ROUTINE is

   include WARM_UP describe -> ;

   describe : STR is return "Tap: " + count + " counts"; end;

end; -- class TAP_ROUTINE
```

`count` entra como siempre; `describe` no, así que escribir una aquí no supone ningún conflicto. Sin el `describe -> ;`, el compilador se negaría: dos rutinas con el mismo nombre y los mismos argumentos en una clase son un error, y Sather no va a adivinar cuál querías.

Esa es la diferencia con una sobrescritura en la mayoría de los lenguajes: el reemplazo se anuncia en lugar de quedar implícito.
