# Instrucciones

La estación meteorológica de Wellington va a sustituir su sistema manual de registro de temperaturas por uno digital nuevo.
En el sistema antiguo, los cálculos se hacían a mano.
En el nuevo, se automatizarán.
Entre los cálculos se incluye convertir la temperatura de Celsius a Fahrenheit y hallar la temperatura media.
El nuevo sistema cuenta con sensores para registrar los datos de temperatura en grados Celsius.

La estación meteorológica de Wellington quiere que le ayudes con el nuevo sistema.

## 1. Convierte la temperatura de Celsius a Kelvin

La estación meteorológica tiene una sección en su sitio web destinada a los investigadores.
Los investigadores están interesados en la temperatura en Kelvin.

Kelvin es una unidad que se usa para medir la temperatura.
Usa la misma escala que Celsius, pero con un punto de partida distinto.
Su punto de partida es el cero absoluto, que es 0K (Kelvin) o -273,15°C (Celsius).

Esta tabla muestra la conversión entre Celsius y Kelvin:

| Celsius (°C) | Kelvin (K) |
| ----------- | --------- |
| -273,15     | 0         |
| -100        | 173,15    |
| 0           | 273,15    |
| 100         | 373,15    |

La estación meteorológica quiere que implementes un método que convierta una temperatura de Celsius a Kelvin.

Implementa el método `Temperature#to_kelvin`, que recibe un argumento `celsius` y devuelve la temperatura en Kelvin sumando 273,15 al valor de `celsius` recibido.

```crystal
Temperature.new.to_kelvin(0)
# => 273.15
```

## 2. Redondea la temperatura

El sensor de temperatura de la estación meteorológica es exacto.
Puede medir la temperatura con una precisión de 0,0001°C.
La estación meteorológica solo quiere mostrar la temperatura redondeada a 1 decimal, ya que a la mayoría de los usuarios no les interesa ese nivel de precisión.

La estación meteorológica quiere que implementes un método que redondee la temperatura a 1 decimal.

Implementa el método `Temperature#round`, que recibe un argumento `celsius` y devuelve la temperatura redondeada a 1 decimal.

```crystal
Temperature.new.round(10.1234)
# => 10.1

Temperature.new.round(10.1567)
# => 10.2
```

## 3. Convierte la temperatura de Celsius a Fahrenheit

La estación meteorológica tiene una sección en su sitio web destinada a los turistas.
Los turistas están interesados en la temperatura en Fahrenheit.

Fahrenheit es una unidad de medida de la temperatura.
Tiene una escala distinta a la de Celsius.
0°C son 32°F, y 1 grado Celsius equivale a 1,8 grados Fahrenheit.

Esta tabla muestra la conversión entre Celsius y Fahrenheit:

| Celsius (°C) | Fahrenheit (°F) |
| ----------- | -------------- |
| -273,15     | -459,8         |
| -100        | -148           |
| 0           | 32             |
| 100         | 212            |

La estación meteorológica quiere que implementes un método que convierta temperaturas de Celsius a Fahrenheit.

Implementa el método `Temperature#to_fahrenheit`, que recibe un argumento `celsius` y devuelve la temperatura en Fahrenheit como número entero.

```crystal
Temperature.new.to_fahrenheit(10)
# => 50
```

## 4. Averigua cuántos sensores faltan

Durante la instalación de los sensores de temperatura, los operarios de mantenimiento se dieron cuenta de que faltaban algunos sensores.
Cada unidad de medición de temperatura necesita cuatro sensores de temperatura.
El equipo de mantenimiento contó cuántos sensores tenía, pero necesitaba saber cuántos faltaban.
Les vendría bien ayuda para contar cuántos sensores necesitan comprar para montar otra unidad de medición de temperatura completa.

Implementa el método `Temperature#number_missing_sensors`, que recibe un argumento `number_of_sensors` y devuelve el número de sensores que faltan.

```crystal
Temperature.new.number_missing_sensors(10)
# => 2
```
