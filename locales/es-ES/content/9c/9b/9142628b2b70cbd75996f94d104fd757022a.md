# Pistas

## 1. Desplazar los bits hacia atrás
- Crystal tiene un [operador][shifts] para desplazar bits a la izquierda.

## 2. Aplicar una máscara de bits
- Crystal tiene un [operador AND bit a bit][binary].

## 3. Establecer algunos bits
- Crystal tiene un [operador OR bit a bit][binary].

## 4. Deshacer el XOR
- Se puede deshacer un XOR aplicando un XOR sobre el mismo valor.
- Crystal tiene operadores para el [NOT bit a bit][not] y el [XOR][xor] bit a bit.
