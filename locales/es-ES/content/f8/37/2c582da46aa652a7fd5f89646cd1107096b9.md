# Conceptos de Luhn

Luhn es un algoritmo de validación que combina afirmaciones textuales y numéricas. Las soluciones en Rust favorecen los enfoques funcionales.

## General

### Primitivos

- `&str` y `char`
  - los estudiantes deben comprender la distinción entre un `char` individual y `&str` para poder excluir o incluir correctamente partes de la entrada proporcionada
- número entero
  - entender los números enteros es importante para hacer la validación numérica necesaria
- Boolean
  - esenciales para las afirmaciones de identidad y las comparaciones finales

### Características de los iteradores

- encadenamiento
  - es importante entender aquí las cadenas de iteradores para resolver el problema de forma ordenada.
- `map`, `filter`, turbofish, posiblemente `fold`
  - combinar map y filter proporciona un patrón de diseño fundamental para problemas de validación como este. Las soluciones con `fold` también destacan por ser más breves.
  - en algunas soluciones se necesita el turbofish para indicarle a Rust qué tipo estás creando a partir de una expresión encadenada

## Solución de ejemplo 1

la [solución](https://exercism.org/tracks/rust/exercises/luhn/solutions/7038c269a4af4f5b95ca35a99c5c3b4d) de york

```rust
pub fn is_valid(code: &str) -> bool {
    code.chars()
        .filter(|c| !c.is_ascii_whitespace())
        .rev()
        .try_fold((0, 0), |(num_count, sum), c| {
            c.to_digit(10).map(|x| {
                let double = x * (num_count % 2 + 1);
                let double = if double > 9 { double - 9 } else { double };
                (num_count + 1, sum + double)
            })
        })
        .map_or(false, |(num_count, sum)| num_count >= 2 && sum % 10 == 0)
}
```

## Solución de ejemplo 2

Canónica

```rust
pub fn is_valid(candidate: &str) -> bool {
    if candidate.chars().filter(|c| c.is_ascii_digit()).take(2).count() <= 1
        || candidate.chars().any(|c| !c.is_ascii_digit() && c != ' ')
    {
        return false;
    }

    candidate
        .chars()
        .filter_map(|c| c.to_digit(10))
        .rev()
        .enumerate()
        .map(|(index, digit)| if index % 2 == 0 { digit } else { digit * 2 })
        .map(|digit| if digit > 9 { digit - 9 } else { digit })
        .sum::<u32>()
        % 10
        == 0
}
```
