# Pistas

## General

- Lee sobre la aritmética básica en la [guía oficial de introducción][getting-started-basic-arithmetic].
- Explora los módulos [`Float`][float-functions] y [`Kernel`][kernel-arithmetic-operators] para aprender sobre las funciones y los operadores que trabajan con números decimales.

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

- Las [operaciones aritméticas básicas][kernel-arithmetic-operators] en las que un argumento es un número entero y el otro es un número decimal devuelven un número decimal.

## 2. Calcula un precio con descuento

- Las [operaciones aritméticas básicas][kernel-arithmetic-operators] en las que un argumento es un número entero y el otro es un número decimal devuelven un número decimal.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

- Hay una [función integrada][kernel-trunc] para convertir números decimales en números enteros.
- Hay una [función integrada][float-ceil] para redondear números decimales hacia arriba.

## 4. Calcula el número de días laborables a partir de un presupuesto, una tarifa por hora y un descuento

- Hay una [función integrada][float-floor] para redondear números decimales hacia abajo con la precisión deseada.
