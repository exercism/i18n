# Pistas

## General

- Lee sobre la recursión en la [guía oficial Getting Started][getting-started-recursion].
- Lee sobre la recursión en [elixirschool.com][elixir-school-recursion].
- Usa funciones con varias cláusulas y coincidencia de patrones.
- Intenta dividir un problema en un caso base y un caso recursivo. Por ejemplo, supongamos que quieres contar cuántas galletas hay en el tarro de galletas con un enfoque recursivo. Un caso base es un tarro vacío: tiene cero galletas. Si el tarro no está vacío, el número de galletas del tarro es igual a una galleta más el número de galletas que quedan en el tarro tras quitar una.

## 1. Comprueba cuántos pájaros han visitado hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de una lista con la [coincidencia de patrones][getting-started-pattern-matching].

## 2. Incrementa el recuento de hoy

- Esta tarea no necesita recursión.
- Se puede acceder al primer elemento de una lista con la [coincidencia de patrones][getting-started-pattern-matching].

## 3. Comprueba si hubo un día sin pájaros visitantes

- Usa la recursión para iterar sobre los elementos de la lista hasta encontrar un día sin pájaros visitantes.
- El caso base es una lista vacía.

## 4. Calcula el número total de pájaros visitantes

- Usa la recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.

## 5. Calcula el número de días ajetreados

- Usa la recursión para iterar sobre cada elemento de la lista.
- El caso base es una lista vacía.
- Una función puede tener más de un caso recursivo.
- Usa un [guard][kernel-equal-or-greater-than] para una de las cláusulas de la función.
