# Pistas

## General

- Todas las palabras que necesitas están en los vocabularios [`math`][math] y
  [`math.functions`][math.functions]. Añádelas a tu línea `USING:`.

## 1. Calcula el valor estimado tras el cambio

- Usa `/` (efecto de pila `( x y -- x/y )`) para dividir el presupuesto entre el tipo de cambio.

## 2. Calcula la moneda que queda después de un cambio

- Usa `-` para restar.

## 3. Calcula el valor de los billetes

- Usa `*` para multiplicar.

## 4. Calcula el número de billetes

- `amount` puede ser un número decimal; necesitas un resultado entero.
- Una opción: convierte antes la cantidad a un número entero con
  `floor >integer` y luego divide con `/i`.
- Una alternativa: usa `/i` directamente (con un denominador entero también
  trunca el número decimal) y después conviértelo con `>integer`.

## 5. Calcula lo que queda después de cambiar a billetes

- Usa `mod` para obtener el residuo.

## 6. Calcula el valor tras el cambio

- Calcula el tipo de cambio *total*: toma el `spread` por ciento de
  `exchange-rate` y súmalo a `exchange-rate`.
- Después, llama a `exchange-money` con el presupuesto y el tipo de cambio total.
- Después, llama a `number-of-bills` para redondear a la baja a un número
  entero de billetes de la denominación dada.
- Después, llama a `value-of-bills` para obtener el valor final.
- Los cuatro subcálculos se encadenan de forma natural; si hacer malabares
  con la pila empieza a resultarte incómodo, la forma con locales (`::` con
  parámetros con nombre) va bien aquí.
