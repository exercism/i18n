# Acerca de

Un [bucle while][while-loops] es una instrucción de flujo de control que permite ejecutar código mientras se cumple una determinada condición.
Swift proporciona dos tipos de bucles while: los bucles while y los bucles repeat-while.
La condición del bucle while se evalúa antes de que se ejecute el cuerpo del bucle; si la condición es falsa, el cuerpo del bucle no se ejecutará en absoluto.
Los bucles while en Swift tienen la siguiente estructura:

```swift
while <#condition#> {
  <#code#>
}
```

Aquí el bucle se ejecutará mientras count sea mayor que 0 y, por tanto, imprimirá los números 2, 1 y «Liftoff!».

```swift
var count = 2
while count > 0 {
  print("\(count)…")
  count -= 1
}
print("Liftoff!")

// prints:
// 2…
// 1…
// Liftoff!
```

Un [bucle repeat-while][while-loops] es similar a un bucle while, pero la condición se evalúa después de que se ejecute el cuerpo del bucle.
Esto significa que el cuerpo del bucle siempre se ejecutará al menos una vez, aunque la condición sea falsa.
Los bucles repeat-while en Swift tienen la siguiente estructura:

```swift
repeat {
  <#code#>
} while <#condition#>
```

Aquí el bucle se ejecutará solo una vez, ya que la condición es falsa.
Como es un bucle repeat-while, el cuerpo del bucle se ejecutará una vez antes de que se evalúe la condición.

```swift
var count = 2
repeat {
  print("\(count)…")
} while count < 0
print("Liftoff!")
```
