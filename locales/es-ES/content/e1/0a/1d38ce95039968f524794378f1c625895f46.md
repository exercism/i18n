# Instrucciones

En este ejercicio vas a escribir código para ayudar a una empresa de carteles a crear mensajes personalizados para sus carteles.

## 1. Crea un cartel para una ocasión

Implementa el método `build_sign( )`, que acepta un string como parámetro `occasion` y un string que contiene el nombre de alguien como parámetro `name`. Los dos parámetros se insertarán en una plantilla de string para producir el mensaje del cartel.

```abap
build_sign( occasion = 'Birthday' 
            name     = 'Rob').
" => "Happy Birthday Rob!"
```

## 2. Crea un cartel de cumpleaños

Implementa el método `build_birthday_sign( )`, que acepta una edad y, según cuál sea, determinará parte del mensaje del cartel. Si la edad es 50 o más, el cartel incluirá la palabra _mature_; de lo contrario, incluirá la palabra _young_.

```abap
build_birthday_sign( 45 ).
" => "Happy Birthday! What a young fellow you are."
```

## 3. Crea un cartel de graduación

Implementa el método `graduation_for( )`, que toma un nombre como parámetro de tipo string y un año como parámetro numérico, y usa plantillas de string para crear una frase para un cartel que utiliza un salto de línea para separar las dos líneas del mensaje.

```abap
graduation_for( name = 'Hannah' 
                year = 2022 ).
" => "Congratulations Hannah!\nClass of 2022"
```

## 4. Calcula el coste de un cartel

Implementa la función `cost_of( sign currency )`, que toma un string con el contenido del cartel y un string que representa la moneda.
El cartel tiene un precio base de 20 en la moneda indicada. Además, cada letra cuesta 2. (Los espacios en blanco también se incluyen en el cálculo.)
La frase devuelta incluye el coste de crear el cartel, escrito con dos decimales, seguido del string de la moneda.

```abap
costOf( sign     = 'Happy Birthday Rob!'
        currency = 'euros');
// => "Your sign costs 58.00 euros."
```
