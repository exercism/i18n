# Introducción

## Números

Go contiene tipos numéricos básicos que pueden representar conjuntos de valores enteros o de coma flotante.
Hay distintos tipos en función del tamaño del valor que necesites y de la arquitectura del ordenador en el que se ejecute la aplicación (p. ej., 32 bits y 64 bits).

Para este ejercicio solo vas a tratar con:

- `int`: p. ej., `0`, `255`, `2147483647`.
  Un entero con signo que ocupa al menos 32 bits (rango de valores: -2147483648 a 2147483647).
  Pero esto dependerá de la arquitectura del sistema.
  La mayoría de los ordenadores modernos son de 64 bits, por lo que `int` ocupará 64 bits (rango de valores: -9223372036854775808 a 9223372036854775807).

- `float64`: p. ej., `0.0`, `3.14`.
  Contiene el conjunto de todos los números de coma flotante de 64 bits.

- `uint`: p. ej., `0`, `255`.
  Un entero sin signo que tiene el mismo tamaño que `int` (rango de valores: 0 a 4294967295 para 32 bits y 0 a 18446744073709551615 para 64 bits)

Los números se pueden convertir a otros tipos numéricos mediante la conversión de tipos.

## Operadores aritméticos

Go admite muchos operadores aritméticos estándar:

| Operador | Ejemplo        |
| -------- | -------------- |
| `+`      | `4 + 6 == 10`  |
| `-`      | `15 - 10 == 5` |
| `*`      | `2 * 3 == 6`   |
| `/`      | `13 / 3 == 4`  |
| `%`      | `13 % 3 == 1`  |

En la división entera se descarta el residuo (p. ej., `5 / 2 == 2`).

Go tiene asignación abreviada para los operadores anteriores (p. ej., `a += 5` es una forma abreviada de `a = a + 5`).
Go también admite las instrucciones de incremento y decremento `++` y `--` (p. ej., `a++`).

## Conversión entre tipos

La conversión entre tipos se realiza mediante una función con el nombre del tipo al que te quieres convertir.
Por ejemplo:

```go
var x int = 42 // x has type int
f := float64(x) // f has type float64 (ie. 42.0)
var y float64 = 11.9 // y has type float64
i := int(y) // i has type int (ie. 11)
```

## Operaciones aritméticas con distintos tipos

En muchos lenguajes puedes realizar operaciones aritméticas con variables de distintos tipos, pero en Go esto da un error.
Por ejemplo:

```go
var x int = 42

// this line produces an error
value := float32(2.0) * x // invalid operation: mismatched types float32 and int

// you must convert int type to float32 before performing arithmetic operation
value := float32(2.0) * float32(x)
```
