# Apéndice de instrucciones

## Instrucciones específicas del track

Tienes que definir dos verbos llamados `allergic_to` y `list`.

## Entradas

1. El verbo `allergic_to` es **diádico**, donde:

    - **Argumento izquierdo**: es un string que contiene el nombre del alérgeno.
    - **Argumento derecho**: es la puntuación obtenida.

1. El verbo `list` es **monádico**, donde:

    - El único argumento es la puntuación obtenida.

Tus verbos se llamarán con estos argumentos de esta forma:

```j
  'cats' allergic_to 255
  list 5
```

## Salidas

La salida del verbo `allergic_to` es un **Boolean**

La salida de `list` es una **lista de cajas**
