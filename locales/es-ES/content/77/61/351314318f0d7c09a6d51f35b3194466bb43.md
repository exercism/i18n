# Instrucciones

En este ejercicio ayudas a tu hermana pequeña a corregir su trabajo para el colegio. El profesor busca una puntuación y una gramática correctas, y una elección de palabras excelente.

Tienes cuatro tareas para limpiar y modificar strings.

## 1. Capitaliza el título del trabajo

Cualquier buen trabajo necesita un título bien formateado.
Implementa la función `capitalize_title(<title>)`, que toma un título `str` como parámetro y pone en mayúscula la primera letra de cada palabra.
Esta función debe devolver un `str` en formato de título.


```python
>>> capitalize_title("my hobbies")
"My Hobbies"
```

## 2. Comprueba si cada frase termina con un punto

Quieres asegurarte de que la puntuación del trabajo sea perfecta.
Implementa la función `check_sentence_ending()`, que toma `sentence` como parámetro. Esta función debe devolver un `bool`.


```python
>>> check_sentence_ending("I like to hike, bake, and read.")
True
```

## 3. Limpia los espacios

Para que el trabajo parezca profesional, hay que eliminar los espacios innecesarios.
Implementa la función `clean_up_spacing()`, que toma `sentence` como parámetro.
La función debe eliminar los espacios adicionales tanto al principio como al final de la frase y devolver un nuevo `str` con la frase actualizada.


```python
>>> clean_up_spacing(" I like to go on hikes with my dog.  ")
"I like to go on hikes with my dog."
```

## 4. Sustituye palabras por un sinónimo

Para que el trabajo sea _aún mejor_, puedes sustituir algunos de los adjetivos por sus sinónimos.
Escribe la función `replace_word_choice()`, que toma `sentence`, `old_word` y `new_word` como parámetros.
Esta función debe reemplazar todas las apariciones de `old_word` por `new_word` y devolver un nuevo `str` con la frase actualizada.


```python
>>> replace_word_choice("I bake good cakes.", "good", "amazing")
"I bake amazing cakes."
```
