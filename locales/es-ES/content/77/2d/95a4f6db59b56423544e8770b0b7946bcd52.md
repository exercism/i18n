# Introducción

## Funciones

En Gleam, las funciones se definen con la sintaxis `pub fn`.

```gleam
pub fn add(x: Int, y: Int) -> Int {
  x + y
}
```

Esta función recibe dos argumentos, ambos de tipo `Int`, y devuelve un valor de tipo `Int`. En Gleam no existe la palabra clave `return`: el valor de la última expresión de una función siempre se devuelve de forma implícita.

Las anotaciones de tipo de los argumentos y el tipo devuelto son opcionales, y Gleam siempre comprobará los tipos de tu código por completo. Normalmente, quienes programan en Gleam añaden anotaciones de tipo a sus funciones para mayor claridad, pero puedes omitirlas si lo prefieres.

```gleam
pub fn add(x, y) {
  x + y
}
```

Se puede llamar a una función con la sintaxis `function_name(argument1, argument2)`.

```gleam
pub fn double(x: Int) -> Int {
  // Call the add function defined above
  add(x, x)
}
```

## Variables

En Gleam, las variables se definen con la sintaxis `let name = expression`.

```gleam
pub fn main() {
  let count = 1
}
```

Las variables se pueden declarar con anotaciones de tipo. Igual que en los argumentos de una función, son opcionales, aunque la mayoría de quienes programan en Gleam omiten las anotaciones de tipo de las variables por brevedad.

```gleam
pub fn main() {
  let count: Int = 1
}
```

## Literales de string

En Gleam, los strings se escriben con comillas dobles.

```gleam
pub fn greeting() {
  "Hello, world!"
}
```

## Comentarios de código

Los comentarios sirven para dejar notas a otros desarrolladores que lean el código fuente. En Gleam, los comentarios son de una sola línea y van precedidos de `//`.

```gleam
pub fn main() {
  // This is a comment
  let x = 1
}
```
