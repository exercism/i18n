# Introducción

JavaScript es un lenguaje dinámico que admite los estilos orientado a objetos, imperativo y declarativo (por ejemplo, la programación funcional).

## (Re)asignación

Hay varias formas principales de asignar valores a nombres en JavaScript: mediante variables o constantes. En Exercism, las variables siempre se escriben en [camelCase][wiki-camel-case] y las constantes en [SCREAMING_SNAKE_CASE][wiki-snake-case]. No hay una guía oficial que seguir, y distintas empresas y organizaciones tienen distintas guías de estilo. _Escribe las variables como prefieras_. La ventaja de escribirlas tal y como se preparan los ejercicios es que se resaltarán de forma distinta en la interfaz web y en la mayoría de los entornos de desarrollo integrados (IDE).

Las variables en JavaScript se pueden definir con la palabra clave [`const`][mdn-const], [`let`][mdn-let] o [`var`][mdn-var].

Cuando usas `let` o `var`, una variable puede hacer referencia a distintos valores a lo largo de su existencia. Por ejemplo, `myFirstVariable` se puede definir y redefinir muchas veces con el operador de asignación `=`:

```javascript
let myFirstVariable = 1;
myFirstVariable = 'Some string';
myFirstVariable = new SomeComplexClass();
```

A diferencia de `let` y `var`, las variables que se definen con `const` solo se pueden asignar una vez. Así es como se definen las constantes en JavaScript.

```javascript
const MY_FIRST_CONSTANT = 10;

// Cannot be re-assigned.
MY_FIRST_CONSTANT = 20;
// => TypeError: Assignment to constant variable.
```

> 💡 En un ejercicio de aprendizaje posterior se explora y se explica la diferencia entre la _asignación_ o _vinculación_ de una constante y el _valor_ de una constante.

## Declaración de funciones

En JavaScript, las unidades de funcionalidad se encapsulan en _funciones_, y normalmente las funciones que van juntas se agrupan en el mismo fichero. Estas funciones pueden recibir parámetros (argumentos) y pueden _devolver_ un valor con la palabra clave `return`. Las funciones se llaman usando la sintaxis `()`.

```javascript
function add(num1, num2) {
  return num1 + num2;
}

add(1, 3);
// => 4
```

> 💡 En JavaScript hay _muchas_ formas distintas de declarar una función. Esas otras formas no se parecen a usar la palabra clave `function`. El track intenta presentarlas poco a poco, pero si ya las conoces, puedes usar la que prefieras. En la mayoría de los casos, usar una u otra no es mejor ni peor.

## Exponer a otros ficheros

Para que una `function`, una constante o una variable estén disponibles en _otros ficheros_, hay que [exportarlas][mdn-export] con la palabra clave `export`. Después, otro fichero puede [importarlas][mdn-import] con la palabra clave `import`. Esto también se conoce como sistema de módulos. Un buen ejemplo es cómo funcionan todos los tests. Cada ejercicio tiene al menos un fichero, por ejemplo `lasagna.js`, que contiene la _implementación_. Además, hay al menos otro fichero, por ejemplo `lasagna.spec.js`, que contiene los _tests_. Este fichero _importa_ las entidades públicas (es decir, exportadas) para probar la implementación:

```javascript
// file.js
export const MY_VALUE = 10;

export function add(num1, num2) {
  return num1 + num2;
}

// file.spec.js
import { MY_VALUE, add } from './file';

add(MY_VALUE, 5);
// => 15
```
