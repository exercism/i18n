# Anexo a las instrucciones

## Implementación

Este ejercicio requiere que crees una estructura de datos de lista enlazada que se pueda recorrer con un iterador.

1. Implementa la propiedad `Count`: no debe ser posible cambiar su valor desde fuera.
2. Implementa el método `Push(T value)`, que añade un valor al principio de la lista.
3. Implementa el método `Pop()`, que elimina y devuelve un valor del principio.
4. Añade un constructor que permita inicializar la lista con un solo valor, o con un iterable.
5. Implementa la interfaz `IEnumerable<T>`. Para más información, consulta [ienumerable].
6. Asegúrate de que el método `Reverse()` esté disponible.

[ienumerable]: https://docs.microsoft.com/en-us/dotnet/api/system.collections.generic.ienumerable-1
