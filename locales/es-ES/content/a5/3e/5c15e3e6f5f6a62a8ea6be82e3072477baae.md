# Instrucciones

Refactoriza una impresora de libro mayor.

El ejercicio del libro mayor es un ejercicio de refactorización.
Hay un código que imprime un libro mayor con un buen formato, dados una configuración regional (estadounidense o neerlandesa) y una moneda (dólar estadounidense o euro).
Sin embargo, el código está bastante mal escrito, aunque, sorprendentemente, siempre pasa el conjunto de pruebas.

Reescribe este código.
Recuerda que, al refactorizar, el truco consiste en dar pasos pequeños que hagan que las pruebas sigan pasando.
Así siempre puedes volver rápidamente a una versión que funcione.
Las herramientas de control de versiones como git también pueden ayudarte en esto.

Lleva un registro de los cambios que hayas hecho y añade un comentario al ejercicio con ese registro; esto ayudará a quienes lo revisen.
