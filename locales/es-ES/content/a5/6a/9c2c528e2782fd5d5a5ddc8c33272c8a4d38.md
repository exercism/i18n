# Introducción

Los caracteres en Factor son números enteros, es decir, puntos de código Unicode, así que los operadores numéricos `<`, `>`, `=` te dan directamente un orden que distingue mayúsculas de minúsculas. El vocabulario [`unicode`][unicode] añade predicados que tienen en cuenta Unicode y la conversión de mayúsculas y minúsculas de caracteres sueltos.

## Predicados de caracteres

```
LETTER?  ( c -- ? )    ! uppercase letter
letter?  ( c -- ? )    ! lowercase letter
Letter?  ( c -- ? )    ! letter, either case
digit?   ( c -- ? )    ! decimal digit
digit>   ( c -- n )    ! the integer value of a digit char
blank?   ( c -- ? )    ! whitespace
```

```factor
USING: unicode ;

CHAR: A LETTER? .    ! => t
CHAR: a letter? .    ! => t
CHAR: 7 digit?  .    ! => t
CHAR: 7 digit>  .    ! => 7
```

## Conversión de mayúsculas y minúsculas

`ch>upper` y `ch>lower` cambian un solo carácter. `>upper` y `>lower`, a nivel de string, los aplican a todos los caracteres de un string.

```factor
CHAR: a ch>upper .   ! => 65   (which is CHAR: A)
"Hello" >upper .     ! => "HELLO"
```

`capitalize` pasa todo un string a minúsculas y después pone en mayúscula su primer carácter, lo que da la capitalización de una sola palabra:

```factor
"hELLO" capitalize .   ! => "Hello"
```

## Literales de carácter

`CHAR: A` se convierte al punto de código entero de `A`. Para los caracteres con nombre, usa los nombres `space`, `tab`, `\n`, etc.:

```factor
CHAR: A .        ! => 65
CHAR: space .    ! => 32
CHAR: \n .       ! => 10
```

## Símbolos

Cuando una palabra tiene que devolver una etiqueta en lugar de un valor, por ejemplo `yes`/`no`/`maybe` en vez de un Boolean, declara cada etiqueta como un *símbolo*. Un símbolo es una palabra que se apila a sí misma cuando se llama, y dos símbolos se consideran iguales solo si tienen el mismo nombre.

```factor
USING: kernel ;

SYMBOLS: yes no maybe ;

yes .    ! => yes
yes yes = .    ! => t
yes no = .     ! => f
```

`SYMBOL: name` declara uno; `SYMBOLS: a b c ;` declara varios.
