# Anexo a las instrucciones

## Implementación

Para completar este ejercicio, tienes que crear el tipo de datos `LinkedList` e implementar las siguientes funciones:

- `new`
- `cons`
- `nil`
- `fromList`
- `head`
- `tail`
- `isNil`
- `reverseLinkedList`
- `toList`

Encontrarás una declaración de tipo provisional y las firmas de tipo ya en su sitio, pero depende de ti definir las funciones y crear un tipo de datos con sentido.
