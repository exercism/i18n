# Aprender PowerShell

Un buen punto de partida para aprender PowerShell es elegir un recurso de aprendizaje en la [learning section][] del sitio web de PowerShell.
Contiene una gran cantidad de información y enlaces a una amplia variedad de temas sobre PowerShell.

PowerShell también cuenta con un sistema de ayuda autodocumentado muy completo.
Puedes explorar gran parte de lo que ofrece PowerShell con el cmdlet `Get-Help`.
Desde PowerShell, prueba lo siguiente:

```PowerShell
Get-Help about
```

Verás unas 3 páginas de temas que puedes explorar.
Otras dos funciones que te resultarán muy útiles son:

- Get-Command
- Get-Member

¿Quieres saber qué hacen?
Prueba `Get-Help Get-Command` y `Get-Help Get-Member`, por supuesto.

## Verbos y sustantivos de PowerShell

PowerShell sigue un esquema bastante estricto de verbo-sustantivo para nombrar sus cmdlets.
Al principio, esto puede resultar chocante para los programadores con experiencia.
Aunque puedes llamar a tus funciones como quieras, familiarizarte con los verbos estándar y adoptarlos mejorará tu forma de programar en PowerShell.

Para ver una lista de todos los verbos aprobados, solo tienes que ejecutar:

```PowerShell
Get-Verb
```
