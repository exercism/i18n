# Acerca de

[Los diccionarios][dictionaries] son uno de los tipos de colección principales de Swift.
Un diccionario almacena asociaciones no ordenadas entre claves únicas y valores correspondientes.
Todas las claves de un diccionario deben ser del mismo tipo, y todos los valores también deben compartir el mismo tipo.

Los literales de diccionario se escriben como pares `key: value` separados por comas y encerrados entre corchetes:

```swift
var addresses: Dictionary<String, String> = [
    "The Munsters": "1313 Mockingbird Lane",
    "The Simpsons": "742 Evergreen Terrace",
    "Buffy Summers": "1630 Revello Drive"
]

var sequences: [String: [Int]] = [
    "Euler's totient": [1, 1, 2, 2, 4, 2, 6, 4],
    "Lazy caterer": [1, 2, 4, 7, 11, 16, 22, 29, 37],
    "Carmichael": [561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841]
]

let constants = [
    "pi": 3.14159,
    "e": 2.71828,
    "phi": 1.618033,
    "avogadro": 6.02214076e23
]
```

Los tipos de diccionario se pueden escribir explícitamente de dos formas: `Dictionary<Key, Value>` o la sintaxis abreviada `[Key: Value]`.

Para crear un diccionario vacío, especifica sus tipos de clave y valor explícitamente:

```swift
var emptyDict1: [Int: Int] = [:]
var emptyDict2 = [Character: String]()
var emptyDict3 = Dictionary<Int, Double>()
```

## Acceder a los valores

Puedes acceder a los valores usando la notación de subíndice: coloca la clave dentro de corchetes después del nombre del diccionario.
Como una clave puede no existir en el diccionario, el acceso por subíndice devuelve un *opcional* (`Value?`).
Si la clave está presente, Swift devuelve el valor envuelto; si no, devuelve `nil`:

```swift
let munster: String? = addresses["The Munsters"]
// Returns Optional("1313 Mockingbird Lane")

let carmichael = sequences["Carmichael"]
// Returns Optional([561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841])

let planck = constants["planck"]
// Returns nil
```

Para evitar trabajar con opcionales, puedes proporcionar un valor predeterminado usando el parámetro `default`:

```swift
let e: Double = constants["e", default: 0]
// Returns 2.71828

let hoagie: [Int] = sequences["Hoagie", default: []]
// Returns []

let betty = addresses["Betty Cooper", default: "Address unknown"]
// Returns "Address unknown"
```

## Modificar diccionarios

Para diccionarios mutables declarados con `var`, puedes añadir o actualizar pares clave-valor usando la asignación por subíndice:

```swift
sequences["Euler's totient"]?.append(contentsOf: [6, 4])
// sequences["Euler's totient"] is now [1, 1, 2, 2, 4, 2, 6, 4, 6, 4]

addresses["Betty Cooper"] = "111 Queens Ave."
addresses["Betty Cooper", default: "Address unknown"]
// Returns "111 Queens Ave."

constants["Gelfond's"] = 23.140692
// Compiler error: Cannot assign through subscript: 'constants' is a 'let' constant
```

## Iterar sobre un diccionario

Puedes iterar a través de cada par clave-valor de un diccionario usando un bucle `for-in`.
Cada elemento se proporciona como una tupla `(key, value)`:

```swift
for (name, address) in addresses {
    print("\(name) lives at \(address)")
}
```

## Ordenar diccionarios

Como los diccionarios no están ordenados, ordenarlos produce un array de pares clave-valor.
Puedes pasar un closure al método `sorted(by:)` que compara dos tuplas `(key, value)` y devuelve `true` si la primera tupla debe aparecer antes que la segunda:

```swift
func sortByNameLengthThenValue(_ lhs: (key: String, value: Double), _ rhs: (key: String, value: Double)) -> Bool {
    let left = lhs.value + Double(lhs.key.count)
    let right = rhs.value + Double(rhs.key.count)
    return left < right
}

let sortedConstants = constants.sorted(by: sortByNameLengthThenValue)
```
