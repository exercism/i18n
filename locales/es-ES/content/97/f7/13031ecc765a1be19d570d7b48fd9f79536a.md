# Tests

Para ejecutar el test con DrRacket, basta con abrir el fichero de test y hacer clic en el botón «Run» de la esquina superior derecha.

Para ejecutar el test desde la línea de comandos, ejecútalo desde el directorio del ejercicio con el siguiente comando:

```
raco test <exercise>-test.rkt
```

donde `<exercise>` se sustituye por el slug del ejercicio.
