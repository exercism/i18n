# Sugerencias

## General

- [Esta página][pattern-matching] ofrece una buena introducción a la coincidencia de patrones en F#.

## 1. Responder a una suposición correcta

- Puedes usar un [patrón constante][constant-patterns] para hacer coincidir un número concreto.

## 2. Responder a una suposición cercana

- Puedes usar un [patrón constante][constant-patterns] o un [patrón de variable][variable-patterns] y una [guarda][guards].

## 3. Responder a suposiciones demasiado bajas

- Puedes usar una combinación de un [patrón de variable][variable-patterns] y una [guarda][guards].

## 4. Responder a suposiciones demasiado altas

- Puedes usar una combinación de un [patrón de variable][variable-patterns] y una [guarda][guards].
