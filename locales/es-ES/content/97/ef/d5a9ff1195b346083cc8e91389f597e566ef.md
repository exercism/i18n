## Herramientas interactivas de jq

Proporciona alguna entrada y experimenta con varios filtros de jq para ver qué se consigue.

- [jq playground][jqplay], una experiencia de «pruébalo en línea».
- [ijq][ijq], herramienta interactiva de jq, como jqplay para la línea de comandos.
- [jqp][jqp] es otra herramienta de línea de comandos: usa gojq como backend, que no es 100 % compatible con el jq original.

## Otras herramientas de procesamiento de JSON

- [gron][gron]: «aplana» JSON en una secuencia de asignaciones individuales, lo que permite usar herramientas orientadas a líneas (grep, etc.) para procesarlo.
- [jo][jo]: una pequeña utilidad para crear objetos JSON a partir de variables de shell.
- [jello][jello]: jello es similar a jq, salvo que jello usa la sintaxis estándar de dict y list de Python.
