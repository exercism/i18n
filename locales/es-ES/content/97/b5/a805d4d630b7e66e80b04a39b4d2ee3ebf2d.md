# Introducción

## Números de coma flotante

Un número de coma flotante es un número con cero o más dígitos detrás del separador decimal. Algunos ejemplos son `-2.4`, `0.1`, `3.14`, `16.984025` y `1024.0`.

Los distintos tipos de coma flotante pueden almacenar un número diferente de dígitos después del separador decimal. A esto se le llama su precisión.

C# tiene tres tipos de coma flotante:

- `float`: 4 bytes (precisión de ~6-9 dígitos). Se escribe como `2.45f`.
- `double`: 8 bytes (precisión de ~15-17 dígitos). Es el tipo más común. Se escribe como `2.45` o `2.45d`.
- `decimal`: 16 bytes (precisión de 28-29 dígitos). Normalmente se usa cuando se trabaja con datos monetarios, ya que su precisión reduce la posibilidad de errores de redondeo. Se escribe como `2.45m`.

Como puede verse, cada tipo puede almacenar un número distinto de dígitos. Por ejemplo, si intentas almacenar PI en un `float`, solo se almacenarán los 6 primeros decimales (con el último dígito almacenado redondeado).

## Bucles while

En este ejercicio puede que quieras usar un bucle. Hay varias formas de escribir bucles en C#, pero el bucle `while` es el más adecuado aquí:

```csharp
int x = 23;

while (x > 10)
{
    // Execute logic if x > 10
    x = x - 2;
}
```

## Bucles do/while

Si el código de un bucle debe ejecutarse siempre al menos una vez, se puede usar un bucle `do`/`while`:

```csharp
int x = 23;

do
{
    // Execute body, repeating only if x > 10
    x = x - 2;
} while (x > 10);
```
