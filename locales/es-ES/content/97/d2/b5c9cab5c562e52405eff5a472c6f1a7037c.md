# Instrucciones

En este ejercicio vas a organizar carreras entre distintos tipos de coches teledirigidos. Cada coche tiene sus propias características de velocidad y consumo de batería.

Los coches empiezan con la batería llena (100%). Cada vez que conduces el coche con el mando a distancia, este recorre en metros la velocidad del coche y reduce el porcentaje de batería restante en su consumo de batería.

Si la batería de un coche está por debajo de su porcentaje de consumo de batería, ya no puedes conducir el coche.

Cada circuito de carreras tiene su propia longitud. Los coches se ponen a prueba comprobando si pueden terminar el circuito sin quedarse sin batería.

## 1. Crea un coche teledirigido

Define una lista `car` con los siguientes elementos:

- speed
- battery_drain
- battery
- distance_traveled

Permite crear un coche teledirigido definiendo una función `new_car` que toma la velocidad del coche en metros y el porcentaje de consumo de batería como sus dos parámetros, y devuelve una lista `car`.

Para un coche nuevo, la batería está al 100% y la distancia recorrida es cero.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
```

## 2. Crea un circuito de carreras

Define otra lista llamada `track` con el único elemento `track_length`.
Permite crear un circuito de carreras definiendo una función `new_track` que toma la distancia del circuito en metros:

```R
track_length <- 800
track <- new_track(track_length)
str(track)
#> List of 1
#>  $ track_length: num 800
```

## 3. Comprueba si la batería está agotada

Implementa la función `battery_drained()` que indica si la batería está agotada.
Se considera que una batería está agotada si no queda suficiente para moverse una vez más.

```R
speed <- 5;
battery_drain <- 2;
car <- new_car(speed, battery_drain);
car <- drive(car);

battery_drained(car);
#> [1] FALSE
```

## 4. Conduce el coche

Implementa la función `drive` que actualiza el número de metros recorridos según la velocidad del coche y reduce la batería según su consumo.
Si no queda batería suficiente para conducir una vez más, el coche no se moverá.

```R
speed <- 5
battery_drain <- 2
car <- new_car(speed, battery_drain)
car <- drive(car)
str(car)
#> List of 4
#>  $ speed             : num 5
#>  $ battery_drain     : num 2
#>  $ battery           : num 98
#>  $ distance_traveled : num 5
```

## 5. Comprueba si un coche teledirigido puede terminar una carrera

Para terminar una carrera, un coche tiene que ser capaz de recorrer su longitud. Esto significa no agotar su batería antes de haber cruzado la línea de meta. 

Implementa la función `can_finish` que toma un `car` y un `track` como sus parámetros y devuelve `TRUE` si el coche puede terminar la carrera; en caso contrario, devuelve `FALSE`.

Supón que estás en la línea de salida de la carrera y arrancas el motor del coche para la carrera. Ten en cuenta que puede que la batería del coche no esté necesariamente llena al empezar la carrera.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)

name <- "track1"
track_length <- 100
track <- new_track(track_length)

can_finish(car, track)
#> [1] TRUE

# partial battery charge
car$battery <- 50
can_finish(car, track)
#> [1] FALSE
```

## 6. Guarda si el coche puede terminar un circuito con la batería llena

Has creado varios circuitos de distintas longitudes y necesitas guardar si tu coche puede completarlos con la batería llena.

Implementa la función `store_track` que toma un coche, un circuito y un nombre de circuito, y devuelve un coche actualizado con un elemento adicional.
Este elemento debe tener el `name` del circuito, y el valor debe ser una sublista con el `track_length` y si el coche lo puede `complete`.

Puede que el coche que se pasa como argumento no esté completamente cargado, así que asegúrate de restablecer la batería y la distancia recorrida antes de usarlo.

```R
speed <- 5
battery_drain <- 5
car <- new_car(speed, battery_drain)
car$battery <- 50

name <- "track1"
track_length <- 100
track <- new_track(track_length)

track1 <- store_track(car, track, "Imola")
str(track1)
#> List of 5
#>  $ speed             : num 5
#>  $ battery_drain     : num 5
#>  $ battery           : num 100
#>  $ distance_traveled : num 0
#>  $ Imola             :List of 2
#>   ..$ track_length: num 100
#>   ..$ complete    : logi TRUE
```
