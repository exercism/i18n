# Instrucciones

En este ejercicio, vas a escribir un poco de código para ayudarte a prepararte para comprar un vehículo.

Tienes tres tareas: una para determinar si necesitas un carné, otra para ayudarte a elegir entre dos vehículos y otra para estimar el precio aceptable de un vehículo de segunda mano.

## 1. Determina si necesitarás un carné de conducir

Algunos tipos de vehículos requieren un carné de conducir para conducirlos.
Supón que solo los tipos `"car"` y `"truck"` requieren carné; todo lo demás se puede conducir sin carné.

Implementa la función `needs_license(kind)`, que recibe el tipo de vehículo como string y devuelve un Boolean que indica si necesitas un carné para ese tipo de vehículo.

```cpp
needs_license("car")
// => true

needs_license("bike")
// => false

needs_license("truck")
// => true
```

## 2. Elige entre dos posibles vehículos que comprar

Evalúas tus opciones entre los vehículos disponibles.
Consigues reducirlas a dos, pero necesitas ayuda para tomar la decisión final.
Para ello, implementa la función `choose_vehicle(option1, option2)`, que recibe dos vehículos como argumentos y devuelve una decisión que incluye la opción que va primero en orden lexicográfico.

```cpp
choose_vehicle("Wuling Hongguang", "Toyota Corolla")
// => "Toyota Corolla is clearly the better choice."

choose_vehicle("Volkswagen Beetle", "Volkswagen Golf")
// => "Volkswagen Beetle is clearly the better choice."
```

La cadena devuelta debe seguir el patrón de «<CHOSEN_VEHICLE> is clearly the better choice.», donde `<CHOSEN_VEHICLE>` es la opción elegida entre los argumentos pasados.

## 3. Calcula una estimación del precio de un vehículo de segunda mano

Ahora que has tomado una decisión, quieres asegurarte de conseguir un precio justo en el concesionario.
Como te interesa comprar un vehículo de segunda mano, el precio depende de la antigüedad del vehículo.
Para una estimación aproximada, supón que, si el vehículo tiene menos de 3 años, cuesta el 80 % del precio original que tenía cuando era nuevo.
Si tiene al menos 10 años, cuesta el 50 %.
Si el vehículo tiene al menos 3 años pero menos de 10, cuesta el 70 % del precio original.

Implementa la función `calculate_resell_price(original_price, age)`, que aplica esta lógica usando `if`, `else if` y `else` (hay otras formas si quieres practicar).
Recibe el precio original y la antigüedad del vehículo como argumentos y devuelve el precio estimado en el concesionario.

```cpp
calculate_resell_price(1000, 1)
// => 800

calculate_resell_price(1000, 5)
// => 700

calculate_resell_price(1000.0, 15)
// => 500
```

> Nota: el valor devuelto es de tipo `double`.
