# Depurar en local

Cuando ejecutas las pruebas del track de Bash con [Bats](https://github.com/bats-core/bats-core), Bats captura tanto STDOUT como STDERR para las aserciones de salida.

```exercism/caution
Esto funciona en local con `bats`, pero **no** en el editor en línea de Exercism.
```

Si quieres imprimir la salida de depuración sin afectar al resultado de la prueba, escríbela en el descriptor de archivo (fd) 3.

```bash
echo 'debug message' >&3
```

Bats muestra la salida escrita en el fd 3 durante la ejecución de las pruebas, pero no incluye esa salida en aserciones como `assert_output`.

Ejemplo de ejecución:

```none
$ bats hello_world.bats
hello_world.bats
 ✓ Say Hi!
debug message
1 test, 0 failures
```

Esto resulta útil cuando ejecutas las pruebas en local.
