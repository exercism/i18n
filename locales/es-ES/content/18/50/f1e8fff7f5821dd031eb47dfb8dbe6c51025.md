# Introducción

Una interfaz es un tipo que contiene miembros que definen un grupo de funcionalidad relacionada. Distancia el uso de una clase de la implementación, lo que permite múltiples implementaciones diferentes o la compatibilidad con algún comportamiento genérico, como el formato, la comparación o la conversión.

La sintaxis de una interfaz es similar a la de una clase o una estructura, salvo que los métodos y las propiedades aparecen solo como la firma y no se proporciona ningún cuerpo.

```csharp
public interface ILanguage
{
    string LanguageName { get; set; }
    string Speak();
}

public class ItalianTaveller : ILanguage, ICloneable
{
    public string LanguageName { get; set; } =  "Italiano";

    public string Speak()
    {
        return "Ciao mondo";
    }

    public object Clone()
    {
        ItalianTaveller it = new ItalianTaveller();
        it.LanguageName = this.LanguageName;
        return it;
    }
}
```

Todas las operaciones definidas por la interfaz deben implementarse.

Las interfaces pueden contener métodos y propiedades de instancia, entre otros miembros.
