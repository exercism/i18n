# Introducción

Una excepción definida por el usuario es cualquier clase definida en tu código que derive de `System.Exception`. Está sujeta a todas las reglas de la herencia de clases, pero además el compilador y el entorno de ejecución del lenguaje tratan estas clases de una forma especial que permite lanzar y capturar sus instancias fuera del flujo de control normal, como se explica en el ejercicio `exceptions`.

Las excepciones definidas por el usuario se usan a menudo para transportar información adicional, como un mensaje y otros datos relevantes, que esté a disposición de las rutinas que las capturan.
