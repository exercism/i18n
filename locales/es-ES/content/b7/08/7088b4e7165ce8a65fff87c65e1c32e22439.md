# Introducción

Swift ofrece una variación de su sintaxis a la hora de trabajar con closures, conocida como closures finales. Los closures finales surgen cuando el último parámetro de la lista de parámetros de una función tiene un tipo de función. En ese caso, si se pasa un closure, el closure puede escribirse _después_ del paréntesis de cierre y se omite la etiqueta del argumento. Ten en cuenta que si la función tiene un solo parámetro, los paréntesis pueden omitirse por completo.

```swift
func fetchURL(_ urlString: String,
              uponReceipt handleResult: (String) -> ()
             )  -> () {
  if let url = URL(string: urlString), let htmlString = fetch(url) {
    handleResult(htmlString)
  }
}

fetchURL("https://www.swift.org") { print($0) }
// prints the fetched html string

["apple", "ball", "carrot"].sorted { $0.count < $1.count }
```
