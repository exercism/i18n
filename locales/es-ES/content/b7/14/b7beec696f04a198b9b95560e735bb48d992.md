# Instructions

Llevas una boutique de moda online. Tu gran periodo de rebajas anual está a punto de empezar, así que tienes que hacer inventario para asegurarte de que tienes todo preparado.

Cada artículo del inventario se representa con un map, y el inventario completo es un array de esos maps.

```elixir
%{
  name: "White Shirt",
  price: 40,
  quantity_by_size: %{s: 3, m: 7, l: 8, xl: 4}
}
```

## 1. Ordena los artículos por precio

Implementa la función `sort_by_price/1`. Debe recibir el inventario y devolverlo ordenado por el precio del artículo, en orden ascendente.

```elixir
BoutiqueInventory.sort_by_price([
  %{price: 65, name: "Maxi Brown Dress", quantity_by_size: %{}},
  %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
  %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
  %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}}
])

# => [
#      %{price: 20, name: "Bamboo Socks Cats", quantity_by_size: %{}},
#      %{price: 50, name: "Red Short Skirt", quantity_by_size: %{}},
#      %{price: 50, name: "Black Short Skirt", quantity_by_size: %{}},
#      %{price: 65, name: "Maxi Brown Dress", price: 65, quantity_by_size: %{}}
#    ]
```

## 2. Encuentra todos los artículos a los que les falta el precio

Después de ordenar tu inventario por precio, te diste cuenta de que debiste cometer un error al hacer el inventario y te olvidaste de rellenar el precio de algunos artículos.

Implementa la función `with_missing_price/1`. Debe recibir el inventario y devolver un array de artículos que no tienen precio.

```elixir
BoutiqueInventory.with_missing_price([
  %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
  %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
  %{price: nil, name: "Denim Skirt", quantity_by_size: %{}},
  %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
])

# => [
#      %{price: nil, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: nil, name: "Denim Skirt", quantity_by_size: %{}}
#    ]
```

## 3. Actualiza los nombres de los artículos

Te has dado cuenta de que en el nombre de algunos artículos aparece una palabra que ya no te gusta usar. Ahora tienes que actualizar todos los nombres de artículos que contengan esa palabra.

Implementa la función `update_names/3`. Debe recibir el inventario, la palabra antigua que quieres eliminar y una palabra nueva que quieres usar en su lugar. Debe devolver un array de artículos con los nombres actualizados.

```elixir
BoutiqueInventory.update_names(
  [
    %{price: 40, name: "Black T-shirt", quantity_by_size: %{}},
    %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
    %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
    %{price: 40, name: "Orange T-shirt", quantity_by_size: %{}}
  ],
  "T-shirt",
  "Tee"
)

# => [
#      %{price: 40, name: "Black Tee", quantity_by_size: %{}},
#      %{price: 70, name: "Denim Pants", quantity_by_size: %{}},
#      %{price: 65, name: "Denim Skirt", quantity_by_size: %{}},
#      %{price: 40, name: "Orange Tee", quantity_by_size: %{}}
#    ]
```


## 4. Incrementa la cantidad del artículo

Algunos artículos se vendían especialmente bien, así que pediste más, de todas las tallas.

Implementa la función `increase_quantity/2`. Debe recibir un único artículo y un número `n`, y devolver ese artículo con la cantidad de cada talla incrementada en `n`.

```elixir
BoutiqueInventory.increase_quantity(
  %{
    name: "Polka Dot Skirt",
    price: 68,
    quantity_by_size: %{s: 3, m: 5, l: 3, xl: 4}
  },
  6
)

# => %{
#      name: "Polka Dot Skirt",
#      price: 68,
#      quantity_by_size: %{l: 9, m: 11, s: 9, xl: 10}
#    }
```

## 5. Calcula la cantidad total del artículo

Para saber cuánto espacio necesitas en tu almacén, tienes que saber cuántas unidades tienes en total de cada artículo.

Implementa la función `total_quantity/1`. Debe recibir un único artículo y devolver cuántas piezas tienes en total, de cualquier talla.

```elixir
BoutiqueInventory.total_quantity(%{
  name: "Red Shirt",
  price: 62,
  quantity_by_size: %{s: 3, m: 6, l: 5, xl: 2}
})

# => 16
```
