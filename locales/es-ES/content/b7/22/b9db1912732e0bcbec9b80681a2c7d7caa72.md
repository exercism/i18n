# Introducción

## Bucles `for`

Una instrucción `for` repite un bloque de código.
Su primera línea controla cuántas veces se repite el bloque:

```go
for init; condition; post {
    // loop body
}
```

- La instrucción de **inicialización** se ejecuta una vez antes de la primera iteración. Es habitual declarar e inicializar la variable contador que usa el bucle.
- La **condición** es una expresión que se evalúa como un valor booleano antes de cada iteración. El bucle se detiene cuando se evalúa como `false`.
- La instrucción **post** se ejecuta después de cada iteración completada. Se puede usar para actualizar un contador.

No rodees `init; condition; post` con paréntesis.
Sin embargo, las llaves `{ }` que rodean el cuerpo del bucle siempre son obligatorias.

Este bucle inicializa `i` a `1`, imprime el valor actual de `i`, lo incrementa para la siguiente iteración y se detiene cuando `i` llega a `10`:

```go
for i := 1; i < 10; i++ {
    fmt.Println(i)
}
```
