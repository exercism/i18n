# Tipos numéricos

Crystal tiene una variedad de tipos numéricos para distintos propósitos.
Por ejemplo, algunos tipos son más rápidos, pero tienen un rango de valores posibles más pequeño que otros.
Algunos tienen un rango de valores posibles más amplio, pero son más lentos.

En Crystal existen tanto tipos de enteros con signo como tipos de enteros sin signo.
Los tipos de enteros con signo pueden ser positivos o negativos.
Los tipos de enteros sin signo solo pueden ser positivos.

## Tipos de enteros con signo

Estos son los [tipos de enteros con signo][int] de Crystal:

| Tipo     | Tamaño (bits) | Rango                                                                                                       |
| -------- | ----------- | ----------------------------------------------------------------------------------------------------------- |
| `Int8`   | 8           | -128 a 127                                                                                                 |
| `Int16`  | 16          | -32_768 a 32_767                                                                                           |
| `Int32`  | 32          | -2_147_483_648 a 2_147_483_647                                                                             |
| `Int64`  | 64          | -9_223_372_036_854_775_808 a 9_223_372_036_854_775_807                                                     |
| `Int128` | 128         | -170_141_183_460_469_231_731_687_303_715_884_105_728 a 170_141_183_460_469_231_731_687_303_715_884_105_727 |

Los tipos más pequeños usan menos memoria y son más rápidos que los tipos más grandes, pero tienen un rango de valores posibles más pequeño.

Cuando sabes que los valores van a estar dentro de un rango concreto, lo mejor es usar el tipo más pequeño posible para ahorrar memoria y mejorar el rendimiento.

El tipo de entero predeterminado es `Int32`.
Para declarar un entero de un tipo concreto, puedes usar el nombre del tipo como sufijo añadiendo `<number>_I <bit>`.

```crystal
1_i8.class
# => Int8
```

Puedes usar el método `to_i<bit>` para convertir entre distintos tipos de enteros.
El método `to_i` convierte al tipo de entero predeterminado, `Int32`.

```crystal
1_i8.to_i16.class
# => Int16

2_i16.to_i.class
# => Int32
```

## Tipos de enteros sin signo

Estos son los [tipos de enteros sin signo][uint] de Crystal:

`UInt8`, `UInt16`, `UInt32`, `UInt64`, `UInt128`

La única diferencia entre los enteros con signo y los enteros sin signo es que los enteros sin signo solo pueden ser positivos.
Para declarar un entero sin signo de un tipo concreto, puedes usar el nombre del tipo como sufijo añadiendo `<number>_u<bit>`.
Puedes usar el método `to_u<bit>` para convertir entre distintos tipos de enteros sin signo.
El método `to_u` convierte al tipo de entero sin signo predeterminado, `UInt32`.

```crystal
1_u8.to_u16.class
# => UInt16
```

## Tipos de coma flotante

Estos son los tipos de coma flotante de Crystal:

| Tipo      | Tamaño (bits) | Rango                |
| --------- | ----------- | -------------------- |
| `Float32` | 32          | 1.2E-38 a 3.4E+38   |
| `Float64` | 64          | 2.3E-308 a 1.7E+308 |

Hay dos [tipos de coma flotante][float] distintos, uno es más preciso que el otro.

El tipo de coma flotante predeterminado es `Float64`.

Puedes usar el método `to_f<bit>` para convertir entre distintos tipos de coma flotante.
El método `to_f` convierte al tipo de coma flotante predeterminado, `Float64`.

## Tipo tras una operación

Cuando ejecutas una operación entre dos números, el resultado será del tipo del número con mayor precisión.
Un número de coma flotante es más preciso que un entero, y un entero es más exacto que un entero sin signo.
Y `Float64` es más preciso que Float32, etcétera.

```crystal
(1_u8 + 2_u64).class
# => UInt64

(1_u8 + 2_i64).class
# => Int64

(1_u8 + 2.0_f64).class
# => Float64
```

## Para profundizar: enteros sin signo frente a enteros con signo

~~~~exercism/advanced
En esencia, lo que diferencia a los enteros sin signo de los enteros con signo es que los enteros con signo usan el primer bit para almacenar el signo.
El signo es positivo o negativo.
En los enteros sin signo, el primer bit se usa para almacenar el valor.
Así, para un entero con signo de 32 bits, el valor máximo es 2^31 - 1.
Para un entero sin signo de 32 bits, el valor máximo es 2^32 - 1.

Si quieres aprender más sobre el signo de los enteros, puedes leer más al respecto en [Wikipedia](https://en.wikipedia.org/wiki/Signedness).
~~~~
