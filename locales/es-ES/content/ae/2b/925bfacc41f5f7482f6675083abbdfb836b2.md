# Instalación

## Instalar V
Sigue las [instrucciones de la documentación oficial](https://github.com/vlang/v/blob/master/README.md#installing-v-from-source) para instalar V en tu ordenador.

Se recomienda encarecidamente que instales desde el código fuente y que después sigas las [instrucciones para crear enlaces simbólicos](https://github.com/vlang/v/blob/master/README.md#symlinking) y así puedas ejecutar V en cualquier sitio.

## Usar un IDE
La mejor forma de usar V en un IDE es usar [VSCodium](https://vscodium.com/) con su [extensión](https://marketplace.visualstudio.com/items?itemName=vlanguage.vscode-vlang). También hay soporte para [Vim](https://github.com/ollykel/v-vim), [Emacs](https://github.com/damon-kwok/v-mode) y [Sublime](https://github.com/elliotchance/vlang-sublime). Para ver una lista completa de los IDE compatibles, consulta la [página de inicio de V](https://vlang.io/).
