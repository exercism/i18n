# Apéndice de instrucciones

## Nota

Si estás editando este archivo en un editor de texto y no en Pharo, consulta la sección [Primeros pasos](https://www.exercism.org/tracks/pharo/installation).

Aunque puedes usar un editor de texto, el IDE de Pharo es, en parte, lo que hace que este lenguaje sea tan especial.

En Pharo puedes ejecutar código (incluidos los tests) con métodos rotos y clases que faltan.
Cuando la máquina virtual se encuentra con código roto, lanza un depurador que te permite examinar el problema un poco mejor.

Después tienes la opción de pulsar el botón Create para añadir la clase o el método que falte, así como corregir cualquier código que provoque un error.
Cuando lo hagas, el depurador retrocederá y te dejará reanudar la ejecución con tus nuevos cambios.

Intenta hacerlo con tu ejemplo HelloWorld, simplemente ejecutando cualquiera de los métodos de test unitario.
