# Introducción

Los condicionales en C++ son similares a los condicionales en otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
Los condicionales se usan a menudo como mecanismos de control de flujo para comprobar diversas condiciones.

Se puede usar un condicional `if`, que ejecuta su código si la condición subyacente es `true`, así:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

En escenarios con más de un caso, se pueden encadenar varios condicionales `if` usando las instrucciones `else if` y `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde C++17, los condicionales `if` también pueden incluir una breve instrucción de inicialización que se puede usar para inicializar una o varias variables para el condicional `if`.
Por ejemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: no se puede acceder a las variables creadas en la inicialización después del final del condicional `if`.
