# Introducción

Los iteradores en Haxe se usan para iterar sobre un valor con un bucle `for`. Hay dos tipos de iteradores:

- `Iterator`, que itera sobre un valor.
- `Iterable`, datos que permiten iterar sobre un tipo de datos.

Ambos conceptos se representan con `Iterator<T>` y `Iterable<T>`:

```haxe
typedef Iterator<T> = {
  function hasNext():Bool;
  function next():T;
}

typedef Iterable<T> = {
  function iterator():Iterator<T>;
}
```

Cualquier clase que unifique con uno de estos tipos se puede recorrer con un bucle `for`. Si una clase define los métodos `hasNext` y `next`, se considera un iterador; si define un método `iterator`, se considera un tipo iterable.
