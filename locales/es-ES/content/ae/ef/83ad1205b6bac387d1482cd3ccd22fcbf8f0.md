# Instrucciones

En este ejercicio, vas a gestionar un sistema de inventario.

El inventario debe organizarse por el nombre de cada artículo y debe llevar la cuenta del número de artículos disponibles.

Tendrás que encargarte de añadir artículos a un inventario.
Cada vez que un artículo aparece en un vector dado, la cantidad de ese artículo debe incrementarse en `1` en el inventario.
También tendrás que encargarte de eliminar artículos de un inventario, decrementando las cantidades en `1` cuando se solicite.

Por último, tendrás que implementar una función que devuelva todos los pares clave-valor de un inventario dado como un `vector` de `pair`s.

~~~~exercism/note
Las pruebas de este ejercicio son agnósticas respecto a la mutación, pero los nombres de las funciones indican que no deberían mutar la entrada.
Si quieres usar las funciones de la introducción sin mutar la entrada, la función `copy()` te resultará útil.
~~~~

## 1. Crea un inventario a partir de un vector

Implementa la función `create_inventory(<input vector>)` que crea un «inventario» a partir de un vector de entrada de artículos.
Debe devolver un `dict` que contenga cada nombre de artículo emparejado con su cantidad correspondiente.

```julia-repl
julia> create_inventory(["coal", "wood", "wood", "diamond", "diamond", "diamond"])
Dict("coal" => 1, "wood" => 2, "diamond" => 3)
```

## 2. Añade artículos de un vector a un diccionario existente

Implementa la función `add_items(<inventory dict>, <item vector>)` que añade un vector de artículos al inventario recibido:

```julia-repl
julia> add_items(Dict("coal" => 1), ["wood", "iron", "coal", "wood"])
Dict("coal" => 2, "wood" => 2, "iron" => 1)
```

## 3. Decrementa artículos del inventario

Implementa la función `decrement_items(<inventory dict>, <items vector>)` que toma un `vector` de artículos.
Tu función debe restar `1` a la cantidad de un artículo por cada vez que ese artículo aparezca en el `vector`:

```julia-repl
julia> decrement_items(Dict("coal" => 3, "diamond" => 1, "iron" => 5), ["diamond", "coal", "iron", "iron"])
Dict("coal" => 2, "diamond" => 0, "iron" => 3)
```

No se debe permitir que las cantidades del inventario caigan por debajo de 0.
Si el número de veces que aparece un artículo en el `vector` de entrada supera la cantidad disponible, la cantidad indicada para ese artículo debe permanecer en 0.
Las peticiones adicionales para eliminar cantidades deben ignorarse una vez que la cantidad llegue a cero.

```julia-repl
julia> decrement_items(Dict("coal" => 2, "wood" => 1, "diamond" => 2), ["coal", "coal", "wood", "wood", "diamond"])
Dict("coal" => 0, "wood" => 0, "diamond" => 1)
```

## 4. Elimina una entrada por completo del inventario

Implementa la función `remove_item(<inventory dict>, <item>)` que elimina un artículo y su cantidad por completo de un inventario:

```julia-repl
julia> remove_item!(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "coal")
Dict("wood" => 1, "diamond" => 2)
```

Si el artículo no se encuentra en el inventario, la función debe devolver el inventario original sin cambios.

```julia-repl
julia> remove_item(Dict("coal" => 2, "wood" => 1, "diamond" => 2), "gold")
Dict("coal" => 2, "wood" => 1, "diamond" => 2)
```

## 5. Devuelve todo el contenido del inventario

Implementa la función `list_inventory(<inventory dict>)` que toma un inventario y devuelve un vector de pares `(item, quantity)`.

El vector solo debe incluir los artículos _disponibles_ (_con una cantidad mayor que cero_), y debe estar ordenado alfabéticamente por artículo:

```julia-repl
julia> list_inventory(Dict("coal" => 7, "wood" => 11, "diamond" => 2, "iron" => 7, "silver" => 0))
["coal" => 7, "diamond" => 2, "iron" => 7, "wood" => 11]
```
