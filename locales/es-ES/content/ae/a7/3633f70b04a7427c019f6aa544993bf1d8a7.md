# Instalación

## Requisitos previos

El track de C++ requiere que tengas instalado en tu sistema el siguiente software:
* un compilador moderno de C++14
* el sistema de compilación multiplataforma CMake

Usamos [Catch2](https://github.com/catchorg/Catch2) para las pruebas, que es una biblioteca de solo cabeceras que se incluye junto con los ejercicios.

Este conjunto de dependencias es muy habitual en los proyectos de C++, así que si tienes algún problema para configurarlo encontrarás muchos recursos útiles en internet.

Muchos IDE, como Visual Studio de Microsoft, Xcode de Apple y CLion de JetBrains, incluyen un compilador y CMake juntos, así que en principio solo tendrás que instalar el IDE.

### Un compilador moderno de C++14

Este track requiere un compilador compatible con [C++14](http://en.wikipedia.org/wiki/C%2B%2B14), que se publicó en 2014. Todos los compiladores principales publicados en los últimos años deberían ser compatibles, así que mientras tengas una versión bastante reciente no deberías tener problemas. En concreto, GCC versión 7 o posterior, Clang versión 6 o posterior, o Visual Studio 2017 o posterior.

### CMake

CMake es un sistema de compilación multiplataforma de código abierto que genera scripts de compilación para tu sistema de compilación nativo (`make`, Visual Studio, Xcode, etc.). El track de C++ de Exercism usa CMake para ofrecerte una compilación ya preparada que:

* compila las pruebas
* compila tu solución
* enlaza el ejecutable de las pruebas
* ejecuta automáticamente las pruebas como parte de cada compilación
* hace que la compilación falle si alguna prueba falla

Usar CMake permite a Exercism ofrecer un script de compilación multiplataforma capaz de generar archivos de proyecto para entornos de desarrollo integrados como Visual Studio y Xcode. Así puedes centrarte en el problema y no preocuparte por configurar una compilación para cada ejercicio.

Conseguir una compilación portable no es fácil y requiere acceso a muchos tipos de sistemas. Si tienes algún problema con la receta de CMake que se incluye, [informa del problema](https://github.com/exercism/cpp/issues) para que podamos mejorar la compatibilidad con CMake.

Para usar la receta de compilación que se proporciona se necesita [CMake 3.5.1 o posterior](http://www.cmake.org/).

## Windows

Los usuarios de Windows pueden descargar [Visual Studio Community](https://www.visualstudio.com/vs/community/), una descarga gratuita que te proporciona el IDE de Visual Studio y la última versión del compilador Microsoft Visual C++.

1. Sigue [estas instrucciones](https://docs.microsoft.com/en-us/cpp/build/cmake-projects-in-visual-studio) para configurar CMake.
1. Descarga el ejercicio con la herramienta [CLI de Exercism](https://exercism.io/cli-walkthrough).
1. Abre Visual Studio 2017 o superior (con las herramientas de Visual C++ para CMake instaladas tal y como se describe en el enlace anterior).
1. Abre la carpeta del ejercicio en VS.
1. Ejecuta «Build->Build the solution». Las pruebas se ejecutarán junto con la compilación y la salida irá a la ventana de compilación. Como las pruebas se ejecutan durante la compilación, VS indicará que la compilación ha fallado si alguna de las pruebas falla, y los mensajes de error de las pruebas aparecerán en la ventana de salida de la compilación.

Deberías poder usar otros IDE integrados, como CLion de JetBrains, de forma similar.

### Instalar Boost en Windows

Los ejercicios `meetup` y `gigasecond` dependen de las bibliotecas de [Boost][boost-website]. Los siguientes pasos describen cómo configurarlas.

1. Descarga las [bibliotecas precompiladas para Windows][sourceforge-boost-binaries] de Boost.
   - Los ejercicios requieren como mínimo la versión 1.58 de Boost.
   - Puedes consultar la versión de MSVC haciendo clic en «Modify» en el Visual Studio Installer.
1. Extrae las bibliotecas en una carpeta local.
1. Asigna a la variable de entorno `BOOST_ROOT` la carpeta donde instalaste las bibliotecas de Boost.
1. Si tenías Visual Studio abierto mientras hacías esto, ciérralo para asegurarte de que se detecte el valor de `BOOST_ROOT`.
1. Inicia Visual Studio y abre la carpeta que contiene el ejercicio `gigasecond` o `meetup`.
1. El «Startup Item» debería ser `gigasecond.exe` o `meetup.exe`, y obtendrás errores de compilación en `gigasecond_test.cpp` o `meetup_test.cpp` que te indicarán que implementes los elementos que faltan, de forma similar a los demás ejercicios.

## Linux

Todas las versiones recientes de las distribuciones de Linux incluyen compiladores compatibles con C++14, así que deberías poder instalarlo con tu gestor de paquetes. Las versiones que admitimos son las que se instalan por defecto en Ubuntu LTS 18.04.

Por ejemplo, en Ubuntu usarías el siguiente comando para instalar gcc.

```bash
$ sudo apt-get install gcc
$ gcc --version
```

Si tienes una distribución más antigua, es posible que no tengas un compilador compatible con C++14. En ese caso, tendrás que consultar los recursos de tu distribución para averiguar cómo instalar la versión mínima del compilador.

## MacOS

Los usuarios de MacOS pueden instalar GCC con [Homebrew](http://brew.sh/) mediante `brew install gcc`.
