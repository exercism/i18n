# Pistas

## General

- El [paquete strings][strings-package] contiene muchas funciones `string` útiles.
- Hay que importar el paquete `strings` antes de poder usarlo.
- Para llamar a funciones dentro del paquete `strings`, antepón `strings.` a su nombre.

## 1. Crea el mensaje de bienvenida

- Los strings se pueden concatenar con el operador `+`.
- Hay una función para [convertir un `string` a mayúsculas][to-upper].

## 2. Añade un borde vistoso

- Hay una función para [crear un `string` con un carácter concreto repetido un número de veces][repeat].
- Un salto de línea es un [carácter de escape][escape-characters] especial.

## 3. Limpia los antiguos mensajes de marketing

- Hay una función para [reemplazar strings dentro de un `string`][replace-all].
- Hay una función para [eliminar los espacios al principio y al final de un `string`][trim-space].
