# Introducción

El bucle `for` es una de las instrucciones más usadas para ejecutar cierta lógica de forma repetida.
En JavaScript, consta de la palabra clave `for`, una _cabecera_ entre paréntesis y un bloque de código que contiene el _cuerpo_ del bucle entre llaves.

```javascript
for (initialization; condition; step) {
  // code that is executed repeatedly as long as the condition is true
}
```

La inicialización normalmente prepara una variable contadora, la condición comprueba si el bucle debe continuar o detenerse y el paso incrementa el contador al final de cada repetición.
Las distintas partes de la cabecera se separan con puntos y coma.

```javascript
const list = ['a', 'b', 'c'];
for (let i = 0; i < list.length; i++) {
  // code that should be executed for each item list[i]
}
```

Definir el paso suele hacerse con el operador de incremento o decremento de JavaScript, como muestra el ejemplo anterior.
Estos operadores modifican una variable in situ.
`++` suma uno a un número, `--` resta uno a un número.

```javascript
let i = 3;
i++;
// i is now 4

let j = 0;
j--;
// j is now -1
```
