# devolución explícita

Elimina la devolución explícita para simplificar el método.

En Ruby, un método devuelve el resultado de la última instrucción evaluada. Por lo tanto, usar explícitamente la palabra clave `return` es innecesario, excepto cuando se quiere devolver antes de terminar el método.

Por ejemplo, esto imprimirá `16`, ya que el método `multiply` devuelve el resultado de `a * b`, su última expresión.

```ruby
def multiple(a, b)
  a * b
end

print multiple(2, 8)
```
