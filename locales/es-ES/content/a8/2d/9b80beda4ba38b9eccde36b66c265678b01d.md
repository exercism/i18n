# Introducción

## La interfaz como conjunto de métodos

En su forma más simple, un **tipo de interfaz** es un conjunto de firmas de métodos.
Aquí tienes un ejemplo de definición de interfaz que incluye dos métodos, `Add` y `Value`:

```go
type Counter interface {
    Add(increment int)
    Value() int
}
```

Los nombres de los parámetros como `increment` pueden omitirse en la definición de la interfaz, pero a menudo aumentan la legibilidad.

Los nombres de las interfaces en Go no contienen la palabra `Interface` ni `I`.
En su lugar, a menudo terminan en `er`, como `Reader` o `Stringer`.

## Implementar una interfaz

Cualquier tipo que defina los métodos de la interfaz la «implementa» automáticamente de forma implícita.
En Go no existe la palabra clave `implements`.

El siguiente tipo implementa la interfaz `Counter` que vimos antes.

```go
type Stats struct {
    value int
    // ...
}

func (s Stats) Add(v int) {
    s.value += v
}

func (s Stats) Value() int {
    return s.value
}

func (s Stats) SomeOtherMethod() {
    // The type can have additional methods not mentioned in the interface.
}
```

Para implementar la interfaz, no importa si el método tiene un receptor de valor o de puntero.
(Vuelve a consultar los [conceptos de métodos][concept-methods] si tienes dudas al respecto.)

> Un valor de tipo interfaz puede contener cualquier valor que implemente esos métodos. ((Go Tour: Interfaces)[go-tour-interfaces])

Esto significa que `Stats` ahora puede usarse en todos los lugares que esperan la interfaz `Counter`.

```go
func SetUpAnalytics(counter Counter) {
    // ...
}

stats := Stats{}
SetUpAnalytics(stats)
// works because Stats implements Counter
```

Como las interfaces se implementan de forma implícita, un tipo puede implementar varias interfaces con facilidad.
Solo necesita tener definidos todos los métodos necesarios.

## La interfaz vacía

En Go hay un tipo de interfaz muy especial, el tipo **interfaz vacía**, que no contiene ningún método.
La interfaz vacía se escribe así: `interface{}`.
En Go 1.18 o superior, también puede usarse `any`.
Se definió como un alias.

Como la interfaz vacía no tiene métodos, todos los tipos la implementan de forma implícita.
Esto resulta útil para definir una función que pueda aceptar cualquier valor de forma genérica.
En ese caso, el parámetro de la función usa el tipo interfaz vacía.
