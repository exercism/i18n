# Pistas

## General

- Para extraer varios argumentos en los parámetros de la función puedes empaquetarlos con el operador `*arguments` para un **array** o `**keyword_arguments` para argumentos basados en palabras clave.
- Para empaquetar o desempaquetar, usa los operadores splat (`*` o `**`).

## 1. Crear un array de todos los vagones

- Varios argumentos en los parámetros de la función se pueden empaquetar con el operador `*arguments`.

## 2. Corregir el array de vagones

- Usar el desempaquetado con el operador splat (`*`) te permite extraer los dos primeros elementos de un **array** y mantener el resto intacto.
- Para añadir otro **array** a un **array** existente, puedes usar el operador splat (`*`) para «esparcir» el **array**.

## 3. Añadir paradas que faltan

- Usar `**keyword_arguments` como argumento de método permite pasar una cantidad arbitraria de argumentos de palabra clave.
- Usar `**<hash>` como argumento desempaqueta un `Hash` en argumentos de palabra clave.
- Puedes poner los argumentos de palabra clave dentro de `{}`, que es otra forma de crear un `Hash`.
- Para extraer los valores de un `Hash`, puedes usar el método `Hash#values`.

## 4. Ampliar la información de enrutamiento

- Usar `**{some_hash: value}` como argumento desempaqueta el `Hash` en argumentos de palabra clave.
