# Apéndice de instrucciones

Aunque existen los métodos `#reversed` y `#reverseDo:` para los strings, ¿puedes averiguar cómo hacerlo tú mismo usando iteración de caracteres de nivel más bajo y streams?

Para ayudarte a explorar el código, Pharo tiene una práctica herramienta de búsqueda de código. Pulsa Mayús+Intro para activarla.

NOTA: Hemos seguido la convención de Exercism de llamar a la solución ReverseString; sin embargo, un nombre más propio de Smalltalk sería StringReverser.

## Smalltalk y strings

En lo que respecta a los strings, hay algunos detalles pequeños y evidentes, como las comillas dobles para los comentarios, las comillas simples para los strings y una sintaxis especial para los caracteres (por ejemplo, $x para el carácter «x»), que pueden confundirte en una primera lectura, ya que las convenciones son distintas de las que se usan en otros lenguajes.

También existe la noción de símbolo, que es un string único en toda la memoria; es decir, cuando se construye (normalmente en tiempo de compilación), se realiza una búsqueda en memoria para determinar si ya existe otro igual, y solo se usa el original. La razón no es únicamente ahorrar memoria, sino también una aceleración notable al comparar símbolos.

```smalltalk
"this is a comment"
'this is a string'
#'this is a symbol'
#thisIsASymbolToo
```

Además, en los programas de Smalltalk hay muy pocas comas, porque no desempeñan ningún papel sintáctico. Por eso los literales de array, por ejemplo, no llevan comas; por ejemplo, `#(1 2 3 4 5)`. Sin embargo, la coma es un operador por derecho propio y lo notarás al concatenar dos strings; por ejemplo, `'string1', 'string2'`.

Por último, conviene saber que Strings y Characters son clases distintas. Un String es una colección de Characters. Esto puede pillarte por sorpresa al iterar sobre strings, ya que puedes acabar pasando caracteres a un método que espera strings. Fíjate en lo siguiente:

```smalltalk
(('hello' at: 2) = $e) inspect.
(('hello' at: 2) = 'e') inspect.
```

## Smalltalk y streams
Los streams son útiles para la lectura y la escritura secuenciales. Hacen que el código sea más limpio al evitar la necesidad de incrementar un índice.
Los streams funcionan con cualquier colección.
```smalltalk
stream := WriteStream on: String new.
stream nextPut: $h ; nextPutAll: 'ell' ; nextPut: $o.
stream contents inspect
```
