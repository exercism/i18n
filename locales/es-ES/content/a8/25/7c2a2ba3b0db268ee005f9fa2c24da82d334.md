# Instrucciones

En este ejercicio vas a escribir código para ayudar a un freelancer a comunicarse con un jefe de proyecto.
Tu tarea es proporcionar unas cuantas utilidades para calcular rápidamente tarifas diarias y mensuales, opcionalmente con un descuento dado.

Primero establecemos unas cuantas reglas entre el freelancer y el jefe de proyecto:

- La tarifa diaria es 8 veces la tarifa por hora.
- Un mes tiene 22 días facturables.

A veces, el freelancer ofrece aplicar un descuento sobre su tarifa diaria (por ejemplo, para sus clientes más fieles o para clientes sin ánimo de lucro).

Los descuentos se representan como números decimales que indican porcentajes; por ejemplo, `25.0` (25 %).

~~~~exercism/note
Estos son los sufijos de las instrucciones de coma flotante:

| Sufijo | Tamaño del operando |
|--------|--------------|
| `ss`   | 32 bits       |
| `sd`   | 64 bits       |

Estas son algunas de las instrucciones mencionadas en este concepto:

| Instrucción       | Descripción                                                  |
|-------------------------|--------------------------------------------------------|
| movss/movsd a, b        | copia b en a                                          |
| addss/addsd a, b        | a = a + b                                              |
| subss/subsd a, b        | a = a - b                                              |
| mulss/mulsd a, b        | a = a * b                                              |
| divss/divsd a, b        | a = a / b                                              |
| cvtsi2ss/cvtsi2sd a, b  | convierte el entero b en el número de coma flotante a                 |
| roundss/roundsd a, b, c | redondea el número de coma flotante b según c y lo almacena en a |
| cvtss2si/cvtsd2si a, b  | convierte el número de coma flotante b en el entero a                 |
| comiss/comisd a, b      | hace una comparación entre a y b, lanza una excepción si `NaN` |
| ucomiss/ucomisd a, b    | hace una comparación entre a y b, establece `PF` si `NaN` |

Estos son los números de control de redondeo en `roundss` y `roundsd`:

| Número | Modo         |
|:-------|:-------------|
| 0      | Al más cercano |
| 1      | Hacia abajo  |
| 2      | Hacia arriba |
| 3      | Truncar      |
~~~~

## 1. Calcula la tarifa diaria a partir de una tarifa por hora

Implementa una función llamada `daily_rate` que calcule la tarifa diaria a partir de una tarifa por hora recibida como parámetro, como número de coma flotante de 64 bits.
El contrato define que un día tiene 8 horas facturables.

```c
daily_rate(60)
// => 480.0
```

La tarifa diaria devuelta debe ser un número de coma flotante de 64 bits.

## 2. Calcula un precio con descuento

Implementa una función `apply_discount` que calcule el precio después de aplicar un descuento.
Debe aceptar dos parámetros: el precio original y el porcentaje de descuento, ambos como números de coma flotante de 64 bits.

```c
apply_discount(150.0, 10.0)
// => 135.0
```

El valor devuelto debe ser siempre un número de coma flotante de 64 bits.

## 3. Calcula la tarifa mensual a partir de una tarifa por hora y un descuento

Implementa una función `monthly_rate` que calcule la tarifa mensual con descuento.
Recibe dos parámetros: una tarifa por hora y el porcentaje de descuento, ambos como números de coma flotante de 64 bits.

```c
monthly_rate(77.0, 10.5)
// => 12130
```

La tarifa mensual devuelta debe redondearse hacia arriba (tomar el techo) al entero de 64 bits más cercano.

## 4. Calcula el número de días completos de trabajo a partir de un presupuesto, una tarifa por hora y un descuento

Implementa una función `days_in_budget` que recibe como parámetros:

1. Un presupuesto, como entero sin signo de 64 bits.
2. Una tarifa por hora, como número de coma flotante de 64 bits.
3. Un porcentaje de descuento, como número de coma flotante de 64 bits.

Esta función debe devolver el número de días completos de trabajo que cubre el presupuesto.

```c
days_in_budget(20000, 80, 11.0)
// => 35
```

El número de días devuelto debe redondearse hacia abajo (tomar el suelo) al entero de 32 bits más cercano.
