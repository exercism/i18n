# Acerca de

El tipo [unión discriminada][define] representa un número fijo de casos con nombre. Cada valor de una unión discriminada se corresponde con exactamente uno de los casos con nombre. Este tipo de dato se conoce como _tipo suma_.

Cada caso de una unión discriminada puede tener opcionalmente datos asociados, y diferentes casos pueden tener diferentes tipos de datos. Si ninguno de los casos tiene datos asociados, la unión discriminada es similar a lo que otros lenguajes suelen llamar una _enumeración_ (o _enum_).

Una unión discriminada se define con la palabra clave `type` y requiere muy poca sintaxis. Esto hace que sean fáciles de usar, y verás que se usan en muchos sitios, incluida la biblioteca base.

```fsharp
// Discriminated union without associated data
type Season =
    | Spring
    | Summer
    | Autumn
    | Winter

// Discriminated union with associated data
type Number =
    | Integer of int
    | Float of float
    | Invalid
```

Crear un valor para un caso específico se puede hacer refiriéndose a su nombre, o a su nombre completo si el nombre no es único. Como los nombres de los casos son solo funciones de constructor, los datos asociados se pueden pasar como un argumento de función normal.

```fsharp
let byName = Integer 2
let byFullName = Number.Invalid
```

Las uniones discriminadas tienen _igualdad estructural_, lo que significa que dos valores para el mismo caso y con los mismos datos (opcionales) son equivalentes.

La forma preferida de trabajar con uniones discriminadas es mediante la [coincidencia de patrones][pattern-matching] usando el [patrón de identificador][identifier-patterns]:

```fsharp
let describe number =
    match number with
    | Integer i -> sprintf "Integer: %d" i
    | Float d  -> sprintf "Float: %f" d
    | Invalid   -> "Invalid"
```
