# Instrucciones

En este ejercicio escribirás código para gestionar un diccionario de códigos de marcado internacional usando un `Map`.

El diccionario permite buscar el nombre de un país (el valor del mapa, como `String`) por el código de marcado internacional (la clave del mapa, como `Integer`).

## 1. Devuelve los códigos en un mapa

Implementa el método `getCodes`, que no recibe parámetros y devuelve un mapa con los códigos de marcado y sus países actualmente en el diccionario.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.getCodes();
// => empty map 
```

## 2. Añade entradas al diccionario

Hay que rellenar el diccionario.
Implementa el método `setDialingCode`, que recibe un código de marcado y el país correspondiente y añade el código de marcado y el país.
Si el código de marcado ya está en el mapa, actualiza el mapa con el código y el país proporcionados.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(679, "Unknown");
// => { 679 => "Unknown" }

dialingCodes.setDialingCode(679, "Fiji");
// => { 679 => "Fiji" }
```

## 3. Busca el país de un código de marcado

Implementa el método `getCountry`, que recibe un código de marcado y devuelve el nombre del país correspondiente a ese código de marcado.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.setDialingCode(55, "Brazil");
dialingCodes.getCountry(55);
// => "Brazil"
```

## 4. No permitas duplicados

Al añadir un código de marcado, hay que tener cuidado para evitar que un código o un país se añada dos veces.
En los casos en que esto ocurra, se puede suponer que la primera entrada es la correcta.
Implementa el método `addNewDialingCode`, que añade una entrada para el código de marcado y el país dados.
Sin embargo, a diferencia de `setDialingCode`, no hace nada si el código de marcado o el país ya están en el mapa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addNewDialingCode(32, "Belgium");
dialingCodes.addNewDialingCode(379, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }


dialingCodes.addNewDialingCode(32, "Other");
dialingCodes.addNewDialingCode(39, "Vatican City");
// => { 32 => "Belgium", 379 => "Vatican City" }
```

## 5. Encuentra el código de marcado de un país

Es poco frecuente, pero se pueden cometer errores.
Para corregir el error, necesitaremos saber a qué código de marcado está asignado actualmente el país.
Para saber qué código de marcado hay que corregir, implementa el método `findDialingCode`, que recibe un país y devuelve su código de marcado.
Devuelve `null` si el país _no_ está en el mapa.

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(44, "UK");
dialingCodes.findDialingCode("UK");
// => 44

dialingCodes.findDialingCode("Unlisted");
// => null
```

## 6. Actualiza el código de marcado del país

Ahora que sabemos qué código de marcado hay que corregir, procedemos a actualizar el código.
Implementa el método `updateCountryDialingCode`, que recibe el nuevo código de marcado del país y el nombre del país y actualiza en consecuencia.
No hagas nada si el país _no_ está en el mapa (ya que este método solo está pensado para ayudar a corregir errores).

```java
DialingCodes dialingCodes = new DialingCodes();
dialingCodes.addDialingCode(88, "Japan");
// => { 88 => "Japan" }

dialingCodes.updateCountryDialingCode(81, "Japan");
// => { 81 => "Japan" }

dialingCodes.updateCountryDialingCode(32, "Mars");
// => { 81 => "Japan"}
```
