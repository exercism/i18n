# Instrucciones

Ellen está creando un juego en el que el jugador tiene que luchar contra alienígenas.
Acaba de aprender programación orientada a objetos (POO) y está deseando aprovechar lo que el uso de `classes` puede ofrecer a su programa.

Para alegría de Ellen, te has ofrecido a ayudarla y ella te ha encargado programar los alienígenas contra los que tiene que luchar el jugador.


## 1. Crea la clase Alien

Define la clase Alien con un constructor que acepte dos parámetros `<x_coordinate>` y `<y_coordinate>`, y que los guarde en las variables de instancia `x_coordinate` y `y_coordinate`.
Cada alienígena también empezará con un nivel de salud de 3, así que la variable `health` también debe inicializarse.

```python
>>> alien = Alien(2, 0)
>>> alien.x_coordinate
2
>>> alien.y_coordinate
0
>>> alien.health
3
```

Ahora, cada alienígena debe poder llevar un seguimiento interno de su propia posición y su salud.

## 2. El método `hit`

A Ellen le gustaría que la `class` Alien tuviera un método `hit` que reduzca en 1 la salud de un objeto alienígena cuando se llama.
De esta forma, puede simplemente llamar a `<alien>.hit()` en lugar de tener que cambiar manualmente la salud de un alienígena.
Depende de ti si `hit()` lleva los puntos de salud _hasta_ cero o _por debajo_ de cero.

```python
>>> alien = Alien(0, 0)

# Initialized health value.
>>> alien.health
3

# Decrements health by 1 point.
>>> alien.hit()
>>> alien.health
2
```

## 3. El método `is_alive`

Te das cuenta de que, si la salud sigue disminuyendo, en algún momento probablemente llegará a 0 (_¡o incluso menos!_).
Sería buena idea añadir un método `is_alive` al que Ellen pueda llamar rápidamente para comprobar si el alienígena está... bueno... vivo. 😉
`<alien>.is_alive()` debe devolver un Boolean.

```python
>>> alien.health
1
>>> alien.is_alive()
True
>>> alien.hit()
>>> alien.health
0
>>> alien.is_alive()
False
```

## 4. El método `teleport`

¡En el juego de Ellen, los alienígenas tienen la capacidad de teletransportarse!
Tendrás que escribir un método `teleport` que reciba nuevos valores de `x_coordinate` y `y_coordinate`, y que cambie las coordenadas del alienígena en consecuencia.

```python
>>> alien.teleport(5, -4)
>>> alien.x_coordinate
5
>>> alien.y_coordinate
-4
```

## 5. El método `collision_detection`

Obviamente, si algo puede golpear a los alienígenas, entonces necesitan poder detectar cuándo se ha producido esa colisión.
Sin embargo, los algoritmos de detección de colisiones pueden ser complicados, y todavía no sabes cómo implementar uno.
Ellen ha dicho que lo hará más adelante, pero aun así le gustaría que el método `collision_detection` apareciera en la clase como recordatorio para desarrollar esa funcionalidad.
Tendrá que recibir una variable de algún tipo (probablemente otro objeto), pero eso es realmente todo lo que sabes.
Tendrás que asegurarte de que incluir la definición del método en la clase no cause ningún error al llamarlo:

```python
>>> alien.collision_detection(other_object)
>>>
```

## 6. Contador de alienígenas

Ellen ha vuelto con una nueva petición para ti.
Quiere llevar un registro de cuántos alienígenas se han creado a lo largo de la partida.
Dice que tiene algo que ver con el sistema de puntuación.

Por ejemplo:

```python
>>> alien_one = Alien(5, 1)
>>> alien_one.total_aliens_created
1
>>> alien_two = Alien(3, 0)
>>> alien_two.total_aliens_created
2
>>> alien_one.total_aliens_created
2
# Accessing the variable from the class directly
>>> Alien.total_aliens_created
2
```
