# Case

[Case][case] (que en otros lenguajes se suele llamar switch) es una forma de expresión de control, igual que if-else.
Case permite encadenar varias instrucciones if-else-if y puede resultar más legible sin dejar de ofrecer control de flujo.

Un case se define mediante la palabra clave `case` seguida de una expresión opcional.
Después, para cada caso se usa la palabra clave `when` seguida de una expresión que se compara con la expresión del case.
La palabra clave `when` no debe llevar sangría respecto a la palabra clave `case`.
Tras la palabra clave `when` va el código que debe ejecutarse si la expresión del case coincide con la expresión del when.
Case admite una instrucción `else` opcional que se ejecuta si no coincide ningún otro caso.

La expresión del case se evalúa y luego se compara con cada expresión del when.
La comparación se hace con el operador de igualdad de case (`===`).

```ruby
value = 1
case value
when 1
  "One"
when 2
  "Two"
else
  "Other"
end

# This is the same as:
value = 1
if 1 === value
  "One"
elsif 2 === value
  "Two"
else
  "Other"
end
```

## Operador de igualdad de case (`===`)

El operador de igualdad de case (`===`) es un poco distinto del operador de igualdad (`==`).
Comprueba si el lado derecho es un miembro del conjunto descrito por el lado izquierdo.
Esto significa que sí importa dónde se coloca cada operando.
Cómo funciona depende del tipo del lado izquierdo; por ejemplo, un `Range` comprobaría si el lado derecho está dentro del rango, y un `Object` comprobaría si el lado derecho es una instancia de `Object`.

```ruby
(1..3) == 1  # => false
(1..3) === 1 # => true

String == "foo"  # => false
String === "foo" # => true
```

## Case con varias expresiones

Los case permiten hacer coincidir varias expresiones en un mismo caso, separando cada valor posible con una coma.
Se ejecutará el código si coincide alguna de las expresiones.
Esto puede resultar útil cuando quieres que un mismo caso tenga varios valores posibles.

```ruby
case var
when 1, 2
  "One or two"
else
  "Other"
end
```

## Case con rangos

Los case también pueden comprobar si un valor está dentro de un rango.
Para ello se usa un rango como expresión del when.

```ruby
case var
when 1..3
  puts "One to three"
else
  puts "Other"
end
```

## Case sin expresión de case

Cuando no se necesita una expresión de case, es posible omitirla.
Al hacerlo, cada expresión se evalúa según su veracidad,
y se comportan como instrucciones if-else-if.

```ruby
case
when 1 == 1
  "One is equal to one"
when 1 > 2
  "One is greater than two"
else
  "Other"
end
```

## When en una sola línea

Ruby permite instrucciones case de una sola línea.
Esto puede usarse cuando tienes una instrucción simple de una sola línea.
La instrucción when de una sola línea se escribe como `when <expression> then <statement>`.
Y cuando se usa en la instrucción else, se escribe como `else <statement>`.

```ruby
case var
when 1 then "One"
when 2 then "Two"
else "Other"
end
```

## Case con tipos

Case permite hacer coincidir con tipos.
Esto resulta útil cuando quieres un comportamiento distinto según el tipo de una variable.

```ruby
case var
when Integer
  "Integer"
when String
  "String"
else
  "Other"
end
```
