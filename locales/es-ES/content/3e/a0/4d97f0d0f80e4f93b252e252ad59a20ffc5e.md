# Pistas

## General

- Una comparación empaquetada escribe una **máscara**: cada carril se establece a todos unos donde se cumple la condición y a todos ceros donde no.
- Las comparaciones de coma flotante toman la condición como un inmediato, o puedes usar las pseudoinstrucciones de NASM como `cmpltps` y `cmpeqps`.
- Las comparaciones de enteros toman la condición como un sufijo: `pcmpgtd` para mayor que con signo, `pcmpeqd` para la igualdad.
- Los bloques están alineados a 16 bytes, así que `movaps` y `movdqa` son seguros.

## 1. Marca las puntuaciones por encima del umbral

- `a > b` es lo mismo que `not (a <= b)` (inmediato 6) o que `b < a` (inmediato 1, con los operandos intercambiados).
- La igualdad no debe contar como estar por encima.

## 2. Marca las puntuaciones perfectas

- Esta es una igualdad de coma flotante directa con `cmpeqps`.
- Compara las puntuaciones con los máximos.
  Cada carril se establece donde coinciden.

## 3. Asigna un rango

- Puedes definir el umbral `50.0` y los valores de rango `1`, `2` y `3` como constantes empaquetadas en memoria, de cuatro carriles cada una.
- Puedes definir dos máscaras.
  Una para «por encima del umbral», como en la tarea 1 (pero contra la constante empaquetada `50.0`).
  Otra para «puntuación perfecta» (como en la tarea 2).
- El rango básico es `1`.
  El rango `2` debe seleccionarse para los carriles donde esté establecida la máscara de por encima del umbral.
  El rango `3` debe seleccionarse para los carriles donde esté establecida la máscara de perfecta.
- Las puntuaciones perfectas también están por encima del umbral.
  Si se aplica primero la máscara de por encima del umbral, la máscara de perfecta la sobrescribe correctamente donde es necesario.
- `blendvps` toma su máscara de `xmm0` y selecciona según el bit superior de cada carril.
  Para los carriles donde este bit está establecido, selecciona del operando origen.
  Para los demás, mantiene el carril que ya está en el operando destino.

## 4. Cuenta los fallos

- Un rango falla cuando está estrictamente por debajo del umbral, es decir, `threshold > rank`.
  Puedes usar `pcmpgtd` con el umbral como destino y los rangos como origen.
- Para cada bloque, `movmskps` puede usarse para reducir la máscara de fallos a un registro de propósito general, tomando el bit superior de cada carril.
  Este registro de propósito general puede ser de 32 o 64 bits.
- Puedes usar `popcnt` para contar el número de bits establecidos en un registro de propósito general.
- Puede haber más de un bloque, así que es necesario un bucle para recorrerlos y acumular un resultado.
- Cada bloque tiene 16 bytes.

## 5. ¿Han aprobado todos?

- Que «todos hayan aprobado» se representa como un resultado de todos ceros en la máscara de fallos.
  Un solo carril distinto de cero es un resultado falso.
- Puede haber más de un bloque, así que es necesario un bucle para recorrerlos y acumular un resultado.
- Cada bloque tiene 16 bytes.
- Un `ptest` de un registro consigo mismo puede usarse para comprobar si son todos ceros.
- Una operación OR conserva los bits establecidos y una operación AND conserva los bits a cero.
  Ambas pueden usarse para acumular valores lógicos en un bucle.
- Una bandera puede transformarse en un resultado `0/1` con `setcc`.
