# Tabla de puntuaciones máximas

## Contexto

Este ejercicio utiliza el contexto de mantener la tabla de puntuaciones máximas de una sala de recreativos para enseñar el concepto de [colecciones][collection] de clave-valor ([mapas][types-map], [hashes][types-hash_map], arrays asociativos, [diccionarios][dict], etc.). El nombre de un jugador sirve como clave y la puntuación como valor.

## Tareas

A continuación, se guía al estudiante a través de varias operaciones:

- Crear una nueva colección vacía.
- Añadir un jugador a la colección.
- Introducir los valores asociados a jugadores existentes en la colección.
- Actualizar los valores de la colección.
- Devolver un array ordenado por clave a partir de la colección.
- Devolver un array ordenado por valor a partir de la colección.
