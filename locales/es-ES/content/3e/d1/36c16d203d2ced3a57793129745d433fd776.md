# Instrucciones

En este ejercicio vas a trabajar en un planificador de citas para un salón de belleza.

Tienes tres tareas, y todas ellas estarán relacionadas con las fechas de las citas.

## 1. Comprobar si una cita ya ha pasado

Implementa la subrutina `appointment_has_passed`, que recibe un string con una fecha y comprueba si la cita fue en algún momento del pasado:

```perl
appointment_has_passed("2019-07-25T13:45:00")
// => true
```

Los strings de fecha se pasarán en formato de fecha y hora ISO 8601: `YYYY-mm-ddTHH:MM:SS`

Tendrás que implementar la subrutina privada `_parse_datetime`.
Se te sugieren un par de módulos:

- [Time::Piece][time-piece] es un módulo del núcleo de Perl.
- [DateTime::Tiny][datetime-tiny] está disponible en CPAN.

## 2. Comprobar si la cita es por la tarde

Implementa la función `is_afternoon_appointment`, que recibe un string con una fecha y comprueba si la cita es por la tarde (>= 12:00 y < 18:00):

```perl
is_afternoon_appointment("2019-07-25T13:45:00")
// => true
```

## 3. Describir la hora y la fecha de la cita

Implementa la función `describe_appointment`, que recibe un string con una fecha y devuelve una descripción de esa fecha y hora:

```perl
describe_appointment("2019-07-25T13:45:00")
// => "You have an appointment on 07/25/2019 1:45 PM"
```

Fíjate en que la hora está en el rango 0-12 y no lleva un cero ni un espacio a la izquierda.

[time-piece]: https://perldoc.perl.org/Time::Piece
[datetime-tiny]: https://metacpan.org/pod/DateTime::Tiny
