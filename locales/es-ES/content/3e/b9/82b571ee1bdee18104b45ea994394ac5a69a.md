# no uses las funciones de `Enum`

El objetivo de este ejercicio es enseñar a usar los arrays y las funciones del módulo `Kernel` y del módulo `List`. Resuélvelo sin usar ninguna de las funciones del módulo `Enum`.

[`Kernel`]: https://hexdocs.pm/elixir/Kernel.html
[`List`]: https://hexdocs.pm/elixir/List.html
[`Enum`]: https://hexdocs.pm/elixir/Enum.html
