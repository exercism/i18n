# Introducción

Una interfaz se puede entender como la firma de una clase, porque describe los campos públicos de esa clase. Una clase _implementa_ una `interface` con la palabra clave `implments`.

Su sintaxis es muy similar a la de una clase, salvo que los métodos aparecen como firmas sin cuerpo:

```haxe
interface Language {
  private var languageName:String;

  public function speak():String;
}

class FrenchSpeaker implements Language {
  var languageName = "French";

  public function speak():String {
    return "Bonjour!";
  }
}
```

Los campos que se implementan desde una interfaz **deben** usar siempre el mismo modificador de visibilidad. Por ejemplo, si la variable `a` es `public` en una interfaz, su implementación también debe ser `public`.
