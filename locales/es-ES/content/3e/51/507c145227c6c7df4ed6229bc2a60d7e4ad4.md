## Introducción

Un puntero es una variable o constante cuyo valor es la dirección de otra variable o constante.
Los punteros son una característica potente y potencialmente peligrosa de C.
Puede resultar complicado entender los punteros.

Las variables y las constantes almacenan su valor en una posición de memoria.
Esa posición de memoria se conoce como la dirección de la variable o la constante.

Para obtener la dirección de una variable usamos el operador de dirección, que es `&`.
```c
int i = 5;
int *i_address = &i;
```

Un tipo seguido de un `*` seguido de un identificador es la forma de declarar un puntero a una variable de ese tipo.
El `*` se conoce como el operador de indirección porque se refiere indirectamente al valor cuya dirección guarda el puntero.

Cuando creamos un array de esta forma

```c
int my_ints[] = {1, 2};
```

El valor de `my_ints` es en realidad su dirección, que además resulta ser la misma que la dirección de su primer elemento.
La dirección de su segundo elemento será la dirección del primer elemento más el tamaño de un `int` en el sistema.

Por eso los punteros se declaran de un tipo determinado.
Si un puntero no supiera a qué tipo apunta, no sabría cuántos bytes avanzar al sumarle `1`.
Sumar `1` a un puntero no significa necesariamente que estemos sumando un byte a la dirección.
Significa que estamos sumando `1` multiplicado por la longitud de su tipo en bytes.
