# Instrucciones

Tienes varias tiendas de porciones de pizza en tu ciudad y quieres escribir una aplicación web que te permita comparar dos configuraciones de pizza distintas para saber quién te dará la porción más grande.

## 1. Escribe una función que calcule el tamaño de las porciones y devuelva nil para entradas no válidas.

Implementa la función `sliceSize(diameter: Double?, slices: Int?) -> Double?`, que, dados el diámetro de una pizza y el número de porciones por pizza, devuelve el área de una porción.
Para diámetros negativos y para un número de porciones menor que 1, devuelve `nil`, ya que no existe una pizza con diámetro negativo y no hay forma de dividir una pizza en menos de 1 porción.
Si cualquiera de los parámetros es `nil`, devuelve también `nil`.

```swift
sliceSize(diameter: 16, slices: 12)
// Returns 16.75516081914556
sliceSize(diameter: nil, slices: 8)
// Returns nil
```

## 2. Procesa la entrada de tu aplicación web para determinar la porción más grande.

Tu aplicación web pasará cuatro strings a tu función, `biggestSlice(diameterA: String, slicesA: String, diameterB: String, slicesB: String) -> String`.
El primer y el segundo string son el diámetro y el número de porciones de la primera pizza, respectivamente, y el tercero y el cuarto son el diámetro y el número de porciones de la segunda pizza, respectivamente.

Implementa `biggestSlice` de forma que intente convertir el diámetro y el número de porciones de cada pizza en un `Double` y un `Int`, respectivamente.
Si se pueden obtener ambos valores a partir de los strings, usa tu primera función para intentar calcular el área; en caso contrario, el área de esa porción es `nil`.
Una vez obtenidas las áreas de ambas porciones, compara las dos áreas siguiendo estas reglas:

1. Si el área de la porción A es un `Double` y la de la porción B es `nil`, devuelve «Slice A is bigger». Si ocurre lo contrario, devuelve «Slice B is bigger».
2. Si ambas áreas son `Double`, devuelve «Slice A is bigger» o «Slice B is bigger» según cuál sea la porción con mayor área.
3. Si ambas áreas son `nil`, o si ambas son `Double` y son iguales, devuelve «Neither slice is bigger».

~~~~exercism/note
Aunque la entrada dé como resultado un área de porción de 0, la porción se sigue considerando válida y debe verse como más grande que una porción con un área de `nil`.
~~~~

```swift
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "14", slicesB: "12")
// Returns "Slice A is bigger"
biggestSlice(diameterA: "10", slicesA: "6", diameterB: "12", slicesB: "8")
// Returns "Slice B is bigger"
biggestSlice(diameterA: "Pepperoni", slicesA: "6", diameterB: "Sausage", slicesB: "12")
// Returns "Neither slice is bigger"
```
