# Introducción

Una `string` en C# es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, puntuación, etc.). Se usan comillas dobles para definir una instancia de `string`:

```csharp
string fruit = "Apple";
```

Los strings se manipulan llamando a los métodos del string. Una vez que se ha construido un string, su valor nunca puede cambiar. Cualquier método que parezca modificar un string en realidad devolverá un nuevo string.

Varios strings se pueden concatenar (sumar) juntos. La forma más sencilla de lograr esto es usando el operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

Para cualquier formato de string más complejo que una simple concatenación, se prefiere la interpolación de strings. Para usar la interpolación en un string, préfijalo con el símbolo del dólar (`$`). Luego puedes usar llaves (`{}`) para acceder a cualquier variable dentro de tu string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
