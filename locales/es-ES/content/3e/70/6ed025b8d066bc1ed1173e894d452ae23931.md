# Introducción

Existen dos mecanismos principales para formatear strings en C#/.NET: el uso de `String.Format()` y la interpolación de strings.

## Formato compuesto

`String.Format()` recibe un string (al que la documentación llama _formato compuesto_) que consta de texto fijo y marcadores de posición (conocidos en la documentación como elementos de formato), y un número variable de argumentos. El valor devuelto resuelve cada elemento de formato con el argumento correspondiente y combina los valores resueltos con el texto fijo.

```csharp
string.Format("I had {0} bitcoins on {1}, the day I forgot my password.", 55.5, new DateTime(2010, 2, 25));
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

Este mecanismo se conoce técnicamente como _formato compuesto_.

## Interpolación de strings

Los strings interpolados llevan el prefijo `$` e incluyen expresiones en tiempo de ejecución encerradas entre llaves. El elemento de formato tiene la siguiente sintaxis: `$"{<interpolationExpression>}"`. Eliminan la necesidad de una lista de argumentos aparte. El resultado es funcionalmente equivalente al mecanismo de `String.Format()`.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf} bitcoins on {thatDay}, the day I forgot my password."
// => "I had 55.5 bitcoins on 2/25/2010 00:00:00, the day I forgot my password." - US settings
```

## Elementos de formato

El texto entre llaves, que son marcadores de posición en el caso del formato compuesto y expresiones interpoladas en el caso de la interpolación de strings, se conoce como _elemento de formato_.

Un elemento de formato puede constar de hasta 3 partes. La primera es la expresión obligatoria o el marcador de posición de argumento, como se ve en el código de ejemplo anterior. Además, hay una alineación opcional (que se introduce con una coma, «,») y un _string de formato_ opcional (que se introduce con dos puntos, «:»).

`{<interpolationExpression>[,<alignment>][:<formatString>]}`

La _alineación_ especifica la longitud del «campo» en el que se coloca el texto, que se rellena con espacios por la izquierda si la alineación es positiva o por la derecha si es negativa.

El _string de formato_ especifica la forma del texto de salida, por ejemplo si se deben incluir separadores de miles en un número o si solo se debe mostrar la parte de la fecha de un objeto `DateTime`.

El siguiente código ilustra cómo mostrar la parte de la fecha de un objeto `DateTime` y un número de coma flotante en forma exponencial.

```csharp
var loadsOf = 55.5;
var thatDay = new DateTime(2010, 2, 25);
$"I had {loadsOf:E} bitcoins on {thatDay:d}, the day I forgot my password."
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings

string.Format(
    "I had {0:E} bitcoins on {1:d}, the day I forgot my password.",
    loadsOf, thatDay)
// => I had 5.550000E+001 bitcoins on 02/25/2010, the day I forgot my password. - US settings
```

Existe tanto formato estándar como personalizado, tanto para números como para fechas. No hay una diferencia fundamental entre el formato _personalizado_ y el _estándar_, salvo que tienes la oportunidad de componer strings de formato personalizados a partir de letras de formato.

## Cultura

Cada hilo tiene una cultura predeterminada, `Thread.CurrentThread.CurrentCulture`, encapsulada en una instancia de `CultureInfo`. La cultura del hilo determina cómo se formatean las fechas y los números con respecto a variaciones regionales, como la diferencia en el formato de fecha convencional entre el _DD/MM/YYYY_ del Reino Unido y el _MM/DD/YYYY_ de EE. UU.

`CultureInfo` implementa la interfaz `IFormatProvider`, que se puede pasar a determinadas sobrecargas de `String.Format()`. Esto permite anular la cultura del hilo.
