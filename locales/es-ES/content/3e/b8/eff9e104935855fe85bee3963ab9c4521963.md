# Pistas

## General

- Todas las direcciones de memoria de este ejercicio están alineadas a 16 bytes, así que los movimientos alineados (`movdqa` para enteros, `movaps` para números de coma flotante) son apropiados.
  Una dirección alineada también se puede usar directamente como operando fuente de memoria.

## 1. Convertir una imagen al orden de visualización

- Dentro de cada píxel de 4 bytes, la conversión intercambia el byte en el desplazamiento `0` (rojo) con el byte en el desplazamiento `2` (azul), y deja los desplazamientos `1` (verde) y `3` (alfa) tal cual.
  El mismo patrón se repite en los cuatro píxeles.
- Se puede usar una [permutación][pshufb] para reordenar bytes in situ según los índices de un vector de control.
- El vector de control puede definirse en memoria.
- Puede haber más de un bloque, y cada bloque tiene 16 bytes.

## 2. Rellenar una región con un solo color

- El color es un único píxel de 4 bytes.
  Para almacenarlo 16 bytes a la vez, primero hay que [difundirlo][pshufd] por los cuatro carriles de un registro `xmm`.
- Primero hay que [mover][pinsrd] un píxel de 4 bytes a un registro `xmm` antes de difundirlo.
- Todos los bloques rellenos son idénticos, así que el registro relleno se puede crear una sola vez y reutilizarlo después.
- Puede haber más de un bloque, y cada bloque tiene 16 bytes.

## 3. Entrelazar dos líneas de barrido

- Se pueden usar las instrucciones de [desempaquetado][unpack] para entrelazar los bytes de dos operandos.
- Ambas instrucciones de desempaquetado toman el primer byte de cada pareja del operando destino, y el segundo del operando fuente.

## 4. Empaquetar una fila aclarada

- Se pueden usar las instrucciones de [empaquetado][pack] para estrechar los carriles y, a la vez, limitar sus valores.
- Las instrucciones de empaquetado toman los carriles bajos del operando destino, y los carriles altos del operando fuente.

## 5. Dividir las coordenadas en x e y

- Se pueden usar [permutaciones de coma flotante][shufps] para seleccionar y reordenar los carriles de dos operandos.
- Las coordenadas `x` están en los carriles pares (`0` y `2`) de cada entrada, y las coordenadas `y` en los carriles impares (`1` y `3`).
