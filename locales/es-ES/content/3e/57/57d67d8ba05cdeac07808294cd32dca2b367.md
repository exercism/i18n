# Introducción

Una **palabra** es el nombre que da Factor a una función. Partiendo de la pila de datos de `basics`, este concepto trata de definir tus propias palabras: hacer aritmética, dar nombre a valores fijos y componer palabras a partir de otras palabras.

Una definición empieza por `:`, indica un efecto de pila, después el cuerpo y, por último, `;`. El compilador comprueba que el cuerpo coincide con el efecto declarado:

```factor
: square ( x -- x*x ) dup * ;

4 square .    ! => 16
```

Las palabras de aritmética de enteros `+`, `-` y `*` sacan dos números cada una y apilan el resultado. Viven en el vocabulario `math`, así que un archivo que las use necesita `math` en su línea `USING:`. La parte superior de la pila es el operando de la derecha:

```factor
2 3 + .    ! => 5
8 3 - .    ! => 5    (8 - 3, not 3 - 8)
2 3 * .    ! => 6
```

`CONSTANT:` da nombre a un valor fijo. Una constante es en sí misma una palabra: llamarla apila el valor:

```factor
CONSTANT: pi 3

pi pi * .    ! => 9
```

El cuerpo de una palabra puede llamar a cualquier palabra que ya esté dentro del scope, incluidas las que hayas definido antes en el mismo archivo:

```factor
: double    ( x -- 2x ) 2 * ;
: quadruple ( x -- 4x ) double double ;

5 quadruple .    ! => 20
```

Una `?` al final de las salidas es la convención para indicar un Boolean, y tanto las palabras como las constantes usan `lowercase-kebab-case`.
