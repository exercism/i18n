# Acerca de

Para ejecutar lógica repetidamente, se pueden usar bucles. Si el código de un bucle debe ejecutarse siempre al menos una vez, se puede usar un bucle `do`/`while`:

```csharp
int x = 0;

do
{
    x = GetX();
    // do something with x
}
while (x != 0);
```

Se usa con menos frecuencia que un bucle `while`, pero en algunos casos da como resultado un código de aspecto más natural.
