# Instrucciones

En el mundo mágico de Echoes existe un poderoso hechizo llamado «EchoSpeak».
Este hechizo permite a los magos comunicar sus pensamientos y observaciones mediante palabras habladas, que unas plumas mágicas se encargan de escribir.
Para dominar este hechizo, los magos deben aprender a formular sus palabras y sus pensamientos de forma clara y concisa, ya sea sobre números, objetos o complejas construcciones mágicas.

Tu tarea como aprendiz de mago es dominar el arte de EchoSpeak.
Para ello tendrás que aprender a imprimir distintos tipos de datos mágicos en los pergaminos encantados.
EchoSpeak funciona tomando una tinta mágica especial, representada por el `ByteArray`, e inscribiendo mensajes formateados en el pergamino mediante hechizos como `println!` y `print!`.

Sin embargo, cuando se trata de construcciones mágicas personalizadas, como objetos o hechizos encantados, EchoSpeak necesita un conjuro especial para entender cómo representar esos objetos.
Ahí es donde entra tu magia: aprender a implementar hechizos especiales conocidos como `traits` para objetos mágicos personalizados.

## 1. Formatear palabras mágicas

A veces, los magos necesitan formatear sus palabras mágicas antes de inscribirlas en los pergaminos.
Escribirás una función que formatee tres palabras mágicas en un único mensaje.

Implementa una función llamada `format_magical_chant` que devuelva un string con la forma «chant1-chant2-chant3».

Ejemplo:

```rust
let result = format_magical_chant("Spark", "Shine", "Glow");
assert_eq!(result, "Spark-Shine-Glow");
```

## 2. Hacer eco de objetos encantados personalizados

El reino de Echoes está lleno de objetos encantados.
Uno de ellos es la EchoStone, que contiene dos atributos mágicos: poder y duración.
Tu tarea es implementar la función `stringify_echo_stone`, que convierte una EchoStone en un `ByteArray` con el formato especial `"EchoStone [power: x, duration: y]"` implementando el trait `Display`.

Ejemplo:

```rust
let stone = EchoStone { power: 100, duration: 300 };
assert_eq!(stringify(stone), "EchoStone [power: 100, duration: 300]");
```

## 3. Depurar la magia

Como aprendiz de mago, depurar es esencial para las construcciones mágicas complejas.
Crearás una función que imprima una `EchoStone` para depurarla usando el trait `Debug`.
El formato debe ser: `"Debugging EchoStone: { power: x, duration: y }"`.

Ejemplo:

```rust
let stone = EchoStone { power: 25, duration: 10 };
assert_eq!(format!("{:?}", stone), "Debugging EchoStone: { power: 25, duration: 10 }");
```
