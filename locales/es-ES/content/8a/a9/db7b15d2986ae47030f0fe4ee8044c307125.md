# usar una guarda a nivel de función

[comment]: # (Este error se muestra cuando la solución usa guardas, pero no en la cláusula de la función)

Usa [guardas](https://hexdocs.pm/elixir/master/guards.html) en la cláusula de la función para evitar que `two_fer/1` ejecute código con entradas que no sean binarias.

```elixir
def hello(what) when is_binary(what) do
  "Hello, #{what}!"
end
```

Cuando se llama a una función con argumentos que no coinciden con ninguna de las cláusulas definidas, se lanza un `FunctionClauseError`.

```elixir
hello(123)

# => ** (FunctionClauseError) no function clause matching in hello/1
#
#    The following arguments were given to Foo.hello/1:
#
#    # 1
#    123
```
