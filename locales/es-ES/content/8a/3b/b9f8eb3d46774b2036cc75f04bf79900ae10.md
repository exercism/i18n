# Tuplas

Una [tupla][tuple] es una lista ordenada finita de elementos que es inmutable.
Las tuplas requieren que todas las posiciones tengan un tipo fijo.
Esto, a su vez, significa que el compilador sabe qué tipo hay en cada posición.
Los tipos usados en una tupla pueden ser diferentes en cada posición, pero los tipos deben conocerse en tiempo de compilación.

## Crear una tupla

Dependiendo de si los tipos de los valores de la tupla se pueden interpretar durante la compilación, la tupla se puede crear de diferentes formas.
Si los valores se conocen en tiempo de compilación, la tupla se puede crear usando la sintaxis literal de tupla; de lo contrario, hay que declararlos explícitamente.
También es importante que los tipos de los valores coincidan con los tipos especificados en la tupla y que el número de valores coincida con el número de tipos especificados.
Aquí tienes un ejemplo de definición mediante la sintaxis literal de tupla:

```crystal
tuple = {1, "foo", 'c'} # Tuple(Int32, String, Char)
```

También existe la posibilidad de crear una tupla usando la clase `Tuple`.

```crystal
tuple = Tuple(Int32, String, Char).new(1, "foo", 'c')
```

Como alternativa, puedes especificar explícitamente el tipo de la variable asignada a la tupla.

```crystal
tuple : Tuple(Int32, String, Char) = {1, "foo", 'c'}
```

Especificar explícitamente el tipo de la tupla puede ser útil, ya que permite definir que una posición contenga un tipo unión.
Esto significa que una posición puede contener varios tipos.

```crystal
tuple : Tuple(Int32 | String, String, Char) = {1, "foo", 'c'}
```

## Conversión

### Crear una tupla a partir de un array

Puedes crear una tupla a partir de un array usando el método `from` de la clase `Tuple`.
Esto requiere que se especifique el tipo de la tupla.

```crystal
array = [1, "foo", 'c']
tuple = Tuple(Int32, String, Char).from(array)
```

### Conversión a array

Puedes convertir una tupla a un array usando el método `to_a`.
El tipo de elemento del array resultante es la unión del tipo de cada campo de la tupla.

```crystal
tuple = {1, "foo", 'c'}
array = tuple.to_a
array # => [1, "foo", 'c']
```

## Acceder a los elementos

Al igual que los arrays, las tuplas están indexadas desde cero, lo que significa que el primer elemento está en el índice 0.
Sin embargo, a diferencia de los arrays, el tipo de cada elemento es fijo y se conoce en tiempo de compilación; por lo tanto, al indexar una tupla, el tipo del elemento es específico de la posición.
Para acceder a un elemento de una tupla, puedes usar el operador `[]`.

```crystal
array = [1, "foo", 'c']
array[0]         # => 1
typeof(array[0]) # => Int32 | String | Char

tuple = {1, "foo", 'c'}
tuple[0]         # => 1
typeof(tuple[0]) # => Int32
```

Otra diferencia a la hora de acceder a los elementos de los arrays es que, si se especifica el índice, el compilador comprobará que el índice esté dentro de los límites de la tupla.
Esto significa que obtendrás un error en tiempo de compilación en lugar de un error en tiempo de ejecución.

```crystal
tuple = {1, "foo", 'c'}
tuple[3]
# => Error: index out of bounds for Tuple(Int32, String, Char) (3 not in -3..2)
```

Sin embargo, si el índice se guarda en una variable, el compilador no podrá comprobar si el índice está dentro de los límites de la tupla en tiempo de compilación y, en su lugar, dará un error en tiempo de ejecución.

## Subtupla

Puedes obtener una subtupla de una tupla usando el operador `[]` con un rango.
Lo que se devuelve es una nueva tupla con los elementos del rango especificado.
El rango debe darse en tiempo de compilación; de lo contrario, el compilador no podrá conocer los tipos de los elementos de la subtupla.
Esto significa que el rango tiene que ser un literal de rango y no puede estar asignado a una variable.

```crystal
tuple = {1, "foo", 'c'}
subtuple = tuple[0..1] # Tuple(Int32, String)

i = 0..1
tuple[i]
# Error: Tuple#[](Range) can only be called with range literals known at compile-time
```

## Cuándo usar una tupla

Las tuplas son útiles cuando quieres agrupar un número fijo de valores cuyos tipos se conocen en tiempo de compilación.
Esto se debe a que las tuplas requieren menos memoria y son más rápidas que los arrays debido a la inmutabilidad de las tuplas.
Otro caso de uso es devolver varios valores desde un método.
Esto es especialmente útil si los valores tienen tipos diferentes, ya que cada posición de la tupla puede tener un tipo diferente.

Las tuplas no deben usarse cuando se necesita una estructura de datos que pueda crecer o reducir su tamaño, o que necesite modificarse con frecuencia.

# Acerca de

Los [símbolos][symbols] son identificadores con nombre que se pueden usar para referirse a un valor.
Los símbolos se crean mediante un literal de símbolo, que consiste en prefijar un nombre con el carácter `:`, p. ej. `:foo`.
También se pueden escribir entre comillas, p. ej. `:"foo"`, lo que permite, por ejemplo, espacios en el nombre.

```crystal
:foo           # => :foo
:"foo boo"     # => :"foo boo"
:foo == :"foo" # => true
```

Los símbolos se usan en muchos lugares del lenguaje, incluso como claves en tuplas con nombre y para representar nombres de métodos y variables.

## Símbolos en Crystal

Los símbolos en Crystal son bastante diferentes de los de Ruby.
En Crystal, un símbolo es un tipo de constante y, por lo tanto, se asigna en tiempo de compilación.
Esto significa que los símbolos no se pueden crear dinámicamente, algo que sí es posible en Ruby.

Los símbolos en Crystal se representan como `Int32`s, lo que los hace muy eficientes.

## Conversión

Los símbolos se pueden convertir a strings, pero no al revés.
Esto se debe a que los símbolos se crean en tiempo de compilación y los strings se crean en tiempo de ejecución.

```crystal
:foo.to_s # => "foo"
```
