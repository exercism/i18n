# Acerca de

Dart combina la programación orientada a objetos y el tipado estático con la flexibilidad de lenguajes dinámicos como JavaScript.
Diseñado para simplificar las tareas habituales de programación, Dart ha ganado popularidad rápidamente en la comunidad de desarrollo de software, sobre todo por su estrecha integración con [Flutter](https://flutter.dev), un framework muy utilizado para el desarrollo multiplataforma.

## Conceptos clave de Dart

- **Simple y familiar:** Dart es fácil de aprender para quienes ya conocen lenguajes como Java, JavaScript o C#.
  Tiene una sintaxis limpia y coherente, lo que lo hace accesible.
- **Lenguaje moderno orientado a objetos:** Dart incorpora principios modernos de la orientación a objetos y ofrece un soporte sólido para clases, herencia e interfaces.
- **Tipado fuerte con flexibilidad:** aunque Dart es un lenguaje de tipado estático, ofrece inferencia de tipos flexible y funcionalidades dinámicas, de modo que reúne lo mejor de ambos mundos.
- **Programación asíncrona sin complicaciones:** las palabras clave `async` y `await` de Dart simplifican la concurrencia.
  El modelo basado en eventos, construido en torno a los **isolates** (estructuras ligeras similares a hilos), permite una ejecución asíncrona eficiente sin necesidad de complicarse con hilos.
- **Herramientas y bibliotecas completas:** Dart ofrece amplias bibliotecas integradas, y su ecosistema se refuerza con [Pub.dev](https://pub.dev), un gestor de paquetes que proporciona una gran variedad de bibliotecas y herramientas de código abierto.
- **Desarrollo multiplataforma:** Dart impulsa [Flutter](https://flutter.dev), uno de los frameworks más populares para crear aplicaciones multiplataforma de alto rendimiento para móvil, web y escritorio a partir de un único código base.
- **Compatibilidad con la web:** el código Dart puede transpilarse a JavaScript, lo que lo hace apto tanto para el desarrollo web del lado del cliente como del lado del servidor.
  Frameworks como [AngularDart](https://github.com/angulardart-community) (anteriormente [https://github.com/angulardart](https://github.com/angulardart)) están pensados específicamente para aplicaciones web hechas con Dart.
- **Capacidades del lado del servidor:** Dart no sirve solo para el desarrollo frontend; también permite crear aplicaciones de servidor escalables con frameworks como [Shelf](https://pub.dev/packages/shelf).
- **Alto rendimiento:** el código Dart se compila a código máquina nativo para aplicaciones móviles y de escritorio, y a JavaScript optimizado para la web, lo que ofrece un alto rendimiento en todas las plataformas.

## Versatilidad de Dart

- **Aplicaciones móviles:** el uso más destacado de Dart es el desarrollo de aplicaciones móviles mediante Flutter, que permite mantener una interfaz de usuario y una lógica de negocio coherentes en iOS y Android.
- **Desarrollo web:** Dart puede compilarse a JavaScript para crear aplicaciones web modernas, ya sea con frameworks nativos de Dart o con Flutter para web.
- **Desarrollo de escritorio:** con Flutter, Dart permite ahora crear aplicaciones nativas para Windows, macOS y Linux, con una capacidad multiplataforma real.
- **Servicios de backend:** Dart se usa cada vez más en servicios de backend gracias a su sintaxis concisa y a sus optimizaciones de rendimiento.
  Puede encargarse de API RESTful, microservicios y mucho más.
- **Integración con Firebase y la nube:** Dart tiene un soporte sólido para integrarse con Firebase y otros servicios en la nube mediante bibliotecas oficiales, lo que lo convierte en una opción preferente para aplicaciones conectadas a la nube.

## Mejoras recientes

- **Seguridad frente a nulos sólida:** Dart introdujo la **seguridad frente a nulos sólida**, que ayuda a eliminar los errores de referencia nula garantizando que los tipos no anulables se usen correctamente durante el desarrollo.
- **Compilación más rápida:** Dart ha avanzado mucho en la mejora de su proceso de compilación, con compilación **anticipada (AOT)** y **justo a tiempo (JIT)**, lo que garantiza ciclos de desarrollo rápidos y compilaciones de publicación optimizadas.
- **Escritorio y dispositivos integrados:** la expansión de Flutter al escritorio y a las plataformas integradas ha hecho que Dart sea más versátil que nunca, y permite crear aplicaciones para una amplia variedad de dispositivos más allá del móvil y la web.

El ecosistema en crecimiento de Dart, su sólido respaldo entre los desarrolladores y sus capacidades multiplataforma lo convierten en una opción atractiva para el desarrollo de aplicaciones modernas.
