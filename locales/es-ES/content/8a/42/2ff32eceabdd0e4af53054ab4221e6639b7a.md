# Pruebas

Cada ejercicio incluye un archivo de pruebas.
Ejecuta las pruebas con el programa `bats`.

```bash
bats hello_world.bats
```

Si necesitas imprimir la salida de depuración mientras ejecutas las pruebas en local, consulta [Depuración en local][debugging].

Tendrás que instalar `bats`.
Consulta la página [Pruebas en el track de Bash][tests] para obtener instrucciones sobre cómo instalar `bats` en tu sistema.

[tests]: https://exercism.org/docs/tracks/bash/tests
[debugging]: https://exercism.org/docs/tracks/bash/debugging

## Pruebas omitidas

Resolver un ejercicio significa conseguir que todas sus pruebas pasen.
De forma predeterminada, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencionado, ya que te permite centrarte en que pase esa única prueba.
Cuando pase, puedes habilitar la siguiente prueba comentando o eliminando la siguiente anotación:

```bash
[[ $BATS_RUN_SKIPPED == true ]] || skip
```

## Anular las omisiones

Para ejecutar todas las pruebas, incluidas las que tienen anotaciones `skip`, puedes ejecutar:

```bash
BATS_RUN_SKIPPED=true bats exercise_name.bats
```

Puede resultar cómodo usar una función envoltorio para no tener que escribir tanto:

```bash
bats() {
    BATS_RUN_SKIPPED=true command bats *.bats
}
```

Después, ejecuta las pruebas simplemente con:

```bash
bats
```
