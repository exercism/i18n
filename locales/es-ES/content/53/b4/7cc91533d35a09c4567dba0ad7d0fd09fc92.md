# Rangos

Los [rangos][range] representan un intervalo entre dos valores.
Los tipos más comunes que admiten rangos son `Integer` y `String`.
Se pueden usar para muchas cosas, como crear una colección rápidamente, extraer subcadenas, comprobar si un valor está dentro de un rango o iterar.
Se crean con el operador de rango `..` o `...` (inclusivo y exclusivo, respectivamente).

```ruby
1..5  # => 1..5
1...5 # => 1...5

(1..5).to_a # => [1, 2, 3, 4, 5]
(1...5).to_a # => [1, 2, 3, 4]
```

La razón de tener dos operadores de rango es permitir crear rangos que incluyan o excluyan el valor final, lo cual puede resultar útil cuando, por ejemplo, trabajas con índices que empiezan en cero.

Los rangos también se pueden crear con el inicializador de `Range`.

```ruby
Range.new(1, 5) # A range containing 1, 2, 3, 4, 5
```

~~~~exercism/note
Cuando creas un rango en Ruby con los operadores de rango `..` o `...` y quieres llamar a un método sobre el rango, tienes que envolver el rango entre paréntesis.
Esto se debe a que, de lo contrario, el método se llamará sobre el segundo argumento del operador de rango.

```ruby
(1..5).sum # => 15
1..5.sum # => Error: undefined method `sum' for 5:Integer (NoMethodError)
```
~~~~

## Obtener subcadenas

Cuando quieres extraer un fragmento de un string, puedes usar el operador de rango para obtener una subcadena.
Es decir, creando un rango con el índice inicial y final de la subcadena.

```ruby
"Hello World"[0..4] # => "Hello"
"Hello World"[6..10] # => "World"
```

También puedes usar índices negativos para obtener la subcadena desde el final del string.

```ruby
"Hello World"[-5..-1] # => "World"
"Hello World"[6..-4] # => "Wo"
```

## Métodos de los rangos

Los rangos tienen un conjunto de métodos con los que puedes trabajar.
Por ejemplo, estos métodos sirven para obtener la suma de todos los valores del rango o para comprobar si el rango incluye un valor.

| Método                  | Descripción                                                             | Ejemplo                         |
| ----------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| [`sum`][sum]            | Devuelve la suma de todos los valores del rango                         | `(1..5).sum # => 15`            |
| [`size`][size]          | Devuelve el tamaño del rango                                            | `(1..5).size # => 5`            |
| [`include?`][indlude]   | Devuelve `true` si el rango incluye el valor dado; en caso contrario, `false` | `(1..5).include?(3) # => true` |

## Rangos sin fin y sin principio

Un rango puede ser sin fin y sin principio.
En un rango sin fin o sin principio, el valor inicial o final es `nil`, pero al definir el rango se puede omitir ese `nil`.

Usar rangos sin principio y sin fin resulta útil cuando quieres, por ejemplo, extraer un fragmento de un string desde el principio o hasta el final.

```ruby
"Hello World"[0..] # => "Hello World"
"Hello World"[4..] # => "o World"
"Hello World"[..5] # => "Hello"
```

~~~~exercism/caution
Si no se usa sobre una colección, el rango sin fin puede provocar una secuencia sin fin si no se usa con cuidado.
~~~~

## Rangos de strings

Los strings también se pueden usar en rangos y permiten obtener un intervalo de strings entre dos strings.
Su comportamiento puede resultar un poco inesperado con ciertos strings, así que úsalo con cuidado.

```ruby
"aa".."az".to_a # => ["aa", "ab", "ac", ..., "az"]
```
