# Tests

Para probar tu solución, simplemente ejecuta:

```bash
make test
```

Esto ejecutará el archivo de tests `<exercise-name>-test.ys`, que contiene todos los
tests que tendrás que pasar para que tu solución sea correcta.
Deberías estudiar el archivo de tests para entender exactamente qué tiene que hacer tu
solución.

> Nota: La primera vez que ejecutes `make test`, también se asegurará de que la
> versión correcta del intérprete `ys` de YAMLScript esté instalada en el
> lugar correcto.

Si ejecutas `make test` antes de cambiar ningún archivo, todos los tests fallarán.
Este es el comportamiento correcto y esperado.
El proceso normal de desarrollo de un ejercicio consiste en mejorar tu solución de
forma iterativa, ejecutando `make test` después de cada cambio, hasta que pasen
todos los tests.

Si quieres ejecutar solo un test concreto (mientras te concentras en esa parte de la
solución), puedes añadir este par clave/valor a ese test:

```yaml
  ONLY: true
```

Si quieres omitir algunos tests concretos (mientras trabajas en otras partes de la
solución), puedes añadir este par clave/valor a esos tests:

```yaml
  SKIP: true
```


## Requisitos previos para ejecutar los tests

Actualmente, YAMLScript se ejecuta en MacOS y Linux.

Tu ordenador tendrá que tener instalados los siguientes comandos, muy habituales:

* `bash`: Puedes ejecutar los tests con cualquier shell, pero `bash` tiene que estar disponible.
* `make`: Tienes que usar GNU `make` para ejecutar los tests.
  En algunos entornos puede que tenga un nombre distinto de `make`.
  Puede que sea `gmake`.
* `prove`: Este programa forma parte de cualquier instalación normal de Perl.
* `curl`: Se usa para instalar ys si aún no está instalado.

Es muy probable que ya tengas todos estos programas instalados.
