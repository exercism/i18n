# Tests

Para ejecutar los tests de esta pista, tendrás que instalar
DUnitX. Consulta las instrucciones de [instalación](http://www.exercism.org/docs/tracks/delphi/installation) para obtener más información.

### Cargar ejercicios en Delphi

Si Delphi está instalado correctamente y los archivos `*.dpr` están asociados con Delphi, al hacer doble clic en el archivo `*.dpr` proporcionado se iniciará Delphi y se cargará el ejercicio/proyecto. `control + F9` es el atajo de teclado para compilar el proyecto, o bien, si pulsas `F9`, se compilará y se ejecutará el proyecto.

También puedes iniciar Delphi y cargar tu proyecto desde el menú desplegable `File`.
