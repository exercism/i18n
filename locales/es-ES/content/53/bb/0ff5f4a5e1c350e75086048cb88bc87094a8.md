# Introducción

## Variables y asignación

R es un lenguaje de tipado dinámico, por lo que, en general, no es necesario especificar el tipo de una variable. El operador de asignación preferido es `<-`

```R
x <- 42
avogadro <- 6.02e23
mystr <- "Hello, World!"
```

Usar `=` en lugar de `<-` suele funcionar, aunque no siempre, y se desaconseja por ser un mal estilo.
Si trabajas en RStudio, puedes introducirlo con el atajo de teclado `Alt-minus`.

Los operadores son en su mayoría convencionales, pero fíjate en `%/%` y `%%`:

```R
2 + 3   # 5
2 - 3   # -1
2 * 3   # 6
2 / 3   # 0.6666667
8 %/% 3 # 2 (integer division)
8 %% 3  # 2 (remainder)
2 ^ 3   # 8 (exponential)
```

En R, `#` inicia un comentario de una sola línea.
No hay una sintaxis aparte para los comentarios de varias líneas.

## Funciones

Para definir una función:

```R
squareit <- function(x) {
    x * x
}
```

Las funciones pueden tener cero o más argumentos, separados por comas.
Los paréntesis `()` son necesarios con `function()`, aunque no haya parámetros.

Se pueden especificar valores por defecto para los argumentos de una función, aunque deben ir después de cualquier argumento sin valor por defecto y hay que usar `=`, no `<-`, para asignar el valor por defecto.
Como ejemplo un tanto inútil:

```R
squareit <- function(x = 42) {
    x * x
}

squareit()
#> [1] 1764
```

Las llaves `{ }` no son estrictamente necesarias para cuerpos de función de una sola línea, pero incluirlas se considera buen estilo.

R devolverá automáticamente el valor final de una función, como en los ejemplos anteriores.

Se puede usar `return()` en cualquier punto del cuerpo de la función para hacer explícito un valor devuelto.

Llamar a una función es igual que en muchos otros lenguajes:

```R
squareit(3)
#> [1] 9
```
