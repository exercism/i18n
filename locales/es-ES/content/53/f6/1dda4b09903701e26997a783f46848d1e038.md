# Pruebas

Para ejecutar las pruebas, ejecuta el comando `sbt test` en el directorio del ejercicio.
Consulta la [página de pruebas](https://exercism.org/docs/tracks/scala/tests) para obtener más información.

## Pruebas omitidas

Al principio, solo se habilitará la primera prueba.
El objetivo es animarte a resolver el ejercicio paso a paso.
Cuando consigas que la primera prueba pase, elimina la palabra clave `pending` del principio de la siguiente prueba y trabaja para que esa prueba también pase.
