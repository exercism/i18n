# Strings

Un string, o cadena de caracteres, es una secuencia de caracteres encerrada entre comillas.
Se admiten tanto las comillas simples como las dobles.

```php
<?php

$where = "Spain";
$what = 'rain';
```

## Expansión de variables en los strings

En los strings entre comillas dobles, si se hace referencia a una variable que está dentro del scope, su valor se inserta en el string.

```php
<?php

$answer = 42;
$expanded = "The answer to life, the universe, and everything is $answer"; 
```

## Compatibilidad con la codificación de caracteres

Históricamente, las funciones para strings de PHP solo admitían caracteres ASCII y no admitían las codificaciones Unicode modernas.
Cada carácter ASCII ocupa 1 byte, mientras que los caracteres Unicode pueden ocupar de 1 a 4 bytes.
Si necesitas manipular strings Unicode de forma segura, consulta las [versiones multibyte][multi-byte-fns] de las funciones históricas.

```php
<?php

$byte_length = strlen('😃'); // => 4
$string_length = mb_strlen('😃'); // => 1
```

[multi-byte-fns]: https://www.php.net/manual/en/ref.mbstring.php
