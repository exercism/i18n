# Acerca de

Cuando recorres una secuencia, a veces el elemento por sí solo no basta: también necesitas la posición. Las palabras de iteración *indexada* de Factor le pasan a la quotation de cada elemento tanto el elemento como el índice, con el índice en la parte superior de la pila. `times` es la palabra relacionada para la iteración contada sin una secuencia subyacente.

```factor
USING: io kernel math.parser sequences ;

! map-index: build a new sequence; quot sees ( elt index )
{ "alice" "bob" "carol" }
[ number>string ": " glue ] map-index .
! => { "alice: 0" "bob: 1" "carol: 2" }

! each-index: for side effect; quot sees ( elt index )
{ "alice" "bob" } [
    number>string ": " glue print
] each-index
! prints alice: 0
! prints bob: 1

! times: run a quotation N times
3 [ "tick " print ] times
```

| palabra      | efecto                                                               |
|--------------|----------------------------------------------------------------------|
| `each-index` | `( seq quot: ( elt index -- ) -- )`                                  |
| `map-index`  | `( seq quot: ( elt index -- newelt ) -- newseq )`                    |
| `times`      | `( n quot: ( -- ) -- )`, pero consulta más abajo                     |

Un matiz sobre `times`: aunque su quotation está documentada como
`( -- )`, la palabra es `inline`, así que una quotation con el efecto
equilibrado como `( str -- str )` funciona sin problema y va pasando la
pila de una iteración a otra. Eso te da un acumulador con contador sin
ningún estado mutable:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

El mismo truco funciona con `each-index` y `map-index`: el efecto
declarado por elemento es un *mínimo*, no un máximo.
