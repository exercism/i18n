# Instalación

## Instalación de Clojure CLI

Clojure ofrece herramientas de línea de comandos para ejecutar un REPL interactivo (Read-Eval-Print Loop), ejecutar programas de Clojure y evaluar expresiones de Clojure.
Te animamos a usar Clojure CLI con los ejercicios. Para instalar la [CLI de Clojure](https://clojure.org/guides/deps_and_cli):

### Windows
Para ver las instrucciones de instalación en Windows, consulta: [Instalación de Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_windows).

### Linux
Para ver las instrucciones de instalación en la mayoría de las plataformas, consulta: [Instalación de Clojure CLI](https://clojure.org/guides/getting_started#_installation_on_linux).

### Homebrew para Mac OS X
Actualiza Homebrew:

``` bash
$ brew update
```

Instala Clojure CLI:
``` bash
$ brew install node clojure/tools/clojure
```

`Node` es necesario para el entorno de Node.

## Probar la instalación

Para comprobar que la instalación es correcta, ejecuta `clojure --help`; te mostrará la versión si todo ha ido bien.

```bash
$ clojure --help
Version: 1.10.1.547
...
```
