# Apéndice de instrucciones

## Registros

| Registro | Uso           | Tipo           | Descripción                                |
| -------- | ------------- | -------------- | ------------------------------------------ |
| `$a0`    | entrada       | número entero  | número natural que se va a factorizar      |
| `$a1`    | entrada/salida | dirección     | array de destino para los factores primos  |
| `$v0`    | salida        | número entero  | número de factores                         |
| `$t0-9`  | temporal      | cualquiera     | se usa para almacenamiento temporal        |
