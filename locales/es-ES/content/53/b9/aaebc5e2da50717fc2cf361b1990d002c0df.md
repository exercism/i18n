# Instalación

## Instala .NET 10

El track de Visual Basic usa .NET 10.
Para compilar y probar los ejercicios en local, instala [el SDK de .NET 10 para tu sistema operativo][install-sdk]:
Instala el SDK, no solo el runtime.

## Comprueba tu instalación

Abre un terminal nuevo y ejecuta:

```bash
dotnet --version
```

El comando debería mostrar `10.0.0` o una versión posterior.

## Compatibilidad con los editores

El SDK de .NET y un editor de texto básico son todo lo que necesitas para completar los ejercicios.
Si quieres funcionalidades más avanzadas, como el autocompletado de código y la depuración, plantéate usar uno de estos editores:

- [Visual Studio 2026][visual-studio] en Windows
- [Visual Studio Code][visual-studio-code] en Windows, Linux o macOS
- [JetBrains Rider][rider] en Windows, Linux o macOS

[rider]: https://www.jetbrains.com/rider/
