# Acerca de

Puedes usar los [tipos de enumeración][enumeration types] siempre que tengas un conjunto fijo de valores constantes. Usar un `enum` te ofrece una forma con seguridad de tipos de interactuar con valores constantes. Un enum se define con la palabra clave `enum`. A un miembro del enum se hace referencia anteponiéndole el nombre del enum y un punto (por ejemplo, `Status.Active`).

Cada miembro del enum es una asociación de un nombre y un valor `int`. Si el primer miembro no tiene un valor explícito, su valor se establece en `0`. Si no se define explícitamente ningún valor para un miembro del enum, su valor se asigna automáticamente al valor del miembro anterior más `1`.

```csharp
enum Season
{
    Spring,     // Auto set 0
    Summer = 2, // Set the value 2
    Autumn,     // Auto set 3
    Winter = 7  // Set the value 7
}
```

Los enums son muy declarativos. Compara las siguientes dos llamadas a métodos:

```csharp
Users.WithStatus(1)
Users.WithStatus(Status.Active)
```

Para alguien que lee el código, la segunda versión (con enum) será más fácil de comprender.

## Enums con tipo numérico

Aunque el tipo numérico predeterminado de los valores es `int`, se puede cambiar especificando explícitamente cualquier otro tipo [numérico integral][integral numeric].

El siguiente enum usa el tipo numérico `byte` para sus valores:

```csharp
enum Priority : byte
{
    Low = 0,
    Medium = 127,
    High = 255
}
```

## Convertir a un miembro de un enum

Siempre deberías plantearte usar un enum cuando quieras modelar algo como un Boolean. Además de las ventajas de legibilidad mencionadas anteriormente, los enums tienen otra ventaja sobre Boolean: siempre se pueden añadir nuevos valores a un enum, mientras que un valor Boolean solo será `true` o `false`. Por tanto, usar un enum está mejor preparado para el futuro.

```csharp
enum Status
{
    Inactive = 0,
    Active = 1
}

Status active = (Status) 1;
active == Status.Active; // True
```

Ten en cuenta que, aunque _se pueden_ convertir valores enteros a un enum, hacerlo puede dar lugar a resultados inesperados cuando el valor entero no se corresponde con ningún valor del enum:

```csharp
Status status = (Status) 2;
status == Status.Inactive; // False
status == Status.Active;   // False
```

## Convertir una cadena a un enum

A veces resulta útil convertir un string a un miembro de un enum según su nombre con [`Enum.Parse`][enum parse]:

```csharp
var input = "Inactive";
Status status = (Status)Enum.Parse(typeof(Status), input);
// Inactive
```

Para comprobar si un nombre o un valor existe en el enum, puedes usar [`Enum.TryParse`][enum tryparse] o [`Enum.IsDefined`][enum isdefined]; ambos devuelven un Boolean que indica si el miembro del enum existe:

```csharp
bool doesExist = Enum.IsDefined(typeof(Status), "Inexistent");
// False
```
