# Pistas

## 1. Calcula el valor de cualquier carta.

- El método `Blackjack.parse_card` debe recibir un string (p. ej. `"ace"`) y devolver su valor (p. ej. 11).
- Define una [instrucción `case`][case] y asigna el valor de la carta como el valor del caso.
- King, Queen, Jack y 10 se pueden manejar con un solo caso.
- La instrucción `case` puede tener un caso `else`.
  En cualquier caso, la función debe devolver `0` para las cartas desconocidas.

## 2. Nombra rangos de valores.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Define una [instrucción `case`][case] y asigna el nombre del rango como el valor del caso.
- La instrucción `case` puede usar objetos [`Range`][range] como casos para comprobar si un valor está dentro de un rango.

## 3. Implementa la lógica de decisión para el primer turno.

- Calcula la puntuación del jugador sumando los valores de las dos cartas del jugador.
- Puedes usar una gran [instrucción `case`][case] sobre la puntuación del jugador
  (quizá con instrucciones `if` anidadas sobre la puntuación del crupier en algunos casos),
- O puedes distinguir distintas categorías de puntuación del jugador (por ejemplo, «manos pequeñas»
  con una puntuación menor que 12, «manos medianas» con una puntuación dentro del rango 12..20 y
  «manos grandes» con una puntuación mayor que 20) y escribir funciones separadas para
  todas (o algunas) de esas categorías.

[case]: https://crystal-lang.org/reference/syntax_and_semantics/case.html
[range]: https://crystal-lang.org/reference/syntax_and_semantics/literals/range.html
