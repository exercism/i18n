# Introducción

El vocabulario [`random`][random] de Factor ofrece una sola palabra genérica, `random`, que se adapta a su argumento, además de palabras auxiliares para barajar y muestrear secuencias.

```factor
USING: random ;

6 random .                       ! a value from 0..5
{ "rock" "paper" "scissors" } random .   ! a random element
{ 1 2 3 4 5 } randomize .        ! the same cards, reordered
{ 1 2 3 4 5 } 2 sample .         ! two distinct elements
```

`random` aplicado a un número entero `n` devuelve un valor en `[0, n)`; aplicado a una secuencia, devuelve un elemento aleatorio. `randomize` baraja in situ y `sample` extrae elementos distintos.

De forma predeterminada, extraen valores de un generador global sembrado a partir del reloj del sistema. Para que los resultados sean reproducibles, instala un generador con semilla con `<mersenne-twister>` (de [`random.mersenne-twister`][mt]) y `with-random`:

```factor
USING: random random.mersenne-twister ;

42 <mersenne-twister> [ 6 random ] with-random .   ! same value every run
```
