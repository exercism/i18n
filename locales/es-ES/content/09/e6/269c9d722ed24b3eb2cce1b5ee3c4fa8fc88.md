# Introducción

## Paquetes y módulos

### Importación

Un módulo se suele cargar con la palabra clave `use`.
Esto lo carga y, además, llama a su método `import`, importando los símbolos exportados.

Los símbolos del array `@EXPORT` del paquete se importan de forma predeterminada.
Los símbolos del array `@EXPORT_OK` del paquete deben importarse explícitamente.

### Exportación

Para que un símbolo se importe, antes debe exportarse.
El módulo [Exporter][Exporter] se incluye con Perl y es una de las opciones más cómodas para exportar.

Definir el módulo:
```perl
package Foo;

use Exporter ('import');
our @EXPORT_OK = ('bar');

sub bar { ... }
```

Usar el módulo:
```perl
use Foo ('bar');

bar();
```

### Módulos principales

Además de [Exporter][Exporter], Perl tiene una gran variedad de [módulos principales][perl-core-modules] disponibles.
Algunos ejemplos útiles para los ejercicios que puedes encontrar aquí son [List::Util][List::Util], [Time::Piece][Time::Piece] y [Math::BigRat][Math::BigRat].

### CPAN

Además de los módulos principales, [CPAN][metacpan] tiene miles de módulos adicionales creados por la comunidad de Perl disponibles para instalar.
El track de Perl usa un [cpanfile][test-runner-cpanfile] para instalar una selección de módulos que se pueden usar con el test runner de Perl de Exercism.
