# Anexo a las instrucciones
 
## Algunas notas adicionales para la implementación en Swift

Los tests de este ejercicio esperan que implementes un par de propiedades que devuelven un valor de tipo `Int` o un [array][array] de tipo `[Int]`. Puedes echar un vistazo a la documentación de la clase Array para encontrar métodos útiles que te ayuden en tu solución.

Los tests finales comprueban la [inmutabilidad][immutability]. Ninguna de las propiedades que tienes que escribir debe modificar las puntuaciones de la partida.

Si quieres practicar un poco más, puedes implementar una función que añada nuevas puntuaciones a la partida o gestionar un array vacío

[array]: https://developer.apple.com/documentation/swift/array
[immutability]: https://en.wikipedia.org/wiki/Immutable_object
