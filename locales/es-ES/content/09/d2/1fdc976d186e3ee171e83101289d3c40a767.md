# Pistas

## General

- Para que un nombre pueda tener varios tipos distintos, tienes que usar un [tipo unión][union-type].
- Para poder usar una variable de instancia en una expresión de control [`if var.is_a?(Type)`][if-is-a], antes hay que asignarla a una variable local.

## 1. Establecer una contraseña

- Tienes que definir una clase con el nombre `PasswordLock`.
- Tienes que definir un método initialize que reciba como argumento un `String`, un `Int32` o un `Float64`.
- Tienes que definir una [variable de instancia][instance-variable] `@password` que se establece con el argumento que se pasa al constructor.

## 2. Cifrar la contraseña

- Define un método de instancia llamado `encrypt`.
- El método debe modificar la [variable de instancia][instance-variable] `@password` para que quede cifrada.
- Para que una rama concreta solo se pueda ejecutar si la variable es de un tipo concreto, tienes que usar el método [`is_a?`][is-a] en una expresión de control.

## 3. Comprobar si una contraseña es correcta

- Puedes usar los métodos que ya has definido para cifrar el intento de contraseña que se te dé.
