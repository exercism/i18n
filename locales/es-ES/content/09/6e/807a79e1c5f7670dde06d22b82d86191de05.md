# no escribas en la consola

Elimina la función o funciones que escriben en la consola, ya que las pruebas no las necesitan y hacen que el código sea un poco más difícil de leer.

Normalmente, estas instrucciones se añaden para ayudar a depurar el código. Sin embargo, un mejor enfoque es depurar el código mientras se ejecutan una o varias pruebas unitarias. Esto tiene la ventaja añadida de que puedes centrarte en depurar un caso de prueba concreto. Aquí tienes algunos enlaces que explican cómo depurar código Scala mientras se ejecutan pruebas unitarias en distintos IDE:

- [IntelliJ](https://www.jetbrains.com/help/idea/run-debug-and-test-scala.html)
- [Eclipse](http://scala-ide.org/docs/current-user-doc/features/scaladebugger/index.html)
