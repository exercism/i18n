El objetivo de este ejercicio es mejorar el ejercicio Comprobador de contraseñas.
Como es probable que una contraseña dada incumpla más de una regla a la vez, un comprobador de contraseñas útil debería comunicar al usuario todas las reglas que se incumplen, en lugar de solo la primera que se descubra.
El comprobador de contraseñas mejorado debería indicar de una sola vez todas las reglas que incumple una contraseña dada.

Las reglas de este comprobador de contraseñas son las mismas que en el ejercicio anterior, Comprobador de contraseñas:

- Debe tener 12 caracteres o más
- Debe tener al menos una letra mayúscula
- Debe tener al menos una letra minúscula
- Debe tener al menos un dígito
- Debe tener al menos un símbolo del conjunto !@#$%^&\*

## 1. Modifica la unión discriminada `PasswordError` para que los valores individuales puedan tratarse como banderas

Ten en cuenta que los tests no compilarán hasta que se complete este paso esencial.

## 2. Implementa la función `checkPassword`

La función `checkPassword` comprueba la contraseña dada contra las reglas mencionadas anteriormente.
La función debe devolver un valor `Result`, donde se devuelve `Ok` cuando la contraseña cumple todas las reglas, y un valor `Error` cuando incumple una o más reglas.
Si la contraseña dada incumple varias reglas, el valor `PasswordError` debe representar todas las reglas incumplidas.

```fsharp
checkPassword "abcdefghijk5"
// => Error (PasswordError.MissingUppercaseLetter ||| PasswordError.MissingSymbol)
```

## 3. Implementa la función ``getStatusPhrases`

La función `getStatusPhrases` devuelve un conjunto de strings, cada uno con una frase legible para las personas que se corresponde con uno de los errores del resultado devuelto por `checkPassword`.

```fsharp
getStatusPhrases (Error PasswordError.MissingDigit ||| PasswordError.LessThan12Characters)
// => List ["12 characters"; "digit"]
```
