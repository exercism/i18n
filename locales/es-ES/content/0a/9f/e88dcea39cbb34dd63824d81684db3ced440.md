# Introducción

## Conceptos básicos 1

### Constantes y funciones

Un valor constante se define con `name = expression`. En Elm, todo lo que no son definiciones son expresiones.

```elm
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`, y los parámetros se separan únicamente por espacios.

```elm
add number1 number2 = number1 + number2
```

Llamar a una función también es una expresión y se hace indicando su nombre y pasando argumentos para cada uno de los parámetros de la función, separados por espacios, igual que en la definición de funciones.

```elm
five = add 2 3
```

Se pueden usar paréntesis para especificar el orden de evaluación de una expresión.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

### Indentación / espacios significativos

Elm no usa marcadores sintácticos como llaves, paréntesis o puntos y coma para especificar los límites del código. En su lugar, usa espacios e indentación.

- Las definiciones de módulo, de import y de funciones de nivel superior deben empezar en la columna más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe estar indentado bajo ella con al menos un espacio.
- Las partes de la expresión que van agrupadas deben indentarse con el mismo número de espacios.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

### Módulos

Cada archivo en Elm es un módulo y debe contener una instrucción `module` antes que cualquier otro código.
Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm.
Todo lo que se define dentro de un módulo tiene un scope privado dentro de él y no se puede acceder desde fuera de este módulo, a menos que aparezca en `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

### Comentarios

Un comentario es un texto dentro del archivo de Elm que no se interpreta como código.
Está pensado principalmente para que lo lean tú y otros programadores.
Existe una sintaxis ligera para los comentarios de una sola línea, basada en dos guiones.
También son posibles los comentarios de varias líneas con el par de delimitadores de apertura y cierre `{-` y `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```

Existe una [guía de estilo](https://elm-lang.org/docs/style-guide) y [elm-format](https://github.com/avh4/elm-format) se puede usar para formatear el código automáticamente.
