# no uses el método main

Prueba a eliminar el método `main` de tu código.
Los tests de los ejercicios no exigen que las soluciones tengan un método `main`, y tener uno hace que el código sea un poco más difícil de leer.

Normalmente, se añade un método `main` para ayudar a hacer debug del código.
Sin embargo, un enfoque mejor es hacer debug del código mientras se ejecutan uno o varios tests unitarios.
Esto tiene la ventaja añadida de que puedes centrarte en hacer debug de un test concreto.

Aquí tienes algunos enlaces que explican cómo hacer debug de código Java mientras se ejecutan tests unitarios en varios IDE:

- [Ejecutar y hacer debug de tests de Java en Visual Studio Code](https://code.visualstudio.com/docs/java/java-testing#_rundebug-test-cases)
- [Hacer debug de tests en IntelliJ IDEA](https://www.jetbrains.com/help/idea/performing-tests.html#RedebugFailedTests)
