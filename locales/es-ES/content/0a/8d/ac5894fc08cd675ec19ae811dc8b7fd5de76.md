# Introducción

## Espacios de nombres

Una técnica importante para organizar el código es el uso de espacios de nombres.
Las clases y los módulos proporcionan espacios de nombres.
Dos métodos podrían tener una colisión de nombres, que se puede resolver colocándolos en espacios de nombres distintos.
Los espacios de nombres pueden anidarse, lo que puede ayudar a estructurar grandes bases de código.
Se accede a los espacios de nombres mediante el operador de resolución de scope `::`.

El ejemplo siguiente muestra el uso de dos métodos `foo` diferentes.
Se usan juntos prefijándolos con sus respectivos espacios de nombres.

```ruby
class MyNamespace
  def self.foo
    44
  end

  class MyInnerNamespace
    def self.baz
      90
    end
  end
end

class MyOtherNamespace
  def self.foo
    -2
  end
end

p MyNamespace::foo + MyOtherNamespace::foo * MyNamespace::MyInnerNamespace::baz  # => -136
```

Ten en cuenta que los espacios de nombres se interpretan según dónde esté el código que se ejecuta.
Para referirte a algo en el espacio de nombres *raíz* (es decir, fuera de todos los espacios de nombres definidos), empieza por `::`.

Por ejemplo:

```ruby
class Example
  def self.example
    5
  end
end

class MyNamespace

  class Example
    def self.example
      10
    end
  end

  def self.call_example
    p Example::example  # => 10
    p ::Example::example  # => 5
  end
end
```
