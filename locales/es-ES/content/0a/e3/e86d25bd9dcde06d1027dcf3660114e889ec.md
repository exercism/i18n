# Instrucciones

En este ejercicio, vas a implementar la lógica de la misión de un nuevo juego de rol que está desarrollando un amigo. La protagonista del juego es Annalyn, una chica valiente con un perro feroz y leal. Por desgracia, ocurre una catástrofe: su mejor amiga ha sido secuestrada mientras buscaba bayas en el bosque. Annalyn intentará encontrar y liberar a su mejor amiga, llevándose opcionalmente a su perro en esta misión.

Tras pasar un tiempo siguiendo el rastro de su mejor amiga, encuentra el campamento en el que está prisionera. Resulta que hay dos secuestradores: un caballero poderoso y un arquero astuto.

Una vez encontrados los secuestradores, Annalyn se plantea cuál de las siguientes acciones puede llevar a cabo:

- Ataque rápido: se puede hacer un ataque rápido si el caballero está durmiendo, ya que tarda un rato en ponerse la armadura, así que estará vulnerable.
- Espiar: se puede espiar al grupo si al menos uno de ellos está despierto. De lo contrario, espiar es una pérdida de tiempo.
- Señalizar al prisionero: se puede hacer señales al prisionero con sonidos de pájaros si el prisionero está despierto y el arquero está durmiendo, ya que los arqueros están entrenados en las señales con sonidos de pájaros, así que podrían interceptar el mensaje.
- _Liberar al prisionero_: Annalyn puede intentar colarse en el campamento para liberar al prisionero.
  Es algo arriesgado y solo puede salir bien de una de estas dos maneras:
  - Si Annalyn lleva consigo a su perro, puede rescatar al prisionero si el arquero está dormido.
    El caballero le tiene miedo al perro y el arquero no tendrá tiempo de prepararse antes de que Annalyn y el prisionero puedan escapar.
  - Si Annalyn no lleva a su perro, tendrán que ser muy sigilosos tanto ella como el prisionero.
    Annalyn puede liberar al prisionero si este está despierto y tanto el caballero como el arquero están durmiendo, pero si el prisionero está durmiendo no se le puede rescatar: el prisionero se asustaría con la aparición repentina de Annalyn y despertaría al caballero y al arquero.

Tienes cuatro tareas: implementar la lógica para determinar si las acciones anteriores están disponibles en función del estado de los tres personajes que se encuentran en el bosque y de si el perro de Annalyn está presente o no.

## 1. Comprueba si la acción «ataque rápido» es posible

Implementa una función llamada `canExecuteFastAttack` que toma un valor Boolean que indica si el caballero está despierto. Esta función devuelve `true` si la acción «ataque rápido» está disponible en función del estado del personaje. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

canExecuteFastAttack knightIsAwake
-- => false
```

## 2. Comprueba si la acción «espiar» es posible

Implementa una función llamada `canSpy` que toma tres valores Boolean, que indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si la acción «espiar» está disponible en función del estado de los personajes. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = true

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSpy knightIsAwake archerIsAwake prisonerIsAwake
-- => true
```

## 3. Comprueba si la acción «señalizar al prisionero» es posible

Implementa una función llamada `canSignalPrisoner` que toma dos valores Boolean, que indican si el arquero y el prisionero, respectivamente, están despiertos. La función devuelve `true` si la acción «señalizar al prisionero» está disponible en función del estado de los personajes. De lo contrario, devuelve `false`:

```purescript
archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

canSignalPrisoner archerIsAwake prisonerIsAwake -- => true
```

## 4. Comprueba si la acción «liberar al prisionero» es posible

Implementa una función llamada `canFreePrisoner` que toma cuatro valores Boolean. Los tres primeros parámetros indican si el caballero, el arquero y el prisionero, respectivamente, están despiertos. El último parámetro indica si el perro de Annalyn está presente. La función devuelve `true` si la acción «liberar al prisionero» está disponible en función del estado de los personajes y de la presencia del perro de Annalyn. De lo contrario, devuelve `false`:

```purescript
knightIsAwake :: Boolean
knightIsAwake = true

archerIsAwake :: Boolean
archerIsAwake = false

prisonerIsAwake :: Boolean
prisonerIsAwake = true

petDogIsPresent :: Boolean
petDogIsPresent = true

canFreePrisoner knightIsAwake archerIsAwake prisonerIsAwake petDogIsPresent
-- => false
```
