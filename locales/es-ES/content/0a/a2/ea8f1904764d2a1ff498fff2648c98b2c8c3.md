# Anexo de instrucciones

Deberías implementar este ejercicio usando una gramática de cláusulas definidas (DCG).
Las DCG no solo sirven para analizar secuencias (arrays), también pueden generarlas, completarlas y comprobarlas.

## Biblioteca

Los archivos de implementación del esqueleto incluyen la siguiente línea:

```prolog
:- use_module(library(dcg/basics)).
```

Esto garantiza que se pueda usar la biblioteca `dcg/basics`, lo cual debería bastar para resolver este ejercicio.
