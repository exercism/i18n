# Pistas

## General

- Lee sobre la [coincidencia de patrones][pattern-matching] en la guía oficial.
- Echa un vistazo a esta chuleta sobre la [desestructuración][destructuring].
- La coincidencia de patrones para registros se [explica aquí][records-pattern-matching] con más detalle.

## 1. Detectar comentarios vacíos

- Puedes usar `(a, b)` directamente en el argumento de la función si el argumento es un par.
- Puedes sustituir los valores que recibes pero que no usas por el comodín `_`.
- Para comprobar si un string está vacío, consulta la [documentación de `String`][string-docs].

## 2. Contar el número de comentarios del creador

- Puedes desestructurar un tipo personalizado con una sola variante `type Box = Box AB` directamente en el argumento de una función así: `(Box ab)`.
- Puedes aplicar coincidencia de patrones al campo `a` de un registro `{a : A, b : B}` usando: `{ a }`.
- Puedes usar ambas técnicas anteriores a la vez para tipos personalizados que contienen un registro.
- No puedes aplicar coincidencia de patrones directamente al par `ab` de un registro `{ ab : (A, B) }`. Primero debes aplicar coincidencia de patrones a `{ ab }` y, después, usar `( a, b) = ab` en una vinculación `let`.
- Para encontrar el número de elementos que cumplen una condición en un array, usa las [funciones de `List`][list-docs].
- Puedes desestructurar pares directamente en los argumentos de las funciones anónimas.

## 3. Detectar tickets asignados al equipo de desarrollo

- Al igual que en la tarea 2, puedes hacer coincidir los campos relevantes de un registro envuelto en una caja en el argumento de la función.
- Puedes usar la coincidencia de patrones de forma recursiva para hacer coincidir un valor anidado como `Just (Box "42")`.
- Puedes usar el comodín `_` para hacer coincidir cualquier cosa en una instrucción `case`. 

## 4. Asignar tickets a los empleados de informática

- Al igual que en las tareas 2 y 3, puedes hacer coincidir los campos relevantes de un registro envuelto en una caja en el argumento de la función.
- Además, puedes usar la palabra clave `as` para aplicar coincidencia de patrones a un campo y también vincular el registro completo: `(Box ({ a } as ab))`.
- Puedes aplicar coincidencia de patrones a los valores de un tipo personalizado con la instrucción `case`.
- Usa el constructor de tipo `Ticket` para devolver un ticket.
- Usa la [sintaxis de actualización de registros][record-update] para modificar registros.
