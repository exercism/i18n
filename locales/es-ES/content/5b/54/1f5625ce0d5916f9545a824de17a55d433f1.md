# Introducción

Cada año, algo nuevo es «la sensación» en tu instituto.
Este año es un juego de dados: [Yacht][yacht].

El juego de Yacht pertenece a la misma familia que el Poker Dice, la Generala y, en particular, el Yahtzee, del cual es un precursor.
El juego consta de doce rondas.
En cada una se lanzan cinco dados y el jugador elige una de las doce categorías.
La categoría elegida se usa después para puntuar la tirada de dados.

[yacht]: https://en.wikipedia.org/wiki/Yacht_(dice_game)
