# Instrucciones

El nuevo aeropuerto de Berlín ha contratado a desarrolladores para su laboratorio de robótica y tú empiezas a trabajar allí.
Tienen unos robots torpes y con un aspecto un tanto humanoide que intentan usar para mejorar la atención al cliente.

Tu primera tarea en el trabajo es escribir un programa para que el robot pueda saludar a las personas en su idioma nativo después de que hayan escaneado su pasaporte en el mostrador de facturación automática.

El robot está orgulloso de sus habilidades, así que siempre dirá primero en qué idioma puede hablar y luego saludará a la persona.
Por ejemplo, si alguien escanea un pasaporte alemán, el robot diría:

```txt
I can speak German: Hallo Dietrich!
```

## 1. Crea la funcionalidad abstracta de saludo

No vas a escribir tú el código de los distintos idiomas, así que tienes que estructurar el código del robot de forma que otros desarrolladores puedan añadir más idiomas fácilmente.

Como primer paso, define una interfaz `Greeter` con dos métodos.

- `LanguageName`, que devuelve el nombre del idioma (un `string`) en el que el robot debe saludar al visitante.
- `Greet`, que acepta el nombre de un visitante (un `string`) y devuelve un `string` con el mensaje de saludo en un idioma concreto.

A continuación, implementa una función `SayHello` que acepte como argumentos el nombre del visitante y cualquier cosa que implemente la interfaz `Greeter`, y que devuelva el string con el saludo deseado.
Por ejemplo, imagina una implementación alemana de `Greeter` para la que `LanguageName` devuelve `"German"` y `Greet` devuelve `"Hallo {name}!"`:

```go
SayHello("Dietrich", germanGreeter)
// => "I can speak German: Hallo Dietrich!"
```

## 2. Implementa el italiano

Ahora tu tarea es hacer que el robot funcione para las personas que escaneen pasaportes italianos.

Para ello, crea una estructura `Italian` e implementa los dos métodos necesarios para que la estructura cumpla la interfaz `Greeter` que definiste en la tarea 1.
Puedes saludar a alguien en italiano con `"Ciao {name}!"`.

## 3. Implementa el portugués

Antes de dar el día por terminado, también tienes que completar la funcionalidad para saludar a las personas en portugués.

Para ello, crea una estructura `Portuguese` e implementa también aquí los dos métodos necesarios para que la estructura cumpla la interfaz `Greeter`.
Puedes saludar a alguien en portugués con `"Olá {name}!"`.
