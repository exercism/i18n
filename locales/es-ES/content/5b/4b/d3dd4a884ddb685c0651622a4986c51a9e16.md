# Pistas

## General

- Puedes realizar todas estas tareas sin usar un condicional `if`.

## 1. Determina si vas a necesitar un carné de conducir

- Usa el [operador de igualdad][cmp] para comprobar si el primer campo es igual a un string concreto.
- Usa una expresión regular para comprobar si el segundo campo contiene las subcadenas necesarias.
- Usa uno de los dos [operadores booleanos][bool] para combinar los dos requisitos.

## 2.Calcula una estimación del precio de un vehículo de segunda mano

- Usa los [operadores de comparación][cmp] para determinar qué descuento usar.

[cmp]: https://www.gnu.org/software/gawk/manual/html_node/Comparison-Operators.html
[bool]: https://www.gnu.org/software/gawk/manual/html_node/Boolean-Ops.html
