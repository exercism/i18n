# Instrucciones

En este ejercicio vas a escribir un TreasureChest genérico (¡y mágico!) para guardar algún tesoro.

## 1. Define el tipo personalizado genérico TreasureChest

Define un tipo personalizado `TreasureChest` con una única variante.

La variante debe tener un valor `String` asociado, que se usará para almacenar la contraseña del cofre del tesoro.

La variante también debe tener un valor genérico asociado, que se usará para almacenar el tesoro.
Este valor es genérico para que el tesoro pueda ser cualquier cosa.

## 2. Define la función getTreasure

Esta función debe recibir dos parámetros:

- un `String` (para probar una contraseña)
- un tipo personalizado genérico `TreasureChest`

Esta función debe comprobar el intento de contraseña proporcionado contra el `String` que hay en el `TreasureChest`.

La función debe devolver un `Maybe`.

Si las contraseñas coinciden, devuelve `Just` con el valor genérico del `TreasureChest` (¡el tesoro!).

Si las contraseñas no coinciden, devuelve `Nothing`.

## 3. Define la función multiplyTreasure

Esta función (de orden superior) debe recibir dos parámetros:

- una función multiplicadora que recibe un parámetro genérico y devuelve un array del mismo tipo genérico
- un tipo personalizado genérico `TreasureChest`, también con el mismo tipo genérico

Esta función debe llamar a la función multiplicadora con el tesoro que hay en el cofre.

La función debe devolver un nuevo TreasureChest, con la misma contraseña que el original y con el tesoro multiplicado (el valor devuelto).
