# Introducción

## Constantes y funciones

Un valor constante se define con `name = expression`, donde en Elm todo, excepto las definiciones, son expresiones.

```elm
five = 5

six = 3 + 3
```

Las funciones se definen con `name parameters... = expression`, y los parámetros se separan solo con un espacio.

```elm
add number1 number2 = number1 + number2
```

Llamar a una función también es una expresión y se hace indicando su nombre y pasando argumentos para cada uno de los parámetros de la función, separados por un espacio, igual que en la definición de la función.

```elm
five = add 2 3
```

Se pueden usar paréntesis para especificar el orden de evaluación de una expresión.

```elm
six = add 2 (1 * 4)

twelve = add 2 1 * 4
```

## Sangrado / espacios en blanco significativos

Elm no usa marcadores sintácticos como llaves, paréntesis o puntos y coma para delimitar el código. En su lugar, usa espacios en blanco y sangrado.

- Las definiciones de módulo, de import y de funciones de nivel superior deben empezar en la columna situada más a la izquierda.
- Si una expresión se divide en varias líneas, el código que forma parte de esa expresión debe ir sangrado bajo ella con al menos un espacio.
- Las partes de la expresión que van agrupadas deben llevar el mismo número de espacios de sangrado.

```elm
-- A function split over multiple lines, so subsequent lines must be indented
add number1 number2 =
    number1 + number2
```

https://elmprogramming.com/indentation.html

## Módulos

Cada archivo en Elm es un módulo y debe contener una instrucción `module` antes que cualquier otro código.
Los nombres de los módulos deben coincidir con el nombre de su archivo, así que el módulo `Calculator` debe estar en el archivo Calculator.elm.
Todo lo que se define dentro de un módulo es privado dentro de él y no se puede acceder desde fuera de ese módulo, a menos que aparezca en `exposing`.

```elm
-- Define the Calculator module, and expose the `add` function
module Calculator exposing (add)

six = 3 + 3

add number1 number2 = number1 + number2
```

```elm
-- Define the Calculator module, and expose everything within: `six` and `add`
module Calculator exposing (..)

six = 3 + 3

add number1 number2 = number1 + number2
```

https://elm-lang.org/docs/syntax#modules

## Comentarios

Un comentario es un texto dentro del archivo de Elm que no se interpreta como código.
Está pensado principalmente para que lo lean tú y otros programadores.
Hay una sintaxis ligera para los comentarios de una sola línea, basada en dos guiones.
También son posibles los comentarios multilínea con el par de delimitadores de apertura y cierre `{-` y `-}`.

```elm
-- a single line comment
-- another single line comment

{- a multiline comment
   spawning multiple lines
-}
```
