# Introducción

Factor es un lenguaje *concatenativo*: cada palabra lee sus entradas de una **pila de datos** compartida y vuelve a colocar sus salidas en ella. No hay otra forma de pasar valores de un sitio a otro.

Escribir un literal lo empuja a la parte superior de la pila; el código se lee de izquierda a derecha:

```factor
1 2 3    ! stack (bottom → top): 1 2 3
```

Una declaración de *efecto de pila* documenta el contrato de una palabra:

```factor
: restow ( a b -- b a ) swap ;
```

`( a b -- b a )` indica que la palabra extrae dos valores y deja otros dos detrás en el orden inverso. Los nombres son documentación (el compilador solo comprueba el *número* de entradas y salidas), y la parte superior de la pila es el nombre de la derecha.

Las **palabras de reordenación** habituales de `kernel` reordenan la parte superior de la pila:

```
dup  ( x   -- x x   )
drop ( x   --       )
swap ( x y -- y x   )
over ( x y -- x y x )
nip  ( x y -- y     )
rot  ( x y z -- y z x )
```

Las palabras se definen con `:` y terminan en `;`; el compilador rechaza una definición cuyo cuerpo no coincida con el efecto declarado.
