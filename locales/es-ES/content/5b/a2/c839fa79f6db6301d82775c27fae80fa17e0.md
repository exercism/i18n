# Anexo a las instrucciones

## Pistas

En este ejercicio te proporcionamos la definición del [tipo de datos algebraico](https://learnyouahaskell.github.io/making-our-own-types-and-typeclasses) llamado `Planet`.
Tienes que implementar la función `ageOn`, que calcula cuántos años tendría alguien en un `Planet` a partir de una edad en segundos.

Puedes usar la firma que te damos si no tienes claros los tipos, pero no dejes que limite tu creatividad:

```haskell
ageOn :: Planet -> Float -> Float
```
