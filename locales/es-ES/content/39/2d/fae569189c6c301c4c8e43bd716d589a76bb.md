# Instructions

Un amigo tuyo tiene una antigua tienda mayorista llamada **Gross Store**.

El nombre proviene de la cantidad del artículo que vende la tienda: todo está en [unidad gross][gross-unit].

Tu amigo te ha pedido que implementes un sistema de punto de venta (POS) para su tienda.

**Primero, quieres construir un prototipo para ello.**

**En tu prototipo, tu sistema solo registrará la cantidad.**

Tu amigo te ha dado una lista de medidas para ayudarte:

| Unidad             | Valor |
| ------------------ | ----- |
| quarter_of_a_dozen | 3     |
| half_of_a_dozen    | 6     |
| dozen              | 12    |
| small_gross        | 120   |
| gross              | 144   |
| great_gross        | 1728  |

## 1. Almacena la unidad de medida en tu programa

Para poder usar la unidad de medida, necesitas almacenarla en tu programa.

```rust
let units = units();
// Felt252Dictionary with entries like { 'dozen': 12 }
```

## 2. Crea una nueva factura del cliente

Necesitas implementar una función que cree una nueva factura (vacía) para el cliente.

```rust
let bill = new_bill();
// Empty Felt252Dictionary
```

## 3. Añade un artículo a la factura del cliente

Para implementar esto, tendrás que:

- Devolver `false` si la `unit` proporcionada no está en el mapa `units`.
- En caso contrario, añadir el artículo a la `bill` del cliente, indexado por el nombre del artículo, y después devolver `true`.
- Si el artículo ya está presente en la factura, aumentar su cantidad en la cantidad que corresponde a la `unit` proporcionada.

```rust
let bill = new_bill();
let units = units();
let ok = add_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: true (since dozen is a valid unit)
```

> Ten en cuenta que el valor devuelto es de tipo `bool`.

## 4. Elimina un artículo de la factura del cliente

Para implementar esto, tendrás que:

- Devolver `false` si el artículo proporcionado **no** está en la factura.
Se considera que un artículo no está en la factura si su cantidad es 0.
- Devolver `false` si la `unit` proporcionada no está en el mapa `units`.
- Devolver `false` si la nueva cantidad fuera menor que 0.
- Si la nueva cantidad es 0, el artículo se considera eliminado de la `bill`, por lo que puedes devolver `true`.
- En caso contrario, reducir la cantidad del artículo y devolver `true`.

```rust
let bill = new_bill();
let units = units();
let ok = remove_item(bill, units, 'carrot', 'dozen');
println!(ok);
// Output: false (because there are no carrots in the bill)
```

> Ten en cuenta que el valor devuelto es de tipo `bool`.

## 5. Devuelve la cantidad de un artículo concreto que está en la factura del cliente

```rust
let mut bill: Felt252Dict<u32> = Default::default();
bill.insert('carrot', 12);
bill.insert('grapes', 3);
let qty = get_item(bill, 'carrot');
println!(qty);
// Output: 12
```

> Ten en cuenta que el valor devuelto es de tipo `u32`.

[gross-unit]: https://en.wikipedia.org/wiki/Gross_(unit)
