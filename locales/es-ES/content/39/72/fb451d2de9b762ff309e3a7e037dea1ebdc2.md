# Introducción

`Enum` es un módulo muy útil que proporciona un conjunto de algoritmos para trabajar con enumerables. Ofrece ordenar, filtrar, agrupar, contar, buscar, encontrar los valores mínimos y máximos y mucho más.

En general, un _enumerable_ es cualquier dato sobre el que se pueda iterar, una colección. En Elixir, un enumerable es cualquier tipo de datos que implemente el [protocolo][exercism-protocols] `Enumerable`. Los más comunes de ellos son las [listas][exercism-lists] y los [mapas][exercism-maps].

Muchas funciones de `Enum` aceptan una función como argumento.

```elixir
Enum.all?([1, 2, 3, 4, 5], fn x -> x > 3 end)
# => false
```

Las funciones de `Enum` más comunes son `map` y `reduce`.

## `map/2`

`Enum.map/2` te permite reemplazar cada elemento de un enumerable por otro elemento. El segundo argumento de `Enum.map/2` es una función que acepta el elemento original y devuelve su reemplazo.

## `reduce/3`

`Enum.reduce/3` te permite _reducir_ todo el enumerable a un único valor. Para lograrlo, se usa una variable especial llamada el _acumulador_. El acumulador lleva el estado intermedio de la reducción entre iteraciones.

El segundo argumento de `Enum.reduce/3` es el valor inicial del acumulador. El tercer argumento es una función que acepta un elemento y un acumulador, y devuelve el nuevo valor del acumulador.

## Trabajar con mapas

Cuando usas mapas con funciones de `Enum`, el mapa se convierte automáticamente en una lista de tuplas de 2 elementos con la forma `{key, value}`.

Para volver a transformarla en un mapa, usa `Enum.into/2`. `Enum.into/2` es una función que transforma un enumerable en un coleccionable, cualquier estructura de datos que implemente el protocolo `Collectable`. Se puede pensar en ella como lo contrario de `Enum.reduce/3`.

`Enum` también tiene `Enum.into/3`. `Enum.into/3` es una variación de `Enum.into/2` que acepta una función de transformación que se aplica mientras se transforma el enumerable en un coleccionable.

### Transformar mapas

En lugar de usar `Enum.into/3` o `Enum.map/2` junto con `Enum.into/2` para aplicar una transformación (mapeo) a un mapa, también podemos usar una función dedicada, `Map.new/2`. Funciona exactamente igual que `Enum.into/3` en el sentido de que acepta un enumerable y una función de transformación, pero siempre devuelve un mapa nuevo en lugar de dejarnos elegir un coleccionable.
