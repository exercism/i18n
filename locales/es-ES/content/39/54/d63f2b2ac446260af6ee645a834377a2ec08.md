# Acerca de

PHP tiene varias estructuras de control de bucles integradas, como `while`. La forma básica de una instrucción `while` es:

```php
while (expr) {
  // statements
}
```

Mientras la expresión (_expr_) se evalúe como un valor _verdadero_, iterará sobre las instrucciones dentro del bucle. Si la expresión (_expr_) se evalúa como falsa antes de la primera iteración, las instrucciones nunca se ejecutan.

Como alternativa, puedes usar un bucle `do-while`, que ejecuta las instrucciones del bucle una vez antes de evaluar la expresión (_expr_).

```php
do {
  // statements
} while (expr);
```
