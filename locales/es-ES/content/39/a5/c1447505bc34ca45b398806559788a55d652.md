# Introducción

En R, `list` es una colección ordenada de elementos, que se diferencia de `vectors` en algunos aspectos:

- Los elementos pueden ser de tipos diferentes (por ejemplo, mezclar `numeric` con `character`).
- Los elementos pueden ser estructuras complejas (por ejemplo, vectores, otras listas, etc.).
- Hay una sintaxis diferente para acceder a los elementos.

Las analogías con otros lenguajes son imprecisas.
En R, `list` es bastante similar a un diccionario de Python, pero está ordenado y se puede acceder a él mediante un índice numérico.
Es bastante similar a un `struct` de C, salvo que el `list` se puede extender fácilmente en tiempo de ejecución.

## Creación de listas

Dar nombres (a menudo llamados «etiquetas») a los elementos es más común en las listas que en los vectores:

```R
list(x = 5.3, y = 4.2, color = "blue")
$x
#> [1] 5.3

$y
#> [1] 4.2

$color
#> [1] "blue"
```

Sin embargo, las etiquetas son opcionales y R usará simplemente números de índice:

```R
list(5.3, 4.2, "blue")
#> [[1]]
#> [1] 5.3

#> [[2]]
#> [1] 4.2

#> [[3]]
#> [1] "blue"
```

## Acceso a los elementos de una lista

Hay tres formas de hacerlo, cada una útil en contextos diferentes.

### 1. Con la notación `$tag`

Muy común si los nombres de las etiquetas se conocen de antemano.

```R
point <- list(x = 5.3, y = 4.2, color = "blue")
point$x
#> [1] 5.3
point$color
#> [1] "blue"
```

### 2. Con la notación `[[tag]]`

Esto tiene la ventaja de que el nombre de la etiqueta se puede elegir en tiempo de ejecución.
Fíjate en los corchetes dobles.

```R
want <- "y"
point[[want]] # same as point$y
#> [1] 4.2
```

### 3. Con índice de posición

Esto funciona tanto si la lista tiene etiquetas como si no.
De nuevo, los corchetes son dobles.

```R
point[[3]] # same as point$color
#> [1] "blue"
```

## Añadir y eliminar elementos

Sencillo: asignar a un elemento lo modificará si existe o lo insertará si es nuevo.

```R
point$color <- "red"
point[[trust]] <- TRUE
str(point)
#> List of 4
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
#>  $ trust: logi TRUE
```

Para eliminar, asigna `NULL` al elemento que no quieras.

```R
point$trust <- NULL
str(point)
#> List of 3
#>  $ x    : num 5.3
#>  $ y    : num 4.2
#>  $ color: chr "red"
```
