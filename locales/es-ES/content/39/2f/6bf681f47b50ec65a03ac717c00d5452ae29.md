# Introducción

## Alias

Para compartir código entre distintos módulos de Elixir dentro del mismo proyecto, necesitas hacer referencia al módulo externo por su nombre completo. Pero ¿y si ese nombre es demasiado largo o confuso?

La forma especial `alias` te permite acortar o cambiar el nombre con el que haces referencia a un módulo externo. Cuando se usa sin argumentos, reduce el nombre del módulo a su último segmento, por ejemplo, `MyApp.Logger.Settings` se convierte en `Settings`. Se puede especificar un nombre personalizado con la opción `:as`.

Normalmente, los alias se añaden al principio de la definición del módulo.

```elixir
defmodule Square do
  alias Integer, as: I

  def area(a), do: I.pow(a, 2)
end
```

## Import

La forma especial `import` te permite usar funciones de un módulo externo sin usar el nombre del módulo.

Importar un módulo externo completo podría crear conflictos con las funciones locales existentes. Para evitar esto, hay dos opciones disponibles: `:except` y `:only`. Ambas esperan una lista de palabras clave, donde la clave es el nombre de la función y el valor es la aridad de la función.

Normalmente, los import se añaden al principio de la definición del módulo.

```elixir
defmodule Square do
  import Integer, only: [pow: 2]

  def area(a), do: pow(a, 2)
end
```
