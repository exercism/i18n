# Tuplas

Las tuplas en Elm pueden contener dos o tres valores, y cada valor puede ser de cualquier tipo.
En Elm, las tuplas se usan sobre todo para tipos transitorios simples.
Por este motivo, las tuplas tienen un máximo de 3 valores y, como aliciente adicional, solo se proporcionan funciones de conveniencia para 2 valores.
Para datos más complejos, lo mejor es pasar a los registros.
Un uso habitual es cuando necesitas devolver más de un valor desde una función.
Los campos de una tupla no tienen nombre; se accede a ellos mediante desestructuración o por posición.

Puedes leer una [introducción concisa a las tuplas][tuples-concise].
También hay una [introducción más detallada][tuples-in-depth], y la [documentación de la API del módulo Tuple][tuple-core] contiene ejemplos de código y documentación detallada.

## Declaración

Los tipos de las tuplas se crean con paréntesis y sus tipos de elemento se separan con comas.

```elm
type alias IntStringTuple = (Int, String)
```

### Creación

Las tuplas se crean con paréntesis y sus elementos se separan con comas.

```elm
aTuple : IntStringTuple
aTuple = (123, "elements can be of differing types")
```

También puedes usar `Tuple.pair` para crear una tupla con dos valores.

```elm
anotherTuple : (String, String)
anotherTuple = Tuple.pair "this time it's" "two strings"
    --> ("this time it's", "two strings")
```

### Acceso

También hay funciones para acceder a los valores de una tupla por posición: `Tuple.first` y `Tuple.second`.

```elm
Tuple.first aTuple
    --> 123

Tuple.second aTuple
    --> "elements can be of differing types"
```

Las tuplas se pueden _desestructurar_ en las asignaciones mediante la coincidencia de patrones de tupla.
La desestructuración se puede hacer en expresiones let, declaraciones de función y expresiones case.

```elm
repeatString : (Int, String) -> Bool
repeatString aTuple =
let
    (aNumber, aString) = aTuple
in
    String.repeat aNumber aString

repeatStringAgain : (Int, String) -> Bool
repeatStringAgain (aNumber, aString) = String.repeat aNumber aString
```

La coincidencia de patrones en una expresión case también te permite hacer coincidir el contenido de los valores:

```elm
has123 : (Int, String, Bool) -> Bool
has123 aTuple =
    case aTuple of
        (123, _, _) ->
            True
        (_, "123", _) ->
            True
        (_, _, True) ->
            True
        _ ->
            False
```
