# Pruebas

## Ejecutar las pruebas

Para ejecutar las pruebas, lanza el siguiente comando:

```bash
make
```

## Resolver el ejercicio

Resolver un ejercicio significa conseguir que todas sus pruebas pasen.
Por defecto, cuando ejecutas las pruebas solo se ejecuta una (la primera).
Esto es intencionado, ya que te permite centrarte en hacer que esa única prueba pase.
Cuando lo consigas, puedes habilitar la siguiente prueba eliminando la línea `TEST_IGNORE()`.
Cuando hayas habilitado todas las pruebas y tu implementación las haga pasar todas, ¡habrás resuelto el ejercicio!
