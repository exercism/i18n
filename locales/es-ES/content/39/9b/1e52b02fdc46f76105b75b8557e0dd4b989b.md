# Luhn: uso del trait From

Antes de hacer este ejercicio, probablemente deberías hacer el ejercicio original de Luhn. Si no has completado Luhn, puedes obtenerlo ejecutando el comando:

```shell
exercism download --exercise=luhn --track=rust
```

En el ejercicio original de Luhn solo validabas strings, pero el algoritmo de Luhn también se puede aplicar a números enteros.

En este ejercicio implementarás el [trait From](https://doc.rust-lang.org/std/convert/trait.From.html) para convertir strings, strs y números enteros sin signo en una Struct que realiza la validación.
