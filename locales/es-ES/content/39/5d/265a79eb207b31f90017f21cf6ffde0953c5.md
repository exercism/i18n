# Introducción

Un array en Gleam es una colección inmutable de cero o más valores. Los valores de un array deben tener todos el mismo tipo. Como los arrays son inmutables, una vez que se ha construido un array, su valor nunca puede cambiar. Cualquier función u operador que parezca modificar un array (como añadir un elemento) en realidad devolverá un nuevo array.

Los arrays se pueden definir de la siguiente manera:

```gleam
let empty = []
let singleValue = [5]
let threeValues = ["a", "b", "c"]
```

La forma más común de añadir un elemento a un array es mediante la sintaxis de propagación:

```gleam
let two_to_four = [2, 3, 4]
let one_to_four = [1, ..two_to_four]
// -> [1, 2, 3, 4]
```

El módulo [`gleam/list`](https://hexdocs.pm/gleam_stdlib/gleam/list.html) de la biblioteca estándar de Gleam contiene muchas funciones útiles para trabajar con arrays. Este módulo se usa muy comúnmente en el código de Gleam, por lo que es bueno familiarizarse con él.

Los patrones de arrays se pueden usar en expresiones case para hacer coincidir con arrays y asignar los valores contenidos a variables:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [] -> "Empty list"
    [x] -> "List with one item: " <> x
    [x, y] -> "List with two items: " <> x <> " and " <> y
    _ -> "List with three or more items"
  }
}
```

Además de hacer coincidir con arrays de longitud exacta, la sintaxis de propagación se puede usar para hacer coincidir con arrays de al menos cierta longitud:

```gleam
pub fn describe(list: List(String)) -> String {
  case list {
    [_, _, ..] -> "List with at least two items"
    [_] -> "List with one item"
    [] -> "Empty list"
  }
}
```

La sintaxis de propagación también se puede usar para asignar el resto del array a una variable:

```gleam
pub fn remove_first_item(list: List(String)) -> List(String) {
  case list {
    // Return the list without the first item
    [_, ..rest] -> rest

    // There's no first item to remove, return an empty list
    _ -> []
  }
}
```

Las expresiones case deben tener un patrón para cada valor posible del tipo con el que se hace coincidir, por lo que a menudo se usa un patrón de descarte final (`_`) para manejar los valores restantes.
