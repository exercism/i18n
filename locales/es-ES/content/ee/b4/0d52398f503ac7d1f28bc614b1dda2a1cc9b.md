# Pistas

## 1. Añadir un lenguaje al array `@Languages`

- Quieres modificar el array `@Languages` para añadir un nuevo lenguaje al final.

## 2. Eliminar un lenguaje del array `@Languages`

- Quieres modificar el array `@Languages` para eliminar el último lenguaje.

## 3. Obtener el primer lenguaje del array `@Languages`

- Quieres devolver el primer elemento del array `@Languages` usando `return`.

## 4. Obtener el último lenguaje del array `@Languages`

- Quieres devolver el último elemento del array `@Languages` usando `return`.

## 5. Obtener una porción de lenguajes del array `@Languages`

- Quieres una porción del array `@Languages`.
- Recuerda que los índices empiezan en 0. El elemento `1` es el índice `0`.

## 6. Comprobar si un lenguaje existe en el array `@Languages`

- Quieres devolver un valor verdadero, por ejemplo `1`, o falso, por ejemplo `0`, si el lenguaje indicado se encuentra en el array `@Languages`.
