# Introducción

En el concepto [`Vectors`][vectors], decíamos que «los arrays son el corazón del lenguaje Julia» y que un vector es un array unidimensional.

Teniendo esto en cuenta, es razonable esperar que el lenguaje ofrezca muchas formas versátiles y potentes de _hacer cosas_ con vectores, sea lo que sea que eso signifique.

## Funciones que esperan un vector como entrada

Algunas funciones muy sencillas reciben como entrada un vector y devuelven como salida un valor escalar.

```julia
v = [2, 3, 4]
length(v)  # => 3
sum(v)  # => 9
```

## Aritmética

Supongamos que tienes un vector numérico y quieres restar 0,5 a cada valor.

```julia-repl
julia> v = [1.2, 1.5, 1.7]
3-element Vector{Float64}:
 1.2
 1.5
 1.7

julia> v - 0.5
ERROR: MethodError: no method matching -(::Vector{Float64}, ::Float64)
```

Eso falla, así que ¿qué pasa si restamos otro vector?

```julia-repl
julia> v - [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

Funciona, pero resulta bastante tedioso y consume mucha memoria a medida que los vectores se alargan.

Afortunadamente, Julia tiene un punto «mágico» que resuelve este problema de forma muy sencilla: `v .- 0.5` es todo lo que necesitas.

La siguiente sección explica por qué.

## Broadcasting

Así que `v - 0.5` falla, pero `v .- 0.5` funciona, y tenemos que entender qué hace el punto.

Dos cosas, que se combinan para dar el resultado deseado.

### 1. Aplicación elemento a elemento

En primer lugar, añadir un punto _antes_ de cualquier operador infijo significa «aplica esta operación a cada elemento por separado».

De forma similar, añadir un punto _después_ del nombre de una función la «vectoriza», incluso si la función se escribió para entradas escalares.

```julia-repl
julia> sqrt.([1, 4, 9])
3-element Vector{Float64}:
 1.0
 2.0
 3.0
```

### 2. Expansión de singletons

Vimos en un ejemplo anterior que podemos restar vectores de la misma longitud, aunque conviene entender que `.-` es un operador _más seguro_ que `-`, porque deja clara la intención de operar elemento a elemento.

```julia-repl
julia> v .- [0.5, 0.5, 0.5]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

¿Y los vectores de distinta longitud?

```julia-repl
julia> v .- [0.5, 0.5]
ERROR: DimensionMismatch: arrays could not be broadcast to a common size

julia> v .- [0.5,]
3-element Vector{Float64}:
 0.7
 1.0
 1.2
```

En general, las longitudes distintas son un error, _excepto_ cuando una tiene longitud 1 (técnicamente, una dimensión «singleton»).

Los singletons como `[0.5,]` o simplemente `0.5` se expanden automáticamente a la longitud necesaria mediante repetición.
Esta es la clave del `broadcasting`.

### Broadcasting in-place

Si te preocupa el uso de memoria, las operaciones in-place son una forma habitual de intentar reducir las asignaciones de memoria.

Sin embargo, las operaciones de broadcasting de los ejemplos anteriores crean un nuevo `Vector` en lugar de modificar el original.

Para modificar in-place el `Vector` original, la modificación debe hacerse con broadcasting.

```julia-repl
julia> v .= v .+ 1
3-element Vector{Int64}:
 2
 3
 4

julia> v .+= 1  # equivalent operation to above
3-element Vector{Int64}:
 3
 4
 5

julia> v
3-element Vector{Int64}:
 3
 4
 5
```

## Indexación

La selección de elementos de un vector por su número de índice ya se ha tratado en conceptos anteriores.

```julia
a = collect('A':'Z')  # => 26-element Vector{Char}

# index with an integer
a[2]  # => 'B'

# index with a range
 a[12:2:18]  # => ['L', 'N', 'P, 'R']
 
 # index with another vector
 a[ [1, 3, 5] ]  # => ['A', 'C', 'E']
```

### Indexación lógica

También es posible seleccionar los elementos que satisfacen cierta expresión lógica (técnicamente, un «predicado»).
Esto normalmente requiere broadcasting.

```julia-repl
julia> a[a .< 'D']
3-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
```

En expresiones más complejas, los puntos tienden a multiplicarse (pero son pequeños y fáciles de escribir).

```julia-repl
julia> a[a .< 'D' .|| a .> 'W']
6-element Vector{Char}:
 'A': ASCII/Unicode U+0041 (category Lu: Letter, uppercase)
 'B': ASCII/Unicode U+0042 (category Lu: Letter, uppercase)
 'C': ASCII/Unicode U+0043 (category Lu: Letter, uppercase)
 'X': ASCII/Unicode U+0058 (category Lu: Letter, uppercase)
 'Y': ASCII/Unicode U+0059 (category Lu: Letter, uppercase)
 'Z': ASCII/Unicode U+005A (category Lu: Letter, uppercase)
```

Recuerda que el «vector» puede ser en realidad cualquier iterable ordenado adecuado, como un rango:

```julia-repl
julia> n = 3:10
3:10

julia> n[isodd.(n)]
4-element Vector{Int64}:
 3
 5
 7
 9
```
