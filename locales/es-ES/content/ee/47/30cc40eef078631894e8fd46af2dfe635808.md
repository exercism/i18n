# Pistas

## 1. Genera un número aleatorio de registro de nave estelar

- Para generar un número aleatorio en el rango de _min_ (incluido) a _max_ (excluido), puedes usar el fragmento `min + Math.random()*(max - min)`.
- Hay una [función incorporada][floor] para convertir un número decimal en un número entero.

## 2.Genera una fecha estelar aleatoria

- Para generar un número aleatorio en el rango de _min_ (incluido) a _max_ (excluido), puedes usar el fragmento `min + Math.random()*(max - min)`.

- Puedes usar un número entero generado aleatoriamente como índice de un array.
