# Aprendizaje

Si eres nuevo en SQLite y quieres aprender lo básico de la sintaxis de SQL y de la gestión de bases de datos, aquí tienes algunos recursos excelentes pensados para principiantes:

- **Introducción a SQL en YouTube**: echa un vistazo a [What is SQL?][sql-youtube], un vídeo de 4 minutos para principiantes de Danielle Thé.

- **SQLite Tutorials**: los [SQLite Tutorials][sqlite-tutorial] ofrecen una introducción a SQLite apta para principiantes, que abarca conceptos fundamentales como la creación de bases de datos, las consultas y la manipulación de datos.

- **SQLZoo**: practica tus conocimientos de SQL con ejercicios y tutoriales interactivos en [SQLZoo][sqlzoo], incluido contenido específico de SQLite adecuado para principiantes.

Estos recursos te proporcionan una base para aprender SQLite y la sintaxis de SQL, y ayudan a quienes empiezan a entender los conceptos de las bases de datos y a adquirir experiencia práctica con bases de datos SQLite.

[sqlite-tutorial]: https://www.sqlitetutorial.net/
[sql-youtube]: https://www.youtube.com/watch?v=27axs9dO7AE
[sqlzoo]: https://sqlzoo.net/
