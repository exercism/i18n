# Introducción

C es un lenguaje de tipado estático, lo que significa que todo tiene un tipo en tiempo de compilación.
Elegir un nombre para una variable e indicar su tipo se conoce como declarar una variable.

Una variable se declara especificando explícitamente su tipo.
El nombre de una variable debe empezar por una letra o un guion bajo.
Algunos nombres no se pueden usar, porque están reservados [para palabras clave][reserved-keywords] u [otros identificadores][reserved-identifiers].

Establecer o actualizar la variable se hace mediante la asignación a variables.
Establecer el valor define esa variable.
Definir la variable también se conoce como inicialización.

```c
int foo;      // Declare an integer named var
foo = 10;     // Define the variable

int bar = 15; // Both can also be done in a single statement
```

El valor de una variable se puede asignar y actualizar con el operador de asignación simple `=`.
Una vez definida, el tipo de una variable nunca puede cambiar.

```c
int foo = 10; // Assign initial value
foo = 25;     // Update to new value

foo = false;  // Compiler error when assigning value of a different type
```

C es un lenguaje imperativo y procedimental.
Toda la computación se lleva a cabo como parte de una serie de instrucciones que forman parte de una función o de varias funciones.

Cada función puede tener cero o más parámetros.
Al definir una función hay que indicar explícitamente el tipo de todos los parámetros y del valor devuelto.
Los valores se devuelven desde las funciones con la palabra clave `return`.
Por defecto, las funciones tienen clase de almacenamiento externa, lo que significa que existen durante toda la vida del programa y pueden ser visibles desde fuera del fichero.
Para evitarlo, se puede añadir la palabra clave `static`, que especifica visibilidad interna.

```c
static int add(int x, int y) {
  return x + y;
}
```

En el ejemplo anterior, las variables `x` y `y` solo se pueden usar dentro de la función; es decir, tienen scope de función.
El scope es la idea de que el valor asociado a un nombre (de un elemento del programa) solo es accesible dentro de la «zona» de código donde se define.
Las principales zonas de código en C son:

- fichero
- función
- bloque (como dentro de bucles y otras construcciones)

Se llama a una función indicando su nombre y pasando un argumento por cada uno de sus parámetros.

```c
int sum = add(1, 2);
```

C admite dos tipos de comentarios.
Los comentarios de una sola línea van precedidos de `//` (desde C99) y los comentarios multilínea se insertan entre `/*` y `*/`.
