# Pistas

## General

- Lee sobre el comportamiento [`Access`][access-behaviour] en la documentación.

## 1. Extrae datos de una estructura de mapas anidados

- Primero tokeniza la ruta del string hasta un estado utilizable. Puedes hacer uso de las [funciones del módulo `String`][string-module].
- Escribe una función recursiva que recorra la estructura de mapas anidados para recuperar el valor o devolver `nil`.

## 2. Refactoriza usando las funciones incluidas

- Revisa las distintas [funciones del módulo `Kernel`][kernel-module] para encontrar alguna que pueda acortar o simplificar tu enfoque.
