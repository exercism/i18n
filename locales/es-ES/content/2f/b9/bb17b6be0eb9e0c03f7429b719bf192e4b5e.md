# Test Runners

Un Test Runner es un programa que ejecuta los tests de un ejercicio contra el código de un estudiante.

Los Test Runners nos aportan dos ventajas:

1. Permiten programar en el navegador, donde el estudiante puede iterar sobre una solución viendo si los tests pasan o fallan.
2. Nos permiten proporcionar información a los mentores sobre si el código de un estudiante «funciona» o no.

## Contribuir a los Test Runners

Cada lenguaje tiene su propio Test Runner, escrito en ese lenguaje.
La web actúa como orquestador entre los Test Runners y las entregas de los estudiantes.

Cada Test Runner vive en la organización de Exercism en GitHub, en un repositorio llamado `<track_slug>-test-runner` (por ejemplo, [`exercism/ruby-test-runner`](https://github.com/exercism/ruby-test-runner)).
Puedes consultar los Test Runners existentes [aquí](https://github.com/search?q=topic%3Aexercism-test-runner&type=repositories).

Si quieres participar y ayudar con un Test Runner que ya existe, abre un issue en su repositorio preguntando si hay algún sitio donde puedas ayudar.
Si quieres crear un Test Runner para un lenguaje que todavía no tiene uno, sigue las instrucciones para [crear un Test Runner desde cero](/docs/building/tooling/test-runners/creating-from-scratch).
