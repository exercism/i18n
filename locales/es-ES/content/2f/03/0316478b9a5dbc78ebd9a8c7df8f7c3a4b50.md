# Acerca de

- Pony tiene tipado estático. Esto significa que *debes* definir de antemano los
  tipos de datos de tus programas. Si le dices a Pony que la variable `x` es un
  número entero, no puedes asignarle un string.
- El sistema de tipos de Pony es lo que hace posibles las garantías de Pony.
  - Si tu programa compila, no fallará.
  - Nunca habrá una excepción no controlada.
  - No existe nada como `null`, así que tu programa nunca intentará
    desreferenciar `null`.
  - Nunca habrá una condición de carrera.
  - Nunca habrá un interbloqueo.
  - Tu código siempre será seguro en cuanto a capacidades (protección frente a
    ataques de cadena de suministro).
- Pony no te permite convertir tipos. Todos los cambios de tipo deben ocurrir a
  través de una función que cree una nueva instancia del nuevo tipo.
- El sistema de tipos de Pony es distinto al de casi cualquier otro lenguaje,
  así que lo vamos a ver por partes, en pequeñas dosis.

## Primitivas

- Las primitivas son la forma más simple de organizar código en Pony.
  - Puedes pensar en ellas como un contenedor o un espacio de nombres para
    funciones.
  - No tiene campos (para eso tenemos las clases).
  - Se define con la palabra clave `primitive`.

## Funciones

- Las funciones se definen con la palabra clave `fun`.
  - Las funciones deben vivir dentro de un `primitive` (o de una `class` o un
    `actor`, pero eso lo veremos más adelante).
  - Las funciones pueden tener argumentos de entrada y un valor devuelto. Deben
    estar tipadas.
  - Si defines un tipo de retorno, tu función *debe* devolver un valor de ese
    tipo. Pony no tiene el concepto de Null.

```pony
primitive Greeter
  // A Function that takes a String, and returns a different String
  fun hello(name: String): String =>
    "Hello " + name + "!"
```

## Comentarios

Los comentarios sirven para dejar notas, recordatorios o simplemente para quitar
código temporalmente del código fuente. Como ya has visto arriba, los comentarios
de una sola línea usan `//`. Los comentarios de varias líneas usan el estilo de C,
`/*` y `*/`.

## Variables

- Las variables siempre empiezan con una letra minúscula
  - Las declararemos con `var`. (`let` y `embed` vienen más adelante).
  - Si Pony puede determinar el tipo de la variable, lo hará por ti.
  - El tipo de la variable se comprueba en tiempo de compilación y nunca puede
    cambiar.
  - Cuando empiezas con Pony, te recomendamos ser explícito con el tipo.

```pony
var name: "Bob"
var bettername: String = "Bobby"
```
