# Anexo a las instrucciones

## Registros

| Registro | Uso       | Tipo    | Descripción                                            |
| -------- | --------- | ------- | ------------------------------------------------------ |
| `$a0`    | entrada   | dirección | string de entrada terminado en nulo                   |
| `$v0`    | salida    | boolean | validez del string de entrada (`0` = `false`, `1` = `true`) |
| `$t0-9`  | temporal  | cualquiera | se usa para almacenamiento temporal                 |
