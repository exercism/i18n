# Introducción

Las listas de palabras clave son una estructura de datos de clave-valor.

```elixir
[month: "April", year: 2018]
```

Las listas de palabras clave son listas de [tuplas][exercism-tuples] `{key, value}` y también se pueden escribir de esa forma, pero la sintaxis corta se usa más.

```elixir
[month: "April"] == [{:month, "April"}]
# => true
```

Las claves de una lista de palabras clave deben ser [átomos][exercism-atoms], pero los valores pueden ser cualquier cosa. Cada clave puede usarse más de una vez. Los pares clave-valor de una lista de palabras clave están ordenados.

Puedes trabajar con las listas de palabras clave usando los mismos enfoques que con las listas, o puedes usar el módulo `Keyword`.

[exercism-tuples]: https://exercism.org/tracks/elixir/concepts/tuples
[exercism-atoms]: https://exercism.org/tracks/elixir/concepts/atoms
