# Introducción

Clojure usa el tipo subyacente `java.lang.Character`, que es una cantidad de 16 bits con la que representar los componentes direccionables más pequeños de un texto.
Varios `char` pueden componer un string como `"word"`, o los `char` pueden
procesarse de forma independiente. Sus literales se escriben así: `\a \b \c`.

Los `char` de Clojure admiten la codificación Unicode UTF-16, por lo que, además del conjunto de caracteres latino, se puede representar prácticamente cualquier sistema de escritura que se use en el mundo,
por ejemplo, la letra griega `'β'`.

Hay muchos métodos de biblioteca para inspeccionar y manipular `char`. Se puede acceder a ellos, mediante interoperabilidad, como métodos de la clase `Character`. Clojure también incluye una biblioteca de utilidades para strings integrada, `clojure.string`, que ofrece muchas funciones potentes para operar con caracteres.
