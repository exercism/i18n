# Introducción

## Cadenas de caracteres

Una cadena de caracteres en C# es un objeto que representa texto inmutable como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Las comillas dobles se usan para definir una instancia de `string`:

```csharp
string fruit = "Apple";
```

### Métodos

Los strings se manipulan llamando a sus [métodos integrados][docs-string-methods].
Por ejemplo, para eliminar los espacios en blanco de un string, puedes usar el [método Trim][tutorial-docs.microsoft.com-trim-white-space] así:

```csharp
string name = " Jane "
name.Trim()
// => "Jane"
```

Una vez que se ha construido un string, su valor nunca puede cambiar.
Cualquier método que parezca modificar un string en realidad devolverá un string nuevo.

### Concatenación

Varios strings se pueden concatenar (añadir) entre sí. La forma más sencilla de lograrlo es usar el operador `+`.

```csharp
string name = "Jane";
"Hello " + name + "!";
// => "Hello Jane!"
```

### Formato

Para cualquier formato de string más complejo que una simple concatenación, se prefiere la interpolación de strings. Para usar la interpolación en un string, antepón el símbolo del dólar (`$`). Después puedes usar llaves (`{}`) para acceder a cualquier variable dentro de tu string.

```csharp
string name = "Jane";
$"Hello {name}!";
// => "Hello Jane!"
```
