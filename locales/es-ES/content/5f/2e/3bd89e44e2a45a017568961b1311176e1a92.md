# Instalación

## Linux

Bash, como shell de GNU, se encuentra en cualquier sistema GNU/Linux.
Es probable que en BSD y otros derivados de UNIX tengas que instalarlo tú.
Si usas BSD, AIX o una distribución de Linux que no venga con bash, consulta los recursos de tu sistema operativo sobre cómo instalar paquetes que no forman parte del sistema base.

En el entorno gráfico que prefieras, busca una aplicación llamada «Terminal»: puede que esté en una sección de «Administrative/System Tools».

Para comprobar la versión de Bash disponible, desde la línea de comandos o el terminal, ejecuta:

    echo $BASH_VERSION

Si tu shell es `bash`, debería mostrar algo como:

    4.4.19(1)-release

No deberías tener que hacer nada más: a estas alturas bash ya está instalado y en tu PATH, porque es tu shell actual.

Si tu shell no es bash, no hay motivo para cambiarlo.
Puedes escribir y ejecutar scripts de bash sin estar en un shell de bash.

Para comprobar la versión de bash instalada, ejecuta:

```plain
bash --version
```

Mostrará algo como esto:

```
GNU bash, version 4.4.19(1)-release (x86_64-pc-linux-gnu)
Copyright (C) 2016 Free Software Foundation, Inc.
License GPLv3+: GNU GPL version 3 or later <http://gnu.org/licenses/gpl.html>

This is free software; you are free to change and redistribute it.
There is NO WARRANTY, to the extent permitted by law.
```

Si no es así, puede que no tengas bash instalado.
Deberías instalarlo con el gestor de paquetes de tu distribución.

## Windows

En Windows 10 puedes instalar [WSL](https://docs.microsoft.com/en-us/windows/wsl/about).
Esto instala una distribución de Linux completa (bueno, sus componentes sin interfaz gráfica) que se ejecuta de forma nativa en Windows.

Como alternativa, puedes instalar:

* [Cygwin](https://cygwin.com/)
* [git for windows](https://gitforwindows.org/)
* [MinGW](http://mingw.org/)
* una distribución de Linux completa en [una máquina virtual](https://docs.microsoft.com/en-us/virtualization/hyper-v-on-windows/about/)

## MacOS

Para Apple OSX:

* abre el Finder,
* abre la carpeta Applications,
* abre la carpeta Utilities,
* por último, abre la aplicación `Terminal`.

Ten en cuenta que la versión de bash instalada en MacOS es muy antigua, la 3.2.
Esto se debe a que (i) las versiones más recientes de bash tienen licencia GPLv3 y (ii) Apple no quiere verse obligada a cumplir los términos de esa licencia.
Además, Apple ha indicado que bash desaparecerá de MacOS: hace poco, el shell de inicio de sesión predeterminado [cambió de bash a zsh](https://support.apple.com/en-us/HT208050).

Para conseguir un bash actualizado en tu Mac:

1. instala [Homebrew](https://brew.sh)
1. en un Terminal, introduce: `brew install bash`

Esto instala un bash actualizado en (creo) `/usr/local/bin/bash` (para no sobrescribir el bash predeterminado del sistema: otras herramientas podrían depender de /bin/bash).

Si quieres que se lance el bash de Homebrew cuando escribas `bash`, edita tu archivo ~/.bash_profile (o ~/.profile) para colocar /usr/local/bin *antes* que /bin en el PATH:

    PATH=/usr/local/bin:$PATH
