# Pruebas

## Escribir el código

Escribe tu código en `src/lib.cairo`.
Los ejercicios incluyen un archivo stub en `src/lib.cairo` que te mostrará las firmas del código que tendrás que escribir.

En la mayoría de los ejercicios, lo mejor es escribir todo tu código en el archivo `src/lib.cairo`.
Si quieres dividir tu solución en varios archivos, consulta el [capítulo sobre módulos][chapter-modules] de The Cairo Book.

[chapter-modules]: https://book.cairo-lang.org/ch07-02-defining-modules-to-control-scope.html

## Ejecutar las pruebas

Para ejecutar las pruebas, primero tienes que cambiar tu directorio de trabajo al directorio del ejercicio que quieres probar:

```bash
cd path/to/exercise
```

Y después ejecuta el siguiente comando:

```bash
scarb cairo-test
```

De forma predeterminada, solo la primera prueba está habilitada.
Cuando estés listo para pasar la siguiente prueba, quita la marca `ignore` de la siguiente prueba (`#[ignore]`).

Para ejecutar todas las pruebas, incluso las marcadas con `ignore`, puedes quitar la marca `ignore` de todas ellas o simplemente ejecutar:

```bash
scarb cairo-test --include-ignored
```

No dudes en escribir el mínimo código posible para que las pruebas pasen.
Los fallos de las pruebas te guiarán sobre qué escribir a continuación.

Como Cairo comprueba todo el código en tiempo de compilación, puede que tus pruebas no compilen hasta que escribas el código necesario.
Incluso las pruebas marcadas con `ignore` se comprueban en tiempo de compilación.
Puedes [comentar][comments] las pruebas que no compilen empezando cada línea con `//`.
Después, cuando estés listo para trabajar en esa prueba, puedes descomentarla.
Cairo también tiene una macro especial llamada `panic!()`, que puedes usar en partes del código sin terminar para que tu programa compile.

[comments]: https://book.cairo-lang.org/ch02-04-comments.html
