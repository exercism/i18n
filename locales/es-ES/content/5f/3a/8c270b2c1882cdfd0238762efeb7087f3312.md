# Acerca de

C# tiene varios operadores para hacer manipulación a nivel de bits:

- [`&`][and-operator]: AND a nivel de bits
- [`|`][or-operator]: OR a nivel de bits
- [`~`][complement-operator]: complemento a nivel de bits
- [`<<`][left-shift-operator]: desplazamiento a nivel de bits a la izquierda
- [`>>`][right-shift-operator]: desplazamiento a nivel de bits a la derecha
