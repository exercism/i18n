# Pistas

## 1. Comprobar si la acción «ataque rápido» es posible

- El operador lógico de negación (`!`) se puede colocar delante de una expresión para negar su valor.
- Echa un vistazo a [este documento][logical-operators] sobre los operadores lógicos

## 2. Comprobar si la acción «espía» es posible

- Las expresiones lógicas se evalúan de izquierda a derecha y se comprueban los posibles «cortocircuitos».
- Para entender a fondo el mecanismo de izquierda a derecha, echa un vistazo a [este artículo][operator-precedence].

## 3. Comprobar si la acción «hacer señales al prisionero» es posible

- Los operadores lógicos ordenados por precedencia (de mayor a menor): `!`, `&&`, `||`.
- Echa un vistazo a [este artículo][operator-precedence] sobre la precedencia de operadores

## 4. Comprobar si la acción «liberar al prisionero» es posible

- `()` es el operador con mayor precedencia. Úsalo para agrupar expresiones lógicas.
