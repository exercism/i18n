# Clases genéricas

Llevas usando `ARRAY{STR}`, `FMAP{STR,INT}` y `FSET{STR}` desde el principio.
Las llaves siempre han contenido un tipo. Ahora vas a escribir una clase con
llaves propias.

## El problema

La oficina de objetos perdidos necesita una caja que guarde una sola cosa y
recuerde quién la entregó. Una caja para un jersey:

```sather
class JUMPER_BOX is
   attr item : JUMPER;
   ...
end;
```

y luego otra vez la misma clase para una botella de agua, y otra vez para un
teléfono. Tres copias que se diferencian en una sola palabra.

## El parámetro de tipo

```sather
class LOST_BOX{T} is

   attr item : T;

   create(thing : T) : SAME is
      box ::= new;
      box.item := thing;
      return box;
   end;

end; -- class LOST_BOX{T}
```

`{T}` después del nombre de la clase es un **parámetro de tipo**. `T` no es un
tipo: es un sustituto del tipo que se indique cuando se use la clase. Dentro
de la clase, `T` se usa exactamente igual que cualquier otro nombre de tipo.

## Cómo se usa

Indica el tipo entre llaves:

```sather
   jumper ::= #LOST_BOX{STR}("blue jumper");
   count ::= #LOST_BOX{INT}(3);

   jumper.item      -- "blue jumper", a STR
   count.item       -- 3, an INT
```

`LOST_BOX{STR}` y `LOST_BOX{INT}` son dos tipos distintos. Poner uno donde se
espera el otro es un error que el compilador detecta, exactamente igual que si
hubieras escrito las dos clases a mano, que es, en efecto, lo que ocurre:
Sather construye una clase distinta a partir del patrón para cada tipo que se
use realmente.

Así que esto no tiene ningún coste en tiempo de ejecución ni supone perder
información de tipo: `jumper.item` es realmente un `STR`, no algo que haya que
comprobar o convertir.

## Más de uno

Una clase puede llevar varios parámetros, separados por comas. `FMAP{K,T}` es
el ejemplo que ya conoces.

```sather
class LABELLED{L,T} is
   attr label : L;
   attr item : T;
   ...
end;
```

## Nomenclatura

Por convención, se usan letras mayúsculas sueltas: `T` para una cosa, `K` para
una clave, `E` para un elemento. La biblioteca las usa en todas partes.
