# Instrucciones

En este ejercicio vas a hacer un poco de ingeniería de datos preprocesando algunos datos de calificaciones.
Una escuela con muchos, muchos, muchos (¿demasiados?) estudiantes está intentando hacer un análisis de datos de las calificaciones que reciben los estudiantes y busca hacerlo de forma eficiente, así que la idea es minimizar y organizar los datos.

La escala de calificaciones suele ir de 0 a 10, así que lo más eficiente es usar un tipo de datos con solo ocho bits por calificación.
- Algunos profesores usan números reales (porque son muy quisquillosos con la precisión), y tendrás que convertirlos al tipo de datos `UInt8`.
- Otros profesores usan números enteros con números negativos (para castigar a los estudiantes especialmente revoltosos), y en estos casos tendrás que convertirlos al tipo de datos `Int8`.

Una vez que hayas implementado la función para convertir las calificaciones, tendrás que escribir otra para manejar las colecciones en las que se guardan, degradando las calificaciones y devolviéndolas en orden descendente.
- Algunos profesores usan `Vector`s ordenados de forma ascendente para guardar sus calificaciones, porque son meticulosos con sus datos.
- Otros profesores usan `Set`s, que no están ordenados, para guardar sus calificaciones, porque son un poco más perezosos.

En ambas funciones tendrás que manejar las entradas no válidas lanzando un MethodError.

~~~~exercism/note
El manejo de excepciones se tratará en un Concepto posterior, así que, para los fines de este ejercicio, puedes usar la siguiente sintaxis:
```julia
throw(MethodError(f, args))
```
Donde `f` es la función y `args` es una tupla con los argumentos de entrada de la función.
Con la función `demote(n)`, `f` es `demote` y `args` es `(n,)`:
```julia
throw(MethodError(demote, (n,)))
```
~~~~

## 1. Degrada las calificaciones

Implementa el método `demote(n)`.
- Con una entrada `Float64`, debe redondear hacia arriba al número entero más cercano y devolver un tipo de datos `UInt8`.
- Con un `Integer` arbitrario, debe devolver el mismo entero en un tipo de datos `Int8`.
- Cualquier otra entrada debe lanzar un MethodError.

```julia-repl
julia> demote(4.2)::UInt8
5

julia> demote(4)::Int8
4

julia> demote("hi")
MethodError: no method matching demote(::String)     #output truncated
```

## 2. Preprocesa los datos

Implementa el método `preprocess(coll)`.
- Con una entrada `Vector`, debe degradar todos los números e invertir el vector.
- Con una entrada `Set`, debe degradar todos los números y devolver un vector ordenado en orden descendente.
- Cualquier otra entrada debe lanzar un MethodError.

```julia-repl
julia> preprocess([1, 2, 3])
3-element Vector{Int8}:
 3
 2
 1

julia> preprocess(Set([2.2, 5.8, 3.4]))
3-element Vector{UInt8}:
 6
 4
 3

julia> preprocess(42)
MethodError: no method matching preprocess(::Int64)     #output truncated
```
