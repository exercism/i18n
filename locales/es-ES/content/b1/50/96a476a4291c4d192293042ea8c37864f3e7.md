# Instrucciones

En este ejercicio vas a escribir código para analizar una cadena de montaje en una fábrica de coches.

## 1. Calcula el número de coches funcionales producidos por hora

Implementa una función que reciba el número de coches producidos por hora y la tasa de éxito, y calcule el número de coches funcionales fabricados por hora. La tasa de éxito se da como un porcentaje, de `0` a `100`:

```lua
cars.calculate_working_cars_per_hour(1547, 90)
--> => 1392.3
```

**Nota:** el valor devuelto debe ser un número decimal.

## 2. Calcula el número de coches funcionales producidos por minuto

Implementa una función que reciba el número de coches producidos por hora y la tasa de éxito, y calcule cuántos coches funcionales se producen cada minuto:

```lua
cars.calculate_working_cars_per_minute(1105, 90)
-- => 16
```

**Nota:** el valor devuelto debe ser un número entero.

## 3. Calcula el coste de producción

Normalmente, cada coche cuesta 10.000 $ producirlo por separado, independientemente de si es funcional o no. Pero con un poco de planificación, se pueden producir 10 coches juntos por 95.000 $. Por ejemplo, 37 coches se pueden producir de la siguiente manera:

37 = 3 x grupos de diez + 7 coches individuales

Así, el coste de 37 coches es:
3 \* 95.000 + 7 \* 10.000 = 355.000

Implementa una función que calcule el coste de producir un número de coches, independientemente de si son funcionales o no:

```lua
cars.calculate_cost(37)
-- => 355000

cars.calculate_cost(21)
-- => 200000
```

**Nota:** el valor devuelto debe ser un número entero.
