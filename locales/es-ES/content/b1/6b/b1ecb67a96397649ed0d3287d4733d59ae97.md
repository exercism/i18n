# Anexo a las instrucciones

## Palabras

- `tick ( matrix cols -- matrix' )`: avanza la cuadrícula una generación y devuelve la cuadrícula nueva.

Cada fila de la cuadrícula se representa como un número entero de 64 bits; `cols` es el número de columnas (como máximo 64). Por ejemplo,

```
    0 1 0
    1 0 0
    1 1 0
```

se representa como

```
0b010
0b100
0b110
```
