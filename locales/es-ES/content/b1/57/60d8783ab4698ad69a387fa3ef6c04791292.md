# Pistas

Para ayudarte a conceptualizarlo: el ejercicio usa números complejos para codificar intersecciones en una cuadrícula.
Como los números complejos pueden verse como un par de dos números, esto también puede reimaginarse como el plano bidimensional x-y, donde el eje x = eje real y el eje y = eje imaginario.

## 1. Número complejo sencillo

- Esta es una función envoltorio sencilla.
- Consulta la Introducción para ver cómo crear un número complejo usando variables.
- Ten cuidado: si no usas los argumentos con nombre, puede que los argumentos posicionales de `complex()` no sean lo que esperas.

## 2. Obtener las direcciones del conductor

- Esta función requiere una única operación matemática.
- El orden de la operación importa (es decir, no es simétrica).

## 3. Obtener la distancia Manhattan

- Recuerda que este es el número total de intersecciones (sin contar la intersección inicial) por las que pasa el taxi mientras sigue las líneas de la cuadrícula.
- Tu función `driver_directions` puede ser útil.
- Otras funciones que pueden ser útiles son [`Re()` y `Im()`][complex-ref].

## 4. Obtener la distancia «a vuelo de pájaro»

- Esta es la distancia en línea recta entre las dos intersecciones.
- Puedes verlo como la hipotenusa del camino que traza una distancia Manhattan con un solo giro.
- También se conoce como la [distancia euclídea][euclid-ref] o norma L2.
- Tu función `driver_directions` puede ser útil.
- Consulta la Introducción para ver otra función de números complejos que puedes usar opcionalmente para hallar el módulo.

## 5. Obtener las direcciones del cuervo

- Tu función `driver_directions` puede ser útil.
- Esta función invierte las direcciones norte/sur de las direcciones del conductor.
- Esto invierte la ubicación percibida respecto al «eje x».
- Consulta la Introducción para ver otra función que puedes usar opcionalmente.
