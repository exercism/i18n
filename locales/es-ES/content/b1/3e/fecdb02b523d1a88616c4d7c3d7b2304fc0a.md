# Introducción

Trabajar con datos binarios es un concepto importante en cualquier lenguaje, y Elixir ofrece una sintaxis elegante para escribir, hacer coincidir y construir datos binarios.

En Elixir, los datos binarios se conocen como el tipo bitstring. El _tipo_ de datos binarios (que no debe confundirse con los datos binarios en general) es una forma concreta de bitstring, que veremos en un ejercicio posterior.

Los literales de bitstring se definen con la forma especial de bitstring `<<>>`. Al definir un literal de bitstring, este se define por segmentos. Cada segmento tiene un valor y un tipo, separados por el operador `::`. El tipo especifica cuántos bits se usarán para codificar el valor. El tipo puede omitirse por completo, en cuyo caso se usa por defecto un valor entero de 8 bits.

```elixir
# This defines a bitstring with three segments of a single bit each
<<0::1, 1::1, 0::1>>
```

Especificar el tipo como `::1` es una forma abreviada de escribir `::size(1)`. Tienes que usar la sintaxis larga si el tamaño en bits proviene de una variable.

## Binario

Al escribir literales enteros binarios, podemos escribirlos directamente en notación de base 2 si precedemos el literal con `0b`. Ten en cuenta que, de todos modos, se mostrarán como números decimales al imprimirlos en los resultados de las pruebas o al usar iex.

```elixir
<<0b1011::4>> == <<11::4>>
# => true
```

## Truncamiento

Si el valor del segmento supera la capacidad del tipo del segmento, se truncará por la izquierda.

```elixir
<<0b1011::3>> == <<0b0011::3>>
# => true
```

## Añadir por delante y por detrás

Puedes añadir contenido tanto por delante como por detrás de un bitstring existente usando la forma especial. El tipo `::bitstring` debe usarse en el bitstring existente si este tiene un tamaño desconocido.

```elixir
value = <<0b110::3, 0b001::3>>
new_value = <<0b011::3, value::bitstring, 0b000::3>>
# => <<120, 8::size(4)>>
```

## Concatenación

Podemos concatenar bitstrings guardados en variables usando la forma especial. El tipo `::bitstring` debe usarse al concatenar dos bitstrings de tamaños desconocidos.

```elixir
first = <<0b110::3>>
second = <<0b001::3>>
concatenated = <<first::bitstring, second::bitstring>>
# => <<49::size(6)>>
```

## Coincidencia de patrones

La coincidencia de patrones también se puede usar para obtener valores de la forma especial. Tienes que saber el número de bits de cada fragmento que quieras capturar, con una excepción: el tipo `::bitstring` puede usarse para aplicar coincidencia de patrones a un bitstring de tamaño desconocido, pero solo puede usarse en el último fragmento.

```elixir
<<value::4, rest::bitstring>> = <<0b01101001::8>>
value == 0b0110
# => true
```

## Inspeccionar bitstrings

~~~~exercism/note
Puede que los bitstrings se impriman (por el ejecutor de pruebas o en iex) en un formato distinto del que se usó para crearlos. Esto suele causar confusión al aprender bitstrings.
~~~~

De forma predeterminada, los bitstrings se muestran en fragmentos de 8 bits (un byte), aunque los hayas creado con fragmentos de otro tamaño.

```elixir
<<2011::11>>
# => <<251, 3::size(3)>>
```

Si creas un bitstring que representa un string imprimible codificado en UTF-8, se muestra como un string.

```elixir
<<>>
# => ""

<<65, 66, 67>>
# => "ABC"
```
