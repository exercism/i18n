# Pistas

## General

- No te preocupes por cómo se obtienen los argumentos; céntrate en combinar los argumentos para devolver el resultado esperado.
- Unison tiene [reglas específicas de precedencia de operadores][operator-precedence]; recuerda usar paréntesis si necesitas ordenar de otra forma la aplicación de funciones.

## 1. Define si Pac-Man puede comerse un fantasma

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [booleano][boolean], si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [booleano][boolean], si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [booleano][boolean].
- Puedes usar el operador [booleano][boolean] `&&` para combinar los argumentos y obtener un resultado.

## 2. Define si Pac-Man puntúa

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [booleano][boolean], si Pac-Man está tocando una píldora de poder. El segundo argumento es un valor [booleano][boolean], si Pac-Man está tocando un punto.
- La función debe devolver un valor [booleano][boolean].
- Puedes usar el operador [booleano][boolean] `||` para combinar los argumentos y obtener un resultado.

## 3. Define si Pac-Man pierde

- Necesitas definir una función con 2 argumentos. El primer argumento es un valor [booleano][boolean], si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [booleano][boolean], si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [booleano][boolean].
- Puedes usar los operadores [booleanos][boolean] `&&` y `not` para combinar los argumentos y obtener un resultado.

## 4. Define si Pac-Man gana

- Necesitas definir una función con 3 argumentos. El segundo argumento es un valor [booleano][boolean], si Pac-Man se ha comido todos los puntos. El primer argumento es un valor [booleano][boolean], si Pac-Man tiene una píldora de poder activa. El segundo argumento es un valor [booleano][boolean], si Pac-Man está tocando un fantasma.
- La función debe devolver un valor [booleano][boolean].
- Puedes usar los operadores [booleanos][boolean] `&&` y `not` para combinar los argumentos y los resultados de las funciones invocadas.
