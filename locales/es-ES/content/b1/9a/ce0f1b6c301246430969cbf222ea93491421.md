# Acerca de

Las [cadenas de caracteres][strings] de Haxe son objetos inmutables que representan texto como una secuencia de caracteres Unicode (letras, dígitos, signos de puntuación, etc.). Las comillas dobles se usan para definir una instancia de `string`:

```haxe
var fruit:String = "Apple";
```

Se puede manipular un string llamando a uno de sus [métodos o propiedades][string-api]. Como los valores de tipo string nunca cambian una vez definidos, todos los métodos de manipulación de strings devuelven un string nuevo.

Un string está delimitado por comillas dobles (`"`). Algunos caracteres especiales necesitan [escape][escaping] mediante el carácter barra invertida (`\`). Además, los strings de Haxe pueden ocupar varias líneas, lo que permite construir fácilmente literales de string largos:

```haxe
var escaped:String = "c:\\test.txt";
var multiline:String = "
- apple
- pear
- banana";
```

La forma más sencilla de concatenar strings es usar el [operador `+`][plus-operator].

```haxe
var name:String = "Jane";
trace("Hello " + name + "!");
// => "Hello Jane!"
```

Para dar formato a strings de forma más compleja, es preferible la [interpolación de strings][interpolation]. Para ello, se encierra el string entre comillas simples (`'`) y se usa el signo del dólar (`$`) para activar la interpolación de variables. También es posible evaluar expresiones completas usando `${expr}`, donde `expr` es cualquier expresión válida de Haxe:

```haxe
var name:String = "Jane";
trace('Hello $name!');
// => "Hello Jane!"
trace('HELLO ${name.toUpperCase()}!');
// => "HELLO JANE!"
```
