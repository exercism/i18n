# Instrucciones

Vas a escribir código para gestionar un array de lenguajes de programación que quieres aprender.

## 1. Añade un lenguaje a un array

Modifica la subrutina `add-language`, que toma un array de lenguajes y un nombre de lenguaje como argumentos, para que devuelva un array con el nuevo lenguaje añadido al final.

## 2. Elimina un lenguaje de un array

Modifica la subrutina `remove-language` para eliminar el último lenguaje de un array dado.

## 3. Obtén el primer lenguaje de un array

Modifica la subrutina `first-language` para que devuelva el primer lenguaje de un array dado.

## 4. Obtén el último lenguaje de un array

Modifica la subrutina `last-language` para que devuelva el último lenguaje de un array dado.

## 5. Obtén una porción de lenguajes de un array

Modifica la subrutina `get-languages`, que toma un array de lenguajes y un array de números para los elementos deseados, para que devuelva una porción del array dado.

## 6. Comprueba si un lenguaje existe en un array

Modifica la subrutina `has-language`, que toma un array de lenguajes y un nombre de lenguaje como argumentos, para que devuelva `True` o `False` indicando si el lenguaje existe en el array dado.
