# Clases inmutables

Un `SCOREBOARD` es una cosa que cambia. Dos nombres para un mismo marcador ven la
misma puntuación, porque solo hay un marcador y ambos nombres apuntan a él.

Un rumbo no es así. `350 degrees` no se convierte en otra cosa; simplemente *es*.
Los números funcionan así, y los strings también, y tus propias clases pueden
hacerlo igual.

## immutable

```sather
immutable class BEARING is

   readonly attr degrees : INT;

end; -- class BEARING
```

Dos palabras lo cambian todo. Un objeto de una clase inmutable es un **valor**,
no algo a lo que se apunta:

- se copia cuando se asigna o se pasa, así que nadie más puede cambiar el tuyo;
- nunca puede ser void;
- y no se puede asignar a sus atributos.

## Cambiar uno creando otro

Como `degrees := 90` no está permitido, `attr` ofrece otra cosa: una rutina que
toma el nuevo valor y devuelve **un objeto nuevo** con él cambiado.

```sather
   b ::= b.degrees(90);      -- not b.degrees := 90
```

El original queda intacto. Esa es toda la técnica, y así es como se escribe
`create`:

```sather
   create(d : INT) : SAME is
      b : SAME;                     -- starts with everything at nought
      return b.degrees(d);
   end;
```

Aquí no hay ningún `new`. Un objeto inmutable siempre existe, así que `b : SAME`
ya es uno, con todos los atributos en su valor vacío.

Por lo tanto, una rutina que «cambia» un rumbo devuelve uno nuevo:

```sather
   turned(by : INT) : SAME is
      return #BEARING(degrees + by);
   end;
```

## Comparar

Los valores se comparan por lo que contienen, no por el objeto que son, pero
hay que decir cómo. Escribe `is_eq`, y `=` lo usará:

```sather
   is_eq(other : SAME) : BOOL is
      return degrees = other.degrees;
   end;
```

Sin él, `=` con dos rumbos no compila.

## Cuál elegir

Usa una clase inmutable cuando la cosa no tiene identidad y nada en ella puede
cambiar de forma sensata: un rumbo, un punto, una fecha, una longitud. Usa una
clase normal cuando la cosa es una cosa concreta a la que le pasan cosas: un
marcador, un arnés, un fichero.

La prueba consiste en si «el mismo» significa «igual» o «exactamente el mismo».
