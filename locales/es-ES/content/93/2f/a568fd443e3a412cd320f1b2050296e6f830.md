# Acerca de

Perl es un lenguaje de programación creado por Larry Wall y publicado por primera vez en 1987.

## Paquetes y módulos

Un paquete es una colección de código, que a menudo se encuentra dentro de un archivo de módulo del mismo nombre con la extensión `.pm`.
El módulo se puede importar después en otro archivo, normalmente con la palabra clave `use`.

```perl
# Foo.pm
package Foo;

# Accessible with `Foo::bar` when module is used
# or just `bar` if the subroutine is exported.
sub bar () {
    return 1;
}
```

## Variables

Existen variables escalares (`$foo`), de tipo array (`@bar`) y de tipo hash (`%baz`).
Para simplificar, aquí solo se usarán variables escalares.
Un valor escalar puede ser lo siguiente: un string, un número, un boolean o una [referencia][perlreftut] a algo.
La ausencia de un valor es `undef`.

Las palabras clave `my` y `our` declaran una variable en el scope léxico, por ejemplo, `my $foo;`.
Con `our`, la variable también se convierte en un alias de una variable de paquete del mismo nombre.
Hay otras formas de declarar variables que no se tratarán aquí.

Puedes asignar un valor a una variable con el operador `=`, por ejemplo, `$foo = 1;`, lo que se puede hacer al mismo tiempo que declaras la variable, por ejemplo, `my $foo = 1;`.

```perl
package Foo;

sub baz () {
    our $bar = 1; # Sets both $bar and $Foo::bar as 1.
    return $bar;
}

$Foo::bar = 2; # $bar is not accessible here, but $Foo::bar is.

# Both of these will print 1.
say baz;
say $Foo::bar;
```

## Subrutinas

La palabra clave `sub` declara una [subrutina][perlsub].
La palabra clave `return` sale de la subrutina y devuelve los valores especificados, o una lista vacía si no se da ninguno.
Si no se especifica `return`, el valor devuelto vendrá determinado por el contexto (escalar, lista o vacío) de la subrutina usada y su última instrucción.

```perl
sub hello () {
    return 'Hello, World!';
}
```

Las versiones recientes de Perl permiten especificar parámetros formales en una [firma][perlsubsig].
La lista de parámetros puede contener variables escalares, de tipo array o de tipo hash.
Una lista de parámetros vacía significa que la subrutina no acepta ningún argumento.
Las versiones anteriores de Perl requerían obtener los argumentos de la variable especial `@_`, lo cual no se tratará aquí.

## Comentarios

Los comentarios en Perl comienzan con un `#` que no forma parte de un string y terminan al final de la línea.
