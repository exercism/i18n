# Anexo

## Comportamiento del Zipper

El Zipper proporciona una forma funcional de navegar por un árbol de `Node`.

Todas las llamadas al Zipper deben devolver un objeto Zipper _nuevo_.
Si el Zipper no cambia valores (es decir, no se ha llamado a ningún método `Set*`), debe usar el mismo árbol subyacente.
Cuando se llama a un método `Set*`, el nuevo Zipper debe tener un árbol nuevo, dejando el árbol original sin cambios.

Las llamadas al Zipper que cambian el foco a un `Node` no válido deben devolver un error.
