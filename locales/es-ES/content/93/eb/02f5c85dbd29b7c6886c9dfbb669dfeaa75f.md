# Anexo a las instrucciones

## Implementación

Hay ocasiones en las que necesitas gestionar problemas inesperados que surgen durante la ejecución del código.
En Dart, puedes usar excepciones para gestionar estas situaciones.

Para lanzar una excepción en Dart, usa la palabra clave `throw` seguida de una instancia de la excepción concreta que quieras lanzar.
Por ejemplo, `throw Exception()` lanza una instancia del tipo base Exception.

En este ejercicio, tienes que definir una excepción personalizada llamada `InvalidNucleotideException`.
Esta excepción debe lanzarse cuando se encuentre un nucleótido no válido.
La suite de tests solo comprueba que se pasa una instancia de `InvalidNucleotideException`, así que tienes libertad para implementarla como consideres oportuno siempre que se lance correctamente.

Para más información sobre las excepciones en Dart, puedes consultar la [documentación sobre excepciones](https://dart.dev/language/error-handling).
Las excepciones personalizadas pueden crearse [implementando la interfaz Exception](https://dart.dev/language#interfaces-and-abstract-classes).
