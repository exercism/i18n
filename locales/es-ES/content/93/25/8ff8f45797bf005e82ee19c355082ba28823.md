# Acerca de

Cuatro palabras de [`grouping`][grouping] y
[`splitting`][splitting] cubren casi cualquier necesidad de
«cortar una secuencia en trozos»:

```factor
USING: grouping kernel sequences splitting splitting.monotonic ;

! Disjoint chunks of N elements
{ 1 2 3 4 5 6 7 } 3 group .
! => { { 1 2 3 } { 4 5 6 } { 7 } }

! Overlapping sliding window of N elements
{ 1 2 3 4 5 } 2 clump .
! => { { 1 2 } { 2 3 } { 3 4 } { 4 5 } }

! Split wherever a predicate fires on an element
{ 1 2 0 3 4 0 5 } [ zero? ] split-when .
! => { { 1 2 } { 3 4 } { 5 } }

! Group runs where adjacent elements are "the same" by some test
{ 1 1 2 2 2 3 } [ = ] monotonic-split .
! => { { 1 1 } { 2 2 2 } { 3 } }
```

| palabra           | efecto                                                                  |
|-------------------|-------------------------------------------------------------------------|
| `group`           | `( seq n -- groups )`: fragmentos disjuntos de tamaño *n*               |
| `clump`           | `( seq n -- clumps )`: ventanas solapadas de tamaño *n*                 |
| `split-when`      | `( seq quot: ( elt -- ? ) -- pieces )`: corta cuando el quot es verdadero |
| `monotonic-split` | `( seq quot: ( a b -- ? ) -- pieces )`: corta cuando el quot de elementos *adyacentes* es `f` |

Un modelo mental útil:

- **`group` / `clump`** se fijan en los tamaños; el parámetro *n*
  indica el tamaño de cada ventana.
- **`split-when`** se fija en *elementos individuales*; el predicado
  decide si cada elemento supone un «corte».
- **`monotonic-split`** se fija en *parejas*; el predicado decide
  si dos elementos adyacentes siguen perteneciendo a la misma racha.

[splitting]: https://docs.factorcode.org/content/vocab-splitting.html
