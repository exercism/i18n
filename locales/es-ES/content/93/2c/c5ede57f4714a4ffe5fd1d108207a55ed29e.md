# Introducción

El valor `null` se usa para denotar la _ausencia_ de un valor. Un tipo **nullable** es un tipo que permite que una variable tome el valor `null`. Para hacer que cualquier tipo sea nullable, lo envolvemos con `Null<T>`:

```haxe
var a:Int = null; // Error
var b:Null<Int> = null; // Allowed
```

Para comprobar si un valor es actualmente `null`, basta con usar una expresión `if`:

```haxe
var a:Null<Int> = 10;

if (a != null) {
  trace("a is not null"); // a is not null
}
```
