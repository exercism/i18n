# Introducción a las aserciones de tipo

Las interfaces de Go pueden introducir ambigüedad sobre el tipo subyacente.
Una aserción de tipo nos permite extraer el valor concreto subyacente del valor de la interfaz con esta sintaxis: `interfaceVariable.(concreteType)`.

Por ejemplo:

```go
var input interface{} = 12
number := input.(int)
```

NOTA: esto provocará un panic si la variable de interfaz no contiene un valor del tipo concreto.

Podemos comprobar si un valor de interfaz contiene un tipo concreto específico utilizando los dos valores devueltos de la aserción de tipo: el valor subyacente y un valor booleano que indica si la aserción se ha realizado correctamente.
Por ejemplo:

```go
str, ok := input.(string) // no panic if input is not a string
```

Si `input` contiene un `string`, `str` será el valor subyacente y `ok` será true.
Si `input` no contiene un `string`, `str` será el valor cero del tipo `string` (es decir, `""`, la cadena vacía) y `ok` será false.
No se produce ningún panic en ningún caso.

## Switch de tipo

Un **switch de tipo** puede realizar varias aserciones de tipo en serie.
Tiene la misma sintaxis que una aserción de tipo (`interfaceVariable.(concreteType)`), pero `concreteType` se sustituye por la palabra clave `type`.
Aquí tienes un ejemplo:

```go
var i interface{} = 12 // try: 12.3, true, int64(12), []int{}, map[string]int{}

switch v := i.(type) {
case int:
    fmt.Printf("the integer %d\n", v)
case string:
    fmt.Printf("the string %q\n", v)
default:
    fmt.Printf("type, %T, not handled explicitly: %#v\n", v, v)
}
```
