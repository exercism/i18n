# Introducción

En Common Lisp una función puede tener parámetros con nombre (a los que se hace referencia como «parámetros de palabra clave»). Estos se designan en la lista lambda mediante la palabra clave de lista lambda `&key`. Los parámetros de palabra clave no son parámetros obligatorios. Al igual que los parámetros opcionales, pueden recibir valores por defecto y símbolos a los que ligar su estado de «suministrado o no».

Al llamar a una función con parámetros de palabra clave, delante del valor del parámetro se escribe el nombre del parámetro como palabra clave. Quien llama a la función puede especificar los parámetros de palabra clave en cualquier orden.

```lisp
(defun keyword-parameters (&key x (y 'default) (z nil z-supplied-p))
  (list x y (if z-supplied-p (list :z-was-supplied z)
                             (list :z-was-not-supplied z))))

(keyword-parameters)            ; => (NIL DEFAULT (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :y 5)       ; => (NIL 5 (:Z-WAS-NOT-SUPPLIED NIL))
(keyword-parameters :z 10 :x 5) ; => (5 DEFAULT (:Z-WAS-SUPPLIED 10))
```

Conviene tener cuidado al combinar parámetros opcionales y de palabra clave, ya que el nombre de la palabra clave y el argumento podrían ser consumidos por los parámetros opcionales:

```lisp
(defun could-be-confusing (&optional x y &key z) (list x y z))
(could-be-confusing :z 'huh?) ; => (:Z HUH? NIL)
```
