# Instalación

El compilador Free Pascal, versión 3.2.2, se puede instalar directamente desde el gestor de paquetes en una amplia variedad de plataformas y sistemas.
Si no está disponible para tu sistema o plataforma, o si quieres instalar Free Pascal en tu directorio personal, puedes obtener los binarios desde [Free Pascal - Download][fpc-download], descomprimir el archivo tar, ejecutar ```install.sh``` y añadir ```$HOME/fpc-3.2.2/bin``` a la variable de entorno ```PATH```.

Para consultar otras opciones de instalación o una descripción más detallada, visita [Installing the Free Pascal Compiler - Free Pascal wiki][fpc-install-wiki].

[fpc-download]: https://www.freepascal.org/download.html
[fpc-install-wiki]: https://wiki.freepascal.org/Installing_the_Free_Pascal_Compiler
