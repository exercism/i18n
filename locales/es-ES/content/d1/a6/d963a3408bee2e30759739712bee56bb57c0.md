# Ejecutar los tests

Con `sbt` instalado, puedes ejecutar los tests desde la línea de comandos con:

```bash
$ sbt test
```

Ten en cuenta que ejecutar `sbt test` cada vez será lento, ya que reinicializa `sbt` en cada invocación.

`sbt` funciona como un shell: una vez iniciado, puedes ejecutar comandos dentro de él.

Por ejemplo, puedes usar `sbt` para volver a ejecutar tus tests siempre que cambien los ficheros fuente:
```bash
$ sbt
>~ test
```

Ten en cuenta que todos los tests están desactivados excepto el primero, para que trabajes en él.
Para continuar, solo tienes que eliminar la palabra clave `pending` del principio de cada caso de test.

Puedes aprender más sobre `sbt` [aquí](https://www.scala-sbt.org/).


Los tests también se pueden ejecutar desde los siguientes entornos de desarrollo (IDE):

* [Metals](https://scalameta.org/metals/docs/#running-tests)
* [IntelliJ IDEA con el plugin de Scala](https://www.jetbrains.com/idea/)
