# Números de coma flotante

En PHP, los números de coma flotante se usan para representar un subconjunto de los números reales.
Empiezan por uno o más dígitos separados por un separador decimal.

```php
<?php

$a = 1.234; 
$b = 1.2e3; 
$c = 7E-10;
$d = 1_234.567; // as of PHP 7.4.0
```

## Errores comunes

No todos los números ni todas las operaciones aritméticas pueden realizarse con números de coma flotante.
Usar números de coma flotante para representar dólares y céntimos a menudo puede dar lugar a errores de redondeo.

```php
<?php

$result = 0.1 + 0.2; // => 0.30000000000000004
```
