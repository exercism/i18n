# Instrucciones

En este ejercicio, vas a implementar una forma de llevar un registro de las puntuaciones más altas del juego más popular de tu salón recreativo local.

Tienes 6 funciones que implementar, en su mayoría relacionadas con la manipulación de un objeto que contiene puntuaciones altas.

## 1. Crea una nueva tabla de puntuaciones altas

Escribe una función `create_score_board` que cree un objeto que sirva como tabla de puntuaciones altas.
Las claves de este objeto serán los nombres de los jugadores y los valores serán sus puntuaciones.
Para las pruebas, quieres incluir directamente una entrada en el objeto.
Esta entrada inicial debe constar de `"The Best Ever"` como nombre del jugador y `1000000` como puntuación.

```jq
create_score_board
# returns an object with one initial entry
```

## 2. Añade jugadores a una tabla de puntuaciones

Para añadir un jugador a la tabla de puntuaciones altas, implementa la función `add_player`.
Toma una tabla de puntuaciones como entrada y necesita dos parámetros: el nombre del jugador y la puntuación del jugador.
La función devuelve el objeto tabla de puntuaciones con el nuevo jugador añadido.

```jq
{"José Valim", 486373}
| add_player("Dave Thomas"; 0)
# => {"Dave Thomas": 0, "José Valim": 486373} -- in some order
```

Si el jugador ya está en la tabla, devuelve la tabla sin cambios.

## 3. Elimina jugadores de una tabla de puntuaciones

Si los jugadores infringen las normas del salón recreativo, se eliminan manualmente de la tabla de puntuaciones altas.
Implementa `remove_player`, que toma una tabla como entrada y un parámetro: el nombre del jugador que se va a eliminar.
Esta función debe eliminar la entrada del jugador indicado de la tabla y devolver la nueva tabla.
Si el jugador no estaba en la tabla en primer lugar, no debe pasar nada con la tabla; debe devolverse tal cual.

```q
{"Dave Thomas": 0} | remove_player("Dave Thomas")
# => {}

{"Dave Thomas": 0} | remove_player("Rose Fanaras")
# => {"Dave Thomas": 0}
```

## 4. Aumenta la puntuación de un jugador

Si un jugador termina otra partida en el salón recreativo, se añadirá una cierta cantidad de puntos a la puntuación anterior en la tabla.
Implementa `update_score`, que toma una tabla de puntuaciones como entrada y necesita dos parámetros: el nombre del jugador y la cantidad de puntuación que se va a añadir.
La función debe devolver la tabla de puntuaciones después de realizar la actualización.

```jq
{"Freyja Ćirić": 12771000} | update_score("Freyja Ćirić"; 73)
# => {"Freyja Ćirić": 12771073}
```

Esta función debe añadir al jugador a la tabla si aún no estaba en ella.

## 5. Aplica los puntos de bonificación de los lunes

El salón recreativo mantiene una tabla de puntuaciones separada los lunes.
Al final del día, cada jugador de esa tabla obtiene 100 puntos adicionales.

Implementa la función `apply_monday_bonus`.
La función añade los puntos de bonificación a cada jugador que figura en esa tabla.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| apply_monday_bonus
# => {"Dave Thomas": 144, "Freyja Ćirić": 639, "José Valim": 365}
```

## 6. Encuentra la puntuación total

Diferentes salones recreativos compiten entre sí para determinar quién tiene los mejores jugadores.
El salón recreativo con la puntuación total más alta gana el honor.

Escribe una función `total_score`.
Toma una tabla de puntuaciones como entrada y devuelve la suma de las puntuaciones de todos los jugadores.

```jq
{
  "Dave Thomas": 44,
  "Freyja Ćirić": 539,
  "José Valim": 265
}
| total_score
# => 848
```
