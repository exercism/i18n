# Introducción

En Elixir, las funciones son ciudadanos de primera clase. Esto significa que:

- Las funciones con nombre y las funciones anónimas se pueden asignar a variables.
- Las funciones con nombre y las funciones anónimas se pueden pasar como datos, tanto como argumentos como valores devueltos.
- Las funciones anónimas se pueden crear de forma dinámica.

Las funciones anónimas, a diferencia de las funciones con nombre, no tienen una referencia estática disponible; solo están disponibles si se asignan a una variable o se invocan inmediatamente.

Podemos usar funciones anónimas para:

- Ocultar datos usando ámbito léxico (también conocido como closure).
- Crear funciones dinámicamente en tiempo de ejecución.

Las funciones anónimas empiezan con la palabra reservada `fn`, los argumentos se separan del cuerpo de la función con el token `->`, y terminan con un `end`. Al igual que con las funciones con nombre, la última expresión de la función se _devuelve implícitamente_ a la función que la llama.

Para invocar una referencia a una función, debes usar un `.` entre la variable de referencia y la lista de argumentos:

```elixir
function_variable = fn param ->
  param + 1
end

function_variable.(1)
# => 2
```

Incluso puedes usar la notación abreviada de captura para que resulte más conciso:

```elixir
variable = &(&1 + 1)

variable.(1)
# => 2
```
