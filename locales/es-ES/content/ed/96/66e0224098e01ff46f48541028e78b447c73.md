# Acerca de

[Clojure](http://clojure.org) es un lenguaje de programación dinámico dirigido a la máquina virtual de Java (JVM). 
Diseñado como un lenguaje de propósito general, Clojure combina la accesibilidad de un lenguaje de scripting con una infraestructura robusta para la programación multihilo.

Clojure es predominantemente un lenguaje de programación funcional y cuenta con un amplio conjunto de [estructuras de datos](http://clojure.org/data_structures) inmutables y persistentes.

Clojure es de código abierto, y [aquí puedes encontrar información](http://clojure.org/contributing) sobre cómo contribuir al lenguaje.

Rich Hickey, el creador de Clojure, quería un Lisp moderno para la programación funcional, simbiótico con la consolidada plataforma Java y diseñado para la concurrencia; así nació Clojure.

Estas dos citas ejemplifican los objetivos de Clojure:

* _El buen diseño no consiste en hacer grandes planes, sino en desmontar las cosas._
* _Programar no consiste en teclear... consiste en pensar._
