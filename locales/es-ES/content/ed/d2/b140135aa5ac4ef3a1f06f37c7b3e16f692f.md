# Acerca de

Una [instrucción `switch`][switch] te permite comparar un valor con varios valores posibles.
Te permite escribir código más conciso que usando varias instrucciones `else-if`.
Una instrucción `switch` empieza por la palabra clave `switch`, seguida del valor que se va a comparar.
Después puedes definir los casos con la palabra clave `case`, seguida del valor con el que se compara.
La palabra clave `default` sirve para definir el caso por defecto, cuando no coincide ninguno de los casos.
Igual que las instrucciones `else-if`, las instrucciones `switch` solo ejecutan el bloque de código asociado al primer caso que coincide.

```swift
switch value {
case 1:
    print("One")
case 2:
    print("Two")
default:
    print("Other")
}
```

Fíjate en el siguiente ejemplo:

```swift
if str == "apple" {
    print("Let's bake an apple crumble")
} else if str == "lemon" {
    print("Let's bake a lemon meringue pie!")
} else if str == "peach" {
    print("Let's bake a peach pie!")
} else {
    print("Let's buy ice cream.")
}
```

En su lugar, podría escribirse así:

```swift
switch str {
case "apple":
    print("Let's bake an apple crumble")
case "lemon":
    print("Let's bake a lemon meringue pie!")
case "peach":
    print("Let's bake a peach pie!")
default:
    print("Let's buy ice cream.")
}
```
