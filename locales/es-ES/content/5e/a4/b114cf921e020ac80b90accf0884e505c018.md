# Referencia de Rust

## Conceptos

Los ejercicios de conceptos de Rust enseñan conceptos desde los fundamentos hasta el dominio del lenguaje. Se clasifican y se enumeran a continuación.

Los conceptos de Exercism existen para servir a quienes aprenden de forma práctica, por lo que difieren de las ideas abstractas. Este documento define qué significan estos conceptos en Rust. Hemos añadido una agrupación visual a continuación para ayudar a quienes mantienen el track a crear un documento de referencia eficaz. Estas agrupaciones _no_ constituyen divisiones pedagógicas. Así que, por favor, no las uses como referencia mientras enseñas.

Las casillas de verificación indican si los conceptos ya se enseñan en la lista de correspondencia de ejercicios.

## Correspondencia de ejercicios de conceptos

Si bien lo ideal sería tener un único ejercicio de conceptos para cada uno de los conceptos enumerados arriba, que enseñe exactamente un concepto y requiera solo sus prerrequisitos, hacerlo no es del todo práctico. Por ejemplo, sería difícil diseñar un ejercicio que enseñara qué son las funciones sin requerir ningún conocimiento de las primitivas; del mismo modo, sería difícil enseñar las primitivas, con una suite de test, sin ningún conocimiento de las funciones.

Los ejercicios de esta tabla deberían formar un DAG que, con el tiempo, cubra todos los conceptos enumerados arriba.

| ejercicio                | prerrequisitos                               | enseña                                                   | narrativa                                                                        |
| ------------------------ | -------------------------------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `hello-world`            | -                                            | funciones, suites de test                                | devuelve el literal `&str` `"hello world"`                                       |
| `compiled-calculator`    | `hello-world`                                | enteros, asignación de variables                         | realiza un conjunto de operaciones matemáticas y devuelve el resultado de forma implícita |
| `conditionals`           | `hello-world`                                | condicionales                                            | debería estructurarse como `if` / `else if` / `else` de 3 ramas; devolución implícita |
| `slices`                 | `hello-world`, `compiled-calculator`         | slices                                                   | extrae un slice de un parámetro que es un slice de enteros                        |
| `loops`                  | `slices`                                     | bucle básico sobre un slice                              | idealmente con una devolución temprana, de modo que resulte engorroso expresarlo como iterador |
| `iterator-use`           | `slices`                                     | uso de iteradores, `collect`                             |
| `integer-sizes`          | `compiled-calculator`                        | enteros que no son `i32`, conversión de tipos            | todavía todos con signo                                                          |
| `unsigned-ints`          | `integer-sizes`                              | enteros sin signo                                        |
| `indexing`               | `integer-sizes`, `slices`                    | indexación, `usize`                                      |
| `floats`                 | `compiled-calculator`                        | números decimales                                        | probablemente el mismo ejercicio de calculadora compilada, con resultados no enteros |
| `bools`                  | `compiled-calculator`                        | booleanos, operadores booleanos                          |
| `char`                   | `compiled-calculator`                        | tipo de dato `char`                                      | debería incluir algunos ejemplos de caracteres anchos                            |
| `str-use`                | `char`, `slices`                             | `&str`                                                   | nota: ¡inmutable!                                                                |
| `string-use`             | `str-use`                                    | `String`                                                 | nota: propio, mutable                                                            |
| `format-macro`           | `string-use`                                 | macro `format!`                                          |
| `str-vs-string`          | `str-use`, `string-use`                      | combinar, convertir, costes, etc.                        |
| `generics-basics`        | `integer-sizes`, `floats`                    | usar traits externos como límites, genéricos básicos     | probablemente siga siendo la calculadora compilada, solo que genérica            |
| `structs`                | `string-use`, `unsigned-ints`, `floats`      | crear y usar un struct para gestionar datos              | `Person` tiene nombre, altura y cantidad de zapatos poseídos                     |
| `implicit-return`        | `compiled-calculator`                        | scopes, expresiones, devolución implícita                |
| `explicit-return`        | `implicit-return`, `conditionals`            | instrucción `return` explícita                           |
| `methods`                | `structs`, `explicit-return`                 | bloques `impl`, métodos                                  |
| `tuples`                 | `structs`                                    | tuplas                                                   | enseñar como structs anónimos; enseñar la sintaxis `.0`                          |
| `tuple-structs`          | `tuples`, `structs`                          | structs de tupla (tuplas con nombre)                     |
| `basic-enums`            | `unsigned-ints`                              | enums básicos (sin campos), `match`                      |
| `enums`                  | `basic-enums`, `tuple-structs`               | sintaxis de tupla para las variantes de un enum          |
| `option`                 | `enums`                                      | `Option<T>`                                              |
| `result`                 | `enums`                                      | `Result<T, E>`                                           |
| `mutability`             | `compiled-calculator`                        | inmutabilidad por defecto; mutabilidad explícita         |
| `let-expressions`        | `loops`, `option`, `result`                  | `if let`, `while let`                                    | probablemente solo dependa de `option` o de `result` según la implementación    |
| `vectors`                | `slices`                                     | `Vec<T>`                                                 |
| `hashmaps`               | `vectors`                                    | `Hashmap<K, V>`                                          |
| `entry-api`              | `hashmaps`                                   | Entry API                                                |
| `hashsets`               | `hashmaps`                                   | `HashSet<K>`                                             |
| `btreemaps`              | `hashmaps`                                   | `BTreeMap<K, V>`                                         |
| `deriving-traits`        | `structs`                                    | `PartialEq`, `PartialOrd`, `Debug`, `Display`, `Default` |
| `implementing-traits`    | `deriving-traits`                            | implementar un trait manualmente                         | probablemente implemente `Iterator`                                              |
| `collection-conversions` | `vectors`, `hashsets`, `implementing-traits` | `FromIterator`, `IntoIterator`                           |
