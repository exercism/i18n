# Acerca de

[`fold`][fold] es un [adaptador de iterador que consume][consuming iterator adaptor] que aplica una función a cada elemento de la iteración, acumulando el resultado en un nuevo valor.

Cada iteración de `fold` toma dos argumentos. El primero es un valor inicial para el acumulador. El segundo es un closure que a su vez toma dos argumentos: el acumulador y un elemento. El valor devuelto por el closure es el siguiente valor del acumulador. Una vez que el iterador se agota, se devuelve el valor final del acumulador.

`fold` se puede usar cuando se desea transformar una colección en un único valor. Por ejemplo, si se desea la suma de todos los números pares

```rust
pub fn main() {
    let even_sum = (1..=10).fold(0, |acc, num| if num % 2 == 0 { acc + num } else { acc });
    println!("{even_sum:?}");
}
```

Imprime `30`.

Lo que se puede hacer con `fold` a menudo se puede hacer con otra función u otras funciones. Para lo anterior, hacer [`filter`][filter] sobre `(1..=10)` y luego [`sum`][sum] sería menos verboso y daría el mismo resultado, así:

```rust
(0..=10).filter(|n| *n % 2 == 0).sum()
```

Otras funciones que se usan más que `fold` incluyen [`product`][product] y [`collect`][collect].

Un acumulador se puede usar para valores que no sean numéricos. Por ejemplo

```rust
pub fn giant_grunts(initial: char) -> String {
    ["Bee", "Fee", "Gee", "Fi", "Hi", "Fo", "Mo", "Fum", "Tum"].iter().fold(
        String::new(),
        |acc, grunt| if grunt.starts_with(initial) { acc + grunt } else { acc },
    )
}

pub fn main() {
    let song = giant_grunts('F');
    println!("{song:?}");
}
```

Imprime `FeeFiFoFum`
