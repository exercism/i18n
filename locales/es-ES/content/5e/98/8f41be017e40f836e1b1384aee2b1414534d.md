# Pruebas en la pista de MoonScript

Las pruebas en la pista de MoonScript son exactamente iguales que [las pruebas en la pista de Lua][lua-tests].
Desde el directorio de un ejercicio, ejecuta:

```console
$ busted
```

## Tests pendientes

Esta pista sigue la metodología de [desarrollo guiado por tests][tdd] de Exercism.
Se te da una suite de tests completa, pero solo el primer test está «activo».

Para activar los tests, cambia el comando de un test de `pending` a `it`.

Si eres de los que les gusta ejecutar todos los tests todo el tiempo, puedes usar una herramienta de línea de comandos para cambiarlos todos de una vez.
Aquí tienes un ejemplo usando perl (que está instalado en casi todas partes):

```console
$ perl -i -pe 's/^\s+\Kpending\b/it/' two_fer_spec.moon
```

Cuando trabajas en el editor en línea, el ejecutor de tests ejecutará todos los tests automáticamente.

## Uso de LuaRocks

Lua por sí solo es un lenguaje muy pequeño.
[LuaRocks][luarocks] es el gestor de paquetes de los módulos de Lua.

Eres libre de usar cualquier módulo en tus soluciones, pero no todos estarán disponibles en el ejecutor de tests en línea.
El ejecutor de tests incluye estos:

**Ya disponibles como dependencias de `busted`**

* [penlight][penlight-home]
* [dkjson][dkjson-home]

**Ya disponibles como dependencias de MoonScript**

* [LPeg][lpeg-home]
* [LuaFileSystem][lfs-home]

**Fecha y hora**

* [date][date-home]
* [lua-tz][lua-tz-home]
* [luatz][luatz-home]
