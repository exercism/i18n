# Instrucciones

Eres un ávido observador de aves que lleva un recuento diario de los pájaros
que visitan su jardín. Los recuentos se almacenan en un array, del día más
antiguo al más reciente.

## 1. El recuento de hoy

Define `today` para que tome el array de recuentos diarios de la pila y
devuelva el recuento de hoy.

```factor
{ 2 5 0 7 4 1 } today .
! => 1
```

## 2. Incrementar el recuento de hoy

Define `increment-todays-count` para que devuelva un array nuevo con el
recuento de hoy aumentado en uno. El array original no debe modificarse.

```factor
{ 2 5 0 7 4 1 } increment-todays-count .
! => { 2 5 0 7 4 2 }
```

## 3. ¿Hubo algún día sin pájaros?

Define `has-day-without-birds?` para que devuelva `t` si al menos un día
registró cero pájaros y, en caso contrario, `f`.

```factor
{ 2 5 0 7 4 1 } has-day-without-birds? .
! => t

{ 2 5 1 } has-day-without-birds? .
! => f
```

## 4. Sumar los primeros días

Define `count-for-first-days` para que tome un array de recuentos y un número
`n`, y devuelva la suma de los primeros `n` recuentos.

```factor
{ 2 5 0 7 4 1 } 4 count-for-first-days .
! => 14
```

## 5. Contar los días ajetreados

Un día ajetreado es aquel en el que hay cinco pájaros o más. Define `busy-days`
para que devuelva el número de días ajetreados del array.

```factor
{ 2 5 0 7 4 1 } busy-days .
! => 2
```

## 6. Rellenar los días que faltan

Si no observaste las aves todos los días de un periodo de `n` días, rellena
con `0` los días finales que faltan. Define `pad-missing-days` para que tome
un array de recuentos y una longitud objetivo `n`, y devuelva un array
de longitud al menos `n` cuyas posiciones adicionales sean `0`. Los recuentos
existentes deben conservarse sin cambios; si la entrada ya tiene al menos `n`
elementos, devuélvela sin cambios.

```factor
{ 2 5 0 } 7 pad-missing-days .
! => { 2 5 0 0 0 0 0 }

{ 4 1 6 8 } 3 pad-missing-days .
! => { 4 1 6 8 }
```
