# Instrucciones

Un [lenguaje específico de dominio (DSL)][dsl] es un lenguaje pequeño optimizado para un dominio concreto.
Como un DSL está enfocado a un dominio, puede mejorar enormemente la productividad y la comprensión, ya que permite a quien lo escribe declarar _qué_ quiere en lugar de _cómo_.

Un área problemática donde se aplican son las personalizaciones y configuraciones complejas.

Por ejemplo, el [lenguaje DOT][dot-language] te permite escribir una descripción textual de un grafo que después se transforma en una imagen con alguna de las herramientas de [Graphviz][graphviz] (como `dot`).
Un grafo sencillo tiene este aspecto:

    graph {
        graph [bgcolor="yellow"]
        a [color="red"]
        b [color="blue"]
        a -- b [color="green"]
    }

Si guardas esto en un fichero `example.dot` y ejecutas `dot example.dot -T png -o example.png`, se crea una imagen `example.png` con un círculo rojo y otro azul unidos por una línea verde sobre un fondo amarillo.

Escribe un lenguaje específico de dominio similar al lenguaje dot de Graphviz.

Nuestro DSL se parece al lenguaje dot de Graphviz en que se usará para crear estructuras de datos de tipo grafo.
Sin embargo, a diferencia del lenguaje DOT, nuestro DSL será un DSL interno que solo se podrá usar en nuestro lenguaje.

[Aprende más sobre la diferencia entre los DSL internos y externos][fowler-dsl].
