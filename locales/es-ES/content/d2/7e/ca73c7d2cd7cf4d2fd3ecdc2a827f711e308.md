# Calculadora de cocina

## Historia

La historia facilita la exploración de las [tuplas][type-tuple] en un lenguaje.

La premisa básica es que a menudo los ingredientes de cocina se miden de formas poco conocidas y requieren conversiones distintas según las cantidades o las herramientas disponibles. Las tuplas se usan para proporcionar [duck typing][concept-duck-typing] al componente numérico de la medida.

Así pues, esto explora la conversión básica de valores usando números de coma flotante.

### Conversiones

| De                       | A       |
| ------------------------ | ------- |
| 1 mL                     | 1 mL    |
| 1 taza                   | 240 mL  |
| 1 onza líquida (EE. UU.) | 29,57 mL |
| 1 cucharadita            | 5 mL    |
| 1 cucharada              | 15 mL   |

## Tareas

Esto debería guiar a los estudiantes sobre cómo usar:

- Las tuplas
- Las tuplas como información agrupada
- Obtener valores de una tupla mediante el índice del elemento
- Obtener valores de una tupla usando coincidencia de patrones
- Crear tuplas nuevas
