# Pistas

## General

- Mira la [excelente charla][phantom-builder-pattern] de Jeroen Engels sobre el patrón phantom builder

## 1. Proporciona un marcador de posición para los cofres del tesoro

- `Chest` puede ser lo mismo que `TreasureChest`, una única variante con un tipo fantasma añadido
- El marcador de posición `Chest todo` no tiene suficientes argumentos de tipo, le falta el tipo fantasma
- El tipo fantasma debe ser un registro, para que se pueda extender
- El tipo inicial es el `Chest treasure {}` sin restricciones y el tipo final es el `Chest treasure { conditions | securePassword : (), uniqueTreasure : () }` totalmente verificado
- Para pasar del tipo inicial al otro, `secureChest` y `uniqueTreasures` añadirán las condiciones `securePassword : ()` y `uniqueTreasure : ()` de forma independiente

## 2. Selecciona cofres seguros

- Puedes usar coincidencia de patrones con el `Chest` del argumento de la función
- Puedes usar la función [`String.length`][string-length] para validar la contraseña
- La condición `securePassword : ()` se añade desde la firma de tipo, no desde el cuerpo de la función
- No puedes poner un `Chest` sin restricciones dentro de un `Just` y esperar que el tipo cambie. Tienes que crear un valor nuevo con el constructor de `Chest`

## 3. Selecciona tesoros únicos

- No hay ninguna función `List.unique` que puedas usar; tendrás que crear la tuya
- Un posible enfoque es usar `List.filterMap` con una función auxiliar de tipo similar a `secureChest`
- La condición `uniqueTreasure : ()` se añade desde la firma de tipo, no desde el cuerpo de la función
- No puedes poner un `Chest` sin restricciones dentro de un `Just` y esperar que el tipo cambie. Tienes que crear un valor nuevo con el constructor de `Chest`

## 4. Disfruta del producto final

- `makeTreasureChest` debería hacer uso del constructor de tipo `TreasureChest`
