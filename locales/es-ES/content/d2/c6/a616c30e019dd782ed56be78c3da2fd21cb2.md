# Operador ternario

El operador ternario proporciona una sintaxis alternativa para realizar una comparación `if..else..` y devolver un valor.

## Sintaxis

PHP proporciona una condicional en la que se puede evaluar una acción en función de la «veracidad» de una condición.

```php
if ($condition) {
  $value = 1;
} else {
  $value = 2
}
```

Como alternativa, el operador ternario puede representar la misma operación:

```php
$value = $condition
  ? 1  // True branch
  : 2; // False branch
```

La sintaxis de la comparación es breve, y se representa así: `(condition) ? (evaluate if true) : (evaluate if false);`.

## Ventajas

La ventaja más evidente de usar un operador ternario es la brevedad, ya que la expresión condicional se escribe en menos espacio que con una instrucción `if..else..`, pero hay varias más:

- Es una expresión que se puede usar dentro de otra expresión.
- Facilita la evaluación perezosa de cada rama.

  ```php
  function expensiveCalculation(): int
  {
    // An expensive calculation is performed
    $answerToEverything = 42;
    return $answerToEverything;
  }

  $needExactAnswer = false;
  $estimatedAnswer = 40;
  $answer = $needExactAnswer ? expensiveCalculation() : $estimatedAnswer;
  ```

  En este ejemplo, si no se necesita la respuesta exacta, no se invoca el cálculo costoso.

## Inconvenientes

Los operadores ternarios tienen varios inconvenientes, por lo que conviene valorar bien su uso:

- Un operador ternario puede ser más difícil de leer, ya que depende de interpretar símbolos en lugar de usar palabras clave.
- Un operador ternario puede dar lugar a bugs sin querer, porque en PHP el operador ternario es asociativo por la izquierda, a diferencia de la mayoría de los lenguajes actuales (p. ej., C, Java o JavaScript).
- La expresión evaluada en la rama verdadera o en la falsa debe devolver un valor.

## Aún más corto

La sintaxis ternaria se puede acortar aún más: `(condition) ?: (evaluate if falsey)`.
Un uso habitual es poder proporcionar un valor de reserva en una expresión:

```php
$fruit = null;
eat($fruit ?: 'apple');
```

Esto también se conoce a veces como el _operador Elvis_ (`?:`).
