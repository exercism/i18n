# Instrucciones

Eres ayudante de un profesor y estás corrigiendo los exámenes de los estudiantes.
Llevar un registro manual de los resultados se está volviendo tedioso y propenso a errores.
Decides hacerlo un poco más interesante creando unas cuantas funciones para contar y calcular los resultados de la clase.

## 1. Redondear las puntuaciones

Aunque puedes dar «puntuación parcial» en las preguntas del examen, las puntuaciones totales del examen tienen que ser `int`s.
Así que, antes de poder hacer cualquier otra cosa con las puntuaciones de la clase, tienes que repasar las notas y convertir en `int` las puntuaciones que sean `double`.

Crea la función `round_down_scores()`, que recibe un `vector` de `student_scores`.
El redondeo que piden las escuelas es un truncamiento.
Por suerte para ti, C++ puede convertir un tipo en otro con `static_cast`.
La conversión con `static_cast` de `double` a `int` descarta todos los dígitos que quedan después del separador decimal.
Esta función debe recibir el `vector` de entrada y `return` un vector nuevo con todas las puntuaciones convertidas a `int`s.

```cpp
std::vector<double> student_scores {90.33, 40.5, 55.44, 70.05, 30.55, 25.45, 80.45, 95.3, 38.7, 40.3};
round_down_scores(student_scores)
// => {90, 40, 55, 70, 30, 25, 80, 95, 38, 40}
```

Hay otros métodos que logran el mismo resultado, pero un _cast_ es algo que se ve con frecuencia.

```cpp
int new_PI{static_cast<int>(3.14) + static_cast<int>(0.001592653589)};
// new_PI is 3.
```

## 2. Estudiantes que no aprueban

Mientras corregías el examen, te diste cuenta de que algunos estudiantes no lo estaban haciendo tan bien como esperabas.
Pero te distrajiste y olvidaste anotar exactamente _cuántos_ estudiantes eran.

Crea la función `count_failed_students()`, que recibe un `vector` de `student_scores`.
Esta función debe contar el número de estudiantes que no han aprobado y devolver ese recuento como un número entero.
Un estudiante necesita una puntuación mayor que **40** para aprobar el examen.

```cpp
count_failed_students({90,40,55,70,30,25,80,95,38,40});
// => 5
```

## 3. Calcular las calificaciones con letra

Al profesor al que ayudas le gusta asignar calificaciones con letra además de puntuaciones numéricas.
Como es raro que los estudiantes saquen un 100 en un examen, los umbrales inferiores de las «calificaciones con letra» se calculan a partir de la puntuación más alta obtenida y aumentan de forma uniforme entre esa puntuación máxima y el umbral de suspenso de **<= 40**.

Crea la función `letter_grades()`, que recibe como parámetro la puntuación «más alta» del examen y devuelve un `array` (no un vector) con los umbrales inferiores de puntuación para cada intervalo de calificación «estilo estadounidense»: `["D", "C", "B", "A"]`.

```cpp
/*Where the highest score is 100, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 55
 56 <= "C" <= 70
 71 <= "B" <= 85
 86 <= "A" <= 100
*/

letter_grades(100);
// => {41, 56, 71, 86}


/*Where the highest score is 88, and failing is <= 40.
       "F" <= 40
 41 <= "D" <= 52
 53 <= "C" <= 64
 65 <= "B" <= 76
 77 <= "A" <= 88
*/

letter_grades(88);
// => {41, 53, 65, 77}
```

## 4. Emparejar nombres con puntuaciones

Tienes las puntuaciones del examen en orden descendente y los nombres de los estudiantes correspondientes (ordenados según sus puntuaciones en el examen).
Te gustaría emparejar el nombre de cada estudiante con su puntuación en el examen e imprimir una clasificación general de la clase.

Crea la función `student_ranking()` con los parámetros `student_scores` y `student_names`.
Empareja cada nombre de estudiante del `vector` student_names con su puntuación del `vector` student_scores.
Puedes dar por hecho que cada `vector` de argumentos está ordenado de la puntuación más alta a la más baja.
La función debe devolver un `vector` de strings con el formato `<rank>. <student name>: <student score>`.

```cpp
std::vector<int> student_scores {100, 99, 90, 84, 66, 53, 47};
std::vector<std::string> student_names {"Joci", "Sara","Kora","Jan","Indra","Bern", "Fred"};
student_ranking(student_scores, student_names)
// =>
//  {"1. Joci: 100", "2. Sara: 99", "3. Kora: 90", "4. Jan: 84", "5. Indra: 66", "6. Bern: 53", "7. Fred: 47"}
```

## 5. Una puntuación «perfecta»

Aunque una puntuación «perfecta» de 100 es rara en un examen, es interesante saber si al menos un estudiante la ha conseguido.

Crea la función `perfect_score()` con los parámetros `student_scores` y `student_names`.
Los arrays son los mismos que en la tarea 4.
La función debe `return` _el primer_ `<name>` (como string) del estudiante que sacó un 100 en el examen.

Si no se encuentra ninguna puntuación de 100, debe devolverse un string vacío `""`.

```cpp
perfect_score({"Nur", "Tony", "Fatima"}, {90, 80, 100});
// => "Fatima"

perfect_score({"Nur", "Tony"}, {90, 80});
// => ""
```
