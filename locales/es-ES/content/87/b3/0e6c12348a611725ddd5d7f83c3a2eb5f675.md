# Pistas

## 1. Convierte una nota numérica en una nota con letra

- Usa una [expresión `if-then-else`][jq-man-if] con tantas ramas `elif` como necesites.

## 2. Cuenta el número de estudiantes para cada nota con letra

- El filtro `reduce` necesita un _flujo_ sobre el que iterar.
  La entrada es un objeto.
  Usa la expresión `to_entries` para transformar el objeto en un array.
- El objeto resultante debe tener todas las notas con letra posibles como claves, aunque ningún estudiante haya obtenido esa nota.
- La [asignación `+=`][jq-man-arith-assign] será útil.

[jq-man-if]: https://jqlang.org/manual/#if-then-else-end
[jq-man-arith-assign]: https://jqlang.org/manual/#arithmetic-update-assignment
