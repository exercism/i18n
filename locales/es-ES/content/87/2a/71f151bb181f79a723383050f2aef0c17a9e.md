# Instrucciones

Tu nostalgia por las tarjetas Blorkemon™️ no muestra signos de disminuir; incluso has vuelto a coleccionarlas y estás consiguiendo que tus amigos se unan a ti.

En este ejercicio, una colección de tarjetas se representa con `Set(String)`, ya que las tarjetas duplicadas no son importantes cuando tu objetivo es conseguir todas las tarjetas existentes.

## 1. Empieza una colección

Quieres que tus amigos se sumen a tu locura por Blorkemon™️, y la mejor forma es poner en marcha su colección regalándoles una tarjeta.

Implementa `new_collection`, que transforma una tarjeta en una colección.

```gleam
new_collection("Newthree")
// -> set.from_list(["Newthree"])
```

## 2. Haz crecer la colección

Una vez que tienes una colección, cobra vida propia y tiene que crecer.

Implementa `add_card`, que toma una tarjeta y una colección, y devuelve una tupla con dos valores: un `Bool` que indica si la tarjeta ya estaba en la colección, y la colección con la tarjeta añadida.

```gleam
add_card(set.from_list(["Newthree"]), "Scientuna")
// -> #(False, set.from_list(["Newthree", "Scientuna"]))
```

## 3. Empieza a intercambiar

Ahora que tus amigos vuelven a estar locos por Blorkemon™️, puedes aprovechar esto para hacer crecer tu propia colección intercambiando tarjetas.

No todos los intercambios merecen la pena, ni siquiera siempre se pueden hacer.
No puedes intercambiar una tarjeta que no tienes, y no deberías cambiar una tarjeta por otra que ya tienes.

Implementa `trade_card`, que toma dos tarjetas que intercambiar (la tuya y la suya) y tu colección actual.
El valor devuelto es una tupla de dos valores: un `Bool` que indica si el intercambio es posible y merece la pena, y la colección con la que acabarías si hicieras el intercambio (aunque en realidad no sea posible).

```gleam
trade_card("Scientuna", "Newthree", set.from_list(["Scientuna"]))
// -> #(True, set.from_list(["Newthree"]))
```

## 4. Tarjetas que todos tienen

Tú y tus amigos aficionados a Blorkemon™️ os reunís y os preguntáis cuáles son las tarjetas más comunes.

Implementa `boring_cards`, que toma una lista de colecciones y devuelve una lista de tarjetas ordenadas que tienen todas las colecciones.

```gleam
boring_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> ["Scientuna"]
```

## 5. Todas las tarjetas

¿Entre tú y tus amigos tenéis todas las tarjetas de Blorkemon™️?

Implementa `total_cards`, que toma una lista de colecciones y devuelve el número total de tarjetas diferentes que hay en todas las colecciones.

```gleam
total_cards([set.from_list(["Scientuna"]), set.from_list(["Newthree", "Scientuna"])])
// -> 2
```

## 6. Brillantes para ganar

Tu sobrino viene a visitarte pronto y te apetece impresionarlo.
A los niños les gustan las cosas brillantes, ¿verdad?
¡Las tarjetas Blorkemon™️ pueden ser brillantes!

Implementa `shiny_cards`, que toma una colección y devuelve un conjunto que contiene todas las tarjetas que empiezan por `"Shiny "`.

```gleam
shiny_cards(set.from_list(["Newthree", "Scientuna", "Shiny Scientuna"]))
// -> set.from_list(["Shiny Scientuna"])
```
