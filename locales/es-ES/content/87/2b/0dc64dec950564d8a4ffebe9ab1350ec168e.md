# Instrucciones

Trabajas para un prestigioso bufete de abogados especializado en gestionar solicitudes testamentarias singulares.

En este ejercicio vas a abrir una misteriosa cámara acorazada.
Eres el albacea de la herencia y reunirás los códigos secretos que tres familias han guardado durante mucho tiempo para obtener un número de cuenta y el código correspondiente.

Para evitar que cualquier familia abra la cámara acorazada por sí sola, esta solo puede abrirse combinando sus conocimientos con un modificador secreto que tú conoces por la última voluntad.

Tienes tres tareas, todas relacionadas con ayudar a las familias a abrir la cámara acorazada.

## 1. Toma asiento frente a las familias y despliega tus papeles

Define un espacio de nombres llamado `EstateExecutor`.
El código de las siguientes tareas debe definirse en el cuerpo del espacio de nombres `EstateExecutor`.

```ruby
class SomeName
  # The space between the class/module name
  # and the `end` keyword
  # is called body of the  namespace.
end
```

## 2. Encuentra el número de cuenta secreto

Este es tu gran momento.
Solo tú tienes la clave del modificador secreto para revelar el número de cuenta secreto.

Define el método `assemble_account_number(secret_modifier)`, que recibe como argumento el modificador secreto `Integer` y devuelve el número de cuenta ensamblado `Integer`.

Para obtener el número correcto, tienes que sumar el `bank_number_part` de cada una de las tres familias.

## 3. Último paso: introduce el código secreto

Las instrucciones del testamento te piden que sumes primero todos los fragmentos azules y después todos los rojos.
El código resultante se obtiene multiplicando ambas sumas.

Define el método `assemble_code`, que devuelve el código resultante combinando los fragmentos de las tres familias en un único resultado `Integer`.
El método no tiene ningún argumento y se basa únicamente en la información de los espacios de nombres correspondientes de las familias.
