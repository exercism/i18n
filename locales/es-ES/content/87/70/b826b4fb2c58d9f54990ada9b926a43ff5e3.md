# Instrucciones

Es otra noche ajetreada en la estación de clasificación de Amberes. Estás de guardia como jefe de circulación: hay que reagrupar los vagones de mercancías que llegan en trenes de salida, inspeccionar los enganches, dividir las rutas en las bifurcaciones y fusionar la carga idéntica para la facturación.

Cada *vagón* es un string que nombra lo que transporta:
`"coal"`, `"timber"`, `"crates"`, etc.

## 1. Acopla los vagones en trenes

Define `couple` para que tome un array de vagones y una longitud `n`, y
devuelva trenes de `n` vagones cada uno que no se solapen. El último tren
puede ser más corto si el total no se divide de forma exacta.

```factor
{ "coal" "coal" "coke" "ore" "ore" "timber" "timber" } 3 couple .
! => { { "coal" "coal" "coke" } { "ore" "ore" "timber" } { "timber" } }
```

## 2. Echa un vistazo a los enganches

Define `peek-couplings` para que tome un array de vagones y devuelva todos
los pares adyacentes, de modo que el inspector pueda examinar cada enganche.

```factor
{ "coal" "ore" "timber" "crates" } peek-couplings .
! => { { "coal" "ore" } { "ore" "timber" } { "timber" "crates" } }
```

## 3. Divide la cadena en las bifurcaciones

Define `split-at-junctions` para que tome un array de vagones y un
array de `junctions` (vagones que marcan un punto de corte), y devuelva
los tramos que quedan entre los vagones de bifurcación. Los propios vagones
de bifurcación no se conservan.

```factor
{ "coal" "coal" "switch" "ore" "switch" "timber" }
{ "switch" } split-at-junctions .
! => { { "coal" "coal" } { "ore" } { "timber" } }
```

## 4. Fusiona la carga idéntica

Define `coalesce-cargo` para que tome un array de vagones y agrupe en
secuencias los vagones *consecutivos* que transportan la misma carga.

```factor
{ "coal" "coal" "ore" "ore" "ore" "timber" "coal" } coalesce-cargo .
! => { { "coal" "coal" } { "ore" "ore" "ore" } { "timber" } { "coal" } }
```
