# Instrucciones

En este ejercicio vas a procesar líneas de registro.

Cada línea de registro es un string con el siguiente formato: `"[<LEVEL>]: <MESSAGE>"`.

Hay tres niveles de registro distintos:

- `INFO`
- `WARNING`
- `ERROR`

Tienes tres tareas, y cada una de ellas recibe una línea de registro y te pide que hagas algo con ella.

## 1. Obtener el mensaje de una línea de registro

Implementa el método (_static_) `LogLine.Message()` para devolver el mensaje de una línea de registro:

```csharp
LogLine.Message("[ERROR]: Invalid operation")
// => "Invalid operation"
```

Hay que eliminar los espacios en blanco que haya al principio o al final:

```csharp
LogLine.Message("[WARNING]:  Disk almost full\r\n")
// => "Disk almost full"
```

## 2. Obtener el nivel de registro de una línea de registro

Implementa el método (_static_) `LogLine.LogLevel()` para devolver el nivel de registro de una línea de registro, que debe devolverse en minúsculas:

```csharp
LogLine.LogLevel("[ERROR]: Invalid operation")
// => "error"
```

## 3. Reformatear una línea de registro

Implementa el método (_static_) `LogLine.Reformat()`, que reformatea la línea de registro colocando primero el mensaje y después el nivel de registro entre paréntesis:

```csharp
LogLine.Reformat("[INFO]: Operation completed")
// => "Operation completed (info)"
```
