# Apéndice de instrucciones

Hay muchas formas de resolver este ejercicio, pero hemos adaptado este ejercicio para quienes quieran practicar escribiendo sus propios [manejadores de ability][ability-handler-docs].

Escribe un ability `Zipper` que te permita navegar por una estructura de datos de árbol binario.

El ability `Zipper` en sí ya está definido, pero tendrás que implementar el manejador que le permite navegar por la estructura de datos de árbol binario que hemos designado.

Dado el siguiente árbol binario, si llamáramos a `Zipper.right`, `Zipper.right`, `Zipper.up` y luego `Zipper.left`, deberíamos estar situados en el nodo cuyo valor es `5`.

```
     1
   /   \
  2     4
 /     /  \
3     5    7
```

A efectos de este ejercicio, si llamas a `left` o `right` sobre un árbol binario que no contenga una rama izquierda o derecha, puedes devolver el valor del nodo actual.

## Cosas para reflexionar

¿En qué sentido se parece un manejador de ability a una cremallera? ¿Podrías considerar la `continuation` de una función como un puntero al siguiente «nodo» de tu programa? ¿Podrías guardar en tu manejador las llamadas anteriores a la continuation para poder navegar «hacia atrás» hasta un estado anterior?

¿Qué otras estructuras de datos podrías recorrer de esta manera? ¿Podrías escribir un Zipper sobre JSON o uno sobre el árbol del DOM HTML?
