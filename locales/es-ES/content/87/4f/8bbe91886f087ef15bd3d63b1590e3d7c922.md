# Acerca de los strings

Un [`string`][ref-string] en Kotlin es una secuencia inmutable de caracteres Unicode.

[`Immutable`][wiki-immutable] significa que cualquier operación sobre un string debe devolver un nuevo string: el string original nunca puede cambiar.

[`Unicode`][wiki-unicode] significa que se pueden representar la mayoría de los sistemas de escritura del mundo, pero (a diferencia de lenguajes más antiguos como C) no existe una correspondencia 1:1 entre caracteres y bytes.
Esto se tratará más a fondo en el concepto [`Chars`][concept-chars].

Un string va entre comillas dobles `" "`.

Algunos caracteres hay que escaparlos: `\\`, además de los habituales caracteres no imprimibles como `\t` (tabulador) y `\n` (salto de línea).

```kotlin
val s = "Escape backslash \\."
// Escape backslash \.
```

Los strings multilínea van entre 3 comillas dobles y pueden contener texto arbitrario (no hace falta escapar nada).

```kotlin
val multi = """I'm a
    multi-line
    string with special characters \ \t """
//I'm a
//    multi-line
//    string with special characters  \ \t 
```

Usa [trimIndent][trimIndent-doc] para eliminar la indentación común de las líneas.
Resulta útil para dar formato al string:

```kotlin
val multi = """
    I'm a
      multi-line
    string""".trimIndent()

//I'm a
//  multi-line
//string
```

Como alternativa, [trimMargin][trimMargin-doc] te permite especificar un delimitador.
Cada línea del `String` empieza entonces después del delimitador.
El delimitador predeterminado es `|`, pero puedes indicar otro distinto como parámetro.
Por ejemplo:

```kotlin
val multi = """
    |I'm a
    |  multi-line
    |string""".trimMargin()

//I'm a
//  multi-line
//string

val multi2 = """
    start>I'm a
    start>  multi-line
    start>string""".trimMargin("start>")

//I'm a
//  multi-line
//string
```

Los strings se pueden concatenar con `+`, pero conviene limitarse a casos cortos y sencillos.
Hay otras opciones, a menudo mejores.

## Plantillas de string

[`Templates`][ref-templates] hace referencia a lo que en otros lenguajes se llama «interpolación».

Si un string contiene un signo de dólar `$` seguido de un nombre, o contiene llaves (`{expression}`) que rodean una expresión, se sustituyen respectivamente por el valor o por el resultado de la expresión.

```kotlin
val x = 42
val st = "x is $x, x squared is {x * x}"
// x is 42, x squared is 1764
```

## Formato de strings

En la plataforma JVM (y solo en ella), `String.format()` permite un formato más preciso que las plantillas de string, con una [sintaxis][web-formats] similar a la de las funciones [`printf`][wiki-printf] (_¡muy antiguas!_).

```kotlin
String.format("%s %.3f", "π ≈", 3.14159)
//π ≈ 3.142
```

Kotlin se puede compilar para varios destinos distintos: la máquina virtual de Java, JavaScript, binarios nativos para Linux, Windows, Android y Apple, además de dos variantes de WebAssembly.

En esencia, se puede usar el mismo código para cada uno, pero las distintas capacidades de las plataformas de destino hacen que haya diferencias en cuanto a las funciones de la biblioteca estándar que se admiten.

## Funciones de string

Kotlin proporciona _muchas_ [`functions`][ref-string-functions] para manipular strings.

En su mayoría son [`extensions functions`][ref-extensions] en lugar de miembros de la clase `String`, aunque esto tiene poca repercusión en cómo las usamos.

~~~~exercism/note
Las [páginas de documentación][ref-string-functions] de Kotlin, bastante complejas, ocultan las funciones de extensión en la vista predeterminada.
En el momento de escribir esto, el contenido más valioso está oculto en una pestaña llamada `Members & Extensions`.
Haz clic en ella para expandir esa sección y ver todos los miembros y extensiones disponibles en la clase `String`.

[ref-string-functions]: https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-string/
~~~~

El siguiente ejemplo muestra solo una pequeña selección de lo que hay disponible:

```kotlin
val str = "Hello World!"

str.length              // => 12 (a property, not a function)
str.elementAt(6)        // => W
str.elementAtOrNull(20) // => null (index out of range)
str.substring(6, 11)    // => "World"
str.substringAfter(" ") // => "World!"

str.lowercase()         // => "hello world!"
str.uppercase()         // => "HELLO WORLD!"

str.startsWith("Hel")   // => true
str.endsWith("xyz")     // => false
str.indexOf("0")        // => 4

str.toCharArray()       // => [H, e, l, l, o,  , W, o, r, l, d, !]
"42".toInt() + 1        // => 43  (parsing; see also toFloat)

"Howdy!  ".trim()       // => "Howdy"
```

## Construir un string

A veces hay que construir un string largo por etapas, por ejemplo dentro de un bucle.

Concatenar strings con `+` pronto deja de ser elegante y eficiente: la inmutabilidad implica que se necesita _muchísima_ copia.

Kotlin tiene varias formas más eficientes de combinar varios strings:

- Plantillas de string, descritas antes.
- [`joinToString()][ref-jointostring], que se verá en el concepto [Lists][concept-lists].
- El [`StringBuilder`][ref-stringbuilder] de Java, que no se considera especialmente idiomático en Kotlin.
- El [`buildString()`][ref-buildstring] de Kotlin, que envuelve `StringBuilder` en una sintaxis más concisa e idiomática.
Esta toma la lógica de construcción del string como argumento lambda, algo que se tratará en un concepto posterior.

En esencia, un `StringBuilder` es una estructura similar a una lista, con muchos métodos prácticos.
Esta es una pequeña selección:

- [`append()`][ref-sb-append] para añadir al final.
- [`insert()`][ref-sb-insert] para añadir en una posición concreta.
- [`deleteAt()`][ref-sb-deleteat] y [`deleteRange()`][ref-sb-deleterange] para eliminar desde una posición o posiciones concretas.
- `toString()` para convertir a un string normal al final: concatena todo en una única operación eficiente.

```kotlin
// Available, not recommended
val sb = StringBuilder()
sb.append("Hello ")
sb.append("World!")
sb.toString()
//Hello World!
```

Un ejemplo de `buildString()`, con sintaxis de conceptos posteriores:

```kotlin
val countDown = buildString {
    for (i in 5 downTo 1) {
        append(i)
        append("_")
    }
}
// countDown is "5_4_3_2_1_"
```
