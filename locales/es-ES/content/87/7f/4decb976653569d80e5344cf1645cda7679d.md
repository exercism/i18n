# Consejos

## General

- Una función se puede definir para recibir varios argumentos empaquetados juntos usando el parámetro `*args` para argumentos de tipo `list` y `tuple`, o el parámetro `**kwargs` para argumentos basados en diccionarios o palabras clave.
- Para empaquetar o desempaquetar, usa el operador `*` o `**`.

## 1. Crea un array con todos los vagones

- Varios argumentos de los parámetros de la función se pueden empaquetar con el operador `*args`.

## 2. Corrige el array de vagones

- Usar el desempaquetado con el operador `*` te permite extraer los dos primeros elementos de un `list` mientras mantienes el resto intacto.
- Para añadir otro `list` a un `list` existente, puedes usar el operador `*` para «esparcir» el `list`.

## 3. Añade las paradas que faltan

- Usar `**kwargs` como parámetro de función permite pasar un número arbitrario de argumentos de palabra clave.
- Usar `**<dict>` como argumento desempaqueta un diccionario en argumentos de palabra clave.
- Puedes escribir los argumentos de palabra clave en un `{}` o en `dict()`.
- Para obtener los valores de un diccionario, puedes usar el método `<dict>.values()`.

## 4. Amplía la información de rutas

- Usar `**<dict>` como argumento desempaqueta un diccionario en argumentos de palabra clave.
- Puedes escribir los argumentos de palabra clave en un `{}` o en `dict()`.

## 5. Corrige el depósito de vagones

- `zip(*iterators)` se puede usar para transponer un `list` anidado.
- Para extraer datos de los iteradores que devuelve `zip`, puedes usar un bucle `for`.
- También puedes desempaquetar los iteradores que devuelve `zip` usando `*`.
  `[*content] = zip(iterator_1, iterator_2)` descomprimirá el `tuple` producido por `zip()` en un `list`.
