# Introducción

¡Este es un tema potencialmente _enorme_!
Es posible escribir un libro extenso sobre ello, y varias personas lo han hecho (busca «unicode book» en Amazon para ver algunos ejemplos).

## Una historia muy breve

Manejar caracteres en los ordenadores era mucho más sencillo hace unas décadas, cuando los programadores daban por sentado que el inglés era el único idioma importante.
Así que: 26 letras, mayúsculas y minúsculas, 10 dígitos, varios signos de puntuación, más un código (0x07) para hacer sonar una campana, y todo cabía en 7 bits: el conjunto de caracteres [ASCII][wiki-ascii].

Como es natural, la gente empezó a preguntar qué pasaba con à, ä y Ł, luego otras personas empezaron a preguntar por ऄ, ஹ y ญ, y los jóvenes querían emojis 😱.
¿Qué hacer?

Para abreviar, muchas personas inteligentes y pacientes tuvieron que formar parte de comités durante años, elaborando los detalles del conjunto de caracteres [Unicode][web-unicode] y de codificaciones como [UTF-8][wiki-utf-8], y mucho software necesitó una reescritura _muy_ complicada.
Además, se introdujeron muchos bugs nuevos.

Para evitar que _todo_ se rompiera, el diseño de Unicode/UTF-8 garantiza que los primeros 127 códigos sean idénticos a ASCII _(incluso la campana)_.

## Caracteres en Kotlin

Los lenguajes diseñados después de 2005 aproximadamente tienen la enorme ventaja de que ya existía un estándar Unicode razonablemente estable.

Kotlin (publicado por primera vez en 2011) pudo dar por sentado que los usuarios usarían una variedad de idiomas (humanos) y que necesitarían Unicode para expresarlos.

Los literales de carácter se escriben entre comillas simples y son distintos de los strings escritos entre comillas dobles.
Esto probablemente sea obvio para quienes vienen del mundo de C/C++, pero puede resultar confuso para quienes programan en Python y JavaScript.

```kotlin
val a = 'a'
a::class.qualifiedName  // => kotlin.Char
a.code  // => 97

val jha = 'झ'  // Devanagari alphabet
jha.code  // => 2333

val heart = '❤'  // heart emoji
heart.code  // => 10084

Char.MAX_VALUE.code  // => 65535 (64k, the largest code point allowed)
```

Convertir entre `Char` e `Int` es sencillo:

```kotlin
a.code  // => 97  (a.toInt() is deprecated)
Char(97) // => 'a'
```

El compilador permite _algunas_ formas de aritmética de enteros con `Char`:

```kotlin
'a' + 5       // => 'f'
'c' - 'a'   // => 2
'c' + 'a'   // => error!

'f' + ('A' - 'a')  // => 'F' (same as 'f'.uppercase()

'f'.dec() // => 'e' (decrement)
'f'.inc() // => 'g' (increment)
```

## Algunas funciones para `Char`

Como siempre, hay [demasiadas funciones][ref-char-lib] para tratarlas aquí, así que esta es solo una selección.

- Para los alfabetos adecuados, cambia entre mayúsculas y minúsculas con [`uppercase()`][ref-uppercase] y [`lowercase()`][ref-lowercase].
- Comprueba el uso de mayúsculas y minúsculas con [`isUpperCase()`][ref-isuppercase] y [`isLowerCase()`][ref-islowercase].
- Comprueba el tipo de carácter con:
    - [`isLetter()`][ref-isletter], abarca muchos alfabetos
    - [`isDigit()`][ref-isdigit], en el rango 0..9
    - `isLetterOrDigit()`, combina las dos anteriores
    - [`isWhitespace()`][ref-iswhitespace], cualquier carácter de espacio en blanco

```kotlin
'झ'.isLetter()      // => true
'A'.isLowerCase()   // => false
'4'.isDigit()       // => true
'\t'.isWhitespace() // => true  (tab character)
```

## Conversiones entre arrays de Char y strings

Para convertir un string en un array de Char, podemos usar `toList()`.

Para convertir un array de Char en un string, existe la función [`joinToString()`][ref-jointostring], que toma un separador (a menudo el string vacío) como argumento.

```kotlin
val kt = "kotlin".toList()  // => [k, o, t, l, i, n]
kt.joinToString("")   // => "kotlin"
kt.joinToString("_")  // => "k_o_t_l_i_n"
```

Ten en cuenta que `joinToString()` opera sobre un List o un Array.
Para _convertir_ un único `Char` en un string de 1 carácter, usa `toString()`.

```kotlin
'a'.toString() // => "a"
```

Para comprobar si un carácter está presente en un `String`, o en un array de `Char`, tenemos `in`, que se corresponde con la función [`contains()`][ref-contains].

```kotlin
val clist = "kotlin".toList()  // => [k, o, t, l, i, n]
't' in clist     // => true
't' in "kotlin"  // => true
```
