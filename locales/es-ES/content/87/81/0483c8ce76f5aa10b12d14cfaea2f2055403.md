# Anexo a las instrucciones

## Palabras

`find-fewest-coins ( coins target -- result )` devuelve un array
de denominaciones de monedas cuya suma es `target`. `coins` es un
conjunto hash (por ejemplo, `HS{ 1 5 10 25 }`); usa las palabras
del vocabulario `sets` (`members`, `in?`, …) para trabajar con él.

Cuando ninguna combinación de `coins` pueda formar `target`, lanza
un error `cannot-make-change`.
