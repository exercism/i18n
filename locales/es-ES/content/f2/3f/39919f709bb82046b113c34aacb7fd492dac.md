# Acerca de

Una _cadena de caracteres_ es el tipo de datos de JavaScript que se usa para almacenar datos de texto.
No existe un tipo de datos aparte para un carácter individual.

## Crear un string

Creas un string [literal][literal] envolviendo el texto entre comillas simples o comillas dobles.
En Exercism se usan comillas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

Algunos caracteres especiales del texto hay que precederlos con una barra invertida `\`; consulta las [secuencias de escape en MDN][mdn-escape-sequences].

<!-- prettier-ignore-start -->
```javascript
const text = 'I\'m having fun.\nWhat about you?';
console.log(text);
// => I'm having fun.
// => What about you?
```
<!-- prettier-ignore-end -->

Además de las comillas simples y dobles, también puedes crear un string envolviendo el texto entre comillas invertidas.
Esta sintaxis permite incluir comillas simples o dobles e incluso saltos de línea sin necesidad de escaparlos.
También permite incrustar expresiones; consulta las [cadenas de plantilla][mdn-template-strings] para obtener más detalles.

```javascript
`A multi-line string
with 'single quotes'
and "double quotes"`;
```

## Los strings como arrays de caracteres

Un string se puede tratar como un array de caracteres en el que el primer carácter tiene índice `0`.
Puedes acceder a un carácter concreto del string usando corchetes y el índice de la letra que quieras obtener.
Como alternativa, también tienes el método `charAt`.

```javascript
'cat'[1];
// => 'a'

'cat'.charAt(2);
// => 't'
```

Puedes determinar el número de caracteres de un string accediendo a la propiedad `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenación y métodos

La forma más sencilla de concatenar strings es usar el operador de suma `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Los strings incluyen muchos métodos auxiliares; consulta la [documentación de MDN sobre métodos de string][mdn-string-methods] para ver la lista completa.
En la siguiente lista se muestran algunos de los métodos auxiliares más habituales.

- [`toUpperCase`][mdn-to-upper-case] y [`toLowerCase`][mdn-to-lower-case]: cambian a mayúsculas o minúsculas todos los caracteres
- [`trim`][mdn-trim]: elimina los espacios en blanco del principio y del final
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] y [`endsWith`][mdn-ends-with]: determinan si otro string forma parte del string en cuestión
- [`slice`][mdn-slice]: extrae una sección del string

## Los strings son inmutables

Aplicar los métodos anteriores nunca cambiará el string original. En su lugar, se crea y se devuelve un nuevo string.
Los strings (y otros tipos de datos primitivos) son inmutables en JavaScript.
Eso también significa que no puedes asignar un carácter distinto en un índice usando la sintaxis de corchetes mostrada arriba (como harías con los arrays).

```javascript
const str = 'cat';
str[1] = 'u'; // fails silently
console.log(str);
// => 'cat'
```
