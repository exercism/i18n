# Anexo de las instrucciones

## Pistas

Para completar este ejercicio, tienes que crear el tipo de dato `Matrix`,
con las instancias `Eq` y `Show`, e implementar las siguientes funciones:

- `cols`
- `column`
- `flatten`
- `fromList`
- `fromString`
- `reshape`
- `row`
- `rows`
- `shape`
- `transpose`

Encontrarás una declaración de datos ficticia y las firmas de tipo ya puestas,
pero depende de ti definir las funciones y crear un tipo de dato,
un newtype o un sinónimo de tipo con sentido.

No es necesario validar la entrada. Deja que falle si la matriz no es
rectangular, si se encuentran caracteres no válidos, etc.

shape es (rows, cols)
