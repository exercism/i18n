# Notas para este ejercicio en el track de Python

Puedes hacer las siguientes suposiciones sobre las entradas de prueba de la
función `sum_of_multiples`:

- Todos los números de entrada son **_`int` no negativos_** (_es decir, números naturales
incluido el cero_).
- Se debe proporcionar un `list` de factores, y sus elementos son únicos
y están ordenados de forma ascendente.
