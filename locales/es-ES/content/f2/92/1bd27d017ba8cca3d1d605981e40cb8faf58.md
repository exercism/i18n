# Acerca de

Los condicionales en C++ son similares a los condicionales de otros lenguajes.
El tipo subyacente de cualquier operación condicional es el tipo `bool`, que puede tener el valor `true` o `false`.
A menudo, los condicionales se usan como mecanismos de control de flujo para comprobar distintas condiciones.

Se puede usar una instrucción `if`, que ejecuta su código si la condición subyacente es `true`, así:

```cpp
std::string value{"val"};

if (value == "val") {
    return "was val";
}
```

En situaciones con más de un caso, se pueden encadenar varias instrucciones `if` usando las instrucciones `else if` y `else`.

```cpp
int number{33};

if (number > 0) {
   return "positive";
} else if (number < 0) {
    return "negative";
} else {
   return "zero";
}
```

Desde C++17, las instrucciones `if` también pueden incluir una instrucción de inicialización corta que sirve para inicializar una o más variables para la propia instrucción `if`.
Por ejemplo:

```cpp
int num{7};
if (int v{2 * num}; v > 10) {
    return v;
} else {
    return num;
}
// => 14
```

> Nota: no se puede acceder a las variables creadas en la inicialización después del final de la instrucción `if`.
