# Anexo a las instrucciones

## Pistas

Para completar este ejercicio necesitas crear el tipo de datos `BST`,
con instancias de `Eq` y `Show`, e implementar las funciones:

- `bstLeft`
- `bstRight`
- `bstValue`
- `empty`
- `fromList`
- `insert`
- `singleton`
- `toList`

Encontrarás ya en su sitio una declaración de datos de prueba y las firmas de tipo,
pero depende de ti definir las funciones y crear un tipo de datos, un newtype o un
sinónimo de tipo que tenga sentido.
