# Introducción

Cuando el número de iteraciones de un bucle no se conoce de antemano, es decir, cuando se trata de «seguir hasta que algún predicado deje de ser verdadero», Factor usa el combinador `while` de [`kernel`][kernel]:

```
while ( pred body -- )
```

Tanto `pred` como `body` son quotations que operan sobre la pila de datos. `while` llama a `pred`; si deja un valor verdadero en la parte superior, `while` ejecuta `body` y repite; en caso contrario, se detiene. El estado que pasa de una iteración a la siguiente vive en la pila entre llamadas (o en variables locales con nombre cuando hay más de un dato de estado).

```factor
USING: kernel math ;

5 [ dup 0 > ] [ dup . 1 - ] while drop
! prints 5 4 3 2 1
```

`until` es la forma simétrica: sigue avanzando *hasta que* el predicado se vuelve verdadero.

[kernel]: https://docs.factorcode.org/content/vocab-kernel.html
