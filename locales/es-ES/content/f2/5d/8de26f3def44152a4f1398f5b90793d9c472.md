# Introducción

Un tipo de dato algebraico (TDA) representa un número fijo de casos con nombre.
Cada valor de un TDA se corresponde exactamente con uno de esos casos.

Un TDA se define con la palabra clave `data`, con los casos separados por barras verticales (`|`).
Si ninguno de los casos tiene datos asociados, el TDA es similar a lo que en otros lenguajes se suele llamar una _enumeración_ (o _enum_).

```haskell
data Season
  = Spring
  | Summer
  | Autumn
  | Winter
```

Cada caso de un TDA puede tener datos asociados de forma opcional, y los distintos casos pueden tener distintos tipos de datos.
Cuando un caso tiene datos asociados, se necesita un constructor.

```haskell
data Number
  = NInt Int      --'NInt' is the constructor for an Int Number.
  | NFloat Float  --'NFloat' is the constructor for an Float Number.
  | Invalid       --'Invalid' does not have data associated to it.
```

Para crear un valor de un caso concreto, basta con referirse a su nombre (por ejemplo, `NInt 22`).
Como los nombres de los casos no son más que funciones constructoras, los datos asociados se pueden pasar como un argumento normal de función.

Los TDA tienen _igualdad estructural_, lo que significa que dos valores del mismo caso y con los mismos datos (opcionales) son equivalentes.

Aunque se pueden usar expresiones `if/else` para trabajar con TDA, la forma recomendada de hacerlo es la coincidencia de patrones mediante la instrucción _case_:

```haskell
add1 :: Number -> String
add1 number =
    case number of
      NInt    i -> show (i + 1)
      NFloat  f -> show (f + 1.0)
      Invalid   -> error "Invalid input"
```
