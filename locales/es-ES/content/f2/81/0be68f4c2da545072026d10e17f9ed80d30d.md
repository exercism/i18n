# Instrucciones

En este ejercicio vas a organizar carreras entre varios tipos de coches teledirigidos.
Cada coche tiene sus propias características de velocidad y descarga de batería.

Los coches empiezan con las baterías llenas (100 %).
Cada vez que conduces el coche con el mando a distancia,
avanza tantos metros como la velocidad del coche y reduce el porcentaje de batería restante según su descarga.

Si la batería de un coche está por debajo de su porcentaje de descarga, ya no puedes conducir el coche.

Cada pista de carreras tiene su propia distancia.
Los coches se prueban comprobando si pueden terminar la pista sin quedarse sin batería.

## 1. Crea un coche teledirigido

Define un struct `Car` con los siguientes campos de tipo `int`:

- battery
- batteryDrain
- speed
- distance

Permite crear un coche teledirigido definiendo una función `NewCar` que recibe la velocidad del coche en metros
y el porcentaje de descarga de la batería como sus dos parámetros (ambos de tipo `int`) y devuelve una instancia de `Car`:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
// => Car{speed: 5, batteryDrain: 2, battery:100, distance: 0}
```

## 2. Crea una pista de carreras

Define otro tipo struct llamado `Track` con el campo `distance` de tipo entero.
Permite crear una pista de carreras definiendo una función `NewTrack` que recibe la distancia de la pista en metros como su único parámetro (que es de tipo `int`):

```go
distance := 800
track := NewTrack(distance)
// => Track{distance: 800}
```

## 3. Conduce el coche

Implementa la función `Drive` que actualiza el número de metros recorridos según la velocidad del coche y reduce la batería según su descarga.
Si no hay batería suficiente para conducir una vez más, el coche no se moverá:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)
car = Drive(car)
// => Car{speed: 5, batteryDrain: 2, battery: 98, distance: 5}
```

## 4. Comprueba si un coche teledirigido puede terminar una carrera

Para terminar una carrera, un coche debe ser capaz de recorrer la distancia de la carrera.
Esto significa no agotar su batería antes de cruzar la línea de meta.
Implementa la función `CanFinish` que recibe una instancia de `Car` y otra de `Track` como parámetros y devuelve `true` si el coche puede terminar la carrera; en caso contrario, devuelve `false`.

Supón que actualmente estás en la línea de salida de la carrera y arrancas el motor del coche para la carrera.
Ten en cuenta que es posible que la batería del coche no esté necesariamente completamente cargada al comenzar la carrera:

```go
speed := 5
batteryDrain := 2
car := NewCar(speed, batteryDrain)

distance := 100
track := NewTrack(distance)

CanFinish(car, track)
// => true
```
