# no uses `%%` ni `/`

Como se menciona en las instrucciones, el objetivo de este ejercicio es construir una criba de Eratóstenes sin usar operaciones como la división o el módulo.
Consulta el [enlace de Wikipedia][wikipedia] para ver una descripción del algoritmo.

Construir la criba de Eratóstenes sin operaciones como la división o el módulo puede resultar complicado,
pero es un algoritmo precioso, inventado hace más de dos milenios, que merece la pena aprender e implementar.
