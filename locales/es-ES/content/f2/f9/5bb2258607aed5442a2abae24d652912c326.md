# Apéndice de instrucciones

## Implementación

Define una única función de Go, MakeChain, que acepta un slice de fichas de dominó e intenta construir una cadena válida de fichas de dominó.

MakeChain debe tener la siguiente firma:

```go
type Domino [2]int

func MakeChain(input []Domino) (chain []Domino, ok bool)
```

El resultado `ok`, de tipo bool, indica si la lista de fichas de dominó de entrada dada se puede disponer en una cadena válida.
Una lista de entrada vacía se considera válida, y una única ficha de dominó cuyos lados son iguales también se considera válida.

El resultado «chain» es un slice de cero o más fichas de dominó dispuestas en un orden que muestra la cadena válida.
Es aceptable (y de esperar) que las fichas de dominó de «input» tengan que rotarse para que cada lado coincida con la ficha adyacente de la cadena.
Las fichas de dominó al principio y al final de la cadena también deben coincidir entre sí por el lado exterior.

Si el slice de fichas de dominó de entrada dado no se puede disponer en una cadena válida,
MakeChain puede devolver nil como resultado de chain, pero debe devolver false como resultado de ok.

Como puede haber más de una cadena válida posible para una lista de entrada dada, cuando `ok` es true, el programa de prueba solo comprobará que la cadena sea válida.
