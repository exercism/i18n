# Instrucciones

Eres un ávido observador de aves que lleva la cuenta de cuántas aves han visitado tu jardín.
Normalmente usas marcas en un cuaderno para contar las aves, pero para trabajar mejor con tus datos, has digitalizado los recuentos de aves de las últimas semanas.

## 1. Determina el número total de aves que has contado hasta ahora

Empecemos analizando los datos con una visión general.
Averigua cuántas aves has contado en total desde que empezaste tus registros.

Implementa una función `totalBirdCount` que acepte un array de valores `Int` que contenga el recuento de aves por día.
Debe devolver el número total de aves que has contado.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
totalBirdCount(birdsPerDay)
// Returns 34
```

## 2. Calcula el número de aves visitantes en una semana concreta

Ahora que ya tienes una idea general de tus cifras de recuento de aves, quieres hacer un análisis más detallado.

Implementa una función `birdsInWeek` que acepte un array de recuentos de aves por día y un número de semana.

Devuelve el número total de aves que contaste en esa semana concreta.
Puedes suponer que las semanas siempre se registran completas.

```swift
let birdsPerDay = [2, 5, 0, 7, 4, 1, 3, 0, 2, 5, 0, 1, 3, 1]
birdsInWeek(birdsPerDay, weekNumber: 2)
// Returns 12
```

## 3. Corrige un error de recuento

Te diste cuenta de que, todo el tiempo que estuviste intentando llevar la cuenta de las aves, había un ave que se escondía en un rincón apartado del jardín.

Descubriste que esta ave pasaba siempre en tu jardín un día sí y otro no.

No sabes exactamente dónde estaba entre esos días, pero desde luego no en tu jardín.

Tu intuición de observador de aves también te dice que el ave estaba en tu jardín el primer día que registraste en tu lista.

Con esta nueva información, escribe una función `fixBirdCountLog` que reciba como argumento un array de aves contadas por día y devuelva el array después de corregir el error de recuento.

```swift
var birdsPerDay = [2, 5, 0, 7, 4, 1]
fixBirdCountLog(birdsPerDay)
// Returns [3, 5, 1, 7, 5, 1]
```
