# Introducción

Un `array` en F# es una colección mutable de cero o más valores con una longitud fija. Esto significa que, una vez creado un array, su tamaño no puede cambiar, pero sus valores sí. Todos los valores de un array deben tener el mismo tipo. Los arrays pueden definirse así:

```fsharp
let empty = [| |]
let emptyAlternative = Array.empty

let singleValue = [| 5 |]
let singleValueAlternative = Array.singleton 5

let threeValues = [| "a"; "b"; "c" |]
```

Los elementos se pueden asignar a un array o recuperar de él usando un índice. Los arrays de F# están basados en cero, lo que significa que el índice del primer elemento siempre es cero:

```fsharp
let numbers = [| 2; 3; 5 |]

// Update value in array
numbers[2] <- 9

// Read value from array
numbers[2]
// => 9
```

Los arrays se manipulan con las funciones y los operadores definidos en el módulo `Array`, o manualmente mediante la coincidencia de patrones, usando el patrón _array_:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty"
    | [| 1; 2; three |] -> sprintf "1, 2, %d" three
    | _ -> "Other"

describe [| |]         // => "Empty"
describe [| 1; 2; 4 |] // => "1, 2, 4"
describe [| 5; 7; 9 |] // => "Other"
```

También puedes _descartar_ un valor al hacer coincidencia de patrones; cuando _no_ te importe un valor en un caso concreto (es decir, no vas a _usar_ ese valor), puedes usar un guion bajo (`'_'`) para indicarlo:

```fsharp
let describe array =
    match array with
    | [| |] -> "Empty array"
    | [| x |] -> "Array with one item"
    | [| _; y |] -> "Array with two items (first item ignored)"
    | _ -> "Array with many items (all items ignored)"

describe [| |]          // => "Empty array"
describe [| 1 |]        // => "Array with one item"
describe [| 5; 7 |]     // => "Array with two items (first item ignored)"
describe [| 5; 7; 9 |]  // => "Array with many items (all items ignored)"
```

El único `'_'` debe ir siempre al _final_ al hacer coincidencia de patrones; todo valor que _no_ coincida con ninguno de los otros casos se gestionará con este caso.
