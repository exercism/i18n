## 1. Lleva a los humanos al mundo de Troya

- El núcleo de este ejercicio es el uso de `unique_ptr` y `shared_ptr`.
  ¿Qué tipo de puntero inteligente deberías usar para cada una de las variables `human`?
- Los `artifacts` no se comparten, pero `powers` es necesario para hacer un seguimiento de las personas influenciadas.
- el puntero `possession` debe ser único y los punteros de poder deben ser compartidos.

## 2. Lleva los artefactos a Troya

- Necesitas crear un puntero inteligente y asignarlo a la variable `possession`
- Usa _referencias_ para cambiar el objeto fuera de la función.
- Consulta [`std::make_unique`][make_unique] para obtener algunas pistas.
- El tipo del objeto al que apunta el puntero debe indicarse entre corchetes angulares y de nuevo dentro de los paréntesis para definir el objeto.
- Aquí tienes un ejemplo completo: `variable = std::make_unique<int>(int{23});`
