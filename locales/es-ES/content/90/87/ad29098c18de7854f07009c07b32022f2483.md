# Introducción

## Operadores ternarios

El _operador ternario_ es una alternativa ligera y compacta para instrucciones _if/else_ simples. Normalmente se usa en instrucciones return (aunque no solo en ellas), y basta con una sola línea para tomar la decisión: devuelve el valor de la izquierda si la expresión es `true` y el valor de la derecha si es `false`, de la siguiente manera:

```java
boolean expr = 0 != 200;

// Ternary statement
int value = expr ? 22 : 33;
// => 22
```

Muchas expresiones _if/else_ simples se pueden simplificar con _operadores ternarios_.
