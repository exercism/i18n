# Instrucciones

Implementa un evaluador para un subconjunto muy sencillo de Forth.

[Forth][forth]
es un lenguaje de programación basado en pila.
Implementa un evaluador muy básico para un pequeño subconjunto de Forth.

Tu evaluador tiene que admitir las siguientes palabras:

- `+`, `-`, `*`, `/` (aritmética de enteros)
- `DUP`, `DROP`, `SWAP`, `OVER` (manipulación de la pila)

Puedes usar una tupla como pila para evitar fift y los códigos de operación relacionados con la pila de asm.

Para simplificar, el único tipo de datos que necesitas admitir es el de enteros con signo de al menos 16 bits de tamaño.

Debes usar las siguientes reglas para la sintaxis: un número es una secuencia de uno o más dígitos (ASCII), y una palabra es una secuencia de una o más letras, dígitos, símbolos o signos de puntuación que no sea un número.
(Es probable que Forth use reglas algo diferentes, pero esto se acerca bastante.)
