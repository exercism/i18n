# Introducción

A veces, cuando recorres una secuencia, necesitas la *posición* del elemento junto al propio elemento. La familia `*-index` en [`sequences`][sequences] entrega ambos a la quotation de cada elemento. `times` es el primo cercano para la iteración contada simple, útil cuando solo necesitas un recuento, no una secuencia.

## `each-index` y `map-index`: el índice en la quotation

```
each-index ( seq quot: ( elt index -- )       -- )
map-index  ( seq quot: ( elt index -- newelt ) -- newseq )
```

La quotation recibe el elemento debajo del índice; `index` está en la **cima** de la pila:

```factor
USING: io kernel math.parser sequences ;

{ "alice" "bob" "carol" } [
    number>string ": " glue print
] each-index
! prints:
! alice: 0
! bob:   1
! carol: 2

{ 10 20 30 } [ + ] map-index .
! => { 10 21 32 }       (index added to each element)
```

`each-index` ejecuta la quotation por su efecto secundario y no devuelve nada. `map-index` recoge los resultados de cada elemento en una nueva secuencia del mismo tipo que la entrada.

## `times`: iteración contada

`times` (en [`math`][math]) ejecuta su quotation `n` veces.

```
times ( n quot: ( -- ) -- )
```

La forma publicada `( -- )` es el *mínimo*, porque `times` es `inline`, una quotation equilibrada en efectos como `( str -- str )` funciona bien, y la pila se va pasando de una iteración a otra. Eso te da un acumulador para una iteración contada sin ningún estado mutable:

```factor
USING: kernel sequences ;

"" 3 [ "clop " append ] times .    ! => "clop clop clop "
```

El cuerpo de cada iteración ve el string en curso, le añade contenido y deja el nuevo string en la pila para la siguiente iteración. El mismo truco funciona para `each-index` y `map-index` cuando quieres pasar un acumulador de una iteración a otra.
