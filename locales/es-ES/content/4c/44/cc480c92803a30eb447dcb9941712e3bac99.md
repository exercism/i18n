# Instalación

La distribución de Racket se puede descargar desde https://download.racket-lang.org

Se proporcionan instaladores para 

* Windows
* Linux
* macOS

Consulta la página [Getting Started](http://docs.racket-lang.org/getting-started/) de Racket para obtener materiales de orientación.

La [Racket Guide](https://docs.racket-lang.org/guide/intro.html) te introduce en el uso interactivo de Racket. 

Consulta [DrRacket: The Racket Programming Environment](https://docs.racket-lang.org/drracket/index.html) para obtener orientación sobre el uso del IDE de DrRacket.

Consulta [Command-Line Tools and Your Editor of Choice](https://docs.racket-lang.org/guide/other-editors.html) para obtener una introducción a las herramientas de línea de comandos de Racket y al uso de otros editores.


## Acerca del instalador de Linux:
La compilación de Linux es lo bastante genérica como para funcionar en la mayoría de las distribuciones, incluidas las relativamente antiguas. 

Después de descargar el archivo de instalación, ejecútalo con
```
sh racket-8.10-x86_64-linux-cs.sh
```

Es posible que tengas que añadir `sudo` al principio del comando para instalar en una ubicación que requiera permisos de administrador.

**Advertencia: es posible que Racket también esté disponible a través del gestor de paquetes de tu distribución, aunque puede ser más antiguo que la última versión de Racket.**
Aunque puedes optar por hacerlo más adelante, como estudiante tendrás una experiencia mucho mejor si te quedas con la versión actual disponible en https://download.racket-lang.org


## Acerca del instalador de macOS:

Si tu ordenador usa procesadores de la serie M1 o M2, selecciona **Apple Silicon** en el menú desplegable de plataforma antes de descargar.
