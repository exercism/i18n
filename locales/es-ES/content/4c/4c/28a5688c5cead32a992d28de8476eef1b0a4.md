# Instalación

Hay muchas formas de instalar Zig, y el número de formas de instalar Zig no deja de crecer a medida que el lenguaje madura.
Por suerte, todos los métodos de instalación populares están en la [página de instalación de Zig][install-zig].

## Versión de Zig

Exercism usa Zig 0.17.0 (publicada el 1 de octubre de 2026).

Es posible que un ejercicio sea compatible con otra versión de Zig, pero no está garantizado.
Zig todavía no ha alcanzado la versión 1.0 y los cambios que rompen la compatibilidad son habituales.

## Utilidades adicionales

### Zig fmt: generar código bien formateado

Al resolver cualquier ejercicio, puedes usar todo tipo de estilos de código en tus soluciones.
Sin embargo, fuera de la resolución de ejercicios, por ejemplo al crear aplicaciones o bibliotecas, suele ser buena idea que tu código sea coherente y legible.
Esas consideraciones son especialmente importantes cuando otras personas que quieran ayudar con tus proyectos tengan que leer tu código.

Para solucionar este problema, el compilador de Zig incluye un [linter][linters] ligero integrado que formatea tu código de forma cómoda.
Este formateador de código pretende seguir la [guía de estilo][style-guide] ya establecida por la [documentación de Zig][documentation].

Para ver las funcionalidades del formateador nativo de Zig, usa el siguiente comando:

```bash
zig fmt --help
```

### Zig Zen: reglas para escribir código

A veces, un poco de orientación ayuda mucho al hacer cualquier tarea, incluso al escribir código.
Por suerte, el compilador de Zig incluye un comando divertido que nos recuerda algunos de los objetivos que hay detrás de escribir buen código Zig.

Para consultar estas palabras de sabiduría, puedes usar el siguiente comando:

```bash
zig zen
```

### El servidor de lenguaje de Zig: soporte completo para editores de Zig

Este software de terceros ofrece autocompletado en el editor y funciones mejoradas de navegación por el código Zig, que pueden ayudarte a aprender el lenguaje más rápido.

Consulta la [guía de instalación de ZLS][install-zls] para ver las instrucciones más recientes.
