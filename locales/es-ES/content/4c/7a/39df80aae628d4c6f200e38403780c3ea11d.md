# Instrucciones

Acabas de empezar a trabajar en la recepción de un rocódromo.
Los socios compran abonos por un número de meses y registran su entrada y su salida cada vez que vienen.
El gerente te ha pedido que escribas una clase de ayuda que responda a las preguntas que más hacen los socios.

## 1. Averigua cuándo termina un abono

Un abono que empieza en una fecha determinada termina el mismo día del mes, el número de meses indicado más tarde.
Cuando ese día no existe en el mes final, el abono termina el último día de ese mes.

Implementa el método `FrontDesk.membershipEnd()`, que recibe la fecha de inicio de un abono y su número de meses, y devuelve la fecha en la que termina:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipEnd(LocalDate.of(2024, 3, 10), 1);
// => LocalDate.of(2024, 4, 10)
frontDesk.membershipEnd(LocalDate.of(2025, 1, 31), 1);
// => LocalDate.of(2025, 2, 28)
```

## 2. Muestra cuánto dura un abono

En la tarjeta de socio, el gimnasio imprime cuánto dura el abono en años, meses y días.

Implementa el método `FrontDesk.membershipLength()`, que recibe la fecha de inicio y la fecha de fin de un abono, y devuelve la duración del abono como un `Period`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.membershipLength(LocalDate.of(2023, 3, 10), LocalDate.of(2024, 5, 25));
// => Period.of(1, 2, 15)
```

## 3. Cuenta los días que le quedan a un abono

Los socios preguntan a menudo cuántos días les quedan antes de que termine su abono.

Implementa el método `FrontDesk.daysLeft()`, que recibe la fecha de hoy y la fecha de fin de un abono, y devuelve el número total de días desde hoy hasta la fecha de fin.
Cuando la fecha de fin es hoy o ya ha pasado, no quedan días, así que el método devuelve `0`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.daysLeft(LocalDate.of(2024, 1, 15), LocalDate.of(2024, 3, 20));
// => 65
frontDesk.daysLeft(LocalDate.of(2024, 4, 2), LocalDate.of(2024, 3, 20));
// => 0
```

## 4. Mide una visita

El gimnasio está abierto las 24 horas y el torniquete registra la fecha y la hora en que cada socio entra y sale.

Implementa el método `FrontDesk.visitDuration()`, que recibe la fecha y hora de entrada y de salida de una visita, y devuelve cuánto duró la visita como un `Duration`:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.visitDuration(LocalDateTime.of(2024, 3, 10, 23, 30), LocalDateTime.of(2024, 3, 11, 1, 15));
// => Duration.ofMinutes(105)
```

## 5. Imprime una visita en el recibo

El recibo muestra la duración de una visita en horas y minutos, así: `1h 35m`.
Los minutos se escriben siempre con dos dígitos, los segundos se descartan y las horas no están limitadas a un solo día.

Implementa el método `FrontDesk.formatVisit()`, que recibe la duración de una visita y la devuelve con este formato:

```java
FrontDesk frontDesk = new FrontDesk();
frontDesk.formatVisit(Duration.ofMinutes(95));
// => "1h 35m"
frontDesk.formatVisit(Duration.ofHours(2).plusMinutes(5));
// => "2h 05m"
frontDesk.formatVisit(Duration.ofHours(26).plusMinutes(10));
// => "26h 10m"
```
