# Consejos

## 1. Crea un inventario nuevo con los elementos

- Tienes que devolver con `return` una referencia a un hash desde la subrutina `create_inventory`, que contenga los elementos como claves y, como valores, la cantidad de cada uno indicada en la referencia al array `$items`.

## 2. Añade elementos al inventario a partir de los elementos

- Tienes que devolver con `return` una referencia a un hash desde la subrutina `add_items`, con la cantidad de elementos aumentada en tantos como haya en la referencia al array `$items`.

## 3. Elimina los elementos del inventario

- Tienes que devolver con `return` una referencia a un hash desde la subrutina `remove_items`, con la cantidad de elementos reducida en tantos como haya en la referencia al array `$items`.
- El recuento de elementos no debe quedar por debajo de `0`.

## 4. Borra el elemento por completo del inventario

- Tienes que devolver con `return` una referencia a un hash desde la subrutina `delete_item`, con el elemento eliminado por completo del inventario.
