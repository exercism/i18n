# Acerca de

[Los cons][hyper-conses] son un tipo de datos básico en Common Lisp. Están compuestos por una cabeza y una cola (llamadas, por [razones históricas][history], el `car` y el `cdr`).
No hay ninguna restricción sobre los tipos de datos de la cabeza y la cola de un cons.

Los cons se crean con la función [`cons`][hyper-cons], que recibe dos objetos y evalúa a un cons (a veces también llamado «celda cons»).

Se puede acceder a las partes de un cons con las funciones [`car`][hyper-car] y [`cdr`][hyper-cdr].

## Referencia

```lisp
;; Testing for atoms
(atom 'foo)              ; => T
(atom '(bar baz))        ; => NIL

;; Testing for cons
(consp 'foo)             ; => NIL
(consp '(bar baz))       ; => T

;; First item of a cons
(car '(one two three))   ; => ONE
(first '(one two three)) ; => ONE

;; Rest of a cons
(cdr '(one two three))   ; => (TWO THREE)
(rest '(one two three))  ; => (TWO THREE)
```
