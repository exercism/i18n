# Instrucciones

Un robot de fiesta está colocando banderines para la gran bonanza. Cada
fila de banderines es una línea horizontal de `n` banderines pequeños, y
el carácter de cada banderín viene determinado por la posición que ocupa en
la fila, contando desde la izquierda y empezando en `0`. Ayuda al robot
a montar los patrones que aparecen a continuación.

## 1. Banderines alfabéticos

Define `alphabet-bunting` para que tome un número entero no negativo `n` de
la pila y devuelva un string con las primeras `n` letras minúsculas
del alfabeto.

```factor
5 alphabet-bunting .
! => "abcde"

0 alphabet-bunting .
! => ""
```

Puedes asumir que `n` es como máximo `26`.

## 2. Banderines numéricos

Define `counting-bunting` para que tome `n` y devuelva un string de `n`
dígitos en el que el banderín de la posición `i` muestre `i mod 10`.

```factor
12 counting-bunting .
! => "012345678901"
```

## 3. Banderines a rayas

Define `stripe-bunting` para que alterne entre dos caracteres: las
posiciones pares llevan `*` y las impares llevan `-`.

```factor
6 stripe-bunting .
! => "*-*-*-"

1 stripe-bunting .
! => "*"
```

## 4. Banderines con marcador

Cada quinto banderín es un marcador especial. Define `marker-bunting` de
forma que las posiciones `0`, `5`, `10`, … lleven `|` y el resto lleven `.`.

```factor
11 marker-bunting .
! => "|....|....|"
```

## 5. Banderines de valle

El robot cuelga una fila de banderines de tamaño fijo, con 10 banderines,
que se sujeta a un gancho en el centro. Contando desde el banderín más a la
izquierda, en la posición `-5`, hasta `5` (sin incluirlo), el carácter de
cada banderín es la distancia al centro, escrita como dígito.

Define `valley-bunting` (que no recibe ninguna entrada) para que devuelva
ese string fijo.

```factor
valley-bunting .
! => "5432101234"
```
