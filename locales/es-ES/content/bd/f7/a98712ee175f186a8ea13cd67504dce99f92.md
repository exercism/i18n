# Introducción

## Espacios de nombres

Los espacios de nombres son una forma de agrupar código relacionado y evitar conflictos de nombres, y por lo general están presentes en todas las bases de código salvo las más triviales.

La sintaxis es la siguiente:

```csharp
namespace MyNameSpace
{
    public class MyClass {}

    public class OtherClass {}
}
```

Se hace referencia a los tipos incluidos en espacios de nombres, fuera del ámbito del espacio de nombres, anteponiendo la sintaxis de punto al nombre del tipo. Como alternativa, y más habitualmente, puedes colocar una directiva `using` al principio del archivo (o dentro de un espacio de nombres) y el tipo se puede usar sin el prefijo. Dentro del mismo espacio de nombres no es necesario calificar los nombres de tipo.

```csharp
namespace MySpace
{
    public class MyClass {}

    public class Foo
    {
        public void Bar()
        {
            var baz = new MyClass();
        }
    }
}

public class Qux
{
    public void Box()
    {
        var nux = new MySpace.MyClass();
    }
}

namespace OtherSpace
{
    using MySpace;

    public class Tix
    {
        public void Jeg()
        {
            var lor = new MyClass();
        }
    }
}
```

Puedes crear un alias de un espacio de nombres con la sintaxis `using MyAlias = MySpace;` y luego usar el alias en cualquier lugar donde se pudiera usar el espacio de nombres.
