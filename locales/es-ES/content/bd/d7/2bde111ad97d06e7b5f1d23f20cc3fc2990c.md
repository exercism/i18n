# Instrucciones

`Two-fer` o `2-fer` es la forma corta de dos por uno: uno para ti y uno para mí.

Dado un nombre, devuelve un string con el mensaje:

```text
One for name, one for me.
```

Donde «name» es el nombre dado.

Sin embargo, si no se proporciona el nombre, devuelve el string:

```text
One for you, one for me.
```

Aquí tienes algunos ejemplos:

|Nombre  |String que devolver
|:-------|:------------------
|Alice   |One for Alice, one for me.
|Bob     |One for Bob, one for me.
|        |One for you, one for me.
|Zaphod  |One for Zaphod, one for me.
