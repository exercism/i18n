# Introducción

Un [array][list] es una colección mutable de elementos en _secuencia_.
 Son estructuras de datos extremadamente flexibles y útiles que muchos métodos y operaciones `built-in` de Python producen como salida.
 Los arrays pueden contener referencias a cualquier tipo (o múltiples tipos) de datos, incluidos otros arrays u otras estructuras de datos como [tuplas][tuples], [conjuntos][sets] o [diccionarios][dicts].
 Se puede iterar sobre el contenido usando la construcción `for item in <list>`.
 Si se necesitan índices junto con el contenido, se puede usar `for index, item in enumerate(<list>)`.
 Se puede acceder a los elementos dentro de un `list` mediante un número de índice `0-based index` desde la izquierda, o un número de índice `-1-based index` desde la derecha.
 Los arrays se pueden copiar enteros o en parte usando  la _notación de rebanada_ o `<list>.copy()`.
