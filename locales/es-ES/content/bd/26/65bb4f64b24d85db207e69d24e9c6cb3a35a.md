# Debug

Cuando falla una prueba, se muestra un mensaje que describe qué ha ido mal y para qué entrada. Puedes inspeccionar valores arbitrarios de tu programa pasándolos al método `debug` (disponible en `exercism/test_runner`). Así se capturarán los valores y se te mostrará la salida.

```gleam
import exercism/test_runner.{ debug }

let value: String = "test"
debug("The value is " <> value)
```
