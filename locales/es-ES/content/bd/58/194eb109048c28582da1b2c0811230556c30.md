# Introducción

Una _cadena de caracteres_ es el tipo de dato de JavaScript que se usa para almacenar datos de texto.

## Crear un string

Creas un string envolviendo el texto entre comillas simples o comillas dobles.
En Exercism se usan comillas simples.

<!-- prettier-ignore-start -->
```javascript
'Hello, World!'
"Hello, World!"
```
<!-- prettier-ignore-end -->

## Los strings como arrays de caracteres

Un string se puede tratar como un array de caracteres en el que el primer carácter tiene el índice `0`.
Puedes acceder a un carácter concreto del string usando corchetes y el índice de la letra que quieras obtener.

```javascript
'cat'[1];
// => 'a'
```

Puedes determinar el número de caracteres de un string accediendo a la propiedad `length`.

```javascript
'cat'.length;
// => 3
```

## Concatenación y métodos

La forma más sencilla de concatenar strings es usar el operador de suma `+`.

```javascript
'I like' + ' ' + 'cats.';
// => "I like cats."
```

Los strings proporcionan muchos métodos auxiliares; consulta la [documentación de MDN sobre los métodos de String][mdn-string-methods] para ver la lista completa.
La siguiente lista muestra algunos de los métodos auxiliares más usados.

- [`toUpperCase`][mdn-to-upper-case] y [`toLowerCase`][mdn-to-lower-case] - cambian las mayúsculas y minúsculas de todos los caracteres
- [`trim`][mdn-trim] - eliminan los espacios en blanco del principio y del final
- [`includes`][mdn-includes], [`startsWith`][mdn-starts-with] y [`endsWith`][mdn-ends-with] - determinan si otro string forma parte del string dado
- [`slice`][mdn-slice] - extrae una sección del string

Los strings son inmutables en JavaScript. Así que una «modificación», por ejemplo con alguno de los métodos anteriores, siempre creará un string nuevo en su lugar.
