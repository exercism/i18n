# se ha creado una variable adicional para el nombre

Crear una variable adicional para guardar el nombre es innecesario, ya que Go no pasa las variables por referencia.
Reasignar `name` no cambiará el valor más allá del scope de la función `ShareWith`.
Como Go no ofrece una forma de proporcionar valores predeterminados a los parámetros de una función,
en Go es una práctica habitual reasignar el valor para dar uno predeterminado.
