# Acerca de

## Herencia

Java admite la herencia como una de sus funcionalidades básicas y, gracias a ella, se pueden aplicar muchos principios de la programación orientada a objetos, como la abstracción.

Una clase puede extender otra clase con la palabra clave `extends` y puede heredar de una interfaz con la palabra clave `implements`.

## Modificadores de acceso

Los modificadores de acceso definen las reglas sobre el acceso desde otras clases (o desde cualquier parte del código) a las variables miembro y los métodos de una clase.

Hay cuatro modificadores de acceso:

- `private`
- `public`
- `protected`
- predeterminado (no se necesita ninguna palabra clave)

Puedes leer más sobre ellos [en este artículo][access-modifiers]

## Herencia frente a composición

Estos conceptos son muy similares y a menudo se confunden.

- La herencia significa que la clase hija tiene una relación IS-A con la clase padre.

```java
interface Animal() {
    public void bark();
}

class Dog implements Animal {
    public void bark() {
        System.out.println("Bark");
    }
}
```

Aquí, `Dog` IS-A `Animal`

- La composición representa una relación HAS-A.

```java
interface Engine {

}

class Car {
    private Engine engine;
}
```

Aquí, `Car` HAS-A `Engine`
