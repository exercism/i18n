# Pistas

## General

- Un [valor entero][integers] se puede definir como uno o más dígitos consecutivos.
- Si ves un error `panic` al ejecutar las pruebas, se debe a que no has implementado una de las funciones (debería indicar cuál) o a que has dejado el código de plantilla tal cual.
  Tienes que eliminar la línea `panic!(...)` del código proporcionado y sustituirla por una implementación real.

## 1. Define el tiempo de horno esperado en minutos

- Tienes que definir una [función][functions] sin ningún parámetro.
- Tienes que [devolver][return] el tiempo de horno esperado en minutos desde la función.

## 2. Calcula el tiempo de horno restante en minutos

- Tienes que definir una [función][functions] con un único parámetro.
- El parámetro de la función es un [número entero][integers].
- Tienes que [devolver explícitamente un número entero][return] desde una función.
- Puedes [llamar][functions] a una de las otras funciones que hayas definido antes.
- Puedes usar el [operador matemático de resta][operators] para restar valores.

## 3. Calcula el tiempo de preparación en minutos

- Tienes que definir una [función][functions] con un único parámetro.
- El parámetro de la función es un [número entero][integers].
- Tienes que [devolver explícitamente un número entero][return] desde una función.
- Puedes usar el [operador matemático de multiplicación][operators] para multiplicar valores.

## 4. Calcula el tiempo de trabajo transcurrido en minutos

- Tienes que definir una [función][functions] con dos parámetros.
- El parámetro de la función es un [número entero][integers].
- Tienes que [devolver explícitamente un número entero][return] desde una función.
- Puedes [llamar][functions] a una de las otras funciones que hayas definido antes.
- Puedes usar el [operador matemático de suma][operators] para sumar valores.
