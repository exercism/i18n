# Instrucciones

Vas a escribir un poco de código para gestionar un array de lenguajes de programación que quieres aprender.
El array se llamará `@LanguageList::Languages`.

## 1. Añadir un lenguaje al array @Languages

Modifica la subrutina `LanguageList::add_language`, que recibe un nombre de lenguaje como argumento, para añadir el lenguaje al final del array `@LanguageList::Languages`.

## 2. Eliminar un lenguaje del array @Languages

Modifica la subrutina `LanguageList::remove_language` para eliminar el último lenguaje del array `@LanguageList::Languages`.

## 3. Obtener el primer lenguaje del array @Languages

Modifica la subrutina `LanguageList::first_language` para que devuelva el primer lenguaje del array `@LanguageList::Languages`.

## 4. Obtener el último lenguaje del array @Languages

Modifica la subrutina `LanguageList::last_language` para que devuelva el último lenguaje del array `@LanguageList::Languages`.

## 5. Obtener una porción de lenguajes del array @Languages

Modifica la subrutina `LanguageList::get_languages`, que recibe un array de números correspondientes a los elementos que se quieren, para que devuelva una porción del array `@LanguageList::Languages`.

## 6. Comprobar si un lenguaje existe en el array @Languages

Modifica la subrutina `LanguageList::has_language`, que recibe un nombre de lenguaje como argumento, para que devuelva un valor verdadero o falso que indique si el lenguaje existe en el array `@LanguageList::Languages`.
