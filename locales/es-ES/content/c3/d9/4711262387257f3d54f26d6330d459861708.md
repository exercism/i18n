# Arrays

Un **array** contiene una fila de valores, todos del mismo tipo, en orden.

El tipo se escribe `ARRAY{T}`, donde `T` es lo que contiene. Un array de
strings es `ARRAY{STR}`; un array de números enteros es `ARRAY{INT}`.

```sather
   row : ARRAY{STR} := |"Mia", "Ana", "Ben"|;
```

Los valores entre las dos marcas `|` son el **literal de array**. Sather
deduce el tamaño a partir de cuántos hay.

## Obtener un valor

Los corchetes indican la posición:

```sather
row[0]      -- "Mia"
row[1]      -- "Ana"
row[2]      -- "Ben"
```

El recuento empieza en **cero**, no en uno. Así que el primer valor está en
`0`, y el último en una fila de tres está en `2`.

## ¿Cuántos?

`.size` indica cuántos valores contiene el array.

```sather
row.size    -- 3
```

Como el recuento empieza en cero, la última posición es siempre `.size - 1`:

```sather
row[row.size - 1]     -- "Ben"
```

Pedir una posición que no existe, como `row[3]` o `row[-1]`, es un error que
Sather no detectará por ti, así que merece la pena escribir `.size - 1` en
lugar de contar los valores a ojo.

## Recorrer un array

Un array y un bucle van de la mano. Incrementa una variable a lo largo de las
posiciones y úsala para acceder a cada valor:

```sather
   total ::= 0;
   i ::= 0;
   loop
      until!(i >= scores.size);
      total := total + scores[i];
      i := i + 1;
   end;
```
