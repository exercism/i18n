# Introducción

El tipo `char` de F# es un valor de 16 bits que representa el componente de texto más pequeño al que se puede acceder, y es inmutable por defecto.

Los `char` se pueden definir como literales con comillas simples:

```fsharp
let ch = 'A'
// => val ch: char = 'A'
```

Las cadenas de caracteres son una secuencia de caracteres.

Se puede obtener un `char` concreto de una cadena mediante indexación (empezando en cero):

```fsharp
"Exercism"[4] //  =>  'c'
```

Al iterar sobre una cadena se obtiene un `char` en cada paso.

El siguiente ejemplo utiliza una función de orden superior y una función anónima, por comodidad.
Estas se tratarán adecuadamente más adelante en el temario, pero por ahora son, esencialmente, una forma concisa de escribir un bucle sobre los caracteres de una cadena.

```fsharp
Seq.map (fun c -> c, int c) "F#"  //  =>  [('F', 70); ('#', 35)]
```

Como se muestra arriba, un `char` se puede convertir a su valor `int`.
Esto también funciona (*al menos en algunos casos*) con otros sistemas de escritura:

```fsharp
Seq.map (fun c -> c, int c) "東京"  //  =>  [('東', 26481); ('京', 20140)]
```

Para comparar caracteres se utiliza el valor Int16 subyacente:

```fsharp
'A' < 'D'  // =>  true
```

Además, un `int` se puede convertir a `char`:

```fsharp
char 77  // => 'M'
```

La biblioteca `System.Char` contiene el conjunto completo de métodos que se esperan de un lenguaje .NET, como las conversiones a mayúsculas y minúsculas:

```fsharp
'a' |> System.Char.ToUpper  // =>  'A'

'Q' |> System.Char.ToLower  // =>  'q'
```
