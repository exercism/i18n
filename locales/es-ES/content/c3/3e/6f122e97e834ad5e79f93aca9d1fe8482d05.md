# Marcador de posición

## Consejos sobre `jq`

Este ejercicio consiste en tomar un objeto de entrada y transformarlo en un objeto nuevo.
Un par de funciones integradas que pueden ayudarte:

- [`to_entries`][x_entries]
  - esta función toma un objeto como entrada
  - genera un _array_: cada elemento del array es un objeto `{"key": "K", "value": V}`
    - cada `K` es una clave del objeto de entrada
    - cada `V` es el valor correspondiente a `K`.
- [`from_entries`][x_entries]
  - la operación inversa
  - toma un array de objetos `{"key": K, "value": V}` y construye un objeto

Un ejemplo:

```sh
jq -n '
    {
        "username": "glennj",
        "tracks": ["bash", "awk", "jq"],
        "reputation": 123
    }
    | to_entries
'
```

produce

```json
[
  {
    "key": "username",
    "value": "glennj"
  },
  {
    "key": "tracks",
    "value": ["bash", "awk", "jq"]
  },
  {
    "key": "reputation",
    "value": 123
  }
]
```

[x_entries]: https://jqlang.org/manual/#to_entries-from_entries-with_entries
