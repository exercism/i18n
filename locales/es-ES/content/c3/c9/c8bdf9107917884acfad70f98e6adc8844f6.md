# Introducción

El atributo Flags permite que los valores definidos en una unión discriminada se representen como posiciones de bits (es decir, banderas).
Como banderas, dichos valores se pueden combinar, lo que permite representar varias condiciones booleanas en un único valor.

```fsharp
[<Flags>]
type PhoneFeatures =
| Call = 1
| Text = 2
```

```fsharp
[<Flags>]
type PhoneFeaturesBinary =
| Call = 0b00000001
| Text = 0b00000010
```

Se puede activar una bandera con el operador OR bit a bit (`|||`); se puede desactivar una bandera con una combinación del operador AND bit a bit (`&&&`) y el operador de negación bit a bit (`~~~`).
Aunque se puede comprobar el estado de una bandera con el operador AND bit a bit, también se puede usar el método `HasFlag()`.

```fsharp
let features = PhoneFeatures.Call

// Set the Text flag
let moreFeatures = features ||| PhoneFeatures.Text

moreFeatures.HasFlag(PhoneFeatures.Call) // => true
moreFeatures.HasFlag(PhoneFeatures.Text) // => true
```

Consulta el [Resumen de los operadores bit a bit][bitwise-operators] para obtener una lista completa de los operadores bit a bit disponibles en el lenguaje F#.
