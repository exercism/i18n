# Pruebas

## Ejecutar las pruebas

1. Consigue un ejercicio:

    ```bash
    $ exercism download -track=kotlin --exercise=hello-world
    ```

2. Cambia al directorio del ejercicio:

    ```bash
    $ cd <path_to_exercise_directory>
    ```

3. Ejecuta las pruebas:

    ```bash
    $ ./gradlew test
    ```

En la mayoría de los ejercicios, solo se ejecuta la primera prueba por defecto.  
Las demás pruebas están anotadas con `@Ignore` para omitirlas.  
A medida que resuelvas cada prueba, elimina el `@Ignore` de la siguiente para avanzar.

Esta es una práctica habitual en el desarrollo guiado por pruebas (o TDD para abreviar).
Se utiliza para asegurarte de que trabajas en un problema a la vez.
