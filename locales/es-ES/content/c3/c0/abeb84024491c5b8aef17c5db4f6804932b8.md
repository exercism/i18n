# Instrucciones

Usa la criba de Eratóstenes para encontrar todos los números primos desde 2 hasta un número dado.

La criba de Eratóstenes es un algoritmo sencillo y antiguo para encontrar todos los números primos hasta un límite dado.
Lo hace marcando de forma iterativa como compuestos (es decir, no primos) los múltiplos de cada primo, empezando por los múltiplos de 2.
No usa ninguna operación de división ni de residuo.

Crea tu rango, empezando en dos y continuando hasta el límite dado incluido.
(es decir, [2, limit])

El algoritmo consiste en repetir lo siguiente una y otra vez:

- toma el siguiente número disponible sin marcar en tu array (es primo)
- marca todos los múltiplos de ese número (no son primos)

Repite hasta que hayas procesado cada número de tu rango.

Cuando el algoritmo termina, todos los números del array que no se hayan marcado son primos.

[Este artículo de Wikipedia][eratosthenes] tiene un gráfico útil que explica el algoritmo.

Fíjate en que este es un algoritmo muy específico, y las pruebas no comprueban que hayas implementado el algoritmo, solo que hayas obtenido el array correcto de números primos.
Una buena primera prueba es comprobar que no usas operaciones de división ni de residuo (div, /, mod o % según el lenguaje).

[eratosthenes]: https://en.wikipedia.org/wiki/Sieve_of_Eratosthenes
