# Instrucciones

Un mismo fabricante puede producir dos tipos diferentes de motores; a partir de aquí, los
motores se llamarán motor A y motor B. Ambos motores tienen 3 componentes necesarios para
la producción: cableado, taladrado y montaje. Cada motor requiere una cantidad de tiempo
distinta para cada una de estas etapas de producción. Por lo general, una unidad de motor A
necesita t_a_1 horas de cableado, t_a_2 horas de taladrado y t_a_3 horas de montaje. Por otro
lado, una unidad de motor B necesita t_b_1 horas de cableado, t_b_2 horas de taladrado y
t_b_3 horas de montaje. Implementa una función que, dados el total de horas asignadas a cada
etapa de producción (t_1 horas para el cableado, t_2 horas para el taladrado y t_3 horas para
el montaje) y los precios de cada tipo de motor (p_a, p_b), calcule las cantidades óptimas
de motor A y motor B que maximizan el beneficio.

La función tendrá 4 parámetros de entrada en total. Se describen a continuación:
1. a_hours: tupla de tres elementos (t_a_1, t_a_2, t_a_3) en horas
2. b_hours: tupla de tres elementos (t_b_1, t_b_2, t_b_3) en horas
3. total_hours: tupla de tres elementos (t_1, t_2, t_3) en horas
4. prices: tupla de dos elementos (p_a, p_b) en dólares

La salida debe ser una única tupla de tres elementos formada por (q_a, q_b, profit), donde:
1. q_a: cantidad óptima de motor A que hay que producir
2. q_b: cantidad óptima de motor B que hay que producir
3. profit: valor del beneficio máximo en dólares

Otros puntos importantes a tener en cuenta:
q_a y q_b no pueden ser números de coma flotante, porque no se puede producir una fracción de motor.
Los resultados del modelo Z3 para las variables tendrán que convertirse al tipo int antes de generar la salida. Si el
resultado del modelo Z3 es de tipo `IntNumRef`, se puede usar el método de clase `as_long()` para convertirlo en un número entero.
Si el problema no tiene solución debido a entradas no válidas, lanza la excepción integrada de Python `ArithmeticError()`.
