# Pruebas

## Resumen
 
- Ve al directorio del problema (p. ej. `~/Exercism/hello-world`).
- Inicia una sesión de `jconsole` en un terminal.
- Carga tu archivo de solución (p. ej. `load 'hello-world.ijs'`).
- Carga el framework de pruebas unitarias escribiendo `load  'general/unittest'`.
- Prueba tu solución escribiendo `unittest 'test.ijs'`.
<br></br>
- Como alternativa, es posible ejecutar las pruebas en una sola línea así: `jconsole -js "load 'hello-world.ijs'" "echo unittest 'test.ijs'" "exit 0"`.

## Sesión de Jconsole

La forma en que están configuradas las pruebas del track se ha pensado para que sea lo más sencilla posible.
Si estás trabajando en un ejercicio, digamos `hamming.ijs`, así es como debería desarrollarse el trabajo.
Edita `hamming.ijs` y escribe tu solución.
Constrúyela de forma interactiva escribiendo primero:

```j
NB. your j terminal binary may be ijconsole (eg. on Debian)
jconsole 'hamming.ijs' NB. start a J console session with definitions loaded hamming.ijs
```

Después, desde dentro de la consola de J, vuelve a cargarla escribiendo

```j
load 'hamming.ijs'
```

El siguiente paso es cargar el framework de pruebas unitarias escribiendo

```j
load 'general/unittest'
```

Para ejecutar las pruebas, una vez que hayas cargado tu solución, escribe

```j
unittest 'test.ijs'
```

Y después observa los resultados.

## Línea de comandos

Puedes ejecutar las pruebas con un comando de una sola línea en el terminal usando el flag -js:

```j
jconsole  -js "load 'hamming.ijs'" "echo unittest 'test.ijs'" "exit 0"
```
donde cada argumento representa un comando que se ejecutará de forma secuencial.
